DESCRIPTIO

N

Les fonctions getservent_r(), getservbyname_r() et getservbyport_r() sont les équivalents réentrants de respectivement, getservent(3), getservbyname(3) et getservbyport(3). Elles diffèrent dans la manière dont la structure servent est retournée, ainsi que dans la signature d'appel et la valeur de retour de la fonction. Cette page de manuel décrit uniquement les différences par rapport aux fonctions non

réentrantes.

Au lieu de retourner un pointeur vers une structure servent allouée statiquement en tant que résultat de la fonction, ces fonctions copient la structure à l'emplacement pointé par result_buf

.

Le tableau buf est utilisé pour stocker les champs de chaîne pointés par la structure servent retournée. (Les fonctions non réentrantes allouent ces chaînes dans un stockage statique.) La taille de ce tableau est spécifiée dans size. Si buf est trop petit, l'appel échoue avec l'erreur ERANGE, et l'appelant doit réessayer avec un tampon plus grand. (Un tampon de 1024 octets devrait être suffisant pour la plupart des applications.

)

Si l'appel de fonction obtient avec succès un enregistrement de service, alors *result est défini pour pointer vers result_buf ; sinon, *result est d

éfini à
NULL.

RENVOYÉE

En cas de succès, ces fonctions renvoient 0. En cas d'erreur, elles renvoient l'un des numéros d'erreur positifs listés dans

erreurs.

En cas d'erreur, enregistrement non trouvé (getservbyname_r(), getservbyport_r()), ou fin de l'entrée (getservent_r()) result est d

éfini à
NULL.

EXEMPLE

S

Le programme ci-dessous utilise getservbyport_r() pour récupérer l' enregistrement de service pour le port et le protocole nommés dans son premier argument de ligne de commande. Si un troisième argument (entier) de ligne de commande est fourni, il est utilisé comme valeur initiale pour size ; si getservbyport_r() échoue avec l'erreur ERANGE, le programme réessaie avec des tailles de tampon plus grandes. La session shell suivante montre quelques exécutions d'exemple

: 


$ ./a.out 7 tcp 1
ERANGE! Réessai avec un tampon plus grand
getservbyport_r() a renvoyé : 0 (succès)  (size=87)
s_name=echo; s_proto=tcp; s_port=7; aliases=
$ ./a.out 77777 tcp
getservbyport_r() a renvoyé : 0 (succès)  (size=1024)
Échec de l'appel/enregistrement non
trouvé

Source du

programme 
#define _GNU_SOURCE
#include <ctype.h>
#include <errno.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MAX_BUF 10000
int
main(int argc, char *argv[])
{
    int size, erange_cnt, port, s;
    struct servent result_buf;
    struct servent *result;
    char buf[MAX_BUF];
    char *protop;
    if (argc < 3) {
        printf("Usage: %s port-num proto-name [size]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    port = htons(atoi(argv[1]));
    protop = (strcmp(argv[2], "null") == 0 ||
              strcmp(argv[2], "NULL") == 0) ?  NULL : argv[2];
    size = 1024;
    if (argc > 3)
        size = atoi(argv[3]);
    if (size > MAX_BUF) {
        printf("Exceeded buffer limit (%d)\n", MAX_BUF);
        exit(EXIT_FAILURE);
    }
    erange_cnt = 0;
    do {
        s = getservbyport_r(port, protop, &result_buf,
                            buf, size, &result);
        if (s == ERANGE) {
            if (erange_cnt == 0)
                printf("ERANGE! Retrying with larger buffer\n");
            erange_cnt++;
            /* Increment a byte at a time so we can see exactly
               what size buffer was required.  */
            size++;
            if (size > MAX_BUF) {
                printf("Exceeded buffer limit (%d)\n", MAX_BUF);
                exit(EXIT_FAILURE);
            }
        }
    } while (s == ERANGE);
    printf("getservbyport_r() returned: %s  (size=%d)\n",
           (s == 0) ? "0 (success)" : (s == ENOENT) ? "ENOENT" :
           strerror(s), size);
    if (s != 0 || result == NULL) {
        printf("Call failed/record not found\n");
        exit(EXIT_FAILURE);
    }
    printf("s_name=%s; s_proto=%s; s_port=%d; aliases=",
           result_buf.s_name, result_buf.s_proto,
           ntohs(result_buf.s_port));
    for (char **p = result_buf.s_aliases; *p != NULL; p++)
        printf("%s ", *p);
    printf("\n");
    exit(EXIT_SUCCESS)
;
}
