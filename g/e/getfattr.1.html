GETFATTR(1) Utilitaires de fichiers GETFATTR(1)

NOM

getfattr - obtenir les attributs étendus des objets du système de fichiers

SYNTAXE

getfattr [-hRLP] -n nom [-e en] 
chemin_fichier...
getfattr [-hRLP] -d [-e en] 
[-m motif] chemin_fichier...

DESCRIPTION

Pour chaque fichier, getfattr affiche le nom du fichier et l'ensemble des noms d'attributs étendus (et éventuellement les valeurs) qui sont associés à ce fichier. Par défaut, seuls les attributs de l'espace de noms utilisateur sont affichés, voir -m.

Le format de sortie de getfattr -d est le suivant :

 1:  # fichier: repertoire/
 2:  user.nom0="valeur0"
 3:  user.nom1="valeur1"
 4:  user.nom2="valeur2"
 5:  ...

La ligne 1 identifie le nom du fichier pour lequel les lignes suivantes sont signalées. Les lignes restantes (lignes 2 à 4 ci-dessus) montrent les paires nom et valeur associées au fichier spécifié.

OPTIONS

-n nom, --name=nom
Afficher la valeur de l'attribut étendu nommé.
-d, --dump
Afficher les valeurs de tous les attributs étendus correspondants.
-e en, --encoding=en
Encoder les valeurs après les avoir récupérées. Les valeurs valides pour en sont "text", "hex" et "base64". Les valeurs encodées en chaînes de texte sont entourées de guillemets ("), tandis que les chaînes encodées en hexadécimal et en base64 sont préfixées respectivement par 0x et 0s.
-h, --no-dereference
Ne pas déréférencer les liens symboliques. Au lieu du fichier auquel un lien symbolique fait référence, c'est le lien symbolique lui-même qui est examiné. Sauf si un parcours logique (-L) est effectué, ne pas suivre les liens symboliques vers les répertoires.
-m motif, --match=motif
Inclure uniquement les attributs dont les noms correspondent à l'expression régulière motif. La valeur par défaut pour motif est "^user\\.", qui inclut tous les attributs de l'espace de noms utilisateur. Spécifiez "-" pour inclure tous les attributs. Reportez-vous à xattr(7) pour une discussion plus détaillée des espaces de noms.
--absolute-names
Ne pas supprimer les barres obliques de début ('/'). Le comportement par défaut est de supprimer les barres obliques de début.
--only-values
Afficher les valeurs brutes des attributs étendus sans les encoder.
-R, --recursive
Lister les attributs de tous les fichiers et répertoires de manière récursive.
-L, --logical
Parcours logique, suivre les liens symboliques vers les répertoires. Le comportement par défaut est de suivre les arguments de liens symboliques sauf si --no-dereference est donné, et de sauter les liens symboliques rencontrés dans les sous-répertoires. N'est efficace qu'en combinaison avec -R.
-P, --physical
Parcours physique, ne pas suivre les liens symboliques vers les répertoires. Cela saute également les arguments de liens symboliques. N'est efficace qu'en combinaison avec -R.
--version
Afficher la version de getfattr et quitter.
--help
Afficher l'aide expliquant les options de la ligne de commande.
--
Fin des options de la ligne de commande. Tous les paramètres restants sont interprétés comme des noms de fichiers, même s'ils commencent par un tiret.
