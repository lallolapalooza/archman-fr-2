get-edid(1) Manuel des commandes générales get-edid(1)

NOM

get-edid, parse-edid - outils de read-edid pour récupérer et interpréter les spécifications des moniteurs en utilisant le protocole VESA VBE DDC

SYNTAXE

get-edid [OPTIONS] | parse-edid
get-edid [OPTIONS] > nom_fichier
parse-edid < nom_fichier

DESCRIPTION

L'utilitaire read-edid comprend deux outils : get-edid et parse-edid.

get-edid utilise des appels en mode réel pour effectuer des transferts Data Display Channel (DDC), ou des appels i2c sous Linux pour effectuer des transferts Enhanced DDC afin de récupérer des informations des moniteurs, notamment les chaînes d'identification, les plages de synchronisation prises en charge, les modes vidéo disponibles et les paramètres des modes vidéo. Ces informations peuvent être utiles pour configurer les serveurs X Window System dans certains cas.

get-edid renvoie directement le bloc brut de données EDID (Extended Display Identification Data) du moniteur. La commande parse-edid est donc disponible pour l'interpréter et générer un bloc de texte lisible qui peut également être inclus dans un fichier xorg.conf X11.

Généralement, la sortie de get-edid est directement redirigée vers parse-edid.

Nouveauté depuis la version 3.0.0, get-edid accepte quelques options.

-b BUS, --bus BUS
ne rechercher que sur le bus i2c BUS (si compilé avec le support i2c)
-c, --classiconly
utiliser uniquement l'ancienne interface VBE (si compilé avec le support i2c et VBE)
-h, --help
afficher un message d'aide de base
-i, --i2conly
utiliser uniquement la nouvelle interface i2c (si compilé avec le support i2c et VBE)
-m NUM, --monitor NUM
essayer de retourner des informations sur le moniteur numéro NUM (VBE uniquement)
-q, --quiet
ne pas afficher de messages sur stderr

parse-edid n'accepte toujours aucune option. --help vous montrera quelles options votre version de read-edid prend en charge.
