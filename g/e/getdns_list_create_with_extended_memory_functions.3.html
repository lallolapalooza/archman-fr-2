DESCRIPTION

Le type getdns_list est utilisé pour gérer des listes indexées hétérogènes de paires nom/valeur dont les types de données des valeurs incluent


getdns_bindata
getdns_dict
getdns_list
uint32_t

La fonction de destruction effectue une destruction "profonde", libérant le stockage de tous les membres de la liste avant de détruire la liste. Il existe un certain nombre de fonctions d'aide qui fournissent un accès à l'objet liste, consultez leurs pages de manuel respectives.

userarg passe cet argument aux fonctions de gestion de mémoire spécifiées par l'utilisateur pour les opérations sur les listes créées à l'aide de fonctions de mémoire étendues

this_list la liste à détruire

VALEURS DE RETOUR

En cas de succès, la fonction getdns_list_create renvoie une structure de liste valide (vide) qui doit être libérée par un appel à getdns_list_destroy. Si un paramètre est invalide ou en cas d'erreur, getdns_list_create renvoie NULL.
