NOM

genbrk - Compile les fichiers source des règles d'itération de coupure ICU en fichiers de données binaires

SYNTAXE

genbrk [ -h, -?, --aide ] [ -V, --version ] [ -c, --copyright ] [ -v, --verbeux ] [ -d, --destdir destination ] [ -i, --icudatadir répertoire ] -r, --regles fichier-regles -o, --sortie fichier-sortie

DESCRIPTION

genbrk lit le code source des règles de coupure (limite) à partir de fichier-regles et crée un fichier de données d'itération de coupure. Normalement, ce fichier de données a l'extension .brk.

Les détails de la syntaxe des règles se trouvent dans le Guide de l'utilisateur d'ICU.

OPTIONS

-h, -?, --aide
Affiche l'aide sur l'utilisation et quitte.
-V, --version
Affiche la version de genbrk et quitte.
-c, --copyright
Intègre le copyright standard d'ICU dans le fichier-sortie.
-v, --verbeux
Affiche des messages informatifs supplémentaires pendant l'exécution.
-d, --destdir destination
Définit le répertoire de destination du fichier-sortie à destination.
-i, --icudatadir répertoire
Recherche les fichiers de données ICU nécessaires dans répertoire. Par exemple, le fichier pnames.icu doit être localisé si les données ICU ne sont pas construites en tant que bibliothèque partagée. Le répertoire de données ICU par défaut est spécifié par la variable d'environnement ICU_DATA. La plupart des configurations d'ICU ne nécessitent pas cet argument.
-r, --regles fichier-regles
Le fichier source à lire.
-o, --sortie fichier-sortie
Le fichier de données de sortie à écrire.

CAVEATS

Lorsque le fichier-regles contient une marque d'ordre des octets (BOM) au début du fichier, qui est le caractère Unicode U+FEFF, alors le fichier-regles est interprété comme Unicode. Sans la BOM, le fichier est interprété dans la page de code par défaut du système d'exploitation actuel. Afin d'éliminer toute ambiguïté sur l'encodage du fichier-regles, il est recommandé d'écrire ce fichier en UTF-8 avec la BOM.

ENVIRONNEMENT

ICU_DATA
Spécifie le répertoire contenant les données ICU. Par défaut : ${prefix}/share/icu/78.1/. Certains outils dans ICU dépendent de la présence de la barre oblique finale. Il est donc important de s'assurer qu'elle est présente si ICU_DATA est définie.
