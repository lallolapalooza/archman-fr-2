NOM

genpyt - générer le lexique PINYIN

SYNTAXE

genpyt fichier-lexique fichier-résultat fichier-log fichier-slm

DESCRIPTION

genpyt est utilisé pour générer le lexique PINYIN. Il ne fonctionne qu'en locale zh_CN.UTF-8.

ARGUMENTS

fichier-lexique
Spécifie un fichier dictionnaire. Il doit s'agir d'un fichier texte ligne par ligne en encodage utf-8. Chaque ligne ressemble à : 
CCC  id  [pinyin'pinyin'pinyin]*

Un fichier dictionnaire par défaut peut être trouvé à l'adresse /usr/share/sunpinyin/dict.utf8.

fichier-résultat
Le fichier binaire du lexique PINYIN de sortie. Ce lexique contient un trie présentant l'arbre clé du PINYIN. Et tous les mots candidats sont triés en utilisant l'unigramme du fichier-slm. Ce fichier peut être utilisé avec les moteurs de méthode d'entrée sunpinyin.
fichier-log
Spécifie le fichier où le journal va. Le fichier-log peut être vu comme la représentation lisible par l'homme du fichier de sortie binaire.
fichier-slm
Le modèle de langue à partir duquel les informations unigrammes sont récupérées. Typiquement, le fichier-slm est généré par slmthread.
