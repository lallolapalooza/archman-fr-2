CGEEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices GE

Objectif :

!>
!> CGEEV calcule pour une matrice complexe A non symétrique de taille N-par-N,
!> les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits.
!>
!> Le vecteur propre droit v(j) de A satisfait
!>                  A * v(j) = lambda(j) * v(j)
!> où lambda(j) est sa valeur propre.
!> Le vecteur propre gauche u(j) de A satisfait
!>               u(j)**H * A = lambda(j) * u(j)**H
!> où u(j)**H dénote la transposée conjuguée de u(j).
!>
!> Les vecteurs propres calculés sont normalisés pour avoir une norme Euclidienne
!> égale à 1 et la composante la plus grande réelle.
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N' : les vecteurs propres gauches de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres gauches de A sont calculés.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N' : les vecteurs propres droits de A ne sont pas calculés ;
!>          = 'V' : les vecteurs propres droits de A sont calculés.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA,N)
!>          En entrée, la matrice A de taille N-par-N.
!>          En sortie, A a été écrasée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

W

!>          W est un tableau COMPLEX de dimension (N)
!>          W contient les valeurs propres calculées.
!>

VL

!>          VL est un tableau COMPLEX de dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres gauches u(j) sont stockés un par un
!>          dans les colonnes de VL, dans le même ordre que leurs valeurs propres.
!>          Si JOBVL = 'N', VL n'est pas référencé.
!>          u(j) = VL(:,j), la j-ième colonne de VL.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL. LDVL >= 1 ; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX de dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres droits v(j) sont stockés un par un
!>          dans les colonnes de VR, dans le même ordre que leurs valeurs propres.
!>          Si JOBVR = 'N', VR n'est pas référencé.
!>          v(j) = VR(:,j), la j-ième colonne de VR.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR. LDVR >= 1 ; si
!>          JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est un tableau COMPLEX de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL de dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ième argument avait une valeur illégale.
!>          > 0 : si INFO = i, l'algorithme QR n'a pas réussi à calculer toutes les
!>                valeurs propres, et aucun vecteur propre n'a été calculé ;
!>                les éléments i+1:N de W contiennent les valeurs propres qui ont
!>                convergé.
!>

SGEEV computes the eigenvalues and, optionally, the left and/or right eigenvectors for GE matrices

Purpose:

!>
!> SGEEV computes for an N-by-N real nonsymmetric matrix A, the
!> eigenvalues and, optionally, the left and/or right eigenvectors.
!>
!> The right eigenvector v(j) of A satisfies
!>                  A * v(j) = lambda(j) * v(j)
!> where lambda(j) is its eigenvalue.
!> The left eigenvector u(j) of A satisfies
!>               u(j)**H * A = lambda(j) * u(j)**H
!> where u(j)**H denotes the conjugate-transpose of u(j).
!>
!> The computed eigenvectors are normalized to have Euclidean norm
!> equal to 1 and largest component real.
!>

Parameters

JOBVL 
!>          JOBVL is CHARACTER*1
!>          = 'N': left eigenvectors of A are not computed;
!>          = 'V': left eigenvectors of A are computed.
!>

JOBVR

!>          JOBVR is CHARACTER*1
!>          = 'N': right eigenvectors of A are not computed;
!>          = 'V': right eigenvectors of A are computed.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the N-by-N matrix A.
!>          On exit, A has been overwritten.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

WR

!>          WR is REAL array, dimension (N)
!>

WI

!>          WI is REAL array, dimension (N)
!>          WR and WI contain the real and imaginary parts,
!>          respectively, of the computed eigenvalues.  Complex
!>          conjugate pairs of eigenvalues appear consecutively
!>          with the eigenvalue having the positive imaginary part
!>          first.
!>

VL

!>          VL is REAL array, dimension (LDVL,N)
!>          If JOBVL = 'V', the left eigenvectors u(j) are stored one
!>          after another in the columns of VL, in the same order
!>          as their eigenvalues.
!>          If JOBVL = 'N', VL is not referenced.
!>          If the j-th eigenvalue is real, then u(j) = VL(:,j),
