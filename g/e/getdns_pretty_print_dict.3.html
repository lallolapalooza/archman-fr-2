Licences: BSD

getdns_pretty_print_dict(3) getdns getdns_pretty_print_dict(3)

NOM

getdns_pretty_print_dict -- retourne une représentation sous forme de chaîne d'un dictionnaire getdns

BIBLIOTHÉQUE

Bibliothèque du résolveur DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

char *
getdns_pretty_print_dict (const getdns_dict *this_dict)

DESCRIPTION

Fonction d'aide qui retourne une chaîne de données joliment formatées, incluant tous les éléments du dictionnaire.

this_dict le dictionnaire à rendre sous forme de chaîne

VALEURURS DE RETOUR

Retourne une chaîne que la fonction appelante doit libérer (elle est allouée en utilisant l'allocateur système et non l'allocateur défini par l'utilisateur). Retourne NULL en cas d'erreur.
