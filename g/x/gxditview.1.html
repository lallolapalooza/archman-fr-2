gxditview accepte toutes les options standard de la ligne de commande de la X Toolkit ainsi que les options supplémentaires

listées
ci-dess
ous.
-page Cette option spécifie le numéro de page du document à afficher.
-backingStore
type-de-backing-store Étant
donné
que le réaffichage de la fenêtre de sortie intermédiaire de groff peut prendre un temps perceptible, cette option fait en sorte que le serveur sauvegarde le contenu de la fenêtre afin que, lorsqu'elle est fait défiler dans la zone de visualisation, la fenêtrem contents saved in backing store. backing-store-type peut être l'un de Always, WhenMapped ou NotUseful.
-printCommand command
La commande par défaut affichée dans la boîte de dialogue pour l'entrée de menu Print sera command.
-resolution res
Le fichier de sortie intermédiaire groff sera affiché à une résolution de res points par pouce, à moins que le fichier DESC ne contienne la commande X11, auquel cas la résolution du périphérique sera utilisée. Ceci correspond à la ressource resolution du widget Dvi. La valeur par défaut est 75.
-filename string
Le nom de fichier par défaut affiché dans la boîte de dialogue pour l'entrée de menu Open sera string. Il peut s'agir d'un nom de fichier ou d'une commande commençant par “|”.

Les arguments de ligne de commande standard du X Toolkit suivants sont couramment utilisés avec gxditview.

-bg color
Cette option spécifie la couleur à utiliser pour l'arrière-plan de la fenêtre. La valeur par défaut est “white”.
-bd color
Cette option spécifie la couleur à utiliser pour la bordure de la fenêtre. La valeur par défaut est “black”.
-bw number
Cette option spécifie la largeur en pixels de la bordure entourant la fenêtre.
-fg color
Cette option spécifie la couleur à utiliser pour l'affichage du texte. La valeur par défaut est “black”.
-fn font
Cette option spécifie la police à utiliser pour l'affichage du texte des widgets. La valeur par défaut est “fixed”.
-rv
Cette option indique que la vidéo inversée doit être simulée en échangeant les couleurs de premier plan et d'arrière-plan.
-geometry geometry
Cette option spécifie la taille et la position préférées de la fenêtre.
-display host:display
Cette option spécifie le serveur X à contacter.
-xrm resourcestring
Cette option spécifie une chaîne de ressources à utiliser.

Environnement

GROFF_FONT_PATH
Une liste de répertoires dans lesquels rechercher le répertoire des fichiers de description de périphérique et de polices du périphérique de sortie sélectionné. Voir troff(1) et groff_font(5).

Fichiers

/usr/lib/X11/app-defaults/GXditview
/usr/lib/X11/app-defaults/GXditview-color
définissent les valeurs par défaut de l'application X pour gxditview. Les utilisateurs peuvent remplacer ces valeurs dans le fichier .Xdefaults, normalement situé dans le répertoire personnel de l'utilisateur. Voir appres(1) et xrdb(1).
/usr/share/groff/1.23.0/font/devX100/DESC
décrit le périphérique de sortie X100.
/usr/share/groff/1.23.0/font/devX100/F
décrit la police connue sous le nom de F sur le périphérique X100.
/usr/share/groff/1.23.0/font/devX100-12/DESC
décrit le périphérique de sortie X100-12.
/usr/share/groff/1.23.0/font/devX100-12/F
décrit la police connue sous le nom de F sur le périphérique X100-12.
/usr/share/groff/1.23.0/font/devX75/DESC
décrit le périphérique de sortie X75.
/usr/share/groff/1.23.0/font/devX75/F
décrit la police connue sous le nom de F sur le périphérique X75.
/usr/share/groff/1.23.0/font/devX75-12/DESC
décrit le périphérique de sortie X75-12.
/usr/share/groff/1.23.0/font/devX75-12/F
décrit la police connue sous le nom de F sur le périphérique X75-12.
/usr/share/groff/1.23.0/tmac/X.tmac
définit les macros à utiliser avec les périphériques de sortie X100, X100-12, X75, et X75-12. Il est automatiquement chargé par troffrc lorsqu'un de ces périphériques de sortie est sélectionné.
/usr/share/groff/1.23.0/tmac/Xps.tmac
configure troff pour utiliser gxditview comme prévisualiseur pour une sortie indépendante du périphérique ciblant le périphérique de sortie ps. Il est automatiquement chargé par troffrc lorsque troff reçoit les options -X et -Tps.

Exemples

La commande suivante visualise cette page de manuel avec une taille de point de base de 12.

groff -TX100-12 -man gxditview.1

La qualité du résultat dépend principalement de la taille de point choisie et de la résolution d'affichage ; pour une prévisualisation rapide, cependant, quelque chose comme

groff -X -P-resolution -P100 document
donne des résultats acceptables.
