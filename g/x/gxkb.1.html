GXKB(1) Commandes utilisateur GXKB(1)

NOM

gxkb - Indicateur et sélecteur de clavier X11.

SYNOPSIS

gxkb

DESCRIPTION

gxkb est un petit applet indicateur qui permet de passer rapidement entre différents agencements de clavier sous X. Un drapeau correspondant au pays de l'agencement actif est affiché dans la zone de l'indicateur.

L'applet est écrit en C et utilise la bibliothèque GTK+ et ne dépend donc d'aucun composant GNOME.

OPTIONS

-v
Affiche le numéro de version de gxkb en sortie standard et liste les fonctionnalités avec lesquelles il a été compilé.
-h
Affiche un message d'utilisation résumant brièvement ces options de ligne de commande, puis quitte.

FICHIERS

Les chemins complets ci-dessous peuvent varier entre les installations. Ils sont également affectés par les variables d'environnement XDG_CONFIG_HOME et XDG_DATA_HOME.

PREFIX/share/gxkb/flags/

Répertoire contenant les ressources système.

$XDG_CONFIG_HOME/gxkb/gxkb.cfg

Paramètres pour gxkb. Si $XDG_CONFIG_HOME n'est ni défini ni vide, une valeur par défaut égale à $HOME/.config/gxkb/gxkb.cfg doit être utilisée. Le fichier de configuration doit être créé lors de la première exécution et peut être modifié lorsque gxkb n'est pas en cours d'exécution. La configuration de gxkb peut être modifiée à la volée avec la commande setxkbmap(1), auquel cas gxkb mettra à jour son fichier de configuration à la sortie.

$XDG_DATA_HOME/gxkb/flags

Les propres ressources de l'utilisateur pour remplacer les images de drapeaux du répertoire PREFIX/share/gxkb/flags. Si $XDG_DATA_HOME n'est ni défini ni vide, une valeur par défaut égale à $HOME/.local/share/gxkb/flags doit être utilisée.
