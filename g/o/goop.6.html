NOM

goop - hack d'écran d'huile transparente molle et de bulles

SYNTAXE

goop [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visual] [--transparent] [--non-transparent] [--additive] [--subtractive] [--xor] [--no-xor] [--fps]

DESCRIPTION

Le programme goop dessine une simulation de bulles dans des couches de fluide translucide multicolore qui se chevauchent.

OPTIONS

goop accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, prétendre que nous sommes sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visual
Spécifier quel visual utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou le numéro d'identification (décimal ou hexadécimal) d'un visual spécifique.
--count entier
Combien de bulles dessiner par couche. Par défaut : aléatoire.
--planes entier
Combien de plans dessiner. Par défaut : aléatoire, basé sur la profondeur de l'écran.
--delay microsecondes
Quel délai introduire entre les étapes de l'animation. Par défaut 12000, soit environ 0.012 secondes.
--transparent
Si --layers est supérieur à 1, alors chaque couche sera dessinée dans une couleur, et lorsqu'elles se chevaucheront, les couleurs seront mélangées. C'est le comportement par défaut.
--non-transparent
Désactive --transparent.
--additive
Si --transparent est spécifié, alors cette option signifie que les couleurs seront mélangées en utilisant un modèle de couleur additif, comme si les blobs étaient de la lumière projetée. C'est le comportement par défaut.
--subtractive
Si --transparent est spécifié, alors cette option signifie que les couleurs seront mélangées en utilisant un modèle de couleur soustractif, comme si les blobs étaient des filtres translucides.
--xor
Dessiner avec xor au lieu des autres astuces de couleur.
--fps
Afficher le taux d'images par seconde et la charge CPU actuels.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de fenêtre à utiliser avec --root.
