NOM

gofmt - formater le code Go

SYNTAXE

gofmt [options] [chemin]...

DESCRIPTION

Un outil pour formater le code source Go. Pour une documentation complète, exécutez gofmt -help ou consultez http://golang.org/cmd/gofmt.
