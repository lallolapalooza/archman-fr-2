NOM

goid-tool - utilitaire de carte à puce pour carte à empreintes digitales GoID

SYNTAXE

goid-tool [OPTIONS] [mode]

DESCRIPTION

L'utilitaire goid-tool peut être utilisé depuis la ligne de commande pour lire et écrire des données de la carte à empreintes digitales GoID[1].

OPTIONS

--help, -h

Affiche le message d'aide à l'écran.

--version, -V

Affiche la version de la version du paquet OpenSC.

--reader chaîne, -r chaîne

Spécifie le numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si l'argument est un ATR, le lecteur avec une carte correspondante sera choisi.

--verbose, -v

Rend goid-tool plus verbeux. Utilisez-le plusieurs fois pour être encore plus verbeux.

--verify-pin, -p

Vérifie le code PIN.

--verify-bio, -b

Vérifie l'empreinte digitale.

--verify-pin-or-bio

Vérifie le code PIN ou l'empreinte digitale (choix de l'utilisateur).

OPTIONS POUR L'APPLET SOCMANAGER

--new-pin

Change le code PIN

--new-bio

Utiliser (plusieurs fois) pour changer un ou plusieurs modèles biométriques

--info

Affiche des informations sur la configuration du SoCManager

OPTIONS POUR L'APPLET PACCESS

--certificate nom_fichier, -c nom_fichier

Utiliser (plusieurs fois) pour passer des certificats CV

--key, -k,

Clé privée pour le certificat CV

--print-cardid

Affiche l'ID de la carte

--write-cardid données

Écrit l'ID de carte spécifié

--print-paccessid

Affiche l'ID PAccess

--write-paccessid données

Écrit l'ID PAccess spécifié

--read-dg id

Lit le groupe de données spécifié ; utiliser plusieurs fois pour lire plusieurs fichiers

--out-file nom_fichier

Écrit la sortie dans un fichier au lieu de l'imprimer ; utiliser une fois pour chaque utilisation de --read-dg

--write-dg id

Écrit le groupe de données spécifié ; utiliser plusieurs fois pour écrire plusieurs fichiers

--in-file nom_fichier

Lit l'entrée depuis un fichier ; utiliser une fois pour chaque utilisation de --write-dg

--delete-dg id

Supprime le groupe de données spécifié ; utiliser plusieurs fois pour supprimer plusieurs fichiers

--create-dg id

Crée le groupe de données spécifié ; utiliser plusieurs fois pour créer plusieurs fichiers

--new-size taille

Taille du fichier des DG nouvellement créés

--new-read-ac condition

Condition d'accès pour la lecture des DG nouvellement créés

--new-read-ac condition

Condition d'accès pour la lecture des DG nouvellement créés

--new-read-ac-chatbit index

Bit d'accès requis dans le CHAT du certificat pour lire les DG nouvellement créés

--new-write-ac condition

Condition d'accès pour l'écriture des DG nouvellement créés

--new-write-ac-chatbit index

Bit d'accès requis dans le CHAT du certificat pour écrire les DG nouvellement créés
