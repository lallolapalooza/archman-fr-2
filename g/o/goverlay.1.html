NOM

goverlay - Interface graphique pour aider à gérer les superpositions Vulkan/OpenGL

SYNTAXE

goverlay [--style STYLE]

DESCRIPTION

GOverlay peut configurer des superpositions Vulkan / OpenGL avec un aperçu. Actuellement pris en charge : MangoHud, vkBasalt et ReplaySorcery.

OPTIONS

--style STYLE
Forcer un style Qt spécifique. Une alternative à cette option est de définir la variable d'environnement QT_STYLE_OVERRIDE.

NOTE

Il est recommandé d'utiliser le thème Breeze (Qt/KDE) ou Adwaita (Gtk/Gnome).
