GOZILLA(1) Manuel des commandes générales GOZILLA(1)

NOM

gozilla - forcer firefox à afficher une partie spécifiée d'un fichier source

SYNOPIS

gozilla [-b navigateur][-p][+ligne] fichier
gozilla [-b navigateur][-p] -d nom

DESCRIPTION

Gozilla force firefox à afficher une partie spécifiée d'un fichier source. Gozilla peut être utilisé avec d'autres navigateurs comme chrome.

Avant d'utiliser cette commande, vous devez exécuter gtags(1) et htags(1) à la racine du répertoire du projet pour créer les fichiers de tags. Ensuite, vous pouvez exécuter cette commande n'importe où dans le projet.

Première forme :

Vous pouvez spécifier un fichier source et un numéro de ligne optionnel. Cette syntaxe est similaire à vi(1) et emacs(1).

Deuxième forme :

Vous pouvez spécifier directement un nom de définition. Le nom de définition doit exister dans ´GTAGS´. Cette option nécessite ´HTML/MAP´ généré par htags(1).

Certains navigateurs nécessitent que vous les chargiez avant d'exécuter gozilla.

OPTIONS

Les options suivantes sont disponibles :

+ligne
Numéro de ligne.
-b navigateur
Navigateur à utiliser. Par défaut, il est supposé que c'est firefox.
-d nom
Afficher les définitions.
--help
Afficher l'aide.
-p
Imprimer uniquement l'URL générée au lieu de l'afficher.
fichier
Nom de fichier ou nom d'alias.
-q, --quiet
Mode silencieux.
-v, --verbose
Mode détaillé.
--version
Afficher le numéro de version.

FICHIERS

´GTAGS´
Fichier de tags pour les définitions.
´HTML/´
Hypertexte du code source.
´HTML/MAP´
Fichier de mappage pour convertir le nom du tag en chemin de la liste des tags.
´gtags.conf´, ´$HOME/.globalrc´
Données de configuration pour GNU Global. Voir gtags.conf(5).

ENVIRONNEMENT

BROWSER
Navigateur à utiliser. Par défaut, il est supposé que c'est firefox. Si vous souhaitez charger le navigateur par défaut sur OSX, vous pouvez définir cette variable sur osx-default.
GTAGSDBPATH
Le répertoire dans lequel se trouvent les fichiers de tags. Cette valeur est ignorée lorsque GTAGSROOT n'est pas défini.
GTAGSROOT
Le répertoire racine du projet.

EXEMPLES

$ gtags
$ htags
$ global -x main
main              82 ctags.c          main(argc, argv)
$ gozilla +82 ctags.c
$ gozilla -d main
$ gozilla -b lynx +82 ctags.c

DIAGNOSTICS

Gozilla se termine avec une valeur non nulle si une erreur s'est produite, 0 sinon.

VOIR AUSSI

global(1), gtags(1), htags(1), epiphany(1), firefox(1), gtags.conf(5).

Système de tags de code source GNU Global
(http://www.gnu.org/software/global/).

AUTEURS

HISTORIQUE
