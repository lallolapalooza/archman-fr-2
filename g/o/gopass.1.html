age

Commandes intégrées pour le backend age. Elles permettent des interactions limitées avec les identités age spécifiques à gopass.
Les identités ajoutées sont automatiquement ajoutées en tant que destinataires à vos secrets lors du chiffrement, mais pas à vos destinataires, assurez-vous de garder vos destinataires et identités synchronisés comme vous le souhaitez. Toutes les identités age, y compris celles des plugins, devraient être prises en charge. Nous prenons toujours en charge les identités github malgré leur dépréciation par age, nous le faisons en nous rabattant sur les identités ssh pour celles-ci et en maintenant un cache local des clés ssh pour une identité github

donnée.

copy

Copy secrets

Copy a secret from a source to a destination. This command may also be used to move secrets if the source and destination are the same directory.

Flags

--force,
-f, Overwrite existing secret and do not prompt to confirm recipients
--revision,
-r, Copy a specific revision of a secret

create

Create a new secret

Create a new secret, using the contents of a file or stdin. The secret will be encrypted with the default recipient. A commit message can be provided using the flags below. An editor can be opened to edit the secret message.

Flags

--commit-message,
-m, Set the commit message
--force,
-f, Overwrite existing secret and do not prompt to confirm recipients
--interactive-commit,
-i, Open an editor for the commit message
--path,
-p, Set the path to operate on

decode

Decode secrets

Decode secrets, which are usually stored in base64. This command is typically used internally or for debugging purposes. The secret needs to be explicitly decrypted first.

decrypt

Decrypt secrets

Decrypt secrets, which are usually stored in base64. This command is typically used internally or for debugging purposes.

Flags

--path,
-p, Set the path to operate on

edit

Edit new or existing secrets

Use this command to insert a new secret or edit an existing one using your $EDITOR. It will attempt to create a secure temporary directory for storing your secret while the editor is accessing it. Please make sure your editor doesn't leak sensitive data to other locations while editing. Note: If $EDITOR is not set we will try 'editor'. If that's not available either we fall back to 'vi'. Consider using 'update-alternatives --config editor to change the defaults.

Flags

--commit-message,
-m, Set the commit message
--create,
-c, Create a new secret if none found
--editor,
-e, Use this editor binary
--interactive-commit,
-i, Open an editor for the commit message
