SYNOPSI

S

gocr [OPTION] [-i] fichier-pnm

DESCRIPTIO

N

gocr est un programme de reconnaissance optique de caractères qui peut être utilisé depuis la ligne de commande. Il accepte des entrées au format PNM, PGM, PBM, PPM ou PCX et écrit le texte reconnu vers stdout. Si le fichier pnm est un tiret unique, les données PNM sont lues depuis stdin. Si gzip, bzip2 et netpbm-progs sont installés et que votre système supporte popen(3), pnm.gz, pnm.bz2, png, jpg, jpeg, tiff, gif, bmp, ps (uniquement les pages

uniques) et eps sont également pris en charge en tant que fichiers d'entrée (pas en
tant que flux d'entrée), où pnm peut être remplacé par l'un de ppm, pgm et pbm.

    gocr(1)

    NOM

    gocr - Programme de reconnaissance optique de caractères (OCR)

    SYNTAXE

    gocr [-i fichier_image] [-o fichier_texte] [-p fichier_de_dictionnaire] [-l fichier_de_langues] [-d niveaux_de_debut] [-e niveaux_de_fin] [-m mode] [-a valeur_alpha] [-F format_de_sortie] [-V] [-h]

    DESCRIPTION

    gocr est un programme de reconnaissance optique de caractères (OCR). Il peut être utilisé pour convertir des images contenant du texte en texte brut. Il prend en charge plusieurs formats d'image et plusieurs langues.

    OPTIONS

    -i fichier_image
    Spécifie le fichier image d'entrée. S'il n'est pas spécifié, l'entrée standard est utilisée.
    -o fichier_texte
    Spécifie le fichier texte de sortie. S'il n'est pas spécifié, la sortie standard est utilisée.
    -p fichier_de_dictionnaire
    Spécifie le fichier de dictionnaire à utiliser.
    -l fichier_de_langues
    Spécifie le fichier de langues à utiliser.
    -d niveaux_de_debut
    Définit les niveaux de débogage de début.
    -e niveaux_de_fin
    Définit les niveaux de débogage de fin.
    -m mode
    Définit le mode de fonctionnement. Les modes disponibles sont :
    • 0 : Mode normal
    • 1 : Mode caractères seuls
    • 2 : Mode lignes seules
    • 3 : Mode mots seuls
    -a valeur_alpha
    Définit la valeur alpha pour le traitement de l'image.
    -F format_de_sortie
    Définit le format de sortie. Les formats disponibles sont :
    • text : Texte brut
    • html : HTML
    • xml : XML
    • hocr : HOCR
    -V
    Affiche la version du programme.
    -h
    Affiche l'aide.

    AUTEUR

    Les auteurs originaux de gocr sont Juergen Buchmayer et Alexander Graf.
