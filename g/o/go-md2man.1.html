NOM

go-md2man - Convertit les fichiers markdown en pages de manuel

SYNTAXE

go-md2man [-in=/chemin/vers/fichier.md] [-out=/chemin/vers/sortie]

DESCRIPTION

go-md2man convertit les documents formatés en markdown standard en pages de manuel. Il est écrit entièrement en Go afin de réduire les dépendances aux bibliothèques tierces.

Par défaut, l'entrée est stdin et la sortie est stdout.

OPTIONS

-in=fichier
Chemin vers le fichier markdown à traiter.

Par défaut, stdin.

-out=fichier
Chemin vers le fichier de sortie traité.

Par défaut, stdout.

EXEMPLES

Convertir le fichier markdown go-md2man.1.md en page de manuel :

go-md2man < go-md2man.1.md > go-md2man.1

Identique, mais en utilisant les arguments de ligne de commande au lieu de la redirection shell :

go-md2man -in=go-md2man.1.md -out=go-md2man.1
