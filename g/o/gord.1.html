NOM

gord - calculer des ordonnancements de matrices creuses de graphes

SYNTAXE

gord [options] [gfile] [ofile] [lfile]

DESCRIPTION

Le programme gord calcule, de manière séquentielle, un ordonnancement d'un graphe source Scotch représentant le motif d'une matrice creuse symétrique.

Le fichier de graphe source gfile ne peut être qu'un fichier de graphe centralisé. L'ordonnancement résultant est stocké dans le fichier ofile. Les informations de journalisation éventuelles (telles que celles produites par l'option -v) sont envoyées au fichier lfile. Lorsque les noms de fichiers ne sont pas spécifiés, les données sont lues depuis l'entrée standard et écrites vers la sortie standard. Les flux standard peuvent également être explicitement représentés par un tiret '-'.

Lorsque les bibliothèques appropriées ont été incluses lors de la compilation, gord peut directement gérer des graphes compressés, en entrée comme en sortie. Un flux est traité comme compressé dès lors que son nom est postfixé par une extension de fichier compressé, comme dans 'brol.grf.bz2' ou '-.gz'. Les formats de compression qui peuvent être pris en charge sont le format bzip2 ('.bz2'), le format gzip ('.gz') et le format lzma ('.lzma').

OPTIONS

-c?opt
Choisir la stratégie d'ordonnancement par défaut selon une ou plusieurs options parmi :
b
forcer autant que possible l'équilibrage de charge.
q
privilégier la qualité sur la vitesse (par défaut).
s
privilégier la vitesse sur la qualité.
t
forcer la sécurité.
-h
afficher une aide.
-m?mfile
sauvegarder les données de mappage des blocs de colonnes dans le fichier mfile. Les données de mappage spécifient, pour chaque sommet, l'indice du bloc de colonnes auquel ce sommet appartient.
-o?strat
utiliser la stratégie d'ordonnancement de graphe séquentielle strat (voir le manuel de l'utilisateur Scotch pour plus d'informations).
-t?tfile
sauvegarder les données de l'arbre de partitionnement dans le fichier tfile. Les données de l'arbre de partitionnement spécifient, pour chaque sommet, l'indice du premier sommet du bloc parent du bloc auquel le sommet appartient. Ensemble avec les données de mappage fournies dans le fichier mfile, cela permet de reconstruire l'arbre des séparateurs du processus de dissection imbriquée.
-V
afficher la version du programme et le copyright.
-v?verb
définir le mode verbeux à verb. C'est un ensemble d'un ou plusieurs caractères qui peuvent être :
s
informations sur la stratégie.
t
informations sur le temps.

EXEMPLE

Réordonner le graphe de matrice brol.grf et sauvegarder l'ordonnancement résultant dans le fichier brol.ord en utilisant la stratégie d'ordonnancement de graphe séquentielle par défaut :

    $ gord brol.grf brol.ord
