gobject-query() gobject-query()

Nom

gobject-query - afficher un arbre de types

Syntaxe

gobject-query froots [OPTION…]
gobject-query tree [OPTION…]

Description

gobject-query est un petit utilitaire qui dessine un arbre de types.

Il prend un argument obligatoire qui spécifie s'il doit itérer sur les types fondamentaux ou afficher un arbre de types.

Commandes

froots

Itérer sur les racines fondamentales.

tree

Afficher l'arbre de types.

Options

-r <TYPE>

Spécifier le type racine.

-n

Ne pas descendre dans l'arbre de types.

-b <CHAÎNE>

Spécifier la chaîne d'indentation.

-i <CHAÎNE>

Spécifier la chaîne d'indentation incrémentale.

-s <NOMBRE>

Spécifier l'espacement des lignes.

-h, --help

Afficher une aide brève et quitter.

-v, --version

Afficher la version et quitter.
