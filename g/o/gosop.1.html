GOSOP(1) Manuel des commandes générales GOSOP(1)

NOM

gosop - Implémentation OpenPGP sans état pour GopenPGP

SYNTAXE :

gosop [options globales] commande [options de commande] [arguments...]

AUTEUR :

Proton Technologies AG

COMMANDES

armor
Ajouter un blindage ASCII
SYNTAXE :
gosop armor [options de commande] < DONNÉES
OPTIONS :
--label valeur
--label={auto|sig|key|cert|message} (défaut : auto)
--help, -h : afficher l'aide (défaut : false)
dearmor
Retirer le blindage ASCII
SYNTAXE :
gosop dearmor < DONNÉES
OPTIONS :
--help, -h : afficher l'aide (défaut : false)
decrypt
Déchiffrer un message
SYNTAXE :
gosop decrypt [options de commande] [CLÉ...] < CHIFFRETEXTE
OPTIONS :
--session-key-out valeur
--session-key-out=CLE SESSION
--with-session-key valeur
--with-session-key=CLE SESSION
--with-password valeur
--with-password=MOT DE PASSE
--verify-out valeur
--verify-out=VERIFICATIONS
--verify-with valeur
--verify-out=CERTIFICATS
--verify-not-before valeur
--verify-not-before={-|DATE} (défaut : -)
--verify-not-after valeur
--verify-not-after={-|DATE} (défaut : now)
--help, -h : afficher l'aide (défaut : false)
encrypt
Chiffrer un message
SYNTAXE :
gosop encrypt [options de commande] [CERTIFICATS...] < DONNÉES
OPTIONS :
--as valeur
--as={binary|text} (défaut : binary)
--no-armor (défaut : false)
--with-password valeur
--with-password=MOT DE PASSE
--sign-with valeur
--sign-with=CLÉ
--help, -h : afficher l'aide (défaut : false)
extract-cert
Extraire un certificat d'une clé secrète
SYNTAXE :
gosop extract-cert [options de commande]
OPTIONS :
--no-armor (défaut : false)
--help, -h : afficher l'aide (défaut : false)
generate-key
Générer une clé secrète
SYNTAXE :
gosop generate-key [options de commande] [ID UTILISATEUR...]
OPTIONS :
--no-armor (défaut : false)
--help, -h : afficher l'aide (défaut : false)
sign
Créer une signature détachée
SYNTAXE :
gosop extract-cert [options de commande]
OPTIONS :
--no-armor (défaut : false)
--help, -h : afficher l'aide (défaut : false)
verify
Vérifier une signature détachée
SYNTAXE :
gosop verify SIGNATURE CERTIFICATS [CERTIFICATS...] < DONNÉES
OPTIONS :
--not-before valeur
--not-before={-|DATE} (défaut : -)
--not-after valeur
--not-after={-|DATE} (défaut : now)
--help, -h : afficher l'aide (défaut : false)
version
Informations sur la version
SYNTAXE :
gosop version [options de commande] [arguments...]
OPTIONS :
--backend (défaut : false)
--extended (défaut : false)
--help, -h : afficher l'aide (défaut : false)
help, h
Affiche une liste de commandes ou l'aide pour une commande

OPTIONS GLOBALES :

--help, -h
affiche l'aide (défaut : false)
--version, -v
affiche la version (défaut : false)
