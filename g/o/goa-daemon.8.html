NOM

goa-daemon - Démon des Comptes en Ligne GNOME

SYNTAXE

goa-daemon [--help] [--replace] [--version]

DESCRIPTION

Le programme goa-daemon expose le nom org.gnome.OnlineAccounts sur le bus de messages de session. Les utilisateurs ou les administrateurs n'auront jamais besoin de démarrer ce démon car il sera automatiquement démarré par dbus-daemon(1) chaque fois qu'une application envoie un message D-Bus au nom org.gnome.OnlineAccounts sur le bus de session.

FICHIER DE CONFIGURATION

Le programme goa-daemon stocke sa configuration dans le fichier $XDG_CONFIG_HOME/goa-1.0/accounts.conf (typiquement ~/.config/goa-1.0/accounts.conf). Le format de ce fichier est privé et les programmes ou bibliothèques tiers ne devraient jamais le lire. Ce fichier ne contient aucun mot de passe ni secret.

Voir la Spécification des répertoires de base XDG[1] pour plus d'informations sur $XDG_CONFIG_HOME.

SECRETS

Le programme goa-daemon stocke les secrets (tels que les jetons OAuth) dans le GNOME Keyring[2]. Le format des secrets stockés est privé et les programmes ou bibliothèques tiers ne devraient jamais lire, modifier ou supprimer ces secrets.

OPTIONS

--replace

Remplace l'instance existante.

--version

Affiche la version du programme.

--help

Affiche les options d'aide.
