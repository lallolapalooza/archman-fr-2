NOM

gpodder-migrate2tres - Migreur de profil gPodder 2.x vers 3.x

SYNTAXE

gpodder-migrate2tres

DESCRIPTION

Utilitaire en ligne de commande pour migrer les données de configuration gPodder 2.x de l'utilisateur pour utilisation avec gPodder 3.x. Invoquez la commande sans aucune option pour migrer les données de configuration de l'utilisateur courant. Des retours d'information sont fournis.

L'utilitaire gpodder-backup (inclus avec gPodder 2.x) peut être utilisé pour sauvegarder la configuration avant la migration. Il n'y a actuellement pas de migration de gPodder 3.x vers gPodder 2.x.

Mai 2012 gpodder 3.2.0
