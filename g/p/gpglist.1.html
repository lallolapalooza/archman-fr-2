NOM

gpglist -- affiche qui a signé quelles UIDs de votre clé

SYNTAXE

gpglist [--signer=id_cle] [--show-revoked] id_cle

DESCRIPTION

gpglist prend un id_cle et crée un listing montrant qui a signé les identifiants utilisateur de id_cle.

$ gpglist 6D8ABE71
+-----  1 Christoph Berg <cb@df7cb.de>
|  +--  2 Christoph Berg <cb@cs.uni-sb.de>
1  2  
x     7929AB90F7AC3AF0 Martin Helas <mhelas@helas.net>
x  x  29BE5D2268FD549F Martin Michlmayr <tbm@cyrius.com>
   x  7DDB2B8DB4B462C5 Martin Wanke <mawan@mawan.de>

Par défaut, seules les identités non révoquées sont listées, mais cela peut être outrepassé avec --show-revoked.

Une ou plusieurs options --signer peuvent être utilisées pour limiter les signataires aux clés correspondantes. Voir le manuel GnuPG pour les différentes manières de spécifier une clé ou un identifiant utilisateur.

Le chemin vers le binaire gpg peut être spécifié avec la variable d'environnement GNUPGBIN (par défaut : "gpg").
