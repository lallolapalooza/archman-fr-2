NOTES

Les options suivantes sont des modes d'affichage du programme gprofng-display(1).

"annotated-source"
Afficher le code source annoté avec les informations de profilage. C'est le mode d'affichage par défaut pour les langages comme C, C++ et Fortran.
"call-graph"
Afficher le graphe d'appels des fonctions. C'est le mode d'affichage par défaut pour la plupart des autres langages.
"flat"
Afficher les fonctions dans un format plat, triées par temps d'exécution ou par nombre d'appels. Ce mode est utile pour obtenir un aperçu rapide des fonctions les plus coûteuses.
"html"
Générer un rapport de profilage au format HTML. Cela permet une visualisation interactive et des liens entre les différentes parties du rapport.
"machine"
Afficher les piles d'appels natives réelles pour tous les threads. C'est le mode d'affichage pour C, C++ et Fortran.
