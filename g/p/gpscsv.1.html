NAME

gpscsv - dump the JSON output from gpsd as CSV

SYNOPSIS

gpscsv [OPTIONS] [host[:port[:device]]]

gpscsv -h

gpscsv -V

DESCRIPTION

gpscsv est un programme Python simple pour lire les flux de données JSON de gpsd et les afficher au format CSV (Comma Separated Values). Il prend l'entrée d'un gpsd spécifié et rapporte vers la sortie standard. Le programme s'exécute jusqu'à ce que gpsd meure, que le nombre de messages "-n COUNT" soit traité, que le temps "-x SECONDS" soit écoulé, ou qu'il soit interrompu par ^C ou par d'autres moyens.

gpscsv ne peut collecter que les données que votre gpsd envoie déjà. Utilisez gpspipe pour voir quelles classes de messages JSON il envoie.

Une bonne utilisation de gpscsv est de créer des fichiers CSV à utiliser avec le programme gnuplot.

gpscsv ne nécessite pas les privilèges root, mais fonctionnera très bien en tant que root.

OPTIONS

Le programme accepte les options suivantes :

-?, -h, --help

Affiche les informations d'aide et quitte.

-c MCLASS, --class MCLASS

Sélectionne les classes de messages JSON de type MCLASS. Remplace la classe par défaut TPV. Voir la section CLASSES ci-dessous pour plus d'informations.

--cvt-isotime

Convertit les champs nommés "time" du format horaire ISO au format horaire UNIX.

-D LVL, --debug LVL

Définit le niveau de débogage à LVL. Par défaut 0. Les arguments supérieurs à 0 produisent plus de sorties de débogage.

--device DEVICE

Le DEVICE sur le gpsd auquel se connecter. Par défaut, tous.

-f FIELDS, -fields FIELDS

Les FIELDS du message JSON à extraire dans la sortie. Définissez FIELD à vide ('') pour tous les champs initialement vus. Le défaut varie selon la CLASS.

--file FILE

Lit le JSON depuis FILE au lieu de gpsd.

--header HEADER

Définit le style d'en-tête à HEADER. 0 pour pas d'en-tête, 1 affiche les champs comme en-tête, 2 envoie les champs comme un commentaire ('#'). Par défaut 1.

--host HOST

Se connecte au gpsd sur HOST. Par défaut, localhost.

-n COUNT, --count COUNT

Quitte après avoir affiché COUNT enregistrements. Mettez COUNT à 0 pour désactiver. Par défaut 0.

--port PORT

Utilise PORT pour se connecter à gpsd. Par défaut 2947.

--separator SEPARATOR

Utilise SEPARATOR comme séparateur de champs. Le séparateur par défaut est une virgule (',').

-V, --version

Affiche la version de gpscsv et quitte.

-x SECONDS, --seconds SECONDS

Quitte après que SECONDS secondes se soient écoulées. Mettez SECONDS à 0 pour désactiver. Par défaut 0.

Toutes les options individuelles ci-dessus peuvent être spécifiées plusieurs fois, mais seule la dernière de chaque sera utilisée.

CLASSES

Certaines des classes de messages JSON de gpsd incluent des sous-classes. gpscsv permet d'y accéder directement en utilisant une méta-classe (MCLASS).

MCLASS Class Description
ALMANAC SUBFRAME ALMANAC de JSON SUBFRAME
HEALTH SUBFRAME HEALTH de JSON SUBFRAME
HEALTH2 SUBFRAME HEALTH2 de JSON SUBFRAME
IONO SUBFRAME IONO de JSON SUBFRAME
NMCT SUBFRAME NMCT de JSON SUBFRAME
SUBFRAME1 SUBFRAME SUBFRAME1 (Éphémérides 1) de JSON SUBFRAME
SUBFRAME2 SUBFRAME SUBFRAME2 (Éphémérides 2) de JSON SUBFRAME
SUBFRAME3 SUBFRAME SUBFRAME3 (Éphémérides 3) de JSON SUBFRAME
SAT SKY Satellites individuels de SKY
SKY SKY Les parties de base de SKY JSON
TPV TPV Les parties de base de TPV JSON

ARGUMENTS

Par défaut, les clients collectent des données à partir du démon gpsd local fonctionnant sur localhost, en utilisant le port GPSD par défaut 2947. L'argument optionnel de n'importe quel client peut modifier ce comportement : [serveur[:port[:périphérique]]]

Pour plus d'explications et d'exemples, consultez la section ARGUMENTS de la page de manuel gps(1)

Exemples de graphiques

Quelques exemples de graphiques, à exécuter dans l'ordre exact indiqué :

Récupérer 100 échantillons de time,lat,lon,altHAE :

  $ gpscsv -n 100 --cvt-isotime  > tpv.dat

Récupérer 100 échantillons de time,epx,epy,epv,eph,sep

  $ gpscsv -n 100 --cvt-isotime -f time,epx,epy,epv,eph,sep > ep.dat

Récupérer 100 échantillons de time,xdop,ydop,vdop,tdop,hdop,gdop,pdop

  $ gpscsv -n 100 --cvt-isotime -c SKY  > sky.dat

Récupérer 100 échantillons de time,nSat,uSat

  $ gpscsv -n 100 --cvt-isotime -c SKY -f time,nSat,uSat  > sat.dat

Visualisation des données CSV avec gnuplot

Démarrez gnuplot en mode interactif :

  $ gnuplot

Quelques instructions de base pour gnuplot :

iv class="Bd-indent"> 
  # ce sont des fichiers csv
  gnuplot> set datafile separator ','
  # utiliser la première ligne comme titre
  gnuplot> set key autotitle columnhead
  # L'axe X est en temps UNIT en secondes.
  gnuplot> set xdata time
  gnuplot> set timefmt "%s"

Maintenant pour tracer le temps par rapport à la latitude, en utilisant tpv.dat ci-dessus :

  gnuplot> plot 'tpv.dat' using 1:2

Ensuite, pour tracer la longitude et altHAE, dans des tracés séparés :

  gnuplot> plot 'tpv.dat' using 1:3
  gnuplot> plot 'tpv.dat' using 1:4

Mettez la latitude et la longitude sur un seul tracé :

  gnuplot> set y2tics
  gnuplot> plot 'tpv.dat' using 1:2, '' using 1:3 axes x1y2

Tracez epx, epy, epv, eph et sep sur un seul tracé, en utilisant ep.dat ci-dessus :

  gnuplot> plot 'ep.dat' using 1:2, '' using 1:3, \
           '' using 1:4, '' using 1:5, '' using 1:6

Tracez tous les DOP sur un seul tracé, à partir de sky.dat ci-dessus :

  gnuplot> plot 'sky.dat' using 1:2, '' using 1:3, '' using 1:4, \
           '' using 1:5, '' using 1:6, '' using 1:7, '' using 1:8

Tracez nSat et uSat ensemble :

  gnuplot> plot 'sat.dat' using 1:2, '' using 1:3

Nuage de points lat/lon :

  # x n'est plus le temps
  gnuplot> set xdata
  gnuplot> plot 'tpv.dat' using 3:2 title 'fix'
