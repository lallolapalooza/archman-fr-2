NOM

gpg-tui.toml - fichier de configuration pour gpg-tui

SYNTAXE

Le fichier gpg-tui.toml est un fichier de configuration pour gpg-tui. Le fichier doit être placé à l'un des emplacements suivants :

$HOME/.config/gpg-tui.toml, $HOME/.config/gpg-tui/gpg-tui.toml, $HOME/.config/gpg-tui/config

Il peut également être spécifié avec l'option --config ou la variable d'environnement $GPG_TUI_CONFIG. Si le fichier n'existe pas à l'emplacement approprié ou n'est pas fourni, gpg-tui utilise ses paramètres de configuration par défaut.

DESCRIPTION

Le fichier TOML utilisé pour configurer gpg-tui contient une section de paramètres généraux suivie de la section gpg qui permet de configurer les options GnuPG.

FORMAT

[general]
Section pour les paramètres généraux.
  • splash : affiche l'écran de démarrage au lancement (par défaut : false)
  • tick_rate : définit le taux de rafraîchissement du terminal (par défaut : 250)
  • color : définit la couleur d'accentuation du terminal (par défaut : gray)
  • style : définit le style du terminal (par défaut : colored) (valeurs possibles : plain, colored)
  • file_explorer : définit l'utilitaire de sélection de fichiers (par défaut : xplr)
  • detail_level : définit le niveau de détail pour les clés (par défaut : minimum) (valeurs possibles : minimum, standard, full)
  • log_file : définit le fichier où enregistrer les journaux
  • key_bindings : liste des raccourcis clavier personnalisés
[gpg]
Section pour les paramètres GnuPG.
  • armor : active la sortie en armure ASCII (par défaut : false)
  • homedir : définit le répertoire personnel GnuPG
  • outdir : définit le répertoire de sortie
  • outfile : définit le modèle pour le nom du fichier de sortie
  • default_key : définit la clé par défaut pour signer

EXEMPLE

Voici un exemple complet de configuration par défaut de gpg-tui.toml :

[general]
  splash = false
  tick_rate = 250
  color = "gray"
  style = "colored"
  file_explorer = "xplr"
  detail_level = "minimum"
  key_bindings = [
    { keys = [ "?", "h", "f1" ], command = ":help" },
    { keys = [ "C-d", "C-c", "q" ], command = ":quit" },
  ]
[gpg]
  armor = false
  homedir = "~/.gnupg"
  outdir = "~/.gnupg/out"
  outfile = "{type}_{query}.{ext}"
  default_key = ""
