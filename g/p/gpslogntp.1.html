NOM

gpslogntp - enregistre les données gpsd pour ntpviz

SYNTAXE

gpslogntp [-h] [-l FICHIER_JOURNAL] [-o] [-w ATTENTE] [-v] [-V]
-h, --help            afficher ce message d'aide et quitter
-l FICHIER_JOURNAL, --logfile FICHIER_JOURNAL
                      ajouter les données journalisées à FICHIER_JOURNAL au lieu de stdout
-o, --once            enregistrer une ligne, puis quitter
-w ATTENTE, --wait ATTENTE  attendre ATTENTE secondes entre les lignes journalisées, par défaut 5
-v, --verbose         être verbeux
-V, --version         afficher le numéro de version du programme et quitter

DESCRIPTION

gpslogntp se connecte à un démon gpsd local et enregistre le nombre de satellites utilisés et la dilution du temps (TDOP). gpslogntp peut être exécuté par n'importe quel utilisateur, aucun privilège spécial n'est requis. Ce journal est destiné à être utilisé par ntpviz.

Par défaut, les données sont écrites sur stdout environ toutes les 5 secondes. Le fichier journal ressemble à ceci :

# Temps       Périphérique     TDOP     nSat
1483668619.0 /dev/ttyS0 0.820000 7
1483668624.0 /dev/ttyS0 0.820000 7
1483668629.0 /dev/ttyS0 0.820000 7

Temps est le temps POSIX du moment où la ligne de journal est écrite.

Périphérique est le périphérique GPS dont proviennent les données.

TDOP est la dilution du temps (Time Dilution of Precision) rapportée par le GPS. Certains GPS produisent toujours un TDOP statique.

nSat est le nombre de satellites utilisés.

Anciennement connu sous le nom de ntploggps et auparavant partie de NTPsec.

Remarque : De nombreux récepteurs GNSS rapportent toujours TDOP comme "1.0".

OPTIONS

-h, --help

Affiche les informations d'utilisation et quitte.

-l FICHIER_JOURNAL, --logfile FICHIER_JOURNAL

Ajouter les données journalisées à FICHIER_JOURNAL au lieu de stdout

-o, --once

Enregistrer une ligne, puis quitter.

-v, --verbose

Être verbeux

-w ATTENTE, --wait ATTENTE

Attendre ATTENTE secondes après chaque ligne journalisée. La valeur par défaut est de 5 secondes. C'est juste le temps d'attente minimum. gpsd peut rapporter les données à un intervalle beaucoup plus lent.

-V, --version

afficher le numéro de version du programme et quitter

UTILISATION

gpslogntp

C'est l'utilisation la plus simple de ce programme. Elle peut être utilisée pour vérifier l'état du démon gpsd local.

gpslogntp -l /var/log/ntpstats/gpsd -w 60 &

Cela enregistrera en continu les données gpsd en arrière-plan dans le fichier /var/log/ntpstats/gpsd. Enregistrement seulement toutes les 60 secondes.
