GPO(1) Commandes utilisateur GPO(1)

NOM

gpo - Interface en mode texte de gPodder

SYNTAXE

gpo [--verbose|-v|--quiet|-q] [COMMANDE] [param...]

DESCRIPTION

gpo est l'interface en mode texte de gPodder. Exécutez-la sans aucun argument pour démarrer le shell interactif (voir ci-dessous). Utilisez "gpo help" pour obtenir une liste des commandes prises en charge.

gpo peut être utilisé pour gérer des podcasts depuis la ligne de commande sans avoir à démarrer gPodder. Il peut également être utilisé pour automatiser des tâches telles que le téléchargement ou la mise à jour de flux.

La base de données et les fichiers sont les mêmes que ceux utilisés par l'interface graphique, gpodder(1).

MODE SHELL INTERACTIF

Si vous exécutez "gpo" sans COMMANDE, il entrera en mode shell interactif. De là, vous pouvez taper des commandes directement. Lorsque readline est disponible, ce shell prend en charge la complétion à l'aide de <Tab>. Les URL des flux de podcasts sont également complétées pour les commandes qui prennent l'URL d'un podcast comme argument.

Certaines commandes (par exemple, search et toplist) afficheront une requête en mode shell interactif (pour s'abonner à des podcasts). Ces requêtes ne seront pas affichées lorsqu'elles sont lancées directement depuis la ligne de commande.

PREFIXES DE COMMANDES

Pour toutes les commandes, vous pouvez utiliser seulement les premiers caractères au lieu de la commande complète, tant que la commande est unique. Sinon, gpo vous montrera toutes les commandes correspondantes et le préfixe le plus court de chacune.

Veuillez noter que les ajouts futurs à l'ensemble des commandes pourraient modifier le préfixe le plus court de n'importe quelle commande donnée, il est donc recommandé d'utiliser la commande complète dans les scripts (par exemple, utilisez "gpo update" et non "gpo up" dans les scripts et les cronjobs). Les préfixes de commande courts sont principalement utiles pour une utilisation interactive.

EXEMPLES

gpo

Entrer en mode shell interactif

gpo update && gpo download

Vérifier les nouveaux épisodes, puis télécharger tous les nouveaux épisodes

gpo search linux outlaws

Rechercher dans le répertoire les podcasts nommés "linux outlaws"

gpo youtube http://youtube.com/watch?v=oHg5SJYRHA0

Afficher l'URL de téléchargement d'une vidéo YouTube sur stdout
