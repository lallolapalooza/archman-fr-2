NOM

gpg-preset-passphrase - Mettre une phrase de passe dans le cache de gpg-agent

SYNTAXE

gpg-preset-passphrase [options] [commande] id-cache

DESCRIPTION

gpg-preset-passphrase est un utilitaire pour pré-remplir le cache interne d'un gpg-agent en cours d'exécution avec des phrases de passe. Il est principalement utile pour les machines non surveillées, où l'outil habituel pinentry ne peut pas être utilisé et où les phrases de passe pour les clés à utiliser sont fournies au démarrage de la machine.

Ce programme fonctionne avec GnuPG 2 et les versions ultérieures. GnuPG 1.x n'est pas supporté.

Les phrases de passe définies avec cet utilitaire n'expirent pas, sauf si l'option --forget est utilisée pour les effacer explicitement du cache — ou si gpg-agent est redémarré ou rechargé (en lui envoyant un SIGHUP). Notez que le temps de cache maximum défini avec --max-cache-ttl est toujours respecté. Il est nécessaire d'autoriser cette présélection de phrases de passe en lançant gpg-agent avec l'option --allow-preset-passphrase.

gpg-preset-passphrase est invoqué comme suit :

gpg-preset-passphrase [options] [commande] id-cache

id-cache est soit une empreinte de clé de 40 caractères hexadécimaux identifiant la clé pour laquelle la phrase de passe doit être définie ou effacée. L'empreinte de clé est listée avec la clé lors de l'exécution de la commande : gpgsm --with-keygrip --list-secret-keys. Alternativement, une chaîne arbitraire peut être utilisée pour identifier une phrase de passe ; il est suggéré que cette chaîne soit préfixée par le nom de l'application (par exemple, foo:12346). Les scripts devraient toujours utiliser l'option --with-colons, qui fournit l'empreinte de clé dans une ligne "grp" (voir ‘doc/DETAILS’).

L'une des options de commande suivantes doit être fournie :

--preset
Pré-sélectionner une phrase de passe. C'est ce que vous utiliserez habituellement. gpg-preset-passphrase lira alors la phrase de passe depuis stdin.
--forget
Supprimer la phrase de passe pour l'ID de cache donné du cache.

Les options supplémentaires suivantes peuvent être utilisées :

-v
--verbose
Afficher des informations supplémentaires pendant l'exécution.
-P chaîne
--passphrase chaîne
Au lieu de lire la phrase de passe depuis stdin, utiliser la chaîne fournie comme phrase de passe. Notez que cela rend la phrase de passe visible pour les autres utilisateurs.
