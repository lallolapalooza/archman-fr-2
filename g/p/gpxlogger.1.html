NOM

gpxlogger - Outil pour se connecter à gpsd et générer un fichier GPX

SYNTAXE

gpxlogger [OPTIONS] [serveur[:port[:périphérique]]]

gpxlogger -h

gpxlogger -V

DESCRIPTION

Le programme gpslogger collecte les positions de gpsd et les enregistre sur la sortie standard au format GPX, un profil XML pour l'enregistrement de traces. Il n'a pas besoin de s'exécuter en tant que root, mais peut le faire.

La sortie peut être composée de plusieurs traces. Une nouvelle trace est créée s'il n'y a pas de position enregistrée pendant un intervalle spécifié par l'option -i ou --interval, avec une valeur par défaut de 5 secondes.

gpxlogger peut utiliser n'importe quelle méthode d'exportation prise en charge par gpsd. Pour une liste de ces méthodes, utilisez l'option -l ou --exports. Pour forcer une méthode, utilisez l'option -e, --export suivie de l'un des noms de méthode se terminant par deux-points de la table -l, --exports.

OPTIONS

-?, -h, --help

Affiche un résumé des options puis quitte.

-d, --daemonize

Exécute en tant que démon en arrière-plan. Nécessite l'option -f, --output, qui dirige la sortie vers un fichier journal spécifié.

-D LVL, --debug LVL

Définit le niveau de débogage, principalement pour le dépannage. Active divers messages de progression sur la sortie d'erreur standard.

-e METHOD, --export METHOD

Si le support D-Bus est disponible sur l'hôte, GPSD est configuré pour l'utiliser, et -e dbus ou --export dbus est spécifié, ce programme écoute les diffusions DBUS de gpsd via org.gpsd.fix.

Avec -e sockets ou si sockets est la méthode par défaut, vous pouvez fournir une spécification [serveur[:port[:périphérique]]] comme arguments. Voir la section ARGUMENTS ci-dessous pour plus de détails.

Avec -e shm, --export shm ce programme écoutera le gpsd local en utilisant la mémoire partagée.

-f OUTFILE, --output OUTFILE

Écrit le journal GPX dans le fichier OUTFILE, au lieu de la sortie standard. Vous pouvez utiliser les options strftime(3) dans OUTFILE.

-F INFILE, --filein INFILE

Lit le JSON de gpsd depuis le fichier INFILE, au lieu d'un démon gpsd.

-g, --garmin

Active les extensions Garmin au format GPX. Cela permet également d'enregistrer la profondeur dans la sortie gpx. Non compatible avec Google Maps.

-i SECONDS, --interval SECONDS

Une nouvelle trace est créée s'il n'y a pas de position enregistrée pendant un intervalle de SECONDS. La valeur par défaut est de 5 secondes.

-l, --exports

Liste toutes les options possibles pour -e, --export.

-m MINMOVE, --minmove MINMOVE

Définit une distance de déplacement minimale en mètres (elle peut inclure une partie décimale fractionnaire). Les mouvements plus courts que cela ne seront pas enregistrés.

-r, --reconnect

Réessaye lorsque GPSd perd la position. Sans -r, gpxlogger quitterait dans ce cas.

-V, --version

Affiche la version du paquet et quitte.

ARGUMENTS

Par défaut, les clients collectent les données du démon gpsd local s'exécutant sur localhost, en utilisant le port par défaut de GPSD, 2947. L'argument optionnel à tout client peut modifier ce comportement : [serveur[:port[:périphérique]]]

Pour plus d'explications et d'exemples, consultez la section ARGUMENTS de la page de manuel gps(1)

VALEURS DE RETOUR

0

En cas de succès.

1

En cas d'échec.

Note

spxlogger envoie les messages d'erreur au journal système, et non à
stderr.

EXEMPLES

Pour exécuter en démon et enregistrer le journal gpx dans un nom de fichier horodaté :

$ gpxlogger -d -f "out-%c.gpx"
