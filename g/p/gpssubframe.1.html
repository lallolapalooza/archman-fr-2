NOM

gpssubframe - outil pour extraire les trames de sous-trame de gpsd

SYNTAXE

gpssubframe [OPTIONS] [serveur[:port[:périphérique]]]

gpssubframe -h

gpssubframe -V

DESCRIPTION

gpssubframe est un outil pour se connecter à gpsd et extraire les données de sous-trame décodées vers la sortie standard. Ceci n'est utile que si votre récepteur GNSS peut émettre des messages de sous-trame GPS et est configuré pour le faire. Une connaissance pratique de IS-GPS-200 est également requise. Gardez votre copie à portée de main.

gpssubframe ne nécessite pas de privilèges root, mais fonctionnera bien en tant que root. Il peut être exécuté simultanément avec d'autres outils se connectant au gpsd local sans causer de problèmes.

Le programme accumulera les messages de sous-trame et les affichera par numéro de satellite GPS à la sortie. Par défaut, le programme ne se termine jamais sauf si l'utilisateur sélectionne le nombre de secondes d'exécution ou le nombre de messages à capturer.

Par défaut, gpssubframe se connecte à un gpsd en cours d'exécution sur l'hôte local. Optionnellement, un hôte, un numéro de port TCP/IP et un périphérique distant peuvent être fournis.

OPTIONS

-?, -h, --help

Imprime un message d'aide et quitte.

-c COUNT, --count COUNT

Quitte après COUNT messages de sous-trame.

-D DEBUG, --debug DEBUG

Définit le niveau de débogage. Doit être un entier. Par défaut 0.

--desc

Imprime de longues descriptions.

--device DEVICE

Se connecte au périphérique DEVICE sur l'hôte gpsd.

-D LVL, --debug LVL

Définit le niveau de débogage à LVL.

--file FILE

Lit le JSON de gpsd depuis FILE au lieu de gpsd.

--host HOST

Se connecte à gpsd sur l'hôte HOST.

--load LOADFILE

Charge les données enregistrées en JSON de sous-trame, TPV et RAW depuis LOADFILE.

-n COUNT, --count COUNT

Nombre de messages à analyser. 0 pour désactiver.

--port PORT

Se connecte à gpsd sur le port PORT.

--progress

Affiche des rapports de progression au fur et à mesure de la réception des messages.

--satpos

Calcule les positions des satellites GPS avant de quitter. Si --time est donné, les positions seront calculées à l'heure spécifiée. Sinon, si un message RAW a été reçu, l'heure de mesure dans ce message sera utilisée. Le dernier recours est d'utiliser l'heure du dernier message TPV.

--save SAVEFILE

Sauvegarde les données de sous-trame décodées dans SAVEFILE au format JSON. Si présent, les derniers enregistrements JSON TPV et RAW seront également sauvegardés.

--test

Exécute le code d'auto-test --satpos.

--time SEC

Calcule la position du satellite au temps SEC en secondes POSIX.

-V, --version

Affiche la version du programme, puis quitte.

-x SEC, --seconds SEC

Secondes de messages à analyser. 0 pour désactiver.

ARGUMENTS

Par défaut, les clients collectent les données du démon gpsd local fonctionnant sur localhost, en utilisant le port par défaut de GPSD, le 2947. L'argument optionnel à tout client peut modifier ce comportement : [serveur[:port[:périphérique]]]

Pour plus d'explications et d'exemples, consultez la section ARGUMENTS de la page de manuel gps(1)

EXEMPLES

Configurez d'abord un u-blox série 9 pour émettre des messages de sous-trame. Ensuite, demandez à gpssubframe de collecter un ensemble complet de sous-trames, puis affichez les données organisées par numéro de satellite GPS. Assurez-vous de remplacer -P 22 par la version de protocole correcte pour votre récepteur. Ensuite, calculez et affichez les positions des satellites connues ainsi que l'azimut, l'élévation et la portée depuis la position actuelle :

ubxtool -P 22 -e SFRBX
gpssubframe -x 750 --satpos

Si fixer un écran vide pendant 12,5 minutes est trop stressant, alors activez les messages de progression :

gpssubframe -x 750 --satpos --progress

VALEURS DE RETOUR

0

en cas de succès.

1

en cas d'échec
