GPGPARTICIPANTS(1) Manuel des commandes générales GPGPARTICIPANTS(1)

NOM

gpgparticipants - générer une liste papier pour une fête de signature de clés

SYNTAXE

gpgparticipants [OPTIONS] {entrée|-} {sortie|-} datestring organisateur titre

DESCRIPTION

gpgparticipants s'adresse aux organisateurs d'une fête de signature de clés qui utilise le protocole de signature de clés Zimmermann-Sassaman.

Il crée un fichier avec toutes les clés d'une liste de participants à votre fête de signature de clés. Vous lui donnez une liste d'identifiants de clés et quelques variables générales, et il générera un fichier que vous pourrez publier. Vous publiez cette liste ; les participants téléchargeront et imprimeront ce fichier pour l'emporter à la fête.

OPTIONS

-aHASHES, --algorithm=HASHES

Pour chaque algorithme dans HASHES, une liste d'algorithmes de hachage séparés par des virgules supportés par gpg(1), ajouter un espace réservé pour la valeur de hachage (à remplir par les participants) au fichier de sortie. Par défaut : SHA256,RIPEMD160.

ENVIRONNEMENT

HOME
Définit le répertoire personnel par défaut.
GNUPGBIN
Définit le binaire gpg. Par défaut : "gpg".
GNUPGHOME
Définit le répertoire de travail par défaut pour gpg. Par défaut : "~/.gnupg".

EXEMPLES

Pour créer un fichier KSP avec toutes les clés présentes dans le porte-clés :


gpg --with-colons --fingerprint | sed -n "/^pub:/ {n; /^fpr:/p}" | cut -sd: -f10 | \
gpgparticipants - ksp-file.txt "20080222 1100" "Mon Nom <mon.nom@mon.mail>" "ma fête 08"

VOIR AUSSI

gpg(1),gpgsigs(1)
