gpssnmp(1)

Paquet: gpsd

GPSSNMP(1) Documentation GPSD GPSSNMP(1)

NOM

gpssnmp - Client auxiliaire SNMP pour gpsd

SYNTAXE

gpssnmp [OPTIONS] [serveur[:port[:périphérique]]]

gpssnmp -h

gpssnmp -g OID

gpssnmp -n OID

gpssnmp -p

gpssnmp -V

DESCRIPTION

gpssnmp est un client gpsd qui fonctionne comme un auxiliaire SNMP pour MRTG.

gpssnmp ne requiert pas de privilèges root. Il fonctionnera également très bien en tant que root.

gpssnmp peut agir en tant qu'agent pour snmpd en mode pass ou en mode pass_persist. Il peut donc être utilisé pour étendre snmpd avec le GPSD-MIB. Compte tenu de la nature du protocole SNMP, ne vous attendez pas à une faible latence. Les données provenant de différentes époques peuvent être mélangées.


Note

Ce programme est nouveau dans la version 3.24.1 et sera sujet à
des modifications pendant quelques révisions. Considérez-le comme un travail en cours (WIP).

OPTIONS

-?, -h, --help

Affiche un résumé des options puis quitte. Utilisez avec "-D 1" pour voir les valeurs OID valides. Utilisez avec "-D 2" pour voir les valeurs OID valides avec leurs échelles et descriptions.

-g OID

Récupère l'OID spécifié.

-n OID

Récupère l'OID suivant à partir de OID.

-p, --persist

Passe en mode pass_persist. Cela permet de meilleures performances lorsqu'il est utilisé comme agent pour le démon snmpd. Voir la page de manuel snmpd.conf pour plus de détails.

-V, --version

Affiche la version du paquet puis quitte.

EXEMPLES:

Pour obtenir le nombre de satellites vus avec l'OID

   $ gpssnmp -g .1.3.6.1.4.1.59054.11.2.1.3.1
   .1.3.6.1.4.1.59054.11.2.1.3.1
   INTEGER
   15

Pour obtenir le nombre de satellites vus avec le nom MIB

   $ gpssnmp -g skynSat.1
   .1.3.6.1.4.1.59054.11.2.1.3.1
   INTEGER
   15

Connexion à snmpd

gpssnmp peut fonctionner comme un script de « passage » avec snmpd. Pour activer cette fonctionnalité sur une installation snmpd déjà fonctionnelle, ajoutez ceci à votre fichier snmpd.conf, puis redémarrez snmpd :

# assurez-vous que la communauté SNMPv2 « public » peut accéder à tous les MIBs :
rocommunity public  localhost
# configurez le passage du GPSD-MIB vers gpssnmp
pass .1.3.6.1.4.1.59054  /usr/local/bin/gpssnmp

Vous pouvez ensuite interroger le nombre de satellites en cours d'utilisation de cette manière :

$ snmpget -c public -v 2c localhost skynSat.1
GPSD-MIB::skynSat.1 = INTEGER: 16

Sauvegardez l'intégralité de l'OID « sky » de cette manière :

$ snmpwalk -c public -v 2c localhost GPSD-MIB::sky
GPSD-MIB::skynSat.1 = INTEGER: 17
GPSD-MIB::skyuSat.1 = INTEGER: 8
GPSD-MIB::skySNRavg.1 = INTEGER: 2000

Sauvegardez l'intégralité du GPSD-MIB de cette manière :

$ snmpwalk -c public -v 2c localhost gpsd
GPSD-MIB::tpvLeapSeconds = INTEGER: 18
GPSD-MIB::tpvNumber = INTEGER: 1
GPSD-MIB::tpvIndex.1 = INTEGER: 1
[...]

gpssnmp prend en charge le mode pass_persist de snmpd. Pour que snmpd utilise gpssnmp dans ce mode, mettez ceci dans votre fichier snmpd.conf :

pass_persist .1.3.6.1.4.1.59054  /usr/local/bin/gpssnmp --persist

VALEURS DE RETOUR

0

En cas de succès.

1

En cas d'échec.
