GP(1) Manuel des commandes générales GP(1)

NOM

gp - La calculatrice PARI

SYNTAXE

gp [-s taille_pile] [-p limite_nombres_premiers] [--emacs] [-f|--fast] [-q|--quiet] [-D|--default clé=val] [--help] [--test] [--texmacs] [--version] [--version-short] [ fichier1 fichier2 ...]

DESCRIPTION

Lance la calculatrice PARI-GP gp ; gp est une calculatrice avancée et programmable, spécialisée en théorie des nombres, qui calcule symboliquement aussi longtemps que possible, numériquement si nécessaire, et contient une multitude de fonctions arithmétiques : factorisations, courbes elliptiques, théorie de Galois, théorie des corps de classes, formes modulaires, etc. Les commandes, écrites dans le langage de script GP, sont saisies interactivement ou chargées à partir de fichiers.

Si des fichiers 'fichier1', 'fichier2', ... sont présents à la fin de la ligne de commande, ils sont chargés au démarrage ; ils doivent être écrits dans le langage GP.

OPTIONS

Les options de ligne de commande sont disponibles sous forme courte (-f) et POSIX-like (--fast). Les arguments numériques peuvent être suivis d'un modificateur k , M ou G à la convenance de l'utilisateur ; dans ce cas, l'argument est multiplié par 10^3, 10^6 ou 10^9 respectivement.

-f, --fast
Démarrage rapide (ou paramètres d'usine). Ne lit pas .gprc (voir ci-dessous) au démarrage.
-p limite
[OBSOLÈTE] Au démarrage, gp calcule une table de petits nombres premiers utilisés dans les applications de théorie des nombres. Si limite_nombres_premiers est définie, la table inclut les nombres premiers jusqu'à cette borne au lieu de la valeur par défaut (= 1048576). Il est maintenant largement inutile de changer cette valeur.
-q, --quiet
Mode silencieux. N'affiche pas les en-têtes, les numéros d'historique et ne dit pas au revoir.
-D, --default clé=val
effectue default(clé, val) ; au démarrage, remplaçant les valeurs du fichier de préférences gprc. 'val' doit être une valeur constante et ne peut impliquer aucun calcul (par exemple, 1+1 est interdit). Un nombre quelconque de telles instructions de définition de défauts peuvent apparaître sur la ligne de commande. Une clé peut être définie plusieurs fois, le dernier réglage prenant la priorité.
-s limite
Taille de la pile interne de gp allouée au démarrage. Lorsque gp manque d'espace, il interrompt le calcul en cours et lève une exception de dépassement de pile. Si cela se produit fréquemment, démarrez avec une pile plus grande. La taille de la pile peut également être augmentée depuis gp, en utilisant default(parisize,limite); il est pratique de définir parisize dans votre .gprc afin que le réglage soit persistant entre les sessions ; une valeur de 80 Mo est raisonnable. Nous conseillons fortement de définir également parisizemax à une valeur positive, beaucoup plus grande, dans votre .gprc (environ ce que vous estimez que votre machine peut supporter, généralement la moitié de la RAM disponible environ) : ceci tente de faire tenir le calcul dans la plage de parisize mais lui permet de la dépasser temporairement (jusqu'à parisizemax). Notez que les calculs avec une pile plus petite peuvent être plus efficaces en raison d'une meilleure localité des données. Enfin, threadsize et threadsizemax jouent des rôles analogues dans la version parallèle de gp.
--emacs
gp peut être exécuté dans un shell Emacs (voir le Manuel Utilisateur de GP pour plus de détails). Ce drapeau est alors requis pour une interaction fluide avec le package PariEmacs (pari.el). Il est automatiquement défini par le package pari.el, et produira des bizarreries d'affichage si vous le définissez en dehors d'une session Emacs.
--help
affiche un résumé des options de ligne de commande disponibles.
--test
exécute gp en mode test : supprime l'affichage des numéros d'historique et renvoie à la ligne les lignes de sortie longues (pour obtenir un diff lisible). Uniquement pour les benchmarks.
--texmacs
gp peut être exécuté depuis une interface TeXmacs. Ce drapeau est défini par TeXmacs, pour activer des canaux de communication spéciaux. Ne le définissez pas vous-même.
--version
affiche les informations de version (bannière) puis quitte.
--version-short
affiche le numéro de version puis quitte.

FICHIERS

gp
exécutable principal
$HOME/.gprc
(ou $GPRC s'il est défini) fichier de préférences utilisateur, lu au début de l'exécution par chaque shell gp. Un fichier gprc par défaut gprc.dft est fourni avec la distribution. Si ce fichier ne peut être trouvé, /etc/gprc est vérifié à la place.
<fichier_journal>
un fichier utilisé pour enregistrer toutes les commandes et les résultats ; par défaut : pari.log (vous devez définir la valeur par défaut log dans votre gprc ou interactivement)
<fichier_ps>
un fichier utilisé pour sauvegarder les dessins PostScript ; par défaut : pari.ps
<fichier_historique>
un fichier où gp conservera un historique de toutes les commandes saisies (vous devez définir la valeur par défaut histfile dans le fichier gprc)
gphelp
programme d'aide externe par défaut (comme ci-dessus)
*.gp
programmes GP

ENVIRONNEMENT

$GPRC
emplacement pour rechercher le fichier de préférences utilisateur (gprc) ; si le fichier n'existe pas, nous vérifions ensuite dans $HOME/.gprc, /etc/gprc, et enfin pour un fichier nommé 'gprc' dans le datadir de PARI.
$GP_DATA_DIR
répertoire contenant les données installées par les paquets PARI optionnels. Par exemple, les fichiers de résolvants de Galois dans le répertoire galdata/ nécessaires à la fonction polgalois, pour les degrés 8 à 11 ; ou les polynômes modulaires dans seadata/ utilisés par la fonction ellap pour de grands corps de base. Cette variable d'environnement remplace le 'datadir' de PARI, défini lors de la configuration.
$GP_POSTSCRIPT_VIEWER
une application capable d'afficher des fichiers PostScript, utilisée par le moteur graphique plotps. Ce moteur est un mécanisme de secours utilisé pour produire des graphiques haute résolution même lorsqu'aucune bibliothèque graphique compatible n'était disponible sur votre plateforme au moment de la configuration. (Sauvegarde le graphique dans un fichier temporaire, puis ouvre le fichier.)
$GP_SVG_VIEW

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

ER
une application capable d'afficher des fichiers images SVG, utilisée par le moteur graphique plotsvg. Ce moteur est un repli utilisé pour produire des tracés haute résolution même lorsqu'aucune bibliothèque graphique compatible n'était disponible sur votre plateforme au moment de l'exécution de Configure. (Découpe le graphique dans un fichier temporaire, puis ouvre le fichier.)
$GPHELP
nom du programme d'aide externe invoqué par les raccourcis ?? et ???.
$GPTMPDIR
nom du répertoire où les fichiers temporaires seront générés.

CURIOSITÉS

Malgré le G initial, GP n'a rien à voir avec GNU. La première version s'appelait à l'origine GPC, pour Great Programmable Calculator. Quand les gens ont commencé à l'appeler « the GPC Calculator », le C final a été supprimé.

PARI n'a rien à voir avec la capitale française. Le nom est un jeu de mots sur les débuts du projet quand les auteurs ont commencé à implémenter une bibliothèque pour « Pascal ARIthmetic » dans le langage de programmation PASCAL. Ils sont rapidement passés à C.

Pour le bénéfice des personnes dont le français n'est pas la langue maternelle, voici une explication légèrement développée : Blaise Pascal (1623-1662) était un célèbre mathématicien et philosophe français qui fut l'un des fondateurs de la théorie des probabilités et conçut l'une des premières « machines arithmétiques ». Il proposa autrefois la « preuve » suivante de l'existence de Dieu pour les incroyables : qu'Il existe ou non, je n'y perds rien en croyant en Lui, alors que s'Il existe et que je me conduis mal... C'est ce qu'on appelle le « pari de Pascal ».

Notez que PARI signifie aussi « fée » en persan.
