DESCRIPTIO

N

gpasm est un assembleur pour les microcontrôleurs PIC (TM) de Microchip (TM). Il est conçu pour être compatible avec l'assembleur MPASM du fabricant. gpasm fait partie de gputils. Consultez la page man gputils(1) pour plus de détails s

ur les autres utilitai
res GNU pour PIC.

Voici un résumé des options de gpasm. Les options de gpasm priment toujours sur tout réglage présent dans le code

source.
-a FMT, --hex-format
FMT
GPASM prend en charge les formats de fichiers hexadécimaux inhx8m, inhx8s, inhx16 et inhx32. Cette option contrôle le format de fichier hexadécimal utilisé. La valeur par défaut est
inhx32.
-c, --obje
ct
Produit un objet relocalisable (nouveau format COFF)

-D SYM=VAL, --define
SYM=VAL
Définit SYM avec la valeur VAL. Cela équivaut à placer « #define SYM VAL » dans la
source.
-e [ON|OFF], --expand
[ON|OFF]
L'expansion des macros dans le fichier de listing est contrôlée à l'aide des directives EXPAND et NOEXPAND. Cette option peut forcer l'ignorance de l'une ou l'autre de ces directives. Lorsque « ON » est sélectionné, les macros sont toujours développées, indépendamment de la présence de NOEXPAND. De même, « OFF » forcera les macros à ne pas être
développées.
-f, --full-addre
ss
Affiche l'adresse complète dans le fichier .lst pour la région de la table de
mémoire.

fo

COFF.

lp
Affiche le message d'utilisation et
quitte.
-i, --ignore-ca
se
Tous les symboles et macros définis par l'utilisateur sont sensibles à la casse. Cette option les rend insensibles à la
casse.
-I DIR, --include
DIR
Le fichier d'assemblage de premier niveau est passé à gpasm en tant qu'argument. Ce fichier peut contenir des directives INCLUDE. Ces directives ouvrent le fichier spécifié, puis son contenu est assemblé. GPASM recherche ces fichiers dans le répertoire local. Si le fichier n'est pas trouvé, le chemin d'en-tête par défaut est vérifié. Enfin, tous les chemins spécifiés à l'aide de cet argument sont
recherchés.

ist
Aide à l'extension du fichier pic16devices.txt dans le projet sdcc. Utilisé seul, il affiche tous les périphériques « 16e ». Combiné avec l'option « -p », il n'affiche que le périphérique
spécifié.

Par défaut, gpasm génère des fichiers hexadécimaux au format ISO. Cependant, certains programmeurs de périphériques nécessitent un fichier au format DOS. Cette option fera en sorte que gpasm génère un fichier hexadécimal au format
DOS.
-o FICHIER, --output
FICHIER
Nom alternatif des fichiers de sortie. Effet de l'option : -- Si l'option « -c » est incluse dans la ligne de commande : FICHIER.o, FICHIER.lst, FICHIER.err (« FICHIER.o » doit être spécifié.) -- Si l'option « -c » n'est pas incluse dans la ligne de commande : FICHIER.hex, FICHIER.cod, FICHIER.lst, FICHIER.err (« FICHIER.hex » doit être spécifié.

[0|1|2]
Définit le niveau de rigueur des paramètres d'instruction recommandés (W ou F et A ou B). Les « messages de rigueur » ont une priorité plus élevée que les avertissements.
