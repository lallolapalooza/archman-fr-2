NOM

gprename - Renommeur de lots complet pour Linux

SYNTAXE

gprename répertoire

DESCRIPTION

Cette page de manuel documente brièvement la commande gprename.

gprename est un renommage par lots complet pour les fichiers et les répertoires, codé pour Linux en GTK2-Perl. GPRename est licencié sous les termes de la Licence Publique Générale GNU. GPRename offre de nombreuses options pour renommer par lots, telles que remplacer, supprimer, insérer ou effacer du texte, ajouter des numéros consécutifs et est disponible dans de nombreuses langues.

FICHIERS

~/.gprename Fichier texte de configuration utilisateur
~/.gprename_log Fichier texte du journal utilisateur
