NOM

gpdasm - Désassembleur GNU PIC

SYNTAXE

gpdasm [options] fichier

AVERTISSEMENT

Les informations de cette page de manuel sont un extrait de la documentation complète de gputils et sont limitées à la signification des options. Pour une documentation complète et à jour, référez-vous à "gputils.ps" situé dans le répertoire des documents de gputils.

DESCRIPTION

gpdasm est un désassembleur pour microcontrôleurs Microchip (TM) PIC (TM). gpdasm fait partie de gputils. Consultez la page de manuel gputils(1) pour plus de détails sur les autres utilitaires GNU PIC.

OPTIONS

-c, --mnemonics
Décode les mnémoniques spéciaux.
-h, --help
Affiche ce message d'utilisation et quitte.
-i, --hex-info
Rapporte des informations supplémentaires sur le fichier hexadécimal d'entrée. Ces informations incluent la taille du fichier et le format hexadécimal.
-j, --mov-fsrn
Dans les instructions MOVIW ou MOVWI, affiche le registre FSRn comme base au lieu de INDFn. [INDFn]
-k FICHIER, --label-list FICHIER
Un fichier qui liste les noms et adresses des étiquettes dans le code du programme désassemblé. (Avec les options -n, -o et -s.)
-l, --list-chips
Liste les processeurs supportés.
-m, --dump
Affiche le contenu de la mémoire d'instructions.
-n, --show-names
Pour certains cas de SFR, affiche le nom au lieu de l'adresse. Affiche également les étiquettes.
-o, --show-config
Affiche les directives CONFIG et IDLOCS - ou __idlocs -.
-p PROC, --processor PROC
Sélectionne le processeur.
-s, --short
Produit le format court. Ce format peut être réassemblé par gpasm. (Voir aussi les options -k, -n et -o.)
-t, --use-tab
Utilise des tabulations dans le texte écrit.
-v, --version
Affiche les informations de version et quitte.
-y, --extended
Active le mode étendu 18xx.
--strict
Désassemble uniquement les opcodes générés par gpasm en cas d'instructions avec plusieurs opcodes.
--strict-options
Si cette option est définie, une option ne peut pas être le paramètre d'une autre option. Par exemple : -p --dump
