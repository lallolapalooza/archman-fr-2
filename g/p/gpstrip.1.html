NOM

gpstrip - supprimer les symboles d'un fichier objet

SYNTAXE

gpstrip [options] [fichier(s)]

AVERTISSEMENT

Les informations contenues dans cette page de manuel sont un extrait de la documentation complète de gputils et se limitent à la signification des options. Pour une documentation complète et à jour, veuillez vous référer à "gputils.ps" situé dans le répertoire des documents de gputils.

DESCRIPTION

gpstrip supprime les symboles des fichiers objets GNU PIC. gpstrip fait partie de gputils. Consultez la page de manuel gputils(1) pour plus de détails sur les autres utilitaires GNU PIC.

OPTIONS

-g, --strip-debug
Supprimer les symboles de débogage.
-h, --help
Afficher le message d'utilisation et quitter.
-k SYMBOLE, --keep-symbol SYMBOLE
Conserver le symbole.
-n SYMBOLE, --strip-symbol SYMBOLE
Supprimer le symbole.
-o FICHIER, --output FICHIER
Nom alternatif du fichier de sortie.
-p, --preserve-dates
Conserver les dates.
-r SECTION, --remove-section SECTION
Supprimer la section.
--strict-options
Si ceci est défini, alors une option ne peut pas être un paramètre d'une autre option. Par exemple : -o --version
-s, --strip-all
Supprimer tous les symboles.
-u, --strip-unneeded
Supprimer les symboles non nécessaires aux relocalisations.
-v, --version
Afficher les informations de version et quitter.
-V, --verbose
Mode verbeux.
-x, --discard-all
Supprimer les symboles non globaux.
