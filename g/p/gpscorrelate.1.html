NOM

gpscorrelate - corrèle les images numériques avec des données GPS en remplissant les champs EXIF

SYNTAXE

gpscorrelate [-z | --timeadd +/-HH[:MM]] [-O | --photooffset secondes] [-i | --no-interpolation] [-v | --verbose] [-d | --datum datum] [-n | --no-write] [-R | --replace] [-m | --max-dist temps] [-t | --ignore-tracksegs] [-M | --no-mtime] [--degmins] [-g fichier.gpx | [-l | --latlong] latitude,longitude[,altitude]] image.jpg...

gpscorrelate -s | --show | -o | --machine image.jpg...

gpscorrelate {-r | --remove} [-M | --no-mtime] image.jpg...

gpscorrelate {-f | --fix-datestamps} {-z | --timeadd +/-HH[:MM]} image.jpg...

gpscorrelate -V | --version | -h | --help

DESCRIPTION

Cette page de manuel documente la commande gpscorrelate. Une documentation plus étendue est disponible au format HTML ; voir ci-dessous.

gpscorrelate est un programme qui agit sur des images numériques au format JPEG, en remplissant les champs EXIF (Exchangeable Image File Format) liés aux informations GPS (Global Positioning System). La source des données GPS est un fichier GPX (GPS Exchange Format), qui enregistre les informations de localisation GPS dans un format basé sur XML. L'acte de remplir ces champs est appelé *corrélation*.

Si des données GPS sont disponibles au moment précis où l'image a été prise (avec une granularité d'une seconde), les données GPS sont stockées sans modification dans les champs EXIF. Sinon, une interpolation linéaire des données GPS disponibles avant et après la prise de vue peut être utilisée. Une mesure de la précision approximative de la lecture GPS est préservée lors de l'écriture dans l'image.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-g, --gps fichier.gpx

Corrèle les images en utilisant le fichier GPX spécifié contenant des points de trace GPS. Cette option peut être donnée plusieurs fois pour spécifier plusieurs fichiers GPX. Pour chaque photo corrélée, le premier fichier contenant une trace couvrant le moment de la prise de vue sera utilisé. Tous les segments <trk> de chaque fichier sont utilisés.

-l, --latlong latitude,longitude[,altitude]

Fournit une coordonnée géographique spécifique à utiliser pour toutes les images au lieu de corréler le long d'un chemin dans un fichier GPX. Le format doit être de la forme générale latitude,longitude,altitude où la latitude et la longitude doivent être chacune sous forme décimale, comme -123.45678, ou sous forme de degrés/minutes/secondes, comme -123°45'67.8" ou -123d45m67s. La fourniture d'une altitude est facultative. Chaque composant peut être séparé par des virgules, des espaces ou des tabulations.

Notez que cette option a un bug connu dans le sens où elle ne parse pas correctement les nombres dans les locales qui utilisent autre chose qu'un "." comme séparateur décimal.

-s, --show

Affiche uniquement les données GPS déjà présentes dans les tags EXIF de l'image donnée, au lieu de les corréler.

-o, --machine

Affiche uniquement les données GPS des images données dans un format CSV lisible par machine. Les images sans tags GPS sont ignorées. Les champs affichés sont le nom du fichier, la date et l'heure, la latitude, la longitude, l'altitude, où la première valeur est le nom du fichier, tel que passé, la seconde est le timestamp, et les trois dernières sont des valeurs flottantes avec un signe plus ou moins optionnel.

-r, --remove

Supprime toutes les données EXIF GPS des images données. Notez que cela ne supprime que les tags GPS que le programme a pu ajouter ; il ne supprime pas tous les tags EXIF GPS possibles. Tous les autres tags restent inchangés.

-z, --timeadd +/-HH[:MM]

Temps à ajouter aux points GPS pour qu'ils correspondent aux horodatages des images. Les horodatages GPS sont en UTC ; les horodatages des images sont généralement en heure locale. Entrez le fuseau horaire utilisé lors de la prise des images ; par exemple, +8 pour Perth, Australie Occidentale ou -2:30 pour St. John's, Terre-Neuve. Par défaut, il s'agit du décalage UTC du fuseau horaire local au moment de la première image traitée (les versions antérieures à 1.7 par défaut à 00:00).

-O, --photooffset secondes

Temps en secondes à ajouter à l'horodatage de la photo pour qu'il corresponde à l'horodatage GPS. Pour déterminer le nombre de secondes nécessaires, créez simplement une photographie de votre appareil GPS montrant l'heure actuelle et comparez-la avec l'horodatage de votre fichier photo. Les tags de temps EXIF dans l'image ne sont pas modifiés en fonction de cette valeur.

-i, --no-interpolation

Désactive l'interpolation linéaire entre les points. Avec ce drapeau, le point exact le plus proche (dans la limite de --max-dist) est utilisé. Sans ce drapeau, les photos prises entre le moment de deux coordonnées GPS enregistrées sont corrélées sur la base d'une interpolation linéaire entre ces deux points.

-v, --verbose

Affiche un peu plus d'informations pendant le processus de corrélation d'images, telles que les données GPS sélectionnées pour chaque image.

-d, --datum datum

Spécifie le datum de mesure GPS. S'il n'est pas défini, WGS-84 est utilisé (TOKYO est une autre possibilité). Cependant, GPX n'est pas censé stocker autre chose que WGS-84, donc cela ne devrait jamais être nécessaire qu'avec l'option --latlong.

-n, --no-write

N'écrit pas les données EXIF corrélées dans l'image. Utile avec --verbose pour voir ce qui se passerait lors de la corrélation d'images.

-R, --replace

Écrase les tags GPS existants dans le fichier. Sans cette option, tout fichier contenant déjà des tags GPS sera ignoré.

-m, --max-dist temps

Temps maximum en secondes par rapport au temps de la photo auquel un point GPS enregistré peut se référer et être toujours utilisé pour la corrélation. La valeur par défaut est 0, ce qui signifie que cette vérification est désactivée. Un seul des deux points doit être dans cette plage pour que la corrélation ait lieu.

Si la précision de la localisation est primordiale et que vous préférez ne pas corréler du tout une position pour une photo si les coordonnées GPS les plus proches ont été enregistrées trop loin dans le passé ou trop loin dans le futur (par rapport au moment où la photo a été prise), définissez cette valeur sur un nombre non nul.

-t, --ignore-tracksegs

Interpole également entre les segments de piste. Généralement, les segments de piste montrent plusieurs sessions d'enregistrement GPS ; entre eux se situe généralement le moment où le GPS n'enregistrait pas. Étant donné que l'interpolation respecte le drapeau --max-dist, même les segments de piste avec de larges écarts de temps peuvent être utilisés en toute sécurité si les deux drapeaux sont activés. Sans ce drapeau, les photos prises pendant l'intervalle de temps entre deux pistes <trkseg> dans le fichier GPX ne sont pas corrélées.

-M, --no-mtime

Ne modifie pas la dernière heure de modification des fichiers modifiés.

-f, --fix-datestamps

Corrige les horodatages GPS erronés écrits avec les versions de gpscorrelate < 1.5.2 en les remplaçant par l'horodatage de la photo. Avant la version 1.5.2, deux bugs écrivaient la mauvaise valeur pour les tags GPSDateStamp et GPSTimeStamp. Cette option vérifie chaque nom de fichier fourni pour le problème et le corrige. Utilisez avec --no-write pour empêcher l'écriture de ces modifications (utile pour vérifier le problème). Cette option implique également --no-mtime. Vous devrez également utiliser --timeadd pour spécifier la différence entre l'heure locale et l'heure UTC pour les photos fournies.

--degmins

Écrit l'emplacement sous forme DD MM.MM (au lieu de DD MM SS.SS plus précis) comme c'était le cas par défaut dans les versions de gpscorrelate < 1.5.3. Il n'y a aucune bonne raison d'utiliser cette option, sauf si un programme défectueux attend ce style.

-h, --help

Affiche uniquement un résumé des options.

-V, --version

N'affiche que le numéro de version de gpscorrelate et les informations de copyright.

RETOUR

gpscorrelate renvoie 0 en cas de succès, 1 en cas d'erreur majeure (telle qu'une erreur de lecture ou d'écriture) et 2 en cas d'erreur mineure (comme le fait que la trace GP

S fournie ne couvre pas la
date et l'heure d'une image).
