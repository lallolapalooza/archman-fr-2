DESCRIPTIO

N

La commande gpasswd est utilisée pour administrer /etc/group et /etc/gshadow. Chaque groupe peut avoir des administrateurs, des membres et un mot de

passe.

Les administrateurs système peuvent utiliser l'option -A pour définir le ou les administrateurs du groupe et l'option -M pour définir les membres. Ils ont tous les droits des administrateurs et des membres du

groupe.

gpasswd appelé par un administrateur de groupe avec uniquement un nom de groupe invite à saisir le nouveau mot de passe du groupe

.

Si un mot de passe est défini, les membres peuvent toujours utiliser newgrp(1) sans mot de passe, et les non-membres doivent fournir le mot de

passe.

Notes sur les mots de passe de

groupe

Les mots de passe de groupe sont un problème de sécurité inhér

ent puisqu'il est permis à plus d'une personne de connaître
le mot de passe. Cependant, les groupes sont un outil util
e pour permettre la coopération entre différents utilisateurs.

CONFIGURATIO

N

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil

:

ENCRYPT_METHOD

(chaîne)
Définit l'algorithme de chiffrement par défaut du système pour chiffrer les mots de passe (si aucun algorithme n'est spécifié sur la ligne de commande).

Elle peut prendre l'une de ces valeurs : DES (par défaut), MD5, SHA256, SHA512, YESCRYPT. MD5 et DES ne devraient pas être utilisés pour de nouveaux hachages, voir crypt(5) pour les recommandations

.

Remarque : ce paramètre remplace la variable MD5_CRYPT_ENAB

.

Remarque : Cela n'affecte que la génération des mots de passe de groupe. La génération d

es mots de passe utilisateur est effectuée par PAM et soumise à la configuration PAM. Il
est recommandé de définir cette variable de manière cohérente avec la configuration PAM.

MAX_MEMBERS_PER_GROU

P (nombre)
Nombre maximal de membres par entrée de groupe. Lorsque le maximum est atteint, une nouvelle entrée de groupe (ligne) est commencée dans /etc/group (avec le même nom, le même mot de passe et le même GID).

La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite au nombre de membres dans un

groupe.

Cette fonctionnalité (groupe divisé) permet de limiter la longueur des lignes dans le fichier de groupe. Cela est utile pour s'assurer que les lignes des groupes NIS ne dépassent pas 1024

caractères.

Si vous devez faire respecter une telle limite, vous pouvez utiliser

25.

Remarque : les groupes divisés peuvent ne pas être pris en charge par t

ous les outils (même dans la suite d'outils Shadow). Vous ne devrie
z pas utiliser cette variable à moins d'en avoir réellement besoin.

MD5_CRYPT_ENAB (

booléen)
Indique si les mots de passe doivent être chiffrés à l'aide de l'algorithme basé sur MD5. Si défini à yes, les nouveaux mots de passe seront chiffrés à l'aide de l'algorithme basé sur MD5 compatible avec celui utilisé par les versions récentes de FreeBSD. Il prend en charge les mots de passe de longueur illimitée et les chaînes de sel plus longues. Défini à no si vous devez copier des mots de passe chiffrés vers d'autres systèmes qui ne comprennent pas le nouvel algorithme. La valeur par défaut est no.

Cette variable est remplacée par la variable ENCRYPT_METHOD ou par toute option de ligne de commande utilisée pour configurer l'algorithme de

chiffrement.

Cette variable est obsolète. Vous devriez utiliser ENCRYPT_METHOD

.

Remarque : Cela n'affecte que la génération des mots de passe de groupe. La génération d

es mots de passe utilisateur est effectuée par PAM et soumise à la configuration PAM. Il
est recommandé de définir cette variable de manière cohérente avec la configuration PAM.

SHA_CRYPT_MIN_ROUNDS (nombre), SHA_CRYPT_MAX_ROUNDS

(nombre)
Lorsque ENCRYPT_METHOD est défini à SHA256 ou SHA512, cela définit le nombre de tours SHA utilisés par l'algorithme de chiffrement par défaut (lorsque le nombre de tours n'est pas spécifié sur la ligne de commande).

Avec beaucoup de tours, il est plus difficile de forcer le mot de passe par force brute. Mais notez également que plus de ressources CPU seront nécessaires pour authentifier les

utilisateurs.

Si ce n'est pas spécifié, la libc choisira le nombre de tours par défaut (5000), ce qui est de plusieurs ordres de grandeur trop faible pour le matériel

moderne.

Les valeurs doivent se situer dans la plage 1000-999 999

999.

Si seulement l'une des valeurs SHA_CRYPT_MIN_ROUNDS ou SHA_CRYPT_MAX_ROUNDS est définie, alors cette valeur sera

utilisée.

Si SHA_CRYPT_MIN_ROUNDS > SHA_CRYPT_MAX_ROUNDS, la valeur la plus élevée sera

utilisée.

Remarque : Cela n'affecte que la génération des mots de passe de grou

pe. La génération des mots de passe utilisateur est effectuée par
PAM et soumise à la configuration PAM. Il est recommandé de défin
ir cette variable de manière cohérente avec la configuration PAM.
