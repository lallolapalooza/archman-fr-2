DESCRIPTIO

N

gpgdir est un script perl qui utilise le module perl CPAN GnuPG::Interface pour chiffrer et déchiffrer récursivement des répertoires à l'aide de gpg. gpgdir parcourt récursivement un répertoire afin de s'assurer qu'il chiffre ou déchiffre chaque fichier d'un répertoire et de tous ses sous-répertoires. Par défaut, les valeurs mtime et atime de tous les fichiers seront préservées lors du chiffrement et du déchiffrement (cela peut être désactivé avec l' --no-preserve-times option). Notez qu'en mode --encrypt, gpgdir supprimera les fichiers originaux qu'il chiffre avec succès (sauf si l' --no-delete option est fournie). Cependant, au démarrage, gpgdir demande d'abord le mot de passe de déchiffrement pour s'assurer qu'un fichier factice peut être chiffré et déchiffré avec succès. Le test initial peut être désactivé avec l' --skip-test option afin qu'un répertoire puisse être facilement chiffré sans avoir à spécifier également un mot de passe (ce qui est cohérent avec le comportement de gpg). Notez également que gpgdir fait attention à ne pas chiffrer les fichiers et répertoires cachés. Après tout, vous ne voulez probablement pas que votre répertoire ~/.gnupg ou votre fichier ~/.bashrc soit chiffré. La clé que gpgdir utilise pour chiffrer/déchiffrer un répertoire est spécifiée dans ~/.

gpgdirrc.

Enfin, gpgdir peut utiliser le programme wipe avec l' --Wipe option de ligne de commande pour supprimer de manière sécurisée les fichiers originaux non chiffrés après qu'ils ont été chiffrés avec succès. Cela élève le niveau de sécurité de gpgdir car il est pl

us difficile de récupérer les données non chiffrées associées aux fichiers depuis le système de fichie
rs après leur chiffrement (unlink() n'efface pas les blocs de données même si un fichier est supprimé).

OPTION

S
-e, --encrypt
<répertoire>
Chiffrer récursivement tous les fichiers du répertoire spécifié sur la ligne de commande. Tous les fichiers d'origine seront supprimés (une vérification du mot de passe est effectuée d'abord pour s'assurer que l'utilisateur connaît le mot de passe correct pour déverrouiller la clé privée GnuPG)
.
-d, --decrypt
<répertoire>
Déchiffrer récursivement tous les fichiers du répertoire spécifié sur la ligne de commande. La version .gpg chiffrée de chaque fichier sera
supprimée.
--sign
<répertoire>
Signer récursivement tous les fichiers du répertoire spécifié sur la ligne de commande. Pour chaque fichier, une signature détachée .asc sera
créée.
--verify
<répertoire>
Vérifier récursivement toutes les signatures .asc des fichiers du répertoire spécifié sur la ligne de
commande.
-g, --gnupg-dir
<répertoire>
Spécifier quel répertoire .gnupg sera utilisé pour trouver les clés GnuPG. La valeur par défaut est ~/.gnupg si cette option n'est pas utilisée. Cette option permet à gpgdir d'être exécuté en tant qu'un utilisateur mais d'utiliser les clés d'un autre utilisateur (en supposant que les permissions sont configurées correctement,
etc.).
-p, --pw-file
<pw-file>
Lire le mot de passe de déchiffrement depuis pw-file au lieu de le taper sur la ligne de
commande.
-t, --test-mo
de
Exécuter un test de chiffrement et de déchiffrement sur un fichier factice et quitter. Ce test est toujours exécuté par défaut à la fois en mode --encrypt et --decryp
t.
-S, --Symmetr
ic
Indiquer à gpgdir de chiffrer et déchiffrer les fichiers à l'aide d'un chiffrement symétrique pris en charge par GnuPG (CAST5 est couramment utilisé). Cela entraîne une accélération significative du processus de chiffrement/déchiffreme
nt.
-T, --Trial-r
un
Afficher les actions de chiffrement/déchiffrement qui auraient lieu sans les exécuter réellement. Le système de fichiers n'est modifié d'aucune manière dans ce
mode.
-I, --Interacti
ve
Demander à l'utilisateur avant de chiffrer ou déchiffrer réellement chaque fichier. C'est utile pour avoir un contrôle fin sur les opérations de gpgdir alors qu'il parcourt une structure de
répertoires.
-F, --For
ce
Dire à gpgdir d'ignorer les conditions d'erreur non fatales, comme l'incapacité de chiffrer ou déchiffrer des fichiers individuels en raison d'erreurs de
permissions.
--Exclude
<motif>
Indiquer à gpgdir de sauter tous les fichiers qui correspondent au motif comme correspondance regex avec chaque nom de fichier. C'est similaire à l' --exclude option de la commande standard GNU
tar.
--Exclude-from
<fichier>
Indiquer à gpgdir d'exclure tous les fichiers correspondant aux motifs listés dans fichier. C'est similaire à l' --exclude-from de la commande GNU
tar.
--Include
<motif>
Indiquer à gpgdir d'inclure uniquement les fichiers qui correspondent au motif comme correspondance regex avec chaque nom de
fichier.
--Include-from
<fichier>
Indiquer à gpgdir d'inclure uniquement les fichiers correspondant aux motifs listés dans fichi
er.
-W, --Wi
pe
Utiliser le programme wipe pour supprimer de manière sécurisée les fichiers après qu'ils ont été chiffrés avec
succès.
-O, --Obfuscate-filen
ame
Dire à gpgdir d'obfusquer les noms des fichiers qu'il chiffre (en mode -e). Les noms de chaque fichier sont stockés dans le fichier .gpgdir_map_file pour chaque sous-répertoire, et ce fichier est lui-même chiffré. En mode déchiffrement (-d), l'argument -O inverse le processus afin que les fichiers d'origine soient
restaurés.
--overwrite-encryp
ted
Écraser les fichiers chiffrés même si un fichier <fichier>.gpg précédent existe
déjà.
--overwrite-decryp
ted
Écraser les fichiers déchiffrés même si le fichier non chiffré précédent existe
déjà.
-K, --Key-id
<id>
Spécifier manuellement un ID de clé GnuPG depuis la ligne de commande. Parce que GnuPG prend en charge la correspondance des clés avec une chaîne, id n'a pas strictement besoin d'être un ID de clé ; cela peut être une chaîne qui correspond de manière unique à une clé dans l'anneau de clés
GnuPG.
-D, --Default-k
ey
Utiliser la clé que GnuPG définit comme par défaut, c'est-à-dire la clé spécifiée par la variable default-key dans ~/.gnupg/options. Si la variable default-key n'est pas définie dans ~/.gnupg/options, alors GnuPG essaie d'utiliser la première clé appropriée sur son anneau de clés (le test initial de chiffrement/déchiffrement s'assure que l'utilisateur connaît le mot de passe correspondant pour la
clé).
-a, --age
nt
Indiquer à gpgdir d'obtenir le mot de passe de la clé gpg depuis une instance gpg-agent en cours
d'exécution.
-A, --Agent-info
<info_connexion>
Spécifier la valeur de la variable d'environnement GPG_AGENT_INFO telle que renvoyée par la commande gpg-agent --daemon. Si l' argument de ligne de commande gpgdir --agent est utilisé au lieu de --Agent-info, alors gpgdir suppose que la variable d'environnement GPG_AGENT_INFO a déjà été définie dans le shell
courant.
-s, --skip-te
st
Sauter le test de chiffrement et de déchiffrement. Cela permettra à gpgdir d'être utilisé pour chiffrer un répertoire sans spécifier de mot de passe (qui est normalement utilisé en mode chiffrement pour tester et s'assurer que le déchiffrement d'un fichier factice fonctionne correctement)
.
-q, --qui
et
Afficher le moins possible à l'écran lors du chiffrement ou du déchiffrement d'un
répertoire.
--no-recur
se
Indiquer à gpgdir de ne pas parcourir les sous-répertoires du répertoire qui est en cours de chiffrement ou de
déchiffrement.
--no-passwo
rd
Indique à gpgdir de ne pas demander un mot de passe à l'utilisateur. Ceci n'est utile que lorsqu'une clé gpg n'a littéralement aucun mot de passe associé (ce qui n'est pas courant)
.
--no-dele
te
Indique à gpgdir de ne pas supprimer les fichiers originaux lors du
chiffrement.
--no-preserveti
mes
Indique à gpgdir de ne pas préserver les valeurs mtime et atime originales des fichiers lors du chiffrement ou du
déchiffrement.
-l, --locale
<locale>
Fournit un paramètre de locale autre que la locale par défaut
"C".
--no-loca
le
Ne pas définir la locale du tout afin que la locale système par défaut soit
appliquée.
-v, --verbo
se
Exécuter en mode
verbeux.
-V, --Versi
on
Afficher le numéro de version et
quitter.
-h, --he
lp
Afficher les
informations
d'utilisatio
n et quitter.

EXEMPLE

S

Les exemples suivants illustrent les arguments de ligne de commande qui peuvent être fournis à gpgdir dans quelques situations

:

Pour chiffrer un répertoire

:

$ gpgdir -e

/some/dir

Pour chiffrer un répertoire et utiliser la commande wipe pour supprimer de manière sécurisée les fichiers originaux non chiffrés

:

$ gpgdir -W -e

/some/dir

Pour chiffrer un répertoire avec la clé GnuPG par défaut définie dans ~/.gnupg/options

:

$ gpgdir -e /some/dir

--Default-key

Pour déchiffrer un répertoire avec une clé spécifiée dans ~/.gpgdirrc

:

$ gpgdir -d

/some/dir

Pour chiffrer un répertoire mais ignorer tous les noms de fichiers contenant la chaîne "host"

:

$ gpgdir -e /some/dir --Exclude

host

Pour chiffrer un répertoire mais ne chiffrer que les fichiers contenant la chaîne "passwd"

:

$ gpgdir -e /some/dir --Include

passwd

Pour obtenir le mot de passe de la clé GnuPG auprès d'un démon gpg-agent en cours d'exécution afin de déchiffrer un répertoire (cela nécessite que gpg-agent ait le mot de passe)

:

$ gpgdir -A /tmp/gpg-H4DBhc/S.gpg-agent:7046:1 -d

/some/dir

Pour chiffrer un répertoire mais ignorer le test de chiffrement/déchiffrement (vous ne serez donc pas invité à saisir un mot de passe de déchiffrement)

:

$ gpgdir -e /some/dir

-s

Pour chiffrer un répertoire et aucun sous-répertoire

:

$ gpgdir -e /some/dir

--no-recurse

Pour chiffrer le répertoire personnel de root, mais utiliser les clés GnuPG associées à l'utilisateur "bob"

:

# gpgdir -e

/root -g /hom
e/bob/.gnupg

DÉPENDANCE

S

gpgdir nécessite que gpg, le Gnu Privacy Guard (http://www.gnupg.org) soit installé. gpgdir nécessite également le module perl GnuPG::Interface de CPAN, mais il est inclus avec gpgdir et est installé dans /usr/lib/gpgdir au moment de l'installation

afin de ne pas polluer l'arboresce
nce des bibliothèques perl du système.
