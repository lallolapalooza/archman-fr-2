NOM

gpsinit - initialiser les modules du noyau CAN pour GPSD

SYNTAXE

gpsinit [-n contrôle] [-s vitesse] nom_module [nom_interface]

gpsinit -h

gpsinit -V

DESCRIPTION

gpsinit initialise les modules nécessaires au niveau du noyau pour permettre à du matériel spécial non-série de communiquer avec une instance gpsd. Note : il nécessitera des permissions root pour charger des modules et effectuer d'autres opérations spéciales, comme changer les débits en bauds des interfaces du noyau.

À l'heure actuelle, tous les modes de cet outil concernent la mise en place d'interfaces au niveau du noyau pour du matériel parlant NMEA2000 sur un réseau CAN (Control Area Network).

Le programme accepte les options suivantes :

-h

Affiche un bref message d'aide.

-n

Définit le numéro de réseau CAN. La valeur par défaut est 0.

-s

Définit le débit en bauds à utiliser pour communiquer sur la ligne série avec le matériel CAN. Le débit par défaut est de 38400 bauds.

-V

Affiche la version de gpsinit.

Le paramètre nom_module est obligatoire. Le module du pilote CAN socket nom_module.ko sera chargé. gpsinit reconnaît les noms de modules suivants :

plx_pci, esd_usb2, vcan, slcan

Le paramètre nom_interface et la vitesse -s peuvent être utilisés ici.

beaglebone

Le module dcan nécessaire pour le beaglebone fait partie du noyau Linux, donc aucun module n'est chargé dans ce cas.

Le paramètre nom_interface est nécessaire uniquement pour le matériel slcan. Il donne le nom du périphérique série auquel le matériel SL CAN est connecté. Le nom par défaut est /dev/ttyUSB0.

EXEMPLES

Tous les exemples suivants devront probablement être exécutés en tant que root.

gpsinit plx_pci

Tente de charger le module plx_pci et d'initialiser le réseau 0 pour la connexion à un réseau NMEA2000. Il définira le débit en bauds à 250 kbits.

gpsinit -n 1 plx_pci

Comme ci-dessus, mais utilise le réseau 1.

gpsinit -s 38400 slcan /dev/ttyUSB0

Tente de charger le module slcan et de communiquer avec le matériel à 38400 bauds connecté au port /dev/ttyUSB0.

gpsinit -h

Affiche un bref message d'aide.

gpsinit -v

Affiche la version de gpsinit.

VALEURS DE RETOUR

0

En cas de succès.

1

En cas d'échec.
