gperl(1) Manuel des commandes générales gperl(1)

Nom

gperl - exécuter des commandes Perl dans des documents groff

Synopsis

gperl [fichier ...]
gperl -h
gperl --help
gperl -v
gperl --version

Description

Ceci est un préprocesseur pour groff(1). Il permet l'utilisation de code perl(7) dans des fichiers groff(7). Le résultat d'une partie Perl peut être stocké dans des chaînes ou des registres numériques de groff en fonction des arguments de la dernière ligne d'une partie Perl.

Si aucun opérande n'est donné, ou si fichier est « - », gperl lit le flux d'entrée standard. Un argument double-tiret (« -- ») provoque l'interprétation de tous les arguments suivants comme opérandes fichier, même si leurs noms commencent par un tiret. -h et --help affichent un message d'utilisation, tandis que -v et --version affichent des informations de version ; tous se terminent ensuite.

Régions Perl

Les parties Perl dans les fichiers groff sont entourées par deux commandes .Perl avec des arguments différents, une commande de démarrage et une commande de fin.

Mode Perl de démarrage

La commande Perl de départ peut être sans arguments, ou par une commande qui a le terme start comme unique argument.

  • .Perl
  • .Perl start

Fin du mode Perl sans stockage

Une ligne de commande .Perl avec un argument différent de start termine une partie Perl en cours. Bien sûr, il serait raisonnable d'ajouter l'argument stop ; c'est possible, mais pas nécessaire.

  • .Perl stop
  • .Perl autre_que_start
L'argument autre_que_start peut également être utilisé comme nom de variable de chaîne groff pour le stockage — voir la section suivante.

Fin du mode Perl avec stockage

Une fonctionnalité utile de gperl est de stocker un ou plusieurs résultats du mode Perl.

La sortie d'une partie Perl peut être obtenue avec des backticks `...`.

Ce programme collecte tout ce qui est imprimé sur STDOUT (sortie standard normale) par le programme Perl print. Cette sortie pseudo-imprimée peut avoir plusieurs lignes, en raison des sauts de ligne imprimés avec \n. Ainsi, la sortie d'une exécution Perl devrait être stockée dans un tableau Perl, avec une seule ligne pour chaque membre du tableau.

Cette sortie de tableau Perl peut être stockée par gperl soit dans

chaînes groff
en créant une commande groff .ds
registre groff
en créant une commande groff .nr

Les modes de stockage peuvent être déterminés par les arguments d'une commande .Perl finale de fin. Chaque argument .ds change le mode en chaîne groff et .nr change le mode en registre groff pour toutes les parties de sortie suivantes.

Par défaut, toute la sortie est sauvegardée comme chaînes, donc .ds n'est pas vraiment nécessaire avant la première commande .nr. Cela convient à groff(7), car toute sortie peut être sauvegardée comme chaîne groff, mais les registres peuvent être très restrictifs.

En mode chaîne, gperl génère une ligne de stockage de chaîne groff

.ds nom_var contenu
En mode registre, la commande groff suivante est générée 
.nr nom_var contenu

Nous présentons les collections d'arguments ci-dessous. Vous pouvez ajouter stop comme premier argument pour toutes. Nous omettons cet élément supplémentaire.

.Perl .ds nom_var
Ceci stockera 1 ligne de sortie dans la chaîne groff nommée nom_var par la commande créée automatiquement
.ds nom_var sortie
.Perl nom_var
Si nom_var est différent de start, cela est équivalent à la commande précédente, car le mode chaîne est le mode chaîne avec la commande .ds. par défaut.
.Perl nom_var1 nom_var2
Ceci stockera 2 lignes de sortie dans les noms de chaînes groff nom_var1 et nom_var2, car le mode par défaut .ds est actif, donc aucun argument .ds n'est nécessaire. Bien sûr, ceci est équivalent à
.Perl .ds nom_var1 nom_var2
et 
.Perl .ds nom_var1 .ds nom_var2
.Perl .nr nom_var1 nomvar2
stocke les deux variables comme variables de registre. gperl génère
.nr nom_var1 ligne_sortie1
.nr nom_var2 ligne_sortie2
.Perl .nr nom_var1 .ds nom_var2
stocke le 1er argument comme registre et le second comme chaîne par
.nr nom_var1 ligne_sortie1
.ds nom_var2 ligne_sortie2

Exemple

Une partie Perl possible dans un fichier roff pourrait ressembler à cela :

avant
.Perl start
my $result = 'des données';
print $result;
.Perl stop .ds chaine_var
après

Ceci stocke le résultat « des données » dans la chaîne roff appelée chaine_var, de telle sorte que la ligne suivante est imprimée :

.ds chaine_var des données
par gperl comme nourriture pour la prochaine exécution de groff.

Une partie Perl avec plusieurs sorties est :

.Perl start
print "première\n";
print "deuxième ligne\n";
print "3\n";
.Perl var1 var2 .nr var3
Ceci stocke 3 lignes imprimées dans 3 chaînes groff. var1,var2,var3. Donc les lignes de commande groff suivantes sont créées : 
.ds var1 première
.ds var2 deuxième ligne
.nr var3 3
