DESCRIPTIO

N

gpg-agent est un démon pour gérer les clés secrètes (privées) indépendamment de tout protocole. Il est utilisé comme serveur principal pour gpg et gpgsm ainsi que pour quelques autres

utilitaires.

L'agent est automatiquement démarré à la demande par gpg, gpgsm, gpgconf, ou gpg-connect-agent. Il n'y a donc aucune raison de le démarrer manuellement. Si vous souhaitez utiliser l'agent Secure Shell inclus, vous pouvez démarrer l'agent en utilisant

: 
gpg-con
nect-age
nt /bye

Si vous souhaitez mettre manuellement fin à l'agent en cours d'exécution, vous pouvez le faire en toute sécurité avec

: 
gpgconf
--kill g
pg-agent

Vous devriez toujours ajouter les lignes suivantes à votre .bashrc ou à quelconque fichier d'initialisation utilisé pour toutes les invocations de shell

: 
GPG_TTY=$(
tty) expo
rt GPG_TTY

Il est important que cette variable d'environnement reflète toujours la sortie de la commande tty. Pour les systèmes W32, cette option n'est pas

requise.

Veuillez vous assurer qu'un programme pinentry approprié a été installé sous le nom de fichier par défaut (qui dépend du système) ou utilisez l'option pinentry-program pour spécifier le nom complet de ce programme. Il est souvent utile d'installer un lien symbolique depuis le pinentry réellement utilisé (par exemple «/usr/bin/pinentry-gtk ») vers celui attendu (par exemple «/usr/bin/pinentry »

)

L'ordre dans lequel les clés sont présentées à ssh est :
Valeurs négatives de Use-for-ssh
Si un fichier de clé a l'attribut « Use-for-ssh » et que sa valeur est
négative, ces clés sont présentées en premier à ssh. Les valeurs
négatives sont plafonnées à -999, -999 étant classé plus bas
que -1.
Ces valeurs peuvent être utilisées pour préférer les clés sur disque aux clés provenant
