GPICVIEW(1) Commandes utilisateur GPICVIEW(1)

NOM

gpicview - visionneuse d'images légère

SYNTAXE

gpicview [OPTION] [fichier]

DESCRIPTION


* Extrêmement léger et rapide avec une faible utilisation mémoire
* Très adapté comme visionneuse d'images par défaut des systèmes de bureau
* Interface simple et intuitive
* Dépendances minimales de bibliothèques
* Indépendant de l'environnement de bureau – aucun environnement de bureau spécifique requis

OPTIONS

--slideshow
Démarrer le diaporama
-v, --version
Afficher les informations de version et quitter
--display=AFFICHAGE
Affichage X à utiliser
-?, -h, --help
Afficher les options d'aide
--help-gtk
Afficher les options GTK+
--help-all
Afficher toutes les options d'aide
