NOM

gpgme-json - Opérations GPGME basées sur la messagerie native

SYNTAXE

gpgme-json [--interactive|-i] [--single|-s] [--identify fichier] [--lib-version] [--help|-h]

DESCRIPTION

gpgme-json est un pont JSON vers GPGME. Cette interface permet aux extensions de navigateur web de communiquer avec la bibliothèque GPGME via la fonctionnalité de messagerie native des navigateurs web.

OPTIONS

gpgme-json accepte les options suivantes en ligne de commande :

-i
--interactive
Active le mode interactif. Le mode interactif fournit également une aide en ligne.
-s
--single
Active le mode de requête unique.
--identify fichier|-
Identifie le type des données trouvées dans ‘fichier’ ou sur l'entrée standard -.
--debug
Active le mode de débogage. Les journaux sont enregistrés dans ‘~/.gnupg/S.gpgme-json.log’.

Notez que vous pouvez également activer le mode de débogage et spécifier un fichier journal personnalisé à l'aide de la variable d'environnement GPGME_JSON_DEBUG.

--lib-version
Affiche la version de la bibliothèque GPGME.
-h
--help
Affiche un message d'utilisation résumant les options de ligne de commande les plus utiles.
