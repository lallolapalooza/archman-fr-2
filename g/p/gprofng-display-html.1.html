GPROFNG-DISPLAY-HTML(1) Commandes utilisateur GPROFNG-DISPLAY-HTML(1)

NOM

gprofng-display-html - Génère une structure de répertoire basée sur HTML pour naviguer dans les profils

SYNTAXE

gprofng display html [option(s)] expérience(s)

DESCRIPTION

Traite une ou plusieurs expériences pour générer un répertoire contenant le fichier index.html qui peut être utilisé pour naviguer dans les données de l'expérience.

OPTIONS

--version
Affiche le numéro de version et quitte.
--help
Affiche les informations d'utilisation et quitte.
--verbose
Active le mode verbeux pour afficher des messages de diagnostic sur le traitement des données. Par défaut, le mode verbeux est désactivé.
-d [db-vol-size], --debug[=db-vol-size]
Contrôle l'affichage des informations de débogage d'exécution pour aider au dépannage ou au développement ultérieur de cet outil.

Le paramètre db-vol-size contrôle le volume de sortie et est l'un des éléments de la liste s, S, m, M, l, L, xl ou XL. Si db-vol-size n'est pas défini, une quantité modeste d'informations est imprimée. Ceci équivaut à sélectionner s ou S. Le volume de données augmente avec la taille. Notez qu'actuellement l/L est équivalent à xl/XL, mais cela devrait changer dans les futures mises à jour. Par défaut, le mode de débogage est désactivé.

--highlight-percentage=valeur
Définit une valeur en pourcentage dans l'intervalle [0,100] pour sélectionner et coder par couleur les lignes sources, ainsi que les instructions, qui se situent dans ce pourcentage des valeurs métriques maximales. La valeur par défaut est 90 (%). Une valeur de zéro désactive cette fonctionnalité.
-o nom_dir, --output=nom_dir
Utilise nom_dir comme nom de répertoire pour stocker les résultats. En l'absence de cette option, le nom par défaut est display.<n>.html. Ce répertoire est créé dans le répertoire courant. Le nombre <n> est le premier nombre entier positif non utilisé dans cette convention de nommage. Un répertoire existant portant le même nom n'est pas écrasé. Si le répertoire existe déjà, un message d'erreur est affiché et l'outil se termine.
-O nom_dir, --overwrite=nom_dir
Utilise nom_dir comme nom de répertoire pour stocker les résultats. En l'absence de cette option, le nom par défaut est display.<n>.html. Ce répertoire est créé dans le répertoire courant. Le nombre <n> est le premier nombre entier positif non utilisé dans cette convention de nommage. Un répertoire existant portant le même nom est écrasé silencieusement.
-q, --quiet
Désactive l'affichage de tous les messages d'avertissement, de débogage, verbeux ou tout autre message. Si activé, les paramètres de verbosité et de débogage sont acceptés, mais ignorés. Avec cette option, il n'y a aucune sortie à l'écran, à l'exception des erreurs. Par défaut, le mode silencieux est désactivé.
--nowarnings
Désactive l'affichage des messages d'avertissement sur stdout. Par défaut, les messages d'avertissement sont affichés.

NOTES

  • Les options et les valeurs sont sensibles à la casse.
  • Dans cette version, la syntaxe des options a été modifiée pour être plus conforme aux autres outils et commandes.

    Les options qui ne prenaient auparavant qu'une valeur on ou off agissent maintenant comme des commutateurs. L'option inverse le réglage par défaut. Par exemple, par défaut, le mode verbeux est désactivé. Il est activé en utilisant l'option --verbose.

    Les options longues, celles qui commencent par "--", et qui nécessitent une valeur, attendent le signe "=" entre l'option et la valeur.

    Bien que la syntaxe et les choix précédents soient toujours acceptés, nous recommandons fortement de modifier l'utilisation des options conformément à la nouvelle syntaxe et aux nouvelles valeurs. À un moment donné, ces paramètres hérités pourraient ne plus être acceptés.

    Pour faciliter la transition, un message d'avertissement est affiché si la syntaxe héritée, la valeur, ou les deux, sont utilisées.

  • L'option -hp est toujours acceptée, mais elle sera dépréciée dans une future version. Utilisez plutôt l'option --highlight-percentage.
  • Lors de la définition d'un nom de répertoire pour y stocker les fichiers HTML, assurez-vous que le umask est réglé sur les bonnes permissions d'accès.
  • Indépendamment du réglage des messages d'avertissement, s'il y a des avertissements, ils sont accessibles via la page principale index.html.
  • L'outil essaie d'accumuler autant d'avertissements et d'erreurs que possible avant d'agir. Ainsi, il est plus facile de traiter plusieurs problèmes à la fois. En conséquence de cette approche, il est possible que les messages ne s'affichent pas immédiatement. En particulier, les avertissements sont affichés vers la fin de l'exécution, mais une ou plusieurs erreurs termineront l'exécution avant que le traitement ne commence.
