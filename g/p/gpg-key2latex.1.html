NOM

gpg-key2latex - Génère un fichier LaTeX pour les feuilles d'empreintes digitales.

SYNTAXE

gpg-key2latex [-p taille_papier] [-s] [--show-photo] [--show-qrcode] id_cle [id_cle...]

DESCRIPTION

gpg-key2latex génère un fichier LaTeX avec une empreinte OpenPGP et des Identifiants Utilisateur, répétés autant de fois que possible sur une seule page. Les données LaTeX sont écrites sur la sortie standard (STDOUT). Remarque : Dans la plupart des cas, le fichier généré peut être compilé en PDF en utilisant pdflatex(1), mais xelatex(1) est requis si certains UID contiennent des caractères CJK.

OPTIONS

-p taille-papier, --paper-size=taille-papier
Sélectionne la taille du papier de sortie. La valeur par défaut est le résultat de paperconf(1), ou a4 si libpaper-utils n'est pas installé.
-s, --show-subkeys
Affiche les informations sur les sous-clés.
--show-photo
Affiche le premier attribut utilisateur valide, le cas échéant. Remarque : Ceci écrit des fichiers JPG dans le répertoire courant.
--show-qrcode
Affiche un QR code de la chaîne spécifiée par --qrcode-data. Remarque : Ceci écrit des fichiers PDF dans le répertoire courant. Nécessite qrencode(1) et epstopdf(1).
--qrcode-data=chaîne
Les données à encoder dans un QR code (implique --show-qrcode). La chaîne "%f" est développée en l'empreinte de clé OpenPGP (40 chiffres hexadécimaux, sans espaces) ; "%k" est développée en l'ID de clé long (16 chiffres hexadécimaux) ; "%%" est remplacé par un seul "%".

Les données par défaut à encoder, si --qrcode-data n'est pas spécifié, sont la chaîne "OPENPGP4FPR:%f".

--attr-height
La hauteur, en nombre de lignes, de la photo et du QR code. La valeur par défaut est le nombre d'identifiants utilisateur, avec un maximum de 5.
-?, --help
Affiche une brève aide et quitte.
--version
Affiche la version et quitte.

ENVIRONNEMENT

HOME
Le répertoire personnel par défaut.
GNUPGBIN
Le binaire gpg. Par défaut : "gpg".
GNUPGHOME
Le répertoire de travail par défaut pour gpg. Par défaut : "$HOME/.gnupg".

VOIR AUSSI

gpg(1), gpg-key2ps(1)
