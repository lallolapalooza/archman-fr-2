NOM

gpsplot - outil pour exporter dynamiquement des données de tracé depuis gpsd

SYNTAXE

gpsplot [OPTIONS] [serveur[:port[:périphérique]]]

gpsplot -h

gpsplot -V

DESCRIPTION

gpsplot est un outil permettant de se connecter à gpsd et d'exporter dynamiquement des données vers l'écran de l'utilisateur. Les types de tracés incluent les nuages de points et les graphiques linéaires.

Le traçage nécessite que le module Python Matplotlib, ainsi que ses nombreuses dépendances, soient installés sur l'hôte d'affichage. Si l'hôte d'affichage n'est pas l'hôte gpsd, alors Matplotlib n'a pas besoin d'être installé sur l'hôte gpsd.

gpslot ne nécessite pas de privilèges root, mais peut être exécuté en tant que root. L'exécution sous sudo entraînera une perte de fonctionnalités. Il peut être exécuté simultanément avec d'autres outils se connectant au gpsd local sans causer de problèmes.

OPTIONS

-?, -h, --help

Affiche un message d'utilisation et quitte.

-b BACKEND, --backend BACKEND

Définit le backend interactif Matplotlib sur BACKEND.

-B, --backends

Affiche les backends interactifs Matplotlib disponibles, puis quitte. Les backends Matplotlib varient considérablement en termes de vitesse d'exécution et d'apparence. Essayez-les tous pour vous faire votre propre opinion.

-d LVL, --debug LVL

Définit le niveau de débogage sur LVL.

--device PÉRIPHÉRIQUE

Le PÉRIPHÉRIQUE sur gpsd auquel se connecter. Par défaut, tous.

--exit

Quitte après la fin de --count, --file, ou --file.

--fields CHAMPS

Le code des champs à tracer. CHAMPS est l'un des suivants : llh (lat/lon/altHAE) ou llm (lat/lon/altMSL).

--file FICHIER

Lit les données JSON depuis FICHIER au lieu de gpsd.

--host HÔTE

Se connecte au gpsd sur HÔTE (serveur). Par défaut, localhost.

--image IMAGE.EXT

Enregistre le tracé sous forme d'IMAGE.EXT. EXT détermine le type d'image (.jpg, .png, etc.). Les EXT pris en charge dépendent de l'installation.

-n COUNT, --count COUNT

Arrête après COUNT messages de tracé. 0 pour désactiver. Par défaut 0.

--plottype TYPE_TRACÉ

Le type de tracé à générer. TYPE_TRACÉ est l'un des suivants : 'scatterplot' ou 'stripchart'.

-p PORT, --port PORT

Utilise le PORT pour se connecter à gpsd. Par défaut, 2947.

-V, --version

Affiche la version du programme et quitte.

-x SECONDES, --seconds SECONDES

Arrête après SECONDES. 0 pour désactiver. Par défaut 0.

ARGUMENTS

Par défaut, les clients collectent des données du démon gpsd local fonctionnant sur localhost, en utilisant le port GPSD par défaut 2947. L'argument optionnel pour tout client peut outrepasser ce comportement : [serveur[:port[:périphérique]]]

Pour plus d'explications et d'exemples, consultez la section ARGUMENTS de la page de manuel gps(1)

ENVIRONNEMENT

Vous pouvez définir la variable d'environnement MPLBACKEND pour votre backend Matplotlib souhaité. Cela vous évite d'utiliser -b BACKEND à chaque fois que vous exécutez gpsplot.

EXEMPLES

Génère un nuage de points de Latitude, Longitude et Altitude au-dessus du niveau moyen de la mer (altMSL). Arrête après 60 secondes :

gpsplot --seconds 60 --fields llm

Génère un graphique linéaire de Latitude, Longitude et Hauteur au-dessus de l'ellipsoïde (altHAE). Arrête après 60 fixations :

gpsplot --count 60 --plottype stripchart

Utilise le backend WXAgg pour répéter la dernière expérience afin de voir si elle est plus rapide ou plus esthétique.

export MPLBACKEND=WX
gpsplot --count 60 --plottype stripchart

Génère localement un nuage de points de Latitude, Longitude et altMSL à partir d'une instance gpsd distante sur l'hôte « example.com » et le périphérique distant « /dev/ttyS0 ». Collecte 60 fixations, arrête, enregistre le tracé sous le nom « save.jpg » et quitte :

gpsplot --count 60 --exit --fields llm --image save.jpg example.com::/dev/ttyS0

VALEURS DE RETOUR

0

en cas de succès.

1

en cas d'échec
