NOM

gpvc - Visionneuse de fichiers COD GNU PIC

SYNTAXE

gpvc [options] fichier

AVERTISSEMENT

Les informations contenues dans cette page de manuel sont un extrait de la documentation complète de gputils et sont limitées à la signification des options. Pour une documentation complète et actuelle, référez-vous à "gputils.ps" situé dans le répertoire de documentation de gputils.

DESCRIPTION

gpvc est une visionneuse de fichiers COD pour les microcontrôleurs PIC (TM) de Microchip (TM). Les fichiers COD sont une sortie de gpasm. Ils contiennent des informations utilisées pour la simulation. gpvc fait partie de gputils. Consultez la page de manuel de gputils(1) pour plus de détails sur les autres utilitaires GNU PIC.

OPTIONS

-a,--tout
Affiche toutes les informations du fichier COD.
-d,--repertoire
Affiche l'en-tête du répertoire.
-l,--listage
Affiche le listage de la source.
-m,--message
Affiche la zone de message de débogage.
-h, --aide
Affiche le message d'utilisation et quitte.
-r,--rom
Affiche la ROM.
-s,--symboles
Affiche les symboles.
-v,--version
Affiche les informations de version et quitte.
-w, --large
Affiche le tableau de code en vue plus large.
