NOM

gputils - Outils GNU pour PIC

DESCRIPTION

gputils est une collection d'outils de développement pour les microcontrôleurs Microchip (TM) PIC (TM). Il est conçu pour être compatible avec les outils du fabricant, MPASM, MPLINK et MPLIB.

VOIR AUSSI

gpasm(1), gpdasm(1), gplib(1), gplink(1), gpstrip(1), gpvc(1), gpvo(1)
