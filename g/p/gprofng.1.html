    gprofng(1) - Pages de manuel Arch Linux

    SYNOPSIS

    gprofng [OPTIONS] [[--] inputfile]

    DESCRIPTION

    gprofng est une implémentation C++ de GNU gprof. Il est conçu pour remplacer et améliorer l'implémentation originale de gprof. Il utilise des informations de profilage de bas niveau (par exemple, les informations de débogage DWARF) pour reconstruire les informations de profilage, plutôt que de se fier à des interruptions de comptage d'horodatage ou de comptage de blocs. Cela permet une analyse de profilage beaucoup plus précise et détaillée.

    OPTIONS

    Le programme accepte les options suivantes :

    • -b, --brief : Affiche la sortie dans un format plus concis, en omettant les détails de chaque appel de fonction.
    • -c, --cycle-report : Génère un rapport de cycles de fonctions.
    • -d, --debug : Affiche des informations de débogage pendant l'exécution.
    • -e FUNCTION, --exclude FUNCTION : Exclut la fonction spécifiée du rapport.
    • -f FUNCTION, --function FUNCTION : Inclut uniquement la fonction spécifiée dans le rapport.
    • -h, --help : Affiche un message d'aide et quitte.
    • -i, --annotated-source : Génère une sortie de code source annotée.
    • -k FUNCTION, --keep FUNCTION : Ne pas exclure la fonction spécifiée, même si elle correspond à un motif d'exclusion.
    • -l, --line-info : Inclut des informations sur les lignes de code dans le rapport.
    • -n, --no-file-paths : N'affiche pas les chemins complets des fichiers source.
    • -p, --flat-profile : Affiche un profilage plat (pas de hiérarchie d'appels).
    • -r, --residual-graph : Affiche le graphe résiduel.
    • -s, --summary-only : Affiche uniquement le résumé du profilage.
    • -t, --traditional : Utilise le format de sortie traditionnel de gprof.
    • -V, --version : Affiche les informations de version et quitte.
    • -W FUNCTION, --whiny-functions FUNCTION : Affiche un avertissement si la fonction spécifiée n'est pas trouvée.
    • --sort ORDER : Trie la sortie selon le critère spécifié (par exemple, name, calls, time).

    inputfile est le fichier d'informations de profilage généré par votre programme compilé avec les options de profilage appropriées (généralement -pg ou des options spécifiques à DWARF).

    ENVIRONNEMENT

    Aucune variable d'environnement spécifique n'est documentée pour gprofng.

    NOTES

    Pour que gprofng fonctionne, votre programme doit être compilé avec les options de profilage appropriées. Pour les exécutables traditionnels, utilisez l'option -pg lors de la compilation et de la liaison. Pour une précision maximale, en particulier avec les compilateurs modernes et les informations DWARF, vous pourriez avoir besoin d'options de compilation spécifiques pour générer des informations de profilage détaillées.
