NOM

gpgrt-config - Script utilitaire pour obtenir des informations sur la version installée des bibliothèques gpg

SYNTAXE

gpgrt-config [options] [ module ]

DESCRIPTION

gpgrt-config est un outil script utilisé par les macros autoconf fournies avec les logiciels gnupg (par exemple, AM_PATH_GPG_ERROR et AM_PATH_GPGME) pour déterminer les indicateurs du compilateur et de l'éditeur de liens qui devraient être utilisés pour compiler et lier les programmes qui utilisent la bibliothèque spécifique (par exemple, libgpg-error ou libgpgme). gpgrt-config utilise les fichiers .pc de pkg-config comme source de données.

En plus des options, gpgrt-config accepte un seul argument module spécifiant le nom de base (sans le suffixe « .pc ») du fichier pkg-config à utiliser comme entrée. module sera gpg-error par défaut s'il n'est pas spécifié.

OPTIONS

gpgrt-config accepte les options suivantes :

--libdir=LIBDIR
Chemin du répertoire parent du chemin de recherche des fichiers pkgconfig. Par exemple, « gpgrt-config --libdir=/usr/lib --exists gpgme » analysera « /usr/lib/pkgconfig/gpgme.pc ».
--exists
Vérifie si le fichier pkg-config « module.pc » existe et se termine avec succès ou erreur en conséquence.
--modversion
Affiche la version actuellement installée de module sur la sortie standard.
--libs
Affiche les indicateurs de l'éditeur de liens nécessaires pour lier un programme utilisant le module.
--cflags
Affiche les indicateurs du compilateur nécessaires pour compiler un programme utilisant le module.
--static
Modifie la sortie si l'on lie statiquement au lieu de dynamiquement.
--variable=VARNAME
Affiche la variable VARNAME du fichier pkg-config du module.

BOGUES

gpgrt-config essaie d'être compatible avec pkg-config et de bien supporter la compilation croisée, mais il n'est pas destiné à être un remplacement.
