GPG-TUI(1) Manuel des commandes générales GPG-TUI(1)

NOM

gpg-tui - gérez vos clés GnuPG en toute simplicité

SYNTAXE

gpg-tui [OPTIONS]

DESCRIPTION

gpg-tui est une interface utilisateur en terminal pour GnuPG.

Il vise à simplifier les opérations de gestion de clés telles que l'exportation/signature en fournissant une interface avec un repli en ligne de commande pour les opérations plus complexes. Il n'essaie pas d'être une interface complète pour toutes les fonctionnalités que gpg propose, mais tente d'apporter une approche plus interactive à la gestion des clés.

OPTIONS

-a, --armor
Active la sortie ASCII blindée
--splash
Affiche l'écran de démarrage au lancement
--config <chemin>
Définit le fichier de configuration [env: GPG_TUI_CONFIG=]
--homedir <rép>
Définit le répertoire personnel GnuPG [env: GNUPGHOME=]
-o, --outdir <rép>
Définit le répertoire de sortie [env: OUTDIR=]
--outfile <chemin>
Définit le modèle pour le nom du fichier de sortie [env: OUTFILE=]
-d, --default-key <clé>
Définit la clé par défaut pour la signature [env: DEFAULT_KEY=]
-t, --tick-rate <ms>
Définit le taux de rafraîchissement du terminal [env: TICK_RATE=] [défaut: 250]
-c, --color <couleur>
Définit la couleur d'accentuation du terminal [env: COLOR=] [défaut: gray]
-s, --style <style>
Définit le style du terminal [env: STYLE=] [défaut: colored] [valeurs possibles : plain, colored]
-f, --file-explorer <app>
Définit l'utilitaire pour la sélection de fichiers [env: FILE_EXPLORER=] [défaut: xplr]
--detail-level <niveau>
Définit le niveau de détail pour les clés [env: DETAIL_LEVEL=] [défaut: minimum] [valeurs possibles : minimum, standard, full]
--log-file <chemin>
Définit le fichier où enregistrer les logs [env: LOG_FILE=]
--select <option>
Active le mode de sélection [env: SELECT=] [valeurs possibles : key_id, key_fpr, user_id, row1, row2]
-h, --help
Imprime les informations d'aide
-V, --version
Imprime les informations de version
