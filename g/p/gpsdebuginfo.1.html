NOM

gpsdebuginfo - Génère un vidage de débogage gpsd de votre hôte.

SYNTAXE

gpsdebuginfo

DESCRIPTION

gpsdebuginfo est un script shell pour exécuter une série de tests courts afin de voir l'état de gpsd sur votre machine. Exécutez-le et envoyez la sortie complète, sans modification, lorsque vous demandez de l'aide.

Le script ne devrait pas collecter d'informations personnellement identifiables (PII). Vous voudrez peut-être étudier la sortie avant de l'envoyer pour vous en assurer.

gpsdebuginfo doit être exécuté en tant que root. Il peut être exécuté en tant qu'utilisateur normal, mais avec une perte de fonctionnalité. L'exécution sous sudo peut entraîner des résultats trompeurs.

OPTIONS

Aucune.

ENVIRONNEMENT

Ce script dépend des variables d'environnement suivantes :

PATH

Pour trouver gpsd, gpspipe, et d'autres composants gpsd installés.

PYTHONPATH

Pour trouver le module Python gps.

VALEURS DE RETOUR

0

En cas de succès.

VOIR AUSSI

gpsd(8), cgps(1), gps(1), gpspipe(1)
