NOM

gpsdctl - outil pour envoyer des commandes à gpsd via son socket de contrôle

SYNTAXE

gpsdctl action périphérique

OPTIONS

action

peut être add ou remove. Si aucune instance du démon n'est en cours d'exécution lors d'une demande add, ce programme en lancera une.

périphérique

l'argument doit être le chemin d'accès d'un périphérique. Le périphérique sera ouvert par gpsd pour lire les données du capteur.

DESCRIPTION

Ceci est un outil pour envoyer des commandes d'une instance de gpsd via son socket de contrôle pour ajouter ou supprimer des périphériques de la liste de périphériques du démon. Il n'est pas destiné à être appelé par les utilisateurs, mais plutôt par le système hotplug de Linux et des installations similaires.

ENVIRONNEMENT

Deux variables d'environnement sont interprétées.

GPSD_SOCKET

définit l'emplacement du socket de contrôle. Si l'ID utilisateur effectif de ce programme est root, il utilise généralement /run/gpsd.sock, bien que certains systèmes puissent utiliser le /var/run/gpsd.sock déprécié à la place. Les utilisateurs non-root utiliseront /tmp/gpsd.sock.

GPSD_OPTIONS

peut être une liste d'options à passer à gpsd lorsque cet outil le lance. Elle est par défaut une chaîne vide.

VALEURS DE RETOUR

0

en cas de succès.

1

si l'action était inconnue ou si l'écriture sur le socket de contrôle a échoué,
