NOM

gplink - éditeur de liens GNU PIC

SYNTAXE

gplink [options] [objets] [bibliothèques]

AVERTISSEMENT

Les informations contenues dans cette page de manuel sont un extrait de la documentation complète de gputils et sont limitées à la signification des options. Pour une documentation complète et à jour, veuillez vous référer à "gputils.ps" situé dans le répertoire docs de gputils.

DESCRIPTION

gplink combine un certain nombre de fichiers objets et d'archives, relocalise leurs données et résout leurs références de symboles. Il génère un exécutable pour les microcontrôleurs Microchip (TM) PIC (TM). gplink fait partie de gputils. Consultez la page de manuel gputils(1) pour plus de détails sur les autres utilitaires GNU PIC.

OPTIONS

-a FMT, --hex-format FMT
gplink prend en charge les formats de fichiers hexadécimaux inhx8m, inhx8s, inhx16 et inhx32. Cette option contrôle le format de fichier hexadécimal utilisé. La valeur par défaut est inhx32.
-b OPT, --optimize-banksel OPT
Supprime les directives Banksel inutiles. [0]
-B, --experimental-banksel
Utilise la suppression expérimentale de Banksel.
-c, --object
Génère un objet exécutable.
-C, --no-cinit-warnings
Désactive les avertissements concernant la section _cinit avec l'option -O2 : "Relocation symbol _cinit has no section."
-d, --debug
Affiche les messages de débogage.
-f VALUE, --fill VALUE
Remplit la mémoire programme inutilisée et non protégée avec la valeur spécifiée. La valeur remplace la valeur de remplissage du script de l'éditeur de liens. La valeur ne doit pas être supérieure à 0xffff. La valeur est en hexadécimal. La valeur peut être précédée de "0x".
-h, --help
Affiche le message d'utilisation et quitte.
-I DIR, --include DIR
Spécifie le répertoire d'inclusion.
-j, --no-save-local
Désactive la sauvegarde des registres locaux dans le fichier COD.
-l, --no-list
Désactive la sortie du fichier liste.
-m, --map
Génère un fichier de mappage.
--mplink-compatible
Cette option active le mode de compatibilité MPLINK.
-o FILE, --output FILE
Nom alternatif du fichier de sortie.
-O OPT, --optimize OPT
Niveau d'optimisation. La valeur par défaut est 1.
-p OPT, --optimize-pagesel OPT
Supprime les directives Pagesel inutiles. [0]
-P, --experimental-pagesel
Utilise la suppression expérimentale de Pagesel.
-q, --quiet
Supprime tout ce qui est envoyé à la sortie standard.
-r, --use-shared
Tente de relocaliser les sections de données non partagées en mémoire partagée si la relocalisation échoue.
-s FILE, --script FILE
Script de l'éditeur de liens.
-t SIZE, --stack SIZE
Crée une section de pile.
-S [0|1|2], --strict [0|1|2]
Définit le niveau de stricte pour les symboles manquants. 0 : C'est la valeur par défaut. Aucun message. 1 : Affiche un message d'avertissement s'il y a un symbole manquant. 2 : Affiche un message d'erreur s'il y a un symbole manquant.
--strict-options
Si cette option est définie, une option ne peut pas être le paramètre d'une autre option. Par exemple : -s --quiet
-u, --macro symbol=[value]
Ajoute une valeur macro pour le script.
-v, --version
Affiche les informations de version et quitte.
-w, --processor-mismatch
Désactive l'avertissement "processor mismatch".
-W, --experimental-pcallw
Supprime les stubs PCALLW inutiles créés par SDCC.
