NOM

gpg-key2ps - génère un fichier PS à partir d'un trousseau GnuPG

SYNTAXE

gpg-key2ps [-r style-révoqué] [-p format-papier] [-1] [-s] id-clé-ou-nom [ ... ]

DESCRIPTION

gpg-key2ps génère un fichier PostScript avec l'empreinte de votre clé OpenPGP (répétée autant de fois qu'elle rentre), utile pour les soirées de signature de clés. Le seul argument est le même que celui que vous passeriez à la commande list-keys de GPG, soit un id de clé, soit un nom (partiel). Les données PS sont écrites sur la sortie standard.

OPTIONS

-p --format-papier format-papier
Sélectionne le format du papier de sortie. Par défaut, regarde dans /etc/papersize ou A4 si libpaper n'est pas installé.
-s --montrer-sous-clés
Active l'impression des informations de sous-clés sur les tickets. Les informations de sous-clés ne sont normalement pas pertinentes pour le processus de signature de clés.
-r --style-révoqué style-révoqué
Sélectionne comment marquer les UID et sous-clés révoqués. Cinq styles sont disponibles :
cacher ne pas montrer du tout (par défaut),
montrer montrer normalement,
gris afficher en 50% de gris,
noter ajouter "[révoqué]", et
barrer barrer.
-1
Imprimer une seule colonne de tickets au lieu des deux par défaut. Utile pour les clés avec des UID longs qui ne rentreraient pas autrement.
id-clé
Id de clé(s) à imprimer. Plusieurs peuvent être séparés par des espaces.
-h --aide
Imprimer l'aide et quitter.
-v --version
Imprimer la version et quitter.

ENVIRONNEMENT

HOME
Le répertoire personnel par défaut.
GNUPGBIN
Le binaire gpg. Par défaut : "gpg".
GNUPGHOME
Le répertoire de travail par défaut pour gpg. Par défaut : "$HOME/.gnupg".
