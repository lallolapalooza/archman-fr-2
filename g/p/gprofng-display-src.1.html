GPROFNG-DISPLAY-SRC(1) Commandes utilisateur GPROFNG-DISPLAY-SRC(1)

NOM

gprofng-display-src - Affiche le code source et éventuellement le désassemblage de l'objet cible

SYNTAXE

gprofng display src [option(s)] fichier-cible

DESCRIPTION

Affiche la liste du code source, ou le code source entrelacé avec le code de désassemblage, tel qu'extrait du fichier cible (un exécutable, une bibliothèque partagée, un fichier objet ou un fichier Java .class).

Par exemple, cette commande affiche le code source et la liste de désassemblage d'une fonction nommée mxv_core qui fait partie du fichier objet mxv.o :

$ gprofng display src -disasm mxv_core mxv.o

Pour lister le code source et le désassemblage de toutes les fonctions de ce fichier, utilisez la commande suivante :

$ gprofng display src -disasm all -1 mxv.o

Le fichier-cible est le nom d'un exécutable, d'une bibliothèque partagée, d'un fichier objet (.o) ou d'un fichier Java .class.

Si aucune option n'est fournie, la liste du code source du fichier-cible est affichée. Ceci est équivalent à -source all -1. Si ces informations ne sont pas disponibles, un message à ce sujet est imprimé.

OPTIONS

--version
Affiche le numéro de version et quitte.
--help
Affiche les informations d'utilisation et quitte.
-functions
Liste toutes les fonctions de l'objet donné.
-source element tag
Affiche le code source de l'element dans fichier-cible. Le tag est utilisé pour différencier les occurrences multiples portant le même nom. Voir la section NOTES pour la définition de element et tag.
-disasm element tag
Inclut le désassemblage dans la liste source. La liste par défaut n'inclut pas le désassemblage. Si le code source n'est pas disponible, affiche uniquement une liste de désassemblage. Voir la section NOTES pour la définition de element et tag.
-outfile nomfichier
Écrit les résultats dans le fichier nomfichier. Un trait d'union (-) écrit sur la sortie standard. C'est également le comportement par défaut. Notez que cette option n'affecte que les options incluses à droite de l'option.

NOTES

Utilisez element pour spécifier le nom d'une fonction, ou d'un fichier source ou objet utilisé pour construire l'exécutable ou la bibliothèque partagée.

Le tag est un index utilisé pour déterminer quel élément est référencé lorsque plusieurs fonctions portent le même nom. Il est requis, mais sera ignoré s'il n'est pas nécessaire pour résoudre la fonction.

L'element peut également être spécifié sous la forme fonction`fichier`, auquel cas le code source ou le désassemblage de la fonction nommée dans le contexte source du fichier nommé sera utilisé.

La combinaison spéciale element et tag all -1, est utilisée pour indiquer la génération de la source, ou du désassemblage, pour toutes les fonctions du fichier-cible.
