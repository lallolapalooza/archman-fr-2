NOM

gmk_msh - créer un graphe source à partir d'un maillage source

SYNTAXE

gmk_msh [options] [mfile] [gfile]

DESCRIPTION

Le programme gmk_msh crée un graphe source à partir d'un maillage source. Les sommets du graphe sont les nœuds du maillage, et tous les éléments du maillage sont transformés en cliques, c'est-à-dire qu'il existe une arête entre deux sommets du graphe s'il existe au moins un élément dans le maillage qui comprend les deux nœuds associés.

OPTIONS

-h
Affiche une aide.
-V
Affiche la version du programme et le copyright.

EXEMPLE

Créer un graphe source brol.grf à partir d'un maillage source brol.msh:

    $ gmk_msh brol.msh brol.grf
