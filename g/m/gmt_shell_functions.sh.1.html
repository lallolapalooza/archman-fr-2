NOM

gmt_shell_functions.sh - Fonctions pratiques à utiliser dans des scripts shell Bourne pour GMT

SYNOPSIS

gmt_init_tmpdir

gmt_remove_tmpdir

gmt_clean_up [ préfixe ]

gmt_message message

gmt_abort message

gmt_build_movie [ -d répertoire ] [ -n ] [ -r framerate ] [ -v ] namestem

gmt_build_gif [ -d répertoire ] [ -l loop ] [ -r delay ] namestem

gmt_build_kmz -p prefix [ -r ] files

gmt_get_nrecords file(s)

gmt_get_ndatarecords file(s)

gmt_get_nfields string

gmt_get_field string

gmt_get_region file(s) [ options ]

gmt_get_gridregion file [ options ]

gmt_get_map_width -R -J

gmt_get_map_height -R -J

gmt_movie_script [ -c canvas OU -e dpi -h height -w width ] [ -f format ]
[ -g fill ] [ -n frames ] [ -m margin ] [ -r rate ] namestem

gmt_launch_jobs [ -c n_cores ] [ -l nlines_per_cluster ] [ -n ] [ -v ] [ -w ] commandfile

gmt_set_psfile scriptfile

gmt_set_pdffile scriptfile

gmt_set_framename prefix framenumber

gmt_set_framenext framenumber

DESCRIPTION

gmt_shell_functions.sh fournit un ensemble de fonctions pour les scripts shell Bourne (Again) en support de GMT. Le script shell appelant doit inclure la ligne suivante avant que les fonctions puissent être utilisées :

. gmt_shell_functions.sh

Une fois inclus dans un script shell, gmt_shell_functions.sh permet aux utilisateurs de GMT de faire du scripting plus facilement que par d'autres moyens. Les fonctions disponibles sont :

gmt_init_tmpdir
Crée un répertoire temporaire dans /tmp ou (lorsqu'il est défini) dans le répertoire spécifié par la variable d'environnement TMPDIR. Le nom du répertoire temporaire est renvoyé en tant que variable d'environnement GMT_TMPDIR. Cette fonction fait également fonctionner GMT en « mode isolation », c'est-à-dire que tous les fichiers temporaires seront créés dans GMT_TMPDIR et le fichier gmt.conf ne sera pas ajusté.
gmt_remove_tmpdir
Supprime le répertoire temporaire et désaffecte la variable d'environnement GMT_TMPDIR .
gmt_cleanup
Supprime tous les fichiers et répertoires dont le nom contient le numéro de processus courant. Si le préfixe facultatif est fourni, nous supprimons également tous les fichiers et répertoires commençant par le préfixe donné.
gmt_message
Envoie un message vers la sortie d'erreur standard.
gmt_abort
Envoie un message vers la sortie d'erreur standard et quitte le shell.
gmt_get_nrecords
Retourne le nombre total de lignes dans file(s)
gmt_get_ndatarecords
Retourne le nombre total d'enregistrements de données dans file(s), c'est-à-dire sans compter les en-têtes.
gmt_get_nfields
Retourne le nombre de champs ou de mots dans string
gmt_get_field
Retourne le champ donné dans une chaîne. La chaîne doit être passée entre guillemets doubles pour la préserver comme un seul élément.
gmt_get_region
Retourne la région sous la forme ou/est/sud/nord basée sur les données du tableau file(s). Ajoutez éventuellement -Idx/dy pour arrondir la réponse.
gmt_get_gridregion
Retourne la région sous la forme ou/est/sud/nord basée sur l'en-tête d'un fichier grille. Ajoutez éventuellement -Idx/dy pour arrondir la réponse.
gmt_get_map_width
Attend que l'utilisateur donne les paramètres -R -J souhaités et retourne la largeur de la carte dans l'unité de mesure courante.
gmt_get_map_height
Attend que l'utilisateur donne les paramètres -R -J souhaités et retourne la hauteur de la carte dans l'unité de mesure courante.
gmt_movie_script
Crée un modèle de script bash d'animation basé sur les arguments qui définissent la taille, le nombre de cadres, le format vidéo, etc. Sans arguments, la fonction affichera son utilisation.
gmt_launch_jobs
Prend un fichier contenant une longue liste de commandes et les divise en plusieurs morceaux qui peuvent être exécutés simultanément. Sans arguments, la fonction affichera son utilisation. Remarque: Il est de votre responsabilité de vous assurer qu'aucune condition de course ne se produit (c'est-à-dire plusieurs commandes écrivant dans le même fichier).
gmt_set_psfile
Crée le nom du fichier PostScript de sortie basé sur le nom de base d'un fichier donné (généralement le nom du script $0).
gmt_set_framename
Retourne une base de nom de fichier triée lexicalement (c'est-à-dire sans extension) étant donné le préfixe du fichier et le numéro de cadre courant, en utilisant une largeur de 6 pour l'entier, y compris les zéros de tête. Utile lors de la création d'animations lorsque des noms de fichiers triés lexicalement sont requis.
gmt_set_framenext
Accepte le compteur entier du cadre courant et retourne le compteur entier suivant.
gmt_build_movie
Accepte un namestem qui donne le préfixe d'une série de fichiers image avec les noms dir/namestem_*.*. Les arguments facultatifs définissent le répertoire [identique à namestem ] et la fréquence d'images [24]. Sans arguments, la fonction affichera son utilisation.
gmt_build_gif
Accepte un namestem qui donne le préfixe d'une série de fichiers image avec les noms dir/namestem_*.*. Les arguments facultatifs définissent le répertoire [identique à namestem], le nombre de boucles et la fréquence d'images [24]. Sans arguments, la fonction affichera son utilisation.
gmt_build_kmz
Accepte -p prefix [ -r ] et un nombre quelconque de fichiers KML et des images auxquels ils peuvent faire référence, et construit un fichier KMZ unique nommé prefix.kmz. Sans arguments, la fonction affichera son utilisation.

NOTES

1. Ces fonctions ne fonctionnent que dans le shell Bourne (sh) et ses dérivés (comme ash, bash, ksh et zsh). Ces fonctions ne fonctionnent pas dans le shell C (csh) ou ses dérivés (comme tcsh), et ne peuvent pas non plus être utilisées dans des scripts batch DOS.

2. gmt_shell_functions.sh ont été introduits pour la première fois dans la version 4.2.2 de GMT et ont depuis été régulièrement étendus avec d'autres raccourcis de scripting pratiques. Si vous souhaitez suggérer d'autres fonctions, veuillez le faire en ajoutant une demande de Nouveau problème (New Issue) sur https://github.com/GenericMappingTools/gmt.

NAME

gmt_shell_functions.sh — GMT shell functions

SYNOPSIS

Source this file (e.g. source gmt_shell_functions.sh) to make the following shell functions available:

    gmt
    gmt_config
    gmt_shell_functions_help

DESCRIPTION

This file contains a few shell functions that may be useful when working with the Generic Mapping Tools (GMT). The main functions are:

gmt
This is a wrapper function that invokes the GMT program.
gmt_config
This function displays various GMT configuration parameters. It is equivalent to running gmt.conf -show=all, but it also displays the shell environment variables that affect GMT's behavior.
gmt_shell_functions_help
This function displays help information about the functions provided in this file.

To use these functions, you need to source this file into your current shell environment. For example, in bash or zsh, you would type:

    source /path/to/gmt_shell_functions.sh

After sourcing, you can use the functions directly, e.g.:

    gmt --version
    gmt_config
    gmt_shell_functions_help

Note that these functions are primarily intended for use in shell scripts or interactive sessions. They are not part of the core GMT executable and do not provide additional functionality beyond what is already available through the standard GMT command-line interface.

NOTES

The behavior of the gmt wrapper function is the same as calling the gmt executable directly. It simply invokes gmt with the given arguments.

The gmt_config function is useful for debugging and understanding how GMT is configured in your environment. It combines information from the GMT configuration file (gmt.conf) and relevant environment variables.

The gmt_shell_functions_help function provides a convenient way to get information about the available shell functions without having to manually inspect the script file.
