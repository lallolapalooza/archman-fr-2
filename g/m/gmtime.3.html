(time_t) -1 peut représenter un temps valide (une seconde avant l'Epoch). Pour déterminer si mktime() a échoué, on doit utiliser le champ tm->tm_wday. Voir le programme d'exemple dans

Le traitement d'un tm_isdst non négatif dans mktime() est mal spécifié, et passer une valeur incorrecte pour le temps spécifié produit des résultats indépendants. Puisque mktime() est l'une des rares fonctions qui savent quand l'heure d'été est en vigueur, fournir une valeur correcte peut être difficile. Un contournement consiste à appeler mktime() deux fois, une fois avec tm_isdst défini à zéro, et une fois avec tm_isdst défini à une valeur positive, et en ignorant les résultats de l'appel qui le modifie. Si aucun des appels ne modifie tm_isdst, alors le temps spécifié se produit probablement pendant une période de retour en arrière où l'heure d'été commence ou se termine, et les deux résultats sont valides mais représentent deux temps différents. Si les deux appels le modifient, cela pourrait indiquer une transition en avant, ou une autre raison pour laquelle le temps spécifié n'existe

pas.

La spécification des fuseaux horaires et de l'heure d'été est laissée aux gouvernements régionaux, change souvent, et peut inclure des discontinuités au-delà de la capacité de mktime à documenter un résultat. Par exemple, un changement dans la définition du f

useau horaire peut provoquer la répétition
ou l'omission d'une heure d'horloge sans
changement correspondant de l'heure d'été.

c 
#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return
t;
}

    SYNOPSIS

    #include <time.h>

struct tm *gmtime(const time_t *timep);

struct tm *gmtime_r(const time_t *timep, struct tm *result);

    DESCRIPTION

    La fonction gmtime convertit la valeur de temps timep (qui pointe vers un objet de type time_t) en une structure tm représentant l'heure locale UTC (Temps Universel Coordonné).

    La structure tm est définie dans <time.h> et contient les champs suivants :

    • tm_sec : secondes après la minute (0 à 60)
    • tm_min : minutes après l'heure (0 à 59)
    • tm_hour : heures après minuit (0 à 23)
    • tm_mday : jour du mois (1 à 31)
    • tm_mon : mois depuis le début de l'année (0 à 11)
    • tm_year : années depuis 1900
    • tm_wday : jour de la semaine depuis le dimanche (0 à 6)
    • tm_yday : jour de l'année depuis le 1er janvier (0 à 365)
    • tm_isdst : indicateur d'heure d'été (ne sera jamais utilisé par gmtime, toujours 0)

    La fonction gmtime_r est une version réentrante de gmtime. Elle stocke le résultat dans la structure fournie par result au lieu d'utiliser une structure statique interne. Cela rend gmtime_r plus sûre à utiliser dans des environnements multithreadés.

    VALEUR DE RETOUR

    Au succès, gmtime renvoie un pointeur vers la structure tm représentant le temps UTC. Cette structure peut être réutilisée par d'autres appels à des fonctions de conversion de temps, il faut donc copier les données si elles doivent être conservées.

    Au succès, gmtime_r renvoie un pointeur vers la structure result fournie.

    En cas d'erreur, les deux fonctions renvoient NULL.

    ERREURS

    La documentation POSIX indique que gmtime et gmtime_r ne doivent pas définir errno. Cependant, des implémentations peuvent définir errno à EOVERFLOW si le temps est trop grand ou trop petit pour être représenté.

    NORMES

    La fonction gmtime est décrite dans la norme POSIX.1-2008. La fonction gmtime_r est également décrite dans POSIX.1-2008.

    HISTORIQUE

    Les fonctions gmtime et gmtime_r sont disponibles depuis les premières versions de Unix.

    AVERTISSEMENTS

    La fonction gmtime utilise une structure statique interne pour stocker le résultat. Cela signifie que les appels successifs à gmtime peuvent écraser les résultats des appels précédents. Si vous avez besoin de conserver le résultat, copiez-le dans une autre structure. Pour des raisons de sécurité dans les environnements multithreadés, il est préférable d'utiliser gmtime_r.

    Le champ tm_isdst est toujours défini à 0 par gmtime car l'heure UTC n'observe pas l'heure d'été.

    EXEMPLES

    #include <stdio.h>
#include <time.h>

int main() {
    time_t t = time(NULL); // Obtenir le temps actuel
    struct tm *data;

    data = gmtime(&t);
    if (data == NULL) {
        perror("gmtime");
        return 1;
    }

    printf("Temps UTC actuel : %02d/%02d/%d %02d:%02d:%02d\n",
           data->tm_mday, data->tm_mon + 1, data->tm_year + 1900,
           data->tm_hour, data->tm_min, data->tm_sec);

    // Exemple avec gmtime_r
    struct tm result;
    if (gmtime_r(&t, &result) == NULL) {
        perror("gmtime_r");
        return 1;
    }

    printf("Temps UTC actuel (gmtime_r) : %02d/%02d/%d %02d:%02d:%02d\n",
           result.tm_mday, result.tm_mon + 1, result.tm_year + 1900,
           result.tm_hour, result.tm_min, result.tm_sec);

    return 0;
}
