N

gmtswitch vous aide à modifier votre environnement pour permettre la permutation entre plusieurs versions de GMT installées. Il fonctionne en maintenant une liste des répertoires des installations de GMT dans un fichier de votr

ATTENTIO

N

GMT se souvient où il a été installé la première fois et utilise ce répertoire pour trouver le répertoire de partage GMT par défau

t. Si vous déplacez toute l'installation GMT après la compilation, vous devrez peut-être définir GMT_SHAREDIR pour qu'il pointe
vers le répertoire principal afin que les choses fonctionnent. Il vaut mieux ne pas déplacer les choses après l'installation.

WINDOW

S

Sous Windows, utilisez gmtswitch.bat qui est un script batch qui modifie la variable PATH Windows afin que le répertoire BIN de la version préférée soit toujours en premier. Pour cela, le batch fonctionne dans deux modes alternatifs

:

1 - Mode

permanent

2 - Mode

temporaire

Le mode permanent utilise le programme exécutable gratuit "EditPath" pour modifier le chemin utilisateur dans le registre. C'est appelé permanent car les changements persistent jusqu'à ... la prochaine modification.

Voir

https://www.softpedia.com/get/Tweak/Registry-Tweak/EditPath.

shtml

Bien sûr, le binaire editpath.exe doit également être dans le chemin de votre système. AVERTISSEMENT : Le changement de chemin ne sera pas visible sur le shell cmd où il a été exécuté. Pour que le changement soit actif, vous devrez ouvrir une nouvelle fenêtre

cmd.

Le second mode est temporaire car le chemin vers le répertoire binaire GMT sélectionné est ajouté en tête du chemin précédent via une ligne de commande shell. Cette modification disparaît lorsque la fenêtre shell cmd où elle a été exécutée est

fermée.

Il est de la responsabilité de l'utilisateur de définir le contenu de G32_32 à G5_64 ci-dessous vers des chemins valides où les binaires des différentes versions GMT sont installés. Notez qu'il n'est pas obligatoire d'avoir les quatre sur votre ordinateur. Pour ceux que vous n'avez pas, laissez-les simplement pointer vers rien, par ex.

,

set

G4_64=

Le mode permanent est celui par défaut (mais cela peut être changé. Voir la section édition) Pour exécuter en mode temporaire, donnez simplement un second argument (peu importe

lequel)

Exemple d'utilisation pour définir un GMT5 64 bits en

permanent
