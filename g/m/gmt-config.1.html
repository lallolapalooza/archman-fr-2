NOM

gmt-config - Obtenir des informations sur l'installation de gmt

SYNTAXE

gmt-config [ options ]

DESCRIPTION

gmt-config est utilisé par les développeurs qui ont besoin de connaître des informations techniques sur l'installation actuelle de GMT, telles que les fichiers d'inclusion à fournir, le chemin vers la bibliothèque, et plus encore.

ARGUMENTS REQUIS

Aucun.

ARGUMENTS OPTIONNELS

--help
Afficher ce message d'aide et quitter.
--all
Afficher toutes les options.
--bits
Indique si la bibliothèque est construite en 32 ou 64 bits.
--cc
Le compilateur C utilisé.
--cflags
Les indicateurs de préprocesseur et du compilateur utilisés.
--datadir
Les répertoires de données de GMT.
--dataserver
L'URL du serveur de données distant de GMT.
--dcw
L'emplacement de la base de données DCW.
--dep-libs
Les bibliothèques dépendantes.
--gshhg
L'emplacement de la base de données GSHHG.
--has-fftw
Indique si FFTW est utilisé dans la construction.
--has-pcre
Indique si PCRE est utilisé dans la construction.
--has-lapack
Indique si LAPACK est utilisé dans la construction.
--has-openmp
Indique si GMT a été construit avec le support d'OpenMP.
--includedir
Le répertoire d'inclusion.
--libdir
Le répertoire de la bibliothèque.
--libs
Les informations de liaison de la bibliothèque.
--plugindir
Le répertoire des plugins de GMT.
--prefix
Le préfixe d'installation.
--version
La version de la bibliothèque

EXEMPLES

Pour déterminer les indicateurs du compilateur nécessaires à un programme externe pour trouver les prototypes de fonctions GMT, essayez :

gmt-config --cflags
