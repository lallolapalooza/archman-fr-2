NOM

gdal-vsi-move - Déplacer/renommer un fichier/répertoire situé sur l'interface système virtuelle GDAL (VSI)

Ajouté dans la version 3.11.

SYNOPIS

Usage: gdal vsi move [OPTIONS] <SOURCE> <DESTINATION>
Déplace/renomme un fichier/répertoire situé sur l'interface système virtuelle GDAL (VSI).
Arguments positionnels :
  --source <SOURCE>            Nom du fichier ou répertoire source [requis]
  --destination <DESTINATION>  Nom du fichier ou répertoire de destination [requis]
Options courantes :
  -h, --help                   Affiche le message d'aide et quitte
  --json-usage                 Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>       Option de configuration [peut être répétée]
  -q, --quiet                  Mode silencieux (pas de barre de progression)

DESCRIPTION

gdal vsi move déplace les fichiers et répertoires situés sur les systèmes de fichiers virtuels GDAL (compressés, hébergés sur le réseau, etc.) : /vsimem, /vsizip, /vsitar, /vsicurl, ....

Si le chemin de destination est un répertoire existant, le fichier y sera déplacé.

Il peut déplacer des fichiers et des répertoires entre différents systèmes de fichiers virtuels, mais cela impliquera une copie et une suppression.

Notez que pour le stockage d'objets dans le cloud, le déplacement/renommage d'un répertoire peut impliquer le renommage récursif de tous les fichiers qu'il contient, et n'est donc pas une opération atomique (et peut être lent et coûteux pour les répertoires contenant de nombreux fichiers !)

Ceci est implémenté par VSIMove().

C'est l'équivalent de la commande UNIX mv, et gdal vsi mv est un alias pour gdal vsi move.

EXEMPLES

Exemple 1 : Renommer un fichier au sein du même système de fichiers virtuel

$ gdal vsi move /vsis3/bucket/my.tif /vsis3/bucket/new_name.tif

Exemple 2 : Déplacer un fichier dans un autre répertoire au sein du même système de fichiers virtuel

$ gdal vsi move /vsis3/bucket/my.tif /vsis3/bucket/existing_subdir

Exemple 3 : Déplacer un répertoire entre deux systèmes de fichiers virtuels différents

$ gdal vsi move /vsis3/bucket/my_directory /vsigs/bucket/
