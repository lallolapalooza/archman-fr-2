gdalmdiminfo(1)

Paquet: gdal

Licences: custom

GDALMDIMINFO(1) GDAL GDALMDIMINFO(1)

NOM

gdalmdiminfo - Rapporte la structure et le contenu d'un jeu de données multidimensionnel

SYNTAXE

Les paramètres de ligne de commande suivants peuvent apparaître dans n'importe quel ordre.

--help
Affiche ce message d'aide et quitte.
--help-general
Donne un bref message d'utilisation pour les options génériques de ligne de commande GDAL et quitte.
-detailed
Sortie la plus verbeuse. Rapport des types de données d'attributs et des valeurs de tableaux.
-nopretty
Sortie sur une seule ligne sans indentation.
-array <nom_tableau>
Nom du tableau utilisé pour restreindre la sortie au tableau spécifié.
-limit <nombre>
Nombre de valeurs dans chaque dimension utilisé pour limiter l'affichage des valeurs de tableaux. Par défaut, illimité. Prend seulement en compte si utilisé avec -detailed.
-oo <NOM>=<VALEUR>
Option d'ouverture du jeu de données (spécifique au format). Cette option peut être utilisée plusieurs fois.
-arrayoption <NOM>=<VALEUR>
Option passée à GDALGroup::GetMDArrayNames() pour filtrer les tableaux rapportés. Une telle option est spécifique au format. Consulter la documentation du pilote. Cette option peut être utilisée plusieurs fois.
-stats
Lit et affiche les statistiques du tableau. Force le calcul si aucune statistique n'est stockée dans un tableau.

Ajouté en version 3.2.

-if <format>
Nom du format/pilote à tenter pour ouvrir le(s) fichier(s) d'entrée. Il n'est généralement pas nécessaire de le spécifier, mais il peut être utilisé pour ignorer la détection automatique du pilote, lorsqu'elle échoue à sélectionner le pilote approprié. Cette option peut être répétée plusieurs fois pour spécifier plusieurs pilotes candidats. Notez qu'elle ne force pas ces pilotes à ouvrir le jeu de données. En particulier, certains pilotes ont des exigences sur les extensions de fichiers.

Ajouté en version 3.2.

API C

Cet utilitaire est également accessible depuis C avec GDALMultiDimInfo().

Exemple 2: Afficher des informations détaillées sur un tableau donné

$ gdalmdiminfo netcdf-4d.nc -array t -detailed -limit 3
