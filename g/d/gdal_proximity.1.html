NOM

gdal_proximity - Produit une carte de proximité raster.

SYNOPIS

gdal_proximity [--help] [--help-general]
                  <srcfile> <dstfile> [-srcband <n>] [-dstband <n>]
                  [-of <format>] [-co <name>=<value>]...
                  [-ot Byte/UInt16/UInt32/Float32/etc]
                  [-values <n>,<n>,<n>] [-distunits {PIXEL|GEO}]
                  [-maxdist <n>] [-nodata <n>] [-use_input_nodata {YES|NO}]
                  [-fixed-buf-val <n>]

DESCRIPTION

gdal_proximity génère une carte de proximité raster indiquant la distance entre le centre de chaque pixel et le centre du pixel le plus proche identifié comme pixel cible. Les pixels cibles sont ceux du raster source pour lesquels la valeur du pixel raster fait partie de l'ensemble des valeurs de pixels cibles.

NOTE :

gdal_proximity est un utilitaire Python et n'est disponible que si les liaisons Python de GDAL sont disponibles.
--help
Affiche ce message d'aide et quitte.
--help-general
Donne un bref message d'utilisation pour les options génériques de ligne de commande GDAL et quitte.
<srcfile>
Le fichier raster source utilisé pour identifier les pixels cibles.
<dstfile>
Le fichier raster de destination vers lequel la carte de proximité sera écrite. Il peut s'agir d'un fichier préexistant de la même taille que srcfile. S'il n'existe pas, il sera créé.
-srcband <n>
Identifie la bande du fichier source à utiliser (par défaut 1).
-dstband <n>
Identifie la bande du fichier de destination à utiliser (par défaut 1).
-of <format>
Sélectionne le format de sortie. Si non spécifié, le format est déduit de l'extension. Utilisez le nom court du format.
-co <NAME>=<VALUE>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler des détails sur le fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression et si le fichier doit être mosaïqué.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être affichée avec l'option de ligne de commande --format, mais la documentation du format est la source faisant autorité sur les options de création du pilote. Voir la documentation spécifique au format Pilotes raster pour connaître les options de création légales pour chaque format.

-ot <type>
Spécifie un type de données pris en charge par le pilote, qui peut être l'un des suivants : Byte, UInt16, Int16, UInt32, Int32, Float32 (par défaut), ou Float64.
-values <n>,<n>,<n>
Une liste de valeurs de pixels cibles dans l'image source à considérer comme pixels cibles. Si non spécifié, tous les pixels non nuls seront considérés comme pixels cibles.
-distunits {PIXEL|GEO}
Indique si les distances générées doivent être en coordonnées pixel ou géoréférencées (par défaut PIXEL).
-maxdist <n>
La distance maximale à générer. La valeur nodata sera utilisée pour les pixels au-delà de cette distance. Si une valeur nodata n'est pas fournie, la bande de sortie sera interrogée pour sa valeur nodata. Si la bande de sortie n'a pas de valeur nodata, la valeur 65535 sera utilisée. La distance est interprétée en pixels sauf si -distunits GEO est spécifié.
-nodata <n>
Spécifie une valeur nodata à utiliser pour le raster de proximité de destination.
-use_input_nodata {YES|NO}
Indique si les pixels nodata dans le raster d'entrée doivent être nodata dans le raster de sortie (par défaut NO).
-fixed-buf-val <n>
Spécifie une valeur à appliquer à tous les pixels qui se trouvent à la distance -maxdist des pixels cibles (y compris les pixels cibles) au lieu d'une valeur de distance.
