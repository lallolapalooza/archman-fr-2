NOM

gdal-dataset-copy - Copie les fichiers d'un jeu de données

Ajouté dans la version 3.12.

gdal dataset copy crée une copie du ou des fichiers du jeu de données, y compris les fichiers associés.

SYNOPSIS

Usage: gdal dataset copy [OPTIONS] <SOURCE> <DESTINATION>
Copie les fichiers d'un jeu de données.
Arguments positionnels :
  --source <SOURCE>            Nom du jeu de données source [requis]
  --destination <DESTINATION>  Nom du jeu de données de destination [requis]
Options communes :
  -h, --help                   Affiche le message d'aide et quitte
  --json-usage                 Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>       Option de configuration [peut être répétée]
Options :
  --overwrite                  Autorise l'écrasement du fichier de sortie existant
Options avancées :
  -f, --format <FORMAT>        Format du jeu de données

OPTIONS

--source <NOMFICHIER>
Nom du fichier ou du répertoire source. Requis.
--destination <NOMFICHIER>
Nom du fichier ou du répertoire de destination. Requis.
-f, ---format <FORMAT>
Format du jeu de données. Utile si la détection automatique ne fonctionne pas.
--overwrite
Permet au programme d'écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.

EXEMPLES

Exemple 1: Copier un jeu de données

$ gdal dataset copy source.tif destination.tif
