GDNSD-PLUGIN-NULL(8) gdnsd GDNSD-PLUGIN-NULL(8)

NOM

gdnsd-plugin-null - plugin null de gdnsd

SYNTAXE

Exemple de configuration des types de services null :

service_types => {
  my_null_mon => {
    plugin => null,
    # ... autres paramètres génériques de service_type
  }
}

RR de fichier de zone utilisant la résolution null :

foo 300 DYNA null
bar 300 DYNC null!whatever

DESCRIPTION

gdnsd-plugin-null existe principalement comme exemple du plugin minimum possible des deux types. C'est à la fois un plugin de surveillance et un plugin de résolution.

Lorsqu'il est utilisé comme plugin de résolution dans les RR "DNYA" ou "DYNC", il ignore tout nom de ressource fourni. Il retourne toujours l'adresse IPv4 0.0.0.0 et l'adresse IPv6 "::".

Lorsqu'il est utilisé comme plugin de surveillance en définissant un type de service comme indiqué dans l'exemple ci-dessus, il émule le comportement d'un vrai plugin de surveillance (mise à jour aux intervalles corrects, etc.) mais envoie un résultat "DOWN" à chaque intervalle de vérification de surveillance sans rien vérifier réellement.
