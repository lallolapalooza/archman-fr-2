NOM

gdal-vsi - Point d'entrée pour les commandes GDAL Virtual System Interface (VSI)

Ajouté dans la version 3.11.

Les sous-commandes de gdal vsi permettent la manipulation de fichiers situés sur les *Systèmes de Fichiers Virtuels GDAL (compressés, hébergés sur le réseau, etc...) : /vsimem, /vsizip, /vsitar, /vsicurl, ...*.

SYNTAXE

Utilisation : gdal vsi <SOUS-COMMANDE> [OPTIONS]
où <SOUS-COMMANDE> est l'un des suivants :
  - copy :   Copier des fichiers situés sur l'interface de système virtuel GDAL (VSI). (alias : cp)
  - delete : Supprimer des fichiers situés sur l'interface de système virtuel GDAL (VSI). (alias : rm, rmdir, del)
  - list :   Lister les fichiers de l'une des interfaces de système virtuel GDAL (VSI). (alias : ls)
  - move :   Déplacer/renommer un fichier/répertoire situé sur l'interface de système virtuel GDAL (VSI). (alias : mv, ren, rename)
  - sozip :  Commandes ZIP optimisées pour la recherche (SOZIP).
  - sync :   Synchroniser le fichier/répertoire source et cible situé sur l'interface de système virtuel GDAL (VSI).
Options communes :
  -h, --help              Afficher le message d'aide et quitter
  --json-usage            Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLÉ>=<VALEUR>  Option de configuration [peut être répétée]

SOUS-COMMANDES DISPONIBLES

  • gdal vsi copy
  • gdal vsi delete
  • gdal vsi list
  • gdal vsi move
  • gdal vsi sync
  • gdal vsi sozip

EXEMPLES

Exemple 1 : Lister récursivement les fichiers dans /vsis3/bucket avec détails

$ gdal vsi list -lR --of=text /vsis3/bucket
