NOM

gdalcompare - Compare deux images.

SYNTAXE

gdalcompare [--help] [--help-general]
               [-dumpdiffs] [-skip_binary] [-skip_overviews]
               [-skip_geolocation] [-skip_geotransform]
               [-skip_metadata] [-skip_rpc] [-skip_srs]
               [-sds] <fichier_référence> <nouveau_fichier>

DESCRIPTION

gdalcompare compare deux jeux de données pris en charge par GDAL et signale les différences. En plus de signaler les différences à la sortie standard, le script retournera également le nombre de différences dans sa valeur de sortie.

Les pixels de l'image et diverses métadonnées sont vérifiés. Une comparaison octet par octet est également effectuée, ce qui compte comme une différence. Ainsi, s'il est seulement important que les données visibles par GDAL soient identiques, une différence de 1 (la différence binaire) devrait être considérée comme acceptable.

NOTE :

gdalcompare est un utilitaire Python et n'est disponible que si les liaisons Python de GDAL sont disponibles.
--help
Affiche ce message d'aide et quitte.
--help-general
Donne un bref message d'utilisation pour les options de ligne de commande GDAL génériques et quitte.
-dumpdiffs
Ajouté dans la version 3.8.

Indique s'il faut exporter la différence de contenu des pixels dans un fichier TIFF dans le répertoire courant.

-skip_binary
Ajouté dans la version 3.8.

Indique s'il faut ignorer la comparaison exacte du contenu binaire.

-skip_overviews
Ajouté dans la version 3.8.

Indique s'il faut ignorer la comparaison des aperçus.

-skip_geolocation
Ajouté dans la version 3.8.

Indique s'il faut ignorer la comparaison du domaine de métadonnées GEOLOCATION.

-skip_geotransform
Ajouté dans la version 3.8.

Indique s'il faut ignorer la comparaison de la matrice de géotransformation.

-skip_metadata
Ajouté dans la version 3.8.

Indique s'il faut ignorer la comparaison des métadonnées.

-skip_rpc
Ajouté dans la version 3.8.

Indique s'il faut ignorer la comparaison du domaine de métadonnées des coefficients polynomiaux rationnels (RPC).

-skip_srs
Ajouté dans la version 3.8.

Indique s'il faut ignorer la comparaison des systèmes de référence spatiaux (SRS).

-sds
Si ce drapeau est passé, le script comparera tous les sous-jeux de données qui font partie du jeu de données, sinon les sous-jeux de données seront ignorés.
<fichier_référence>
Le fichier considéré comme correct, appelé fichier de référence.
<nouveau_fichier>
Le fichier comparé au fichier de référence, appelé nouveau fichier.

Notez que le script gdalcompare (comme tous les autres scripts) peut également être appelé en tant que bibliothèque depuis du code Python : from osgeo_utils import gdalcompare. Le point d'entrée principal est gdalcompare.compare_db() qui prend un gdal.Dataset de référence et un gdal.Dataset nouveau comme arguments et renvoie un compte de différences (à l'exclusion de la comparaison binaire). Le point d'entrée gdalcompare.compare_sds() peut être utilisé pour comparer les sous-jeux de données.

EXEMPLES

gdalcompare -dumpdiffs N.tiff S.tiff; echo $?
Files differ at the binary level.
Band 1 checksum difference:
  Golden: 36694
  New:    40645
  Pixels Differing: 1509
  Maximum Pixel Difference: 255.0
  Wrote Diffs to: 1.tif
Differences Found: 2
2
gdalcompare N.tiff N.tiff; echo $?
Differences Found: 0
0
