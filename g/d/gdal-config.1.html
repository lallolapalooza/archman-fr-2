NOM

gdal-config - Détermine diverses informations sur une installation GDAL.

Détermine diverses informations sur une installation GDAL.

SYNTAXE

gdal-config [OPTIONS]

Options :

--prefix[=DIR]]
le répertoire principal de l'installation GDAL.
--libs
Les bibliothèques et directives de liaison requises pour utiliser GDAL.
--cflags
Les instructions d'inclusion et les définitions de macros nécessaires pour compiler des modules utilisant GDAL.
--version
Rapporte la version de GDAL.
--ogr-enabled
Rapporte « oui » ou « non » sur la sortie standard, selon que OGR est intégré à GDAL.
--formats
Rapporte les formats configurés dans GDAL sur stdout.

DESCRIPTION

Ce script utilitaire (disponible sur les systèmes Unix) peut être utilisé pour déterminer diverses informations sur une installation GDAL. Il est normalement juste utilisé par les scripts de configuration pour les applications utilisant GDAL, mais peut être interrogé par un utilisateur final.
