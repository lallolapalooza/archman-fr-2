NOM

gdal-raster - Point d'entrée pour les commandes raster

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal raster <SOUS-COMMANDE> [OPTIONS]
où <SOUS-COMMANDE> est l'une des suivantes :
  - as-features:     Crée des entités à partir des pixels d'un jeu de données raster
  - aspect:          Génère une carte d'aspect
  - blend:           Mélange/compose deux jeux de données raster
  - calc:            Effectue des opérations d'algèbre raster
  - clean-collar:    Nettoie le collier d'un jeu de données raster, en supprimant le bruit.
  - clip:            Recadre un jeu de données raster.
  - color-map:       Génère un jeu de données RVB ou RVBA à partir d'une seule bande, en utilisant une carte de couleurs
  - compare:         Compare deux jeux de données raster.
  - contour:         Crée un contour vectoriel à partir d'un modèle d'élévation raster (DEM).
  - convert:         Convertit un jeu de données raster.
  - create:          Crée un nouveau jeu de données raster.
  - edit:            Modifie un jeu de données raster.
  - fill-nodata:     Remplit les régions raster sans données par interpolation à partir des bords.
  - footprint:       Calcule l'empreinte d'un jeu de données raster.
  - hillshade:       Génère une carte d'ombrage
  - index:           Crée un index vectoriel de jeux de données raster.
  - info:            Retourne des informations sur un jeu de données raster.
  - mosaic:          Construit une mosaïque, virtuelle (VRT) ou matérialisée.
  - neighbors:       Calcule la valeur de chaque pixel à partir de ses voisins (statistiques focales) (alias : neighbours)
  - nodata-to-alpha: Remplace les valeurs sans données par une bande alpha.
  - overview:        Gère les aperçus d'un jeu de données raster.
  - pansharpen:      Effectue une opération de pansharpening.
  - pipeline:        Traite un jeu de données raster en appliquant plusieurs étapes.
  - pixel-info:      Retourne des informations sur un pixel d'un jeu de données raster.
  - polygonize:      Crée un jeu de données d'entités polygonales à partir d'une bande raster.
  - proximity:       Produit une carte de proximité raster.
  - reclassify:      Reclasse les valeurs dans un jeu de données raster
  - reproject:       Reprojette un jeu de données raster.
  - resize:          Redimensionne un jeu de données raster sans modifier les extents géoréférencés.
  - rgb-to-palette:  Convertit une image RVB en une image pseudo-couleur / palettisée.
  - roughness:       Génère une carte de rugosité
  - scale:           Met à l'échelle les valeurs des bandes d'un jeu de données raster.
  - select:          Sélectionne un sous-ensemble de bandes d'un jeu de données raster.
  - set-type:        Modifie le type de données des bandes d'un jeu de données raster.
  - sieve:           Supprime les petites polygones d'un jeu de données raster.
  - slope:           Génère une carte de pente
  - stack:           Combine les bandes d'entrée dans une sortie multibande, virtuelle (VRT) ou matérialisée.
  - tile:            Génère des tuiles dans des fichiers séparés à partir d'un jeu de données raster.
  - tpi:             Génère une carte d'indice de position topographique (TPI)
  - tri:             Génère une carte d'indice de rugosité du terrain (TRI)
  - unscale:         Convertit les valeurs mises à l'échelle d'un jeu de données raster en valeurs non mises à l'échelle.
  - update:          Met à jour le raster de destination avec le contenu du raster d'entrée.
  - viewshed:        Calcule la vueshed d'un jeu de données raster.
  - zonal-stats:     Calcule des statistiques zonales raster
Options communes :
  -h, --help              Affiche le message d'aide et quitte
  --json-usage            Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>  Option de configuration [peut être répétée]
Options :
  --drivers               Affiche la liste des pilotes raster sous forme de document JSON

EXEMPLES

Exemple 1 : Obtenir des informations sur le fichier utm.tif (avec sortie JSON)

$ gdal raster info utm.tif

Exemple 2 : Convertir le fichier utm.tif en raster GeoPackage

$ gdal raster convert utm.tif utm.gpkg

Exemple 3 : Obtenir la liste des pilotes raster (avec sortie JSON)

$ gdal raster --drivers
