NOM

gdal-mdim-convert - Convertir un jeu de données multidimensionnel

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal mdim convert [OPTIONS] <ENTRÉE> <SORTIE>
Convertir un jeu de données multidimensionnel.
Arguments positionnels :
  -i, --input <ENTRÉE>                                 Jeu de données raster ou raster multidimensionnel d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster multidimensionnel de sortie (créé par l'algorithme) [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLÉ>=<VALEUR>                              Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie
  --co, --creation-option <CLÉ>=<VALEUR>                Option de création [peut être répétée]
  --overwrite                                          Indique si l'écrasement de la sortie existante est autorisé
  --array <SPÉCIFICATION-TABLEAU>                      Sélectionner un seul tableau au lieu de convertir tout le jeu de données. [peut être répétée]
  --array-option <CLÉ>=<VALEUR>                       Option passée à GDALGroup::GetMDArrayNames() pour filtrer les tableaux. [peut être répétée]
  --group <SPÉCIFICATION-GROUPE>                       Sélectionner un seul groupe au lieu de convertir tout le jeu de données. [peut être répétée]
  --subset <SPÉCIFICATION-SOUS-ENSEMBLE>               Sélectionner un sous-ensemble des données. [peut être répétée]
  --scale-axes <SPÉCIFICATION-MISE-À-L'ÉCHELLE>        Applique un facteur d'échelle intégral à une ou plusieurs dimensions [peut être répétée]
  --strict                                             Transformer les avertissements en erreurs.

DESCRIPTION

gdal mdim convert peut être utilisé pour convertir des données multidimensionnelles entre différents formats.

Les options suivantes sont disponibles :

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Sélectionne le format de sortie. Il peut s'agir d'un format qui prend en charge la sortie multidimensionnelle (comme NetCDF : Network Common Data Form, VRT multidimensionnel), ou de formats 2D « classiques », si une seule matrice 2D résulte des autres opérations de conversion spécifiées. Lorsque cette option n'est pas spécifiée, le format est deviné lorsque cela est possible à partir de l'extension du nom de fichier de destination.
--co, --creation-option <CLÉ>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler des détails spécifiques du fichier créé.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être affichée avec l'option de ligne de commande --format, mais la documentation du format est la source d'information définitive sur les options de création du pilote. Voir la documentation spécifique du format Pilotes raster pour les options de création légales pour chaque format.

Les options de création au niveau du tableau peuvent être transmises en les préfixant avec ARRAY:. Voir GDALGroup::CopyFrom() pour plus de détails concernant ces options.

--overwrite
Permet au programme d'écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
--array <spécification-tableau>
Au lieu de convertir l'ensemble du jeu de données, sélectionne un tableau, et éventuellement effectue des opérations dessus. Cette option peut être spécifiée plusieurs fois pour opérer sur différents tableaux.

<spécification-tableau> peut être simplement un nom de tableau, utilisant potentiellement une syntaxe complètement qualifiée (/groupe/sous-groupe/nom-tableau). Ou cela peut être une combinaison d'options avec la syntaxe : nom={nom-tableau-source}[,nomdst={nom-tableau-destination}][,resample=oui][,transpose=[{axe1},{axe2},...][,vue={expression-vue}]

Les options suivantes sont traitées dans cet ordre :

  • resample=oui demande que le tableau passe par GDALMDArray::GetResampled().
[{axe1},{axe2},...] est l'argument de GDALMDArray::Transpose().
Par exemple, transpose=[1,0] inverse l'ordre des axes d'un tableau 2D. Voir Exemple 5.
•
{expression-vue} est la valeur de l'argument viewExpr de GDALMDArray::GetView(). Voir Exemple 4.

Lors de la spécification d'une expression de vue qui effectue un découpage ou un sous-ensemble sur une dimension, l'opération équivalente sera appliquée à la variable d'indexation correspondante.

--array-option <NOM>=<VALEUR>
Option passée à GDALGroup::GetMDArrayNames() pour filtrer les tableaux signalés. Une telle option est spécifique au format. Consulter la documentation du pilote. Cette option peut être utilisée plusieurs fois.
--group <spécification-groupe>
Au lieu de convertir l'ensemble du jeu de données, sélectionne un groupe, et éventuellement effectue des opérations dessus. Cette option peut être spécifiée plusieurs fois pour opérer sur différents groupes. Si un seul groupe est spécifié, son contenu sera copié directement dans le groupe racine cible. Si plusieurs sont spécifiés, ils sont copiés sous le groupe racine cible.

<spécification-groupe> peut être juste un nom de groupe, utilisant potentiellement une syntaxe complètement qualifiée (/groupe/sous-groupe/sous-sous-groupe_nom). Ou cela peut être une combinaison d'options avec la syntaxe : nom={nom-groupe-source}[,nomdst={nom-groupe-destination}][,recursive=non]

--subset <spécification-sous-ensemble>
Effectue une opération de sous-ensemble (découpage ou tranchage) le long d'une dimension, à condition qu'elle soit indexée par une variable 1D de type numérique ou chaîne de caractères, et dont les valeurs sont triées monotoniquement. <spécification-sous-ensemble> suit exactement le codage KVP de OGC WCS 2.0 pour le sous-ensemble.

C'est-à-dire dim_nom(val_min,val_max) ou dim_nom(val_tranché) La première syntaxe sous-ensemble la dimension dim_nom pour les valeurs dans la plage [val_min,val_max]. La seconde syntaxe tranche la dimension dim_nom à la valeur val_tranché (et cette dimension sera supprimée des tableaux qui la référencent)

L'utilisation de --subset est incompatible avec la spécification d'une option vue dans --array.

Voir Exemple 2.

-scaleaxes <spécification-mise-à-l'échelle>
Applique un facteur d'échelle intégral à une ou plusieurs dimensions, c'est-à-dire extrait 1 valeur toutes les N valeurs (sans rééchantillonnage).

C'est-à-dire <nom_dim1>(<facteur_échelle>)[,<nom_dim2>(<facteur_échelle>)]...

L'utilisation de --scaleaxes est incompatible avec la spécification d'une option vue dans --array.

Voir Exemple 3.

--strict
Par défaut, certains échecs lors de la traduction sont tolérés, comme ne pas pouvoir écrire les attributs de groupe. En définissant cette option, de tels échecs provoqueront l'échec du processus.

Options avancées

--oo <NOM>=<VALEUR>
Option d'ouverture du jeu de données (spécifique au format).

Peut être répété.

--if <format>
Nom du format/pilote à tenter pour ouvrir le ou les fichiers d'entrée. Il est généralement inutile de le spécifier, mais il peut être utilisé pour ignorer la détection automatique du pilote, lorsque celle-ci échoue à sélectionner le pilote approprié. Cette option peut être répétée plusieurs fois pour spécifier plusieurs pilotes candidats. Notez qu'elle ne force pas ces pilotes à ouvrir le jeu de données. En particulier, certains pilotes ont des exigences concernant les extensions de fichiers.

Peut être répété.

EXEMPLES

Exemple 1 : Convertir un fichier netCDF en fichier VRT multidimensionnel

gdal mdim convert in.nc out.vrt

Exemple 2 : Extraire une tranche 2D d'un tableau time,Y,X

gdal mdim convert in.nc out.tif --subset "time(\"2010-01-01\")" --array temperature

Exemple 3 : Sous-échantillonner le long des axes X et Y

gdal mdim convert in.nc out.nc --scaleaxes "X(2),Y(2)"

Exemple 4 : Réordonner les valeurs d'un tableau

Réordonner les valeurs du tableau time,Y,X le long de l'axe Y de haut en bas à de bas en haut (ou l'inverse)

gdal mdim convert in.nc out.nc --array "name=temperature,view=[:,::-1,:]"

Exemple 5 : Transposer un tableau ayant l'ordre de dimension X,Y,time en time,Y,X

gdal mdim convert in.nc out.nc --array "name=temperature,transpose=[2,1,0]"
