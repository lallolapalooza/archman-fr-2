NOM

gdal-raster-update - Met à jour le raster de destination avec le contenu du raster d'entrée.

Ajouté dans la version 3.12.

SYNOPSIS

Utilisation : gdal raster update [OPTIONS] <INPUT> <OUTPUT>
Met à jour le raster de destination avec le contenu du raster d'entrée.
Arguments positionnels :
  -i, --input <INPUT>                        Jeu de données raster d'entrée [requis]
  -o, --output <OUTPUT>                      Jeu de données raster de sortie [requis]
Options communes :
  -h, --help                                 Afficher le message d'aide et quitter
  --json-usage                               Afficher l'utilisation sous forme de document JSON et quitter
  --config <KEY>=<VALUE>                     Option de configuration [peut être répétée]
  -q, --quiet                                Mode silencieux (pas de barre de progression)
Options :
  --geometry <GEOMETRY>                      Géométrie de découpage (WKT ou GeoJSON)
  --geometry-crs <GEOMETRY-CRS>              SCR de la géométrie de découpage
  -r, --resampling <RESAMPLING>              Méthode de rééchantillonnage. RESAMPLING=nearest|bilinear|cubic|cubicspline|lanczos|average|rms|mode|min|max|med|q1|q3|sum (par défaut : nearest)
  --no-update-overviews                      Ne pas mettre à jour les surcouches existantes
Options avancées :
  --oo, --open-option <KEY>=<VALUE>          Options d'ouverture [peut être répétée]
  --if, --input-format <INPUT-FORMAT>        Formats d'entrée [peut être répétée]
  --wo, --warp-option <NAME>=<VALUE>         Option(s) de reprojection [peut être répétée]
  --to, --transform-option <NAME>=<VALUE>    Option(s) de transformation [peut être répétée]
  --et, --error-threshold <ERROR-THRESHOLD>  Seuil d'erreur

DESCRIPTION

gdal raster update peut être utilisé pour mettre à jour un jeu de données raster cible existant avec les valeurs de pixels du raster source, en effectuant une reprojection si les jeux de données source et cible n'ont pas les mêmes systèmes de coordonnées de référence. L'étendue, la taille, la résolution ou le système de coordonnées de référence du jeu de données cible ne sont pas modifiés par cette opération.

Les surcouches sont mises à jour par cette commande (en utilisant gdal raster overview refresh), sauf si --no-update-overviews est spécifié.

Options standard

-r, --resampling <RESAMPLING>
Méthode de rééchantillonnage à utiliser. Les méthodes disponibles sont :

nearest: rééchantillonnage au voisin le plus proche (par défaut, algorithme le plus rapide, qualité d'interpolation la plus faible).

bilinear: rééchantillonnage bilinéaire.

cubic: rééchantillonnage cubique.

cubicspline: rééchantillonnage par spline cubique.

lanczos: rééchantillonnage sinc fenêtré de Lanczos.

average: rééchantillonnage par moyenne, calcule la moyenne pondérée de tous les pixels contribuants non-NODATA.

rms moyenne quadratique / écart type quadratique de tous les pixels contribuants non-NODATA

mode: rééchantillonnage par mode, sélectionne la valeur qui apparaît le plus souvent parmi tous les points échantillonnés. En cas d'égalité, la première valeur identifiée comme mode sera sélectionnée.

max: rééchantillonnage par maximum, sélectionne la valeur maximale parmi tous les pixels contribuants non-NODATA.

min: rééchantillonnage par minimum, sélectionne la valeur minimale parmi tous les pixels contribuants non-NODATA.

med: rééchantillonnage par médiane, sélectionne la valeur médiane de tous les pixels contribuants non-NODATA.

q1: rééchantillonnage par premier quartile, sélectionne la valeur du premier quartile de tous les pixels contribuants non-NODATA.

q3: rééchantillonnage par troisième quartile, sélectionne la valeur du troisième quartile de tous les pixels contribuants non-NODATA.

sum: calcule la somme pondérée de tous les pixels contribuants non-NODATA

NOTE :

Lorsqu'un sous-échantillonnage est effectué (utilisation de --resolution ou --size), les surcouches existantes (qu'elles soient internes/implicites ou externes) de l'image source seront utilisées par défaut en sélectionnant la surcouche la plus proche de la résolution de sortie souhaitée. La méthode de rééchantillonnage utilisée pour créer ces surcouches n'est généralement pas celle que vous spécifiez via l'option -r .
--geometry <WKT_or_GeoJSON>
Géométrie sous forme de chaîne WKT ou GeoJSON d'un polygone (ou multipolygone) à laquelle restreindre la mise à jour. Si la géométrie d'entrée est GeoJSON, son SCR est supposé être WGS84, sauf s'il y a un SCR défini dans la géométrie GeoJSON ou si --geometry-crs est spécifié. Si la géométrie d'entrée est WKT, son SCR est supposé être celui du jeu de données d'entrée, sauf si --geometry-crs est spécifié. Les axes X et Y sont les « conviviaux SIG », c'est-à-dire X est la longitude ou l'est, et Y est la latitude ou le nord.
--geometry-crs <CRS>
SCR dans lequel les valeurs de coordonnées de --geometry sont exprimées. Si non spécifié, il est supposé être le SCR du jeu de données d'entrée. La géométrie sera reprojetée du geometry-crs vers le SCR du jeu de données en cours de mise à jour.
--no-update-overviews
Ne pas mettre à jour les surcouches existantes.

Options avancées

--wo, --warp-option <NAME>=<VALUE>
Définir une option de reprojection. La documentation de GDALWarpOptions::papszWarpOptions montre toutes les options. Plusieurs options peuvent être listées.
--to <NAME>=<VALUE>
Définir une option de transformation adaptée à passer à GDALCreateGenImgProjTransformer2(). Voir GDALCreateRPCTransformerV2() pour les options spécifiques aux RPC.
--et, --error-threshold <ERROR-THRESHOLD>
Seuil d'erreur pour l'approximation de la transformation, exprimé en nombre de pixels source. Par défaut à 0.125 pixel sauf si l'option RPC_DEM est spécifiée, auquel cas un transformateur exact, c'est-à-dire --error-threshold=0, sera utilisé.

EXEMPLES

Exemple 1 : Mettre à jour out.tif existant avec le contenu de in.tif en utilisant l'interpolation cubique

$ gdal raster update -r cubic in.tif out.tif
