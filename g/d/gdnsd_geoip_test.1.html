NOM

gdnsd_geoip_test - Programme de test en ligne de commande pour les cartes gdnsd-plugin-geoip

SYNOPSIS

gdnsd_geoip_test [-c /etc/gdnsd] [nom_carte addr]
  -c            Répertoire de configuration gdnsd, voir la page de manuel principale gdnsd(8) pour les détails
  nom_carte     Nom de la carte depuis la configuration du plugin geoip
  addr          Adresse IP du client à mapper.

DESCRIPTION

Ceci est un programme de test simple en ligne de commande pour les configurations de cartes de "gdnsd-plugin-geoip". Il analyse votre fichier de configuration gdnsd standard, extrait les éléments pertinents de la section du plugin geoip, et traite la section "maps" en utilisant le même code de base que le plugin lui-même. Il résout ensuite l'adresse IP fournie par rapport au nom de carte fourni, fournissant une liste ordonnée de centres de données (et un masque de portée edns) comme résultat.

Les adresses IP d'entrée sur la ligne de commande n'acceptent pas les informations de sous-réseau CIDR. Ceci est intentionnel. En raison de la méthode par laquelle "gdnsd-plugin-geoip" construit, optimise et effectue des recherches sur les données internes, le masque de sous-réseau client est non pertinent, et le masque de portée de la réponse est toujours aussi spécifique ou général que nécessaire. Pour simuler différents masques d'entrée edns sur les mêmes données d'adresse, mettez simplement à zéro davantage de bits de droite de l'adresse.

Si aucun "[nom_carte addr]" n'est donné sur la ligne de commande, le programme entre en mode REPL (Read-Eval-Print Loop) avec une invite, vous permettant d'entrer interactivement plusieurs paires "[nom_carte addr]" sans recharger la ou les bases de données configurées.
