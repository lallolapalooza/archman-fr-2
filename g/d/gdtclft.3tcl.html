NOM

gdtclft - rend des images dans divers formats bitmap (GD, GD2, GIF, JPEG, PNG, WBMP, XBM)

DESCRIPTION

                             EXTENSION GD POUR TCL
   Le paquet Gd de Thomas Boutell fournit un moyen pratique de générer
   des images bitmap avec un programme C. Si vous, comme moi, préférez
   Tcl pour les applications CGI, vous voudrez mon extension GD pour TCL.

Aperçu
   Ce paquet fournit une interface Tcl simple au paquet gd (dessin bitmap).
   Il inclut une interface à toutes les fonctions et structures de données
   de gd à partir de commandes Tcl.
Référence
   Une commande Tcl, 'gd', est ajoutée. Toutes les actions du paquet gd
   sont des sous-commandes (ou « options » en terminologie Tcl) de cette
   commande.
   Chaque image gd active est désignée par un « handle ». Le handle est un
   nom de la forme gd# (par ex., gd0) renvoyé par les options de gd create.
   Presque toutes les commandes gd prennent un handle comme premier
   argument (après l'option). Toutes les commandes de dessin prennent un
   color_idx comme argument suivant.
   gd create <width> <height> ?true?
          Renvoie un handle vers un nouveau gdImage de largeur X hauteur.
	  Si "true" est spécifié, la nouvelle image est "TrueColor".
   gd createTrueColor <width> <height>
          Renvoie un handle vers un nouveau gdImage trueColor de largeur X hauteur.
   gd createFromGD <file>
   gd createFromGD2 <file>
   gd createFromGIF <file>
   gd createFromJPEG <file>
   gd createFromPNG <file>
   gd createFromWBMP <file>
   gd createFromXBM <file>
          Renvoie un handle vers un nouveau gdImage créé en lisant une
          image au format indiqué depuis le nom de fichier ou le handle de
          fichier TCL ouvert
	  (sauf pour XPM, qui n'accepte que les noms de fichiers).
   gd destroy <gdhandle>
          Détruit le gdImage référencé par gdhandle.
   gd writeGD <gdhandle> <file>
   gd writeGD2 <gdhandle> <file>
   gd writeGIF <gdhandle> <file>
   gd writeJPEG <gdhandle> <file>
   gd writePNG <gdhandle> <file>
   gd writeWBMP <gdhandle> <file>
   gd writeXBM <gdhandle> <file>
          Écrit l'image dans gdhandle vers le nom de fichier ou le handle
	  de fichier TCL ouvert au format indiqué.
   gd writePNGvar <gdhandle> <varname>
          Écrit l'image dans gdhandle dans la variable Tcl "varname" sous
          forme d'objet PNG codé en binaire.
   gd interlace <gdhandle> <on-off>
          Rend l'image de sortie entrelacée (si on-off est vrai) ou non (si
          on-off est faux).
   gd color new <gdhandle> <red> <green> <blue>
          Alloue une nouvelle couleur avec les valeurs RGB données. Renvoie
          le color_idx, ou -1 en cas d'échec (256 couleurs déjà allouées).
   gd color exact <gdhandle> <red> <green> <blue>
          Trouve un color_idx dans l'image qui correspond exactement à la
          couleur RGB donnée. Renvoie le color_idx, ou -1 s'il n'y a pas de
          correspondance exacte.
   gd color closest <gdhandle> <red> <green> <blue>
          Trouve une couleur dans l'image la plus proche de la couleur RGB
          donnée. Garantit de renvoyer un color_idx.
   gd color resolve <gdhandle> <red> <green> <blue>
          Renvoie l'indice du meilleur effort possible pour obtenir une
          couleur. Garantit de renvoyer un color_idx. Équivalent à :
               if {[set idx [gd color exact $gd $r $g $b]] == -1} {
                   if {[set idx [gd color neW $Gd $r $g $b]] == -1} {
                       set idx [gd color closest $gd $r $g $b]
                   }
               }
   gd color free <gdhandle> <color_idx>
          Libère la couleur à l'index color_idx donné pour réutilisation.
   gd color transparent <gdhandle> [<color_idx>]
          Marque la couleur à <color_idx> comme couleur d'arrière-plan
          transparente. Ou, renvoie le color_idx transparent si aucun
          color_idx n'est spécifié.
   gd color get <gdhandle> [<color_idx>]
          Renvoie la valeur RGB à <color_idx>, ou {} si elle n'est pas
          allouée. Si <color_idx> n'est pas spécifié, renvoie une liste de
          valeurs {color_idx R G B} pour toutes les couleurs allouées.
   gd brush <gdhandle> <brushhandle>
          Définit l'image de brosse à utiliser pour les lignes brossées. Les
          pixels transparents dans la brosse ne changeront pas l'image
          lorsque la brosse est appliquée.
   gd style <gdhandle> <color_idx> ...
          Définit le style de ligne comme liste d'indices de couleur. Ceci
          est interprété de l'une de deux manières. Pour une ligne stylée
          simple, chaque couleur est appliquée aux points le long de la
          ligne à tour de rôle. La valeur color_idx transparente peut être
          utilisée pour laisser des espaces dans la ligne. Pour une ligne
          stylée et brossée, un 0 (ou le color_idx transparent) signifie ne
          pas remplir le pixel, et une valeur non nulle signifie appliquer
          la brosse.
   gd tile <gdhandle> <tilehandle>
          Définit l'image de motif à utiliser pour les remplissages en
          motif. Les pixels transparents dans le motif ne changeront pas
          l'image sous-jacente pendant le motif.
          Dans toutes les fonctions de dessin, le color_idx est un nombre,
          ou peut être l'une des chaînes styled, brushed, tiled,
          "styled brushed" ou "brushed styled". Le style, la brosse ou le
          motif actuellement en vigueur sera utilisé. Le brossage et le
          style s'appliquent aux lignes, le motif aux zones remplies.
   gd set <gdhandle> <color_idx> <x> <y>
          Définit le pixel à (x,y) sur la couleur <color_idx>.
   gd line <gdhandle> <color_idx> <x1> <y1> <x2> <y2>
   gd rectangle <gdhandle> <color_idx> <x1> <y1> <x2> <y2>
   gd fillrectangle <gdhandle> <color_idx> <x1> <y1> <x2> <y2>
          Dessine le contour de (resp. remplit) un rectangle de couleur
          <color_idx> avec les coins à (x1,y1) et (x2,y2).
   gd arc       <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd fillarc   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd openarc   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd chord     <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd fillchord <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd openchord <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd pie       <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd fillpie   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
   gd openpie   <gdhandle> <color_idx> <cx> <cy> <width> <height> <start> <end>
          Tous décrivent une forme basée sur un arc de couleur
          <color_idx>, centrée à (cx,cy) dans un rectangle largeur x
          hauteur, commençant à start degrés et se terminant à end degrés.
	  arc       - Juste la ligne courbe.
	  fillarc   - (Conçu pour être un remplissage entre la courbe et la
		      corde, mais gd ne fait pas cela) - Identique à pie.
	  openarc   - Forme en contour avec courbe et corde.
	  chord     - Corde en ligne droite entre les extrémités de la
		      courbe, mais sans montrer la courbe.
	  fillchord - Triangle rempli entre la corde et le centre.
	  openchord - Triangle en contour entre la corde et le centre.
	  pie       - Segment de tarte rempli entre la courbe et le centre.
	  fillpie   - Identique à pie.
	  openpie   - Segment de tarte en contour entre la courbe et le centre.
   gd polygon <gdhandle> <color_idx> <x1> <y1> ...
   gd fillpolygon <gdhandle> <color_idx> <x1> <y1> ...
          Dessine le contour de, ou remplit, un polygone spécifié par la
          liste de coordonnées x, y. Au moins 3 points doivent être
          spécifiés.
   gd fill <gdhandle> <color_idx> <x> <y>
   gd fill <gdhandle> <color_idx> <x> <y> <borderindex>
          Remplit avec la couleur <color_idx>, à partir de (x,y) dans une
          région de pixels tous de la couleur du pixel à (x,y) (resp.,
          dans une bordure de couleur borderindex).
   gd size <gdhandle>
          Renvoie une liste {width height} de l'image.
   gd text <gdhandle> <color_idx> <fontlist> <size> <angle> <x> <y> <string>
          Dessine du texte en utilisant <fontlist> de couleur <color_idx>,
          avec la taille de point <size>, une rotation en radians <angle>,
          avec le coin inférieur gauche à (x,y). La chaîne peut contenir
          des séquences UTF8 comme : "&"
          Renvoie les 4 coordonnées des coins du rectangle englobant.
          Utilisez gdhandle = {} pour obtenir les limites sans rendre.
          Utilisez le négatif de color_idx pour désactiver l'antialiasing.
	  <fontlist> peut contenirsoit un chemin complet vers une police, incluant
	  l'extension ".ttf", soit il peut contenir une liste de noms
	  alternatifs pour une police, séparés par des espaces, sans le ".ttf".  p. ex.
		"Times-Roman times"
          Le fichier <name>.ttf correspondant à l'un des noms alternatifs
	  doit être trouvé dans le DEFAULT_FONTPATH intégré, ou dans le
	  chemin de polices spécifié dans la variable d'environnement GDFONTPATH.
   gd copy <desthandle> <srchandle> <destx> <desty> <srcx> <srcy> <w> <h>
	  Copie une sous-image de srchandle(srcx, srcy)
	  vers desthandle(destx, desty), de taille w x h.
   gd copy <desthandle> <srchandle> <destx> <desty> <srcx> <srcy> \
       <destw> <desth> <srcw> <srch>
	  Copie une sous-image de srchandle(srcx, srcy) 
          vers desthandle(destx, desty), et redimensionne la sous-image 
	  de srcw par srch en destw par desth.
Exemples
   Le programme d'exemple de la documentation de gd peut être écrit ainsi :
#!/bin/sh
# la ligne suivante est un commentaire en tcl exec tclsh "$0" ${1+"$@"}
package require Gdtclft
################################################################
# Programme gdtcl d'exemple  - de la page de manuel gdtclft
#
# Créer une image de 64 x 64
set im [gd create 64 64]
# Obtenir le noir et le blanc comme couleurs. Le noir est la couleur d'arrière-plan car
# il est alloué en premier depuis une nouvelle image.
set black [gd color new $im 0 0 0]
set white [gd color new $im 255 255 255]
# Dessiner une ligne du coin supérieur gauche au coin inférieur droit
gd line $im $white 0 0 63 63
# Ouvrir un fichier en écriture (Tcl sur Unix, au moins, ne supporte pas le mode 'wb')
set out [open test.png w]
# Écrire l'image dans le fichier disque
gd writePNG $im $out
# Fermer le fichier
close $out
# Détruire l'image en mémoire
gd destroy $im
  GDDEMO
   Voici le programme gddemo.c traduit en tcl.
#!/bin/sh
# la ligne suivante est un commentaire en tcl exec tclsh "$0" ${1+"$@"}
package require Gdtclft
################################################################
#
# gddemo en tcl
#
# ouvrir demoin.png ou quitter
if {[catch {open demoin.png r} in]} {
  puts stderr "Impossible de charger l'image source ; cette démo est beaucoup";
  puts stderr "plus impressionnante si demoin.png est disponible";
  exit
}
# Créer l'image de sortie 128 x 128
set im_out [gd create 128 128]
# La première couleur est l'arrière-plan
set white [gd color new $im_out 255 255 255]
# Définir la transparence
gd color transparent $im_out $white
# Charger demoin.png et coller une partie de celui-ci dans l'image de sortie.
set im_in [gd createFromPNG $in]
close $in
# Copier et réduire
gd copy $im_out $im_in 16 16 0 0 96 96 128 128]
# Obtenir quelques couleurs
set red [gd color new $im_out 255 0 0]
set green [gd color new $im_out 0 255 0]
set blue [gd color new $im_out 0 0 255]
# Dessiner un rectangle
gd line $im_out $green 8 8 120 8
gd line $im_out $green 120 8 120 120
gd line $im_out $green 120 120 8 120
gd line $im_out $green 8 120 8 8
# Texte
gd text $im_out $red arial 20 0 16 16 hi
gd text $im_out $red arial 20 90 23 23 hi
# Cercle
gd arc $im_out $blue 64 64 30 10 0 360
# Arc
gd arc $im_out $blue 64 64 20 20 45 135
# Remplissage par diffusion
gd fill $im_out $blue 4 4
# Polygone
gd fillpolygon $im_out $green 32 0 0 64 64 64
# Brosse. Un exemple assez excentrique impliquant aussi un style de ligne !
if {$im_in != ""} {
  set brush [gd create 8 8];
  eval [concat gd copy $brush $im_in 0 0 0 0 [gd size $brush] [gd size $im_in]]
  gd brush $im_out $brush
  # Style pour qu'ils ne se superposent pas les uns aux autres.
  gd style $im_out "0 0 0 0 0 0 0 1"
  gd line $im_out "styled brushed" 0 0 128 128
}
# Entrelacer le résultat pour un "fondu à l'entrée" dans les visionneuses qui le supportent
gd interlace $im_out true
# Écrire le PNG
set out [open demoout.png w]
gd writePNG $im_out $out
close $out
gd destroy $im_out
  GDSHOW
   Une procédure Tcl rapide pour afficher une image GD en utilisant le programme xv.
################################################################
# gdshow -- utiliser xv pour afficher une image.
#
# Attend jusqu'à ce que xv quitte pour retourner.
#
proc gdshow {gd} {
  set f [open "|xv -" w]
  catch {gd writePNG $gd $f}
  catch {close $f} xx
  if {$xx != {}} {
    error "Erreur XV : $xx"
  }
}
