Normalement, les tuiles de l'image de base sont stockées comme
décrit dans
-targetDir . Pour les grandes images, certains systèmes de fichiers ont des problèmes de performance si le nombre de fichiers dans un répertoire est trop grand, ce qui empêche gdal_retile de se terminer dans un délai raisonnable. L'utilisation de ce paramètre crée une structure de sortie différente. Les tuiles de l'image de
base sont stockées dans un sous-répertoire appelé 0, les pyramides dans des sous-répertoires numérotés 1,2,.... Au sein de chacun de ces répertoires, un au
tre niveau de sous-répertoires est créé, numérotés de 0...n, selon le nombre de rangées de tuiles nécessaires pour chaque niveau. Enfin, un répertoire ne con
tient que les tuiles d'une seule rangée pour un niveau spécifique. Pour les grandes images, une amélioration de performance d'un facteur N peut être obtenue.
