NOM

gdal-raster-rgb-to-palette - Convertir une image RVB en image pseudo-couleur / palettisée.

Ajouté en version 3.12.

SYNTAXE

Utilisation : gdal raster rgb-to-palette [OPTIONS] <ENTRÉE> <SORTIE>
Convertir une image RVB en image pseudo-couleur / palettisée.
Arguments positionnels :
  -i, --input <ENTRÉE>                                 Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster de sortie [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLÉ>=<VALEUR>                               Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLÉ>=<VALEUR>                Option de création [peut être répétée]
  --overwrite                                          Autoriser l'écrasement du fichier de sortie existant
                                                       Mutuellement exclusif avec --append
  --append                                             Ajouter comme sous-jeu de données au fichier de sortie existant
                                                       Mutuellement exclusif avec --overwrite
  --color-count <NOMBRE-COULEURS>                      Sélectionner le nombre de couleurs dans la table de couleurs générée (défaut: 256)
  --color-map <CARTE-COULEURS>                         Fichier de carte de couleurs
Options avancées :
  --if, --input-format <FORMAT-ENTRÉE>                 Formats d'entrée [peut être répété]
  --oo, --open-option <CLÉ>=<VALEUR>                    Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster rgb-to-palette calcule une table de pseudo-couleurs optimale pour une image RVB donnée en utilisant un algorithme de coupe médiane sur un histogramme RVB sous-échantillonné, sauf si une table de couleurs est fournie avec l'option --color-map. Ensuite, il convertit l'image en une image pseudo-colorisée à l'aide de la table de couleurs. Cette conversion utilise le tramage de Floyd-Steinberg (diffusion d'erreur) pour maximiser la qualité visuelle de l'image de sortie.

Cette sous-commande est également disponible comme étape potentielle de gdal raster pipeline

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format de sortie raster utiliser. Les valeurs autorisées peuvent être obtenues par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler les détails du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être tuilé.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être répertoriée avec l'option de ligne de commande --formats, mais la documentation du format est la source d'information faisant autorité sur les options de création du pilote. Voir la documentation spécifique au format Pilotes raster pour les options de création valides pour chaque format.

--overwrite
Permet au programme d'écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
--color-count <NOMBRE-COULEURS>
Sélectionner le nombre de couleurs dans la table de couleurs générée. La valeur par défaut est 256. Doit être compris entre 2 et 256.
--color-map <NOMFICHIER>
Extraire la table de couleurs du <NOMFICHIER> au lieu de la calculer. Peut être utilisé pour avoir une table de couleurs cohérente pour plusieurs fichiers. Le <NOMFICHIER> doit être soit un fichier raster dans un format supporté par GDAL avec une palette, soit un fichier de couleurs dans un format supporté (.txt, .qml QGIS, .qlr QGIS).

SORTIE GDALG (DU COURS DES ÉVÉNEMENTS / FLUX DE DONNÉES)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière dynamique / en flux.

NOTE :

Cependant, cet algorithme n'est pas nativement compatible avec le flux. Par conséquent, un jeu de données temporaire sera généré, ce qui peut entraîner un temps de traitement important à l'ouverture.

EXEMPLES

Exemple 1

Convertir un fichier TIFF en une image PNG palettisée

$ gdal raster rgb-to-palette input.tif output.png
