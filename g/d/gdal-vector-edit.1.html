DESCRIPTIO

N

gdal vector edit peut être utilisé pour modifier les métadonnées d'un jeu de données vectoriel : son SCR, le type de géométrie de la couche, les métadonnées du jeu de données et de la

couche.

edit peut également être utilisé comme une étape d'un gdal vector p

ipeline.

Les entités ne sont pas

modifiées.

Quel format vectoriel de sortie utiliser. Les valeurs autorisées peuvent être obtenues par gdal --
formats | gre

--co <NOM>
=<VALEUR>
De nombreux formats ont une ou plusieurs options de création de jeu de données facultatives qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoPackage prend en charge des options de création pour contrôler la version.

Peut être

répétée.

Les options de création de jeu de données disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être obtenue avec l'option de ligne de commande --formats, mais la documentation du format est la source définitive d'informations sur les options de création du pilote. Voir la documentation spécifique au format des pilotes vectoriels pour les options de création autorisées pour chaque

format.
