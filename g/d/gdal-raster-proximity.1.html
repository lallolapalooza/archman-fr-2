DESCRIPTIO

N

gdal raster proximity génère une carte de proximité raster indiquant la distance cartésienne du centre de chaque pixel au centre du pixel le plus proche identifié comme pixel cible. Les pixels cibles sont ceux du raster source pour lesquels la valeur du pixel raster est dans l'ensemble des valeurs de pixels

cibles.

Cette sous-commande est également disponible en tant qu'étape potentielle de gdal raster

pipeline

SORTIE GDALG (JEU DE DONNÉES EN TEMPS RÉEL / EN

FLUX)

Ce programme prend en charge la sérialisation de la ligne de commande en fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert en tant que jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière en temps réel / en

flux.

NOTE

:
Cependant, cet algorithme n'est pas nativement compatible avec le streaming. Par conséquent, un jeu de données temporaire sera généré, ce qui peut entraîner un temps de traitement important à
l'ouverture. v>
