NOM

gdal-raster-fill-nodata - Remplit les valeurs nodata dans un jeu de données raster

Ajouté dans la version 3.11.

SYNOPSIS

Utilisation : gdal raster fill-nodata [OPTIONS] <ENTRÉE> <SORTIE>
Remplit les régions raster nodata par interpolation depuis les bords.
Arguments positionnels :
  -i, --input <ENTRÉE>                                  Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster de sortie [requis]
Options communes :
  -h, --help                                           Affiche le message d'aide et quitte
  --json-usage                                         Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>                              Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLÉ>=<VALEUR>               Option de création [peut être répétée]
  --overwrite                                          Indique si l'écrasement de la sortie existante est autorisé
                                                       Mutuellement exclusif avec --append
  --append                                             Ajoute comme sous-jeu de données à la sortie existante
                                                       Mutuellement exclusif avec --overwrite
  -b, --band <BANDE>                                   Bande d'entrée (index basé sur 1) (par défaut : 1)
  -d, --max-distance <DISTANCE_MAX>                    La distance maximale (en pixels) que l'algorithme parcourra pour rechercher des valeurs à interpoler. (par défaut : 100)
  -s, --smoothing-iterations <ITÉRATIONS LISSAGE>      Le nombre d'itérations de lissage par filtre moyen 3x3 à exécuter après l'interpolation pour atténuer les artefacts. Le nombre d'itérations de lissage par défaut est zéro. (par défaut : 0)
  --mask <MASQUE>                                      Utilise la première bande du fichier spécifié comme masque de validité (zéro est invalide, non nul est valide).
  --strategy <STRATÉGIE>                               Par défaut, les pixels sont interpolés en utilisant un pondération par distance inverse (invdist). Il est également possible de choisir une stratégie du plus proche voisin (nearest). STRATÉGIE=invdist|nearest (par défaut : invdist)
Options avancées :
  --if, --input-format <FORMAT-ENTRÉE>                 Formats d'entrée [peut être répétée]
  --oo, --open-option <CLÉ>=<VALEUR>                   Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster fill-nodata remplit les zones nodata en interpolant depuis les pixels valides autour des bords de la zone.

Cette sous-commande est également disponible en tant qu'étape potentielle de gdal raster pipeline (depuis GDAL 3.12)

OPTIONS

Les options suivantes sont disponibles :

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format de raster de sortie utiliser. Les valeurs autorisées peuvent être données par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression et si le fichier doit être tuilé.

Peut être répétée.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont pas d'options de création du tout. Une liste des options prises en charge pour un format peut être listée avec l'option de ligne de commande --formats mais la documentation du format est la source définitive d'informations sur les options de création du pilote. Voir Pilotes raster la documentation spécifique au format pour les options de création légales de chaque format.

--overwrite
Autorise le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
--output-layer <COUCHE-SORTIE>
Nom de la couche de sortie.
--overwrite
Autorise le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
-b <BANDE>
Sélectionne une <BANDE> d'entrée à traiter. Les bandes sont numérotées à partir de 1. La valeur par défaut est la première bande du jeu de données d'entrée.
-max-distance <DISTANCE_MAX>
Spécifie la distance maximale (en pixels) que l'algorithme parcourra pour rechercher des valeurs à interpoler. La valeur par défaut est 100 pixels.
--smoothing-iterations <ITÉRATIONS LISSAGE>
Spécifie le nombre d'itérations de lissage à appliquer au raster rempli. Cela peut aider à réduire les artefacts dans les zones remplies. La valeur par défaut est 0 itération.
--strategy <STRATÉGIE>
Sélectionne la <STRATÉGIE> d'interpolation à utiliser. Par défaut, les pixels sont interpolés en utilisant une pondération par distance inverse (invdist). Il est également possible de choisir une stratégie du plus proche voisin (nearest) .
--mask <MASQUE>
Utilise la première bande du fichier spécifié comme masque de validité (zéro est invalide, non nul est valide).

Ajouté dans la version 3.12.

SORTIE GDALG (JEU DE DONNÉES À LA VOLÉE / EN FLUX)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG . Le fichier résultant peut ensuite être ouvert en tant que jeu de données raster en utilisant le pilote GDALG : GDAL Streamed Algorithm et appliquer le pipeline spécifié de manière à la volée / en flux.

NOTE :

Cependant, cet algorithme n'est pas nativement compatible avec le streaming. Par conséquent, un jeu de données temporaire sera généré, ce qui peut entraîner un temps de traitement important à l'ouverture.

EXEMPLES

Exemple 1 : Remplir les zones nodata dans un raster

La commande spécifie d'utiliser la deuxième bande du raster d'entrée, une distance maximale de 50 px, 3 itérations de lissage et la stratégie nearest pour l'interpolation. La sortie sera enregistrée dans output.tif.

gdal raster fill-nodata -b 2 --max-distance 50 --smoothing-iterations 3 \
    --strategy nearest --mask mask.tif \
    input.tif output.tif
