NOM

gdal-raster-roughness - Générer une carte de rugosité

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal raster roughness [OPTIONS] <ENTRÉE> <SORTIE>
Générer une carte de rugosité
Arguments positionnels :
  -i, --input <ENTRÉE>                                 Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster de sortie [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLÉ>=<VALEUR>                              Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLÉ>=<VALEUR>             Option de création [peut être répétée]
  --overwrite                                          Autoriser l'écrasement de la sortie existante
                                                       Mutuellement exclusif avec --append
  --append                                             Ajouter en tant que sous-ensemble de données à la sortie existante
                                                       Mutuellement exclusif avec --overwrite
  -b, --band <BANDE>                                    Bande d'entrée (index basé sur 1) (défaut : 1)
  --no-edges                                           Ne pas essayer d'interpoler les valeurs aux bords du jeu de données ou près des valeurs nodata
Options avancées :
  --if, --input-format <FORMAT-ENTRÉE>                 Formats d'entrée [peut être répété]
  --oo, --open-option <CLÉ>=<VALEUR>                   Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster roughness génère un raster à bande unique avec des valeurs calculées à partir de l'altitude. La rugosité est la plus grande différence inter-cellule d'un pixel central et de sa cellule environnante, telle que définie dans Wilson et al. (2007, Marine Geodesy 30:3-35).

Cette sous-commande est également disponible comme une étape potentielle de gdal raster pipeline

La valeur nodata -9999 est utilisée comme valeur nodata.

Une valeur nodata dans le jeu de données cible sera également émise si au moins un pixel défini à la valeur nodata est trouvé dans la fenêtre 3x3 centrée autour de chaque pixel source. Par défaut, l'algorithme calculera des valeurs aux bords de l'image ou si une valeur nodata est trouvée dans la fenêtre 3x3, en interpolant les valeurs manquantes, sauf si --no-edges est spécifié, auquel cas une bordure de 1 pixel autour de l'image sera définie avec la valeur nodata.

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format de raster de sortie utiliser. Les valeurs autorisées peuvent être fournies par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler les détails du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être carrelé.

Peut être répété.

Les options de création disponibles varient selon le pilote de format et certains formats simples n'ont aucune option de création. Une liste des options supportées pour un format peut être obtenue avec l'option de ligne de commande --formats mais la documentation du format est la source d'information définitive sur les options de création du pilote. Voir la documentation spécifique au format Pilotes raster pour les options de création légales pour chaque format.

--overwrite
Autorise le programme à écraser un fichier ou un jeu de données cible existant. Sinon, par défaut, gdal renvoie une erreur si le fichier ou le jeu de données cible existe déjà.
-b, --band <BANDE>
Index (commençant à 1) de la bande pour laquelle la rugosité doit être calculée.
--no-edges
Ne pas essayer d'interpoler les valeurs aux bords du jeu de données ou près des valeurs nodata

SORTIE GDALG (À LA VOLÉE / FLUX DE DONNÉES)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière à la volée / en flux.

EXEMPLES

Exemple 1 : Génère une carte de rugosité à partir d'un fichier DTED0.

$ gdal raster roughness n43.dt0 out.tif --overwrite
