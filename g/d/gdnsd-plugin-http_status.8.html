NOM

gdnsd-plugin-http_status - Module de surveillance HTTP de gdnsd

SYNTAXE

Exemple de configuration des service_types pour http_status :

service_types => {
  webcheck => {
    plugin => http_status,
    port => 8080,             # par défaut 80
    url_path => /checkme      # par défaut '/'
    vhost => www.example.com  # par défaut none
    ok_codes => [ 200, 301 ], # par défaut [ 200 ]
    up_thresh => 20,
    ok_thresh => 10,
    down_thresh => 10,
    interval => 10,
    timeout => 3,
  }
}

DESCRIPTION

gdnsd-plugin-http_status est un module de surveillance qui vérifie les services HTTP de base.

PARAMÈTRES

port
Le numéro de port numérique sur lequel se connecter, par défaut 80.
url_path
L'URL sous forme de chaîne de caractères à requêter auprès du service distant, par défaut "/"
vhost
Le nom d'hôte sous forme de chaîne de caractères à fournir dans l'en-tête "Host:" avec la requête. Pas de valeur par défaut. Si non spécifié, aucun en-tête "Host:" n'est envoyé.
ok_codes
Un tableau de codes de statut HTTP entiers qui sont acceptables en tant que réponses positives. La valeur par défaut est "[ 200 ]".
