NOM

gdal-raster-create - Crée un nouveau jeu de données raster

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal raster create [OPTIONS] <SORTIE>
Crée un nouveau jeu de données raster.
Arguments positionnels :
  -o, --output <SORTIE>                                    Jeu de données raster de sortie (créé par l'algorithme) [requis]
Options communes :
  -h, --help                                               Affiche le message d'aide et quitte
  --json-usage                                             Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>                                  Option de configuration [peut être répétée]
  -q, --quiet                                              Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>      Format de sortie
  -i, --like, --input <ENTREE>                             Jeu de données raster d'entrée
  --co, --creation-option <CLE>=<VALEUR>                 Option de création [peut être répétée]
  --overwrite                                              Autorise l'écrasement du fichier de sortie existant
                                                           Mutuellement exclusif avec --append
  --append                                                 Ajouter comme sous-jeu de données à la sortie existante
                                                           Mutuellement exclusif avec --overwrite
  --size <largeur>,<hauteur>                               Taille de sortie en pixels
  --band-count <NBANDE>                                   Nombre de bandes (défaut : 1)
  --ot, --datatype, --output-data-type <TYPE-DONNEES-SORTIE> Type de données de sortie. TYPE-DONNEES-SORTIE=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64 (défaut : Byte)
  --nodata <NODATA>                                        Attribue une valeur nodata spécifiée aux bandes de sortie ('none', valeur numérique, 'nan', 'inf', '-inf')
  --burn <VALEUR>                                          Valeur à graver [peut être répétée]
  --crs <CRS>                                              Définit le SCR (Système de Coordonnées de Référence)
  --bbox <BOITE>                                           Boîte englobante sous la forme xmin,ymin,xmax,ymax
  --metadata <CLE>=<VALEUR>                                Ajoute un élément de métadonnées [peut être répété]
  --copy-metadata                                          Copie les métadonnées du jeu de données d'entrée
  --copy-overviews                                         Crée les mêmes niveaux d'aperçu que le jeu de données d'entrée
Options avancées :
  --oo, --open-option <CLE>=<VALEUR>                     Options d'ouverture [peut être répétée]
  --if, --input-format <FORMAT-ENTREE>                     Formats d'entrée [peut être répété]

DESCRIPTION

gdal raster create peut être utilisé pour initialiser un nouveau fichier raster, à partir de ses dimensions, du nombre de bandes, du SCR, de la transformation géométrique, de la valeur nodata et des métadonnées.

Le nouveau fichier peut également être initialisé à partir d'un fichier d'entrée modèle avec l'option facultative --like, en copiant ses propriétés mais pas ses valeurs de pixels. Par défaut, les métadonnées et la structure des aperçus ne sont pas copiées du fichier d'entrée modèle, sauf si --copy-metadata et --copy-overviews sont spécifiés. Les options --size, --band-count, --datatype, --nodata, --crs, --bbox, --metadata peuvent être utilisées pour remplacer les valeurs héritées du fichier d'entrée modèle.

Pour une sortie GeoTIFF, la définition de l'option de création SPARSE_OK à YES peut être utile pour créer un fichier de taille minimale.

gdal raster create peut également être utilisé dans des cas spéciaux, comme la création d'un fichier PDF à partir d'un fichier de composition XML.

OPTIONS

--like, --like <JEU-DONNEES>
Nom du jeu de données d'entrée GDAL qui sert de modèle pour les valeurs par défaut des options --size, --band-count, --datatype, --crs, --bbox et --nodata. Notez que les valeurs de pixels ne seront pas copiées.
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler des particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression et si le fichier doit être tuilé.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être obtenue avec l'option de ligne de commande --formats, mais la documentation du format est la source définitive d'information sur les options de création du pilote. Consultez la documentation spécifique au format des Pilotes raster pour connaître les options de création valides pour chaque format.

--overwrite
Autorise le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
--append
Ajoute le nouveau raster comme un nouveau sous-jeu de données au fichier de sortie existant. Ne fonctionne qu'avec les pilotes qui prennent en charge l'ajout de sous-jeux de données tels que GTiff -- Format de fichier GeoTIFF et GPKG -- GeoPackage raster.
--size <taille-x>,<taille-y>
Définit la taille du fichier de sortie en pixels. La première valeur est la largeur. La seconde est la hauteur.
--band-count <nombre>
Nombre de bandes. Par défaut, 1.
--ot, --datatype, --output-data-type <TYPE-DONNEES-SORTIE>
Type de données de sortie parmi Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.
--nodata <valeur>
Définit la valeur nodata.

null ou none peuvent être spécifiés pour annuler la valeur nodata existante du jeu de données --like si elle est définie. nan, inf ou -inf sont également acceptés pour les rasters flottants pour signifier respectivement les valeurs spéciales non un nombre, infini positif et infini négatif.

--burn <valeur>
Une valeur fixe à graver dans une bande. Une liste d'options --burn peut être fournie, une par bande (la première valeur s'appliquera à la première bande, la seconde à la deuxième bande, etc.). Si une seule valeur est spécifiée, elle s'appliquera à toutes les bandes.
--crs <SCR>
Définit le SCR.

Les systèmes de coordonnées de référence qui peuvent être transmis sont tout ce qui est pris en charge par l'appel OGRSpatialReference::SetFromUserInput(), ce qui inclut les SCR Projetés, Géographiques ou Composites EPSG (c'est-à-dire EPSG:4296), une définition de SCR en texte bien connu (WKT), des déclarations PROJ.4, ou le nom d'un fichier .prj contenant une définition de SCR en WKT.

null ou none peuvent être spécifiés pour annuler le SCR existant du jeu de données --like s'il est défini.

Notez que l'étendue spatiale reste également inchangée.

--bbox <xmin>,<ymin>,<xmax>,ymax>
Définit la boîte englobante spatiale, en unités du SCR. 'x' correspond aux valeurs de longitude pour un SCR géographique et à l'est pour un SCR projeté. 'y' correspond aux valeurs de latitude pour un SCR géographique et au nord pour un SCR projeté.
--metadata <CLE>=<VALEUR>
Ajoute un élément de métadonnées, au niveau du jeu de données.
--copy-metadata
Copie les métadonnées du jeu de données et des bandes raster d'entrée. Nécessite que --like soit spécifié.
--copy-overviews
Crée les mêmes niveaux d'aperçus que le jeu de données d'entrée. Nécessite que --like soit spécifié.
--oo <CLE>=<VALEUR>
Options d'ouverture du jeu de données d'entrée. Peut être répété.
--if <FORMAT-ENTREE>
Format(s) du jeu de données d'entrée. Peut être répété.

EXEMPLES

Créer un fichier GeoTIFF vide de 100x50 pixels :
  $ gdal raster create output.tif --size 100,50
Créer un fichier GeoTIFF de 100x50 pixels avec une bande, de type Byte, et
une valeur nodata de -9999 :
  $ gdal raster create output.tif --size 100,50 --band-count 1 --ot Byte --nodata -9999
Créer un fichier GeoTIFF de 100x50 pixels avec 3 bandes, et une valeur
nodata de NaN :
  $ gdal raster create output.tif --size 100,50 --band-count 3 --nodata nan
Créer un fichier GeoTIFF basé sur la structure d'un fichier existant,
mais avec une taille différente et une nouvelle valeur nodata :
  $ gdal raster create output.tif --like input.tif --size 200,150 --nodata 0
Créer un fichier GeoTIFF avec des métadonnées personnalisées :
  $ gdal raster create output.tif --size 100,50 --metadata TITLE="Mon Image" --metadata CREATOR="Moi"
Créer un fichier GeoTIFF avec un SCR et une boîte englobante spécifiés :
  $ gdal raster create output.tif --size 100,50 --crs EPSG:4326 --bbox "-100,30,-90,40"
Créer un fichier GeoTIFF 3 bandes, en gravant la valeur 1 dans la première
bande et la valeur 2 dans la deuxième bande :
  $ gdal raster create output.tif --size 100,50 --band-count 3 --burn 1 --burn 2
Créer un fichier GeoTIFF avec compression LZ4 et tuiles de 256x256 pixels :
  $ gdal raster create output.tif --size 100,50 --co COMPRESS=LZ4 --co TILED=YES --co BLOCKXSIZE=256 --co BLOCKYSIZE=256
Ajouter un nouveau raster comme sous-jeu de données à un fichier GPKG existant :
  $ gdal raster create existing.gpkg --append --size 100,50 --band-count 1
