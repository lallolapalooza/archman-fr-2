NOM

gdal-dataset-identify - Identifier le pilote ouvrant le(s) jeu(x) de données

Ajouté dans la version 3.12.

gdal manage-dataset identify signale le nom des pilotes qui peuvent ouvrir un ou plusieurs jeux de données.

SYNOPSIS

Usage: gdal dataset identify [OPTIONS] <FILENAME>
Identifier le pilote ouvrant le(s) jeu(x) de données.
Arguments positionnels :
  --filename <FILENAME>                                Nom de fichier ou de répertoire [peut être répété] [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <KEY>=<VALUE>                               Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <OUTPUT-FORMAT>  Format de sortie. OUTPUT-FORMAT=json|text
  -r, --recursive                                      Scanner récursivement les fichiers/dossiers pour les jeux de données
  --force-recursive                                    Scanner récursivement les dossiers pour les jeux de données, forçant la récursion dans les dossiers reconnus comme formats valides
  --report-failures                                    Signaler les échecs si le type de fichier n'est pas identifié

OPTIONS

--filename <FILENAME>
Nom de fichier ou de répertoire. Requis. Peut être répété.
-f, --of, --format, --output-format json|text
Quel format de sortie utiliser. Par défaut, JSON, ou texte lorsqu'il est appelé depuis la ligne de commande.
-r, --recursive
Scanner récursivement les fichiers/dossiers pour les jeux de données.
--force-recursive
Scanner récursivement les dossiers pour les jeux de données, forçant la récursion dans les dossiers reconnus comme formats valides.
--report-failures
Signaler les échecs si le type de fichier n'est pas identifié.

EXEMPLES

Exemple 1 : Identifier un seul fichier

$ gdal dataset identify --of=text NE1_50M_SR_W.tif
NE1_50M_SR_W.tif: GTiff

Exemple 2 : Identifier un seul fichier avec sortie JSON

$ gdal dataset identify NE1_50M_SR_W.tif
[
   {
     "name": "NE1_50M_SR_W.tif",
     "driver": "GTiff"
   }
]

Exemple 3 : Le mode récursif analysera les sous-dossiers et signalera le format des données

$ gdal dataset identify --of=text -r 50m_raster/
NE1_50M_SR_W/ne1_50m.jpg: JPEG
NE1_50M_SR_W/ne1_50m.png: PNG
NE1_50M_SR_W/ne1_50m_20pct.tif: GTiff
NE1_50M_SR_W/ne1_50m_band1.tif: GTiff
NE1_50M_SR_W/ne1_50m_print.png: PNG
NE1_50M_SR_W/NE1_50M_SR_W.aux: HFA
NE1_50M_SR_W/NE1_50M_SR_W.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub2.tif: GTiff
