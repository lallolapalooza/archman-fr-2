NOM

gdal-raster-resize - Redimensionner un jeu de données raster

Ajouté dans la version 3.11.

SYNOPSIS

Usage: gdal raster resize [OPTIONS] <ENTREE> <SORTIE>
Redimensionne un jeu de données raster sans modifier les étendues géoréférencées.
Arguments positionnels :
  -i, --input <ENTREE>                                 Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster de sortie [requis]
Options communes :
  -h, --help                                           Affiche le message d'aide et quitte
  --json-usage                                         Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>                                Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLE>=<VALEUR>                Option de création [peut être répétée]
  --overwrite                                          Autorise l'écrasement du fichier de sortie existant
                                                       Mutuellement exclusif avec --append
  --append                                             Ajouter comme sous-jeu de données à la sortie existante
                                                       Mutuellement exclusif avec --overwrite
  --resolution <xres>,<yres>                           Résolution cible (dans les unités de la CRS de destination)
                                                       Mutuellement exclusif avec --size
  --size <largeur[%]>,<hauteur[%]>                     Taille cible en pixels (ou pourcentage si suffixe '%' utilisé) [requis]
                                                       Mutuellement exclusif avec --resolution
  -r, --resampling <METHODE>                           Méthode de rééchantillonnage. METHODE=nearest|bilinear|cubic|cubicspline|lanczos|average|mode (défaut : nearest)
Options avancées :
  --if, --input-format <FORMAT-ENTREE>                 Formats d'entrée [peut être répété]
  --oo, --open-option <CLE>=<VALEUR>                   Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster resize peut être utilisé pour redimensionner un jeu de données raster sans modifier les étendues géoréférencées.

Cette sous-commande est également disponible comme étape potentielle de gdal raster pipeline

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format raster de sortie utiliser. Les valeurs autorisées peuvent être données par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler des détails du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être découpé en tuiles.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être affichée avec l'option de ligne de commande --formats, mais la documentation du format est la source d'information faisant autorité sur les options de création du pilote. Voir la documentation spécifique du format Pilotes raster pour connaître les options de création valides pour chaque format.

--overwrite
Autorise le programme à écraser le fichier ou jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou jeu de données cible existe déjà.
--resolution <xres>,<yres>
Ajouté dans la version 3.12.

Définit la résolution du fichier de sortie (dans les unités géoréférencées cibles).

Mutuellement exclusif avec --size.

--size <largeur[%]>,<hauteur[%]>
Définit la largeur et la hauteur du raster de sortie, exprimées en pixels, ou en pourcentage si le suffixe % est utilisé. Si la largeur ou la hauteur est définie à 0, l'autre dimension sera déduite de la résolution calculée.

Mutuellement exclusif avec --resolution.

-r, --resampling <METHODE>
Méthode de rééchantillonnage à utiliser. Les méthodes disponibles sont :

nearest : rééchantillonnage du voisin le plus proche (défaut, algorithme le plus rapide, qualité d'interpolation la plus faible).

bilinear : rééchantillonnage bilinéaire.

cubic : rééchantillonnage cubique.

cubicspline : rééchantillonnage par spline cubique.

lanczos : rééchantillonnage par fonction sinus cardinal fenêtrée de Lanczos.

average : rééchantillonnage par moyenne, calcule la moyenne pondérée de tous les pixels contributeurs non-NODATA.

SORTIE GDALG (DONNÉES À LA VOLÉE / EN FLUX)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données raster en utilisant le pilote GDALG : Algorithme GDAL en flux, et appliquer le pipeline spécifié de manière à la volée / en flux.

EXEMPLES

Exemple 1: Redimensionner un jeu de données à 1000 colonnes et 500 lignes en utilisant un rééchantillonnage cubique

$ gdal raster resize --size=1000,500 -r cubic in.tif out.tif --overwrite

Exemple 2: Redimensionner un jeu de données à moitié en utilisant un rééchantillonnage cubique

$ gdal raster resize --size=50%,50% -r cubic in.tif out.tif --overwrite
