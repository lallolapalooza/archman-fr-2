NOM

gdb-add-index - Ajoute des fichiers d'index pour accélérer GDB

SYNTAXE

gdb-add-index [-dwarf-5] nom_fichier

DESCRIPTION

Lorsque GDB trouve un fichier de symboles, il analyse les symboles dans le fichier afin de construire une table de symboles interne. Cela permet à la plupart des opérations GDB de fonctionner rapidement, au prix d'un délai initial. Pour les programmes volumineux, ce délai peut être assez long, GDB fournit donc un moyen de construire un index, ce qui accélère le démarrage.

Pour déterminer si un fichier contient un tel index, utilisez la commande "readelf -S nom_fichier" : l'index est stocké dans une section nommée ".gdb_index" (pré-DWARF 5) ou ".debug_names" et ".debug_str" (DWARF 5). Les index ne peuvent être produits que sur les systèmes utilisant des binaires ELF et des informations de débogage DWARF (c'est-à-dire des sections nommées ".debug_*").

Par défaut, gdb-add-index ajoutera une section ".gdb_index" pré-DWARF 5 à nom_fichier. Avec -dwarf-5, des sections DWARF 5 sont ajoutées à la place.

nom_fichier doit être inscriptible.

gdb-add-index utilise GDB, objcopy et readelf trouvés dans la variable d'environnement PATH. Si vous souhaitez utiliser différentes versions de ces programmes, vous pouvez les spécifier via les variables d'environnement appropriées (voir ci-dessous).

gdb-add-index se termine avec le statut 0 s'il réussit à créer l'index pour nom_fichier, ou supérieur à 0 si une erreur se produit.

Voir plus d'informations dans le manuel GDB, dans le nœud "Index Files" -- commande shell "info -f gdb -n "Index Files"".

OPTIONS

-dwarf-5
Ajoute des sections DWARF 5 au lieu de la section ".debug_index" précédente.

ENVIRONNEMENT

GDB
Nom de fichier complet du programme "gdb" à utiliser pour la génération d'index. S'il n'est pas défini, le PATH sera recherché pour un programme "gdb".
OBJCOPY
Nom de fichier complet du programme "objcopy" à utiliser pour copier les informations de section dans le fichier donné. S'il n'est pas défini, le PATH sera recherché pour un programme "objcopy".
READELF
Nom de fichier complet du programme "readelf" à utiliser pour inspecter les propriétés du fichier donné. S'il n'est pas défini, le PATH sera recherché pour un programme "readelf".

VOIR AUSSI

La documentation complète de GDB est maintenue sous forme de manuel Texinfo. Si les programmes "info" et "gdb" ainsi que la documentation Texinfo de GDB sont correctement installés sur votre site, la commande

info gdb

devrait vous donner accès au manuel complet.
