Nom

gdbus - Outil pour travailler avec les objets D-Bus

Syntaxe

gdbus introspect [--system | --session | --address adresse] --dest nom_bus --object-path /chemin/vers/objet [--xml] [--recurse] [--only-properties]
gdbus monitor [--system | --session | --address adresse] --dest nom_bus [--object-path /chemin/vers/objet]
gdbus call [--system | --session | --address adresse] --dest nom_bus --object-path /chemin/vers/objet --method org.projet.NomInterface.NomMethode [--timeout secondes | --interactive] [ARG…]
gdbus emit [--system | --session | --address adresse] --object-path /chemin/vers/objet --signal org.projet.NomInterface.NomSignal [--dest nom_bus_unique] [ARG…]
gdbus wait [--system | --session | --address adresse] --activate nom_bus [--timeout secondes] nom_bus
gdbus help

DESCRIPTION

gdbus est un outil simple pour travailler avec les objets D-Bus.

COMMANDES

introspect

Affiche les interfaces et les valeurs des propriétés d'un objet distant. Pour que cela fonctionne, le propriétaire de l'objet doit implémenter l'interface org.freedesktop.DBus.Introspectable. Si l'option --xml est utilisée, le XML d'introspection renvoyé est affiché, sinon une représentation analysée et formatée est affichée. L'option --recurse peut être utilisée pour introspecter les enfants (et leurs enfants et ainsi de suite) et l'option --only-properties peut être utilisée pour n'afficher que les interfaces avec des propriétés.

monitor

Surveille un ou tous les objets appartenant au propriétaire de nom_bus.

call

Invoque une méthode sur un objet distant. Chaque argument à passer à la méthode doit être spécifié comme un GVariant sérialisé, à l'exception des chaînes de caractères qui n'ont pas besoin de guillemets explicites. Les valeurs de retour sont affichées sous forme de valeurs GVariant sérialisées.

emit

Émet un signal. Chaque argument à inclure dans le signal doit être spécifié comme un GVariant sérialisé, à l'exception des chaînes de caractères qui n'ont pas besoin de guillemets explicites.

wait

Attend que nom_bus soit possédé par un processus sur le bus. Si --activate est spécifié, ce nom de bus sera démarré automatiquement en premier. Il peut être identique au nom de bus attendu, ou différent.

help

Affiche l'aide et quitte.

COMPLETION BASH

gdbus fournit un script de complétion bash pour compléter les commandes, les destinations, les noms de bus, les chemins d'objets et les noms d'interface/méthode.

EXEMPLES

Ceci montre comment introspecter un objet — notez que la valeur de chaque propriété est affichée :

$ gdbus introspect --system \
        --dest org.freedesktop.NetworkManager \
        --object-path /org/freedesktop/NetworkManager/Devices/0
node /org/freedesktop/NetworkManager/Devices/0 {
  interface org.freedesktop.DBus.Introspectable {
    methods:
      Introspect(out s data);
  };
  interface org.freedesktop.DBus.Properties {
    methods:
      Get(in  s interface,
          in  s propname,
          out v value);
      Set(in  s interface,
          in  s propname,
          in  v value);
      GetAll(in  s interface,
             out a{sv} props);
  };
  interface org.freedesktop.NetworkManager.Device.Wired {
    signals:
      PropertiesChanged(a{sv} arg_0);
    properties:
      readonly b Carrier = false;
      readonly u Speed = 0;
      readonly s HwAddress = '00:1D:72:88:BE:97';
  };
  interface org.freedesktop.NetworkManager.Device {
    methods:
      Disconnect();
    signals:
      StateChanged(u arg_0,
                   u arg_1,
                   u arg_2);
    properties:
      readonly u DeviceType = 1;
      readonly b Managed = true;
      readwrite o Ip6Config = '/';
      readwrite o Dhcp4Config = '/';
      readwrite o Ip4Config = '/';
      readonly u State = 2;
      readwrite u Ip4Address = 0;
      readonly u Capabilities = 3;
      readonly s Driver = 'e1000e';
      readwrite s Interface = 'eth0';
      readonly s Udi = '/sys/devices/pci0000:00/0000:00:19.0/net/eth0';
  };
};

Les options --recurse et --only-properties peuvent être utiles lorsque l'on souhaite inspecter tous les objets appartenant à un processus particulier :

$ gdbus introspect --system --dest org.freedesktop.UPower --object-path / --recurse  --only-properties
node / {
  node /org {
    node /org/freedesktop {
      node /org/freedesktop/UPower {
        interface org.freedesktop.UPower {
          properties:
            readonly b IsDocked = true;
            readonly b LidForceSleep = false;
            readonly b LidIsPresent = false;
            readonly b LidIsClosed = false;
            readonly b OnLowBattery = false;
            readonly b OnBattery = false;
            readonly b CanHibernate = true;
            readonly b CanSuspend = true;
            readonly s DaemonVersion = '0.9.10';
        };
        node /org/freedesktop/UPower/Policy {
        };
        node /org/freedesktop/UPower/Wakeups {
          interface org.freedesktop.UPower.Wakeups {
            properties:
              readonly b HasCapability = true;
          };
        };
      };
    };
  };
};

De même, la commande introspect peut être utilisée pour connaître les détails de la méthode Notify :

[…]
  interface org.freedesktop.Notifications {
    methods:
      GetServerInformation(out s return_name,
                           out s return_vendor,
                           out s return_version,
                           out s return_spec_version);
      GetCapabilities(out as return_caps);
      CloseNotification(in  u id);
      Notify(in  s app_name,
             in  u id,
             in  s icon,
             in  s summary,
             in  s body,
             in  as actions,
             in  a{sv} hints,
             in  i timeout,
             out u return_id);
  };
[…]

Avec ces informations, il est facile d'utiliser la commande call pour afficher une notification :

$ gdbus call --session \
             --dest org.freedesktop.Notifications \
             --object-path /org/freedesktop/Notifications \
             --method org.freedesktop.Notifications.Notify \
             mon_nom_app \
             42 \
             gtk-dialog-info \
             "Le Résumé" \
             "Voici le corps de la notification" \
             [] \
             {} \
             5000
(uint32 12,)

Appeler une méthode avec un argument de descripteur de fichier :

$ gdbus call --session \
             --dest org.example.foo \
             --object-path /org/example/foo \
             --method SendFDs \
             1 \
             10 \
             10<file.foo
