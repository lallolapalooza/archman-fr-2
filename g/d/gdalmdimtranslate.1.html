De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les particularités du fichier créé.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont pas d'options de création du tout. Une liste des options prises en charge pour un format peut être listée avec l' --format ligne de commande option mais la documentation du format est la source définitive d'informations sur les options de création du pilote. Effectue une opération de sous-ensemble (rognage ou découpe) le long d'une dimension, à condition qu'elle soit indexée par une variable 1D de type de données numérique ou chaîne de caractères, et dont les valeurs sont triées de manière monotonique. <spéc_subset> suit exactement l' OGC encodage KVP WCS 2.0 pour le sous-ensemble.
