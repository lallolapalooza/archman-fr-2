NOM

gdal-vector-index - Créer un index vectoriel de jeux de données vectorielles

Ajouté dans la version 3.12.

SYNTAXE

Les options suivantes sont disponibles :

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format vectoriel de sortie utiliser. Les valeurs autorisées peuvent être obtenues avec gdal --formats | grep vector | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression, et si le fichier doit être tuilé.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être obtenue avec l'option de ligne de commande --formats, mais la documentation du format est la source définitive d'information sur les options de création du pilote. Voir la documentation spécifique du format Pilotes raster pour les options de création légales pour chaque format.

-lco <NOM>=<VALEUR>
Option de création de couche (spécifique au format)
--overwrite
Autoriser le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal renvoie une erreur si le fichier ou le jeu de données cible existe déjà.
--update
Si le jeu de données de sortie doit être ouvert en mode mise à jour. Implique qu'il existe déjà.
--overwrite-layer
Si l'écrasement de la couche vectorielle de sortie existante est autorisé.
--append
Si l'ajout d'entités à la couche vectorielle de sortie existante est autorisé.
-l, --nln, --layer <COUCHE>
Fournit un nom pour la couche vectorielle de sortie.
--recursive
Si les répertoires d'entrée doivent être explorés récursivement.
--filename-filter <FILTRE-NOM-FICHIER>
Motif que les noms de fichiers contenus dans les répertoires d'entrée doivent suivre. Le caractère '*' est un caractère générique qui correspond à n'importe quel nombre de caractères, y compris aucun. Le caractère '?' est un caractère générique qui correspond à un seul caractère. Les comparaisons sont effectuées de manière insensible à la casse. Plusieurs filtres peuvent être spécifiés.

Par exemple : --filename-filter "*.shp,*.gpkg"

--location-name <NOM-EMPLACEMENT>
Le nom du champ de sortie qui contiendra le chemin d'accès/l'emplacement des vecteurs indexés. Le nom de champ par défaut est location.
--absolute-path
Le chemin absolu des fichiers vectoriels est stocké dans le fichier d'index. Par défaut, les noms de fichiers vectoriels seront placés dans le fichier tels quels tels qu'ils sont spécifiés dans la ligne de commande.
--dst-crs <CRS-DEST>
Les enveloppes des fichiers d'entrée seront transformées vers le système de référence de coordonnées de destination souhaité. Par défaut, des polygones rectangulaires simples sont créés dans le même système de référence de coordonnées que les vecteurs d'entrée.
--source-crs-field-name <NOM-CHAMP-CRS-SOURCE>
Le nom du champ pour stocker le CRS de chaque tuile. Ce nom de champ peut être utilisé comme valeur du mot-clé TILESRS dans MapServer.
--source-crs-format auto|WKT|EPSG|PROJ
Le format dans lequel le CRS de chaque tuile doit être écrit. Les types peuvent être auto, WKT, EPSG, PROJ. Cette option doit être utilisée conjointement avec --source-crs-field-name.
--source-layer-name <NOM-COUCHE-SOURCE>
Ajouter une couche nommée à partir de chaque fichier source dans l'index de tuiles.
--source-layer-index <INDEX-COUCHE-SOURCE>
Ajouter une couche d'index spécifié (base 0) à partir de chaque fichier source dans l'index de tuiles.
--accept-different-crs
Autoriser la création d'un index lorsque les couches des jeux de données d'entrée ont des CRS différents.
--accept-different-schemas
Autoriser la création d'un index lorsque les couches des jeux de données d'entrée ont des schémas différents.
--dataset-name-only
Écrire le nom du jeu de données seulement, au lieu de celui-ci suffixé avec l'index de la couche.
