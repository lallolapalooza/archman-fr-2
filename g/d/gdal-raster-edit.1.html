SYNOPSI

S 
Utilisation : gdal raster edit [OPTIONS] <DATASET>
Modifier un jeu de données raster.
Arguments positionnels :
  --dataset <DATASET>               Jeu de données (à mettre à jour sur place, sauf avec --auxiliary) [requis]
Options communes :
  -h, --help                        Afficher le message d'aide et quitter
  --json-usage                      Afficher l'utilisation sous
forme de document JSON et quitter --config <KEY>=<VALUE> Option de configuration [peut être répétée] -q, --quiet Mode silencieux (pas de barre de progression) Options : --auxiliary Demander la modification d'un fichier auxiliaire .aux.xml --crs <CRS> Remplacer le SCR (sans reprojection) --bb
ox <BBOX> Boîte englobante sous la forme xmin,ymin,xmax,ymax --nodata <NODATA> Assigner une valeur nodata spécifiée aux bandes de sortie ('none', valeur numérique, 'nan', 'inf', '-inf') --metadata <KEY>=<VALUE> Ajouter/mettre à jour un élément de métadonnées du jeu de données [peut être répété] --unset-metadata <KEY>
Supprimer un ou des éléments de métadonnées du jeu de données [peut être répété] --unset-metadata-domain <DOMAIN> Supprimer un ou des domaines de métadonnées du jeu de données [peut être répété] --gcp <GCP> Ajouter un point de contrôle au sol, formaté comme pixel,ligne,est,nord[,altitude], ou @nomdefichier [peut être répété] --stats
Calculer les statistiques, en utilisant tous les pixels Mutuellement exclusif avec --approx-stats --approx-stats Calculer les statistiques, en utilisant un sous-ensemble de pixels Mutuellement exclusif avec --stats --hist Calculer l'histogramme

--crs
<CRS>
Remplacer le SCR, sans reprojection.

Les systèmes de référence de coordonnées qui peuvent être passés sont tout ce qui est pris en charge par l'appel OGRSpatialReference::SetFromUserInput() , ce qui inclut les SCR EPSG projetés, géographiques ou composés (c'est-à-dire EPSG:4296), une définition de SCR en well known text (WKT), des déclarations PROJ.4, ou le nom d'un fichier .prj contenant une définition de SCR

WKT.

--gcp
<GCP>
Ajouté dans la version 3.12.

Définir des points de contrôle au sol, en remplaçant tout GCP existant. Chaque GCP doit être formaté sous la forme d'une chaîne "pixel,ligne,est,nord" ou "pixel,ligne,est,nord,altitude". Chaque GCP doit être spécifié avec un argument --gc

Il est également possible de fournir un seul --gcp dont la valeur est le nom de fichier d'un jeu de données vectoriel, préfixé par @. Ce jeu de données doit avoir une seule couche avec les champs requis suivants column, line, x, y, et éventuellement id, info et z
