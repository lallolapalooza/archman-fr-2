NOM

gdal - Point d'entrée principal de gdal

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal <COMMANDE> [OPTIONS]
où <COMMANDE> est l'une des suivantes :
  convert :  Convertit un jeu de données (raccourci pour 'gdal raster convert' ou 'gdal vector convert').
  dataset :  Commandes pour gérer les jeux de données.
  driver :   Commande pour les opérations spécifiques au pilote.
  info :     Retourne des informations sur un jeu de données (raccourci pour 'gdal raster info' ou 'gdal vector info').
  mdim :     Commandes multidimensionnelles.
  pipeline : Traite un jeu de données en appliquant plusieurs étapes.
  raster :   Commandes raster.
  vector :   Commandes vectorielles.
  vsi :      Commandes GDAL Virtual System Interface (VSI).
Options communes :
  -h, --help              Affiche le message d'aide et quitte
  --json-usage            Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>  Option de configuration [peut être répétée]
Options :
  --version               Affiche la version de GDAL et quitte
  --drivers               Affiche la liste des pilotes sous forme de document JSON
'gdal <NOMFICHIER>' peut également être utilisé comme raccourci pour 'gdal info <NOMFICHIER>'.
Et 'gdal read <NOMFICHIER> ! ...' comme raccourci pour 'gdal pipeline <NOMFICHIER> ! ...'.

EXEMPLES

Exemple 1 : Obtenir des informations sur le fichier utm.tif (avec sortie JSON)

$ gdal info utm.tif

Exemple 2 : Convertir le fichier utm.tif en raster GeoPackage

$ gdal convert utm.tif utm.gpkg

Exemple 3 : Obtenir des informations sur toutes les commandes et sous-commandes disponibles sous forme de document JSON.

$ gdal --json-usage

Exemple 4 : Obtenir la liste de tous les formats supportés par la construction GDAL actuelle, en texte brut

$ gdal --formats

Exemple 5 : Obtenir la liste de tous les formats supportés par la construction GDAL actuelle, au format JSON.

$ gdal --formats --json
