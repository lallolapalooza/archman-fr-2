NOM

gdal-raster-nodata-to-alpha - Remplace les valeurs de non-données par une bande alpha

Ajouté dans la version 3.12.

SYNTAXE

Usage: gdal raster nodata-to-alpha [OPTIONS] <ENTREE> <SORTIE>
Remplace les valeurs de non-données par une bande alpha.
Arguments positionnels :
  -i, --input <ENTREE>                                 Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster de sortie [requis]
Options courantes :
  -h, --help                                           Affiche le message d'aide et quitte
  --json-usage                                         Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>                              Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLE>=<VALEUR>                Option de création [peut être répétée]
  --overwrite                                          Autorise l'écrasement de la sortie existante
                                                       Mutuellement exclusif avec --append
  --append                                             Ajouter comme sous-jeu de données à la sortie existante
                                                       Mutuellement exclusif avec --overwrite
  --nodata <NODATA>                                    Remplace la valeur de non-données des bandes d'entrée (valeur numérique, 'nan', 'inf', '-inf') [peut être répétée]
Options avancées :
  --if, --input-format <FORMAT-ENTREE>                 Formats d'entrée [peut être répété]
  --oo, --open-option <CLE>=<VALEUR>                   Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster nodata-to-alpha ajoute une bande alpha basée sur les métadonnées de la valeur de non-données définies sur les bandes du jeu de données d'entrée.

S'il n'y a pas de valeur de non-données explicite sur le jeu de données d'entrée, il est possible de l'ajouter avec l'option --nodata.

Ce programme n'a aucun effet et peut être utilisé en toute sécurité si le jeu de données d'entrée n'a pas de valeur de non-données et que --nodata n'est pas spécifié.

Options

--nodata <NODATA>
Remplace la valeur de non-données des bandes d'entrée (valeur numérique, 'nan', 'inf', '-inf'). On peut spécifier une seule valeur ou autant de valeurs qu'il y a de bandes d'entrée. Lorsque plusieurs valeurs sont spécifiées, un pixel n'est considéré comme invalide que s'il correspond aux valeurs de non-données sur toutes les bandes.
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être tuilé.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être listée avec l'option de ligne de commande --formats, mais la documentation du format est la source définitive d'information sur les options de création du pilote. Voir la documentation spécifique au format des Pilotes raster pour les options de création valides pour chaque format.

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format de raster de sortie utiliser. Les valeurs autorisées peuvent être obtenues avec gdal --formats | grep raster | grep rw | sort
--ot, --datatype, --output-data-type <TYPE-DONNEES-SORTIE>
Type de données de sortie parmi Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.

SORTIE GDALG (EN TEMPS RÉEL / FLUX DE DONNÉES)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière temps réel / flux.

EXEMPLES

Exemple 1

$ gdal raster nodata-to-alpha input_with_nodata.tif output_with_alpha_band.tif
