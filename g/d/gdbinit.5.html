GDBINIT(5) Outils de développement GNU GDBINIT(5)

NOM

gdbinit - Scripts d'initialisation GDB

SYNTAXE

~/.config/gdb/gdbinit

~/.gdbinit

./.gdbinit

DESCRIPTION

Ces fichiers contiennent des commandes GDB à exécuter automatiquement au démarrage de GDB. Les lignes de contenu sont des séquences de commandes enregistrées, décrites dans le manuel GDB au nœud "Sequences" -- commande shell "info -f gdb -n Sequences".

Veuillez lire davantage dans le manuel GDB au nœud "Startup" -- commande shell "info -f gdb -n Startup".

(non activé avec "--with-system-gdbinit" lors de la compilation)
Fichier d'initialisation global. Il est exécuté à moins que l'utilisateur n'ait spécifié l'option GDB "-nx" ou "-n". Voir plus dans le manuel GDB au nœud "System-wide configuration" -- commande shell "info -f gdb -n 'System-wide configuration'".
(non activé avec "--with-system-gdbinit-dir" lors de la compilation)
Répertoire d'initialisation global. Tous les fichiers de ce répertoire sont exécutés au démarrage à moins que l'utilisateur n'ait spécifié l'option GDB "-nx" ou "-n", tant qu'ils ont une extension de fichier reconnue. Voir plus dans le manuel GDB au nœud "System-wide configuration" -- commande shell "info -f gdb -n 'System-wide configuration'".
~/.config/gdb/gdbinit ou ~/.gdbinit
Fichier d'initialisation utilisateur. Il est exécuté à moins que l'utilisateur n'ait spécifié les options GDB "-nx", "-n" ou "-nh".
.gdbinit
Fichier d'initialisation pour le répertoire courant. Il peut nécessiter d'être activé avec la commande de sécurité GDB "set auto-load local-gdbinit". Voir plus dans le manuel GDB au nœud "Init File in the Current Directory" -- commande shell "info -f gdb -n 'Init File in the Current Directory'".
