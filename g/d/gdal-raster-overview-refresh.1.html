DESCRIPTIO

N

gdal raster overview refresh peut être utilisé pour actualiser les surcouches existantes d'un jeu de données. Par défaut, toutes les surcouches sont actualisées, mais il est également possible de restreindre les surcouches actualisées par niveau et/ou

étendue.
--dataset
<DATASET>
Nom du jeu de données, à mettre à jour sur place par défaut (sauf si --external
est sp
écifié).

--resampling {nearest|average|cubic|cubicspline|lanczos|bilinear|gauss|average_magphase|rms|mo
de}
Sélectionner un algorithme de rééchantillonnage. La valeur par défaut est nearest, ce qui est généralement inapproprié si une précision sous-pixel est souhaitée.

Lors de l'actualisation des surcouches TIFF existantes, la méthode précédemment utilisée, telle qu'indiquée dans l'élément de métadonnées RESAMPLING de la surcouche, sera utilisée si -r n'est pas

spécifié.

Les méthodes disponibles

sont :

nearest applique un rééchantillonneur au plus proche voisin (échantillonnage

simple).

average calcule la moyenne de tous les pixels contributeurs non-NODATA. Il s'agit d'une moyenne pondérée prenant correctement en compte le poids des pixels sources ne contribuant pas totalement au pixel

cible.

bilinear applique un noyau de convolution

bilinéaire.

cubic applique un noyau de convolution

cubique.

cubicspline applique un noyau de convolution

B-Spline.

lanczos applique un noyau de convolution sinc fenêtré de

Lanczos.

gauss applique un noyau gaussien avant de calculer la surcouche, ce qui peut donner de meilleurs résultats qu'une simple moyenne, par ex. en cas de bords nets à fort contraste ou de motifs bruités. Les valeurs de niveau conseillées doivent être 2, 4, 8, ... afin qu'un noyau gaussien de rééchantillonnage 3x3 soit

sélectionné.

average_magphase fait la moyenne des données complexes dans l'espace

magnitude/phase.

rms calcule la moyenne quadratique / racine de la moyenne carrée de tous les pixels contributeurs

non-NODATA

mode sélectionne la valeur qui app

Cette option effectue une actualisation partielle des surcouches existantes, dans la région d'intérêt spécifiée par un ou plusieurs noms de fichiers (noms séparés par des virgules). Notez que les noms de fichiers ne sont utilisés que pour déterminer les régions d'intérêt à actualiser. Les pixels sources de référence sont ceux du jeu de données principal.
