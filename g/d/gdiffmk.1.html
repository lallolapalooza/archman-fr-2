gdiffmk(1) Manuel des commandes générales gdiffmk(1)

Nom

gdiffmk - marquer les différences entre fichiers groff/nroff/troff

Synopsis

gdiffmk [-a marque-ajout] [-c marque-changement] [-d marque-suppression] [-x commande-diff] [-D [-B] [-M marque1 marque2]] [--] fichier1 fichier2 [sortie]
gdiffmk --help
gdiffmk --version

Description

gdiffmk compare deux documents roff(7), fichier1 et fichier2, et crée un document roff constitué de fichier2 avec des requêtes de caractères de marge (.mc) ajoutées indiquant les lignes de sortie qui diffèrent de fichier1. Si l'argument fichier1 ou fichier2 est “-”, gdiffmk lit le flux d'entrée standard pour cette entrée. Si l'opérande sortie est présent, gdiffmk écrit la sortie dans un fichier de ce nom. S'il est “-” ou absent, gdiffmk écrit la sortie sur le flux de sortie standard. “-” ne peut pas être un opérande d'entrée et de sortie simultanément.

Options

--help affiche un message d'utilisation et --version affiche les informations de version ; les deux se terminent ensuite.

-a marque-ajout
Utilise marque-ajout pour les lignes sources qui ne sont pas dans fichier1 mais présentes dans fichier2. Par défaut : “+”.
-B
Par défaut, les textes supprimés marqués par l'option -D se terminent par une requête de saut de ligne roff ajoutée, .br, pour garantir que les suppressions sont correctement marquées. C'est la seule façon de garantir que les suppressions et les petits changements sont signalés. Cette option demande au programme de ne pas insérer ces sauts ; elle n'a pas de sens sans -D.
-c marque-changement
Utilise marque-changement pour les lignes sources modifiées. Par défaut : “|”.
-d marque-suppression
Utilise marque-suppression pour les lignes sources supprimées. Par défaut : “*”.
-D
Affiche les portions supprimées du texte modifié et supprimé.
-M marque1 marque2
Modifie les marques délimitant pour l'option -D. Il n'a pas de sens d'utiliser cette option sans -D. Marques délimitant par défaut : “[[” ... “]]”.
-x commande-diff
Utilise la commande commande-diff pour effectuer la comparaison de fichier1 et fichier2. En particulier, commande-diff doit accepter l'option -D de GNU diff(1). Par défaut : diff.
--
Traite tous les arguments suivants comme des noms de fichiers, même s'ils commencent par “-”.

Bugs

La sortie n'est pas nécessairement compatible avec tous les packages de macros et tous les préprocesseurs. Une solution de contournement qui résout souvent les problèmes de préprocesseur consiste à exécuter gdiffmk sur la sortie de tous les préprocesseurs au lieu de la source d'entrée.

gdiffmk s'appuie sur l'option -D de GNU diff pour créer un format de sortie fusionné “#ifdef”. Il est connu que le diff de Busybox ne la prend pas en charge. Voir également l'option -x commande-diff.

Auteurs

gdiffmk a été écrit par Mike Bianchi, maintenant retraité. Il est maintenu par les développeurs de groff.
