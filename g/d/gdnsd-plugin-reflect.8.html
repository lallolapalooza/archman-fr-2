NOM

gdnsd-plugin-reflect - plugin de réflexion de cache gdnsd

SYNOPSIS

RR de fichier de zone utilisant la résolution reflect

reflect      10 DYNA reflect
reflect-dns  10 DYNA reflect!dns
reflect-edns 10 DYNA reflect!edns
reflect-both 10 DYNA reflect!both
reflect-best 10 DYNA reflect!best

DESCRIPTION

gdnsd-plugin-reflect est un plugin de résolution qui sert d'outil de débogage en direct. Il reflète une vue de l'adresse réseau du client dans la réponse sous forme de RR "A" ou "AAAA". Il peut être utilisé avec les RR "DYNA" et "DYNC", et retournera des données d'adresse dans les deux cas.

Le plugin peut fonctionner dans l'un des quatre modes nommés "dns", "edns", "both", et "best", qui peuvent être sélectionnés en utilisant le nom du mode comme nom de ressource dans le fichier de zone, comme le montre l'exemple ci-dessus. Le mode par défaut est "best". Les modes fonctionnent comme suit :

dns
En mode "dns", l'adresse dans la réponse est toujours l'adresse IP source de la requête telle que vue par gdnsd. Notez qu'il s'agit généralement de l'adresse publique d'un serveur cache/résolveur central plutôt que du client utilisateur final lui-même.
edns
En mode "edns", l'adresse dans la réponse est l'adresse envoyée par le client dans l'option "edns-client-subnet". Si le client n'a pas envoyé une telle option, l'adresse IPv4 0.0.0.0 est retournée.
both
En mode "both", les deux résultats ci-dessus sont retournés dans la même réponse, mais aucun 0.0.0.0 artificiel n'est ajouté si aucune option "edns-client-subnet" n'était disponible.
best
En mode "best" (par défaut), si l'option "edns-client-subnet" a été spécifiée, ses données sont retournées comme dans le cas "edns", sinon l'adresse IP source est retournée comme dans le cas "dns".
