NOM

gdal-raster-set-type - Modifier le type de données des bandes d'un jeu de données raster

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal raster set-type [OPTIONS] <ENTRÉE> <SORTIE>
Modifier le type de données des bandes d'un jeu de données raster.
Arguments positionnels :
  -i, --input <ENTRÉE>                                     Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                    Jeu de données raster de sortie [requis]
Options courantes :
  -h, --help                                               Afficher le message d'aide et quitter
  --json-usage                                             Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLÉ>=<VALEUR>                                   Option de configuration [peut être répétée]
  -q, --quiet                                              Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>      Format de sortie (« GDALG » autorisé)
  --co, --creation-option <CLÉ>=<VALEUR>                    Option de création [peut être répétée]
  --overwrite                                              Autoriser l'écrasement des sorties existantes
                                                           Mutuellement exclusif avec --append
  --append                                                 Ajouter en tant que sous-ensemble à la sortie existante
                                                           Mutuellement exclusif avec --overwrite
  --ot, --datatype, --output-data-type <TYPE-DONNÉES-SORTIE>  Type de données de sortie. TYPE-DONNÉES-SORTIE=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64 [requis]
Options avancées :
  --if, --input-format <FORMAT-ENTRÉE>                      Formats d'entrée [peuvent être répétés]
  --oo, --open-option <CLÉ>=<VALEUR>                        Options d'ouverture [peuvent être répétées]

DESCRIPTION

gdal raster set-type peut être utilisé pour forcer les bandes d'image de sortie à avoir un type de données spécifique. Les valeurs peuvent être tronquées ou arrondies si le type de données de sortie est « plus petit » que celui d'entrée.

Cette sous-commande est également disponible comme étape potentielle du pipeline raster gdal

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format raster de sortie utiliser. Les valeurs autorisées peuvent être obtenues par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression, et si le fichier doit être tuilé.

Peut être répété.

Les options de création disponibles varient selon le pilote du format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être listée avec l'option de ligne de commande --formats, mais la documentation du format est la source d'information définitive sur les options de création du pilote. Voir la documentation spécifique au format Pilotes raster pour les options de création légales pour chaque format.

--overwrite
Autoriser le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal signale une erreur si le fichier ou le jeu de données cible existe déjà.
--ot, --datatype, --output-data-type <TYPE-DONNÉES-SORTIE>
Type de données de sortie parmi Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.

SORTIE GDALG (À LA VOLÉE / FLUXÉ DATASET)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière à la volée / fluxée.

EXEMPLES

Exemple 1 : Conversion en type de données Float32

$ gdal raster set-type --datatype Float32 byte.tif float32.tif --overwrite
