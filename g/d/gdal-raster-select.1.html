DESCRIPTIO

N

gdal raster select peut être utilisé pour sélectionner et réordonner un sous-ensemble de bandes raster d'un jeu de données

raster.

Cette sous-commande est également disponible en tant qu'étape potentielle de gdal raster

pipeline

--band
<BAND>
Sélectionner une ou plusieurs bandes d'entrée. Les bandes sont numérotées à partir de 1. Plusieurs valeurs peuvent être sélectionnées pour choisir un ensemble de bandes d'entrée à écrire dans le fichier de sortie, ou pour réordonner les bandes. La valeur spéciale mask signifie la bande de masque de la première bande du jeu de données d'entrée. La bande de masque de n'importe quelle bande peut être spécifiée avec mask:<band>. Une bande de masque sélectionnée avec --band deviendra une bande o

--mask
<BAND>
Sélectionner une bande d'entrée pour créer la bande de masque du jeu de données de sortie. Les bandes sont numérotées à partir de 1. La valeur spéciale mask signifie la bande de masque de la première bande du jeu de données d'entrée. La bande de masque de n'importe quelle bande peut être spécifiée avec mask:<band>. <BAND> peut être défini à none pour éviter de copier le masque global du jeu de données d'entrée s'il existe. Sinon, il est copié par défaut, sauf si le masque est un canal alpha, ou s'il est explicitement sélectionné comme bande régulière du jeu de données de sortie (--b

S

Exemple 1 : Réordonner un jeu de données à 3 bandes avec les bandes ordonnées Bleu, Vert, Rouge en Rouge, Vert,

Bleu 
$ gdal raste
r select --b
and 3,2,1 bgr
.tif rgb.tif
--overwrite

YCbCR 
$ gdal raster sel

--mask 4 --co CO

METRIC=YCBCR rgba
.tif rgb_mask.tif
