Utilisation : gdal pipeline [OPTIONS] <PIPELINE> Traiter un jeu de données en appliquant plusieurs étapes. Arguments positionnels : Options courantes : -h, --help Afficher le message d'aide et quitter --json-usage Afficher l'utilisation sous forme de document JSON et quitter --config <KEY>=<VALUE> Option de configuration [peut être répétée] -q, --quiet Mode silencieux (pas de barre de progression) Options avancées : --<user-provided-option>=<value> Argument fourni par l'utilisateur <PIPELINE> est de la forme : read|calc|concat|mosaic|stack [READ-OPTIONS] ( ! <STEP-NAME> [STEP-OPTIONS] )* ! write!info!tile

[WRITE-OPTIONS]

* grid <COMMAND> [OPTIONS] -------------------------- où <COMMAND> est l'une des suivantes : - average: Créer une grille régulière à partir de points dispersés en utilisant l'interpolation par moyenne mobile. - average-distance: Créer une grille régulière à partir de points dispersés en utilisant la distance moyenne entre le nœud de grille (centre de l'ellipse de recherche) et tous les points de données dans l'ellipse de recherche. - average-distance-points: Créer une grille régulière à partir de points dispersés en utilisant la distance moyenne entre les points de données dans l'ellipse de recherche. - count: Créer une grille régulière à partir de points dispersés en utilisant le nombre de points dans l'ellipse de recherche. - invdist: Créer une grille régulière à partir de points dispersés en utilisant l'interpolation par distance inverse pondérée. - invdistnn: Créer une grille régulière à partir de points dispersés en utilisant l'interpolation par
distance inverse pondérée plus proche voisin. - linear: Créer une grille régulière à partir de points dispersés en utilisant l'interpolation linéaire/barycentrique. - maximum: Créer une grille régulière à partir de points dispersés
en utilisant la valeur maximale dans l'ellipse de recherche. - minimum: Créer une grille régulière à partir de points dispersés en utilisant la valeur minimale dans l'ellipse de recherche. - nearest: Créer une grille régulière
à partir de points dispersés en utilisant l'interpolation par plus proche voisin. - range: Créer une grille régulière à partir de points dispersés en utilisant la différence entre les valeurs minimale et maximale dans l'ellipse de recherche.

Exemple 5 : Calculer l'empreinte d'un raster et appliquer un tampon sur l'empreinte

Exemple 6 : Rastériser et reprojeter

$ gdal pipeline ! read in.gpkg ! rasterize --size 1000,1000 ! reproject --dst-crs EPSG:4326 ! write out.tif --overwrite

Exemple 7 : Utiliser un pipeline existant qui rastérise et reprojette, mais changer son fichier d'entrée et son CRS cible, et spécifier le fichier de sortie

$ gdal pipeline raster_reproject.gdalg.json --input=my.gpkg --output=out.tif --dst-crs=EPSG:32631
