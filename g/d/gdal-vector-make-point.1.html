NOM

gdal vector make-point - Créer des entités ponctuelles à partir de champs d'attributs

Ajouté dans la version 3.12.

SYNTAXE

Usage: gdal vector make-point [OPTIONS] <INPUT> <OUTPUT>
Créer des géométries ponctuelles à partir de champs d'attributs
Arguments positionnels :
  -i, --input <INPUT>                                  Jeux de données vectoriels d'entrée [requis]
  -o, --output <OUTPUT>                                Jeu de données vectorielles de sortie [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <KEY>=<VALUE>                               Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -l, --layer, --input-layer <INPUT-LAYER>             Nom(s) de la couche d'entrée [peut être répété]
  -f, --of, --format, --output-format <OUTPUT-FORMAT>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <KEY>=<VALUE>                Option de création [peut être répétée]
  --lco, --layer-creation-option <KEY>=<VALUE>         Option de création de couche [peut être répétée]
  --overwrite                                          Autoriser l'écrasement de la sortie existante
  --update                                             Ouvrir le jeu de données existant en mode mise à jour
  --overwrite-layer                                    Autoriser l'écrasement de la sortie existante
  --append                                             Ajouter à la couche existante
                                                       Mutuellement exclusif avec --upsert
  --output-layer <OUTPUT-LAYER>                        Nom de la couche de sortie
  --skip-errors                                        Ignorer les erreurs lors de l'écriture des entités
  --x <X>                                              Champ à partir duquel la coordonnée X doit être lue [requis]
  --y <Y>                                              Champ à partir duquel la coordonnée Y doit être lue [requis]
  --z <Z>                                              Champ optionnel à partir duquel la coordonnée Z doit être lue
  --m <M>                                              Champ optionnel à partir duquel la coordonnée M doit être lue
  --dst-crs <DST-CRS>                                  CRS de destination
Options avancées :
  --if, --input-format <INPUT-FORMAT>                  Formats d'entrée [peut être répété]
  --oo, --open-option <KEY>=<VALUE>                    Options d'ouverture [peut être répétée]
  --output-oo, --output-open-option <KEY>=<VALUE>      Options d'ouverture de sortie [peut être répétée]
  --upsert                                             Mettre à jour/insérer des entités (implique 'append')
                                                       Mutuellement exclusif avec --append

DESCRIPTION

gdal vector make-point crée des géométries ponctuelles à partir de champs d'attributs contenant des coordonnées.

OPTIONS

--x <NOM_CHAMP>
Nom du champ contenant les valeurs de coordonnées X
--y <NOM_CHAMP>
Nom du champ contenant les valeurs de coordonnées Y
--z <NOM_CHAMP>
Nom du champ optionnel contenant les valeurs de coordonnées Z
--m <NOM_CHAMP>
Nom du champ optionnel contenant les valeurs de coordonnées M
--dst-crs <CRS>
Système de référence de coordonnées optionnel à attribuer aux points créés. Les systèmes de référence de coordonnées qui peuvent être passés sont tous ceux pris en charge par l'appel OGRSpatialReference::SetFromUserInput(), ce qui inclut les CRS projetés, géographiques ou composés EPSG (c'est-à-dire EPSG:4296), une définition de CRS en texte bien connu (WKT), des déclarations PROJ.4, ou le nom d'un fichier .prj contenant une définition de CRS WKT.
