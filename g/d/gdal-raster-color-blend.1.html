NOM

gdal-raster-color-blend - Utiliser une image en niveaux de gris pour remplacer l'intensité d'un jeu de données RVB/RVBA

Ajouté dans la version 3.12.

SYNOPSIS

Usage: gdal raster blend [OPTIONS] <COULEUR-ENTREE> <RECOUVREMENT> <SORTIE>
Mélange/compose deux jeux de données raster
Arguments positionnels :
  -i, --color-input, --input <COULEUR-ENTREE>             Jeu de données d'entrée [requis]
  --overlay <RECOUVREMENT>                               Jeu de données de recouvrement [requis]
  -o, --output <SORTIE>                                  Jeu de données de sortie [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLE>=<VALEUR>                                Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLE>=<VALEUR>                Option de création [peut être répétée]
  --overwrite                                          Autoriser l'écrasement des sorties existantes
                                                       Mutuellement exclusif avec --append
  --append                                             Ajouter en tant que sous-jeu de données à la sortie existante
                                                       Mutuellement exclusif avec --overwrite
  --operator <OPERATEUR>                                Opérateur de composition. OPERATEUR=src-over|hsv-value (par défaut: src-over)
  --opacity <OPACITE>                                  Pourcentage d'opacité à appliquer au jeu de données de recouvrement (0=entièrement transparent, 100=utilisation complète de l'opacité du recouvrement) (par défaut: 100)
Options avancées :
  --if, --input-format <FORMAT-ENTREE>                 Formats d'entrée [peut être répété]
  --oo, --open-option <CLE>=<VALEUR>                    Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster blend permet à l'utilisateur de composer deux jeux de données raster (de même taille) en utilisant une opération de mélange sélectionnée et un réglage d'opacité.

Ceci peut être utilisé par exemple pour coloriser une image d'ombre de relief générée par gdal raster hillshade avec un rendu hypsométrique d'un MNT généré par gdal raster color-map lors de l'utilisation de l'opérateur de mélange hsv-value.

L'opérateur de mélange plus standard src-over, qui effectue un "mélange alpha", est également disponible.

Cette sous-commande est également disponible comme étape potentielle de gdal raster pipeline.

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format de sortie raster utiliser. Les valeurs autorisées peuvent être obtenues par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être segmenté.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être affichée avec l'option de ligne de commande --formats mais la documentation du format est la source d'information définitive sur les options de création du pilote. Voir la documentation spécifique au format des Pilotes Raster pour les options de création légales pour chaque format.

--overwrite
Autorise le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
--input <ENTREE>
Nom du jeu de données dans lequel mélanger le jeu de données de recouvrement. Requis.

Lors de l'utilisation de l'opérateur de mélange hsv-value, il doit s'agir d'un raster Byte à trois ou quatre bandes.

--overlay <GRIS>
Nom du jeu de données de recouvrement. Requis.
--operator src-over|hsv-value
Sélectionne l'opérateur de mélange, qui définit comment le jeu de données de recouvrement est mélangé au jeu de données d'entrée. Par défaut, src-over.
  • src-over effectue un mélange alpha standard, en composant le jeu de données de recouvrement sur le jeu de données d'entrée.

    Étant donné overlay_{C} la valeur d'un des composants rouge, vert ou bleu du jeu de données de recouvrement, overlay_{A} la valeur du composant alpha du jeu de données de recouvrement, input_{C} la valeur du composant correspondant du jeu de données d'entrée, input_{A} la valeur du composant alpha du jeu de données d'entrée et opacity, la valeur de --opacity, le composant résultant output_{C} est (toutes les valeurs normalisées à la plage [0,1]) :


    output_{C} * output_{A} = (overlay_{C} * overlay_{A} * opacity) + (input_{C} * input_{A} * (1 - overlay_{A} * opacity))

    avec


    output_{A} = (overlay_{A} * opacity) + (input_{A} * (1 - overlay_{A} * opacity))

  • hsv-value crée une couleur avec la valeur du recouvrement et la teinte et la saturation de l'entrée. Il effectue les étapes suivantes :
  • lire les composantes RVB (Rouge, Vert, Bleu) du jeu de données d'entrée
  • transformer les composantes RVB dans l'espace colorimétrique HSV (Teinte, Saturation, Valeur)
  • calculer la valeur de sortie output_{V}, à partir de input_{V} la valeur d'entrée calculée à l'étape précédente, overlay_{V} la valeur du recouvrement, overlay_{A} la valeur du composant alpha du jeu de données de recouvrement et opacity, la valeur de --opacity (toutes les valeurs normalisées à la plage [0,1]) :


    output_{V} = (overlay_{V} * overlay_{A} * opacity) + (input_{V} * (1 - overlay_{A} * opacity))

    Si le jeu de données de recouvrement est un jeu de données RVB/RVBA, overlay_{V} est max(overlay_{R},overlay_{G},overlay_{B}).

  • retransformer (Teinte, Saturation, :math:output_{V}) en RVB.

Si le canal alpha du jeu de données d'entrée est présent, il est conservé inchangé.

--opacity <OPACITE>
Opacité à utiliser lors du mélange du jeu de données de recouvrement, en pourcentage entre 0 et 100. 0 signifie que le jeu de données de recouvrement est considéré comme entièrement transparent. 100 signifie que le jeu de données de recouvrement est mélangé au maximum de son canal alpha. Par défaut, 100.

SORTIE GDALG (TEMPS RÉEL / DONNÉES EN FLUX)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière temps réel / en flux.
