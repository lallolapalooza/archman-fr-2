NOM

gdal-raster-overview-delete - Supprimer les vues d'ensemble d'un jeu de données raster

Ajouté dans la version 3.11.

SYNOPIS

Utilisation : gdal raster overview delete [OPTIONS] <DATASET>
Suppression des vues d'ensemble.
Arguments positionnels :
  --dataset <DATASET>                Jeu de données (à mettre à jour sur place, sauf si --read-only) [obligatoire]
Options communes :
  -h, --help                         Afficher le message d'aide et quitter
  --json-usage                       Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLE>=<VALEUR>             Option de configuration [peut être répétée]
  -q, --quiet                        Mode silencieux (pas de barre de progression)
Options :
  --external                         Supprimer les vues d'ensemble externes
Options avancées :
  --oo, --open-option <CLE>=<VALEUR>  Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster overview delete peut être utilisé pour supprimer toutes les vues d'ensemble existantes d'un jeu de données.

NOTE :

Pour la plupart des formats de fichiers (y compris GeoTIFF ou GeoPackage), l'espace précédemment occupé par les vues d'ensemble supprimées peut ne pas être récupéré. Il peut être nécessaire d'utiliser gdal raster convert pour créer un nouveau jeu de données compact.
--dataset <DATASET>
Nom du jeu de données, à mettre à jour sur place par défaut (sauf si --external est spécifié). Obligatoire.
--external
Supprimer les vues d'ensemble externes .ovr.

EXEMPLES

Exemple 1 : Supprimer les vues d'ensemble d'un fichier GeoTIFF.

gdal raster overview delete my.tif
