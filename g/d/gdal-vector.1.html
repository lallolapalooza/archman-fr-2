NOM

gdal-vector - Point d'entrée pour les commandes vectorielles

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal vector <SOUS-COMMANDE> [OPTIONS]
où <SOUS-COMMANDE> est l'une des suivantes :
  - buffer:              Calcule un tampon autour des géométries d'un jeu de données vectoriel.
  - check-coverage:      Vérifie la validité d'une couverture polygonale
  - check-geometry:      Vérifie un jeu de données pour des géométries invalides
  - clean-coverage:      Modifie les frontières des polygones pour rendre les arêtes communes identiques, supprimant les trous et les chevauchements
  - clip:                Découpe un jeu de données vectoriel.
  - concat:              Concatène des jeux de données vectoriels.
  - convert:             Convertit un jeu de données vectoriel.
  - edit:                Modifie les métadonnées d'un jeu de données vectoriel.
  - explode-collections: Explose les géométries de type collection d'un jeu de données vectoriel.
  - filter:              Filtre un jeu de données vectoriel.
  - grid:                Crée une grille régulière à partir de points dispersés.
  - index:               Crée un index vectoriel de jeux de données vectoriels.
  - info:                Retourne des informations sur un jeu de données vectoriel.
  - layer-algebra:       Effectue une opération algébrique entre 2 couches.
  - make-point:          Crée des géométries ponctuelles à partir de champs d'attributs
  - make-valid:          Corrige la validité des géométries d'un jeu de données vectoriel.
  - partition:           Partitionne un jeu de données vectoriel en plusieurs fichiers.
  - pipeline:            Traite un jeu de données vectoriel en appliquant plusieurs étapes.
  - rasterize:           Vectorise des géométries vectorielles dans un raster.
  - reproject:           Reprojette un jeu de données vectoriel.
  - segmentize:          Segmentize les géométries d'un jeu de données vectoriel.
  - select:              Sélectionne un sous-ensemble de champs d'un jeu de données vectoriel.
  - set-field-type:      Modifie le type d'un champ d'un jeu de données vectoriel.
  - set-geom-type:       Modifie le type de géométrie d'un jeu de données vectoriel.
  - simplify:            Simplifie les géométries d'un jeu de données vectoriel.
  - simplify-coverage:   Simplifie les frontières communes d'un jeu de données vectoriel polygonal.
  - sql:                 Applique une ou plusieurs instructions SQL à un jeu de données.
  - swap-xy:             Inverse les coordonnées X et Y des géométries d'un jeu de données vectoriel.
Options communes :
  -h, --help              Affiche le message d'aide et quitte
  --json-usage            Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>  Option de configuration [peut être répétée]
Options :
  --drivers               Affiche la liste des pilotes vectoriels sous forme de document JSON et quitte

EXEMPLES

Exemple 1 : Obtenir des informations sur le fichier poly.gpkg (avec sortie JSON)

$ gdal vector info poly.gpkg

Exemple 2 : Convertir le fichier poly.gpkg en Esri File Geodatabase

$ gdal vector convert --format=OpenFileGDB poly.gpkg poly.gdb
