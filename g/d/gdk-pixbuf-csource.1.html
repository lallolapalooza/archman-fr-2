Nom

gdk-pixbuf-csource - utilitaire de génération de code C pour les images GdkPixbuf

Syntaxe

gdk-pixbuf-csource [OPTIONS...] <IMAGE>

Description

gdk-pixbuf-csource est un petit utilitaire qui génère du code C contenant des images, utile pour compiler des images directement dans les programmes.

gdk-pixbuf-csource prend en entrée soit le nom d'un fichier image pour lequel générer du code, soit, en utilisant l'option --build-list, une liste de paires (nom, image) pour générer du code pour une liste d'images dans des variables nommées.

Cet outil est principalement destiné à des fins de compatibilité ascendante. Les nouvelles applications et bibliothèques devraient utiliser GResource pour intégrer des ressources d'image dans leur binaire.

Options

--stream

Génère un flux de données pixbuf : une seule chaîne contenant une structure GdkPixdata sérialisée en ordre d'octets réseau.

--struct

Génère une structure GdkPixdata ; votre code a besoin de la définition de structure GdkPixdata de gdk-pixdata.h.

--macros

Génère des définitions de macro *_ROWSTRIDE, *_WIDTH, *_HEIGHT, *_BYTES_PER_PIXEL et *_RLE_PIXEL_DATA ou *_PIXEL_DATA pour l'image.

--rle

Active le codage par longueur de série pour les données pixelisées générées (par défaut).

--raw

Désactive le codage par longueur de série pour les données pixelisées générées.

--extern

Génère des symboles externes.

--static

Génère des symboles statiques (par défaut).

--decoder

Fournit une définition de macro *_RUN_LENGTH_DECODE(image_buf, rle_data, size, bpp) pour décoder les données d'image codées par longueur de série.

--name=identificateur

Spécifie le nom de l'identificateur (préfixe) pour les variables ou macros générées (utile uniquement si --build-list n'a pas été spécifié).

--build-list

Active le mode d'analyse des paires (nom, image).

-h, --help

Affiche une aide succincte et quitte.

-v, --version

Affiche la version de l'outil et quitte.

--g-fatal-warnings

Traite les avertissements comme des erreurs fatales et provoque l'arrêt du programme.

Voir aussi

La documentation de GdkPixbuf, fournie par gdk-pixbuf, et également disponible en ligne sur docs.gtk.org https://docs.gtk.org/gdk-pixbuf/.

Bogues

L'encodeur par longueur de série perd la synchronisation avec les limites de pixels, car il inclut le remplissage de la stride de ligne dans le flux encodé. De plus, il génère des pixbufs avec une stride de ligne sous-optimale dans certains cas.
