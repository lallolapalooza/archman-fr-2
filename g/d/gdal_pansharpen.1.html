gdal_pansharpen(1)

Paquet: gdal

Licences: custom

GDAL_PANSHARPEN(1) GDAL GDAL_PANSHARPEN(1)

NOM

gdal_pansharpen - Effectue une opération de pan-sharpening.

SYNTAXE

gdal_pansharpen [--help] [--help-general]
                <dataset_pan>
                <dataset_spectral>[,band=<num>] [<dataset_spectral>[,band=<num>]]...
                <dataset_sortie>
                [-of <format>] [-b <band>]... [-w <val_poids>]...
                [-r {nearest|bilinear|cubic|cubicspline|lanczos|average}]
                [-threads {ALL_CPUS|<nombre>}] [-bitdepth <val>] [-nodata <val>]
                [-spat_adjust {union|intersection|none|nonewithoutwarning}]
                [-co <NOM>=<VALEUR>]... [-q]

DESCRIPTION

gdal_pansharpen effectue une opération de pan-sharpening. Il peut créer un jeu de données de sortie « classique » (tel que GeoTIFF), ou un jeu de données VRT décrivant l'opération de pan-sharpening.

Plus de détails peuvent être trouvés dans la section VRT Pan-sharpened.

NOTE :

gdal_pansharpen est un utilitaire Python, et n'est disponible que si les liaisons Python de GDAL sont disponibles.
--help
Affiche ce message d'aide et quitte.
--help-general
Donne un bref message d'utilisation pour les options génériques de la ligne de commande GDAL et quitte.
-of <format>
Sélectionne le format de sortie. Si non spécifié, le format est deviné à partir de l'extension. Utiliser le nom court du format. VRT peut également être utilisé.
-b <bande>
Sélectionne la bande bande parmi les bandes spectrales d'entrée pour la sortie. Les bandes sont numérotées à partir de 1 dans l'ordre où les bandes spectrales sont spécifiées. Plusieurs options -b peuvent être utilisées. Lorsque aucune option -b n'est utilisée, toutes les bandes spectrales d'entrée sont définies pour la sortie.
-w <val_poids>
Spécifie un poids pour le calcul de la valeur panchromatique pseudo-intense. Il doit y avoir autant d'options -w que de bandes spectrales d'entrée.
-r {nearest|bilinear|cubic|cubicspline|lanczos|average}
Sélectionne un algorithme de rééchantillonnage. cubic est la valeur par défaut.
-threads {ALL_CPUS|<nombre>}
Spécifie le nombre de threads à utiliser pour le rééchantillonnage et le pan-sharpening lui-même. Peut être un nombre entier ou ALL_CPUS.
-bitdepth <val>
Spécifie la profondeur de bits des bandes panchromatiques et spectrales (par exemple, 12). Si non spécifiée, l'élément de métadonnées NBITS de la bande panchromatique sera utilisé s'il existe.
-nodata <val>
Spécifie la valeur de données nulles pour les bandes. Utilisé pour le calcul du rééchantillonnage et du pan-sharpening lui-même. Si non défini, il est déduit des bandes d'entrée, à condition qu'elles aient une configuration cohérente.
-spat_adjust {union|intersection|none|nonewithoutwarning}
Sélectionne le comportement lorsque les bandes n'ont pas la même étendue. Voir la documentation SpatialExtentAdjustment dans VRT Pan-sharpened. union est la valeur par défaut.
-co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler des détails du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être tuilé.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être listée avec l'option de ligne de commande --format, mais la documentation du format est la source d'information définitive sur les options de création du pilote. Voir la documentation spécifique du format Pilotes raster pour les options de création légales pour chaque format.

-q
Supprime le moniteur de progression et les autres sorties non-erronées.
<dataset_pan>
Jeu de données avec bande panchromatique (la première bande sera utilisée).
<dataset_spectral>[,band=<num>]
Jeu de données avec une ou plusieurs bandes spectrales. Si l'option de bande n'est pas spécifiée, toutes les bandes des jeux de données sont prises en compte. Sinon, seule la bande spécifiée (num) est prise en compte. Le même jeu de données peut être répété plusieurs fois.
<dataset_sortie>
Jeu de données de sortie.

Les bandes doivent être dans la même projection.

EXEMPLE

Exemple 1 : Avec des bandes spectrales dans un seul jeu de données

gdal_pansharpen panchro.tif multispectral.tif pansharpened_out.tif

Exemple 2 : Avec quelques bandes spectrales d'un seul jeu de données, réordonnées

gdal_pansharpen panchro.tif multispectral.tif,band=3 multispectral.tif,band=2 multispectral.tif,band=1 pansharpened_out.tif

Exemple 3 : Avec des bandes spectrales dans plusieurs jeux de données

gdal_pansharpen panchro.tif band1.tif band2.tif band3.tif pansharpened_out.tif

Exemple 4 : Spécification des poids

gdal_pansharpen -w 0.7 -w 0.2 -w 0.1 panchro.tif multispectral.tif pansharpened_out.tif

Exemple 5 : Spécifier les bandes RVB d'un jeu de données multispectral RVBNir tout en calculant l'intensité panchromatique pseudo sur les 4 bandes RVBNir

gdal_pansharpen -b 1 -b 2 -b 3 panchro.tif rgbnir.tif pansharpened_out.tif
