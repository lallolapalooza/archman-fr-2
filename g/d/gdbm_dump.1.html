NOM

gdbm_dump - exporter une base de données GDBM dans un fichier

SYNTAXE

gdbm_dump [-H FORMAT] [--format=FORMAT] FICHIER_BDD [FICHIER]

gdbm_dump [-Vh] [--help] [--usage] [--version]

DESCRIPTION

L'utilitaire gdbm_dump crée une exportation de la base de données gdbm(3) spécifiée. Le nom du fichier d'exportation de sortie est fourni par le deuxième argument (FICHIER). S'il n'est pas spécifié, la sortie va vers la sortie standard d'erreur.

L'exportation créée peut être fournie comme argument à l'utilitaire gdbm_load(1) afin de recréer une copie exacte du FICHIER_BDD.

OPTIONS

-H, --format=FORMAT
Sélectionne le format d'exportation. La valeur binary (ou 0) demande à gdbm_dump de produire une exportation binaire, compatible avec les versions antérieures de gdbm (jusqu'à la version 1.9). La valeur ascii (ou 1) lui demande de créer une exportation ASCII (c'est le comportement par défaut). Cette dernière est préférée car, en plus des données réelles, elle contient également des méta-informations qui permettront à gdbm_load(1) de recréer une copie exacte du fichier.
-h, --help
Affiche un bref résumé de l'utilisation.
--usage
Affiche une liste des options disponibles.
-V, --version
Affiche la version du programme

VOIR AUSSI

gdbm_load(1), gdbmtool(1), gdbm(3).
