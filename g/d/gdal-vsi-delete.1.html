NOM

gdal-vsi-delete - Supprimer des fichiers situés sur l'interface système virtuelle GDAL (VSI)

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal vsi delete [OPTIONS] <NOMFICHIER>
Supprime des fichiers situés sur l'interface système virtuelle GDAL (VSI).
Arguments positionnels :
  --filename <NOMFICHIER>   Nom du fichier ou répertoire à supprimer [requis]
Options communes :
  -h, --help              Affiche le message d'aide et quitte
  --json-usage            Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>  Option de configuration [peut être répétée]
Options :
  -r, -R, --recursive     Supprimer les répertoires de manière récursive

DESCRIPTION

gdal vsi delete supprime des fichiers et des répertoires situés sur les Systèmes de fichiers virtuels GDAL (compressés, hébergés sur le réseau, etc. : /vsimem, /vsizip, /vsitar, /vsicurl, ...).

Ceci est l'équivalent de la commande UNIX rm, et gdal vsi rm est un alias pour gdal vsi delete.

ATTENTION :

Soyez prudent. Cette commande ne peut pas être annulée. Elle peut également agir sur le système de fichiers "réel".

Options

-r, -R, --recursive
Supprimer les répertoires de manière récursive.

EXEMPLES

Exemple 1 : Supprimer récursivement des fichiers de /vsis3/bucket/my_dir

$ gdal vsi delete -r /vsis3/bucket/my_dir
