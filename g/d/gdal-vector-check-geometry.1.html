DESCRIPTIO

N

gdal vector check-geometry vérifie que les éléments individuels d'un jeu de données sont valides et simples selon la norme OGC Simple Features. Pour chaque entité invalide ou non simple, il produira une description et, dans la plupart des cas, un point de localisation de

l'erreur.

Les vérifications suivantes sont effectuées, en fonction du type de géométrie d'entrée

:
  • Les Polygons et MultiPolygons sont vérifiés pour leur validité. Un seul point d'erreur sera signalé même s'il y a plusieurs causes
    • d'invalidité.
  • Les LineStrings et MultiLineStrings sont vérifiés pour leur simplicité. Tous les points d'auto-intersection seront signalés si GDAL est compilé avec la version 3.14 ou ultérieure de la bibliothèque GEOS. Avec les versions antérieures, les points d'auto-intersection ne sont pas
    • signalés.
  • Les GeometryCollections sont vérifiés pour que leurs éléments individuels soient valides / simples. Un seul point d'erreur sera signalé même s'il y a plusieurs causes
    • d'invalidité.
  • Les autres ty
    • pes de géomét
rie ne sont
pas vérifiés.

La vérification de validité/simplicité est effectuée par la bibliothèque GEOS et devrait être cohérente avec les résultats de logiciels tels que PostGIS, QGIS et shapely qui utilisent également cette bibliothèque. GEOS ne considère pas les points répétés comme une cause d'invalidité ou de

non-simplicité.

NOM
     gdal-vector-check-geometry - Vérifie la validité géométrique des entités vectorielles.

SYNOPSIS
     gdal-vector-check-geometry [-validity] [-brief] [-log] [-append] [-update] [-id] [-ofilter <filter>] [-o <output_file>] [-where <where_clause>] [-sql <sql_query>] <input_datasource> [<input_layer>...]

DESCRIPTION
     La commande gdal-vector-check-geometry est un outil développé pour vérifier la validité géométrique des entités géométriques dans une couche de données vectorielles. Elle peut être utilisée pour identifier les entités ayant des géométries non valides, telles que des lignes qui s'auto-intersectent, des polygones dont les anneaux intérieurs dépassent les anneaux extérieurs, ou d'autres déviations des standards définis dans le langage OGC (Open Geospatial Consortium).

GDALG_OUTPUT (ON-THE-FLY / STREAMED DATASET)
     Lorsque l'GDALG_OUTPUT est défini, il permet de créer un jeu de données de sortie en flux. Cela signifie que les données ne sont pas sauvegardées dans un fichier temporaire, mais traitées et envoyées directement au format de sortie désiré. Ce mode est utile pour le traitement de très grandes données ou lors de l'intégration dans des pipelines de traitement.

OPTIONS
     -validity
          Vérifie la validité géométrique des entités. Par défaut, l'outil vérifie uniquement les auto-intersections.

     -brief
          Produit une sortie concise, ne listant que les entités invalides.

     -log
          Enregistre les résultats dans un fichier journal.

     -append
          Ajoute les résultats au fichier de sortie existant au lieu de l'écraser.

     -update
          Met à jour les entités invalides dans le jeu de données d'entrée.

     -id
          Inclut l'identifiant unique des entités dans la sortie.

     -ofilter <filter>
          Filtre les entités de sortie selon un critère spécifique.

     -o <output_file>
          Spécifie le fichier de sortie pour les résultats.

     -where <where_clause>
          Applique une clause WHERE pour sélectionner les entités à vérifier.

     -sql <sql_query>
          Exécute une requête SQL pour sélectionner les entités à vérifier.

EXEMPLES
     Vérifier les auto-intersections dans le fichier Shapefile "input.shp" et afficher uniquement les entités concernées :
          gdal-vector-check-geometry input.shp

     Vérifier toutes les invalidités géométriques dans la couche "roads" du fichier GeoPackage "data.gpkg", enregistrer les résultats dans "invalid_roads.log" :
          gdal-vector-check-geometry -validity -log invalid_roads.log data.gpkg roads

     Vérifier les entités dont l'attribut "type" est "autoroute" dans le fichier GeoJSON "routes.geojson", et mettre à jour les entités invalides :
          gdal-vector-check-geometry -where "type = 'autoroute'" -update routes.geojson
