NOM

gdal_fillnodata - Remplit les régions raster par interpolation à partir des bords.

SYNOPIS

gdal_fillnodata [--help] [--help-general] [-q] [-md <distance_max>]
           [-si <iterations_lissage>] [-o <nom>=<valeur> [<nom>=<valeur> ...]]
           [-mask <fichier>] [-interp {inv_dist,nearest}] [-b <bande>]
           [-of <format_gdal>] [-co <nom>=<valeur>]
           <fichier_source> <fichier_destination>

DESCRIPTION

gdal_fillnodata remplit les régions sélectionnées (généralement les zones sans données) en interpolant à partir des pixels valides autour des bords de la zone.

Des détails supplémentaires sur l'algorithme sont disponibles dans la documentation de GDALFillNodata().

NOTE :

gdal_fillnodata est un utilitaire Python et n'est disponible que si les liaisons Python de GDAL sont présentes.
--help
Afficher ce message d'aide et quitter.
--help-general
Donne un bref message d'utilisation pour les options générales de ligne de commande GDAL et quitte.
-q
Le script s'exécute en mode silencieux. Le moniteur de progression est supprimé et les messages de routine ne sont pas affichés.
-md <distance_max>
La distance maximale (en pixels) que l'algorithme recherchera pour obtenir des valeurs à interpoler. La valeur par défaut est de 100 pixels.
-si <iterations_lissage>
Le nombre d'itérations du filtre de lissage moyen 3x3 à exécuter après l'interpolation pour atténuer les artefacts. La valeur par défaut est zéro itération de lissage.
-o <nom>=<valeur>
Spécifie un argument spécial pour l'algorithme. Actuellement, aucun n'est pris en charge.
-b <bande>
La bande sur laquelle opérer, par défaut la première bande est utilisée.
-mask <fichier>
Utilise la première bande du fichier spécifié comme masque de validité (zéro est invalide, non-zéro est valide).
-of <format>
Sélectionne le format de sortie. La valeur par défaut est GTiff -- GeoTIFF File Format. Utilisez le nom court du format.
-interp {inv_dist,nearest}
Ajouté dans la version 3.9.

Par défaut, les pixels sont interpolés en utilisant un poids par distance inverse (inv_dist). Il est également possible de choisir une stratégie de voisin le plus proche (nearest).

<fichier_source>
Le fichier raster source utilisé pour identifier les pixels cibles. Une seule bande est utilisée.
<fichier_destination>
Le nouveau fichier à créer avec le résultat interpolé.
