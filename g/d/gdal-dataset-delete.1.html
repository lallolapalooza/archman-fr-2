NOM

gdal-dataset-delete - Supprimer un ou plusieurs jeux de données

Ajouté dans la version 3.12.

gdal dataset delete supprime un ou plusieurs jeux de données, y compris les fichiers associés/parallèles potentiels.

SYNTAXE

Usage: gdal dataset delete [OPTIONS] <FILENAME>
Supprimer un ou plusieurs jeux de données.
Arguments positionnels :
  --filename <FILENAME>   Nom de fichier ou de répertoire [peut être répété] [requis]
Options communes :
  -h, --help              Afficher le message d'aide et quitter
  --json-usage            Afficher l'utilisation sous forme de document JSON et quitter
  --config <KEY>=<VALUE>  Option de configuration [peut être répétée]
Options avancées :
  -f, --format <FORMAT>   Format du jeu de données

OPTIONS

--filename <FILENAME>
Tout nom de fichier ou de répertoire. Requis. Peut être répété.
-f, --format <FORMAT>
Format du jeu de données. Utile si la détection automatique ne fonctionne pas.

EXEMPLES

Exemple 1 : Supprimer un jeu de données

$ gdal dataset delete NE1_50M_SR_W.tif
