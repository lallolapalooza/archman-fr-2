DESCRIPTIO

N

gdal raster tri génère un raster mono-bande avec des valeurs calculées à partir de l'altitude. TRI signifie Terrain Ruggedness Index (indice de rugosité du terrain), qui mesure la différence entre un pixel central et ses cellules

environnantes.

Cette sous-commande est également disponible en tant qu'étape potentielle de gdal raster

pipeline

La valeur -9999 est utilisée comme valeur

nodata.

Une valeur nodata dans le jeu de données cible sera également émise si au moins un pixel défini sur la valeur nodata est trouvé dans la fenêtre 3x3 centrée autour de chaque pixel source. Par défaut, l'algorithme calculera les valeurs aux bords de l'image ou si une valeur nodata est trouvée dans la fenêtre 3x3, en interpolant les valeurs manquantes, sauf si --no-edges est spécifié, au quel cas une bordure d'un pixel autour de l'image sera définie avec la valeur

nodata.
