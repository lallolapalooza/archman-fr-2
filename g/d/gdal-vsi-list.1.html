NOM

gdal-vsi-list - Lister les fichiers de l'une des interfaces système virtuelles GDAL (VSI)

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal vsi list [OPTIONS] <NOMFICHIER>
Lister les fichiers de l'une des interfaces système virtuelles GDAL (VSI).
Arguments positionnels :
  --filename <NOMFICHIER>                                Nom de fichier ou de répertoire [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLE>=<VALEUR>                               Option de configuration [peut être répétée]
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie. FORMAT-SORTIE=json|text
  -l, --long, --long-listing                           Utiliser un format de liste détaillée
  -R, --recursive                                      Lister les sous-répertoires récursivement
  --depth <PROFONDEUR>                                 Profondeur maximale en mode récursif
  --abs, --absolute-path                               Afficher le chemin absolu
  --tree                                               Utiliser une présentation hiérarchique pour la sortie JSON

DESCRIPTION

gdal vsi list liste les fichiers des Systèmes de fichiers virtuels GDAL (compressés, hébergés sur réseau, etc.) : /vsimem, /vsizip, /vsitar, /vsicurl, ....

C'est l'équivalent de la commande ls de UNIX, et gdal vsi ls est un alias pour gdal vsi list.

Par défaut, elle affiche les noms de fichiers, au niveau immédiat, sans détails, et au format JSON.

Options

--filename <NOMFICHIER>
Tout nom de fichier ou de répertoire, appartenant à l'un des systèmes de fichiers virtuels GDAL. Requis.
-f, --of, --format, --output-format json|text
Quel format de sortie utiliser. Le défaut est JSON, et depuis GDAL 3.12, texte lorsqu'il est appelé depuis la ligne de commande.
-l, --long, --long-listing
Utiliser un format de liste détaillée, ajoutant les permissions, la taille du fichier et la date de dernière modification.
-R, --recursive
Lister les sous-répertoires récursivement. Par défaut, la profondeur est illimitée, mais elle peut être réduite avec --depth.
--depth <PROFONDEUR>
Profondeur maximale en mode récursif. 1 correspond à aucune récursion, 2 aux sous-répertoires immédiats, etc.
--abs, --absolute-path
Indique s'il faut rapporter les noms de fichiers comme des chemins absolus. Par défaut, ils sont relatifs au nom de fichier d'entrée.
--tree
Utiliser une présentation hiérarchique pour la sortie JSON, au lieu d'une liste plate. Valide uniquement lorsque --output-format est réglé sur json (ou laissé à sa valeur par défaut).

EXEMPLES

Exemple 1 : Lister récursivement les fichiers dans /vsis3/bucket avec détails

$ gdal vsi list -lR --of=text /vsis3/bucket
