NOM

gdal-dataset - Point d'entrée pour les commandes de gestion de jeux de données

Ajouté dans la version 3.12.

gdal dataset peut effectuer diverses opérations sur des fichiers de données, en fonction de l'opération choisie. Cela inclut l'identification des types de données et la suppression, le renommage ou la copie des fichiers.

SYNTAXE

Utilisation : gdal dataset <SOUS-COMMANDE> [OPTIONS]
où <SOUS-COMMANDE> est l'un des suivants :
  copy :     Copie les fichiers d'un jeu de données. (alias : cp)
  delete :   Supprime le(s) jeu(x) de données. (alias : rm, remove)
  identify : Identifie le pilote ouvrant le(s) jeu(x) de données.
  rename :   Renomme les fichiers d'un jeu de données. (alias : ren, mv)
Options communes :
  -h, --help              Affiche le message d'aide et quitte
  --json-usage            Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>  Option de configuration [peut être répétée]

SOUS-COMMANDES DISPONIBLES

  • gdal dataset identify : Identifie le pilote ouvrant le(s) jeu(x) de données
  • gdal dataset copy : Copie les fichiers d'un jeu de données.
  • gdal dataset rename : Renomme les fichiers d'un jeu de données.
  • gdal dataset delete : Supprime le(s) jeu(x) de données
