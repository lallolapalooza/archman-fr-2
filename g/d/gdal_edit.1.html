DESCRIPTIO

N

gdal_edit peut être utilisé pour modifier sur place diverses informations d'un jeu de données GDAL existant (projection, géotransformation, nodata, métadonnées)

.

Il ne fonctionne qu'avec les formats raster qui prennent en charge l'accès en mise à jour aux jeux de données

existants.

ATTENTION

:
Selon le format, les anciennes valeurs des informations mises à jour peuvent toujours être présentes dans le fichier dans un état « fantôme », même si elles ne sont plus accessibles via l'API GDAL. C'est par exemple le cas du format GTiff -- GeoTIFF File Format
(cette liste n'es
t pas exhaustive).

-scale
<value>
Assigne une valeur d'échelle spécifiée aux bandes de sortie. Si une seule valeur d'échelle est fournie, elle sera définie pour toutes les bandes. Alternativement, une valeur d'échelle par bande peut être fournie, auquel cas le nombre de valeurs d'échelle doit correspondre au nombre de bandes. Si aucune échelle n'est nécessaire, il est recommandé de définir la valeur à 1. L'échelle et le décalage sont généralement utilisés ensemble. Par exemple, l'échelle et le décalage peuvent être utilisés pour stocker des altitudes dans un fichier entier non signé 16 bits avec une précision de 0,1, et en partant de -100.
