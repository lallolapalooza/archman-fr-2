NOM

gdal_create - Créer un fichier raster (sans jeu de données source)

SYNOPSIS

Utilisation : gdal_create [--help] [--long-usage] [--help-general]
                   [-ot Byte|Int8|[U]Int{16|32|64}|CInt{16|32}|[C]Float{32|64}]
                   [-of <output_format>] [-outsize <xsize> <ysize>]
                   [-bands <count>] [-burn <value>]... [-a_srs <srs_def>]
                   [-a_ullr <ulx> <uly> <lrx> <lry>] [-a_nodata <value>]
                   [-mo <NAME>=<VALUE>]... [-co <NAME>=<VALUE>]... [--quiet]
                   [-if <input_dataset>]
                   <out_dataset>

DESCRIPTION

L'utilitaire gdal_create peut être utilisé pour initialiser un nouveau fichier raster, à partir de ses dimensions, du nombre de bandes et définir divers paramètres, tels que le SCR, la géotransformation, la valeur nodata, les métadonnées. Il peut également être utilisé dans des cas particuliers, comme la création d'un fichier PDF à partir d'un fichier de composition XML.

--help
Afficher ce message d'aide et quitter
--help-general
Donne un bref message d'utilisation pour les options génériques de la ligne de commande GDAL et quitte.
-ot <type>
Forcer les bandes de l'image de sortie à avoir un type de données spécifique pris en charge par le pilote, qui peut être l'un des suivants : Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, Float32, Float64, CInt16, CInt32, CFloat32 ou CFloat64.
-of <format>
Sélectionner le format de sortie. S'il n'est pas spécifié, le format est déduit de l'extension. Utiliser le nom court du format.
-outsize <xsize> <ysize>
Définir la taille du fichier de sortie en pixels. La première valeur est la largeur. La deuxième est la hauteur.
-bands <count>
Nombre de bandes. Par défaut à 1 si -outsize est spécifié, ou 0 sinon.
-burn <value>
Une valeur fixe à brûler dans une bande. Une liste d'options -burn peut être fournie, une par bande (la première valeur s'appliquera à la première bande, la deuxième à la deuxième bande, etc.). Si une seule valeur est spécifiée, elle s'appliquera à toutes les bandes.
-a_srs <srs_def>
Remplacer la projection pour le fichier de sortie. Le<srs_def> peut être n'importe lequel des formats habituels GDAL/OGR, WKT complet, PROJ.4, EPSG:n ou un fichier contenant le WKT. Aucune reprojection n'est effectuée.
-a_ullr <ulx> <uly> <lrx> <lry>
Attribuer les limites géoréférencées du fichier de sortie.
-a_nodata <value>
Attribuer une valeur nodata spécifiée aux bandes de sortie.
-mo <META-TAG>=<VALUE>
Transmettre une clé et une valeur de métadonnées à définir sur le jeu de données de sortie si possible.
-co <NAME>=<VALUE>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression et si le fichier doit être tuilé.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être listée avec l'option de ligne de commande --format mais la documentation du format est la source définitive d'informations sur les options de création du pilote. Voir Pilotes raster la documentation spécifique au format pour les options de création légales de chaque format.

-q
Supprimer le moniteur de progression et les autres sorties non-erreurs.
-if <input_dataset>
Ajouté dans la version 3.3.

Nom du jeu de données d'entrée GDAL qui sert de modèle pour les valeurs par défaut des options -outsize, -bands, -ot, -a_srs, -a_ullr et -a_nodata. Notez que les valeurs de pixels ne seront pas copiées.

<out_dataset>
Le nom du fichier de destination.

EXEMPLES

Exemple 1 : Initialiser un nouveau fichier GeoTIFF avec une valeur uniforme de 10

gdal_create -outsize 20 20 -a_srs EPSG:4326 -a_ullr 2 50 3 49 -burn 10 out.tif

Exemple 2 : Créer un fichier PDF à partir d'un fichier de composition XML

gdal_create -co COMPOSITION_FILE=composition.xml out.pdf

Exemple 3 : Initialiser un fichier GeoTIFF vierge à partir d'un fichier d'entrée

gdal_create -if prototype.tif output.tif
