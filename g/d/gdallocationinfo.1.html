NAME


gdallocationinfo


récupère les informations de localisation de pixels à partir de fichiers raster GDAL






SYNOPSIS


gdallocationinfo [options] <fichier_raster> [fichier_coords | x y]+






DESCRIPTION


La commande gdallocationinfo peut être utilisée pour récupérer la valeur des pixels à des coordonnées spécifiques. Les coordonnées peuvent être spécifiées sous forme de ligne/colonne ou sous forme de coordonnées géoréférencées. Les coordonnées peuvent être fournies directement sur la ligne de commande ou lues à partir d'un fichier.


Les lignes et les colonnes sont 1-basées.


Les coordonnées géoréférencées sont supposées être dans le même système de coordonnées que le fichier raster d'entrée, sauf indication contraire de l'option -t_srs.


Les coordonnées peuvent être spécifiées en utilisant une entrée standard ou un fichier. Si un nom de fichier est spécifié en tant qu'argument de position, il sera traité comme un fichier contenant les coordonnées à interroger. Si un nom de fichier de coordonnées est spécifié, le programme s'attendra à ce que chaque ligne contienne un ensemble de coordonnées délimitées par des espaces ou des virgules. La valeur par défaut consiste à interroger les lignes/colonnes dans un format ligne,colonne.


Si aucune coordonnée n'est fournie sur la ligne de commande, la commande gdallocationinfo passera en mode interactif, interrogeant les coordonnées entrées par l'utilisateur jusqu'à ce que le programme soit terminé.


Les options suivantes sont disponibles :


    

  • 
-A : Imprime des informations sur toutes les bandes au lieu de seulement la première.
    • 

  • 
-b <band_num> : Sélectionne la bande à interroger. La valeur par défaut est la première bande (1).
    • 

  • 
-E : Imprime les coordonnées Est/Nord des points demandés.
    • 

  • 
-f <format> : Spécifie le format de sortie. Le format par défaut est "Report".
    • 

  • 
-geoloc : Les coordonnées sont géoréférencées. La valeur par défaut est d'utiliser les coordonnées pixel (ligne/colonne).
    • 

  • 
-l : Les coordonnées sont données sous la forme ligne/colonne. C'est le comportement par défaut.
    • 

  • 
-valonly : Imprime uniquement la valeur du pixel.
    • 

  • 
-field_sep <chaine> : Spécifie le délimiteur de champ à utiliser lors de la lecture des coordonnées depuis un fichier et lors de l'impression de la sortie. La valeur par défaut est un espace.
    • 

  • 
-t_srs <srs_def> : Définit le SRS des coordonnées d'entrée pour la transformation en coordonnées de pixel.
    • 

  • 
-q : Mode silencieux, supprime les messages de progression et de statut.
    •
