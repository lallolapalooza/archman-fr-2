NOM

gdal-vsi-sozip - Commandes liées à SOZIP (Seek-Optimized ZIP).

Ajouté dans la version 3.11.

DESCRIPTION

L'utilitaire gdal vsi sozip peut être utilisé pour :

  • créer un fichier SOZip (Seek-Optimized ZIP)
  • ajouter des fichiers à un fichier ZIP/SOZip existant
  • lister le contenu d'un fichier ZIP/SOZip
  • valider un fichier SOZip
  • convertir un fichier Zip existant en un fichier optimisé SOZip

SYNTAXE

Usage: gdal vsi sozip <SOUS-COMMANDE> [OPTIONS]
où <SOUS-COMMANDE> est l'une des suivantes :
  - create:   Crée un fichier ZIP optimisé pour la recherche (SOZIP).
  - list:     Liste le contenu d'un fichier ZIP, avec des informations liées à SOZIP.
  - optimize: Crée un fichier ZIP optimisé pour la recherche (SOZIP) à partir d'un fichier ZIP ordinaire.
  - validate: Valide un fichier ZIP, potentiellement en utilisant l'optimisation SOZIP.
Options communes :
  -h, --help              Affiche le message d'aide et quitte
  --json-usage            Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>  Option de configuration [peut être répétée]

GDAL VSI SOZIP CREATE

Description

Ajoute un ou plusieurs fichiers à un fichier zip nouveau ou existant.

Syntaxe

Usage: gdal vsi sozip create [OPTIONS] <ENTRÉE> <SORTIE>
Crée un fichier ZIP optimisé pour la recherche (SOZIP).
Arguments positionnels :
  -i, --input <ENTRÉE>                                          Noms de fichiers d'entrée [peut être répété] [requis]
  -o, --output <SORTIE>                                        Nom du fichier ZIP de sortie [requis]
Options communes :
  -h, --help                                                   Affiche le message d'aide et quitte
  --json-usage                                                 Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>                                       Option de configuration [peut être répétée]
  -q, --quiet                                                  Mode silencieux (pas de barre de progression)
Options :
  --overwrite                                                  Indique si l'écrasement du fichier de sortie existant est autorisé
  -r, --recursive                                              Parcourt la structure du répertoire des répertoires spécifiés de manière récursive
  -j, --junk-paths, --no-paths                                 Stocke uniquement le nom du fichier sauvegardé, et ne stocke pas les noms de répertoire
  --enable-sozip <ENABLE-SOZIP>                                Indique s'il faut appliquer automatiquement/systématiquement/jamais l'optimisation SOZIP. ENABLE-SOZIP=auto|yes|no (défaut : auto)
  --sozip-chunk-size <valeur en octets ou avec suffixe K/M>       Taille du bloc pour un fichier optimisé pour la recherche (défaut : 32768)
  --sozip-min-file-size <valeur en octets ou avec suffixe K/M/G> Taille minimale du fichier pour décider si un fichier doit être optimisé pour la recherche (défaut : 1 Mo)
  --content-type <CONTENT-TYPE>                                Stocke le type de contenu du fichier ajouté.

Options

-i, --input <ENTRÉE>
Noms de fichiers d'entrée. Requis. Plusieurs noms de fichiers ou de répertoires sont acceptés.
-o, --output <SORTIE>
Nom du fichier ZIP de sortie. Requis. Doit avoir l'extension .zip
--overwrite
Indique si l'écrasement du fichier de sortie existant est autorisé.
-r, --recursive
Parcourt la structure du répertoire des répertoires spécifiés récursivement.
-j, --junk-paths, --no-paths
Stocke uniquement le nom du fichier sauvegardé (supprime le chemin), et ne stocke pas les noms de répertoire. Par défaut, sozip stockera le chemin complet (relatif au répertoire courant).
--enable-sozip auto|yes|no
En mode auto, un fichier est optimisé pour la recherche uniquement si sa taille est supérieure à la valeur de --sozip-min-file-size. En mode yes, tous les fichiers d'entrée seront optimisés pour la recherche. En mode no, aucun fichier d'entrée ne sera optimisé pour la recherche.
--sozip-chunk-size <valeur>
Taille du bloc pour un fichier optimisé pour la recherche. Par défaut, 32768 octets. La valeur est spécifiée en octets, ou les suffixes K et M (précédés facultativement d'un espace) peuvent être respectivement utilisés pour spécifier une valeur en kilo-octets ou méga-octets.
--sozip-min-file-size <valeur>
Taille minimale du fichier pour décider si un fichier doit être optimisé pour la recherche, en mode --enable-sozip=auto. Par défaut, 1 Mo. La valeur est spécifiée en octets, ou les suffixes K, M ou G (précédés facultativement d'un espace) peuvent être respectivement utilisés pour spécifier une valeur en kilo-octets, méga-octets ou giga-octets.
--content-type <valeur>
Stocke le Type de Contenu pour le fichier ajouté sous forme de paire clé-valeur dans l'extension de champ supplémentaire 'KV' (0x564b) dédiée au stockage des métadonnées de paires clé-valeur.
-q, --quiet
Ne pas afficher de message informatif (uniquement les erreurs).

Multithreading

L'option de configuration GDAL_NUM_THREADS peut être définie sur ALL_CPUS ou une valeur entière pour spécifier le nombre de threads à utiliser pour les fichiers compressés SOZip. Par défaut, ALL_CPUS.

Exemples

Exemple 1 : Créer un fichier ZIP, potentiellement optimisé pour la recherche, avec le contenu de my.gpkg

gdal vsi sozip create my.gpkg my.gpkg.zip

Exemple 2 : Créer un fichier ZIP, potentiellement optimisé pour la recherche, à partir du contenu d'un répertoire source :

gdal vsi sozip create -r source_dir/ my.gpkg.zip

Description

Crée un nouveau fichier zip à partir du contenu d'un fichier existant, en appliquant éventuellement l'optimisation SOZip lorsque pertinent.

Syntaxe

Usage: gdal vsi sozip optimize [OPTIONS] <ENTRÉE> <SORTIE>
Crée un fichier ZIP optimisé pour la recherche (SOZIP) à partir d'un fichier ZIP ordinaire.
Arguments positionnels :
  -i, --input <ENTRÉE>                                          Nom du fichier ZIP d'entrée [requis]
  -o, --output <SORTIE>                                        Nom du fichier ZIP de sortie [requis]
Options communes :

  --config <CLÉ>=<VALEUR>                                       Option de configuration [peut être répétée]
  -q, --quiet                                                  Mode silencieux (pas de barre de progression)
