DESCRIPTIO

N

gdal vector buffer calcule un POLYGON ou MULTIPOLYGON qui représente tous les points dont la distance par rapport à une géométrie/géographie est inférieure ou égale à une distance donnée. Une distance négative réduit la géométrie au lieu de l'étendre. Une distance négative peut réduire un polygone complètement, auquel cas POLYGON EMPTY est renvoyé. Pour les points et les lignes, les distances négatives renvoient toujours des résultats

vides. paramètres.

Cette commande peut également être utilisée comme une étape d'un pipeline gdal

vector.
