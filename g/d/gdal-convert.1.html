NOM

gdal-convert - Convertir un jeu de données

Ajouté dans la version 3.11.

Agit comme un raccourci pour gdal raster convert ou gdal vector convert selon la nature du jeu de données spécifié.

SYNTAXE

Usage: gdal convert [OPTIONS] <ENTREE> <SORTIE>
Convertir un jeu de données (raccourci pour 'gdal raster convert' ou 'gdal vector convert').
Arguments positionnels:
  -i, --input <ENTREE>                                 Jeu de données raster, vectoriel ou multidimensionnel d'entrée [obligatoire]
  -o, --output <SORTIE>                                Jeu de données raster, vectoriel ou multidimensionnel de sortie (créé par l'algorithme) [obligatoire]
Options courantes:
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLÉ>=<VALEUR>                             Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options:
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie
Pour toutes les options, exécutez 'gdal raster convert --help' ou 'gdal vector convert --help'

EXEMPLES

Exemple 1: Conversion du fichier utm.tif en raster GeoPackage

$ gdal convert utm.tif utm.gpkg
