NOM

gdalmanage - Identifier, supprimer, renommer et copier des fichiers de données raster.

SYNTAXE

Usage: gdalmanage [--help] [--help-general]
                  <mode> [-r] [-fr] [-u] [-f <format>]
                  <nom_jeu_donnees> [<nouveau_nom_jeu_donnees>]

DESCRIPTION

Le programme gdalmanage peut effectuer diverses opérations sur les fichiers de jeux de données, en fonction du mode choisi. Cela inclut l'identification des types de jeux de données et la suppression, le renommage ou la copie des fichiers.

<mode>
Mode de fonctionnement
identify <nom_jeu_donnees>:
Lister le format des données des fichiers.
copy <nom_jeu_donnees> <nouveau_nom_jeu_donnees>:
Créer une copie du fichier du jeu de données avec un nouveau nom.
rename <nom_jeu_donnees> <nouveau_nom_jeu_donnees>:
Changer le nom du fichier du jeu de données.
delete <nom_jeu_donnees>:
Supprimer les fichiers du jeu de données.
-r
Scanner récursivement les fichiers/dossiers pour trouver les fichiers de jeux de données.
-fr
Scanner récursivement les dossiers pour trouver les fichiers de jeux de données, en forçant la récursion dans les dossiers reconnus comme des formats valides.
-u
Signaler les échecs si le type de fichier n'est pas identifié.
-f <format>
Spécifier le format du fichier du jeu de données s'il est inconnu par l'application. Utilise le nom court du format de données (par ex. GTiff).
<nom_jeu_donnees>
Fichier raster sur lequel opérer. Avec identify, peut être répété pour plusieurs fichiers.
<nouveau_nom_jeu_donnees>
Pour les modes copy et rename, vous fournissez un nom de fichier source et un nom de fichier cible, tout comme les commandes copy et move dans un système d'exploitation.

EXEMPLES

Utilisation du mode identify

Signaler le format des données du fichier du jeu de données en utilisant le mode identify et en spécifiant un nom de fichier de données :

$ gdalmanage identify NE1_50M_SR_W.tif
NE1_50M_SR_W.tif: GTiff

Le mode récursif scannera les sous-dossiers et signalera le format des données :

$ gdalmanage identify -r 50m_raster/
NE1_50M_SR_W/ne1_50m.jpg: JPEG
NE1_50M_SR_W/ne1_50m.png: PNG
NE1_50M_SR_W/ne1_50m_20pct.tif: GTiff
NE1_50M_SR_W/ne1_50m_band1.tif: GTiff
NE1_50M_SR_W/ne1_50m_print.png: PNG
NE1_50M_SR_W/NE1_50M_SR_W.aux: HFA
NE1_50M_SR_W/NE1_50M_SR_W.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub.tif: GTiff
NE1_50M_SR_W/ne1_50m_sub2.tif: GTiff

Utilisation du mode copy

Copier le jeu de données :

$ gdalmanage copy NE1_50M_SR_W.tif ne1_copy.tif

Utilisation du mode rename

Renommer le jeu de données :

$ gdalmanage rename NE1_50M_SR_W.tif ne1_rename.tif

Utilisation du mode delete

Supprimer le jeu de données :

gdalmanage delete NE1_50M_SR_W.tif
