NOM

gdump - vide le contenu d'un graphe source sous forme de code source

SYNTAXE

gdump [options] [igfile] [ocfile]

DESCRIPTION

Le programme gdump permet de créer un équivalent en code source au chargement d'un graphe source centralisé. Le contenu du graphe source est représenté sous forme de tableaux de données qui sont assemblés en appelant la routine SCOTCH_graphBuild de la bibliothèque libScotch.

OPTIONS

-b?base
Définit la valeur base du graphe décrit par le code source.
-h
Affiche une aide.
-p?prefix
Définit le prefix à ajouter à tous les noms de tableaux et au nom de la fonction de construction du graphe.
-s?suffix
Définit le suffix à ajouter à tous les noms de tableaux et au nom de la fonction de construction du graphe.
-V
Affiche la version du programme et le copyright.

EXEMPLE

Crée un fichier source C 'brol.c' qui correspond au graphe 'brol.grf', avec le suffixe '_brol' pour l'identifiant et le nom de la fonction de création.

    $ gdump -s_brol brol.grf brol.c
