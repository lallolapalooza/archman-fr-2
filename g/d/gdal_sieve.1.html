NOM

gdal_sieve - Supprime les petits polygones raster.

SYNTAXE

gdal_sieve [--help] [--help-general]
              [-q] [-st threshold] [-4] [-8] [-o name=value]
              <srcfile> [-nomask] [-mask filename] [-of format] [<dstfile>]

DESCRIPTION

gdal_sieve supprime les polygones raster plus petits qu'une taille de seuil donnée (en pixels) et les remplace par la valeur de pixel du polygone voisin le plus grand. Le résultat peut être écrit dans la bande raster existante ou copié dans un nouveau fichier.

Le jeu de données d'entrée est lu en tant que données entières, ce qui signifie que les valeurs à virgule flottante sont arrondies à des entiers. La mise à l'échelle des données sources peut être nécessaire dans certains cas (par exemple, données à virgule flottante 32 bits avec min=0 et max=1).

Des détails supplémentaires sur l'algorithme sont disponibles dans la documentation de GDALSieveFilter().

NOTE :

gdal_sieve est un utilitaire Python et n'est disponible que si les liaisons Python de GDAL sont disponibles.
