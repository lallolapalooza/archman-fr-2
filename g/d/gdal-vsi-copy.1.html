NOM

gdal-vsi-copy - Copie des fichiers situés sur l'interface du système de fichiers virtuel GDAL (VSI)

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal vsi copy [OPTIONS] <SOURCE> <DESTINATION>
Copie des fichiers situés sur l'interface du système de fichiers virtuel GDAL (VSI).
Arguments positionnels :
  --source <SOURCE>            Nom du fichier ou répertoire source [requis]
  --destination <DESTINATION>  Nom du fichier ou répertoire de destination [requis]
Options communes :
  -h, --help                   Affiche le message d'aide et quitte
  --json-usage                 Affiche l'utilisation sous forme de document JSON et quitte
  --config <KEY>=<VALUE>       Option de configuration [peut être répétée]
  -q, --quiet                  Mode silencieux (pas de barre de progression)
Options :
  -r, --recursive              Copie les sous-répertoires de manière récursive
  --skip-errors                Ignore les erreurs

DESCRIPTION

gdal vsi copy copie des fichiers et des répertoires situés sur les Systèmes de Fichiers Virtuels GDAL (compressés, hébergés sur le réseau, etc.) : /vsimem, /vsizip, /vsitar, /vsicurl, ....

Il peut copier des fichiers et des répertoires entre différents systèmes de fichiers virtuels.

C'est l'équivalent de la commande UNIX cp, et gdal vsi cp est un alias pour gdal vsi copy.

Options

-r, --recursive
Copie les répertoires de manière récursive.
--skip-errors
Ignore les erreurs qui se produisent pendant la copie.

EXEMPLES

Exemple 1 : Copie récursive des fichiers de /vsis3/bucket/my_dir vers le répertoire local, créant un répertoire my_dir s'il n'existe pas.

$ gdal vsi copy -r /vsis3/bucket/my_dir .

Exemple 2 : Copie récursive des fichiers de /vsis3/bucket/my_dir vers le répertoire local, sans créer de répertoire my_dir, sans barre de progression

$ gdal vsi copy --quiet -r /vsis3/bucket/my_dir/* .
