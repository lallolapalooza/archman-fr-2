DESCRIPTIO

N

gdal raster reclassify reclassifie les valeurs dans un jeu de données d'entrée. Un fichier (ou une chaîne) spécifie la correspondance des valeurs de pixels d'entrée ou des plages vers des fichiers de

sortie.

Un exemple de fichier est présenté

ci-dessous. 
# remap land cover types
0       = 10
# land [2,4] = 20 # freshwat
er 1 = 40 # ocean NO_DATA = N
O_DATA # leave NoData pixels unmodified

(Le caractère # indique un commentaire qui est ignoré par le parseur mais peut rendre le fichier plus facile à lire.) Dans ce cas

:
  • les valeurs d'entrée de 0 seront produites en sortie comme
    • 10
  • les valeurs d'entrée comprises entre 2 et 4 (inclus) seront produites en sortie comme
    • 20
  • les valeurs d'entrée de 1 seront produites en sortie comme
    • 40
  • les valeurs No
    • Data seront pr
éservées en t
ant que NoData

La présence de toute autre valeur en entrée provoquera une erreur. Si ce n'est pas souhaité, la plage d'entrée DEFAULT peut être utilisée pour spécifier une valeur de sortie pour les pixels non couverts par aucune autre plage d'entrée. Ces pixels peuvent être convertis en NoData (DEFAULT = NO_DATA), une autre valeur constante (par exemple, DEFAULT = 50), ou laissés inchangés (DEFAULT = PASS_T

HROUGH).
