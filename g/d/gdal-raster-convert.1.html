NOM

gdal-raster-convert - Convertir un jeu de données raster

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal raster convert [OPTIONS] <ENTRÉE> <SORTIE>
Convertir un jeu de données raster.
Arguments positionnels :
  -i, --input <ENTRÉE>                                 Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster de sortie [requis]
Options courantes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLÉ>=<VALEUR>                               Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLÉ>=<VALEUR>                Option de création [peut être répétée]
  --overwrite                                          Indique si l'écrasement du fichier de sortie existant est autorisé
                                                       Mutuellement exclusif avec --append
  --append                                             Ajouter comme sous-ensemble à un fichier de sortie existant
                                                       Mutuellement exclusif avec --overwrite
Options avancées :
  --if, --input-format <FORMAT-ENTRÉE>                 Formats d'entrée [peut être répété]
  --oo, --open-option <CLÉ>=<VALEUR>                   Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster convert peut être utilisé pour convertir des données raster entre différents formats.

Les options suivantes sont disponibles :

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format raster de sortie utiliser. Les valeurs autorisées peuvent être obtenues avec gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les détails du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être mosaïqué.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être répertoriée avec l'option de ligne de commande --formats, mais la documentation du format est la source définitive d'information sur les options de création du pilote. Voir la documentation spécifique du format Pilotes raster pour les options de création légales pour chaque format.

--overwrite
Autorise le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
--append
Ajouter le raster d'entrée comme un nouveau sous-ensemble au fichier de sortie existant. Fonctionne uniquement avec les pilotes qui prennent en charge l'ajout de sous-ensembles, tels que GTiff -- Format de fichier GeoTIFF et GPKG -- GeoPackage raster.

Options avancées

--oo <NOM>=<VALEUR>
Option d'ouverture du jeu de données (spécifique au format).

Peut être répété.

--if <format>
Nom du format/pilote à tenter pour ouvrir le(s) fichier(s) d'entrée. Il n'est généralement pas nécessaire de le spécifier, mais il peut être utilisé pour sauter la détection automatique du pilote, lorsqu'elle échoue à sélectionner le pilote approprié. Cette option peut être répétée plusieurs fois pour spécifier plusieurs pilotes candidats. Notez qu'elle ne force pas ces pilotes à ouvrir le jeu de données. En particulier, certains pilotes ont des exigences sur les extensions de fichiers.

Peut être répété.

EXEMPLES

Exemple 1: Conversion du fichier utm.tif en GeoTIFF optimisé pour le cloud avec compression JPEG

$ gdal raster convert --format=COG --co COMPRESS=JPEG utm.tif utm_cog.tif

Exemple 2: Conversion du fichier utm.tif en raster GeoPackage

$ gdal raster convert utm.tif utm.gpkg
