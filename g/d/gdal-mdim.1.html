NOM

gdal mdim - Point d'entrée pour les commandes multidimensionnelles

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal mdim <SOUS-COMMANDE> [OPTIONS]
où <SOUS-COMMANDE> est l'une des suivantes :
  convert: Convertir un jeu de données multidimensionnel.
  info:    Retourne des informations sur un jeu de données multidimensionnel.
  mosaic:  Construire une mosaïque, virtuelle (VRT) ou matérialisée, à partir de jeux de données multidimensionnels.
Options communes :
  -h, --help              Affiche le message d'aide et quitte
  --json-usage            Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>  Option de configuration [peut être répétée]
Options :
  --drivers               Affiche la liste des pilotes multidimensionnels sous forme de document JSON

SOUS-COMMANDES DISPONIBLES

  • gdal mdim info
  • gdal mdim convert
  • gdal mdim mosaic

EXEMPLES

Exemple 1: Obtenir des informations sur le fichier temperatures.nc (avec sortie JSON)

$ gdal mdim info temperatures.nc

Exemple 2: Convertir le fichier temperatures.nc en Zarr

$ gdal mdim convert temperatures.nc temperatures.zarr

Exemple 3: Obtenir la liste des pilotes multidimensionnels (avec sortie JSON)

$ gdal mdim --drivers
