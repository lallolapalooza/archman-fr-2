gdal-info - Obtenir des informations sur un jeu de

données

Ajouté dans la version 3.

11.

Sert de raccourci pour gdal raster info ou gdal vector info selon la na

ture du jeu de d
onnées spécifié.

SYNOPSI

S 
Utilisation : gdal info [OPTIONS] <ENTRÉE>
Retourne des informations sur un jeu de données (raccourci pour 'gdal raster info' ou 'gdal vector info').
Arguments positi
onnels : -i, --input <ENTRÉE> Jeu de données raster, vectoriel ou raster multidimensionnel en entrée [requis] Options communes : -h
, --help Afficher le message d'aide et quitter --json-usage Afficher l'utilisation
sous forme de document JSON et quitter --config <CLÉ>=<VALEUR> Option de configuration [peut être répétée] Options : -f, --of, --forma
t, --output-format <FORMAT-SORTIE> Format de sortie. FORMAT-SORTIE=json|text Pour toutes les options, exécutez 'gdal raster info --help' ou 'gdal vector info --help'
