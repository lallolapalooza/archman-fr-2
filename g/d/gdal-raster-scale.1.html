NOM

gdal-raster-scale - Met à l'échelle les valeurs des bandes d'un jeu de données raster

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal raster scale [OPTIONS] <ENTRÉE> <SORTIE>
Met à l'échelle les valeurs des bandes d'un jeu de données raster.
Arguments positionnels :
  -i, --input <ENTRÉE>                                      Jeux de données raster d'entrée [obligatoire]
  -o, --output <SORTIE>                                    Jeu de données raster de sortie [obligatoire]
Options courantes :
  -h, --help                                               Affiche le message d'aide et quitte
  --json-usage                                             Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>                                   Option de configuration [peut être répétée]
  -q, --quiet                                              Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>      Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLÉ>=<VALEUR>                    Option de création [peut être répétée]
  --overwrite                                              Autorise l'écrasement du fichier de sortie existant
                                                           Mutuellement exclusif avec --append
  --append                                                 Ajoute en tant que sous-jeu de données à la sortie existante
                                                           Mutuellement exclusif avec --overwrite
  --ot, --datatype, --output-data-type <TYPE-DONNÉES-SORTIE>  Type de données de sortie. TYPE-DONNÉES-SORTIE=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64
  -b, --band <BANDE>                                        Sélectionne la bande pour restreindre la mise à l'échelle (index basé sur 1)
  --src-min <SRC-MIN>                                      Valeur minimale de la plage source
  --src-max <SRC-MAX>                                      Valeur maximale de la plage source
  --dst-min <DST-MIN>                                      Valeur minimale de la plage de destination
  --dst-max <DST-MAX>                                      Valeur maximale de la plage de destination
  --exponent <EXPOSANT>                                    Exposant pour appliquer une mise à l'échelle non linéaire avec une fonction de puissance
  --no-clip                                                Ne pas rogner les valeurs d'entrée dans [srcmin, srcmax]
Options avancées :
  --if, --input-format <FORMAT-ENTRÉE>                      Formats d'entrée [peuvent être répétés]
  --oo, --open-option <CLÉ>=<VALEUR>                        Options d'ouverture [peuvent être répétées]

DESCRIPTION

gdal raster scale peut être utilisé pour mettre à l'échelle les valeurs des pixels d'entrée de la plage --src-min à --src-max vers la plage --dst-min à --dst-max. Il est également souvent nécessaire de réinitialiser le type de données de sortie avec le commutateur --ot. S'il est omis, la plage de sortie va de la valeur minimale à la valeur maximale autorisée pour les types de données entiers (par exemple, de 0 à 255 pour une sortie Byte) ou de 0 à 1 pour les types de données flottants. S'il est omis, la plage d'entrée est automatiquement calculée à partir du jeu de données source. Cela peut être une opération lente sur un grand jeu de données source, et si vous l'utilisez plusieurs fois pour plusieurs invocations de gdal_translate, il pourrait être bénéfique d'appeler préalablement gdal raster edit --stats {source_dataset} pour précalculer les statistiques, pour les formats qui prennent en charge la sérialisation des calculs de statistiques (GeoTIFF, VRT...). Les valeurs sources sont rognées dans la plage définie par srcmin et srcmax, sauf si --no-clip est défini.

Par défaut, la mise à l'échelle est appliquée à toutes les bandes. Il est possible de la restreindre à une seule bande avec --band et de laisser les valeurs des autres bandes inchangées.

Cette commande est l'opération inverse de gdal raster unscale.

Cette sous-commande est également disponible en tant qu'étape potentielle de gdal raster pipeline

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format de sortie raster utiliser. Les valeurs autorisées peuvent être données par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les détails du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être découpé en tuiles.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être obtenue avec l'option de ligne de commande --formats, mais la documentation du format est la source d'information définitive sur les options de création des pilotes. Consultez la documentation spécifique du format Pilotes raster pour connaître les options de création valides pour chaque format.

--overwrite
Permet au programme d'écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal renvoie une erreur si le fichier ou le jeu de données cible existe déjà.
--ot, --datatype, --output-data-type <TYPE-DONNÉES-SORTIE>
Type de données de sortie parmi Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.
-b, --band <BANDE>
Index (commençant à 1) de la bande à laquelle la mise à l'échelle doit s'appliquer uniquement.
--src-min <SRCMIN>
Valeur minimale de la plage source. Si elle n'est pas spécifiée, elle sera calculée à partir du jeu de données d'entrée. Cette option doit être utilisée conjointement avec --src-max.
--src-max <SRCMAX>
Valeur maximale de la plage source. Si elle n'est pas spécifiée, elle sera calculée à partir du jeu de données source. Cette option doit être utilisée conjointement avec --src-min.
--dst-min <DSTMIN>
Valeur minimale de la plage de sortie. Cette option doit être utilisée conjointement avec --dst-max.
--dst-max <DSTMAX>
Valeur maximale de la plage de sortie. Cette option doit être utilisée conjointement avec --dst-min.
--exponent <EXPOSANT>
Applique une mise à l'échelle non linéaire avec une fonction de puissance. exp_val est l'exposant de la fonction de puissance (doit être positif). Cette option doit être utilisée avec les options --src-min / --src-max / --dst-min / --dst-max.

La valeur mise à l'échelle Dst est calculée à partir de la valeur source Src avec la formule suivante :


{Dst} = \left( {Dst}_{max} - {Dst}_{min} \right) \times \operatorname{max} \left( 0, \operatorname{min} \left( 1, \left( \frac{{Src} - {Src}_{min}}{{Src}_{max}-{Src}_{min}} \right)^{exp\_val} \right) \right) + {Dst}_{min}



NOTE :

gdal raster unscale suppose une mise à l'échelle linéaire, et ne peut pas redonner les valeurs d'origine.
--no-clip
Désactive le rognage des valeurs d'entrée dans la plage source. Notez que l'utilisation de cette option avec une mise à l'échelle non linéaire et un exposant non entier entraînera le mappage des valeurs d'entrée inférieures à la valeur minimale de la plage source vers "non un nombre" (NaN).
