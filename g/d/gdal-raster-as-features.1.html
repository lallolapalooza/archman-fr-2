NOM

gdal-raster-as-features - Créer des entités représentant les pixels d'une grille

Ajouté dans la version 3.12.

SYNTAXE

Usage : gdal raster as-features [OPTIONS] <ENTRÉE> <SORTIE>
Créer des entités à partir des pixels d'un jeu de données raster
Arguments positionnels :
  -i, --input <ENTRÉE>                                  Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données vectorielles de sortie [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <CLE>=<VALEUR>                                Option de configuration [peut être répétée]
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie (« GDALG » autorisé)
  --co, --creation-option <CLE>=<VALEUR>                Option de création [peut être répétée]
  --lco, --layer-creation-option <CLE>=<VALEUR>         Option de création de couche [peut être répétée]
  --overwrite                                          Indique si l'écrasement d'une sortie existante est autorisé
  --update                                             Indique si l'ouverture d'un jeu de données existant en mode mise à jour est autorisée
  --overwrite-layer                                    Indique si l'écrasement d'une sortie existante est autorisé
  --append                                             Indique si l'ajout à une couche existante est autorisé
  --output-layer <COUCHE-SORTIE>                        Nom de la couche de sortie
  -b, --band <BANDE>                                    Bande(s) d'entrée (indice basé sur 1) [peut être répétée]
  --geometry-type <TYPE-GEOMETRIE>                      Type de géométrie. TYPE-GEOMETRIE=none|point|polygon (défaut : none)
  --skip-nodata                                        Omettre les pixels NoData du résultat
  --include-xy                                         Inclure les champs pour les coordonnées du centre de la cellule
  --include-row-col                                    Inclure les colonnes pour la ligne et la colonne
Options avancées :
  --if, --input-format <FORMAT-ENTREE>                  Formats d'entrée [peut être répété]
  --oo, --open-option <CLE>=<VALEUR>                    Options d'ouverture [peut être répétée]
  --output-oo, --output-open-option <CLE>=<VALEUR>      Options d'ouverture de sortie [peut être répétée]

DESCRIPTION

gdal raster as-features crée des entités représentant les pixels d'un jeu de données raster. Les entités peuvent être créées sous forme de polygones, de points, ou sans aucune géométrie. Contrairement à gdal raster polygonize, les pixels adjacents ayant les mêmes valeurs ne sont pas combinés.

Cet algorithme peut faire partie d'un pipeline gdal ou d'un pipeline raster gdal.

Les options suivantes sont disponibles :

--geometry-type
Spécifie le type de géométrie des entités créées. Les options disponibles sont « none » (par défaut), « point » ou « polygon ».
--skip-nodata
Si défini, aucune entité ne sera émise pour les pixels égaux à la valeur NoData.
--include-xy
Si défini, des champs CENTER_X et CENTER_Y seront ajoutés avec les coordonnées du centre de chaque pixel.
--include-row-col
Si défini, des champs ROW et COL seront ajoutés avec les positions des cellules.
-b <bande>
Spécifie les bandes pour lesquelles les valeurs de pixels doivent être ajoutées comme champs des entités créées. Par défaut, les valeurs seront ajoutées pour toutes les bandes.
-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format vectoriel de sortie utiliser. Les valeurs autorisées peuvent être obtenues par gdal --formats | grep vector | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression et si le fichier doit être segmenté.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être listée avec l'option de ligne de commande --formats, mais la documentation du format est la source faisant autorité pour les informations sur les options de création du pilote. Voir la documentation spécifique du format de Pilotes raster pour les options de création légales pour chaque format.

--overwrite
Permet au programme d'écraser un fichier ou un jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.

EXEMPLES

Exemple 1 : Créer des points au centre des pixels ayant une valeur inférieure à 150

gdal pipeline read input.tif !
         reclassify -m "[-inf, 150)=1; DEFAULT=NO_DATA" !
         as-features --geometry-type point --skip-nodata !
         write out.shp
