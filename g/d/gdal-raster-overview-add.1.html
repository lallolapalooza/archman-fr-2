NOM

gdal-raster-overview-add - Ajouter des aperçus à un jeu de données raster

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal raster overview add [OPTIONS] <INPUT>
Ajout des aperçus.
Arguments positionnels :
  -i, --dataset, --input <INPUT>         Jeu de données (à mettre à jour sur place, sauf si --external) [requis]
Options communes :
  -h, --help                             Afficher le message d'aide et quitter
  --json-usage                           Afficher l'utilisation sous forme de document JSON et quitter
  --config <KEY>=<VALUE>                 Option de configuration [peut être répétée]
  -q, --quiet                            Mode silencieux (pas de barre de progression)
Options :
  --overview-src <OVERVIEW-SRC>          Jeu de données d'aperçu source [peut être répété]
                                         Mutuellement exclusif avec --levels
  --external                             Ajouter des aperçus externes
  -r, --resampling <RESAMPLING>          Méthode de rééchantillonnage. RESAMPLING=nearest|average|cubic|cubicspline|lanczos|bilinear|gauss|average_magphase|rms|mode
  --levels <LEVELS>                      Niveaux / facteurs de décimation [peut être répété]
                                         Mutuellement exclusif avec --overview-src
  --min-size <MIN-SIZE>                  Largeur ou hauteur maximale du plus petit niveau d'aperçu.
  --co, --creation-option <KEY>=<VALUE>  Option de création d'aperçu [peut être répétée]
Options avancées :
  --oo, --open-option <KEY>=<VALUE>      Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster overview add peut être utilisé pour construire ou reconstruire des images d'aperçus pour la plupart des formats de fichiers pris en charge avec l'un des plusieurs algorithmes de sous-échantillonnage.

À partir de GDAL 3.12, gdal raster overview add peut être utilisé comme étape d'un pipeline. Dans ce cas, des aperçus virtuels sont générés à la sortie de l'étape, et peuvent potentiellement être matérialisés dans l'étape d'écriture finale, lors de l'écriture d'un fichier GeoTIFF avec l'option de création COPY_SRC_OVERVIEWS, ou lors de l'écriture vers un fichier COG (Cloud Optimized GeoTIFF).

Options

--dataset <DATASET>
Nom du jeu de données, à mettre à jour sur place par défaut (sauf si --external est spécifié). Requis pour une exécution autonome, implicite lors d'une exécution en tant qu'étape de pipeline.
--external
Créer des aperçus externes .ovr sous forme de fichiers GeoTIFF. Non disponible lors d'une exécution en tant qu'étape de pipeline.
--overview-src <INPUT>
Ajouté dans la version 3.12.

Ajouter les jeux de données raster d'entrée spécifiés comme aperçus du jeu de données cible. Les aperçus sources peuvent provenir de n'importe quel format pris en charge par GDAL, à condition qu'ils aient le même nombre de bandes et la même étendue géospatiale que le jeu de données cible.

Ce mode est actuellement implémenté uniquement lorsque le jeu de données cible est au format GeoTIFF, ou lors de l'utilisation de --external.

Mutuellement exclusif avec --levels.

--resampling {nearest|average|cubic|cubicspline|lanczos|bilinear|gauss|average_magphase|rms|mode}
Sélectionner un algorithme de rééchantillonnage. La valeur par défaut est nearest, ce qui n'est généralement pas approprié si une précision infra-pixel est souhaitée.

Lors du rafraîchissement d'aperçus TIFF existants, la méthode précédemment utilisée, telle que notée dans l'élément de métadonnées RESAMPLING de l'aperçu, sera utilisée si -r n'est pas spécifié.

Les méthodes disponibles sont :

nearest applique un rééchantillonneur par voisinage le plus proche (échantillonnage simple).

average calcule la moyenne de tous les pixels contribuant non-NODATA. Il s'agit d'une moyenne pondérée tenant correctement compte du poids des pixels sources ne contribuant pas entièrement au pixel cible.

bilinear applique un noyau de convolution bilinéaire.

cubic applique un noyau de convolution cubique.

cubicspline applique un noyau de convolution B-Spline.

lanczos applique un noyau sinc fenêtré de Lanczos.

gauss applique un noyau Gaussien avant de calculer l'aperçu, ce qui peut conduire à de meilleurs résultats qu'une simple moyenne dans le cas par exemple de bords nets avec un contraste élevé ou de motifs bruités. Les valeurs de niveau conseillées devraient être 2, 4, 8, ... afin qu'un noyau Gaussien de rééchantillonnage 3x3 soit sélectionné.

average_magphase moyenne les données complexes dans l'espace mag/phase.

rms calcule la moyenne quadratique de tous les pixels contribuant non-NODATA.

mode sélectionne la valeur qui apparaît le plus souvent parmi tous les points échantillonnés.

--levels <niveau1,niveau2,...>
Une liste de niveaux d'aperçus à construire. Chaque niveau d'aperçu doit être une valeur entière supérieure ou égale à 2.

Lorsque les niveaux explicites ne sont pas spécifiés,

  • S'il existe déjà des aperçus, les niveaux correspondants seront utilisés pour les rafraîchir si aucun niveau explicite n'est spécifié.
  • Sinon, des facteurs de puissance de deux d'aperçus appropriés seront sélectionnés jusqu'à ce que le plus petit aperçu soit plus petit que la valeur du commutateur --min-size.

Mutuellement exclusif avec --overview-src.

--min-size <val>
Largeur ou hauteur maximale du plus petit niveau d'aperçu. Seulement pris en compte si les niveaux explicites ne sont pas spécifiés. Par défaut à 256.
--co <NAME>=<VALUE>
Ajouté dans la version 3.12.

Options de création d'aperçu. Peut être répété.

De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les particularités des aperçus créés. Les options disponibles peuvent être obtenues en consultant la liste OverviewCreationOptionList renvoyée par gdal --format <NOM-FORMAT>.

La plupart des formats supporteront les aperçus externes dans un fichier GeoTIFF dans un fichier secondaire d'extension .ovr. Vous pouvez consulter les options de création d'aperçu pour GeoTIFF.

EXEMPLES

Exemple 1 : Créer des aperçus, intégrés dans le fichier TIFF fourni, avec calcul automatique des niveaux

gdal raster overview add -r average abc.tif

Exemple 2 : Créer des aperçus, intégrés dans le fichier TIFF fourni

gdal raster overview add -r average --levels=2,4,8,16 abc.tif

Exemple 3 : Créer un fichier d'aperçu GeoTIFF compressé externe à partir du fichier ERDAS .IMG

gdal raster overview add --external --levels=2,4,8,16 --co COMPRESS=YES erdas.img
