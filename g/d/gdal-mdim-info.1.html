NOM

gdal-mdim-info - Obtenir des informations sur un jeu de données multidimensionnel

Ajouté dans la version 3.11.

SYNTAXE

Utilisation : gdal mdim info [OPTIONS] <ENTREE>
Retourne des informations sur un jeu de données multidimensionnel.
Arguments positionnels :
  -i, --dataset, --input <ENTREE>       Jeu de données raster multidimensionnel d'entrée [requis]
Options communes :
  -h, --help                           Affiche le message d'aide et quitte
  --json-usage                         Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>               Option de configuration [peut être répétée]
Options :
  --detailed                           Sortie la plus détaillée. Rapporte les types de données des attributs et les valeurs des tableaux.
  --array <TABLEAU>                    Nom du tableau, utilisé pour restreindre la sortie au tableau spécifié.
  --limit <LIMITE>                     Nombre de valeurs dans chaque dimension utilisé pour limiter l'affichage des valeurs de tableau.
  --array-option <CLE>=<VALEUR>        Option passée à GDALGroup::GetMDArrayNames() pour filtrer les tableaux rapportés. [peut être répétée]
  --stats                              Lire et afficher les statistiques d'image.
Options avancées :
  --oo, --open-option <CLE>=<VALEUR>    Options d'ouverture [peut être répétée]
  --if, --input-format <FORMAT-ENTREE>  Formats d'entrée [peut être répétée]

DESCRIPTION

gdal mdim info liste diverses informations sur un jeu de données multidimensionnel supporté par GDAL.

Les éléments suivants seront rapportés (lorsqu'ils sont connus) sous forme de JSON :

  • Le pilote de format utilisé pour accéder au fichier.
  • Hiérarchie des groupes
  • Attributs des groupes
Tableaux :
  • Nom
  • Nom de la dimension, tailles, variable d'indexation
  • Type de données
  • Attributs
  • SRS
  • Valeur nodata
  • Unités
  • Statistiques (si demandées)

Les options suivantes sont disponibles :

Options standard

--detailed
Sortie la plus détaillée. Rapporte les types de données des attributs et les valeurs des tableaux.
--array <nom_tableau>
Nom du tableau utilisé pour restreindre la sortie au tableau spécifié.

NOTE :

La complétion Bash pour --array est possible si le nom du jeu de données est spécifié avant.
--limit <nombre>
Nombre de valeurs dans chaque dimension utilisé pour limiter l'affichage des valeurs de tableau. Par défaut, illimité. Uniquement pris en compte si utilisé avec -detailed.
--array-option <NOM>=<VALEUR>
Option passée à GDALGroup::GetMDArrayNames() pour filtrer les tableaux rapportés. Une telle option est spécifique au format. Consultez la documentation du pilote. Cette option peut être utilisée plusieurs fois.

NOTE :

La complétion Bash pour --array-option est possible si le nom du jeu de données est spécifié avant.
--stats
Lire et afficher les statistiques des tableaux. Force le calcul si aucune statistique n'est stockée dans un tableau.

Options avancées

--oo <NOM>=<VALEUR>
Option d'ouverture du jeu de données (spécifique au format).

Peut être répété.

--if <format>
Nom du format/pilote à tenter pour ouvrir les fichiers d'entrée. Il n'est généralement pas nécessaire de le spécifier, mais il peut être utilisé pour sauter la détection automatique du pilote, lorsque celle-ci échoue à sélectionner le pilote approprié. Cette option peut être répétée plusieurs fois pour spécifier plusieurs pilotes candidats. Notez qu'elle ne force pas ces pilotes à ouvrir le jeu de données. En particulier, certains pilotes ont des exigences sur les extensions de fichiers.

Peut être répété.
