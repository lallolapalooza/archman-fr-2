NOM

gdal-raster-tpi - Génère une carte d'indice de position topographique (TPI)

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal raster tpi [OPTIONS] <ENTREE> <SORTIE>
Génère une carte d'indice de position topographique (TPI)
Arguments positionnels :
  -i, --input <ENTREE>                                 Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                Jeu de données raster de sortie [requis]
Options communes :
  -h, --help                                           Affiche le message d'aide et quitte
  --json-usage                                         Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLE>=<VALEUR>                              Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLE>=<VALEUR>            Option de création [peut être répétée]
  --overwrite                                          Autorise l'écrasement des sorties existantes
                                                       Mutuellement exclusif avec --append
  --append                                             Ajoute en tant que sous-ensemble de sortie existante
                                                       Mutuellement exclusif avec --overwrite
  -b, --band <BANDE>                                    Bande d'entrée (indice basé sur 1) (défaut : 1)
  --no-edges                                           N'essaie pas d'interpoler les valeurs aux bords du jeu de données ou près des valeurs nodata
Options avancées :
  --if, --input-format <FORMAT-ENTREE>                 Formats d'entrée [peut être répété]
  --oo, --open-option <CLE>=<VALEUR>                 Options d'ouverture [peut être répétée]

DESCRIPTION

gdal raster tpi génère un raster à bande unique avec des valeurs calculées à partir de l'élévation. TPI signifie Topographic Position Index, qui est défini comme la différence entre un pixel central et la moyenne de ses cellules environnantes (voir Wilson et al 2007, Marine Geodesy 30:3-35).

Cette sous-commande est également disponible en tant qu'étape potentielle du gdal raster pipeline

La valeur -9999 est utilisée comme valeur nodata.

Une valeur nodata dans le jeu de données cible sera également émise si au moins un pixel défini à la valeur nodata est trouvé dans la fenêtre 3x3 centrée autour de chaque pixel source. Par défaut, l'algorithme calculera des valeurs aux bords de l'image ou si une valeur nodata est trouvée dans la fenêtre 3x3, par interpolation des valeurs manquantes, à moins que --no-edges ne soit spécifié, auquel cas une bordure de 1 pixel autour de l'image sera définie avec la valeur nodata.

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format raster de sortie utiliser. Les valeurs autorisées peuvent être fournies par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création facultatives qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge des options de création pour contrôler la compression et si le fichier doit être tuilé.

Peut être répété.

Les options de création disponibles varient selon le pilote du format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être obtenue avec l'option de ligne de commande --formats, mais la documentation du format est la source d'information faisant autorité sur les options de création du pilote. Voir la documentation spécifique du format Pilotes raster pour les options de création valides pour chaque format.

--overwrite
Permet au programme d'écraser un fichier ou un jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
-b, --band <BANDE>
Indice (à partir de 1) de la bande pour laquelle le TPI doit être calculé.
--no-edges
N'essaie pas d'interpoler les valeurs aux bords du jeu de données ou près des valeurs nodata

SORTIE GDALG (SUR VOL / DONNÉES EN FLUX)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON à l'aide du format de sortie GDALG. Le fichier résultant peut ensuite être ouvert en tant que jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié d'une manière sur vol / en flux.

EXEMPLES

Exemple 1 : Génère une carte d'indice de position topographique (TPI) à partir d'un fichier DTED0.

$ gdal raster tpi n43.dt0 out.tif --overwrite
