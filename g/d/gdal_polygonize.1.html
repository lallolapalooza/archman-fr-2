NOM

gdal_polygonize - Produit une couche de fonctionnalités vectorielles à partir d'une raster.

SYNTAXE

gdal_polygonize [--help] [--help-general]
                   [-8] [-o <name>=<value>]... [-nomask]
                   [-mask <filename>] <raster_file> [-b <band>]
                   [-q] [-f <ogr_format>] [-lco <name>=<value>]...
                   [-overwrite] <out_file> [<layer>] [<fieldname>]

DESCRIPTION

Cet utilitaire crée des polygones vectoriels pour toutes les régions connectées de pixels dans la raster partageant une valeur de pixel commune. Chaque polygone est créé avec un attribut indiquant la valeur du pixel de ce polygone. Un masque raster peut également être fourni pour déterminer quels pixels sont éligibles pour le traitement.

L'utilitaire créera la source de données vectorielles de sortie si elle n'existe pas déjà, sinon il tentera d'ajouter à une source existante.

L'utilitaire est basé sur la fonction :GDALPolygonize() qui contient des détails supplémentaires sur l'algorithme.

NOTE :

gdal_polygonize est un utilitaire Python, et n'est disponible que si les liaisons Python GDAL sont disponibles.
--help
Affiche ce message d'aide et quitte
--help-general
Donne un bref message d'utilisation pour les options de ligne de commande GDAL génériques et quitte.
-8
Utilise la connexion 8. La valeur par défaut est la connexion 4.
-nomask
N'utilise pas le masque de validité par défaut pour la bande d'entrée (comme les masques nodata ou alpha).
-mask <filename>
Utilise la première bande du fichier spécifié comme masque de validité (zéro est invalide, non-zéro est valide). Si non spécifié, le masque de validité par défaut pour la bande d'entrée (comme les masques nodata ou alpha) sera utilisé (sauf si -nomask est spécifié)
<raster_file>
Le fichier raster source à partir duquel les polygones sont dérivés.
-b <band>
La bande sur <raster_file> pour construire les polygones. La valeur peut également être définie sur "mask", pour indiquer que le masque de bande de la première bande doit être utilisé (ou "mask,band_number" pour le masque d'une bande spécifiée)
-f <ogr_format>
Sélectionne le format de sortie. Si non spécifié, le format est deviné à partir de l'extension. Utiliser le nom court du format
-o <NAME>=<VALUE>
Ajouté dans la version 3.7.

Option Polygonize. Voir la documentation :GDALPolygonize().

-lco <NAME>=<VALUE>
Ajouté dans la version 3.7.

Option de création de couche (spécifique au format)

-overwrite
Ajouté dans la version 3.8.

Écrase la couche de sortie si elle existe déjà.

<out_file>
Le fichier vectoriel de destination où les polygones seront écrits.
<layer>
Le nom de la couche créée pour contenir les fonctionnalités de polygones.
<fieldname>
Le nom du champ à créer (par défaut "DN").
-q
Le script s'exécute en mode silencieux. Le moniteur de progression est supprimé et les messages de routine ne sont pas affichés.
