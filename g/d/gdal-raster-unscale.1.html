NOM

gdal-raster-unscale - Convertit les valeurs mises à l'échelle d'un jeu de données raster en valeurs non mises à l'échelle

Ajouté dans la version 3.11.

SYNTAXE

Usage: gdal raster unscale [OPTIONS] <ENTRÉE> <SORTIE>
Convertit les valeurs mises à l'échelle d'un jeu de données raster en valeurs non mises à l'échelle.
Arguments positionnels :
  -i, --input <ENTRÉE>                                      Jeux de données raster d'entrée [requis]
  -o, --output <SORTIE>                                    Jeu de données raster de sortie [requis]
Options communes :
  -h, --help                                               Affiche le message d'aide et quitte
  --json-usage                                             Affiche l'utilisation sous forme de document JSON et quitte
  --config <CLÉ>=<VALEUR>                                   Option de configuration [peut être répétée]
  -q, --quiet                                              Mode silencieux (pas de barre de progression)
Options :
  -f, --of, --format, --output-format <FORMAT-SORTIE>      Format de sortie ("GDALG" autorisé)
  --co, --creation-option <CLÉ>=<VALEUR>                    Option de création [peut être répétée]
  --overwrite                                              Autorise l'écrasement de la sortie existante
                                                           Mutuellement exclusif avec --append
  --append                                                 Ajouter comme sous-ensemble à la sortie existante
                                                           Mutuellement exclusif avec --overwrite
  --ot, --datatype, --output-data-type <TYPE-DONNÉES-SORTIE>  Type de données de sortie. TYPE-DONNÉES-SORTIE=Byte|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64

DESCRIPTION

gdal raster unscale applique les métadonnées d'échelle/décalage des bandes pour convertir les valeurs mises à l'échelle en valeurs non mises à l'échelle.

Si le type de données de la bande d'entrée est Byte, Int8, UInt16, Int16, UInt32, Int32, Int64, UInt64, Float16 ou Float32, le type de données de sortie par défaut sera Float32. Si le type de données de la bande d'entrée est Float64, il sera conservé comme type de données de sortie par défaut. Si le type de données de la bande d'entrée est CInt16, CFloat16 ou CFloat32, le type de données de sortie par défaut sera Float32. Si le type de données de la bande d'entrée est CFloat64, il sera conservé comme type de données de sortie par défaut.

La valeur non mise à l'échelle est calculée à partir de la valeur brute mise à l'échelle avec la formule suivante :


{valeur\_non\_mise\_à\_l'échelle} = {valeur\_mise\_à\_l'échelle} * {échelle} + {décalage}



Si l'une des bandes d'entrée n'a pas de métadonnées d'échelle/décalage, ses valeurs sont conservées sans modification.

Cette commande est l'opération inverse de gdal raster scale.

Ce sous-commande est également disponible en tant qu'étape potentielle de gdal raster pipeline

Options standard

-f, --of, --format, --output-format <FORMAT-SORTIE>
Quel format de raster de sortie utiliser. Les valeurs autorisées peuvent être obtenues par gdal --formats | grep raster | grep rw | sort
--co <NOM>=<VALEUR>
De nombreux formats ont une ou plusieurs options de création optionnelles qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoTIFF prend en charge les options de création pour contrôler la compression et si le fichier doit être découpé en tuiles.

Peut être répété.

Les options de création disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options supportées pour un format peut être listée avec l'option de commande --formats, mais la documentation du format est la source d'information définitive sur les options de création du pilote. Voir la documentation spécifique au format Pilotes raster pour les options de création légales pour chaque format.

--overwrite
Permet au programme d'écraser un fichier ou un jeu de données cible existant. Sinon, par défaut, gdal génère une erreur si le fichier ou le jeu de données cible existe déjà.
--ot, --datatype, --output-data-type <TYPE-DONNÉES-SORTIE>
Type de données de sortie parmi Byte, Int8, UInt16, Int16, UInt32, Int32, UInt64, Int64, CInt16, CInt32, Float32, Float64, CFloat32, CFloat64.

SORTIE GDALG (SUR VOL / JEU DE DONNÉES EN FLUX)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON en utilisant le format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données raster en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière sur vol / en flux.

EXEMPLES

Exemple 1 : Démise à l'échelle d'un raster mis à l'échelle vers un raster Float32

$ gdal raster unscale scaled_byte.tif unscaled_float32.tif --overwrite
