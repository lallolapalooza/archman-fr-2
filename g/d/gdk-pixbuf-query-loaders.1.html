Nom

gdk-pixbuf-query-loaders - Utilitaire d'enregistrement des chargeurs GdkPixbuf

SYNTAXE

gdk-pixbuf-query-loaders [OPTIONS...] [MODULES..]

DESCRIPTION

gdk-pixbuf-query-loaders collecte des informations sur les modules chargeables pour gdk-pixbuf et les écrit dans l'emplacement du cache par défaut, ou sur stdout.

S'il est appelé sans arguments, il recherche les modules dans le répertoire des chargeurs gdk-pixbuf.

S'il est appelé avec des arguments, il recherche les modules spécifiés. Les arguments peuvent être des chemins absolus ou relatifs.

Normalement, la sortie de gdk-pixbuf-query-loaders est écrite dans $libdir/gdk-pixbuf-2.0/2.10.0/loaders.cache, où gdk-pixbuf la recherche par défaut. Si elle est écrite dans un autre emplacement, la variable d'environnement GDK_PIXBUF_MODULE_FILE peut être définie pour pointer gdk-pixbuf vers le fichier.

OPTIONS

--update-cache

Écrit la sortie à l'emplacement du cache par défaut au lieu de la sortie standard.

ENVIRONNEMENT

La variable d'environnement GDK_PIXBUF_MODULEDIR peut être utilisée pour spécifier un répertoire de chargeurs différent.

Le répertoire de chargeurs gdk-pixbuf par défaut est LIBDIR/gdk-pixbuf-2.0/VERSION/loaders, où :

  • LIBDIR est le répertoire lib utilisé lors de la compilation de gdk-pixbuf
  • VERSION est la version ABI pour les chargeurs gdk-pixbuf
