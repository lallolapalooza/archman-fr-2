NOM

gdalmove - Transforme le géoréférencement d'un fichier raster sur place.

SYNOPIS

gdalmove [--help] [--help-general]
            [-s_srs <srs_defn>] -t_srs <srs_defn>
            [-et <max_pixel_err>] <fichier_cible>

DESCRIPTION

Le script gdalmove transforme les limites d'un fichier raster d'un système de coordonnées à un autre, puis met à jour le système de coordonnées et le géoréférencement du fichier. Ceci est fait sans altérer du tout les valeurs des pixels. C'est un peu similaire à l'utilisation de gdalwarp pour transformer une image, mais en évitant l'étape de rééchantillonnage afin d'éviter d'endommager l'image. Il convient généralement uniquement aux transformations qui sont effectivement linéaires dans la zone du fichier.

Si aucune valeur de seuil d'erreur (-et) n'est fournie, le fichier n'est pas réellement mis à jour, mais les erreurs qui seraient encourues sont rapportées. Si -et est fourni, le fichier n'est modifié que si l'erreur apparente introduite est inférieure au seuil indiqué (en pixels).

Actuellement, le géoréférencement transformé est calculé en se basant sur la transformation des coins supérieur gauche, supérieur droit et inférieur gauche. Une erreur globale réduite pourrait être obtenue en utilisant un ajustement par moindres carrés d'au moins les quatre points d'angle.

NOTE :

gdalmove est un utilitaire Python et n'est disponible que si les liaisons Python de GDAL sont disponibles.
--help
Affiche ce message d'aide et quitte.
--help-general
Donne un bref message d'utilisation pour les options génériques de ligne de commande GDAL et quitte.
-s_srs <srs_defn>
Remplace le système de coordonnées du fichier par la définition de système de coordonnées indiquée. Facultatif. S'il n'est pas fourni, le système de coordonnées source est lu à partir du fichier source.
-t_srs <srs_defn>
Définit le système de coordonnées cible. Ce système de coordonnées sera écrit dans le fichier après une mise à jour.
-et <max_pixel_err>
Le seuil d'erreur (en pixels) au-delà duquel le fichier ne sera pas mis à jour. S'il n'est pas fourni, aucune mise à jour ne sera appliquée au fichier, mais les erreurs seront rapportées.

<fichier_cible>

Le fichier sur lequel opérer. Pour mettre à jour, il doit s'agir d'un format de fichier qui prend en charge les mises à jour sur place du géoréférencement et du SRS.
