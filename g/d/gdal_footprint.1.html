NAME

gdal_footprint - Calculates the footprint of a raster dataset.

SYNOPSIS

gdal_footprint [options] src_filename dst_filename

DESCRIPTION

The gdal_footprint utility creates a vector layer containing the geographic footprint of a raster dataset. The footprint is generally a polygon representing the extent of the raster data.

The following options are available:

-dsco <NAME>=<VALUE>
Option de création de jeu de données (spécifique au format)
-lyr_name <valeur>
Nom de la couche cible. footprint si non spécifié.
-overwrite
Écrase la couche cible si elle existe.
<nom_fichier_source>
Le nom du fichier raster source.
<nom_fichier_destination>
Le nom du fichier vecteur de destination. Si le fichier et la couche de sortie existent, l'empreinte est ajoutée à ceux-ci, sauf si -overwrite est utilisé.

Les opérations géométriques post-vectorisation sont appliquées dans l'ordre suivant :

  • division optionnelle (-split_polys)
  • densification optionnelle (-densify)
  • reprojection optionnelle (-t_srs)
  • filtrage optionnel par surface de bague minimale (-min_ring_area)
  • application optionnelle de l'enveloppe convexe (-convex_hull)
  • simplification optionnelle (-simplify)
  • limitation du nombre de points (-max_points)

C API

Cet utilitaire est également appelable depuis C avec GDALFootprint().

EXAMPLES

Exemple 1: Calculer l'empreinte d'un fichier GeoTIFF en tant que fichier GeoJSON

gdal_footprint -t_srs EPSG:4326 input.tif output.geojson

L'empreinte sera écrite en utilisant les coordonnées longitude, latitude WGS84, quel que soit le système de référence spatiale utilisé par le raster d'entrée.
