NOM

gdal-vector-set-geom-type - Modifier le type de géométrie d'un ensemble de données vectorielles

Ajouté dans la version 3.12.

SYNOPSIS

Utilisation : gdal vector set-geom-type [OPTIONS] <INPUT> <OUTPUT>
Modifier le type de géométrie d'un ensemble de données vectorielles.
Arguments positionnels :
  -i, --input <INPUT>                                  Jeux de données vectorielles en entrée [requis]
  -o, --output <OUTPUT>                                Jeux de données vectorielles en sortie [requis]
Options communes :
  -h, --help                                           Afficher le message d'aide et quitter
  --json-usage                                         Afficher l'utilisation sous forme de document JSON et quitter
  --config <KEY>=<VALUE>                               Option de configuration [peut être répétée]
  -q, --quiet                                          Mode silencieux (pas de barre de progression)
Options :
  -l, --layer, --input-layer <INPUT-LAYER>             Nom(s) de couche(s) en entrée [peut être répété]
  -f, --of, --format, --output-format <OUTPUT-FORMAT>  Format de sortie ("GDALG" autorisé)
  --co, --creation-option <KEY>=<VALUE>                Option de création [peut être répétée]
  --lco, --layer-creation-option <KEY>=<VALUE>         Option de création de couche [peut être répétée]
  --overwrite                                          Indique si l'écrasement de la sortie existante est autorisé
  --update                                             Indique si l'ouverture du jeu de données existant se fait en mode mise à jour
  --overwrite-layer                                    Indique si l'écrasement de la sortie existante est autorisé
  --append                                             Indique si l'ajout à une couche existante est autorisé
                                                       Exclusif mutuellement avec --upsert
  --output-layer <OUTPUT-LAYER>                        Nom de la couche en sortie
  --skip-errors                                        Ignorer les erreurs lors de l'écriture des entités
  --active-layer <ACTIVE-LAYER>                        Définir la couche active (si non spécifiée, toutes)
  --active-geometry <ACTIVE-GEOMETRY>                  Nom du champ de géométrie auquel restreindre le traitement (si non spécifié, tous)
  --layer-only                                         Modifier uniquement le type de géométrie de la couche
                                                       Exclusif mutuellement avec --feature-only
  --feature-only                                       Modifier uniquement le type de géométrie des entités
                                                       Exclusif mutuellement avec --layer-only
  --geometry-type <GEOMETRY-TYPE>                      Type de géométrie
  --multi                                              Forcer les géométries vers des types de géométrie MULTI
                                                       Exclusif mutuellement avec --single
  --single                                             Forcer les géométries vers des types de géométrie non-MULTI
                                                       Exclusif mutuellement avec --multi
  --linear                                             Convertir les géométries courbes en types linéaires
                                                       Exclusif mutuellement avec --curve
  --curve                                              Convertir les géométries linéaires en types courbes
                                                       Exclusif mutuellement avec --linear
  --dim <DIM>                                          Forcer les géométries vers la dimension spécifiée. DIM=XY|XYZ|XYM|XYZM
  --skip                                               Ignorer l'entité lorsque le changement du type de géométrie de l'entité échoue
Options avancées :
  --if, --input-format <INPUT-FORMAT>                  Formats en entrée [peut être répété]
  --oo, --open-option <KEY>=<VALUE>                    Options d'ouverture [peut être répétée]
  --output-oo, --output-open-option <KEY>=<VALUE>      Options d'ouverture en sortie [peut être répétée]
  --upsert                                             Mettre à jour ou insérer les entités (implique 'append')
                                                       Exclusif mutuellement avec --append

DESCRIPTION

gdal vector set-geom-type peut être utilisé pour modifier le type de géométrie des champs de géométrie au niveau de la couche et/ou de l'entité.

Il peut également être utilisé comme une étape de gdal vector pipeline.

Les groupes d'options suivants peuvent être combinés entre eux : - --multi / --single - --linear / --curve - --dim

Options standard

-f, --of, --format, --output-format <OUTPUT-FORMAT>
Quel format de vecteur de sortie utiliser. Les valeurs autorisées peuvent être fournies par gdal --formats | grep vector | grep rw | sort
--co <NAME>=<VALUE>
De nombreux formats ont une ou plusieurs options de création de jeu de données facultatives qui peuvent être utilisées pour contrôler les particularités du fichier créé. Par exemple, le pilote GeoPackage prend en charge des options de création pour contrôler la version.

Peut être répétée.

Les options de création de jeu de données disponibles varient selon le pilote de format, et certains formats simples n'ont aucune option de création. Une liste des options prises en charge pour un format peut être listée avec l' --formats option de ligne de commande, mais la documentation du format est la source définitive d'informations sur les options de création du pilote. Voir Pilotes vectoriels la documentation spécifique au format pour les options de création légales de chaque format.

Notez que les options de création de jeu de données sont différentes des options de création de couche.

-lco <NAME>=<VALUE>
Option de création de couche (spécifique au format)
--overwrite
Autoriser le programme à écraser le fichier ou le jeu de données cible existant. Sinon, par défaut, gdal renvoie une erreur si le fichier ou le jeu de données cible existe déjà.
--active-layer <ACTIVE-LAYER>
Définir la couche active. Lorsqu'elle est spécifiée, seule la couche spécifiée par son nom sera soumise au traitement. Les autres couches ne seront pas modifiées. Si cette option n'est pas spécifiée, toutes les couches seront soumises au traitement.
--active-geometry <ACTIVE-GEOMETRY>
Définir le champ de géométrie actif à partir de son nom. Lorsqu'il est spécifié, seul le champ de géométrie spécifié sera soumis au traitement. Les autres champs de géométrie ne seront pas modifiés. Si cette option n'est pas spécifiée, tous les champs de géométrie seront soumis au traitement. Cette option peut être combinée avec --active-layer.
--layer-only
Modifier uniquement le type de géométrie de la couche. Un cas d'utilisation typique est lorsque le type de géométrie de la couche est défini sur inconnu et que l'utilisateur sait que la couche ne contient que des géométries d'un type donné.
--feature-only
Modifier uniquement le type de géométrie des entités.
--geometry-type <GEOMETRY-TYPE>
Changer le type de géométrie pour qu'il soit l'un des suivants : GEOMETRY, POINT, LINESTRING, POLYGON, MULTIPOINT, MULTILINESTRING, MULTIPOLYGON, GEOMETRYCOLLECTION, CURVE, CIRCULARSTRING, COMPOUNDCURVE, SURFACE, CURVEPOLYGON, MULTICURVE, MULTISURFACE, POLYHEDRALSURFACE ou TIN. Z, M ou ZM peuvent être ajoutés aux valeurs ci-dessus pour indiquer la dimensionnalité.

Cette option est exclusivement mutuellement avec --multi, --single, --linear, --curve, et --dim.

--multi
Forcer les géométries vers des types de géométrie MULTI. p. ex. POINT ==> MULTIPOINT. Cette option est exclusivement mutuellement avec --single.
--single
Forcer les géométries vers des types de géométrie non-MULTI. p. ex. MULTIPOINT ==> POINT. Cette option est exclusivement mutuellement avec --multi. Les MultiPoint ou MultiLinestring comportant plus d'un composant seront conservés sans modification. Les MultiPolygon comportant plus d'un composant seront fusionnés en un seul polygone (probablement invalide selon la règle des OGC Simple Features), fusionnant tous leurs anneaux.
--linear
Force les géométries à être des types de géométrie linéaires/non-courbes, en approximant les arcs par des segments linéaires. L'approximation linéaire peut être contrôlée par les options de configuration OGR_ARC_STEPSIZE et OGR_ARC_MAX_GAP (spécifiées à l'aide de --config). par exemple, COMPOUNDCURVE ==> LINESTRING. Cette option est mutuellement exclusive avec --curve.
--curve
Force les géométries à être des types de géométrie courbes. par exemple, LINESTRING ==> COMPOUNDCURVE ou POLYGON ==> CURVEPOLYGON. Les points sont conservés sans modification. Cette option est mutuellement exclusive avec --linear.
--dim
Force les géométries à la dimension spécifiée (XY, XYZ, XYM, ou XYZM). Si la géométrie d'entrée manque de composantes Z ou M, elles seront définies à 0. Cette option est mutuellement exclusive avec --geometry-type.
--skip
Ignore une entité lorsque le changement de type de géométrie de l'entité a échoué (par exemple, en tentant de forcer un type de géométrie Point pour une géométrie LineString). Sinon, la géométrie source sera conservée sans modification (ce qui peut la rendre incompatible avec la couche de sortie si elle ne prend pas en charge les mélanges de types de géométrie). Cette option s'applique à la fois lorsque le type de géométrie cible est défini avec --geometry-type, ou avec l'un de --multi, --single, --linear et --curve.

Options avancées

--oo <NOM>=<VALEUR>
Option d'ouverture du jeu de données (spécifique au format).

Peut être répétée.

--if <format>
Nom du format/pilote à essayer pour ouvrir le(s) fichier(s) d'entrée. Il n'est généralement pas nécessaire de le spécifier, mais il peut être utilisé pour ignorer la détection automatique du pilote, lorsqu'elle échoue à sélectionner le pilote approprié. Cette option peut être répétée plusieurs fois pour spécifier plusieurs pilotes candidats. Notez qu'elle ne force pas l'ouverture du jeu de données par ces pilotes. En particulier, certains pilotes ont des exigences sur les extensions de fichier.

Peut être répétée.

Sortie GDAL (en vol / jeu de données en flux)

Ce programme prend en charge la sérialisation de la ligne de commande sous forme de fichier JSON à l'aide du format de sortie GDALG. Le fichier résultant peut ensuite être ouvert comme un jeu de données vectoriel en utilisant le pilote GDALG: GDAL Streamed Algorithm, et appliquer le pipeline spécifié de manière "en vol" / "en flux".

Exemples

Exemple 1 : Convertir un shapefile mélangeant polygones et multipolygones vers un GeoPackage avec des multipolygones.

$ gdal vector set-geom-type --geometry-type=MULTIPOLYGON in.shp out.gpkg --overwrite

Exemple 2 : Convertir un GeoPackage avec des géométries courbes vers un Shapefile (qui ne les prend pas en charge).

$ gdal vector set-geom-type --linear in.gpkg out.shp --overwrite
