gnutls_certificate_set_ocsp_status_request_mem(3)

gnutls_certificate_set_ocsp_status_request_mem(3) gnutls gnutls_certificate_set_ocsp_status_request_mem(3)

NOM

gnutls_certificate_set_ocsp_status_request_mem - Fonction API

SYNOPIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_ocsp_status_request_mem(gnutls_certificate_credentials_t sc, const gnutls_datum_t * resp_data, unsigned idx, gnutls_x509_crt_fmt_t fmt);

ARGUMENTS

gnutls_certificate_credentials_t sc
est une structure de credentials.
const gnutls_datum_t * resp_data
un tampon mémoire contenant une réponse OCSP
unsigned idx
est un index de certificat tel que retourné par gnutls_certificate_set_key() et similaires
gnutls_x509_crt_fmt_t fmt
est PEM ou DER

DESCRIPTION

Cette fonction définit les réponses OCSP à envoyer au pair pour la chaîne de certificats spécifiée par idx. Lorsque fmt est réglé sur PEM, plusieurs réponses peuvent être chargées.

NOTE

La capacité de définir plusieurs réponses OCSP par structure de credential via l'index idx a été ajoutée dans la version 3.5.6. Pour des raisons de compatibilité ascendante, elle nécessite l'utilisation de gnutls_certificate_set_flags() avec le drapeau GNUTLS_CERTIFICATE_API_V2 pour que les fonctions de définition de certificat retournent un index utilisable par cette fonction.

Cette fonction doit être appelée après la définition de tout certificat, et ne peut pas être utilisée pour des certificats fournis via un rappel - c'est-à-dire lorsque gnutls_certificate_set_retrieve_function() est utilisé.

Cette fonction peut être appelée plusieurs fois lorsque plusieurs réponses s'appliquant à la chaîne de certificats sont disponibles. Si la réponse fournie ne correspond à aucun certificat présent dans la chaîne, le code GNUTLS_E_OCSP_MISMATCH_WITH_CERTS est retourné. Si la réponse est déjà expirée au moment du chargement, le code GNUTLS_E_EXPIRED est retourné.

RETOURNE

En cas de succès, le nombre de réponses chargées est retourné, sinon un code d'erreur négatif.
