NOM

gnutls_x509_crt_get_serial - fonction API

SYNOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_get_serial(gnutls_x509_crt_t cert, void * result, size_t * result_size);

ARGUMENTS

gnutls_x509_crt_t cert
devrait contenir un type gnutls_x509_crt_t
void * result
L'endroit où le numéro de série sera copié
size_t * result_size
Contient la taille du champ résultat.

DESCRIPTION

Cette fonction renverra le numéro de série du certificat X.509. Ceci est obtenu à partir du champ numéro de série du certificat X509. Le numéro de série n'est pas toujours un nombre de 32 ou 64 bits. Certaines autorités de certification utilisent de grands numéros de série, il peut donc être judicieux de le traiter comme un tableau de uint8_t.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
