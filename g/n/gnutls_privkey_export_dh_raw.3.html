NOM

gnutls_privkey_export_dh_raw - fonction de l'API

SYNOPSIS

#include <gnutls/abstract.h>

int gnutls_privkey_export_dh_raw(gnutls_privkey_t key, gnutls_dh_params_t params, gnutls_datum_t * y, gnutls_datum_t * x, unsigned int flags);

ARGUMENTS

gnutls_privkey_t key
Contient la clé privée
gnutls_dh_params_t params
contiendra les paramètres Diffie-Hellman (optionnel), doit être initialisé
gnutls_datum_t * y
contiendra le y (optionnel)
gnutls_datum_t * x
contiendra le x
unsigned int flags
indicateurs de gnutls_abstract_export_flags_t

DESCRIPTION

Cette fonction exporte le paramètre de clé privée Diffie-Hellman trouvé dans la structure gnutls_privkey_t donnée. Le nouveau paramètre sera alloué en utilisant gnutls_malloc() et sera stocké dans le datum approprié.

Pour récupérer d'autres paramètres communs aux clés publiques et privées, utilisez gnutls_dh_params_export_raw().

VALEUR DE RETOUR

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
