NOM

gnutls_pkcs8_info - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_pkcs8_info(const gnutls_datum_t * data, gnutls_x509_crt_fmt_t format, unsigned int * schema, unsigned int * cipher, void * salt, unsigned int * salt_size, unsigned int * iter_count, char ** oid);

ARGUMENTS

const gnutls_datum_t * data
Contient les données PKCS 8
gnutls_x509_crt_fmt_t format
le format des données PKCS 8
unsigned int * schema
indique le schéma comme l'un des gnutls_pkcs_encrypt_flags_t
unsigned int * cipher
le chiffrement utilisé comme gnutls_cipher_algorithm_t
void * salt
sel PBKDF2 (si non NULL, alors salt_size contient initialement sa taille)
unsigned int * salt_size
taille du sel PBKDF2
unsigned int * iter_count
nombre d'itérations PBKDF2
char ** oid
si non NULL, contiendra une variable allouée et terminée par un caractère nul avec l'OID

DESCRIPTION

Cette fonction fournira des informations sur les algorithmes utilisés dans une structure PKCS 8 particulière. Si les algorithmes de la structure sont inconnus, le code GNUTLS_E_UNKNOWN_CIPHER_TYPE sera retourné, et seul oid sera défini. C'est-à-dire que oid sera défini sur les structures PKCS 8 chiffrées, qu'elles soient prises en charge ou non. Il doit être désinitialisé en utilisant gnutls_free(). Les autres variables ne sont définies que sur les structures prises en charge.

RETOURNE

GNUTLS_E_INVALID_REQUEST si la structure fournie n'est pas une clé chiffrée, GNUTLS_E_UNKNOWN_CIPHER_TYPE si le chiffrement de la structure n'est pas pris en charge, ou un autre code d'erreur négatif en cas d'échec. Zéro en cas de succès.
