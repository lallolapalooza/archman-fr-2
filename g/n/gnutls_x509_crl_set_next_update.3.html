NOM

gnutls_x509_crl_set_next_update - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crl_set_next_update(gnutls_x509_crl_t crl, time_t exp_time);

ARGUMENTS

gnutls_x509_crl_t crl
doit contenir un type gnutls_x509_crl_t
time_t exp_time
L'heure réelle

DESCRIPTION

Cette fonction définira l'heure à laquelle cette CRL sera mise à jour. Il s'agit d'une valeur facultative à définir sur une CRL et cet appel peut être omis lors de la génération d'une CRL.

Avant GnuTLS 3.5.7, la définition d'un champ nextUpdate était obligatoire pour générer une CRL.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
