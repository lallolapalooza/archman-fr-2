NOM

gnutls_prf_early - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_prf_early(gnutls_session_t session, size_t label_size, const char * label, size_t context_size, const char * context, size_t outsize, char * out);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
size_t label_size
taille de la variable label.
const char * label
étiquette utilisée dans le calcul de PRF, typiquement une courte chaîne de caractères.
size_t context_size
taille de la variable extra.
const char * context
données supplémentaires optionnelles pour amorcer le PRF.
size_t outsize
taille du tampon de sortie pré-alloué pour contenir la sortie.
char * out
tampon pré-alloué pour contenir les données générées.

DESCRIPTION

Cette fonction est similaire à gnutls_prf_rfc5705(), mais ne fonctionne qu'à partir de TLS 1.3 pour exporter le matériel de clé précoce.

Notez que le matériel de clé n'est disponible qu'après le traitement du message ClientHello et avant que les clés de trafic applicatives ne soient établies. Par conséquent, cette fonction doit être appelée dans une fonction de crochet de handshake pour GNUTLS_HANDSHAKE_CLIENT_HELLO.

La variable label contient généralement une chaîne de caractères indiquant le but des données générées.

La variable context peut être utilisée pour ajouter des données supplémentaires à la graine, après les variables aléatoires. Elle peut être utilisée pour s'assurer que la sortie générée est fortement liée à des données supplémentaires (par exemple, une chaîne utilisée dans l'authentification de l'utilisateur).

La sortie est placée dans out, qui doit être pré-alloué.

Notez que, pour fournir le contexte RFC5705, la variable context doit être non nulle.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.
