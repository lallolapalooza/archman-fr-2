NOM

gnutls_compression_get_id - Fonction API

SYNTAXE

#include <gnutls/compat.h>

gnutls_compression_method_t gnutls_compression_get_id(const char * name);

ARGUMENTS

const char * name
est un nom de méthode de compression

DESCRIPTION

Les noms sont comparés sans tenir compte de la casse.

VALEUR RENVOYÉE

un identifiant de la méthode de compression spécifiée dans une chaîne, ou GNUTLS_COMP_UNKNOWN en cas d'erreur.
