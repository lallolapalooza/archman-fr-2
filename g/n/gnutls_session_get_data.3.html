NOM

gnutls_session_get_data - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_session_get_data(gnutls_session_t session, void * session_data, size_t * session_data_size);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
void * session_data
est un pointeur vers l'espace alloué pour la session.
size_t * session_data_size
est la taille de session_data, ou sera définie par la fonction.

DESCRIPTION

Retourne tous les paramètres de session nécessaires pour permettre la reprise, dans un tampon pré-alloué.

Voir gnutls_session_get_data2() pour plus d'informations.

VALEUR DE RETOUR

En cas de succès, retourne GNUTLS_E_SUCCESS (0), sinon un code d'erreur.
