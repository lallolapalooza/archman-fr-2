gnu::format(3attr) gnu::format(3attr)

NOM

gnu::format - spécifier le style de la chaîne de format

SYNTAXE

[[gnu::format(style, fmt-idx, first-idx)]]

DESCRIPTION

Cet attribut peut être appliqué à une fonction. Il spécifie qu'un paramètre de fonction est une chaîne de format et indique le style de cette chaîne de format. Cela permet de vérifier la syntaxe de la chaîne de format, ainsi que les types des arguments variadiques. Le style peut être l'un des suivants.

printf
scanf
strftime
strfmon

fmt-idx est un index basé sur 1 qui spécifie la position de la chaîne de format dans la liste des paramètres.

first-idx est un index basé sur 1 qui spécifie la position du premier argument correspondant à la chaîne de format. Si le premier argument fait partie d'un argument va_list, il doit être spécifié comme 0.

VERSIONS

Syntaxe GNU

__attribute__((format(style, fmt-idx, first-idx)))

Styles

Sur certaines cibles, d'autres styles sont également pris en charge.

MinGW
Microsoft Windows
ms_printf
ms_scanf
ms_strftime

Ceux-ci correspondent aux formats pris en charge par la bibliothèque msvcrt.dll.

GCC uniquement.

Solaris
cmn_err
Darwin
CFString
OpenBSD
kprintf
syslog
syslog
Clang uniquement.
FreeBSD
freebsd_kprintf
Clang uniquement.

Dans certaines langues, d'autres styles sont également pris en charge.

Objective-C
NSString

Fonctions non-variadiques

Clang accepte l'attribut sur les fonctions non-variadiques comme une extension.

NORMES

GNU.

HISTORIQUE

gcc, g++, clang 2.8, clang++ 2.8.

EXEMPLES


[[gnu::format(printf, 3, 0)]]
int
vstprintf(int size;
    char buf[restrict size], int size,
    const char *restrict fmt, va_list args)
{
	int len;
	if (size == 0) {
		errno = EOVERFLOW;
		return -1;
	}
	len = vsnprintf(buf, size, fmt, args);
	if (len >= size) {
		errno = E2BIG;
		return -1;
	}
	return len;
}
[[gnu::format(printf, 3, 4)]]
int
stprintf(int size;
    char buf[restrict size], int size,
    const char *restrict fmt, ...)
{
	int len;
	va_list args;
	va_start(args, fmt);
	len = vstprintf(buf, size, fmt, args);
	va_end(args);
	return len;
}
