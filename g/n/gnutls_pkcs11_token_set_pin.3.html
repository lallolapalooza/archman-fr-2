NOM

gnutls_pkcs11_token_set_pin - Fonction de l'API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_token_set_pin(const char * token_url, const char * oldpin, const char * newpin, unsigned int flags);

ARGUMENTS

const char * token_url
Une URL PKCS 11 spécifiant un jeton
const char * oldpin
Code PIN de l'ancien utilisateur
const char * newpin
Nouveau code PIN de l'utilisateur
unsigned int flags
Un des gnutls_pin_flag_t.

DESCRIPTION

Cette fonction modifiera ou définira le code PIN d'un utilisateur ou administrateur pour le jeton donné. Si elle est appelée pour définir un code PIN pour la première fois, oldpin doit être NULL. Lors de la définition du code PIN de l'administrateur avec le drapeau GNUTLS_PIN_SO, la valeur oldpin doit être fournie (cette exigence est assouplie après GnuTLS 3.6.5, depuis lequel le code PIN sera demandé s'il est manquant).

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
