NOM

gnutls_cipher_suite_info - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

const char * gnutls_cipher_suite_info(size_t idx, unsigned char * cs_id, gnutls_kx_algorithm_t * kx, gnutls_cipher_algorithm_t * cipher, gnutls_mac_algorithm_t * mac, gnutls_protocol_t * min_version);

ARGUMENTS

size_t idx
index de la suite de chiffrement pour laquelle obtenir des informations, commence à 0.
unsigned char * cs_id
zone mémoire de sortie avec une capacité de 2 octets, indiquant la valeur de la suite de chiffrement.
gnutls_kx_algorithm_t * kx
variable de sortie indiquant l'algorithme d'échange de clés, ou NULL.
gnutls_cipher_algorithm_t * cipher
variable de sortie indiquant le chiffrement, ou NULL.
gnutls_mac_algorithm_t * mac
variable de sortie indiquant l'algorithme MAC, ou NULL.
gnutls_protocol_t * min_version
variable de sortie indiquant la version du protocole TLS, ou NULL.

DESCRIPTION

Obtenir des informations sur les suites de chiffrement supportées. Utilisez la fonction itérativement pour obtenir des informations sur toutes les suites de chiffrement supportées. Appelez avec idx=0 pour obtenir des informations sur la première suite de chiffrement, puis idx=1 et ainsi de suite jusqu'à ce que la fonction retourne NULL.

VALEURS DE RETOUR

le nom de la suite de chiffrement idx, et définit les informations sur la suite de chiffrement dans les variables de sortie. Si idx est hors limites, NULL est retourné.
