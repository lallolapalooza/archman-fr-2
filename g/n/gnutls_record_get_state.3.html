NOM

gnutls_record_get_state - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_record_get_state(gnutls_session_t session, unsigned read, gnutls_datum_t * mac_key, gnutls_datum_t * IV, gnutls_datum_t * cipher_key, unsigned char [8] seq_number);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t
unsigned read
si non nul, les paramètres de lecture sont retournés, sinon ceux d'écriture
gnutls_datum_t * mac_key
la clé utilisée pour le MAC (si un MAC est utilisé)
gnutls_datum_t * IV
le vecteur d'initialisation ou la nonce utilisée
gnutls_datum_t * cipher_key
la clé de chiffrement
unsigned char [8] seq_number
Un numéro de séquence de 64 bits

DESCRIPTION

Cette fonction retournera les paramètres de l'état de l'enregistrement actuel. Ceux-ci ne sont utiles que pour être fournis à un périphérique ou sous-système de déchargement externe. Les valeurs retournées doivent être considérées comme constantes et valides pendant la durée de vie de la session.

Dans ce cas, pour synchroniser l'état en retour, vous devez appeler gnutls_record_set_state().

RETOUR

GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.

Depuis 3.4.0
