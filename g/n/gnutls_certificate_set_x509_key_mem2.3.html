gnutls_certificate_set_x509_key_mem2(3) gnutls gnutls_certificate_set_x509_key_mem2(3)

NOM

gnutls_certificate_set_x509_key_mem2 - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_key_mem2(gnutls_certificate_credentials_t res, const gnutls_datum_t * cert, const gnutls_datum_t * key, gnutls_x509_crt_fmt_t type, const char * pass, unsigned int flags);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
const gnutls_datum_t * cert
contient une liste de certificats (chemin) pour la clé privée spécifiée
const gnutls_datum_t * key
est la clé privée, ou NULL
gnutls_x509_crt_fmt_t type
est PEM ou DER
const char * pass
est le mot de passe de la clé
unsigned int flags
une séquence OR de gnutls_pkcs_encrypt_flags_t

DESCRIPTION

Cette fonction configure une paire certificat/clé privée dans le type gnutls_certificate_credentials_t. Cette fonction peut être appelée plus d'une fois, dans le cas où plusieurs clés/certificats existent pour le serveur.

Notez que l'extension PKIX keyUsage (2.5.29.15) dans les certificats X.509 est prise en charge. Cela signifie que les certificats destinés à la signature ne peuvent pas être utilisés pour des suites de chiffrement qui nécessitent un chiffrement.

Si le certificat et la clé privée sont fournis en encodage PEM, les chaînes qui contiennent leurs valeurs doivent être terminées par un caractère nul.

La key peut être NULL si vous utilisez une fonction de rappel de signature, voir gnutls_sign_callback_set().

Notez que, par défaut, cette fonction retourne zéro en cas de succès et une valeur négative en cas d'erreur. Depuis la version 3.5.6, lorsque le drapeau GNUTLS_CERTIFICATE_API_V2 est défini à l'aide de gnutls_certificate_set_flags(), elle retourne un indice (supérieur ou égal à zéro). Cet indice peut être utilisé dans d'autres fonctions pour faire référence à la paire clé ajoutée.

RETOUR

En cas de succès, cette fonction retourne zéro, et sinon une valeur négative en cas d'erreur (voir ci-dessus pour modifier ce comportement).
