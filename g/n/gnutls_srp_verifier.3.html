NOM

gnutls_srp_verifier - Fonction API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_srp_verifier(const char * username, const char * password, const gnutls_datum_t * salt, const gnutls_datum_t * generator, const gnutls_datum_t * prime, gnutls_datum_t * res);

ARGUMENTS

const char * username
est le nom de l'utilisateur.
const char * password
est le mot de passe de l'utilisateur.
const gnutls_datum_t * salt
devrait être des octets générés aléatoirement.
const gnutls_datum_t * generator
est le générateur du groupe.
const gnutls_datum_t * prime
est le nombre premier du groupe.
gnutls_datum_t * res
où le vérificateur sera stocké.

DESCRIPTION

Cette fonction créera un vérificateur SRP, tel que spécifié dans la RFC2945. Les paramètres prime et generator devraient être des paramètres statiques définis dans gnutls/gnutls.h ou peuvent être générés.

Le vérificateur sera alloué avec @gnutls_malloc() et sera stocké dans
res en format binaire.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, ou un code d'erreur.
