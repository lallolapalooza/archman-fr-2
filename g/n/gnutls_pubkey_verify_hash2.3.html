gnutls_pubkey_verify_hash2(3)

gnutls_pubkey_verify_hash2(3) gnutls gnutls_pubkey_verify_hash2(3)

NOM

gnutls_pubkey_verify_hash2 - Fonction API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_pubkey_verify_hash2(gnutls_pubkey_t key, gnutls_sign_algorithm_t algo, unsigned int flags, const gnutls_datum_t * hash, const gnutls_datum_t * signature);

ARGUMENTS

gnutls_pubkey_t key
Contient la clé publique
gnutls_sign_algorithm_t algo
L'algorithme de signature utilisé
unsigned int flags
Zéro ou une combinaison OR de gnutls_certificate_verify_flags
const gnutls_datum_t * hash
contient le digest de hachage à vérifier
const gnutls_datum_t * signature
contient la signature

DESCRIPTION

Cette fonction vérifiera le digest signé donné, en utilisant les paramètres de la clé publique. Notez que contrairement à gnutls_privkey_sign_hash(), cette fonction accepte un algorithme de signature plutôt qu'un algorithme de hachage. Vous pouvez utiliser gnutls_pk_to_sign() pour obtenir la valeur appropriée.

RETOURNE

En cas d'échec de vérification, GNUTLS_E_PK_SIG_VERIFY_FAILED est retourné, et un code positif ou zéro en cas de succès. Pour les signatures connues comme étant peu sûres, cette fonction retournera GNUTLS_E_INSUFFICIENT_SECURITY à moins que le drapeau GNUTLS_VERIFY_ALLOW_BROKEN ne soit spécifié.
