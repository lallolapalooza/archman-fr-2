gnome-shell(1) Commandes utilisateur gnome-shell(1)

Nom

gnome-shell - Shell graphique pour le bureau GNOME

SYNTAXE

gnome-shell [OPTION...]

DESCRIPTION

GNOME shell fournit les fonctions de base de l'interface utilisateur pour le bureau GNOME 3, telles que le passage d'une fenêtre à l'autre et le lancement d'applications. GNOME shell tire parti des capacités du matériel graphique moderne et introduit des concepts d'interface utilisateur innovants pour offrir une expérience visuellement attrayante et facile à utiliser.

gnome-shell est un composant requis du bureau GNOME, c'est-à-dire qu'il est répertorié dans le champ RequiredComponents de /usr/share/gnome-session/sessions/gnome.session. Il est lancé dans la phase du gestionnaire de fenêtres de la session.

OPTIONS

--wayland

Exécute en tant que compositeur Wayland

--display-server

Exécute en tant que serveur d'affichage complet, plutôt qu'imbriqué

--nested

Exécute en tant que compositeur imbriqué

--no-x11

Exécute le compositeur Wayland sans démarrer Xwayland

--x11

Exécute avec le backend X11

--wayland-display=DISPLAY

Nom de l'affichage Wayland à utiliser

-d, --display=DISPLAY

Affichage X à utiliser

-r, --replace

Remplace le gestionnaire de fenêtres en cours d'exécution

--sm-disable

Désactive la connexion au gestionnaire de session

--sm-client-id=ID

Spécifie l'identifiant de gestion de session ID

--sm-save-file=FILE

Initialise la session à partir du fichier FILE

--sync

Rend les appels X synchrones

--mode=MODE

Utilise un mode spécifique, par exemple "gdm" pour l'écran de connexion

--list-modes

Liste les modes possibles et quitte

--version

Affiche la version et quitte

--help

Affiche l'aide et quitte

FICHIERS

/usr/share/gnome-session/sessions/gnome.session, /usr/share/applications/org.gnome.Shell.desktop.

BOGUES

Le traqueur de bogues est accessible en visitant le site web https://gitlab.gnome.org/GNOME/gnome-shell/issues. Avant d'envoyer un rapport de bogue, veuillez vérifier que vous disposez de la dernière version de gnome-shell. De nombreux bogues (majeurs et mineurs) sont corrigés à chaque publication, et si le vôtre est obsolète, le problème peut déjà avoir été résolu.

INFORMATIONS COMPLÉMENTAIRES

Pour plus d'informations, visitez le site web https://gitlab.gnome.org/GNOME/gnome-shell/-/blob/main/README.md.
