NOM

gnutls_init - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_init(gnutls_session_t * session, unsigned int flags);

ARGUMENTS

gnutls_session_t * session
est un pointeur vers un type gnutls_session_t.
unsigned int flags
indique si cette session doit être utilisée pour le serveur ou le client.

DESCRIPTION

Cette fonction initialise la session fournie. Chaque session doit être initialisée avant utilisation, et après une initialisation et une utilisation réussies, elle doit être désinitialisée en appelant gnutls_deinit().


flags peut être toute combinaison de drapeaux de gnutls_init_flags_t.

Notez que depuis la version 3.1.2, cette fonction active par défaut certains extensions TLS courantes telles que les tickets de session et la requête de statut de certificat OCSP côté client. Pour éviter cela, utilisez le drapeau GNUTLS_NO_DEFAULT_EXTENSIONS.

Notez qu'il n'est jamais obligatoire d'utiliser gnutls_deinit() après l'échec de cette fonction. Depuis gnutls 3.8.0, il est sûr d'appeler gnutls_deinit() sans condition même après un échec, que la mémoire ait été initialisée avant gnutls_init() ou non ; cependant, les clients souhaitant être portables vers d'anciennes versions de la bibliothèque devraient soit sauter la désinitialisation en cas d'échec, soit pré-initialiser la mémoire passée à gnutls_init() à tous les zéros via memset() ou une méthode similaire.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.
