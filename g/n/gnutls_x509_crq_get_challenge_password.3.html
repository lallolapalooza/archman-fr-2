NOM

gnutls_x509_crq_get_challenge_password - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_get_challenge_password(gnutls_x509_crq_t crq, char * pass, size_t * pass_size);

ARGUMENTS

gnutls_x509_crq_t crq
doit contenir un type gnutls_x509_crq_t
char * pass
contiendra une chaîne de mot de passe (terminée par 0)
size_t * pass_size
Contient initialement la taille de pass.

DESCRIPTION

Cette fonction renvoie le mot de passe de défi dans la requête. Le mot de passe de défi est destiné à être utilisé pour demander la révocation du certificat.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon une valeur d'erreur négative.
