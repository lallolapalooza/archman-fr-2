DESCRIPTIO

N

GNU Go joue une partie de Go contre l'utilisateur. Il possède de nombreuses autres fonctionnalités : il peut jouer contre lui-même ou un autre programme, analyser et compter une partie enregistrée. GNU Go est compatible avec le protocole Go modem, charge et enregistre les parties au format Smart

Game.

GNU Go affiche par défaut un plateau simple alphanumérique, mais vous pouvez utiliser un client tel que CGoban.

Le jeu de

Go

Le Go est un jeu de stratégie entre deux joueurs, généralement joué sur une grille 19x19 appelée goban. Les deux joueurs placent des pierres noires et blanches sur le goban pour encercler un territoire. Le Go a été inventé il y a environ 4000 ans dans la Chine antique. Autres noms pour ce jeu : (chinois) Wei Chi, (coréen) Baduk et (Ing) Goe.

Jouer une partie en mode

ASCII

Pour commencer une partie avec les options par défaut, il suffit d'invoquer "gnugo". Le plateau sera dessiné dans votre terminal à l'aide de lettres ASCII. Dans ce mode, vous pouvez obtenir de l'aide sur les commandes disponibles avec la touche h. Pour jouer en tant que Noir avec un handicap de 4 pierres, un komi de 0.5, en enregistrant la partie dans le fichier record.sgf

: 
gnugo --color black --handicap 4 --komi 0.5 -o record.
sgf

Jouer une partie avec

CGoban

CGoban est un client généraliste de Bill Shubert pour jouer au Go. Il s'exécute sous X Window System avec un affichage graphique redimensionnable et esthétique. Pour utiliser GNU Go sous X Window System, obtenez la version la plus récente de CGoban depuis le site web de Bill

Shubert

http://www.igoweb.org/~wms/comp/cgoban/index.

html

Lancez CGoban. Lorsque le panneau de contrôle de CGoban apparaît, sélectionnez « Go Modem. » Vous obtiendrez la configuration du protocole Go Modem. Choisissez un (ou les deux) des joueurs comme « Program, » et remplissez le champ avec le chemin vers gnugo. Après avoir cliqué sur OK, la fenêtre de configuration de la partie apparaît. Choisissez « Rules Set » comme japonais (sinon les handicaps ne fonctionneront pas). Définissez la taille du plateau et le handicap si vous le souhaitez. Cliquez sur OK et vous êtes prêt à

jouer.

Dans la fenêtre de configuration du protocole Go Modem, lorsque vous spécifiez le chemin vers GNU Go, vous pouvez lui donner des options de ligne de commande, telles que --quiet pour supprimer la plupart des messages. Comme le protocole Go Modem préempte les E/S standard, les autres messages sont envoyés vers stderr, même s'il ne s'agit pas de messages d'erreur. Ceux-ci apparaîtront dans le terminal à partir duquel vous avez lancé CGoban.

Système de

comptage

La partie s'arrête lorsque les deux joueurs passent. GNU Go tentera de calculer et de vous annoncer le score. Il peut occasionnellement faire des erreurs en raison d'une mauvaise évaluation du statut d'un groupe. Vous pouvez vérifier le score comme suit. En mode ASCII, à la fin de la partie, les pierres considérées comme mortes sont marquées en lettres minuscules, et vous avez la possibilité de basculer leur statut avant le comptage. Avec CGoban, vous pouvez utiliser la fonction de comptage de CGoban pour compter la partie selon les règles japonaises ou chinoises.

Voir une partie

enregistrée

gnugo -l filename.sgf --mode

ascii

charge filename.sgf et vous permet de naviguer dans la partie en utilisant les commandes forward, back, goto et last. Il n'est pas possible de naviguer dans les variations en mode ascii. Vous pouvez également utiliser CGoban pour voir les parties enregistrées. CGoban peut naviguer dans les variations.

Documentatio

n

Les fichiers du répertoire doc contiennent une documentation détaillée sur les options de débogage et la structure interne du programme. D'autres documentations peuvent être trouvées dans les commentaires à travers le code source.

Protocole Go

Modem

Le protocole Go Modem est une interface standard entre les programmes Go et l'affichage

graphique.

Le protocole Go Modem a été développé par Bruce Wilcox avec les contributions de David Fotland, Anders Kierulf et d'autres. Tout programme Go *devrait* utiliser ce protocole car il est standard. Comme CGoban prend en charge ce protocole, l'interface utilisateur de tout programme Go peut être faite entièrement via CGoban. En utilisant le protocole Go Modem, vous pouvez jouer avec un autre ordinateur exécutant un programme différent (même sur un système d'exploitation différent) en utilisant un modem, un câble série ou via Internet si l'autre programme prend également en charge le protocole. Vous pouvez également communiquer avec les serveurs Go via CGoban.

Format Smart

Game

Les parties (avec commentaires, variations et autres fonctionnalités) peuvent être enregistrées au format Smart Game (SGF). Ce format a été créé dans le programme Smart Go d'Anders Kierulf. Martin Muller et Arno Hollosi ont développé la norme actuelle, qui peut être trouvée

à

http://www.red-bean.

com/sgf/

OPTION

Options

principales

--mode mode

force le mode de jeu (ascii', gtp ou gmp). Par défaut c'est ASCII. Si aucun terminal n'est détecté, GMP (Go Modem Protocol) sera

supposé.

--replay color

rejoue la partie en générant des coups pour color, où color est white, black, ou both. (nécessite -l

)

--quie

t

Ne pas afficher le copyright et les autres messages

d'information.

-l, --infile file

Charge le fichier SGF (pour compter ou analyser une partie enregistrée)

.

-L, --until move

Arrête le chargement juste avant que move soit joué (ex. 154 ou L10)

.

-o, --outfile file

Enregistre la partie jouée dans file au format SGF.

Options de partie

:

--boardsize num

Définit la taille du plateau à utiliser (1-19). Par défaut c'est 19, d'autres formats courants sont 13 et

9.

--color color

Choisissez votre couleur (black ou white). Le Noir joue en premier, le Blanc reçoit la compensation du

komi.

--handicap num

Définit le nombre de pierres de

handicap.

--komi num

Définit le komi (points donnés au joueur blanc pour compenser l'avantage du premier coup, généralement 5.5 ou 0.5). Par défaut c'est 5.5.

Go.

--help

Options de débogage et avancées

:

-T,

--printboard

--level num

--score [estimate⎪finish⎪aftermath

Compte ou estime le territoire du fichier d'entrée. Utilisation

Charge le fichier SGF et estime le score en mesurant l'influence. Utilisez avec -L si vous voulez l'estimation ailleurs qu'à la fin du

fichier.

gnugo --score finish -l

Charge le fichier SGF et gnugo continue à jouer tout seul jusqu'à la toute fin. Ensuite, le gagnant est déterminé en comptant le territotory

filename

Similaire à --score finish, sauf qu'un algorithme plus précis mais plus lent est utilisé pour déterminer le statut final des

groupes.

Si l'option -o outputfilename est fournie, les résultats seront également écrits en commentaire à la fin du fichier de

sortie.
