NOM

gnubiff - programme de notification de courrier électronique prenant en charge GTK+ et GNOME

SYNOPIS

gnubiff [options]

DESCRIPTION

gnubiff est un programme de notification de courrier électronique qui vérifie le courrier, affiche les en-têtes lorsqu'un nouveau courrier est arrivé et permet de lire les premières lignes des nouveaux messages. Il repose sur les bibliothèques GNOME et GTK mais peut être compilé et utilisé avec ou sans prise en charge de GNOME. Les protocoles pris en charge sont pop3, apop, imap4, mh, qmail et mailfile. De plus, gnubiff est entièrement configurable avec de nombreuses options telles que l'intervalle de vérification, l'heure de connexion, les sons, le lecteur de courrier, les noms de boîtes aux lettres, etc., et peut également filtrer le spam. Notez que gnubiff n'est pas un lecteur de courrier, même s'il offre la possibilité de lire les toutes premières lignes des nouveaux messages. Si vous envoyez des demandes de fonctionnalités spécifiques à implémenter, gardez cela à l'esprit !

OPTIONS

gnubiff accepte les options de ligne de commande suivantes :

-c nomfichier, --config nomfichier
Utilise le fichier spécifié comme fichier de configuration (par défaut : ~/.gnubiffrc)
-n, --noconfigure
Ignore le processus de configuration
--nogui
Démarre gnubiff sans interface graphique
--systemtray
Démarre gnubiff dans la barre d'état système
-?, --help
Affiche un résumé des options
-v, --version
Affiche les informations sur la version

FICHIERS

~/.gnubiffrc
Fichier d'options spécifique à l'utilisateur

VOIR AUSSI

Vous trouverez plus de documentation sur gnubiff dans les pages info avec la commande info gnubiff
