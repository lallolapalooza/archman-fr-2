NOM

gnutls_pkcs11_crt_is_known - Fonction API

SYNTAXE

#include <gnutls/pkcs11.h>

unsigned gnutls_pkcs11_crt_is_known(const char * url, gnutls_x509_crt_t cert, unsigned int flags);

ARGUMENTS

const char * url
Une URL PKCS 11 identifiant un jeton
gnutls_x509_crt_t cert
est le certificat dont on recherche l'émetteur
unsigned int flags
Utiliser zéro ou des drapeaux de GNUTLS_PKCS11_OBJ_FLAG.

DESCRIPTION

Cette fonction vérifie si le certificat fourni est stocké dans le jeton spécifié. Ceci est utile en combinaison avec GNUTLS_PKCS11_OBJ_FLAG_RETRIEVE_TRUSTED ou GNUTLS_PKCS11_OBJ_FLAG_RETRIEVE_DISTRUSTED, pour vérifier si une autorité de certification est présente ou si un certificat est non approuvé dans un module PKCS 11 de confiance.

Cette fonction peut être utilisée avec une url de "pkcs11:", et dans ce cas tous les modules seront recherchés. Pour restreindre les modules à ceux marqués comme approuvés dans p11-kit, utilisez le drapeau GNUTLS_PKCS11_OBJ_FLAG_PRESENT_IN_TRUSTED_MODULE.

Notez que le drapeau GNUTLS_PKCS11_OBJ_FLAG_RETRIEVE_DISTRUSTED est spécifique aux modules de confiance de p11-kit.

RETOURNE

Si le certificat existe, une valeur non nulle est retournée, sinon zéro.
