NOM

gnutls_x509_crq_set_extension_by_oid - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_set_extension_by_oid(gnutls_x509_crq_t crq, const char * oid, const void * buf, size_t sizeof_buf, unsigned int critical);

ARGUMENTS

gnutls_x509_crq_t crq
une requête de certificat de type gnutls_x509_crq_t
const char * oid
contient un identifiant d'objet sous forme de chaîne de caractères terminée par null
const void * buf
un pointeur vers des données encodées en DER
size_t sizeof_buf
contient la taille de buf
unsigned int critical
doit être non nul si l'extension doit être marquée comme critique

DESCRIPTION

Cette fonction définit l'extension, par l'OID spécifié, dans la requête de certificat. Les données de l'extension doivent être des données binaires encodées en DER.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
