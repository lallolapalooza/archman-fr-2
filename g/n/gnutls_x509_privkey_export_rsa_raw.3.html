NOM

gnutls_x509_privkey_export_rsa_raw - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_privkey_export_rsa_raw(gnutls_x509_privkey_t key, gnutls_datum_t * m, gnutls_datum_t * e, gnutls_datum_t * d, gnutls_datum_t * p, gnutls_datum_t * q, gnutls_datum_t * u);

ARGUMENTS

gnutls_x509_privkey_t key
une clé
gnutls_datum_t * m
contiendra le module
gnutls_datum_t * e
contiendra l'exposant public
gnutls_datum_t * d
contiendra l'exposant privé
gnutls_datum_t * p
contiendra le premier premier (p)
gnutls_datum_t * q
contiendra le second premier (q)
gnutls_datum_t * u
contiendra le coefficient

DESCRIPTION

Cette fonction exportera les paramètres de la clé privée RSA trouvés dans la structure donnée. Les nouveaux paramètres seront alloués en utilisant gnutls_malloc() et seront stockés dans le datum approprié.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
