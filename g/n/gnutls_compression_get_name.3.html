NOM

gnutls_compression_get_name - Fonction de l'API

SYNTAXE

#include <gnutls/compat.h>

const char * gnutls_compression_get_name(gnutls_compression_method_t algorithm);

ARGUMENTS

gnutls_compression_method_t algorithm
est un algorithme de compression

DESCRIPTION

Convertit une valeur gnutls_compression_method_t en chaîne de caractères.

VALEUR

Un pointeur vers une chaîne de caractères contenant le nom de l'algorithme de compression spécifié, ou NULL.
