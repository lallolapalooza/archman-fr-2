NOM

gnutls_db_set_remove_function - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_db_set_remove_function(gnutls_session_t session, gnutls_db_remove_func rem_func);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
gnutls_db_remove_func rem_func
est la fonction.

DESCRIPTION

Définit la fonction qui sera utilisée pour supprimer des données de la base de données des sessions reprises. Cette fonction doit retourner 0 en cas de succès.

Le premier argument de rem_func sera nul à moins que gnutls_db_set_ptr() n'ait été appelé.
