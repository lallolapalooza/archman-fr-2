NOM

gnutls_session_set_verify_cert2 - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_session_set_verify_cert2(gnutls_session_t session, gnutls_typed_vdata_st * data, unsigned elements, unsigned flags);

ARGUMENTS

gnutls_session_t session
est une session gnutls
gnutls_typed_vdata_st * data
un tableau de données typées
unsigned elements
le nombre d'éléments de données
unsigned flags
indicateurs pour la vérification de certificat -- gnutls_certificate_verify_flags

DESCRIPTION

Cette fonction demande à GnuTLS de vérifier le certificat du pair en utilisant les informations fournies dans les données typées. Si la vérification échoue, la négociation échouera également avec GNUTLS_E_CERTIFICATE_VERIFICATION_ERROR. Dans ce cas, le résultat de la vérification peut être obtenu en utilisant gnutls_session_get_verify_cert_status().

Les données typées acceptables sont les mêmes que celles de gnutls_certificate_verify_peers(), et une fois définies, elles doivent rester valides pendant toute la durée de vie de la session. Plus précisément, elles doivent être disponibles lors de toute négociation ultérieure.

Si flags est fourni et contient un profil, cette fonction doit être appelée après toute fonction de définition de priorité de session.
