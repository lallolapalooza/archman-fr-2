NOM

gnutls_privkey_export_gost_raw2 - Fonction d'API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_privkey_export_gost_raw2(gnutls_privkey_t key, gnutls_ecc_curve_t * curve, gnutls_digest_algorithm_t * digest, gnutls_gost_paramset_t * paramset, gnutls_datum_t * x, gnutls_datum_t * y, gnutls_datum_t * k, unsigned int flags);

ARGUMENTS

gnutls_privkey_t key
Contient la clé publique
gnutls_ecc_curve_t * curve
conviendra à la courbe
gnutls_digest_algorithm_t * digest
conviendra au digest
gnutls_gost_paramset_t * paramset
conviendra à l'ID de l'ensemble de paramètres GOST
gnutls_datum_t * x
conviendra à la coordonnée x
gnutls_datum_t * y
conviendra à la coordonnée y
gnutls_datum_t * k
conviendra à la clé privée
unsigned int flags
indicateurs de gnutls_abstract_export_flags_t

DESCRIPTION

Cette fonction exportera les paramètres de la clé privée GOST trouvés dans la structure donnée. Les nouveaux paramètres seront alloués en utilisant gnutls_malloc() et seront stockés dans le datum approprié.

NOTE

les paramètres seront stockés avec l'octet de poids faible en premier. Dans la version 3.6.3, ils étaient incorrectement renvoyés au format big-endian.

RETOURNE

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
