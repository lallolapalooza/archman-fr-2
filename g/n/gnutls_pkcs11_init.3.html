NOM

gnutls_pkcs11_init - Fonction d'API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_init(unsigned int flags, const char * deprecated_config_file);

ARGUMENTS

unsigned int flags
Une séquence OR de GNUTLS_PKCS11_FLAG_*
const char * deprecated_config_file
soit NULL, soit l'emplacement d'un fichier de configuration obsolète

DESCRIPTION

Cette fonction initialisera le sous-système PKCS 11 dans gnutls. Elle lira les fichiers de configuration si GNUTLS_PKCS11_FLAG_AUTO est utilisé, ou vous permettra de charger indépendamment des modules PKCS 11 en utilisant gnutls_pkcs11_add_provider() si GNUTLS_PKCS11_FLAG_MANUAL est spécifié.

Vous n'avez pas besoin d'appeler cette fonction depuis GnuTLS 3.3.0 car elle est appelée lors de la première opération PKCS 11 demandée. Cet appel supposera le drapeau GNUTLS_PKCS11_FLAG_AUTO. Si d'autres drapeaux sont requis, elle doit être appelée indépendamment avant toute opération PKCS 11.

VALEUR DE RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
