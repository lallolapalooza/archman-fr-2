NOM

gnutls_utf8_password_normalize - Fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_utf8_password_normalize(const unsigned char * password, unsigned plen, gnutls_datum_t * out, unsigned flags);

ARGUMENTS

const unsigned char * password
contient le mot de passe au format UTF-8
unsigned plen
la longueur du mot de passe fourni
gnutls_datum_t * out
le résultat dans une chaîne allouée et terminée par un caractère nul
unsigned flags
doit être zéro

DESCRIPTION

Cette fonction convertira le mot de passe UTF-8 fourni conformément aux règles de normalisation de la RFC7613.

Si l'indicateur GNUTLS_UTF8_IGNORE_ERRS est spécifié, toutes les erreurs d'encodage UTF-8 seront ignorées, et dans ce cas, la sortie sera une copie de l'entrée.

RETOURNE

GNUTLS_E_INVALID_UTF8_STRING en cas de données UTF-8 invalides, ou 0 en cas de succès.
