gnutls_x509_crt_get_authority_key_id(3) gnutls gnutls_x509_crt_get_authority_key_id(3)

NOM

gnutls_x509_crt_get_authority_key_id - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_authority_key_id(gnutls_x509_crt_t cert, void * id, size_t * id_size, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
void * id
L'emplacement où l'identifiant sera copié
size_t * id_size
Contient la taille du champ id.
unsigned int * critical
sera non nul si l'extension est marquée comme critique (peut être nul)

DESCRIPTION

Cette fonction renverra l'identifiant de clé de l'autorité du certificat X.509v3. Ceci est obtenu par le champ d'extension d'identifiant de clé d'autorité X.509 (2.5.29.35). Notez que cette fonction ne renvoie que le champ keyIdentifier de l'extension et GNUTLS_E_X509_UNSUPPORTED_EXTENSION, si l'extension contient le nom et le numéro de série du certificat. Dans ce cas, gnutls_x509_crt_get_authority_key_gn_serial() peut être utilisé.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE si l'extension n'est pas présente, sinon une valeur d'erreur négative.
