NOM

gnutls_pubkey_export_gost_raw2 - Fonction API

SYNOPSIS

#include <gnutls/abstract.h>

int gnutls_pubkey_export_gost_raw2(gnutls_pubkey_t key, gnutls_ecc_curve_t * curve, gnutls_digest_algorithm_t * digest, gnutls_gost_paramset_t * paramset, gnutls_datum_t * x, gnutls_datum_t * y, unsigned int flags);

ARGUMENTS

gnutls_pubkey_t key
Contient la clé publique
gnutls_ecc_curve_t * curve
contiendra la courbe (peut être NULL)
gnutls_digest_algorithm_t * digest
contiendra la courbe (peut être NULL)
gnutls_gost_paramset_t * paramset
contiendra l'identifiant des paramètres (peut être NULL)
gnutls_datum_t * x
contiendra la coordonnée x (peut être NULL)
gnutls_datum_t * y
contiendra la coordonnée y (peut être NULL)
unsigned int flags
indicateurs de gnutls_abstract_export_flags_t

DESCRIPTION

Cette fonction va exporter les paramètres de la clé publique GOST trouvés dans la clé donnée. Les nouveaux paramètres seront alloués en utilisant gnutls_malloc() et seront stockés dans la structure de données appropriée.

NOTE

Les paramètres seront stockés avec l'octet de poids faible en premier. Dans la version 3.6.3, ils étaient incorrectement retournés en format big-endian.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
