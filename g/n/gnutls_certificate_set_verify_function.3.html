NOM

gnutls_certificate_set_verify_function - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_certificate_set_verify_function(gnutls_certificate_credentials_t cred, gnutls_certificate_verify_function * func);

ARGUMENTS

gnutls_certificate_credentials_t cred
est un type gnutls_certificate_credentials_t.
gnutls_certificate_verify_function * func
est la fonction de rappel

DESCRIPTION

Cette fonction définit un rappel à appeler lorsque le certificat du pair a été reçu afin de le vérifier à la réception plutôt qu'après la fin de la négociation.

Le prototype de la fonction de rappel est : int (*callback)(gnutls_session_t);

Si la fonction de rappel est fournie, gnutls l'appellera, lors de la négociation, juste après la réception du message de certificat. Pour vérifier ou obtenir le certificat, les fonctions gnutls_certificate_verify_peers2(), gnutls_certificate_type_get(), gnutls_certificate_get_peers() peuvent être utilisées.

La fonction de rappel doit retourner 0 pour que la négociation continue ou une valeur non nulle pour la terminer.
