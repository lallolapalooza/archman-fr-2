NOM

gnutls_x509_crt_get_dn_by_oid - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_dn_by_oid(gnutls_x509_crt_t cert, const char * oid, unsigned indx, unsigned int raw_flag, void * buf, size_t * buf_size);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
const char * oid
contient un identifiant d'objet sous forme de chaîne terminée par null
unsigned indx
Au cas où plusieurs OID identiques existent dans le RDN, ceci spécifie lequel renvoyer. Utilisez (0) pour obtenir le premier.
unsigned int raw_flag
Si non nul, renvoie les données DER brutes de la partie DN.
void * buf
un pointeur où la partie DN sera copiée (peut être null).
size_t * buf_size
contient initialement la taille de buf

DESCRIPTION

Cette fonction extrait la partie du nom du sujet du Certificat spécifiée par l'OID donné. La sortie, si le drapeau brut n'est pas utilisé, sera encodée comme décrit dans la RFC4514. Donc une chaîne encodée en ASCII ou en UTF-8, selon les données du certificat.

Certaines macros d'aide avec des OID populaires peuvent être trouvées dans gnutls/x509.h. Si le drapeau brut est (0), cette fonction ne renverra que les OID connus sous forme de texte. D'autres OID seront encodés en DER, comme décrit dans la RFC4514 -- au format hexadécimal avec un préfixe '#'. Vous pouvez vérifier les OID connus en utilisant gnutls_x509_dn_oid_known().

Si buf est null, seule la taille sera renseignée. Si le raw_flag n'est pas spécifié, la sortie est toujours terminée par null, bien que la
buf_size n'inclura pas le caractère null.

RETOURNE

GNUTLS_E_SHORT_MEMORY_BUFFER si le tampon fourni n'est pas assez long, et dans ce cas buf_size sera mis à jour avec la taille requise. GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE s'il n'y a pas de données dans l'index courant. En cas de succès, 0 est retourné.
