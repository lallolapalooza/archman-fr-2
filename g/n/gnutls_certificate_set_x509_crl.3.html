NOM

gnutls_certificate_set_x509_crl - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_crl(gnutls_certificate_credentials_t res, gnutls_x509_crl_t * crl_list, int crl_list_size);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
gnutls_x509_crl_t * crl_list
est une liste de CRLs de confiance. Elles doivent avoir été vérifiées au préalable.
int crl_list_size
contient la taille de la crl_list

DESCRIPTION

Cette fonction ajoute les CRLs de confiance afin de vérifier les certificats client ou serveur. Dans le cas d'un client, il n'est pas nécessaire d'appeler cette fonction si les certificats ne sont pas vérifiés en utilisant gnutls_certificate_verify_peers2(). Cette fonction peut être appelée plusieurs fois.

RETOUR

nombre de CRLs traitées, ou un code d'erreur négatif en cas d'erreur.
