NOM

gnutls_auth_server_get_type - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

gnutls_credentials_type_t gnutls_auth_server_get_type(gnutls_session_t session);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.

DESCRIPTION

Retourne le type d'identifiants utilisé pour l'authentification du serveur. Les informations retournées doivent être utilisées pour distinguer la fonction utilisée pour accéder aux données d'authentification.

Notez que sur les sessions reprises, cette fonction retourne le schéma utilisé lors de l'authentification de la session d'origine.

RETOURNE

Le type d'identifiants pour le schéma d'authentification du serveur, un type gnutls_credentials_type_t.
