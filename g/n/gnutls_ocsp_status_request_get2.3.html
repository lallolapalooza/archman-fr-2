NOM

gnutls_ocsp_status_request_get2 - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_ocsp_status_request_get2(gnutls_session_t session, unsigned idx, gnutls_datum_t * response);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
unsigned idx
l'index du certificat du pair
gnutls_datum_t * response
un gnutls_datum_t avec la réponse OCSP encodée en DER

DESCRIPTION

Cette fonction renvoie la réponse de statut OCSP reçue du serveur TLS pour l'index de certificat fourni. L'index correspond aux certificats tels que renvoyés par gnutls_certificate_get_peers. Lorsque l'index est zéro, cette fonction fonctionne de manière identique à gnutls_ocsp_status_request_get().

Le response renvoyé doit être traité comme constant. Si aucune réponse OCSP n'est disponible pour l'index donné, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est renvoyé.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon un code d'erreur négatif est renvoyé.
