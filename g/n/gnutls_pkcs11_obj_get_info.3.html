NOM

gnutls_pkcs11_obj_get_info - Fonction API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_get_info(gnutls_pkcs11_obj_t obj, gnutls_pkcs11_obj_info_t itype, void * output, size_t * output_size);

ARGUMENTS

gnutls_pkcs11_obj_t obj
doit contenir un type gnutls_pkcs11_obj_t
gnutls_pkcs11_obj_info_t itype
Désigne le type d'information demandé
void * output
où la sortie sera stockée
size_t * output_size
contient la taille maximale du tampon de sortie et sera écrasé par la taille réelle.

DESCRIPTION

Cette fonction renvoie des informations sur le certificat PKCS11 tel que le label, l'identifiant ainsi que les informations du token où la clé est stockée.

Lorsque la sortie est du texte, une chaîne terminée par un nul est écrite dans output et sa longueur de chaîne est écrite dans output_size (sans le terminateur nul). Si le tampon est trop petit, output_size contiendra la taille attendue du tampon (avec le terminateur nul pour le texte) et renverra GNUTLS_E_SHORT_MEMORY_BUFFER.

Dans les versions antérieures à 3.6.0, cette fonction incluait le caractère de terminaison nul dans output_size. Après 3.6.0, la taille de sortie n'inclut pas le caractère terminateur.

RETOURNE

GNUTLS_E_SUCCESS (0) en cas de succès ou un code d'erreur négatif en cas d'échec.
