NOM

gnutls_x509_crt_verify_data2 - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_verify_data2(gnutls_x509_crt_t crt, gnutls_sign_algorithm_t algo, unsigned int flags, const gnutls_datum_t * data, const gnutls_datum_t * signature);

ARGUMENTS

gnutls_x509_crt_t crt
Contient le certificat à vérifier
gnutls_sign_algorithm_t algo
L'algorithme de signature utilisé
unsigned int flags
Zéro ou une liste OR de gnutls_certificate_verify_flags
const gnutls_datum_t * data
Contient les données signées
const gnutls_datum_t * signature
Contient la signature

DESCRIPTION

Cette fonction vérifiera les données signées fournies, en utilisant les paramètres du certificat.

RETOURNE

En cas d'échec de vérification, GNUTLS_E_PK_SIG_VERIFY_FAILED est retourné, GNUTLS_E_EXPIRED ou GNUTLS_E_NOT_YET_ACTIVATED en cas de certificat expiré ou non encore activé, et zéro ou un code positif en cas de succès.

Notez que depuis GnuTLS 3.5.6, cette fonction introduit des vérifications sur le certificat final ( crt ), y compris des vérifications temporelles et des vérifications d'utilisation de clés.
