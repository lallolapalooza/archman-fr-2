NOM

gnutls_aead_cipher_encryptv2 - Fonction API

SYNOPSIS

#include <gnutls/crypto.h>

int gnutls_aead_cipher_encryptv2(gnutls_aead_cipher_hd_t handle, const void * nonce, size_t nonce_len, const giovec_t * auth_iov, int auth_iovcnt, const giovec_t * iov, int iovcnt, void * tag, size_t * tag_size);

ARGUMENTS

gnutls_aead_cipher_hd_t handle
est un type gnutls_aead_cipher_hd_t.
const void * nonce
le nonce à définir
size_t nonce_len
La longueur du nonce
const giovec_t * auth_iov
données supplémentaires à authentifier
int auth_iovcnt
Le nombre de tampons dans auth_iov
const giovec_t * iov
les données à chiffrer
int iovcnt
Le nombre de tampons dans iov
void * tag
Le tag d'authentification
size_t * tag_size
La taille du tag à utiliser (utiliser zéro pour la valeur par défaut)

DESCRIPTION

Ceci est similaire à gnutls_aead_cipher_encrypt(), mais effectue un chiffrement sur place sur les tampons de données fournis.

RETOUR

Zéro ou un code d'erreur négatif en cas d'erreur.
