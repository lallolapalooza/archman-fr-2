gnutls_x509_crt_get_name_constraints(3) gnutls gnutls_x509_crt_get_name_constraints(3)

NOM

gnutls_x509_crt_get_name_constraints - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_name_constraints(gnutls_x509_crt_t crt, gnutls_x509_name_constraints_t nc, unsigned int flags, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t crt
doit contenir un type gnutls_x509_crt_t
gnutls_x509_name_constraints_t nc
Le type intermédiaire des contraintes de nom
unsigned int flags
zéro ou GNUTLS_EXT_FLAG_APPEND
unsigned int * critical
l'état de l'extension

DESCRIPTION

Cette fonction renvoie un type intermédiaire contenant les contraintes de nom du certificat CA fourni. Cette structure peut être utilisée en combinaison avec gnutls_x509_name_constraints_check() pour vérifier si le nom d'un serveur est conforme aux contraintes.

Lorsque flags est défini à GNUTLS_EXT_FLAG_APPEND, alors si la structure nc est vide, cette fonction se comportera identiquement comme si le drapeau n'était pas défini. Sinon, s'il y a des éléments dans la structure nc, les contraintes seront fusionnées avec les contraintes existantes en suivant la RFC5280 p6.1.4 (les contraintes exclues seront ajoutées, les contraintes permises seront intersectées).

Notez que nc doit être initialisé avant d'appeler cette fonction.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE si l'extension n'est pas présente, sinon une valeur d'erreur négative.
