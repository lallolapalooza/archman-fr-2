NOM

gnutls_certificate_set_known_dh_params - Fonction de l'API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_set_known_dh_params(gnutls_certificate_credentials_t res, gnutls_sec_param_t sec_param);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t
gnutls_sec_param_t sec_param
est une option de l'énumération gnutls_sec_param_t

DESCRIPTION

Cette fonction définira les paramètres Diffie-Hellman à utiliser par un serveur de certificats. Ces paramètres seront utilisés dans les suites de chiffrement Diffie-Hellman éphémères et seront sélectionnés parmi l'ensemble FFDHE de la RFC7919 conformément au niveau de sécurité fourni.

DÉPRÉCIÉ

Cette fonction est inutile et déconseillée à partir de GnuTLS 3.6.0. Depuis la version 3.6.0, les paramètres DH sont négociés conformément à la RFC7919.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
