gnutls_pkcs11_obj_list_import_url3(3)

gnutls_pkcs11_obj_list_import_url3(3) gnutls gnutls_pkcs11_obj_list_import_url3(3)

NOM

gnutls_pkcs11_obj_list_import_url3 - Fonction API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_list_import_url3(gnutls_pkcs11_obj_t * p_list, unsigned int * n_list, const char * url, unsigned int flags);

ARGUMENTS

gnutls_pkcs11_obj_t * p_list
Une liste d'objets non initialisée (peut être NULL)
unsigned int * n_list
Doit initialement contenir la taille maximale de la liste. Conterra la taille réelle.
const char * url
Une URL PKCS 11 identifiant un ensemble d'objets
unsigned int flags
Un ou une séquence d'indicateurs GNUTLS_PKCS11_OBJ_*

DESCRIPTION

Cette fonction initialisera et attribuera des valeurs à une liste d'objets en utilisant tous les objets identifiés par une URL PKCS 11.

Cette fonction énumérera tous les objets spécifiés par l'URL PKCS11 fournie. Elle attend une p_list déjà allouée qui contient * n_list éléments, et cette valeur sera mise à jour vers le nombre réel d'objets présents. Les
objets p_list seront initialisés et définis par cette fonction. Pour obtenir une liste de tous les objets disponibles, utilisez une url de 'pkcs11:'.

Tous les objets retournés doivent être désinitialisés en utilisant gnutls_pkcs11_obj_deinit().

Les indicateurs pris en charge par cette fonction sont GNUTLS_PKCS11_OBJ_FLAG_LOGIN, GNUTLS_PKCS11_OBJ_FLAG_LOGIN_SO, GNUTLS_PKCS11_OBJ_FLAG_PRESENT_IN_TRUSTED_MODULE, GNUTLS_PKCS11_OBJ_FLAG_CRT, GNUTLS_PKCS11_OBJ_FLAG_PUBKEY, GNUTLS_PKCS11_OBJ_FLAG_PRIVKEY, GNUTLS_PKCS11_OBJ_FLAG_WITH_PRIVKEY, GNUTLS_PKCS11_OBJ_FLAG_MARK_CA, GNUTLS_PKCS11_OBJ_FLAG_MARK_TRUSTED, et depuis la version 3.5.1 GNUTLS_PKCS11_OBJ_FLAG_OVERWRITE_TRUSTMOD_EXT.

Dans les versions de GnuTLS antérieures à 3.4.0, la fonction équivalente était gnutls_pkcs11_obj_list_import_url(). Elle est également disponible dans cette version sous forme de macro qui pointe vers cette fonction.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
