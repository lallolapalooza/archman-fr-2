NOM

gnutls_srtp_get_keys - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_srtp_get_keys(gnutls_session_t session, void * key_material, unsigned int key_material_size, gnutls_datum_t * client_key, gnutls_datum_t * client_salt, gnutls_datum_t * server_key, gnutls_datum_t * server_salt);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
void * key_material
Espace pour contenir le matériel de clé généré
unsigned int key_material_size
La taille maximale du matériel de clé
gnutls_datum_t * client_key
La clé de chiffrement principale du client, pointant à l'intérieur du matériel de clé
gnutls_datum_t * client_salt
Le sel de chiffrement principal du client, pointant à l'intérieur du matériel de clé
gnutls_datum_t * server_key
La clé de chiffrement principale du serveur, pointant à l'intérieur du matériel de clé
gnutls_datum_t * server_salt
Le sel de chiffrement principal du serveur, pointant à l'intérieur du matériel de clé

DESCRIPTION

Ceci est une fonction d'aide pour générer le matériel de clé pour SRTP. Elle nécessite que l'espace du matériel de clé soit pré-alloué (devrait être au moins 2x la taille maximale de clé et de sel). Les client_key , client_salt , server_key et server_salt sont des structures de données pratiques qui pointent à l'intérieur du matériel de clé. Elles peuvent être NULL.

RETOUR

En cas de succès, la taille du matériel de clé est retournée, sinon, GNUTLS_E_SHORT_MEMORY_BUFFER si le tampon fourni n'est pas suffisant, ou un code d'erreur négatif.

Depuis 3.1.4
