NOM

gnutls_credentials_set - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_credentials_set(gnutls_session_t session, gnutls_credentials_type_t type, void * cred);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
gnutls_credentials_type_t type
est le type des identifiants
void * cred
les identifiants à définir

DESCRIPTION

Définit les identifiants nécessaires pour le type spécifié. Par exemple, nom d'utilisateur, mot de passe - ou clés publiques et privées, etc. Le paramètre cred est une structure qui dépend du type spécifié et de la session actuelle (client ou serveur). Un seul cred peut être défini pour chaque type différent ; les appels ultérieurs avec le même type remplaceront les identifiants précédemment définis.

Afin de minimiser l'utilisation de la mémoire et de partager les identifiants entre plusieurs threads, gnutls conserve un pointeur vers cred, et non la structure entière des identifiants. Ainsi, vous devrez garder la structure allouée jusqu'à ce que vous appeliez gnutls_deinit(), ou qu'un appel futur à gnutls_credentials_set() avec le même type remplace la structure cred.

Pour GNUTLS_CRD_ANON, cred doit être gnutls_anon_client_credentials_t dans le cas d'un client. Dans le cas d'un serveur, il doit être gnutls_anon_server_credentials_t.

Pour GNUTLS_CRD_SRP, cred doit être gnutls_srp_client_credentials_t dans le cas d'un client, et gnutls_srp_server_credentials_t, dans le cas d'un serveur.

Pour GNUTLS_CRD_CERTIFICATE, cred doit être gnutls_certificate_credentials_t.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné.
