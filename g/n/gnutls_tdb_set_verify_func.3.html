NOM

gnutls_tdb_set_verify_func - Fonction API

SYNOPSIS

#include <gnutls/gnutls.h>

void gnutls_tdb_set_verify_func(gnutls_tdb_t tdb, gnutls_tdb_verify_func verify);

ARGUMENTS

gnutls_tdb_t tdb
Le stockage de confiance
gnutls_tdb_verify_func verify
La fonction de vérification

DESCRIPTION

Cette fonction associera une fonction de récupération à la structure de stockage de confiance. La fonction est de la forme suivante.

int gnutls_tdb_verify_func(const char* db_name, const char* host, const char* service, const gnutls_datum_t* pubkey);

La fonction de vérification devrait retourner zéro en cas de correspondance, GNUTLS_E_CERTIFICATE_KEY_MISMATCH en cas de discrépance, et tout autre code d'erreur négatif sinon.

Le paramètre db_name devrait être utilisé pour passer des données privées à cette fonction.
