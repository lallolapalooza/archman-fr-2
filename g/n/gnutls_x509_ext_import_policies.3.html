NOM

gnutls_x509_ext_import_policies - Fonction API

SYNTAXE

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_policies(const gnutls_datum_t * ext, gnutls_x509_policies_t policies, unsigned int flags);

ARGUMENTS

const gnutls_datum_t * ext
les données de l'extension encodées en DER
gnutls_x509_policies_t policies
Un pointeur vers des politiques initialisées.
unsigned int flags
doit être zéro

DESCRIPTION

Cette fonction extrait l'extension de politique de certificat (2.5.29.32) et la stocke dans les politiques fournies.

VALEUR DE RETOUR

En cas de succès, retourne GNUTLS_E_SUCCESS (0), sinon une valeur d'erreur négative.
