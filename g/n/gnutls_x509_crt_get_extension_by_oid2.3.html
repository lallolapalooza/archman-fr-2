NOM

gnutls_x509_crt_get_extension_by_oid2 - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_extension_by_oid2(gnutls_x509_crt_t cert, const char * oid, unsigned indx, gnutls_datum_t * output, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
const char * oid
contient un identifiant d'objet sous forme de chaîne terminée par null
unsigned indx
Au cas où plusieurs OID identiques existent dans les extensions, ceci spécifie lequel envoyer. Utilisez (0) pour obtenir le premier.
gnutls_datum_t * output
contiendra les données d'extension allouées
unsigned int * critical
sera différent de zéro si l'extension est marquée comme critique

DESCRIPTION

Cette fonction retournera l'extension spécifiée par l'OID dans le certificat. Les extensions seront retournées sous forme de données binaires encodées DER, dans le tampon fourni.

VALEUR DE RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné. Si le certificat ne contient pas l'extension spécifiée, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
