NOM

gnutls_x509_crq_set_dn - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_set_dn(gnutls_x509_crq_t crq, const char * dn, const char ** err);

ARGUMENTS

gnutls_x509_crq_t crq
un certificat de type gnutls_x509_crq_t
const char * dn
une chaîne de caractères DN séparée par des virgules (RFC4514)
const char ** err
indique la position de l'erreur (le cas échéant)

DESCRIPTION

Cette fonction définira le DN sur le certificat fourni. La chaîne d'entrée doit être encodée en ASCII brut ou UTF-8. En cas d'erreur d'analyse du DN, GNUTLS_E_PARSING_ERROR est retourné.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
