NOM

gnutls_x509_crq_get_pk_oid - Fonction de l'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_get_pk_oid(gnutls_x509_crq_t crq, char * oid, size_t * oid_size);

ARGUMENTS

gnutls_x509_crq_t crq
doit contenir un type gnutls_x509_crq_t
char * oid
un pointeur vers un tampon pour stocker l'OID (peut être nul)
size_t * oid_size
contient initialement la taille de oid

DESCRIPTION

Cette fonction renvoie l'OID de l'algorithme de clé publique sur cette demande de certificat. Cette fonction est utile dans le cas où gnutls_x509_crq_get_pk_algorithm() a renvoyé GNUTLS_PK_UNKNOWN.

RETOURNE

zéro ou un code d'erreur négatif en cas d'erreur.

DEPUIS
