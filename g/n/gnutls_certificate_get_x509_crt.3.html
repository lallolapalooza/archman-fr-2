NOM

gnutls_certificate_get_x509_crt - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_get_x509_crt(gnutls_certificate_credentials_t res, unsigned index, gnutls_x509_crt_t ** crt_list, unsigned * crt_list_size);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
unsigned index
L'index de la liste de certificats à obtenir.
gnutls_x509_crt_t ** crt_list
Où stocker la liste de certificats.
unsigned * crt_list_size
Contiendra le nombre de certificats.

DESCRIPTION

Obtient une liste de certificats X.509 qui a été stockée dans res avec l'une des fonctions gnutls_certificate_set_x509_key(), gnutls_certificate_set_key(), gnutls_certificate_set_x509_key_file(), gnutls_certificate_set_x509_key_file2(), gnutls_certificate_set_x509_key_mem(), ou gnutls_certificate_set_x509_key_mem2(). Chaque certificat de la liste retournée doit être libéré avec gnutls_x509_crt_deinit(), et la liste elle-même doit être libérée avec gnutls_free().

L' index correspond à la valeur de retour des fonctions gnutls_certificate_set_x509_key() et similaires, lorsque le drapeau GNUTLS_CERTIFICATE_API_V2 est défini.

S'il n'y a pas de certificat avec l'index donné, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est retourné. Si le certificat avec l'index donné n'est pas un certificat X.509, GNUTLS_E_INVALID_REQUEST est retourné. Les certificats retournés doivent être désinitialisés après utilisation, et le pointeur crt_list doit être libéré en utilisant gnutls_free().

RETOUR

GNUTLS_E_SUCCESS (0) en cas de succès, ou un code d'erreur négatif.
