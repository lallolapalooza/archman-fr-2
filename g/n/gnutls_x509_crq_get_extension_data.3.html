gnutls_x509_crq_get_extension_data(3)

gnutls_x509_crq_get_extension_data(3) gnutls gnutls_x509_crq_get_extension_data(3)

NOM

gnutls_x509_crq_get_extension_data - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_get_extension_data(gnutls_x509_crq_t crq, unsigned indx, void * data, size_t * sizeof_data);

ARGUMENTS

gnutls_x509_crq_t crq
devrait contenir un type gnutls_x509_crq_t
unsigned indx
Spécifie le numéro de l'extension à obtenir. Utiliser (0) pour obtenir la première.
void * data
un pointeur vers une structure pour contenir les données (peut être null)
size_t * sizeof_data
contient initialement la taille de oid

DESCRIPTION

Cette fonction retournera les données de l'extension demandée dans le certificat. Les données de l'extension seront stockées sous forme de chaîne dans le tampon fourni.

Utilisez gnutls_x509_crq_get_extension_info() pour extraire l'OID et le drapeau critique. Utilisez plutôt gnutls_x509_crq_get_extension_by_oid() si vous souhaitez obtenir des données indexées par l'OID de l'extension plutôt que par séquence.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif en cas de problème. Si vous avez atteint la dernière extension disponible, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
