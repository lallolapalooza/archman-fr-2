NOM

gnutls_x509_crt_get_version - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_version(gnutls_x509_crt_t cert);

ARGUMENTS

gnutls_x509_crt_t cert
devrait contenir un type gnutls_x509_crt_t

DESCRIPTION

Cette fonction renvoie la version du certificat spécifié.

VALEUR

version du certificat, ou un code d'erreur négatif en cas d'erreur.
