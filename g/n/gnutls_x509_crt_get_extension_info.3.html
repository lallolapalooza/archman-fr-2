gnutls_x509_crt_get_extension_info(3) gnutls gnutls_x509_crt_get_extension_info(3)

NOM

gnutls_x509_crt_get_extension_info - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_extension_info(gnutls_x509_crt_t cert, unsigned indx, void * oid, size_t * oid_size, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
unsigned indx
Spécifie quel OID d'extension doit être renvoyé. Utiliser (0) pour obtenir le premier.
void * oid
un pointeur vers une structure pour stocker l'OID
size_t * oid_size
contient initialement la taille maximale de oid , à son retour contient la taille réelle de oid .
unsigned int * critical
variable de sortie avec le drapeau critique, peut être NULL.

DESCRIPTION

Cette fonction renverra l'OID d'extension demandé dans le certificat, ainsi que le drapeau critique associé. L'OID de l'extension sera stocké sous forme de chaîne dans le tampon fourni. Utilisez gnutls_x509_crt_get_extension() pour extraire les données.

Si le tampon fourni n'est pas assez grand pour contenir la sortie, alors
oid_size sera mis à jour et GNUTLS_E_SHORT_MEMORY_BUFFER sera renvoyé. L' oid renvoyé sera terminé par un caractère nul, bien que
oid_size ne tienne pas compte du nul final (ce dernier n'est pas vrai pour GnuTLS avant la version 3.6.0).

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon un code d'erreur négatif est renvoyé. Si vous avez atteint la dernière extension disponible, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera renvoyé.
