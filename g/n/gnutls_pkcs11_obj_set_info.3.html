NOM

gnutls_pkcs11_obj_set_info - Fonction d'API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_set_info(gnutls_pkcs11_obj_t obj, gnutls_pkcs11_obj_info_t itype, const void * data, size_t data_size, unsigned flags);

ARGUMENTS

gnutls_pkcs11_obj_t obj
doit contenir un type gnutls_pkcs11_obj_t
gnutls_pkcs11_obj_info_t itype
Indique le type d'informations à définir
const void * data
les données à définir
size_t data_size
la taille des données
unsigned flags
Ou une séquence d'indicateurs GNUTLS_PKCS11_OBJ_*

DESCRIPTION

Cette fonction définira les attributs sur l'objet fourni. Les options disponibles pour itype sont GNUTLS_PKCS11_OBJ_LABEL, GNUTLS_PKCS11_OBJ_ID_HEX, et GNUTLS_PKCS11_OBJ_ID.

RETOUR

GNUTLS_E_SUCCESS (0) en cas de succès ou un code d'erreur négatif en cas d'erreur.
