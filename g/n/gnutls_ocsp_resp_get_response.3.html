NOM

gnutls_ocsp_resp_get_response - fonction d'API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_get_response(gnutls_ocsp_resp_const_t resp, gnutls_datum_t * response_type_oid, gnutls_datum_t * response);

ARGUMENTS

gnutls_ocsp_resp_const_t resp
doit contenir un type gnutls_ocsp_resp_t
gnutls_datum_t * response_type_oid
nouveau tampon de sortie alloué avec l'OID du type de réponse
gnutls_datum_t * response
nouveau tampon de sortie alloué avec la réponse codée en DER

DESCRIPTION

Cette fonction extrait l'OID du type de réponse et les données de réponse d'une réponse OCSP. Normalement,
response_type_oid est toujours "1.3.6.1.5.5.7.48.1.1", ce qui signifie que
response doit être décodé comme une réponse OCSP de base, mais techniquement d'autres types de réponses pourraient être utilisés.

Cette fonction est généralement utile uniquement lorsque vous souhaitez extraire l'OID du type de réponse d'une réponse à des fins de diagnostic. Sinon, gnutls_ocsp_resp_import() décodera la partie réponse OCSP de base et l'appelant n'aura pas à s'en soucier.

Depuis la version 3.7.0, response_type_oid ->size ne tient pas compte de l'octet nul de terminaison.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon une valeur d'erreur négative.
