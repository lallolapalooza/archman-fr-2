NOM

gnutls_sec_param_to_pk_bits - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

unsigned int gnutls_sec_param_to_pk_bits(gnutls_pk_algorithm_t algo, gnutls_sec_param_t param);

ARGUMENTS

gnutls_pk_algorithm_t algo
est un algorithme de clé publique
gnutls_sec_param_t param
est un paramètre de sécurité

DESCRIPTION

Lors de la génération de paires de clés privées et publiques, une question difficile est de savoir quelle taille de « bits » aura le module RSA et la taille du groupe pour DSA. La réponse facile est 1024, ce qui est également faux. Cette fonction convertira un paramètre de sécurité compréhensible par l'homme en une taille appropriée pour l'algorithme spécifique.

VALEUR DE RETOUR

Le nombre de bits, ou (0).
