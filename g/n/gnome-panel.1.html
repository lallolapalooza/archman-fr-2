GNOME-PANEL(1) Manuel des commandes générales GNOME-PANEL(1)

NOM

gnome-panel - Affiche le panneau GNOME

SYNOPIS

gnome-panel [--replace] [--version] [--display=DISPLAY]

DESCRIPTION

Le programme gnome-panel fournit les panneaux du bureau GNOME.

Les panneaux sont les zones du bureau qui contiennent, entre autres, le menu des applications, les lanceurs d'applications, la zone de notification et la liste des fenêtres.

De petites applications appelées applets peuvent également être intégrées dans les panneaux. Les applets fournissent généralement un accès rapide à des fonctionnalités spécifiques.

OPTIONS

--replace
Remplace un panneau déjà en cours d'exécution.
--version
Affiche la version et quitte.
--display=DISPLAY
Définit l'affichage X à utiliser.

BOGUES

Si vous trouvez des bogues dans le programme gnome-panel, veuillez les signaler sur https://bugzilla.gnome.org.
