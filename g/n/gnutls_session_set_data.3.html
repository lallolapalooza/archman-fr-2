NOM

gnutls_session_set_data - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_session_set_data(gnutls_session_t session, const void * session_data, size_t session_data_size);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
const void * session_data
est un pointeur vers l'espace pour contenir la session.
size_t session_data_size
est la taille de la session

DESCRIPTION

Définit tous les paramètres de session, afin de reprendre une session précédemment établie. Les données de session fournies doivent être celles renvoyées par gnutls_session_get_data(). Cette fonction doit être appelée avant gnutls_handshake().

Gardez à l'esprit que la reprise de session est facultative. Le serveur peut choisir de ne pas reprendre la session, un handshake complet sera donc effectué.

VALEUR DE RETOUR

En cas de succès, renvoie GNUTLS_E_SUCCESS (0), sinon un code d'erreur est renvoyé.
