NOM

gnutls_ext_get_name - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

const char * gnutls_ext_get_name(unsigned int ext);

ARGUMENTS

unsigned int ext
est un identifiant numérique d'extension TLS

DESCRIPTION

Convertit un identifiant numérique d'extension TLS en une chaîne imprimable.

RETOURNE

un pointeur vers une chaîne contenant le nom du chiffrement spécifié, ou NULL.
