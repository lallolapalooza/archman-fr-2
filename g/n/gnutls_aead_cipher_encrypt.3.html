NOM

gnutls_aead_cipher_encrypt - Fonction API

SYNTAXE

#include <gnutls/crypto.h>

int gnutls_aead_cipher_encrypt(gnutls_aead_cipher_hd_t handle, const void * nonce, size_t nonce_len, const void * auth, size_t auth_len, size_t tag_size, const void * ptext, size_t ptext_len, void * ctext, size_t * ctext_len);

ARGUMENTS

gnutls_aead_cipher_hd_t handle
est un type gnutls_aead_cipher_hd_t.
const void * nonce
le nonce à définir
size_t nonce_len
La longueur du nonce
const void * auth
données supplémentaires à authentifier
size_t auth_len
La longueur des données
size_t tag_size
La taille de la balise à utiliser (utilisez zéro pour la valeur par défaut)
const void * ptext
les données à chiffrer
size_t ptext_len
La longueur des données à chiffrer
void * ctext
les données chiffrées incluant la balise d'authentification
size_t * ctext_len
la longueur des données chiffrées (doit initialement contenir la taille maximale disponible, y compris l'espace pour la balise)

DESCRIPTION

Cette fonction chiffre les données fournies en utilisant l'algorithme spécifié par le contexte. Les données de sortie contiendront la balise d'authentification.

RETOUR

Zéro ou un code d'erreur négatif en cas d'erreur.
