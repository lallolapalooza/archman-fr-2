NOM

gnutls_pkcs12_bag_get_type - Fonction API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_bag_get_type(gnutls_pkcs12_bag_t bag, unsigned indx);

ARGUMENTS

gnutls_pkcs12_bag_t bag
Le sac
unsigned indx
L'élément du sac dont il faut obtenir le type

DESCRIPTION

Cette fonction renvoie le type du sac.

RETOURNE

En cas d'erreur, une valeur d'erreur négative ou l'une des énumérations gnutls_pkcs12_bag_type_t.
