gnutls_ext_register(3) gnutls gnutls_ext_register(3)

NOM

gnutls_ext_register - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_ext_register(const char * name, int id, gnutls_ext_parse_type_t parse_point, gnutls_ext_recv_func recv_func, gnutls_ext_send_func send_func, gnutls_ext_deinit_data_func deinit_func, gnutls_ext_pack_func pack_func, gnutls_ext_unpack_func unpack_func);

ARGUMENTS

const char * name
le nom de l'extension à enregistrer
int id
l'identifiant numérique TLS de l'extension
gnutls_ext_parse_type_t parse_point
le type d'analyse de l'extension (voir gnutls_ext_parse_type_t)
gnutls_ext_recv_func recv_func
une fonction pour recevoir les données
gnutls_ext_send_func send_func
une fonction pour envoyer les données
gnutls_ext_deinit_data_func deinit_func
une fonction pour désinitialiser toute donnée privée
gnutls_ext_pack_func pack_func
une fonction qui sérialise les données privées de l'extension (utilisée lors de la mise en paquet de session pour la reprise)
gnutls_ext_unpack_func unpack_func
une fonction qui désérialisera les données privées de l'extension

DESCRIPTION

Cette fonction enregistrera un nouveau type d'extension. L'extension restera enregistrée jusqu'à ce que gnutls_global_deinit() soit appelée. Si le type d'extension est déjà enregistré, GNUTLS_E_ALREADY_REGISTERED sera retourné.

Chaque extension enregistrée peut stocker des données temporaires dans la structure gnutls_session_t en utilisant gnutls_ext_set_data(), et elles peuvent être récupérées en utilisant gnutls_ext_get_data().

Toutes les extensions enregistrées avec cette fonction sont valides pour le client et le serveur hello TLS1.2 (ou extensions chiffrées pour TLS1.3).

Cette fonction n'est pas thread-safe.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
