NOM

gnutls_certificate_set_trust_list - fonction d'API

SYNTAXE

#include <gnutls/x509.h>

void gnutls_certificate_set_trust_list(gnutls_certificate_credentials_t res, gnutls_x509_trust_list_t tlist, unsigned flags);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
gnutls_x509_trust_list_t tlist
est un type gnutls_x509_trust_list_t
unsigned flags
doit être zéro

DESCRIPTION

Cette fonction définit une liste de confiance dans le type gnutls_certificate_credentials_t.

Notez que le tlist fera partie de la structure des identifiants et ne doit pas être désalloué. Il sera automatiquement désalloué lorsque la structure res sera désinitialisée.
