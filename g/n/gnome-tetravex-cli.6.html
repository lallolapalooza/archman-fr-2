NOM

Tetravex - Un jeu de puzzle simple à jouer en CLI

SYNTAXE

gnome-tetravex-cli [OPTION...] [COMMANDE]

DESCRIPTION

GNOME Tetravex est un puzzle simple où les pièces doivent être positionnées de telle sorte que les mêmes numéros se touchent.
Ceci est un programme CLI ; voir aussi `gnome-tetravex` pour l'application Gtk.

OPTIONS

-c, --colors=NOMBRE
Définir le nombre de couleurs (2-10)
-s, --size=TAILLE
Définir la taille du plateau (2-6)
-v, --version
Afficher la version de la release et quitter

COMMANDE

A1b2
Inverse deux tuiles, celle en A1, et celle en b2.
Une majuscule cible une tuile du plateau initial.
Une minuscule cible une tuile du plateau gauche/final.
Les chiffres spécifient les lignes des deux tuiles à inverser.

(rien)
status
show

Affiche le puzzle actuel.
nouveau
Crée un nouveau puzzle ; pour changer la taille, utiliser --size.
résoudre
Abandonne le puzzle actuel et affiche la solution.

terminer
fin

Termine le puzzle actuel, automatiquement. Fonctionne pour les puzzles résolus directement ou s'il ne reste qu'une tuile.

haut,    g-haut
bas,  g-bas
gauche, g-gauche
droite, g-droite

Déplace toutes les tuiles du plateau gauche vers le haut/bas/gauche/droite d'une position.

d-haut
d-bas
d-gauche
d-droite

Déplace toutes les tuiles du plateau droit vers le haut/bas/gauche/droite d'une position.
