NOM

gnome-pie - lanceur d'applications visuel pour GNOME

SYNTAXE

gnome-pie [OPTIONS]

DESCRIPTION

gnome-pie est un lanceur d'applications visuel radial pour GNOME. Il permet à l'utilisateur de lier des groupes d'applications fréquemment utilisées à un anneau qui apparaît lorsqu'une touche de raccourci / une liaison de souris est déclenchée.

OPTIONS

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gtk
Afficher les options GTK+

Options de l'application :

-o, --open=ID
Ouvrir le Pie avec l'ID donné
-r, --reset
Réinitialiser toutes les options aux valeurs par défaut
--display=DISPLAY
Affichage X à utiliser
