gnutls_pkcs11_copy_x509_privkey(3)

gnutls_pkcs11_copy_x509_privkey(3) gnutls gnutls_pkcs11_copy_x509_privkey(3)

NOM

gnutls_pkcs11_copy_x509_privkey - Fonction API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_copy_x509_privkey(const char * token_url, gnutls_x509_privkey_t key, const char * label, unsigned int key_usage, unsigned int flags);

ARGUMENTS

const char * token_url
Une URL PKCS 11 spécifiant un jeton
gnutls_x509_privkey_t key
Une clé privée
const char * label
Un nom à utiliser pour les données stockées
unsigned int key_usage
Un parmi GNUTLS_KEY_*
unsigned int flags
Un parmi les drapeaux GNUTLS_PKCS11_OBJ_*

DESCRIPTION

Cette fonction copiera une clé privée dans un jeton PKCS 11 spécifié par une URL.

Depuis la version 3.6.3, les objets sont marqués comme sensibles par défaut à moins que GNUTLS_PKCS11_OBJ_FLAG_MARK_NOT_SENSITIVE ne soit spécifié.

VALEUR DE RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
