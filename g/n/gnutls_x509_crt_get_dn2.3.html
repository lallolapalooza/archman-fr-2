NOM

gnutls_x509_crt_get_dn2 - Fonction API

SYNOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_get_dn2(gnutls_x509_crt_t cert, gnutls_datum_t * dn);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
gnutls_datum_t * dn
un pointeur vers une structure pour contenir le nom; doit être libéré avec gnutls_free()

DESCRIPTION

Cette fonction alloue un tampon et copie le nom du Certificat. Le nom sera sous la forme "C=xxxx,O=yyyy,CN=zzzz" comme décrit dans RFC4514. La chaîne de sortie sera encodée en ASCII ou en UTF-8, selon les données du certificat.

Cette fonction ne produit pas une chaîne entièrement conforme à la RFC4514; si c'est ce que vous souhaitez, consultez gnutls_x509_crt_get_dn3().

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
