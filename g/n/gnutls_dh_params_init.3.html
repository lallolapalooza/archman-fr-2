NOM

gnutls_dh_params_init - Fonction API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_dh_params_init(gnutls_dh_params_t * dh_params);

ARGUMENTS

gnutls_dh_params_t * dh_params
Les paramètres

DESCRIPTION

Cette fonction initialise le type de paramètres DH.

VALEUR RETOURNÉE

En cas de succès, retourne GNUTLS_E_SUCCESS (0), sinon retourne un code d'erreur négatif.
