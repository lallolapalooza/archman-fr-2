NOM

gnutls_x509_crt_check_ip - Fonction d'API

SYNOPSIS

#include <gnutls/x509.h>

unsigned gnutls_x509_crt_check_ip(gnutls_x509_crt_t cert, const unsigned char * ip, unsigned int ip_size, unsigned int flags);

ARGUMENTS

gnutls_x509_crt_t cert
devrait contenir un type gnutls_x509_crt_t
const unsigned char * ip
Un pointeur vers l'adresse IP brute
unsigned int ip_size
le nombre d'octets dans ip (4 ou 16)
unsigned int flags
devrait être zéro

DESCRIPTION

Cette fonction vérifie si les adresses IP autorisées dans le nom alternatif du sujet du certificat correspondent à l'adresse IP fournie.

RETOURNE

une valeur non nulle en cas de succès de la correspondance, et zéro en cas d'échec.
