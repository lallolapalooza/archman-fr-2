NOM

gnutls_aead_cipher_decrypt - Fonction API

SYNTAXE

#include <gnutls/crypto.h>

int gnutls_aead_cipher_decrypt(gnutls_aead_cipher_hd_t handle, const void * nonce, size_t nonce_len, const void * auth, size_t auth_len, size_t tag_size, const void * ctext, size_t ctext_len, void * ptext, size_t * ptext_len);

ARGUMENTS

gnutls_aead_cipher_hd_t handle
est un type gnutls_aead_cipher_hd_t.
const void * nonce
le nonce à définir
size_t nonce_len
La longueur du nonce
const void * auth
données supplémentaires à authentifier
size_t auth_len
La longueur des données
size_t tag_size
La taille de la balise à utiliser (utiliser zéro pour la valeur par défaut)
const void * ctext
les données à déchiffrer (y compris la balise d'authentification)
size_t ctext_len
la longueur des données à déchiffrer (inclut la taille de la balise)
void * ptext
les données déchiffrées
size_t * ptext_len
la longueur des données déchiffrées (doit initialement contenir la taille maximale disponible)

DESCRIPTION

Cette fonction déchiffrera les données fournies en utilisant l'algorithme spécifié par le contexte. Cette fonction doit recevoir les données complètes à déchiffrer, y compris la balise d'authentification. Sur plusieurs chiffrements AEAD, la balise d'authentification est ajoutée au texte chiffré, bien que ce ne soit pas une règle générale. Cette fonction échouera si la vérification de la balise échoue.

RETOUR

Zéro ou un code d'erreur négatif en cas d'échec de vérification ou d'autre erreur.
