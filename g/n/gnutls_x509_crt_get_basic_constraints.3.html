NOM

gnutls_x509_crt_get_basic_constraints - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_basic_constraints(gnutls_x509_crt_t cert, unsigned int * critical, unsigned int * ca, int * pathlen);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
unsigned int * critical
sera non-nul si l'extension est marquée comme critique
unsigned int * ca
pointeur vers un entier de sortie indiquant le statut de CA, peut être NULL, la valeur est 1 si le drapeau CA du certificat est défini, 0 sinon.
int * pathlen
pointeur vers un entier de sortie indiquant la longueur du chemin (peut être NULL), les codes d'erreur positifs indiquent un champ pathLenConstraint présent et la valeur réelle, -1 indique que le champ est absent.

DESCRIPTION

Cette fonction lit les contraintes de base du certificat et renvoie le statut de CA du certificat. Elle lit l'extension X.509 basicConstraints (2.5.29.19).

RETOUR

Si le certificat est une CA, une valeur positive sera renvoyée, ou (0) si le certificat n'a pas le drapeau CA défini. Un code d'erreur négatif peut être renvoyé en cas d'erreur. Si le certificat ne contient pas l'extension basicConstraints, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera renvoyé.
