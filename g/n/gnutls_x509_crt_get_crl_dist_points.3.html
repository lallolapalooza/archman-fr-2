NOM

gnutls_x509_crt_get_crl_dist_points - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_crl_dist_points(gnutls_x509_crt_t cert, unsigned int seq, void * san, size_t * san_size, unsigned int * reason_flags, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
unsigned int seq
spécifie le numéro de séquence du point de distribution (0 pour le premier, 1 pour le second, etc.)
void * san
est l'emplacement où le point de distribution sera copié
size_t * san_size
contient la taille de ret.
unsigned int * reason_flags
Raisons de révocation. Une séquence OR des drapeaux de gnutls_x509_crl_reason_flags_t.
unsigned int * critical
sera différent de zéro si l'extension est marquée comme critique (peut être nul)

DESCRIPTION

Cette fonction récupère les points de distribution CRL (2.5.29.31), contenus dans le certificat donné dans les extensions de certificat X509v3.

VALEUR DE RETOUR

GNUTLS_E_SHORT_MEMORY_BUFFER et met à jour ret_size si
ret_size n'est pas suffisant pour contenir le point de distribution, ou le type du point de distribution si tout s'est bien passé. Le type est l'une des énumérations gnutls_x509_subject_alt_name_t. Si le certificat n'a pas de nom alternatif avec le numéro de séquence spécifié, alors GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est retourné.
