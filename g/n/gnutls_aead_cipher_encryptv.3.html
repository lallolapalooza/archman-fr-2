NOM

gnutls_aead_cipher_encryptv - Fonction de l'API

SYNTAXE

#include <gnutls/crypto.h>

int gnutls_aead_cipher_encryptv(gnutls_aead_cipher_hd_t handle, const void * nonce, size_t nonce_len, const giovec_t * auth_iov, int auth_iovcnt, size_t tag_size, const giovec_t * iov, int iovcnt, void * ctext, size_t * ctext_len);

ARGUMENTS

gnutls_aead_cipher_hd_t handle
est un type gnutls_aead_cipher_hd_t.
const void * nonce
le nonce à définir
size_t nonce_len
La longueur du nonce
const giovec_t * auth_iov
données supplémentaires à authentifier
int auth_iovcnt
Le nombre de tampons dans auth_iov
size_t tag_size
La taille de la balise à utiliser (utiliser zéro pour la valeur par défaut)
const giovec_t * iov
les données à chiffrer
int iovcnt
Le nombre de tampons dans iov
void * ctext
les données chiffrées y compris la balise d'authentification
size_t * ctext_len
la longueur des données chiffrées (doit initialement contenir la taille maximale disponible, y compris l'espace pour la balise)

DESCRIPTION

Cette fonction chiffrera les tampons de données fournis en utilisant l'algorithme spécifié par le contexte. Les données de sortie contiendront la balise d'authentification.

RETOUR

Zéro ou un code d'erreur négatif en cas d'erreur.
