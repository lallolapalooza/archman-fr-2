NOM

gnutls_cipher_encrypt3 - Fonction API

SYNTAXE

#include <gnutls/crypto.h>

int gnutls_cipher_encrypt3(gnutls_cipher_hd_t handle, const void * ptext, size_t ptext_len, void * ctext, size_t * ctext_len, unsigned flags);

ARGUMENTS

gnutls_cipher_hd_t handle
est un type gnutls_cipher_hd_t
const void * ptext
les données à chiffrer
size_t ptext_len
la longueur des données à chiffrer
void * ctext
les données chiffrées
size_t * ctext_len
la longueur des données chiffrées (doit initialement contenir la taille maximale disponible)
unsigned flags
indicateurs pour le remplissage

DESCRIPTION

Cette fonction chiffre les données fournies en utilisant l'algorithme spécifié par le contexte. Pour les chiffrements par bloc, ptext_len est généralement un multiple de la taille du bloc. Si ce n'est pas le cas, l'appelant peut demander à la fonction de remplir le dernier bloc conformément aux flags. Actuellement, le seul schéma de remplissage disponible est GNUTLS_CIPHER_PADDING_PKCS7.

Si ctext n'est pas NULL, il doit contenir suffisamment d'espace pour stocker le texte chiffré résultant. Pour vérifier la taille requise, cette fonction peut être appelée avec ctext défini sur NULL. Alors ctext_len sera mis à jour sans effectuer le chiffrement réel.

RETOURNE

Zéro ou un code d'erreur négatif en cas d'erreur.
