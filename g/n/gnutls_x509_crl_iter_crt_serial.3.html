gnutls_x509_crl_iter_crt_serial(3) gnutls gnutls_x509_crl_iter_crt_serial(3)

NOM

gnutls_x509_crl_iter_crt_serial - Fonction de l'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crl_iter_crt_serial(gnutls_x509_crl_t crl, gnutls_x509_crl_iter_t * iter, unsigned char * serial, size_t * serial_size, time_t * t);

ARGUMENTS

gnutls_x509_crl_t crl
doit contenir un type gnutls_x509_crl_t
gnutls_x509_crl_iter_t * iter
Un pointeur vers un itérateur (initialement, l'itérateur doit être NULL)
unsigned char * serial
où le numéro de série sera copié
size_t * serial_size
contient initialement la taille du numéro de série
time_t * t
s'il n'est pas nul, contiendra l'heure à laquelle ce certificat a été révoqué

DESCRIPTION

Cette fonction effectue la même opération que gnutls_x509_crl_get_crt_serial(), mais elle lit séquentiellement et mémorise l'état dans l'itérateur entre les appels. Cela lui permet d'offrir de meilleures performances dans les séquences comportant de nombreux éléments (50000+).

Lorsque l'on dépasse le dernier élément, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est retourné et l'itérateur est réinitialisé.

Après utilisation, l'itérateur doit être désinitialisé en utilisant gnutls_x509_crl_iter_deinit().

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
