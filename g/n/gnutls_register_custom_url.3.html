NOM

gnutls_register_custom_url - Fonction API

SYNTAXE

#include <gnutls/urls.h>

int gnutls_register_custom_url(const gnutls_custom_url_st * st);

ARGUMENTS

const gnutls_custom_url_st * st
Une structure gnutls_custom_url_st

DESCRIPTION

Enregistre une URL personnalisée. Ceci affectera les fonctions suivantes : gnutls_url_is_supported(), gnutls_privkey_import_url(), gnutls_pubkey_import_url, gnutls_x509_crt_import_url() et toutes les fonctions qui en dépendent, par exemple gnutls_certificate_set_x509_key_file2().

La structure et les fonctions de rappel fournies doivent être valides pendant toute la durée de vie du processus. L'enregistrement d'un type d'URL existant échouera avec GNUTLS_E_INVALID_REQUEST. Depuis GnuTLS 3.5.0, cette fonction peut être utilisée pour remplacer les URLs intégrées.

Cette fonction n'est pas thread-safe.

RETOURNE

Retourne zéro si la structure fournie a été importée ou une valeur négative sinon.
