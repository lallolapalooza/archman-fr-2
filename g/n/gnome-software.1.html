NOM

gnome-software - Installer et mettre à jour des applications

SYNTAXE

gnome-software [OPTION]

DESCRIPTION

gnome-software vous permet d'ajouter et de supprimer des applications ainsi que de mettre à jour votre système.

OPTIONS

--mode=MODE

Démarre gnome-software dans le mode spécifié. MODE peut être updates, updated, installed ou overview. Le mode par défaut est overview.

--search=RECHERCHE

Recherche des applications.

--details=ID

Affiche les détails de l'application (en utilisant l'ID de l'application).

--details-pkg=NOMDUPAQUET

Affiche les détails de l'application (en utilisant le nom du paquet).

--install=ID

Installe l'application (en utilisant l'ID de l'application).

--uninstall=ID

Désinstalle l'application (en utilisant l'ID de l'application).

--local-filename=NOMDUFICHIER

Ouvre un fichier de paquet local.

--interaction=INTERACTION

Le type d'interaction attendu pour cette action : soit none, notify, ou full.

--show-metainfo=NOMDUFICHIER

Affiche un fichier local de metainfo ou appdata.

--verbose

Active la sortie de débogage détaillée (de l'instance en cours d'exécution, si elle est déjà en cours).

--autoupdate

Installe les mises à jour en attente en arrière-plan.

--prefs

Affiche les préférences.

--quit

Quitte l'instance en cours d'exécution.

--prefer-local

Préfère les sources de fichiers locaux à AppStream.

--version

Affiche la version et quitte.

-?, --help

Affiche l'aide et quitte.

D'autres options GNOME standard non listées ici sont également supportées.

BOGUES

Le traqueur de bogues est accessible en visitant le site web https://gitlab.gnome.org/GNOME/gnome-software/issues.
