NOM

gnutls_certificate_get_ocsp_expiration - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

time_t gnutls_certificate_get_ocsp_expiration(gnutls_certificate_credentials_t sc, unsigned idx, int oidx, unsigned flags);

ARGUMENTS

gnutls_certificate_credentials_t sc
est une structure de credentials.
unsigned idx
est un indice de chaîne de certificats tel que retourné par gnutls_certificate_set_key() et fonctions similaires
int oidx
est un indice de réponse OCSP
unsigned flags
doit être zéro

DESCRIPTION

Cette fonction retourne la validité des réponses OCSP chargées, afin de fournir des informations sur quand les recharger/rafraîchir.

Notez que la structure de credentials doit être en lecture seule lorsqu'elle est utilisée. Par conséquent, lors du rechargement, soit la structure de credentials ne doit être utilisée par aucune session, soit une nouvelle structure de credentials doit être allouée pour les nouvelles sessions.

Lorsque oidx est (-1), le temps de rafraîchissement minimum pour toutes les réponses est retourné. Sinon, l'indice spécifie la réponse correspondant au certificat odix dans la chaîne de certificats.

RETOUR

En cas de succès, l'heure d'expiration de la réponse OCSP. Sinon (time_t)(-1) en cas d'erreur, ou (time_t)-2 en cas de dépassement de capacité.
