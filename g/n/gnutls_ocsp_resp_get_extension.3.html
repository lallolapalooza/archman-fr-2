NOM

gnutls_ocsp_resp_get_extension - fonction d'API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_get_extension(gnutls_ocsp_resp_const_t resp, unsigned indx, gnutls_datum_t * oid, unsigned int * critical, gnutls_datum_t * data);

ARGUMENTS

gnutls_ocsp_resp_const_t resp
devrait contenir un type gnutls_ocsp_resp_t
unsigned indx
Spécifie quel OID d'extension obtenir. Utilisez (0) pour obtenir le premier.
gnutls_datum_t * oid
contiendra un nouveau tampon alloué avec l'OID de l'extension, peut être NULL
unsigned int * critical
variable de sortie avec le drapeau critique, peut être NULL.
gnutls_datum_t * data
contiendra un nouveau tampon alloué avec les données de l'extension, peut être NULL

DESCRIPTION

Cette fonction retournera toutes les informations sur l'extension demandée dans la réponse OCSP. Les informations retournées sont l'OID, le drapeau critique et les données elles-mêmes. L'OID de l'extension sera stocké sous forme de chaîne de caractères. N'importe lequel de oid, critical et data peut être NULL, ce qui signifie que l'appelant n'est pas intéressé par la récupération de ces informations.

L'appelant doit libérer la mémoire en appelant gnutls_free() sur
oid ->data et data ->data.

Depuis la version 3.7.0, oid ->size ne prend pas en compte le caractère nul de fin.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné. Si vous avez atteint la dernière extension disponible, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
