NOM

gnutls_certificate_set_verify_flags - Fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

void gnutls_certificate_set_verify_flags(gnutls_certificate_credentials_t res, unsigned int flags);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t
unsigned int flags
sont les drapeaux

DESCRIPTION

Cette fonction définira les drapeaux à utiliser pour la vérification des certificats et remplacera les valeurs par défaut. Les drapeaux fournis doivent être une combinaison OR des énumérations gnutls_certificate_verify_flags.
