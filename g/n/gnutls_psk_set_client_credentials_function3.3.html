gnutls_psk_set_client_credentials_function3(3) gnutls gnutls_psk_set_client_credentials_function3(3)

NOM

gnutls_psk_set_client_credentials_function3 - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_psk_set_client_credentials_function3(gnutls_psk_client_credentials_t cred, gnutls_psk_client_credentials_function3 * func);

ARGUMENTS

gnutls_psk_client_credentials_t cred
est un type gnutls_psk_server_credentials_t.
gnutls_psk_client_credentials_function3 * func
est la fonction de rappel

DESCRIPTION

Cette fonction peut être utilisée pour définir un rappel afin de récupérer le nom d'utilisateur et le mot de passe pour l'authentification PSK côté client. La forme de la fonction de rappel est : int (*callback)(gnutls_session_t, gnutls_datum_t* username, gnutls_datum_t* key, gnutls_datum_t* context, gnutls_psk_key_flags *flags) ;

Cette fonction de rappel a les mêmes sémantiques que celle de gnutls_psk_set_client_credentials_function2(), mais elle renvoie des indicateurs associés à la clé. Le rappel peut importer des PSK externes en utilisant la méthode décrite dans la RFC 9258 en utilisant gnutls_psk_format_imported_identity().

Le champ data de username, key et context doit être alloué en utilisant gnutls_malloc(). Le username doit être une chaîne ASCII ou UTF-8. Dans le cas d'une chaîne UTF-8, il est recommandé de suivre le cadre PRECIS pour les noms d'utilisateur (rfc8265).

La fonction de rappel sera appelée une fois par négociation.

La fonction de rappel doit renvoyer 0 en cas de succès. -1 indique une erreur.
