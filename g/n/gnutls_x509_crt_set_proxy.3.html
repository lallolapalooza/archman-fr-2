NOM

gnutls_x509_crt_set_proxy - fonction API

SYNOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crt_set_proxy(gnutls_x509_crt_t crt, int pathLenConstraint, const char * policyLanguage, const char * policy, size_t sizeof_policy);

ARGUMENTS

gnutls_x509_crt_t crt
un certificat de type gnutls_x509_crt_t
int pathLenConstraint
les codes d'erreur non négatifs indiquent la longueur maximale du chemin, et les codes d'erreur négatifs indiquent que le champ pathLenConstraints ne doit pas être présent.
const char * policyLanguage
OID décrivant le langage de policy.
const char * policy
tableau d'octets uint8_t avec le langage de la politique, peut être NULL
size_t sizeof_policy
taille de policy.

DESCRIPTION

Cette fonction définira l'extension proxyCertInfo.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
