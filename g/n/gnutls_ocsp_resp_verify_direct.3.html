NOM

gnutls_ocsp_resp_verify_direct - fonction d'API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_verify_direct(gnutls_ocsp_resp_const_t resp, gnutls_x509_crt_t issuer, unsigned int * verify, unsigned int flags);

ARGUMENTS

gnutls_ocsp_resp_const_t resp
doit contenir un type gnutls_ocsp_resp_t
gnutls_x509_crt_t issuer
certificat censé avoir signé la réponse
unsigned int * verify
variable de sortie avec le statut de vérification, une gnutls_ocsp_verify_reason_t
unsigned int flags
indicateurs de vérification de gnutls_certificate_verify_flags

DESCRIPTION

Vérifie la signature de la réponse OCSP de base par rapport à la clé publique du certificat de l'émetteur (issuer).

La variable de sortie verify contiendra des codes d'état de vérification (par exemple, GNUTLS_OCSP_VERIFY_SIGNER_NOT_FOUND, GNUTLS_OCSP_VERIFY_INSECURE_ALGORITHM) qui ne sont valides que si la fonction a retourné GNUTLS_E_SUCCESS.

Notez que la fonction retourne GNUTLS_E_SUCCESS même lorsque la vérification a échoué. L'appelant doit toujours inspecter la variable verify pour connaître l'état de la vérification.

La variable flags doit être 0 pour l'instant.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
