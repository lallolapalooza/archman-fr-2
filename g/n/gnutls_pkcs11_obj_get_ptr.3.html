NOM

gnutls_pkcs11_obj_get_ptr - Fonction API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_get_ptr(gnutls_pkcs11_obj_t obj, void ** ptr, void ** session, void ** ohandle, unsigned long * slot_id, unsigned int flags);

ARGUMENTS

gnutls_pkcs11_obj_t obj
doit contenir un type gnutls_pkcs11_obj_t
void ** ptr
contiendra le pointeur CK_FUNCTION_LIST_PTR (peut être NULL)
void ** session
contiendra le CK_SESSION_HANDLE de l'objet
void ** ohandle
contiendra le CK_OBJECT_HANDLE de l'objet
unsigned long * slot_id
l'identifiant du slot (peut être NULL)
unsigned int flags
Ou une séquence de drapeaux GNUTLS_PKCS11_OBJ_*

DESCRIPTION

Obtient les identifiants de session PKCS11 d'un objet. session et ohandle doivent être désinitialisés par l'appelant. Les pointeurs retournés sont indépendants de la durée de vie de obj.

RETOUR

GNUTLS_E_SUCCESS (0) en cas de succès ou un code d'erreur négatif en cas d'erreur.
