NOM

gnutls_supplemental_register - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_supplemental_register(const char * name, gnutls_supplemental_data_format_type_t type, gnutls_supp_recv_func recv_func, gnutls_supp_send_func send_func);

ARGUMENTS

const char * name
le nom des données supplémentaires à enregistrer
gnutls_supplemental_data_format_type_t type
le type du format des données supplémentaires
gnutls_supp_recv_func recv_func
la fonction pour recevoir les données
gnutls_supp_send_func send_func
la fonction pour envoyer les données

DESCRIPTION

Cette fonction enregistrera un nouveau type de données supplémentaires (rfc4680). Les données enregistrées resteront jusqu'à ce que gnutls_global_deinit() soit appelée. Le type fourni doit être un type non assigné dans gnutls_supplemental_data_format_type_t. Si le type est déjà enregistré ou géré par GnuTLS en interne, GNUTLS_E_ALREADY_REGISTERED sera retourné.

Cette fonction n'est pas thread-safe. Comme les données supplémentaires ne sont pas définies dans TLS 1.3, cette fonction désactivera le support de TLS 1.3 globalement.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
