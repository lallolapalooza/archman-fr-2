NOM

gnutls_x509_privkey_generate - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_privkey_generate(gnutls_x509_privkey_t key, gnutls_pk_algorithm_t algo, unsigned int bits, unsigned int flags);

ARGUMENTS

gnutls_x509_privkey_t key
une clé initialisée
gnutls_pk_algorithm_t algo
est l'un des algorithmes de gnutls_pk_algorithm_t.
unsigned int bits
la taille des paramètres à générer
unsigned int flags
Doit être zéro ou des drapeaux de gnutls_privkey_flags_t.

DESCRIPTION

Cette fonction générera une clé privée aléatoire. Notez que cette fonction doit être appelée sur une clé privée initialisée.

Le drapeau GNUTLS_PRIVKEY_FLAG_PROVABLE indique au processus de génération de clé d'utiliser des algorithmes comme Shawe-Taylor (de FIPS PUB186-4) qui génèrent des paramètres prouvables à partir d'une graine pour les clés RSA et DSA. Voir gnutls_x509_privkey_generate2() pour plus d'informations.

Notez que lors de la génération d'une clé elliptique, la courbe peut être substituée à la place du paramètre bits en utilisant la macro GNUTLS_CURVE_TO_BITS(). L'entrée de la macro est n'importe quelle courbe de gnutls_ecc_curve_t.

Pour les clés DSA, si la taille du sous-groupe doit être spécifiée, consultez la macro GNUTLS_SUBGROUP_TO_BITS().

Il est recommandé de ne pas définir directement le nombre de bits, utilisez plutôt gnutls_sec_param_to_pk_bits().

Voir aussi gnutls_privkey_generate(), gnutls_x509_privkey_generate2().

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
