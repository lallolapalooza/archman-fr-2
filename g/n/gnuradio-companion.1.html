GNURADIO-COMPANION(1) Commandes utilisateur GNURADIO-COMPANION(1)

NOM

gnuradio-companion - GNU Radio Companion (GRC) est un outil graphique pour créer des graphes de flux de traitement du signal GNU Radio.

SYNOPSIS

gnuradio-companion [options] [graphes-de-flux]

DESCRIPTION

GNU Radio est une boîte à outils de développement logicielle libre et open-source qui fournit des blocs de traitement du signal pour implémenter des radios définies par logiciel et des systèmes de traitement du signal. Les applications GNU Radio elles-mêmes sont généralement connues sous le nom de « graphes de flux », qui sont une série de blocs de traitement du signal connectés ensemble, décrivant ainsi un flux de données.

gnuradio-companion est essentiellement un outil de génération de code Python. Lorsqu'un graphe de flux est « compilé » dans GRC, il génère du code Python qui crée les fenêtres et les widgets GUI souhaités, et crée et connecte les blocs du graphe de flux.

OPTIONS

graphes-de-flux Invoque le programme avec un ou plusieurs graphes de flux existants.

-h, --help
affiche un message d'aide et quitte.
--log
définit le niveau de sortie des journaux.
