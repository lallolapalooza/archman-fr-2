NOM

Mines - Le célèbre jeu de logique Démineur

SYNTAXE

gnome-mines [OPTION...]

DESCRIPTION

gnome-mines est un jeu de puzzle où vous localisez des mines flottant dans un océan en utilisant uniquement votre cerveau et un peu de chance.

OPTIONS

-v, --version
Affiche la version de publication et quitte

--small
--medium
--big

Démarre le jeu avec un plateau petit (8 par 8), moyen (16 par 16) ou grand (30 par 16). Si plus d'une de ces options est donnée, la plus grande taille est sélectionnée.

Ce programme accepte également les options GNOME et GTK standard.

AUTEURS

Cette page de manuel a été écrite par Sven Arvidsson <sa@whiz.se>, pour le projet Debian (mais peut être utilisée par d'autres).
