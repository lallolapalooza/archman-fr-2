mail - page de manuel pour mail (GNU Mailutils)

mail [OPTION...] [adresse...]

DESCRIPTION

GNU mail -- l'interface standard /bin/mail

SIGNALEMENT DES BOGUES

Signalez les bogues à <bug-mailutils@gnu.org>.

VOIR AUSSI

La documentation complète pour mail est maintenue sous forme de manuel Texinfo. Si les programmes info et mail sont correctement installés sur votre site, la commande

info mail

devrait vous donner accès au manuel complet.
