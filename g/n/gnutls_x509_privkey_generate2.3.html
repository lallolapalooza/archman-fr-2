NOM

gnutls_x509_privkey_generate2 - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_privkey_generate2(gnutls_x509_privkey_t key, gnutls_pk_algorithm_t algo, unsigned int bits, unsigned int flags, const gnutls_keygen_data_st * data, unsigned data_size);

ARGUMENTS

gnutls_x509_privkey_t key
une clé
gnutls_pk_algorithm_t algo
est l'un des algorithmes de gnutls_pk_algorithm_t.
unsigned int bits
la taille du module
unsigned int flags
Doit être zéro ou des indicateurs de gnutls_privkey_flags_t.
const gnutls_keygen_data_st * data
Permet de spécifier des types de gnutls_keygen_data_st tels que la graine à utiliser.
unsigned data_size
Le nombre de data disponibles.

DESCRIPTION

Cette fonction générera une clé privée aléatoire. Notez que cette fonction doit être appelée sur une clé privée initialisée.

L'indicateur GNUTLS_PRIVKEY_FLAG_PROVABLE demande au processus de génération de clé d'utiliser des algorithmes tels que Shawe-Taylor (de FIPS PUB186-4) qui génèrent des paramètres prouvables à partir d'une graine pour les clés RSA et DSA. Sur les clés DSA, les paramètres PQG sont générés en utilisant la graine, tandis que sur les clés RSA, les deux nombres premiers.

Pour spécifier une graine explicite (par défaut une graine aléatoire est utilisée), utilisez data avec un type GNUTLS_KEYGEN_SEED.

Notez que lors de la génération d'une clé de courbe elliptique, la courbe peut être substituée à la place du paramètre bits en utilisant la macro GNUTLS_CURVE_TO_BITS().

Pour exporter les clés générées en mémoire ou dans des fichiers, il est recommandé d'utiliser le format PKCS8 car il peut gérer tous les types de clés et stocker des paramètres supplémentaires tels que la graine, en cas de clés RSA ou DSA prouvables. Les clés générées peuvent être exportées en mémoire à l'aide de gnutls_privkey_export_x509(), puis avec gnutls_x509_privkey_export2_pkcs8().

Si la génération de clés fait partie de votre application, évitez de définir directement le nombre de bits, et utilisez plutôt gnutls_sec_param_to_pk_bits(). Ainsi, les clés générées s'adapteront aux niveaux de sécurité de la bibliothèque GnuTLS sous-jacente.

Voir aussi gnutls_privkey_generate2().

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
