NOM

gnutls_x509_ext_import_name_constraints - fonction d'API

SYNTAXE

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_name_constraints(const gnutls_datum_t * ext, gnutls_x509_name_constraints_t nc, unsigned int flags);

ARGUMENTS

const gnutls_datum_t * ext
une extension encodée en DER
gnutls_x509_name_constraints_t nc
les contraintes de nom
unsigned int flags
zéro ou GNUTLS_NAME_CONSTRAINTS_FLAG_APPEND

DESCRIPTION

Cette fonction retournera un type intermédiaire contenant les contraintes de nom de l'extension NameConstraints fournie. Cela peut être utilisé en combinaison avec gnutls_x509_name_constraints_check() pour vérifier si le nom d'un serveur est conforme aux contraintes.

Lorsque le paramètre flags est défini à GNUTLS_NAME_CONSTRAINTS_FLAG_APPEND, si le type nc est vide, cette fonction se comportera de manière identique comme si le drapeau n'était pas défini. Sinon, s'il y a des éléments dans la structure nc, les contraintes seront fusionnées avec les contraintes existantes en suivant la RFC5280 p6.1.4 (les contraintes exclues seront ajoutées, les contraintes permises seront intersectées).

Notez que nc doit être initialisé avant d'appeler cette fonction.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE si l'extension n'est pas présente, sinon une valeur d'erreur négative.
