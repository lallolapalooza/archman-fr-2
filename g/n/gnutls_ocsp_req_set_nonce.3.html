NOM

gnutls_ocsp_req_set_nonce - fonction API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_set_nonce(gnutls_ocsp_req_t req, unsigned int critical, const gnutls_datum_t * nonce);

ARGUMENTS

gnutls_ocsp_req_t req
doit contenir un type gnutls_ocsp_req_t
unsigned int critical
indicateur critique, normalement faux.
const gnutls_datum_t * nonce
les données du nonce

DESCRIPTION

Cette fonction ajoutera une extension nonce à la requête OCSP. Appeler cette fonction plusieurs fois écrasera les valeurs des appels précédents.

VALEUR DE RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon un code d'erreur négatif est renvoyé.
