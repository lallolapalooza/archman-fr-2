NOM

gnutls_x509_crt_get_key_purpose_oid - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_key_purpose_oid(gnutls_x509_crt_t cert, unsigned indx, void * oid, size_t * oid_size, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
unsigned indx
Ceci spécifie quel OID retourner. Utiliser (0) pour obtenir le premier.
void * oid
un pointeur vers un tampon pour stocker l'OID (peut être null)
size_t * oid_size
contient initialement la taille de oid
unsigned int * critical
indicateur de sortie pour indiquer la criticité de l'extension

DESCRIPTION

Cette fonction extrait les OID d'usage de clé du Certificat spécifié par l'index donné. Ceux-ci sont stockés dans l'extension Usage de Clé Étendue (2.5.29.37). Voir les définitions GNUTLS_KP_* pour les noms lisibles par l'homme.

Si oid est null, seule la taille sera remplie. L' oid retourné sera terminé par null, bien que oid_size ne tienne pas compte du null final.

RETOURNE

GNUTLS_E_SHORT_MEMORY_BUFFER si le tampon fourni n'est pas assez long, et dans ce cas *oid_size sera mis à jour avec la taille requise. En cas de succès, 0 est retourné.
