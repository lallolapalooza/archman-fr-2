gnutls_x509_crt_get_subject_alt_othername_oid(3) gnutls gnutls_x509_crt_get_subject_alt_othername_oid(3)

NOM

gnutls_x509_crt_get_subject_alt_othername_oid - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_subject_alt_othername_oid(gnutls_x509_crt_t cert, unsigned int seq, void * oid, size_t * oid_size);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
unsigned int seq
spécifie le numéro de séquence du nom alternatif (0 pour le premier, 1 pour le second, etc.)
void * oid
est l'emplacement où l'OID otherName sera copié
size_t * oid_size
contient la taille de la valeur retournée.

DESCRIPTION

Cette fonction extrait l'OID de type d'un nom de sujet alternatif (Subject Alternative Name) de type otherName, contenu dans le certificat donné, et retourne le type sous forme d'élément énuméré.

Cette fonction n'est utile que si gnutls_x509_crt_get_subject_alt_name() a retourné GNUTLS_SAN_OTHERNAME.

Si oid est nul alors seule la taille sera remplie. L'oid retourné sera terminé par un caractère nul, bien que oid_size ne tienne pas compte de ce caractère nul final.

VALEUR

le type de nom de sujet alternatif en cas de succès, l'une des énumérations gnutls_x509_subject_alt_name_t. Pour les OIDs pris en charge, elle retournera l'un des types virtuels (GNUTLS_SAN_OTHERNAME_*), par exemple GNUTLS_SAN_OTHERNAME_XMPP, et GNUTLS_SAN_OTHERNAME pour les OIDs inconnus. Elle retournera GNUTLS_E_SHORT_MEMORY_BUFFER si
oid_size n'est pas assez grand pour contenir la valeur. Dans ce cas
oid_size sera mis à jour avec la taille requise. Si le certificat ne possède pas de nom alternatif avec le numéro de séquence spécifié et de type otherName, alors GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
