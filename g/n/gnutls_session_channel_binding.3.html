NOM

gnutls_session_channel_binding - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_session_channel_binding(gnutls_session_t session, gnutls_channel_binding_t cbtype, gnutls_datum_t * cb);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
gnutls_channel_binding_t cbtype
une énumération de type gnutls_channel_binding_t
gnutls_datum_t * cb
un tableau de tampon de sortie avec des données

DESCRIPTION

Extrait les données de liaison de canal données du type cbtype (par exemple, GNUTLS_CB_TLS_UNIQUE).

RETOURNE

GNUTLS_E_SUCCESS en cas de succès, GNUTLS_E_UNIMPLEMENTED_FEATURE si le cbtype n'est pas pris en charge, GNUTLS_E_CHANNEL_BINDING_NOT_AVAILABLE si les données ne sont pas actuellement disponibles, ou un code d'erreur.
