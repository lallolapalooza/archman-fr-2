NOM

gnutls_x509_crt_get_inhibit_anypolicy - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_inhibit_anypolicy(gnutls_x509_crt_t cert, unsigned int * skipcerts, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
unsigned int * skipcerts
conindra le nombre de certificats après lesquels anypolicy n'est plus acceptable.
unsigned int * critical
sera non nul si l'extension est marquée comme critique

DESCRIPTION

Cette fonction renvoie la valeur du certificat concernant SkipCerts, c'est-à-dire l'extension X.509 Inhibit anyPolicy (2.5.29.54).

La valeur renvoyée est le nombre de certificats supplémentaires qui peuvent apparaître dans le chemin avant que anyPolicy ne soit plus acceptable.

RETOURNE

zéro en cas de succès, ou un code d'erreur négatif en cas d'erreur d'analyse. Si le certificat ne contient pas l'extension Inhibit anyPolicy, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera renvoyé.
