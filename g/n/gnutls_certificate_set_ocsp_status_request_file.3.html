gnutls_certificate_set_ocsp_status_request_file(3) gnutls gnutls_certificate_set_ocsp_status_request_file(3)

NOM

gnutls_certificate_set_ocsp_status_request_file - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_ocsp_status_request_file(gnutls_certificate_credentials_t sc, const char * response_file, unsigned idx);

ARGUMENTS

gnutls_certificate_credentials_t sc
est une structure de credentials.
const char * response_file
un nom de fichier de réponse OCSP
unsigned idx
est un index de certificat retourné par gnutls_certificate_set_key() et fonctions similaires

DESCRIPTION

Cette fonction charge la réponse OCSP fournie. Elle sera envoyée au client s'il demande un statut de certificat OCSP pour la chaîne de certificats spécifiée par idx.

NOTE

La capacité de définir plusieurs réponses OCSP par structure de credential via l'index idx a été ajoutée dans la version 3.5.6. Pour maintenir la compatibilité ascendante, elle nécessite l'utilisation de gnutls_certificate_set_flags() avec le drapeau GNUTLS_CERTIFICATE_API_V2 pour que les fonctions de certificat définies retournent un index utilisable par cette fonction.

Cette fonction peut être appelée plusieurs fois depuis GnuTLS 3.6.3 lorsque plusieurs réponses s'appliquant à la chaîne sont disponibles. Si la réponse fournie ne correspond à aucun certificat présent dans la chaîne, le code GNUTLS_E_OCSP_MISMATCH_WITH_CERTS est retourné. Pour revenir au comportement précédent, définissez le drapeau GNUTLS_CERTIFICATE_SKIP_OCSP_RESPONSE_CHECK dans la structure des credentials du certificat. Dans ce cas, seule la réponse OCSP du certificat final peut être définie. Si la réponse est déjà expirée au moment du chargement, le code GNUTLS_E_EXPIRED est retourné.

Pour revenir au comportement précédent de cette fonction qui ne retourne aucune erreur, définissez le drapeau GNUTLS_CERTIFICATE_SKIP_OCSP_RESPONSE_CHECK

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné.
