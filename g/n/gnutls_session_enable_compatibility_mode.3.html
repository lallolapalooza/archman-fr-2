NOM

gnutls_session_enable_compatibility_mode - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_session_enable_compatibility_mode(gnutls_session_t session);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.

DESCRIPTION

Cette fonction peut être utilisée pour désactiver certaines fonctionnalités (de sécurité) dans TLS afin de maintenir une compatibilité maximale avec les clients bogués. Étant donné que plusieurs compromis en matière de sécurité sont activés, s'ils sont requis, ils seront signalés via le sous-système d'audit.

Normalement, seuls les serveurs qui nécessitent une compatibilité maximale avec tout ce qui existe ont besoin d'appeler cette fonction.

Notez que cette fonction doit être appelée après tout appel aux fonctions gnutls_priority.
