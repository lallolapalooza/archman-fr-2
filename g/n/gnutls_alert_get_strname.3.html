NOM

gnutls_alert_get_strname - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

const char * gnutls_alert_get_strname(gnutls_alert_description_t alerte);

ARGUMENTS

gnutls_alert_description_t alerte
est un numéro d'alerte.

DESCRIPTION

Cette fonction renverra une chaîne de caractères représentant le nom de l'alerte.

RETOURNE

la chaîne correspondant à la valeur de gnutls_alert_description_t.
