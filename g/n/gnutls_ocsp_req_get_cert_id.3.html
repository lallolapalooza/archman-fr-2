NOM

gnutls_ocsp_req_get_cert_id - Fonction API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_get_cert_id(gnutls_ocsp_req_const_t req, unsigned indx, gnutls_digest_algorithm_t * digest, gnutls_datum_t * issuer_name_hash, gnutls_datum_t * issuer_key_hash, gnutls_datum_t * serial_number);

ARGUMENTS

gnutls_ocsp_req_const_t req
devrait contenir un type gnutls_ocsp_req_t
unsigned indx
Spécifie quel OID d'extension obtenir. Utilisez (0) pour obtenir le premier.
gnutls_digest_algorithm_t * digest
variable de sortie avec l'algorithme de hachage gnutls_digest_algorithm_t
gnutls_datum_t * issuer_name_hash
tampon de sortie avec le hachage du DN de l'émetteur
gnutls_datum_t * issuer_key_hash
tampon de sortie avec le hachage de la clé publique de l'émetteur
gnutls_datum_t * serial_number
tampon de sortie avec le numéro de série du certificat à vérifier

DESCRIPTION

Cette fonction retournera les informations du certificat de la
requête indx dans la requête OCSP. Les informations retournées correspondent à la structure CertID :

<informalexample><programlisting> CertID ::= SEQUENCE { hashAlgorithm AlgorithmIdentifier, issuerNameHash OCTET STRING, -- Hash of Issuer's DN issuerKeyHash OCTET STRING, -- Hash of Issuers public key serialNumber CertificateSerialNumber } </programlisting></informalexample>

Chacun des pointeurs vers les variables de sortie peut être NULL pour indiquer que l'appelant n'est pas intéressé par cette valeur.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné. Si vous avez atteint le dernier CertID disponible, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
