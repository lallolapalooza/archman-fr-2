NOM

gnutls_srp_base64_encode2 - Fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_srp_base64_encode2(const gnutls_datum_t * data, gnutls_datum_t * result);

ARGUMENTS

const gnutls_datum_t * data
contient les données brutes
gnutls_datum_t * result
contiendra les données encodées nouvellement allouées

DESCRIPTION

Cette fonction convertira les données fournies en données imprimables, en utilisant l'encodage base64. C'est l'encodage utilisé dans les fichiers de mots de passe SRP. Cette fonction allouera la mémoire nécessaire pour contenir les données encodées.

Vous devriez utiliser gnutls_free() pour libérer les données retournées.

Attention ! Cet encodage base64 n'est pas l'encodage "standard", ne l'utilisez donc pas à des fins non-SRP.

RETOURNE

0 en cas de succès, ou un code d'erreur.
