gnutls_certificate_set_x509_simple_pkcs12_file(3) gnutls gnutls_certificate_set_x509_simple_pkcs12_file(3)

NOM

gnutls_certificate_set_x509_simple_pkcs12_file - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_simple_pkcs12_file(gnutls_certificate_credentials_t res, const char * pkcs12file, gnutls_x509_crt_fmt_t type, const char * password);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
const char * pkcs12file
nom du fichier contenant le blob PKCS12.
gnutls_x509_crt_fmt_t type
est PEM ou DER du fichier pkcs12file.
const char * password
mot de passe optionnel utilisé pour décrypter le fichier PKCS12, les sacs et les clés.

DESCRIPTION

Cette fonction définit une paire certificat/clé privée et/ou une CRL dans le type gnutls_certificate_credentials_t. Cette fonction peut être appelée plus d'une fois (en cas de multiples clés/certificats pour le serveur).

Les fichiers PKCS12 avec une MAC, les sacs cryptés et les clés privées PKCS8 sont supportés. Cependant, seuls les mots de passe et le même mot de passe pour toutes les opérations sont supportés.

Le fichier PKCS12 peut contenir plusieurs clés et/ou certificats, et cette fonction essaiera de détecter automatiquement la paire certificat et clé à utiliser en fonction de l'ID de la clé. Si le fichier PKCS12 contient l'émetteur du certificat sélectionné, il sera ajouté au certificat pour former une chaîne.

Si plus d'une clé privée est stockée dans le fichier PKCS12, une seule clé sera lue (et il est indéfini laquelle).

On pense que les limitations de cette fonction sont acceptables pour la plupart des usages, et que toute flexibilité supplémentaire introduirait une complexité qui rendrait cette fonctionnalité plus difficile à utiliser.

Notez que cette fonction renvoie par défaut zéro en cas de succès et une valeur négative en cas d'erreur. Depuis la version 3.5.6, lorsque le drapeau GNUTLS_CERTIFICATE_API_V2 est défini à l'aide de gnutls_certificate_set_flags(), elle renvoie un index (supérieur ou égal à zéro). Cet index peut être utilisé pour d'autres fonctions afin de faire référence à la paire clé ajoutée.

RETOURNE

En cas de succès, cette fonction retourne zéro, et sinon une valeur négative en cas d'erreur (voir ci-dessus pour modifier ce comportement).
