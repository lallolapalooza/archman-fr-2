NOM

gnutls_record_recv - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

ssize_t gnutls_record_recv(gnutls_session_t session, void * data, size_t data_size);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
void * data
le tampon dans lequel les données seront lues
size_t data_size
le nombre d'octets demandés

DESCRIPTION

Cette fonction a des sémantiques similaires à recv(). La seule différence est qu'elle accepte une session GnuTLS et utilise des codes d'erreur différents. Dans le cas spécial où le pair demande une renégociation, l'appelant recevra un code d'erreur GNUTLS_E_REHANDSHAKE. Dans le cas d'un client, ce message peut simplement être ignoré, répondu avec une alerte GNUTLS_A_NO_RENEGOTIATION, ou répondu avec une nouvelle négociation, selon la volonté du client. Un serveur recevant ce code d'erreur ne peut qu'initier une nouvelle négociation ou terminer la session.

Si EINTR est retourné par la fonction de lecture interne (par défaut, recv()), alors GNUTLS_E_INTERRUPTED sera retourné. Si GNUTLS_E_INTERRUPTED ou GNUTLS_E_AGAIN est retourné, vous devez appeler à nouveau cette fonction pour obtenir les données. Voir aussi gnutls_record_get_direction().

RETOURNE

Le nombre d'octets reçus et zéro sur EOF (pour les connexions en flux). Un code d'erreur négatif est retourné en cas d'erreur. Le nombre d'octets reçus peut être inférieur au data_size demandé.
