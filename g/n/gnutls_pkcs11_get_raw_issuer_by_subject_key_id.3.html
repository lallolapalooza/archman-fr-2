NOM

gnutls_pkcs11_get_raw_issuer_by_subject_key_id - Fonction d'API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_get_raw_issuer_by_subject_key_id(const char * url, const gnutls_datum_t * dn, const gnutls_datum_t * spki, gnutls_datum_t * issuer, gnutls_x509_crt_fmt_t fmt, unsigned int flags);

ARGUMENTS

const char * url
Une URL PKCS 11 identifiant un jeton
const gnutls_datum_t * dn
est le DN à rechercher (peut être NULL)
const gnutls_datum_t * spki
est l'ID de clé du sujet à rechercher
gnutls_datum_t * issuer
Contiendra l'émetteur, le cas échéant, dans un tampon alloué.
gnutls_x509_crt_fmt_t fmt
Le format de l'émetteur exporté.
unsigned int flags
Utiliser zéro ou des drapeaux de GNUTLS_PKCS11_OBJ_FLAG.

DESCRIPTION

Cette fonction renverra le certificat avec le DN et le spki donnés, s'il est stocké dans le jeton. Par défaut, seuls les émetteurs marqués comme de confiance sont renvoyés. Si un émetteur quelconque doit être renvoyé, spécifiez GNUTLS_PKCS11_OBJ_FLAG_RETRIEVE_ANY dans flags.

Le nom de la fonction inclut « issuer » car elle peut être utilisée pour découvrir les émetteurs de certificats.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon une valeur d'erreur négative.
