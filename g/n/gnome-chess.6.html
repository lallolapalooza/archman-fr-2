NOM

gnome-chess — Une application d'échecs simple pour GNOME

SYNTAXE

gnome-chess

DESCRIPTION

gnome-chess est une application d'échecs, anciennement connue sous le nom de glchess. Elle prend en charge les intelligences artificielles compatibles CECP et UCI.

Plus d'informations peuvent être trouvées sur https://gitlab.gnome.org/GNOME/gnome-chess

VOIR AUSSI

gnuchess(6), crafty(6), amy(6), faile(6), xboard(6).
