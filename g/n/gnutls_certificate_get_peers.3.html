NOM

gnutls_certificate_get_peers - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

const gnutls_datum_t * gnutls_certificate_get_peers(gnutls_session_t session, unsigned int * list_size);

ARGUMENTS

gnutls_session_t session
est une session gnutls
unsigned int * list_size
est la longueur de la liste de certificats (peut être NULL)

DESCRIPTION

Récupère le certificat brut du pair (chaîne) tel qu'envoyé par le pair. Ces certificats sont au format brut (encodé DER pour X.509). Dans le cas d'un X.509, une liste de certificats peut être présente. La liste est fournie telle qu'envoyée par le serveur; le serveur doit envoyer comme premier certificat de la liste son propre certificat, suivi du certificat de l'émetteur, puis de l'émetteur de l'émetteur, etc. Cependant, certains serveurs violent ce principe et donc, dans certaines occasions, il peut s'agir d'une liste non triée.

Dans les sessions reprises, cette fonction retournera la liste de certificats du pair telle qu'utilisée dans la première/originale session.

RETOUR

un pointeur vers une gnutls_datum_t contenant les certificats du pair, ou NULL en cas d'erreur ou si aucun certificat n'a été utilisé.
