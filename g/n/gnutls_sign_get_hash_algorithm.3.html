NOM

gnutls_sign_get_hash_algorithm - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

gnutls_digest_algorithm_t gnutls_sign_get_hash_algorithm(gnutls_sign_algorithm_t sign);

ARGUMENTS

gnutls_sign_algorithm_t sign
est un algorithme de signature

DESCRIPTION

Cette fonction renvoie l'algorithme de hachage correspondant aux algorithmes de signature donnés.

DEPUIS

3.1.1

RETOURS

renvoie une valeur gnutls_digest_algorithm_t, ou GNUTLS_DIG_UNKNOWN en cas d'erreur.
