NOM

gnucash-cli - outil en ligne de commande pour GnuCash

SYNTAXE

gnucash-cli [options] [ accounts.gnucash ]

DESCRIPTION

gnucash-cli permet certaines interactions avec un fichier de données gnucash directement depuis la ligne de commande.

Il dispose de deux modes : le mode quotes et le mode report.

Mode Quotes (activé avec --quotes <cmd>)

Ce mode propose des options pour obtenir des cotations en ligne pour les devises étrangères et les actions dans le fichier de données donné. Il prend en charge la commande suivante :

info
Affiche la version de Finance::Quote et les sources de cotation exposées.
get
Récupère les cotations en ligne. Notez que cela nécessite que Finance::Quote soit correctement configuré pour votre système.

La commande get prend les options suivantes :

--namespace=REGEXP
Expression régulière déterminant quelles marchandises de quel namespace seront récupérées.
dump
Récupère les cotations actuelles pour les devises ou actions spécifiées à partir d'un namespace spécifié et affiche les résultats dans la console. Ceci doit être suivi d'une source et d'un ou plusieurs symboles, sauf si la source est "currency" dans quel cas elle doit être suivie de deux symboles ou plus, le premier étant la devise dans laquelle les taux de change pour les autres seront cotés.

La commande dump prend l'option

-v
--verbose
Liste tous les paramètres que Finance::Quote renvoie pour le symbole au lieu de seulement ceux dont Gnucash a besoin.

Mode Rapport (activé avec --report <cmd>)

Ce mode propose des options pour travailler avec les rapports dans le fichier de données donné. Il prend en charge la commande suivante :

run
Exécute un rapport sur le fichier de données donné.

La commande run prend les options suivantes :

--name=NOM_RAPPORT
Nom du rapport à exécuter
--export-type=TYPE
Spécifier le type d'exportation

Options Générales

--version
Afficher la version de GnuCash
--help
Afficher ce message d'aide
--debug
Activer le mode de débogage : augmentation de la journalisation pour fournir des détails approfondis.
--extra
Activer les fonctionnalités supplémentaires/développement/débogage.
--log
Surtensions du niveau de journalisation, de la forme "log.ger.path={debug,info,warn,crit,error}" Cette option peut être spécifiée plusieurs fois.
--logto
Fichier dans lequel enregistrer ; par défaut "$TMPDIR/gnucash.trace" ; utiliser "stderr" ou "stdout" pour écrire dans le terminal.

FICHIERS

~/.gnucash/config.auto

Fichier de configuration généré automatiquement par utilisateur. NE PAS MODIFIER MANUELLEMENT !

ENVIRONNEMENT

GNC_DEBUG
Activer la sortie de débogage. Cela vous permet d'activer le débogage plus tôt dans le processus de démarrage que vous ne le pouvez avec --debug.
GUILE_LOAD_PATH
Un remplacement du chemin de chargement scheme de GnuCash. Vous ne devriez pas avoir besoin de le modifier. Pour plus d'informations, consultez le fichier README.
GNC_MODULE_PATH
Un remplacement du chemin de chargement scheme de GnuCash pour les modules Gnucash. Vous ne devriez pas avoir besoin de le modifier. Pour plus d'informations, consultez le fichier README.

BOGUES

Veuillez signaler tout bogue en utilisant le formulaire de signalement de bogue sur le site Web de GnuCash.

VOIR AUSSI

Des informations supplémentaires et la dernière version sont disponibles sur le site Web : https://www.gnucash.org
