NOM

gnutls_error_to_alert - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_error_to_alert(int err, int * level);

ARGUMENTS

int err
est un entier négatif
int * level
le niveau d'alerte y sera stocké

DESCRIPTION

Obtenir une alerte en fonction du code d'erreur renvoyé par une fonction gnutls. Toutes les alertes envoyées par cette fonction doivent être considérées comme fatales. La seule exception est lorsque err est GNUTLS_E_REHANDSHAKE, où une alerte d'avertissement doit être envoyée au pair pour indiquer qu'aucune renégociation ne sera effectuée.

S'il n'y a pas de correspondance avec une alerte valide, l'alerte indiquant une erreur interne (GNUTLS_A_INTERNAL_ERROR) est renvoyée.

RETOURNE

le code d'alerte à utiliser pour un code d'erreur particulier.
