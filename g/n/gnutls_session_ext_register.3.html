NOM

gnutls_session_ext_register - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_session_ext_register(gnutls_session_t session, const char * name, int id, gnutls_ext_parse_type_t parse_point, gnutls_ext_recv_func recv_func, gnutls_ext_send_func send_func, gnutls_ext_deinit_data_func deinit_func, gnutls_ext_pack_func pack_func, gnutls_ext_unpack_func unpack_func, unsigned flags);

ARGUMENTS

gnutls_session_t session
la session pour laquelle cette extension sera définie
const char * name
le nom de l'extension à enregistrer
int id
l'identifiant numérique de l'extension
gnutls_ext_parse_type_t parse_point
le type d'analyse de l'extension (voir gnutls_ext_parse_type_t)
gnutls_ext_recv_func recv_func
une fonction pour recevoir les données
gnutls_ext_send_func send_func
une fonction pour envoyer les données
gnutls_ext_deinit_data_func deinit_func
une fonction pour désinitialiser toute donnée privée
gnutls_ext_pack_func pack_func
une fonction qui sérialise les données privées de l'extension (utilisée lors de l'empaquetage de session pour la reprise)
gnutls_ext_unpack_func unpack_func
une fonction qui désérialisera les données privées de l'extension
unsigned flags
doit être zéro ou des drapeaux de gnutls_ext_flags_t

DESCRIPTION

Cette fonction enregistre un nouveau type d'extension. L'extension ne sera utilisable qu'au sein de la session enregistrée. Si le type d'extension est déjà enregistré, GNUTLS_E_ALREADY_REGISTERED sera retourné, à moins que le drapeau GNUTLS_EXT_FLAG_OVERRIDE_INTERNAL ne soit spécifié. Ce dernier drapeau, lorsqu'il est spécifié, peut être utilisé pour remplacer certaines extensions introduites après la version 3.6.0. Il est censé être utilisé par les applications qui gèrent des extensions personnalisées non prises en charge actuellement par GnuTLS, mais un support direct pourrait être ajouté à l'avenir.

Chaque extension enregistrée peut stocker des données temporaires dans la structure gnutls_session_t en utilisant gnutls_ext_set_data(), et elles peuvent être récupérées en utilisant gnutls_ext_get_data().

La validité de l'extension enregistrée peut être donnée par les drapeaux appropriés de gnutls_ext_flags_t. Si aucune validité n'est donnée, l'extension enregistrée sera valide pour le client et le serveur TLS1.2 hello (ou les extensions chiffrées pour TLS1.3).

RETOUR

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
