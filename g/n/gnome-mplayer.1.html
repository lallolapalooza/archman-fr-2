DESCRIPTIO

N

Cette page de manuel documente brièvement la commande gnome

-mplayer.

gnome-mplayer fournit une interface simple et épurée pour MPlayer.
GNOME MPlayer dispose d'une riche API exposée via DBus.
À l'aide de DBus, vous pouvez contrôler une ou plusieurs instances de GNOME MPlayer depuis une seule commande.
GNOME MPlayer peut être utilisé pour lire des médias sur des sites web lorsqu'il est utilisé en conjonction avec Gecko

Mediaplayer.

Page d'accueil : http://kdekorte.googlepages.

com/gnomemplaye
