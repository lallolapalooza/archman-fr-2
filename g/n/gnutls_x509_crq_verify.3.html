NOM

gnutls_x509_crq_verify - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_verify(gnutls_x509_crq_t crq, unsigned int flags);

ARGUMENTS

gnutls_x509_crq_t crq
est la requête de certificat à vérifier
unsigned int flags
Indicateurs qui peuvent être utilisés pour modifier l'algorithme de vérification. Utiliser l'opérateur OR des énumérations gnutls_certificate_verify_flags.

DESCRIPTION

Cette fonction vérifiera la signature interne de la requête de certificat et retournera son statut.

VALEUR

En cas d'échec de vérification, GNUTLS_E_PK_SIG_VERIFY_FAILED est retourné, et un code zéro ou positif en cas de succès.

Depuis 2.12.0
