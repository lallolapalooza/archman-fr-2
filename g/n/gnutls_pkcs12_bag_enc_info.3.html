NOM

gnutls_pkcs12_bag_enc_info - Fonction API

SYNOPSIS

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_bag_enc_info(gnutls_pkcs12_bag_t bag, unsigned int * schema, unsigned int * cipher, void * salt, unsigned int * salt_size, unsigned int * iter_count, char ** oid);

ARGUMENTS

gnutls_pkcs12_bag_t bag
Le sac
unsigned int * schema
indique le schéma comme l'une des gnutls_pkcs_encrypt_flags_t
unsigned int * cipher
le chiffrement utilisé comme gnutls_cipher_algorithm_t
void * salt
sel PBKDF2 (si non NULL, alors salt_size contient initialement sa taille)
unsigned int * salt_size
taille du sel PBKDF2
unsigned int * iter_count
nombre d'itérations PBKDF2
char ** oid
si non NULL, il contiendra une variable allouée et terminée par null avec l'OID

DESCRIPTION

Cette fonction fournira des informations sur les algorithmes de chiffrement utilisés dans un sac chiffré. Si les algorithmes de la structure sont inconnus, le code GNUTLS_E_UNKNOWN_CIPHER_TYPE sera retourné, et seul oid sera défini. C'est-à-dire que oid sera défini pour les sacs chiffrés, qu'ils soient supportés ou non. Il doit être désinitialisé à l'aide de gnutls_free(). Les autres variables ne sont définies que pour les structures supportées.

RETOURNE

GNUTLS_E_INVALID_REQUEST si le sac fourni n'est pas chiffré, GNUTLS_E_UNKNOWN_CIPHER_TYPE si le chiffrement de la structure n'est pas supporté, ou un autre code d'erreur négatif en cas d'échec. Zéro en cas de succès.
