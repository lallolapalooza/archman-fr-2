NOM

gnutls_x509_crl_verify - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crl_verify(gnutls_x509_crl_t crl, const gnutls_x509_crt_t * trusted_cas, unsigned tcas_size, unsigned int flags, unsigned int * verify);

ARGUMENTS

gnutls_x509_crl_t crl
est le CRL à vérifier
const gnutls_x509_crt_t * trusted_cas
est une liste de certificats considérée comme fiable
unsigned tcas_size
contient le nombre de certificats d'AC dans CA_list
unsigned int flags
Indicateurs qui peuvent être utilisés pour modifier l'algorithme de vérification. Utiliser l'opérateur OR des énumérations gnutls_certificate_verify_flags.
unsigned int * verify
contiendra le résultat de la vérification du CRL.

DESCRIPTION

Cette fonction tentera de vérifier le CRL donné et renverra son statut de vérification. Voir gnutls_x509_crt_list_verify() pour une description détaillée des valeurs de retour. Notez qu'à partir de GnuTLS 3.1.4, cette fonction inclut les vérifications temporelles.

Notez que la valeur de verify n'est définie que lorsque la valeur de retour de cette fonction est un succès (c'est-à-dire qu'un échec à faire confiance à un CRL ou à un certificat n'implique pas une valeur de retour négative).

Avant GnuTLS 3.5.7, cette fonction renvoyait zéro ou un nombre positif en cas de succès.

RETOUR

En cas de succès, renvoie GNUTLS_E_SUCCESS (0), sinon une valeur d'erreur négative.
