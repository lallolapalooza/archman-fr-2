NOM

gnutls_openpgp_privkey_sign_hash - Fonction d'API

SYNOPSIS

#include <gnutls/compat.h>

int gnutls_openpgp_privkey_sign_hash(gnutls_openpgp_privkey_t key, const gnutls_datum_t * hash, gnutls_datum_t * signature);

ARGUMENTS

gnutls_openpgp_privkey_t key
Contient la clé
const gnutls_datum_t * hash
Contient les données à signer
gnutls_datum_t * signature
Contiendra la nouvelle signature allouée

DESCRIPTION

Cette fonction ne fait rien.

RETOUR

GNUTLS_E_UNIMPLEMENTED_FEATURE.
