gnu::aligned(3attr) gnu::aligned(3attr)

NOM

gnu::aligned - définir l'alignement d'un objet

SYNOPIS

[[gnu::aligned(alignement)]]
[[gnu::aligned]]

DESCRIPTION

Cet attribut peut être appliqué à un type ou à une variable, et définit son alignement en octets.

Si l’alignement n’est pas spécifié, l’alignement maximal est utilisé. Ceci est équivalent à


[[gnu::aligned(alignof(max_align_t))]]

VERSIONS

__attribute__((aligned(alignement)))
__declspec(align(alignement))

C11 fournit le spécificateur de type _Alignas(), qui a une sémantique similaire.

NORMES

GNU.

HISTORIQUE

gcc, g++, clang 11, clang++ 2.8.0.

LIMITATIONS

Cet attribut peut augmenter l'alignement naturel d'un type, mais il ne peut pas le diminuer.

L'éditeur de liens peut limiter l'alignement maximal qui peut être appliquée.
