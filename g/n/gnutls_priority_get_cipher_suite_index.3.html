NOM

gnutls_priority_get_cipher_suite_index - Fonction API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_priority_get_cipher_suite_index(gnutls_priority_t pcache, unsigned int idx, unsigned int * sidx);

ARGUMENTS

gnutls_priority_t pcache
est un type gnutls_priority_t.
unsigned int idx
est un numéro d'index.
unsigned int * sidx
index interne de la suite de chiffrement pour laquelle obtenir des informations.

DESCRIPTION

Fournit l'index interne de la suite de chiffrement à utiliser avec gnutls_cipher_suite_info(). L'index idx fourni est un index conservé dans la structure des priorités. Il se peut qu'un index de priorité valide ne corresponde pas à une suite de chiffrement et, dans ce cas, GNUTLS_E_UNKNOWN_CIPHER_SUITE sera retourné. Une fois le dernier index disponible dépassé, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.

RETOURNE

En cas de succès, renvoie GNUTLS_E_SUCCESS (0), ou une valeur d'erreur négative sinon.
