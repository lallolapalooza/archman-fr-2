NOM

gnutls_x509_trust_list_add_cas - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_trust_list_add_cas(gnutls_x509_trust_list_t list, const gnutls_x509_crt_t * clist, unsigned clist_size, unsigned int flags);

ARGUMENTS

gnutls_x509_trust_list_t list
La liste
const gnutls_x509_crt_t * clist
Une liste de CA
unsigned clist_size
La longueur de la liste de CA
unsigned int flags
Drapeaux de gnutls_trust_list_flags_t

DESCRIPTION

Cette fonction ajoutera les autorités de certification données à la liste de confiance. Les CA dans clist ne doivent pas être désinitialisées pendant la durée de vie de list .

Si le drapeau GNUTLS_TL_NO_DUPLICATES est spécifié, cette fonction garantira qu'aucun doublon ne sera présent dans la liste de confiance finale.

Si le drapeau GNUTLS_TL_NO_DUPLICATE_KEY est spécifié, cette fonction garantira qu'aucun certificat avec la même clé ne sera présent dans la liste de confiance finale.

Si GNUTLS_TL_NO_DUPLICATE_KEY ou GNUTLS_TL_NO_DUPLICATES sont donnés, gnutls_x509_trust_list_deinit() doit être appelé avec le paramètre
all égal à 1.

RETOURNE

Le nombre d'éléments ajoutés est retourné ; cela inclut les entrées doublons.
