NOM

gnutls_certificate_type_get2 - fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

gnutls_certificate_type_t gnutls_certificate_type_get2(gnutls_session_t session, gnutls_ctype_target_t target);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
gnutls_ctype_target_t target
est un type gnutls_ctype_target_t.

DESCRIPTION

Cette fonction renvoie le type de certificat que l'une des parties a négocié pour utiliser. Le type de certificat est X.509 par défaut, sauf si un type de certificat alternatif est activé par gnutls_init() et négocié pendant la session.

Le paramètre target spécifie si l'on doit demander le type de certificat négocié pour le client (GNUTLS_CTYPE_CLIENT) ou pour le serveur (GNUTLS_CTYPE_SERVER). De plus, dans une connexion P2P où l'on ne sait pas à l'avance qui sera le client et qui sera le serveur, on peut utiliser les indicateurs (GNUTLS_CTYPE_OURS) et (GNUTLS_CTYPE_PEERS) pour récupérer les types de certificats correspondants.

Les sessions reprises renverront le type de certificat qui a été négocié et utilisé lors de la session d'origine. C'est-à-dire que cette fonction peut être utilisée pour déterminer de manière fiable le type du certificat renvoyé par gnutls_certificate_get_peers().

RETOURNE

le type de certificat gnutls_certificate_type_t actuellement utilisé pour le client ou le serveur.
