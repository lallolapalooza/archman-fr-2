NOM

gnutls_pkcs12_bag_set_data - Fonction API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_bag_set_data(gnutls_pkcs12_bag_t bag, gnutls_pkcs12_bag_type_t type, const gnutls_datum_t * data);

ARGUMENTS

gnutls_pkcs12_bag_t bag
Le sac
gnutls_pkcs12_bag_type_t type
Le type des données
const gnutls_datum_t * data
les données à copier.

DESCRIPTION

Cette fonction insérera les données fournies du type spécifié dans le sac.

RETOURNE

l'index du sac ajouté en cas de succès, ou une valeur négative en cas d'erreur.
