NOM

gnutls_x509_crq_get_key_id - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_get_key_id(gnutls_x509_crq_t crq, unsigned int flags, unsigned char * output_data, size_t * output_data_size);

ARGUMENTS

gnutls_x509_crq_t crq
un certificat de type gnutls_x509_crq_t
unsigned int flags
devrait être l'un des drapeaux de gnutls_keyid_flags_t
unsigned char * output_data
contiendra l'identifiant de clé
size_t * output_data_size
contient la taille de output_data (et sera remplacé par la taille réelle des paramètres)

DESCRIPTION

Cette fonction renverra un identifiant unique qui dépend des paramètres de la clé publique. Cet identifiant peut être utilisé pour vérifier si un certificat correspond à la clé privée donnée.

Si le tampon fourni n'est pas assez long pour contenir la sortie, alors * output_data_size est mis à jour et GNUTLS_E_SHORT_MEMORY_BUFFER sera renvoyé. La sortie sera normalement une sortie de hachage SHA-1, qui fait 20 octets.

RETOUR

En cas d'échec, un code d'erreur négatif sera renvoyé, et 0 en cas de succès.
