NOM

gnutls_handshake_set_hook_function - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_handshake_set_hook_function(gnutls_session_t session, unsigned int htype, int when, gnutls_handshake_hook_func func);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t
unsigned int htype
la gnutls_handshake_description_t du message à intercepter
int when
GNUTLS_HOOK_* selon le moment où la fonction de rappel doit être appelée
gnutls_handshake_hook_func func
est la fonction à appeler

DESCRIPTION

Cette fonction définira un rappel à appeler après ou avant la réception ou la génération du message de négociation spécifié. Ceci est une généralisation de gnutls_handshake_set_post_client_hello_function().

Pour appeler la fonction de rappel avant la génération ou le traitement du message, utilisez GNUTLS_HOOK_PRE comme paramètre when, GNUTLS_HOOK_POST pour appeler après, et GNUTLS_HOOK_BOTH pour les deux cas.

Ce rappel doit retourner 0 en cas de succès ou un code d'erreur gnutls pour terminer la négociation.

Pour intercepter tous les messages de négociation, utilisez un htype de GNUTLS_HANDSHAKE_ANY.

AVERTISSEMENT

Vous ne devriez pas utiliser cette fonction pour terminer la négociation en fonction de l'entrée du client, sauf si vous savez ce que vous faites. Avant que la négociation ne soit terminée, il n'y a aucun moyen de savoir si une attaque de l'homme du milieu est en cours.
