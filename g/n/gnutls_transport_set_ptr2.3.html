NOM

gnutls_transport_set_ptr2 - Fonction API

SYNOPSIS

#include <gnutls/gnutls.h>

void gnutls_transport_set_ptr2(gnutls_session_t session, gnutls_transport_ptr_t recv_ptr, gnutls_transport_ptr_t send_ptr);

ARGUMENTS

gnutls_session_t session
est de type gnutls_session_t.
gnutls_transport_ptr_t recv_ptr
est la valeur pour la fonction de récupération (pull)
gnutls_transport_ptr_t send_ptr
est la valeur pour la fonction d'envoi (push)

DESCRIPTION

Utilisé pour définir le premier argument de la fonction de transport (pour les callbacks d'envoi et de récupération). Dans les sockets de style Berkeley, cette fonction définira le descripteur de connexion. Avec cette fonction, vous pouvez utiliser deux pointeurs différents pour la réception et l'envoi.
