gnutls_record_send(3)

gnutls_record_send(3) gnutls gnutls_record_send(3)

NOM

gnutls_record_send - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

ssize_t gnutls_record_send(gnutls_session_t session, const void * data, size_t data_size);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
const void * data
contient les données à envoyer
size_t data_size
est la longueur des données

DESCRIPTION

Cette fonction a des sémantiques similaires à send(). La seule différence est qu'elle accepte une session GnuTLS et utilise des codes d'erreur différents. Notez que si le tampon d'envoi est plein, send() bloquera cette fonction. Voir la documentation de send() pour plus d'informations.

Vous pouvez remplacer la fonction push par défaut, qui est send(), en utilisant gnutls_transport_set_push_function().

Si EINTR est renvoyé par la fonction push interne, GNUTLS_E_INTERRUPTED sera renvoyé. Si GNUTLS_E_INTERRUPTED ou GNUTLS_E_AGAIN est renvoyé, vous devez appeler cette fonction à nouveau avec exactement les mêmes paramètres, ou fournir un pointeur NULL pour data et 0 pour data_size, afin d'écrire les mêmes données qu'auparavant. Si vous souhaitez supprimer les données précédentes au lieu de retenter, vous devez appeler gnutls_record_discard_queued() avant d'appeler cette fonction avec des paramètres différents. Notez que cette dernière ne fonctionne que sur des transports spéciaux (par exemple, UDP). cf. gnutls_record_get_direction().

Notez qu'en DTLS, cette fonction renverra le code d'erreur GNUTLS_E_LARGE_PACKET si les données envoyées dépassent la valeur MTU des données - telle que renvoyée par gnutls_dtls_get_data_mtu(). La valeur errno EMSGSIZE est également mappée à GNUTLS_E_LARGE_PACKET. Notez que depuis la version 3.2.13, cette fonction peut être appelée sous cork en mode DTLS, et refusera d'envoyer des données dépassant la taille MTU en renvoyant GNUTLS_E_LARGE_PACKET.

RETOUR

Le nombre d'octets envoyés, ou un code d'erreur négatif. Le nombre d'octets envoyés peut être inférieur à data_size. Le nombre maximum d'octets que cette fonction peut envoyer en un seul appel dépend de la taille maximale des enregistrements négociée.
