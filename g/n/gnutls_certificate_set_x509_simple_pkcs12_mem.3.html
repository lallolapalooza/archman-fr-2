gnutls_certificate_set_x509_simple_pkcs12_mem(3)

gnutls_certificate_set_x509_simple_pkcs12_mem(3) gnutls gnutls_certificate_set_x509_simple_pkcs12_mem(3)

NOM

gnutls_certificate_set_x509_simple_pkcs12_mem - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_simple_pkcs12_mem(gnutls_certificate_credentials_t res, const gnutls_datum_t * p12blob, gnutls_x509_crt_fmt_t type, const char * password);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
const gnutls_datum_t * p12blob
le blob PKCS12.
gnutls_x509_crt_fmt_t type
est PEM ou DER du pkcs12file.
const char * password
mot de passe optionnel utilisé pour décrypter le fichier PKCS12, les conteneurs et les clés.

DESCRIPTION

Cette fonction configure une paire certificat/clé privée et/ou une CRL dans le type gnutls_certificate_credentials_t. Cette fonction peut être appelée plusieurs fois (en cas de clés/certificats multiples pour le serveur).

Les conteneurs PKCS12 chiffrés et les clés privées PKCS8 sont pris en charge. Cependant, seule la sécurité basée sur un mot de passe, et le même mot de passe pour toutes les opérations, sont pris en charge.

Le fichier PKCS12 peut contenir de nombreuses clés et/ou certificats, et cette fonction tentera de détecter automatiquement, en fonction de l'identifiant de clé, la paire certificat et clé à utiliser. Si le fichier PKCS12 contient l'émetteur du certificat sélectionné, il sera ajouté au certificat pour former une chaîne.

Si plus d'une clé privée est stockée dans le fichier PKCS12, une seule clé sera lue (et il est indéfini laquelle).

On estime que les limitations de cette fonction sont acceptables pour la plupart des utilisations, et que toute flexibilité supplémentaire introduirait une complexité qui rendrait plus difficile l'utilisation de cette fonctionnalité.

Notez que, par défaut, cette fonction retourne zéro en cas de succès et une valeur négative en cas d'erreur. Depuis la version 3.5.6, lorsque le flag GNUTLS_CERTIFICATE_API_V2 est défini à l'aide de gnutls_certificate_set_flags(), elle retourne un index (supérieur ou égal à zéro). Cet index peut être utilisé dans d'autres fonctions pour faire référence à la paire clé ajoutée.

RETOURNE

En cas de succès, cette fonction retourne zéro, et sinon une valeur négative en cas d'erreur (voir ci-dessus pour modifier ce comportement).
