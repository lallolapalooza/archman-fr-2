NOM

gnutls_pkcs11_obj_get_exts - fonction d'API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_get_exts(gnutls_pkcs11_obj_t obj, gnutls_x509_ext_st ** exts, unsigned int * exts_size, unsigned int flags);

ARGUMENTS

gnutls_pkcs11_obj_t obj
doit contenir un type gnutls_pkcs11_obj_t
gnutls_x509_ext_st ** exts
un pointeur vers un pointeur gnutls_x509_ext_st
unsigned int * exts_size
sera mis à jour avec le nombre de exts
unsigned int flags
Ou une séquence de drapeaux GNUTLS_PKCS11_OBJ_*

DESCRIPTION

Cette fonction renverra des informations sur les extensions attachées qui sont associées à l'objet fourni (qui devrait être un certificat). Les extensions sont les extensions du module de confiance p11-kit attachées.

Chaque élément de exts doit être désinitialisé à l'aide de gnutls_x509_ext_deinit() tandis que exts doit être désalloué à l'aide de gnutls_free().

VALEUR DE RETOUR

GNUTLS_E_SUCCESS (0) en cas de succès ou un code d'erreur négatif en cas d'échec.
