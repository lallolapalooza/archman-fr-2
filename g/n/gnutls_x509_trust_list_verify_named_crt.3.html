NOM

gnutls_x509_trust_list_verify_named_crt - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_trust_list_verify_named_crt(gnutls_x509_trust_list_t list, gnutls_x509_crt_t cert, const void * name, size_t name_size, unsigned int flags, unsigned int * voutput, gnutls_verify_output_function func);

ARGUMENTS

gnutls_x509_trust_list_t list
La liste
gnutls_x509_crt_t cert
est le certificat à vérifier
const void * name
est le nom du certificat
size_t name_size
est la taille du nom du certificat
unsigned int flags
Drapeaux qui peuvent être utilisés pour modifier l'algorithme de vérification. Utiliser l'opérateur OU des énumérations gnutls_certificate_verify_flags.
unsigned int * voutput
contiendra la sortie de la vérification du certificat.
gnutls_verify_output_function func
S'il n'est pas nul, sera appelé sur chaque élément de la chaîne de vérification avec la sortie.

DESCRIPTION

Cette fonction tentera de trouver un certificat associé au nom fourni --voir gnutls_x509_trust_list_add_named_crt(). Si une correspondance est trouvée, le certificat est considéré comme valide. En plus de cela, cette fonction vérifiera également les listes de révocation de certificats (CRL). Le paramètre voutput contiendra une séquence OU des drapeaux gnutls_certificate_status_t.

De plus, un profil de vérification de certificat peut être spécifié parmi ceux de gnutls_certificate_verification_profiles_t en appliquant l'opérateur OU au résultat de GNUTLS_PROFILE_TO_VFLAGS() aux drapeaux de vérification.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
