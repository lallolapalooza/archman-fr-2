NOM

gnutls_certificate_set_retrieve_function3 - Fonction de l'API

SYNTAXE

#include <gnutls/abstract.h>

void gnutls_certificate_set_retrieve_function3(gnutls_certificate_credentials_t cred, gnutls_certificate_retrieve_function3 * func);

ARGUMENTS

gnutls_certificate_credentials_t cred
est un type gnutls_certificate_credentials_t.
gnutls_certificate_retrieve_function3 * func
est la fonction de rappel

DESCRIPTION

Cette fonction définit un rappel qui sera appelé pour récupérer le certificat et les réponses OCSP à utiliser lors de l'établissement de la connexion. func ne sera appelé que si le pair demande un certificat soit pendant l'établissement de la connexion, soit pendant l'authentification post-établissement.

Le prototype de la fonction de rappel est défini dans `abstract.h':

int gnutls_certificate_retrieve_function3( gnutls_session_t, const struct gnutls_cert_retr_st *info, gnutls_pcert_st **certs, unsigned int *certs_length, gnutls_ocsp_data_st **ocsp, unsigned int *ocsp_length, gnutls_privkey_t *privkey, unsigned int *flags);

Le champ info du rappel contient :
req_ca_dn qui est une liste des noms des CA que le serveur considère comme fiables. Ceci est un indice et typiquement le client devrait envoyer un certificat signé par l'une de ces CA. Ces noms, lorsqu'ils sont disponibles, sont encodés en DER. Pour obtenir une valeur plus significative, utilisez la fonction gnutls_x509_rdn_get().
pk_algos contient une liste des algorithmes de clés publiques acceptables par le serveur. Le certificat retourné doit supporter les algorithmes donnés par le serveur.

Le rappel doit remplir les valeurs suivantes :


certs doit contenir une liste allouée de certificats et de clés publiques.
certs_length est la taille de la liste précédente.
ocsp doit contenir une liste allouée de réponses OCSP.
ocsp_length est la taille de la liste précédente.
privkey est la clé privée.

Si les indicateurs dans le rappel sont définis à GNUTLS_CERT_RETR_DEINIT_ALL, alors toutes les valeurs fournies doivent être allouées en utilisant gnutls_malloc() et seront libérées par gnutls ; sinon, elles ne seront pas modifiées par gnutls.

La fonction de rappel doit définir la liste de certificats et de réponses OCSP à envoyer, et retourner 0 en cas de succès. Si aucun certificat n'est disponible, certs_length et ocsp_length doivent être mis à zéro. La valeur de retour (-1) indique une erreur et l'établissement de la connexion sera terminé. Si des certificats sont définis dans les identifiants et qu'un rappel est disponible, le rappel prend le dessus.

Clés publiques brutes : Dans le cas où des clés publiques brutes sont négociées comme type de certificat, les certificats qui contiendraient normalement les informations de la clé publique ne sont pas disponibles. Dans ce cas,
certs contient une liste allouée avec seulement la clé publique. Puisqu'il n'y a pas de certificat, il n'y a pas non plus de statut de certificat. Par conséquent, aucune information OCSP ne doit être définie.
