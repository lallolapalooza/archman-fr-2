NOM

gnutls_store_commitment - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_store_commitment(const char * db_name, gnutls_tdb_t tdb, const char * host, const char * service, gnutls_digest_algorithm_t hash_algo, const gnutls_datum_t * hash, time_t expiration, unsigned int flags);

ARGUMENTS

const char * db_name
Un fichier spécifiant les clés stockées (utiliser NULL pour la valeur par défaut)
gnutls_tdb_t tdb
Une structure de stockage ou NULL pour utiliser la valeur par défaut
const char * host
Le nom du pair
const char * service
non-NULL si cette clé est spécifique à un service (par exemple, http)
gnutls_digest_algorithm_t hash_algo
Le type d'algorithme de hachage
const gnutls_datum_t * hash
Le hachage brut
time_t expiration
L'heure d'expiration (utiliser 0 pour désactiver l'expiration)
unsigned int flags
doit être 0 ou GNUTLS_SCOMMIT_FLAG_ALLOW_BROKEN.

DESCRIPTION

Cette fonction stockera l'engagement de hachage fourni dans la liste des clés publiques stockées. La clé avec le hachage donné sera considérée comme valide jusqu'à l'heure d'expiration fournie.

La variable tdb, si non nulle, spécifie un backend personnalisé pour le stockage des entrées. Si elle est NULL, le backend de fichier par défaut sera utilisé.

Notez que cette fonction n'est pas thread-safe avec le backend par défaut.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
