gnutls_x509_trust_list_add_trust_file(3) gnutls gnutls_x509_trust_list_add_trust_file(3)

NOM

gnutls_x509_trust_list_add_trust_file - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_trust_list_add_trust_file(gnutls_x509_trust_list_t list, const char * ca_file, const char * crl_file, gnutls_x509_crt_fmt_t type, unsigned int tl_flags, unsigned int tl_vflags);

ARGUMENTS

gnutls_x509_trust_list_t list
La liste
const char * ca_file
Un fichier contenant une liste d'AC (facultatif)
const char * crl_file
Un fichier contenant une liste de CRL (facultatif)
gnutls_x509_crt_fmt_t type
Le format des certificats
unsigned int tl_flags
indicateurs de gnutls_trust_list_flags_t
unsigned int tl_vflags
gnutls_certificate_verify_flags si les indicateurs spécifient GNUTLS_TL_VERIFY_CRL

DESCRIPTION

Cette fonction ajoutera les autorités de certification données à la liste de confiance. Les URL PKCS 11 sont également acceptées à la place de fichiers par cette fonction. Une URL PKCS 11 implique une base de données de confiance (un module spécialement marqué dans p11-kit) ; l'URL "pkcs11:" implique toutes les bases de données de confiance du système. Une seule URL spécifiant des bases de données de confiance peut être définie ; elles ne peuvent pas être empilées avec plusieurs appels.

RETOURNE

Le nombre d'éléments ajoutés est retourné.
