gnutls_x509_privkey_import_rsa_raw2(3) gnutls gnutls_x509_privkey_import_rsa_raw2(3)

NOM

gnutls_x509_privkey_import_rsa_raw2 - Fonction de l'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_privkey_import_rsa_raw2(gnutls_x509_privkey_t key, const gnutls_datum_t * m, const gnutls_datum_t * e, const gnutls_datum_t * d, const gnutls_datum_t * p, const gnutls_datum_t * q, const gnutls_datum_t * u, const gnutls_datum_t * e1, const gnutls_datum_t * e2);

ARGUMENTS

gnutls_x509_privkey_t key
les données pour stocker la clé analysée
const gnutls_datum_t * m
contient le module
const gnutls_datum_t * e
contient l'exposant public
const gnutls_datum_t * d
contient l'exposant privé
const gnutls_datum_t * p
contient le premier nombre premier (p)
const gnutls_datum_t * q
contient le second nombre premier (q)
const gnutls_datum_t * u
contient le coefficient (optionnel)
const gnutls_datum_t * e1
contient e1 = d mod (p-1) (optionnel)
const gnutls_datum_t * e2
contient e2 = d mod (q-1) (optionnel)

DESCRIPTION

Cette fonction convertira les paramètres bruts RSA donnés dans le format natif gnutls_x509_privkey_t. La sortie sera stockée dans
key .

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
