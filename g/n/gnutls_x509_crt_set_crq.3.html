NOM

gnutls_x509_crt_set_crq - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_set_crq(gnutls_x509_crt_t crt, gnutls_x509_crq_t crq);

ARGUMENTS

gnutls_x509_crt_t crt
un certificat de type gnutls_x509_crt_t
gnutls_x509_crq_t crq
contient une requête de certificat

DESCRIPTION

Cette fonction définira le nom et les paramètres publics ainsi que les extensions de la requête de certificat donnée au certificat. Seules les clés RSA sont actuellement prises en charge.

Notez que cette fonction ne définira le crq que s'il est auto-signé et que la signature est correcte. Voir gnutls_x509_crq_sign2().

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
