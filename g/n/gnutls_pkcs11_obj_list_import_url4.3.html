gnutls_pkcs11_obj_list_import_url4(3) gnutls gnutls_pkcs11_obj_list_import_url4(3)

NOM

gnutls_pkcs11_obj_list_import_url4 - Fonction API

SYNOPSIS

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_list_import_url4(gnutls_pkcs11_obj_t ** p_list, unsigned int * n_list, const char * url, unsigned int flags);

ARGUMENTS

gnutls_pkcs11_obj_t ** p_list
Une liste d'objets non initialisée (peut être NULL)
unsigned int * n_list
Contiendra la taille de la liste.
const char * url
Une URL PKCS 11 identifiant un ensemble d'objets
unsigned int flags
Ou une séquence de drapeaux GNUTLS_PKCS11_OBJ_*

DESCRIPTION

Cette fonction énumérera tous les objets spécifiés par l'URL PKCS11 fournie. Elle initialisera et définira les valeurs de la liste de pointeurs d'objets ( p_list ) fournie. Pour obtenir une liste de tous les objets disponibles, utilisez l'URL 'pkcs11:'.

Tous les objets retournés doivent être désinitialisés en utilisant gnutls_pkcs11_obj_deinit(), et p_list doit être désalloué en utilisant gnutls_free().

Les drapeaux pris en charge par cette fonction sont GNUTLS_PKCS11_OBJ_FLAG_LOGIN, GNUTLS_PKCS11_OBJ_FLAG_LOGIN_SO, GNUTLS_PKCS11_OBJ_FLAG_PRESENT_IN_TRUSTED_MODULE, GNUTLS_PKCS11_OBJ_FLAG_CRT, GNUTLS_PKCS11_OBJ_FLAG_PUBKEY, GNUTLS_PKCS11_OBJ_FLAG_PRIVKEY, GNUTLS_PKCS11_OBJ_FLAG_WITH_PRIVKEY, GNUTLS_PKCS11_OBJ_FLAG_MARK_CA, GNUTLS_PKCS11_OBJ_FLAG_MARK_TRUSTED, et depuis la version 3.5.1, GNUTLS_PKCS11_OBJ_FLAG_OVERWRITE_TRUSTMOD_EXT.

Dans les versions de GnuTLS antérieures à 3.4.0, la fonction équivalente était gnutls_pkcs11_obj_list_import_url2(). Celle-ci est également disponible dans cette version en tant que macro qui pointe vers cette fonction.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
