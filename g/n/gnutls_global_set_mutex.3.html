NOM

gnutls_global_set_mutex - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_global_set_mutex(mutex_init_func init, mutex_deinit_func deinit, mutex_lock_func lock, mutex_unlock_func unlock);

ARGUMENTS

mutex_init_func init
fonction d'initialisation de mutex
mutex_deinit_func deinit
fonction de désinitialisation de mutex
mutex_lock_func lock
fonction de verrouillage de mutex
mutex_unlock_func unlock
fonction de déverrouillage de mutex

DESCRIPTION

Avec cette fonction, vous êtes autorisé à remplacer les verrous de mutex par défaut utilisés dans certaines parties de gnutls et des bibliothèques dépendantes. Cette fonction doit être utilisée si vous avez un contrôle complet de votre programme et de vos bibliothèques. Ne l'appelez pas depuis une bibliothèque, ou de préférence depuis une application sauf si c'est vraiment nécessaire. GnuTLS utilisera les verrous appropriés pour le système en cours d'exécution.

Cette fonction doit être appelée avant toute autre fonction GnuTLS ; sinon, le comportement est indéfini.

OBSOLÈTE

Cette fonction est déconseillée à partir de GnuTLS 3.7.3 ou version ultérieure.
