NOM

gnutls_encode_ber_digest_info - Fonction d'API

SYNTAXE

#include <gnutls/crypto.h>

int gnutls_encode_ber_digest_info(gnutls_digest_algorithm_t hash, const gnutls_datum_t * digest, gnutls_datum_t * output);

ARGUMENTS

gnutls_digest_algorithm_t hash
l'algorithme de hachage utilisé pour obtenir le digest
const gnutls_datum_t * digest
doit contenir les données du digest
gnutls_datum_t * output
conterra les données encodées en BER DigestInfo allouées

DESCRIPTION

Cette fonction encodera les données de digest fournies, ainsi que leur algorithme, dans une structure RSA PKCS1 1.5 DigestInfo.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur est retourné.
