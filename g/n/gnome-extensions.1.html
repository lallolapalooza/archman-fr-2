Nom

gnome-extensions - Outil en ligne de commande pour gérer les extensions GNOME

SYNOPSIS

gnome-extensions help [COMMANDE]
gnome-extensions version
gnome-extensions enable UUID
gnome-extensions disable UUID
gnome-extensions reset UUID
gnome-extensions info UUID
gnome-extensions show UUID
gnome-extensions list [OPTION...]
gnome-extensions prefs UUID
gnome-extensions create [OPTION...]
gnome-extensions pack [OPTION...]
gnome-extensions install [OPTION...] PAQUET
gnome-extensions uninstall UUID
gnome-extensions upload [OPTION...] PAQUET...

DESCRIPTION

gnome-extensions est un utilitaire qui rend disponibles en ligne de commande certaines opérations courantes sur les extensions GNOME.

OPTIONS COMMUNES

Toutes les commandes sauf help et version gèrent les options suivantes :

--quiet, -q

Ne pas afficher les messages d'erreur

COMMANDES

help [COMMANDE]

Affiche un bref synopsis des commandes disponibles ou fournit une aide détaillée sur une commande spécifique.

version

Affiche la version du programme.

enable UUID

Active l'extension identifiée par UUID.

La commande ne détectera pas les erreurs provenant de l'extension elle-même, utilisez la commande info pour confirmer que l'état de l'extension est ACTIVE.

Si l'extension est déjà activée, la commande ne fera rien.

disable UUID

Désactive l'extension identifiée par UUID.

Si l'extension n'est pas activée, la commande ne fera rien.

reset UUID

Réinitialise l'extension identifiée par UUID.

L'extension sera désactivée dans GNOME, mais pourra être activée par d'autres sessions comme GNOME Classic.

info UUID

Affiche les détails de l'extension identifiée par UUID, y compris le nom, la description et l'état.

show UUID

Synonyme de info.

list [OPTION...]

Affiche une liste des extensions installées.

Crée un paquet d'extension adapté à la publication. Le paquet inclura toujours les fichiers requis extension.js et metadata.json, ainsi que les fichiers optionnels stylesheet.css, stylesheet-dark.css, stylesheet-light.css ou prefs.js s'ils sont trouvés. Chaque source supplémentaire à inclure doit être spécifiée avec--extra-source

. Si l'extension inclut un ou plusieurs schémas GSettings, ils peuvent être placés dans un dossier schemas/ pour être détectés automatiquement, ou être spécifiés avec--schema

. De même, les traductions sont incluses automatiquement lorsqu'elles sont situées dans un dossier po/, sinon l'option --podir peut être utilisée pour indiquer le bon répertoire. Si aucun domaine gettext n'est fourni en ligne de commande, la valeur du champ de métadonnées gettext-domain

est utilisée si elle existe, et l'UUID de l'extension sinon. Tous les fichiers sont recherchés dans RÉPERTOIRE-SOURCE

s'il est spécifié, sinon dans le répertoire courant.
