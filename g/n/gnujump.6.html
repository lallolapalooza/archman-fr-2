NOM

GNUjump - un clone de xjump

SYNTAXE

sdljump [ REPLAY ] [ OPTIONS ]
sdljump [ --help ]

DESCRIPTION

GNUjump GNUjump fait partie du projet GNU.

GNUjump est un clone du jeu simple mais addictif Xjump, ajoutant de nouvelles fonctionnalités comme le multijoueur, un nombre illimité d'images par seconde, une chute de plateforme douce, des graphismes thématiques, etc...

Le but de ce jeu est de sauter sur la plateforme suivante pour ne pas tomber. Plus vous montez dans la Tour Descendante, plus les plateformes tomberont vite. Essayez de survivre plus longtemps que quiconque.

Pour que les parties multijoueurs durent plus longtemps, vous pouvez choisir d'avoir plus d'une vie, mais le résultat final sera divisé par le nombre de vies consommées.

OPTIONS

Si vous donnez un fichier de rejeu comme argument, le programme le lira et se quittera.

-w largeurecran, --width largeurecran
Force la largeur de l'écran à largeurecran unités.
-h hauteurcran, --heigth hauteurcran
Force la hauteur de l'écran à hauteurcran unités.
-b bitsparpixel, --bpp bitsparpixel
Définit la profondeur de bits de l'écran à bitsparpixel.
-f , --fullscreen
Force le mode plein écran.
-s , --software
Force le rendu logiciel.
-o , --opengl
Force le rendu OpenGL.
-a , --antialias
Force l'anticrénelage pour les sprites en rotation.
-n , --no-aa
Désactive l'anticrénelage pour les sprites en rotation.
-? , --help
Affiche l'écran d'aide.

MEILLEURS SCORES

L'onglet mode dans les Meilleurs Scores peut sembler étrange au premier abord, mais il est assez simple : il représente les options de Mode de Jeu définies lors de cette partie. Chaque lettre représente une option :

1ère Lettre : Le limiteur d'images par seconde

s : Par défaut GNUjump - Une limite arbitraire d'images par seconde. x : Xjump - 40 images par seconde, la valeur par défaut de xjump

2ème Lettre : La rotation du joueur

s : Par défaut GNUjump - rotation complète. x : Mode de rotation Xjump n : Pas de rotation

3ème Lettre : Le mode de défilement des plateformes.

s : Par défaut GNUjump - Doux x : Xjump - Dur
