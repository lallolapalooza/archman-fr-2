gnutls_x509_trust_list_remove_trust_mem(3) gnutls gnutls_x509_trust_list_remove_trust_mem(3)

NOM

gnutls_x509_trust_list_remove_trust_mem - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_trust_list_remove_trust_mem(gnutls_x509_trust_list_t list, const gnutls_datum_t * cas, gnutls_x509_crt_fmt_t type);

ARGUMENTS

gnutls_x509_trust_list_t list
La liste
const gnutls_datum_t * cas
Un tampon contenant une liste d'AC (optionnel)
gnutls_x509_crt_fmt_t type
Le format des certificats

DESCRIPTION

Cette fonction supprimera les autorités de certification fournies de la liste de confiance, et les ajoutera dans une liste de blocage si nécessaire.

Voir aussi gnutls_x509_trust_list_remove_cas().

RETOURNE

Le nombre d'éléments supprimés est retourné.
