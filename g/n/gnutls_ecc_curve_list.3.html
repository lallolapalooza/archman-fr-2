NOM

gnutls_ecc_curve_list - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

const gnutls_ecc_curve_t * gnutls_ecc_curve_list( void);

ARGUMENTS

void

DESCRIPTION

Obtenir la liste des courbes elliptiques prises en charge.

Cette fonction n'est pas thread-safe.

RETOURNE

Retourne une liste (terminée par 0) d'entiers gnutls_ecc_curve_t indiquant les courbes disponibles.
