NOM

gnutls_certificate_set_ocsp_status_request_file2 - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_ocsp_status_request_file2(gnutls_certificate_credentials_t sc, const char * response_file, unsigned idx, gnutls_x509_crt_fmt_t fmt);

ARGUMENTS

gnutls_certificate_credentials_t sc
est une structure de credentials.
const char * response_file
est le nom de fichier de la réponse OCSP
unsigned idx
est un index de certificat tel que retourné par gnutls_certificate_set_key() et ses similaires
gnutls_x509_crt_fmt_t fmt
est PEM ou DER

DESCRIPTION

Cette fonction charge les réponses OCSP à envoyer au pair pour la chaîne de certificats spécifiée par idx. Lorsque fmt est défini sur PEM, plusieurs réponses peuvent être chargées.

Cette fonction doit être appelée après la définition des certificats, et ne peut pas être utilisée pour les certificats fournis via un rappel (callback) ; c'est-à-dire lorsque gnutls_certificate_set_retrieve_function() est utilisé. Dans ce cas, envisagez d'utiliser gnutls_certificate_set_retrieve_function3().

Cette fonction peut être appelée plusieurs fois lorsque plusieurs réponses applicables à la chaîne de certificats sont disponibles. Si la réponse fournie ne correspond à aucun certificat présent dans la chaîne, le code GNUTLS_E_OCSP_MISMATCH_WITH_CERTS est retourné. Si la réponse est déjà expirée au moment du chargement, le code GNUTLS_E_EXPIRED est retourné.

RETOUR

En cas de succès, le nombre de réponses chargées est retourné, sinon un code d'erreur négatif.
