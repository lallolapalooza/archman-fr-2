gnutls_x509_crt_privkey_sign(3) gnutls gnutls_x509_crt_privkey_sign(3)

NOM

gnutls_x509_crt_privkey_sign - Fonction d'API

SYNOPSIS

#include <gnutls/abstract.h>

int gnutls_x509_crt_privkey_sign(gnutls_x509_crt_t crt, gnutls_x509_crt_t issuer, gnutls_privkey_t issuer_key, gnutls_digest_algorithm_t dig, unsigned int flags);

ARGUMENTS

gnutls_x509_crt_t crt
un certificat de type gnutls_x509_crt_t
gnutls_x509_crt_t issuer
est le certificat de l'émetteur du certificat
gnutls_privkey_t issuer_key
contient la clé privée de l'émetteur
gnutls_digest_algorithm_t dig
Le digest du message à utiliser, GNUTLS_DIG_SHA256 est un choix sûr
unsigned int flags
doit être 0

DESCRIPTION

Cette fonction va signer le certificat avec la clé privée de l'émetteur, et copiera les informations de l'émetteur dans le certificat.

Ce doit être la dernière étape de la génération d'un certificat car tous les paramètres définis précédemment sont maintenant signés.

Une limitation connue de cette fonction est qu'un certificat nouvellement signé ne sera pas entièrement fonctionnel (par exemple, pour la vérification de la signature) tant qu'il n'aura pas été exporté puis ré-importé.

Après GnuTLS 3.6.1, la valeur de dig peut être GNUTLS_DIG_UNKNOWN, et dans ce cas, un algorithme approprié et raisonnable pour l'algorithme de clé sera sélectionné.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
