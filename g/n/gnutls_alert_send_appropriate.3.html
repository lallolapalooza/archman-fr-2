NOM

gnutls_alert_send_appropriate - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_alert_send_appropriate(gnutls_session_t session, int err);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
int err
est un code d'erreur renvoyé par une autre fonction GnuTLS

DESCRIPTION

Envoie une alerte au pair en fonction du code d'erreur renvoyé par une fonction gnutls. Cette fonction appellera gnutls_error_to_alert() pour déterminer l'alerte appropriée à envoyer.

Cette fonction peut également renvoyer GNUTLS_E_AGAIN ou GNUTLS_E_INTERRUPTED.

Historiquement, cette fonction envoyait toujours une alerte au pair, même si err n'était pas approprié pour répondre avec une alerte (par exemple, GNUTLS_E_SUCCESS). Depuis la version 3.6.6, cette fonction renvoie un succès sans transmettre de données pour les codes d'erreur qui ne devraient pas entraîner d'alerte.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon un code d'erreur est renvoyé.
