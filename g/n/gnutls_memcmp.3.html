NOM

gnutls_memcmp - Fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_memcmp(const void * s1, const void * s2, size_t n);

ARGUMENTS

const void * s1
la première adresse à comparer
const void * s2
la deuxième adresse à comparer
size_t n
la taille de la mémoire à comparer

DESCRIPTION

Cette fonction fonctionne de manière similaire à memcmp(), mais le temps d'opération ne dépend que de la taille de la chaîne. C'est-à-dire qu'elle ne retournera pas prématurément si les chaînes ne correspondent pas dès le premier octet.

RETOURNE

une valeur non nulle en cas de différence et zéro si les tampons sont identiques.
