NOM

gnutls_certificate_type_get - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

gnutls_certificate_type_t gnutls_certificate_type_get(gnutls_session_t session);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.

DESCRIPTION

Cette fonction retourne le type de certificat qui est négocié pour cette partie afin d'être envoyé au pair. Le type de certificat est X.509 par défaut, sauf si un type de certificat alternatif est activé par gnutls_init() et négocié pendant la session.

Les sessions reprises retourneront le type de certificat qui a été négocié et utilisé dans la session d'origine.

Depuis la version 3.6.4, il est recommandé d'utiliser gnutls_certificate_type_get2(), qui est plus précis.

RETOURNE

le type de certificat gnutls_certificate_type_t actuellement utilisé, tel que négocié pour le côté 'notre' de la connexion.
