gnutls_pkcs12_simple_parse(3) gnutls gnutls_pkcs12_simple_parse(3)

NOM

gnutls_pkcs12_simple_parse - Fonction d'API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_simple_parse(gnutls_pkcs12_t p12, const char * password, gnutls_x509_privkey_t * key, gnutls_x509_crt_t ** chain, unsigned int * chain_len, gnutls_x509_crt_t ** extra_certs, unsigned int * extra_certs_len, gnutls_x509_crl_t * crl, unsigned int flags);

ARGUMENTS

gnutls_pkcs12_t p12
Un type pkcs12
const char * password
mot de passe optionnel utilisé pour déchiffrer la structure, les sacs et les clés.
gnutls_x509_privkey_t * key
une structure pour stocker la clé privée analysée.
gnutls_x509_crt_t ** chain
la chaîne de certificats correspondant à la clé (peut être NULL)
unsigned int * chain_len
sera mis à jour avec le nombre de certificats supplémentaires (peut être NULL)
gnutls_x509_crt_t ** extra_certs
pointeur optionnel pour recevoir un tableau de certificats supplémentaires trouvés dans la structure PKCS12 (peut être NULL).
unsigned int * extra_certs_len
sera mis à jour avec le nombre de certificats supplémentaires (peut être NULL).
gnutls_x509_crl_t * crl
une structure optionnelle pour stocker la CRL analysée (peut être NULL).
unsigned int flags
devrait être zéro ou l'un des GNUTLS_PKCS12_SP_*

DESCRIPTION

Cette fonction analyse une structure PKCS12 dans pkcs12 et extrait la clé privée, la chaîne de certificats correspondante, les certificats supplémentaires et une CRL. Les structures dans key , chain crl et extra_certs ne doivent pas être initialisées.

Les paramètres extra_certs et extra_certs_len sont optionnels et peuvent tous deux être définis à NULL. Si l'un d'eux est non-NULL, alors les deux doivent être définis. La valeur pour extra_certs est allouée en utilisant gnutls_malloc().

Les sacs PKCS12 chiffrés et les clés privées PKCS8 sont pris en charge, mais uniquement avec une sécurité basée sur un mot de passe et le même mot de passe pour toutes les opérations.

Notez qu'une structure PKCS12 peut contenir de nombreuses clés et/ou certificats, et qu'il n'y a aucun moyen d'identifier la paire clé/certificat souhaitée. Pour cette raison, cette fonction est utile pour les fichiers PKCS12 qui ne contiennent qu'une seule paire clé/certificat et/ou une seule CRL.

Si la structure fournie contient des champs chiffrés mais qu'aucun mot de passe n'est fourni, cette fonction renvoie GNUTLS_E_DECRYPTION_FAILED.

Notez que normalement la chaîne construite n'inclut pas les certificats auto-signés, pour se conformer aux exigences de TLS. Si, cependant, le drapeau GNUTLS_PKCS12_SP_INCLUDE_SELF_SIGNED est spécifié, alors les certificats auto-signés seront inclus dans la chaîne.

Avant d'utiliser cette fonction, l'intégrité de la structure PKCS 12 doit être vérifiée à l'aide de gnutls_pkcs12_verify_mac().

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon une valeur d'erreur négative.
