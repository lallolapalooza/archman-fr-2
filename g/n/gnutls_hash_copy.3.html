NOM

gnutls_hash_copy - Fonction d'API

SYNTAXE

#include <gnutls/crypto.h>

gnutls_hash_hd_t gnutls_hash_copy(gnutls_hash_hd_t handle);

ARGUMENTS

gnutls_hash_hd_t handle
est un type gnutls_hash_hd_t

DESCRIPTION

Cette fonction créera une copie du contexte de résumé de message, contenant tout son état actuel. La copie de contextes pour les résumés de message enregistrés à l'aide de gnutls_crypto_register_digest() n'est pas prise en charge et aboutira toujours à une erreur. En outre, certaines implémentations de résumé de message ne prennent pas en charge cette opération. Les applications doivent vérifier la valeur de retour et fournir une solution de remplacement appropriée.

RETOURNE

un nouveau contexte de résumé de message ou NULL en cas d'erreur.
