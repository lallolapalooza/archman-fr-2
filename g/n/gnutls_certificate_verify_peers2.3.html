NOM

gnutls_certificate_verify_peers2 - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_verify_peers2(gnutls_session_t session, unsigned int * status);

ARGUMENTS

gnutls_session_t session
est une session gnutls
unsigned int * status
est le résultat de la vérification

DESCRIPTION

Cette fonction vérifiera le certificat du pair et stockera le statut dans la variable status comme un OU bit à bit de valeurs gnutls_certificate_status_t ou zéro si le certificat est fiable. Notez que la valeur de status n'est définie que lorsque la valeur de retour de cette fonction est succès (c'est-à-dire qu'un échec de fiabilité d'un certificat n'implique pas une valeur de retour négative). Les drapeaux de vérification par défaut utilisés par cette fonction peuvent être remplacés en utilisant gnutls_certificate_set_verify_flags().

Cette fonction prendra en compte les réponses OCSP greffées (stapled) envoyées par le serveur, ainsi que les extensions de certificat X.509 suivantes : contraintes de nom (Name Constraints), usage de clé (Key Usage) et contraintes de base (Basic Constraints) (longueur de chemin).

Notez que vous devez également vérifier le nom du pair afin de vérifier si le certificat vérifié appartient au pair réel, voir gnutls_x509_crt_check_hostname(), ou utiliser gnutls_certificate_verify_peers3().

Pour éviter les attaques par déni de service, certaines limites supérieures par défaut concernant la taille de la clé et la taille de la chaîne du certificat sont définies. Pour les remplacer, utilisez gnutls_certificate_set_verify_limits().

Notez que lors de l'utilisation de clés publiques brutes, la vérification ne fonctionnera pas car il n'y a pas de corps de certificat correspondant à la clé brute qui puisse être vérifié. Dans ce cas, cette fonction retournera GNUTLS_E_INVALID_REQUEST.

RETOURNE

GNUTLS_E_SUCCESS (0) lorsque la validation est effectuée, ou un code d'erreur négatif sinon. Un code d'erreur de succès signifie que le paramètre status doit être vérifié pour obtenir le statut de validation.
