NOM

gnutls_certificate_get_ours - Fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

const gnutls_datum_t * gnutls_certificate_get_ours(gnutls_session_t session);

ARGUMENTS

gnutls_session_t session
est une session gnutls

DESCRIPTION

Obtient le certificat tel qu'envoyé au pair lors de la dernière négociation. Le certificat est au format brut (DER). Aucune liste de certificats n'est retournée. Seul le premier certificat est retourné.

Cette fonction retourne le certificat qui a été envoyé dans la négociation actuelle. Dans les sessions de reprise ultérieures, cette fonction retournera NULL. Cela diffère de gnutls_certificate_get_peers() qui retourne toujours le certificat du pair utilisé lors de la session d'origine.

RETOURNE

Un pointeur vers une gnutls_datum_t contenant notre certificat, ou NULL en cas d'erreur ou si aucun certificat n'a été utilisé.
