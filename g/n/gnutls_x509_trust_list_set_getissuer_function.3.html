gnutls_x509_trust_list_set_getissuer_function(3) gnutls gnutls_x509_trust_list_set_getissuer_function(3)

NOM

gnutls_x509_trust_list_set_getissuer_function - Fonction d'API

SYNOPSIS

#include <gnutls/x509.h>

void gnutls_x509_trust_list_set_getissuer_function(gnutls_x509_trust_list_t tlist, gnutls_x509_trust_list_getissuer_function * func);

ARGUMENTS

gnutls_x509_trust_list_t tlist
est un type gnutls_x509_trust_list_t.
gnutls_x509_trust_list_getissuer_function * func
est la fonction de rappel

DESCRIPTION

Cette fonction définit un rappel à appeler lorsque la chaîne de certificats du pair est incomplète en raison d'un certificat intermédiaire manquant. Le rappel peut fournir le certificat manquant à utiliser pendant la vérification.

Le prototype de la fonction de rappel est défini dans gnutls/x509.h comme suit :

int (*callback)(gnutls_x509_trust_list_t list, const gnutls_x509_crt_t cert, gnutls_x509_crt_t **issuers, unsigned int *issuers_size);

Si la fonction de rappel est fournie, gnutls l'appellera pendant la procédure de vérification du certificat. Le rappel peut souhaiter utiliser gnutls_x509_crt_get_authority_info_access() pour obtenir une URI à partir de laquelle tenter de télécharger le certificat d'émetteur manquant, si disponible.

En cas d'appel réussi, le rappel doit définir '*issuers' et '*issuers_size', même si le résultat est vide ; dans ce cas, '*issuers' pointera vers NULL et sera alloué à l'aide de gnutls_x509_crt_list_import2(). La propriété du tableau et des éléments est transférée à l'appelant et, par conséquent, l'application n'a pas besoin de maintenir la mémoire après l'appel.

La fonction de rappel doit renvoyer 0 si la tentative de récupération des certificats d'émetteur pour 'crt' a réussi, ou une valeur non nulle pour indiquer qu'une erreur s'est produite pendant la tentative. Dans ce dernier cas, '*issuers' et '*issuers_size' ne sont pas définis.
