NOM

gnutls_x509_crq_get_subject_alt_othername_oid - fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_get_subject_alt_othername_oid(gnutls_x509_crq_t crq, unsigned int seq, void * ret, size_t * ret_size);

ARGUMENTS

gnutls_x509_crq_t crq
devrait contenir un type gnutls_x509_crq_t
unsigned int seq
spécifie le numéro de séquence du nom alternatif (0 pour le premier, 1 pour le second, etc.)
void * ret
est l'emplacement où l'OID otherName sera copié.
size_t * ret_size
contient la taille de ret.

DESCRIPTION

Cette fonction extraira l'OID de type d'un nom alternatif de sujet otherName, contenu dans le certificat donné, et retournera le type sous forme d'élément énuméré.

Cette fonction n'est utile que si gnutls_x509_crq_get_subject_alt_name() a retourné GNUTLS_SAN_OTHERNAME.

RETOURNE

le type de nom alternatif du sujet en cas de succès, l'un des enumerated gnutls_x509_subject_alt_name_t. Pour les OIDs supportés, il retournera l'un des types virtuels (GNUTLS_SAN_OTHERNAME_*), par ex. GNUTLS_SAN_OTHERNAME_XMPP, et GNUTLS_SAN_OTHERNAME pour les OIDs inconnus. Il retournera GNUTLS_E_SHORT_MEMORY_BUFFER si
ret_size n'est pas assez grand pour contenir la valeur. Dans ce cas
ret_size sera mis à jour avec la taille requise. Si le certificat n'a pas de nom alternatif avec le numéro de séquence spécifié et avec le type otherName, alors GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est retourné.
