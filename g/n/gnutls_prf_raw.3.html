NOM

gnutls_prf_raw - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_prf_raw(gnutls_session_t session, size_t label_size, const char * label, size_t seed_size, const char * seed, size_t outsize, char * out);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
size_t label_size
taille de la variable label.
const char * label
étiquette utilisée dans le calcul PRF, généralement une courte chaîne.
size_t seed_size
taille de la variable seed.
const char * seed
données supplémentaires optionnelles pour initialiser le PRF.
size_t outsize
taille du tampon de sortie pré-alloué pour contenir la sortie.
char * out
tampon pré-alloué pour contenir les données générées.

DESCRIPTION

Applique la fonction pseudo-aléatoire TLS (PRF) sur le secret maître et les données fournies.

La variable label contient généralement une chaîne indiquant le but des données générées. Le seed contient généralement des données telles que le aléatoire du client et du serveur, peut-être avec des données supplémentaires ajoutées pour garantir l'unicité de la sortie pour un but particulier.

Étant donné que la sortie n'est pas garantie d'être unique pour une session particulière, sauf si seed inclut les champs aléatoires du client et du serveur (le PRF produirait les mêmes données lors d'une autre connexion reprise de la première), il n'est pas recommandé d'utiliser cette fonction directement. La fonction gnutls_prf() initialise le PRF directement avec les champs aléatoires du client et du serveur, et est recommandée si vous souhaitez générer des données pseudo-aléatoires uniques pour chaque session.

NOTE

Cette fonction ne fonctionnera que pour les versions de TLS antérieures à la version 1.3. En TLS1.3, l'utilisation du PRF est remplacée par HKDF et les exportateurs génériques comme gnutls_prf_rfc5705() doivent être utilisés à la place. Sous TLS1.3, cette fonction renvoie GNUTLS_E_INVALID_REQUEST.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.
