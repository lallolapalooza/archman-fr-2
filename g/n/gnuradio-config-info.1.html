GNURADIO-CONFIG-INFO(1) Commandes utilisateur GNURADIO-CONFIG-INFO(1)

NOM

gnuradio-config-info - afficher les détails sur GNU radio installé

DESCRIPTION

Options du programme : gnuradio [options] :

-h [ --help ]
afficher le message d'aide
--prefix
afficher le préfixe d'installation de gnuradio
--sysconfdir
afficher le répertoire de configuration système de gnuradio
--prefsdir
afficher le répertoire des préférences de gnuradio
--builddate
afficher la date de construction de gnuradio (format RFC2822)
-v [ --version ]
afficher la version de gnuradio

VOIR AUSSI

La documentation complète de GNU Radio est au format HTML. Si le paquet gnuradio-doc est correctement installé sur votre site,

/usr/share/doc/gnuradio-doc/html/

devrait vous donner accès au manuel complet.
