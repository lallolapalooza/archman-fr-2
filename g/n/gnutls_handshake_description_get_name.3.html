NOM

gnutls_handshake_description_get_name - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

const char * gnutls_handshake_description_get_name(gnutls_handshake_description_t type);

ARGUMENTS

gnutls_handshake_description_t type
est une description de message de négociation (handshake)

DESCRIPTION

Convertit une valeur gnutls_handshake_description_t en une chaîne de caractères.

RETOUR

une chaîne contenant le nom du message de négociation spécifié ou NULL.
