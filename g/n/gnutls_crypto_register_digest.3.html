NOM

gnutls_crypto_register_digest - Fonction d'API

SYNOPSIS

#include <gnutls/crypto.h>

int gnutls_crypto_register_digest(gnutls_digest_algorithm_t algorithm, int priority, gnutls_digest_init_func init, gnutls_digest_hash_func hash, gnutls_digest_output_func output, gnutls_digest_deinit_func deinit, gnutls_digest_fast_func hash_fast);

ARGUMENTS

gnutls_digest_algorithm_t algorithm
est l'identifiant de résumé gnutls
int priority
est la priorité de l'algorithme
gnutls_digest_init_func init
Une fonction qui initialise le résumé
gnutls_digest_hash_func hash
Effectue l'opération de hachage
gnutls_digest_output_func output
Fournit la sortie du résumé
gnutls_digest_deinit_func deinit
Une fonction qui désinitialise le résumé
gnutls_digest_fast_func hash_fast
Effectue l'opération de résumé en une seule fois

DESCRIPTION

Cette fonction enregistrera un algorithme de résumé à utiliser par gnutls. Tout algorithme enregistré remplacera les algorithmes inclus et, par convention, les algorithmes implémentés par le noyau ont une priorité de 90 et ceux assistés par CPU une priorité de 80. L'algorithme avec la priorité la plus basse sera utilisé par gnutls.

OBSOLÈTE

depuis la version 3.7.0, il n'est plus possible de remplacer l'implémentation des chiffrements

RETOURNE

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
