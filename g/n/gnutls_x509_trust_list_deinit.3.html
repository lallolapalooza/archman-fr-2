NOM

gnutls_x509_trust_list_deinit - fonction d'API

SYNTAXE

#include <gnutls/x509.h>

void gnutls_x509_trust_list_deinit(gnutls_x509_trust_list_t list, unsigned int all);

ARGUMENTS

gnutls_x509_trust_list_t list
La liste à désinitialiser
unsigned int all
si non nul, cela désinitialisera tous les certificats et CRL contenus dans la structure.

DESCRIPTION

Cette fonction désinitialisera une liste de confiance. Notez que
le drapeau all devrait généralement être non nul à moins que vous n'ayez spécifié vos certificats en utilisant gnutls_x509_trust_list_add_cas() et que vous vouliez empêcher qu'ils soient désinitialisés par cette fonction.
