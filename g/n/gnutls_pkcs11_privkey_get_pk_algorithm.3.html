NOM

gnutls_pkcs11_privkey_get_pk_algorithm - Fonction API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_privkey_get_pk_algorithm(gnutls_pkcs11_privkey_t clé, unsigned int * bits);

ARGUMENTS

gnutls_pkcs11_privkey_t clé
doit contenir un type gnutls_pkcs11_privkey_t
unsigned int * bits
si bits n'est pas nul, il contiendra la taille des paramètres en bits

DESCRIPTION

Cette fonction retournera l'algorithme de clé publique d'une clé privée.

RETOURNE

un membre de l'énumération gnutls_pk_algorithm_t en cas de succès, ou un code d'erreur négatif en cas d'erreur.
