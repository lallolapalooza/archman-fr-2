NOM

gnutls_mac_get_key_size - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

size_t gnutls_mac_get_key_size(gnutls_mac_algorithm_t algorithm);

ARGUMENTS

gnutls_mac_algorithm_t algorithm
est un algorithme de chiffrement

DESCRIPTION

Retourne la taille de la clé MAC utilisée dans TLS.

VALEUR

longueur (en octets) de la taille de clé MAC donnée, ou 0 si l'algorithme MAC donné est invalide.
