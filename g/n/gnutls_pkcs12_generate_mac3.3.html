NOM

gnutls_pkcs12_generate_mac3 - Fonction d'API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_generate_mac3(gnutls_pkcs12_t pkcs12, gnutls_mac_algorithm_t mac, const char * pass, unsigned int flags);

ARGUMENTS

gnutls_pkcs12_t pkcs12
Un type pkcs12
gnutls_mac_algorithm_t mac
l'algorithme MAC à utiliser
const char * pass
Le mot de passe pour le MAC
unsigned int flags
une séquence OR de gnutls_pkcs12_flags_t

DESCRIPTION

Cette fonction générera un MAC pour la structure PKCS12.

Si flags contient GNUTLS_PKCS12_USE_PBMAC1, elle utilise la fonction de dérivation de clé PBMAC1 au lieu de celle de PKCS12.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
