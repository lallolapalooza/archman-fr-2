NAME

gnutls_pkcs12_bag_set_friendly_name - Fonction de l'API

SYNOPSIS

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_bag_set_friendly_name(gnutls_pkcs12_bag_t bag, unsigned indx, const char * name);

ARGUMENTS

gnutls_pkcs12_bag_t bag
Le sac
unsigned indx
L'élément du sac auquel ajouter l'identifiant
const char * name
Le nom

DESCRIPTION

Cette fonction ajoutera le nom convivial de clé donné à l'élément spécifié, par son index, dans le sac. Le nom sera codé sous forme d'attribut de sac 'Friendly name', qui est généralement utilisé pour définir un nom d'utilisateur pour la paire clé privée locale et certificat.

RETURNS

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative. ou un code d'erreur négatif en cas d'erreur.
