NOM

gnome-dictionary - Rechercher des mots dans des dictionnaires en ligne

SYNTAXE

gnome-dictionary [[--look-up MOT] | [--match MOT]] [--source NOM] [--database NOM] [--strategy NOM] [--help]

DESCRIPTION

gnome-dictionary recherche des mots dans des dictionnaires en ligne en utilisant le protocole DICT.

OPTIONS

--look-up MOT

Recherche le MOT spécifié en utilisant la source du dictionnaire par défaut, ou celle spécifiée avec l'option de ligne de commande --source.

--match MOT

Liste toutes les entrées dans la source du dictionnaire qui correspondent au MOT spécifié.

--source=NOM, -s NOM

Spécifie la source du dictionnaire à utiliser pour la recherche ou la correspondance de mots.

--database=NOM, -D NOM

Spécifie la base de données dans la source du dictionnaire à utiliser pour la recherche ou la correspondance de mots.

--strategy=NOM, -S NOM

Spécifie la stratégie de correspondance dans la source du dictionnaire à utiliser pour la recherche ou la correspondance de mots.
