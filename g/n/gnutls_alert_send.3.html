NOM

gnutls_alert_send - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_alert_send(gnutls_session_t session, gnutls_alert_level_t level, gnutls_alert_description_t desc);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
gnutls_alert_level_t level
est le niveau de l'alerte
gnutls_alert_description_t desc
est la description de l'alerte

DESCRIPTION

Cette fonction enverra une alerte au pair pour l'informer de quelque chose d'important (par exemple, son certificat n'a pas pu être vérifié). Si le niveau de l'alerte est Fatal, le pair est censé fermer la connexion, sinon il peut ignorer l'alerte et continuer.

Le code d'erreur de la fonction d'envoi d'enregistrement sous-jacente sera retourné, vous pouvez donc également recevoir GNUTLS_E_INTERRUPTED ou GNUTLS_E_AGAIN.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur est retourné.
