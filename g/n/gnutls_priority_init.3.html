NOM

gnutls_priority_init - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_priority_init(gnutls_priority_t * priority_cache, const char * priorities, const char ** err_pos);

ARGUMENTS

gnutls_priority_t * priority_cache
est un type gnutls_priority_t.
const char * priorities
est une chaîne décrivant les priorités (peut être NULL)
const char ** err_pos
En cas d'erreur, contiendra la position dans la chaîne où l'erreur s'est produite

DESCRIPTION

Pour les applications qui ne modifient pas leurs paramètres cryptographiques par version, envisagez d'utiliser gnutls_priority_init2() avec le drapeau GNUTLS_PRIORITY_INIT_DEF_APPEND à la place. Nous suggérons d'utiliser des paramètres cryptographiques centralisés gérés par la bibliothèque GnuTLS, et les applications modifiant les paramètres par défaut selon leurs besoins.

Cette fonction est identique à gnutls_priority_init2() avec des drapeaux nuls.

Une chaîne priorities NULL indique les priorités par défaut à utiliser (ceci est disponible depuis GnuTLS 3.3.0).

RETOURNE

En cas d'erreur de syntaxe, retourne GNUTLS_E_INVALID_REQUEST, GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.
