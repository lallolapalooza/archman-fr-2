NOM

gnutls_certificate_set_x509_key_file - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_key_file(gnutls_certificate_credentials_t res, const char * certfile, const char * keyfile, gnutls_x509_crt_fmt_t type);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
const char * certfile
est un fichier contenant la liste des certificats (chemin) pour la clé privée spécifiée, au format PKCS7, ou une liste de certificats
const char * keyfile
est un fichier contenant la clé privée
gnutls_x509_crt_fmt_t type
est PEM ou DER

DESCRIPTION

Cette fonction définit une paire certificat/clé privée dans le type gnutls_certificate_credentials_t. Cette fonction peut être appelée plusieurs fois, dans le cas où plusieurs clés/certificats existent pour le serveur. Pour les clients qui doivent envoyer plus que leur certificat d'entité finale, par exemple, un certificat d'autorité intermédiaire, alors le
certfile doit contenir la chaîne de certificats ordonnée.

Notez que les noms dans le certificat fourni seront pris en compte lors de la sélection du certificat approprié à utiliser (en cas de multiples paires certificat/clé).

Cette fonction peut également accepter des URL pour keyfile et certfile. Dans ce cas, elle utilisera la clé privée et le certificat indiqués par les URL. Notez que les URL prises en charge sont celles indiquées par gnutls_url_is_supported().

Si le certfile est fourni comme une URL PKCS 11, alors le certificat, et ses émetteurs présents sur le jeton, sont importés (c'est-à-dire, formant la chaîne de confiance requise).

Si cette fonction échoue à charger la structure res, celle-ci est dans un état indéfini et ne doit pas être réutilisée pour charger d'autres clés ou certificats.

Notez que, par défaut, cette fonction renvoie zéro en cas de succès et une valeur négative en cas d'erreur. Depuis la version 3.5.6, lorsque le drapeau GNUTLS_CERTIFICATE_API_V2 est défini à l'aide de gnutls_certificate_set_flags(), elle renvoie un index (supérieur ou égal à zéro). Cet index peut être utilisé par d'autres fonctions pour faire référence à la paire clé ajoutée.

RETOURNE

En cas de succès, cette fonction retourne zéro, sinon une valeur négative en cas d'erreur (voir ci-dessus pour modifier ce comportement).
