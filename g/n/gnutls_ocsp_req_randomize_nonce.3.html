NOM

gnutls_ocsp_req_randomize_nonce - Fonction de l'API

SYNOPIS

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_randomize_nonce(gnutls_ocsp_req_t req);

ARGUMENTS

gnutls_ocsp_req_t req
devrait contenir un type gnutls_ocsp_req_t

DESCRIPTION

Cette fonction ajoutera ou mettra à jour une extension nonce dans la requête OCSP avec une nouvelle valeur aléatoire générée.

VALEUR DE RETOUR

En cas de succès, renvoie GNUTLS_E_SUCCESS (0), sinon renvoie un code d'erreur négatif.
