NOM

gnutls_ocsp_req_get_nonce - fonction d'API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_get_nonce(gnutls_ocsp_req_const_t req, unsigned int * critical, gnutls_datum_t * nonce);

ARGUMENTS

gnutls_ocsp_req_const_t req
doit contenir un type gnutls_ocsp_req_t
unsigned int * critical
indique si l'extension nonce est marquée comme critique, ou NULL
gnutls_datum_t * nonce
conindra un nouveau tampon alloué avec les données nonce

DESCRIPTION

Cette fonction retournera les données de l'extension nonce de la requête OCSP.

L'appelant doit libérer la mémoire en appelant gnutls_free() sur
nonce ->data.

VALEUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné.
