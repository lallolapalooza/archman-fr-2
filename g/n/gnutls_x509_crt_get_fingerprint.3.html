NOM

gnutls_x509_crt_get_fingerprint - fonction de l'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_fingerprint(gnutls_x509_crt_t cert, gnutls_digest_algorithm_t algo, void * buf, size_t * buf_size);

ARGUMENTS

gnutls_x509_crt_t cert
devrait contenir un type gnutls_x509_crt_t
gnutls_digest_algorithm_t algo
est un algorithme de hachage
void * buf
un pointeur vers une structure pour contenir l'empreinte digitale (peut être null)
size_t * buf_size
contient initialement la taille de buf

DESCRIPTION

Cette fonction calculera et copiera l'empreinte digitale du certificat dans le tampon fourni. L'empreinte digitale est un hachage des données du certificat encodées en DER.

Si le tampon est null, seule la taille sera remplie.

RETOUR

GNUTLS_E_SHORT_MEMORY_BUFFER si le tampon fourni n'est pas assez long, et dans ce cas *buf_size sera mis à jour avec la taille requise. En cas de succès, 0 est retourné.
