NOM

gnutls_sign_algorithm_get - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_sign_algorithm_get(gnutls_session_t session);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.

DESCRIPTION

Retourne l'algorithme de signature qui est (ou sera) utilisé dans cette session par le serveur pour signer des données. Cette fonction ne doit être utilisée qu'avec TLS 1.2 ou une version ultérieure.

RETOUR

L'algorithme de signature ou GNUTLS_SIGN_UNKNOWN.
