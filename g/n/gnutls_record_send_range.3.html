NOM

gnutls_record_send_range - Fonction de l'API

SYNOPSIS

#include <gnutls/gnutls.h>

ssize_t gnutls_record_send_range(gnutls_session_t session, const void * data, size_t data_size, const gnutls_range_st * range);

ARGUMENTS

gnutls_session_t session
est de type gnutls_session_t.
const void * data
contient les données à envoyer.
size_t data_size
est la longueur des données.
const gnutls_range_st * range
est la plage de longueurs dans laquelle la longueur réelle des données doit être cachée.

DESCRIPTION

Cette fonction fonctionne comme gnutls_record_send() mais, alors que gnutls_record_send() ajoute un rembourrage minimal à chaque enregistrement TLS, cette fonction utilise la fonctionnalité de rembourrage supplémentaire TLS pour dissimuler la taille réelle des données dans la plage de longueurs fournie. Certaines sessions TLS ne prennent pas en charge le rembourrage supplémentaire (par exemple, les chiffrements de flux dans TLS standard ou les sessions SSL3). Pour savoir si la session actuelle prend en charge le rembourrage supplémentaire, et donc le masquage de la longueur, utilisez la fonction gnutls_record_can_use_length_hiding().

NOTE

Cette fonction est actuellement limitée aux sockets bloquants.

RETOUR

Le nombre d'octets envoyés (c'est-à-dire data_size dans une invocation réussie), ou un code d'erreur négatif.
