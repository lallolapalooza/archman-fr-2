NOM

gnutls_x509_aki_set_cert_issuer - Fonction API

SYNTAXE

#include <gnutls/x509-ext.h>

int gnutls_x509_aki_set_cert_issuer(gnutls_x509_aki_t aki, unsigned int san_type, const gnutls_datum_t * san, const char * othername_oid, const gnutls_datum_t * serial);

ARGUMENTS

gnutls_x509_aki_t aki
L'identifiant de la clé d'autorité
unsigned int san_type
le type du nom (de gnutls_subject_alt_names_t), peut être nul
const gnutls_datum_t * san
Les données du nom alternatif
const char * othername_oid
L'identificateur d'objet si san_type est GNUTLS_SAN_OTHERNAME
const gnutls_datum_t * serial
Le numéro authorityCertSerialNumber (peut être nul)

DESCRIPTION

Cette fonction définira le nom authorityCertIssuer et le numéro authorityCertSerialNumber à stocker dans le type aki. Lors du stockage de plusieurs noms, le numéro de série doit être défini lors du premier appel, et les appels suivants doivent utiliser un numéro de série NULL.

Depuis la version 3.5.7, GNUTLS_SAN_RFC822NAME, GNUTLS_SAN_DNSNAME et GNUTLS_SAN_OTHERNAME_XMPP sont convertis en format ACE lorsque nécessaire.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
