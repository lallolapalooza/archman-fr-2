NOM

gnutls_pkcs12_bag_set_crt - fonction d'API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_bag_set_crt(gnutls_pkcs12_bag_t bag, gnutls_x509_crt_t crt);

ARGUMENTS

gnutls_pkcs12_bag_t bag
Le sac
gnutls_x509_crt_t crt
le certificat à copier.

DESCRIPTION

Cette fonction insérera le certificat donné dans le sac. Ce n'est qu'un wrapper pour gnutls_pkcs12_bag_set_data().

VALEUR DE RETOUR

l'index du sac ajouté en cas de succès, ou une valeur négative en cas d'échec.
