NOM

gnutls_pkcs12_bag_decrypt - Fonction d'API

SYNOPSIS

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_bag_decrypt(gnutls_pkcs12_bag_t bag, const char * pass);

ARGUMENTS

gnutls_pkcs12_bag_t bag
Le sac
const char * pass
Le mot de passe utilisé pour le chiffrement, doit être en ASCII.

DESCRIPTION

Cette fonction déchiffrera le sac chiffré donné et retournera 0 en cas de succès.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné.
