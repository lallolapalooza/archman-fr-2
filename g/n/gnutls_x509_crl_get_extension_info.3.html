NOM

gnutls_x509_crl_get_extension_info - Fonction API

SYNOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crl_get_extension_info(gnutls_x509_crl_t crl, unsigned indx, void * oid, size_t * sizeof_oid, unsigned int * critical);

ARGUMENTS

gnutls_x509_crl_t crl
doit contenir un type gnutls_x509_crl_t
unsigned indx
Spécifie quel OID d'extension envoyer, utilisez (0) pour obtenir le premier.
void * oid
un pointeur pour stocker l'OID
size_t * sizeof_oid
contient initialement la taille maximale de oid , à la sortie contient la taille réelle de oid .
unsigned int * critical
variable de sortie avec le drapeau critique, peut être NULL.

DESCRIPTION

Cette fonction retournera l'OID d'extension demandé dans la CRL, et le drapeau critique associé. L'OID d'extension sera stocké sous forme de chaîne dans le tampon fourni. Utilisez gnutls_x509_crl_get_extension_data() pour extraire les données.

Si le tampon fourni n'est pas assez long pour contenir la sortie, alors * sizeof_oid est mis à jour et GNUTLS_E_SHORT_MEMORY_BUFFER sera retourné.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif en cas de problème. Si vous avez atteint la dernière extension disponible, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
