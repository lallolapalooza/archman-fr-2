NOM

gnutls_x509_policies_init - Fonction API

SYNTAXE

#include <gnutls/x509-ext.h>

int gnutls_x509_policies_init(gnutls_x509_policies_t * policies);

ARGUMENTS

gnutls_x509_policies_t * policies
L'identifiant de l'autorité

DESCRIPTION

Cette fonction initialisera un type d'identifiant d'autorité.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
