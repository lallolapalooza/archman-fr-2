NOM

gnutls_priority_cipher_list - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_priority_cipher_list(gnutls_priority_t pcache, const unsigned int ** list);

ARGUMENTS

gnutls_priority_t pcache
est un type gnutls_priority_t.
const unsigned int ** list
pointera vers une liste d'entiers.

DESCRIPTION

Obtenir une liste des chiffrements disponibles dans la structure de priorité.

VALEUR

le nombre d'éléments, ou un code d'erreur.
