NOM

gnutls_prf_rfc5705 - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_prf_rfc5705(gnutls_session_t session, size_t label_size, const char * label, size_t context_size, const char * context, size_t outsize, char * out);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
size_t label_size
longueur de la variable label.
const char * label
label utilisé dans le calcul du PRF, généralement une courte chaîne de caractères.
size_t context_size
longueur de la variable extra.
const char * context
données supplémentaires optionnelles pour initialiser le PRF.
size_t outsize
taille du tampon de sortie pré-alloué pour contenir le résultat.
char * out
tampon pré-alloué pour contenir les données générées.

DESCRIPTION

Exporte des clés à partir d'une session TLS/DTLS vers une application, conformément à la RFC5705.

Dans les versions de TLS antérieures à la 1.3, elle applique la fonction Pseudo-Aléatoire (PRF) de TLS sur le secret maître et les données fournies, initialisée avec les champs aléatoires du client et du serveur.

En TLS 1.3, elle applique HKDF sur le secret maître exportateur dérivé du secret maître.

La variable label contient généralement une chaîne dénotant le but des données générées.

La variable context peut être utilisée pour ajouter plus de données à l'initialisation, après les variables aléatoires. Elle peut être utilisée pour s'assurer que le résultat généré est fortement lié à des données supplémentaires (par exemple, une chaîne utilisée dans l'authentification de l'utilisateur).

Le résultat est placé dans out, qui doit être pré-alloué.

Notez que, pour fournir le contexte RFC5705, la variable context doit être non nulle.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.
