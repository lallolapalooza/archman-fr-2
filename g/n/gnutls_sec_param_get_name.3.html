NOM

gnutls_sec_param_get_name - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

const char * gnutls_sec_param_get_name(gnutls_sec_param_t param);

ARGUMENTS

gnutls_sec_param_t param
est un paramètre de sécurité

DESCRIPTION

Convertit une valeur gnutls_sec_param_t en chaîne de caractères.

RETOURNE

Un pointeur vers une chaîne contenant le nom du niveau de sécurité spécifié, ou NULL.
