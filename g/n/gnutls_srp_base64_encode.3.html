NOM

gnutls_srp_base64_encode - Fonction de l'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_srp_base64_encode(const gnutls_datum_t * data, char * result, size_t * result_size);

ARGUMENTS

const gnutls_datum_t * data
contient les données brutes
char * result
l'emplacement où les données base64 seront copiées
size_t * result_size
contient la taille du résultat

DESCRIPTION

Cette fonction convertira les données fournies en données imprimables, en utilisant l'encodage base64, tel qu'utilisé dans libsrp. C'est l'encodage utilisé dans les fichiers de mots de passe SRP. Si le tampon fourni n'est pas assez long, GNUTLS_E_SHORT_MEMORY_BUFFER est retourné.

Attention ! Cet encodage base64 n'est pas l'encodage « standard », ne l'utilisez donc pas à des fins non-SRP.

RETOURNE

GNUTLS_E_SHORT_MEMORY_BUFFER si le tampon fourni n'est pas assez long, ou 0 en cas de succès.
