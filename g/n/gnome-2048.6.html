NOM

GNOME 2048 - Obtenir la tuile la plus haute

SYNTAXE

gnome-2048 [OPTION...]

DESCRIPTION

2048 est un jeu solo très addictif. Le gameplay consiste à joindre des nombres dans une grille pour obtenir des valeurs plus importantes.

Utilisez les touches fléchées de votre clavier ou les gestes pour faire glisser toutes les tuiles dans la direction souhaitée. Attention : toutes les tuiles glissent vers leurs positions les plus éloignées possibles, vous ne pouvez pas faire glisser une seule tuile ou une seule ligne ou colonne. Les tuiles de même valeur sont jointes lorsqu'elles glissent l'une sur l'autre. Après votre tour, une nouvelle tuile est ajoutée au jeu.

Gnome 2048 n'ajoute que des tuiles de valeur 2, contrairement au jeu 2048 original. De plus, il vous permet de jouer sur des grilles de différentes tailles.

OPTIONS

--cli=<commande>
Jouer dans le terminal. Voir “--cli=help” pour la documentation.
-t, --taille=<taille>
Change la taille de la grille. La taille doit être comprise entre 2 et 9, ou sous la forme 2x3.
-v, --version
Affiche la version du programme et quitte.

Ce programme accepte également les options standard de GTK+.
