NOM

gnutls_handshake_set_private_extensions - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_handshake_set_private_extensions(gnutls_session_t session, int allow);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
int allow
est un entier (0 ou 1)

DESCRIPTION

Cette fonction activera ou désactivera l'utilisation des suites de chiffrement privées (celles qui commencent par 0xFF). Par défaut, ou si allow est 0, ces suites de chiffrement ne seront ni annoncées ni utilisées.

Actuellement, GnuTLS n'inclut pas de telles suites de chiffrement ou algorithmes de compression.

L'activation des suites de chiffrement privées lors de la communication avec des serveurs et clients autres que GnuTLS peut entraîner des problèmes d'interopérabilité.
