NOM

gnutls_pcert_import_x509_list - Fonction API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_pcert_import_x509_list(gnutls_pcert_st * pcert_list, gnutls_x509_crt_t * crt, unsigned * ncrt, unsigned int flags);

ARGUMENTS

gnutls_pcert_st * pcert_list
Les structures pour stocker les certificats ; ne doit pas contenir de structures gnutls_pcert_st initialisées.
gnutls_x509_crt_t * crt
Les certificats à importer.
unsigned * ncrt
Le nombre de certificats dans crt ; sera mis à jour si nécessaire.
unsigned int flags
zéro ou GNUTLS_X509_CRT_LIST_SORT

DESCRIPTION

Cette fonction pratique importera les certificats donnés dans un ensemble déjà alloué de structures gnutls_pcert_st. Les structures doivent être désinitialisées par la suite en utilisant gnutls_pcert_deinit(). pcert_list doit contenir de l'espace pour au moins ncrt éléments.

Si GNUTLS_X509_CRT_LIST_SORT est spécifié et que la fonction ne peut pas trier la liste, GNUTLS_E_CERTIFICATE_LIST_UNSORTED sera retourné. Actuellement, le tri peut échouer si la taille de la liste dépasse une contrainte interne (16).

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
