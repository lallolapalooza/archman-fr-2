NOM

gnome-disk-image-mounter - Attacher et monter des images disque

SYNTAXE

gnome-disk-image-mounter [--writable] [URI...]

DESCRIPTION

gnome-disk-image-mounter peut être utilisé pour configurer des images disque. Les fichiers réguliers ainsi que les URI GVfs (tels que smb://filer/media/file.iso) peuvent être utilisés dans le paramètre URI. Si aucun URI n'est donné et qu'un serveur graphique est en cours d'exécution, un sélecteur de fichiers graphique sera présenté.

Notez que gnome-disk-image-mounter ne montera pas les systèmes de fichiers et ne déverrouillera pas les volumes chiffrés dans l'image disque - cette responsabilité est laissée à l'automonteur dans GNOME Shell afin de garantir que les mêmes interactions se produisent que si l'image disque était un périphérique physique ou un disque régulier.

Par défaut, les images disque sont attachées en lecture seule, utilisez l'option --writable pour changer cela.

VALEUR DE RETOUR

gnome-disk-image-mounter retourne 0 en cas de succès et une valeur non nulle en cas d'échec.

AUTEUR
