NOM

gnutls_x509_ext_import_inhibit_anypolicy - Fonction d'API

SYNOPSIS

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_inhibit_anypolicy(const gnutls_datum_t * ext, unsigned int * skipcerts);

ARGUMENTS

const gnutls_datum_t * ext
les données de l'extension codées en DER
unsigned int * skipcerts
contiendra le nombre de certificats après lesquels anypolicy n'est plus acceptable.

DESCRIPTION

Cette fonction retournera la valeur SkipCerts du certificat, en lisant les données DER de l'extension X.509 Inhibit anyPolicy (2.5.29.54).

La valeur skipcerts est le nombre de certificats supplémentaires qui peuvent apparaître dans le chemin avant que anyPolicy (GNUTLS_X509_OID_POLICY_ANY) ne soit plus acceptable.

RETOURNE

zéro, ou un code d'erreur négatif en cas de problème d'analyse. Si le certificat ne contient pas l'extension Inhibit anyPolicy, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
