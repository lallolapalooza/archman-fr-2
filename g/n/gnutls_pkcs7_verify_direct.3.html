gnutls_pkcs7_verify_direct(3) gnutls gnutls_pkcs7_verify_direct(3)

NOM

gnutls_pkcs7_verify_direct - fonction API

SYNTAXE

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_verify_direct(gnutls_pkcs7_t pkcs7, gnutls_x509_crt_t signer, unsigned idx, const gnutls_datum_t * data, unsigned flags);

ARGUMENTS

gnutls_pkcs7_t pkcs7
doit contenir un type gnutls_pkcs7_t
gnutls_x509_crt_t signer
le certificat censé avoir signé la structure
unsigned idx
l'index de l'information de signature à vérifier
const gnutls_datum_t * data
Les données à vérifier ou NULL
unsigned flags
Zéro ou une liste OR de gnutls_certificate_verify_flags

DESCRIPTION

Cette fonction vérifiera les données fournies par rapport à la signature présente dans les SignedData de la structure PKCS 7. Si les données fournies sont nulles, les données du champ encapsulatedContent seront utilisées à la place.

Notez que, contrairement à gnutls_pkcs7_verify(), cette fonction ne vérifie pas le but de la clé du signataire. Il est attendu que l'appelant vérifie le but prévu du signer - par exemple, via gnutls_x509_crt_get_key_purpose_oid(), ou gnutls_x509_crt_check_key_purpose().

Notez également que, depuis GnuTLS 3.5.6, cette fonction introduit des vérifications sur le certificat final ( signer ), y compris les vérifications de temps et de l'utilisation de la clé.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative. Une erreur de vérification résulte en GNUTLS_E_PK_SIG_VERIFY_FAILED et l'absence de données encapsulées à vérifier en GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
