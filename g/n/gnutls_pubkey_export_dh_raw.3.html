NOM

gnutls_pubkey_export_dh_raw - Fonction API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_pubkey_export_dh_raw(gnutls_pubkey_t key, gnutls_dh_params_t params, gnutls_datum_t * y, unsigned flags);

ARGUMENTS

gnutls_pubkey_t key
Contient la clé publique
gnutls_dh_params_t params
conviendra au paramètre Diffie-Hellman (facultatif), doit être initialisé
gnutls_datum_t * y
conviendra à y
unsigned flags
indicateurs de gnutls_abstract_export_flags_t

DESCRIPTION

Cette fonction exportera le paramètre de clé publique Diffie-Hellman trouvé dans la clé publique donnée. Le nouveau paramètre sera alloué à l'aide de gnutls_malloc() et sera stocké dans la donnée appropriée.

Pour récupérer d'autres paramètres communs aux clés publique et privée, utilisez gnutls_dh_params_export_raw().

Cette fonction autorise les paramètres NULL depuis la version 3.4.1.

RETOURNE

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif.
