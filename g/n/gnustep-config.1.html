NOM

gnustep-config - affiche des informations sur l'installation actuelle de gnustep.

SYNTAXE

gnustep-config [ --variable=variable |--objc-flags|--objc-libs|--base-libs|--gui-libs ]

DESCRIPTION

gnustep-config peut afficher des informations sur le système GNUstep installé actuellement. La sortie est générée dynamiquement en fonction des variables d'environnement telles que GNUSTEP_CONFIG_FILE et GNUSTEP_MAKEFILES, bien que des valeurs par défaut pour celles-ci soient générées lors de la configuration/installation de l'outil. La sortie concerne principalement les emplacements où diverses ressources GNUstep sont installées, mais fournit également les drapeaux utilisés pour compiler différents types de projets GNUstep.

OPTIONS

--variable=variable
affiche la valeur de la variable spécifiée. Les variables possibles sont :

GNUSTEP_MAKEFILES

GNUSTEP_USER_DIR

GNUSTEP_USER_DEFAULTS_DIR

GNUSTEP_HOST

GNUSTEP_HOST_CPU

GNUSTEP_HOST_VENDOR

GNUSTEP_HOST_OS

GNUSTEP_IS_FLATTENED

GNUSTEP_xxx_APPS

GNUSTEP_xxx_TOOLS

GNUSTEP_xxx_LIBRARY

GNUSTEP_xxx_HEADERS

GNUSTEP_xxx_LIBRARIES

GNUSTEP_xxx_DOC

GNUSTEP_xxx_DOC_MAN

GNUSTEP_xxx_DOC_INFO

où 'xxx' peut être l'un des termes suivants : 'SYSTEM', 'NETWORK', 'LOCAL' et 'USER'.
--objc-flags
affiche tous les drapeaux requis pour compiler un fichier ObjC.
--objc-libs

affiche tous les drapeaux requis pour lier un programme ObjC pur (sans fondation/gui).
--base-libs
affiche tous les drapeaux requis pour lier un programme ObjC en ligne de commande (sans gui).
--gui-libs
affiche tous les drapeaux requis pour lier un programme ObjC avec interface graphique.
