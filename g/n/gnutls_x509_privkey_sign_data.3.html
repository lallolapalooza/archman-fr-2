gnutls_x509_privkey_sign_data(3)

Paquet: gnutls

Licences: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_privkey_sign_data(3) gnutls gnutls_x509_privkey_sign_data(3)

NOM

gnutls_x509_privkey_sign_data - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_privkey_sign_data(gnutls_x509_privkey_t clé, gnutls_digest_algorithm_t digest, unsigned int flags, const gnutls_datum_t * data, void * signature, size_t * signature_size);

ARGUMENTS

gnutls_x509_privkey_t clé
une clé
gnutls_digest_algorithm_t digest
doit être un algorithme de hachage
unsigned int flags
doit être 0 pour l'instant
const gnutls_datum_t * data
contient les données à signer
void * signature
conviendra la signature
size_t * signature_size
contient la taille de la signature (et sera remplacée par la nouvelle taille)

DESCRIPTION

Cette fonction signera les données fournies en utilisant un algorithme de signature pris en charge par la clé privée. Les algorithmes de signature sont toujours utilisés conjointement avec des fonctions de hachage. Différentes fonctions de hachage peuvent être utilisées pour l'algorithme RSA, mais seulement SHA-1 pour les clés DSA.

Si le tampon fourni n'est pas assez long pour contenir la sortie, alors * signature_size sera mis à jour et GNUTLS_E_SHORT_MEMORY_BUFFER sera retourné.

Utilisez gnutls_x509_crt_get_preferred_hash_algorithm() pour déterminer l'algorithme de hachage.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
