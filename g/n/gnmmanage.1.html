NOM

gnmmanage - Gère les réseaux

SYNTAXE

Usage: gnmmanage [--help][--help-general][-q][-quiet][--long-usage]
                 [info]
                 [create [-f <format_name>] [-t_srs <srs_name>] [-dsco <NAME>=<VALUE>]... ]
                 [import <src_dataset_name>] [-l <layer_name>]
                 [connect <gfid_src> <gfid_tgt> <gfid_con> [-c <cost>] [-ic <inv_cost>] [-dir <dir>]]
                 [disconnect <gfid_src> <gfid_tgt> <gfid_con>]
                 [rule <rule_str>]
                 [autoconnect <tolerance>]
                 [delete]
                 [change [-bl <gfid>][-unbl <gfid>][-unblall]]
                 <gnm_name> [<layer> [<layer>]...]

DESCRIPTION

Le programme gnmmanage peut effectuer diverses opérations de gestion sur les réseaux géographiques dans GDAL. En plus de créer et supprimer des réseaux, il inclut des fonctionnalités pour gérer les entités, la topologie et les règles des réseaux.

--help
Affiche ce message d'aide et quitte.
--help-general
Fournit un bref message d'utilisation pour les options générales de la ligne de commande GDAL et quitte.
-info
Diverses informations sur le réseau : couches système et de classes, métadonnées du réseau, système de référence spatial du réseau.
create
Crée un réseau.
-f <format_name>
Nom du format de fichier de sortie.
-t_srs <srs_name>
Système de référence spatial d'entrée.
-dsco <NAME>=<VALUE>
Option de création de réseau définie comme paire nom=valeur.
import <src_dataset_name>
Importe une couche avec le nom du jeu de données à copier.
-l <layer_name>
Nom de la couche dans le jeu de données. Si non spécifié, la couche 0 est copiée.
connect <gfid_src> <gfid_tgt> <gfid_con>
Établit une connexion topologique, où gfid_src et gfid_tgt sont des sommets et gfid_con est une arête (gfid_con peut être -1, auquel cas l'arête système sera insérée).

Attribue manuellement les valeurs suivantes :

-c <cost>
Coût / poids
-ic <invcost>
Coût inverse
-dir <dir>
Direction de l'arête.
disconnect <gfid_src> <gfid_tgt> <gfid_con>
Supprime la connexion du graphe.
rule <rule_str>
Crée une règle dans le réseau par la chaîne rule_str donnée.
autoconnect <tolerance>
Crée la topologie automatiquement avec la tolérance double et les noms de couches donnés. Si aucun nom de couche n'est fourni, toutes les couches du réseau seront utilisées.
delete
Supprime le réseau.
change
Change l'état de blocage des arêtes ou des sommets du réseau.
-bl <gfid>
Bloque une entité avant l'opération principale. Les entités bloquées sont enregistrées dans une couche spéciale.
-unbl <gfid>
Débloque une entité avant l'opération principale.
-unblall
Débloque toutes les entités bloquées avant l'opération principale.
<gnm_name>
Le réseau avec lequel travailler (chemin et nom).
<layer>
Le nom de la couche du réseau.
