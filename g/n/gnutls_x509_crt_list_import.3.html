NOM

gnutls_x509_crt_list_import - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_list_import(gnutls_x509_crt_t * certs, unsigned int * cert_max, const gnutls_datum_t * data, gnutls_x509_crt_fmt_t format, unsigned int flags);

ARGUMENTS

gnutls_x509_crt_t * certs
Indique où la liste analysée sera copiée. Ne doit pas être initialisé.
unsigned int * cert_max
Doit initialement contenir le nombre maximum de certificats. Sera mis à jour avec le nombre de certificats disponibles.
const gnutls_datum_t * data
Le certificat encodé au format PEM.
gnutls_x509_crt_fmt_t format
Soit DER, soit PEM.
unsigned int flags
doit être (0) ou une séquence OR de gnutls_certificate_import_flags.

DESCRIPTION

Cette fonction convertira la liste de certificats encodés au format PEM fournie au format natif gnutls_x509_crt_t. La sortie sera stockée dans certs. Ils seront automatiquement initialisés.

Le drapeau GNUTLS_X509_CRT_LIST_IMPORT_FAIL_IF_EXCEED provoquera l'échec de l'importation si les certificats dans le tampon fourni sont plus nombreux que les structures disponibles. Le drapeau GNUTLS_X509_CRT_LIST_FAIL_IF_UNSORTED fera échouer la fonction si la liste fournie n'est pas triée du sujet à l'émetteur.

Si le certificat est encodé en PEM, il devrait avoir un en-tête de "X509 CERTIFICATE", ou "CERTIFICATE".

RETOUR

Le nombre de certificats lus ou une valeur d'erreur négative.
