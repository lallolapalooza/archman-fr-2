NOM

gnustep-tests - script pour exécuter une suite de tests GNUstep

SYNTAXE

gnustep-tests [ répertoire | test.m ]

DESCRIPTION

gnustep-tests exécute les tests spécifiés, ou tout test trouvé dans le répertoire. Si aucun argument n'est donné, le répertoire courant et ses sous-répertoires sont analysés et traités en conséquence.

OPTIONS

--documentation
affiche des détails complets sur le framework de test
--clean
supprime les anciens journaux et les fichiers résiduels
--failfast
s'arrête après la première erreur de test rencontrée
--debug
exécute les tests échoués dans gdb(1)
--developer
traite tous les espoirs comme de vrais tests
--verbose
journalisation détaillée
--sequential
désactive la compilation parallèle
