GNOME-COMMANDER(1) Manuel des commandes générales GNOME-COMMANDER(1)

NOM

gnome-commander - un gestionnaire de fichiers GNOME

SYNOPSIS

gnome-commander [-d STRING] [options] [options gtk,gnome,bonobo]

DESCRIPTION

GNOME Commander est un gestionnaire de fichiers graphique rapide et puissant pour l'environnement de bureau GNOME, il possède une interface "à deux panneaux" dans la tradition de Norton et Midnight Commander.

OPTIONS

--help
Affiche un résumé des options.
--version
Affiche la version du programme.
-l, --start-left-dir=CHAINE
Spécifie le répertoire de départ pour le panneau de gauche.
-r, --start-right-dir=CHAINE
Spécifie le répertoire de départ pour le panneau de droite.
  --config-dir=CHAINE
Spécifie le répertoire pour les fichiers de configuration.
-d, --debug=CHAINE
Spécifie les indicateurs de débogage à utiliser. La sortie de débogage sera écrite dans STDOUT.
Indicateurs possibles :
a : active tous les indicateurs de débogage
c : comptage de fichiers et de répertoires
d : comptage de références de répertoires
f : comptage de références de fichiers
g : débogage de run_command
i : imageloader
k : pool de répertoires
l : listes de répertoires
m : débogage de connexion
n : surveillance des répertoires
p : surveillance des scripts
s : navigateur réseau SMB
t : balises de métadonnées
u : débogage des actions utilisateur
v : visionneuse interne
w : widget_lookup
x : xfer
y : chargement d'image bref basé sur MIME
z : chargement d'image détaillé basé sur MIME
[options gtk,gnome,bonobo]
Les options standard gtk, gnome, bonobo sont prises en charge. Utilisez --help pour voir les options possibles.

EXEMPLES

gnome-commander -d nvl
Démarre GNOME Commander avec le débogage des listes de répertoires, du visualiseur interne et des fonctions de surveillance de répertoires.

DOSSIERS

~/.config/gnome-commander/scripts
Scripts spécifiques à l'utilisateur, utilisés dans le menu contextuel des fichiers.
/usr/lib/gnome-commander/plugins
Plugins à l'échelle du système.

BOGUES

Si vous trouvez des bogues, veuillez les signaler (ou mieux encore, les corriger et envoyer un patch). Consultez la page d'accueil de GNOME Commander pour plus d'informations :
https://gcmd.github.io/

AUTEUR

GNOME Commander a été initialement développé par Marcus Bjurman de 2001 à 2004. Assaf Gordon a ajouté le code du visualiseur interne et d'autres fonctionnalités. Piotr Eljasiak a été le chef de projet de 2006 jusqu'en 2012. Depuis 2013 jusqu'à maintenant, Uwe Scholz <u.scholz83@gmx.de> est le chef de projet actuel.
Des traductions et d'autres contributions ont été faites par de nombreuses personnes. Voir
https://gitlab.gnome.org/GNOME/gnome-commander/-/graphs/master

La page de manuel originale a été écrite par Michael Vogt <mvo@debian.org>, pour le système Debian GNU/Linux. La page de manuel actuelle est maintenue dans le cadre du projet GNOME Commander.
