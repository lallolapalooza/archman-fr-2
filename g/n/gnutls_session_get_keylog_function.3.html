NOM

gnutls_session_get_keylog_function - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

gnutls_keylog_func gnutls_session_get_keylog_function(const gnutls_session_t session);

ARGUMENTS

const gnutls_session_t session
est de type gnutls_session_t

DESCRIPTION

Cette fonction retourne la fonction de rappel définie à l'aide de gnutls_session_set_keylog_function().

VALEUR DE RETOUR

La fonction définie ou NULL sinon.
