NOM

gnutls_certificate_free_credentials - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_certificate_free_credentials(gnutls_certificate_credentials_t sc);

ARGUMENTS

gnutls_certificate_credentials_t sc
est un type gnutls_certificate_credentials_t.

DESCRIPTION

Libère une structure gnutls_certificate_credentials_t.

Cette fonction ne libère aucun paramètre temporaire associé à cette structure (par exemple, les paramètres RSA et DH ne sont pas libérés par cette fonction).
