NOM

gnutls_x509_crt_get_ca_status - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_ca_status(gnutls_x509_crt_t cert, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
unsigned int * critical
sera non nul si l'extension est marquée comme critique

DESCRIPTION

Cette fonction renverra le statut d'autorité de certification (CA) du certificat, en lisant l'extension X.509 basicConstraints (2.5.29.19). Si le certificat est une CA, une valeur positive sera renvoyée, ou (0) si le certificat n'a pas le drapeau CA défini.

Utilisez gnutls_x509_crt_get_basic_constraints() si vous voulez également lire le champ pathLenConstraint.

RETOURNE

Si le certificat est une CA, une valeur positive sera renvoyée, ou (0) si le certificat n'a pas le drapeau CA défini. Un code d'erreur négatif peut être renvoyé en cas d'erreurs. Si le certificat ne contient pas l'extension basicConstraints, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera renvoyé.
