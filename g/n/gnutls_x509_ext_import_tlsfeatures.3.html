NOM

gnutls_x509_ext_import_tlsfeatures - Fonction API

SYNTAXE

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_tlsfeatures(const gnutls_datum_t * ext, gnutls_x509_tlsfeatures_t f, unsigned int flags);

ARGUMENTS

const gnutls_datum_t * ext
Les données de l'extension encodées en DER
gnutls_x509_tlsfeatures_t f
La structure des fonctionnalités
unsigned int flags
zéro ou GNUTLS_EXT_FLAG_APPEND

DESCRIPTION

Cette fonction exportera les fonctionnalités de l'extension PKIX TLS Features fournie, encodée en DER, vers un type gnutls_x509_tlsfeatures_t. f doit être initialisé.

Lorsque le paramètre flags est défini sur GNUTLS_EXT_FLAG_APPEND, si la structure features est vide, cette fonction se comportera de manière identique comme si le drapeau n'était pas défini. Sinon, si des éléments sont présents dans la structure features, ils seront fusionnés.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
