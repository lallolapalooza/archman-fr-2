NOM

Tetravex - Un jeu de puzzle simple pour GNOME

SYNTAXE

gnome-tetravex [OPTION...]

DESCRIPTION

GNOME Tetravex est un puzzle simple où les pièces doivent être positionnées de manière à ce que les mêmes nombres se touchent. Votre partie est chronométrée, ces temps sont stockés dans un tableau de scores système.

OPTIONS

--cli=COMMANDE
Jouer dans le terminal (voir “--cli=help”)
-c, --couleurs=NOMBRE
Définir le nombre de couleurs (2-10)
-p, --pause
Démarrer le jeu en pause
-r, --restaurer
Restaurer la dernière partie, le cas échéant
-s, --taille=TAILLE
Définir la taille du plateau (2-6)
-v, --version
Afficher la version du logiciel et quitter

Ce programme accepte également les options standard GNOME et GTK.
