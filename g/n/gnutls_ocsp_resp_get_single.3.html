NOM

gnutls_ocsp_resp_get_single - fonction API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_get_single(gnutls_ocsp_resp_const_t resp, unsigned indx, gnutls_digest_algorithm_t * digest, gnutls_datum_t * issuer_name_hash, gnutls_datum_t * issuer_key_hash, gnutls_datum_t * serial_number, unsigned int * cert_status, time_t * this_update, time_t * next_update, time_t * revocation_time, unsigned int * revocation_reason);

ARGUMENTS

gnutls_ocsp_resp_const_t resp
doit contenir un type gnutls_ocsp_resp_t
unsigned indx
Spécifie le numéro de réponse à obtenir. Utiliser (0) pour obtenir la première.
gnutls_digest_algorithm_t * digest
variable de sortie avec l'algorithme de hachage gnutls_digest_algorithm_t
gnutls_datum_t * issuer_name_hash
tampon de sortie avec le hachage du nom distinctif de l'émetteur
gnutls_datum_t * issuer_key_hash
tampon de sortie avec le hachage de la clé publique de l'émetteur
gnutls_datum_t * serial_number
tampon de sortie avec le numéro de série du certificat à vérifier
unsigned int * cert_status
un statut de certificat, une énumération gnutls_ocsp_cert_status_t.
time_t * this_update
heure à laquelle le statut est connu pour être correct.
time_t * next_update
quand des informations plus récentes seront disponibles, ou (time_t)-1 si non spécifié
time_t * revocation_time
quand cert_status est GNUTLS_OCSP_CERT_REVOKED, contient l'heure de révocation.
unsigned int * revocation_reason
raison de révocation, une énumération gnutls_x509_crl_reason_t.

DESCRIPTION

Cette fonction renverra les informations du certificat de la
réponse indexée par indx dans la réponse OCSP de base resp. Les informations renvoyées correspondent à la structure OCSP SingleResponse, à l'exception des singleExtensions finales.

Chacun des pointeurs vers les variables de sortie peut être NUL pour indiquer que l'appelant n'est pas intéressé par cette valeur.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon un code d'erreur négatif est renvoyé. Si vous avez atteint le dernier CertID disponible, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera renvoyé.
