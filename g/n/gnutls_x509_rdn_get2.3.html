NOM

gnutls_x509_rdn_get2 - fonction API

SYNOPSIS

#include <gnutls/x509.h>

int gnutls_x509_rdn_get2(const gnutls_datum_t * idn, gnutls_datum_t * str, unsigned flags);

ARGUMENTS

const gnutls_datum_t * idn
doit contenir une séquence RDN encodée en DER
gnutls_datum_t * str
une donnée qui contiendra le nom
unsigned flags
zéro ou GNUTLS_X509_DN_FLAG_COMPAT

DESCRIPTION

Cette fonction retournera le nom de la séquence RDN donnée. Le nom sera sous la forme "C=xxxx,O=yyyy,CN=zzzz" comme décrit dans RFC4514.

Lorsque le drapeau GNUTLS_X509_DN_FLAG_COMPAT est spécifié, le format de sortie correspondra au format de sortie des versions de GnuTLS antérieures à la 3.5.6, qui n'était pas entièrement conforme à RFC4514.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, ou GNUTLS_E_SHORT_MEMORY_BUFFER est retourné et * buf_size est mis à jour si le tampon fourni n'est pas assez long, sinon une valeur d'erreur négative.
