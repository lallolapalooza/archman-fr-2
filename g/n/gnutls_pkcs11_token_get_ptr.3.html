NOM

gnutls_pkcs11_token_get_ptr - Fonction d'API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_token_get_ptr(const char * url, void ** ptr, unsigned long * slot_id, unsigned int flags);

ARGUMENTS

const char * url
doit contenir une URL PKCS11 identifiant un jeton
void ** ptr
conindra le pointeur CK_FUNCTION_LIST_PTR
unsigned long * slot_id
conindra l'identifiant du slot (peut être NULL)
unsigned int flags
doit être zéro

DESCRIPTION

Cette fonction retournera le pointeur de fonction du jeton spécifié par l'URL. Les pointeurs retournés sont valides jusqu'à la désinitialisation de gnutls, cf. _global_deinit().

VALEUR

GNUTLS_E_SUCCESS (0) en cas de succès ou un code d'erreur négatif en cas d'erreur.
