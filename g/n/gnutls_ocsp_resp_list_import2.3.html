NOM

gnutls_ocsp_resp_list_import2 - Fonction de l'API

SYNOPSIS

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_list_import2(gnutls_ocsp_resp_t ** ocsps, unsigned int * size, const gnutls_datum_t * resp_data, gnutls_x509_crt_fmt_t format, unsigned int flags);

ARGUMENTS

gnutls_ocsp_resp_t ** ocsps
Contiendra la liste des réponses OCSP analysées.
unsigned int * size
Contiendra la taille de la liste.
const gnutls_datum_t * resp_data
La liste des réponses OCSP codées en PEM.
gnutls_x509_crt_fmt_t format
Soit GNUTLS_X509_FMT_PEM soit GNUTLS_X509_FMT_DER
unsigned int flags
doit être (0) ou une séquence OR d'indicateurs de gnutls_certificate_import_flags.

DESCRIPTION

Cette fonction convertira la liste des réponses OCSP codées en PEM fournie dans le format natif gnutls_ocsp_resp_t. La sortie sera stockée dans ocsps qui sera alloué et initialisé.

Les réponses OCSP doivent avoir un en-tête "OCSP RESPONSE".

Pour désinitialiser les réponses, vous devez désinitialiser chaque structure gnutls_ocsp_resp_t indépendamment et utiliser gnutls_free() sur ocsps.

Dans les fichiers PEM, lorsqu'aucune réponse OCSP n'est détectée, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera renvoyé.

RETOUR

Le nombre de réponses lues ou une valeur d'erreur négative.
