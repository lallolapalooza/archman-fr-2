NOM

gnutls_pkcs11_reinit - fonction d'API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_reinit( void);

ARGUMENTS

void

DESCRIPTION

Cette fonction réinitialise le sous-système PKCS 11 dans gnutls. Ceci est requis par PKCS 11 lorsqu'une application utilise fork(). La fonction de réinitialisation doit être appelée sur l'enfant.

Notez que depuis GnuTLS 3.3.0, la réinitialisation du sous-système PKCS 11 se fait automatiquement après un fork.

VALEUR DE RETOUR

En cas de succès, retourne GNUTLS_E_SUCCESS (0), sinon une valeur d'erreur négative.
