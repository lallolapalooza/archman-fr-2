NOM

gnutls_x509_ext_import_crl_dist_points - Fonction API

SYNOPSIS

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_crl_dist_points(const gnutls_datum_t * ext, gnutls_x509_crl_dist_points_t cdp, unsigned int flags);

ARGUMENTS

const gnutls_datum_t * ext
les données d'extension codées en DER
gnutls_x509_crl_dist_points_t cdp
Un pointeur vers des points de distribution CRL initialisés.
unsigned int flags
doit être zéro

DESCRIPTION

Cette fonction extraira l'extension des points de distribution CRL (2.5.29.31) et la stockera dans le type fourni.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
