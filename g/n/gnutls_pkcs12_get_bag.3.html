NOM

gnutls_pkcs12_get_bag - Fonction API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_get_bag(gnutls_pkcs12_t pkcs12, int indx, gnutls_pkcs12_bag_t bag);

ARGUMENTS

gnutls_pkcs12_t pkcs12
Un type pkcs12
int indx
contient l'index du sac à extraire
gnutls_pkcs12_bag_t bag
Un sac initialisé, où le contenu du sac sera copié

DESCRIPTION

Cette fonction retournera un Sac de la structure PKCS12.

Une fois que le dernier Sac a été lu, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
