gnutls_x509_crt_check_revocation(3) gnutls gnutls_x509_crt_check_revocation(3)

NOM

gnutls_x509_crt_check_revocation - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_check_revocation(gnutls_x509_crt_t cert, const gnutls_x509_crl_t * crl_list, unsigned crl_list_length);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
const gnutls_x509_crl_t * crl_list
doit contenir une liste de types gnutls_x509_crl_t
unsigned crl_list_length
la longueur de la crl_list

DESCRIPTION

Cette fonction vérifie si le certificat donné est révoqué. Il est supposé que les CRL ont été vérifiés au préalable.

RETOURNE

0 si le certificat n'est PAS révoqué, et 1 s'il l'est. Un code d'erreur négatif est retourné en cas d'erreur.
