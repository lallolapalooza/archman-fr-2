NOM

gnutls_global_set_mem_functions - Fonction API

SYNTAXE

#include <gnutls/compat.h>

void gnutls_global_set_mem_functions(gnutls_alloc_function alloc_func, gnutls_alloc_function secure_alloc_func, gnutls_is_secure_function is_secure_func, gnutls_realloc_function realloc_func, gnutls_free_function free_func);

ARGUMENTS

gnutls_alloc_function alloc_func
c'est la fonction d'allocation mémoire par défaut. Comme malloc().
gnutls_alloc_function secure_alloc_func
Ceci est la fonction d'allocation mémoire qui sera utilisée pour les données sensibles.
gnutls_is_secure_function is_secure_func
une fonction qui renvoie 0 si la mémoire fournie n'est pas sécurisée. Peut être NULL.
gnutls_realloc_function realloc_func
Une fonction de réallocation
gnutls_free_function free_func
La fonction qui libère les données allouées. Doit accepter un pointeur NULL.

DÉPRÉCIÉ

depuis la version 3.3.0, il n'est plus possible de remplacer les fonctions d'allocation mémoire utilisées en interne.

C'est la fonction où vous définissez les fonctions d'allocation mémoire que gnutls va utiliser. Par défaut, les fonctions d'allocation de la libc (malloc(), free()) sont utilisées par gnutls pour allouer des données sensibles et non sensibles. Cette fonction est fournie pour définir les fonctions d'allocation mémoire sur autre chose que les valeurs par défaut.

Cette fonction doit être appelée avant que gnutls_global_init() ne soit appelée. Cette fonction n'est pas thread-safe.
