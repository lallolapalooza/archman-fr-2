NOM

gnutls_x509_crq_get_dn_oid - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_get_dn_oid(gnutls_x509_crq_t crq, unsigned indx, void * oid, size_t * sizeof_oid);

ARGUMENTS

gnutls_x509_crq_t crq
doit contenir un type gnutls_x509_crq_t
unsigned indx
Spécifie quel OID DN obtenir. Utilisez (0) pour obtenir le premier.
void * oid
un pointeur vers une structure pour contenir le nom (peut être NULL)
size_t * sizeof_oid
contient initialement la taille de oid

DESCRIPTION

Cette fonction extrait l'OID demandé du nom du sujet de la requête de certificat, spécifié par l'index donné.

RETOURNE

GNUTLS_E_SHORT_MEMORY_BUFFER si le tampon fourni n'est pas assez grand, et dans ce cas * sizeof_oid sera mis à jour avec la taille requise. En cas de succès, 0 est retourné.
