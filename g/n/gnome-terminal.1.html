GNOME-TERMINAL(1) Commandes utilisateur GNOME-TERMINAL(1)

NOM

gnome-terminal - Un émulateur de terminal pour GNOME

SYNTAXE

gnome-terminal [OPTION...] [-- PROGRAMME [ARG...]]

DESCRIPTION

gnome-terminal est une application émulateur de terminal pour accéder à un environnement shell UNIX qui peut être utilisé pour exécuter des programmes disponibles sur votre système. Il prend en charge plusieurs profils, plusieurs onglets et implémente plusieurs raccourcis clavier.

OPTIONS

--help, -h

Affiche un bref aperçu de toutes les options.

--help-all

Affiche toutes les options en détail.

--help-gtk

Affiche toutes les options GTK.

--help-terminal

Affiche toutes les options pour sélectionner entre de nouveaux onglets ou fenêtres de terminal.

--help-terminal-options

Affiche toutes les options pour modifier les attributs des terminaux, qu'ils soient dans des onglets ou des fenêtres séparés.

--help-window-options

Affiche toutes les options pour modifier les attributs des fenêtres contenant des terminaux.

--load-config=FICHIER

Restaure l'application à un état précédemment enregistré en chargeant à partir d'un fichier de configuration.

--preferences

Affiche la fenêtre des préférences.

--print-environment, -p

Affiche les variables d'environnement pour interagir avec les nouveaux terminaux créés.

--quiet, -q

Supprime les diagnostics.

--verbose, -v

Augmente la verbosité des diagnostics.

--tab

Ouvre un nouvel onglet contenant un terminal dans la dernière fenêtre ouverte avec le profil par défaut.

--window

Ouvre une nouvelle fenêtre avec un onglet contenant un terminal avec le profil par défaut.

--command, -e COMMANDE

Divise l'argument de cette option en un programme et des arguments de la même manière qu'un shell, et exécute la ligne de commande résultante dans le terminal.

Cette option est obsolète. Utilisez plutôt -- pour terminer les options, et placez le programme et les arguments à exécuter après : par exemple, au lieu de gnome-terminal -e "python3 -q", préférez utiliser gnome-terminal -- python3 -q.

Notez que la commande COMMANDE n'est pas exécutée via un shell : elle est divisée en mots et exécutée comme un programme. Si la syntaxe du shell est requise, utilisez la forme gnome-terminal -- sh -c '...'.

--execute PROGRAMME [ARGS], -x PROGRAMME [ARGS]

Arrête l'analyse des options à ce stade et interprète toutes les options suivantes comme un programme et ses arguments à exécuter dans le terminal.

Cette option est obsolète : utilisez plutôt --. Par exemple, au lieu de gnome-terminal -x python3 -q, préférez utiliser gnome-terminal -- python3 -q.

--fd=FD

Transmet le descripteur de fichier.

--profile=NOM-PROFIL

Utilise le profil donné au lieu du profil par défaut.

--title, -t TITRE

Définit le titre initial du terminal.

--wait

Attend que le processus enfant du terminal se termine.

--working-directory=DIRNAME

Définit le répertoire de travail du terminal.

--zoom=ZOOM

Définit le facteur de zoom du terminal. 1.0 est la taille normale.

--active

Définit le dernier onglet spécifié comme actif dans sa fenêtre.

--full-screen

Met la fenêtre en plein écran.

--geometry=GEOMETRIE

Définit la taille de la fenêtre sous la forme COLSxROWS+X+Y. Par exemple, 80x24 ou 80x24+200+200.

--hide-menubar

Désactive la barre de menu de la fenêtre.

--show-menubar

Active la barre de menu de la fenêtre.

--maximize

Maximise la fenêtre.

--role=ROLE

Définit le rôle de la fenêtre X.

--class=CLASS

Classe du programme telle qu'utilisée par le gestionnaire de fenêtres.

--display=DISPLAY

Affichage X à utiliser.

--g-fatal-warnings

Rend tous les avertissements fatals.

--gdk-debug=FLAGS

Indicateurs de débogage GDK à définir.

--gdk-no-debug=FLAGS

Indicateurs de débogage GDK à désactiver.

--gtk-debug=FLAGS

Indicateurs de débogage GTK à définir.

--gtk-no-debug=FLAGS

Indicateurs de débogage GTK à désactiver.

--gtk-module=MODULES

Charge des modules GTK supplémentaires.

--name=NAME

Nom du programme tel qu'utilisé par le gestionnaire de fenêtres.

BOGUES

Veuillez lire https://wiki.gnome.org/Apps/Terminal/ReportingBugs sur la manière de signaler les bogues.

EXEMPLES

Pour exécuter un terminal contenant une invite Python interactive :

        gnome-terminal --title=Python -- python3 -q

Pour interpréter la syntaxe shell dans un terminal, écrivez-la soit dans un script shell séparé, soit utilisez sh -c :

        gnome-terminal -- sh -c 'if [ "$(id -u)" = 0 ]; then ...'

VOIR AUSSI

Pour plus d'informations, visitez le site web https://wiki.gnome.org/Apps/Terminal. Il existe une liste de questions fréquemment posées à https://wiki.gnome.org/Apps/Terminal/FAQ.
