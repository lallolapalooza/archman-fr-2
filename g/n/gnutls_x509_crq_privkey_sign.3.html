gnutls_x509_crq_privkey_sign(3)

gnutls_x509_crq_privkey_sign(3) gnutls gnutls_x509_crq_privkey_sign(3)

NOM

gnutls_x509_crq_privkey_sign - Fonction d'API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_x509_crq_privkey_sign(gnutls_x509_crq_t crq, gnutls_privkey_t key, gnutls_digest_algorithm_t dig, unsigned int flags);

ARGUMENTS

gnutls_x509_crq_t crq
doit contenir un type gnutls_x509_crq_t
gnutls_privkey_t key
contient une clé privée
gnutls_digest_algorithm_t dig
Le résumé de message à utiliser, par exemple, GNUTLS_DIG_SHA1
unsigned int flags
doit être 0

DESCRIPTION

Cette fonction signera la demande de certificat avec une clé privée. Ce doit être la même clé que celle utilisée dans gnutls_x509_crt_set_key() car une demande de certificat est auto-signée.

Ce doit être la dernière étape dans la génération d'une demande de certificat car tous les paramètres définis précédemment sont maintenant signés.

Une limitation connue de cette fonction est qu'une demande nouvellement signée ne sera pas entièrement fonctionnelle (par exemple, pour la vérification de signature) jusqu'à ce qu'elle soit exportée puis ré-importée.

Après GnuTLS 3.6.1, la valeur de dig peut être GNUTLS_DIG_UNKNOWN, et dans ce cas, un algorithme approprié mais raisonnable pour l'algorithme de clé sera sélectionné.

RETOURNE

GNUTLS_E_SUCCESS en cas de succès, sinon un code d'erreur négatif. GNUTLS_E_ASN1_VALUE_NOT_FOUND est retourné si vous n'avez pas défini toutes les informations dans la demande de certificat (par exemple, la version en utilisant gnutls_x509_crq_set_version()).
