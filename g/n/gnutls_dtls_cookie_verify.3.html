NOM

gnutls_dtls_cookie_verify - fonction API

SYNTAXE

#include <gnutls/dtls.h>

int gnutls_dtls_cookie_verify(gnutls_datum_t * key, void * client_data, size_t client_data_size, void * _msg, size_t msg_size, gnutls_dtls_prestate_st * prestate);

ARGUMENTS

gnutls_datum_t * key
est une clé aléatoire à utiliser pour la génération du cookie
void * client_data
contient des données identifiant le client (par exemple, l'adresse)
size_t client_data_size
La taille des données du client
void * _msg
Un message entrant qui initie une connexion.
size_t msg_size
La taille du message.
gnutls_dtls_prestate_st * prestate
Le cookie de ce client.

DESCRIPTION

Cette fonction vérifie si le message reçu contient un cookie valide. Si un cookie valide est retourné, il doit être associé à la session en utilisant gnutls_dtls_prestate_set();

Cette fonction doit être appelée après gnutls_dtls_cookie_send().

RETOURNE

GNUTLS_E_SUCCESS (0) en cas de succès, ou un code d'erreur négatif.
