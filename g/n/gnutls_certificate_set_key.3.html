NOM

gnutls_certificate_set_key - fonction API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_certificate_set_key(gnutls_certificate_credentials_t res, const char ** names, int names_size, gnutls_pcert_st * pcert_list, int pcert_list_size, gnutls_privkey_t key);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
const char ** names
est un tableau de noms DNS appartenant à la clé publique (NULL s'il n'y en a pas)
int names_size
contient la taille de la liste des noms
gnutls_pcert_st * pcert_list
contient une liste de certificats (chaîne) ou une clé publique brute
int pcert_list_size
contient la taille de la liste des certificats
gnutls_privkey_t key
est une clé gnutls_privkey_t correspondant à la première clé publique dans pcert_list

DESCRIPTION

Cette fonction définit une paire clé publique/clé privée dans le type gnutls_certificate_credentials_t. La clé publique donnée peut être encapsulée dans un certificat ou peut être fournie comme une clé brute. Cette fonction peut être appelée plus d'une fois, si plusieurs paires de clés existent pour le serveur. Pour les clients qui souhaitent envoyer plus que leur propre certificat d'entité finale (par exemple, également un certificat CA intermédiaire), la chaîne de certificats complète doit être fournie dans pcert_list.

Notez que la key deviendra partie intégrante de la structure de credentials et ne doit pas être désallouée. Elle sera automatiquement désallouée lorsque la structure res sera désinitialisée.

Si cette fonction échoue, la structure res est dans un état indéfini et ne doit pas être réutilisée pour charger d'autres clés ou certificats.

Notez que, par défaut, cette fonction retourne zéro en cas de succès et une valeur négative en cas d'erreur. Depuis la version 3.5.6, lorsque le flag GNUTLS_CERTIFICATE_API_V2 est défini en utilisant gnutls_certificate_set_flags(), elle retourne un index (supérieur ou égal à zéro). Cet index peut être utilisé par d'autres fonctions pour faire référence à la paire clé ajoutée.

Depuis GnuTLS 3.6.6, cette fonction gère également les clés publiques brutes.

RETOUR

En cas de succès, cette fonction retourne zéro, sinon une valeur négative en cas d'erreur (voir ci-dessus pour modifier ce comportement).
