NOM

gnutls_pkcs12_export2 - Fonction API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_export2(gnutls_pkcs12_t pkcs12, gnutls_x509_crt_fmt_t format, gnutls_datum_t * out);

ARGUMENTS

gnutls_pkcs12_t pkcs12
Un type pkcs12
gnutls_x509_crt_fmt_t format
le format des paramètres de sortie. Soit PEM soit DER.
gnutls_datum_t * out
conterra une structure encodée en PEM ou DER

DESCRIPTION

Cette fonction exportera la structure pkcs12 au format DER ou PEM.

Le tampon de sortie est alloué en utilisant gnutls_malloc().

Si la structure est encodée en PEM, elle aura un en-tête "BEGIN PKCS12".

RETOURNE

En cas d'échec, un code d'erreur négatif sera retourné, et 0 en cas de succès.
