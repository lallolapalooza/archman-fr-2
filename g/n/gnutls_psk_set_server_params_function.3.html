NOM

gnutls_psk_set_server_params_function - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_psk_set_server_params_function(gnutls_psk_server_credentials_t res, gnutls_params_function * func);

ARGUMENTS

gnutls_psk_server_credentials_t res
est un type gnutls_certificate_credentials_t
gnutls_params_function * func
est la fonction à appeler

DESCRIPTION

Cette fonction définit un rappel afin que le serveur obtienne les paramètres Diffie-Hellman pour l'authentification PSK. Le rappel doit retourner GNUTLS_E_SUCCESS (0) en cas de succès.

DÉPRÉCIATION

Cette fonction est inutile et déconseillée à partir de GnuTLS 3.6.0. Depuis la version 3.6.0, les paramètres DH sont négociés conformément à la RFC7919.
