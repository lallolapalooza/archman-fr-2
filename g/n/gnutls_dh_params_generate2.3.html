NOM

gnutls_dh_params_generate2 - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_dh_params_generate2(gnutls_dh_params_t dparams, unsigned int bits);

ARGUMENTS

gnutls_dh_params_t dparams
Les paramètres
unsigned int bits
est le nombre de bits du nombre premier

DESCRIPTION

Cette fonction générera une nouvelle paire de nombres premiers et de générateurs à utiliser dans l'échange de clés Diffie-Hellman. Cela peut prendre beaucoup de temps.

Il est recommandé de ne pas définir le nombre de bits directement, mais d'utiliser plutôt gnutls_sec_param_to_pk_bits(). Notez également que les paramètres DH ne sont utiles qu'aux serveurs. Étant donné que les clients utilisent les paramètres envoyés par le serveur, il est inutile d'appeler cela côté client.

Les paramètres générés sont de forme DSA. Il est également possible de générer des paramètres prouvables (suivant l'algorithme de Shawe-Taylor), en utilisant gnutls_x509_privkey_generate2() avec l'option DSA et le drapeau GNUTLS_PRIVKEY_FLAG_PROVABLE activé. Ceux-ci peuvent ensuite être importés avec gnutls_dh_params_import_dsa().

Il n'est plus recommandé aux applications de générer des paramètres. Voir la section « Génération de paramètres » dans le manuel.

VALEUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné.
