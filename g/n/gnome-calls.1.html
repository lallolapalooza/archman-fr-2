NOM

gnome-calls - Passer et recevoir des appels

SYNTAXE

gnome-calls [OPTIONS...] [URI SIP/TEL]

DESCRIPTION

gnome-calls est un numéroteur basé sur GTK pour la PSTN et le SIP.

Il utilise ModemManager pour communiquer avec le modem cellulaire pour la PSTN. En plus des appels téléphoniques, il gère également les requêtes USSD. Dans le cas du SIP, il utilise sofia-sip pour la signalisation SIP et les pipelines GStreamer pour gérer la charge utile RTP des données audio.

Il fonctionne sur les bureaux, mais s'adapte également aux petits écrans tels que les smartphones et autres appareils mobiles.

OPTIONS

-h, --help

Affiche les options d'aide.

--help-all

Affiche toutes les options d'aide.

--help-gapplication

Affiche les options GApplication.

--help-gtk

Affiche les options GTK+.

--version

Affiche la version du programme.

--p, --provider=PLUGIN

Les plugins à utiliser comme fournisseur d'appels. Peut être spécifié plusieurs fois. Par défaut, ModemManager et SIP (-p mm -p sip).

-l, --dial=NUMBER

Compose un numéro de téléphone (pas besoin du préfixe d'URI tel:).

-d, --daemon

Indique s'il faut présenter la fenêtre principale au démarrage.

-v, --verbose

Active les messages de débogage détaillés. Peut être spécifié plusieurs fois.
