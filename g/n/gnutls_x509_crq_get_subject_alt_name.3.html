NOM

gnutls_x509_crq_get_subject_alt_name - Fonction API

SYNOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_subject_alt_name(gnutls_x509_crq_t crq, unsigned int seq, void * ret, size_t * ret_size, unsigned int * ret_type, unsigned int * critical);

ARGUMENTS

gnutls_x509_crq_t crq
doit contenir un type gnutls_x509_crq_t
unsigned int seq
spécifie le numéro de séquence du nom alternatif, 0 pour le premier, 1 pour le second, etc.
void * ret
est l'emplacement où le nom alternatif sera copié
size_t * ret_size
contient la taille de ret.
unsigned int * ret_type
contient le type de nom gnutls_x509_subject_alt_name_t
unsigned int * critical
sera non nul si l'extension est marquée comme critique (peut être nul)

DESCRIPTION

Cette fonction retournera les noms alternatifs contenus dans le certificat donné. Elle est identique à gnutls_x509_crq_get_subject_alt_name() à l'exception du fait qu'elle retournera le type du nom alternatif dans ret_type même si la fonction échoue pour une raison quelconque (c'est-à-dire si le tampon fourni n'est pas suffisant).

RETOURNE

le type de nom alternatif du sujet en cas de succès, l'une des énumérations gnutls_x509_subject_alt_name_t. Elle retournera GNUTLS_E_SHORT_MEMORY_BUFFER si ret_size n'est pas assez grand pour contenir la valeur. Dans ce cas, ret_size sera mis à jour avec la taille requise. Si la demande de certificat n'a pas de nom alternatif avec le numéro de séquence spécifié, alors GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est retourné.
