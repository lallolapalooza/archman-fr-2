gnutls_certificate_set_x509_trust_dir(3) gnutls gnutls_certificate_set_x509_trust_dir(3)

NOM

gnutls_certificate_set_x509_trust_dir - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_trust_dir(gnutls_certificate_credentials_t cred, const char * ca_dir, gnutls_x509_crt_fmt_t type);

ARGUMENTS

gnutls_certificate_credentials_t cred
est un type gnutls_certificate_credentials_t.
const char * ca_dir
est un répertoire contenant la liste des AC de confiance (liste DER ou PEM)
gnutls_x509_crt_fmt_t type
est PEM ou DER

DESCRIPTION

Cette fonction ajoute les AC de confiance présentes dans le répertoire afin de vérifier les certificats client ou serveur. Cette fonction est identique à gnutls_certificate_set_x509_trust_file() mais charge tous les certificats d'un répertoire.

RETOUR

le nombre de certificats traités
