gnutls_x509_crt_get_subject_alt_name(3) gnutls gnutls_x509_crt_get_subject_alt_name(3)

NOM

gnutls_x509_crt_get_subject_alt_name - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_subject_alt_name(gnutls_x509_crt_t cert, unsigned int seq, void * san, size_t * san_size, unsigned int * critical);

ARGUMENTS

gnutls_x509_crt_t cert
devrait contenir un type gnutls_x509_crt_t
unsigned int seq
spécifie le numéro de séquence du nom alternatif (0 pour le premier, 1 pour le second, etc.)
void * san
est l'emplacement où le nom alternatif sera copié
size_t * san_size
contient la taille de san.
unsigned int * critical
sera non nul si l'extension est marquée comme critique (peut être nul)

DESCRIPTION

Cette fonction récupère le Nom Alternatif du Sujet (2.5.29.17), contenu dans le certificat donné dans les extensions de certificat X509v3.

Lorsque le type SAN est otherName, il extraira les données du champ de valeur de otherName, et GNUTLS_SAN_OTHERNAME sera retourné. Vous pouvez utiliser gnutls_x509_crt_get_subject_alt_othername_oid() pour obtenir l'OID correspondant et les types SAN « virtuels » (par exemple, GNUTLS_SAN_OTHERNAME_XMPP).

Si un OID otherName est connu, les données seront décodées. Sinon, les données retournées seront encodées en DER, et vous devrez les décoder vous-même. Actuellement, seul l'adresse XMPP id-on-xmppAddr RFC 3920 est reconnue.

RETOURNE

le type du nom alternatif du sujet en cas de succès, l'une des valeurs énumérées gnutls_x509_subject_alt_name_t. Elle retournera GNUTLS_E_SHORT_MEMORY_BUFFER si san_size n'est pas assez grand pour contenir la valeur. Dans ce cas, san_size sera mis à jour avec la taille requise. Si le certificat n'a pas de nom alternatif avec le numéro de séquence spécifié, alors GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
