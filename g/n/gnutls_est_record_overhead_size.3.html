NOM

gnutls_est_record_overhead_size - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

size_t gnutls_est_record_overhead_size(gnutls_protocol_t version, gnutls_cipher_algorithm_t cipher, gnutls_mac_algorithm_t mac, gnutls_compression_method_t comp, unsigned int flags);

ARGUMENTS

gnutls_protocol_t version
est une valeur gnutls_protocol_t
gnutls_cipher_algorithm_t cipher
est une valeur gnutls_cipher_algorithm_t
gnutls_mac_algorithm_t mac
est une valeur gnutls_mac_algorithm_t
gnutls_compression_method_t comp
est une valeur gnutls_compression_method_t (ignorée)
unsigned int flags
doit être zéro

DESCRIPTION

Cette fonction renvoie la taille fixe en octets de la surcharge due à TLS (ou DTLS) par enregistrement.

Notez que cette fonction peut fournir des valeurs inexactes lorsque des extensions TLS modifiant le format de l'enregistrement sont négociées. Dans ces cas, une valeur plus précise peut être obtenue en utilisant gnutls_record_overhead_size() après un handshake terminé.
