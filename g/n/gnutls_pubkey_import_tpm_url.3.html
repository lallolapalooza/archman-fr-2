NOM

gnutls_pubkey_import_tpm_url - Fonction d'API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_pubkey_import_tpm_url(gnutls_pubkey_t pkey, const char * url, const char * srk_password, unsigned int flags);

ARGUMENTS

gnutls_pubkey_t pkey
La clé publique
const char * url
L'URL de la clé TPM à importer
const char * srk_password
Le mot de passe de la clé SRK (optionnel)
unsigned int flags
doit être zéro

DESCRIPTION

Cette fonction importera la clé privée donnée dans le type abstrait gnutls_privkey_t.

Notez que, sauf si GNUTLS_PUBKEY_DISABLE_CALLBACKS est spécifié, si des mots de passe incorrects (ou NULL) sont fournis, les fonctions de rappel PKCS11 seront utilisées pour obtenir les mots de passe corrects. Sinon, si le mot de passe SRK est erroné, GNUTLS_E_TPM_SRK_PASSWORD_ERROR sera retourné.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
