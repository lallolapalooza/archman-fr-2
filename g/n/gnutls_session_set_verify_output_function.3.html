NOM

gnutls_session_set_verify_output_function - Fonction API

SYNTAXE

#include <gnutls/x509.h>

void gnutls_session_set_verify_output_function(gnutls_session_t session, gnutls_verify_output_function * func);

ARGUMENTS

gnutls_session_t session
est un type gnutls_x509_trust_list_t.
gnutls_verify_output_function * func
est la fonction de rappel

DESCRIPTION

Cette fonction définit une fonction de rappel à appeler lorsque la chaîne de certificats du pair doit être vérifiée et que le chemin complet vers la racine de confiance doit être imprimé.

Le prototype de la fonction de rappel est défini dans `x509.h' : int (*callback)( gnutls_x509_crt_t cert, gnutls_x509_crt_t issuer, gnutls_x509_crl_t crl, unsigned int verification_output);

Si la fonction de rappel est fournie, gnutls l'appellera lors de la procédure de vérification du certificat. Pour vérifier la chaîne de certificats et imprimer son chemin jusqu'à la racine de confiance, des fonctions telles que gnutls_certificate_verify_peers(), gnutls_x509_trust_list_verify_crt() et gnutls_x509_trust_list_verify_crt2() peuvent être utilisées. La fonction de rappel est définie dans _gnutls_verify_crt_status() et _gnutls_pkcs11_verify_crt_status().
