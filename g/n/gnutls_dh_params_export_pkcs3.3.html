NOM

gnutls_dh_params_export_pkcs3 - Fonction API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_dh_params_export_pkcs3(gnutls_dh_params_t params, gnutls_x509_crt_fmt_t format, unsigned char * params_data, size_t * params_data_size);

ARGUMENTS

gnutls_dh_params_t params
Contient les paramètres DH
gnutls_x509_crt_fmt_t format
Le format des paramètres de sortie. Soit PEM, soit DER.
unsigned char * params_data
Contiendra une structure PKCS3 DHParams encodée en PEM ou en DER.
size_t * params_data_size
Contient la taille de params_data (et sera remplacé par la taille réelle des paramètres).

DESCRIPTION

Cette fonction exportera les paramètres DH donnés vers une structure PKCS3 DHParams. C'est le format généré par l'outil "openssl dhparam". Si le tampon fourni n'est pas assez grand pour contenir la sortie, alors GNUTLS_E_SHORT_MEMORY_BUFFER sera retourné.

Si la structure est encodée en PEM, elle aura un en-tête "BEGIN DH PARAMETERS".

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné.
