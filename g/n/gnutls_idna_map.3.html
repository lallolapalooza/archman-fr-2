NOM

gnutls_idna_map - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_idna_map(const char * input, unsigned ilen, gnutls_datum_t * out, unsigned flags);

ARGUMENTS

const char * input
contient le nom de domaine formaté en UTF-8
unsigned ilen
la longueur de la chaîne fournie
gnutls_datum_t * out
le résultat dans une chaîne allouée et terminée par null
unsigned flags
devrait être zéro

DESCRIPTION

Cette fonction convertira le nom de domaine UTF-8 fourni en son mappage IDNA dans une variable allouée. Notez que, selon les indicateurs avec lesquels la bibliothèque gnutls utilisée a été compilée, le résultat de cette fonction peut varier (c'est-à-dire qu'il peut s'agir d'IDNA2008 ou d'IDNA2003).

Pour forcer IDNA2008, spécifiez l'indicateur GNUTLS_IDNA_FORCE_2008. Dans le cas où GnuTLS n'est pas compilé avec les dépendances nécessaires, GNUTLS_E_UNIMPLEMENTED_FEATURE sera renvoyé pour indiquer que gnutls est incapable d'effectuer la conversion demandée.

Notez également que cette fonction renverra une chaîne vide si une chaîne vide est fournie en entrée.

RETOUR

GNUTLS_E_INVALID_UTF8_STRING en cas de données UTF-8 invalides, ou 0 en cas de succès.
