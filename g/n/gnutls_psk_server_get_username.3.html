NOM

gnutls_psk_server_get_username - fonction API

SYNTAXE

#include <gnutls/gnutls.h>

const char * gnutls_psk_server_get_username(gnutls_session_t session);

ARGUMENTS

gnutls_session_t session
est une session gnutls

DESCRIPTION

Ceci ne devrait être appelé qu'en cas d'authentification PSK et en cas de serveur.

Le pointeur retourné doit être considéré comme constant (ne pas libérer) et valide pendant la durée de vie de la session.

Cette fonction retournera NULL si le nom d'utilisateur contient des octets NULL intégrés. Dans ce cas, gnutls_psk_server_get_username2() devrait être utilisé pour récupérer le nom d'utilisateur.

RETOURNE

Le nom d'utilisateur du pair, ou NULL en cas d'erreur, ou si le nom d'utilisateur a des NULL intégrés.
