NOM

gnutls_certificate_set_retrieve_function - fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

void gnutls_certificate_set_retrieve_function(gnutls_certificate_credentials_t cred, gnutls_certificate_retrieve_function * func);

ARGUMENTS

gnutls_certificate_credentials_t cred
est un type gnutls_certificate_credentials_t.
gnutls_certificate_retrieve_function * func
est la fonction de rappel

DESCRIPTION

Cette fonction définit une fonction de rappel à appeler pour récupérer le certificat à utiliser lors de l'établissement de la connexion. La fonction de rappel prendra le contrôle uniquement si un certificat est demandé par le pair. Il est conseillé d'utiliser gnutls_certificate_set_retrieve_function2() car elle est beaucoup plus efficace dans le traitement qu'elle demande à gnutls.

Le prototype de la fonction de rappel est : int (*callback)(gnutls_session_t, const gnutls_datum_t* req_ca_dn, int nreqs, const gnutls_pk_algorithm_t* pk_algos, int pk_algos_length, gnutls_retr2_st* st);


req_ca_dn n'est utilisé que pour les certificats X.509. Contient une liste des noms des AC que le serveur considère comme fiables. Ceci est une indication et typiquement le client devrait envoyer un certificat signé par l'une de ces AC. Ces noms, lorsqu'ils sont disponibles, sont encodés en DER. Pour obtenir une valeur plus significative, utilisez la fonction gnutls_x509_rdn_get().


pk_algos contient une liste des algorithmes de clé publique acceptables par le serveur. Le certificat retourné doit supporter les algorithmes donnés par le serveur.


st doit contenir les certificats et les clés privées.

Si la fonction de rappel est fournie, gnutls l'appellera lors de l'établissement de la connexion, après la réception du message de demande de certificat.

Côté serveur, pk_algos et req_ca_dn sont NULL.

La fonction de rappel doit définir la liste des certificats à envoyer et retourner 0 en cas de succès. Si aucun certificat n'a été sélectionné, le nombre de certificats doit être mis à zéro. La valeur (-1) indique une erreur et l'établissement de la connexion sera terminé. Si les deux certificats sont définis dans les identifiants et qu'une fonction de rappel est disponible, la fonction de rappel a la priorité.
