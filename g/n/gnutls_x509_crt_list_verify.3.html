gnutls_x509_crt_list_verify(3) gnutls gnutls_x509_crt_list_verify(3)

NOM

gnutls_x509_crt_list_verify - Fonction d'API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_list_verify(const gnutls_x509_crt_t * cert_list, unsigned cert_list_length, const gnutls_x509_crt_t * CA_list, unsigned CA_list_length, const gnutls_x509_crl_t * CRL_list, unsigned CRL_list_length, unsigned int flags, unsigned int * verify);

ARGUMENTS

const gnutls_x509_crt_t * cert_list
est la liste de certificats à vérifier
unsigned cert_list_length
contient le nombre de certificats dans cert_list
const gnutls_x509_crt_t * CA_list
est la liste des CA qui sera utilisée pour la vérification
unsigned CA_list_length
contient le nombre de certificats CA dans CA_list
const gnutls_x509_crl_t * CRL_list
contient une liste de CRL.
unsigned CRL_list_length
la longueur de la liste CRL.
unsigned int flags
Indicateurs qui peuvent être utilisés pour modifier l'algorithme de vérification. Utilisez l'OR des énumérations gnutls_certificate_verify_flags.
unsigned int * verify
conterra le résultat de la vérification du certificat.

DESCRIPTION

Cette fonction tentera de vérifier la liste de certificats donnée et retournera son statut. Les détails de la vérification sont les mêmes que dans gnutls_x509_trust_list_verify_crt2().

Vous devez vérifier le nom du pair afin de vérifier si le certificat vérifié appartient au pair réel.

Le résultat de la vérification du certificat sera stocké dans verify et sera un ou plusieurs des éléments de l'énumération gnutls_certificate_status_t combinés par OU bit à bit. Pour un statut de vérification plus détaillé, utilisez gnutls_x509_crt_verify() pour chaque élément de la liste.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
