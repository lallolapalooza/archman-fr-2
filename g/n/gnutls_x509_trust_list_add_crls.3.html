NOM

gnutls_x509_trust_list_add_crls - Fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_trust_list_add_crls(gnutls_x509_trust_list_t list, const gnutls_x509_crl_t * crl_list, unsigned crl_size, unsigned int flags, unsigned int verification_flags);

ARGUMENTS

gnutls_x509_trust_list_t list
La liste
const gnutls_x509_crl_t * crl_list
Une liste de CRL
unsigned crl_size
La taille de la liste de CRL
unsigned int flags
flags de gnutls_trust_list_flags_t
unsigned int verification_flags
gnutls_certificate_verify_flags si flags spécifie GNUTLS_TL_VERIFY_CRL

DESCRIPTION

Cette fonction ajoutera les listes de révocation de certificats données à la liste de confiance. Les CRL dans crl_list ne doivent pas être désinitialisées pendant la durée de vie de list.

Cette fonction doit être appelée après gnutls_x509_trust_list_add_cas() pour permettre la vérification de la validité des CRL. Si le drapeau GNUTLS_TL_NO_DUPLICATES est donné, alors la liste finale de CRL ne contiendra pas d'entrées dupliquées.

Si le drapeau GNUTLS_TL_NO_DUPLICATES est donné, gnutls_x509_trust_list_deinit() doit être appelé avec le paramètre all à 1.

Si le drapeau GNUTLS_TL_VERIFY_CRL est donné, les CRL seront vérifiées avant d'être ajoutées, et si la vérification échoue, elles seront ignorées.

RETOURNE

Le nombre d'éléments ajoutés est retourné ; cela inclut les entrées dupliquées.
