NOM

gnutls_x509_crq_get_dn3 - Fonction d'API

SYNOPSIS

#include <gnutls/x509.h>

int gnutls_x509_crq_get_dn3(gnutls_x509_crq_t crq, gnutls_datum_t * dn, unsigned flags);

ARGUMENTS

gnutls_x509_crq_t crq
doit contenir un type gnutls_x509_crq_t
gnutls_datum_t * dn
un pointeur vers une structure pour contenir le nom ; doit être libéré en utilisant gnutls_free()
unsigned flags
zéro ou GNUTLS_X509_DN_FLAG_COMPAT

DESCRIPTION

Cette fonction allouera un tampon et copiera le nom de la demande de certificat. Le nom sera sous la forme "C=xxxx,O=yyyy,CN=zzzz" comme décrit dans RFC4514. La chaîne de sortie sera encodée en ASCII ou en UTF-8, en fonction des données du certificat.

Lorsque le drapeau GNUTLS_X509_DN_FLAG_COMPAT est spécifié, le format de sortie correspondra au format de sortie des versions précédentes à 3.5.6 de GnuTLS, qui n'étaient pas entièrement conformes à RFC4514.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative. et un code d'erreur négatif en cas d'erreur.
