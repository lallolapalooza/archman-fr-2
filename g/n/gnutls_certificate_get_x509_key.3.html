NOM

gnutls_certificate_get_x509_key - fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_certificate_get_x509_key(gnutls_certificate_credentials_t res, unsigned index, gnutls_x509_privkey_t * key);

ARGUMENTS

gnutls_certificate_credentials_t res
est un type gnutls_certificate_credentials_t.
unsigned index
L'indice de la clé à obtenir.
gnutls_x509_privkey_t * key
Emplacement pour stocker la clé.

DESCRIPTION

Récupère une clé privée X.509 qui a été stockée dans res avec l'une des fonctions suivantes : gnutls_certificate_set_x509_key(), gnutls_certificate_set_key(), gnutls_certificate_set_x509_key_file(), gnutls_certificate_set_x509_key_file2(), gnutls_certificate_set_x509_key_mem(), ou gnutls_certificate_set_x509_key_mem2(). La clé retournée doit être désallouée avec gnutls_x509_privkey_deinit() lorsqu'elle n'est plus nécessaire.

L'index correspond à la valeur de retour des fonctions telles que gnutls_certificate_set_x509_key(), lorsque le drapeau GNUTLS_CERTIFICATE_API_V2 est défini.

S'il n'y a pas de clé avec l'indice donné, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est retourné. Si la clé avec l'indice donné n'est pas une clé X.509, GNUTLS_E_INVALID_REQUEST est retourné.

RETOURNE

GNUTLS_E_SUCCESS (0) en cas de succès, ou un code d'erreur négatif.
