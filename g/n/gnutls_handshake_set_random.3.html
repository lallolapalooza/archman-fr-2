NOM

gnutls_handshake_set_random - Fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_handshake_set_random(gnutls_session_t session, const gnutls_datum_t * random);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
const gnutls_datum_t * random
une valeur aléatoire de 32 octets

DESCRIPTION

Cette fonction définira explicitement la valeur aléatoire du client ou du serveur hello lors de la négociation TLS suivante. La valeur aléatoire doit être une valeur de 32 octets.

Notez que cette fonction ne doit normalement pas être utilisée car gnutls sélectionnera automatiquement une valeur aléatoire pour la négociation.

Cette fonction ne doit pas être utilisée lors de la reprise d'une session.

RETOUR

GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.

Depuis 3.1.9
