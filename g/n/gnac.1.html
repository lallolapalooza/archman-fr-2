NOM

Gnac - Convertisseur audio pour GNOME

SYNTAXE

gnac [option...] [URIs...]

DESCRIPTION

Gnac est un programme de conversion audio facile à utiliser pour le bureau GNOME. Il est conçu pour être puissant mais simple ! Il permet une conversion facile des fichiers audio entre tous les formats audio pris en charge par GStreamer.

OPTIONS

-a, --profile-audio=nom
Utiliser le profil audio 'nom'
-l, --lister-profils
Lister les profils disponibles et quitter
--verbose
Activer la sortie détaillée
--debug
Afficher les informations de débogage
--version
Afficher la version du programme et quitter
--display=AFFICHAGE
Affichage X à utiliser
-? , -h , --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gst
Afficher les options GStreamer
--help-gtk
Afficher les options GTK+

RACCCOURCIS CLAVIER

Raccourcis clavier globaux pour Gnac :

Ctrl+i Ajouter de nouveaux fichiers ou dossiers
Ctrl+Maj+c Effacer la liste des fichiers
Ctrl+Maj+x Démarrer et arrêter une conversion
Entrée Afficher les propriétés du fichier sélectionné
Suppr Supprimer le fichier sélectionné de la liste

FICHIERS

~/.local/share/gnac/profiles/

Le répertoire des profils.

/usr/share/gnac/profiles/default/

Le répertoire des profils par défaut.
