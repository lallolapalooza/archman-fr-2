NOM

gnutls_x509_crt_check_issuer - Fonction de l'API

SYNTAXE

#include <gnutls/x509.h>

unsigned gnutls_x509_crt_check_issuer(gnutls_x509_crt_t cert, gnutls_x509_crt_t issuer);

ARGUMENTS

gnutls_x509_crt_t cert
est le certificat à vérifier
gnutls_x509_crt_t issuer
est le certificat d'un émetteur possible

DESCRIPTION

Cette fonction vérifie si le certificat donné a été émis par l'émetteur donné. Elle vérifie la correspondance des champs DN ainsi que des champs d'identifiant de clé d'autorité et d'identifiant de clé de sujet.

Si le même certificat est fourni dans les champs cert et issuer, elle vérifie si le certificat s'auto-signe.

RETOURNE

Elle retournera vrai (1) si le certificat donné est émis par l'émetteur donné, et faux (0) sinon.
