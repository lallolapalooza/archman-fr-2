NOM

gnutls_ocsp_resp_get_responder2 - Fonction d'API

SYNTAXE

#include <gnutls/ocsp.h>

int gnutls_ocsp_resp_get_responder2(gnutls_ocsp_resp_const_t resp, gnutls_datum_t * dn, unsigned flags);

ARGUMENTS

gnutls_ocsp_resp_const_t resp
doit contenir un type gnutls_ocsp_resp_t
gnutls_datum_t * dn
buffer nouvellement alloué avec le nom
unsigned flags
zéro ou GNUTLS_X509_DN_FLAG_COMPAT

DESCRIPTION

Cette fonction extrait le nom de la réponse OCSP de base dans le buffer fourni. Le nom sera sous la forme "C=xxxx,O=yyyy,CN=zzzz" comme décrit dans la RFC2253. La chaîne de sortie sera encodée en ASCII ou en UTF-8, en fonction des données du certificat.

Si l'identifiant du répondeur n'est pas un nom mais un hachage, cette fonction retournera zéro et les éléments de dn seront définis à NULL.

L'appelant doit désallouer la mémoire en appelant gnutls_free() sur
dn ->data.

Lorsque le drapeau GNUTLS_X509_DN_FLAG_COMPAT est spécifié, le format de sortie correspondra au format produit par les versions de GnuTLS antérieures à la 3.5.6, qui n'étaient pas entièrement conformes à la RFC4514.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif est retourné. En l'absence de données, il retournera GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
