NOM

gnutls_pkcs11_get_raw_issuer - fonction API

SYNTAXE

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_get_raw_issuer(const char * url, gnutls_x509_crt_t cert, gnutls_datum_t * issuer, gnutls_x509_crt_fmt_t fmt, unsigned int flags);

ARGUMENTS

const char * url
Une URL PKCS 11 identifiant un jeton.
gnutls_x509_crt_t cert
C'est le certificat pour lequel trouver l'émetteur.
gnutls_datum_t * issuer
Contiendra l'émetteur s'il y en a un, dans un tampon alloué.
gnutls_x509_crt_fmt_t fmt
Le format de l'émetteur exporté.
unsigned int flags
Utilisez zéro ou des indicateurs de GNUTLS_PKCS11_OBJ_FLAG.

DESCRIPTION

Cette fonction renverra l'émetteur d'un certificat donné, s'il est stocké dans le jeton. Par défaut, seuls les émetteurs marqués comme fiables sont renvoyés. Si tout émetteur doit être renvoyé, spécifiez GNUTLS_PKCS11_OBJ_FLAG_RETRIEVE_ANY dans flags.

VALEUR REPoURNEE

En cas de succès, GNUTLS_E_SUCCESS (0) est renvoyé, sinon une valeur d'erreur négative.
