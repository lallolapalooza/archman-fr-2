NOM

gnutls_x509_crq_get_attribute_data - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crq_get_attribute_data(gnutls_x509_crq_t crq, unsigned indx, void * data, size_t * sizeof_data);

ARGUMENTS

gnutls_x509_crq_t crq
doit contenir un type gnutls_x509_crq_t
unsigned indx
Spécifie quel numéro d'attribut obtenir. Utilisez (0) pour obtenir le premier.
void * data
un pointeur vers une structure pour stocker les données (peut être null)
size_t * sizeof_data
contient initialement la taille de oid

DESCRIPTION

Cette fonction retournera les données d'attribut demandées dans la demande de certificat. Les données d'attribut seront stockées sous forme de chaîne dans le tampon fourni.

Utilisez gnutls_x509_crq_get_attribute_info() pour extraire l'OID. Utilisez plutôt gnutls_x509_crq_get_attribute_by_oid() si vous souhaitez obtenir des données indexées par l'OID d'attribut plutôt que par séquence.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur négatif en cas d'erreur. Si vous avez atteint la dernière extension disponible, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE sera retourné.
