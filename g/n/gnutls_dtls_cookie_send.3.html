NOM

gnutls_dtls_cookie_send - Fonction API

SYNTAXE

#include <gnutls/dtls.h>

int gnutls_dtls_cookie_send(gnutls_datum_t * key, void * client_data, size_t client_data_size, gnutls_dtls_prestate_st * prestate, gnutls_transport_ptr_t ptr, gnutls_push_func push_func);

ARGUMENTS

gnutls_datum_t * key
est une clé aléatoire à utiliser pour la génération du cookie
void * client_data
contient des données identifiant le client (par exemple, son adresse)
size_t client_data_size
La taille des données du client
gnutls_dtls_prestate_st * prestate
Le cookie précédent renvoyé par gnutls_dtls_cookie_verify()
gnutls_transport_ptr_t ptr
Un pointeur de transport à utiliser par push_func
gnutls_push_func push_func
Une fonction qui sera utilisée pour répondre

DESCRIPTION

Cette fonction peut être utilisée pour prévenir les attaques par déni de service sur un serveur DTLS en exigeant que le client réponde en utilisant un cookie envoyé par cette fonction. De cette façon, il est possible de s'assurer qu'un client pour lequel nous avons alloué des ressources (par exemple, gnutls_session_t) est bien celui qui est à l'origine du paquet entrant.

Cette fonction doit être appelée lors du premier paquet entrant, avant d'allouer des ressources, et doit être suivie de gnutls_dtls_cookie_verify().

RETOUR

Le nombre d'octets envoyés, ou un code d'erreur négatif.
