NOM

gnutls_x509_crt_get_issuer_dn - fonction API

SYNTAXE

#include <gnutls/x509.h>

int gnutls_x509_crt_get_issuer_dn(gnutls_x509_crt_t cert, char * buf, size_t * buf_size);

ARGUMENTS

gnutls_x509_crt_t cert
doit contenir un type gnutls_x509_crt_t
char * buf
un pointeur vers une structure pour contenir le nom (peut être nul)
size_t * buf_size
contient initialement la taille de buf

DESCRIPTION

Cette fonction copiera le nom de l'émetteur du certificat dans le tampon fourni. Le nom sera sous la forme "C=xxxx,O=yyyy,CN=zzzz" comme décrit dans la RFC4514. La chaîne de sortie sera encodée en ASCII ou en UTF-8, en fonction des données du certificat.

Si buf est nul, seule la taille sera remplie.

Cette fonction ne produit pas une chaîne entièrement conforme à la RFC4514 ; si c'est ce qui est requis, voir gnutls_x509_crt_get_issuer_dn3().

RETOUR

GNUTLS_E_SHORT_MEMORY_BUFFER si le tampon fourni n'est pas assez long, et dans ce cas, buf_size sera mis à jour avec la taille requise. GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE si le DN n'existe pas, ou une autre valeur d'erreur en cas de problème. En cas de succès, 0 est retourné.
