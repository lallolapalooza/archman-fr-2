NOM

gnutls_cipher_init - fonction API

SYNTAXE

#include <gnutls/crypto.h>

int gnutls_cipher_init(gnutls_cipher_hd_t * handle, gnutls_cipher_algorithm_t cipher, const gnutls_datum_t * key, const gnutls_datum_t * iv);

ARGUMENTS

gnutls_cipher_hd_t * handle
est un type gnutls_cipher_hd_t
gnutls_cipher_algorithm_t cipher
l'algorithme de chiffrement à utiliser
const gnutls_datum_t * key
la clé à utiliser pour le chiffrement/déchiffrement
const gnutls_datum_t * iv
l'IV à utiliser (si non applicable, mettre NULL)

DESCRIPTION

Cette fonction initialise le contexte handle pour qu'il soit utilisable pour le chiffrement/déchiffrement de données. Cela utilisera effectivement le backend cryptographique actuel utilisé par gnutls ou l'accélérateur cryptographique en cours d'utilisation.

RETOURNE

Zéro ou un code d'erreur négatif en cas d'erreur.
