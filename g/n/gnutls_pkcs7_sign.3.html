NOM

gnutls_pkcs7_sign - Fonction d'API

SYNOPSIS

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_sign(gnutls_pkcs7_t pkcs7, gnutls_x509_crt_t signer, gnutls_privkey_t signer_key, const gnutls_datum_t * data, gnutls_pkcs7_attrs_t signed_attrs, gnutls_pkcs7_attrs_t unsigned_attrs, gnutls_digest_algorithm_t dig, unsigned flags);

ARGUMENTS

gnutls_pkcs7_t pkcs7
doit contenir un type gnutls_pkcs7_t
gnutls_x509_crt_t signer
le certificat pour signer la structure
gnutls_privkey_t signer_key
la clé pour signer la structure
const gnutls_datum_t * data
Les données à signer ou NULL si les données sont déjà intégrées
gnutls_pkcs7_attrs_t signed_attrs
Tout attribut supplémentaire à inclure dans ceux signés (ou NULL)
gnutls_pkcs7_attrs_t unsigned_attrs
Tout attribut supplémentaire à inclure dans ceux non signés (ou NULL)
gnutls_digest_algorithm_t dig
L'algorithme de hachage à utiliser pour la signature
unsigned flags
Doit être zéro ou l'un des drapeaux GNUTLS_PKCS7

DESCRIPTION

Cette fonction ajoutera une signature dans la structure PKCS 7 fournie pour les données fournies. Plusieurs signatures peuvent être créées avec différents signataires.

Les drapeaux disponibles sont : GNUTLS_PKCS7_EMBED_DATA, GNUTLS_PKCS7_INCLUDE_TIME, GNUTLS_PKCS7_INCLUDE_CERT, et GNUTLS_PKCS7_WRITE_SPKI. Ils sont expliqués dans la définition gnutls_pkcs7_sign_flags.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
