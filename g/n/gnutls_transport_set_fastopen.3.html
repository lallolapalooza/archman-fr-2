NOM

gnutls_transport_set_fastopen - Fonction de l'API

SYNOPSIS

#include <gnutls/socket.h>

void gnutls_transport_set_fastopen(gnutls_session_t session, int fd, struct sockaddr * connect_addr, socklen_t connect_addrlen, unsigned int flags);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t.
int fd
est le descripteur de socket de la session
struct sockaddr * connect_addr
est l'adresse à laquelle nous voulons nous connecter
socklen_t connect_addrlen
est la longueur de connect_addr
unsigned int flags
doit être zéro

DESCRIPTION

Active TCP Fast Open (TFO) pour la session client TLS spécifiée. Cela signifie que l'établissement de la connexion TCP et la transmission du premier paquet TLS client hello sont combinés. L'adresse du pair doit être spécifiée dans connect_addr et connect_addrlen, et le socket spécifié par fd ne doit pas être connecté.

TFO ne fonctionne que pour les sockets TCP de type AF_INET et AF_INET6. Si le système d'exploitation ne prend pas en charge TCP fast open, cette fonction entraînera l'utilisation transparente de connect() par gnutls lors de la première écriture.

NOTE

Cette fonction remplace toutes les fonctions de rappel de transport. Si cela n'est pas souhaitable, TCP Fast Open doit être implémenté dans les fonctions de rappel utilisateur sans appeler cette fonction. Lors de l'utilisation de cette fonction, les rappels de transport ne doivent pas être définis, et gnutls_transport_set_ptr() ou gnutls_transport_set_int() ne doivent pas être appelés.

Sur GNU/Linux, TFO doit être activé au niveau du système, c'est-à-dire dans /proc/sys/net/ipv4/tcp_fastopen, le bit 0 doit être défini.

Cette fonction n'a aucun effet sur les sessions serveur.
