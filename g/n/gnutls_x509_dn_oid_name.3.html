NOM

gnutls_x509_dn_oid_name - fonction d'API

SYNOPSIS

#include <gnutls/x509.h>

const char * gnutls_x509_dn_oid_name(const char * oid, unsigned int flags);

ARGUMENTS

const char * oid
contient un identifiant d'objet dans une chaîne terminée par un octet nul
unsigned int flags
0 ou GNUTLS_X509_DN_OID_*

DESCRIPTION

Cette fonction renverra le nom d'un OID de DN connu. Si GNUTLS_X509_DN_OID_RETURN_OID est spécifié, cette fonction renverra l'OID donné si aucun nom descriptif n'a été trouvé.

RETOUR

Une chaîne terminée par un octet nul ou NULL sinon.
