NOM

gnutls_dh_get_group - fonction d'API

SYNOPSIS

#include <gnutls/gnutls.h>

int gnutls_dh_get_group(gnutls_session_t session, gnutls_datum_t * raw_gen, gnutls_datum_t * raw_prime);

ARGUMENTS

gnutls_session_t session
est une session gnutls
gnutls_datum_t * raw_gen
contiendra le générateur.
gnutls_datum_t * raw_prime
contiendra le nombre premier.

DESCRIPTION

Cette fonction renverra les paramètres de groupe utilisés dans le dernier échange de clés Diffie-Hellman avec le pair. Ce sont le nombre premier et le générateur utilisés. Cette fonction doit être utilisée pour le Diffie-Hellman anonyme et éphémère. Les paramètres de sortie doivent être libérés avec gnutls_free().

Notez que le nombre premier et le générateur sont exportés en tant qu'entiers non signés et peuvent inclure un octet zéro de tête.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon un code d'erreur est retourné.
