NOM

gnutls_x509_aia_get - Fonction d'API

SYNTAXE

#include <gnutls/x509-ext.h>

int gnutls_x509_aia_get(gnutls_x509_aia_t aia, unsigned int seq, gnutls_datum_t * oid, unsigned * san_type, gnutls_datum_t * san);

ARGUMENTS

gnutls_x509_aia_t aia
L'information d'accès de l'autorité
unsigned int seq
spécifie le numéro de séquence du descripteur d'accès (0 pour le premier, 1 pour le second, etc.)
gnutls_datum_t * oid
le type de données disponibles ; à traiter comme une constante.
unsigned * san_type
contiendra le type du nom de gnutls_subject_alt_names_t (peut être nul).
gnutls_datum_t * san
le nom de l'emplacement d'accès ; à traiter comme une constante (peut être nul).

DESCRIPTION

Cette fonction lit le type Authority Information Access.

Le paramètre d'entrée seq est utilisé pour indiquer à quel membre de la séquence le programmeur s'intéresse. Le premier membre est 0, le deuxième membre 1 et ainsi de suite. Lorsque la valeur de seq est hors limites, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE est retournée.

Typiquement, oid est GNUTLS_OID_AD_CAISSUERS ou GNUTLS_OID_AD_OCSP.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
