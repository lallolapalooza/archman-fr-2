NOM

gnutls_pubkey_import_tpm_raw - Fonction de l'API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_pubkey_import_tpm_raw(gnutls_pubkey_t pkey, const gnutls_datum_t * fdata, gnutls_tpmkey_fmt_t format, const char * srk_password, unsigned int flags);

ARGUMENTS

gnutls_pubkey_t pkey
La clé publique
const gnutls_datum_t * fdata
La clé TPM à importer
gnutls_tpmkey_fmt_t format
Le format de la clé privée
const char * srk_password
Le mot de passe de la clé SRK (facultatif)
unsigned int flags
Un des drapeaux GNUTLS_PUBKEY_*

DESCRIPTION

Cette fonction importera la clé publique de la structure de clé TPM fournie.

Concernant les mots de passe, les mêmes règles que pour gnutls_pubkey_import_tpm_url() s'appliquent.

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
