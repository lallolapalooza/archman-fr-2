NOM

gnutls_pkcs12_init - Fonction d'API

SYNTAXE

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_init(gnutls_pkcs12_t * pkcs12);

ARGUMENTS

gnutls_pkcs12_t * pkcs12
Un pointeur vers le type à initialiser

DESCRIPTION

Cette fonction initialise un type PKCS12. Les structures PKCS12 contiennent généralement des listes de certificats X.509 et de listes de révocation de certificats X.509.

RETOUR

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, sinon une valeur d'erreur négative.
