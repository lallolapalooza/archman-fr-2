NOM

gnutls_privkey_export_x509 - Fonction API

SYNTAXE

#include <gnutls/abstract.h>

int gnutls_privkey_export_x509(gnutls_privkey_t pkey, gnutls_x509_privkey_t * key);

ARGUMENTS

gnutls_privkey_t pkey
La clé privée
gnutls_x509_privkey_t * key
Emplacement pour exporter la clé.

DESCRIPTION

Convertit la clé privée abstraite donnée en type gnutls_x509_privkey_t. La clé abstraite doit être de type GNUTLS_PRIVKEY_X509. L'argument
key ne doit pas être initialisé. La clé retournée dans key doit être désinitialisée en utilisant gnutls_x509_privkey_deinit().

RETOUR

En cas de succès, renvoie GNUTLS_E_SUCCESS (0), sinon une valeur d'erreur négative.
