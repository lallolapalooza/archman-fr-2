NOM

gnutls_x509_ext_import_subject_key_id - fonction API

SYNTAXE

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_subject_key_id(const gnutls_datum_t * ext, gnutls_datum_t * id);

ARGUMENTS

const gnutls_datum_t * ext
une extension encodée en DER
gnutls_datum_t * id
conterra l'identifiant de clé sujet

DESCRIPTION

Cette fonction retournera l'identifiant de clé sujet stocké dans l'extension SubjectKeyIdentifier fournie. L'identifiant sera alloué en utilisant gnutls_malloc().

RETOURNE

En cas de succès, GNUTLS_E_SUCCESS (0) est retourné, GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE si l'extension n'est pas présente, sinon une valeur d'erreur négative.
