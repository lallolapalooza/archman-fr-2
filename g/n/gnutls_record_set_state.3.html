NOM

gnutls_record_set_state - Fonction d'API

SYNTAXE

#include <gnutls/gnutls.h>

int gnutls_record_set_state(gnutls_session_t session, unsigned read, const unsigned char [8] seq_number);

ARGUMENTS

gnutls_session_t session
est un type gnutls_session_t
unsigned read
si différent de zéro, les paramètres de lecture sont retournés, sinon ceux d'écriture
const unsigned char [8] seq_number
Un numéro de séquence de 64 bits

DESCRIPTION

Cette fonction définit le numéro de séquence dans l'état d'enregistrement actuel. Elle est utile si l'envoi et la réception sont déchargés de gnutls. C'est-à-dire, si gnutls_record_get_state() a été utilisé.

RETOURNE

GNUTLS_E_SUCCESS en cas de succès, ou un code d'erreur.

Depuis 3.4.0
