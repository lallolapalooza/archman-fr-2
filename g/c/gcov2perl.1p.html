gcov2perl(1p)

Paquet: perl-devel-cover

Licences: PerlArtistic, GPL

GCOV2PERL(1) Documentation Perl fournie par l'utilisateur GCOV2PERL(1)

NOM

gcov2perl - convertir les fichiers gcov en bases de données Devel::Cover

VERSION

version 1.51

SYNTAXE

gcov2perl -h -i -v -db base_de_donnees fichiers_gcov

DESCRIPTION

Convertit les fichiers gcov en bases de données Devel::Cover.

OPTIONS

Les options de ligne de commande suivantes sont prises en charge :

-db base_de_donnees    - spécifier la base de données à utiliser
-h -help        - afficher l'aide
-i -info        - afficher la documentation
-v -version     - afficher la version

DETAILS

Pour obtenir une couverture des fichiers XS, ceux-ci doivent d'abord être compilés avec les options appropriées. Dans un environnement Makefile standard, tel que celui créé par ExtUtils::MakeMaker, cela peut être réalisé avec la commande :

HARNESS_PERL_SWITCHES=-MDevel::Cover make test \
  CCFLAGS=-O0\ -fprofile-arcs\ -ftest-coverage \
  OTHERLDFLAGS=-fprofile-arcs\ -ftest-coverage

Si vous avez déjà construit vos fichiers objets, il peut être nécessaire d'exécuter d'abord make clean, ou de trouver un autre moyen de garantir qu'ils soient reconstruits avec les options requises par gcov.

Maintenant que les données de couverture du code ont été collectées, "gcov" doit être exécuté :

gcov Monlib.xs

Cela créera un ou plusieurs fichiers gcov sur lesquels vous pouvez exécuter "gcov2perl" :

gcov2perl Monlib.xs.gcov

Enfin, "cover" doit être exécuté comme d'habitude avec toutes les options requises :

cover

Si vous exécutez tout avec les options standard, vous pouvez faire tout cela avec une seule commande :

cover -test

ETAT SORTIE

Les valeurs de sortie suivantes sont renvoyées :

0   Tous les fichiers convertis avec succès
>0  Une erreur s'est produite.
