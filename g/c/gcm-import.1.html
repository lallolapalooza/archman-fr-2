NOM

gcm-import - Outil d'importation du gestionnaire de couleurs GNOME

SYNTAXE

gcm-import [ --verbose ]

DESCRIPTION

Cette page de manuel documente brièvement la commande gcm-import.

gcm-import vous permet d'importer des fichiers ICC fournis par les fournisseurs.
