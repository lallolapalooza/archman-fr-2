NOM

gcv - convertisseur de fichiers de graphes

SYNTAXE

gcv [options] [fichier_entree] [fichier_sortie] [fichier_geometrie]

DESCRIPTION

Le programme gcv convertit les fichiers de graphes Scotch d'et vers d'autres formats de fichiers externes.

Le fichier fichier_entree est converti en fichier de graphe fichier_sortie, avec des données géométriques optionnelles placées dans le fichier géométrique fichier_geometrie, si disponible.

Lorsque les noms de fichiers ne sont pas spécifiés, les données sont lues depuis l'entrée standard et écrites vers la sortie standard. Les flux standard peuvent également être représentés explicitement par un tiret '-'.

Lorsque les bibliothèques appropriées ont été incluses lors de la compilation, gcv peut directement gérer les graphes compressés, en entrée comme en sortie. Un flux est traité comme compressé chaque fois que son nom est suffixé par une extension de fichier compressé, comme dans 'brol.grf.bz2' ou '-.gz'. Les formats de compression pris en charge sont le format bzip2 ('.bz2'), le format gzip ('.gz') et le format lzma ('.lzma').

OPTIONS

-h
Afficher une aide.
-i?fmt_entree
Définir le format du fichier de graphe d'entrée, qui peut être :
b?num
Format Boeing-Harwell. C'est un format matriciel. Seules les matrices carrées sont prises en charge. Les matrices carrées avec un motif asymétrique sont symétrisées. Dans le cas où le fichier contient plusieurs matrices, le paramètre num permet à l'utilisateur de fournir l'indice de la matrice à convertir, en commençant par 0. Lorsque le paramètre num n'est pas défini, il est supposé être 0.
c
Format Chaco. C'est un format de graphe d'adjacence, également utilisé par MeTiS.
m
Format Matrix Market. C'est un format matriciel décrivant les arêtes individuelles. Le motif de la matrice est symétrisé, de sorte que les matrices rectangulaires sont finalement mises au carré.
s
Format de graphe Scotch. C'est un format de graphe d'adjacence.
-o?fmt_sortie
Définir le format du fichier de graphe de sortie, qui peut être :
c
Format Chaco.
m
Format de motif symétrique Matrix Market.
s
Format Scotch. C'est la valeur par défaut.
-V
Afficher la version du programme et le copyright.

EXEMPLE

Convertir un graphe Matrix Market en un graphe Scotch. Les fichiers Matrix Market ne contiennent pas de données géométriques, donc aucun fichier géométrique n'est nécessaire en sortie :

    $ gcv -im brol.mm brol.grf
