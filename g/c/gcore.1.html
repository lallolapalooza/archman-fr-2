NOM

gcore - Générer un fichier core d'un programme en cours d'exécution

SYNTAXE

gcore [-a] [-o préfixe] [-d répertoire] pid1 [pid2...pidN]

DESCRIPTION

Génère des dumps de core d'un ou plusieurs programmes en cours d'exécution avec les identifiants de processus (pid) pid1, pid2, etc. Un fichier core produit par gcore est équivalent à un fichier produit par le noyau lorsque le processus plante (et lorsque "ulimit -c" a été utilisé pour définir une limite appropriée pour les dumps de core). Cependant, contrairement à après un crash, après que gcore a terminé son travail, le programme reste en cours d'exécution sans aucun changement.

OPTIONS

-a
Dump toutes les correspondances mémoire. L'effet réel de cette option dépend du système d'exploitation. Sur GNU/Linux, cela désactivera "use-coredump-filter" et activera "dump-excluded-mappings".
-o préfixe
L'argument optionnel préfixe spécifie le préfixe à utiliser lors de la composition des noms de fichiers des dumps de core. Le nom du fichier est composé comme suit : préfixe.pid, où pid est l'identifiant du processus du programme en cours d'exécution analysé par gcore. S'il n'est pas spécifié, le préfixe par défaut est gcore.
-d répertoire
Utilise répertoire comme répertoire de données lors de l'invocation de GDB pour exécuter la commande gcore. Cet argument est facultatif.
