NOM

gcab - Programme pour créer des archives cabinet Microsoft (.cab)

SYNTAXE

gcab [OPTION]... FICHIER_CAB FICHIERS...

DESCRIPTION

Crée le fichier cabinet FICHIER_CAB à partir de la liste de FICHIERS.

OPTIONS

-c, --créer
crée une nouvelle archive cabinet
-x, --extraire
extrait des fichiers d'une archive cabinet
-t, --lister
liste les fichiers d'une archive cabinet
-n, --sans-chemin
crée des fichiers sans noms de chemin
-C, --répertoire DIR
change ou extrait vers le répertoire DIR
-v, --verbeux
liste en mode verbeux les fichiers traités
-z, --zip
utilise la compression zip
