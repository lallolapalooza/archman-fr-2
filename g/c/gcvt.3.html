gcvt(3) Manuel des fonctions de bibliothèque gcvt(3)

NOM

gcvt - convertir un nombre à virgule flottante en chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
char *gcvt(double nombre, int ndigit, char *buf);
Exigences pour les macros de test de fonctionnalités dans glibc (voir feature_test_macros(7)) :

gcvt() :

    Depuis glibc 2.17
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 200809L))
            || /* glibc >= 2.20 */ _DEFAULT_SOURCE
            || /* glibc <= 2.19 */ _SVID_SOURCE
    glibc 2.12 à glibc 2.16 :
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 200112L))
            || _SVID_SOURCE
    Avant glibc 2.12 :
        _SVID_SOURCE || _XOPEN_SOURCE >= 500

DESCRIPTION

La fonction gcvt() convertit nombre en une chaîne ASCII minimale et terminée par un caractère nul, et la stocke dans buf. Elle produit ndigit chiffres significatifs, soit au format F de printf(3), soit au format E.

VALEUR DE RETOUR

La fonction gcvt() retourne buf.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
gcvt () Sécurité des threads MT-Safe

NORMES

Aucune.

HISTORIQUE

Marquée comme OBSOLÈTE dans POSIX.1-2001. POSIX.1-2008 l'a supprimée, recommandant l'utilisation de sprintf(3) à la place (bien que snprintf(3) puisse être préférable).

VOIR AUSSI

ecvt(3), fcvt(3), sprintf(3)
