NOM

gcdmaster - Interface graphique pour cdrdao pour composer des CDs audio

SYNTAXE

gcdmaster [fichier-toc]

DESCRIPTION

gcdmaster permet la création de fichiers toc pour cdrdao et peut contrôler le processus d'enregistrement. Son application principale est la composition de CDs audio à partir d'un ou plusieurs fichiers audio. Il prend en charge l'édition des canaux PQ, la saisie de métadonnées telles que les codes ISRC/CD-TEXT et la découpe non destructive des données audio.

Si un fichier-toc est spécifié, il sera lu et les données audio référencées seront affichées. Il est également possible de spécifier un fichier « .cue ».

L'interface graphique interroge périodiquement tous les lecteurs CD-ROM et graveurs CD configurés (voir la section DIALOGUE DE CONFIGURATION DES PÉRIPHÉRIQUES) pour obtenir leur état (prêt, occupé, aucun disque). Cela est fait en envoyant une commande TEST UNIT READY aux périphériques. Les problèmes suivants peuvent survenir :

o
Certains périphériques (par exemple, le Philips CDD2600) bloquent le bus SCSI lors de l'émission d'une commande TEST UNIT READY pendant qu'il charge un nouveau média. Cela provoquera un sous-dépassement de tampon pour tous les périphériques en cours d'enregistrement connectés au même bus.
o
L'interface graphique ne peut pas détecter si un périphérique est utilisé par un autre programme. Elle continuera à interroger le périphérique, ce qui peut perturber le fonctionnement de l'autre programme.

L'interface graphique prend en charge l'enregistrement de projets identiques ou différents sur plusieurs périphériques en parallèle. Cependant, il existe quelques mises en garde et votre système doit répondre à certaines prérequis :

o
Sous Linux, une version du noyau >= 2.2.6 doit être utilisée. Le périphérique SCSI générique des noyaux plus anciens ne prend pas en charge l'accès parallèle à plusieurs périphériques.
o
Les bandes passantes des disques contenant les données sources et des bus impliqués doivent être suffisantes pour desservir tous les périphériques d'enregistrement.
o
Certains périphériques d'enregistrement peuvent bloquer le bus SCSI lors de l'éjection du disque par le logiciel après le processus de gravure (par exemple, le Plextor PX-R412). Pour cette raison, un message d'avertissement s'affichera si le bouton « Éjecter » est coché dans la boîte de dialogue « Enregistrer ». L'éjection manuelle d'un disque ne semble pas poser de problème.
o
Les périphériques ATAPI pris en charge par le pilote 'generic-mmc' bloquent le bus IDE lors de la gravure du lead-in et du lead-out. Ainsi, l'écriture parallèle avec de tels périphériques connectés au même canal IDE ne fonctionnera pas. Il existe un moyen d'éviter ce blocage avec certains périphériques ATAPI, mais il n'est pas encore implémenté.

CONCEPTS

L'idée principale de cette interface graphique est de maintenir un flux continu de données audio qui peut être composé de plusieurs fichiers audio. Il est possible d'utiliser uniquement des portions de fichiers audio dans le flux audio, ce qui est l'idée de base de la capacité de découpe non destructive.

Par exemple, si vous supprimez certains échantillons au milieu d'un fichier audio, le résultat sera une portion commençant au début du fichier audio et se terminant au début de la région coupée, et une deuxième portion commençant à la fin de la région coupée et allant jusqu'à la fin du fichier audio. Bien sûr, tout cela est caché par l'interface graphique et vous verrez seulement le résultat.

Les marqueurs de piste et d'index sont placés relativement au flux audio continu. Il n'est pas nécessaire d'avoir un fichier audio séparé pour chaque piste. Les marqueurs de piste/index peuvent être définis, déplacés et supprimés sans influencer le flux de données audio.

Marqueur d'échantillon

Un marqueur d'échantillon sert de position d'insertion pour les données audio. Il est équivalent au curseur d'un éditeur de texte. Toutes les fonctions qui insèrent des données audio nécessitent un marqueur défini. Au plus un marqueur d'échantillon peut être actif à la fois.

Sélection d'échantillon

Une sélection d'échantillons spécifie une plage continue d'échantillons audio. Au plus une sélection d'échantillons peut être active à la fois.

Marqueur de piste

Un marqueur de piste spécifie un point dans le flux audio où le numéro de piste ou le numéro d'index change. Les marqueurs de piste sont écrits sous forme d'une paire de deux nombres comme 5.1 pour la piste 5, index 1. Les numéros de piste peuvent être compris entre 1 et 99, la plage valide pour les numéros d'index est 0 à 99. L'index 0 représente le pré-espace d'une piste où le temps relatif de la piste compte à rebours jusqu'à zéro. L'index 1 marque le début réel de la piste. Cette position est stockée dans le toc central du CD et est utilisée par les lecteurs CD pour sauter directement à une piste. Tous les numéros d'index > 2 peuvent être utilisés pour subdiviser une piste mais n'ont pas d'autre effet. Certains lecteurs CD peuvent sauter à ces marques d'index.

Les marqueurs de piste peuvent être sélectionnés pour afficher des données sur une piste ou pour effectuer des opérations sur la piste complète. Au plus un marqueur de piste peut être sélectionné à la fois.

Temps

Le temps est généralement affiché sous la forme m:s:f.x où m représente les minutes, s représente les secondes (0..59), f représente les images (0..74, 1/75 seconde) et x représente les échantillons (0..587, 1/44100 seconde).

FENÊTRE PRINCIPALE

La fenêtre principale se compose d'une barre de menus, d'un affichage des échantillons, d'une ligne de marqueurs/sélection, d'une ligne de boutons et d'une ligne d'état.

Le titre de la fenêtre principale affiche le nom du fichier toc actuel. Un « (*) » derrière le nom indique que les modifications n'ont pas été enregistrées.

Barre de menus

Les fonctions accessibles via la barre de menus sont décrites dans la section FONCTIONS DU MENU.

Affichage des échantillons

L'affichage des échantillons fournit une représentation visuelle du flux audio et des marqueurs de piste/index placés.

Les échantillons sont affichés sous forme de deux graphiques distincts pour les canaux gauche et droit, où l'axe des x représente le temps et l'axe des y représente l'amplitude (à l'échelle linéaire). Si un pixel représente plus d'un échantillon, l'amplitude maximale et minimale de tous les échantillons tombant dans ce pixel est affichée. Il est possible de zoomer et dézoomer et de modifier la portion affichée avec la barre de défilement.

Les marqueurs de piste/index sont affichés par-dessus les deux graphiques. Les marqueurs de piste avec l'index 1 sont représentés par un symbole de piste rempli. Tous les autres marqueurs de piste utilisent un symbole de piste creux. La paire numéro de piste/index est affichée sur le côté droit du symbole de piste.

Les marqueurs de piste peuvent être sélectionnés ou déplacés en cliquant ou en faisant glisser avec le pointeur de la souris situé sur un symbole de piste. Les paires numéro de piste/index ne sont pas sensibles.

Ligne de marqueur/sélection

Cette ligne affiche la position actuelle du curseur et du marqueur actif, ainsi que la sélection d'échantillon active.

Le champ curseur est en lecture seule et affiche la valeur temporelle de la position actuelle du pointeur de la souris dans le flux audio s'il est situé à l'intérieur de l'affichage des échantillons. Pendant la lecture, le champ curseur affiche la valeur temporelle du son actuellement audible.

Le champ marqueur affiche la valeur temporelle du marqueur actif. Une valeur temporelle peut être entrée et l'appui sur la touche retour définit la nouvelle position du marqueur si la valeur temporelle est valide.

Les champs de sélection d'échantillon affichent la plage d'échantillons sélectionnée active. Des valeurs temporelles peuvent être entrées et l'appui sur la touche retour dans l'un de ces champs définit la nouvelle sélection d'échantillons si les valeurs temporelles sont valides.

Ligne de boutons

Les boutons radio zoom/sélection spécifient le comportement lors du glisser-déposer de la souris dans l'affichage des échantillons. Si « zoom » est actif, l'affichage des échantillons effectuera un zoom sur la plage d'échantillons sélectionnée. Si « sélection » est actif, la sélection d'échantillons active sera définie sur la plage d'échantillons sélectionnée.

Le bouton lecture lira la sélection d'échantillons actuellement active via la carte son. Si aucune sélection d'échantillons n'est active, la plage d'échantillons actuellement affichée sera utilisée. Pendant la lecture, le projet en cours est

Cadre

CD-TEXT

Les données CD-TEXT peuvent être spécifiées pour jusqu'à 8 langues différentes. Chaque langue est référencée par un numéro de langue 0..7. La première langue devrait avoir le numéro de langue 0. Les numéros de langue devraient être utilisés de manière

continue.

La langue réelle pour un numéro de langue est spécifiée avec le menu d'options "Langue" : L'option "Inconnue" est affichée pour un code de langue inconnu (par exemple si le fichier toc a été édité manuellement). Il n'est pas possible de sélectionner cette option. L'option "Indéfinie" signifie qu'aucune langue n'a été assignée pour ce numéro de langue. Il est possible de saisir des données CD-TEXT et les données saisies seront enregistrées dans le fichier toc mais elles ne seront pas gravées sur un CD-R/CD-RW. Les options restantes sélectionnent la langue souhaitée. Chaque langue ne peut être assignée qu'à un seul numéro de

langue.

Les champs CD-TEXT restants contiennent des

données ASCII. Il n'est pas nécessaire
de tous les utiliser mais au moins "Titre"
et "Interprète" devraient être remplis.

Cette boîte de dialogue non modale peut être utilisée pour enregistrer le projet actuel sur un CD-R/CD-RW. Il est possible d'enregistrer le projet actuel sur plusieurs enregistreurs

simultanément.

Le bouton « Start » lancera les processus d'enregistrement sur tous les périphériques sélectionnés dans le navigateur « Available Recorder Devices ». À cette fin, l'exécutable cdrdao sera appelé et devrait être disponible dans votre PATH. Pour chaque périphérique sélectionné, une boîte de dialogue de progression non modale sera

ouverte.

Après le démarrage de l'enregistrement sur tous les périphériques sélectionnés, il est possible de charger un autre fichier toc ou de continuer à modifier le projet existant. Il est également possible de quitter l'interface graphique en toute sécurité. L'enregistrement continuera en arrière-plan mais vous n'aurez aucun retour sur la

progression.

Le bouton « Cancel » fermera la boîte de

dialogue.
