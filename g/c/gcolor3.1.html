NOM

gcolor3 - une boîte de dialogue de sélection de couleur

SYNTAXE

gcolor3 [OPTIONS]

DESCRIPTION

gcolor3 vous permet de choisir la couleur de n'importe quel pixel de votre écran. Il offre également une palette, afin que vous puissiez facilement mélanger et associer plusieurs couleurs.

OPTIONS

Options d'aide

-h, --help
Affiche les options d'aide
--help-all
Affiche toutes les options d'aide

Options de l'application

-v, --version
Affiche la version de l'application
--display=AFFICHAGE
Affichage X à utiliser

FICHIERS

$XDG_CONFIG_HOME/gcolor3/rgb.ini
Vos couleurs enregistrées sont stockées dans ce fichier

NOTES

gcolor3 imprime la dernière couleur sélectionnée sur stdout au format hexadécimal à la sortie.

BOGUES

Pour tout bogue ou demande de fonctionnalité, veuillez créer un problème sur GitLab à l'adresse https://gitlab.gnome.org/World/gcolor3/issues
