NOM

gc - compter les composantes d'un graphe

SYNTAXE

gc [ -necCaDUrsv? ] [ fichiers ]

DESCRIPTION

gc est un analogue de wc pour les graphes, car il affiche sur la sortie standard le nombre de nœuds, d'arêtes, de composantes connexes ou de clusters contenus dans les fichiers d'entrée. Il affiche également un compte total pour tous les graphes si plusieurs graphes sont donnés.

OPTIONS

Les options suivantes sont prises en charge :

-n
Compter les nœuds.
-e
Compter les arêtes.
-c
Compter les composantes connexes.
-C
Compter les clusters. Par définition, un cluster est un graphe ou sous-graphe dont le nom commence par "cluster".
-a
Tout compter. Équivalent à -encC
-r
Analyser récursivement les sous-graphes.
-s
Ne rien afficher. Seule la valeur de sortie est importante.
-D
Analyser uniquement les graphes orientés.
-U
Analyser uniquement les graphes non orientés.
-v
Affichage verbeux.
-?
Afficher les informations d'utilisation.

Par défaut, gc renvoie le nombre de nœuds et d'arêtes.

OPÉRANDES

L'opérande suivant est pris en charge :

fichiers
Noms des fichiers contenant 1 ou plusieurs graphes au format dot. Si aucun opérande fichiers n'est spécifié, l'entrée standard sera utilisée.

STATUT DE SORTIE

Les valeurs de sortie suivantes sont renvoyées :

0
Achèvement réussi.
1
L'option -U ou -E a été utilisée, et un graphe du type incorrect a été rencontré.
