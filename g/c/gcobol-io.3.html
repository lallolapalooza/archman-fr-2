La bibliothèque implémente une fonction que le binaire produit par gcobolappelle directement :

  • gcobol_io_t * gcobol_fileops()
    Cette fonction remplit un objet gcobol_io_t avec les pointeurs de fonction ci-dessus. Le binaire compilé commence par appeler gcobol_fileops(), puis utilise les pointeurs fournis pour effectuer les E/S.

VALEURS DE RETOUR

Les fonctions d'E/S retournent void. gcobol_fileops() retourne gcobol_io_t*.

NORMES

La bibliothèque d'E/S fournie par gcobol, libgcobolio.so, prend en charge la sémantique d'E/S définie par ISO COBOL. Elle n'est pas destinée à être compatible avec un autre ODF. C'est-à-dire que libgcobolio.so ne peut pas être utilisée pour échanger des données avec une autre implémentation COBOL.

Le but de la structure gcobol_io_t est de permettre l'utilisation d'autres implémentations d'E/S avec d'autres représentations ODF.

AVERTISSEMENTS

La bibliothèque n'est pas bien testée, en partie parce qu'elle n'est pas implémentée.
