gccmakedep(1) Manuel des commandes générales gccmakedep(1)

NOM

gccmakedep - crée les dépendances dans les makefiles en utilisant 'gcc -M'

SYNTAXE

gccmakedep [ -sséparateur ] [ -fmakefile ] [ -a ] [ -- options -- ] fichier_source ...

DESCRIPTION

Le programme gccmakedep appelle 'gcc -M' pour générer des règles de makefile décrivant les dépendances de chaque fichier_source, afin que make(1) sache quels fichiers objets doivent être recompilés lorsqu'une dépendance a changé.

Par défaut, gccmakedep place sa sortie dans le fichier nommé makefile s'il existe, sinon Makefile. Un makefile alternatif peut être spécifié avec l'option -f. Il recherche d'abord dans le makefile une ligne commençant par

# DO NOT DELETE

ou celle fournie avec l'option -s, comme délimiteur pour la sortie des dépendances. S'il la trouve, il supprimera tout ce qui suit cette ligne jusqu'à la fin du makefile et placera la sortie après cette ligne. S'il ne la trouve pas, le programme ajoutera la chaîne à la fin du makefile et placera la sortie après cela.

EXEMPLE

Normalement, gccmakedep sera utilisé dans une cible de makefile afin qu'en tapant 'make depend' les dépendances soient mises à jour pour le makefile. Par exemple,

    SRCS = fichier1.c fichier2.c ...
    CFLAGS = -O -DHACK -I../foobar -xyz
    depend:
            gccmakedep -- $(CFLAGS) -- $(SRCS)

OPTIONS

Le programme ignorera toute option qu'il ne comprend pas, vous pouvez donc utiliser les mêmes arguments que ceux que vous utiliseriez pour gcc(1), y compris les options -D et -U pour définir et annuler la définition de symboles, et -I pour définir le chemin d'inclusion.

-a
Ajouter les dépendances au fichier au lieu de remplacer les dépendances existantes.
-fmakefile
Nom de fichier. Ceci vous permet de spécifier un makefile alternatif dans lequel gccmakedep peut placer sa sortie. Spécifier « - » comme nom de fichier (c'est-à-dire -f-) envoie la sortie vers la sortie standard au lieu de modifier un fichier existant.
-schaîne
Chaîne de caractères de début. Cette option permet de spécifier une chaîne différente que gccmakedep doit rechercher dans le makefile. La valeur par défaut est « # DO NOT DELETE ».
-- options --
Si gccmakedep rencontre un double trait d'union (--) dans la liste des arguments, alors tous les arguments non reconnus qui le suivent seront silencieusement ignorés. Un second double trait d'union termine ce traitement spécial. De cette façon, gcc makedep peut être amené à ignorer en toute sécurité des arguments de compilateur ésotériques qui pourraient normalement se trouver dans une macro CFLAGS de make (voir la section EXEMPLE ci-dessus). Les options -D, -I et -U apparaissant entre la paire de doubles traits d'union sont toujours traitées normalement.

VOIR AUSSI

gcc(1), make(1), makedepend(1).
