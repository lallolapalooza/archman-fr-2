NOM

git-verify-tag - Vérifie la signature GPG des étiquettes

SYNTAXE

git verify-tag [-v | --verbose] [--format=<format>] [--raw] <tag>...

DESCRIPTION

Valide la signature gpg créée par git tag dans les objets d'étiquette listés sur la ligne de commande.

OPTIONS

--raw

Affiche la sortie brute du statut gpg sur la sortie d'erreur standard au lieu de la sortie normale lisible par l'homme.

-v, --verbose

Affiche le contenu de l'objet d'étiquette avant de le valider.
