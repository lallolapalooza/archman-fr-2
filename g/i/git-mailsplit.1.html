NOM

git-mailsplit - Simple programme de division de mbox UNIX

SYNOPSIS

git mailsplit [-b] [-f<nn>] [-d<prec>] [--keep-cr] [--mboxrd]
                -o<directory> [--] [(<mbox>|<Maildir>)...]

DESCRIPTION

Divise un fichier mbox ou un Maildir en une liste de fichiers : "0001" "0002" .. dans le répertoire spécifié afin que vous puissiez les traiter davantage à partir de là.


Important

La division Maildir repose sur le tri des noms de fichiers pour produire les patchs dans le bon ordre.

OPTIONS

<mbox>

Fichier mbox à diviser. S'il n'est pas donné, le mbox est lu depuis l'entrée standard.

<Maildir>

Racine du Maildir à diviser. Ce répertoire doit contenir les sous-répertoires cur, tmp et new.

-o<directory>

Répertoire dans lequel placer les messages individuels.

-b

Si un fichier ne commence pas par une ligne From, supposez qu'il s'agit d'un seul message de courrier électronique au lieu de signaler une erreur.

-d<prec>

Au lieu des 4 chiffres par défaut avec des zéros non significatifs, une précision différente peut être spécifiée pour les noms de fichiers générés.

-f<nn>

Ignore les <nn> premiers numéros, par exemple si -f3 est spécifié, commence la numérotation à partir de 0004.

--keep-cr

Ne supprime pas le \r des lignes se terminant par \r\n.

--mboxrd

L'entrée est au format "mboxrd" et l'échappement de ligne "^>+From " est inversé.
