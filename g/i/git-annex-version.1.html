NOM

git-annex-version - afficher les informations de version

SYNTAXE

git annex version

DESCRIPTION

Affiche la version de git-annex, ainsi que des informations sur la version du dépôt.

La version de git-annex est de la forme MAJOR.DATE, où MAJOR est un nombre comme 5, correspondant à la version actuelle du dépôt, et DATE est la date de la dernière publication, comme 20150320.

Les compilations quotidiennes de git-annex ajouteront un "-gREF" à la version, correspondant au ref git du dépôt source de git-annex qui a été compilé. Par conséquent, "5.20150320-gdd35cf3" est une compilation quotidienne, et "5.20150401" est une sortie du 1er avril réalisée un peu plus tard.

OPTIONS

--raw
Force la sortie de la seule version de git-annex, et rien d'autre.
Les git-annex-common-options(1) peuvent aussi être utilisés.
