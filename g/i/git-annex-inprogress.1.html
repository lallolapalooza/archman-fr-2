git-annex-inprogress(1) Manuel des commandes générales git-annex-inprogress(1)

NOM

git-annex-inprogress - accéder aux fichiers pendant leur téléchargement

SYNTAXE

git annex inprogress [chemin ...]

DESCRIPTION

Cette commande permet d'accéder au contenu d'un fichier annexé pendant sa phase de téléchargement. Elle affiche sur la sortie standard le nom du fichier temporaire utilisé pour télécharger le fichier annexé spécifié.

Rien ne sera affiché lorsque le téléchargement provient d'un dépôt spécial chiffré ou segmenté.

Ceci peut parfois être utilisé pour streamer un fichier avant qu'il ne soit entièrement téléchargé, par exemple :


git annex get video.mpeg &
vlc $(git annex inprogress video.mpeg)

Bien sûr, si le fichier se télécharge trop lentement, le lecteur multimédia atteindra la fin trop tôt et n'affichera pas l'intégralité du contenu. Et bien sûr, seuls certains formats de fichiers peuvent être streamés utilement de cette manière.

OPTIONS

[chemin ..]
Les fichiers ou répertoires dont vous souhaitez accéder au contenu partiellement téléchargé.
Notez que, lorsqu'aucun chemin n'est spécifié, la commande recherche par défaut tous les fichiers du répertoire de travail courant et de ses sous-répertoires, ce qui peut prendre du temps à parcourir. Il est plus efficace de spécifier le fichier qui vous intéresse, ou d'utiliser --all.
--all -A
Au lieu de spécifier un nom de fichier ou un chemin, cette option peut être utilisée pour accéder à tous les fichiers actuellement en cours de téléchargement.
--key=nomducle
Accéder au fichier en cours de téléchargement pour la clé spécifiée.
options de correspondance de fichiers
Les options de correspondance de fichiers git-annex(1) peuvent être utilisées pour spécifier les fichiers à accéder.
Egalement les options communes git-annex(1) peuvent être utilisées.

STATUT DE SORTIE

Si l'un des éléments demandés n'est pas en cours de téléchargement, le statut de sortie sera 1.
