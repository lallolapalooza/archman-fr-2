NOM

git-citool - Alternative graphique à git-commit

SYNOPSIS

git citool

DESCRIPTION

Une interface graphique basée sur Tcl/Tk pour examiner les fichiers modifiés, les ajouter à l'index, saisir un message de commit et enregistrer le nouveau commit sur la branche courante. Cette interface est une alternative au programme moins interactif git commit.

git citool est en fait un alias standard pour git gui citool. Voir git-gui(1) pour plus de détails.
