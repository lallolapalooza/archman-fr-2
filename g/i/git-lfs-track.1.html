NOM

git-lfs-track - Consulter ou ajouter des chemins Git LFS aux attributs Git

SYNTAXE

git lfs track [options] [<motif>...]

DESCRIPTION

Commence à suivre les motifs fournis via Git LFS. L'argument est écrit dans .gitattributes. Si aucun chemin n'est fourni, liste simplement les chemins actuellement suivis.

La documentation de gitattributes https://git-scm.com/docs/gitattributes stipule que les motifs utilisent les règles de motif gitignore https://git-scm.com/docs/gitignore pour correspondre aux chemins. Cela signifie que les motifs contenant un astérisque (*), un point d'interrogation (?) et des caractères de crochet ([ et ]) sont traités spécialement ; pour désactiver ce comportement et les traiter littéralement à la place, utilisez --filename ou échappez le caractère avec une barre oblique inverse.

OPTIONS

--verbose, -v

Si activé, fait journaliser par git lfs track les fichiers qu'il va toucher. Désactivé par défaut.

--dry-run, -d

Si activé, fait journaliser par git lfs track toutes les actions qu'il effectuerait normalement (ajout d'entrées à .gitattributes, toucher des fichiers sur disque, etc.) sans effectuer d'opérations mutatives sur le disque.

git lfs track --dry-run [fichiers] simule implicitement le comportement de passage de l'option --verbose, et journalisera plus en détail ce qu'il fait.

Désactivé par défaut.

--filename

Traiter les arguments comme des noms de fichiers littéraux, et non comme des motifs. Tous les caractères spéciaux de glob dans le nom du fichier seront échappés lors de l'écriture du fichier .gitattributes.

--lockable, -l

Rendre les chemins "verrouillables", ce qui signifie qu'ils doivent être verrouillés pour les modifier, et qu'ils seront rendus en lecture seule dans la copie de travail lorsqu'ils ne sont pas verrouillés.

--not-lockable

Supprimer le drapeau verrouillable des chemins afin qu'ils ne soient plus en lecture seule sauf s'ils sont verrouillés.

--no-excluded


Ne pas lister les motifs exclus dans la sortie ; lister uniquement les motifs suivis. --no-modify-attrs : Rend les entrées correspondantes "stat-dirty" afin que Git puisse réindexer les fichiers que vous souhaitez convertir en LFS. Ne modifie aucun fichier .gitattributes.

EXEMPLES

•Lister les motifs que Git LFS suit actuellement :

git lfs track

•Configurer Git LFS pour suivre les fichiers GIF :

git lfs track "*.gif"

•Configurer Git LFS pour suivre les fichiers PSD et les rendre en lecture seule sauf s'ils sont verrouillés :

git lfs track --lockable "*.psd"

•Configurer Git LFS pour suivre le fichier nommé project [1].psd :

git lfs track --filename "project [1].psd"

git-lfs-untrack(1), git-lfs-install(1), gitattributes(5), gitignore(5).
