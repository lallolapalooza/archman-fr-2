NOM

giftext - exporter les pixels et métadonnées GIF sous forme de texte

SYNTAXE

giftext [-v] [-c] [-e] [-z] [-p] [-r] [-h] [fichier-gif]

DESCRIPTION

Un programme pour exporter (texte seulement) des informations générales sur un fichier GIF.

Si aucun fichier GIF n'est fourni, giftext essaiera de lire un fichier GIF depuis l'entrée standard.

OPTIONS

-v

Mode verbeux (afficher la progression). Active l'affichage des lignes de balayage en cours.

-c

Exporte les palettes de couleurs.

-e

Exporte les octets codés - les pixels après compression par l'algorithme LZ et chaînage pour former des octets. C'est la forme sous laquelle les données sont enregistrées dans le fichier GIF. Exportation en hexadécimal - 2 chiffres par octet.

-z

Exporte les codes LZ de l'image. Exportation en hexadécimal - 3 chiffres par code (car nous sommes limités à 12 bits).

-p

Exporte les pixels de l'image. Exportation en hexadécimal - 2 chiffres par pixel (<=octet).

-r

Exporte les pixels bruts comme un octet par pixel. Cette option inhibe toutes les autres options et seuls les pixels sont exportés. Cette option peut être utilisée pour convertir des fichiers GIF en données brutes. Note : la palette de couleurs peut être extraite par l'utilitaire gifclrmp. Si plusieurs images sont incluses dans le fichier, toutes les images seront exportées dans l'ordre.

-h

Affiche une ligne d'aide de ligne de commande, similaire à la Syntaxe ci-dessus.
