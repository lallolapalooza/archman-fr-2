NOM

git-annex-oldkeys - lister les clés utilisées pour les anciennes versions de fichiers

SYNTAXE

git annex oldkeys [chemin ...]

DESCRIPTION

Liste les clés utilisées pour les anciennes versions des fichiers ou répertoires spécifiés.

La sortie de cette commande peut être redirigée vers une commande telle que git-annex drop --batch-keys

Les clés sont listées dans l'ordre, de la plus récente à la plus ancienne.

Lorsqu'on liste les anciennes clés pour un répertoire, cela inclut les clés utilisées par les fichiers supprimés qui se trouvaient dans ce répertoire dans les commits passés.

OPTIONS

--unchecked
Par défaut, cette commande ne liste pas une clé qui est également utilisée par un fichier dans la branche actuellement extraite. Cette option permet également de lister de telles clés.
Le comportement par défaut évite les surprises lors de la suppression des clés listées. Cette option peut être utile, par exemple, lors de la copie de toutes les anciennes versions d'un fichier vers un dépôt distant.
--revision-range=valeur
Ne lister que les anciennes clés utilisées dans la plage de révisions spécifiée. Cela fonctionne de la même manière que l'option de plage de révisions de git log. Voir gitrevisions(7) pour la documentation sur le format de cette option.
Par exemple, pour ne lister que les clés utilisées depuis le tag v1.0, utilisez --revision-range=v1.0..HEAD
Les options git-annex-common-options(1) peuvent également être utilisées.
