NOM

git-unpack-objects - Décompresse les objets d'une archive packagée

SYNOPSIS

git unpack-objects [-n] [-q] [-r] [--strict]

DESCRIPTION

Lit une archive packagée (.pack) depuis l'entrée standard, décompresse les objets qu'elle contient et les écrit dans le dépôt au format "lâche" (un objet par fichier).

Les objets qui existent déjà dans le dépôt ne seront **pas** décompressés à partir du fichier pack. Par conséquent, rien ne sera décompressé si vous utilisez cette commande sur un fichier pack qui existe dans le dépôt cible.

Voir git-repack(1) pour les options de génération de nouveaux packs et de remplacement des packs existants.

OPTIONS

-n

Essai à blanc. Vérifie le fichier pack sans réellement décompresser les objets.

-q

La commande affiche généralement une progression en pourcentage. Cette option la supprime.

-r

Lors de la décompression d'un fichier pack corrompu, la commande échoue à la première corruption. Cette option lui dit de continuer et de faire de son mieux pour récupérer autant d'objets que possible.

--strict

Ne pas écrire les objets avec un contenu ou des liens cassés.

--max-input-size=<taille>

Échoue si le pack est plus grand que <taille>.
