NOM

git-annex-group - ajouter un dépôt à un groupe

SYNTAXE

git annex group dépôt [nomdugroupe]

DESCRIPTION

Ajoute un dépôt à un groupe, tel que « archive » ou « transfer ». Le nom du groupe doit être un seul mot.

Omettez le nom du groupe pour afficher les groupes auxquels un dépôt appartient actuellement.

Il existe des groupes standards qui ont des réglages de contenu préféré différents par défaut. Voir https://git-annex.branchable.com/preferred_content/standard_groups/

Un dépôt peut appartenir à plusieurs groupes en même temps.

OPTIONS

--list
Affiche une liste de tous les groupes utilisés par au moins un dépôt.
Les options git-annex-common-options(1) peuvent également être utilisées.
