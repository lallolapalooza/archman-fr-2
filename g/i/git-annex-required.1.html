git-annex-required(1) Manuel des commandes générales git-annex-required(1)

NOM

git-annex-required - obtenir ou définir l'expression de contenu requis

SYNOPSIS

git annex required dépôt [expression]

DESCRIPTION

Lorsqu'exécutée avec une expression, configure le contenu qui est requis dans le dépôt.

Sans expression, affiche le réglage actuel du contenu requis du dépôt.

Alors que git-annex-wanted(1) est juste une préférence, ceci désigne le contenu qui ne devrait vraiment pas être supprimé. Par exemple, un fichier qui est voulu peut être supprimé avec git annex drop, mais si ce fichier est requis, il devrait être supprimé avec git annex drop --force.

De plus, git annex fsck signalera les contenus requis qui ne sont pas présents.

Par exemple :


git annex required ici "include=*.mp3 or include=*.ogg"

Pour que le dépôt revienne à son comportement par défaut d'origine, utilisez une valeur vide pour l'expression, par exemple :

git annex required ici ""

OPTIONS

Les git-annex-common-options(1) peuvent être utilisées.

NOTES

La commande required a été ajoutée dans git-annex 5.20150420.
