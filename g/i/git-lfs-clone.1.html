NOM

git-lfs-clone - Clone efficacement un dépôt compatible LFS

SYNOPIS

git lfs clone [options git clone] <dépôt> [<répertoire>]

DESCRIPTION

Clone un dépôt Git activé pour LFS plus efficacement en désactivant LFS pendant le clone git, puis en effectuant un 'git lfs pull' directement après.

'git lfs clone' installe également tous les hooks au niveau du dépôt (.git/hooks) requis par LFS pour fonctionner. Si --separate-git-dir est fourni, les hooks seront installés là.

Ceci est plus rapide qu'un 'git clone' normal car ce dernier téléchargerait le contenu LFS en utilisant le filtre smudge, qui est exécuté individuellement par fichier dans la copie de travail. Ceci est relativement inefficace par rapport au mode batch et aux téléchargements parallèles effectués par 'git lfs pull'.

OPTIONS

Toutes les options prises en charge par 'git clone'

-I <chemins>, --include=<chemins>

Voir INCLUDE AND EXCLUDE.

-X <chemins>, --exclude=<chemins>

Voir INCLUDE AND EXCLUDE.

--skip-repo

Ignore l'installation des hooks au niveau du dépôt (.git/hooks) requis par LFS. Désactivé par défaut.

INCLUSION ET EXCLUSION

Vous pouvez configurer Git LFS pour ne télécharger les objets que pour satisfaire les références dans certains chemins du dépôt, et/ou pour exclure certains chemins du dépôt, afin de réduire le temps passé à télécharger des choses que vous n'utilisez pas.

Dans votre configuration Git ou dans un fichier .lfsconfig, vous pouvez définir lfs.fetchinclude et/ou lfs.fetchexclude à des listes de chemins séparés par des virgules. Si lfs.fetchinclude est défini, les objets Git LFS ne seront téléchargés que si leur chemin correspond à l'un de cette liste, et si lfs.fetchexclude est défini, les objets Git LFS ne seront téléchargés que si leur chemin ne correspond à aucun de cette liste. Les chemins sont mis en correspondance à l'aide de la correspondance de caractères génériques conformément à gitignore(5).

Notez que l'utilisation des options en ligne de commande -I et -X remplace les paramètres de configuration respectifs. Définir une option sur une chaîne vide efface la valeur.

VOIR AUSSI

git-clone(1), git-lfs-pull(1), gitignore(5).

Fait partie de la suite git-lfs(1).
