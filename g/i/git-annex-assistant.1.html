NOM

git-annex-assistant - démon pour ajouter des fichiers et synchroniser automatiquement les modifications

SYNTAXE

git annex assistant

DESCRIPTION

Surveille les modifications des fichiers dans le répertoire courant et ses sous-répertoires, et les synchronise automatiquement vers d'autres dépôts distants. Cela inclut l'ajout de nouveaux fichiers. Les nouveaux fichiers publiés sur les dépôts distants par d'autres utilisateurs sont également téléchargés automatiquement.

Par défaut, tous les nouveaux fichiers dans le répertoire seront ajoutés au dépôt. (Y compris les fichiers cachés.) Pour empêcher l'ajout de certains fichiers, utilisez les fichiers .gitignore.

Par défaut, tous les fichiers qui sont ajoutés le sont dans l'annexe, de la même manière que lorsque vous exécutez git annex add. Si vous configurez annex.largefiles, les fichiers qui ne correspondent pas seront ajoutés avec git add.

OPTIONS

--autostart
Démarre automatiquement l'assistant en cours d'exécution dans chaque dépôt listé dans le fichier ~/.config/git-annex/autostart
Ceci est généralement lancé au démarrage, ou lors de votre connexion.
--startdelay=N
Attend N secondes avant d'exécuter le scan de démarrage. Ce processus peut être coûteux et vous pourriez ne pas vouloir l'exécuter immédiatement après la connexion.
Lorsque --autostart est utilisé, la valeur par défaut est --startdelay=5.
--foreground
Évite de se détacher en arrière-plan.
--stop
Arrête un démon en cours d'exécution dans le dépôt courant.
--autostop
Le complément de --autostart ; arrête tous les démons en cours d'exécution dans les dépôts listés dans le fichier autostart.
Les git-annex-common-options(1) peuvent aussi être utilisés.
