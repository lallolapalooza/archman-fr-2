NOM

git-whatchanged - Affiche les journaux avec les différences introduites par chaque commit

SYNTAXE

git whatchanged <option>...

AVERTISSEMENT

git whatchanged est obsolète et sa suppression est prévue dans une future version de Git, car il s'agit simplement de git log avec des paramètres par défaut différents.

DESCRIPTION

Affiche les journaux de commits et la sortie de diff que chaque commit introduit.

Les nouveaux utilisateurs sont encouragés à utiliser git-log(1) à la place. La commande whatchanged est essentiellement la même que git-log(1) mais elle affiche par défaut la sortie de diff au format brut et ignore les fusions :

git log --raw --no-merges

La commande est principalement conservée pour des raisons historiques ; les doigts de beaucoup de personnes qui ont appris Git bien avant l'invention de git log en lisant la liste de diffusion du noyau Linux sont entraînés à la taper.

EXEMPLES

git whatchanged -p v2.6.12.. include/scsi drivers/scsi

Affiche sous forme de patchs les commits depuis la version v2.6.12 qui ont modifié un fichier dans les sous-répertoires include/scsi ou drivers/scsi

git whatchanged --since="2 semaines avant" -- gitk

Affiche les changements durant les deux dernières semaines sur le fichier gitk. Le "--" est nécessaire pour éviter la confusion avec la branche nommée gitk
