NOM

git-annex-status - afficher l'état de l'arbre de travail (obsolète)

SYNTAXE

git annex status [chemin ...]

DESCRIPTION

Similaire à git status --short, cette commande affiche l'état des fichiers dans l'arbre de travail.

Affiche les fichiers qui ne sont pas validés dans git (?), supprimés (D), modifiés (M), ajoutés mais non validés (A), et dont le type a changé/déverrouillé (T).

OPTIONS

--ignore-submodules=quand
Cette option est transmise à git status, voir sa page de manuel pour les détails.
--json
Activer la sortie JSON. Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement envoyés à la sortie d'erreur standard sont inclus dans le JSON à la place.
Les git-annex-common-options(1) peuvent également être utilisés.
