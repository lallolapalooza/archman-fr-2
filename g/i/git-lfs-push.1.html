NOM

git-lfs-push - Pousse les gros fichiers mis en file d'attente vers le point d'accès Git LFS

SYNTAXE

git lfs push [options] <remote> [<ref>...]
git lfs push <remote> [<ref>...]
git lfs push [options] <remote> --stdin git lfs push --object-id <remote> [<oid>...] git lfs push --object-id <remote> --stdin

DESCRIPTION

Télécharge les fichiers Git LFS vers le point d'accès configuré pour le dépôt Git distant actuel. Par défaut, il filtre les objets qui sont déjà référencés par le clone local du dépôt distant.

OPTIONS

--dry-run

Affiche les fichiers qui seraient poussés, sans réellement les pousser.

--all

Ceci pousse tous les objets vers le dépôt distant qui sont référencés par n'importe quel commit atteignable à partir des refs fournies en arguments. Si aucune ref n'est fournie, alors toutes les refs locales sont poussées. Notez que ce comportement diffère de celui de git-lfs-fetch(1) lorsque son option --all est utilisée ; dans ce cas, toutes les refs sont téléchargées, y compris celles autres que celles sous refs/heads et refs/tags. Si vous migrez un dépôt avec ces commandes, assurez-vous d'exécuter git lfs push pour toutes les refs distantes supplémentaires qui contiennent des objets Git LFS non atteignables depuis vos refs locales.

--object-id

Ceci pousse uniquement les OID d'objets listés à la fin de la commande, séparés par des espaces.

--stdin

Lit une liste de refs délimitées par des nouvelles lignes (ou d'IDs d'objets lors de l'utilisation de --object-id) depuis l'entrée standard au lieu de la ligne de commande.

VOIR AUSSI

git-lfs-fetch(1), git-lfs-pre-push(1).

Fait partie de la suite git-lfs(1).
