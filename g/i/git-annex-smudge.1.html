NOM

git-annex-smudge - pilote de filtre git pour git-annex

SYNOPSIS

git annex smudge [--clean] fichier

git annex smudge --update

DESCRIPTION

Cette commande permet à git-annex d'être utilisé comme un pilote de filtre git, ce qui permet aux fichiers annexés dans le dépôt git d'être déverrouillés, au lieu d'être des liens symboliques, et permet à git add de stocker les fichiers dans l'annexe.

Lors de l'ajout d'un fichier avec git add, la configuration annex.largefiles est consultée pour décider si un fichier donné doit être ajouté à git tel quel, ou si son contenu est suffisamment volumineux pour nécessiter l'utilisation de git-annex. Le paramètre annex.gitaddtoannex annule ce comportement ; le régler sur false empêche git add d'ajouter des fichiers à l'annexe.

Cependant, si git-annex peut déterminer qu'un fichier a déjà été annexé, il sera toujours ajouté à l'annexe, même si ces configurations l'empêcheraient normalement. Deux exemples de cela sont l'ajout d'une version modifiée d'un fichier annexé, et le déplacement d'un fichier annexé vers un nouveau nom de fichier et l'ajout de celui-ci.

La configuration git pour utiliser cette commande comme pilote de filtre est la suivante. Elle est normalement configurée pour vous par git-annex init, vous ne devriez donc pas avoir besoin de la configurer manuellement.


[filter "annex"]
smudge = git-annex smudge %f
clean = git-annex smudge --clean %f

Pour que git utilise ce pilote de filtre, il doit être configuré dans le fichier .gitattributes ou dans .git/info/attributes. Ce dernier est normalement configuré lors de l'initialisation d'un dépôt, avec le contenu suivant :


* filter=annex

Le filtre smudge ne fournit pas à git le contenu des fichiers annexés, car ce serait lent et déclencherait des fuites de mémoire dans git. Au lieu de cela, il enregistre les fichiers de l'espace de travail qui doivent être mis à jour, et git annex smudge --update met à jour ultérieurement l'espace de travail pour contenir le contenu. Ceci est exécuté par plusieurs hooks git, y compris post-checkout et post-merge. Cependant, quelques commandes git, notamment git stash et git cherry-pick, n'exécutent aucun hook, donc après avoir utilisé ces commandes, vous pouvez exécuter manuellement git annex smudge --update pour mettre à jour l'espace de travail.

OPTIONS

Les git-annex-common-options(1) peuvent être utilisés.
