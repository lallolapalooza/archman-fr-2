NOM

git-unpack-file - Crée un fichier temporaire avec le contenu d'un blob

SYNOPIS

git unpack-file <blob>

DESCRIPTION

Crée un fichier contenant le contenu du blob spécifié par sha1. Il renvoie le nom du fichier temporaire au format suivant : .merge_file_XXXXX

OPTIONS

<blob>

Doit être un identifiant de blob

Fait partie de la suite git(1)
