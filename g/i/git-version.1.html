NOM

git-version - Afficher les informations de version de Git

SYNTAXE

git version [--build-options]

DESCRIPTION

Sans aucune option, la version de git est imprimée sur la sortie standard.

Notez que git --version est identique à git version car le premier est converti en interne en ce dernier.

OPTIONS

--build-options

Inclure des informations supplémentaires sur la façon dont git a été compilé à des fins de diagnostic.

Les bibliothèques utilisées pour implémenter les algorithmes SHA-1 et SHA-256 sont affichées sous la forme SHA-1: <option> et SHA-256: <option>. Notez que les options SHA-1 SHA1_APPLE, SHA1_OPENSSL, et SHA1_BLK n'utilisent pas d'algorithme de détection de collision et peuvent donc être vulnérables aux attaques connues de collision SHA-1. Lorsqu'une implémentation SHA-1 plus rapide sans détection de collision est utilisée uniquement à des fins non cryptographiques, l'algorithme est affiché sous la forme non-collision-detecting-SHA-1: <option>.
