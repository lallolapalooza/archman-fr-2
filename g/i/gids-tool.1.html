NOM

gids-tool - utilitaire de carte à puce pour les cartes GIDS

SYNTAXE

gids-tool [OPTIONS]

L'utilitaire gids-tool peut être utilisé depuis la ligne de commande pour effectuer diverses opérations sur une carte à puce GIDS.

OPTIONS

-X, --initialize

Initialise le jeton.

--admin-key argument

Définit la clé d'administrateur.

--pin pin

Cette option peut être utilisée pour spécifier la valeur du code PIN sur la ligne de commande. Si la valeur est définie sur env:VARIABLE, la valeur de la variable d'environnement spécifiée est utilisée. Par défaut, le code est demandé sur la ligne de commande si nécessaire.

Notez que sur la plupart des systèmes d'exploitation, tout utilisateur peut afficher la ligne de commande de tout processus sur le système en utilisant des utilitaires tels que ps(1). Par conséquent, vous devriez préférer passer les codes via une variable d'environnement sur un système non sécurisé.

--serial-number argument

Définit le numéro de série.

-U, --unblock

Débloque le code PIN utilisateur après une authentification administrateur.

-C, --change-admin-key

Change la clé d'administrateur.

--new-admin-key argument

Définit la nouvelle clé d'administrateur.

--reader argument, -r argument

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si argument est une ATR, le lecteur avec une carte correspondante sera choisi.

-w, --wait

Attend l'insertion d'une carte.

-v, --verbose

Opération détaillée. Utilisez plusieurs fois pour activer la sortie de débogage.
