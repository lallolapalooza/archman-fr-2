NOM

git-lfs-uninstall - Supprimer la configuration Git LFS

SYNTAXE

git lfs uninstall

DESCRIPTION

Effectue les actions suivantes pour supprimer la configuration Git LFS :

•Supprime les filtres de nettoyage et de salissage « lfs » de la configuration Git globale.
•Désinstalle le hook pré-push de Git LFS si exécuté depuis un dépôt Git.

OPTIONS

--local

Supprime les filtres de salissage et de nettoyage « lfs » de la configuration git du dépôt local, au lieu de la configuration git globale (~/.gitconfig).

--worktree

Supprime les filtres de salissage et de nettoyage « lfs » de la configuration git de l'arbre de travail actuel, au lieu de la configuration git globale (~/.gitconfig) ou de la configuration git du dépôt local ($GIT_DIR/config). Si plusieurs arbres de travail sont utilisés, l'extension de configuration Git worktreeConfig doit être activée pour utiliser cette option. S'il n'y a qu'un seul arbre de travail utilisé, --worktree a le même effet que --local. Cette option n'est disponible que si la version installée de Git est au moins 2.20.0 et prend donc en charge l'extension « worktreeConfig ».

--system

Supprime les filtres de salissage et de nettoyage « lfs » de la configuration git système, au lieu de la configuration git globale (~/.gitconfig).

--skip-repo

Ignore le nettoyage du dépôt local ; à utiliser si vous souhaitez désinstaller les filtres lfs globaux mais ne pas apporter de modifications au dépôt actuel.

VOIR AUSSI

git-lfs-install(1), git-worktree(1).

Fait partie de la suite git-lfs(1).
