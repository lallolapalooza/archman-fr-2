git-branchless-restack(1) Manuel des commandes générales git-branchless-restack(1)

NOM

restack - Corriger les commits abandonnés par une opération de réécriture précédente

SYNTAXE

restack [--hidden] [-f|--force-rewrite] [--in-memory] [--on-disk] [--no-deduplicate-commits] [-m|--merge] [--debug-dump-rebase-constraints] [--debug-dump-rebase-plan] [-h|--help] [REVSETS]

DESCRIPTION

Corriger les commits abandonnés par une opération de réécriture précédente

OPTIONS

--hidden
Inclure les commits cachés dans les résultats de l'évaluation des expressions revset
-f, --force-rewrite
Forcer le déplacement des commits publics, même si d'autres personnes peuvent y avoir accès
--in-memory
Tenter uniquement un rebasage en mémoire. S'il échoue, ne pas tenter de rebasage sur disque
--on-disk
Sauter la tentative d'utilisation d'un rebasage en mémoire, et essayer directement un rebasage sur disque
--no-deduplicate-commits
Ne pas tenter de dédupliquer les commits. Normalement, un commit ayant le même contenu qu'un autre commit qui a déjà été appliqué à la branche cible est ignoré. Si ce drapeau est défini, cette vérification est ignorée
-m, --merge
Tenter de résoudre les conflits de fusion, le cas échéant. Si un conflit de fusion survient et que cette option n'est pas définie, l'opération est abandonnée
--debug-dump-rebase-constraints
Option de débogage. Afficher les contraintes utilisées pour créer le plan de rebasage avant de l'exécuter
--debug-dump-rebase-plan
Option de débogage. Afficher le plan de rebasage qui sera exécuté avant de l'exécuter
-h, --help
Afficher l'aide
[REVSETS] [défaut : draft()]
Les identifiants des commits abandonnés dont les descendants doivent être restackés. S'ils ne sont pas fournis, tous les commits abandonnés sont restackés
