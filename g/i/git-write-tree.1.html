NOM

git-write-tree - Créer un objet arbre à partir de l'index courant

SYNOPSIS

git write-tree [--missing-ok] [--prefix=<préfixe>/]

DESCRIPTION

Crée un objet arbre à partir de l'index courant. Le nom du nouvel objet arbre est affiché sur la sortie standard.

L'index doit être dans un état de fusion complètement résolu.

Conceptuellement, git write-tree synchronise le contenu de l'index courant dans un ensemble de fichiers arbre. Pour que cela corresponde à ce qui se trouve réellement dans votre répertoire, vous devez avoir effectué une phase git update-index avant de faire git write-tree.

OPTIONS

--missing-ok

Normalement, git write-tree s'assure que les objets référencés par le répertoire existent dans la base de données des objets. Cette option désactive cette vérification.

--prefix=<préfixe>/

Écrit un objet arbre qui représente un sous-répertoire <préfixe>. Ceci peut être utilisé pour écrire l'objet arbre d'un sous-projet qui se trouve dans le répertoire spécifié.
