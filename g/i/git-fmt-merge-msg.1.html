NOM

git-fmt-merge-msg - Produire un message de commit de fusion

SYNTAXE

git fmt-merge-msg [-m <message>] [--into-name <branche>] [--log[=<n>] | --no-log]
git fmt-merge-msg [-m <message>] [--log[=<n>] | --no-log] -F <fichier>

DESCRIPTION

Prend la liste des objets fusionnés sur l'entrée standard et produit un message de commit approprié à utiliser pour le commit de fusion, généralement à passer comme argument <message-de-fusion> de git merge.

Cette commande est principalement destinée à un usage interne par des scripts invoquant automatiquement git merge.

OPTIONS

--log[=<n>]

En plus des noms de branches, peuple le message du journal avec des descriptions en une ligne provenant des commits réels qui sont fusionnés. Au plus <n> commits de chaque parent de fusion seront utilisés (20 si <n> est omis). Cela remplace la variable de configuration merge.log.

--no-log

Ne liste pas les descriptions en une ligne des commits réels qui sont fusionnés.

--summary, --no-summary

Synonymes de --log et --no-log ; ceux-ci sont dépréciés et seront supprimés dans le futur.

-m <message>, --message <message>

Utilise <message> à la place des noms de branches pour la première ligne du message du journal. Pour utilisation avec --log.

--into-name <branche>

Prépare le message de fusion comme si l'on fusionnait vers la branche <branche>, au lieu du nom de la vraie branche vers laquelle la fusion est effectuée.

-F <fichier>, --file <fichier>

Prend la liste des objets fusionnés du fichier <fichier> au lieu de l'entrée standard.

CONFIGURATION

merge.branchdesc

En plus des noms de branches, peuple le message du journal avec le texte de description de branche qui leur est associé. Par défaut à faux.

merge.log

En plus des noms de branches, peuple le message du journal avec au plus le nombre spécifié de descriptions en une ligne provenant des commits réels qui sont fusionnés. Par défaut à faux, et vrai est un synonyme pour 20.

merge.suppressDest

En ajoutant un glob qui correspond aux noms des branches d'intégration à cette variable de configuration multi-valeur, le message de fusion par défaut calculé pour les fusions vers ces branches d'intégration omettra "into <nom-branche>" de son titre.

Un élément avec une valeur vide peut être utilisé pour effacer la liste des globs accumulés à partir des entrées de configuration précédentes. Lorsqu'il n'y a pas de variable merge.suppressDest définie, la valeur par défaut de master est utilisée pour des raisons de compatibilité ascendante.

merge.summary

Synonyme de merge.log ; ceci est déprécié et sera supprimé dans le futur.

EXEMPLES

$ git fetch origin master
$ git fmt-merge-msg --log <$GIT_DIR/FETCH_HEAD

Imprimer un message de journal décrivant une fusion de la branche "master" du dépôt distant "origin".
