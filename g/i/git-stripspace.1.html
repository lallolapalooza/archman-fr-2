NOM

git-stripspace - Supprimer les espaces inutiles

SYNOPSIS

git stripspace [-s | --strip-comments]
git stripspace [-c | --comment-lines]

DESCRIPTION

Lire du texte, tel que les messages de commit, les notes, les tags et les descriptions de branches, depuis l'entrée standard et le nettoyer de la manière utilisée par Git.

Sans aucun argument, cela va :

•supprimer les espaces de fin de ligne de toutes les lignes
•réduire les lignes vides consécutives multiples à une seule ligne vide
•supprimer les lignes vides du début et de la fin de l'entrée
•ajouter un \n manquant à la dernière ligne si nécessaire.

Dans le cas où l'entrée est entièrement constituée de caractères d'espacement, aucune sortie ne sera produite.

NOTE: Ceci est destiné au nettoyage des métadonnées. Préférez le mode --whitespace=fix de git-apply(1) pour corriger les espaces des patches ou des fichiers du dépôt.

OPTIONS

-s, --strip-comments

Ignorer et supprimer toutes les lignes commençant par un caractère de commentaire (core.commentChar, par défaut #).

-c, --comment-lines

Ajouter le caractère de commentaire et un espace avant chaque ligne. Les lignes seront automatiquement terminées par un saut de ligne. Sur les lignes vides, seul le caractère de commentaire sera ajouté.

EXEMPLES

Étant donné l'entrée bruyante suivante avec $ indiquant la fin d'une ligne :

|Une brève introduction   $
|   $
|$
|Un nouveau paragraphe$
|# avec une ligne commentée    $
|expliquant beaucoup de choses.$
|$
|# Un ancien paragraphe, également commenté. $
|      $
|La fin.$
|  $

Utilisez git stripspace sans arguments pour obtenir :

|Une brève introduction$
|$
|Un nouveau paragraphe$
|# avec une ligne commentée$
|expliquant beaucoup de choses.$
|$
|# Un ancien paragraphe, également commenté.$
|$
|La fin.$

Utilisez git stripspace --strip-comments pour obtenir :

|Une brève introduction$
|$
|Un nouveau paragraphe$
|expliquant beaucoup de choses.$
|$
|La fin.$
