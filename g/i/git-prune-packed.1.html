NOM

git-prune-packed - Supprime les objets supplémentaires qui sont déjà dans des fichiers pack

SYNTAXE

git prune-packed [-n | --dry-run] [-q | --quiet]

DESCRIPTION

Ce programme recherche dans le répertoire d'objets $GIT_OBJECT_DIRECTORY tous les objets qui existent actuellement à la fois dans un fichier pack et dans les répertoires d'objets indépendants.

Tous ces objets supplémentaires sont supprimés.

Un pack est une collection d'objets, compressés individuellement, avec une compression delta appliquée, stockés dans un seul fichier, avec un fichier d'index associé.

Les packs sont utilisés pour réduire la charge sur les systèmes miroir, les moteurs de sauvegarde, le stockage disque, etc.

OPTIONS

-n, --dry-run

Ne supprime aucun objet, affiche seulement ceux qui auraient été supprimés.

-q, --quiet

Supprime l'indicateur de progression.
