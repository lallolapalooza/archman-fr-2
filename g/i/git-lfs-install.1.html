NOM

git-lfs-install - Installer la configuration Git LFS.

SYNTAXE

git lfs install [options]

DESCRIPTION

Effectue les actions suivantes pour s'assurer que Git LFS est correctement configuré :

•Configure les filtres clean et smudge sous le nom "lfs" dans la configuration globale de Git.
•Installe un hook pre-push pour exécuter git-lfs-pre-push(1) pour le dépôt courant, si exécuté depuis l'intérieur d'un dépôt. Si "core.hooksPath" est configuré dans une quelconque configuration Git (et est supporté, c'est-à-dire que la version de Git installée est au moins 2.9.0), alors le hook pre-push sera installé dans ce répertoire à la place.

OPTIONS

Sans aucune option, git lfs install configurera uniquement les filtres smudge et clean "lfs" s'ils ne sont pas déjà définis.

--force

Définit les filtres smudge et clean "lfs", écrasant les valeurs existantes.

--local

Définit les filtres smudge et clean "lfs" dans la configuration Git du dépôt local, au lieu de la configuration Git globale (~/.gitconfig).

--worktree

Définit les filtres smudge et clean "lfs" dans la configuration Git de l'arbre de travail courant, au lieu de la configuration Git globale (~/.gitconfig) ou de la configuration Git du dépôt local ($GIT_DIR/config). Si plusieurs arbres de travail sont utilisés, l'extension de configuration Git worktreeConfig doit être activée pour utiliser cette option. Si un seul arbre de travail est utilisé, --worktree a le même effet que --local. Cette option n'est disponible que si la version de Git installée est au moins 2.20.0 et supporte donc l'extension "worktreeConfig".

--manual

Affiche des instructions pour mettre à jour manuellement vos hooks afin d'inclure les fonctionnalités de git-lfs. Utilisez cette option si git lfs install échoue en raison de hooks existants et que vous souhaitez conserver leur fonctionnalité.

--system

Définit les filtres smudge et clean "lfs" dans la configuration système de Git, par exemple /etc/gitconfig au lieu de la configuration globale de Git (~/.gitconfig).

--skip-smudge

Ignore le téléchargement automatique des objets lors du clonage ou du pull. Cela nécessite un "git lfs pull" manuel à chaque fois qu'un nouveau commit est extrait de votre dépôt.

--skip-repo

Ignore l'installation des hooks dans le dépôt local ; utilisez cette option si vous souhaitez installer les filtres LFS mais pas modifier les hooks. Il est valide d'utiliser --local, --global ou --system en conjonction avec cette option.

VOIR AUSSI

git-lfs-uninstall(1), git-worktree(1).

Fait partie de la suite git-lfs(1).
