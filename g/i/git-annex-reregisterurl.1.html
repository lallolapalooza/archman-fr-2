NOM

git-annex-reregisterurl - met à jour les informations d'enregistrement d'URL

SYNOPSIS

git annex reregisterurl [clé]

DESCRIPTION

Cette commande de bas niveau met à jour les informations sur les URL qui sont enregistrées pour une clé.

OPTIONS

--move-from=nom|uuid
Pour chaque clé, met à jour les URL actuellement revendiquées par le dépôt distant spécifié pour être utilisées à la place par le dépôt spécial web.
Ceci pourrait être utilisé par exemple lorsqu'un dépôt spécial était nécessaire pour fournir une autorisation afin d'obtenir une URL, mais que l'URL est maintenant devenue publiquement disponible et que le dépôt spécial web peut donc être utilisé.
Notez que, comme git-annex unregisterurl, l'utilisation de cette option désenregistre une URL d'un dépôt spécial, mais ne marque pas le contenu comme étant absent de ce dépôt spécial. Cependant, comme git-annex registerurl, cette option marque le contenu comme étant présent dans le dépôt spécial web.
--batch
En mode entrée par lots, les lignes sont lues depuis l'entrée standard, et chaque ligne doit contenir une clé.
-z
En mode par lots, l'entrée est délimitée par des caractères nuls au lieu des sauts de ligne habituels.
--json
Active la sortie JSON. Ceci est destiné à être analysé par les programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement affichés sur la sortie d'erreur standard sont inclus dans le JSON à la place.
Les git-annex-common-options(1) peuvent également être utilisés.
