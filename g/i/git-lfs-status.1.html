NOM

git-lfs-status - Afficher l'état des fichiers Git LFS dans l'arbre de travail

SYNTAXE

git lfs status [<options>]

DESCRIPTION

Affiche les chemins des objets Git LFS qui

•n'ont pas été envoyés au serveur Git LFS. Ce sont des fichiers volumineux qui seraient téléchargés par git push.
•présentent des différences entre le fichier d'index et le dernier commit HEAD. Ce sont des fichiers volumineux qui seraient validés par git commit.
•présentent des différences entre l'arbre de travail et le fichier d'index. Ce sont des fichiers qui pourraient être ajoutés à l'index à l'aide de git add.

Cette commande doit être exécutée dans un dépôt non nu (non-bare).

OPTIONS

-p, --porcelain

Donne la sortie dans un format facile à analyser pour les scripts.

-j, --json

Donne la sortie dans un format JSON stable pour les scripts.

VOIR AUSSI

git-lfs-ls-files(1).

Fait partie de la suite git-lfs(1).
