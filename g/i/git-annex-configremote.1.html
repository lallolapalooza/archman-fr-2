NOM

git-annex-configremote - modifie la configuration d'un dépôt distant spécial

SYNOPSIS

git annex configremote nom|uuid|desc [param=valeur ...]

DESCRIPTION

Modifie la configuration d'un dépôt distant spécial qui a été configuré auparavant avec git-annex initremote. Le dépôt distant spécial n'a pas besoin d'être activé pour être utilisé dans le dépôt actuel, et cette commande ne l'activera pas.

Cette commande peut actuellement uniquement être utilisée pour modifier la valeur du paramètre autoenable, par ex. "autoenable=false".

Pour modifier d'autres paramètres, utilisez git-annex enableremote

OPTIONS

La plupart des options ne sont pas précédées d'un tiret, et définissent des paramètres du dépôt distant, comme montré ci-dessus.

De plus, les options communes de git-annex-common-options(1) peuvent être utilisées.
