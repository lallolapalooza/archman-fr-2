git-branchless-move(1) Manuel des commandes générales git-branchless-move(1)

NOM

move - Déplacer un sous-arbre de commits d'un emplacement à un autre

SYNTAXE

move [-s|--source] [-b|--base] [-x|--exact] [-d|--dest] [--hidden] [-f|--force-rewrite] [--in-memory] [--on-disk] [--no-deduplicate-commits] [-m|--merge] [--debug-dump-rebase-constraints] [--debug-dump-rebase-plan] [-F|--fixup] [-I|--insert] [-h|--help]

DESCRIPTION

Déplacer un sous-arbre de commits d'un emplacement à un autre.

Par défaut, `git move` tente de déplacer la pile entière actuelle si vous ne fournissez pas l'option `--source` ou `--base` (équivalent à écrire `--base HEAD`).

Par défaut, `git move` tente de rebaser tous les commits en mémoire. Si vous souhaitez forcer un rebasage sur disque, utilisez l'option `--on-disk`. Notez que les hooks `post-commit` ne sont pas appelés pendant les rebasages en mémoire.

OPTIONS

-s, --source=SOURCE
Le commit source à déplacer. Ce commit, ainsi que tous ses descendants, seront déplacés.
-b, --base=BASE
Un commit à l'intérieur d'un sous-arbre à déplacer. Le sous-arbre entier, en partant de la branche principale, sera déplacé, pas seulement les commits descendants de ce commit.
-x, --exact=EXACT
Un ensemble de commits spécifiques à déplacer. Ils seront retirés de leurs emplacements actuels et tous les enfants non déplacés seront déplacés vers leur ancêtre non déplacé le plus proche.
-d, --dest=DEST
Le commit de destination sur lequel tous les commits sources seront déplacés. S'il n'est pas fourni, utilise le commit actuel par défaut.
--hidden
Inclure les commits cachés dans les résultats de l'évaluation des expressions revset.
-f, --force-rewrite
Forcer le déplacement de commits publics, même si d'autres personnes peuvent avoir accès à ces commits.
--in-memory
Tenter uniquement d'effectuer un rebasage en mémoire. S'il échoue, ne pas tenter de rebasage sur disque.
--on-disk
Ignorer la tentative d'utilisation d'un rebasage en mémoire, et essayer directement un rebasage sur disque.
--no-deduplicate-commits
Ne pas tenter de dédupliquer les commits. Normalement, un commit ayant le même contenu qu'un autre commit déjà appliqué à la branche cible est ignoré. Si cette option est définie, ce contrôle est ignoré.
-m, --merge
Tenter de résoudre les conflits de fusion, le cas échéant. Si un conflit de fusion survient et que cette option n'est pas définie, l'opération est annulée.
--debug-dump-rebase-constraints
Option de débogage. Afficher les contraintes utilisées pour créer le plan de rebasage avant de l'exécuter.
--debug-dump-rebase-plan
Option de débogage. Afficher le plan de rebasage qui sera exécuté avant de l'exécuter.
-F, --fixup
Combiner les commits déplacés et les écraser dans le commit de destination.
-I, --insert
Insérer le sous-arbre entre la destination et ses enfants, le cas échéant. Uniquement supporté si le sous-arbre déplacé a une seule tête.
-h, --help
Afficher l'aide (voir un résumé avec '-h').
