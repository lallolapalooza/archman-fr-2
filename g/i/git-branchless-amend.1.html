git-branchless-amend(1) Manuel des commandes générales git-branchless-amend(1)

NOM

amend - Modifier le commit HEAD actuel

SYNOPSIS

amend [-f|--force-rewrite] [--in-memory] [--on-disk] [--no-deduplicate-commits] [-m|--merge] [--debug-dump-rebase-constraints] [--debug-dump-rebase-plan] [--reparent] [-h|--help]

DESCRIPTION

Modifier le commit HEAD actuel

OPTIONS

-f, --force-rewrite
Forcer le déplacement de commits publics, même si d'autres personnes peuvent y avoir accès
--in-memory
Essayer uniquement d'effectuer un rebase en mémoire. S'il échoue, ne pas essayer de rebase sur disque
--on-disk
Ignorer la tentative d'utilisation d'un rebase en mémoire et essayer directement un rebase sur disque
--no-deduplicate-commits
Ne pas essayer de dédupliquer les commits. Normalement, un commit ayant le même contenu qu'un autre commit déjà appliqué à la branche cible est ignoré. Si défini, ce drapeau ignore cette vérification
-m, --merge
Essayer de résoudre les conflits de fusion, le cas échéant. Si un conflit de fusion survient et que cette option n'est pas définie, l'opération est abandonnée
--debug-dump-rebase-constraints
Option de débogage. Afficher les contraintes utilisées pour créer le plan de rebase avant de l'exécuter
--debug-dump-rebase-plan
Option de débogage. Afficher le plan de rebase qui sera exécuté avant de l'exécuter
--reparent
Modifier le contenu du commit HEAD actuel, mais conserver exactement le même contenu des commits descendants (c'est-à-dire les "reparenter"). Cela peut être utile lors de l'application de changements de formatage ou de refactorisation
-h, --help
Afficher l'aide
amend
