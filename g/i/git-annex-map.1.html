NOM

git-annex-map - génère une carte des dépôts

SYNTAXE

git annex map

DESCRIPTION

Vous aide à suivre vos dépôts et les connexions entre eux, en allant voir tous ceux auxquels il peut accéder, et en générant un fichier Graphviz qui représente tout cela. Si la commande xdot ou dot est disponible, elle est utilisée pour afficher le fichier sur votre écran.

Cette commande se connecte uniquement aux hôtes auxquels l'hôte sur lequel elle est exécutée peut se connecter directement. Elle n'essaie pas de passer par des hôtes intermédiaires. Elle pourrait donc ne pas montrer toutes les connexions entre les dépôts du réseau.

De plus, si la connexion à un hôte nécessite un mot de passe, vous pourrez avoir à le saisir plusieurs fois pendant la construction de la carte.

Notez que cette sous-commande peut être utilisée pour visualiser n'importe quel dépôt git ; elle n'est pas limitée aux dépôts git-annex.

LÉGENDE

Les ovales représentent les dépôts. Blanc pour ordinaire, vert pour fiable, rouge pour non fiable, et gris pour mort.

Les flèches entre les dépôts représentent des connexions via des remotes git.

Les boîtes bleu clair représentent les hôtes qui ont été cartographiés, et contiennent les dépôts sur cet hôte.

OPTIONS

--fast
N'affiche pas le fichier Graphviz généré, mais l'enregistre pour une utilisation ultérieure.
--json
Génère la carte sous forme d'objet JSON.
Les git-annex-common-options(1) peuvent également être utilisées.
