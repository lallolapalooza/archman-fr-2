git-branchless-sync(1) Manuel des commandes générales git-branchless-sync(1)

NOM

sync - Déplace toutes les piles de commits locales au-dessus de la branche principale

SYNTAXE

sync [-p|--pull] [-f|--force-rewrite] [--in-memory] [--on-disk] [--no-deduplicate-commits] [-m|--merge] [--debug-dump-rebase-constraints] [--debug-dump-rebase-plan] [--hidden] [-h|--help] [REVSETS]

DESCRIPTION

Déplace toutes les piles de commits locales au-dessus de la branche principale

OPTIONS

-p, --pull
Exécute `git fetch` pour mettre à jour les références distantes avant d'effectuer la synchronisation
-f, --force-rewrite
Force le déplacement des commits publics, même si d'autres personnes peuvent y avoir accès
--in-memory
Tente uniquement d'effectuer un rebase en mémoire. S'il échoue, n'essaie pas de rebase sur disque
--on-disk
Ignore la tentative d'utilisation d'un rebase en mémoire et essaie directement un rebase sur disque
--no-deduplicate-commits
Ne tente pas de dédupliquer les commits. Normalement, un commit ayant le même contenu qu'un autre commit déjà appliqué à la branche cible est ignoré. Si défini, ce drapeau ignore cette vérification
-m, --merge
Tente de résoudre les conflits de fusion, le cas échéant. Si un conflit de fusion survient et que cette option n'est pas définie, l'opération est abandonnée
--debug-dump-rebase-constraints
Option de débogage. Affiche les contraintes utilisées pour créer le plan de rebase avant de l'exécuter
--debug-dump-rebase-plan
Option de débogage. Affiche le plan de rebase qui sera exécuté avant de l'exécuter
--hidden
Inclut les commits cachés dans les résultats de l'évaluation des expressions revset
-h, --help
Affiche l'aide
[REVSETS]
Les commits dont les piles seront déplacées au-dessus de la branche principale. Si aucun commit n'est fourni, tous les commits brouillons seront synchronisés
