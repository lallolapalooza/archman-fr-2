NOM

git-bug-bridge-new - Configurer un nouveau pont

SYNTAXE

git-bug bridge new [options]

DESCRIPTION

Configurer un nouveau pont en passant des options ou/et en utilisant les invites interactives du terminal. Vous pouvez éviter toutes les invites du terminal en passant toutes les options nécessaires pour configurer votre pont.

OPTIONS

-n, --name="" Un nom distinctif pour identifier le pont

-t, --target="" La cible du pont. Les valeurs valides sont [github,gitlab,jira,launchpad-preview]

-u, --url="" L'URL du dépôt distant

-b, --base-url="" L'URL de base de votre gestionnaire de tickets distant

-l, --login="" Le login sur votre gestionnaire de tickets distant

-c, --credential="" L'identifiant ou le préfixe d'une credential déjà connue pour votre gestionnaire de tickets distant (voir "git-bug bridge auth")

--token="" Un jeton d'authentification brut pour le gestionnaire de tickets distant

--token-stdin[=false] Lire le jeton depuis stdin et ignorer --token

-o, --owner="" Le propriétaire du dépôt distant

-p, --project="" Le nom du dépôt distant

--non-interactive[=false] Ne pas demander d'entrée à l'utilisateur

-h, --help[=false] Aide pour new

EXEMPLE

# Exemple interactif
[1]: github
[2]: gitlab
[3]: jira
[4]: launchpad-preview

nom [défaut]: défaut
Projets détectés :

[0]: Autre projet
Sélectionner une option : 1
[1]: jeton fourni par l'utilisateur
[2]: création de jeton interactive
Sélectionner une option : 1
Vous pouvez générer un nouveau jeton en visitant https://github.com/settings/tokens.
Choisissez 'Générer un nouveau jeton' et définissez le champ d'accès nécessaire pour votre dépôt.
Le champ d'accès dépend du type de dépôt.
Public :
	- 'public_repo' : pour pouvoir lire les dépôts publics
Privé :
	- 'repo'       : pour pouvoir lire les dépôts privés
Entrez le jeton : 87cf5c03b64029f18ea5f9ca5679daa08ccbd700
Pont configuré avec succès : défaut
# Pour GitHub
git bug bridge new \
    --name=défaut \
    --target=github \
    --owner=propriétaire-exemple
    --project=dépôt-exemple \
    --token=$JETON
# Pour Launchpad
git bug bridge new \
    --name=défaut \
    --target=launchpad-preview \
    --url=https://bugs.launchpad.net/ubuntu/
# Pour Gitlab
git bug bridge new \
    --name=défaut \
    --target=gitlab \
    --url=https://github.com/exemple-org/exemple-dépôt \
    --token=$JETON
