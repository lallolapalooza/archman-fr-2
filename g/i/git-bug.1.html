NOM

git-bug - Un suivi de bogues intégré à Git

SYNTAXE

git-bug [flags]

DESCRIPTION

git-bug est un suivi de bogues intégré à git.

git-bug utilise les objets git pour stocker le suivi des bogues, séparément de l'historique des fichiers. Comme les bogues sont des objets git réguliers, ils peuvent être poussés et tirés depuis/vers le même dépôt distant que vous utilisez déjà pour collaborer avec d'autres personnes.

OPTIONS

-h, --help[=false] aide pour git-bug
