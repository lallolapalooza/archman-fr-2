NOM

git-verify-commit - Vérifier la signature GPG des commits

SYNTAXE

git verify-commit [-v | --verbose] [--raw] <commit>...

DESCRIPTION

Valide la signature GPG créée par git commit -S sur les objets commit donnés en ligne de commande.

OPTIONS

--raw

Affiche la sortie brute de statut gpg sur la sortie d'erreur standard au lieu de la sortie lisible par l'homme normale.

-v, --verbose

Affiche le contenu de l'objet commit avant de le valider.
