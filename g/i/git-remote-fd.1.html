NOM

git-remote-fd - Refléter le flux de transport intelligent à l'appelant

SYNTAXE

"fd:<infd>[,<outfd>][/<quelconque>]" (comme URL)

DESCRIPTION

Ce gestionnaire utilise des descripteurs de fichiers spécifiés pour se connecter à un serveur Git distant. Ceci n'est pas destiné aux utilisateurs finaux mais aux programmes et scripts appelant git fetch, push, ou archive.

Si seul <infd> est donné, il est supposé être un socket bidirectionnel connecté à un serveur Git distant (git-upload-pack, git-receive-pack, ou git-upload-archive). Si <infd> et <outfd> sont tous deux donnés, ils sont supposés être des tubes connectés à un serveur Git distant (<infd> étant le tube entrant et <outfd> le tube sortant).

Il est supposé que toute procédure de négociation a déjà été effectuée (comme l'envoi d'une requête de service pour git://) avant que ce gestionnaire ne soit démarré.

<quelconque> peut être n'importe quelle chaîne de caractères. Elle est ignorée. Elle est destinée à fournir des informations à l'utilisateur dans l'URL au cas où cette URL serait affichée dans un certain contexte.

VARIABLES D'ENVIRONNEMENT

GIT_TRANSLOOP_DEBUG

Si défini, imprime des informations de débogage sur diverses lectures/écritures.

EXEMPLES

git fetch fd::17 master

Récupère master, en utilisant le descripteur de fichier #17 pour communiquer avec git-upload-pack.

git fetch fd::17/foo master

Identique à ci-dessus.

git push fd::7,8 master (comme URL)

Pousse master, en utilisant le descripteur de fichier #7 pour lire les données de git-receive-pack et le descripteur de fichier #8 pour écrire des données dans le même service.

git push fd::7,8/bar master

Identique à ci-dessus.
