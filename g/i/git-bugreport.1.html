NOM

git-bugreport - Collecte les informations pour que l'utilisateur dépose un rapport de bug

SYNOPIS

git bugreport [(-o | --output-directory) <chemin>]
                [(-s | --suffix) <format> | --no-suffix]
                [--diagnose[=<mode>]]

DESCRIPTION

Collecte des informations sur la machine de l'utilisateur, le client Git et l'état du dépôt, en plus d'un formulaire demandant des informations sur le comportement observé par l'utilisateur, et les stocke dans un seul fichier texte que l'utilisateur peut ensuite partager, par exemple sur la liste de diffusion Git, afin de signaler un bug observé.

Les informations suivantes sont demandées à l'utilisateur :

•Étapes de reproduction
•Comportement attendu
•Comportement actuel

Les informations suivantes sont capturées automatiquement :

•git version --build-options
•Noms système, version, numéro de version et chaînes de machine de uname
•Chaîne d'informations spécifique au compilateur
•Une liste des hooks activés
•$SHELL

Des informations supplémentaires peuvent être collectées dans une archive zip séparée en utilisant l'option --diagnose, et peuvent être jointes au document du rapport de bug pour fournir un contexte supplémentaire aux lecteurs.

Cet outil est lancé via le processus de configuration typique de Git, ce qui signifie que dans certains cas, il pourrait ne pas pouvoir être lancé - par exemple, si un fichier de configuration pertinent est illisible. Dans ce genre de scénario, il peut être utile de rassembler manuellement le type d'informations énumérées ci-dessus lors d'une demande d'aide.

OPTIONS

-o <chemin>, --output-directory <chemin>

Place le fichier du rapport de bug résultant dans <chemin> au lieu du répertoire courant.

-s <format>, --suffix <format>, --no-suffix

Spécifie un suffixe alternatif pour le nom du rapport de bug, pour créer un fichier nommé git-bugreport-<suffix-formaté>. Ceci devrait prendre la forme d'une chaîne de format strftime(3) ; l'heure locale actuelle sera utilisée. --no-suffix désactive le suffixe et le fichier est simplement nommé git-bugreport sans aucune mesure de désambiguïsation.

--no-diagnose, --diagnose[=<mode>]

Crée une archive zip d'informations supplémentaires sur la machine de l'utilisateur, le client Git et l'état du dépôt. L'archive est écrite dans le même répertoire de sortie que le rapport de bug et est nommée git-diagnostics-<suffix-formaté>.

Sans spécifier de mode, l'archive de diagnostic contiendra l'ensemble par défaut des statistiques rapportées par git diagnose. Une valeur de mode optionnelle peut être spécifiée pour changer les informations incluses dans l'archive. Voir git-diagnose(1) pour la liste des valeurs valides pour mode et les détails de leur utilisation.
