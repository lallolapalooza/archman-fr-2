NOM

git-credential-cache--daemon - Stocker temporairement les informations d'identification de l'utilisateur en mémoire

SYNOPSIS

git credential-cache--daemon [--debug] <chemin-socket>

DESCRIPTION


Note

Vous ne voudrez probablement pas invoquer cette commande vous-même ; elle est démarrée automatiquement lorsque vous utilisez git-credential-cache(1).

Cette commande écoute sur le socket de domaine Unix spécifié par <chemin-socket> pour les clients de git-credential-cache. Les clients peuvent stocker et récupérer des informations d'identification. Chaque information d'identification est conservée pendant un délai d'attente spécifié par le client ; une fois qu'aucune information d'identification n'est conservée, le démon se termine.

Si l'option --debug est spécifiée, le démon ne ferme pas son flux stderr et peut y afficher des diagnostics supplémentaires même après avoir commencé à écouter les clients.
