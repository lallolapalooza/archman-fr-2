NOM

git-mergetool--lib - Scriptlets communs pour les outils de fusion Git

SYNOPSIS

TOOL_MODE=(diff|merge) . "$(git --exec-path)/git-mergetool--lib"

DESCRIPTION

Ceci n'est pas une commande que l'utilisateur final voudrait exécuter. Jamais. Cette documentation est destinée aux personnes qui étudient les scripts de type Porcelain et/ou qui en écrivent de nouveaux.

Le scriptlet git-mergetool--lib est conçu pour être sourcé (en utilisant .) par d'autres scripts shell afin de configurer des fonctions pour travailler avec les outils de fusion Git.

Avant de sourcer git-mergetool--lib, votre script doit définir TOOL_MODE pour définir le mode d'opération des fonctions listées ci-dessous. diff et merge sont des valeurs valides.

FONCTIONS

get_merge_tool

Retourne un outil de fusion. Le code de retour est 1 si nous avons retourné un outil de fusion deviné, sinon 0. $GIT_MERGETOOL_GUI peut être défini sur true pour rechercher l'outil graphique approprié.

get_merge_tool_cmd

Retourne la commande personnalisée pour un outil de fusion.

get_merge_tool_path

Retourne le chemin personnalisé pour un outil de fusion.

initialize_merge_tool

Met des fonctions spécifiques à l'outil de fusion dans la portée pour qu'elles puissent être utilisées ou remplacées.

run_merge_tool

Lance un outil de fusion étant donné le nom de l'outil et un drapeau vrai/faux pour indiquer si une base de fusion est présente. $MERGED, $LOCAL, $REMOTE, et $BASE doivent être définis pour être utilisés par l'outil de fusion.
