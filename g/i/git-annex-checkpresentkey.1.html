NOM

git-annex-checkpresentkey - vérifier si une clé est présente sur un dépôt distant

SYNOPSIS

git annex checkpresentkey clé [dépôt]

DESCRIPTION

Cette commande de bas niveau vérifie si le contenu de la clé spécifiée est présent dans le dépôt distant spécifié.

Lorsqu'aucun dépôt distant n'est spécifié, il vérifie si le contenu de la clé est présent dans n'importe quel dépôt distant accessible.

Se termine avec le code 0 si le contenu est vérifié comme étant présent dans le dépôt distant, ou 1 s'il est vérifié comme étant absent du dépôt distant. En cas de problème, le code de sortie spécial 100 est utilisé et un message d'erreur est affiché sur stderr.

OPTIONS

--batch
Active le mode batch. Dans ce mode, la clé n'est pas spécifiée sur la ligne de commande, mais le dépôt peut l'être. Les lignes contenant des clés sont lues depuis stdin, et une ligne est générée avec "1" si la clé est vérifiée comme présente, et "0" sinon.
Les options git-annex-common-options(1) peuvent aussi être utilisées.
