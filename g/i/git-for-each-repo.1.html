NOM

git-for-each-repo - Exécute une commande Git sur une liste de dépôts

SYNTAXE

git for-each-repo --config=<config> [--] <arguments>

DESCRIPTION

Exécute une commande Git sur une liste de dépôts. Les arguments après les options connues ou l'indicateur -- sont utilisés comme arguments pour le sous-processus Git.

CETTE COMMANDE EST EXPÉRIMENTALE. SON COMPORTEMENT PEUT CHANGER.

Par exemple, nous pourrions exécuter la maintenance sur chacun d'une liste de dépôts stockés dans une variable de configuration maintenance.repo en utilisant

git for-each-repo --config=maintenance.repo maintenance run

Cela exécutera git -C <repo> maintenance run pour chaque valeur <repo> de la variable de configuration multivaluée maintenance.repo.

OPTIONS

--config=<config>

Utilise la variable de configuration donnée comme une liste multivaluée stockant des chemins d'accès absolus. Itère sur cette liste de chemins pour exécuter les arguments donnés.

Ces valeurs de configuration sont chargées à partir de la configuration Git système, globale et locale, selon leur disponibilité. Si git for-each-repo est exécuté dans un répertoire qui n'est pas un dépôt Git, seule la configuration système et globale est utilisée.

--keep-going

Continue avec les dépôts restants si la commande a échoué sur un dépôt. Le code de sortie indiquera toujours que l'opération globale n'a pas réussi.

Notez que le code de sortie exact de la commande défaillante n'est pas transmis comme code de sortie de la commande for-each-repo : Si la commande a échoué dans l'un des dépôts spécifiés, le code de sortie global sera 1.

COMPORTEMENT DU SOUS-PROCESSUS

Si un sous-processus git -C <repo> <arguments> retourne un code de sortie non nul, alors le processus git for-each-repo retourne ce code de sortie sans exécuter plus de sous-processus.

Chaque sous-processus git -C <repo> <arguments> hérite des descripteurs de fichiers standards stdin, stdout et stderr.
