NOM

git-check-mailmap - Afficher les noms et adresses électroniques canoniques des contacts

SYNOPIS

git check-mailmap [<options>] <contact>...

DESCRIPTION

Pour chaque “Nom <utilisateur@hote>”, “<utilisateur@hote>”, ou “utilisateur@hote” de la ligne de commande ou de l'entrée standard (lors de l'utilisation de --stdin), rechercher le nom et l'adresse électronique canoniques de la personne (voir «MAPPAGE AUTEURS» ci-dessous). Si trouvé, les afficher ; sinon, afficher l'entrée telle quelle.

OPTIONS

--stdin

Lire les contacts, un par ligne, depuis l'entrée standard après avoir épuisé les contacts fournis en ligne de commande.

--mailmap-file=<fichier>

En plus de tous les fichiers mailmap configurés, lire le fichier mailmap spécifié. Les entrées de ce fichier ont priorité sur les entrées du fichier mailmap par défaut ou de tout fichier mailmap configuré.

--mailmap-blob=<blob>

Comme --mailmap-file, mais considérer la valeur comme une référence à un blob dans le dépôt. Si --mailmap-file et --mailmap-blob sont spécifiés, les entrées de --mailmap-file auront priorité.

SORTIE

Pour chaque contact, une seule ligne est produite, terminée par un saut de ligne. Si le nom est fourni ou connu du mailmap, “Nom <utilisateur@hote>” est affiché ; sinon, seul “<utilisateur@hote>” est affiché.

CONFIGURATION

Voir mailmap.file et mailmap.blob dans git-config(1) pour savoir comment spécifier un fichier cible .mailmap personnalisé ou un objet.

MAPPAGE AUTEURS

Voir gitmailmap(5).
