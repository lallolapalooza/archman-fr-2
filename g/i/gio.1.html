DESCRIPTION

gio est un utilitaire qui rend de nombreuses fonctionnalités GIO disponibles depuis la ligne de commande. Ce faisant, il fournit des commandes similaires aux utilitaires traditionnels, mais vous permet d'utiliser des emplacements GIO au lieu de fichiers locaux : par exemple, vous pouvez utiliser quelque chose comme smb://serveur/ressource/fichier.txt comme emplacement.

Les noms de fichiers simples contenant un deux-points seront interprétés comme des URI avec un protocole inconnu. Pour éviter cela, préfixez-les avec un chemin tel que ./, ou avec le protocole file:.

Les volumes, lecteurs et montages sont limités à ceux considérés comme intéressants pour l'utilisateur, tels que les lecteurs amovibles. Les montages système ne seront pas affichés, ce qui signifie que la sortie de gio mount n'est pas équivalente à la sortie d'outils comme fdisk, et gio monitor --mounts ne listera que les événements pertinents pour les montages sélectionnés.

COMMANDES

help COMMANDE

Affiche une brève description des commandes disponibles ou fournit une aide détaillée sur une commande spécifique.

version

Affiche la version de GLib à laquelle gio appartient.

cat EMPLACEMENT…

Concatène les fichiers donnés et les affiche sur la sortie standard.

La commande cat fonctionne comme l'utilitaire traditionnel cat.

Remarque : redirigez simplement via cat si vous avez besoin de ses options de mise en forme comme -n, -T ou autres.

copy [OPTION…] SOURCE… DESTINATION

Copie un ou plusieurs fichiers de SOURCE vers DESTINATION. Si plusieurs sources sont spécifiées, la destination doit être un répertoire.

La commande copy est similaire à l'utilitaire traditionnel cp.

Options

-T, --no-target-directory

Ne pas copier dans DESTINATION même s'il s'agit d'un répertoire.

-p, --progress

Afficher la progression.

-i, --interactive

Demander une confirmation avant d'écraser les fichiers.

--preserve

Conserver tous les attributs des fichiers copiés.

-b, --backup

Créer des sauvegardes des fichiers de destination existants.

-P, --no-dereference

Ne jamais suivre les liens symboliques.

--default-permissions

Utiliser les permissions par défaut du processus courant pour le fichier de destination, plutôt que de copier les permissions du fichier source.

info [OPTION…] EMPLACEMENT…

Affiche des informations sur les emplacements donnés.

La commande info est similaire à l'utilitaire traditionnel ls.

Options

-w, --query-writable

Lister les attributs inscriptibles.

-f, --filesystem

Afficher les informations sur le système de fichiers sur lequel résident les emplacements donnés.

-a, --attributes=<ATTRIBUTS>

Les attributs à récupérer.

Les attributs peuvent être spécifiés par leur nom GIO, par exemple standard::icon, ou juste par leur espace de noms, par exemple unix, ou par *, qui correspond à tous les attributs. Plusieurs attributs ou groupes d'attributs peuvent être spécifiés, séparés par des virgules.

Par défaut, tous les attributs sont listés.

-n, --nofollow-symlinks

Ne pas suivre les liens symboliques.

launch FICHIER-DESKTOP [ARG-FICHIER…]

Lance un fichier de bureau depuis n'importe quel emplacement donné.

La commande launch étend le comportement de la commande open en permettant de lancer n'importe quel fichier de bureau, pas seulement ceux enregistrés comme gestionnaires de fichiers.

list [OPTION…] [EMPLACEMENT…]

Liste le contenu des emplacements donnés. Si aucun emplacement n'est donné, le contenu du répertoire courant est affiché.

La commande list est similaire à l'utilitaire traditionnel ls.

Options

-a, --attributes=<ATTRIBUTS>

Les attributs à récupérer.

Les attributs peuvent être spécifiés par leur nom GIO, par exemple standard::icon, ou juste par leur espace de noms, par exemple unix, ou par *, qui correspond à tous les attributs. Plusieurs attributs ou groupes d'attributs peuvent être spécifiés, séparés par des virgules.

Par défaut, tous les attributs sont listés.

-h, --hidden

Afficher les fichiers cachés.

-l, --long

Utiliser un format de liste long.

-n, --nofollow-symlinks

Ne pas suivre les liens symboliques.

-d, --print-display-names

Afficher les noms d'affichage.

-u, --print-uris

Afficher les URI complets.

mime TYPE-MIME [GESTIONNAIRE]

Si aucun gestionnaire n'est donné, la commande mime liste les applications enregistrées et recommandées pour le type MIME. Si un gestionnaire est donné, il est défini comme le gestionnaire par défaut pour le type MIME.

Les gestionnaires doivent être spécifiés par le nom de leur fichier de bureau, y compris l'extension. Exemple : org.gnome.gedit.desktop.

mkdir [OPTION…] EMPLACEMENT…

Crée des répertoires.

La commande mkdir est similaire à l'utilitaire traditionnel mkdir.

Options

-p, --parent

Créer les répertoires parents si nécessaire.

monitor [OPTION…] [EMPLACEMENT…]

Surveille les fichiers ou répertoires pour détecter les changements, tels que la création, la suppression, les modifications de contenu et d'attributs, ainsi que les opérations de montage et de démontage affectant les emplacements surveillés.

La commande monitor utilise les API de surveillance de fichiers GIO pour accomplir sa tâche. GIO a différentes implémentations pour différentes plateformes. L'implémentation la plus courante sous Linux utilise inotify.

Options

-d, --dir=<EMPLACEMENT>

Surveiller l'emplacement donné comme un répertoire. Normalement, le type de fichier est utilisé pour déterminer s'il faut surveiller comme un fichier ou comme un répertoire.

-f, --file=<EMPLACEMENT>

Surveiller l'emplacement donné comme un fichier. Normalement, le type de fichier est utilisé pour déterminer s'il faut surveiller comme un fichier ou comme un répertoire.

--mounts

Surveiller les événements de montage et de démontage.

--watch-directory

Surveiller le répertoire spécifié pour les événements de création et de suppression de fichiers, ainsi que les changements de nom.

mount [OPTION…] [EMPLACEMENT…]

Affiche les volumes, lecteurs et montages disponibles. Si aucun emplacement n'est donné, affiche les montages du système.

La commande mount est similaire à la commande mount traditionnelle, mais elle peut fonctionner avec des emplacements GIO.

Options

-u, --unmount

Démonte les volumes spécifiés.

-m, --mount

Monte les volumes spécifiés.

-a, --all

Liste tous les montages.

-d, --device=<DEVICE>

Spécifie le périphérique à monter ou démonter.

-t, --type=<TYPE>

Spécifie le type de système de fichiers.

-o, --options=<OPTIONS>

Spécifie les options de montage.

move [OPTION…] SOURCE… DESTINATION

Déplace un ou plusieurs fichiers de SOURCE vers DESTINATION. Si plusieurs sources sont spécifiées, la destination doit être un répertoire.

La commande move est similaire à l'utilitaire traditionnel mv.

Options

-T, --no-target-directory

Ne pas déplacer dans DESTINATION même s'il s'agit d'un répertoire.

-i, --interactive

Demander une confirmation avant d'écraser les fichiers.

--preserve

Conserver tous les attributs des fichiers déplacés.

-b, --backup

Créer des sauvegardes des fichiers de destination existants.

-P, --no-dereference

Ne jamais suivre les liens symboliques.

--default-permissions

Utiliser les permissions par défaut du processus courant pour le fichier de destination, plutôt que de copier les permissions du fichier source.

open EMPLACEMENT…

Ouvre les fichiers ou URI donnés avec l'application par défaut.

La commande open est similaire à la commande xdg-open ou gvfs-open.

rename EMPLACEMENT NOM

Renomme le fichier ou le répertoire donné en NOM.

La commande rename est similaire à la commande mv, mais elle ne renomme qu'un seul fichier à la fois.

remove [OPTION…] EMPLACEMENT…

Supprime les fichiers ou répertoires donnés.

La commande remove est similaire à l'utilitaire traditionnel rm.

Options

-r, --recursive

Supprimer récursivement les répertoires.

-f, --force

Forcer la suppression sans demander de confirmation.

-i, --interactive

Demander une confirmation avant chaque suppression.

save [OPTION…] DESTINATION

Sauvegarde le contenu de l'entrée standard dans la DESTINATION.

La commande save est similaire à l'utilitaire traditionnel tee, mais elle ne peut pas écrire dans plusieurs fichiers.

set [OPTION…] EMPLACEMENT ATTRIBUT VALEUR…

Définit les attributs des emplacements donnés.

Les attributs peuvent être spécifiés par leur nom GIO, par exemple standard::icon, ou juste par leur espace de noms, par exemple unix. Plusieurs attributs peuvent être spécifiés.

trash [OPTION…] [EMPLACEMENT…]

Déplace les fichiers ou répertoires donnés vers la corbeille.

La commande trash est similaire à la commande gvfs-trash.

Options

-f, --force

Forcer le déplacement vers la corbeille sans demander de confirmation.

tree [OPTION…] [EMPLACEMENT…]

Affiche les répertoires sous forme d'arbre. Si aucun emplacement n'est donné, affiche le répertoire courant.

La commande tree est similaire à l'utilitaire traditionnel tree.

Options

-a, --attributes=<ATTRIBUTS>

Les attributs à afficher.

Par défaut, seuls les noms de fichiers et de répertoires sont affichés.

-d, --directories-only

N'afficher que les répertoires.

-L, --level=<LEVEL>

Niveau de profondeur à afficher.

trash [OPTION…] [LOCATIO

N…]
Envoie des fichiers ou des répertoires vers la « corbeille » ou les restaure depuis la « corbeille ». Cela peut être un dossier différent selon l'emplacement du fichier, et tous les systèmes de fichiers ne prennent pas en charge ce concept. Dans le cas courant où le fichier se trouve dans le répertoire personnel d'un utilisateur, le dossier de la corbeille est $XDG_DATA_HOME/Trash.

Notez que le déplacement de fichiers vers la corbeille ne libère pas d'espace sur le système de fichiers tant que la « corbeille » n'est pas vidée. Si vous êtes intéressé par la suppression irréversible d'un fichier, consultez la commande

remove.

L'inspection et le vidage de la « corbeille » sont normalement pris en charge par les gestionnaires de fichiers graphiques tels que Nautilus, mais vous pouvez aussi voir la corbeille avec la commande : gio trash --list ou gio list tr
