Remarque : actuellement, il n'y a pas d'interopérabilité entre les dépôts SHA-256 et les dépôts SHA-1. Par le passé, nous avons averti que les dépôts SHA-256 pourraient nécessiter plus tard des changements incompatibles avec les versions antérieures lorsque nous introduirions de telles fonctionnalités d'interopérabilité. Aujourd'hui, nous n'attendons que des changements compatibles. De plus, si de tels changements s'avéraient nécessaires, on peut s'attendre à ce que les dépôts SHA-256 créés avec la version actuelle de Git soient utilisables par les futures versions de Git sans perte de données. --ref-format= <format> Spécifier le <for

Spécifie le répertoire à partir duquel les modèles seront copiés.

init.defaultBranch

Permet de remplacer le nom de la branche par défaut, par ex. lors de l'initialisation d'un nouveau dépôt.

init.defaultObjectFormat

Permet de remplacer le format d'objet par défaut pour les nouveaux dépôts. Voir --object-format= dans git-init(1). L'option de ligne de commande ainsi que la variable d'environnement GIT_DEFAULT_HASH ont la priorité sur cette configuration.

init.defaultRefFormat

Permet de remplacer le format de stockage des références par défaut pour les nouveaux dépôts. Voir --ref-format= dans git-init(1). L'option de ligne de commande ainsi que la GIT_DEFAULT_REF_FORMAT variable d'environnement ont la priorité sur cette configuration.
