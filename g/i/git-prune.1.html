NOM

git-prune - Supprimer tous les objets inatteignables de la base de données d'objets

SYNTAXE

git prune [-n] [-v] [--progress] [--expire <temps>] [--] [<tête>...]

DESCRIPTION


Note

Dans la plupart des cas, les utilisateurs devraient exécuter git gc, qui appelle git prune. Voir la section « NOTES », ci-dessous.

Ceci exécute git fsck --unreachable en utilisant toutes les références disponibles dans refs/, éventuellement avec un ensemble supplémentaire d'objets spécifiés sur la ligne de commande, et supprime tous les objets décompressés inatteignables par l'un de ces objets de tête de la base de données d'objets. De plus, il supprime les objets décompressés qui sont également trouvés dans des packs en exécutant git prune-packed. Il supprime également les entrées de .git/shallow qui ne sont atteignables par aucune référence.

Notez que les objets empaquetés inatteignables resteront. Si ce n'est pas souhaité, voir git-repack(1).

OPTIONS

-n, --dry-run

Ne rien supprimer ; signaler seulement ce qui serait supprimé.

-v, --verbose

Signaler tous les objets supprimés.

--progress

Afficher la progression.

--expire <temps>

N'expirer que les objets lâches plus anciens que <temps>.

--

Ne pas interpréter les arguments suivants comme des options.

<tête>...

En plus des objets atteignables par l'une de nos références, conserver les objets atteignables par les <têtes> listées.

EXEMPLES

Pour supprimer les objets non utilisés par votre dépôt ou par un autre qui emprunte à votre dépôt via son .git/objects/info/alternates :

$ git prune $(cd ../autre && git rev-parse --all)

NOTES

Dans la plupart des cas, les utilisateurs n'auront pas besoin d'appeler git prune directement, mais devraient plutôt appeler git gc, qui gère la suppression ainsi que de nombreuses autres tâches de maintenance.

Pour une description des objets considérés pour la suppression, voir l'option --unreachable de git fsck.

VOIR AUSSI

git-fsck(1), git-gc(1), git-reflog(1)
