NOM

git-annex-findcomputed - liste les fichiers calculés

SYNTAXE

git annex findcomputed [chemin ...]

DESCRIPTION

Affiche une liste des fichiers dans le chemin spécifié qui peuvent être calculés par des dépôts spéciaux de calcul activés. Sans chemin, liste les fichiers dans le répertoire courant et ses sous-répertoires.

En plus du nom de chaque fichier calculé, ceci affiche l'entrée qui a été fournie à git-annex-addcomputed(1).

Par exemple :

# git-annex findcomputed foo.jpeg (imageconvert) -- convert file.raw file.jpeg passes=10 bar.gz (compressor) -- compress bar --level=9

OPTIONS

options de correspondance
Les options de correspondance git-annex-matching-options(1) peuvent être utilisées pour spécifier les fichiers à lister.
--branch=ref
Liste les fichiers calculés dans la branche ou l'arbre spécifié.
--inputs
Affiche chaque fichier calculé suivi de l'entrée utilisée pour le produire. L'emplacement courant du fichier d'entrée dans l'arbre de travail est affiché, mais si le fichier d'entrée n'est pas dans l'arbre de travail, la clé est affichée à la place.
Par exemple :
foo.jpeg file.raw bar.gz bar
Lorsque plusieurs fichiers d'entrée sont nécessaires pour calculer un fichier, affiche plusieurs lignes pour ce fichier :
foo bar foo baz
--format=valeur
Utilise un formatage de sortie personnalisé.
Cette option fonctionne de la même manière que dans git-annex-find(1), avec ces variables supplémentaires disponibles pour l'utiliser : "${remote}", "${computation}"
Le format de sortie par défaut est le même que --format='${file} (${remote}) -- ${computation}\n', sauf lors de la sortie vers un terminal, les caractères de contrôle seront échappés.
Lorsque --inputs est utilisé, il existe des variables supplémentaires "${inputfile}" qui est le nom du fichier d'entrée, "${inputkey}" qui est la clé d'entrée, et "${input}" qui est soit le nom du fichier, soit la clé. Le format de sortie par défaut pour --inputs est le même que --format='${file} ${input}\n' Pour séparer les paires de fichiers par des nulls à la place, utilisez par exemple --format='${file}\000${input}\n'
--json
Affiche la liste des fichiers au format JSON.
Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement affichés sur la sortie standard sont inclus dans le JSON à la place.
