NOM

git-http-fetch - Télécharge depuis un dépôt Git distant via HTTP

SYNOPSIS

git http-fetch [-c] [-t] [-a] [-d] [-v] [-w <nom_fichier>] [--recover] [--stdin | --packfile=<hash> | <commit>] <URL>

DESCRIPTION

Télécharge un dépôt Git distant via HTTP.

Cette commande récupère toujours tous les objets. Historiquement, il y avait trois options -a, -c et -t pour choisir quels objets télécharger. Elles sont maintenant silencieusement ignorées.

OPTIONS

identifiant_commit

Soit le hash, soit le nom de fichier sous [URL]/refs/ à récupérer.

-a, -c, -t

Ces options sont ignorées pour des raisons historiques.

-v

Rapporte ce qui est téléchargé.

-w <nom_fichier>

Écrit l'identifiant_commit dans le fichier spécifié sous $GIT_DIR/refs/<nom_fichier> côté local une fois le transfert terminé.

--stdin

Au lieu d'un identifiant_commit sur la ligne de commande (ce qui n'est pas attendu dans ce cas), git http-fetch attend des lignes sur stdin dans le format 
<identifiant_commit>['\t'<nom_fichier_tel_que_dans--w>]

--packfile=<hash>

Pour usage interne uniquement. Au lieu d'un identifiant_commit sur la ligne de commande (ce qui n'est pas attendu dans ce cas), git http-fetch télécharge le fichier pack directement à l'URL donnée et utilise index-pack pour générer les fichiers .idx et .keep correspondants. Le hash est utilisé pour déterminer le nom du fichier temporaire et est arbitraire. La sortie d'index-pack est affichée sur stdout. Nécessite --index-pack-args.

--index-pack-args=<args>

Pour usage interne uniquement. La commande à exécuter sur le contenu du fichier pack téléchargé. Les arguments sont encodés en URL séparés par des espaces.

--recover

Vérifie que tout ce qui est atteignable depuis la cible a été récupéré. Utilisé après l'interruption d'un fetch précédent.
