git-branchless-switch(1) Manuel des commandes générales git-branchless-switch(1)

NOM

switch - Basculer vers la branche ou le commit fourni

SYNTAXE

switch [-i|--interactive] [-c|--create] [-f|--force] [-m|--merge] [-d|--detach] [-h|--help] [TARGET]

DESCRIPTION

Basculer vers la branche ou le commit fourni.

OPTIONS

-i, --interactive
Sélectionner interactivement un commit à extraire.
-c, --create=NOM_BRANCHE
Lors de l'extraction du commit cible, créer également une branche avec le nom fourni, pointant vers ce commit.
-f, --force
Forcer le changement de commit, en écartant les modifications de la copie de travail si nécessaire.
-m, --merge
Si les modifications actuelles de la copie de travail ne s'appliquent pas proprement au commit cible, démarrer la résolution des conflits de fusion au lieu d'annuler.
-d, --detach
Si la cible est une branche, basculer vers cette branche et s'en détacher immédiatement.
-h, --help
Afficher l'aide (voir un résumé avec '-h').
[TARGET]
Le commit ou la branche à extraire.

Si ceci n'est pas fourni, alors une sélection interactive de commit démarre, comme si `--interactive` avait été passé.

Si ceci est fourni et que l'option `--interactive` est passée, ce texte est utilisé pour pré-remplir le sélecteur de commit interactif.
