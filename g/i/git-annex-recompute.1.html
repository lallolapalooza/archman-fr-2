NOM

git-annex-recompute - Recompute les fichiers calculés

SYNOPSIS

git-annex recompute [chemin ...]

DESCRIPTION

Cette commande met à jour les fichiers calculés qui ont été ajoutés avec git-annex-addcomputed(1).

Par défaut, elle ne recompute que les fichiers dont les fichiers d'entrée ont changé. Le nouveau contenu des fichiers d'entrée est utilisé pour ré-exécuter le calcul.

Lorsque le résultat du calcul est différent, le fichier calculé est mis à jour avec le nouveau contenu. Le fichier mis à jour est indexé dans git.

OPTIONS

--original
Ré-exécute le calcul avec le contenu original des fichiers d'entrée.
--remote=nom
Ne recompute que les fichiers qui ont été calculés par cette remote de calcul.
Lorsque cette option n'est pas utilisée, tous les fichiers calculés sont recomputed en utilisant la remote de calcul qui a été utilisée à l'origine pour les ajouter. (Dans les cas où un fichier peut être calculé par plusieurs remotes, celle ayant le coût configuré le plus bas est utilisée.)
--unreproducible, -u
Indique que le calcul n'est pas censé être entièrement reproductible. Il peut varier, de manière à produire des fichiers suffisamment équivalents pour être interchangeables, mais pas nécessairement identiques.
C'est le comportement par défaut, sauf si la remote de calcul indique qu'elle produit un résultat reproductible.
--reproducible, -r
Indique que le calcul est censé être entièrement reproductible.
C'est le comportement par défaut lorsque la remote de calcul indique qu'elle produit un résultat reproductible.
--json
Active la sortie JSON. Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
options de correspondance
Les options de git-annex-matching-options(1) peuvent être utilisées pour contrôler quels fichiers recompute.
Les options communes de git-annex(1) peuvent aussi être utilisées.
