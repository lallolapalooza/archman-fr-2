NOM

git-branchless - Flux de travail sans branche pour Git

SYNTAXE

git-branchless [-C ] [--color] [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Flux de travail sans branche pour Git.

Consultez la documentation sur https://github.com/arxanas/git-branchless/wiki.

OPTIONS

-C=RÉPERTOIRE_TRAVAIL
Changez pour le répertoire donné avant d'exécuter le reste du programme. (L'option s'appelle `-C` par symétrie avec Git.)
--color=COULEUR
Indicateur pour forcer l'activation ou la désactivation des couleurs du terminal

Valeurs possibles :

  • auto : Détermine automatiquement s'il faut afficher les couleurs en fonction du terminal et des variables d'environnement. C'est le comportement par défaut.
  • always : Toujours afficher les couleurs du terminal.
  • never : Ne jamais afficher les couleurs du terminal.
-h, --help
Imprimer l'aide (voir un résumé avec '-h')
-V, --version
Imprimer la version
