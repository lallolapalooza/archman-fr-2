git-branchless-difftool(1) Manuel des commandes générales git-branchless-difftool(1)

NOM

difftool - Utiliser l'interface de sélection de commit partiel comme difftool compatible Git ; voir git-difftool(1) pour plus d'informations sur les difftools Git

SYNTAXE

difftool [-d|--dir-diff] [--read-only] [-N|--dry-run] [-b|--base] [-o|--output] [-h|--help] <GAUCHE> <DROITE>

DESCRIPTION

Utiliser l'interface de sélection de commit partiel comme difftool compatible Git ; voir git-difftool(1) pour plus d'informations sur les difftools Git

OPTIONS

-d, --dir-diff
Au lieu de comparer deux fichiers, comparer deux répertoires récursivement
--read-only
Désactiver tous les contrôles d'édition et ne pas écrire le contenu du commit sélectionné sur le disque
-N, --dry-run
Afficher ce qui aurait été écrit sur le disque dans le cadre de la sélection du commit, mais sans l'écrire réellement
-b, --base=BASE
Rendre l'interface comme un outil de fusion (mergetool) au lieu d'un difftool et utiliser ce fichier comme base d'une comparaison à trois voies dans le cadre de la résolution de conflits de fusion
-o, --output=SORTIE
Écrire les conflits de fusion résolus dans ce fichier
-h, --help
Afficher l'aide
<GAUCHE>
Le fichier de gauche à comparer (ou le répertoire si `--dir-diff` est passé)
<DROITE>
Le fichier de droite à comparer (ou le répertoire si `--dir-diff` est passé)
