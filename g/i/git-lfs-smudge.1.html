NOM

git-lfs-smudge - Filtre smudge Git qui convertit les pointeurs dans les blobs en contenu réel

SYNTAXE

git lfs smudge [<chemin>]
git lfs smudge --skip [<chemin>]

DESCRIPTION

Lit un fichier pointeur Git LFS depuis l'entrée standard et écrit le contenu du fichier volumineux correspondant en sortie standard. Si nécessaire, télécharge le contenu du fichier depuis le point d'accès Git LFS. L'argument, s'il est fourni, est uniquement utilisé pour une barre de progression.

Smudge est généralement exécuté par le filtre smudge de Git, configuré par les attributs Git du dépôt.

Dans votre configuration Git ou dans un fichier .lfsconfig, vous pouvez définir l'un ou les deux de lfs.fetchinclude et lfs.fetchexclude avec des listes de chemins séparés par des virgules. Si lfs.fetchinclude est défini, les fichiers pointeurs Git LFS ne seront remplacés par le contenu du fichier objet Git LFS correspondant que si leur chemin correspond à l'un de cette liste, et si lfs.fetchexclude est défini, les fichiers pointeurs Git LFS ne seront remplacés par le contenu du fichier objet Git LFS correspondant que si leur chemin ne correspond pas à l'un de cette liste. Les chemins sont mis en correspondance à l'aide de la correspondance de caractères génériques comme spécifié dans gitignore(5). Les fichiers pointeurs Git LFS qui ne sont pas remplacés par le contenu de leurs fichiers objets correspondants sont simplement copiés en sortie standard sans modification.

OPTIONS

Sans aucune option, git lfs smudge écrit le contenu brut de Git LFS en sortie standard.

--skip

Ignore le téléchargement automatique des objets lors du clonage ou de la récupération.

GIT_LFS_SKIP_SMUDGE

Désactive le processus de smudge. Pour plus d'informations, voir : git-lfs-config(5).

BOGUES CONNUS

Sur Windows, Git avant la version 2.34.0 ne gère pas les fichiers dans l'arbre de travail de plus de 4 gigaoctets. Les versions plus récentes de Git, ainsi que les versions Unix, ne sont pas affectées.

VOIR AUSSI

git-lfs-install(1), gitattributes(5), gitignore(5).

Fait partie de la suite git-lfs(1).
