NOM

git-annex-contentlocation - recherche le contenu pour une clé

SYNTAXE

git annex contentlocation [clé ...]

DESCRIPTION

Cette commande de bas niveau recherche le nom de fichier utilisé pour stocker le contenu d'une clé. Le nom de fichier est affiché sur la sortie standard. Si le contenu de la clé n'est pas présent dans le dépôt local, rien n'est affiché, et la commande se termine avec un code d'erreur.

OPTIONS

--batch
Active le mode batch, dans lequel une ligne contenant la clé est lue depuis l'entrée standard, le nom de fichier de son contenu est affiché sur la sortie standard (avec un saut de ligne final), et ainsi de suite.
Notez que si le contenu d'une clé n'est pas présent, une ligne vide est affichée sur la sortie standard à la place.
Aussi les options communes git-annex-common-options(1) peuvent être utilisées.
