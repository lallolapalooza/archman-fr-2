NOM

gimp - un programme de manipulation d'images et de peinture.

SYNTAXE

gimp [-h] [--help] [--help-all] [--help-gtk] [-v] [--version] [--license] [--verbose] [-n] [--new-instance] [-a] [--as-new] [-i] [--no-interface] [-d] [--no-data] [-f] [--no-fonts] [-s] [--no-splash] [--no-shm] [--no-cpu-accel] [--display affichage] [--session <nom>] [-g] [--gimprc <gimprc>] [--system-gimprc <gimprc>] [--dump-gimprc] [--console-messages] [--debug-handlers] [--stack-trace-mode <mode>] [--pdb-compat-mode <mode>] [--batch-interpreter <procédure>] [-b] [--batch <commande>] [nomfichier] ...

DESCRIPTION

GIMP est le GNU Image Manipulation Program. Il est utilisé pour éditer et manipuler des images. Il peut charger et sauvegarder une variété de formats d'images et peut être utilisé pour convertir entre les formats.

GIMP peut également être utilisé comme programme de peinture. Il propose un ensemble d'outils de dessin et de peinture tels que l'aérographe, le clone, le crayon et le pinceau. Les outils de peinture et de dessin peuvent être appliqués à une image avec une variété de modes de peinture. Il offre également un large éventail d'outils de sélection comme le rectangle, l'ellipse, la sélection floue, la sélection de Bézier, les ciseaux intelligents, et la sélection par couleur.

GIMP propose une variété de greffons qui effectuent une variété de manipulations d'images. Les exemples incluent le bumpmap, la détection de contours, le flou gaussien, et beaucoup d'autres. De plus, GIMP dispose de plusieurs extensions de script qui permettent un traitement et une création d'images avancés et non interactifs.

GIMP est livré avec un deuxième binaire appelé gimp-console. Ce binaire est une version uniquement en console et se comporte comme si gimp était appelé avec l'option de ligne de commande --no-interface.

Sur les plates-formes avec le système de bus de messages D-Bus, GIMP vérifiera par défaut si une instance est déjà en cours d'exécution dans cette session utilisateur. S'il le détecte, il transmettra tous les noms de fichiers donnés sur la ligne de commande à l'instance GIMP déjà en cours d'exécution et quittera.

OPTIONS

GIMP accepte les options suivantes :

-h, --help
Afficher les options de ligne de commande de GIMP.
--help-all
Afficher toutes les options de ligne de commande.
--help-gtk
Afficher les options de ligne de commande GTK.
--help-gegl
Afficher les options de ligne de commande GEGL.
-v, --version
Afficher les informations de version et quitter. Lorsqu'il est combiné avec l'option --verbose , les informations de version concernant les bibliothèques utilisées par GIMP sont également affichées.
--license
Afficher les informations de licence et quitter.
--verbose
Soyez verbeux et générez des informations sur la sortie standard.
-n, --new-instance
N'essayez pas de réutiliser une instance GIMP déjà en cours d'exécution. Lancez toujours une nouvelle instance.
-a, --as-new
Ouvrir les noms de fichiers passés en ligne de commande en tant que nouvelles images, ne pas définir le nom de fichier sur ceux-ci.
-i, --no-interface
Exécuter sans interface utilisateur.
-d, --no-data
Ne pas charger les motifs, dégradés, palettes ou brosses. Souvent utile dans les situations non interactives où le temps de démarrage doit être minimisé.
-f, --no-fonts
Ne charger aucune police. Aucune fonctionnalité de texte ne sera disponible si cette option est utilisée.
--display affichage
Utiliser l'affichage X désigné.
-s, --no-splash
Ne pas afficher l'écran de démarrage.
--no-shm
Ne pas utiliser la mémoire partagée entre GIMP et ses greffons. Au lieu d'utiliser la mémoire partagée, GIMP enverra les données via un tuyau. Cela entraînera des performances plus lentes que l'utilisation de la mémoire partagée.
--no-cpu-accel
Ne pas utiliser les accélérations CPU telles que MMX ou SSE, même si GIMP détecte que votre CPU fournit cette fonctionnalité.
--session <nom>
Utiliser un fichier sessionrc différent pour cette session GIMP. Le nom de session donné est ajouté au nom de fichier sessionrc par défaut.
-g, --gimprc <gimprc>
Utiliser un fichier gimprc alternatif au lieu de celui par défaut. Utile dans les cas où les chemins des greffons ou les spécifications machine peuvent être différents.
--system-gimprc <gimprc>
Utiliser un fichier gimprc système alternatif.
--dump-gimprc
Afficher un fichier gimprc avec les paramètres par défaut.
--debug-handlers
Activer les gestionnaires de signaux de débogage.
-c, --console-messages
Ne pas afficher de boîtes de dialogue en cas d'erreurs ou d'avertissements. Afficher les messages dans la console à la place.
--stack-trace-mode {never|query|always}
Indique si une trace de pile doit être générée en cas de signaux fatals.
--pdb-compat-mode {off|on|warn}
Indique si le PDB doit fournir des alias pour les fonctions dépréciées.
--batch-interpreter <procédure>
Spécifie la procédure à utiliser pour traiter les événements par lots. Par défaut, c'est Script-Fu qui évalue les commandes.
-b, --batch <commande>
Exécute <commande> de manière non interactive. Cette option peut apparaître plusieurs fois. <commande> est passée à l'interpréteur par lots. Lorsque <commande> est - , les commandes sont lues depuis l'entrée standard.

ENVIRONNEMENT

GIMP respecte un certain nombre de variables d'environnement.

DISPLAY
pour obtenir l'hôte et le numéro d'affichage par défaut.
GIMP3_DIRECTORY
pour obtenir le nom du répertoire personnel GIMP. S'il n'est pas défini, $XDG_CONFIG_HOME/GIMP/3.0 est utilisé. S'il s'agit d'un chemin absolu, il est utilisé tel quel. S'il s'agit d'un chemin relatif, il est considéré comme un sous-répertoire de $XDG_CONFIG_HOME.
GIMP3_DATADIR
pour obtenir l'emplacement de base des fichiers de données tels que les brosses et les motifs. S'il n'est pas défini, /usr/share/gimp/3.0 est utilisé.
GIMP3_LOCALEDIR
pour obtenir l'emplacement de base des traductions. S'il n'est pas défini, /usr/share/locale est utilisé.
GIMP3_PLUGINDIR
pour obtenir l'emplacement de base des greffons et des modules. S'il n'est pas défini, /usr/lib/gimp/3.0 est utilisé.
GIMP3_SYSCONFDIR
pour obtenir l'emplacement des fichiers de configuration. S'il n'est pas défini, /etc/gimp/3.0 est utilisé.
GIMP3_CACHEDIR
pour obtenir l'emplacement des fichiers de cache. S'il n'est pas défini, le défaut système pour les fichiers de cache par utilisateur est utilisé.
GIMP3_TEMPDIR
pour obtenir l'emplacement des fichiers temporaires. S'il n'est pas défini, le défaut système pour les fichiers temporaires est utilisé.

Sous Linux, GIMP peut être compilé avec le support de la relocabilité binaire. Cela permettra de rechercher les fichiers de données, les greffons et les fichiers de configuration par rapport à l'emplacement du fichier exécutable gimp, sauf si cela est remplacé par les variables d'environnement mentionnées ci-dessus.

FICHIERS

Les fichiers de données de GIMP sont stockés dans /usr/share/gimp/3.0, où ${datarootdir} est défini à l'installation, mais est généralement /usr/share. Les fichiers de configuration système de GIMP sont stockés dans /etc/gimp/3.0, où ${prefix} est généralement /usr.

La plupart de la configuration de GIMP est lue depuis le fichier d'initialisation de l'utilisateur, $XDG_CONFIG_HOME/GIMP/3.0/gimprc. L'équivalent système se trouve dans /etc/gimp/3.0/gimprc. Le fichier système est analysé en premier et le gimprc de l'utilisateur peut remplacer les paramètres système. /etc/gimp/3.0/gimprc_user est le gimprc par défaut placé dans les répertoires personnels des utilisateurs la première fois que GIMP est exécuté.

$XDG_CONFIG_HOME/GIMP/3.0/devicerc - contient les paramètres des périphériques d'entrée ainsi que l'outil, les couleurs, le pinceau, le motif et le dégradé associés à ce périphérique.

$XDG_CONFIG_HOME/GIMP/3.0/gtkrc - ensemble de paramètres de configuration GTK spécifiques à GIMP pour l'utilisateur. Des options telles que la couleur des widgets et la taille des polices peuvent être définies ici.

/etc/gimp/3.0/gtkrc - ensemble par défaut de paramètres de configuration GTK spécifiques à GIMP au niveau du système.

$XDG_CONFIG_HOME/GIMP/3.0/shortcutsrc - ensemble de raccourcis clavier de l'utilisateur.

$XDG_CONFIG_HOME/GIMP/3.0/parasiterc - Stocke tous les parasites persistants de GIMP. Ce fichier sera réécrit à chaque fois que vous quittez GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/sessionrc - Ce fichier prend les informations spécifiques à la session (c'est-à-dire les informations que vous souhaitez conserver entre deux sessions GIMP). Vous n'êtes pas censé le modifier manuellement, mais bien sûr vous pouvez le faire. Ce fichier sera entièrement réécrit à chaque fois que vous quittez GIMP. Si ce fichier n'est pas trouvé, les valeurs par défaut sont utilisées.

$XDG_CONFIG_HOME/GIMP/3.0/templaterc - Les modèles d'images sont conservés dans ce fichier. De nouvelles images peuvent être facilement créées à partir de ces modèles. Si ce fichier n'est pas trouvé, les valeurs par défaut sont utilisées.

/etc/gimp/3.0/unitrc - base de données des unités utilisateur par défaut. Elle contient les définitions d'unités pour les centimètres, les mètres, les pieds, les yards, les points typographiques et les picas typographiques et est placée dans les répertoires personnels des utilisateurs la première fois que GIMP est exécuté. Si ce fichier n'est pas trouvé, les valeurs par défaut sont utilisées.

$XDG_CONFIG_HOME/GIMP/3.0/unitrc - Ce fichier contient votre base de données d'unités utilisateur. Vous pouvez modifier cette liste avec l'éditeur d'unités. Vous n'êtes pas censé le modifier manuellement, mais bien sûr vous pouvez le faire. Ce fichier sera entièrement réécrit à chaque fois que vous quittez GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/plug-ins - emplacement des greffons installés par l'utilisateur.

$XDG_CONFIG_HOME/GIMP/3.0/pluginrc - les valeurs d'initialisation des greffons sont stockées ici. Ce fichier est analysé au démarrage et régénéré si besoin est.

$XDG_CONFIG_HOME/GIMP/3.0/modules - emplacement des modules installés par l'utilisateur.

$XDG_CONFIG_HOME/GIMP/3.0/tmp - emplacement par défaut que GIMP utilise comme espace temporaire.

/usr/share/gimp/3.0/brushes - fichiers de pinceaux au niveau du système.

$XDG_CONFIG_HOME/GIMP/3.0/brushes - fichiers de pinceaux créés et installés par l'utilisateur. Ces fichiers sont aux formats de fichier .gbr, .gih ou .vbr.

$XDG_CONFIG_HOME/GIMP/3.0/curves - Profils et préréglages de courbes tels que enregistrés depuis l'outil Courbes.

$XDG_CONFIG_HOME/GIMP/3.0/gimpressionist - Les préréglages ainsi que les pinceaux et papiers créés par l'utilisateur sont stockés ici.

$XDG_CONFIG_HOME/GIMP/3.0/levels - Profils et préréglages de niveaux tels que enregistrés depuis l'outil Niveaux.

/usr/share/gimp/3.0/palettes - les fichiers de palettes au niveau du système.

$XDG_CONFIG_HOME/GIMP/3.0/palettes - fichiers de palettes créés et modifiés par l'utilisateur. Ces fichiers sont au format .gpl.

/usr/share/gimp/3.0/patterns - ensemble de motifs de base pour une utilisation dans GIMP.

$XDG_CONFIG_HOME/GIMP/3.0/patterns - fichiers de motifs GIMP créés et installés par l'utilisateur. Ces fichiers sont au format .pat.

/usr/share/gimp/3.0/gradients - ensemble standard de fichiers de dégradés au niveau du système.

$XDG_CONFIG_HOME/GIMP/3.0/gradients - fichiers de dégradés créés et installés par l'utilisateur.

/usr/share/gimp/3.0/scripts - répertoire système de scripts utilisé dans Script-Fu et d'autres extensions de script.

$XDG_CONFIG_HOME/GIMP/3.0/scripts - scripts créés et installés par l'utilisateur.

/usr/share/gimp/3.0/gflares - répertoire système utilisé par le greffon gflare.

$XDG_CONFIG_HOME/GIMP/3.0/gflares - fichiers gflare créés et installés par l'utilisateur.

/usr/share/gimp/3.0/gfig - répertoire système utilisé par le greffon gfig.

$XDG_CONFIG_HOME/GIMP/3.0/gfig - fichiers gfig créés et installés par l'utilisateur.

/usr/share/gimp/3.0/images/gimp-splash.png - l'image par défaut utilisée pour l'écran de démarrage de GIMP.

/usr/share/gimp/3.0/images/gimp-logo.png - image utilisée dans la boîte de dialogue « À propos de » de GIMP.

/usr/share/gimp/3.0/tips/gimp-tips.xml - astuces affichées dans la boîte de dialogue « Astuce du jour ».

IMAGES DE DÉMARRAGE

GIMP est livré avec une image par défaut pour l'écran de démarrage mais il permet aux administrateurs système et aux utilisateurs de personnaliser l'écran de démarrage en fournissant d'autres images. L'image à utiliser avec l'écran de démarrage est choisie comme suit :

1.
GIMP essaie de charger un écran de démarrage aléatoire depuis le répertoire $XDG_CONFIG_HOME/GIMP/3.0/splashes.
2.
Il utilise ensuite $XDG_CONFIG_HOME/GIMP/3.0/gimp-splash.png.
3.
Si l'utilisateur n'a installé aucune image de démarrage personnalisée, une image aléatoire est choisie dans /usr/share/gimp/3.0/splashes.
4.
En dernier recours, GIMP utilise l'image de démarrage par défaut située dans /usr/share/gimp/3.0/images/gimp-splash.png.

SUGGESTIONS ET RAPPORTS DE BOGUES

Tout bogue trouvé doit être rapporté au système de suivi de bogues en ligne disponible sur le web à l'adresse https://gitlab.gnome.org/GNOME/gimp/issues. Avant de rapporter des bogues, veuillez vérifier si le bogue n'a pas déjà été rapporté.

Lors du rapport de bogues de GIMP, il est important d'inclure une manière fiable de reproduire le bogue, le numéro de version de GIMP (et probablement de GTK), le nom et la version du système d'exploitation, et toute spécification matérielle pertinente. Si un bogue provoque un plantage, il est très utile de pouvoir fournir une trace de pile. Et bien sûr, des correctifs pour corriger le bogue sont encore mieux.

AUTRES INFORMATIONS

L'emplacement canonique pour trouver des informations sur GIMP est à https://www.gimp.org/. Ici, vous pouvez trouver des liens vers de nombreux autres sites GIMP, tutoriels, ensembles de données, archives de listes de diffusion, et plus encore.

Un manuel d'utilisation de GIMP est également disponible à l'adresse https://docs.gimp.org/ qui entre beaucoup plus dans le détail de l'utilisation interactive de GIMP.

Les dernières versions de GIMP et des bibliothèques GTK sont toujours disponibles à l'adresse https://download.gimp.org/.
