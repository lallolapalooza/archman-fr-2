NOM

git-var - Afficher une variable logique Git

SYNOPSIS

git var (-l | <variable>)

DESCRIPTION

Affiche une variable logique Git. Se termine avec le code 1 si la variable n'a pas de valeur.

OPTIONS

-l

Affiche les variables logiques. De plus, toutes les variables du fichier de configuration Git .git/config sont également listées. (Cependant, la fonctionnalité de listage des variables de configuration est dépréciée au profit de git config -l.)

EXEMPLES

$ git var GIT_AUTHOR_IDENT
Eric W. Biederman <ebiederm@lnxi.com> 1121223278 -0600

VARIABLES

GIT_AUTHOR_IDENT

L'auteur d'un morceau de code.

GIT_COMMITTER_IDENT

La personne qui a intégré un morceau de code dans Git.

GIT_EDITOR

Éditeur de texte à utiliser par les commandes Git. La valeur est destinée à être interprétée par le shell lorsqu'elle est utilisée. Exemples : ~/bin/vi, $SOME_ENVIRONMENT_VARIABLE, "C:\Program Files\Vim\gvim.exe" --nofork. L'ordre de préférence est $GIT_EDITOR, puis la valeur de configuration core.editor, puis $VISUAL, puis $EDITOR, et enfin le défaut choisi à la compilation, qui est généralement vi.

GIT_SEQUENCE_EDITOR

Éditeur de texte utilisé pour éditer le fichier todo lors de l'exécution de git rebase -i. Comme pour GIT_EDITOR, la valeur est destinée à être interprétée par le shell lorsqu'elle est utilisée. L'ordre de préférence est $GIT_SEQUENCE_EDITOR, puis la valeur de configuration sequence.editor, et enfin la valeur de git var GIT_EDITOR.

GIT_PAGER

Visionneur de texte à utiliser par les commandes Git (par exemple, less). La valeur est destinée à être interprétée par le shell. L'ordre de préférence est $GIT_PAGER, puis la valeur de configuration core.pager, puis $PAGER, et enfin le défaut choisi à la compilation (généralement less).

GIT_DEFAULT_BRANCH

Le nom de la première branche créée dans les dépôts nouvellement initialisés.

GIT_SHELL_PATH

Le chemin binaire qui fournit le shell POSIX pour les commandes qui utilisent le shell.

GIT_ATTR_SYSTEM

Le chemin vers le fichier gitattributes(5) système, si un est activé.

GIT_ATTR_GLOBAL

Le chemin vers le fichier gitattributes(5) global (par utilisateur).

GIT_CONFIG_SYSTEM

Le chemin vers le fichier de configuration système, si un est activé.

GIT_CONFIG_GLOBAL

Le chemin vers les fichiers de configuration globaux (par utilisateur), s'il y en a.

La plupart des valeurs de chemin ne contiennent qu'une seule valeur. Cependant, certaines peuvent contenir plusieurs valeurs, séparées par des sauts de ligne, et listées dans l'ordre de priorité la plus élevée à la plus basse. Les appelants doivent être préparés à ce que toute valeur de chemin de ce type contienne plusieurs éléments.

Notez que les chemins sont imprimés même s'ils n'existent pas, mais pas s'ils sont désactivés par d'autres variables d'environnement.
