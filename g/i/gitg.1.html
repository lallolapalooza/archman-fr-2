GITG(1) Commandes utilisateur GITG(1)

NOM

gitg - Visualiseur de dépôts Git

SYNTAXE

gitg [OPTION]... [DÉPÔT]...

DESCRIPTION

gitg est une interface utilisateur graphique pour Git. Il vise à être un outil petit, rapide et pratique pour visualiser l'historique des dépôts Git. En plus de la visualisation, gitg fournit également plusieurs utilitaires pour gérer votre dépôt et commiter votre travail.

OPTIONS

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gtk
Afficher les options GTK+

Options de l'application :

-v, --version
Afficher la version de l'application
--activity
Démarrer gitg avec une activité particulière
-c, --commit
Démarrer gitg avec l'activité commit (raccourci pour --activity commit)
--no-wd
Ne pas essayer de charger un dépôt depuis le répertoire de travail courant
--standalone
Exécuter gitg en mode autonome
--display=AFFICHAGE
Affichage X à utiliser
-a, --all
Sélectionner tous les commits par défaut dans l'activité d'historique
-b, --branches
Sélectionner toutes les branches par défaut dans l'activité d'historique
-r, --remotes
Sélectionner toutes les branches distantes par défaut dans l'activité d'historique
-t, --tags
Sélectionner toutes les étiquettes par défaut dans l'activité d'historique
-s, --select-reference=RÉFÉRENCE
Sélectionner la référence spécifiée par défaut dans l'activité d'historique

gitg essaiera de charger tout DÉPÔT passé en argument de ligne de commande (plusieurs chemins peuvent être passés).

Si aucun dépôt n'est spécifié, gitg essaiera d'ouvrir le dépôt spécifié par la variable d'environnement GIT_DIR ; si GIT_DIR n'est pas définie, gitg essaiera d'ouvrir le dépôt dans le répertoire de travail courant.

VARIABLES D'ENVIRONNEMENT

GIT_DIR

Si la variable d'environnement GIT_DIR est définie, et qu'aucun dépôt n'a été passé en argument de ligne de commande, alors elle spécifie un chemin à utiliser à la place du chemin par défaut .git pour la base du dépôt.
