NOM

git-bug-bug - Lister les bugs

SYNTAXE

git-bug bug [REQUÊTE] [indicateurs]

DESCRIPTION

Affiche un résumé de chaque bug.

Vous pouvez passer une requête supplémentaire pour filtrer et trier les résultats. Cette requête peut être exprimée soit avec un langage de requête simple, des indicateurs, une recherche plein texte en langage naturel, soit une combinaison des éléments ci-dessus.

OPTIONS

-s, --status=[] Filtrer par statut. Valeurs valides : [ouvert,fermé]

-a, --author=[] Filtrer par auteur

-m, --metadata=[] Filtrer par métadonnées. Exemple : github-url=URL

-p, --participant=[] Filtrer par participant

-A, --actor=[] Filtrer par acteur

-l, --label=[] Filtrer par étiquette

-t, --title=[] Filtrer par titre

-n, --no=[] Filtrer par absence de quelque chose. Valeurs valides : [étiquette]

-b, --by="creation" Trier les résultats par une caractéristique. Valeurs valides : [id,création,édition]

-d, --direction="asc" Sélectionner la direction du tri. Valeurs valides : [asc,desc]

-f, --format="default" Sélectionner le style de format de sortie. Valeurs valides : [défaut,simple,id,json,org-mode]

-h, --help[=false] aide pour bug

EXEMPLE

Lister les bugs ouverts triés par dernière édition avec une requête :
git bug status:ouvert tri:edition-desc
Lister les bugs fermés triés par création avec des indicateurs :
git bug --status fermé --par création
Effectuer une recherche plein texte de tous les bugs :
git bug "foo bar" baz
Utiliser des requêtes, des indicateurs et une recherche plein texte :
git bug status:ouvert --par création "foo bar" baz
