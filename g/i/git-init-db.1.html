NOM

git-init-db - Crée un dépôt Git vide

SYNTAXE

git init-db [-q | --quiet] [--bare] [--template=<répertoire-modèle>] [--separate-git-dir <répertoire-git>] [--shared[=<permissions>]]

DESCRIPTION

Ceci est un synonyme de git-init(1). Veuillez vous référer à la documentation de cette commande.
