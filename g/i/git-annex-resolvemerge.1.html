NOM

git-annex-resolvemerge - résoudre les conflits de fusion

SYNOPSIS

git annex resolvemerge

DESCRIPTION

Résout automatiquement un conflit de fusion. Ceci est fait automatiquement lors de l'utilisation de git annex sync ou git annex merge.

Lorsque deux arborescences en cours de fusion contiennent des versions conflictuelles d'un fichier annexé, le conflit de fusion sera résolu en ajoutant les deux versions à l'arborescence, en utilisant des variantes du nom de fichier.

Lorsqu'une arborescence a modifié le fichier et que l'autre arborescence a supprimé le fichier, le conflit de fusion sera résolu en ajoutant le fichier modifié à l'aide d'une variante du nom de fichier, laissant le nom de fichier original supprimé.

Lorsque le conflit de fusion implique un fichier qui est annexé dans une arborescence, mais qui n'est pas annexé dans l'autre arborescence, il est résolu en conservant le fichier non annexé tel quel, et en ajoutant la version annexée à l'aide d'une variante du nom de fichier.

Notez que seuls les conflits de fusion impliquant un ou plusieurs fichiers annexés sont résolus. Les conflits de fusion entre deux fichiers qui ne sont pas annexés ne seront pas résolus automatiquement.

EXEMPLES

Supposons qu'Alice commite un changement dans le fichier annexé foo, et que Bob commite un changement différent dans le même fichier foo.

La fusion entre eux échouera alors, et git présentera le conflit de fusion comme un fichier foo pointant vers une version du lien symbolique git-annex, avec git status indiquant que foo a un conflit non résolu.

Exécuter git annex resolvemerge dans cette situation résoudra le conflit de fusion, en remplaçant le fichier foo par des fichiers nommés comme foo.variant-c696 et foo.variant-f16a. L'un des fichiers contient le contenu qu'Alice a commité, et l'autre contient le contenu que Bob a commité.

L'utilisateur peut alors examiner les deux variantes du fichier, et soit fusionner les deux changements en un seul fichier, soit renommer l'un d'eux en foo et supprimer l'autre.

Supposons maintenant qu'Alice commite un changement dans le fichier annexé bar, tandis que Bob commite une suppression du même fichier bar. La fusion échouera. Exécuter git annex resolvemerge dans cette situation résoudra le conflit de fusion en créant un fichier nommé comme bar.variant-421f contenant la version d'Alice. Le fichier bar reste supprimé. L'utilisateur peut plus tard examiner la variante du fichier et soit la renommer en bar, soit décider de la supprimer également.

OPTIONS

Les git-annex-common-options(1) peuvent être utilisés.
