Si vous voulez avoir une URL unique à la fois pour gitweb et pour vos dépôts http://, vous pouvez configurer Apache comme ceci

<VirtualHost *:80>
    ServerName    git.example.org
    DocumentRoot  /pub/git

    # activer mod_rewrite
RewriteEngine on # faire de la page d'accueil une réécriture interne vers le script gitweb RewriteRule ^/$ /cgi-bin/gitweb.cgi # permettre l'accès p

Définir la variable d'environnement GITWEB_CONFIG indiquera à gitweb d'utiliser le fichier nommé (c'est-à-dire dans cet exemple /etc/gitweb.conf) comme configuration pour gitweb. Vous n'en avez pas vraiment besoin dans l'exemple ci-dessus ; cela n'est requis que si votre fichier de configuration est à un endroit différent de celui intégré (pendant la compilation de gitweb) gitweb_config.perl ou /etc/gitweb.conf. priorité.

Si vous utilisez les règles de réécriture de l'exemple, vous aurez peut-être aussi besoin de quelque chose comme ce qui suit dans votre fichier de configuration gitweb (/etc/gitweb.conf selon l'exemple)

projets

    SetEnv        GITWEB_CONFIG  /etc/gitweb.conf

    RewriteEngine on
    # faire de la page d'accueil une réécriture interne vers le script gitweb
    RewriteRule ^/$  /cgi-bin/gitweb.cgi  [QSA,L,PT]
    # chercher un répertoire public_git dans le répertoire personnel des utilisateurs unix
    # http://git.example.org/~<user>/
    RewriteRule ^/\~([^\/]+)(/
|/gitweb.cgi)?$ /cgi-bin/gitweb.cgi \ [QSA,E=GITWEB_PROJECTROOT:/home/$1/public_git/,L,PT] # http://git.example.org/+<user>/ #RewriteRule ^/\+([^\/]+)(/|/gitweb.cgi)?$ /cgi-bin/gitweb.cgi \ [QSA,E=GITWEB_PROJECTROOT:/home/$1/public_git/,L,PT] # http://git.example.org/user/<user>/ #RewriteRule ^/user/([^\/]+)/(gitweb.cgi)?$ /cgi-bin/gitweb.cgi \ [QSA,E=GITWEB_PROJECTROOT:/home/$1/public_git/,L,PT]

onfig ;
