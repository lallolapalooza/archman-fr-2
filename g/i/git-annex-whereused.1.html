NOM

git-annex-whereused - trouve les fichiers qui utilisent ou ont utilisé une clé

SYNOPSIS

git annex whereused --key=nomdeclé|--unused

DESCRIPTION

Trouve les fichiers qui utilisent ou ont utilisé une clé.

Pour chaque fichier dans l'arbre de travail qui utilise une clé, cela affiche une ligne, commençant par la clé, puis un espace, et enfin le nom du fichier. Lorsque plusieurs fichiers utilisent la même clé, ils seront tous listés. Lorsque rien n'est trouvé qui utilise la clé, il n'y aura aucune sortie.

Par défaut, seules les fichiers dans l'arbre de travail actuel qui utilisent une clé sont recherchés. L'option --historical permet de rechercher également les versions antérieures des fichiers.

OPTIONS

--key=nomdeclé
Opère sur cette clé.
--unused
Opère sur les clés trouvées lors de la dernière exécution de git-annex unused.
Généralement, ces clés ne seront pas utilisées par les fichiers de l'arbre de travail actuel, ni par des tags ou des branches. La combinaison de cette option avec --historical permettra de trouver les utilisations antérieures des clés.
--historical
Lorsque aucun fichier dans l'arbre de travail actuel n'utilise une clé, cela déclenche un travail supplémentaire, en examinant les versions antérieures de la branche actuelle, d'autres branches, des tags et le reflog, pour trouver où la clé a été utilisée. Il s'arrête après avoir trouvé une utilisation de la clé et affiche une révision git qui fait référence à l'endroit où elle a été utilisée, par exemple "HEAD@{40}:unfichier"
