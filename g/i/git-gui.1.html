NOM

git-gui - Interface graphique portable pour Git

SYNTAXE

git gui [<commande>] [<arguments>]

DESCRIPTION

Une interface graphique à base de Tcl/Tk pour Git. git gui se concentre sur la possibilité pour les utilisateurs de modifier leur dépôt en créant de nouveaux commits, en modifiant des commits existants, en créant des branches, en effectuant des fusions locales et en récupérant/poussant vers des dépôts distants.

Contrairement à gitk, git gui se concentre sur la génération de commits et l'annotation de fichiers uniques, et n'affiche pas l'historique du projet. Il fournit cependant des actions de menu pour démarrer une session gitk depuis git gui.

git gui est connu pour fonctionner sur tous les systèmes UNIX populaires, Mac OS X et Windows (sous Cygwin et MSYS). Dans la mesure du possible, les directives d'interface utilisateur spécifiques au système d'exploitation sont suivies, ce qui fait de git gui une interface assez native pour les utilisateurs.

COMMANDES

blame

Lance un visualiseur de blame sur le fichier spécifié dans la version donnée (ou le répertoire de travail si non spécifié).

browser

Lance un explorateur d'arborescence montrant tous les fichiers dans le commit spécifié. Les fichiers sélectionnés via l'explorateur sont ouverts dans le visualiseur de blame.

citool

Lance git gui et organise-le pour effectuer exactement un commit avant de quitter et de retourner au shell. L'interface est limitée aux actions de commit uniquement, réduisant légèrement le temps de démarrage de l'application et simplifiant la barre de menus.

version

Affiche la version actuellement exécutée de git gui.

EXEMPLES

git gui blame Makefile

Affiche le contenu du fichier Makefile dans le répertoire de travail actuel et fournit des annotations pour l'auteur original de chaque ligne, ainsi que pour celui qui a déplacé la ligne à son emplacement actuel. Le fichier non validé est annoté, et les modifications non validées (le cas échéant) sont explicitement attribuées à Not Yet Committed.

git gui blame v0.99.8 Makefile

Affiche le contenu de Makefile dans la révision v0.99.8 et fournit des annotations pour chaque ligne. Contrairement à l'exemple ci-dessus, le fichier est lu à partir de la base de données d'objets et non du répertoire de travail.

git gui blame --line=100 Makefile

Charge les annotations comme décrit ci-dessus et fait défiler automatiquement la vue pour centrer sur la ligne 100.

git gui citool

Effectue un commit et retourne au shell une fois qu'il est terminé. Cette commande retourne un code de sortie non nul si la fenêtre a été fermée d'une manière autre qu'en effectuant un commit.

git gui citool --amend

Entrée automatique en mode Modifier le dernier commit de l'interface.

git gui citool --nocommit

Se comporte comme citool normal, mais au lieu de faire un commit, il se termine simplement avec un code de sortie nul. Il vérifie toujours que l'index ne contient aucune entrée non fusionnée, vous pouvez donc l'utiliser comme une version GUI de git-mergetool(1)

git citool

Identique à git gui citool (ci-dessus).

git gui browser maint

Affiche un explorateur pour l'arborescence de la branche maint. Les fichiers sélectionnés dans l'explorateur peuvent être vus avec le visualiseur de blame interne.

VOIR AUSSI

gitk(1)

Le navigateur de dépôt Git. Affiche les branches, l'historique des commits et les différences de fichiers. gitk est l'utilitaire démarré par les actions de visualisation du dépôt de git gui.

AUTRE

git gui est en fait maintenu comme un projet indépendant, mais des versions stables sont distribuées dans le cadre de la suite Git pour la commodité des utilisateurs finaux.

Le dépôt officiel du projet git gui peut être trouvé à l'adresse :

https://github.com/j6t/git-gui
