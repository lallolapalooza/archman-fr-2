NOM

git-annex-backends - backends clé/valeur pour git-annex

DESCRIPTION

Le « backend » dans git-annex contrôle comment une clé est générée à partir du contenu d'un fichier et/ou des métadonnées du système de fichiers. La plupart des backends sont différents types de sommes de contrôle. Un seul dépôt peut utiliser différents backends pour différents fichiers.

Pour une liste des backends disponibles, voir git-annex version. Pour plus de détails, voir https://git-annex.branchable.com/backends/
