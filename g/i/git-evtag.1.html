NOM

git-evtag - Signer un commit git avec des sommes de contrôle étendues

SYNTAXE

git evtag sign [OPTIONS...] {NOMTAG}

git evtag verify [OPTIONS...] {NOMTAG}

DESCRIPTION

Alors que git peut utiliser GPG pour signer des tags et des commits, cela ne couvre qu'un objet de commit, qui est sujet aux faiblesses de SHA1. Cet outil utilise SHA512 sur l'ensemble du contenu d'un tag, créant ainsi un niveau d'assurance plus solide.

OPTIONS

Voir l'aide de la sous-commande, par exemple git-evtag sign --help.
