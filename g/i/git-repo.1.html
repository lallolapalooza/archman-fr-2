NOM

git-repo - Récupérer des informations sur le dépôt

SYNOPSIS

git repo info [--format=(keyvalue|nul)] [-z] [<clé>...]
git repo structure [--format=(table|keyvalue|nul)]

DESCRIPTION

Récupérer des informations sur le dépôt.

CETTE COMMANDE EST EXPÉRIMENTALE. SON COMPORTEMENT PEUT CHANGER.

COMMANDES

info [--format=(keyvalue|nul)] [-z] [<clé>...]

Récupérer des informations relatives aux métadonnées du dépôt actuel. Seules les données demandées seront retournées en fonction de leurs clés (voir la section "CLÉS D'INFO" ci-dessous).

Les valeurs sont retournées dans le même ordre que celui dans lequel leurs clés respectives ont été demandées.

Le format de sortie peut être choisi via l'option --format. Deux formats sont pris en charge :

keyvalue

sortie de paires clé-valeur une par ligne, utilisant le caractère = comme délimiteur entre la clé et la valeur. Les valeurs contenant des caractères "inhabituels" sont mises entre guillemets comme expliqué pour la variable de configuration core.quotePath (voir git-config(1)). C'est le défaut.

nul

similaire à keyvalue, mais utilisant un caractère de nouvelle ligne comme délimiteur entre la clé et la valeur et utilisant un caractère NUL après chaque valeur. Ce format est mieux adapté à l'analyse par d'autres applications que keyvalue. Contrairement au format keyvalue, les valeurs ne sont jamais mises entre guillemets.

-z est un alias pour --format=nul.

structure [--format=(table|keyvalue|nul)]

Récupérer des statistiques sur la structure du dépôt actuel. Les types d'informations suivants sont rapportés :
•Comptes de références catégorisés par type
•Comptes d'objets accessibles catégorisés par type

Le format de sortie peut être choisi via l'option --format. Trois formats sont pris en charge :

table

Sortie des statistiques du dépôt dans un tableau convivial. Ce format peut changer et n'est pas destiné à l'analyse par machine. C'est le format par défaut.

keyvalue

Chaque ligne de sortie contient une paire clé-valeur pour une statistique du dépôt. Le caractère = est utilisé pour délimiter la clé et la valeur. Les valeurs contenant des caractères "inhabituels" sont mises entre guillemets comme expliqué pour la variable de configuration core.quotePath (voir git-config(1)).

nul

Similaire à keyvalue, mais utilise un caractère NUL pour délimiter les paires clé-valeur au lieu d'une nouvelle ligne. Utilise également un caractère de nouvelle ligne comme délimiteur entre la clé et la valeur au lieu de =. Contrairement au format keyvalue, les valeurs contenant des caractères "inhabituels" ne sont jamais mises entre guillemets.

CLÉS D'INFO

Afin d'obtenir un ensemble de valeurs à partir de git repo info, vous devez fournir les clés qui les identifient. Voici une liste des clés disponibles et des valeurs qu'elles retournent :

layout.bare

true si c'est un dépôt nu (bare), sinon false.

layout.shallow

true si c'est un dépôt superficiel (shallow), sinon false.

object.format

Le format d'objet (algorithme de hachage) utilisé dans le dépôt.

references.format

Le format de stockage des références. Les valeurs valides sont :
•files pour les fichiers lâches avec refs packées. C'est le défaut.
•reftable pour le format reftable. Ce format est expérimental et ses internes sont sujets à changement.

EXEMPLES

•Récupère le format de référence du dépôt actuel : 
git repo info references.format
•Récupère si le dépôt actuel est nu et s'il est superficiel en utilisant le format nul : 
git repo info --format=nul layout.bare layout.shallow
