NOM

git-lfs-pointer - Construire, comparer et vérifier les pointeurs

SYNTAXE

git lfs pointer --file=chemin/vers/fichier
git lfs pointer --file=chemin/vers/fichier --pointer=chemin/vers/pointeur
git lfs pointer --file=chemin/vers/fichier --stdin
git lfs pointer --check --file=chemin/vers/fichier

DESCRIPTION

Construit et, optionnellement, compare les fichiers pointeurs générés pour assurer la cohérence entre les différentes implémentations de Git LFS.

OPTIONS

--file

Un fichier local à partir duquel construire le pointeur.

--pointer

Un fichier local incluant le contenu d'un pointeur généré à partir d'une autre implémentation. Ceci est comparé au pointeur généré à partir de --file.

--stdin

Lit le pointeur depuis STDIN pour le comparer au pointeur généré à partir de --file.

--check

Lit le pointeur depuis STDIN (si --stdin est donné) ou depuis le chemin du fichier (si --file est donné). Si ni --stdin ni --file ne sont donnés, ou si les deux sont donnés, l'appel est invalide. Quitte avec le code 0 si les données lues sont un pointeur Git LFS valide. Quitte avec le code 1 sinon.

--strict, --no-strict

En conjonction avec --check, --strict vérifie que le pointeur est canonique ; c'est-à-dire qu'il serait celui créé par Git LFS. S'il ne l'est pas, quitte avec le code 2. La valeur par défaut, pour des raisons de compatibilité descendante, est --no-strict, mais cela pourrait changer dans une future version.

VOIR AUSSI

Fait partie de la suite git-lfs(1).
