EXEMPLE

Supposons que vous vouliez empêcher git annex sync de commiter les modifications des fichiers, de sorte qu'un workflow de commit git manuel soit utilisé dans tous les clones du dépôt. Exécutez alors :


git annex config --set annex.autocommit false

Si vous souhaitez remplacer cela dans un clone particulier, utilisez simplement git config dans le clone :


git config annex.autocommit true

Et pour revenir au comportement par défaut :


git annex config --unset annex.autocommit
