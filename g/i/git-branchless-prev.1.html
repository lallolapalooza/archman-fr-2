git-branchless-prev(1) Manuel des commandes générales git-branchless-prev(1)

NOM

prev - Déplacer vers un commit précédent dans la pile actuelle

SYNTAXE

prev [-a|--all] [-b|--branch] [-o|--oldest] [-n|--newest] [-i|--interactive] [-m|--merge] [-f|--force] [-h|--help] [NB_COMMITS]

DESCRIPTION

Déplacer vers un commit précédent dans la pile actuelle

OPTIONS

-a, --all
Parcourir autant de commits que possible
-b, --branch
Déplacer le nombre spécifié de branches plutôt que de commits
-o, --oldest
Lorsqu'il rencontre plusieurs commits suivants, choisir le plus ancien
-n, --newest
Lorsqu'il rencontre plusieurs commits suivants, choisir le plus récent
-i, --interactive
Lorsqu'il rencontre plusieurs commits suivants, demander interactivement lequel utiliser
-m, --merge
Si les modifications locales entrent en conflit avec le commit de destination, essayer de les fusionner
-f, --force
Si les modifications locales entrent en conflit avec le commit de destination, les ignorer. (Utiliser avec prudence !)
-h, --help
Afficher l'aide (voir un résumé avec '-h')
[NB_COMMITS]
Le nombre de commits à parcourir.

Si non fourni, vaut 1 par défaut.
