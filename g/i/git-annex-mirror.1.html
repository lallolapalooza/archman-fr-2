NOM

git-annex-mirror - dupliquer le contenu des fichiers vers/depuis un autre dépôt

SYNTAXE

git annex mirror [chemin ...] [--to=dépôt|--from=dépôt]

DESCRIPTION

Ceci fait qu'un dépôt de destination duplique un dépôt source.

Chaque fichier spécifié dans le dépôt source est dupliqué vers le dépôt de destination. Si le contenu d'un fichier est présent dans le dépôt source, il est copié vers le dépôt de destination. Si le contenu d'un fichier n'est pas présent dans le dépôt source, il sera supprimé du dépôt de destination lorsque le réglage numcopies le permettra.

Notez que mirror ne synchronise pas le dépôt git, mais uniquement les contenus des fichiers. Utilisez git-annex-sync(1) pour cela.

OPTIONS

--to=dépôt
Utilise le dépôt local comme dépôt source et duplique son contenu vers le dépôt distant.
--from=dépôt
Utilise le dépôt distant comme dépôt source et duplique son contenu vers le dépôt local.
--jobs=N -JN
Active les transferts parallèles avec jusqu'à N travaux exécutés simultanément. Par exemple : -J10
Le réglage sur "cpus" exécutera un travail par cœur de CPU.
--all -A
Duplique tous les objets stockés dans le dépôt annexé, pas seulement les objets utilisés par les fichiers existants actuellement.
Cependant, cela ignore la vérification du réglage annex.numcopies de .gitattributes lors de la suppression de fichiers.
C'est le comportement par défaut lors de l'exécution de git-annex dans un dépôt nu (bare).
--branch=ref
Opère sur les fichiers de la branche ou de l'arbre spécifié.
Comme --all, cela ignore la vérification du réglage annex.numcopies de .gitattributes lors de la suppression de fichiers.
--unused
Opère sur les fichiers trouvés lors de la dernière exécution de git-annex unused.
--failed
Opère sur les fichiers qui ont récemment échoué lors du transfert.
options de correspondance
Les options de correspondance de git-annex-matching-options(1) peuvent être utilisées pour contrôler ce qui doit être dupliqué.
--json
Active la sortie JSON. Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
Notez que contrairement à toutes les autres commandes qui supportent --json, cette commande produit différents types d'objets JSON dans différentes circonstances.
--json-progress
Inclut des objets de progression dans la sortie JSON.
--json-error-messages
Les messages qui seraient normalement affichés sur la sortie d'erreur standard sont inclus dans le JSON à la place.
Les options générales de git-annex (git-annex-common-options(1)) peuvent également être utilisées.
