NOM

git-instaweb - Parcourir instantanément votre dépôt de travail dans gitweb

SYNOPSIS

git instaweb [--local] [--httpd=<httpd>] [--port=<port>]
               [--browser=<browser>]
git instaweb [--start] [--stop] [--restart]

DESCRIPTION

Un script simple pour configurer gitweb et un serveur web pour parcourir le dépôt local.

OPTIONS

-l, --local

Ne lier le serveur web qu'à l'IP locale (127.0.0.1).

-d, --httpd

La ligne de commande du démon HTTP qui sera exécutée. Des options de ligne de commande peuvent être spécifiées ici, et le fichier de configuration sera ajouté à la fin de la ligne de commande. Actuellement, apache2, lighttpd, mongoose, plackup, python et webrick sont supportés. (Défaut : lighttpd)

-m, --module-path

Le chemin des modules (uniquement nécessaire si httpd est Apache). (Défaut : /usr/lib/apache2/modules)

-p, --port

Le numéro de port auquel lier le httpd. (Défaut : 1234)

-b, --browser

Le navigateur web qui devrait être utilisé pour visualiser la page gitweb. Ceci sera passé au script d'aide git web--browse avec l'URL de l'instance gitweb. Voir git-web--browse(1) pour plus d'informations à ce sujet. Si le script échoue, l'URL sera imprimée sur stdout.

start, --start

Démarre l'instance httpd et quitte. Régénère les fichiers de configuration nécessaires au lancement d'une nouvelle instance.

stop, --stop

Arrête l'instance httpd et quitte. Ceci ne génère aucun fichier de configuration pour lancer une nouvelle instance, ni ne ferme le navigateur.

restart, --restart

Redémarre l'instance httpd et quitte. Régénère les fichiers de configuration nécessaires au lancement d'une nouvelle instance.

CONFIGURATION

Vous pouvez spécifier la configuration dans votre fichier .git/config

[instaweb]
        local = true
        httpd = apache2 -f
        port = 4321
        browser = konqueror
        modulePath = /usr/lib/apache2/modules

Si la variable de configuration instaweb.browser n'est pas définie, web.browser sera utilisé à la place s'il est défini. Voir git-web--browse(1) pour plus d'informations à ce sujet.
