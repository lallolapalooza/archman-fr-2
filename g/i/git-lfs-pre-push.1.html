NOM

git-lfs-pre-push - Implémentation du hook pré-push de Git

SYNTAXE

git lfs pre-push <nom-distante> [url-distante]

DESCRIPTION

Répond aux événements de hook pré de Git. Il lit la plage de commits depuis STDIN, dans le format suivant :

<ref-local> ESP <sha1-local> ESP <ref-distante> ESP <sha1-distante> \n

Il prend également le nom et l'URL de la distante comme arguments.

Si l'un de ces objets Git est associé à des objets Git LFS, ces objets seront poussés vers l'API Git LFS.

Dans le cas de la poussée d'une nouvelle branche, la liste des objets Git sera tous les objets Git de cette branche.

Dans le cas de la suppression d'une branche, aucune tentative de pousser des objets Git LFS ne sera effectuée.

OPTIONS

•GIT_LFS_SKIP_PUSH : Ne rien faire lors du pré-push. Pour plus d'informations, voir : git-lfs-config(5).

VOIR AUSSI

git-lfs-clean(1), git-lfs-push(1).

Fait partie de la suite git-lfs(1).
