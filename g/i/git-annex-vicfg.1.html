NOM

git-annex-vicfg - éditer la configuration dans la branche git-annex

SYNOPSIS

git annex vicfg

DESCRIPTION

Ouvre EDITOR sur un fichier temporaire contenant tous les paramètres de configuration de git-annex stockés dans la branche git-annex, et lorsqu'il se ferme, stocke toutes les modifications apportées dans la branche git-annex.

Contrairement aux paramètres de configuration git, ces paramètres de configuration peuvent être vus par tous les clones du dépôt.

OPTIONS

Les git-annex-common-options(1) peuvent être utilisées.

VOIR AUSSI

git-annex(1)

git-config(1)
