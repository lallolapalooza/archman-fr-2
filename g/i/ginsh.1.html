DESCRIPTIO

N

ginsh est une interface interactive pour le framework de calcul symbolique GiNaC. Elle est destinée à servir d'outil pour tester et expérimenter les fonctionnalités de GiNaC, et non comme un remplacement pour les systèmes traditionnels de calcul formel interactif. Bien qu'elle puisse faire de nombreuses chos

es que ces systèmes traditionnels peuvent faire, ginsh ne fournit pas de constructions de programmation comme les boucles ou les expressions conditionnelle
s. Si vous avez besoin de cette fonctionnalité, il est conseillé d'écrire votre programme en C++, en utilisant le framework de classes « natif » de GiNaC.

UTILISATI

ON

FORMAT

D'ENTRÉE

Après le démarrage, ginsh affiche une invite (« > ») indiquant qu'il est prêt à accepter votre saisie. Les entrées acceptables sont des expressions numériques ou symboliques composées de nombres (par exemple 42, 2/3 ou 0.17), de symboles (par exemple x ou result), d'opérateurs mathématiques comme + et *, et de fonctions (par exemple sin ou normal). Chaque expression d'entrée doit être terminée soit par un point-virgule (;), soit par deux-points (:). Si elle est terminée par un point-virgule, ginsh évaluera l'impression du résultat sur stdout. Si elle est terminée par deux-points, ginsh évaluera l'expression mais n'imprimera pas le résultat. Il est possible de saisir plusieurs expressions sur une même ligne. Les espaces blancs (espaces, tabulations, retours à la ligne) peuvent être utilisés librement entre les jetons. Pour quitter ginsh, saisissez quit ou exit, ou tapez un EOF

(Ctrl-D)
à l'invite.

COMMENTAIRE

S

Tout ce qui suit une double barre oblique (//) jusqu'à la fin de la ligne, et toutes les lignes commençant par une dièse (#), sont traitées comme

un commentair
e et ignorées.

NOMBRE

S

ginsh accepte les nombres dans les notations décimales habituelles. Cela inclut les entiers et les rationnels de précision arbitraire ainsi que les nombres en virgule flottante en notation standard ou scientifique (par exemple 1.2E6). La règle générale est que si un nombre contient un point décimal (.), c'est un nombre en virgule flottante (imprécis) ; sinon, c'est un entier (exact) ou un rationnel. Les entiers peuvent être spécifiés en binaire, octal, hexadécimal ou dans une base arbitraire (2-36) en les préfixant par #b, #o, #x, ou #nR , respec

tive
ment.

SYMBOLE

S

Les symboles sont composés d'une chaîne de caractères alphanumériques et du souligné (_), le premier caractère devant être non numérique. Par exemple a et mu_1 sont des noms de symboles acceptables, tandis que 2pi ne l'est pas. Il est possible d'utiliser des symboles portant les mêmes noms que des fonctions (par exemple sin) ; ginsh est capable de distinguer les

deux.

Les symboles peuvent se voir attribuer des valeurs en

;

Pour annuler la valeur d'un symbole attribué,

ci-dessus.

Les symboles sont considérés comme étant dans le domaine complexe par défaut, c'est-à-dire qu'ils sont traités comme s'ils représentaient des nombres complexes. Ce comportement peut être modifié à l'aide des mots-clés real_symbols et complex_symbols et affecte tous les symboles nouvellement

Les listes sont utilisées par les fonctions subs et lsolve. Une liste se compose d'une accolade ouvrante ({), d'une séquence d'expressions (possiblement vide) séparées par des virgules, et d'une accolade fermante (})

MATRICE

S

Une matrice se compose d'un crochet ouvrant ([), d'une séquence non vide de lignes de matrice séparées par des virgules, et d'un crochet fermant (]). Chaque ligne de matrice se compose d'un crochet ouvrant ([), d'une séquence non vide d'expressions séparées par des virgules, et d'un crochet fermant (]). Si les lignes d'une matrice n'ont pas la même longueur, la largeur de la matrice devient celle de la li

FONCTION

S

Un appel de fonction dans ginsh a la

forme

où arguments est une séquence d'expressions séparées par des virgules. ginsh fournit quelques fonctions intégrées et « importe » également toutes les fonctions symboliques définies par GiNaC et des bibliothèques supplémentaires. Il n'y a aucun moyen de définir vos propres fonctions autrement qu'en liant ginsh à une bibliothèque qui définit des fonctions symboliques GiNaC.

ginsh fournit la complétion par tabulation sur les noms de fonctions : si vous tapez la première partie d'un nom de fonction, appuyer sur Tab complétera le nom si possible. Si la partie que vous avez tapée n'est pas unique, appuyer à nouveau sur Tab affichera une liste des fonctions correspondantes. Appuyer deux fois sur Tab à l'invite affichera la liste de toutes les fonctions

disponibles.

NAME

ginsh - interactive shell for GiNaC

SYNOPSIS

ginsh [file ...]

DESCRIPTION

ginsh is an interactive shell which allows you to compute with GiNaC symbols, numbers, expressions etc. It is useful for interactively testing algorithms and for performing symbolic calculations.

You can enter GiNaC expressions, assign them to symbols, and evaluate them. All standard GiNaC functions are available.

This manual page lists some of the most frequently used GiNaC functions. For a complete reference please refer to the GiNaC documentation.

All functions can be entered in uppercase or lowercase. For a list of available functions, just type in a question mark ?

Example

> ?

This will print a list of all available functions.

SPECIAL COMMANDS

To exit ginsh, enter

quit
or
exit

ginsh can display a (short) help for a given topic (mostly about functions and operators) by entering

?topic
Typing
??
will display a list of available help topics.

The command

print(expression);
will print a dump of GiNaC's internal representation for the given expression. This is useful for debugging and for learning about GiNaC internals.

The command

print_latex(expression);
prints a LaTeX representation of the given expression.

The command

print_csrc(expression);
prints the given expression in a way that can be used in a C or C++ program.

The command

iprint(expression);
prints the given expression (which must evaluate to an integer) in decimal, octal, and hexadecimal representations.

Finally, the shell escape

! [command [arguments]]
passes the given command and optionally arguments to the shell for execution. With this method, you can execute shell commands from within ginsh without having to quit.
