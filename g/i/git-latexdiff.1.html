NOM

git-latexdiff - Appeler latexdiff sur deux révisions Git d'un fichier

OPTIONS

Usage: git latexdiff [options] OLD [NEW]
       git latexdiff [options] OLD --
       git latexdiff [options] -- OLD
Appelle latexdiff sur deux révisions Git d'un fichier.
OLD et NEW sont des identifiants de révision Git. NEW est par défaut HEAD.
Si "--" est utilisé pour NEW, alors on compare avec l'espace de travail.
Options :
    --help                ce message d'aide
    --help-examples       afficher des exemples d'utilisation
    --main <fichier>      nom du fichier principal LaTeX, R Sweave,
                            ou Emacs Org mode.
                            La recherche du seul fichier contenant 'documentclass'
                            sera tentée si non spécifié.
                            Pour les fichiers non-LaTeX, une commande `prepare` raisonnable
                            sera utilisée sauf si explicitement fournie.
    --no-view             ne pas afficher le fichier PDF résultant
    --latex               exécuter latex au lieu de pdflatex
    --xelatex             exécuter xelatex au lieu de pdflatex
    --lualatex            exécuter lualatex au lieu de pdflatex
    --tectonic            exécuter tectonic au lieu de pdflatex
    --bibtex, --bbl       afficher les changements dans la bibliographie
                             (exécute bibtex pour générer les fichiers *.bbl et
                             les inclure dans le fichier source en utilisant
                             latexpand --expand-bbl avant de calculer
                             la différence)
    --biber               comme --bibtex, mais exécute biber.
    --run-bibtex, -b      exécuter bibtex ainsi que latex pour générer le fichier PDF
                             (pdflatex,bibtex,pdflatex,pdflatex)
                          NOTE : --bibtex fonctionne généralement mieux
    --run-biber           exécuter BibLaTex-Biber ainsi que latex pour générer le fichier PDF
                             (pdflatex,biber,pdflatex,pdflatex)
                          NOTE : --biber fonctionne généralement mieux
    --view                afficher le fichier PDF résultant
                            (par défaut si -o n'est pas utilisé)
    --pdf-viewer <cmd>    utiliser <cmd> pour afficher le fichier PDF (défaut : $PDFVIEWER)
    --no-cleanup          ne pas nettoyer le répertoire temporaire après exécution
    --no-flatten          ne pas appeler latexpand pour aplatir le document
    --cleanup MODE        Nettoyer les fichiers temporaires selon MODE :
                           - keeppdf (défaut) : garder uniquement le
                                  fichier PDF généré
                           - none : garder tous les fichiers temporaires
                                  (peut saturer votre disque)
                           - all : effacer tous les fichiers générés.
                                  Problématique avec --view lorsque le
                                  visualiseur est par exemple evince, et n'aime pas
                                  quand le fichier visualisé est supprimé.
    --latexmk             utiliser latexmk
    --build-dir           utiliser les PDFs d'un répertoire de construction spécifique
    --latexopt            passer des options supplémentaires à latex (par ex. -shell-escape)
    -o <fichier>, --output <fichier>
                          copier le PDF résultant dans <fichier> (se terminant généralement par .pdf)
                          Implique "--cleanup all"
    --tmpdirprefix        où le répertoire temporaire sera créé (défaut : /tmp).
                            Un chemin relatif utilisera la racine du dépôt comme base.
    --verbose, -v         fournir une sortie plus détaillée
    --quiet               rediriger la sortie des sous-processus vers des fichiers journaux
    --prepare <cmd>       exécuter <cmd> avant latexdiff (par ex. exécuter make pour générer
                             les fichiers inclus)
    --filter <cmd>        exécuter <cmd> après latexdiff et avant la compilation
                             (par ex. pour corriger la sortie de latexdiff)
    --ln-untracked        lier symboliquement les fichiers non committés de l'espace de travail
    --version             afficher la version de git-latexdiff.
    --subtree             extraire l'arbre à partir et en dessous du fichier principal
                             (activé par défaut, désactiver avec --whole-tree)
    --whole-tree          extraire l'arbre entier (à comparer avec --subtree)
    --ignore-latex-errors continuer même si latex donne des erreurs, tant qu'un
                          fichier PDF est produit.
    --ignore-makefile     ignorer le Makefile, construire comme s'il n'existait pas
    -*                    d'autres options sont passées directement à latexdiff
    --latexpand OPT       passer l'option OPT à latexpand. Utiliser plusieurs fois comme
                          --latexpand OPT1 --latexpand OPT2 pour passer plusieurs options.
    --latexdiff-flatten   utiliser --flatten de latexdiff au lieu de latexpand
Les options non reconnues sont passées telles quelles à latexdiff.
Exemples :
Comparer la révision précédente avec le dernier commit :
    git latexdiff HEAD^
Comparer le dernier commit avec l'espace de travail :
    git latexdiff HEAD --
Comparer le dernier commit avec la branche master :
    git latexdiff master HEAD
Passer --type=CHANGEBAR à latexdiff pour obtenir des barres de changement dans les marges
au lieu de la différence rouge+barré/bleu+souligné :
    git latexdiff --type=CHANGEBAR HEAD^
Utiliser un fichier de configuration latexdiff spécifique :
    git latexdiff --config /chemin/vers/fichier HEAD^
