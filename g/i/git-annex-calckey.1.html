NOM

git-annex-calckey - calcule la clé d'un fichier

SYNTAXE

git annex calckey [fichier ...]

DESCRIPTION

Cette commande de bas niveau calcule la clé qui serait utilisée pour désigner un fichier. Le fichier n'est pas ajouté à l'annexe par cette commande. La clé est affichée sur la sortie standard.

Le backend utilisé est celui défini dans le paramètre de configuration annex.backend, qui peut être remplacé par l'option --backend. Par exemple, pour forcer l'utilisation du backend SHA1 :


git annex calckey --backend=SHA1 fichier

OPTIONS

--backend=nom
Spécifie quel backend clé-valeur utiliser.
--batch
Active le mode batch, dans lequel une ligne contenant le nom du fichier est lue depuis l'entrée standard, la clé est affichée sur la sortie standard (avec une nouvelle ligne à la fin), et ainsi de suite.
-z
Fait en sorte que l'entrée du mode --batch soit délimitée par des caractères nuls au lieu des nouvelles lignes habituelles.
Aussi les options-communes-git-annex(1) peuvent être utilisées.
