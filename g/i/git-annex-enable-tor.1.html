NOM

git-annex-enable-tor - activer le service caché tor

SYNTAXE

git annex enable-tor

sudo git annex enable-tor $(id -u)

DESCRIPTION

Cette commande active un service caché tor pour git-annex.

Elle modifie le fichier /etc/tor/torrc pour enregistrer le service caché. Si elle est exécutée en tant qu'utilisateur normal, elle essaiera d'utiliser sudo/su/etc pour obtenir un accès root afin de modifier ce fichier. Si vous l'exécutez en tant que root, transmettez-lui votre numéro d'identifiant d'utilisateur non-root, tel qu'indiqué par id -u.

Après l'exécution de cette commande, git annex remotedaemon pourra être exécuté pour servir le service caché tor, puis git annex p2p --pair ou git annex p2p --gen-addresses pourra être exécuté pour donner à d'autres utilisateurs un accès à votre dépôt via le service caché tor.

OPTIONS

Les options communes à git-annex-common-options(1) peuvent être utilisées.

VOIR AUSSI

git-annex-p2p(1)

git-annex-remotedaemon(1)
