NOM

git-lfs-ls-files - Affiche les informations sur les fichiers Git LFS dans l'index et l'arbre de travail

SYNOPSIS

git lfs ls-files [<référence>]
git lfs ls-files <référence> <référence>

DESCRIPTION

Affiche les chemins des fichiers Git LFS trouvés dans l'arbre à la référence donnée. Si aucune référence n'est donnée, analyse la branche actuellement extraite. Si deux références sont données, les fichiers LFS qui ont été modifiés entre les deux références sont affichés ; les suppressions ne sont pas listées.

Un astérisque (*) après l'OID indique un objet complet, un trait d'union (-) indique un pointeur LFS.

OPTIONS

-l, --long

Affiche l'OID complet de 64 caractères, au lieu des 10 premiers.

-s, --size

Affiche la taille de l'objet LFS entre parenthèses à la fin d'une ligne.

-d, --debug

Affiche autant d'informations que possible sur un fichier LFS. Ceci est destiné à une inspection manuelle ; le format exact peut changer à tout moment.

-a, --all

Inspecte l'historique complet du dépôt, pas le HEAD actuel (ou une autre référence fournie). Cela inclura les versions précédentes des objets LFS qui ne se trouvent plus dans l'arbre actuel.

--deleted

Affiche l'historique complet de la référence donnée, y compris les objets qui ont été supprimés.

-I <chemins>, --include=<chemins>

Inclut les chemins correspondant uniquement à ces modèles ; voir [_fetch_settings].

-X <chemins>, --exclude=<chemins>

Exclut les chemins correspondant à l'un de ces modèles ; voir [_fetch_settings].

-n, --name-only

Affiche uniquement les noms des fichiers suivis par lfs.

-j, --json

Donne la sortie dans un format json stable pour les scripts.

VOIR AUSSI

git-lfs-status(1), git-lfs-config(5).

Fait partie de la suite git-lfs(1).
