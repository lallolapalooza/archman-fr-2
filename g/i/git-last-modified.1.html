NOM

git-last-modified - EXPÉRIMENTAL : Affiche quand les fichiers ont été modifiés pour la dernière fois

SYNTAXE

git last-modified [--recursive] [--show-trees] [<plage-de-révisions>] [[--] <chemin>...]

DESCRIPTION

Affiche quel commit a modifié pour la dernière fois chacun des fichiers et sous-répertoires pertinents. Un commit renommant un chemin, ou changeant son mode est également pris en compte.

CETTE COMMANDE EST EXPÉRIMENTALE. SON COMPORTEMENT PEUT CHANGER.

OPTIONS

-r, --recursive

Au lieu d'afficher les entrées d'arbre, pénètre dans les sous-arbres et affiche toutes les entrées qu'ils contiennent récursivement.

-t, --show-trees

Affiche les entrées d'arbre même lors de la récursion à l'intérieur. N'a aucun effet sans --recursive.

<plage-de-révisions>

Ne traverse que les commits dans la plage de révisions spécifiée. Lorsqu'aucune <plage-de-révisions> n'est spécifiée, elle est par défaut HEAD (c'est-à-dire tout l'historique menant au commit actuel). Pour une liste complète des façons d'épeler <plage-de-révisions>, voir la section Spécification des plages de gitrevisions(7).

[--] <chemin>...

Pour chaque <chemin> donné, le commit qui l'a modifié pour la dernière fois est renvoyé. Sans paramètre de chemin optionnel, tous les fichiers et sous-répertoires dans le parcours du chemin sont inclus dans la sortie.

VOIR AUSSI

git-blame(1), git-log(1).
