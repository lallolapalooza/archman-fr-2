git-annex-findkeys(1) Manuel des commandes générales git-annex-findkeys(1)

NOM

git-annex-findkeys - liste les clés disponibles

SYNTAXE

git annex findkeys

DESCRIPTION

Affiche une liste des clés connues par git-annex.

OPTIONS

options de correspondance
Les options de correspondance git-annex-matching-options(1) peuvent être utilisées pour spécifier quelles clés lister.
Par défaut, la commande findkeys ne liste que les clés dont le contenu est actuellement présent. La spécification de l'une des options de correspondance annulera ce comportement par défaut et fera correspondre toutes les clés que git-annex connaît.
Pour lister toutes les clés, présentes ou non, spécifiez --anything.
Pour lister les clés dont le contenu n'est pas présent, spécifiez --not --in=here
--print0
Affiche les clés terminées par des nulls, pour utilisation avec xargs -0
--format=valeur
Utilise un format de sortie personnalisé.
La valeur est une chaîne de format, dans laquelle '${var}' est développé en la valeur d'une variable. Pour justifier à droite une variable avec des espaces, utilisez '${var;largeur}' ; pour justifier à gauche une variable, utilisez '${var;-largeur}' ; pour échapper les caractères inhabituels (y compris les caractères de contrôle) dans une variable, utilisez '${var_echappee}'
Ces variables sont disponibles pour être utilisées dans les formats : key, backend, bytesize, humansize, keyname, hashdirlower, hashdirmixed, mtime (pour le champ mtime d'une clé WORM).
De plus, '\n' est un saut de ligne, '\000' est un NULL, etc.
Le format de sortie par défaut est identique à --format='${cle_echappee}\n' sauf lorsque la sortie est dirigée vers un terminal, les caractères de contrôle seront alors échappés.
--json
Affiche la liste des clés au format JSON.
Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement affichés sur la sortie d'erreur standard sont inclus dans le JSON à la place.
Les options communes git-annex-common-options(1) peuvent également être utilisées.
