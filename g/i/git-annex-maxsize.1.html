NOM

git-annex-maxsize - configurer la taille maximale d'un dépôt

SYNOPSIS

git annex maxsize dépôt taille

git annex maxsize dépôt

git annex maxsize

DESCRIPTION

Configure la taille combinée maximale des fichiers annexés qui peuvent être stockés dans un dépôt. Lorsqu'il est exécuté avec un dépôt mais sans taille, il affiche le maxsize actuellement configuré. Lorsqu'il est exécuté sans paramètres, il affiche un aperçu de la taille et du maxsize de tous les dépôts.

Le dépôt peut être spécifié par le nom de la télécommande git ou par son UUID. Pour le dépôt actuel, utilisez "here".

La taille peut être spécifiée en utilisant n'importe quelles unités. Par exemple, "100 gigaoctets" ou "0.8To".

Ceci est uniquement indicatif, cela n'empêche pas git-annex d'essayer de stocker plus de données dans un dépôt. Lorsqu'un dépôt a une expression de contenu préféré configurée à l'aide de "balanced" ou "sizebalanced", il prendra en compte le maxsize lors de la vérification du contenu préféré. Il est toujours possible que le maxsize soit dépassé, par exemple lorsqu'il y a plusieurs écrivains sur le même dépôt.

Une limite de taille dure du dépôt doit être appliquée d'une autre manière, par exemple en plaçant le dépôt sur une partition de la taille désirée. Cette commande peut alors être utilisée pour informer git-annex de cette limite de taille.

Par exemple, si un dépôt git se trouve sur un disque de 1 téraoctet, et qu'il est la seule chose stockée sur ce disque, et que annex.diskreserve est configuré à 1 gigaoctet, il serait alors logique d'exécuter git-annex maxsize here "999 gigaoctets"

Pour arrêter de vérifier la taille maximale d'un dépôt, réglez le maxsize à 0.

OPTIONS

--bytes
Affiche la taille maximale en octets, désactivant les unités plus agréables par défaut.
--json
Active la sortie JSON.
Les git-annex-common-options(1) peuvent également être utilisées.
