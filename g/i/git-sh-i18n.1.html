NOM

git-sh-i18n - Code de configuration i18n de Git pour les scripts shell

SYNOPSIS

. "$(git --exec-path)/git-sh-i18n"

DESCRIPTION

Ce n'est pas une commande que l'utilisateur final voudrait exécuter. Jamais. Cette documentation s'adresse aux personnes qui étudient les scripts de type "Porcelaine" et/ou qui en écrivent de nouveaux.

Le scriptlet 'git sh-i18n est conçu pour être sourcé (en utilisant .) par les programmes de porcelaine de Git implémentés en script shell. Il fournit des wrappers pour les fonctions GNU gettext et eval_gettext accessibles via le script gettext.sh, et fournit des solutions de repli directes sur les systèmes sans GNU gettext.

FONCTIONS

gettext

Actuellement une fonction factice de repli implémentée comme un wrapper autour de printf(1). Sera remplacée par une vraie implémentation gettext dans une version ultérieure.

eval_gettext

Actuellement une fonction factice de repli implémentée comme un wrapper autour de printf(1) avec les variables développées par l'aide git-sh-i18n--envsubst(1). Sera remplacée par une vraie implémentation gettext dans une version ultérieure.
