NOM

git-annex-renameremote - change le nom d'un dépôt distant spécial

SYNTAXE

git annex renameremote nom|uuid|desc nouveau_nom

DESCRIPTION

Change le nom utilisé pour activer un dépôt distant spécial.

Normalement, le nom actuel est utilisé pour identifier le dépôt distant spécial à renommer, mais son uuid ou sa description peuvent également être utilisés.

Ceci est particulièrement utile lorsqu'un ancien dépôt distant spécial utilisait un nom, et que vous souhaitez maintenant utiliser ce nom pour un nouveau dépôt distant spécial. git annex initremote ne vous permet pas de créer un dépôt avec un nom conflictuel, renommez donc d'abord l'ancien dépôt.


git annex renameremote phone lost-phone
git annex initremote phone ...

Ceci met uniquement à jour le nom que git-annex a stocké pour être utilisé par git annex enableremote. Cela ne met pas à jour la section de configuration git du dépôt distant spécial pour utiliser le nouveau nom, mais bien sûr, vous pouvez éditer la configuration git si vous souhaitez le renommer là.

OPTIONS

Les options communes de git-annex (git-annex-common-options(1)) peuvent être utilisées.
