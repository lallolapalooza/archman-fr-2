gi-decompile-typelib(1) Manuel des commandes générales gi-decompile-typelib(1)

Nom

gi-decompile-typelib - Décompilateur de Typelib

Syntaxe

gi-decompile-typelib [OPTION…] TYPELIB [TYPELIB…]

Description

gi-decompile-typelib est un décompilateur GIR, utilisant l'API du dépôt. Il génère des fichiers XML GIR à partir du format binaire compilé de typelib. La sortie sera écrite sur la sortie standard, sauf si --output est spécifié.

Le format binaire de typelib stocke un sous-ensemble des informations disponibles dans le XML GIR, donc toutes les typelibs ne peuvent pas être décompilées de cette manière, et le XML GIR résultant peut être incomplet.

Normalement, le XML GIR devrait être généré à partir du code source, des en-têtes et des bibliothèques partagées à l'aide de g-ir-scanner(1) <man:g-ir-scanner(1)> au lieu d'utiliser cet outil.

Options

--help
Afficher les options d'aide.
--output FILENAME, -o FILENAME
Sauvegarder la sortie résultante dans FILENAME.
--includedir DIRECTORY
Ajouter DIRECTORY au chemin de recherche des typelibs. Cette option peut être utilisée plus d'une fois. Le premier DIRECTORY sur la ligne de commande sera recherché en premier (priorité la plus élevée).
--all
Afficher toutes les informations disponibles.
--version
Afficher le numéro de version du programme et quitter.

Exemple

::
$ libdir=/usr/lib/x86_64-linux-gnu # ou /usr/lib64 ou similaire $ gi-decompile-typelib -o Gio-2.0.gir
Message système : ERREUR/3 (../glib/docs/reference/girepository/gi-decompile-typelib.rst:, ligne 84)
Indentation inattendue.
$libdir/girepository-1.0/Gio-2.0.typelib

$ diff -u /usr/share/gir-1.0/Gio-2.0.gir Gio-2.0.gir

Vous verrez que le XML GIR d'origine contient beaucoup plus d'informations que le typelib décompilé.

Signaler les bogues à https://gitlab.gnome.org/GNOME/glib/-/issues
