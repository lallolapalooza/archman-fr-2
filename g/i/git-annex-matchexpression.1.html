git-annex-matchexpression(1) Manuel des commandes générales git-annex-matchexpression(1)

NOM

git-annex-matchexpression - vérifie si une expression correspond

SYNTAXE

git annex matchexpression expression [données]

DESCRIPTION

Cette commande de bas niveau est donnée une expression de contenu préféré, et des données, et vérifie si l'expression correspond aux données. Elle se termine avec le code 0 si elle correspond, et 1 sinon. Si pas assez de données ont été fournies, elle affiche une erreur et se termine avec le code spécial 42.

Par exemple, ceci se terminera avec 0 :


git annex matchexpression "include=*.png and largerthan=1mb" --file=foo.png --size=10mb

OPTIONS

--fichier=
Fournit le nom de fichier à comparer. Notez que le fichier n'a pas besoin d'exister réellement sur le disque.
--taille=
Indique la taille du fichier. La taille peut être spécifiée avec toutes les unités couramment utilisées, par exemple, "0.5 Go" ou "100 KiloBytes".
--cle=
Indique la clé qui est comparée. Ceci est nécessaire pour comparer des expressions telles que "copies=N" et "metadonnees=etiquette=foo" et "present", qui nécessitent toutes de rechercher les informations du fichier pour une clé.
De nombreuses clés ont une taille connue, et donc --taille n'est pas nécessaire lorsque l'on spécifie une telle clé.
--fichiers-volumineux
Analyse l'expression comme une expression annex.fichiers-volumineux, plutôt qu'une expression de contenu préféré.
--type-mime=
Indique le type MIME du fichier. Nécessaire uniquement lors de l'utilisation de --fichiers-volumineux avec une expression type-mime=.
--encodage-mime=
Indique l'encodage MIME du fichier. Nécessaire uniquement lors de l'utilisation de --fichiers-volumineux avec une expression encodage-mime=.
--expliquer
Affiche une explication des parties de l'expression de contenu préféré qui correspondent et celles qui ne correspondent pas.
Les options-communes-git-annex(1) peuvent aussi être utilisées.
