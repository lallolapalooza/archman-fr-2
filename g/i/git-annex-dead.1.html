git-annex-dead(1) Manuel des commandes générales git-annex-dead(1)

NOM

git-annex-dead - masquer un dépôt ou une clé perdue

SYNOPHIS

git annex dead [dépôt ...] [--clé quelqueclé ...]

DESCRIPTION

Cette commande existe pour traiter les situations où des données ont été perdues, que vous le sachiez, et que vous vouliez cesser d'en être rappelé.

Lorsqu'un dépôt est spécifié, cela indique que le dépôt a été perdu irrécupérablement, donc il ne sera pas listé par ex. dans git annex whereis. Les dépôts peuvent être spécifiés en utilisant leur nom distant, leur description, ou leur UUID. (Pour annuler, utilisez git-annex semitrust.)

Lorsqu'une clé est spécifiée, cela indique que le contenu de cette clé a été perdu irrécupérablement. Cela fait que la clé sera ignorée lors des opérations sur toutes les clés avec par ex. --all. (Pour annuler, ajoutez le contenu de la clé au dépôt, en utilisant par ex. git-annex reinject.)

OPTIONS

--clé=quelqueclé
À utiliser pour spécifier une clé qui est morte.
--json
Active la sortie JSON. Ceci est destiné à être analysé par les programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-messages-d'erreur
Les messages qui seraient normalement affichés sur la sortie standard d'erreur sont inclus dans le JSON à la place.
Aussi les options-communes-git-annex(1) peuvent être utilisées.
