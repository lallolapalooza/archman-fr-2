NOM

git-annex-undo - annuler la dernière modification d'un fichier ou d'un répertoire

SYNOPIS

git annex [nom_fichier|répertoire] ...

DESCRIPTION

Lorsqu'un nom de fichier est passé en argument, annule la dernière modification apportée à ce fichier.

Lorsqu'un répertoire est passé en argument, annule la dernière modification apportée au contenu de ce répertoire.

Exécuter undo une seconde fois annulera l'annulation, ramenant l'arbre de travail dans l'état où il était avant. Pour permettre l'annulation d'une annulation de modifications indexées, toute modification indexée est d'abord commitée par la commande undo.

Notez que cela n'annule pas le get/drop du contenu d'un fichier ; cela n'opère que sur l'arborescence de fichiers commitée dans git.

OPTIONS

--json
Active la sortie JSON. Ceci est destiné à être interprété par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement affichés sur la sortie standard d'erreur sont inclus dans le JSON à la place.
Les options communes git-annex-common-options(1) peuvent également être utilisées.
