NOM

git-annex-forget - élaguer l'historique de la branche git-annex

SYNOPIS

git annex forget

DESCRIPTION

Réécrit la branche git-annex, rejetant les données historiques sur les emplacements passés des fichiers. La branche résultante utilisera moins d'espace, mais git annex log ne pourra plus montrer où les fichiers étaient auparavant situés.

Lorsque cette branche réécrite sera fusionnée dans d'autres clones du dépôt, git-annex effectuera automatiquement la même réécriture de leurs branches git-annex locales. L'oubli se propagera donc automatiquement à partir de son point de départ jusqu'à ce que tous les dépôts exécutant git-annex aient oublié leur ancien historique. (Vous pourriez devoir forcer git à pousser la branche vers les dépôts git qui n'exécutent pas git-annex.)

OPTIONS

--drop-dead
Élaguer également les références aux dépôts qui ont été marqués comme morts.
Également les options-communes-git-annex(1) peuvent être utilisées.
