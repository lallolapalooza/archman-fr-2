Nom

gio-querymodules - Création du cache des modules GIO

Syntaxe

gio-querymodules RÉPERTOIRE…

Description

gio-querymodules crée un fichier giomodule.cache dans les répertoires listés. Ce fichier répertorie les points d'extension implémentés par chaque module trouvé. Il est utilisé par GIO à l'exécution pour éviter d'ouvrir tous les modules afin de déterminer quels points d'extension ils implémentent.

Les modules GIO sont généralement installés dans le sous-répertoire gio/modules du libdir.
