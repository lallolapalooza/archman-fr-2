NOM

git-verify-pack - Valider les fichiers d'archive Git empaquetés

SYNOPIS

git verify-pack [-v | --verbose] [-s | --stat-only] [--] <pack>.idx...

DESCRIPTION

Lit chaque fichier idx pour l'archive Git empaquetée donnée en ligne de commande, et valide le fichier idx ainsi que le fichier pack correspondant.

OPTIONS

-v, --verbose

Après avoir validé le pack, affiche la liste des objets contenus dans le pack et un histogramme de la longueur de la chaîne de delta.

-s, --stat-only

Ne pas valider le contenu du pack ; seulement afficher l'histogramme de la longueur de la chaîne de delta. Avec --verbose, la liste des objets est également affichée.

--

Ne pas interpréter d'autres arguments comme des options.

FORMAT DE LA SORTIE

Lors de la spécification de l'option -v, le format utilisé est :

nom-objet type taille taille-dans-fichier-pack décalage-dans-fichier-pack

pour les objets qui ne sont pas défeitos dans le pack, et

nom-objet type taille taille-dans-fichier-pack décalage-dans-fichier-pack profondeur objet-base

pour les objets qui sont défeitos.
