NOM

git-lfs-filter-process - Processus de filtre Git qui convertit entre pointeurs et contenu réel

SYNTAXE

git lfs filter-process
git lfs filter-process --skip

DESCRIPTION

Implémente l'API de processus de filtre de Git, échangeant des messages de poignée de main puis acceptant et répondant aux requêtes pour nettoyer (clean) ou souiller (smudge) un fichier.

filter-process est toujours exécuté par le processus de filtre de Git et est configuré par les attributs Git du dépôt.

Dans votre configuration Git ou dans un fichier .lfsconfig, vous pouvez définir lfs.fetchinclude et/ou lfs.fetchexclude à des listes de chemins séparées par des virgules. Si lfs.fetchinclude est défini, les fichiers pointeurs Git LFS ne seront remplacés par le contenu du fichier objet Git LFS correspondant que si leur chemin correspond à l'un de ceux de cette liste, et si lfs.fetchexclude est défini, les fichiers pointeurs Git LFS ne seront remplacés par le contenu du fichier objet Git LFS correspondant que si leur chemin ne correspond à aucun de ceux de cette liste. Les chemins sont comparés à l'aide d'une correspondance de caractères génériques comme spécifié dans gitignore(5). Les fichiers pointeurs Git LFS qui ne sont pas remplacés par le contenu de leurs fichiers objets correspondants sont simplement copiés sur la sortie standard sans modification.

Le processus de filtre utilise le protocole pkt-line de Git pour communiquer, et est documenté en détail dans gitattributes(5).

OPTIONS

Sans aucune option, filter-process accepte et répond aux requêtes normalement.

--skip

Ignore le téléchargement automatique des objets lors du clonage ou du pull.

GIT_LFS_SKIP_SMUDGE

Désactive le processus de souillage (smudge). Pour plus d'informations, voir : git-lfs-config(5).

VOIR AUSSI

git-lfs-clean(1), git-lfs-install(1), git-lfs-smudge(1), gitattributes(5), gitignore(5).

Fait partie de la suite git-lfs(1).
