NOM

git-annex-updatecluster - met à jour les enregistrements des nœuds de cluster

SYNOPSIS

git-annex updatecluster

DESCRIPTION

Cette commande est utilisée pour enregistrer les nœuds d'un cluster dans la branche git-annex, et pour configurer le proxy vers les nœuds. Elle doit être exécutée dans le dépôt qui servira de passerelle vers le cluster.

Elle examine la configuration git remote.name.annex-cluster-node de chaque distant. Lorsque celle-ci est définie sur le nom d'un cluster qui a été initialisé avec git-annex initcluster, le nœud sera enregistré dans la branche git-annex.

Pour supprimer un nœud d'un cluster, désactivez remote.name.annex-cluster-node et exécutez cette commande.

Pour ajouter des passerelles supplémentaires à un cluster, après avoir exécuté cette commande, utilisez git-annex-extendcluster.

OPTIONS

Les git-annex-common-options(1) peuvent être utilisées.
