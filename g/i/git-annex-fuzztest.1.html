NOM

git-annex-fuzztest - génère des fichiers de test de fuzz

SYNOPSIS

git annex fuzztest

DESCRIPTION

Génère des modifications aléatoires sur les fichiers du dépôt courant, à utiliser pour tester l'assistant. C'est dangereux, donc cela ne fera rien à moins que --forced ne soit spécifié.

OPTIONS

Les options communes à git-annex-common-options(1) peuvent être utilisées.
