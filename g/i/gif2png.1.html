NOM

gif2png - convertir des GIFs en PNGs

SYNTAXE

gif2png [-bdfmvwO] [fichier.[gif]...]

DESCRIPTION

Le programme gif2png convertit les fichiers au format obsolète Graphic Interchange Format (GIF) en format Portable Network Graphics (PNG), une norme ouverte du W3C.

Normalement, gif2png convertit chaque fichier nommé sur la ligne de commande, en laissant l'original en place. Si un nom n'a pas d'extension .gif, le nom non modifié sera essayé en premier, suivi du nom avec .gif ajouté. Pour chaque fichier nommé foo.gif, un fichier foo.png sera créé.

Lorsqu'un fichier GIF multi-image nommé foo.gif est converti, gif2png crée plusieurs fichiers PNG, chacun contenant une image ; leurs noms seront foo.png, foo.p01, foo.p02, etc.

Si aucun fichier source n'est spécifié et que l'entrée standard est un terminal, gif2png affiche un résumé d'utilisation et des informations de version, puis se termine.

Si aucun fichier source n'est spécifié et que l'entrée standard est un périphérique ou un tuyau, l'entrée standard est convertie en noname.png. (Le programme ne peut pas être un filtre normal entrée standard vers sortie standard en raison de la possibilité que le GIF d'entrée contienne plusieurs images).

Cependant, si le mode filtre est forcé (avec -f), l'entrée standard sera convertie vers la sortie standard, et gif2png retournera un code d'erreur si le GIF est multi-image.

Toutes les données graphiques (pixels, tables de couleurs RVB) seront converties sans perte d'information. La transparence est également préservée. Le champ ratio d'aspect du GIF, le champ décalage, et les extensions sont supprimés.

Le programme détecte automatiquement les images dans lesquelles toutes les couleurs sont grises (valeurs R, V et B égales) et convertit de telles images en niveaux de gris PNG. D'autres images sont converties pour utiliser le type de palette PNG. Les entrées de couleur dupliquées sont silencieusement préservées. L'entrelacement est supprimé.

L'action du programme peut être modifiée avec les options de ligne de commande suivantes :

-b {#}RRGGBB

Arrière-plan. Remplace les pixels transparents par la valeur RVB donnée, six chiffres hexadécimaux interprétés comme deux chiffres hexadécimaux chacun pour la valeur rouge, verte et bleue. La valeur peut éventuellement être précédée d'un #, style HTML.

-d

Supprimer les fichiers GIF source après une conversion réussie.

-f

Mode filtre. Convertir le GIF de l'entrée standard en PNG sur la sortie standard, retourner une erreur si le GIF est multi-image.

-m

Conserver l'heure de modification du fichier. La sortie PNG reçoit l'heure de modification du fichier d'entrée, et non l'heure à laquelle il a été converti.

-v

Mode verbeux ; afficher une ligne de résumé, -vv active les statistiques de conversion et les messages de débogage.

-w

Option de balayage Web ; liste les GIFs qui n'ont pas d'images multiples sur la sortie standard. Les GIFs qui échouent à ce filtre génèrent des messages d'erreur sur la sortie d'erreur standard.

-O

Utiliser le niveau de compression zlib 9 (meilleure compression) au lieu du niveau par défaut.

LIMITATIONS

Convertir naïvement tous vos GIFs d'un coup avec gif2png ne vous donnera probablement pas les résultats escomptés. Les GIFs animés ne peuvent pas être traduits en PNG, qui est un format d'image unique.

L'option de balayage Web est destinée à être utilisée avec des scripts pour convertir des sites Web. Dans les versions de cet outil jusqu'à la 2.5.2, elle filtrait les GIFs avec transparence ainsi que les GIFs animés, mais la prise en charge de la transparence PNG est universelle dans les navigateurs depuis environ 2006.

VALEURS DE RETOUR

Retourne normalement 0 en cas de succès. Un retour de 1 est une erreur récupérable (le traitement par lots continue).

NORMES ET SPÉCIFICATIONS

Des copies de la spécification GIF89 sont largement disponibles sur le Web ; recherchez "GRAPHICS INTERCHANGE FORMAT". Graphics Interchange Format(c) est la propriété de copyright de CompuServe Incorporated. GIF(sm) est une marque de service de CompuServe Incorporated. Le format GIF était auparavant couvert par un brevet bloquant sur la compression LZW, mais il a expiré en juin 2003.

Le site principal du PNG à http://www.libpng.org/pub/png/ contient des informations très complètes sur la norme PNG, les bibliothèques PNG et les outils PNG.
