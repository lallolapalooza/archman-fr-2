git-branchless-next(1) Manuel des commandes générales git-branchless-next(1)

NOM

next - Passer au commit suivant dans la pile actuelle

SYNTAXE

next [-a|--all] [-b|--branch] [-o|--oldest] [-n|--newest] [-i|--interactive] [-m|--merge] [-f|--force] [-h|--help] [NUM_COMMITS]

DESCRIPTION

Passer au commit suivant dans la pile actuelle.

OPTIONS

-a, --all
Parcourir autant de commits que possible.
-b, --branch
Déplacer le nombre spécifié de branches plutôt que de commits.
-o, --oldest
Lors de la rencontre de plusieurs commits suivants, choisir le plus ancien.
-n, --newest
Lors de la rencontre de plusieurs commits suivants, choisir le plus récent.
-i, --interactive
Lors de la rencontre de plusieurs commits suivants, demander interactivement lequel choisir.
-m, --merge
Si les modifications locales entrent en conflit avec le commit de destination, tenter de les fusionner.
-f, --force
Si les modifications locales entrent en conflit avec le commit de destination, les ignorer. (À utiliser avec précaution !)
-h, --help
Afficher l'aide (voir un résumé avec '-h').
[NUM_COMMITS]
Le nombre de commits à parcourir.

S'il n'est pas fourni, la valeur par défaut est 1.
