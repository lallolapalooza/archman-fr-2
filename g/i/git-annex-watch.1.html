NOM

git-annex-watch - démon pour surveiller les changements

SYNOPSIS

git annex watch

DESCRIPTION

Surveille les changements apportés aux fichiers dans le répertoire courant et ses sous-répertoires, et s'occupe d'ajouter automatiquement les nouveaux fichiers, ainsi que de gérer les fichiers supprimés, copiés et déplacés. Avec ce processus exécuté en tant que démon en arrière-plan, vous n'avez plus besoin d'exécuter manuellement des commandes git lors de la manipulation de vos fichiers.

Par défaut, tous les nouveaux fichiers dans le répertoire seront ajoutés au dépôt. (Y compris les fichiers cachés.) Pour empêcher l'ajout de certains fichiers, utilisez les fichiers .gitignore.

Par défaut, tous les fichiers ajoutés sont ajoutés à l'annexe, comme lorsque vous exécutez git annex add. Si vous configurez annex.largefiles, les fichiers qui ne correspondent pas seront ajoutés avec git add.

OPTIONS

--foreground
Empêche le passage en arrière-plan.
--stop
Arrête un démon en cours d'exécution dans le dépôt courant.
Les git-annex-common-options(1) peuvent également être utilisés.
