NOM

git-lfs - Travailler avec des fichiers volumineux dans les dépôts Git

SYNTAXE

git lfs <commande> [<arguments>]

DESCRIPTION

Git LFS est un système pour gérer et versionner des fichiers volumineux en association avec un dépôt Git. Au lieu de stocker les fichiers volumineux dans le dépôt Git sous forme de blobs, Git LFS stocke des fichiers "pointeurs" spéciaux dans le dépôt, tout en stockant le contenu réel du fichier sur un serveur Git LFS. Le contenu du fichier volumineux est téléchargé automatiquement lorsque nécessaire, par exemple lorsque la branche Git contenant le fichier volumineux est extraite.

Git LFS fonctionne en utilisant un filtre "smudge" pour rechercher le contenu du fichier volumineux à partir du fichier pointeur, et un filtre "clean" pour créer une nouvelle version du fichier pointeur lorsque le contenu du fichier volumineux change. Il utilise également un hook pre-push pour télécharger le contenu du fichier volumineux vers le serveur Git LFS chaque fois qu'un commit contenant une nouvelle version d'un fichier volumineux est sur le point d'être poussé vers le serveur Git correspondant.

COMMANDES

Comme Git, les commandes Git LFS sont séparées en commandes de haut niveau ("porcelaine") et en commandes de bas niveau ("plomberie").

Commandes de haut niveau (porcelaine)

git-lfs-checkout(1)

Peuple le répertoire de travail avec le contenu réel des fichiers Git LFS.

git-lfs-completion(1)

Génère des scripts de shell pour la complétion par tabulation des commandes Git LFS.

git-lfs-dedup(1)

Déduplique les fichiers Git LFS.

git-lfs-env(1)

Affiche l'environnement Git LFS.

git-lfs-ext(1)

Affiche les détails des extensions Git LFS.

git-lfs-fetch(1)

Télécharge les fichiers Git LFS depuis un distant.

git-lfs-fsck(1)

Vérifie la cohérence des fichiers Git LFS.

git-lfs-install(1)

Installe la configuration Git LFS.

git-lfs-lock(1)

Définit un fichier comme "verrouillé" sur le serveur Git LFS.

git-lfs-locks(1)

Liste les fichiers actuellement "verrouillés" sur le serveur Git LFS.

git-lfs-logs(1)

Affiche les erreurs de la commande Git LFS.

git-lfs-ls-files(1)

Affiche des informations sur les fichiers Git LFS dans l'index et l'arbre de travail.

git-lfs-migrate(1)

Migre l'historique vers ou depuis Git LFS.

git-lfs-prune(1)

Supprime les anciens fichiers Git LFS du stockage local.

git-lfs-pull(1)

Récupère les modifications Git LFS du distant et extrait les fichiers nécessaires du répertoire de travail.

git-lfs-push(1)

Pousse les fichiers volumineux mis en file d'attente vers le point de terminaison Git LFS.

git-lfs-status(1)

Affiche le statut des fichiers Git LFS dans l'arbre de travail.

git-lfs-track(1)

Affiche ou ajoute des chemins Git LFS aux attributs Git.

git-lfs-uninstall(1)

Désinstalle Git LFS en supprimant les hooks et la configuration des filtres smudge/clean.

git-lfs-unlock(1)

Supprime le réglage de "verrouillé" d'un fichier sur le serveur Git LFS.

git-lfs-untrack(1)

Supprime les chemins Git LFS des attributs Git.

git-lfs-update(1)

Met à jour les hooks Git pour le dépôt Git actuel.

git-lfs-version(1)

Rapporte le numéro de version.

Commandes de bas niveau (plomberie)

git-lfs-clean(1)

Filtre Git clean qui convertit les fichiers volumineux en pointeurs.

git-lfs-filter-process(1)

Filtre de processus Git qui convertit entre fichiers volumineux et pointeurs.

git-lfs-merge-driver(1)

Fusionne les fichiers LFS basés sur du texte.

git-lfs-pointer(1)

Construit et compare les pointeurs.

git-lfs-post-checkout(1)

Implémentation du hook post-checkout de Git.

git-lfs-post-commit(1)

Implémentation du hook post-commit de Git.

git-lfs-post-merge(1)

Implémentation du hook post-merge de Git.

git-lfs-pre-push(1)

Implémentation du hook pre-push de Git.

git-lfs-smudge(1)

Filtre smudge Git qui convertit le pointeur dans les blobs en contenu réel.

git-lfs-standalone-file(1)

Adaptateur de transfert Git LFS autonome pour les URL de fichiers (chemins locaux).

EXEMPLES

Pour commencer avec Git LFS, les commandes suivantes peuvent être utilisées.

1.Installez Git LFS sur votre système. Vous n'avez à faire cela qu'une seule fois par compte utilisateur : 
git lfs install
2.Choisissez le type de fichiers que vous souhaitez suivre, par exemple toutes les images ISO, avec git-lfs-track(1) : 
git lfs track "*.iso"
3.La commande ci-dessus stocke ces informations dans des fichiers gitattributes(5), donc ce fichier doit être ajouté au dépôt : 
git add .gitattributes
4.Commitez, poussez et travaillez avec les fichiers normalement : 
git add file.iso
git commit -m "Ajouter l'image disque"
git push
