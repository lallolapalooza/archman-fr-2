NOM

git-lfs-fsck - Vérifie la cohérence des fichiers GIT LFS

SYNOPSIS

git lfs fsck [options] [révisions]

DESCRIPTION

Vérifie la cohérence de tous les fichiers Git LFS dans le HEAD actuel.

Les fichiers corrompus sont déplacés dans ".git/lfs/bad".

Les révisions peuvent être spécifiées soit comme un seul committish, auquel cas seul ce commit est inspecté ; spécifiées comme une plage de la forme A..B (et seulement cette forme), auquel cas cette plage est inspectée ; ou omises entièrement, auquel cas HEAD (et, pour --objects, l'index) est examiné.

Par défaut, toutes les vérifications sont effectuées.

Dans votre configuration Git ou dans un fichier .lfsconfig, vous pouvez définir lfs.fetchexclude à une liste de chemins séparés par des virgules. Si lfs.fetchexclude est défini, alors tous les fichiers Git LFS dont les chemins correspondent à l'un d'eux ne seront pas vérifiés pour la cohérence. Les chemins sont mis en correspondance à l'aide d'une correspondance de caractères génériques comme spécifié dans gitignore(5).

OPTIONS

--objects

Vérifie que chaque objet dans HEAD correspond à son hash attendu et que chaque objet existe sur le disque.

--pointers

Vérifie que chaque pointeur est canonique et que chaque fichier qui devrait être stocké comme fichier Git LFS l'est.

VOIR AUSSI

git-lfs-ls-files(1), git-lfs-status(1), gitignore(5).

Fait partie de la suite git-lfs(1).
