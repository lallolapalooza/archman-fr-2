NOM

git-bug-bug-show - Affiche les détails d'un bug

SYNTAXE

git-bug bug show [BUG_ID] [indicateurs]

DESCRIPTION

Affiche les détails d'un bug.

OPTIONS

--field="" Sélectionne le champ à afficher. Les valeurs valides sont [author,authorEmail,createTime,lastEdit,humanId,id,labels,shortId,status,title,actors,participants]

-f, --format="default" Sélectionne le style de formatage de la sortie. Les valeurs valides sont [default,json,org-mode]

-h, --help[=false] Aide pour show
