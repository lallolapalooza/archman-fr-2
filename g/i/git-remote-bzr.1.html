NOM

git-remote-bzr - Support de remote Git pour les dépôts Bazaar

SYNTAXE

git clone bzr::<repo-source> [<destination>]
git fetch bzr::<repo-source> [<destination>]

DESCRIPTION

Cette commande fournit le support pour utiliser les dépôts bzr comme remotes Git, via le plugin breezy-git. Pour l'instant, elle supporte le clonage depuis, le fetch depuis et le push vers des dépôts Bazaar. Le support du fetch est encore expérimental et peut être lent.

BOGUES

Veuillez signaler les bogues à https://launchpad.net/brz/+filebug
