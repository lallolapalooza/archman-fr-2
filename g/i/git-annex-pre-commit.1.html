NOM

git-annex-pre-commit - exécuté par le hook git pre-commit

SYNTAXE

git annex pre-commit [chemin ...]

DESCRIPTION

Ceci est destiné à être appelé depuis le hook pre-commit de git. git annex init crée automatiquement un hook pre-commit utilisant ceci.

Corrige les liens symboliques qui sont indexés dans le cadre d'un commit, pour s'assurer qu'ils pointent vers du contenu annexé.

Lorsqu'on est dans une vue, met à jour les métadonnées pour refléter les changements apportés aux fichiers dans la vue.

OPTIONS

Les git-annex-common-options(1) peuvent être utilisées.
