NOM

git-bug-bridge-pull - Récupère les mises à jour depuis un traqueur de bugs distant

SYNTAXE

git-bug bridge pull [NOM] [options]

DESCRIPTION

Récupère les mises à jour depuis un traqueur de bugs distant

OPTIONS

-n, --no-resume[=false] force l'importation de tous les bugs

-s, --since="" importe seulement les bugs mis à jour après la date donnée (ex : "200h" ou "2 juin 2019")

-h, --help[=false] aide pour pull
