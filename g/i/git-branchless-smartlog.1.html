git-branchless-smartlog(1) Manuel des commandes générales git-branchless-smartlog(1)

NOM

smartlog - commande `smartlog`

SYNTAXE

smartlog [--event-id] [--reverse] [--exact] [--hidden] [-h|--help] [REVSET]

DESCRIPTION

Commande `smartlog`

OPTIONS

--event-id=ID_ÉVÉNEMENT
Le point dans le temps auquel afficher le smartlog. S'il n'est pas fourni, rend le smartlog à l'heure actuelle. S'il est négatif, il est traité comme un décalage par rapport à l'événement actuel.
--reverse
Imprimer le smartlog dans l'ordre inverse de l'ordre habituel, avec les derniers commits en premier.
--exact
Ne pas ajouter automatiquement HEAD et la branche principale à la liste des commits à présenter. Ils seront toujours ajoutés s'ils sont inclus dans le revset.
--hidden
Inclure les commits cachés dans les résultats de l'évaluation des expressions revset.
-h, --help
Imprimer l'aide.
[REVSET]
Les commits à rendre. Ces commits, ainsi que tout commit associé, seront rendus.
