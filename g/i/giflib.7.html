NOM

giflib - Utilitaires GIFLIB

DESCRIPTION

GIFLIB est une bibliothèque de services liables et un ensemble d'utilitaires pour traiter les images encodées au format GIF (Graphics Interchange Format).

Ces utilitaires n'ont pas l'intention de concurrencer ou de remplacer des boîtes à outils graphiques multi-formats comme ImageMagick ou la Python Imaging Library, ni des éditeurs graphiques tels que le GIMP. Si vous avez besoin de recadrer, redimensionner, faire pivoter, activer l'entrelacement ou effectuer d'autres transformations d'image conventionnelles, trouvez l'un de ces outils ou un équivalent. Au contraire, ils sont destinés à faciliter les opérations spécifiques au format GIF que les outils multi-formats pourraient ne pas supporter adéquatement.

La documentation de l'API pour la bibliothèque de services est mieux consultée via un navigateur sur le site web du projet : http://sourceforge.net/projects/giflib/?source=directory.
