NOM

git-annex-post-receive - exécuté par le hook git post-receive

SYNOPSIS

git annex post-receive

DESCRIPTION

Ceci est destiné à être appelé depuis le hook post-receive de git. git annex init crée automatiquement un hook post-receive qui utilise cette commande.

Lorsqu'un dépôt est configuré avec receive.denyCurrentBranch=updateInstead, les pushes vers le dépôt mettent à jour son arborescence de travail. Cependant, cela ne fonctionne pas pour les dépôts qui ont une branche ajustée (adjusted branch) vérifiée. Le hook met à jour l'arborescence de travail lorsqu'il est exécuté dans un tel dépôt, de la même manière que l'exécution de git-annex merge.

Lorsqu'un dépôt est configuré pour agir comme proxy vers un remote spécial avec exporttree=yes, et que la branche annex-tracking-branch du remote configuré est reçue, le hook gère la mise à jour de l'arbre exporté vers le remote spécial.

OPTIONS

Les git-annex-common-options(1) peuvent être utilisées.
