NOM

git-request-pull - Génère un résumé des changements en attente

SYNOPSIS

git request-pull [-p] <début> <URL> [<fin>]

DESCRIPTION

Génère une demande demandant au projet en amont de récupérer des changements dans son arbre. La demande, imprimée sur la sortie standard, commence par la description de la branche, résume les changements et indique d'où ils peuvent être récupérés.

Le projet en amont est censé avoir le commit nommé par <début> et la sortie lui demande d'intégrer les changements que vous avez effectués depuis ce commit, jusqu'au commit nommé par <fin>, en visitant le dépôt nommé par <URL>.

OPTIONS

-p

Inclut le texte du patch dans la sortie.

<début>

Commit à partir duquel commencer. Ceci nomme un commit qui est déjà dans l'historique en amont.

<URL>

L'URL du dépôt à récupérer.

<fin>

Commit à la fin (par défaut HEAD). Ceci nomme le commit au bout de l'historique que vous demandez à être récupéré.

Lorsque le dépôt nommé par <URL> a un commit à la pointe d'une référence qui est différente de la référence que vous avez localement, vous pouvez utiliser la syntaxe <local>:<distant>, pour avoir son nom local, deux-points :, et son nom distant.

EXEMPLES

Imaginez que vous ayez bâti votre travail sur votre branche master par-dessus la sortie de la version v1.0, et que vous souhaitiez qu'elle soit intégrée dans le projet. D'abord, vous poussez ce changement vers votre dépôt public pour que d'autres puissent le voir :

git push https://git.ko.xz/project master

Ensuite, vous exécutez cette commande :

git request-pull v1.0 https://git.ko.xz/project master

ce qui produira une demande à l'amont, résumant les changements entre la sortie v1.0 et votre master, pour la récupérer depuis votre dépôt public.

Si vous avez poussé votre changement vers une branche dont le nom est différent de celui que vous avez localement, par exemple :

git push https://git.ko.xz/project master:for-linus

alors vous pouvez demander à ce que cela soit récupéré avec :

git request-pull v1.0 https://git.ko.xz/project master:for-linus
