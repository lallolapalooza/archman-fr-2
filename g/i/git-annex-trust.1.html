NOM

git-annex-trust - faire confiance à un dépôt

SYNOPSIS

git annex trust [dépôt ...]

DESCRIPTION

Enregistre qu'un dépôt est fiable et ne perdra pas de contenu de manière inattendue. À utiliser avec prudence.

Les dépôts peuvent être spécifiés par leur nom distant, leur description ou leur UUID. Pour faire confiance au dépôt courant, utilisez "ici".

Avant de faire confiance à un dépôt, considérez ce scénario. Le dépôt A est fiable et le dépôt B ne l'est pas ; les deux contiennent le même contenu. git-annex drop est exécuté sur le dépôt A, qui vérifie que B contient toujours le contenu, et la suppression réussit. Ensuite, git-annex drop est exécuté sur le dépôt B, qui fait confiance à A pour contenir toujours le contenu, donc la suppression réussit. Le contenu a maintenant été perdu.

OPTIONS

--json
Active la sortie JSON. Ceci est destiné à être analysé par des programmes utilisant git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement écrits sur la sortie d'erreur standard sont inclus dans le JSON à la place.
Également les options communes de git-annex(1) peuvent être utilisées.
