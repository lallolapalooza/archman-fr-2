git-branchless-record(1) Manuel des commandes générales git-branchless-record(1)

NOM

record - Créer un commit en sélectionnant interactivement les modifications à inclure

SYNTAXE

record [-m|--message] [-i|--interactive] [-c|--create] [-d|--detach] [-I|--insert] [-s|--stash] [-h|--help]

DESCRIPTION

Créer un commit en sélectionnant interactivement les modifications à inclure

OPTIONS

-m, --message=MESSAGES
Le message de commit à utiliser. S'il n'est pas fourni, une invite demandera de fournir un message de commit interactivement.
-i, --interactive
Sélectionner interactivement les modifications à inclure, plutôt que d'utiliser les modifications actuellement indexées/non indexées.
-c, --create=CREATE
Créer et basculer vers une nouvelle branche avec le nom donné avant de commiter.
-d, --detach
Détacher la branche actuelle avant de commiter.
-I, --insert
Insérer le nouveau commit entre le commit actuel et ses enfants, le cas échéant.
-s, --stash
Après avoir créé le nouveau commit, revenir au commit précédent.
-h, --help
Afficher l'aide.
