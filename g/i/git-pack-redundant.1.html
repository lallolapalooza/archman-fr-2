NOM

git-pack-redundant - Trouver les fichiers pack redondants

SYNTAXE

git pack-redundant [--verbose] [--alt-odb] (--all | <nom-de-fichier-pack>...)

AVERTISSEMENT

git pack-redundant est obsolète et est programmé pour être supprimé dans une future version de Git. Comme il ne peut supprimer que des packs entiers en double et non des objets individuels en double, ce n'est généralement pas un outil utile pour réduire la taille du dépôt. Il est préférable d'utiliser git gc à cet effet, qui placera les objets dans un nouveau pack, supprimant les doublons.

L'exécution de pack-redundant sans le drapeau --i-still-use-this échouera dans cette version. Si vous pensez avoir un cas d'utilisation pour lequel pack-redundant convient mieux et que vous vous opposez à cette suppression, veuillez contacter la liste de diffusion Git à l'adresse git@vger.kernel.org[1]. Plus d'informations sur la liste sont disponibles sur https://git-scm.com/community.

DESCRIPTION

Ce programme calcule quels packs de votre dépôt sont redondants. La sortie est adaptée pour être redirigée vers xargs rm si vous êtes à la racine du dépôt.

git pack-redundant accepte une liste d'objets sur l'entrée standard. Tous les objets donnés seront ignorés lors de la vérification des packs requis. Ceci rend la commande suivante utile si vous souhaitez supprimer des packs contenant des objets inaccessibles.

git fsck --full --unreachable | cut -d ' ' -f3 | \ git pack-redundant --all | xargs rm

OPTIONS

--all

Traite tous les packs. Tous les noms de fichiers sur la ligne de commande sont ignorés.

--alt-odb

Ne pas exiger que les objets présents dans les packs provenant de bases d'objets (odb) alternatives soient présents dans les packs locaux.

--verbose

Affiche des statistiques sur stderr. Entraîne une légère pénalité de performance.
