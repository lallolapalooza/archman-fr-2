NOM

git-warp-time - Utilitaire en ligne de commande qui réinitialise les horodatages des fichiers dans un répertoire de travail d'un dépôt Git à l'horodatage exact du dernier commit qui a modifié chaque fichier

SYNTAXE

git-warp-time [-d|--dirty] [-i|--ignored] [-o|--ignore-older] [-q|--quiet] [-h|--help] [CHEMINS]

DESCRIPTION

Utilitaire en ligne de commande qui réinitialise les horodatages des fichiers dans un répertoire de travail d'un dépôt Git à l'horodatage exact du dernier commit qui a modifié chaque fichier

OPTIONS

-d, --dirty
Inclure les fichiers suivis par Git mais avec des modifications dans la zone de travail
-i, --ignored
Inclure les fichiers suivis par Git mais aussi ignorés
-o, --ignore-older
Ne toucher que les fichiers plus récents que leur historique, ignorer ceux qui sont plus anciens
-q, --quiet
Ne pas afficher de sortie concernant les fichiers touchés ou ignorés
-h, --help
Afficher l'aide
[CHEMINS]
Liste optionnelle de chemins sur lesquels opérer au lieu du défaut qui est tous les fichiers suivis par Git
