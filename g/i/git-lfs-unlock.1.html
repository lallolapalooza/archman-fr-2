NOM

git-lfs-unlock - Supprimer le paramètre « verrouillé » pour un fichier sur le serveur Git LFS

SYNTAXE

git lfs unlock [<options>] <chemin>

DESCRIPTION

Supprime le chemin de fichier donné comme « verrouillé » sur le serveur Git LFS. Les fichiers doivent exister et avoir un état git propre avant de pouvoir être déverrouillés. L'indicateur --force ignorera ces vérifications.

OPTIONS

-r <nom>, --remote=<nom>

Spécifie le serveur Git LFS à utiliser. Ignoré si la clé de configuration lfs.url est définie.

-f, --force

Indique au serveur de supprimer le verrou, même s'il appartient à un autre utilisateur.

-i <id>, --id=<id>

Spécifie un verrou par son ID au lieu de son chemin.

-j, --json

Écrit les informations de verrouillage au format JSON sur STDOUT si la commande se termine avec succès. Destiné à l'interopérabilité avec des outils externes. Si la commande se termine avec un code de sortie non nul, des messages en texte brut seront envoyés à STDERR.

VOIR AUSSI

git-lfs-lock(1), git-lfs-locks(1).

Fait partie de la suite git-lfs(1).
