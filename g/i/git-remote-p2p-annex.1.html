NOM

git-remote-p2p-annex - programme d'aide à la connexion distante pour communiquer avec git-annex via un réseau P2P

SYNTAXE

git fetch p2p-annex::nom_réseau+adresse

git remote add nom foo p2p-annex::nom_réseau+adresse

DESCRIPTION

Il s'agit d'un programme d'aide à la connexion distante de git qui permet à git de récupérer (pull) et de pousser (push) sur un réseau P2P.

Ceci utilise une commande git-annex-p2p-<nom_réseau> pour communiquer avec le réseau P2P.
