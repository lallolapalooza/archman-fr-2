NOM

git-annex-diffdriver - pilote diff de git

SYNTAXE

git annex diffdriver [--get,--text] [-- --diffopts --]

git annex diffdriver -- commande --options --

DESCRIPTION

Normalement, git diff exécuté sur des fichiers annexés affiche les changements qui sont indexés dans git, par exemple les liens symboliques et les pointeurs annex. Cette commande permet à git diff de comparer le contenu des fichiers annexés à la place.

Cette commande peut être utilisée soit comme un simple comparateur de texte, soit comme un pont qui exécute un pilote diff externe de git.

Si certains de vos fichiers annexés sont textuels et peuvent être différenciés utilement avec diff(1), vous pouvez configurer git pour utiliser cette commande pour les comparer, en configurant .gitattributes pour contenir par exemple *.txt diff=annextextdiff et en réglant git config diff.annextextdiff.command "git annex diffdriver --text".

Si vos fichiers annexés ne sont pas textuels, vous aurez besoin d'un programme pilote diff externe capable de comparer les formats de fichiers que vous utilisez. Voir la documentation de git sur GIT_EXTERNAL_DIFF et la documentation de gitattributes(5) sur les pilotes diff externes.

Normalement, lors de l'utilisation de git diff avec un pilote diff externe, celui-ci ne verra pas le contenu des fichiers annexés, car git lui passe les liens symboliques ou les fichiers pointeurs de git-annex. Cette commande contourne le problème en exécutant le véritable pilote diff externe et en lui passant les chemins vers le contenu annexé. Configurez git pour utiliser "git-annex diffdriver -- commande params --" comme pilote diff externe, où commande est le pilote diff externe que vous souhaitez utiliser, et params sont les paramètres supplémentaires à lui passer. Notez le "--" final, qui est requis.

Par exemple, pour utiliser le programme j-c-diff comme pilote diff externe, définissez GIT_EXTERNAL_DIFF="git-annex diffdriver -- j-c-diff --"

OPTIONS

Pour obtenir le contenu des fichiers annexés depuis les dépôts distants lorsqu'ils ne sont pas déjà présents, utilisez l'option --get. Le contenu des fichiers restera dans le dépôt pour une utilisation ultérieure jusqu'à ce qu'il soit supprimé de la manière habituelle.

Pour comparer des fichiers texte avec diff(1), utilisez l'option --text. Pour passer des options supplémentaires à diff(1), utilisez par exemple "--text -- --color --"

Pour utiliser une commande pilote diff externe, les options doivent commencer par "--" suivi de la commande pilote diff, de ses options, et d'un autre "--"

Les options communes de git-annex-common-options(1) peuvent également être utilisées.
