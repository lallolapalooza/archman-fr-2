NOM

git-annex-unannex - annuler une commande d'ajout accidentelle

SYNTAXE

git annex unannex [chemin ...]

DESCRIPTION

Utilisez ceci pour annuler une commande git annex add accidentelle. Elle restaure le fichier dans l'état où il était avant l'ajout.

Notez que, par mesure de sécurité, le contenu du fichier reste dans l'annexe, jusqu'à ce que vous utilisiez git annex unused et git annex dropunused.

Ce n'est pas la commande que vous devriez utiliser si vous avez intentionnellement ajouté un fichier il y a un certain temps et que vous ne voulez plus de son contenu. Dans ce cas, vous devriez plutôt utiliser git annex drop, et vous pouvez également utiliser git rm pour supprimer le fichier.

OPTIONS

--fast
Normalement, cela effectue une copie lente du fichier. En mode --fast, il crée plutôt un lien physique vers le contenu de l'annexe. Mais utilisez le mode --fast avec prudence, car la modification du fichier modifiera le contenu de l'annexe.
--json
Active la sortie JSON. Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement émis sur la sortie d'erreur standard sont inclus dans le JSON.
Options de correspondance de fichiers
Les options de correspondance de git-annex(1) peuvent être utilisées pour spécifier les fichiers à annuler.
Également les options communes de git-annex(1) peuvent être utilisées.
