NOM

git-hook - Exécute les hooks git

SYNTAXE

git hook run [--ignore-missing] [--to-stdin=<chemin>] <nom-du-hook> [-- <arguments-du-hook>]

DESCRIPTION

Une interface de commande pour exécuter les hooks git (voir githooks(5)), à utiliser par d'autres commandes git scriptées.

SOUS-COMMANDES

run

Exécute le hook <nom-du-hook>. Voir githooks(5) pour les noms de hooks pris en charge.

Tous les arguments positionnels du hook doivent être passés après un obligatoire -- (ou --end-of-options, voir gitcli(7)). Voir githooks(5) pour les arguments que les hooks peuvent attendre (le cas échéant).

OPTIONS

--to-stdin

Pour "run"; spécifie un fichier qui sera transmis au stdin du hook. Le hook recevra l'intégralité du fichier depuis le début jusqu'à EOF.

--ignore-missing

Ignore tout hook manquant en retournant silencieusement zéro. Utilisé par les outils qui souhaitent exécuter à l'aveugle un hook qui peut être présent ou non.

VOIR AUSSI

githooks(5)
