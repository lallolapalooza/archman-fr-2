git-branchless-reword(1) Manuel des commandes générales git-branchless-reword(1)

NOM

reword - Reformuler des commits

SYNOPSIS

reword [--hidden] [-f|--force-rewrite] [-m|--message] [-d|--discard] [--fixup] [-h|--help] [REVSETS]

DESCRIPTION

Reformuler des commits

OPTIONS

--hidden
Inclure les commits cachés dans les résultats de l'évaluation des expressions revset
-f, --force-rewrite
Forcer la reformulation de commits publics, même si d'autres personnes peuvent y avoir accès
-m, --message=MESSAGES
Message à appliquer aux commits. Plusieurs messages seront combinés en paragraphes séparés, similaire à `git commit`
-d, --discard
Jeter les messages de commit originaux.

Si `commit.template` est défini, alors l'éditeur est pré-rempli avec cela ; sinon, l'éditeur démarre vide.

--fixup=COMMIT_TO_FIXUP
Un commit à "corriger". Les commits reformulés deviendront des commits `fixup!` (adaptés pour être utilisés avec `git rebase --autosquash`) ciblant le commit fourni
-h, --help
Afficher l'aide (voir un résumé avec '-h')
[REVSETS] [défaut: stack() | @]
Zéro ou plusieurs commits à reformuler
