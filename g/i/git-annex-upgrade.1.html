NOM

git-annex-upgrade - mettre à niveau le dépôt

SYNOPSIS

git annex upgrade

DESCRIPTION

Met à niveau le dépôt vers la dernière version.

Chaque dépôt git-annex possède une valeur `annex.version` dans sa configuration git, qui indique la version du dépôt. Lorsqu'une ancienne version de dépôt devient obsolète, git-annex la mettra automatiquement à niveau (sauf si `annex.autoupgraderepository` est défini sur false). Pour mettre à niveau manuellement, vous pouvez utiliser cette commande.

Parfois, il existe une version de dépôt plus récente qui n'est pas encore la valeur par défaut, et dans ce cas, vous pouvez utiliser cette commande pour y passer.

Actuellement, git-annex prend en charge les mises à niveau depuis la version 0, qui n'était utilisée que par son auteur. On s'attend à ce que git-annex prenne toujours en charge les mises à niveau depuis toutes les versions antérieures de dépôts ; c'est nécessaire pour permettre l'archivage hors ligne pendant des années et une utilisation ultérieure.

OPTIONS

--autoonly
Effectue uniquement la mise à niveau automatique possible, ne met pas nécessairement à niveau vers la dernière version. Ceci est utilisé en interne par git-annex.
--json
Active la sortie JSON. Ceci est destiné à être analysé par les programmes qui utilisent git-annex.
--json-error-messages
Les messages qui seraient normalement affichés sur la sortie d'erreur standard sont inclus dans le JSON à la place.
Les options communes git-annex-common-options(1) peuvent également être utilisées.
