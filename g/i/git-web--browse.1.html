NOM

git-web--browse - Script d'aide Git pour lancer un navigateur web

SYNTAXE

git web--browse [<options>] (<URL>|<fichier>)...

DESCRIPTION

Ce script essaie, autant que possible, d'afficher les URLs et FICHIERS passés en arguments, sous forme de pages HTML dans de nouveaux onglets d'un navigateur web déjà ouvert.

Les navigateurs (ou commandes) suivants sont actuellement pris en charge :

•firefox (c'est le défaut sous X Window quand KDE n'est pas utilisé)
•iceweasel
•seamonkey
•iceape
•chromium (également pris en charge sous le nom de chromium-browser)
•google-chrome (également pris en charge sous le nom de chrome)
•konqueror (c'est le défaut sous KDE, voir Note sur konqueror ci-dessous)
•opera
•w3m (c'est le défaut en dehors des environnements graphiques)
•elinks
•links
•lynx
•dillo
•open (c'est le défaut sous l'interface graphique Mac OS X)
•start (c'est le défaut sous MinGW)
•cygstart (c'est le défaut sous Cygwin)
•xdg-open

Des commandes personnalisées peuvent également être spécifiées.

OPTIONS

-b <navigateur>, --browser=<navigateur>

Utilise le navigateur spécifié. Il doit figurer dans la liste des navigateurs pris en charge.

-t <navigateur>, --tool=<navigateur>

Identique à ci-dessus.

-c <var.conf>, --config=<var.conf>

VAR.CONF est recherchée dans les fichiers de configuration Git. Si elle est définie, sa valeur spécifie le navigateur qui doit être utilisé.

VARIABLES DE CONFIGURATION

VAR.CONF (depuis l'option -c) et web.browser

Le navigateur web peut être spécifié en utilisant une variable de configuration passée avec l'option de ligne de commande -c (ou --config), ou la variable de configuration web.browser si la première n'est pas utilisée.

browser.<outil>.path

Vous pouvez fournir explicitement un chemin d'accès complet à votre navigateur préféré en définissant la variable de configuration browser.<outil>.path. Par exemple, vous pouvez configurer le chemin absolu vers firefox en définissant browser.firefox.path. Sinon, git web--browse suppose que l'outil est disponible dans PATH.

browser.<outil>.cmd

Lorsque le navigateur, spécifié par les options ou les variables de configuration, ne figure pas parmi ceux pris en charge, alors la variable de configuration correspondante browser.<outil>.cmd sera recherchée. Si cette variable existe, alors git web--browse traitera l'outil spécifié comme une commande personnalisée et utilisera un shell eval pour exécuter la commande avec les URLs passées en arguments.

NOTE SUR KONQUEROR

Lorsque konqueror est spécifié par une option de ligne de commande ou une variable de configuration, nous lançons kfmclient pour essayer d'ouvrir la page man HTML sur un konqueror déjà ouvert dans un nouvel onglet si possible.

Par souci de cohérence, nous essayons également une telle astuce si browser.konqueror.path est défini sur quelque chose comme CHEMIN_VERS/konqueror. Cela signifie que nous essaierons de lancer CHEMIN_VERS/kfmclient à la place.

Si vous voulez vraiment utiliser konqueror, alors vous pouvez utiliser quelque chose comme ce qui suit :

        [web]
                browser = konq
        [browser "konq"]
                cmd = CHEMIN_VERS/konqueror

Note sur git-config --global

Notez que ces variables de configuration devraient probablement être définies en utilisant l'option --global, par exemple comme ceci :

$ git config --global web.browser firefox

car elles sont probablement plus spécifiques à l'utilisateur qu'au dépôt. Voir git-config(1) pour plus d'informations à ce sujet.
