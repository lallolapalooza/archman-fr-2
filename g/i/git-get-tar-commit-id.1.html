NOM

git-get-tar-commit-id - Extraire l'identifiant de commit d'une archive créée avec git-archive

SYNTAXE

git get-tar-commit-id

DESCRIPTION

Lit une archive tar créée par git archive depuis l'entrée standard et extrait l'identifiant de commit qui y est stocké. Elle ne lit que les 1024 premiers octets de l'entrée, donc son temps d'exécution n'est pas très influencé par la taille de l'archive tar.

Si aucun identifiant de commit n'est trouvé, git get-tar-commit-id se termine silencieusement avec un code de retour de 1. Cela peut se produire si l'archive n'a pas été créée à l'aide de git archive ou si le premier paramètre de git archive était un identifiant d'arbre au lieu d'un identifiant de commit ou d'un tag.
