NOM

git-annex-webapp - lance l'application web

SYNOPSIS

git annex webapp

DESCRIPTION

Ouvre une application web qui permet une configuration facile d'un dépôt git-annex et le contrôle de l'assistant git-annex. Si l'assistant n'est pas déjà en cours d'exécution, il sera démarré. Cela provoquera l'ajout de nouveaux fichiers et l'exécution d'opérations de synchronisation.

Par défaut, l'application web n'est accessible que depuis localhost, et son lancement ouvre une fenêtre de navigateur.

OPTIONS

--listen=adresse
Utile pour utiliser l'application web sur un ordinateur distant. Ceci fait que l'application web écoute sur l'adresse IP spécifiée. (Ou sur l'adresse à laquelle un nom d'hôte spécifié est résolu.)
Ceci désactive le lancement d'un navigateur web local et affiche l'URL que vous pouvez utiliser pour ouvrir l'application web.
Définissez annex.listen dans la configuration git pour que l'application web écoute toujours sur une adresse IP.
--port=nombre
Utilisez cette option pour spécifier un port pour l'application web. Par défaut, l'application web choisit un port inutilisé.
Les options git-annex-common-options(1) peuvent également être utilisées.

UTILISER HTTPS

Lorsque vous utilisez l'application web sur un ordinateur distant, vous voudrez presque certainement activer HTTPS. L'application web utilisera HTTPS si elle trouve les fichiers .git/annex/privkey.pem et .git/annex/certificate.pem. Voici une façon de générer ces fichiers, en utilisant un certificat auto-signé :


openssl genrsa -out .git/annex/privkey.pem 4096
openssl req -new -x509 -key .git/annex/privkey.pem > .git/annex/certificate.pem
