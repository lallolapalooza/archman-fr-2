NOM

git-annex-test - exécuter la suite de tests intégrée

SYNOPSIS

git annex test

DESCRIPTION

Ceci exécute la suite de tests intégrée de git-annex.

La suite de tests s'exécute dans le sous-répertoire .t du répertoire courant.

Il peut être utile d'exécuter la suite de tests sur différents systèmes de fichiers, ou pour vérifier votre installation locale de git-annex.

OPTIONS

Il existe plusieurs options, fournies par le framework de tests tasty de Haskell. Passez --help pour plus de détails à ce sujet.

--jobs=N -JN
Nombre de tests à exécuter en parallèle. La valeur par défaut est "cpus", qui exécutera un travail par cœur de processeur.
--keep-failures
En cas d'échec des tests, laisse le répertoire .t rempli de dépôts démontrant les échecs, pour analyse ultérieure.
--test-git-config nom=valeur
La suite de tests empêche git de lire les fichiers de configuration git. Habituellement, il est bon d'exécuter la suite de tests avec une configuration git standard. Cependant, cette option peut être utile pour voir quel effet un paramètre de configuration git a sur la suite de tests.
Certains paramètres de configuration casseront la suite de tests, de manière qui est due à un bug dans git-annex. Mais il est possible que la modification d'une configuration trouve un bug légitime dans git-annex.
Une utilisation valide de ceci est de changer une configuration git à une valeur qui est prévue pour être le nouveau défaut dans une future version de git.
De plus, certaines choses ne peuvent être testées qu'avec une configuration git. Par exemple, annex.shared-sop-command doit être défini pour que la suite de tests teste en utilisant cette commande.
--test-debug
Normalement, la sortie des commandes exécutées par la suite de tests est cachée, donc même lorsque annex.debug ou --debug est activé, elle ne sera pas affichée. Cette option fait que la sortie complète des commandes exécutées par la suite de tests soit affichée. Elle fait également exécuter la suite de tests à git-annex avec --debug.
Il est conseillé d'utiliser -J1 en combinaison avec ceci, sinon la sortie des tests concurrents sera mélangée.
