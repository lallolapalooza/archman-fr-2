NOM

git-remote-tor-annex - programme d'aide à la connexion distante pour communiquer avec git-annex via tor

SYNTAXE

git fetch tor-annex::adresse.onion:port

git remote add tor tor-annex::adresse.onion:port

DESCRIPTION

Il s'agit d'un programme d'aide à la connexion distante git qui permet à git d'effectuer des opérations de pull et de push via tor(1), en communiquant avec un service caché tor.

Le service caché tor nécessite probablement un jeton d'authentification (authtoken) pour être utilisé. L'authtoken peut être fourni dans la variable d'environnement GIT_ANNEX_P2P_AUTHTOKEN. Ou, s'il existe un fichier dans .git/annex/creds/ correspondant à l'adresse onion du service caché, sa première ligne est utilisée comme authtoken.
