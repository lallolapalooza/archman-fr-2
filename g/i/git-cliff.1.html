git-cliff(1) Manuel des commandes générales git-cliff(1)

NOM

git-cliff - Un générateur de journal des modifications hautement personnalisable ⛰️

SYNTAXE

git-cliff [-h|--help] [-V|--version] [-v|--verbose]... [-i|--init] [-c|--config] [--config-url] [-w|--workdir] [-r|--repository] [--include-path] [--exclude-path] [--tag-pattern] [--with-commit] [--with-tag-message] [--ignore-tags] [--count-tags] [--skip-commit] [-p|--prepend] [-o|--output] [-t|--tag] [--bump] [--bumped-version] [-b|--body] [-l|--latest] [--current] [-u|--unreleased] [--topo-order] [--use-branch-tags] [--no-exec] [-x|--context] [--from-context] [-s|--strip] [--sort] [--github-token] [--github-repo] [--gitlab-token] [--gitlab-repo] [--gitea-token] [--gitea-repo] [--bitbucket-token] [--bitbucket-repo] [--use-native-tls] [PLAGE]

DESCRIPTION

Un générateur de journal des modifications hautement personnalisable ⛰️

OPTIONS

-h, --help
Affiche les informations d'aide
-V, --version
Affiche les informations de version
-v, --verbose
Augmente la verbosité de la journalisation
--bumped-version
Affiche la version incrémentée pour les modifications non publiées
-l, --latest
Traite les commits à partir du dernier tag
--current
Traite les commits qui appartiennent au tag actuel
-u, --unreleased
Traite les commits qui n'appartiennent à aucun tag
--topo-order
Trie les tags par ordre topologique
--use-branch-tags
Inclut uniquement les tags qui appartiennent à la branche actuelle
--no-exec
Désactive l'exécution des commandes externes
-x, --context
Affiche le contexte du journal des modifications au format JSON
--use-native-tls
Charge les certificats TLS depuis le magasin de certificats natif

PARAMÈTRES

-i, --init [<CONFIG>]
Écrit le fichier de configuration par défaut dans cliff.toml
-c, --config <CHEMIN> [défaut : cliff.toml]
Définit le fichier de configuration
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_CONFIG.
--config-url <URL>
Définit l'URL du fichier de configuration
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_CONFIG_URL.
-w, --workdir <CHEMIN>
Définit le répertoire de travail
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_WORKDIR.
-r, --repository <CHEMIN>...
Définit le dépôt git
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_REPOSITORY.
--include-path <MOTIF>...
Définit le chemin pour inclure les commits associés
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_INCLUDE_PATH.
--exclude-path <MOTIF>...
Définit le chemin pour exclure les commits associés
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_EXCLUDE_PATH.
--tag-pattern <MOTIF>
Définit l'expression régulière pour faire correspondre les tags git
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_TAG_PATTERN.
--with-commit <MSG>...
Définit les messages de commit personnalisés à inclure dans le journal des modifications
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_WITH_COMMIT.
--with-tag-message [<MSG>]
Définit le message personnalisé pour la dernière version
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_WITH_TAG_MESSAGE.
--ignore-tags <MOTIF>
Définit les tags à ignorer dans le journal des modifications
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_IGNORE_TAGS.
--count-tags <MOTIF>
Définit les tags à compter dans le journal des modifications
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_COUNT_TAGS.
--skip-commit <SHA1>...
Définit les commits qui seront ignorés dans le journal des modifications
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_SKIP_COMMIT.
-p, --prepend <CHEMIN>
Ajoute des entrées au début du fichier de journal des modifications donné
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_PREPEND.
-o, --output [<CHEMIN>]
Écrit la sortie dans le fichier donné
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_OUTPUT.
-t, --tag <TAG>
Définit le tag pour la dernière version
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_TAG.
--bump [<BUMP>]
Incrémente la version pour les modifications non publiées. Optionnellement avec une version spécifiée
-b, --body <MODELE>
Définit le modèle pour le corps du journal des modifications
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_TEMPLATE.
--from-context <CHEMIN>
Génère le journal des modifications à partir d'un contexte JSON
Peut également être spécifié avec la variable d'environnement GIT_CLIFF_CONTEXT.
-s, --strip <PARTIE>
Supprime les parties données du journal des modifications

[valeurs possibles : header, footer, all]

--sort <TRI> [défaut : oldest]
Définit le tri des commits dans les sections

[valeurs possibles : oldest, newest]

--github-token <TOKEN>
Définit le token de l'API GitHub
Peut également être spécifié avec la variable d'environnement GITHUB_TOKEN.
--github-repo <PROPRIETAIRE/REPO>
Définit le dépôt GitHub
Peut également être spécifié avec la GITHUB_REPO variable d'environnement
