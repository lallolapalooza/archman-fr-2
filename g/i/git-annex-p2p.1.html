git-annex-p2p(1) Manuel des commandes générales git-annex-p2p(1)

NOM

git-annex-p2p - configurer des liens peer-to-peer entre dépôts

SYNTAXE

git annex p2p [options]

DESCRIPTION

Cette commande peut être utilisée pour lier des dépôts git-annex sur des réseaux peer-to-peer.

git-annex inclut un support intégré pour utiliser les services cachés Tor comme réseau P2P. (Cela nécessite que Tor soit installé.)

git-annex peut également supporter d'autres réseaux P2P, en utilisant un programme auxiliaire que vous pouvez installer. Ces programmes ont des noms de la forme git-annex-p2p-<nomnet>. Voir https://git-annex.branchable.com/special_remotes/p2p/ pour plus de détails.

OPTIONS

--enable <nomnet>
Active l'utilisation du réseau P2P avec le nom spécifié.
Pour les réseaux autres que tor, cela nécessite que le programme auxiliaire git-annex-p2p-<nomnet> soit installé.
Après l'exécution de cette commande, git annex remotedaemon peut être lancé pour servir les connexions entrantes des pairs, et git annex p2p --pair ou git annex p2p --gen-addresses peut être lancé pour donner à d'autres utilisateurs l'accès à votre dépôt via le réseau P2P.
--pair
Exécutez ceci dans deux dépôts pour les jumeler sur le réseau P2P.
Ceci affichera une phrase codée, comme "3-mangue-éléphant", et vous demandera d'entrer la phrase codée de l'autre dépôt.
Une fois que les phrases codées auront été échangées, les deux dépôts seront jumelés. Une télécommande git sera créée pour l'autre dépôt, avec un nom comme "peer1".
Ceci utilise [Magic Wormhole](https://github.com/warner/magic-wormhole) pour vérifier les phrases codées et communiquer de manière sécurisée les adresses P2P des dépôts, vous devrez donc l'avoir installé sur les deux ordinateurs jumelés.
Cette fonctionnalité était présente sous une forme défectueuse dans les versions de git-annex antérieures à la version 6.20180705. Assurez-vous qu'une version suffisamment récente de git-annex est installée sur les deux ordinateurs qui sont jumelés.
--gen-addresses
Génère des adresses qui peuvent être utilisées pour accéder à ce dépôt git-annex via les réseaux P2P disponibles. L'adresse ou les adresses sont affichées sur la sortie standard.
Notez que quiconque connaît ces adresses peut accéder à votre dépôt via les réseaux P2P.
Cela peut être exécuté de manière répétée, afin de donner différentes adresses à différentes personnes.
--link
Configure une télécommande git qui est accédée via un réseau P2P.
Ceci vous demandera de saisir une adresse ; vous devriez y coller l'adresse générée par --gen-addresses dans le dépôt distant.
Par défaut, la télécommande git sera nommée "peer1", "peer2", etc. Ceci peut être outrepassé avec l'option --name.
--name
Spécifiez un nom à utiliser lors de la configuration d'une télécommande git avec --link ou --pair.
Les options communes de git-annex-common-options(1) peuvent également être utilisées.
