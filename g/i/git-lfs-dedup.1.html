NOM

git-lfs-dedup - Dédupliquer les fichiers Git LFS

SYNOPIS

git lfs dedup

DESCRIPTION

Déduplique le stockage en recréant les fichiers de l'arbre de travail comme des clones des fichiers du répertoire de stockage Git LFS en utilisant la fonctionnalité de création de fichiers copy-on-write du système d'exploitation.

Si le système d'exploitation ou le système de fichiers ne prend pas en charge la création de fichiers copy-on-write, cette commande se termine sans succès.

Cette commande se terminera également sans succès si des extensions Git LFS sont configurées, car celles-ci seront généralement utilisées pour modifier le contenu des fichiers avant qu'ils ne soient écrits dans le répertoire de stockage Git LFS, et par conséquent, les fichiers de l'arbre de travail ne devraient pas être des clones copy-on-write des fichiers objets LFS.

VOIR AUSSI

Fait partie de la suite git-lfs(1).
