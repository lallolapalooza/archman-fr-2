NOM

giftool - outil de transformation GIF

SYNTAXE

giftool [-a rapport] [-b couleur_fond] [-d delai] [-i entrelacement] [-n liste_images] [-p gauche,haut] [-s largeur,hauteur] [-t couleur_transparente] [-u indicateur_tri] [-x retrait] [-z indicateur_tri]

DESCRIPTION

Un filtre pour transformer les GIF. Sans aucune option, c'est une copie coûteuse d'un GIF de l'entrée standard vers la sortie standard. Les options spécifient des opérations de filtrage et sont exécutées dans l'ordre spécifié sur la ligne de commande.

L'option -n sélectionne les images, permettant à l'outil d'agir sur un sous-ensemble d'images dans un GIF multi-images. Cette option prend une liste d'entiers décimaux séparés par des virgules qui sont interprétés comme des indices d'image à base 1 ; ce sont les images sur lesquelles l'outil agira. Si aucune option -n n'est spécifiée, l'outil sélectionnera et transformera toutes les images.

L'option -b prend un argument entier décimal et l'utilise pour définir l'indice de couleur de fond de l'écran (base 0).

L'option -f accepte une chaîne de format de style printf et y substitue les valeurs des champs de descripteur d'image et de contrôle graphique. La chaîne est formatée et affichée une fois pour chaque image sélectionnée. Les échappements normaux de style C \b, \f, \n, \r, \t. \v, et \xNN sont interprétés ; \e produit également ESC (ASCII 0x1b). Les marqueurs de format suivants sont substitués :

%a

Octet de rapport pixel.

%b

Couleur de fond de l'écran.

%d

Délai de l'image

%h

Hauteur de l'image (dimension y)

%n

Indice de l'image

%p

Position de l'image (comme une paire x,y)

%s

Taille de l'écran (comme une paire x,y)

%t

Indice de couleur transparente de l'image

%u

Indicateur d'entrée utilisateur de l'image (booléen)

%v

Chaîne de version GIF

%w

Largeur de l'image (dimension x)

%x

Mode de retrait GIF89 de l'image

%z

Indicateur de tri de la table de couleurs de l'image (booléen, faux s'il n'y a pas de carte de couleurs locale)

Les substitutions booléennes peuvent prendre un préfixe pour modifier leur affichage :

1

"1" ou "0"

o

"on" ou "off"

t

"t" ou "f"

y

"yes" ou "no"

Ainsi, par exemple, "%oz" affiche les indicateurs de tri d'image en utilisant les chaînes "on" et "off". Le comportement par défaut sans préfixe est numérique.

L'option -a prend un argument entier décimal non signé et l'utilise pour définir l'octet de rapport d'aspect dans le bloc descripteur d'écran logique.

L'option -b prend un argument entier décimal non signé et l'utilise pour définir l'indice de couleur de fond dans le bloc descripteur d'écran logique.

L'option -d prend un argument entier décimal et l'utilise pour définir un délai, en centièmes de seconde, sur les images sélectionnées.

L'option -i définit ou efface l'entrelacement dans les images sélectionnées. Les arguments acceptables sont "1", "0", "yes", "no", "on", "off", "t", "f"

L'option -p prend une paire de coordonnées x,y (base 0) et la définit comme les coordonnées préférées du coin supérieur gauche des images sélectionnées.

L'option -s prend une paire de coordonnées x,y (base 0) et la définit comme la taille d'écran attendue pour l'affichage.

L'option -t prend un argument entier décimal et l'utilise pour définir l'indice (base 0) de la couleur de transparence dans les images sélectionnées.

L'option -u définit ou efface l'indicateur d'entrée utilisateur dans les images sélectionnées. Les arguments acceptables sont "1", "0", "yes", "no", "on", "off", "t", "f".

L'option -x prend un argument entier décimal et l'utilise pour définir le mode de retrait GIF89 dans les images sélectionnées.

L'option -z définit ou efface l'indicateur de tri de la table de couleurs dans les images sélectionnées. Les arguments acceptables sont "1", "0", "yes", "no", "on", "off", "t", "f".

Notez que les options -a, -b, -p, -s et -z sont incluses pour compléter la capacité de modifier tous les champs définis dans la norme GIF, mais elles ne devraient avoir aucun effet sur la façon dont une image est rendue sur les navigateurs ou les visionneuses modernes.
