NOM

git-annex-assist - ajoute des fichiers et synchronise les changements avec les dépôts distants

SYNTAXE

git annex assist [dépôt distant ...]

DESCRIPTION

Cette commande vous aide à ajouter des fichiers au dépôt et à synchroniser les changements avec les dépôts distants. C'est la manière la plus simple d'utiliser git-annex en ligne de commande, car une seule commande doit être exécutée régulièrement.

Cette commande ajoute d'abord les nouveaux fichiers au dépôt, et valide ceux-ci ainsi que les fichiers modifiés. Ensuite, elle exécute l'équivalent de l'exécution de [[git-annex-pull](1) suivi de git-annex-push(1).

Cette commande opère sur tous les fichiers de l'arbre de travail, même lorsqu'elle est exécutée dans un sous-répertoire. Pour limiter son champ d'action aux fichiers d'un sous-répertoire, utilisez l'option --content-of.

Pour empêcher l'ajout de certains fichiers au dépôt, utilisez les fichiers .gitignore.

Par défaut, tous les fichiers ajoutés le sont à l'annexe, comme lorsque vous exécutez git annex add. Si vous configurez annex.largefiles, les fichiers qui ne correspondent pas seront ajoutés avec git add.

OPTIONS

--message=msg -m msg
Utilisez cette option pour spécifier un message de commit.
Si plusieurs options -m sont données, leurs valeurs sont concaténées sous forme de paragraphes séparés.
--content-of=chemin -C chemin
Ajoute, tire et pousse uniquement les fichiers dans le chemin donné.
Cette option peut être répétée plusieurs fois avec des chemins différents.
De plus, toutes les options prises en charge par
git-annex-pull(1) et git-annex-push(1) peuvent être utilisées.
De plus, les git-annex-common-options(1) peuvent être utilisées.
