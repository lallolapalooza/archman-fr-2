git-annex-info(1) Manuel des commandes générales git-annex-info(1)

NOM

git-annex-info - informations sur un élément ou le dépôt

SYNTAXE

git annex info [répertoire|fichier|arbre|dépôt distant|description|uuid ...]

DESCRIPTION

Affiche des statistiques et d'autres informations pour l'élément spécifié.

Lorsque aucun élément n'est spécifié, affiche des informations générales. Celles-ci comprennent une liste de tous les dépôts connus, la quantité de données annexées présente dans le dépôt local, la taille totale de toutes les données annexées dans l'arbre de travail, la taille combinée des données annexées dans tous les dépôts, et les tailles des annexes de chaque dépôt.

Lorsqu'un répertoire est spécifié, affiche des informations sur les fichiers annexés dans ce répertoire (et ses sous-répertoires). Cela inclut la quantité de données annexées présente dans le dépôt local, la taille totale de toutes les données annexées dans le répertoire, le nombre de fichiers ayant le nombre de copies spécifié ou plus (+1, +2, etc.) ou moins (-1, -2, etc.), et des informations sur la quantité de données annexées stockées dans les dépôts connus.

Lorsqu'un arbre est spécifié, affiche des informations similaires à celles d'un répertoire, mais concernant les fichiers annexés dans cet arbre.

Lorsqu'un dépôt distant, une description de dépôt ou un UUID est spécifié, affiche des informations sur le dépôt spécifié, y compris la quantité totale de données annexées qui y est stockée, et une variété d'informations de configuration.

OPTIONS

--afficher=nom
Évite que l'info ne fasse des calculs dont vous n'avez pas besoin en spécifiant ce qu'il faut afficher. Cette option peut être spécifiée plus d'une fois.
Le nom est le texte avant le « : » dans la sortie d'info, par exemple « taille de l'annexe locale » et « tailles des annexes des dépôts ».
--rapide
Affiche uniquement les informations qui peuvent être collectées rapidement.
--json
Active la sortie JSON. Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-messages-erreur
Les messages qui seraient normalement envoyés à la sortie d'erreur standard sont inclus dans le JSON à la place.
--octets
Affiche les tailles de fichiers en octets, désactivant les unités plus agréables par défaut.
--lot
Active le mode lot, dans lequel une ligne contenant un élément est lue depuis stdin, les informations le concernant sont envoyées à stdout, et cela se répète.
-z
Fait en sorte que l'entrée --lot soit délimitée par des nuls au lieu des sauts de ligne habituels.
--autoactiver
Affiche une liste des dépôts spéciaux qui ont été configurés pour s'activer automatiquement.
--depots-morts
Affiche une liste des dépôts qui ont été marqués comme morts. Ces dépôts ne sont pas affichés dans d'autres affichages d'informations.
options correspondantes
Les git-annex-matching-options(1) peuvent être utilisées pour sélectionner quels fichiers considérer lors de l'opération sur un répertoire. Ces options sont ignorées lors de l'opération sur d'autres éléments.
Les git-annex-common-options(1) peuvent également être utilisées.

EXEMPLES

Supposons que vous souhaitiez exécuter « git annex get . », mais souhaiteriez d'abord voir combien d'espace disque cela utilisera. Exécutez alors :


git annex info --rapide . --pas --dans ici
