DESCRIPTIO

N

git difftool est une commande Git qui permet de comparer et d'éditer des fichiers entre des révisions à l'aide des outils de diff courants. git difftool est une interface pour git diff et accepte les mêmes options et arguments. Voir git-di

ff(
1).

OPTION

S

-d,

--dir-diff
Copier les fichiers modifiés vers un emplacement temporaire et effectuer un diff de répertoire sur ceux-ci. Ce mode ne demande jamais confirmation avant de lancer l'outil de
diff.

-y,

--no-prompt
Ne pas demander confirmation avant de lancer un outil de
diff.

--promp

t
Demander confirmation avant chaque invocation de l'outil de diff. C'est le comportement par défaut ; l'option est fournie pour remplacer toute
configuration.

--rotate-to=<file

>
Commencer à afficher le diff pour le chemin donné, les chemins avant celui-ci seront déplacés à la fin de la
sortie.

--skip-to=<file

>
Commencer à afficher le diff pour le chemin donné, en ignorant tous les chemins avant
celui-ci.

-t <tool>,

--tool=<tool>
Utiliser l'outil de diff spécifié par <tool>. Les valeurs valides incluent emerge, kompare, meld et vimdiff. Exécuter git difftool --tool-help pour la liste des paramètres <tool> valides.

Si un outil de diff n'est pas spécifié, git difftool utilisera la variable de configuration diff.tool. Si la variable de configuration diff.tool n'est pas définie, git difftool choisira une valeur par défaut

appropriée.

Vous pouvez fournir explicitement le chemin complet vers l'outil en définissant la variable de configuration difftool.<tool>.path. Par exemple, vous pouvez configurer le chemin absolu vers kdiff3 en définissant difftool.kdiff3.path. Sinon, git difftool suppose que l'outil est disponible dans

PATH.

Au lieu d'exécuter l'un des outils de diff connus, git difftool peut être personnalisé pour exécuter un programme alternatif en spécifiant la ligne de commande à invoquer dans une variable de configuration difftool.<tool>.cm

d.

Quand git difftool est invoqué avec cet outil (soit via l'option -t ou --tool ou la variable de configuration diff.tool) la ligne de commande configurée sera invoquée avec les variables suivantes disponibles : $LOCAL est défini au nom du fichier temporaire contenant le contenu de la pré-image du diff et $REMOTE est défini au nom du fichier temporaire contenant le contenu de la post-image du diff. $MERGED est le nom du fichier qui est en cours de comparaison. $BASE est fourni pour la compatibilité avec les commandes d'outil de fusion personnalisées et a la même valeur que $MER

GE
D.

--tool-hel

p
Afficher la liste des outils de diff pouvant être utilisés avec --tool
.

--symlinks,

--no-symlinks
Le comportement par défaut de git difftool est de créer des liens symboliques vers l'arbre de travail quand il est exécuté en mode --dir-diff et que le côté droit de la comparaison produit le même contenu que le fichier dans l'arbre de travail.

Spécifier --no-symlinks indique à git difftool de créer des copies à la place. --no-symlinks est la valeu

r par défaut
sur Windows.

-x <command>, --extcmd=<command

>
Spécifier une commande personnalisée pour visualiser les diffs. git-difftool ignore les valeurs par défaut configurées et exécute <command> $LOCAL $REMOTE quand cette option est spécifiée. De plus, $BASE est défini dans l'environnement
.

-g, --gui,

--no-gui
Quand git-difftool est invoqué avec l'option -g ou --gui, l'outil de diff par défaut sera lu depuis la variable configurée diff.guitool au lieu de diff.tool. Cela peut être sélectionné automatiquement à l'aide de la variable de configuration difftool.guiDefault. L'option --no-gui peut être utilisée pour remplacer ces paramètres. Si diff.guitool n'est pas défini, nous reviendrons dans l'ordre à merge.guitool, diff.tool, merge.tool jusqu'à ce qu'un outil soit
trouvé.

--trust-exit-code, --no-trust-exit-cod

e
Les erreurs signalées par l'outil de diff sont ignorées par défaut. Utiliser --trust-exit-code pour faire en sorte que git-difftool se termine quand un outil de diff invoqué renvoie un code de sortie non nul.

git-difftool transmettra le code de sortie de l'outil invoqué quand --trust-exit-co

de est
utilisé.

Voir git-diff(1) pour la liste complè

te des options p
rises en charge.

difftool.<tool>.

cmd
Spécifier la commande pour invoquer l'outil de diff spécifié. La commande spécifiée est évaluée dans un shell avec les variables suivantes disponibles : LOCAL est défini au nom du fichier temporaire contenant le contenu de la pré-image du diff et REMOTE est défini au nomde du fichier temporaire contenant le contenu de l'image post-diff.

Voir l'option --tool=<outil> dans git-difftool(1) pour plus de détails.

difftool.<outil>.path

Remplace le chemin pour l'outil donné. Ceci est utile si votre outil n'est pas dans le PATH.

difftool.trustExitCode

Quitte difftool si l'outil de diff appelé renvoie un statut de sortie non nul.

Voir l'option --trust-exit-code dans git-difftool(1) pour plus de détails.

difftool.prompt

Demande avant chaque invocation de l'outil de diff.

difftool.guiDefault

Définit true pour utiliser diff.guitool par défaut (équivalent à spécifier l'argument --gui), ou auto pour sélectionner diff.guitool ou diff.tool en fonction de la présence d'une valeur dans la variable d'environnement DISPLAY. La valeur par défaut est false, où l'argument --gui doit être fourni explicitement pour que diff.guitool soit utilisé.
