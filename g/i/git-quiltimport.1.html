NOM

git-quiltimport - Applique un ensemble de correctifs quilt sur la branche courante

SYNTAXE

git quiltimport [--dry-run | -n] [--author <auteur>] [--patches <rép>]
                [--series <fichier>] [--keep-non-patch]

DESCRIPTION

Applique un ensemble de correctifs quilt sur la branche Git courante, en préservant les limites des correctifs, l'ordre des correctifs et les descriptions des correctifs présents dans l'ensemble de correctifs quilt.

Pour chaque correctif, le code tente d'extraire l'auteur de la description du correctif. Si cela échoue, il utilise l'auteur spécifié avec --author comme solution de repli. Si l'option --author n'a pas été donnée, la description du correctif est affichée et l'utilisateur est invité à saisir interactivement l'auteur du correctif.

Si un sujet n'est pas trouvé dans la description du correctif, le nom du correctif est conservé comme sujet d'une seule ligne dans la description Git.

OPTIONS

-n, --dry-run

Parcourt les correctifs de la série et avertit si nous ne pouvons pas trouver toutes les informations nécessaires pour valider un correctif. Au moment de la rédaction, seuls les auteurs manquants sont signalés.

--author Nom de l'auteur <Email de l'auteur>

Le nom et l'adresse e-mail de l'auteur à utiliser lorsqu'aucune information d'auteur ne peut être trouvée dans la description du correctif.

--patches <rép>

Le répertoire où trouver les correctifs quilt.

La valeur par défaut pour le répertoire des correctifs est patches ou la valeur de la variable d'environnement $QUILT_PATCHES.

--series <fichier>

Le fichier de série quilt.

La valeur par défaut pour le fichier de série est <patches>/series ou la valeur de la variable d'environnement $QUILT_SERIES.

--keep-non-patch

Passe le drapeau -b à git mailinfo (voir git-mailinfo(1)).
