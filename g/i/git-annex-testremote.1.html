NOM

git-annex-testremote - tester les transferts vers/depuis une télécommande

SYNTAXE

git annex testremote télécommande

DESCRIPTION

Ceci teste une télécommande en lui envoyant des objets, en téléchargeant des objets depuis celle-ci, etc.

Il est sûr de l'exécuter dans un dépôt existant (le contenu du dépôt n'est pas modifié), bien que cela puisse effectuer des transferts de données coûteux.

Il est préférable de créer une nouvelle télécommande à des fins de test. Bien que le test tente de nettoyer après lui-même, si la télécommande testée avait un bug, le nettoyage pourrait échouer, laissant des données de test dans la télécommande. De plus, certaines télécommandes spéciales ne prennent pas en charge la suppression des données qui y ont été stockées, donc les données de test ne pourront pas être nettoyées lors du test de celles-ci.

Le test utilisera la configuration de la télécommande, faisant varier automatiquement les tailles de morceaux, avec le chiffrement partagé simple désactivé puis activé, et exporttree désactivé puis activé. Si la télécommande est en lecture seule, le test est limité à la vérification de diverses propriétés de téléchargement depuis celle-ci.

OPTIONS

--rapide
Effectue un ensemble de tests plus restreint.
--test-lecture-seule=fichier
Normalement, des objets aléatoires sont générés pour le test et envoyés à la télécommande. Lorsqu'une télécommande en lecture seule est testée, cela ne peut pas être fait, et vous devez donc spécifier des fichiers annexés à utiliser pour le test, en utilisant cette option. Leur contenu doit être présent dans la télécommande en lecture seule testée et dans le dépôt local.
Cette option peut être répétée.
--taille=NUnités
Ajuste la taille de base des objets générés. La valeur par défaut est 1 Mio.
Les options communes de git-annex(1) peuvent aussi être utilisées.
