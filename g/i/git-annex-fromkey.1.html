NOM

git-annex-fromkey - ajoute un fichier en utilisant une clé spécifique

SYNTAXE

git annex fromkey [clé fichier ...]

DESCRIPTION

Cette commande de bas niveau peut être utilisée pour configurer manuellement un fichier dans le dépôt git afin de le lier à une clé spécifiée.

Plusieurs paires fichier et clé peuvent être fournies sur une seule ligne de commande.

Si aucune paire clé et fichier n'est spécifiée sur la ligne de commande, l'entrée par lots est utilisée, comme si l'option --batch avait été spécifiée.

Normalement, la clé est une clé formatée git-annex. Cependant, pour faciliter l'ajout d'URL, si la clé ne peut pas être analysée comme une clé et est une URL valide, une clé URL est construite à partir de l'URL. Notez que cela n'enregistre pas l'URL comme une localisation de la clé ; utilisez git-annex-registerurl(1) pour ce faire.

OPTIONS

--force
Permet de faire pointer un fichier vers une clé dont le contenu n'est pas dans le dépôt local. La clé peut ne pas être connue de git-annex du tout.
--batch
En mode d'entrée par lots, les lignes sont lues depuis stdin, et chaque ligne doit contenir une clé et un nom de fichier, séparés par un seul espace.
-z
En mode par lots, l'entrée est délimitée par des nuls au lieu des sauts de ligne habituels.
(Notez que pour utiliser ceci, vous devez explicitement activer le mode par lots avec --batch)
--json
Active la sortie JSON. Ceci est destiné à être analysé par les programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
Les options-communes-git-annex(1) peuvent également être utilisées.
