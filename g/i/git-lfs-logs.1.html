NOM

git-lfs-logs - Afficher les erreurs de la commande git-lfs

SYNTAXE

git lfs logs
git lfs logs <fichier>
git lfs logs effacer
git lfs logs boomtown

DESCRIPTION

Affiche les erreurs de la commande git-lfs. Chaque fois qu'elle plante, les détails sont enregistrés dans ".git/lfs/logs".

COMMANDES

effacer

Efface toutes les erreurs enregistrées existantes.

boomtown

Déclenche une exception factice.

OPTIONS

Sans aucune option, git lfs logs affiche simplement la liste des journaux d'erreurs.

•<fichier> : Affiche le journal d'erreurs spécifié. Utilisez "last" pour afficher l'erreur la plus récente.

VOIR AUSSI

Fait partie de la suite git-lfs(1).
