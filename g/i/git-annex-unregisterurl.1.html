NOM

git-annex-unregisterurl - désenregistre une url pour une clé

SYNTAXE

git annex unregisterurl [clé url]

DESCRIPTION

Cette commande de bas niveau peut être utilisée pour désenregistrer des urls lorsque les clés ne peuvent plus être téléchargées à partir d'elles.

Normalement, la clé est une clé formatée par git-annex. Cependant, si la clé ne peut pas être analysée comme une clé et qu'elle est une url valide, une clé d'url est construite à partir de l'url.

Désenregistrer la dernière url web d'une clé fera que git-annex ne considérera plus que le contenu est présent dans le dépôt spécial web. Si un autre dépôt spécial revendique l'url, le désenregistrement de l'url ne mettra pas à jour les informations de présence pour ce dépôt, car le contenu peut toujours être présent sur ce dépôt.

OPTIONS

--remote=nom|uuid
Indique que l'url est censée être revendiquée par le dépôt spécifié. Si un autre dépôt revendique l'url à la place, son désenregistrement échouera.
Notez que --remote=web empêchera tout autre dépôt de revendiquer l'url.
--batch
En mode d'entrée par lots, les lignes sont lues à partir de l'entrée standard, et chaque ligne doit contenir une clé et une url, séparées par un seul espace.
-z
En mode par lots, l'entrée est délimitée par des zéros (nulls) au lieu des retours à la ligne habituels.
--json
Active la sortie JSON. Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement dirigés vers la sortie d'erreur standard sont inclus dans le JSON à la place.
Aussi les options-communes-git-annex(1) peuvent être utilisées.
