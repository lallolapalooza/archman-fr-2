git-branchless-hide(1) Manuel des commandes générales git-branchless-hide(1)

NOM

hide - Masquer les commits fournis du smartlog

SYNTAXE

hide [--hidden] [--no-delete-branches] [-r|--recursive] [-h|--help] [REVSETS]

DESCRIPTION

Masquer les commits fournis du smartlog

OPTIONS

--hidden
Inclure les commits masqués dans les résultats de l'évaluation des expressions revset
--no-delete-branches
Ne pas supprimer les branches pointant vers des commits qui seraient masqués. (Ces commits resteront donc visibles).
-r, --recursive
Masquer également récursivement tous les enfants visibles des commits fournis
-h, --help
Afficher l'aide
[REVSETS]
Zéro ou plusieurs commits à masquer
hide
