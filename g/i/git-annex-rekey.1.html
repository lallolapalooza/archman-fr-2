NOM

git-annex-rekey - changer les clés utilisées pour les fichiers

SYNTAXE

git annex rekey [fichier clé ...]

DESCRIPTION

Cette commande de bas niveau est similaire à migrate, mais vous spécifiez à la fois le fichier et la nouvelle clé à utiliser pour celui-ci.

Plusieurs paires de fichier et de clé peuvent être fournies sur une seule ligne de commande.

Notez que, contrairement à git-annex migrate, ceci ne copie pas les métadonnées, les URL, et autres informations similaires de l'ancienne clé vers la nouvelle.

OPTIONS

--force
Permet de changer la clé même pour les fichiers dont le contenu n'est pas actuellement disponible. À utiliser avec prudence.
--batch
Active le mode batch, dans lequel les lignes sont lues depuis l'entrée standard. Chaque ligne doit contenir le fichier et la nouvelle clé à utiliser pour ce fichier, séparés par un seul espace.
-z
Fait en sorte que l'entrée --batch soit délimitée par des caractères nuls au lieu des retours à la ligne habituels.
--json
Active la sortie JSON. Ceci est destiné à être analysé par des programmes qui utilisent git-annex. Chaque ligne de sortie est un objet JSON.
--json-error-messages
Les messages qui seraient normalement affichés sur la sortie d'erreur standard sont inclus dans le JSON à la place.
Aussi les options communes de git-annex(1) peuvent être utilisées.
