NOM

gh-project-item-archive - Archiver un élément dans un projet

SYNOPSIS

gh project item-archive [<numéro>] [flags]

OPTIONS

--format <string>
Format de sortie : {json}
--id <string>
ID de l'élément à archiver
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--owner <string>
Login du propriétaire. Utiliser "@me" pour l'utilisateur actuel.
-t, --template <string>
Formater la sortie JSON en utilisant un modèle Go ; voir "gh help formatting"
--undo
Désarchiver un élément

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Archiver un élément dans le projet "1" de l'utilisateur actuel
$ gh project item-archive 1 --owner "@me" --id <ID-de-l-élément>
