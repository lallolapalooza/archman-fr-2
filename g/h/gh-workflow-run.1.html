NOM

gh-workflow-run - Exécute un workflow en créant un événement workflow_dispatch

SYNTAXE

gh workflow run [<id-du-workflow> | <nom-du-workflow>] [flags]

DESCRIPTION

Crée un événement workflow_dispatch pour un workflow donné.

Cette commande déclenchera GitHub Actions pour exécuter un fichier de workflow donné. Le fichier de workflow doit prendre en charge un déclencheur on.workflow_dispatch pour pouvoir être exécuté de cette manière.

Si le fichier de workflow prend en charge des entrées, elles peuvent être spécifiées de plusieurs manières :

  • Interactivement
  • Via les options -f/--raw-field ou -F/--field
  • Sous forme de JSON, via l'entrée standard

OPTIONS

-F, --field <clé=valeur>
Ajoute un paramètre de chaîne au format clé=valeur, en respectant la syntaxe @ (voir "gh help api").
--json
Lit les entrées du workflow sous forme de JSON via STDIN.
-f, --raw-field <clé=valeur>
Ajoute un paramètre de chaîne au format clé=valeur.
-r, --ref <chaîne>
Nom de la branche ou du tag qui contient la version du fichier de workflow que vous souhaitez exécuter.

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/REPO>
Sélectionne un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/REPO.

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

# Demande à gh quel workflow exécuter et collecte interactivement les entrées
$ gh workflow run
# Exécute le fichier de workflow 'triage.yml' sur la branche par défaut du distant
$ gh workflow run triage.yml
# Exécute le fichier de workflow 'triage.yml' sur une référence spécifiée
$ gh workflow run triage.yml --ref ma-branche
# Exécute le fichier de workflow 'triage.yml' avec des entrées en ligne de commande
$ gh workflow run triage.yml -f nom=scully -f salutation=bonjour
# Exécute le fichier de workflow 'triage.yml' avec du JSON via l'entrée standard
$ echo '{"nom":"scully", "salutation":"bonjour"}' | gh workflow run triage.yml --json
