NOM

gh-auth-switch - Changer de compte GitHub actif

SYNTAXE

gh auth switch [options]

DESCRIPTION

Change le compte actif pour un hôte GitHub spécifié.

Cette commande modifie la configuration d'authentification qui sera utilisée lors de l'exécution de commandes ciblant l'hôte GitHub spécifié.

Si l'hôte spécifié a deux comptes, le compte actif sera changé automatiquement. S'il y a plus de deux comptes, une désambiguïsation sera requise, soit via l'option --user, soit par une invite interactive.

Pour obtenir une liste des comptes authentifiés, vous pouvez exécuter gh auth status.

OPTIONS

-h, --hostname <chaîne>
Le nom d'hôte de l'instance GitHub pour laquelle changer de compte
-u, --user <chaîne>
Le compte vers lequel changer

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Sélectionner quel hôte et compte changer via une invite
$ gh auth switch
# Changer le compte actif sur un hôte spécifique vers un utilisateur spécifique
$ gh auth switch --hostname enterprise.internal --user monalisa
