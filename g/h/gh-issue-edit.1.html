NOM

gh-issue-edit - Modifier des problèmes

SYNTAXE

gh issue edit {<numéros> | <urls>} [indicateurs]

DESCRIPTION

Modifie un ou plusieurs problèmes dans le même dépôt.

La modification des projets d'un problème nécessite une autorisation avec la portée project. Pour autoriser, exécutez gh auth refresh -s project.

Les indicateurs --add-assignee et --remove-assignee prennent tous deux en charge les valeurs spéciales suivantes : - @me : assigner ou désassigner vous-même - @copilot : assigner ou désassigner Copilot (non pris en charge sur GitHub Enterprise Server)

OPTIONS

--add-assignee <login>
Ajoute les utilisateurs assignés par leur nom d'utilisateur. Utilisez "@me" pour vous assigner vous-même, ou "@copilot" pour assigner Copilot.
--add-label <nom>
Ajoute des étiquettes par leur nom
--add-project <titre>
Ajoute le problème aux projets par leur titre
-c, --body <chaîne>
Définit le nouveau corps.
-F, --body-file <fichier>
Lit le texte du corps depuis un fichier (utilisez "-" pour lire depuis l'entrée standard)
-m, --milestone <nom>
Modifie le jalon auquel le problème appartient par son nom
--remove-assignee <login>
Supprime les utilisateurs assignés par leur nom d'utilisateur. Utilisez "@me" pour vous désassigner vous-même, ou "@copilot" pour désassigner Copilot.
--remove-label <nom>
Supprime des étiquettes par leur nom
--remove-milestone
Supprime l'association du jalon du problème
--remove-project <titre>
Retire le problème des projets par leur titre
-t, --title <chaîne>
Définit le nouveau titre.

OPTIONS HERITÉS DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionne un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh issue edit 23 --title "J'ai trouvé un bug" --body "Rien ne fonctionne"
$ gh issue edit 23 --add-label "bug,aide voulue" --remove-label "core"
$ gh issue edit 23 --add-assignee "@me" --remove-assignee monalisa,hubot
$ gh issue edit 23 --add-assignee "@copilot"
$ gh issue edit 23 --add-project "Feuille de route" --remove-project v1,v2
$ gh issue edit 23 --milestone "Version 1"
$ gh issue edit 23 --remove-milestone
$ gh issue edit 23 --body-file body.txt
$ gh issue edit 23 34 --add-label "aide voulue"
