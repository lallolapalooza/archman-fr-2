NOM

gh-search-repos - Rechercher des dépôts

SYNOPSIS

gh search repos [<requête>] [drapeaux]

DESCRIPTION

Rechercher des dépôts sur GitHub.

La commande permet de construire des requêtes en utilisant la syntaxe de recherche de GitHub, les drapeaux de paramètres et de qualificateurs, ou une combinaison des deux.

La syntaxe de recherche de GitHub est documentée à l'adresse :

⟨https://docs.github.com/search-github/searching-on-github/searching-for-repositories⟩

Pour plus d'informations sur le traitement des requêtes de recherche contenant un trait d'union, exécutez gh search --help.

OPTIONS

--archived
Filtrer selon l'état archivé du dépôt {true|false}
--created <date>
Filtrer selon la date de création
--followers <nombre>
Filtrer selon le nombre de followers
--forks <nombre>
Filtrer selon le nombre de forks
--good-first-issues <nombre>
Filtrer selon le nombre d'issues avec l'étiquette « good first issue »
--help-wanted-issues <nombre>
Filtrer selon le nombre d'issues avec l'étiquette « help wanted »
--include-forks <chaîne>
Inclure les forks dans les dépôts récupérés : {false|true|only}
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Afficher en JSON avec les champs spécifiés
--language <chaîne>
Filtrer selon le langage de programmation
--license <chaînes>
Filtrer selon le type de licence
-L, --limit <int> (par défaut 30)
Nombre maximal de dépôts à récupérer
--match <chaînes>
Restreindre la recherche à un champ spécifique du dépôt : {name|description|readme}
--number-topics <nombre>
Filtrer selon le nombre de topics
--order <chaîne> (par défaut « desc »)
Ordre des dépôts retournés, ignoré sauf si le drapeau '--sort' est spécifié : {asc|desc}
--owner <chaînes>
Filtrer selon le propriétaire
--size <chaîne>
Filtrer selon une plage de tailles, en kilo-octets
--sort <chaîne> (par défaut « best-match »)
Trier les dépôts récupérés : {forks|help-wanted-issues|stars|updated}
--stars <nombre>
Filtrer selon le nombre d'étoiles
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »
--topic <chaînes>
Filtrer selon le topic
--updated <date>
Filtrer selon la date de dernière mise à jour
--visibility <chaînes>
Filtrer selon la visibilité : {public|private|internal}
-w, --web
Ouvrir la requête de recherche dans le navigateur web

CHAMPS JSON

createdAt, defaultBranch, description, forksCount, fullName, hasDownloads, hasIssues, hasPages, hasProjects, hasWiki, homepage, id, isArchived, isDisabled, isFork, isPrivate, language, license, name, openIssuesCount, owner, pushedAt, size, stargazersCount, updatedAt, url, visibility, watchersCount

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

REMARQUE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

# Rechercher les dépôts correspondant à l'ensemble de mots-clés « cli » et « shell »
$ gh search repos cli shell
# Rechercher les dépôts correspondant à la phrase « vim plugin »
$ gh search repos "vim plugin"
# Rechercher les dépôts publics de l'organisation microsoft
$ gh search repos --owner=microsoft --visibility=public
# Rechercher les dépôts avec un ensemble de topics
$ gh search repos --topic=unix,terminal
# Rechercher les dépôts par langage de programmation et nombre de good first issues
$ gh search repos --language=go --good-first-issues=">=10"
# Rechercher les dépôts sans le topic « linux »
$ gh search repos -- -topic:linux
# Rechercher les dépôts en excluant les dépôts archivés
$ gh search repos --archived=false
