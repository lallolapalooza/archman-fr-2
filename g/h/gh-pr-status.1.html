GH-PR-STATUS(1) Manuel de l'outil en ligne de commande GitHub GH-PR-STATUS(1)

NOM

gh-pr-status - Afficher le statut des pull requests pertinentes

SYNTAXE

gh pr status [options]

DESCRIPTION

Affiche le statut des pull requests pertinentes.

Le statut montre un résumé des pull requests qui inclut des informations telles que le numéro de la pull request, le titre, les vérifications CI, les revues, etc.

Pour voir plus de détails sur les vérifications CI, exécutez gh pr checks.

OPTIONS

-c, --conflict-status
Affiche le statut de conflit de fusion de chaque pull request
-q, --jq <expression>
Filtre la sortie JSON à l'aide d'une expression jq
--json <champs>
Produit une sortie JSON avec les champs spécifiés
-t, --template <chaîne>
Met en forme la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »

OPTIONS HÉRITÉES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionne un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CHAMPS JSON

additions, assignees, author, autoMergeRequest, baseRefName, baseRefOid, body, changedFiles, closed, closedAt, closingIssuesReferences, comments, commits, createdAt, deletions, files, fullDatabaseId, headRefName, headRefOid, headRepository, headRepositoryOwner, id, isCrossRepository, isDraft, labels, latestReviews, maintainerCanModify, mergeCommit, mergeStateStatus, mergeable, mergedAt, mergedBy, milestone, number, potentialMergeCommit, projectCards, projectItems, reactionGroups, reviewDecision, reviewRequests, reviews, state, statusCheckRollup, title, updatedAt, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.
