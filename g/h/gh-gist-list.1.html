NOM

gh-gist-list - Lister vos gists

SYNTAXE

gh gist list [options]

DESCRIPTION

Liste les gists de votre compte utilisateur.

Vous pouvez utiliser une expression régulière pour filtrer la description, les noms de fichiers, ou même le contenu des fichiers dans le gist en utilisant --filter.

Pour la syntaxe des expressions régulières prise en charge, voir ⟨https://pkg.go.dev/regexp/syntax⟩.

Utilisez --include-content pour inclure le contenu des fichiers, en notant que cela sera plus lent et augmentera l'utilisation de la limite de débit. Au lieu d'imprimer un tableau, le code sera imprimé avec des mises en surbrillance similaires à gh search code :

{{ID du gist}} {{nom du fichier}}
    {{description}}
        {{lignes correspondantes du contenu}}

Aucune mise en surbrillance ou autre couleur n'est imprimée lorsque la sortie est redirigée.

OPTIONS

--filter <expression>
Filtre les gists en utilisant une expression régulière
--include-content
Inclut le contenu des fichiers des gists lors du filtrage
-L, --limit <int> (par défaut 10)
Nombre maximum de gists à récupérer
--public
Affiche uniquement les gists publics
--secret
Affiche uniquement les gists secrets

ALIAS

gh gist ls

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Lister tous les gists secrets de votre compte utilisateur
$ gh gist list --secret
# Trouver tous les gists de votre compte utilisateur mentionnant "octo" n'importe où
$ gh gist list --filter octo --include-content
