NOM

gh-pr-view - Afficher une pull request

SYNTAXE

gh pr view [<numéro> | <url> | <branche>] [options]

DESCRIPTION

Affiche le titre, le corps et d'autres informations d'une pull request.

Sans argument, la pull request appartenant à la branche actuelle est affichée.

Avec l'option --web, la pull request est ouverte dans un navigateur web à la place.

OPTIONS

-c, --comments
Afficher les commentaires de la pull request
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--json <champs>
Sortie JSON avec les champs spécifiés
-t, --template <chaîne>
Formater la sortie JSON en utilisant un template Go ; voir « gh help formatting »
-w, --web
Ouvrir une pull request dans le navigateur

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/REPO

CHAMPS JSON

additions, assignees, author, autoMergeRequest, baseRefName, baseRefOid, body, changedFiles, closed, closedAt, closingIssuesReferences, comments, commits, createdAt, deletions, files, fullDatabaseId, headRefName, headRefOid, headRepository, headRepositoryOwner, id, isCrossRepository, isDraft, labels, latestReviews, maintainerCanModify, mergeCommit, mergeStateStatus, mergeable, mergedAt, mergedBy, milestone, number, potentialMergeCommit, projectCards, projectItems, reactionGroups, reviewDecision, reviewRequests, reviews, state, statusCheckRollup, title, updatedAt, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
