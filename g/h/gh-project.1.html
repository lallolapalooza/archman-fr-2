NOM

gh-project - Gérer les Projets GitHub.

SYNTAXE

gh project <commande> [options]

DESCRIPTION

Gérer les Projets GitHub.

La portée minimale requise pour le jeton est : project. Vous pouvez vérifier la portée de votre jeton en exécutant gh auth status et ajouter la portée project en exécutant gh auth refresh -s project.

COMMANDES DISPONIBLES

gh-project-close(1)
Fermer un projet
gh-project-copy(1)
Copier un projet
gh-project-create(1)
Créer un projet
gh-project-delete(1)
Supprimer un projet
gh-project-edit(1)
Modifier un projet
gh-project-field-create(1)
Créer un champ dans un projet
gh-project-field-delete(1)
Supprimer un champ dans un projet
gh-project-field-list(1)
Lister les champs d'un projet
gh-project-item-add(1)
Ajouter une requête de tirage ou un problème à un projet
gh-project-item-archive(1)
Archiver un élément dans un projet
gh-project-item-create(1)
Créer un brouillon de problème dans un projet
gh-project-item-delete(1)
Supprimer un élément d'un projet par son ID
gh-project-item-edit(1)
Modifier un élément dans un projet
gh-project-item-list(1)
Lister les éléments d'un projet
gh-project-link(1)
Lier un projet à un dépôt ou une équipe
gh-project-list(1)
Lister les projets d'un propriétaire
gh-project-mark-template(1)
Marquer un projet comme modèle
gh-project-unlink(1)
Détacher un projet d'un dépôt ou d'une équipe
gh-project-view(1)
Afficher un projet

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh project create --owner monalisa --title "Roadmap"
$ gh project view 1 --owner cli --web
$ gh project field-list 1 --owner cli
$ gh project item-list 1 --owner cli
