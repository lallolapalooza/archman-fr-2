NOM

gh-ruleset-list - Lister les ensembles de règles pour un dépôt ou une organisation

SYNTAXE

gh ruleset list [indicateurs]

DESCRIPTION

Liste les ensembles de règles GitHub pour un dépôt ou une organisation.

Si aucune option n'est fournie, les ensembles de règles du dépôt actuel sont listés. Vous pouvez interroger les ensembles de règles d'un autre dépôt en utilisant l'indicateur --repo. Vous pouvez également utiliser l'indicateur --org pour lister les ensembles de règles configurés pour l'organisation fournie.

Utilisez l'indicateur --parents pour contrôler si les ensembles de règles configurés à des niveaux supérieurs qui s'appliquent également au dépôt ou à l'organisation fournis doivent être retournés. La valeur par défaut est true.

Votre jeton d'accès doit avoir la portée admin:org pour utiliser l'indicateur --org, qui peut être accordée en exécutant gh auth refresh -s admin:org.

OPTIONS

-L, --limit <entier> (par défaut 30)
Nombre maximum d'ensembles de règles à lister
-o, --org <chaîne>
Lister les ensembles de règles à l'échelle de l'organisation pour l'organisation fournie
-p, --parents (par défaut true)
Indique s'il faut inclure les ensembles de règles configurés à des niveaux supérieurs qui s'appliquent également
-w, --web
Ouvrir la liste des ensembles de règles dans le navigateur Web

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/DEPOT>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/DEPOT

ALIASES

gh rs ls, gh ruleset ls

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Lister les ensembles de règles dans le dépôt actuel
$ gh ruleset list
# Lister les ensembles de règles dans un autre dépôt, y compris ceux configurés à des niveaux supérieurs
$ gh ruleset list --repo proprietaire/depot --parents
# Lister les ensembles de règles dans une organisation
$ gh ruleset list --org nom-organisation
