NOM

gh-extension-search - Rechercher des extensions pour la CLI GitHub

SYNTAXE

gh extension search [<requête>] [flags]

DESCRIPTION

Recherche des extensions gh.

Sans arguments, cette commande affiche les 30 premières extensions disponibles à installer, triées par nombre d'étoiles. Plus d'extensions peuvent être récupérées en spécifiant une limite plus élevée avec le flag --limit.

Lorsqu'elle est connectée à un terminal, cette commande affiche trois colonnes. La première contient un ✓ si l'extension est déjà installée localement. La deuxième est le nom complet du dépôt de l'extension au format PROPRIÉTAIRE/DÉPÔT. La troisième est la description de l'extension.

Lorsqu'elle n'est pas connectée à un terminal, le caractère ✓ est rendu sous forme du mot "installé", mais sinon l'ordre et le contenu des colonnes sont identiques.

Cette commande se comporte de manière similaire à gh search repos mais ne prend pas en charge autant de qualificateurs de recherche. Pour une recherche plus précise des extensions, essayez d'utiliser :

gh search repos --topic "gh-extension"

et ajoutez des qualificateurs selon vos besoins. Voir gh help search repos pour en savoir plus sur la recherche de dépôts.

Pour lister uniquement les extensions déjà installées localement, voir :

gh ext list

OPTIONS

-q, --jq <expression>
Filtre la sortie JSON à l'aide d'une expression jq.
--json <champs>
Affiche la sortie JSON avec les champs spécifiés.
--license <chaînes>
Filtre basé sur le type de licence.
-L, --limit <entier> (par défaut 30)
Nombre maximum d'extensions à récupérer.
--order <chaîne> (par défaut "desc")
Ordre des dépôts retournés, ignoré sauf si le flag '--sort' est spécifié : {asc|desc}
--owner <chaînes>
Filtre sur le propriétaire.
--sort <chaîne> (par défaut "best-match")
Trie les dépôts récupérés : {forks|help-wanted-issues|stars|updated}
-t, --template <chaîne>
Formate la sortie JSON à l'aide d'un template Go ; voir "gh help formatting".
-w, --web
Ouvre la requête de recherche dans le navigateur web.

CHAMPS JSON

createdAt, defaultBranch, description, forksCount, fullName, hasDownloads, hasIssues, hasPages, hasProjects, hasWiki, homepage, id, isArchived, isDisabled, isFork, isPrivate, language, license, name, openIssuesCount, owner, pushedAt, size, stargazersCount, updatedAt, url, visibility, watchersCount

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Liste les 30 premières extensions triées par nombre d'étoiles, décroissant
$ gh ext search
# Liste plus d'extensions
$ gh ext search --limit 300
# Liste les extensions correspondant au terme "branch"
$ gh ext search branch
# Liste les extensions appartenant à l'organisation "github"
$ gh ext search --owner github
# Liste les extensions, triées par mise à jour récente, croissant
$ gh ext search --sort updated --order asc
# Liste les extensions, filtrées par licence
$ gh ext search --license MIT
# Ouvre les résultats de recherche dans le navigateur
$ gh ext search -w
