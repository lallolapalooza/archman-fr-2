NOM

gh-label-create - Créer une nouvelle étiquette

SYNTAXE

gh label create <nom> [options]

DESCRIPTION

Crée une nouvelle étiquette sur GitHub, ou met à jour une étiquette existante avec --force.

Le nom de l'étiquette doit être spécifié. La description et la couleur sont facultatives. Si aucune couleur n'est fournie, une couleur aléatoire sera choisie.

La couleur de l'étiquette doit être une valeur hexadécimale à 6 caractères.

OPTIONS

-c, --color <chaîne>
Couleur de l'étiquette
-d, --description <chaîne>
Description de l'étiquette
-f, --force
Met à jour la couleur et la description de l'étiquette si elle existe déjà

OPTIONS HERITEES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionne un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Crée une nouvelle étiquette de bug
$ gh label create bug --description "Quelque chose ne fonctionne pas" --color E99695
