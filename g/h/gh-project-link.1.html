NOM

gh-project-link - Lier un projet à un dépôt ou une équipe

SYNTAXE

gh project link [<nombre>] [options]

OPTIONS

--owner <chaîne>
Identifiant de connexion du propriétaire. Utiliser "@me" pour l'utilisateur actuel.
-R, --repo <chaîne>
Le dépôt à lier à ce projet.
-T, --team <chaîne>
L'équipe à lier à ce projet.

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Lier le projet 1 de monalisa à son dépôt "my_repo"
$ gh project link 1 --owner monalisa --repo my_repo
# Lier le projet 1 de l'organisation de monalisa à son équipe "my_team"
$ gh project link 1 --owner my_organization --team my_team
# Lier le projet 1 de monalisa au dépôt du répertoire courant si ni --repo ni --team n'est spécifié
$ gh project link 1
