NOM

gh-issue - Gérer les problèmes (issues)

SYNOPIS

gh issue <commande> [options]

DESCRIPTION

Travaillez avec les problèmes (issues) GitHub.

COMMANDES GÉNÉRALES

gh-issue-create(1)
Créer un nouveau problème
gh-issue-list(1)
Lister les problèmes d'un dépôt
gh-issue-status(1)
Afficher le statut des problèmes pertinents

COMMANDES CIBLÉES

gh-issue-close(1)
Fermer un problème
gh-issue-comment(1)
Ajouter un commentaire à un problème
gh-issue-delete(1)
Supprimer un problème
gh-issue-develop(1)
Gérer les branches liées pour un problème
gh-issue-edit(1)
Modifier des problèmes
gh-issue-lock(1)
Verrouiller la conversation d'un problème
gh-issue-pin(1)
Épingler un problème
gh-issue-reopen(1)
Rouvrir un problème
gh-issue-transfer(1)
Transférer un problème vers un autre dépôt
gh-issue-unlock(1)
Déverrouiller la conversation d'un problème
gh-issue-unpin(1)
Désépingler un problème
gh-issue-view(1)
Afficher un problème

OPTIONS

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consulter l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh issue list
$ gh issue create --label bug
$ gh issue view 123 --web
