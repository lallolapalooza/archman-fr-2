NOM

gh-run - Afficher les détails des exécutions de flux de travail

SYNOPIS

gh run <commande> [indicateurs]

DESCRIPTION

Lister, afficher et surveiller les exécutions récentes de flux de travail depuis GitHub Actions.

COMMANDES DISPONIBLES

gh-run-cancel(1)
Annuler une exécution de flux de travail
gh-run-delete(1)
Supprimer une exécution de flux de travail
gh-run-download(1)
Télécharger les artefacts générés par une exécution de flux de travail
gh-run-list(1)
Lister les exécutions récentes de flux de travail
gh-run-rerun(1)
Relancer une exécution
gh-run-view(1)
Afficher un résumé d'une exécution de flux de travail
gh-run-watch(1)
Surveiller une exécution jusqu'à son achèvement, en montrant sa progression

OPTIONS

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consulter l'aide de la commande pour plus d'informations.
