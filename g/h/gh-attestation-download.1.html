NOM

gh-attestation-download - Télécharger les attestations d'un artefact pour une utilisation hors ligne

SYNTAXE

gh attestation download [<chemin-fichier> | oci://<uri-image>] [--owner | --repo] [options]

DESCRIPTION

NOTE: Cette fonctionnalité est actuellement en aperçu public, et susceptible de modification.

Télécharge les attestations associées à un artefact pour une utilisation hors ligne.

La commande nécessite soit : * un chemin de fichier vers un artefact, soit * un URI d'image conteneur (par ex. oci://<uri-image>)
* (notez que si vous fournissez une URL OCI, vous devez déjà être authentifié auprès de son registre de conteneurs)

En outre, la commande nécessite soit : * l'option --repo (par ex. --repo github/example). * l'option --owner (par ex. --owner github), soit

La valeur de l'option --repo doit correspondre au nom du dépôt GitHub avec lequel l'artefact est lié.

La valeur de l'option --owner doit correspondre au nom de l'organisation GitHub à laquelle appartient le dépôt lié de l'artefact.

Les éventuels bundles associés seront écrits dans un fichier du répertoire courant portant le nom du digest de l'artefact. Par exemple, si le digest est "sha256:1234", le fichier sera nommé "sha256:1234.jsonl".

Les deux-points sont des caractères spéciaux sous Windows et ne peuvent pas être utilisés dans les noms de fichiers. Pour compenser, un trait d'union sera utilisé pour séparer l'algorithme du digest dans le nom du fichier d'attestations. Par exemple, si le digest est "sha256:1234", le fichier sera nommé "sha256-1234.jsonl".

OPTIONS

-d, --digest-alg <chaîne> (défaut "sha256")
L'algorithme utilisé pour calculer un digest de l'artefact : {sha256|sha512}
--hostname <chaîne>
Configurer l'hôte à utiliser
-L, --limit <entier> (défaut 30)
Nombre maximum d'attestations à récupérer
-o, --owner <chaîne>
Organisation GitHub pour limiter la recherche d'attestations par
--predicate-type <chaîne>
Filtrer les attestations par type de prédicat fourni
-R, --repo <chaîne>
Nom du dépôt au format /

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Télécharger les attestations pour un artefact local lié à une organisation
$ gh attestation download example.bin -o github
# Télécharger les attestations pour un artefact local lié à un dépôt
$ gh attestation download example.bin -R github/example
# Télécharger les attestations pour une image OCI liée à une organisation
$ gh attestation download oci://example.com/foo/bar:latest -o github
