NOM

gh-repo-rename - Renommer un dépôt

SYNTAXE

gh repo rename [<nouveau-nom>] [flags]

DESCRIPTION

Renomme un dépôt GitHub.

<nouveau-nom> est le nom de dépôt souhaité sans le propriétaire.

Par défaut, le dépôt actuel est renommé. Sinon, le dépôt spécifié avec --repo est renommé.

Pour transférer la propriété d'un dépôt à un autre compte d'utilisateur ou organisation, vous devez suivre des étapes supplémentaires sur github.com.

Pour plus d'informations sur le transfert de propriété de dépôt, voir :

⟨https://docs.github.com/fr/repositories/creating-and-managing-repositories/transferring-a-repository⟩

OPTIONS

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT
-y, --yes
Ignorer la demande de confirmation

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

REMARQUE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Renommer le dépôt actuel (foo/bar -> foo/baz)
$ gh repo rename baz
# Renommer le dépôt spécifié (qux/quux -> qux/baz)
$ gh repo rename -R qux/quux baz
