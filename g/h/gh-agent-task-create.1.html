GH-AGENT-TASK-CREATE(1) Manuel de l'interface de ligne de commande GitHub GH-AGENT-TASK-CREATE(1)

NOM

gh-agent-task-create - Créer une tâche d'agent (aperçu)

SYNTAXE

gh agent-task create [<description de la tâche>] [options]

OPTIONS

-b, --base <chaîne>
Branche de base pour la demande d'extraction (utiliser la branche par défaut si non fournie)
-a, --custom-agent <chaîne>
Utiliser un agent personnalisé pour la tâche. Par exemple, utiliser 'mon-agent' pour l'agent 'mon-agent.md'
--follow
Suivre les journaux de session de l'agent
-F, --from-file <fichier>
Lire la description de la tâche depuis un fichier (utiliser "-" pour lire depuis l'entrée standard)
-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Créer une tâche à partir d'une description en ligne
$ gh agent-task create "construis-moi une nouvelle application"
# Créer une tâche à partir d'une description en ligne et suivre les journaux
$ gh agent-task create "construis-moi une nouvelle application" --follow
# Créer une tâche à partir d'un fichier
$ gh agent-task create -F task-desc.md
# Créer une tâche avec un énoncé de problème depuis stdin
$ echo "construis-moi une nouvelle application" | gh agent-task create -F -
# Créer une tâche avec un éditeur
$ gh agent-task create
# Créer une tâche avec un éditeur et un fichier comme modèle
$ gh agent-task create -F task-desc.md
# Sélectionner une autre branche de base pour la PR
$ gh agent-task create "corriger les erreurs" --base branch
# Créer une tâche en utilisant l'agent personnalisé défini dans '.github/agents/my-agent.md'
$ gh agent-task create "construis-moi une nouvelle application" --custom-agent my-agent
