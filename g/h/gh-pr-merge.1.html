NOM

gh-pr-merge - Fusionner une demande d'extraction (pull request)

SYNTAXE

gh pr merge [<numéro> | <url> | <branche>] [options]

DESCRIPTION

Fusionne une demande d'extraction sur GitHub.

Sans argument, la demande d'extraction appartenant à la branche courante est sélectionnée.

Lorsqu'on cible une branche qui nécessite une file d'attente de fusion, aucune stratégie de fusion n'est requise. Si les vérifications nécessaires ne sont pas encore passées, la fusion automatique sera activée. Si les vérifications nécessaires sont passées, la demande d'extraction sera ajoutée à la file d'attente de fusion. Pour contourner une file d'attente de fusion et fusionner directement, utilisez l'option --admin.

OPTIONS

--admin
Utilise les privilèges d'administrateur pour fusionner une demande d'extraction qui ne satisfait pas aux exigences
-A, --author-email <texte>
Texte d'e-mail pour l'auteur du commit de fusion
--auto
Fusionner automatiquement seulement une fois les exigences nécessaires satisfaites
-b, --body <texte>
Texte du corps pour le commit de fusion
-F, --body-file <fichier>
Lire le texte du corps depuis un fichier (utiliser "-" pour lire depuis l'entrée standard)
-d, --delete-branch
Supprimer la branche locale et distante après la fusion
--disable-auto
Désactiver la fusion automatique pour cette demande d'extraction
--match-head-commit <SHA>
SHA du commit que la tête de la demande d'extraction doit correspondre pour autoriser la fusion
-m, --merge
Fusionner les commits avec la branche de base
-r, --rebase
Réappliquer les commits sur la branche de base
-s, --squash
Empaqueter les commits en un seul commit et le fusionner dans la branche de base
-t, --subject <texte>
Texte du sujet pour le commit de fusion

OPTIONS INHERITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
