NOM

gh-project-item-add - Ajouter une pull request ou une issue à un projet

SYNOPIS

gh project item-add [<numéro>] [options]

OPTIONS

--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--owner <chaîne>
Nom de connexion du propriétaire. Utiliser "@me" pour l'utilisateur actuel.
-t, --template <chaîne>
Formater la sortie JSON en utilisant un modèle Go ; voir "gh help formatting"
--url <chaîne>
URL de l'issue ou de la pull request à ajouter au projet

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Ajouter un élément au projet "1" de monalisa
$ gh project item-add 1 --owner monalisa --url https://github.com/monalisa/myproject/issues/23
