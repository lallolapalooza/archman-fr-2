GH-PROJECT-DELETE(1) Manuel de l'interface en ligne de commande GitHub GH-PROJECT-DELETE(1)

NOM

gh-project-delete - Supprimer un projet

SYNTAXE

gh project delete [<numéro>] [indicateurs]

OPTIONS

--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--owner <chaîne>
Identifiant du propriétaire. Utilisez « @moi » pour l'utilisateur actuel.
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Supprimer le projet « 1 » de l'utilisateur actuel
$ gh project delete 1 --owner "@me"
