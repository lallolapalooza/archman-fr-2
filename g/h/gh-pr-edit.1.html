NOM

gh-pr-edit - Modifier une demande d'extraction (pull request)

SYNTAXE

gh pr edit [<numéro> | <url> | <branche>] [indicateurs]

DESCRIPTION

Modifie une demande d'extraction.

Sans argument, la demande d'extraction appartenant à la branche actuelle est sélectionnée.

La modification des projets d'une demande d'extraction nécessite une autorisation avec la portée project. Pour autoriser, exécutez gh auth refresh -s project.

Les indicateurs --add-assignee et --remove-assignee prennent tous deux en charge les valeurs spéciales suivantes : - @me : attribuer ou désattribuer vous-même - @copilot : attribuer ou désattribuer Copilot (non pris en charge sur GitHub Enterprise Server)

Les indicateurs --add-reviewer et --remove-reviewer ne prennent pas en charge ces valeurs spéciales.

OPTIONS

--add-assignee <login>
Ajouter des utilisateurs assignés par leur identifiant de connexion. Utilisez « @me » pour vous assigner, ou « @copilot » pour assigner Copilot.
--add-label <nom>
Ajouter des étiquettes par leur nom.
--add-project <titre>
Ajouter la demande d'extraction à des projets par leur titre.
--add-reviewer <login>
Ajouter des réviseurs par leur identifiant de connexion.
-B, --base <branche>
Modifier la branche de base pour cette demande d'extraction.
-b, --body <chaîne>
Définir le nouveau corps.
-F, --body-file <fichier>
Lire le texte du corps depuis un fichier (utilisez « - » pour lire depuis l'entrée standard).
-m, --milestone <nom>
Modifier le jalon auquel la demande d'extraction appartient par son nom.
--remove-assignee <login>
Supprimer des utilisateurs assignés par leur identifiant de connexion. Utilisez « @me » pour vous désassigner, ou « @copilot » pour désassigner Copilot.
--remove-label <nom>
Supprimer des étiquettes par leur nom.
--remove-milestone
Supprimer l'association du jalon de la demande d'extraction.
--remove-project <titre>
Retirer la demande d'extraction des projets par leur titre.
--remove-reviewer <login>
Supprimer des réviseurs par leur identifiant de connexion.
-t, --title <chaîne>
Définir le nouveau titre.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/REPO.

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh pr edit 23 --title "J'ai trouvé un bug" --body "Rien ne fonctionne"
$ gh pr edit 23 --add-label "bug,aide-demandée" --remove-label "core"
$ gh pr edit 23 --add-reviewer monalisa,hubot  --remove-reviewer monorganisation/equipe-nom
$ gh pr edit 23 --add-assignee "@me" --remove-assignee monalisa,hubot
$ gh pr edit 23 --add-assignee "@copilot"
$ gh pr edit 23 --add-project "Feuille de route" --remove-project v1,v2
$ gh pr edit 23 --milestone "Version 1"
$ gh pr edit 23 --remove-milestone
