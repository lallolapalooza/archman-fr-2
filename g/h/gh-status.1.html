NOM

gh-status - Affiche des informations sur les problèmes, les requêtes de tirage et les notifications pertinents sur les dépôts

SYNTAXE

gh status [options]

DESCRIPTION

La commande status affiche des informations sur votre travail sur GitHub dans tous les dépôts auxquels vous êtes abonné, notamment :

  • Problèmes assignés
  • Requêtes de tirage assignées
  • Demandes de révision
  • Mentions
  • Activité du dépôt (nouveaux problèmes/requêtes de tirage, commentaires)

OPTIONS

-e, --exclude <chaînes>
Liste de dépôts séparés par des virgules au format propriétaire/nom
-o, --org <chaîne>
Rapporter le statut au sein d'une organisation

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh status -e cli/cli -e cli/go-gh # Exclure plusieurs dépôts
$ gh status -o cli # Limiter les résultats à une seule organisation
