NOM

gh-gist-clone - Cloner un gist localement

SYNTAXE

gh gist clone <gist> [<répertoire>] [-- <flags-git>...]

DESCRIPTION

Cloner un gist GitHub localement.

Un gist peut être fourni en argument sous l'un des formats suivants : - par ID, par exemple 5b0e0062eb8e9654adad7bb1d81cc75f - par URL, par exemple https://gist.github.com/OWNER/5b0e0062eb8e9654adad7bb1d81cc75f

Passez des drapeaux supplémentaires de git clone en les listant après --.

CODES DE FIN

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de fin supplémentaires. Consultez l'aide de la commande pour plus d'informations.
