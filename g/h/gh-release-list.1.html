NOM

gh-release-list - Lister les versions dans un dépôt

SYNTAXE

gh release list [flags]

OPTIONS

--exclude-drafts
Exclure les versions brouillons
--exclude-pre-releases
Exclure les pré-versions
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--json <champs>
Sortie JSON avec les champs spécifiés
-L, --limit <int> (par défaut 30)
Nombre maximum d'éléments à récupérer
-O, --order <string> (par défaut "desc")
Ordre des versions retournées : {asc|desc}
-t, --template <string>
Mettre en forme la sortie JSON en utilisant un modèle Go ; voir "gh help formatting"

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOST/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOST/]PROPRIETAIRE/REPO

ALIAS

gh release ls

CHAMPS JSON

createdAt, isDraft, isImmutable, isLatest, isPrerelease, name, publishedAt, tagName

CODES DE SORTIE

0: Exécution réussie

1: Erreur

2: Commande annulée

4: Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.
