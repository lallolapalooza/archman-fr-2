NOM

gh-ruleset-view - Afficher des informations sur un ensemble de règles

SYNTAXE

gh ruleset view [<id-ensemble-de-regles>] [indicateurs]

DESCRIPTION

Affiche des informations sur un ensemble de règles GitHub.

Si aucun ID n'est fourni, une invite interactive sera utilisée pour choisir l'ensemble de règles à afficher.

Utilisez l'indicateur --parents pour contrôler si les ensembles de règles configurés à des niveaux supérieurs qui s'appliquent également au dépôt ou à l'organisation fournis doivent être renvoyés. La valeur par défaut est true.

OPTIONS

-o, --org <chaine>
Nom de l'organisation si l'ID fourni est un ensemble de règles au niveau de l'organisation
-p, --parents (défaut true)
Indique s'il faut inclure les ensembles de règles configurés à des niveaux supérieurs qui s'appliquent également
-w, --web
Ouvre l'ensemble de règles dans le navigateur

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/DEPOT>
Sélectionne un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/DEPOT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

REMARQUE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Choisir interactivement un ensemble de règles à afficher parmi tous les ensembles de règles qui s'appliquent au dépôt actuel
$ gh ruleset view
# Choisir interactivement un ensemble de règles à afficher parmi uniquement les ensembles de règles configurés dans le dépôt actuel
$ gh ruleset view --no-parents
# Afficher un ensemble de règles configuré dans le dépôt actuel ou l'un de ses parents
$ gh ruleset view 43
# Afficher un ensemble de règles configuré dans un autre dépôt ou l'un de ses parents
$ gh ruleset view 23 --repo owner/repo
# Afficher un ensemble de règles au niveau de l'organisation
$ gh ruleset view 23 --org my-org
