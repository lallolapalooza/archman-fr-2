NOM

gh-codespace - Se connecter aux codespaces et les gérer

SYNTAXE

gh codespace [options]

COMMANDES DISPONIBLES

gh-codespace-code(1)
Ouvrir un codespace dans Visual Studio Code
gh-codespace-cp(1)
Copier des fichiers entre les systèmes de fichiers locaux et distants
gh-codespace-create(1)
Créer un codespace
gh-codespace-delete(1)
Supprimer des codespaces
gh-codespace-edit(1)
Modifier un codespace
gh-codespace-jupyter(1)
Ouvrir un codespace dans JupyterLab
gh-codespace-list(1)
Lister les codespaces
gh-codespace-logs(1)
Accéder aux journaux des codespaces
gh-codespace-ports(1)
Lister les ports d'un codespace
gh-codespace-rebuild(1)
Reconstruire un codespace
gh-codespace-ssh(1)
Se connecter en SSH à un codespace
gh-codespace-stop(1)
Arrêter un codespace en cours d'exécution
gh-codespace-view(1)
Afficher les détails d'un codespace

ALIAS

gh cs

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.
