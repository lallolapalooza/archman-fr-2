NOM

gh-issue-list - Lister les problèmes d'un dépôt

SYNTAXE

gh issue list [options]

DESCRIPTION

Lister les problèmes d'un dépôt GitHub. Par défaut, seules les problèmes ouverts sont listés.

La syntaxe de requête de recherche est documentée ici :

⟨https://docs.github.com/fr/search-github/searching-on-github/searching-issues-and-pull-requests⟩

Sur les hôtes GitHub compatibles, une syntaxe de recherche avancée de problèmes peut être utilisée dans la requête --search. Pour plus d'informations sur la recherche avancée de problèmes, voir :

⟨https://docs.github.com/fr/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues⟩

OPTIONS

--app <chaîne>
Filtrer par auteur d'application GitHub
-a, --assignee <chaîne>
Filtrer par responsable
-A, --author <chaîne>
Filtrer par auteur
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Afficher JSON avec les champs spécifiés
-l, --label <chaînes>
Filtrer par étiquette
-L, --limit <entier> (défaut 30)
Nombre maximum de problèmes à récupérer
--mention <chaîne>
Filtrer par mention
-m, --milestone <chaîne>
Filtrer par numéro ou titre d'étape importante
-S, --search <requête>
Rechercher des problèmes avec la requête
-s, --state <chaîne> (défaut « open »)
Filtrer par état : {open|closed|all}
-t, --template <chaîne>
Mettre en forme la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »
-w, --web
Lister les problèmes dans le navigateur Web

OPTIONS HERITEES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

ALIAS

gh issue ls

CHAMPS JSON

assignees, author, body, closed, closedAt, closedByPullRequestsReferences, comments, createdAt, id, isPinned, labels, milestone, number, projectCards, projectItems, reactionGroups, state, stateReason, title, updatedAt, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh issue list --label "bug" --label "help wanted"
$ gh issue list --author monalisa
$ gh issue list --assignee "@me"
$ gh issue list --milestone "La grande 1.0"
$ gh issue list --search "erreur no:assignee sort:created-asc"
$ gh issue list --state all
