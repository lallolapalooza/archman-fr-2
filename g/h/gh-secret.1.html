NOM

gh-secret - Gérer les secrets GitHub

SYNTAXE

gh secret <commande> [indicateurs]

DESCRIPTION

Les secrets peuvent être définis au niveau du dépôt ou de l'organisation pour être utilisés dans les Actions GitHub ou Dependabot. Les secrets d'utilisateur, d'organisation et de dépôt peuvent être définis pour être utilisés dans les Codespaces GitHub. Les secrets d'environnement peuvent être définis pour être utilisés dans les Actions GitHub. Exécutez gh help secret set pour apprendre comment commencer.

COMMANDES DISPONIBLES

gh-secret-delete(1)
Supprimer des secrets
gh-secret-list(1)
Lister les secrets
gh-secret-set(1)
Créer ou mettre à jour des secrets

OPTIONS

-R, --repo <[HOST/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HOST/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
