NOM

gh-repo-create - Créer un nouveau dépôt

SYNTAXE

gh repo create [<nom>] [options]

DESCRIPTION

Crée un nouveau dépôt GitHub.

Pour créer un dépôt interactivement, utilisez gh repo create sans arguments.

Pour créer un dépôt distant de manière non interactive, fournissez le nom du dépôt et l'une des options --public, --private, ou --internal. Utilisez --clone pour cloner le nouveau dépôt localement.

Si la partie PROPRIÉTAIRE/ de l'argument PROPRIÉTAIRE/DÉPÔT est omise, elle sera par défaut le nom de l'utilisateur authentifié.

Pour créer un dépôt distant à partir d'un dépôt local existant, spécifiez le répertoire source avec --source. Par défaut, le nom du dépôt distant sera le nom du répertoire source.

Utilisez --push pour pousser les commits locaux vers le nouveau dépôt. Si le dépôt est nu (bare), cela mettra à jour toutes les références.

Pour les modèles .gitignore de langue ou de plateforme à utiliser avec --gitignore, consultez ⟨https://github.com/github/gitignore⟩.

Pour les mots-clés de licence à utiliser avec --license, exécutez gh repo license list ou visitez ⟨https://choosealicense.com⟩.

Le dépôt est créé avec la branche par défaut du dépôt configurée, voir ⟨https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-personal-account-on-github/managing-user-account-settings/managing-the-default-branch-name-for-your-repositories⟩.

OPTIONS

--add-readme
Ajouter un fichier README au nouveau dépôt
-c, --clone
Cloner le nouveau dépôt dans le répertoire courant
-d, --description <chaîne>
Description du dépôt
--disable-issues
Désactiver les problèmes dans le nouveau dépôt
--disable-wiki
Désactiver le wiki dans le nouveau dépôt
-g, --gitignore <chaîne>
Spécifier un modèle gitignore pour le dépôt
-h, --homepage <URL>
URL de la page d'accueil du dépôt
--include-all-branches
Inclure toutes les branches du dépôt modèle
--internal
Rendre le nouveau dépôt interne
-l, --license <chaîne>
Spécifier une licence Open Source pour le dépôt
--private
Rendre le nouveau dépôt privé
--public
Rendre le nouveau dépôt public
--push
Pousser les commits locaux vers le nouveau dépôt
-r, --remote <chaîne>
Spécifier le nom de la télécommande pour le nouveau dépôt
-s, --source <chaîne>
Spécifier le chemin vers le dépôt local à utiliser comme source
-t, --team <nom>
Le nom de l'équipe de l'organisation à laquelle accorder l'accès
-p, --template <dépôt>
Faire du nouveau dépôt une base à partir d'un dépôt modèle

ALIASES

gh repo new

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

# Créer un dépôt interactivement
$ gh repo create
# Créer un nouveau dépôt distant et le cloner localement
$ gh repo create mon-projet --public --clone
# Créer un nouveau dépôt distant dans une autre organisation
$ gh repo create mon-org/mon-projet --public
# Créer un dépôt distant à partir du répertoire courant
$ gh repo create mon-projet --private --source=. --remote=upstream
