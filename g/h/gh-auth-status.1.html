NOM

gh-auth-status - Afficher le compte actif et l'état d'authentification sur chaque hôte GitHub connu

SYNTAXE

gh auth status [indicateurs]

DESCRIPTION

Affiche le compte actif et l'état d'authentification sur chaque hôte GitHub connu.

Pour chaque hôte, l'état d'authentification de chaque compte connu est vérifié et les éventuels problèmes sont inclus dans la sortie. Chaque section d'hôte indiquera le compte actif, qui sera utilisé lors du ciblage de cet hôte.

Si un compte sur un hôte (ou celui fourni via --hostname) présente des problèmes d'authentification, la commande se terminera avec le code de sortie 1 et affichera un message sur la sortie d'erreur standard. Notez que lors de l'utilisation de l'option --json, la commande se terminera toujours avec le code de sortie zéro, quelle que soit la présence de problèmes d'authentification, sauf en cas d'erreur fatale.

Pour changer le compte actif d'un hôte, consultez gh auth switch.

OPTIONS

-a, --active
Afficher uniquement le compte actif
-h, --hostname <chaîne>
Vérifier uniquement l'état d'authentification d'un hôte spécifique
--jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Sortie JSON avec les champs spécifiés
-t, --show-token
Afficher le jeton d'authentification
--template <chaîne>
Mettre en forme la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »

CHAMPS JSON

hôtes

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Afficher l'état d'authentification pour tous les comptes sur tous les hôtes
$ gh auth status
# Afficher l'état d'authentification pour le compte actif sur un hôte spécifique
$ gh auth status --active --hostname github.example.com
# Afficher les jetons en texte brut
$ gh auth status --show-token
# Mettre en forme l'état d'authentification en JSON
$ gh auth status --json hosts
# Inclure le jeton en texte brut dans la sortie JSON
$ gh auth status --json hosts --show-token
# Mettre en forme les hôtes comme un tableau JSON plat
$ gh auth status --json hosts --jq '.hosts | add'
