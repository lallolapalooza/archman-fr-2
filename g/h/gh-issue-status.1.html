GH-ISSUE-STATUS(1) Manuel de l'outil en ligne de commande GitHub GH-ISSUE-STATUS(1)

NOM

gh-issue status - Afficher le statut des problèmes pertinents

SYNTAXE

gh issue status [indicateurs]

OPTIONS

-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Sortie JSON avec les champs spécifiés
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »

OPTIONS HERITÉES DES COMMANDES PARENTES

-R, --repo <[HOST/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOST/]PROPRIÉTAIRE/REPO

CHAMPS JSON

assignees, author, body, closed, closedAt, closedByPullRequestsReferences, comments, createdAt, id, isPinned, labels, milestone, number, projectCards, projectItems, reactionGroups, state, stateReason, title, updatedAt, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.
