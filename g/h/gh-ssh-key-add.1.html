NOM

gh-ssh-key-add - Ajouter une clé SSH à votre compte GitHub

SYNTAXE

gh ssh-key add [<fichier-clé>] [indicateurs]

OPTIONS

-t, --title <chaîne>
Titre pour la nouvelle clé
--type <chaîne> (par défaut "authentication")
Type de la clé SSH : {authentication|signing}

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.
