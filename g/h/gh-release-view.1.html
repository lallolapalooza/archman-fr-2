NOM

gh-release-view - Afficher les informations sur une release

SYNOPHIS

gh release view [<tag>] [flags]

DESCRIPTION

Affiche les informations sur une release GitHub.

Sans argument de nom de tag explicite, la dernière release du projet est affichée.

OPTIONS

-q, --jq <expression>
Filtre la sortie JSON en utilisant une expression jq
--json <champs>
Produit une sortie JSON avec les champs spécifiés
-t, --template <chaîne>
Formate la sortie JSON en utilisant un modèle Go ; voir « gh help formatting »
-w, --web
Ouvre la release dans le navigateur

OPTIONS HERITées DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/DEPOT>
Sélectionne un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/DEPOT

CHAMPS JSON

apiUrl, assets, author, body, createdAt, databaseId, id, isDraft, isImmutable, isPrerelease, name, publishedAt, tagName, tarballUrl, targetCommitish, uploadUrl, url, zipballUrl

CODES SORTIE

0: Exécution réussie

1: Erreur

2: Commande annulée

4: Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
