NOM

gh-label-list - Lister les étiquettes dans un dépôt

SYNTAXE

gh label list [indicateurs]

DESCRIPTION

Affiche les étiquettes dans un dépôt GitHub.

Lors de l'utilisation de l'indicateur --search, les résultats sont triés par meilleure correspondance avec la requête. Ce comportement ne peut pas être configuré avec les indicateurs --order ou --sort.

OPTIONS

-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--json <champs>
Sortir au format JSON avec les champs spécifiés
-L, --limit <entier> (défaut 30)
Nombre maximum d'étiquettes à récupérer
--order <chaîne> (défaut "asc")
Ordre des étiquettes retournées : {asc|desc}
-S, --search <chaîne>
Rechercher les noms et descriptions d'étiquettes
--sort <chaîne> (défaut "created")
Trier les étiquettes récupérées : {created|name}
-t, --template <chaîne>
Formater la sortie JSON en utilisant un template Go ; voir "gh help formatting"
-w, --web
Lister les étiquettes dans le navigateur web

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/DEPOT>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/DEPOT

ALIAS

gh label ls

CHAMPS JSON

color, createdAt, description, id, isDefault, name, updatedAt, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Trier les étiquettes par nom
$ gh label list --sort name
# Trouver les étiquettes contenant "bug" dans le nom ou la description
$ gh label list --search bug
