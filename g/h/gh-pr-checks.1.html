NOM

gh-pr-checks - Afficher le statut CI pour une seule pull request

SYNTAXE

gh pr checks [<numéro> | <url> | <branche>] [indicateurs]

DESCRIPTION

Affiche le statut CI pour une seule pull request.

Sans argument, la pull request appartenant à la branche actuelle est sélectionnée.

Lorsque l'indicateur --json est utilisé, il inclut un champ bucket, qui catégorise le champ state en pass, fail, pending, skipping, ou cancel.

Codes de sortie supplémentaires : 8 : Vérifications en attente

OPTIONS

--fail-fast
Quitter le mode de surveillance à la première défaillance de vérification
-i, --interval <entier> (par défaut 10)
Intervalle de rafraîchissement en secondes en mode de surveillance
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Sortie JSON avec les champs spécifiés
--required
Afficher uniquement les vérifications qui sont requises
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »
--watch
Surveiller les vérifications jusqu'à ce qu'elles se terminent
-w, --web
Ouvrir le navigateur Web pour afficher les détails sur les vérifications

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/REPO

CHAMPS JSON

bucket, completedAt, description, event, link, name, startedAt, state, workflow

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
