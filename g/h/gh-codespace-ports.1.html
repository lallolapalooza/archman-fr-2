NOM

gh-codespace-ports - Lister les ports d'un codespace

SYNTAXE

gh codespace ports [options]

COMMANDES DISPONIBLES

gh-codespace-ports-forward(1)
Transférer les ports
gh-codespace-ports-visibility(1)
Changer la visibilité du port transféré

OPTIONS

-c, --codespace <chaîne>
Nom du codespace
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Afficher la sortie JSON avec les champs spécifiés
-R, --repo <chaîne>
Filtrer la sélection du codespace par le nom du dépôt (utilisateur/dépôt)
--repo-owner <chaîne>
Filtrer la sélection du codespace par le propriétaire du dépôt (nom d'utilisateur ou organisation)
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go; voir "gh help formatting"

CHAMPS JSON

browseUrl, label, sourcePort, visibility

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.
