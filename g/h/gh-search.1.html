NOM

gh-search - Rechercher des dépôts, des problèmes et des demandes d'extraction

SYNTAXE

gh search <commande> [indicateurs]

DESCRIPTION

Rechercher sur tout GitHub.

Exclure les résultats de recherche qui correspondent à un qualificateur

Dans un navigateur, la syntaxe de recherche GitHub permet d'exclure les résultats qui correspondent à un qualificateur de recherche en ajoutant un trait d'union devant le qualificateur. Par exemple, pour rechercher des problèmes qui n'ont pas l'étiquette « bug », vous utiliseriez -label:bug comme qualificateur de recherche.

gh prend également en charge cette syntaxe dans gh search, mais cela nécessite des arguments de ligne de commande supplémentaires pour éviter que le trait d'union ne soit interprété comme un indicateur de ligne de commande car il commence par un trait d'union.

Sur les systèmes de type Unix, vous pouvez utiliser l'argument -- pour indiquer que les arguments qui suivent ne sont pas un indicateur, mais une chaîne de requête. Par exemple :

$ gh search issues -- "my-search-query -label:bug"

Sur PowerShell, vous devez utiliser à la fois l'argument --% et l'argument -- pour obtenir le même effet. Par exemple :

$ gh --% search issues -- "my search query -label:bug"

Voir ce qui suit pour plus d'informations : - Syntaxe de recherche GitHub : ⟨https://docs.github.com/en/search-github/getting-started-with-searching-on-github/understanding-the-search-syntax#exclude-results-that-match-a-qualifier⟩ - L'indicateur d'arrêt d'analyse PowerShell --% : ⟨https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_parsing?view=powershell-7.5#the-stop-parsing-token⟩ - L'argument Unix-like -- : ⟨https://www.gnu.org/software/bash/manual/bash.html#Shell-Builtin-Commands-1⟩
