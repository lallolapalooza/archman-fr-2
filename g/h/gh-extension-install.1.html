NOM

gh-extension-install - Installer une extension gh depuis un dépôt

SYNTAXE

gh extension install <dépôt> [flags]

DESCRIPTION

Installe une extension GitHub CLI depuis un dépôt GitHub ou local.

Pour les dépôts GitHub, l'argument dépôt peut être spécifié au format PROPRIÉTAIRE/DÉPÔT ou sous forme d'URL de dépôt complète. Le format d'URL est utile lorsque le dépôt n'est pas hébergé sur github.com.

Pour les dépôts distants, GitHub CLI recherche d'abord les artefacts de version en supposant qu'il s'agit d'une extension binaire, c'est-à-dire des binaires précompilés fournis dans le cadre de la version. En l'absence de version, le dépôt lui-même est cloné en supposant qu'il s'agit d'une extension script, c'est-à-dire un exécutable ou un script précompilé existe à sa racine.

L'indicateur --pin peut être utilisé pour spécifier une balise ou un commit pour les extensions binaires et script respectivement, la dernière version étant utilisée sinon.

Pour les dépôts locaux, souvent utilisés lors du développement d'extensions, utilisez . comme valeur de l'argument dépôt. Notez ce qui suit :

  • Après avoir installé une extension à partir d'un dépôt cloné localement, GitHub CLI gérera cette extension comme un lien symbolique (ou un mécanisme équivalent sous Windows) pointant vers un fichier exécutable portant le même nom que le dépôt dans la racine du dépôt. Par exemple, si le dépôt s'appelle gh-foobar, le lien symbolique pointera vers gh-foobar dans la racine du dépôt d'extension.
  • Lors de l'exécution de l'extension, GitHub CLI exécutera le fichier exécutable trouvé en suivant le lien symbolique. Si aucun fichier exécutable n'est trouvé, l'extension ne pourra pas s'exécuter.
  • Si l'extension est précompilée, le fichier exécutable doit être construit manuellement et placé à la racine du dépôt.

Pour la liste des extensions disponibles, voir ⟨https://github.com/topics/gh-extension⟩.

OPTIONS

--force
Forcer la mise à niveau de l'extension, ou ignorer si la dernière est déjà installée.
--pin <chaîne>
Épingler l'extension à une balise de version ou à un commit

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Installer une extension depuis un dépôt distant hébergé sur GitHub
$ gh extension install proprietaire/gh-extension
# Installer une extension depuis un dépôt distant via une URL complète
$ gh extension install https://my.ghes.com/proprietaire/gh-extension
# Installer une extension depuis un dépôt local dans le répertoire de travail courant
$ gh extension install .
