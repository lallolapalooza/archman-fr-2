NOM

gh-repo-edit - Modifier les paramètres du dépôt

SYNTAXE

gh repo edit [<dépôt>] [options]

DESCRIPTION

Modifier les paramètres du dépôt.

Pour désactiver un paramètre, utilisez la syntaxe --<option>=false.

Changer la visibilité d'un dépôt peut avoir des conséquences inattendues, notamment mais sans s'y limiter :

  • Perte d'étoiles et d'observateurs, affectant le classement du dépôt
  • Détachement des forks publics du réseau
  • Désactivation des ensembles de règles de push
  • Autorisation d'accès à l'historique et aux journaux de GitHub Actions

Lorsque l'option --visibility est utilisée, l'option --accept-visibility-change-consequences est requise.

Pour plus d'informations sur toutes les conséquences potentielles, voir ⟨https://gh.io/setting-repository-visibility⟩.

OPTIONS

--accept-visibility-change-consequences
Accepter les conséquences du changement de visibilité du dépôt
--add-topic <chaînes>
Ajouter un sujet de dépôt
--allow-forking
Autoriser le fork d'un dépôt d'organisation
--allow-update-branch
Autoriser la mise à jour d'une branche tête de pull request lorsqu'elle est en retard par rapport à sa branche de base
--default-branch <nom>
Définir le nom de la branche par défaut pour le dépôt
--delete-branch-on-merge
Supprimer la branche tête lors de la fusion des pull requests
-d, --description <chaîne>
Description du dépôt
--enable-advanced-security
Activer la sécurité avancée dans le dépôt
--enable-auto-merge
Activer la fonctionnalité de fusion automatique
--enable-discussions
Activer les discussions dans le dépôt
--enable-issues
Activer les problèmes dans le dépôt
--enable-merge-commit
Activer la fusion des pull requests par commit de fusion
--enable-projects
Activer les projets dans le dépôt
--enable-rebase-merge
Activer la fusion des pull requests par rebase
--enable-secret-scanning
Activer le scan des secrets dans le dépôt
--enable-secret-scanning-push-protection
Activer la protection de push de scan des secrets dans le dépôt. Le scan des secrets doit être activé au préalable
--enable-squash-merge
Activer la fusion des pull requests par squash de commit
--enable-wiki
Activer le wiki dans le dépôt
-h, --homepage <URL>
URL de la page d'accueil du dépôt
--remove-topic <chaînes>
Supprimer un sujet de dépôt
--template
Rendre le dépôt disponible en tant que dépôt modèle
--visibility <chaîne>
Changer la visibilité du dépôt en {public,private,internal}

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Activer les problèmes et le wiki
$ gh repo edit --enable-issues --enable-wiki
# Désactiver les projets
$ gh repo edit --enable-projects=false
