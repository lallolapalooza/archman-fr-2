NOM

gh-repo-clone - Cloner un dépôt localement

SYNTAXE

gh repo clone <dépôt> [<répertoire>] [-- <indicateurs-git>...]

DESCRIPTION

Clone un dépôt GitHub localement. Passez des indicateurs git clone supplémentaires en les listant après --.

Si la partie PROPRIÉTAIRE/ de l'argument de dépôt PROPRIÉTAIRE/DÉPÔT est omise, elle prend par défaut le nom de l'utilisateur authentifié.

Lorsqu'un schéma de protocole n'est pas fourni dans l'argument du dépôt, le protocole_git sera choisi à partir de votre configuration, ce qui peut être vérifié via gh config get git_protocol. Si le schéma de protocole est fourni, le dépôt sera cloné en utilisant le protocole spécifié.

Si le dépôt est une copie (fork), son dépôt parent sera ajouté comme un dépôt distant Git supplémentaire appelé upstream. Le nom du dépôt distant peut être configuré à l'aide de --upstream-remote-name. L'option --upstream-remote-name prend en charge une valeur @propriétaire qui nommera le dépôt distant d'après le propriétaire du dépôt parent.

Si le dépôt est une copie (fork), son dépôt parent sera défini comme le dépôt distant par défaut.

OPTIONS

-u, --upstream-remote-name <chaîne> (par défaut "upstream")
Nom du dépôt distant parent lors du clonage d'une copie (fork)

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Cloner un dépôt d'une organisation spécifique
$ gh repo clone cli/cli
# Cloner un dépôt de votre propre compte
$ gh repo clone monrepo
# Cloner un dépôt, en remplaçant la configuration du protocole git
$ gh repo clone https://github.com/cli/cli
$ gh repo clone git@github.com:cli/cli.git
# Cloner un dépôt dans un répertoire personnalisé
$ gh repo clone cli/cli workspace/cli
# Cloner un dépôt avec des indicateurs git clone supplémentaires
$ gh repo clone cli/cli -- --depth=1
