NOM

gh-secret-delete - Supprimer des secrets

SYNTAXE

gh secret delete <nom-du-secret> [indicateurs]

DESCRIPTION

Supprimer un secret à l'un des niveaux suivants : - dépôt (par défaut) : disponible pour les exécutions GitHub Actions ou Dependabot dans un dépôt - environnement : disponible pour les exécutions GitHub Actions pour un environnement de déploiement dans un dépôt - organisation : disponible pour les exécutions GitHub Actions, Dependabot ou Codespaces au sein d'une organisation - utilisateur : disponible pour Codespaces pour votre utilisateur

OPTIONS

-a, --app <chaîne>
Supprimer un secret pour une application spécifique : {actions|codespaces|dependabot}
-e, --env <chaîne>
Supprimer un secret pour un environnement
-o, --org <chaîne>
Supprimer un secret pour une organisation
-u, --user
Supprimer un secret pour votre utilisateur

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

ALIASES

gh secret remove

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.
