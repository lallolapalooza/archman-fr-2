NOM

gh-attestation-trusted-root - Affiche le contenu de trusted_root.jsonl, probablement pour une vérification hors ligne

SYNTAXE

gh attestation trusted-root [--tuf-url <url> --tuf-root <chemin-fichier>] [--verify-only] [indicateurs]

DESCRIPTION

Affiche le contenu d'un fichier trusted_root.jsonl, probablement pour une vérification hors ligne.

Lorsque vous utilisez gh attestation verify, si votre machine est connectée à Internet, cela se fait automatiquement. Mais pour effectuer une vérification hors ligne, vous devez fournir un fichier racine de confiance avec --custom-trusted-root ; cette commande vous aidera à récupérer un fichier trusted_root.jsonl à cette fin.

Vous pouvez appeler cette commande sans aucun indicateur pour obtenir un fichier racine de confiance couvrant l'instance Sigstore Public Good ainsi que l'instance Sigstore de GitHub.

Sinon, vous pouvez utiliser --tuf-url pour spécifier l'URL d'un miroir de dépôt TUF personnalisé, et --tuf-root doit être le chemin vers le fichier root.json que vous avez obtenu en toute sécurité hors bande.

Si vous souhaitez simplement vérifier l'intégrité de votre dépôt TUF local, et que vous ne voulez pas du contenu d'un fichier trusted_root.jsonl, utilisez --verify-only.

OPTIONS

--hostname <chaîne>
Configurer l'hôte à utiliser
--tuf-root <chaîne>
Chemin vers le fichier root.json de TUF sur le disque
--tuf-url <chaîne>
URL du miroir du dépôt TUF
--verify-only
Ne pas afficher le contenu de trusted_root.jsonl

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Obtenir un trusted_root.jsonl pour Sigstore Public Good et l'instance de GitHub
$ gh attestation trusted-root
