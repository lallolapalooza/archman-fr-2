NOM

gh-auth-logout - Se déconnecter d'un compte GitHub

SYNTAXE

gh auth logout [flags]

DESCRIPTION

Supprime l'authentification pour un compte GitHub.

Cette commande supprime la configuration d'authentification stockée pour un compte. La configuration d'authentification n'est supprimée qu'en local.

Cette commande ne révoque pas les jetons d'authentification.

Pour révoquer tous les jetons d'authentification générés par GitHub CLI :

1.
Visitez ⟨https://github.com/settings/applications⟩
2.
Sélectionnez l'application "GitHub CLI"
3.
Sélectionnez "Révoquer l'accès"
4.
Sélectionnez "Je comprends, révoquer l'accès"

Note : cette procédure révoquera tous les jetons d'authentification jamais générés par GitHub CLI sur tous vos appareils.

Pour plus d'informations sur la révocation des jetons d'applications OAuth, consultez :

⟨https://docs.github.com/en/apps/oauth-apps/using-oauth-apps/reviewing-your-authorized-oauth-apps⟩

OPTIONS

-h, --hostname <chaîne>
Le nom d'hôte de l'instance GitHub à déconnecter
-u, --user <chaîne>
Le compte à déconnecter

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Sélectionner quel hôte et compte déconnecter via une invite
$ gh auth logout
# Se déconnecter d'un hôte et d'un compte spécifiques
$ gh auth logout --hostname enterprise.internal --user monalisa
