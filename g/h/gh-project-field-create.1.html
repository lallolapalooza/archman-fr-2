NOM

gh-project-field-create - Créer un champ dans un projet

SYNOPIS

gh project field-create [<numéro>] [flags]

OPTIONS

--data-type <chaîne>
Type de données du nouveau champ : {TEXT|SINGLE_SELECT|DATE|NUMBER}
--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--name <chaîne>
Nom du nouveau champ
--owner <chaîne>
Login du propriétaire. Utilisez "@me" pour l'utilisateur actuel.
--single-select-options <chaînes>
Options pour le type de données SINGLE_SELECT
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Créer un champ dans le projet "1" de l'utilisateur actuel
$ gh project field-create 1 --owner "@me" --name "nouveau champ" --data-type "text"
# Créer un champ avec trois options parmi lesquelles choisir pour le propriétaire monalisa
$ gh project field-create 1 --owner monalisa --name "nouveau champ" --data-type "SINGLE_SELECT" --single-select-options "un,deux,trois"
