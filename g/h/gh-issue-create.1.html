NOM

gh-issue-create - Créer un nouveau problème

SYNTAXE

gh issue create [options]

DESCRIPTION

Crée un problème sur GitHub.

L'ajout d'un problème aux projets nécessite une autorisation avec le scope project. Pour autoriser, exécutez gh auth refresh -s project.

L'option --assignee prend en charge les valeurs spéciales suivantes : - @me : vous assigner - @copilot : assigner Copilot (non pris en charge sur GitHub Enterprise Server)

OPTIONS

-a, --assignee <login>
Assigner des personnes par leur nom d'utilisateur. Utilisez "@me" pour vous assigner.
-b, --body <chaine>
Fournir un corps de texte. Sinon, il sera demandé.
-F, --body-file <fichier>
Lire le corps du texte à partir d'un fichier (utilisez "-" pour lire depuis l'entrée standard)
-e, --editor
Ignorer les invites et ouvrir l'éditeur de texte pour écrire le titre et le corps. La première ligne est le titre et le texte restant est le corps.
-l, --label <nom>
Ajouter des étiquettes par nom.
-m, --milestone <nom>
Ajouter le problème à une étape clé par nom.
-p, --project <titre>
Ajouter le problème à des projets par titre.
--recover <chaine>
Récupérer l'entrée d'une exécution échouée de create.
-T, --template <nom>
Nom du modèle à utiliser comme texte du corps initial.
-t, --title <chaine>
Fournir un titre. Sinon, il sera demandé.
-w, --web
Ouvrir le navigateur pour créer un problème.

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOST/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOST/]PROPRIETAIRE/REPO.

ALIASES

gh issue new

CODES DE SORTIE

0: Exécution réussie

1: Erreur

2: Commande annulée

4: Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh issue create --title "J'ai trouvé un bug" --body "Rien ne fonctionne"
$ gh issue create --label "bug,demande d'aide"
$ gh issue create --label bug --label "demande d'aide"
$ gh issue create --assignee monalisa,hubot
$ gh issue create --assignee "@me"
$ gh issue create --assignee "@copilot"
$ gh issue create --project "Feuille de route"
$ gh issue create --template "Rapport de bug"
