NOM

gh-extension-browse - Entrer dans une interface pour parcourir, ajouter et supprimer des extensions

SYNTAXE

gh extension browse [options]

DESCRIPTION

Cette commande prendra le contrôle de votre terminal et exécutera une interface entièrement interactive pour parcourir, ajouter et supprimer des extensions gh. Une largeur de terminal supérieure à 100 colonnes est recommandée.

Pour apprendre à contrôler cette interface, appuyez sur ? après avoir exécuté la commande pour voir le texte d'aide.

Appuyez sur q pour quitter.

L'exécution de cette commande avec --single-column devrait rendre cette commande plus intelligible pour les utilisateurs qui dépendent de technologies d'assistance telles que les lecteurs d'écran ou le zoom élevé.

Pour une manière plus traditionnelle de découvrir des extensions, voir :

gh ext search

ainsi que gh ext install, gh ext remove, et gh repo view.

OPTIONS

--debug
Journaliser dans /tmp/extBrowse-*
-s, --single-column
Afficher l'interface utilisateur graphique (TUI) avec une seule colonne de texte

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.
