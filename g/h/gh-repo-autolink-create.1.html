NOM

gh-repo-autolink-create - Créer une nouvelle référence d'autolien

SYNTAXE

gh repo autolink create <prefixClé> <modèleURL> [indicateurs]

DESCRIPTION

Crée une nouvelle référence d'autolien pour un dépôt.

L'argument prefixClé spécifie le préfixe qui générera un lien lorsqu'il sera suivi de certains caractères.

L'argument modèleURL spécifie l'URL cible qui sera générée lorsque le prefixClé sera trouvé, et doit contenir la variable <num> pour le numéro de référence.

Par défaut, les autoliens sont alphanumériques avec l'indicateur --numeric utilisé pour créer un autolien numérique.

Le comportement de la variable <num> diffère selon que l'autolien est alphanumérique ou numérique :

  • alphanumérique : correspond à A-Z (insensible à la casse), 0-9 et -
  • numérique : correspond à 0-9

Si le modèle contient plusieurs instances de <num>, seule la première sera remplacée.

OPTIONS

-n, --numeric
Marquer l'autolien comme numérique

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

ALIAS

gh repo autolink new

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Créer un autolien alphanumérique vers example.com pour le préfixe de clé « TICKET- ».
# Génère https://example.com/TICKET?query=123abc à partir de « TICKET-123abc ».
$ gh repo autolink create TICKET- "https://example.com/TICKET?query=<num>"
# Créer un autolien numérique vers example.com pour le préfixe de clé « STORY- ».
# Génère https://example.com/STORY?id=123 à partir de « STORY-123 ».
$ gh repo autolink create STORY- "https://example.com/STORY?id=<num>" --numeric
