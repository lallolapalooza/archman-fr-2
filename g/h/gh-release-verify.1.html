NOM

gh-release-verify - Vérifier l'attestation d'une publication

SYNOPIS

gh release verify [<tag>] [flags]

DESCRIPTION

Vérifie qu'une publication GitHub est accompagnée d'une attestation valide cryptographiquement signée.

Une attestation est une déclaration faite par GitHub concernant une publication et ses ressources.

Cette commande vérifie que la publication spécifiée (ou la dernière publication, si aucune étiquette n'est donnée) possède une attestation valide. Elle récupère l'attestation de la publication et affiche les métadonnées de toutes les ressources référencées dans l'attestation, y compris leurs digests.

OPTIONS

--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/RÉPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/RÉPO

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Vérifier la dernière publication
gh release verify
# Vérifier une publication spécifique par étiquette
gh release verify v1.2.3
# Vérifier une publication spécifique par étiquette et afficher l'attestation au format JSON
gh release verify v1.2.3 --format json
