GH-LABEL-EDIT(1) Manuel de l'outil en ligne de commande GitHub GH-LABEL-EDIT(1)

NOM

gh-label-edit - Modifier une étiquette

SYNTAXE

gh label edit <nom> [indicateurs]

DESCRIPTION

Met à jour une étiquette sur GitHub.

Une étiquette peut être renommée en utilisant l'indicateur --name.

La couleur de l'étiquette doit être une valeur hexadécimale à 6 caractères.

OPTIONS

-c, --color <chaîne>
Couleur de l'étiquette
-d, --description <chaîne>
Description de l'étiquette
-n, --name <chaîne>
Nouveau nom de l'étiquette

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consulter l'aide de la commande pour plus d'informations.

EXEMPLE

# Modifier la couleur de l'étiquette bug
$ gh label edit bug --color FF0000
# Renommer et modifier la description de l'étiquette bug
$ gh label edit bug --name gros-bug --description "Bug plus gros que la normale"
