NOM

gh-run-watch - Surveiller une exécution jusqu'à sa complétion, en affichant sa progression

SYNTAXE

gh run watch <run-id> [flags]

DESCRIPTION

Surveiller une exécution jusqu'à sa complétion, en affichant sa progression.

Par défaut, toutes les étapes sont affichées. L'option --compact peut être utilisée pour n'afficher que les étapes pertinentes/échouées.

Cette commande ne prend pas en charge l'authentification via des PAT à granularité fine, car il n'est actuellement pas possible de créer un PAT avec l'autorisation checks:read.

OPTIONS

--compact
Afficher uniquement les étapes pertinentes/échouées
--exit-status
Sortir avec un statut non nul si l'exécution échoue
-i, --interval <entier> (par défaut 3)
Intervalle de rafraîchissement en secondes

OPTIONS HÉRITÉES DES COMMANDES PARENT

-R, --repo <[HOST/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOST/]PROPRIETAIRE/REPO

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Surveiller une exécution jusqu'à ce qu'elle soit terminée
$ gh run watch
# Surveiller une exécution en mode compact
$ gh run watch --compact
# Exécuter une autre commande une fois l'exécution terminée
$ gh run watch && notify-send 'l'exécution est terminée !'
