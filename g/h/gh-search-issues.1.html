DESCRIPTIO

N

Rechercher des issues sur

GitHub.

La commande permet de construire des requêtes en utilisant la syntaxe de recherche GitHub, les drapeaux de paramètres et de qualificateurs, ou une combinaison des

deux.

La syntaxe de recherche GitHub est documentée à l'adresse

:

⟨https://docs.github.com/search-github/searching-on-github/searching-issues-and-pull-requests

⟩

Sur les hôtes GitHub pris en charge, la syntaxe avancée de recherche d'issues peut être utilisée dans la requête --search. Pour plus d'informations sur la recherche avancée d'issues, voir

:

⟨https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues

⟩

Pour plus d'informations sur le traitement des requêtes de recherche contenant un trait d'union, exécuter gh searc

EXEMPL

E 
# Rechercher les issues correspondant à l'ensemble de mots-clés "readme" et "typo"
$ gh search issues readme typo
# Rechercher les issues correspondant à la phrase "broken feature"
$ gh search issues "broken feature"
# Rechercher les issues et pull requests dans l'organisation cli
$ gh search issues --include-prs --owner=cli
# Rechercher les issues ouvertes assignées à vous-même
$ gh search issues --assignee=@me --state=open
# Rechercher les issues avec de nombreux commentaires
$ gh search issues --comments=">100"
# Rechercher les issues sans l'étiquette "bug"
$ gh search issues -- -label:bug
# Rechercher les issues uniquement à partir des dépôts non archivés (par défaut, tous les dépôts)
$ gh search issues --owner github
--archived=fals
