GH-CACHE-DELETE(1) Manuel de l'interface de ligne de commande GitHub GH-CACHE-DELETE(1)

NOM

gh-cache-delete - Supprime les caches d'actions GitHub

SYNTAXE

gh cache delete [<id-cache> | <clé-cache> | --all] [indicateurs]

DESCRIPTION

Supprime les caches d'actions GitHub.

La suppression nécessite une autorisation avec la portée repo.

OPTIONS

-a, --all
Supprime tous les caches
-r, --ref <chaîne>
Supprime par clé de cache et ref, formaté en refs/heads/ ou refs/pull//merge
--succeed-on-no-caches <--all>
Retourne le code de sortie 0 si aucun cache n'est trouvé. Doit être utilisé en conjonction avec --all

OPTIONS HÉRITÉES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/RÉPO>
Sélectionne un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/RÉPO

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Supprimer un cache par id
$ gh cache delete 1234
# Supprimer un cache par clé
$ gh cache delete cache-key
# Supprimer un cache par id dans un dépôt spécifique
$ gh cache delete 1234 --repo cli/cli
# Supprimer un cache par clé et ref de branche
$ gh cache delete cache-key --ref refs/heads/feature-branch
# Supprimer un cache par clé et ref de PR
$ gh cache delete cache-key --ref refs/pull/<numéro-PR>/merge
# Supprimer tous les caches (code de sortie 1 en cas de caches non trouvés)
$ gh cache delete --all
# Supprimer tous les caches (code de sortie 0 en cas de caches non trouvés)
$ gh cache delete --all --succeed-on-no-caches
