GH-EXTENSION(1) Manuel de l'interface en ligne de commande GitHub GH-EXTENSION(1)

NOM

gh-extension - Gérer les extensions de gh

SYNTAXE

gh extension [flags]

DESCRIPTION

Les extensions de l'interface en ligne de commande GitHub sont des dépôts qui fournissent des commandes gh supplémentaires.

Le nom du dépôt d'extension doit commencer par gh- et il doit contenir un exécutable du même nom. Tous les arguments passés à l'invocation gh <nom_ext> seront transmis à l'exécutable gh-<nom_ext> de l'extension.

Une extension ne peut pas remplacer l'une des commandes principales de gh. Si un nom d'extension entre en conflit avec une commande principale de gh, vous pouvez utiliser gh extension exec <nom_ext>.

Lors de l'exécution d'une extension, gh vérifiera les nouvelles versions une fois toutes les 24 heures et affichera un avis de mise à niveau. Voir gh help environment pour savoir comment désactiver les notifications d'extension.

Pour la liste des extensions disponibles, voir ⟨https://github.com/topics/gh-extension⟩.

COMMANDES DISPONIBLES

gh-extension-browse(1)
Ouvre une interface pour parcourir, ajouter et supprimer des extensions
gh-extension-create(1)
Crée une nouvelle extension
gh-extension-exec(1)
Exécute une extension installée
gh-extension-install(1)
Installe une extension gh depuis un dépôt
gh-extension-list(1)
Liste les commandes des extensions installées
gh-extension-remove(1)
Supprime une extension installée
gh-extension-search(1)
Recherche des extensions pour l'interface en ligne de commande GitHub
gh-extension-upgrade(1)
Met à jour les extensions installées

ALIAS

gh extensions, gh ext

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.
