GH(1) Manuel de GitHub CLI GH(1)

NOM

gh - GitHub CLI

SYNTAXE

gh <commande> <sous-commande> [options]

DESCRIPTION

Travaillez de manière transparente avec GitHub depuis la ligne de commande.

COMMANDES DE BASE

gh-auth(1)
Authentifie gh et git avec GitHub
gh-browse(1)
Ouvre les dépôts, les problèmes, les pull requests et plus encore dans le navigateur
gh-codespace(1)
Connectez-vous aux codespaces et gérez-les
gh-gist(1)
Gérez les gists
gh-issue(1)
Gérez les problèmes
gh-org(1)
Gérez les organisations
gh-pr(1)
Gérez les pull requests
gh-project(1)
Travaillez avec les projets GitHub.
gh-release(1)
Gérez les releases
gh-repo(1)
Gérez les dépôts

COMMANDES GITHUB ACTIONS

gh-cache(1)
Gérez les caches de GitHub Actions
gh-run(1)
Affichez les détails des exécutions de workflows
gh-workflow(1)
Affichez les détails des workflows de GitHub Actions

COMMANDES ADDITIONNELLES

gh-agent-task(1)
Travaillez avec les tâches d'agent (aperçu)
gh-alias(1)
Créez des raccourcis de commandes
gh-api(1)
Effectuez une requête API GitHub authentifiée
gh-attestation(1)
Travaillez avec les attestations d'artefacts
gh-completion(1)
Générez des scripts de complétion pour le shell
gh-config(1)
Gérez la configuration pour gh
gh-extension(1)
Gérez les extensions de gh
gh-gpg-key(1)
Gérez les clés GPG
gh-label(1)
Gérez les étiquettes
gh-preview(1)
Exécutez les aperçus pour les fonctionnalités de gh
gh-ruleset(1)
Affichez des informations sur les règles de dépôts
gh-search(1)
Recherchez des dépôts, des problèmes et des pull requests
gh-secret(1)
Gérez les secrets GitHub
gh-ssh-key(1)
Gérez les clés SSH
gh-status(1)
Affichez des informations sur les problèmes, pull requests et notifications pertinents à travers les dépôts
gh-variable(1)
Gérez les variables de GitHub Actions

OPTIONS

--version
Afficher la version de gh

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh issue create
$ gh repo clone cli/cli
$ gh pr checkout 321
