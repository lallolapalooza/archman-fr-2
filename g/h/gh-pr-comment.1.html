GH-PR-COMMENT(1) Manuel de l'outil en ligne de commande GitHub GH-PR-COMMENT(1)

NOM

gh-pr-comment - Ajouter un commentaire à une demande d'extraction

SYNTAXE

gh pr comment [<numéro> | <url> | <branche>] [options]

DESCRIPTION

Ajouter un commentaire à une demande d'extraction GitHub.

Si le corps du commentaire n'est pas fourni via les options, la commande demandera interactivement le texte du commentaire.

OPTIONS

-b, --body <texte>
Le texte du corps du commentaire
-F, --body-file <fichier>
Lire le corps du commentaire à partir d'un fichier (utiliser "-" pour lire depuis l'entrée standard)
--create-if-none
Créer un nouveau commentaire si aucun commentaire n'est trouvé. Peut être utilisé uniquement avec --edit-last
--delete-last
Supprimer le dernier commentaire de l'utilisateur actuel
--edit-last
Modifier le dernier commentaire de l'utilisateur actuel
-e, --editor
Ignorer les invites et ouvrir l'éditeur de texte pour écrire le corps
-w, --web
Ouvrir le navigateur web pour écrire le commentaire
--yes
Ignorer l'invite de confirmation de suppression lorsque --delete-last est fourni

OPTIONS HERITÉES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh pr comment 13 --body "Salut depuis GitHub CLI"
