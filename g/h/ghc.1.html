SYNOPSIS

Chacune des options de ligne de commande de GHC est classée comme statique ou dynamique. Un drapeau statique ne peut être spécifié que sur la ligne de commande, tandis qu'un drapeau dynamique peut également être donné dans une pragma OPTIONS dans un fichier source ou défini depuis la ligne de commande de GHCi avec :set .

Par convention, toutes les options de langage sont dynamiques, comme les options d'avertissement et les options de débogage.

Les autres sont statiques, avec les exceptions notables de -v, -cpp, -fasm, -fvia-C, -fllvm, et -#include. Les sections OPTIONS listent le statut de chaque drapeau.

Les suffixes courants des noms de fichiers pour Haskell sont :

.hs
code source Haskell ; prétraiter, compiler
.lhs
source Haskell littérale ; unlit, prétraiter, compiler
.hi
fichier d'interface ; contient des informations sur les symboles exportés
.hc
