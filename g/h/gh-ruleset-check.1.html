NOM

gh-ruleset-check - Afficher les règles qui s'appliqueraient à une branche donnée

SYNTAXE

gh ruleset check [<branche>] [options]

DESCRIPTION

Affiche des informations sur les règles GitHub qui s'appliquent à une branche donnée.

Le nom de branche fourni n'a pas besoin d'exister ; les règles qui s'appliqueraient à une branche portant ce nom seront affichées. Toutes les règles sont retournées, quelle que soit la manière dont elles sont configurées.

Si aucun nom de branche n'est fourni, la branche actuelle sera utilisée.

L'option --default peut être utilisée pour afficher les règles qui s'appliquent à la branche par défaut du dépôt.

OPTIONS

--default
Vérifier les règles sur la branche par défaut
-w, --web
Ouvrir la page des règles de branche dans un navigateur web

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/DEPOT>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/DEPOT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Afficher toutes les règles qui s'appliquent à la branche actuelle
$ gh ruleset check
# Afficher toutes les règles qui s'appliquent à une branche nommée "ma-branche" dans un autre dépôt
$ gh ruleset check ma-branche --repo proprietaire/depot
# Afficher toutes les règles qui s'appliquent à la branche par défaut dans un autre dépôt
$ gh ruleset check --default --repo proprietaire/depot
# Afficher une règle configurée dans un dépôt différent ou l'un de ses parents
$ gh ruleset view 23 --repo proprietaire/depot
# Afficher une règle au niveau de l'organisation
$ gh ruleset view 23 --org ma-org
