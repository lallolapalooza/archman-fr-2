NOM

gh-run-list - Lister les exécutions de workflows récentes

SYNOPIS

gh run list [options]

DESCRIPTION

Liste les exécutions de workflows récentes.

Notez que la spécification du nom du workflow avec l'option -w ne récupérera pas les workflows désactivés. Passez également l'option -a pour récupérer les exécutions de workflows désactivés en utilisant le nom du workflow et l'option -w.

Les exécutions créées par les workflows de règles d'organisation et d'entreprise n'afficheront pas de nom de workflow en raison des limitations de l'API GitHub.

Pour voir les exécutions associées à une pull request, les utilisateurs doivent exécuter gh pr checks.

OPTIONS

-a, --all
Inclure les workflows désactivés
-b, --branch <chaîne>
Filtrer les exécutions par branche
-c, --commit <SHA>
Filtrer les exécutions par le SHA du commit
--created <date>
Filtrer les exécutions par la date à laquelle elles ont été créées
-e, --event <événement>
Filtrer les exécutions par l'événement qui a déclenché l'exécution
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Sortir en JSON avec les champs spécifiés
-L, --limit <entier> (par défaut 20)
Nombre maximum d'exécutions à récupérer
-s, --status <chaîne>
Filtrer les exécutions par statut : {queued|completed|in_progress|requested|waiting|pending|action_required|cancelled|failure|neutral|skipped|stale|startup_failure|success|timed_out}
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"
-u, --user <chaîne>
Filtrer les exécutions par l'utilisateur qui a déclenché l'exécution
-w, --workflow <chaîne>
Filtrer les exécutions par workflow

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/REPO

ALIAS

gh run ls

CHAMPS JSON

attempt, conclusion, createdAt, databaseId, displayTitle, event, headBranch, headSha, name, number, startedAt, status, updatedAt, url, workflowDatabaseId, workflowName

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
