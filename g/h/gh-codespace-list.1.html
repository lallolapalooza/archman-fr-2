NOM

gh-codespace-list - Lister les codespaces

SYNTAXE

gh codespace list [options]

DESCRIPTION

Lister les codespaces de l'utilisateur authentifié.

Alternativement, les administrateurs d'organisation peuvent lister tous les codespaces facturés à l'organisation.

OPTIONS

-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--json <champs>
Afficher la sortie JSON avec les champs spécifiés
-L, --limit <entier> (par défaut 30)
Nombre maximum de codespaces à lister
-o, --org <login>
Le nom de connexion de l'organisation pour laquelle lister les codespaces (réservé aux administrateurs)
-R, --repo <chaîne>
Nom du dépôt avec propriétaire : utilisateur/dépôt
-t, --template <chaîne>
Formater la sortie JSON en utilisant un modèle Go ; voir « gh help formatting »
-u, --user <nom d'utilisateur>
Le nom d'utilisateur pour lequel lister les codespaces (utilisé avec --org)
-w, --web
Lister les codespaces dans le navigateur web, ne peut pas être utilisé avec --user ou --org

ALIAS

gh codespace ls, gh cs ls

CHAMPS JSON

createdAt, displayName, gitStatus, lastUsedAt, machineName, name, owner, repository, state, vscsTarget

CODES SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

REMARQUE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.
