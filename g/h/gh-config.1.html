NOM

gh-config - Gérer la configuration de gh

SYNTAXE

gh config <commande> [flags]

DESCRIPTION

Affiche ou modifie les paramètres de configuration pour gh.

Paramètres actuellement pris en compte : - git_protocol : le protocole à utiliser pour les opérations de clonage et de push git {https | ssh} (par défaut https) - editor : le programme d'édition de texte à utiliser pour la rédaction de texte - prompt : activer/désactiver les invites interactives dans le terminal {enabled | disabled} (par défaut enabled) - prefer_editor_prompt : activer/désactiver la préférence pour les invites interactives basées sur l'éditeur dans le terminal {enabled | disabled} (par défaut disabled) - pager : le programme de pagination du terminal auquel envoyer la sortie standard - http_unix_socket : le chemin d'un socket Unix via lequel établir une connexion HTTP - browser : le navigateur Web à utiliser pour ouvrir les URL - color_labels : si les étiquettes doivent être affichées en utilisant leurs codes couleur hexadécimaux RVB dans les terminaux qui prennent en charge la vraie couleur {enabled | disabled} (par défaut disabled) - accessible_colors : si des couleurs accessibles et personnalisables sur 4 bits doivent être utilisées {enabled | disabled} (par défaut disabled) - accessible_prompter : si un inviteur accessible doit être utilisé {enabled | disabled} (par défaut disabled) - spinner : si un indicateur de progression animé doit être utilisé {enabled | disabled} (par défaut enabled)

COMMANDES DISPONIBLES

gh-config-clear-cache(1)
Efface le cache de l'interface graphique
gh-config-get(1)
Affiche la valeur d'une clé de configuration donnée
gh-config-list(1)
Affiche une liste de clés et de valeurs de configuration
gh-config-set(1)
Met à jour la configuration avec une valeur pour la clé donnée

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.
