NOM

gh-secret-list - Lister les secrets

SYNTAXE

gh secret list [options]

DESCRIPTION

Lister les secrets à l'un des niveaux suivants : - dépôt (par défaut) : disponibles pour les exécutions GitHub Actions ou Dependabot dans un dépôt - environnement : disponibles pour les exécutions GitHub Actions pour un environnement de déploiement dans un dépôt - organisation : disponibles pour les exécutions GitHub Actions, Dependabot ou Codespaces au sein d'une organisation - utilisateur : disponibles pour Codespaces pour votre utilisateur

OPTIONS

-a, --app <chaîne>
Lister les secrets pour une application spécifique : {actions|codespaces|dependabot}
-e, --env <chaîne>
Lister les secrets pour un environnement
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--json <champs>
Afficher la sortie JSON avec les champs spécifiés
-o, --org <chaîne>
Lister les secrets pour une organisation
-t, --template <chaîne>
Formater la sortie JSON en utilisant un template Go ; voir "gh help formatting"
-u, --user
Lister un secret pour votre utilisateur

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/REPO

ALIAS

gh secret ls

CHAMPS JSON

name, numSelectedRepos, selectedReposURL, updatedAt, visibility

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
