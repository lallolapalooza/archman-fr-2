NOM

gh-issue-develop - Gérer les branches liées à un problème

SYNTAXE

gh issue develop {<numéro> | <url>} [options]

DESCRIPTION

Gérer les branches liées à un problème.

Lorsque vous utilisez l'option --base, la nouvelle branche de développement sera créée à partir de la branche distante spécifiée. La nouvelle branche sera configurée comme branche de base pour les pull requests créées en utilisant gh pr create.

OPTIONS

-b, --base <chaîne>
Nom de la branche distante à partir de laquelle vous souhaitez créer votre nouvelle branche.
--branch-repo <chaîne>
Nom ou URL du dépôt où vous souhaitez créer votre nouvelle branche.
-c, --checkout
Extraire la branche après sa création.
-l, --list
Lister les branches liées au problème.
-n, --name <chaîne>
Nom de la branche à créer.

OPTIONS INHERITÉES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT.

CODES DE FIN

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de fin supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Lister les branches pour le problème 123
$ gh issue develop --list 123
# Lister les branches pour le problème 123 dans le dépôt cli/cli
$ gh issue develop --list --repo cli/cli 123
# Créer une branche pour le problème 123 basée sur la branche my-feature
$ gh issue develop 123 --base my-feature
# Créer une branche pour le problème 123 et l'extraire
$ gh issue develop 123 --checkout
# Créer une branche dans le dépôt monalisa/cli pour le problème 123 dans le dépôt cli/cli
$ gh issue develop 123 --repo cli/cli --branch-repo monalisa/cli
