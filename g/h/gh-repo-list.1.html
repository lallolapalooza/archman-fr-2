NOM

gh-repo-list - Lister les dépôts détenus par un utilisateur ou une organisation

SYNTAXE

gh repo list [<propriétaire>] [options]

DESCRIPTION

Lister les dépôts détenus par un utilisateur ou une organisation.

Notez que la liste n'inclura que les dépôts détenus par l'argument fourni, et les options --fork ou --source ne traverseront pas les frontières de propriété. Par exemple, lors de la liste des forks dans une organisation, la sortie n'inclurait pas ceux détenus par des utilisateurs individuels.

OPTIONS

--archived
Afficher uniquement les dépôts archivés
--fork
Afficher uniquement les forks
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Sortie JSON avec les champs spécifiés
-l, --language <chaîne>
Filtrer par langage de codage principal
-L, --limit <entier> (défaut 30)
Nombre maximum de dépôts à lister
--no-archived
Omettre les dépôts archivés
--source
Afficher uniquement les non-forks
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"
--topic <chaînes>
Filtrer par sujet
--visibility <chaîne>
Filtrer par visibilité du dépôt : {public|private|internal}

ALIAS

gh repo ls

CHAMPS JSON

archivedAt, assignableUsers, codeOfConduct, contactLinks, createdAt, defaultBranchRef, deleteBranchOnMerge, description, diskUsage, forkCount, fundingLinks, hasDiscussionsEnabled, hasIssuesEnabled, hasProjectsEnabled, hasWikiEnabled, homepageUrl, id, isArchived, isBlankIssuesEnabled, isEmpty, isFork, isInOrganization, isMirror, isPrivate, isSecurityPolicyEnabled, isTemplate, isUserConfigurationRepository, issueTemplates, issues, labels, languages, latestRelease, licenseInfo, mentionableUsers, mergeCommitAllowed, milestones, mirrorUrl, name, nameWithOwner, openGraphImageUrl, owner, parent, primaryLanguage, projects, projectsV2, pullRequestTemplates, pullRequests, pushedAt, rebaseMergeAllowed, repositoryTopics, securityPolicyUrl, squashMergeAllowed, sshUrl, stargazerCount, templateRepository, updatedAt, url, usesCustomOpenGraphImage, viewerCanAdminister, viewerDefaultCommitEmail, viewerDefaultMergeMethod, viewerHasStarred, viewerPermission, viewerPossibleCommitEmails, viewerSubscription, visibility, watchers

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
