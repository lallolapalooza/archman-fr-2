NOM

gh-codespace-ssh - Se connecter en SSH à un codespace

SYNTAXE

gh codespace ssh [<options>...] [-- <options-ssh>...] [<commande>]

DESCRIPTION

La commande ssh permet de se connecter en SSH à un codespace. Sous sa forme la plus simple, vous pouvez exécuter gh cs ssh, sélectionner un codespace de manière interactive et vous connecter.

La commande ssh créera automatiquement une paire de clés SSH publique/privée dans le répertoire ~/.ssh si vous ne possédez pas déjà une paire de clés valide. Lors de la sélection de la paire de clés à utiliser, l'ordre de préférence est le suivant :

1.
Clé spécifiée par -i dans <options-ssh>
2.
Clé automatique, si elle existe déjà
3.
Première paire de clés valide dans la configuration SSH (conformément à ssh -G)
4.
Clé automatique, nouvellement créée

La commande ssh prend également en charge une intégration plus poussée avec OpenSSH à l'aide d'une option --config qui génère une configuration SSH par codespace au format OpenSSH. L'inclusion de cette configuration dans votre fichier ~/.ssh/config améliore l'expérience utilisateur des outils qui s'intègrent à OpenSSH, tels que la complétion Bash/Zsh des noms d'hôtes SSH, la complétion de chemins distants pour scp/rsync/sshfs, les dépôts SSH git, etc.

Une fois que cela est configuré (voir le deuxième exemple ci-dessous), vous pouvez vous connecter en SSH aux codespaces comme s'ils étaient des hôtes distants ordinaires (en utilisant ssh, et non gh cs ssh).

Notez que le codespace auquel vous vous connectez doit avoir un serveur SSH préinstallé. Si l'image Docker utilisée pour le codespace ne contient pas de serveur SSH, installez-le dans votre Dockerfile ou, pour les codespaces utilisant des images basées sur Debian, vous pouvez ajouter ce qui suit à votre devcontainer.json :

"features": {
	"ghcr.io/devcontainers/features/sshd:1": {
		"version": "latest"
	}
}

OPTIONS

-c, --codespace <chaîne>
Nom du codespace
--config
Écrit la configuration OpenSSH sur la sortie standard
-d, --debug
Enregistre les données de débogage dans un fichier
--debug-file <chaîne>
Chemin du fichier journal
--profile <chaîne>
Nom du profil SSH à utiliser
-R, --repo <chaîne>
Filtre la sélection du codespace par nom de référentiel (utilisateur/repo)
--repo-owner <chaîne>
Filtre la sélection du codespace par propriétaire du référentiel (nom d'utilisateur ou organisation)
--server-port <entier> (par défaut 0)
Numéro de port du serveur SSH (0 => choisir un port inutilisé)

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh codespace ssh
$ gh codespace ssh --config > ~/.ssh/codespaces
$ printf 'Match all\nInclude ~/.ssh/codespaces\n' >> ~/.ssh/config
