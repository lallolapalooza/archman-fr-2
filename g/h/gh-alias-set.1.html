GH-ALIAS-SET(1) Manuel de l'outil en ligne de commande GitHub GH-ALIAS-SET(1)

NOM

gh-alias-set - Créer un raccourci pour une commande gh

SYNTAXE

gh alias set <alias> <expansion> [flags]

DESCRIPTION

Définit un mot qui sera développé en une commande gh complète lorsqu'il sera invoqué.

L'expansion peut spécifier des arguments et des options supplémentaires. Si l'expansion inclut des espaces réservés positionnels tels que $1, les arguments supplémentaires qui suivent l'alias seront insérés de manière appropriée. Sinon, les arguments supplémentaires seront ajoutés à la commande développée.

Utilisez - comme argument d'expansion pour lire la chaîne d'expansion depuis l'entrée standard. Ceci est utile pour éviter les problèmes de guillemets lors de la définition d'expansions.

Si l'expansion commence par ! ou si --shell a été donné, l'expansion est une expression shell qui sera évaluée par l'interpréteur sh lorsque l'alias sera invoqué. Cela permet d'enchaîner plusieurs commandes via le piping et la redirection.

OPTIONS

--clobber
Écrase les alias existants du même nom
-s, --shell
Déclare un alias à passer par un interpréteur shell

CODES DE SORTIE

0: Exécution réussie

1: Erreur

2: Commande annulée

4: Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Remarque : L'invite de commande sous Windows nécessite l'utilisation de guillemets doubles pour les arguments
$ gh alias set pv 'pr view'
$ gh pv -w 123  #=> gh pr view -w 123
$ gh alias set bugs 'issue list --label=bugs'
$ gh bugs
$ gh alias set homework 'issue list --assignee @me'
$ gh homework
$ gh alias set 'issue mine' 'issue list --mention @me'
$ gh issue mine
$ gh alias set epicsBy 'issue list --author="$1" --label="epic"'
$ gh epicsBy vilmibm  #=> gh issue list --author="vilmibm" --label="epic"
$ gh alias set --shell igrep 'gh issue list --label="$1" | grep "$2"'
$ gh igrep epic foo  #=> gh issue list --label="epic" | grep "foo"
