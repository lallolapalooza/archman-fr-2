NOM

gh-alias-import - Importer des alias à partir d'un fichier YAML

SYNOPIS

gh alias import [<nom_fichier> | -] [options]

DESCRIPTION

Importe des alias à partir du contenu d'un fichier YAML.

Les alias doivent être définis comme une carte en YAML, où les clés représentent les alias et les valeurs représentent les expansions correspondantes. Un exemple de fichier devrait ressembler à ceci :

bugs: issue list --label=bug
igrep: '!gh issue list --label="$1" | grep "$2"'
features: |-
    issue list
    --label=enhancement

Utilisez - pour lire les alias (au format YAML) depuis l'entrée standard.

La sortie de gh alias list peut être utilisée pour produire un fichier YAML contenant vos alias, que vous pouvez utiliser pour les importer d'une machine à une autre. Exécutez gh help alias list pour en savoir plus.

OPTIONS

--clobber
Écrase les alias existants du même nom

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Importer des alias depuis un fichier
$ gh alias import aliases.yml
# Importer des alias depuis l'entrée standard
$ gh alias import -
