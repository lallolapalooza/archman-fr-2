NOM

gh-pr-list - Lister les demandes d'extraction dans un dépôt

SYNTAXE

gh pr list [options]

DESCRIPTION

Lister les demandes d'extraction (pull requests) dans un dépôt GitHub. Par défaut, ne liste que les PR ouvertes.

La syntaxe de la requête de recherche est documentée ici :

⟨https://docs.github.com/en/search-github/searching-on-github/searching-issues-and-pull-requests⟩

Sur les hôtes GitHub compatibles, la syntaxe de recherche avancée des problèmes peut être utilisée dans la requête --search. Pour plus d'informations sur la recherche avancée des problèmes, voir :

⟨https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues⟩

OPTIONS

--app <chaîne>
Filtrer par auteur d'application GitHub
-a, --assignee <chaîne>
Filtrer par personne assignée
-A, --author <chaîne>
Filtrer par auteur
-B, --base <chaîne>
Filtrer par branche de base
-d, --draft
Filtrer par état de brouillon
-H, --head <chaîne>
Filtrer par branche de tête (":" syntax non supportée)
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Afficher JSON avec les champs spécifiés
-l, --label <chaînes>
Filtrer par étiquette
-L, --limit <entier> (défaut 30)
Nombre maximum d'éléments à récupérer
-S, --search <requête>
Rechercher les demandes d'extraction avec une requête
-s, --state <chaîne> (défaut "open")
Filtrer par état : {open|closed|merged|all}
-t, --template <chaîne>
Mettre en forme la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"
-w, --web
Lister les demandes d'extraction dans le navigateur Web

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

ALIAS

gh pr ls

CHAMPS JSON

additions, assignees, author, autoMergeRequest, baseRefName, baseRefOid, body, changedFiles, closed, closedAt, closingIssuesReferences, comments, commits, createdAt, deletions, files, fullDatabaseId, headRefName, headRefOid, headRepository, headRepositoryOwner, id, isCrossRepository, isDraft, labels, latestReviews, maintainerCanModify, mergeCommit, mergeStateStatus, mergeable, mergedAt, mergedBy, milestone, number, potentialMergeCommit, projectCards, projectItems, reactionGroups, reviewDecision, reviewRequests, reviews, state, statusCheckRollup, title, updatedAt, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Lister les PR rédigées par vous
$ gh pr list --author "@me"
# Lister les PR avec un nom de branche de tête spécifique
$ gh pr list --head "typo"
# Lister uniquement les PR avec toutes les étiquettes données
$ gh pr list --label bug --label "priority 1"
# Filtrer les PR en utilisant la syntaxe de recherche
$ gh pr list --search "status:success review:required"
# Trouver une PR qui a introduit un commit donné
$ gh pr list --search "<SHA>" --state merged
