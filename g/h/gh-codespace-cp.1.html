NOM

gh-codespace-cp - Copier des fichiers entre systèmes de fichiers locaux et distants

SYNTAXE

gh codespace cp [-e] [-r] [-- [<options scp>...]] <sources>... <dest>

DESCRIPTION

La commande cp copie des fichiers entre les systèmes de fichiers locaux et distants.

Comme avec la commande cp de UNIX, le premier argument spécifie la source et le dernier la destination ; des sources supplémentaires peuvent être spécifiées après la première, si la destination est un répertoire.

L'indicateur --recursive est requis si une source est un répertoire.

Un préfixe remote: sur un nom de fichier indique qu'il fait référence au système de fichiers de la machine distante (Codespace). Il est résolu par rapport au répertoire personnel de l'utilisateur distant.

Par défaut, les noms de fichiers distants sont interprétés littéralement. Avec l'indicateur --expand, chaque argument de ce type est traité de la même manière que scp, comme une expression Bash à évaluer sur la machine distante, soumise à l'expansion des tildes, accolades, globbing, variables d'environnement et guillemets inversés. Pour des raisons de sécurité, n'utilisez pas cet indicateur avec des arguments fournis par des utilisateurs non fiables ; voir ⟨https://lwn.net/Articles/835962/⟩ pour la discussion.

Par défaut, la commande cp créera une paire de clés SSH publique/privée pour s'authentifier auprès du codespace à l'intérieur du répertoire ~/.ssh.

OPTIONS

-c, --codespace <chaîne>
Nom du codespace
-e, --expand
Développer les noms de fichiers distants sur le shell distant
-p, --profile <chaîne>
Nom du profil SSH à utiliser
-r, --recursive
Copier récursivement les répertoires
-R, --repo <chaîne>
Filtrer la sélection du codespace par nom de dépôt (utilisateur/dépôt)
--repo-owner <chaîne>
Filtrer la sélection du codespace par propriétaire du dépôt (nom d'utilisateur ou organisation)

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh codespace cp -e README.md 'remote:/workspaces/$RepositoryName/'
$ gh codespace cp -e 'remote:~/*.go' ./gofiles/
$ gh codespace cp -e 'remote:/workspaces/myproj/go.{mod,sum}' ./gofiles/
$ gh codespace cp -e -- -F ~/.ssh/codespaces_config 'remote:~/*.go' ./gofiles/
