NOM

gh-browse - Ouvrir des dépôts, des problèmes, des demandes de tirage et plus encore dans le navigateur

SYNTAXE

gh browse [<numéro> | <chemin> | <commit-sha>] [indicateurs]

DESCRIPTION

Passez du terminal au navigateur web pour afficher et interagir avec :

  • Problèmes
  • Demandes de tirage
  • Contenu du dépôt
  • Page d'accueil du dépôt
  • Paramètres du dépôt

OPTIONS

-b, --branch <chaîne>
Sélectionner une autre branche en passant le nom de la branche
-c, --commit <chaîne>
Sélectionner un autre commit en passant le SHA du commit, par défaut le dernier commit
-n, --no-browser
Afficher l'URL de destination au lieu d'ouvrir le navigateur
-p, --projects
Ouvrir les projets du dépôt
-r, --releases
Ouvrir les versions du dépôt
-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT
-s, --settings
Ouvrir les paramètres du dépôt
-w, --wiki
Ouvrir le wiki du dépôt

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

# Ouvrir la page d'accueil du dépôt actuel
$ gh browse
# Ouvrir le répertoire des scripts du dépôt actuel
$ gh browse script/
# Ouvrir le problème ou la demande de tirage 217
$ gh browse 217
# Ouvrir la page du commit
$ gh browse 77507cd94ccafcf568f8560cfecde965fcfa63
# Ouvrir les paramètres du dépôt
$ gh browse --settings
# Ouvrir main.go à la ligne 312
$ gh browse main.go:312
# Ouvrir main.go avec le dépôt à la tête de la branche bug-fix
$ gh browse main.go --branch bug-fix
# Ouvrir main.go avec le dépôt au commit 775007cd
$ gh browse main.go --commit=77507cd94ccafcf568f8560cfecde965fcfa63
