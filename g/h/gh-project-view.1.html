NOM

gh-project-view - Afficher un projet

SYNTAXE

gh project view [<nombre>] [indicateurs]

OPTIONS

--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--owner <chaîne>
Identifiant de connexion du propriétaire. Utiliser "@me" pour l'utilisateur actuel.
-t, --template <chaîne>
Mettre en forme la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"
-w, --web
Ouvrir un projet dans le navigateur

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Afficher le projet "1" de l'utilisateur actuel
$ gh project view 1
# Ouvrir le projet "1" de l'utilisateur monalisa dans le navigateur
$ gh project view 1 --owner monalisa --web
