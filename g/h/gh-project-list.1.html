GH-PROJECT-LIST(1) Manuel de l'interface en ligne de commande GitHub GH-PROJECT-LIST(1)

NOM

gh-project-list - Lister les projets d'un propriétaire

SYNTAXE

gh project list [options]

OPTIONS

--closed
Inclure les projets fermés
--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
-L, --limit <entier> (par défaut 30)
Nombre maximum de projets à récupérer
--owner <chaîne>
Identifiant du propriétaire
-t, --template <chaîne>
Formater la sortie JSON en utilisant un modèle Go ; voir « gh help formatting »
-w, --web
Ouvrir la liste des projets dans le navigateur

ALIASES

gh project ls

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Lister les projets de l'utilisateur actuel
$ gh project list
# Lister les projets de l'organisation github, y compris les projets fermés
$ gh project list --owner github --closed
