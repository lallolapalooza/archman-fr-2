NOM

gh-variable-set - Créer ou mettre à jour des variables

SYNOPSIS

gh variable set <nom-variable> [options]

DESCRIPTION

Définit une valeur pour une variable à l'un des niveaux suivants : - dépôt (par défaut) : disponible pour les exécutions GitHub Actions ou Dependabot dans un dépôt - environnement : disponible pour les exécutions GitHub Actions pour un environnement de déploiement dans un dépôt - organisation : disponible pour les exécutions GitHub Actions ou Dependabot au sein d'une organisation

Une variable d'organisation peut éventuellement être limitée pour n'être disponible qu'à des dépôts spécifiques.

OPTIONS

-b, --body <chaîne>
La valeur de la variable (lit depuis l'entrée standard si non spécifié)
-e, --env <environnement>
Définir une variable d'environnement de déploiement
-f, --env-file <fichier>
Charger les noms et valeurs de variables à partir d'un fichier au format dotenv
-o, --org <organisation>
Définir une variable d'organisation
-r, --repos <dépôts>
Liste des dépôts pouvant accéder à une variable d'organisation
-v, --visibility <chaîne> (par défaut « private »)
Définir la visibilité d'une variable d'organisation : {all|private|selected}

OPTIONS HERITEES DES COMMANDES PARENTES

-R, --repo <[HOTE/]PROPRIETAIRE/DEPOT>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/DEPOT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Ajouter la valeur d'une variable pour le dépôt actuel dans une invite interactive
$ gh variable set MA_VARIABLE
# Lire la valeur de la variable à partir d'une variable d'environnement
$ gh variable set MA_VARIABLE --body "$VALEUR_ENV"
# Lire la valeur de la variable à partir d'un fichier
$ gh variable set MA_VARIABLE < mon_fichier.txt
# Définir une variable pour un environnement de déploiement dans le dépôt actuel
$ gh variable set MA_VARIABLE --env mon_environnement
# Définir une variable au niveau de l'organisation visible par les dépôts publics et privés
$ gh variable set MA_VARIABLE --org monOrg --visibility all
# Définir une variable au niveau de l'organisation visible par des dépôts spécifiques
$ gh variable set MA_VARIABLE --org monOrg --repos depot1,depot2,depot3
# Définir plusieurs variables importées du fichier ".env"
$ gh variable set -f .env
