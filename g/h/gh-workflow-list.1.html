NOM

gh-workflow-list - Lister les workflows

SYNTAXE

gh workflow list [options]

DESCRIPTION

Lister les fichiers de workflow, en masquant les workflows désactivés par défaut.

OPTIONS

-a, --all
Inclure les workflows désactivés
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--json <champs>
Afficher la sortie JSON avec les champs spécifiés
-L, --limit <entier> (par défaut 50)
Nombre maximum de workflows à récupérer
-t, --template <chaîne>
Formater la sortie JSON en utilisant un modèle Go ; voir « gh help formatting »

OPTIONS HÉRITÉES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

ALIAS

gh workflow ls

CHAMPS JSON

id, name, path, state

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.
