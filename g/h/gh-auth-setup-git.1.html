NOM

gh-auth-setup-git - Configure git avec GitHub CLI

SYNOPSIS

gh auth setup-git [options]

DESCRIPTION

Cette commande configure git pour utiliser GitHub CLI comme gestionnaire d'identifiants. Pour plus d'informations sur les gestionnaires d'identifiants git, veuillez consulter :

⟨https://git-scm.com/docs/gitcredentials⟩.

Par défaut, GitHub CLI sera configuré comme gestionnaire d'identifiants pour tous les hôtes authentifiés. S'il n'y a pas d'hôtes authentifiés, la commande échoue avec une erreur.

Alternativement, utilisez l'option --hostname pour spécifier un seul hôte à configurer. Si l'hôte n'est pas authentifié, la commande échoue avec une erreur.

OPTIONS

-f, --force <--hostname>
Force la configuration même si l'hôte n'est pas connu. Doit être utilisé en conjonction avec --hostname
-h, --hostname <chaîne>
Le nom d'hôte pour lequel configurer git

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Configurer git pour utiliser GitHub CLI comme gestionnaire d'identifiants pour tous les hôtes authentifiés
$ gh auth setup-git
# Configurer git pour utiliser GitHub CLI comme gestionnaire d'identifiants pour l'hôte enterprise.internal
$ gh auth setup-git --hostname enterprise.internal
