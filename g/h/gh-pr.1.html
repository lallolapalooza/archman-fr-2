NOM

gh-pr - Gérer les demandes d'extraction (pull requests)

SYNOPSIS

gh pr <commande> [options]

DESCRIPTION

Travailler avec les demandes d'extraction GitHub.

COMMANDES GÉNÉRALES

gh-pr-create(1)
Créer une demande d'extraction
gh-pr-list(1)
Lister les demandes d'extraction dans un dépôt
gh-pr-status(1)
Afficher l'état des demandes d'extraction pertinentes

COMMANDES CIBLÉES

gh-pr-checkout(1)
Extraire une demande d'extraction dans git
gh-pr-checks(1)
Afficher l'état CI pour une seule demande d'extraction
gh-pr-close(1)
Fermer une demande d'extraction
gh-pr-comment(1)
Ajouter un commentaire à une demande d'extraction
gh-pr-diff(1)
Afficher les modifications dans une demande d'extraction
gh-pr-edit(1)
Modifier une demande d'extraction
gh-pr-lock(1)
Verrouiller la conversation d'une demande d'extraction
gh-pr-merge(1)
Fusionner une demande d'extraction
gh-pr-ready(1)
Marquer une demande d'extraction comme prête pour revue
gh-pr-reopen(1)
Rouvrir une demande d'extraction
gh-pr-revert(1)
Annuler une demande d'extraction
gh-pr-review(1)
Ajouter une revue à une demande d'extraction
gh-pr-unlock(1)
Déverrouiller la conversation d'une demande d'extraction
gh-pr-update-branch(1)
Mettre à jour la branche d'une demande d'extraction
gh-pr-view(1)
Afficher une demande d'extraction

OPTIONS

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh pr checkout 353
$ gh pr create --fill
$ gh pr view --web
