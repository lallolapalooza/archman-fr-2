GHOSTWRITER(1) Manuel de l'utilisateur ghostwriter GHOSTWRITER(1)

NOM

ghostwriter - éditeur de texte sans distraction pour Markdown

SYNOPIS

ghostwriter [FICHIER]

DESCRIPTION

ghostwriter est une application d'édition de texte Qt pour Markdown qui offre un environnement d'écriture esthétique et sans distraction.

Créez vos propres thèmes personnalisés, écrivez en mode plein écran, ou utilisez le mode concentration pour vous concentrer sur une ou plusieurs lignes.

Un aperçu HTML en direct vous permet de visualiser le formatage final au fur et à mesure de votre frappe. Les options d'aperçu et d'exportation HTML sont fournies par le processeur Markdown intégré, cmark-gfm ; mais vous pouvez en ajouter d'autres en installant Pandoc, MultiMarkdown ou les processeurs cmark. L'application détectera automatiquement leur installation si leurs emplacements sont dans la variable d'environnement PATH du système.

OPTIONS

--disable-gpu

Désactive l'accélération GPU.
