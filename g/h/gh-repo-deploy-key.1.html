NOM

gh-repo-deploy-key - Gérer les clés de déploiement dans un dépôt

SYNTAXE

gh repo deploy-key <commande> [indicateurs]

COMMANDES DISPONIBLES

gh-repo-deploy-key-add(1)
Ajouter une clé de déploiement à un dépôt GitHub
gh-repo-deploy-key-delete(1)
Supprimer une clé de déploiement d'un dépôt GitHub
gh-repo-deploy-key-list(1)
Lister les clés de déploiement dans un dépôt GitHub

OPTIONS

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.
