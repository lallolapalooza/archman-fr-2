NOM

gh-repo-set-default - Configurer le dépôt par défaut pour ce répertoire

SYNTAXE

gh repo set-default [<dépôt>] [options]

DESCRIPTION

Cette commande définit le dépôt distant par défaut à utiliser lors de l'interrogation de l'API GitHub pour le dépôt cloné localement.

gh utilise le dépôt par défaut pour des actions telles que :

  • visualiser et créer des demandes d'extraction (pull requests)
  • visualiser et créer des problèmes (issues)
  • visualiser et créer des versions (releases)
  • travailler avec les Actions GitHub

NOTE : gh n'utilise pas le dépôt par défaut pour gérer les secrets de dépôt et d'environnement.

OPTIONS

-u, --unset
Supprimer le dépôt par défaut actuel
-v, --view
Afficher le dépôt par défaut actuel

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Sélectionner interactivement un dépôt par défaut
$ gh repo set-default
# Définir un dépôt explicitement
$ gh repo set-default owner/repo
# Afficher le dépôt par défaut actuel
$ gh repo set-default --view
# Afficher plus d'options de dépôt dans le sélecteur interactif
$ git remote add newrepo https://github.com/owner/repo
$ gh repo set-default
