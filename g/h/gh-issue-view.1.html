NOM

gh-issue-view - Afficher un ticket

SYNTAXE

gh issue view {<numéro> | <url>} [options]

DESCRIPTION

Affiche le titre, le corps et d'autres informations d'un ticket.

Avec l'option --web, ouvre le ticket dans un navigateur web à la place.

OPTIONS

-c, --comments
Afficher les commentaires du ticket
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Produire une sortie JSON avec les champs spécifiés
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »
-w, --web
Ouvrir un ticket dans le navigateur

OPTIONS HERITEEES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CHAMPS JSON

assignees, author, body, closed, closedAt, closedByPullRequestsReferences, comments, createdAt, id, isPinned, labels, milestone, number, projectCards, projectItems, reactionGroups, state, stateReason, title, updatedAt, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.
