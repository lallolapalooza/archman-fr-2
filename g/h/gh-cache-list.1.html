GH-CACHE-LIST(1) Manuel de l'interface de ligne de commande GitHub GH-CACHE-LIST(1)

NOM

gh-cache-list - Lister les caches GitHub Actions

SYNTAXE

gh cache list [indicateurs]

OPTIONS

-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--json <champs>
Sortie JSON avec les champs spécifiés
-k, --key <chaîne>
Filtrer par préfixe de clé de cache
-L, --limit <entier> (défaut 30)
Nombre maximum de caches à récupérer
-O, --order <chaîne> (défaut "desc")
Ordre des caches retournés : {asc|desc}
-r, --ref <chaîne>
Filtrer par ref, formaté comme refs/heads/ ou refs/pull//merge
-S, --sort <chaîne> (défaut "last_accessed_at")
Trier les caches récupérés : {created_at|last_accessed_at|size_in_bytes}
-t, --template <chaîne>
Formater la sortie JSON en utilisant un modèle Go ; voir « gh help formatting »

OPTIONS INHERITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/RÉPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/RÉPO

ALIAS

gh cache ls

CHAMPS JSON

createdAt, id, key, lastAccessedAt, ref, sizeInBytes, version

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Lister les caches pour le dépôt actuel
$ gh cache list
# Lister les caches pour un dépôt spécifique
$ gh cache list --repo cli/cli
# Lister les caches triés par date d'accès la plus ancienne
$ gh cache list --sort last_accessed_at --order asc
# Lister les caches dont les clés correspondent à un préfixe (ou correspondent exactement)
$ gh cache list --key key-prefix
# Lister les caches pour une branche spécifique, remplacez <nom-de-branche> par le nom de branche réel
$ gh cache list --ref refs/heads/<nom-de-branche>
# Lister les caches pour une demande de tirage (pull request) spécifique, remplacez <numéro-pr> par le numéro de demande de tirage réel
$ gh cache list --ref refs/pull/<numéro-pr>/merge
