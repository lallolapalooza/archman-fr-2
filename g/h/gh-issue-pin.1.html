NOM

gh-issue-pin - Épingler un ticket

SYNTAXE

gh issue pin {<numéro> | <url>} [options]

DESCRIPTION

Épingler un ticket à un dépôt.

Le ticket peut être spécifié par son numéro ou son URL.

OPTIONS HÉRITÉES DES COMMANDES PARENTALES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Épingler un ticket au dépôt courant
$ gh issue pin 23
# Épingler un ticket par URL
$ gh issue pin https://github.com/owner/repo/issues/23
# Épingler un ticket à un dépôt spécifique
$ gh issue pin 23 --repo owner/repo
