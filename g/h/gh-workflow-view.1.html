GH-WORKFLOW-VIEW(1) Manuel de l'outil en ligne de commande GitHub GH-WORKFLOW-VIEW(1)

NOM

gh-workflow-view - Visualiser le résumé d'un workflow

SYNTAXE

gh workflow view [<id-du-workflow> | <nom-du-workflow> | <nom-de-fichier>] [options]

OPTIONS

-r, --ref <chaîne>
Le nom de la branche ou du tag contenant la version du fichier de workflow que vous souhaitez visualiser.
-w, --web
Ouvrir le workflow dans le navigateur.
-y, --yaml
Visualiser le fichier YAML du workflow.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT.

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

# Sélectionner interactivement un workflow à visualiser
$ gh workflow view
# Visualiser un workflow spécifique
$ gh workflow view 0451
