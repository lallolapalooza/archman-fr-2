NOM

gh-auth-refresh - Actualise les identifiants d'authentification stockés

SYNOPIS

gh auth refresh [options]

DESCRIPTION

Développe ou corrige les étendues d'autorisations pour les identifiants stockés pour le compte actif.

L'option --scopes accepte une liste d'étendues séparées par des virgules que vous souhaitez que vos identifiants gh possèdent. Si aucune étendue n'est fournie, la commande conserve les étendues précédemment ajoutées.

L'option --remove-scopes accepte une liste d'étendues séparées par des virgules que vous souhaitez supprimer de vos identifiants gh. La suppression des étendues est idempotente. L'ensemble minimal d'étendues (repo, read:org et gist) ne peut pas être supprimé.

L'option --reset-scopes réinitialise les étendues de vos identifiants gh à l'ensemble d'étendues par défaut pour votre flux d'authentification.

Si vous avez plusieurs comptes dans gh auth status et que vous souhaitez actualiser les identifiants d'un compte inactif, vous devrez utiliser gh auth switch vers ce compte avant d'utiliser cette commande, puis revenir en arrière une fois que vous avez terminé.

Pour plus d'informations sur les étendues OAuth, voir

⟨https://docs.github.com/en/developers/apps/building-oauth-apps/scopes-for-oauth-apps/⟩.

OPTIONS

-c, --clipboard
Copie le code d'appareil OAuth à usage unique dans le presse-papiers.
-h, --hostname <chaîne>
L'hôte GitHub à utiliser pour l'authentification.
--insecure-storage
Enregistre les identifiants d'authentification en texte brut au lieu d'un gestionnaire d'identifiants.
-r, --remove-scopes <chaînes>
Étendues d'authentification à supprimer de gh.
--reset-scopes
Réinitialise les étendues d'authentification à l'ensemble minimal d'étendues par défaut.
-s, --scopes <chaînes>
Étendues d'authentification supplémentaires pour gh.

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Ouvre un navigateur pour ajouter les étendues write:org et read:public_key
$ gh auth refresh --scopes write:org,read:public_key
# Ouvre un navigateur pour s'assurer que vos identifiants d'authentification ont les étendues minimales correctes
$ gh auth refresh
# Ouvre un navigateur pour supprimer idempotemment l'étendue delete_repo
$ gh auth refresh --remove-scopes delete_repo
# Ouvre un navigateur pour se ré-authentifier avec les étendues minimales par défaut
$ gh auth refresh --reset-scopes
# Ouvre un navigateur pour se ré-authentifier et copier le code OAuth à usage unique dans le presse-papiers
$ gh auth refresh --clipboard
