NOM

gh-agent-task-view - Voir une session de tâche d'agent (aperçu)

SYNTAXE

gh agent-task view [<id-session> | <numéro-pr> | <url-pr> | <branche-pr>] [flags]

DESCRIPTION

Voir une session de tâche d'agent.

OPTIONS

--follow
Suivre les journaux de session de l'agent
--log
Afficher les journaux de session de l'agent
-R, --repo <[HÔTE/]PROPRIÉTAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/REPO
-w, --web
Ouvrir la tâche de l'agent dans le navigateur

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Voir une tâche d'agent par ID de session
$ gh agent-task view e2fa49d2-f164-4a56-ab99-498090b8fcdf
# Voir une tâche d'agent par numéro de pull request dans le dépôt courant
$ gh agent-task view 12345
# Voir une tâche d'agent par numéro de pull request
$ gh agent-task view --repo PROPRIÉTAIRE/REPO 12345
# Voir une tâche d'agent par référence de pull request
$ gh agent-task view PROPRIÉTAIRE/REPO#12345
# Voir les tâches d'agents d'une pull request dans le navigateur
$ gh agent-task view 12345 --web
