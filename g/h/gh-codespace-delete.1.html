NOM

gh-codespace-delete - Supprime les codespaces

SYNTAXE

gh codespace delete [options]

DESCRIPTION

Supprime des codespaces en fonction des critères de sélection.

Tous les codespaces de l'utilisateur authentifié peuvent être supprimés, ainsi que les codespaces d'un dépôt spécifique. Alternativement, seuls les codespaces âgés de plus de N jours peuvent être supprimés.

Les administrateurs d'organisation peuvent supprimer tout codespace facturé à l'organisation.

OPTIONS

--all
Supprime tous les codespaces
-c, --codespace <chaîne>
Nom du codespace
--days <N> (par défaut 0)
Supprime les codespaces âgés de plus de N jours
-f, --force
Ignore la confirmation pour les codespaces contenant des modifications non sauvegardées
-o, --org <identifiant>
L'identifiant de connexion de l'organisation (réservé aux administrateurs)
-R, --repo <chaîne>
Filtre la sélection de codespaces par nom de dépôt (utilisateur/dépôt)
--repo-owner <chaîne>
Filtre la sélection de codespaces par propriétaire du dépôt (nom d'utilisateur ou organisation)
-u, --user <nom-utilisateur>
Le nom d'utilisateur pour lequel supprimer les codespaces (utilisé avec --org)

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
