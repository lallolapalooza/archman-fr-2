NOM

gh-project-item-create - Créer un brouillon d'élément d'issue dans un projet

SYNOPSIS

gh project item-create [<numéro>] [flags]

OPTIONS

--body <chaîne>
Corps de l'issue brouillon
--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--owner <chaîne>
Nom de connexion du propriétaire. Utilisez "@me" pour l'utilisateur actuel.
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"
--title <chaîne>
Titre de l'issue brouillon

CODES DE RETOUR

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de retour supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Créer un brouillon d'élément dans le projet "1" de l'utilisateur actuel
$ gh project item-create 1 --owner "@me" --title "nouvel élément" --body "corps du nouvel élément"
