NOM

gh-label-clone - Clone les étiquettes d'un dépôt à un autre

SYNTAXE

gh label clone <dépôt-source> [flags]

DESCRIPTION

Clone les étiquettes d'un dépôt source vers un dépôt destination sur GitHub. Par défaut, le dépôt destination est le dépôt actuel.

Toutes les étiquettes du dépôt source seront copiées dans le dépôt destination. Les étiquettes du dépôt destination qui ne sont pas présentes dans le dépôt source ne seront ni supprimées ni modifiées.

Les étiquettes du dépôt source qui existent déjà dans le dépôt destination seront ignorées. Vous pouvez écraser les étiquettes existantes dans le dépôt destination en utilisant le drapeau --force.

OPTIONS

-f, --force
Écrase les étiquettes dans le dépôt destination

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionne un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0: Exécution réussie

1: Erreur

2: Commande annulée

4: Authentification requise

NOTE: Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Clone et écrase les étiquettes du dépôt cli/cli dans le dépôt actuel
$ gh label clone cli/cli --force
# Clone les étiquettes du dépôt cli/cli dans un dépôt octocat/cli
$ gh label clone cli/cli --repo octocat/cli
