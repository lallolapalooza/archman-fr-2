NOM

gh alias - Créer des raccourcis de commande

SYNTAXE

gh alias <commande> [flags]

DESCRIPTION

Les alias peuvent être utilisés pour créer des raccourcis pour les commandes gh ou pour composer plusieurs commandes.

Exécutez gh help alias set pour en savoir plus.

COMMANDES DISPONIBLES

gh-alias-delete(1)
Supprimer les alias définis
gh-alias-import(1)
Importer des alias à partir d'un fichier YAML
gh-alias-list(1)
Lister vos alias
gh-alias-set(1)
Créer un raccourci pour une commande gh

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.
