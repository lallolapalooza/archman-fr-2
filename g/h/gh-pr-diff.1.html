NOM

gh-pr-diff - Afficher les modifications dans une requête de tirage (pull request)

SYNTAXE

gh pr diff [<numéro> | <url> | <branche>] [indicateurs]

DESCRIPTION

Affiche les modifications dans une requête de tirage.

Sans argument, la requête de tirage appartenant à la branche actuelle est sélectionnée.

Avec l'indicateur --web, ouvre les différences de la requête de tirage dans un navigateur Web.

OPTIONS

--color <chaîne> (par défaut "auto")
Utiliser la couleur dans la sortie des différences : {toujours|jamais|auto}
--name-only
Afficher uniquement les noms des fichiers modifiés
--patch
Afficher les différences au format patch
-w, --web
Ouvrir les différences de la requête de tirage dans le navigateur

OPTIONS HERITEES DES COMMANDES PARENTES

-R, --repo <[HOTE/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/REPO

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consulter l'aide de la commande pour plus d'informations.
