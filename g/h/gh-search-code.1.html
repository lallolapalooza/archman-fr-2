NOM

gh-search-code - Rechercher dans le code

SYNOPSIS

gh search code <requête> [options]

DESCRIPTION

Rechercher dans le code des dépôts GitHub.

La syntaxe de recherche est documentée ici :

⟨https://docs.github.com/search-github/searching-on-github/searching-code⟩

Notez que ces résultats de recherche sont alimentés par ce qui est maintenant un moteur de recherche de code GitHub hérité. Les résultats peuvent ne pas correspondre à ce qui est vu sur github.com, et les nouvelles fonctionnalités comme la recherche par expressions régulières ne sont pas encore disponibles via l'API GitHub.

Pour plus d'informations sur la gestion des requêtes de recherche contenant un trait d'union, exécutez gh search --help.

OPTIONS

--extension <chaîne>
Filtrer par extension de fichier
--filename <chaîne>
Filtrer par nom de fichier
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Afficher la sortie JSON avec les champs spécifiés
--language <chaîne>
Filtrer les résultats par langue
-L, --limit <entier> (par défaut 30)
Nombre maximum de résultats de code à récupérer
--match <chaînes>
Restreindre la recherche au contenu de fichier ou au chemin de fichier : {fichier|chemin}
--owner <chaînes>
Filtrer par propriétaire
-R, --repo <chaînes>
Filtrer par dépôt
--size <chaîne>
Filtrer par plage de taille, en kilo-octets
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir « gh help formatting »
-w, --web
Ouvrir la requête de recherche dans le navigateur web

CHAMPS JSON

path, repository, sha, textMatches, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Rechercher du code correspondant à "react" et "lifecycle"
$ gh search code react lifecycle
# Rechercher du code correspondant à "gestion des erreurs"
$ gh search code "gestion des erreurs"
# Rechercher du code correspondant à "deque" dans des fichiers Python
$ gh search code deque --language=python
# Rechercher du code correspondant à "cli" dans les dépôts appartenant à l'organisation microsoft
$ gh search code cli --owner=microsoft
# Rechercher du code correspondant à "panic" dans le dépôt GitHub CLI
$ gh search code panic --repo cli/cli
# Rechercher du code correspondant au mot-clé "lint" dans les fichiers package.json
$ gh search code lint --filename package.json
