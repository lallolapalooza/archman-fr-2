NOM

gh-pr-update-branch - Mettre à jour une branche de pull request

SYNTAXE

gh pr update-branch [<numéro> | <url> | <branche>] [options]

DESCRIPTION

Mettre à jour une branche de pull request avec les derniers changements de la branche de base.

Sans argument, la pull request appartenant à la branche actuelle est sélectionnée.

Le comportement par défaut est de mettre à jour avec un commit de fusion (c'est-à-dire, fusionner la branche de base dans la branche de la PR). Pour réconcilier les changements avec un rebase au-dessus de la branche de base, l'option --rebase doit être fournie.

OPTIONS

--rebase
Mettre à jour la branche de PR en rebasant sur la dernière branche de base

OPTIONS HERITEES DES COMMANDES PARENTES

-R, --repo <[HOTE/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/REPO

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh pr update-branch 23
$ gh pr update-branch 23 --rebase
$ gh pr update-branch 23 --repo owner/repo
