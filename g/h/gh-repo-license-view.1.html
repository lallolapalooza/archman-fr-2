NOM

gh-repo-license-view - Afficher la licence d'un dépôt spécifique

SYNTAXE

gh repo license view {<clé-licence> | <spdx-id>} [flags]

DESCRIPTION

Affiche une licence de dépôt spécifique par sa clé ou son identifiant SPDX.

Exécutez gh repo license list pour voir les licences courantes disponibles. Pour encore plus de licences, visitez ⟨https://choosealicense.com/appendix⟩.

OPTIONS

-w, --web
Ouvre https://choosealicense.com/ dans le navigateur.

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Afficher la licence MIT à partir de l'ID SPDX
$ gh repo license view MIT
# Afficher la licence MIT à partir de la clé de licence
$ gh repo license view mit
# Afficher la licence GNU AGPL-3.0 à partir de l'ID SPDX
$ gh repo license view AGPL-3.0
# Afficher la licence GNU AGPL-3.0 à partir de la clé de licence
$ gh repo license view agpl-3.0
# Créer un fichier LICENSE.md avec la licence MIT
$ gh repo license view MIT > LICENSE.md
