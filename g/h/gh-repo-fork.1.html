NOM

gh-repo-fork - Créer une copie (fork) d'un dépôt

SYNTAXE

gh repo fork [<dépôt>] [-- <gitflags>...] [options]

DESCRIPTION

Crée une copie (fork) d'un dépôt.

Sans argument, crée une copie du dépôt actuel. Sinon, crée une copie du dépôt spécifié.

Par défaut, la nouvelle copie est configurée comme votre distant origin et tout distant origin existant est renommé en upstream. Pour modifier ce comportement, vous pouvez spécifier un nom pour le distant de la nouvelle copie avec --nom-distant.

Le distant upstream sera défini comme le dépôt distant par défaut.

Des options supplémentaires de git clone peuvent être passées après --.

OPTIONS

--clone
Cloner la copie (fork)
--branche-par-defaut-uniquement
Inclure uniquement la branche par défaut dans la copie (fork)
--nom-fork <chaîne>
Renommer le dépôt copié (forked)
--organisation <chaîne>
Créer la copie (fork) dans une organisation
--distant
Ajouter un distant git pour la copie (fork)
--nom-distant <chaîne> (par défaut "origin")
Spécifier le nom du nouveau distant

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
