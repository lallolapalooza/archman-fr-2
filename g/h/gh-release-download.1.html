NOM

gh-release-download - Télécharger des actifs de release

SYNTAXE

gh release download [<tag>] [flags]

DESCRIPTION

Télécharger des actifs depuis une release GitHub.

Sans argument de nom de tag explicite, les actifs sont téléchargés depuis la dernière release du projet. Dans ce cas, --pattern ou --archive est requis.

OPTIONS

-A, --archive <format>
Télécharger l'archive du code source dans le format spécifié (zip ou tar.gz)
--clobber
Écraser les fichiers existants portant le même nom
-D, --dir <répertoire> (par défaut ".")
Le répertoire dans lequel télécharger les fichiers
-O, --output <fichier>
Le fichier dans lequel écrire un seul actif (utilisez "-" pour écrire sur la sortie standard)
-p, --pattern <stringArray>
Télécharger uniquement les actifs qui correspondent à un motif glob
--skip-existing
Ignorer le téléchargement lorsque des fichiers du même nom existent

OPTIONS HERITEES DES COMMANDES PARENT

-R, --repo <[HOTE/]PROPRIETAIRE/REPO>
Sélectionner un autre dépôt en utilisant le format [HOTE/]PROPRIETAIRE/REPO

CODES DE RETOUR

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de retour supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Télécharger tous les actifs d'une release spécifique
$ gh release download v1.2.3
# Télécharger uniquement les paquets Debian pour la dernière release
$ gh release download --pattern '*.deb'
# Spécifier plusieurs motifs de fichiers
$ gh release download -p '*.deb' -p '*.rpm'
# Télécharger l'archive du code source d'une release
$ gh release download v1.2.3 --archive=zip
