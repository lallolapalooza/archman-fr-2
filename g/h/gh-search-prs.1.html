DESCRIPTIO

N

Rechercher des pull requests sur

GitHub.

La commande permet de construire des requêtes en utilisant la syntaxe de recherche de GitHub, les options de paramètres et de qualificateurs, ou une combinaison des

deux.

La syntaxe de recherche de GitHub est documentée à l'adresse

:

⟨https://docs.github.com/search-github/searching-on-github/searching-issues-and-pull-requests

⟩

Sur les hôtes GitHub pris en charge, la syntaxe de recherche avancée des issues peut être utilisée dans la requête --search. Pour plus d'informations sur la recherche avancée des issues, voir

:

⟨https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues

⟩

Pour plus d'informations sur le traitement des requêtes de recherche contenant un tiret, exécuter gh searc

EXEMPL

E 
# Rechercher les pull requests correspondant à un ensemble de mots-clés "fix" et "bug"
$ gh search prs fix bug
# Rechercher les pull requests brouillon dans le dépôt cli
$ gh search prs --repo=cli/cli --draft
# Rechercher les pull requests ouvertes demandant votre révision
$ gh search prs --review-requested=@me --state=open
# Rechercher les pull requests fusionnées qui vous sont assignées
$ gh search prs --assignee=@me --merged
# Rechercher les pull requests avec de nombreuses réactions
$ gh search prs --reactions=">100"
# Rechercher les pull requests sans l'étiquette "bug"
$ gh search prs -- -label:bug
# Rechercher les pull requests uniquement à partir de dépôts non archivés (par défaut, tous les dépôts)
$ gh search prs --owner github
--archived=fals
