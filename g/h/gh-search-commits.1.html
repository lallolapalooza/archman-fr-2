NOM

gh-search-commits - Rechercher des commits

SYNTAXE

gh search commits [<requête>] [options]

DESCRIPTION

Recherche des commits sur GitHub.

La commande prend en charge la construction de requêtes en utilisant la syntaxe de recherche GitHub, les options de paramètres et de qualificateurs, ou une combinaison des deux.

La syntaxe de recherche GitHub est documentée ici :

⟨https://docs.github.com/search-github/searching-on-github/searching-commits⟩

Pour plus d'informations sur la gestion des requêtes de recherche contenant un tiret, exécutez gh search --help.

OPTIONS

--author <chaîne>
Filtrer par auteur
--author-date <date>
Filtrer basé sur la date de création
--author-email <chaîne>
Filtrer sur l'e-mail de l'auteur
--author-name <chaîne>
Filtrer sur le nom de l'auteur
--committer <chaîne>
Filtrer par committer
--committer-date <date>
Filtrer basé sur la date de commit
--committer-email <chaîne>
Filtrer sur l'e-mail du committer
--committer-name <chaîne>
Filtrer sur le nom du committer
--hash <chaîne>
Filtrer par hash de commit
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
--json <champs>
Afficher la sortie JSON avec les champs spécifiés
-L, --limit <entier> (par défaut 30)
Nombre maximum de commits à récupérer
--merge
Filtrer sur les commits de fusion
--order <chaîne> (par défaut "desc")
Ordre des commits renvoyés, ignoré sauf si l'option '--sort' est spécifiée : {asc|desc}
--owner <chaînes>
Filtrer sur le propriétaire du dépôt
--parent <chaîne>
Filtrer par hash du parent
-R, --repo <chaînes>
Filtrer sur le dépôt
--sort <chaîne> (par défaut "best-match")
Trier les commits récupérés : {author-date|committer-date}
-t, --template <chaîne>
Mettre en forme la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"
--tree <chaîne>
Filtrer par hash de l'arbre
--visibility <chaînes>
Filtrer basé sur la visibilité du dépôt : {public|private|internal}
-w, --web
Ouvrir la requête de recherche dans le navigateur web

CHAMPS JSON

author, commit, committer, id, parents, repository, sha, url

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

# Rechercher des commits correspondant aux mots-clés "readme" et "typo"
$ gh search commits readme typo
# Rechercher des commits correspondant à la phrase "correction de bug"
$ gh search commits "correction de bug"
# Rechercher des commits commis par l'utilisateur "monalisa"
$ gh search commits --committer=monalisa
# Rechercher des commits créés par des utilisateurs nommés "Jane Doe"
$ gh search commits --author-name="Jane Doe"
# Rechercher des commits correspondant au hash "8dd03144ffdc6c0d486d6b705f9c7fba871ee7c3"
$ gh search commits --hash=8dd03144ffdc6c0d486d6b705f9c7fba871ee7c3
# Rechercher des commits créés avant le 1er février 2022
$ gh search commits --author-date="<2022-02-01"
