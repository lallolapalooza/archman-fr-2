NOM

gh-repo-sync - Synchroniser un dépôt

SYNTAXE

gh repo sync [<dépôt-destination>] [options]

DESCRIPTION

Synchronise le dépôt de destination à partir du dépôt source. La synchronisation utilise la branche par défaut du dépôt source pour mettre à jour la branche correspondante sur le dépôt de destination afin qu'elles soient identiques. Une mise à jour de type « fast-forward » sera utilisée, sauf si l'option --force est spécifiée, auquel cas les deux branches seront synchronisées en utilisant une réinitialisation complète.

Sans argument, le dépôt local est sélectionné comme dépôt de destination.

Le dépôt source est le parent du dépôt de destination par défaut. Cela peut être outrepassé avec l'option --source.

OPTIONS

-b, --branch <chaîne>
Branche à synchroniser (par défaut : branche par défaut)
--force
Réinitialiser complètement la branche du dépôt de destination pour qu'elle corresponde au dépôt source
-s, --source <chaîne>
Dépôt source

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Synchroniser le dépôt local à partir du parent distant
$ gh repo sync
# Synchroniser le dépôt local à partir du parent distant sur une branche spécifique
$ gh repo sync --branch v1
# Synchroniser une fourche distante à partir de son parent
$ gh repo sync owner/cli-fork
# Synchroniser un dépôt distant à partir d'un autre dépôt distant
$ gh repo sync owner/repo --source owner2/repo2
