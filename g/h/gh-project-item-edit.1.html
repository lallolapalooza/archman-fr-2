NOM

gh-project-item-edit - Modifier un élément d'un projet

SYNOPIS

gh project item-edit [options]

DESCRIPTION

Modifie une ébauche de problème (draft issue) ou un élément de projet. Les deux utilisations nécessitent l'identifiant de l'élément à modifier.

Pour les problèmes non-ébauches, l'identifiant du projet est également requis, et seule la valeur d'un champ peut être mise à jour par invocation.

Supprimez la valeur d'un champ d'élément de projet en utilisant l'option --clear.

OPTIONS

--body <chaîne>
Corps de l'élément de problème ébauche
--clear
Supprimer la valeur du champ
--date <chaîne>
Valeur de date pour le champ (AAAA-MM-JJ)
--field-id <chaîne>
Identifiant du champ à mettre à jour
--format <chaîne>
Format de sortie : {json}
--id <chaîne>
Identifiant de l'élément à modifier
--iteration-id <chaîne>
Identifiant de la valeur d'itération à définir sur le champ
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--number <flottant> (défaut 0)
Valeur numérique pour le champ
--project-id <chaîne>
Identifiant du projet auquel le champ appartient
--single-select-option-id <chaîne>
Identifiant de l'option de sélection unique à définir sur le champ
-t, --template <chaîne>
Mettre en forme la sortie JSON en utilisant un modèle Go ; voir « gh help formatting »
--text <chaîne>
Valeur textuelle pour le champ
--title <chaîne>
Titre de l'élément de problème ébauche

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Modifier la valeur d'un champ texte d'un élément
$ gh project item-edit --id <item-id> --field-id <field-id> --project-id <project-id> --text "nouveau texte"
# Effacer la valeur d'un champ d'un élément
$ gh project item-edit --id <item-id> --field-id <field-id> --project-id <project-id> --clear
