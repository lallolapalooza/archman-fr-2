NOM

gh-gist-create - Créer un nouveau gist

SYNTAXE

gh gist create [<nom_de_fichier>... | <motif>... | -] [options]

DESCRIPTION

Crée un nouveau gist GitHub avec le contenu donné.

Les gists peuvent être créés à partir d'un ou plusieurs fichiers. Alternativement, passez - comme nom de fichier pour lire depuis l'entrée standard.

Par défaut, les gists sont secrets ; utilisez --public pour en faire des gists listés publiquement.

OPTIONS

-d, --desc <chaîne>
Une description pour ce gist
-f, --filename <chaîne>
Fournit un nom de fichier à utiliser lors de la lecture depuis l'entrée standard
-p, --public
Liste le gist publiquement (par défaut, "secret")
-w, --web
Ouvre le navigateur web avec le gist créé

ALIAS

gh gist new

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

# Publie le fichier 'hello.py' en tant que gist public
$ gh gist create --public hello.py
# Crée un gist avec une description
$ gh gist create hello.py -d "mon programme Hello-World en Python"
# Crée un gist contenant plusieurs fichiers
$ gh gist create hello.py world.py cool.txt
# Crée un gist contenant plusieurs fichiers en utilisant des motifs
$ gh gist create *.md *.txt artifact.*
# Lit depuis l'entrée standard pour créer un gist
$ gh gist create -
# Crée un gist à partir de la sortie transmise par une autre commande
$ cat cool.txt | gh gist create
