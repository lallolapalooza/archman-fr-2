NOM

gh-repo - Gérer les dépôts

SYNTAXE

gh repo <commande> [options]

DESCRIPTION

Gérer les dépôts GitHub.

COMMANDES GÉNÉRALES

gh-repo-create(1)
Créer un nouveau dépôt
gh-repo-list(1)
Lister les dépôts appartenant à l'utilisateur ou à l'organisation

COMMANDES CIBLÉES

gh-repo-archive(1)
Archiver un dépôt
gh-repo-autolink(1)
Gérer les références d'autolien
gh-repo-clone(1)
Cloner un dépôt localement
gh-repo-delete(1)
Supprimer un dépôt
gh-repo-deploy-key(1)
Gérer les clés de déploiement dans un dépôt
gh-repo-edit(1)
Modifier les paramètres du dépôt
gh-repo-fork(1)
Créer un fork d'un dépôt
gh-repo-gitignore(1)
Lister et afficher les modèles gitignore disponibles pour les dépôts
gh-repo-license(1)
Explorer les licences des dépôts
gh-repo-rename(1)
Renommer un dépôt
gh-repo-set-default(1)
Configurer le dépôt par défaut pour ce répertoire
gh-repo-sync(1)
Synchroniser un dépôt
gh-repo-unarchive(1)
Désarchiver un dépôt
gh-repo-view(1)
Voir un dépôt

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Les commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Consultez l'aide de la commande pour plus d'informations.

EXEMPLE

$ gh repo create
$ gh repo clone cli/cli
$ gh repo view --web
