GH-SECRET-SET(1) Manuel de l'interface de ligne de commande GitHub GH-SECRET-SET(1)

NOM

gh-secret-set - Créer ou mettre à jour des secrets

SYNTAXE

gh secret set <nom-du-secret> [options]

DESCRIPTION

Définit une valeur pour un secret à l'un des niveaux suivants : - dépôt (par défaut) : disponible pour les exécutions GitHub Actions ou Dependabot dans un dépôt - environnement : disponible pour les exécutions GitHub Actions pour un environnement de déploiement dans un dépôt - organisation : disponible pour les exécutions GitHub Actions, Dependabot ou Codespaces au sein d'une organisation - utilisateur : disponible pour Codespaces pour votre utilisateur

Les secrets d'organisation et d'utilisateur peuvent éventuellement être restreints à ne pouvoir être accessibles que par des dépôts spécifiques.

Les valeurs des secrets sont chiffrées localement avant d'être envoyées à GitHub.

OPTIONS

-a, --app <chaîne>
Définit l'application pour un secret : {actions|codespaces|dependabot}
-b, --body <chaîne>
La valeur du secret (lit depuis l'entrée standard si non spécifiée)
-e, --env <environnement>
Définit un secret d'environnement de déploiement
-f, --env-file <fichier>
Charge les noms et valeurs de secrets à partir d'un fichier au format dotenv
--no-repos-selected
Aucun dépôt ne peut accéder au secret de l'organisation
--no-store
Affiche la valeur chiffrée et encodée en base64 au lieu de la stocker sur GitHub
-o, --org <organisation>
Définit un secret d'organisation
-r, --repos <dépôts>
Liste des dépôts pouvant accéder à un secret d'organisation ou d'utilisateur
-u, --user
Définit un secret pour votre utilisateur
-v, --visibility <chaîne> (par défaut "private")
Définit la visibilité pour un secret d'organisation : {all|private|selected}

OPTIONS HERITÉES DES COMMANDES PARENTES

-R, --repo <[HÔTE/]PROPRIÉTAIRE/DÉPÔT>
Sélectionne un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/DÉPÔT

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Collez la valeur du secret pour le dépôt actuel dans une invite interactive
$ gh secret set MYSECRET
# Lisez la valeur du secret à partir d'une variable d'environnement
$ gh secret set MYSECRET --body "$ENV_VALUE"
# Définissez un secret pour un dépôt distant spécifique
$ gh secret set MYSECRET --repo origin/repo --body "$ENV_VALUE"
# Lisez la valeur du secret à partir d'un fichier
$ gh secret set MYSECRET < myfile.txt
# Définissez un secret pour un environnement de déploiement dans le dépôt actuel
$ gh secret set MYSECRET --env monenvironnement
# Définissez un secret au niveau de l'organisation visible par les dépôts publics et privés
$ gh secret set MYSECRET --org ma_MonOrg --visibility all
# Définissez un secret au niveau de l'organisation visible par des dépôts spécifiques
$ gh secret set MYSECRET --org ma_MonOrg --repos repo1,repo2,repo3
# Définissez un secret au niveau de l'organisation visible par aucun dépôt
$ gh secret secret MYSECRET --org ma_MonOrg --no-repos-selected
# Définissez un secret au niveau utilisateur pour Codespaces
$ gh secret set MYSECRET --user
# Définissez un secret au niveau du dépôt pour Dependabot
$ gh secret set MYSECRET --app dependabot
# Définissez plusieurs secrets importés du fichier ".env"
$ gh secret set -f .env
# Définissez plusieurs secrets depuis stdin
$ gh secret set -f - < myfile.txt
