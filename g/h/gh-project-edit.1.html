NOM

gh-project-edit - Modifier un projet

SYNTAXE

gh project edit [<nombre>] [indicateurs]

OPTIONS

-d, --description <chaîne>
Nouvelle description du projet
--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON en utilisant une expression jq
--owner <chaîne>
Login du propriétaire. Utiliser "@me" pour l'utilisateur courant.
--readme <chaîne>
Nouveau README pour le projet
-t, --template <chaîne>
Formater la sortie JSON en utilisant un modèle Go ; voir "gh help formatting"
--title <chaîne>
Nouveau titre pour le projet
--visibility <chaîne>
Changer la visibilité du projet : {PUBLIC|PRIVATE}

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Se référer à l'aide de la commande pour plus d'informations.

EXEMPLE

# Modifier le titre du projet "1" de monalisa
$ gh project edit 1 --owner monalisa --title "Nouveau titre"
