NOM

gh-run-rerun - Relancer une exécution

SYNOPIS

gh run rerun [<id-exécution>] [flags]

DESCRIPTION

Relance une exécution entière, uniquement les tâches échouées, ou une tâche spécifique d'une exécution.

Notez qu'en raison de raisons historiques, l'indicateur --job peut ne pas prendre ce que vous attendez. Spécifiquement, lors de la navigation vers une tâche dans le navigateur, l'URL ressemble à ceci : https://github.com/<propriétaire>/<repo>/actions/runs/<id-exécution>/jobs/<nombre>.

Cependant, ce <nombre> ne doit pas être utilisé avec l'indicateur --job et entraînera un retour de l'API avec un code 404 NOT FOUND. Au lieu de cela, vous pouvez obtenir les bons ID de tâche en utilisant la commande suivante :

gh run view <id-exécution> --json jobs --jq '.jobs[] | {name, databaseId}'

Vous devrez utiliser le champ databaseId pour déclencher la relance des tâches.

OPTIONS

-d, --debug
Relancer avec la journalisation de débogage
--failed
Relancer uniquement les tâches échouées, y compris les dépendances
-j, --job <chaîne>
Relancer un ID de tâche spécifique d'une exécution, y compris les dépendances

OPTIONS INHERITED FROM PARENT COMMANDS

-R, --repo <[HOST/]OWNER/REPO>
Sélectionner un autre dépôt en utilisant le format [HOST/]OWNER/REPO

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Référez-vous à l'aide de la commande pour plus d'informations.
