GH-RELEASE-VERIFY-ASSET(1) Manuel de l'outil en ligne de commande GitHub GH-RELEASE-VERIFY-ASSET(1)

NOM

gh-release-verify-asset - Vérifier qu'un actif donné provient d'une libération

SYNTAXE

gh release verify-asset [<tag>] <chemin-fichier> [indicateurs]

DESCRIPTION

Vérifie qu'un fichier d'actif donné provient d'une Libération GitHub spécifique en utilisant des attestations signées cryptographiquement.

Une attestation est une déclaration faite par GitHub concernant une libération et ses actifs.

Cette commande vérifie que l'actif que vous fournissez correspond à une attestation valide pour la libération spécifiée (ou la dernière libération, si aucun tag n'est donné).

Elle garantit l'intégrité de l'actif en validant que son résumé correspond au sujet dans l'attestation et que l'attestation est associée à la libération.

OPTIONS

--format <chaîne>
Format de sortie : {json}
-q, --jq <expression>
Filtrer la sortie JSON à l'aide d'une expression jq
-t, --template <chaîne>
Formater la sortie JSON à l'aide d'un modèle Go ; voir "gh help formatting"

OPTIONS HÉRITÉES DES COMMANDES PARENT

-R, --repo <[HÔTE/]PROPRIÉTAIRE/RÉPO>
Sélectionner un autre dépôt en utilisant le format [HÔTE/]PROPRIÉTAIRE/RÉPO

CODES DE SORTIE

0 : Exécution réussie

1 : Erreur

2 : Commande annulée

4 : Authentification requise

NOTE : Des commandes spécifiques peuvent avoir des codes de sortie supplémentaires. Reportez-vous à l'aide de la commande pour plus d'informations.

EXEMPLE

# Vérifier un actif de la dernière libération
$ gh release verify-asset ./dist/my-asset.zip
# Vérifier un actif d'une étiquette de libération spécifique
$ gh release verify-asset v1.2.3 ./dist/my-asset.zip
# Vérifier un actif d'une étiquette de libération spécifique et afficher l'attestation au format JSON
$ gh release verify-asset v1.2.3 ./dist/my-asset.zip --format json
