GFTOPK(1) Manuel des commandes générales GFTOPK(1)

NOM

gftopk - convertir les fichiers de police génériques en fichiers de police compactés

SYNTAXE

gftopk [-v] nom_fichier_gf [nom_fichier_pk]

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le programme gftopk convertit un fichier de police générique (gf) généré, par exemple, par mf(1), en un fichier de police compacté (pk) utilisable par les programmes de lecture de DVI. Les fichiers de police compactés (fichiers pk) sont beaucoup plus petits que les fichiers gf correspondants, ils sont donc généralement le format de police de choix.

Le nom_fichier_gf sur la ligne de commande doit être complet. Étant donné que la résolution fait partie de l'extension, il n'est pas logique d'ajouter une extension par défaut comme le font les logiciels TeX ou de lecture de DVI. Le nom_fichier_pk prend par défaut le même nom (tronqué) que le nom_fichier_gf, et il est placé dans le répertoire de travail courant avec le suffixe pk remplaçant gf. Par exemple, le fichier d'entrée cmr10.300gf deviendrait cmr10.300pk.

OPTIONS

Sauf si l'option -v est donnée, gftopk fonctionne silencieusement. Avec -v, le numéro de version du programme et des statistiques sur la compression sont affichés sur stdout.

ENVIRONNEMENT

gftopk recherche le nom_fichier_gf d'abord dans le répertoire courant. S'il n'y est pas, il utilise la variable d'environnement GFFONTS. Si celle-ci n'est pas définie, il utilise la variable TEXFONTS. Si celle-ci n'est pas définie, il utilise la valeur par défaut du système.

Voir tex(1) pour les détails de la recherche.

VOIR AUSSI

gftype(1), pktogf(1), pktype(1).
Donald E. Knuth et al., Metafontware.

AUTEURS

Tomas Rokicki a écrit le programme. Il a été publié dans le cadre du rapport technique Metafontware, disponible auprès du TeX Users Group. Paul Richards l'a initialement porté sur Unix.
