GFTYPE(1) Manuel des commandes générales GFTYPE(1)

NOM

gftype - traduire un fichier de police générique lisible par l'homme

SYNTAXE

gftype [-i] [-m] nom_fichier_gf [nom_fichier_sortie]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le programme gftype traduit un fichier gf (police générique) généré par, par exemple, mf(1), en un fichier lisible par l'homme. Il sert également de programme de validation de fichiers gf (c'est-à-dire que si gftype peut le lire, il est correct) et d'exemple de programme de lecture de fichiers gf pour d'autres logiciels souhaitant lire des fichiers gf.

Le nom_fichier_gf sur la ligne de commande doit être complet. Comme la résolution fait partie de l'extension, il ne serait pas logique d'ajouter une extension par défaut comme le font les logiciels de lecture de TeX ou DVI. Si aucun nom_fichier_sortie n'est spécifié, la sortie va sur stdout.

OPTIONS

Le fichier de sortie inclut des images bitmap des caractères si -i est spécifié sur la ligne de commande, et un listing symbolique des commandes gf si -m est spécifié.

ENVIRONNEMENT

gftype recherche nom_fichier_gf en utilisant la variable d'environnement GFFONTS. Si elle n'est pas définie, il utilise la variable TEXFONTS. Si elle n'est pas définie, il utilise les valeurs par défaut du système.

VOIR AUSSI

dvitype(1), pktype(1).
Donald E. Knuth et al., Metafontware.

AUTEURS

David Fuchs et Don Knuth ont écrit le programme. Il a été publié dans le cadre du rapport technique Metafontware, disponible auprès du TeX Users Group. Paul Richards l'a initialement porté sur Unix.
