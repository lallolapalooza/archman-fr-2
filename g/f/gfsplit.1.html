GFSPLIT(1) Commandes utilisateur GFSPLIT(1)

NOM

gfsplit - diviser un fichier en un certain nombre de parts

SYNTAXE

gfsplit [OPTIONS] FICHIER_ENTRANT [STEM_SORTIE]

DESCRIPTION

Générer une part N sur M du FICHIER_ENTRANT.

-n N
le seuil pour la recombinaison
-m M
le nombre de parts à générer

Le STEM_SORTIE, s'il est omis, prendra par défaut le nom du FICHIER_ENTRANT. Le programme utilisera par défaut une part 3 sur 5 si aucune autre instruction n'est donnée.
