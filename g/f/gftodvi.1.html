GFTODVI(1) Manuel des commandes générales GFTODVI(1)

NOM

gftodvi - créer des feuilles de preuve à partir de fichiers de polices génériques

SYNTAXE

gftodvi [-overflow-label-offset=réel] [-verbose] nom_fichier_gf

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C : Une implémentation de TeX.

Le programme gftodvi convertit un fichier de police générique (gf) produit, par exemple, par mf(1), en un fichier indépendant de l'appareil (DVI) (qui peut ensuite être composé à l'aide du même logiciel qui a déjà été écrit pour TeX). Les caractères du fichier gf apparaîtront un par page, avec des étiquettes, des titres et des annotations tels que spécifiés dans l'Annexe H (Preuves papier) de The Metafontbook.

gftodvi utilise d'autres polices en plus du fichier principal gf. Une police `grise' est utilisée pour composer les pixels qui composent réellement le caractère. (Nous ne voudrions pas que tous les pixels soient simplement noirs, car alors les étiquettes, les points clés et d'autres informations seraient perdus.) Une police `titre' est utilisée pour les informations en haut de la page. Une police `étiquette' est utilisée pour les étiquettes sur les points clés de la figure. Une police `oblique' est utilisée pour composer les lignes diagonales, qui autrement devraient être simulées à l'aide de règles horizontales et verticales. Les polices par défaut grise, titre et étiquette sont respectivement gray, cmr8 et cmtt10 ; il n'y a pas de police oblique par défaut.

Pour changer les polices par défaut, vous pouvez donner des commandes special dans votre fichier source Metafont, ou vous pouvez changer les polices en ligne. Un dialogue en ligne s'engage si vous terminez le nom_fichier_gf par un `/'. Par exemple,
gftodvi cmr10.300gf/
Substitution de police spéciale : grayfont noir
OK ; encore ? grayfontarea /home/art/don/
OK ; encore ? slantfont /home/fonts/slantimagen6
OK ; encore ? <RET>
utilisera /home/art/don/black comme police `grise' et /home/fonts/slantimagen6 comme police `oblique' (ce nom indique une police pour les lignes de pente 1/6 à la résolution d'une imprimante Imagen).

Le nom_fichier_gf sur la ligne de commande doit être complet. Étant donné que la résolution fait partie de l'extension, il ne serait pas logique d'ajouter une extension par défaut comme c'est le cas avec TeX ou les logiciels de lecture DVI. Le nom du fichier de sortie utilise la même racine que le fichier gf, avec l'extension .dvi ajoutée. Par exemple, le fichier d'entrée cmr10.2602gf deviendrait cmr10.dvi.

OPTIONS

L'argument de -overflow-label-offset spécifie la distance par rapport au bord droit de la boîte englobante du caractère à laquelle les équations de débordement (le cas échéant) sont composées. La valeur est donnée en points TeX. La valeur par défaut est un peu plus de deux pouces.

Sans l'option -verbose, gftodvi fonctionne silencieusement. Avec elle, une bannière et un rapport de progression sont imprimés sur stdout.

ENVIRONNEMENT

gftodvi recherche nom_fichier_gf en utilisant la variable d'environnement GFFONTS. Si celle-ci n'est pas définie, il utilise la variable TEXFONTS. Si celle-ci n'est pas définie, il utilise la valeur par défaut du système.

Voir tex(1) pour les détails de la recherche.

FICHIERS

Les polices par défaut.
