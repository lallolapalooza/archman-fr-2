DESCRIPTIO

N

Cette page manuelle documente comment appeler libguestfs depuis le langage de programmation Java. Cette page documente uniquement les différences avec l'API C et donne quelques exemples. Si vous n'êtes pas familier avec l'utilisation de libguestfs, vous devez également lire guestfs

(3).

FERMETURE DU

HANDLE

Le handle est fermé lorsqu'il est récupéré par le ramasse-miettes. Comme les handles de libguestfs contiennent beaucoup d'état, il est également possible de les fermer (et donc de les libérer) explicitement en appelant la méthode

"clo
se".

EXCEPTION

S

Les erreurs provenant des fonctions de libguestfs sont converties en exception "LibGuestFSException". Celle-ci a un seul paramètre qui est le message d'erreur (un "String

").

L'appel de n'importe quelle méthode sur un handle fermé lève la même

exception.

Si malloc(3) ou une autre allocation échoue à l'intérieur des liaisons (bindings), l'exception "LibGuestFSOutOfMem

ory"
est levée.

ÉVÉNEMENT

S

L'API d'événements de libguestfs est entièrement prise en charge depuis Java. Créez une classe qui implémente l'interface "EventCallback", créez une instance de cette classe, puis appelez la méthode "GuestFS#set_event_callback" pour enregistrer cette instance. La méthode "event" de la classe est appelée lorsque libguestfs génère un

événement.

Par exemple, ceci affichera tous les événements de traçage

: 
GuestFS g = new GuestFS ();
g.set_trace (true);
g.set_event_callback (
  new EventCallback () {
    public void event (long event, int eh,
                       String buffer, long[] array) {
      System.out.println (GuestFS.eventToString (event) +
                          ": " + buffer);
    }
  },
  GuestFS.EVENT_TRACE);
g.add_drive_ro ("disk.img");
//
etc.

La sortie ressemble à ceci

: 
EVENT_TRACE: add_drive_ro
"disk.img" EVENT_TRACE:
add_drive_ro = 0 // etc.

ARGUMENTS

OPTIONNELS

Certaines méthodes prennent une map optionnelle de paramètres. Un exemple de cela est "g.add_drive" qui peut être appelé de l'une des deux manières suivantes

: 
g.add_drive ("disk.img")
;

ou avec des arguments optionnels

: 
Map<String, Object> optargs =
  new HashMap<String, Object>() {
  {
    put ("readonly", Boolean.TRUE);
    put ("format", "raw");
  }
};
g.add_drive ("disk.img", optargs)
;

Pour plus d'informations sur ce sujet, voir "CALLS WITH OPTIONAL ARGUMENTS" dans guestfs

(3).

handle

Map<String, Object> optargs =
  new HashMap<String, Object>() {
  {
    put ("close_on_exit", Boolean.FALSE);
    put ("environment", Boolean.TRUE);
  }

EXEMPLE 1 : CRÉER UNE IMAGE DE

DISQUE 
// Exemple montrant comment créer une image de disque.

import java.io.*;
import java.util.Map;
import java.util.HashMap;
import com.redhat.et.libguestfs.*;

public class CreateDisk
{
    static String output = "disk.img";

    public static void main (String[] argv)
    {
        try {
            GuestFS g = new GuestFS ();

            // Créer une image de disque creuse au format brut, de 512 Mo.
            RandomAccessFile f = new RandomAccessFile (output, "rw");
            f.setLength (512 * 1024 * 1024);
            f.close ();

            // Définir l'indicateur de traçage pour pouvoir voir chaque appel
            // à libguestfs.
            g.set_trace (true);

            // Attacher l'image de disque à libguestfs.
            @SuppressWarnings("serial") Map<String, Object> optargs =
                new HashMap<String, Object>() {
                {
                    put ("format", "raw");
                    put ("readonly", Boolean.FALSE);
                }
            };
            g.add_drive_opts (output, optargs);

            // Exécuter le back-end de libguestfs.
            g.launch ();

            // Obtenir la liste des périphériques. Comme nous n'avons ajouté
            // qu'un seul disque ci-dessus, nous nous attendons à ce que cette
            // liste contienne un seul élément.
            String[] devices = g.list_devices ();
            if (devices.length != 1)
                throw new Error ("expected a single device from list-devices");

            // Partitionner le disque en une seule partition MBR.
            g.part_disk (devices[0], "mbr");

            // Obtenir la liste des partitions. Nous nous attendons à un seul
            // élément, qui est la partition que nous venons de créer.
            String[] partitions = g.list_partitions ();
            if (partitions.length != 1)
                throw new Error ("expected a single partition from list-partitions");

            // Créer un système de fichiers sur la partition.
            g.mkfs ("ext4", partitions[0]);

            // Maintenant monter le système de fichiers pour pouvoir ajouter
            // des fichiers.
            g.mount (partitions[0], "/");

            // Créer quelques fichiers et répertoires.
            g.touch ("/empty");
            String message = "Hello, world\n";
            g.write ("/hello", message.getBytes());
            g.mkdir ("/foo");

            // Celui-ci téléverse le fichier local /etc/resolv.conf dans
            // l'image de disque.
            g.upload ("/etc/resolv.conf", "/foo/resolv.conf");

            // Parce que nous avons écrit sur le disque et que nous voulons
            // détecter les erreurs d'écriture, appelez g.shutdown. Vous
            // n'avez pas besoin de faire cela :
            // g.close le fera implicitement.
            g.shutdown ();

            // Notez également que les handles sont automatiquement fermés
            // s'ils sont récupérés par le ramasse-miettes. Vous n'avez besoin
            // d'appeler close que si vous voulez fermer le handle
            // immédiatement.
            g.close ();
        }
        catch (Exception exn) {
            System.err.println (exn);
            System.exit (1);
        }
    }
}

EXEMPLE 2 : INSPECTER UNE IMAGE DE DISQUE DE MACHINE

VIRTUELLE 
// Exemple montrant comment inspecter un disque de machine virtuelle.

import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import com.redhat.et.libguestfs.*;

public class InspectVM
{
    static final Comparator<String> COMPARE_KEYS_LEN =
        new Comparator<String>() {
        public int compare (String k1, String k2) {
            return k1.length() - k2.length();
        }
    };

    public static void main (String[] argv)
    {
        try {
            if (argv.length != 1)
                throw new Error ("usage: InspectVM disk.img");

            String disk = argv[0];

            GuestFS g = new GuestFS ();

            // Attacher l'image de disque en lecture seule à libguestfs.
            @SuppressWarnings("serial") Map<String, Object> optargs =
                new HashMap<String, Object>() {
                {
                    //put ("format", "raw");
                    put ("readonly", Boolean.TRUE);
                }
            };

            g.add_drive_opts (disk, optargs);

            // Exécuter le moteur de libguestfs.
            g.launch ();

            // Demander à libguestfs d'inspecter les systèmes d'exploitation.
            String roots[] = g.inspect_os ();
            if (roots.length == 0)
                throw new Error ("inspect_vm: no operating systems found");

            for (String root : roots) {
                System.out.println ("Root device: " + root);

                // Afficher les informations de base sur le système d'exploitation.
                System.out.println ("  Product name: " +
                                    g.inspect_get_product_name (root));
                System.out.println ("  Version:      " +
                                    g.inspect_get_major_version (root) +
                                    "." +
                                    g.inspect_get_minor_version (root));
                System.out.println ("  Type:         " +
                                    g.inspect_get_type (root));
                System.out.println ("  Distro:       " +
                                    g.inspect_get_distro (root));

                // Monter les disques, comme avec guestfish -i.
                //
                // Trier les clés par longueur, la plus courte d'abord, afin de
                // monter les systèmes de fichiers dans le bon ordre.
                Map<String,String> mps = g.inspect_get_mountpoints (root);
                List<String> mps_keys = new ArrayList<String> (mps.keySet ());
                Collections.sort (mps_keys, COMPARE_KEYS_LEN);

                for (String mp : mps_keys) {
                    String dev = mps.get (mp);
                    try {
                        g.mount_ro (dev, mp);
                    }
                    catch (Exception exn) {
                        System.err.println (exn + " (ignored)");
                    }
                }

                // Si le fichier /etc/issue.net existe, afficher jusqu'à 3 lignes.
                String filename = "/etc/issue.net";
                if (g.is_file (filename)) {
                    System.out.println ("--- " + filename + " ---");
                    String[] lines = g.head_n (3, filename);
                    for (String line : lines)
                        System.out.println (line);
                }

                // Tout démonter.
                g.umount_all ();
            }
        }
        catch (Exception exn) {
            System.err.println (exn);
            System.exit (1);
        }
    }
}
