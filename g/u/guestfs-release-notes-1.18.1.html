guestfs-release-notes - Notes de version de libguestfs

NOTES DE VERSION POUR LIBGUESTFS 1.18

Ces notes de version ne couvrent que les différences par rapport à la précédente séparation stable/dev (1.16.0). Pour les journaux de modifications détaillés, veuillez consulter le dépôt git, ou le fichier ChangeLog distribué dans l'archive tar.

Nouvelles fonctionnalités

outils virt

- virt-sysprep a été réécrit et étendu (merci à Wanlong Gao)
  http://libguestfs.org/virt-sysprep.1.html
- virt-sparsify --zero est une nouvelle option qui met à zéro la
  partition ou le système de fichiers nommé
- virt-sparsify peut maintenant rendre les partitions swap Linux
  creuses en toute sécurité
- virt-sparsify a été corrigé pour nettoyer après ^C
  http://libguestfs.org/virt-sparsify.1.html
- un nouvel outil 'libguestfs-make-fixed-appliance' est fourni pour
  construire des appliances fixes qui peuvent être copiées sur d'autres
  machines qui n'ont pas de support febootstrap
  http://libguestfs.org/libguestfs-make-fixed-appliance.1.html
- virt-filesystems affiche maintenant les parents (conteneurs) des
  périphériques MD et des groupes de volumes
- virt-alignment-scan, exécuté sans arguments, affiche les informations
  d'alignement pour tous les domaines libvirt
- virt-df et virt-alignment-scan afficheront les informations de tous
  les invités même lorsqu'un disque est inaccessible
- nouvelle option --scratch de virt-rescue pour créer des disques
  temporaires
  https://rwmj.wordpress.com/2012/04/26/virt-rescue-scratch/#content
- virt-make-fs peut maintenant être utilisé pour créer du btrfs
- virt-edit préserve les permissions, l'UID, le GID et le contexte
  SELinux lors de l'édition de fichiers
- guestfish transmet correctement l'événement de fermeture via stdout
  et remote
- la nouvelle option '--pipe-error' de guestfish vous permet de
  détecter les erreurs dans les commandes de pipeline
- les jokers de guestfish développent maintenant les noms de
  périphériques
- les caractères virgule et deux-points dans les noms de fichiers sont
  maintenant gérés correctement par tous les outils virt

inspection

- ajout du support pour Fedora 17+
- ajout du support pour FreeDOS
- ajout du support pour Buildroot et Cirros
- l'inspection est maintenant compatible avec les invités Windows qui
  ont subi un sysprep (merci à Grant Williamson).

API

- ajout d'un support étendu pour btrfs, incluant l'ajout de
  plusieurs périphériques, fsck, instantanés (merci à Wanlong Gao)
- la nouvelle API 'mount-local' intègre directement le support FUSE
  dans l'API principale de libguestfs
  https://rwmj.wordpress.com/2012/05/14/tip-using-mount-local-api-from-c/#content
- nouvelle page man : guestfs-performance(1), qui contient des conseils
  d'optimisation des performances
  http://libguestfs.org/guestfs-performance.1.html
- nouvelle page man : guestfs-faq(1), Questions fréquentes
  http://libguestfs.org/guestfs-faq.1.html
- ENOTSUP (depuis guestfs_last_errno) est maintenant renvoyé pour les
  API qui ne sont pas supportées

exemples

- exemple 'copy_over' montrant comment copier entre deux handles
- le programme 'display_icon' affiche l'icône associée à un invité
- l'exemple 'mount_local.c' montre comment utiliser l'API mount-local

Sécurité

(aucun problème de sécurité n'a été trouvé ou corrigé dans cette version)

Nouvelles API

btrfs-device-add : Ajouter des périphériques à un système de fichiers btrfs.
btrfs-device-delete : Supprimer des périphériques d'un système de fichiers btrfs.
btrfs-filesystem-sync : Synchroniser un système de fichiers btrfs.
btrfs-filesystem-balance : Équilibrer un système de fichiers btrfs.
btrfs-fsck : Vérifier un système de fichiers btrfs.
btrfs-set-seeding : Activer ou désactiver le seeding.
btrfs-subvolume-create : Créer un instantané btrfs.
btrfs-subvolume-delete : Supprimer un instantané btrfs.
btrfs-subvolume-list : Lister les instantanés et sous-volumes btrfs.
btrfs-subvolume-set-default : Définir le sous-volume btrfs par défaut.
btrfs-subvolume-snapshot : Créer un instantané btrfs accessible en écriture.
get-e2attrs : Lister les attributs de fichier ext2 d'un fichier.
get-e2generation : Obtenir la génération de fichier ext2 d'un fichier.
isoinfo, isoinfo-device : Obtenir des informations depuis l'en-tête de fichiers ISO.
llz : Lister les fichiers avec les informations SELinux.
lvcreate-free : Créer un volume logique LVM dans % d'espace libre restant.
md-stat : Renvoyer les périphériques sous-jacents d'un périphérique MD.
mkfs-brtfs : Créer un système de fichiers btrfs, avec tous les réglages.
mount-local, mount-local-run, umount-local : Support FUSE dans l'API.
ntfsclone-in, ntfsclone-out : Sauvegarder, restaurer NTFS depuis une sauvegarde.
ntfsfix : Corriger les erreurs courantes et forcer Windows à vérifier NTFS.
set-e2attrs : Définir ou effacer les attributs de fichier ext2 d'un fichier.
set-e2generation : Définir la génération de fichier ext2 d'un fichier.
set-label : Interface unifiée pour définir l'étiquette du système de fichiers.
vgmeta : Obtenir les métadonnées du groupe de volumes.
wipefs : Effacer les signatures du système de fichiers d'un périphérique.
zero-free-space : Mettre à zéro l'espace libre dans un système de fichiers.

Détails internes

- Le sous-répertoire debian/ a été supprimé. Nous vous recommandons
  d'utiliser les paquets Debian officiels créés par Hilko Bengen.
  http://people.debian.org/~bengen/libguestfs/
  http://packages.debian.org/search?keywords=libguestfs
- O_CLOEXEC / SOCK_CLOEXEC est maintenant utilisé pour presque tous les
  descripteurs de fichiers ouverts par la bibliothèque.
- posix_fadvise est appelé lors de la lecture ou de l'écriture
  séquentielle de fichiers volumineux.
- fermer tous les descripteurs de fichiers et supprimer tous les
  gestionnaires de signaux dans le processus de récupération
- plusieurs avertissements gcc et bogues Coverity ont été corrigés ;
  de nombreux bogues strict-overflow ont également été corrigés
- utiliser ./configure --enable-valgrind-daemon pour utiliser valgrind
  sur le démon ; de nombreuses erreurs ont été corrigées
- utiliser ./configure --with-qemu-options pour passer des options
  supplémentaires à qemu
- le démon a maintenant un type de tampon de chaînes extensible
  (DECLARE_STRINGSBUF)
- le fichier d'en-tête <guestfs.h> fonctionne avec C++ et nous avons un
  test de régression pour cela
- plusieurs API qui ne devraient être appelées que dans l'état CONFIG
  donnent maintenant une erreur si ce n'est pas le cas
- .gitignore corrigé pour utiliser des chemins absolus
- les liaisons gobject ont été étendues, incluant la correspondance des
  événements libguestfs aux signaux gobject (merci à Matt Booth)
- la documentation gobject est générée correctement (merci à Matt
  Booth)
- les fichiers d'en-tête gobject vivent maintenant dans un
  sous-répertoire
- le test CompareWithString dans le générateur fonctionne maintenant
- les types de champ de structure FUInt32, FUInt64 utilisent maintenant
  le bon type XDR
- les tests OCaml sont maintenant exécutés sur le code bytecode et le
  code natif.
- java -Xlint:all est utilisé, et tous les avertissements ont été
  corrigés
- bmptopng, wrestool (etc) manquants ou en échec n'impriment plus de
  messages d'avertissement
- ruby : Utiliser RbConfig au lieu de Config.
- PYTHONPATH est défini par le script ./run.
- la construction de l'appliance est maintenant thread-safe.
- l'appliance utilise maintenant 'ip' au lieu des commandes 'ifconfig'
  et 'netstat'
- plusieurs correctifs pour faire fonctionner correctement les
  constructions parallèles
- guestfish --listen nettoie maintenant correctement
- l'état BUSY a été supprimé
- gettextize a été supprimé, remplacé par un simple Makefile.am
- le support gettext couvre maintenant virt-resize, virt-sparsify et
  virt-sysprep
- meilleur support de l'architecture arm
