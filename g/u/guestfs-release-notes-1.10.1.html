NOTES DE VERSION POUR LIBGUESTFS 1.

10

Ces notes de version ne couvrent que les différences par rapport à la précédente séparation des branches stable/dev (1.8.0). Pour les journaux de modifications détaillés, veuillez consulter le dépôt git, ou le fichier ChangeLog distribué dans la

tarball.

Nouvelles

fonctionnalités 
- libguestfs et les outils peuvent être utilisés sur des machines
  virtuelles en cours d'exécution. Voir les options 'guestfish --live' et
  'guestmount --live', et (pour l'interface de bas niveau) les nouvelles API
  set-attach-method et get-attach-method.
- Nouveaux outils virt :
  virt-copy-in, virt-copy-out, virt-tar-in, virt-tar-out.
- libguestfs peut obtenir les correspondances de lettres de lecteur pour les
  invités Windows.
- virt-inspector affiche les correspondances de lettres de lecteur pour les
  invités Windows.
- Les lettres de lecteur peuvent maintenant être utilisées dans les programmes
  virt-edit et guestfish lors du fonctionnement sur des invités Windows.
- virt-resize fonctionne maintenant sur des hôtes 32 bits.
- Vous pouvez maintenant inspecter les disques d'installation et les CD live de
  nombreux systèmes d'exploitation différents.
- guestfish <! cmd qui exécute une commande shell et intègre le résultat.
- guestfish, guestmount, virt-rescue supportent maintenant tous les options
  --ro et --rw, et la valeur par défaut peut être choisie via un fichier de
  configuration (/etc/libguestfs-tools.conf).
- La nouvelle API d'événements permet d'enre
gistrer plus d'un rappel pour chaque événement, rend possible l'appel de l'API depuis d'autres langages, et permet de rediriger presque tous les messages de journalisation, de débogage et de traçage depuis stderr. - Meilleure conformité au FHS pour les fichiers temporaires, y compris l'utilisation de /var/tmp pour les fichiers en cache volumineux qui doivent survivre au redémarrage (au lieu de /tmp). - L'option -m de guestfish, guestmount permet de transmettre les options de montage au système de fichiers sous-jacent. - mkfs-opts permet de spécifier les caractéristiques du système de fichiers. - Traitement plus intelligent des points de montage, permettant aux commandes mkmountpoint, mount et umount-all de fonctionner correctement ensemble. - Les messages de traçage sont préfixés par une chaîne distincte, permettant de les extraire facilement des sorties de débogage avec 'grep'. - guestfs_launch (commande 'run' de guestfish) produit maintenant des messages de progression (une barre de progression guestfish) s'il prend plus de 5 secondes à s'exécuter. - Plusieurs commandes de longue durée pour lesquelles nous ne pouvons pas estimer le temps de fin
ition génèrent des événements de progression en "mode pulsation". La barre de progression dans guestfish a été mise à jour pour les afficher. - Publication de nouveaux exemples de code en : C, Perl, Python, OCaml, Ruby. - Nouveau programme exemple virt-dhcp-address. - Les liaisons Java et Ruby ont été grandement améliorées. - Perl inclut un moyen d'obtenir le errno de la dernière erreur. - Les liaisons Python sont maintenant compatibles avec rpyc (merci à Erez Shinan). - Transifex est maintenant utilisé pour gérer les traductions. http://www.transifex.net/projects/p/libguestfs/ - L'inspection supporte maintenant Red Hat Desktop, les distributions Slackware. - L'inspection ne échoue plus pour les invités Windows qui ont deux disques ou plus. - L'inspection peut maintenant faire la différence entre Windows 2008 Server et Windows 7. - L'inspection peut détecter les applications 32 bits installées dans Windows 64 bits, s'exécutant sur l'émulateur WOW64. - Une série de correctifs de protocole a corrigé l'ancien bogue RHBZ#576879 qui causait autrefois des erreurs lors de la perte de synchronisation du protocole pendant la commande d'upload. - Nouveau logo !

Détails

internes 
- Le fichier 'HACKING' est obsolète. Son contenu a été déplacé dans une
  section de la page manuelle guestfs(3).
- libguestfs-test-tool simplifié. Il n'a plus bes
oin du binaire statique ni n'essaie de construire un ISO. - Les fichiers générés par rpcgen sont compilés avec -fno-strict-aliasing ce qui devrait être plus sû
r (merci à Matt Booth). - virt-resize a été réécrit en OCaml. - guestfish et d'autres outils testés avec valgrind ; quelques fuites de mémoire ont été corrigées.
