NOM

Gufw - Interface graphique pour gérer ufw

DESCRIPTION

Gufw est un pare-feu Ubuntu / Linux facile à utiliser, propulsé par ufw.

Gufw est un moyen simple et intuitif de gérer votre pare-feu Ubuntu. Il prend en charge les tâches courantes telles que l'autorisation ou le blocage de ports préconfigurés, de ports courants p2p ou de ports individuels, et bien plus encore ! Gufw est propulsé par ufw. Introduction iptables est déjà un outil très puissant en soi, mais sa syntaxe peut parfois être gênante et difficile à comprendre, c'est pourquoi les développeurs d'Ubuntu ont décidé de créer ufw ("La raison pour laquelle ufw a été développé est que nous voulions créer un utilitaire de pare-feu au niveau serveur qui soit un peu plus pour les `êtres humains`"), qui devait être plus simple. Maintenant, du côté graphique, Firestarter existait déjà. Mais pourquoi ne pas créer une GUI encore plus facile à utiliser pour les `êtres humains` de bureau, propulsée par ufw ? C'est là qu'intervient Gufw.

UTILISATION

RÉGLAGES DE BASE

Gufw a deux états : Activé et désactivé. Lorsque Gufw est activé, vous pouvez autoriser/rejeter/refuser toutes les connexions entrantes et sortantes.

AJOUTER DES RÈGLES PRÉCONFIGURÉES

Vous pouvez choisir parmi plusieurs programmes et services préconfigurés. Un programme/service peut avoir plusieurs règles.

SUPPRIMER UNE RÈGLE

Étapes :
1. Sélectionnez une règle dans la liste.
2. Cliquez sur le bouton Supprimer. Vous pouvez supprimer plusieurs règles si vous les sélectionnez.

RÉINITIALISER LA CONFIGURATION

Vous supprimerez toutes les règles et réinitialiserez la configuration ufw à son état initial (désactivé) !

MODIFIER LES PRÉFÉRENCES

Vous pouvez modifier vos préférences dans le menu /Édition/Préférences.

TRANSMISSION IP/PORTS

Pour la politique de routage et les règles, vous devez configurer la transmission IP :
Fermer Gufw
Décommentez les lignes suivantes dans /etc/ufw/sysctl.conf :
net/ipv4/ip_forward=1
net/ipv6/conf/default/forwarding=1
net/ipv6/conf/all/forwarding=1
Redémarrer le pare-feu :
ufw reload
Ouvrir à nouveau Gufw : Vous verrez une nouvelle option "Routé" (avec une flèche autour du bouclier) et vous pourrez transmettre n'importe quelle règle depuis la fenêtre Mise à jour ou l'onglet Avancé dans la fenêtre Ajouter.

UTILISER GUFW SANS ENVIRONNEMENT GRAPHIQUE OU ORDINATEUR À DISTANCE

Vous pouvez utiliser Gufw sur un Linux sans environnement graphique (par exemple un serveur Ubuntu) ou depuis un ordinateur distant. Vous aurez besoin de Gufw 13.10.2 ou supérieur. Exportez simplement votre affichage X. Toutes les opérations dans Gufw seront appliquées sur l'ordinateur distant. Important : Si vous activez le pare-feu via ssh sans la règle ssh, vous fermerez la connexion ssh, alors avant d'activer Gufw via une connexion ssh, ajoutez la règle ssh en utilisant ufw avec cette commande :
sudo ufw enable ssh Linux, par exemple :
Ordinateur distant sans environnement graphique (IP = 192.168.1.102, Gufw installé et serveur ssh).
Ordinateur Linux local. Sur cet ordinateur local, ouvrez un terminal et exécutez cette commande :
ssh utilisateur_distant@192.168.1.102 -X
sudo /usr/bin/gufw-pkexec -ssh Windows (Par exemple, IP Windows = 192.168.1.101; IP Linux = 192.168.1.100) :
Installez Putty & Xming.
Sous Windows : Lancez XLaunch depuis le menu Démarrer et cochez "Aucun contrôle d'accès" à la dernière étape.
Connectez-vous à votre Linux avec Putty et exécutez :
export DISPLAY=192.168.1.101:0.0
sudo /usr/bin/gufw-pkexec -ssh
