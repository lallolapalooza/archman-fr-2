guestfs-release-notes - Notes de version de libguestfs

NOTES DE VERSION POUR LIBGUESTFS 1.4

Ces notes de version couvrent uniquement les différences par rapport à la branche stable/dev précédente (1.2.0). Pour des journaux de modifications détaillés, veuillez consulter le dépôt git, ou le fichier ChangeLog distribué dans l'archive tar.

Nouvelles fonctionnalités

- guestfish vous permet de choisir une image disque préparée, par exemple :
    guestfish -N fs:ext4
- Ajout du support en écriture au module guestmount (FUSE).
- virt-resize peut désormais redimensionner le contenu des partitions et des volumes logiques
  dans l'invité, et nous avons un meilleur support pour la réduction des invités.
- Script de complétion par tabulation Bash pour guestfish.
- Ajout du support ZFS à virt-rescue.
- Nouveau outil 'virt-make-fs' pour créer des systèmes de fichiers avec du contenu.
- Autorisation des suffixes sur tous les paramètres numériques de guestfish, par exemple « 1M ».
- La commande 'man' de guestfish ouvre la page de manuel.
- guestfish prend en charge une syntaxe « heredoc » pour le téléchargement de fichiers :
    upload -<<_end_ /foo
    contenu
    _end_
- Certaines commandes guestfish impriment désormais leur sortie en octal ou en hexadécimal
  le cas échéant (RHBZ#583242).
- Autorisation du préfixe tiret sur la ligne de commande guestfish. Cela ignore toute
  erreur de la deuxième commande : (RHBZ#578407)
    guestfish -- cmd1 : -cmd2 : cmd3
- La commande guestfish -h / help renvoie désormais une erreur pour les commandes inexistantes
  (RHBZ#597145).
- Nouvelle commande 'supported' dans guestfish pour lister les groupes de
  commandes optionnelles qui sont prises en charge par le démon / la configuration.
- virt-inspector et guestfish -i fonctionnent désormais pour les noms de fichiers qui
  contiennent des espaces (RHBZ#507810).
- Changement du protocole pour utiliser des adresses link-local, afin d'éviter
  les conflits avec toute adresse que l'hôte pourrait utiliser
  (RHBZ#588763).
- libguestfs définit désormais l'heure et le fuseau horaire corrects lors des modifications de système de fichiers.
- Tri des domaines par ordre alphabétique dans virt-df.
- Commande mkfs-b fonctionnant pour FAT et NTFS en mappant le paramètre blocksize
  à la taille du cluster (RHBZ#599464).
- Ajout de numéros de version aux modules Perl (RHBZ#521674).
- La localisation fonctionne désormais pour tous les outils libguestfs (RHBZ#559963).
- Les outils prennent désormais en charge les VM avec système de fichiers sur image (RHBZ#590167).
- virt-list-partitions a une option '-t' pour afficher la taille totale des disques.
- Inclusion de lentilles Augeas supplémentaires dans l'appliance supermin (Matthew Booth).
- Ajout de rappels d'erreur et de fermeture.
- Ajout de la méthode de fermeture explicite dans l'API Perl.
- Multiples corrections pour la compatibilité RHEL 5.
- Multiples corrections pour la compatibilité Debian/Ubuntu.
- Multiples révisions pour améliorer la documentation.

Sécurité

- Correction d'un déni de service potentiel dans virt-inspector et virt-v2v si une image disque spécialement
  conçue contenait un périphérique caractère à la place de l'un des
  fichiers de configuration que nous lisons sous /etc (RHBZ#582484).

Nouvelles API

- aug-clear - effacer le chemin Augeas
- available-all-groups - retourner une liste de tous les groupes optionnels
- base64-in - télécharger des données encodées en base64 dans un fichier
- base64-out - télécharger un fichier et l'encoder en base64
- checksum-device - calculer des sommes de contrôle sur le contenu d'un périphérique
- checksums-out - calculer des sommes de contrôle de plusieurs fichiers dans un répertoire
- debug-upload - télécharger un fichier vers l'appliance
- fallocate64 - préallouer un fichier dans le système de fichiers de l'invité
- fill-pattern - remplir un fichier avec un motif répétitif d'octets
- get-umask - obtenir le umask actuel
- lvresize-free - étendre un LV pour remplir l'espace libre
- ntfsresize - redimensionner un système de fichiers NTFS
- ntfsresize-size - redimensionner un système de fichiers NTFS (avec taille)
- part-del - supprimer une partition
- part-get-bootable - obtenir le drapeau démarrable d'une partition
- part-get-mbr-id - obtenir l'octet de type MBR d'une partition
- part-set-mbr-id - définir l'octet de type MBR d'une partition
- pvresize-size - redimensionner un volume physique (avec taille)
- pwrite - écrire dans une partie d'un fichier
- resize2fs-size - redimensionner un système de fichiers ext2/3/4 (avec taille)
- txz-in - décompresser une archive tar compressée dans un répertoire (RHBZ#580556)
- txz-out - compresser un répertoire dans une archive tar compressée (RHBZ#580556)
- vfs-label - obtenir le libellé du système de fichiers
- vfs-uuid - obtenir l'UUID du système de fichiers
- vgscan - rechercher les volumes physiques LVM, les groupes de volumes et les volumes logiques
- write - créer un nouveau fichier
- zero-device - écrire des zéros sur un périphérique entier

Internes

- Extension du générateur pour supporter les tests de fonctionnalités optionnelles.
- Vérifications plus strictes des paramètres d'entrée pour de nombreux appels (RHBZ#501893 RHBZ#501894)
- Extension du protocole pour supporter l'envoi de tampons de données 8 bits arbitraires.
- Distribution du fichier 'BUGS' avec les versions. Il s'agit d'un résumé des bugs dans
  la base de données Bugzilla de Red Hat.
- Distribution du fichier 'RELEASE-NOTES' avec les versions, contenant les notes de version.
- Unification de la construction de l'appliance supermin en un seul endroit, dans febootstrap 2.7.
- Correction du code du protocole pour gérer le cas où les deux extrémités envoient des messages d'annulation
  en même temps.
