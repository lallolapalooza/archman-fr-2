GUARDS(1) Documentation Perl fournie par l'utilisateur GUARDS(1)

NOM

guards - sélectionne parmi une liste de fichiers protégés par des conditions

SYNTAXE

guards [--prefix=dir] [--path=dir1:dir2:...] [--default=<0|1>] [--check|--list] [--invert-match] [--with-guards] [--config=<fichier>] symbole ...

DESCRIPTION

Le script lit un fichier de configuration qui peut contenir des protections (dites guards), des noms de fichiers et des commentaires, et écrit les noms de fichiers qui satisfont toutes les protections sur la sortie standard. Le script prend une liste de symboles comme arguments. Chaque ligne du fichier de configuration est traitée séparément. Les lignes peuvent commencer par un certain nombre de protections. Les protections suivantes sont définies :

+xxx Inclure le(s) fichier(s) de cette ligne si le symbole xxx est défini.

-xxx Exclure le(s) fichier(s) de cette ligne si le symbole xxx est défini.

+!xxx Inclure le(s) fichier(s) de cette ligne si le symbole xxx n'est pas défini.

-!xxx Exclure le(s) fichier(s) de cette ligne si le symbole xxx n'est pas défini.

- Exclure ce fichier. Utilisé pour éviter les messages de --check parasites.

Les protections sont traitées de gauche à droite. La dernière protection qui correspond détermine si le fichier est inclus. Si aucune protection n'est spécifiée, le réglage --default détermine si le fichier est inclus.

Si aucun fichier de configuration n'est spécifié, le script lit depuis l'entrée standard.

L'option --check est utilisée pour comparer le fichier de spécification avec le système de fichiers. Si des fichiers sont référencés dans la spécification mais n'existent pas, ou si des fichiers ne sont pas listés dans le fichier de spécification, des avertissements sont imprimés. L'option --path peut être utilisée pour spécifier quel(s) répertoire(s) scanner. Plusieurs répertoires sont séparés par un signe deux-points (":"). L'option --prefix spécifie l'emplacement des fichiers. Alternativement, la syntaxe --path=@<fichier> peut être utilisée pour spécifier un fichier à partir duquel les noms de fichiers seront lus.

Utilisez --list pour lister tous les fichiers indépendamment de toute règle. Utilisez --invert-match pour lister uniquement les patchs exclus. Utilisez --with-guards pour inclure également toutes les règles d'inclusion et d'exclusion.
