DESCRIPTIO

N

Cette page man documente comment appeler libguestfs depuis le langage de programmation Erlang. Cette page documente uniquement les différences avec l'API C et donne quelques exemples. Si vous n'êtes pas familier avec l'utilisation de libguestfs, vous devez également lire guestfs

(3).

OUVERTURE ET FERMURE DU

POIGNÉE

Les liaisons Erlang sont implémentées à l'aide d'un programme externe appelé "erl-guestfs". Ce programme doit se trouver dans le PATH actuel, ou vous devez spécifier le chemin complet vers le programme

: 
{ok, G} = guestfs:create().
{ok, G} = guestfs:create("/path/to/erl-guestfs")
.

"G" est le poignée libguestfs que vous devez passer aux autres

fonctions.

Pour fermer le poignée

: 
ok = gu
estfs:cl
ose(G).

OPTIONNELS

Pour les fonctions qui prennent des arguments optionnels, les premiers arguments sont ceux qui ne sont pas optionnels. Le dernier argument est une liste de tuples fournissant les arguments optionnels

restants.

                            [{format, "raw"}, {readonly, true}])

VALEURS DE RETOUR ET

ERREURS

En cas de succès, la plupart des fonctions renvoient un terme "Result" (qui peut être une liste, une chaîne, un tuple, etc.). S'il n'y a rien à renvoyer de la fonction, alors l'atome "ok" est

renvoyé.

En cas d'erreur, vous verrez l'un des tuples suivants

:
"{error, Msg, Errno}
"
Cela indique une erreur ordinaire de la fonction.

"Msg" est le message d'erreur (chaîne) et "Errno" est l'erreur Unix (entier)

.

"Errno" peut être zéro. Voir "guestfs_last_errno" dans guestf

"
Cela indique que la fonction que vous avez appelée est inconnue. Généralement, cela signifie que vous mélangez "erl-guestfs" d'une autre version de libguestfs, ce que vous ne devriez pas faire.

EXEMPLE 1 : CRÉER UNE IMAGE DE

DISQUE 
#!/usr/bin/env escript
%%! -smp enable -sname create_disk debug verbose
% Exemple montrant comment créer une image de disque.

main(_) ->
    Output = "disk.img",

    {ok, G} = guestfs:create(),

    % Créer une image de disque creuse au format brut, de 512 Mo.
    {ok, File} = file:open(Output, [raw, write, binary]),
    {ok, _} = file:position(File, 512 * 1024 * 1024 - 1),
    ok = file:write(File, " "),
    ok = file:close(File),

    % Définir l'indicateur de trace pour que nous puissions voir chaque appel à libguestfs.
    ok = guestfs:set_trace(G, true),

    % Attacher l'image de disque à libguestfs.
    ok = guestfs:add_drive_opts(G, Output,
                                [{format, "raw"}, {readonly, false}]),

    % Exécuter le back-end libguestfs.
    ok = guestfs:launch(G)
, % Obtenir la liste des périphériques. Parce que nous n'avons ajouté qu'un seul disque % ci-dessus, nous nous attendons à ce que cette liste contienne un seul % élément. [Device] = guestfs:list_devices(G), % Partitionner le disque en une seule partition MBR. ok = guestfs:part_disk(G, Device, "mbr"), % Obtenir la liste des partitions. Nous nous attendons à un seul élément, qui % est la partition que nous venons de créer. [Partition] = guestfs:list_partitions(G), % Créer un système de fichiers sur la partition. ok = guestfs:mkfs(G, "ext4", Partition), % Maintenant monter le système de fichiers pour que nous puissions ajouter des fichiers. *) ok = guestfs:mount(G, Partition, "/"), % Créer quelques fichiers et répertoires. *)
ok = guestfs:touch(G, "/empty"), Message = "Hello, world\n", ok = guestfs:write(G, "/hello", Message), ok = guestfs:mkdir(G, "/foo"), % Celui-ci téléverse le fichier local /etc/resolv.conf dans % l'image de disque. ok = guestfs:upload(G, "/etc/resolv.conf", "/foo/resolv.conf"), % Parce que nous avons écrit sur le disque et que nous voulons détecter les erreurs % d'écriture, appelez guestfs:shutdown. Vous n'avez pas besoin de le faire : % guestfs:close le fera implicitement. ok = guestfs:shutdown(G), % Notez également que les poignées sont automatiquement fermées si elles sont % récupérées par le ramasse-miettes. Vous n'avez besoin d'appeler close % que si vous voulez fermer le poignée immédiatement. ok = guestfs:close(G).

EXEMPLE 2 : INSPECTER UNE IMAGE DE DISQUE DE MACHINE

VIRTUELLE 
#!/usr/bin/env escript
%%! -smp enable -sname inspect_vm debug verbose
% Exemple montrant comment inspecter un disque de machine virtuelle.

main([Disk]) ->
    {ok, G} = guestfs:create(),

    % Attacher l'image de disque en lecture seule à libguestfs.
    ok = guestfs:add_drive_opts(G, Disk, [{readonly, true}]),

    % Exécuter le back-end libguestfs.
    ok = guestfs:launch(G),

    % Demander à libguestfs d'inspecter les systèmes d'exploitation.
    case guestfs:inspect_os(G) of
        [] ->
            io:fwrite("inspect_vm: no operating systems found~n"),
            exit(no_operating_system);
        Roots ->
            list_os(G, Roots)
    end.

list_os(_, []) ->
    ok;
list_os(G, [Root|Roots]) ->
    io:fwrite("Root device: ~s~n", [Root]),

    % Afficher les informations de base sur le système
d'exploitation. Product_name = guestfs:inspect_get_product_name(G, Root), io:fwrite(" Product name: ~s~n", [Product_name]), Major = guestfs:inspect_get_major_version(G, Root), Minor = guestfs:inspect_get_minor_version(G, Root), io:fwrite(" Version: ~w.~w~n", [Major, Minor]), Type = guestfs:inspect_get_type(G, Root), io:fwrite(" Type: ~s~n", [Type]), Distro = guestfs:inspect_get_distro(G, Root), io:fwrite(" Distro: ~s~n", [Distro]), % Monter les disques, comme guestfish -i. Mps = sort_mps(guestfs:inspect_get_mountpoints(G, Root)), mount_mps(G, Mps), % Si le fichier /etc/issue.net existe, afficher jusqu'à 3 lignes. *) Filename = "/etc/issue.net", Is_file = guestfs:is_file(G, Filename), if Is_file -> io:fwrite
("--- ~s ---~n", [Filename]), Lines = guestfs:head_n(G, 3, Filename), write_lines(Lines); true -> ok end, % Démonter tout. ok = guestfs:umount_all(G), list_os(G, Roots). % Trier les clés par longueur, la plus courte d'abord, pour que nous finissions par % monter les systèmes de fichiers dans le bon ordre. sort_mps(Mps) -> Cmp = fun ({A,_}, {B,_}) -> length(A) =< length(B) end, lists:sort(Cmp, Mps). mount_mps(_, []) -> ok; mount_mps(G, [{Mp, Dev}|Mps]) -> case guestfs:mount_ro(G, Dev, Mp) of ok -> ok; { error, Msg, _ } -> io:fwrite("~s (ignored)~n", [Msg]) end, mount_mps(G, Mps). write_lines([]) -> ok; write_lines([Line|Lines]) -> io:fwrite("~s~n", [Line]), write_lines(Lines).
