NOM

guestfs-ruby - Comment utiliser libguestfs depuis Ruby

SYNOPSIS

require 'guestfs'
g = Guestfs::Guestfs.new()
g.add_drive_opts("disk.img",
                 :readonly => true, :format => "raw")
g.launch()

DESCRIPTION

Cette page de manuel documente comment appeler libguestfs depuis le langage de programmation Ruby. Cette page documente uniquement les différences par rapport à l'API C et donne quelques exemples. Si vous n'êtes pas familier avec l'utilisation de libguestfs, vous devez également lire guestfs(3).

EXCEPTIONS

Les erreurs des fonctions de libguestfs sont mappées dans l'exception "Error". Celle-ci a un seul paramètre qui est le message d'erreur (une chaîne).

EXEMPLE 1: CRÉER UNE IMAGE DISQUE

# Exemple montrant comment créer une image disque.

require 'guestfs'

output = "disk.img"

g = Guestfs::Guestfs.new()

# Crée une image disque éparse au format raw, d'une taille de 512 Mo.
g.disk_create (output, "raw", 512 * 1024 * 1024)

# Définit le drapeau de traçage afin que nous puissions voir chaque appel libguestfs.
g.set_trace(1)

# Attache l'image disque à libguestfs.
g.add_drive_opts(output, :format => "raw")

# Lance le backend libguestfs.
g.launch();

# Obtient la liste des périphériques. Comme nous n'avons ajouté qu'un seul disque
# ci-dessus, nous nous attendons à ce que cette liste contienne un seul
# élément.
devices = g.list_devices()
if devices.length != 1 then
  raise "erreur: un seul périphérique attendu de list-devices"
end

# Partitionne le disque en une seule partition MBR.
g.part_disk(devices[0], "mbr")

# Obtient la liste des partitions. Nous attendons un seul élément, qui est
# la partition que nous venons de créer.
partitions = g.list_partitions()
if partitions.length != 1 then
  raise "erreur: une seule partition attendue de list-partitions"
end

# Crée un système de fichiers sur la partition.
g.mkfs("ext4", partitions[0])

# Monte maintenant le système de fichiers afin que nous puissions ajouter des fichiers.
g.mount(partitions[0], "/")

# Crée quelques fichiers et répertoires.
g.touch("/empty")
message = "Bonjour, le monde\n"
g.write("/hello", message)
g.mkdir("/foo")

# Ceci téléverse le fichier local /etc/resolv.conf dans
# l'image disque.
g.upload("/etc/resolv.conf", "/foo/resolv.conf")

# Comme nous avons écrit sur le disque et que nous voulons détecter les erreurs
# d'écriture, appelez g.shutdown. Vous n'avez pas besoin de faire cela :
# g.close le fera implicitement.
g.shutdown()

# Notez également que les poignées sont automatiquement fermées si elles sont
# récupérées par le garbage collector. Vous n'avez besoin d'appeler close
# que si vous souhaitez fermer la poignée immédiatement.
g.close()

EXEMPLE 2: INSPECTER UNE IMAGE DISQUE DE MACHINE VIRTUELLE

# Exemple montrant comment inspecter un disque de machine virtuelle.

require 'guestfs'

if ARGV.length == 0
  puts "utilisation: inspect_vm disk.img"
  exit 1
end
disk = ARGV[0]

g = Guestfs::Guestfs.new()

# Attache l'image disque en lecture seule à libguestfs.
g.add_drive_opts(disk, :readonly => true)

# Lance le backend libguestfs.
g.launch()

# Demande à libguestfs d'inspecter les systèmes d'exploitation.
roots = g.inspect_os()
if roots.length == 0
  puts "inspect_vm: aucun système d'exploitation trouvé"
  exit 1
end

for root in roots do
  printf("Périphérique racine : %s\n", root)

  # Affiche des informations de base sur le système d'exploitation.
  printf("  Nom du produit : %s\n", g.inspect_get_product_name(root))
  printf("  Version :      %d.%d\n",
         g.inspect_get_major_version(root),
         g.inspect_get_minor_version(root))
  printf("  Type :         %s\n", g.inspect_get_type(root))
  printf("  Distribution : %s\n", g.inspect_get_distro(root))

  # Monte les disques, comme guestfish -i.
  #
  # Trie les clés par longueur, la plus courte en premier, afin que nous finissions
  # par monter les systèmes de fichiers dans le bon ordre.
  mps = g.inspect_get_mountpoints(root)
  mps = mps.sort {|a,b| a[0].length <=> b[0].length}
  for mp in mps do
    begin
      g.mount_ro(mp[1], mp[0])
    rescue Guestfs::Error => msg
      printf("%s (ignoré)\n", msg)
    end
  end

  # Si le fichier /etc/issue.net existe, affiche jusqu'à 3 lignes.
  filename = "/etc/issue.net"
  if g.is_file filename then
    printf("--- %s ---\n", filename)
    lines = g.head_n(3, filename)
    for line in lines do
      puts line
    end
  end

  # Démonte tout.
  g.umount_all()
end

Pour obtenir une liste des bogues contre libguestfs, utilisez ce lien : https://bugzilla.redhat.com/buglist.cgi?component=libguestfs&product=Virtualization+Tools

Pour signaler un nouveau bogue contre libguestfs, utilisez ce lien : https://bugzilla.redhat.com/enter_bug.cgi?component=libguestfs&product=Virtualization+Tools

Lors du signalement d'un bogue, veuillez fournir :

  • La version de libguestfs.
  • Où vous avez obtenu libguestfs (par exemple, quelle distribution Linux, compilé à partir des sources, etc.)
  • Décrivez le bogue avec précision et donnez un moyen de le reproduire.
  • Exécutez libguestfs-test-tool(1) et collez la sortie complète et non modifiée dans le rapport de bogue.
