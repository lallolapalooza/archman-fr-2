NOTES DE VERSION DE LIBGUESTFS 1.

12

Ces notes de version ne couvrent que les différences par rapport à la précédente séparation stable/dev (1.10.0). Pour les journaux de modifications détaillés, veuillez consulter le dépôt git, ou le fichier ChangeLog distribué dans la

tarball.

Nouvelles

fonctionnalités

guestfis

h 
- Les chaînes de guestfish peuvent utiliser des séquences d'échappement,
  par ex. ><fs> write /foo "ligne 1\nligne 2\n"
- La commande guestfish write-append peut être utilisée pour ajouter du contenu à la fin de fichiers.
- Les téléversements et téléchargements de fichiers de longue durée peuvent être
  annulés via l'API ou en appuyant sur ^C dans guestfish.
- Nouvelle commande guestfish "display" pour afficher des fichiers graphiques
  à l'intérieur des invités.
- Dans guestfish, la complétion par tabulation fonctionne désormais avec les
  périphériques
/dev/mapper.

virt-inspecto

r 
- L'API d'inspection peut obtenir une icône ou un logo pour certains invités.
- virt-inspector inclut le logo et le nom d'hôte pour certains invités.
- virt-inspector peut désormais obtenir les numéros de version et de release des
  paquets RPM.
- CentOS et Scientific Linux sont désormais traités comme des distributions
  distinctes par l'API
d'inspection.

virt-resiz

e 
- virt-resize peut désormais gérer btrfs.
- La nouvelle option virt-resize --ntfsresize-force permet de redimensionner
  plusieurs fois des machines virtuelles
Windows.

autres outils

virt 
- guestfish, guestmount, virt-cat, virt-df, virt-edit, virt-filesystems,
  virt-inspector, virt-ls et virt-rescue vous permettent désormais d'utiliser
  l'option "-d UUID" pour spécifier un invité par UUID. Cela les rend plus
  robustes lorsqu'ils sont utilisés depuis d'autres programmes.
- L'option virt-ls -lR permet des itérations complexes de fichiers et l'analyse
  d'invités.
- virt-win-reg prend en charge HKEY_USERS\<SID> et HKEY_USERS\<nomdutilisateur>.
- La nouvelle option virt-win-reg --unsafe-printable-strings permet d'afficher
  des chaînes imprimables dans la sortie (de manière non sûre : lisez la
  documentation avant de l'utiliser).
- virt-edit a été réécrit en
C.

API et liaisons de

langage 
- Java est désormais entièrement pris en charge.
  Voir http://libguestfs.org/guestfs-java.3.html
- JRuby est pris en charge via les liaisons Java.
- guestfs_close apparaît désormais dans les messages de trace.
- La liaison Python ajoute la méthode explicite g.close().
- Les programmes Python peuvent désormais utiliser la nouvelle API d'événements.
- Le GIL Python est libéré lors des appels à libguestfs, permettant aux programmes
  Python multi-threads de fonctionner correctement.
- 9pfs (systèmes de fichiers Plan 9 exportés depuis l'hôte) sont désormais pris en charge.
- Ajoutez -DGUESTFS_WARN_DEPRECATED=1 pour avertir de l'utilisation de fonctions
  d'API obsolètes dans les programmes C.
- Nouvelle page de manuel guestfs-recipes(1) avec des recettes.
- mkfs-opts peut désormais définir la taille d'inode et la taille de secteur sur
  les systèmes de fichiers créés (merci à Nikita Menkovich).
- guestfs_last_errno est désormais accessible depuis OCaml (comme g#last_errno
())
.

Sécurit

é 
- optargs_bitmask est vérifié même pour les appels qui n'ont
pas d'arguments optionnels. Cela ferme une possible faille d
'exploitation dans le démon venant d'appelants non fiables.

internes 
- Coverity (un outil d'analyse statique) a été exécuté sur l'ensemble du
  code et de nombreuses corrections ont été apportées.
- Le générateur peut gérer les fonctions qui retournent RBufferOut et ont des
  arguments optionnels.
- Compatible avec Perl 5.14. - Compatible avec gcc 4.6. - Effectue des vérifications de sécurité sur QEMU. - Les tests de l'API C peuvent désormais tester complètement les appels qui ont des arguments optionnels. - Utilisez ./con
figure --enable-install-daemon pour installer /usr/sbin/guestfsd. - Le répertoire po-docs couvre désormais toutes les pages de manuel. - La sortie stderr du processus qemu est désormais capturée par le sous-système d'événements.

Notes de publication 1.12.1

Cette version contient principalement des corrections de bogues et des améliorations de stabilité mineures.

Corrections de bogues notables :

  • Correction d'un problème qui provoquait le blocage de l'application lors de l'ouverture de certains types de fichiers.
  • Amélioration de la gestion des erreurs pour les opérations réseau.
  • Correction d'un problème d'interface utilisateur qui affectait la mise en page sur des écrans de différentes tailles.

Autres améliorations :

  • Mises à jour de sécurité mineures.
  • Optimisations des performances dans diverses sections de l'application.

Nous recommandons à tous les utilisateurs de mettre à jour vers cette version pour bénéficier des dernières corrections et améliorations.
