NOM

guestfs-lua - Comment utiliser libguestfs depuis Lua

SYNOPSIS

local G = require "guestfs"
g = G.create ()
g:add_drive ("test.img", { format = "raw", readonly = true })
g:launch ()
devices = g:list_devices ()
g:close ()

DESCRIPTION

Cette page man documente comment appeler libguestfs depuis le langage de programmation Lua. Cette page documente uniquement les différences avec l'API C et donne quelques exemples. Si vous n'êtes pas familier avec l'utilisation de libguestfs, vous devez également lire guestfs(3).

IMPORTATION DU MODULE

"require "guestfs"" renvoie le module, vous devez donc l'affecter à une variable locale. Utilisation typique :

local G = require "guestfs"

(vous pouvez utiliser le nom de votre choix à la place de "G", mais dans les exemples de cette page man nous utilisons toujours "G").

OUVERTURE ET FERMETURE DU HANDLE

Pour créer un nouveau handle, appelez :

g = G.create ()

Vous pouvez également utiliser les arguments facultatifs :

g = G.create { environment = 0, close_on_exit = 0 }

pour définir les drapeaux "GUESTFS_CREATE_NO_ENVIRONMENT" et/ou "GUESTFS_CREATE_NO_CLOSE_ON_EXIT".

Le handle sera fermé par le ramasse-miettes, mais vous pouvez également le fermer explicitement en faisant :

g:close ()

APPEL DES MÉTHODES

Utilisez la convention Lua habituelle pour appeler des méthodes sur le handle. Par exemple :

g:set_verbose (true)

FONCTIONS AVEC ARGUMENTS FACULTATIFS

Pour les fonctions qui prennent des arguments facultatifs, les premiers arguments sont ceux qui ne sont pas facultatifs. Le dernier argument facultatif est une table fournissant les arguments facultatifs.

g:add_drive ("test.img")

ou :

g:add_drive ("test.img", { format = "raw", readonly = true })

VALEURS SUR 64 BITS

Actuellement, les valeurs sur 64 bits doivent être passées sous forme de chaînes et sont retournées sous forme de chaînes. C'est parce que Lua sur 32 bits ne peut pas gérer correctement les entiers sur 64 bits. Nous espérons trouver une meilleure solution plus tard.

ERREURS

La plupart (mais pas toutes) des erreurs sont converties en objets (c'est-à-dire des tables) contenant les champs suivants :

msg
Le message d'erreur (correspondant à "guestfs_last_error" dans guestfs(3)).
code
Le "errno" (correspondant à "guestfs_last_errno" dans guestfs(3)).

Ces objets ont également des fonctions "__tostring" attachées, vous pouvez donc utiliser "tostring" (ou la conversion implicite) pour les convertir en chaînes imprimables.

Notez que la bibliothèque lance également certaines erreurs sous forme de chaînes simples. Vous devrez peut-être vérifier le type.

ÉVÉNEMENTS

Les événements peuvent être enregistrés en appelant "set_event_callback":

eh = g:set_event_callback (cb, "close")

ou pour enregistrer un seul rappel pour plusieurs événements, faites du deuxième argument une liste :

eh = g:set_event_callback (cb, { "appliance", "library", "trace" })

Une liste de tous les types d'événements valides (chaînes) se trouve dans la variable globale "G.event_all".

Le rappel ("cb") est appelé avec les paramètres suivants :

function cb (g, event, eh, flags, buf, array)
  -- g est le handle guestfs
  -- event est une chaîne qui est le nom de l'événement déclenché
  -- flags est toujours zéro
  -- buf est le tampon de données (par ex. message de journal, etc.)
  -- array est le tableau d'entiers sur 64 bits (par ex. état de la barre de progression, etc.)
  ...
end

Vous pouvez également supprimer un rappel en utilisant le handle d'événement ("eh") qui a été retourné lorsque vous avez enregistré le rappel :

g:delete_event_callback (eh)

EXEMPLE 1 : CRÉER UNE IMAGE DE DISQUE

-- Exemple montrant comment créer une image de disque.

local G = require "guestfs"

local output = "disk.img"

local g = G.create ()

-- Créer une image de disque creuse au format brut, de 512 Mo.
file = io.open (output, "w")
file:seek ("set", 512 * 1024 * 1024)
file:write (' ')
file:close ()

-- Définir le drapeau de trace pour pouvoir voir chaque appel à libguestfs.
g:set_trace (true)

-- Attacher l'image de disque à libguestfs.
g:add_drive (output, { format = "raw", readonly = false })

-- Exécuter le back-end de libguestfs.
g:launch ()

-- Obtenir la liste des périphériques.  Parce que nous n'avons ajouté qu'un seul disque
-- ci-dessus, nous nous attendons à ce que cette liste contienne un seul
-- élément.
devices = g:list_devices ()
if table.getn (devices) ~= 1 then
   error "expected a single device from list-devices"
end

-- Partitionner le disque en une seule partition MBR.
g:part_disk (devices[1], "mbr")

-- Obtenir la liste des partitions.  Nous nous attendons à un seul élément, qui
-- est la partition que nous venons de créer.
partitions = g:list_partitions ()
if table.getn (partitions) ~= 1 then
   error "expected a single partition from list-partitions"
end

-- Créer un système de fichiers sur la partition.
g:mkfs ("ext4", partitions[1])

-- Maintenant monter le système de fichiers pour pouvoir ajouter des fichiers.
g:mount (partitions[1], "/")

-- Créer quelques fichiers et répertoires.
g:touch ("/empty")
message = "Hello, world\n"
g:write ("/hello", message)
g:mkdir ("/foo")

-- Celui-ci téléverse le fichier local /etc/resolv.conf dans
-- l'image de disque.
g:upload ("/etc/resolv.conf", "/foo/resolv.conf")

-- Parce que nous avons écrit sur le disque et que nous voulons détecter les erreurs
-- d'écriture, appelez g:shutdown.  Vous n'avez pas besoin de faire cela :
-- g:close le fera implicitement.
g:shutdown ()

-- Notez également que les handles sont automatiquement fermés s'ils sont
-- récupérés par le ramasse-miettes.  Vous n'avez besoin d'appeler close
-- que si vous voulez fermer le handle immédiatement.
g:close ()

EXEMPLE 2 : INSPECTER UNE IMAGE DE DISQUE DE MACHINE VIRTUELLE

-- Exemple montrant comment inspecter un disque de machine virtuelle.

local G = require "guestfs"

if table.getn (arg) == 1 then
   disk = arg[1]
else
   error ("usage: inspect_vm disk.img")
end

local g = G.create ()

-- Attacher l'image de disque en lecture seule à libguestfs.
g:add_drive (disk, { -- format:"raw"
                     readonly = true })

-- Exécuter le back-end de libguestfs.
g:launch ()

-- Demander à libguestfs d'inspecter les systèmes d'exploitation.
local roots = g:inspect_os ()
if table.getn (roots) == 0 then
   error ("inspect_vm: no operating systems found")
end

for _, root in ipairs (roots) do
   print ("Root device: ", root)

   -- Afficher les informations de base sur le système d'exploitation.
   print ("  Product name: ", g:inspect_get_product_name (root))
   print ("  Version:      ",
          g:inspect_get_major_version (root),
          g:inspect_get_minor_version (root))
   print ("  Type:         ", g:inspect_get_type (root))
   print ("  Distro:       ", g:inspect_get_distro (root))

   -- Monter les disques, comme guestfish -i.
   --
   -- Trier les clés par longueur, la plus courte d'abord, afin que nous
   -- montions les systèmes de fichiers dans le bon ordre.
   mps = g:inspect_get_mountpoints (root)
   table.sort (mps,
               function (a, b)
                  return string.len (a) < string.len (b)
               end)
   for mp,dev in pairs (mps) do
      pcall (function () g:mount_ro (dev, mp) end)
   end

   -- Si le fichier /etc/issue.net existe, afficher jusqu'à 3 lignes.
   filename = "/etc/issue.net"
   if g:is_file (filename) then
      print ("--- ", filename, &quot; ---")
      lines = g:head_n (3, filename)
      for _, line in ipairs (lines) do
         print (line)
      end
   end

   -- Unmount everything.
   g:umount_all ()
end
