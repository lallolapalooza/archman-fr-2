guestfs-release-notes - Notes de publication de libguestfs

NOTES DE PUBLICATION POUR LIBGUESTFS 1.16

Ces notes de publication ne couvrent que les différences par rapport à la branche stable/de développement précédente (1.14.0). Pour des journaux des modifications détaillés, veuillez consulter le dépôt git, ou le fichier ChangeLog distribué dans l'archive tar.

Nouvelles fonctionnalités

libguestfs

- Permet de créer des systèmes de fichiers XFS sur un système de fichiers existant
  (Wanlong Gao)
- L'alignement par défaut (non spécifié) pour part-disk a été
  modifié en 64K pour un meilleur support du stockage réseau haut de gamme
- nouvelle page de manuel guestfs-testing(1)
- list-filesystems retourne les périphériques MD contenant des systèmes de fichiers
  (Matthew Booth)
- support pour GCC >= 4.7 (Jim Meyering)
- vérifie que l'utilisateur n'ajoute pas le même disque deux fois (Wanlong Gao).

liaisons de langage

- Liaisons GObject expérimentales, avec support pour GObject
  Introspection. Vous pouvez maintenant utiliser libguestfs depuis Javascript.
  Veuillez noter qu'elles ne sont pas stables et finales dans cette version.
  (Matthew Booth).
- support pour Ruby >= 1.9
- les liaisons Ruby peuvent être désactivées individuellement (Hilko Bengen)
- support pour Python 2.6, 3.x (Richard Jones, Hilko Bengen)
- support pour PHP >= 5.4
- le nouveau hash %guestfs_introspection est disponible dans les liaisons Perl afin
  que vous puissiez interroger quels arguments optionnels sont disponibles

inspection

- les invités avec des périphériques MD peuvent être inspectés (Matthew Booth)
- support pour les invités GNU/Hurd

guestfish

- les événements libguestfs (tels que les événements de barre de progression et les messages de journal) peuvent
  être interceptés et traités par des scripts shell définis par l'utilisateur.
- les périphériques MD sont complétés par tabulation (Matthew Booth)

outils virtuels

- Nouveau outil virt-format pour effacer et créer des disques vierges
- virt-sparsify nouvelles options --compress et -o pour permettre une sortie compressée
  et dans différents formats
- virt-sparsify peut maintenant détecter et rendre plus sparse les fichiers .vdi
- virt-sysprep ne nécessite plus xmlstarlet ; une nouvelle option virt-inspector --xpath
  a été ajoutée pour remplacer cette fonctionnalité
- virt-rescue a une nouvelle option --suggest qui suggère des commandes de montage
  pour l'invité
- virt-resize ne nécessite plus la bibliothèque pcre d'OCaml

libguestfs live

- le démon n'essaiera plus de modifier votre configuration lvm /etc/lvm en direct
- correction d'un problème de sécurité potentiel avec des noms /tmp prévisibles (Steve Kemp)

Sécurité

CVE-2011-4127, RHBZ#757071
Atténuation d'une possible élévation de privilèges via l'ioctl SG_IO
Pour plus d'informations, voir : https://github.com/libguestfs/libguestfs/commit/9a5f784d511a8f00a8386f316eab41fe660430db

Nouvelles APIs

blkid: affiche tous les attributs d'un périphérique connu de blkid (Wanlong Gao)
e2fsck: accès à plus de fonctionnalités de e2fsck (Wanlong Gao)
list-md-devices: liste des périphériques MD Linux (Matthew Booth)
md-create: crée un périphérique MD
md-detail: retourne les métadonnées d'un périphérique MD (Matthew Booth)
md-stop: arrête un périphérique MD (Wanlong Gao)
tune2fs: permet d'ajuster les systèmes de fichiers ext2/3/4

Internes

L'hébergement Git a été déplacé vers http://github.com/libguestfs
Les divers répertoires de test ont été réorganisés logiquement et apparaissent
maintenant tous sous 'tests/'.
Il existe une règle 'make extra-tests' qui exécute les tests ordinaires et
des tests supplémentaires, en utilisant valgrind pour vérifier les problèmes de mémoire.
Plusieurs fuites de mémoire et autres problèmes trouvés par valgrind ont été corrigés.
Le support des arguments optionnels dans le générateur a été réécrit
pour fournir plus de fonctionnalités et de sécurité (Matthew Booth).
Avec gcc, -fvisibility=hidden est utilisé pour les symboles internes, évitant
l'indirection d'appel via le PLT.
Les fonctions RHashtable peuvent être testées dans le générateur.
La macro ADD_ARG dans le démon permet de construire des listes d'arguments sans
risque d'écrasement de pile.
Correction de la génération de fonctions OCaml ayant plus de 10 arguments.
psmisc a été ajouté à l'appliance, permettant l'utilisation de 'fuser',
'killall' et 'pstree' pour le débogage.
bindtests couvre maintenant RBufferOut et les arguments optionnels (Matthew Booth).

- 761460 guestfs_utimens se bloque sur les tubes nommés
- 761451 guestfs_utimens ne peut pas définir les heures sur un répertoire
- 760775 « guestfish: les systèmes d'exploitation multi-démarrages ne sont pas pris en charge par l'option -i » devrait être plus explicite
- 760669 guestfish copy-in et <! (exécution en ligne) ne se mélangent pas bien : pclose : Pas de processus fils
- 760000 libguestfs ne compile pas avec Ruby >= 1.9
- 755729 Le message d'erreur pour resize2fs-M doit être ajusté
- 750889 Le code Python est incompatible avec Python v3.
- 596761 Ctrl-\ provoque l'arrêt de guestfish
