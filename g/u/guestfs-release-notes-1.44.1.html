guestfs-release-notes - Notes de publication de libguestfs

NOTES DE PUBLICATION POUR LIBGUESTFS 1.44

Liaisons de langage

Le support de Python 2 a été abandonné. La version minimale de Python requise est 3.6.

Les liaisons Python n'utilisent plus "PyEval_ThreadsInitialized", qui est obsolète.

Les liaisons Python incluent désormais des indications de type (Sam Eiderman).

Les liaisons Erlang utilisent désormais libei au lieu d'liberl_interface (Sergei Golovan).

Outils

virt-get-kernel(1) peut désormais trouver des noyaux non compressés (Pino Toscano).

virt-sysprep(1) régénère désormais le magasin de certificats de l'invité lorsqu'un certificat est supprimé de l'invité (Pino Toscano).

virt-sysprep(1) peut désormais supprimer les fichiers d'inscription IPA et les keytabs Kerberos (Pino Toscano, Christian Heimes et François Cami).

API

Nouvelles API

"cryptsetup-open" et "cryptsetup-close" remplacent "luks-open", luks-open-ro et luks-close. Les nouvelles API ajoutent le support du chiffrement BitLocker.

Autres changements d'API

"lvm-canonical-lv" ne produit plus un message d'erreur bruyant lorsqu'il est appelé avec un paramètre autre qu'une LV.

Changements de compilation

Les programmes C utilisant libguestfs peuvent désormais être compilés par rapport au répertoire de construction :

../libguestfs/run ./configure
../libguestfs/run make

Les composants OCaml sont désormais correctement liés lors de la compilation dans un répertoire différent de celui de la source (Geoff Toole).

GCC LTO est désormais pris en charge.

Weblate est désormais utilisé pour la localisation au lieu de Zanata (Pino Toscano).

Les dépendances pour guestfsd ne sont plus codées en dur mais sont désormais générées à partir du binaire compilé, garantissant qu'elles ne seront pas désynchronisées à l'avenir (Hilko Bengen).

Internes

lib/guestfs.h a été déplacé vers include/guestfs.h dans la source. Ce n'est pas un changement visible de l'extérieur, mais cela a affecté de nombreux endroits dans le système de construction.

Bugs corrigés

https://bugzilla.redhat.com/1811539
La commande virt-diff ne fonctionne pas sur l'image Windows 2019
https://bugzilla.redhat.com/1384241
La commande tar-in ne permet pas de restaurer les capacités de fichier
