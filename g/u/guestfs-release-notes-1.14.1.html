NOTES DE VERSION POUR LIBGUESTFS 1.

14

Ces notes de version ne couvrent que les différences par rapport à la précédente séparation stable/dev (1.12.0). Pour les journaux de modifications détaillés, veuillez consulter le dépôt git ou le fichier ChangeLog distribué dans la

tarball.

Nouvelles

fonctionnalités 
Liaisons Erlang.
virt-alignment-scan est un nouvel outil pour vérifier l'alignement des
partitions au sein de machines virtuelles ou d'images de disque.
virt-sparsify est un nouvel outil pour rendre les images de disque de
machines virtuelles creuses (sparse).
virt-sysprep est un nouvel outil pour simplifier le clonage d'invités à
partir d'un
modèle.

guestfis

h 
- Nouvelles commandes setenv, unsetenv, pour définir des variables
  d'environnement.
- Le fichier d'entrée et le numéro de ligne sont affichés dans les
  messages d'erreur.
- Les barres de progression de guestfish sont désormais une
  « mini-bibliothèque » utilisée aussi par d'autres
outils.

guestmoun

t 
- l'option --live (pour l'accès aux VM en fonctionnement) fonctionne
désormais.

virt-ca

t 
- virt-cat peut désormais gérer les chemins Windows et les lettres de
  lecteur (RHBZ#693359)
.

virt-filesystem

s 
- le type d'octet de partition MBR est affiché dans la sortie
--long.

virt-make-f

s 
- virt-make-fs définit désormais correctement l'octet de type de
  partition MBR, améliorant la compatibilité avec Windows (RHBZ#746295)
.

virt-resiz

e 
- virt-resize peut désormais fonctionner avec des invités utilisant des
  partitions étendues et logiques, en particulier les invités Ubuntu.
- virt-resize peut désormais aligner la première partition des invités
  Windows, améliorant les performances. La nouvelle option
  virt-resize --align-first contrôle ce comportement.
- L'indicateur virt-resize --machine-readable permet d'utiliser
  virt-resize depuis d'autres programmes.
- Les partitions sont désormais alignées sur 128 secteurs (généralement
  64K) par défaut. Cela améliore l'efficacité sur les stockages haut de
  gamme. La nouvelle option virt-resize --alignment permet d'ajuster
l'alignement.

virt-win-re

g 
- La syntaxe pour supprimer des clés et des valeurs de registre est
  documentée dans la page man (RHBZ#737944)
.

bibliothèq

ue 
- les caractères non imprimibles sont correctement échappés dans la
  sortie de débogage.
- GUESTFS_EVENT_ENTER est un nouveau type d'événement généré à chaque
  fois qu'une fonction libguestfs est appelée.
- la bibliothèque contient des sondes systemtap/DTrace.
- la bibliothèque peut désormais être compilée sans hivex (RHBZ#723474)
.

inspectio

n 
- Amélioration de la détection des disques Windows.
- Ajout du support pour :
      ttylinux - un Linux minimal
      Mageia (merci à Michael Scherer)
      OpenSUSE et zypper (merci à Michael Scherer, Vincent Untz)
      les logos Ubuntu (merci à Michael Scherer)
      NetBSD et pkgsrc (merci à Michael Scherer)
- Gestion de certains types d'invités qui utilisent /dev/root dans
  /etc/fstab.
- Correction de la gestion des invités avec plus de 26 disques (merci à
  Matthew Booth)
- Ajout du support pour les invités avec des disques HP Smart Array (merci
  à Matthew
Booth)

febootstra

p

  FEBOOTSTRAP_MODULES peuvent être définies pour choisir le noyau à
  utiliser pour
l'appliance.

Nouvelles

API 
compress-out, compress-device-out, copy-device-to-device,
copy-device-to-file, copy-file-to-device, copy-file-to
-file, get-smp, part-to-partnum, set-smp. L'API de montage n'ajoute plus implicitement les options -o sync,noatim
e. add-domain a un nouveau paramètre optionnel 'readonlydisk' pour contrôler la gestion des disques <readonly/>.

Détails

internes 
- Coverity a été exécuté sur les sources et davantage de bogues ont été
  identifiés et corrigés.
- La bibliothèque PCRE est désormais requise pour compiler libguestfs.
- APIC est désormais le défaut pour l'appliance. Vous pouvez également
  activer le support SMP dans l'appliance.
- Les li
aisons OCaml acquièrent désormais correctement le verrou GC lors des rappels. - Les compilations hors de l'arbre devraient désormais fonctionner correctement (merci à Hilko Bengen). - ./configure --with-extra="..." peut être utilisé par les empaqueteurs pour définir la chaîne de vers
ion supplémentaire. - API zero, zero-device : si les blocs contiennent déjà des zéros, ne pas écrire de zéros, afin de ne pas rendre inutilement le stockage sous-jacent non creux (non sparse). - API is-zero, is-zero-device : optimisées pour que la détection des zéros soit plus rapide.
