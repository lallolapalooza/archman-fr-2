guestfs-tools-release-notes - Notes de publication des outils guestfs

NOTES DE PUBLICATION POUR GUESTFS TOOLS 1.50

Voici les notes de publication de la version stable 1.50 des outils guestfs. Elles décrivent les changements majeurs depuis la version 1.48.

Guestfs tools 1.50.0 a été publié le 7 février 2023.

Sécurité

CVE-2022-2211
https://bugzilla.redhat.com/show_bug.cgi?id=2100862

Un dépassement de tampon a été trouvé dans l'option --key de plusieurs outils guestfs. Pour plus d'informations sur ce bug de faible gravité, voir le rapport de bug ci-dessus (Laszlo Ersek).

Nouveau outil virt-drivers

Ce nouvel outil peut examiner une image disque pour déterminer :

  • Si elle utilise BIOS ou UEFI pour le démarrage
  • Quel chargeur de démarrage elle utilise (Linux uniquement)
  • Quels noyaux peuvent être choisis au démarrage (Linux uniquement)
  • Quels pilotes (modules noyau) sont installés

Ceci est utile pour déterminer comment (ou si) un invité peut démarrer sur un hyperviseur de virtualisation.

virt-customize

--selinux-relabel est maintenant le comportement par défaut pour les invités SELinux. Vous n'avez plus besoin de spécifier cet indicateur. Dans le cas rare où vous ne souhaitez pas relabéliser un invité après l'avoir personnalisé, vous pouvez utiliser --no-selinux-relabel. Notez que ce n'est pas nécessaire pour les invités non-SELinux, il fera la bonne chose automatiquement (Laszlo Ersek).

Nouvelles opérations --inject-qemu-ga et --inject-virtio-win qui injectent respectivement l'agent invité QEMU et les pilotes virtio-win dans les invités Windows.

Les invités Rocky Linux sont désormais pris en charge (merci Harry Benson).

virt-inspector

Virt-inspector génère maintenant le nouvel élément <build_id> contenant l'ID de construction de l'invité, si vous utilisez libguestfs ≥ 1.50.

virt-sysprep

Nouvelle opération "lvm-system-devices" pour supprimer le fichier system.devices de LVM2. Cela évite certains problèmes lors du clonage d'une VM (Laszlo Ersek).

Virt-sysprep prend en charge les invités utilisant des volumes logiques LUKS sur LVM (Laszlo Ersek).

Changements communs

Tous les outils prenant en charge l'option --key peuvent maintenant utiliser Clevis/Tang pour décrypter le chiffrement complet du disque en utilisant ce schéma basé sur le réseau (Laszlo Ersek).

Changements de compilation

Notez que libguestfs nécessite désormais OCaml 4.04 minimum. Il ne compilera pas sur RHEL 6.

Notez que libosinfo est une nouvelle dépendance requise.

OCaml 4.14 est maintenant pris en charge.

"./configure --disable-ocaml" et "./configure --disable-perl" désactivent maintenant respectivement les outils basés sur OCaml et Perl (merci Simon Walter).

Prise en charge expérimentale de la compilation sur macOS.

Lors de l'exécution de "make check-valgrind", les journaux Valgrind ne sont plus écrits dans des fichiers séparés sous tmp/. Au lieu de cela, la sortie est écrite dans le fichier normal test-name.log.
