NOM

guile - Le langage d'extension du projet GNU

SYNOPIS

guile [-L RÉPERTOIRE] [-l FICHIER] [-e FONCTION] [\] [-c EXPR] [-s SCRIPT] [--] [SCRIPT [ARGUMENTS pour SCRIPT]]

Seules les options les plus utiles sont listées ici ; voir ci-dessous pour le reste.

DESCRIPTION

GNU Guile est une implémentation du langage de programmation Scheme. Il étend les normes de langage R5RS et R6RS, fournissant des fonctionnalités supplémentaires nécessaires pour une utilisation dans le monde réel.

Guile fonctionne bien pour une utilisation interactive, le scripting de base, et l'extension d'applications plus importantes, ainsi que pour le développement d'applications Scheme autonomes.

L'exécutable guile lui-même fournit un compilateur et un environnement d'exécution autonomes pour les programmes Scheme, à la fois pour une utilisation interactive et pour exécuter des scripts ou des programmes Scheme.

Cette page de manuel fournit seulement des instructions brèves pour invoquer guile depuis la ligne de commande. Veuillez consulter la documentation info de Guile pour plus d'informations, (tapez info "(guile)Invoking Guile" à une invite de commande).

OPTIONS

-L RÉPERTOIRE
Ajoute RÉPERTOIRE au début du chemin de chargement des modules de Guile.
-l FICHIER
Charge le code source Scheme depuis FICHIER.
-e FONCTION
Après avoir lu SCRIPT, applique FONCTION aux arguments de la ligne de commande. Notez que FONCTION est évaluée, donc, par exemple, (@ (my-module) my-proc) est valide ici.
\
Le "méta-switch", utilisé pour contourner les limitations des scripts #!. Voir "The Meta Switch" dans la documentation texinfo pour plus de détails.
--
Arrête le traitement des arguments, et démarre guile en mode interactif.
-c EXPR
Arrête le traitement des arguments, et évalue EXPR comme une expression Scheme.
-s FICHIER-SCRIPT
Charge le code source Scheme depuis FICHIER-SCRIPT et l'exécute comme un script. Notez que dans de nombreux cas, il n'est pas nécessaire d'utiliser -s ; on peut invoquer guile simplement comme guile FICHIER-SCRIPT ARG...
-ds
Exécute -s SCRIPT à ce point de la séquence d'options. Notez que cet argument doit être utilisé en conjonction avec -s.
--debug
Démarre guile avec la machine virtuelle de débogage. Par défaut, le débogage est activé lorsque guile est invoqué interactivement ; il est désactivé sinon.
--no-debug
Démarre guile sans la machine virtuelle de débogage, même si guile est exécuté interactivement.
--auto-compile
Compile automatiquement les fichiers source (comportement par défaut).
--no-auto-compile
Désactive la compilation automatique des fichiers source.
--listen[=P]
Écoute sur un port ou une socket pour des connexions REPL distantes. Voir le manuel pour plus de détails.
--use-srfi=N,M...
Charge les extensions SRFI N, M, etc. Par exemple, --use-srfi=8,13.
-x EXTENSION
Ajoute EXTENSION à la liste des extensions de chargement de guile.
-h, --help
Décrit les options de la ligne de commande et quitte.
-v, --version
Affiche la version de guile et quitte.
-q
En mode interactif, supprime le chargement du fichier d'initialisation de l'utilisateur, ~/.guile.

ENVIRONNEMENT

GUILE_LOAD_PATH
Si $GUILE_LOAD_PATH est défini avant le démarrage de guile, sa valeur est utilisée pour augmenter le chemin de recherche des fichiers Scheme lors du chargement. Il doit s'agir d'une liste de répertoires séparés par des deux-points, qui seront ajoutés au début du chemin par défaut %load-path.
GUILE_LOAD_COMPILED_PATH
Si $GUILE_LOAD_COMPILED_PATH est défini avant le démarrage de guile, sa valeur est utilisée pour augmenter le chemin de recherche des fichiers Scheme compilés (.go) lors du chargement. Il doit s'agir d'une liste de répertoires séparés par des deux-points, qui seront ajoutés au début du chemin par défaut %load-compiled-path.

FICHIERS

~/.guile
Un script Guile qui est exécuté avant tout autre traitement. Par exemple, le .guile suivant active l'interface readline de guile :
(use-modules (ice-9 readline))
(activate-readline)

VOIR AUSSI

La documentation complète de Guile est maintenue sous forme de manuel Texinfo. Si les programmes info et guile sont correctement installés sur votre site, la commande

info guile

devrait vous donner accès au manuel complet.

http://www.schemers.org fournit une introduction générale au langage Scheme.

SIGNALER LES BOGUES

Il existe une liste de diffusion, bug-guile@gnu.org, pour signaler les bogues et les corrections de Guile. Mais avant de signaler quelque chose comme un bogue, veuillez essayer d'être sûr que c'en est vraiment un, et non une incompréhension ou une fonctionnalité délibérée. Nous vous demandons de lire la section « Reporting Bugs » du manuel de référence de Guile (ou du système Info) pour obtenir des indices sur comment et quand signaler des bogues. De plus, incluez le numéro de version de Guile que vous utilisez dans chaque rapport de bogue que vous envoyez. Les bogues ont tendance à être corrigés s'ils peuvent être isolés, il est donc dans votre intérêt de les signaler d'une manière qui permette de les reproduire facilement.
