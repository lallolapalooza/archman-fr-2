NOM

guestfs-gobject - Comment utiliser libguestfs avec les liaisons GObject

DÉPRECATION

Ces liaisons sont dépréciées et seront supprimées dans libguestfs 1.58.

SYNTAXE

Depuis Javascript avec gjs :

const Guestfs = imports.gi.Guestfs;
var g = new Guestfs.Session();
g.add_drive('disk.img', null);
g.launch();
g.close();

DESCRIPTION

Cette page de manuel documente comment appeler libguestfs en utilisant les liaisons GObject, particulièrement depuis Javascript.

Notez que les liaisons GObject ont des problèmes pour gérer les valeurs 64 bits. Vous ne devriez pas utiliser les liaisons GObject s'il existe des liaisons natives pour votre langage. Par exemple, pour utiliser libguestfs depuis Python, il est fortement conseillé d'utiliser les liaisons natives Python à la place (voir guestfs-python(3)).

Cette page documente uniquement les différences par rapport à l'API C et donne quelques exemples. Si vous n'êtes pas familier avec l'utilisation de libguestfs, vous devez également lire guestfs(3).

JAVASCRIPT

En utilisant gjs, vous pouvez écrire un fichier ".js" contenant :

const Guestfs = imports.gi.Guestfs;
var g = new Guestfs.Session();
g.add_drive('disk.img', null);
g.launch();
g.close();

et ensuite l'exécuter en utilisant :

gjs program.js

Lorsque vous signalez un bogue, veuillez fournir :

  • Où vous avez obtenu libguestfs (par ex. quelle distribution Linux, compilé à partir des sources, etc.).
  • Décrivez le bogue avec précision et donnez un moyen de le reproduire.
  • Exécutez libguestfs-test-tool(1) et collez la sortie complète et non modifiée dans le rapport de bogue.
