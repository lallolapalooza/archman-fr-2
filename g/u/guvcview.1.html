GUVCVIEW(1) Manuel des commandes générales GUVCVIEW(1)

NOM

guvcview - Visionneuse UVC basée sur GTK+

SYNTAXE

guvcview

DESCRIPTION

Guvcview est une application pour capturer et visionner des vidéos depuis des périphériques supportés par l'interface video4linux2 du noyau Linux.

UTILISATION

guvcview [options...]

OPTIONS

-h,--help
Afficher l'aide
-v,--version
Afficher la version
-w,--verbosity=NIVEAU
Définir le niveau de verbosité (défaut : 0)
-d,--device=PÉRIPH_AUDIO
Définir le nom du périphérique (défaut : /dev/video0)
-c,--capture=MÉTHODE
Définir la méthode de capture [read | mmap (défaut)]
-b,--disable_libv4l2
Désactiver les appels à libv4l2
-x,--resolution=LARGEURxHAUTEUR
Demander une résolution (par ex. 640x480)
-f,--format=FOURCC
Demander un format (par ex. MJPG)
-F,--fps=FPS_NUM[/FPS_DENOM]
Demander les images par seconde (par ex. 25 ; 7/3 ; ...)
-r,--render=API_RENDU
Sélectionner l'API de rendu (par ex. none; sdl; sfml)
-m,--render_window=INDICATEURS_FENÊTRE_RENDU
Définir les indicateurs de la fenêtre de rendu (par ex. none; full; max; LARGEURxHAUTEUR)
-a,--audio=API_AUDIO
Sélectionner l'API audio (par ex. none; port; pulse)
-k,--audio_device=PÉRIPH_AUDIO
Sélectionner l'index du périphérique audio pour l'API sélectionnée (0..N)
-g,--gui=API_GUI
Sélectionner l'API GUI (par ex. none; gtk3; qt6)
-o,--audio_codec=codecAudio
Codec audio [pcm mp2 mp3 aac ac3 vorb]
-u,--video_codec=codec
Codec vidéo [raw mjpg mpeg flv1 wmv1 mpg2 mp43
dx50 h264 vp80 theo]
-p,--profile=nom_de_fichier
Charger le profil de contrôle
-j,--video=nom_de_fichier
Nom de fichier pour la vidéo capturée)
-i,--image=nom_de_fichier
Nom de fichier pour l'image capturée)
-y,--video_timer=TEMPS_EN_SEC
Temps (double) en secondes pour la capture vidéo)
-t,--photo_timer=TEMPS_EN_SEC
Temps (double) en secondes entre les photos capturées)
-n,--photo_total=total
Nombre total de photos capturées)
-e,--exit_on_term
Quitter l'application après la fin de la capture vidéo ou d'image
-z,--control_panel
Démarrer en mode panneau de contrôle
