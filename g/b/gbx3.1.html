NOM

gbx3 - Interpréteur GAMBAS

SYNTAXE

gbx3 [options] [<répertoire de projet>] [-- <arguments>]
gbx3 -e <expression>

DESCRIPTION

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec des extensions objet, un mélange de Java(tm) et Visual Basic(tm). Avec Gambas, vous pouvez rapidement concevoir l'interface graphique de votre programme avec Qt ou GTK+, accéder aux systèmes de bases de données comme MySQL, PostgreSQL, SQlite ou ODBC, piloter des applications avec DBus, traduire votre programme dans de nombreuses langues, créer des applications GStreamer, OpenGL ou SDL, et ainsi de suite...

gbx3 est l'interpréteur qui vous permet d'exécuter un projet Gambas ou d'évaluer une expression Gambas (option -e).

OPTIONS

-a <chemin>
remplace le chemin de l'application
-e
évalue une expression
-g
entre en mode débogage
-h, --help
affiche l'aide et quitte
-H, --httpd
exécute via un serveur http intégré
-j
désactive le compilateur juste-à-temps
-k
ne décharge pas les bibliothèques partagées
-L, --license
affiche la licence
-p <chemin>
active le mode profilage et débogage
-r <chemin>
redirige la sortie d'erreur standard
-s <classe>
remplace la classe de démarrage
-t, --trace
affiche la position de chaque ligne de code exécutée
-T
liste tous les modules de test
-T <tests>
exécute les modules de test spécifiés
-V, --version
affiche la version

VARIABLES D'ENVIRONNEMENT

GB_DB_DEBUG
Mis à "1" pour activer le débogage du composant base de données.
GB_GUI
Définit le composant GUI qui sera chargé par la famille de composants 'gb.gui*'.
GB_GUI_DARK_THEME
Mis à "1" pour forcer le comportement de thème sombre.
GB_GUI_PLATFORM
Définit la plateforme graphique utilisée par les composants GUI. Peut être "x11" ou "wayland".
GB_HTTPD_DEBUG
Mis à "1" pour activer le mode de débogage du serveur web intégré.
GB_HTTPD_HOST
Définit le nom d'hôte utilisé par le serveur web intégré.
GB_HTTPD_PORT
Définit le port utilisé par le serveur web intégré.
GB_HTTPD_TIMEOUT
Définit le délai d'attente des requêtes du serveur web intégré.
GB_JIT_CACHE
Mis à "0" pour utiliser l'ancien processus de compilation qui n'utilise pas de mise en cache.
GB_JIT_CC
Définit le compilateur utilisé par le composant juste-à-temps. "gcc" ou "clang" sont supportés pour le moment.
GB_JIT_CFLAGS
Définit les indicateurs de compilation utilisés pour générer du code juste-à-temps.
GB_JIT_DEBUG
Mis à "1" pour activer le débogage du compilateur juste-à-temps.
GB_JIT_ENABLED
Mis à "0" pour désactiver le compilateur juste-à-temps.
GB_JIT_FORCE
Mis à "1" pour ignorer le cache et forcer une nouvelle compilation du code juste-à-temps.
GB_JIT_TRACE
Mis à "1" pour afficher chaque ligne exécutée par le code compilé juste-à-temps.
GB_MEDIA_DEBUG
Mis à "1" pour activer le débogage du composant 'gb.media'.
GB_NO_JIT
Mis à "1" pour désactiver le compilateur juste-à-temps.
GB_REVERSE
Mis à "1" pour inverser la direction de la langue.
GB_STOCK_DEBUG
Mis à "1" pour activer le débogage du thème d'icônes.
GB_WEB_GUI_DEBUG
Mis à "1" pour activer le débogage du composant 'gb.web.gui'.

DISPONIBILITÉ

La dernière version de Gambas est toujours disponible sur gambas.sourceforge.net, la documentation sur le langage se trouve sur http://gambaswiki.org/wiki.
