NOM

gba3 - Archiver GAMBAS

SYNTAXE

gba3 [options] [<répertoire de projet>]
gba3 -x <chemin d'archive> <fichier>

DESCRIPTION

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec des extensions objet, un mélange de Java(tm) et de Visual Basic(tm). Avec Gambas, vous pouvez rapidement concevoir l'interface graphique de votre programme avec Qt ou GTK+, accéder à des systèmes de bases de données comme MySQL, PostgreSQL, SQLite ou ODBC, piloter des applications avec DBus, traduire votre programme dans de nombreuses langues, créer des applications GStreamer, OpenGL ou SDL, et ainsi de suite...

gba3 est l'archiveur qui vous permet de créer un exécutable autonome en un seul fichier à partir d'un projet Gambas ou d'extraire un fichier spécifique d'un exécutable Gambas (option -x).

OPTIONS

-h, --help
affiche l'aide et quitte
-i, --ignore=CHEMIN
exclut un fichier ou un répertoire spécifique
-l, --list=ARCHIVE
liste les fichiers d'archive
-L, --license
affiche la licence
-o, --output=ARCHIVE
chemin de l'archive [<répertoire de projet>/<nom du projet>.gambas]
-p, --ignore-public
exclut le répertoire '.public'
-s, --swap
échange l'endianisme
-x, --extract=ARCHIVE
chemin de l'archive
-v, --verbose
sortie détaillée
-V, --version
affiche la version

DISPONIBILITÉ

La dernière version de Gambas est toujours disponible sur gambas.sourceforge.net. La documentation sur le langage se trouve sur http://gambaswiki.org/wiki.
