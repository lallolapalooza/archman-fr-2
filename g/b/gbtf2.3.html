sous-routine cgbtf2 (integer m, integer n, integer kl, integer ku, complex, dimension( ldab, * ) ab, integer ldab, integer, dimension( * ) ipiv, integer info)

CGBTF2 calcule la factorisation LU d'une matrice bande générale en utilisant la version non bloquée de l'algorithme.

Objectif :

!>
!> CGBTF2 calcule une factorisation LU d'une matrice bande complexe m par n
!> A en utilisant le pivotage partiel avec échanges de lignes.
!>
!> Ceci est la version non bloquée de l'algorithme, appelant les BLAS de niveau 2.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

KL

!>          KL est un ENTIER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est un ENTIER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est un tableau COMPLEXE, de dimension (LDAB,N)
!>          À l'entrée, la matrice A en stockage bande, dans les lignes KL+1 à
!>          2*KL+KU+1 ; les lignes 1 à KL du tableau n'ont pas besoin d'être
!>          définies.
!>          La j-ième colonne de A est stockée dans la j-ième colonne du
!>          tableau AB comme suit :
!>          AB(kl+ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(m,j+kl)
!>
!>          À la sortie, détails de la factorisation : U est stockée comme une
!>          matrice bande triangulaire supérieure avec KL+KU super-diagonales dans
!>          les lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant la
!>          factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>          Voir ci-dessous pour plus de détails.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimension (min(M,N))
!>          Les indices de pivot ; pour 1 <= i <= min(M,N), la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = +i, U(i,i) est exactement zéro. La factorisation
!>               a été complétée, mais le facteur U est exactement
!>               singulier, et une division par zéro se produira s'il est utilisé
!>               pour résoudre un système d'équations.
!>

Détails supplémentaires :

!>
!>  Le schéma de stockage bande est illustré par l'exemple suivant, quand
!>  M = N = 6, KL = 2, KU = 1 :
!>
!>  À l'entrée :                       À la sortie :
!>
!>      *    *    *    +    +    +       *    *    *   u14  u25  u36
!>      *    *    +    +    +    +       *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
!>     a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
!>     a21  a32  a43  a54  a65   *      m21  m32  m43  m54  m65   *
!>     a31  a42  a53  a64   *    *      m31  m42  m53  m64   *    *
!>
!>  Les éléments de tableau marqués * ne sont pas utilisés par la sous-routine ;
!>  les éléments marqués + n'ont pas besoin d'être définis à l'entrée, mais
!>  sont requis par la sous-routine pour stocker des éléments de U, en raison
!>  du remplissage résultant des échanges de lignes.
!>
