DESCRIPTIO

N

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec des extensions objet, un mélange de Java(tm) et de Visual Basic(tm). Avec Gambas, vous pouvez concevoir rapidement l'interface graphique de votre programme avec Qt ou GTK+, accéder à des systèmes de bases de données comme MySQL, PostgreSQL, SQlite ou des bases de données ODBC, piloter des applications avec DBus, traduire votre programme en plusieurs langues, créer des applications GStreamer, OpenGL ou SDL, et bien plus encore..

.

gbs3 est l'interpréteur qui vous permet de compiler et d'exécuter un script Gambas.
gbs3 peut également être utilisé pour convertir un

projet Gambas en scri
pt ou un script en projet.

gbs3 peut convertir un projet Gambas en fichier script exécutable à l'aide de l'option --convert-project. Le répertoire du projet d'entrée est utilisé pour créer le script qui est écrit dans le répertoire de script de sortie. Le script est créé et nommé de la même manière que le projet d'origine.

CONVERSION DE

SCRIPT

gbs3 peut convertir un fichier script en projet Gambas complet à l'aide de l'option --convert-script.
Le script d'entrée est traduit en projet portant le même nom de base que le script et est créé dans le répertoire spécifié. Si aucun répertoire de sortie n'est spécifié, la variable d'environnement PWD est utilisée comme emplacement pour créer le projet Gambas.
gbs3 MonScript.gbs ~/Projets
Cela a créé le répertoire de proj

et 'MonScript' dans le répertoir
e 'Projets' de l'utilisateur.

PLUGIN

S

gbs3 peut créer des plugins qui peuvent être utilisés par d'autres scripts ou applications Gambas après avoir été construits à l'aide de l'option --plugin ou -p. Les plugins sont créés dans un répertoire choisi par l'utilisateur et sont également exécutés et mis en cache dans ce répertoire, contrairement à un script normal, où les exécutables sont créés dans le répertoire temporaire et exécutés depuis celui-ci. Cela permet aux plugins de persister après la sortie du scripteur.
Si aucune destination de sortie n'est spécifiée, le plugin est créé dans le répertoire ~/.local/lib/gambas et peut être chargé depuis là-bas à l'aide de la fonction component.load().
gbs3 MonScriptPlugin [Réperto

ire de destinat
ion du plugin]
