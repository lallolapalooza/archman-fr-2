NOM

gbs3 - Interpréteur de scripts GAMBAS

SYNTAXE

gbs3 [options] [--] [<fichier de script> | -]
gbs3 --convert-project <répertoire projet source> <répertoire script destination>

DESCRIPTION

DESCRIPTION

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec des extensions orientées objet, un mélange de Java(tm) et Visual Basic(tm). Avec Gambas, vous pouvez rapidement concevoir l'interface graphique de votre programme avec Qt ou GTK+, accéder à des systèmes de bases de données tels que MySQL, PostgreSQL, SQlite ou ODBC, piloter des applications avec DBus, traduire votre programme en plusieurs langues, créer des applications GStreamer, OpenGL ou SDL, et ainsi de suite...

gbs3 est l'interpréteur qui vous permet de compiler et d'exécuter un script Gambas.
gbs3 peut également être utilisé pour convertir un projet gambas en script

OPTIONS

-b, --buildonly
traiter et compiler le script sans l'exécuter
-c, --nocache
forcer la compilation du script (ne pas vérifier le cache)
-e
exécuter le code source fourni sur la ligne de commande (séparateur ':' )
-f, --fast
utiliser le compilateur juste-à-temps TP -g, --debug ajouter des informations de débogage à l'application
-h, --help
afficher l'aide et quitter
-l, --list
afficher une liste des Composants ou Bibliothèques disponibles, '-l composant' ou '-l bibliothèque'
-L, --license
afficher la licence
-S --strict
échouer si 'Public' ou 'Sub' sont définis sans fonction 'main', sinon créer main()
-t, --trace
activer l'option de traçage pendant l'exécution
-T, --terse
n'afficher qu'un rapport d'erreur très concis en cas d'erreurs de compilation
-u, --use
charger des composants ou des bibliothèques ('comp1,comp2,lib1...')
-v, --verbose
être verbeux
-V, --version
afficher la version
-w, --warnings
afficher les avertissements pendant la compilation
--convert-project
convertir un projet simple en script

CONVERSION DE PROJET

gbs3 peut convertir un projet gambas en fichier script exécutable en utilisant l'option --convert-project.
Le répertoire du projet d'entrée est utilisé pour créer le script qui est écrit dans le répertoire de scripts de sortie.
Le script est créé et nommé de la même manière que le projet d'origine.

gbs3 MonRépertoireProjet MonRépertoireScriptDestination

EXEMPLE

#!/usr/bin/env gbs3
for i as integer = 0 to 10
print i;;
next
