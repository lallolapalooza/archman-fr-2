NOM

gbase - définit la valeur de base d'un graphe source

SYNTAXE

gbase [options] bval [igfile] [ogfile]

DESCRIPTION

Le programme gbase permet de définir à bval la valeur de base d'un graphe source, c'est-à-dire l'indice de départ utilisé pour numéroter ses sommets et ses arêtes. La valeur de base peut être définie à 0 ou 1, de sorte que les graphes puissent être facilement importés depuis et/ou exportés vers des outils écrits en C ou en Fortran. Scotch peut gérer des graphes indépendamment de leur valeur de base.

Lorsque les bibliothèques appropriées ont été incluses lors de la compilation, gbase peut directement gérer des graphes compressés, tant en entrée qu'en sortie. Un flux est considéré comme compressé chaque fois que son nom est suivi d'une extension de fichier compressé, comme dans 'brol.grf.bz2' ou '-.gz'. Les formats de compression qui peuvent être pris en charge sont le format bzip2 ('.bz2'), le format gzip ('.gz') et le format lzma ('.lzma').

OPTIONS

-h
Affiche une aide.
-V
Affiche la version du programme et le copyright.

EXEMPLE

Définit la base du graphe 'brol.grf' à 1, et écrit le graphe modifié dans le fichier 'brol_b1.grf'.

    $ gbase 1 brol.grf brol_b1.grf
