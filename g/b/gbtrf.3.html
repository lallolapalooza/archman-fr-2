CGBTR

F

But

: 
!>
!> CGBTRF calcule une factorisation LU d'une matrice bande complexe m par n A
!> en utilisant le pivotage partiel avec échanges de lignes.
!>
!> Il s'agit de la version par blocs de l'algorithme, faisant appel aux BLAS de niveau 3.
!
>

Paramètre

s
M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!
>

K

L 
!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!
>

K

U 
!>          KU est INTEGER
!>          Le nombre de sur-diagonales dans la bande de A.  KU >= 0.
!
>

A

B 
!>          AB est un tableau COMPLEX, dimension (LDAB,N)
!>          À l'entrée, la matrice A en stockage bande, dans les lignes KL+1 à
!>          2*KL+KU+1 ; les lignes 1 à KL du tableau n'ont pas besoin d'être définies.
!>          La j-ième colonne de A est stockée dans la j-ième colonne du
!>          tableau AB comme suit :
!>          AB(kl+ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(m,j+kl)
!>
!>          À la sortie, détails de la factorisation : U est stockée comme une
!>          matrice bande triangulaire supérieure avec KL+KU sur-diagonales dans
!>          les lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant la
!>          factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>          Voir ci-dessous pour plus de détails.
!
>

LDA

B 
!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (min(M,N))
!>          Les indices de pivot ; pour 1 <= i <= min(M,N), la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = +i, U(i,i) est exactement nul. La factorisation
!>               a été complétée, mais le facteur U est exactement
!>               singulier, et une division par zéro se produira s'il est utilisé
!>               pour résoudre un système d'équations.
!
>

NAME

sgbtrf, zgbtrf — LU factorization for a general band matrix

SYNOPSIS

      SUBROUTINE SGBTRF(M, N, KL, KU, AB, LDAB, IPIV, INFO)
          INTEGER M, N, KL, KU, LDAB, INFO
          REAL AB(LDAB,*)
          INTEGER IPIV(*)

      SUBROUTINE ZGBTRF(M, N, KL, KU, AB, LDAB, IPIV, INFO)
          INTEGER M, N, KL, KU, LDAB, INFO
          COMPLEX*16 AB(LDAB,*)
          INTEGER IPIV(*)

Detailed Description

Purpose:

!>
!> SGBTRF et ZGBTRF calculent une factorisation LU d'une matrice bande réelle
!> (SGBTRF) ou complexe (ZGBTRF) de taille m x n, A, à l'aide du pivotage partiel
!> avec échanges de lignes.
!>
!> Il s'agit de la version bloquée de l'algorithme, utilisant les routines BLAS de
!> niveau 3.
!>

subroutine sgbtrf (integer m, integer n, integer kl, integer ku, real, dimension( ldab, * ) ab, integer ldab, integer, dimension( * ) ipiv, integer info)

SGBTRF

Purpose:

!>
!> SGBTRF calcule une factorisation LU d'une matrice bande réelle m x n, A,
!> à l'aide du pivotage partiel avec échanges de lignes.
!>
!> Il s'agit de la version bloquée de l'algorithme, appelant le BLAS de niveau 3.
!>

Paramètres

M 
!>          M est un entier (INTEGER).
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier (INTEGER).
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

KL

!>          KL est un entier (INTEGER).
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est un entier (INTEGER).
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est un tableau de réels (REAL), de dimension (LDAB, N).
!>          À l'entrée, la matrice A est stockée en bande, dans les lignes KL+1 à
!>          2*KL+KU+1; les lignes 1 à KL du tableau n'ont pas besoin d'être initialisées.
!>          La j-ième colonne de A est stockée dans la j-ième colonne du
!>          tableau AB comme suit :
!>          AB(kl+ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(m,j+kl)
!>
!>          À la sortie, les détails de la factorisation : U est stockée comme une
!>          matrice bande triangulaire supérieure avec KL+KU super-diagonales dans
!>          les lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant la
!>          factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>          Voir ci-dessous pour plus de détails.
!>

LDAB

!>          LDAB est un entier (INTEGER).
!>          La dimension de tête du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau d'entiers (INTEGER), de dimension (min(M,N)).
!>          Les indices de pivot ; pour 1 <= i <= min(M,N), la i-ème ligne de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

INFO

!>          INFO est un entier (INTEGER).
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = +i, U(i,i) est exactement zéro. La factorisation
!>               a été complétée, mais le facteur U est exactement
!>               singulier, et une division par zéro se produira si elle est utilisée
!>               pour résoudre un système d'équations.
!>
