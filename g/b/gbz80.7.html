NOM

gbz80 — Référence des codes d'opération du CPU

DESCRIPTION

Ceci est la liste des codes d'opération supportés par rgbasm(1), incluant une brève description, le nombre d'octets nécessaires pour les coder et le nombre de cycles CPU à 1 MHz (ou 2 MHz en mode double vitesse GBC) nécessaires pour les compléter.

Remarque : Toutes les instructions arithmétiques et logiques qui utilisent le registre A comme destination peuvent omettre la destination, car elle est supposée être le registre A par défaut. Les deux lignes suivantes ont donc le même effet :

OR A,B
OR B

De plus, l'instruction CPL peut prendre une destination optionnelle A, car il ne peut s'agir que du registre A. Les deux lignes suivantes ont donc le même effet :

CPL
CPL A

LEGENDE

Liste des abréviations utilisées dans ce document.

N'importe lequel des registres 8 bits (A, B, C, D, E, H, L).
r16
N'importe lequel des registres généraux 16 bits (BC, DE, HL).
n8
Constante entière 8 bits (signée ou non signée, de -128 à 255).
n16
Constante entière 16 bits (signée ou non signée, de -32768 à 65535).
e8
Décalage signé 8 bits (de -128 à 127).
u3
Indice de bit non signé 3 bits (de 0 à 7, avec 0 comme bit de poids faible).
cc
Un code de condition :
Z
Exécuter si Z est défini.
NZ
Exécuter si Z n'est pas défini.
C
Exécuter si C est défini.
NC
Exécuter si C n'est pas défini.
vec
Un vecteur RST (0x00, 0x08, 0x10, 0x18, 0x20, 0x28, 0x30 et 0x38).

DAA

Ajustement décimal de l'accumulateur.

Conçu pour être utilisé après l'exécution d'une instruction arithmétique (ADD, ADC, SUB, SBC) dont les entrées étaient en code décimal binaire (BCD), ajustant le résultat pour qu'il soit également en BCD.

Le comportement exact de cette instruction dépend de l'état du drapeau de soustraction N:

Si le drapeau de soustraction N est défini :
  1. Initialiser l'ajustement à 0.
  2. Si le drapeau de demi-carry H est défini, alors ajouter $6 à l'ajustement.
  3. Si le drapeau de retenue est défini, alors ajouter $60 à l'ajustement.
  4. Soustraire l'ajustement de A.
Si le drapeau de soustraction N n'est pas défini :
  1. Initialiser l'ajustement à 0.
  2. Si le drapeau de demi-carry H est défini ou A & $F > $9, alors ajouter $6 à l'ajustement.
  3. Si le drapeau de retenue est défini ou A > $99, alors ajouter $60 à l'ajustement et définir le drapeau de retenue.
  4. Ajouter l'ajustement à A.

HALT

Passe le CPU en mode de faible consommation jusqu'à ce qu'une interruption se produise.

Le comportement exact de cette instruction dépend de l'état du drapeau IME et de la présence d'interruptions en attente (c'est-à-dire si «[IE] & [IF]» est non nul) :

Si le drapeau IME est défini :
Le CPU entre en mode de faible consommation jusqu'à ce que après qu'une interruption soit sur le point d'être traitée. Le gestionnaire est exécuté normalement, et le CPU reprend l'exécution après le HALT lorsque celui-ci se termine.
Si le drapeau IME n'est pas défini, et qu'aucune interruption n'est en attente :
Dès qu'une interruption est en attente, le CPU reprend l'exécution. C'est comme ci-dessus, sauf que le gestionnaire n'est pas appelé.
Si le drapeau IME n'est pas défini, et qu'une interruption est en attente :
Le CPU continue l'exécution après le HALT, mais l'octet suivant est lu deux fois de suite (PC n'est pas incrémenté, en raison d'un bug matériel).
