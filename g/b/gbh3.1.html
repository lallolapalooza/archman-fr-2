NOM

gbh3 - Extracteur d'aide GAMBAS

SYNTAXE

gbh3 [options] [<sources>]

DESCRIPTION

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec des extensions objet, un mélange de Java(tm) et Visual Basic(tm). Avec Gambas, vous pouvez rapidement concevoir l'interface graphique de votre programme avec Qt ou GTK+, accéder à des systèmes de bases de données comme MySQL, PostgreSQL, SQlite ou ODBC, piloter des applications avec DBus, traduire votre programme dans de nombreuses langues, créer des applications GStreamer, OpenGL ou SDL, et ainsi de suite...

gbh3 est utilisé pour extraire la documentation Gambas des fichiers sources C/C++ et créer des fichiers .help pour un composant à partir de ceux-ci.

OPTIONS

-r, --root <racine>
donne le répertoire d'installation de Gambas
-c, --component <composant>
génère l'aide directement dans un fichier '*.help' de composant
-v, --verbose
exécute en mode verbeux
-V, --version
affiche la version
-L, --license
affiche la licence
-h, --help
affiche l'aide et quitte

DISPONIBILITÉ

La dernière version de Gambas peut toujours être obtenue sur gambas.sourceforge.net, la documentation sur le langage se trouve sur http://gambaswiki.org/wiki.

Signaler les bogues sur http://gambaswiki.org/bugtracker
