Documentation de la fonction

sous-routine cgbbrd (character vect, integer m, integer n, integer ncc, integer kl, integer ku, complex, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldpt, * ) pt, integer ldpt, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CGBBRD

Objectif:

!>
!> CGBBRD réduit une matrice bande complexe générale m par n, A, en une forme
!> bidiagonale réelle supérieure B par une transformation unitaire : Q**H * A * P = B.
!>
!> La routine calcule B, et éventuellement forme Q ou P**H, ou calcule
!> Q**H*C pour une matrice C donnée.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          Spécifie si les matrices Q et P**H doivent être formées ou non.
!>          = 'N' : ne forme ni Q ni P**H ;
!>          = 'Q' : forme Q seulement ;
!>          = 'P' : forme P**H seulement ;
!>          = 'B' : forme les deux.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NCC

!>          NCC est INTEGER
!>          Le nombre de colonnes de la matrice C.  NCC >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales de la matrice A. KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales de la matrice A. KU >= 0.
!>

AB

!>          AB est un tableau COMPLEX de dimension (LDAB,N)
!>          À l'entrée, la matrice bande A, m par n, stockée dans les lignes 1 à
!>          KL+KU+1. La j-ème colonne de A est stockée dans la j-ème colonne du
!>          tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(m,j+kl).
!>          À la sortie, A est écrasée par les valeurs générées pendant la
!>          réduction.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension de tête du tableau A. LDAB >= KL+KU+1.
!>

D

!>          D est un tableau REAL de dimension (min(M,N))
!>          Les éléments diagonaux de la matrice bidiagonale B.
!>

E

!>          E est un tableau REAL de dimension (min(M,N)-1)
!>          Les éléments superdiagonaux de la matrice bidiagonale B.
!>

Q

!>          Q est un tableau COMPLEX de dimension (LDQ,M)
!>          Si VECT = 'Q' ou 'B', la matrice unitaire Q de taille m x m.
!>          Si VECT = 'N' ou 'P', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension de tête du tableau Q.
!>          LDQ >= max(1,M) si VECT = 'Q' ou 'B' ; LDQ >= 1 sinon.
!>

PT

!>          PT est un tableau COMPLEX de dimension (LDPT,N)
!>          Si VECT = 'P' ou 'B', la matrice unitaire P' de taille n x n.
!>          Si VECT = 'N' ou 'Q', le tableau PT n'est pas référencé.
!>

LDPT

!>          LDPT est INTEGER
!>          La dimension de tête du tableau PT.
!>          LDPT >= max(1,N) si VECT = 'P' ou 'B' ; LDPT >= 1 sinon.
!>

C

!>          C est un tableau COMPLEX de dimension (LDC,NCC)
!>          À l'entrée, une matrice C de taille m x ncc.
!>          À la sortie, C est écrasée par Q**H*C.
!>          C n'est pas référencée si NCC = 0.
!>

LDC

!>          LDC est INTEGER
!>          La dimension de tête du tableau C.
!>          LDC >= max(1,M) si NCC > 0 ; LDC >= 1 si NCC = 0.
!>

WORK

!>          WORK est un tableau COMPLEX de dimension (max(M,N))
!>

RWORK

!>          RWORK est un tableau REAL de dimension (max(M,N))
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
