NOM

gbc3 - Compilateur GAMBAS

SYNOPSIS

gbc3 [options] [<répertoire du projet>]

DESCRIPTION

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec extensions objet, un mélange de Java(tm) et Visual Basic(tm). Avec Gambas, vous pouvez rapidement concevoir l'interface graphique de votre programme avec Qt ou GTK+, accéder aux systèmes de bases de données comme MySQL, PostgreSQL, SQLite ou ODBC, piloter des applications avec DBus, traduire votre programme en plusieurs langues, créer des applications GStreamer, OpenGL ou SDL, et ainsi de suite...

gbc3 est le compilateur qui vous permet de compiler des projets Gambas en bytecode indépendant de l'architecture.

OPTIONS

-a, --all
compiler tout
-b, --bytecode-version
forcer une version spécifique du bytecode
-d, --output-desc
sortir les fichiers de description de classe pour l'IDE
-e, --translate-errors
afficher les messages d'erreur traduisibles
-F, --form <fichier de formulaire>
convertir un fichier de formulaire en code et l'afficher
-g, --debug
ajouter des informations de débogage
-h, --help
afficher l'aide et quitter
-j, --jobs <nombre>
nombre de tâches en arrière-plan (défaut : <nombre de cœurs de CPU>)
-L, --license
afficher la licence
-n, --default-namespace <espace de noms>
espace de noms par défaut pour les classes exportées
-q --quiet
ne rien afficher si la compilation réussit
-r, --root <répertoire>
donne le répertoire d'installation de gambas
-s, --swap
inverser l'endianness
-t, --translate
sortir les fichiers de traduction
-v, --verbose
sortie verbeuse
-V, --version
afficher la version
-w, --warnings
afficher les avertissements
-x, --exec
définir la constante du préprocesseur 'Exec'

INDICATEURS DU COMPILATEUR

-f check-prefix
vérifier le préfixe des variables si les avertissements sont activés
-f public-module
les symboles de module sont publics par défaut
-f public-control
les contrôles de formulaire sont publics

DISPONIBILITÉ

La dernière version de Gambas peut toujours être obtenue sur gambas.sourceforge.net, la documentation sur le langage est à http://gambaswiki.org/wiki.
