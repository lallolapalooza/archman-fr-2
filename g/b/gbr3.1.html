NOM

gbr3 - Interpréteur GAMBAS

SYNTAXE

gbr3 [options] <fichier exécutable> [<arguments>]

DESCRIPTION

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec des extensions objet, un mélange de Java(tm) et Visual Basic(tm). Avec Gambas, vous pouvez rapidement concevoir l'interface graphique de votre programme avec Qt ou GTK+, accéder à des systèmes de bases de données comme MySQL, PostgreSQL, SQlite ou ODBC, piloter des applications avec DBus, traduire votre programme dans de nombreuses langues, créer des applications GStreamer, OpenGL ou SDL, et bien plus encore...

gbr3 est l'interpréteur qui vous permet d'exécuter un exécutable Gambas.

OPTIONS

-a <chemin>
remplacer le chemin de l'application
-g
entrer en mode débogage
-h, --help
afficher l'aide et quitter
-H, --httpd
exécuter via un serveur http intégré
-j
désactiver le compilateur juste-à-temps
-k
ne pas décharger les bibliothèques partagées
-L, --license
afficher la licence
-p <chemin>
activer le mode de profilage et de débogage
-r <chemin>
rediriger la sortie d'erreur standard
-s <classe>
remplacer la classe de démarrage
-t, --trace
afficher la position de chaque ligne de code exécutée
-T
lister tous les modules de test
-T <tests>
exécuter les modules de test spécifiés
-V, --version
afficher la version

DISPONIBILITÉ

La dernière version de Gambas peut toujours être obtenue sur gambas.sourceforge.net, la documentation sur le langage se trouve sur www.gambasdoc.org.
