NOM

g-ir-compiler - Compilateur de typelib

SYNTAXE

g-ir-compiler [OPTION...] FICHIER_GIR

DESCRIPTION

g-ir-compiler convertit un ou plusieurs fichiers GIR en un ou plusieurs typelibs. La sortie sera écrite sur la sortie standard sauf si l'option --output est spécifiée.

OPTIONS

--help
Afficher les options d'aide
--output=NOMFICHIER
Enregistrer la sortie résultante dans NOMFICHIER.
--verbose
Afficher les messages verbeux
--debug
Afficher les messages de débogage
--includedir=RÉPERTOIRE
Ajoute un répertoire qui sera utilisé pour trouver les inclusions dans le format GIR.
--module=MODULE
À CORRIGER
--shared-library=NOMFICHIER
Spécifie la bibliothèque partagée où les symboles du typelib peuvent être trouvés. Le nom de la bibliothèque ne doit pas contenir le suffixe de bibliothèque partagée.
--version
Afficher le numéro de version du programme et quitter

BOGUES

Signaler les bogues à https://gitlab.gnome.org/GNOME/gobject-introspection/issues
