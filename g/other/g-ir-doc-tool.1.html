NOM

g-ir-doc-tool - Générateur de documentation

SYNTAXE

g-ir-doc-tool [OPTION...] FICHIER GIR

DESCRIPTION

g-ir-doc-tool génère la documentation de bibliothèques directement à partir des fichiers .gir. La sortie est ajustée en fonction de la langue de programmation pour laquelle vous générez la documentation.

OPTIONS

--help
Affiche les options d'aide
--output=RÉPERTOIRE
Enregistre la sortie résultante dans RÉPERTOIRE.
--format=FORMAT
Format de sortie. Un parmi devdocs, mallard ou sections.
--language=LANGUE
Langue de sortie. Un parmi c, python, ou gjs.
--add-include-path=RÉPERTOIRE
Ajoute un répertoire qui sera utilisé pour trouver les inclusions dans le format GIR.
--version
Affiche le numéro de version du programme et quitte
--write-sections-file
Équivalent rétrocompatible à -f sections.

BOGUES

Signalez les bogues à https://gitlab.gnome.org/GNOME/gobject-introspection/issues
