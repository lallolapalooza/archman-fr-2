NOM

gv_guile - manipulation de graphes en guile

SYNTAXE

(load-extension "./libgv.so" "SWIG_init")

UTILISATION

INTRODUCTION

gv_guile est une extension chargée dynamiquement pour guile qui fournit un accès aux fonctionnalités de graphes de graphviz.

COMMANDES

Nouveaux graphes

Nouveau graphe vide

handle_graphe gv.graph (nom);
handle_graphe gv.digraph (nom);
handle_graphe gv.strictgraph (nom);
handle_graphe gv.strictdigraph (nom);
Nouveau graphe à partir d'une chaîne de caractères ou d'un fichier en syntaxe dot

handle_graphe gv.readstring (chaîne);
handle_graphe gv.read (nom_fichier);
handle_graphe gv.read (canal);
Ajouter un nouveau sous-graphe à un graphe existant

handle_graphe gv.graph (handle_graphe, nom);
Nouveaux nœuds

Ajouter un nouveau nœud à un graphe existant

handle_nœud gv.node (handle_graphe, nom);
Nouveaux arcs

Ajouter un nouvel arc entre nœuds existants

handle_arc gv.edge (handle_nœud_queue, handle_nœud_tête);
Ajouter un nouvel arc entre un nœud de queue existant et un nœud de tête nommé qui sera induit dans le graphe s'il n'existe pas déjà

handle_arc gv.edge (handle_nœud_queue, nom_nœud_tête);
Ajouter un nouvel arc entre un nœud de tête existant et un nœud de queue nommé qui sera induit dans le graphe s'il n'existe pas déjà

handle_arc gv.edge (nom_nœud_queue, handle_nœud_tête);
Ajouter un nouvel arc entre des nœuds de queue et de tête nommés qui seront induits dans le graphe s'ils n'existent pas déjà

handle_arc gv.edge (handle_graphe, nom_nœud_queue, nom_nœud_tête);
Définir des valeurs d'attribut

Définir la valeur d'un attribut nommé du graphe/nœud/arc - créant l'attribut si nécessaire

chaîne gv.setv (handle_graphe, nom_attribut, valeur_attribut);
chaîne gv.setv (handle_nœud, nom_attribut, valeur_attribut);
chaîne gv.setv (handle_arc, nom_attribut, valeur_attribut);
Définir la valeur d'un attribut existant du graphe/nœud/arc (en utilisant le handle d'attribut)

chaîne gv.setv (handle_graphe, handle_attribut, valeur_attribut);
chaîne gv.setv (handle_nœud, handle_attribut, valeur_attribut);
chaîne gv.setv (handle_arc, handle_attribut, valeur_attribut);
Obtenir des valeurs d'attribut

Obtenir la valeur d'un attribut nommé du graphe/nœud/arc

chaîne gv.getv (handle_graphe, nom_attribut);
chaîne gv.getv (handle_nœud, nom_attribut);
chaîne gv.getv (handle_arc, nom_attribut);
Obtenir la valeur d'un attribut du graphe/nœud/arc (en utilisant le handle d'attribut)

chaîne gv.getv (handle_graphe, handle_attribut);
chaîne gv.getv (handle_nœud, handle_attribut);
chaîne gv.getv (handle_arc, handle_attribut);
Obtenir les noms à partir des handles

chaîne gv.nameof (handle_graphe);
chaîne gv.nameof (handle_nœud);
chaîne gv.nameof (handle_attribut);
Trouver des handles à partir des noms

handle_graphe gv.findsubg (handle_graphe, nom);
handle_nœud gv.findnode (handle_graphe, nom);
handle_arc gv.findedge (handle_nœud_queue, handle_nœud_tête);
handle_attribut gv.findattr (handle_graphe, nom);
handle_attribut gv.findattr (handle_nœud, nom);
handle_attribut gv.findattr (handle_arc, nom);
Divers navigateurs de graphes renvoyant des handles

handle_nœud gv.headof (handle_arc);
handle_nœud gv.tailof (handle_arc);
handle_graphe gv.graphof (handle_graphe);
handle_graphe gv.graphof (handle_arc);
handle_graphe gv.graphof (handle_nœud);
handle_graphe gv.rootof (handle_graphe);
Obtenir les handles des nœuds/arcs prototypes pour définir les valeurs d'attribut par défaut

handle_nœud gv.protonode (handle_graphe);
handle_arc gv.protoedge (handle_graphe);

Tests de fin d'itération

booléen gv.ok (handle_nœud);

Itérer sur les arcs sortants d'un graphe

handle_arc gv.firstout (handle_graphe);
handle_arc gv.nextout (handle_graphe, handle_arc);
Itérer sur les arcs d'un nœud

handle_arc gv.firstedge (handle_nœud);
handle_arc gv.nextedge (handle_nœud, handle_arc);
Itérer sur les arcs sortants d'un nœud

handle_arc gv.firstout (handle_nœud);
handle_arc gv.nextout (handle_nœud, handle_arc);
Itérer sur les nœuds de tête atteignables depuis les arcs sortants d'un nœud

handle_nœud gv.firsthead (handle_nœud);
