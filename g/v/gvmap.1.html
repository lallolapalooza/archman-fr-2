GVMAP(1) Manuel des commandes générales GVMAP(1)

NOM

gvmap - trouve des clusters et crée une carte géographique mettant en évidence les clusters.

SYNTAXE

gvmap [ options ] [ -o fichier_sortie ] [ fichiers ]

DESCRIPTION

gvmap prend en entrée un graphe au format DOT, trouve les clusters de nœuds et produit un rendu du graphe sous forme de carte géographique, avec les clusters mis en évidence comme des pays, au format xdot.

Dans le graphe d'entrée, chaque nœud doit avoir des informations de position, largeur et hauteur (attributs pos, width et height, respectivement) définies, et les nœuds ne doivent pas se chevaucher.

Par défaut, gvmap génère les clusters à partir des données. Si désiré, le graphe d'entrée peut spécifier des informations de cluster en donnant à chaque nœud un attribut cluster dont la valeur est un petit entier positif. (Cela fonctionne mieux si les valeurs de cluster sont toutes des entiers dans l'intervalle [1,K] pour un certain K. Les nœuds partageant la même valeur d'attribut cluster seront regroupés dans le même cluster. N.B. Pour que l'attribut cluster soit utilisé, tous les nœuds doivent avoir une valeur valide.)

Si l'option -D est utilisée, gvmap utilisera les sous-graphes de cluster de niveau supérieur pour déterminer le clustering. Tous les nœuds ne faisant pas partie d'un tel cluster seront placés dans un unique cluster fourre-tout.

Si l'entrée spécifie le clustering souhaité comme décrit ci-dessus, elle peut également spécifier une coloration souhaitée en ayant un nœud dans chaque cluster qui fournit un attribut clustercolor. N.B. Sauf si l'on spécifie -c0, seule la clustercolor du dernier nœud d'un cluster a un effet. De plus, sauf si l'on utilise -O, gvmap peut permuter les couleurs données.

OPTIONS

Les options suivantes sont supportées :

-a k
L'entier k spécifie le nombre moyen de points artificiels ajoutés le long de la boîte englobante des étiquettes. Ces points artificiels sont ajoutés pour éviter qu'une frontière de pays ne coupe la boîte englobante des étiquettes. Le temps de calcul est proportionnel à k ; par conséquent, pour les grands graphes, une petite valeur de k est suggérée. Si k = -1, une valeur de k appropriée est automatiquement sélectionnée en fonction de la taille du graphe. Par défaut, k = -1.
-b v
Le nombre réel v spécifie l'épaisseur de la ligne utilisée pour dessiner les frontières des polygones, avec v < 0 pour aucune ligne. Par défaut, v = 0.
-c k
L'entier k spécifie le schéma de couleurs utilisé pour colorier les pays. Par défaut, k = 1.

Les valeurs acceptables sont :

0 : pas de polygones
1 : pastel
2 : bleu à jaune
3 : blanc à rouge
4 : gris clair à rouge
5 : couleurs primaires
6 : séquentiel à teinte unique rouge
7 : séquentiel à teinte unique rouge plus clair
8 : gris clair
-c_opacity=xy
Spécifie une chaîne hexadécimale de deux caractères indiquant l'opacité des polygones.
-C d
L'entier d spécifie le nombre maximum de clusters (pays) autorisés. Par défaut, d = 0, ce qui signifie qu'il n'y a pas de limite.
-d d
L'entier d spécifie la graine aléatoire utilisée lors de l'optimisation d'affectation des couleurs qui maximise la différence de couleur entre les pays voisins.
-D
Si spécifié, les sous-graphes de cluster du graphe sont utilisés pour spécifier le clustering.
-e
Si spécifié, les arêtes seront incluses dans la sortie finale.
-g c
Spécifie la couleur de la boîte englobante. Si non spécifié, aucune boîte englobante n'est dessinée.
-h k
Le nombre de points artificiels ajoutés pour maintenir un pont entre les points d'extrémité. Par défaut, cela est zéro.
-highlight=k
Ne dessine que le cluster k. Par défaut, tous les clusters sont dessinés.
-k
Si spécifié, augmente le caractère aléatoire de la frontière extérieure.
-l s
Utilise la chaîne s comme étiquette pour le dessin.
-m v
Génère une marge de v points autour du dessin. Par défaut, elle est déterminée par gvmap.
-O
NE PAS effectuer l'optimisation d'affectation des couleurs qui maximise les différences de couleurs entre les pays voisins.
-o<fichier>
Placer la sortie dans <fichier>. La sortie par défaut est stdout
-p k
Indique quel niveau de points doit être affiché. Par défaut, aucun point n'est affiché.

Les valeurs acceptables sont :

0 : pas de points
1 : tous les points
2 : points d'étiquette
3 : points aléatoires/artificiels
-Q
Utilise la qualité de modularité pour le clustering plutôt que le clustering par défaut basé sur la modularité.
-r k
Le nombre de points aléatoires k (entier) utilisé pour définir les frontières maritimes et lacustres. Si 0, attribué automatiquement. Par défaut, v = 0
-s v
Le nombre réel v spécifie la profondeur de la mer et des rivages des lacs en points. Si 0, attribué automatiquement. Par défaut, v = 0.
-t n
Effectue n tentatives pour améliorer la contiguïté des clusters.
-v
Mode verbeux.
-z c
Spécifie la couleur de la ligne des polygones. La couleur par défaut est noir.
-?
Affiche l'aide et quitte.

EXEMPLES

Étant donné un graphe foo.gv, une façon de générer une disposition et de mettre en évidence les clusters est de d'abord sélectionner un moteur de disposition avec une méthode appropriée de suppression de chevauchement, puis d'alimenter la sortie dans gvmap, et enfin de rendre la carte en utilisant un format graphique spécifique. Par exemple, le pipeline suivant crée une carte avec des arêtes en gris clair semi-transparent et des nœuds disposés à l'aide de sfdp :

sfdp -Goverlap=prism foo.gv | gvmap -e | neato -n2 -Ecolor=#55555522 -Tpng > foo.png

Le script shell gvmap.sh fournit un raccourci pour de tels pipelines. Par exemple, le pipeline ci-dessus peut être réalisé en utilisant

gvmap.sh -Ae -Ecolor=#55555522 -Tpng foo.gv > foo.png
