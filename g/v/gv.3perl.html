gv(3perl) — Graphviz language bindings — Arch manual pages

NAME

gv - Perl interface to Graphviz graph manipulation language

SYNOPSIS

use gv;

USAGE

This module is intended to be used as an imported module.

INTRODUCTION

This module allows you to create, manipulate and render graphs using the Graphviz library from Perl.

A graph is a collection of nodes and edges. The Graphviz library provides a standard DOT language for describing graphs, and layout engines like dot, neato, fdp, circo and twopi for visualizing them.

This module provides Perl functions that map directly to the C API of the Graphviz library, making it possible to use Graphviz directly from Perl scripts.
