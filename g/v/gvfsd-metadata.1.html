NOM

gvfs-metadata - Démon de métadonnées pour gvfs

SYNTAXE

gvfs-metadata [OPTION...]

DESCRIPTION

gvfsd-metadata est un démon agissant comme un sérialiseur d'écriture pour le stockage interne des métadonnées de gvfs. Il est lancé automatiquement par les clients GIO lorsqu'ils effectuent des modifications de métadonnées. Les opérations de lecture sont effectuées directement par le code GIO côté client, et ne nécessitent pas que le démon soit en cours d'exécution.

Les fonctionnalités de métadonnées de gvfs sont utilisées par le gestionnaire de fichiers nautilus, par exemple.

OPTIONS

-h, --help

Affiche un court texte d'aide et quitte.

--version

Affiche le numéro de version et quitte.

-r, --replace

Remplace l'instance actuellement en cours d'exécution.

STATUT DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.

FICHIERS

$XDG_DATA_HOME/gvfs-metadata

Le répertoire où les fichiers de la base de données des métadonnées gvfs sont stockés

VOIR AUSSI

gvfs(7), nautilus(1)
