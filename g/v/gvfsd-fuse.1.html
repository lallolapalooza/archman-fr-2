NOM

gvfsd-fuse - Démon Fuse pour gvfs

SYNTAXE

gvfsd-fuse CHEMIN

DESCRIPTION

gvfsd-fuse maintient un montage fuse pour rendre les backends gvfs accessibles aux applications POSIX. Le point de montage du système de fichiers fuse est fourni par l'argument [CHEMIN].

gvfsd-fuse est normalement démarré par gvfsd(1). Dans ce cas, le point de montage est $XDG_RUNTIME_DIR/gvfs ou $HOME/.gvfs.

OPTIONS

-d

Active la sortie de débogage de fuse. Ceci implique -f.

-f

Exécute en premier plan.

-s

Exécute en mono-thread.

-o OPTION

Définit une option spécifique à fuse. Voir la documentation de fuse pour une liste de ces options.

STATUT DE SORTIE

En cas de succès, 0 est retourné, sinon un code d'échec non nul.
