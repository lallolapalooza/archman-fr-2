NOM

gvfs - Système de fichiers virtuel GIO

DESCRIPTION

GIO fournit une API VFS aux applications GLib. Elle inclut une implémentation 'locale' utilisant POSIX. gvfs fournit des implémentations qui vont au-delà et permettent d'accéder aux fichiers et au stockage via de nombreux protocoles, tels que ftp, http, sftp, dav, nfs, etc. Il offre également un support pour les dossiers de corbeille, pour la gravure de CD et pour la surveillance des périphériques et volumes intéressants sur l'ordinateur.

Les applications utilisent gvfs indirectement, par le biais de GIO chargeant le module gvfs qui implémente les points d'extension GIO. Le support gvfs pour la surveillance des volumes est inclus dans un module chargeable séparé.

L'implémentation réelle de gvfs est répartie sur un certain nombre de processus. Aucun d'entre eux ne devrait être lancé depuis la ligne de commande, sauf à des fins de débogage.

Processus principaux :

•gvfsd - le démon gvfs principal
•gvfsd-fuse - monte gvfs comme un système de fichiers fuse
•gvfsd-metadata - écrit les métadonnées gvfs

Moniteurs de volume :

•gvfs-afc-volume-monitor - un moniteur de volume pour les appareils Apple iPhone/iPod Touch
•gvfs-goa-volume-monitor - un moniteur de volume pour les comptes en ligne GNOME
•gvfs-gphoto2-volume-monitor - un moniteur de volume pour les appareils PTP
•gvfs-mtp-volume-monitor - un moniteur de volume pour les appareils MTP
•gvfs-udisks2-volume-monitor - un moniteur de volume basé sur udisks2

Backends de montage :

•gvfsd-admin - monte le système de fichiers local avec des privilèges d'administrateur
•gvfsd-afc - monte les volumes iPhone/iPod touch
•gvfsd-afp - monte les volumes Apple Filing Protocol
•gvfsd-afp-browse - parcourt les volumes Apple Filing Protocol
•gvfsd-archive - monte des fichiers d'archive dans divers formats
•gvfsd-burn - fournit un emplacement pour graver des CD
•gvfsd-cdda - monte les CD audio
•gvfsd-computer - fournit computer://
•gvfsd-dav - monte des systèmes de fichiers DAV
•gvfsd-dnssd - parcourt dnssd
•gvfsd-ftp - monte sur FTP
•gvfsd-google - monte des partages Google Drive
•gvfsd-gphoto2 - monte sur PTP
•gvfsd-http - monte sur HTTP
•gvfsd-localtest - un backend de test
•gvfsd-mtp - monte sur MTP
•gvfsd-network - fournit network://
•gvfsd-nfs - monte sur NFS
•gvfsd-recent - fournit recent://
•gvfsd-sftp - monte sur sftp
•gvfsd-smb - monte des volumes de systèmes de fichiers de partage Windows
•gvfsd-smb-browse - parcourt des volumes de systèmes de fichiers de partage Windows
•gvfsd-trash - fournit trash://

ENVIRONNEMENT

GIO_USE_VFS

Si défini, spécifie l'implémentation vfs GIO à utiliser. Les valeurs possibles incluent 'local' et 'gvfs'.

GIO_USE_VOLUME_MONITOR

Si défini, spécifie l'implémentation de moniteur de volume GIO à utiliser. Les valeurs possibles incluent 'unix', 'GProxyVolumeMonitorUDisks2', ainsi que d'autres moniteurs de volume natifs décrits dans les fichiers clés de $XDG_DATA_DIRS/gvfs/remote-volume-monitors.

FICHIERS

$XDG_DATA_DIRS/gvfs/mounts

Ce répertoire contient les fichiers clés décrivant les démons de montage.

$XDG_DATA_DIRS/gvfs/remote-volume-monitors

Ce répertoire contient les fichiers clés décrivant les moniteurs de volume distants.
