GVGEN(1) Manuel des commandes générales GVGEN(1)

NOM

gvgen - générer des graphes

SYNOPSIS

gvgen [ -dv? ] [ -in ] [ -cn ] [ -Cx,y ] [ -g[f]x,y ] [ -G[f]x,y ] [ -hn ] [ -kn ] [ -bx,y ] [ -Bx,y ] [ -mn ] [ -Mx,y ] [ -pn ] [ -rx,y ] [ -Rx ] [ -sn ] [ -Sn ] [ -Sn,d ] [ -tn ] [ -td,n ] [ -Tx,y ] [ -Tx,y,u,v ] [ -useed ] [ -wn ] [ -nprefix ] [ -Nname ] [ -ooutfile ]

DESCRIPTION

gvgen génère une variété de graphes abstraits simples et à structure régulière.

OPTIONS

Les options suivantes sont prises en charge :

-c n
Génère un cycle avec n sommets et arêtes.
-C x,y
Génère un cylindre de x par y . Cela produira x*y sommets et 2*x*y - y arêtes.
-g [f]x,y
Génère une grille de x par y . Si f est spécifié, la grille est pliée, avec une arête reliant chaque paire de sommets d'angle opposés. Cela produira x*y sommets et 2*x*y - y - x arêtes si non pliée et 2*x*y - y - x + 2 arêtes si pliée.
-G [f]x,y
Génère une grille partielle de x par y . Si f est spécifié, la grille est pliée, avec une arête reliant chaque paire de sommets d'angle opposés. Cela produira x*y sommets.
-h n
Génère un hypercube de degré n. Cela produira 2^n sommets et n*2^(n-1) arêtes.
-k n
Génère un graphe complet sur n sommets avec n*(n-1)/2 arêtes.
-b x,y
Génère un graphe biparti complet de x par y . Cela produira x+y sommets et x*y arêtes.
-B x,y
Génère une boule de x par y , c'est-à-dire un cylindre de x par y avec deux nœuds « capuchon » fermant les extrémités. Cela produira x*y + 2 sommets et 2*x*y + y arêtes.
-m n
Génère un maillage triangulaire avec n sommets sur un côté. Cela produira (n+1)*n/2 sommets et 3*(n-1)*n/2 arêtes.
-M x,y
Génère une bande de Moebius de x par y. Cela produira x*y sommets et 2*x*y - y arêtes.
-p n
Génère un chemin sur n sommets. Cela produira n-1 arêtes.
-r x,y
Génère un graphe aléatoire. Le nombre de sommets sera la plus grande valeur de la forme 2^n-1 inférieure ou égale à x. Des valeurs plus grandes de y augmentent la densité du graphe.
-R x
Génère un arbre enraciné aléatoire sur x sommets.
-s n
Génère une étoile sur n sommets. Cela produira n-1 arêtes.
-S n
Génère un graphe de Sierpinski d'ordre n. Cela produira 3*(3^(n-1) + 1)/2 sommets et 3^n arêtes.
-S n,d
Génère un graphe de Sierpinski de dimension det d'ordre n. Actuellement, d doit être 2 ou 3. Pour d égal à 3, il y aura 4*(4^(n-1) + 1)/2 sommets et 6 * 4^(n-1) arêtes.
-t n
Génère un arbre binaire de hauteur n. Cela produira 2^n-1 sommets et 2^n-2 arêtes.
-t h,n
Génère un arbre n-aire de hauteur h.
-T x,y
-T x,y,u,v
Génère un tore de x par y . Cela produira x*y sommets et 2*x*y arêtes. Si u et v sont spécifiés, ils indiquent des torsions de cette quantité dans les directions horizontale et verticale, respectivement.
-u seed
Spécifie l'état initial du générateur de nombres aléatoires. Si cette option n'est pas donnée, l'heure actuelle est utilisée pour dériver une graine.
-w n
Génère un chemin sur n sommets. Cela produira n-1 arêtes.
-i n
Génère n graphes du type demandé. Actuellement, disponible uniquement si l'option -R est utilisée.
-n prefix
Normalement, des entiers sont utilisés comme noms de nœuds. Si prefix est spécifié, il sera préfixé à l'entier pour créer le nom.
-N name
Utilise name comme nom du graphe. Par défaut, le graphe est anonyme.
-o outfile
Si spécifié, le graphe généré est écrit dans le fichier outfile. Sinon, le graphe est écrit sur la sortie standard.
-d
Rend le graphe généré orienté.
-v
Sortie détaillée.
-?
Affiche les informations d'utilisation.

STATUT DE SORTIE

gvgen se termine avec 0 en cas de réussite, et se termine avec 1 si un drapeau mal formé ou incorrect est donné, ou si le fichier de sortie spécifié n'a pas pu être ouvert.
