LIBGVPR(3) Manuel des fonctions de bibliothèque LIBGVPR(3)

NOM

libgvpr - bibliothèque pour le filtrage de graphes

SYNTAXE

#include <graphviz/gvpr.h>
  /* Si défini, gvpr appelle exit() en cas d'erreur */
#define GV_USE_EXIT 1
  /* Si défini, gvpr stocke les graphes de sortie dans gvpropts */
#define GV_USE_OUTGRAPH 2
typedef ssize_t (*gvprwr) (void*, const char *buf, size_t nbyte, void*);
typedef struct {
    Agraph_t** ingraphs;      /* Tableau terminé par NULL de graphes d'entrée */
    int n_outgraphs;          /* Si GV_USE_OUTGRAPH est défini, graphes de sortie */
    Agraph_t** outgraphs;
    gvprwr out;               /* fonction d'écriture pour stdout */
    gvprwr err;               /* fonction d'écriture pour stderr */
    int flags;
} gvpropts;
extern int gvpr (int argc, char *argv[], gvpropts* opts);

DESCRIPTION

La bibliothèque gvpr permet à une application d'effectuer des manipulations et filtrages généraux de graphes basés sur un langage de type awk. (Pour une description plus complète de ce langage, voir gvpr(1).)

La bibliothèque a un seul point d'entrée : la fonction gvpr(). Celle-ci fournit une interface standard argc/argv, ainsi qu'une structure pour gérer les graphes en mémoire, les fonctions d'impression de l'application, et des options supplémentaires.

Lorsqu'elle est appelée, gvpr() traite les indicateurs fournis dans le tableau argv, et compile le programme gvpr à exécuter (fourni soit via l'indicateur -f, soit comme élément de argv). Elle exécute ensuite le programme sur chaque graphe d'entrée. Si opts->ingraphs n'est pas NULL, cela est considéré comme un tableau terminé par NULL de graphes en mémoire à utiliser comme entrée. Sinon, les éléments non traités de argv sont considérés comme les noms de fichiers contenant les graphes à traiter. (S'il n'en reste aucun, gvpr lira depuis l'entrée standard.)

Normalement, gvpr écrit tout graphe de sortie sur la sortie standard. Cependant, si l'indicateur GV_USE_OUTGRAPH est défini dans opts->flags, les graphes de sortie seront stockés dans un tableau pointé par opts->outgraphs et le compteur sera stocké dans opts->n_outgraphs. Dans ce cas, l'application doit appeler agclose() sur chaque graphe de sortie lorsqu'elle a terminé de l'utiliser.

L'application peut remplacer les fonctions d'écriture par défaut pour la sortie standard et la sortie d'erreur en utilisant les champs out et err dans opts. Lorsque appelée par gvpr, le deuxième argument pointera vers un tampon de caractères à écrire, tandis que le troisième argument fournira le nombre de caractères. La fonction devrait retourner le nombre d'octets effectivement écrits.

VALEURS DE RETOUR

Normalement, gvpr retourne 0 en cas de succès et une valeur non nulle si une erreur se produit. Tout message d'erreur pertinent aura été écrit sur la sortie d'erreur ou la fonction opts->err de l'application aura été appelée. Si, cependant, GV_USE_EXIT est défini dans opts->flags, gvpr appellera exit(3) en cas d'erreur.

VOIR AUSSI

gvpr(1), awk(1), cgraph(3)
