NOM

g2root - convertir les fichiers de géométrie GEANT en fichiers ROOT

SYNOPSIS

g2rootd [-f nom_map] nom_geant nom_macro

DESCRIPTION

Vous pouvez convertir une géométrie GEANT (voir http://geant.cern.ch/ pour plus d'informations sur GEANT) en géométrie ROOT en suivant les étapes suivantes

1
Lancez la version interactive de GEANT et produisez un fichier Zebra RZ detector.geom, en tapant la commande :
Geant > rz/file 21 detector.geom on
2
Lancez le programme g2root pour convertir le fichier Zebra RZ en une macro ROOT detector.C :
g2root detector.geom detector.C
3
Lancez la session ROOT suivante ; 
root [1] .x detector.C
root [2] detector.Draw()
root [3] c1.x3d()   // (cela invoque la visionneuse 3D de Root)
root [4] TFile f("detector.root","NEW") //ouvrir un nouveau fichier root
root [5] detector.Write() //Écrire la structure de géométrie
root [6] f.Write()

Notez que la structure TNode actuellement dans ROOT n'a pas été conçue comme un remplacement pour un véritable package de géométrie. L'idée était principalement de dessiner des géométries simples dans des programmes d'affichage d'événements. Nous explorons actuellement plusieurs alternatives pour un package de géométrie réel et efficace supportant ;

-
une base de données disque avec stockage de multiples versions de géométrie
-
un éditeur et une visionneuse interactifs
-
avec des vues 3D
-
mais aussi des vues coupées 2D
-
avec des interfaces vers des MC existants ou futurs tels que GEANT3 ou GEANT4

Un second programme appelé gh2root (voir http://root.cern/root/gh2root.html) génère automatiquement du code C++ correspondant aux structures GEANT3 Zebra JSET, JVERTX, JKINE, JHITS et JDIGI.
