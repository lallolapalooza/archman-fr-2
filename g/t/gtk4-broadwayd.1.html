Nom

gtk4-broadwayd - Le serveur d'affichage Broadway

Syntaxe

gtk4-broadwayd [OPTIONS...] <AFFICHAGE>
gtk4-broadwayd --port=PORT --address=ADRESSE <AFFICHAGE>
gtk4-broadwayd --unixaddress=ADRESSE <AFFICHAGE>

DESCRIPTION

gtk4-broadwayd est un serveur d'affichage pour le backend GDK Broadway. Il permet à plusieurs applications GTK d'afficher leurs fenêtres dans le même navigateur web, en se connectant à gtk4-broadwayd.

Lors de l'utilisation de gtk4-broadwayd, spécifiez le numéro d'affichage à utiliser, précédé d'un deux-points, similaire à X. Le numéro d'affichage par défaut est 0.

gtk4-broadwayd :5

Puis pointez votre navigateur web vers http://127.0.0.1:8085.

Démarrez vos applications comme ceci :

GDK_BACKEND=broadway BROADWAY_DISPLAY=:5 gtk4-demo

OPTIONS

--port PORT

Utilise le PORT donné pour la connexion HTTP, au lieu de la valeur par défaut 8080 + (AFFICHAGE - 1).

--address ADRESSE

Utilise l'adresse donnée pour la connexion HTTP, au lieu de la valeur par défaut http://127.0.0.1.

--unixsocket ADRESSE

Utilise l'adresse donnée comme adresse de socket de domaine Unix. Cette option remplace --address et --port, et elle n'est disponible que sur les systèmes de type Unix.
