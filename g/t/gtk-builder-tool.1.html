GTK-BUILDER-TOOL(1) Commandes utilisateur GTK-BUILDER-TOOL(1)

NOM

gtk-builder-tool - Utilitaire de fichiers GtkBuilder

SYNTAXE

gtk-builder-tool [COMMANDE] [OPTION...] FICHIER

DESCRIPTION

gtk-builder-tool peut effectuer diverses opérations sur les fichiers .ui GtkBuilder.

Vous devriez toujours tester les fichiers .ui modifiés produits par gtk-builder-tool avant de les utiliser en production.

COMMANDES

Les commandes suivantes sont comprises :

validate

Valide le fichier .ui et signale les erreurs sur la sortie d'erreur standard.

simplify

Simplifie le fichier .ui en supprimant les propriétés qui sont définies à leurs valeurs par défaut et écrit le XML résultant sur la sortie standard, ou le remplace dans le fichier d'entrée.

enumerate

Liste tous les objets nommés qui sont créés dans le fichier .ui.

preview

Aperçu du fichier .ui. Cette commande accepte des options pour spécifier l'ID d'un objet et un fichier .css à utiliser.

OPTIONS_SIMPLIFY

La commande simplify accepte les options suivantes :

--replace

Écrit le contenu dans le fichier .ui au lieu de la sortie standard.

OPTIONS_PREVIEW

La commande preview accepte les options suivantes :

--id=ID

L'ID de l'objet à prévisualiser. Si non spécifié, gtk-builder-tool choisira un objet approprié de lui-même.

--css=FICHIER

Charge les informations de style du fichier .css donné.
