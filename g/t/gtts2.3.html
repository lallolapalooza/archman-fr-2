fonction

sous-programme cgtts2 (integer itrans, integer n, integer nrhs, complex, dimension( * ) dl, complex, dimension( * ) d, complex, dimension( * ) du, complex, dimension( * ) du2, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer

ldb)

CGTTS2 résout un système d'équations linéaires avec une matrice tridiagonale en utilisant la factorisation LU calculée par

sgttrf.

But

: 
!>
!> CGTTS2 résout l'un des systèmes d'équations
!>    A * X = B,  A**T * X = B,  ou  A**H * X = B,
!> avec une matrice tridiagonale A en utilisant la factorisation LU calculée
!> par CGTTRF.
!
>

Paramètre

s
ITRANS 
!>          ITRANS est INTEGER
!>          Spécifie la forme du système d'équations.
!>          = 0 :  A * X = B     (Pas de transposition)
!>          = 1 :  A**T * X = B  (Transposition)
!>          = 2 :  A**H * X = B  (Transposition conjuguée)
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!
>

D

L 
!>          DL est un tableau COMPLEX, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L à partir de la
!>          factorisation LU de A.
!
>

D 
!>          D est un tableau COMPLEX, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U à partir de
!>          la factorisation LU de A.
!
>

D

U 
!>          DU est un tableau COMPLEX, dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!
>

DU

2 
!>          DU2 est un tableau COMPLEX, dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours soit
!>          i ou i+1 ; IPIV(i) = i indique qu'un échange de lignes n'a pas été
!>          requis.
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des vecteurs seconds membres B.
!>          À la sortie, B est écrasé par les vecteurs solution X.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>
