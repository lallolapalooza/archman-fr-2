NOM

gtstemplate - génère un modèle utilisé pour créer de nouvelles classes d'objets.

SYNOPIS

gtstemplate [OPTIONS] [BIBLIOTHEQUES]

DESCRIPTION

Cette page de manuel documente brièvement la commande gtstemplate.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

--no-extra-data
--no-extra-method
--overload=METHODE
