GTAGS.CONF(5) Manuel des formats de fichiers GTAGS.CONF(5)

NOM

gtags.conf - données de configuration pour GNU Global

SYNTAXE

´gtags.conf´
´~/.globalrc´

DESCRIPTION

´gtags.conf´ contient les données de configuration pour global(1), gozilla(1), gtags(1) et htags(1). Ils recherchent les fichiers suivants dans cet ordre et lisent à partir du premier qui existe et est accessible en lecture.

(1) --gtagsconf fichier
(2) $GTAGSCONF
(3) [racine du projet]/gtags.conf
(4) [racine du projet]/[objdir]/gtags.conf
(5) $HOME/.globalrc
(6) /etc/gtags.conf
(7) [sysconfdir]/gtags.conf

[objdir] est ´obj´ par défaut ; vous pouvez le changer par GTAGSOBJDIR ou MAKEOBJDIR. [sysconfdir] est ´/usr/local/etc´ par défaut ; vous pouvez le changer par l'option --sysconfdir du script configure.

Sa syntaxe est similaire à termcap(5), à l'exception de quelques extensions décrites plus tard. Un fichier inclut un ou plusieurs enregistrements. Vous devriez sélectionner un enregistrement en utilisant une étiquette. L'étiquette par défaut est ´default´. Si GTAGSLABEL est définie, sa valeur est utilisée. Veuillez noter que la signification de ´default´ est différente de celle de termcap(5).

Les lignes commençant par ´#´ sont ignorées. Un enregistrement est constitué d'un ou plusieurs champs séparés par ´:´ et se termine par un saut de ligne. Le premier champ doit avoir un nom d'étiquette. Chacun des champs restants contient une définition de variable. Il existe trois types de variables.

Booléen : Ce type n'a pas de valeur ; l'existence de la variable signifie vrai, sinon faux.
Nombre : Ce type a une valeur numérique après ´#´.
Chaîne : Ce type a une valeur de chaîne après ´=´.
La plupart des variables sont de type chaîne.

Si les données incluent ´:´ ou un saut de ligne, vous devez les échapper avec ´\´. Un champ vide est autorisé, mais il n'a pas de sens.

Lorsqu'il y a plus d'une définition, la précédente est adoptée. Exceptionnellement, toutes les valeurs de skip, langmap et gtags_parser sont adoptées et connectées respectivement.

Substitution de variable

La substitution de variable, similaire à sh(1), est disponible. Vous pouvez faire référence à n'importe quelle variable de chaîne en utilisant le préfixe ´$´. Par exemple, le b suivant a la valeur ´XYZ´.

:a=Y:b=X${a}Z:

Inclusion d'un autre enregistrement

Tc est une variable spéciale ; elle lit les définitions d'un autre enregistrement. Elle est similaire au tc de termcap(5). Sa syntaxe est la suivante :
tc=étiquette[@fichier]
Si seule une étiquette est donnée, tc est lu à partir d'un enregistrement spécifié par l'étiquette dans le même fichier. Si @fichier est également donné, tc est lu à partir d'un enregistrement spécifié par l'étiquette dans le fichier spécifié. Fichier doit être un chemin absolu et ne doit pas contenir de variables. Différent de termcap(5), vous pouvez utiliser tc n'importe quand et n'importe où.

CONFIGURATION

Concernant les variables pour chaque commande, veuillez consulter le manuel correspondant.

Vous pouvez utiliser les variables d'environnement suivantes comme variables de chaîne. Si ces variables sont définies, les variables d'environnement du même nom sont définies avant l'exécution de la commande.
GREP_COLOR
GREP_COLORS
GTAGSBLANKENCODE
GTAGSCACHE
GTAGSFORCECPP
GTAGSGLOBAL
GTAGSGTAGS
GTAGSLIBPATH
GTAGSLOGGING
GTAGSTHROUGH
GTAGS_OPTIONS
HTAGS_OPTIONS
MAKEOBJDIR
MAKEOBJDIRPREFIX
TMPDIR

Les variables suivantes sont également disponibles en tant que variables de chaîne. Par défaut, chacune d'elles a un chemin de répertoire fourni par le script configure.
bindir
datadir
libdir
localstatedir
sysconfdir

ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution des commandes.

GTAGSCONF
Si cette variable est définie, sa valeur est utilisée comme fichier de configuration.
GTAGSLABEL
Si cette variable est définie, sa valeur est utilisée comme étiquette du fichier de configuration. La valeur par défaut est default.

VOIR AUSSI

global(1), gozilla(1), gtags(1), htags(1).

(http://www.gnu.org/software/global/).
