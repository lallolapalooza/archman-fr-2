Nom

gtk4-builder-tool - Utilitaire de fichiers GtkBuilder

SYNOPSIS

gtk4-builder-tool <COMMANDE> [OPTIONS...] <FICHIER>
gtk4-builder-tool validate [OPTIONS...] <FICHIER>
gtk4-builder-tool enumerate [OPTIONS...] <FICHIER>
gtk4-builder-tool simplify [OPTIONS...] <FICHIER>
gtk4-builder-tool preview [OPTIONS...] <FICHIER>
gtk4-builder-tool render [OPTIONS...] <FICHIER>
gtk4-builder-tool screenshot [OPTIONS...] <FICHIER>

DESCRIPTION

gtk4-builder-tool peut effectuer diverses opérations sur les fichiers de définition d'interface utilisateur GtkBuilder.

COMMANDES

Validation

La commande validate valide le fichier de définition d'interface spécifié et rapporte les erreurs sur stderr.

Notez qu'il existe des limitations quant à la validation qui peut être effectuée pour les modèles, car ils sont étroitement liés à la fonction class_init dans laquelle ils sont utilisés. Si votre fichier d'interface utilise des types provenant de bibliothèques tierces, il peut être utile d'ajouter ces bibliothèques à la variable d'environnement LD_PRELOAD.

--deprecations

Avertit sur l'utilisation de types obsolètes dans le fichier de définition d'interface.

Énumération

La commande enumerate affiche tous les objets nommés présents dans le fichier de définition d'interface.

--callbacks

Affiche également les noms des fonctions de rappel.

Aperçu

La commande preview affiche le fichier de définition d'interface.

Cette commande accepte des options pour spécifier l'ID de l'objet de premier niveau et un fichier CSS à utiliser.

--id=ID

L'ID de l'objet à prévisualiser. S'il n'est pas spécifié, gtk4-builder-tool choisira un objet approprié lui-même.

--css=FICHIER

Charge les informations de style à partir du fichier CSS spécifié.

Rendu

La commande render enregistre un rendu du fichier de définition d'interface sous forme d'image png ou de fichier node. Le nom du fichier à écrire peut être spécifié comme second argument FICHIER.

Cette commande accepte des options pour spécifier l'ID de l'objet de premier niveau et un fichier CSS à utiliser.

--id=ID

L'ID de l'objet à prévisualiser. S'il n'est pas spécifié, gtk4-builder-tool choisira un objet approprié lui-même.

--css=FICHIER

Charge les informations de style à partir du fichier CSS spécifié.

--node

Écrit un fichier node sérialisé au lieu d'une image png.

--force

Écrase un fichier existant.

Capture d'écran

La commande screenshot est un alias pour render.

Simplification

La commande simplify simplifie le fichier de définition d'interface en supprimant les propriétés définies à leurs valeurs par défaut et écrit le XML résultant sur la sortie standard, ou le remet dans le fichier d'entrée.

Lorsque l'option --3to4 est spécifiée, la commande simplify interprète l'entrée comme un fichier de définition d'interface GTK 3 et tente de le convertir en équivalents GTK 4. Elle effectue diverses conversions, telles que le renommage de propriétés, la traduction de propriétés enfants en propriétés de mise en page, la réécriture de la configuration pour GtkNotebook, GtkStack, GtkAssistant ou le changement de barres d'outils en boîtes.

Vous devriez toujours tester les fichiers de définition d'interface modifiés produits par gtk4-builder-tool avant de les utiliser en production.

Notez en particulier que la conversion effectuée avec --3to4 est destinée à être un point de départ pour un port de GTK 3 vers GTK 4. Il est attendu que vous devrez effectuer des corrections manuelles après la conversion initiale.

--replace

Réécrit le contenu dans le fichier de définition d'interface au lieu d'utiliser la sortie standard.

--3to4

Transforme un fichier de définition d'interface GTK 3 en ses définitions GTK 4 équivalentes.
