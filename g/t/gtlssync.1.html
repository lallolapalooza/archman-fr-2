NOM

gtlssync - Un wrapper pour exécuter rsync sur gtlssh

SYNOPSIS

gtlssync [options rsync]

DESCRIPTION

Le programme gtlssync enveloppe simplement rsync pour utiliser gtlssh comme transport. rsync n'est pas décrit ici, voir rsync(1) pour les options.

VOIR AUSSI

rsync(1) gtlssh(1)

PROBLÈMES CONNUS

Aucun.
