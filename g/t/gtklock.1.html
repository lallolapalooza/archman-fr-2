gtklock(1) Manuel des commandes générales gtklock(1)

NOM

gtklock - Écran de verrouillage basé sur GTK pour Wayland

SYNOPSIS

gtklock [options...]

OPTIONS

-h, --help

Afficher les options d'aide

--help-config

Afficher les options disponibles dans la configuration. Voir CONFIGURATION.

-d, --daemonize

Détacher du terminal de contrôle.

-c, --config <chemin>

Spécifier le fichier de configuration à utiliser. Par défaut, les chemins suivants sont vérifiés dans l'ordre suivant : $XDG_CONFIG_HOME/gtklock/config.ini et gtklock/config.ini sous chaque répertoire dans $XDG_CONFIG_DIRS.

CONFIGURATION

La configuration est stockée au format de fichier clé glib. Les options sont spécifiées sous la forme nom=valeur et peuvent être utilisées depuis la ligne de commande comme --nom=valeur. Toutes les options doivent être sous le groupe principal.

Toutes les options disponibles sont :

-g, --gtk-theme <chaîne>

Définir le thème GTK.

-s, --style <chemin>

Charger le fichier de style CSS.

-x, --layout <chemin>

Charger le fichier de mise en page XML.

-m, --modules <nom>

Charger les modules gtklock. Le nom du module peut être un chemin absolu, un chemin relatif (commençant par ./ ou ../) ou un nom dans un répertoire système (comme example-module.so pour /usr/lib/gtklock/example-module.so). Le suffixe .so peut être omis.

-b, --background <chemin>

Charger l'arrière-plan. L'arrière-plan spécifié peut être écrasé par CSS.

-t, --time-format <chaîne>

Définir le format de l'heure. Voir date(1).

-d, --date-format <chaîne>

Définir le format de la date. Voir date(1).

-f, --follow-focus

Suivre le focus entre les moniteurs. Peut ne pas fonctionner pour tous les compositeurs, recommandé pour hyprland.

-H, --idle-hide

Cacher le formulaire de saisie lorsqu'il est inactif.

-T, --idle-timeout <int>

Délai d'inactivité en secondes.

-S, --start-hidden

Démarrer avec le formulaire de saisie caché.

-L, --lock-command

Commande à exécuter après le verrouillage. La commande est exécutée asynchroniquement.

-U, --unlock-command

Commande à exécuter après le déverrouillage. La commande est exécutée asynchroniquement.

-M, --monitor-priority <nom>

Définir la priorité du focus du moniteur. L'option peut être spécifiée plusieurs fois.

EXEMPLE

Exemple de configuration :

[main]
gtk-theme=Adwaita-dark

Exemple de style :

window {
   background-image: url("background.png");
   background-size: cover;
   background-repeat: no-repeat;
   background-position: center;
   background-color: black;
}
