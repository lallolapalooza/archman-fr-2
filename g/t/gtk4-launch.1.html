Nom

gtk4-launch - Lancer une application

SYNOPSIS

gtk4-launch [OPTIONS...] <APPLICATION> [URI...]

DESCRIPTION

gtk4-launch lance une application en utilisant le nom donné. L'application est démarrée avec une notification de démarrage appropriée sur un affichage par défaut, sauf indication contraire.

gtk4-launch prend au moins un argument, le nom de l'application à lancer. Le nom doit correspondre au nom du fichier desktop de l'application, tel qu'il se trouve dans les sous-répertoires des applications des répertoires de données XDG, avec ou sans le suffixe .desktop.

Si l'appel comporte plus d'un argument, les autres arguments, en plus du nom de l'application, sont considérés comme des emplacements URI et sont transmis en tant qu'arguments à l'application lancée.

OPTIONS

-?, -h, --help

Affiche l'aide de la commande et quitte.

--version

Affiche la version de la commande et quitte.

ENVIRONNEMENT

Certaines variables d'environnement affectent le comportement de gtk4-launch :

XDG_DATA_HOME, XDG_DATA_DIRS

Les variables d'environnement spécifiant les répertoires de données XDG.
