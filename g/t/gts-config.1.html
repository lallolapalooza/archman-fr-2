NOM

gts-config - définit les valeurs pour les programmes utilisant gts.

SYNTAXE

gts-config [OPTIONS] [BIBLIOTHEQUES]

DESCRIPTION

Cette page de manuel documente brièvement la commande gts-config.

OPTIONS

Ces programmes suivent la syntaxe habituelle de ligne de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

--prefix[=DIR]
--exec-prefix[=DIR]
--version
--libs
--cflags
--check

BIBLIOTHEQUES

gts
gmodule
gthread
