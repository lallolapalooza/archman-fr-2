Nom

gtester-report - utilitaire de formatage de rapports de tests

SYNTAXE

gtester-report [OPTION...] gtester-log

DESCRIPTION

gtester-report est un script qui convertit la sortie XML générée par gtester en HTML.

Depuis GLib 2.62, gtester-report est déprécié. Utilisez TAP pour rapporter les résultats des tests à la place, et alimentez-le dans la suite de tests fournie par votre système de construction.

OPTIONS

-h, --help

Affiche l'aide et quitte.

-v, --version

Affiche les informations de version et quitte.

-s, --subunit

Produit une sortie subunit. Nécessite python-subunit.

VOIR AUSSI

gtester(1) <man:gtester(1)>
