NOM

gtk3-demo - Démonstration des widgets GTK+

SYNTAXE

gtk3-demo [--help] [--list] [--run EXEMPLE] [--autoquit]

DESCRIPTION

gtk3-demo est une collection d'exemples. Son objectif est de démontrer de nombreux widgets GTK+ d'une manière utile pour les développeurs d'applications.

L'application affiche le code source de chaque exemple, ainsi que les autres ressources utilisées, telles que les fichiers ui et les icônes.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Afficher les options d'aide

--list

Lister les exemples disponibles.

-run EXEMPLE

Exécuter l'exemple nommé. Utiliser --list pour voir les exemples disponibles.

--autoquit

Quitter après un court délai. Ceci est destiné à être utilisé avec --run, par exemple lors du profilage.
