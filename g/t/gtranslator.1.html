NOM

gtranslator -- un éditeur de fichiers po gettext confortable avec de nombreuses fonctionnalités.

SYNTAXE

gtranslator [ FICHIER-PO ]

DESCRIPTION

gtranslator est un éditeur de fichiers po gettext confortable doté de nombreuses fonctionnalités telles que l'édition de caractères spéciaux, la vue des formes plurielles, le support de différents jeux de caractères, des préférences confortables, une vue en liste des messages, une fonction de recherche basée sur les expressions régulières, des possibilités de compilation/mise à jour et bien plus encore.

Bien entendu, toutes les fonctionnalités standard d'une bonne application comme le glisser-déposer, la gestion des sessions, les fichiers supplémentaires pour les types mime et les éléments de menu sont présentes.
L'affichage instantané des commentaires, une table de navigation rapide et confortable des messages avec des couleurs personnalisables, des thèmes de couleurs, le support UTF-8, un haut niveau de personnalisation et un tampon d'apprentissage personnel/mémoire de traduction avec des capacités d'auto-traduction sont les principales fonctionnalités de gtranslator en plus de l'édition confortable des entrées de traduction.

OPTIONS

--help
Vous affiche une petite aide générée automatiquement par GNOME.

TAMPON D'APPRENTISSAGE

Le tampon d'apprentissage est l'implémentation d'une mémoire de traduction (MT) personnelle dans gtranslator. gtranslator utilise le format UMTF (un fichier XML compressé, généralement assez lisible à la main une fois décompressé) pour stocker ses chaînes apprises.
Vos chaînes apprises sont alors disponibles pour la fonction d'auto-traduction de gtranslator, où gtranslator remplit automatiquement les traductions correspondantes et précieuses pour tout message qui a déjà été appris auparavant. Cela se traduit par un pourcentage assez élevé de messages pré-remplis/pré-traduits.
Le style courant et bon de travailler avec le tampon d'apprentissage et avec l'auto-traduction est d'apprendre les fichiers po/traduction principaux pour votre langue.
Vous devriez apprendre les fichiers po principaux (pour GNOME par exemple gnumeric, nautilus, evolution ou tout autre fichier po plus grand, déjà traduit, d'un paquet) pour votre langue) ; vous pouvez utiliser un nouveau script du paquet gtranslator pour automatiser un peu cette tâche : il s'agit de “build-gtranslator-learn-buffer.sh” qui est installé dans le répertoire des scripts de gtranslator, que vous pouvez voir en appelant gtranslator -b et vous exécutez simplement le script avec son chemin complet et suivez simplement les informations sur la ligne de commande pour cela.
Ensuite, vous pouvez simplement utiliser l'entrée de menu "Autotranslation" de l'interface graphique ou utiliser le raccourci clavier "F10" pour que gtranslator auto-traduise toutes les traductions manquantes à partir de votre tampon d'apprentissage personnel. Cela facilitera votre travail de traduction et permettra de pré-traduire une grande partie des fichiers po.
Avec un tampon d'apprentissage personnel assez grand, d'environ 2 Mo, vous pouvez obtenir de nombreux messages pré-traduits pour un nouveau projet/une nouvelle traduction.
Si vous souhaitez utiliser le contenu du tampon d'apprentissage stocké pour produire un fichier po avec toutes les traductions « apprises », vous pouvez également utiliser la capacité "exporter le tampon d'apprentissage" de gtranslator pour obtenir une version en fichier po brut du tampon d'apprentissage.
