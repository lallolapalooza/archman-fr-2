Nom

gtk4-rendernode-tool - Utilitaire GskRenderNode

SYNOPSIS

gtk4-rendernode-tool <COMMANDE> [OPTIONS...] <FICHIER>
gtk4-rendernode-tool benchmark [OPTIONS...] <FICHIER>
gtk4-rendernode-tool compare [OPTIONS...] <FICHIER1> <FICHIER2>
gtk4-rendernode-tool convert [OPTIONS...] <FICHIER1>
gtk4-rendernode-tool extract [OPTIONS...] <FICHIER>
gtk4-rendernode-tool info [OPTIONS...] <FICHIER>
gtk4-rendernode-tool render [OPTIONS...] <FICHIER> [<FICHIER>]
gtk4-rendernode-tool show [OPTIONS...] <FICHIER>

DESCRIPTION

gtk4-rendernode-tool peut effectuer diverses opérations sur des rendernodes sérialisés.

COMMANDES

Informations

La commande info affiche des informations générales sur le rendernode, telles que le nombre de nœuds et la profondeur de l'arbre.

Affichage

La commande show affiche le rendernode.

--offload

Place le nœud dans un GraphicsOffload. Destiné à tester les capacités d'offloading de rendernodes simples.

--undecorated

Supprime les décorations de fenêtre. Ceci est destiné au rendu exact du rendernode sans aucune barre de titre.

Rendu

La commande render enregistre un rendu du rendernode sous forme d'image png, tiff ou svg, ou de document pdf. Le nom du fichier à écrire peut être spécifié comme deuxième argument FICHIER.

--renderer=RENDERER

Utilise le rendu spécifié. Utilisez --renderer=help pour obtenir des informations sur les valeurs possibles pour RENDERER.

--dont-move

Conserve la position du nœud inchangée, par rapport à la grille de pixels.

Benchmark

La commande benchmark effectue un test de performance du rendu d'un nœud avec les rendus existants et affiche les temps d'exécution.

--renderer=RENDERER

Ajoute le rendu spécifié. Cet argument peut être passé plusieurs fois pour tester plusieurs rendus. Par défaut, tous les principaux rendus GTK sont exécutés.

--runs=RUNS

Nombre de fois où le nœud est rendu sur chaque rendu. Par défaut, ce nombre est de 3. Gardez à l'esprit que la première exécution est souvent utilisée pour remplir les caches et peut être significativement plus lente.

--no-download

N'essaie pas de télécharger le résultat. Cela peut entraîner une mesure qui n'inclut pas l'exécution des commandes sur le GPU. Il peut être utile d'utiliser ce drapeau pour tester les performances de soumission des commandes.

Comparer

La commande compare compare le rendu d'un nœud avec une image de référence, ou les rendus de deux nœuds, ou deux images. Si des différences sont trouvées, le code de sortie est 1. Si les images sont identiques, il est 0.

--renderer=RENDERER

Utilise le rendu spécifié.

--output=FICHIER

Enregistre les différences sous forme d'image png dans FICHIER.

--quiet

N'écrit pas les résultats sur la sortie standard.

Convertir

La commande convert convertit une icône SVG symbolique en un nœud et écrit le résultat sur la sortie standard.

--recolor

Si cette option est utilisée, le nœud résultant aura ses couleurs symboliques remplacées par les valeurs données aux options --fg, --success, --warning et --error. Sinon, le nœud aura les couleurs non remplacées, ce qui peut être utile pour diagnostiquer les problèmes de rendu.

--fg=COLOR --success=COLOR --warning=COLOR --error=COLOR

Définit les couleurs symboliques pour recolorer l'icône. Si elles ne sont pas spécifiées, les couleurs par défaut sont utilisées.

--size=SIZE

Définit la taille à laquelle rendre l'icône. La taille peut être un nombre ou une chaîne de la forme LARGEURxHAUTEUR.

Extraire

La commande extract enregistre toutes les url de données trouvées dans un fichier de nœud dans un répertoire donné. Les noms de fichiers pour les fichiers extraits sont dérivés du mimetype de l'url.

--dir=DIRECTORY

Enregistre les fichiers extraits dans DIRECTORY (par défaut, le répertoire courant).
