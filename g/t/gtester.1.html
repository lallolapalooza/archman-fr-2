Nom

gtester - utilitaire d'exécution de tests

SYNTAXE

gtester [OPTION…] programme-de-tests

DESCRIPTION

gtester est un utilitaire permettant d'exécuter des tests unitaires qui ont été écrits à l'aide du framework de test GLib.

Depuis GLib 2.62, gtester-report est obsolète. Utilisez TAP pour le rapport des résultats de tests à la place, et alimentez-le dans le système d'exécution de tests fourni par votre système de construction.

Lorsqu'il est appelé avec l'option -o, gtester écrit un rapport XML des résultats des tests, qui peut être converti en HTML à l'aide de l'utilitaire gtester-report.

OPTIONS

-h, --help

Affiche l'aide et quitte.

-v, --verbose

Affiche les informations de version et quitte.

--g-fatal-warnings

Rend les avertissements fatals.

-k, --keep-going

Continue l'exécution après l'échec des tests.

-l

Liste les chemins des cas de test disponibles.

-m=<MODE>

Exécute les cas de test en MODE, qui peut être l'un des suivants :
  • perf

    Exécute les tests de performance.

  • slow, thorough

    Exécute les tests lents, ou répète plus souvent les tests non déterministes.

  • quick

    Ne pas exécuter les tests lents ou de performance, ou ne pas répéter davantage les tests non déterministes (par défaut).

  • undefined

    Exécute les cas de test qui provoquent délibérément des vérifications ou des échecs d'assertion, s'ils sont implémentés (par défaut).

  • no-undefined

    Ne pas exécuter les cas de test qui provoquent délibérément des vérifications ou des échecs d'assertion.

-p=<CHEMIN-TEST>

N'exécute que les cas de test correspondant à CHEMIN-TEST.

-s=<CHEMIN-TEST>

Ignore les cas de test correspondant à CHEMIN-TEST.

--seed=<CHAÎNE-GRAINE>

Exécute tous les cas de test avec la graine de nombre aléatoire CHAÎNE-GRAINE.

-o=<FICHIER-LOG>

Écrit le journal des tests dans FICHIER-LOG.

-q, --quiet

Supprime la sortie par binaire de test.

--verbose

Rapporte le succès par cas de test.

VOIR AUSSI

gtester-report(1) <man:gtester-report(1)>
