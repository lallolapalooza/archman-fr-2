Nom

gtk4-image-tool - Utilitaire d'image

SYNOPSIS

gtk4-image-tool <COMMANDE> [OPTIONS...] <FICHIER>...
gtk4-image-tool compare [OPTIONS...] <FICHIER1> <FICHIER2>
gtk4-image-tool convert [OPTIONS...] <FICHIER1> <FICHIER2>
gtk4-image-tool info [OPTIONS...] <FICHIER>
gtk4-image-tool relabel [OPTIONS...] <FICHIER1> <FICHIER2>
gtk4-image-tool show [OPTIONS...] <FICHIER>...

DESCRIPTION

gtk4-image-tool peut effectuer diverses opérations sur les images.

COMMANDES

Informations

La commande info affiche des informations générales sur l'image, telles que son format et son état de couleur.

Affichage

La commande show affiche une ou plusieurs images, côte à côte.

--undecorated

Supprime les décorations de fenêtre. Ceci est destiné au rendu exact de l'image sans aucune barre de titre.

Comparaison

La commande compare compare deux images. Si des différences sont trouvées, le code de sortie est 1. Si les images sont identiques, il est 0.

--output=FICHIER

Enregistre les différences sous forme d'image png dans FICHIER.

--quiet

N'écrit pas les résultats sur la sortie standard.

Conversion

La commande convert convertit l'image dans un format ou un état de couleur différent. Le format du fichier de sortie est déterminé par l'extension du nom de fichier.

--format=FORMAT

Convertit vers le format donné. Les formats pris en charge peuvent être listés avec --format=list.

--color-state=COLORSTATE

Convertit vers l'état de couleur donné. Les états de couleur pris en charge peuvent être listés avec --format=list.

--cicp=CICP

Convertit vers un état de couleur spécifié sous forme de tuple cicp. Le tuple cicp doit être spécifié comme quatre nombres, séparés par /, par exemple 1/13/6/0.

Réétiquetage

La commande relabel modifie l'état de couleur d'une image sans conversion. Le format du fichier de sortie est déterminé par l'extension du nom de fichier.

Cela peut être utile pour produire des rendus de couleur incorrects à des fins de diagnostic.

--color-state=COLORSTATE

Réétiquette vers l'état de couleur donné. Les états de couleur pris en charge peuvent être listés avec --format=list.

--cicp=CICP

Réétiquette vers un état de couleur spécifié sous forme de tuple cicp. Le tuple cicp doit être spécifié comme quatre nombres, séparés par /, par exemple 1/13/6/0.
