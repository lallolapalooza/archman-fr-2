NOM

gtk-query-settings - Utilitaire pour afficher le nom et la valeur de toutes les propriétés GtkSettings

SYNOPSIS

gtk-query-settings [MOTIF]

DESCRIPTION

gtk-query-settings affiche le nom et la valeur de toutes les propriétés disponibles dans la classe GtkSettings. Optionnellement, vous pouvez filtrer les propriétés à afficher en spécifiant un MOTIF.
