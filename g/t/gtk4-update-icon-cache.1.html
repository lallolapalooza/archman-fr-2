Nom

gtk4-update-icon-cache - Utilitaire de mise en cache des thèmes d'icônes

SYNOPSIS

gtk4-update-icon-cache [OPTIONS...] <CHEMIN>

DESCRIPTION

gtk4-update-icon-cache crée des fichiers de cache mmap(2)-ables pour les thèmes d'icônes.

Il s'attend à recevoir le CHEMIN vers un répertoire de thème d'icônes contenant un fichier index.theme, par exemple /usr/share/icons/hicolor, et écrit un fichier icon-theme.cache contenant des informations mises en cache sur les icônes dans l'arborescence du répertoire donné.

GTK peut utiliser les fichiers de cache créés par gtk4-update-icon-cache pour éviter de nombreux appels système et des frais généraux de recherche sur disque lors du démarrage de l'application. Étant donné que le format des fichiers de cache permet de les partager entre plusieurs processus, par exemple en utilisant l'appel système POSIX mmap(2), la consommation globale de mémoire est également réduite.

OPTIONS

-f, --force

Écrase un fichier de cache existant même s'il semble à jour.

-t, --ignore-theme-index

Ne vérifie pas l'existence de index.theme dans le répertoire du thème d'icônes. Sans cette option, gtk4-update-icon-cache refuse de créer un cache d'icônes dans un répertoire qui ne semble pas être le répertoire de niveau supérieur d'un thème d'icônes.

-i, --index-only

N'inclut pas les données d'image dans le cache.

--include-image-data

Inclut les données d'image dans le cache.

-c, --source <NOM>

Sort un fichier d'en-tête C déclarant une constante NOM avec le contenu du cache d'icônes.

-q, --quiet

Désactive la sortie verbeuse.

-v, --validate

Valide le cache d'icônes existant.
