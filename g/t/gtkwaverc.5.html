Fichier de configuration pour gtkwave(1). Le chemin de recherche du fichier de configuration (s'il n'est pas spéci

fié) est le répertoire de travail courant sui

lerator>
Cela permet de remplacer les touches d'accélération des menus. Voir le fichier .gtkwaverc dans la distribution source pour des exemples de syntaxe de pathvalue et d'accelerator. La valeur d'accélération spéciale (null) signifie qu'aucune accélération n'est associée à l'élément de

r>
Cela permet d'utiliser un autre caractère en plus du hier_delimeter pour délimiter les niveaux dans la hiérarchie pour VCD. Seul le premier caractère de la valeur est significatif. hiérarchique.

convert_to_reals <valu
e>
Converts all integer and parameter VCD declarations to real-valued ones when set to a nonzero/yes value. The positive aspect of this is that integers and parameters will take up less space in memory and will automatically display in decimal format. The negative aspect of this is that integers and parameters will only be displayable as decimals and can't be bit reversed, inverted,

">
This is used to specify a string (quotes mandatory) for when gtkwave invokes a text editor (e.g., Open Source Definition). Examples are: editor "vimx -g +%d %s", editor "gedit +%d %s", editor "emacs +%d %s", and for OSX, editor "mate -l %d %s". The %d may be combined with other characters in a string such as +, etc. The %s argument must stand by itself. Note that if this rc variable is not set, then the environment variable GTKWAVE_EDITOR will be consulted next, then finally gedit will be used (if found)

use_pango_fonts <valu

Utilise des polices pango anti-crénelées (GTK2) plutôt que des polices X11 matricielles. Par défaut, cette option est

Une valeur non nulle indique que les tracés de vecteurs doivent être dessinés avec des extrémités arrondies plutôt que perpendiculaires. La valeur par défaut pour cela est

use_scrollbar_only <valu
e>
Une valeur non nulle indique que les boutons de page, de décalage, de récupération et d'abandon ne doivent pas être dessinés (c'est-à-dire que les manipulations de temps doivent se faire uniquement via la barre de défilement plutôt que par les boutons du panneau avant). La valeur par défaut pour cela est
zéro.
use_scrollwheel_as_y <valu
e>
Une valeur non nulle indique que la molette de la souris doit être utilisée pour faire défiler les signaux vers le haut et vers le bas plutôt que de faire défiler la valeur temporelle de gauche à

use_standard_clicking <valu
e>

e>
Une valeur non nulle empêche les tracés actuellement sélectionnés de se désélectionner lors de l'appui sur un bouton de la souris. Cela permet au glisser-déposer de fonctionner plus fluidement. Comportement n'étant pas le fonctionnement normal de GTK, cette option est désactivée par

use_toolbutton_interface <valu
e>
Une valeur non nulle indique qu'une barre d'outils avec des boutons doit se trouver en haut de l'écran au lieu des groupes de boutons gtkwave de style traditionnel. Par défaut, cette option est

vcd_explicit_zero_subscripts <valeu
r>
indique que les noms de signaux doivent être stockés internement sous la forme nom.numérobit lorsque cette option est activée. Lorsqu'elle est désactivée, un ordonnancement plus « normal » de nom[numérobit] est utilisé. Notez que lorsque cette option est désactivée, les options Bundle Up et Bundle Down sont désactivées dans les options Signal Search Regexp, Signal Search Hierarchy et Signal Search Tree. Ceci est nécessaire car les structures de données internes des signaux sont représentées avec un niveau de hiérarchie « de moins » que lorsque l'option est activée et que ces fonctions ne fonctionneraient pas correctement. Cela ne devrait pas poser de problème si atomic_vectors sont activés. La valeur par défaut de vcd_explicit_zero_subscripts est
désactivé.
vcd_preserve_glitches <valeu
r>
indique que toute répétition de valeurs égales pour un réseau couvrant différentes valeurs de temps dans le fichier VCD/FST ne doit pas être compressée en un seul changement de valeur mais doit rester afin de permettre la présence de glitches dans ce cas. La valeur par défaut de vcd_preserve_glitches est
désactivé.
vcd_preserve_glitches_real <valeu
r>
indique que toute répétition de valeurs égales pour un réseau réel couvrant différentes valeurs de temps dans le fichier VCD/FST ne doit pas être compressée en un seul changement de valeur mais doit rester dans ce cas. La valeur par défaut de vcd_preserve_glitches est désactivé. L'utilisation prévue est pour la visualisation de données analogiques interpolées afin que la suppression de valeurs dupliquées ne déforme pas incorrectement
l'interpolation.
vcd_warning_filesize <valeu
r>
produit un message d'avertissement si la taille du fichier VCD est supérieure à la taille de l'argument en Mo. Définissez à zéro pour désactiver cette
option.

r>
indique le nombre de pixels d'espace blanc supplémentaire qui doivent être ajoutés à toute chaîne dans le but de calculer le texte dans les vecteurs. Les valeurs autorisées vont de 0 à 16, la valeur par défaut étant
4.
vlist_compression <valeu
r>
indique la valeur à passer à zlib lors du traitement vlist (qui est utilisé dans le recoder VCD). -1 désactive la compression, 0-9 correspondent aux valeurs attendues par zlib. 4 est la valeur par
