gtkgreet(1) Manuel des commandes générales gtkgreet(1)

NOM

gtkgreet - Un greeter basé sur Gtk pour greetd

SYNOPSIS

gtkgreet [options]

OPTIONS

-h, --help

Afficher le message d'aide et quitter.

-c, --command <commande>

Spécifie la commande à exécuter en cas de connexion réussie. gtkgreet demandera si aucune n'est spécifiée.

-l, --layer-shell

Utiliser wlr-layer-shell pour afficher une fenêtre sur chaque sortie. Doit être activé lors de la compilation.

-b, --background

Spécifie une image d'arrière-plan à utiliser par gtkgreet. JPG et PNG sont connus pour fonctionner. L'image sera ancrée dans le coin supérieur gauche et rendue 1:1 lorsque la mise à l'échelle DPI est de 1.

Note : Ceci ne gère pas correctement les valeurs de mise à l'échelle autres que 1. Utilisez une feuille de style pour une rendition d'arrière-plan plus flexible et correcte.

-s, --style <fichier.css>

Spécifie une feuille de style CSS personnalisée avec des styles supplémentaires pour la fenêtre gtkgreet. Voir https://developer.gnome.org/gtk3/stable/theming.html pour la description du sous-ensemble CSS pris en charge dans GTK.

Note : Ceci ne peut pas charger les feuilles de style de thème Gtk, et est uniquement destiné aux modifications au niveau de l'application. Pour sélectionner un thème, utilisez les mécanismes de sélection de thème Gtk habituels.

DESCRIPTION

gtkgreet est un greeter graphique basé sur Gtk pour greetd(1).

gtkgreet permet la sélection de l'application à démarrer lors de la connexion. Voir la section ENVIRONMENTS pour plus d'informations sur la configuration des options fournies. L'utilisateur peut également spécifier l'application directement lors de la connexion en écrivant la ligne de commande souhaitée.

gtkgreet nécessite un compositeur Wayland pour fonctionner, tel que cage(1) ou sway(1).

INSTALLATION

Pour utiliser gtkgreet, configurez un compositeur Wayland de votre choix pour qu'il soit votre greeter. Faites en sorte que le compositeur démarre gtkgreet, et surtout, qu'il s'arrête lui-même une fois que gtkgreet se termine.

En utilisant cage, la ligne de commande devient simplement « cage gtkgreet ».

En utilisant sway(1), on peut utiliser une configuration sway contenant « exec 'gtkgreet; swaymsg exit' », et une ligne de commande similaire à « sway --config /etc/greetd/sway-config ». Le composant « ; swaymg exit » est important, car il fait en sorte que sway se termine une fois que gtkgreet a finalisé une connexion.

Voir greetd(5) pour des informations sur la configuration de greetd. Lisez la documentation de votre compositeur choisi pour savoir comment l'utiliser correctement.

STYLISTIQUE

La feuille de style peut être utilisée pour modifier le style des éléments de gtkgreet, tels que l'arrière-plan de la fenêtre, les polices, le conteneur d'invite de connexion et autres.

Un exemple de feuille de style peut être vu ici :

window {
        background-image: url("file:///etc/greetd/gtkgreet-background.jpg");
        background-size: cover;
        background-position: center;
}
box#body {
        background-color: rgba(50, 50, 50, 0.5);
        border-radius: 10px;
        padding: 50px;
}

ENVIRONNEMENTS

gtkgreet peuple les options utilisateur pour les applications à démarrer lors de la connexion en utilisant à la fois un fichier de configuration et l'argument de ligne de commande '-c'.

Le fichier de configuration est lu à partir de /etc/greetd/environments, et est une liste d'options séparées par des nouvelles lignes, chacune étant une ligne de commande à exécuter lors de la connexion si sélectionnée.
