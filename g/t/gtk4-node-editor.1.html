Nom

gtk4-node-editor - Afficher et modifier les fichiers de nœuds de rendu

SYNOPSIS

gtk4-node-editor [OPTIONS...] [FICHIER]

DESCRIPTION

gtk4-node-editor est un utilitaire pour afficher et modifier les fichiers de nœuds de rendu. Ces fichiers de nœuds de rendu peuvent être obtenus par exemple à partir de l'inspecteur GTK ou dans le cadre de la suite de tests dans les sources de GTK.

gtk4-node-editor est utilisé par les développeurs GTK pour le débogage et les tests, et il prend en charge l'enregistrement de cas de test dans le cadre de la suite de tests GTK.

OPTIONS

-h, --help

Affiche l'aide de l'application.

--version

Affiche la version du programme.

--reset

Ne restaure pas le contenu sauvegardé automatiquement et supprime les fichiers de sauvegarde automatique.

ENVIRONNEMENT

GTK_SOURCE_DIR

peut être défini pour pointer vers l'emplacement où résident les sources GTK, afin que les cas de test puissent être enregistrés au bon endroit. Si cette variable n'est pas utilisée, gtk4-node-editor vérifie si le répertoire de travail actuel ressemble à un checkout GTK, et à défaut, enregistre le cas de test dans le répertoire de travail actuel.
