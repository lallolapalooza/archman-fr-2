NOM

gtk-query-immodules-3.0 - Utilitaire d'enregistrement des modules de méthodes d'entrée

SYNTAXE

gtk-query-immodules-3.0 [--update-cache] [MODULE...]

DESCRIPTION

gtk-query-immodules-3.0 collecte des informations sur les modules de méthodes d'entrée chargeables pour GTK+ et les écrit à l'emplacement de cache par défaut, ou sur la sortie standard.

S'il est appelé sans arguments, il recherche les modules dans le chemin des modules de méthodes d'entrée GTK+.

S'il est appelé avec des arguments, il recherche les modules spécifiés. Les arguments peuvent être des chemins absolus ou relatifs.

Normalement, la sortie de gtk-query-immodules-3.0 est écrite dans libdir/gtk-3.0/3.0.0/immodules.cache, où GTK+ la recherche par défaut. Si elle est écrite à un autre emplacement, la variable d'environnement GTK_IM_MODULE_FILE peut être définie pour indiquer à GTK+ l'emplacement du fichier.

OPTIONS

--update-cache

Écrit la sortie à l'emplacement de cache par défaut au lieu de la sortie standard

FICHIERS

libdir/gtk-3.0/3.0.0/immodules.cache

Le fichier de cache im par défaut utilisé par les applications GTK+

ENVIRONNEMENT

GTK_PATH

Ajoute des répertoires au chemin des modules de méthodes d'entrée

GTK_IM_MODULE_FILE

Spécifie un cache de modules im alternatif pour les applications GTK+
