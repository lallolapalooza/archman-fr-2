NOM

gspath - Utilitaires pour afficher les informations standard sur les répertoires/chemins

SYNTAXE

gspath

DESCRIPTION

Cet utilitaire peut être utilisé pour imprimer un répertoire ou un chemin unique afin que les applications externes sachent quels chemins le système GNUstep utilise. Il a été écrit pour fournir des informations pour le paquet make de GNUstep.

L'utilitaire gspath est appelé avec exactement un argument, qui détermine ce qu'il imprime.

Arguments

Pour afficher le chemin du répertoire des defaults pour l'utilisateur actuel, utilisez l'argument defaults.

Pour afficher le chemin de recherche des répertoires nécessaire pour localiser les bibliothèques dynamiques, utilisez l'argument libpath.

Pour afficher le chemin de recherche des répertoires nécessaire pour localiser les programmes en ligne de commande, utilisez l'argument path.

Pour afficher le répertoire d'accueil GNUstep de l'utilisateur actuel, utilisez l'argument user.
