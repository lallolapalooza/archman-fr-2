gsound-play(1)

Paquet: gsound

Licences: LGPL

GSound(1) Manuel des commandes générales GSound(1)

NOM

GSound - une petite bibliothèque pour jouer des sons système

SYNTAXE

gsound-play [options]

DESCRIPTION

gsound-play est un petit programme pour jouer des sons.

OPTIONS

-h, --help
Afficher les options d'aide.
-i, --id=CHAÎNE
Identifiant du son d'événement.
-f, --file=CHEMIN
Jouer le fichier.
-d, --description=CHAÎNE
Description du son d'événement.
-c, --cache-control=CHAÎNE
Contrôle du cache (permanent, volatil, jamais).
-l, --loop=ENTIER
Boucler plusieurs fois (par défaut : 1).
-v, --volume=CHAÎNE
Une valeur flottante en dB pour le volume de l'échantillon (ex : 0.0).
-b, --backend=CHAÎNE
Backend libcanberra à utiliser.

VOIR AUSSI

Pour plus d'informations, visitez le site web https://wiki.gnome.org/Projects/GSound

BOGUES

Tous les bugs de l'application peuvent être signalés sur le Gitlab de GNOME à https://gitlab.gnome.org/GNOME/gsound/-/issues
