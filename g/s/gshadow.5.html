GSHADOW(5) Formats et configuration de fichiers GSHADOW(5)

NOM

gshadow - fichier de groupe mis en ombre

DESCRIPTION

Le fichier /etc/gshadow contient les informations mises en ombre pour les comptes de groupe.

Ce fichier ne doit pas être lisible par les utilisateurs ordinaires si la sécurité des mots de passe doit être maintenue.

Chaque ligne de ce fichier contient les champs suivants séparés par des deux-points :

Nom du groupe

Il doit s'agir d'un nom de groupe valide, qui existe sur le système.

Mot de passe chiffré

Consultez crypt(3) pour plus de détails sur la manière dont cette chaîne est interprétée.

Si le champ du mot de passe contient une chaîne qui n'est pas un résultat valide de crypt(3), par exemple ! ou *, les utilisateurs ne pourront pas utiliser un mot de passe Unix pour accéder au groupe (mais les membres du groupe n'ont pas besoin du mot de passe).

Le mot de passe est utilisé lorsqu'un utilisateur qui n'est pas membre du groupe souhaite obtenir les permissions de ce groupe (voir newgrp(1)).

Ce champ peut être vide, auquel cas seuls les membres du groupe peuvent obtenir les permissions du groupe.

Un champ de mot de passe qui commence par un point d'exclamation signifie que le mot de passe est verrouillé. Les caractères restants sur la ligne représentent le champ du mot de passe avant que le mot de passe ne soit verrouillé.

Ce mot de passe remplace tout mot de passe spécifié dans /etc/group.

Administrateurs

Il doit s'agir d'une liste de noms d'utilisateurs séparés par des virgules.

Les administrateurs peuvent changer le mot de passe ou les membres du groupe.

Les administrateurs ont également les mêmes permissions que les membres (voir ci-dessous).

Membres

Il doit s'agir d'une liste de noms d'utilisateurs séparés par des virgules.

Les membres peuvent accéder au groupe sans qu'on leur demande de mot de passe.

Vous devriez utiliser la même liste d'utilisateurs que dans /etc/group.

FICHIERS

/etc/group

Informations sur les comptes de groupe.

/etc/gshadow

Informations sécurisées sur les comptes de groupe.

VOIR AUSSI

gpasswd(5), group(5), grpck(8), grpconv(8), newgrp(1).
