NOM

gsasl_session_hook_get - Fonction de l'API

SYNTAXE

#include <gsasl.h>

void * gsasl_session_hook_get(Gsasl_session * sctx);

ARGUMENTS

Gsasl_session * sctx
Handle de session libgsasl.

DESCRIPTION

Récupère les données spécifiques à l'application depuis le handle de session libgsasl.

Les données de l'application sont définies à l'aide de gsasl_callback_hook_set(). Ceci est normalement utilisé par l'application pour maintenir un état par session entre le programme principal et les callbacks.

Valeur de retour : Renvoie les données spécifiques à l'application, ou NULL.
