NOM

gsasl_register - fonction API

SYNOPSIS

#include <gsasl.h>

int gsasl_register(Gsasl * ctx, const Gsasl_mechanism * mech);

ARGUMENTS

Gsasl * ctx
pointeur vers le handle libgsasl.
const Gsasl_mechanism * mech
structure de plugin avec des informations sur le plugin.

DESCRIPTION

Cette fonction initialise le mécanisme donné, et si elle réussit, l'ajoute à la liste des plugins utilisés par la bibliothèque.

Valeur de retour : GSASL_OK en cas de succès, sinon GSASL_MALLOC_ERROR.
