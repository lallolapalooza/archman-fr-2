NOM

gsasl_callback_hook_get - Fonction API

SYNTAXE

#include <gsasl.h>

void * gsasl_callback_hook_get(Gsasl * ctx);

ARGUMENTS

Gsasl * ctx
Handle libgsasl.

DESCRIPTION

Récupère les données spécifiques à l'application à partir du handle libgsasl.

Les données de l'application sont définies à l'aide de gsasl_callback_hook_set(). Ceci est normalement utilisé par l'application pour maintenir un état global entre le programme principal et les rappels.

Valeur de retour : Retourne les données spécifiques à l'application, ou NULL.
