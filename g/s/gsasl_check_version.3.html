NOM

gsasl_check_version - Fonction API

SYNTAXE

#include <gsasl.h>

const char * gsasl_check_version(const char * req_version);

ARGUMENTS

const char * req_version
chaîne de version à comparer, ou NULL.

DESCRIPTION

Vérifie la version de la bibliothèque GNU SASL.

Voir GSASL_VERSION pour une chaîne req_version adéquate.

Cette fonction est l'une des rares de la bibliothèque à pouvoir être utilisée sans un appel réussi à gsasl_init().

Valeur de retour : Vérifie que la version de la bibliothèque est au minimum celle fournie sous forme de chaîne dans req_version et renvoie la chaîne de version réelle de la bibliothèque ; renvoie NULL si la condition n'est pas remplie. Si NULL est passé à cette fonction, aucune vérification n'est effectuée et seule la chaîne de version est renvoyée.
