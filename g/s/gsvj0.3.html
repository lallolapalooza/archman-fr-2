sous-routine cgsvj0 (character*1 jobv, integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( n ) d, real, dimension( n ) sva, integer mv, complex, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, complex, dimension( lwork ) work, integer lwork, integer info)

CGSVJ0 préprocesseur pour la sous-routine cgesvj.

Objectif :

!>
!> CGSVJ0 est appelée depuis CGESVJ en tant que préprocesseur et c'est son objectif principal. Elle applique des rotations de Jacobi de la même manière que CGESVJ, mais elle ne vérifie pas la convergence (critère d'arrêt). Quelques paramètres d'ajustement (marqués par [TP]) sont disponibles pour l'implémenteur.
!>

Paramètres

JOBV 
!>          JOBV est CHARACTER*1
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V': le produit des rotations de Jacobi est accumulé
!>                 par post-multiplication du tableau V de taille N par N.
!>                (Voir la description de V.)
!>          = 'A': le produit des rotations de Jacobi est accumulé
!>                 par post-multiplication du tableau V de taille MV par N.
!>                (Voir les descriptions de MV et V.)
!>          = 'N': les rotations de Jacobi ne sont pas accumulées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, matrice A de taille M par N, telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          À la sortie,
!>          A_en_sortie * diag(D_en_sortie) représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés respectivement
!>          dans TOL et NSWEEP.
!>          (Voir les descriptions de D, TOL et NSWEEP.)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est un tableau COMPLEXE, de dimension (N)
!>          Le tableau D accumule les facteurs de mise à l'échelle des rotations
!>          de Jacobi complexes mises à l'échelle.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_en_sortie*diag(D_en_sortie) représente la matrice d'entrée
!>          post-multipliée par une séquence de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés respectivement
!>          dans TOL et NSWEEP.
!>          (Voir les descriptions de A, TOL et NSWEEP.)
!>

SVA

!>          SVA est un tableau REEL, de dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes de
!>          la matrice A_en_sortie*diag(D_en_sortie).
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!>

V

!>          V est un tableau COMPLEXE, de dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par une
!>                           séquence de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS est REAL
!>          EPS = SLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN est REAL
!>          SFMIN = SLAMCH('Safe Minimum')
!>

TOL

!>          TOL est REAL
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          A(:,p), A(:,q) de colonnes pivots, la rotation de Jacobi est
!>          appliquée uniquement si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP est INTEGER
!>          NSWEEP est le nombre de balayages de rotations de Jacobi à effectuer.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          LWORK est la dimension de WORK. LWORK >= M.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
