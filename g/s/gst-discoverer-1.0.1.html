NOM

gst-discoverer-1.0 - Affiche les métadonnées de fichier et les informations de flux

SYNTAXE

gst-discoverer-1.0 FICHIER|RÉPERTOIRE|URI [FICHIER2|RÉPERTOIRE2|URI2]

DESCRIPTION

gst-discoverer-1.0 est un outil qui peut être utilisé pour afficher les métadonnées de base et les informations de flux d'un fichier multimédia. Il peut être exécuté sur des fichiers individuels ou des répertoires entiers. Dans ce dernier cas, il parcourra les sous-répertoires de manière récursive.

OPTIONS

gst-discoverer-1.0 accepte les options suivantes :

--help
Affiche le synopsis d'aide et les FLAGS disponibles
-v, --verbose
Affiche toutes les informations disponibles
-a, --async
Utilise le chemin de code asynchrone
-t, --timeout=T
Spécifie le délai d'attente en secondes (défaut : 10 secondes)
-c, --toc
Affiche la Table des matières (chapitres et éditions) si disponible
