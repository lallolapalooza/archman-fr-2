NOM

gsf - utilitaire d'archivage utilisant la bibliothèque G Structured File

SYNTAXE

gsf [OPTION...] SOUSCOMMANDE ARCHIVE...

DESCRIPTION

Cette page de manuel documente brièvement la commande gsf.

gsf est un utilitaire d'archive simple, quelque peu similaire à tar(1). Il opère sur des fichiers suivant l'un des formats de fichiers structurés compris par la bibliothèque G Structured File, par exemple, les fichiers Microsoft Excel(TM).

OPTIONS

Options

-?, --help
Afficher les options d'aide
-v, --version
Afficher la version de gsf

Sous-commandes

cat
Afficher un ou plusieurs fichiers de l'archive
dump
Exporter un ou plusieurs fichiers de l'archive en hexadécimal formaté
help
Lister les sous-commandes
list
Lister les fichiers dans l'archive
props
Lister les noms des propriétés de l'archive

EXEMPLES

Pour lister la structure de contenu d'un fichier Microsoft Excel(TM) arrays.xls :

gsf list arrays.xls

Pour exporter Workbook, un flux de données individuel dans arrays.xls :

gsf dump arrays.xls Workbook
