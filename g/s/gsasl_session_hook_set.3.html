NOM

gsasl_session_hook_set - Fonction API

SYNTAXE

#include <gsasl.h>

void gsasl_session_hook_set(Gsasl_session * sctx, void * hook);

ARGUMENTS

Gsasl_session * sctx
handle de session libgsasl.
void * hook
pointeur opaque vers des données spécifiques à l'application.

DESCRIPTION

Stocker des données spécifiques à l'application dans le handle de session libgsasl.

Les données de l'application peuvent être ultérieurement (par exemple, dans une fonction de rappel) récupérées en appelant gsasl_session_hook_get(). Ceci est normalement utilisé par l'application pour maintenir un état par session entre le programme principal et les fonctions de rappel.
