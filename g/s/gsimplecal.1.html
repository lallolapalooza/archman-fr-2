Description des options de configuration
Les options sont assez explicites, mais voici une description détaillée :
show_calendar
: 1 ou 0, valeur par défaut 1.
Définit si le calendrier doit être affiché. La plupart des utilisateurs veulent que cette option soit à 1.
show_timezones : 1 ou 0, valeur par défaut 0.
Définit si les horloges des différents fuseaux horaires doivent être affichées.
mark_today
: 1 ou 0, valeur par défaut 1.
Définit si la date du jour sera marquée dans le calendrier (en plus de la sélection par défaut, c'est-à-dire lorsque vous cliquez sur un autre jour, aujourd'hui restera marqué d'une manière ou d'une autre, par exemple en gras).
show_week_numbers
: 1 ou 0, valeur par défaut 0.
Définit si les numéros de semaine sont affichés dans le calendrier.
close_on_unfocus : 1 ou 0, valeur par défaut 0.
Définit si le calendrier se fermera si la fenêtre perd le focus. Notez que si mainwindow_skip_taskbar est défini à 1, la fenêtre du calendrier peut ne pas recevoir le focus lors de sa création.
close_on_mouseleave
: 1 ou 0, valeur par défaut 0.
Définit si le calendrier se fermera si le pointeur de la souris quitte la fenêtre.

clock_labe
l
et clock_tz : cha

Ces deux options doivent aller en paires et **doivent** être dans l'ordre indiqué.
Chaque paire crée une nouvelle horloge. La variable `clock_label` définit la chaîne de caractères à afficher près de l'horloge, `clock_tz` définit le fuseau horaire.
Si vous omettez la valeur pour `clock_tz`, l'heure locale sera affichée.
Pour savoir comment spécifier un fuseau horaire différent, consultez man timezone. Il s'agit généralement d'une chaîne de caractères au format « :{Région}/{Lieu} », mais il s'agit en réalité d'un deux-points suivi du chemin relatif vers le fichier qui stocke les informations de fuseau horaire. Le répertoire contenant les fichiers est généralement /usr/share/zoneinfo, il suffit donc de consulter le contenu du répertoire et de choisir les fichiers dont vous avez besoin.

RACCOURCIS CLAVIER

Vous pouvez utiliser les raccourcis clavier suivants lorsque la fenêtre de gsimplecal est active (pas encore configurable) :

Échap, Ctrl+w, Ctrl+q
Fermer la fenêtre.
Entrée
Exécuter le visualiseur externe sur le jour sélectionné.
n
Passer au mois suivant.
p
Passer au mois précédent.
N
Avancer d'un an.
P
Reculer d'un an.
hjkl
Navigation dans les dates style Vi :

h -> gauche

j -> bas

k -> haut

l -> droite

g, Début
Aller à la date actuelle.
