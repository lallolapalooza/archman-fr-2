GS-MOUNT(1) Manuel des commandes générales GS-MOUNT(1)

NOM

gs-mount — Client de système de fichiers sécurisé via le Socket Global.

SYNTAXE

gs-mount [-lTR] [-s secret] [-k fichier_clé] [point_montage]

DESCRIPTION

L'utilitaire gs-mount est un script wrapper pour gs-netcat. Il permet à un utilisateur de monter et d'accéder à un système de fichiers à partir d'un autre utilisateur via le Réseau de Relais par Socket Global (GSRN). Ceci est utile dans un scénario où les deux utilisateurs sont derrière un NAT/Pare-feu et incapables de se connecter directement l'un à l'autre.

OPTIONS

-s secret
Un mot de passe choisi par l'utilisateur. Les deux utilisateurs doivent utiliser le même mot de passe pour se connecter.
-k FICHIER
Un fichier contenant le mot de passe.
-l
Mode serveur. Le mode par défaut est client.
-R
Place le serveur (-l) en mode lecture seule. Les tentatives d'ouverture de fichiers en écriture, ainsi que d'autres opérations qui modifient l'état du système de fichiers, seront refusées.
-T
Utiliser TOR. L'outil gs-mount se connectera via TOR au GSRN. Cela nécessite que TOR soit installé et en cours d'exécution. L'adresse IP et le PORT du serveur TOR peuvent être définis à l'aide de variables d'environnement.

Voir gs-netcat(1) pour plus d'options.

EXEMPLES

Exemple 1 - Alice partage son répertoire actuel :

$ gs-mount -s MonSecret -l

Bob monte le répertoire d'Alice dans ~/gs-alice :

$ gs-mount -s MonSecret ~/gs-alice

ENVIRONNEMENT

Voir gs-netcat(1) pour une liste des variables d'environnement prises en charge.

VOIR AUSSI

gsocket(1), gs-netcat(1), gs-sftp(1), blitz(1), sshfs(1)

BOGUES

Des efforts ont été faits pour que gs-mount "fasse la bonne chose" dans tous ses modes variés. Si vous pensez qu'il fait la mauvaise chose dans quelles que soient les circonstances, veuillez m'en informer (skyper@thc.org) et me dire comment vous pensez qu'il devrait se comporter.
