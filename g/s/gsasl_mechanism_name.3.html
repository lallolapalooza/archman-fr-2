NOM

gsasl_mechanism_name - fonction API

SYNOPSIS

#include <gsasl.h>

const char * gsasl_mechanism_name(Gsasl_session * sctx);

ARGUMENTS

Gsasl_session * sctx
handle de session libgsasl.

DESCRIPTION

Cette fonction retourne le nom du mécanisme SASL utilisé dans la session. Le pointeur ne doit pas être désalloué par l'appelant.

Valeur de retour : Renvoie un tableau de caractères terminé par un zéro avec le nom du mécanisme SASL, ou NULL si non connu.
