NOM

gsf-vba-dump - extraire les macros Visual Basic for Applications

SYNTAXE

gsf-vba-dump [FICHIER]...

DESCRIPTION

Cette page de manuel documente brièvement la commande gsf-vba-dump.

Divers formats de données binaires de Microsoft, y compris Excel (.xls), Word (.doc) et PowerPoint (.ppt) peuvent intégrer des flux de code de macro. Ces flux de macro sont en P-code (langage intermédiaire) compilé à partir de Visual Basic for Applications (VBA).

L'utilitaire gsf-vba-dump extrait ces flux de macro.

BOGUES

L'extraction de macros à partir de fichiers Powerpoint (.ppt) n'a pas encore été implémentée.
