NOM

gsl - Bibliothèque scientifique GNU

SYNTAXE

#include <gsl/...>

DESCRIPTION

La bibliothèque scientifique GNU (GSL) est une collection de routines pour le calcul numérique. Les routines sont écrites à partir de zéro par l'équipe GSL en C, et présentent une interface de programmation d'applications (API) moderne pour les programmeurs C, permettant la création de wrappers pour des langages de très haut niveau.

La bibliothèque couvre les domaines suivants,

Nombres complexes
Racines de polynômes
Fonctions spéciales
Vecteurs et Matrices
Permutations
Combinaisons
Tri
Support BLAS
Algèbre linéaire
Systèmes propres
Transformées de Fourier rapides
Quadrature
Nombres aléatoires
Suites quasi-aléatoires
Distributions aléatoires
Statistiques
Histogrammes
N-uplets
Intégration Monte Carlo
Recuit simulé
Équations différentielles
Interpolation
Différentiation numérique
Approximations de Chebyshev
Accélération de séries
Transformées de Hankel discrètes
Recherche de racines
Minimisation
Ajustement par moindres carrés
Constantes physiques
Flottants IEEE

Pour plus d'informations, veuillez consulter le Manuel de référence de la GSL, disponible sous forme de fichier info. Vous pouvez le lire en ligne en utilisant la commande shell info gsl-ref (si la bibliothèque est installée).

Veuillez signaler tout bug à bug-gsl@gnu.org.
