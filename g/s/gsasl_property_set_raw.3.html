NOM

gsasl_property_set_raw - fonction API

SYNOPSIS

#include <gsasl.h>

int gsasl_property_set_raw(Gsasl_session * sctx, Gsasl_property prop, const char * data, size_t len);

ARGUMENTS

Gsasl_session * sctx
handle de session.
Gsasl_property prop
valeur énumérée de type Gsasl_property, indiquant le type de données dans data .
const char * data
chaîne de caractères à stocker.
size_t len
longueur de la chaîne de caractères à stocker.

DESCRIPTION

Fait une copie de data de taille len et en stocke une version terminée par zéro dans le handle de session pour la propriété indiquée prop .

Vous pouvez libérer immédiatement data après avoir appelé cette fonction, sans affecter les données stockées dans le handle de session.

À l'exception de l'indicateur de longueur, cette fonction est identique à gsasl_property_set.

Valeur de retour : GSASL_OK si succès, sinon GSASL_MALLOC_ERROR.
