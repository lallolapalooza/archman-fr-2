NOM

gsound - Outil pour effectuer des entrées/sorties audio avec le générateur de sons gensio

SYNTAXE

gsound [-r|--rate num] [-n|--nbufs num] [-c|--channels num] [-s|--bufsize num] [-t|--type num] [-f|--format str] [-p|--play] [-L|--list-devs] [-d|--debug] [-h|--help] <périphérique> [<fichier>]

DESCRIPTION

Le programme gsound vous permet d'enregistrer/reproduire du son vers/depuis le périphérique audio spécifié. Les données audio vont vers/depuis un fichier, ou le flux standard si aucun fichier n'est donné.

OPTIONS

-r|--rate num
Le taux d'échantillonnage, par défaut 44100.
-n|--nbufs num
Le nombre de tampons, par défaut 4.
-c|--channels num
Le nombre de canaux, par défaut 1.
-s|--bufsize num
La taille du tampon, par défaut 2048.
-t|--type num
Le type d'interface, soit alsa (Linux), win (Windows), portaudio (généralement MacOS) ou file. Par défaut alsa, win, ou portaudio selon la plateforme.
-f|--format str
Le format d'entrée/sortie. Par défaut float. Peut être l'un des suivants : double, float, int32, int24, int16, ou int8.
-p|--play
Lecture des données depuis l'entrée standard. Par défaut, enregistre les données vers la sortie standard.
-L|--list-devs
Liste les périphériques disponibles et quitte.
-d|--debug
Active le débogage. Spécifiez plusieurs fois pour augmenter le niveau de débogage.
-h|--help
Aide.
