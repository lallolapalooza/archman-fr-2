NOM

gsasl_property_set - fonction API

SYNTAXE

#include <gsasl.h>

int gsasl_property_set(Gsasl_session * sctx, Gsasl_property prop, const char * data);

ARGUMENTS

Gsasl_session * sctx
gestionnaire de session.
Gsasl_property prop
valeur énumérée du type Gsasl_property, indiquant le type de données dans data .
const char * data
chaîne de caractères terminée par un zéro à stocker.

DESCRIPTION

Fait une copie de data et la stocke dans le gestionnaire de session pour la propriété indiquée prop .

Vous pouvez immédiatement libérer data après avoir appelé cette fonction, sans affecter les données stockées dans le gestionnaire de session.

Valeur de retour : GSASL_OK si succès, sinon GSASL_MALLOC_ERROR.
