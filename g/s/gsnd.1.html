GSND(1) Ghostscript GSND(1)

NOM

gsnd - Exécute Ghostscript (moteur PostScript et PDF) sans affichage

SYNTAXE

gsnd [ options ] [ fichiers ] ...

DESCRIPTION

Ce script invoque simplement gs(1) avec l'indicateur -NODISPLAY, suivi de tout autre argument de la ligne de commande.

VOIR AUSSI

gs(1)

VERSION

Ce document a été révisé pour la dernière fois pour la version 10.04.0 de Ghostscript.
