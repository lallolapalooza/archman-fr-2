NOM

gst-typefind-1.0 - imprime le type de média d'un fichier

SYNTAXE

gst-typefind-1.0 <fichier>

DESCRIPTION

gst-typefind-1.0 utilise le système de recherche de types de GStreamer pour déterminer le plugin GStreamer pertinent pour analyser ou décoder fichier, et le type de média correspondant.

OPTIONS

gst-typefind-1.0 accepte les options suivantes :

--help
Imprimer le synopsis d'aide et les DRAPEAUX disponibles
--gst-info-mask=DRAPEAUX
GStreamer masques d'information à définir (liste avec --help)
--gst-debug-mask=DRAPEAUX
GStreamer masques de débogage à définir (liste avec --help)
--gst-mask=DRAPEAUX
GStreamer masques d'information et de débogage à définir (liste avec --help)
--gst-plugin-path=CHEMIN
Ajouter des répertoires séparés par ':' au chemin de recherche des plugins

VOIR AUSSI

gst-inspect-1.0(1), gst-launch-1.0(1)
