NOM

gsasl_init - Fonction de l'API

SYNTAXE

#include <gsasl.h>

int gsasl_init(Gsasl ** ctx);

ARGUMENTS

Gsasl ** ctx
pointeur vers le handle de libgsasl.

DESCRIPTION

Cette fonction initialise libgsasl. Le handle pointé par ctx est valide pour une utilisation avec d'autres fonctions libgsasl si cette fonction réussit. Elle enregistre également tous les mécanismes SASL intégrés, en utilisant gsasl_register().

Valeur de retour : GSASL_OK si succès, sinon GSASL_MALLOC_ERROR.
