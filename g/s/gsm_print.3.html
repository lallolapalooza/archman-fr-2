gsm_print(3)

Paquet: gsm

Licences: custom

GSM_PRINT(3) Manuel des fonctions de bibliothèque GSM_PRINT(3)

NOM

gsm_print — Fonction supplémentaire de GSM 06.10 pour le débogage

SYNTAXE

#include "gsm.h" #include <stdio.h>

int gsm_print(f, g, frame);
FILE * f;
gsm g;
gsm_frame frame;

DESCRIPTION

Gsm est une implémentation du projet final de la norme GSM 06.10 pour le transcodage vocal pleine fréquence, un algorithme de compression vocale avec pertes. La forme compressée implique 76 variables avec différents nombres de bits significatifs empaquetés dans 33 octets.

Si vous souhaitez étudier les détails de ce schéma de codage, gsm_print() peut être utilisé pour vider le contenu des gsm_frames individuels dans un pointeur de fichier fourni par l'application.

VALEUR DE RETOUR

gsm_print() retourne -1 si l'image est invalide, sinon 0.

EXEMPLE

Une seule image ressemble à ceci : 

LARc:   29  32  20  11  08  05  06  07
#1:     Nc 0040    bc 0    Mc 1    xmaxc 60
        06 04 00 03 03 06 04 02 02 04 05 04 01
#2:     Nc 0045    bc 1    Mc 1    xmaxc 48
        03 07 01 03 04 04 07 01 03 02 04 05 03
#3:     Nc 0091    bc 1    Mc 1    xmaxc 46
        00 03 03 07 01 06 02 04 05 03 03 02 04
#4:     Nc 0120    bc 0    Mc 1    xmaxc 47
        07 03 06 00 03 03 06 05 00 03 02 07 04
