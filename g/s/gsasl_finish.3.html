NOM

gsasl_finish - Fonction de l'API

SYNTAXE

#include <gsasl.h>

void gsasl_finish(Gsasl_session * sctx);

ARGUMENTS

Gsasl_session * sctx
Handle de session libgsasl.

DESCRIPTION

Détruit un handle client ou serveur libgsasl. Le handle ne doit pas être utilisé avec d'autres fonctions libgsasl après cet appel.
