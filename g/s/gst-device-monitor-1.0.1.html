NOM

gst-device-monitor-1.0 - Outil de test simple en ligne de commande pour les moniteurs de périphériques GStreamer

SYNTAXE

gst-device-monitor-1.0 [CLASSES_DE_PERIPHERIQUES[:CAPS_FILTRE]] [CLASSES_DE_PERIPHERIQUES[:CAPS_FILTRE]]

DESCRIPTION

gst-device-monitor-1.0 est un outil en ligne de commande qui peut être utilisé pour tester la fonctionnalité de surveillance des périphériques de GStreamer. Par défaut, il affiche simplement une liste de tous les périphériques trouvés et se termine, mais vous pouvez également le faire attendre d'autres périphériques en passant l'option --follow. Vous pouvez également lui passer un ou plusieurs arguments de filtre pour filtrer le type de périphériques qui vous intéressent.

OPTIONS

gst-device-monitor-1.0 accepte les options suivantes :

--help
Affiche la syntaxe d'aide et les options de ligne de commande disponibles
--version
Affiche la version et quitte
-f, --follow
Ne quitte pas après avoir montré la liste initiale des périphériques, mais attend que des périphériques soient ajoutés ou supprimés
-i, --include-hidden
Inclut les périphériques des fournisseurs de périphériques cachés.

EXEMPLES

gst-device-monitor-1.0

gst-device-monitor-1.0 --follow
gst-device-monitor-1.0 Audio/Source
gst-device-monitor-1.0 Video/Source:video/x-raw
gst-device-monitor-1.0 -i Audio/Sink
