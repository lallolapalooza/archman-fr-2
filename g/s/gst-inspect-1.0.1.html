NOM

gst-inspect-1.0 - afficher des informations sur un plugin ou un élément GStreamer

SYNTAXE

gst-inspect-1.0 [OPTION...] [PLUGIN|ÉLÉMENT]

DESCRIPTION

gst-inspect-1.0 est un outil qui affiche des informations sur les plugins GStreamer disponibles, des informations sur un plugin particulier, ou des informations sur un élément particulier. Lorsqu'il est exécuté sans argument PLUGIN ou ÉLÉMENT, gst-inspect-1.0 affichera une liste de tous les plugins et éléments accompagnée d'un résumé. Lorsqu'il est exécuté avec un argument PLUGIN ou ÉLÉMENT, gst-inspect-1.0 affichera des informations sur ce plugin ou élément.

OPTIONS

gst-inspect-1.0 accepte les arguments et options suivants :

PLUGIN
Nom d'un plugin
ÉLÉMENT
Nom d'un élément
--help
Afficher la syntaxe d'aide et les DRAPEAUX disponibles
--gst-info-mask=DRAPEAUX
Drapeaux d'information GStreamer à définir (liste avec --help)
-a, --print-all
Afficher tous les plugins et éléments
-b, --print-blacklist
Afficher la liste des fichiers mis en liste noire
--plugin
Lister le contenu du plugin
--types=Élément/Types
Permet d'inspecter uniquement les éléments qui correspondent à tous les types d'éléments filtrés dans cette liste de types d'éléments séparés par des slashs ('/'). Ces types correspondent à ce qui est aussi appelé 'klass', qui est une chaîne décrivant le type d'élément, comme 'Decoder', 'Audio', 'Encoder', etc... Cette option implique que seuls les éléments seront affichés (pas les fonctions de recherche de type ou les traceurs).
--exists
Vérifier si l'élément ou le plugin spécifié existe
--atleast-version
Lors de la vérification si un élément ou un plugin existe, vérifier également que sa version est au moins égale à la version spécifiée
-u, --uri-handlers
Afficher les schémas URI pris en charge, avec les éléments qui les implémentent
--no-colors
Désactiver les couleurs dans la sortie. Vous pouvez également obtenir le même résultat en définissant la variable d'environnement 'GST_INSPECT_NO_COLORS' à n'importe quelle valeur.
-C, --color
Colorer la sortie, même lorsqu'elle n'est pas connectée à un tty.
--print-plugin-auto-install-info
Afficher une liste d'informations analysables par machine que le plugin spécifié fournit. Utile en combinaison avec des mécanismes externes d'installation automatique de plugins.
--gst-debug-mask=DRAPEAUX
Drapeaux de débogage GStreamer à définir (liste avec --help)
--gst-mask=DRAPEAUX
Drapeaux d'information et de débogage GStreamer à définir (liste avec --help)
--gst-plugin-path=CHEMIN
Ajouter des répertoires séparés par ':' au chemin de recherche des plugins

VARIABLES D'ENVIRONNEMENT

gst-inspect-1.0 lit les variables d'environnement suivantes, en plus des variables d'environnement génériques GStreamer également décrites dans gst-launch-1.0(1) :

GST_LESS
Remplacer les options passées à less (par défaut "RXF").
Voir less(1) pour plus d'informations.
