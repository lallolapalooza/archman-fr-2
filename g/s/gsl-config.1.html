NOM

gsl-config - script pour obtenir le numéro de version et les indicateurs du compilateur de la bibliothèque GSL installée

SYNTAXE

gsl-config [--prefix] [--version] [--libs] [--libs-without-cblas] [--cflags]

DESCRIPTION

gsl-config est un outil utilisé pour configurer et déterminer les indicateurs du compilateur et de l'éditeur de liens qui devraient être utilisés pour compiler et lier des programmes utilisant GSL. Il est également utilisé en interne par les macros .m4 pour GNU autoconf qui sont incluses avec GSL.

OPTIONS

gsl-config accepte les options suivantes :

--version
Affiche la version actuellement installée de GSL sur la sortie standard.
--libs
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme GSL, avec cblas
--libs-without-cblas
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme GSL, sans cblas
--cflags
Affiche les indicateurs du compilateur qui sont nécessaires pour compiler un programme GSL.
--prefix
Affiche le préfixe d'installation de GSL.
