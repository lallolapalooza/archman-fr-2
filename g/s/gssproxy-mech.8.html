GSSPROXY-MECH(8) Mécanisme GSSAPI GssProxy GSSPROXY-MECH(8)

NOM

gssproxy-mech - Plugin de mécanisme GSSAPI GssProxy

SYNTAXE

proxymech_v1 2.16.840.1.113730.3.8.15.1 /usr/lib64/gssproxy/proxymech.so [options]

DESCRIPTION

Le module proxymech de gssproxy est un plugin d'interposition chargé par GSSAPI. Il est activé par le fichier de configuration /etc/gss/mech.

Le plugin d'interposition permet d'intercepter toute la communication GSSAPI et de la rediriger vers le démon gssproxy. Lorsque le plugin d'interposition est installé, deux autres conditions doivent être remplies pour l'activer :

a) Fichier de configuration de l'interposeur

Le plugin doit être activé manuellement dans le fichier /etc/gss/mech.

b) Variable d'environnement gssproxy

Avec les options de compilation par défaut, le plugin d'interposition ne redirigera pas vers le démon gssproxy, sauf si la variable d'environnement nommée GSS_USE_PROXY=yes est définie.

Ce comportement par défaut peut être contrôlé au moment de la compilation et peut être configuré pour toujours rediriger, sauf si la variable d'environnement est définie sur GSS_USE_PROXY=no

Le réglage actuel pour la redirection systématique est : false

De plus, le plugin d'interposition peut être configuré pour se comporter de différentes manières lorsqu'il est appelé depuis GSSAPI. Ce comportement est contrôlé via la variable d'environnement GSSPROXY_BEHAVIOR. Elle accepte quatre valeurs différentes :

LOCAL_ONLY

Toutes les commandes reçues avec ce réglage entraîneront une réentrée immédiate dans GSSAPI sans aucune interaction avec le démon gssproxy. Lorsque la requête ne peut pas être traitée, elle échoue simplement.

LOCAL_FIRST

Toutes les commandes reçues avec ce réglage entraîneront une réentrée immédiate dans GSSAPI. Lorsque la GSSAPI locale ne peut pas traiter la requête, elle renvoie la requête au démon gssproxy.

REMOTE_FIRST

Toutes les commandes reçues avec ce réglage seront d'abord redirigées vers le démon gssproxy. Si la requête ne peut pas être gérée là-bas, la requête sera renvoyée à la GSSAPI locale.

REMOTE_ONLY

Ce réglage n'est actuellement pas entièrement implémenté et n'est donc pas pris en charge.

Le réglage par défaut pour GSSPROXY_BEHAVIOR est REMOTE_FIRST.

Enfin, l'interposeur peut avoir besoin d'utiliser un socket spécial par service pour communiquer avec gssproxy. Le chemin vers ce socket est défini via la variable d'environnement GSSPROXY_SOCKET.

VOIR AUSSI

gssproxy.conf(5) et gssproxy(8).
