NOM

gsasl_server_mechlist - Fonction API

SYNOPIS

#include <gsasl.h>

int gsasl_server_mechlist(Gsasl * ctx, char ** out);

ARGUMENTS

Gsasl * ctx
handle libgsasl.
char ** out
tableau de caractères de sortie nouvellement alloué.

DESCRIPTION

Retourne une chaîne nouvellement allouée contenant les noms SASL, séparés par des espaces, des mécanismes pris en charge par le serveur libgsasl. out est alloué par cette fonction, et il est de la responsabilité de l'appelant de le désallouer.

Valeur de retour : retourne GSASL_OK en cas de succès, ou un code d'erreur.
