gsettings() gsettings()

Nom

gsettings - Outil de configuration GSettings

SYNTAXE

gsettings get SCHÉMA*[:*CHEMIN] CLÉ
gsettings monitor SCHÉMA*[:*CHEMIN] CLÉ
gsettings writable SCHÉMA*[:*CHEMIN] CLÉ
gsettings range SCHÉMA*[:*CHEMIN] CLÉ
gsettings describe SCHÉMA*[:*CHEMIN] CLÉ
gsettings set SCHÉMA*[:*CHEMIN] CLÉ VALEUR
gsettings reset SCHÉMA*[:*CHEMIN] CLÉ
gsettings reset-recursively SCHÉMA*[:*CHEMIN]
gsettings list-schemas [--print-paths]
gsettings list-relocatable-schemas
gsettings list-keys SCHÉMA*[:*CHEMIN]
gsettings list-children SCHÉMA*[:*CHEMIN]
gsettings list-recursively [SCHÉMA*[:*CHEMIN]]
gsettings help [COMMANDE]

DESCRIPTION

gsettings offre une interface en ligne de commande simple pour GSettings. Elle vous permet d'obtenir, de définir ou de surveiller une clé individuelle pour les modifications.

Les arguments SCHÉMA et CLÉ sont requis pour la plupart des commandes afin de spécifier l'identifiant du schéma et le nom de la clé sur laquelle opérer. L'identifiant du schéma peut éventuellement avoir un suffixe :CHEMIN. La spécification du chemin n'est nécessaire que si le schéma n'a pas de chemin fixe.

Lors de la définition d'une clé, vous devez également spécifier une VALEUR. Le format de la valeur est celui d'un GVariant sérialisé, donc par exemple une chaîne de caractères doit inclure des guillemets explicites : 'foo'. Ce format est également utilisé lors de l'affichage des valeurs.

Notez que gsettings nécessite une connexion au bus de session D-Bus pour écrire les modifications dans la base de données dconf.

COMMANDES

get

Obtient la valeur de la CLÉ. La valeur est affichée sous forme de GVariant sérialisé.

monitor

Surveille la CLÉ pour les modifications et affiche les valeurs modifiées. Si aucune CLÉ n'est spécifiée, toutes les clés du schéma sont surveillées. La surveillance se poursuivra jusqu'à ce que le processus soit terminé.

writable

Détermine si la CLÉ est modifiable.

range

Interroge la plage des valeurs valides pour la CLÉ.

describe

Interroge la description des valeurs valides pour la CLÉ.

set

Définit la valeur de la CLÉ à la VALEUR. La valeur est spécifiée sous forme de GVariant sérialisé.

reset

Réinitialise la CLÉ à sa valeur par défaut.

reset-recursively

Réinitialise toutes les clés sous le SCHÉMA donné.

list-schemas

Liste les schémas installés et non déplaçables. Voir list-relocatable-schemas si vous êtes intéressé par les schémas déplaçables. Si --print-paths est donné, le chemin où chaque schéma est mappé est également affiché.

list-relocatable-schemas

Liste les schémas installés et déplaçables. Voir list-schemas si vous êtes intéressé par les schémas non déplaçables.

list-keys

Liste les clés du SCHÉMA.

list-children

Liste les enfants du SCHÉMA.

list-recursively

Liste les clés et les valeurs, de manière récursive. Si aucun SCHÉMA n'est donné, liste les clés de tous les schémas.

help

Affiche l'aide et quitte.
