NOM

gssproxy - Daemon GssProxy

SYNTAXE

gssproxy [options]

DESCRIPTION

gssproxy fournit un démon pour gérer l'accès aux identifiants GSSAPI.

gssproxy se compose du démon gssproxy (configuré par le fichier gssproxy.conf(5)) et d'un plugin d'interposition GSSAPI (gssproxy-mech(8)).

OPTIONS

-D,--daemon

Devient un démon après le démarrage.

-c,--config

Spécifie un fichier de configuration à utiliser comme fichier de configuration principal (lu avant le reste du répertoire de configuration). Par défaut, le fichier /etc/gssproxy/gssproxy.conf est utilisé. Pour référence sur la syntaxe et les options du fichier de configuration, consultez la page de manuel gssproxy.conf(5).

-C,--configdir

Spécifie un répertoire de configuration non par défaut. Les fichiers nommés sous la forme "##-foo.conf" (c'est-à-dire commençant par deux chiffres et un trait d'union, et se terminant par ".conf") seront lus dans l'ordre numérique à partir de ce répertoire, en plus du fichier de configuration lui-même. Le répertoire par défaut est /etc/gssproxy. Pour référence sur la syntaxe et les options du fichier de configuration, consultez la page de manuel gssproxy.conf(5).

-d,--debug

Active le débogage. Cette option est identique à --debug-level=1.

--debug-level=

Active le débogage au niveau spécifié. 0 correspond à aucune journalisation, tandis que 1 active la journalisation de débogage de base. Le niveau 2 augmente la verborosité, y compris une vérification plus détaillée des identifiants.

Aux niveaux 3 et supérieurs, la sortie KRB5_TRACE est journalisée. Si KRB5_TRACE était déjà défini dans l'environnement d'exécution, la sortie de trace est envoyée à sa valeur à la place.

-i,--interactive

Exécute en avant-plan, ne devient pas un démon.

-u,--userproxy

Exécute gssproxy en mode userproxy. Ce mode ignore les fichiers de configuration et écoute sur un socket dans $XDG_RUNTIME_DIR/gssproxy/default.sock à la place. Voir la documentation du projet pour plus d'informations sur le comportement de ce mode.

-s,--socket

Spécifie un nom de socket par défaut personnalisé. Ce socket sera utilisé par toutes les sections qui ne définissent pas de socket explicite.

--syslog-status

Active la journalisation supplémentaire dans syslog.

--version

Affiche le numéro de version et quitte.

SIGNALS

SIGTERM/SIGINT

Informe GssProxy de terminer gracieusement tous ses processus enfants puis de s'arrêter.

SIGHUP

Demande un rechargement de toute la configuration pour gssproxy. S'il y a une erreur dans les fichiers de configuration, la configuration existante ne sera pas remplacée ; s'il y a un problème lors de l'application de la nouvelle configuration, gssproxy se terminera.

VOIR AUSSI

gssproxy.conf(5) et gssproxy-mech(8).
