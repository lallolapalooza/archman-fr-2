NOM

GSmartControl - Outil d'inspection de l'état des disques durs et SSD

SYNTAXE

gsmartcontrol [OPTIONS]

gsmartcontrol-root [--desktop=<bureau>] [OPTIONS]

DESCRIPTION

GSmartControl est une interface graphique pour smartctl (de smartmontools), qui est un outil pour interroger et contrôler les données SMART (Self-Monitoring, Analysis, and Reporting Technology) sur les disques durs et SSD modernes. Il vous permet d'inspecter les données SMART du disque pour déterminer son état, ainsi que d'y exécuter divers tests.

Cette page de manuel documente brièvement les commandes gsmartcontrol et gsmartcontrol-root.

La commande gsmartcontrol-root lance gsmartcontrol avec des privilèges administratifs. L'argument desktop spécifie quel bureau est actuellement en cours d'exécution, pour une sélection automatique du mécanisme su natif. Les valeurs valides pour desktop sont auto, kde, gnome, other.

OPTIONS

Options d'aide :

-?, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gtk
Afficher les options GTK+
--help-debug
Afficher les options de journalisation

Options de l'application :

-l, --no-locale
Ne pas utiliser la locale du système
-V, --version
Afficher les informations de version
--no-scan
Ne pas analyser les périphériques au démarrage
--add-virtual
Charger les données smartctl depuis un fichier, en créant un disque virtuel. Vous pouvez spécifier cette option plusieurs fois.
--add-device
Ajouter ce périphérique à la liste des périphériques. Le format du périphérique est <périphérique>::<type>::<args_supplémentaires>, où le type et les args_supplémentaires sont optionnels. Cette option est utile avec --no-scan pour lister uniquement certains disques. Vous pouvez spécifier cette option plusieurs fois. Exemple : 
--add-device /dev/sda --add-device /dev/twa0::3ware,2 --add-device '/dev/sdb::::-T permissive'
--display=AFFICHAGE
Affichage X à utiliser
-v, --verbose
Activer la journalisation détaillée ; équivalent à --verbosity-level 5
-q, --quiet
Désactiver la journalisation ; équivalent à --verbosity-level 0
-b, --verbosity-level
Définir le niveau de verbosité [0-5]
