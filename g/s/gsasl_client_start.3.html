NOM

gsasl_client_start - fonction d'API

SYNTAXE

#include <gsasl.h>

int gsasl_client_start(Gsasl * ctx, const char * mech, Gsasl_session ** sctx);

ARGUMENTS

Gsasl * ctx
handle libgsasl.
const char * mech
nom du mécanisme SASL.
Gsasl_session ** sctx
pointeur vers le handle client.

DESCRIPTION

Cette fonction initie une authentification SASL client. Cette fonction doit être appelée avant toute autre fonction gsasl_client_*().

Valeur de retour : Retourne GSASL_OK en cas de succès, ou un code d'erreur.
