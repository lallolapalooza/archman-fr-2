!> !> CGSVJ1 est appelé depuis CGESVJ en tant que pré-processeur et c'est son !> principal rôle. Il applique des rotations de Jacobi de la même manière !> que CGESVJ, mais il ne cible que des pivots particuliers et ne vérifie !> pas la convergence (critère d'arrêt). Quelques paramètres de réglage !> (marqués par [TP]) sont disponibles pour l'implémenteur. !> !> Détails supplémentaires !> ~~~~~~~~~~~~~~~~~~~~~~~ !> CGSVJ1 applique quelques balayages de rotations de Jacobi dans l'espace !> des colonnes de la matrice d'entrée A de dimension M par N. Les paires !> de pivots sont prises dans le bloc hors-diagonale (1,2) de la matrice !> de Gram correspondante A^T * A. Les entrées de bloc (tuiles) du bloc !> hors-diagonale (1,2) sont marquées par les [x] dans le schéma suivant : !> !> | * * * [x] [x] [x]| !> | * * * [x] [x] [x]| Balayage par lignes dans les blocs [x] de !> | * * * [x] [x] [x]| dimension nblr par nblc. !> |[x] [x] [x] * * * | Pivotement cyclique par lignes à !> |[x] [x] [x] * * * | l'intérieur de chaque bloc [x]. !> |[x] [x] [x] * * * | !> !> En termes de colonnes de A, les N1 premières colonnes sont pivotées !> « contre » les N-N1 colonnes restantes, en essayant d'augmenter l'angle !> entre les sous-espaces correspondants. Le bloc hors-diagonale est de !> dimension N1 par (N-N1) et il est tuilé à l'aide de tuiles carrées de !> côté KBL. Ici, KBL est un paramètre de réglage. Le nombre de balayages !> est donné dans NSWEEP et le seuil d'orthogonalité est donné

dans TOL. !>

!> manière que ZGESVJ, mais il ne cible que des pivots particuliers et il
!> ne vérifie pas la convergence (critère d'arrêt). Quelques paramètres de
!> réglage (marqués par [TP]) sont disponibles pour l'implémenteur.
!>
!> Détails supplémentaires
!> ~~~~~~~~~~~~~~~~~~~~~~~
!> ZGSVJ1 applique quelques balayages de rotations de Jacobi dans l'espace
!> des colonnes de la matrice d'entrée A de taille M par N. Les paires de
!> pivots sont prises dans le bloc (1,2) hors diagonale de la matrice de
!> Gram correspondante A^T * A. Les entrées de bloc (tuiles) du bloc (1,2)
!> hors diagonale sont marquées par les [x] dans le schéma suivant :
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Balayage par lignes dans les blocs [x] de taille nblr par nblc.
!>    | *  *  * [x] [x] [x]|    Pivotage cyclique par lignes à l'intérieur de chaque bloc [x].
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>
!> En termes de colonnes de A, les N1 premières colonnes sont pivotées
!> « contre » les N-N1 colonnes restantes, en essayant d'augmenter l'angle
!> entre les sous-espaces correspondants. Le bloc hors diagonale est de
!> taille N1 par (N-N1) et il est tuilé à l'aide de tuiles carrées de côté
!> KBL. Ici, KBL est un paramètre de réglage. Le nombre de balayages est
!> donné par NSWEEP et le seuil d'orthogonalité est donné par TOL.
!> 




Paramètres


JOBV

!>          JOBV est de type CHARACTER*1.
!>          Spécifie si la sortie de cette procédure est utilisée
!>          pour calculer la matrice V :
!>          = 'V' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau V de taille N par N.
!>                (Voir la description de V.)
!>          = 'A' : le produit des rotations de Jacobi est accumulé
!>                 en post-multipliant le tableau V de taille MV par N.
!>                (Voir les descriptions de MV et V.)
!>          = 'N' : les rotations de Jacobi ne sont pas accumulées.
!> 


M


!>          M est un entier.
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!> 


N


!>          N est un entier.
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!> 


N1


!>          N1 est un entier.
!>          N1 spécifie la partition en blocs 2 x 2 ; les N1 premières colonnes sont
!>          pivotées « contre » les N-N1 colonnes restantes de A.
!> 


A


!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, A est une matrice M par N telle que A*diag(D) représente
!>          la matrice d'entrée.
!>          À la sortie,
!>          A_onexit * D_onexit représente la matrice d'entrée A*diag(D)
!>          post-multipliée par une suite de rotations de Jacobi, où le
!>          seuil de rotation et le nombre total de balayages sont donnés
!>          respectivement par TOL et NSWEEP.
!>          (Voir les descriptions de N1, D, TOL et NSWEEP.)
!> 


LDA


!>          LDA est un entier.
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!> 


D


!>          D est un tableau de type COMPLEX*16, de dimension (N)
!>          Le tableau D accumule les facteurs d'échelle provenant des
!>          rotations de Jacobi mises à l'échelle rapides.
!>          À l'entrée, A*diag(D) représente la matrice d'entrée.
!>          À la sortie, A_onexit*diag(D_onexit) représente la matrice
!>          d'entrée post-multipliée par une suite de rotations de Jacobi,
!>          où le seuil de rotation et le nombre total de balayages sont
!>          donnés respectivement par TOL et NSWEEP.
!>          (Voir les descriptions de N1, A, TOL et NSWEEP.)
!> 


SVA


!>          SVA est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          À l'entrée, SVA contient les normes euclidiennes des colonnes
!>          de la matrice A*diag(D).
!>          À la sortie, SVA contient les normes euclidiennes des colonnes
!>          de la matrice onexit*diag(D_onexit).
!> 


MV


!>          MV est un entier.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par
!>                           une suite de rotations de Jacobi.
!>          Si JOBV = 'N',   alors MV n'est pas référencé.
!> 


V


!>          V est un tableau de type COMPLEX*16, de dimension (LDV,N)
!>          Si JOBV = 'V', alors N lignes de V sont post-multipliées par
!>                           une suite de rotations de Jacobi.
!>          Si JOBV = 'A', alors MV lignes de V sont post-multipliées par
!>                           une suite de rotations de Jacobi.
!>          Si JOBV = 'N',   alors V n'est pas référencé.
!> 


LDV


!>          LDV est un entier.
!>          La dimension principale du tableau V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!> 


EPS


!>          EPS est de type DOUBLE PRECISION.
!>          EPS = DLAMCH('Epsilon')
!> 


SFMIN


!>          SFMIN est de type DOUBLE PRECISION.
!>          SFMIN = DLAMCH('Safe Minimum')
!> 


TOL


!>          TOL est de type DOUBLE PRECISION.
!>          TOL est le seuil pour les rotations de Jacobi. Pour une paire
!>          de colonnes pivot A(:,p), A(:,q), la rotation de Jacobi est
!>          appliquée uniquement si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!> 


NSWEEP


!>          NSWEEP est un entier.
!>          NSWEEP est le nombre de balayages de rotations de Jacobi à
!>          effectuer.
!> 


WORK


!>          WORK est un tableau de type COMPLEX*16, de dimension (LWORK)
!> 


LWORK


!>          LWORK est un entier.
!>          LWORK est la dimension de WORK. LWORK >= M.
!> 


INFO


!>          INFO est un INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
