NOM

gsasl_scram_secrets_from_password - fonction de l'API

SYNTAXE

#include <gsasl.h>

int gsasl_scram_secrets_from_password(Gsasl_hash hash, const char * password, unsigned int iteration_count, const char * salt, size_t saltlen, char * salted_password, char * client_key, char * server_key, char * stored_key);

ARGUMENTS

Gsasl_hash hash
un élément Gsasl_hash, par exemple GSASL_HASH_SHA256.
const char * password
paramètre d'entrée avec le mot de passe.
unsigned int iteration_count
nombre de tours PBKDF2 à appliquer.
const char * salt
tableau de caractères d'entrée de longueur saltlen avec le sel pour PBKDF2.
size_t saltlen
longueur du salt.
char * salted_password
tampon de sortie pré-alloué avec le mot de passe salé dérivé.
char * client_key
tampon de sortie pré-alloué avec la clé client dérivée.
char * server_key
tampon de sortie pré-alloué avec la clé serveur dérivée.
char * stored_key
tampon de sortie pré-alloué avec la clé stockée dérivée.

DESCRIPTION

Fonction utilitaire pour générer les secrets SCRAM à partir d'un mot de passe. Les
tampons salted_password , client_key , server_key , et stored_key doivent avoir une taille suffisante pour contenir le digest pour le hash donné, utilisez GSASL_HASH_MAX_SIZE qui est suffisant pour tous les hashes.

Valeur de retour : Retourne GSASL_OK en cas de succès, ou un code d'erreur.
