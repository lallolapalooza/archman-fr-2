NOM

gscriptor - Script Perl pour envoyer des commandes à une carte à puce via une interface graphique Gtk

SYNTAXE

gscriptor

DESCRIPTION

Cette page de manuel décrit brièvement la commande gscriptor.

gscriptor est un programme qui envoie des commandes à une carte à puce en utilisant un fichier batch. La syntaxe des commandes est la même que pour scriptor(1).

scriptor(1) est en mode texte. gscriptor(1) utilise une interface graphique Perl-Gtk et peut être plus conviviale.

Voir scriptor(1) pour les détails sur le format des commandes.

OPTIONS

aucune
