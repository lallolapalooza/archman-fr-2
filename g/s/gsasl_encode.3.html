NOM

gsasl_encode - Fonction d'API

SYNTAXE

#include <gsasl.h>

int gsasl_encode(Gsasl_session * sctx, const char * input, size_t input_len, char ** output, size_t * output_len);

ARGUMENTS

Gsasl_session * sctx
Handle de session libgsasl.
const char * input
Tableau d'octets d'entrée.
size_t input_len
Taille du tableau d'octets d'entrée.
char ** output
Tableau d'octets de sortie nouvellement alloué.
size_t * output_len
Pointeur vers la variable de sortie contenant la taille du tableau d'octets de sortie.

DESCRIPTION

Encode les données selon le mécanisme SASL négocié. Cela peut signifier que les données sont protégées en intégrité ou en confidentialité.

Le tampon output est alloué par cette fonction, et il est de la responsabilité de l'appelant de le désallouer en appelant gsasl_free( output ).

Valeur de retour : Retourne GSASL_OK si l'encodage a réussi, sinon un code d'erreur.
