NOM

gstack - Imprime une trace de pile d'un programme en cours d'exécution

SYNTAXE

gstack [-h | --help] [-v | --version] pid

DESCRIPTION

Imprime une trace de pile d'un programme en cours d'exécution avec l'identifiant de processus pid. Si le processus est multi-threadé, gstack affiche les traces de pile pour chaque thread existant dans le processus.

Le script appelle GDB, s'attache à l'identifiant de processus donné, imprime la trace de pile et se détache du processus.

gstack se termine avec un statut non nul si "gdb" n'a pas pu s'attacher à l'identifiant de processus donné pour une raison quelconque, telle qu'un identifiant de processus inexistant ou des privilèges insuffisants pour s'attacher au processus.

OPTIONS

--help
-h
Liste toutes les options, avec de brèves explications.
--version
-v
Affiche les informations de version puis quitte.

ENVIRONNEMENT

AWK
Nom complet du fichier d'un interpréteur Awk à utiliser. S'il n'est pas défini, le PATH sera recherché pour trouver un programme "awk".
GDB
Nom complet du fichier d'un exécutable GDB à utiliser pour générer des traces de pile. S'il n'est pas défini, le PATH sera recherché pour trouver un programme "gdb".
GDBARGS
Arguments optionnels à passer au programme "gdb".

VOIR AUSSI

La documentation complète de GDB est maintenue sous forme de manuel Texinfo. Si les programmes "info" et "gdb" ainsi que la documentation Texinfo de GDB sont correctement installés sur votre site, la commande

info gdb

devrait vous donner accès au manuel complet.

Using GDB: A Guide to the GNU Source-Level Debugger, Richard M. Stallman et Roland H. Pesch, juillet 1991.
