NOM

gsasl_mechanism_name_p - Fonction API

SYNTAXE

#include <gsasl.h>

int gsasl_mechanism_name_p(const char * mech);

ARGUMENTS

const char * mech
variable d'entrée avec le nom du mécanisme sous forme de chaîne.

DESCRIPTION

Vérifie si la chaîne de nom de mécanisme mech respecte les règles syntaxiques. Elle ne vérifie pas si le nom est enregistré auprès de l'IANA. Elle ne vérifie pas si le nom de mécanisme est réellement implémenté et pris en charge.

Les mécanismes SASL sont nommés par des chaînes, d'une longueur de 1 à 20 caractères, composées de lettres majuscules, de chiffres, de tirets et/ou de traits de soulignement.

VALEUR DE RETOUR

non-zéro lorsque la chaîne de nom de mécanisme mech est conforme aux règles, zéro lorsqu'elle ne répond pas aux exigences.
