NOM

gsasl_hash_length - Fonction API

SYNTAXE

#include <gsasl.h>

size_t gsasl_hash_length(Gsasl_hash hash);

ARGUMENTS

Gsasl_hash hash
un élément Gsasl_hash, par exemple GSASL_HASH_SHA256.

DESCRIPTION

Retourne la taille de sortie du digest pour la fonction de hachage hash. Par exemple, gsasl_hash_length(GSASL_HASH_SHA256) retourne GSASL_HASH_SHA256_SIZE, qui est 32.

VALEUR DE RETOUR

Taille de l'élément Gsasl_hash fourni.
