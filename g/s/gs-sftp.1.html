NOM

gs-sftp — Protocole de transfert de fichiers sécurisé via Global Socket.

SYNTAXE

gs-sftp [-lTR] [-s secret] [-k fichier_clé]

DESCRIPTION

L'utilitaire gs-sftp est un script enveloppant pour gs-netcat. Il permet à deux utilisateurs d'établir une connexion SFTP sécurisée via le réseau de relais Global Socket (GSRN). Ceci est utile dans un scénario où les deux utilisateurs sont derrière un NAT/pare-feu et sont incapables de se connecter directement l'un à l'autre.

OPTIONS

-s secret
Un mot de passe choisi par l'utilisateur. Les deux utilisateurs doivent utiliser le même mot de passe pour se connecter.
-k FICHIER
Un fichier contenant le mot de passe.
-l
Mode serveur. Le mode par défaut est client.
-R
Place le serveur (-l) en mode lecture seule. Les tentatives d'ouverture de fichiers en écriture, ainsi que d'autres opérations qui modifient l'état du système de fichiers, seront refusées.
-T
Utiliser TOR. L'outil gs-sftp se connectera via TOR au GSRN. Cela nécessite que TOR soit installé et en cours d'exécution. L'adresse IP et le port du serveur TOR peuvent être définis à l'aide de variables d'environnement.

Voir gs-netcat(1) pour plus d'options.

EXEMPLES

Exemple 1 — Serveur SFTP à l'écoute des clients en utilisant le mot de passe 'MonSecret':

$ gs-sftp -s MonSecret -l

Connecter le client sftp en utilisant le même mot de passe:

$ gs-sftp -s MonSecret

ENVIRONNEMENT

Voir gs-netcat(1) pour une liste des variables d'environnement prises en charge.

VOIR AUSSI

gsocket(1), gs-netcat(1), sftp(1)

BOGUES

Des efforts ont été faits pour que gs-sftp fasse la bonne chose dans tous ses différents modes. Si vous pensez qu'il fait la mauvaise chose dans certaines circonstances, veuillez m'en informer (skyper@thc.org) et me dire comment vous pensez qu'il devrait se comporter.
