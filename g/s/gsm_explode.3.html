GSM_EXPLODE(3) Manuel des fonctions de bibliothèque GSM_EXPLODE(3)

NOM

gsm_explode, gsm_implode — fonctions supplémentaires GSM 06.10 pour les tests

SYNTAXE

#include "gsm.h"

void gsm_explode(g, frame, xframe)
gsm g;
gsm_frame frame;
gsm_signal xframe[ 76 ];

void gsm_implode(g, xframe, frame)
gsm g;
gsm_signal xframe[ 76 ];
gsm_frame frame;

DESCRIPTION

Gsm est une implémentation du projet final de la norme GSM 06.10 pour le transcodage de la parole à débit plein. Des données de test pour des implémentations de ce document particulier peuvent être achetées et utilisées pour vérifier une implémentation.

Les données de test encodées utilisent un format différent de celui que l'on utiliserait pour transmettre des trames avec le moins de bits possible. Gsm_explode() et gsm_implode() convertissent entre le format interne, petit, de 33 octets et le format de 76 mots utilisé par les données de test.

VALEUR DE RETOUR

gsm_explode() renvoie -1 si la trame passée est invalide, sinon 0.

BOGUES

Veuillez adresser les rapports de bogues à jutta@pobox.com et cabo@tzi.org.
