NOM

gsasl_property_fast - fonction API

SYNOPIS

#include <gsasl.h>

const char * gsasl_property_fast(Gsasl_session * sctx, Gsasl_property prop);

ARGUMENTS

Gsasl_session * sctx
handle de session.
Gsasl_property prop
valeur énumérée de type Gsasl_property, indiquant le type de données dans data .

DESCRIPTION

Récupère les données stockées dans le handle de session pour la propriété donnée
prop .

Le pointeur pointe vers des données actives et ne doit pas être désalloué ou modifié de quelque manière que ce soit.

Cette fonction n'invoquera pas le rappel de l'application.

Valeur de retour : Retourne la valeur de la propriété, si connue, ou NULL si aucune valeur n'est connue.
