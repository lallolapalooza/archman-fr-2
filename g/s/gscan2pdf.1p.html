NOM

gscan2pdf - Une interface graphique pour produire des PDF ou des DjVu à partir de documents numérisés

UTILISATION

1. Numériser une ou plusieurs pages avec Fichier/Numériser
2. Créer un PDF des pages sélectionnées avec Fichier/Enregistrer

ARGUMENTS REQUIS

Aucun

OPTIONS

gscan2pdf possède les options en ligne de commande suivantes :

--device=périphérique
Spécifie le périphérique à utiliser, au lieu d'obtenir la liste des périphériques via l'API SANE. Cela peut être utile si le scanner se trouve sur un ordinateur distant qui ne diffuse pas son existence.
--help
Affiche cette page d'aide et quitte.
--log=fichier_log
Spécifie un fichier pour stocker les messages de journalisation.
--debug, --info, --warn, --error, --fatal
Définit le niveau de journalisation. Si un fichier journal est spécifié, ceci est par défaut --debug, sinon --error.
--import=PDF|DjVu|images
Importe les fichiers spécifiés. Si le document contient plus d'une page, une fenêtre s'affiche pour sélectionner les pages requises.
--import-all=PDF|DjVu|images Importe toutes les pages des fichiers spécifiés.
--version
Affiche la version du programme et quitte.

La numérisation est gérée avec SANE via scanimage. La conversion PDF est effectuée par PDF::Builder. L'exportation TIFF est gérée par libtiff (plus rapide et moins d'empreinte mémoire pour les fichiers multipages).

DIAGNOSTICS

Pour diagnostiquer une éventuelle erreur, démarrez gscan2pdf depuis la ligne de commande avec la journalisation activée :

"gscan2pdf --log=fichier.log"

et vérifiez fichier.log.

STATUT DE SORTIE

Aucun

CONFIGURATION

gscan2pdf crée un fichier de ressources texte dans ~/.config/gscan2pdfrc. Le répertoire peut être modifié en définissant la variable $XDG_CONFIG_HOME. Généralement, cependant, les préférences doivent être modifiées via le menu Édition/Préférences, ou sont capturées automatiquement lors d'une utilisation normale du programme.

INCOMPATIBILITÉS

Aucune connue.

BOGUES ET LIMITATIONS

Bien qu'il soit possible d'importer des PDF, cela est destiné à permettre le retour sur fichiers créés par gscan2pdf.

Téléchargement

gscan2pdf est disponible sur Sourceforge (https://sourceforge.net/projects/gscan2pdf/files/gscan2pdf/).

Basé sur Debian

Si vous utilisez Debian, vous devriez trouver que sid https://www.debian.org/releases/sid/ contient déjà la dernière version packagée.

Si vous utilisez un système basé sur Ubuntu, vous pouvez vous tenir automatiquement à jour avec la dernière version via le ppa :

"sudo apt-add-repository ppa:jeffreyratcliffe/ppa"

Si vous utilisez Synaptic, alors utilisez le menu Édition/Recharger les informations sur les paquets, recherchez gscan2pdf dans la liste des paquets, et voilà, vous pouvez installer la nouvelle version brillante.

Depuis la ligne de commande :

"sudo apt update"

"sudo apt install gscan2pdf"

À partir des sources

Les sources sont hébergées dans la section fichiers du projet gscan2pdf sur Sourceforge (https://sourceforge.net/projects/gscan2pdf/files/).

Depuis le dépôt

gscan2pdf utilise Git comme système de contrôle de révision. Vous pouvez parcourir l'arbre à l'adresse https://sourceforge.net/p/gscan2pdf/code/.

Les utilisateurs de Git peuvent cloner l'arbre complet avec "git clone git://git.code.sf.net/p/gscan2pdf/code"

Construction de gscan2pdf à partir des sources

Après avoir téléchargé les sources soit depuis une version de fichier Sourceforge, soit depuis le dépôt Git, décompressez-les si nécessaire avec "tar xvfz gscan2pdf-x.x.x.tar.gz cd gscan2pdf-x.x.x"

"perl Makefile.PL", créera le Makefile.

"make test" devrait exécuter plusieurs centaines de tests pour confirmer que les choses fonctionneront correctement sur votre système.

Vous pouvez installer directement à partir des sources avec "make install", mais la construction du paquet approprié pour votre distribution devrait être aussi simple que "make debdist" ou "make rpmdist". Cependant, vous aurez en outre besoin des paquets rpm, devscripts, fakeroot, debhelper et gettext.

Traductions

gscan2pdf a déjà été partiellement traduit en plusieurs langues. Si vous souhaitez contribuer à une traduction existante ou nouvelle, veuillez consulter Rosetta : https://translations.launchpad.net/gscan2pdf

Notez que les traductions des options du scanner sont prises directement depuis sane-backends. Si vous souhaitez y contribuer, vous pouvez le faire soit en contactant la liste de diffusion sane-devel (sane-devel@lists.alioth.debian.org) et en consultant le répertoire po/ dans le code source http://www.sane-project.org/cvs.html.

Alternativement, Ubuntu a son propre projet de traduction. Pour la version 9.04, les traductions sont disponibles à l'adresse https://translations.launchpad.net/ubuntu/jaunty/+source/sane-backends/+pots/sane-backends

Si vous avez mis à jour un fichier « .po » dans le répertoire « po » de l'arborescence source de gscan2pdf et souhaitez le tester, choisissez un répertoire de test pour les localisations compilées, par exemple « ./locale », et créez les fichiers « .mo » avec :

« perl Makefile.PL LOCALEDIR=./locale »

Si la localisation mise à jour est votre localisation standard, alors ce qui suit trouvera le fichier mis à jour :

« perl -I lib bin/gscan2pdf --log=log --locale=locale »

Si ce n'est pas votre localisation standard, vous aurez besoin de quelque chose comme (pour le russe) :

« LC_ALL=ru_RU.utf8 LC_MESSAGES=ru_RU.utf8 LC_CTYPE=ru_RU.utf8 LANG=ru_RU.utf8 LANGUAGE=ru_RU.utf8 perl -I lib bin/gscan2pdf --log=log --locale=locale »

ou pour l'allemand :

« LC_ALL=de_DE LC_MESSAGES=de_DE LC_CTYPE=de_DE LANG=de_DE LANGUAGE=de_DE perl -I lib bin/gscan2pdf --log=log --locale=locale »

Si ce qui précède ne fonctionne pas, assurez-vous qu'elle figure dans la liste produite par « locale -a », y compris tout suffixe « .utf8 » . Si nécessaire, générez de nouvelles localisations avec « sudo dpkg-reconfigure locales »

DESCRIPTION

Fichier

Nouveau

Efface la liste des pages.

Ouvrir

Ouvre tout format pris en charge par imagemagick. Les PDF auront leurs images intégrées extraites et importées, une par page.

Notez que les fichiers peuvent aussi être importés en les faisant glisser dans la liste des miniatures depuis un programme comme nautilus ou konqueror.

Numériser

Définit les options avant la numérisation via SANE.

Périphérique

Choisissez parmi les scanners disponibles.

Nb de pages

Sélectionnez le nombre de pages, ou toutes les pages à numériser.

Document source

Sélectionnez entre pages recto seul ou recto-verso.

Cela affecte la numérotation des pages. Les numérisations recto seul sont numérotées consécutivement. Les numérisations recto-verso sont incrémentées (ou décrémentées, voir ci-dessous) de 2, c'est-à-dire 1, 3, 5, etc.

Face à numériser

Si recto-verso est sélectionné ci-dessus, en supposant un scanner non duplex, c'est-à-dire un scanner qui ne peut pas numériser automatiquement les deux côtés d'une page, cela détermine si le numéro de page est incrémenté ou décrémenté de 2.

Pour numériser les deux côtés de trois pages, c'est-à-dire 6 faces :

1. Sélectionnez :
Nb de pages = 3 (ou « toutes » si votre scanner peut détecter qu'il n'y a plus de papier)

Recto-verso

Face avant

2. Numérise les faces 1, 3 et 5.
3. Replacez la pile avec le scanner prêt à numériser le verso de la dernière page.
4. Sélectionnez :
Nb de pages = 3 (ou « toutes » si votre scanner peut détecter qu'il n'y a plus de papier)

Recto-verso

Face arrière

5. Numérise les faces 6, 4 et 2.
6. gscan2pdf trie automatiquement les pages pour qu'elles apparaissent dans le bon ordre.

Options dépendantes du périphérique

Celles-ci dépendent naturellement de votre scanner. Elles peuvent inclure

la taille de la page,
le mode (couleur/noir et blanc/niveaux de gris),
la résolution (en PPP)
Numérisation par lots
Garantit qu'une condition « aucun document » sera renvoyée après la dernière page numérisée, pour éviter des numérisations ininterrompues sur la table après un numérisation par lot.
Attendre le bouton/Attente du bouton
Après l'envoi de la commande de numérisation, attendre que le bouton sur le scanner soit pressé avant de commencer réellement le processus de numérisation.
Source
Sélectionne la source du document. Les options possibles peuvent inclure la table plate ou l'ADF. Sur certains scanners, c'est le seul moyen de générer un signal de fin de documents.

Enregistrer

Enregistre les pages sélectionnées ou toutes les pages en PDF, DjVu, TIFF, PNG, JPEG, PNM ou GIF.

Métadonnées

Les métadonnées sont des informations qui ne sont pas visibles lors de l'affichage du PDF/DjVu, mais qui sont intégrées au fichier et donc consultables et examinables, généralement avec l'option « Propriétés » du visualiseur de documents.

Les métadonnées sont totalement facultatives, mais peuvent aussi être utilisées pour générer le nom de fichier ; voir les préférences pour plus de détails.

La date peut être sélectionnée à l'aide du widget de calendrier. La date affichée peut être incrémentée ou décrémentée à l'aide des touches '+' et '-'.

DjVu

Les images en noir et blanc, ainsi qu'en couleur, produisent une meilleure compression que le PDF. Voir http://www.djvuzone.org/ pour plus de détails.

Envoyer par courriel en PDF

Joindre les pages sélectionnées ou toutes les pages en PDF à un courriel vierge. Cela nécessite xdg-email, qui se trouve dans le paquet xdg-utils. S'il n'est pas présent, l'option est grisée.

Imprimer

Imprime les pages sélectionnées ou toutes les pages.

Compresser les fichiers temporaires

Si votre répertoire temporaire ($TMPDIR) est en train de se remplir, cette fonction peut être utile - elle compresse toutes les images en TIFF compressés par LZW. Ceux-ci nécessitent beaucoup moins d'espace que les fichiers PNM généralement produits par SANE ou lors de l'importation d'un PDF.

Édition

Supprimer

Supprime la page sélectionnée.

Renuméroter

Renumérote les pages de 1 à n.

Notez que l'ordre des pages peut aussi être modifié par glisser-déposer dans la vue des miniatures.

Sélectionner

Les menus de sélection peuvent être utilisés pour sélectionner toutes les pages, les pages paires, impaires, vides, sombres ou modifiées. La sélection des pages vides ou sombres exécute imagemagick pour prendre la décision. La sélection des pages modifiées choisit celles qui ont été modifiées par seuillage, flou, etc., depuis la dernière exécution de l'OCR.

Propriétés

Lorsqu'une image est numérisée, gscan2pdf tente d'extraire la résolution à partir des options de numérisation. Cela fonctionne presque toujours sans problème.

L'importation d'une image peut être plus délicate, cependant. Certains formats d'image comme le PNM n'encodent pas les métadonnées de résolution. Dans d'autres cas, les données sont incorrectes. Édition/Propriétés permet à l'utilisateur de corriger manuellement les métadonnées d'une page particulière, corrigeant ainsi la taille du PDF ou du DjVu final. L'image elle-même n'est pas modifiée - elle n'est ni réduite ni

agrandie.

Interface

s

gscan2pdf a initialement pris en charge deux interfaces, scanimage et scanadf. La prise en charge de scanadf a été ajoutée lorsque l'on a réalisé que scanadf fonctionne mieux que scanimage avec certains scanners. Sur les systèmes basés sur Debian, scanadf se trouve dans le paquet sane, et non, comme scanimage, dans sane-utils. Si scanadf n'est pas présent, l'option est évidemment

grisée.

En 0.9.27, les liaisons Perl pour SANE ont été introduites. Elles sont appelées

libsane-perl.

Avant la version 1.2.0, les options disponibles via les interfaces en ligne de commande comme scanimage étaient rendues visibles à mesure que les utilisateurs les demandaient. En 1.2.0, toutes les options peuvent être affichées ou masquées via Édition/Préférences, ainsi que la possibilité de spécifier quelles options déclenchent un

rechargement.

En 1.8.3, de nouvelles liaisons Perl pour SANE ont été introduites. Elles sont appelées libimage-sane-perl et constituent l'interface

préférée.

En 1.8.5, la prise en charge de libsane-perl a été

supprimée.
