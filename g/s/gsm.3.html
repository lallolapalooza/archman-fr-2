GSM(3) Manuel des fonctions de bibliothèque GSM(3)

NOM

gsm_create, gsm_destroy, gsm_encode, gsm_decode — Compression sonore avec perte GSM 06.10

SYNTAXE

#include <gsm.h>

gsm gsm_create();

void gsm_encode(handle, src, dst)
gsm handle;

gsm_signal src[160];

gsm_frame dst;

int gsm_decode(handle, src, dst)
gsm handle;

gsm_frame src;

gsm_signal dst[160];

void gsm_destroy(handle)
gsm handle;

DESCRIPTION

Gsm est une implémentation de la version finale du standard GSM 06.10 pour le transcodage de la parole à débit plein.

gsm_create() initialise un passage gsm et renvoie un objet 'gsm' qui peut être utilisé comme descripteur dans les appels ultérieurs à gsm_decode(), gsm_encode() ou gsm_destroy().

gsm_encode() encode un tableau de 160 échantillons de 13 bits (fournis sous forme de gsm_signal, valeurs entières signées d'au moins 16 bits) en une gsm_frame de 33 octets. (gsm_frame est un type défini comme un tableau de 33 gsm_bytes dans gsm.h.)

gsm_decode() décode une gsm_frame en un tableau de 160 échantillons de 13 bits (fournis sous forme de gsm_signals), qui sonnent plutôt comme ce que vous avez transmis à gsm_encode() de l'autre côté du fil.

gsm_destroy() termine un passage gsm et libère tout le stockage qui lui est associé.

Format des échantillons

La mise à l'échelle suivante est supposée pour l'entrée de l'algorithme :

   0  1                             11 12
   S..v..v..v..v..v..v..v..v..v..v..v..v..*..*..*
Seuls les 13 bits supérieurs sont utilisés comme valeur d'entrée signée.
La sortie de gsm_decode() a ses trois bits inférieurs mis à zéro.

VALEUR DE RETOUR

gsm_create() renvoie un objet descripteur opaque de type gsm, ou 0 en cas d'erreur. gsm_decode() renvoie -1 si la trame passée est invalide, sinon 0.

EXEMPLE

#include <gsm.h>
gsm handle;
gsm_frame buf;
gsm_signal sample[160];
int cc, soundfd;
play() {	/* lit les données compressées depuis l'entrée standard, écrit dans soundfd */
	if (!(handle = gsm_create())) error...
	while (cc = read(0, (char *)buf, sizeof buf)) {
		if (cc != sizeof buf) error...
		if (gsm_decode(handle, buf, sample) < 0) error... 
		if (write(soundfd, sample, sizeof sample) != sizeof sample)
			error...
	}
	gsm_destroy(handle);
}
record() {	/* lit depuis soundfd, écrit les données compressées vers la sortie standard */
	if (!(handle = gsm_create())) error...
	while (cc = read(soundfd, sample, sizeof sample)) {
		if (cc != sizeof sample) error...
		gsm_encode(handle, sample, buf);
		if (write(1, (char *)buf, sizeof buf) != sizeof sample) 
			error...
	}
	gsm_destroy(handle);
}
