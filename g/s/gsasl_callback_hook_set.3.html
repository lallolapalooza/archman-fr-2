NOM

gsasl_callback_hook_set - Fonction API

SYNOPSIS

#include <gsasl.h>

void gsasl_callback_hook_set(Gsasl * ctx, void * hook);

ARGUMENTS

Gsasl * ctx
Handle libgsasl.
void * hook
Pointeur opaque vers des données spécifiques à l'application.

DESCRIPTION

Stocke des données spécifiques à l'application dans le handle libgsasl.

Les données de l'application peuvent être récupérées ultérieurement (par exemple, dans un rappel) en appelant gsasl_callback_hook_get(). Ceci est normalement utilisé par l'application pour maintenir un état global entre le programme principal et les rappels.
