NOM

gst-stats-1.0 - affiche les informations collectées à partir d'un fichier journal GStreamer

SYNTAXE

gst-stats-1.0 [OPTION...] FICHIER

DESCRIPTION

gst-stats-1.0 est un outil qui analyse les informations collectées à partir d'un fichier journal basé sur les messages de trace de GStreamer.

OPTIONS

gst-stats-1.0 accepte les arguments et options suivants :

FICHIER
Nom d'un fichier
-h, --aide
Affiche la syntaxe de l'aide et les FLAGS disponibles
--gst-aide-tout
Affiche toutes les options d'aide
--gst-aide-gst
Affiche les options Gstreamer

VOIR AUSSI
