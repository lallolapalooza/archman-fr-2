NOM

gsasl_step - Fonction API

SYNTAXE

#include <gsasl.h>

int gsasl_step(Gsasl_session * sctx, const char * input, size_t input_len, char ** output, size_t * output_len);

ARGUMENTS

Gsasl_session * sctx
handle de session libgsasl.
const char * input
tableau d'octets d'entrée.
size_t input_len
taille du tableau d'octets d'entrée.
char ** output
tableau d'octets de sortie nouvellement alloué.
size_t * output_len
pointeur vers la variable de sortie avec la taille du tableau d'octets de sortie.

DESCRIPTION

Effectue une étape d'authentification SASL. Ceci lit des données de l'autre extrémité (depuis input et input_len ), les traite (invoquant potentiellement des rappels à l'application), et écrit des données vers le serveur (dans la variable nouvellement allouée output et output_len qui indiquent la longueur de output ).

Le contenu du buffer output n'est pas spécifié si cette fonction renvoie autre chose que GSASL_OK ou GSASL_NEEDS_MORE. Si cette fonction renvoie GSASL_OK ou GSASL_NEEDS_MORE, cependant, le buffer
output est alloué par cette fonction, et il est de la responsabilité de l'appelant de le désallouer en appelant gsasl_free( output ).

Valeur de retour : Renvoie GSASL_OK si l'authentification s'est terminée avec succès, GSASL_NEEDS_MORE si des données supplémentaires sont nécessaires, ou un code d'erreur.
