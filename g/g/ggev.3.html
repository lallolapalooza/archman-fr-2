CGGEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices GE

Objectif :

!>
!> CGGEV calcule pour une paire de matrices complexes non symétriques de taille N x N
!> (A,B), les valeurs propres généralisées, et éventuellement, les vecteurs propres généralisés gauches et/ou droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire
!> lambda ou un rapport alpha/beta = lambda, tel que A - lambda*B soit
!> singulière. Elle est généralement représentée par la paire (alpha,beta), car
!> il existe une interprétation raisonnable pour beta=0, et même pour que les deux
!> soient nuls.
!>
!> Le vecteur propre généralisé droit v(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> Le vecteur propre généralisé gauche u(j) correspondant à la
!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> où u(j)**H est la transposée conjuguée de u(j).
!>

Paramètres

JOBVL 
!>          JOBVL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs propres généralisés gauches ;
!>          = 'V' : calculer les vecteurs propres généralisés gauches.
!>

JOBVR

!>          JOBVR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs propres généralisés droits ;
!>          = 'V' : calculer les vecteurs propres généralisés droits.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VL, et VR.  N >= 0.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA, N)
!>          En entrée, la matrice A dans la paire (A,B).
!>          En sortie, A a été écrasé.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX de dimension (LDB, N)
!>          En entrée, la matrice B dans la paire (A,B).
!>          En sortie, B a été écrasé.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA est un tableau COMPLEX de dimension (N)
!>

BETA

!>          BETA est un tableau COMPLEX de dimension (N)
!>          En sortie, ALPHA(j)/BETA(j), j=1,...,N, seront les
!>          valeurs propres généralisées.
!>
!>          Remarque : les quotients ALPHA(j)/BETA(j) peuvent facilement
!>          déborder ou sous-déborder, et BETA(j) peut même être zéro.  Ainsi, l'utilisateur
!>          devrait éviter de calculer naïvement le rapport alpha/beta.
!>          Cependant, ALPHA sera toujours inférieur et généralement
!>          comparable à norm(A) en magnitude, et BETA toujours inférieur
!>          et généralement comparable à norm(B).
!>

VL

!>          VL est un tableau COMPLEX de dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres généralisés gauches u(j) sont
!>          stockés les uns après les autres dans les colonnes de VL, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVL = 'N'.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEX de dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres généralisés droits v(j) sont
!>          stockés les uns après les autres dans les colonnes de VR, dans le même
!>          ordre que leurs valeurs propres.
!>          Chaque vecteur propre est mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVR = 'N'.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale de la matrice VR. LDVR >= 1, et
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est un tableau COMPLEX de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, une requête de mémoire est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau RÉEL de dimension (8*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          =1,...,N :
!>                L'itération QZ a échoué. Aucun vecteur propre n'a été
!>                calculé, mais ALPHA(j) et BETA(j) devraient être
!>                corrects pour j=INFO+1,...,N.
!>          > N :  =N+1 : autre échec de l'itération QZ dans CHGEQZ,
!>                =N+2 : retour d'erreur de CTGEVC.
!>

!> valeur propre généralisée lambda(j) de (A,B) satisfait
!>
!>              u(j)**T * A = lambda(j) * u(j)**T * B
!>
!> où u(j)**T est la transposée de u(j).
!>

!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

!>          VR est un tableau DOUBLE PRECISION de dimension (LDVR,N)

!>          La dimension principale de la matrice VR. LDVR >= 1, et
