CGGSVD3 calcule la décomposition en valeurs singulières (SVD) pour les matrices OTHER

But :

!>
!> CGGSVD3 calcule la décomposition en valeurs singulières généralisées (GSVD)
!> d'une matrice complexe A de dimensions M par N et d'une matrice complexe B de
!> dimensions P par N :
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> où U, V et Q sont des matrices unitaires.
!> Soit K+L = le rang numérique effectif de la
!> matrice (A**H,B**H)**H, alors R est une matrice triangulaire supérieure
!> non singulière de dimensions (K+L) par (K+L), D1 et D2 sont des matrices
!> de dimensions M par (K+L) et P par (K+L)
!> respectivement, de structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et éventuellement les matrices de
!> transformation unitaires U, V et Q.
!>
!> En particulier, si B est une matrice non singulière de dimensions N par N,
!> alors la GSVD de A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H a des colonnes orthonormales, alors la GSVD de A et B est
!> également égale à la décomposition CS de A et B. De plus, la GSVD peut
!> être utilisée pour obtenir la solution du problème de valeurs propres :
!>                      A**H*A x = lambda* B**H*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la forme
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, et D1 et D2 sont
!> « diagonales ». La première forme de GSVD peut être convertie en la
!> seconde forme en prenant la matrice non singulière X comme
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U' : la matrice unitaire U est calculée ;
!>          = 'N' : U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V' : la matrice unitaire V est calculée ;
!>          = 'N' : V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q' : la matrice unitaire Q est calculée ;
!>          = 'N' : Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          À la sortie, K et L spécifient la dimension des sous-blocs
!>          décrits dans But.
!>          K + L = rang numérique effectif de (A**H,B**H)**H.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie, A contient la matrice triangulaire R, ou une partie de R.
!>          Voir But pour plus de détails.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,N)
!>          À l'entrée, la matrice B de dimensions P par N.
!>          À la sortie, B contient une partie de la matrice triangulaire R si
!>          M-K-L < 0.  Voir But pour plus de détails.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

ALPHA

!>          ALPHA est un tableau REAL, dimension (N)
!>

BETA

!>          BETA est un tableau REAL, dimension (N)
!>
!>          À la sortie, ALPHA et BETA contiennent les paires de valeurs
!>          singulières généralisées de A et B ;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          et si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = C,
!>            BETA(K+1:K+L)  = S,
!>          ou si M-K-L < 0,
!>            ALPHA(K+1:M)=C, ALPHA(M+1:K+L)=0
!>            BETA(K+1:M) =S, BETA(M+1:K+L) =1
!>          et
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0
!>

U

!>          U est un tableau COMPLEX, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice unitaire U de dimensions M par M.
!>          Si JOBU = 'N', U n'est pas référencée.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,M) si
!>          JOBU = 'U' ; LDU >= 1 sinon.
!>

V

!>          V est un tableau COMPLEX, dimension (LDV,P)          Si JOBV = 'V', V contient la matrice unitaire P-par-P V.
!>          Si JOBV = 'N', V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 sinon.
!>

Q

!>          Q est un tableau COMPLEX, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contient la matrice unitaire N-par-N Q.
!>          Si JOBQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 sinon.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale
!>          du tableau WORK, retourne cette valeur comme première entrée
!>          du tableau WORK, et aucun message d'erreur lié à LWORK n'est
!>          émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (2*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>          À la sortie, IWORK stocke les informations de tri. Plus
!>          précisément, la boucle suivante triera ALPHA
!>             for I = K+1, min(M,K+L)
!>                 swap ALPHA(I) et ALPHA(IWORK(I))
!>             endfor
!>          de sorte que ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = 1, la procédure de type Jacobi n'a pas
!>                convergé. Pour plus de détails, voir la sous-routine CTGSJA.
!>

Paramètres internes:

!>  TOLA    REAL
!>  TOLB    REAL
!>          TOLA et TOLB sont les seuils pour déterminer le rang effectif
!>          de (A**H,B**H)**H. Généralement, ils sont définis à
!>                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          La taille de TOLA et TOLB peut affecter la taille des erreurs
!>          arrière de la décomposition.
!>

!> où U, V et Q sont des matrices orthogonales.
!> Soit K+L = le rang numérique effectif de la matrice (A**T,B**T)**T,
!> alors R est une matrice triangulaire supérieure non singulière de
!> taille K+L par K+L, D1 et D2 sont des matrices de taille M par (K+L)
!> et P par (K+L) respectivement, de structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N), et R33 est stocké
!>   ( 0  R22 R23 )
!>   dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> La routine calcule C, S, R, et optionnellement les matrices de
!> transformation orthogonales U, V et Q.
!>
!> En particulier, si B est une matrice non singulière N par N, alors la
!> GSVD de A et B donne implicitement la SVD de A*inv(B) :
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T a des colonnes orthonormales, alors la GSVD de A
!> et B est aussi égale à la décomposition CS de A et B. De plus, la
!> GSVD peut être utilisée pour dériver la solution du problème de
!> valeurs propres :
!>                      A**T*A x = lambda* B**T*B x.
!> Dans certaines littératures, la GSVD de A et B est présentée sous la
!> forme
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> où U et V sont orthogonales et X est non singulière, D1 et D2 sont
!> « diagonales ». La première forme de GSVD peut être convertie en la
!> seconde forme en prenant la matrice non singulière X comme
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

Detailed Description


ZGGSVD3 computes the generalized singular value decomposition
    (GSDVD) of two general complex matrices A and B, of dimensions M-by-N and
    P-by-N, respectively. The GSDVD is defined as


A = Q * S11 * D12 * V**H
B = Q * S21 * D22 * V**H



where S11 is M-by-N, S21 is P-by-N, and D12 and D22 are
    diagonal matrices.


Q, V are unitary matrices. V**H is the conjugate transpose of
    V.


The function ZGGSVD3 is the LAPACK3.1+ version of ZGGSVD.
