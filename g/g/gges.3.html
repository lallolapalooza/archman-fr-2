subroutine cgges (character jobvsl, character jobvsr, character sort, external selctg, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, integer sdim, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldvsl, * ) vsl, integer ldvsl, complex, dimension( ldvsr, * ) vsr, integer ldvsr, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, logical, dimension( * ) bwork, integer

CGGES calcule les valeurs propres, la forme de Schur et, en option, la matrice des vecteurs de Schur pour les matrices

GE

But

: 
!>
!> CGGES calcule pour une paire de matrices complexes non symétriques
!> N×N (A,B), les valeurs propres généralisées, la forme de Schur
!> complexe généralisée (S, T) et, en option, les vecteurs de Schur
!> gauche et/ou droit (VSL et VSR). Cela donne la factorisation de
!> Schur généralisée
!>
!>         (A,B) = ( (VSL)*S*(VSR)**H, (VSL)*T*(VSR)**H )
!>
!> où (VSR)**H est le conjugué-transposé de VSR.
!>
!> En option, elle ordonne également les valeurs propres de sorte
!> qu'un groupe sélectionné de valeurs propres apparaisse dans les
!> blocs diagonaux de tête des matrices triangulaires supérieures S et
!> T. Les colonnes de tête de VSL et VSR forment alors une base
!> unitaire pour les sous-espaces propres gauche et droit
!> correspondants (sous-espaces déflationnaires).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires,
!> utilisez plutôt le pilote CGGEV, qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est
!> un scalaire w ou un rapport alpha/beta = w, tel que A - w*B soit
!> singulier. Elle est généralement représentée sous la forme de la
!> paire (alpha,beta), car il existe une interprétation raisonnable
!> pour beta=0, et même lorsque les deux sont nuls.
!>
!> Une paire de matrices (S,T) est en forme de Schur complexe
!> généralisée si S et T sont triangulaires supérieures et, de plus,
!> les éléments diagonaux de T sont des nombres réels non négatifs.
!
>

Paramètre

s
JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauche ;
!>          = 'V' : calculer les vecteurs de Schur gauche.
!
>

JOBVS

R 
!>          JOBVSR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droit ;
!>          = 'V' : calculer les vecteurs de Schur droit.
!
>

SOR

T 
!>          SORT est CHARACTER*1
!>          Indique s'il faut ou non ordonner les valeurs propres sur
!>          la diagonale de la forme de Schur généralisée.
!>          = 'N' : les valeurs propres ne sont pas ordonnées ;
!>          = 'S' : les valeurs propres sont ordonnées (voir SELCTG).
!
>

SELCT

G 
!>          SELCTG est une FUNCTION LOGICAL de deux arguments COMPLEX
!>          SELCTG doit être déclarée EXTERNAL dans la subroutine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs
!>          propres à trier en haut à gauche de la forme de Schur.
!>          Une valeur propre ALPHA(j)/BETA(j) est sélectionnée si
!>          SELCTG(ALPHA(j),BETA(j)) est vraie.
!>
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus
!>          satisfaire SELCTG(ALPHA(j),BETA(j)) = .TRUE. après le tri, car

!>          cas, INFO est défini à N+2 (voir INFO ci-dessous).

DGGES calcule les valeurs propres, la forme de Schur et, optionnellement, la matrice des vecteurs de Schur pour les matrices

GE

But

: 
!>
!> DGGES calcule, pour une paire de matrices réelles non symétriques N par N (A,B),
!> les valeurs propres généralisées, la forme de Schur réelle généralisée (S,T),
!> et, optionnellement, les matrices de vecteurs de Schur gauche et/ou droite (VSL et
!> VSR). Cela donne la factorisation de Schur généralisée
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Optionnellement, elle ordonne aussi les valeurs propres de sorte qu'un
!> cluster sélectionné de valeurs propres apparaisse dans les blocs diagonaux
!> dominants de la matrice quasi-triangulaire supérieure S et de la matrice
!> triangulaire supérieure T. Les colonnes dominantes de VSL et VSR
!> forment alors une base orthonormale pour les sous-espaces propres
!> gauche et droite correspondants (sous-espaces défléchissants).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires, utilisez
!> plutôt le pilote DGGEV, qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe
!> une interprétation raisonnable pour beta=0 ou si les deux sont nuls.
!>
!> Une paire de matrices (S,T) est sous forme de Schur réelle généralisée si T est
!> triangulaire supérieure avec diagonale non négative et S est triangulaire
!> supérieure par blocs avec des blocs 1 par 1 et 2 par 2. Les blocs 1 par 1
!> correspondent aux valeurs propres généralisées réelles, tandis que les blocs
!> 2 par 2 de S seront en rendant les éléments correspondants de T de la
!> forme :
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> et la paire de blocs 2 par 2 correspondants dans S et T aura une
!> paire conjuguée complexe de valeurs propres généralisées.
!>
!
>

s
JOBVSL 
!>          JOBVSL est de type CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauche ;
!>          = 'V' : calculer les vecteurs de Schur gauche.

G

GE

But

: 
!>
!> SGGES calcule pour une paire de matrices réelles non symétriques N par N (A,B),
!> les eigenvalues généralisées, la forme de Schur réelle généralisée (S,T),
!> et optionnellement, les matrices gauche et/ou droite des vecteurs de Schur (VSL et
