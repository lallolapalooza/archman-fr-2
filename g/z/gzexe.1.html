GZEXE(1) Manuel des commandes générales GZEXE(1)

NOM

gzexe - compresse les fichiers exécutables sur place

SYNTAXE

gzexe nom ...

DESCRIPTION

L'utilitaire gzexe vous permet de compresser les exécutables sur place et de les faire se décompresser et s'exécuter automatiquement lorsque vous les lancez (au détriment des performances). Par exemple, si vous exécutez ``gzexe /usr/bin/gdb'', il créera les deux fichiers suivants :

    -rwxr-xr-x  1 root root 1026675 Jun  7 13:53 /usr/bin/gdb
    -rwxr-xr-x  1 root root 2304524 May 30 13:02 /usr/bin/gdb~

/usr/bin/gdb~ est le fichier original et /usr/bin/gdb est le fichier exécutable auto-décompressant. Vous pouvez supprimer /usr/bin/gdb~ une fois que vous êtes sûr que /usr/bin/gdb fonctionne correctement.

Cet utilitaire est surtout utile sur les systèmes avec de très petits disques.

OPTIONS

-d
Décompresse les exécutables donnés au lieu de les compresser.

VOIR AUSSI

gzip(1), znew(1), zmore(1), zcmp(1), zforce(1)

MISE EN GARDE

L'exécutable compressé est un script shell. Cela peut créer des vulnérabilités de sécurité. En particulier, l'exécutable compressé dépend de la variable d'environnement PATH pour trouver gzip et quelques utilitaires standards (basename, chmod, ln, mkdir, mktemp, rm, sleep, et tail).

BOGUES

La commande gzexe tente de conserver les attributs du fichier original sur l'exécutable compressé, mais vous devrez peut-être les corriger manuellement dans certains cas, en utilisant chmod ou chown.
