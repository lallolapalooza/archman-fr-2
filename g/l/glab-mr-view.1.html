NOM

glab-mr-view - Affiche le titre, le corps et d'autres informations concernant une requête de fusion.

SYNTAXE

glab mr view { | } [flags]

DESCRIPTION

Affiche le titre, le corps et d'autres informations concernant une requête de fusion.

OPTIONS

-c, --comments[=false] Afficher les commentaires et activités de la requête de fusion.

-F, --output="text" Format de sortie : text, json.

-p, --page=0 Numéro de page.

-P, --per-page=20 Nombre d'éléments à afficher par page.

-s, --system-logs[=false] Afficher les activités et journaux système.

-w, --web[=false] Ouvrir la requête de fusion dans un navigateur. Utilise le navigateur par défaut ou celui spécifié dans la variable BROWSER.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide de cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/DEPOT ou GROUPE/ESPACE_NOM/DEPOT. Accepte également une URL complète ou une URL Git.
