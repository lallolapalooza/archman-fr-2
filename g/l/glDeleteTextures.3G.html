NOM

glDeleteTextures - supprimer les textures nommées

SPÉCIFICATION C

void glDeleteTextures(GLsizei n, const GLuint * textures);

PARAMÈTRES

n

Spécifie le nombre de textures à supprimer.

textures

Spécifie un tableau de textures à supprimer.

DESCRIPTION

glDeleteTextures supprime n textures nommées par les éléments du tableau textures. Après la suppression d'une texture, elle n'a plus de contenu ni de dimensionnalité, et son nom est libre pour être réutilisé (par exemple, par glGenTextures()). Si une texture actuellement liée est supprimée, la liaison est rétablie à 0 (la texture par défaut).

glDeleteTextures ignore silencieusement les 0 et les noms qui ne correspondent pas à des textures existantes.

ERREURS

GL_INVALID_VALUE est générée si n est négatif.

GET ASSOCIÉS

glIsTexture()
