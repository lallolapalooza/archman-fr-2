NOM

glGetProgramInfoLog - Retourne le journal d'informations pour un objet programme

SPÉCIFICATION C

void glGetProgramInfoLog(GLuint program, GLsizei maxLength, GLsizei *length, GLchar *infoLog);

PARAMÈTRES

program

Spécifie l'objet programme dont le journal d'informations doit être interrogé.

maxLength

Spécifie la taille du tampon de caractères pour stocker le journal d'informations retourné.

length

Retourne la longueur de la chaîne retournée dans infoLog (hors caractère nul de terminaison).

infoLog

Spécifie un tableau de caractères utilisé pour retourner le journal d'informations.

DESCRIPTION

glGetProgramInfoLog retourne le journal d'informations pour l'objet programme spécifié. Le journal d'informations d'un objet programme est modifié lors de la liaison ou de la validation du programme. La chaîne retournée sera terminée par un caractère nul.

glGetProgramInfoLog retourne dans infoLog autant du journal d'informations que possible, jusqu'à un maximum de maxLength caractères. Le nombre de caractères effectivement retournés, hors caractère nul de terminaison, est spécifié par length. Si la longueur de la chaîne retournée n'est pas requise, une valeur de NULL peut être passée dans l'argument length. La taille du tampon requise pour stocker le journal d'informations retourné peut être obtenue en appelant glGetProgram() avec la valeur GL_INFO_LOG_LENGTH.

Le journal d'informations d'un objet programme est soit une chaîne vide, soit une chaîne contenant des informations sur la dernière opération de liaison, soit une chaîne contenant des informations sur la dernière opération de validation. Il peut contenir des messages de diagnostic, des avertissements et d'autres informations. Lorsqu'un objet programme est créé, son journal d'informations est une chaîne de longueur 0.

NOTES

Le journal d'informations d'un objet programme est le principal mécanisme du fournisseur OpenGL pour transmettre des informations sur la liaison et la validation. Par conséquent, le journal d'informations peut être utile aux développeurs d'applications pendant le processus de développement, même lorsque ces opérations réussissent. Les développeurs d'applications ne doivent pas s'attendre à ce que différentes implémentations OpenGL produisent des journaux d'informations identiques.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si program n'est pas un objet programme.

GL_INVALID_VALUE est généré si maxLength est inférieur à 0.

GETS ASSOCIÉS

glGetProgram() avec l'argument GL_INFO_LOG_LENGTH

glIsProgram()
