NOM

glab-mr-issues - Obtenir les problèmes liés à une requête de fusion particulière.

SYNTAXE

glab mr issues [ | ] [options]

DESCRIPTION

Obtenir les problèmes liés à une requête de fusion particulière.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACEDE_NOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Lister les problèmes pour la requête de fusion 46
$ glab mr issues 46
$ glab mr issues branche
# Utiliser la branche extraite
$ glab mr issues
