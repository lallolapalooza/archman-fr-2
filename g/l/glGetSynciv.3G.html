NOM

glGetSynciv - interroger les propriétés d'un objet sync

SPÉCIFICATION C

void glGetSynciv(GLsync sync, GLenum pname, GLsizei bufSize, GLsizei *length, GLint *values);

PARAMÈTRES

sync

Spécifie l'objet sync dont il faut interroger les propriétés.

pname

Spécifie le paramètre dont il faut récupérer la valeur à partir de l'objet sync spécifié par sync.

bufSize

Spécifie la taille du tampon dont l'adresse est donnée dans values.

length

Spécifie l'adresse d'une variable où recevoir le nombre d'entiers placés dans values.

values

Spécifie l'adresse d'un tableau où recevoir les valeurs du paramètre interrogé.

DESCRIPTION

glGetSynciv récupère les propriétés d'un objet sync. sync spécifie le nom de l'objet sync dont il faut récupérer les propriétés.

En cas de succès, glGetSynciv remplace jusqu'à bufSize entiers dans values avec les valeurs de propriété correspondantes de l'objet interrogé. Le nombre réel d'entiers remplacés est retourné dans la variable dont l'adresse est spécifiée dans length. Si length est NULL, aucune longueur n'est retournée.

Si pname est GL_OBJECT_TYPE, une seule valeur représentant le type spécifique de l'objet sync est placée dans values. Le seul type supporté est GL_SYNC_FENCE.

Si pname est GL_SYNC_STATUS, une seule valeur représentant l'état de l'objet sync (GL_SIGNALED ou GL_UNSIGNALED) est placée dans values.

Si pname est GL_SYNC_CONDITION, une seule valeur représentant la condition de l'objet sync est placée dans values. La seule condition supportée est GL_SYNC_GPU_COMMANDS_COMPLETE.

Si pname est GL_SYNC_FLAGS, une seule valeur représentant les drapeaux avec lesquels l'objet sync a été créé est placée dans values. Aucun drapeau n'est actuellement supporté[1].

Si une erreur se produit, rien ne sera écrit dans values ou length.

ERREURS

GL_INVALID_VALUE est généré si sync n'est pas le nom d'un objet sync.

GL_INVALID_ENUM est généré si pname n'est pas l'un des jetons acceptés.
