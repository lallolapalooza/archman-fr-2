NOM

glab-repo-list - Obtenir la liste des dépôts.

SYNTAXE

glab repo list [flags]

DESCRIPTION

Obtenir la liste des dépôts.

OPTIONS

-a, --all[=false] Lister tous les projets de l'instance.

--archived[=false] Filtrer par statut archivé. Utiliser 'false' pour exclure les dépôts archivés. Utilisé avec le drapeau '--group'.

-g, --group="" Retourner les dépôts du groupe spécifié uniquement.

-G, --include-subgroups[=false] Inclure les projets dans les sous-groupes de ce groupe. Par défaut, c'est false. Utilisé avec le drapeau '--group'.

--member[=false] Lister uniquement les projets dont vous êtes membre.

-m, --mine[=false] Lister uniquement les projets qui vous appartiennent. Par défaut si aucun filtre n'est fourni.

-o, --order="last_activity_at" Retourner les dépôts triés par id, name, path, created_at, updated_at, similarity, star_count, last_activity_at.

-F, --output="text" Formater la sortie en : text, json.

-p, --page=1 Numéro de page.

-P, --per-page=30 Nombre d'éléments à lister par page.

-s, --sort="" Retourner les dépôts triés par ordre ascendant ou descendant.

--starred[=false] Lister uniquement les projets favoris.

-u, --user="" Lister les projets de l'utilisateur.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab repo list
