NOM

glGetAttribLocation - Retourne l'emplacement d'une variable d'attribut

SPÉCIFICATION C

GLint glGetAttribLocation(GLuint program, const GLchar *name);

PARAMÈTRES

program

Spécifie l'objet programme à interroger.

name

Pointe vers une chaîne terminée par un caractère nul contenant le nom de la variable d'attribut dont l'emplacement doit être interrogé.

DESCRIPTION

glGetAttribLocation interroge l'objet programme préalablement lié, spécifié par program, pour la variable d'attribut spécifiée par name et retourne l'indice de l'attribut de sommet générique qui est lié à cette variable d'attribut. Si name est une variable d'attribut matricielle, l'indice de la première colonne de la matrice est retourné. Si la variable d'attribut nommée n'est pas un attribut actif dans l'objet programme spécifié ou si name commence par le préfixe réservé "gl_", une valeur de -1 est retournée.

L'association entre un nom de variable d'attribut et un indice d'attribut générique peut être spécifiée à tout moment en appelant glBindAttribLocation(). Les liaisons d'attributs ne prennent effet que lorsque glLinkProgram() est appelé. Après qu'un objet programme a été lié avec succès, les valeurs d'indice pour les variables d'attribut restent fixes jusqu'à la prochaine commande de liaison. Les valeurs d'attribut ne peuvent être interrogées après une liaison que si celle-ci a réussi. glGetAttribLocation retourne la liaison qui a effectivement pris effet lors de la dernière exécution de glLinkProgram() pour l'objet programme spécifié. Les liaisons d'attributs spécifiées depuis la dernière opération de liaison ne sont pas retournées par glGetAttribLocation.

ERREURS

GL_INVALID_OPERATION est généré si program n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si program n'est pas un objet programme.

GL_INVALID_OPERATION est généré si program n'a pas été lié avec succès.

GETS ASSOCIÉS

glGetActiveAttrib() avec l'argument program et l'indice d'un attribut actif

glIsProgram()
