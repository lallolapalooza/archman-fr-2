NOM

glab-issue-update - Mettre à jour un problème

SYNTAXE

glab issue update [options]

DESCRIPTION

Mettre à jour un problème

OPTIONS

-a, --assignee=[] Assigner des utilisateurs par nom d'utilisateur. Préfixez avec '!' ou '-' pour supprimer des personnes déjà assignées, ou '+' pour ajouter de nouvelles. Sinon, remplace les personnes assignées existantes par celles-ci. Plusieurs noms d'utilisateur peuvent être séparés par des virgules ou spécifiés en répétant l'option.

-c, --confidential[=false] Rendre le problème confidentiel

-d, --description="" Description du problème. Définir sur "-" pour ouvrir un éditeur.

--due-date="" Une date au format 'AAAA-MM-JJ'.

-l, --label=[] Ajouter des étiquettes.

--lock-discussion[=false] Verrouiller la discussion sur le problème.

-m, --milestone="" Titre du jalon auquel assigner. Définir sur "" ou 0 pour désassigner.

-p, --public[=false] Rendre le problème public.

-t, --title="" Titre du problème.

--unassign[=false] Désassigner tous les utilisateurs.

-u, --unlabel=[] Supprimer des étiquettes.

--unlock-discussion[=false] Déverrouiller la discussion sur le problème.

-w, --weight=0 Définir le poids du problème.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE_NOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab issue update 42 --label ui,ux
$ glab issue update 42 --unlabel working
