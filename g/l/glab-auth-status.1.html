NOM

glab-auth-status - Afficher le statut d'authentification.

SYNOPIS

glab auth status [options]

DESCRIPTION

Vérifie et affiche des informations sur votre état d'authentification.

Par défaut, cette commande vérifie l'état d'authentification de l'instance GitLab déterminée par votre contexte actuel (variable d'environnement git remote, GITLAB_HOST, ou configuration). Utilisez --all pour vérifier toutes les instances configurées, ou --hostname pour vérifier une instance spécifique.

OPTIONS

-a, --all[=false] Vérifie toutes les instances configurées.

--hostname="" Vérifie le statut d'authentification d'une instance spécifique.

-t, --show-token[=false] Affiche le jeton d'authentification.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Affiche l'aide pour cette commande.
