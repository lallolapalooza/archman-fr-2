NOM

glIsTransformFeedback - déterminer si un nom correspond à un objet de retour de transformation

SPÉCIFICATION C

GLboolean glIsTransformFeedback(GLuint id);

PARAMÈTRES

id

Spécifie une valeur qui peut être le nom d'un objet de retour de transformation.

DESCRIPTION

glIsTransformFeedback retourne GL_TRUE si id est actuellement le nom d'un objet de retour de transformation. Si id est zéro, ou si id n'est pas le nom d'un objet de retour de transformation, ou si une erreur se produit, glIsTransformFeedback retourne GL_FALSE. Si id est un nom retourné par glGenTransformFeedbacks(), mais qui n'a pas encore été lié via un appel à glBindTransformFeedback(), alors le nom n'est pas un objet de retour de transformation et glIsTransformFeedback retourne GL_FALSE.
