NOM

glIsFramebuffer - détermine si un nom correspond à un objet framebuffer

SPÉCIFICATION C

GLboolean glIsFramebuffer(GLuint framebuffer);

PARAMÈTRES

framebuffer

Spécifie une valeur qui peut être le nom d'un objet framebuffer.

DESCRIPTION

glIsFramebuffer renvoie GL_TRUE si framebuffer est actuellement le nom d'un objet framebuffer. Si framebuffer est zéro, ou si framebuffer n'est pas le nom d'un objet framebuffer, ou si une erreur se produit, glIsFramebuffer renvoie GL_FALSE. Si framebuffer est un nom retourné par glGenFramebuffers(), mais qui n'a pas encore été lié via un appel à glBindFramebuffer(), alors le nom n'est pas un objet framebuffer et glIsFramebuffer renvoie GL_FALSE.
