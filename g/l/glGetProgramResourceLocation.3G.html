NOM

glGetProgramResourceLocation - interroger l'emplacement d'une ressource nommée dans un programme

SPÉCIFICATION C

GLint glGetProgramResourceLocation(GLuint program, GLenum programInterface, const char * name);

PARAMÈTRES

program

Le nom d'un objet programme dont les ressources doivent être interrogées.

programInterface

Un jeton identifiant l'interface dans program contenant la ressource nommée name.

name

Le nom de la ressource dont l'emplacement doit être interrogé.

DESCRIPTION

glGetProgramResourceLocation renvoie l'emplacement attribué à la variable nommée name dans l'interface programInterface de l'objet programme program. program doit être le nom d'un programme qui a été lié avec succès. programInterface doit être l'un des jetons suivants : GL_UNIFORM, GL_PROGRAM_INPUT, GL_PROGRAM_OUTPUT, GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, GL_COMPUTE_SUBROUTINE_UNIFORM, ou GL_TRANSFORM_FEEDBACK_BUFFER.

La valeur -1 sera renvoyée si une erreur se produit, si name n'identifie pas une variable active sur programInterface, ou si name identifie une variable active qui n'a pas d'emplacement valide attribué, comme décrit ci-dessus. Les emplacements renvoyés par ces commandes sont les mêmes emplacements renvoyés lors de l'interrogation des propriétés de ressource GL_LOCATION et GL_LOCATION_INDEX.

Une chaîne fournie à glGetProgramResourceLocation est considérée comme correspondant à une variable active si :

•la chaîne correspond exactement au nom de la variable active
•si la chaîne identifie le nom de base d'un tableau actif, où la chaîne correspondrait exactement au nom de la variable si le suffixe « [0] » était ajouté à la chaîne
•si la chaîne identifie un élément actif du tableau, où la chaîne se termine par la concaténation du caractère « [ », d'un entier sans signe « + », zéros de tête supplémentaires, ou espaces blancs identifiant un élément de tableau, l'entier est inférieur au nombre d'éléments actifs de la variable tableau, et où la chaîne correspondrait exactement au nom énuméré du tableau si l'entier décimal était remplacé par zéro.

Toute autre chaîne est considérée comme n'identifiant pas une variable active. Si la chaîne spécifie un élément d'une variable tableau, glGetProgramResourceLocation renvoie l'emplacement attribué à cet élément. Si elle spécifie le nom de base d'un tableau, elle identifie les ressources associées au premier élément du tableau.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme existant.

GL_INVALID_ENUM est généré si programInterface n'est pas l'un des types d'interface acceptés.

GL_INVALID_OPERATION est généré si program n'a pas été lié avec succès.
