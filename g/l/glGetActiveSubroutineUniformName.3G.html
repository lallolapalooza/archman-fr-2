NOM

glGetActiveSubroutineUniformName - interroger le nom d'un uniforme de sous-routine de shader actif

SPÉCIFICATION C

void glGetActiveSubroutineUniformName(GLuint program, GLenum shadertype, GLuint index, GLsizei bufSize, GLsizei *length, GLchar *name);

PARAMÈTRES

program

Spécifie le nom du programme contenant la sous-routine.

shadertype

Spécifie l'étape de shader à partir de laquelle interroger le paramètre de sous-routine. shadertype doit être l'un des suivants : GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER.

index

Spécifie l'index de l'uniforme de sous-routine du shader.

bufSize

Spécifie la taille du tampon dont l'adresse est donnée dans name.

length

Spécifie l'adresse d'une variable dans laquelle est écrit le nombre de caractères copiés dans name.

name

Spécifie l'adresse d'un tampon qui recevra le nom de l'uniforme de sous-routine de shader spécifié.

DESCRIPTION

glGetActiveSubroutineUniformName récupère le nom d'un uniforme de sous-routine de shader actif. program contient le nom du programme contenant l'uniforme. shadertype spécifie l'étape pour laquelle la localisation de l'uniforme, donnée par index, est valide. index doit être compris entre zéro et la valeur de GL_ACTIVE_SUBROUTINE_UNIFORMS moins un pour l'étape de shader.

Le nom de l'uniforme est renvoyé sous forme de chaîne terminée par un caractère nul dans name. Le nombre réel de caractères écrits dans name, excluant le terminateur nul, est renvoyé dans length. Si length est NULL, aucune longueur n'est renvoyée. Le nombre maximum de caractères pouvant être écrits dans name, y compris le terminateur nul, est spécifié par bufSize. La longueur du nom d'uniforme de sous-routine le plus long dans program et shadertype est donnée par la valeur de GL_ACTIVE_SUBROUTINE_UNIFORM_MAX_LENGTH, qui peut être interrogée avec glGetProgramStage().

ERREURS

GL_INVALID_ENUM est générée si shadertype ou pname ne fait pas partie des valeurs acceptées.

GL_INVALID_VALUE est générée si index est supérieur ou égal à la valeur de GL_ACTIVE_SUBROUTINE_UNIFORMS.

GL_INVALID_VALUE est générée si program n'est pas le nom d'un objet programme existant.

GETS ASSOCIÉS

glGetProgramStage() avec l'argument GL_ACTIVE_SUBROUTINE_UNIFORMS
