GLADE(1) Commandes utilisateur GLADE(1)

NOM

glade - Créer des interfaces utilisateur GTK+

SYNTAXE

glade [OPTION...] [FICHIER...]

DESCRIPTION

glade est un outil pour créer ou éditer des interfaces utilisateur pour les applications GTK+ ou GNOME. Il enregistre les descriptions d'interfaces utilisateur dans des fichiers xml qui peuvent être lus par l'API GtkBuilder, qui fait partie de GTK+.

OPTIONS

Les options suivantes peuvent être spécifiées :

-h, --help

Afficher les options d'aide.

--help-all

Afficher toutes les options d'aide.

--help-debug

Afficher les options de débogage de Glade.

--help-gtk

Afficher les options GTK+.

--version

Afficher les informations de version et quitter.

--without-devhelp

Désactiver l'intégration de devhelp.

--display=DISPLAY

Affichage X à utiliser.
