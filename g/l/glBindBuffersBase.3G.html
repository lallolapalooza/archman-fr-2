NOM

glBindBuffersBase - lie un ou plusieurs objets tampons à une séquence de cibles de tampon indexées

SP CIFICATION

void glBindBuffersBase(GLenum target, GLuint first, GLsizei count, const GLuint *buffers);

PARAMÈTRES

target

Spécifie la cible de l'opération de liaison. target doit être l'un de GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER ou GL_SHADER_STORAGE_BUFFER.

first

Spécifie l'indice du premier point de liaison dans le tableau spécifié par target.

count

Spécifie le nombre de points de liaison contigus auxquels lier les tampons.

buffers

Un pointeur vers un tableau de noms d'objets tampons à lier aux cibles du point de liaison spécifié, ou NULL.

DÉSCRIPPTION

glBindBuffersBase lie un ensemble de count objets tampons dont les noms sont donnés dans le tableau buffers aux count points de liaison consécutifs commençant à l'indice first du tableau de cibles spécifié par target. Si buffers est NULL, alors glBindBuffersBase délie les tampons actuellement liés aux points de liaison référencés. En supposant qu'aucune erreur ne soit générée, cela est équivalent au pseudo-code suivant, qui appelle glBindBufferBase(), à la différence près que la cible non indexée target n'est pas modifiée par glBindBuffersBase :

    for (i = 0; i < count; i++) {
        if (buffers != NULL) {
            glBindBufferBase(target, first + i, buffers[i]);
        } else {
            glBindBufferBase(target, first + i, 0);
        }
    }

Chaque entrée dans buffers sera vérifiée individuellement et si elle est trouvée invalide, l'état de cet index de liaison de tampon ne sera pas modifié et une erreur sera générée. Cependant, l'état des autres indices de liaison de tampon référencés par la commande sera toujours mis à jour.

NOTES

glBindBuffersBase n'est disponible que si la version GL est 4.4 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si target n'est pas GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER ou GL_SHADER_STORAGE_BUFFER.

GL_INVALID_OPERATION est généré si first + count est supérieur au nombre de points de liaison indexés spécifiques à la cible.

GL_INVALID_OPERATION est généré si une valeur dans buffers n'est pas zéro ou le nom d'un objet tampon existant.
