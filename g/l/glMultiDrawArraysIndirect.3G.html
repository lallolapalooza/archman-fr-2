NOM

glMultiDrawArraysIndirect - rend plusieurs ensembles de primitives à partir de données de tableaux, en prenant les paramètres de la mémoire

SPÉCIFICATION C

void glMultiDrawArraysIndirect(GLenum mode, const void *indirect, GLsizei drawcount, GLsizei stride);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

indirect

Spécifie l'adresse d'un tableau de structures contenant les paramètres de dessin.

drawcount

Spécifie le nombre d'éléments dans le tableau des structures de paramètres de dessin.

stride

Spécifie la distance en unités machine de base entre les éléments du tableau de paramètres de dessin.

DESCRIPTION

glMultiDrawArraysIndirect spécifie plusieurs primitives géométriques avec très peu d'appels de sous-routine. glMultiDrawArraysIndirect se comporte de manière similaire à une multitude d'appels à glDrawArraysInstancedBaseInstance(), sauf que les paramètres de chaque appel à glDrawArraysInstancedBaseInstance() sont stockés dans un tableau en mémoire à l'adresse indiquée par indirect, séparés par le pas (stride), en unités machine de base, spécifié par stride. Si stride est zéro, alors le tableau est supposé être compacté en mémoire.

Les paramètres adressés par indirect sont regroupés dans un tableau de structures, dont chaque élément prend la forme (en C) :

    typedef  struct {
        uint  count;
        uint  instanceCount;
        uint  first;
        uint  baseInstance;
    } DrawArraysIndirectCommand;

Un seul appel à glMultiDrawArraysIndirect est équivalent, en supposant qu'aucune erreur n'est générée, à :

    GLsizei n;
    for (n = 0; n < drawcount; n++) {
        const DrawArraysIndirectCommand *cmd;
        if (stride != 0) {
            cmd = (const DrawArraysIndirectCommand  *)((uintptr)indirect + n * stride);
        } else  {
            cmd = (const DrawArraysIndirectCommand  *)indirect + n;
        }
        glDrawArraysInstancedBaseInstance(mode, cmd->first, cmd->count, cmd->instanceCount, cmd->baseInstance);
    }

Si un tampon est lié à la liaison GL_DRAW_INDIRECT_BUFFER au moment d'un appel à glMultiDrawArraysIndirect, indirect est interprété comme un décalage, en unités machine de base, dans ce tampon et les données de paramètres sont lues à partir du tampon plutôt qu'à partir de la mémoire cliente.

Contrairement à glDrawArraysInstancedBaseInstance(), le premier membre de la structure de paramètres est non signé, et les indices hors limites ne génèrent pas d'erreur.

Les attributs de sommet qui sont modifiés par glMultiDrawArraysIndirect ont une valeur indéterminée après le retour de glMultiDrawArraysIndirect. Les attributs qui ne sont pas modifiés restent bien définis.

NOTES

Le membre baseInstance de la structure DrawArraysIndirectCommand n'est défini que si la version de GL est 4.2 ou supérieure. Pour les versions de GL antérieures à 4.2, ce paramètre est présent mais est réservé et doit être mis à zéro. Dans les versions antérieures de GL, le comportement est indéfini s'il est non nul.

glMultiDrawArraysIndirect n'est disponible que si la version de GL est 4.3 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si stride n'est pas un multiple de quatre.

GL_INVALID_VALUE est généré si drawcount est négatif.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé ou à la liaison GL_DRAW_INDIRECT_BUFFER et que le stockage de données de l'objet tampon est actuellement mappé.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si mode est GL_PATCHES et qu'aucun shader de contrôle de tessellation n'est actif.
