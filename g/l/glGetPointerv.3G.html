NOM

glGetPointerv - renvoie l'adresse du pointeur spécifié

SPÉCIFICATION C

void glGetPointerv(GLenum pname, void ** params);

PARAMÈTRES

pname

Spécifie le pointeur à renvoyer. Doit être l'une des constantes GL_DEBUG_CALLBACK_FUNCTION ou GL_DEBUG_CALLBACK_USER_PARAM.

params

Renvoie la valeur du pointeur spécifiée par pname.

DESCRIPTION

glGetPointerv renvoie des informations sur les pointeurs. pname indique le pointeur à renvoyer, et params est un pointeur vers un emplacement où stocker les données renvoyées. Les paramètres qui peuvent être interrogés incluent :

GL_DEBUG_CALLBACK_FUNCTION

Renvoie la fonction de rappel actuelle définie avec l'argument callback de glDebugMessageCallback().

GL_DEBUG_CALLBACK_USER_PARAM

Renvoie le paramètre utilisateur de la fonction de rappel actuelle définie avec l'argument userParam de glDebugMessageCallback().

NOTES

glGetPointerv est disponible dans le profil core d'OpenGL uniquement si la version GL est 4.3 ou ultérieure. Il est disponible dans le profil de compatibilité pour toutes les versions GL, et accepte des requêtes supplémentaires. Cependant, ces pages de référence ne documentent que le profil core.

ERREURS

GL_INVALID_ENUM est généré si pname n'est pas une valeur acceptée.
