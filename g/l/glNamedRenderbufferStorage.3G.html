NOM

glRenderbufferStorage, glNamedRenderbufferStorage - définir le stockage de données, le format et les dimensions de l'image d'un objet renderbuffer

SPÉCIFICATION C

void glRenderbufferStorage(GLenum target, GLenum internalformat, GLsizei width, GLsizei height);

void glNamedRenderbufferStorage(GLuint renderbuffer, GLenum internalformat, GLsizei width, GLsizei height);

PARAMÈTRES

target

Spécifie une cible de liaison pour l'allocation de la fonction glRenderbufferStorage. Doit être GL_RENDERBUFFER.

renderbuffer

Spécifie le nom de l'objet renderbuffer pour la fonction glNamedRenderbufferStorage.

internalformat

Spécifie le format interne à utiliser pour le stockage de l'image de l'objet renderbuffer.

width

Spécifie la largeur du renderbuffer, en pixels.

height

Spécifie la hauteur du renderbuffer, en pixels.

DESCRIPTION

glRenderbufferStorage est équivalent à appeler glRenderbufferStorageMultisample() avec samples défini à zéro, et glNamedRenderbufferStorage est équivalent à appeler glNamedRenderbufferStorageMultisample avec samples défini à zéro.

Pour glRenderbufferStorage, la cible de l'opération, spécifiée par target, doit être GL_RENDERBUFFER. Pour glNamedRenderbufferStorage, renderbuffer doit être le nom d'un objet renderbuffer existant. internalformat spécifie le format interne à utiliser pour le stockage de l'objet renderbuffer et doit être un format color-renderable, depth-renderable, ou stencil-renderable. width et height sont les dimensions, en pixels, du renderbuffer. Les deux, width et height, doivent être inférieurs ou égaux à la valeur de GL_MAX_RENDERBUFFER_SIZE.

En cas de succès, glRenderbufferStorage et glNamedRenderbufferStorage suppriment tout stockage de données existant pour l'image du renderbuffer et le contenu du stockage de données après l'appel de glRenderbufferStorage est indéfini.

ERREURS

GL_INVALID_ENUM est généré par glRenderbufferStorage si target n'est pas GL_RENDERBUFFER.

GL_INVALID_OPERATION est généré par glNamedRenderbufferStorage si renderbuffer n'est pas le nom d'un objet renderbuffer existant.

GL_INVALID_VALUE est généré si width ou height est négatif, ou supérieur à la valeur de GL_MAX_RENDERBUFFER_SIZE.

GL_INVALID_ENUM est généré si internalformat n'est pas un format color-renderable, depth-renderable, ou stencil-renderable.

GL_OUT_OF_MEMORY est généré si le GL est incapable de créer un stockage de données de la taille demandée.
