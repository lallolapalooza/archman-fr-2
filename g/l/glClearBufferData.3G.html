DESCRIPTIO

N

glClearBufferData et glClearNamedBufferData remplissent l'intégralité du magasin de données d'un objet tampon avec des données provenant de la mémoire

client.

Les données, initialement fournies dans un format spécifié par format avec un type de données type, sont lues à l'adresse mémoire donnée par data et converties en la représentation interne donnée par internalformat, qui doit être l'un des formats internes dimensionnés suivants

ERREUR

S

GL_INVALID_ENUM est généré par glClearBufferData si target n'est pas l'une des cibles de liaison de tampon

génériques.

GL_INVALID_VALUE est généré par glClearBufferData si aucun tampon n'est lié à target

.

GL_INVALID_OPERATION est généré par glClearNamedBufferData si buffer n'est pas le nom d'un objet tampon

existant.

GL_INVALID_ENUM est généré si internalformat n'est pas l'un des formats internes dimensionnés valides listés dans le tableau

ci-dessus.

GL_INVALID_OPERATION est généré si une partie de la plage spécifiée de l'objet tampon est mappée avec glMapBufferRange() ou glMapBuffer(), sauf si elle a été mappée avec le GL_MAP_PERSISTENT_BIT bit défini dans les drapeaux d'accès de glMapBufferRange

.

GL_INVALID_VALUE est généré si format n'est pas un format valide, ou si type n'est pas

un type
valide.
