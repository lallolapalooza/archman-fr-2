NOM

glGetActiveUniformBlockName - récupérer le nom d'un bloc uniforme actif

SPÉCIFICATION C

void glGetActiveUniformBlockName(GLuint program, GLuint uniformBlockIndex, GLsizei bufSize, GLsizei *length, GLchar *uniformBlockName);

PARAMÈTRES

program

Spécifie le nom d'un programme contenant le bloc uniforme.

uniformBlockIndex

Spécifie l'index du bloc uniforme dans program.

bufSize

Spécifie la taille du tampon adressé par uniformBlockName.

length

Spécifie l'adresse d'une variable pour recevoir le nombre de caractères qui ont été écrits dans uniformBlockName.

uniformBlockName

Spécifie l'adresse d'un tableau de caractères pour recevoir le nom du bloc uniforme à uniformBlockIndex.

DESCRIPTION

glGetActiveUniformBlockName récupère le nom du bloc uniforme actif à uniformBlockIndex dans program.

program doit être le nom d'un objet programme pour lequel la commande glLinkProgram() a dû être appelée par le passé, bien qu'il ne soit pas obligatoire que glLinkProgram() ait réussi. Le lien peut avoir échoué car le nombre d'uniformes actifs dépassait la limite.

uniformBlockIndex est un index de bloc uniforme actif de program, et doit être inférieur à la valeur de GL_ACTIVE_UNIFORM_BLOCKS.

En cas de succès, le nom du bloc uniforme identifié par unifomBlockIndex est renvoyé dans uniformBlockName. Le nom est terminé par un caractère nul. Le nombre réel de caractères écrits dans uniformBlockName, excluant le terminateur nul, est renvoyé dans length. Si length est NULL, aucune longueur n'est renvoyée.

bufSize contient le nombre maximum de caractères (y compris le terminateur nul) qui seront écrits dans uniformBlockName.

Si une erreur survient, rien ne sera écrit dans uniformBlockName ou length.

ERREURS

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un objet programme pour lequel glLinkProgram() a été appelé par le passé.

GL_INVALID_VALUE est généré si uniformBlockIndex est supérieur ou égal à la valeur de GL_ACTIVE_UNIFORM_BLOCKS ou n'est pas l'index d'un bloc uniforme actif dans program.

NOTES

glGetActiveUniformBlockName n'est disponible que si la version de GL est 3.1 ou supérieure.
