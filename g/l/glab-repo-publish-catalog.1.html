NOM

glab-repo-publish-catalog - [EXPÉRIMENTAL] Publie les composants CI/CD dans le catalogue.

SYNTAXE

glab repo publish catalog [options]

DESCRIPTION

[EXPÉRIMENTAL] Publie les composants CI/CD du projet dans le catalogue CI/CD en utilisant le nom de balise fourni.

Nécessite que le drapeau de fonctionnalité ci_release_cli_catalog_publish_option soit activé pour ce projet dans votre instance GitLab.

Nécessite le même utilisateur que l'auteur de la publication.

  • Il récupère les composants du dépôt actuel en recherchant les fichiers yml dans le répertoire "templates" et ses sous-répertoires.
  • Il échoue si le drapeau de fonctionnalité ci_release_cli_catalog_publish_option n'est pas activé pour ce projet dans votre instance GitLab.

Les composants peuvent être définis :

  • Dans des fichiers uniques se terminant par .yml pour chaque composant, comme templates/secret-detection.yml.
  • Dans des sous-répertoires contenant des fichiers template.yml comme points d'entrée, pour les composants qui regroupent plusieurs fichiers associés. Par exemple, templates/secret-detection/template.yml.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

- glab repo publish catalog v1.2.3
