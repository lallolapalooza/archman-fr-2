PARAMÈTRES

location

Spécifie l'emplacement de la variable uniforme à modifier.

count

Pour les commandes vectorielles (glUniform*v), spécifie le nombre d'éléments à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau, et 1 ou plus si c'est un tableau.

Pour les commandes matricielles (glUniformMatrix*), spécifie le nombre de matrices à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau de matrices, et 1 ou plus si c'est un tableau de matrices.

transpose

Pour les commandes matricielles, spécifie si la matrice doit être transposée lors du chargement des valeurs dans la variable uniforme.

v0, v1, v2, v3

Pour les commandes scalaires, spécifie les nouvelles valeurs à utiliser pour la variable uniforme spécifiée.

value

Pour les commandes vectorielles et matricielles, spécifie un pointeur vers un tableau de count valeurs qui seront utilisées pour mettre à jour la variable uniforme spécifiée.

DESCRIPTION

glUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant par l'appel à glUseProgram().

Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs flottantes sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs aux variables uniformes définies comme int,

PARAMETERS

location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of matrices that will be downloaded and sent to the uniform variable.
transpose
Specifies whether each individual matrix is transposed before being unpacked into the active uniform variable. Must be GL_FALSE.
value
Specifies a pointer to an array of `count` values that will be used to update the uniform variable.

DESCRIPTION

glUniformMatrix*fv routines update the value of a uniform variable within the current active program object. They should be called only between a glUseProgram and the next call to glUseProgram, or between the execution of glBeginConditionalRender and glEndConditionalRender. If the named uniform variable is not active in the current program object, or if location is not valid for the current program object, these routines do nothing.

The uniform variable can be a matrix or an array of matrices. The matrix types are specified by their dimensions. For example, glUniformMatrix2fv specifies a uniform variable that is either a 2x2 matrix, or an array of 2x2 matrices. The dimensions are always specified with the height first, then the width. For example, glUniformMatrix2x3fv specifies a 2x3 matrix. The suffix ‘fv’ indicates that the data is specified as an array of floating-point values.

The matrices are unpacked from the array pointed to by value. For example, a 2x2 matrix requires 4 floating-point values. A 4x4 matrix requires 16 floating-point values. The matrices are loaded into the uniform variable in column-major order. The transpose parameter must be GL_FALSE, as transposition is not supported.

If the uniform variable is an array of matrices, the matrices in the array are loaded contiguously into the uniform variable. For example, if location points to the first element of an array of 3x3 matrices, and count is 2, then the first 18 floats in value will be used to update the first matrix, and the next 18 floats will be used to update the second matrix.

If the uniform variable is not a matrix or an array of matrices, or if its data type does not match the specified uniform type (e.g., attempting to set a matrix uniform with a vector uniform function), a GL_INVALID_OPERATION error is generated.

If location is not valid, a GL_INVALID_OPERATION error is generated.

NOTES

The value of a uniform variable can also be set using a single matrix or an array of matrices using the corresponding `glUniform*ui*v` or `glUniform*i*v` functions, but these are only intended for integer uniforms.

The constants GL_TRUE and GL_FALSE are defined in <GL/gl.h>.

ERRORS

GL_INVALID_OPERATION is generated if glUniformMatrix*fv is included in a call to glBeginQuery and glEndQuery.

GL_INVALID_OPERATION is generated if the specified uniform variable is not the correct type, or if location is not valid.
