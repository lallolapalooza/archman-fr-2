NOM

glGetShaderSource - Récupère la chaîne de code source d'un objet shader

SPÉCIFICATION C

void glGetShaderSource(GLuint shader, GLsizei bufSize, GLsizei *length, GLchar *source);

PARAMÈTRES

shader

Spécifie l'objet shader à interroger.

bufSize

Spécifie la taille du tampon de caractères pour stocker la chaîne de code source retournée.

length

Retourne la longueur de la chaîne retournée dans source (hors terminateur nul).

source

Spécifie un tableau de caractères utilisé pour retourner la chaîne de code source.

DESCRIPTION

glGetShaderSource retourne la concaténation des chaînes de code source de l'objet shader spécifié par shader. Les chaînes de code source d'un objet shader sont le résultat d'un appel précédent à glShaderSource(). La chaîne retournée par la fonction sera terminée par un caractère nul.

glGetShaderSource retourne dans source autant de la chaîne de code source que possible, jusqu'à un maximum de bufSize caractères. Le nombre de caractères réellement retournés, hors caractère de terminaison nulle, est spécifié par length. Si la longueur de la chaîne retournée n'est pas requise, une valeur de NULL peut être passée dans l'argument length. La taille du tampon requis pour stocker la chaîne de code source retournée peut être obtenue en appelant glGetShader() avec la valeur GL_SHADER_SOURCE_LENGTH.

ERREURS

GL_INVALID_VALUE est généré si shader n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si shader n'est pas un objet shader.

GL_INVALID_VALUE est généré si bufSize est inférieur à 0.

OBTIENT ASSOCIÉS

glGetShader() avec l'argument GL_SHADER_SOURCE_LENGTH

glIsShader()
