NOM

glActiveShaderProgram - définit l'objet programme actif pour un objet pipeline de programmes

SPÉCIFICATION C

void glActiveShaderProgram(GLuint pipeline, GLuint program);

PARAMÈTRES

pipeline

Spécifie l'objet pipeline de programmes pour lequel définir l'objet programme actif.

program

Spécifie l'objet programme à définir comme objet programme actif pour le pipeline de programmes pipeline.

DESCRIPTION

glActiveShaderProgram définit le programme lié nommé par program comme programme actif pour l'objet pipeline de programmes pipeline. Le programme actif dans l'objet pipeline de programmes actif est la cible des appels à glUniform() lorsqu'aucun programme n'a été rendu courant par un appel à glUseProgram().

ERREURS

GL_INVALID_OPERATION est généré si pipeline n'est pas un nom précédemment retourné par un appel à glGenProgramPipelines() ou si un tel nom a été supprimé par un appel à glDeleteProgramPipelines().

GL_INVALID_OPERATION est généré si program fait référence à un objet programme qui n'a pas été lié avec succès.
