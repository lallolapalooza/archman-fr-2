NOM

glutRemoveMenuItem - supprimer l'élément de menu spécifié.

SYNTAXE

void glutRemoveMenuItem(int entry);

ARGUMENTS

entry
Index parmi les éléments de menu du menu actuel (1 est l'élément de menu le plus haut).

DESCRIPTION

glutRemoveMenuItem supprime l'élément de menu d'index entry, qu'il s'agisse d'une entrée de menu ou d'un déclencheur de sous-menu. entry doit être compris entre 1 et glutGet(GLUT_MENU_NUM_ITEMS) inclus. Les éléments de menu situés en dessous de l'élément de menu supprimé sont renumérotés.

VOIR AUSSI

glutAddMenuEntry, glutAddSubMenu, glutChangeToMenuEntry, glutChangeToSubMenu
