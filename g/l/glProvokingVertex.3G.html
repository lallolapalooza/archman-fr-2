GLPROVOKINGVERTEX(3G) [FIXME: manuel] GLPROVOKINGVERTEX(3G)

NOM

glProvokingVertex - spécifie le sommet à utiliser comme source de données pour les variables lissées à plat

SPÉCIFICATION C

void glProvokingVertex(GLenum provokeMode);

PARAMÈTRES

provokeMode

Spécifie le sommet à utiliser comme source de données pour les variables lissées à plat.

DESCRIPTION

Le lissage à plat d'une sortie variable d'un shader de sommets signifie attribuer à tous les sommets du primitif la même valeur pour cette sortie. Le sommet à partir duquel ces valeurs sont dérivées est connu sous le nom de sommet provocateur et glProvokingVertex spécifie quel sommet doit être utilisé comme source de données pour les variables lissées à plat.

provokeMode doit être soit GL_FIRST_VERTEX_CONVENTION, soit GL_LAST_VERTEX_CONVENTION, et contrôle la sélection du sommet dont les valeurs sont attribuées aux sorties variables lissées à plat. L'interprétation de ces valeurs pour les types de primitives pris en charge est la suivante :

Type de primitive du polygone Convention du premier sommet Convention du dernier sommet
point i i
ligne indépendante 2i - 1 2i
boucle de ligne i i + 1, si i < n .PP 1, si i = n
bande de ligne i i + 1
triangle indépendant 3i - 2 3i
bande de triangle i i + 2
éventail de triangle i + 1 i + 2
adjacence de ligne 4i - 2 4i - 1
bande d'adjacence de ligne i + 1 i + 2
adjacence de triangle 6i - 5 6i - 1
bande d'adjacence de triangle 2i - 1 2i + 3

Si un shader de sommets ou de géométrie est actif, les sorties variables définies par l'utilisateur peuvent être lissées à plat en utilisant le qualificateur `flat` lors de la déclaration de la sortie.

NOTES

glProvokingVertex n'est disponible que si la version de GL est supérieure ou égale à 3.2.

ERREURS

GL_INVALID_ENUM est généré si provokeMode n'est pas une valeur acceptée.
