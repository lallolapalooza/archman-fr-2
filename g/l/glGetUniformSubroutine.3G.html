NOM

glGetUniformSubroutine - récupérer la valeur d'un uniforme de sous-routine d'une étape de shader donnée du programme courant

SPÉCIFICATION C

void glGetUniformSubroutineuiv(GLenum shadertype, GLint location, GLuint *values);

PARAMÈTRES

shadertype

Spécifie l'étape du shader dont on veut interroger l'indice d'uniforme de sous-routine. shadertype doit être l'un des suivants : GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER.

location

Spécifie l'emplacement de l'uniforme de sous-routine.

values

Spécifie l'adresse d'une variable pour recevoir la ou les valeurs de l'uniforme de sous-routine.

DESCRIPTION

glGetUniformSubroutine récupère la valeur de l'uniforme de sous-routine à l'emplacement location pour l'étape de shader shadertype du programme courant. location doit être inférieur à la valeur de GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS pour le shader actuellement utilisé à l'étape de shader shadertype. La valeur de l'uniforme de sous-routine est retournée dans values.

ERREURS

GL_INVALID_ENUM est généré si shadertype n'est pas l'une des valeurs acceptées.

GL_INVALID_VALUE est généré si location est supérieure ou égale à la valeur de GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS pour le shader actuellement utilisé à l'étape de shader shadertype.

GL_INVALID_OPERATION est généré si aucun programme n'est actif.
