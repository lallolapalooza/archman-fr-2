NOM

glab-repo-create - Crée un nouveau projet/dépôt GitLab.

SYNTAXE

glab repo create [chemin] [options]

DESCRIPTION

Crée le nouveau projet avec votre premier hôte configuré dans votre configuration glab. L'hôte par défaut est GitLab.com s'il n'est pas défini. Pour définir un hôte, fournissez l'un des éléments suivants :

  • Une variable d'environnement GITLAB_HOST.
  • Une URL complète pour le projet.

OPTIONS

--defaultBranch="" Branche par défaut du projet. La valeur par défaut est master si non fournie.

-d, --description="" Description du nouveau projet.

-g, --group="" Espace de noms ou groupe pour le nouveau projet. La valeur par défaut est l'espace de noms de l'utilisateur actuel.

--internal[=false] Rendre le projet interne : visible par tout utilisateur authentifié. Par défaut.

-n, --name="" Nom du nouveau projet.

-p, --private[=false] Rendre le projet privé : visible uniquement par les membres du projet.

-P, --public[=false] Rendre le projet public : visible sans aucune authentification.

--readme[=false] Initialiser le projet avec README.md.

--remoteName="origin" Nom de la télécommande pour le dépôt Git dans lequel vous vous trouvez. La valeur par défaut est origin si non fournie.

-s, --skipGitInit[=false] Ignorer l'exécution de 'git init'.

-t, --tag=[] La liste des tags pour le projet.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

# Crée un dépôt sous votre compte en utilisant le nom du répertoire courant.
$ glab repo create
# Crée un dépôt sous un groupe en utilisant le nom du répertoire courant.
$ glab repo create --group glab-cli
# Crée un dépôt avec un nom spécifique.
$ glab repo create mon-projet
# Crée un dépôt pour un groupe.
$ glab repo create glab-cli/mon-projet
# Crée sur un hôte autre que gitlab.com.
$ GITLAB_HOST=example.com glab repo create
$ glab repo create <host>/chemin/vers/le/depot
