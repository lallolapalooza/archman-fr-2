NOM

glDrawArrays - rendu de primitives à partir de données de tableau

SPÉCIFICATION C

void glDrawArrays(GLenum mode, GLint first, GLsizei count);

PARAMÈTRES

mode

Spécifie quel type de primitives rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

first

Spécifie l'indice de départ dans les tableaux activés.

count

Spécifie le nombre d'indices à rendre.

DESCRIPTION

glDrawArrays spécifie plusieurs primitives géométriques avec très peu d'appels de sous-routine. Au lieu d'appeler une procédure GL pour passer chaque sommet, normale, coordonnée de texture, drapeau d'arête ou couleur individuellement, vous pouvez pré-spécifier des tableaux séparés de sommets, de normales et de couleurs et les utiliser pour construire une séquence de primitives avec un seul appel à glDrawArrays.

Lorsque glDrawArrays est appelée, elle utilise count éléments séquentiels de chaque tableau activé pour construire une séquence de primitives géométriques, en commençant par l'élément first. mode spécifie quel type de primitives sont construites et comment les éléments du tableau construisent ces primitives.

Les attributs de sommet qui sont modifiés par glDrawArrays ont une valeur indéfinie après le retour de glDrawArrays. Les attributs qui ne sont pas modifiés restent bien définis.

NOTES

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_TRIANGLES_ADJACENCY ne sont disponibles que si la version de GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si count est négatif.

GL_INVALID_OPERATION est généré si un objet tampon non nul est lié à un tableau activé et que le magasin de données de l'objet tampon est actuellement mappé.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.
