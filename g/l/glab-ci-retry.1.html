NOM

glab-ci-retry - Réessayer un travail CI/CD.

SYNOPIS

glab ci retry [options]

DESCRIPTION

Réessayer un travail CI/CD.

OPTIONS

-b, --branch="" La branche pour rechercher le travail. (branche actuelle par défaut)

-p, --pipeline-id=0 L'ID du pipeline pour rechercher le travail.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

# Sélectionner interactivement un travail à retenter
$ glab ci retry
# Retenter le travail avec l'ID 224356863
$ glab ci retry 224356863
# Retenter le travail nommé 'lint'
$ glab ci retry lint
