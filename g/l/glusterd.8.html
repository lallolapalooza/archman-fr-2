NOM

Glusterd - démon de gestion de volumes élastiques Gluster

SYNTAXE

glusterd [OPTION...]

DESCRIPTION

Le démon glusterd est utilisé pour la gestion de volumes élastiques. Le démon doit être exécuté sur tous les serveurs d'exportation.

OPTIONS

Options de base

-l <FICHIER_JOURNAL>, --log-file=<FICHIER_JOURNAL>
Fichier à utiliser pour la journalisation.
-L <NIVEAU_JOURNAL>, --log-level=<NIVEAU_JOURNAL>
Gravité de la journalisation. Les options valides sont TRACE, DEBUG, INFO, WARNING, ERROR et CRITICAL (INFO est la valeur par défaut).
--localtime-logging
Active les horodatages locaux dans les journaux.
--debug
Exécute le programme en mode débogage. Cette option définit --no-daemon, --log-level sur DEBUG et --log-file sur la console.
-N, --no-daemon
Exécute le programme en premier plan.

Options diverses :

-?, --help
Affiche cette aide.
--usage
Affiche un bref message d'utilisation.
-V, --version
Affiche la version du programme.

FICHIERS

/var/lib/glusterd/*
