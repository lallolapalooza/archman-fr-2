NOM

glBindBufferRange - lier une plage dans un objet tampon à une cible de tampon indexée

SPÉCIFICATION C

void glBindBufferRange(GLenum target, GLuint index, GLuint buffer, GLintptr offset, GLsizeiptr size);

PARAMÈTRES

target

Spécifie la cible de l'opération de liaison. target doit être l'un des GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER, ou GL_SHADER_STORAGE_BUFFER.

index

Spécifie l'indice du point de liaison dans le tableau spécifié par target.

buffer

Le nom d'un objet tampon à lier au point de liaison spécifié.

offset

Le décalage de départ en unités de machine de base dans l'objet tampon buffer.

size

La quantité de données en unités de machine qui peut être lue à partir de l'objet tampon lorsqu'il est utilisé comme cible indexée.

DESCRIPTION

glBindBufferRange lie une plage de l'objet tampon buffer représentée par offset et size au point de liaison à l'indice index du tableau de cibles spécifié par target. Chaque target représente un tableau indexé de points de liaison de tampon, ainsi qu'un point de liaison général unique qui peut être utilisé par d'autres fonctions de manipulation de tampon telles que glBindBuffer() ou glMapBuffer(). En plus de lier une plage de buffer à la cible de liaison de tampon indexée, glBindBufferRange lie également la plage au point de liaison de tampon générique spécifié par target.

offset spécifie le décalage en unités de machine de base dans l'objet tampon buffer et size spécifie la quantité de données qui peut être lue à partir de l'objet tampon lorsqu'il est utilisé comme cible indexée.

NOTES

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version GL est 4.2 ou supérieure.

La cible GL_SHADER_STORAGE_BUFFER n'est disponible que si la version GL est 4.3 ou supérieure.

ERREURS

GL_INVALID_ENUM est générée si target n'est pas l'un des GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER ou GL_SHADER_STORAGE_BUFFER.

GL_INVALID_VALUE est générée si index est supérieur ou égal au nombre de points de liaison indexés spécifiques à target.

GL_INVALID_VALUE est générée si size est inférieur ou égal à zéro, ou si offset + size est supérieur à la valeur de GL_BUFFER_SIZE.

Des erreurs supplémentaires peuvent être générées si offset enfreint des restrictions d'alignement spécifiques à target.
