GLPATCHPARAMETER(3G) [FIXME: manual] GLPATCHPARAMETER(3G)

NOM

glPatchParameter - spécifie les paramètres pour les primitives de patch

SPÉCIFICATION C

void glPatchParameteri(GLenum pname, GLint value);

void glPatchParameterfv(GLenum pname, const GLfloat *values);

PARAMÈTRES

pname

Spécifie le nom du paramètre à définir. Les constantes symboliques GL_PATCH_VERTICES, GL_PATCH_DEFAULT_OUTER_LEVEL et GL_PATCH_DEFAULT_INNER_LEVEL sont acceptées.

value

Spécifie la nouvelle valeur du paramètre donné par pname.

values

Spécifie l'adresse d'un tableau contenant les nouvelles valeurs du paramètre donné par pname.

DESCRIPTION

glPatchParameter spécifie les paramètres qui seront utilisés pour les primitives de patch. pname spécifie le paramètre à modifier et doit être soit GL_PATCH_VERTICES, GL_PATCH_DEFAULT_OUTER_LEVEL soit GL_PATCH_DEFAULT_INNER_LEVEL. Pour glPatchParameteri, value spécifie la nouvelle valeur pour le paramètre spécifié par pname. Pour glPatchParameterfv, values spécifie l'adresse d'un tableau contenant les nouvelles valeurs pour le paramètre spécifié par pname.

Lorsque pname est GL_PATCH_VERTICES, value spécifie le nombre de sommets qui seront utilisés pour former une primitive de patch unique. Les primitives de patch sont consommées par le shader de contrôle de tessellation (s'il est présent) et utilisées ultérieurement pour la tessellation. Lorsque des primitives sont spécifiées à l'aide de glDrawArrays() ou d'une fonction similaire, chaque patch sera composé de parameter points de contrôle, chacun représenté par un sommet pris dans les tableaux de sommets activés. parameter doit être supérieur à zéro et inférieur ou égal à la valeur de GL_MAX_PATCH_VERTICES.

Lorsque pname est GL_PATCH_DEFAULT_OUTER_LEVEL ou GL_PATCH_DEFAULT_INNER_LEVEL, values contient l'adresse d'un tableau contenant les niveaux de tessellation externes ou internes par défaut, respectivement, à utiliser lorsqu'aucun shader de contrôle de tessellation n'est présent.

ERREURS

GL_INVALID_ENUM est généré si pname n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si pname est GL_PATCH_VERTICES et que value est inférieur ou égal à zéro, ou supérieur à la valeur de GL_MAX_PATCH_VERTICES.
