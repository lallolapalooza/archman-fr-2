NOM

glBindAttribLocation - Associe un index d'attribut de sommet générique avec une variable d'attribut nommée

SPÉCIFICATION C

void glBindAttribLocation(GLuintprogram, GLuintindex, const GLchar *name);

PARAMÈTRES

program

Spécifie le handle de l'objet programme dans lequel l'association doit être faite.

index

Spécifie l'index de l'attribut de sommet générique à lier.

name

Spécifie une chaîne terminée par un caractère nul contenant le nom de la variable d'attribut du vertex shader à laquelle index doit être lié.

DESCRIPTION

glBindAttribLocation est utilisé pour associer une variable d'attribut définie par l'utilisateur dans l'objet programme spécifié par program avec un index d'attribut de sommet générique. Le nom de la variable d'attribut définie par l'utilisateur est passé sous forme de chaîne terminée par un caractère nul dans name. L'index d'attribut de sommet générique à lier à cette variable est spécifié par index. Quand program fait partie de l'état courant, les valeurs fournies via l'attribut de sommet générique index modifieront la valeur de la variable d'attribut définie par l'utilisateur spécifiée par name.

Si name fait référence à une variable d'attribut matricielle, index fait référence à la première colonne de la matrice. Les autres colonnes de la matrice sont alors automatiquement liées aux emplacements index+1 pour une matrice de type mat2; index+1 et index+2 pour une matrice de type mat3; et index+1, index+2, et index+3 pour une matrice de type mat4.

Cette commande permet aux vertex shaders d'utiliser des noms descriptifs pour les variables d'attribut plutôt que des variables génériques numérotées de zéro à la valeur de GL_MAX_VERTEX_ATTRIBS moins un. Les valeurs envoyées à chaque index d'attribut générique font partie de l'état courant. Si un objet programme différent est rendu courant en appelant glUseProgram(), les attributs de sommet génériques sont suivis de telle façon que les mêmes valeurs seront observées par les attributs du nouvel objet programme qui sont également liés à index.

Les liaisons nom de variable d'attribut vers index d'attribut générique pour un objet programme peuvent être explicitement assignées à tout moment en appelant glBindAttribLocation. Les liaisons d'attributs ne prennent pas effet avant l'appel de glLinkProgram(). Après qu'un objet programme a été lié avec succès, les valeurs d'index pour les attributs génériques restent fixes (et leurs valeurs peuvent être interrogées) jusqu'à ce que la prochaine commande de liaison ait lieu.

Toute liaison d'attribut qui se produit après que l'objet programme a été lié ne prendra pas effet avant la prochaine fois où l'objet programme est lié.

NOTES

glBindAttribLocation peut être appelé avant que des objets vertex shader soient liés à l'objet programme spécifié. Il est également permis de lier un index d'attribut générique à un nom de variable d'attribut qui n'est jamais utilisé dans un vertex shader.

Si name avait été lié précédemment, cette information est perdue. Ainsi, vous ne pouvez pas lier une variable d'attribut définie par l'utilisateur à plusieurs index, mais vous pouvez lier plusieurs variables d'attribut définies par l'utilisateur au même index.

Les applications sont autorisées à lier plus d'une variable d'attribut définie par l'utilisateur au même index d'attribut de sommet générique. C'est ce qu'on appelle l'aliasing, et cela n'est autorisé que si un seul des attributs aliasés est actif dans le programme exécutable, ou si aucun chemin à travers le shader ne consomme plus d'un attribut d'un ensemble d'attributs aliasés vers le même emplacement. Le compilateur et l'éditeur de liens sont autorisés à supposer qu'aucun aliasing n'est fait et sont libres d'employer des optimisations qui ne fonctionnent qu'en l'absence d'aliasing. Les implémentations OpenGL ne sont pas tenues de faire de vérification d'erreurs pour détecter l'aliasing.

Les attributs actifs qui ne sont pas explicitement liés seront liés par l'éditeur de liens quand glLinkProgram() est appelé. Les emplacements assignés peuvent être interrogés en appelant glGetAttribLocation().

OpenGL copie la chaîne name quand glBindAttribLocation est appelé, de sorte qu'une application peut libérer sa copie de la chaîne name

immédiatement après le retour de la fonction. Les emplacements d'attributs génériques peuvent être spécifiés dans le texte source du shader en utilisant un qualificateur de disposition location . Dans ce cas, l'emplacement de l'attribut spécifié dans la source du shader prend le dessus et peut être interrogé en appelantglGetAttribLocation

().

ERREUR GL_INVALID_VALUE est généré si index est supérieur ou égal àGL_MAX_VERTEX_ATTRIBS

. GL_INVALID_OPERATION est généré si name

commence par le préfixe réservé "gl_". GL_INVALID_VALUE est généré si program

n'est pas une valeur générée par OpenGL. GL_INVALID_OPERATION est généré si program

n'est pas un objet programme.
