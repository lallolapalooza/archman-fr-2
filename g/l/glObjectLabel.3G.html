GLOBJECTLABEL(3G) [FIXME : manuel] GLOBJECTLABEL(3G)

NOM

glObjectLabel - étiquette un objet nommé identifié dans un espace de noms

SPÉCIFICATION C

void glObjectLabel(GLenum identifier, GLuint name, GLsizei length, const char * label);

PARAMÈTRES

identifier

L'espace de noms à partir duquel le nom de l'objet est alloué.

name

Le nom de l'objet à étiqueter.

length

La longueur de l'étiquette à utiliser pour l'objet.

label

L'adresse d'une chaîne de caractères contenant l'étiquette à attribuer à l'objet.

DESCRIPTION

glObjectLabel étiquette l'objet identifié par name dans l'espace de noms donné par identifier. identifier doit être l'un des GL_BUFFER, GL_SHADER, GL_PROGRAM, GL_VERTEX_ARRAY, GL_QUERY, GL_PROGRAM_PIPELINE, GL_TRANSFORM_FEEDBACK, GL_SAMPLER, GL_TEXTURE, GL_RENDERBUFFER, GL_FRAMEBUFFER, pour indiquer respectivement l'espace de noms contenant les noms des tampons, shaders, programmes, objets de tableau de sommets, objets de requête, pipelines de programmes, objets de retour de transformation, échantillonneurs, textures, tampons de rendu et tampons d'images.

label est l'adresse d'une chaîne de caractères qui sera utilisée pour étiqueter un objet. length contient le nombre de caractères dans label. Si length est négatif, il est implicite que label contient une chaîne terminée par un caractère nul. Si label est NULL, toute étiquette de débogage est effectivement supprimée de l'objet.

ERREURS

GL_INVALID_ENUM est généré si identifier n'est pas l'un des types d'objets acceptés.

GL_INVALID_OPERATION est généré si name n'est pas le nom d'un objet existant du type spécifié par identifier.

GL_INVALID_VALUE est généré si le nombre de caractères dans label, excluant le terminateur nul lorsque length est négatif, est supérieur à la valeur de GL_MAX_LABEL_LENGTH.

GETS ASSOCIÉS

glGet() avec l'argument GL_MAX_LABEL_LENGTH.
