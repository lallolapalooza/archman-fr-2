NOM

glab-auth-login - S'authentifier auprès d'une instance GitLab.

SYNTAXE

glab auth login [indicateurs]

DESCRIPTION

S'authentifie auprès d'une instance GitLab. Vous pouvez passer un jeton en entrée standard en utilisant --stdin. Les portées minimales requises pour le jeton sont : api, write_repository. La configuration et les identifiants sont stockés dans le fichier de configuration global (par défaut ~/.config/glab-cli/config.yml)

Lors de l'exécution en mode interactif à l'intérieur d'un dépôt Git, glab détectera automatiquement les instances GitLab à partir de vos dépôts distants Git et les présentera comme options, vous évitant ainsi de devoir taper manuellement le nom d'hôte.

INDICATEURS

-a, --api-host="" URL de l'hôte de l'API.

-p, --api-protocol="" Protocole de l'API : https, http

-g, --git-protocol="" Protocole Git : ssh, https, http

--hostname="" Le nom d'hôte de l'instance GitLab auprès de laquelle s'authentifier.

-j, --job-token="" Jeton de travail CI.

--stdin[=false] Lire le jeton depuis l'entrée standard.

-t, --token="" Votre jeton d'accès GitLab.

--use-keyring[=false] Stocker le jeton dans le trousseau de clés de votre système d'exploitation.

INDICATEURS HERITE DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

# Démarrer la configuration interactive
# (Si dans un dépôt Git, glab détectera et suggérera les instances GitLab à partir des dépôts distants)
$ glab auth login
# S'authentifier auprès de `gitlab.com` en lisant le jeton depuis un fichier
$ glab auth login --stdin < monaccesstoken.txt
# S'authentifier auprès de GitLab Self-Managed ou GitLab Dedicated
$ glab auth login --hostname salsa.debian.org
# Configuration non interactive
$ glab auth login --hostname gitlab.example.org --token glpat-xxx --api-host gitlab.example.org:3443 --api-protocol https --git-protocol ssh
# Configuration non interactive lisant le jeton depuis un fichier
$ glab auth login --hostname gitlab.example.org --api-host gitlab.example.org:3443 --api-protocol https --git-protocol ssh  --stdin < monaccesstoken.txt
# Configuration non interactive CI/CD
$ glab auth login --hostname $CI_SERVER_HOST --job-token $CI_JOB_TOKEN
