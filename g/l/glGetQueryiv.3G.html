NOM

glGetQueryiv - renvoie les paramètres d'une cible d'objet de requête

SPÉCIFICATION C

void glGetQueryiv(GLenum target, GLenum pname, GLint * params);

PARAMÈTRES

target

Spécifie une cible d'objet de requête. Doit être GL_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED_CONSERVATIVE GL_PRIMITIVES_GENERATED, GL_TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN, GL_TIME_ELAPSED, ou GL_TIMESTAMP.

pname

Spécifie le nom symbolique d'un paramètre de cible d'objet de requête. Les valeurs acceptées sont GL_CURRENT_QUERY ou GL_QUERY_COUNTER_BITS.

params

Retourne les données demandées.

DESCRIPTION

glGetQueryiv renvoie dans params un paramètre sélectionné de la cible d'objet de requête spécifiée par target.

pname nomme un paramètre spécifique de la cible d'objet de requête. Lorsque pname est GL_CURRENT_QUERY, le nom de la requête actuellement active pour target, ou zéro si aucune requête n'est active, sera placé dans params. Si pname est GL_QUERY_COUNTER_BITS, le nombre de bits, dépendant de l'implémentation, utilisé pour contenir le résultat des requêtes pour target est retourné dans params.

NOTES

La cible GL_ANY_SAMPLES_PASSED_CONSERVATIVE est disponible uniquement si la version GL est 4.3 ou supérieure.

Si une erreur est générée, aucune modification n'est apportée au contenu de params.

ERREURS

GL_INVALID_ENUM est généré si target ou pname n'est pas une valeur acceptée.
