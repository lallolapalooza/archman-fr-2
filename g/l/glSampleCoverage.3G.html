NOM

glSampleCoverage - spécifie les paramètres de couverture multisampling

SPÉCIFICATION C

void glSampleCoverage(GLfloat value, GLboolean invert);

PARAMÈTRES

value

Spécifie une valeur unique de couverture d'échantillon en virgule flottante. La valeur est bornée dans l'intervalle 0 1. La valeur initiale est 1.0.

invert

Spécifie une valeur booléenne unique représentant si les masques de couverture doivent être inversés. GL_TRUE et GL_FALSE sont acceptés. La valeur initiale est GL_FALSE.

DESCRIPTION

Le multisampling échantillonne un pixel plusieurs fois à divers emplacements sous-pixel dépendant de l'implémentation pour générer des effets d'anti-aliasing. Le multisampling anti-aliase de manière transparente les points, les lignes, les polygones et les images s'il est activé.

value est utilisé pour construire un masque temporaire utilisé pour déterminer quels échantillons seront utilisés dans la résolution de la couleur finale du fragment. Ce masque est combiné par un ET bit à bit avec le masque de couverture généré par le calcul multisampling. Si le flag invert est activé, le masque temporaire est inversé (tous les bits sont retournés) puis le ET bit à bit est calculé.

Si une implémentation ne dispose d'aucun tampon multisample disponible, ou si le multisampling est désactivé, la rastérisation se produit avec un seul échantillon calculant la couleur RVB finale d'un pixel.

À condition qu'une implémentation supporte les tampons multisample et que le multisampling soit activé, la couleur finale d'un pixel est générée en combinant plusieurs échantillons par pixel. Chaque échantillon contient des informations de couleur, de profondeur et de stencil, permettant à ces opérations d'être effectuées sur chaque échantillon.

NOTES

Le type du paramètre value a été changé de GLclampf à GLfloat. Ce changement est transparent pour le code utilisateur et est décrit en détail sur la page removedTypes().
