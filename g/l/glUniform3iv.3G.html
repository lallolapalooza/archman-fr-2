glUniform modifie la
valeur d'une variable

uniform

e

ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgram(). Les commandes glUniform{1|2|3|4}{f|i|ui} sont util

isées

pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par ex., 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour des variables uniformes définies comme int, ivec2, ivec3, ivec4, ou des tableaux de ceux-ci. Les variantes ui de cette fonction doivent être utilisées pour fournir des valeurs à des variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les variantes f doivent être utilisées pour fournir des valeurs à des variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de ceux-ci. Les variantes i, ui ou f peuvent être utilisées pour fournir des valeurs à des variables uniformes de type bool, bvec2, bvec3, bvec4, ou des tableaux de ceux-ci. La variable uniforme sera définie à false si la valeur d'entrée est 0 ou 0.0f, et elle sera définie à true dans le cas

contraire.

Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. Elles conservent les valeurs qui leur ont été assignées par un appel à glUniform jusqu'à ce que la prochaine opération de liaison réussie se produise sur l'objet programme, moment où elles sont à nouveau initialisées à

0.

Les commandes glUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une variable uniforme unique ou un tableau de variables uniformes. Ces commandes transmettent un compte et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un compte de 1 doit être utilisé si l'on modifie la valeur d'une seule variable uniforme, et un compte de 1 ou supérieur peut être utilisé pour modifier un tableau entier ou une partie d'un tableau. Lors du chargement de n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 dans le tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est supérieur à la taille du tableau de variables uniformes, les valeurs de tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre indiqué dans le nom de la commande indique le nombre de composantes pour chaque élément dans value, et il doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, bool ; 2 pour vec2, ivec2, bvec2, etc.). Le type de données spécifié dans le nom de la commande doit correspondre au type de données de la variable uniforme spécifiée comme décrit précédemment pour glUniform{1|2|3|4}

{f|i|ui}.

Pour les tableaux de variables uniformes, chaque élément du tableau est considéré comme étant du type indiqué dans le nom de la commande (par exemple, glUniform3f ou glUniform3fv peuvent être utilisés pour charger un tableau de variables uniformes de type vec3). Le nombre d'éléments du tableau de variables uniformes à modifier est spécifié par coun

t

Les commandes glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv sont utilisées pour modifier une matrice ou un tableau de matrices. Les nombres dans le nom de la commande sont interprétés comme la dimensionnalité de la matrice. Le nombre 2 indique une matrice 2 × 2 (c'est-à-dire 4 valeurs), le nombre 3 indique une matrice 3 × 3 (c'est-à-dire 9 valeurs), et le nombre 4 indique une matrice 4 × 4 (c'est-à-dire 16 valeurs). La dimensionnalité des matrices non carrées est explicite, le premier nombre représentant le nombre de colonnes et le deuxième nombre représentant le nombre de lignes. Par exemple, 2x4 indique une matrice 2 × 4 avec 2 colonnes et 4 lignes (c'est-à-dire 8 valeurs). Si transpose est GL_FALSE, chaque matrice est supposée être fournie dans l'ordre colonne majeur. Si transpose est GL_TRUE, chaque matrice est supposée être fournie dans l'ordre ligne majeur. L'argument count indique le nombre de matrices à transmettre. Un compte de 1 doit être utilisé si l'on modifie la v

aleur d'une seule matrice, et un compte supérieur à 1
peut être utilisé pour modifier un tableau de matrices.

NOTE

S

glUniform1i et glUniform1iv sont les deux seules fonctions qui peuvent être utilisées pour charger des variables uniformes définies comme types de samplers. Le chargement de samplers avec toute autre fonction entraînera une erreur GL_INVALID_OPERATION

.

Si count est supérieur à 1 et que la variable uniforme indiquée n'est pas un tableau, une erreur GL_INVALID_OPERATION est générée et la variable uniforme spécifiée restera

inchangée.

En dehors des exceptions précédentes, si le type et la taille de la variable uniforme tels que définis dans le shader ne correspondent pas au type et à la taille spécifiés dans le nom de la commande utilisée pour charger sa valeur, une erreur GL_INVALID_OPERATION sera générée et la variable uniforme spécifiée restera

inchangée.

Si location est une valeur autre que -1 et qu'elle ne représente pas un emplacement de variable uniforme valide dans l'objet programme courant, une erreur sera générée, et aucun changement ne sera apporté au stockage des variables uniformes de l'objet programme courant. Si location est égal à -1, les données transmises seront ignorées sile

ncieusement et la variable uniforme
spécifiée ne sera pas modifiée.

NAME

glUniformMatrix2x3fv - set the value of a uniform variable

C SPECIFICATION

void glUniformMatrix2x3fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);

PARAMETERS

location
Specifies the uniform variable to be modified.
count
Specifies the number of matrices that will be modified. The total number of values written will be count * 6.
transpose
Specifies whether to transpose the matrix or matrices. Must be GL_FALSE.
value
Specifies the address of the buffer in which the specified texture unit indices are stored.

DESCRIPTION

glUniformMatrix2x3fv sets the value of a uniform variable from an array of floating-point values. The uniform variable is identified by the given location, a uniform variable previously returned by a call to glGetUniformLocation().

The uniform variables are specified by location and count. count indicates the number of matrices to be modified. This is because glUniformMatrix2x3fv can also be used to modify the entries of an array of uniform variables.

If transpose is GL_FALSE, the matrices are assumed to be column-major. If transpose is GL_TRUE, the matrices are assumed to be row-major.

The matrices are set to the values found in the array of floating-point numbers specified by value. The matrices are loaded in column-major order. For a 2x3 matrix, 6 values are copied from the corresponding component of value.

If the uniform variable indicated by location refers to a matrix of 2 columns and 3 rows, then count matrices of dimensions 2x3 are loaded. The values are taken from the array pointed to by value.

If the uniform variable specified by location is not a matrix type, an error is generated.

NOTES

If location is the handle of a uniform variable that does not exist in the current program object, or if location is GL_INVALID_INDEX, then the command is ignored.

If location refers to a uniform variable that is neither an array nor a matrix, and count is greater than 1, an error is generated.

If count is greater than 1, location must refer to the first matrix in an array of matrices. The matrices are loaded in the order they appear in the array, from index 0 to count - 1.

If transpose is GL_TRUE, then for each matrix, the first 3 elements of the first row of the matrix contain the values for the first column of the returned matrix, the next 3 elements of the second row contain the values for the second column, and so on.

ERRORS

GL_INVALID_OPERATION is generated if location is not GL_INVALID_INDEX and refers to a uniform variable that does not exist in the current program object.

GL_INVALID_VALUE is generated if count is negative.

GL_INVALID_OPERATION is generated if location refers to a uniform variable that is not of type matrix.

GL_INVALID_OPERATION is generated if transpose is not GL_FALSE.
