DESCRIPTIO

N

Le rendu conditionnel est démarré à l'aide de glBeginConditionalRender et terminé à l'aide de glEndConditionalRender. Pendant le rendu conditionnel, toutes les commandes de tableau de sommets, ainsi que glClear() et glClearBuffer() n'ont aucun effet si le résultat (GL_SAMPLES_PASSED) de l'objet de requête id est nul, ou si le résultat (GL_ANY_SAMPLES_PASSED) est GL_FALSE. Les résultats des commandes définissant l'état courant des sommets, telles que glVertexAttrib(), sont indéfinis. Si le résultat (GL_SAMPLES_PASSED) est non nul ou si le résultat (GL_ANY_SAMPLES_PASSED) est GL_TRUE, de telles commandes ne sont pas ignorées. Le paramètre id de glBeginConditionalRender doit être le nom d'un objet de requête précédemment renvoyé par un appel à glGenQueries(). mode indique comment les résultats de l'objet de requête doivent être interprétés. Si mode est GL_QUERY_WAIT, la GL attend que les résultats de la requête soient disponibles puis utilise ces résultats pour déterminer si les commandes de rendu suivantes sont ignorées. Si mode est GL_QUERY_NO_WAIT, la GL peut choisir d'exécuter inconditionnellement les commandes de rendu suivantes sans attendre la fin de la

requête.

Si mode est GL_QUERY_BY_REGION_WAIT, la GL attendra également les résultats de la requête d'occlusion et ignorera les commandes de rendu si le résultat de la requête d'occlusion est nul. Si le résultat de la requête est non nul, les commandes de rendu suivantes sont exécutées, mais la GL peut ignorer les résultats des commandes pour toute région du tampon de trame qui n'a pas contribué au comptage d'échantillons dans la requête d'occlusion spécifiée. Un tel rejet est effectué d'une manière dépendante de l'implémentation, mais les résultats des commandes de rendu peuvent ne pas être rejetés pour les échantillons ayant contribué au comptage d'échantillons de la requête d'occlusion. Si mode est GL_QUERY_BY_REGION_NO_WAIT, la GL fonctionne comme avec GL_QUERY_BY_REGION_WAIT, mais peut choisir d'exécuter inconditionnellement

les commandes de rendu suivante
s sans attendre la fin de la requête.
