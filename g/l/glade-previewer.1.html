NOM

glade-previewer - Prévisualiser les définitions d'interface utilisateur glade

SYNTAXE

glade-previewer [OPTION...]

DESCRIPTION

glade-previewer est un outil qui peut charger et afficher une interface utilisateur définie avec glade. glade utilise lui-même glade-previewer, mais il peut également être utilisé comme utilitaire autonome.

OPTIONS

Les options suivantes peuvent être spécifiées :

-f NOM FICHIER, --filename=NOM FICHIER

Nom du fichier à prévisualiser.

-t NIVEAU_SUPERIEUR, --toplevel=NIVEAU_SUPERIEUR

Nom du niveau supérieur à prévisualiser.

-l, --listen

Écouter sur l'entrée standard.

-v, --version

Afficher les informations de version et quitter.

--display=AFFICHAGE

Affichage X à utiliser.

Une des options --filename ou --listen doit être spécifiée.
