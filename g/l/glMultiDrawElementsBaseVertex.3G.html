NOM

glMultiDrawElementsBaseVertex - rendre plusieurs ensembles de primitives en spécifiant les indices des données de tableau et un indice à appliquer à chaque indice

SPÉCIFICATION C

void glMultiDrawElementsBaseVertex(GLenum mode, const GLsizei *count, GLenum type, const void * const *indices, GLsizei drawcount, const GLint *basevertex);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

count

Pointe vers un tableau des décomptes d'éléments.

type

Spécifie le type des valeurs dans indices. Doit être l'une des valeurs GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT ou GL_UNSIGNED_INT.

indices

Spécifie un pointeur vers l'emplacement où sont stockés les indices.

drawcount

Spécifie la taille des tableaux count, indices et basevertex.

basevertex

Pointe vers l'emplacement où sont stockés les sommets de base.

DESCRIPTION

glMultiDrawElementsBaseVertex se comporte de manière identique à glDrawElementsBaseVertex(), sauf que drawcount listes d'éléments distinctes sont spécifiées à la place.

Elle a le même effet que :

    for (int i = 0; i < drawcount; i++)
        if (count[i] > 0)
            glDrawElementsBaseVertex(mode,
                                     count[i],
                                     type,
                                     indices[i],
                                     basevertex[i]);

NOTES

glMultiDrawElementsBaseVertex n'est disponible que si la version de GL est 3.1 ou supérieure.

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_TRIANGLES_ADJACENCY ne sont disponibles que si la version de GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si drawcount est négatif.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé ou au tableau d'éléments, et que le magasin de données de l'objet tampon est actuellement mappé.
