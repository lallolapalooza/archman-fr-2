NOM

glab-repo-members-add - Ajouter un membre au projet.

SYNTAXE

glab repo members add [options]

DESCRIPTION

Ajouter un membre au projet avec le rôle spécifié.

Rôles :

  • guest (10) : Peut visualiser le projet.
  • reporter (20) : Peut visualiser et créer des issues.
  • developer (30) : Peut pousser vers des branches non protégées.
  • maintainer (40) : Peut gérer le projet.
  • owner (50) : Accès complet au projet.

Pour les rôles personnalisés, utilisez --role-id avec l'ID d'un rôle personnalisé défini dans le projet ou le groupe. Note : Si le rôle personnalisé n'existe pas, une erreur sera retournée.

OPTIONS

-e, --expires-at="" Date d'expiration de l'adhésion (AAAA-MM-JJ)

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE DE NOMS/DÉPÔT. Accepte également une URL complète ou une URL Git.

-r, --role="developer" Rôle pour l'utilisateur (guest, reporter, developer, maintainer, owner)

--role-id=0 ID d'un rôle personnalisé défini dans le projet ou le groupe

-u, --user-id=0 ID utilisateur au lieu du nom d'utilisateur

--username="" Nom d'utilisateur au lieu de l'ID utilisateur

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

# Ajouter un utilisateur en tant que développeur
$ glab repo members add --username=john.doe --role=developer
# Ajouter un utilisateur en tant que mainteneur avec une date d'expiration
$ glab repo members add --username=jane.smith --role=maintainer --expires-at=2024-12-31
# Ajouter un utilisateur par ID
$ glab repo members add --user-id=123 --role=reporter
# Ajouter un utilisateur avec un rôle personnalisé
$ glab repo members add --username=john.doe --role-id=101
