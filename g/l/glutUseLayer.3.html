NOM

glutUseLayer - change la couche utilisée pour la fenêtre actuelle.

ATTENTION

Pas encore implémenté dans freeglut.

SYNTAXE

void glutUseLayer(GLenum layer);

ARGUMENTS

layer
Soit GLUT_NORMAL soit GLUT_OVERLAY, sélectionnant respectivement le plan normal ou la superposition.

DESCRIPTION

glutUseLayer change la couche par fenêtre utilisée pour la fenêtre actuelle, sélectionnant soit le plan normal soit la superposition. La superposition ne doit être spécifiée que si une superposition existe, cependant les fenêtres sans superposition peuvent toujours appeler glutUseLayer(GLUT_NORMAL).

Les commandes OpenGL pour la fenêtre sont dirigées vers la couche actuellement utilisée.

Pour interroger la couche utilisée pour une fenêtre, appelez glutLayerGet(GLUT_LAYER_IN_USE).

VOIR AUSSI

glutEstablishOverlay, glutSetWindow
