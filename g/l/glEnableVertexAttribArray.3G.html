NOM

glEnableVertexAttribArray, glDisableVertexAttribArray, glEnableVertexArrayAttrib, glDisableVertexArrayAttrib - Activer ou désactiver un tableau d'attributs de sommet générique

C SPÉCIFICATION

void glEnableVertexAttribArray(GLuint index);

void glDisableVertexAttribArray(GLuint index);

void glEnableVertexArrayAttrib(GLuint vaobj, GLuint index);

void glDisableVertexArrayAttrib(GLuint vaobj, GLuint index);

PARAMÈTRES

vaobj

Spécifie le nom de l'objet tableau de sommets pour les fonctions glDisableVertexArrayAttrib et glEnableVertexArrayAttrib.

index

Spécifie l'index de l'attribut de sommet générique à activer ou désactiver.

DESCRIPTION

glEnableVertexAttribArray et glEnableVertexArrayAttrib activent le tableau d'attributs de sommet générique spécifié par index. glEnableVertexAttribArray utilise l'objet tableau de sommets actuellement lié pour l'opération, tandis que glEnableVertexArrayAttrib met à jour l'état de l'objet tableau de sommets avec l'identifiant vaobj.

glDisableVertexAttribArray et glDisableVertexArrayAttrib désactivent le tableau d'attributs de sommet générique spécifié par index. glDisableVertexAttribArray utilise l'objet tableau de sommets actuellement lié pour l'opération, tandis que glDisableVertexArrayAttrib met à jour l'état de l'objet tableau de sommets avec l'identifiant vaobj.

Par défaut, toutes les capacités côté client sont désactivées, y compris tous les tableaux d'attributs de sommets génériques. S'ils sont activés, les valeurs du tableau d'attributs de sommets génériques seront accédées et utilisées pour le rendu lorsque des appels sont faits aux commandes de tableaux de sommets telles que glDrawArrays(), glDrawElements(), glDrawRangeElements(), glMultiDrawElements(), ou glMultiDrawArrays().

ERREURS

GL_INVALID_OPERATION est généré par glEnableVertexAttribArray et glDisableVertexAttribArray si aucun objet tableau de sommets n'est lié.

GL_INVALID_OPERATION est généré par glEnableVertexArrayAttrib et glDisableVertexArrayAttrib si vaobj n'est pas le nom d'un objet tableau de sommets existant.

GL_INVALID_VALUE est généré si index est supérieur ou égal à GL_MAX_VERTEX_ATTRIBS.

GETS ASSOCIÉS

glGet() avec l'argument GL_MAX_VERTEX_ATTRIBS

glGetVertexAttrib() avec les arguments index et GL_VERTEX_ATTRIB_ARRAY_ENABLED

glGetVertexAttribPointerv() avec les arguments index et GL_VERTEX_ATTRIB_ARRAY_POINTER
