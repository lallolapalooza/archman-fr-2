DESCRIPTIO

N

glDrawElementsInstancedBaseInstance se comporte de manière identique à glDrawElements() sauf que instancecount instances de l'ensemble d'éléments sont exécutées et la valeur du compteur interne instanceID avance à chaque itération. instanceID est un compteur interne entier sur 32 bits qui peut être lu par un shader de sommet comme gl_InstanceID

.

glDrawElementsInstancedBaseInstance a le même effet que

: 
    if (mode, count, or type is invalid )
        generate appropriate error
    else {
        for (int i = 0; i < instancecount ; i++) {
            instanceID = i;
            glDrawElements(mode, count, type, indices);
        }
        instanceID = 0;
}

Des attributs de sommet spécifiques peuvent être classés comme instanciés via l'utilisation de glVertexAttribDivisor(). Les attributs de sommet instanciés fournissent des données de sommet par instance au shader de sommet. L'indice du sommet récupéré à partir des tableaux d'attributs de sommet instanciés activés est calculé comme gl _ InstanceID divisor + baseInstance. Notez que baseinstance n'affecte pas la valeur de gl_InstanceID visi

ble par l
e shader.

NOTE

S

glDrawElementsInstancedBaseInstance n'est disponible que si la version de GL est 4.2 ou

supérieure.

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_TRIANGLES_ADJACENCY sont disponibles uniq

uement si la version de G

ERREUR

S

GL_INVALID_ENUM est généré si mode n'est pas l'un de GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN ou GL_TRIANGLES

.

GL_INVALID_VALUE est généré si count ou instancecount est

négatif.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et mode est incompatible avec le type d'entrée primitive du shader de géométrie dans l'objet programme actuellement

installé.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tabl

eau activé et que le magasin de données de
l'objet tampon est actuellement mappé.
