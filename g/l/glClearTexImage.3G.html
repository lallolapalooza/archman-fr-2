NOM

glClearTexImage - remplit toutes les images d'une texture avec une valeur constante

SPÉCIFICATION C

void glClearTexImage(GLuint texture, GLint level, GLenum format, GLenum type, const void * data);

PARAMÈTRES

texture

Le nom d'un objet texture existant contenant l'image à effacer.

level

Le niveau de texture contenant la région à effacer.

format

Le format des données dont l'adresse mémoire est donnée par data.

type

Le type des données dont l'adresse mémoire est donnée par data.

data

L'adresse mémoire des données à utiliser pour effacer la région spécifiée.

DESCRIPTION

glClearTexImage remplit toutes les images contenues dans une texture avec une valeur fournie par l'application. texture doit être le nom d'une texture existante. De plus, texture ne peut pas être le nom d'une texture tampon (buffer texture), ni avoir un format interne compressé.

format et type spécifient le format et le type des données sources et sont interprétés comme pour glTexImage3D(). Les textures dont le format interne de base est GL_DEPTH_COMPONENT, GL_STENCIL_INDEX ou GL_DEPTH_STENCIL nécessitent des données de composante de profondeur, de stencil ou de profondeur-stencil respectivement. Les textures avec d'autres formats internes de base nécessitent des formats RGBA. Les textures avec des formats internes entiers nécessitent des données entières.

data est un pointeur vers un tableau d'un à quatre composantes de données de texels qui sera utilisé comme source pour la valeur de remplissage constante. Les éléments de data sont convertis par le GL dans le format interne de l'image de texture (qui a été spécifié lorsque le niveau a été défini par l'une des commandes glTexImage*, glTexStorage* ou glCopyTexImage*), puis utilisés pour remplir la plage spécifiée du niveau de texture de destination. Si data est NULL, alors le pointeur est ignoré et la sous-plage de l'image de texture est remplie avec des zéros. Si la texture est une texture multisample, tous les échantillons dans un texel sont effacés à la valeur spécifiée par data.

NOTES

glClearTexImage n'est disponible que si la version d'OpenGL est 4.4 ou supérieure.

ERREURS

GL_INVALID_OPERATION est généré si texture est zéro ou n'est pas le nom d'un objet texture existant.

GL_INVALID_OPERATION est généré si texture est une texture tampon.

GL_INVALID_OPERATION est généré si texture a un format interne compressé.

GL_INVALID_OPERATION est généré si le format interne de base est GL_DEPTH_COMPONENT et que format n'est pas GL_DEPTH_COMPONENT.

GL_INVALID_OPERATION est généré si le format interne de base est GL_DEPTH_STENCIL et que format n'est pas GL_DEPTH_STENCIL.

GL_INVALID_OPERATION est généré si le format interne de base est GL_STENCIL_INDEX et que format n'est pas GL_STENCIL_INDEX.

GL_INVALID_OPERATION est généré si le format interne de base est GL_RGBA et que format est GL_DEPTH_COMPONENT, GL_STENCIL_INDEX ou GL_DEPTH_STENCIL.

GL_INVALID_OPERATION est généré si le format interne est entier et que format ne spécifie pas de données entières.

GL_INVALID_OPERATION est généré si le format interne n'est pas entier et que format spécifie des données entières.

GL_INVALID_OPERATION est généré si le tableau d'images identifié par level n'a pas été précédemment défini par un appel à glTexImage* ou glTexStorage*.
