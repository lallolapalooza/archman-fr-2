NOM

glab-repo-clone - Cloner un dépôt ou un projet GitLab.

SYNTAXE

glab repo clone [options] [] [-- ...] glab repo clone -g [options] [] [-- ...]

DESCRIPTION

clone prend en charge ces références abrégées :

  • dépôt
  • espace de noms/dépôt
  • organisation/groupe/dépôt
  • ID de projet

OPTIONS

-g, --group="" Spécifier le groupe à partir duquel cloner les dépôts.

-p, --preserve-namespace[=false] Cloner le dépôt dans un sous-répertoire basé sur l'espace de noms.

-a, --archived[=false] Limiter par le statut archivé. Utiliser avec '-a=false' pour exclure les dépôts archivés. Utilisé avec l'option --group.

-G, --include-subgroups[=true] Inclure les projets dans les sous-groupes de ce groupe. La valeur par défaut est true. Utilisé avec l'option --group.

-m, --mine[=false] Limiter par les projets du groupe appartenant à l'utilisateur authentifié actuel. Utilisé avec l'option --group.

-v, --visibility="" Limiter par la visibilité : public, internal, private. Utilisé avec l'option --group.

-I, --with-issues-enabled[=false] Limiter par les projets avec la fonctionnalité d'issues activée. La valeur par défaut est false. Utilisé avec l'option --group.

-M, --with-mr-enabled[=false] Limiter par les projets avec la fonctionnalité de requêtes de fusion activée. La valeur par défaut est false. Utilisé avec l'option --group.

-S, --with-shared[=true] Inclure les projets partagés avec ce groupe. La valeur par défaut est true. Utilisé avec l'option --group.

--paginate[=false] Effectuer des requêtes HTTP supplémentaires pour récupérer toutes les pages de projets avant le clonage. Respecte --per-page.

--page=1 Numéro de page.

--per-page=30 Nombre d'éléments à lister par page.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

# Clone le dépôt dans le répertoire courant
$ glab repo clone gitlab-org/cli
$ glab repo clone https://gitlab.com/gitlab-org/cli
# Clone le dépôt dans 'mydirectory'
$ glab repo clone gitlab-org/cli mydirectory
# Clone le dépôt 'glab' pour l'utilisateur courant
$ glab repo clone glab
# Trouve le projet par l'ID fourni et le clone
$ glab repo clone 4356677
# Clone tous les dépôts d'un groupe
$ glab repo clone -g everyonecancontribute --paginate
# Clone tous les dépôts non archivés d'un groupe
$ glab repo clone -g everyonecancontribute --archived=false --paginate
# Clone depuis une instance GitLab Auto-gérée ou dédiée GitLab
$ GITLAB_HOST=salsa.debian.org glab repo clone myrepo
