NOM

glab-incident - Gérer les incidents GitLab.

SYNTAXE

glab incident [commande] [options]

DESCRIPTION

Gérer les incidents GitLab.

OPTIONS

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser soit le format PROPRIÉTAIRE/DÉPÔT, soit GROUPE/ESPACENOM/DÉPÔT. Accepte également l'URL complète ou l'URL Git.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab incident list
