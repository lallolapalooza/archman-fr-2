NOM

glVertexBindingDivisor, glVertexArrayBindingDivisor - modifier le taux auquel les attributs de sommets génériques avancent

SPÉCIFICATION C

void glVertexBindingDivisor(GLuint bindingindex, GLuint divisor);

void glVertexArrayBindingDivisor(GLuint vaobj, GLuint bindingindex, GLuint divisor);

PARAMÈTRES

vaobj

Spécifie le nom de l'objet tableau de sommets pour la fonction glVertexArrayBindingDivisor.

bindingindex

L'index de la liaison dont le diviseur doit être modifié.

divisor

La nouvelle valeur pour le taux de pas d'instance à appliquer.

DESCRIPTION

glVertexBindingDivisor et glVertexArrayBindingDivisor modifient le taux auquel les attributs de sommets génériques avancent lors du rendu de multiples instances de primitives dans une seule commande de dessin. Si divisor est zéro, les attributs utilisant le tampon lié à bindingindex avancent une fois par sommet. Si divisor est différent de zéro, les attributs avancent une fois par divisor instances de l'ensemble des sommets rendus. Un attribut est considéré comme instancié si la valeur correspondante de divisor est différente de zéro.

glVertexBindingDivisor utilise l'objet tableau de sommets actuellement lié, tandis que glVertexArrayBindingDivisor met à jour l'état de l'objet tableau de sommets avec l'identifiant vaobj.

ERREURS

GL_INVALID_VALUE est généré si bindingindex est supérieur ou égal à la valeur de GL_MAX_VERTEX_ATTRIB_BINDINGS.

GL_INVALID_OPERATION par glVertexBindingDivisor est généré si aucun objet tableau de sommets n'est lié.

GL_INVALID_OPERATION est généré par glVertexArrayBindingDivisor si vaobj n'est pas le nom d'un objet tableau de sommets existant.

GETS ASSOCIÉS

glGet() avec les arguments GL_MAX_VERTEX_ATTRIB_BINDINGS, GL_VERTEX_BINDING_DIVISOR.
