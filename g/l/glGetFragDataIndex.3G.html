NOM

glGetFragDataIndex - interroger les liaisons des indices de couleur aux variables de sortie variables définies par l'utilisateur

SPÉCIFICATION C

GLint glGetFragDataIndex(GLuint program, const char * name);

PARAMÈTRES

program

Le nom du programme contenant la variable de sortie variable dont on souhaite interroger la liaison

name

Le nom de la variable de sortie variable définie par l'utilisateur dont on souhaite interroger l'indice

DESCRIPTION

glGetFragDataIndex retourne l'indice de la couleur du fragment à laquelle la variable name a été liée lors de la dernière liaison de l'objet programme program. Si name n'est pas une variable de sortie variable de program, ou si une erreur se produit, -1 sera retourné.

NOTES

glGetFragDataIndex n'est disponible que si la version de GL est 3.3 ou supérieure.

ERREURS

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un objet programme.
