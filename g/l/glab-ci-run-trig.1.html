NOM

glab-ci-run-trig - Exécute un déclencheur de pipeline CI/CD.

SYNTAXE

glab ci run-trig [options]

DESCRIPTION

Spécifiez une ou plusieurs entrées de pipeline en utilisant l'option -i ou --input pour chaque entrée. Chaque option d'entrée utilise le format clé:valeur.

Les valeurs sont typées et auront par défaut le type string sauf si un type est explicitement spécifié. Pour spécifier un type, utilisez la syntaxe type(valeur). Par exemple, clé:string(valeur) passera la chaîne valeur en tant qu'entrée.

Les types valides sont :

  • string : Une valeur de chaîne. C'est le type par défaut. Par exemple, clé:string(valeur).
  • int : Une valeur entière. Par exemple, clé:int(42).
  • float : Une valeur à virgule flottante. Par exemple, clé:float(3.14).
  • bool : Une valeur booléenne. Par exemple, clé:bool(true).
  • array : Un tableau de chaînes. Par exemple, clé:array(foo,bar).

Un tableau de chaînes peut être spécifié avec une virgule à la fin. Par exemple, clé:array(foo,bar,) passera le tableau [foo, bar]. array() spécifie un tableau vide. Pour passer un tableau contenant une chaîne vide, utilisez array(,).

Les arguments de valeur contenant des parenthèses doivent être échappés du shell avec des guillemets. Par exemple, --input clé:array(foo,bar) doit être écrit comme --input 'clé:array(foo,bar)'.

OPTIONS

-b, --branch="" Crée le pipeline sur la branche ou la référence .

-i, --input=[] Passe les entrées au pipeline au format ':'. Ne peut pas être utilisé pour les pipelines de demande de fusion. Voir la documentation pour des exemples.

-t, --token="" Jeton de déclenchement du pipeline. Peut être omis seulement si la variable d'environnement CI_JOB_TOKEN est définie.

--variables=[] Passe les variables au pipeline au format :. Plusieurs variables peuvent être séparées par des virgules ou spécifiées en répétant l'option.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab ci run-trig -t xxxx
$ glab ci run-trig -t xxxx -b main
# Spécifier les variables CI
$ glab ci run-trig -t xxxx -b main --variables clé1:val1
$ glab ci run-trig -t xxxx -b main --variables clé1:val1,clé2:val2
$ glab ci run-trig -t xxxx -b main --variables clé1:val1 --variables clé2:val2
# Spécifier les entrées CI
$ glab ci run-trig -t xxxx -b main --input clé1:val1 --input clé2:val2
$ glab ci run-trig -t xxxx -b main --input "réplicas:int(3)" --input "debug:bool(false)" --input "regiones:array(us-east,eu-west)"
