NOM

glab-cluster-agent-token-cache-list - Lister les jetons de cache de l'agent GitLab

SYNTAXE

glab cluster agent token-cache list [flags]

DESCRIPTION

Lister tous les jetons de cache de l'agent GitLab depuis le trousseau de clés et le cache du système de fichiers.

Par défaut, cette commande affiche les jetons des deux types de cache (trouseau et système de fichiers). Utilisez --keyring=false ou --filesystem=false pour filtrer des types de cache spécifiques.

OPTIONS

--agent=[] Filtrer par identifiants d'agent spécifiques

--filesystem[=true] Inclure les jetons du cache du système de fichiers

--keyring[=true] Inclure les jetons du cache du trousseau de clés

-R, --repo="" Sélectionner un autre dépôt en utilisant le format PROPRIÉTAIRE/DÉPÔT

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide de cette commande.
