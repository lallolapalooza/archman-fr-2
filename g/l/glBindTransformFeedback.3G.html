NOM

glBindTransformFeedback - lier un objet de retour de transformation

SPÉCIFICATION C

void glBindTransformFeedback(GLenum cible, GLuint id);

PARAMÈTRES

cible

Spécifie la cible à laquelle lier l'objet de retour de transformation id. cible doit être GL_TRANSFORM_FEEDBACK.

id

Spécifie le nom d'un objet de retour de transformation réservé par glGenTransformFeedbacks().

DESCRIPTION

glBindTransformFeedback lie l'objet de retour de transformation portant le nom id à l'état GL actuel. id doit être un nom précédemment retourné par un appel à glGenTransformFeedbacks(). Si id n'a pas été lié précédemment, un nouvel objet de retour de transformation portant le nom id et initialisé avec le vecteur d'état de transformation par défaut est créé.

Dans l'état initial, un objet de retour de transformation par défaut est lié et traité comme un objet de retour de transformation portant le nom zéro. Si le nom zéro est lié par la suite, l'objet de retour de transformation par défaut est à nouveau lié à l'état GL.

Lorsqu'un objet de tampon de retour de transformation est lié, les opérations GL sur la cible à laquelle il est lié affectent l'objet de retour de transformation lié, et les requêtes sur la cible à laquelle un objet de retour de transformation est lié retournent l'état de l'objet lié. Lorsque des objets de tampon sont liés pour le retour de transformation, ils sont attachés à l'objet de retour de transformation actuellement lié. Les objets de tampon sont utilisés pour le retour de transformation uniquement s'ils sont attachés à l'objet de retour de transformation actuellement lié.

ERREURS

GL_INVALID_ENUM est généré si cible n'est pas GL_TRANSFORM_FEEDBACK.

GL_INVALID_OPERATION est généré si l'opération de retour de transformation est active sur l'objet de retour de transformation actuellement lié, et que cette opération n'est pas en pause.

GL_INVALID_OPERATION est généré si id n'est pas zéro ou le nom d'un objet de retour de transformation retourné par un appel précédent à glGenTransformFeedbacks(), ou si un tel nom a été supprimé par glDeleteTransformFeedbacks().

GETS ASSOCIÉS

glGet() avec l'argument GL_TRANSFORM_FEEDBACK_BINDING
