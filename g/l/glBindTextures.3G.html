DESCRIPTIO

N

glBindTextures lie un tableau d'objets de texture existants à un nombre spécifié d'unités de texture consécutives. count spécifie le nombre d'objets de texture dont les noms sont stockés dans le tableau textures. Ce nombre de noms de texture est lu depuis le tableau et lié aux count unités de texture consécutives à partir de first. La cible, ou le type de texture, est déduit de l'objet de texture et chaque texture est liée à la cible correspondante de l'unité de texture. Si le nom zéro apparaît dans le tableau textures, toute liaison existante à n'importe quelle cible de l'unité de texture est réinitialisée et la texture par défaut pour cette cible est liée à sa place. Toute entrée non nulle dans textures doit être le nom d'un objet de texture existant. Si textures est NULL, c'est comme si un tableau de taille appropriée contenant uniquement des zéros avait été

spécifié.

À l'exception où le sélecteur de texture active conserve sa valeur actuelle, glBindTextures est équivalent au pseudo-code suivant

: 
    for (i = 0; i < count; i++) {
        GLuint texture;
        if (textures == NULL) {
            texture = 0;
        } else {
            texture = textures[i];
        }
        glActiveTexture(GL_TEXTURE0 + first + i);
        if (texture != 0) {
            GLenum target = /* target of textures[i] */;
            glBindTexture(target, textures[i]);
        } else {
            for (target in all supported targets) {
                glBindTexture(target, 0);
            }
        }
}

Chaque entrée dans textures sera vérifiée individuellement et si elle est trouvée invalide, l'état de cette unité de texture ne sera pas modifié

et une erreur sera générée. Cependant, l'état des autres unités de
texture référencées par la commande sera toujours mis à jour.

REMARQUE

S

glBindTextures n'est disponible que si la version de GL est 4.4 ou

supérieure.

Notez que parce que glBindTextures ne peut pas créer de nouvelles textures (même si un nom passé a été précédemment généré par un appel à glGenTextures()), les noms passés à glBindTextures doivent avoir été liés au moins une fois auparavant via un appel à glBindTe

xtur
e().

ERREUR

S

GL_INVALID_OPERATION est généré si first + count est supérieur au nombre d'unités d'image de texture prises en charge par l'implémentation

.

GL_INVALID_OPERATION est généré si une valeur dans textures

n'est pas zéro ou le nom d
'un objet de texture existant.
