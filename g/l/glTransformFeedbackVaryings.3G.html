DESCRIPTIO

N

Les noms des sorties du vertex shader ou du geometry shader à enregistrer en mode transform feedback sont spécifiés à l'aide de glTransformFeedbackVaryings. Lorsqu'un geometry shader est actif, le transform feedback enregistre les valeurs des variables de sortie du geometry shader sélectionnées à partir des vertices émis. Sinon, les valeurs des sorties du vertex shader sélectionnées sont

enregistrées.

L'état défini par glTranformFeedbackVaryings est stocké et prend effet la prochaine fois que glLinkProgram() est appelé sur program. Lorsque glLinkProgram() est appelé, program est lié de sorte que les valeurs des variables varying spécifiées pour les vertices de chaque primitive générée par le GL sont écrites dans un seul objet tampon si bufferMode est GL_INTERLEAVED_ATTRIBS ou dans plusieurs objets tampon si bufferMode est GL_SEPARATE_ATTRIBS

.

glTransformFeedbackVaryings peut aussi utiliser des identifiants spéciaux si bufferMode est GL_INTERLEAVED_A

feedback.

•Le count spécifié par glTransformFeedbackVaryings est non nul, mais l'objet programme n'a pas de vertex shader ni de geometry

•Tout nom de variable spécifié dans le tableau varyings n'est pas déclaré comme une sortie dans le vertex shader (ou le geometry shader, s'il est actif), ou n'est pas l'un des identifiants spéciaux listés

•Deux entrées quelconques du tableau varyings, qui ne sont pas l'un des varyings spéciaux ci-dessus, spécifient la même variable
varying.
•En ignorant les identifiants spéciaux, le nombre total de composants à capturer dans n'importe quelle variable varying dans varyings est supérieur à la constante GL_MAX_TRANSFORM_FEEDBACK_SEPARATE_COMPONENTS et le mode tampon est GL_SEPARATE_ATTRIBS

    glTransformFeedbackVaryings(3G)

    glTransformFeedbackVaryings — glTransformFeedbackVaryings

    Nom

    glTransformFeedbackVaryings — configure les variables à enregistrer lors de la rétroaction de transformation

    Syntaxe

    void glTransformFeedbackVaryings(GLuint program, GLsizei count, const GLchar **varyings, GLenum bufferMode);

    Paramètres

    program
    Spécifie le programme de nuanceur dont les variables de rétroaction de transformation doivent être configurées.
    count
    Spécifie le nombre de variables de rétroaction de transformation à enregistrer.
    varyings
    Spécifie un tableau de chaînes terminées par un caractère nul contenant les noms des variables de rétroaction de transformation à enregistrer.
    bufferMode
    Spécifie le mode de mise en mémoire tampon. Il peut être GL_INTERLEAVED_ATTRIBS ou GL_SEPARATE_ATTRIBS.

    Description

    glTransformFeedbackVaryings configure le programme de nuanceur program pour enregistrer les valeurs des variables spécifiées par varyings lors de l'exécution de la rétroaction de transformation.

    Le paramètre count spécifie le nombre de variables de rétroaction de transformation à enregistrer.

    Le paramètre varyings spécifie un tableau de chaînes terminées par un caractère nul contenant les noms des variables de rétroaction de transformation à enregistrer.

    Le paramètre bufferMode spécifie le mode de mise en mémoire tampon. Il peut être GL_INTERLEAVED_ATTRIBS ou GL_SEPARATE_ATTRIBS.

    • GL_INTERLEAVED_ATTRIBS : les données des variables de rétroaction de transformation sont entrelacées dans un seul tampon.
    • GL_SEPARATE_ATTRIBS : les données de chaque variable de rétroaction de transformation sont stockées dans un tampon distinct.

    Erreurs

    GL_INVALID_VALUE est généré si count est négatif.

    GL_INVALID_OPERATION est généré si program n'est pas un identifiant de programme valide.

    GL_INVALID_OPERATION est généré si bufferMode n'est ni GL_INTERLEAVED_ATTRIBS ni GL_SEPARATE_ATTRIBS.

    GL_INVALID_OPERATION est généré si l'un des noms dans varyings ne correspond pas à une variable active dans le programme ou s'il n'est pas qualifié pour la rétroaction de transformation.

    Spécifications

    Spécification OpenGL 3.0
