DESCRIPTIO

N

Ces commandes retournent un paramètre sélectionné de l'objet de requête spécifié par id. glGetQueryObject retourne dans params un paramètre sélectionné de l'objet de requête spécifié par id. glGetQueryBufferObject retourne dans buffer un paramètre sélectionné de l'objet de requête spécifié par id, en l'écrivant dans le magasin de données du buffer au décalage en octets spécifié par offset

.

pname nomme un paramètre spécifique de l'objet de requête. pname peut être le

suivant:

GL_QUERY_RESUL

T
params ou buffer retourne la valeur du compteur d'échantillons validés de l'objet de requête. La valeur initiale est
0.

GL_QUERY_RESULT_NO_WAI

T
Si le résultat de la requête est disponible (c'est-à-dire, une requête de GL_QUERY_RESULT_AVAILABLE retournerait non-zéro), alors params ou buffer retourne la valeur du compteur d'échantillons validés de l'objet de requête, sinon, les données référencées par params ou buffer ne sont pas modifiées. La valeur initiale est
0.

GL_QUERY_RESULT_AVAILABL

E
params ou buffer retourne si le compteur d'échantillons validés est immédiatement disponible. Si un délai se produirait en attendant le résultat de la requête, GL_FALSE est retourné. Sinon, GL_TRUE est retourné, ce qui indique aussi que les résultats de toutes les requêtes précédentes sont également
disponibles.

GL_QUERY_TARGE

T
params ou buffer retourne la cible
de l'objet
de requête.

NOTE

S

Si une erreur est générée, aucun changement n'est fait au contenu de params ou buffer

.

glGetQueryObject et glGetQueryBufferObject vident implicitement le pipeline GL de sorte que tout rendu incomplet délimité par la requête d'occlusion se termine en temps

fini.

Si plusieurs requêtes sont émises en utilisant le même objet de requête id avant d'appeler glGetQueryObject ou glGetQueryBufferObject, les résultats de la requête la plus récente seront retournés. Dans ce cas, lors de l'émission d'une nouvelle requête, les résultats de la requête précédente sont

jetés.

glGetQueryObjecti64v et glGetQueryObjectui64v sont disponibles seulement si la version GL est 3.3 ou

supérieure.

GL_QUERY_RESULT_NO_WAIT est accepté pour pname seulement si la version GL est 4.4 ou

supérieure.

La cible GL_QUERY_RESULT_BUFFER est disponible seulement si la version GL est 4.4 ou supérieure. Sur les versions antérieures de GL, params est toujours une

adresse en m
émoire client.

ERREUR

S

GL_INVALID_ENUM est généré si pname n'est pas une valeur

acceptée.

GL_INVALID_OPERATION est généré si id n'est pas le nom d'un objet de

requête.

GL_INVALID_OPERATION est généré par glGetQueryBufferObject si buffer n'est pas le nom d'un objet tampon déjà

créé.

GL_INVALID_OPERATION est généré si id est le nom d'un objet de requête actuellement

actif.

GL_INVALID_OPERATION est généré par glGetQueryObject si un tampon est actuellement lié à la cible GL_QUERY_RESULT_BUFFER et que la commande causerait l'écriture de données au-delà des limites du magasin de données de ce

tampon.

GL_INVALID_OPERATION est généré par glGetQueryBufferObject si la commande causerait l'écriture de données au-delà des limites du magasin de données du

buffer.

GL_INVALID_VALUE est généré par glGetQueryBufferObject si offset est

nég
atif.
