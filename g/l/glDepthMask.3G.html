NOM

glDepthMask - activer ou désactiver l'écriture dans le tampon de profondeur

SPÉCIFICATION C

void glDepthMask(GLboolean flag);

PARAMÈTRES

flag

Spécifie si le tampon de profondeur est activé pour l'écriture. Si flag est GL_FALSE, l'écriture dans le tampon de profondeur est désactivée. Sinon, elle est activée. Initialement, l'écriture dans le tampon de profondeur est activée.

DESCRIPTION

glDepthMask spécifie si le tampon de profondeur est activé pour l'écriture. Si flag est GL_FALSE, l'écriture dans le tampon de profondeur est désactivée. Sinon, elle est activée. Initialement, l'écriture dans le tampon de profondeur est activée.

ASSOCIÉS GETS

glGet() avec l'argument GL_DEPTH_WRITEMASK

NOTES

Même si le tampon de profondeur existe et que le masque de profondeur est non nul, le tampon de profondeur n'est pas mis à jour si le test de profondeur est désactivé. Pour écrire inconditionnellement dans le tampon de profondeur, le test de profondeur doit être activé et défini sur GL_ALWAYS (voir glDepthFunc()).
