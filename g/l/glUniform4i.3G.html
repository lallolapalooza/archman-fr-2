PARAMÈTRES

location

Spécifie l'emplacement de la variable uniforme à modifier.

count

Pour les commandes de vecteur (glUniform*v), spécifie le nombre d'éléments à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau, et 1 ou plus si c'est un tableau.

Pour les commandes de matrice (glUniformMatrix*), spécifie le nombre de matrices à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau de matrices, et 1 ou plus si c'est un tableau de matrices.

transpose

Pour les commandes de matrice, spécifie s'il faut transposer la matrice lorsque les valeurs sont chargées dans la variable uniforme.

v0, v1, v2, v3

Pour les commandes scalaires, spécifie les nouvelles valeurs à utiliser pour la variable uniforme spécifiée.

value

Pour les commandes de vecteur et de matrice, spécifie un pointeur vers un tableau de count valeurs qui seront utilisées pour mettre à jour la variable uniforme spécifiée.

DESCRIPTION

glUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgram().

Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour les variables uniformes définies comme int, ivec2, ivec3, ivec4, ou des tableaux de ceux-ci. Les ui de cette fonction devraient être utilisés pour fournir des valeurs pour des variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les f devraient être utilisés pour fournir des valeurs pour des variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de ceux-ci. L'un des i

Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. NAME

glUniform4i, glUniform4iv — set uniform variable values

C SPECIFICATION

void glUniform4i(GLint location,
GLint v0, GLint v1, GLint v2, GLint v3);
void glUniform4iv(GLint location, GLsizei count, const GLint *value);

PARAMETERS

location
Specifies the location of the uniform variable to be modified.
v0, v1, v2, v3
Specifies the new values to be applied to the uniform variable at location.
count
Specifies the number of elements that are to be modified. Must be 0 in order to set nothing.
value
Specifies a pointer to an array of count values that will be used to update the specified uniform variable.

DESCRIPTION

glUniform4i and glUniform4iv specify the value of a uniform variable within a program object. These commands must be used between calls to glUseProgram. They affect the uniform variable identified by location.

glUniform4i specifies the value of a single 4-component integer uniform variable. The parameters v0, v1, v2, and v3 are four integer values that will be loaded into the specified uniform variable.

glUniform4iv specifies the value of a specified array of 4-component integer uniform variables. The parameter count indicates the number of elements in the array uniform variable to be modified. The parameter value points to an array of countx4 integer values that will be loaded into the specified uniform variable array.

If the uniform variable is an array, its elements are assigned values sequentially starting from the first element.

If the uniform variable referenced by location is not an integer, or if the size of the uniform variable is not compatible with the arguments, a GL error is generated.

The value of a uniform variable remains unchanged until a new value is set.

NOTES

The uniform variable locations are obtained using glGetUniformLocation.

The state required by glUniform4i and glUniform4iv is part of the active program object. Therefore, these commands are unaffected by the current value of gl.html

glUniform4i is equivalent to calling glUniform4iv with count set to 1 and value pointing to an array containing the four integer values.

ERRORS

A GL error of type GL_INVALID_OPERATION is generated if glUniform4i or glUniform4iv is called between the execution of glUseProgram and the completion of rendering.

A GL error of type GL_INVALID_VALUE is generated if the uniform variable referenced by location is not a 4-component integer uniform variable, or if count is negative.

ASSOCIATED GETS

glGetUniformiv, glGetUniformLocation
