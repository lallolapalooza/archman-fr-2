NOM

glGetCompressedTexImage, glGetnCompressedTexImage, glGetCompressedTextureImage - renvoie une image de texture compressée

SPÉCIFICATIONS C

void glGetCompressedTexImage(GLenum target, GLint level, void * pixels);

void glGetnCompressedTexImage(GLenum target, GLint level, GLsizei bufSize, void *pixels);

void glGetCompressedTextureImage(GLuint texture, GLint level, GLsizei bufSize, void *pixels);

PARAMÈTRES

target

Spécifie la cible à laquelle la texture est liée pour les fonctions glGetCompressedTexImage et glGetnCompressedTexImage. GL_TEXTURE_1D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_3D, GL_TEXTURE_CUBE_MAP_ARRAY, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, et GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, GL_TEXTURE_RECTANGLE sont acceptés.

texture

Spécifie le nom de l'objet texture pour la fonction glGetCompressedTextureImage.

level

Spécifie le numéro de niveau de détail de l'image désirée. Le niveau 0 est l'image de base. Le niveau $n$ est l'image de réduction mipmap $n$-ième.

bufSize

Spécifie la taille du tampon pixels pour les fonctions glGetCompressedTextureImage et glGetnCompressedTexImage.

pixels

Renvoie l'image de texture compressée.

DESCRIPTION

glGetCompressedTexImage et glGetnCompressedTexImage renvoient l'image de texture compressée associée à target et lod dans pixels. glGetCompressedTextureImage remplit la même fonction, mais au lieu de prendre une cible de texture, elle prend l'ID de l'objet texture. pixels doit être un tableau de bufSize octets pour les fonctions glGetnCompressedTexImage et glGetCompressedTextureImage, et de GL_TEXTURE_COMPRESSED_IMAGE_SIZE octets dans le cas de glGetCompressedTexImage. Si les données réelles prennent moins de place que bufSize, les octets restants ne seront pas touchés. target spécifie la cible de texture, à laquelle la texture dont les données sont extraites par la fonction est liée. lod spécifie le numéro de niveau de détail de l'image désirée.

Si un objet tampon nommé non nul est lié à la cible GL_PIXEL_PACK_BUFFER (voir glBindBuffer()), lors de la demande d'une image de texture, pixels est traité comme un décalage en octets dans le magasin de données de l'objet tampon.

Pour minimiser les erreurs, vérifiez d'abord que la texture est compressée en appelant glGetTexLevelParameter() avec l'argument GL_TEXTURE_COMPRESSED. Si la texture est compressée, vous pouvez déterminer la quantité de mémoire nécessaire pour stocker la texture compressée en appelant glGetTexLevelParameter() avec l'argument GL_TEXTURE_COMPRESSED_IMAGE_SIZE. Enfin, récupérez le format interne de la texture en appelant glGetTexLevelParameter() avec l'argument GL_TEXTURE_INTERNAL_FORMAT. Pour stocker la texture pour une utilisation ultérieure, associez le format interne et la taille à l'image de texture récupérée. Ces données peuvent être utilisées par la routine respective de chargement de texture ou de sous-texture utilisée pour charger les textures target.

ERREURS

GL_INVALID_OPERATION est générée par glGetCompressedTextureImage si texture n'est pas le nom d'un objet texture existant.

GL_INVALID_VALUE est générée si level est inférieur à zéro ou supérieur au nombre maximum de LOD permis par l'implémentation.

GL_INVALID_OPERATION est générée si glGetCompressedTexImage, glGetnCompressedTexImage, et glGetCompressedTextureImage sont utilisés pour récupérer une texture qui est dans un format interne non compressé.

GL_INVALID_OPERATION est générée si un objet tampon nommé non nul est lié à la cible GL_PIXEL_PACK_BUFFER, le stockage du tampon n'a pas été initialisé avec glBufferStorage en utilisant le drapeau GL_MAP_PERSISTENT_BIT et le magasin de données de l'objet tampon est actuellement mappé.

GL_INVALID_OPERATION est générée si un objet tampon nommé non nul est lié à la cible GL_PIXEL_PACK_BUFFER et que les données seraient empaquetées dans l'objet tampon de telle sorte que les écritures mémoire requises dépasseraient la taille du magasin de données.

GETS ASSOCIÉS

glGetTexLevelParameter() avec l'argument GL_TEXTURE_COMPRESSED

glGetTexLevelParameter() avec l'argument GL_TEXTURE_COMPRESSED_IMAGE_SIZE

glGetTexLevelParameter() avec l'argument GL_TEXTURE_INTERNAL_FORMAT

glGet() avec l'argument GL_PIXEL_PACK_BUFFER_BINDING
