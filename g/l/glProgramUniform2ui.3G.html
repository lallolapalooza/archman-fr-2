PARAMÈTRES

program

Spécifie le descripteur du programme contenant la variable uniforme à modifier.

location

Spécifie l'emplacement de la variable uniforme à modifier.

count

Pour les commandes de vecteur (glProgramUniform*v), spécifie le nombre d'éléments à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau, et 1 ou plus si c'est un tableau.

Pour les commandes de matrice (glProgramUniformMatrix*), spécifie le nombre de matrices à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau de matrices, et 1 ou plus s'il s'agit d'un tableau.

transpose

Pour les commandes de matrice (glProgramUniformMatrix*), spécifie si une matrice doit être transposée. Les valeurs acceptables sont GL_FALSE et GL_TRUE.

value

Pointeur vers le ou les valeurs à utiliser pour définir la ou les variables uniformes spécifiées.

DESCRIPTION

Les commandes glProgramUniform définissent les valeurs d'une ou plusieurs variables uniformes pour l'objet programme actif associé à l'unité de rendu spécifiée par program. Ces fonctions sont des versions préférées des fonctions glUniform car elles n'affectent pas le programme actuellement utilisé, qui est défini par glUseProgram.

Il existe des fonctions pour définir des variables uniformes de type int, float, unsigned int, des vecteurs de ces types, et des matrices de type float. Les fonctions terminées par un chiffre seul définissent une seule variable uniforme. Par exemple, glProgramUniform3f définit une variable uniforme à 3 composantes.

Les fonctions terminées par un v (par exemple, glProgramUniform4fv) définissent un tableau de variables uniformes. count spécifie le nombre d'éléments (pour les vecteurs) ou de matrices (pour les matrices) à définir à partir du pointeur value.

Les fonctions glProgramUniformMatrix* définissent un ou plusieurs éléments de matrice. transpose spécifie si les matrices doivent être transposées avant d'être définies. Si transpose est GL_TRUE, les matrices sont transposées; sinon, elles sont utilisées telles quelles.

Les matrices sont stockées en mémoire sous forme de vecteurs de colonne. Par conséquent, pour définir une matrice de 2x3, le pointeur value doit pointer vers 6 valeurs flottantes. Ces valeurs sont organisées comme suit :

[ v00, v10, v01, v11, v02, v12 ]

si transpose est GL_FALSE, ou

[ v00, v01, v10, v11, v20, v21 ]

si transpose est GL_TRUE.

Les valeurs entières sont mappées aux valeurs flottantes en les divisant par le maximum positif représentable pour le type correspondant de variable uniforme.

ERREURS

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un programme valide.

GL_INVALID_OPERATION est généré si program est le nom d'un programme qui est soit en cours d'utilisation par une autre unité de rendu, soit qui a été supprimé.

GL_INVALID_OPERATION est généré si location n'est pas un emplacement valide pour une variable uniforme dans program, ou si location est celui d'une variable uniforme non spécifiée dans le programme ou une variable qui ne peut pas être accédée à partir du code appelant.

GL_INVALID_VALUE est généré si count est négatif.

GL_INVALID_OPERATION est généré si le type de la variable uniforme identifiée par location n'est pas compatible avec le type des paramètres fournis.

glProgramUniform
Pour les commandes scalaires, spécifie les nouvelles valeurs à utiliser pour la variable uniforme spécifiée.

valeur

Pour les commandes de vecteur et de matrice, spécifie un pointeur vers un tableau de count valeurs qui seront utilisées pour mettre à jour la variable uniforme spécifiée.

DESCRIPTION

glProgramUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glProgramUniform opère sur l'objet programme spécifié par program.

Les commandes glProgramUniform{1|2|3|4}{f|i|ui} sont utilisées pour modifier la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs à virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour les variables uniformes définies comme int, ivec2, ivec3, ivec4, ou des tableaux de celles-ci. Les variantes ui doivent être utilisées pour fournir des valeurs pour les variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de celles-ci. Les variantes f doivent être utilisées pour fournir des valeurs pour les variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de celles-ci. Les variantes i, ui ou f peuvent être utilisées pour fournir des valeurs pour les variables uniformes de type bool, bvec2, bvec3, bvec4, ou des tableaux de celles-ci. La variable uniforme sera mise à false si la valeur d'entrée est 0 ou 0.0f, et elle sera mise à true sinon.

Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lors de la liaison réussie de l'objet programme. Elles conservent les valeurs qui leur sont assignées par un appel à glProgramUniform jusqu'à la prochaine opération de liaison réussie sur l'objet programme, moment où elles sont à nouveau initialisées à 0.

Les commandes glProgramUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une seule variable uniforme ou un tableau de variables uniformes. Ces commandes passent un nombre et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un nombre de 1 doit être utilisé si l'on modifie la valeur d'une seule variable uniforme, et un nombre de 1 ou plus peut être utilisé pour modifier un tableau entier ou une partie d'un tableau. Lors du chargement de n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 du tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est supérieur à la taille du tableau de variables uniformes, les valeurs pour tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre spécifié dans le nom de la commande indique le nombre de composantes pour chaque élément de value, et il doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, bool ; 2 pour vec2, ivec2, bvec2, etc.). Le type de données spécifié dans le nom de la commande doit correspondre au type de données de la variable uniforme spécifiée, comme décrit précédemment pour glProgramUniform{1|2|3|4}{f|i|ui}.

Pour les tableaux de variables uniformes, chaque élément du tableau est considéré comme étant du type indiqué dans le nom de la commande (par exemple, glProgramUniform3f ou glProgramUniform3fv peuvent être utilisés pour charger un tableau de variables uniformes de type vec3). Le nombre d'éléments du tableau de variables uniformes à modifier est spécifié par count.

Les commandes glProgramUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv sont utilisées pour modifier une matrice ou un tableau de matrices. Les nombres dans le nom de la commande sont interprétés comme la dimensionnalité de la matrice. Le nombre 2 indique une matrice 2 × 2 (c'est-à-dire 4 valeurs), le nombre 3 indique une matrice 3 × 3 (c'est-à-dire 9 valeurs), et le nombre 4 indique une matrice 4 × 4 (c'est-à-dire 16 valeurs). La dimensionnalité non carrée est explicite, le premier nombre représentant le nombre de colonnes et le second nombre représentant le nombre de lignes. Par exemple, 2x4 indique une matrice 2 × 4 avec 2 colonnes et 4 lignes (c'est-à-dire 8 valeurs). Si transpose est GL_FALSE, chaque matrice est supposée être fournie en ordre colonne majeur. Si transpose est GL_TRUE, chaque matrice est supposée être fournie en ordre ligne majeur. L'argument count indique le nombre de matrices à passer. Un nombre de 1 doit être utilisé si l'on modifie la valeur d'une seule matrice, et un nombre supérieur à 1 peut être utilisé pour modifier un tableau de matrices.

NOTES

glProgramUniform1i et glProgramUniform1iv sont les deux seules fonctions qui peuvent être utilisées pour charger des variables uniformes définies comme des types sampler. Le chargement de samplers avec toute autre fonction entraînera une erreur GL_INVALID_OPERATION.

Si count est supérieur à 1 et que la variable uniforme indiquée n'est pas un tableau, une erreur GL_INVALID_OPERATION est générée et la variable uniforme spécifiée restera inchangée.

À l'exception des exceptions précédentes, si le type et la taille de la variable uniforme telle que définie dans le shader ne correspondent pas au type et à la taille spécifiés dans le nom de la commande utilisée pour charger sa valeur, une erreur GL_INVALID_OPERATION sera générée et la variable uniforme spécifiée restera inchangée.

Si location est une valeur autre que -1 et qu'elle ne représente pas un emplacement de variable uniforme valide dans program, une erreur sera générée et aucune modification ne sera apportée au stockage de la variable uniforme de program. Si location est égal à -1, les données passées seront ignorées silencieusement et la variable uniforme spécifiée ne sera pas modifiée.

ERREURS

GL_INVALID_OPERATION est généré si program ne fait pas référence à un objet programme appartenant à GL.

GL_INVALID_OPERATION est généré si la taille de la variable uniforme déclarée dans le shader ne correspond pas à la taille indiquée par la commande glProgramUniform.

GL_INVALID_OPERATION est généré si l'une des variantes entières signées ou non signées de cette fonction est utilisée pour charger une variable uniforme de type float, vec2, vec3, vec4, ou un tableau de celles-ci, ou si l'une des variantes à virgule flottante de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières signées de cette fonction est utilisée pour charger une variable uniforme de type unsigned int, uvec2, uvec3, uvec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières non signées de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si location est un emplacement uniforme invalide pour program et que location n'est pas égal à -1.

GL_INVALID_VALUE est généré si count est inférieur à 0.

GL_INVALID_OPERATION est généré si count est supérieur à 1 et que la variable uniforme indiquée n'est pas une variable tableau.

GL_INVALID_OPERATION est généré si un sampler est chargé à l'aide d'une commande autre que glProgramUniform1i et glProgramUniform1iv.
