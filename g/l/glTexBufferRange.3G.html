DESCRIPTIO

N

glTexBufferRange et glTextureBufferRange attachent une plage du magasin de données d'un objet tampon spécifié à un objet texture spécifié, et spécifient le format de stockage pour l'image de texture trouvée dans l'objet tampon. L'objet texture doit être une texture

tampon.

Si buffer est zéro, tout objet tampon attaché à la texture tampon est détaché et aucun nouvel objet tampon n'est attaché. Si buffer est non nul, il doit être le nom d'un objet tampon

existant.

Le début et la taille de la plage sont spécifiés par offset et size respectivement, tous deux mesurés en unités machine de base. offset doit être supérieur ou égal à zéro, size doit être supérieur à zéro, et la somme de offset et size ne doit pas dépasser la valeur de GL_BUFFER_SIZE pour buffer. De plus, offset doit être un multiple entier de la valeur de GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT

.

internalformat spécifie le format de stockage et doit être l'un des formats internes dimensionnés suivants

Lorsqu'une plage d'un objet tampon est attachée à une texture tampon, la plage spécifiée du magasin de données de l'objet tampon est prise comme le tableau de texels de la texture. Le nombre de texels dans le tableau de texels de la texture tampon est donné par $$ \left\lfloor { size \over { components \times sizeof(base\_type) } } \right\rfloor $$ où $components$ et $base\_type$ sont le nombre d'éléments et le type de données de base des éléments, comme spécifié dans le tableau ci-dessus. Le nombre de texels dans le tableau de texels est ensuite limité à la valeur de la limite dépendant de l'implémentation GL_MAX_TEXTURE_BUFFER_SIZE. Lorsqu'une texture tampon est accédée dans un shader, les résultats d'une récupération de texel sont indéf

inis si la coordonnée de texel spécifiée est négative, ou supérieu
re ou égale au nombre limité de texels dans le tableau de texels.

ERREUR

S

GL_INVALID_ENUM est généré par glTexBufferRange si target n'est pas GL_TEXTURE_BUFFER

.

GL_INVALID_OPERATION est généré par glTextureBufferRange si texture n'est pas le nom d'un objet texture

existant.

GL_INVALID_ENUM est généré par glTextureBufferRange si la cible effective de texture n'est pas GL_TEXTURE_BUFFER

.

GL_INVALID_ENUM est généré si internalformat n'est pas l'un des formats internes dimensionnés décrits

ci-dessus.

GL_INVALID_OPERATION est généré si buffer n'est pas zéro et n'est pas le nom d'un objet tampon

existant.

GL_INVALID_VALUE est généré si offset est négatif, si size est inférieur ou égal à zéro, ou si offset + size est supérieur à la valeur de GL_BUFFER_SIZE pour buffer

.

GL_INVALID_VALUE est généré si offset n'est pas un multiple entier de la valeur de GL_TEXTURE_BUFFER_OFFSET_ALIGNMEN

T
.
