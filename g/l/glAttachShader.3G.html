NOM

glAttachShader - Attache un objet shader à un objet programme

SPÉCIFICATIONS C

void glAttachShader(GLuint program, GLuint shader);

PARAMÈTRES

program

Spécifie l'objet programme auquel un objet shader sera attaché.

shader

Spécifie l'objet shader qui doit être attaché.

DESCRIPTION

Pour créer un programme shader complet, il doit y avoir un moyen de spécifier la liste des éléments qui seront liés ensemble. Les objets programme fournissent ce mécanisme. Les shaders qui doivent être liés ensemble dans un objet programme doivent d'abord y être attachés. glAttachShader attache l'objet shader spécifié par shader à l'objet programme spécifié par program. Cela indique que shader sera inclus dans les opérations de liaison qui seront effectuées sur program.

Toutes les opérations qui peuvent être effectuées sur un objet shader sont valides, qu'il soit attaché ou non à un objet programme. Il est permis d'attacher un objet shader à un objet programme avant que le code source ne soit chargé dans l'objet shader ou avant que l'objet shader ne soit compilé. Il est permis d'attacher plusieurs objets shader du même type car chacun peut contenir une partie du shader complet. Il est également permis d'attacher un objet shader à plus d'un objet programme. Si un objet shader est supprimé alors qu'il est attaché à un objet programme, il sera marqué pour suppression, et la suppression n'aura lieu que lorsque glDetachShader() sera appelée pour le détacher de tous les objets programme auxquels il est attaché.

ERREURS

GL_INVALID_VALUE est généré si program ou shader n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si program n'est pas un objet programme.

GL_INVALID_OPERATION est généré si shader n'est pas un objet shader.

GL_INVALID_OPERATION est généré si shader est déjà attaché à program.

GETS ASSOCIÉS

glGetAttachedShaders() avec le handle d'un objet programme valide

glGetShaderInfoLog()

glGetShaderSource()

glIsProgram()

glIsShader()
