NOM

glDrawTransformFeedbackInstanced - Dessine plusieurs instances de primitives en utilisant un compte dérivé d'un objet de retour de transformation.

SPÉCIFICATION C

void glDrawTransformFeedbackInstanced(GLenum mode, GLuint id, GLsizei instancecount);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, et GL_PATCHES sont acceptées.

id

Spécifie le nom d'un objet de retour de transformation à partir duquel récupérer un compte de primitives.

instancecount

Spécifie le nombre d'instances de la géométrie à rendre.

DESCRIPTION

glDrawTransformFeedbackInstanced dessine plusieurs copies d'une plage de primitives du type spécifié par mode en utilisant un compte récupéré depuis le flux de retour de transformation spécifié par stream de l'objet de retour de transformation spécifié par id. L'appel à glDrawTransformFeedbackInstanced est équivalent à l'appel à glDrawArraysInstanced() avec mode et instancecount tels que spécifiés, first défini à zéro, et count défini au nombre de sommets capturés sur le flux de sommets zéro lors de la dernière activation du retour de transformation sur l'objet de retour de transformation nommé par id.

L'appel à glDrawTransformFeedbackInstanced est équivalent à l'appel à glDrawTransformFeedbackStreamInstanced() avec stream défini à zéro.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si id n'est pas le nom d'un objet de retour de transformation.

GL_INVALID_VALUE est généré si stream est supérieur ou égal à la valeur de GL_MAX_VERTEX_STREAMS.

GL_INVALID_OPERATION est généré si un objet tampon non nul est lié à un tableau activé et que le magasin de données de l'objet tampon est actuellement mappé.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si mode est GL_PATCHES et qu'aucun shader de contrôle de tessellation n'est actif.

GL_INVALID_OPERATION est généré si

glEndTransformFeedback n'a jamais été appelé alors que l'objet de retour de transformation nommé par id était lié.
