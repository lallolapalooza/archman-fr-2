NOM

glab-opentofu-init - Initialise OpenTofu ou Terraform.

SYNOPIS

glab opentofu init [indicateurs]

DESCRIPTION

Initialise OpenTofu ou Terraform.

OPTIONS

-b, --binary="tofu" Nom ou chemin du binaire OpenTofu ou Terraform à utiliser pour l'initialisation.

-d, --directory="." Répertoire du projet OpenTofu ou Terraform à initialiser.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre répertoire. Peut utiliser le format PROPRIÉTAIRE/RÉPERTOIRE ou GROUPE/ESPACE DE NOMS/RÉPERTOIRE. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Initialiser l'état avec le nom de production dans le répertoire de travail
$ glab opentofu init production
# Initialiser l'état avec le nom de production dans le répertoire infra/
$ glab opentofu init production -d infra/
# Initialiser l'état avec le nom de production avec Terraform
$ glab opentofu init production -b terraform
# Initialiser l'état avec le nom de production avec reconfigurer l'état
$ glab opentofu init production -- -reconfigure
