NOM

glBindSamplers - lie un ou plusieurs objets sampler nommés à une séquence d'unités de sampler consécutives

SPÉCIFICATION C

void glBindSamplers(GLuint first, GLsizei count, const GLuint *samplers);

PARAMÈTRES

first

Spécifie la première unité de sampler à laquelle un objet sampler doit être lié.

count

Spécifie le nombre de samplers à lier.

samplers

Spécifie l'adresse d'un tableau de noms d'objets sampler existants.

DESCRIPTION

glBindSamplers lie des samplers d'un tableau d'objets sampler existants à un nombre spécifié d'unités de sampler consécutives. count spécifie le nombre d'objets sampler dont les noms sont stockés dans le tableau samplers. Ce nombre de noms de samplers est lu à partir du tableau et lié aux count unités de sampler consécutives commençant à first.

Si le nom zéro apparaît dans le tableau samplers, toute liaison existante à l'unité de sampler est réinitialisée. Toute entrée non nulle dans samplers doit être le nom d'un objet sampler existant. Lorsqu'une entrée non nulle dans samplers est présente, cet objet sampler est lié à l'unité de sampler correspondante. Si samplers est NULL, c'est comme si un tableau de taille appropriée contenant uniquement des zéros avait été spécifié.

glBindSamplers est équivalent au pseudo-code suivant :

    for (i = 0; i < count; i++) {
        if (samplers == NULL) {
            glBindSampler(first + i, 0);
        } else {
            glBindSampler(first + i, samplers[i]);
        }
    }

Chaque entrée dans samplers sera vérifiée individuellement et si elle est trouvée invalide, l'état de cette unité de sampler ne sera pas modifié et une erreur sera générée. Cependant, l'état des autres unités de sampler référencées par la commande sera toujours mis à jour.

NOTES

glBindSamplers n'est disponible que si la version de GL est 4.4 ou supérieure.

ERREURS

GL_INVALID_OPERATION est généré si first + count est supérieur au nombre d'unités de sampler supportées par l'implémentation.

GL_INVALID_OPERATION est généré si toute valeur dans samplers n'est pas zéro ou le nom d'un objet sampler existant.

GETS ASSOCIÉS

glGet() avec l'argument GL_SAMPLER_BINDING
