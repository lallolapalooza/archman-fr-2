NOM

glCreateFramebuffers - crée des objets framebuffer

SPÉCIFICATION C

void glCreateFramebuffers(GLsizei n, GLuint *framebuffers);

PARAMÈTRES

n

Nombre d'objets framebuffer à créer.

framebuffers

Spécifie un tableau dans lequel sont stockés les noms des nouveaux objets framebuffer.

DESCRIPTION

glCreateFramebuffers retourne n noms de framebuffer précédemment inutilisés dans framebuffers, chacun représentant un nouveau objet framebuffer initialisé à son état par défaut.

ERREURS

GL_INVALID_VALUE est généré si n est négatif.
