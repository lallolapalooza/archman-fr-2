PARAMÈTRES

location

Spécifie l'emplacement de la variable uniforme à modifier.

count

Pour les commandes de vecteurs (glUniform*v), spécifie le nombre d'éléments à modifier. Il doit être de 1 si la variable uniforme ciblée n'est pas un tableau, et de 1 ou plus si c'est un tableau.

Pour les commandes de matrices (glUniformMatrix*), spécifie le nombre de matrices à modifier. Il doit être de 1 si la variable uniforme ciblée n'est pas un tableau de matrices, et de 1 ou plus si c'est un tableau de matrices.

transpose

Pour les commandes de matrices, spécifie si la matrice doit être transposée lors du chargement des valeurs dans la variable uniforme.

v0, v1, v2, v3

Pour les commandes scalaires, spécifie les nouvelles valeurs à utiliser pour la variable uniforme spécifiée.

value

Pour les commandes de vecteurs et de matrices, spécifie un pointeur vers un tableau de count valeurs qui seront utilisées pour mettre à jour la variable uniforme spécifiée.

DESCRIPTION

glUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant par un appel à glUseProgram().

Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs flottantes sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. NAME

glUniformMatrix2fv — set the value of a uniform variable

C SPECIFICATION

void glUniformMatrix2fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);

PARAMETERS

location
Specifies the uniform variable to be modified. Must be the active uniform variable associated with the specified location. If location is equal to −1, the function does nothing.
count
Specifies the number of matrices that will be downloaded and uploaded to the active uniform variable.
transpose
Specifies whether to transpose the matrix or matrices. Must be GL_FALSE
value
Specifies a pointer to the new values that will be used to update the specified uniform variable.

DESCRIPTION

glUniformMatrix* functions update the value of a uniform variable within the current active program object. The particular variable is specified by its location, which must have been previously obtained by generating a.

The location parameter must be the active uniform variable associated with the specified location in the current program object. If the uniform variable specified by location is not an array, then count must be 1. If the uniform variable is an array, count can be greater than 1, in which case location must refer to the first element of the array, and the function will update count elements of the array.

The transpose parameter indicates whether the matrix, or matrices, should be transposed. If transpose is GL_TRUE the matrix is transposed. If it is GL_FALSE the matrix is not transposed.

The value parameter points to a list of count matrices, each of size 2x2, to be uploaded to the uniform variable. The matrices are taken from the array in standard mathematical, column-major, or row-major, depending on the value of transpose The matrices are loaded into the uniform variable in the order they appear in the array.

If location is −1, the command is ignored. This is useful for optimization, as it allows you to avoid computing an updated uniform value if it's not actively being used.

If the named uniform variable is not found in the current active program, or if location is not valid, then glUniformMatrix2fv glUniformMatrix2x3fv glUniformMatrix2x4fv glUniformMatrix3fv glUniformMatrix3x2fv glUniformMatrix3x4fv glUniformMatrix4fv glUniformMatrix4x2fv and glUniformMatrix4x3fv are ignored.

The transpose parameter must be GL_FALSE for all the matrix uniform setting functions except for the 2x2, 3x3 and 4x4 matrices.

The matrix values are loaded into the uniform variable in the order they appear in the array. For example, if transpose is GL_FALSE the matrix

    m00 m10 m20 m30
    m01 m11 m21 m31
    m02 m12 m22 m32
    m03 m13 m23 m33

will be loaded from the array pointed to by value which will contain

    m00 m01 m02 m03 m10 m11 m12 m13 m20 m21 m22 m23 m30 m31 m32 m33

If transpose is GL_TRUE the matrix will be loaded from the array pointed to by value in the order

    m00 m10 m20 m30 m01 m11 m21 m31 m02 m12 m22 m32 m03 m13 m23 m33

NOTES

If the program object containing the uniform variable does not contain a program pipeline object, glUniformMatrix2fv glUniformMatrix2x3fv glUniformMatrix2x4fv glUniformMatrix3fv glUniformMatrix3x2fv glUniformMatrix3x4fv glUniformMatrix4fv glUniformMatrix4x2fv and glUniformMatrix4x3fv update the uniform variable in the program object specified by glUseProgram If the program object does not contain a program pipeline object, this function has no effect.

Uniform locations are associated with a program object, not with individual shader objects. If a program object is relinked but its uniform variables are not renamed, the locations of the uniform variables remain valid.

The transpose parameter is only supported for 2x2, 3x3 and 4x4 matrices.

ERRORS

The following generate a GL_INVALID_OPERATION error:

  • If location is not valid for the active program object.
  • If the named uniform variable is not found in the active program object.
  • If transpose is not GL_FALSE and the matrix is not 2x2, 3x3, or 4x4.

The following generate a GL_INVALID_VALUE error:

  • If count is greater than 1 and location does not refer to the first element of an array uniform variable.
  • If any of the dimensions of the specified uniform variable (e.g., rows, columns) are not compatible with the dimensions implied by the function call.
