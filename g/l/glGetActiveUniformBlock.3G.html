NOM

glGetActiveUniformBlock - interroge des informations sur un bloc uniforme actif

SPÉCIFICATION C

void glGetActiveUniformBlockiv(GLuintprogram, GLuintuniformBlockIndex, GLenumpname, GLint *params);

PARAMÈTRES

program

Spécifie le nom d'un programme contenant le bloc uniforme.

uniformBlockIndex

Spécifie l'index du bloc uniforme dans program.

pname

Spécifie le nom du paramètre à interroger.

params

Spécifie l'adresse d'une variable destinée à recevoir le résultat de l'interrogation.

DESCRIPTION

glGetActiveUniformBlockiv récupère des informations sur un bloc uniforme actif dans program.

program doit être le nom d'un objet programme pour lequel la commande glLinkProgram() a dû être appelée par le passé, bien qu'il ne soit pas requis que glLinkProgram() ait réussi. La liaison aurait pu échouer parce que le nombre d'uniformes actifs a dépassé la limite.

uniformBlockIndex est un index de bloc uniforme actif de program, et doit être inférieur à la valeur de GL_ACTIVE_UNIFORM_BLOCKS.

En cas de succès, le(s) paramètre(s) du bloc uniforme spécifié(s) par pname sont renvoyé(s) dans params. Si une erreur se produit, rien ne sera écrit dans params.

Si pname est GL_UNIFORM_BLOCK_BINDING, alors l'index du point de liaison du tampon uniforme dernier sélectionné par le bloc uniforme spécifié par uniformBlockIndex pour program est renvoyé. Si aucun bloc uniforme n'a été spécifié auparavant, zéro est renvoyé.

Si pname est GL_UNIFORM_BLOCK_DATA_SIZE, alors la taille totale minimale de l'objet tampon, en unités machine de base, requise pour contenir tous les uniformes actifs dans le bloc uniforme identifié par uniformBlockIndex est renvoyée. Il n'est ni garanti ni attendu qu'une implémentation donnée arrange les valeurs uniformes de manière serrée dans un objet tampon. L'exception à cela est la disposition de bloc uniforme std140, qui garantit un comportement de paquetage spécifique et ne requiert pas de l'application d'interroger les décalages et les pas. Dans ce cas, la taille minimale peut toujours être interrogée, même si elle est déterminée à l'avance sur la seule base de la déclaration du bloc uniforme.

Si pname est GL_UNIFORM_BLOCK_NAME_LENGTH, alors la longueur totale (incluant le terminateur nul) du nom du bloc uniforme identifié par uniformBlockIndex est renvoyée.

Si pname est GL_UNIFORM_BLOCK_ACTIVE_UNIFORMS, alors le nombre d'uniformes actifs dans le bloc uniforme identifié par uniformBlockIndex est renvoyé.

Si pname est GL_UNIFORM_BLOCK_ACTIVE_UNIFORM_INDICES, alors une liste des index d'uniformes actifs pour le bloc uniforme identifié par uniformBlockIndex est renvoyée. Le nombre d'éléments qui seront écrits dans params est la valeur de GL_UNIFORM_BLOCK_ACTIVE_UNIFORMS pour uniformBlockIndex.

Si pname est GL_UNIFORM_BLOCK_REFERENCED_BY_VERTEX_SHADER, GL_UNIFORM_BLOCK_REFERENCED_BY_TESS_CONTROL_SHADER, GL_UNIFORM_BLOCK_REFERENCED_BY_TESS_EVALUATION_SHADER, GL_UNIFORM_BLOCK_REFERENCED_BY_GEOMETRY_SHADER, GL_UNIFORM_BLOCK_REFERENCED_BY_FRAGMENT_SHADER, ou GL_UNIFORM_BLOCK_REFERENCED_BY_COMPUTE_SHADER alors une valeur booléenne indiquant si le bloc uniforme identifié par uniformBlockIndex est référencé par les étages de programmation de vertex, de contrôle de tessellation, d'évaluation de tessellation, de géométrie, de fragment ou de calcul du programme, respectivement, est renvoyée.

ERREUR

GL_INVALID_VALUE est généré si uniformBlockIndex est supérieur ou égal à la valeur de GL_ACTIVE_UNIFORM_BLOCKS ou n'est pas l'index d'un bloc uniforme actif dans program.

GL_INVALID_ENUM est généré si pname n'est pas l'un des jetons acceptés.

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un objet programme pour lequel glLinkProgram() a été appelé par le passé.

NOTES

glGetActiveUniformBlockiv n'est disponible que si la version GL est 3.1 ou supérieure.

GL_UNIFORM_BLOCK_REFERENCED_BY_COMPUTE_SHADER n'est accepté que si la version GL est 4.3 ou supérieure.
