NOM

glShaderSource - Remplace le code source dans un objet shader

SPÉCIFICATION C

void glShaderSource(GLuint shader, GLsizei count, const GLchar **string, const GLint *length);

PARAMÈTRES

shader

Spécifie le descripteur de l'objet shader dont le code source doit être remplacé.

count

Spécifie le nombre d'éléments dans les tableaux string et length.

string

Spécifie un tableau de pointeurs vers des chaînes contenant le code source à charger dans le shader.

length

Spécifie un tableau des longueurs de chaînes.

DESCRIPTION

glShaderSource définit le code source dans shader comme étant le code source dans le tableau de chaînes spécifié par string. Tout code source précédemment stocké dans l'objet shader est complètement remplacé. Le nombre de chaînes dans le tableau est spécifié par count. Si length est NULL, chaque chaîne est supposée être terminée par un caractère nul. Si length est une valeur autre que NULL, il pointe vers un tableau contenant une longueur de chaîne pour chacun des éléments correspondants de string. Chaque élément dans le tableau length peut contenir la longueur de la chaîne correspondante (le caractère nul n'est pas compté comme faisant partie de la longueur de la chaîne) ou une valeur inférieure à 0 pour indiquer que la chaîne est terminée par un caractère nul. Les chaînes de code source ne sont pas analysées ou interprétées à ce moment-là ; elles sont simplement copiées dans l'objet shader spécifié.

NOTES

OpenGL copie les chaînes de code source du shader lorsque glShaderSource est appelée, donc une application peut libérer sa copie des chaînes de code source immédiatement après le retour de la fonction.

ERREURS

GL_INVALID_VALUE est générée si shader n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est générée si shader n'est pas un objet shader.

GL_INVALID_VALUE est générée si count est inférieur à 0.

GETS ASSOCIÉS

glGetShader() avec les arguments shader et GL_SHADER_SOURCE_LENGTH

glGetShaderSource() avec l'argument shader

glIsShader()
