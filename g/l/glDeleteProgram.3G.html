NOM

glDeleteProgram - Supprime un objet programme

SPÉCIFICATION C

void glDeleteProgram(GLuint program);

PARAMÈTRES

program

Spécifie l'objet programme à supprimer.

DESCRIPTION

glDeleteProgram libère la mémoire et invalide le nom associé à l'objet programme spécifié par program. Cette commande annule effectivement les effets d'un appel à glCreateProgram().

Si un objet programme est en cours d'utilisation dans le cadre de l'état de rendu actuel, il sera marqué pour suppression, mais il ne sera pas supprimé tant qu'il ne fera plus partie de l'état actuel pour aucun contexte de rendu. Si un objet programme à supprimer a des objets shader attachés, ces objets shader seront automatiquement détachés mais pas supprimés à moins qu'ils n'aient déjà été marqués pour suppression par un appel précédent à glDeleteShader(). Une valeur de 0 pour program sera ignorée silencieusement.

Pour déterminer si un objet programme a été marqué pour suppression, appelez glGetProgram() avec les arguments program et GL_DELETE_STATUS.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas une valeur générée par OpenGL.

GETS ASSOCIÉS

glGet() avec l'argument GL_CURRENT_PROGRAM

glGetProgram() avec les arguments program et GL_DELETE_STATUS

glIsProgram()
