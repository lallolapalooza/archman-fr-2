NOM

glGetProgramPipelineInfoLog - récupérer la chaîne du journal d'informations d'un objet pipeline de programme

SPÉCIFICATION C

void glGetProgramPipelineInfoLog(GLuint pipeline, GLsizei bufSize, GLsizei *length, GLchar *infoLog);

PARAMÈTRES

pipeline

Spécifie le nom d'un objet pipeline de programme à partir duquel récupérer le journal d'informations.

bufSize

Spécifie le nombre maximum de caractères, y compris le terminateur null, qui peuvent être écrits dans infoLog.

length

Spécifie l'adresse d'une variable dans laquelle sera écrit le nombre de caractères écrits dans infoLog.

infoLog

Spécifie l'adresse d'un tableau de caractères dans lequel sera écrit le journal d'informations pour pipeline.

DESCRIPTION

glGetProgramPipelineInfoLog récupère le journal d'informations pour l'objet pipeline de programme pipeline. Le journal d'informations, y compris son terminateur null, est écrit dans le tableau de caractères dont l'adresse est donnée par infoLog. Le nombre maximum de caractères pouvant être écrits dans infoLog est donné par bufSize, et le nombre réel de caractères écrits dans infoLog est retourné dans l'entier dont l'adresse est donnée par length. Si length est NULL, aucune longueur n'est retournée.

La longueur réelle du journal d'informations pour le pipeline de programme peut être déterminée en appelant glGetProgramPipeline() avec pname défini sur GL_INFO_LOG_LENGTH.

ERREURS

GL_INVALID_OPERATION est généré si pipeline n'est pas un nom retourné précédemment par un appel à glGenProgramPipelines() ou si un tel nom a été supprimé par un appel à glDeleteProgramPipelines().

GETS ASSOCIÉS

glGetProgramPipeline() avec le paramètre GL_INFO_LOG_LENGTH.
