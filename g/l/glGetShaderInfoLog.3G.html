NOM

glGetShaderInfoLog - Renvoie le journal d'informations d'un objet shader

SPÉCIFICATION EN C

void glGetShaderInfoLog(GLuint shader, GLsizei maxLength, GLsizei *length, GLchar *infoLog);

PARAMÈTRES

shader

Spécifie l'objet shader dont le journal d'informations doit être interrogé.

maxLength

Spécifie la taille du tampon de caractères pour stocker le journal d'informations renvoyé.

length

Renvoie la longueur de la chaîne renvoyée dans infoLog (hors caractère nul de terminaison).

infoLog

Spécifie un tableau de caractères qui est utilisé pour renvoyer le journal d'informations.

DESCRIPTION

glGetShaderInfoLog renvoie le journal d'informations pour l'objet shader spécifié. Le journal d'informations d'un objet shader est modifié lorsque le shader est compilé. La chaîne renvoyée sera terminée par un caractère nul.

glGetShaderInfoLog renvoie dans infoLog autant d'informations que possible du journal, jusqu'à un maximum de maxLength caractères. Le nombre de caractères réellement renvoyés, hors caractère de terminaison nul, est spécifié par length. Si la longueur de la chaîne renvoyée n'est pas requise, une valeur de NULL peut être passée dans l'argument length. La taille du tampon requise pour stocker le journal d'informations renvoyé peut être obtenue en appelant glGetShader() avec la valeur GL_INFO_LOG_LENGTH.

Le journal d'informations d'un objet shader est une chaîne qui peut contenir des messages de diagnostic, des avertissements et d'autres informations sur la dernière opération de compilation. Lorsqu'un objet shader est créé, son journal d'informations sera une chaîne de longueur 0.

NOTES

Le journal d'informations d'un objet shader est le principal mécanisme utilisé par l'implémentation OpenGL pour transmettre des informations sur le processus de compilation. Par conséquent, le journal d'informations peut être utile aux développeurs d'applications pendant le processus de développement, même lorsque la compilation réussit. Les développeurs d'applications ne doivent pas s'attendre à ce que différentes implémentations OpenGL produisent des journaux d'informations identiques.

ERREURS

GL_INVALID_VALUE est généré si shader n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si shader n'est pas un objet shader.

GL_INVALID_VALUE est généré si maxLength est inférieur à 0.

GETS ASSOCIÉS

glGetShader() avec l'argument GL_INFO_LOG_LENGTH

glIsShader()
