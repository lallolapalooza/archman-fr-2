NOM

glCreateSamplers - créer des objets échantillonneurs

SPÉCIFICATION C

void glCreateSamplers(GLsizei n, GLuint *samplers);

PARAMÈTRES

n

Nombre d'objets échantillonneurs à créer.

samplers

Spécifie un tableau dans lequel sont stockés les noms des nouveaux objets échantillonneurs.

DESCRIPTION

glCreateSamplers renvoie n noms d'échantillonneurs précédemment inutilisés dans samplers, représentant chacun un nouvel objet échantillonneur initialisé à l'état par défaut.

ERREURS

GL_INVALID_VALUE est généré si n est négatif.
