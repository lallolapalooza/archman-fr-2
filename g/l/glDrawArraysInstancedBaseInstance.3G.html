NOM

glDrawArraysInstancedBaseInstance - dessine plusieurs instances d'une plage d'éléments avec un décalage appliqué aux attributs instanciés

SPÉCIFICATION C

void glDrawArraysInstancedBaseInstance(GLenum mode, GLint first, GLsizei count, GLsizei instancecount, GLuint baseinstance);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_PATCHES sont acceptées.

first

Spécifie l'indice de départ dans les tableaux actifs.

count

Spécifie le nombre d'indices à rendre.

instancecount

Spécifie le nombre d'instances de la plage d'indices spécifiée à rendre.

baseinstance

Spécifie l'instance de base à utiliser pour récupérer les attributs de sommet instanciés.

DESCRIPTION

glDrawArraysInstancedBaseInstance se comporte de manière identique à glDrawArrays() sauf que instancecount instances de la plage d'éléments sont exécutées et la valeur du compteur interne instanceID s'incrémente pour chaque itération. instanceID est un compteur entier interne de 32 bits qui peut être lu par un shader de sommets sous le nom de gl_InstanceID.

glDrawArraysInstancedBaseInstance a le même effet que :

    si ( mode ou count est invalide )
        générer l'erreur appropriée
    sinon {
        pour (int i = 0; i < instancecount ; i++) {
            instanceID = i;
            glDrawArrays(mode, first, count);
        }
        instanceID = 0;
    }

Certains attributs de sommet peuvent être classés comme instanciés grâce à l'utilisation de glVertexAttribDivisor(). Les attributs de sommet instanciés fournissent des données de sommet par instance au shader de sommets. L'indice du sommet récupéré des tableaux d'attributs de sommet instanciés actifs est calculé comme : gl _ InstanceID * diviseur + baseInstance. Notez que baseinstance n'affecte pas la valeur visible par le shader de gl_InstanceID.

ERREURS

GL_INVALID_ENUM est générée si mode n'est pas l'une des valeurs acceptées.

GL_INVALID_OPERATION est générée si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_VALUE est générée si count ou instancecount est négatif.

GL_INVALID_OPERATION est générée si un objet tampon non nul est lié à un tableau actif et que le stockage de données de l'objet tampon est actuellement mappé.
