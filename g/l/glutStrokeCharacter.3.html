glutStrokeCharacter(3)

Paquet: freeglut

Licences: X11

glutStrokeCharacter(3) freeglut glutStrokeCharacter(3)

NOM

glutStrokeCharacter - rend un caractère en traits à l'aide d'OpenGL.

SYNTAXE

void glutStrokeCharacter(void *font, int character);

ARGUMENTS

font
Police en traits à utiliser.
caractère
Caractère à rendre (pas limité à 8 bits).

DESCRIPTION

Sans utiliser de listes d'affichage, glutStrokeCharacter rend le caractère de la police en traits nommée. Les polices disponibles sont :

GLUT_STROKE_ROMAN
Une police Roman Simplex à espacement proportionnel pour les caractères ASCII de 32 à 127. Le caractère le plus haut de la police est à 119.05 unités ; le bas descend de 33.33 unités.
GLUT_STROKE_MONO_ROMAN
Une police Roman Simplex à espacement mono-espacé (mêmes caractères que GLUT_STROKE_ROMAN) pour les caractères ASCII de 32 à 127. Le caractère le plus haut de la police est à 119.05 unités ; le bas descend de 33.33 unités. Chaque caractère mesure 104.76 unités de large.

Le rendu d'un caractère inexistant n'a aucun effet. Un glTranslatef est utilisé pour translater la matrice de vue du modèle actuelle afin de faire avancer la largeur du caractère.

EXEMPLE

Voici une routine qui montre comment rendre une chaîne de texte ASCII avec glutStrokeCharacter :

  void
  output(GLfloat x, GLfloat y, char *text)
  {
    char *p;
    glPushMatrix();
    glTranslatef(x, y, 0);
    for (p = text; *p; p++)
      glutStrokeCharacter(GLUT_STROKE_ROMAN, *p);
    glPopMatrix();
  }

Si vous souhaitez dessiner du texte en police de traits avec des lignes épaisses et anti-aliassées, utilisez :

  glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);
  glEnable(GL_BLEND);
  glEnable(GL_LINE_SMOOTH);
  glLineWidth(2.0);
  output(200, 225, "Ceci est anti-aliassé.");
