Code LilyPond intégré

Un lilypond partie au sein d'une structure écrite dans le groff langage est la partie entière entre les marques

.lilypond start
et 
.lilypond end
Une groff entrée peut avoir plusieurs de ces lilypond parties.

Lors du traitement d'une telle lilypond partie entre .lilypond start et .lilypond end nous disons que le glilypond programme est en mode lilypond.

Ces lilypond parties sont envoyées dans des fichiers lilypond temporaires avec l'extension de nom de fichier .ly. Ces fichiers sont transformés plus tard en fichiers EPS .

Inclusion de .ly fichiers

Une ligne de commande supplémentaire pour l'inclusion de fichiers de lilypond est donnée par

.lilypond include file_name

dans groff entrée. Pour chaque include commande, un fichier de code lilypond peut être inclus dans le groff code. Arbitrairement beaucoup de ces commandes peuvent être incluses dans le groff entrée.

Ces commandes include ne peuvent être utilisées qu'en dehors des lilypond parties. Dans le mode lilypond, cette inclusion est impossible. Donc .lilypond include ne peut pas être utilisé en mode lilypond, c'est-à-dire entre .lilypond start et .lilypond end. Ces fichiers lyinclus sont également transformés en fichiers EPS .

Fichiers générés

Par le processus de transformation des lilypond parties en fichiers EPS , de nombreux fichiers sont générés. Par défaut, ces fichiers sont considérés comme des fichiers temporaires et sont stockés dans un répertoire temporaire.

Ce processus peut être modifié par des options de ligne de commande.

Options de ligne de commande pour les répertoires

Le répertoire temporaire pour ce programme est soit créé automatiquement, soit peut être nommé par l'option -t|--temp_dir dir.

De plus, les EPS fichiers auxquels il est fait référence plus tard par la .PSPIC commande dans la sortie groff finale peuvent être stockés dans un répertoire différent qui peut être défini par l'option de ligne de commande -e|--eps_dir directory_name. Avec cette option, le répertoire temporaire peut être complètement supprimé à la fin du programme.

Le début des noms des fichiers temporaires peut être défini par les options de ligne de commande -p ou --prefix.

Tous les fichiers temporaires à l'exception des EPS fichiers sont finalement supprimés. Cela peut être modifié en définissant les options de ligne de commande -k ou --keep_files. Avec cela, tous les fichiers et répertoires temporaires sont conservés, non supprimés.

Ces EPS fichiers sont stockés dans un répertoire temporaire ou EPS . Mais ils ne peuvent pas être supprimés par le processus de transformation car ils sont nécessaires pour l'affichage, ce qui peut prendre du temps.

Processus de transformation pour générer des fichiers EPS

Mode pdf2eps

Ce mode est le défaut actuel et peut également être choisi par l'option --pdf2eps.

Dans ce mode, les .ly fichiers sont transformés par le lilypond(1) programme en fichiers PDF , en utilisant

lilypond --pdf --output=file-name
pour chaque .ly fichier. Le file-name doit être fourni sans l' extension .pdf. Par ce processus, un fichier file-name.pdf est généré.

L'étape suivante est de transformer ces fichiers PDF en un fichier PS . Cela est fait par le pdf2ps(1) programme en utilisant

$
pdf2ps
file-name.pdf
file-name.pds
L'étape suivante crée un fichier EPS à partir du fichier PS . Cela est fait par le ps2eps(1) programme en utilisant 
$ ps2eps file-name.ps

Par cela, un fichier file-name.eps est créé pour chaque lilypond partie dans le groff fichier ou entrée standard.

La dernière étape à effectuer est de remplacer toutes les lilypond parties par la groff commande

.PSPIC file-name.eps

Mode ly2eps

Autrefois, ce mode était le défaut. Mais maintenant il ne fonctionne plus, donc acceptez le nouveau défaut pdf2eps. Pour les tests, ce mode peut également être choisi par l' glilypond option --ly2eps.

Dans ce mode, les .ly fichiers sont transformés par le lilypond programme en de nombreux fichiers de formats différents, y compris des fichiers eps , en utilisant

$
lilypond --ps -dbackend=eps -dgs-load-fonts --output=
file-name
pour chaque .ly fichier. La sortie file-name doit être fournie sans extension, son répertoire est temporaire.

De nombreux EPS fichiers sont créés. Un ayant le fichier ly transformé complet, nommé file-name .eps.De plus, il y a des

EPS fichiers pour chaque page, nommés file-name -digit.eps.La dernière étape à effectuer est de remplacer toutes les

lilypond parties par la collection des fichiers de page EPS correspondants. Cela est fait par des groff commandes .PSPIC

file-name -digit.epsSortie
