NOM

glShaderStorageBlockBinding - change la liaison d'un bloc de stockage de shader actif

SPÉCIFICATION C

void glShaderStorageBlockBinding(GLuint program, GLuint storageBlockIndex, GLuint storageBlockBinding);

PARAMÈTRES

program

Le nom du programme contenant le bloc dont la liaison doit être modifiée.

storageBlockIndex

L'indice du bloc de stockage dans le programme.

storageBlockBinding

L'indice de liaison du bloc de stockage à associer au bloc de stockage spécifié.

DESCRIPTION

glShaderStorageBlockBinding modifie le bloc de stockage de shader actif avec un indice assigné de storageBlockIndex dans l'objet programme program. storageBlockIndex doit être un indice de bloc de stockage de shader actif dans program. storageBlockBinding doit être inférieur à la valeur de GL_MAX_SHADER_STORAGE_BUFFER_BINDINGS. En cas de succès, glShaderStorageBlockBinding spécifie que program utilisera le stockage de données de l'objet tampon lié au point de liaison storageBlockBinding pour lire et écrire les valeurs des variables du tampon dans le bloc de stockage du shader identifié par storageBlockIndex.

ERREURS

GL_INVALID_VALUE est générée si program n'est pas le nom d'un objet programme ou d'un objet shader.

GL_INVALID_OPERATION est générée si program est le nom d'un objet shader.

GL_INVALID_VALUE est générée si storageBlockIndex n'est pas un indice de bloc de stockage de shader actif dans program, ou si storageBlockBinding est supérieur ou égal à la valeur de MAX_SHADER_STORAGE_BUFFER_BINDINGS.

GETS ASSOCIÉS

glGet() avec les arguments GL_SHADER_STORAGE_BUFFER_BINDING, GL_MAX_SHADER_STORAGE_BUFFER_BINDINGS, GL_MAX_VERTEX_SHADER_STORAGE_BLOCKS, GL_MAX_TESS_CONTROL_SHADER_STORAGE_BLOCKS, GL_MAX_TESS_EVALUATION_SHADER_STORAGE_BLOCKS, GL_MAX_GEOMETRY_SHADER_STORAGE_BLOCKS, GL_MAX_FRAGMENT_SHADER_STORAGE_BLOCKS, GL_MAX_COMPUTE_SHADER_STORAGE_BLOCKS ou GL_MAX_COMBINED_SHADER_STORAGE_BLOCKS, GL_MAX_SHADER_STORAGE_BUFFER_BINDINGS, ou GL_MAX_COMBINED_SHADER_OUTPUT_RESOURCES.
