NOM

glutKeyboardFunc - définit la fonction de rappel du clavier pour la fenêtre courante.

SYNTAXE

void glutKeyboardFunc(void (*func)(unsigned char key,
                      int x, int y));

ARGUMENTS

func
La nouvelle fonction de rappel du clavier.

DESCRIPTION

glutKeyboardFunc définit la fonction de rappel du clavier pour la fenêtre courante. Lorsqu'un utilisateur tape dans la fenêtre, chaque frappe de touche générant un caractère ASCII déclenchera un rappel du clavier. Le paramètre de rappel de la touche est le caractère ASCII généré. L'état des touches modificatrices telles que Shift ne peut pas être déterminé directement ; leur seul effet sera sur les données ASCII retournées. Les paramètres de rappel x et y indiquent l'emplacement de la souris dans des coordonnées relatives à la fenêtre lorsque la touche a été enfoncée. Lors de la création d'une nouvelle fenêtre, aucune fonction de rappel du clavier n'est initialement enregistrée, et les frappes de touches ASCII dans la fenêtre sont ignorées. Passer NULL à glutKeyboardFunc désactive la génération des rappels du clavier.

Pendant un rappel du clavier, glutGetModifiers peut être appelé pour déterminer l'état des touches modificatrices lors de la frappe qui a généré le rappel.

Utilisez glutSpecialFunc pour un moyen de détecter les frappes de touches non ASCII.
