NOM

glViewport - définir le point de vue

SPÉCIFICATION C

void glViewport(GLint x, GLint y, GLsizei width, GLsizei height);

PARAMÈTRES

x, y

Spécifient le coin inférieur gauche du rectangle du point de vue, en pixels. La valeur initiale est (0,0).

width, height

Spécifient la largeur et la hauteur du point de vue. Lorsqu'un contexte GL est d'abord attaché à une fenêtre, width et height sont définis sur les dimensions de cette fenêtre.

DESCRIPTION

glViewport spécifie la transformation affine de x et y des coordonnées normalisées de l'appareil aux coordonnées de la fenêtre. Soient x nd et y nd les coordonnées normalisées de l'appareil. Alors les coordonnées de la fenêtre x w et y w sont calculées comme suit :

x w = x nd + 1 ⁢ width 2 + x

y w = y nd + 1 ⁢ height 2 + y

La largeur et la hauteur du point de vue sont silencieusement limitées à une plage qui dépend de l'implémentation. Pour interroger cette plage, appelez glGet() avec l'argument GL_MAX_VIEWPORT_DIMS.

ERREURS

GL_INVALID_VALUE est généré si width ou height est négatif.

GETS ASSOCIÉS

glGet() avec l'argument GL_VIEWPORT

glGet() avec l'argument GL_MAX_VIEWPORT_DIMS
