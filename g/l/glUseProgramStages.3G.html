NOM

glUseProgramStages - lier des étapes d'un objet programme à un pipeline de programme

SPÉCIFICATION C

void glUseProgramStages(GLuint pipeline, GLbitfield stages, GLuint program);

PARAMÈTRES

pipeline

Spécifie l'objet pipeline de programme auquel lier les étapes de program.

stages

Spécifie un ensemble d'étapes de programme à lier à l'objet pipeline de programme.

program

Spécifie l'objet programme contenant les exécutables de shader à utiliser dans pipeline.

DESCRIPTION

glUseProgramStages lie les exécutables d'un objet programme associé à un ensemble spécifié d'étapes de shader au pipeline de programme donné par pipeline. pipeline spécifie l'objet pipeline de programme auquel les exécutables sont liés. stages contient une combinaison logique de bits indiquant les étapes de shader à utiliser au sein de program avec l'objet pipeline de programme pipeline. stages doit être une combinaison logique de GL_VERTEX_SHADER_BIT, GL_TESS_CONTROL_SHADER_BIT, GL_TESS_EVALUATION_SHADER_BIT, GL_GEOMETRY_SHADER_BIT, GL_FRAGMENT_SHADER_BIT et GL_COMPUTE_SHADER_BIT. De plus, la valeur spéciale GL_ALL_SHADER_BITS peut être spécifiée pour indiquer que tous les exécutables contenus dans program doivent être installés dans pipeline.

Si program fait référence à un objet programme avec un shader valide attaché pour une étape de shader indiquée, glUseProgramStages installe le code exécutable pour cette étape dans l'objet pipeline de programme indiqué pipeline. Si program est zéro, ou fait référence à un objet programme sans exécutable de shader valide pour une étape donnée, c'est comme si l'objet pipeline n'avait pas d'étape programmable configurée pour les étapes de shader indiquées. Si stages contient des bits autres que ceux listés ci-dessus, et n'est pas égal à GL_ALL_SHADER_BITS, une erreur est générée.

NOTES

Le bit GL_COMPUTE_SHADER_BIT n'est disponible que si la version de GL est 4.3 ou supérieure.

ERREURS

GL_INVALID_VALUE est généré si shaders contient des bits définis qui ne sont pas reconnus, et n'est pas la valeur réservée GL_ALL_SHADER_BITS.

GL_INVALID_OPERATION est généré si program fait référence à un objet programme qui n'a pas été lié avec son statut GL_PROGRAM_SEPARABLE défini.

GL_INVALID_OPERATION est généré si program fait référence à un objet programme qui n'a pas été lié avec succès.

GL_INVALID_OPERATION est généré si pipeline n'est pas un nom retourné précédemment par un appel à glGenProgramPipelines() ou si un tel nom a été supprimé par un appel à glDeleteProgramPipelines().
