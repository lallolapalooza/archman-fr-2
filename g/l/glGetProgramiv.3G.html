DESCRIPTIO

glGetProgram renvoie dans params la valeur d'un paramètre pour un objet programme spécifique. Les paramètres suivants sont définis

:

GL_DELETE_STATU

S

params renvoie GL_TRUE si program est actuellement marqué pour suppression, et GL_FALSE

GL_LINK_STATU

S

params renvoie GL_TRUE si la dernière opération de liaison sur program a réussi, et GL_FALSE

si
non.

GL_VALIDATE_STATU

S

params renvoie GL_TRUE si la dernière opération de validation sur program a réussi, et GL_FALSE

si
non.

GL_INFO_LOG_LENGT

H

params renvoie le nombre de caractères dans le journal d'informations pour program, y compris le caractère de terminaison nul (c'est-à-dire la taille du tampon de caractères requis pour stocker le journal d'informations). Si program n'a pas de journal d'infor

mations, la valeu

GL_ATTACHED_SHADER

ra

ra

S

params renvoie le nombre de variables d'attributs actives pour prog

ra
m.

GL_ACTIVE_ATTRIBUTE_MAX_LENGT

params renvoie la longueur du nom d'attribut actif le plus long pour program, y compris le caractère de terminaison nul (c'est-à-dire la taille du tampon de caractères r

equis pour stocker le nom d'attribut le plus long).

GL_ACTIVE_UNIFORM_MAX_LENGT

REMARQUE

S

GL_ACTIVE_UNIFORM_BLOCKS et GL_ACTIVE_UNIFORM_BLOCK_MAX_NAME_LENGTH ne sont disponibles que si la version GL est 3.1 ou

supérieure.

GL_GEOMETRY_VERTICES_OUT, GL_GEOMETRY_INPUT_TYPE et GL_GEOMETRY_OUTPUT_TYPE ne sont acceptés que si la version GL est 3.2 ou

supérieure.

GL_COMPUTE_WORK_GROUP_SIZE n'est accepté que si la version GL est 4.3 ou

supérieure.

Si une erreur est générée, aucun changement n'est apporté au contenu de para

m
s.

ERREUR

S

GL_INVALID_VALUE est généré si program n'est pas une valeur générée par

OpenGL.

GL_INVALID_OPERATION est généré si program ne fait pas référence à un objet

programme.

GL_INVALID_OPERATION est généré si pname est GL_GEOMETRY_VERTICES_OUT, GL_GEOMETRY_INPUT_TYPE, ou GL_GEOMETRY_OUTPUT_TYPE, et program ne contient pas de shader de

géométrie.

GL_INVALID_ENUM est généré si pname n'est pas une valeur

acceptée.

GL_INVALID_OPERATION est généré si pname est GL_COMPUTE_WORK_GROUP_SIZE et program ne contient pas de binai

re pour l'étage de
shader de calcul.
