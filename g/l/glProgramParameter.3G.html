NOM

glProgramParameter - spécifier un paramètre pour un objet programme

SPÉCIFICATION C

void glProgramParameteri(GLuint program, GLenum pname, GLint value);

PARAMÈTRES

program

Spécifie le nom d'un objet programme dont le paramètre doit être modifié.

pname

Spécifie le nom du paramètre à modifier.

value

Spécifie la nouvelle valeur du paramètre spécifié par pname pour program.

DESCRIPTION

glProgramParameter spécifie une nouvelle valeur pour le paramètre nommé pname pour l'objet programme program.

Si pname est GL_PROGRAM_BINARY_RETRIEVABLE_HINT, value doit être GL_FALSE ou GL_TRUE pour indiquer à l'implémentation l'intention de l'application de récupérer la représentation binaire du programme avec glGetProgramBinary(). L'implémentation peut utiliser cette information pour stocker des informations qui pourraient être utiles pour une future requête de la représentation binaire du programme. Il est recommandé de définir GL_PROGRAM_BINARY_RETRIEVABLE_HINT pour le programme à GL_TRUE avant d'appeler glLinkProgram(), et d'utiliser le programme à l'exécution si le binaire doit être récupéré ultérieurement.

Si pname est GL_PROGRAM_SEPARABLE, value doit être GL_TRUE ou GL_FALSE et indique si program peut être lié à des étapes de pipeline individuelles via glUseProgramStages(). Le paramètre GL_PROGRAM_SEPARABLE d'un programme doit être défini à GL_TRUE avant que glLinkProgram() ne soit appelé pour qu'il puisse être utilisé avec un objet pipeline de programme. L'état initial de GL_PROGRAM_SEPARABLE est GL_FALSE.

ERREURS

GL_INVALID_OPERATION est générée si program n'est pas le nom d'un objet programme existant.

GL_INVALID_ENUM est générée si pname n'est pas l'une des valeurs acceptées.

GL_INVALID_VALUE est générée si value n'est pas une valeur valide pour le paramètre nommé par pname.

GETS ASSOCIÉS

glGetProgram().
