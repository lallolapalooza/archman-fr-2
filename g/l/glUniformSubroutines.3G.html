NOM

glUniformSubroutines - charger les uniformes de sous-routines actifs

SPÉCIFICATION C

void glUniformSubroutinesuiv(GLenum shadertype, GLsizei count, const GLuint *indices);

PARAMÈTRES

shadertype

Spécifie l'étape du shader à partir de laquelle interroger l'indice de l'uniforme de sous-routine. shadertype doit être l'un des éléments suivants : GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER.

count

Spécifie le nombre d'indices d'uniformes stockés dans indices.

indices

Spécifie l'adresse d'un tableau contenant les indices à charger dans les variables uniformes de sous-routines.

DESCRIPTION

glUniformSubroutines charge tous les uniformes de sous-routines actifs pour l'étape de shader shadertype du programme actuel avec les indices de sous-routines de indices, en stockant indices[i] dans l'uniforme à la position i. count doit être égal à la valeur de GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS pour le programme actuellement utilisé à l'étape du shader shadertype. De plus, toutes les valeurs dans indices doivent être inférieures à la valeur de GL_ACTIVE_SUBROUTINES pour l'étape du shader.

ERREURS

GL_INVALID_OPERATION est généré si aucun objet programme n'est en cours d'utilisation.

GL_INVALID_VALUE est généré si count n'est pas égal à la valeur de GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS pour l'étape du shader shadertype du programme actuel.

GL_INVALID_VALUE est généré si une valeur dans indices est supérieure ou égale à la valeur de GL_ACTIVE_SUBROUTINES pour l'étape du shader shadertype du programme actuel.

GL_INVALID_ENUM est généré si shadertype n'est pas l'une des valeurs acceptées.

ASSOCIÉES GETS

glGetProgramStage() avec l'argument GL_ACTIVE_SUBROUTINES

glGetProgramStage() avec l'argument GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS
