NOM

glGetShaderiv - Renvoie un paramètre d'un objet shader

SPÉCIFICATION C

void glGetShaderiv(GLuint shader, GLenum pname, GLint *params);

PARAMÈTRES

shader

Spécifie l'objet shader à interroger.

pname

Spécifie le paramètre de l'objet. Les noms symboliques acceptés sont GL_SHADER_TYPE, GL_DELETE_STATUS, GL_COMPILE_STATUS, GL_INFO_LOG_LENGTH, GL_SHADER_SOURCE_LENGTH.

params

Renvoie le paramètre de l'objet demandé.

DESCRIPTION

glGetShader renvoie dans params la valeur d'un paramètre pour un objet shader spécifique. Les paramètres suivants sont définis :

GL_SHADER_TYPE

params renvoie GL_VERTEX_SHADER si shader est un objet de shader de sommet, GL_GEOMETRY_SHADER si shader est un objet de shader de géométrie, et GL_FRAGMENT_SHADER si shader est un objet de shader de fragment.

GL_DELETE_STATUS

params renvoie GL_TRUE si shader est actuellement marqué pour suppression, et GL_FALSE sinon.

GL_COMPILE_STATUS

params renvoie GL_TRUE si la dernière opération de compilation sur shader a réussi, et GL_FALSE sinon.

GL_INFO_LOG_LENGTH

params renvoie le nombre de caractères dans le journal d'informations pour shader, y compris le caractère de fin de chaîne (c'est-à-dire la taille du tampon de caractères requis pour stocker le journal d'informations). Si shader n'a pas de journal d'informations, une valeur de 0 est renvoyée.

GL_SHADER_SOURCE_LENGTH

params renvoie la longueur de la concaténation des chaînes sources qui composent le code source du shader pour le shader, y compris le caractère de fin de chaîne. (c'est-à-dire la taille du tampon de caractères requis pour stocker le code source du shader). Si aucun code source n'existe, 0 est renvoyé.

NOTES

En cas d'erreur générée, le contenu de params n'est pas modifié.

ERREURS

GL_INVALID_VALUE est généré si shader n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si shader ne fait pas référence à un objet shader.

GL_INVALID_ENUM est généré si pname n'est pas une valeur acceptée.

GETS ASSOCIÉS

glGetShaderInfoLog() avec l'argument shader

glGetShaderSource() avec l'argument shader

glIsShader()
