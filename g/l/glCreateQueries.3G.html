NOM

glCreateQueries - création d'objets de requête

SPÉCIFICATION C

void glCreateQueries(GLenum target, GLsizei n, GLuint *ids);

PARAMÈTRES

target

Spécifie la cible de chaque objet de requête créé.

n

Nombre d'objets de requête à créer.

ids

Spécifie un tableau dans lequel sont stockés les noms des nouveaux objets de requête.

DESCRIPTION

glCreateQueries renvoie n noms d'objets de requête précédemment inutilisés dans ids, représentant chacun un nouvel objet de requête avec la target spécifiée.

target peut être l'un des suivants : GL_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED_CONSERVATIVE, GL_TIME_ELAPSED, GL_TIMESTAMP, GL_PRIMITIVES_GENERATED ou GL_TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN.

ERREURS

GL_INVALID_ENUM est générée si target n'est pas une valeur acceptée.

GL_INVALID_VALUE est générée si n est négatif.
