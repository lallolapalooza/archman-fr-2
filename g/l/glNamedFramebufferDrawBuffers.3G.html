GLDRAWBUFFERS(3G) [FIXME: manuel] GLDRAWBUFFERS(3G)

NOM

glDrawBuffers, glNamedFramebufferDrawBuffers - Spécifie une liste de buffers de couleur dans lesquels écrire

SPÉCIFICATION

void glDrawBuffers(GLsizei n, const GLenum *bufs);

void glNamedFramebufferDrawBuffers(GLuint framebuffer, GLsizei n, const GLenum *bufs);

PARAMÈTRES

framebuffer

Spécifie le nom de l'objet framebuffer pour glNamedFramebufferDrawBuffers.

n

Spécifie le nombre de buffers dans bufs.

bufs

Pointe vers un tableau de constantes symboliques spécifiant les buffers dans lesquels les couleurs des fragments ou les valeurs de données seront écrites.

DESCRIPTION

glDrawBuffers et glNamedFramebufferDrawBuffers définissent un tableau de buffers dans lesquels les sorties des données du shader de fragment seront écrites. Si un shader de fragment écrit une valeur dans une ou plusieurs variables de sortie définies par l'utilisateur, alors la valeur de chaque variable sera écrite dans le buffer spécifié à un emplacement dans bufs correspondant à l'emplacement attribué à cette sortie utilisateur. Le buffer de dessin utilisé pour les sorties utilisateur attribuées à des emplacements supérieurs ou égaux à n est implicitement défini à GL_NONE et toute donnée écrite dans une telle sortie est discardée.

Pour glDrawBuffers, l'objet framebuffer qui est lié à la liaison GL_DRAW_FRAMEBUFFER sera utilisé. Pour glNamedFramebufferDrawBuffers, framebuffer est le nom de l'objet framebuffer. Si framebuffer est zéro, alors le framebuffer par défaut est affecté.

Les constantes symboliques contenues dans bufs peuvent être chacune des suivantes :

GL_NONE

La valeur de sortie du shader de fragment n'est écrite dans aucun buffer de couleur.

GL_FRONT_LEFT

La valeur de sortie du shader de fragment est écrite dans le buffer de couleur avant gauche.

GL_FRONT_RIGHT

La valeur de sortie du shader de fragment est écrite dans le buffer de couleur avant droit.

GL_BACK_LEFT

La valeur de sortie du shader de fragment est écrite dans le buffer de couleur arrière gauche.

GL_BACK_RIGHT

La valeur de sortie du shader de fragment est écrite dans le buffer de couleur arrière droit.

GL_COLOR_ATTACHMENTn

La valeur de sortie du shader de fragment est écrite dans la n-ième pièce jointe de couleur du framebuffer courant. n peut varier de zéro à la valeur de GL_MAX_COLOR_ATTACHMENTS.

À l'exception de GL_NONE, les constantes symboliques précédentes ne peuvent pas apparaître plus d'une fois dans bufs. Le nombre maximum de buffers de dessin pris en charge dépend de l'implémentation et peut être interrogé en appelant glGet() avec l'argument GL_MAX_DRAW_BUFFERS.

NOTES

Les constantes symboliques GL_FRONT, GL_BACK, GL_LEFT, GL_RIGHT et GL_FRONT_AND_BACK ne sont pas autorisées dans le tableau bufs car elles peuvent faire référence à plusieurs buffers.

Si un shader de fragment n'écrit pas dans une variable de sortie définie par l'utilisateur, les valeurs des couleurs des fragments après exécution du shader sont indéfinies. Pour chaque fragment généré dans cette situation, une valeur différente peut être écrite dans chacun des buffers spécifiés par bufs.

ERREURS

Une erreur GL_INVALID_OPERATION est générée par glNamedFramebufferDrawBuffers si framebuffer n'est pas zéro ou le nom d'un objet framebuffer existant.

GL_INVALID_ENUM est générée si l'une des valeurs de bufs n'est pas une valeur acceptée.

GL_INVALID_ENUM est générée si l'appel API fait référence au framebuffer par défaut et que l'une des valeurs dans bufs est l'un des jetons GL_COLOR_ATTACHMENTn.

GL_INVALID_ENUM est générée si l'appel API fait référence à un objet framebuffer et que l'une des valeurs dans bufs est autre chose que GL_NONE ou l'un des jetons GL_COLOR_ATTACHMENTn.

GL_INVALID_ENUM est générée si n est inférieur à 0.

GL_INVALID_OPERATION est générée si une constante symbolique autre que GL_NONE apparaît plus d'une fois dans bufs.

GL_INVALID_OPERATION est générée si l'une des entrées dans bufs (autre que GL_NONE) indique un buffer de couleur qui n'existe pas dans le contexte GL actuel.

GL_INVALID_OPERATION est générée si une valeur dans bufs est GL_BACK, et que n n'est pas un.

GL_INVALID_VALUE est générée si n est supérieur à GL_MAX_DRAW_BUFFERS.

GETS ASSOCIÉS

glGet() avec l'argument GL_MAX_DRAW_BUFFERS

glGet() avec l'argument GL_DRAW_BUFFERi où i indique le numéro du buffer de dessin dont la valeur doit être interrogée.
