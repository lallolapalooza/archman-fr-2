NOM

glutKeyboardUpFunc - définit le rappel de relâchement de touche (keyboard up) pour la fenêtre courante.

SYNTAXE

void glutKeyboardUpFunc(void (*func)(unsigned char key,
                      int x, int y));

ARGUMENTS

func
La nouvelle fonction de rappel pour le relâchement de touche.

DESCRIPTION

glutKeyboardFunc définit le rappel de relâchement de touche (keyboard up) pour la fenêtre courante. Lorsqu'un utilisateur tape dans la fenêtre, chaque relâchement de touche correspondant à un caractère ASCII générera un rappel de relâchement de touche. Le paramètre de rappel corresponds à la touche est le caractère ASCII généré. L'état des touches modificatrices comme Shift ne peut pas être déterminé directement ; leur seul effet sera sur les données ASCII retournées. Les paramètres x et y du rappel indiquent l'emplacement de la souris dans les coordonnées relatives à la fenêtre au moment où la touche a été relâchée. Lorsqu'une nouvelle fenêtre est créée, aucun rappel de clavier n'est initialement enregistré, et les frappes de touches ASCII dans la fenêtre sont ignorées. Passer NULL à glutKeyboardFunc désactive la génération des rappels de clavier.

Pendant un rappel de relâchement de touche, glutGetModifiers peut être appelé pour déterminer l'état des touches modificatrices au moment où la frappe de touche générant le rappel s'est produite.

Pour éviter le rapport de paires de relâchement/appui de touche en raison de la répétition automatique, utilisez glutIgnoreKeyRepeat pour ignorer les frappes de touche répétées automatiquement.

Il n'y a aucune garantie que le rappel d'appui de touche corresponde exactement au même caractère ASCII que le rappel de relâchement de touche. Par exemple, l'appui peut être pour un 'b' minuscule, mais le relâchement peut rapporter un 'B' majuscule si l'état Shift a changé. Il en va de même pour les symboles et les caractères de contrôle. Le comportement précis dépend du système de fenêtrage.

Utilisez glutSpecialUpFunc pour un moyen de détecter les relâchements de touches non-ASCII.

VOIR AUSSI
