NOM

glIsProgram - Détermine si un nom correspond à un objet programme

SPÉCIFICATION C

GLboolean glIsProgram(GLuint program);

PARAMÈTRES

program

Spécifie un objet programme potentiel.

DESCRIPTION

glIsProgram renvoie GL_TRUE si program est le nom d'un objet programme précédemment créé avec glCreateProgram() et non encore supprimé avec glDeleteProgram(). Si program est zéro ou une valeur non nulle qui n'est pas le nom d'un objet programme, ou si une erreur se produit, glIsProgram renvoie GL_FALSE.

NOTES

Aucune erreur n'est générée si program n'est pas un nom d'objet programme valide.

Un objet programme marqué pour suppression avec glDeleteProgram() mais toujours utilisé comme partie de l'état de rendu actuel est toujours considéré comme un objet programme et glIsProgram renverra GL_TRUE.
