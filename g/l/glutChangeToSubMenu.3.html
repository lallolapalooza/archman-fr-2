glutChangeToSubMenu(3)

Paquet: freeglut

Licences: X11

glutChangeToSubMenu(3) freeglut glutChangeToSubMenu(3)

NOM

glutChangeToSubMenu - modifie l'élément de menu spécifié dans le menu courant en un déclencheur de sous-menu.

SYNTAXE

void glutChangeToSubMenu(int entry, char *name, int menu);

ARGUMENTS

entry
Index dans les éléments de menu du menu courant (1 est l'élément de menu le plus haut).
name
Chaîne de caractères ASCII à afficher dans l'élément de menu pour faire défiler le sous-menu.
menu
Identifiant du menu à faire défiler à partir de cet élément de sous-menu.

DESCRIPTION

glutChangeToSubMenu modifie l'élément de menu spécifié dans le menu courant en un déclencheur de sous-menu. Le paramètre entry détermine quel élément de menu doit être modifié, un étant l'élément le plus haut. entry doit être compris entre 1 et glutGet(GLUT_MENU_NUM_ITEMS) inclus. L'élément de menu à modifier n'a pas besoin d'être déjà un déclencheur de sous-menu. La chaîne name sera affichée pour le déclencheur de sous-menu nouvellement modifié. L'identifiant menu nomme le sous-menu à faire défiler à partir du déclencheur de sous-menu nouvellement ajouté.

VOIR AUSSI

glutChangeToMenuEntry, glutAddSubMenu, glutRemoveMenuItem
