NOM

glDeleteRenderbuffers - supprimer les objets de tampon de rendu

SPÉCIFICATION C

void glDeleteRenderbuffers(GLsizei n, GLuint *renderbuffers);

PARAMÈTRES

n

Spécifie le nombre d'objets de tampon de rendu à supprimer.

renderbuffers

Un pointeur vers un tableau contenant n objets de tampon de rendu à supprimer.

DESCRIPTION

glDeleteRenderbuffers supprime les n objets de tampon de rendu dont les noms sont stockés dans le tableau pointé par renderbuffers. Le nom zéro est réservé par la GL et est ignoré silencieusement s'il apparaît dans renderbuffers, tout comme les autres noms inutilisés. Une fois qu'un objet de tampon de rendu est supprimé, son nom redevient inutilisé et il n'a plus de contenu. Si un tampon de rendu actuellement lié à la cible GL_RENDERBUFFER est supprimé, c'est comme si glBindRenderbuffer() avait été exécuté avec une cible de GL_RENDERBUFFER et un nom de zéro.

Si un objet de tampon de rendu est attaché à un ou plusieurs points d'attache dans le framebuffer actuellement lié, c'est comme si glFramebufferRenderbuffer() avait été appelé, avec un renderbuffer de zéro pour chaque point d'attache auquel cette image était attachée dans le framebuffer actuellement lié. En d'autres termes, cet objet de tampon de rendu est d'abord détaché de tous les points d'attache dans le framebuffer actuellement lié. Notez que l'image du tampon de rendu n'est spécifiquement *pas* détachée des framebuffers non liés.

ERREURS

GL_INVALID_VALUE est généré si n est négatif.
