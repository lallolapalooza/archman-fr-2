NOM

glIsSampler - déterminer si un nom correspond à un objet échantillonneur

SPÉCIFICATION C

GLboolean glIsSampler(GLuint id);

PARAMÈTRES

id

Spécifie une valeur qui peut être le nom d'un objet échantillonneur.

DESCRIPTION

glIsSampler renvoie GL_TRUE si id est actuellement le nom d'un objet échantillonneur. Si id est zéro, ou est une valeur non nulle qui n'est pas actuellement le nom d'un objet échantillonneur, ou si une erreur se produit, glIsSampler renvoie GL_FALSE.

Un nom retourné par glGenSamplers() est le nom d'un objet échantillonneur.

NOTES

glIsSampler n'est disponible que si la version GL est 3.3 ou supérieure.
