NOM

glInvalidateBufferData - invalide le contenu du magasin de données d'un objet tampon

SPÉCIFICATION C

void glInvalidateBufferData(GLuint buffer);

PARAMÈTRES

buffer

Le nom d'un objet tampon dont le magasin de données doit être invalidé.

DESCRIPTION

glInvalidateBufferData invalide tout le contenu du magasin de données d'un objet tampon. Après l'invalidation, le contenu du magasin de données du tampon devient indéfini.

ERREURS

GL_INVALID_VALUE est généré si buffer n'est pas le nom d'un objet tampon existant.

GL_INVALID_OPERATION est généré si une partie de buffer est actuellement mappée.

GETS ASSOCIÉS

glGetBufferParameter() avec l'argument GL_BUFFER_SIZE
