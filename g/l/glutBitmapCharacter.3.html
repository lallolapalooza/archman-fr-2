glutBitmapCharacter(3)

Paquet: freeglut

Licences: X11

glutBitmapCharacter(3) freeglut glutBitmapCharacter(3)

NOM

glutBitmapCharacter - rend un caractère bitmap en utilisant OpenGL.

SYNTAXE

void glutBitmapCharacter(void *font, int character);

ARGUMENTS

font
Police bitmap à utiliser.
character
Caractère à rendre (pas limité à 8 bits).

DESCRIPTION

Sans utiliser de listes d'affichage, glutBitmapCharacter rend le caractère dans la police bitmap nommée. Les polices disponibles sont :

GLUT_BITMAP_8_BY_13
Une police à largeur fixe où chaque caractère tient dans un rectangle de 8 par 13 pixels. Les bitmaps exacts à utiliser sont définis par les bitmaps de glyphes X standard pour la police X nommée :

-misc-fixed-medium-r-normal--13-120-75-75-C-80-iso8859-1

GLUT_BITMAP_9_BY_15
Une police à largeur fixe où chaque caractère tient dans un rectangle de 9 par 15 pixels. Les bitmaps exacts à utiliser sont définis par les bitmaps de glyphes X standard pour la police X nommée :

-misc-fixed-medium-r-normal--15-140-75-75-C-90-iso8859-1

GLUT_BITMAP_TIMES_ROMAN_10
Une police Times Roman proportionnelle de 10 points. Les bitmaps exacts à utiliser sont définis par les bitmaps de glyphes X standard pour la police X nommée :

-adobe-times-medium-r-normal--10-100-75-75-p-54-iso8859-1

GLUT_BITMAP_TIMES_ROMAN_24
Une police Times Roman proportionnelle de 24 points. Les bitmaps exacts à utiliser sont définis par les bitmaps de glyphes X standard pour la police X nommée :

-adobe-times-medium-r-normal--24-240-75-75-p-124-iso8859-1

GLUT_BITMAP_HELVETICA_10
Une police Helvetica proportionnelle de 10 points. Les bitmaps exacts à utiliser sont définis par les bitmaps de glyphes X standard pour la police X nommée :

-adobe-helvetica-medium-r-normal--10-100-75-75-p-56-iso8859-1

GLUT_BITMAP_HELVETICA_12
Une police Helvetica proportionnelle de 12 points. Les bitmaps exacts à utiliser sont définis par les bitmaps de glyphes X standard pour la police X nommée :

-adobe-helvetica-medium-r-normal--12-120-75-75-p-67-iso8859-1

GLUT_BITMAP_HELVETICA_18
Une police Helvetica proportionnelle de 18 points. Les bitmaps exacts à utiliser sont définis par les bitmaps de glyphes X standard pour la police X nommée :

-adobe-helvetica-medium-r-normal--18-180-75-75-p-98-iso8859-1

Le rendu d'un caractère inexistant n'a aucun effet. glutBitmapCharacter configure automatiquement les modes de stockage de pixels de déballage d'OpenGL dont il a besoin et enregistre et restaure les modes précédents avant de retourner. L'appel généré à glBitmap ajustera la position raster actuelle en fonction de la largeur du caractère.

EXEMPLE

Voici une routine qui montre comment rendre une chaîne de texte ASCII avec glutBitmapCharacter :

  void
  output(int x, int y, char *string)
  {
    int len, i;
    glRasterPos2f(x, y);
    len = (int) strlen(string);
    for (i = 0; i < len; i++) {
      glutBitmapCharacter(GLUT_BITMAP_HELVETICA_18, string[i]);
    }
  }
