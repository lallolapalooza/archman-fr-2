global(n) Commandes intégrées Tcl global(n)

NOM

global - Accéder aux variables globales

SYNTAXE

global ?nom_var ...?

DESCRIPTION

Cette commande n'a aucun effet sauf si elle est exécutée dans le contexte du corps d'une procédure. Si la commande global est exécutée dans le contexte du corps d'une procédure, elle crée des variables locales liées aux variables globales correspondantes (bien que ces variables liées, comme celles créées par upvar, ne soient pas incluses dans la liste retournée par info locals).

Si nom_var contient des qualifiants d'espace de noms, le nom de la variable locale est le nom non qualifié de la variable globale, tel que déterminé par la commande namespace tail.

nom_var est toujours traitée comme le nom d'une variable, pas d'un élément de tableau. Une erreur est retournée si le nom ressemble à un élément de tableau, tel que a(b).

EXEMPLES

Cette procédure définit la variable d'espace de noms ::a::x

proc reset {} {
    global a::x
    set x 0
}

Cette procédure accumule les chaînes qui lui sont passées dans un tampon global, séparées par des sauts de ligne. Elle est utile dans les situations où vous souhaitez construire un message pièce par pièce (comme avec puts) mais envoyer ce message complet en une seule pièce (par exemple, sur une connexion ouverte avec socket ou dans le cadre d'une réponse HTTP comptée).

proc accum {chaine} {
    global accumulateur
    append accumulateur $chaine \n
}
