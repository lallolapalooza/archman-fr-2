NOM

glClearBufferSubData, glClearNamedBufferSubData - remplir tout ou partie du stockage de données d'un objet tampon avec une valeur fixe

SPÉCIFICATION C

void glClearBufferSubData(GLenum target, GLenum internalformat, GLintptr offset, GLsizeiptr size, GLenum format, GLenum type, const void * data);

void glClearNamedBufferSubData(GLuint buffer, GLenum internalformat, GLintptr offset, GLsizeiptr size, GLenum format, GLenum type, const void *data);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet tampon est lié pour glClearBufferSubData, qui doit être l'une des cibles de liaison de tampon dans le tableau suivant :
Cible de liaison de tampon Objectif
GL_ARRAY_BUFFER Attributs de sommet
GL_ATOMIC_COUNTER_BUFFER Stockage de compteurs atomiques
GL_COPY_READ_BUFFER Source de copie de tampon
GL_COPY_WRITE_BUFFER Destination de copie de tampon
GL_DISPATCH_INDIRECT_BUFFER Commandes indirectes de dispatch de calcul
GL_DRAW_INDIRECT_BUFFER Arguments de commande indirecte
GL_ELEMENT_ARRAY_BUFFER Indices de tableau de sommets
GL_PIXEL_PACK_BUFFER Cible de lecture de pixels
GL_PIXEL_UNPACK_BUFFER Source de données de texture
GL_QUERY_BUFFER Tampon de résultat de requête
GL_SHADER_STORAGE_BUFFER Stockage lecture/écriture pour les shaders
GL_TEXTURE_BUFFER Tampon de données de texture
GL_TRANSFORM_FEEDBACK_BUFFER Tampon de retour de transformation
GL_UNIFORM_BUFFER Stockage de blocs uniformes

buffer

Spécifie le nom de l'objet tampon pour glClearNamedBufferSubData.

internalformat

Le format interne avec lequel les données seront stockées dans l'objet tampon.

offset

Le décalage en unités machine de base dans le stockage de données de l'objet tampon où commencer le remplissage.

size

La taille en unités machine de base de la plage du stockage de données à remplir.

format

Le format des données en mémoire adressée par data.

type

Le type des données en mémoire adressée par data.

data

L'adresse d'un emplacement mémoire stockant les données à répliquer dans le stockage de données du tampon.

DESCRIPTION

glClearBufferSubData et glClearNamedBufferSubData remplissent une région spécifiée du stockage de données d'un objet tampon avec des données de la mémoire client.

offset et size spécifient l'étendue de la région dans le stockage de données de l'objet tampon à remplir avec des données. Les données, initialement fournies dans un format spécifié par format de type de données type, sont lues depuis l'adresse mémoire donnée par data et converties dans la représentation interne donnée par internalformat, qui doit être l'un des formats internes dimensionnés suivants :

Ces données converties sont ensuite répliquées dans toute la région spécifiée du magasin de données de l'objet tampon. Si data est NULL, alors la sous-plage du magasin de données du tampon est remplie de zéros.

ERREURS

GL_INVALID_ENUM est généré par glClearBufferSubData si target n'est pas l'une des cibles génériques de liaison de tampon.

GL_INVALID_VALUE est généré par glClearBufferSubData si aucun tampon n'est lié à target.

GL_INVALID_OPERATION est généré par glClearNamedBufferSubData si buffer n'est pas le nom d'un objet tampon existant.

GL_INVALID_ENUM est généré si internalformat n'est pas l'un des formats internes dimensionnés valides listés dans le tableau ci-dessus.

GL_INVALID_VALUE est généré si offset ou range ne sont pas des multiples du nombre d'unités machine de base par élément pour le format interne spécifié par internalformat. Cette valeur peut être calculée en multipliant le nombre de composants pour internalformat du tableau par la taille du type de base du tableau.

GL_INVALID_VALUE est généré si offset ou size est négatif, ou si $offset + size$ est supérieur à la valeur de GL_BUFFER_SIZE pour l'objet tampon.

GL_INVALID_OPERATION est généré si une partie de la plage spécifiée de l'objet tampon est mappée avec glMapBufferRange() ou glMapBuffer(), à moins qu'elle n'ait été mappée avec le bit GL_MAP_PERSISTENT_BIT défini dans les drapeaux d' glMapBufferRange accès .

GL_INVALID_VALUE est généré si format n'est pas un format valide, ou si type n'est pas un type valide.
