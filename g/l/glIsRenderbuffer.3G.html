NOM

glIsRenderbuffer - déterminer si un nom correspond à un objet renderbuffer

SPÉCIFICATION C

GLboolean glIsRenderbuffer(GLuint renderbuffer);

PARAMÈTRES

renderbuffer

Spécifie une valeur qui peut être le nom d'un objet renderbuffer.

DESCRIPTION

glIsRenderbuffer renvoie GL_TRUE si renderbuffer est actuellement le nom d'un objet renderbuffer. Si renderbuffer est zéro, ou si renderbuffer n'est pas le nom d'un objet renderbuffer, ou si une erreur se produit, glIsRenderbuffer renvoie GL_FALSE. Si renderbuffer est un nom retourné par glGenRenderbuffers(), mais qui n'a pas encore été lié par un appel à glBindRenderbuffer() ou glFramebufferRenderbuffer(), alors le nom n'est pas un objet renderbuffer et glIsRenderbuffer renvoie GL_FALSE.
