NOM

glab-config-edit - Ouvre le fichier de configuration de glab.

SYNOPSIS

glab config edit [flags]

DESCRIPTION

Ouvre le fichier de configuration de glab. La commande utilise l'ordre suivant pour choisir l'éditeur à utiliser :

1.
Champ 'glab_editor' dans le fichier de configuration
2.
Variable d'environnement 'VISUAL'
3.
Variable d'environnement 'EDITOR'

OPTIONS

-l, --local[=false] Ouvre le fichier '.git/glab-cli/config.yml' au lieu du fichier global '~/.config/glab-cli/config.yml'.

OPTIONS INHERITées DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

EXEMPLE

Ouvre le fichier de configuration avec l'éditeur par défaut
- glab config edit
Ouvre le fichier de configuration avec vim
- EDITOR=vim glab config edit
Définit vim pour être utilisé pour toutes les futures invocations de 'glab config edit'
- glab config set editor vim
- glab config edit
Ouvre le fichier de configuration local avec l'éditeur par défaut
- glab config edit -l
