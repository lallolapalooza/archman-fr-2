L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur renvoyée par glGetUniformLocation(). glProgramUniform opère sur l'objet programme spécifi

é

par program. Les commandes glProgramUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par ex., 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs à des variables uniformes définies comme int, ivec2, ivec3, ivec4, ou des tableaux de ceux-ci. Les variantes ui de cette fonction doivent être utilisées pour fournir des valeurs à des variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les variantes f doivent être utilisées pour fournir des valeurs à des v ariables uniformes de type float, vec2, vec3, vec4, ou des tableaux de ceux-ci. Les variantes i, ui ou f peuvent être utilisées pour fournir des valeurs à des variables uniformes de type bool, bvec2, bvec3, bvec4, ou des tableaux de ceux-ci. La

variable

uniforme sera définie à false si la valeur d'entrée est 0 ou 0.0f, et elle sera définie à true dans le cas contraire. Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. Elles conservent les valeurs qui leur ont été assignées par un appel

à

glProgramUniform jusqu'à ce que la prochaine opération de liaison réussie ait lieu sur l'objet programme, moment où elles sont à nouveau initialisées à 0. Les commandes glProgramUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une seule variable uniforme ou un tableau de variables uniformes. Ces commandes passent un compte et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un compte de 1 doit être utilisé si l'on modifie la valeur d'une seule variable uniforme, et un compte de 1 ou plus peut être utilisé pour modifier un tableau entier ou une partie d'un tableau. Lors du chargement n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 du tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est supérieur à la taille du tableau de variables uniformes, les valeurs pour tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre spécifié dans le nom de la commande indique le nombre de composantes pour chaque élément dans value, et il doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par ex., 1 pour float, int, b

ool ; 2 pour

vec2, ivec2, bvec2, etc.). Le type de données spécifié dans le nom de la commande doit correspondre au type de données de la variable uniforme spécifiée comme décrit précédemment pour glProgramUniform{1|2|3|4}{f|i|ui}. Pour les tableaux de variables uniformes, chaque élément du tableau est considéré comme étant du type indiqué dans le nom de

la

commande (par ex., glProgramUniform3f ou glProgramUniform3fv peuvent être utilisées pour charger un tableau de variables uniformes de type vec3). Le nombre d'éléments du tableau de variables uniformes à modifier est spécifié par count Les commandes glProgramUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3} fv sont utilisées pour modifier une matrice ou un tableau de matrices. Les nombres dans le nom de la commande sont interprétés comme la dimensionnalité de la matrice. Le nombre 3 indique une matrice 3 × 3 (c.-à-d. 9 valeurs), et le nombre 4 indique une matrice 4 × 4 (c.-à-d. 16 valeurs). La dimensionnalité des matrices non carrées est explicite, le premier nombre représentant le nombre de colonnes et le second nombre représentant le nombre de lignes. Par exemple, 2x4 indique une matice 2 × 4 avec 2 colonnes et 4 lignes (c.-à-d. 8 valeurs). Si transpose est GL_FALSE, chaque matrice est supposée être fournie dans l'ordre colonne-major. Si transpose est GL_TRUE, cha

que matrice est supposée être fournie dans l'ordre ligne-m
ajor. L'argument count indique le nombre de matrices à

passer

.

Un compte de 1 doit être utilisé si l'on modifie la valeur d'une seule matrice, et un compte supérieur à 1 peut être utilisé pour modifier un tableau de matrices. NOTES glProgramUniform1i et glProgramUniform1iv sont les seules deux
