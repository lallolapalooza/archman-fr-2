REMARQUE

S

Si une erreur est générée, aucune modification n'est apportée au contenu de params ou buffer

.

glGetQueryObject et glGetQueryBufferObject vident implicitement le pipeline GL afin que tout rendu incomplet délimité par la requête d'occlusion se termine en temps

fini.

Si plusieurs requêtes sont émises en utilisant le même objet de requête id avant d'appeler glGetQueryObject ou glGetQueryBufferObject, les résultats de la requête la plus récente seront renvoyés. Dans ce cas, lors de l'émission d'une nouvelle requête, les résultats de la requête précédente sont

jetés.

glGetQueryObjecti64v et glGetQueryObjectui64v sont disponibles uniquement si la version GL est 3.3 ou

supérieure.

GL_QUERY_RESULT_NO_WAIT est accepté pour pname uniquement si la version GL est 4.4 ou

supérieure.

La cible GL_QUERY_RESULT_BUFFER est disponible uniquement si la version GL est 4.4 ou supérieure. Sur les versions antérieures de GL, params est toujours une

adresse en m
émoire client.

NAME

glGetQueryBufferObjectiv, glGetQueryBufferObjectuiv, glGetQueryBufferObjecti64v, glGetQueryBufferObjectui64v

get query objectiv, uiv, i64v, ui64v commands

C SPECIFICATION

void glGetQueryBufferObjectiv(GLuint query, GLuint bufsize, GLenum pname, GLint *param);

void glGetQueryBufferObjectuiv(GLuint query, GLuint bufsize, GLenum pname, GLuint *param);

void glGetQueryBufferObjecti64v(GLuint query, GLuint bufsize, GLenum pname, GLint64 *param);

void glGetQueryBufferObjectui64v(GLuint query, GLuint bufsize, GLenum pname, GLuint64 *param);

PARAMETERS

query
Specifies the name of a query object.
bufsize
Specifies the size of the buffer pointed to by param.
pname
Specifies the symbolic name of a query object parameter. Accepted symbolic names are:
param
Specifies the address of a buffer into which the requested data is returned.

DESCRIPTION

These commands return information about the parameters of a query object. The results are returned in the array pointed to by param. The size of the array is specified by bufsize.

The query object is specified by query. If query is zero, the commands behave as if a query object named zero were created, and the results are returned in param as appropriate for the state requested.

The symbolic name pname determines which parameter is returned:

GL_QUERY_RESULT_AVAILABLE
Returns a single integer value indicating whether the result of the query is available. This value will be 1 if the result is available, and 0 otherwise. This query is only valid for query objects of type GL_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED_CONSERVATIVE, GL_PRIMITIVES_GENERATED, GL_TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN, GL_TIME_ELAPSED.
GL_QUERY_RESULT
Returns the result of the query. The type of the result depends on the function called. The query must have finished, and GL_QUERY_RESULT_AVAILABLE must be true. If GL_QUERY_RESULT_AVAILABLE is false, the result is undefined. This query is only valid for query objects of type GL_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED_CONSERVATIVE, GL_PRIMITIVES_GENERATED, GL_TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN.
GL_QUERY_RESULT_STRIDE
Returns the stride, in bytes, between consecutive results for a query object of type GL_TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN.

If bufsize is less than the number of values expected for the requested parameter, then the contents of param are undefined.

NOTES

If the query object has not finished, then calling glGetQueryBufferObjectiv, glGetQueryBufferObjectuiv, glGetQueryBufferObjecti64v, or glGetQueryBufferObjectui64v with GL_QUERY_RESULT as the value of pname is an error.

ERRORS

An error can be generated by any of these functions if:

GL_INVALID_OPERATION
If pname is GL_QUERY_RESULT and the query object has not finished.
GL_INVALID_OPERATION
If pname is GL_QUERY_RESULT and the query type is GL_TIME_ELAPSED.
GL_INVALID_VALUE
If query is not the name of a query object.
GL_INVALID_VALUE
If bufsize is less than the number of values that would be returned for the requested pname.
