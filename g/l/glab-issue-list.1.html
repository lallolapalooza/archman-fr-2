NOM

glab-issue-list - Lister les tickets de projet.

SYNTAXE

glab issue list [options]

DESCRIPTION

Lister les tickets de projet.

OPTIONS

-A, --all[=false] Obtenir tous les tickets.

-a, --assignee="" Filtrer les tickets par assigné.

--author="" Filtrer les tickets par auteur.

-c, --closed[=false] Obtenir seulement les tickets fermés.

-C, --confidential[=false] Filtrer par tickets confidentiels.

-e, --epic=0 Lister les tickets appartenant à une épopée donnée (nécessite --group, pas de support de pagination).

-g, --group="" Sélectionner un groupe ou un sous-groupe. Ignoré si un argument de dépôt est défini.

--in="title,description" Rechercher dans : titre, description.

-t, --issue-type="" Filtrer les tickets par leur type. Options : issue, incident, test_case.

-i, --iteration=0 Filtrer les tickets par itération.

-l, --label=[] Filtrer les tickets par étiquette. Plusieurs étiquettes peuvent être séparées par des virgules ou spécifiées en répétant le drapeau.

-m, --milestone="" Filtrer les tickets par jalon.

--not-assignee="" Filtrer les tickets qui ne sont pas assignés à.

--not-author="" Filtrer les tickets qui ne sont pas de l'auteur(s).

--not-label=[] Filtrer les tickets qui n'ont pas l'étiquette. Plusieurs étiquettes peuvent être séparées par des virgules ou spécifiées en répétant le drapeau.

--order="created_at" Ordonner les tickets par. Options d'ordre : created_at, updated_at, priority, due_date, relative_position, label_priority, milestone_due, popularity, weight.

-O, --output="text" Options : 'text' ou 'json'.

-F, --output-format="details" Options : 'details', 'ids', 'urls'.

-p, --page=1 Numéro de page.

-P, --per-page=30 Nombre d'éléments à lister par page.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/DEPOT ou GROUPE/ESPACENOM/DEPOT. Accepte aussi une URL complète ou une URL Git.

--search="" Rechercher dans les champs définis par '--in'.

--sort="desc" Retourner les tickets triés dans l'ordre asc ou desc.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab issue list --all
$ glab issue ls --all
$ glab issue list --assignee=@me
$ glab issue list --milestone release-2.0.0 --opened
