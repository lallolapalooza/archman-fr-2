NOM

glab-completion - Générer des scripts de complétion pour le shell.

SYNOPSIS

glab completion [options]

DESCRIPTION

Cette commande génère du code destiné à être sauvegardé dans un fichier ou évalué immédiatement par un shell interactif. Pour charger les complétions :

Bash

Pour charger les complétions dans votre session shell actuelle :

source <(glab completion -s bash)

Pour charger les complétions pour chaque nouvelle session, exécutez cette commande une seule fois :

Linux

glab completion -s bash > /etc/bash_completion.d/glab

macOS

glab completion -s bash > /usr/local/etc/bash_completion.d/glab

Zsh

Si la complétion du shell n'est pas déjà activée dans votre environnement, vous devez l'activer. Exécutez cette commande une seule fois :

echo "autoload -U compinit; compinit" >> ~/.zshrc

Pour charger les complétions dans votre session shell actuelle :

source <(glab completion -s zsh); compdef _glab glab

Pour charger les complétions pour chaque nouvelle session, exécutez cette commande une seule fois :

Linux

glab completion -s zsh > "${fpath[1]}/_glab"

macOS

Pour les anciennes versions de macOS, vous pourriez avoir besoin de cette commande :

glab completion -s zsh > /usr/local/share/zsh/site-functions/_glab

La version Homebrew de glab devrait installer les complétions automatiquement.

fish

Pour charger les complétions dans votre session shell actuelle :

glab completion -s fish | source

Pour charger les complétions pour chaque nouvelle session, exécutez cette commande une seule fois :

glab completion -s fish > ~/.config/fish/completions/glab.fish

PowerShell

Pour charger les complétions dans votre session shell actuelle :

glab completion -s powershell | Out-String | Invoke-Expression

Pour charger les complétions pour chaque nouvelle session, ajoutez la sortie de la commande ci-dessus à votre profil PowerShell.

Lors de l'installation de glab via un gestionnaire de paquets, cependant, vous n'aurez peut-être pas besoin de configuration supplémentaire du shell pour prendre en charge les complétions. Pour Homebrew, voir la complétion shell de brew ⟨https://docs.brew.sh/Shell-Completion⟩

OPTIONS

--no-desc[=false] Ne pas inclure la description de la complétion du shell.

-s, --shell="bash" Type de shell : bash, zsh, fish, powershell.

OPTIONS INHERITées DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.
