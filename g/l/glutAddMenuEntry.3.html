NOM

glutAddMenuEntry - ajoute une entrée de menu au bas du menu actuel.

SYNTAXE

void glutAddMenuEntry(char *name, int value);

ARGUMENTS

name
Chaîne de caractères ASCII à afficher dans l'entrée du menu.
value
Valeur à retourner à la fonction de rappel du menu si l'entrée du menu est sélectionnée.

DESCRIPTION

glutAddMenuEntry ajoute une entrée de menu au bas du menu actuel. La chaîne de caractères name sera affichée pour la nouvelle entrée de menu. Si l'entrée du menu est sélectionnée par l'utilisateur, la fonction de rappel du menu sera appelée en passant value comme paramètre de la fonction de rappel.

VOIR AUSSI

glutAddSubMenu, glutCreateMenu, glutChangeToMenuEntry, glutRemoveMenuItem
