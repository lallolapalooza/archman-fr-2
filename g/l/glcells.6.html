NOM

glcells - hack graphique de cellules croissantes

SYNTAXE

glcells [--display hôte:écran.serveur] [--window] [--root] [--window-id nombre][--install] [--visual visuel] [--delay num] [--pause num] [--maxcells num] [--radius num] [--seeds num] [--quality num] [--minfood num] [--maxfood num] [--divideage num] [--mindist num] [--keepold] [--wireframe] [--fps]

DESCRIPTION

Le programme glcells dessine des cellules qui se divisent exponentiellement, se nourrissent et finissent par mourir.

OPTIONS

glcells accepte les options suivantes :

--window
Dessiner sur une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id nombre
Dessiner sur la fenêtre spécifiée.
--install
Installer une colormap privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--pause num
Spécifie la pause à la fin de l'animation (toutes les cellules sont mortes ou la quantité maximale de cellules est atteinte). L'unité est en images, défaut 20.
--maxcells num
Spécifie le nombre maximal de cellules à l'écran (les cellules mortes comptent également, même si invisibles). Défaut : 800.
--radius num
Spécifie le rayon des cellules. Défaut : 40.
--seeds num
Spécifie le nombre de cellules au démarrage de l'animation. Défaut : 1.
--quality num
Spécifie la qualité de subdivision des sphères utilisées pour dessiner les cellules [0...5]. Défaut : 3.
--minfood num
La nourriture est distribuée aléatoirement sur l'écran (Oui, les cellules ont besoin de manger). Ce paramètre spécifie la quantité minimale de nourriture par pixel. Défaut : 5.
--maxfood num
La nourriture est distribuée aléatoirement sur l'écran (Oui, les cellules ont besoin de manger). Ce paramètre spécifie la quantité maximale de nourriture par pixel. Défaut : 20.
--divideage num
Spécifie l'âge minimum en images qu'une cellule doit avoir avant de pouvoir se diviser. Défaut : 20
--mindist num
Spécifie la distance minimale entre les cellules. Défaut : 1.4
--delay num
Temps de pause entre les images. Défaut : 20000, soit 0.02 seconde.
--fps
Affiche le taux d'images par seconde actuel, la charge CPU et le nombre de polygones.
--wireframe
Dessiner uniquement en fil de fer.
--keepold
Les cellules mortes restent à l'écran.

ENVIRONNEMENT

DISPLAY
Pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
Pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.
