NOM

glab-ssh-key-add - Ajoute une clé SSH à votre compte GitLab.

SYNTAXE

glab ssh-key add [fichier-clé] [indicateurs]

DESCRIPTION

Crée une nouvelle clé SSH appartenant à l'utilisateur authentifié actuellement.

Nécessite l'indicateur '--title'.

OPTIONS

-e, --expires-at="" La date d'expiration de la clé SSH. Utilise le format ISO 8601 : AAAA-MM-JJTHH:MM:SSZ.

-t, --title="" Titre de la nouvelle clé SSH.

-u, --usage-type="auth_and_signing" Portée d'utilisation pour la clé. Valeurs possibles : 'auth', 'signing' ou 'auth_and_signing'. Valeur par défaut : 'auth_and_signing'.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACEDNOM/DÉPÔT. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

# Lit la clé ssh depuis l'entrée standard et la télécharge.
$ glab ssh-key add -t "mon titre"
# Lit la clé ssh depuis le fichier spécifié, la télécharge et définit le type de clé ssh sur "authentification".
$ glab ssh-key add ~/.ssh/id_ed25519.pub -t "mon titre" --usage-type "auth"
