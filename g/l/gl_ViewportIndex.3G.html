GL_VIEWPORTINDEX(3G) [FIXME: manuel] GL_VIEWPORTINDEX(3G)

NOM

gl_ViewportIndex - contient l'indice de la fenêtre d'affichage à utiliser pour la transformation de fenêtre et le découpage

DÉCLARATION

// Dans les shaders de géométrie

out int gl_ViewportIndex ;

// Dans les shaders de fragment

in int gl_ViewportIndex ;

DESCRIPTION

Dans le langage de géométrie, gl_ViewportIndex est utilisé pour spécifier l'indice de la fenêtre d'affichage sur laquelle le prochain primitive émis par le shader doit être dessiné. Les primitives générées par le shader de géométrie subiront une transformation de fenêtre et un test de découpage en utilisant la transformation de fenêtre et le rectangle de découpage sélectionnés par la valeur de gl_ViewportIndex. L'indice de fenêtre utilisé proviendra de l'un des sommets de la primitive en cours de rendu. Cependant, de quel sommet provient l'indice de fenêtre est défini par l'implémentation, il est donc recommandé d'utiliser le même indice de fenêtre pour tous les sommets d'une primitive. Si un shader de géométrie n'assigne pas de valeur à gl_ViewportIndex, la transformation de fenêtre et le rectangle de découpage zéro seront utilisés. Si un shader de géométrie assigne statiquement une valeur à gl_ViewportIndex et qu'il existe un chemin à travers le shader qui n'assigne pas de valeur à gl_ViewportIndex, la valeur de gl_ViewportIndex est indéfinie pour les exécutions du shader qui empruntent ce chemin.

Dans le langage de fragment, gl_ViewportIndex aura la même valeur qui a été écrite dans la variable de sortie gl_ViewportIndex dans l'étape de géométrie. Si l'étape de géométrie n'affecte pas dynamiquement gl_ViewportIndex, la valeur de gl_ViewportIndex dans le shader de fragment sera indéfinie. Si l'étape de géométrie ne fait aucune affectation statique à gl_ViewportIndex, le shader de fragment lira zéro. Sinon, le shader de fragment lira la même valeur écrite par l'étape de géométrie, même si cette valeur est hors limites. Si un shader de fragment contient un accès statique à gl_ViewportIndex, il comptera dans la limite définie par l'implémentation pour le nombre maximum d'entrées de l'étape de fragment.
