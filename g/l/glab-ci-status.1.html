NOM

glab-ci-status - Afficher un pipeline CI/CD en cours sur la branche actuelle ou une autre branche spécifiée.

SYNOPSIS

glab ci status [options]

DESCRIPTION

Affiche un pipeline CI/CD en cours sur la branche actuelle ou une autre branche spécifiée.

OPTIONS

-b, --branch="" Vérifier l'état du pipeline pour une branche. (branche actuelle par défaut)

-c, --compact[=false] Afficher l'état au format compact.

-l, --live[=false] Afficher l'état en temps réel jusqu'à la fin du pipeline.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/REPO ou GROUPE/NAMESPACE/REPO. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab ci status --live
# Une vue plus compacte
$ glab ci status --compact
# Obtenir le pipeline pour la branche principale
$ glab ci status --branch=main
# Obtenir le pipeline pour la branche actuelle
$ glab ci status
