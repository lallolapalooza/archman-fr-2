NOM

glWaitSync - ordonne au serveur GL de bloquer jusqu'à ce que l'objet de synchronisation spécifié soit signalé

SPÉCIFICATION C

void glWaitSync(GLsync sync, GLbitfield flags, GLuint64 timeout);

PARAMÈTRES

sync

Spécifie l'objet de synchronisation sur lequel attendre.

flags

Un champ de bits contrôlant le comportement de vidage de commande. flags peut être zéro.

timeout

Spécifie le délai d'attente avant de continuer. timeout doit être GL_TIMEOUT_IGNORED.

DESCRIPTION

glWaitSync fait bloquer le serveur GL et attendre jusqu'à ce que sync soit signalé. sync est le nom d'un objet de synchronisation existant sur lequel attendre. flags et timeout ne sont actuellement pas utilisés et doivent être définis à zéro et à la valeur spéciale GL_TIMEOUT_IGNORED, respectivement[1]. glWaitSync attendra toujours au maximum un délai d'attente dépendant de l'implémentation. La durée de ce délai d'attente en nanosecondes peut être interrogée en appelant glGet() avec le paramètre GL_MAX_SERVER_WAIT_TIMEOUT. Il n'existe actuellement aucun moyen de déterminer si glWaitSync a été débloqué parce que le délai d'attente a expiré ou parce que l'objet de synchronisation sur lequel on attendait a été signalé.

Si une erreur se produit, glWaitSync ne fait pas bloquer le serveur GL.

NOTES

glWaitSync n'est disponible que si la version GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_VALUE est généré si sync n'est pas le nom d'un objet de synchronisation.

GL_INVALID_VALUE est généré si flags n'est pas zéro.

GL_INVALID_VALUE est généré si timeout n'est pas GL_TIMEOUT_IGNORED.
