NOM

glab-securefile-list - Liste les fichiers sécurisés d'un projet.

SYNOPIS

glab securefile list [flags]

DESCRIPTION

Liste les fichiers sécurisés d'un projet.

OPTIONS

-p, --page=1 Numéro de page.

-P, --per-page=30 Nombre d'éléments à lister par page.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

Liste tous les fichiers sécurisés.
- glab securefile list
Liste tous les fichiers sécurisés avec l'alias 'cmd'.
- glab securefile ls
Liste une page spécifique de fichiers sécurisés.
- glab securefile list --page 2
Liste une page spécifique de fichiers sécurisés, avec une taille de page personnalisée.
- glab securefile list --page 2 --per-page 10
