NOM

glab-ci-view - Visualiser, exécuter, suivre, journaliser et annuler les pipelines CI/CD actuels.

SYNOPSIS

glab ci view [branche/tag] [options]

DESCRIPTION

Permet de visualiser, d'exécuter, de suivre et d'annuler les tâches.

Utilisez les touches fléchées pour naviguer entre les tâches et les journaux.

  • Entrée pour basculer entre les journaux / traces d'une tâche, ou afficher un pipeline enfant. Les tâches déclenchées sont marquées d'un ».
  • Échap ou q pour fermer les journaux ou la trace, ou revenir au pipeline parent.
  • Ctrl+R, Ctrl+P pour exécuter, relancer ou jouer une tâche. Utilisez Tab ou les touches fléchées pour naviguer dans la fenêtre modale, et Entrée pour confirmer.
  • Ctrl+D pour annuler une tâche. Si la tâche sélectionnée n'est pas en cours d'exécution ou en attente, quitte la vue CI/CD.
  • Ctrl+Q pour quitter la vue CI/CD.
  • Ctrl+Espace pour suspendre l'application et afficher les journaux. Similaire à glab pipeline ci trace.
  • Prend en charge les raccourcis de style vi et les touches fléchées pour naviguer entre les tâches et les journaux.

OPTIONS

-b, --branch="" Vérifier l'état du pipeline pour une branche ou une étiquette. Par défaut, utilise la branche actuelle.

-p, --pipelineid=0 Vérifier l'état du pipeline pour un ID de pipeline spécifique.

-w, --web[=false] Ouvrir le pipeline dans un navigateur. Utilise le navigateur par défaut, ou le navigateur spécifié dans la variable BROWSER.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/RÉPERTOIRE ou GROUPE/ESPACE DE NOMS/RÉPERTOIRE. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Utilise la branche actuelle
$ glab pipeline ci view
# Obtenir le dernier pipeline sur la branche main
$ glab pipeline ci view main
# Identique au deuxième exemple
$ glab pipeline ci view -b main
# Obtenir le dernier pipeline sur la branche main du dépôt myusername/glab
$ glab pipeline ci view -b main -R myusername/glab
