NOM

glutGameModeGet - récupère les informations du mode jeu GLUT représentées par des entiers.

SYNTAXE

int glutGameModeGet(GLenum info);

ARGUMENTS

info
Nom de l'information du mode jeu à récupérer.
GLUT_GAME_MODE_ACTIVE
Non nul si le mode jeu de GLUT est actif ; nul sinon. Le mode jeu n'est pas actif initialement. Le mode jeu devient actif lorsque glutEnterGameMode est appelé. Le mode jeu devient inactif lorsque glutLeaveGameMode est appelé.
GLUT_GAME_MODE_POSSIBLE
Non nul si la chaîne de mode jeu spécifiée en dernier à glutGameModeString est une configuration de mode jeu possible ; nul sinon. Être "possible" ne garantit pas que si le mode jeu est entré avec glutEnterGameMode que les paramètres d'affichage seront réellement modifiés. GLUT_GAME_MODE_DISPLAY_CHANGED doit être appelé une fois le mode jeu entré pour déterminer si le mode d'affichage a effectivement été modifié.
GLUT_GAME_MODE_WIDTH
Largeur en pixels de l'écran lorsque le mode jeu est activé.
GLUT_GAME_MODE_HEIGHT
Hauteur en pixels de l'écran lorsque le mode jeu est activé.
GLUT_GAME_MODE_PIXEL_DEPTH
Profondeur de pixels de l'écran lorsque le mode jeu est activé.
GLUT_GAME_MODE_REFRESH_RATE
Taux de rafraîchissement de l'écran en cycles par seconde (hertz) lorsque le mode jeu est activé. Zéro est retourné si le taux de rafraîchissement est inconnu ou ne peut pas être interrogé.
GLUT_GAME_MODE_DISPLAY_CHANGED
Non nul si l'entrée en mode jeu a effectivement modifié les paramètres d'affichage. Si la chaîne de mode jeu n'est pas possible ou si le mode d'affichage n'a pas pu être modifié pour une autre raison, zéro est retourné.

DESCRIPTION

glutGameModeGet récupère les informations du mode jeu GLUT représentées par des entiers. Le paramètre info détermine quel type d'information du mode jeu retourner. Demander des informations du mode jeu pour un nom d'information de mode jeu GLUT invalide retourne moins un.

VOIR AUSSI

glutGet, glutDeviceGet, glutLayerGet, glutGameModeString, glutEnterGameMode, glutLeaveGameMode
