NOM

glReadBuffer, glNamedFramebufferReadBuffer - sélectionner une source de tampon de couleur pour les pixels

SPÉCIFICATION C

void glReadBuffer(GLenummode);

void glNamedFramebufferReadBuffer(GLuintframebuffer, GLenummode);

PARAMÈTRES

framebuffer

Spécifie le nom de l'objet framebuffer pour la fonction glNamedFramebufferReadBuffer .

mode

Spécifie un tampon de couleur. Les valeurs acceptées sont GL_FRONT_LEFT, GL_FRONT_RIGHT, GL_BACK_LEFT, GL_BACK_RIGHT, GL_FRONT, GL_BACK, GL_LEFT, GL_RIGHT, et les constantes GL_COLOR_ATTACHMENTi.

DESCRIPTION

glReadBuffer spécifie un tampon de couleur comme source pour les commandes suivantes : glReadPixels(), glCopyTexImage1D(), glCopyTexImage2D(), glCopyTexSubImage1D(), glCopyTexSubImage2D(), et glCopyTexSubImage3D(). mode accepte l'une des douze valeurs prédéfinies ou plus. Dans un système entièrement configuré, GL_FRONT, GL_LEFT, et GL_FRONT_LEFT désignent tous le tampon avant gauche, GL_FRONT_RIGHT et GL_RIGHT désignent le tampon avant droit, et GL_BACK_LEFT et GL_BACK désignent le tampon arrière gauche. De plus, les constantes GL_COLOR_ATTACHMENTi peuvent être utilisées pour indiquer le ième attachement de couleur où i varie de zéro à la valeur de GL_MAX_COLOR_ATTACHMENTS moins un.

Les configurations tampon double non stéréoscopiques n'ont qu'un tampon avant gauche et un tampon arrière gauche. Les configurations tampon simple ont un tampon avant gauche et un tampon avant droit si stéréoscopiques, et seulement un tampon avant gauche si non stéréoscopiques. C'est une erreur de spécifier un tampon inexistant à glReadBuffer.

mode est initialement GL_FRONT dans les configurations tampon simple et GL_BACK dans les configurations tampon double.

Pour glReadBuffer, l'objet framebuffer cible est celui lié à GL_READ_FRAMEBUFFER. Pour glNamedFramebufferReadBuffer, framebuffer doit être soit zéro ou le nom de l'objet framebuffer cible. Si framebuffer est zéro, alors le framebuffer de lecture par défaut est affecté.

ERREUR

GL_INVALID_ENUM est généré si mode n'est pas l'une des douze valeurs (ou plus) acceptées.

GL_INVALID_OPERATION est généré si mode spécifie un tampon qui n'existe pas.

GL_INVALID_OPERATION est généré par glNamedFramebufferReadBuffer si framebuffer n'est pas zéro ou le nom d'un objet framebuffer existant.

ACCÈS ASSOCIÉS

glGet() avec l'argument GL_READ_BUFFER
