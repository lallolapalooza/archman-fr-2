NOM

glab-issue-delete - Supprime un ticket.

SYNOPSIS

glab issue delete [flags]

DESCRIPTION

Supprime un ticket.

OPTIONS INHERITÉS DES COMMANDES PARENTALES

-h, --help[=false] Affiche l'aide de cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE DE NOMS/DÉPÔT. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

$ glab issue delete 123
$ glab issue del 123
$ glab issue delete https://gitlab.com/profclems/glab/-/issues/123
