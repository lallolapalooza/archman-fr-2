NOM

glPointSize - spécifier le diamètre des points rasterisés

SPÉCIFICATION EN C

void glPointSize(GLfloat size);

PARAMÈTRES

size

Spécifie le diamètre des points rasterisés. La valeur initiale est 1.

DESCRIPTION

glPointSize spécifie le diamètre des points rasterisés. Si le mode de taille de point est désactivé (voir glEnable() avec le paramètre GL_PROGRAM_POINT_SIZE), cette valeur sera utilisée pour rasteriser les points. Sinon, la valeur écrite dans la variable intégrée du langage de ombrage gl_PointSize sera utilisée.

NOTES

La taille de point spécifiée par glPointSize est toujours retournée lorsque GL_POINT_SIZE est interrogée. Le plafonnement et l'arrondi pour les points n'ont aucun effet sur la valeur spécifiée.

ERREURS

GL_INVALID_VALUE est générée si size est inférieur ou égal à 0.

GETS ASSOCIÉS

glGet() avec l'argument GL_POINT_SIZE_RANGE

glGet() avec l'argument GL_POINT_SIZE_GRANULARITY

glGet() avec l'argument GL_POINT_SIZE

glGet() avec l'argument GL_POINT_FADE_THRESHOLD_SIZE

glIsEnabled() avec l'argument GL_PROGRAM_POINT_SIZE
