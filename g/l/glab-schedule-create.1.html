NOM

glab-schedule-create - Planifier un nouveau pipeline.

SYNTAXE

glab schedule create [options]

DESCRIPTION

Planifier un nouveau pipeline.

OPTIONS

--active[=true] Indique si le planning est actif ou non.

--cron="" Modèle d'intervalle Cron.

--cronTimeZone="UTC" Fuseau horaire Cron.

--description="" Description du planning.

--ref="" Branche ou tag cible.

--variable=[] Transmettre des variables au planning au format :. Répétez l'indicateur pour plusieurs variables.

OPTIONS INHERITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE DE NOMS/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Créer un pipeline planifié qui s'exécute toutes les heures
$ glab schedule create --cron "0 * * * *" --description "Décrivez votre pipeline ici" --ref "main" --variable "foo:bar" --variable "baz:baz"
> Planning créé
