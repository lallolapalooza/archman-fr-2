NOM

glmark2-wayland - Suite de tests de performance pour OpenGL (ES) 2.0

SYNTAXE

glmark2-wayland [options]

DESCRIPTION

glmark2-wayland est un benchmark pour OpenGL (ES) 2.0. Il n'utilise que le sous-ensemble de l'API OpenGL 2.0 compatible avec OpenGL ES 2.0.

OPTIONS

-b, --benchmark BENCH
Un test de performance à exécuter : 'scene(:opt1=val1)*' (l'option peut être utilisée plusieurs fois)
-f, --benchmark-file FICHIER
Charger les tests de performance à exécuter depuis un fichier contenant une liste de descriptions de tests (une par ligne) (l'option peut être utilisée plusieurs fois)
--validate
Exécuter un test de validation rapide de la sortie au lieu d'exécuter les tests de performance
--data-path CHEMIN
Chemin vers les modèles, shaders et textures de glmark2
--frame-end METHODE
Comment terminer une image [default,none,swap,finish,readpixels]
--swap-mode MODE
Comment échanger une image, tous les modes pris en charge uniquement dans le type DRM, 'fifo' disponible dans tous les types pour forcer la synchronisation verticale [default,immediate,mailbox,fifo]
--off-screen
Rendu sur une surface hors écran
--visual-config
La configuration visuelle à utiliser pour la cible de rendu : ´id=ID:red=R:green=G:blue=B:alpha=A:buffer=BUF:stencil=STENCIL:samples=SAMPLES'. Les paramètres peuvent être définis dans n'importe quel ordre, et tous les paramètres omis supposent une valeur par défaut de '0' (id, stencil, samples) ou '1' (red, green, blue, alpha, buffer). Si 'id' est défini à une valeur non nulle, tous les autres paramètres sont ignorés
--reuse-context
Utiliser un seul contexte pour toutes les scènes (par défaut, chaque scène obtient son propre contexte)
-s, --size LxH
Taille de la fenêtre de sortie (défaut : 800x600)
--fullscreen
Exécuter en mode plein écran (équivalent à --size -1x-1)
--results RESULTATS
Les types de résultats à rapporter pour chaque test de performance, sous forme de liste séparée par ':' [fps,cpu,shader]
--results-file FICHIER-RESULTATS
Le fichier dans lequel enregistrer les résultats, au format déterminé par l'extension du fichier [csv,xml]
--winsys-options OPTS
Une liste de paires 'opt=valeur' pour les options spécifiques au système de fenêtrage, séparées par ':'
-l, --list-scenes
Afficher des informations sur les scènes disponibles et leurs options
--show-all-options
Afficher toutes les valeurs d'options de scène utilisées pour les tests de performance (seules les options explicitement définies sont affichées par défaut)
--run-forever
Exécuter indéfiniment, en bouclant du dernier test de performance au premier
--annotate
Annoter les tests de performance avec des informations à l'écran (identique à -b :show-fps=true:title=#info#)
-d, --debug
Afficher les messages de débogage
--version
Afficher la version du programme
-h, --help
Afficher l'aide

BENCHMARKS

glmark2-wayland offre une suite de scènes qui peuvent être utilisées pour mesurer de nombreux aspects des performances OpenGL (ES) 2.0. La manière dont chaque scène est rendue est configurable via un ensemble d'options. Pour obtenir les scènes disponibles et leurs options acceptables, vous pouvez utiliser l'option de ligne de commande -l, --list-scenes.

Dans glmark2-wayland, un test de performance est défini comme une scène plus un ensemble de valeurs d'options. Vous pouvez spécifier la liste et l'ordre des tests de performance à exécuter en utilisant l'option de ligne de commande -b, --benchmark (éventuellement plusieurs fois). Si aucun test de performance n'est spécifié, un ensemble par défaut est utilisé. Si une option de test de performance n'est pas spécifiée, elle prend sa valeur par défaut (listée avec -l, --list-scenes).

À titre spécial, une chaîne de description de test de performance est autorisée à ne pas contenir de nom de scène (c'est-à-dire à commencer par ':'). Dans ce cas, toutes les valeurs d'options spécifiées sont utilisées comme valeurs par défaut pour les tests de performance qui suivent cette chaîne de description.

EXEMPLES

Pour exécuter les tests de performance par défaut :

glmark2-wayland

Pour exécuter un test de performance utilisant la scène 'shading' avec une 'duration' de '5.0' secondes et
un 'shading' de type 'phong' :

glmark2-wayland -b shading:duration=5.0:shading=phong

Pour exécuter une série de tests de performance, utilisez l'option de ligne de commande -b, --benchmark plusieurs fois :

glmark2-wayland -b shading:duration=5.0 -b build:use-vbo=false -b texture

Pour définir des valeurs d'options par défaut pour les tests de performance :

glmark2-wayland -b :duration=2.0 -b shading -b build -b :duration=5.0 -b texture
