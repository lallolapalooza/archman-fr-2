DESCRIPTIO

N

La fonction glob() recherche tous les chemins correspondant au motif selon les règles utilisées par le shell (voir glob(7)). Aucune expansion de tilde ni substitution de paramètre n'est effectuée ; si vous le souhaitez, utilisez wordexp

(3).

La fonction globfree() libère le stockage alloué dynamiquement lors d'un appel précédent à glob(

).

Les résultats d'un appel à glob() sont stockés dans la structure pointée par pglob. Cette structure est de type glob_t (déclarée dans <glob.h>) et inclut les éléments suivants définis par POSIX.2 (d'autres peuvent être présents en tant qu'extension)

: 


typedef struct {
    size_t   gl_pathc;    /* Nombre de chemins correspondants jusqu'à présent */
    char   **gl_pathv;    /* Liste des chemins correspondants.  */
    size_t   gl_offs;     /* Emplacements à réserver dans gl_pathv.  */
}
glob_t;

Les résultats sont stockés dans un stockage alloué

dynamiquement.

L'argument flags est constitué du OU binaire de zéro ou plusieurs des constantes symboliques suivantes, qui modifient le comportement de glob()

:
GLOB_E
RR
Retourner en cas d'erreur de lecture (par exemple parce qu'un répertoire n'a pas la permission de lecture). Par défaut, glob() tente de continuer malgré les erreurs, en lisant tous les répertoires qu'il
peut.
GLOB_MA
RK
Ajouter une barre oblique à chaque chemin correspondant à un
répertoire.
GLOB_NOSO
RT
Ne pas trier les chemins retournés. La seule raison de le faire est d'économiser du temps de traitement. Par défaut, les chemins retournés sont
triés.
GLOB_DOOF
FS
Réserver pglob->gl_offs emplacements au début de la liste de chaînes dans pglob->pathv. Les emplacements réservés contiennent des pointeurs
nuls.
GLOB_NOCHE
CK
Si aucun motif ne correspond, retourner le motif original. Par défaut, glob() retourne GLOB_NOMATCH s'il n'y a aucune
correspondance.
GLOB_APPE
ND
Ajouter les résultats de cet appel au vecteur de résultats retourné par un appel précédent à glob(). Ne pas définir ce drapeau lors de la première invocation de glob(
).
GLOB_NOESCA
PE
Ne pas autoriser la barre oblique inverse ('\') comme caractère d'échappement. Normal
ement, une barre oblique inverse peut être utilisée pour protéger le caractère suivan
t, offrant un mécanisme pour désactiver la signification spéciale des métacaractères.

flags peut également inclure l'un des éléments suivants, qui sont des extensions GNU et non définies par POSIX.2

:
GLOB_PERI
OD
Permettre à un point initial d'être apparié par les métacaractères. Par défaut, les métacaractères ne peuvent pas apparier un point
initial.
GLOB_ALTDIRF
UNC
Utiliser les fonctions alternatives pglob->gl_closedir, pglob->gl_readdir, pglob->gl_opendir, pglob->gl_lstat et pglob->gl_stat pour l'accès au système de fichiers au lieu des fonctions de bibliothèque
normales.
GLOB_BRA
CE
Développer les expressions à accolades de style csh(1) de la forme {a,b}. Les expressions à accolades peuvent être imbriquées. Ainsi, par exemple, spécifier le motif "{foo/{,cat,dog},bar}" retournerait les mêmes résultats que quatre appels glob() séparés utilisant les chaînes : "foo/", "foo/cat", "foo/dog" et
"bar".
GLOB_NOMAG
IC
Si le motif ne contient aucun métacaractère, il doit être retourné comme mot correspondant unique, même s'il n'existe pas de fichier portant ce
nom.
GLOB_TIL
DE
Effectuer l'expansion de tilde. Si un tilde ('~') est le seul caractère du motif, ou si un tilde initial est immédiatement suivi d'une barre oblique ('/'), le répertoire personnel de l'appelant est substitué au tilde. Si un tilde initial est suivi d'un nom d'utilisateur (par exemple, "~andrea/bin"), le tilde et le nom d'utilisateur sont substitués par le répertoire personnel de cet utilisateur. Si le nom d'utilisateur est invalide, ou si le répertoire personnel ne peut pas être déterminé, aucune substitution n'est
effectuée.
GLOB_TILDE_CH
ECK
Cela fournit un comportement similaire à celui de GLOB_TILDE. La différence est que si le nom d'utilisateur est invalide, ou si le répertoire personnel ne peut pas être déterminé, alors au lieu d'utiliser le motif lui-même comme nom, glob() retourne GLOB_NOMATCH pour indiquer une
erreur.
GLOB_ONLYD
IR
C'est un indice pour glob() indiquant que l'appelant s'intéresse uniquement aux répertoires correspondant au motif. Si l'implémentation peut facilement déterminer le type de fichier, les fichiers non-répertoires ne sont pas retournés à l'appelan
t. Cependant, l'appelant doit quand même vérifier que les fichiers retournés sont des répertoires. (Le but de ce
drapeau est simplement d'optimiser les performances lorsque l'appelant s'intéresse uniquement aux répertoires.)

Si errfunc n'est pas NULL, il sera appelé en cas d'erreur avec les arguments epath, un pointeur vers le chemin qui a échoué, et eerrno, la valeur de errno telle que retournée par l'un des appels à opendir(3), readdir(3) ou stat(2). Si errfunc retourne une valeur non nulle, ou si GLOB_ERR est défini, glob() se terminera après l'appel à errfunc

.

Au retour réussi, pglob->gl_pathc contient le nombre de chemins correspondants et pglob->gl_pathv contient un pointeur vers la liste des pointeurs vers les chemins correspondants. La liste des pointeurs est terminée par un pointeur

nul.

Il est possible d'appeler glob() plusieurs fois. Dans ce cas, le drapeau GLOB_APPEND doit être défini dans flags lors des invocations

suivantes.

En tant qu'extension GNU, pglob->gl_flags est défini aux drapeaux spécifiés, combinés par OU avec GLOB_MAGCHAR si des métaca

ractères ont
été trouvés.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, POSIX.2.

NOTES

Les éléments de la structure gl_pathc et gl_offs sont déclarés comme size_t dans glibc 2.1, comme ils devraient l'être selon POSIX.2, mais sont déclarés comme int dans glibc 2.0.

BOGUES

La fonction glob() peut échouer en raison de l'échec d'appels de fonctions sous-jacentes, tels que malloc(3) ou opendir(3). Ceux-ci stockeront leur code d'erreur dans errno.

EXEMPLES

Un exemple d'utilisation est le code suivant, qui simule la saisie


ls -l *.c ../*.c

dans le shell :


glob_t globbuf;
globbuf.gl_offs = 2;
glob("*.c", GLOB_DOOFFS, NULL, &globbuf);
glob("../*.c", GLOB_DOOFFS | GLOB_APPEND, NULL, &globbuf);
globbuf.gl_pathv[0] = "ls";
globbuf.gl_pathv[1] = "-l";
execvp("ls", &globbuf.gl_pathv[0]);
