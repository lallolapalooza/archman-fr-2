GLSTENCILFUNCSEPARAT(3G) [FIXME: manuel] GLSTENCILFUNCSEPARAT(3G)

NOM

glStencilFuncSeparate - définit la fonction et/ou la valeur de référence avant et/ou arrière pour le test de stencil

SPÉCIFICATION C

void glStencilFuncSeparate(GLenumface, GLenumfunc, GLintref, GLuintmask);

PARAMÈTRES

face

Spécifie si l'état du stencil avant et/ou arrière est mis à jour. Trois constantes symboliques sont valides : GL_FRONT, GL_BACK, et GL_FRONT_AND_BACK.

func

Spécifie la fonction de test. Huit constantes symboliques sont valides : GL_NEVER, GL_LESS, GL_LEQUAL, GL_GREATER, GL_GEQUAL, GL_EQUAL, GL_NOTEQUAL, et GL_ALWAYS. La valeur initiale est GL_ALWAYS.

ref

Spécifie la valeur de référence pour le test de stencil. ref est limitée à l'intervalle 0 à 2 n - 1, où n est le nombre de plans de bits dans le tampon de stencil. La valeur initiale est 0.

mask

Spécifie un masque qui est combiné par ET logique (AND) avec la valeur de référence et la valeur de stencil stockée lorsque le test est effectué. La valeur initiale est tous les bits à 1.

DESCRIPTION

Le stencil, comme le tampon de profondeur, permet et désactive le dessin au niveau du pixel. Vous dessinez dans les plans de stencil à l'aide des primitives de dessin OpenGL, puis vous rendez de la géométrie et des images, en utilisant les plans de stencil pour masquer des portions de l'écran. Le stencil est généralement utilisé dans des algorithmes de rendu multi-passes pour obtenir des effets spéciaux, tels que les décalques, le contourage et le rendu de géométrie solide constructive.

Le test de stencil élimine conditionnellement un pixel en fonction du résultat d'une comparaison entre la valeur de référence et la valeur dans le tampon de stencil. Pour activer et désactiver le test, appelez glEnable() et

glDisable avec l'argument GL_STENCIL_TEST. Pour spécifier des actions basées sur le résultat du test de stencil, appelez glStencilOp() ou glStencilOpSeparate().

Il peut y avoir deux ensembles distincts de paramètres func, ref, et mask ; l'un affecte les polygones orientés vers l'arrière, et l'autre affecte les polygones orientés vers l'avant ainsi que les autres primitives non polygonales. glStencilFunc() définit l'état du stencil avant et arrière aux mêmes valeurs, comme si glStencilFuncSeparate() était appelé avec face défini à GL_FRONT_AND_BACK.

func est une constante symbolique qui détermine la fonction de comparaison du stencil. Elle accepte l'une des huit valeurs, montrées dans la liste suivante. ref est une valeur de référence entière utilisée dans la comparaison du stencil. Elle est limitée à l'intervalle 0 à 2 n - 1, où n est le nombre de plans de bits dans le tampon de stencil. mask est combiné par ET logique (AND) avec la valeur de référence et la valeur de stencil stockée, les valeurs combinées participant à la comparaison.

Si stencil représente la valeur stockée dans l'emplacement de tampon de stencil correspondant, la liste suivante montre l'effet de chaque fonction de comparaison qui peut être spécifiée par func. Ce n'est que si la comparaison réussit que le pixel est transmis à l'étape suivante du processus de rasterisation (voir glStencilOp()). Tous les tests traitent les valeurs stencil comme des entiers non signés dans l'intervalle 0 à 2 n - 1, où n est le nombre de plans de bits dans le tampon de stencil.

Les valeurs suivantes sont acceptées par func:

GL_NEVER

Échoue toujours.

GL_LESS

Passe si ( ref & mask ) < ( stencil & mask ).

GL_LEQUAL

Passe si ( ref & mask ) <= ( stencil & mask ).

GL_GREATER

Passe si ( ref & mask ) > ( stencil & mask ).

GL_GEQUAL

Passe si ( ref & mask ) >= ( stencil & mask ).

GL_EQUAL

Passe si ( ref & mask ) = ( stencil & mask ).

GL_NOTEQUAL

Passe si ( ref & mask ) != ( stencil & mask ).

GL_ALWAYS

Passe toujours.

REMARQUES

Initialement, le test de stencil est désactivé. S'il n'y a pas de tampon de stencil, aucune modification du stencil ne peut se produire et c'est comme si le test de stencil passait toujours.

ERREURS

GL_INVALID_ENUM est généré si func n'est pas l'une des huit valeurs acceptées.

REQUÊTES ASSOCIÉES

glGet() avec l'argument GL_STENCIL_FUNC, GL_STENCIL_VALUE_MASK, GL_STENCIL_REF, GL_STENCIL_BACK_FUNC, GL_STENCIL_BACK_VALUE_MASK, GL_STENCIL_BACK_REF, ou GL_STENCIL_BITS

glIsEnabled() avec l'argument GL_STENCIL_TEST
