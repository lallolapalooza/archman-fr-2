NOM

glDeleteSamplers - supprime des objets échantillonneurs nommés

SPÉCIFICATION C

void glDeleteSamplers(GLsizei n, const GLuint * samplers);

PARAMÈTRES

n

Spécifie le nombre d'objets échantillonneurs à supprimer.

samplers

Spécifie un tableau d'objets échantillonneurs à supprimer.

DESCRIPTION

glDeleteSamplers supprime n objets échantillonneurs nommés par les éléments du tableau samplers. Après la suppression d'un objet échantillonneur, son nom redevient inutilisé. Si un objet échantillonneur actuellement lié à une unité d'échantillonneur est supprimé, c'est comme si glBindSampler() était appelé avec l'unité définie sur l'unité à laquelle l'échantillonneur est lié et l'échantillonneur à zéro. Les noms inutilisés dans samplers sont ignorés silencieusement, tout comme le nom réservé zéro.

NOTES

glDeleteSamplers n'est disponible que si la version de GL est 3.3 ou supérieure.

ERREURS

GL_INVALID_VALUE est généré si n est négatif.

GETS ASSOCIÉS

glIsSampler()
