NOM

glab-issue-create - Créer un ticket.

SYNTAXE

glab issue create [options]

DESCRIPTION

Créer un ticket.

OPTIONS

-a, --assignee=[] Assigner le ticket à des personnes par leur nom d'utilisateur. Plusieurs noms d'utilisateur peuvent être séparés par des virgules ou spécifiés en répétant l'option.

-c, --confidential[=false] Définir un ticket comme confidentiel. (par défaut false)

-d, --description="" Description du ticket.

--due-date="" Une date au format 'YYYY-MM-DD'.

--epic=0 ID de l'épopée à laquelle ajouter le ticket.

-l, --label=[] Ajouter une étiquette par nom. Plusieurs étiquettes peuvent être séparées par des virgules ou spécifiées en répétant l'option.

--link-type="relates_to" Type du lien du ticket

--linked-issues=[] Les IID des tickets auxquels ce ticket est lié. Plusieurs IID peuvent être séparés par des virgules ou spécifiés en répétant l'option.

--linked-mr=0 L'IID d'une demande de fusion dans laquelle résoudre tous les tickets.

-m, --milestone="" L'identifiant global ou le titre d'une étape clé à assigner.

--no-editor[=false] Ne pas ouvrir d'éditeur pour saisir une description. Si défini à true, utilise une invite. (par défaut false)

--recover[=false] Sauvegarder les options dans un fichier si la création du ticket échoue. Si le fichier existe, les options seront chargées depuis le fichier de récupération. (EXPÉRIMENTAL)

-e, --time-estimate="" Définir l'estimation de temps pour le ticket.

-s, --time-spent="" Définir le temps passé sur le ticket.

-t, --title="" Titre du ticket.

--web[=false] Continuer la création du ticket avec l'interface web.

-w, --weight=0 Poids du ticket. Les valeurs valides sont supérieures ou égales à 0.

-y, --yes[=false] Ne pas demander de confirmation pour soumettre le ticket.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide de cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/REPO ou GROUPE/NAMESPACE/REPO. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab issue create
$ glab issue new
$ glab issue create -m release-2.0.0 -t "nous avons besoin de cette fonctionnalité" --label important
$ glab issue new -t "Correction CVE-AAAA-XXXX" -l security --linked-mr 123
$ glab issue create -m release-1.0.1 -t "correction de sécurité" --label security --web --recover
