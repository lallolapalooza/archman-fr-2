NOM

glDeleteVertexArrays - supprimer des objets de tableau de sommets

SPÉCIFICATION C

void glDeleteVertexArrays(GLsizei n, const GLuint *arrays);

PARAMÈTRES

n

Spécifie le nombre d'objets de tableau de sommets à supprimer.

arrays

Spécifie l'adresse d'un tableau contenant les n noms des objets à supprimer.

DESCRIPTION

glDeleteVertexArrays supprime n objets de tableau de sommets dont les noms sont stockés dans le tableau pointé par arrays. Une fois qu'un objet de tableau de sommets est supprimé, il n'a plus de contenu et son nom redevient inutilisé. Si un objet de tableau de sommets actuellement lié est supprimé, la liaison pour cet objet revient à zéro et le tableau de sommets par défaut devient courant. Les noms inutilisés dans arrays sont silencieusement ignorés, tout comme la valeur zéro.

ERREURS

GL_INVALID_VALUE est générée si n est négatif.
