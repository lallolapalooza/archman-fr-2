NOM

glGetFragDataLocation - interroger les liaisons des numéros de couleur aux variables de sortie variables définies par l'utilisateur

SPÉCIFICATION C

GLint glGetFragDataLocation(GLuint program, const char * name);

PARAMÈTRES

program

Le nom du programme contenant la variable de sortie variable dont il faut interroger la liaison

name

Le nom de la variable de sortie variable définie par l'utilisateur dont il faut interroger la liaison

DESCRIPTION

glGetFragDataLocation récupère la liaison du numéro de couleur attribué à la variable de sortie variable définie par l'utilisateur name pour le programme program. program doit avoir été précédemment lié. name doit être une chaîne terminée par un caractère nul. Si name n'est pas le nom d'une variable de fragment de sortie active définie par l'utilisateur dans program, -1 sera retourné.

ERREURS

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un objet programme.
