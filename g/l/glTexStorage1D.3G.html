NOM

glTexStorage1D, glTextureStorage1D - spécifier simultanément le stockage pour tous les niveaux d'une texture unidimensionnelle

SPÉCIFICATION C

void glTexStorage1D(GLenum target, GLsizei levels, GLenum internalformat, GLsizei width);

void glTextureStorage1D(GLuint texture, GLsizei levels, GLenum internalformat, GLsizei width);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet texture est lié pour glTexStorage1D. Doit être l'un des GL_TEXTURE_1D ou GL_PROXY_TEXTURE_1D.

texture

Spécifie le nom de l'objet texture pour glTextureStorage1D. La cible effective de texture doit être l'une des valeurs de target valides non proxy mentionnées ci-dessus.

levels

Spécifie le nombre de niveaux de texture.

internalformat

Spécifie le format interne redimensionné à utiliser pour stocker les données de l'image de texture.

width

Spécifie la largeur de la texture, en texels.

DESCRIPTION

glTexStorage1D et glTextureStorage1D spécifient les exigences de stockage pour tous les niveaux d'une texture unidimensionnelle simultanément. Une fois qu'une texture est spécifiée avec cette commande, le format et les dimensions de tous les niveaux deviennent immuables, sauf s'il s'agit d'une texture proxy. Le contenu de l'image peut toujours être modifié, cependant, ses exigences de stockage ne peuvent pas changer. Une telle texture est appelée une texture à format immuable.

Appeler glTexStorage1D est équivalent, en l'absence d'erreurs, à exécuter le pseudo-code suivant :

    for (i = 0; i < levels; i++) {
        glTexImage1D(target, i, internalformat, width, 0, format, type, NULL);
        width = max(1, (width / 2));
    }

Appeler glTextureStorage1D est équivalent au pseudo-code ci-dessus, où target est la cible effective de texture et c'est comme si texture était lié à target aux fins de glTexImage1D.

Comme aucune donnée de texture n'est fournie, les valeurs utilisées dans le pseudo-code pour format et type sont sans importance et peuvent être considérées comme n'importe quelles valeurs légales pour l'énumérateur internalformat choisi. internalformat doit être l'un des formats internes redimensionnés indiqués dans le Tableau 1 ci-dessous, l'un des formats redimensionnés de composante de profondeur GL_DEPTH_COMPONENT32F, GL_DEPTH_COMPONENT24, ou GL_DEPTH_COMPONENT16, l'un des formats combinés profondeur-stencil, GL_DEPTH32F_STENCIL8, ou GL_DEPTH24_STENCIL8, ou le format stencil uniquement, GL_STENCIL_INDEX8. En cas de succès, la valeur de GL_TEXTURE_IMMUTABLE_FORMAT devient GL_TRUE. La valeur de GL_TEXTURE_IMMUTABLE_FORMAT peut être découverte en appelant glGetTexParameter() avec pname défini sur GL_TEXTURE_IMMUTABLE_FORMAT. Aucune modification ultérieure des dimensions ou du format de l'objet texture ne peut être effectuée. L'utilisation de toute commande susceptible de modifier les dimensions ou le format de l'objet texture (telle que glTexImage1D() ou un autre appel à glTexStorage1D) entraînera la génération d'une erreur GL_INVALID_OPERATION, même si cela ne modifierait pas, en fait, les dimensions ou le format de l'objet.
