NOM

glCreateShader - Crée un objet shader

SPÉCIFICATION C

GLuint glCreateShader(GLenum shaderType);

PARAMÈTRES

shaderType

Spécifie le type de shader à créer. Doit être l'une des valeurs suivantes : GL_COMPUTE_SHADER, GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER, ou GL_FRAGMENT_SHADER.

DESCRIPTION

glCreateShader crée un objet shader vide et renvoie une valeur non nulle par laquelle il peut être référencé. Un objet shader est utilisé pour conserver les chaînes de code source qui définissent un shader. shaderType indique le type de shader à créer. Cinq types de shaders sont supportés. Un shader de type GL_COMPUTE_SHADER est un shader destiné à s'exécuter sur le processeur de calcul programmable. Un shader de type GL_VERTEX_SHADER est un shader destiné à s'exécuter sur le processeur de sommets programmable. Un shader de type GL_TESS_CONTROL_SHADER est un shader destiné à s'exécuter sur le processeur de tessellation programmable à l'étape de contrôle. Un shader de type GL_TESS_EVALUATION_SHADER est un shader destiné à s'exécuter sur le processeur de tessellation programmable à l'étape d'évaluation. Un shader de type GL_GEOMETRY_SHADER est un shader destiné à s'exécuter sur le processeur géométrique programmable. Un shader de type GL_FRAGMENT_SHADER est un shader destiné à s'exécuter sur le processeur de fragments programmable.

Lors de sa création, le paramètre GL_SHADER_TYPE de l'objet shader est défini sur GL_COMPUTE_SHADER, GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER, en fonction de la valeur de shaderType.

NOTES

Comme les objets tampons et textures, l'espace de noms pour les objets shaders peut être partagé entre un ensemble de contextes, tant que les côtés serveur des contextes partagent le même espace d'adressage. Si l'espace de noms est partagé entre des contextes, tous les objets attachés et les données associées à ces objets attachés sont également partagés.

Les applications sont responsables de fournir la synchronisation entre les appels d'API lorsque les objets sont accédés à partir de différents threads d'exécution.

GL_COMPUTE_SHADER n'est disponible que si la version de GL est 4.3 ou supérieure.

ERREURS

Cette fonction renvoie 0 si une erreur survient lors de la création de l'objet shader.

GL_INVALID_ENUM est généré si shaderType n'est pas une valeur acceptée.

GETS ASSOCIÉS

glGetShaderInfoLog() avec un objet shader valide
