NOM

glGetUniformLocation - Renvoie l'emplacement d'une variable uniforme

SPÉCIFICATION C

GLint glGetUniformLocation(GLuint program, const GLchar *name);

PARAMÈTRES

program

Spécifie l'objet programme à interroger.

name

Pointe vers une chaîne terminée par un caractère nul contenant le nom de la variable uniforme dont l'emplacement doit être interrogé.

DESCRIPTION

glGetUniformLocation renvoie un entier qui représente l'emplacement d'une variable uniforme spécifique dans un objet programme. name doit être une chaîne terminée par un caractère nul qui ne contient pas d'espaces blancs. name doit être un nom de variable uniforme actif dans program qui n'est pas une structure, un tableau de structures, ou une sous-composante d'un vecteur ou d'une matrice. Cette fonction renvoie -1 si name ne correspond pas à une variable uniforme active dans program, si name commence par le préfixe réservé "gl_", ou si name est associé à un compteur atomique ou à un bloc uniforme nommé.

Les variables uniformes qui sont des structures ou des tableaux de structures peuvent être interrogées en appelant glGetUniformLocation pour chaque champ de la structure. L'opérateur d'élément de tableau "[]" et l'opérateur de champ de structure "." peuvent être utilisés dans name afin de sélectionner des éléments dans un tableau ou des champs dans une structure. Le résultat de l'utilisation de ces opérateurs ne peut pas être une autre structure, un tableau de structures, ou une sous-composante d'un vecteur ou d'une matrice. Sauf si la dernière partie de name indique un tableau de variables uniformes, l'emplacement du premier élément d'un tableau peut être récupéré en utilisant le nom du tableau, ou en utilisant le nom suivi de "[0]".

Les emplacements réels attribués aux variables uniformes ne sont connus qu'après que l'objet programme a été lié avec succès. Après la liaison, la commande glGetUniformLocation peut être utilisée pour obtenir l'emplacement d'une variable uniforme. Cette valeur d'emplacement peut ensuite être passée à glUniform() pour définir la valeur de la variable uniforme ou à glGetUniform() afin d'interroger la valeur actuelle de la variable uniforme. Après qu'un objet programme a été lié avec succès, les valeurs d'indice des variables uniformes restent fixes jusqu'à la prochaine commande de liaison. Les emplacements et les valeurs des variables uniformes ne peuvent être interrogés après une liaison que si la liaison a réussi.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si program n'est pas un objet programme.

GL_INVALID_OPERATION est généré si program n'a pas été lié avec succès.

GETS ASSOCIÉS

glGetActiveUniform() avec les arguments program et l'indice d'une variable uniforme active

glGetProgram() avec les arguments program et GL_ACTIVE_UNIFORMS ou GL_ACTIVE_UNIFORM_MAX_LENGTH

glGetUniform() avec les arguments program et le nom d'une variable uniforme

glIsProgram()
