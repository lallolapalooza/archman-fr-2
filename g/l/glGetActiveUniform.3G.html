NOM

glGetActiveUniform - Retourne des informations sur une variable uniforme active pour l'objet de programme spécifié

SPÉCIFICATION C

void glGetActiveUniform(GLuint program, GLuint index, GLsizei bufSize, GLsizei *length, GLint *size, GLenum *type, GLchar *name);

PARAMÈTRES

program

Spécifie l'objet programme à interroger.

index

Spécifie l'index de la variable uniforme à interroger.

bufSize

Spécifie le nombre maximum de caractères qu'OpenGL est autorisé à écrire dans le tampon de caractères indiqué par name.

length

Retourne le nombre de caractères effectivement écrits par OpenGL dans la chaîne indiquée par name (à l'exclusion du terminateur nul) si une valeur autre que NULL est passée.

size

Retourne la taille de la variable uniforme.

type

Retourne le type de données de la variable uniforme.

name

Retourne une chaîne terminée par un caractère nul contenant le nom de la variable uniforme.

DESCRIPTION

glGetActiveUniform retourne des informations sur une variable uniforme active dans l'objet programme spécifié par program. Le nombre de variables uniformes actives peut être obtenu en appelant glGetProgram() avec la valeur GL_ACTIVE_UNIFORMS. Une valeur de 0 pour index sélectionne la première variable uniforme active. Les valeurs admissibles pour index vont de zéro au nombre de variables uniformes actives moins un.

Les shaders peuvent utiliser des variables uniformes intégrées, des variables uniformes définies par l'utilisateur, ou les deux. Les variables uniformes intégrées ont le préfixe "gl_" et font référence à l'état OpenGL existant ou à des valeurs dérivées de cet état (par exemple, gl_DepthRangeParameters, voir la spécification du langage de shading OpenGL pour une liste complète.) Les variables uniformes définies par l'utilisateur ont des noms arbitraires et obtiennent leurs valeurs de l'application via des appels à glUniform(). Une variable uniforme (intégrée ou définie par l'utilisateur) est considérée comme active si elle est déterminée pendant l'opération de liaison qu'elle peut être accédée pendant l'exécution du programme. Par conséquent, program aurait dû être précédemment la cible d'un appel à glLinkProgram(), mais il n'est pas nécessaire qu'il ait été lié avec succès.

La taille du tampon de caractères requis pour stocker le nom de variable uniforme le plus long dans program peut être obtenue en appelant glGetProgram() avec la valeur GL_ACTIVE_UNIFORM_MAX_LENGTH. Cette valeur doit être utilisée pour allouer un tampon de taille suffisante pour stocker le nom de variable uniforme retourné. La taille de ce tampon de caractères est passée dans bufSize, et un pointeur vers ce tampon de caractères est passé dans name.

glGetActiveUniform retourne le nom de la variable uniforme indiquée par index, en le stockant dans le tampon de caractères spécifié par name. La chaîne retournée sera terminée par un caractère nul. Le nombre réel de caractères écrits dans ce tampon est retourné dans length, et ce compte n'inclut pas le caractère de terminaison nul. Si la longueur de la chaîne retournée n'est pas requise, une valeur de NULL peut être passée dans l'argument length.

L'argument type retournera un pointeur vers le type de données de la variable uniforme. Les constantes symboliques retournées pour les types uniformes sont indiquées dans le tableau ci-dessous.

Si un ou plusieurs éléments d'un tableau sont actifs, le nom du tableau est renvoyé dans name, le type est renvoyé dans type, et le paramètre size renvoie l'indice de l'élément de tableau le plus élevé utilisé, plus un, tel que déterminé par le compilateur et/ou l'éditeur de liens. Une seule variable uniforme active sera signalée pour un tableau uniforme.

Les variables uniformes déclarées comme structures ou tableaux de structures ne seront pas renvoyées directement par cette fonction. Au lieu de cela, chacune de ces variables uniformes sera réduite à ses composants fondamentaux contenant les opérateurs "." et "[]" de telle sorte que chacun des noms soit valide comme argument de glGetUniformLocation(). Chacune de ces variables uniformes réduites est comptée comme une variable uniforme active et se voit attribuer un indice. Un nom valide ne peut pas être une structure, un tableau de structures ou un sous-composant d'un vecteur ou d'une matrice.

La taille de la variable uniforme sera renvoyée dans size. Les variables uniformes autres que les tableaux auront une taille de 1. Les structures et les tableaux de structures seront réduits comme décrit précédemment, de sorte que chacun des noms renvoyés sera un type de données dans la liste précédente. Si cette réduction aboutit à un tableau, la taille renvoyée sera telle que décrite pour les tableaux uniformes ; sinon, la taille renvoyée sera 1.

La liste des variables uniformes actives peut inclure des variables uniformes intégrées (qui commencent par le préfixe "gl_") ainsi que des noms de variables uniformes définies par l'utilisateur.

Cette fonction renverra autant d'informations que possible sur la variable uniforme active spécifiée. Si aucune information n'est disponible, length sera 0 et name sera une chaîne vide. Cette situation peut se produire si cette fonction est appelée après une opération de liaison qui a échoué. En cas d'erreur, les valeurs de retour length, size, type et name ne seront pas modifiées.

NOTES

Les types doubles, GL_DOUBLE, GL_DOUBLE_VEC2, GL_DOUBLE_VEC3, GL_DOUBLE_VEC4, GL_DOUBLE_MAT2, GL_DOUBLE_MAT3, GL_DOUBLE_MAT4, GL_DOUBLE_MAT2x3, GL_DOUBLE_MAT2x4, GL_DOUBLE_MAT3x2, GL_DOUBLE_MAT3x4, GL_DOUBLE_MAT4x2 et GL_DOUBLE_MAT4x3 ne sont disponibles que si la version de GL est 4.1 ou supérieure.

Les types d'images, GL_IMAGE_1D, GL_IMAGE_2D, GL_IMAGE_3D, GL_IMAGE_2D_RECT, GL_IMAGE_CUBE, GL_IMAGE_BUFFER, GL_IMAGE_1D_ARRAY, GL_IMAGE_2D_ARRAY, GL_IMAGE_2D_MULTISAMPLE, GL_IMAGE_2D_MULTISAMPLE_ARRAY, GL_INT_IMAGE_1D, GL_INT_IMAGE_2D, GL_INT_IMAGE_3D, GL_INT_IMAGE_2D_RECT, GL_INT_IMAGE_CUBE, GL_INT_IMAGE_BUFFER, GL_INT_IMAGE_1D_ARRAY, GL_INT_IMAGE_2D_ARRAY, GL_INT_IMAGE_2D_MULTISAMPLE, GL_INT_IMAGE_2D_MULTISAMPLE_ARRAY, GL_UNSIGNED_INT_IMAGE_1D, GL_UNSIGNED_INT_IMAGE_2D, GL_UNSIGNED_INT_IMAGE_3D, GL_UNSIGNED_INT_IMAGE_2D_RECT, GL_UNSIGNED_INT_IMAGE_CUBE, GL_UNSIGNED_INT_IMAGE_BUFFER, GL_UNSIGNED_INT_IMAGE_1D_ARRAY, GL_UNSIGNED_INT_IMAGE_2D_ARRAY, GL_UNSIGNED_INT_IMAGE_2D_MULTISAMPLE, GL_UNSIGNED_INT_IMAGE_2D_MULTISAMPLE_ARRAY, et le type de compteur atomique, GL_UNSIGNED_INT_ATOMIC_COUNTER ne sont disponibles que si la version de GL est 4.2 ou supérieure.

ERREURS

GL_INVALID_VALUE est générée si program n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est générée si program n'est pas un objet programme.

GL_INVALID_VALUE est générée si index est supérieur ou égal au nombre de variables uniformes actives dans program.

GL_INVALID_VALUE est générée si bufSize est inférieur à 0.

glGetActiveUniform

glGetActiveUniform renvoie des informations sur une variable uniforme active dans le programme d'ombrage actuel.

NOM

glGetActiveUniform — renvoie des informations sur une variable uniforme active

SPÉCIFICATION C

void glGetActiveUniform( GLuint program, GLuint index, GLsizei bufSize, GLsizei *length, GLint *size, GLenum *type, GLchar *name );

PARAMÈTRES

program
Spécifie l' identifiant du programme dont la variable uniforme active doit être interrogée.
index
Spécifie l' index de la variable uniforme active à interroger. Les variables uniformes dans un programme sont indexées de 0 à n-1, où n est le nombre total de variables uniformes actives dans le programme.
bufSize
Spécifie la taille du tampon name.
length
Renvoie la longueur du nom de la variable uniforme demandée, y compris le caractère nul de terminaison. Si length est NULL, aucune information n'est renvoyée.
size
Renvoie la taille de la variable uniforme demandée. Si le type de la variable uniforme est un type de base (scalaires, vecteurs ou matrices), la taille est 1. Si le type est un tableau, la taille est le nombre d'éléments dans le tableau. Si size est NULL, aucune information n'est renvoyée.
type
Renvoie le type de données de la variable uniforme demandée. Les types possibles sont énumérés dans la section 7.2 du manuel OpenGL 4.5. Si type est NULL, aucune information n'est renvoyée.
name
Renvoie le nom de la variable uniforme demandée sous forme de chaîne de caractères terminée par un caractère nul. Si name est NULL, aucune information n'est renvoyée.

DESCRIPTION

glGetActiveUniform renvoie des informations sur une variable uniforme active dans le programme d'ombrage actuel. La variable uniforme est identifiée par program et index. Les informations renvoyées comprennent le nom de la variable uniforme, sa taille, son type et, si length est spécifié, la longueur de son nom.

Le paramètre index est utilisé pour itérer sur toutes les variables uniformes actives dans le programme. L'itération doit commencer à index = 0 et se poursuivre jusqu'à ce que glGetActiveUniform renvoie GL_INVALID_INDEX. Le nombre total de variables uniformes actives peut être obtenu à l'aide de glGetProgramiv avec GL_ACTIVE_UNIFORMS.

Le nom de la variable uniforme est renvoyé dans le tampon name. La longueur du nom, y compris le caractère nul de terminaison, est renvoyée dans length. Si la longueur du nom dépasse bufSize moins 1, le nom est tronqué.

La taille de la variable uniforme est renvoyée dans size. Si la variable uniforme est un tableau, size sera le nombre d'éléments dans le tableau. Sinon, size sera 1.

Le type de données de la variable uniforme est renvoyé dans type. Les types possibles sont les mêmes que ceux utilisés dans glUniform*.

NOTES

Les variables uniformes qui ne sont pas utilisées par le programme sont omises lors de la génération de la liste des variables uniformes actives.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas l'identifiant d'un programme valide.

GL_INVALID_VALUE est généré si index est supérieur ou égal au nombre de variables uniformes actives dans program.

GL_INVALID_VALUE est généré si bufSize est négatif.

GETS ASSOCIÉS

glGetProgramiv, glGetUniformfv, glGetUniformiv.

SUPPORT DE VERSION

Version Modification
OpenGL 2.0 Ajout de glGetActiveUniform.
