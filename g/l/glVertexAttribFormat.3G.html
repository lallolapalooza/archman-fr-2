NAME

glVertexAttribFormat, glVertexAttribIFormat, glVertexAttribLFormat, glVertexArrayAttribFormat, glVertexArrayAttribIFormat, glVertexArrayAttribLFormat - assign the parameters of an application-specified attribute to a vertex stream

PARAMETERS

vaobj
Specifies the vertex array object to be modified. If vaobj is zero, the vertex attributes of the currently bound vertex array object are modified.
attribindex
Specifies the index of the vertex attribute to be modified.
size
Specifies the number of components per vertex attribute. Must be a value of 1, 2, 3, or 4. Otherwise, an GLerror may be generated.
type
Specifies the data type of each component in the vertex attribute. The symbolic constants in table 1 are accepted. For glVertexAttribFormat, the type must be an unsigned normalized integer type, or a floating-point type. For glVertexAttribIFormat, the type must be an integer type. For glVertexAttribLFormat, the type must be a double-precision floating-point type. Otherwise, an GLerror may be generated.
normalized
For glVertexAttribFormat, specifies whether fixed-point data types should be mapped to the range [−1, 1] (GL_TRUE) or to the range [0, 1] (GL_FALSE) when they are converted to floating-point values. If normalized is GL_TRUE, then the data is normalized. Otherwise, it is not normalized.
relativeoffset
Specifies the offset, in bytes, of the first component of the first vertex element from the beginning of the buffer binding specified by glVertexArrayVertexAttribIOffsetAndDivisor. This offset is a byte offset relative to the start of the buffer.

DESCRIPTION

These commands are used to specify the parameters of an application-specified vertex attribute. They define the structure of the data for a vertex attribute within a vertex buffer binding. When used with glVertexArrayVertexAttribIOffsetAndDivisor, they define how the attribute is read from the buffer.

The glVertexAttrib*Format commands modify the vertex array object (VAO) that is currently bound to the vertex array binding points. The glVertexArrayAttrib*Format commands modify the specified VAO directly.

For each enabled vertex attribute, the OpenGL client and server must maintain the following state information:

  • The vertex attribute's data type (e.g., GL_FLOAT, GL_INT, GL_UNSIGNED_INT).
  • The number of components per vertex attribute (1 to 4).
  • Whether the attribute data is normalized. This is only applicable for glVertexAttribFormat and glVertexArrayAttribFormat.
  • The byte offset of the first component of the vertex attribute within the buffer associated with the vertex attribute binding.

These commands specify the parameters for a vertex attribute, but they do not associate a buffer object with the attribute. That association is done by glVertexAttribBinding and glVertexArrayVertexAttribIOffsetAndDivisor.

The glVertexAttribFormat command corresponds to the vertex attribute at attribindex. The glVertexArrayAttribFormat command corresponds to the vertex attribute at attribindex for the vertex array object vaobj.

The size parameter specifies the number of data values per generic vertex attribute. It must be 1, 2, 3, or 4. For example, if a vertex data tuple is three-dimensional, then size should be set to 3.

The type parameter specifies the normalized data type of each component in the generic vertex attribute. For glVertexAttribFormat and glVertexArrayAttribFormat, the type must be an unsigned normalized integer type, or a floating-point type. For glVertexAttribIFormat and glVertexArrayAttribIFormat, the type must be an integer type. For glVertexAttribLFormat and glVertexArrayAttribLFormat, the type must be a double-precision floating-point type.

The normalized parameter is used only for glVertexAttribFormat and glVertexArrayAttribFormat. If set to GL_TRUE, it indicates that fixed-point data values should be normalized. Fixed-point data values are linearly mapped to the floating-point range [−1, 1] if the type is signed, or to the floating-point range [0, 1] if the type is unsigned. If GL_FALSE, it indicates that fixed-point data values should be linearly converted to floating-point values without normalization. Normalized integer types specified for type are treated as normalized regardless of the value of normalized.

The relativeoffset parameter specifies the byte offset of the first component of the vertex attribute relative to the start of the buffer.

NOTES

The vertex attribute format is not reset by calls to glUseProgram, but it is reset by glLinkProgram. Vertex attribute formats are associated with the vertex array object that is bound to the vertex array binding points.
