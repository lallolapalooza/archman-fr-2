NOM

gl_Position - contient la position du sommet courant

DÉCLARATION

gl_Position est un membre du bloc nommé gl_PerVertex :

    out gl_PerVertex {
        vec4 gl_Position;
        float gl_PointSize;
        float gl_ClipDistance[];
    };

DESCRIPTION

Dans les langages de shader de sommet, d'évaluation de tessellation et de géométrie, une seule instance globale du bloc nommé gl_PerVertex est disponible et son membre gl_Position est une sortie qui reçoit la position homogène du sommet. Elle peut être écrite à tout moment pendant l'exécution du shader. La valeur écrite dans gl_Position sera utilisée par l'assemblage de primitives, le clipping, le culling et d'autres fonctionnalités fixes, le cas échéant, qui opèrent sur les primitives après que le traitement des sommets a eu lieu.

Dans le langage de contrôle de tessellation, le bloc nommé gl_PerVertex est utilisé pour construire un tableau, gl_out[], dont les membres gl_Position contiennent la position homogène du point de contrôle, qui devient disponible comme entrée pour le shader d'évaluation de tessellation subséquent.

La valeur de gl_Position (ou du membre gl_Position du tableau gl_out[], dans le cas du shader de contrôle de tessellation) est indéfinie après les étapes de shading de sommet, de contrôle de tessellation et d'évaluation de tessellation si l'exécutable de shader correspondant n'écrit pas dans gl_Position. Elle est également indéfinie après l'étape de traitement de géométrie si l'exécutable du shader de géométrie appelle EmitVertex() sans avoir écrit gl_Position depuis le dernier appel à EmitVertex() (ou sans l'avoir écrit du tout).

Dans les langages de contrôle de tessellation, d'évaluation de tessellation et de géométrie, le bloc nommé gl_PerVertex est utilisé pour construire un tableau, gl_in[], d'entrées par sommet ou par point de contrôle dont le contenu représente les sorties correspondantes écrites par l'étape précédente.
