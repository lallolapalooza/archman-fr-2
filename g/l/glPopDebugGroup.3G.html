NOM

glPopDebugGroup - dépiler le groupe de débogage actif

SPÉCIFICATION C

void glPopDebugGroup(void);

DESCRIPTION

glPopDebugGroup dépile le groupe de débogage actif. Après avoir dépilé un groupe de débogage, le GL générera également un message de sortie de débogage décrivant sa cause, basé sur la chaîne message, la source source et un ID id soumis à la commande glPushDebugGroup() correspondante. GL_DEBUG_TYPE_PUSH_GROUP et GL_DEBUG_TYPE_POP_GROUP partagent un seul espace de noms pour les id de message. severity a la valeur GL_DEBUG_SEVERITY_NOTIFICATION. Le type a la valeur GL_DEBUG_TYPE_POP_GROUP. Dépiler un groupe de débogage restaure le contrôle du volume de sortie de débogage du groupe de débogage parent.

ERREURS

GL_STACK_UNDERFLOW est généré si une tentative est faite de dépiler le groupe de débogage par défaut de la pile.

OBTENTIONS ASSOCIÉES

glGet() avec l'argument GL_MAX_DEBUG_MESSAGE_LENGTH.
