NOM

glab-ci-delete - Supprimer les pipelines CI/CD.

SYNTAXE

glab ci delete [options]

DESCRIPTION

Supprimer les pipelines CI/CD.

OPTIONS

--dry-run[=false] Simuler le processus, mais ne rien supprimer.

--older-than=0s Filtrer les pipelines plus anciens que la durée donnée. Unités valides : h, m, s, ms, us, ns.

--page=0 Numéro de page.

--paginate[=false] Effectuer des requêtes HTTP supplémentaires pour récupérer toutes les pages de projets avant de cloner. Respecte « --per-page ».

--per-page=0 Nombre d'éléments à lister par page.

--source="" Filtrer les pipelines par source : api, chat, external, external_pull_request_event, merge_request_event, ondemand_dast_scan, ondemand_dast_validation, parent_pipeline, pipeline, push, schedule, security_orchestration_policy, trigger, web, webide.

-s, --status="" Supprimer les pipelines par statut : running, pending, success, failed, canceled, skipped, created, manual.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/REPO ou GROUPE/ESPACE DE NOMS/REPO. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

$ glab ci delete 34
$ glab ci delete 12,34,2
$ glab ci delete --source=api
$ glab ci delete --status=failed
$ glab ci delete --older-than 24h
$ glab ci delete --older-than 24h --status=failed
