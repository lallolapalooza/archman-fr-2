NOM

glab-label-list - Lister les étiquettes dans le dépôt.

SYNOPSIS

glab label list [flags]

DESCRIPTION

Lister les étiquettes dans le dépôt.

OPTIONS

-g, --group="" Lister les étiquettes pour un groupe.

-F, --output="text" Formater la sortie en : text, json.

-p, --page=1 Numéro de page.

-P, --per-page=30 Nombre d'éléments à lister par page.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab label list
$ glab label ls
$ glab label list -R owner/repository
$ glab label list -g mygroup
