DESCRIPTION glTexStorage2D et glTextureStorage2D spécifient les exigences de stockage pour tous les niveaux d'une texture bidimensionnelle ou d'un tableau de textures unidimensionnelles simultanément. Une fois qu'une texture est spécifiée avec cette commande, le format et les dimensions de tous les niveaux deviennent immuables, sauf s'il s'agit d'une texture proxy. Le contenu de l'image peut toujours être modifié, cependant, ses exigenc

es de

stockage ne peuvent pas changer. Une telle texture est appelée une texture à format immuable. Le comportement de glTexStorage2D dépend du paramètre target.
