NOM

glab-changelog-generate - Génère un journal des modifications pour le dépôt ou le projet.

SYNTAXE

glab changelog generate [indicateurs]

DESCRIPTION

Génère un journal des modifications pour le dépôt ou le projet.

OPTIONS

--config-file="" Chemin du fichier de configuration du journal des modifications dans le dépôt Git du projet. Par défaut : '.gitlab/changelog_config.yml'.

--date="" Date et heure de la publication. Utilise le format ISO 8601 (2016-03-11T03:45:40Z). Par défaut, l'heure actuelle.

--from="" Début de la plage de commits (sous forme de SHA) à utiliser lors de la génération du journal des modifications. Ce commit n'est pas inclus dans la liste.

--to="" Fin de la plage de commits (sous forme de SHA) à utiliser lors de la génération du journal des modifications. Ce commit est inclus dans la liste. Par défaut, le HEAD de la branche par défaut du projet.

--trailer="" La bande-annonce Git à utiliser pour inclure les commits. Par défaut : 'Changelog'.

-v, --version="" Version pour laquelle générer le journal des modifications. Doit suivre le versionnement sémantique. Par défaut, la version de la copie locale, comme avec 'git describe'.

OPTIONS INHERITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

# Générer un journal des modifications
$ glab changelog generate
