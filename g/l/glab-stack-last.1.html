NOM

glab-stack-last - Déplace vers le dernier diff dans la pile. (EXPÉRIMENTAL)

SYNTAXE

glab stack last [options]

DESCRIPTION

Se déplace vers le dernier diff de la pile et checkout cette branche.

Cette fonctionnalité est expérimentale. Elle peut être défectueuse ou supprimée sans préavis. En savoir plus sur ce que signifient les fonctionnalités expérimentales à https://docs.gitlab.com/policy/development_stages_support/

Utilisez les fonctionnalités expérimentales à vos propres risques.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE_NOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab stack last
