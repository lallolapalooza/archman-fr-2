DESCRIPTIO

N

glGetVertexArrayIndexediv et glGetVertexArrayIndexed64iv fournissent un moyen d'interroger les paramètres d'un attribut à un index spécifié par l'utilisateur d'un objet de tableau de sommets. L'objet de tableau de sommets n'a pas besoin d'être lié au contexte de rendu au moment de l'appel, mais doit avoir été lié au moins une fois avant cet

appel.

Les valeurs de paramètres suivantes peuvent être récupérées avec glGetVertexArrayIndexediv pour chacun des attributs définis pour un objet de tableau de sommets

:
•GL_VERTEX_ATTRIB_ARRAY_ENABLED : param renvoie une valeur non nulle (vrai) si le tableau d'attributs de sommet pour index est activé et 0 (faux) s'il est désactivé. La valeur initiale est GL_FALSE
.
•GL_VERTEX_ATTRIB_ARRAY_SIZE : param renvoie une valeur unique, la taille du tableau d'attributs de sommet pour index. La taille est le nombre de valeurs pour chaque élément du tableau d'attributs de sommet, et elle sera 1, 2, 3 ou 4. La valeur initiale est
4.
•GL_VERTEX_ATTRIB_ARRAY_STRIDE : param renvoie une valeur unique, le pas du tableau pour (le nombre d'octets entre les éléments successifs dans) le tableau d'attributs de sommet pour index. Une valeur de 0 indique que les éléments du tableau sont stockés séquentiellement en mémoire. La valeur initiale est
0.
•GL_VERTEX_ATTRIB_ARRAY_TYPE : param renvoie une valeur unique, une constante symbolique indiquant le type de tableau pour le tableau d'attributs de sommet pour index. Les valeurs possibles sont GL_BYTE, GL_DOUBLE, GL_FIXED, GL_FLOAT, GL_HALF_FLOAT, GL_INT, GL_INT_2_10_10_10_REV, GL_SHORT, GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, GL_UNSIGNED_INT, GL_UNSIGNED_INT_2_10_10_10_REV, et GL_UNSIGNED_INT_10F_11F_11F_REV . La valeur initiale est GL_FLOAT
.
•GL_VERTEX_ATTRIB_ARRAY_NORMALIZED : param renvoie une valeur unique qui est non nulle (vrai) si les types de données à virgule fixe du tableau d'attributs de sommet indiqué par index sont normalisés lorsqu'ils sont convertis en virgule flottante, et 0 (faux) sinon. La valeur initiale est GL_FALSE
.
•GL_VERTEX_ATTRIB_ARRAY_INTEGER : param renvoie une valeur unique qui est non nulle (vrai) si les types de données à virgule fixe du tableau d'attributs de sommet indiqué par index ont un type de données entier, et 0 (faux) sinon. La valeur initiale est 0 (GL_FALS
E).
•GL_VERTEX_ATTRIB_ARRAY_LONG : param renvoie une valeur unique qui est non nulle (vrai) si un attribut de sommet est stocké comme un double non converti, et 0 (faux) sinon. La valeur initiale est 0 (GL_FALS
E).
•GL_VERTEX_ATTRIB_ARRAY_DIVISOR : param renvoie une valeur unique qui est le diviseur de fréquence utilisé pour le rendu instancié. Voir glVertexAttribDivisor. La valeur initiale est
0.
•GL_VERTEX_ATTRIB_RELATIVE_OFFSET : param renvoie une valeur unique qui est le décalage en octets du premier élément par rapport au début de la liaison du tampon de sommet à partir de laquelle les attributs spécifiés sont récupérés. La valeur initiale est
0.

glGetVertexArrayIndexed64iv peut être utilisé pour récupérer la valeur du paramètre GL_VERTEX_BINDING_OFFSET pour n'importe lequel des attributs définis pour un objet de tableau de sommets. Lorsque pname est défini à GL_VERTEX_BINDING_OFFSET, param renvoie une valeur unique qui est le décalage en octets du premier élément d

ans le magasin de données du tampon lié. La
valeur initiale de ce paramètre est 0.

ERREUR

S

L'erreur GL_INVALID_OPERATION est générée si vaobj n'est pas le nom d'un objet de tableau de sommets

existant.

L'erreur GL_INVALID_VALUE est générée si index est supérieur ou égal à la valeur de GL_MAX_VERTEX_ATTRIBS

.

L'erreur GL_INVALID_ENUM est générée si pname n'est pas l'une des valeurs valides.
