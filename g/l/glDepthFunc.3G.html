NOM

glDepthFunc - spécifier la valeur utilisée pour les comparaisons du tampon de profondeur

SPÉCIFICATION C

void glDepthFunc(GLenum func);

PARAMÈTRES

func

Spécifie la fonction de comparaison de profondeur. Les constantes symboliques GL_NEVER, GL_LESS, GL_EQUAL, GL_LEQUAL, GL_GREATER, GL_NOTEQUAL, GL_GEQUAL et GL_ALWAYS sont acceptées. La valeur initiale est GL_LESS.

DESCRIPTION

glDepthFunc spécifie la fonction utilisée pour comparer chaque valeur de profondeur entrante avec la valeur de profondeur présente dans le tampon de profondeur. La comparaison n'est effectuée que si le test de profondeur est activé. (Voir glEnable() et

glDisable de GL_DEPTH_TEST.)

func spécifie les conditions sous lesquelles le pixel sera dessiné. Les fonctions de comparaison sont les suivantes :

GL_NEVER

Ne passe jamais.

GL_LESS

Passe si la valeur de profondeur entrante est inférieure à la valeur de profondeur stockée.

GL_EQUAL

Passe si la valeur de profondeur entrante est égale à la valeur de profondeur stockée.

GL_LEQUAL

Passe si la valeur de profondeur entrante est inférieure ou égale à la valeur de profondeur stockée.

GL_GREATER

Passe si la valeur de profondeur entrante est supérieure à la valeur de profondeur stockée.

GL_NOTEQUAL

Passe si la valeur de profondeur entrante n'est pas égale à la valeur de profondeur stockée.

GL_GEQUAL

Passe si la valeur de profondeur entrante est supérieure ou égale à la valeur de profondeur stockée.

GL_ALWAYS

Passe toujours.

La valeur initiale de func est GL_LESS. Initialement, le test de profondeur est désactivé. Si le test de profondeur est désactivé ou si aucun tampon de profondeur n'existe, c'est comme si le test de profondeur réussissait toujours.

NOTES

Même si le tampon de profondeur existe et que le masque de profondeur est non nul, le tampon de profondeur n'est pas mis à jour si le test de profondeur est désactivé. Afin d'écrire inconditionnellement dans le tampon de profondeur, le test de profondeur doit être activé et défini sur GL_ALWAYS.

ERREURS

GL_INVALID_ENUM est généré si func n'est pas une valeur acceptée.

ASSOCIÉES GETS

glGet() avec l'argument GL_DEPTH_FUNC

glIsEnabled() avec l'argument GL_DEPTH_TEST
