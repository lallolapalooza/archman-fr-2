glutGameModeString(3)

Paquet: freeglut

Licences: X11

glutGameModeString(3) freeglut glutGameModeString(3)

NOM

glutGameModeString - définit la configuration du mode jeu via une chaîne de caractères.

SYNTAXE

void glutGameModeString(const char *string);

ARGUMENTS

string
Chaîne de caractères ASCII pour sélectionner une configuration de mode jeu.

DESCRIPTION

glutGameModeString définit la configuration du mode jeu via une chaîne de caractères ASCII. La chaîne de configuration du mode jeu pour le mode jeu plein écran de GLUT décrit la largeur et la hauteur de l'écran en pixels, la profondeur en pixels en bits, et la fréquence de rafraîchissement vidéo en hertz. La chaîne de configuration du mode jeu peut également spécifier un mode d'affichage dépendant du système de fenêtrage.

La chaîne est une liste de zéro ou plusieurs descriptions de capacités séparées par des espaces et des tabulations. Chaque description de capacité est un nom de capacité suivi d'un comparateur et d'une valeur numérique. (Contrairement à la chaîne de mode d'affichage spécifiée avec glutInitDisplayString, le comparateur et la valeur numérique ne sont *pas* optionnels.) Par exemple, "width>=640" et "bpp=32" sont des critères valides.

Les descriptions de capacités sont traduites en un ensemble de critères utilisés pour sélectionner la configuration de mode jeu appropriée.

Les critères sont mis en correspondance dans l'ordre strict de priorité, de gauche à droite. Autrement dit, le premier critère spécifié (le plus à gauche) a la priorité sur les critères ultérieurs pour les critères non exacts (comparateurs supérieur, inférieur, etc.). Les critères exacts (comparateurs égal, différent) doivent correspondre exactement, donc la priorité n'est pas pertinente.

La valeur numérique est un entier qui est analysé selon le comportement strtol(str, strptr, 0) d'ANSI C. Cela signifie que les valeurs décimales, octales (0 en préfixe) et hexadécimales (0x en préfixe) sont acceptées.

Les comparateurs valides sont :

=
Égal.
!=
Différent.
<
Inférieur et préférant une plus grande différence (le moins est le mieux).
>
Supérieur et préférant de plus grandes différences (le plus est le mieux).
<=
Inférieur ou égal et préférant une plus grande différence (le moins est le mieux).
>=
Supérieur ou égal et préférant plus plutôt que moins. Ce comparateur est utile pour allouer des ressources comme la précision des couleurs ou la précision du tampon de profondeur, où la précision maximale est généralement préférée. À comparer avec le comparateur tilde (~).
~
Supérieur ou égal mais préférant moins plutôt que plus. Ce comparateur est utile pour allouer des ressources telles que des bits de stencil ou des tampons de couleur auxiliaires où il est préférable de ne pas sur-allouer.

Les noms de capacités valides sont :

bpp
Bits par pixel pour le tampon d'image.
height
Hauteur de l'écran en pixels.
hertz
Taux de rafraîchissement vidéo de l'écran en hertz.
num
Numéro de la configuration du mode d'affichage dépendante du système de fenêtrage.
width
Largeur de l'écran en pixels.

Un format de description de résolution d'écran compact supplémentaire est pris en charge. Cette description compacte encode de manière pratique la description de la résolution de l'écran en une seule phrase. Par exemple, "640x480:16@60" demande un écran de 640 par 480 pixels avec 16 bits par pixel à une fréquence de rafraîchissement vidéo de 60 hertz. Une description de résolution d'écran compacte peut être mélangée avec des descriptions de capacités conventionnelles.

Le format de description de résolution d'écran compact est le suivant :

[ width "x" height ][ ":" bitsPerPixel ][ "@" videoRate ]

Les descriptions de capacités non spécifiées entraîneront la génération de critères non spécifiés. Ces critères non spécifiés aident glutGameModeString à se comporter de manière raisonnable avec des chaînes de description de mode jeu concises.
