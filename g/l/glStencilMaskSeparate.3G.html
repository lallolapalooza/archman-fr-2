NOM

glStencilMaskSeparate - contrôle l'écriture des bits individuels dans les plans de stencil pour le côté avant et/ou arrière.

SPÉCIFICATION EN C

void glStencilMaskSeparate(GLenum face, GLuint mask);

PARAMÈTRES

face

Spécifie si le masque d'écriture du stencil avant et/ou arrière est mis à jour. Trois constantes symboliques sont valides : GL_FRONT, GL_BACK, et GL_FRONT_AND_BACK.

mask

Spécifie un masque de bits pour activer et désactiver l'écriture des bits individuels dans les plans de stencil. Initialement, le masque est composé de tous les 1.

DESCRIPTION

glStencilMaskSeparate contrôle l'écriture des bits individuels dans les plans de stencil. Les n bits les moins significatifs de mask, où n est le nombre de bits dans le tampon de stencil, spécifient un masque. Là où un 1 apparaît dans le masque, il est possible d'écrire dans le bit correspondant du tampon de stencil. Là où un 0 apparaît, le bit correspondant est protégé en écriture. Initialement, tous les bits sont activés pour l'écriture.

Il peut y avoir deux masques d'écriture de stencil distincts ; l'un affecte les polygones dont la face est orientée vers l'arrière, et l'autre affecte les polygones dont la face est orientée vers l'avant ainsi que d'autres primitives non polygonales. glStencilMask() définit les masques d'écriture de stencil avant et arrière aux mêmes valeurs, comme si glStencilMaskSeparate() avait été appelée avec face défini à GL_FRONT_AND_BACK.

ERREURS

GL_INVALID_ENUM est générée si face n'est pas l'un des jetons acceptés.

GETS ASSOCIÉS

glGet() avec l'argument GL_STENCIL_WRITEMASK, GL_STENCIL_BACK_WRITEMASK, ou GL_STENCIL_BITS
