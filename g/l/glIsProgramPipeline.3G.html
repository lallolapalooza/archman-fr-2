NOM

glIsProgramPipeline - déterminer si un nom correspond à un objet pipeline de programme

SPÉCIFICATION C

GLboolean glIsProgramPipeline(GLuint pipeline);

PARAMÈTRES

pipeline

Spécifie une valeur qui peut être le nom d'un objet pipeline de programme.

DESCRIPTION

glIsProgramPipeline renvoie GL_TRUE si pipeline est actuellement le nom d'un objet pipeline de programme. Si pipeline est zéro, ou si pipeline n'est pas le nom d'un objet pipeline de programme, ou si une erreur se produit, glIsProgramPipeline renvoie GL_FALSE. Si pipeline est un nom renvoyé par glGenProgramPipelines(), mais qui n'a pas encore été lié via un appel à glBindProgramPipeline(), alors le nom n'est pas un objet pipeline de programme et glIsProgramPipeline renvoie GL_FALSE.
