NOM

glDeleteTransformFeedbacks - supprime les objets de retour de transformation

SPÉCIFICATION

void glDeleteTransformFeedbacks(GLsizei n, const GLuint *ids);

PARAMÈTRES

n

Spécifie le nombre d'objets de retour de transformation à supprimer.

ids

Spécifie un tableau de noms d'objets de retour de transformation à supprimer.

DESCRIPTION

glDeleteTransformFeedbacks supprime les n objets de retour de transformation dont les noms sont stockés dans le tableau ids. Les noms inutilisés dans ids sont ignorés, tout comme le nom zéro. Après la suppression d'un objet de retour de transformation, son nom redevient inutilisé et il n'a plus de contenu. Si un objet de retour de transformation actif est supprimé, son nom devient immédiatement inutilisé, mais l'objet sous-jacent n'est pas supprimé tant qu'il n'est plus actif.

ASSOCIÉ AVEC GET

glGet() avec l'argument GL_TRANSFORM_FEEDBACK_BINDING
