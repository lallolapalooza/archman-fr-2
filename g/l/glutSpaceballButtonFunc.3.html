NOM

glutSpaceballButtonFunc - définit la fonction de rappel pour les boutons du Spaceball pour la fenêtre courante.

SYNTAXE

void glutSpaceballButtonFunc(void (*func)(int button, int state));

ARGUMENTS

func
La nouvelle fonction de rappel pour les boutons du Spaceball.

DESCRIPTION

glutSpaceballButtonFunc définit la fonction de rappel pour les boutons du Spaceball pour la fenêtre courante. La fonction de rappel pour les boutons du Spaceball d'une fenêtre est appelée lorsque la fenêtre a le focus d'entrée du Spaceball (normalement, lorsque la souris est dans la fenêtre) et que l'utilisateur actionne les boutons du Spaceball. Le paramètre button sera le numéro du bouton (commençant à un). Le nombre de boutons de Spaceball disponibles peut être déterminé avec glutDeviceGet(GLUT_NUM_SPACEBALL_BUTTONS). L'état est soit GLUT_UP soit GLUT_DOWN, indiquant si l'appel de fonction est dû à un relâchement ou à une pression, respectivement.

L'enregistrement d'une fonction de rappel pour les boutons du Spaceball lorsqu'aucun périphérique Spaceball n'est disponible est sans effet et ne produit pas d'erreur. Dans ce cas, aucune fonction de rappel pour les boutons du Spaceball ne sera générée.

Passer NULL à glutSpaceballButtonFunc désactive la génération des fonctions de rappel pour les boutons du Spaceball. Lorsqu'une nouvelle fenêtre est créée, aucune fonction de rappel pour les boutons du Spaceball n'est initialement enregistrée.
