DESCRIPTIO

N

glBufferSubData et glNamedBufferSubData redéfinissent une partie ou la totalité du magasin de données de l'objet tampon spécifié. Les données commençant à l'octet de décalage offset et s'étendant sur size octets sont copiées dans le magasin de données depuis la mémoire pointée par data. offset et size doivent définir une plage entièrement conte

nue dans le magasin de do
nnées de l'objet tampon.

NOTE

S

Lors du remplacement de l'intégralité du magasin de données, envisagez d'utiliser glBufferSubData plutôt que de recréer complètement le magasin de données avec glBufferData. Cela évite le coût de la réallocation du magasin de

données.

Envisagez d'utiliser plusieurs objets tampons pour éviter de bloquer le pipeline de rendu lors des mises à jour du magasin de données. Si un rendu quelconque dans le pipeline fait référence à des données dans l'objet tampon en cours de mise à jour par glBufferSubData, en particulier depuis la région spécifique en cours de mise à jour, ce rendu doit être vidé du pipeline avant que le magasin de données ne puisse être mis à

jour.

Les clients doivent aligner les éléments de données de manière cohérente avec les exigences de la plateforme client, avec une exigence supplémentaire de niveau de base selon laquelle un décalage dans un tampon vers une donnée composée de $N$ octets doit être un multiple de

$N$.

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version de GL est 4.2 ou

supérieure.

Les cibles GL_DISPATCH_INDIRECT_BUFFER et GL_SHADER_STORAGE_BUFFER ne sont disponibles que si la version de GL est 4.3 ou

supérieure.

La cible GL_QUERY_BUFFER n'est disponible que

si la version de GL e
st 4.4 ou supérieure.

ERREU

R

GL_INVALID_ENUM est généré par glBufferSubData si target n'est pas l'une des cibles de tampon

acceptées.

GL_INVALID_OPERATION est généré par glBufferSubData si zéro est lié à target

.

GL_INVALID_OPERATION est généré par glNamedBufferSubData si buffer n'est pas le nom d'un objet tampon

existant.

GL_INVALID_VALUE est généré si offset ou size est négatif, ou si $offset + size$ est supérieur à la valeur de GL_BUFFER_SIZE pour l'objet tampon

spécifié.

GL_INVALID_OPERATION est généré si une partie de la plage spécifiée de l'objet tampon est mappée avec glMapBufferRange() ou glMapBuffer(), sauf si elle a été mappée avec le bit GL_MAP_PERSISTENT_BIT défini dans les drapeaux d'accès glMapBufferRange

.

GL_INVALID_OPERATION est généré si la valeur du drapeau GL_BUFFER_IMMUTABLE_STORAGE de l'objet tampon est GL_TRUE et si la valeur de GL_BUFFER_STORAGE_FLAGS pour l'objet tampon n'a pas le bit GL_DYNAMIC_STOR

AGE_BIT
défini.
