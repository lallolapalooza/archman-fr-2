NOM

glab-snippet-create - Créer un nouveau snippet.

SYNTAXE

glab snippet create [options] -t [...] glab snippet create [options] -t -f # lit depuis stdin

DESCRIPTION

Créer un nouveau snippet.

OPTIONS

-d, --description="" Description du snippet.

-f, --filename="" Nom de fichier du snippet dans GitLab.

-p, --personal[=false] Créer un snippet personnel.

-t, --title="" (requis) Titre du snippet.

-v, --visibility="private" Limiter par visibilité : 'public', 'internal', ou 'private'

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/DEPOT ou GROUPE/ESPACE-NOM/DEPOT. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

$ glab snippet create script.py --title "Titre du snippet"
$ echo "package main" | glab snippet new --title "Titre du snippet" --filename "main.go"
$ glab snippet create -t Titre -f "different.go" -d Description main.go
$ glab snippet create -t Titre -f "different.go" -d Description --filename different.go main.go
$ glab snippet create --personal --title "Snippet personnel" script.py
