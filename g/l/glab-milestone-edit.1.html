NOM

glab-milestone-edit - Modifier un jalon de groupe ou de projet.

SYNTAXE

glab milestone edit [indicateurs]

DESCRIPTION

Modifier un jalon de groupe ou de projet.

OPTIONS

--description="" Description du jalon.

--due-date="" Date d'échéance du jalon. Attendu au format ISO 8601 (2025-04-15T08:00:00Z).

--group="" L'identifiant ou le chemin encodé par URL du groupe.

--project="" L'identifiant ou le chemin encodé par URL du projet.

--start-date="" Date de début du jalon. Attendu au format ISO 8601 (2025-04-15T08:00:00Z).

--state="" État du jalon. Peut être 'activate' ou 'close'.

--title="" Titre du jalon.

OPTIONS HERITEES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/DEPOT ou GROUPE/ESPACEDEVIS/DEPOT. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Modifier le jalon pour le projet actuel
$ glab milestone edit 123 --title='Titre d'exemple' --due-date='2025-12-16'
# Modifier le jalon pour le projet spécifié
$ glab milestone edit 123 --title='Jalon de groupe d'exemple' --due-date='2025-12-16' --project chemin-exemple/chemin-projet
# Modifier le jalon pour le groupe spécifié
$ glab milestone edit 123 --title='Jalon de groupe d'exemple' --due-date='2025-12-16' --group 789
