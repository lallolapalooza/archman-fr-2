DESCRIPTIO

N

glClearTexSubImage remplit toute ou une partie d'une image contenue dans une texture avec une valeur fournie par l'application. texture doit être le nom d'une texture existante. De plus, texture ne peut pas être le nom d'une texture tampon, et son format interne ne peut pas être

compressé.

Les arguments xoffset, yoffset et zoffset spécifient les coordonnées du texel inférieur gauche d'une sous-région rectangulaire du tableau de texels de largeur width, de hauteur height et de profondeur

depth.

Pour les textures de tableau unidimensionnelles, yoffset est interprété comme la première couche à effacer et height est le nombre de couches à effacer. Pour les textures de tableau bidimensionnelles, zoffset est interprété comme la première couche à effacer et depth est le nombre de couches à effacer. Les textures de cube map sont traitées comme un tableau de six tranches dans la dimension z, où la valeur de zoffset est interprétée comme spécifiant la face du cube map pour la couche correspondante et depth est le nombre de faces à effacer. Pour les textures de tableau de cube map, zoffset est la première couche-face à effacer, et depth est le nombre de couches-faces à effacer. Chaque couche-face est traduite en une couche de tableau et une face de cube map comme décrit dans la spécification

OpenGL.

Les valeurs négatives de xoffset, yoffset et zoffset correspondent aux coordonnées des texels de bordure. En prenant ws, hs, ds, wb, hb et db comme étant les valeurs spécifiées width, height, depth, et la largeur, hauteur et profondeur de la bordure du tableau de texels, et en prenant x, y, z, w, h et d comme étant les valeurs des arguments xoffset, yoffset, zoffset, width, height et depth, l'une des relations suivantes génère une erreur GL_INVALID_OPER

Pour les types de texture qui n'ont pas certaines dimensions, cette commande traite ces dimensions comme ayant une taille de 1. Par exemple, pour effacer une portion d'une texture bidimensionnelle, utilisez zoffset égal à zéro et depth égal à

un.

format et type spécifient le format et le type des données source et sont interprétés comme pour glTexImage3D(). Les textures avec un format interne de base GL_DEPTH_COMPONENT, GL_STENCIL_INDEX ou GL_DEPTH_STENCIL nécessitent respectivement des données de composante de profondeur, de stencil ou de profondeur-stencil. Les textures avec d'autres formats internes de base nécessitent des formats RGBA. Les textures avec des formats internes entiers nécessitent des données

entières.

data est un pointeur vers un tableau d'un à quatre composantes de données de texel qui seront utilisées comme source pour la valeur de remplissage constante. Les éléments de data sont convertis par la GL en le format interne de l'image de texture (qui a été spécifié lorsque le niveau a été défini par l'une des commandes glTexImage*, glTexStorage* ou glCopyTexImage*), puis utilisés pour remplir la plage spécifiée du niveau de texture de destination. ERREU

R

GL_INVALID_OPERATION est généré si texture vaut zéro ou n'est pas le nom d'un objet texture

existant.

GL_INVALID_OPERATION est généré si texture est une texture

tampon.

GL_INVALID_OPERATION est généré si texture a un format interne

compressé.

GL_INVALID_OPERATION est généré si le format interne de base est GL_DEPTH_COMPONENT et format n'est pas GL_DEPTH_COMPONENT

.

GL_INVALID_OPERATION est généré si le format interne de base est GL_DEPTH_STENCIL et format n'est pas GL_DEPTH_STENCIL

.

GL_INVALID_OPERATION est généré si le format interne de base est GL_STENCIL_INDEX et format n'est pas GL_STENCIL_INDEX

.

GL_INVALID_OPERATION est généré si le format interne de base est GL_RGBA et format est GL_DEPTH_COMPONENT, GL_STENCIL_INDEX ou GL_DEPTH_STENCIL

.

GL_INVALID_OPERATION est généré si le format interne est entier et format ne spécifie pas des données

entières.

GL_INVALID_OPERATION est généré si le format interne n'est pas entier et format spécifie des données

entières.

L'erreur GL_INVALID_OPERATION est générée si les paramètres xoffset, yoffset, zoffset, width, height et depth (ou leurs combinaisons) spécifient une région qui tombe en dehors du

tableau d'images de texture défini (y
