glutStrokeWidth(3)

Paquet: freeglut

Licences: X11

glutStrokeWidth(3) freeglut glutStrokeWidth(3)

NOM

glutStrokeWidthf, glutStrokeWidth - renvoie la largeur d'un caractère de trait.
glutStrokeLengthf, glutStrokeLength - renvoie la longueur d'une chaîne de caractères de police de traits.

SYNTAXE

float glutStrokeWidthf(void *font, int character);
float glutStrokeLengthf(void *font, const unsigned char *string);
Interfaces dépréciées
int glutStrokeWidth(void *font, int character);
int glutStrokeLength(void *font, const unsigned char *string);

ARGUMENTS

font
Police de traits à utiliser. Pour les valeurs valides, voir la description de glutStrokeWidth.
caractère
Caractère dont on veut renvoyer la largeur (pas limité à 8 bits).
chaîne
Chaîne de texte (caractères 8 bits), terminée par un caractère nul.

DESCRIPTION

glutStrokeWidthf renvoie la largeur en unités de modélisation d'un caractère de trait dans une police de traits supportée. Bien que la largeur des caractères d'une police puisse varier (bien que les polices à chasse fixe ne varient pas), les caractéristiques de hauteur maximale d'une police particulière sont fixes.

glutStrokeLengthf renvoie la longueur en unités de modélisation d'une chaîne (caractères 8 bits). Cette longueur est équivalente à la somme de toutes les largeurs renvoyées par glutStrokeWidthf pour chaque caractère de la chaîne.

BOGUES

Les routines dépréciées glutStrokeWidth et glutStrokeLength renvoient un entier plutôt qu'un flottant. Les programmes GLUT plus récents devraient utiliser les nouvelles routines glutStrokeWidthf et glutStrokeLengthf qui renvoient des flottants. Notez que ces nouvelles routines flottantes n'existent pas dans les implémentations antérieures à GLUT 3.8. De plus, la routine glutStrokeLength additionnait des largeurs de caractères entièreïsées, ce qui sous-estimait la longueur des chaînes avant GLUT 3.8, mais l'implémentation de glutStrokeLength dans GLUT 3.8 et versions ultérieures additionne les largeurs de caractères pour les chaînes dans un flottant (bien que glutStrokeLength renvoie toujours un entier).
