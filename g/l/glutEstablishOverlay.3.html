NOM

glutEstablishOverlay - établit une superposition (si possible) pour la fenêtre actuelle.

AVERTISSEMENT

Pas encore implémenté dans freeglut.

SYNTAXE

void glutEstablishOverlay(void);

DESCRIPTION

glutEstablishOverlay établit une superposition (si possible) pour la fenêtre actuelle. Le mode d'affichage demandé pour la superposition est déterminé par le mode d'affichage initial. glutLayerGet(GLUT_OVERLAY_POSSIBLE) peut être appelé pour déterminer si une superposition est possible pour la fenêtre actuelle avec le mode d'affichage initial actuel. N'essayez pas d'établir une superposition lorsqu'elle n'est pas possible ; GLUT terminera le programme.

Si glutEstablishOverlay est appelé alors qu'une superposition existe déjà, la superposition existante est d'abord supprimée, puis une nouvelle superposition est établie. L'état du contexte OpenGL de l'ancienne superposition est perdu.

L'état d'affichage initial d'une superposition est affiché, cependant la superposition n'est réellement affichée que si la fenêtre de la superposition est affichée.

Implicitement, la couche de la fenêtre en cours d'utilisation passe à la superposition immédiatement après l'établissement de la superposition.

EXEMPLE

L'établissement d'une superposition est un peu complexe, mais facile une fois que vous vous y habituez. Voici un exemple :

  int overlaySupport;
  int transparent, red, white;
  glutInitDisplayMode(GLUT_SINGLE | GLUT_INDEX);
  overlaySupport = glutLayerGet(GLUT_OVERLAY_POSSIBLE);
  if (overlaySupport) {
    glutEstablishOverlay();
    glutHideOverlay();
    transparent = glutLayerGet(GLUT_TRANSPARENT_INDEX);
    glClearIndex(transparent);
    red = (transparent + 1) % glutGet(GLUT_WINDOW_COLORMAP_SIZE);
    white = (transparent + 2) % glutGet(GLUT_WINDOW_COLORMAP_SIZE);
    glutSetColor(red, 1.0, 0.0, 0.0);  /* Rouge. */
    glutSetColor(white, 1.0, 1.0, 1.0);  /* Blanc. */
    glutOverlayDisplayFunc(redrawOverlay);
    glutReshapeFunc(reshape);
  } else {
    printf("Désolé, pas de superposition sympa (essayez une station SGI) !0);
  }

Si vous configurez une superposition et installez une fonction de redimensionnement, vous devez mettre à jour les vues et éventuellement les matrices de projection du plan normal et de la superposition. Par exemple, votre fonction de redimensionnement pourrait ressembler à ceci :

  void
  reshape(int w, int h)
  {
    if (overlaySupport) {
      glutUseLayer(GLUT_OVERLAY);
      /* Configuration de la superposition pour avoir un système de coordonnées de style X. */
      glViewport(0, 0, w, h);
      glMatrixMode(GL_PROJECTION);
      glLoadIdentity();
      gluOrtho2D(0, w, 0, h);
      glScalef(1, -1, 1);
      glTranslatef(0, -h, 0);
      glMatrixMode(GL_MODELVIEW);
      glutUseLayer(GLUT_NORMAL);
    }
    glViewport(0, 0, w, h);
  }

Voir la page de manuel glutOverlayDisplayFunc pour un exemple montrant une façon d'écrire votre fonction d'affichage de superposition.

NOTES D'IMPLEMENTATION X

GLUT pour X utilise la convention SERVER_OVERLAY_VISUALS pour déterminer si des visuels de superposition sont disponibles. Bien que la convention permette des superpositions opaques (sans transparence) et des superpositions avec transparence spécifiée sous forme de masque de bits, la gestion des superpositions de GLUT ne fournit l'accès qu'aux superpositions de pixels transparents.

Tant que les superpositions RGBA ne seront pas mieux comprises, GLUT ne prendra en charge que les superpositions d'index de couleur.
