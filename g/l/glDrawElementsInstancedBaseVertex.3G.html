NOM

glDrawElementsInstancedBaseVertex - Rendre plusieurs instances d'un ensemble de primitives à partir de données tableau avec un décalage par élément

SPc C SPÉCIFICATION

void glDrawElementsInstancedBaseVertex(GLenum mode, GLsizei count, GLenum type, void *indices, GLsizei instancecount, GLint basevertex);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_PATCHES sont acceptées.

count

Spécifie le nombre d'éléments à rendre.

type

Spécifie le type des valeurs dans les indices. Doit être l'un de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, ou GL_UNSIGNED_INT.

indices

Spécifie un pointeur vers l'emplacement où les indices sont stockés.

instancecount

Spécifie le nombre d'instances de la géométrie indexée qui doivent être dessinées.

basevertex

Spécifie une constante qui doit être ajoutée à chaque élément de indices lors du choix des éléments à partir des tableaux de sommets activés.

DESCRIPTION

glDrawElementsInstancedBaseVertex se comporte de manière identique à glDrawElementsInstanced() à ceci près que le ième élément transféré par l'appel de dessin correspondant sera pris de l'élément indices[i] + basevertex de chaque tableau activé. Si la valeur résultante est supérieure à la valeur maximale représentable par type, c'est comme si le calcul avait été converti en entiers non signés de 32 bits (avec dépassement en cas de débordement). L'opération est indéfinie si la somme est négative.

NOTES

glDrawElementsInstancedBaseVertex n'est pris en charge que si la version de GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si count ou instancecount est négatif.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé ou au tableau d'éléments et que le magasin de données de l'objet tampon est actuellement mappé.
