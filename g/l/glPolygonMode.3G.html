NOM

glPolygonMode - sélectionner un mode de rastérisation de polygone

SPÉCIFICATION C

void glPolygonMode(GLenum face, GLenum mode);

PARAMÈTRES

face

Spécifie les polygones auxquels mode s'applique. Doit être GL_FRONT_AND_BACK pour les polygones orientés vers l'avant et vers l'arrière.

mode

Spécifie comment les polygones seront rastérisés. Les valeurs acceptées sont GL_POINT, GL_LINE et GL_FILL. La valeur initiale est GL_FILL pour les polygones orientés vers l'avant et vers l'arrière.

DESCRIPTION

glPolygonMode contrôle l'interprétation des polygones pour la rastérisation. face décrit à quels polygones mode s'applique : les deux faces des polygones (GL_FRONT_AND_BACK). Le mode de polygone n'affecte que la rastérisation finale des polygones. En particulier, les sommets d'un polygone sont éclairés et le polygone est découpé et éventuellement écarté avant que ces modes ne soient appliqués.

Trois modes sont définis et peuvent être spécifiés dans mode :

GL_POINT

Les sommets du polygone marqués comme début d'un bord de frontière sont dessinés comme des points. Les attributs de point tels que GL_POINT_SIZE et GL_POINT_SMOOTH contrôlent la rastérisation des points. Les attributs de rastérisation de polygone autres que GL_POLYGON_MODE n'ont aucun effet.

GL_LINE

Les bords de frontière du polygone sont dessinés comme des segments de ligne. Les attributs de ligne tels que GL_LINE_WIDTH et GL_LINE_SMOOTH contrôlent la rastérisation des lignes. Les attributs de rastérisation de polygone autres que GL_POLYGON_MODE n'ont aucun effet.

GL_FILL

L'intérieur du polygone est rempli. Les attributs de polygone tels que GL_POLYGON_SMOOTH contrôlent la rastérisation du polygone.

EXEMPLES

Pour dessiner une surface avec des polygones esquissés, appelez

glPolygonMode(GL_FRONT_AND_BACK, GL_LINE);

NOTES

Les sommets sont marqués comme bordure ou non-bordure avec un indicateur d'arête. Les indicateurs d'arête sont générés en interne par le GL lorsqu'il décompose les bandes et les éventails de triangles.

ERREURS

GL_INVALID_ENUM est généré si face ou mode n'est pas une valeur acceptée.

GETS ASSOCIÉS

glGet() avec l'argument GL_POLYGON_MODE
