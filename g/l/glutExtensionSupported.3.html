glutExtensionSupported(3)

Paquet: freeglut

Licences: X11

glutExtensionSupported(3) freeglut glutExtensionSupported(3)

NOM

glutExtensionSupported - aide à déterminer facilement si une extension OpenGL donnée est prise en charge.

SYNTAXE

int glutExtensionSupported(char *extension);

ARGUMENTS

extension
Nom de l'extension OpenGL.

DESCRIPTION

glutExtensionSupported aide à déterminer facilement si une extension OpenGL donnée est prise en charge ou non. Le paramètre extension nomme l'extension à interroger. Les extensions prises en charge peuvent également être déterminées avec glGetString(GL_EXTENSIONS), mais glutExtensionSupported effectue l'analyse correcte de la chaîne retournée.

glutExtensionSupported renvoie une valeur non nulle si l'extension est prise en charge, zéro sinon.

Il doit y avoir une fenêtre active valide pour appeler glutExtensionSupported.

glutExtensionSupported ne renvoie des informations que sur les extensions OpenGL uniquement. Cela signifie que les extensions dépendant du système de fenêtrage (par exemple, les extensions GLX) ne sont pas signalées par glutExtensionSupported.

EXEMPLE

Voici un exemple d'utilisation de glutExtensionSupported :

  if (!glutExtensionSupported("GL_EXT_texture")) {
    fprintf(stderr, "Missing the texture extension!\n");
    exit(1);
  }
Notez que l'argument name inclut à la fois le préfixe GL et le préfixe de famille d'extensions (EXT).
