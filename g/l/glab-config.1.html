NOM

glab-config - Gérer les paramètres de glab.

SYNTAXE

glab config [options]

DESCRIPTION

Gère les chaînes clé/valeur.

Paramètres actuellement pris en charge :

  • browser : S'il n'est pas défini, utilise le navigateur par défaut. Remplacez avec la variable d'environnement $BROWSER.
  • check_update : S'il est défini sur true, notifie des nouvelles versions de glab. Par défaut à true. Remplacez avec la variable d'environnement $GLAB_CHECK_UPDATE.
  • display_hyperlinks : S'il est défini sur true, et si un TTY est utilisé, affiche des hyperliens pour les listes de problèmes et de demandes de fusion. Par défaut à false.
  • editor : S'il n'est pas défini, utilise l'éditeur par défaut. Remplacez avec la variable d'environnement $EDITOR.
  • glab_pager : Votre commande de pager souhaitée, telle que 'less -R'.
  • glamour_style : Votre style de rendu Markdown souhaité. Les options sont dark, light, notty. Des styles personnalisés sont disponibles en utilisant glamour ⟨https://github.com/charmbracelet/glamour#styles⟩.
  • host : S'il n'est pas défini, utilise par défaut https://gitlab.com.
  • token : Votre jeton d'accès GitLab. Utilise par défaut les variables d'environnement.
  • visual : Prend le pas sur 'editor'. S'il n'est pas défini, utilise l'éditeur par défaut. Remplacez avec la variable d'environnement $VISUAL.

OPTIONS

-g, --global[=false] Utilise le fichier de configuration global.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Affiche l'aide pour cette commande.

VOIR AUSSI
