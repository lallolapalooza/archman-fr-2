NOM

glDebugMessageControl - contrôle le signalement des messages de débogage dans un contexte de débogage

SPÉCIFICATION C

void glDebugMessageControl(GLenumsource, GLenumtype, GLenumseverity, GLsizeicount, const GLuint *ids, GLbooleanenabled);

PARAMÈTRES

source

La source des messages de débogage à activer ou désactiver.

type

Le type des messages de débogage à activer ou désactiver.

severity

La gravité des messages de débogage à activer ou désactiver.

count

La longueur du tableau ids.

ids

L'adresse d'un tableau d'entiers non signés contenant les identifiants des messages à activer ou désactiver.

enabled

Un drapeau booléen déterminant si les messages sélectionnés doivent être activés ou désactivés.

DESCRIPTION

glDebugMessageControl contrôle le signalement des messages de débogage générés par un contexte de débogage. Les paramètres source, type et severity forment un filtre pour sélectionner des messages parmi l'ensemble des messages potentiels générés par le GL.

source peut être GL_DEBUG_SOURCE_API, GL_DEBUG_SOURCE_WINDOW_SYSTEM_, GL_DEBUG_SOURCE_SHADER_COMPILER, GL_DEBUG_SOURCE_THIRD_PARTY, GL_DEBUG_SOURCE_APPLICATION, GL_DEBUG_SOURCE_OTHER pour sélectionner les messages générés respectivement par l'utilisation de l'API GL, le système de fenêtrage, le compilateur de shaders, des outils ou bibliothèques tiers, explicitement par l'application ou par une autre source. Il peut aussi prendre la valeur GL_DONT_CARE. Si source n'est pas GL_DONT_CARE alors seuls les messages dont la source correspond à source seront référencés.

type peut être l'une des valeurs suivantes GL_DEBUG_TYPE_ERROR, GL_DEBUG_TYPE_DEPRECATED_BEHAVIOR, GL_DEBUG_TYPE_UNDEFINED_BEHAVIOR, GL_DEBUG_TYPE_PORTABILITY, GL_DEBUG_TYPE_PERFORMANCE, GL_DEBUG_TYPE_MARKER, GL_DEBUG_TYPE_PUSH_GROUP, GL_DEBUG_TYPE_POP_GROUP, ou GL_DEBUG_TYPE_OTHER pour indiquer le type de messages décrivant respectivement les erreurs GL, la tentative d'utilisation de fonctionnalités obsolètes, le déclenchement de comportements indéfinis, les problèmes de portabilité, les notifications de performance, les marqueurs, les événements de pile de groupes (push et pop) et d'autres types de messages. Il peut aussi prendre la valeur GL_DONT_CARE. Si type n'est pas GL_DONT_CARE alors seuls les messages dont le type correspond à type seront référencés.

severity peut être l'une des valeurs suivantes GL_DEBUG_SEVERITY_LOW, GL_DEBUG_SEVERITY_MEDIUM, ou GL_DEBUG_SEVERITY_HIGH pour sélectionner les messages de gravité faible, moyenne ou élevée, ou GL_DEBUG_SEVERITY_NOTIFICATION pour les notifications. Il peut aussi prendre la valeur GL_DONT_CARE. Si severity n'est pas GL_DONT_CARE alors seuls les messages dont la gravité correspond à severity seront référencés.

ids contient une liste de count identifiants de messages pour sélectionner des messages spécifiques parmi l'ensemble des messages disponibles. Si count est zéro alors la valeur de ids est ignorée. Sinon, seuls les messages apparaissant dans cette liste sont sélectionnés. Dans ce cas, source et type ne peuvent pas être GL_DONT_CARE et severity doit être GL_DONT_CARE.

Si enabled est GL_TRUE alors les messages qui correspondent au filtre formé par source, type, severity et ids sont activés. Sinon, ces messages sont désactivés.

NOTES

Bien que les messages de débogage puissent être activés dans un contexte non débogage, la quantité et le détail de ces messages peuvent être nettement inférieurs à ceux d'un contexte de débogage. En particulier, une implémentation valide de la file d'attente des messages de débogage dans un contexte non débogage peut ne produire aucun message.

GL_DEBUG_TYPE_MARKER, GL_DEBUG_TYPE_PUSH_GROUP, GL_DEBUG_TYPE_POP_GROUP, et GL_DEBUG_SEVERITY_NOTIFICATION ne sont disponibles que si la version du GL est 4.3 ou supérieure.

ERREUR

GL_INVALID_VALUE est généré si count est négatif.

GL_INVALID_ENUM est généré si l'une des valeurs source, type ou severity n'est pas l'un des types d'interface acceptés.

GL_INVALID_OPERATION est généré si count est non nul et soit source soit type est GL_DONT_CARE , ou si severity n'est pas GL_DONT_CARE.
