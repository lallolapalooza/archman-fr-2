NOM

glDebugMessageCallback - spécifier une fonction de rappel pour recevoir les messages de débogage de GL

SPÉCIFICATION EN C

void glDebugMessageCallback(DEBUGPROC callback, const void * userParam);

PARAMÈTRES

callback

L'adresse d'une fonction de rappel qui sera appelée lorsqu'un message de débogage est généré.

userParam

Un pointeur fourni par l'utilisateur qui sera passé à chaque invocation de callback.

DESCRIPTION

glDebugMessageCallback définit la fonction de rappel de sortie de débogage actuelle comme étant la fonction dont l'adresse est fournie dans callback. La fonction de rappel doit avoir le prototype suivant (en C), ou être autrement compatible avec un tel prototype :

        typedef void (APIENTRY *DEBUGPROC)(GLenum source,
            GLenum type,
            GLuint id,
            GLenum severity,
            GLsizei length,
            const GLchar *message,
            const void *userParam);

Cette fonction est définie pour avoir la même convention d'appel que les fonctions de l'API GL. Dans la plupart des cas, elle est définie comme APIENTRY, bien que cela varie en fonction de la plateforme, du langage et du compilateur.

Chaque fois qu'un message de débogage est généré, la fonction de rappel de débogage sera appelée avec source, type, id, et severity associés au message, et length défini sur la longueur du message de débogage dont la chaîne de caractères est dans le tableau pointé par message. userParam sera défini sur la valeur passée dans le paramètre userParam lors du dernier appel à glDebugMessageCallback.

NOTES

Lorsque GL est utilisé à distance, le serveur peut ne pas être en mesure d'appeler des fonctions dans l'espace d'adressage du client. Dans de tels cas, la fonction de rappel peut ne pas être invoquée et l'utilisateur doit récupérer les messages de débogage du journal des messages de débogage du contexte en appelant glGetDebugMessageLog().
