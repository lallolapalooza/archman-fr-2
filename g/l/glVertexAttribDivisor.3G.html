NOM

glVertexAttribDivisor - modifier la fréquence à laquelle les attributs de sommets génériques avancent lors du rendu d'instances

SPÉCIFICATION C

void glVertexAttribDivisor(GLuint index, GLuint divisor);

PARAMÈTRES

index

Spécifie l'index de l'attribut de sommet générique.

divisor

Spécifie le nombre d'instances qui passeront entre les mises à jour de l'attribut générique à l'emplacement index.

DESCRIPTION

glVertexAttribDivisor modifie la fréquence à laquelle les attributs de sommets génériques avancent lors du rendu de plusieurs instances de primitives en un seul appel de dessin. Si divisor est zéro, l'attribut à l'emplacement index avance une fois par sommet. Si divisor est différent de zéro, l'attribut avance une fois par divisor instances de l'ensemble (ou des ensembles) de sommets rendus. Un attribut est dit instancié si sa valeur GL_VERTEX_ATTRIB_ARRAY_DIVISOR est différente de zéro.

index doit être inférieur à la valeur de GL_MAX_VERTEX_ATTRIBS.

NOTES

glVertexAttribDivisor n'est disponible que si la version de GL est 3.3 ou supérieure.

ERREURS

GL_INVALID_VALUE est généré si index est supérieur ou égal à la valeur de GL_MAX_VERTEX_ATTRIBS.
