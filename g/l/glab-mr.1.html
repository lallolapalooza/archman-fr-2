NOM

glab-mr - Créer, visualiser et gérer les demandes de fusion.

SYNOPIS

glab mr [options]

DESCRIPTION

Créer, visualiser et gérer les demandes de fusion.

OPTIONS

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser soit le format PROPRIÉTAIRE/DÉPÔT, soit GROUPE/ESPACEDE_NOMMAGE/DÉPÔT. Accepte également une URL complète ou une URL Git.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab mr create --fill --label bugfix
$ glab mr merge 123
$ glab mr note -m "doit faire X avant d'être fusionné" branch-foo
