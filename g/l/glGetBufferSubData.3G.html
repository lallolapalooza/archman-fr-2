DESCRIPTIO

N

glGetBufferSubData et glGetNamedBufferSubData renvoient une partie ou la totalité du contenu des données du magasin de données de l'objet tampon spécifié. Les données commençant à l'offset d'octet offset et s'étendant sur size octets sont copiées du magasin de données de l'objet tampon vers la mémoire pointée par data. Une erreur est levée si l'objet tampon est actuellement mappé, ou si offset et size définissent ensemble une plage dépassant l

es limites du magasin de
données de l'objet tampon.

REMARQUE

S

Si une erreur est générée, aucune modification n'est apportée au contenu de data

.

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version de GL est 4.2 ou

supérieure.

Les cibles GL_DISPATCH_INDIRECT_BUFFER et GL_SHADER_STORAGE_BUFFER ne sont disponibles que si la version de GL est 4.3 ou

supérieure.

La cible GL_QUERY_BUFFER n'est disponible que s

i la version de GL
est 4.4 ou supérieure.

ERREUR

S

GL_INVALID_ENUM est généré par glGetBufferSubData si target n'est pas l'une des cibles génériques de liaison de

tampon.

GL_INVALID_OPERATION est généré par glGetBufferSubData si zéro est lié à target

.

GL_INVALID_OPERATION est généré par glGetNamedBufferSubData si buffer n'est pas le nom d'un objet tampon

existant.

GL_INVALID_VALUE est généré si offset ou size est négatif, ou si $offset + size$ est supérieur à la valeur de GL_BUFFER_SIZE pour l'objet

tampon.

GL_INVALID_OPERATION est généré si l'objet tampon est mappé avec glMapBufferRange() ou glMapBuffer(), sauf s'il a été mappé avec le bit GL_MAP_PERSISTENT_BIT défini dans les drapeaux d'accès glMapBufferRang

e
.
