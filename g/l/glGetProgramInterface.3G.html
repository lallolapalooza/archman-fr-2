NOM

glGetProgramInterface - interroger une propriété d'une interface dans un programme

SPÉCIFICATION C

void glGetProgramInterfaceiv(GLuintprogram, GLenumprogramInterface, GLenumpname, GLint *params);

PARAMÈTRES

program

Le nom d'un objet programme dont on veut interroger l'interface.

programInterface

Un jeton identifiant l'interface à interroger dans program .

pname

Le nom du paramètre à interroger dans programInterface .

params

L'adresse d'une variable où récupérer la valeur de pname pour l'interface du programme.

DESCRIPTION

glGetProgramInterfaceiv interroge la propriété de l'interface identifiée par programInterface dans program, dont le nom de propriété est donné par pname.

program doit être le nom d'un objet programme existant. programInterface est le nom de l'interface dans program à interroger et doit être l'une des valeurs suivantes :

GL_UNIFORM

La requête porte sur l'ensemble des uniformes actifs dans program.

GL_UNIFORM_BLOCK

La requête porte sur l'ensemble des blocs d'uniformes actifs dans program.

GL_ATOMIC_COUNTER_BUFFER

La requête porte sur l'ensemble des points de liaison de tampons de compteurs atomiques actifs dans program.

GL_PROGRAM_INPUT

La requête porte sur l'ensemble des variables d'entrée actives utilisées par le premier étage de shader de program. Si program contient plusieurs étages de shader, les variables d'entrée de tout étage autre que le premier ne seront pas énumérées.

GL_PROGRAM_OUTPUT

La requête porte sur l'ensemble des variables de sortie actives produites par le dernier étage de shader de program. Si program contient plusieurs étages de shader, les variables de sortie de tout étage autre que le dernier ne seront pas énumérées.

GL_VERTEX_SUBROUTINE, GL_TESS_CONTROL_SUBROUTINE, GL_TESS_EVALUATION_SUBROUTINE, GL_GEOMETRY_SUBROUTINE, GL_FRAGMENT_SUBROUTINE, GL_COMPUTE_SUBROUTINE

La requête porte sur l'ensemble des sous-routines actives pour les étages de shader de sommet, de contrôle de tessellation, d'évaluation de tessellation, de géométrie, de fragment et de calcul de program, respectivement.

GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, GL_COMPUTE_SUBROUTINE_UNIFORM

La requête porte sur l'ensemble des variables uniformes de sous-routine actives utilisées par les étages de shader de sommet, de contrôle de tessellation, d'évaluation de tessellation, de géométrie, de fragment et de calcul de program, respectivement.

GL_TRANSFORM_FEEDBACK_VARYING

La requête porte sur l'ensemble des variables de sortie du dernier étage non fragment de program qui seraient capturées si la transformation par rétroaction était active.

GL_BUFFER_VARIABLE

La requête porte sur l'ensemble des variables de tampon actives utilisées par program.

GL_SHADER_STORAGE_BLOCK

La requête porte sur l'ensemble des blocs de stockage de shader actifs utilisés par program.

GL_TRANSFORM_FEEDBACK_BUFFER

La requête porte sur l'ensemble des points de liaison de tampon actifs vers lesquels les variables de sortie de l'interface GL_TRANSFORM_FEEDBACK_VARYING sont écrites.

pname identifie la propriété de programInterface à retourner dans params.

Si pname est GL_ACTIVE_RESOURCES, la valeur retournée est le nombre de ressources dans la liste des ressources actives pour programInterface. Si la liste des ressources actives pour programInterface est vide, zéro est retourné.

Si pname est GL_MAX_NAME_LENGTH, la valeur retournée est la longueur de la chaîne de nom active la plus longue pour une ressource active dans programInterface. Cette longueur inclut un caractère supplémentaire pour le terminateur nul. Si la liste des ressources actives pour programInterface est vide, zéro est retourné. Il est une erreur de spécifier GL_MAX_NAME_LENGTH lorsque programInterface est GL_ATOMIC_COUNTER_BUFFER, car les ressources de tampon de compteurs atomiques actifs ne se voient pas attribuer de chaînes de nom.

Si pname est GL_MAX_NUM_ACTIVE_VARIABLES, la valeur retournée est le nombre de variables actives appartenant au bloc d'interface ou à la ressource de tampon de compteurs atomiques dans programInterface ayant le plus grand nombre de variables actives. Si la liste des ressources actives pour programInterface est vide, zéro est retourné. Lorsque pname est GL_MAX_NUM_ACTIVE_VARIABLES, programInterface doit être GL_UNIFORM_BLOCK, GL_ATOMIC_COUNTER_BUFFER, ou GL_SHADER_STORAGE_BLOCK.

Si pname est GL_MAX_NUM_COMPATIBLE_SUBROUTINES, la valeur retournée est le nombre de sous-routines compatibles appartenant à la variable uniforme de sous-routine active dans programInterface ayant le plus grand nombre de sous-routines compatibles. Si la liste des ressources actives pour programInterface est vide, zéro est retourné. Lorsque pname est GL_MAX_NUM_COMPATIBLE_SUBROUTINES, programInterface doit être l'une des valeurs suivantes : GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, ou GL_COMPUTE_SUBROUTINE_UNIFORM.

ERREURS

GL_INVALID_ENUM est généré si identifier n'est pas l'un des types d'objets acceptés.

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet de synchronisation existant.

GL_INVALID_VALUE est généré si bufSize est zéro.

GL_INVALID_OPERATION est généré si pname est GL_MAX_NAME_LENGTH et programInterface est GL_ATOMIC_COUNTER_BUFFER ou GL_TRANSFORM_FEEDBACK_BUFFER, car les ressources de tampon de compteurs atomiques et de transformation par rétroaction actifs ne se voient pas attribuer de chaînes de nom.

L'erreur GL_INVALID_OPERATION est générée si pname est GL_MAX_NUM_ACTIVE_VARIABLES et programInterface n'est pas GL_UNIFORM_BLOCK, GL_SHADER_STORAGE_BLOCK, GL_ATOMIC_COUNTER_BUFFER, ou GL_TRANSFORM_FEEDBACK_BUFFER.

Si ce n'est pas NULL, length et label doivent être des adresses auxquelles le client a un accès en écriture, sinon un comportement indéfini, y compris la terminaison du processus, peut survenir.

ACCÈS ASSOCIÉS

glGet() avec l'argument GL_MAX_LABEL_LENGTH.
