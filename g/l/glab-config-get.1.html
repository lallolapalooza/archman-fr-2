NOM

glab-config-get - Affiche la valeur d'une clé de configuration donnée.

SYNTAXE

glab config get [indicateurs]

DESCRIPTION

Affiche la valeur d'une clé de configuration donnée.

OPTIONS

-g, --global[=false] Lire à partir du fichier de configuration global (~/.config/glab-cli/config.yml). (par défaut, vérifie 'Variables d'environnement → Local → Global')

--host="" Obtenir le paramètre par hôte.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab config get editor
> vim
$ glab config get glamour_style
> notty
