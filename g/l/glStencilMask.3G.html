NOM

glStencilMask - contrôler l'écriture avant et arrière des bits individuels dans les plans de stencil

SPÉCIFICATION C

void glStencilMask(GLuint mask);

PARAMÈTRES

mask

Spécifie un masque binaire pour activer et désactiver l'écriture des bits individuels dans les plans de stencil. Initialement, le masque est constitué de tous les 1.

DESCRIPTION

glStencilMask contrôle l'écriture des bits individuels dans les plans de stencil. Les n bits de poids faible de mask, où n est le nombre de bits dans le tampon de stencil, spécifient un masque. Là où un 1 apparaît dans le masque, il est possible d'écrire dans le bit correspondant du tampon de stencil. Là où un 0 apparaît, le bit correspondant est protégé en écriture. Initialement, tous les bits sont activés pour l'écriture.

Il peut y avoir deux masques d'écriture de stencil distincts ; l'un affecte les polygones dont la face est tournée vers l'arrière, et l'autre affecte les polygones dont la face est tournée vers l'avant ainsi que d'autres primitives non polygonales. glStencilMask() définit les deux masques d'écriture de stencil avant et arrière aux mêmes valeurs. Utilisez glStencilMaskSeparate() pour définir les masques d'écriture de stencil avant et arrière à des valeurs différentes.

NOTES

glStencilMask() est équivalent à appeler glStencilMaskSeparate() avec face défini sur GL_FRONT_AND_BACK.

GETS ASSOCIÉS

glGet() avec l'argument GL_STENCIL_WRITEMASK, GL_STENCIL_BACK_WRITEMASK, ou GL_STENCIL_BITS
