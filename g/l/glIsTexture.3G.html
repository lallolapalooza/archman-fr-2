NOM

glIsTexture - déterminer si un nom correspond à une texture

SPÉCIFICATION C

GLboolean glIsTexture(GLuint texture);

PARAMÈTRES

texture

Spécifie une valeur qui peut être le nom d'une texture.

DESCRIPTION

glIsTexture renvoie GL_TRUE si texture est actuellement le nom d'une texture. Si texture est zéro, ou s'il s'agit d'une valeur non nulle qui n'est pas actuellement le nom d'une texture, ou si une erreur se produit, glIsTexture renvoie GL_FALSE.

Un nom renvoyé par glGenTextures(), mais pas encore associé à une texture en appelant glBindTexture(), n'est pas le nom d'une texture.
