GLDRAWARRAYSINDIRECT(3G) [FIXME: manuel] GLDRAWARRAYSINDIRECT(3G)

NOM

glDrawArraysIndirect - dessine des primitives à partir de données de tableau, en prenant les paramètres en mémoire

SPÉCIFICATION C

void glDrawArraysIndirect(GLenum mode, const void *indirect);

PARAMÈTRES

mode

Spécifie le type de primitives à dessiner. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, et GL_PATCHES sont acceptées.

indirect

Spécifie l'adresse d'une structure contenant les paramètres de dessin.

DESCRIPTION

glDrawArraysIndirect spécifie plusieurs primitives géométriques avec très peu d'appels de sous-routine. glDrawArraysIndirect se comporte de manière similaire à glDrawArraysInstancedBaseInstance(), sauf que les paramètres de glDrawArraysInstancedBaseInstance() sont stockés en mémoire à l'adresse indiquée par indirect.

Les paramètres adressés par indirect sont regroupés dans une structure qui a la forme (en C) :

    typedef  struct {
        uint  count;
        uint  instanceCount;
        uint  first;
        uint  baseInstance;
    } DrawArraysIndirectCommand;
    const DrawArraysIndirectCommand *cmd = (const DrawArraysIndirectCommand *)indirect;
    glDrawArraysInstancedBaseInstance(mode, cmd->first, cmd->count, cmd->instanceCount, cmd->baseInstance);

Si un tampon est lié à la liaison GL_DRAW_INDIRECT_BUFFER au moment d'un appel à glDrawArraysIndirect, indirect est interprété comme un décalage, en unités machine de base, dans ce tampon et les données des paramètres sont lues depuis le tampon plutôt que depuis la mémoire client.

Contrairement à glDrawArraysInstancedBaseInstance(), le premier membre de la structure de paramètres est non signé, et les indices hors limites ne génèrent pas d'erreur.

Les attributs de sommet qui sont modifiés par glDrawArraysIndirect ont une valeur indéfinie après le retour de glDrawArraysIndirect. Les attributs qui ne sont pas modifiés restent bien définis.

NOTES

Le membre baseInstance de la structure DrawArraysIndirectCommand est défini uniquement si la version de GL est 4.2 ou supérieure. Pour les versions de GL antérieures à 4.2, ce paramètre est présent mais réservé et doit être mis à zéro. Dans les versions antérieures de GL, le comportement est indéfini s'il n'est pas nul.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_OPERATION est généré si un objet tampon non nul est lié à un tableau activé ou à la liaison GL_DRAW_INDIRECT_BUFFER et que le magasin de données de l'objet tampon est actuellement mappé.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si mode est GL_PATCHES et qu'aucun shader de contrôle de tessellation n'est actif.
