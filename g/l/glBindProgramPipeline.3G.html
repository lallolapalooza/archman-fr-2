NOM

glBindProgramPipeline - Lier un pipeline de programmes au contexte actuel

SPÉCIFICATION C

void glBindProgramPipeline(GLuint pipeline);

PARAMÈTRES

pipeline

Spécifie le nom du pipeline objet à lier au contexte.

DESCRIPTION

glBindProgramPipeline lie un pipeline d'objets programme au contexte actuel. pipeline doit être un nom retourné précédemment par un appel à glGenProgramPipelines(). Si aucun pipeline d'objet programme n'existe avec le nom pipeline, alors un nouvel objet pipeline est créé avec ce nom et initialisé à l'état par défaut.

Lorsqu'un objet pipeline de programmes est lié à l'aide de glBindProgramPipeline, toute liaison précédente est rompue et remplacée par une liaison à l'objet pipeline spécifié. Si pipeline est zéro, la liaison précédente est rompue et non remplacée, ne laissant aucun objet pipeline lié. Si aucun objet programme actuel n'a été établi par glUseProgram(), les objets programmes utilisés pour chaque étape et pour les mises à jour des uniformes sont pris de l'objet pipeline de programmes lié, le cas échéant. S'il existe un objet programme actuel établi par glUseProgram(), l'objet pipeline de programmes lié n'a aucun effet sur le rendu ou les mises à jour des uniformes. Lorsqu'un objet pipeline de programmes lié est utilisé pour le rendu, les exécutables des shaders individuels sont pris de ses objets programmes.

ERREURS

GL_INVALID_OPERATION est généré si pipeline n'est pas zéro ou un nom retourné précédemment par un appel à glGenProgramPipelines() ou si un tel nom a été supprimé par un appel à glDeleteProgramPipelines().
