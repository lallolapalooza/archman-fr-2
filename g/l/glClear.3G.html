NOM

glClear - efface les tampons avec des valeurs prédéfinies

SPÉCIFICATION C

void glClear(GLbitfield mask);

PARAMÈTRES

mask

OU logique des masques indiquant les tampons à effacer. Les trois masques sont GL_COLOR_BUFFER_BIT, GL_DEPTH_BUFFER_BIT et GL_STENCIL_BUFFER_BIT.

DESCRIPTION

glClear définit la zone des plans de bits de la fenêtre avec les valeurs précédemment sélectionnées par glClearColor, glClearDepth et glClearStencil. Plusieurs tampons de couleur peuvent être effacés simultanément en sélectionnant plusieurs tampons à la fois avec glDrawBuffer().

Le test de propriété des pixels, le test de cisaillement, le tramage et le masque d'écriture des tampons affectent le fonctionnement de glClear. La boîte de cisaillement délimite la région effacée. La fonction alpha, la fonction de mélange, l'opération logique, le stencil, le mappage de texture et le tampon de profondeur sont ignorés par glClear.

glClear prend un seul argument qui est le OU logique de plusieurs valeurs indiquant quel tampon doit être effacé.

Les valeurs sont les suivantes :

GL_COLOR_BUFFER_BIT

Indique les tampons actuellement activés pour l'écriture de couleur.

GL_DEPTH_BUFFER_BIT

Indique le tampon de profondeur.

GL_STENCIL_BUFFER_BIT

Indique le tampon de stencil.

La valeur à laquelle chaque tampon est effacé dépend du paramètre de la valeur de clairage pour ce tampon.

NOTES

Si un tampon n'est pas présent, alors un glClear dirigé vers ce tampon n'a aucun effet.

ERREURS

GL_INVALID_VALUE est généré si un bit autre que les trois bits définis est défini dans mask.

ASSOCIÉES GETS

glGet() avec l'argument GL_DEPTH_CLEAR_VALUE

glGet() avec l'argument GL_COLOR_CLEAR_VALUE

glGet() avec l'argument GL_STENCIL_CLEAR_VALUE
