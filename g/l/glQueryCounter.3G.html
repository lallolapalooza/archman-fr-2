NOM

glQueryCounter - enregistre le temps GL dans un objet de requête après que toutes les commandes précédentes aient atteint le serveur GL mais pas nécessairement encore exécuté.

SPc CIFICATIONS

void glQueryCounter(GLuint id, GLenum target);

PARAMc TRES

id

Spécifie le nom d'un objet de requête dans lequel enregistrer le temps GL.

target

Spécifie le compteur à interroger. target doit être GL_TIMESTAMP.

DESCRIPTION

glQueryCounter demande au GL d'enregistrer l'heure actuelle dans l'objet de requête nommé id. target doit être GL_TIMESTAMP. L'heure est enregistrée après que toutes les commandes précédentes sur l'état du client et du serveur GL ainsi que le framebuffer aient été entièrement réalisées. Lorsque l'heure est enregistrée, le résultat de la requête pour cet objet est marqué comme disponible. Les requêtes de temps glQueryCounter peuvent être utilisées dans un bloc glBeginQuery() /

glEndQuery où la cible est GL_TIME_ELAPSED et cela n'affecte pas le résultat de cet objet de requête.

NOTES

glQueryCounter n'est disponible que si la version GL est 3.3 ou supérieure.

ERREURS

GL_INVALID_OPERATION est générée si id est le nom d'un objet de requête déjà en cours d'utilisation dans un bloc glBeginQuery() /

glEndQuery.

GL_INVALID_VALUE est générée si id n'est pas le nom d'un objet de requête retourné par un appel précédent à glGenQueries().

GL_INVALID_ENUM est générée si target n'est pas GL_TIMESTAMP.
