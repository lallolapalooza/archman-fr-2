NOM

glValidateProgram - Valide un objet programme

SPÉCIFICATION C

void glValidateProgram(GLuint program);

PARAMÈTRES

program

Spécifie le descripteur de l'objet programme à valider.

DESCRIPTION

glValidateProgram vérifie si les exécutables contenus dans program peuvent s'exécuter compte tenu de l'état OpenGL actuel. Les informations générées par le processus de validation seront stockées dans le journal d'informations de program. Les informations de validation peuvent consister en une chaîne vide, ou être une chaîne contenant des informations sur la manière dont l'objet programme actuel interagit avec le reste de l'état OpenGL actuel. Cela permet aux implémenteurs OpenGL de fournir plus d'informations sur les raisons pour lesquelles le programme actuel est inefficace, sous-optimal, ne parvient pas à s'exécuter, etc.

Le statut de l'opération de validation sera stocké comme faisant partie de l'état de l'objet programme. Cette valeur sera définie sur GL_TRUE si la validation a réussi, et GL_FALSE sinon. Elle peut être interrogée en appelant glGetProgram() avec les arguments program et GL_VALIDATE_STATUS. Si la validation réussit, program est garanti d'exécution compte tenu de l'état actuel. Sinon, program est garanti de ne pas s'exécuter.

Cette fonction est généralement utile uniquement pendant le développement de l'application. La chaîne informative stockée dans le journal d'informations dépend entièrement de l'implémentation ; par conséquent, une application ne doit pas s'attendre à ce que différentes implémentations OpenGL produisent des chaînes d'informations identiques.

NOTES

Cette fonction imite l'opération de validation que les implémentations OpenGL doivent effectuer lorsque des commandes de rendu sont émises alors que des shaders programmables font partie de l'état actuel. L'erreur GL_INVALID_OPERATION sera générée par toute commande qui déclenche le rendu de géométrie si :

• deux échantillonneurs actifs dans l'objet programme actuel sont de types différents, mais font référence à la même unité de texture,
• le nombre d'échantillonneurs actifs dans le programme dépasse le nombre maximal d'unités de texture autorisées.

Il peut être difficile ou causer une dégradation des performances pour les applications d'intercepter ces erreurs lorsque des commandes de rendu sont émises. Par conséquent, il est conseillé aux applications d'appeler glValidateProgram pour détecter ces problèmes pendant le développement de l'application.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si program n'est pas un objet programme.

GETS ASSOCIÉS

glGetProgram() avec les arguments program et GL_VALIDATE_STATUS

glGetProgramInfoLog() avec l'argument program

glIsProgram()
