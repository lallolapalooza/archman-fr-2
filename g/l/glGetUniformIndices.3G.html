NOM

glGetUniformIndices - récupérer l'index d'un bloc uniforme nommé

SPÉCIFICATION C

void glGetUniformIndices(GLuint program, GLsizei uniformCount, const GLchar **uniformNames, GLuint *uniformIndices);

PARAMÈTRES

program

Spécifie le nom d'un programme contenant les uniformes dont les indices doivent être interrogés.

uniformCount

Spécifie le nombre d'uniformes dont les indices doivent être interrogés.

uniformNames

Spécifie l'adresse d'un tableau de pointeurs vers des tampons contenant les noms des uniformes interrogés.

uniformIndices

Spécifie l'adresse d'un tableau qui recevra les indices des uniformes.

DESCRIPTION

glGetUniformIndices récupère les indices d'un certain nombre d'uniformes dans program.

program doit être le nom d'un objet programme pour lequel la commande glLinkProgram() doit avoir été appelée par le passé, bien qu'il ne soit pas obligatoire que glLinkProgram() ait réussi. Le lien a pu échouer car le nombre d'uniformes actifs a dépassé la limite.

uniformCount indique à la fois le nombre d'éléments dans le tableau de noms uniformNames et le nombre d'indices qui peuvent être écrits dans uniformIndices.

uniformNames contient une liste de uniformCount chaînes de noms identifiant les noms d'uniformes dont les indices doivent être interrogés. Pour chaque chaîne de noms dans uniformNames, l'indice attribué à l'uniforme actif de ce nom sera écrit dans l'élément correspondant de uniformIndices. Si une chaîne dans uniformNames n'est pas le nom d'un uniforme actif, la valeur spéciale GL_INVALID_INDEX sera écrite dans l'élément correspondant de uniformIndices.

En cas d'erreur, rien n'est écrit dans uniformIndices.

ERREURS

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un objet programme pour lequel glLinkProgram() a été appelée par le passé.

NOTES

glGetUniformIndices n'est disponible que si la version de GL est 3.1 ou supérieure.
