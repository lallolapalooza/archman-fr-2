DESCRIPTIO

N

Ces fonctions renvoient dans data un paramètre sélectionné de l'objet tampon

spécifié.

pname nomme un paramètre spécifique de l'objet tampon, comme suit

:

GL_BUFFER_ACCES

S
params renvoie la politique d'accès définie lors du mappage de l'objet tampon (la valeur du paramètre enum access passé à glMapBuffer). Si le tampon a été mappé avec glMapBufferRange, la politique d'accès est déterminée en traduisant les bits de ce paramètre access vers l'un des énumérations pris en charge pour glMapBuffer comme décrit dans la spécification
OpenGL.

GL_BUFFER_ACCESS_FLAG

S
params renvoie la politique d'accès définie lors du mappage de l'objet tampon (la valeur du champ de bits paramètre access passé à glMapBufferRange). Si le tampon a été mappé avec glMapBuffer, la politique d'accès est déterminée en traduisant les énumérations de ce paramètre access vers les bits correspondants pour glMapBufferRange comme décrit dans la spécification OpenGL. La valeur initiale est
zéro.

GL_BUFFER_IMMUTABLE_STORAG

E
params renvoie un indicateur booléen indiquant si l'objet tampon est immuable. La valeur initiale est GL_FALSE
.

GL_BUFFER_MAPPE

D
params renvoie un indicateur indiquant si l'objet tampon est actuellement mappé. La valeur initiale est GL_FALSE
.

GL_BUFFER_MAP_LENGT

H
params renvoie la longueur du mappage dans l'objet tampon établi avec glMapBuffer*. Les versions i64v de ces requêtes doivent être utilisées pour ce paramètre. La valeur initiale est
zéro.

GL_BUFFER_MAP_OFFSE

T
params renvoie le décalage du mappage dans l'objet tampon établi avec glMapBuffer*. Les versions i64v de ces requêtes doivent être utilisées pour ce paramètre. La valeur initiale est
zéro.

GL_BUFFER_SIZ

E
params renvoie la taille de l'objet tampon, mesurée en octets. La valeur initiale est
0.

GL_BUFFER_STORAGE_FLAG

S
params renvoie un champ de bits indiquant les drapeaux de stockage pour l'objet tampon. Si l'objet tampon est immuable, la valeur renvoyée sera celle spécifiée lorsque le magasin de données a été établi avec glBufferStorage. Si le magasin de données a été établi avec glBufferData, la valeur sera GL_MAP_READ_BIT | GL_MAP_WRITE_BIT | GL_DYNAMIC_STORAGE_BIT | GL_MAP_WRITE_BIT. La valeur initiale est
zéro.

GL_BUFFER_USAG

E
params renvoie le motif d'utilisation de l'objet tampon. La valeur initiale est GL_STATIC_DRA
W
.

REMARQUE

S

Si une erreur est générée, aucune modification n'est apportée au contenu de data

.

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version GL est 4.2 ou

supérieure.

Les cibles GL_DISPATCH_INDIRECT_BUFFER et GL_SHADER_STORAGE_BUFFER ne sont disponibles que si la version GL est 4.3 ou

supérieure.

La cible GL_QUERY_BUFFER n'est disponible que

si la version GL
est 4.4 ou supérieure.

ERREU

R

GL_INVALID_ENUM est généré par glGetBufferParameter* si target n'est pas l'une des cibles de tampon

acceptées.

GL_INVALID_OPERATION est généré par glGetBufferParameter* si zéro est lié à target

.

GL_INVALID_OPERATION est généré par glGetNamedBufferParameter* si buffer n'est pas le nom d'un objet tampon

existant.

GL_INVALID_ENUM est généré si pname n'est pas l'un des noms de par

amètres d'objet tampo
n décrits ci-dessus.
