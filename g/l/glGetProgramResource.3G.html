NOM

glGetProgramResource - récupère les valeurs de plusieurs propriétés d'une seule ressource active dans un objet programme

SPÉCIFICATION C

void glGetProgramResourceiv(GLuint program, GLenum programInterface, GLuint index, GLsizei propCount, const GLenum * props, GLsizei bufSize, GLsizei * length, GLint * params);

PARAMÈTRES

program

Le nom d'un objet programme dont les ressources doivent être interrogées.

programInterface

Un jeton identifiant l'interface dans program contenant la ressource nommée name.

DESCRIPTION

glGetProgramResourceiv retourne les valeurs de plusieurs propriétés d'une seule ressource active avec l'index index dans l'interface programInterface de l'objet programme program. Pour chaque ressource, les valeurs de propCount propriétés spécifiées par le tableau props sont retournées. propCount ne peut pas être zéro. Une erreur est générée si une valeur dans props n'est pas l'une des propriétés décrites ci-dessous ou si une valeur dans props n'est pas autorisée pour programInterface. L'ensemble des valeurs programInterface autorisées pour chaque propriété se trouve dans le tableau suivant :

Pour la propriété GL_NAME_LENGTH, un seul entier identifiant la longueur de la chaîne de nom associée à une variable active, un bloc d'interface ou une sous-routine est écrit dans params. La longueur du nom inclut un caractère nul de fin.

Pour la propriété GL_TYPE, un seul entier identifiant le type d'une variable active est écrit dans params. L'entier retourné est l'une des valeurs trouvées dans le tableau 2.16.

Pour la propriété GL_ARRAY_SIZE, un seul entier identifiant le nombre d'éléments de tableau actifs d'une variable active est écrit dans params. La taille du tableau retournée est en unités du type associé à la propriété GL_TYPE. Pour les variables actives ne correspondant pas à un tableau de types de base, la valeur zéro est écrite dans params.

Pour la propriété GL_BLOCK_INDEX, un seul entier identifiant l'index du bloc d'interface actif contenant une variable active est écrit dans params. Si la variable n'est pas membre d'un bloc d'interface, la valeur -1 est écrite dans params.

Pour la propriété GL_OFFSET, un seul entier identifiant le décalage d'une variable active est écrit dans params. Pour les variables dans les interfaces GL_UNIFORM et GL_BUFFER_VARIABLE qui sont soutenues par un objet tampon, la valeur écrite est le décalage de cette variable par rapport à la base de la plage du tampon contenant sa valeur. Pour la propriété GL_ARRAY_STRIDE, un entier unique identifiant le pas entre les éléments d'un tableau dans une variable active est écrit dans params. Pour les variables actives déclarées comme un tableau de types de base, la valeur écrite est la différence, en unités machine de base, entre les décalages des éléments consécutifs dans un tableau. Pour les variables actives non déclarées comme un tableau de types de base, zéro est écrit dans params. Pour les variables actives non soutenues par un objet tampon, -1 est écrit dans params, quel que soit le type de la

variable.

Pour la propriété GL_MATRIX_STRIDE, un entier unique identifiant le pas entre les colonnes d'une matrice en ordre colonne ou les lignes d'une matrice en ordre ligne est écrit dans params. Pour les variables actives déclarées comme une matrice unique ou un tableau de matrices, la valeur écrite est la différence, en unités machine de base, entre les décalages des colonnes ou lignes consécutives dans chaque matrice. Pour les variables actives non déclarées comme une matrice ou un tableau de matrices, zéro est écrit dans params. Pour les variables actives non soutenues par un objet tampon, -1 est écrit dans params, quel que soit le type de la

variable.

Pour la propriété GL_IS_ROW_MAJOR, un entier unique identifiant si une variable active est une matrice en ordre ligne est écrit dans params. Pour les variables actives soutenues par un objet tampon, déclarées comme une matrice unique ou un tableau de matrices, et stockées en ordre ligne, un est écrit dans params. Pour toutes les autres variables actives, zéro est écrit dans params

.

Pour la propriété GL_ATOMIC_COUNTER_BUFFER_INDEX, un entier unique identifiant l'index du tampon de compteurs atomiques actif contenant une variable active est écrit dans params. Si la variable n'est pas un uniforme de compteur atomique, la valeur -1 est écrite dans params

.

Pour la propriété GL_BUFFER_BINDING, l'index du point de liaison de tampon associé au bloc uniforme actif, au bloc de stockage de shader, au tampon de compteurs atomiques ou au tampon de retour de transformation est écrit dans params

.

Pour la propriété GL_BUFFER_DATA_SIZE, la taille totale minimale du tampon, dépendant de l'implémentation, en unités machine de base, requise pour contenir toutes les variables actives associées à un bloc uniforme actif, un bloc de stockage de shader ou un tampon de compteurs atomiques est écrite dans params. Si le dernier membre d'un bloc de stockage de shader actif est un tableau sans taille déclarée, la taille minimale du tampon est calculée en supposant que le tableau a été déclaré comme un tableau d'un

élément.

Pour la propriété GL_NUM_ACTIVE_VARIABLES, le nombre de variables actives associées à un bloc uniforme actif, un bloc de stockage de shader, un tampon de compteurs atomiques ou un tampon de retour de transformation est écrit dans params

.

Pour la propriété GL_ACTIVE_VARIABLES, un tableau d'index de variables actives associées à un bloc uniforme actif, un bloc de stockage de shader, un tampon de compteurs atomiques ou un tampon de retour de transformation est écrit dans params. Le nombre de valeurs écrites dans params pour une ressource active est donné par la valeur de la propriété GL_NUM_ACTIVE_VARIABLES pour la

ressource.

Pour les propriétés GL_REFERENCED_BY_VERTEX_SHADER, GL_REFERENCED_BY_TESS_CONTROL_SHADER, GL_REFERENCED_BY_TESS_EVALUATION_SHADER, GL_REFERENCED_BY_GEOMETRY_SHADER, GL_REFERENCED_BY_FRAGMENT_SHADER, et GL_REFERENCED_BY_COMPUTE_SHADER, un entier unique est écrit dans params, identifiant si la ressource active est référencée par les shaders de sommet, de contrôle de tessellation, d'évaluation de tessellation, de géométrie ou de fragment, respectivement, dans l'objet programme. La valeur un est écrite dans params si une variable active est référencée par le shader correspondant, ou si un bloc uniforme actif, un bloc de stockage de shader ou un tampon de compteurs atomiques contient au moins une variable référencée par le shader correspondant. Sinon, la valeur zéro est écrite dans params

.

Pour la propriété GL_TOP_LEVEL_ARRAY_SIZE, un entier unique identifiant le nombre d'éléments actifs du tableau du membre de niveau supérieur du bloc de stockage de shader contenant la variable active est écrit dans params. Si le membre de niveau supérieur du bloc n'est pas déclaré comme un tableau, la valeur un est écrite dans params. Si le membre de niveau supérieur du bloc est un tableau sans taille déclarée, la valeur zéro est écrite dans params

.

Pour la propriété GL_TOP_LEVEL_ARRAY_STRIDE, un entier unique identifiant le pas entre les éléments du tableau du membre de niveau supérieur du bloc de stockage de shader contenant la variable active est écrit dans params. Pour les membres de niveau supérieur du bloc déclarés comme des tableaux, la valeur écrite est la différence, en unités machine de base, entre les décalages de la variable active pour les éléments consécutifs dans le tableau de niveau supérieur. Pour les membres de niveau supérieur du bloc non déclarés comme un tableau, zéro est écrit dans params

.

Pour la propriété GL_LOCATION, un entier unique identifiant l'emplacement assigné pour une variable uniforme active, d'entrée, de sortie ou de sous-routine est écrit dans params. Pour les variables d'entrée, de sortie ou uniformes dont les emplacements sont spécifiés par un qualificateur de disposition, l'emplacement spécifié est utilisé. Pour les variables d'entrée de shader de sommet ou de sortie de shader de fragment sans qualificateur de disposition, l'emplacement assigné lors de la liaison d'un programme est écrit dans params. Pour toutes les autres variables d'entrée et de sortie, la valeur -1 est écrite dans params. Pour les uniformes dans des blocs uniformes, la valeur -1 est écrite dans params

.

Pour la propriété GL_LOCATION_INDEX, un entier unique identifiant l'index de couleur de fragment d'une variable de sortie de shader de fragment active est écrit dans params. Si la variable active est une sortie pour un shader non fragment, la valeur -1 sera écrite dans params

.

Pour la propriété GL_IS_PER_PATCH, un entier unique identifiant si l'entrée ou la sortie est un attribut par patch. Si la variable active est un attribut par patch (déclarée avec le qualificateur patch), la valeur un est écrite dans params ; sinon, la valeur zéro est écrite dans params

.

Pour la propriété GL_LOCATION_COMPONENT, un entier unique indiquant le premier composant de l'emplacement assigné à une variable d'entrée ou de sortie active est écrit dans params. Pour les variables d'entrée et de sortie dont un composant est spécifié par un qualificateur de disposition, le composant spécifié est écrit. Pour toutes les autres variables d'entrée et de sortie, la valeur zéro est

écrite.

Pour la propriété GL_TRANSFORM_FEEDBACK_BUFFER_INDEX, un entier unique identifiant l'index du tampon de retour de transformation actif associé à une variable active est écrit dans params. Pour les variables correspondant aux noms spéciaux "gl_NextBuffer", "gl_SkipComponents1", "gl_SkipComponents2", "gl_SkipComponents3", et "gl_SkipComponents4", -1 est écrit dans params

.
