DESCRIPTIO

N

Le fichier de configuration de glHack stocke les paramètres pour les options NetHack standard (comme « hilite_pet ») ainsi que pour les options spécifiques à glHack (comme « keyrepeat »). Les options qui prennent une valeur seront montrées ici avec des valeurs

d'exemple.

Le fichier de configuration est toujours ~/.g

lha
ckrc

FORMA

T

Le format est un sur-ensemble du format du fichier de configuration standard de NetHack (.nethackrc). Les lignes commençant par une dièse (`#') sont des commentaires et sont ignorées. Les lignes vides sont également ignorées. Les lignes restantes ont la forme

:
MOTCLEF=data..
.

(Les mots-clés sont en majuscules par convention, mais ce n'est pas obligatoire). Les deux principaux mots-clés sont OPTIONS et GL_OPTIONS. Le premier est utilisé pour les options NetHack standard, et le second est nouveau et est utilisé pour les options spécifiques à glHack. NetHack définit également quelques mots-clés supplémentaires : DUNGEON, EFFECTS, MONSTERS, TRAPS et BOULDER, qui ont peu de pertinence pour glHack car ils ne contrôlent que la vue de la carte

textuelle.

Les données après le signe `=' dépendent du mot-clé. Pour les deux OPTIONS et GL_OPTIONS, les données consistent en un ou plusieurs noms d'options (éventuellement avec des valeurs) séparés par des virgules (`,'). Un deux-points (`:') est utilisé entre un nom d'option et sa valeur. Par exemple

:
GL_OPTIONS=windowed,depth:
32

contient deux options glHack : « windowed » (sans aucune valeur), et « depth » (avec la valeur « 32 »)

.

Les options peuvent être booléennes, entières ou chaînes de caractères. Les options booléennes sont a

ctivées simplement en incluant leur nom, et sont désactivées en utilisant un point d'exclamation (`!'
) avant leur nom (par ex. « !windowed »). Les valeurs de chaîne ne doivent pas être entre guillemets.

OPTIONS

GLHACK

Ces options doivent apparaître après le mot-clé GL_OPTIONS

:
mode:
1024x768
Utilise le mode vidéo spécifié. Normalement, glHack détectera automatiquement le mode, mais l'utilisation de cette option l'outrepassera. La valeur par défaut (quand tout le reste échoue) est
800x600.
depth:
32
Profondeur vidéo (bits par pixel). Les valeurs possibles sont 15, 16, 24 et 32, et 8 lors de l'utilisation du rendu logiciel. La valeur par défaut est détectée
automatiquement.
window
ed
Ouvre dans une fenêtre. Le mode par défaut est plein
écran.
gamma:
+1
Valeur de correction gamma. La plage est de -5 à +5, où les valeurs positives rendent l'écran plus clair, et les valeurs négatives le rendent plus sombre. Zéro est la valeur par défaut (aucun ajustement)
.
jailsize:
60
Définit la taille de la « prison », qui est un pourcentage de la taille de l'écran. La plage utilisable est de 1 à 100.

La prison contrôle quand la fenêtre de la carte défile : lorsqu'elle est définie à 1, le joueur sera toujours centré sur l'écran, et la carte défile toujours lors des déplacements. Lorsqu'elle est définie à 100, la carte ne défilera que si le joueur essaie de se déplacer hors de

l'écran.

Cette option est ignorée lorsque « jumpscroll » est activé (voir

ci-dessous)
.
defzoom:
16
Définit le facteur de zoom par défaut, en pixels. Utilisez 0 pour le rendre identique à la taille des tuiles (c'est-à-dire une échelle 1:1), ce qui est le défaut. Utilisez 8 pour signifier la vue en mode
texte.
keyrepeat:
never
Active/désactive la répétition automatique du clavier. Utilisez « never » pour la désactiver partout, « always » pour l'activer partout, et « partial » est un compromis qui active la répétition automatique pour les fenêtres défilantes (etc.) mais la désactive pour les commandes de jeu (déplacement, etc.
).
altpr
ev
Active le mode d'historique précédent alternatif (CTRL-P), qui ressemble davantage à la version TTY : les lignes sont limitées à la fenêtre de messages, et vous n'avez pas besoin d'appuyer sur CTRL-O, espace ou échap pour fermer la
fenêtre.
prevstep:
3
Nombre de lignes à parcourir dans l'historique des messages précédents. Pour le mode altprev, utiliser la même valeur que la hauteur de la fenêtre de messages (vary_msgcount) donne les meilleurs résultats. C'est la valeur par défaut pour le mode altprev, pour le mode normal la valeur par défaut est
1.
reform
at
Fait en sorte que les fenêtres de texte qui ne tiennent pas sur toute la largeur de l'écran soient reformatées. Le défaut est
désactivé.
shrinkwr
ap
Réduit les polices des fenêtres de texte si elles ne tiennent pas sur toute la largeur de l'écran. C'est principalement une alternative à l'option `reformat'. Le défaut est
désactivé.
flippi
ng
Retourne horizontalement les tuiles des monstres pour que la direction qu'ils affichent à l'écran corresponde à la direction dans laquelle ils se déplacent. NOTE : cela ne fonctionne qu'en mode GL, et ne fonctionne pas avec le jeu de tuiles
isométrique.
jumpscro
ll
Fait défiler la fenêtre de la carte en grands sauts plutôt qu'en pas uniques, ce qui améliore la vitesse lors de l'utilisation du rendu logiciel. Lorsque cette option est activée, l'option NetHack standard « scroll_margin » sera utilisée pour décider quand
défiler.
invis
fx
Dessine les monstres invisibles (mais
visibles par le joueur) en utilisant l
e mélange alpha (c'est-à-dire de façon
translucide). Le défaut est désactivé.

OPTIONS

NETHACK

Notez que cette page man ne documente que quelques options NetHack standard (celles particulièrement pertinentes pour glHack). Il y en a beaucoup d'autres disponibles, veuillez consulter le Guidebook de NetHack pour la liste

complète.

Ces options doivent apparaître après le mot-clé OPTIONS

windowtype:
SDL
L'option windowtype est très importante pour glHack. C'est le seul moyen de choisir entre le rendu OpenGL et le rendu purement logiciel.

La valeur `GL' (sans guillemets) sélectionne le rendu OpenGL. C'est la valeur par

défaut.

La valeur `SDL' sélectionne l

e rendu
logiciel.
tile_height:
64
Choisissez le jeu de tuiles à utiliser. Les valeurs autorisées sont 16, 32 et 64. Les tuiles 16x16 sont les mêmes
que celles de NetHack 3.4.0 standard. Les autres tuiles ont été créées (à partir de nombreuses sources) spécialem
ent pour glHack. La valeur `64' sélectionne le jeu de tuiles isométrique (pseudo-3D). La valeur par défaut est 32. 
font_size_map:20
font_size_message:8
font_size_status:14
font_size_menu:
22 font_size_text:22
 
Ces options définissent la taille de police utilisée dans les différentes fenêtres de l'écran. Chaque nombre représente la hauteur de la police, et il y a actuellement quatre polices disponibles : 8, 14, 20 et 22. Toutes les polices utilisent le jeu de caractères IBM VGA (cp437), et l'option `IBMgraphics' peut être activée pour la vue de la carte textuelle.

La valeur par défaut pour font_size_map est 14, et pour font_size_message est 20. Les valeurs par défaut pour le reste seront copiées depuis font_size_message (leur permettant de toutes partager la même

taille)
.
vary_msgcount:
4
Définit le nombre de lignes dans la fenêtre de messages. La plage acceptable est entre 2 et 8. La valeur par défaut est
3.
scroll_margin:
4
Lorsque l'option glHack « jumpscroll » est activée, la valeur de scroll_margin est utilisée pour déterminer quand défiler. Elle spécifie (approximativement) le nombre de tuiles à laisser au bord de l'écran, de sorte que lorsque le joueur franchit cette ligne, la carte
défile.

en

NAME


glhackrc


glHack configuration file






DESCRIPTION


This file contains configuration settings for glHack. It is
   read at the start of the game. Lines starting with a #
   are comments. The settings are divided into two types: NETHACK
   and GLHACK.






FORMAT


The file contains directives of the form:


VARIABLE:value
VARIABLE:
VARIABLE:value1:value2:value3



Leading and trailing whitespace around the variable name and value
   is ignored. An empty value means the option is turned off. A value of
   0 or false turns it off, anything else
   turns it on.


Some options take a list of characters as their value. These
   lists are comma-separated.






GLHACK OPTIONS


These options are specific to glHack.




!windowed


Run in windowed mode instead of fullscreen.


keyrepeat:always


Enable key repeat.


keyrepeat:never


Disable key repeat.


keyrepeat:shift


Enable key repeat only when Shift key is pressed.


altprev


Use alternate key bindings for previous.


prevstep:N


Set the number of steps to backtrack with the previous command to N.


flipping


Enable screen flipping.


!jumpscroll


Disable jump scrolling.








NETHACK OPTIONS


These options are inherited from NetHack.




dogname:NAME


catname:NAME


horsename:NAME


Set the name of your pet.


fruit:NAME


Set the name of the fruit you start with.


color


Enable color display.


hilite_pet


Highlight your pet.


safe_pet


Make your pet immune to damage.


verbose


Enable verbose output.


lit_corridor


Light up corridors.


confirm


Ask for confirmation before dangerous actions.


pickup_burden:CHAR


Set the burden pickup threshold to CHAR.


pickup_types:CHARS


Set the types of items to automatically pick up.


!showexp


Do not show experience points.


showscore


Show score.


splash_screen


Show splash screen.


!time


Do not show time.


toptenwin


Show top ten winners.


tombstone


Show tombstone.


menustyle:partial


Use partial menu style.


!prayconfirm


Do not ask for confirmation before praying.


pushweapon


Push weapon.


disclose:CHARS


Show disclosed item types.








EXAMPLES


Here is a sample .glhackrc file:


# My glHack configuration
OPTIONS=dogname:Woofer,catname:Morris
OPTIONS=horsename:Tally,fruit:mango
OPTIONS=color,hilite_pet,safe_pet
OPTIONS=verbose,lit_corridor,confirm
OPTIONS=pickup_burden:U,pickup_types:$?!/="
OPTIONS=!showexp,showscore,splash_screen,!time
OPTIONS=toptenwin,tombstone,menustyle:partial
OPTIONS=!prayconfirm,pushweapon,disclose:yi ya yv
#
GL_OPTIONS=!windowed,keyrepeat:always
GL_OPTIONS=altprev,prevstep:3
GL_OPTIONS=flipping,!jumpscroll
