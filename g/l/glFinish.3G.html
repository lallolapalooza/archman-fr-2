NOM

glFinish - bloquer jusqu'à ce que toute l'exécution GL soit terminée

SPÉCIFICATION C

void glFinish(void);

DESCRIPTION

glFinish ne retourne pas tant que les effets de toutes les commandes GL précédemment appelées ne sont pas terminés. Ces effets incluent toutes les modifications de l'état GL, toutes les modifications de l'état de connexion et toutes les modifications du contenu du tampon de trame.

NOTES

glFinish nécessite un aller-retour vers le serveur.
