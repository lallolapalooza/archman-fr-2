NOM

gl_TessLevelInner - contient les niveaux de tessellation internes pour le patch courant

DÉCLARATION

// Dans les shaders de contrôle de tessellation

out float gl_TessLevelInner[2] ;

// Dans les shaders d'évaluation de tessellation

in float gl_TessLevelInner[2] ;

DESCRIPTION

Disponible uniquement dans les langages de contrôle et d'évaluation de tessellation, gl_TessLevelInner est utilisé pour assigner des valeurs aux niveaux de tessellation internes correspondants du patch courant. Les valeurs écrites dans gl_TessLevelInner par le shader de contrôle de tessellation sont utilisées par le générateur de primitives de tessellation pour contrôler la tessellation des primitives et peuvent être lues par le shader d'évaluation de tessellation subséquent.

En tant qu'entrées pour le shader d'évaluation de tessellation, gl_TessLevelInner contient les valeurs écrites par le shader de contrôle de tessellation, s'il est présent. Si aucun shader de contrôle de tessellation n'est présent, il contient le niveau de tessellation par défaut.
