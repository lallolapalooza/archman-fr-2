NOM

glab-mr-create - Créer une nouvelle demande de fusion.

SYNTAXE

glab mr create [options]

DESCRIPTION

Créer une nouvelle demande de fusion.

OPTIONS

--allow-collaboration[=false] Autoriser les commits des autres membres.

-a, --assignee=[] Assigner la demande de fusion à des personnes par leur nom d'utilisateur. Plusieurs noms d'utilisateur peuvent être séparés par des virgules ou spécifiés en répétant l'option.

--copy-issue-labels[=false] Copier les étiquettes du ticket vers la demande de fusion. Utilisé avec --related-issue.

--create-source-branch[=false] Créer une branche source si elle n'existe pas.

-d, --description="" Fournir une description pour la demande de fusion.

--draft[=false] Marquer la demande de fusion comme brouillon.

-f, --fill[=false] Ne pas demander le titre ou la description, et utiliser uniquement les informations du commit. Définit push à true et pousse la branche.

--fill-commit-body[=false] Remplir la description avec le corps de chaque commit lorsqu'il y en a plusieurs. Ne peut être utilisé qu'avec --fill.

-H, --head="" Sélectionner un autre dépôt tête en utilisant le format PROPRIETAIRE/REPO ou GROUPE/NAMESPACE/REPO, l'ID du projet ou l'URL complète.

-l, --label=[] Ajouter une étiquette par nom. Plusieurs étiquettes peuvent être séparées par des virgules ou spécifiées en répétant l'option.

-m, --milestone="" L'ID global ou le titre d'un jalon à assigner.

--no-editor[=false] Ne pas ouvrir d'éditeur pour entrer une description. Si vrai, utilise l'invite de commande. Par défaut à faux.

--push[=false] Pousser les modifications commitées après la création de la demande de fusion. Assurez-vous d'avoir commité les modifications.

--recover[=false] Sauvegarder les options dans un fichier si la création de la demande de fusion échoue. Si le fichier existe, les options sont chargées depuis le fichier de récupération. (EXPÉRIMENTAL)

-i, --related-issue="" Créer une demande de fusion pour un ticket. Si --title n'est pas fourni, utilise le titre du ticket.

--remove-source-branch[=false] Supprimer la branche source lors de la fusion.

--reviewer=[] Demander une révision à des utilisateurs par leur nom d'utilisateur. Plusieurs noms d'utilisateur peuvent être séparés par des virgules ou spécifiés en répétant l'option.

--signoff[=false] Ajouter une signature DCO à la description de la demande de fusion.

-s, --source-branch="" Créer une demande de fusion à partir de cette branche. Par défaut, c'est la branche courante.

--squash-before-merge[=false] Squasher les commits en un seul commit lors de la fusion.

-b, --target-branch="" La branche cible ou de base dans laquelle vous souhaitez fusionner votre code.

-t, --title="" Fournir un titre pour la demande de fusion.

-w, --web[=false] Continuer la création de la demande de fusion dans un navigateur.

--wip[=false] Marquer la demande de fusion comme brouillon. Alternative à --draft.

-y, --yes[=false] Ignorer la demande de confirmation de soumission. Utiliser --fill pour ignorer toutes les demandes optionnelles.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/REPO ou GROUPE/NAMESPACE/REPO. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

$ glab mr new
$ glab mr create -a nom_utilisateur -t "correction bug ennuyeux"
$ glab mr create -f --draft --label RFC
$ glab mr create --fill --web
$ glab mr create --fill --fill-commit-body --yes
