NOM

glab-variable-update - Met à jour une variable existante pour un projet ou un groupe.

SYNTAXE

glab variable update [options]

DESCRIPTION

Met à jour une variable existante pour un projet ou un groupe.

OPTIONS

-d, --description="" Définit la description d'une variable.

-g, --group="" Définit une variable pour un groupe.

-m, --masked[=false] Indique si la variable est masquée.

-p, --protected[=false] Indique si la variable est protégée.

-r, --raw[=false] Indique si la variable doit être traitée comme une chaîne brute.

-s, --scope="" L'environnement_scope de la variable. Valeurs : all (), ou environnements spécifiques.

-t, --type="env_var" Le type d'une variable : env_var, file.

-v, --value="" La valeur d'une variable.

OPTIONS HERITEES DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIETAIRE/DEPOT ou GROUPE/ESPACE_NOM/DEPOT. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab variable update AVEC_ARGUMENT "une valeur"
$ glab variable update DE_FLAG -v "une valeur"
$ glab variable update DE_ENV_AVEC_ARGUMENT "${VAR_ENV}"
$ glab variable update DE_ENV_AVEC_FLAG -v"${VAR_ENV}"
$ glab variable update DE_FICHIER < secret.txt
$ cat file.txt | glab variable update JETON_GROUPE
$ cat token.txt | glab variable update JETON_GROUPE -g mon_groupe --scope=prod
