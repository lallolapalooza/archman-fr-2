FBB::Glob(3bobcat) Fichiers correspondant à un motif FBB::Glob(3bobcat)

NOM

FBB::Glob - Wrapper autour de glob(3) pour trouver des fichiers correspondant à un motif

SYNOPIS

#include <bobcat/glob>
Option de liaison : -lbobcat

DESCRIPTION

La classe FBB::Glob est un wrapper autour de la fonction C glob(3). Elle renvoie une liste de fichiers correspondant à un certain motif fourni aux constructeurs ou membres de FBB::Glob.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace nominal FBB.

HÉRITE DE

-

ÉNUMÉRATIONS

Glob::Type :
Cette énumération, qui est identique à l'énumération Type de stat(3bobcat), définit les valeurs suivantes :

o
BLOCK_DEVICE (0060000) : l'objet est un périphérique bloc ;
o
CHARACTER_DEVICE (0020000) : l'objet est un périphérique caractère ;
o
DIRECTORY (0040000) : l'objet est un répertoire ;
o
FIFO (0010000) : l'objet est un tube nommé (une file d'attente) ;
o
REGULAR_FILE (0100000) : l'objet est un fichier régulier ;
o
SOCKET (0140000) : l'objet est une socket ;
o
SYMBOLIC_LINK (0120000) : l'objet est un lien symbolique ;
o
ANY : n'importe lequel des types ci-dessus.

Ces valeurs sont également utilisées par stat(2) et lstat(2). Bien qu'elles puissent être combinées à l'aide de l'opérateur bitor, elles ne sont pas uniquement reconnaissables lorsqu'elles sont combinées. Par exemple, la valeur de CHARACTER_DEVICE | DIRECTORY est égale à la valeur de BLOCK_DEVICE. Il est également possible de combiner des valeurs de Type dans un std::unordered_set, ce qui évite la confusion pouvant résulter de l'utilisation de l'opérateur bitor.

Glob::Flags :

o
NO_FLAG : Égale 0, et peut être utilisé pour éviter d'avoir à spécifier 0. Il n'a pas d'autre utilité.
o
ERR : Retourner en cas d'erreurs de lecture ;
o
MARK : Ajouter une barre oblique à chaque nom.
o
NOSORT : Ne pas trier les noms.
o
NOESCAPE : Les barres obliques ne citent pas les métacaractères.
o
PERIOD : Les caractères . en début de nom peuvent être mis en correspondance par des métacaractères (c'est-à-dire * et ?).
o
NOMATCH : Lorsque spécifié, les constructeurs ne lèveront pas d'exceptions si aucun fichier correspondant à leurs motifs glob ne pouvait être trouvé. Au lieu de cela, ils retourneront normalement, et le membre size() de Glob (voir ci-dessous) renverra 0.

Glob::Dots :

o
FIRST : Les noms de fichiers commençant par un point seront listés en premier. Au sein de cet ensemble et dans l'ensemble restant, l'ordre relatif est maintenu.
o
DEFAULT : Retourner les noms de fichiers tels qu'ils apparaissent dans le processus de globbing.

CONSTRUCTEURS

o
Glob(std::string const &pattern = "*", int flags = PERIOD, Dots dots = FIRST) :
Ce constructeur (qui peut également être utilisé comme constructeur par défaut) détermine tous les éléments correspondant au pattern.
Une exception Exception est levée si le constructeur n'a pas pu terminer correctement ses tâches.
Plusieurs drapeaux peuvent être spécifiés, séparés par l'opérateur bitor.
Ce constructeur termine correctement sa tâche si seuls des valeurs Flag définies ont été spécifiées et si la fonction glob(3) s'est terminée sans erreur ;
o
Glob(Type type, std::string const &pattern = "*", int flags = PERIOD, Dots dots = FIRST) :
Ce constructeur détermine tous les éléments du pattern lorsque leurs types `elementType' sont égaux à la valeur de elementType & type. La valeur type spécifiée peut consister en toute combinaison bitor-ée des valeurs d'énumération définies par l'énumération Type. Notez que cela peut produire des résultats confus. Par exemple, lors de la spécification de DIRECTORY, les éléments qui sont des BLOCK_DEVICEs ou des SOCKETs sont également acceptés. Le constructeur suivant peut être utilisé pour éviter cette confusion ;
o
Glob(std::unordered_set<Type> const &typeSet, std::string const &pattern = "*", int flags = PERIOD, Dots dots = FIRST) :
Ce constructeur détermine tous les éléments du pattern lorsque leurs types sont trouvés dans typeSet. Différent du constructeur précédent, pour qu'un élément soit accepté, son type doit correspondre exactement à une valeur de type dans l'ensemble typeSet.

Les constructeurs et opérateurs de copie et de déplacement sont disponibles.

OPÉRATEURS SURCHARGÉS

o
char const *operator[](size_t idx) const :
L'élément à la position d'indice idx est renvoyé sous forme de chaîne C. Il renvoie une chaîne vide si idx est inférieur ou égal à size().

FONCTIONS MEMBRES

o
size_t size() const :
Renvoie le nombre d'éléments qui ont été détectés ;
o
char const *const *begin() const :
Renvoie un pointeur vers le premier élément détecté. Ce pointeur peut être utilisé dans des algorithmes génériques comme un itérateur de sortie supportant l'arithmétique de pointeurs ;
o
char const *const *end() const :
Renvoie un pointeur au-delà du dernier élément détecté. Ce pointeur peut être utilisé dans des algorithmes génériques comme un itérateur de sortie supportant l'arithmétique de pointeurs ;
o
void swap(Glob &other) :
Échange le contenu de l'autre objet avec l'objet actuel.

EXEMPLES

    int main(int argc, char **argv)
    {
        if (argc == 1)
        {
            cout << "Fournir une expression glob comme 1er argument\n";
            return 1;
        }
        cout << "Général :\n";
        Glob general;
        for (size_t idx = 0; idx < general.size(); idx++)
            cout << idx << ": " << general[idx] << endl;
        cout << "Motif : " << argv[1] << "\n";
        Glob pattern(argv[1], Glob::PERIOD, Glob::DEFAULT);
        for (size_t idx = 0; idx < pattern.size(); idx++)
            cout << idx << ": " << pattern[idx] << endl;
    }
