GLOBASH(1) Manuel des commandes générales GLOBASH(1)

NOM

globash - un shell spécial pour Global utilisant GNU bash

SYNTAXE

globash

DESCRIPTION

Globash est un shell spécial pour Global utilisant GNU bash. Vous pouvez utiliser de nombreuses fonctions pour faciliter la lecture du code source, telles que la pile de tags, la marque de tag et le cookie. Tout d'abord, vous devez créer des fichiers de tags en utilisant gtags et appeler cette commande dans le projet. Veuillez vous référer à l'aide (tapez ´ghelp<RET>´) pour des instructions détaillées.

FICHIERS

´GTAGS´
Fichier de tags pour les définitions.
´GRTAGS´
Fichier de tags pour les références.
´GPATH´
Fichier de tags pour les fichiers source.
´~/.globashrc´
Fichier de démarrage.
´~/.globash/´
Répertoire de session.
