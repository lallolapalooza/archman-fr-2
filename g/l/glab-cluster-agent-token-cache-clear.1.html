NOM

glab-cluster-agent-token-cache-clear - Efface le cache des jetons de l'agent GitLab

SYNTAXE

glab cluster agent token-cache clear [options]

DESCRIPTION

Efface les jetons de l'agent GitLab mis en cache dans le trousseau et dans le cache du système de fichiers.

Par défaut, cette commande efface les jetons du trousseau et du cache du système de fichiers, et les révoque sur le serveur GitLab. Utilisez --no-revoke pour ignorer la révocation.

OPTIONS

--agent=[] Efface les jetons pour des identifiants d'agent spécifiques uniquement

--filesystem[=true] Efface les jetons du cache du système de fichiers

--keyring[=true] Efface les jetons du cache du trousseau

-R, --repo="" Sélectionne un autre dépôt en utilisant le format PROPRIETAIRE/DEPOT

--revoke[=true] Révoque les jetons sur le serveur GitLab avant d'effacer le cache

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Affiche l'aide pour cette commande.
