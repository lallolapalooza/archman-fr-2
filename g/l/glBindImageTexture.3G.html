NOM

glBindImageTexture - lier un niveau de texture à une unité d'image

SPÉCIFICATION C

void glBindImageTexture(GLuint unit, GLuint texture, GLint level, GLboolean layered, GLint layer, GLenum access, GLenum format);

PARAMÈTRES

unit

Spécifie l'index de l'unité d'image à laquelle lier la texture

texture

Spécifie le nom de la texture à lier à l'unité d'image.

level

Spécifie le niveau de la texture à lier.

layered

Spécifie si une liaison de texture en couches doit être établie.

layer

Si layered est GL_FALSE, spécifie la couche de texture à lier à l'unité d'image. Ignoré sinon.

access

Spécifie un jeton indiquant le type d'accès qui sera effectué sur l'image.

format

Spécifie le format dans lequel les éléments de l'image seront traités à des fins de stockage formaté.

DESCRIPTION

glBindImageTexture lie un niveau unique d'une texture à une unité d'image dans le but de la lire et de l'écrire depuis les shaders. unit spécifie l'index basé sur zéro de l'unité d'image à laquelle lier le niveau de texture. texture spécifie le nom d'un objet de texture existant à lier à l'unité d'image. Si texture est zéro, toute liaison existante à l'unité d'image est rompue. level spécifie le niveau de la texture à lier à l'unité d'image.

Si texture est le nom d'une texture de tableau unidimensionnelle, bidimensionnelle ou tridimensionnelle, d'une texture de carte cube ou de tableau de carte cube, ou d'une texture de tableau multisample bidimensionnelle, alors il est possible de lier soit l'ensemble du tableau, soit seulement une couche unique du tableau à l'unité d'image. Dans de tels cas, si layered est GL_TRUE, l'ensemble du tableau est attaché à l'unité d'image et layer est ignoré. Cependant, si layered est GL_FALSE, alors layer spécifie la couche du tableau à attacher à l'unité d'image.

access spécifie les types d'accès qui seront effectués par les shaders et peut être défini sur GL_READ_ONLY, GL_WRITE_ONLY, ou GL_READ_WRITE pour indiquer un accès en lecture seule, en écriture seule ou en lecture-écriture, respectivement. La violation du type d'accès spécifié dans access (par exemple, si un shader écrit dans une image liée avec access défini sur GL_READ_ONLY) entraînera des résultats indéfinis, y compris potentiellement la terminaison du programme.

format spécifie le format qui sera utilisé lors de l'exécution d'écritures formatées dans l'image depuis les shaders. format doit être compatible avec le format interne de la texture et doit être l'un des formats listés dans le tableau suivant.

Lorsqu'une texture est liée à une unité d'image, le paramètre format de l'unité d'image n'a pas besoin de correspondre exactement au format interne de la texture tant que les formats sont considérés comme compatibles, tels que définis dans la spécification OpenGL. Le critère de correspondance utilisé pour une texture donnée peut être déterminé en appelant glGetTexParameter() avec value défini sur GL_IMAGE_FORMAT_COMPATIBILITY_TYPE, avec les valeurs de retour GL_IMAGE_FORMAT_COMPATIBILITY_BY_SIZE et GL_IMAGE_FORMAT_COMPATIBILITY_BY_CLASS, spécifiant les correspondances par taille et par classe, respectivement.

NOTES

La fonction glBindImageTexture n'est disponible que si la version GL est 4.2 ou supérieure.

ERREURS

GL_INVALID_VALUE est générée si unit est supérieur ou égal à la valeur de GL_MAX_IMAGE_UNITS.

GL_INVALID_VALUE est générée si texture n'est pas le nom d'un objet de texture existant.

GL_INVALID_VALUE est générée si level ou layer est inférieur à zéro.

GL_INVALID_ENUM est générée si access ou format n'est pas l'un des jetons pris en charge.

GETS ASSOCIÉS

glGet() avec l'argument GL_IMAGE_BINDING_NAME.

glGet() avec l'argument GL_IMAGE_BINDING_LEVEL.

glGet() avec l'argument GL_IMAGE_BINDING_LAYERED.

glGet() avec l'argument GL_IMAGE_BINDING_LAYER.

glGet() avec l'argument GL_IMAGE_BINDING_ACCESS.

glGet() avec l'argument GL_IMAGE_BINDING_FORMAT.
