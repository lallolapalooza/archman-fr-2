NOM

glDeleteBuffers - supprimer des objets de tampon nommés

SPÉCIFICATION C

void glDeleteBuffers(GLsizei n, const GLuint * buffers);

PARAMÈTRES

n

Spécifie le nombre d'objets de tampon à supprimer.

buffers

Spécifie un tableau d'objets de tampon à supprimer.

DESCRIPTION

glDeleteBuffers supprime n objets de tampon nommés par les éléments du tableau buffers. Après la suppression d'un objet de tampon, il n'a plus de contenu et son nom est libre pour réutilisation (par exemple par glGenBuffers()). Si un objet de tampon actuellement lié est supprimé, la liaison revient à 0 (l'absence de tout objet de tampon).

glDeleteBuffers ignore silencieusement les 0 et les noms qui ne correspondent pas à des objets de tampon existants.

ERREURS

GL_INVALID_VALUE est généré si n est négatif.

GETS ASSOCIÉS

glIsBuffer()
