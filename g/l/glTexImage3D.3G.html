Si le
paramètre internalformat est l'un des formats compressés génériques, GL_COMPRESSED_RED, GL_COMPRESSED_RG, GL_COMPRESSED_RGB, ou GL_COMPRESSED_RGBA, le GL remplacera le format interne par la constante symbolique d'un format interne spécifique et compressera la texture avant le stockage. Si aucun format interne correspondant n'est disponible, ou si le GL ne peut pas compresser cette image pour une raison quelconque, le format interne est remplacé par un format interne de base

correspondant.

Si le paramètre internalformat est GL_SRGB, GL_SRGB8, GL_SRGB_ALPHA, ou GL_SRGB8_ALPHA8, la texture est traitée comme si les composantes rouge, verte, bleue ou luminance étaient encodées dans l'espace colorimétrique sRGB. Toute composante alpha est laissée inchangée. La conversion du composant encodé en sRGB c s vers un composant linéaire c l est

:

Utilisez la cible GL_PROXY_TEXTURE_3D pour essayer une résolution et un format. L'implémentation mettra à jour et recalculera sa meilleure correspondance pour la résolution et le format de stockage demandés. Pour interroger cet état, appelez glGetTexLevelParameter(). Si la texture ne peut pas être prise en charge, l'état de la texture est défini à

0.

Une image de texture à un composant utilise uniquement la composante rouge de la couleur RGBA extraite de data. Une image à deux composants utilise les valeurs R et A. Une image à trois composants uti

lise les valeurs R, G et B. Une image à quatr
