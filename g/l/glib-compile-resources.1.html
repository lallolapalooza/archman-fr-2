DESCRIPTIO

N

glib-compile-resources lit la description de la ressource depuis le FICHIER ainsi que les fichiers qu'il référence et crée un paquet de ressources binaire adapté à l'utilisation avec l' API GResource. Le paquet résultant est ensuite écrit tel quel, ou en tant que source C pour être lié dans une

application.

Les fichiers de ressources XML ont normalement l'extension de nom de fichier .gresource.xml. Pour une description détaillée du format de fichier XML, voir la documentation de GResource https://docs.gtk.org/gi

o/struct.Re
source.html.

--manual-registe

r
Par défaut, le code généré par --generate-source utilise l'initialisation automatique de la ressource. Cela fonctionne sur la plupart des systèmes en utilisant le support du compilateur pour les constructeurs. Cependant, certains compilateurs (peu courants) peuvent ne pas le supporter, vous pouvez alors spécifier --manual-register, qui générera des fonctions d'enregistrement et de désenregistrement personnalisées que votre code peut appeler manuellement lors de l'initialisation et de la désinitialisatio
n
.

--interna

l
Par défaut, le code généré par --generate-source déclare toutes les fonctions d'initialisation comme extern. Elles sont donc exportées sauf si cela est empêché par un script de liaison ou d'autres moyens. Comme les bibliothèques souhaitent généralement utiliser les fonctions uniquement en interne, il peut être plus utile de les déclarer comme G_GNUC_INTERNAL, ce que --interna
l f
ait.

a

le fichier C généré, et les donné
