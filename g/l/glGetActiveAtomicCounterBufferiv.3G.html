NOM

glGetActiveAtomicCounterBufferiv - récupérer des informations sur l'ensemble des tampons de compteur atomique actifs pour un programme

SPÉCIFICATION C

void glGetActiveAtomicCounterBufferiv(GLuint program, GLuint bufferIndex, GLenum pname, GLint *params);

PARAMÈTRES

program

Le nom d'un objet programme à partir duquel récupérer des informations.

bufferIndex

Spécifie l'index d'un tampon de compteur atomique actif.

pname

Spécifie quel paramètre du tampon de compteur atomique récupérer.

params

Spécifie l'adresse d'une variable dans laquelle écrire les informations récupérées.

DESCRIPTION

glGetActiveAtomicCounterBufferiv récupère des informations sur l'ensemble des tampons de compteur atomique actifs pour un objet programme. program est le nom d'un objet programme pour lequel la commande glLinkProgram() a été émise par le passé. Il n'est pas nécessaire que program ait été lié avec succès. La liaison a pu échouer parce que le nombre de compteurs atomiques actifs a dépassé les limites.

bufferIndex spécifie l'index d'un tampon de compteur atomique actif et doit être dans la plage de zéro à la valeur de GL_ACTIVE_ATOMIC_COUNTER_BUFFERS moins un. La valeur de GL_ACTIVE_ATOMIC_COUNTER_BUFFERS pour program indique le nombre de tampons de compteur atomique actifs et peut être interrogée avec glGetProgram().

Si aucune erreur ne se produit, le ou les paramètres spécifiés par pname sont retournés dans params. Si une erreur est générée, le contenu de params n'est pas modifié.

Si pname est GL_ATOMIC_COUNTER_BUFFER_BINDING, alors l'index du point de liaison du tampon de compteur associé au tampon de compteur atomique actif bufferIndex pour program est retourné.

Si pname est GL_ATOMIC_COUNTER_BUFFER_DATA_SIZE, alors la taille minimale dépendant de l'implémentation du tampon, en unités machine de base, requise pour contenir tous les compteurs atomiques actifs dans le point de liaison du compteur atomique identifié par bufferIndex est retournée.

Si pname est GL_ATOMIC_COUNTER_BUFFER_ACTIVE_ATOMIC_COUNTERS, alors le nombre de compteurs atomiques actifs pour le tampon de compteur atomique identifié par bufferIndex est retourné.

Si pname est GL_ATOMIC_COUNTER_BUFFER_ACTIVE_ATOMIC_COUNTER_INDICES, alors une liste des indices des compteurs atomiques actifs pour le tampon de compteur atomique identifié par bufferIndex est retournée. Le nombre d'éléments qui seront écrits dans params est la valeur de GL_ATOMIC_COUNTER_BUFFER_ACTIVE_ATOMIC_COUNTERS pour bufferIndex.

Si pname est GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_VERTEX_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_TESS_CONTROL_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_TESS_EVALUATION_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_GEOMETRY_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_FRAGMENT_SHADER, GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_COMPUTE_SHADER alors une valeur booléenne indiquant si le tampon de compteur atomique identifié par bufferIndex est référencé par les étapes de vertex, de contrôle de tessellation, d'évaluation de tessellation, de géométrie, de fragment ou de calcul de program, respectivement, est retournée.

NOTES

glGetActiveAtomicCounterBufferiv n'est disponible que si la version de GL est 4.2 ou supérieure.

GL_ATOMIC_COUNTER_BUFFER_REFERENCED_BY_COMPUTE_SHADER n'est disponible que si la version de GL est 4.3 ou supérieure.

ERREURS

GL_INVALID_VALUE est générée si program n'est pas le nom d'un objet programme pour lequel glLinkProgram() a été appelé par le passé.

GL_INVALID_VALUE est générée si bufferIndex est supérieur ou égal à la valeur de GL_ACTIVE_ATOMIC_COUNTER_BUFFERS pour program.

GL_INVALID_ENUM est générée si pname n'est pas l'un des jetons acceptés.
