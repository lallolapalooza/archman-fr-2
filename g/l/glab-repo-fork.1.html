NOM

glab-repo-fork - Fork un dépôt GitLab.

SYNTAXE

glab repo fork [options]

DESCRIPTION

Fork un dépôt GitLab.

OPTIONS

-c, --clone[=false] Clone le fork. Options : true, false.

-n, --name="" Le nom attribué au nouveau projet après le fork.

-p, --path="" Le chemin attribué au nouveau projet après le fork.

--remote[=false] Ajoute une référence distante pour le fork. Options : true, false.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Affiche l'aide pour cette commande.

EXEMPLE

$ glab repo fork
$ glab repo fork namespace/repo
$ glab repo fork namespace/repo --clone
