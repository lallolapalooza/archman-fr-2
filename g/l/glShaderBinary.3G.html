NOM

glShaderBinary - charger des binaires de shaders pré-compilés

SPÉCIFICATION C

void glShaderBinary(GLsizei count, const GLuint *shaders, GLenum binaryFormat, const void *binary, GLsizei length);

PARAMÈTRES

count

Spécifie le nombre de descripteurs d'objets shader contenus dans shaders.

shaders

Spécifie l'adresse d'un tableau de descripteurs de shader dans lesquels charger les binaires de shaders pré-compilés.

binaryFormat

Spécifie le format des binaires de shaders contenus dans binary.

binary

Spécifie l'adresse d'un tableau d'octets contenant le code binaire du shader pré-compilé.

length

Spécifie la longueur du tableau dont l'adresse est donnée dans binary.

DESCRIPTION

glShaderBinary charge le code binaire de shader pré-compilé dans les count objets shader dont les descripteurs sont donnés dans shaders. binary pointe vers length octets de code binaire de shader stocké dans la mémoire client. binaryFormat spécifie le format du code pré-compilé.

L'image binaire contenue dans binary sera décodée selon la spécification de l'extension définissant le jeton binaryFormat spécifié. OpenGL ne définit aucun format binaire spécifique, mais il fournit un mécanisme pour obtenir des valeurs de jeton pour de tels formats fournis par de telles extensions.

Selon les types des objets shader dans shaders, glShaderBinary chargera individuellement des shaders vertex ou fragment binaires, ou chargera un binaire exécutable contenant une paire optimisée de shaders vertex et fragment stockés dans le même binaire.

ERREURS

GL_INVALID_OPERATION est généré si plus d'un des descripteurs dans shaders fait référence au même objet shader.

GL_INVALID_ENUM est généré si binaryFormat n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si les données pointées par binary ne correspondent pas au format spécifié par binaryFormat.

GETS ASSOCIÉS

glGet() avec le paramètre GL_NUM_SHADER_BINARY_FORMATS.

glGet() avec le paramètre GL_SHADER_BINARY_FORMATS.
