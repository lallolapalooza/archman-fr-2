NOM

glabels - Programme de création d'étiquettes et de cartes de visite pour GNOME

SYNTAXE

glabels-3 [OPTIONS] [nom-fichier-etiquette...]

glabels-3-batch [OPTIONS] [nom-fichier-etiquette...]

DESCRIPTION

glabels-3 est un programme léger de création d'étiquettes et de cartes de visite pour l'environnement de bureau GNOME. Il est conçu pour fonctionner avec divers types de feuilles d'étiquettes détachables et de cartes de visite pour imprimantes laser/jet d'encre que l'on trouve dans la plupart des magasins de fournitures de bureau. glabels-3 est préconfiguré avec des modèles pour plusieurs de ces produits. Il fournit également un concepteur de modèles interactif pour créer de nouveaux modèles selon les spécifications de l'utilisateur.

Pour une documentation complète, consultez l'aide en ligne de gLabels.

glabels-3-batch est un utilitaire en ligne de commande pour imprimer des étiquettes préparées précédemment avec glabels-3.

OPTIONS

-?, --help
Affiche un résumé des options de ligne de commande disponibles.
--usage
Affiche un bref résumé d'utilisation.
-v, --version
Affiche les informations de version du programme.

Options spécifiques à glabels-batch

-o nom-fichier, --output=nom-fichier
Définit le nom du fichier de sortie à nom-fichier. (par défaut : « output.ps »)
-s n, --sheets=n
Définit le nombre de feuilles à n. (par défaut : 1)
-c n, --copies=n
Définit le nombre de copies à n. (par défaut : 1)
-f n, --first=n
Définit l'étiquette sur la première feuille à partir de laquelle commencer l'impression à n. (par défaut : 1)
-l, --outline
Imprime des contours autour des étiquettes. Ceci est utile pour tester l'alignement de l'imprimante ou pour imprimer des feuilles de preuve.
-r, --reverse
Imprime une image miroir des étiquettes. Ceci est utile pour les étiquettes transparentes destinées à être vues par l'arrière à travers du verre.

FICHIERS

Le répertoire $HOME/.config/libglabels/templates contient tous les modèles définis par l'utilisateur.
