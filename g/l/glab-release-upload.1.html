NOM

glab-release-upload - Télécharger des fichiers ou des liens d'assets de release vers une release GitLab.

SYNTAXE

glab release upload [...] [options]

DESCRIPTION

Télécharge les assets de release vers une release GitLab.

Définissez le nom d'affichage en ajoutant '#' après le nom de fichier. Le type de lien vient après le nom d'affichage, comme ceci : 'monfichier.tar.gz#Mon nom d'affichage#package'

OPTIONS

-a, --assets-links="" Représentation de chaîne JSON des liens d'assets, comme : --assets-links='[{"name": "Asset1", "url":"https://<domaine>/quelque/part/1", "link_type": "other", "direct_asset_path": "chemin/vers/fichier"}]'.

--package-name="release-assets" Le nom du paquet à utiliser lors du téléchargement des assets vers la release de paquet générique avec --use-package-registry.

--use-package-registry[=false] Télécharge les assets de release vers le registre de paquets générique du projet. Alternativement à cette option, vous pouvez également définir la variable d'environnement GITLAB_RELEASE_ASSETS_USE_PACKAGE_REGISTRY à la valeur true ou 1. L'option a priorité sur cette variable d'environnement.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Affiche l'aide pour cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIETAIRE/REPO ou GROUPE/NAMESPACE/REPO. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Télécharge un asset de release avec un nom d'affichage. Le type est 'other' par défaut.
$ glab release upload v1.0.1 '/chemin/vers/asset.zip#Mon label d'affichage'
# Télécharge un asset de release avec un nom d'affichage et un type.
$ glab release upload v1.0.1 '/chemin/vers/asset.png#Mon label d'affichage#image'
# Télécharge tous les assets d'un dossier spécifié. Le type est 'other' par défaut.
$ glab release upload v1.0.1 ./dist/*
# Télécharge tous les tarballs d'un dossier spécifié. Le type est 'other' par défaut.
$ glab release upload v1.0.1 ./dist/*.tar.gz
# Télécharge des liens d'assets de release spécifiés sous forme de chaîne JSON
$ glab release upload v1.0.1 --assets-links='
  [
    {
      "name": "Asset1",
      "url":"https://<domaine>/quelque/part/1",
      "link_type": "other",
      "direct_asset_path": "chemin/vers/fichier"
    }
  ]'
