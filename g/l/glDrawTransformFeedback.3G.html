NOM

glDrawTransformFeedback - dessine des primitives à l'aide d'un compte dérivé d'un objet de retour de transformation

SPÉCIFICATION C

void glDrawTransformFeedback(GLenum mode, GLuint id);

PARAMÈTRES

mode

Spécifie le type de primitives à dessiner. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

id

Spécifie le nom d'un objet de retour de transformation à partir duquel récupérer un compte de primitives.

DESCRIPTION

glDrawTransformFeedback dessine des primitives d'un type spécifié par mode en utilisant un compte récupéré à partir du retour de transformation spécifié par id. L'appel à glDrawTransformFeedback est équivalent à l'appel de glDrawArrays() avec mode tel que spécifié, first mis à zéro et count mis au nombre de sommets capturés sur le flux de sommets zéro lors de la dernière activation du retour de transformation sur l'objet de retour de transformation nommé par id.

ERREURS

GL_INVALID_ENUM est générée si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est générée si id n'est pas le nom d'un objet de retour de transformation.

GL_INVALID_OPERATION est générée si un objet de tampon non nul est lié à un tableau activé et que le stockage de données de l'objet de tampon est actuellement mappé.

GL_INVALID_OPERATION est générée si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet de programme actuellement installé.

GL_INVALID_OPERATION est générée si mode est GL_PATCHES et qu'aucun shader de contrôle de tessellation n'est actif.

GL_INVALID_OPERATION est générée si

glEndTransformFeedback n'a jamais été appelé pendant que l'objet de retour de transformation nommé par id était lié.
