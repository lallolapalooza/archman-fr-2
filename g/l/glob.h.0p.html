PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

glob.h — types de correspondance de motifs de noms de chemin

SYNTAXE

#include <glob.h>

DESCRIPTION

L'en-tête <glob.h> définira les structures et les constantes symboliques utilisées par la fonction glob().

L'en-tête <glob.h> définira le type de structure glob_t, qui inclura au moins les membres suivants :

size_t   gl_pathc Nombre de chemins correspondant au motif.
char   **gl_pathv Pointeur vers une liste de noms de chemin correspondants.
size_t   gl_offs  Emplacements à réserver au début de gl_pathv.

L'en-tête <glob.h> définira le type size_t tel que décrit dans <sys/types.h>.

L'en-tête <glob.h> définira les constantes symboliques suivantes comme valeurs pour l'argument flags :

GLOB_APPEND
Ajoute les noms de chemin générés à ceux précédemment obtenus.
GLOB_DOOFFS
Spécifie combien de pointeurs nuls ajouter au début de gl_pathv.
GLOB_ERR
Force le retour de glob() en cas d'erreur.
GLOB_MARK
Chaque nom de chemin qui est un répertoire correspondant au motif se voit ajouter un <slash>.
GLOB_NOCHECK
Si le motif ne correspond à aucun nom de chemin, retourne une liste ne contenant que le motif.
GLOB_NOESCAPE
Désactive l'échappement par anti-slash.
GLOB_NOSORT
Ne trie pas les noms de chemin retournés.

L'en-tête <glob.h> définira les constantes symboliques suivantes comme valeurs de retour d'erreur :

GLOB_ABORTED
Le balayage a été arrêté car GLOB_ERR était défini ou (*errfunc)() a retourné une valeur non nulle.
GLOB_NOMATCH
Le motif ne correspond à aucun chemin existant, et GLOB_NOCHECK n'était pas défini dans flags.
GLOB_NOSPACE
Une tentative d'allocation mémoire a échoué.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonction seront fournis.

int  glob(const char *restrict, int, int(*)(const char *, int),
         glob_t *restrict);
void globfree(glob_t *);
