NOM

glGetTexLevelParameter - renvoyer les valeurs des paramètres de texture pour un niveau de détail spécifique

SPÉCIFICATION C

void glGetTexLevelParameterfv(GLenum target, GLint level, GLenum pname, GLfloat * params);

void glGetTexLevelParameteriv(GLenum target, GLint level, GLenum pname, GLint * params);

void glGetTextureLevelParameterfv(GLuint texture, GLint level, GLenum pname, GLfloat *params);

void glGetTextureLevelParameteriv(GLuint texture, GLint level, GLenum pname, GLint *params);

PARAMÈTRES

target

Spécifie la cible à laquelle la texture est liée pour les fonctions glGetTexLevelParameterfv et glGetTexLevelParameteriv. Doit être l'une des valeurs suivantes : GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_RECTANGLE, GL_TEXTURE_2D_MULTISAMPLE, GL_TEXTURE_2D_MULTISAMPLE_ARRAY, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, GL_PROXY_TEXTURE_1D, GL_PROXY_TEXTURE_2D, GL_PROXY_TEXTURE_3D, GL_PROXY_TEXTURE_1D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_RECTANGLE, GL_PROXY_TEXTURE_2D_MULTISAMPLE, GL_PROXY_TEXTURE_2D_MULTISAMPLE_ARRAY, GL_PROXY_TEXTURE_CUBE_MAP, ou GL_TEXTURE_BUFFER.

texture

Spécifie le nom de l'objet texture pour les fonctions glGetTextureLevelParameterfv et glGetTextureLevelParameteriv.

level

Spécifie le numéro de niveau de détail de l'image souhaitée. Le niveau 0 est le niveau d'image de base. Le niveau n est l'image de réduction mipmap n.

pname

Spécifie le nom symbolique d'un paramètre de texture. GL_TEXTURE_WIDTH, GL_TEXTURE_HEIGHT, GL_TEXTURE_DEPTH, GL_TEXTURE_INTERNAL_FORMAT, GL_TEXTURE_RED_SIZE, GL_TEXTURE_GREEN_SIZE, GL_TEXTURE_BLUE_SIZE, GL_TEXTURE_ALPHA_SIZE, GL_TEXTURE_DEPTH_SIZE, GL_TEXTURE_COMPRESSED, GL_TEXTURE_COMPRESSED_IMAGE_SIZE, et GL_TEXTURE_BUFFER_OFFSET sont acceptés.

params

Renvoie les données demandées.

DESCRIPTION

glGetTexLevelParameterfv, glGetTexLevelParameteriv, glGetTextureLevelParameterfv et glGetTextureLevelParameteriv renvoient dans params les valeurs des paramètres de texture pour un niveau de détail spécifique, spécifié par level. Pour les deux premières fonctions, target définit la texture cible, soit GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_PROXY_TEXTURE_1D, GL_PROXY_TEXTURE_2D, GL_PROXY_TEXTURE_3D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, ou GL_PROXY_TEXTURE_CUBE_MAP. Les deux dernières prennent un argument texture qui spécifie le nom de l'objet texture.

GL_MAX_TEXTURE_SIZE, et GL_MAX_3D_TEXTURE_SIZE ne sont pas vraiment assez descriptifs. Il faut rapporter la plus grande image de texture carrée qui peut être accommodée avec des mipmaps, mais une texture longue et étroite, ou une texture sans mipmaps peut facilement tenir dans la mémoire texture. Les cibles proxy permettent à l'utilisateur de demander plus précisément si le GL peut accommoder une texture d'une configuration donnée. Si la texture ne peut pas être accommodée, les variables d'état de texture, qui peuvent être interrogées avec glGetTexLevelParameter et glGetTextureLevelParameter, sont définies à 0. Si la texture peut être accommodée, les valeurs d'état de texture seront définies comme elles le seraient pour une cible non-proxy.

pname spécifie le paramètre de texture dont la ou les valeurs seront renvoyées.

Les noms de paramètres acceptés sont les suivants :

GL_TEXTURE_WIDTH

params renvoie une seule valeur, la largeur de l'image texture. La valeur initiale est 0.

GL_TEXTURE_HEIGHT

params renvoie une seule valeur, la hauteur de l'image texture. La valeur initiale est 0.

GL_TEXTURE_DEPTH

params renvoie une seule valeur, la profondeur de l'image texture. La valeur initiale est 0.

GL_TEXTURE_INTERNAL_FORMAT

params renvoie une seule valeur, le format interne de l'image texture.

GL_TEXTURE_RED_TYPE, GL_TEXTURE_GREEN_TYPE, GL_TEXTURE_BLUE_TYPE, GL_TEXTURE_ALPHA_TYPE, GL_TEXTURE_DEPTH_TYPE

Le type de données utilisé pour stocker le composant. Les types GL_NONE, GL_SIGNED_NORMALIZED, GL_UNSIGNED_NORMALIZED, GL_FLOAT, GL_INT, et GL_UNSIGNED_INT peuvent être renvoyés pour indiquer respectivement des composants normalisés signés, normalisés non signés, en virgule flottante, entiers non normalisés et entiers non signés non normalisés.

GL_TEXTURE_RED_SIZE, GL_TEXTURE_GREEN_SIZE, GL_TEXTURE_BLUE_SIZE, GL_TEXTURE_ALPHA_SIZE, GL_TEXTURE_DEPTH_SIZE

La résolution de stockage interne d'un composant individuel. La résolution choisie par le GL sera une correspondance étroite avec la résolution demandée par l'utilisateur avec l'argument composant de glTexImage1D(), glTexImage2D(), glTexImage3D(), glCopyTexImage1D(), et glCopyTexImage2D(). La valeur initiale est 0.

GL_TEXTURE_COMPRESSED

params renvoie une seule valeur booléenne indiquant si l'image texture est stockée dans un format interne compressé. La valeur initiale est GL_FALSE.

GL_TEXTURE_COMPRESSED_IMAGE_SIZE

params renvoie une seule valeur entière, le nombre d'octets non signés de l'image texture compressée qui serait renvoyé par glGetCompressedTexImage().

GL_TEXTURE_BUFFER_OFFSET

params renvoie une seule valeur entière, le décalage dans le magasin de données du tampon lié à une texture tampon. glTexBufferRange().

GL_TEXTURE_BUFFER_SIZE

params renvoie une seule valeur entière, la taille de la plage d'un magasin de données du tampon lié à une texture tampon. glTexBufferRange().

NOTES

En cas d'erreur, aucun changement n'est apporté au contenu de params.

glGetTexLevelParameter renvoie les paramètres de niveau de texture pour l'unité de texture active.

GL_TEXTURE_BUFFER_OFFSET et GL_TEXTURE_BUFFER_SIZE ne sont disponibles que si la version GL est 4.3 ou supérieure.

ERREURS

GL_INVALID_OPERATION est généré par les fonctions glGetTextureLevelParameterfv et glGetTextureLevelParameteriv si texture n'est pas le nom d'un objet texture existant.

GL_INVALID_ENUM est généré par les fonctions glGetTexLevelParameterfv et glGetTexLevelParameteriv si target ou pname n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si level est inférieur à 0.

GL_INVALID_VALUE peut être généré si level est supérieur à log 2 de max, où max est la valeur renvoyée par GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE est généré si target est GL_TEXTURE_BUFFER et level n'est pas zéro.

GL_INVALID_OPERATION est généré si GL_TEXTURE_COMPRESSED_IMAGE_SIZE est interrogé sur des images textures avec un format interne non compressé ou sur des cibles proxy.
