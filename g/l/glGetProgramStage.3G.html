NOM

glGetProgramStage - récupérer les propriétés d'un objet programme correspondant à une étape de shader spécifiée

SPÉCIFICATION C

void glGetProgramStageiv(GLuint program, GLenum shadertype, GLenum pname, GLint *values);

PARAMÈTRES

program

Spécifie le nom du programme contenant l'étape de shader.

shadertype

Spécifie l'étape de shader à partir de laquelle interroger le paramètre de sous-routine. shadertype doit être l'un de GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER.

pname

Spécifie le paramètre du shader à interroger. pname doit être GL_ACTIVE_SUBROUTINE_UNIFORMS, GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS, GL_ACTIVE_SUBROUTINES, GL_ACTIVE_SUBROUTINE_UNIFORM_MAX_LENGTH, ou GL_ACTIVE_SUBROUTINE_MAX_LENGTH.

values

Spécifie l'adresse d'une variable dans laquelle la ou les valeurs interrogées seront placées.

DESCRIPTION

glGetProgramStage interroge un paramètre d'une étape de shader attachée à un objet programme. program contient le nom du programme auquel le shader est attaché. shadertype spécifie l'étape à partir de laquelle interroger le paramètre. pname spécifie quel paramètre doit être interrogé. La ou les valeurs du paramètre à interroger sont renvoyées dans la variable dont l'adresse est fournie dans values.

Si pname est GL_ACTIVE_SUBROUTINE_UNIFORMS, le nombre de variables de sous-routines actives dans l'étape est renvoyé dans values.

Si pname est GL_ACTIVE_SUBROUTINE_UNIFORM_LOCATIONS, le nombre d'emplacements de variables de sous-routines actives dans l'étape est renvoyé dans values.

Si pname est GL_ACTIVE_SUBROUTINES, le nombre de sous-routines actives dans l'étape est renvoyé dans values.

Si pname est GL_ACTIVE_SUBROUTINE_UNIFORM_MAX_LENGTH, la longueur de l'uniforme de sous-routine la plus longue pour l'étape est renvoyée dans values.

Si pname est GL_ACTIVE_SUBROUTINE_MAX_LENGTH, la longueur du nom de sous-routine le plus long pour l'étape est renvoyée dans values. La longueur du nom renvoyé inclut l'espace pour le terminateur nul.

S'il n'y a pas de shader du type shadertype présent, la valeur renvoyée sera cohérente avec un shader ne contenant aucune sous-routine ni uniforme de sous-routine.

ERREURS

GL_INVALID_ENUM est généré si shadertype ou pname ne fait pas partie des valeurs acceptées.

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme existant.
