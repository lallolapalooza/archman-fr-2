NOM

glab-repo-archive - Obtenir une archive du dépôt.

SYNTAXE

glab repo archive [options]

DESCRIPTION

Clone prend en charge ces références abrégées :

  • repo
  • namespace/repo
  • namespace/group/repo

OPTIONS

-f, --format="zip" Optionnel. Spécifiez le format si vous souhaitez une archive téléchargée : tar.gz, tar.bz2, tbz, tbz2, tb2, bz2, tar, zip.

-s, --sha="" Le SHA du commit à télécharger. Une balise, une référence de branche ou un SHA peuvent être utilisés. Par défaut, pointe sur la dernière version de la branche par défaut si non spécifié.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab repo archive profclems/glab
# Télécharge un fichier zip du dépôt actuel
$ glab repo archive
# Télécharge le fichier zip du dépôt dans mon répertoire
$ glab repo archive profclems/glab mydirectory
# Trouve le dépôt de l'utilisateur actuel et le télécharge au format ZIP
$ glab repo archive profclems/glab --format=zip
