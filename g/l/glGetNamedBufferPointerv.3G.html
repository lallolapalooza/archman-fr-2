GLGETBUFFERPOINTERV(3G) [FIXME: manual] GLGETBUFFERPOINTERV(3G)

NOM

glGetBufferPointerv, glGetNamedBufferPointerv - renvoient le pointeur vers le magasin de données d'un objet tampon mappé

SPÉCIFICATION C

void glGetBufferPointerv(GLenumtarget, GLenumpname, void **params);

void glGetNamedBufferPointerv(GLuintbuffer, GLenumpname, void **params);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet tampon est lié pour glGetBufferPointerv, qui doit être l'une des cibles de liaison de tampon du tableau suivant :
Cible de liaison du tampon But
GL_ARRAY_BUFFER Attributs de sommet
GL_ATOMIC_COUNTER_BUFFER Stockage de compteur atomique
GL_COPY_READ_BUFFER Source de copie de tampon
GL_COPY_WRITE_BUFFER Destination de copie de tampon
GL_DISPATCH_INDIRECT_BUFFER Commandes de dispatch de calcul indirect
GL_DRAW_INDIRECT_BUFFER Arguments de commande indirects
GL_ELEMENT_ARRAY_BUFFER Indices de tableau de sommets
GL_PIXEL_PACK_BUFFER Cible de lecture de pixels
GL_PIXEL_UNPACK_BUFFER Source de données de texture
GL_QUERY_BUFFER Tampon de résultat de requête
GL_SHADER_STORAGE_BUFFER Stockage lecture-écriture pour les shaders
GL_TEXTURE_BUFFER Tampon de données de texture
GL_TRANSFORM_FEEDBACK_BUFFER Tampon de transform feedback
GL_UNIFORM_BUFFER Stockage de bloc uniforme

buffer

Spécifie le nom de l'objet tampon pour glGetNamedBufferPointerv.

pname

Spécifie le nom du pointeur à renvoyer. Doit être GL_BUFFER_MAP_POINTER.

params

Renvoie la valeur du pointeur spécifiée par pname.

DESCRIPTION

glGetBufferPointerv et glGetNamedBufferPointerv renvoient le pointeur de tampon pname, qui doit être GL_BUFFER_MAP_POINTER. Le pointeur de mappage unique du tampon est renvoyé dans params. Un pointeur NULL est renvoyé si le magasin de données de l'objet tampon n'est pas actuellement mappé ; ou si le contexte demandeur n'a pas mappé le magasin de données de l'objet tampon, et que l'implémentation est incapable de prendre en charge le mappage sur plusieurs clients.

REMARQUES

Si une erreur est générée, aucune modification n'est apportée au contenu de params.

La valeur initiale du pointeur est NULL.

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version de GL est 4.2 ou supérieure.

Les cibles GL_DISPATCH_INDIRECT_BUFFER et GL_SHADER_STORAGE_BUFFER ne sont disponibles que si la version de GL est 4.3 ou supérieure.

La cible GL_QUERY_BUFFER n'est disponible que si la version de GL est 4.4 ou supérieure.

ERREUR

GL_INVALID_ENUM est généré par glGetBufferPointerv si target n'est pas l'une des cibles de tampon acceptées, ou si pname n'est pas GL_BUFFER_MAP_POINTER.

GL_INVALID_OPERATION est généré par glGetBufferPointerv si zéro est lié à target.

GL_INVALID_OPERATION est généré par glGetNamedBufferPointerv si buffer n'est pas le nom d'un objet tampon existant.
