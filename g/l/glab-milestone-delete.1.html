NOM

glab-milestone-delete - Supprimer une étape de groupe ou de projet.

SYNOPSIS

glab milestone delete [indicateurs]

DESCRIPTION

Supprimer une étape de groupe ou de projet.

OPTIONS

--group="" L'identifiant ou le chemin encodé dans l'URL du groupe.

--project="" L'identifiant ou le chemin encodé dans l'URL du projet.

OPTIONS HERITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide de cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACEDE NOMMAGE/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Supprimer une étape pour le projet actuel
$ glab milestone delete 123
# Supprimer une étape pour le projet spécifié
$ glab milestone delete 123 --project nom-du-projet
# Supprimer une étape pour le groupe spécifié
$ glab milestone delete 123 --group nom-du-groupe
