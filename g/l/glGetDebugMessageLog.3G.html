DESCRIPTIO

N

glGetDebugMessageLog récupère les messages du journal de messages de débogage. Un maximum de count messages est récupéré depuis le journal. Si sources n'est pas NULL, alors la source de chaque message est écrite dans jusqu'à count éléments du tableau. Si types n'est pas NULL alors le type de chaque message est écrit dans jusqu'à count éléments de le tableau. Si id n'est pas NULL, alors l'identifiant de chaque message est écrit dans jusqu'à count éléments du tableau. Si severities n'est pas NULL, alors la sévérité de chaque message est écrite dans jusqu'à count éléments du tableau. Si lengths n'est pas NULL, alors la longueur de chaque message est écrite dans jusqu'à count éléments de le

tableau.

messageLog spécifie l'adresse d'un tableau de caractères dans lequel les messages de débogage seront écrits. Chaque message sera concaténé au tableau en commençant au premier élément de messageLog. bufSize spécifie la taille du tableau messageLog. Si un message ne peut pas tenir dans l'espace restant dans messageLog, alors la fonction se termine et renvoie le nombre de messages écrits jusqu'à présent, qui peut être

zéro.

Si glGetDebugMessageLog renvoie zéro, alors aucun message n'est présent dans le journal de débogage, ou il n'y avait pas assez d'espace dans messageLog pour récupérer le premier message de la file d'attente. Si messageLog est NULL alors aucun message n'est écrit et la valeur de bufSize es

t ign
orée.

NOTE

S

Bien que les messages de débogage puissent être activés dans un contexte non débogué, la quantité et le détail de ces m

essages peuvent être sensiblement inférieurs à ceux d'un contexte de débogage. En particulier, une implémentation valid
e de la file d'attente de messages de débogage dans un contexte non débogué peut ne produire aucun message du tout.
