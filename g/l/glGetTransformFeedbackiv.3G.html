NOM

glGetTransformFeedbackiv - interroger l'état d'un objet de retour de transformation.

SPÉCIFICATION C

void glGetTransformFeedbackiv(GLuint xfb, GLenum pname, GLint *param);

void glGetTransformFeedbacki_v(GLuint xfb, GLenum pname, GLuint index, GLint *param);

void glGetTransformFeedbacki64_v(GLuint xfb, GLenum pname, GLuint index, GLint64 *param);

PARAMÈTRES

xfb

Le nom d'un objet de retour de transformation existant, ou zéro pour l'objet de retour de transformation par défaut.

pname

Propriété à utiliser pour la requête. Doit être l'une des valeurs : GL_TRANSFORM_FEEDBACK_BUFFER_BINDING, GL_TRANSFORM_FEEDBACK_BUFFER_START, GL_TRANSFORM_FEEDBACK_BUFFER_SIZE, GL_TRANSFORM_FEEDBACK_PAUSED, GL_TRANSFORM_FEEDBACK_ACTIVE.

index

Indice du flux de retour de transformation (pour l'état indexé).

param

L'adresse d'un tampon dans lequel seront écrites les informations d'état demandées.

DESCRIPTION

Afin d'utiliser la fonctionnalité de retour de transformation, vous devez configurer les liaisons indexées des tampons de retour de transformation. Cela peut être réalisé en utilisant glBindBufferBase ou glBindBuffersBase pour associer un stockage d'objet tampon entier à l'un des points de liaison de retour de transformation, ou en appelant glBindBufferRange ou glBindBuffersRange pour utiliser une région de stockage d'objet tampon pour la liaison. Vous pouvez vouloir (mais ce n'est pas obligatoire) lier un objet de retour de transformation en premier, afin de mettre en cache la configuration de la liaison. Cela vous permet généralement de restaurer la configuration de retour de transformation plus rapidement que si vous exécutiez une liste d'appels d'API nécessaires pour configurer l'état de retour de transformation de votre choix.

Cette page de référence traite de deux types de récupérateurs qui agissent sur les objets de retour de transformation et leurs liaisons.

La première classe agit sur le point de liaison général de retour de transformation et comprend la fonction glGetTransformFeedbackiv. glGetTransformFeedbackiv peut être utilisée pour récupérer des informations sur l'objet de retour de transformation lié au point de liaison général de retour de transformation, tel que configuré par un appel à glBindTransformFeedback. Dans ce cas, vous pouvez vérifier :

•Quel est l'ID de l'objet de retour de transformation actuellement lié ; (GL_TRANSFORM_FEEDBACK_BUFFER_BINDING)
•Si le processus de retour de transformation est actuellement en pause ; (GL_TRANSFORM_FEEDBACK_PAUSED)
•Si le processus de retour de transformation a été lancé et est en cours ; (GL_TRANSFORM_FEEDBACK_ACTIVE)

La dernière classe, qui comprend les fonctions glGetTransformFeedbacki_v et glGetTransformFeedbacki64_v, peut être utilisée pour vérifier la configuration actuelle de chaque région d'objet tampon liée aux points de liaison des tampons de retour de transformation. Cela vous permet de rechercher les informations suivantes :

•glGetTransformFeedbacki_v uniquement : Quel est l'ID de l'objet tampon lié à un point de liaison de retour de transformation d'indice spécifié par l'utilisateur ; (GL_TRANSFORM_FEEDBACK_BUFFER_BINDING).
•glGetTransformFeedbacki64_v uniquement : Quel est le décalage de départ configuré pour la liaison ; (GL_TRANSFORM_FEEDBACK_BUFFER_START) ;
•glGetTransformFeedbacki64_v uniquement : Quelle est la longueur de la région utilisée pour la liaison ; (GL_TRANSFORM_FEEDBACK_BUFFER_SIZE) ;

ERREURS

Une erreur GL_INVALID_OPERATION est générée si xfb n'est pas zéro ou le nom d'un objet de retour de transformation existant.

Une erreur GL_INVALID_ENUM est générée par glGetTransformFeedbackiv si pname n'est pas GL_TRANSFORM_FEEDBACK_PAUSED ou GL_TRANSFORM_FEEDBACK_ACTIVE.

Une erreur GL_INVALID_ENUM est générée par glGetTransformFeedbacki_v si pname n'est pas GL_TRANSFORM_FEEDBACK_BUFFER_BINDING.

Une erreur GL_INVALID_ENUM est générée par glGetTransformFeedbacki64_v si pname n'est pas GL_TRANSFORM_FEEDBACK_BUFFER_START ou GL_TRANSFORM_FEEDBACK_BUFFER_SIZE.

Une erreur GL_INVALID_VALUE est générée par glGetTransformFeedbacki_v et glGetTransformFeedbacki64_v si index est supérieur ou égal au nombre de points de liaison pour le retour de transformation (la valeur de GL_MAX_TRANSFORM_FEEDBACK_BUFFERS).
