NOM

glGenTextures - générer des noms de textures

SPÉCIFICATION C

void glGenTextures(GLsizei n, GLuint * textures);

PARAMÈTRES

n

Spécifie le nombre de noms de textures à générer.

textures

Spécifie un tableau dans lequel les noms de textures générés sont stockés.

DESCRIPTION

glGenTextures renvoie n noms de textures dans textures. Il n'y a aucune garantie que les noms forment un ensemble contigu d'entiers ; cependant, il est garanti qu'aucun des noms renvoyés n'était en cours d'utilisation immédiatement avant l'appel à glGenTextures.

Les textures générées n'ont pas de dimensionnalité ; elles prennent la dimensionnalité de la cible de texture à laquelle elles sont d'abord liées (voir glBindTexture()).

Les noms de textures renvoyés par un appel à glGenTextures ne sont pas renvoyés par des appels ultérieurs, à moins qu'ils ne soient d'abord supprimés avec glDeleteTextures().

ERREURS

GL_INVALID_VALUE est généré si n est négatif.

GETS ASSOCIÉS

glIsTexture()
