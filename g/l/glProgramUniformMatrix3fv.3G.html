PARAMETRES

location

Specifies the location of the uniform variable to be modified.

count

Specifies the number of elements that are to be modified. For uniform variables that are not arrays, this value must be 1. For uniform variable arrays, this value indicates the number of elements to be modified, starting from the element specified by location.

transpose

For the matrix commands, specifies whether to transpose the matrix as the values are loaded into the uniform variable.

v0, v1, v2, v3

For the scalar commands, specifies the new values to be used for the specified uniform variable.

value

For the vector and matrix commands, specifies a pointer to an array of count values that will be used to update the specified uniform variable.

DESCRIPTION

glProgramUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glProgramUniform opère sur l'objet programme spécifié par program.

Les commandes glProgramUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs à virgule flottante sont passées; le suffixe i indique que des valeurs entières sont passées; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs aux variables uniformes définies comme int, ivec2, ivec3, ivec4, ou des tableaux de ceux-ci. Les variantes ui de cette fonction doivent être utilisées pour fournir des valeurs aux variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les variantes f doivent être utilisées pour fournir des valeurs aux variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de celles-ci. Les variantes i, ui ou f peuvent être utilisées pour fournir des valeurs aux variables uniformes de type bool, bvec2, bvec3, bvec4, ou des tableaux de celles-ci. La variable uniforme sera mise à false si la valeur d'entrée est 0 ou 0.0f, et elle sera mise à true sinon.

Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lors du succès de la liaison de l'objet programme. Elles conservent les valeurs qui leur ont été assignées par un appel à glProgramUniform jusqu'à la prochaine opération de liaison réussie sur l'objet programme, moment où elles sont à nouveau initialisées à 0.

Les commandes glProgramUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une seule variable uniforme ou un tableau de variables uniformes. Ces commandes passent un nombre et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un nombre de 1 doit être utilisé si l'on modifie la valeur d'une seule variable uniforme, et un nombre de 1 ou plus peut être utilisé pour modifier un tableau entier ou une partie d'un tableau. Lors du chargement de n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 du tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est supérieur à la taille du tableau de variables uniformes, les valeurs pour tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre spécifié dans le nom de la commande indique le nombre de composantes pour chaque élément dans value, et il doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, bool; 2 pour vec2, ivec2, bvec2, etc.). Le type de données spécifié dans le nom de la commande doit correspondre au type de données de la variable uniforme spécifiée, comme décrit précédemment pour glProgramUniform{1|2|3|4}{f|i|ui}.

Pour les tableaux de variables uniformes, chaque élément du tableau est considéré comme étant du type indiqué dans le nom de la commande (par exemple, glProgramUniform3f ou glProgramUniform3fv peut être utilisé pour charger un tableau de variables uniformes de type vec3). Le nombre d'éléments du tableau de variables uniformes à modifier est spécifié par count

Les commandes glProgramUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv sont utilisées pour modifier une matrice ou un tableau de matrices. Les nombres dans le nom de la commande sont interprétés comme la dimensionnalité de la matrice. Le nombre 2 indique une matrice 2 × 2 (c'est-à-dire 4 valeurs), le nombre 3 indique une matrice 3 × 3 (c'est-à-dire 9 valeurs), et le nombre 4 indique une matrice 4 × 4 (c'est-à-dire 16 valeurs). La dimensionnalité des matrices non carrées est explicite, le premier nombre représentant le nombre de colonnes et le second nombre représentant le nombre de lignes. Par exemple, 2x4 indique une matrice 2 × 4 avec 2 colonnes et 4 lignes (c'est-à-dire 8 valeurs). Si transpose est GL_FALSE, chaque matrice est supposée être fournie en ordre de colonne. Si transpose est GL_TRUE, chaque matrice est supposée être fournie en ordre de ligne. L'argument count indique le nombre de matrices à passer. Un nombre de 1 doit être utilisé si l'on modifie la valeur d'une seule matrice, et un nombre supérieur à 1 peut être utilisé pour modifier un tableau de matrices.

NOTES

glProgramUniform1i et glProgramUniform1iv sont les deux seules fonctions qui peuvent être utilisées pour charger des variables uniformes définies comme types échantillonneurs. Le chargement d'échantillonneurs avec toute autre fonction entraînera une erreur GL_INVALID_OPERATION.

Si count est supérieur à 1 et que la variable uniforme indiquée n'est pas un tableau, une erreur GL_INVALID_OPERATION est générée et la variable uniforme spécifiée restera inchangée.

À l'exception des exceptions précédentes, si le type et la taille de la variable uniforme tels que définis dans le shader ne correspondent pas au type et à la taille spécifiés dans le nom de la commande utilisée pour charger sa valeur, une erreur GL_INVALID_OPERATION sera générée et la variable uniforme spécifiée restera inchangée.

Si location est une valeur autre que -1 et qu'elle ne représente pas un emplacement de variable uniforme valide dans program, une erreur sera générée, et aucune modification ne sera apportée au stockage de la variable uniforme de program. Si location est égal à -1, les données fournies seront ignorées silencieusement et la variable uniforme spécifiée ne sera pas modifiée.

ERREURS

GL_INVALID_OPERATION est généré si program ne fait pas référence à un objet programme appartenant au GL.

GL_INVALID_OPERATION est généré si la taille de la variable uniforme déclarée dans le shader ne correspond pas à la taille indiquée par la commande glProgramUniform.

GL_INVALID_OPERATION est généré si l'une des variantes entières signées ou non signées de cette fonction est utilisée pour charger une variable uniforme de type float, vec2, vec3, vec4, ou un tableau de celles-ci, ou si l'une des variantes à virgule flottante de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières signées de cette fonction est utilisée pour charger une variable uniforme de type unsigned int, uvec2, uvec3, uvec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières non signées de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si location est un emplacement uniforme invalide pour program et que location n'est pas égal à -1.

GL_INVALID_VALUE est généré si count est inférieur à 0.

GL_INVALID_OPERATION est généré si count est supérieur à 1 et que la variable uniforme indiquée n'est pas une variable de tableau.

GL_INVALID_OPERATION est généré si un échantillonneur est chargé en utilisant une commande autre que glProgramUniform1i et glProgramUniform1iv.
