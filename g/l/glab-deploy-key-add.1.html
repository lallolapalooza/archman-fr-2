NOM

glab-deploy-key-add - Ajoute une clé de déploiement à un projet GitLab.

SYNTAXE

glab deploy-key add [fichier-clé] [options]

DESCRIPTION

Crée une nouvelle clé de déploiement.

Nécessite l'option '--title'.

OPTIONS

-c, --can-push[=false] Si vrai, les clés de déploiement peuvent être utilisées pour envoyer du code au dépôt.

-e, --expires-at="" La date d'expiration de la clé de déploiement, au format ISO-8601 : YYYY-MM-DDTHH:MM:SSZ.

-t, --title="" Le titre de la nouvelle clé de déploiement.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACEDENOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Lit la clé de déploiement depuis l'entrée standard et l'envoie.
$ glab deploy-key add -t "mon titre"
# Lit la clé de déploiement depuis le fichier de clé spécifié et l'envoie
$ cat ~/.ssh/id_ed25519.pub | glab deploy-key add --title='test' -
# Lit la clé de déploiement depuis le fichier de clé spécifié, l'envoie et définit l'attribut "peut envoyer".
$ glab deploy-key add ~/.ssh/id_ed25519.pub -t "mon titre" --can-push true
