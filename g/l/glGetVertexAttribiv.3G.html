DESCRIPTIO

N

glGetVertexAttrib renvoie dans params la valeur d'un paramètre d'attribut de sommet générique. L'attribut de sommet générique à interroger est spécifié par index, et le paramètre à interroger est spécifié par pname

.

Les noms de paramètres acceptés sont les suivants

:

GL_VERTEX_ATTRIB_ARRAY_BUFFER_BINDIN

G

params renvoie une seule valeur, le nom de l'objet tampon actuellement lié au point de liaison correspondant au tableau d'attributs de sommet générique index. Si aucun objet tampon n'est lié, 0

est renvoyé. La v
aleur initiale est 0.

GL_VERTEX_ATTRIB_ARRAY_ENABLE

D

params renvoie une seule valeur non nulle (vrai) si le tableau d'attributs de sommet pour index est activé et 0 (faux) s'il est désactivé. La valeur initiale est GL_F

ALS
E.

GL_VERTEX_ATTRIB_ARRAY_SIZ

E

params renvoie une seule valeur, la taille du tableau d'attributs de sommet pour index. La taille est le nombre de valeurs pour chaque élément du tableau d

'attributs de sommet, et elle sera 1, 2
, 3 ou 4. La valeur initiale est 4.

GL_VERTEX_ATTRIB_ARRAY_STRID

E

params renvoie une seule valeur, le pas du tableau (le nombre d'octets entre les éléments successifs dans) le tableau d'attributs de sommet pour index. Une valeur de 0 indique que les éléments du tableau so

nt stockés séquentiellement en mé
moire. La valeur initiale est 0.

GL_VERTEX_ATTRIB_ARRAY_TYP

E

params renvoie une seule valeur, une constante symbolique indiquant le type de tableau pour le tableau d'attributs de sommet pour index. Les valeurs possibles sont GL_BYTE, GL_UNSIGNED_BYTE, GL_SHORT, GL_UNSIGNED_SHORT, GL_INT, GL_UNSIGNED_INT, GL_FLOAT, et GL_DOUBLE. La valeur initiale est GL_F

LOA
T.

GL_VERTEX_ATTRIB_ARRAY_NORMALIZE

D

params renvoie une seule valeur non nulle (vrai) si les types de données à virgule fixe pour le tableau d'attributs de sommet indiqué par index sont normalisés lorsqu'ils sont convertis en virgule flottante, et 0 (faux) sinon. La valeur initiale est GL_F

ALS
E.

GL_VERTEX_ATTRIB_ARRAY_INTEGE

R

params renvoie une seule valeur non nulle (vrai) si les types de données à virgule fixe pour le tableau d'attributs de sommet indiqué par index ont des types de données entiers, et 0 (faux) sinon. La valeur initiale est 0 (GL_FA

LSE
).

GL_VERTEX_ATTRIB_ARRAY_LON

G

param renvoie une seule valeur non nulle (vrai) si un attribut de sommet est stocké comme un double non converti, et 0 (faux) sinon. La valeur initiale est 0 (GL_FA

LSE
).

GL_VERTEX_ATTRIB_ARRAY_DIVISO

R

params renvoie une seule valeur qui est le diviseur de fréquence utilisé pour le rendu instancié. Voir glVertexAttribDivisor(). La

valeur i
nitiale est 0.

GL_VERTEX_ATTRIB_BINDIN

G

params renvoie une seule valeur, la liaison du tampon de sommet du tableau d'attributs de sommet ind

e
x.

GL_VERTEX_ATTRIB_RELATIVE_OFFSE

T

params renvoie une seule valeur qui est le décalage en octets du premier élément par rapport au début de la liais

on du tampon de sommet à partir de laquelle les attribu
ts spécifiés sont récupérés. La valeur initiale est 0.

GL_CURRENT_VERTEX_ATTRI

B

params renvoie quatre valeurs représentant la valeur actuelle pour l'attribut de sommet générique spécifié par index. L'attribut de sommet générique 0 est unique en ce qu'il n'a pas d'état actuel, donc une erreur sera générée si index vaut 0. La valeur initiale pour tous les autres attributs de sommet génériques est (0,0,0,1)

.

glGetVertexAttribdv et glGetVertexAttribfv renvoient les valeurs d'attribut actuelles sous forme de quatre valeurs flottantes de précision simple ; glGetVertexAttribiv les lit comme des valeurs flottantes et les convertit en quatre valeurs entières ; glGetVertexAttribIiv et glGetVertexAttribIuiv les lisent et les renvoient respectivement sous forme de valeurs entières signées ou non signées ; glGetVertexAttribLdv les lit et les renvoie sous f

orme de quatre valeurs flot
tantes de double précision.

Tous les paramètres sauf GL_CURRENT_VERTEX_ATTRIB représentent l'état stocké

dans l'objet de tableau de
sommet actuellement lié.

NOTE

S

Si une erreur est générée, aucune modification n'est apportée au contenu de para

m
s.

ERREUR

S

GL_INVALID_OPERATION est généré si pname n'est pas GL_CURRENT_VERTEX_ATTRIB et qu'il n'y a pas d'objet de tableau de sommet actuellement

lié.

GL_INVALID_VALUE est généré si index est supérieur ou égal à GL_MAX_VERTEX_ATTRIBS

.

GL_INVALID_ENUM est généré si pname n'est pas une valeur

acceptée.

GL_INVALID_OPERATION est généré si index vaut 0 et pname est GL_CURRENT_VERTEX_ATTRI

B
.
