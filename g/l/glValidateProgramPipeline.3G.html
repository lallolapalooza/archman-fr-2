NOM

glValidateProgramPipeline - valide un objet pipeline de programme par rapport à l'état GL actuel

SPÉCIFICATION C

void glValidateProgramPipeline(GLuint pipeline);

PARAMÈTRES

pipeline

Spécifie le nom d'un objet pipeline de programme à valider.

DESCRIPTION

glValidateProgramPipeline demande à l'implémentation de valider les exécutables de shader contenus dans pipeline par rapport à l'état GL actuel. L'implémentation peut utiliser ceci comme une opportunité pour effectuer toutes les modifications de shader internes qui pourraient être nécessaires pour assurer le fonctionnement correct des shaders installés étant donné l'état GL actuel.

Après qu'un pipeline de programme ait été validé, son statut de validation est défini à GL_TRUE. Le statut de validation d'un objet pipeline de programme peut être interrogé en appelant glGetProgramPipeline() avec le paramètre GL_VALIDATE_STATUS.

Si pipeline est un nom retourné précédemment par un appel à glGenProgramPipelines() mais qui n'a pas encore été lié par un appel à glBindProgramPipeline(), un nouvel objet pipeline de programme est créé avec le nom pipeline et l'état vectoriel par défaut.

ERREURS

GL_INVALID_OPERATION est généré si pipeline n'est pas un nom retourné précédemment par un appel à glGenProgramPipelines() ou si un tel nom a été supprimé par un appel à glDeleteProgramPipelines().

OBTIENT ASSOCIÉS

glGetProgramPipeline() avec le paramètre GL_VALIDATE_STATUS.
