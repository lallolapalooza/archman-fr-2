NOM

glGetVertexArrayiv - récupérer les paramètres d'un objet tableau de sommets

SPÉCIFICATION C

void glGetVertexArrayiv(GLuint vaobj, GLenum pname, GLint *param);

PARAMÈTRES

vaobj

spécifie le nom de l'objet tableau de sommets à utiliser pour la requête.

pname

Nom de la propriété à utiliser pour la requête. Doit être GL_ELEMENT_ARRAY_BUFFER_BINDING.

param

Retourne la valeur demandée.

DESCRIPTION

Cette fonction fournit un moyen d'interroger les propriétés d'un objet tableau de sommets existant. L'objet tableau de sommets n'a pas besoin d'être lié au contexte de rendu au moment de l'appel, mais doit avoir été lié au moins une fois avant cet appel.

glGetVertexArrayiv peut être utilisé pour récupérer l'ID d'un objet tampon qui sera lié au point de liaison GL_ELEMENT_ARRAY_BUFFER chaque fois que l'objet tableau de sommets interrogé est lié au contexte de rendu. La liaison peut être modifiée pour un objet tableau de sommets actif avec un appel glBindBuffer.

ERREURS

Une erreur GL_INVALID_OPERATION est générée si vaobj n'est pas le nom d'un objet tableau de sommets existant.

Une erreur GL_INVALID_ENUM est générée si pname n'est pas GL_ELEMENT_ARRAY_BUFFER_BINDING.
