NOM

glClearStencil - spécifie la valeur de nettoyage pour le tampon pochoir

SPÉCIFICATION C

void glClearStencil(GLint s);

PARAMÈTRES

s

Spécifie l'indice utilisé lorsque le tampon pochoir est nettoyé. La valeur initiale est 0.

DÉSCRIPTION

glClearStencil spécifie l'indice utilisé par glClear() pour nettoyer le tampon pochoir. s est masqué avec 2 m - 1, où m est le nombre de bits dans le tampon pochoir.

GETS ASSOCIÉS

glGet() avec l'argument GL_STENCIL_CLEAR_VALUE

glGet() avec l'argument GL_STENCIL_BITS
