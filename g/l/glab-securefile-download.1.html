NOM

glab-securefile-download - Télécharger un fichier sécurisé pour un projet.

SYNTAXE

glab securefile download [indicateurs]

DESCRIPTION

Télécharger un fichier sécurisé pour un projet.

OPTIONS

--all[=false] Télécharger tous les fichiers sécurisés (limite 100) d'un projet. Les fichiers sont téléchargés avec leur nom et leur extension d'origine.

--force-download[=false] Forcer le téléchargement des fichiers même si la vérification de la somme de contrôle échoue. Attention : lorsqu'il est activé, ce paramètre permet le téléchargement de fichiers corrompus ou falsifiés.

--id=0 ID du fichier sécurisé à télécharger.

--name="" Nom du fichier sécurisé à télécharger. Sauvegarde le fichier avec ce nom, ou vers le chemin spécifié par --path.

--no-verify[=false] Ne pas vérifier la somme de contrôle des fichiers téléchargés. Attention : lorsqu'il est activé, ce paramètre permet le téléchargement de fichiers corrompus ou falsifiés.

--output-dir="." Répertoire de sortie pour les fichiers téléchargés avec --all.

-p, --path="./downloaded.tmp" Chemin où télécharger le fichier sécurisé, y compris le nom du fichier et son extension.

OPTIONS HERITEES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIETAIRE/REPO ou GROUPE/ESPACENOM/REPO. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Télécharger un fichier sécurisé d'un projet en utilisant l'ID du fichier par argument ou indicateur.
$ glab securefile download 1
$ glab securefile download --id 1
# Télécharger un fichier sécurisé d'un projet vers un chemin donné.
$ glab securefile download 1 --path="fichiers_securises/fichier.txt"
# Télécharger un fichier sécurisé d'un projet sans vérifier sa somme de contrôle.
$ glab securefile download 1 --no-verify
# Télécharger un fichier sécurisé d'un projet même si la vérification de la somme de contrôle échoue.
$ glab securefile download 1 --force-download
# Télécharger un fichier sécurisé d'un projet en utilisant le nom du fichier dans le répertoire courant.
$ glab securefile download --name mon-fichier-securise.pem
# Télécharger un fichier sécurisé d'un projet en utilisant le nom du fichier vers un chemin donné.
$ glab securefile download --name mon-fichier-securise.pem --path=fichiers_securises/un-autre-nom.pem
# Télécharger tous les fichiers sécurisés d'un projet (limite 100).
$ glab securefile download --all
# Télécharger tous les fichiers sécurisés d'un projet (limite 100) vers un répertoire donné.
$ glab securefile download --all --output-dir fichiers_securises/
