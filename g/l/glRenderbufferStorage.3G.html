NOM

glRenderbufferStorage, glNamedRenderbufferStorage - définir le stockage de données, le format et les dimensions de l'image d'un objet tampon de rendu

SPÉCIFICATION C

void glRenderbufferStorage(GLenumtarget, GLenuminternalformat, GLsizeiwidth, GLsizeiheight);

void glNamedRenderbufferStorage(GLuintrenderbuffer, GLenuminternalformat, GLsizeiwidth, GLsizeiheight);

PARAMÈTRES

target

Spécifie une cible de liaison pour l'allocation de la glRenderbufferStorage fonction. Doit être GL_RENDERBUFFER.

renderbuffer

Spécifie le nom de l'objet tampon de rendu pour la glNamedRenderbufferStorage fonction.

internalformat

Spécifie le format interne à utiliser pour l'image de l'objet tampon de rendu.

width

Spécifie la largeur du tampon de rendu, en pixels.

height

Spécifie la hauteur du tampon de rendu, en pixels.

DESCRIPTION

glRenderbufferStorage est équivalent à appeler glRenderbufferStorageMultisample() avec le paramètre samples défini à zéro, et glNamedRenderbufferStorage est équivalent à appeler glNamedRenderbufferStorageMultisample avec les échantillons définis à zéro.

Pour glRenderbufferStorage, la cible de l'opération, spécifiée par target doit être GL_RENDERBUFFER. Pour glNamedRenderbufferStorage, renderbuffer doit être le nom d'un objet tampon de rendu existant. internalformat spécifie le format interne à utiliser pour le stockage de l'objet tampon de rendu et doit être un format rendable en couleur, en profondeur ou en stencil. width et height sont les dimensions, en pixels, du tampon de rendu. Les deux width et height doivent être inférieurs ou égaux à la valeur de GL_MAX_RENDERBUFFER_SIZE.

En cas de succès, glRenderbufferStorage et glNamedRenderbufferStorage suppriment tout magasin de données existant pour l'image du tampon de rendu et le contenu du magasin de données après l'appel à glRenderbufferStorage est indéfini.

ERREUR

GL_INVALID_ENUM est généré par glRenderbufferStorage si target n'est pas GL_RENDERBUFFER.

GL_INVALID_OPERATION est généré par glNamedRenderbufferStorage si renderbuffer n'est pas le nom d'un objet tampon de rendu existant.

GL_INVALID_VALUE est généré si l'un des width ou height est négatif, ou supérieur à la valeur de GL_MAX_RENDERBUFFER_SIZE.

GL_INVALID_ENUM est généré si internalformat n'est pas un format rendable en couleur, en profondeur ou en stencil.

GL_OUT_OF_MEMORY est généré si le GL est incapable de créer un magasin de données de la taille demandée.
