NOM

glClearColor - spécifie les valeurs de nettoyage pour les tampons de couleur

SPÉCIFICATION C

void glClearColor(GLfloat red, GLfloat green, GLfloat blue, GLfloat alpha);

PARAMÈTRES

red, green, blue, alpha

Spécifient les valeurs rouge, verte, bleue et alpha utilisées lors du nettoyage des tampons de couleur. Les valeurs initiales sont toutes à 0.

DESCRIPTION

glClearColor spécifie les valeurs rouge, verte, bleue et alpha utilisées par glClear() pour nettoyer les tampons de couleur. Les valeurs spécifiées par glClearColor sont limitées à la plage 0 1.

NOTES

Le type des paramètres red, green, blue et alpha a été modifié de GLclampf à GLfloat. Ce changement est transparent pour le code utilisateur et est décrit en détail sur la page removedTypes().

GET ASSOCIÉS

glGet() avec l'argument GL_COLOR_CLEAR_VALUE
