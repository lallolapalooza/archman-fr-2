NOM

glab-alias-set - Définir un alias pour une commande plus longue.

SYNTAXE

glab alias set '' [options]

DESCRIPTION

Déclare un mot comme alias pour une commande plus longue.

Votre expansion peut inclure des arguments et des options. Si votre expansion inclut des espaces réservés positionnels tels que $1 ou $2, les arguments supplémentaires qui suivent l'invocation d'un alias sont insérés de manière appropriée.

Spécifiez --shell dans votre alias pour l'exécuter via sh, un convertisseur de shell. La conversion de shell vous permet de composer des commandes avec | ou de rediriger avec >, avec ces mises en garde :

  • Les arguments supplémentaires suivant l'alias ne sont pas passés aux arguments de l'expression étendue par défaut.
  • Vous devez accepter explicitement les arguments en utilisant $1, $2, et ainsi de suite.
  • Utilisez $@ pour accepter tous les arguments.

Pour les utilisateurs de Windows uniquement :

  • Sous Windows, les alias de shell sont exécutés avec sh tel qu'installé par Git pour Windows. Si vous avez installé Git d'une autre manière sous Windows, les alias de shell pourraient ne pas fonctionner pour vous.
  • Utilisez toujours des guillemets lors de la définition d'une commande, comme dans les exemples.

OPTIONS

-s, --shell[=false] Déclare un alias à passer par un interpréteur de shell.

OPTIONS HERITEES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab alias set mrv 'mr view'
$ glab mrv -w 123
> glab mr view -w 123
$ glab alias set createissue 'glab create issue --title "$1"'
$ glab createissue "Mon Ticket" --description "Quelque chose ne fonctionne pas."
> glab create issue --title "Mon Ticket" --description "Quelque chose ne fonctionne pas."
$ glab alias set --shell igrep 'glab issue list --assignee="$1" | grep $2'
$ glab igrep user foo
> glab issue list --assignee="user" | grep "foo"
