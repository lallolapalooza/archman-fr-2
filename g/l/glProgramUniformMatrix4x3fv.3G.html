DESCRIPTION

glProgramUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glProgramUniform opère sur l'objet programme spécifié par program.

Les commandes glProgramUniform{1|2|3|4}{f|i|ui} sont utilisées pour modifier la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs flottantes sont transmises ; le suffixe i indique que des valeurs entières sont transmises ; le suffixe ui indique que des valeurs entières non signées sont transmises, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs aux variables uniformes définies comme int, ivec2, ivec3, ivec4, ou des tableaux de celles-ci. Les variantes ui doivent être utilisées pour fournir des valeurs aux variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de celles-ci. Les variantes f doivent être utilisées pour fournir des valeurs aux variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de celles-ci. Les variantes i, ui ou f peuvent être utilisées pour fournir des valeurs aux variables uniformes de type bool, bvec2, bvec3, bvec4, ou des tableaux de celles-ci. La variable uniforme sera définie sur false si la valeur d'entrée est 0 ou 0.0f, et elle sera définie sur true sinon.

Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. Elles conservent les valeurs qui leur sont assignées par un appel à glProgramUniform jusqu'à la prochaine opération de liaison réussie sur l'objet programme, moment où elles sont à nouveau initialisées à 0.

Les commandes glProgramUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une seule variable uniforme ou un tableau de variables uniformes. Ces commandes transmettent un nombre et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un nombre de 1 doit être utilisé si on modifie la valeur d'une seule variable uniforme, et un nombre de 1 ou plus peut être utilisé pour modifier un tableau entier ou une partie d'un tableau. Lors du chargement de n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 du tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est supérieur à la taille du tableau de variables uniformes, les valeurs pour tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre spécifié dans le nom de la commande indique le nombre de composantes pour chaque élément de value, et il doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, bool ; 2 pour vec2, ivec2, bvec2, etc.). Le type de données spécifié dans le nom de la commande doit correspondre au type de données de la variable uniforme spécifiée, comme décrit précédemment pour glProgramUniform{1|2|3|4}{f|i|ui}.

Pour les tableaux de variables uniformes, chaque élément du tableau est considéré comme étant du type indiqué dans le nom de la commande (par exemple, glProgramUniform3f ou glProgramUniform3fv peuvent être utilisés pour charger un tableau de variables uniformes de type vec3). Le nombre d'éléments du tableau de variables uniformes à modifier est spécifié par count.

Les commandes glProgramUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv sont utilisées pour modifier une matrice ou un tableau de matrices. Les nombres dans le nom de la commande sont interprétés comme la dimensionnalité de la matrice. Le nombre 2 indique une matrice 2 × 2 (c'est-à-dire 4 valeurs), le nombre 3 indique une matrice 3 × 3 (c'est-à-dire 9 valeurs), et le nombre 4 indique une matrice 4 × 4 (c'est-à-dire 16 valeurs). La dimensionnalité des matrices non carrées est explicite, le premier nombre représentant le nombre de colonnes et le second nombre représentant le nombre de lignes. Par exemple, 2x4 indique une matrice 2 × 4 avec 2 colonnes et 4 lignes (c'est-à-dire 8 valeurs). Si transpose est GL_FALSE, chaque matrice est supposée être fournie en ordre de colonne. Si transpose est GL_TRUE, chaque matrice est supposée être fournie en ordre de ligne. L'argument count indique le nombre de matrices à transmettre. Un nombre de 1 doit être utilisé si on modifie la valeur d'une seule matrice, et un nombre supérieur à 1 peut être utilisé pour modifier un tableau de matrices.

NOTES

glProgramUniform1i et glProgramUniform1iv sont les deux seules fonctions qui peuvent être utilisées pour charger des variables uniformes définies comme types d'échantillonneurs. Le chargement d'échantillonneurs avec toute autre fonction entraînera une erreur GL_INVALID_OPERATION.

Si count est supérieur à 1 et que la variable uniforme indiquée n'est pas un tableau, une erreur GL_INVALID_OPERATION est générée et la variable uniforme spécifiée ne sera pas modifiée.

À l'exception des exceptions précédentes, si le type et la taille de la variable uniforme tels que définis dans le shader ne correspondent pas au type et à la taille spécifiés dans le nom de la commande utilisée pour charger sa valeur, une erreur GL_INVALID_OPERATION sera générée et la variable uniforme spécifiée restera inchangée.

Si location est une valeur autre que -1 et qu'elle ne représente pas un emplacement de variable uniforme valide dans program, une erreur sera générée et aucune modification ne sera apportée au stockage de la variable uniforme de program. Si location est égal à -1, les données transmises seront ignorées silencieusement et la variable uniforme spécifiée ne sera pas modifiée.

ERREURS

GL_INVALID_OPERATION est généré si program ne fait pas référence à un objet programme appartenant au GL.

GL_INVALID_OPERATION est généré si la taille de la variable uniforme déclarée dans le shader ne correspond pas à la taille indiquée par la commande glProgramUniform.

GL_INVALID_OPERATION est généré si l'une des variantes entières signées ou non signées de cette fonction est utilisée pour charger une variable uniforme de type float, vec2, vec3, vec4, ou un tableau de celles-ci, ou si l'une des variantes flottantes de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières signées de cette fonction est utilisée pour charger une variable uniforme de type unsigned int, uvec2, uvec3, uvec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières non signées de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, ou un tableau de celles-ci.

GL_INVALID_OPERATION est généré si location est un emplacement uniforme invalide pour program et que location n'est pas égal à -1.

GL_INVALID_VALUE est généré si count est inférieur à 0.

GL_INVALID_OPERATION est généré si count est supérieur à 1 et que la variable uniforme indiquée n'est pas une variable de tableau.

GL_INVALID_OPERATION est généré si un échantillonneur est chargé en utilisant une commande autre que glProgramUniform1i et glProgramUniform1iv.

NAME

glProgramUniformMatrix4x3fv — set the value of a uniform variable in the calling program object

C SPECIFICATION

void glProgramUniformMatrix4x3fv( GLuint program, GLint location, GLsizei count, GLboolean transpose, const GLfloat *value );

PARAMETERS

program
Specifies the program object containing the uniform variable to be modified.
location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of `mat4x3' matrices that will be downloaded and uploaded to the uniform variable.
transpose
Specifies whether to transpose the matrix or matrices. Must be GL_FALSE.
value
Specifies a pointer to the new values that will be used to update the specified uniform variable.

DESCRIPTION

With the exception of the program argument, the parameters for glProgramUniformMatrix4x3fv correspond to those of `glUniformMatrix4x3fv'.

glProgramUniformMatrix4x3fv sets the value of a uniform variable within the specified program object. This command may not be used to set the value of a uniform variable in a program object that is not part of the currently active program pipeline. If the uniform variable is not found, or if program is not a program object, then glProgramUniformMatrix4x3fv does nothing.

If program is a program object that has been linked successfully, and if location is a valid uniform location for the active program object, then the indicated uniform variable within that program object is set to value.

The uniform variable specified by location must be a `mat4x3' or `mat4x3v' (a column-major matrix with 4 rows and 3 columns). If location corresponds to a uniform array, the elements `location' through `location + count - 1' are updated.

If transpose is GL_TRUE, the matrix or matrices indicated by value are transposed before being applied to the uniform variable. If transpose is GL_FALSE, the matrices are loaded as specified.

count indicates the number of matrices to be downloaded and uploaded. It must be 1 or greater.

The values passed in value are laid out in column-major order. That is, for a single `mat4x3' matrix: 

     | m00 m10 m20 m30 |
     | m01 m11 m21 m31 |
     | m02 m12 m22 m32 |

the values in value are m00, m01, m02, m10, m11, m12, m20, m21, m22, m30, m31, m32.

NOTES

glProgramUniformMatrix4x3fv is available only when the GLSL version is 1.20 or greater.

The transpose argument is ignored by desktop OpenGL implementations, as all matrices are assumed to be column-major. It is provided for compatibility with OpenGL ES.

For OpenGL versions 3.0 and greater, it is recommended to use glProgramUniformMatrix4x3fv instead of the older `glUniformMatrix4x3fv' when working with program objects.

If the uniform variable specified by location is not present in the program object, then the command has no effect.

If location does not correspond to a uniform variable, or if program is not a program object, an error will be generated.

ERRORS

GL_INVALID_OPERATION is generated if program is not a value generated by the execution of glCreateProgram.

GL_INVALID_OPERATION is generated if program is not the name of an object for which glLinkProgram has been executed successfully.

GL_INVALID_OPERATION is generated if location is not a valid uniform location for the active program object.

GL_INVALID_VALUE is generated if count is less than 1.
