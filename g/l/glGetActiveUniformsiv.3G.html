DESCRIPTIO

N

glGetActiveUniformsiv interroge la valeur du paramètre nommé pname pour chacun des uniformes dans program dont les indices sont spécifiés dans le tableau de uniformCount entiers non signés uniformIndices. En cas de succès, la valeur du paramètre pour chaque uniforme est écrite dans l'entrée correspondante du tableau dont l'adresse est donnée dans params. Si une erreur est générée, rien n'est écrit dans params

.

Si pname est GL_UNIFORM_SIZE, alors un tableau identifiant la taille des uniformes spécifiés par le tableau correspondant de uniformIndices est renvoyé. Les tailles renvoyées sont en unités du type renvoyé par une interrogation de GL_UNIFORM_TYPE. Pour les uniformes actifs qui sont des tableaux, la taille est le nombre d'éléments actifs dans le tableau ; pour tous les autres uniformes, la taille est

un.

Si pname est GL_UNIFORM_NAME_LENGTH, alors un tableau identifiant la longgth, y compris le caractère nul de fin, des chaînes de noms uniformes spécifiées par le tableau correspondant de uniformIndices est

retourné.

Si pname est GL_UNIFORM_BLOCK_INDEX, un tableau identifiant l'indice du bloc uniforme de chacun des uniformes spécifiés par le tableau correspondant de uniformIndices est retourné. L'indice du bloc uniforme d'un uniforme associé au bloc uniforme par défaut est

-1.

Si pname est GL_UNIFORM_OFFSET, un tableau de décalages de tampon uniforme est retourné. Pour les uniformes dans un bloc uniforme nommé, la valeur retournée sera son décalage, en unités machine de base, par rapport au début des données du bloc uniforme dans le magasin de données de l'objet tampon. Pour les uniformes de compteur atomique, la valeur retournée sera son décalage par rapport au début de son tampon de compteurs atomiques actif. Pour tous les autres uniformes, -1 sera

retourné.

Si pname est GL_UNIFORM_ARRAY_STRIDE, un tableau identifiant le pas entre les éléments de chacun des uniformes spécifiés par le tableau correspondant de uniformIndices est retourné. Pour les uniformes dans des blocs uniformes nommés et pour les uniformes déclarés comme compteurs atomiques, le pas est la différence, en unités machine de base, entre les éléments consécutifs d'un tableau, ou zéro pour les uniformes non déclarés comme tableau. Pour tous les autres uniformes, un pas de -1 sera

retourné.

Si pname est GL_UNIFORM_MATRIX_STRIDE, un tableau identifiant le pas entre les colonnes d'une matrice en ordre colonne ou les lignes d'une matrice en ordre ligne, en unités machine de base, de chacun des uniformes spécifiés par le tableau correspondant de uniformIndices est retourné. Le pas de matrice d'un uniforme associé au bloc uniforme par défaut est -1. Notez que cette information n'a de sens que pour les uniformes qui sont des matrices. Pour les uniformes qui ne sont pas des matrices, mais qui sont déclarés dans un bloc uniforme nommé, un pas de matrice de zéro est

retourné.

Si pname est GL_UNIFORM_IS_ROW_MAJOR, un tableau identifiant si chacun des uniformes spécifiés par le tableau correspondant de uniformIndices est une matrice en ordre ligne ou non est retourné. Une valeur de un indique une matrice en ordre ligne, et une valeur de zéro indique une matrice en ordre colonne, une matrice dans le bloc uniforme par défaut, ou une

non-matrice.

Si pname est GL_UNIFORM_ATOMIC_COUNTER_BUFFER_INDEX, un tableau identifiant l'indice du tampon de compteurs atomiques actif de chacun des uniformes spécifiés par le tableau correspondant de uniformIndices est retourné. Pour les uniformes autres que les compteurs atomiques, l'indice de tampon retourné est -1. Les indices retournés peuvent être passés à glGetActiveAtomicCounterBufferiv() pour interroger les propriétés du tampon associé,

et pas nécessairement le point de liaison spé
cifié dans la déclaration de l'uniforme.

NOTE

S

Les types double, GL_DOUBLE, GL_DOUBLE_VEC2, GL_DOUBLE_VEC3, GL_DOUBLE_VEC4, GL_DOUBLE_MAT2, GL_DOUBLE_MAT3, GL_DOUBLE_MAT4, GL_DOUBLE_MAT2x3, GL_DOUBLE_MAT2x4, GL_DOUBLE_MAT3x2, GL_DOUBLE_MAT3x4, GL_DOUBLE_MAT4x2, et GL_DOUBLE_MAT4x3 ne sont disponibles que si la version de GL est 4.1 ou

supérieure.

GL_UNIFORM_ATOMIC_COUNTER_BUFFER_INDEX n'est accepté par pname que si la version de

GL est 4.2 o
u supérieure.

ERREUR

S

GL_INVALID_VALUE est généré si program n'est pas une valeur générée par

OpenGL.

GL_INVALID_OPERATION est généré si program n'est pas un objet

programme.

GL_INVALID_VALUE est généré si uniformCount est supérieur ou égal à la valeur de GL_ACTIVE_UNIFORMS pour program

.

GL_INVALID_ENUM est généré si pname n'est pas un

jeton
accepté.
