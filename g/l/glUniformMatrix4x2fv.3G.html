PARAMÈTRES

location

Spécifie l'emplacement de la variable uniforme à modifier.

count

Pour les commandes de vecteur (glUniform*v), spécifie le nombre d'éléments à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau, et 1 ou plus si c'est un tableau.

Pour les commandes de matrice (glUniformMatrix*), spécifie le nombre de matrices à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau de matrices, et 1 ou plus si c'est un tableau de matrices.

transpose

Pour les commandes de matrice, spécifie si la matrice doit être transposée lors du chargement des valeurs dans la variable uniforme.

v0, v1, v2, v3

Pour les commandes scalaires, spécifie les nouvelles valeurs à utiliser pour la variable uniforme spécifiée.

value

Pour les commandes de vecteur et de matrice, spécifie un pointeur vers un tableau de count valeurs qui sera utilisé pour mettre à jour la variable uniforme spécifiée.

DESCRIPTION

glUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant par l'appel à glUseProgram().

Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes du type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs flottantes sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs aux variables uniformes définies

Les variantes ui de cette fonction doivent être utilisées pour fournir des valeurs pour des variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les variantes f doivent être utilisées pour fournir des valeurs pour des variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de ceux-ci. Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. Les commandes glUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une variable uniforme unique ou un tableau de variables uniformes. Ces commandes passent un compte et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un compte de 1 doit être utilisé si l'on modifie la valeur d'une seule variable uniforme, et un compte de 1 ou supérieur peut être utilisé pour modifier un tableau entier ou une partie d'un tableau. Lors du chargement de n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 dans le tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est plus grand que la taille du tableau de variables uniformes, les valeurs pour tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre spécifié dans le nom de la commande indique le nombre de composantes pour chaque élément dans value, et il doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, bool ; 2 pour vec2, ivec2, bvec2, etc.). Le type de données spécifié dans le nom de la commande doit correspondre au type de données de la variable uniforme spécifiée comme décrit précédemment pour glUniform{1|2|3|4}

{f|i|ui}.

Pour les tableaux de variables uniformes, chaque élément du tableau est considéré comme étant du type indiqué dans le nom de la commande (par exemple, glUniform3f ou glUniform3fv peuvent être utilisés pour charger un tableau de variables uniformes de type vec3). Les commandes glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv sont utilisées pour modifier une matrice ou un tableau de matrices. Les nombres dans le nom de la commande sont interprétés comme la dimensionnalité de la matrice. Le nombre 2 indique une matrice 2 × 2 (c'est-à-dire 4 valeurs), le nombre 3 indique une matrice 3 × 3 (c'est-à-dire 9 valeurs), et le nombre 4 indique une matrice 4 × 4 (c'est-à-dire 16 valeurs). La dimensionnalité des matrices non carrées est explicite, le premier nombre représentant le nombre de colonnes et le second nombre représentant le nombre de lignes. Par exemple, 2x4 indique une matrice 2 × 4 avec 2 colonnes et 4 lignes (c'est-à-dire 8 valeurs). Si transpose est GL_FALSE, chaque matrice est supposée être fournie dans l'ordre colonne majeur. Si transpose est GL_TRUE, chaque matrice est supposée être fournie dans l'ordre ligne majeur. L'argument count indique le nombre de matrices à passer. Un compte de 1 doit être utilisé si l'on modifie la vale

ur d'une seule matrice, et un compte supérieur à 1 peut être utilisé pour modifier un tableau de matrices.

NAME

glUniformMatrix4x2fv — specify the value of a uniform matrix

C SPECIFICATION

void glUniformMatrix4x2fv( GLint location,
 GLsizei count,
 GLboolean transpose,
 const GLfloat *value );

PARAMETERS

location

Specifies the integer token for the uniform variable to be modified.

count

Specifies the number of matrices that will be downloaded and updated in the uniform variable.

transpose

Specifies whether to transpose the matrix or matrices before setting the uniform variable. Must be GL_FALSE.

value

Specifies a pointer to an array of count values that will be used to update the specified uniform matrix. For example, if location corresponds to a uniform variable of type mat4x2, value must point to an array of at least count * 8 floating-point values.

DESCRIPTION

Calls to glUniformMatrix*fv update the value of a uniform variable within the current active program object. They can be used to update uniforms of type matNxM, where N and M are the number of rows and columns, respectively.

If transpose is GL_FALSE, the matrix is assumed to be in column-major order. If transpose is GL_TRUE, the matrix is assumed to be in row-major order. In OpenGL, matrices are typically stored in column-major order. Therefore, transpose should always be GL_FALSE.

If location corresponds to a uniform array variable, the update is applied to the element location of the array. If location corresponds to a uniform array variable, and count is greater than 1, the update is applied to count consecutive elements of the array, starting at the element indicated by location.

The matrices are specified in column-major order. For example, the matrix

$$ \begin{bmatrix} a & b & c & d \\ e & f & g & h \\ i & j & k & l \\ m & n & o & p \end{bmatrix} $$

is passed as the array

a, e, i, m, b, f, j, n, c, g, k, o, d, h, l, p.

A call to glUniformMatrix4x2fv takes a pointer to a block of floating-point data. This block consists of count matrices, each of size 4 rows and 2 columns. The matrices are laid out in column-major order.

The transpose parameter must be GL_FALSE. A value of GL_TRUE is not supported.

If location is not valid, or if the specified matrix type does not match the type of the uniform variable pointed to by location, then errors will not be generated; otherwise, if transpose is not GL_FALSE, then GL_INVALID_VALUE is generated. If count is negative, then GL_INVALID_VALUE is generated.

If a runtime error occurs during the uniform setting, such as due to the use of an invalid value, then the uniform value is not modified and the command is flagged for a deferred error.

Errors such as GL_INVALID_OPERATION are generated if glUniformMatrix4x2fv is called between a call to glBegin and the corresponding call to glEnd.

The function glUniformMatrix4x2fv is available only when the GL_VERSION_4_0 is included in the OpenGL context.

NOTES

Uniform variables are part of the programmable shader pipeline. They are typically used to pass data, such as transformation matrices, lighting parameters, or material properties, from the application to the vertex, geometry, or fragment shaders.

The location parameter is obtained by calling glGetUniformLocation.

If the uniform variable specified by location is not active in the active program object, or if location is not a valid uniform location, then the command is ignored.

The transpose parameter is often confusing. If you are passing a matrix that is already in column-major order, you should set transpose to GL_FALSE. If you are passing a matrix in row-major order, you should set transpose to GL_TRUE. However, this function only supports GL_FALSE.

ERRORS

GL_INVALID_OPERATION is generated if glUniformMatrix4x2fv is called between the execution of glBegin and a later call to glEnd.

GL_INVALID_VALUE is generated if transpose is not GL_FALSE.

GL_INVALID_VALUE is generated if count is negative.
