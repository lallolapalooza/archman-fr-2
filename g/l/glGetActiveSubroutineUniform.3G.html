NOM

glGetActiveSubroutineUniform - interroger une propriété d'un uniforme de sous-routine de shader actif

SPÉCIFICATION EN C

void glGetActiveSubroutineUniformiv(GLuint program, GLenum shadertype, GLuint index, GLenum pname, GLint *values);

PARAMÈTRES

program

Spécifie le nom du programme contenant l'uniforme.

shadertype

Spécifie l'étape du shader à partir de laquelle interroger le paramètre de la sous-routine. shadertype doit être l'un des choix suivants : GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER.

index

Spécifie l'indice de l'uniforme de sous-routine du shader.

pname

Spécifie le paramètre de l'uniforme de sous-routine du shader à interroger. pname doit être GL_NUM_COMPATIBLE_SUBROUTINES, GL_COMPATIBLE_SUBROUTINES, GL_UNIFORM_SIZE ou GL_UNIFORM_NAME_LENGTH.

values

Spécifie l'adresse d'un tableau dans lequel la ou les valeurs interrogées seront placées.

DESCRIPTION

glGetActiveSubroutineUniform interroge un paramètre d'un uniforme de sous-routine de shader actif. program contient le nom du programme contenant l'uniforme. shadertype spécifie l'étape pour laquelle l'emplacement de l'uniforme, donné par index, est valide. index doit être compris entre zéro et la valeur de GL_ACTIVE_SUBROUTINE_UNIFORMS moins un pour l'étape du shader.

Si pname est GL_NUM_COMPATIBLE_SUBROUTINES, un entier unique indiquant le nombre de sous-routines pouvant être assignées à l'uniforme est renvoyé dans values.

Si pname est GL_COMPATIBLE_SUBROUTINES, un tableau d'entiers est renvoyé dans values, chaque entier spécifiant l'indice d'une sous-routine active pouvant être assignée à l'uniforme de sous-routine sélectionné. Le nombre d'entiers renvoyés est identique à la valeur renvoyée pour GL_NUM_COMPATIBLE_SUBROUTINES.

Si pname est GL_UNIFORM_SIZE, un entier unique est renvoyé dans values. Si l'uniforme de sous-routine sélectionné est un tableau, la taille déclarée du tableau est renvoyée ; sinon, un est renvoyé.

Si pname est GL_UNIFORM_NAME_LENGTH, un entier unique spécifiant la longueur du nom de l'uniforme de sous-routine (incluant le caractère nul de terminaison) est renvoyé dans values.

ERREURS

GL_INVALID_ENUM est généré si shadertype ou pname n'est pas l'une des valeurs acceptées.

GL_INVALID_VALUE est généré si index est supérieur ou égal à la valeur de GL_ACTIVE_SUBROUTINES.

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme existant.

GETS ASSOCIÉS

glGetProgramStage() avec l'argument GL_ACTIVE_SUBROUTINE_UNIFORMS
