NOM

glPointParameter - spécifier les paramètres des points

SPÉCIFICATION EN C

void glPointParameterf(GLenum pname, GLfloat param);

void glPointParameteri(GLenum pname, GLint param);

void glPointParameterfv(GLenum pname, const GLfloat * params);

void glPointParameteriv(GLenum pname, const GLint * params);

PARAMÈTRES

pname

Spécifie un paramètre de point à valeur unique. GL_POINT_FADE_THRESHOLD_SIZE et GL_POINT_SPRITE_COORD_ORIGIN sont acceptés.

param

Pour glPointParameterf et glPointParameteri, spécifie la valeur à laquelle pname sera réglé.

params

Pour glPointParameterfv et glPointParameteriv, spécifie un pointeur vers un tableau où la ou les valeurs à attribuer à pname sont stockées.

DESCRIPTION

Les valeurs suivantes sont acceptées pour pname:

GL_POINT_FADE_THRESHOLD_SIZE

params est une valeur flottante unique qui spécifie la valeur seuil à laquelle les tailles de point sont écrêtées si elles dépassent la valeur spécifiée. La valeur par défaut est 1.0.

GL_POINT_SPRITE_COORD_ORIGIN

params est une énumération unique spécifiant l'origine des coordonnées de texture des sprites de point, soit GL_LOWER_LEFT, soit GL_UPPER_LEFT. La valeur par défaut est GL_UPPER_LEFT.

ERREURS

GL_INVALID_VALUE est générée si la valeur spécifiée pour GL_POINT_FADE_THRESHOLD_SIZE est inférieure à zéro.

GL_INVALID_ENUM est générée si la valeur spécifiée pour GL_POINT_SPRITE_COORD_ORIGIN n'est ni GL_LOWER_LEFT ni GL_UPPER_LEFT.

GETS ASSOCIÉS

glGet() avec l'argument GL_POINT_FADE_THRESHOLD_SIZE

glGet() avec l'argument GL_POINT_SPRITE_COORD_ORIGIN
