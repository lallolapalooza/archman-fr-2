NOM

glGetBufferSubData, glGetNamedBufferSubData - renvoie un sous-ensemble des données d'un magasin de données d'objet tampon

SPÉCIFICATION C

void glGetBufferSubData(GLenumtarget, GLintptroffset, GLsizeiptrsize, void *data);

void glGetNamedBufferSubData(GLuintbuffer, GLintptroffset, GLsizeiptrsize, void *data);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet tampon est lié pour glGetBufferSubData, qui doit être l'une des cibles de liaison de tampon du tableau suivant :
Cible de liaison de tampon But
GL_ARRAY_BUFFER Attributs de sommet
GL_ATOMIC_COUNTER_BUFFER Stockage de compteur atomique
GL_COPY_READ_BUFFER Source de copie de tampon
GL_COPY_WRITE_BUFFER Destination de copie de tampon
GL_DISPATCH_INDIRECT_BUFFER Commandes de dispatch de calcul indirect
GL_DRAW_INDIRECT_BUFFER Arguments de commande indirecte
GL_ELEMENT_ARRAY_BUFFER Indices de tableau de sommets
GL_PIXEL_PACK_BUFFER Cible de lecture de pixels
GL_PIXEL_UNPACK_BUFFER Source de données de texture
GL_QUERY_BUFFER Tampon de résultat de requête
GL_SHADER_STORAGE_BUFFER Stockage lecture-écriture pour les shaders
GL_TEXTURE_BUFFER Tampon de données de texture
GL_TRANSFORM_FEEDBACK_BUFFER Tampon de transform feedback
GL_UNIFORM_BUFFER Stockage de bloc uniforme

buffer

Spécifie le nom de l'objet tampon pour glGetNamedBufferSubData.

offset

Spécifie le décalage dans le magasin de données de l'objet tampon à partir duquel les données seront renvoyées, mesuré en octets.

size

Spécifie la taille en octets de la région du magasin de données qui est renvoyée.

data

Spécifie un pointeur vers l'emplacement où les données de l'objet tampon sont renvoyées.

DESCRIPTION

glGetBufferSubData et glGetNamedBufferSubData renvoient une partie ou la totalité du contenu des données du magasin de données de l'objet tampon spécifié. Les données commençant à l'octet de décalage offset et s'étendant sur size octets sont copiées du magasin de données de l'objet tampon vers la mémoire pointée par data. Une erreur est levée si l'objet tampon est actuellement mappé, ou si offset et size définissent ensemble une plage au-delà des limites du magasin de données de l'objet tampon.

REMARQUES

Si une erreur est générée, aucune modification n'est apportée au contenu de data.

La GL_ATOMIC_COUNTER_BUFFER cible n'est disponible que si la version GL est 4.2 ou supérieure.

Les GL_DISPATCH_INDIRECT_BUFFER et GL_SHADER_STORAGE_BUFFER cibles ne sont disponibles que si la version GL est 4.3 ou supérieure.

La GL_QUERY_BUFFER cible n'est disponible que si la version GL est 4.4 ou supérieure.

ERREUR

GL_INVALID_ENUM est généré par glGetBufferSubData si target n'est pas l'une des cibles génériques de liaison de tampon.

GL_INVALID_OPERATION est généré par glGetBufferSubData si zéro est lié à target.

GL_INVALID_OPERATION est généré par glGetNamedBufferSubData si buffer n'est pas le nom d'un objet tampon existant.

GL_INVALID_VALUE est généré si offset ou size est négatif, ou si $offset + size$ est supérieur à la valeur de GL_BUFFER_SIZE pour l'objet tampon.

GL_INVALID_OPERATION est généré si l'objet tampon est mappé avec glMapBufferRange() ou glMapBuffer(), sauf s'il a été mappé avec le bit GL_MAP_PERSISTENT_BIT défini dans les drapeaux d' glMapBufferRange access .

glGetNamedBufferSubData

GLapi

NOM

glGetNamedBufferSubData - récupère des données d'un sous-ensemble d'un tampon nommé

SPÉCIFICATION C

void glGetNamedBufferSubData( GLuint buffer, GLenum pname, GLintptr offset, GLsizeiptr size, void *data );

PARAMÈTRES

buffer
Le nom du tampon cible.
pname
L'indicateur de propriété à renvoyer. Doit être GL_BUFFER_DATA.
offset
Le décalage du premier octet des données de tampon à récupérer.
size
La taille en octets des données de tampon à récupérer.
data
Un pointeur vers une variable dans laquelle les données récupérées sont renvoyées.

DESCRIPTION

Utilise glGetNamedBufferSubData pour récupérer des données d'un sous-ensemble d'un tampon nommé. La partie du tampon de stockage du tampon nommé est spécifiée par offset et size. Les données sont renvoyées dans le pointeur data. La taille des données à récupérer est spécifiée par size.

Si pname est GL_BUFFER_DATA, alors data recevra les données du tampon spécifié par buffer à partir du décalage offset pour une taille de size octets.

L'appel à glGetNamedBufferSubData ne provoque aucune restriction sur les opérations de rendu ultérieures, et aucune ressource autre que le tampon nommé ne sera affectée.

Si buffer n'est pas le nom d'un tampon de tampon valide, alors une erreur GL_INVALID_NAME est générée.

Si size est négatif, alors une erreur GL_INVALID_VALUE est générée.

Si offset est négatif, alors une erreur GL_INVALID_VALUE est générée.

Si offset + size dépasse la taille du tampon, alors une erreur GL_INVALID_VALUE est générée.

Si pname n'est pas GL_BUFFER_DATA, alors une erreur GL_INVALID_ENUM est générée.

NOTES

Les fonctions glGetNamedBufferSubData et glGetBufferSubData sont similaires, sauf que glGetNamedBufferSubData prend un nom de tampon comme premier argument, tandis que glGetBufferSubData prend un identifiant de cible de tampon.

ERREURS

GL_INVALID_NAME est généré si buffer n'est pas le nom d'un tampon valide.

GL_INVALID_ENUM est généré si pname n'est pas GL_BUFFER_DATA.

GL_INVALID_VALUE est généré si size ou offset est négatif, ou si offset + size dépasse la taille du tampon.

SUPPORT VERSION

Les versions suivantes de OpenGL sont prises en charge :

  • 2.0

Les versions suivantes de OpenGL ES sont prises en charge :

  • 3.0
