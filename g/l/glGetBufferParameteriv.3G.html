NOM

glGetBufferParameteriv, glGetBufferParameteri64v, glGetNamedBufferParameteriv, glGetNamedBufferParameteri64v - renvoient les paramètres d'un objet tampon

SPÉCIFICATION C

void glGetBufferParameteriv(GLenumtarget, GLenumvalue, GLint *data);

void glGetBufferParameteri64v(GLenumtarget, GLenumvalue, GLint64 *data);

void glGetNamedBufferParameteriv(GLuintbuffer, GLenumpname, GLint *params);

void glGetNamedBufferParameteri64v(GLuintbuffer, GLenumpname, GLint64 *params);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet tampon est lié pour glGetBufferParameteriv et glGetBufferParameteri64v. Doit être l'une des cibles de liaison de tampon du tableau suivant :
Cible de liaison de tampon But
GL_ARRAY_BUFFER Attributs de sommet
GL_ATOMIC_COUNTER_BUFFER Stockage de compteur atomique
GL_COPY_READ_BUFFER Source de copie de tampon
GL_COPY_WRITE_BUFFER Destination de copie de tampon
GL_DISPATCH_INDIRECT_BUFFER Commandes de dispatch de calcul indirect
GL_DRAW_INDIRECT_BUFFER Arguments de commande indirecte
GL_ELEMENT_ARRAY_BUFFER Indices de tableau de sommets
GL_PIXEL_PACK_BUFFER Cible de lecture de pixels
GL_PIXEL_UNPACK_BUFFER Source de données de texture
GL_QUERY_BUFFER Tampon de résultat de requête
GL_SHADER_STORAGE_BUFFER Stockage lecture-écriture pour les shaders
GL_TEXTURE_BUFFER Tampon de données de texture
GL_TRANSFORM_FEEDBACK_BUFFER Tampon de transform feedback
GL_UNIFORM_BUFFER Stockage de bloc uniforme

buffer

Spécifie le nom de l'objet tampon pour glGetNamedBufferParameteriv et glGetNamedBufferParameteri64v.

value

Spécifie le nom du paramètre de l'objet tampon à interroger.

data

Renvoie le paramètre demandé.

DESCRIPTION

Ces fonctions renvoient dans data un paramètre sélectionné de l'objet tampon spécifié.

pname nomme un paramètre spécifique de l'objet tampon, comme suit :

GL_BUFFER_ACCESS

params renvoie la politique d'accès définie lors du mappage de l'objet tampon (la valeur de l'énumération du paramètre access passé à glMapBuffer). Si le tampon a été mappé avec glMapBufferRange, la politique d'accès est déterminée en traduisant les bits de ce paramètre access vers l'une des énumérations prises en charge pour glMapBuffer comme décrit dans la spécification OpenGL.

GL_BUFFER_ACCESS_FLAGS

params renvoie la politique d'accès définie lors du mappage de l'objet tampon (la valeur du champ de bits du paramètre access passé à glMapBufferRange). Si le tampon a été mappé avec glMapBuffer, la politique d'accès est déterminée en traduisant les énumérations de ce paramètre access vers les bits correspondants pour glMapBufferRange comme décrit dans la spécification OpenGL. La valeur initiale est zéro.

GL_BUFFER_IMMUTABLE_STORAGE

params renvoie un indicateur booléen indiquant si l'objet tampon est immuable. La valeur initiale est GL_FALSE.

GL_BUFFER_MAPPED

params renvoie un indicateur indiquant si l'objet tampon est actuellement mappé. La valeur initiale est GL_FALSE.

GL_BUFFER_MAP_LENGTH

params renvoie la longueur du mappage dans l'objet tampon établi avec glMapBuffer*. Les versions i64v de ces requêtes doivent être utilisées pour ce paramètre. La valeur initiale est zéro.

GL_BUFFER_MAP_OFFSET

params renvoie le décalage du mappage dans l'objet tampon établi avec glMapBuffer*. Les versions i64v de ces requêtes doivent être utilisées pour ce paramètre. La valeur initiale est zéro.

GL_BUFFER_SIZE

params renvoie la taille de l'objet tampon, mesurée en octets. La valeur initiale est 0.

GL_BUFFER_STORAGE_FLAGS

params renvoie un champ de bits indiquant les drapeaux de stockage de l'objet tampon. Si l'objet tampon est immuable, la valeur renvoyée sera celle spécifiée lorsque le magasin de données a été établi avec glBufferStorage. Si le magasin de données a été établi avec glBufferData, la valeur sera GL_MAP_READ_BIT | GL_MAP_WRITE_BIT | GL_DYNAMIC_STORAGE_BIT | GL_MAP_WRITE_BIT. La valeur initiale est zéro.

GL_BUFFER_USAGE

params renvoie le motif d'utilisation de l'objet tampon. La valeur initiale est GL_STATIC_DRAW.

REMARQUES

Si une erreur est générée, aucune modification n'est apportée au contenu de data.

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version GL est 4.2 ou supérieure.

Les cibles GL_DISPATCH_INDIRECT_BUFFER et GL_SHADER_STORAGE_BUFFER ne sont disponibles que si la version GL est 4.3 ou supérieure.

La cible GL_QUERY_BUFFER n'est disponible que si la version GL est 4.4 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré par glGetBufferParameter* si target n'est pas l'une des cibles de tampon acceptées.

GL_INVALID_OPERATION est généré par glGetBufferParameter* si zéro est lié à target.

GL_INVALID_OPERATION est généré par glGetNamedBufferParameter* si buffer n'est pas le nom d'un objet tampon existant.

GL_INVALID_ENUM est généré si pname n'est pas l'un des noms de paramètres d'objet tampon décrits ci-dessus.
