NOM

glMinSampleShading - spécifie le taux minimum auquel le rendu par échantillons a lieu

SPÉCIFICATION C

void glMinSampleShading(GLfloat value);

PARAMÈTRES

value

Spécifie le taux auquel les échantillons sont rendus dans chaque pixel couvert.

DESCRIPTION

glMinSampleShading spécifie le taux auquel les échantillons sont rendus dans un pixel couvert. Le rendu par échantillon est activé en appelant glEnable() avec le paramètre GL_SAMPLE_SHADING. Si GL_MULTISAMPLE ou GL_SAMPLE_SHADING est désactivé, le rendu par échantillon n'a aucun effet. Sinon, une implémentation doit fournir au moins autant de valeurs de couleur uniques pour chaque fragment couvert que spécifié par value multiplié par samples, où samples est la valeur de GL_SAMPLES pour le framebuffer actuel. Au moins 1 échantillon pour chaque fragment couvert est généré.

Une valeur de value de 1.0 indique que chaque échantillon du framebuffer doit être rendu indépendamment. Une valeur de value de 0.0 permet efficacement au GL d'ignorer le rendu par taux d'échantillons. Toute valeur comprise entre 0.0 et 1.0 permet au GL de rendre seulement un sous-ensemble des échantillons totaux dans chaque fragment couvert. Les échantillons qui sont rendus et l'algorithme utilisé pour sélectionner ce sous-ensemble des échantillons du fragment dépendent de l'implémentation.

NOTES

Le type du paramètre value a été modifié de GLclampf à GLfloat. Ce changement est transparent pour le code utilisateur et est décrit en détail sur la page removedTypes().

ERREURS

Aucune.

GETS ASSOCIÉS

glGet() avec l'argument GL_MIN_SAMPLE_SHADING.

glGet() avec l'argument GL_SAMPLES.
