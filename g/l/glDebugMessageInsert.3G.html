NOM

glDebugMessageInsert - injecte un message fourni par l'application dans la file d'attente des messages de débogage

SPÉCIFICATION C

void glDebugMessageInsert(GLenum source, GLenum type, GLuint id, GLenum severity, GLsizei length, const char *message);

PARAMÈTRES

source

La source du message de débogage à insérer.

type

Le type de l'insertion du message de débogage.

id

L'identifiant fourni par l'utilisateur du message à insérer.

severity

La sévérité des messages de débogage à insérer.

length

La longueur de la chaîne contenue dans le tableau de caractères dont l'adresse est donnée par message.

message

L'adresse d'un tableau de caractères contenant le message à insérer.

DESCRIPTION

glDebugMessageInsert insère un message fourni par l'utilisateur dans la file de sortie de débogage. source spécifie la source qui sera utilisée pour classer le message et doit être GL_DEBUG_SOURCE_APPLICATION ou GL_DEBUG_SOURCE_THIRD_PARTY. Toutes les autres sources sont réservées à l'implémentation GL. type indique le type du message à insérer et peut être l'un des GL_DEBUG_TYPE_ERROR, GL_DEBUG_TYPE_DEPRECATED_BEHAVIOR, GL_DEBUG_TYPE_UNDEFINED_BEHAVIOR, GL_DEBUG_TYPE_PORTABILITY, GL_DEBUG_TYPE_PERFORMANCE, GL_DEBUG_TYPE_MARKER, GL_DEBUG_TYPE_PUSH_GROUP, GL_DEBUG_TYPE_POP_GROUP, ou GL_DEBUG_TYPE_OTHER. severity indique la sévérité du message et peut être GL_DEBUG_SEVERITY_LOW, GL_DEBUG_SEVERITY_MEDIUM, GL_DEBUG_SEVERITY_HIGH ou GL_DEBUG_SEVERITY_NOTIFICATION. id est disponible pour l'utilisation définie par l'application et peut prendre n'importe quelle valeur. Cette valeur sera enregistrée et utilisée pour identifier le message.

length contient un compte des caractères dans le tableau de caractères dont l'adresse est donnée dans message. Si length est négatif, alors message est traité comme une chaîne terminée par null. La longueur du message, qu'elle soit spécifiée explicitement ou implicitement, doit être inférieure ou égale à la constante définie par l'implémentation GL_MAX_DEBUG_MESSAGE_LENGTH.

NOTES

GL_DEBUG_TYPE_MARKER, GL_DEBUG_TYPE_PUSH_GROUP, GL_DEBUG_TYPE_POP_GROUP, et GL_DEBUG_SEVERITY_NOTIFICATION ne sont disponibles que si la version GL est 4.3 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si source, type ou severity n'est pas l'un des types d'interface acceptés.

GL_INVALID_VALUE est généré si la longueur du message est supérieure à la valeur de GL_MAX_DEBUG_MESSAGE_LENGTH.
