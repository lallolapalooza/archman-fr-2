Paquet: freeglut

Licences: X11

glutBitmapWidth(3) freeglut glutBitmapWidth(3)

NOM

glutBitmapWidth - retourne la largeur d'un caractère bitmap.
glutBitmapLength retourne la longueur d'une chaîne de polices bitmap.

SYNTAXE

int glutBitmapWidth(void *font, int character)
int glutBitmapLength(void *font, const unsigned char *string)

ARGUMENTS

font
Police bitmap à utiliser. Pour les valeurs valides, voir la description de glutBitmapCharacter.
caractere
Caractère dont on veut retourner la largeur (pas limité à 8 bits).
chaine
Chaîne de texte (caractères 8 bits), terminée par un nul.

DESCRIPTION

glutBitmapWidth retourne la largeur en pixels d'un caractère bitmap dans une police bitmap supportée. Bien que la largeur des caractères d'une police puisse varier (bien que les polices à chasse fixe ne varient pas), les caractéristiques de hauteur maximale d'une police particulière sont fixes.

glutBitmapLength retourne la longueur en pixels d'une chaîne (caractères 8 bits). Cette longueur est équivalente à la somme de toutes les largeurs retournées par glutBitmapWidth pour chaque caractère de la chaîne.

VOIR AUSSI

glutBitmapCharacter, glutStrokeWidth
