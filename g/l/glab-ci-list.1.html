NOM

glab-ci-list - Récupérer la liste des pipelines CI/CD.

SYNTAXE

glab ci list [options]

DESCRIPTION

Récupérer la liste des pipelines CI/CD.

OPTIONS

-n, --name="" Retourner uniquement les pipelines avec le nom donné.

-o, --orderBy="id" Trier les pipelines par ce champ. Options : id, status, ref, updated_at, user_id.

-F, --output="text" Formater la sortie. Options : text, json.

-p, --page=1 Numéro de page.

-P, --per-page=30 Nombre d'éléments à lister par page.

-r, --ref="" Retourner uniquement les pipelines pour la référence donnée.

--scope="" Retourner uniquement les pipelines avec la portée donnée : {running|pending|finished|branches|tags}

--sha="" Retourner uniquement les pipelines avec le SHA donné.

--sort="desc" Trier les pipelines. Options : asc, desc.

--source="" Retourner uniquement les pipelines déclenchés via la source donnée. Voir https://docs.gitlab.com/ci/jobs/job_rules/#ci_pipeline_source-predefined-variable pour la liste complète. Options couramment utilisées : {merge_request_event|parent_pipeline|pipeline|push|trigger}

-s, --status="" Obtenir le pipeline avec ce statut. Options : running, pending, success, failed, canceled, skipped, created, manual, waiting_for_resource, preparing, scheduled

-a, --updated-after="" Retourner uniquement les pipelines mis à jour après la date spécifiée. Format attendu ISO 8601 (2019-03-15T08:00:00Z).

-b, --updated-before="" Retourner uniquement les pipelines mis à jour avant la date spécifiée. Format attendu ISO 8601 (2019-03-15T08:00:00Z).

-u, --username="" Retourner uniquement les pipelines déclenchés par le nom d'utilisateur donné.

-y, --yaml-errors[=false] Retourner uniquement les pipelines avec des configurations invalides.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE DE NOMS/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab ci list
$ glab ci list --status=failed
