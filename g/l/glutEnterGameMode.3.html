Paquet: freeglut

Licences: X11

glutEnterGameMode(3) freeglut glutEnterGameMode(3)

NOM

glutEnterGameMode, glutLeaveGameMode - entre et quitte le mode jeu de GLUT.

SYNTAXE

int glutEnterGameMode(void);
void glutLeaveGameMode(void);

DESCRIPTION

glutEnterGameMode est conçu pour activer le rendu GLUT plein écran haute performance, éventuellement avec un format d'affichage différent. Appeler glutEnterGameMode crée une fenêtre GLUT plein écran spéciale (avec ses propres rappels et son propre état de contexte de rendu OpenGL). Si la chaîne de mode jeu décrit un format d'affichage possible, GLUT modifie également le format d'affichage pour celui décrit par la chaîne de mode jeu. glutLeaveGameMode quitte le mode jeu de GLUT et restaure le format d'affichage à son format par défaut.

Lorsque le mode jeu est activé, certaines fonctionnalités de GLUT sont désactivées pour faciliter le rendu plein écran haute performance. Les menus contextuels de GLUT ne sont pas disponibles en mode jeu. Les autres fenêtres et sous-fenêtres créées ne sont pas affichées en mode jeu de GLUT. Le mode jeu masquera également toutes les autres applications en cours d'exécution sur l'écran de l'ordinateur. L'intention de ces restrictions est d'éliminer les problèmes de superposition de fenêtres, de permettre les changements de format d'affichage et d'optimiser le rendu plein écran, comme le changement de page pour les échanges de tampons en mode plein écran.

La valeur renvoyée par glutEnterGameMode est un identifiant entier unique de petite taille pour la fenêtre plein écran. La plage des identifiants alloués commence à un. Cet identifiant de fenêtre peut être utilisé lors de l'appel de glutSetWindow.

Après avoir quitté le mode jeu, les fonctionnalités de GLUT désactivées en mode jeu redeviennent disponibles. La fenêtre en mode jeu (et son état de rendu OpenGL) est détruite lors de la sortie du mode jeu. Toutes les fenêtres et sous-fenêtres créées avant d'entrer en mode jeu sont affichées à leurs emplacements précédents. L'état OpenGL des fenêtres et sous-fenêtres GLUT normales n'est pas perturbé par l'entrée et/ou la sortie du mode jeu.

Les routines GLUT suivantes sont ignorées en mode jeu : glutFullScreen, glutSetWindowTitle, glutSetIconTitle, glutPositionWindow, glutReshapeWindow, glutPopWindow, glutPushWindow, glutIconifyWindow, glutShowWindow, glutHideWindow.

glutEnterGameMode peut être appelée alors que le mode jeu est déjà actif. Cela détruira la fenêtre du mode jeu précédente (y compris tout état de rendu OpenGL) et créera une nouvelle fenêtre en mode jeu avec un nouveau contexte de rendu OpenGL. De plus, si glutEnterGameMode est appelée alors que le mode jeu est déjà actif et si la chaîne du mode jeu a été modifiée et décrit un format d'affichage possible, le nouveau format d'affichage prendra effet. Un rappel de remodelage est généré si la taille de la fenêtre du mode jeu change en raison d'une modification du format d'affichage.

Rentrer en mode jeu fournit un mécanisme pour changer le format d'affichage alors que le mode jeu est déjà actif. Notez cependant que l'état OpenGL de la fenêtre du mode jeu est perdu dans ce processus et que l'application est responsable de réinitialiser l'état OpenGL de la fenêtre du mode jeu nouvellement créée lors de la réentrée en mode jeu.

Le mode jeu ne peut pas être activé pendant l'utilisation de menus contextuels.

Notez que les routines glutEnterGameMode et glutFullScreen fonctionnent différemment. glutFullScreen redimensionne simplement la fenêtre actuelle à la taille de l'écran. glutFullScreen ne modifie pas le format d'affichage et ne désactive aucune fonctionnalité de GLUT comme les menus contextuels ; glutFullScreen continue de fonctionner en mode "fenêtré". glutEnterGameMode crée un nouveau style de fenêtre, modifie potentiellement le mode d'affichage de l'écran, limite les fonctionnalités de GLUT et masque les autres applications.

glutGameModeGet, glutGameModeString, glutInitDisplayString
