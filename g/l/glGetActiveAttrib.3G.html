DESCRIPTIO

N

glGetActiveAttrib renvoie des informations sur une variable d'attribut active dans l'objet programme spécifié par program. Le nombre d'attributs actifs peut être obtenu en appelant glGetProgram() avec la valeur GL_ACTIVE_ATTRIBUTES. Une valeur de 0 pour index sélectionne la première variable d'attribut active. Les valeurs admissibles pour index vont de zéro au nombre de variables d'attribut actives moins

un.

Un vertex shader peut utiliser soit des variables d'attribut intégrées, soit des variables d'attribut définies par l'utilisateur, soit les deux. Les variables d'attribut intégrées ont un préfixe "gl_" et font référence aux attributs de sommet OpenGL conventionnels (par ex., gl_Vertex, gl_Normal, etc., voir la spécification du langage de shading OpenGL pour une liste complète.) Les variables d'attribut définies par l'utilisateur ont des noms arbitraires et obtiennent leurs valeurs par l'intermédiaire d'attributs de sommet génériques numérotés. Une variable d'attribut (intégrée ou définie par l'utilisateur) est considérée comme active s'il est déterminé pendant l'opération de liaison qu'elle peut être accédée pendant l'exécution du programme. Par conséquent, program doit avoir précédemment été la cible d'un appel à glLinkProgram(), mais il n'est pas nécessaire qu'elle ait été liée avec

succès.

La taille du tampon de caractères nécessaire pour stocker le nom de la variable d'attribut le plus long dans program peut être obtenue en appelant glGetProgram() avec la valeur GL_ACTIVE_ATTRIBUTE_MAX_LENGTH. Cette valeur devrait être utilisée pour allouer un tampon de taille suffisante pour stocker le nom d'attribut renvoyé. La taille de ce tampon de caractères est transmise dans bufSize, et un pointeur vers ce tampon de caractères est transmis dans name

.

glGetActiveAttrib renvoie le nom de la variable d'attribut indiquée par index, en le stockant dans le tampon de caractères spécifié par name. La chaîne renvoyée sera terminée par un caractère nul. Le nombre réel de caractères écrits dans ce tampon est renvoyé dans length, et ce compteur n'inclut pas le caractère de terminaison nul. Si la longueur de la chaîne renvoyée n'est pas nécessaire, une valeur de NULL peut être transmise dans l'argument length

.

L' type argument spécifie un pointeur vers une variable dans laquelle le type de données de la variable d'attribut sera écrit. Les constantes symboliques GL_FLOAT, GL_FLOAT_VEC2, GL_FLOAT_VEC3, GL_FLOAT_VEC4, GL_FLOAT_MAT2, GL_FLOAT_MAT3, GL_FLOAT_MAT4, GL_FLOAT_MAT2x3, GL_FLOAT_MAT2x4, GL_FLOAT_MAT3x2, GL_FLOAT_MAT3x4, GL_FLOAT_MAT4x2, GL_FLOAT_MAT4x3, GL_INT, GL_INT_VEC2, GL_INT_VEC3, GL_INT_VEC4, GL_UNSIGNED_INT, GL_UNSIGNED_INT_VEC2, GL_UNSIGNED_INT_VEC3, GL_UNSIGNED_INT_VEC4, GL_DOUBLE, GL_DOUBLE_VEC2, GL_DOUBLE_VEC3, GL_DOUBLE_VEC4, GL_DOUBLE_MAT2, GL_DOUBLE_MAT3, GL_DOUBLE_MAT4, GL_DOUBLE_MAT2x3, GL_DOUBLE_MAT2x4, GL_DOUBLE_MAT3x2, GL_DOUBLE_MAT3x4, GL_DOUBLE_MAT4x2, ou GL_DOUBLE_MAT4x3 peuvent être renvoyés. L'argument size renverra la taille de l'attribut, en unités du type renvoyé dans type

.

La liste des variables d'attribut actives peut inclure à la fois des variables d'attribut intégrées (qui commencent par le préfixe "gl_") ainsi que des noms de variables d'attribut définies par

l'utilisateur.

Cette fonction renverra autant d'informations que possible sur la variable d'attribut active spécifiée. Si aucune information n'est disponible, length sera 0, et name sera une chaîne vide. Cette situation pourrait survenir si cette fonction est appelée après une opération de liaison qui a échoué. Si une erreur se produit, les valeurs de retour length, size, type, et name ne seront

pas mod
ifiées.

GL_INVALID_OPERATION est généré si program n'est pas un objet

GL_INVALID_VALUE est généré si index est supérieur ou égal au nombre de variables d'attribut actives dans program

.

GL_INVALID_VALUE est généré si bufSize est inf

érieur
à 0.
