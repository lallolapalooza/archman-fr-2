NOM

glutVideoResizeGet - récupère les informations de redimensionnement vidéo GLUT représentées par des entiers.

AVERTISSEMENT

Pas encore implémenté dans freeglut.

SYNTAXE

int glutVideoResizeGet(GLenum param);

ARGUMENTS

param
Nom des informations de redimensionnement vidéo à récupérer.
GLUT_VIDEO_RESIZE_POSSIBLE
Non nul si le redimensionnement vidéo est pris en charge par le système sous-jacent ; nul si non pris en charge. Si cette valeur est nulle, les autres appels GLUT de redimensionnement vidéo ne font rien lorsqu'ils sont appelés. Voir les notes d'implémentation ci-dessous.
GLUT_VIDEO_RESIZE_IN_USE
GLUT_VIDEO_RESIZE_X_DELTA
GLUT_VIDEO_RESIZE_Y_DELTA
GLUT_VIDEO_RESIZE_WIDTH_DELTA
GLUT_VIDEO_RESIZE_HEIGHT_DELTA
GLUT_VIDEO_RESIZE_X
GLUT_VIDEO_RESIZE_Y
GLUT_VIDEO_RESIZE_WIDTH
GLUT_VIDEO_RESIZE_HEIGHT

DESCRIPTION

glutVideoResizeGet récupère les informations de redimensionnement vidéo GLUT représentées par des entiers. Le paramètre param détermine le type d'informations de redimensionnement vidéo à retourner.

NOTES D'IMPLÉMENTATION X

L'implémentation actuelle utilise l'extension GLX SGIX_video_resize. Cette extension est actuellement prise en charge sur les systèmes basés sur InfiniteReality de SGI.

NOTES D'IMPLÉMENTATION WIN32

L'implémentation actuelle ne signale jamais que le redimensionnement vidéo est possible.

VOIR AUSSI

glutGet, glutSetupVideoResizing, glutStopVideoResizing, glutVideoResize, glutVideoPan
