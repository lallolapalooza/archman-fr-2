NOM

glGetActiveSubroutineName - interroger le nom d'une sous-routine de shader active

SPÉCIFICATION C

void glGetActiveSubroutineName(GLuint program, GLenum shadertype, GLuint index, GLsizei bufSize, GLsizei *length, GLchar *name);

PARAMÈTRES

program

Spécifie le nom du programme contenant la sous-routine.

shadertype

Spécifie l'étage du shader à partir duquel interroger le nom de la sous-routine.

index

Spécifie l'index de l'uniform de sous-routine du shader.

bufSize

Spécifie la taille du tampon dont l'adresse est donnée dans name.

length

Spécifie l'adresse d'une variable qui recevra la longueur du nom de l'uniform de sous-routine du shader.

name

Spécifie l'adresse d'un tableau dans lequel le nom de l'uniform de sous-routine du shader sera écrit.

DESCRIPTION

glGetActiveSubroutineName interroge le nom d'une uniforme de sous-routine de shader active à partir de l'objet programme donné dans program. index spécifie l'index de l'uniforme de sous-routine de shader dans l'étage de shader donné par stage, et doit être compris entre zéro et la valeur de GL_ACTIVE_SUBROUTINES moins un pour l'étage de shader.

Le nom de la sous-routine sélectionnée est renvoyé sous forme de chaîne terminée par un caractère nul dans name. Le nombre réel de caractères écrits dans name, sans inclure le terminateur nul, est renvoyé dans length. Si length est NULL, aucune longueur n'est renvoyée. Le nombre maximal de caractères pouvant être écrits dans name, y compris le terminateur nul, est donné dans bufSize.

ERREURS

GL_INVALID_VALUE est généré si index est supérieur ou égal à la valeur de GL_ACTIVE_SUBROUTINES.

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme existant.

GETS ASSOCIÉS

glGetProgramStage() avec l'argument GL_ACTIVE_SUBROUTINE_UNIFORM_MAX_LENGTH
