NOM

glBlendEquationSeparate - définit l'équation de mélange RGB et l'équation de mélange alpha séparément

SPÉCIFICATION C

void glBlendEquationSeparate(GLenum modeRGB, GLenum modeAlpha);

void glBlendEquationSeparatei(GLuint buf, GLenum modeRGB, GLenum modeAlpha);

PARAMÈTRES

buf

pour glBlendEquationSeparatei, spécifie l'index du tampon de dessin pour lequel définir les équations de mélange.

modeRGB

spécifie l'équation de mélange RGB, comment les composantes rouge, verte et bleue des couleurs source et destination sont combinées. Doit être GL_FUNC_ADD, GL_FUNC_SUBTRACT, GL_FUNC_REVERSE_SUBTRACT, GL_MIN, GL_MAX.

modeAlpha

spécifie l'équation de mélange alpha, comment la composante alpha des couleurs source et destination sont combinées. Doit être GL_FUNC_ADD, GL_FUNC_SUBTRACT, GL_FUNC_REVERSE_SUBTRACT, GL_MIN, GL_MAX.

DESCRIPTION

Les équations de mélange déterminent comment un nouveau pixel (la couleur « source ») est combiné avec un pixel déjà dans le framebuffer (la couleur « destination »). Ces fonctions spécifient une équation de mélange pour les composantes de couleur RGB et une équation de mélange pour la composante alpha. glBlendEquationSeparatei spécifie les équations de mélange pour un seul tampon de dessin tandis que glBlendEquationSeparate définit les équations de mélange pour tous les tampons de dessin.

Les équations de mélange utilisent les facteurs de mélange source et destination spécifiés par glBlendFunc() ou glBlendFuncSeparate(). Voir glBlendFunc() ou glBlendFuncSeparate() pour une description des différents facteurs de mélange.

Dans les équations suivantes, les composantes de couleur source et destination sont désignées par R s G s B s A s et R d G d B d A d, respectivement. La couleur résultante est désignée par R r G r B r A r. Les facteurs de mélange source et destination sont désignés par s R s G s B s A et d R d G d B d A, respectivement. Pour ces équations, toutes les composantes de couleur sont comprises comme ayant des valeurs dans l'intervalle 0 1.

Mode Composantes RGB Composante Alpha
GL_FUNC_ADD Rr = R s ⁢ s R + R d ⁢ d R Gr = G s ⁢ s G + G d ⁢ d G Br = B s ⁢ s B + B d ⁢ d B Ar = A s ⁢ s A + A d ⁢ d A
GL_FUNC_SUBTRACT Rr = R s ⁢ s R - R d ⁢ d R Gr = G s ⁢ s G - G d ⁢ d G Br = B s ⁢ s B - B d ⁢ d B Ar = A s ⁢ s A - A d ⁢ d A
GL_FUNC_REVERSE_SUBTRACT Rr = R d ⁢ d R - R s ⁢ s R Gr = G d ⁢ d G - G s ⁢ s G Br = B d ⁢ d B - B s ⁢ s B Ar = A d ⁢ d A - A s ⁢ s A
GL_MIN Rr = min ⁡ R s R d Gr = min ⁡ G s G d Br = min ⁡ B s B d Ar = min ⁡ A s A d
GL_MAX Rr = max ⁡ R s R d Gr = max ⁡ G s G d Br = max ⁡ B s B d Ar = max ⁡ A s A d

Les résultats de ces équations sont limités à l'intervalle 0 1.

Les équations GL_MIN et GL_MAX sont utiles pour les applications qui analysent les données d'image (seuil d'image par rapport à une couleur constante, par exemple). L'équation GL_FUNC_ADD est utile pour l'anticrénelage et la transparence, entre autres.

Initialement, l'équation de mélange RGB et l'équation de mélange alpha sont toutes deux définies sur GL_FUNC_ADD.

NOTES

Les équations GL_MIN et GL_MAX n'utilisent pas les facteurs source ou destination, seulement les couleurs source et destination.

ERREURS

GL_INVALID_ENUM est généré si modeRGB ou modeAlpha n'est pas GL_FUNC_ADD, GL_FUNC_SUBTRACT, GL_FUNC_REVERSE_SUBTRACT, GL_MAX, ou GL_MIN.

GL_INVALID_VALUE est généré par glBlendEquationSeparatei si buf est supérieur ou égal à la valeur de GL_MAX_DRAW_BUFFERS.

ASSOCIÉES GETS

glGet() avec un argument GL_BLEND_EQUATION_RGB

glGet() avec un argument GL_BLEND_EQUATION_ALPHA
