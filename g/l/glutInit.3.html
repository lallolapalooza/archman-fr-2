NOM

glutInit - initialise la bibliothèque GLUT.

SYNTAXE

void glutInit(int *argcp, char **argv);

ARGUMENTS

argcp
Un pointeur vers la variable argc du programme main, non modifiée. Au retour, la valeur pointée par argcp sera mise à jour, car glutInit extrait les options de ligne de commande destinées à la bibliothèque GLUT.
argv
La variable argv du programme main, non modifiée. Comme argcp, les données pour argv seront mises à jour car glutInit extrait les options de ligne de commande comprises par la bibliothèque GLUT.

DESCRIPTION

glutInit initialise la bibliothèque GLUT et négocie une session avec le système de fenêtrage. Au cours de ce processus, glutInit peut entraîner la terminaison du programme GLUT avec un message d'erreur à l'utilisateur si GLUT ne peut être initialisé correctement. Les exemples de cette situation incluent l'échec de la connexion au système de fenêtrage, l'absence de prise en charge du système de fenêtrage par OpenGL, et des options de ligne de commande invalides.

glutInit traite également les options de ligne de commande, mais les options spécifiques analysées dépendent du système de fenêtrage.

NOTES D'IMPLEMENTATION SOUS X

Les options spécifiques au système X Window analysées par glutInit sont les suivantes :

-display DISPLAY
Spécifie le serveur X auquel se connecter. Si non spécifié, la valeur de la variable d'environnement DISPLAY est utilisée.
-geometry WxH+X+Y
Détermine où les fenêtres doivent être créées à l'écran. Le paramètre suivant -geometry doit être formaté comme une spécification de géométrie X standard. L'effet de l'utilisation de cette option est de modifier la taille initiale et la position initiale de GLUT, comme si glutInitWindowSize ou glutInitWindowPosition avaient été appelés directement.
-iconic
Demande que toutes les fenêtres de premier niveau soient créées à l'état iconique.
-indirect
Force l'utilisation de contextes de rendu OpenGL indirects.
-direct
Force l'utilisation de contextes de rendu OpenGL directs (toutes les implémentations GLX ne supportent pas les contextes de rendu directs). Une erreur fatale est générée si le rendu direct n'est pas pris en charge par l'implémentation OpenGL.

Si ni -indirect ni -direct ne sont utilisés pour forcer un comportement particulier, GLUT tentera d'utiliser le rendu direct si possible et, sinon, se rabattra sur le rendu indirect.

-gldebug
Après avoir traité les callbacks et/ou les événements, vérifie s'il y a des erreurs OpenGL en appelant glGetError. Si une erreur est signalée, affiche un avertissement en recherchant le code d'erreur avec gluErrorString. L'utilisation de cette option est utile pour détecter les erreurs d'exécution OpenGL.
-sync
Active les transactions de protocole X synchrones. Cette option facilite le suivi des erreurs potentielles du protocole X.

VOIR AUSSI

glutCreateWindow, glutInitWindowPosition, glutInitWindowSize, glutMainLoop
