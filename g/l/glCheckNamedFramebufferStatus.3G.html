GLCHECKFRAMEBUFFERST(3G) [FIXME: manual] GLCHECKFRAMEBUFFERST(3G)

NOM

glCheckFramebufferStatus, glCheckNamedFramebufferStatus - vérifier l'état de complétude d'un framebuffer

SPÉCIFICATION C

GLenum glCheckFramebufferStatus(GLenumtarget);

GLenum glCheckNamedFramebufferStatus(GLuintframebuffer, GLenumtarget);

PARAMÈTRES

target

Spécifie la cible à laquelle le framebuffer est lié pour glCheckFramebufferStatus, et la cible par rapport à laquelle la complétude du framebuffer de framebuffer est vérifiée pour glCheckNamedFramebufferStatus.

framebuffer

Spécifie le nom de l'objet framebuffer pour glCheckNamedFramebufferStatus

DESCRIPTION

glCheckFramebufferStatus et glCheckNamedFramebufferStatus renvoient l'état de complétude d'un objet framebuffer lorsqu'il est traité comme un framebuffer de lecture ou d'écriture, selon la valeur de target.

Pour glCheckFramebufferStatus, le framebuffer vérifié est celui lié à target, qui doit être GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER ou GL_FRAMEBUFFER. GL_FRAMEBUFFER est équivalent à GL_DRAW_FRAMEBUFFER.

Pour glCheckNamedFramebufferStatus, framebuffer est zéro ou le nom de l'objet framebuffer à vérifier. Si framebuffer est zéro, l'état du framebuffer de lecture ou d'écriture par défaut, tel que déterminé par target, est renvoyé.

La valeur de retour est GL_FRAMEBUFFER_COMPLETE si le framebuffer spécifié est complet. Sinon, la valeur de retour est déterminée comme suit :

•GL_FRAMEBUFFER_UNDEFINED est renvoyé si le framebuffer spécifié est le framebuffer de lecture ou d'écriture par défaut, mais que le framebuffer par défaut n'existe pas.
•GL_FRAMEBUFFER_INCOMPLETE_ATTACHMENT est renvoyé si l'un des points de rattachement du framebuffer est incomplet.
•GL_FRAMEBUFFER_INCOMPLETE_MISSING_ATTACHMENT est renvoyé si le framebuffer n'a pas au moins une image rattachée.
•GL_FRAMEBUFFER_INCOMPLETE_DRAW_BUFFER est renvoyé si la valeur de GL_FRAMEBUFFER_ATTACHMENT_OBJECT_TYPE est GL_NONE pour l'un des points de rattachement couleur nommés par GL_DRAW_BUFFERi.
•GL_FRAMEBUFFER_INCOMPLETE_READ_BUFFER est renvoyé si GL_READ_BUFFER n'est pas GL_NONE et que la valeur de GL_FRAMEBUFFER_ATTACHMENT_OBJECT_TYPE est GL_NONE pour le point de rattachement couleur nommé par GL_READ_BUFFER.
•GL_FRAMEBUFFER_UNSUPPORTED est renvoyé si la combinaison des formats internes des images rattachées viole un ensemble de restrictions dépendant de l'implémentation.
•GL_FRAMEBUFFER_INCOMPLETE_MULTISAMPLE est renvoyé si la valeur de GL_RENDERBUFFER_SAMPLES n'est pas la même pour tous les tampons de rendu rattachés ; si la valeur de GL_TEXTURE_SAMPLES n'est pas la même pour toutes les textures rattachées ; ou, si les images rattachées sont un mélange de tampons de rendu et de textures, la valeur de GL_RENDERBUFFER_SAMPLES ne correspond pas à la valeur de GL_TEXTURE_SAMPLES.
•GL_FRAMEBUFFER_INCOMPLETE_MULTISAMPLE est également renvoyé si la valeur de GL_TEXTURE_FIXED_SAMPLE_LOCATIONS n'est pas la même pour toutes les textures rattachées ; ou, si les images rattachées sont un mélange de tampons de rendu et de textures, la valeur de GL_TEXTURE_FIXED_SAMPLE_LOCATIONS n'est pas GL_TRUE pour toutes les textures rattachées.
•GL_FRAMEBUFFER_INCOMPLETE_LAYER_TARGETS est renvoyé si un rattachement de framebuffer est en couches, et qu'un rattachement peuplé n'est pas en couches, ou si tous les rattachements couleur peuplés ne proviennent pas de textures de la même cible.

De plus, si une erreur se produit, zéro est renvoyé.

ERREURS

GL_INVALID_ENUM est généré si target n'est pas GL_DRAW_FRAMEBUFFER, GL_READ_FRAMEBUFFER ou GL_FRAMEBUFFER.

GL_INVALID_OPERATION est généré par glCheckNamedFramebufferStatus si framebuffer n'est pas zéro ou le nom d'un objet framebuffer existant.
