NOM

glCreateRenderbuffers - créer des objets renderbuffer

SPÉCIFICATION C

void glCreateRenderbuffers(GLsizei n, GLuint *renderbuffers);

PARAMÈTRES

n

Nombre d'objets renderbuffer à créer.

renderbuffers

Spécifie un tableau dans lequel sont stockés les noms des nouveaux objets renderbuffer.

DESCRIPTION

glCreateRenderbuffers renvoie n noms d'objets renderbuffer auparavant inutilisés dans renderbuffers, chacun représentant un nouvel objet renderbuffer initialisé à l'état par défaut.

ERREURS

GL_INVALID_VALUE est généré si n est négatif.
