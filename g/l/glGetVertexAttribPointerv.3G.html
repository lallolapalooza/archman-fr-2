NOM

glGetVertexAttribPointerv - retourne l'adresse du pointeur d'attribut de sommet générique spécifié

SPÉCIFICATION C

void glGetVertexAttribPointerv(GLuint index, GLenum pname, void **pointer);

PARAMÈTRES

index

Spécifie le paramètre d'attribut de sommet générique à retourner.

pname

Spécifie le nom symbolique du paramètre d'attribut de sommet générique à retourner. Doit être GL_VERTEX_ATTRIB_ARRAY_POINTER.

pointer

Retourne la valeur du pointeur.

DESCRIPTION

glGetVertexAttribPointerv retourne les informations du pointeur. index est l'attribut de sommet générique à interroger, pname est une constante symbolique indiquant le pointeur à retourner, et params est un pointeur vers un emplacement où placer les données retournées.

Le pointer retourné est un décalage en octets dans le magasin de données de l'objet buffer qui était lié à la cible GL_ARRAY_BUFFER (voir glBindBuffer()) lorsque le pointeur désiré a été précédemment spécifié.

NOTES

L'état retourné est récupéré à partir de l'objet tableau de sommets actuellement lié.

La valeur initiale de chaque pointeur est 0.

ERREURS

GL_INVALID_OPERATION est généré si aucun objet tableau de sommets n'est actuellement lié.

GL_INVALID_VALUE est généré si index est supérieur ou égal à GL_MAX_VERTEX_ATTRIBS.

GL_INVALID_ENUM est généré si pname n'est pas une valeur acceptée.

ASSOCIÉES GETS

glGet() avec l'argument GL_MAX_VERTEX_ATTRIBS
