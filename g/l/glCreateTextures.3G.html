NOM

glCreateTextures - créer des objets texture

SPÉCIFICATION C

void glCreateTextures(GLenum target, GLsizei n, GLuint *textures);

PARAMÈTRES

target

Spécifie la cible de texture effective de chaque texture créée.

n

Nombre d'objets texture à créer.

textures

Spécifie un tableau dans lequel sont stockés les noms des nouveaux objets texture.

DESCRIPTION

glCreateTextures renvoie n noms de texture précédemment inutilisés dans textures, chacun représentant un nouvel objet texture de la dimensionnalité et du type spécifiés par target et initialisé avec les valeurs par défaut pour ce type de texture.

target doit être l'un de GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_RECTANGLE, GL_TEXTURE_CUBE_MAP, GL_TEXTURE_CUBE_MAP_ARRAY, GL_TEXTURE_BUFFER, GL_TEXTURE_2D_MULTISAMPLE ou GL_TEXTURE_2D_MULTISAMPLE_ARRAY.

ERREURS

GL_INVALID_ENUM est généré si target n'est pas l'une des valeurs autorisées.

GL_INVALID_VALUE est généré si n est négatif.
