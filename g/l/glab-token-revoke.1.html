NOM

glab-token-revoke - Révoquer les jetons d'accès utilisateur, de groupe ou de projet

SYNOPSIS

glab token revoke [options]

DESCRIPTION

Révoque un jeton d'accès utilisateur, de groupe ou de projet. Si plusieurs jetons portent le même nom, vous pouvez spécifier l'identifiant du jeton.

Le format de sortie peut être "JSON" ou "text". La sortie JSON affichera les métadonnées du jeton révoqué. La sortie texte normale est une description du nom et de l'identifiant du jeton révoqué.

Les administrateurs peuvent révoquer les jetons d'accès personnels appartenant à d'autres utilisateurs.

OPTIONS

-g, --group="" Révoque un jeton d'accès de groupe. Ignoré si un argument utilisateur ou dépôt est défini.

-F, --output="text" Formate la sortie comme : text, json. 'text' fournit le nom et l'identifiant du jeton révoqué ; 'json' affiche le jeton avec ses métadonnées.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE_NOMMÉ/DÉPÔT. Accepte également les URL complètes ou les URL Git.

-U, --user="" Révoque un jeton d'accès personnel. Utiliser @me pour l'utilisateur actuel.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

EXEMPLE

# Révoquer un jeton d'accès de projet du projet actuel
$ glab token revoke mon-jeton-projet
# Révoquer un jeton d'accès de projet d'un projet spécifique
$ glab token revoke --repo utilisateur/mon-repo mon-jeton-projet
# Révoquer un jeton d'accès de groupe
$ glab token revoke --group groupe/sous-groupe mon-jeton-groupe
# Révoquer mon jeton d'accès personnel
$ glab token revoke --user @me mon-jeton-personnel
# Révoquer le jeton d'accès personnel d'un autre utilisateur (administrateur uniquement)
$ glab token revoke --user jean-dupont jeton-personnel-de-jean
