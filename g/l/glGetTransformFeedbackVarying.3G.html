NOM

glGetTransformFeedbackVarying - récupérer des informations sur les variables variant sélectionnées pour le retour de transformation

SPÉCIFICATION C

void glGetTransformFeedbackVarying(GLuint program, GLuint index, GLsizei bufSize, GLsizei *length, GLsizei *size, GLenum *type, char *name);

PARAMÈTRES

program

Le nom de l'objet programme cible.

index

L'index de la variable variant dont on souhaite récupérer les informations.

bufSize

Le nombre maximal de caractères, incluant le terminateur nul, pouvant être écrits dans name.

length

L'adresse d'une variable qui recevra le nombre de caractères écrits dans name, excluant le terminateur nul. Si length est NULL, aucune longueur n'est retournée.

size

L'adresse d'une variable qui recevra la taille de la variable variant.

type

L'adresse d'une variable qui recevra le type de la variable variant.

name

L'adresse d'un tampon dans lequel sera écrit le nom de la variable variant.

DESCRIPTION

Les informations sur l'ensemble des variables variants dans un programme lié qui seront capturées pendant le retour de transformation peuvent être récupérées en appelant glGetTransformFeedbackVarying. glGetTransformFeedbackVarying fournit des informations sur la variable variant sélectionnée par index. Un index de 0 sélectionne la première variable variant spécifiée dans le tableau varyings passé à glTransformFeedbackVaryings(), et un index égal à la valeur de GL_TRANSFORM_FEEDBACK_VARYINGS moins un sélectionne la dernière variable de ce type.

Le nom de la variable variant sélectionnée est retourné sous forme de chaîne terminée par un caractère nul dans name. Le nombre réel de caractères écrits dans name, excluant le terminateur nul, est retourné dans length. Si length est NULL, aucune longueur n'est retournée. Le nombre maximal de caractères pouvant être écrits dans name, incluant le terminateur nul, est spécifié par bufSize.

La longueur du nom de variable variant le plus long dans le programme est donnée par GL_TRANSFORM_FEEDBACK_VARYING_MAX_LENGTH, qui peut être interrogée avec glGetProgram().

Pour la variable variant sélectionnée, son type est retourné dans type. La taille de la variable variant est retournée dans size. La valeur dans size est en unités du type retourné dans type. Le type retourné peut être l'un des types d'attributs scalaires, vectoriels ou matriciels retournés par glGetActiveAttrib(). Si une erreur s'est produite, les paramètres de retour length, size, type et name ne seront pas modifiés. Cette commande retournera autant d'informations que possible sur les variables variants. Si aucune information n'est disponible, length sera mis à zéro et name sera une chaîne vide. Cette situation peut survenir si glGetTransformFeedbackVarying est appelée après un échec de liaison.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme.

GL_INVALID_VALUE est généré si index est supérieur ou égal à la valeur de GL_TRANSFORM_FEEDBACK_VARYINGS.

GL_INVALID_OPERATION est généré si program n'a pas été lié.

GETS ASSOCIÉS

glGetProgram() avec l'argument GL_TRANSFORM_FEEDBACK_VARYING_MAX_LENGTH.
