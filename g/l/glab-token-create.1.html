NOM

glab-token-create - Crée des jetons d'accès utilisateur, de groupe ou de projet.

SYNTAXE

glab token create [indicateurs]

DESCRIPTION

Crée un nouveau jeton d'accès pour un utilisateur, un groupe ou un projet. Par défaut, il s'agit d'un jeton d'accès de projet, sauf si un nom d'utilisateur ou de groupe est spécifié.

La date d'expiration du jeton est calculée en ajoutant la durée (par défaut : 30 jours) à la date actuelle, l'expiration se produisant à minuit UTC à la date calculée. Vous pouvez spécifier une durée différente en utilisant des jours (j), des semaines (s) ou des heures (h), ou fournir une date de fin explicite.

Le nom du jeton doit être unique. Le jeton est affiché sur la sortie standard.

Les administrateurs peuvent créer des jetons d'accès personnels complets pour eux-mêmes et pour d'autres utilisateurs.

Les non-administrateurs ne peuvent créer des jetons d'accès personnels que pour eux-mêmes (@moi). Ces jetons doivent utiliser le périmètre 'k8s_proxy'. Pour plus d'informations, consultez la documentation GitLab pour l'API des jetons d'utilisateur ⟨https://docs.gitlab.com/api/user-tokens/#create-a-personal-access-token⟩.

OPTIONS

-A, --access-level=aucun Niveau d'accès du jeton : 'guest', 'reporter', 'developer', 'maintainer', 'owner'.

--description="description" Définit la description du jeton.

-D, --duration=30d Définit la durée de vie du jeton en jours. Accepte : jours (30j), semaines (4s), ou heures par multiples de 24 (24h, 168h, 720h). Maximum : 365j. Le jeton expire à minuit UTC à la date calculée.

-E, --expires-at=0001-01-01 Définit la date et l'heure d'expiration du jeton, au format AAAA-MM-JJ. Si non spécifié, --duration est utilisé.

-g, --group="" Crée un jeton d'accès de groupe. Ignoré si un argument utilisateur ou référentiel est défini.

-F, --output="text" Formate la sortie en 'text' pour la valeur du jeton, 'json' pour la structure réelle du jeton API.

-R, --repo="" Sélectionne un autre référentiel. Peut utiliser le format PROPRIÉTAIRE/RÉFÉRENTIEL ou GROUPE/ESPACE DE NOMS/RÉFÉRENTIEL. Accepte également une URL complète ou une URL Git.

-S, --scope=[read_repository] Périmètres pour le jeton. Plusieurs périmètres peuvent être séparés par des virgules ou spécifiés en répétant l'indicateur. Pour une liste, voir https://docs.gitlab.com/user/profile/personal_access_tokens/#personal-access-token-scopes.

-U, --user="" Crée un jeton d'accès personnel. Pour l'utilisateur actuel, utilisez @moi.

OPTIONS INHERITEES DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

EXEMPLE

# Crée un jeton d'accès de projet pour le projet actuel (par défaut 30 jours)
$ glab token create --access-level developer --scope read_repository --scope read_registry mon-jeton-projet
# Crée un jeton d'accès de projet avec une durée de vie de 7 jours
$ glab token create --repo utilisateur/mon-repo --access-level owner --scope api mon-jeton-projet --duration 7j
# Crée un jeton d'accès de groupe expirant dans 2 semaines
$ glab token create --group groupe/sous-groupe --access-level owner --scope api mon-jeton-groupe --duration 2s
# Crée un jeton d'accès personnel pour l'utilisateur actuel avec une durée de vie de 90 jours
$ glab token create --user @moi --scope k8s_proxy mon-jeton-personnel --duration 90j
# (administrateur uniquement) Crée un jeton d'accès personnel pour un autre utilisateur
$ glab token create --user johndoe --scope api jeton-personnel-de-john --duration 180j
# Crée un jeton avec une date d'expiration explicite
$ glab token create --access-level developer --scope api mon-jeton --expires-at 2025-12-31
