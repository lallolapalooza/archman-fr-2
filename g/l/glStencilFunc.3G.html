NOM

glStencilFunc - définit la fonction avant et arrière et la valeur de référence pour le test stencil

SPÉCIFICATION C

void glStencilFunc(GLenum func, GLint ref, GLuint mask);

PARAMÈTRES

func

Spécifie la fonction de test. Huit constantes symboliques sont valides : GL_NEVER, GL_LESS, GL_LEQUAL, GL_GREATER, GL_GEQUAL, GL_EQUAL, GL_NOTEQUAL et GL_ALWAYS. La valeur initiale est GL_ALWAYS.

ref

Spécifie la valeur de référence pour le test stencil. ref est limité à la plage 0 2 n - 1, où n est le nombre de plans binaires dans le tampon stencil. La valeur initiale est 0.

mask

Spécifie un masque qui est appliqué par un ET logique à la fois à la valeur de référence et à la valeur stencil stockée lors du test. La valeur initiale est tous les 1.

DESCRIPTION

Le stencil, comme le tampon de profondeur, active et désactive le dessin pixel par pixel. Les plans stencil sont d'abord dessinés à l'aide de primitives de dessin GL, puis la géométrie et les images sont rendues à l'aide des plans stencil pour masquer des parties de l'écran. Le stencil est généralement utilisé dans les algorithmes de rendu multipasse pour obtenir des effets spéciaux, tels que les décals, les contours et le rendu de géométrie solide constructive.

Le test stencil élimine conditionnellement un pixel en fonction du résultat d'une comparaison entre la valeur de référence et la valeur dans le tampon stencil. Pour activer et désactiver le test, appelez glEnable() et

glDisable avec l'argument GL_STENCIL_TEST. Pour spécifier des actions basées sur le résultat du test stencil, appelez glStencilOp() ou glStencilOpSeparate().

Il peut y avoir deux ensembles distincts de paramètres func, ref et mask ; l'un affecte les polygones dont la face est visible (back-facing), et l'autre affecte les polygones dont la face est orientée vers l'avant (front-facing) ainsi que d'autres primitives non polygonales. glStencilFunc() définit l'état du stencil avant et arrière aux mêmes valeurs. Utilisez glStencilFuncSeparate() pour définir des états de stencil avant et arrière à des valeurs différentes.

func est une constante symbolique qui détermine la fonction de comparaison du stencil. Elle accepte l'une des huit valeurs, présentées dans la liste suivante. ref est une valeur de référence entière utilisée dans la comparaison du stencil. Elle est limitée à la plage 0 2 n - 1, où n est le nombre de plans binaires dans le tampon stencil. mask est appliqué par un ET logique à la fois à la valeur de référence et à la valeur stencil stockée, les valeurs résultantes participant à la comparaison.

Si stencil représente la valeur stockée dans l'emplacement correspondant du tampon stencil, la liste suivante montre l'effet de chaque fonction de comparaison qui peut être spécifiée par func. Ce n'est que si la comparaison réussit que le pixel passe à l'étape suivante du processus de rastérisation (voir glStencilOp()). Tous les tests traitent les valeurs stencil comme des entiers non signés dans la plage 0 2 n - 1, où n est le nombre de plans binaires dans le tampon stencil.

Les valeurs suivantes sont acceptées par func :

GL_NEVER

Échoue toujours.

GL_LESS

Réussit si ( ref & mask ) < ( stencil & mask ).

GL_LEQUAL

Réussit si ( ref & mask ) <= ( stencil & mask ).

GL_GREATER

Réussit si ( ref & mask ) > ( stencil & mask ).

GL_GEQUAL

Réussit si ( ref & mask ) >= ( stencil & mask ).

GL_EQUAL

Réussit si ( ref & mask ) = ( stencil & mask ).

GL_NOTEQUAL

Réussit si ( ref & mask ) != ( stencil & mask ).

GL_ALWAYS

Réussit toujours.

NOTES

Initialement, le test stencil est désactivé. S'il n'y a pas de tampon stencil, aucune modification du stencil ne peut se produire et c'est comme si le test stencil réussissait toujours.

glStencilFunc() est identique à l'appel de glStencilFuncSeparate() avec face défini sur GL_FRONT_AND_BACK.

ERREURS

GL_INVALID_ENUM est généré si func n'est pas l'une des huit valeurs acceptées.

GETS ASSOCIÉS

glGet() avec l'argument GL_STENCIL_FUNC, GL_STENCIL_VALUE_MASK, GL_STENCIL_REF, GL_STENCIL_BACK_FUNC, GL_STENCIL_BACK_VALUE_MASK, GL_STENCIL_BACK_REF, ou GL_STENCIL_BITS

glIsEnabled() avec l'argument GL_STENCIL_TEST

glStencilFunc

NOM

glStencilFunc — définit le test de fonction du stencil et l'opération d'écriture.

SPÉCIFICATION C

void glStencilFunc(GLenum func, GLint ref, GLuint mask);

PARAMÈTRES

Spécifiez la fonction de comparaison du stencil, la valeur de référence du stencil, et le masque d'écriture du stencil.

func
Spécifie la fonction de comparaison du stencil. Les valeurs possibles sont :
  • GL_NEVER : Le test ne passe jamais.
  • GL_LESS : Le test passe si la référence est strictement supérieure à la valeur du stencil.
  • GL_EQUAL : Le test passe si la référence est égale à la valeur du stencil.
  • GL_LEQUAL : Le test passe si la référence est supérieure ou égale à la valeur du stencil.
  • GL_GREATER : Le test passe si la référence est strictement inférieure à la valeur du stencil.
  • GL_NOTEQUAL : Le test passe si la référence est différente de la valeur du stencil.
  • GL_GEQUAL : Le test passe si la référence est inférieure ou égale à la valeur du stencil.
  • GL_ALWAYS : Le test passe toujours.
ref
Spécifie la référence du stencil à comparer avec les valeurs actuelles du stencil.
mask
Spécifie un masque d'écriture d'octet. Seuls les bits masqués de la valeur de référence et de la valeur du stencil sont comparés.

DESCRIPTION

glStencilFunc définit les paramètres pour le test de stencil, qui est appliqué à chaque fragment résultant d'un dessin. Le stencil buffer est une mémoire tampon d'entiers par pixel. Les opérations de stencil sont typiquement utilisées pour des effets comme les ombres, les reflets, la détection de collision, ou pour ne dessiner qu'une partie d'une image.

Le test de stencil est exécuté après le test de profondeur et avant l'exécution de l'écriture de couleur. Si le test de stencil échoue, le fragment est descarté.

func, ref, et mask sont utilisés comme suit : pour chaque fragment, la valeur de stencil actuelle stockée dans le stencil buffer est comparée à ref à l'aide de la fonction spécifiée par func. Le masque mask est appliqué à la fois à la valeur de référence et à la valeur du stencil avant la comparaison. Si la comparaison réussit, le fragment est autorisé à continuer dans le pipeline de rendu.

Les opérations de stencil sont contrôlées par glStencilOp. Le stencil buffer est mis à jour uniquement si les tests de profondeur et de stencil réussissent, et si le test d'occlusion (s'il est activé) réussit. Sinon, les opérations de stencil ne sont pas exécutées.

Lorsque le stencil buffer est activé, les appels à glClear remettent à zéro les valeurs du stencil.

Utilisez glEnable(GL_STENCIL_TEST) pour activer le test de stencil et glDisable(GL_STENCIL_TEST) pour le désactiver.

NOTES

La valeur ref est une valeur entière avec signe, tandis que la valeur du stencil est une valeur entière sans signe. Pour la comparaison, les deux sont traitées comme des entiers sans signe.

Les masques mask et les valeurs ref sont interprétés comme des valeurs binaires. Seuls les bits pour lesquels le bit correspondant dans mask est défini sont pris en compte lors de la comparaison.

ERREURS

GL_INVALID_ENUM est généré si func n'est pas l'une des valeurs énumérées suivantes : GL_NEVER, GL_LESS, GL_EQUAL, GL_LEQUAL, GL_GREATER, GL_NOTEQUAL, GL_GEQUAL, ou GL_ALWAYS.

GETS ASSOCIÉS

glGet avec les constantes suivantes :

  • GL_STENCIL_FUNC
  • GL_STENCIL_REF
  • GL_STENCIL_VALUE_MASK
  • GL_STENCIL_FAIL
  • GL_STENCIL_PASS_DEPTH_FAIL
  • GL_STENCIL_PASS_DEPTH_PASS
  • GL_STENCIL_WRITEMASK
