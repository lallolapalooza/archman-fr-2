NOM

glIsVertexArray - déterminer si un nom correspond à un objet tableau de sommets

SPÉCIFICATION C

GLboolean glIsVertexArray(GLuint array);

PARAMÈTRES

array

Spécifie une valeur qui peut être le nom d'un objet tableau de sommets.

DESCRIPTION

glIsVertexArray retourne GL_TRUE si array est actuellement le nom d'un objet tableau de sommets. Si array est zéro, ou si array n'est pas le nom d'un objet tableau de sommets, ou si une erreur se produit, glIsVertexArray retourne GL_FALSE. Si array est un nom renvoyé par glGenVertexArrays(), mais qui n'a pas encore été lié par un appel à glBindVertexArray(), alors le nom n'est pas un objet tableau de sommets et glIsVertexArray retourne GL_FALSE.
