NOM

glsnake - Serpent de Rubik amélioré par OpenGL, pour perdre du temps.

SYNOPSIS

glsnake [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro] [--visual visuel] [--delay microsecondes] [--fps] [--wireframe] [--altcolour] [--angvel angulaire] [--explode distance] [--statictime millisecondes] [--yangvel angle] [--zangvel angle]

DESCRIPTION

glsnake est une imitation du Serpent de Rubik, utilisant OpenGL.

OPTIONS

glsnake accepte les options suivantes :

--window
Dessiner dans une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessiner dans la fenêtre racine.
--window-id numéro
Dessiner dans la fenêtre spécifiée.
--install
Installer une carte de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou le numéro d'identification (décimal ou hexadécimal) d'un visuel spécifique.
--fps
Afficher la fréquence d'images actuelle, la charge CPU et le nombre de polygones.
--wireframe
Afficher le serpent en mode fil de fer, plutôt qu'en mode solide par défaut.
--altcolour
Utiliser le schéma de couleurs alternatif pour le serpent. L'identification des formes par couleur sera désactivée.
-angvel angulaire
Changer la vitesse à laquelle le serpent se transforme en une nouvelle forme.
-explode distance
Changer la distance entre les nœuds d'un serpent.
--statictime millisecondes
Changer le temps entre les transformations.
--yangvel angle
Changer l'angle de rotation autour de l'axe Y par image.
--zangvel angle
Changer l'angle de rotation autour de l'axe Z par image.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1),
https://spacepants.org/src/glsnake/

BOGUES

Le serpent peut joyeusement s'intersecter lui-même pendant la transformation (ce n'est pas un bug).

La rotation/position de la caméra est nulle.
