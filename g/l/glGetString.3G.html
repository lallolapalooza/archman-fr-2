glGetString - renvoie u

ne chaîne décrivant la
connexion GL actuelle

SPÉCIFICATION

C

const GLubyte *glGetString(GLenumname)

;

const GLubyte *glGetStringi(GLenumname, GLuintindex)

;

PARAMÈTRE

S

nam

e
Spécifie une constante symbolique, l'une des suivantes : GL_VENDOR, GL_RENDERER, GL_VERSION, ou GL_SHADING_LANGUAGE_VERSION. De plus, glGetStringi accepte le jeton GL_EXTENSIONS
.

inde

x
Pour glGetStringi, spécifie l'ind
ex de la chaîne
à renvoyer.

DESCRIPTIO

N

glGetString renvoie un pointeur vers une chaîne statique décrivant un aspect de la connexion GL actuelle. name peut être l'une des valeurs suivantes

:

GL_VENDO

R
Renvoie l'entreprise responsable de cette implémentation GL. Ce nom ne change pas d'une version à
l'autre.

GL_RENDERE

R
Renvoie le nom du moteur de rendu. Ce nom est généralement spécifique à une configuration particulière d'une plateforme matérielle. Il ne change pas d'une version à
l'autre.

GL_VERSIO

N
Renvoie un numéro de version ou de
publication.

GL_SHADING_LANGUAGE_VERSIO

N
Renvoie un numéro de version ou de publication pour le langage de
shading.

glGetStringi renvoie un pointeur vers une chaîne statique indexée par index. name peut être l'une des valeurs suivantes

:

GL_EXTENSION

S
Uniquement pour glGetStringi, renvoie la chaîne d'extensions prise en charge par l'implémentation à l'index index
.

Chaînes GL_VENDOR et GL_RENDERER spécifient ensemble de manière unique une plateforme. Elles ne changent pas d'une version à l'autre et doivent être utilisées par les algorithmes de reconnaissance de

plateforme.

Les chaînes GL_VERSION et GL_SHADING_LANGUAGE_VERSION commencent par un numéro de version. Le numéro de version utilise l'une de ces formes

:

numero_majeur.numero_mineur numero_majeur.numero_mineur.numero_publicatio

n

Des informations spécifiques au fournisseur peuvent suivre le numéro de version. Leur format dépend de l'implémentation, mais un espace sépare toujours le numéro de version et les informations spécifiques au

fournisseur.

Toutes les chaînes

sont terminées par
un caractère nul.

REMARQUE

S

Si une erreur est générée, glGetString renvoie

0.

Le client et le serveur peuvent prendre en charge des versions différentes. glGetString renvoie toujours un numéro de version compatibl

e. Le numéro de publicati
on décrit toujours le serveur.

ERREUR

S

GL_INVALID_ENUM est généré si name n'est pas une valeur

acceptée.

GL_INVALID_VALUE est généré par glGetStringi si index est en dehors de la plage valide pour l'état indexé na

me
.
