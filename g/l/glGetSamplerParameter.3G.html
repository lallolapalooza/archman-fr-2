NOM

glGetSamplerParameter - renvoie les valeurs des paramètres du sampler

SPÉCIFICATION C

void glGetSamplerParameterfv(GLuintsampler, GLenumpname, GLfloat *params);

void glGetSamplerParameteriv(GLuintsampler, GLenumpname, GLint *params);

void glGetSamplerParameterIiv(GLuintsampler, GLenumpname, GLint *params);

void glGetSamplerParameterIuiv(GLuintsampler, GLenumpname, GLuint *params);

PARAMÈTRES

sampler

Spécifie le nom de l'objet sampler à partir duquel récupérer les paramètres.

pname

Spécifie le nom symbolique d'un paramètre du sampler. GL_TEXTURE_MAG_FILTER, GL_TEXTURE_MIN_FILTER, GL_TEXTURE_MIN_LOD, GL_TEXTURE_MAX_LOD, GL_TEXTURE_LOD_BIAS, GL_TEXTURE_WRAP_S, GL_TEXTURE_WRAP_T, GL_TEXTURE_WRAP_R, GL_TEXTURE_BORDER_COLOR, GL_TEXTURE_COMPARE_MODEet GL_TEXTURE_COMPARE_FUNC sont acceptés.

params

Renvoie les paramètres du sampler.

DESCRIPTION

glGetSamplerParameter renvoie dans params la valeur ou les valeurs du paramètre du sampler spécifié par pname. sampler définit le sampler cible et doit être le nom d'un objet sampler existant, renvoyé par un appel précédent à glGenSamplers(). pname accepte les mêmes symboles que glSamplerParameter(), avec les mêmes interprétations :

GL_TEXTURE_MAG_FILTER

Renvoie le filtre d'agrandissement de texture à valeur unique, une constante symbolique. La valeur initiale est GL_LINEAR.

GL_TEXTURE_MIN_FILTER

Renvoie le filtre de réduction de texture à valeur unique, une constante symbolique. La valeur initiale est GL_NEAREST_MIPMAP_LINEAR.

GL_TEXTURE_MIN_LOD

Renvoie la valeur de niveau de détail minimum de texture à valeur unique. La valeur initiale est -1000.

GL_TEXTURE_MAX_LOD

Renvoie la valeur de niveau de détail maximum de texture à valeur unique. La valeur initiale est 1000.

GL_TEXTURE_WRAP_S

Renvoie la fonction de répétition à valeur unique pour la coordonnée de texture s, une constante symbolique. La valeur initiale est GL_REPEAT.

GL_TEXTURE_WRAP_T

Renvoie la fonction de répétition à valeur unique pour la coordonnée de texture t, une constante symbolique. La valeur initiale est GL_REPEAT.

GL_TEXTURE_WRAP_R

Renvoie la fonction de répétition à valeur unique pour la coordonnée de texture r, une constante symbolique. La valeur initiale est GL_REPEAT.

GL_TEXTURE_BORDER_COLOR

Renvoie quatre nombres entiers ou flottants qui composent la couleur RGBA de la bordure de la texture. Les valeurs flottantes sont renvoyées dans l'intervalle 0 1. Les valeurs entières sont renvoyées comme une correspondance linéaire de la représentation interne en virgule flottante telle que 1.0 correspond à l'entier positif représentable le plus grand et -1.0 correspond à l'entier négatif représentable le plus petit. La valeur initiale est (0, 0, 0, 0).

GL_TEXTURE_COMPARE_MODE

Renvoie un mode de comparaison de texture à valeur unique, une constante symbolique. La valeur initiale est GL_NONE. Voir glSamplerParameter().

GL_TEXTURE_COMPARE_FUNC

Renvoie une fonction de comparaison de texture à valeur unique, une constante symbolique. La valeur initiale est GL_LEQUAL. Voir glSamplerParameter().

REMARQUES

Si une erreur est générée, le contenu de paramsn'est pas modifié.

glGetSamplerParameter n'est disponible que si la version de GL est 3.3 ou supérieure.

ERREUR

GL_INVALID_VALUE est généré si sampler n'est pas le nom d'un objet sampler renvoyé par un appel précédent à glGenSamplers().

GL_INVALID_ENUM est généré si pname n'est pas une valeur acceptée.
