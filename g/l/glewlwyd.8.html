Options en ligne de commande :

-c --config-file CHEMIN

Chemin vers le fichier de configuration

-e --env-variables

Utiliser les variables d'environnement pour configurer Glewlwyd

-p --port PORT

Port d'écoute

-u --url-prefix PREFIX

Préfixe de l'URL de l'API

-m --log-mode MODE

Modes de journalisation disponibles : console, syslog ou file. Si vous souhaitez plusieurs modes, séparez-les par une virgule « , ». Défaut : console.

-l --log-level NIVEAU

Niveaux de journalisation disponibles : NONE, ERROR, WARNING, INFO, DEBUG. Défaut : INFO.

-f --log-file CHEMIN

Chemin du fichier journal si le mode de journalisation file est spécifié

-v --version

Afficher la version actuelle de Glewlwyd

-h --help

Afficher ce message

VOIR AUSSI

La documentation complète de glewlwyd est maintenue sous forme de manuel Texinfo. Si les programmes info et glewlwyd sont correctement installés sur votre système, la commande

info glewlwyd

devrait vous donner accès au manuel complet.
