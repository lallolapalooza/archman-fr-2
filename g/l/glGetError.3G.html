NOM

glGetError - retourner des informations d'erreur

SPÉCIFICATION C

GLenum glGetError(void);

DESCRIPTION

glGetError retourne la valeur du drapeau d'erreur. Chaque erreur détectable se voit attribuer un code numérique et un nom symbolique. Lorsqu'une erreur survient, le drapeau d'erreur est défini sur la valeur appropriée du code d'erreur. Aucune autre erreur n'est enregistrée jusqu'à ce que glGetError soit appelé, que le code d'erreur soit retourné et que le drapeau soit réinitialisé à GL_NO_ERROR. Si un appel à glGetError retourne GL_NO_ERROR, il n'y a eu aucune erreur détectable depuis le dernier appel à glGetError, ou depuis l'initialisation du GL.

Pour permettre des implémentations distribuées, il peut y avoir plusieurs drapeaux d'erreur. Si un seul drapeau d'erreur a enregistré une erreur, la valeur de ce drapeau est retournée et ce drapeau est réinitialisé à GL_NO_ERROR lorsque glGetError est appelé. Si plusieurs drapeaux ont enregistré une erreur, glGetError retourne et efface une valeur d'erreur arbitraire. Ainsi, glGetError doit toujours être appelé en boucle, jusqu'à ce qu'il retourne GL_NO_ERROR, si tous les drapeaux d'erreur doivent être réinitialisés.

Initialement, tous les drapeaux d'erreur sont définis sur GL_NO_ERROR.

Les erreurs suivantes sont actuellement définies :

GL_NO_ERROR

Aucune erreur n'a été enregistrée. La valeur de cette constante symbolique est garantie d'être 0.

GL_INVALID_ENUM

Une valeur inacceptable est spécifiée pour un argument énuméré. La commande fautive est ignorée et n'a pas d'autre effet secondaire que de définir le drapeau d'erreur.

GL_INVALID_VALUE

Un argument numérique est hors limites. La commande fautive est ignorée et n'a pas d'autre effet secondaire que de définir le drapeau d'erreur.

GL_INVALID_OPERATION

L'opération spécifiée n'est pas autorisée dans l'état actuel. La commande fautive est ignorée et n'a pas d'autre effet secondaire que de définir le drapeau d'erreur.

GL_INVALID_FRAMEBUFFER_OPERATION

L'objet framebuffer n'est pas complet. La commande fautive est ignorée et n'a pas d'autre effet secondaire que de définir le drapeau d'erreur.

GL_OUT_OF_MEMORY

Il n'y a pas assez de mémoire restante pour exécuter la commande. L'état du GL est indéfini, à l'exception de l'état des drapeaux d'erreur, après que cette erreur soit enregistrée.

GL_STACK_UNDERFLOW

Une tentative a été faite pour effectuer une opération qui provoquerait un sous-dépassement d'une pile interne.

GL_STACK_OVERFLOW

Une tentative a été faite pour effectuer une opération qui provoquerait un dépassement d'une pile interne.

Lorsqu'un drapeau d'erreur est défini, les résultats d'une opération GL sont indéfinis seulement si GL_OUT_OF_MEMORY s'est produit. Dans tous les autres cas, la commande générant l'erreur est ignorée et n'a aucun effet sur l'état du GL ou le contenu du framebuffer. Si la commande génératrice retourne une valeur, elle retourne 0. Si glGetError lui-même génère une erreur, il retourne 0.
