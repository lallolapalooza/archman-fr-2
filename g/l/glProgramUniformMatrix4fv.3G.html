NAME

glProgramUniformMatrix2fv glProgramUniformMatrix2x3fv glProgramUniformMatrix2x4fv glProgramUniformMatrix3fv glProgramUniformMatrix3x2fv glProgramUniformMatrix3x4fv glProgramUniformMatrix4fv glProgramUniformMatrix4x2fv glProgramUniformMatrix4x3fv

set uniforms for program objects

C SPECIFICATION

void glProgramUniformMatrix[2|2x3|2x4|3|3x2|3x4|4|4x2|4x3]fv(
  GLint location,
  GLsizei count,
  GLboolean transpose,
  const GLfloat *value);

PARAMETERS

location
Specifies the uniform variable location.
count
Specifies the number of matrices that are to be downloaded to the identified matrix-compatible uniform variable.
transpose
Specifies whether to transpose the matrix. Should be GL_TRUE if the matrix is transposed, and GL_FALSE otherwise.
value
Specifies a pointer to the uniform variable to be modified. This point must point to an array of 
count
matrix elements.

DESCRIPTION

calls specify the value of a uniform variable (or a matrix of uniform variables) within the current program object. These routines are part of the OpenGL ‐ core profile, and do not require the program object to be currently active.

The commands differ in the number of elements they set, and the dimensions of the matrix.

The commands with a “2” in their name set a 2x2 matrix, commands with a “3” set a 3x3 matrix, and commands with a “4” set a 4x4 matrix. Commands with an additional “xN” specify a non-square matrix.

The commands with “fv” in their name require a pointer to a block of floating-point values.

The matrices are laid out in column-major order, meaning that elements of column j of matrix i are found in contiguous locations in the array. This is the standard layout for matrices in OpenGL.

If transpose is GL_TRUE, all matrices specified in the array 

value
will be transposed before being loaded into the uniform variable.

If count is greater than 1, 

location
refers to the starting matrix index of an array of uniform variables. Otherwise, if 
count
is 1, the uniform variable specified by 
location
is a single matrix. The arrays of uniform variables are identified by the name of the variable, followed by “[index]”, where index is a zero-based array index.

The 

transpose
parameter is ignored if the uniform variable is not a matrix.

If the uniform variable specified by 

location
is not a matrix, or if the dimensions specified do not match the dimensions of the uniform variable, a GL_INVALID_OPERATION error is generated.

If 

location
is not a valid uniform location, a GL_INVALID_OPERATION error is generated.

If 

count
is negative, a GL_INVALID_VALUE error is generated.

If 

value
is the null pointer, a GL_INVALID_VALUE error is generated.

NOTES

The functions are equivalent to calling glUniformMatrix[2|2x3|2x4|3|3x2|3x4|4|4x2|4x3]fv, but they operate without needing to make the program object current.

ERRORS

GL_INVALID_OPERATION is generated if 

location
does not correspond to a uniform variable location in the program object currently assigned to glUseProgram. GL_INVALID_OPERATION is generated if the specified dimension does not match the dimension of the uniform variable.

GL_INVALID_VALUE is generated if 

count
is negative or if 
value
is the null pointer.
