NOM

glab-repo-delete - Supprimer un projet existant sur GitLab.

SYNTAXE

glab repo delete [/] [options]

DESCRIPTION

Supprime un projet existant sur GitLab.

Cela supprime définitivement l'intégralité du projet, y compris :

  • Le dépôt Git.
  • Les issues et les demandes de fusion (merge requests).
  • Les pages Wiki.
  • Les pipelines CI/CD et les artefacts des jobs.
  • D'autres contenus et paramètres du projet.

Cette action ne peut pas être annulée.

OPTIONS

-y, --yes[=false] Ignorer l'invite de confirmation et supprimer immédiatement le projet.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

# Supprimer un projet personnel.
$ glab repo delete dotfiles
# Supprimer un projet dans un groupe GitLab, ou un autre projet
# auquel vous avez accès en écriture :
$ glab repo delete mygroup/dotfiles
$ glab repo delete myorg/mynamespace/dotfiles
