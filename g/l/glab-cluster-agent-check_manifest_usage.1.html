NOM

glab-cluster-agent-check_manifest_usage - Vérifie les fichiers de configuration d'agent pour l'utilisation des manifestes GitOps intégrés. (EXPÉRIMENTAL)

SYNTAXE

glab cluster agent check_manifest_usage [options]

DESCRIPTION

Vérifie les descendants d'un groupe pour les agents enregistrés dont les fichiers de configuration s'appuient sur les paramètres de manifestes GitOps dépréciés. La sortie peut être redirigée vers un fichier de valeurs séparées par des tabulations (TSV).

Cette fonctionnalité est expérimentale. Elle pourrait être cassée ou supprimée sans préavis. Lisez-en plus sur ce que signifient les fonctionnalités expérimentales à https://docs.gitlab.com/policy/development_stages_support/

Utilisez les fonctionnalités expérimentales à vos propres risques.

OPTIONS

-a, --agent-page=1 Numéro de page pour les projets.

-A, --agent-per-page=30 Nombre de projets à lister par page.

-g, --group="" ID du groupe à vérifier.

-p, --page=1 Numéro de page pour les projets.

-P, --per-page=30 Nombre de projets à lister par page.

-r, --recursive[=false] Vérifie récursivement les sous-groupes.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Affiche l'aide pour cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également l'URL complète ou l'URL Git.
