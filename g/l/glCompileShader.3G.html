NOM

glCompileShader - Compile un objet shader

SPÉCIFICATION C

void glCompileShader(GLuint shader);

PARAMÈTRES

shader

Spécifie l'objet shader à compiler.

DESCRIPTION

glCompileShader compile les chaînes de code source qui ont été stockées dans l'objet shader spécifié par shader.

Le statut de compilation sera stocké dans l'état de l'objet shader. Cette valeur sera définie à GL_TRUE si le shader a été compilé sans erreurs et est prêt à être utilisé, et GL_FALSE sinon. Elle peut être interrogée en appelant glGetShader() avec les arguments shader et GL_COMPILE_STATUS.

La compilation d'un shader peut échouer pour un certain nombre de raisons spécifiées par la spécification du langage d'ombrage OpenGL. Que la compilation ait réussi ou non, des informations sur la compilation peuvent être obtenues à partir du journal d'informations de l'objet shader en appelant glGetShaderInfoLog().

ERREURS

GL_INVALID_VALUE est généré si shader n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si shader n'est pas un objet shader.

GETS ASSOCIÉS

glGetShaderInfoLog() avec l'argument shader

glGetShader() avec les arguments shader et GL_COMPILE_STATUS

glIsShader()
