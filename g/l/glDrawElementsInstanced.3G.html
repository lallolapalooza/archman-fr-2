NOM

glDrawElementsInstanced - dessiner plusieurs instances d'un ensemble d'éléments

SPÉCIFICATION C

void glDrawElementsInstanced(GLenum mode, GLsizei count, GLenum type, const void * indices, GLsizei instancecount);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

count

Spécifie le nombre d'éléments à rendre.

type

Spécifie le type des valeurs dans indices. Doit être l'un de GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, ou GL_UNSIGNED_INT.

indices

Spécifie un pointeur vers l'emplacement où les indices sont stockés.

instancecount

Spécifie le nombre d'instances de la plage spécifiée d'indices à rendre.

DESCRIPTION

glDrawElementsInstanced se comporte de manière identique à glDrawElements() sauf que instancecount instances de l'ensemble d'éléments sont exécutées et que la valeur du compteur interne instanceID s'incrémente pour chaque itération. instanceID est un compteur interne de 32 bits qui peut être lu par un shader de vertex en tant que gl_InstanceID.

glDrawElementsInstanced a le même effet que :

    if (mode, count, or type is invalid )
        generate appropriate error
    else {
        for (int i = 0; i < instancecount ; i++) {
            instanceID = i;
            glDrawElements(mode, count, type, indices);
        }
        instanceID = 0;
    }

NOTES

glDrawElementsInstanced est disponible uniquement si la version de GL est 3.1 ou supérieure.

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_TRIANGLES_ADJACENCY sont disponibles uniquement si la version de GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas l'un de GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, ou GL_TRIANGLES.

GL_INVALID_VALUE est généré si count ou instancecount est négatif.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé et que le stockage de données de l'objet tampon est actuellement mappé.
