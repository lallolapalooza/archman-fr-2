NOM

glab-token-rotate - Rotation des jetons d'accès utilisateur, de groupe ou de projet

SYNOPSIS

glab token rotate [options]

DESCRIPTION

Fait pivoter le jeton d'accès utilisateur, de groupe ou de projet, puis affiche le nouveau jeton sur la sortie standard. Si plusieurs jetons du même nom existent, vous pouvez spécifier l'ID du jeton.

La date d'expiration du jeton sera calculée en ajoutant la durée (par défaut 30 jours) à la date actuelle, l'expiration ayant lieu à minuit UTC à la date calculée. Alternativement, vous pouvez spécifier une durée différente en utilisant des jours (d), des semaines (w) ou des heures (h), ou fournir une date de fin explicite.

Le format de sortie peut être « JSON » ou « text ». La sortie JSON montrera les métadonnées du jeton pivoté.

Les administrateurs peuvent faire pivoter les jetons d'accès personnels appartenant à d'autres utilisateurs.

OPTIONS

-D, --duration=30d Définit la durée de vie du jeton en jours. Accepte : jours (30j), semaines (4s), ou heures par multiples de 24 (24h, 168h, 720h). Maximum : 365j. Le jeton expire à minuit UTC à la date calculée.

-E, --expires-at=0001-01-01 Définit la date et l'heure d'expiration du jeton, au format AAAA-MM-JJ. Si non spécifié, --duration est utilisé.

-g, --group="" Fait pivoter le jeton d'accès de groupe. Ignoré si un argument utilisateur ou dépôt est défini.

-F, --output="text" Format de sortie : text, json. 'text' fournit la valeur du nouveau jeton ; 'json' affiche le jeton avec ses métadonnées.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE_NOMMAGE/DÉPÔT. Accepte également une URL complète ou une URL Git.

-U, --user="" Fait pivoter le jeton d'accès personnel. Utilisez @moi pour l'utilisateur actuel.

OPTIONS INHERITED FROM PARENT COMMANDS

-h, --help[=false] Affiche l'aide pour cette commande.

EXEMPLE

# Fait pivoter le jeton d'accès du projet du projet actuel (par défaut 30 jours)
$ glab token rotate mon-jeton-projet
# Fait pivoter le jeton d'accès du projet avec une date d'expiration explicite
$ glab token rotate --repo utilisateur/repo mon-jeton-projet --expires-at 2025-08-08
# Fait pivoter le jeton d'accès de groupe avec une durée de vie de 7 jours
$ glab token rotate --group groupe/sous-groupe mon-jeton-groupe --duration 7d
# Fait pivoter le jeton d'accès personnel avec une durée de vie de 2 semaines
$ glab token rotate --user @moi mon-jeton-personnel --duration 2w
# Fait pivoter le jeton d'accès personnel d'un autre utilisateur (administrateur uniquement)
$ glab token rotate --user johndoe jeton-personnel-de-john --duration 90d
