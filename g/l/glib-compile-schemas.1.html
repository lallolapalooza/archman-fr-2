Nom

glib-compile-schemas - Compilateur de schémas GSettings

SYNOPSIS

glib-compile-schemas [OPTION…] RÉPERTOIRE

DESCRIPTION

glib-compile-schemas compile tous les fichiers de schéma XML GSettings dans RÉPERTOIRE en un fichier binaire nommé gschemas.compiled qui peut être utilisé par GSettings. Les fichiers de schéma XML doivent avoir l'extension de nom de fichier .gschema.xml. Pour une description détaillée du format de fichier XML, consultez la documentation GSettings.

Au moment de l'exécution, GSettings recherche les schémas dans les sous-répertoires glib-2.0/schemas de tous les répertoires spécifiés dans les variables d'environnement XDG_DATA_DIRS et XDG_DATA_HOME. L'emplacement habituel pour installer les fichiers de schéma est /usr/share/glib-2.0/schemas.

En plus des fichiers de schéma, glib-compile-schemas lit les fichiers de ‘remplacement de vendeur’ (vendor override), qui sont des fichiers clés pouvant remplacer les valeurs par défaut pour les clés dans les schémas. Les noms de groupe dans les fichiers clés sont l'identifiant du schéma, et les valeurs sont écrites sous forme de GVariant sérialisé. Les fichiers de remplacement de vendeur doivent avoir l'extension de nom de fichier .gschema.override.

Par convention, les fichiers de remplacement de vendeur commencent par nn_ où nn est un nombre de 00 à 99. Les fichiers avec un nombre plus élevé ont une priorité plus haute (par exemple, si le même remplacement est fait dans un fichier numéroté 10 puis à nouveau dans un fichier numéroté 20, le remplacement de 20 prendra le dessus).

OPTIONS

-h, --help

Affiche l'aide et quitte.

--version

Affiche la version du programme et quitte.

--targetdir <CIBLE>

Stocke gschemas.compiled dans le répertoire CIBLE au lieu de RÉPERTOIRE.

--strict

Arrête en cas d'erreurs dans les schémas. Sans cette option, les fichiers de schéma défectueux sont simplement omis du schéma compilé résultant.

--dry-run

N'écrit pas gschemas.compiled. Cette option peut être utilisée pour vérifier les sources .gschema.xml pour des erreurs.

--allow-any-name

N'applique pas de restrictions sur les noms de clé. Notez que cette option est uniquement destinée à faciliter la transition depuis GConf et sera supprimée à un moment donné dans le futur.
