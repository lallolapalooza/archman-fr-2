DESCRIPTIO

N

glUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgr

am().

Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par ex., 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour les variables uniformes définies en tant que int, ivec2, ivec3, ivec4, ou des tableaux de ceux-ci. Les variantes ui de cette fonction doivent être utilisées pour fournir des valeurs à des variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les variantes f doivent être utilisées pour fournir des valeurs à des variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de ceux-ci. Les variantes i, ui ou f peuvent être utilisées pour fournir des valeurs à des variables uniformes de type bool, bvec2, bvec3, bvec4, ou des tableaux de ceux-ci. La variable uniforme sera définie à false si la valeur d'entrée est 0 ou 0.0f, et elle sera définie à true dans le cas

contraire.

Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. Elles conservent les valeurs qui leur ont été assignées par un appel à glUniform jusqu'à ce que la prochaine opération de liaison réussie se produise sur l'objet programme, auquel moment elles sont à nouveau initialisées à

0.

Les commandes glUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une variable uniforme unique ou un tableau de variables uniformes. Ces commandes passent un compteur et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes. Un compteur de 1 doit être utilisé si l'on modifie la valeur d'une seule variable uniforme, et un compteur de 1 ou supérieur peut être utilisé pour modifier un tableau entier ou une partie d'un tableau. Lors du chargement n éléments à partir d'une position arbitraire m dans un tableau de variables uniformes, les éléments m + n - 1 dans le tableau seront remplacés par les nouvelles valeurs. Si m + n - 1 est plus grand que la taille du tableau de variables uniformes, les valeurs pour tous les éléments du tableau au-delà de la fin du tableau seront ignorées. Le nombre spécifié dans le nom de la commande indique le nombre de composants pour chaque élément dans value, et il doit correspondre au nombre de composants dans le type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, bool ; 2 pour vec2, ivec2, bvec2, etc.). Le type de données spécifié dans le nom de la commande doit correspondre au type de données de la variable uniforme spécifiée comme décrit précédemment pour glUniform{1|2|3|4}

{f|i|ui}.

Pour les tableaux de variables uniformes, chaque élément du tableau est considéré comme étant du type indiqué dans le nom de la commande (par exemple, glUniform3f ou glUniform3fv peuvent être utilisés pour charger un tableau de variables uniformes de type vec3). Le nombre d'éléments du tableau de variables uniformes à modifier est spécifié par coun

t

Les commandes glUniformMatrix{2|3|4|2x3|3x2|2x4|4x2|3x4|4x3}fv sont utilisées pour modifier une matrice ou un tableau de matrices. Les nombres dans le nom de la commande sont interprétés comme la dimensionnalité de la matrice. Le nombre 2 indique une matrice 2 × 2 (c'est-à-dire 4 valeurs), le nombre 3 indique une matrice 3 × 3 (c'est-à-dire 9 valeurs), et le nombre 4 indique une matrice 4 × 4 (c'est-à-dire 16 valeurs). La dimensionnalité des matrices non carrées est explicite, le premier nombre représentant le nombre de colonnes et le second nombre représentant le nombre de lignes. Par exemple, 2x4 indique une matrice 2 × 4 avec 2 colonnes et 4 lignes (c'est-à-dire 8 valeurs). Si transpose est GL_FALSE, chaque matrice est supposée être fournie en ordre colonne majeur. Si transpose est GL_TRUE, chaque matrice est supposée être fournie en ordre ligne majeur. L'argument count indique le nombre de matrices à passer. Un compteur de 1 doit être utilisé si l'on modifie la vale

ur d'une seule matrice, et un compteur supérieur à 1
peut être utilisé pour modifier un tableau de matrices.

NOTE

S

glUniform1i et glUniform1iv sont les deux seules fonctions qui peuvent être utilisées pour charger des variables uniformes définies comme des types sampler. Le chargement de samplers avec toute autre fonction entraînera une erreur GL_INVALID_OPERATION

.

Si count est supérieur à 1 et que la variable uniforme indiquée n'est pas un tableau, une erreur GL_INVALID_OPERATION est générée et la variable uniforme spécifiée restera

inchangée.

En dehors des exceptions précédentes, si le type et la taille de la variable uniforme tels que définis dans le shader ne correspondent pas au type et à la taille spécifiés dans le nom de la commande utilisée pour charger sa valeur, une erreur GL_INVALID_OPERATION sera générée et la variable uniforme spécifiée restera

inchangée.

Si location est une valeur autre que -1 et qu'elle ne représente pas un emplacement de variable uniforme valide dans l'objet programme courant, une erreur sera générée, et aucun changement ne sera apporté au stockage de la variable uniforme de l'objet programme courant. Si location est égal à -1, les données passées seront silencieusement

ignorées et la variable uniforme
spécifiée ne sera pas modifiée.

ERREUR

S

GL_INVALID_OPERATION est généré s'il n'y a pas d'objet programme

courant.

GL_INVALID_OPERATION est généré si la taille de la variable uniforme déclarée dans le shader ne correspond pas à la taille indiquée par la commande glUn

iform.

GL_INVALID_OPERATION est généré si l'une des variantes signées ou non signées de cette fonction est utilisée pour charger une variable uniforme de type float, vec2, vec3, vec4, ou un tableau de ceux-ci, ou si l'une des variantes en virgule flottante de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, unsigned int, uvec2, uvec3, uvec4, ou un tableau de

ceux-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières signées de cette fonction est utilisée pour charger une variable uniforme de type unsigned int, uvec2, uvec3, uvec4, ou un tableau de

ceux-ci.

GL_INVALID_OPERATION est généré si l'une des variantes entières non signées de cette fonction est utilisée pour charger une variable uniforme de type int, ivec2, ivec3, ivec4, ou un tableau de

ceux-ci.

GL_INVALID_OPERATION est généré si location est un emplacement de uniforme invalide pour l'objet programme courant et que location n'est pas égal à

-1.

GL_INVALID_VALUE est généré si count est inférieur à

0.

GL_INVALID_OPERATION est généré si count est supérieur à 1 et que la variable uniforme indiquée n'est pas une variable

tableau.

GL_INVALID_OPERATION est généré si un sampler est chargé à l'aide d'une commande autre que glUniform1i et glUniform1i

v
.

glUniformMatrix2x3fv - Man page

NOM

glUniformMatrix2x3fv - définir les valeurs d'une matrice uniforme de type float à 2 colonnes et 3 lignes.

SPÉCIFICATION C

void glUniformMatrix2x3fv(GLint location,
                         GLsizei count,
                         GLboolean transpose,
                         const GLfloat *value);

PARAMÈTRES

location
Spécifie l'emplacement de la matrice uniforme cible dans le programme.
count
Spécifie le nombre d'éléments uniformes à modifier. Il doit être supérieur ou égal à 1.
transpose
Spécifie si les matrices doivent être transposées. Les valeurs acceptées sont GL_TRUE et GL_FALSE.
value
Pointe vers le premier élément des count matrices à charger dans la matrice uniforme spécifiée par location.

DESCRIPTION

glUniformMatrix2x3fv définit les valeurs d'une ou plusieurs matrices uniformes à 2 colonnes et 3 lignes dans le programme actuel.

Les matrices sont fournies dans un tableau de flottants, dans un ordre de stockage par colonne. Si transpose est GL_TRUE, chaque matrice 2x3 value est transposée avant d'être chargée dans la matrice uniforme.

Si location correspond à une matrice uniforme non unique, alors count matrices seront écrites. Sinon, une seule matrice sera écrite.

Les valeurs spécifiées par value sont des flottants simples. Si le type de données du parametre uniforme est différent, les valeurs seront converties.

NOTES

glUniformMatrix2x3fv est disponible dans les versions de OpenGL à partir de la version 2.0.

Les matrices uniformes sont définies dans un espace de coordonnées. La fonction glUniformMatrix2x3fv peut être utilisée pour définir des matrices telles que des matrices de modélisation, de visualisation et de projection.

ERREURS

  • GL_INVALID_OPERATION est générée si location ne correspond à aucune variable uniforme active dans le programme actuel, ou si location correspond à une variable uniforme non matrice.
  • GL_INVALID_VALUE est générée si count est négatif.
  • GL_INVALID_OPERATION est générée si location correspond à une variable uniforme qui n'est pas du type attendu (matrice à 2x3 flottants).

GETS ASSOCIÉS

glGetUniformfv, glGetActiveUniform, glGetUniformLocation.
