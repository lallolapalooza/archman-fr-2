NOM

gluster-setgfid2path - Outil Gluster pour définir les attributs étendus GFID vers Chemin

SYNTAXE

gluster-setgfid2path fichier

DESCRIPTION

Nouvelle fonctionnalité introduite avec la version 3.12 de Gluster, pour trouver le chemin complet à partir d'un GFID. Cette fonctionnalité peut être activée en utilisant la commande de configuration de volume gluster volume set <VOLUME> storage.gfid2path enable

Une fois la fonctionnalité gfid2path activée, elle commence à enregistrer les attributs étendus nécessaires à la fonctionnalité. Cependant, elle n'ajoutera pas d'attributs étendus aux fichiers déjà existants. Cet outil fournit la possibilité de mettre à jour les attributs étendus gfid2path pour le chemin de fichier donné.

EXEMPLES

Pour ajouter les attributs étendus d'un seul fichier,

gluster-setgfid2path /briques/b1/bonjour.txt

Pour définir les attributs étendus pour tous les fichiers existants, exécutez le script ci-dessous sur chaque brique.

BRIQUE=/briques/b1
find $BRIQUE -type d \( -path "${BRIQUE}/.trashcan" -o -path \
    "${BRIQUE}/.glusterfs" \) -prune -o -type f \
    -exec gluster-setgfid2path {} \;
