glutInitDisplayMode(3)

Paquet: freeglut

Licences: X11

glutInitDisplayMode(3) freeglut glutInitDisplayMode(3)

NOM

glutInitDisplayMode - définit le mode d'affichage initial.

SYNTAXE

void glutInitDisplayMode(unsigned int mode);

ARGUMENTS

mode
Mode d'affichage, normalement le résultat d'un OU logique bit à bit des masques de bits de mode d'affichage GLUT. Voir les valeurs ci-dessous :
GLUT_RGBA
Masque de bits pour sélectionner une fenêtre en mode RGBA. C'est le mode par défaut si ni GLUT_RGBA ni GLUT_INDEX ne sont spécifiés.
GLUT_RGB
Un alias pour GLUT_RGBA.
GLUT_INDEX
Masque de bits pour sélectionner une fenêtre en mode index de couleur. Ceci remplace GLUT_RGBA si celui-ci est également spécifié.
GLUT_SINGLE
Masque de bits pour sélectionner une fenêtre en simple tampon. C'est le mode par défaut si ni GLUT_DOUBLE ni GLUT_SINGLE ne sont spécifiés.
GLUT_DOUBLE
Masque de bits pour sélectionner une fenêtre en double tampon. Ceci remplace GLUT_SINGLE si celui-ci est également spécifié.
GLUT_ACCUM
Masque de bits pour demander une fenêtre avec un tampon d'accumulation.
GLUT_ALPHA
Masque de bits pour demander une fenêtre avec une composante alpha dans le(s) tampon(s) de couleur.
GLUT_DEPTH
Masque de bits pour demander une fenêtre avec un tampon de profondeur.
GLUT_STENCIL
Masque de bits pour demander une fenêtre avec un tampon de stencil.
GLUT_MULTISAMPLE
Masque de bits pour demander une fenêtre avec prise en charge du multisampling. Si le multisampling n'est pas disponible, une fenêtre sans multisampling sera automatiquement choisie. Note : l'implémentation côté client et côté serveur d'OpenGL doit prendre en charge l'extension GLX_SAMPLE_SGIS pour que le multisampling soit disponible.
GLUT_STEREO
Masque de bits pour sélectionner une fenêtre stéréo.
GLUT_LUMINANCE
Masque de bits pour sélectionner une fenêtre avec un modèle de couleur "luminance". Ce modèle fournit la fonctionnalité du modèle de couleur RGBA d'OpenGL, mais les composantes verte et bleue ne sont pas conservées dans le tampon d'image. Au lieu de cela, la composante rouge de chaque pixel est convertie en un index compris entre zéro et glutGet(GLUT_WINDOW_COLORMAP_SIZE)-1 et recherchée dans une carte de couleurs par fenêtre pour déterminer la couleur des pixels dans la fenêtre. La carte de couleurs initiale des fenêtres GLUT_LUMINANCE est initialisée avec une rampe de gris linéaire, mais peut être modifiée avec les routines de carte de couleurs de GLUT.

DESCRIPTION

Le mode d'affichage initial est utilisé lors de la création de fenêtres de premier niveau, de sous-fenêtres et de superpositions pour déterminer le mode d'affichage OpenGL de la fenêtre ou de la superposition à créer.

Notez que GLUT_RGBA sélectionne le modèle de couleur RGBA, mais ne demande pas l'allocation de bits alpha (parfois appelés tampon alpha ou alpha de destination). Pour demander de l'alpha, spécifiez GLUT_ALPHA. Il en va de même pour GLUT_LUMINANCE.

Notez que certains bits "demandent" une capacité et d'autres bits "sélectionnent" une capacité. Une capacité demandée peut être attribuée à la fenêtre créée même si le bit de la capacité n'a pas été défini. Par exemple, GLUT peut créer une fenêtre avec un tampon de profondeur même si GLUT_DEPTH n'est pas spécifié.

La routine glutInitDisplayString offre un moyen plus puissant de sélectionner les capacités du tampon d'image pour les fenêtres GLUT.

NOTES D'IMPLÉMENTATION GLUT_LUMINANCE

GLUT_LUMINANCE n'est pas pris en charge sur la plupart des plateformes OpenGL.

VOIR AUSSI

glutInit, glutCreateWindow, glutInitDisplayString
