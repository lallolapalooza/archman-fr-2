NOM

glutMouseFunc - définit la fonction de rappel de la souris pour la fenêtre actuelle.

SYNTAXE

void glutMouseFunc(void (*func)(int button, int state,
                   int x, int y));

ARGUMENTS

func
La nouvelle fonction de rappel de la souris.

DESCRIPTION

glutMouseFunc définit la fonction de rappel de la souris pour la fenêtre actuelle. Lorsqu'un utilisateur appuie et relâche les boutons de la souris dans la fenêtre, chaque pression et chaque relâchement génère un rappel de souris. Le paramètre button est l'un des GLUT_LEFT_BUTTON, GLUT_MIDDLE_BUTTON, ou GLUT_RIGHT_BUTTON. Pour les systèmes avec seulement deux boutons de souris, il peut ne pas être possible de générer un rappel GLUT_MIDDLE_BUTTON. Pour les systèmes avec un seul bouton de souris, il peut être possible de générer seulement un rappel GLUT_LEFT_BUTTON. Le paramètre state est soit GLUT_UP, soit GLUT_DOWN, indiquant si le rappel a été déclenché par un relâchement ou une pression respectivement. Les paramètres de coordonnées x et y du rappel indiquent les coordonnées relatives à la fenêtre au moment où l'état du bouton de la souris a changé. Si un rappel GLUT_DOWN pour un bouton spécifique est déclenché, le programme peut supposer qu'un rappel GLUT_UP pour le même bouton sera généré (en supposant que la fenêtre a toujours une fonction de rappel de souris enregistrée) lorsque le bouton de la souris sera relâché, même si la souris a quitté la fenêtre.

Si un menu est attaché à un bouton pour une fenêtre, les rappels de souris ne seront pas générés pour ce bouton.

Pendant un rappel de souris, glutGetModifiers peut être appelé pour déterminer l'état des touches modificatrices lorsque l'événement de souris générant le rappel s'est produit.

Passer NULL à glutMouseFunc désactive la génération des rappels de souris.
