NAME

glTexStorage2D, glTextureStorage2D - specify the storage for a 2D texture.

C SPECIFICATION

    void glTexStorage2D(GLenum target,
                        GLint levels,
                        GLenum internalformat,
                        GLsizei width,
                        GLsizei height);

    void glTextureStorage2D(GLuint texture,
                            GLint levels,
                            GLenum internalformat,
                            GLsizei width,
                            GLsizei height);

PARAMETERS

target
Specifies the target texture. Must be GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP, GL_TEXTURE_2D_ARRAY, or the appropriate proxy targets: GL_PROXY_TEXTURE_2D, GL_PROXY_TEXTURE_CUBE_MAP, GL_PROXY_TEXTURE_2D_ARRAY.
texture
The name of a texture object.
levels
The number of texture levels (i.e. mipmaps) or layers in the texture array.
internalformat
Specifies the internal format of the texture. See Table 2.
width
Specifies the width of the texture.
height
Specifies the height of the texture.

DESCRIPTION

glTexStorage2D and glTextureStorage2D specify the complete, fixed-format storage requirements for all the layers and mipmap levels of a specified texture object.

Once the storage for a texture object is specified using glTexStorage2D or glTextureStorage2D, the dimensions, internal format, and number of layers of the texture object cannot be modified. This means that the texture object becomes immutable, and immutable textures can only be updated using commands such as glCopyBufferSubData, glCopyTexSubImage2D, glCopyTextureSubImage2D, and fragment shader texture fetches.

The target parameter specifies whether the texture is a standard 2D texture, a cubemap texture, or a texture array.

The levels parameter specifies the number of mipmap levels to be used for the texture. For GL_TEXTURE_2D and GL_TEXTURE_CUBE_MAP, this is the number of mipmaps. For GL_TEXTURE_2D_ARRAY, this specifies the number of layers in the texture array.

The internalformat parameter specifies the data format that the GL will use to store the texture. This parameter must be a sized internal format, meaning it must specify both the data type and the precision or size. Table 2 lists the valid sized internal formats.

The width and height parameters specify the dimensions of the base level (level 0) of the texture. They must be greater than or equal to 1.

If target is GL_TEXTURE_2D or GL_PROXY_TEXTURE_2D, then levels must be less than or equal to log 2(max(width, height)) + 1.

If target is GL_TEXTURE_2D_ARRAY or GL_PROXY_TEXTURE_2D_ARRAY, then levels must be less than or equal to log 2(width) + 1.

If target is GL_TEXTURE_CUBE_MAP or GL_PROXY_TEXTURE_CUBE_MAP, then width and height must be equal. The number of levels must be less than or equal to log 2(width) + 1.

Proxy targets are used to test the feasibility of a requested texture format, size, and number of levels. The GL will not perform any texture storage or manipulation, but it will perform all the parameter checking described below, and the results of the parameter checking will be reflected in the values returned by glGetTexParameter.

The proxy texture targets are only useful when querying texture properties using glGetTexLevelParameter. glTexStorage2D and glTextureStorage2D, when used with proxy targets, will return values for texture properties that indicate whether the requested texture would be supported by the GL.

Once storage has been allocated using glTexStorage2D or glTextureStorage2D, the texture object is considered immutable. Calls to glTexImage2D with the same target will fail with GL_INVALID_OPERATION.

glTexStorage2D operates on the currently bound texture object. glTextureStorage2D operates on a specified texture object. The latter is preferred since it avoids the need to bind the texture object first.

NOTES

GL_STENCIL_INDEX8
is accepted for internalformat only if the GL version is 4.4 or higher.

ERRORS

GL_INVALID_OPERATION is generated by glTexStorage2D if zero is bound to target.

GL_INVALID_OPERATION is generated by glTextureStorage2D if texture is not the name of an existing texture object.

GL_INVALID_ENUM is generated if internalformat is not a valid sized internal format.

GL_INVALID_ENUM is generated if target or the effective target of texture is not one of the accepted targets described above.

GL_INVALID_VALUE is generated if width, height or levels are less than 1.

GL_INVALID_OPERATION is generated if target is GL_TEXTURE_1D_ARRAY or GL_PROXY_TEXTURE_1D_ARRAY and levels is greater than log 2 width + 1.

GL_INVALID_OPERATION is generated if target is not GL_TEXTURE_1D_ARRAY or GL_PROXY_TEXTURE_1D_ARRAY and levels is greater than log 2 max width ,   height + 1.
