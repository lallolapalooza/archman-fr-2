NOM

gl_FragDepth - établit une valeur de profondeur pour le fragment actuel

DÉCLARATION

out float gl_FragDepth ;.SH "DESCRIPTION"

Disponible uniquement dans le langage de fragment, gl_FragDepth est une variable de sortie utilisée pour établir la valeur de profondeur du fragment actuel. Si le tampon de profondeur est activé et qu'aucun shader n'écrit dans gl_FragDepth, la valeur de fonction fixe pour la profondeur sera utilisée (cette valeur est contenue dans la composante z de gl_FragCoord()) ; sinon, la valeur écrite dans gl_FragDepth est utilisée. Si un shader écrit statiquement dans gl_FragDepth, alors la valeur de la profondeur du fragment peut être indéfinie pour les exécutions du shader qui ne suivent pas ce chemin. C'est-à-dire, si l'ensemble des shaders de fragment liés contient statiquement une écriture dans gl_FragDepth, alors il est de sa responsabilité de toujours l'écrire.
