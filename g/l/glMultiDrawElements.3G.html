NOM

glMultiDrawElements - dessine plusieurs ensembles de primitives en spécifiant les indices des éléments de données tableau

SPÉCIFICATION C

void glMultiDrawElements(GLenum mode, const GLsizei * count, GLenum type, const void * const * indices, GLsizei drawcount);

PARAMÈTRES

mode

Spécifie le type de primitives à dessiner. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

count

Pointe vers un tableau des décomptes d'éléments.

type

Spécifie le type des valeurs dans indices. Doit être l'une des valeurs GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, ou GL_UNSIGNED_INT.

indices

Pointe vers l'emplacement où les indices sont stockés.

drawcount

Spécifie la taille des tableaux count et indices.

DESCRIPTION

glMultiDrawElements spécifie plusieurs ensembles de primitives géométriques avec très peu d'appels de sous-routines. Au lieu d'appeler une fonction GL pour passer chaque sommet, normale, coordonnée de texture, drapeau de bord, ou couleur individuel, vous pouvez pré-spécifier des tableaux séparés de sommets, normales, etc., et les utiliser pour construire une séquence de primitives avec un seul appel à glMultiDrawElements.

glMultiDrawElements est identique en opération à glDrawElements() à ceci près que drawcount listes séparées d'éléments sont spécifiées.

Les attributs de sommet qui sont modifiés par glMultiDrawElements ont une valeur indéterminée après le retour de glMultiDrawElements. Les attributs qui ne sont pas modifiés conservent leurs valeurs précédentes.

NOTES

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_TRIANGLES_ADJACENCY ne sont disponibles que si la version de GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si drawcount est négatif.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé ou au tableau d'éléments et que le magasin de données de l'objet tampon est actuellement mappé.
