DESCRIPTIO

N

Le mode transform feedback capture les valeurs des variables varying écrites par le vertex shader (ou, s'il est actif, le geometry shader). Le transform feedback est dit actif après un appel à glBeginTransformFeedback jusqu'à un appel ultérieur

à

glEndTransformFeedback. Les commandes de transform feedback doivent être

appariées.

Si aucun geometry shader n'est présent, alors que le transform feedback est actif, le paramètre mode de glDrawArrays() doit correspondre à ceux spécifiés dans le tableau suivant

S

Les geometry shaders, ainsi que les GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY, GL_LINES_ADJACENCY et GL_LINE_STRIP_ADJACENCY modes de primitives ne sont dispo

ERREU

R

GL_INVALID_OPERATION est généré si glBeginTransformFeedback est exécuté alors que le transform feedback est

actif.

GL_INVALID_OPERATION est généré si glEndTransformFeedback est exécuté alors que le transform feedback n'est pas

actif.

GL_INVALID_OPERATION est généré par glDrawArrays() si aucun geometry shader n'est présent, que le transform feedback est actif et mode n'est pas l'un des modes

autorisés.

GL_INVALID_OPERATION est généré par glDrawArrays() si un geometry shader est présent, que le transform feedback est actif et que le type de primitive de sortie du geometry shader ne correspond pas au primitiveMod

e

GL_INVALID_OPERATION est généré par glBeginTransformFeedback si un point de liaison utilisé en mode transform feedback n'a pas d'objet tampon

lié.

GL_INVALID_OPERATION est généré par glBeginTransformFeedback si aucun point de liaison ne serait utilisé, soit parce qu'aucun objet programm

e n'est actif, soit parce que l'objet programme actif n
'a spécifié aucune variable varying à enregistrer.
