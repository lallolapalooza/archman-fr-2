Lorsqu'un objet tampon est attaché à une texture tampon, le magasin de données de l'objet tampon est considéré comme le tableau de texels de la texture. Le nombre de texels dans le tableau de texels de la texture tampon est donné par $$ \left\lfloor { size \over { components \times sizeof(base\_type) } } \right\rfloor $$ où $size$ est la taille de l'objet tampon en unités machine de base ( la valeur de GL_BUFFER_SIZE pour buffer), et $components$ et $base\_type$ sont le nombre d'éléments et le type de données de base pour les éléments, comme spécifié dans le tableau ci-dessus. Le nombre de texels dans le tableau de texels est ensuite limité à la valeur de la limite dépendant de l'implémentation GL_MAX_TEXTURE_BUFFER_SIZE. Lorsqu'une texture tampon est accédée dans un shader, les résultats d'une récupération de texel sont indéfinis si la coordonnée de texel spécifiée est négative, ou supérieure ou égale au nombre limité de texels dans le tableau de texels.

ERREURS

GL_INVALID_ENUM est généré par glTexBuffer si target n'est pas GL_TEXTURE_BUFFER.

GL_INVALID_OPERATION est généré par glTextureBuffer si texture n'est pas le nom d'un objet texture existant.

GL_INVALID_ENUM est généré par glTextureBuffer si la cible effective de texture n'est pas GL_TEXTURE_BUFFER.

GL_INVALID_ENUM est généré si internalformat n'est pas l'un des formats internes dimensionnés décrits ci-dessus.

GL_INVALID_OPERATION est généré si buffer n'est pas zéro et n'est pas le nom d'un objet tampon existant.

REQUÊTES ASSOCIÉES

glGet() avec l'argument GL_MAX_TEXTURE_BUFFER_SIZE

glGet() avec l'argument GL_TEXTURE_BINDING_BUFFER

glGetTexLevelParameter() avec l'argument GL_TEXTURE_BUFFER_DATA_STORE_BINDING
