NOM

glmark2-drm - Suite de banc d'essai OpenGL (ES) 2.0

SYNTAXE

glmark2-drm [options]

DESCRIPTION

glmark2-drm est un banc d'essai pour OpenGL (ES) 2.0. Il utilise uniquement le sous-ensemble de l'API OpenGL 2.0 compatible avec OpenGL ES 2.0.

OPTIONS

-b, --benchmark BENCH
Un banc d'essai à exécuter : 'scene(:opt1=val1)*' (l'option peut être utilisée plusieurs fois)
-f, --benchmark-file FICHIER
Charge les bancs d'essai à exécuter à partir d'un fichier contenant une liste de descriptions de bancs d'essai (une par ligne) (l'option peut être utilisée plusieurs fois)
--validate
Exécute un test rapide de validation de sortie au lieu d'exécuter les bancs d'essai
--data-path CHEMIN
Chemin vers les modèles, shaders et textures de glmark2
--frame-end METHODE
Comment terminer une image [default,none,swap,finish,readpixels]
--swap-mode MODE
Comment échanger une image, tous les modes sont pris en charge uniquement dans la version DRM, 'fifo' est disponible dans toutes les versions pour forcer la synchronisation verticale [default,immediate,mailbox,fifo]
--off-screen
Rendu sur une surface hors écran
--visual-config
La configuration visuelle à utiliser pour la cible de rendu : ´id=ID:red=R:green=G:blue=B:alpha=A:buffer=BUF:stencil=STENCIL:samples=SAMPLES'. Les paramètres peuvent être définis dans n'importe quel ordre, et les paramètres omis supposent une valeur par défaut de '0' (id, stencil, samples) ou '1' (red, green, blue, alpha, buffer). Si 'id' est défini sur une valeur non nulle, tous les autres paramètres sont ignorés
--reuse-context
Utilise un seul contexte pour toutes les scènes (par défaut, chaque scène obtient son propre contexte)
-s, --size LxH
Taille de la fenêtre de sortie (par défaut : 800x600)
--fullscreen
Exécute en mode plein écran (équivalent à --size -1x-1)
--results RESULTATS
Les types de résultats à rapporter pour chaque banc d'essai, sous forme de liste séparée par ':' [fps,cpu,shader]
--results-file FICHIER-RESULTATS
Le fichier où enregistrer les résultats, dans le format déterminé par l'extension du fichier [csv,xml]
--winsys-options OPTS
Une liste de paires 'opt=valeur' pour les options spécifiques au système de fenêtrage, séparées par ':'
-l, --list-scenes
Affiche des informations sur les scènes disponibles et leurs options
--show-all-options
Affiche toutes les valeurs d'options de scène utilisées pour les bancs d'essai (seules les options explicitement définies sont affichées par défaut)
--run-forever
Exécute indéfiniment, bouclant du dernier banc d'essai au premier
--annotate
Annote les bancs d'essai avec des informations à l'écran (identique à -b :show-fps=true:title=#info#)
-d, --debug
Affiche les messages de débogage
--version
Affiche la version du programme
-h, --help
Affiche l'aide

BANCS D'ESSAI

glmark2-drm propose une suite de scènes qui peuvent être utilisées pour mesurer de nombreux aspects des performances d'OpenGL (ES) 2.0. La façon dont chaque scène est rendue est configurable via un ensemble d'options. Pour obtenir les scènes disponibles et leurs options acceptables, vous pouvez utiliser l'option de ligne de commande -l, --list-scenes.

Dans glmark2-drm, un banc d'essai est défini comme une scène plus un ensemble de valeurs d'options. Vous pouvez spécifier la liste et l'ordre des bancs d'essai à exécuter en utilisant l'option de ligne de commande -b, --benchmark (éventuellement plusieurs fois). Si aucun banc d'essai n'est spécifié, un ensemble par défaut de bancs d'essai est utilisé. Si une option de banc d'essai n'est pas spécifiée, elle prend sa valeur par défaut (listée avec -l, --list-scenes).

À titre de cas spécial, une chaîne de description de banc d'essai est autorisée à ne pas contenir de nom de scène (c'est-à-dire à commencer par ':'). Dans ce cas, les valeurs d'options spécifiées sont utilisées comme valeurs par défaut pour les bancs d'essai qui suivent cette chaîne de description.

EXEMPLES

Pour exécuter les bancs d'essai par défaut :

glmark2-drm

Pour exécuter un banc d'essai en utilisant la scène 'shading' avec une 'duration' de '5.0' secondes et
'shading' de type 'phong' :

glmark2-drm -b shading:duration=5.0:shading=phong

Pour exécuter une série de bancs d'essai, utilisez l'option de ligne de commande -b, --benchmark plusieurs fois :

glmark2-drm -b shading:duration=5.0 -b build:use-vbo=false -b texture

Pour définir les valeurs d'options par défaut pour les bancs d'essai :

glmark2-drm -b :duration=2.0 -b shading -b build -b :duration=5.0 -b texture
