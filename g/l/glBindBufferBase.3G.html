NOM

glBindBufferBase - lier un objet tampon à une cible de tampon indexée

SPÉCIFICATION C

void glBindBufferBase(GLenum target, GLuint index, GLuint buffer);

PARAMÈTRES

target

Spécifie la cible de l'opération de liaison. target doit être l'un de GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER ou GL_SHADER_STORAGE_BUFFER.

index

Spécifie l'index du point de liaison dans le tableau spécifié par target.

buffer

Le nom d'un objet tampon à lier au point de liaison spécifié.

DESCRIPTION

glBindBufferBase lie l'objet tampon buffer au point de liaison à l'index index du tableau de cibles spécifié par target. Chaque target représente un tableau indexé de points de liaison de tampon, ainsi qu'un point de liaison général unique qui peut être utilisé par d'autres fonctions de manipulation de tampons telles que glBindBuffer() ou glMapBuffer(). En plus de lier buffer à la cible de liaison de tampon indexée, glBindBufferBase lie également buffer au point de liaison de tampon générique spécifié par target.

NOTES

Appeler glBindBufferBase est équivalent à appeler glBindBufferRange() avec offset à zéro et size égal à la taille du tampon.

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version GL est 4.2 ou supérieure.

La cible GL_SHADER_STORAGE_BUFFER n'est disponible que si la version GL est 4.3 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si target n'est pas GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER ou GL_SHADER_STORAGE_BUFFER.

GL_INVALID_VALUE est généré si index est supérieur ou égal au nombre de points de liaison indexés spécifiques à target.

GL_INVALID_VALUE est généré si buffer n'a pas de magasin de données associé, ou si la taille de ce magasin est nulle.
