NOM

glTexBufferRange, glTextureBufferRange - attacher une plage de la mémoire d'un objet tampon à un objet texture tampon

SPÉCIFICATION

void glTexBufferRange(GLenum target, GLenum internalformat, GLuint buffer, GLintptr offset, GLsizeiptr size);

void glTextureBufferRange(GLuint texture, GLenum internalformat, GLuint buffer, GLintptr offset, GLsizei size);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet texture est lié pour glTexBufferRange. Doit être GL_TEXTURE_BUFFER.

texture

Spécifie le nom de l'objet texture pour glTextureBufferRange.

internalformat

Spécifie le format interne des données dans la mémoire appartenant à buffer.

buffer

Spécifie le nom de l'objet tampon dont la mémoire doit être attachée à la texture tampon active.

offset

Spécifie le décalage du début de la plage de la mémoire du tampon à attacher.

size

Spécifie la taille de la plage de la mémoire du tampon à attacher.

DESCRIPTION

glTexBufferRange et glTextureBufferRange attachent une plage de la mémoire d'un objet tampon spécifié à un objet texture spécifié, et spécifient le format de stockage pour l'image texture trouvée dans l'objet tampon. L'objet texture doit être une texture tampon.

Si buffer est zéro, tout objet tampon attaché à la texture tampon est détaché et aucun nouvel objet tampon n'est attaché. Si buffer n'est pas zéro, il doit être le nom d'un objet tampon existant.

Le début et la taille de la plage sont spécifiés respectivement par offset et size, tous deux mesurés en unités machine de base. offset doit être supérieur ou égal à zéro, size doit être supérieur à zéro, et la somme de offset et size ne doit pas dépasser la valeur de GL_BUFFER_SIZE pour buffer. De plus, offset doit être un multiple entier de la valeur de GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT.

internalformat spécifie le format de stockage, et doit être l'un des formats internes dimensionnés suivants :

Lorsqu'une plage d'un objet tampon est attachée à une texture tampon, la plage spécifiée du magasin de données de l'objet tampon est prise comme le tableau de texels de la texture. Le nombre de texels dans le tableau de texels de la texture tampon est donné par $$ \left\lfloor { size \over { components \times sizeof(base\_type) } } \right\rfloor $$ où $components$ et $base\_type$ sont le nombre d'éléments et le type de données de base pour les éléments, comme spécifié dans le tableau ci-dessus. Le nombre de texels dans le tableau de texels est ensuite limité à la valeur de la limite dépendant de l'implémentation GL_MAX_TEXTURE_BUFFER_SIZE. Lorsqu'une texture tampon est accédée dans un shader, les résultats d'une récupération de texel sont indéfinis si la coordonnée de texel spécifiée est négative, ou supérieure ou égale au nombre limité de texels dans le tableau de texels.

ERREURS

GL_INVALID_ENUM est généré par glTexBufferRange si target n'est pas GL_TEXTURE_BUFFER.

GL_INVALID_OPERATION est généré par glTextureBufferRange si texture n'est pas le nom d'un objet texture existant.

GL_INVALID_ENUM est généré par glTextureBufferRange si la cible effective de texture n'est pas GL_TEXTURE_BUFFER.

GL_INVALID_ENUM est généré si internalformat n'est pas l'un des formats internes dimensionnés décrits ci-dessus.

GL_INVALID_OPERATION est généré si buffer n'est pas zéro et n'est pas le nom d'un objet tampon existant.

GL_INVALID_VALUE est généré si offset est négatif, si size est inférieur ou égal à zéro, ou si offset + size est supérieur à la valeur de GL_BUFFER_SIZE pour buffer.

GL_INVALID_VALUE est généré si offset n'est pas un multiple entier de la valeur de GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT.

INTERROGATIONS ASSOCIÉES

glGet() avec l'argument GL_TEXTURE_BUFFER_OFFSET_ALIGNMENT

glGetTexLevelParameter() avec les arguments GL_TEXTURE_BUFFER_OFFSET ou GL_TEXTURE_BUFFER_SIZE.
