GLGENERATEMIPMAP(3G) [FIXME: manuel] GLGENERATEMIPMAP(3G)

NOM

glGenerateMipmap, glGenerateTextureMipmap - générer des mipmaps pour un objet texture spécifié

SPÉCIFICATION C

void glGenerateMipmap(GLenum target);

void glGenerateTextureMipmap(GLuint texture);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet texture est lié pour glGenerateMipmap. Doit être l'une des valeurs parmi GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP, ou GL_TEXTURE_CUBE_MAP_ARRAY.

texture

Spécifie le nom de l'objet texture pour glGenerateTextureMipmap.

DESCRIPTION

glGenerateMipmap et glGenerateTextureMipmap génèrent des mipmaps pour l'objet texture spécifié. Pour glGenerateMipmap, l'objet texture est celui lié à target. Pour glGenerateTextureMipmap, texture est le nom de l'objet texture.

Pour les textures de type cube map et cube map array, l'objet texture doit être complet en cube map ou complet en cube map array respectivement.

La génération de mipmaps remplace les niveaux d'image de texel $level_{base} + 1$ jusqu'à $q$ par des images dérivées de l'image $level_{base}$, indépendamment de leur contenu précédent. Toutes les autres images mipmap, y compris l'image $level_{base}$, ne sont pas modifiées par ce calcul.

Les formats internes des images mipmap dérivées correspondent tous à ceux de l'image $level_{base}$. Le contenu des images dérivées est calculé par une réduction répétée et filtrée de l'image $level_{base}$. Pour les textures array unidimensionnelles et bidimensionnelles, ainsi que pour les textures cube map array, chaque couche est filtrée indépendamment.

NOTES

Les textures cube map array ne sont acceptées que si la version de GL est 4.0 ou supérieure.

ERREURS

GL_INVALID_ENUM est générée par glGenerateMipmap si target n'est pas l'une des cibles de texture acceptées.

GL_INVALID_OPERATION est générée par glGenerateTextureMipmap si texture n'est pas le nom d'un objet texture existant.

GL_INVALID_OPERATION est générée si target est GL_TEXTURE_CUBE_MAP ou GL_TEXTURE_CUBE_MAP_ARRAY, et si l'objet texture spécifié n'est pas complet en cube map ou complet en cube map array, respectivement.
