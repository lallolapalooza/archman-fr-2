NOM

glab-incident-list - Lister les incidents d'un projet.

SYNTAXE

glab incident list [indicateurs]

DESCRIPTION

Lister les incidents d'un projet.

OPTIONS

-A, --all[=false] Obtenir tous les incidents.

-a, --assignee="" Filtrer les incidents par assigné .

--author="" Filtrer les incidents par auteur .

-c, --closed[=false] Obtenir seulement les incidents fermés.

-C, --confidential[=false] Filtrer par incidents confidentiels.

-e, --epic=0 Lister les tickets appartenant à une épique donnée (nécessite --group, pas de support de pagination).

-g, --group="" Sélectionner un groupe ou sous-groupe. Ignoré si un argument de dépôt est défini.

--in="title,description" Rechercher dans : titre, description.

-l, --label=[] Filtrer les incidents par libellé . Plusieurs libellés peuvent être séparés par des virgules ou spécifiés en répétant l'indicateur.

-m, --milestone="" Filtrer les incidents par jalon .

--not-assignee="" Filtrer les incidents par non-assigné à .

--not-author="" Filtrer les incidents par non-auteur(s) .

--not-label=[] Filtrer les incidents par absence de libellé . Plusieurs libellés peuvent être séparés par des virgules ou spécifiés en répétant l'indicateur.

--order="created_at" Ordonner les incidents par . Options d'ordre : created_at, updated_at, priority, due_date, relative_position, label_priority, milestone_due, popularity, weight.

-O, --output="text" Options : 'text' ou 'json'.

-F, --output-format="details" Options : 'details', 'ids', 'urls'.

-p, --page=1 Numéro de page.

-P, --per-page=30 Nombre d'éléments à lister par page.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

--search="" Rechercher dans les champs définis par '--in'.

--sort="desc" Retourner les incidents triés par ordre ascendant ou descendant.

OPTIONS INHERIT DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab incident list --all
$ glab incident ls --all
$ glab incident list --assignee=@me
$ glab incident list --milestone release-2.0.0 --opened
