NOM

glCopyTexImage2D - copie des pixels dans une image de texture 2D

SPÉCIFICATION C

void glCopyTexImage2D(GLenumtarget, GLintlevel, GLenuminternalformat, GLintx, GLinty, GLsizeiwidth, GLsizeiheight, GLintborder);

PARAMÈTRES

target

Spécifie la texture cible. Doit être GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, ou GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

level

Spécifie le numéro de niveau de détail. Le niveau 0 est le niveau de l'image de base. Le niveau n est la nième image de réduction de mipmap.

internalformat

Spécifie le format interne de la texture. Doit être l'une des constantes symboliques suivantes : GL_COMPRESSED_RED, GL_COMPRESSED_RG, GL_COMPRESSED_RGB, GL_COMPRESSED_RGBA. GL_COMPRESSED_SRGB, GL_COMPRESSED_SRGB_ALPHA. GL_DEPTH_COMPONENT, GL_DEPTH_COMPONENT16, GL_DEPTH_COMPONENT24, GL_DEPTH_COMPONENT32, GL_STENCIL_INDEX8, GL_RED, GL_RG, GL_RGB, GL_R3_G3_B2, GL_RGB4, GL_RGB5, GL_RGB8, GL_RGB10, GL_RGB12, GL_RGB16, GL_RGBA, GL_RGBA2, GL_RGBA4, GL_RGB5_A1, GL_RGBA8, GL_RGB10_A2, GL_RGBA12, GL_RGBA16, GL_SRGB, GL_SRGB8, GL_SRGB_ALPHA, ou GL_SRGB8_ALPHA8.

x, y

Spécifient les coordonnées de fenêtre du coin inférieur gauche de la région rectangulaire de pixels à copier.

width

Spécifie la largeur de l'image de texture.

height

Spécifie la hauteur de l'image de texture.

border

Doit être 0.

DESCRIPTION

glCopyTexImage2D définit une image de texture bidimensionnelle, ou une image de texture de cube-map avec des pixels provenant du GL_READ_BUFFERcourant.

Le rectangle de pixels aligné sur l'écran dont le coin inférieur gauche se trouve en (x, y) et dont la largeur est width et la hauteur est height définit le tableau de texture au niveau de mipmap spécifié par level. internalformat spécifie le format interne du tableau de texture.

Les pixels du rectangle sont traités exactement comme si glReadPixels() avait été appelé, mais le processus s'arrête juste avant la conversion finale. À ce stade, toutes les valeurs de composantes de pixel sont limitées à l'intervalle 0 1 puis converties vers le format interne de la texture pour être stockées dans le tableau de texels.

L'ordre des pixels est tel que les coordonnées x et y de l'écran plus faibles correspondent aux coordonnées de texture s et t plus faibles.

Si l'un des pixels à l'intérieur du rectangle spécifié du GL_READ_BUFFER courant se trouve en dehors de la fenêtre associée au contexte de rendu courant, alors les valeurs obtenues pour ces pixels sont indéfinies.

Lorsque internalformat est de l'un des types sRGB, le GL ne convertit pas automatiquement les pixels sources vers l'espace colorimétrique sRGB. Dans ce cas, la fonction glPixelMap peut être utilisée pour effectuer la conversion.

REMARQUES

1, 2, 3 et 4 ne sont pas des valeurs acceptées pour internalformat.

Une image avec une hauteur ou une largeur de 0 indique une texture NULL.

GL_STENCIL_INDEX8 est accepté pour internalformat uniquement si la version du GL est 4.4 ou supérieure.

ERREUR

GL_INVALID_ENUM est généré si target n'est pas GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, ou GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

GL_INVALID_VALUE est généré si level est inférieur à 0.

GL_INVALID_VALUE peut être généré si level est supérieur à log 2 ⁢ max, où max est la valeur renvoyée par GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE est généré si width est inférieur à 0 ou supérieur à GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE est généré si border n'est pas 0.

GL_INVALID_VALUE est généré si internalformat n'est pas un format accepté.

GL_INVALID_OPERATION est généré si internalformat est GL_DEPTH_COMPONENT, GL_DEPTH_COMPONENT16, GL_DEPTH_COMPONENT24, ou GL_DEPTH_COMPONENT32 et qu'il n'y a pas de tampon de profondeur.
