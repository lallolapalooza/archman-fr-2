NOM

glutReportErrors - à des fins de débogage ; affiche les erreurs d'exécution OpenGL.

SYNTAXE

void glutReportErrors(void);

DESCRIPTION

Cette routine affiche toutes les erreurs d'exécution OpenGL en attente et efface les erreurs. Cette routine ne devrait généralement être utilisée qu'à des fins de débogage car son appel ralentira les programmes OpenGL. Elle est fournie par commodité ; tout ce que fait la routine est d'appeler glGetError jusqu'à ce qu'aucune erreur ne soit signalée. Toutes les erreurs détectées sont signalées avec un avertissement GLUT et le message texte correspondant généré par gluErrorString.

Appeler glutReportErrors à plusieurs reprises dans votre programme peut aider à isoler les erreurs OpenGL à la commande OpenGL fautive. N'oubliez pas que vous pouvez utiliser l'option -gldebug pour détecter les erreurs OpenGL dans n'importe quel programme GLUT.

VOIR AUSSI

glutInit, glutCreateWindow, glutInitDisplayMode, gluErrorString, glGetError
