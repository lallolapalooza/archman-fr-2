GLDRAWBUFFER(3G) [FIXME: manuel] GLDRAWBUFFER(3G)

NOM

glDrawBuffer, glNamedFramebufferDrawBuffer - spécifier quels tampons de couleur doivent être utilisés pour l'écriture

SPÉCIFICATION C

void glDrawBuffer(GLenum buf);

void glNamedFramebufferDrawBuffer(GLuint framebuffer, GLenum buf);

PARAMÈTRES

framebuffer

Spécifie le nom de l'objet framebuffer pour la fonction glNamedFramebufferDrawBuffer. Doit être zéro ou le nom d'un objet framebuffer existant.

buf

Pour le framebuffer par défaut, l'argument spécifie jusqu'à quatre tampons de couleur dans lesquels écrire. Les constantes symboliques GL_NONE, GL_FRONT_LEFT, GL_FRONT_RIGHT, GL_BACK_LEFT, GL_BACK_RIGHT, GL_FRONT, GL_BACK, GL_LEFT, GL_RIGHT, et GL_FRONT_AND_BACK sont acceptées. La valeur initiale est GL_FRONT pour les contextes à tampon unique, et GL_BACK pour les contextes à double tampon. Pour les objets framebuffer, les énumérations GL_COLOR_ATTACHMENT$m$ et GL_NONE sont acceptées, où $m$ est une valeur comprise entre 0 et GL_MAX_COLOR_ATTACHMENTS.

DESCRIPTION

Lorsque des couleurs sont écrites dans le tampon de trame, elles sont écrites dans les tampons de couleur spécifiés par glDrawBuffer. Une des valeurs suivantes peut être utilisée pour le framebuffer par défaut :

GL_NONE

Aucun tampon de couleur n'est écrit.

GL_FRONT_LEFT

Seul le tampon de couleur gauche avant est écrit.

GL_FRONT_RIGHT

Seul le tampon de couleur droit avant est écrit.

GL_BACK_LEFT

Seul le tampon de couleur gauche arrière est écrit.

GL_BACK_RIGHT

Seul le tampon de couleur droit arrière est écrit.

GL_FRONT

Seuls les tampons de couleur gauche avant et droit avant sont écrits. S'il n'y a pas de tampon de couleur droit avant, seul le tampon de couleur gauche avant est écrit.

GL_BACK

Seuls les tampons de couleur gauche arrière et droit arrière sont écrits. S'il n'y a pas de tampon de couleur droit arrière, seul le tampon de couleur gauche arrière est écrit.

GL_LEFT

Seuls les tampons de couleur gauche avant et gauche arrière sont écrits. S'il n'y a pas de tampon de couleur gauche arrière, seul le tampon de couleur gauche avant est écrit.

GL_RIGHT

Seuls les tampons de couleur droit avant et droit arrière sont écrits. S'il n'y a pas de tampon de couleur droit arrière, seul le tampon de couleur droit avant est écrit.

GL_FRONT_AND_BACK

Tous les tampons de couleur avant et arrière (gauche avant, droite avant, gauche arrière, droite arrière) sont écrits. S'il n'y a pas de tampons de couleur arrière, seuls les tampons de couleur gauche avant et droite avant sont écrits. S'il n'y a pas de tampons de couleur droits, seuls les tampons de couleur gauche avant et gauche arrière sont écrits. S'il n'y a ni tampon de couleur droit ni tampon de couleur arrière, seul le tampon de couleur gauche avant est écrit.

Si plus d'un tampon de couleur est sélectionné pour l'écriture, alors le mélange ou les opérations logiques sont calculés et appliqués indépendamment pour chaque tampon de couleur et peuvent produire des résultats différents dans chaque tampon.

Les contextes monoscopiques n'incluent que les tampons *gauche*, et les contextes stéréoscopiques incluent les tampons *gauche* et *droite*. De même, les contextes à tampon unique n'incluent que les tampons *avant*, et les contextes à double tampon incluent les tampons *avant* et *arrière*. Le contexte est sélectionné lors de l'initialisation de GL.

Pour les objets framebuffer, les énumérations GL_COLOR_ATTACHMENT$m$ et GL_NONE sont acceptées, où $m$ est une valeur comprise entre 0 et GL_MAX_COLOR_ATTACHMENTS. glDrawBuffer définira le tampon de dessin pour les couleurs de fragment autres que zéro à GL_NONE.

ERREURS

Une erreur GL_INVALID_OPERATION est générée par glNamedFramebufferDrawBuffer si framebuffer n'est pas zéro ou le nom d'un objet framebuffer existant.

GL_INVALID_ENUM est générée si buf n'est pas une valeur acceptée.

GL_INVALID_OPERATION est générée si le framebuffer par défaut est affecté et qu'aucun des tampons indiqués par buf n'existe.

GL_INVALID_OPERATION est générée si un objet framebuffer est affecté et que buf n'est pas égal à GL_NONE ou GL_COLOR_ATTACHMENT$m$, où $m$ est une valeur comprise entre 0 et GL_MAX_COLOR_ATTACHMENTS.

GETS ASSOCIÉS

glGet() avec l'argument GL_DRAW_BUFFER
