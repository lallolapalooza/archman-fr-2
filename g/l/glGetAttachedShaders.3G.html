GLGETATTACHEDSHADERS(3G) [FIXME: manual] GLGETATTACHEDSHADERS(3G)

NOM

glGetAttachedShaders - Renvoie les identifiants des objets shader attachés à un objet programme

SPÉCIFICATION C

void glGetAttachedShaders(GLuint program, GLsizei maxCount, GLsizei *count, GLuint *shaders);

PARAMÈTRES

program

Spécifie l'objet programme à interroger.

maxCount

Spécifie la taille du tableau pour stocker les noms d'objets renvoyés.

count

Renvoie le nombre de noms effectivement renvoyés dans shaders.

shaders

Spécifie un tableau qui est utilisé pour renvoyer les noms des objets shader attachés.

DESCRIPTION

glGetAttachedShaders renvoie les noms des objets shader attachés à program. Les noms des objets shader attachés à program seront renvoyés dans shaders. Le nombre réel de noms de shader écrits dans shaders est renvoyé dans count. Si aucun objet shader n'est attaché à program, count est mis à 0. Le nombre maximum de noms de shader qui peuvent être renvoyés dans shaders est spécifié par maxCount.

Si le nombre de noms effectivement renvoyés n'est pas nécessaire (par exemple, s'il a été obtenu en appelant glGetProgram()), une valeur de NULL peut être passée pour count. Si aucun objet shader n'est attaché à program, une valeur de 0 sera renvoyée dans count. Le nombre réel de shaders attachés peut être obtenu en appelant glGetProgram() avec la valeur GL_ATTACHED_SHADERS.

ERREURS

GL_INVALID_VALUE est généré si program n'est pas une valeur générée par OpenGL.

GL_INVALID_OPERATION est généré si program n'est pas un objet programme.

GL_INVALID_VALUE est généré si maxCount est inférieur à 0.

GETS ASSOCIÉS

glGetProgram() avec l'argument GL_ATTACHED_SHADERS

glIsProgram()
