NOM

glUniformBlockBinding - assigne un point de liaison à un bloc uniforme actif

SPÉCIFICATION C

void glUniformBlockBinding(GLuint program, GLuint uniformBlockIndex, GLuint uniformBlockBinding);

PARAMÈTRES

program

Le nom d'un objet programme contenant le bloc uniforme actif dont le point de liaison doit être assigné.

uniformBlockIndex

L'index du bloc uniforme actif dans program dont le point de liaison doit être assigné.

uniformBlockBinding

Spécifie le point de liaison auquel le bloc uniforme d'index uniformBlockIndex dans program doit être lié.

DESCRIPTION

Les points de liaison pour les blocs uniformes actifs sont assignés en utilisant glUniformBlockBinding. Chacun des blocs uniformes actifs d'un programme possède un point de liaison de tampon uniforme correspondant. program est le nom d'un objet programme pour lequel la commande glLinkProgram() a été émise précédemment.

En cas de succès, glUniformBlockBinding spécifie que program utilisera le stockage de données de l'objet tampon lié au point de liaison uniformBlockBinding pour extraire les valeurs des uniformes du bloc uniforme identifié par uniformBlockIndex.

Lorsqu'un objet programme est lié ou relinké, le point de liaison de l'objet tampon uniforme assigné à chacun de ses blocs uniformes actifs est réinitialisé à zéro.

ERREURS

GL_INVALID_VALUE est généré si uniformBlockIndex n'est pas un index de bloc uniforme actif de program.

GL_INVALID_VALUE est généré si uniformBlockBinding est supérieur ou égal à la valeur de GL_MAX_UNIFORM_BUFFER_BINDINGS.

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme généré par le GL.

NOTES

glUniformBlockBinding n'est disponible que si la version GL est 3.1 ou supérieure.

ASSOCIÉES GETS

glGetActiveUniformBlock() avec l'argument GL_UNIFORM_BLOCK_BINDING
