glutChangeToMenuEntry(3)

Paquet: freeglut

Licences: X11

glutChangeToMenuEntry(3) freeglut glutChangeToMenuEntry(3)

NOM

glutChangeToMenuEntry - change une entrée de menu spécifiée dans le menu courant en une entrée de menu.

SYNTAXE

void glutChangeToMenuEntry(int entry, char *name, int value);

ARGUMENTS

entry
Indice parmi les éléments du menu courant (1 est l'élément de menu le plus haut).
name
Chaîne de caractères ASCII à afficher dans l'entrée de menu.
value
Valeur à retourner à la fonction de rappel du menu si l'entrée de menu est sélectionnée.

DESCRIPTION

glutChangeToMenuEntry modifie l'entrée de menu spécifiée dans le menu courant pour en faire une entrée de menu. Le paramètre entry détermine quel élément de menu doit être modifié, 1 étant le premier élément. entry doit être compris entre 1 et glutGet(GLUT_MENU_NUM_ITEMS) inclus. L'élément de menu à modifier n'a pas besoin d'être déjà une entrée de menu. La chaîne name sera affichée pour la nouvelle entrée de menu modifiée. La valeur sera retournée à la fonction de rappel du menu si cette entrée de menu est sélectionnée.

VOIR AUSSI

glutChangeToSubMenu, glutAddMenuEntry, glutRemoveMenuItem
