GLBLENDEQUATION(3G) [FIXME : manuel] GLBLENDEQUATION(3G)

NOM

glBlendEquation - spécifie l'équation utilisée à la fois pour l'équation de mélange RGB et l'équation de mélange Alpha

SPÉCIFICATION C

void glBlendEquation(GLenummode);

void glBlendEquationi(GLuintbuf, GLenummode);

PARAMÈTRES

buf

pour glBlendEquationi, spécifie l'index du tampon de dessin pour lequel définir l'équation de mélange.

mode

spécifie comment les couleurs source et destination sont combinées. Elle doit être GL_FUNC_ADD, GL_FUNC_SUBTRACT, GL_FUNC_REVERSE_SUBTRACT, GL_MIN, GL_MAX.

DESCRIPTION

Les équations de mélange déterminent comment un nouveau pixel (la couleur « source ») est combiné avec un pixel déjà présent dans le tampon de trame (la couleur « destination »). Cette fonction définit à la fois l'équation de mélange RGB et l'équation de mélange alpha à une seule équation. glBlendEquationi spécifie l'équation de mélange pour un seul tampon de dessin alors que glBlendEquation définit l'équation de mélange pour tous les tampons de dessin.

Ces équations utilisent les facteurs de mélange source et destination spécifiés par glBlendFunc() ou glBlendFuncSeparate(). Voir glBlendFunc() ou glBlendFuncSeparate() pour une description des différents facteurs de mélange.

Dans les équations suivantes, les composantes de couleur source et destination sont désignées respectivement par R s G s B s A s et R d G d B d A d. La couleur du résultat est désignée par R r G r B r A r. Les facteurs de mélange source et destination sont désignés respectivement par s R s G s B s A et d R d G d B d A. Pour ces équations, toutes les composantes de couleur sont supposées avoir des valeurs dans l'intervalle 0 1.

Mode Composantes RGB Composante Alpha
GL_FUNC_ADD Rr = R s ⁢ s R + R d ⁢ d R Gr = G s ⁢ s G + G d ⁢ d G Br = B s ⁢ s B + B d ⁢ d B Ar = A s ⁢ s A + A d ⁢ d A
GL_FUNC_SUBTRACT Rr = R s ⁢ s R - R d ⁢ d R Gr = G s ⁢ s G - G d ⁢ d G Br = B s ⁢ s B - B d ⁢ d B Ar = A s ⁢ s A - A d ⁢ d A
GL_FUNC_REVERSE_SUBTRACT Rr = R d ⁢ d R - R s ⁢ s R Gr = G d ⁢ d G - G s ⁢ s G Br = B d ⁢ d B - B s ⁢ s B Ar = A d ⁢ d A - A s ⁢ s A
GL_MIN Rr = min ⁡ R s R d Gr = min ⁡ G s G d Br = min ⁡ B s B d Ar = min ⁡ A s A d
GL_MAX Rr = max ⁡ R s R d Gr = max ⁡ G s G d Br = max ⁡ B s B d Ar = max ⁡ A s A d

Les résultats de ces équations sont limités à l'intervalle 0 1.

Les GL_MIN et GL_MAX équations sont utiles pour les applications qui analysent des données d'image (par exemple, le seuillage d'image par rapport à une couleur constante). L'équation GL_FUNC_ADD est utile pour l'antialiasing et la transparence, entre autres.

Initialement, à la fois l'équation de mélange RGB et l'équation de mélange alpha sont définies à GL_FUNC_ADD.

REMARQUES

Les GL_MINet GL_MAX équations n'utilisent pas les facteurs source ou destination, seulement les couleurs source et destination.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas l'une des valeurs GL_FUNC_ADD, GL_FUNC_SUBTRACT, GL_FUNC_REVERSE_SUBTRACT, GL_MAX, ou GL_MIN.

GL_INVALID_VALUE est généré par glBlendEquationi si buf est supérieur ou égal à la valeur de GL_MAX_DRAW_BUFFERS.

ACCÈS ASSOCIÉS

glGet() avec un argument GL_BLEND_EQUATION_RGB

glGet() avec un argument GL_BLEND_EQUATION_ALPHA
