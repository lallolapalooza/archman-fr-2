NOM

glGetUniformBlockIndex - récupérer l'indice d'un bloc d'uniformes nommé

SPÉCIFICATION C

GLuint glGetUniformBlockIndex(GLuint program, const GLchar *uniformBlockName);

PARAMÈTRES

program

Spécifie le nom d'un programme contenant le bloc d'uniformes.

uniformBlockName

Spécifie l'adresse d'un tableau de caractères contenant le nom du bloc d'uniformes dont il faut récupérer l'indice.

DESCRIPTION

glGetUniformBlockIndex récupère l'indice d'un bloc d'uniformes dans program.

program doit être le nom d'un objet programme pour lequel la commande glLinkProgram() a déjà été appelée, bien qu'il ne soit pas obligatoire que glLinkProgram() ait réussi. Le lien peut avoir échoué car le nombre d'uniformes actifs dépassait la limite.

uniformBlockName doit contenir une chaîne terminée par un caractère nul spécifiant le nom du bloc d'uniformes.

glGetUniformBlockIndex retourne l'indice du bloc d'uniformes pour le bloc d'uniformes nommé uniformBlockName du programme program. Si uniformBlockName n'identifie pas un bloc d'uniformes actif du programme program, glGetUniformBlockIndex retourne l'identifiant spécial, GL_INVALID_INDEX. Les indices des blocs d'uniformes actifs d'un programme sont attribués de manière consécutive, en commençant par zéro.

ERREURS

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un objet programme pour lequel glLinkProgram() a été appelée dans le passé.

NOTES

glGetUniformBlockIndex n'est disponible que si la version de GL est 3.1 ou supérieure.
