NOM

glab-mcp-serve - Démarrer un serveur MCP avec transport stdio. (EXPÉRIMENTAL)

SYNOPIS

glab mcp serve [indicateurs]

DESCRIPTION

Démarre un serveur Model Context Protocol (MCP) pour exposer les fonctionnalités de GitLab en tant qu'outils pour les assistants IA tels que Claude Code.

Le serveur utilise le transport stdio (entrée et sortie standard) pour la communication et fournit des outils pour :

  • Gérer les issues (lister, créer, mettre à jour, fermer, ajouter des notes)
  • Gérer les merge requests (lister, créer, mettre à jour, fusionner, ajouter des notes)
  • Gérer les projets (lister, obtenir des détails)
  • Gérer les pipelines et les jobs CI/CD

Pour configurer ce serveur dans Claude Code, ajoutez ce code à vos paramètres MCP :

{
  "mcpServers": {
    "glab": {
      "type": "stdio",
      "command": "glab",
      "args": ["mcp", "serve"]
    }
  }
}

Cette fonctionnalité est expérimentale. Elle peut être défaillante ou supprimée sans préavis. En savoir plus sur ce que signifient les fonctionnalités expérimentales sur https://docs.gitlab.com/policy/development_stages_support/

Utilisez les fonctionnalités expérimentales à vos propres risques.
