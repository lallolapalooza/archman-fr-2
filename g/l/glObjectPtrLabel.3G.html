NOM

glObjectPtrLabel - étiqueter un objet de synchronisation identifié par un pointeur

C SPÉCIFICATION

void glObjectPtrLabel(void * ptr, GLsizei length, const char * label);

PARAMÈTRES

ptr

Un pointeur identifiant un objet de synchronisation.

length

La longueur de l'étiquette à utiliser pour l'objet.

label

L'adresse d'une chaîne contenant l'étiquette à assigner à l'objet.

DESCRIPTION

glObjectPtrLabel étiquette l'objet de synchronisation identifié par ptr.

label est l'adresse d'une chaîne qui sera utilisée pour étiqueter l'objet. length contient le nombre de caractères dans label. Si length est négatif, il est implicite que label contient une chaîne terminée par un caractère nul. Si label est NULL, toute étiquette de débogage est effectivement supprimée de l'objet.

ERREURS

GL_INVALID_VALUE est généré si ptr n'est pas un objet de synchronisation valide.

GL_INVALID_VALUE est généré si le nombre de caractères dans label, hors le terminateur nul lorsque length est négatif, est supérieur à la valeur de GL_MAX_LABEL_LENGTH.

GETS ASSOCIÉS

glGet() avec l'argument GL_MAX_LABEL_LENGTH.
