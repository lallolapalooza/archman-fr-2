NOM

glCompressedTexImage1D - spécifie une image de texture unidimensionnelle dans un format compressé

SPÉCIFICATION C

void glCompressedTexImage1D(GLenumtarget, GLintlevel, GLenuminternalformat, GLsizeiwidth, GLintborder, GLsizeiimageSize, const void *data);

PARAMÈTRES

target

Spécifie la texture cible. Doit être GL_TEXTURE_1D ou GL_PROXY_TEXTURE_1D.

level

Spécifie le numéro de niveau de détail. Le niveau 0 est le niveau d'image de base. Le niveau n est la nième image de réduction de mipmap.

internalformat

Spécifie le format des données d'image compressées stockées à l'adresse data.

width

Spécifie la largeur de l'image de texture. Toutes les implémentations prennent en charge des images de texture d'au moins 64 texels de large. La hauteur de l'image de texture 1D est 1.

border

Cette valeur doit être 0.

imageSize

Spécifie le nombre d'octets non signés de données d'image commençant à l'adresse spécifiée par data.

data

Spécifie un pointeur vers les données d'image compressées en mémoire.

DESCRIPTION

La texturation permet aux éléments d'un tableau d'images d'être lus par les shaders.

glCompressedTexImage1D charge une image de texture unidimensionnelle compressée préalablement définie et récupérée si target est GL_TEXTURE_1D (voir glTexImage1D()).

Si target est GL_PROXY_TEXTURE_1D, aucune donnée n'est lue depuis data, mais tout l'état de l'image de texture est recalculé, vérifié pour la cohérence, et vérifié par rapport aux capacités de l'implémentation. Si l'implémentation ne peut pas gérer une texture de la taille demandée, elle définit tout l'état de l'image à 0, mais ne génère pas d'erreur (voir glGetError()). Pour interroger un tableau de mipmap entier, utilisez un niveau de tableau d'image supérieur ou égal à 1.

internalformat doit être un format de texture compressée spécifié par une extension. Quand une texture est chargée avec glTexImage1D() en utilisant un format de texture compressé générique (par exemple, GL_COMPRESSED_RGB), le GL sélectionne parmi l'une de ses extensions prenant en charge les textures compressées. Afin de charger l'image de texture compressée en utilisant glCompressedTexImage1D, interrogez la taille et le format de l'image de texture compressée en utilisant glGetTexLevelParameter().

Si un objet tampon nommé non nul est lié à la cible GL_PIXEL_UNPACK_BUFFER (voir glBindBuffer()) pendant qu'une image de texture est spécifiée, data est traité comme un décalage en octets dans le magasin de données de l'objet tampon.

Si les données compressées sont arrangées en blocs de taille fixe de texels, les modes de stockage de pixels peuvent être utilisés pour sélectionner un sous-rectangle à partir d'un rectangle conteneur plus grand. Ces modes de stockage de pixels fonctionnent de la même manière que pour glTexImage1D(). Dans la description suivante, désignez par bs, bw, bh et bd les valeurs des modes de stockage de pixels GL_UNPACK_COMPRESSED_BLOCK_SIZE, GL_UNPACK_COMPRESSED_BLOCK_WIDTH, GL_UNPACK_COMPRESSED_BLOCK_HEIGHT, et GL_UNPACK_COMPRESSED_BLOCK_DEPTH, respectivement. bs est la taille du bloc compressé en octets ; bw, bh et bd sont la largeur, la hauteur et la profondeur du bloc compressé en pixels.

Par défaut, les modes de stockage de pixels GL_UNPACK_ROW_LENGTH, GL_UNPACK_SKIP_ROWS, GL_UNPACK_SKIP_PIXELS, GL_UNPACK_IMAGE_HEIGHT et GL_UNPACK_SKIP_IMAGES sont ignorés pour les images compressées. Pour activer GL_UNPACK_SKIP_PIXELS et GL_UNPACK_ROW_LENGTH, bs et bw doivent tous deux être non nuls. Pour activer également GL_UNPACK_SKIP_ROWS et GL_UNPACK_IMAGE_HEIGHT, bh doit être non nul. Pour activer également GL_UNPACK_SKIP_IMAGES, bd doit être non nul. Tous les paramètres doivent être cohérents avec le format compressé pour produire les résultats désirés.

Lors de la sélection d'un sous-rectangle à partir d'une image compressée,

•la valeur de GL_UNPACK_SKIP_PIXELS doit être un multiple de bw

imageSize doit être égal à :

b s × width b w

ERREURS

GL_INVALID_ENUM est généré si internalformat n'est pas un format interne compressé spécifique pris en charge, ou est l'un des formats internes compressés génériques : GL_COMPRESSED_RED, GL_COMPRESSED_RG, GL_COMPRESSED_RGB, GL_COMPRESSED_RGBA. GL_COMPRESSED_SRGB, ou GL_COMPRESSED_SRGB_ALPHA.

GL_INVALID_VALUE est généré si imageSize n'est pas cohérent avec le format, les dimensions et le contenu des données d'image compressées spécifiées.

GL_INVALID_VALUE est généré si border n'est pas 0.

GL_INVALID_OPERATION est généré si des combinaisons de paramètres ne sont pas prises en charge par le format interne compressé spécifique tel que spécifié dans l'extension de compression de texture spécifique.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à la cible GL_PIXEL_UNPACK_BUFFER et le magasin de données de l'objet tampon est actuellement mappé.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à la cible GL_PIXEL_UNPACK_BUFFER et les données seraient décompressées depuis l'objet tampon de telle sorte que les lectures mémoire requises dépasseraient la taille du magasin de données.

Des résultats indéfinis, y compris une terminaison anormale du programme, sont générés si data n'est pas encodé d'une manière cohérente avec la spécification de l'extension définissant le format de compression interne.
