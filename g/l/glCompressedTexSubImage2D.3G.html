NOM

glCompressedTexSubImage2D, glCompressedTextureSubImage2D - spécifier une sous-image de texture bidimensionnelle dans un format compressé

SPÉCIFICATION C

void glCompressedTexSubImage2D(GLenum target, GLint level, GLint xoffset, GLint yoffset, GLsizei width, GLsizei height, GLenum format, GLsizei imageSize, const void * data);

void glCompressedTextureSubImage2D(GLuint texture, GLint level, GLint xoffset, GLint yoffset, GLsizei width, GLsizei height, GLenum format, GLsizei imageSize, const void *data);

PARAMÈTRES

target

Spécifie la cible à laquelle la texture est liée pour la fonction glCompressedTexSubImage2D. Doit être GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, ou GL_TEXTURE_CUBE_MAP_NEGATIVE_Z.

texture

Spécifie le nom de l'objet texture pour la fonction glCompressedTextureSubImage2D.

level

Spécifie le numéro du niveau de détail. Le niveau 0 est le niveau de l'image de base. Le niveau n est l'image de réduction mipmap n.

xoffset

Spécifie un décalage de texel dans la direction x au sein du tableau de textures.

yoffset

Spécifie un décalage de texel dans la direction y au sein du tableau de textures.

width

Spécifie la largeur de la sous-image de texture.

height

Spécifie la hauteur de la sous-image de texture.

format

Spécifie le format des données de l'image compressée stockées à l'adresse data.

imageSize

Spécifie le nombre d'octets non signés de données d'image à partir de l'adresse spécifiée par data.

data

Spécifie un pointeur vers les données de l'image compressée en mémoire.

DESCRIPTION

La texturation permet de lire des éléments d'un tableau d'images par les shaders.

glCompressedTexSubImage2D et glCompressedTextureSubImage2D redéfinissent une région contiguë d'une image de texture bidimensionnelle existante. Les texels référencés par data remplacent la partie du tableau de textures existant avec les indices x xoffset et xoffset + width - 1, et les indices y yoffset et yoffset + height - 1, inclus. Cette région ne peut pas inclure de texels en dehors de la plage du tableau de textures tel qu'il a été spécifié à l'origine. Ce n'est pas une erreur de spécifier une sous-texture avec une largeur de 0, mais une telle spécification n'a aucun effet.

internalformat doit être un format d'image compressé connu (tel que GL_RGTC) ou un format de texture compressée spécifié par une extension. Le format de l'image de texture compressée est sélectionné par l'implémentation GL qui l'a compressée (voir glTexImage2D()) et devrait être interogé au moment où la texture a été compressée avec glGetTexLevelParameter().

Si un objet tampon nommé non nul est lié à la cible GL_PIXEL_UNPACK_BUFFER (voir glBindBuffer()) pendant la spécification d'une image de texture, data est traité comme un décalage d'octets dans le magasin de données de l'objet tampon.

ERREURS

GL_INVALID_ENUM est généré si internalformat est des formats internes compressés génériques : GL_COMPRESSED_RED, GL_COMPRESSED_RG, GL_COMPRESSED_RGB, GL_COMPRESSED_RGBA. GL_COMPRESSED_SRGB, ou GL_COMPRESSED_SRGB_ALPHA.

GL_INVALID_ENUM est généré par glCompressedTexSubImage2D si target est GL_TEXTURE_RECTANGLE ou GL_PROXY_TEXTURE_RECTANGLE.

GL_INVALID_VALUE est généré si imageSize n'est pas cohérent avec le format, les dimensions et le contenu des données d'image compressées spécifiées.

GL_INVALID_OPERATION est généré si les combinaisons de paramètres ne sont pas prises en charge par le format interne compressé spécifique, comme spécifié dans l'extension de compression de texture spécifique.

GL_INVALID_OPERATION est généré si un objet tampon nommé non nul est lié à la cible GL_PIXEL_UNPACK_BUFFER et que le magasin de données de l'objet tampon est actuellement mappé.

GL_INVALID_OPERATION est généré si un objet tampon nommé non nul est lié à la cible GL_PIXEL_UNPACK_BUFFER et que les données seraient décompressées à partir de l'objet tampon de telle sorte que les lectures mémoire requises dépasseraient la taille du magasin de données.

GL_INVALID_OPERATION est généré par glCompressedTextureSubImage2D si texture n'est pas le nom d'un objet texture existant.

GL_INVALID_OPERATION est généré par glCompressedTextureSubImage2D si la cible effective est GL_TEXTURE_RECTANGLE.

Des résultats indéfinis, y compris une terminaison anormale du programme, sont générés si data n'est pas encodé d'une manière cohérente avec la spécification d'extension définissant le format de compression interne.

ASSOCIÉES GETS

glGetCompressedTexImage()

glGet() avec l'argument GL_TEXTURE_COMPRESSED

glGet() avec l'argument GL_PIXEL_UNPACK_BUFFER_BINDING

glGetTexLevelParameter() avec les arguments GL_TEXTURE_INTERNAL_FORMAT et GL_TEXTURE_COMPRESSED_IMAGE_SIZE
