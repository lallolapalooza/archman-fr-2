NOM

glBlendColor - définit la couleur de mélange

SPÉCIFICATION C

void glBlendColor(GLfloat red, GLfloat green, GLfloat blue, GLfloat alpha);

PARAMÈTRES

red, green, blue, alpha

spécifient les composantes de GL_BLEND_COLOR

DESCRIPTION

Le GL_BLEND_COLOR peut être utilisé pour calculer les facteurs de mélange source et destination. Les composantes de couleur sont limitées à la plage 0 1 avant d'être stockées. Voir glBlendFunc() pour une description complète des opérations de mélange. Initialement, le GL_BLEND_COLOR est défini sur (0, 0, 0, 0).

NOTES

Le type des paramètres red, green, blue et alpha a été modifié de GLclampf à GLfloat. Ce changement est transparent pour le code utilisateur et est décrit en détail sur la page removedTypes().

OBTENTIONS ASSOCIÉES

glGet() avec l'argument GL_BLEND_COLOR
