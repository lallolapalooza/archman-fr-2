NOM

glCreateProgram - Crée un objet programme

SPéCIFICATION C

GLuint glCreateProgram(void);

DESCRIPTION

glCreateProgram crée un objet programme vide et renvoie une valeur non nulle par laquelle il peut être référencé. Un objet programme est un objet auquel des objets shader peuvent être attachés. Cela fournit un mécanisme pour spécifier les objets shader qui seront liés pour créer un programme. Il fournit également un moyen de vérifier la compatibilité des shaders qui seront utilisés pour créer un programme (par exemple, vérifier la compatibilité entre un shader de sommet et un shader de fragment). Lorsqu'ils ne sont plus nécessaires dans le cadre d'un objet programme, les objets shader peuvent être détachés.

Un ou plusieurs exécutables sont créés dans un objet programme en y attachant avec succès des objets shader avec glAttachShader(), en compilant avec succès les objets shader avec glCompileShader() et en liant avec succès l'objet programme avec glLinkProgram(). Ces exécutables sont rendus partie de l'état actuel lorsque glUseProgram() est appelé. Les objets programmes peuvent être supprimés en appelant glDeleteProgram(). La mémoire associée à l'objet programme sera supprimée lorsqu'elle ne fera plus partie de l'état de rendu actuel pour aucun contexte.

NOTES

Comme les objets tampon et texture, l'espace de noms pour les objets programme peut être partagé entre un ensemble de contextes, tant que les côtés serveur des contextes partagent le même espace d'adressage. Si l'espace de noms est partagé entre les contextes, tous les objets attachés et les données associées à ces objets attachés sont également partagés.

Les applications sont responsables de la synchronisation entre les appels API lorsque les objets sont accédés depuis différents threads d'exécution.

ERREURS

Cette fonction renvoie 0 si une erreur survient lors de la création de l'objet programme.
