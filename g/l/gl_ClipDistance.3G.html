NOM

gl_ClipDistance - fournit un mécanisme compatible avec l'avenir pour le découpage des sommets

DECLARATION

gl_ClipDistance est un membre du bloc nommé gl_PerVertex :

    out gl_PerVertex {
        vec4 gl_Position;
        float gl_PointSize;
        float gl_ClipDistance[];
    };

Dans les shaders de fragments, il est intrinsèquement déclaré comme : in float gl_ClipDistance[] ;

DESCRIPTION

La variable gl_ClipDistance fournit un mécanisme compatible avec l'avenir pour contrôler le découpage utilisateur. L'élément gl_ClipDistance[i] spécifie une distance de découpage pour chaque plan de découpage utilisateur i. Une distance de 0.0 signifie que le sommet est sur le plan, une distance positive signifie que le sommet est à l'intérieur du plan de découpage, et une distance négative signifie que le point est à l'extérieur du plan de découpage. Les distances de découpage seront interpolées linéairement sur la primitive et la partie de la primitive avec des distances interpolées inférieures à 0.0 sera découpée.

Le tableau gl_ClipDistance est initialement prédéclaré sans taille et doit être dimensionné par le shader, soit en le redéclarant avec une taille explicite, soit en l'indexant uniquement avec des expressions constantes entières. Le tableau doit être dimensionné pour inclure tous les plans de découpage qui sont activés via l'API OpenGL ; si la taille n'inclut pas tous les plans activés, les résultats sont indéfinis. La taille ne peut pas dépasser gl_MaxClipDistances. Le nombre de composants variables consommés par gl_ClipDistance correspondra à la taille du tableau, quel que soit le nombre de plans activés. Le shader doit également définir toutes les valeurs de gl_ClipDistance qui ont été activées via l'API OpenGL, sinon les résultats sont indéfinis. Les valeurs écrites dans les plans gl_ClipDistance qui ne sont pas activés n'ont aucun effet.

Dans les langages de vertex, d'évaluation de tessellation et de géométrie, une seule instance globale du bloc nommé gl_PerVertex est disponible et son membre gl_ClipDistance est une sortie qui reçoit les distances de découpage pour le sommet courant. Il peut être écrit à tout moment pendant l'exécution du shader. La valeur écrite dans gl_ClipDistance sera utilisée par l'assemblage de primitives, le découpage, le rejet et d'autres opérations de fonctionnalité fixe, s'ils sont présents, qui opèrent sur les primitives après que le traitement des sommets a eu lieu.

Dans le langage de contrôle de tessellation, le bloc nommé gl_PerVertex est utilisé pour construire un tableau, gl_out[], dont les membres gl_ClipDistance contiennent les distances de découpage pour chacun des points de contrôle, qui deviennent disponibles en entrée pour le shader d'évaluation de tessellation suivant.

La valeur de gl_ClipDistance (ou du membre gl_ClipDistance du tableau gl_out[], dans le cas du shader de contrôle de tessellation) est indéfinie après les étapes de vertex, de contrôle de tessellation et d'évaluation de tessellation si l'exécutable du shader correspondant n'écrit pas dans gl_ClipDistance. Elle est également indéfinie après l'étape de traitement de la géométrie si l'exécutable du shader de géométrie appelle EmitVertex() sans avoir écrit gl_ClipDistance depuis le dernier appel à EmitVertex() (ou sans l'avoir écrit du tout).

Dans les langages de contrôle de tessellation, d'évaluation de tessellation et de géométrie, le bloc nommé gl_PerVertex est utilisé pour construire un tableau, gl_in[] d'entrées par sommet ou par point de contrôle dont le contenu représente les sorties correspondantes écrites par l'étape précédente. Seuls les éléments du tableau gl_ClipDistance qui correspondent aux plans de découpage activés ont des valeurs définies.
