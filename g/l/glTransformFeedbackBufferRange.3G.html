NOM

glTransformFeedbackBufferRange - lier une plage dans un objet tampon à un objet tampon de retour de transformation

SPÉCIFICATION C

void glTransformFeedbackBufferRange(GLuint xfb, GLuint index, GLuint buffer, GLintptr offset, GLsizei size);

PARAMÈTRES

xfb

Nom de l'objet tampon de retour de transformation.

index

Indice du point de liaison dans xfb.

buffer

Nom de l'objet tampon à lier au point de liaison spécifié.

offset

Le décalage de départ en unités machine de base dans l'objet tampon.

size

La quantité de données en unités machine de base qui peut être lue ou écrite dans l'objet tampon lorsqu'il est utilisé comme cible indexée.

DESCRIPTION

glTransformFeedbackBufferRange lie une plage de l'objet tampon buffer représentée par offset et size au point de liaison à l'indice index de l'objet de retour de transformation xfb.

offset spécifie le décalage en unités machine de base dans l'objet tampon buffer et size spécifie la quantité de données qui peut être lue à partir de l'objet tampon lorsqu'il est utilisé comme cible indexée.

NOTES

ERREURS

GL_INVALID_OPERATION est généré si xfb n'est pas le nom d'un objet de retour de transformation existant.

GL_INVALID_VALUE est généré si buffer n'est pas zéro ou le nom d'un objet tampon existant.

GL_INVALID_VALUE est généré si index est supérieur ou égal au nombre de points de liaison de tampons de retour de transformation (la valeur de GL_TRANSFORM_FEEDBACK_BUFFER_BINDING).

GL_INVALID_VALUE est généré si offset est négatif.

GL_INVALID_VALUE est généré si buffer est non nul et soit size est inférieur ou égal à zéro, soit offset + size est supérieur à la valeur de GL_BUFFER_SIZE pour buffer.
