NOM

glGetBufferParameteriv, glGetBufferParameteri64v, glGetNamedBufferParameteriv, glGetNamedBufferParameteri64v - renvoyer les paramètres d'un objet tampon

SPÉCIFICATION

void glGetBufferParameteriv(GLenum target, GLenum value, GLint * data);

void glGetBufferParameteri64v(GLenum target, GLenum value, GLint64 * data);

void glGetNamedBufferParameteriv(GLuint buffer, GLenum pname, GLint *params);

void glGetNamedBufferParameteri64v(GLuint buffer, GLenum pname, GLint64 *params);

PARAMÈTRES

target

Spécifie la cible à laquelle l'objet tampon est lié pour glGetBufferParameteriv et glGetBufferParameteri64v. Doit être une des cibles de liaison de tampon dans le tableau suivant:
Cible de liaison de tampon Usage
GL_ARRAY_BUFFER Attributs de sommet
GL_ATOMIC_COUNTER_BUFFER Stockage de compteur atomique
GL_COPY_READ_BUFFER Source de copie de tampon
GL_COPY_WRITE_BUFFER Destination de copie de tampon
GL_DISPATCH_INDIRECT_BUFFER Commandes de calcul indirectes
GL_DRAW_INDIRECT_BUFFER Arguments de commande indirects
GL_ELEMENT_ARRAY_BUFFER Indices du tableau de sommets
GL_PIXEL_PACK_BUFFER Cible de lecture de pixels
GL_PIXEL_UNPACK_BUFFER Source de données de texture
GL_QUERY_BUFFER Tampon de résultat de requête
GL_SHADER_STORAGE_BUFFER Stockage en lecture/écriture pour les shaders
GL_TEXTURE_BUFFER Tampon de données de texture
GL_TRANSFORM_FEEDBACK_BUFFER Tampon de retour de transformation
GL_UNIFORM_BUFFER Stockage de bloc uniforme

buffer

Spécifie le nom de l'objet tampon pour glGetNamedBufferParameteriv et glGetNamedBufferParameteri64v.

value

Spécifie le nom du paramètre de l'objet tampon à interroger.

data

Renvoie le paramètre demandé.

DESCRIPTION

Ces fonctions renvoient dans data un paramètre sélectionné de l'objet tampon spécifié.

pname nomme un paramètre spécifique de l'objet tampon, comme suit:

GL_BUFFER_ACCESS

params renvoie la politique d'accès définie lors du mappage de l'objet tampon (la valeur de l'énumération du paramètre access passée à glMapBuffer). Si le tampon a été mappé avec glMapBufferRange, la politique d'accès est déterminée en traduisant les bits de ce paramètre access en l'un des énumérés pris en charge pour glMapBuffer comme décrit dans la Spécification OpenGL.

GL_BUFFER_ACCESS_FLAGS

params renvoie la politique d'accès définie lors du mappage de l'objet tampon (la valeur du champ de bits du paramètre access passé à glMapBufferRange). Si le tampon a été mappé avec glMapBuffer, la politique d'accès est déterminée en traduisant les énumérés de ce paramètre access dans les bits correspondants pour glMapBufferRange comme décrit dans la Spécification OpenGL. La valeur initiale est zéro.

GL_BUFFER_IMMUTABLE_STORAGE

params renvoie un indicateur booléen indiquant si l'objet tampon est immuable. La valeur initiale est GL_FALSE.

GL_BUFFER_MAPPED

params renvoie un indicateur indiquant si l'objet tampon est actuellement mappé. La valeur initiale est GL_FALSE.

GL_BUFFER_MAP_LENGTH

params renvoie la longueur du mappage dans l'objet tampon établi avec glMapBuffer*. Les versions i64v de ces requêtes doivent être utilisées pour ce paramètre. La valeur initiale est zéro.

GL_BUFFER_MAP_OFFSET

params renvoie le décalage du mappage dans l'objet tampon établi avec glMapBuffer*. Les versions i64v de ces requêtes doivent être utilisées pour ce paramètre. La valeur initiale est zéro.

GL_BUFFER_SIZE

params renvoie la taille de l'objet tampon, mesurée en octets. La valeur initiale est 0.

GL_BUFFER_STORAGE_FLAGS

params renvoie un champ de bits indiquant les indicateurs de stockage pour l'objet tampon. Si l'objet tampon est immuable, la valeur renvoyée sera celle spécifiée lorsque le magasin de données a été établi avec glBufferStorage. Si le magasin de données a été établi avec glBufferData, la valeur sera GL_MAP_READ_BIT | GL_MAP_WRITE_BIT | GL_DYNAMIC_STORAGE_BIT | GL_MAP_WRITE_BIT. La valeur initiale est zéro.

GL_BUFFER_USAGE

params renvoie le modèle d'utilisation de l'objet tampon. La valeur initiale est GL_STATIC_DRAW.

NOTES

Si une erreur est générée, aucune modification n'est apportée au contenu de data.

La cible GL_ATOMIC_COUNTER_BUFFER n'est disponible que si la version de GL est 4.2 ou supérieure.

Les cibles GL_DISPATCH_INDIRECT_BUFFER et GL_SHADER_STORAGE_BUFFER ne sont disponibles que si la version de GL est 4.3 ou supérieure.

La cible GL_QUERY_BUFFER n'est disponible que si la version de GL est 4.4 ou supérieure.

ERREURS

GL_INVALID_ENUM est générée par glGetBufferParameter* si target n'est pas l'une des cibles de tampon acceptées.

GL_INVALID_OPERATION est générée par glGetBufferParameter* si zéro est lié à target.

GL_INVALID_OPERATION est générée par glGetNamedBufferParameter* si buffer n'est pas le nom d'un objet tampon existant.

GL_INVALID_ENUM est générée si pname n'est pas l'un des noms de paramètre d'objet tampon décrits ci-dessus.

glGetBufferParameteri64v(3G)

NAME

glGetBufferParameteri64v - query buffer object parameters

C SPECIFICATION

GLint64 glGetBufferParameteri64v(GLenum target, GLenum pname, GLint64 *params);

PARAMETERS

 target
Specifies the target buffer object. The symbolic constant must be one of GL_ARRAY_BUFFER, GL_ATOMIC_COUNTER_BUFFER, GL_COPY_READ_BUFFER, GL_COPY_WRITE_BUFFER, GL_DISPATCH_INDIRECT_BUFFER, GL_DRAW_INDIRECT_BUFFER, GL_ELEMENT_ARRAY_BUFFER, GL_PIXEL_PACK_BUFFER, GL_PIXEL_UNPACK_BUFFER, GL_QUERY_BUFFER, GL_SHADER_STORAGE_BUFFER, GL_TEXTURE_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, or GL_UNIFORM_BUFFER.
 pname
Specifies the parameter to be returned. Must be one of the following:
GL_BUFFER_ACCESS_FLAGS
Returns flags indicating how the buffer is accessed. See glBufferStorage().
GL_BUFFER_STORAGE_FLAGS
Returns flags indicating how the buffer is stored. See glBufferStorage().
GL_BUFFER_MAP_LENGTH
Returns the length of the currently mapped region. If the buffer is not currently mapped, this will be zero.
GL_BUFFER_MAP_OFFSET
Returns the offset of the currently mapped region. If the buffer is not currently mapped, this will be zero.
GL_BUFFER_SIZE
Returns the size, in units of basic memory, of the buffer object's currently bound buffer data store.
GL_BUFFER_BINDING
Returns the name of the buffer object that is bound to target. If no buffer object is bound to target, zero is returned.
 params
A pointer to a location where the result will be written.

DESCRIPTION

Returns parameters of the buffer object currently bound to target. The symbolic constant pname is one of the parameters that can be queried. If pname is GL_BUFFER_SIZE, GL_BUFFER_BINDING, GL_BUFFER_MAP_LENGTH, or GL_BUFFER_MAP_OFFSET, then params is a pointer to a single GLint64 variable. If pname is GL_BUFFER_ACCESS_FLAGS or GL_BUFFER_STORAGE_FLAGS, then params is a pointer to a single GLbitfield. In either case, the specified parameter is written into the location pointed to by params.

If the buffer object was created with glBufferStorage, then GL_BUFFER_ACCESS_FLAGS returns the access flags that were specified when the buffer was created, and GL_BUFFER_STORAGE_FLAGS returns the storage flags that were specified when the buffer was created.

If the buffer object was not created with glBufferStorage, then GL_BUFFER_ACCESS_FLAGS and GL_BUFFER_STORAGE_FLAGS return zero.

If the buffer object is currently mapped, then GL_BUFFER_MAP_LENGTH returns the length of the currently mapped region, and GL_BUFFER_MAP_OFFSET returns the offset of the currently mapped region.

If the buffer object is not currently mapped, then GL_BUFFER_MAP_LENGTH and GL_BUFFER_MAP_OFFSET return zero.

If no buffer object is bound to target, then GL_BUFFER_SIZE, GL_BUFFER_MAP_LENGTH, and GL_BUFFER_MAP_OFFSET return zero, and GL_BUFFER_BINDING returns zero.

NOTES

A buffer object can be created by calling glGenBuffers, glBindBuffer, and then glBufferData or glBufferStorage.

If target is GL_UNIFORM_BUFFER, GL_SHADER_STORAGE_BUFFER, or GL_ATOMIC_COUNTER_BUFFER, then the value of GL_BUFFER_BINDING is the name of the buffer object currently bound to the corresponding binding point.

If target is GL_TRANSFORM_FEEDBACK_BUFFER, then the value of GL_BUFFER_BINDING is the name of the buffer object currently bound to the transform feedback buffer binding point.

ERRORS

GL_INVALID_ENUM is generated if target or pname is not a recognized symbol.

GL_INVALID_OPERATION is generated if target is not a valid buffer target.
