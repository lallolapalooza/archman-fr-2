NOM

glDrawTransformFeedbackStream - rendu de primitives à l'aide d'un nombre dérivé d'un flux spécifié d'un objet de retour de transformation

SPÉCIFICATION C

void glDrawTransformFeedbackStream(GLenum mode, GLuint id, GLuint stream);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, et GL_PATCHES sont acceptées.

id

Spécifie le nom d'un objet de retour de transformation à partir duquel récupérer un nombre de primitives.

stream

Spécifie l'indice du flux de retour de transformation à partir duquel récupérer un nombre de primitives.

DESCRIPTION

glDrawTransformFeedbackStream dessine des primitives du type spécifié par mode en utilisant un nombre récupéré du flux de retour de transformation spécifié par stream de l'objet de retour de transformation spécifié par id. L'appel à glDrawTransformFeedbackStream est équivalent à l'appel de glDrawArrays() avec mode tel que spécifié, first défini à zéro, et count défini au nombre de sommets capturés sur le flux de sommets stream lors de la dernière fois où le retour de transformation était actif sur l'objet de retour de transformation nommé par id.

L'appel à glDrawTransformFeedback() est équivalent à l'appel de glDrawTransformFeedbackStream avec stream défini à zéro.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si id n'est pas le nom d'un objet de retour de transformation.

GL_INVALID_VALUE est généré si stream est supérieur ou égal à la valeur de GL_MAX_VERTEX_STREAMS.

GL_INVALID_OPERATION est généré si un objet de buffer non nul est lié à un tableau activé et que le magasin de données de l'objet de buffer est actuellement mappé.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si mode est GL_PATCHES et qu'aucun shader de contrôle de tessellation n'est actif.

GL_INVALID_OPERATION est généré si

glEndTransformFeedback n'a jamais été appelé tant que l'objet de retour de transformation nommé par id était lié.
