NOM

glutCopyColormap - copie la table des couleurs logique pour la couche en cours d'utilisation d'une fenêtre spécifiée vers la fenêtre courante.

SYNTAXE

void glutCopyColormap(int win);

ARGUMENTS

win
L'identifiant de la fenêtre à partir de laquelle copier la table des couleurs logique.

DESCRIPTION

glutCopyColormap copie (paresseusement si possible pour promouvoir le partage) la table des couleurs logique d'une fenêtre spécifiée vers la couche en cours d'utilisation de la fenêtre courante. La copie se fera du plan normal vers le plan normal ; ou de la surcouche vers la surcouche (jamais entre différentes couches). Une fois qu'une table des couleurs a été copiée, évitez de définir des cellules dans la table des couleurs avec glutSetColor, car cela forcera une copie réelle de la table des couleurs si elle a été précédemment copiée par référence. glutCopyColormap ne devrait être appelée que lorsque la fenêtre courante et la fenêtre win sont toutes deux des fenêtres à index de couleur.

EXEMPLE

Voici un exemple de la manière de créer deux fenêtres GLUT à index de couleur avec leurs tables de couleurs chargées identiquement et de telle sorte que les fenêtres partagent probablement la même table de couleurs :

  int win1, win2;
  glutInitDisplayMode(GLUT_INDEX);
  win1 = glutCreateWindow("première fenêtre à index de couleur");
  glutSetColor(0, 0.0, 0.0, 0.0);  /* noir */
  glutSetColor(1, 0.5, 0.5, 0.5);  /* gris */
  glutSetColor(2, 1.0, 1.0, 1.0);  /* blanc */
  glutSetColor(3, 1.0, 0.0, 0.0);  /* rouge */
  win2 = glutCreateWindow("seconde fenêtre à index de couleur");
  glutCopyColormap(win1);

VOIR AUSSI

glutSetColor, glutGetColor, glutCreateWindow
