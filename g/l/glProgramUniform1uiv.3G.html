NAME

glProgramUniform1uiv - set uniform block values

C SPECIFICATION

void glProgramUniform1uiv(GLint location, GLsizei count, const GLuint *value);

PARAMETERS

location
Specifies the uniform variable location.
count
Specifies the number of elements that are to be updated.
value
Specifies a pointer to an array of count values that will be used to update the specified uniform variable.

DESCRIPTION

glProgramUniform1uiv specifies the value of a single uniform variable or a uniform array when the program object containing the uniform variable is part of the currently active program.

glProgramUniform1uiv is used to set the value of a uniform variable of type uint[].

If the uniform variable indicated by location is not part of the active program, or if it is not of type uint[], the command is ignored.

location is the integer name of a uniform variable in the active program.

count is the number of elements to be written.

value points to the first element of an array of count uniform values to be downloaded to the uniform variable.

glProgramUniform1uiv is available for programs that are part of a program pipeline. It is also available for programs that are not part of a program pipeline, and if used in this way, the glProgramUniform... commands query the active program object.

NOTES

To query the location of a uniform variable, call glGetUniformLocation.

Uniform variables are immutable once they are set.

The commands glProgramUniform... update uniforms in the program object that is bound to the program pipeline stage corresponding to the program object specified by glUseProgramStages. If the program object was not specified by glUseProgramStages, the commands do not affect any uniforms.

The commands glProgramUniform... are part of the OpenGL 4.0 core profile. They may be available in earlier versions of OpenGL through extensions.

ERRORS

There are no errors generated by glProgramUniform1uiv.
