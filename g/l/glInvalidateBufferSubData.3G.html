NOM

glInvalidateBufferSubData - invalide une région du stockage de données d'un objet tampon

SPÉCIFICATION C

void glInvalidateBufferSubData(GLuint buffer, GLintptr offset, GLsizeiptr length);

PARAMÈTRES

buffer

Le nom d'un objet tampon, dont une sous-plage du stockage de données doit être invalidée.

offset

Le décalage dans le stockage de données du tampon du début de la plage à invalider.

length

La longueur de la plage dans le stockage de données du tampon à invalider.

DESCRIPTION

glInvalidateBufferSubData invalide tout ou partie du contenu du stockage de données d'un objet tampon. Après l'invalidation, le contenu de la plage spécifiée du stockage de données du tampon devient indéfini. Le début de la plage est donné par offset et sa taille est donnée par length, tous deux mesurés en unités machine de base.

ERREURS

GL_INVALID_VALUE est générée si offset ou length est négatif, ou si offset + length est supérieur à la valeur de GL_BUFFER_SIZE pour buffer.

GL_INVALID_VALUE est générée si buffer n'est pas le nom d'un objet tampon existant.

GL_INVALID_OPERATION est générée si une partie de buffer est actuellement mappée.

OBTIENT ASSOCIÉS

glGetBufferParameter() avec l'argument GL_BUFFER_SIZE
