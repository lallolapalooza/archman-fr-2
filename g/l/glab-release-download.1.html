NOM

glab-release-download - Télécharger les fichiers d'assets d'une release GitLab.

SYNTAXE

glab release download [options]

DESCRIPTION

Télécharger les fichiers d'assets d'une release GitLab.

Si aucune étiquette n'est spécifiée, télécharge les assets de la dernière release. Pour spécifier un nom de fichier à télécharger parmi les assets de la release, utilisez --asset-name. L'option --asset-name accepte les motifs glob.

OPTIONS

-n, --asset-name=[] Télécharger uniquement les assets dont le nom correspond ou un motif glob.

-D, --dir="." Répertoire où télécharger les assets de la release.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE_NOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Télécharger tous les assets de la dernière release
$ glab release download
# Télécharger tous les assets de l'étiquette de release spécifiée
$ glab release download v1.1.0
# Télécharger les assets dont les noms correspondent au motif glob
$ glab release download v1.10.1 --asset-name="*.tar.gz"
