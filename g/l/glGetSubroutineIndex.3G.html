GLGETSUBROUTINEINDEX(3G) [FIXME: manual] GLGETSUBROUTINEINDEX(3G)

NOM

glGetSubroutineIndex - récupère l'index d'un uniforme de sous-routine d'une étape de shader donnée au sein d'un programme

SPÉCIFICATION C

GLuint glGetSubroutineIndex(GLuint program, GLenum shadertype, const GLchar *name);

PARAMÈTRES

program

Spécifie le nom du programme contenant l'étape de shader.

shadertype

Spécifie l'étape de shader pour laquelle interroger l'index de l'uniforme de sous-routine. shadertype doit être l'une des valeurs suivantes : GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER.

name

Spécifie le nom de l'uniforme de sous-routine dont il faut interroger l'index.

DESCRIPTION

glGetSubroutineIndex renvoie l'index d'un uniforme de sous-routine au sein d'une étape de shader attachée à un objet programme. program contient le nom du programme auquel le shader est attaché. shadertype spécifie l'étape pour laquelle interroger l'index de la sous-routine du shader. name contient le nom terminé par null de l'uniforme de sous-routine dont il faut interroger le nom.

Si name n'est pas le nom d'un uniforme de sous-routine dans l'étape de shader, GL_INVALID_INDEX est renvoyé, mais aucune erreur n'est générée. Si name est le nom d'un uniforme de sous-routine dans l'étape de shader, une valeur comprise entre zéro et la valeur de GL_ACTIVE_SUBROUTINES moins un sera renvoyée. Les index de sous-routines sont attribués à l'aide d'entiers consécutifs dans la plage de zéro à la valeur de GL_ACTIVE_SUBROUTINES moins un pour l'étape de shader.

ERREURS

GL_INVALID_ENUM est généré si shadertype ou pname ne fait pas partie des valeurs acceptées.

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme existant.
