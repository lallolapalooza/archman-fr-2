NOM

glIsBuffer - déterminer si un nom correspond à un objet tampon

SPÉCIFICATION C

GLboolean glIsBuffer(GLuint buffer);

PARAMÈTRES

buffer

Spécifie une valeur qui peut être le nom d'un objet tampon.

DESCRIPTION

glIsBuffer renvoie GL_TRUE si buffer est actuellement le nom d'un objet tampon. Si buffer est zéro, ou s'il s'agit d'une valeur non nulle qui n'est pas actuellement le nom d'un objet tampon, ou si une erreur se produit, glIsBuffer renvoie GL_FALSE.

Un nom renvoyé par glGenBuffers(), mais non encore associé à un objet tampon en appelant glBindBuffer(), n'est pas le nom d'un objet tampon.
