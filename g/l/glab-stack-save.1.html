NOM

glab-stack-save - Sauvegarder votre progression dans un diff empilé. (EXPÉRIMENTAL)

SYNTAXE

glab stack save [flags]

DESCRIPTION

Sauvegarde votre progression actuelle avec un diff sur la pile.

Cette fonctionnalité est expérimentale. Elle peut être défectueuse ou supprimée sans préavis. En savoir plus sur ce que signifient les fonctionnalités expérimentales à l'https://docs.gitlab.com/policy/development_stages_support/

Utilisez les fonctionnalités expérimentales à vos propres risques.

OPTIONS

-d, --description="" Description du changement.

-m, --message="" Alias pour le flag de description.

OPTIONS INHERITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACEDE NOM/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab stack save added_file
$ glab stack save . -m "ajouté une fonction"
$ glab stack save -m "ajouté une fonction"
