NOM

glGetProgramResourceName - interroger le nom d'une ressource indexée dans un programme

SPÉCIFICATION C

void glGetProgramResourceName(GLuint program, GLenum programInterface, GLuint index, GLsizei bufSize, GLsizei * length, char * name);

PARAMÈTRES

program

Le nom d'un objet programme dont on veut interroger les ressources.

programInterface

Un jeton identifiant l'interface dans program contenant la ressource indexée.

index

L'index de la ressource dans programInterface de program.

bufSize

La taille du tableau de caractères dont l'adresse est donnée par name.

length

L'adresse d'une variable qui recevra la longueur du nom de la ressource.

name

L'adresse d'un tableau de caractères dans lequel sera écrit le nom de la ressource.

DESCRIPTION

glGetProgramResourceName récupère la chaîne de nom attribuée à la seule ressource active avec un index de index dans l'interface programInterface de l'objet programme program. index doit être inférieur au nombre d'entrées dans la liste des ressources actives pour programInterface.

program doit être le nom d'un objet programme existant. programInterface est le nom de l'interface dans program qui contient la ressource et doit être l'une des valeurs suivantes :

GL_UNIFORM

La requête cible l'ensemble des uniformes actifs dans program.

GL_UNIFORM_BLOCK

La requête cible l'ensemble des blocs uniformes actifs dans program.

GL_PROGRAM_INPUT

La requête cible l'ensemble des variables d'entrée actives utilisées par le premier stade du shader de program. Si program contient plusieurs stades de shader, les variables d'entrée d'un autre stade que le premier ne seront pas énumérées.

GL_PROGRAM_OUTPUT

La requête cible l'ensemble des variables de sortie actives produites par le dernier stade du shader de program. Si program contient plusieurs stades de shader, les variables de sortie d'un autre stade que le dernier ne seront pas énumérées.

GL_VERTEX_SUBROUTINE, GL_TESS_CONTROL_SUBROUTINE, GL_TESS_EVALUATION_SUBROUTINE, GL_GEOMETRY_SUBROUTINE, GL_FRAGMENT_SUBROUTINE, GL_COMPUTE_SUBROUTINE

La requête cible l'ensemble des sous-routines actives pour les stades de vertex, de contrôle de tessellation, d'évaluation de tessellation, de géométrie, de fragment et de calcul de program, respectivement.

GL_VERTEX_SUBROUTINE_UNIFORM, GL_TESS_CONTROL_SUBROUTINE_UNIFORM, GL_TESS_EVALUATION_SUBROUTINE_UNIFORM, GL_GEOMETRY_SUBROUTINE_UNIFORM, GL_FRAGMENT_SUBROUTINE_UNIFORM, GL_COMPUTE_SUBROUTINE_UNIFORM

La requête cible l'ensemble des variables uniformes de sous-routines actives utilisées par les stades de vertex, de contrôle de tessellation, d'évaluation de tessellation, de géométrie, de fragment et de calcul de program, respectivement.

GL_TRANSFORM_FEEDBACK_VARYING

La requête cible l'ensemble des variables de sortie du dernier stade non-fragment de program qui seraient capturées si le transform feedback était actif.

GL_BUFFER_VARIABLE

La requête cible l'ensemble des variables de tampon actives utilisées par program.

GL_SHADER_STORAGE_BLOCK

La requête cible l'ensemble des blocs de stockage de shader actifs utilisés par program.

La chaîne de nom attribuée à la ressource active identifiée par index est retournée sous forme de chaîne terminée par un caractère nul dans le tableau de caractères dont l'adresse est donnée dans name. Le nombre réel de caractères écrits dans name, hors terminateur nul, est retourné dans length. Si length est NULL, aucune longueur n'est retournée. Le nombre maximum de caractères pouvant être écrits dans name, y compris le terminateur nul, est spécifié par bufSize. Si la longueur de la chaîne de nom incluant le terminateur nul est supérieure à bufSize, les bufSize-1 premiers caractères de la chaîne de nom seront écrits dans name, suivis d'un terminateur nul. Si bufSize est zéro, aucune erreur ne sera générée mais aucun caractère ne sera écrit dans name. La longueur de la chaîne de nom la plus longue pour programInterface, y compris un terminateur nul, peut être interrogée en appelant glGetProgramInterface() avec un pname de GL_MAX_NAME_LENGTH.

ERREURS

GL_INVALID_ENUM est générée si programInterface n'est pas l'un des types d'interface acceptés.

GL_INVALID_VALUE est générée si progam n'est pas le nom d'un programme existant.

GL_INVALID_VALUE est générée si index est supérieur ou égal au nombre d'entrées dans la liste des ressources actives pour programInterface.

GL_INVALID_ENUM est générée si programInterface est GL_ATOMIC_COUNTER_BUFFER ou GL_TRANSFORM_FEEDBACK_BUFFER, car les ressources de compteurs atomiques actives et de tampons de transform feedback ne se voient pas attribuer de chaînes de nom.
