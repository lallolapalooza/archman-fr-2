NOM

glPushDebugGroup - insère un groupe de débogage nommé dans le flux de commandes

SPÉCIFICATION C

void glPushDebugGroup(GLenum source, GLuint id, GLsizei length, const char * message);

PARAMÈTRES

source

La source du message de débogage.

id

L'identifiant du message.

length

La longueur du message à envoyer au flux de sortie de débogage.

message

La chaîne de caractères contenant le message à envoyer au flux de sortie de débogage.

DESCRIPTION

glPushDebugGroup insère un groupe de débogage décrit par la chaîne message dans le flux de commandes. La valeur de id spécifie l'ID des messages générés. Le paramètre length contient le nombre de caractères dans message. Si length est négatif, on suppose que message contient une chaîne terminée par un caractère nul. Le message a la source et l'id spécifiés, le type GL_DEBUG_TYPE_PUSH_GROUP, et la sévérité GL_DEBUG_SEVERITY_NOTIFICATION. GL placera un nouveau groupe de débogage au sommet de la pile des groupes de débogage, qui héritera du contrôle du volume de sortie de débogage du groupe de débogage précédemment au sommet de la pile des groupes de débogage. Étant donné que les groupes de débogage sont strictement hiérarchiques, tout contrôle supplémentaire du volume de sortie de débogage ne s'appliquera qu'au sein du groupe de débogage actif et des groupes de débogage insérés au-dessus du groupe de débogage actif.

ERREURS

GL_INVALID_ENUM est généré si la valeur de source n'est ni GL_DEBUG_SOURCE_APPLICATION ni GL_DEBUG_SOURCE_THIRD_PARTY.

GL_INVALID_VALUE est généré si length est négatif et que le nombre de caractères dans message, hors le terminateur nul, n'est pas inférieur à la valeur de GL_MAX_DEBUG_MESSAGE_LENGTH.

ASSOCIÉES GETS

glGet() avec l'argument GL_MAX_DEBUG_MESSAGE_LENGTH.
