DESCRIPTIO

N

glBindBuffersRange lie un ensemble de count plages à partir de objets tampon dont les noms sont donnés dans le tableau buffers aux count points de liaison consécutifs à partir de l'index first du tableau de cibles spécifié par target. offsets spécifie l'adresse d'un tableau contenant count décalages de départ dans les tampons, et sizes spécifie l'adresse d'un tableau de count tailles des plages. Si buffers est NULL, alors offsets et sizes sont ignorés et glBindBuffersRange délie tous les tampons actuellement liés aux points de liaison référencés. En supposant qu'aucune erreur n'est générée, cela équivaut au pseudo-code suivant, qui appelle glBindBufferRange(), à l'exception que la cible non indexée target n'est pas modifiée par glBindBuffers

Range : 
    for (i = 0; i < count; i++) {
        if (buffers != NULL) {
            glBindBufferRange(target, first + i, buffers[i], offsets[i], sizes[i]);
        } else {
            glBindBufferRange(target, first + i, 0);
        }
}

Chaque entrée dans buffers, offsets, et sizes sera vérifiée individuellement et si elle est trouvée invalide, l'état pour cet index de liaison de tampon ne sera pas modifié et

une erreur sera générée. Cependant, l'état des autres indices de li
aison de tampon référencés par la commande sera toujours mis à jour.

S

GL_INVALID_OPERATION est généré si first + count est supérieur au nombre de points de liaison indexés spécifiques à la

cible.

existant.

GL_INVALID_VALUE est généré si une valeur dans offsets est inférieure à zéro ou si une valeur dans sizes est inférieure à

zéro.
