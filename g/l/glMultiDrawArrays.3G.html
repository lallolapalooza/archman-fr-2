NOM

glMultiDrawArrays - dessine plusieurs ensembles de primitives à partir de données de tableaux

SPÉCIFICATION C

void glMultiDrawArrays(GLenum mode, const GLint * first, const GLsizei * count, GLsizei drawcount);

PARAMÈTRES

mode

Spécifie le type de primitives à dessiner. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

first

Pointe vers un tableau d'indices de départ dans les tableaux activés.

count

Pointe vers un tableau du nombre d'indices à dessiner.

drawcount

Spécifie la taille de first et count

DESCRIPTION

glMultiDrawArrays spécifie plusieurs ensembles de primitives géométriques avec très peu d'appels de sous-routine. Au lieu d'appeler une procédure GL pour passer chaque sommet, normale, coordonnée de texture, indicateur d'arête ou couleur individuel, vous pouvez pré-spécifier des tableaux séparés de sommets, de normales et de couleurs et les utiliser pour construire une séquence de primitives avec un seul appel à glMultiDrawArrays.

glMultiDrawArrays se comporte de manière identique à glDrawArrays() sauf que drawcount plages distinctes d'éléments sont spécifiées à la place.

Lorsque glMultiDrawArrays est appelé, il utilise count éléments séquentiels de chaque tableau activé pour construire une séquence de primitives géométriques, en commençant par l'élément first. mode spécifie le type de primitives construites et comment les éléments du tableau construisent ces primitives.

Les attributs de sommet qui sont modifiés par glMultiDrawArrays ont une valeur indéterminée après le retour de glMultiDrawArrays. Les attributs qui ne sont pas modifiés restent bien définis.

NOTES

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_TRIANGLES_ADJACENCY ne sont disponibles que si la version de GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si drawcount est négatif.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé et que le magasin de données de l'objet tampon est actuellement mappé.
