NOM

glBindVertexArray - lier un objet tableau de sommets

SPÉCIFICATION C

void glBindVertexArray(GLuint array);

PARAMÈTRES

array

Spécifie le nom du tableau de sommets à lier.

DÉCRIPTION

glBindVertexArray lie l'objet tableau de sommets portant le nom array. array est le nom d'un objet tableau de sommets retourné précédemment par un appel à glGenVertexArrays(), ou zéro pour délier l'objet tableau de sommets existant.

Si aucun objet tableau de sommets avec le nom array n'existe, un est créé lors de la première liaison de array. Si la liaison réussit, aucun changement n'est apporté à l'état de l'objet tableau de sommets, et toute liaison précédente d'objet tableau de sommets est rompue.

ERREURS

GL_INVALID_OPERATION est générée si array n'est pas zéro ou le nom d'un objet tableau de sommets retourné précédemment par un appel à glGenVertexArrays().
