NOM

glCreateBuffers - créer des objets tampon

SPÉCIFICATION C

void glCreateBuffers(GLsizei n, GLuint *buffers);

PARAMÈTRES

n

Spécifie le nombre d'objets tampon à créer.

buffers

Spécifie un tableau dans lequel les noms des nouveaux objets tampon sont stockés.

DESCRIPTION

glCreateBuffers retourne n noms de tampon inutilisés précédemment dans buffers, chacun représentant un nouvel objet tampon initialisé comme s'il avait été lié à une cible non spécifiée.

ERREURS

GL_INVALID_VALUE est générée si n est négatif.
