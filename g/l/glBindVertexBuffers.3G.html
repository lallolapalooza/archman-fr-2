NOM

glBindVertexBuffers, glVertexArrayVertexBuffers - attacher plusieurs objets tampons à un objet de tableau de sommets

SPÉCIFICATION C

void glBindVertexBuffers(GLuintfirst, GLsizeicount, const GLuint *buffers, const GLintptr *offsets, const GLsizei *strides);

void glVertexArrayVertexBuffers(GLuintvaobj, GLuintfirst, GLsizeicount, const GLuint *buffers, const GLintptr *offsets, const GLsizei *strides);

PARAMÈTRES

vaobj

Spécifie le nom de l'objet de tableau de sommets pour glVertexArrayVertexBuffers.

first

Spécifie le premier point de liaison de tampon de sommets auquel un objet tampon doit être lié.

count

Spécifie le nombre de tampons à lier.

buffers

Spécifie l'adresse d'un tableau de noms d'objets tampons existants.

offsets

Spécifie l'adresse d'un tableau de décalages à associer aux points de liaison.

strides

Spécifie l'adresse d'un tableau de pas à associer aux points de liaison.

DESCRIPTION

glBindVertexBuffers et glVertexArrayVertexBuffers lient le stockage d'un tableau d'objets tampons existants à un nombre spécifié de points de liaison consécutifs de tampon de sommets dans un objet de tableau de sommets. Pour glBindVertexBuffers, l'objet de tableau de sommets est l'objet de tableau de sommets actuellement lié. Pour glVertexArrayVertexBuffers, vaobj est le nom de l'objet de tableau de sommets.

count objets tampons existants sont liés aux points de liaison de tampon de sommets numérotés $first$ à $first + count - 1$. Si buffers n'est pas NULL, il spécifie un tableau de count valeurs, dont chacune doit être zéro ou le nom d'un objet tampon existant. offsets et strides spécifient des tableaux de count valeurs indiquant le décalage du premier élément et le pas entre les éléments dans chaque tampon, respectivement. Si buffers est NULL, chaque point de liaison de tampon de sommets affecté de $first$ à $first + count - 1$ sera réinitialisé pour n'avoir aucun objet tampon lié. Dans ce cas, les décalages et les pas associés aux points de liaison sont définis sur des valeurs par défaut, en ignorant offsets et strides.

glBindVertexBuffers est équivalent (en supposant qu'aucune erreur n'est générée) à :

    for (i = 0; i < count; i++) {
        if (buffers == NULL) {
            glBindVertexBuffer(first + i, 0, 0, 16);
        } else {
            glBindVertexBuffer(first + i, buffers[i], offsets[i], strides[i]);
        }
    }

sauf que les tampons ne seront pas créés s'ils n'existent pas.

glVertexArrayVertexBuffers est équivalent au pseudocode ci-dessus, mais en remplaçant glBindVertexBuffers(args) par glVertexArrayVertexBuffers(vaobj, args).

Les valeurs spécifiées dans buffers, offsets, et strides seront vérifiées séparément pour chaque point de liaison de tampon de sommets. Lorsqu'une valeur pour un point de liaison de tampon de sommets spécifique est invalide, l'état de ce point de liaison restera inchangé et une erreur sera générée. Cependant, l'état des autres points de liaison de tampon de sommets sera toujours modifié si leurs valeurs correspondantes sont valides.

ERREURS

GL_INVALID_OPERATION est généré par glBindVertexBuffers si aucun objet de tableau de sommets n'est lié.

GL_INVALID_OPERATION est généré par glVertexArrayVertexBuffers si vaobj n'est pas le nom de l'objet de tableau de sommets.

GL_INVALID_OPERATION est généré si $first + count$ est supérieur à la valeur de GL_MAX_VERTEX_ATTRIB_BINDINGS.

GL_INVALID_OPERATION est généré si une valeur quelconque dans buffers n'est pas zéro ou le nom d'un objet tampon existant.

GL_INVALID_VALUE est généré si une valeur quelconque dans offsets ou strides est négative, ou si une valeur stride est supérieure à la valeur de GL_MAX_VERTEX_ATTRIB_STRIDE.

    NAME

    glBindVertexBuffers — binds one or more buffer objects to a vertex buffer binding point

    SYNOPSIS

    void glBindVertexBuffers(GLint first​, GLsizei count​, const GLuint *buffers​, const GLintptr *offsets​, const GLsizei *strides​);

    PARAMETERS

    first

    Specifies the first vertex buffer binding point to which the buffer objects in buffers will be bound.

    count

    Specifies the number of buffer objects to bind.

    buffers

    Specifies an array of buffer objects to be bound.

    offsets

    Specifies an array of byte offsets into the buffer objects specified by buffers.

    strides

    Specifies an array of strides, in bytes, between elements in the buffer objects specified by buffers.

    DESCRIPTION

    glBindVertexBuffers binds an array of buffer objects to an array of vertex buffer binding points. first specifies the index of the first vertex buffer binding point to be modified. count specifies the number of vertex buffer binding points to be modified. buffers is an array of buffer object names. offsets is an array of byte offsets. strides is an array of strides.

    When a vertex buffer binding point is updated, the buffer object named by the corresponding element of buffers is bound to that binding point. If buffers[i] is zero, then the binding for the vertex buffer binding point first + i is reset, and the corresponding elements of offsets and strides are ignored. Otherwise, the specified buffer object is bound to the vertex buffer binding point, and the offset and stride are set to the values specified by offsets[i] and strides[i], respectively.

    The vertex buffer binding points are indexed from zero. If first + count is greater than the value of GL_MAX_VERTEX_ATTRIBS, then an INVALID_OPERATION error is generated.

    This command is equivalent to calling glBindBufferRange multiple times, once for each binding point. For example, calling glBindVertexBuffers(first, count, buffers, offsets, strides) is equivalent to calling glBindBufferRange(GL_VERTEX_ATTRIB_BINDING_BUFFER, first + i, buffers[i], offsets[i], strides[i]) for i from 0 to count-1.

    ERRORS

    INVALID_OPERATION is generated if first + count is greater than GL_MAX_VERTEX_ATTRIBS.

    INVALID_VALUE is generated if any of the values in strides are negative.

    VERSION SUPPORT

    API Version Feature
    4.4 glBindVertexBuffers
