NOM

glDrawElementsBaseVertex - dessine des primitives à partir de données de tableau avec un décalage par élément

SPÉCIFICATION C

void glDrawElementsBaseVertex(GLenum mode, GLsizei count, GLenum type, void *indices, GLint basevertex);

PARAMÈTRES

mode

Spécifie le type de primitives à dessiner. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_PATCHES sont acceptés.

count

Spécifie le nombre d'éléments à dessiner.

type

Spécifie le type des valeurs dans les indices. Doit être l'une des valeurs GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, ou GL_UNSIGNED_INT.

indices

Spécifie un pointeur vers l'emplacement où les indices sont stockés.

basevertex

Spécifie une constante qui doit être ajoutée à chaque élément de indices lors du choix des éléments des tableaux de sommets activés.

DESCRIPTION

glDrawElementsBaseVertex se comporte de manière identique à glDrawElements() sauf que le i-ème élément transféré par l'appel de dessin correspondant sera pris de l'élément indices[i] + basevertex de chaque tableau activé. Si la valeur résultante est supérieure à la valeur maximale représentable par type, c'est comme si le calcul était converti en entiers non signés 32 bits (avec enroulement en cas de dépassement). Le comportement est indéfini si la somme est négative.

NOTES

glDrawElementsBaseVertex n'est pris en charge que si la version de GL est 3.2 ou supérieure, ou si l'extension ARB_draw_elements_base_vertex est prise en charge.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si count est négatif.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si un nom d'objet de tampon non nul est lié à un tableau activé ou au tableau d'éléments et que le magasin de données de l'objet de tampon est actuellement mappé.
