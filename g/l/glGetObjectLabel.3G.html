NOM

glGetObjectLabel - récupérer l'étiquette d'un objet nommé identifié dans un espace de noms

SPÉCIFICATION C

void glGetObjectLabel(GLenum identifier, GLuint name, GLsizei bufSize, GLsizei * length, char * label);

PARAMÈTRES

identifier

L'espace de noms à partir duquel le nom de l'objet est alloué.

name

Le nom de l'objet dont l'étiquette doit être récupérée.

bufSize

La longueur du tampon dont l'adresse est dans label.

length

L'adresse d'une variable pour recevoir la longueur de l'étiquette de l'objet.

label

L'adresse d'une chaîne qui recevra l'étiquette de l'objet.

DESCRIPTION

glGetObjectLabel récupère l'étiquette de l'objet identifié par name dans l'espace de noms donné par identifier. identifier doit être l'un des éléments suivants : GL_BUFFER, GL_SHADER, GL_PROGRAM, GL_VERTEX_ARRAY, GL_QUERY, GL_PROGRAM_PIPELINE, GL_TRANSFORM_FEEDBACK, GL_SAMPLER, GL_TEXTURE, GL_RENDERBUFFER, GL_FRAMEBUFFER, pour indiquer l'espace de noms contenant les noms des tampons, shaders, programmes, objets de tableau de sommets, objets de requête, pipelines de programme, objets de feedback de transformation, échantillonneurs, textures, tampons de rendu et tampons d'images, respectivement.

label est l'adresse d'une chaîne qui sera utilisée pour stocker l'étiquette de l'objet. bufSize spécifie le nombre de caractères dans le tableau identifié par label. length contient l'adresse d'une variable qui recevra le nombre de caractères dans l'étiquette de l'objet. Si length est NULL, alors il est ignoré et aucune donnée n'est écrite. De même, si label est NULL, ou si bufSize est zéro, alors aucune donnée n'est écrite dans label.

ERREURS

GL_INVALID_ENUM est généré si identifier n'est pas l'un des types d'objets acceptés.

GL_INVALID_OPERATION est généré si name n'est pas le nom d'un objet existant du type spécifié par identifier.

GL_INVALID_VALUE est généré si bufSize est zéro.

Si non NULL, length et label doivent être des adresses auxquelles le client a un accès en écriture, sinon un comportement indéfini, y compris la terminaison du processus, peut se produire.

GETS ASSOCIÉS

glGet() avec l'argument GL_MAX_LABEL_LENGTH.
