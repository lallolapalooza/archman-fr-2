NOM

glib-genmarshal - utilitaire de génération de code de marshalling C pour les fermetures GLib

SYNOPSIS

glib-genmarshal [OPTION…] [FICHIER…]

DESCRIPTION

glib-genmarshal est un petit utilitaire qui génère du code de marshalling C pour les fonctions de rappel du mécanisme GClosure de la sous-bibliothèque GObject de GLib. Les fonctions de marshalling ont une signature standard ; elles reçoivent la fermeture appelante, un tableau de structures de valeurs contenant les paramètres de la fonction de rappel et une structure de valeur pour la valeur de retour du rappel. Le marshaller est ensuite responsable d'appeler la fonction C correspondante de la fermeture avec tous les paramètres sur la pile et de récupérer sa valeur de retour.

glib-genmarshal prend en entrée une liste de marshallers à générer. La liste de marshallers est soit lue depuis les fichiers passés en arguments supplémentaires sur la ligne de commande ; soit depuis l'entrée standard, en utilisant - comme fichier d'entrée.

FORMAT DE LA LISTE DE MARSHALLERS

Les listes de marshallers sont traitées ligne par ligne ; une ligne peut contenir un commentaire sous la forme :

# ceci est un commentaire

ou une spécification de marshaller sous la forme :

RTYPE:PTYPE
RTYPE:PTYPE,PTYPE
RTYPE:PTYPE,PTYPE,PTYPE
…

La partie RTYPE spécifie le type de retour du rappel et les instances PTYPE à droite du deux-points spécifient la liste des paramètres du rappel, à l'exception des premier et dernier arguments qui sont toujours des pointeurs.

TYPES DE PARAMÈTRES

Actuellement, les types suivants sont pris en charge :

VOID

Indique l'absence de type de retour, ou l'absence de paramètres supplémentaires. Si VOID est utilisé comme liste de paramètres, aucun paramètre supplémentaire ne peut être présent.

BOOLEAN

Pour les types booléens (gboolean).

CHAR

Pour les types char signés (gchar).

UCHAR

Pour les types char non signés (guchar).

INT

Pour les types entiers signés (gint).

UINT

Pour les types entiers non signés (guint).

LONG

Pour les types long signés (glong).

ULONG

Pour les types long non signés (gulong).

INT64

Pour les types entiers 64 bits signés (gint64).

UINT64

Pour les types entiers 64 bits non signés (guint64).

ENUM

Pour les types énumération (gint).

FLAGS

Pour les types énumération de drapeaux (guint).

FLOAT

Pour les types flottants simple précision (gfloat).

DOUBLE

Pour les types flottants double précision (gdouble).

STRING

Pour les types chaîne (gchar*).

BOXED

Pour les types boxed (anonymes mais comptés par référence) (GBoxed*).

PARAM

Pour GParamSpec ou les types dérivés (GParamSpec*).

POINTER

Pour les types pointeur anonymes (gpointer).

OBJECT

Pour GObject ou les types dérivés (GObject*).

VARIANT

Pour les types GVariant (GVariant*).

NONE

Alias obsolète pour VOID.

BOOL

Alias obsolète pour BOOLEAN.

OPTIONS

--header

Génère le contenu du fichier d'en-tête des marshallers. Cette option est mutuellement exclusive avec l'option --body .

--body

Génère le contenu du fichier de code C des marshallers. Cette option est mutuellement exclusive avec l'option --header .

--prefix <PRÉFIXE>

Spécifie le préfixe des marshallers. Le préfixe par défaut est g_cclosure_user_marshal.

--skip-source

Ignore les remarques d'emplacement source dans les commentaires générés.

--stdinc

Utilise les marshallers standard de la bibliothèque GObject et inclut glib-object.h dans les fichiers d'en-tête générés. Cette option est mutuellement exclusive avec l'option --nostdinc .

--nostdinc

N'utilise pas les marshallers standard de la bibliothèque GObject et ignore la directive d'inclusion glib-object.h dans les fichiers d'en-tête générés. Cette option est mutuellement exclusive avec l'option --stdinc .

--internal

Marque les fonctions générées comme internes, en utilisant G_GNUC_INTERNAL.

-valist-marshallers

Génère des marshallers valist , pour une utilisation avec g_signal_set_va_marshaller().

-v, --version

Affiche les informations de version et quitte.

--g-fatal-warnings

Rend les avertissements fatals. C'est-à-dire, quitte immédiatement dès qu'un avertissement se produit.

-h, --help

Affiche une aide brève et quitte.

--output <FICHIER>

Écrit la sortie dans FICHIER au lieu de la sortie standard.

--prototypes

Génère les prototypes de fonctions avant la définition de la fonction dans le fichier source C, afin d'éviter l'avertissement du compilateur missing-prototypes . Cette option n'est utile que lorsque l'option --body est utilisée.

--pragma-once

Utilise le pragma once au lieu d'un garde d'en-tête de style ancien lors de la génération du fichier d'en-tête C. Cette option n'est utile que lorsque l'option --header est utilisée.

--include-header <EN-TÊTE>

Ajoute une directive #include pour le fichier donné dans le fichier source C. Cette option n'est utile que lorsque l'option --body est utilisée.

-D <SYMBOL>[=<VALEUR>]

Ajoute une directive de préprocesseur C #define pour SYMBOL et sa VALEURdonnée, ou "1" si la valeur n'est pas définie. Vous pouvez utiliser cette option plusieurs fois ; si vous le faites, tous les symboles seront définis dans le même ordre donné sur la ligne de commande, avant les symboles indéfinis à l'aide de l'option -U . Cette option n'est utile que lorsque l'option --body est utilisée.

-U <SYMBOL>

Ajoute une directive de préprocesseur C #undef pour indéfinir le SYMBOLdonné. Vous pouvez utiliser cette option plusieurs fois ; si vous le faites, tous les symboles seront indéfinis dans le même ordre donné sur la ligne de commande, après les symboles définis à l'aide de l'option -D . Cette option n'est utile que lorsque l'option --body est utilisée.

--quiet

Minimise la sortie de glib-genmarshal, en n'affichant que les avertissements et les erreurs. Cette option est mutuellement exclusive avec l'option --verbose .

--verbose

Augmente le niveau de verbosité de glib-genmarshal, en affichant des informations de débogage. Cette option est mutuellement exclusive avec l'option --quiet .

UTILISATION DE GLIB-GENMARSHAL AVEC MESON

Meson prend en charge la génération de marshallers de fermetures à l'aide de glib-genmarshal directement dans son module gnome .

Dans votre fichier meson.build , vous appellerez généralement la méthode gnome.genmarshal() avec la liste des sources des marshallers à générer :

gnome = import('gnome')
marshal_files = gnome.genmarshal('marshal',
  sources: 'marshal.list',
  internal: true,
)

La variable marshal_files contiendra un tableau de deux éléments dans l'ordre suivant :

  • une cible de compilation pour le fichier source
  • une cible de compilation pour le fichier d'en-tête

Vous devez utiliser les objets retournés pour fournir une dépendance à toutes les autres cibles de compilation qui référencent le fichier source ou le fichier d'en-tête ; par exemple, si vous utilisez la source pour construire une bibliothèque :

mainlib = library('project',
  sources: project_sources + marshal_files,
  …
)

De plus, si vous incluez le fichier d'en-tête généré dans une cible de compilation qui dépend de la bibliothèque que vous venez de construire, vous devez vous assurer que la dépendance interne inclut l'en-tête généré en tant que fichier source requis :

mainlib_dep = declare_dependency(sources: marshal_files[1], link_with: mainlib)

Vous ne devez pas inclure le fichier source généré, sinon il sera compilé séparément pour chaque cible qui en dépend, provoquant des échecs de compilation. Pour en savoir plus sur la raison pour laquelle tout cela est nécessaire, veuillez consulter l'entrée correspondante de la FAQ de Meson https://mesonbuild.com/FAQ.html#how-do-i-tell-meson-that-my-sources-use-generated-headers.

Pour plus d'informations sur l'utilisation de la méthode, consultez la documentation de Meson https://mesonbuild.com/Gnome-module.html#gnomegenmarshal pour gnome.genmarshal().

UTILISATION DE GLIB-GENMARSHAL AVEC AUTOTOOLS

Afin d'utiliser glib-genmarshal dans votre projet lorsque vous utilisez Autotools comme système de build, vous devrez d'abord modifier votre fichier configure.ac pour vous assurer de trouver la commande appropriée en utilisant pkg-config, de la même manière que vous découvrez les options du compilateur et de l'éditeur de liens pour GLib :

PKG_PROG_PKG_CONFIG([0.28])
PKG_CHECK_VAR([GLIB_GENMARSHAL], [glib-2.0], [glib_genmarshal])

Dans votre fichier Makefile.am , vous aurez généralement besoin de règles très simples pour générer les fichiers C nécessaires à la compilation :

marshal.h: marshal.list
        $(AM_V_GEN)$(GLIB_GENMARSHAL) \
                --header \
                --output=$@ \
                $<
marshal.c: marshal.list marshal.h
        $(AM_V_GEN)$(GLIB_GENMARSHAL) \
                --include-header=marshal.h \
                --body \
                --output=$@ \
                $<
BUILT_SOURCES += marshal.h marshal.c
CLEANFILES += marshal.h marshal.c
EXTRA_DIST += marshal.list

Dans l'exemple ci-dessus, la première règle génère le fichier d'en-tête et dépend d'un fichier marshal.list afin de régénérer le résultat si la liste des marshallers est mise à jour. La deuxième règle génère le fichier source pour le même marshal.listet inclut le fichier généré par la règle de l'en-tête.

EXEMPLE

Pour générer des marshallers pour les fonctions de rappel suivantes :

void   foo (gpointer data1,
            gpointer data2);
void   bar (gpointer data1,
            gint     param1,
            gpointer data2);
gfloat baz (gpointer data1,
            gboolean param1,
            guchar   param2,
            gpointer data2);

Le fichier marshaller.list doit ressembler à ceci :

VOID:VOID
VOID:INT
FLOAT:BOOLEAN,UCHAR

et vous appelez glib-genmarshal comme ceci :

glib-genmarshal --header marshaller.list > marshaller.h
glib-genmarshal --body marshaller.list > marshaller.c

Les marshallers générés ont les arguments encodés dans leur nom de fonction. Pour cette liste particulière, ils sont :

g_cclosure_user_marshal_VOID__VOID(...),
g_cclosure_user_marshal_VOID__INT(...),
g_cclosure_user_marshal_FLOAT__BOOLEAN_UCHAR(...).

Ils peuvent être utilisés directement pour les GClosures ou être passés en tant qu'argument GSignalCMarshaller c_marshaller lors de la création de signaux :

GClosure *cc_foo, *cc_bar, *cc_baz;
cc_foo = g_cclosure_new (NULL, foo, NULL);
g_closure_set_marshal (cc_foo, g_cclosure_user_marshal_VOID__VOID);
cc_bar = g_cclosure_new (NULL, bar, NULL);
g_closure_set_marshal (cc_bar, g_cclosure_user_marshal_VOID__INT);
cc_baz = g_cclosure_new (NULL, baz, NULL);
g_closure_set_marshal (cc_baz, g_cclosure_user_marshal_FLOAT__BOOLEAN_UCHAR);
