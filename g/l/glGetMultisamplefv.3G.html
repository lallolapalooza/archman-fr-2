NOM

glGetMultisamplefv - récupérer l'emplacement d'un échantillon

SPÉCIFICATION EN C

void glGetMultisamplefv(GLenum pname, GLuint index, GLfloat *val);

PARAMÈTRES

pname

Spécifie le nom du paramètre d'échantillon. pname doit être GL_SAMPLE_POSITION.

index

Spécifie l'index de l'échantillon dont on veut interroger la position.

val

Spécifie l'adresse d'un tableau qui recevra la position de l'échantillon.

DESCRIPTION

glGetMultisamplefv interroge l'emplacement d'un échantillon donné. pname spécifie le paramètre d'échantillon à récupérer et doit être GL_SAMPLE_POSITION. index correspond à l'échantillon pour lequel l'emplacement doit être retourné. L'emplacement de l'échantillon est retourné sous forme de deux valeurs flottantes dans val[0] et val[1], chacune comprise entre 0 et 1, correspondant respectivement aux emplacements x et y dans l'espace pixel GL de cet échantillon. (0.5, 0.5) correspond au centre du pixel. index doit être compris entre zéro et la valeur de GL_SAMPLES moins un.

Si le mode multisampling n'a pas d'emplacements d'échantillons fixes, les valeurs retournées peuvent seulement refléter les emplacements des échantillons à l'intérieur de certains pixels.

ERREURS

GL_INVALID_ENUM est généré si pname n'est pas GL_SAMPLE_POSITION.

GL_INVALID_VALUE est généré si index est supérieur ou égal à la valeur de GL_SAMPLES.
