NOM

glutDeviceGet - récupère les informations des périphériques GLUT représentées par des entiers.

SYNTAXE

int glutDeviceGet(GLenum info);

ARGUMENTS

info
Nom de l'information du périphérique à récupérer.
GLUT_HAS_KEYBOARD
Non nul si un clavier est disponible ; nul s'il n'est pas disponible. Pour la plupart des implémentations GLUT, un clavier peut être supposé.
GLUT_HAS_MOUSE
Non nul si une souris est disponible ; nul si elle n'est pas disponible. Pour la plupart des implémentations GLUT, une souris peut être supposée.
GLUT_HAS_SPACEBALL
Non nul si un Spaceball est disponible ; nul s'il n'est pas disponible.
GLUT_HAS_DIAL_AND_BUTTON_BOX
Non nul si une boîte de potentiomètres et boutons est disponible ; nulle si elle n'est pas disponible.
GLUT_HAS_TABLET
Non nul si une tablette graphique est disponible ; nulle si elle n'est pas disponible.
GLUT_NUM_MOUSE_BUTTONS
Nombre de boutons supportés par la souris. Si aucune souris n'est supportée, zéro est retourné.
GLUT_NUM_SPACEBALL_BUTTONS
Nombre de boutons supportés par le Spaceball. Si aucun Spaceball n'est supporté, zéro est retourné.
GLUT_NUM_BUTTON_BOX_BUTTONS
Nombre de boutons supportés par le périphérique de boîte de potentiomètres et boutons. Si aucun périphérique de boîte de potentiomètres et boutons n'est supporté, zéro est retourné.
GLUT_NUM_DIALS
Nombre de potentiomètres supportés par le périphérique de boîte de potentiomètres et boutons. Si aucun périphérique de boîte de potentiomètres et boutons n'est supporté, zéro est retourné.
GLUT_NUM_TABLET_BUTTONS
Nombre de boutons supportés par la tablette graphique. Si aucune tablette graphique n'est supportée, zéro est retourné.
GLUT_DEVICE_IGNORE_KEY_REPEAT
Retourne vrai si les touches répétées automatiquement de la fenêtre courante sont ignorées. Cet état est contrôlé par glutIgnoreKeyRepeat.
GLUT_DEVICE_KEY_REPEAT
L'état global de répétition des touches du système de fenêtrage. Retourne soit GLUT_KEY_REPEAT_OFF, GLUT_KEY_REPEAT_ON, ou GLUT_KEY_REPEAT_DEFAULT. Ceci ne retournera pas nécessairement la valeur passée en dernier à glutSetKeyRepeat.
GLUT_JOYSTICK_POLL_RATE
Retourne le taux d'interrogation du joystick de la fenêtre courante tel que défini par glutJoystickFunc. Si aucun joystick n'est supporté, le taux d'interrogation sera toujours zéro. Le taux d'interrogation du joystick retournera également zéro si le taux d'interrogation spécifié en dernier à glutJoystickFunc est négatif ou si un callback NULL a été enregistré.
GLUT_HAS_JOYSTICK
Non nul si un joystick est disponible ; nul s'il n'est pas disponible.
GLUT_JOYSTICK_BUTTONS
Nombre de boutons supportés par le joystick. Si aucun joystick n'est supporté, zéro est retourné.
GLUT_JOYSTICK_AXES
Nombre d'axes supportés par le joystick. Si aucun joystick n'est supporté, zéro est retourné.

DESCRIPTION

glutDeviceGet récupère les informations des périphériques GLUT représentées par des entiers. Le paramètre info détermine le type d'informations du périphérique à retourner. Demander des informations sur un nom de périphérique GLUT invalide retourne moins un.

NOTES D'IMPLÉMENTATION X

L'implémentation actuelle utilise l'extension d'entrée X pour reconnaître les périphériques Spaceball, tablette graphique et boîte de potentiomètres et boutons de SGI.

NOTES D'IMPLÉMENTATION WIN32

GLUT_DEVICE_KEY_REPEAT retourne toujours GLUT_KEY_REPEAT_ON.

VOIR AUSSI

glutGet, glutKeyboardFunc, glutMouseFunc, glutSpaceballMotion, glutTabletMotionFunc, glutTabletButtonFunc, glutDialsFunc, glutButtonBoxFunc, glutIgnoreKeyRepeat, glutSetKeyRepeat, glutJoystickFunc
