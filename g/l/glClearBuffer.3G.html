NOM

glClearBuffer - efface des tampons spécifiés.

SPÉCIFICATION C

void glClearBufferiv(GLenum buffer, GLint drawbuffer, const GLint *value);
void glClearBufferuiv(GLenum buffer, GLint drawbuffer, const GLuint *value);
void glClearBufferfv(GLenum buffer, GLint drawbuffer, const GLfloat *value);
void glClearBufferfi(GLenum buffer, GLint drawbuffer, GLfloat depth, GLint stencil);

PARAMETRES

buffer
Spécifie le tampon à effacer.
drawbuffer
Spécifie le numéro du tampon de dessin s'il s'agit du tampon de couleur.
value
Indique la valeur à utiliser pour effacer le tampon.
depth
Indique la valeur de profondeur à utiliser pour effacer le tampon de profondeur.
stencil
Indique la valeur de gabarit à utiliser pour effacer le tampon de gabarit.

DESCRIPTION

Ces fonctions effacent les tampons spécifiés dans le contexte OpenGL courant.

La fonction glClearBufferfv efface le tampon de couleur spécifié par buffer et drawbuffer avec les valeurs dans value.

La fonction glClearBufferiv efface le tampon de couleur spécifié par buffer et drawbuffer avec les valeurs entières dans value.

La fonction glClearBufferuiv efface le tampon de couleur spécifié par buffer et drawbuffer avec les valeurs entières non signées dans value.

La fonction glClearBufferfi efface le tampon de profondeur spécifié par buffer avec la valeur depth et le tampon de gabarit spécifié par buffer avec la valeur stencil.

ERREURS

Des erreurs appropriées seront générées si les tampons spécifiés ne sont pas valides ou si les types de données ne correspondent pas aux formats des tampons.

SUPPORT DE VERSION

Les fonctions glClearBufferfv, glClearBufferiv et glClearBufferuiv sont disponibles à partir de la version 3.0 d'OpenGL.

La fonction glClearBufferfi est disponible à partir de la version 4.4 d'OpenGL.

Les fonctions glClearNamedFramebufferfv, glClearNamedFramebufferiv, glClearNamedFramebufferuiv et glClearNamedFramebufferfi sont disponibles à partir de la version 4.4 d'OpenGL.
