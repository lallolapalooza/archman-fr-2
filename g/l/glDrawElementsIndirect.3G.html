DESCRIPTIO

N

glDrawElementsIndirect spécifie plusieurs primitives géométriques indexées avec très peu d'appels de sous-routine. glDrawElementsIndirect se comporte de manière similaire à glDrawElementsInstancedBaseVertexBaseInstance(), sauf que les paramètres de glDrawElementsInstancedBaseVertexBaseInstance() sont stockés en mémoire à l'adresse donnée par indirect

.

Les paramètres adressés par indirect sont regroupés dans une structure de la forme (en C)

: 
    typedef  struct {
        uint  count;
        uint  instanceCount;
        uint  firstIndex;
        int  baseVertex;
        uint  baseInstance;
    } DrawElementsIndirectComman
d
;

glDrawElementsIndirect est équivalent à

: 
    void glDrawElementsIndirect(GLenum mode, GLenum type, const void * indirect) {
        const DrawElementsIndirectCommand *cmd  = (const DrawElementsIndirectCommand *)indirect;
        glDrawElementsInstancedBaseVertexBaseInstance(mode,
                                                      cmd->count,
                                                      type,
                                                      cmd->firstIndex * taille-du-type,
                                                      cmd->instanceCount,
                                                      cmd->baseVertex,
                                                      cmd->baseInstance);
}

Si un tampon est lié à la liaison GL_DRAW_INDIRECT_BUFFER au moment de l'appel à glDrawElementsIndirect, indirect est interprété comme un décalage, en unités machine de base, dans ce tampon et les données de paramètres sont lues depuis le tampon plutôt que depuis la mémoire

client.

Notez que les indices stockés en mémoire client ne sont pas pris en charge. Si aucun tampon n'est lié à la liaison GL_ELEMENT_ARRAY_BUFFER, une erreur sera

générée.

Les résultats de l'opération sont indéfinis si le membre reservedMustBeZero de la structure de paramètres est non nul. Cependant, aucune erreur n'est générée dans ce

cas.

Les attributs de sommet modifiés par glDrawElementsIndirect ont une valeur indéfinie après le retour de glDrawElementsIndirect. Les attributs qui ne

sont pas modifiés
restent bien définis.

NOTE

S

Le membre baseInstance de la structure DrawElementsIndirectCommand n'est défini que si la version du GL est 4.2 ou supérieure. Pour les versions du GL inférieures à 4.2, ce paramèt

re est présent mais est réservé et devrait être défini à zéro. Sur les
versions antérieures du GL, le comportement est indéfini s'il est non nul.

ERREU

R

GL_INVALID_ENUM est généré si mode n'est pas une valeur

acceptée.

GL_INVALID_OPERATION est généré si zéro est lié à la liaison GL_ELEMENT_ARRAY_BUFFER, ou si le magasin de données d'un tel tampon est actuellement

mappé.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé ou à la liaison GL_DRAW_INDIRECT_BUFFER et que le magasin de données de l'objet tampon est actuellement

mappé.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement

installé.

GL_INVALID_OPERATION est généré si mode est GL_PATCHES et qu'aucun shader de co
