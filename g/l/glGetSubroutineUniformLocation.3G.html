NOM

glGetSubroutineUniformLocation - récupère l'emplacement d'un uniforme de sous-routine d'une étape de shader donnée au sein d'un programme

SPÉCIFICATION C

GLint glGetSubroutineUniformLocation(GLuint program, GLenum shadertype, const GLchar *name);

PARAMÈTRES

program

Spécifie le nom du programme contenant l'étape de shader.

shadertype

Spécifie l'étape de shader à partir de laquelle interroger l'indice d'uniforme de sous-routine. shadertype doit être l'un des suivants : GL_VERTEX_SHADER, GL_TESS_CONTROL_SHADER, GL_TESS_EVALUATION_SHADER, GL_GEOMETRY_SHADER ou GL_FRAGMENT_SHADER.

name

Spécifie le nom de la variable uniforme de sous-routine dont il faut interroger l'indice.

DESCRIPTION

glGetSubroutineUniformLocation renvoie l'emplacement de la variable uniforme de sous-routine name dans l'étape de shader de type shadertype attachée au program, avec un comportement par ailleurs identique à celui de glGetUniformLocation().

Si name n'est pas le nom d'une uniforme de sous-routine dans l'étape de shader, -1 est renvoyé, mais aucune erreur n'est générée. Si name est le nom d'une uniforme de sous-routine dans l'étape de shader, une valeur comprise entre zéro et la valeur de GL_ACTIVE_SUBROUTINE_LOCATIONS moins un sera renvoyée. Les emplacements de sous-routines sont assignés en utilisant des entiers consécutifs dans la plage de zéro à la valeur de GL_ACTIVE_SUBROUTINE_LOCATIONS moins un pour l'étape de shader. Pour les uniformes de sous-routines actives déclarées comme des tableaux, les éléments du tableau déclarés se voient attribuer des emplacements consécutifs.

ERREURS

GL_INVALID_ENUM est généré si shadertype ou pname ne font pas partie des valeurs acceptées.

GL_INVALID_VALUE est généré si program n'est pas le nom d'un objet programme existant.
