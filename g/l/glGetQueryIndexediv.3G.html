NOM

glGetQueryIndexediv - renvoie les paramètres d'une cible de requête indexée

SPÉCIFICATION C

void glGetQueryIndexediv(GLenum target, GLuint index, GLenum pname, GLint * params);

PARAMÈTRES

target

Spécifie une cible d'objet de requête. Doit être GL_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED, GL_ANY_SAMPLES_PASSED_CONSERVATIVE GL_PRIMITIVES_GENERATED, GL_TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN, GL_TIME_ELAPSED, ou GL_TIMESTAMP.

index

Spécifie l'index de la cible d'objet de requête.

pname

Spécifie le nom symbolique d'un paramètre de cible d'objet de requête. Les valeurs acceptées sont GL_CURRENT_QUERY ou GL_QUERY_COUNTER_BITS.

params

Renvoie les données demandées.

DESCRIPTION

glGetQueryIndexediv renvoie dans params un paramètre sélectionné de la cible d'objet de requête indexée spécifiée par target et index. index spécifie l'index de la cible d'objet de requête et doit être compris entre zéro et un maximum spécifique à la cible.

pname nomme un paramètre de cible d'objet de requête spécifique. Lorsque pname est GL_CURRENT_QUERY, le nom de la requête actuellement active pour l'index index spécifié de target, ou zéro si aucune requête n'est active, sera placé dans params. Si pname est GL_QUERY_COUNTER_BITS, le nombre de bits utilisés pour détenir le résultat des requêtes pour target, dépendant de l'implémentation, est renvoyé dans params.

NOTES

La cible GL_ANY_SAMPLES_PASSED_CONSERVATIVE est disponible uniquement si la version GL est 4.3 ou supérieure.

Si une erreur est générée, aucun changement n'est apporté au contenu de params.

Appeler glGetQueryiv() est équivalent à appeler glGetQueryIndexediv avec index défini à zéro.

ERREURS

GL_INVALID_ENUM est généré si target ou pname n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si index est supérieur ou égal au maximum spécifique à la cible.
