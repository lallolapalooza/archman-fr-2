NOM

glDrawTransformFeedbackStreamInstanced - rend plusieurs instances de primitives en utilisant un décompte dérivé d'un flux spécifié d'un objet de retour de transformation

SPÉCIFICATION C

void glDrawTransformFeedbackStreamInstanced(GLenum mode, GLuint id, GLuint stream, GLsizei instancecount);

PARAMÈTRES

mode

Spécifie le type de primitives à rendre. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, et GL_PATCHES sont acceptées.

id

Spécifie le nom d'un objet de retour de transformation à partir duquel récupérer un décompte de primitives.

stream

Spécifie l'index du flux de retour de transformation à partir duquel récupérer un décompte de primitives.

instancecount

Spécifie le nombre d'instances de la géométrie à rendre.

DESCRIPTION

glDrawTransformFeedbackStreamInstanced dessine plusieurs copies d'une plage de primitives d'un type spécifié par mode en utilisant un décompte récupéré du flux de retour de transformation spécifié par stream de l'objet de retour de transformation spécifié par id. L'appel à glDrawTransformFeedbackStreamInstanced est équivalent à l'appel de glDrawArraysInstanced() avec mode et instancecount tels que spécifiés, first défini à zéro, et count défini au nombre de sommets capturés sur le flux de sommets stream lors de la dernière activation du retour de transformation sur l'objet de retour de transformation nommé par id.

L'appel à glDrawTransformFeedbackInstanced() est équivalent à l'appel de glDrawTransformFeedbackStreamInstanced avec stream défini à zéro.

ERREURS

GL_INVALID_ENUM est générée si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est générée si id n'est pas le nom d'un objet de retour de transformation.

GL_INVALID_VALUE est générée si stream est supérieur ou égal à la valeur de GL_MAX_VERTEX_STREAMS.

GL_INVALID_OPERATION est générée si un objet buffer non nul est lié à un tableau activé et que le magasin de données de l'objet buffer est actuellement mappé.

GL_INVALID_OPERATION est générée si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est générée si mode est GL_PATCHES et qu'aucun shader de contrôle de tessellation n'est actif.

GL_INVALID_OPERATION est générée si

glEndTransformFeedback n'a jamais été appelé alors que l'objet de retour de transformation nommé par id était lié.
