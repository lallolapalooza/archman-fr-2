NOM

glGetObjectPtrLabel - récupérer l'étiquette d'un objet sync identifié par un pointeur

SPÉCIFICATION C

void glGetObjectPtrLabel(void * ptr, GLsizei bufSize, GLsizei * length, char * label);

PARAMÈTRES

ptr

Le nom de l'objet sync dont récupérer l'étiquette.

bufSize

La taille du tampon dont l'adresse est dans label.

length

L'adresse d'une variable pour recevoir la longueur de l'étiquette de l'objet.

label

L'adresse d'une chaîne de caractères qui recevra l'étiquette de l'objet.

DESCRIPTION

glGetObjectPtrLabel récupère l'étiquette de l'objet sync identifié par ptr.

label est l'adresse d'une chaîne de caractères qui sera utilisée pour stocker l'étiquette de l'objet. bufSize spécifie le nombre de caractères dans le tableau identifié par label. length contient l'adresse d'une variable qui recevra le nombre de caractères dans l'étiquette de l'objet. Si length est NULL, alors il est ignoré et aucune donnée n'est écrite. De même, si label est NULL, ou si bufSize est zéro, alors aucune donnée n'est écrite dans label.

ERREURS

GL_INVALID_ENUM est générée si identifier n'est pas l'un des types d'objets acceptés.

GL_INVALID_VALUE est générée si ptr n'est pas le nom d'un objet sync existant.

GL_INVALID_VALUE est générée si bufSize est zéro.

Si ce n'est pas NULL, length et label doivent être des adresses auxquelles le client a un accès en écriture, sinon un comportement indéfini, y compris la terminaison du processus, peut se produire.

GETS ASSOCIÉS

glGet() avec l'argument GL_MAX_LABEL_LENGTH.
