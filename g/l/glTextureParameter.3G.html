glTexParameter, glTextureParameter - définir les paramètres de texture

PARAMÈTRES

target

Spécifie la cible à laquelle la texture est liée pour les fonctions glTexParameter. Doit être l'une des valeurs suivantes : GL_TEXTURE_1D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_2D_MULTISAMPLE, GL_TEXTURE_2D_MULTISAMPLE_ARRAY, GL_TEXTURE_3D, GL_TEXTURE_CUBE_MAP, GL_TEXTURE_CUBE_MAP_ARRAY, ou GL_TEXTURE_RECTANGLE.

texture

Spécifie le nom de l'objet texture pour les fonctions glTextureParameter.

pname

Spécifie le nom symbolique d'un paramètre de texture à valeur unique. pname peut être l'un des suivants : GL_DEPTH_STENCIL_TEXTURE_MODE, GL_TEXTURE_BASE_LEVEL, GL_TEXTURE_COMPARE_FUNC, GL_TEXTURE_COMPARE_MODE, GL_TEXTURE_LOD_BIAS, GL_TEXTURE_MIN_FILTER, GL_TEXTURE_MAG_FILTER, GL_TEXTURE_MIN_LOD, GL_TEXTURE_MAX_LOD, GL_TEXTURE_MAX_LEVEL, GL_TEXTURE_SWIZZLE_R, GL_TEXTURE_SWIZZLE_G, GL_TEXTURE_SWIZZLE_B, GL_TEXTURE_SWIZZLE_A, GL_TEXTURE_WRAP_S, GL_TEXTURE_WRAP_T, ou GL_TEXTURE_WRAP_R.

Pour les commandes vectorielles (glTexParameter*v), pname peut également être l'une des valeurs suivantes : GL_TEXTURE_BORDER_COLOR ou GL_TEXTURE_SWIZZLE_RGBA.

param

Pour les commandes scalaires, spécifie la valeur de pname.

params

Pour les commandes vectorielles, spécifie un pointeur vers un tableau où la ou les valeurs de pname sont stockées.

DESCRIPTION

glTexParameter et glTextureParameter assignent la valeur ou les valeurs de params au paramètre de texture spécifié par pname. Pour glTexParameter, target définit la texture cible, soit GL_TEXTURE_1D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_2D_MULTISAMPLE, GL_TEXTURE_2D_MULTISAMPLE_ARRAY, GL_TEXTURE_3D, GL_TEXTURE_CUBE_MAP, GL_TEXTURE_CUBE_MAP_ARRAY, ou GL_TEXTURE_RECTANGLE. Les symboles suivants sont acceptés pour pname :

GL_DEPTH_STENCIL_TEXTURE_MODE

Spécifie le mode utilisé pour lire à partir des textures au format profondeur-stencil. params doit être l'une des valeurs GL_DEPTH_COMPONENT ou GL_STENCIL_INDEX. Si le mode profondeur-stencil est GL_DEPTH_COMPONENT, alors les lectures à partir des textures au format profondeur-stencil retourneront le composant de profondeur du texel en Rt et le composant stencil sera ignoré. Si le mode profondeur-stencil est GL_STENCIL_INDEX, alors le composant stencil est retourné en Rt et le composant de profondeur est ignoré. La valeur initiale est GL_DEPTH_COMPONENT.

GL_TEXTURE_BASE_LEVEL

Spécifie l'indice du plus bas niveau mipmap défini. C'est une valeur entière. La valeur initiale est 0.

GL_TEXTURE_BORDER_COLOR

Les données dans params spécifient quatre valeurs qui définissent les couleurs de bordure à utiliser pour les texels de bordure. Si un texel est échantillonné à partir du bord de la texture, les valeurs de GL_TEXTURE_BORDER_COLOR sont interprétées comme une couleur RGBA correspondant au format interne de la texture et substituées aux données de texel inexistantes. Si la texture contient des composants de profondeur, le premier composant de GL_TEXTURE_BORDER_COLOR est interprété comme une valeur de profondeur. La valeur initiale est 0.0, 0.0, 0.0, 0.0.

Si les valeurs pour GL_TEXTURE_BORDER_COLOR sont spécifiées avec glTexParameterIiv ou glTexParameterIuiv, les valeurs sont stockées sans modification avec un type de données interne entier. Si elles sont spécifiées avec glTexParameteriv, elles sont converties en virgule flottante selon l'équation suivante : f = 2 c + 1 2 b - 1. Si elles sont spécifiées avec glTexParameterfv, elles sont stockées sans modification en tant que valeurs à virgule flottante.

GL_TEXTURE_COMPARE_FUNC

Spécifie l'opérateur de comparaison utilisé lorsque GL_TEXTURE_COMPARE_MODE est réglé sur GL_COMPARE_REF_TO_TEXTURE. Les valeurs autorisées sont :
Fonction de comparaison de texture Résultat calculé
GL_LEQUAL result = 1.0 0.0 ⁢   r <= D t r > D t
GL_GEQUAL result = 1.0 0.0 ⁢   r >= D t r < D t
GL_LESS result = 1.0 0.0 ⁢   r < D t r >= D t
GL_GREATER result = 1.0 0.0 ⁢   r > D t r <= D t
GL_EQUAL result = 1.0 0.0 ⁢   r = D t r ≠ D t
GL_NOTEQUAL result = 1.0 0.0 ⁢   r ≠ D t r = D t
GL_ALWAYS result = 1.0
GL_NEVER result = 0.0

où r est la coordonnée de texture interpolée actuelle, et D t est la valeur de profondeur de la texture échantillonnée à partir de la texture de profondeur actuellement liée. result est assigné au canal rouge.

GL_TEXTURE_COMPARE_MODE

Spécifie le mode de comparaison de texture pour les textures de profondeur actuellement liées. C'est-à-dire, une texture dont le format interne est GL_DEPTH_COMPONENT_*; voir glTexImage2D()). Les valeurs autorisées sont :

GL_COMPARE_REF_TO_TEXTURE

Spécifie que la coordonnée de texture r interpolée et limitée doit être comparée à la valeur dans la texture de profondeur actuellement liée. Voir la discussion sur GL_TEXTURE_COMPARE_FUNC pour les détails sur la manière dont la comparaison est évaluée. Le résultat de la comparaison est assigné au canal rouge.

GL_NONE

Spécifie que le canal rouge doit recevoir la valeur appropriée de la texture de profondeur actuellement liée.

GL_TEXTURE_LOD_BIAS

params spécifie une valeur de biais fixe qui doit être ajoutée au paramètre de niveau de détail (level-of-detail) pour la texture avant l'échantillonnage de texture. La valeur spécifiée est ajoutée à la valeur de biais fournie par le shader (s'il y en a une) et ensuite limitée dans la plage définie par l'implémentation - bias max bias max, où bias max est la valeur de la constante définie par l'implémentation GL_MAX_TEXTURE_LOD_BIAS. La valeur initiale est 0.0.

b>GL_TEXTURE_MIN_FILTE

R
La fonction de minification de texture est utilisée chaque fois que la fonction de niveau de détail utilisée lors de l'échantillonnage à partir de la texture détermine que la texture doit être minifiée. Il existe six fonctions de minification définies. Deux d'entre elles utilisent soit les éléments de texture les plus proches, soit une moyenne pondérée de plusieurs éléments de texture pour calculer la valeur de la texture. Les quatre autres utilisent les mipmaps.

Un mipmap est un ensemble ordonné de tableaux représentant la même image à des résolutions progressivement plus basses. Si la texture a des dimensions 2 n × 2 m, il y a max ⁡ n m + 1 mipmaps. Le premier mipmap est la texture d'origine, avec les dimensions 2 n × 2 m. Chaque mipmap suivant a les dimensions 2 k - 1 × 2 l - 1, où 2 k × 2 l sont les dimensions du mipmap précédent, jusqu'à ce que k = 0 ou l = 0. À ce moment-là, les mipmaps suivants ont la dimension 1 × 2 l - 1 ou 2 k - 1 × 1 jusqu'au mipmap final, qui a la dimension 1 × 1. Pour définir les mipmaps, appelez glTexImage1D(), glTexImage2D(), glTexImage3D(), glCopyTexImage1D() ou glCopyTexImage2D() avec l' argument level indiquant l'ordre des mipmaps. Le niveau 0 est la texture d'origine ; le niveau max ⁡ n m est le mipmap final 1 ×

1.

params fournit une fonction pour minifier la texture, parmi les suivantes

:

GL_NEARES

T
Renvoie la valeur de l'élément de texture le plus proche (en distance de Manhattan) des coordonnées de texture
spécifiées.

GL_LINEA

R
Renvoie la moyenne pondérée des quatre éléments de texture les plus proches des coordonnées de texture spécifiées. Ceux-ci peuvent inclure des éléments enveloppés ou répétés d'autres parties d'une texture, selon les valeurs de GL_TEXTURE_WRAP_S et GL_TEXTURE_WRAP_T, et selon le mappage
exact.

GL_NEAREST_MIPMAP_NEARES

T
Choisit le mipmap qui correspond le plus étroitement à la taille du pixel texturé et utilise le critère GL_NEAREST (l'élément de texture le plus proche des coordonnées de texture spécifiées) pour produire une valeur de
texture.

GL_LINEAR_MIPMAP_NEARES

T
Choisit le mipmap qui correspond le plus étroitement à la taille du pixel texturé et utilise le critère GL_LINEAR (une moyenne pondérée des quatre éléments de texture les plus proches des coordonnées de texture spécifiées) pour produire une valeur de
texture.

GL_NEAREST_MIPMAP_LINEA

R
Choisit les deux mipmaps qui correspondent le plus étroitement à la taille du pixel texturé et utilise le critère GL_NEAREST (l' élément de texture le plus proche des coordonnées de texture spécifiées) pour produire une valeur de texture à partir de chaque mipmap. La valeur de texture finale est une moyenne pondérée de ces deux
valeurs.

GL_LINEAR_MIPMAP_LINEA

R
Choisit les deux mipmaps qui correspondent le plus étroitement à la taille du pixel texturé et utilise le critère GL_LINEAR (une moyenne pondérée des éléments de texture les plus proches des coordonnées de texture spécifiées) pour produire une valeur de texture à partir de chaque mipmap. La valeur de texture finale est une moyenne pondérée de ces deux
valeurs.

Plus d'éléments de texture sont échantillonnés lors du processus de minification, moins d'artefacts d'aliasing seront apparents. Bien que les fonctions de minification GL_NEAREST et GL_LINEAR puissent être plus rapides que les quatre autres, elles n'échantillonnent qu'un ou plusieurs éléments de texture pour déterminer la texture du pixel rendu et peuvent produire des motifs de moiré ou des transitions irrégulières. La valeur initiale de GL_TEXTURE_MIN_FILTER est GL_NEAREST_MIPMAP_LINEA

R
.

GL_TEXTURE_MAG_FILTE

R
La fonction d'agrandissement de texture est utilisée chaque fois que la fonction de niveau de détail utilisée lors de l'échantillonnage à partir de la texture détermine que la texture doit être agrandie. Elle définit la fonction d'agrandissement de texture sur soit GL_NEAREST ou GL_LINEAR (voir ci-dessous). GL_NEAREST est généralement plus rapide que GL_LINEAR, mais elle peut produire des images texturées avec des bords plus nets car la transition entre les éléments de texture n'est pas aussi lisse. La valeur initiale de GL_TEXTURE_MAG_FILTER est GL_LINEAR.

Renvoie la valeur de l'élément de texture le plus proche (en distance de Manhattan) des coordonnées de texture
spécifiées.

Renvoie la moyenne pondérée des éléments de texture les plus proches des coordonnées de texture spécifiées. Ceux-ci peuvent inclure des éléments enveloppés ou répétés d'autres parties d'une texture, selon les valeurs de GL_TEXTURE_WRAP_S et GL_TEXTURE_WRAP_T, et se

GL_TEXTURE_MIN_LO

D
Définit le paramètre de niveau de détail minimum. Cette valeur en virgule flottante limite la sélection du mipmap de résolution la plus élevée (niveau de mipmap le plus bas). La valeur initiale est
-1000.

GL_TEXTURE_MAX_LO

D
Définit le paramètre de niveau de détail maximum. Cette valeur en virgule flottante limite la sélection du mipmap de résolution la plus faible (niveau de mipmap le plus élevé). La valeur initiale est
1000.

GL_TEXTURE_MAX_LEVE

L
Définit l'index du niveau de mipmap défini le plus élevé. C'est une valeur entière. La valeur initiale est
1000.

GL_TEXTURE_SWIZZLE_

R
Définit le swizzle qui sera appliqué au composant r d'un texel avant qu'il ne soit renvoyé au shader. Les valeurs valides pour param sont GL_RED, GL_GREEN, GL_BLUE, GL_ALPHA, GL_ZERO et GL_ONE. Si GL_TEXTURE_SWIZZLE_R est GL_RED, la valeur de r sera prise depuis le premier canal du texel récupéré. Si GL_TEXTURE_SWIZZLE_R est GL_GREEN, la valeur de r sera prise depuis le deuxième canal du texel récupéré. Si GL_TEXTURE_SWIZZLE_R est GL_BLUE, la valeur de r sera prise depuis le troisième canal du texel récupéré. Si GL_TEXTURE_SWIZZLE_R est GL_ALPHA, la valeur de r sera prise depuis le quatrième canal du texel récupéré. Si GL_TEXTURE_SWIZZLE_R est GL_ZERO, la valeur de r sera remplacée par 0.0. Si GL_TEXTURE_SWIZZLE_R est GL_ONE, la valeur de r sera remplacée par 1.0. La valeur initiale est GL_RED
.

GL_TEXTURE_SWIZZLE_

G
Définit le swizzle qui sera appliqué au composant g d'un texel avant qu'il ne soit renvoyé au shader. Les valeurs valides pour param et leurs effets sont similaires à ceux de GL_TEXTURE_SWIZZLE_R. La valeur initiale est GL_GREEN
.

GL_TEXTURE_SWIZZLE_

B
Définit le swizzle qui sera appliqué au composant b d'un texel avant qu'il ne soit renvoyé au shader. Les valeurs valides pour param et leurs effets sont similaires à ceux de GL_TEXTURE_SWIZZLE_R. La valeur initiale est GL_BLUE
.

GL_TEXTURE_SWIZZLE_

A
Définit le swizzle qui sera appliqué au composant a d'un texel avant qu'il ne soit renvoyé au shader. Les valeurs valides pour param et leurs effets sont similaires à ceux de GL_TEXTURE_SWIZZLE_R. La valeur initiale est GL_ALPHA
.

GL_TEXTURE_SWIZZLE_RGB

A
Définit les swizzles qui seront appliqués aux composants r, g, b, et a d'un texel avant qu'ils ne soient renvoyés au shader. Les valeurs valides pour params et leurs effets sont similaires à ceux de GL_TEXTURE_SWIZZLE_R, sauf que tous les canaux sont spécifiés simultanément. Définir la valeur de GL_TEXTURE_SWIZZLE_RGBA est équivalent (en supposant qu'aucune erreur n'est générée) à définir les paramètres de chacun de GL_TEXTURE_SWIZZLE_R, GL_TEXTURE_SWIZZLE_G, GL_TEXTURE_SWIZZLE_B, et GL_TEXTURE_SWIZZLE_A
successivement.

GL_TEXTURE_WRAP_

S
Définit le paramètre de répétition pour la coordonnée de texture s sur soit GL_CLAMP_TO_EDGE, GL_CLAMP_TO_BORDER, GL_MIRRORED_REPEAT, GL_REPEAT, ou GL_MIRROR_CLAMP_TO_EDGE. GL_CLAMP_TO_EDGE provoque le bornage des coordonnées s à l'intervalle 1 2N 1 - 1 2N, où N est la taille de la texture dans la direction du bornage. GL_CLAMP_TO_BORDER évalue les coordonnées s d'une manière similaire à GL_CLAMP_TO_EDGE. Cependant, dans les cas où un bornage aurait eu lieu en mode GL_CLAMP_TO_EDGE, les données du texel récupéré sont remplacées par les valeurs spécifiées par GL_TEXTURE_BORDER_COLOR. GL_REPEAT provoque l'ignorance de la partie entière de la coordonnée s ; GL n'utilise que la partie fractionnelle, créant ainsi un motif répétitif. GL_MIRRORED_REPEAT provoque la définition de la coordonnée s sur la partie fractionnelle de la coordonnée de texture si la partie entière de s est paire ; si la partie entière de s est impaire, alors la coordonnée de texture s est définie sur 1 - frac ⁡ s, où frac ⁡ s représente la partie fractionnelle de s. GL_MIRROR_CLAMP_TO_EDGE provoque la répétition de la coordonnée s comme pour GL_MIRRORED_REPEAT pour une répétition de la texture, après quoi la coordonnée est bornée comme dans GL_CLAMP_TO_EDGE. Initialement, GL_TEXTURE_WRAP_S est défini sur GL_REPEAT
.

GL_TEXTURE_WRAP_

T
Définit le paramètre de répétition pour la coordonnée de texture t sur soit GL_CLAMP_TO_EDGE, GL_CLAMP_TO_BORDER, GL_MIRRORED_REPEAT, GL_REPEAT, ou GL_MIRROR_CLAMP_TO_EDGE. Voir la discussion sous GL_TEXTURE_WRAP_S. Initialement, GL_TEXTURE_WRAP_T est défini sur GL_REPEAT
.

GL_TEXTURE_WRAP_

R
Définit le paramètre de répétition pour la coordonnée de texture r sur soit GL_CLAMP_TO_EDGE, GL_CLAMP_TO_BORDER, GL_MIRRORED_REPEAT, GL_REPEAT, ou GL_MIRROR_CLAMP_TO_EDGE. Voir la discussion sous GL_TEXTURE_WRAP_S. Initialement, GL_TEXTURE_WRAP_R est défini sur GL_RE
PEAT.

NOTE

S

Supposons qu'un programme tente d'échantillonner à partir d'une texture et a défini GL_TEXTURE_MIN_FILTER sur l'une des fonctions qui nécessitent un mipmap. Si les dimensions des images de texture actuellement définies (avec des appels précédents à glTexImage1D(), glTexImage2D(), glTexImage3D(), glCopyTexImage1D(), ou glCopyTexImage2D()) ne suivent pas la séquence appropriée pour les mipmaps (décrite ci-dessus), ou s'il y a moins d'images de texture définies que nécessaire, ou si l'ensemble des images de texture a des nombres différents de composants de texture, alors la texture est considérée comme incomplète

.

Le filtrage linéaire n'accède qu'aux quatre éléments de texture les plus proches dans les textures 2D. Dans les textures 1D, le filtrage linéaire accède aux deux éléments de texture les plus proches. Dans les textures 3D, le filtrage linéaire accède aux huit éléments de texture les plus

proches.

glTexParameter spécifie les paramètres de texture pour l'unité de texture active, spécifiée en appelant glActiveTexture(). glTextureParameter spécifie les paramètres de texture pour l'objet texture avec l'ID texture

.

GL_DEPTH_STENCIL_TEXTURE_MODE n'est disponible que si la version GL est 4.3 ou

supérieure.

GL_MIRROR_CLAMP_TO_EDGE n'est disponible que

si la version GL
est 4.4 ou supérieure.
