NOM

glBindFragDataLocation - lie une variable de sortie utilisateur (varying out) à un numéro de couleur du shader de fragment

SPÉCIFICATION C

void glBindFragDataLocation(GLuint program, GLuint colorNumber, const char * name);

PARAMÈTRES

program

Le nom du programme contenant la variable de sortie utilisateur (varying out) dont la liaison doit être modifiée

colorNumber

Le numéro de couleur auquel lier la variable de sortie utilisateur (varying out)

name

Le nom de la variable de sortie utilisateur (varying out) dont la liaison doit être modifiée

DESCRIPTION

glBindFragDataLocation spécifie explicitement la liaison de la variable de sortie utilisateur (varying out) name au numéro de couleur de shader de fragment colorNumber pour le programme program. Si name était déjà lié, sa liaison affectée est remplacée par colorNumber. name doit être une chaîne terminée par un caractère nul. colorNumber doit être inférieur à GL_MAX_DRAW_BUFFERS.

Les liaisons spécifiées par glBindFragDataLocation n'ont aucun effet tant que le programme program n'est pas relinké. Les liaisons peuvent être spécifiées à tout moment après la création du programme program. Plus précisément, elles peuvent être spécifiées avant que les objets shader ne soient attachés au programme. Par conséquent, n'importe quel nom peut être spécifié dans name, y compris un nom qui n'est jamais utilisé comme variable de sortie utilisateur dans aucun objet shader de fragment. Les noms commençant par gl_ sont réservés par le GL.

En plus des erreurs générées par glBindFragDataLocation, le programme program échouera à la liaison si :

•Le nombre de sorties actives est supérieur à la valeur GL_MAX_DRAW_BUFFERS.
•Plus d'une variable de sortie utilisateur (varying out) est liée au même numéro de couleur.

NOTES

Les variables de sortie utilisateur (varying out) peuvent avoir des emplacements indexés assignés explicitement dans le texte du shader à l'aide d'un qualificateur de disposition (layout qualifier) d'emplacement. Si un shader assigne statiquement un emplacement à une variable de sortie utilisateur (varying out) dans le texte du shader, cet emplacement est utilisé et tout emplacement assigné avec glBindFragDataLocation est ignoré.

ERREURS

GL_INVALID_VALUE est généré si colorNumber est supérieur ou égal à GL_MAX_DRAW_BUFFERS.

GL_INVALID_OPERATION est généré si name commence par le préfixe réservé gl_.

GL_INVALID_OPERATION est généré si program n'est pas le nom d'un objet programme.

GETS ASSOCIÉS

glGetFragDataLocation() avec un objet programme valide et le nom d'une variable de sortie utilisateur (varying out)
