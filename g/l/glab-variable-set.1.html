NOM

glab-variable-set - Crée une nouvelle variable pour un projet ou un groupe.

SYNOPSIS

glab variable set [indicateurs]

DESCRIPTION

Crée une nouvelle variable pour un projet ou un groupe.

OPTIONS

-d, --description="" Définit la description d'une variable.

-g, --group="" Définit la variable pour un groupe.

--hidden[=false] Indique si la variable est cachée.

-m, --masked[=false] Indique si la variable est masquée.

-p, --protected[=false] Indique si la variable est protégée.

-r, --raw[=false] Indique si la variable est traitée comme une chaîne brute.

-s, --scope="" Le champ environment_scope de la variable. Valeurs : all (), ou environnements spécifiques.

-t, --type="env_var" Le type d'une variable : env_var, file.

-v, --value="" La valeur d'une variable.

OPTIONS HERITEES DES COMMANDES PARENTES

-h, --help[=false] Affiche l'aide de cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également l'URL complète ou une URL Git.

EXEMPLE

$ glab variable set AVEC_ARGUMENT "une valeur"
$ glab variable set AVEC_DESC "une valeur" --description "une description"
$ glab variable set DEPUIS_INDICATEUR -v "une valeur"
$ glab variable set DEPUIS_ENV_AVEC_ARGUMENT "${VAR_ENV}"
$ glab variable set DEPUIS_ENV_AVEC_INDICATEUR -v"${VAR_ENV}"
$ glab variable set DEPUIS_FICHIER < secret.txt
$ cat file.txt | glab variable set JETON_SERVEUR
$ cat token.txt | glab variable set JETON_GROUPE -g monGroupe --scope=prod
