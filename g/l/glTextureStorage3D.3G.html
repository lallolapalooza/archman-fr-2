DESCRIPTIO

N

glTexStorage3D et glTextureStorage3D spécifient les besoins en stockage pour tous les niveaux d'une texture tridimensionnelle, d'un tableau bidimensionnel ou d'un tableau de cube-map simultanément. Une fois qu'une texture est spécifiée avec cette commande, le format et les dimensions de tous les niveaux deviennent immuables, sauf s'il s'agit d'une texture proxy. Le contenu de l'image peut toujours être modifié, cependant, ses besoins en stockage ne peuvent pas changer. Une telle texture est appelée une texture à format

immuable.

Le comportement de glTexStorage3D dépend du paramètre target . Quand target est GL_TEXTURE_3D, ou GL_PROXY_TEXTURE_3D, appeler glTexStorage3D est équivalent, en supposant qu'aucune erreur n'est générée, à exécuter le pseudo-code suivant

: 
    for (i = 0; i < levels; i++) {
        glTexImage3D(target, i, internalformat, width, height, depth, 0, format, type, NULL);
        width = max(1, (width / 2));
        height = max(1, (height / 2));
        depth = max(1, (depth / 2));
}

Quand target est GL_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP_ARRAY, ou GL_PROXY_TEXTURE_CUBE_MAP_ARRAY, glTexStorage3D est équivalent à

: 
    for (i = 0; i < levels; i++) {
        glTexImage3D(target, i, internalformat, width, height, depth, 0, format, type, NULL);
        width = max(1, (width / 2));
        height = max(1, (height / 2));
}

Appeler glTextureStorage3D est équivalent au pseudo-code ci-dessus, où target est la cible effective de texture et c'est comme si texture était lié à target aux fins de glTexImage3D

.

Puisqu'aucune donnée de texture n'est réellement fournie, les valeurs utilisées dans le pseudo-code pour format et type sont sans importance et peuvent être considérées comme n'importe quelles valeurs légales pour l'énumérateur internalformat choisi. internalformat doit être l'un des formats internes dimensionnés donnés dans le Tableau 1 ci-dessous, l'un des formats de composante de profondeur dimensionnés GL_DEPTH_COMPONENT32F, GL_DEPTH_COMPONENT24, ou GL_DEPTH_COMPONENT16, l'un des formats combinés profondeur-stencil, GL_DEPTH32F_STENCIL8, ou GL_DEPTH24_STENCIL8, ou le format stencil seul, GL_STENCIL_INDEX8. En cas de succès, la valeur de GL_TEXTURE_IMMUTABLE_FORMAT devient GL_TRUE. La valeur de GL_TEXTURE_IMMUTABLE_FORMAT peut être obtenue en appelant glGetTexParameter() avec pname défini à GL_TEXTURE_IMMUTABLE_FORMAT. Aucune modification ultérieure des dimensions ou du format de l'objet texture ne peut être effectuée. Utiliser n'importe quelle commande qui pourrait altérer les dimensions ou le format de l'objet texture (comme glTexImage3D() ou un autre appel à glTexStorage3D) entraînera la génération d'une erreur GL_INVALID_OPERATION, même si elle ne modifierait pas, en fait, les dimensions ou le format de

l'objet.

NAME

glTextureStorage3D, glTextureStorage3DEXT - specify the storage of a 3D texture

C SPECIFICATION

void glTextureStorage3D(GLuint texture, GLsizei levels, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth);

PARAMETERS

 
Specifies the texture object name.
levels
Specifies the number of **texture levels** for the new texture. The number of levels is expected to be one more than the value of log 2 of the largest dimension, or zero for automatic calculation.
internalformat
Specifies the internal format of the texture that will be used for storage. The format of the texel data is specified by internalformat.
width
Specifies the width of the texture.
height
Specifies the height of the texture.
depth
Specifies the depth of the texture.

DESCRIPTION

glTextureStorage3D specifies the storage, format, dimensions, and number of mipmap levels for a three-dimensional texture object, or an array texture, or a cube map array texture.

The texture's immutable storage is defined by the internalformat, width, height, and depth parameters. Once the storage is specified, it cannot be modified until the texture object is deleted and recreated.

The internalformat parameter must be one of the sized internal texture formats. The texture object's format is set to internalformat, and its dimensions are set to width, height, and depth.

If levels is zero, the number of texture levels is computed as:

    N = floor(log 2(max(width, height, depth))) + 1

Otherwise, levels must be less than or equal to the computed value of N.

The width, height, and depth parameters specify the dimensions of the base texel level (level 0). These dimensions must be powers of two unless the texture is one of the non-power-of-two formats supported by the implementation. All dimensions must be at least 1.

The texture parameter identifies the texture object to be modified.

The internalformat parameter must be a sized internal format. The following table lists the accepted sized internal formats:

NOTES

GL_STENCIL_INDEX8
is accepted for internalformat only if the GL version is 4.4 or higher.

ERRORS

GL_INVALID_OPERATION is generated by glTexStorage3D if zero is bound to target.

GL_INVALID_OPERATION is generated by glTextureStorage3D if texture is not the name of an existing texture object.

GL_INVALID_ENUM is generated if internalformat is not a valid sized internal format.

GL_INVALID_ENUM is generated if target or the effective target of texture is not one of the accepted targets described above.

GL_INVALID_VALUE is generated if width, height, depth or levels are less than 1.

GL_INVALID_OPERATION is generated if target is GL_TEXTURE_3D or GL_PROXY_TEXTURE_3D and levels is greater than log 2 max width ,   height ,   depth + 1.

GL_INVALID_OPERATION is generated if target is GL_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_TEXURE_CUBE_MAP_ARRAY, or GL_PROXY_TEXTURE_CUBE_MAP_ARRAY and levels is greater than log 2 max width ,   height + 1.
