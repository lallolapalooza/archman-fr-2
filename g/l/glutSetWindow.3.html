glutSetWindow(3)

Paquet: freeglut

Licences: X11

glutSetWindow(3) freeglut glutSetWindow(3)

NOM

glutSetWindow - définit la fenêtre courante ; glutGetWindow - retourne l'identifiant de la fenêtre courante.

SYNTAXE

void glutSetWindow(int win);
int glutGetWindow(void);

ARGUMENTS

win
Identifiant de la fenêtre GLUT à faire devenir la fenêtre courante.

DESCRIPTION

glutSetWindow définit la fenêtre courante ; glutGetWindow retourne l'identifiant de la fenêtre courante. Si aucune fenêtre n'existe ou si la fenêtre précédemment courante a été détruite, glutGetWindow retourne zéro. glutSetWindow ne change pas la couche utilisée pour la fenêtre ; ceci est fait à l'aide de glutUseLayer.

VOIR AUSSI

glutCreateWindow, glutSetMenu
