PARAMÈTRES

location

Spécifie l'emplacement de la variable uniforme à modifier.

count

Pour les commandes de vecteur (glUniform*v), spécifie le nombre d'éléments à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau, et 1 ou plus si c'est un tableau.

Pour les commandes de matrice (glUniformMatrix*), spécifie le nombre de matrices à modifier. Cela doit être 1 si la variable uniforme ciblée n'est pas un tableau de matrices, et 1 ou plus si c'est un tableau de matrices.

transpose

Pour les commandes de matrice, spécifie s'il faut transposer la matrice lorsque les valeurs sont chargées dans la variable uniforme.

v0, v1, v2, v3

Pour les commandes scalaires, spécifie les nouvelles valeurs à utiliser pour la variable uniforme spécifiée.

value

Pour les commandes de vecteur et de matrice, spécifie un pointeur vers un tableau de count valeurs qui seront utilisées pour mettre à jour la variable uniforme spécifiée.

DESCRIPTION

glUniform modifie la valeur d'une variable uniforme ou d'un tableau de variables uniformes. L'emplacement de la variable uniforme à modifier est spécifié par location, qui doit être une valeur retournée par glGetUniformLocation(). glUniform opère sur l'objet programme qui a été rendu partie de l'état courant en appelant glUseProgram().

Les commandes glUniform{1|2|3|4}{f|i|ui} sont utilisées pour changer la valeur de la variable uniforme spécifiée par location en utilisant les valeurs passées en arguments. Le nombre spécifié dans la commande doit correspondre au nombre de composantes dans le type de données de la variable uniforme spécifiée (par exemple, 1 pour float, int, unsigned int, bool ; 2 pour vec2, ivec2, uvec2, bvec2, etc.). Le suffixe f indique que des valeurs en virgule flottante sont passées ; le suffixe i indique que des valeurs entières sont passées ; le suffixe ui indique que des valeurs entières non signées sont passées, et ce type doit également correspondre au type de données de la variable uniforme spécifiée. Les variantes i de cette fonction doivent être utilisées pour fournir des valeurs pour les variables uniformes définies en tant que int, ivec2, ivec3, ivec4, ou des tableaux de ceux-ci. Les ui de cette fonction doivent être utilisés pour fournir des valeurs pour des variables uniformes définies comme unsigned int, uvec2, uvec3, uvec4, ou des tableaux de ceux-ci. Les f doivent être utilisés pour fournir des valeurs pour des variables uniformes de type float, vec2, vec3, vec4, ou des tableaux de ceux-ci. Soit les i

La variable uniforme sera définie à false si la valeur d'entrée est 0 ou 0.0f, et elle sera définie à true dans le cas contraire. Toutes les variables uniformes actives définies dans un objet programme sont initialisées à 0 lorsque l'objet programme est lié avec succès. Elles conservent les valeurs qui leur ont été assignées par un appel à glUniform jusqu'à ce que la prochaine opération de liaison réussie se produise sur l'objet programme, auquel cas elles sont à nouveau initialisées à 0. Les commandes glUniform{1|2|3|4}{f|i|ui}v peuvent être utilisées pour modifier une variable uniforme unique ou un tableau de variables uniformes. Ces commandes passent un compte et un pointeur vers les valeurs à charger dans une variable uniforme ou un tableau de variables uniformes.
