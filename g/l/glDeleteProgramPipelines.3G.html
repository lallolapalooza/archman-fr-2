NOM

glDeleteProgramPipelines - supprime les objets de pipeline de programme

SPÉCIFICATION C

void glDeleteProgramPipelines(GLsizei n, const GLuint *pipelines);

PARAMÈTRES

n

Spécifie le nombre d'objets de pipeline de programme à supprimer.

pipelines

Spécifie un tableau de noms d'objets de pipeline de programme à supprimer.

DESCRIPTION

glDeleteProgramPipelines supprime les n objets de pipeline de programme dont les noms sont stockés dans le tableau pipelines. Les noms inutilisés dans pipelines sont ignorés, de même que le nom zéro. Après la suppression d'un objet de pipeline de programme, son nom est à nouveau inutilisé et il n'a aucun contenu. Si un objet de pipeline de programme actuellement lié est supprimé, la liaison pour cet objet revient à zéro et aucun objet de pipeline de programme ne devient courant.

GETS ASSOCIÉS

glGet() avec l'argument GL_PROGRAM_PIPELINE_BINDING
