NOM

glab-mr-merge - Fusionner ou accepter une demande de fusion.

SYNTAXE

glab mr merge { | } [flags]

DESCRIPTION

Fusionne ou accepte une demande de fusion.

OPTIONS

--auto-merge[=true] Définir la fusion automatique.

-m, --message="" Message de commit de fusion personnalisé.

-r, --rebase[=false] Réappliquer les commits sur la branche de base.

-d, --remove-source-branch[=false] Supprimer la branche source lors de la fusion.

--sha="" SHA du commit de fusion.

-s, --squash[=false] Aplatir les commits lors de la fusion.

--squash-message="" Message de commit d'aplatissement personnalisé.

-y, --yes[=false] Ignorer la demande de confirmation de soumission.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACE DE NOMS/DÉPÔT. Accepte également une URL complète ou une URL Git.

EXEMPLE

# Fusionner une demande de fusion
$ glab mr merge 235
$ glab mr accept 235
# Trouve une demande de fusion ouverte à partir de la branche actuelle
$ glab mr merge
