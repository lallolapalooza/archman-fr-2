NOM

glScissorIndexed - définir la boîte de ciseaux pour une fenêtre d'affichage spécifique

SPÉCIFICATION C

void glScissorIndexed(GLuint index, GLint left, GLint bottom, GLsizei width, GLsizei height);

void glScissorIndexedv(GLuint index, const GLint *v);

PARAMÈTRES

index

Spécifie l'index de la fenêtre d'affichage dont la boîte de ciseaux doit être modifiée.

left, bottom

Spécifient la coordonnée du coin inférieur gauche de la boîte de ciseaux, en pixels.

width, height

Spécifient les dimensions de la boîte de ciseaux, en pixels.

v

Pour glScissorIndexedv, spécifie l'adresse d'un tableau contenant le bord gauche, le bord inférieur, la largeur et la hauteur de chaque boîte de ciseaux, dans cet ordre.

DESCRIPTION

glScissorIndexed définit la boîte de ciseaux pour une fenêtre d'affichage spécifiée. index spécifie l'index de la boîte de ciseaux à modifier. index doit être inférieur à la valeur de GL_MAX_VIEWPORTS. Pour glScissorIndexed, left, bottom, width et height spécifient respectivement le bord gauche, le bord inférieur, la largeur et la hauteur de la boîte de ciseaux, en pixels. Pour glScissorIndexedv, v spécifie l'adresse d'un tableau contenant des entiers spécifiant le coin inférieur gauche de la boîte de ciseaux, ainsi que la largeur et la hauteur de la boîte de ciseaux, dans cet ordre.

Pour activer et désactiver le test de ciseaux, appelez glEnable() et

glDisable avec l'argument GL_SCISSOR_TEST. Le test est initialement désactivé pour toutes les fenêtres d'affichage. Tant que le test est activé, seuls les pixels qui se trouvent dans la boîte de ciseaux peuvent être modifiés par les commandes de dessin. Les coordonnées de la fenêtre ont des valeurs entières aux coins partagés des pixels du tampon d'image. glScissor(0,0,1,1) permet la modification du seul pixel inférieur gauche de la fenêtre, et glScissor(0,0,0,0) ne permet la modification d'aucun pixel de la fenêtre.

Lorsque le test de ciseaux est désactivé, il est comme si la boîte de ciseaux incluait toute la fenêtre.

ERREURS

GL_INVALID_VALUE est générée si index est supérieur ou égal à la valeur de GL_MAX_VIEWPORTS.

GL_INVALID_VALUE est générée si une largeur ou une hauteur spécifiée dans le tableau v est négative.

GETS ASSOCIÉS

glGet() avec l'argument GL_SCISSOR_BOX

glIsEnabled() avec l'argument GL_SCISSOR_TEST
