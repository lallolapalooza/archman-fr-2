GLDISPATCHCOMPUTEIND(3G) [FIXME: manuel] GLDISPATCHCOMPUTEIND(3G)

NOM

glDispatchComputeIndirect - lance un ou plusieurs groupes de travail de calcul en utilisant des paramètres stockés dans un tampon

SPÉCIFICATION C

void glDispatchComputeIndirect(GLintptr indirect);

PARAMÈTRES

indirect

Le décalage dans l'objet tampon actuellement lié à la cible de tampon GL_DISPATCH_INDIRECT_BUFFER où les paramètres de lancement sont stockés.

DESCRIPTION

glDispatchComputeIndirect lance un ou plusieurs groupes de travail de calcul en utilisant des paramètres stockés dans l'objet tampon actuellement lié à la cible GL_DISPATCH_INDIRECT_BUFFER. Chaque groupe de travail est traité par l'objet programme actif pour l'étape du shader de calcul. Alors que les invocations de shader individuelles au sein d'un groupe de travail sont exécutées comme une unité, les groupes de travail sont exécutés de manière totalement indépendante et dans un ordre non spécifié. indirect contient le décalage dans le magasin de données de l'objet tampon lié à la cible GL_DISPATCH_INDIRECT_BUFFER où les paramètres sont stockés.

Les paramètres adressés par indirect sont regroupés dans une structure, qui prend la forme (en C) :

    typedef  struct {
        uint  num_groups_x;
        uint  num_groups_y;
        uint  num_groups_z;
    } DispatchIndirectCommand;

Un appel à glDispatchComputeIndirect est équivalent, en supposant qu'aucune erreur n'est générée, à :

    cmd = (const DispatchIndirectCommand  *)indirect;
    glDispatchCompute(cmd->num_groups_x, cmd->num_groups_y, cmd->num_groups_z);

Contrairement à glDispatchCompute(), aucune erreur n'est générée si l'un des membres num_groups_x, num_groups_y ou num_groups_z de la structure DispatchIndirectCommand est supérieur à la valeur de GL_MAX_COMPUTE_WORK_GROUP_COUNT pour la dimension correspondante. Dans de telles circonstances, le comportement est indéfini et peut entraîner l'arrêt de l'application.

ERREURS

GL_INVALID_OPERATION est généré s'il n'y a pas de programme actif pour l'étape du shader de calcul.

GL_INVALID_VALUE est généré si indirect est inférieur à zéro ou n'est pas un multiple de quatre.

GL_INVALID_OPERATION est généré si aucun tampon n'est lié à la cible GL_DISPATCH_INDIRECT_BUFFER ou si la commande tente de lire des données au-delà de la fin du magasin de données de l'objet tampon.

GETS ASSOCIÉS

glGet() avec l'argument GL_MAX_COMPUTE_WORK_GROUP_COUNT
