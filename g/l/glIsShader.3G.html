NOM

glIsShader - Détermine si un nom correspond à un objet shader

SPÉCIFICATION C

GLboolean glIsShader(GLuint shader);

PARAMÈTRES

shader

Spécifie un objet shader potentiel.

DESCRIPTION

glIsShader renvoie GL_TRUE si shader est le nom d'un objet shader précédemment créé avec glCreateShader() et pas encore supprimé avec glDeleteShader(). Si shader est zéro ou une valeur non nulle qui n'est pas le nom d'un objet shader, ou si une erreur se produit, glIsShader renvoie GL_FALSE.

NOTES

Aucune erreur n'est générée si shader n'est pas un nom d'objet shader valide.

Un objet shader marqué pour suppression avec glDeleteShader() mais toujours attaché à un objet programme est toujours considéré comme un objet shader et glIsShader renverra GL_TRUE.

ASSOCIATED GETS

glGetAttachedShaders() avec un objet programme valide

glGetShader() avec les arguments shader et un paramètre à interroger

glGetShaderInfoLog() avec l'argument object

glGetShaderSource() avec l'argument object
