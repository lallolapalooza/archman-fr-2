NOM

gl_PrimitiveID - contient l'indice de la primitive courante

DÉCLARATION

// Dans les shaders de contrôle de tesselation, d'évaluation de tesselation et de fragment

in int gl_PrimitiveID ;

// Dans les shaders de géométrie

out int gl_PrimitiveID ;

DESCRIPTION

gl_PrimitiveID est une variable d'entrée des langages de shader de contrôle de tesselation, d'évaluation de tesselation et de fragment. Pour les langages de shader de contrôle de tesselation et d'évaluation de tesselation, elle contient le nombre de primitives traitées par le shader depuis le début du jeu de primitives de rendu actuel. La première primitive traitée par la commande de dessin est numérotée zéro et le compteur d'identifiant de primitive est incrémenté après le traitement de chaque primitive individuelle (point, ligne ou triangle). Pour les triangles dessinés en mode point ou ligne, le compteur d'identifiant de primitive n'est incrémenté qu'une seule fois, même si plusieurs points ou lignes peuvent effectivement être dessinés. Le redémarrage d'une topologie de primitive à l'aide de l'indice de redémarrage de primitive n'a aucun effet sur le compteur d'identifiant de primitive.

Dans le langage de géométrie, gl_PrimitiveID est une variable de sortie qui est transmise à la variable d'entrée correspondante gl_PrimitiveID dans le shader de fragment. S'il n'y a pas de shader de géométrie présent, alors gl_PrimitiveID dans le langage de fragment se comporte de manière identique à ce qu'il ferait dans les langages de contrôle de tesselation et d'évaluation. Si un shader de géométrie est présent mais n'écrit pas dans gl_PrimitiveID, la valeur de gl_PrimitiveID dans le shader de fragment est indéfinie.
