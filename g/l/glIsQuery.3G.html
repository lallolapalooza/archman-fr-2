NOM

glIsQuery - déterminer si un nom correspond à un objet requête

SPÉCIFICATION C

GLboolean glIsQuery(GLuint id);

PARAMÈTRES

id

Spécifie une valeur qui peut être le nom d'un objet requête.

DESCRIPTION

glIsQuery renvoie GL_TRUE si id est actuellement le nom d'un objet requête. Si id est zéro, ou est une valeur non nulle qui n'est pas actuellement le nom d'un objet requête, ou si une erreur se produit, glIsQuery renvoie GL_FALSE.

Un nom renvoyé par glGenQueries(), mais pas encore associé à un objet requête en appelant glBeginQuery(), n'est pas le nom d'un objet requête.
