NOM

glGenProgramPipelines - réserver des noms d'objets de pipeline de programme

SPÉCIFICATION C

void glGenProgramPipelines(GLsizei n, GLuint *pipelines);

PARAMÈTRES

n

Spécifie le nombre de noms d'objets de pipeline de programme à réserver.

pipelines

Spécifie un tableau dans lequel les noms réservés seront écrits.

DESCRIPTION

glGenProgramPipelines renvoie n noms d'objets de pipeline de programme jusqu'alors inutilisés dans pipelines. Ces noms sont marqués comme utilisés, uniquement dans le but de glGenProgramPipelines, mais ils n'acquièrent d'état de pipeline de programme que lorsqu'ils sont liés pour la première fois.

GETS ASSOCIÉS

glGet() avec l'argument GL_PROGRAM_PIPELINE_BINDING

glIsProgramPipeline()
