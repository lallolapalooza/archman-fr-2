NOM

glCreateShaderProgramv - crée un programme autonome à partir d'un tableau de chaînes de code source terminées par null

SPÉCIFICATION C

GLuint glCreateShaderProgramv(GLenum type, GLsizei count, const char **strings);

PARAMÈTRES

type

Spécifie le type de shader à créer.

count

Spécifie le nombre de chaînes de code source dans le tableau strings.

strings

Spécifie l'adresse d'un tableau de pointeurs vers des chaînes de code source à partir desquelles créer l'objet programme.

DESCRIPTION

glCreateShaderProgram crée un objet programme contenant des shaders compilés et liés pour une seule étape spécifiée par type. strings fait référence à un tableau de count chaînes à partir desquelles créer les exécutables du shader.

glCreateShaderProgram est équivalent (en supposant qu'aucune erreur n'est générée) à :

    const GLuint shader = glCreateShader(type);
    if (shader) {
        glShaderSource(shader, count, strings, NULL);
        glCompileShader(shader);
        const GLuint program = glCreateProgram();
        if (program) {
            GLint compiled = GL_FALSE;
            glGetShaderiv(shader, GL_COMPILE_STATUS, &compiled);
            glProgramParameteri(program, GL_PROGRAM_SEPARABLE, GL_TRUE);
            if (compiled) {
                glAttachShader(program, shader);
                glLinkProgram(program);
                glDetachShader(program, shader);
            }
            /* append-shader-info-log-to-program-info-log */
        }
        glDeleteShader(shader);
        return program;
    } else {
        return 0;
    }

L'objet programme créé par glCreateShaderProgram a son statut GL_PROGRAM_SEPARABLE défini sur GL_TRUE.

ERREURS

GL_INVALID_ENUM est généré si type n'est pas un type de shader accepté.

GL_INVALID_VALUE est généré si count est négatif.

D'autres erreurs sont générées si le code shader fourni échoue à la compilation et à la liaison, comme décrit pour les commandes de la séquence pseudocode ci-dessus, mais toutes ces erreurs sont générées sans aucun effet secondaire de l'exécution de ces commandes.
