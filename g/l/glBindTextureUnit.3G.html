NOM

glBindTextureUnit - lie un objet texture existant à l'unité de texture spécifiée

SPÉCIFICATION C

void glBindTextureUnit(GLuint unit, GLuint texture);

PARAMÈTRES

unit

Spécifie l'unité de texture à laquelle l'objet texture doit être lié.

texture

Spécifie le nom d'une texture.

DESCRIPTION

glBindTextureUnit lie un objet texture existant à l'unité de texture numérotée unit.

texture doit être zéro ou le nom d'un objet texture existant. Lorsque texture est le nom d'un objet texture existant, cet objet est lié à la cible, dans l'unité de texture correspondante, qui a été spécifiée lors de la création de l'objet. Lorsque texture est zéro, chacune des cibles énumérées au début de cette section est réinitialisée à sa texture par défaut pour l'unité d'image texture correspondante.

GETS ASSOCIÉS

glGet() avec les arguments GL_TEXTURE_BINDING_1D, GL_TEXTURE_BINDING_2D, GL_TEXTURE_BINDING_3D, GL_TEXTURE_BINDING_1D_ARRAY, GL_TEXTURE_BINDING_2D_ARRAY, GL_TEXTURE_BINDING_RECTANGLE, GL_TEXTURE_BINDING_BUFFER, GL_TEXTURE_BINDING_CUBE_MAP, GL_TEXTURE_BINDING_CUBE_MAP_ARRAY, GL_TEXTURE_BINDING_2D_MULTISAMPLE ou GL_TEXTURE_BINDING_2D_MULTISAMPLE_ARRAY.

ERREURS

Une erreur GL_INVALID_OPERATION est générée si texture n'est pas zéro ou le nom d'un objet texture existant.
