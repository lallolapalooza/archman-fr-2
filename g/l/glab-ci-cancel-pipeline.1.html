NOM

glab-ci-cancel-pipeline - Annuler les pipelines CI/CD.

SYNTAXE

glab ci cancel pipeline [flags]

DESCRIPTION

Annuler les pipelines CI/CD.

OPTIONS

--dry-run[=false] Simule le processus, mais n'annule rien.

OPTIONS HÉRITÉES DES COMMANDES PARENT

-h, --help[=false] Affiche l'aide pour cette commande.

-R, --repo="" Sélectionne un autre dépôt. Peut utiliser le format PROPRIETAIRE/REPO ou GROUPE/ESPACE_NOM/REPO. Accepte également une URL complète ou une URL Git.

EXEMPLE

$ glab ci cancel pipeline 1504182795
$ glab ci cancel pipeline 1504182795,1504182796
$ glab ci cancel pipeline "1504182795 1504182796"
$ glab ci cancel pipeline 1504182795,1504182796 --dry-run
