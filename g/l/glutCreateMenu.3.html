glutCreateMenu(3)

Paquet: freeglut

Licences: X11

glutCreateMenu(3) freeglut glutCreateMenu(3)

NOM

glutCreateMenu - crée un nouveau menu contextuel.

SYNTAXE

int glutCreateMenu(void (*func)(int value));

ARGUMENTS

func
La fonction de rappel pour le menu qui est appelée lorsqu'une entrée de menu est sélectionnée. La valeur passée à la fonction de rappel est déterminée par la valeur de l'entrée de menu sélectionnée.

DESCRIPTION

glutCreateMenu crée un nouveau menu contextuel et retourne un identifiant entier unique et petit. La plage des identifiants alloués commence à un. La plage des identifiants de menu est séparée de la plage des identifiants de fenêtre. Implicitement, le menu courant est défini sur le menu nouvellement créé. Cet identifiant de menu peut être utilisé lors de l'appel à glutSetMenu.

Lorsque la fonction de rappel de menu est appelée parce qu'une entrée de menu est sélectionnée pour ce menu, le menu courant sera implicitement défini sur le menu contenant l'entrée sélectionnée avant que la fonction de rappel ne soit appelée.

EXEMPLE

Voici un exemple rapide de la façon de créer un menu contextuel GLUT avec deux sous-menus et de l'attacher au bouton droit de la fenêtre courante :

  int submenu1, submenu2;
  submenu1 = glutCreateMenu(selectMessage);
  glutAddMenuEntry("abc", 1);
  glutAddMenuEntry("ABC", 2);
  submenu2 = glutCreateMenu(selectColor);
  glutAddMenuEntry("Green", 1);
  glutAddMenuEntry("Red", 2);
  glutAddMenuEntry("White", 3);
  glutCreateMenu(selectFont);
  glutAddMenuEntry("9 by 15", 0);
  glutAddMenuEntry("Times Roman 10", 1);
  glutAddMenuEntry("Times Roman 24", 2);
  glutAddSubMenu("Messages", submenu1);
  glutAddSubMenu("Color", submenu2);
  glutAttachMenu(GLUT_RIGHT_BUTTON);

NOTES D'IMPLÉMENTATION X

Si disponible, GLUT pour X utilisera les plans de surimpression (overlay planes) pour implémenter les menus contextuels. L'utilisation de plans de surimpression peut éliminer les appels de rappel d'affichage lorsque les menus contextuels sont désactivés. La convention SERVER_OVERLAY_VISUALS est utilisée pour déterminer si les visuels de surimpression sont disponibles.

VOIR AUSSI

glutCreateWindow, glutDestroyMenu, glutSetMenu, glutAttachMenu
