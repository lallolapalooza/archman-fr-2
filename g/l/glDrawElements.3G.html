NOM

glDrawElements - dessiner des primitives à partir de données de tableau

SPÉCIFICATION EN C

void glDrawElements(GLenum mode, GLsizei count, GLenum type, const void * indices);

PARAMÈTRES

mode

Spécifie le type de primitives à dessiner. Les constantes symboliques GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES, GL_TRIANGLE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY et GL_PATCHES sont acceptées.

count

Spécifie le nombre d'éléments à dessiner.

type

Spécifie le type des valeurs dans indices. Doit être l'une des valeurs : GL_UNSIGNED_BYTE, GL_UNSIGNED_SHORT, ou GL_UNSIGNED_INT.

indices

Spécifie un pointeur vers l'emplacement où les indices sont stockés.

DESCRIPTION

glDrawElements spécifie plusieurs primitives géométriques avec très peu d'appels de sous-rotines. Au lieu d'appeler une fonction GL pour passer chaque sommet individuel, normale, coordonnée de texture, drapeau d'arête ou couleur, vous pouvez pré-spécifier des tableaux séparés de sommets, de normales, etc., et les utiliser pour construire une séquence de primitives avec un seul appel à glDrawElements.

Lorsque glDrawElements est appelé, il utilise count éléments séquentiels d'un tableau activé, en commençant à indices, pour construire une séquence de primitives géométriques. mode spécifie quel type de primitives sont construites et comment les éléments du tableau construisent ces primitives. Si plus d'un tableau est activé, chacun est utilisé.

Les attributs de sommet qui sont modifiés par glDrawElements ont une valeur indéterminée après le retour de glDrawElements. Les attributs qui ne sont pas modifiés conservent leurs valeurs précédentes.

NOTES

GL_LINE_STRIP_ADJACENCY, GL_LINES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY et GL_TRIANGLES_ADJACENCY ne sont disponibles que si la version de GL est 3.2 ou supérieure.

ERREURS

GL_INVALID_ENUM est généré si mode n'est pas une valeur acceptée.

GL_INVALID_VALUE est généré si count est négatif.

GL_INVALID_OPERATION est généré si un shader de géométrie est actif et que mode est incompatible avec le type de primitive d'entrée du shader de géométrie dans l'objet programme actuellement installé.

GL_INVALID_OPERATION est généré si un nom d'objet tampon non nul est lié à un tableau activé ou au tableau d'éléments et que le magasin de données de l'objet tampon est actuellement mappé.
