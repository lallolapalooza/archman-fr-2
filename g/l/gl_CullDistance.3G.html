NOM

gl_CullDistance - fournit un mécanisme pour contrôler l'écrêtage utilisateur

DÉCLARATION

gl_CullDistance est un membre du bloc nommé gl_PerVertex :

    out gl_PerVertex {
        vec4 gl_Position;
        float gl_PointSize;
        float gl_ClipDistance[];
        float gl_CullDistance[];
    };

Dans les shaders de fragment, il est intrinsèquement déclaré comme : in float gl_CullDistance[] ;

DESCRIPTION

La variable gl_CullDistance fournit un mécanisme pour contrôler l'écrêtage utilisateur. L'élément gl_CullDistance[i] spécifie une distance d'écrêtage pour chaque plan i. Une distance de 0.0 signifie que le sommet est sur le plan, une distance positive signifie que le sommet est à l'intérieur du volume d'écrêtage, et une distance négative signifie que le point est à l'extérieur du volume d'écrêtage. Les primitives dont tous les sommets ont une distance de clip négative pour le plan i seront rejetées.

Le tableau gl_CullDistance est prédéclaré comme non dimensionné et doit être dimensionné par le shader, soit en le redéclarant avec une taille, soit en l'indexant uniquement avec des expressions constantes entières. La taille détermine le nombre et l'ensemble des distances d'écrêtage activées et ne peut pas dépasser gl_MaxCullDistances. Le nombre de composants variables consommés par gl_CullDistance correspondra à la taille du tableau. Les shaders écrivant dans gl_CullDistance doivent écrire toutes les distances activées, sinon les résultats de l'écrêtage sont indéfinis.

En tant que variable de sortie, gl_CullDistance fournit l'emplacement où le shader écrit ces distances. En tant qu'entrée dans tous les langages sauf le langage de fragment, il lit les valeurs écrites dans l'étape de shader précédente. Dans le langage de fragment, le tableau gl_CullDistance contient des valeurs interpolées linéairement pour les valeurs de sommet écrites par un shader dans la variable de sortie de sommet gl_CullDistance.

C'est une erreur de compilation ou de liaison si la somme des tailles des tableaux gl_ClipDistance et gl_CullDistance dans l'ensemble des shaders formant un programme est supérieure à gl_MaxCombinedClipAndCullDistances.
