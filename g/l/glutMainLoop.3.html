glutMainLoop(3) freeglut glutMainLoop(3)

NOM

glutMainLoop - entre dans la boucle de traitement des événements GLUT.

SYNTAXE

void glutMainLoop(void);

DESCRIPTION

glutMainLoop entre dans la boucle de traitement des événements GLUT. Cette routine ne doit être appelée qu'une seule fois dans un programme GLUT. Une fois appelée, cette routine ne retournera jamais. Elle appellera, si nécessaire, toutes les fonctions de rappel qui ont été enregistrées.
