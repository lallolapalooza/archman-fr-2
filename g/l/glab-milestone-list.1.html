NOM

glab-milestone-list - Obtenir une liste des jalons d'un projet ou d'un groupe.

SYNTAXE

glab milestone list [indicateurs]

DESCRIPTION

Obtenir une liste des jalons d'un projet ou d'un groupe.

OPTIONS

--group="" L'ID ou le chemin encodé dans l'URL du groupe.

--include-ancestors[=false] Inclure les jalons de tous les groupes parents.

-p, --page=1 Numéro de page.

-P, --per-page=20 Nombre d'éléments à afficher par page.

--project="" L'ID ou le chemin encodé dans l'URL du projet.

--search="" Retourner uniquement les jalons dont le titre ou la description correspond à la chaîne fournie.

--show-id[=false] Afficher les IDs dans la sortie du tableau.

--state="" Retourner uniquement les jalons 'actifs' ou 'fermés'.

--title="" Retourner uniquement les jalons ayant le titre donné.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-h, --help[=false] Afficher l'aide pour cette commande.

-R, --repo="" Sélectionner un autre dépôt. Peut utiliser le format PROPRIÉTAIRE/DÉPÔT ou GROUPE/ESPACENOM/DÉPÔT. Accepte également l'URL complète ou l'URL Git.

EXEMPLE

 # Lister les jalons pour un projet donné
$ glab milestone list --project 123
$ glab milestone list --project exemple-groupe/chemin-projet
# Lister les jalons pour un groupe
$ glab milestone list --group exemple-groupe
# Lister uniquement les jalons actifs pour un groupe donné
$ glab milestone list --group exemple-groupe --state active
