glutSetKeyRepeat(3) freeglut glutSetKeyRepeat(3)

NOM

glutSetKeyRepeat - définit le mode de répétition des touches

SYNTAXE

int glutSetKeyRepeat(int repeatMode);

ARGUMENTS

repeatMode
Mode de configuration de la répétition des touches.
GLUT_KEY_REPEAT_OFF
Désactive la répétition des touches pour le système de fenêtrage sur une base globale si possible.
GLUT_KEY_REPEAT_ON
Active la répétition des touches pour le système de fenêtrage sur une base globale si possible.
GLUT_KEY_REPEAT_DEFAULT
Réinitialise le mode de répétition des touches du système de fenêtrage à son état par défaut si possible.

DESCRIPTION

glutSetKeyRepeat définit le mode de répétition des touches pour le système de fenêtrage sur une base globale si possible. Si le système de fenêtrage le prend en charge, la répétition des touches peut être activée, désactivée ou définie sur l'état de répétition par défaut du système de fenêtrage.

NOTES D'IMPLÉMENTATION GLUT POUR X11

X11 envoie des événements KeyPress de manière répétée lorsque la répétition automatique globale du système de fenêtrage est activée. glutIgnoreKeyRepeat peut empêcher que ces frappes répétées automatiquement ne soient rapportées comme des callbacks clavier ou spéciaux, mais il y a toujours une surcharge minimale pour le serveur X pour diffuser continuellement des événements KeyPress à l'application GLUT. La routine glutSetKeyRepeat peut être utilisée pour désactiver réellement l'envoi global des événements KeyPress répétés automatiquement. Notez que glutSetKeyRepeat affecte l'état global de répétition automatique du système de fenêtrage, donc d'autres applications ne répéteront pas automatiquement si vous désactivez la répétition automatique globalement via glutSetKeyRepeat.

Les applications GLUT utilisant l'implémentation GLUT X11 devraient désactiver la répétition des touches avec glutSetKeyRepeat pour désactiver les répétitions de touches le plus efficacement.

Les applications GLUT qui modifient l'état de répétition des touches avec glutSetKeyRepeat sont responsables de restaurer explicitement l'état de répétition par défaut à la sortie.

NOTES D'IMPLÉMENTATION GLUT POUR WIN32

L'implémentation Win32 de glutSetKeyRepeat ne fait rien. La routine glutIgnoreKeyRepeat peut être utilisée dans l'implémentation GLUT Win32 pour ignorer les touches répétées sur une base par fenêtre sans modifier la répétition globale des touches du système de fenêtrage.
