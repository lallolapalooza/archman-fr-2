NOM

glab-duo-ask - Générer des commandes Git à partir du langage naturel.

SYNTAXE

glab duo ask [options]

DESCRIPTION

Générer des commandes Git à partir du langage naturel à l'aide de l'IA.

Décrivez ce que vous voulez faire en langage clair, et GitLab Duo suggérera les commandes Git appropriées. L'IA fournira à la fois les commandes et une explication.

Après avoir reçu les commandes suggérées, vous pouvez les exécuter directement depuis la CLI. Vous devez confirmer chaque commande avant son exécution.

Utilisez cette commande pour :

  • Récupérer des commandes Git oubliées.
  • Apprendre comment effectuer des opérations Git spécifiques.
  • Obtenir des conseils sur des flux de travail Git complexes.
  • Réduire le changement de contexte pendant le développement.

OPTIONS

--git[=true] Poser une question sur Git.

OPTIONS HERITEES DES COMMANDES PARENT

-h, --help[=false] Afficher l'aide pour cette commande.

EXEMPLE

$ glab duo ask list last 10 commit titles
> Une liste de commandes Git pour afficher les titres des 10 derniers commits avec une explication et une option pour exécuter les commandes.
$ glab duo ask how do I undo my last commit
> Suggestions pour annuler le dernier commit avec des explications sur différentes approches.
$ glab duo ask show me files changed in the last commit
> Commandes pour afficher les fichiers modifiés dans le dernier commit.
