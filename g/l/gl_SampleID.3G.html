NOM

gl_SampleID - contient l'indice de l'échantillon actuellement traité

DECLARATION

dans int gl_SampleID ;.SH "DESCRIPTION"

gl_SampleID est une variable d'entrée du langage de fragment qui contient l'indice de l'échantillon actuellement traité. Cette variable est dans l'intervalle de 0 à gl_NumSamples() - 1, où gl_NumSamples() est le nombre total d'échantillons par fragment pour le tampon de trame actuel (et donc 1 si le rendu est effectué sur un tampon non multisampling). Toute utilisation statique de cette variable dans un shader de fragment entraîne l'évaluation complète du shader par échantillon plutôt que par fragment.

Lors du rendu sur un tampon non multisampling, ou si l'échantillonnage multisampling est désactivé, gl_SampleID sera toujours zéro. gl_NumSamples() est le compte d'échantillons du tampon de trame, que l'échantillonnage multisampling soit activé ou non.
