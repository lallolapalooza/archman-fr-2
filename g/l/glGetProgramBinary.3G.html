NOM

glGetProgramBinary - renvoie une représentation binaire de la compilation et de la liaison exécutable source d'un objet programme

SPÉCIFICATION C

void glGetProgramBinary(GLuint program, GLsizei bufSize, GLsizei *length, GLenum *binaryFormat, void *binary);

PARAMÈTRES

program

Spécifie le nom d'un objet programme dont la représentation binaire doit être récupérée.

bufSize

Spécifie la taille du tampon dont l'adresse est donnée par binary.

length

Spécifie l'adresse d'une variable pour recevoir le nombre d'octets écrits dans binary.

binaryFormat

Spécifie l'adresse d'une variable pour recevoir un jeton indiquant le format des données binaires renvoyées par le GL.

binary

Spécifie l'adresse d'un tableau dans lequel le GL renverra la représentation binaire de program.

DESCRIPTION

glGetProgramBinary renvoie une représentation binaire de l'exécutable compilé et lié pour program dans le tableau d'octets dont l'adresse est spécifiée dans binary. Le nombre maximum d'octets qui peuvent être écrits dans binary est spécifié par bufSize. Si le binaire du programme est plus volumineux que bufSize octets, une erreur est générée, sinon le nombre réel d'octets écrits dans binary est renvoyé dans la variable dont l'adresse est donnée par length. Si length est NULL, alors aucune longueur n'est renvoyée.

Le format du binaire du programme écrit dans binary est renvoyé dans la variable dont l'adresse est donnée par binaryFormat, et peut dépendre de l'implémentation. Le binaire produit par le GL peut ensuite être renvoyé au GL en appelant glProgramBinary(), avec binaryFormat et length définis sur les valeurs renvoyées par glGetProgramBinary, et en passant les données binaires renvoyées dans le paramètre binary.

ERREURS

GL_INVALID_OPERATION est généré si bufSize est inférieur à la taille de GL_PROGRAM_BINARY_LENGTH pour program.

GL_INVALID_OPERATION est généré si GL_LINK_STATUS pour l'objet programme est faux.

ASSOCIÉES GETS

glGetProgram() avec l'argument GL_PROGRAM_BINARY_LENGTH
