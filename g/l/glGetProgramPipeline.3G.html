NOM

glGetProgramPipeline - récupérer les propriétés d'un objet pipeline de programme

SPÉCIFICATION C

void glGetProgramPipelineiv(GLuint pipeline, GLenum pname, GLint *params);

PARAMÈTRES

pipeline

Spécifie le nom d'un objet pipeline de programme dont il faut récupérer un paramètre.

pname

Spécifie le nom du paramètre à récupérer.

params

Spécifie l'adresse d'une variable dans laquelle sera écrite la ou les valeurs de pname pour pipeline.

DESCRIPTION

glGetProgramPipelineiv récupère la valeur d'une propriété de l'objet pipeline de programme pipeline. pname spécifie le nom du paramètre dont il faut récupérer la valeur. La valeur du paramètre est écrite dans la variable dont l'adresse est donnée par params.

Si pname est GL_ACTIVE_PROGRAM, le nom de l'objet programme actif du pipeline de programme est renvoyé dans params.

Si pname est GL_VERTEX_SHADER, le nom de l'objet programme courant pour le type de shader de sommets du pipeline de programme est renvoyé dans params.

Si pname est GL_TESS_CONTROL_SHADER, le nom de l'objet programme courant pour le type de shader de contrôle de tessellation du pipeline de programme est renvoyé dans params.

Si pname est GL_TESS_EVALUATION_SHADER, le nom de l'objet programme courant pour le type de shader d'évaluation de tessellation du pipeline de programme est renvoyé dans params.

Si pname est GL_GEOMETRY_SHADER, le nom de l'objet programme courant pour le type de shader géométrique du pipeline de programme est renvoyé dans params.

Si pname est GL_FRAGMENT_SHADER, le nom de l'objet programme courant pour le type de shader de fragment du pipeline de programme est renvoyé dans params.

Si pname est GL_INFO_LOG_LENGTH, la longueur du journal d'informations, incluant le terminateur null, est renvoyée dans params. S'il n'y a pas de journal d'informations, zéro est renvoyé.

ERREURS

GL_INVALID_OPERATION est généré si pipeline n'est pas zéro ou un nom précédemment renvoyé par un appel à glGenProgramPipelines() ou si un tel nom a été supprimé par un appel à glDeleteProgramPipelines().

GL_INVALID_ENUM est généré si pname n'est pas l'une des valeurs acceptées.
