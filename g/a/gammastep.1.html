NOM

gammastep - régler la température de couleur de l'écran en fonction de l'heure de la journée

SYNTAXE

gammastep [-l LAT:LON | -l FOURNISSEUR:OPTIONS] [-t JOUR:NUIT] [OPTIONS...]

DESCRIPTION

gammastep ajuste la température de couleur de votre écran en fonction de votre environnement. Cela peut aider à réduire la fatigue oculaire ou à diminuer le risque de syndrome de phase de sommeil retardée si vous travaillez devant l'écran la nuit.

La température de couleur est réglée en fonction de la position du soleil. Une température de couleur différente est appliquée pendant la nuit et le jour. Pendant le crépuscule et tôt le matin, la température de couleur évolue en douceur de la température nocturne à la température diurne pour permettre à vos yeux de s'adapter lentement sur une période d'environ une heure. La nuit, la température de couleur doit correspondre à celle des lampes de votre pièce. Il s'agit généralement d'une température basse d'environ 3000K-4000K (par défaut 4500K). Pendant la journée, la température de couleur doit correspondre à la lumière extérieure, généralement autour de 5500K-6500K (par défaut 6500K). La lumière a une température plus élevée par temps couvert.

En plus de l'outil en ligne de commande gammastep, l'interface graphique gammastep-indicator offre une interface alternative qui apparaît comme une icône de notification dans l'environnement de bureau.

OPTIONS

-h
Afficher le message d'aide.
-v
Activer la sortie détaillée.
-V
Afficher la version du programme.
-b JOUR:NUIT
Luminosité de l'écran à appliquer (entre 0.1 et 1.0).
-c FICHIER
Charger les paramètres depuis le fichier de configuration spécifié.
-g R:G:B
Correction gamma supplémentaire à appliquer.
-l LAT:LON
Votre position actuelle, en degrés, donnée sous forme de nombres décimaux, vers le nord et l'est, les nombres négatifs représentant le sud et l'ouest, respectivement.
-l FOURNISSEUR[:OPTIONS]
Sélectionner le fournisseur pour les mises à jour automatiques de la position (Utiliser "-l liste" pour voir les fournisseurs disponibles).
-m MÉTHODE[:OPTIONS]
Méthode à utiliser pour régler la température de couleur (Utiliser "-m liste" pour voir les méthodes disponibles).
-o
Mode unique (ne pas ajuster continuellement la température de couleur). Utiliser avec l'option -P pour effacer les courbes gamma existantes avant d'appliquer la nouvelle température de couleur.
-O TEMP
Mode manuel unique (définir la température de couleur). Utiliser avec l'option -P pour effacer les courbes gamma existantes avant d'appliquer le nouvel effet de couleur.
-p
Mode d'impression (afficher uniquement les paramètres et quitter).
-P
Réinitialiser les courbes gamma existantes avant d'appliquer le nouvel effet de couleur.
-x
Mode de réinitialisation (supprimer l'ajustement de l'écran).
-r
Désactiver le fondu entre les températures de couleur.
-t JOUR:NUIT
Température de couleur à régler pendant la journée/nuit.

La température neutre est de 6500K. Utiliser cette valeur ne changera pas la température de couleur de l'écran. Définir la température de couleur à une valeur supérieure à celle-ci résulte en plus de lumière bleue, et définir une valeur inférieure résultera en plus de lumière rouge.

Valeurs de température par défaut :

Journée : 6500K, nuit : 4500K

FICHIER DE CONFIGURATION

Un fichier de configuration nommé config.ini peut facultativement être placé dans ~/.config/gammastep/ (si la variable d'environnement XDG_CONFIG_HOME est indéfinie) ou ${XDG_CONFIG_HOME}/gammastep/ (si XDG_CONFIG_HOME est définie). Le fichier a le format INI standard. Les options générales du programme sont placées sous l'en-tête general, tandis que les options pour les fournisseurs de localisation et les méthodes d'ajustement sont placées sous un en-tête portant le nom de ce fournisseur ou de cette méthode. Les options générales sont :

temp-day = entier
Température diurne
temp-night = entier
Température nocturne
fade = 0 ou 1
Désactiver ou activer le fondu entre les températures de couleur.
brightness-day = 0.1-1.0
Luminosité de l'écran pendant la journée
brightness-night = 0.1-1.0
Luminosité de l'écran la nuit
elevation-high = décimal
L'élévation solaire en degrés pour la transition vers le jour
elevation-low = décimal
L'élévation solaire en degrés pour la transition vers la nuit
dawn-time = HH:MM[-HH:MM]
L'intervalle de temps personnalisé pour la transition de la nuit au jour le matin. Lorsqu'il est spécifié, l'élévation solaire ne sera pas utilisée pour déterminer la période diurne/nocturne actuelle. Si cette option est définie, dusk-time doit également être spécifié.
dusk-time = HH:MM[-HH:MM]
L'intervalle de temps personnalisé pour la transition du jour à la nuit le soir. Lorsqu'il est spécifié, l'élévation solaire ne sera pas utilisée pour déterminer la période diurne/nocturne actuelle. Si cette option est définie, dawn-time doit également être spécifié.
gamma = R:G:B
Ajustement gamma à appliquer (jour et nuit)
gamma-day = R:G:B
Ajustement gamma à appliquer pendant la journée
gamma-night = R:G:B
Ajustement gamma à appliquer la nuit
adjustment-method = nom
Sélectionner la méthode d'ajustement. Les options pour la méthode d'ajustement peuvent être fournies sous l'en-tête du fichier de configuration du même nom.
location-provider = nom
Sélectionner le fournisseur de localisation. Les options pour le fournisseur de localisation peuvent être fournies sous l'en-tête du fichier de configuration du même nom.

Les options pour les fournisseurs de localisation et les méthodes d'ajustement se trouvent dans l'aide des fournisseurs et méthodes.

EXEMPLE

Exemple pour Copenhague, Danemark :

$ gammastep -l 55.7:12.6 -t 5700:3600 -g 0.8 -m randr -v

Un exemple de fichier de configuration ayant le même effet que la commande ci-dessus :

[general]
temp-day=5700
temp-night=3600
gamma=0.8
adjustment-method=randr
location-provider=manual
[manual]
lat=55.7
lon=12.6

HOOKS

Les exécutables (par exemple, des scripts) placés dans le dossier ~/.config/gammastep/hooks seront exécutés lorsqu'un certain événement se produit. Le premier paramètre du script indique l'événement et les paramètres supplémentaires peuvent indiquer plus de détails sur l'événement. L'événement period-changed est indiqué lorsque la période change (night, daytime

, transition). Le second paramètre est l'ancienne période et le troisième est la nouvelle période. L'événement est également signalé au démarrage avec l'ancienne période définie à none. Les fichiers cachés (dotfiles) du dossier sont

ignorés.

Un script simple pour gérer ces événements peut être écrit comme ceci

: 
#!/bin/sh
case $1 in
    period-changed)
        exec notify-send "Gammastep" "Période changée en $3"
e
sac
