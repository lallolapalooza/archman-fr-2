DESCRIPTIO

N

gapplication est une implémentation en ligne de commande du côté client de l'interface org.freedesktop.Application telle que spécifiée par la spécification Desktop Entry de freedesktop.

org.

gapplication peut être utilisé pour démarrer des applications qui ont DBusActivatable défini à true dans leurs fichiers .desktop et peut être utilisé pour envoyer des messages aux instances déjà en cours d'exécution d'autres

applications.

Il est possible pour les applications de référencer gapplication dans la ligne Exec de leur fichier .desktop afin de maintenir la rétrocompatibilité avec les implémentations qui ne prennent pas directement en charge DBusActivatable

.

gapplication est fourni

dans le ca
dre de GLib.

Depuis les lignes Exec d'un fichier .de

sktop

L'interface en ligne de commande de gapplication a été conçue afin qu'elle puisse être utilisée directement depuis la ligne Exec d'un fichier .de

sktop.

Vous pourriez vouloir faire cela pour permettre la rétrocompatibilité avec les implémentations de la spécification qui ne comprennent pas comment faire l'activation D-Bus, sans avoir à installer un programme utilitaire

séparé.

Considérez l'exemple suivant

: 
[Desktop Entry]
Version=1.1
Type=Application
Name=Foo Viewer
DBusActivatab
le=true MimeType=image/x-foo; Exec=gapplication launch org.example.fooview
%F Actions=gallery;create; [Desktop Action gallery] Name=Browse Gallery Ex
ec=gapplication action org.example.fooview gallery [Desktop Action create]
Name=Create a new Foo! Exec=gapplication action org.example.fooview create

Depuis un

script

Si vous installez une application qui prend en charge l'activation D-Bus, vous pourriez toujours vouloir mettre un fichier dans /usr/bin afin que votre programme puisse être démarré depuis un

terminal.

Il est possible que ce fichier soit un script shell. Le script peut gérer des arguments tels que --help et --version directement. Il peut également analyser d'autres arguments de ligne de commande et les convertir en utilisations de gapplication pour activer l'application, ouvrir des fichiers ou invoquer des

actions.

Voici un exemple simplifié, tel qu'il pourrait être installé dans /usr/bin/foo

view : 
#!/bin/sh
case "$1" in
  --help)
    echo "see ‘man fooview’ for mor
e information" ;; --version) echo "fooview 1.2" ;; -
-gallery) gapplication action org.example.fooview gallery ;;
--create) gapplication action org.example.fooview create ;
; -*) echo "unrecognized commandline argument" exit 1
;; *) gapplication launch org.example.fooview "$@" ;; esac
