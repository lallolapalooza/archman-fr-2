NOM

gawkbug - signaler un bogue dans gawk

SYNTAXE

gawkbug [--version] [--help] [adresse-email]

DESCRIPTION

gawkbug est un script shell conçu pour aider l'utilisateur à composer et envoyer par courrier des rapports de bogue concernant gawk dans un format standard. gawkbug utilise l'éditeur spécifié par la variable d'environnement EDITOR sur une copie temporaire de l'ébauche du format du rapport de bogue. L'utilisateur doit remplir les champs appropriés et quitter l'éditeur. gawkbug envoie ensuite le rapport complété à bug-gawk@gnu.org, ou à adresse-email. Si le rapport ne peut pas être envoyé par courrier, il est sauvegardé dans le fichier dead.gawkbug dans le répertoire personnel de l'utilisateur invokedant.

L'ébauche du format du rapport de bogue se compose de plusieurs sections. La première section fournit des informations sur la machine, le système d'exploitation, la version de gawk et l'environnement de compilation. La deuxième section doit être remplie avec une description du bogue. La troisième section doit décrire comment reproduire le bogue. La quatrième section facultative est destinée à une correction proposée. Les corrections sont encouragées.

ENVIRONNEMENT

gawkbug utilisera les variables d'environnement suivantes si elles existent :

EDITOR
Spécifie l'éditeur préféré. Si EDITOR n'est pas défini, gawkbug tente de localiser un certain nombre d'éditeurs alternatifs, y compris vim, et si nécessaire, emacs. Si gawkbug ne parvient à localiser aucun des éditeurs alternatifs, il tente d'exécuter vi.
HOME
Répertoire dans lequel le rapport de bogue échoué est sauvegardé si l'envoi par courrier échoue.
TMPDIR
Répertoire dans lequel créer les fichiers et répertoires temporaires.
