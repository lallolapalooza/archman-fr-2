gai.conf(5) Format de fichier gai.conf(5)

NOM

gai.conf - fichier de configuration de getaddrinfo(3)

DESCRIPTION

Un appel à getaddrinfo(3) peut retourner plusieurs réponses. Selon la RFC 3484, ces réponses doivent être triées de manière à ce que la réponse ayant le taux de succès le plus élevé soit la première de la liste. La RFC fournit un algorithme pour ce tri. Les règles statiques ne sont cependant pas toujours adéquates. Pour cette raison, la RFC exige également que les administrateurs système aient la possibilité de changer dynamiquement le tri. Pour l'implémentation glibc, cela peut être réalisé avec le fichier /etc/gai.conf.

Chaque ligne du fichier de configuration se compose d'un mot-clé et de ses paramètres. Les espaces blancs sont ignorés. Les lignes commençant par '#' sont des commentaires et sont ignorées.

Les mots-clés actuellement reconnus sont :

label masque_r\303\251seau pr\303\251c\303\251dence
La valeur est ajoutée à la table des étiquettes utilisée dans le tri RFC 3484. Si une définition label est présente dans le fichier de configuration, la table par défaut n'est pas utilisée. Toutes les définitions d'étiquettes de la table par défaut qui doivent être conservées doivent être dupliquées. Après le mot-clé, la ligne doit contenir un masque réseau et une valeur de précellence.
precedence masque_r\303\251seau pr\303\251c\303\251dence
Ce mot-clé est similaire à label, mais la valeur est ajoutée à la table des précellences spécifiée dans la RFC 3484. Encore une fois, la présence d'une seule ligne precedence dans le fichier de configuration entraîne la non-utilisation de la table par défaut.
reload <oui|non>
Ce mot-clé contrôle si un processus vérifie si le fichier de configuration a été modifié depuis la dernière fois qu'il a été lu. Si la valeur est « oui », le fichier est relu. Cela peut causer des problèmes dans les applications multithread et est généralement une mauvaise idée. La valeur par défaut est « non ».
scopev4 masque valeur
Ajoute une nouvelle règle à la table des scopes RFC 3484 pour les adresses IPv4. Par défaut, les IDs de scope décrits dans la section 3.2 de la RFC 3438 sont utilisés. La modification de ces valeurs par défaut ne devrait jamais être nécessaire.

FICHIERS

/etc/gai.conf

VERSIONS

Le fichier gai.conf est pris en charge depuis glibc 2.5.

EXEMPLES

La table par défaut selon la RFC 3484 serait spécifiée avec le fichier de configuration suivant :


label  ::1/128       0
label  ::/0          1
label  2002::/16     2
label ::/96          3
label ::ffff:0:0/96  4
precedence  ::1/128       50
precedence  ::/0          40
precedence  2002::/16     30
precedence ::/96          20
precedence ::ffff:0:0/96  10

VOIR AUSSI

getaddrinfo(3), RFC 3484
