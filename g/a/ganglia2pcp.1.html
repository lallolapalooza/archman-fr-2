GANGLIA2PCP(1) Manuel des commandes générales GANGLIA2PCP(1)

NOM

ganglia2pcp - importer des données ganglia et créer une archive PCP

SYNTAXE

ganglia2pcp [-D debug] [-d outdir] [-e end] [-f outfile] [-h hostname] [-s start] [-V version] [-Z timezone] input_dir

DESCRIPTION

ganglia2pcp est destiné à lire un ensemble de fichiers ganglia stockés au format rrd et à les traduire en une archive Performance Co-Pilot (PCP) dont le nom de base est outfile.

L'intention de ce convertisseur est de prendre tous les fichiers rrd trouvés dans input_dir et de générer un seul fichier d'archive pcp. Le mappage des métriques ganglia aux métriques pcp est défini en interne.

L'archive PCP résultante peut être utilisée avec tous les outils clients PCP pour créer des graphiques de sous-ensembles de données à l'aide de pmchart(1), effectuer des réductions et des rapports de données, filtrer avec le moteur d'inférence PCP pmie(1), etc.

Une série de fichiers physiques sera créée avec le préfixe outfile. Ce sont outfile.0 (les données de performance), outfile.meta (les métadonnées décrivant les données de performance) et outfile.index (un index temporel pour améliorer l'efficacité des opérations de relecture pour l'archive). Si l'un de ces fichiers existe déjà, alors sar2pcp ne les écrasera **pas** et quittera avec un message d'erreur de la forme

__pmLogNewFile: ``blah.0'' existe déjà, non écrasé

ganglia2pcp est un script Perl qui utilise le wrapper Perl PCP::LogImport autour de la bibliothèque libpcp_import de PCP, et à ce titre pourrait être utilisé comme exemple pour développer de nouveaux outils afin d'importer d'autres types de données de performance et créer des archives PCP. Le wrapper Perl RRDs est utilisé pour analyser les fichiers bruts au format rrd.

OPTIONS

Les options de ligne de commande disponibles sont :

-d outdir
L'argument outdir spécifie une sortie sur laquelle écrire. Le défaut est le répertoire courant.
-e end
L'argument end spécifie une heure de fin dans un format compris par str2time. L'heure de début par défaut est l'heure actuelle.
-f outfile
L'argument outfile spécifie un nom de fichier de sortie. Le nom par défaut est au format standard pmlogger basé sur l'heure de début, par exemple, 20150201.00.10.
-h hostname
L'argument hostname spécifie un nom d'hôte à écrire dans l'archive. Le défaut est tiré du nom du répertoire dans lequel résident les fichiers rrd.
-s start
L'argument start spécifie une heure de début dans un format compris par str2time. L'heure de début par défaut est 24 heures avant l'heure actuelle.
-V version
L'option -V spécifie la version pour l'archive PCP de sortie. Par défaut, la version d'archive $PCP_ARCHIVE_VERSION (définie à 3 dans les versions actuelles de PCP) est utilisée, et les seules valeurs actuellement prises en charge pour version sont 2 ou 3.
-Z timezone
L'argument timezone définit le fuseau horaire source dans l'archive PCP (le défaut est d'utiliser le fuseau horaire local). Le fuseau horaire doit avoir le format +HHMM (pour les heures et minutes à l'Est de UTC) ou -HHMM (pour les heures et minutes à l'Ouest de UTC) ou UTC. Notez en particulier que **ni** le format zoneinfo (alias Olson), par exemple Europe/Paris, **ni** le format Posix TZ, par exemple EST+5, ne sont autorisés. Exemple : timezone=``+1100''.

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE BOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider au diagnostic des problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et de leur signification.

Les options de débogage spécifiques à ganglia2pcp sont les suivantes :

Option Description
appl0 configuration et découverte de métriques
appl1 génération de métriques-valeurs
