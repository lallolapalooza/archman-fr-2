NOM

gammu-smsd-mysql - module de stockage de gammu-smsd(1) utilisant un serveur de base de données MySQL

DESCRIPTION

Le module MySQL stocke toutes les données dans un serveur de base de données MySQL, dont les paramètres sont définis par la configuration (voir gammu-smsdrc pour la description des options de configuration).

Pour la description des tables, voir gammu-smsd-tables.

Ce module est basé sur gammu-smsd-sql.

CONFIGURATION

Avant de lancer gammu-smsd, vous devez créer les tables nécessaires dans la base de données, comme décrit ci-dessous.

Le fichier de configuration peut ensuite ressembler à ceci :

[smsd]
service = sql
driver = native_mysql
host = localhost

VOIR AUSSI :

gammu-smsdrc

PRIVILÈGES

L'utilisateur accédant à la base de données n'a pas besoin de nombreux privilèges, les privilèges suivants devraient suffire :

GRANT USAGE ON *.* TO 'smsd'@'localhost' IDENTIFIED BY 'password';
GRANT SELECT, INSERT, UPDATE, DELETE ON `smsd`.* TO 'smsd'@'localhost';
CREATE DATABASE smsd;

NOTE :

Pour créer les tables SQL, vous avez besoin de plus de privilèges, en particulier pour créer les déclencheurs (triggers), qui sont utilisés pour certaines fonctionnalités.

CRÉATION DES TABLES POUR MYSQL

En fonction de la version et des paramètres de MySQL, veuillez choisir le script le plus adapté pour créer les tables :

  • mysql.sql, nécessite MySQL 5.6.5 ou plus récent
  • mysql-legacy.sql prend en charge les anciennes versions de MySQL, mais ne nécessite aucun des modes NO_ZERO_DATE, ANSI ou STRICT configurés sur le serveur

Script SQL mysql.sql pour créer les tables dans la base de données MySQL :

-- 
-- Database for Gammu SMSD
-- 
-- In case you get errors about not supported charset, please

-- Table structure for table `gammu`
--

  `Version` integer NOT NULL default '0' PRIMARY KEY
) ENGINE=MyISAM DEFAULT CHARSET=utf8mb4;

-- Dumping data for table `gammu`
-- 
INSERT INTO `gammu` (`Version`) VALUES (17);

-- Table structure for table `inbox`
-- 
CREATE TABLE `inbox` (
  `UpdatedInDB` timestamp NOT NULL default CURRENT_TIMESTAMP on update CURRENT_TIMESTAMP,
  `ReceivingDateTime` timestamp NOT NULL default CURRENT_TIMESTAMP,
  `Text` text NOT NULL,
  `SenderNumber` varchar(20) NOT NULL default '',
  `Coding` enum('Default_No_Compression','Unicode_No_Compression','8bit','Default_Compression','Unicode_Compression') NOT NULL default 'Default_No_Compression',
  `UDH` text NOT NULL,
  `SMSCNumber` varchar(20) NOT NULL default '',
  `Class` integer NOT NULL default '-1',
  `TextDecoded` text NOT NULL,
  `ID` integer unsigned NOT NULL auto_increment,
  `RecipientID` text NOT NULL,
  `Processed` enum('false','true') NOT NULL default 'false',
  `Status` integer NOT NULL default '-1',
  PRIMARY KEY `ID` (`ID`)
) ENGINE=MyISAM DEFAULT CHARSET=utf8mb4 AUTO_INCREMENT=1 ;
-- 
-- Dumping data for table `inbox`
-- 
-- --------------------------------------------------------
-- 
-- Table structure for table `outbox`
-- 
CREATE TABLE `outbox` (
  `UpdatedInDB` timestamp NOT NULL default CURRENT_TIMESTAMP on update CURRENT_TIMESTAMP,
  `InsertIntoDB` timestamp NOT NULL default CURRENT_TIMESTAMP,
  `SendingDateTime` timestamp NOT NULL default CURRENT_TIMESTAMP,
  `SendBefore` time NOT NULL DEFAULT '23:59:59',
  `SendAfter` time NOT NULL DEFAULT '00:00:00',
  `Text` text,
  `DestinationNumber` varchar(20) NOT NULL default '',
  `Coding` enum('Default_No_Compression','Unicode_No_Compression','8bit','Default_Compression','Unicode_Compression') NOT NULL default 'Default_No_Compression',
  `UDH` text,
  `Class` integer default '-1',
  `TextDecoded` text NOT NULL,
  `ID` integer unsigned NOT NULL auto_increment,
  `MultiPart` enum('false','true') default 'false',
  `RelativeValidity` integer default '-1',
  `SenderID` varchar(255),
  `SendingTimeOut` timestamp NULL default CURRENT_TIMESTAMP,
  `DeliveryReport` enum('default','yes','no') default 'default',
  `CreatorID` text NOT NULL,
  `Retries` int(3) default 0,
  `Priority` integer default 0,
  `Status` enum('SendingOK','SendingOKNoReport','SendingError','DeliveryOK','DeliveryFailed','DeliveryPending','DeliveryUnknown','Error','Reserved') NOT NULL default 'Reserved',
  `StatusCode` integer NOT NULL default '-1',
  PRIMARY KEY `ID` (`ID`)
) ENGINE=MyISAM DEFAULT CHARSET=utf8mb4;
CREATE INDEX outbox_date ON outbox(SendingDateTime, SendingTimeOut);
CREATE INDEX outbox_sender ON outbox(SenderID(250));

-- Déclencheurs pour définir les horodatages par défaut
--
DELIMITER //
CREATE TRIGGER inbox_timestamp BEFORE INSERT ON inbox
FOR EACH ROW
BEGIN
    IF NEW.ReceivingDateTime = '0000-00-00 00:00:00' THEN
        SET NEW.ReceivingDateTime = CURRENT_TIMESTAMP();
    END IF;
END;//
CREATE TRIGGER outbox_timestamp BEFORE INSERT ON outbox
FOR EACH ROW
BEGIN
    IF NEW.InsertIntoDB = '0000-00-00 00:00:00' THEN
        SET NEW.InsertIntoDB = CURRENT_TIMESTAMP();
    END IF;
    IF NEW.SendingDateTime = '0000-00-00 00:00:00' THEN
        SET NEW.SendingDateTime = CURRENT_TIMESTAMP();
    END IF;
    IF NEW.SendingTimeOut = '0000-00-00 00:00:00' THEN
        SET NEW.SendingTimeOut = CURRENT_TIMESTAMP();
    END IF;
END;//
CREATE TRIGGER phones_timestamp BEFORE INSERT ON phones
FOR EACH ROW
BEGIN
    IF NEW.InsertIntoDB = '0000-00-00 00:00:00' THEN
        SET NEW.InsertIntoDB = CURRENT_TIMESTAMP();
    END IF;
    IF NEW.TimeOut = '0000-00-00 00:00:00' THEN
        SET NEW.TimeOut = CURRENT_TIMESTAMP();
    END IF;
END;//
CREATE TRIGGER sentitems_timestamp BEFORE INSERT ON sentitems
FOR EACH ROW
BEGIN
    IF NEW.InsertIntoDB = '0000-00-00 00:00:00' THEN
        SET NEW.InsertIntoDB = CURRENT_TIMESTAMP();
    END IF;
    IF NEW.SendingDateTime = '0000-00-00 00:00:00' THEN
        SET NEW.SendingDateTime = CURRENT_TIMESTAMP();
    END IF;
END;//
DELIMITER ;

MISE À NIVEAU DES TABLES

La façon la plus simple de mettre à niveau la structure de la base de données est de sauvegarder l'ancienne et de commencer par en créer une nouvelle basée sur l'exemple ci-dessus.

Pour mettre à niveau une base de données existante, vous pouvez utiliser les modifications décrites dans smsd-tables-history puis mettre à jour manuellement le champ Version dans la table gammu
