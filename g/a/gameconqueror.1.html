NOM

gameconqueror - Une interface graphique pour scanmem, un outil de piratage de jeux.

SYNTAXE

gameconqueror [options] [pid-du-programme-cible]

DESCRIPTION

Scanmem est un utilitaire de débogage interactif simple pour Linux, utilisé pour localiser l'adresse d'une variable dans un processus en cours d'exécution. Ceci peut être utilisé pour l'analyse ou la modification d'un processus hostile sur une machine compromise, pour l'ingénierie inverse, ou comme un "trouveur de triche" pour tricher aux jeux vidéo.

GameConqueror est une interface graphique pour scanmem, vise à fournir plus de fonctionnalités que scanmem, et une interface conviviale similaire à CheatEngine.

OPTIONS

-v, --version
Affiche la version et quitte.
-h, --help
Affiche une courte description des options de la ligne de commande et quitte.
-s, --search=valeur
Remplit la boîte de recherche avec la valeur donnée.
