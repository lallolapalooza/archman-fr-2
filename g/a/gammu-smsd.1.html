NOM

gammu-smsd - Démon SMS pour Gammu

SYNOPSIS

gammu-smsd [OPTION]...

DESCRIPTION

Cette page manuel documente brièvement la commande gammu-smsd .

gammu-smsd est un programme qui scanne périodiquement le modem GSM pour les messages reçus, les stocke dans le stockage défini et envoie également les messages mis en file d'attente dans ce stockage.

Le démon peut recharger le fichier de configuration après l'envoi du signal d'accroche (SIGHUP) et se termine proprement sur SIGINT et SIGTERM.

Le programme accepte les options suivantes (veuillez noter que les options longues peuvent ne pas être acceptées sur certaines plateformes) :

-h, --help
Affiche l'aide.
-v, --version
Affiche les informations de version et les fonctionnalités compilées.
-c, --config=file
Fichier de configuration à utiliser, par défaut c'est /etc/gammu-smsdrc, sur Windows il n'y a pas de valeur par défaut et le chemin du fichier de configuration doit toujours être spécifié.

Si vous exécutez SMSD en tant que démon système (ou service), il est recommandé d'utiliser le chemin absolu vers le fichier de configuration car le répertoire de démarrage peut être différent de ce que vous attendez.

Voir gammu-smsdrc pour la documentation du fichier de configuration.

-p, --pid=file
Fichier de verrouillage pour stocker le pid, vide pour aucun verrouillage. Non pris en charge sur Windows.
-U, --user=user
Abaisse les privilèges du démon vers l'utilisateur choisi après le démarrage.
-G, --group=group
Abaisse les privilèges du démon vers le groupe choisi après le démarrage.
-d, --daemon
Transforme le programme en démon au démarrage. Non pris en charge sur Windows.
-i, --install-service
Installe SMSD en tant que service Windows.
-u, --uninstall-service
Désinstalle SMSD en tant que service Windows.
-s, --start-service
Démarre le service SMSD Windows.
-k, --stop-service
Arrête le service SMSD Windows.
-f, --max-failures=count
Se termine après un nombre défini d'échecs. Utilisez 0 pour ne pas se terminer (c'est la valeur par défaut).
-X, --suicide=seconds
Se tue après un nombre de secondes.
-S, --run-service
Exécute le programme en tant que service SMSD Windows. Cela ne devrait pas être utilisé manuellement, mais seul le gestionnaire de services Windows devrait utiliser cette commande.
-n, --service-name=name
Définit le nom d'un service Windows. Chaque service nécessite un nom unique, donc si vous voulez exécuter plusieurs instances SMSD, vous devez nommer chaque service différemment. La valeur par défaut est "GammuSMSD".
-l, --use-log
Utilise la journalisation telle que configurée dans le fichier de configuration (par défaut).
-L, --no-use-log
N'utilise pas la journalisation telle que configurée dans le fichier de configuration.
-e, --install-event-log
Installe la description Windows EventLog dans le registre.

Nouveau dans la version 1.31.90.

-E, --uninstall-event-log
Désinstalle la description Windows EventLog du registre.

Nouveau dans la version 1.31.90.

SIGNAUX

SMSD peut être contrôlé à l'aide des signaux POSIX suivants (si votre plateforme le supporte) :

SIGHUP
Recharge la configuration et se reconnecte au téléphone.
SIGINT, SIGTERM
Arrête le démon proprement.
SIGALRM
Utilisé en interne pour gammu-smsd -X
SIGUSR1
Suspend l'opération de SMSD, fermant la connexion au téléphone et à la base de données.
SIGUSR2
Reprend l'opération de SMSD (après la suspension précédente).

Changé dans la version 1.22.91 : Ajout du support pour SIGHUP.

Changé dans la version 1.22.95 : Ajout du support pour SIGALRM.

Changé dans la version 1.31.90 : Ajout du support pour SIGUSR1 et SIGUSR2.

EXEMPLES

Exemples Linux/Unix

Démarrer SMSD en tant que démon sur Linux :

gammu-smsd --config /etc/gammu-smsdrc --pid /var/run/gammu-smsd.pid --daemon

Démarrer SMSD en tant que démon sur Linux avec des privilèges réduits :

gammu-smsd --config /etc/gammu-smsdrc --pid /var/run/gammu-smsd.pid --daemon --user gammu --group gammu

SMSD en tant que démon système

Pour utiliser SMSD en tant que démon, vous voudrez peut-être utiliser le script d'init qui est fourni avec Gammu dans le répertoire contrib/init. Il n'est pas installé par défaut, soit installez-le manuellement, soit consultez le fichier INSTALL pour des instructions.

Sous Windows 7, vous devrez peut-être désactiver le UAC (contrôle de compte utilisateur) avant de pouvoir installer le service SMSD.

Exemples de services Windows

Installer le service Windows Gammu SMSD :

gammu-smsd.exe -c c:\Gammu\smsdrc -i

Installer deux instances du service Windows SMSD :

gammu-smsd.exe -c c:\Gammu\smsdrc-1 -n Gammu-first-phone -i
gammu-smsd.exe -c c:\Gammu\smsdrc-2 -n Gammu-second-phone -i

Pour désinstaller un service Windows :

gammu-smsd.exe -u

Dépannage du service Windows

Si Gammu échoue à démarrer en tant que service Windows (vous obtiendrez généralement "Erreur 1053 : Le service n'a pas répondu à la demande de démarrage ou de contrôle dans les délais impartis"), vérifiez d'abord vos journaux SMSD. S'ils ne contiennent aucun indice utile, essayez de démarrer SMSD manuellement avec exactement les mêmes paramètres que ceux avec lesquels vous avez installé le service (sans -i).

Par exemple, la ligne de commande peut ressembler à :

gammu-smsd.exe -c smsdrc

Vous devriez maintenant pouvoir obtenir les erreurs de SMSD même s'il échoue à démarrer en tant que service.

Invoquer Gammu et suspendre SMSD

CommeVous ne pouvez pas exécuter Gammu et Gammu SMSD en même temps sur un seul appareil. Vous pouvez contourner cette limitation en suspendant temporairement SMSD en utilisant SIGUSR1 et SIGUSR2 signaux (voir aussi Signaux) :

SMSD_PID=`pidof gammu-smsd`
if [ -z "$SMSD_PID" ] ; then
    echo "Failed to figure out SMSD PID!"
else
    kill -SIGUSR1 $SMSD_PID
    gammu identify
    kill -SIGUSR2 $SMSD_PID
fi

Ou même créer un script gammu-safe :

#!/bin/bash
SMSD_PID=`pidof gammu-smsd`
if [ -z "$SMSD_PID" ] ; then
  gammu $@
else
  tty=$(lsof |grep -E "gammu-sms\s+$SMSD_PID\s+.*/dev/tty*"|awk {'print $NF'})
  kill -SIGUSR1 $SMSD_PID
  while test "$(fuser $ttyfuser $tty 2> /dev/null|xargs)" = $SMSD_PID
  do
    sleep 1
  done
  sleep 1
  gammu $@
  kill -SIGUSR2 $SMSD_PID
  while test "$(fuser $ttyfuser $tty 2> /dev/null|xargs)" != $SMSD_PID
  do
    sleep 1
  done
  sleep 1
fi

LIMITATIONS CONNUES

Vous ne pouvez pas utiliser le même téléphone par plusieurs programmes en même temps. Cependant, si vous n'avez pas activé le verrouillage dans la section [gammu] , il est possible de démarrer la communication avec le téléphone depuis plusieurs programmes. Dans ce cas, aucun des programmes ne fonctionnera probablement, voir Invoquer Gammu et suspendre SMSD pour une solution de contournement.

Il n'existe aucun moyen de détecter qu'un message SMS est la réponse à un autre en examinant les en-têtes du message. La seule façon d'y parvenir est d'ajouter un jeton au message et de demander à l'utilisateur de l'inclure dans sa réponse.
