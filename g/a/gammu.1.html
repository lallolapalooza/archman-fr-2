GAMMU(1) Gammu GAMMU(1)

NOM

gammu - Effectue des opérations intéressantes avec votre téléphone portable ou modem.

SYNTAXE

gammu [paramètres] <commande> [options]

Les commandes indiquent l'opération que Gammu doit effectuer. Elles peuvent être spécifiées avec ou sans un préfixe --.

DESCRIPTION

Ce programme est un outil pour téléphones portables. De nombreux fabricants et modèles sont pris en charge, pour une liste actualisée, consultez la Base de données des téléphones Gammu.

Options

Les paramètres avant la commande configurent le comportement de gammu :

-c, --config <nom_fichier>
nom du fichier de configuration (voir gammurc)
-s, --section <nom_section>
section du fichier de configuration à utiliser, par exemple 42
-d, --debug <niveau>
niveau de débogage (voir LogFormat dans gammurc pour les valeurs possibles)
-f, --debug-file <nom_fichier>
fichier pour l'enregistrement des messages de débogage

Commandes SMS et EMS

L'envoi de messages peut sembler un peu compliqué lors de la première utilisation. Mais soyez patient, la ligne de commande a été conçue pour permettre presque toutes les utilisations. Consultez la section EXEMPLE pour quelques conseils d'utilisation.

Il existe également une option pour utiliser gammu-smsd lorsque vous souhaitez envoyer ou recevoir plus de messages et les traiter automatiquement.

Introduction aux formats SMS

Gammu prend en charge de nombreux formats SMS tels que :

Nokia Smart Messaging
utilisé pour les images monochromes, les profils téléchargeables, les logos d'opérateur monochromes, les logos d'appelant monochromes et les sonneries monophoniques
SMS liés (Linked SMS)
avec des numéros d'identification en-tête à 8 et 16 bits
EMS
c'est le format SMS utilisé pour enregistrer des images monochromes, des sonneries monophoniques, des animations, le formatage de texte et autres
Notifications MMS
contient des liens où le téléphone doit télécharger les MMS
Messages logo Alcatel
format propriétaire pour les logos

Vous devez vous assurer que le téléphone cible prend en charge le type de message que vous souhaitez envoyer. Sinon, le téléphone ne pourra pas l'afficher ou plantera même, car le firmware du téléphone ne s'attendait pas à cette possibilité.

Encodage des caractères dans le texte SMS

Le texte dans un SMS peut être codé de deux manières :

Alphabet par Défaut GSM

Avec l'Alphabet par Défaut GSM, vous pouvez faire tenir au maximum 160 caractères dans un seul SMS (Gammu ne prend pas en charge la compression de tels textes selon les normes GSM, mais ce n'est pas une grande limite, car il n'y a pas de téléphones les prenant en charge), mais ils proviennent d'un ensemble limité :

  • toutes les lettres minuscules et majuscules latines
  • tous les chiffres
  • quelques caractères grecs
  • quelques autres caractères nationaux
  • quelques symboles comme @ ! " # & / ( ) % * + = - , . : ; < > ?
  • quelques autres

Unicode

Avec l'Unicode, un seul SMS peut contenir au maximum 70 caractères, mais ceux-ci peuvent être n'importe quels caractères, y compris tous les caractères nationaux et spéciaux.

AVERTISSEMENT :

Veuillez noter que certains téléphones plus anciens peuvent avoir des problèmes pour afficher un tel message.

Conversion

Gammu fait de son mieux pour gérer les caractères non ASCII dans votre message. Tout est traité en interne en Unicode (l'entrée est convertie en fonction de la configuration de vos locales) et si le message utilise Unicode, le texte sera transmis tel quel au message.
