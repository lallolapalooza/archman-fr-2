SQL QUERIES

By default gammu-smsd uses MySQL database and following queries are written for it. You can change them in config file. For details see gammu-smsdrc(5).

save_inbox_sms_insert
Insérer le message reçu.

Valeur par défaut:

INSERT INTO inbox (ReceivingDateTime, Text, SenderNumber, Coding, SMSCNumber, UDH,
Class, TextDecoded, RecipientID) VALUES (%d, %E, %R, %c, %F, %u, %x, %T, %P)
update_received
Mettre à jour les statistiques après réception du message.

Valeur par défaut:

UPDATE phones SET Received = Received + 1 WHERE IMEI = %I
refresh_send_status
Mettre à jour les messages dans la boîte d'envoi.

Valeur par défaut:

UPDATE outbox SET SendingTimeOut = (NOW() + INTERVAL 60 SECOND) + 0
WHERE ID = %1 AND (SendingTimeOut < NOW() OR SendingTimeOut IS NULL)

La requête par défaut calcule le délai d'envoi basé sur la valeur LoopSleep.

Paramètres spécifiques à la requête:

%1
ID du message
find_outbox_sms_id
Trouver les messages SMS à envoyer.

Valeur par défaut:

SELECT ID, InsertIntoDB, SendingDateTime, SenderID FROM outbox
WHERE SendingDateTime < NOW() AND SendingTimeOut < NOW() AND
SendBefore >= CURTIME() AND SendAfter <= CURTIME() AND
( SenderID is NULL OR SenderID = '' OR SenderID = %P ) ORDER BY InsertIntoDB ASC LIMIT %1

Paramètres spécifiques à la requête:

%1
limite de messages SMS envoyés en une seule passe dans la boucle
find_outbox_body
Sélectionner le corps du message.

Valeur par défaut:

SELECT Text, Coding, UDH, Class, TextDecoded, ID, DestinationNumber, MultiPart,
RelativeValidity, DeliveryReport, CreatorID FROM outbox WHERE ID=%1

Paramètres spécifiques à la requête:

%1
ID du message
find_outbox_multipart
Sélectionner les parties restantes du message SMS.

Valeur par défaut:

SELECT Text, Coding, UDH, Class, TextDecoded, ID, SequencePosition
FROM outbox_multipart WHERE ID=%1 AND SequencePosition=%2

Paramètres spécifiques à la requête:

%1
ID du message
%2
Numéro de la partie multipart du message
delete_outbox
Supprimer les messages de la boîte d'envoi après leur envoi réussi.

Valeur par défaut:

DELETE FROM outbox WHERE ID=%1

Paramètres spécifiques à la requête:

%1
ID du message
delete_outbox_multipart
Supprimer les messages de outbox_multipart après leur envoi réussi.

Valeur par défaut:

DELETE FROM outbox_multipart WHERE ID=%1

Paramètres spécifiques à la requête:

%1
ID du message
create_outbox
Créer un message (insérer dans la boîte d'envoi).

Valeur par défaut:

INSERT INTO outbox (CreatorID, SenderID, DeliveryReport, MultiPart,
InsertIntoDB, Text, DestinationNumber, RelativeValidity, Coding, UDH, Class,
TextDecoded) VALUES (%1, %P, %2, %3, NOW(), %E, %R, %V, %c, %u, %x, %T)

Paramètres spécifiques à la requête:

%1
créateur du message
%2
rapport de statut de livraison - oui/par défaut
%3
multipart - FAUX/VRAI
%4
Partie (numéro de partie)
%5
ID du message
create_outbox_multipart
Créer les parties restantes du message.

Valeur par défaut:

INSERT INTO outbox_multipart (SequencePosition, Text, Coding, UDH, Class,
TextDecoded, ID) VALUES (%4, %E, %c, %u, %x, %T, %5)

Paramètres spécifiques à la requête:

créateur du message

multipart - FAUX/VRAI
%4
Partie (numéro de partie)

ID du message
add_sent_info
Insérer dans sentitems.

Valeur par défaut:

INSERT INTO sentitems (CreatorID,ID,SequencePosition,Status,SendingDateTime,
SMSCNumber, TPMR, SenderID,Text,DestinationNumber,Coding,UDH,Class,TextDecoded,
InsertIntoDB,RelativeValidity)
VALUES (%A, %1, %2, %3, NOW(), %F, %4, %P, %E, %R, %c, %u, %x, %T, %5, %V)

Paramètres spécifiques à la requête:

%1
ID du message SMS
%2
numéro de partie (pour SMS multipart)
%3
état du message (SendingError, Error, SendingOK, SendingOKNoReport)
%4
référence du message (TPMR)
%5
heure d'insertion dans la base de données
update_sent
Mettre à jour les statistiques d'envoi après l'envoi du message.

Valeur par défaut:

UPDATE phones SET Sent= Sent + 1 WHERE IMEI = %I
refresh_phone_status
Mettre à jour le statut du téléphone (batterie, signal).

Valeur par défaut:

UPDATE phones SET TimeOut= (NOW() + INTERVAL 10 SECOND) + 0,
Battery = %1, Signal = %2 WHERE IMEI = %I

Paramètres spécifiques à la requête:

%1
pourcentage de batterie
%2
pourcentage de signal
update_retries
Mettre à jour le nombre de tentatives pour un message en attente. L'intervalle peut être configuré par RetryTimeout.
UPDATE outbox SET SendngTimeOut = (NOW() + INTERVAL 600 SECOND) + 0,
Retries = %2 WHERE ID = %1

Paramètres spécifiques à la requête:

%1
ID du message
%2
nombre de tentatives
