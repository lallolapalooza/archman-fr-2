NOM

gajim - un client de chat XMPP complet

SYNTAXE

gajim -h

gajim --start-chat

gajim [-q] [-v] [-w] [-l sous-système=niveau] [-u nom] [-p nom] [-s] [-c répertoire] [--gdebug] [--cprofile]

DESCRIPTION

gajim se veut un client XMPP facile à utiliser et complet. Discutez simplement avec vos amis ou votre famille, partagez facilement des images et vos pensées ou discutez de l'actualité avec vos groupes. Discutez en toute sécurité avec le chiffrement de bout en bout via OMEMO ou OpenPGP. Gajim s'intègre bien avec vos autres appareils : continuez simplement vos conversations sur votre appareil mobile.

XMPP est le Extensible Messaging and Presence Protocol, un ensemble de technologies ouvertes pour la messagerie instantanée, la présence, le chat multipartite, les appels vocaux et vidéo, la collaboration, le middleware léger, la syndication de contenu et le routage généralisé des données XML. Pour plus d'informations sur le protocole XMPP, voir https://xmpp.org/about/.

OPTIONS

-h, --help
Afficher les options d'aide
-V, --version
Afficher la version de l'application
-q, --quiet
Afficher uniquement les erreurs critiques
-s, --separate
OBSOLÈTE : Séparer complètement les fichiers de profil (même la base de données d'historique et les plugins)
-v, --verbose
Imprimer les strophes XML et autres informations de débogage
-u, --user-profile=NOM
Utiliser un profil pour exécuter plusieurs instances de Gajim
-p, --profile=NOM
OBSOLÈTE : Utiliser le profil défini dans le répertoire de configuration
-c, --config-path=CHEMIN
Définir le répertoire de configuration
-l, --loglevel=SOUS-SYSTÈME=NIVEAU
Configurer la journalisation.

SOUS-SYSTÈME, par ex. gajim.c.m

NIVEAU (DEBUG, INFO, WARNING, ERROR, CRITICAL)

Exemple : gajim.c.m=DEBUG

-w, --warnings
Afficher tous les avertissements
--gdebug
Définit une variable d'environnement pour que les messages de débogage GLib soient imprimés
--cprofile
Profiler l'application avec cprofile
--start-chat
Démarrer un nouveau chat

FICHIERS

$XDG_CACHE_HOME/gajim/
Le répertoire pour les données mises en cache.
$XDG_CONFIG_HOME/gajim/
Le répertoire où les paramètres et configurations sont stockés.
$XDG_DATA_HOME/gajim/
Le répertoire où toutes les données persistantes, par ex. la base de données des messages, sont stockées.
