GAMMU-SMSD-ODBC(7) Gammu GAMMU-SMSD-ODBC(7)

NOM

gammu-smsd-odbc - backend de gammu-smsd(1) utilisant la couche d'abstraction ODBC pour utiliser n'importe quelle base de données prise en charge comme stockage de messages

DESCRIPTION

Nouveau dans la version 1.29.92.

Le backend ODBC stocke toutes les données dans n'importe quelle base de données prise en charge par ODBC, dont les paramètres sont définis par la configuration (voir gammu-smsdrc pour la description des options de configuration).

Pour la description des tables, voir gammu-smsd-tables.

Ce backend est basé sur gammu-smsd-sql.

PILOTES PRIS EN CHARGE

Sous Microsoft Windows, Gammu utilise ODBC natif, sur d'autres plateformes, unixODBC peut être utilisé.

LIMITATIONS

En raison des limites de l'interface ODBC, Gammu ne peut pas détecter de manière fiable le moteur SQL auquel il est connecté.

Dans la plupart des cas, cela peut être résolu en définissant le paramètre SQL sur le dialecte correct.

Si cela échoue, vous pouvez également ajuster les requêtes SQL pour qu'elles fonctionnent sur le serveur SQL utilisé, voir Requêtes SQL pour plus de détails. Néanmoins, vous devriez définir SQL sur le dialecte SQL le plus proche.

CONFIGURATION

Avant d'exécuter gammu-smsd, vous devez créer les tables nécessaires dans la base de données. Vous pouvez utiliser les exemples donnés dans les parties du manuel spécifiques aux backends de base de données pour ce faire.

Vous spécifiez le nom de la source de données (DSN) comme Host dans gammu-smsdrc. La source de données est configurée en fonction de votre plateforme.

NOTE :

N'oubliez pas que SMSD peut s'exécuter dans un contexte différent de celui de votre utilisateur (compte séparé sous Linux ou en tant que service sous Windows), le DSN ODBC doit donc être configuré comme étant global dans ce cas (DSN système sous Windows ou dans la configuration globale sous Linux).

Sous Microsoft Windows, vous pouvez trouver des instructions sur le site Web de Microsoft : https://support.microsoft.com/kb/305599

Pour unixODBC, ceci est documenté dans le manuel de l'utilisateur : http://www.unixodbc.org/doc/UserManual/

CRÉATION DES TABLES

Avant de démarrer SMSD, vous devez créer les tables qu'il utilisera. Gammu fournit des scripts SQL pour plusieurs bases de données afin de le faire :

  • mysql-create
  • pgsql-create
  • sqlite-create

EXEMPLE

Exemple de configuration :

[smsd]
service = sql
driver = odbc
host = dsn_de_votre_base_de_donnees
sql = variante_sql_a_utiliser
user = nom_utilisateur
password = mot_de_passe
