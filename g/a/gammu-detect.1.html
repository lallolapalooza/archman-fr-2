NOM

gammu-detect - Détection de périphérique Gammu

Nouveau depuis la version 1.28.95.

SYNTAXE

gammu-detect [OPTIONS]

DESCRIPTION

Script pour détecter les périphériques disponibles, qui pourraient convenir à gammu.

NOTE :

Ce programme liste tous les périphériques potentiels, il n'effectue pas de sondage sur les périphériques eux-mêmes.

Actuellement, il prend en charge les périphériques suivants :

  • Périphériques USB utilisant udev
  • Ports série utilisant udev
  • Ports série sous Windows
  • Périphériques Bluetooth utilisant Bluez

NOTE :

Les périphériques pris en charge dépendent de la plateforme que vous utilisez et des fonctionnalités intégrées lors de la compilation. Vous pouvez savoir ce qui est réellement compilé en exécutant gammu-detect -v.

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (--). Un résumé des options est inclus ci-dessous.

-h, --help
Afficher un résumé des options.
-d, --debug
Afficher la sortie de débogage pour la détection des périphériques.
-v, --version
Afficher les informations de version et les fonctionnalités compilées.
-u, --no-udev
Désactive l'analyse udev.
-b, --no-bluez
Désactive l'analyse avec Bluez.
-w, --no-win32-serial
Désactive l'analyse des ports série Windows.

SORTIE

La sortie de gammu-detect est un fichier de configuration pour Gammu (voir gammurc) avec une section de configuration pour chaque périphérique qui pourrait être utilisé avec gammu.

NOTE :

Vous pouvez choisir la section à utiliser dans gammu avec gammu -s.

Lorsqu'il est invoqué avec gammu-detect -d, tous les périphériques examinés sont également listés sous forme de commentaires dans la sortie.

EXEMPLE

; Fichier de configuration généré par gammu-detect.
; Veuillez consulter le manuel Gammu pour plus d'informations.
[gammu]
device = /dev/ttyACM0
name = Nokia E52
connection = at
[gammu1]
device = /dev/ttyACM1
name = Nokia E52
connection = at
[gammu2]
device = /dev/ttyS0
name = Téléphone sur port série 0
connection = at
[gammu3]
device = /dev/ttyS1
name = Téléphone sur port série 1
connection = at
[gammu4]
device = /dev/ttyS2
name = Téléphone sur port série 2
connection = at
[gammu5]
device = /dev/ttyS3
name = Téléphone sur port série 3
connection = at
[gammu6]
device = 5C:57:C8:BB:BB:BB
name = Nokia E52
connection = bluephonet
