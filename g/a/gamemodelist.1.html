NOM

gamemodelist - rechercher les processus s'exécutant avec gamemode

SYNOPSIS

gamemodelist

DESCRIPTION

gamemodelist recherche dans l'exécution de tous les processus en cours d'exécution qui ont démarré GameMode via libgamemodeauto.so et les affiche avec la sortie de la commande ps(1). Ce script utilitaire facilite la recherche des processus qui utilisent GameMode via libgamemodeauto.so lors du dépannage de problèmes potentiels de jeu.

UTILISATION

libgamemodeauto.so.0 sera trouvé dans les cartes d'objet partagé des processus en cours d'exécution utilisant GameMode. Exécutez la commande suivante pour afficher les processus chargés avec libgamemodeauto.so.0. GameMode peut être démarré d'autres manières, mais ce script ne détectera que les processus utilisant GameMode via libgamemodeauto.so.

gamemodelist

SORTIE

La sortie est une table des processus de la commande ps(1).

PID PPID USER NI PSR COMMAND

Où chacun de ces champs est défini dans le manuel de ps(1). Pour votre commodité, voici une définition pour chaque champ.

COLONNE DESCRIPTION
PID Identifiant du processus
PPID Identifiant du processus parent
USER Nom d'utilisateur propriétaire du processus.
NI Valeur Nice. Elle varie de 19 (le plus gentil) à -20 (pas gentil envers les autres), voir nice (1).
PSR Processeur auquel le processus est actuellement attribué. Utile lors de la définition de l'affinité des processus à l'aide de l'utilitaire taskset (1).
COMMAND Nom de la commande (uniquement le nom de l'exécutable).

VOIR AUSSI

gamemodrun(1), nice(1), ps(1), taskset(1).
