NOM

gammu-smsd-monitor - Surveille l'état du démon SMS pour Gammu

SYNTAXE

gammu-smsd-monitor [OPTION]...

DESCRIPTION

Cette page de manuel documente brièvement la commande gammu-smsd-monitor.

gammu-smsd-monitor est un programme qui surveille l'état du démon SMS de Gammu. Il affiche périodiquement des informations sur le téléphone et le nombre de messages traités.

Le programme accepte les options suivantes (veuillez noter que les options longues peuvent ne pas être acceptées sur certaines plateformes) :

-h, --help
Affiche l'aide.
-v, --version
Affiche les informations de version et les fonctionnalités compilées.
-c, --config=fichier
Fichier de configuration à utiliser, par défaut /etc/gammu-smsdrc, sous Windows il n'y a pas de valeur par défaut et le chemin du fichier de configuration doit toujours être spécifié.
-n, --loops=compteur
Nombre de boucles, par défaut le moniteur boucle à l'infini.
-d, --delay=secondes
Délai entre les interrogations de l'état du SMSD, par défaut 20 secondes.
-C, --csv
Affiche la sortie au format valeurs séparées par des virgules :
client;ID téléphone;IMEI;envoyés;reçus;en échec;batterie;signal
-l, --use-log
Utiliser la journalisation telle que configurée dans le fichier de configuration.
-L, --no-use-log
Ne pas utiliser la journalisation telle que configurée dans le fichier de configuration (par défaut).
