NOM

gammu-smsd-null - backend de gammu-smsd(1) ne stockant pas les messages

DESCRIPTION

Le backend NULL ne stocke aucune donnée. Il peut être utile si vous ne souhaitez pas stocker les messages du tout et que vous souhaitez les traiter dans le gestionnaire RunOnReceive.

CONFIGURATION

Le fichier de configuration peut alors ressembler à ceci :

[smsd]
Service = null
RunOnReceive = /usr/local/bin/process-sms
