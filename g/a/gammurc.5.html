NOM

gammurc - fichier de configuration de gammu(1)

SYNTAXE

Sur Linux, MacOS X, BSD et autres systèmes Unix-likes, le fichier de configuration est recherché dans l'ordre suivant :

1.
$XDG_CONFIG_HOME/gammu/config
2.
~/.config/gammu/config
3.
~/.gammurc
4.
/etc/gammurc

Sur Microsoft Windows :

1.
%PROFILE%\Application Data\gammurc
2.
.\gammurc

DESCRIPTION

Gammu nécessite une configuration pour pouvoir communiquer correctement avec votre téléphone. gammu lit la configuration à partir d'un fichier de configuration. Son emplacement est déterminé au moment de l'exécution, voir ci-dessus pour les chemins de recherche.

Vous pouvez utiliser gammu-config ou gammu-detect pour générer un fichier de configuration ou commencer à partir d'un exemple entièrement documenté.

Pour des indications sur la configuration de votre téléphone, vous pouvez consulter la base de données des téléphones Gammu https://wammu.eu/phones/ pour voir ce que les utilisateurs ont expérimenté.

Ce fichier utilise la syntaxe des fichiers ini, voir ini.

Le fichier de configuration pour gammu peut contenir plusieurs sections - [gammu], [gammu1], [gammuN], ... Chaque section configure un ensemble de connexion et en mode par défaut, gammu essaie toutes les sections dans l'ordre numérique. Vous pouvez également spécifier quelle section de configuration utiliser en donnant son numéro ([gammu] a le numéro 0) comme paramètre à gammu, et il n'utilisera alors que cette section.

[gammu]

Cette section est lue par défaut, sauf si vous en spécifiez une autre en ligne de commande.

Paramètres de connexion du périphérique

Connexion
Protocole qui sera utilisé pour communiquer avec votre téléphone.

Pour les câbles Nokia, vous voudrez utiliser l'un des suivants :

fbus
connexion série FBUS
dlr3
câbles DLR-3 et compatibles
dku2
câbles DKU-2 et compatibles
dku5
câbles DKU-5 et compatibles
mbus
connexion série MBUS

Si vous utilisez un câble non original, vous pourriez avoir besoin d'ajouter -nodtr (par exemple pour les câbles basés sur ARK3116) ou -nopower, mais Gammu devrait être capable de le détecter automatiquement.

Pour les téléphones non-Nokia connectés par câble, vous voulez généralement :

at
connexion générique basée sur les commandes AT

Vous pouvez éventuellement spécifier la vitesse de la connexion, par exemple at19200, mais ce n'est pas nécessaire pour les câbles USB modernes.

Pour les connexions IrDA, utilisez l'une des options suivantes :

irdaphonet
connexion Phonet pour les téléphones Nokia.
irdaat
connexion par commandes AT pour la plupart des téléphones (ceci n'est pas supporté sous Linux).
irdaobex
connexion OBEX (IrMC ou transfert de fichiers) pour la plupart des téléphones.
irdagnapbus
connexion basée sur GNapplet pour les téléphones Symbian, voir gnapplet.

Pour la connexion Bluetooth, utilisez l'une des options suivantes :

bluephonet
connexion Phonet pour les téléphones Nokia.
bluefbus
connexion FBUS pour les téléphones Nokia.
blueat
connexion par commandes AT pour la plupart des téléphones.
blueobex
connexion OBEX (IrMC ou transfert de fichiers) pour la plupart des téléphones.
bluerfgnapbus
connexion basée sur GNapplet pour les téléphones Symbian, voir gnapplet.
blues60
connexion à l'applet Series60 dans les téléphones S60, voir s60.

Nouveau depuis la version 1.29.90.

Nouveau depuis la version 1.36.7 : Gammu supporte désormais la connexion via une commande proxy.

Vous pouvez également proxifier la connexion via une commande shell, par exemple vers un autre hôte. Cela peut être fait en utilisant des connexions proxy :

proxyphonet
connexion Phonet pour les téléphones Nokia.
proxyfbus
connexion FBUS pour les téléphones Nokia.
proxyat
connexion par commandes AT pour la plupart des téléphones.
proxyobex
connexion OBEX (IrMC ou transfert de fichiers) pour la plupart des téléphones.
proxygnapbus
connexion basée sur GNapplet pour les téléphones Symbian, voir gnapplet.
proxys60
connexion à l'applet Series60 dans les téléphones S60, voir s60.

Périphérique
Nouveau depuis la version 1.27.95.

Nœud ou adresse du périphérique du téléphone. Cela dépend de la connexion utilisée.

Pour les câbles ou les ports série émulés, vous entrez le nom du périphérique (par exemple /dev/ttyS0, /dev/ttyACM0, /dev/ircomm0, /dev/rfcomm0 sous Linux, /dev/cuad0 sous FreeBSD ou COM1: sous Windows). L'exception spéciale concerne les câbles DKU-2 et DKU-5 sous Windows, où le périphérique est automatiquement détecté à partir des informations du pilote et ce paramètre est ignoré.

NOTE :

Certains modems USB exposent plusieurs interfaces, dans ce cas, Gammu fonctionne mieux avec celle de type "User", vous pouvez trouver plus d'informations sur http://www.dd-wrt.com/wiki/index.php/Mobile_Broadband.

Pour les connexions USB (actuellement uniquement fbususb et dku2 sous Linux), vous pouvez spécifier à quel périphérique USB Gammu doit se connecter. Vous pouvez fournir soit les identifiants vendeur/produit, soit l'adresse du périphérique sur USB :

Périphérique = 0x1234:0x5678  # Faire correspondre le périphérique par l'identifiant vendeur et produit
Périphérique = 0x1234:-1      # Faire correspondre le périphérique par l'identifiant vendeur
Périphérique = 1.10           # Faire correspondre le périphérique par l'adresse du bus et du périphérique USB
Périphérique = 10             # Faire correspondre le périphérique par l'adresse du périphérique USB
Périphérique = serial:123456  # Faire correspondre le périphérique par la chaîne de caractères série

NOTE :

Sur les systèmes Linux, vous pourriez manquer des permissions pour certains nœuds de périphérique. Vous pourriez avoir besoin d'être membre de certains groupes (par exemple plugdev ou dialout) ou d'ajouter des règles udev spéciales pour vous permettre d'accéder à ces périphériques en tant que non-root.

Pour les téléphones Nokia, vous pouvez placer le fichier suivant (également disponible dans les sources sous contrib/udev/69-gammu-acl.rules) comme /etc/udev/rules.d/69-gammu-acl.rules :

#
# Règle udev pour donner aux utilisateurs l'accès au périphérique USB à utiliser par Gammu
#
ACTION!="add|change", GOTO="gammu_acl_rules_end"
KERNEL!="ttyACM[0-9]*", GOTO="gammu_acl_rules_end"
SUBSYSTEM!="tty", GOTO="gammu_acl_rules_end"
# Périphériques Nokia
ATTRS{manufacturer}=="Nokia", TAG+="uaccess"
# Exemple pour Sony Ericsson J108i Cedar
# ATTRS{idVendor}=="0fce", ATTRS{idProduct}=="d14e", TAG+="uaccess"
LABEL="gammu_acl_rules_end"
