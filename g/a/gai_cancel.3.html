getaddrinfo_a(3) Manuel des fonctions de bibliothèque getaddrinfo_a(3)

NOM

getaddrinfo_a, gai_suspend, gai_error, gai_cancel - traduction asynchrone d'adresses réseau et de services

BIBLIOTHÈQUE

Bibliothèque de résolution de noms asynchrone (libanl, -lanl)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <netdb.h>
int getaddrinfo_a(int mode, struct gaicb *list[restrict n],
                  int n, struct sigevent *restrict sevp);
int gai_suspend(const struct gaicb *const list[n], int n,
                  const struct timespec *timeout);
int gai_error(struct gaicb *req);
int gai_cancel(struct gaicb *req);

DESCRIPTION

La fonction getaddrinfo_a() effectue la même tâche que getaddrinfo(3), mais permet d'effectuer plusieurs recherches de noms de manière asynchrone, avec notification optionnelle à la fin des opérations de recherche.

L'argument mode a l'une des valeurs suivantes :

GAI_WAIT
Effectuer les recherches de manière synchrone. L'appel bloque jusqu'à ce que les recherches soient terminées.
GAI_NOWAIT
Effectuer les recherches de manière asynchrone. L'appel retourne immédiatement, et les requêtes sont résolues en arrière-plan. Voir la discussion sur l'argument sevp ci-dessous.

Le tableau list spécifie les requêtes de recherche à traiter. L'argument n spécifie le nombre d'éléments dans list. Les opérations de recherche demandées sont démarrées en parallèle. Les éléments NULL dans list sont ignorés. Chaque requête est décrite par une structure gaicb, définie comme suit :


struct gaicb {
    const char            *ar_name;
    const char            *ar_service;
    const struct addrinfo *ar_request;
    struct addrinfo       *ar_result;
};

Les éléments de cette structure correspondent aux arguments de getaddrinfo(3). Ainsi, ar_name correspond à l'argument node et ar_service à l'argument service, identifiant un hôte Internet et un service. L'élément ar_request correspond à l'argument hints, spécifiant les critères de sélection des structures d'adresses de socket retournées. Enfin, ar_result correspond à l'argument res ; vous n'avez pas besoin d'initialiser cet élément, il sera automatiquement défini lorsque la requête sera résolue. La structure addrinfo référencée par les deux derniers éléments est décrite dans getaddrinfo(3).

Lorsque mode est spécifié comme GAI_NOWAIT, les notifications sur les requêtes résolues peuvent être obtenues en utilisant la structure sigevent pointée par l'argument sevp. Pour la définition et les détails généraux de cette structure, voir sigevent(3type). Le champ sevp->sigev_notify peut avoir les valeurs suivantes :

SIGEV_NONE
Ne fournir aucune notification.
SIGEV_SIGNAL
Lorsqu'une recherche est terminée, générer le signal sigev_signo pour le processus. Voir sigevent(3type) pour les détails généraux. Le champ si_code de la structure siginfo_t sera défini à SI_ASYNCNL.
SIGEV_THREAD
Lorsqu'une recherche est terminée, appeler sigev_notify_function comme s'il s'agissait de la fonction de démarrage d'un nouveau thread. Voir sigevent(3type) pour les détails.

Pour SIGEV_SIGNAL et SIGEV_THREAD, il peut être utile de pointer sevp->sigev_value.sival_ptr vers list.

La fonction gai_suspend() suspend l'exécution du thread appelant, en attendant la complétion d'une ou plusieurs requêtes dans le tableau list. L'argument n spécifie la taille du tableau list. L'appel bloque jusqu'à ce que l'un des événements suivants se produise :

•
Une ou plusieurs des opérations dans list sont terminées.
•
L'appel est interrompu par un signal intercepté.
•
L'intervalle de temps spécifié dans timeout s'écoule. Cet argument spécifie un délai d'attente en secondes plus nanosecondes (voir nanosleep(2) pour les détails de la structure timespec). Si timeout est NULL, l'appel bloque indéfiniment (jusqu'à ce que l'un des événements ci-dessus se produise).

Aucune indication explicite de la requête terminée n'est donnée ; vous devez déterminer quelle(s) requête(s) est (sont) terminée(s) en itérant avec gai_error() sur la liste des requêtes.

La fonction gai_error() retourne l'état de la requête req : soit EAI_INPROGRESS si la requête n'est pas encore terminée, 0 si elle a été traitée avec succès, ou un code d'erreur si la requête n'a pas pu être résolue.

La fonction gai_cancel() annule la requête req. Si la requête a été annulée avec succès, son état d'erreur sera défini à EAI_CANCELED et la notification asynchrone normale sera effectuée. La requête ne peut pas être annulée si elle est en cours de traitement ; dans ce cas, elle sera traitée comme si gai_cancel() n'avait jamais été appelée. Si req est NULL, une tentative est faite pour annuler toutes les requêtes en cours que le processus a émises.

VALEUR DE RETOUR

La fonction getaddrinfo_a() retourne 0 si toutes les requêtes ont été mises en file d'attente avec succès, ou l'un des codes d'erreur non nuls suivants :

EAI_AGAIN
Les ressources nécessaires pour mettre en file d'attente les requêtes de recherche n'étaient pas disponibles. L'application peut vérifier l'état d'erreur de chaque requête pour déterminer celles qui ont échoué.
EAI_MEMORY
Mémoire insuffisante.
EAI_SYSTEM
mode est invalide.

La fonction gai_suspend() retourne 0 si au moins une des requêtes listées a été terminée. Sinon, elle retourne l'un des codes d'erreur non nuls suivants :

EAI_AGAIN
Le délai d'attente imparti s'est écoulé avant que l'une des requêtes puisse être terminée.
EAI_ALLDONE
Aucune requête réelle n'a été fournie à la fonction.
EAI_INTR
Un signal a interrompu la fonction. Notez que cette interruption pourrait avoir été causée par la notification d'un signal pour une requête de recherche terminée.

La fonction gai_error() peut retourner EAI_INPROGRESS pour une requête de recherche inachevée, 0 pour une requête de recherche terminée avec succès (comme décrit ci-dessus), l'un des codes d'erreur qui pourrait être retourné par getaddrinfo(3), ou le code d'erreur EAI_CANCELED si la requête a été explicitement annulée avant de pouvoir être terminée.

La fonction gai_cancel() peut retourner l'une de ces valeurs :

EAI_CANCELED
La requête a été annulée avec succès.
EAI_NOTCANCELED
La requête n'a pas été annulée.
EAI_ALLDONE
La requête est déjà terminée.

La fonction gai_strerror(3) traduit ces codes d'erreur en une chaîne de caractères lisible, appropriée pour le rapport d'erreurs.

EXEMPLE

S

Deux exemples sont fournis : un exemple simple qui résout plusieurs requêtes en parallèle de manière synchrone, et un exemple complexe montrant certaines des fonctionnalités

asynchrones.

Exemple

synchrone

Le programme ci-dessous résout simplement plusieurs noms d'hôtes en parallèle, ce qui est plus rapide que de résoudre les noms d'hôtes séquentiellement avec getaddrinfo(3). Le programme pourrait être utilisé ainsi

: 


$ ./a.out mirrors.kernel.org enoent.linuxfoundation.org gnu.org;
mirrors.kernel.org: 139.178.88.99
enoent.linuxfoundation.org: Name or service not known
gnu.org: 209.51.188.
116

Voici le code source du

programme 
#define _GNU_SOURCE
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MALLOC(n, type)  ((type *) reallocarray(NULL, n, sizeof(type)))
int
main(int argc, char *argv[])
{
    int ret;
    struct gaicb *reqs[argc - 1];
    char host[NI_MAXHOST];
    struct addrinfo *res;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s HOST...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        reqs[i] = MALLOC(1, struct gaicb);
        if (reqs[i] == NULL)
            err(EXIT_FAILURE, "malloc");
        memset(reqs[i], 0, sizeof(*reqs[0]));
        reqs[i]->ar_name = argv[i + 1];
    }
    ret = getaddrinfo_a(GAI_WAIT, reqs, argc - 1, NULL);
    if (ret != 0) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        printf("%s: ", reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (ret == 0) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret != 0) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
    exit(EXIT_SUCCESS);
}

Le source du programme est le suivant

: 
#define _GNU_SOURCE
#include <assert.h>
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define CALLOC(n, type)  ((type *) calloc(n, sizeof(type)))
#define REALLOCF(ptr, n, type)                                          \
({                                                                      \
    static_assert(__builtin_types_compatible_p(typeof(ptr), type *));   \
                                                                        \
    (type *) reallocarrayf(ptr, n, sizeof(type));                       \
})
static struct gaicb **reqs = NULL;
static size_t nreqs = 0;
static inline void *
reallocarrayf(void *p, size_t n, size_t size)
{
    void  *q;
    q = reallocarray(p, n, size);
    if (q == NULL && n != 0 && size != 0)
        free(p);
    return q;
}
static char *
getcmd(void)
{
    static char buf[256];
    fputs("> ", stdout);
    fflush(stdout);
    if (fgets(buf, sizeof(buf), stdin) == NULL)
        return NULL;
    if (buf[strlen(buf) - 1] == '\n')
        buf[strlen(buf) - 1] = 0;
    return buf;
}
/* Add requests for specified hostnames.  */
static void
add_requests(void)
{
    size_t nreqs_base = nreqs;
    char *host;
    int ret;
    while ((host = strtok(NULL, " "))) {
        nreqs++;
        reqs = REALLOCF(reqs, nreqs, struct gaicb *);
        if (reqs == NULL)
            err(EXIT_FAILURE, "reallocf");
        reqs[nreqs - 1] = CALLOC(1, struct gaicb);
        if (reqs[nreqs - 1] == NULL)
            err(EXIT_FAILURE, "calloc");
        reqs[nreqs - 1]->ar_name = strdup(host);
    }
    /* Queue nreqs_base..nreqs requests.  */
    ret = getaddrinfo_a(GAI_NOWAIT, &reqs[nreqs_base],
                        nreqs - nreqs_base, NULL);
    if (ret) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
}
/* Wait until at least one of specified requests completes.  */
static void
wait_requests(void)
{
    char *id;
    int ret;
    size_t n;
    struct gaicb const **wait_reqs;
    wait_reqs = CALLOC(nreqs, const struct gaicb *);
    if (wait_reqs == NULL)
        err(EXIT_FAILURE, "calloc");
                /* NULL elements are ignored by gai_suspend().  */
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Bad request number: %s\n", id);
            return;
        }
        wait_reqs[n] = reqs[n];
    }
    ret = gai_suspend(wait_reqs, nreqs, NULL);
    if (ret) {
        printf("gai_suspend(): %s\n", gai_strerror(ret));
        return;
    }
    for (size_t i = 0; i < nreqs; i++) {
        if (wait_reqs[i] == NULL)
            continue;
        ret = gai_error(reqs[i]);
        if (ret == EAI_INPROGRESS)
            continue;
        printf("[%02zu] %s: %s\n", i, reqs[i]->ar_name,
               ret == 0 ? "Finished" : gai_strerror(ret));
    }
}
/* Cancel specified requests.  */
static void
cancel_requests(void)
{
    char *id;
    int ret;
    size_t n;
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Bad request number: %s\n", id);
            return;
        }
        ret = gai_cancel(reqs[n]);
        printf("[%s] %s: %s\n", id, reqs[atoi(id)]->ar_name,
               gai_strerror(ret));
    }
}
/* List all requests.  */
static void
list_requests(void)
{
    int ret;
    char host[NI_MAXHOST];
    struct addrinfo *res;
    for (size_t i = 0; i < nreqs; i++) {
        printf("[%02zu] %s: ", i, reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (!ret) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
}
int
main(void)
{
    char *cmdline;
    char *cmd;
    while ((cmdline = getcmd()) != NULL) {
        cmd = strtok(cmdline, " ");
        if (cmd == NULL) {
            list_requests();
        } else {
            switch (cmd[0]) {
            case 'a':
                add_requests();
                break;
            case 'w':
                wait_requests();
                break;
            case 'c':
                cancel_requests();
                break;
            case 'l':
                list_requests();
                break;
            default:
                fprintf(stderr, "Bad command: %c\n", cmd[0]);
                break;
            }
        }
    }
    exit(EXIT_SUCCESS)
;
}
