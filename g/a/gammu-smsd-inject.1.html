NOM

gammu-smsd-inject - Injecte des messages dans la file d'attente du démon SMS de Gammu

SYNTAXE

gammu-smsd-inject [OPTION]... TYPE_DE_MESSAGE DESTINATAIRE [PARAMÈTRE_MESSAGE]...

DESCRIPTION

Cette page de manuel documente brièvement la commande gammu-smsd-inject.

gammu-smsd-inject est un programme qui met en file d'attente des messages dans le démon SMS de Gammu, lesquels seront envoyés ultérieurement par le démon à l'aide du modem GSM connecté.

Le support de ce programme dépend des fonctionnalités disponibles dans le backend de service SMSD utilisé, bien qu'actuellement, il soit pris en charge par tous.

Le programme accepte les options suivantes (notez que les options longues pourraient ne pas être acceptées sur certaines plateformes) :

-h, --help
Affiche l'aide.
-v, --version
Affiche les informations de version et les fonctionnalités compilées.
-c, --config=fichier
Fichier de configuration à utiliser, par défaut /etc/gammu-smsdrc. Sur Windows, il n'y a pas de valeur par défaut et le chemin du fichier de configuration doit toujours être spécifié.
-l, --use-log
Utilise la journalisation telle que configurée dans le fichier de configuration.
-L, --no-use-log
N'utilise pas la journalisation telle que configurée dans le fichier de configuration (par défaut).

Pour la description des types de messages et de leurs paramètres, veuillez consulter la documentation de gammu savesms.

EXEMPLES

Pour essayer, vous devez avoir un fichier de configuration pour SMSD. Voir gammu-smsdrc pour plus de détails à ce sujet.

Injecter un message texte de 160 caractères maximum :

echo "All your base are belong to us" | gammu-smsd-inject TEXT 123456

ou

gammu-smsd-inject TEXT 123456 -text "All your base are belong to us"

Injecter un message texte unicode :

gammu-smsd-inject TEXT 123456 -unicode -text "Zkouška sirén"

Injecter un long message texte :

echo "All your base are belong to us" | gammu-smsd-inject TEXT 123456 -len 400

ou

gammu-smsd-inject TEXT 123456 -len 400 -text "All your base are belong to us"

ou

gammu-smsd-inject EMS 123456 -text "All your base are belong to us"

Injecter un message fantaisiste avec un son prédéfini et une animation à partir de 2 bitmaps :

gammu-smsd-inject EMS 123456 -text "Greetings" -defsound 1 -text "from Gammu" -tone10 axelf.txt -animation 2 file1.bmp file2.bmp

Injecter un message protégé avec une sonnerie :

gammu-smsd-inject EMS 123456 -protected 2 -variablebitmaplong ala.bmp -toneSElong axelf.txt -toneSE ring.txt

Injecter une requête USSD :

gammu-smsd-inject USSD '*101#'
