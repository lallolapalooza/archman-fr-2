NOM

gamma4scanimage - créer une table gamma pour scanimage

SYNTAXE

gamma4scanimage gamma [shadow [highlight [maxin [maxout]]]]

DESCRIPTION

L'outil gamma4scanimage crée une table gamma dans le format attendu par scanimage. Vous pouvez définir une valeur de gamma, une valeur d'ombre (shadow) et une valeur de lumière (highlight). Vous pouvez également spécifier la taille (maxin) et la valeur de sortie maximale (maxout) de la table gamma.

gamma est une valeur à virgule flottante, la valeur neutre étant 1.0. Si la valeur est supérieure à 1.0, l'image est plus lumineuse.

shadow définit la valeur d'entrée minimale nécessaire pour créer une valeur de sortie supérieure à zéro. shadow doit être dans la plage [0..maxin]. Sa valeur par défaut est 0.

highlight définit la valeur d'entrée maximale qui produit une valeur de sortie inférieure à maxout. highlight doit être dans la plage [0..maxin] et supérieure à shadow. Sa valeur par défaut est la même que maxin (16383 si non défini).

maxin définit la taille de la table gamma. La taille dépend du scanner/backend. Si le scanner utilise une entrée gamma de 8 bits, maxin doit être défini sur 255, 1023 pour 10 bits, 4095 pour 12 bits et 16383 pour 14 bits. La valeur par défaut est 16383. Pour savoir quelle valeur maxin doit avoir, appelez scanimage(1) avec une table gamma très grande [0]0-[99999]255 et scanimage(1) affichera un message d'erreur avec la taille de table gamma nécessaire.

maxout définit la valeur de sortie maximale. Regardez la sortie de scanimage -h pour savoir ce que maxout doit être. La valeur par défaut est 255.

EXEMPLE

scanimage --custom-gamma=yes --gamma-table `gamma4scanimage 1.8 0 11500 16383 255` >image.pnm
