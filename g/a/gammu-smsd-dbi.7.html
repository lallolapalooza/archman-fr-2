DESCRIPTIO

N

Le backend DBI stocke toutes les données dans n'importe quelle base de données prise en charge par libdbi, dont les paramètres sont définis par la configuration (voir gammu-smsdrc pour la description des options de configuration)

.

Pour la description des tables, voir gammu-smsd-tables

.

Ce backend est basé sur

gammu-smsd-sql.

REMARQUE

:
Le pilote DBI n'est actuellement
pas pris en charge sur Windows
car la bibliothèque libdbi ne pren
d pas en charge cette plateforme.

CONFIGURATIO

N

Avant d'exécuter gammu-smsd, vous devez créer les tables nécessaires dans la base de données. Vous pouvez utiliser les exemples donnés dans les parties consacrées aux backends spécifiques aux bases de données de ce manuel pour ce

faire.

Le fichier de configuration peut ensuite ressembler à

: 
[smsd]
service
= sql driver
= DBI_DRIVER ho
st = localhost

MISE À JOUR DES

TABLES

La façon la plus simple de mettre à jour la structure de la base de données est de sauvegarder l'ancienne et de commencer par en créer une nouvelle basée sur l'exemple

ci-dessus.

Pour mettre à jour une base de données existante, vous pouvez utiliser les changements décrits dans smsd-tables-history puis mettre à jour manuellement le champ Version dans la table

gam
mu.
