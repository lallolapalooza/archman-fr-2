NOM

gammu-smsd-pgsql - Backend gammu-smsd(1) utilisant le serveur de base de données PostgreSQL comme stockage de messages

DESCRIPTION

Le backend PGSQL stocke toutes les données dans un serveur de base de données PostgreSQL, dont les paramètres sont définis par la configuration (voir gammu-smsdrc pour la description des options de configuration).

Pour la description des tables, voir gammu-smsd-tables.

Ce backend est basé sur gammu-smsd-sql.

CONFIGURATION

Avant d'exécuter gammu-smsd, vous devez créer les tables nécessaires dans la base de données, ce qui est décrit ci-dessous.

Le fichier de configuration peut alors ressembler à ceci :

[smsd]
service = sql
driver = native_pgsql
host = localhost

VOIR AUSSI :

gammu-smsdrc

MISE À NIVEAU DES TABLES

La façon la plus simple de mettre à niveau la structure de la base de données est de sauvegarder l'ancienne et de commencer par en créer une nouvelle basée sur l'exemple ci-dessus.

Pour mettre à niveau une base de données existante, vous pouvez utiliser les modifications décrites dans smsd-tables-history puis mettre à jour manuellement le champ Version dans la table gammu.
