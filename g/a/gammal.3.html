gamma(3) Manuel des fonctions de bibliothèque gamma(3)

NOM

gamma, gammaf, gammal - fonction gamma (logarithme de la)

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
[[deprecated]] double gamma(double x);
[[deprecated]] float gammaf(float x);
[[deprecated]] long double gammal(long double x);
Exigences de la macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

gamma() :

    _XOPEN_SOURCE
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

gammaf(), gammal() :

    _XOPEN_SOURCE >= 600 || (_XOPEN_SOURCE && _ISOC99_SOURCE)
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions sont obsolètes : utilisez plutôt soit les fonctions tgamma(3), soit lgamma(3), selon le cas.

Pour la définition de la fonction Gamma, voir tgamma(3).

Version *BSD

La libm dans 4.4BSD et certaines versions de FreeBSD avait une fonction gamma() qui calculait la fonction Gamma, comme on pourrait s'y attendre.

Version glibc

glibc a une fonction gamma() qui est équivalente à lgamma(3) et calcule le logarithme naturel de la fonction Gamma.

VALEUR DE RETOUR

Voir lgamma(3).

ERREURS

Voir lgamma(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
gamma (), gammaf (), gammal () Sécurité des threads MT-Unsafe race:signgam

NORMES

Aucune.

HISTORIQUE

SVID 2.

En raison des variations historiques de comportement entre les systèmes, cette fonction n'est spécifiée dans aucune norme récente.

4.2BSD avait une fonction gamma() qui calculait ln(|Gamma(|x|)|), laissant le signe de Gamma(|x|) dans l'entier externe signgam. Dans 4.3BSD, le nom a été changé en lgamma(3), et la page de manuel promettait


« À un moment donné dans le futur, le nom gamma sera réhabilité et utilisé pour la fonction Gamma »

Cela s'est effectivement produit dans 4.4BSD, où gamma() calcule la fonction Gamma (sans affecter signgam). Cependant, c'était trop tard, et nous avons maintenant tgamma(3), la fonction "vraie gamma".

VOIR AUSSI

lgamma(3), signgam(3), tgamma(3)
