NOM

gammu-backup - Format de fichier de sauvegarde de gammu.

Le format de sauvegarde est un fichier texte codé en ASCII ou en UCS-2-BE.

Ce fichier utilise la syntaxe des fichiers ini, voir ini.

EXEMPLES

Si vous sauvegardez les paramètres dans un fichier texte Gammu, il sera possible de le modifier. C'est facile : beaucoup de choses dans ce fichier seront écrites en double - une fois en Unicode, une fois en ASCII. Lorsque vous supprimerez la version Unicode, Gammu utilisera l'ASCII lors de la restauration (et vous pourrez facilement modifier le texte ASCII) et le convertira selon la locale de votre système d'exploitation. Lorsque la version Unicode du texte sera disponible, elle sera utilisée à la place de l'ASCII (utile avec les téléphones Unicode - peu importe la locale définie sur l'ordinateur et aucune conversion Unicode->ASCII et ASCII->Unicode n'est faite).

Vous pouvez utiliser n'importe quel éditeur disposant d'une fonction d'expressions régulières pour modifier le fichier texte de sauvegarde. Des exemples d'éditeurs de ce type peuvent être vim ou TextPad qui supportent tous deux les expressions régulières.

Supprimer les informations sur les tags vocaux

Trouver :

^Entry\([0-9][0-9]\)VoiceTag = \(.*\)\n

Remplacer :

<vide>

Changer tous les numéros commençant par +3620, +3630, +3660, +3670 en +3620

Trouver :

Type = NumberGeneral\nEntry\([0-9][0-9]\)Text = "\+36\(20\|30\|60\|70\)\n

Remplacer :

Type = NumberMobile\nEntry\1Text = "\+3620

Changer le type de numéros de téléphone en mobile pour les numéros commençant par +3620, +3630,... et supprimer la ligne TextUnicode correspondante

Trouver :

Type = NumberGeneral\nEntry\([0-9][0-9]\)Text = "\+36\([2367]0\)\([^\"]*\)"\nEntry\([0-9][0-9]\)TextUnicode = \([^\n]*\)\n

Remplacer :

Type = NumberMobile\nEntry\1Text = "\+36\2\3"\n
