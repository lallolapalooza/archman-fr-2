NOM

gammu-config - Configurateur Gammu

SYNTAXE

gammu-config [-f|--force] [-c|--config CONFIG]

DESCRIPTION

Script pour aider à configurer gammu.

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (-). Un résumé des options est inclus ci-dessous.

-h, --help
Afficher le résumé des options.
-f, --force
Forcer la configuration même si le fichier de configuration existe déjà.
-c, --config CONFIG
Définir quel fichier de configuration utiliser.
