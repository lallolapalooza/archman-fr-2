NOM

gajim-remote - utilitaire de contrôle à distance pour gajim(1)

SYNTAXE

gajim-remote -h

gajim-remote commande [arguments ...]

DESCRIPTION

gajim-remote est une application pour contrôler et communiquer avec une instance en cours d'exécution de gajim(1) via dbus.

OPTIONS

-h, --help
Afficher l'aide
--app-id APP_ID
L'identifiant de l'application de l'instance gajim(1) en cours d'exécution

COMMANDES

list_contacts compte
Obtenir tous les contacts de la liste de contacts
list_accounts
Obtenir la liste des comptes
change_status {offline,online,away,xa,dnd} message compte
Changer le statut
send_chat_message adresse message compte
Envoyer un message de chat à un contact
send_groupchat_message adresse message compte
Envoyer un message de chat à un chat de groupe
account_info compte
Obtenir les détails du compte
get_status compte
Obtenir le statut actuel
get_status_message compte
Obtenir le message de statut actuel
get_unread_msgs_number
Obtenir le nombre de messages non lus

BOGUES

Veuillez soumettre les bogues à https://dev.gajim.org/gajim/gajim/issues.

SUPPORT
