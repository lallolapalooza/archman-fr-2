GAI_STRERROR(3P) Manuel du programmeur POSIX GAI_STRERROR(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

gai_strerror — description d'erreur d'informations d'adresse et de nom

SYNTAXE

#include <netdb.h>
const char *gai_strerror(int ecode);

DESCRIPTION

La fonction gai_strerror() renvoie une chaîne de caractères décrivant une valeur d'erreur pour les fonctions getaddrinfo() et getnameinfo() listées dans l'en-tête <netdb.h>.

Lorsque l'argument ecode est l'une des valeurs suivantes listées dans l'en-tête <netdb.h> :

[EAI_AGAIN] [EAI_BADFLAGS] [EAI_FAIL] [EAI_FAMILY] [EAI_MEMORY] [EAI_NONAME] [EAI_OVERFLOW] [EAI_SERVICE] [EAI_SOCKTYPE] [EAI_SYSTEM]

la valeur de retour de la fonction pointe vers une chaîne décrivant l'erreur. Si l'argument n'est pas l'une de ces valeurs, la fonction renvoie un pointeur vers une chaîne dont le contenu indique une erreur inconnue.

VALEUR RENVOYÉE

En cas de succès, gai_strerror() renvoie un pointeur vers une chaîne définie par l'implémentation.

ERREURS

Aucune erreur n'est définie.
