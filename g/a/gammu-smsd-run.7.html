NOM

gammu-smsd-run - documentation pour la directive RunOnReceive

DESCRIPTION

Gammu SMSD peut être configuré par la directive RunOnReceive (voir gammu-smsdrc pour plus de détails) pour exécuter un programme défini après la réception de chaque message. Il peut recevoir un message unique ou plusieurs messages, qui font partie d'un même message multi-parties.

Ce paramètre est exécuté via le shell, vous devrez donc peut-être échapper certains caractères spéciaux et vous pouvez inclure un nombre quelconque de paramètres. De plus, des paramètres contenant les identifiants des messages reçus sont ajoutés à la ligne de commande. Les identifiants dépendent du service utilisé, généralement il s'agit de l'ID de la ligne insérée pour les services base de données ou du nom de fichier pour les services basés sur des fichiers.

Gammu SMSD attend la fin du script. Si vous effectuez une opération chronophage, cela empêchera SMSD de recevoir de nouveaux messages. Toutefois, pour limiter les dégâts de cette situation, le temps d'attente est limité à deux minutes. Après ce délai, SMSD reprendra son fonctionnement normal et pourra exécuter votre script à nouveau.

NOTE :

Tous les descripteurs de fichiers d'entrée et de sortie sont fermés lorsque ce programme est invoqué, vous devez donc veiller à ouvrir les fichiers vous-même.

ENVIRONNEMENT

Nouveau dans la version 1.28.0.

Le programme est exécuté avec un environnement qui contient de nombreuses informations sur le message. Vous pouvez l'utiliser avec le service NULL (voir gammu-smsd-null) pour implémenter un traitement entièrement personnalisé des messages.

Variables globales

SMS_MESSAGES
Nombre de messages physiques reçus.
DECODED_PARTS
Nombre de parties de message décodées.
PHONE_ID
Nouveau dans la version 1.38.2.

Valeur de PhoneID. Utile lors de l'exécution de plusieurs instances (voir smsd-multi).

Variables par message

Les variables décrites ci-dessous sous la forme SMS_1_... sont générées pour chaque message physique, où 1 est remplacé par le numéro courant du message.

SMS_1_CLASS
Classe du message.
SMS_1_NUMBER
Numéro de l'expéditeur.
SMS_1_TEXT
Texte du message. Le texte n'est pas disponible pour les messages binaires 8 bits.
SMS_1_REFERENCE
Nouveau dans la version 1.38.5.

Référence du message. Si le statut de livraison est reçu, cette variable contient le TPMR du message original

Variables par partie

Les variables décrites ci-dessous sous la forme DECODED_1_... sont générées pour chaque partie du message, où 1 est remplacé par le numéro courant de la partie. Seules les variables dont le contenu est présent dans le message sont définies.

DECODED_1_TEXT
Texte du message long décodé.
DECODED_1_MMS_SENDER
Expéditeur du message d'indication MMS.
DECODED_1_MMS_TITLE
Titre du message d'indication MMS.
DECODED_1_MMS_ADDRESS
Adresse (URL) du MMS issue du message d'indication MMS.

VOIR AUSSI :

faq-mms-download
DECODED_1_MMS_SIZE
Taille du MMS telle que spécifiée dans le message d'indication MMS.

EXEMPLES

Activation de RunOnReceive

Pour activer cette fonctionnalité, vous devez définir RunOnReceive dans le fichier gammu-smsdrc.

[smsd]
RunOnReceive = /chemin/vers/script.sh

Traitement des messages avec le service fichiers

Le script suivant (s'il est utilisé comme gestionnaire RunOnReceive ) transmet les données du message à un autre programme. Cela ne fonctionne qu'avec le service gammu-smsd-files.

#!/bin/sh
INBOX=/chemin/vers/smsd/inbox
PROGRAM=/bin/cat
for ID in "$@" ; do
    $PROGRAM < $INBOX/$ID
done

Invoquer des commandes en fonction du texte du message

Le script suivant (s'il est utilisé comme gestionnaire RunOnReceive ) exécute des programmes donnés en fonction du texte du message.

#!/bin/sh
# Vérifier le numéro de l'expéditeur
if [ "$SMS_1_NUMBER" != "+420123456789" ] ; then
    exit
fi
# Traiter les commandes
case "$SMS_1_TEXT" in
    "DMS A")
        /usr/bin/dms-a
        ;;
    "DMS B")
        /usr/bin/dms-b
        ;;
esac

Transmettre le texte du message à un programme

Le script suivant (s'il est utilisé comme gestionnaire RunOnReceive ) transmet le texte du message et l'expéditeur à un programme externe.

#!/bin/sh
PROGRAM=/bin/echo
for i in `seq $SMS_MESSAGES` ; do
    eval "$PROGRAM \"\${SMS_${i}_NUMBER}\" \"\${SMS_${i}_TEXT}\""
done

Transmettre les paramètres d'indication MMS à un programme externe

Le script suivant (s'il est utilisé comme gestionnaire RunOnReceive ) écrira des informations sur chaque message d'indication MMS reçu dans le fichier journal. Remplacez simplement la commande echo par votre propre programme pour effectuer un traitement personnalisé.

#!/bin/sh
if [ $DECODED_PARTS -eq 0 ] ; then
    # Pas de parties décodées, rien à traiter
    exit
fi
if [ "$DECODED_1_MMS_ADDRESS" ] ; then
    echo "$DECODED_1_MMS_ADDRESS" "$DECODED_1_MMS_SENDER" "$DECODED_1_MMS_TITLE" >> /tmp/smsd-mms.log
fi

Traitement du texte du message en Python

Le script suivant (s'il est utilisé comme gestionnaire RunOnReceive ) écrit en Python, concaténera tout le texte du message reçu :

#!/usr/bin/env python
from __future__ import print_function
import os
import sys
numparts = int(os.environ['DECODED_PARTS'])
text = ''
# Y a-t-il des parties décodées ?
if numparts == 0:
    text = os.environ['SMS_1_TEXT']
# Obtenir toutes les parties de texte
else:
    for i in range(1, numparts + 1):
        varname = 'DECODED_%d_TEXT' % i
        if varname in os.environ:
            text = text + os.environ[varname]
# Faire quelque chose avec le texte
print('Le numéro %s a envoyé le texte : %s' % (os.environ['SMS_1_NUMBER'], text))

NAME

gammu-smsd-run - Script to run gammu-smsd in background

DESCRIPTION

This script is intended to be used by system initialisation daemons, which can run scripts to start and stop services. It is not intended to be used directly by the user.

It starts gammu-smsd in the background and logs its output to a file specified by the SMSD_LOGFILE environment variable. It also handles the logging of the PID file, which is needed to stop the daemon later.

The script expects the gammu-smsd binary to be in the system's PATH. The configuration file for gammu-smsd is expected to be specified using the gammu-smsd command line options or by the GAMMU_SMSD_CONF environment variable.

The script supports starting and stopping the daemon using arguments like start and stop.

ENVIRONMENT

SMSD_LOGFILE: The path to the log file where the output of gammu-smsd will be redirected.

GAMMU_SMSD_CONF: The path to the configuration file for gammu-smsd. If not set, the default configuration file is used.

PIDFILE: The path to the PID file where the process ID of the running gammu-smsd daemon will be stored.

EXAMPLES

To start the gammu-smsd daemon:

/path/to/gammu-smsd-run start

To stop the gammu-smsd daemon:

/path/to/gammu-smsd-run stop

To start the daemon with a specific configuration file and log file:

SMSD_LOGFILE=/var/log/gammu-smsd.log GAMMU_SMSD_CONF=/etc/gammu-smsdrc \
/path/to/gammu-smsd-run start
