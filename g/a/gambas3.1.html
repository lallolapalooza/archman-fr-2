NOM

gambas3 - Environnement de développement intégré

SYNTAXE

gambas3 [options] [<répertoire du projet>]

DESCRIPTION

Gambas est un environnement de développement libre basé sur un interpréteur Basic avec extensions objet, un mélange de Java(tm) et Visual Basic(tm). Avec Gambas, vous pouvez rapidement concevoir l'interface graphique de votre programme avec Qt ou GTK+, accéder à des systèmes de bases de données comme MySQL, PostgreSQL, SQLite ou les bases de données ODBC, piloter des applications avec DBus, traduire votre programme en plusieurs langues, créer des applications GStreamer, OpenGL ou SDL, et ainsi de suite...

Un programme écrit avec Gambas est un ensemble de fichiers. Chaque fichier décrit une classe, dans le cadre de la programmation orientée objet. Les fichiers de classe sont compilés, puis exécutés par un interpréteur. De ce point de vue, il est très inspiré de Java.

Gambas est composé des programmes suivants :


* Un compilateur.
* Un interpréteur.
* Un archiveur.
* Un composant d'interface graphique utilisateur.
* Un environnement de développement.

L'environnement de développement est écrit avec Gambas lui-même, suivant le paradigme "mange ta propre merde", et démontrant les capacités du langage.

gambas3 démarre l'environnement de développement intégré.

OPTIONS

-V, --version
affiche la version
-L, --license
affiche la licence
-h, --help
affiche l'aide et quitte

DISPONIBILITÉ

La dernière version de Gambas peut toujours être obtenue sur gambas.sourceforge.net, la documentation sur le langage est sur http://gambaswiki.org/wiki.
