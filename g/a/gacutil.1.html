NOM

gacutil - Utilitaire de gestion du cache d'assemblage global.

SYNTAXE

gacutil [-user] [commande] [options]

DESCRIPTION

gacutil est un outil utilisé par les développeurs pour installer des assemblages versionnés dans le cache d'assemblage global (GAC) du système afin qu'ils deviennent disponibles pour toutes les applications à l'exécution.

Notez qu'ils ne sont pas directement accessibles au compilateur. La convention est que les assemblages doivent également être placés dans un répertoire séparé pour être accessibles par le compilateur. Ceci est fait avec la directive -package de gacutil.

L'outil permet l'installation, la suppression et le listage du contenu du cache d'assemblage.

Le GAC est relatif au préfixe d'installation de Mono : mono_prefix/lib/mono.

COMMANDES

-i <chemin_assemblage> [-check_refs] [-package NOM] [-root REPERTOIRE_RACINE] [-gacdir REPERTOIRE_GAC]


Installe un assemblage dans le cache d'assemblage global. <chemin_assemblage> est le nom du fichier contenant le manifeste de l'assemblage.

L'option -package peut être utilisée pour créer également un répertoire dans prefix/lib/mono avec le nom NOM, et un lien symbolique est créé de NAME/assembly_name vers l'assemblage dans le GAC. Ceci est utilisé pour que les développeurs puissent référencer un ensemble de bibliothèques à la fois.

L'option -root est utilisée pour spécifier la valeur "libdir" d'un préfixe d'installation qui diffère du préfixe du GAC du système. L'utilisation typique d'automake est "-root $(DESTDIR)$(prefix)/lib". Pour accéder aux assemblages installés dans un préfixe autre que le préfixe mono, il est nécessaire de définir la variable d'environnement MONO_GAC_PREFIX.

L'option -gacdir est incluse pour des raisons de compatibilité ascendante mais n'est pas recommandée pour du nouveau code. Utilisez plutôt l'option -root.

L'option -check_refs est utilisée pour s'assurer que l'assemblage installé dans le GAC ne référence aucun assemblage non signé par une clé forte. Les assemblages installés dans le GAC ne devraient pas référencer d'assemblages non signés par une clé forte, cependant, il s'agit d'une vérification optionnelle.

-l [nom_assemblage] [-root REPERTOIRE_RACINE] [-gacdir REPERTOIRE_GAC]

Liste le contenu du cache d'assemblage global. Lorsque le paramètre <nom_assemblage> est spécifié, seuls les assemblages correspondants sont listés.

-u <nom_affichage_assemblage> [-package NOM] [-root REPERTOIRE_RACINE] [-gacdir REPERTOIRE_GAC]

Désinstalle un assemblage du cache d'assemblage global. <nom_affichage_assemblage> est le nom de l'assemblage (partiel ou entièrement qualifié) à supprimer du cache d'assemblage global. Si un nom partiel est spécifié, tous les assemblages correspondants seront désinstallés. Contrairement à l'option d'installation qui prend un nom de fichier, celle-ci prend en argument le nom de l'assemblage, qui ressemble à ceci :

MyLibrary.Something, version=1.0.0.0, publicKeyToken=xxxx,culture=neutral

Notez que vous pouvez avoir des espaces dans la ligne de commande. Il n'est pas nécessaire de les mettre entre guillemets.

Effectue une suppression agressive. Si vous ne spécifiez qu'un seul composant comme, "MyLibrary.Something", cela supprimera toutes les versions de la bibliothèque.

-us <chemin_assemblage> [-package NOM] [-root REPERTOIRE_RACINE] [-gacdir REPERTOIRE_GAC] Désinstalle un assemblage en utilisant le nom complet de l'assemblage spécifié. <chemin_assemblage> est le chemin vers un assemblage. Le nom complet de l'assemblage est récupéré à partir de l'assemblage spécifié. Si un assemblage portant un nom correspondant existe dans le GAC, il est supprimé. Contrairement à l'option -u, cette option prend un nom de fichier, comme suit :

        Exemple : -us myDll.dll

-ul <fichier_liste_assemblages> [-package NOM] [-root REPERTOIRE_RACINE] [-gacdir REPERTOIRE_GAC] Désinstalle un ou plusieurs assemblages du cache d'assemblage global. <fichier_liste_assemblages> est le chemin vers un fichier texte contenant une liste de noms d'assemblages sur des lignes séparées.

Exemple -ul assembly_list.txt
Contenu de assembly_list.txt :
    assembly1,Version=1.0.0.0,Culture=en,PublicKeyToken=0123456789abcdef
    assembly2,Version=2.0.0.0,Culture=en,PublicKeyToken=0123456789abcdef

FICHIERS

Sur Unix, les assemblages sont chargés depuis le répertoire lib d'installation. Si vous définissez `prefix' sur /usr, les assemblages seront situés dans /usr/lib. Sur Windows, les assemblages sont chargés depuis le répertoire où se trouvent mono et mint.

/etc/mono/config, ~/.mono/config

Fichier de configuration du runtime Mono. Voir la page de manuel mono-config(5) pour plus d'informations.
