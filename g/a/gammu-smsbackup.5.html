NOM

gammu-smsbackup - Format de fichier de sauvegarde SMS de gammu(1).

Le format de sauvegarde SMS est un fichier texte encodé dans le codage actuel de la plateforme où Gammu est exécuté.

Ce fichier utilise la syntaxe des fichiers ini, voir ini.

SECTIONS

Le fichier se compose de sections, dont le nom commence par SMSBackup. Lors de la création du fichier de sauvegarde, trois chiffres sont ajoutés à ce texte définissant l'ordre. Lors de la lecture de la sauvegarde, toute partie après le texte SMSBackup est ignorée et tout ce qui commence par celui-ci est traité. Vous pouvez donc également nommer la section SMSBackupFoo et elle sera traitée.

Le nombre de messages dans le fichier de sauvegarde est actuellement limité par GSM_BACKUP_MAX_SMS (100 000 au moment de la rédaction de ce document).

Section SMSBackup

Chaque section interprète un message SMS physique (par exemple, une partie de message dans le cas de messages multipartites).

Texte décodé

Pour les sauvegardes SMS créées par Gammu, il y a un texte décodé comme commentaire juste après le nom de la section :

[SMSBackup001]
; Ceci est le texte du message

Le texte peut être divisé en plusieurs lignes s'il est trop long ou si le message original incluait des sauts de ligne.

NOTE :

C'est la manière la plus simple d'obtenir le texte du message, mais aussi la moins fiable, car il est stocké dans les commentaires du fichier.

Variables

Les variables suivantes peuvent être définies pour chaque SMS :

SMSC
Représentation textuelle du numéro du SMSC, non utilisée par Gammu si SMSCUnicode existe.
SMSCUnicode
Chaîne UCS-2 encodée en hexadécimal avec le numéro du SMSC.
Class
Classe du message.
Sent
Horodatage, lorsque le message a été envoyé.
PDU
Type de message, l'un des suivants :
  • Deliver - message reçu
  • Submit - message à envoyer
  • Status_Report - message à envoyer avec rapport de livraison
DateTime
Horodatage du message (envoyé ou reçu).
RejectDuplicates
Si le destinataire doit rejeter les doublons.
ReplaceMessage
ID du message à remplacer.
MessageReference
Numéro de référence du message tel que généré par le réseau.
State
État du message :
  • Read
  • UnRead
  • Sent
  • UnSent
Number
Numéro du destinataire.
Name
Nom du message.
Length
Longueur du texte du message.
Coding
Codage du message :
  • 8bit - message binaire
  • Default - codage GSM, jusqu'à 160 caractères dans le message
  • Unicode - codage Unicode, jusqu'à 70 caractères dans le message
Text00 ... TextNN
Parties numérotées de la charge utile du message.
Folder
ID du dossier où le message a été sauvegardé.
UDH
En-tête défini par l'utilisateur du message.
