Attributs spécifiques aux objets des périphériques PCI.

Documentation des champs

unsigned char hwloc_obj_attr_u::hwloc_pcidev_attr_s::bus

Numéro de bus (yy dans la notation BDF PCI xxxx:yy:zz.t).

unsigned short hwloc_obj_attr_u::hwloc_pcidev_attr_s::class_id

Le numéro de classe (deux premiers octets, sans le prog_if).

unsigned char hwloc_obj_attr_u::hwloc_pcidev_attr_s::dev

Numéro de périphérique (zz dans la notation BDF PCI xxxx:yy:zz.t).

unsigned short hwloc_obj_attr_u::hwloc_pcidev_attr_s::device_id

ID du périphérique (yyyy dans [xxxx:yyyy]).

unsigned short hwloc_obj_attr_u::hwloc_pcidev_attr_s::domain

Numéro de domaine (xxxx dans la notation BDF PCI xxxx:yy:zz.t). Seuls les domaines PCI 16 bits sont supportés par défaut.

unsigned char hwloc_obj_attr_u::hwloc_pcidev_attr_s::func

Numéro de fonction (t dans la notation BDF PCI xxxx:yy:zz.t).

float hwloc_obj_attr_u::hwloc_pcidev_attr_s::linkspeed

Vitesse de liaison en Go/s. Ce débit est la vitesse actuellement configurée de toute la liaison PCI (somme de la bande passante de toutes les voies PCI de cette liaison). Elle peut changer pendant l'exécution car certains périphériques sont capables de ralentir leurs liaisons PCI lorsqu'elles sont inactives.

unsigned char hwloc_obj_attr_u::hwloc_pcidev_attr_s::revision

Numéro de révision.

unsigned short hwloc_obj_attr_u::hwloc_pcidev_attr_s::subdevice_id

ID du sous-périphérique.

unsigned short hwloc_obj_attr_u::hwloc_pcidev_attr_s::subvendor_id

ID du sous-fabricant.

unsigned short hwloc_obj_attr_u::hwloc_pcidev_attr_s::vendor_id

ID du fabricant (xxxx dans [xxxx:yyyy]).
