int hwloc_bitmap_singlify (hwloc_bitmap_t

bitmap)

Conserve un seul index parmi ceux définis dans le bitmap bitmap. Peut être utile avant le binding afin que le processus n'ait pas la possibilité de migrer entre plusieurs processeurs dans le masque d'origine. Au lieu de s'exécuter sur n'importe quelle PU à l'intérieur de l'ensemble de CPU donné, le planificateur du système d'exploitation sera forcé de l'exécuter sur une seule de ces PUs. Cela évite un surcoût de migration et des allers-retours de lignes de cache entre les

PUs.

Not

e
Cette fonction n'est PAS destinée à distribuer plusieurs processus au sein d'un seul ensemble de CPU. Elle renvoie toujours le même bit unique lorsqu'elle est appelée plusieurs fois sur le même ensemble d'entrée. hwloc_distrib() peut être utilisé pour générer des ensembles de CPU afin de distribuer plusieurs tâches sous un seul objet multi-PU.

Cette fonction ne peut pas être appliquée directement à un ensemble d'objets. Elle doit être appliquée à une copie (qui peut être obtenue avec hwloc_bi
