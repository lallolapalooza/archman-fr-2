hypot(3) Manuel des fonctions de bibliothèque hypot(3)

NOM

hypot, hypotf, hypotl - fonction de distance euclidienne

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double hypot(double x, double y);
float hypotf(float x, float y);
long double hypotl(long double x, long double y);
Exigences de macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

hypot():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

hypotf(), hypotl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent sqrt(x*x+y*y). C'est la longueur de l'hypoténuse d'un triangle rectangle de côtés de longueur x et y, ou la distance du point (x,y) à l'origine.

Le calcul est effectué sans débordement ou sous-dépassement excessif pendant les étapes intermédiaires du calcul.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la longueur de l'hypoténuse d'un triangle rectangle de côtés de longueur x et y.

Si x ou y est un infini, l'infini positif est retourné.

Si x ou y est un NaN, et l'autre argument n'est pas un infini, un NaN est retourné.

Si le résultat provoque un dépassement, une erreur de plage se produit, et les fonctions retournent HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement.

Si les deux arguments sont subnormaux, et le résultat est subnormal, une erreur de plage se produit, et le résultat correct est retourné.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de plage : dépassement du résultat
errno est défini à ERANGE. Une exception de virgule flottante de dépassement (FE_OVERFLOW) est déclenchée.
Erreur de plage : sous-dépassement du résultat
Une exception de virgule flottante de sous-dépassement (FE_UNDERFLOW) est déclenchée.
Ces fonctions ne définissent pas errno pour ce cas.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
hypot (), hypotf (), hypotl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD.

VOIR AUSSI

cabs(3), sqrt(3)
