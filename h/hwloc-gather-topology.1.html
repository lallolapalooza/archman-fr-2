HWLOC-GATHER-TOPOLOGY(1) hwloc HWLOC-GATHER-TOPOLOGY(1)

NOM

hwloc-gather-topology - Sauvegarde les fichiers pertinents de topologie Linux et x86 ainsi que les sorties texte et XML de lstopo pour une utilisation ultérieure (éventuellement hors ligne)

SYNTAXE

hwloc-gather-topology [options] <chemin>

OPTIONS

--io
Sauvegarde également les fichiers liés aux E/S. La sauvegarde peut être beaucoup plus lente et l'archive générée peut être beaucoup plus volumineuse.
--dmi
Sauvegarde également les fichiers liés à DMI/SMBIOS. La sauvegarde nécessite un accès root et le module noyau dmi-sysfs doit être chargé.
--dt
Sauvegarde également les fichiers CPU de Device-Tree. Ces fichiers ne sont pas nécessaires pour hwloc, mais ils peuvent être utilisés pour déboguer ce que Linux expose dans /sys.
--no-cpuid
Ne sauvegarde pas le dump du CPUID x86 à l'aide de hwloc-gather-cpuid.
--keep
Conserve la copie temporaire des fichiers dumpés au lieu de la détruire.
--version
Affiche la version et quitte.
-h --help
Affiche le message d'aide et quitte.

DESCRIPTION

hwloc-gather-topology sauvegarde tous les fichiers de topologie pertinents dans une archive (<chemin>.tar.bz2), la sortie de lstopo (<chemin>.output) et le XML de lstopo (<chemin>.xml). L'utilitaire stocke par exemple le fichier /proc/cpuinfo et l'intégralité de l'arborescence du répertoire /sys/devices/system/node/.

Ces fichiers peuvent être utilisés ultérieurement pour explorer la topologie de la machine hors ligne. Une fois l'archive décompressée, elle peut par exemple être fournie à certaines utilitaires en ligne de commande hwloc via leur option --input. Il est également possible de remplacer la topologie par défaut que la bibliothèque hwloc lira en définissant le chemin extrait dans la variable d'environnement HWLOC_FSROOT.

L'archive et les sorties texte et XML de lstopo peuvent également être soumises aux développeurs hwloc pour déboguer les problèmes à distance.

hwloc-gather-topology est un outil spécifique à Linux, il n'est pas installé sur d'autres systèmes d'exploitation.

NOTE: hwloc-gather-topology rassemble de nombreux détails matériels sur la plateforme. Les sorties et l'archive ne doivent pas être publiées sur des listes ou sites web publics, sauf s'il est clair qu'ils ne contiennent aucune information sensible.

NOTE: La collecte peut prendre plusieurs minutes, surtout sur les nœuds volumineux.

NOTE: Il est fortement recommandé de lire la page d'aperçu hwloc(7) avant de lire cette page de manuel.

EXEMPLES

Pour stocker les informations de topologie à utiliser ultérieurement (éventuellement sur un autre hôte), veuillez exécuter :


$ hwloc-gather-topology /tmp/monhote

Cela stockera tous les fichiers de topologie pertinents dans l'archive /tmp/monhote.tar.bz2, la sortie lstopo dans le fichier /tmp/monhote.output, et le XML lstopo dans le fichier /tmp/monhote.xml. Ces fichiers peuvent être transférés vers un autre hôte pour une analyse ultérieure/hors ligne et/ou comme entrée pour divers utilitaires hwloc.

Pour utiliser ces données avec les utilitaires hwloc, vous devez d'abord décompresser l'archive monhote.tar.bz2 :


$ tar jxvf /tmp/monhote.tar.bz2

Un nouveau répertoire nommé monhote contient maintenant tous les fichiers de topologie. Ensuite, vous demandez à divers utilitaires hwloc d'utiliser cette topologie au lieu de celle de la machine réelle en passant --input monhote. Pour afficher la topologie, exécutez simplement :


$ lstopo --input ./monhote

Il n'est pas nécessaire que la topologie soit extraite dans le répertoire courant, les chemins absolus ou relatifs sont également pris en charge :


$ lstopo --input /chemin/vers/hote/distant/topologie/extraite/

Pour voir comment hwloc distribuerait 8 travaux parallèles sur l'hôte d'origine :


$ hwloc-distrib --input monhote --single 8

Pour obtenir les index physiques correspondants dans la commande précédente :


$ hwloc-calc --input monhote --po --li -I pu $(hwloc-distrib --input monhote --single 8)

N'importe quel programme peut en fait remplacer la topologie par défaut par une topologie archivée donnée, même s'il n'a pas d'option --input. La variable d'environnement HWLOC_FSROOT doit être utilisée pour ce faire :


$ HWLOC_FSROOT=monhote hwloc-calc --po --li -I pu $(hwloc-distrib --single 8)

Toutes ces commandes produiront le même résultat que si elles étaient exécutées directement sur l'hôte sur lequel les informations de topologie ont été initialement collectées par le script hwloc-gather-topology.

VALEUR DE RETOUR

En cas d'exécution réussie, hwloc-gather-topology se terminera avec le code 0.

hwloc-gather-topology retournera un statut de sortie non nul si un quelconque type d'erreur survient, comme (mais sans s'y limiter) l'échec de la création de l'archive ou des fichiers de sortie.
