Description détaillée

Documentation du type énuméré

enum hwloc_distances_kind_e

Genres de matrices de distances. L'attribut kind de la structure hwloc_distances_s est un ensemble OR de genres.

Chaque matrice de distances ne peut avoir qu'un seul genre parmi HWLOC_DISTANCES_KIND_FROM_* spécifiant d'où proviennent les informations de distance, et un genre parmi HWLOC_DISTANCES_KIND_MEANS_* spécifiant si les valeurs sont des latences ou des bandes passantes.

Énumérateur

HWLOC_DISTANCES_KIND_FROM_OS
Ces distances ont été obtenues auprès du système d'exploitation ou du matériel.
HWLOC_DISTANCES_KIND_FROM_USER
Ces distances ont été fournies par l'utilisateur.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Les valeurs de distance sont similaires aux latences entre objets. Les valeurs sont plus petites pour les objets plus proches, donc minimales sur la diagonale de la matrice (distance entre un objet et lui-même). Cela peut aussi être le nombre de sauts réseau entre objets, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Les valeurs de distance sont similaires aux bandes passantes entre objets. Les valeurs sont plus élevées pour les objets plus proches, donc maximales sur la diagonale de la matrice (distance entre un objet et lui-même). De telles valeurs sont actuellement ignorées pour le groupement basé sur les distances.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Cette structure de distances couvre des objets de types différents. Cela peut s'appliquer à la structure 'NVLinkBandwidth' en présence d'un NVSwitch ou d'un port NVLink de processeur POWER.

enum hwloc_distances_transform_e

Transformations des structures de distances.

Énumérateur

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Supprime les objets NULL de la structure de distances. Chaque objet qui a été remplacé par NULL dans le tableau objs est supprimé et le tableau values est mis à jour en conséquence.

Au moins 2 objets doivent rester, sinon hwloc_distances_transform() renverra -1 avec errno défini sur EINVAL.

kind sera mis à jour avec ou sans HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES selon les objets restants.

HWLOC_DISTANCES_TRANSFORM_LINKS
Remplace les valeurs de bande passante par un nombre de liens. Généralement, toutes les valeurs seront soit 0 (aucun lien) soit 1 (un lien). Cependant, certaines matrices pourraient obtenir des valeurs plus grandes si certaines paires de pairs sont connectées par un nombre différent de liens.

Les valeurs sur la diagonale sont mises à 0.

Cette transformation ne s'applique qu'aux matrices de bande passante.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionne les switches avec plusieurs ports en un seul objet. Ceci s'applique actuellement uniquement aux NVSwitches où les GPU semblent connectés à différents ports de switch. Les ports de switch doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Cette transformation remplacera tous les ports par uniquement le premier, désormais connecté à tous les GPU. Les autres ports sont supprimés en appliquant HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL en interne.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Applique une fermeture transitive à la matrice pour connecter les objets à travers les switches. Toutes les paires de GPU seront rapportées comme étant directement connectées au lieu que les GPU ne soient connectés qu'aux switches.

Les ports de switch doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupère les matrices de distances. Récupère les matrices de distances de la topologie dans le tableau distances.

flags est actuellement inutilisé, doit être 0.

kind sert de filtre. Si 0, toutes les matrices de distances sont renvoyées. Si il contient des HWLOC_DISTANCES_KIND_FROM_*, seules les matrices de distances dont le genre correspond à l'un de ceux-ci sont renvoyées. Si il contient des HWLOC_DISTANCES_KIND_MEANS_*, seules les matrices de distances dont le genre correspond à l'un de ceux-ci sont renvoyées.

En entrée, nr pointe vers le nombre de matrices de distances qui peuvent être stockées dans distances. En sortie, nr pointe vers le nombre de matrices de distances qui ont été effectivement trouvées, même si certaines d'entre elles n'ont pas pu être stockées dans distances.
