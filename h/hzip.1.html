hunzip(1) Manuel des commandes générales hunzip(1)

NOM

hunzip - compresse et chiffre les fichiers de dictionnaire

SYNTAXE

hzip [-h] [-P mot de passe] [fichier(s)]

DESCRIPTION

hunzip est un petit utilitaire pour la compression et le chiffrement de fichiers texte, spécialement conçu pour les dictionnaires triés. "hunspell nom_de_fichier" crée le fichier compressé "nom_de_fichier.hz" sans supprimer le fichier original.

L'algorithme de compression utilise un codage Huffman sur 16 bits et une compression préfixe-suffixe orientée ligne. Il offre un bon taux de compression pour les listes de mots triées volumineuses.

OPTIONS

-h
Affiche une courte aide.
-P mot de passe
Compression chiffrée avec un mot de passe de longueur arbitraire.

VOIR AUSSI

hzip (1), hunspell(1)
