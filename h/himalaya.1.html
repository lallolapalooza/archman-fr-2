NOM

himalaya - CLI pour gérer les emails

SYNTAXE

himalaya [-c|--config] [-o|--output] [--debug] [--trace] [-h|--help] [-V|--version] [sous-commandes]

DESCRIPTION

CLI pour gérer les emails

OPTIONS

-c, --config=CHEMIN
Remplace le chemin du fichier de configuration par défaut.

Les chemins donnés sont développés par le shell puis canonicalisés (si applicable). Si le premier chemin ne pointe pas vers un fichier valide, l'assistant proposera de vous aider à créer le fichier de configuration. D'autres chemins sont fusionnés avec le premier, ce qui vous permet de séparer votre configuration publique de vos configurations privées.

Peut également être spécifié avec la variable d'environnement HIMALAYA_CONFIG.
-o, --output=FORMAT [défaut : plain]
Personnalise le format de sortie.

Le format de sortie détermine comment afficher les résultats des commandes dans le terminal.

Les valeurs possibles sont :

- json : la sortie sera sous forme d'objet compatible JSON

- plain : la sortie sera sous forme de texte brut ou de tableau, selon la commande

[valeurs possibles : plain, json]

--debug
Active les logs avec spantrace.

C'est la même chose que d'exécuter la commande avec la variable d'environnement `RUST_LOG=debug`.

--trace
Active les logs verbeux avec backtrace.

C'est la même chose que d'exécuter la commande avec les variables d'environnement `RUST_LOG=trace` et `RUST_BACKTRACE=1`.

-h, --help
Affiche l'aide (voir un résumé avec '-h')
-V, --version
Affiche la version

SOUS-COMMANDES

himalaya-account(1)
Configure, liste et diagnostique vos comptes
himalaya-folder(1)
Crée, liste et purge vos dossiers (également appelés boîtes aux lettres)
himalaya-envelope(1)
Liste, recherche et trie vos enveloppes
himalaya-flag(1)
Ajoute, modifie et supprime les drapeaux de vos enveloppes
himalaya-message(1)
Lit, écrit, envoie, copie, déplace et supprime vos messages
himalaya-attachment(1)
Télécharge les pièces jointes de vos messages
himalaya-template(1)
Génère, sauvegarde et envoie des modèles de messages
himalaya-manual(1)
Génère les pages de manuel dans le répertoire donné
himalaya-completion(1)
Affiche le script de complétion pour le shell donné sur stdout
himalaya-help(1)
Affiche ce message ou l'aide des sous-commandes données
