Description détaillée

Documentation des types énumérés

enum hwloc_distances_kind_e

Types de matrices de distances. L'attribut kind de la structure hwloc_distances_s est un ensemble OR de types.

Chaque matrice de distances ne peut avoir qu'un seul type parmi HWLOC_DISTANCES_KIND_FROM_* spécifiant d'où proviennent les informations de distance, et un seul type parmi HWLOC_DISTANCES_KIND_MEANS_* spécifiant si les valeurs sont des latences ou des bandes passantes.

Énumérateur

HWLOC_DISTANCES_KIND_FROM_OS
Ces distances ont été obtenues du système d'exploitation ou du matériel.
HWLOC_DISTANCES_KIND_FROM_USER
Ces distances ont été fournies par l'utilisateur.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Les valeurs de distance sont similaires aux latences entre les objets. Les valeurs sont plus petites pour les objets plus proches, donc minimales sur la diagonale de la matrice (distance entre un objet et lui-même). Cela peut aussi être le nombre de sauts réseau entre les objets, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Les valeurs de distance sont similaires aux bandes passantes entre les objets. Les valeurs sont plus élevées pour les objets plus proches, donc maximales sur la diagonale de la matrice (distance entre un objet et lui-même). Ces valeurs sont actuellement ignorées pour le regroupement basé sur la distance.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Cette structure de distances couvre des objets de types différents. Cela peut s'appliquer à la structure 'NVLinkBandwidth' en présence d'un NVSwitch ou d'un port NVLink de processeur POWER.

enum hwloc_distances_transform_e

Transformations des structures de distances.

Énumérateur

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Supprimer les objets NULL du tableau des objets de la structure de distances. Chaque objet qui a été remplacé par NULL dans le tableau objets est supprimé et le tableau values est mis à jour en conséquence.

Au moins 2 objets doivent rester, sinon hwloc_distances_transform() renverra -1 avec errno défini à EINVAL.

kind sera mis à jour avec ou sans HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES en fonction des objets restants.

HWLOC_DISTANCES_TRANSFORM_LINKS
Remplacer les valeurs de bande passante par un nombre de liens. Généralement, toutes les valeurs seront soit 0 (aucun lien), soit 1 (un lien). Cependant, certaines matrices peuvent obtenir des valeurs plus grandes si certaines paires de pairs sont connectées par différents nombres de liens.

Les valeurs sur la diagonale sont définies à 0.

Cette transformation ne s'applique qu'aux matrices de bande passante.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionner les commutateurs avec plusieurs ports en un seul objet. Ceci ne s'applique actuellement qu'aux NVSwitches où les GPU semblent connectés à différents ports du commutateur. Les ports du commutateur doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Cette transformation remplacera tous les ports par le premier port uniquement, désormais connecté à tous les GPU. Les autres ports sont supprimés en appliquant HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL en interne.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Appliquer une fermeture transitive à la matrice pour connecter les objets à travers les commutateurs. Toutes les paires de GPU seront signalées comme directement connectées au lieu que les GPU ne soient connectés qu'aux commutateurs.

Les ports des commutateurs doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Documentation des fonctions

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupérer les matrices de distances. Récupère les matrices de distances de la topologie dans le tableau distances.

flags est actuellement inutilisé, devrait être 0.

kind sert de filtre. Si 0, toutes les matrices de distances sont renvoyées. Si elle contient des HWLOC_DISTANCES_KIND_FROM_*, seules les matrices de distances dont le type correspond à l'un de ceux-ci sont renvoyées. Si elle contient des HWLOC_DISTANCES_KIND_MEANS_*, seules les matrices de distances dont le type correspond à l'un de ceux-ci sont renvoyées.

En entrée, nr pointe vers le nombre de matrices de distances qui peuvent être stockées dans distances. En sortie, nr pointe vers le nombre de matrices de distances qui ont été effectivement trouvées, même si certaines d'entre elles n'ont pas pu être stockées dans distances. Chaque matrice de distances retournée dans le tableau distances doit être libérée par l'appelant en utilisant hwloc_distances_release().

int hwloc_distances_get_by_depth (hwloc_topology_t topology, int depth, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupère les matrices de distances pour les objets à une profondeur spécifique dans la topologie. Identique à hwloc_distances_get() avec le filtre de profondeur depth supplémentaire.

Retourne

0 en cas de succès, -1 en cas d'erreur.

int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Récupère une matrice de distances avec le nom donné. Habituellement, seule une structure de distances peut correspondre à un nom donné.

Le nom de la structure la plus courante est 'NUMALatency'. D'autres incluent 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth' et 'NVLinkBandwidth'.

Retourne

0 en cas de succès, -1 en cas d'erreur.

int hwloc_distances_get_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupère les matrices de distances pour les objets d'un type spécifique. Identique à hwloc_distances_get() avec le filtre de type type supplémentaire.

Retourne

0 en cas de succès, -1 en cas d'erreur.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Obtient une description du contenu d'une structure de distances. Par exemple 'NUMALatency' pour les distances NUMA fournies par le matériel (ACPI SLIT), ou NULL si inconnu.

Retourne

la chaîne constante contenant le nom de la structure de distances.

Note

Le nom retourné ne doit pas être libéré par l'appelant, il appartient à la bibliothèque hwloc.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Libère une structure de matrice de distances précédemment retournée par hwloc_distances_get().

Note

Cette fonction n'est pas nécessaire si la structure est supprimée avec hwloc_distances_release_remove().

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Applique une transformation à une structure de distances. Modifie une structure de distances qui a été précédemment obtenue avec hwloc_distances_get() ou l'une de ses variantes.

Cela modifie la copie locale des structures de distances mais ne modifie pas les informations de distances stockées à l'intérieur de la topologie (récupérées par un autre appel à hwloc_distances_get() ou exportées en XML). Pour ce faire, on doit ajouter une nouvelle structure de distances avec le même nom, type, objets et valeurs (voir Ajouter des distances entre des objets) puis supprimer l'ancienne avec hwloc_distances_release_remove().

transform doit être l'une des transformations listées dans hwloc_distances_transform_e.

Ces transformations peuvent modifier le contenu des tableaux objs ou values .

transform_attr doit être NULL pour l'instant.

flags doit être 0 pour l'instant.

Retourne

0 en cas de succès, -1 en cas d'erreur, par exemple si les drapeaux sont invalides.

Note

Les objets dans le tableau objs de distances peuvent être directement modifiés sur place sans utiliser hwloc_distances_transform(). On peut utiliser hwloc_get_obj_with_same_locality() pour convertir facilement entre des objets similaires de types différents.
