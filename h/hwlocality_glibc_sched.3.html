hwlocality_glibc_sched - Interopérabilité avec l'affinité de planification glibc

SYNOPSIS

Description détaillée

Cette interface offre des moyens de convertir entre les jeux d'UC hwloc et les jeux d'UC glibc tels que ceux manipulés par sched_getaffinity() ou pthread_attr_setaffinity_np().

Note

La topologie topology doit correspondre à la machine actuelle.

Documentation des fonctions

int hwloc_cpuset_from_glibc_sched_affinity (hwloc_topology_t topologie, hwloc_cpuset_t hwlocset, const cpu_set_t * schedset, size_t schedsetsize) [inline]

Convertit le jeu d'UC d'affinité de planification glibc schedset en un jeu d'UC hwloc. Cette fonction peut être utilisée avant d'appeler sched_setaffinity ou toute autre fonction qui prend un cpu_set_t comme paramètre d'entrée.

schedsetsize doit être sizeof(cpu_set_t) à moins que schedset n'ait été alloué dynamiquement avec CPU_ALLOC.

Retourne

0 en cas de succès.

-1 avec errno défini à ENOMEM si une réallocation interne a échoué.

schedsetsize doit être sizeof(cpu_set_t) à moins que schedset n'ait été alloué dynamiquement avec CPU_ALLOC.
