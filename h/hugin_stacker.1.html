NOM

hugin_stacker - empile des images qui se chevauchent pour en faire une seule image

SYNTAXE

hugin_stacker [options] --mode=CHAÎNE images

DESCRIPTION

hugin_stacker agit sur une pile d'images qui se chevauchent et produit une image combinée et/ou un ensemble d'images de sortie masquées.

hugin_stacker est utile par exemple pour :

  • la suppression automatique des touristes (pas seulement des touristes, aussi d'autres objets en mouvement ;-))
  • la réduction du bruit
  • visualiser le mouvement
  • la multiplicité

OPTIONS

--mode
Sélectionne le mode d'empilement :
min|minimum|le_plus_sombre
Sélectionne le pixel le plus sombre.
max|maximum|le_plus_brillant
Sélectionne le pixel le plus brillant.
avg|average|moyen
Calcule la moyenne pour chaque position.
median
Calcule la médiane pour chaque position.
winsor
Calcule la moyenne tronquée de Winsor pour chaque position. Le paramètre peut être défini avec --winsor-trim=NOMBRE (par défaut : 0.2).
sigma
Calcule la moyenne coupée par sigma pour chaque position. Ajustez avec --max-sigma=NOMBRE (par défaut : 2) et --max-iterations=NOMBRE (par défaut : 5).

Paramètres supplémentaires

--output=FICHIER
Définit le nom du fichier de sortie (sinon, final.tif est utilisé).
--compression=valeur
Définit la compression des fichiers de sortie. Pour les fichiers jpeg, utilisez des valeurs entre 0 et 100. Pour les fichiers tiff, les valeurs valides sont : PACKBITS, DEFLATE, LZW.
--bigtiff
Écrit la sortie au format BigTIFF (uniquement avec sortie TIFF).

Masquer les images d'entrée

--mask-input
En plus de la sortie empilée, hugin_stacker peut également masquer les images d'entrée (disponible uniquement pour les modes d'empilement median|winsor|clip). Ce mode est activé avec --mask-input. Dans ce cas, l'image empilée est calculée en premier. Ensuite, chaque pixel de chaque image est vérifié : si la valeur de ce pixel diffère de plus de mask sigma * écart-type de la moyenne/médiane, ce pixel est rendu visible. S'il est dans la plage mentionnée, le pixel est masqué.
--mask-sigma=NOMBRE
définit le paramètre sigma pour --mask-input. La valeur par défaut est 2.
--mask-suffix=CHAÎNE
Produit une image de masque séparée pour chaque image d'entrée nommée nom_de_fichier_entréeCHAÎNE. La valeur par défaut est "_mask".
--multi-layer-output
Produit un TIFF multicouche avec le nom spécifié avec --output. Le fichier contient l'image moyennée comme couche 0 et toutes les images d'entrée comme couches supplémentaires avec le masque tel que décrit ci-dessus.
