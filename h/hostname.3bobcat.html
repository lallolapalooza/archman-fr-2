FBB::Hostname(3bobcat) Informations sur l'hôte FBB::Hostname(3bobcat)

NOM

FBB::Hostname - Contient des informations de nom/adresse sur un hôte

SYNTAXE

#include <bobcat/hostname>
Option de compilation : -lbobcat

DESCRIPTION

Les objets FBB::Hostname héritent de Hostent et offrent des informations sur un hôte, comme Hostent. En plus d'être initialisés par un nom d'hôte ou une adresse d'hôte, ils peuvent également être initialisés par un objet FBB::InetAddress. La plupart des fonctionnalités d'un objet FBB::Hostname sont disponibles via sa classe parente FBB::Hostent.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace nominal FBB.

HERITE DE

FBB::Hostent

CONSTRUCTEURS

o
Hostname() :
Le constructeur par défaut initialise un objet FBB::Hostname vide.
o
Hostname((std::string const &host)) :
Ce constructeur initialise un objet FBB::Hostname à partir d'une chaîne représentant le nom ou l'adresse décimale pointée d'un hôte. Un objet FBB::Exception est levé si les informations du nom d'hôte n'ont pas pu être récupérées.
o
Hostname(InetAddress const &inetAddress) :
Ce constructeur initialise un objet FBB::Hostname à partir d'un objet InetAddress. Un objet FBB::Exception est levé si les informations du nom d'hôte n'ont pas pu être récupérées.

Les constructeurs et opérateurs de copie et de déplacement (ainsi que les opérateurs d'affectation) sont disponibles.

FONCTIONS MEMBRES

Tous les membres de FBB::Hostent sont disponibles, car FBB::Hostname hérite de cette classe. Il n'y a pas de membres supplémentaires.

EXEMPLE

#include <iostream>
#include <bobcat/hostname>
#include <bobcat/exception>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    while (true)
    {
        cout << "Entrez le nom ou l'adresse:\n";
        string str;
        if (!getline(cin, str))
            return 0;
        if (str == "")
            break;
        try
        {
            Hostname h(str);
            cout << "Nom officiel:\n";
                cout << h.hostname() << endl;
            cout << "Alias:\n";
            for (size_t idx = 0; idx < h.nAliases(); idx++)
                cout << h.alias(idx) << " ";
            cout << endl;
            cout << "Adresses:\n";
            for (size_t idx = 0; idx < h.nAddresses(); idx++)
                cout << h.dottedDecimalAddress(idx) << " ";
            cout << endl;
        }
        catch (exception const &err)
        {
            cout << err.what() << endl;
        }
    }
}
