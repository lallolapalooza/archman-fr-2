FBB::Hash(3bobcat) Conteneurs de hachage de clés FBB::Hash(3bobcat)

NOM

FBB::Hash - Diverses classes de mappage utilisant le hachage

SYNTAXE

#include <bobcat/hash>

DESCRIPTION

Le groupe de classes de gabarits FBB::Hash offre un mappage basé sur le hachage. Diverses variantes sont disponibles, toutes basées sur les facilités offertes par unordered_map.

Le hachage de table proposé dans le conteneur unordered_map possède une interface de construction assez complexe, et Hash est une tentative de simplifier cette partie de son interface. En pratique, le hachage utilise une clé textuelle, qui peut être basée sur std::string ou sur char *, et les clés peuvent être utilisées avec distinction de casse ou sans distinction de casse. Hash demande simplement à ses utilisateurs de spécifier le type de valeur de la carte, tandis que la clé peut être un char const * ou std::string, utilisé avec ou sans distinction de casse.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::unordered_map, utilisant diverses instanciations.

TYPE

Toutes les variantes définissent value_type comme le value_type correspondant de unordered_map. En pratique, un value_type définit une std::pair<Key, Value>, où Key représente le type de clé du hachage et Value représente le type de valeur du hachage.

CONSTRUCTEURS

Des variantes du conteneur FBB::Hash sont disponibles pour les clés char const * ou std::string, utilisées avec ou sans distinction de casse.

Toutes les variantes prennent en charge la construction par défaut et par déplacement (ainsi que l'affectation par déplacement), la construction à partir de listes d'initialisation et la construction à partir d'itérateurs définissant une plage semi-ouverte de valeurs value_type.

Les variantes suivantes sont disponibles (montrant leurs constructeurs par défaut). Value fait référence au type de valeur stocké dans la table de hachage.

o
HashCharPtr<Value>():
cette table de hachage utilise des clés sensibles à la casse char const *;
o
HashCharCasePtr<Value>():
cette table de hachage utilise des clés insensibles à la casse char const *;
o
HashString<Value>():
cette table de hachage utilise des clés sensibles à la casse std::string;
o
HashStringCase<Value>():
cette table de hachage utilise des clés insensibles à la casse std::string ;

OPÉRATEUR(S) SOBRECARGÉ(S)

En plus de l'opérateur d'index hérité de unordered_map, les opérateurs d'affectation par copie et par déplacement surchargés sont disponibles pour tous les conteneurs Hash.

FONCTIONS MEMBRES

Tous les membres du conteneur unordered_map sont disponibles, car Hash hérite de cette classe de gabarit.

EXEMPLE

    #include <iostream>
    #include <bobcat/hash>
    using namespace std;
    using namespace FBB;
    pair<char const *, size_t> ap[] =
    {
        pair<char const *, size_t>("one", 1),
        pair<char const *, size_t>("two", 2),
    };
    int main()
    {
        HashCharPtr<size_t> hcp;
        HashCharPtr<size_t> hcp2(ap, ap + 2);
        HashCharPtr<size_t> hcp3(hcp2);
        hcp = hcp2;
        cout << hcp2["one"] << endl;
    }
