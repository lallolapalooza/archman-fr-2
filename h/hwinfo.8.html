HWINFO(8) Configuration système HWINFO(8)

NOM

hwinfo - sonder le matériel

SYNTAXE

hwinfo [ OPTIONS ]

DESCRIPTION

hwinfo est utilisé pour sonder le matériel présent dans le système. Il peut être utilisé pour générer un journal d'aperçu du système qui peut être utilisé ultérieurement pour le support.

OPTIONS

Notez que lancer hwinfo sans aucune option est à peu près équivalent à 'hwinfo --all --log=-'.

--<ELEMENT_MATERIEL>
Cette option peut être donnée plus d'une fois. Sonder pour un ELEMENT_MATERIEL particulier. Les éléments matériels disponibles sont :

all, arch, bios, block, bluetooth, braille, bridge, camera, cdrom, chipcard, cpu, disk, dsl, dvb, fingerprint, floppy, framebuffer, gfxcard, hub, ide, isapnp, isdn, joystick, keyboard, memory, mmc-ctrl, modem, monitor, mouse, netcard, network, partition, pci, pcmcia, pcmcia-ctrl, pppoe, printer, redasd, reallyall, scanner, scsi, smp, sound, storage-ctrl, sys, tape, tv, uml, usb, usb-ctrl, vbe, wlan, xen, zip

Notez que si cette option est absente, aucun sondage matériel ne sera effectué !

--short
Afficher seulement un résumé. Utilisez cette option en plus d'une option de sondage matériel.
--listmd
Normalement, hwinfo ne rapporte pas les périphériques RAID. Ajoutez cette option pour les voir.
--only NOM_PERIPH
Cette option peut être donnée plus d'une fois. Si vous ajoutez cette option, seules les entrées de la liste des périphériques correspondant à NOM_PERIPH seront affichées. Notez que vous devez également spécifier --<ELEMENT_MATERIEL> pour déclencher un sondage des périphériques.
--save-config SPEC
Stocker la configuration pour un périphérique particulier dans /var/lib/hardware. SPEC peut être un nom de périphérique, un UDI, ou 'all'. Cette option doit être donnée en plus d'une option de sondage matériel.
--show-config UDI
Afficher les données de configuration sauvegardées pour un périphérique particulier.
--map
Si les noms de disques ont changé (par exemple, après une mise à jour du noyau), cela affiche une liste des mappages de noms de disques. Notez que vous devez avoir utilisé --save-config à un moment donné auparavant pour que cela fonctionne.
--debug N
Définir le niveau de débogage à N. Les informations de débogage ne sont affichées que dans le fichier journal. Si vous spécifiez un fichier journal, le niveau de débogage est implicitement défini à une valeur raisonnable (N est un masque de bits pour des indicateurs individuels).
--verbose
Augmenter la verbosité. Seulement en combinaison avec --map.
--log FICHIER
Écrire les informations du journal dans FICHIER. N'oubliez pas de spécifier également --<ELEMENT_MATERIEL> pour déclencher un sondage des périphériques.
--dump-db N
Vider la base de données matérielle. N est soit 0 pour la base de données externe dans /var/lib/hardware, soit 1 pour la base de données interne.
--version
Afficher la version de libhd.
--help
Afficher l'utilisation.

ENVIRONNEMENT

hwprobe peut contenir une liste d'indicateurs de sondage séparés par des virgules, précédés de '+' ou '-' pour être activés ou désactivés. Pour obtenir une liste complète des indicateurs supportés, exécutez 'hwinfo -all' (notez : pas '--all') et regardez en haut de la sortie.

hwinfo examine également /proc/cmdline pour une option hwprobe.

EXEMPLES

- afficher tous les disques
hwinfo --disk
- juste un aperçu
hwinfo --short --block
- afficher un disque particulier
hwinfo --disk --only /dev/sdb
- sauvegarder l'état de configuration du disque
hwinfo --disk --save-config=all
- essayer 4 ports de carte graphique pour les données du moniteur (par défaut : 3)
hwprobe=bios.ddc.ports=4 hwinfo --monitor
- la détection du moniteur exécute le BIOS vidéo pour obtenir les données du moniteur ; vider une trace complète d'exécution du code BIOS dans le journal
hwprobe=bios.ddc.ports=1,x86emu=trace:dump:trace.only=0:dump.only=0 hwinfo --monitor --log=foo

FICHIERS

/var/lib/hardware/hd.ids
Base de données matérielle externe (en texte lisible). Essayez l'option --dump-db pour voir le format.
/var/lib/hardware/udi
Répertoire où les données de configuration persistantes sont stockées (voir l'option --save-config).

BOGUES

Tout le matériel ne peut pas être détecté.

VOIR AUSSI

Plus de documentation dans /usr/share/doc/packages/hwinfo.
