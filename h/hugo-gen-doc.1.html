NOM

hugo-gen-doc - Génère la documentation Markdown pour l'interface CLI de Hugo

SYNTAXE

hugo gen doc [indicateurs] [arguments]

DESCRIPTION

Génère la documentation Markdown pour l'interface CLI de Hugo. Cette commande est principalement utilisée pour créer une documentation à jour de l'interface en ligne de commande de Hugo pour https://gohugo.io/.

Elle crée un fichier Markdown par commande avec un front matter adapté
au rendu dans Hugo.

OPTIONS

--dir="/tmp/hugodoc/" le répertoire où écrire la documentation.

-h, --help[=false] aide pour la commande doc

OPTIONS HERITEES DES COMMANDES PARENTES

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de compilation

--ignoreVendorPaths="" ignore tous les chemins de module _vendor correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne crée pas le fichier .hugo_build.lock

--quiet[=false] compile en mode silencieux

-M, --renderToMemory[=false] rend en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers où lire les fichiers relativement depuis

--themesDir="" chemin du système de fichiers du répertoire des thèmes
