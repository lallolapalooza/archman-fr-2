Description

détaillée

La manière habituelle d'ajouter des distances est

: 
hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}

Énumérateur

HWLOC_DISTANCES_ADD_FLAG_GROUP
Tente de regrouper les objets en fonction des nouvelles informations de distance fournies. Le regroupement n'est effectué que lorsque la structure de distances contient des latences et lorsque tous les objets sont du même
type.
HWLOC_DISTANCES_ADD_FLAG_GROUP_INACCURATE
En cas de regroupement, considère les valeurs de distances comme imprécises et assouplit les comparaisons pendant les algorithmes de regroupement. La précision réelle peut être modifiée via la variable d'environnement HWLOC_GROUPING_ACCURACY (voir Variables

flags)

Valide une nouvelle structure de distances. Cette fonction finalise la structure de distances et l'insère dans la

topologie.

Paramètre handle a été précédemment retourné par hwloc_distances_add_create(). Puis les objets et les valeurs ont été spécifiés avec hwloc_distances_add_values()

distances.

En cas d'erreur, la structure de distances temporaire et son contenu sont

Crée une nouvelle structure de distances vide. Crée une structure de distances vide à remplir avec hwloc_distances_add_values() puis à valider avec hwloc_distances_add

_commit().

Paramètre name est facultatif, il peut être NULL. Sinon, il sera copié en interne et pourra ensuite être libéré par

Un seul type de signification et un seul type de provenance peuvent être donnés si approprié (par ex. HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH et HWLOC_DISTANCES_KIND_FROM_USER). Le type HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES sera automatiquement défini en fonction des objets ayant des types différents dans hwloc_distances_add_values()

int hwloc_distances_add_values (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned nbobjs, hwloc_obj_t * objs, hwloc_uint64_t * values, unsigned long

flags)

Spécifie les objets et les valeurs dans une nouvelle structure de distances vide. Spécifie les objets et les valeurs pour une nouvelle structure de distances qui a été retournée sous forme de poignée par hwloc_distances_add_create(). La structure doit ensuite être validée avec hwloc_distances_add

_commit().

Le nombre d'objets est nbobjs et le tableau d'objets est objs. Les valeurs de distance sont stockées sous forme d'un tableau unidimensionnel dans values. La distance de l'objet i à l'objet j se trouve à la position

i*nbobjs+j.

nbobjs doit être au moins

2.

Les tableaux objs et values seront copiés en interne, ils pourront ensuite être libérés par

l'appelant.

En cas d'erreur, la structure de distances temporaire et son contenu sont

détruits.
