hg-annotate(1)

Paquet: mercurial

Licences: GPL

HG(ANNOTATE) HG(ANNOTATE)

NOM

hg annotate - affiche les informations de commit ligne par ligne pour chaque fichier

SYNTAXE

hg annotate [-r REV] [-f] [-a] [-u] [-d] [-n] [-c] [-l] FICHIER...

DESCRIPTION

Liste les changements dans les fichiers, en montrant l'identifiant de révision responsable de chaque ligne.

Cette commande est utile pour découvrir quand une modification a été apportée et par qui.

Si vous incluez --file, --user, ou --date, le numéro de révision est supprimé à moins que vous n'incluiez également --number.

Sans l'option -a/--text, annotate évitera de traiter les fichiers qu'il détecte comme binaires. Avec -a, annotate annotera quand même le fichier, bien que les résultats ne soient probablement ni utiles ni souhaitables.

Utilisez les options -L/--line-range FICHIER,M:N pour filtrer la sortie aux lignes de M à N dans FICHIER. Cette option est incompatible avec --no-follow et ne peut pas être combinée avec des arguments de modèle de fichier. Lorsqu'elle est combinée avec --rev, les plages de lignes se réfèrent à l'état du fichier à la révision demandée.

Modèle :

Les mots-clés suivants sont pris en charge en plus des mots-clés et fonctions de modèle courants. Voir aussi hg help templates.

lines
Liste des lignes avec les données d'annotation.
path
Chaîne de caractères. Chemin absolu du dépôt du fichier spécifié.

Et chaque entrée de {lines} fournit les sous-mots-clés suivants en plus de {date}, {node}, {rev}, {user}, etc.

line
Chaîne de caractères. Contenu de la ligne.
lineno
Entier. Numéro de ligne à cette révision.
path
Chaîne de caractères. Chemin absolu du fichier à cette révision.

Voir hg help templates.operators pour la syntaxe d'expansion de liste.

Retourne 0 en cas de succès.

OPTIONS

-r,--rev <REV>
annoter la révision spécifiée
--follow
suivre les copies/renommages et lister le nom de fichier (OBSOLÈTE)
--no-follow
ne pas suivre les copies et renommages
-a, --text
traiter tous les fichiers comme du texte
-u, --user
lister l'auteur (long avec -v)
-f, --file
lister le nom de fichier
-d, --date
lister la date (court avec -q)
-n, --number
lister le numéro de révision (par défaut)
-c, --changeset
lister le jeu de modifications
-l, --line-number
afficher le numéro de ligne à la première apparition
--skip <REV[+]>
revset à ne pas afficher (EXPÉRIMENTAL)
-L,--line-range <FICHIER,PLAGE[+]>
suivre la plage de lignes du fichier spécifié (EXPÉRIMENTAL)
-w, --ignore-all-space
ignorer les espaces blancs lors de la comparaison des lignes
-b, --ignore-space-change
ignorer les changements dans la quantité d'espaces blancs
-B, --ignore-blank-lines
ignorer les changements dont les lignes sont toutes vides
-Z, --ignore-space-at-eol
ignorer les changements d'espaces blancs à la fin de ligne
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-T,--template <MODÈLE>
afficher avec le modèle

[+] l'option marquée peut être spécifiée plusieurs fois
