NOM

h2paspp - Programme de préprocesseur h2pas de Free Pascal.

SYNTAXE

h2paspp [-doih] fichier1 ... fichiern

DESCRIPTION

h2paspp lit un ou plusieurs fichiers d'en-tête C et les préprocesse, écrivant le résultat dans des fichiers portant le même nom que les originaux au fur et à mesure. Il n'accepte pas tous les jetons du préprocesseur C, mais prend en charge les directives de préprocesseur suivantes :

#define symbole
Définit le nouveau symbole symbole. Notez que les macros ne sont pas prises en charge.
#if symbole
Le texte suivant cette directive est inclus si symbole est défini.
#ifdef symbole
Le texte suivant cette directive est inclus si symbole est défini.
#ifndef symbole
Le texte suivant cette directive est inclus si symbole n'est pas défini.
#include nomdefichier
Les directives d'inclusion sont supprimées, sauf si l'option -I a été donnée, auquel cas le fichier inclus est inclus et écrit dans le fichier de sortie.
#undef symbole
Le symbole symbole est non défini.

UTILISATION

h2paspp accepte un ou plusieurs noms de fichiers et les préprocesse. Il lira l'entrée et écrira la sortie dans un fichier portant le même nom, sauf si l'option -o est donnée, auquel cas le fichier est écrit dans le fichier spécifié. Notez qu'un seul nom de fichier de sortie peut être donné.

OPTIONS

h2paspp a un petit nombre d'options pour contrôler son comportement :

-dsymbole
Définit le symbole symbole avant le début du traitement.
-h
émet une courte aide.
-ofichier_sortie
Si cette option est donnée, la sortie sera écrite dans un fichier nommé fichier_sortie. Notez qu'un seul fichier de sortie peut être donné.
