hg-incoming(1)

Paquet: mercurial

Licences: GPL

HG(INCOMING) HG(INCOMING)

NOM

hg incoming - afficher les nouveaux changements trouvés dans la source

SYNTAXE

hg incoming [-p] [-n] [-M] [-f] [-r REV]... [--bundle FICHIER] [SOURCE]

DESCRIPTION

Affiche les nouveaux changements trouvés dans le chemin/URL spécifié ou l'emplacement de téléchargement par défaut. Ce sont les changements qui auraient été téléchargés par hg pull au moment où vous avez émis cette commande.

Voir pull pour les détails sur le format de la source valide.

Avec -B/--bookmarks, le résultat de la comparaison des marques entre les dépôts locaux et distants est affiché. Avec -v/--verbose, le statut est également affiché pour chaque marque comme ci-dessous :

BM1               01234567890a ajouté
BM2               1234567890ab avancé
BM3               234567890abc divergé
BM4               34567890abcd modifié

L'action entreprise localement lors du téléchargement dépend du statut de chaque marque :

ajoutées

pull la créera

avancées

pull la mettra à jour

divergentes

pull créera une marque divergente

modifiées

le résultat dépend des changements distants

Du point de vue du comportement de téléchargement, une marque existante uniquement dans le dépôt distant est traitée comme ajoutée, même si elle est en fait supprimée localement.

Pour le dépôt distant, utiliser --bundle évite de télécharger les changements deux fois si la commande incoming est suivie d'un pull.

Exemples :

  • afficher les changements entrants avec des patchs et la description complète : 
    hg incoming -vp
  • afficher les changements entrants en excluant les fusions, stocker un bundle : 
    hg in -vpM --bundle incoming.hg
hg pull incoming.hg
  • lister brièvement les changements dans un bundle : 
    hg in changes.hg -T "{desc|firstline}\n"

    Retourne 0 s'il y a des changements entrants, 1 sinon.

OPTIONS

-f, --force
exécuter même si le dépôt distant n'est pas lié
-n, --newest-first
afficher le plus récent d'abord
--bundle <FICHIER>
fichier où stocker les bundles
-r,--rev <REV[+]>
un changement distant destiné à être ajouté
-B, --bookmarks
comparer les marques
-b,--branch <BRANCHE[+]>
une branche spécifique que vous souhaitez télécharger
-p, --patch
afficher le patch
-g, --git
utiliser le format de diff étendu de git
-l,--limit <NB>
limiter le nombre de changements affichés
-M, --no-merges
ne pas afficher les fusions
--stat
afficher un résumé des changements de type diffstat
-G, --graph
afficher le DAG des révisions
--style <STYLE>
afficher en utilisant un fichier de mapping de modèle (OBSOLÈTE)
-T,--template <MODÈLE>
afficher avec un modèle
-e,--ssh <CMD>
spécifier la commande ssh à utiliser
--remotecmd <CMD>
spécifier la commande hg à exécuter du côté distant
--insecure
ne pas vérifier le certificat du serveur (ignorant la configuration web.cacerts)
-S, --subrepos
récursion dans les sous-répertoires

[+] l'option marquée peut être spécifiée plusieurs fois
