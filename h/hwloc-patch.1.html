NOM

hwloc-patch - Appliquer une différence de topologie à une topologie XML existante

SYNTAXE

hwloc-patch [options] [<topology.xml> | nom_ref] [<diff.xml> | -] <output.xml>

hwloc-patch [options] [<topology.xml> | nom_ref] [<diff.xml> | -]

OPTIONS

-R --reverse
Inverser le sens du fichier de différence.
--version
Afficher la version et quitter.
-h --help
Afficher le message d'aide et quitter.

DESCRIPTION

hwloc-patch charge la différence entre deux topologies à partir d'un fichier XML (ou depuis l'entrée standard) et l'applique à une topologie existante, générant une nouvelle topologie modifiée.

La différence XML peut avoir été calculée précédemment avec hwloc-diff ou hwloc-compress-dir.

Si <output.xml> est spécifié, la nouvelle topologie modifiée est stockée dans ce nouveau fichier. Sinon, <topology.xml> est modifié sur place.

Si nom_ref est spécifié à la place de <topology.xml>, le nom du fichier de topologie d'entrée est automatiquement deviné en lisant le champ nom_ref du fichier de différence XML. Par défaut, hwloc-diff génère des différences XML avec le nom de fichier de la topologie de référence correcte (sans préfixe de chemin).

Si - est spécifié à la place de <diff.xml>, la différence de topologie est lue depuis l'entrée standard.

NOTE : Si des données utilisateur spécifiques à une application ont été exportées dans les fichiers XML d'entrée, elles seront ignorées et supprimées de la sortie car hwloc n'a aucun moyen de les comprendre et de les patcher.

NOTE : Il est fortement recommandé de lire la page d'aperçu hwloc(7) avant de lire cette page de manuel. La plupart des concepts décrits dans hwloc(7) s'appliquent directement à l'utilitaire hwloc-patch.

EXEMPLES

Le fonctionnement de hwloc-patch est mieux décrit à travers plusieurs exemples.

Appliquer un fichier de différence de topologie XML à une topologie existante :


$ hwloc-patch fourmi023.xml diff.xml fourmi023-new.xml

Appliquer un fichier de différence de topologie XML dont le champ nom_ref contient la bonne topologie d'entrée :


$ hwloc-patch nom_ref diff.xml fourmi023-new.xml

Appliquer une topologie XML depuis l'entrée standard :


$ cat diff.xml | hwloc-patch fourmi023.xml - fourmi023-new.xml

Calculer directement la différence entre deux topologies et l'appliquer à une autre, sur place :


$ hwloc-diff fourmi023.xml fourmi024.xml | hwloc-patch fourmi025.xml -

VALEUR DE RETOUR

En cas d'exécution réussie, hwloc-patch génère la topologie modifiée. La valeur de retour est 0.

hwloc-patch retourne également une valeur non nulle si une erreur quelconque se produit, comme (mais sans s'y limiter) l'échec de l'analyse de la ligne de commande.
