Description détaillée

Ceci inclut des auxiliaires pour manipuler les fichiers cpumap du noyau Linux, et des équivalents hwloc des appels système Linux sched_setaffinity et sched_getaffinity.

Documentation des fonctions

int hwloc_linux_get_tid_cpubind (hwloc_topology_t topology, pid_t tid, hwloc_cpuset_t set)

Obtenir la liaison actuelle du thread tid. L'ensemble de CPU set (préalablement alloué par l'appelant) est rempli avec la liste des UCs auxquelles le thread était précédemment lié.

Le comportement est exactement le même que l'appel système Linux sched_getaffinity, mais utilise un ensemble de CPU hwloc.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

Ceci est équivalent à appeler hwloc_get_proc_cpubind() avec HWLOC_CPUBIND_THREAD comme indicateurs.

int hwloc_linux_get_tid_last_cpu_location (hwloc_topology_t topology, pid_t tid, hwloc_bitmap_t set)

Obtenir le dernier CPU physique où le thread tid s'est exécuté. L'ensemble de CPU set (préalablement alloué par l'appelant) est rempli avec l'UC sur laquelle le thread s'est exécuté en dernier.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

Ceci est équivalent à appeler hwloc_get_proc_last_cpu_location() avec HWLOC_CPUBIND_THREAD comme indicateurs.

int hwloc_linux_read_path_as_cpumask (const char * path, hwloc_bitmap_t set)

Convertir un chemin de fichier cpumask du noyau Linux en un ensemble de bitmaps hwloc set. Peut être utilisé lors de la lecture d'ensembles de CPU à partir d'attributs sysfs tels que la topologie et les caches pour les processeurs, ou les cpus locaux pour les périphériques.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

Cette fonction ignore la variable d'environnement HWLOC_FSROOT.

int hwloc_linux_set_tid_cpubind (hwloc_topology_t topology, pid_t tid, hwloc_const_cpuset_t set)

Lier un thread tid aux CPUs donnés dans l'ensemble de CPUs set. Le comportement est exactement le même que l'appel système Linux sched_setaffinity, mais utilise un ensemble de CPUs hwloc.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

Ceci est équivalent à appeler hwloc_set_proc_cpubind() avec HWLOC_CPUBIND_THREAD comme indicateurs.
