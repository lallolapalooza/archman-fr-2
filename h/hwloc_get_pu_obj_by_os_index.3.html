int hwloc_bitmap_singlify_per_core (hwloc_topology_t topology, hwloc_bitmap_t cpuset, unsigned which)

Supprime les processeurs logiques (PU) du multithreading simultané d'un jeu de processeurs. Pour chaque cœur dans la topologie, si cpuset contient des PU de ce cœur, modifie cpuset pour ne conserver qu'une seule PU pour ce cœur.

which spécifie quelle PU sera conservée. Les PU sont considérées dans l'ordre de leur index physique. Si 0, pour chaque cœur, la fonction conserve la première PU qui était initialement définie dans cpuset.

Si which est supérieur au nombre de PU d'un cœur qui étaient initialement définies dans cpuset, aucune PU n'est conservée pour ce cœur.

Retourne

0.

Note

Les PU qui ne sont pas sous un objet Cœur sont ignorées (par exemple, si la topologie ne contient aucun objet Cœur). Aucune d'entre elles n'est supprimée de cpuset.

unsigned hwloc_get_closest_objs (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_t *restrict objs, unsigned max)

Effectue un parcours en profondeur de la topologie pour trouver et trier tous les objets qui se trouvent à la même profondeur que src. Rapportez dans objs jusqu'à max objets physiquement les plus proches de src.

Retourne

le nombre d'objets retournés dans objs.

0 si src est un objet d'E/S.

Note

Cette fonction nécessite que l'objet src ait un jeu de processeurs.

hwloc_obj_t hwloc_get_numanode_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Retourne l'objet de type HWLOC_OBJ_NUMANODE avec l'index système os_index. Cette fonction est utile pour convertir un jeu de nœuds (nodeset) en objets de nœuds NUMA qu'il contient. Lors de la récupération de la liaison actuelle (par exemple avec hwloc_get_membind() avec HWLOC_MEMBIND_BYNODESET), on peut itérer sur les bits du jeu de nœuds résultant avec hwloc_bitmap_foreach_begin(), et trouver les nœuds NUMA correspondants avec cette fonction.

Retourne

l'objet de nœud NUMA, ou NULL s'il n'y en a aucun correspondant.

hwloc_obj_t hwloc_get_obj_below_array_by_type (hwloc_topology_t topology, int nr, hwloc_obj_type_t * typev, unsigned * idxv) [inline]

Recherche un objet sous une chaîne d'objets spécifiés par des types et des index. C'est une version généralisée de hwloc_get_obj_below_by_type().

Les tableaux typev et idxv doivent contenir nr types et index.

Commence à l'objet système supérieur et parcourt les tableaux typev et idxv. Pour chaque couple type et index logique dans les tableaux, recherche sous l'objet trouvé précédemment pour trouver le nième objet du type donné. Les index sont spécifiés à l'intérieur du parent, pas dans l'ensemble du système.

Par exemple, si nr est 3, typev contient NODE, PACKAGE et CORE, et idxv contient 0, 1 et 2, retourne le troisième objet cœur sous le deuxième paquet sous le premier nœud NUMA.

Retourne

un objet correspondant s'il y en a un, NULL sinon.

Note

Cette fonction nécessite que tous ces objets et l'objet racine aient un jeu de processeurs.

hwloc_obj_t hwloc_get_obj_below_by_type (hwloc_topology_t topology, hwloc_obj_type_t type1, unsigned idx1, hwloc_obj_type_t type2, unsigned idx2) [inline]

Recherche un objet sous un autre objet, les deux spécifiés par des types et des index. Commence à l'objet système supérieur et trouve l'objet de type type1 et d'index logique idx1. Ensuite, cherche sous cet objet et trouve un autre objet de type type2 et d'index logique idx2. Les index sont spécifiés à l'intérieur du parent, pas dans l'ensemble du système.

Par exemple, si type1 est PACKAGE, idx1 est 2, type2 est CORE et idx2 est 3, retourne le quatrième objet cœur sous le troisième paquet.

Retourne

un objet correspondant s'il y en a un, NULL sinon.

Note

Cette fonction nécessite que ces objets aient un jeu de processeurs.

hwloc_obj_t hwloc_get_obj_with_same_locality (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_type_t type, const char * subtype, const char * nameprefix, unsigned long flags)

Retourne un objet d'un type différent ayant la même localité. Si l'objet source src est un type normal ou mémoire, cette fonction retourne un objet de type type avec les mêmes jeux de processeurs et de nœuds, soit en dessous, soit au-dessus dans la hiérarchie.

Si l'objet source src est un périphérique PCI ou un périphérique système sous un périphérique PCI, la fonction peut retourner soit ce périphérique PCI, soit un autre périphérique système sous le même parent PCI. Cela peut par exemple être utile pour convertir entre des périphériques système tels que 'nvml0' ou 'rsmi1' utilisés dans les structures de distance vers le périphérique PCI, ou le périphérique système CUDA ou OpenCL qui correspond à la même carte physique.

Si subtype n'est pas NULL, il ne sélectionne que les objets dont l'attribut subtype existe et correspond à subtype (insensible à la casse), par exemple 'OpenCL' ou 'CUDA'.

Si nameprefix n'est pas NULL, il ne sélectionne que les objets dont l'attribut name existe et commence par nameprefix (insensible à la casse), par exemple 'rsmi' pour correspondre à 'rsmi0'.

Si plusieurs objets correspondent, le premier est retourné.

Cette fonction ne traversera pas la hiérarchie à travers les ponts car la localité PCI pourrait devenir différente. Cette fonction ne peut pas non plus convertir entre des objets normaux/mémoire et des objets d'E/S ou Divers.

flags doit être 0 pour l'instant.

Retourne

Un objet avec une localité identique, correspondant à subtype et nameprefix s'il y en a.

NULL si aucun objet correspondant n'a pu être trouvé, ou si l'objet source et le type cible sont incompatibles, par exemple lors de la conversion entre des objets CPU et E/S.

NAME

hwloc_get_pu_obj_by_os_index - return the PU object corresponding to an OS index

SYNOPSIS

#include <hwloc.h>

struct hwloc_obj * hwloc_get_pu_obj_by_os_index(hwloc_topology_t topology, int os_index);

DESCRIPTION

Returns the object of type HWLOC_OBJ_PU with os_index. This function is useful for converting a CPU set into the PU objects it contains. When retrieving the current binding (e.g. with hwloc_get_cpubind()), one may iterate over the bits of the resulting CPU set with hwloc_bitmap_foreach_begin(), and find the corresponding PUs with this function.

Returns

the PU object, or NULL if none matches.
