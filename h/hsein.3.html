sous-routine chsein (character side, character eigsrc, character initv, logical, dimension( * ) select, integer n, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( * ) w, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, complex, dimension( * ) work, real, dimension( * ) rwork, integer, dimension( * ) ifaill, integer, dimension( * ) ifailr, integer

info)

CHSEI

N

But

: 
!>
!> CHSEIN utilise l'itération inverse pour trouver les vecteurs propres droits et/ou gauches
!> spécifiés d'une matrice de Hessenberg supérieure complexe H.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de la matrice H
!> correspondant à une valeur propre w sont définis par :
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> où y**h désigne la transposée conjuguée du vecteur y.
!
>

Paramètre

s
SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer à la fois les vecteurs propres droits et gauches.
!
>

EIGSR

C 
!>          EIGSRC est CHARACTER*1
!>          Spécifie la source des valeurs propres fournies dans W :
!>          = 'Q' : les valeurs propres ont été trouvées à l'aide de CHSEQR ; ainsi, si
!>                 H a des éléments sous-diagonaux nuls, et est donc
!>                 triangulaire par blocs, on peut supposer que la j-ième valeur propre
!>                 est une valeur propre du bloc contenant
!>                 la j-ième ligne/colonne. Cette propriété permet à CHSEIN de
!>                 effectuer l'itération inverse sur un seul bloc diagonal.
!>          = 'N' : aucune hypothèse n'est faite sur la correspondance
!>                 entre les valeurs propres et les blocs diagonaux. Dans ce
!>                 cas, CHSEIN doit toujours effectuer l'itération inverse
!>                 en utilisant la matrice entière H.
!
>

INIT

V 
!>          INITV est CHARACTER*1
!>          = 'N' : aucun vecteur initial n'est fourni ;
!>          = 'U' : les vecteurs initiaux fournis par l'utilisateur sont stockés dans les tableaux
!>                 VL et/ou VR.
!
>

SELEC

T 
!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Spécifie les vecteurs propres à calculer. Pour sélectionner le
!>          vecteur propre correspondant à la valeur propre W(j),
!>          SELECT(j) doit être défini à .TRUE..
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice H.  N >= 0.
!
>

H 
!>          H est un tableau COMPLEX, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>          Si un NaN est détecté dans H, la routine retournera avec INFO=-6.
!
>

LD

H 
!>          LDH est INTEGER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!
>

W 
!>          W est un tableau COMPLEX, dimension (N)
!>          À l'entrée, les valeurs propres de H.
!>          À la sortie, les parties réelles de W peuvent avoir été modifiées car
!>          les valeurs propres proches sont légèrement perturbées lors de la recherche de
!>          vecteurs propres indépendants.
!
>

V

L 
!>          VL est un tableau COMPLEX, dimension (LDVL,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'L' ou 'B', VL doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres gauches ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans la même colonne où le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'L' ou 'B', les vecteurs propres gauches
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VL, dans le même ordre que leurs valeurs propres.
!>          Si SIDE = 'R', VL n'est pas référencé.
!
>

LDV

L 
!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.
!>          LDVL >= max(1,N) si SIDE = 'L' ou 'B' ; LDVL >= 1 sinon.
!
>

V

R 
!>          VR est un tableau COMPLEX, dimension (LDVR,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'R' ou 'B', VR doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres droits ; le vecteur de départ pour chaque vecteur propre
!>          doit être dans la même colonne où le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'R' ou 'B', les vecteurs propres droits
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VR, dans le même ordre que leurs valeurs propres.
!>          Si SIDE = 'L', VR n'est pas référencé.
!
>

LDV

R 
!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.
!>          LDVR >= max(1,N) si SIDE = 'R' ou 'B' ; LDVR >= 1 sinon.
!
>

M

M 
!>          MM est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!
>

M 
!>          M est INTEGER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR nécessaires pour
!>          stocker les vecteurs propres (= le nombre d'éléments .TRUE. dans
!>          SELECT).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (N*N)
!
>

RWOR

K 
!>          RWORK est un tableau REAL, dimension (N)
!
>

IFAIL

L 
!>          IFAILL est un tableau INTEGER, dimension (MM)
!>          Si SIDE = 'L' ou 'B', IFAILL(i) = j > 0 si le vecteur propre gauche
!>          dans la i-ième colonne de VL (correspondant à la
!>          valeur propre w(j)) n'a pas convergé ; IFAILL(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante.
!>          Si SIDE = 'R', IFAILL n'est pas référencé.
!
>

IFAIL

R 
!>          IFAILR est un tableau INTEGER, dimension (MM)
!>          Si SIDE = 'R' ou 'B', IFAILR(i) = j > 0 si le vecteur propre droit
!>          dans la i-ième colonne de VR (correspondant à la
!>          valeur propre w(j)) n'a pas convergé ; IFAILR(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante.
!>          Si SIDE = 'L', IFAILR n'est pas référencé.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ième argument avait une valeur illégale
!>          > 0 :  si INFO = i, i est le nombre de vecteurs propres qui
!>                n'ont pas convergé ; voir IFAILL et IFAILR pour plus de
!>                détails.
!
>
