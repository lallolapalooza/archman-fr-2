NOM

halibut - outil de formatage de documentation multi-format

SYNTAXE

halibut [options] fichier1.but [fichier2.but ...]

DESCRIPTION

halibut lit les fichiers d'entrée donnés, les assemble en un document, et exporte ce document dans un ou plusieurs formats.

Les options de ligne de commande disponibles peuvent configurer les formats dans lesquels Halibut doit exporter, et peuvent également configurer d'autres aspects du fonctionnement de Halibut.

OPTIONS

Les options de ligne de commande supportées par halibut sont :

--text[=nom_fichier]
Demande à Halibut de générer un fichier de sortie au format texte brut. Si le paramètre optionnel nom_fichier est fourni, le fichier texte de sortie aura ce nom. Sinon, le nom du fichier texte de sortie sera celui spécifié dans les fichiers d'entrée, ou output.txt si aucun n'est spécifié du tout.
--html[=nom_fichier]
Demande à Halibut de générer un ou plusieurs fichiers de sortie au format HTML. Si le paramètre optionnel nom_fichier est fourni, il y aura précisément un fichier de sortie HTML portant ce nom, contenant l'intégralité du document. Sinon, il pourra y avoir un ou plusieurs fichiers HTML produits en sortie ; cela, ainsi que les noms de fichiers, seront tels que spécifiés dans les fichiers d'entrée, ou recevront des noms par défaut commençant par Contents.html si aucun n'est spécifié du tout.
--chm[=nom_fichier]
Demande à Halibut de générer un fichier de sortie au format d'aide HTML pour Windows. Si le paramètre optionnel nom_fichier est fourni, le fichier d'aide de sortie aura ce nom. Sinon, le nom du fichier d'aide de sortie sera celui spécifié dans les fichiers d'entrée, ou output.chm si aucun n'est spécifié du tout.
--winhelp[=nom_fichier]
Demande à Halibut de générer un fichier de sortie au format d'aide Windows ancien style. Si le paramètre optionnel nom_fichier est fourni, le fichier d'aide de sortie aura ce nom. Sinon, le nom du fichier d'aide de sortie sera celui spécifié dans les fichiers d'entrée, ou output.hlp si aucun n'est spécifié du tout.

Le fichier d'aide de sortie doit avoir un nom se terminant par .hlp ; s'il ne se termine pas ainsi, .hlp sera ajouté. Un fichier de contenu secondaire sera créé à côté du fichier d'aide principal, avec le même nom sauf qu'il se terminera par .cnt (par exemple output.cnt, si le fichier principal est output.hlp).

--man[=nom_fichier]
Demande à Halibut de générer un fichier de sortie au format page de manuel Unix man. Si le paramètre optionnel nom_fichier est fourni, la page de manuel man de sortie portera ce nom. Sinon, le nom de la page de manuel man de sortie sera celui spécifié dans les fichiers d'entrée, ou output.1 si aucun n'est spécifié du tout.
--info[=nom_fichier]
Demande à Halibut de générer un fichier info. Si le paramètre optionnel nom_fichier est fourni, le fichier info de sortie portera ce nom. Sinon, le nom du fichier info de sortie sera celui spécifié dans les fichiers d'entrée, ou output.info si aucun n'est spécifié du tout.

Par défaut, sauf configuration contraire à l'aide de la directive \cfg{info-max-file-size}{0}, la sortie info sera divisée en plusieurs fichiers. Le fichier principal portera le nom que vous spécifiez ; les fichiers subsidiaires auront les suffixes -1, -2, etc.

--pdf[=nom_fichier]
Demande à Halibut de générer un fichier de sortie au format PDF. Si le paramètre optionnel nom_fichier est fourni, le fichier de sortie PDF portera ce nom. Sinon, le nom du fichier de sortie PDF sera celui spécifié dans les fichiers d'entrée, ou output.pdf si aucun n'est spécifié du tout.
--ps[=nom_fichier]
Demande à Halibut de générer un fichier de sortie au format PostScript. Si le paramètre optionnel nom_fichier est fourni, le fichier de sortie PostScript portera ce nom. Sinon, le nom du fichier de sortie PostScript sera celui spécifié dans les fichiers d'entrée, ou output.ps si aucun n'est spécifié du tout.
-Cmot:mot[:mot...]
Ajoute une directive de configuration à l'entrée traitée par Halibut. L'utilisation de cette directive est exactement équivalente à ajouter un fichier d'entrée supplémentaire à la ligne de commande qui contient la directive \cfg{mot}{mot}{mot...}.
--input-charset=jeu_de_caracteres
Change le jeu de caractères présumé pour les fichiers d'entrée par défaut ASCII.
--list-charsets
Demande à Halibut de lister les jeux de caractères qu'il connaît.
--list-fonts
Demande à Halibut de lister les polices qu'il connaît, soit intrinsèquement, soit en étant fournies comme fichiers d'entrée.
--precise
Demande à Halibut de signaler le numéro de colonne ainsi que le numéro de ligne lorsqu'il rencontre une erreur dans un fichier d'entrée.
--help
Demande à Halibut d'afficher un bref résumé de ses options de ligne de commande.
--version
Demande à Halibut d'afficher son numéro de version.
--licence
Demande à Halibut d'afficher sa licence (MIT).
