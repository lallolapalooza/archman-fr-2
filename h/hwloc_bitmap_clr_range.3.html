Le type hwloc_bitmap_treprésente un ensemble d'entiers (positifs ou nuls). Un bitmap peut être de taille infinie (tous les bits sont définis après un certain point). Un bitmap peut même être complet si tous les bits sont définis. Les bitmap sont utilisés par hwloc pour les ensembles de processeurs du système d'exploitation (qui peuvent en fait être des fils matériels) sous la forme
hwloc_cpuset_t (un typedef pourhwloc_bitmap_t ), ou pour les ensembles de nœuds de mémoire NUMA sous la forme
hwloc_nodeset_t (également un typedef pourhwloc_bitmap_t ). Ceux-ci sont utilisés pour les champs cpuset et nodeset dans la structure

hwloc_ob

j

, voir Ensembles d'objets (hwloc_cpuset_t et hwloc_nodeset_t

)

. Les ensembles de CPU et de nœuds sont toujours indexés par le numéro physique du système d'exploitation. Cependant, les utilisateurs ne devraient généralement pas construire manuellement les ensembles de CPU et de nœuds (par exemple avec hwloc_bitmap_set() ). Il vaut mieux utiliser les ensembles d'objets existants et les combiner avec hwloc_bitmap_or() , etc. Par exemple, lier le thread actuel à une paire de cœurs peut être effectué avec

:

hwloc_obj_t core1 = ... , core2 = ... ; hwloc_bitmap_t set = hwloc_bitmap_alloc(); hwloc_bitmap_or(set, core1->cpuset, core2->cpuset); hwloc_set_cpubind(topology, set, HWLOC_CPUBIND_THREAD); hwloc_bitmap_free(set); Remarque La plupart des fonctions ci-dessous renvoient 0 en cas de succès et -1 en cas d'erreur. Le cas d'erreur habituel serait un échec interne de realloc/extension du stockage du bitmap

(errno

int hwloc_bitmap_list_asprintf (char ** strp, hwloc_const_bitmap_t bitmap)

Stringify a bitmap into a newly allocated list string. Note that if the bitmap is a CPU or nodeset, it contains physical indexes.

Lists are comma-separated indexes or ranges. Ranges are dash separated indexes. A bitmap containing bits 1, 33, 34, and all from 64 to 95 is printed as '1,33-34,64-95'. The last range may not have an ending index if the bitmap is infinitely set.

Returns

the number of characters that were written (not including the ending \0).

-1 on error, for instance with errno set to ENOMEM on failure to allocate the output string.

int hwloc_bitmap_list_snprintf (char *restrict buf, size_t buflen, hwloc_const_bitmap_t bitmap)

Stringify a bitmap in the list format. Note that if the bitmap is a CPU or nodeset, it contains physical indexes.

Lists are comma-separated indexes or ranges. Ranges are dash separated indexes. A bitmap containing bits 1, 33, 34, and all from 64 to 95 is printed as '1,33-34,64-95'. The last range may not have an ending index if the bitmap is infinitely set.

Up to buflen characters may be written in buffer buf.

If buflen is 0, buf may safely be NULL.

Returns

the number of characters that were actually written if not truncating, or that would have been written (not including the ending \0).

-1 on error.
