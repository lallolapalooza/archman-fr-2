Description détaillée

Documentation des types énumérés

enum hwloc_distances_kind_e

Types de matrices de distances. L'attribut kind de la structure hwloc_distances_s est un ensemble OR des types.

Chaque matrice de distances peut avoir un seul type parmi HWLOC_DISTANCES_KIND_FROM_* spécifiant d'où proviennent les informations de distance, et un type parmi HWLOC_DISTANCES_KIND_MEANS_* spécifiant si les valeurs sont des latences ou des bandes passantes.

Énumérateur

HWLOC_DISTANCES_KIND_FROM_OS
Ces distances ont été obtenues du système d'exploitation ou du matériel.
HWLOC_DISTANCES_KIND_FROM_USER
Ces distances ont été fournies par l'utilisateur.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Les valeurs de distance sont similaires aux latences entre les objets. Les valeurs sont plus petites pour les objets plus proches, donc minimales sur la diagonale de la matrice (distance entre un objet et lui-même). Cela peut aussi être le nombre de sauts réseau entre objets, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Les valeurs de distance sont similaires aux bandes passantes entre les objets. Les valeurs sont plus élevées pour les objets plus proches, donc maximales sur la diagonale de la matrice (distance entre un objet et lui-même). De telles valeurs sont actuellement ignorées pour le regroupement basé sur la distance.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Cette structure de distances couvre des objets de types différents. Cela peut s'appliquer à la structure 'NVLinkBandwidth' en présence d'un NVSwitch ou d'un port NVLink de processeur POWER.

enum hwloc_distances_transform_e

Transformations des structures de distances.

Énumérateur

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Supprimer les objets NULL de la structure de distances. Chaque objet qui a été remplacé par NULL dans le tableau objs est supprimé et le tableau values est mis à jour en conséquence.

Au moins 2 objets doivent rester, sinon hwloc_distances_transform() retournera -1 avec errno défini à EINVAL.

kind sera mis à jour avec ou sans HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES en fonction des objets restants.

HWLOC_DISTANCES_TRANSFORM_LINKS
Remplacer les valeurs de bande passante par un nombre de liens. Habituellement, toutes les valeurs seront soit 0 (aucun lien) soit 1 (un lien). Cependant, certaines matrices peuvent obtenir des valeurs plus grandes si certaines paires de pairs sont connectées par différents nombres de liens.

Les valeurs sur la diagonale sont mises à 0.

Cette transformation ne s'applique qu'aux matrices de bande passante.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionner les commutateurs avec plusieurs ports en un seul objet. Ceci ne s'applique actuellement qu'aux NVSwitches où les GPU semblent connectés à différents ports de commutateur. Les ports de commutateur doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Cette transformation remplacera tous les ports par le premier port uniquement, maintenant connecté à tous les GPU. Les autres ports sont supprimés en appliquant HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL en interne.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Appliquer une fermeture transitive à la matrice pour connecter des objets à travers les commutateurs. Toutes les paires de GPU seront signalées comme directement connectées au lieu que les GPU ne soient connectés qu'aux commutateurs.

Les ports de commutateur doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Detailed Description

The hwloc library provides access to the hardware topology of modern systems. This API exposes hardware locality information such as distances between components.

The hwloc_distances_get_* functions return arrays of distance structures, each describing the locality distances between groups of objects.

Each distance structure contains an array of objects (grouped by type and depth) and a 2D array of distances between these objects. For instance, it may contain the NUMA latency between memory nodes.

The kind parameter may be used to filter the types of distances to retrieve. It can be a combination of:

HWLOC_DISTANCES_KIND_ONLY_HWDATA
Only retrieve distances that are provided by the hardware (e.g. ACPI SLIT).
HWLOC_DISTANCES_KIND_ONLY_JULIA
Only retrieve distances that are computed by the hwloc library itself (e.g. based on latency estimations or object distances).
HWLOC_DISTANCES_KIND_ALL
Retrieve all available distances, whether hardware-provided or library-computed.

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve all available distance matrices in the topology.

If distances is NULL, the function will simply return the number of available distance matrices. Otherwise, it will return the array of structures.

The caller may find out if the topology has changed by comparing the value pointed to by nr before and after the function call. If the value changed, the previous array pointed to by distances is no longer valid and must be released using hwloc_distances_release() before calling hwloc_distances_get() again.

Each distance matrix returned in the distances array should be released by the caller using hwloc_distances_release().

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_depth (hwloc_topology_t topology, int depth, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve distance matrices for objects at a specific depth in the topology. Identical to hwloc_distances_get() with the additional depth filter.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Retrieve a distance matrix with the given name. Usually only one distances structure may match a given name.

The name of the most common structure is 'NUMALatency'. Others include 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth', and 'NVLinkBandwidth'.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve distance matrices for objects of a specific type. Identical to hwloc_distances_get() with the additional type filter.

Returns

0 on success, -1 on error.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Get a description of what a distances structure contains. For instance 'NUMALatency' for hardware-provided NUMA distances (ACPI SLIT), or NULL if unknown.

Returns

the constant string with the name of the distance structure.

Note

The returned name should not be freed by the caller, it belongs to the hwloc library.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Release a distance matrix structure previously returned by hwloc_distances_get().

Note

This function is not required if the structure is removed with hwloc_distances_release_remove().

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Apply a transformation to a distances structure. Modify a distances structure that was previously obtained with hwloc_distances_get() or one of its variants.

This modifies the local copy of the distances structures but does not modify the distances information stored inside the topology (retrieved by another call to hwloc_distances_get() or exported to XML). To do so, one should add a new distances structure with same name, kind, objects and values (see Add distances between objects) and then remove this old one with hwloc_distances_release_remove().

transform must be one of the transformations listed in hwloc_distances_transform_e.

These transformations may modify the contents of the objs or values arrays.

transform_attr must be NULL for now.

flags must be 0 for now.

Returns

0 on success, -1 on error for instance if flags are invalid.

Note

Objects in distances array objs may be directly modified in place without using hwloc_distances_transform(). One may use hwloc_get_obj_with_same_locality() to easily convert between similar objects of different types.

Enumeration Type Documentation

enum hwloc_distances_transform_e

These values are used to specify which transformation to apply to a distances matrix.

HWLOC_DISTANCES_TRANSFORM_ADD
Add the distances matrix from transform_attr to the existing one.
HWLOC_DISTANCES_TRANSFORM_SUBTRACT
Subtract the distances matrix from transform_attr from the existing one.
HWLOC_DISTANCES_TRANSFORM_REPLACE
Replace the existing distances matrix with the one from transform_attr.
HWLOC_DISTANCES_TRANSFORM_CLIP
Clip the distances matrix to keep only distances smaller than the one from transform_attr.
HWLOC_DISTANCES_TRANSFORM_SCALE
Scale the distances matrix by the value from transform_attr.
