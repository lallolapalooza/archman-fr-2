NOM

hub-alias - Afficher les instructions du shell pour encapsuler git.

SYNTAXE

hub alias [-s] [SHELL]

OPTIONS

-s

Générer un script shell adapté à eval.

SHELL

Spécifier le type de shell (par défaut : variable d'environnement "$SHELL").
