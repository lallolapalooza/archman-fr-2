hwloc_distances_kind_e Types de matrices de distances. L'attribut

kind

de struct hwloc_distances_s est un ensemble de types combinés par OR. Chaque matrice de distances ne peut avoir qu'un seul type parmi HWLOC_DISTANCES_KIND_FROM_* spécifiant la provenance des informations de distance, et un seul type parmi HWLOC_DISTANCES_KIND_MEANS_* spécifiant si les valeurs sont des latences ou des largeurs

de bande.

HWLOC_DISTANCES_KIND_FROM_OS

Ces distances ont été obtenues depuis le système d'exploitation ou le matériel.
HWLOC_DISTANCES_KIND_FROM_USE
R
Ces distances ont été fournies par l'utilisateur.
HWLOC_DISTANCES_KIND_MEANS_LATEN
CY
Les valeurs de distance sont similaires aux latences entre objets. Les valeurs sont plus petites pour les objets proches, donc minimales sur la diagonale de la matrice (distance entre un objet et lui-même). Il pourrait aussi s'agir du nombre de sauts réseau entre objets, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDT
H
Les valeurs de distance sont similaires aux largeurs de bande entre objets. Les valeurs sont plus élevées pour les objets proches, donc maximales sur la diagonale de la matrice (distance entre un objet et lui-même). De telles valeurs sont actuellement ignorées pour le regroupement basé sur les distances.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPE
S
Cette structure de distances couvre des objets de types différents. Cela peut s'appliquer à la structure 'NVLinkBandwidth' en présence d'un NVSwitch ou d'un port NVLink de processeur POWER.

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long

flags)

Récupérer les matrices de distances. Récupérer les matrices de distances depuis la topologie dans le tableau distances

.

flags est actuellement inutilisé, d

evrait être 0.

kind sert de filtre. Si 0, toutes les matrices de distances sont retournées. S'il contient certains HWLOC_DISTANCES_KIND_FROM_*, seules les matrices de distances dont le type correspond à l'un d'entre eux sont retournées. S'il contient certains HWLOC_DISTANCES_KIND_MEANS_*, seules les matrices de distances dont le type correspond à l'un d'entre eux sont

retournées.

En entrée, nr pointe vers le nombre de matrices de distances qui peuvent être stockées dans distances. En sortie, nr pointe vers le nombre de matrices de distances qui ont effectivement été trouvées, même si certaines d'entre elles n'ont pas pu être stockées dans distances. Les matrices de distances qui n'ont pas pu être stockées sont ignorées, mais la fonction renvoie toujours le succès (0). L'appelant peut le savoir en comparant la valeur pointée par nr avant et après l'appel à la

fonction.

Chaque matrice de distances retournée dans le tableau distances doit être libérée par l'appelant en utilisant hwloc_distances_release()

.

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long

Applique une transformation à une structure de distances. Modifie une structure de distances qui a été précédemment obtenue avec hwloc_distances_get() ou l'une de ses

Cela modifie la copie locale des structures de distances mais ne modifie pas les informations de distances stockées à l'intérieur de la topologie (récupérées par un autre appel à hwloc_distances_get() ou exportées en XML).
