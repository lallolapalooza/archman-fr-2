NOM

hashkit_clone - Documentation de libhashkit

SYNTAXE

#include <libhashkit-1.0/hashkit.h>
Compiler et lier avec -lhashkit
typedef struct hashkit_st hashkit_st
hashkit_st *hashkit_create(hashkit_st *hash)
Paramètres
hash -- adresse mémoire d'une structure hashkit_st ; si nullptr est passé, la structure sera allouée dynamiquement par libhashkit
Retourne
pointeur vers une structure hashkit_st initialisée
hashkit_st *hashkit_clone(hashkit_st *destination, const hashkit_st *ptr)
Paramètres
  • destination -- adresse mémoire d'une structure hashkit_st ; si nullptr est passé, la structure sera allouée dynamiquement par libhashkit
  • ptr -- pointeur de la structure hashkit_st à copier
Retourne
pointeur vers une structure hashkit_st (destination, si non nullptr), initialisée à partir de ptr
void hashkit_free(hashkit_st *hash)
Paramètres
hash -- pointeur vers une structure hashkit_st initialisée
bool hashkit_is_allocated(const hashkit_st *hash)
Paramètres
hash -- pointeur vers une structure hashkit_st initialisée
Retourne
bool, si la structure hash a été allouée dynamiquement

DESCRIPTION

La fonction hashkit_create() initialise un objet hashkit pour son utilisation. Si vous passez un argument nullptr pour hash, la mémoire de l'objet est allouée. Si vous spécifiez une zone mémoire pré-allouée, celle-ci est initialisée pour utilisation.

La fonction hashkit_clone() initialise un objet hashkit de manière similaire à hashkit_create(), mais au lieu d'utiliser les paramètres par défaut, elle utilisera les paramètres de l'objet hashkit ptr.

La fonction hashkit_free() libère toutes les ressources utilisées par les objets hashkit qui ont été initialisés avec hashkit_create() ou hashkit_clone().

La fonction hashkit_is_allocated() indique si la mémoire a été allouée pour un objet hashkit.

VALEUR DE RETOUR

hashkit_create() et hashkit_clone() retourneront nullptr en cas d'échec ou un pointeur vers hashkit_st en cas de succès.

hashkit_is_allocated() retourne true si la mémoire pour l'objet hashkit a été allouée à l'intérieur de hashkit_create() ou hashkit_clone(), sinon elle retourne false et la mémoire était fournie par l'utilisateur.
