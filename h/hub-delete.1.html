NOM

hub-delete - Supprime un dépôt existant sur GitHub.

SYNTAXE

hub delete [-y] [ORGANIZATION/]NAME

OPTIONS

-y, --yes

Ignore la demande de confirmation et supprime immédiatement le dépôt.

[ORGANIZATION/]NAME

Le nom du dépôt sur GitHub.

EXEMPLES

$ hub delete recipes
[ dépôt personnel supprimé sur GitHub ]
$ hub delete sinatra/recipes
[ dépôt supprimé dans l'organisation GitHub ]
