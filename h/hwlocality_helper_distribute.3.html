Documentation des fonctions

int hwloc_distrib (hwloc_topology_t topology, hwloc_obj_t * roots, unsigned n_roots, hwloc_cpuset_t * set, unsigned n, int until, unsigned long flags) [inline]

Distribue n éléments sur la topologie sous roots. Le tableau set sera rempli avec n jeux de processeurs distribués récursivement de manière linéaire sur la topologie sous les objets roots, jusqu'à la profondeur until (qui peut être INT_MAX pour distribuer jusqu'au niveau le plus fin).

n_roots est généralement 1 et roots ne contient que l'objet racine de la topologie afin de distribuer sur toute la topologie.

Ceci est généralement utile lorsqu'une application souhaite distribuer n threads sur une machine, en donnant à chacun autant de cache privé que possible et en les gardant localement par ordre numérique.

L'appelant peut généralement vouloir appeler hwloc_bitmap_singlify() avant de lier un thread afin qu'il ne bouge pas du tout.

flags doit être 0 ou un ensemble OR'é de hwloc_distrib_flags_e.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

Sur les processeurs hybrides (ou les plateformes asymétriques), la distribution peut être sous-optimale car le nombre de cœurs ou d'unités de traitement à l'intérieur des paquets ou sous les caches peut varier (le partitionnement récursif descendant ignore ces nombres jusqu'à ce qu'il atteigne leurs niveaux). Il est donc recommandé de distribuer uniquement à l'intérieur d'un seul domaine homogène. Par exemple, sur un processeur avec des cœurs E économes en énergie et des cœurs P haute performance, il faut distribuer séparément N tâches sur les cœurs E et M tâches sur les cœurs P au lieu d'essayer de distribuer directement M+N tâches sur tous les processeurs.

Cette fonction nécessite que les objets roots aient un jeu de processeurs.
