NOM

hugin_executor - assembler un projet hugin

SYNTAXE

hugin_executor [-h] [-a] [-s] [-t <num>] [-p <str>] [-d] input.pto

DESCRIPTION

hugin_executor est un outil en ligne de commande, utile pour assembler des projets dans des scripts shell.

OPTIONS

-h, --help
Affiche le message d'aide.
-a, --assistant
Exécute l'assistant.
-s, --stitching
Exécute l'assemblage avec le projet donné.
-t, --threads=num
Nombre de threads utilisés.
-p, --prefix=str
Préfixe utilisé pour l'assemblage. Si aucun préfixe n'est spécifié, il utilisera le préfixe de sortie trouvé dans la boîte de dialogue Préférences de Hugin. La valeur par défaut pour le préfixe de sortie est le nom de fichier (chemin inclus) du fichier projet.
-u, --user-defined-output=str
Utilise les commandes définies par l'utilisateur dans le fichier donné.
-d, --dry-run
Affiche seulement les commandes.
