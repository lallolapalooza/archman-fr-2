Nom

hcidump - Analyser les données HCI

SYNOPSIS

hcidump -h

hcidump [OPTIONS ...] [FILTRES]

DESCRIPTION

hcidump(1) lit les données HCI brutes provenant et allant vers un périphérique Bluetooth (qui peut être spécifié avec l'option -i, par défaut le premier disponible) et affiche à l'écran les commandes, événements et données sous une forme lisible par l'homme. Optionnellement, le vidage peut être écrit dans un fichier plutôt qu'analysé, et le fichier de vidage peut être analysé ultérieurement.

OPTIONS

-i <hciX>
Les données sont lues depuis hciX, qui doit être le nom d'un périphérique Bluetooth installé. Si non spécifié, et si l'option -r n'est pas définie, les données sont lues depuis le premier périphérique Bluetooth disponible.
-l <len>, --snap-len=<len>
Définit la longueur maximale des paquets traités à len.
-p <psm>, --psm=<psm>
Définit le multiplexeur de service de protocole (PSM) par défaut à psm.
-m <compid>, --manufacturer=<compid>
Définit l'identifiant de société par défaut pour le fabricant à compid.
-w <fichier>, --save-dump=<fichier>
La sortie de l'analyse n'est pas imprimée à l'écran, au lieu de cela, les données lues du périphérique sont enregistrées dans fichier. Le fichier de vidage sauvegardé peut ensuite être analysé avec l'option -r.
-r <fichier>, --read-dump=<fichier>
Les données ne sont pas lues depuis un périphérique Bluetooth, mais depuis fichier. fichier est créé avec l'option -t, --timestamp ajoute un horodatage à chaque paquet.
-a, --ascii
Pour chaque paquet, non seulement le type de paquet est affiché, mais aussi toutes les données en ASCII.
-x, --hex
Pour chaque paquet, non seulement le type de paquet est affiché, mais aussi toutes les données en hexadécimal.
-X, --ext
Pour chaque paquet, non seulement le type de paquet est affiché, mais aussi toutes les données en hexadécimal et ASCII.
-R, --raw
Pour chaque paquet, seules les données brutes sont affichées.
-C <psm>, --cmtp=<psm>
Définit la valeur PSM pour le protocole de transport de messages CAPI.
-H <psm>, --hcrp=<psm>
Définit la valeur PSM pour le canal de contrôle d'impression (Hardcopy Control Channel).
-O <channel>, --obex=<channel>
Définit la valeur du canal RFCOMM pour le protocole d'échange d'objets (Object Exchange Protocol).
-P <channel>, --ppp=<channel>
Définit la valeur du canal RFCOMM pour le protocole point à point (Point-to-Point Protocol).
-D <fichier>, --pppdump=<fichier>
Extrait le trafic PPP au format pppdump.
-A <fichier>, --audio=<fichier>
Extrait les données audio SCO.
-Y, --novendor
N'affiche aucune commande ni événement du fabricant et n'affiche aucun code PIN ni clé de liaison en texte clair.
-h
Affiche les informations d'utilisation et quitte

FILTRES

filter est une liste séparée par des espaces de catégories de paquets : les catégories disponibles sont lmp, hci, sco, l2cap, rfcomm, sdp, bnep, cmtp, hidp, hcrp, avdtp, avctp, obex, capi et ppp. Si des filtres sont utilisés, seuls les paquets appartenant aux catégories spécifiées sont vidés. Par défaut, tous les paquets sont vidés.
