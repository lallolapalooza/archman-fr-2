DESCRIPTIO

N

horst est un petit analyseur de réseau local sans fil IEEE802.11 léger avec une interface textuelle. Sa fonction de base est similaire à tcpdump, Wireshark ou Kismet, mais il est beaucoup plus petit et affiche des informations différentes et agrégées qui ne sont pas facilement disponibles avec d'autres outils. Il est principalement destiné au débogage des réseaux locaux sans fil, avec un accent sur le mode ad-hoc (IBSS) dans les grands réseaux maillés. Il peut être utile pour obtenir un aperçu rapide de ce qui se passe sur tous les canaux des réseaux locaux sans fil et pour identifier les

problèmes.

Modes de fonctionnement

Champ de bits du type de mode de fonctionnement déduit des paquets reçus. Les modes peuvent se chevaucher, il est donc courant de voir STA et PRB en même temps.

UNKNOWN 0x20 Inconnu, par ex. RTS/CTS ou ACK

MODE MONITEUR

Pour capturer et analyser le trafic 802.11, l'interface doit être en mode moniteur. Vous pouvez soit configurer l'interface manuellement au préalable, soit laisser horst la configurer automatiquement au démarrage. Habituellement, des privilèges root sont nécessaires pour modifier la configuration d'une interface.

horst devrait fonctionner avec n'importe quelle carte LAN sans fil et pilote qui prend en charge le mode moniteur, avec des en-têtes "prism2" ou "radiotap". Cela inclut la plupart des pilotes modernes basés sur mac80211.

Si l'interface n'est pas en mode moniteur au démarrage, horst essaie d'abord de la mettre en mode moniteur. Si cela échoue (par exemple, si l'interface est déjà utilisée), une nouvelle interface moniteur virtuelle (horst0) est ajoutée et utilisée à la place. L'interface moniteur virtuelle est supprimée lorsque horst se termine. Notez que le changement de canal via une interface moniteur virtuelle n'est pas autorisé par le pilote sans fil, donc les options -C et -s ne fonctionnent pas lorsque l'interface moniteur virtuelle est utilisée.

Exemples de configuration manuelle d'une interface :

Avec iw :
iw wlan0 interface add mon0 type monitor
ou
sudo iw wlan1 set type monitor
sudo iw wlan1 set channel 6
Avec iwconfig :
iwconfig wlan0 mode monitor
iwconfig wlan0 channel 1
ifconfig wlan0 up
Avec madwifi :
wlanconfig wlan0 create wlandev wifi0 wlanmode monitor
Avec hostap :
iwconfig wlan0 mode monitor
iwpriv wlan0 monitor_type 1

NOTES

Les valeurs et plages de signaux peuvent varier entre les pilotes et les versions sans fil.
