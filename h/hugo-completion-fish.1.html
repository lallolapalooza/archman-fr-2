NOM

hugo-completion-fish - Générer le script d'autocomplétion pour fish

SYNTAXE

hugo completion fish [options]

DESCRIPTION

Génère le script d'autocomplétion pour le shell fish.

Pour charger les complétions dans votre session shell actuelle :

hugo completion fish | source

Pour charger les complétions pour chaque nouvelle session, exécutez une fois :

hugo completion fish > ~/.config/fish/completions/hugo.fish

Vous devrez démarrer un nouveau shell pour que cette configuration prenne effet.

OPTIONS

-h, --help[=false] aide pour fish

--no-descriptions[=false] désactiver les descriptions de complétion

OPTIONS HERITEES DES COMMANDES PARENTES

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de compilation

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de modules correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne pas créer le fichier .hugo_build.lock

--quiet[=false] compiler en mode silencieux

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers où lire les fichiers relativement à

--themesDir="" chemin du système de fichiers du répertoire des thèmes
