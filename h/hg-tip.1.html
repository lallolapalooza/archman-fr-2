NOM

hg tip - afficher la révision de pointe (OBSOLÈTE)

SYNTAXE

hg tip [-p] [-g]

DESCRIPTION

La révision de pointe (généralement appelée simplement « tip ») est le changement (changeset) le plus récemment ajouté au dépôt (et par conséquent la tête la plus récemment modifiée).

Si vous venez de faire un commit, ce commit sera la pointe. Si vous venez de récupérer des changements d'un autre dépôt, la pointe de cet autre dépôt devient la pointe actuelle. Le tag « tip » est spécial et ne peut pas être renommé ou attribué à un autre changement.

Cette commande est obsolète, utilisez plutôt hg heads.

Retourne 0 en cas de succès.

OPTIONS

-p, --patch
afficher le patch
-g, --git
utiliser le format de diff étendu de git
--style <STYLE>
afficher en utilisant un fichier de modèle (OBSOLÈTE)
-T,--template <TEMPLATE>
afficher avec un modèle
