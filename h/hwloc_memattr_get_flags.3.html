Description détaillée

Les attributs de mémoire sont identifiés par un ID (hwloc_memattr_id_t) et un nom. hwloc_memattr_get_name() et hwloc_memattr_get_by_name() convertissent entre les deux (ou renvoient une erreur si l'attribut n'existe pas).

L'ensemble des hwloc_memattr_id_t valides est un ensemble contigu commençant à 0. Il contient d'abord les attributs prédéfinis, tels que listés dans hwloc_memattr_id_e (de 0 à HWLOC_MEMATTR_ID_MAX-1). Ensuite, des attributs personnalisés peuvent être enregistrés dynamiquement avec hwloc_memattr_register(). Ils recevront les IDs suivants (HWLOC_MEMATTR_ID_MAX pour le premier, etc.).

Pour parcourir tous les attributs valides (qu'ils soient prédéfinis ou enregistrés dynamiquement en tant que personnalisés), on peut parcourir les IDs à partir de 0 jusqu'à ce que hwloc_memattr_get_name() ou hwloc_memattr_get_flags() renvoie une erreur.

Les valeurs d'un attribut existant ou d'attributs personnalisés enregistrés dynamiquement peuvent être définies ou modifiées avec hwloc_memattr_set_value().

Documentation du type énumération

enum hwloc_memattr_flag_e

Drapeaux d'attribut de mémoire. Donnés à hwloc_memattr_register() et renvoyés par hwloc_memattr_get_flags().

Énumérateur

HWLOC_MEMATTR_FLAG_HIGHER_FIRST
Les meilleurs nœuds pour cet attribut de mémoire sont ceux ayant les valeurs les plus élevées. Par exemple la bande passante.
HWLOC_MEMATTR_FLAG_LOWER_FIRST
Les meilleurs nœuds pour cet attribut de mémoire sont ceux ayant les valeurs les plus basses. Par exemple la latence.
HWLOC_MEMATTR_FLAG_NEED_INITIATOR
La valeur renvoyée pour cet attribut de mémoire dépend de l'initiateur donné. Par exemple la bande passante et la latence, mais pas la capacité.

int hwloc_memattr_get_flags (hwloc_topology_t topology, hwloc_memattr_id_t attribute, unsigned long * flags)

Renvoie les drapeaux de l'attribut donné. Les drapeaux sont un ensemble combiné par OR de hwloc_memattr_flag_e.

Le pointeur de sortie flags ne peut pas être NULL.

Renvoie

0 en cas de succès.

-1 avec errno défini à EINVAL si l'attribut n'existe pas.

int hwloc_memattr_get_name (hwloc_topology_t topology, hwloc_memattr_id_t attribute, const char ** name)

Renvoie le nom d'un attribut de mémoire. Le pointeur de sortie name ne peut pas être NULL.

Renvoie

0 en cas de succès.

-1 avec errno défini à EINVAL si l'attribut n'existe pas.

int hwloc_memattr_register (hwloc_topology_t topology, const char * name, unsigned long flags, hwloc_memattr_id_t * id)

Enregistre un nouvel attribut de mémoire. Ajoute un nouvel attribut de mémoire personnalisé. Les drapeaux sont un ensemble combiné par OR de hwloc_memattr_flag_e. Il doit contenir l'un des deux HWLOC_MEMATTR_FLAG_HIGHER_FIRST ou HWLOC_MEMATTR_FLAG_LOWER_FIRST mais pas les deux.

Le nouvel attribut id est immédiatement après le dernier ID d'attribut existant (qui est soit l'ID du dernier attribut enregistré s'il y en a, soit l'ID du dernier attribut prédéfinis dans hwloc_memattr_id_e).

Renvoie

0 en cas de succès.

-1 avec errno défini à EINVAL si un ensemble invalide de drapeaux est donné.

-1 avec errno défini à EBUSY si un autre attribut utilise déjà ce nom.

int hwloc_memattr_set_value (hwloc_topology_t topology, hwloc_memattr_id_t attribute, hwloc_obj_t target_node, struct hwloc_location * initiator, unsigned long flags, hwloc_uint64_t value)

Définit une valeur d'attribut pour un nœud NUMA cible spécifique. Si l'attribut ne se rapporte pas à un initiateur spécifique (il n'a pas le drapeau HWLOC_MEMATTR_FLAG_NEED_INITIATOR), l'initiateur location est ignoré et peut être NULL.

L'initiateur sera copié dans la topologie, l'appelant doit libérer tout ce qui a été alloué pour stocker l'initiateur, par exemple le cpuset.

target_node ne peut pas être NULL.

attribute ne peut pas être HWLOC_MEMATTR_ID_CAPACITY ou HWLOC_MEMATTR_ID_LOCALITY.

flags doit être 0 pour l'instant.

Remarque

L'initiateur initiator doit être de type HWLOC_LOCATION_TYPE_CPUSET lorsqu'il fait référence aux accès effectués par les cœurs CPU. HWLOC_LOCATION_TYPE_OBJECT n'est actuellement pas utilisé en interne par hwloc, mais les utilisateurs peuvent par exemple l'utiliser pour fournir des informations personnalisées sur les accès à la mémoire de l'hôte effectués par les GPU.

Renvoie

0 en cas de succès ou -1 en cas d'erreur.

hwloc-memattr-get-flags(3)

Nom

hwloc_memattr_get_flags - obtenir les drapeaux d'attribut de mémoire

Synopsis

#include <hwloc.h>

int hwloc_memattr_get_flags(hwloc_topology_t topology,
                           hwloc_obj_t obj,
                           unsigned memory_depth,
                           hwloc_memattr_flag_t flags);

Description

La fonction hwloc_memattr_get_flags renvoie les drapeaux associés à un attribut de mémoire spécifique pour un objet donné dans la hiérarchie de topologie.

  • topology: le handle de la topologie.
  • obj: le pointeur vers l'objet dont vous souhaitez obtenir les attributs de mémoire.
  • memory_depth: la profondeur des objets de mémoire dans la topologie. Typiquement, cela serait HWLOC_OBJ_MEMCACHE_DEPTH pour les caches de mémoire, ou HWLOC_OBJ_NODE_DEPTH pour les nœuds mémoire.
  • flags: un masque des drapeaux d'attributs de mémoire pour lesquels vous souhaitez récupérer les valeurs.

Cette fonction est utile pour interroger des propriétés spécifiques de la mémoire, telles que sa performance ou sa localisation. Les drapeaux possibles sont définis dans l'API hwloc.

Types d'énumération

Aucun type d'énumération défini pour cette fonction.
