hivexget(1) Registre Windows hivexget(1)

NOM

hivexget - Obtenir une sous-clé d'un fichier binaire de registre Windows "hive"

SYNTAXE

hivexget fichier_hive '\Chemin\Vers\SousClef'
hivexget fichier_hive '\Chemin\Vers\SousClef' nom

NOTE

Ceci est un outil de bas niveau. Pour une manière plus pratique de naviguer dans le registre Windows dans les machines virtuelles Windows, voir virt-win-reg(1). Pour un formatage regedit approprié, utiliser hivexregedit(1).

DESCRIPTION

Ce programme navigue à travers un fichier binaire de registre Windows "hive" et extrait soit toutes les paires de données (clé, valeur) stockées dans cette sous-clé, soit le seul élément de valeur nommé.

Dans la première forme :

hivexget fichier_hive '\Chemin\Vers\SousClef'

"fichier_hive" est un fichier binaire de registre Windows, et "\Chemin\Vers\SousClef" est un chemin à l'intérieur de ce hive. NB le chemin est relatif au sommet de ce hive, et n'est pas le chemin complet tel que vous l'utiliseriez sous Windows (par exemple, "HKEY_LOCAL_MACHINE\SYSTEM" n'est pas un chemin valide).

Si la sous-clé existe, alors la sortie liste toutes les paires de données sous cette sous-clé, dans un format similaire à "regedit" sous Windows.

Dans la seconde forme :

hivexget fichier_hive '\Chemin\Vers\SousClef' nom

"fichier_hive" et le chemin sont comme ci-dessus. "nom" est le nom de la valeur d'intérêt (utiliser "@" pour la valeur par défaut).

L'élément de données correspondant est imprimé "brut" (c'est-à-dire sans traitement ni échappement) sauf :

1.
Si c'est une chaîne, nous la convertirons de Windows UTF-16 en UTF-8, si cette conversion est possible. La chaîne est imprimée avec un seul saut de ligne final.
2.
Si c'est une valeur à chaînes multiples, chaque chaîne est imprimée sur une ligne séparée.
3.
Si c'est une valeur numérique, elle est imprimée comme un nombre décimal.
