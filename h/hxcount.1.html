NOM

hxcount - compte les éléments et les attributs dans les fichiers HTML ou XML

SYNTAXE

hxcount [ fichier-ou-URL ]

DESCRIPTION

La commande hxcount compte le nombre d'éléments et d'attributs de chaque type qui apparaît dans l'entrée et imprime un rapport sur la sortie standard.

OPÉRANDES

L'opérande suivant est supporté :

fichier-ou-URL
Le nom ou l'URL d'un fichier HTML ou XML. S'il est absent, l'entrée standard est lue à la place.

STATUT DE SORTIE

Les valeurs de sortie suivantes sont retournées :

0
Achèvement réussi.
> 0
Une erreur s'est produite lors de l'analyse du fichier HTML ou XML. hxcount essaiera de récupérer de l'erreur et produira quand même une sortie.

ENVIRONNEMENT

Pour utiliser un proxy afin de récupérer les fichiers distants, définissez les variables d'environnement http_proxy et ftp_proxy. Par exemple, http_proxy="http://localhost:8080/"

BOGUES

Ne faites pas confiance à la sortie s'il y a eu des erreurs dans l'entrée.

Les fichiers distants (spécifiés avec une URL) ne sont actuellement pris en charge que pour HTTP. Les fichiers protégés par mot de passe ou les fichiers qui dépendent des "cookies" HTTP ne sont pas gérés. (Vous pouvez utiliser des outils tels que curl(1) ou wget(1) pour récupérer de tels fichiers.)

VOIR AUSSI
