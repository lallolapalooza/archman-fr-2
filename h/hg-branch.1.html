NOM

hg branch - définir ou afficher le nom de la branche courante

SYNTAXE

hg branch [-fC] [NOM]

DESCRIPTION

Note
Les noms de branche sont permanents et globaux. Utilisez hg bookmark pour créer un marqueur léger à la place. Consultez hg help glossary pour plus d'informations sur les branches nommées et les marqueurs.

Sans argument, affiche le nom de la branche courante. Avec un argument, définit le nom de la branche du répertoire de travail (la branche n'existera pas dans le dépôt avant le prochain commit). La pratique courante recommande que le développement principal se déroule sur la branche 'default'.

Sauf si -f/--force est spécifié, branch ne vous permettra pas de définir un nom de branche qui existe déjà.

Utilisez -C/--clean pour réinitialiser le nom de la branche du répertoire de travail à celui de son parent, annulant ainsi une modification précédente de branche.

Utilisez la commande hg update pour basculer vers une branche existante. Utilisez hg commit --close-branch pour marquer la tête de cette branche comme fermée. Lorsque toutes les têtes d'une branche sont fermées, la branche sera considérée comme fermée.

Retourne 0 en cas de succès.

OPTIONS

-f, --force
définir le nom de branche même s'il masque une branche existante
-C, --clean
réinitialiser le nom de branche au nom de la branche parente
-r,--rev <VALEUR[+]>
changer les branches des révisions données (EXPÉRIMENTAL)

[+] l'option marquée peut être spécifiée plusieurs fois
