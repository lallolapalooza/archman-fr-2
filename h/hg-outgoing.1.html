Paquet: mercurial

HG(SORTANT) HG(SORTANT)

NOM

hg outgoing - affiche les changeset qui ne se trouvent pas dans la destination

SYNOPSIS

hg outgoing [-M] [-p] [-n] [-f] [-r REV]... [DEST]...

DESCRIPTION

Affiche les changesets qui ne se trouvent pas dans le dépôt de destination spécifié ou l'emplacement de pousse par défaut. Ce sont les changesets qui seraient poussés si une opération de pousse était demandée.

Voir pull pour des détails sur les formats de destination valides.

Avec -B/--bookmarks, le résultat de la comparaison des marques locales et distantes est affiché. Avec -v/--verbose, le statut est également affiché pour chaque marque comme ci-dessous :

BM1               01234567890a added
BM2                            deleted
BM3               234567890abc advanced
BM4               34567890abcd diverged
BM5               4567890abcde changed

L'action entreprise lors d'une pousse dépend du statut de chaque marque :

ajouté

une pousse avec -B la créera

supprimé

une pousse avec -B la supprimera

avancé

la pousse la mettra à jour

divergé

une pousse avec -B la mettra à jour

modifié

une pousse avec -B la mettra à jour

Du point de vue du comportement de la pousse, les marques existant uniquement dans le dépôt distant sont traitées comme supprimé, même si elles sont effectivement ajoutées à distance.

Retourne 0 s'il y a des changements sortants, 1 sinon.

OPTIONS

-f, --force
exécute même si la destination n'est pas liée
-r,--rev <REV[+]>
un changeset destiné à être inclus dans la destination
-n, --newest-first
affiche d'abord les enregistrements les plus récents
-B, --bookmarks
compare les marques
-b,--branch <BRANCH[+]>
une branche spécifique que vous souhaitez pousser
-p, --patch
affiche le patch
-g, --git
utilise le format de diff étendu git
-l,--limit <NUM>
limite le nombre de changements affichés
-M, --no-merges
n'affiche pas les fusions
--stat
affiche un résumé des changements de type diffstat
-G, --graph
affiche le DAG de révision
--style <STYLE>
affiche en utilisant le fichier de modèle (OBSOLÈTE)
-T,--template <TEMPLATE>
affiche avec un modèle
-e,--ssh <CMD>
spécifie la commande ssh à utiliser
--remotecmd <CMD>
spécifie la commande hg à exécuter du côté distant
--insecure
ne vérifie pas le certificat du serveur (ignorant la configuration web.cacerts)
-S, --subrepos
récursivement dans les sous-dépôts

[+] l'option marquée peut être spécifiée plusieurs fois
