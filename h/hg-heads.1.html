NOM

hg heads - afficher les têtes de branche

SYNOPIS

hg heads [-ct] [-r STARTREV] [REV]...

DESCRIPTION

Sans arguments, affiche toutes les têtes de branche ouvertes dans le dépôt. Les têtes de branche sont des changeset qui n'ont pas de descendants sur la même branche. Ce sont les endroits où le développement se déroule généralement et ce sont les cibles habituelles pour les opérations de mise à jour et de fusion.

Si un ou plusieurs REVs sont donnés, seules les têtes de branche ouvertes sur les branches associées aux changements spécifiés sont affichées. Cela signifie que vous pouvez utiliser hg heads . pour voir les têtes sur la branche actuellement sélectionnée.

Si -c/--closed est spécifié, affiche également les têtes de branche marquées comme fermées (voir hg commit --close-branch).

Si STARTREV est spécifié, seules les têtes qui sont descendantes de STARTREV seront affichées.

Si -t/--topo est spécifié, les mécaniques de branche nommée seront ignorées et seules les têtes topologiques (changesets sans enfants) seront affichées.

Retourne 0 si des têtes correspondantes sont trouvées, 1 sinon.

OPTIONS

-r,--rev <STARTREV>
afficher seulement les têtes descendantes de STARTREV
-t, --topo
afficher uniquement les têtes topologiques
-a, --active
afficher uniquement les têtes de branche actives (OBSOLÈTE)
-c, --closed
afficher les têtes de branche normales et fermées
--style <STYLE>
afficher en utilisant un fichier de map de style (OBSOLÈTE)
-T,--template <TEMPLATE>
afficher avec un template
