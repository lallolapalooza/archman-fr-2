hwloc_obj_type_t hwloc_get_depth_type (hwloc_topology_t topology, int depth)

Retourne le type des objets à la profondeur depth. depth doit être compris entre 0 et hwloc_topology_get_depth()-1, ou une profondeur virtuelle telle que HWLOC_TYPE_DEPTH_NUMANODE.

Retourne

Le type des objets à la profondeur depth.

(hwloc_obj_type_t)-1 si la profondeur depth n'existe pas.

int hwloc_get_memory_parents_depth (hwloc_topology_t topology)

Retourne la profondeur des parents auxquels les objets mémoire sont attachés. Les objets mémoire ont des profondeurs négatives virtuelles car ils ne font pas partie de la hiérarchie principale des objets côté CPU. Cette profondeur ne doit pas être comparée à d'autres profondeurs de niveau.

Si tous les objets mémoire sont attachés à des parents Normaux à la même profondeur, cette profondeur parente peut être comparée aux autres comme d'habitude, par exemple pour savoir si les nœuds NUMA sont attachés au-dessus ou en dessous des Paquets.

Retourne

La profondeur des parents Normaux de tous les enfants mémoire si tous ces parents ont la même profondeur. Par exemple, la profondeur du niveau Paquet si tous les nœuds NUMA sont attachés à des objets Paquets.

HWLOC_TYPE_DEPTH_MULTIPLE si les parents Normaux de tous les enfants mémoire n'ont pas la même profondeur. Par exemple si certains nœuds NUMA sont attachés à des Paquets tandis que d'autres sont attachés à des Groupes.

int hwloc_get_type_depth (hwloc_topology_t topology, hwloc_obj_type_t type)

Retourne le niveau des objets de type type.

Retourne

Le niveau des objets de type type.

Un niveau virtuel négatif si un type d'objet de nœud NUMA, E/S ou Divers est fourni. Ces objets sont stockés dans des niveaux spéciaux qui ne sont pas liés au CPU. Ce niveau virtuel peut être passé à d'autres fonctions hwloc telles que hwloc_get_obj_by_depth() mais il ne doit pas être considéré comme un niveau réel par l'application. En particulier, il ne doit pas être comparé avec le niveau d'un autre objet ou avec le niveau de la topologie complète.

HWLOC_TYPE_DEPTH_UNKNOWN si aucun objet de ce type n'est présent sur l'architecture sous-jacente, ou si le système d'exploitation ne fourne pas ce type d'information.

HWLOC_TYPE_DEPTH_MULTIPLE si le type HWLOC_OBJ_GROUP est fourni et que plusieurs niveaux de Groupes existent.

Note

Si le type est absent mais qu'un type similaire est acceptable, voir aussi hwloc_get_type_or_below_depth() et hwloc_get_type_or_above_depth().

Voir aussi

hwloc_get_memory_parents_depth() pour gérer le niveau des objets de mémoire.

hwloc_type_sscanf_as_depth() pour retourner le niveau des objets dont le type est donné sous forme de chaîne.

int hwloc_get_type_or_above_depth (hwloc_topology_t topology, hwloc_obj_type_t type) [inline]

Retourne le niveau des objets de type type ou au-dessus. Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, la fonction retourne le niveau du premier objet « présent » contenant généralement type.

Cette fonction n'est significative que pour les types d'objets normaux. Si un type d'objet de mémoire, E/S ou Divers est fourni, le niveau virtuel correspondant est toujours retourné (voir hwloc_get_type_depth()).

Peut retourner HWLOC_TYPE_DEPTH_MULTIPLE pour HWLOC_OBJ_GROUP tout comme hwloc_get_type_depth().

int hwloc_get_type_or_below_depth (hwloc_topology_t topology, hwloc_obj_type_t type) [inline]

Retourne le niveau des objets de type type ou en-dessous. Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, la fonction retourne le niveau du premier objet « présent » trouvé généralement à l'intérieur de type.

Cette fonction n'est significative que pour les types d'objets normaux. Si un type d'objet de mémoire, E/S ou Divers est fourni, le niveau virtuel correspondant est toujours retourné (voir hwloc_get_type_depth()).

Peut retourner HWLOC_TYPE_DEPTH_MULTIPLE pour HWLOC_OBJ_GROUP tout comme hwloc_get_type_depth().

int hwloc_topology_get_depth (hwloc_topology_t restrict topology)

Obtient le niveau de l'arbre hiérarchique des objets. Il s'agit du niveau des objets HWLOC_OBJ_PU plus un.

Retourne

le niveau de l'arbre d'objets.

Note

Les nœuds NUMA, les objets E/S et Divers sont ignorés lors du calcul du niveau de l'arbre (ils sont placés sur des niveaux spéciaux).
