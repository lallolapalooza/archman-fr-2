HWLOC-GATHER-CPUID(1) hwloc HWLOC-GATHER-CPUID(1)

NOM

hwloc-gather-cpuid - Récupère les valeurs pertinentes de cpuid de x86 pour une utilisation ultérieure (éventuellement hors ligne)

SYNTAXE

hwloc-gather-cpuid [options] [<rep_sortie>]

OPTIONS

-c <idx>
Ne récupère les valeurs de cpuid que pour le processeur logique dont l'index OS/physique est <idx>.
-q --quiet -s --silent
Ne pas afficher de messages verbeux.
--version
Signaler la version et quitter.
-h --help
Afficher le message d'aide et quitter.

DESCRIPTION

hwloc-gather-cpuid enregistre toutes les valeurs pertinentes de cpuid x86 dans le sous-répertoire cpuid du répertoire courant, ou dans <rep_sortie> si spécifié.

Ces fichiers peuvent être utilisés plus tard pour explorer la topologie de la machine hors ligne, par exemple en définissant la variable d'environnement HWLOC_CPUID_PATH sur le répertoire contenant tous les fichiers de sortie, et en forçant le backend x86 avec HWLOC_COMPONENTS=x86,stop.

Le contenu du répertoire peut également être soumis aux développeurs hwloc pour déboguer des problèmes à distance.

Si - est utilisé comme <rep_sortie>, la sortie est envoyée à la sortie standard, mais un processeur logique unique doit avoir été fourni avec -c.

hwloc-gather-cpuid est un outil spécifique à x86, il ne peut pas être utilisé sur d'autres plateformes.

NOTE: hwloc-gather-cpuid rassemble de nombreux détails matériels sur la plateforme. Les fichiers de sortie ne doivent pas être publiés sur des listes ou sites Web publics à moins qu'il ne soit clair qu'ils ne contiennent aucune information sensible.

NOTE: La sortie de hwloc-gather-cpuid est incluse dans l'archive créée par hwloc-gather-topology sous Linux/x86.

NOTE: Il est fortement recommandé de lire la page d'aperçu hwloc(7) avant de lire cette page de manuel.

EXEMPLES

Pour stocker les informations cpuid de tous les processeurs logiques de la machine courante :


$ hwloc-gather-cpuid
Gathering in directory ./cpuid ...
Gathering CPUID of PU P#0 in path ./hwloc-x86-cpuid/pu0 ...
Gathering CPUID of PU P#1 in path ./hwloc-x86-cpuid/pu1 ...
Gathering CPUID of PU P#2 in path ./hwloc-x86-cpuid/pu2 ...
Gathering CPUID of PU P#3 in path ./hwloc-x86-cpuid/pu3 ...
Summary written to ./cpuid/hwloc-cpuid-info

VALEUR DE RETOUR

Lors d'une exécution réussie, hwloc-gather-cpuid se terminera avec le code 0.

hwloc-gather-cpuid renverra un statut de sortie non nul si une erreur quelconque survient, telle que (mais sans s'y limiter) l'échec de création des fichiers de sortie.

VOIR AUSSI
