NOM

hg help - afficher l'aide pour un sujet donné ou un aperçu de l'aide

SYNTAXE

hg help [-eck] [-s PLATEFORME] [SUJET]

DESCRIPTION

Sans arguments, imprime une liste de commandes avec de courts messages d'aide.

Donner un sujet, une extension ou un nom de commande, imprime l'aide pour ce sujet.

Retourne 0 en cas de succès.

OPTIONS

-e, --extension
afficher uniquement l'aide pour les extensions
-c, --command
afficher uniquement l'aide pour les commandes
-k, --keyword
afficher les sujets correspondant au mot-clé
-s,--system <PLATEFORME[+]>
afficher l'aide pour des plateformes spécifiques

[+] l'option marquée peut être spécifiée plusieurs fois
