int hwloc_get_obj_index_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t obj) [inline]

Renvoyer l'index logique parmi les objets inclus dans l'ensemble de CPU set. Consulter tous les objets du même niveau que obj et à l'intérieur de l'ensemble de CPU set dans l'ordre logique, et renvoyer l'index de obj parmi eux. Si set couvre toute la topologie, il s'agit de l'index logique de obj. Sinon, c'est similaire à un index logique au sein de la partie de la topologie définie par l'ensemble de CPU set

.

Renvoi

e "Bd-indent">l'indice logique parmi les objets inclus dans l'ensemble le cas échéant.

-1 si l'objet n'est pas inclus dans l'ensemble.

Note

Les objets avec des ensembles de CPU vides sont ignorés (sinon ils seraient considérés comme inclus dans tout ensemble donné).

Cette fonction ne peut pas fonctionner si obj n'a pas d'ensembles de CPU (objets I/O).
