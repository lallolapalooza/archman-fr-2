subroutine chesv (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer info)

CHESV calcule la solution du système d'équations linéaires A * X = B pour les matrices HE

But :

!>
!> CHESV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne N par N et X et B sont des matrices
!> N par NRHS.
!>
!> La méthode de pivotage diagonal est utilisée pour factoriser A comme
!>    A = U * D * U**H,  si UPLO = 'U', ou
!>    A = L * D * L**H,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et de matrices
!> triangulaires supérieures (inférieures) unitaires, et D est hermitienne
!> et bloc-diagonale avec des blocs diagonaux de taille 1 par 1 et 2 par 2.
!> La forme factorisée de A est ensuite utilisée pour résoudre le système
!> d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure N par N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie
!>          triangulaire strictement inférieure de A n'est pas référencée.
!>          Si UPLO = 'L', la partie triangulaire inférieure N par N de A
!>          contient la partie triangulaire inférieure de la matrice A, et
!>          la partie triangulaire strictement supérieure de A n'est pas
!>          référencée.
!>
!>          À la sortie, si INFO = 0, la matrice bloc-diagonale D et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à partir
!>          de la factorisation A = U*D*U**H ou A = L*D*L**H telle que
!>          calculée par CHETRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure de blocs de D, tels que
!>          déterminés par CHETRF.  Si IPIV(k) > 0, alors les lignes et
!>          colonnes k et IPIV(k) ont été échangées, et D(k,k) est un bloc
!>          diagonal de taille 1 par 1.  Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0,
!>          alors les lignes et colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal de taille 2 par 2.  Si UPLO = 'L' et
!>          IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1 et
!>          -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal
!>          de taille 2 par 2.
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des seconds membres B de taille N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= 1, et pour de meilleures
!>          performances LWORK >= max(1,N*NB), où NB est la taille de bloc
!>          optimale pour CHETRF.
!>          pour LWORK < N, TRS sera fait avec le BLAS de niveau 2
!>          pour LWORK >= N, TRS sera fait avec le BLAS de niveau 3
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau WORK, et
!>          aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro.  La factorisation
!>               a été complétée, mais la matrice bloc-diagonale D est
!>               exactement singulière, donc la solution n'a pas pu être calculée.
!>

ZHESV calcule la solution au système d'équations linéaires A * X = B pour les matrices HE

Objectif :

!>
!> ZHESV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne N par N et X et B sont des matrices N par NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A comme suit :
!>    A = U * D * U**H,  si UPLO = 'U', ou
!>    A = L * D * L**H,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et de matrices triangulaires unitaires supérieures (inférieures), et D est hermitienne et diagonale par blocs avec des blocs diagonaux 1x1 et 2x2. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est de type CHARACTER*1
!>          = 'U' : La partie supérieure de A est stockée ;
!>          = 'L' : La partie inférieure de A est stockée.
!>

ZSYSV calcule la solution au système d'équations linéaires A * X = B pour les matrices SY

Objectif :

!>
!> ZSYSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice symétrique N par N et X et B sont des matrices N par NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A comme suit :
!>    A = U * D * U**T,  si UPLO = 'U', ou
!>    A = L * D * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et de matrices triangulaires unitaires supérieures (inférieures), et D est symétrique et diagonale par blocs avec des blocs diagonaux 1x1 et 2x2. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est de type CHARACTER*1
!>          = 'U' : La partie supérieure de A est stockée ;
!>          = 'L' : La partie inférieure de A est stockée.
!>

!>          N est un entier.
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A. N >= 0.

NRHS

zhesv — résout un système d'équations linéaires A*X = B où A est une matrice hermitienne et définie positive, ou une matrice hermitienne et indéfinie.

        CHARACTER(*) :: UPLO

        COMPLEX*16 :: A(LDA, *), B(LDB, *), WORK(*)
        INTEGER :: IPIV(*)

DESCRIPTION

Le sous-programme zhesv effectue la factorisation LU de A en utilisant des permutations et une factorisation de type bloc de Brody pour résoudre un système d'équations linéaires.

La matrice A est une matrice complexe hermitienne et définie positive, ou une matrice complexe hermitienne et indéfinie. La factorisation de A est de la forme A = U*D*UH ou A = L*D*LH, où U est une matrice triangulaire unitaire supérieure, L est une matrice triangulaire unitaire inférieure, et D est une matrice triangulaire réelle.

Le sous-programme zhesv utilise le sous-programme zhesvx pour effectuer la factorisation et la résolution du système.

Parameters

UPLO
           UPLO is CHARACTER*1
           On entry, UPLO specifies whether the upper or lower triangular
           part of the array A is to be used as follows:
              UPLO = 'U'   =>   Upper triangular part
              UPLO = 'L'   =>   Lower triangular part
N
           N is INTEGER
           The order of the matrix A. N >= 0.
NRHS
           NRHS is INTEGER
           The number of right hand sides, i.e., the number of columns of
           the matrix B. NRHS >= 0.
A
           A is COMPLEX*16 array, dimension (LDA, N)
           On entry, the complex hermitian matrix A.
           On exit, if INFO = 0, the block diagonal matrix D and the
           multipliers used to obtain the factor U or L from the
           factorization A = U*D*U**T or A = L*D*L**T as computed by
           ZSYTRF.
LDA
           LDA is INTEGER
           The leading dimension of the array A. LDA >= max(1,N).
IPIV
           IPIV is INTEGER array, dimension (N)
           Details of the interchanges and the block structure of D, as
           determined by ZSYTRF.  If IPIV(k) > 0, then rows and columns
           k and IPIV(k) were interchanged, and D(k,k) is a 1-by-1
           diagonal block.  If UPLO = 'U' and IPIV(k) = IPIV(k-1) < 0,
           then rows and columns k-1 and -IPIV(k) were interchanged and
           D(k-1:k,k-1:k) is a 2-by-2 diagonal block.  If UPLO = 'L' and
           IPIV(k) = IPIV(k+1) < 0, then rows and columns k+1 and
           -IPIV(k) were interchanged and D(k:k+1,k:k+1) is a 2-by-2
           diagonal block.
B
           B is COMPLEX*16 array, dimension (LDB,NRHS)
           On entry, the N-by-NRHS right hand side matrix B.
           On exit, if INFO = 0, the N-by-NRHS solution matrix X.
LDB
           LDB is INTEGER
           The leading dimension of the array B.  LDB >= max(1,N).
WORK
           WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
           On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
LWORK
           LWORK is INTEGER
           The length of WORK.  LWORK >= 1, and for best performance
           LWORK >= max(1,N*NB), where NB is the optimal blocksize for
           ZSYTRF.
           for LWORK < N, TRS will be done with Level BLAS 2
           for LWORK >= N, TRS will be done with Level BLAS 3
           If LWORK = -1, then a workspace query is assumed; the routine
           only calculates the optimal size of the WORK array, returns
           this value as the first entry of the WORK array, and no error
           message related to LWORK is issued by XERBLA.
INFO
           INFO is INTEGER
           = 0: successful exit
           < 0: if INFO = -i, the i-th argument had an illegal value
           > 0: if INFO = i, D(i,i) is exactly zero.  The factorization
                has been completed, but the block diagonal matrix D is
                exactly singular, so the solution could not be computed.
