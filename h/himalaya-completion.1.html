NOM

completion - Imprime le script de complétion pour le shell donné sur la sortie standard

SYNTAXE

completion [-h|--help] <SHELL>

DESCRIPTION

Imprime le script de complétion pour le shell donné sur la sortie standard.

Cette commande vous permet de générer un script de complétion pour un shell donné. Le script est imprimé sur la sortie standard. Si vous souhaitez l'écrire dans un fichier, utilisez simplement la redirection Unix.

OPTIONS

-h, --help
Imprime l'aide (voir un résumé avec '-h')
<SHELL>
Shell pour lequel le script de complétion doit être généré

[valeurs possibles : bash, elvish, fish, powershell, zsh]
