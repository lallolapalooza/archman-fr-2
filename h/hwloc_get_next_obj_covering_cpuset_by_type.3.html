Documentation des fonctions

hwloc_obj_t hwloc_get_child_covering_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t parent) [inline]

Obtenir l'enfant couvrant au moins le jeu de CPU set.

Retourne

l'enfant qui couvre entièrement l'ensemble.

NULL si aucun enfant ne correspond ou si set est vide.

Note

Cette fonction ne peut pas fonctionner si parent n'a pas de jeu de CPU (objets I/O ou Misc).

hwloc_obj_t hwloc_get_next_obj_covering_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth, hwloc_obj_t prev) [inline]

Itérer sur les objets de même profondeur couvrant au moins le jeu de CPU set. La prochaine invocation doit passer la valeur de retour précédente dans prev afin d'obtenir le prochain objet couvrant au moins une autre partie de set.

Retourne

le premier objet à la profondeur depth couvrant au moins une partie du jeu de CPU set si l'objet prev est NULL.

le suivant si prev n'est pas NULL.

NULL s'il n'y a pas d'objet suivant.

Note

Cette fonction ne peut pas fonctionner si les objets à la profondeur donnée n'ont pas de jeux de CPU (objets I/O ou Misc).

hwloc_obj_t hwloc_get_next_obj_covering_cpuset_by_type (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type, hwloc_obj_t prev) [inline]

Itérer sur les objets de même type couvrant au moins le jeu de CPU set. La prochaine invocation doit passer la valeur de retour précédente dans prev afin d'obtenir le prochain objet de type type couvrant au moins une autre partie de set.

Retourne

le premier objet de type type couvrant au moins une partie du jeu de CPU set si l'objet prev est NULL.

le suivant si prev n'est pas NULL.

NULL s'il n'y a pas d'objet suivant.

NULL s'il n'y a pas de profondeur pour le type donné.

NULL s'il y a plusieurs profondeurs pour le type donné, l'appelant doit se rabattre sur hwloc_get_next_obj_covering_cpuset_by_depth().

Note

Cette fonction ne peut pas fonctionner si les objets du type donné n'ont pas de jeux de CPU (objets I/O ou Misc).

hwloc_obj_t hwloc_get_obj_covering_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set) [inline]

Obtenir l'objet le plus bas couvrant au moins le jeu de CPU set.

Retourne

l'objet le plus bas couvrant entièrement l'ensemble.

NULL si aucun objet ne correspond ou si set est vide.
