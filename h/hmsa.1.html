NOM

hmsa - Créateur et convertisseur d'images disque Atari MSA / ST

SYNTAXE

hmsa image_disque [taille_disque]

DESCRIPTION

Hmsa est un petit programme pour créer des images disque Atari MSA (Magic Shadow Archiver) compressées et non compressées, ainsi que pour convertir des images disque entre ces deux formats.

Le code de sauvegarde des formats d'image MSA et ST est identique à celui de Hatari lui-même.

UTILISATION

Si vous ne donnez qu'un seul paramètre, le nom de fichier d'une image disque MSA ou ST existante, cette image sera convertie vers l'autre format d'image disque sous un nouveau nom de fichier approprié.

Si le fichier n'existe pas et que vous donnez également une taille de disque :

SS
Simple face (360 Ko)
DS
Double face (720 Ko)
HD
Haute densité (1,44 Mo)
ED
Densité étendue (2,88 Mo)

Un disque vide de la taille donnée sera créé.

Le format de l'image disque est reconnu en fonction de l'extension du nom de fichier (soit .msa, soit .st).

EXEMPLES

Créer une image disque ST normale double face vide :
hmsa vide.st DS

Convertir une image disque au format MSA en une image au format ST :
hmsa disque.msa

VOIR AUSSI

hatari(1), zip2st(1), atari-hd-image(1)
