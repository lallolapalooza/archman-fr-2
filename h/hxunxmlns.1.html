NOM

hxunxmlns - remplacer les noms "globaux" XML par des préfixes d'espace de noms

SYNTAXE

hxunxmlns [ -- ] [ fichier ]

DESCRIPTION

hxunxmlns est l'inverse de hxxmlns(1). Il convertit les noms d'éléments et d'attributs de la forme


<{URL1}foo {URL2}bar="...">

en


<foo xmlns="URL1" xmlns:x="URL2" x:bar="...">

L'espace de noms XML prédéfini est reconnu et remplacé par le préfixe "xml:".

DIAGNOSTICS

Les valeurs de sortie suivantes sont retournées :

0
Achèvement réussi.
> 0
Un ou plusieurs erreurs se sont produites lors de l'analyse du fichier.

VOIR AUSSI

hxxmlns(1)

BOGUES

La récupération d'erreurs pour le XML incorrect est primitive.
