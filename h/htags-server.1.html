HTAGS-SERVER(1) Manuel des commandes générales HTAGS-SERVER(1)

NOM

htags-server - un serveur Web/CGI privé pour htags

SYNTAXE

htags-server [-b adresse-ip][-u langue][--retry[=n]][port]

DESCRIPTION

Htags-server est un serveur Web/CGI privé pour le texte hyper-texte généré par htags(1).

Avant d'utiliser cette commande, vous devez exécuter htags(1). Vous pouvez ensuite exécuter htags-server au même endroit. Vous pouvez commencer la navigation à l'adresse 'http://localhost:8000/' par défaut. Pour arrêter le serveur, appuyez simplement sur 'CTRL-C'.

Python 2/3 ou Ruby équipé de WEBrick est requis. Par défaut, htags-server recherche d'abord python, si non trouvé, il recherche ruby.

OPTIONS

Les options suivantes sont disponibles :

-b, --bind adresse-ip
Spécifie l'adresse IP sur laquelle htags-server écoute. La valeur par défaut est 127.0.0.1.
-u, --use langue
Spécifie la langue à utiliser, qui peut être : « python » ou « ruby ».
--retry[=n]
Si le port est déjà utilisé, réessayez n fois en incrémentant le numéro de port. La valeur par défaut de n est 20.
port
Spécifie le port sur lequel htags-server écoute. Si vous souhaitez utiliser plusieurs sessions, vous devez utiliser un numéro unique pour chaque htags-server. La valeur par défaut est 8000.

EXEMPLES

$ gtags
$ htags --suggest2
$ htags-server
Python2 http/cgi server
Serving HTTP on 127.0.0.1 port 8000 ...
(autre terminal)
$ firefox http://localhost:8000/
$ htags-server
Error: port 8000 already in use.
$ htags-server --retry
Warning: port 8000 already in use (skipped)
Please access at http://127.0.0.1:8001
Python2 http/cgi server
Serving HTTP on 127.0.0.1 port 8001 ...

DIAGNOSTICS

Htags-server se termine avec une valeur autre que 0 en cas d'erreur, 0 sinon.
