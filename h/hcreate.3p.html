HCREATE(3P) Manuel du programmeur POSIX HCREATE(3P)

PROLOGUE

Cette page manuelle fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page manuelle Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

hcreate, hdestroy, hsearch — gérer une table de recherche par hachage

SYNOPSISSE

#include <search.h>
int hcreate(size_t nel);
void hdestroy(void);
ENTRY *hsearch(ENTRY item, ACTION action);

DESCRIPTION

Les fonctions hcreate(), hdestroy(), et hsearch() gèrent les tables de recherche par hachage.

La fonction hcreate() alloue l'espace suffisant pour la table, et l'application doit s'assurer qu'elle est appelée avant que hsearch() soit utilisé. L'argument nel est une estimation du nombre maximal d'entrées que la table doit contenir. Ce nombre peut être augmenté par l'algorithme afin d'obtenir certaines conditions mathématiquement favorables.

La fonction hdestroy() libère la table de recherche, et peut être suivie d'un autre appel à hcreate(). Après l'appel à hdestroy(), les données ne peuvent plus être considérées comme accessibles.

La fonction hsearch() est une routine de recherche dans une table de hachage. Elle doit renvoyer un pointeur dans une table de hachage indiquant l'emplacement où une entrée peut être trouvée. L'argument item est une structure de type ENTRY (définie dans l'en-tête <search.h> ) contenant deux pointeurs : item.key pointe vers la clé de comparaison (un char *), et item.data (un void *) pointe vers toute autre donnée à associer à cette clé. La fonction de comparaison utilisée par hsearch() est strcmp(). L'argument action est un membre d'un type énuméré ACTION indiquant le traitement de l'entrée si elle ne peut pas être trouvée dans la table. ENTER indique que l'élément doit être inséré dans la table à un point approprié. FIND indique qu'aucune entrée ne doit être créée. Une résolution infructueuse est indiquée par le renvoi d'un pointeur nul.

Ces fonctions n'ont pas besoin d'être sûres dans un environnement multithread.

VALEUR RENVOYÉE

La fonction hcreate() doit renvoyer 0 si elle ne peut pas allouer l'espace suffisant pour la table ; sinon, elle doit renvoyer une valeur non nulle.

La fonction hdestroy() ne doit pas renvoyer de valeur.

La fonction hsearch() doit renvoyer un pointeur nul si soit l'action est FIND et l'élément n'a pas pu être trouvé, soit l'action est ENTER et la table est pleine.

ERREURS

Les fonctions hcreate() et hsearch() peuvent échouer si :

ENOMEM
Espace de stockage insuffisant disponible.

EXEMPLES

L'exemple suivant lit des chaînes suivies de deux nombres et les stocke dans une table de hachage, en écartant les doublons. Il lit ensuite des chaînes et trouve l'entrée correspondante dans la table de hachage et l'affiche.

#include <stdio.h>
#include <search.h>
#include <string.h>
struct info {        /* Ceci est l'info stockée dans la table */
    int age, room;   /* autre que la clé. */
};
#define NUM_EMPL    5000    /* # d'éléments dans la table de recherche. */
int main(void)
{
    char string_space[NUM_EMPL*20];   /* Espace pour stocker les chaînes. */
    struct info info_space[NUM_EMPL]; /* Espace pour stocker les infos employé. */
    char *str_ptr = string_space;     /* Espace suivant dans string_space. */
    struct info *info_ptr = info_space;
                                      /* Espace suivant dans info_space. */
    ENTRY item;
    ENTRY *found_item; /* Nom à chercher dans la table. */
    char name_to_find[30];
    int i = 0;
    /* Créer la table ; aucune vérification d'erreur n'est effectuée. */
    (void) hcreate(NUM_EMPL);
    while (scanf("%s%d%d", str_ptr, &info_ptr->age,
           &info_ptr->room) != EOF && i++ < NUM_EMPL) {
        /* Mettre l'information dans la structure, et la structure dans item. */
        item.key = str_ptr;
        item.data = info_ptr;
        str_ptr += strlen(str_ptr) + 1;
        info_ptr++;
        /* Mettre l'élément dans la table. */
        (void) hsearch(item, ENTER);
    }
    /* Accéder à la table. */
    item.key = name_to_find;
    while (scanf("%s", item.key) != EOF) {
        if ((found_item = hsearch(item, FIND)) != NULL) {
            /* Si l'élément est dans la table. */
            (void)printf("found %s, age = %d, room = %d\n",
                found_item->key,
                ((struct info *)found_item->data)->age,
                ((struct info *)found_item->data)->room);
        } else
            (void)printf("no such employee %s\n", name_to_find);
    }
    return 0;
}

UTILISATION DANS LES APPLICATIONS

Les fonctions hcreate() et hsearch() peuvent utiliser malloc() pour allouer de l'espace.
