int hwloc_bitmap_singlify_per_core (hwloc_topology_t topology, hwloc_bitmap_t cpuset, unsigned which)

Supprime les PU de multithreading simultané d'un ensemble de CPU. Pour chaque cœur dans la topologie, si cpuset contient certains PU de ce cœur, modifie cpuset pour ne conserver qu'un seul PU pour ce cœur.

which spécifie quel PU sera conservé. Les PU sont considérés dans l'ordre de l'index physique. Si 0, pour chaque cœur, la fonction conserve le premier PU qui était initialement défini dans cpuset.

Si which est supérieur au nombre de PU dans un cœur qui étaient initialement définis dans cpuset, aucun PU n'est conservé pour ce cœur.

Renvoie

0.

Note

Les PU qui ne sont pas sous un objet Core sont ignorés (par exemple si la topologie ne contient aucun objet Core). Aucun d'entre eux n'est supprimé de cpuset.

unsigned hwloc_get_closest_objs (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_t *restrict objs, unsigned max)

Effectue un parcours en profondeur de la topologie pour trouver et trier tous les objets qui sont à la même profondeur que src. Rapporte dans objs jusqu'à max des plus proches physiquement de src.

Renvoie

le nombre d'objets renvoyés dans objs.

0 si src est un objet d'E/S.

Note

Cette fonction nécessite que l'objet src ait un ensemble de CPU.

hwloc_obj_t hwloc_get_numanode_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Renvoie l'objet de type HWLOC_OBJ_NUMANODE avec os_index. Cette fonction est utile pour convertir un nodeset en objets de nœud NUMA qu'il contient. Lors de la récupération de la liaison actuelle (par exemple avec hwloc_get_membind() avec HWLOC_MEMBIND_BYNODESET), on peut itérer sur les bits du nodeset résultant avec hwloc_bitmap_foreach_begin(), et trouver les nœuds NUMA correspondants avec cette fonction.

Renvoie

l'objet de nœud NUMA, ou NULL si aucun ne correspond.

hwloc_obj_t hwloc_get_obj_below_array_by_type (hwloc_topology_t topology, int nr, hwloc_obj_type_t * typev, unsigned * idxv) [inline]

Trouve un objet sous une chaîne d'objets spécifiée par des types et des index. C'est une version généralisée de hwloc_get_obj_below_by_type().

Les tableaux typev et idxv doivent contenir nr types et index.

Commence à partir de l'objet système supérieur et parcourt les tableaux typev et idxv. Pour chaque couple type et index logique dans les tableaux, cherche sous l'objet précédemment trouvé pour trouver le i-ème objet du type donné. Les index sont spécifiés au sein du parent, pas au sein de tout le système.

Par exemple, si nr vaut 3, typev contient NODE, PACKAGE et CORE, et idxv contient 0, 1 et 2, renvoie le troisième objet cœur sous le deuxième package sous le premier nœud NUMA.

Renvoie

un objet correspondant s'il y en a un, NULL sinon.

Note

Cette fonction nécessite que tous ces objets et l'objet racine aient un ensemble de CPU.

hwloc_obj_t hwloc_get_obj_below_by_type (hwloc_topology_t topology, hwloc_obj_type_t type1, unsigned idx1, hwloc_obj_type_t type2, unsigned idx2) [inline]

Trouve un objet sous un autre objet, tous deux spécifiés par des types et des index. Commence à partir de l'objet système supérieur et trouve l'objet de type type1 et d'index logique idx1. Puis cherche sous cet objet et trouve un autre objet de type type2 et d'index logique idx2. Les index sont spécifiés au sein du parent, pas au sein de tout le système.

Par exemple, si type1 vaut PACKAGE, idx1 vaut 2, type2 vaut CORE et idx2 vaut 3, renvoie le quatrième objet cœur sous le troisième package.

Renvoie

un objet correspondant s'il y en a un, NULL sinon.

Note

Cette fonction nécessite que ces objets aient un ensemble de CPU.

hwloc_obj_t hwloc_get_obj_with_same_locality (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_type_t type, const char * subtype, const char * nameprefix, unsigned long flags)

Renvoie un objet d'un type différent avec la même localité. Si l'objet source src est de type normal ou mémoire, cette fonction renvoie un objet de type type avec les mêmes ensembles de CPU et de nœuds, soit en dessous soit au-dessus dans la hiérarchie.

Si l'objet source src est un périphérique PCI ou un périphérique OS au sein d'un périphérique PCI, la fonction peut soit renvoyer ce périphérique PCI, soit un autre périphérique OS dans le même parent PCI. Cela peut par exemple être utile pour convertir entre des périphériques OS tels que 'nvml0' ou 'rsmi1' utilisés dans les structures de distance vers le périphérique PCI, ou le périphérique OS CUDA ou OpenCL qui correspond à la même carte physique.

Si ce n'est pas NULL, le paramètre subtype ne sélectionne que les objets dont l'attribut subtype existe et vaut subtype (sans tenir compte de la casse), par exemple 'OpenCL' ou 'CUDA'.

Si ce n'est pas NULL, le paramètre nameprefix ne sélectionne que les objets dont l'attribut name existe et commence par nameprefix (sans tenir compte de la casse), par exemple 'rsmi' pour correspondre à 'rsmi0'.

Si plusieurs objets correspondent, le premier est renvoyé.

Cette fonction ne parcourra pas la hiérarchie à travers les ponts car la localité PCI peut devenir différente. Cette fonction ne peut pas non plus convertir entre objets normaux/mémoire et objets d'E/S ou Misc.

flags doit être 0 pour l'instant.

Renvoie

Un objet avec une localité identique, correspondant à subtype et nameprefix s'il y en a un.

NULL si aucun objet correspondant n'a pu être trouvé, ou si l'objet source et le type cible sont incompatibles, par exemple lors d'une conversion entre objets CPU et objets d'E/S.

hwloc_obj_t hwloc_get_pu_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Renvoie l'objet de type HWLOC_OBJ_PU avec l'os_index. Cette fonction est utile pour convertir un jeu de CPU (CPU set) en objets PU qu'il contient. Lors de la récupération de la liaison actuelle (par exemple avec hwloc_get_cpubind()), on peut parcourir les bits du jeu de CPU résultant avec hwloc_bitmap_foreach_begin(), et trouver les PU correspondants avec cette fonction.

Renvoie

l'objet PU, ou NULL si aucun ne correspond.
