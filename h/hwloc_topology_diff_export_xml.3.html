Description détaillée

Les applications qui manipulent de nombreuses topologies similaires, par exemple une pour chaque nœud d'un cluster homogène, peuvent vouloir compresser les topologies afin de réduire l'empreinte mémoire.

Ce fichier offre un moyen de manipuler la différence entre les topologies et de l'exporter/importer depuis/vers XML. La compression peut donc être réalisée en stockant une topologie intégralement tandis que les autres ne sont décrites que par leurs différences avec la première. La topologie réelle peut être reconstruite lorsque nécessaire en appliquant la différence précalculée à la topologie de référence.

Cette interface cible les nœuds très similaires. Seules des différences très simples entre topologies sont réellement supportées, par exemple un changement dans la taille de la mémoire, le nom de l'objet, ou un attribut d'information. Des différences plus complexes telles que l'ajout ou la suppression d'objets ne peuvent pas être représentées dans les structures de différence et retournent donc des erreurs. Les différences entre ensembles d'objets ou ensembles autorisés à l'échelle de la topologie ne peuvent pas non plus être représentées.

Cela signifie qu'il n'est pas nécessaire d'appliquer la différence lorsqu'on examine l'organisation arborescente (combien de niveaux, combien d'objets par niveau, quel type d'objets, ensembles de CPU et de nœuds, etc.) et lorsqu'on se lie aux objets. Cependant, la différence doit être appliquée lorsqu'on examine les attributs des objets tels que le nom, la taille de la mémoire ou les attributs d'information.

Documentation des fonctions

int hwloc_topology_diff_apply (hwloc_topology_t topology, hwloc_topology_diff_t diff, unsigned long flags)

Applique une différence de topologie à une topologie existante. flags est un ensemble OR'é des hwloc_topology_diff_apply_flags_e.

La nouvelle topologie est modifiée sur place. hwloc_topology_dup() peut être utilisée pour la dupliquer avant la modification.

Si la différence ne peut pas être appliquée entièrement, tous les éléments précédemment appliqués sont désappliqués avant le retour.

Retourne

0 en cas de succès.

-N si l'application de la différence a échoué en essayant d'appliquer la N-ième partie de la différence. Par exemple, -1 est retourné si le tout premier élément de différence n'a pas pu être appliqué.

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t * diff)

Calcule la différence entre 2 topologies. La différence est stockée sous forme d'une liste d'entrées hwloc_topology_diff_t commençant à diff. Elle est calculée en effectuant simultanément une traversée en profondeur des deux arbres de topologie.

Si la différence entre 2 objets est trop complexe pour être représentée (par exemple si certains objets ont des types différents, ou des nombres d'enfants différents), une entrée de diff spéciale de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX est mise en file d'attente. Le calcul de la diff ne se poursuit pas en dessous de ces objets. Ainsi, chaque entrée de diff de ce type signifie que la différence entre deux sous-arbres n'a pas pu être calculée.

Renvoie

0 si la différence peut être correctement représentée.

0 avec diff pointant vers NULL s'il n'y a pas de différence entre les topologies.

1 si la différence est trop complexe (voir ci-dessus). Certaines entrées dans la liste seront de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 sur toute autre erreur.

Note

flags n'est actuellement pas utilisé. Il doit être 0.

La diff de sortie doit être libérée avec hwloc_topology_diff_destroy().

La diff de sortie ne peut être exportée en XML ou passée à hwloc_topology_diff_apply() que si 0 a été renvoyé, c'est-à-dire si aucune entrée de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX n'est listée.

La diff de sortie peut être modifiée en supprimant certaines entrées de la liste. Les entrées supprimées doivent être libérées en les passant à hwloc_topology_diff_destroy() (possiblement en tant qu'une autre liste).

int hwloc_topology_diff_destroy (hwloc_topology_diff_t diff)

Détruit une liste de différences de topologie.

Renvoie

0.

int hwloc_topology_diff_export_xml (hwloc_topology_diff_t diff, const char * refname, const char * xmlpath)

Exporte une liste de différences de topologie vers un fichier XML. Si NULL, refname définit une chaîne d'identification pour la topologie de référence qui a été utilisée comme base lors du calcul de cette différence. Cette identification est généralement le nom de l'autre fichier XML contenant la topologie de référence. Cet attribut est restitué lors de la lecture de la diff depuis XML.

Renvoie

0 en cas de succès, -1 en cas d'erreur.

int hwloc_topology_diff_export_xmlbuffer (hwloc_topology_diff_t diff, const char * refname, char ** xmlbuffer, int * buflen)

Exporte une liste de différences de topologie vers un tampon XML. Si NULL, refname définit une chaîne d'identification pour la topologie de référence qui a été utilisée comme base lors du calcul de cette différence. Cette identification est généralement le nom de l'autre fichier XML contenant la topologie de référence. Cet attribut est restitué lors de la lecture de la diff depuis XML.

Le tampon renvoyé se termine par un \0 inclus dans la longueur renvoyée.

Renvoie

0 en cas de succès, -1 en cas d'erreur.

Note

Le tampon XML doit ensuite être libéré avec hwloc_free_xmlbuffer().

int hwloc_topology_diff_load_xml (const char * xmlpath, hwloc_topology_diff_t * diff, char ** refname)

Charge une liste de différences de topologie depuis un fichier XML. Si NULL, refname sera rempli avec la chaîne d'identification de la topologie de référence pour le fichier de différence, si une telle identification a été spécifiée dans le fichier XML. Cette identification est généralement le nom de l'autre fichier XML qui contient la topologie de référence.

Renvoie

0 en cas de succès, -1 en cas d'erreur.

Note

le pointeur renvoyé dans refname devra ensuite être libéré par l'appelant.

int hwloc_topology_diff_load_xmlbuffer (const char * xmlbuffer, int buflen, hwloc_topology_diff_t * diff, char ** refname)

Charge une liste de différences de topologie depuis un tampon XML. Construit une liste de différences à partir du tampon mémoire XML donné dans xmlbuffer et de la longueur buflen (y compris un \0 final). Ce tampon a pu être rempli précédemment avec hwloc_topology_diff_export_xmlbuffer().

Si NULL, refname sera rempli avec la chaîne d'identification de la topologie de référence pour le fichier de différence, si une telle identification a été spécifiée dans le fichier XML. Cette identification est généralement le nom de l'autre fichier XML qui contient la topologie de référence.

Renvoie

0 en cas de succès, -1 en cas d'erreur.

Note

le pointeur renvoyé dans refname devra ensuite être libéré par l'appelant.
