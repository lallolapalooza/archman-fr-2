CHEGVD

Objectif :

!>
!> CHEGVD calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème aux valeurs propres généralisé Hermitien-défini complexe, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou  B*A*x=(lambda)*x. Ici, A et
!> B sont supposés Hermitiens et B est aussi défini positif.
!> Si des vecteurs propres sont désirés, il utilise un algorithme de diviser pour régner.
!>
!>

Paramètres

ITYPE 
!>          ITYPE est INTEGER
!>          Spécifie le type de problème à résoudre :
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Les triangles supérieurs de A et B sont stockés ;
!>          = 'L' : Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          En entrée, la matrice hermitienne A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de A contient
!>          la partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient la
!>          matrice Z des vecteurs propres. Les vecteurs propres sont normalisés
!>          comme suit :
!>          si ITYPE = 1 ou 2, Z**H*B*Z = I ;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors en sortie, le triangle supérieur (si UPLO='U')
!>          ou le triangle inférieur (si UPLO='L') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX, dimension (LDB, N)
!>          En entrée, la matrice hermitienne B. Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de B contient
!>          la partie triangulaire supérieure de la matrice B. Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de B contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**H*U ou B = L*L**H.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

W

!>          W est un tableau REAL, dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK.
!>          Si N <= 1,                LWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LWORK >= N + 1.
!>          Si JOBZ  = 'V' et N > 1, LWORK >= 2*N + N**2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (MAX(1,LRWORK))
!>          En sortie, si INFO = 0, RWORK(1) renvoie LRWORK optimal.
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.
!>          Si N <= 1,                LRWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LRWORK >= N.
!>          Si JOBZ  = 'V' et N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) renvoie LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : CPOTRF ou CHEEVD a retourné un code d'erreur :
!>             <= N : si INFO = i et JOBZ = 'N', alors l'algorithme
!>                    n'a pas convergé ; i éléments hors diagonale d'une
!>                    forme tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>                    si INFO = i et JOBZ = 'V', alors l'algorithme
!>                    n'a pas pu calculer une valeur propre tout en travaillant sur la
!>                    sous-matrice située dans les lignes et colonnes INFO/(N+1)
!>                    jusqu'à mod(INFO,N+1) ;
!>             > N :   si INFO = N + i, pour 1 <= i <= N, alors le mineur
!>                    principal avant de taille i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>

NAME


zhbgvd - Computes the eigenvalues and eigenvectors of a generalized
    Hermitian-definite banded eigenvalue problem (two-matrix).






SYNOPSIS


SUBROUTINE ZHBGVD(
   JOBZ, LAYOUT, UPLO, N, KA, KB, AB, LDAB, BB, LDBB,
   D, Z, LDZ, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK,
   INFO
   )

CHARACTER(LEN=1) :: JOBZ, LAYOUT, UPLO
INTEGER :: N, KA, KB, LDAB, LDBB, LDZ, LWORK, LRWORK, LIWORK, INFO
COMPLEX(8), DIMENSION( LDAB, * ) :: AB
COMPLEX(8), DIMENSION( LDBB, * ) :: BB
COMPLEX(8), DIMENSION( LDZ, * ) :: Z
REAL(8), DIMENSION( * ) :: D, RWORK
INTEGER, DIMENSION( * ) :: IWORK
COMPLEX(8), DIMENSION( * ) :: WORK







Detailed Description


zhbgvd computes the eigenvalues and eigenvectors of a generalized
    Hermitian-definite banded eigenvalue problem, such
    that A Z = lambda B Z, A**H Z = lambda B Z,
    or A B Z = lambda Z, or A B**H Z = lambda Z. Here A
    is a real symmetric banded matrix and B is a real symmetric banded
    matrix. A and B must be positive definite.


Input arguments:




JOBZ


JOBZ specifies the computation of:




    

  • 'N': only the eigenvalues are computed.
    • 

  • 'V': the eigenvalues and eigenvectors are computed.
    • 





LAYOUT


LAYOUT specifies the storage format of the matrices:




    

  • 'C': Column-major
    • 

  • 'R': Row-major
    • 





UPLO


UPLO specifies whether the upper or lower triangular part of A and B
        is stored:




    

  • 'U': Upper
    • 

  • 'L': Lower
    • 





N


The order of the matrices A and B. N >= 0.


KA


The number of super-diagonals of A. 0 <= KA < N.


KB


The number of super-diagonals of B. 0 <= KB < N.


AB


The upper or lower triangular part of the matrix A, stored in banded
          format. AB is a 2D array of size (LDAB, N).


LDAB


The leading dimension of the array AB.


BB


The upper or lower triangular part of the matrix B, stored in banded
          format. BB is a 2D array of size (LDBB, N).


LDBB


The leading dimension of the array BB.




Output arguments:




D


The eigenvalues in ascending order. If JOBZ = 'L', then the eigenvalues
          are computed for the problem A B Z = lambda Z.


Z


If JOBZ = 'V', then Z contains the normalized eigenvectors, such that
          the i-th column of Z contains the eigenvector of lambda_i. If
          JOBZ = 'N', then Z is not used.


LDZ


The leading dimension of the array Z.


WORK


Complex*16 array, dimension (LWORK).


LWORK


The dimension of the array WORK. LWORK >= 1.


RWORK


Real*8 array, dimension (LRWORK).


LRWORK


The dimension of the array RWORK. LRWORK >= max(N, 2*KA+1, 2*KB+1).


IWORK


Integer array, dimension (LIWORK).


LIWORK


The dimension of the array IWORK. LIWORK >= 5.


INFO




INFO = 0: successful exit.


INFO < 0: If INFO = -i, the i-th
    argument had an illegal value.


INFO > 0: If INFO = i > 0, then the
    algorithm failed to compute an eigenvalue while working on
    the submatrix lying in rows and columns INFO/(N+1)
    through mod(INFO,N+1);


> N: if INFO = N + i, for 1 <= i <= N, then the leading
    principal minor of order i of B is not positive.
    The factorization of B could not be completed and
    no eigenvalues or eigenvectors were computed.
