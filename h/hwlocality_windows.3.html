Description détaillée

Ces fonctions interrogent les groupes de processeurs Windows. Ces groupes divisent le système d'exploitation en ensembles virtuels d'UC jusqu'à 64 voisines. Les threads et les processus ne peuvent être liés qu'à l'intérieur d'un seul groupe. Bien que les groupes de processeurs Windows puissent être exposés dans la hiérarchie hwloc en tant que groupes hwloc, ils sont également souvent fusionnés dans des objets hwloc existants tels que des nœuds NUMA ou des Packages. Cette API fournit des informations explicites sur les groupes de processeurs Windows afin que les applications sachent si la liaison à un grand ensemble d'UC peut échouer parce qu'elle s'étend sur plusieurs groupes de processeurs Windows.

Documentation des fonctions

int hwloc_windows_get_nr_processor_groups (hwloc_topology_t topology, unsigned long flags)

Obtient le nombre de groupes de processeurs Windows. flags doit être 0 pour l'instant.

Retourne

au moins 1 en cas de succès.

-1 en cas d'erreur, par exemple si la topologie ne correspond pas au système actuel (par exemple, chargée à partir d'une autre machine via XML).

int hwloc_windows_get_processor_group_cpuset (hwloc_topology_t topology, unsigned pg_index, hwloc_cpuset_t cpuset, unsigned long flags)

Obtient l'ensemble de CPU d'un groupe de processeurs Windows. Obtient l'ensemble des UC inclus dans le groupe de processeurs spécifié par pg_index. pg_index doit être compris entre 0 et la valeur retournée par hwloc_windows_get_nr_processor_groups() moins 1.

flags doit être 0 pour l'instant.

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si pg_index est invalide, ou si la topologie ne correspond pas au système actuel (par exemple, chargée à partir d'une autre machine via XML).
