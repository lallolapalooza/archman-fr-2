NOM

hid-replay - Relecture d'entrée de périphérique HID via uhid

SYNTAXE

hid-replay [--verbose] [FICHIER]

OPTIONS

--verbose
Activer la sortie de débogage

DESCRIPTION

hid-replay crée un périphérique HID virtuel basé sur le fichier enregistré, généralement enregistré par hid-recorder(1). Ce périphérique se comporte comme s'il était physiquement connecté au système. Tous les événements du fichier enregistré sont rejoués en temps réel.

hid-replay est un outil de débogage de bas niveau. Il utilise le modèle de noyau uhid pour créer le périphérique et toutes les données sont traitées par le module noyau HID respectif du périphérique.

hid-replay doit pouvoir écrire dans /dev/uhid ; généralement, cela signifie qu'il doit être exécuté en tant que root.

FORMAT DE FICHIER

Les fichiers pris en charge par hid-replay ont la syntaxe suivante :

•
# les lignes de commentaires sont ignorées lors de l'analyse
•
D: l'indice du périphérique, utilisé uniquement lors de l'enregistrement de plusieurs périphériques
•
R: la longueur du descripteur de rapport en octets, suivie des octets du descripteur de rapport en hexadécimal
•
N: le nom du périphérique
•
P: chemin physique
•
I: bus vendor_id product_id
•
E: horodatage taille rapport en hexadécimal

ATTENTION

hid-replay est un injecteur d'événements de très bas niveau. Pour que le périphérique virtuel soit géré par le module noyau HID correct, hid-replay fait semblant que le périphérique est sur le bus d'origine (USB, I2C ou BT). Ainsi, si le module noyau utilisé doit écrire *en retour* vers le périphérique, le noyau peut rencontrer un problème (oops) si le module essaie de communiquer directement avec la couche physique.

Assurez-vous d'utiliser ce programme avec des modules HID conviviaux qui ne reposent que sur les rappels génériques de HID.

CODE DE SORTIE

hid-replay renvoie 1 en cas d'erreur.
