Exporte la topologie dans un fichier XML. Ce fichier peut être chargé plus tard via hwloc_topology_se

Par défaut, le format d'export le plus récent est utilisé, ce qui signifie que les versions plus anciennes de hwloc (p. ex. v1.x) ne pourront pas l'importer. void hwloc_topology_set_userdata_export_callback (hwloc_topology_t topology, void(*)(void *reserved, hwloc_topology_t topology, hwloc_obj_t obj)

export_cb)

Définit le callback spécifique à l'application pour l'exportation des userdata d'objets. Le pointeur userdata de l'objet n'est pas exporté vers XML par défaut car hwloc ne sait pas ce qu'il

contient.

Cette fonction permet aux applications de définir export_cb comme fonction callback qui convertit ce userdata opaque en une chaîne

exportable.

export_cb est invoqué lors de l'exportation XML pour chaque objet dont le pointeur userdata n'est pas NULL. Le callback doit utiliser hwloc_export_obj_userdata() ou hwloc_export_obj_userdata_base64() pour effectivement exporter quelque chose vers XML (éventuellement plusieurs fois par objet)

.

export_cb peut être défini à NULL si les userdata ne doivent pas être exportés vers

XML.

void hwloc_topology_set_userdata_import_callback (hwloc_topology_t topology, void(*)(hwloc_topology_t topology, hwloc_obj_t obj, const char *name, const void *buffer, size_t length)

import_cb)

Définit le callback spécifique à l'application pour l'importation des userdata. Lors de l'importation XML, les userdata sont ignorés par défaut car hwloc ne sait pas comment les stocker en

mémoire.

Cette fonction permet aux applications de définir import_cb comme fonction callback qui recevra les userdata stockés en XML et les stockera dans l'objet comme attendu par

l'application.

import_cb est appelé lors de hwloc_topology_load() autant de fois que hwloc_export_obj_userdata() a été appelé lors de l'exportation. La topologie n'est pas encore entièrement configurée. Les attributs des objets sont prêts à être consultés, mais les liens entre les objets ne le sont

pas.

import_cb peut être NULL si les userdata doivent être ignorés lors de

l'importation.
