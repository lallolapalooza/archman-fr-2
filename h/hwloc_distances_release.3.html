Documentation des types énumérés

enum hwloc_distances_kind_e

Genres de matrices de distance. L'attribut kind de la structure hwloc_distances_s est un ensemble de genres combinés par OU.

Chaque matrice de distance ne peut avoir qu'un seul genre parmi HWLOC_DISTANCES_KIND_FROM_* spécifiant d'où proviennent les informations de distance, et un genre parmi HWLOC_DISTANCES_KIND_MEANS_* spécifiant si les valeurs représentent des latences ou des bandes passantes.

Énumérateur

HWLOC_DISTANCES_KIND_FROM_OS
Ces distances ont été obtenues depuis le système d'exploitation ou le matériel.
HWLOC_DISTANCES_KIND_FROM_USER
Ces distances ont été fournies par l'utilisateur.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Les valeurs de distance sont similaires aux latences entre objets. Les valeurs sont plus petites pour les objets plus proches, donc minimales sur la diagonale de la matrice (distance entre un objet et lui-même). Il peut aussi s'agir du nombre de sauts réseau entre objets, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Les valeurs de distance sont similaires aux bandes passantes entre objets. Les valeurs sont plus élevées pour les objets plus proches, donc maximales sur la diagonale de la matrice (distance entre un objet et lui-même). Ces valeurs sont actuellement ignorées pour le groupement basé sur la distance.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Cette structure de distances couvre des objets de types différents. Cela peut s'appliquer à la structure 'NVLinkBandwidth' en présence d'un NVSwitch ou d'un port NVLink d'un processeur POWER.

enum hwloc_distances_transform_e

Transformations des structures de distances.

Énumérateur

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Supprimer les objets NULL de la structure de distances. Chaque objet qui a été remplacé par NULL dans le tableau objs est supprimé et le tableau values est mis à jour en conséquence.

Au moins 2 objets doivent rester, sinon hwloc_distances_transform() retournera -1 avec errno défini à EINVAL.

kind sera mis à jour avec ou sans HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES selon les objets restants.

HWLOC_DISTANCES_TRANSFORM_LINKS
Remplacer les valeurs de bande passante par un nombre de liens. Généralement, toutes les valeurs seront soit 0 (aucun lien), soit 1 (un lien). Cependant, certaines matrices pourraient obtenir des valeurs plus grandes si certaines paires de pairs sont connectées par différents nombres de liens.

Les valeurs sur la diagonale sont mises à 0.

Cette transformation ne s'applique qu'aux matrices de bande passante.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionner les commutateurs avec plusieurs ports en un seul objet. Ceci ne s'applique actuellement qu'aux NVSwitches où les GPUs semblent connectés à différents ports de commutateur. Les ports de commutateur doivent être des objets avec le sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Cette transformation remplacera tous les ports par seulement le premier, maintenant connecté à tous les GPUs. Les autres ports sont supprimés en appliquant HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL en interne.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Appliquer une fermeture transitive à la matrice pour connecter les objets à travers les commutateurs. Toutes les paires de GPUs seront signalées comme étant directement connectées au lieu que les GPUs ne soient connectés qu'aux commutateurs.

Les ports de commutateur doivent être des objets avec le sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupérer les matrices de distance. Récupérer les matrices de distance de la topologie dans le tableau distances.

flags est actuellement inutilisé, il doit être 0.

kind sert de filtre. S'il est 0, toutes les matrices de distance sont retournées. S'il contient des HWLOC_DISTANCES_KIND_FROM_*, seules les matrices de distance dont le genre correspond à l'un de ceux-ci sont retournées. S'il contient des HWLOC_DISTANCES_KIND_MEANS_*, seules les matrices de distance dont le genre correspond à l'un de ceux-ci sont retournées.

En entrée, nr pointe vers le nombre de matrices de distance qui peuvent être stockées dans distances. En sortie, nr pointe vers le nombre de matrices de distance qui ont été réellement trouvées, même si certaines d'entre elles n'ont pas pu être stockées dans distances.
