NOM

hub-gist - Créer et afficher des Gists GitHub

SYNTAXE

hub gist create [-oc] [--public] [FICHIERS...]
hub gist show ID [NOMFICHIER]

COMMANDES

create

Crée une nouvelle gist. Si aucun FICHIER n'est spécifié, le contenu est lu depuis l'entrée standard.

show

Affiche le contenu d'une gist. Si la gist contient plusieurs fichiers, l'opération échouera à moins que NOMFICHIER ne soit spécifié.

OPTIONS

--public

Rend la nouvelle gist publique (par défaut: false).

-o, --browse

Ouvre la nouvelle gist dans un navigateur Web.

-c, --copy

Copie l'URL de la nouvelle gist dans le presse-papiers au lieu de l'afficher.

EXEMPLES

$ echo hello | hub gist create --public
$ hub gist create file1.txt file2.txt
# afficher un fichier spécifique dans une gist :
$ hub gist show ID testfile1.txt
