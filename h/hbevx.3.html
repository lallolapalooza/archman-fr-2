CHBEVX calcule les valeurs propres et, en option, les vecteurs propres gauche et/ou droit pour les matrices

OTHER

But

: 
!>
!> CHBEVX calcule les valeurs propres sélectionnées et, en option, les vecteurs propres
!> d'une matrice bande hermitienne complexe A. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnées en spécifiant soit un intervalle de valeurs, soit un intervalle
!> d'indices pour les valeurs propres souhaitées.
!
>

Paramètre

s
JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' :  calcule uniquement les valeurs propres ;
!>          = 'V' :  calcule les valeurs propres et les vecteurs propres.
!
>

RANG

E 
!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées ;
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I' : les valeurs propres de la IL-ième à la IU-ième seront trouvées.
!
>

UPL

O 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

K

D 
!>          KD est INTEGER
!>          Le nombre de surdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!
>

A

B 
!>          AB est un tableau COMPLEX, dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande
!>          hermitienne A, stocké dans les premières KD+1 lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par les valeurs générées pendant la
!>          réduction en forme tridiagonale.
!
>

LDA

B 
!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!
>

Q 
!>          Q est un tableau COMPLEX, dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice unitaire N par N utilisée dans la
!>                          réduction en forme tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!
>

LD

Q 
!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.  Si JOBZ = 'V', alors
!>          LDQ >= max(1,N).
!
>

V

L 
!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

V

U 
!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

I

L 
!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

I

U 
!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

ABSTO

L 
!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergée
!>          lorsqu'il est déterminé qu'elle se situe dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la 1-norme de la matrice tridiagonale obtenue
!>          en réduisant AB en forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec la plus grande précision
!>          lorsque ABSTOL est défini à deux fois le seuil de débordement
!>          2*SLAMCH('S'), et non à zéro. Si cette routine retourne avec
!>          INFO>0, indiquant que certains vecteurs propres n'ont pas convergé,
!>          essayez de définir ABSTOL à 2*SLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!
>

M 
!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W est un tableau REAL, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées
!>          dans l'ordre croissant.
!
>

Z 
!>          Z est un tableau COMPLEX, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ième
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne parvient pas à converger, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Remarque : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!
>

LD

Z 
!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (N)
!
>

RWOR

K 
!>          RWORK est un tableau RÉEL, dimension (7*N)
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension (5*N)
!
>

IFAI

L 
!>          IFAIL est un tableau INTEGER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont nuls.  Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                 Leurs indices sont stockés dans le tableau IFAIL.
!
>

subroutine ssbevx (character jobz, character range, character uplo, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldq, * ) q, integer ldq, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSBEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour D'AUTRES matrices

Objectif:

!>
!> SSBEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice bande symétrique réelle A. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres souhaitées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I': les IL-èmes à IU-èmes valeurs propres seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau REEL, de dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          En sortie, AB est écrasé par les valeurs générées lors de
!>          la réduction à une forme tridiagonale. Si UPLO = 'U', la première
!>          super-diagonale et la diagonale de la matrice tridiagonale T
!>          sont retournées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont retournées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!>

Q

!>          Q est un tableau REEL, de dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice orthogonale N x N utilisée dans la
!>                         réduction à une forme tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q.  Si JOBZ = 'V', alors
!>          LDQ >= max(1,N).
!>

VL

!>          VL est REEL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REEL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REEL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>           lorsqu'il est déterminé qu'elle se trouve dans un intervalle [a,b]
!>          de largeur inférieure ou égale à

!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>

ZHBEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour D'AUTRES matrices

Objectif:

!>
!> ZHBEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice bande hermitienne complexe A. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres souhaitées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I': les IL-èmes à IU-èmes valeurs propres seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX*16, de dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          En sortie, AB est écrasé par les valeurs générées lors de

!>          réduction à la forme tridiagonale.
