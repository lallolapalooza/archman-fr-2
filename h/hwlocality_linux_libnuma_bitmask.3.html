Description détaillée

Cette interface aide à convertir les masques de bits libnuma de Linux en ensembles d'UC et d'ensembles de nœuds hwloc.

Note

Topology topology doit correspondre à la machine actuelle.

Le comportement de libnuma est indéfini si le noyau n'est pas conscient du NUMA. (lorsque CONFIG_NUMA n'est pas défini dans la configuration du noyau). Cette aide et libnuma peuvent donc ne pas être strictement compatibles dans ce cas, ce qui peut être détecté en vérifiant si numa_available() retourne -1.

Documentation des fonctions

int hwloc_cpuset_from_linux_libnuma_bitmask (hwloc_topology_t topology, hwloc_cpuset_t cpuset, const struct bitmask * bitmask) [inline]

Convertit le masque de bits libnuma bitmask en ensemble d'UC hwloc cpuset. Cette fonction peut être utilisée après avoir appelé de nombreuses fonctions numa_ qui utilisent une struct bitmask comme paramètre de sortie.

Retourne

0 en cas de succès.

-1 avec errno défini à ENOMEM si une réallocation interne a échoué.

struct bitmask * hwloc_cpuset_to_linux_libnuma_bitmask (hwloc_topology_t topology, hwloc_const_cpuset_t cpuset) [inline]

Convertit l'ensemble d'UC hwloc cpuset en masque de bits libnuma retourné. Le masque de bits retourné doit être libéré plus tard avec numa_bitmask_free.

Cette fonction peut être utilisée avant d'appeler de nombreuses fonctions numa_ qui utilisent une struct bitmask comme paramètre d'entrée.

Retourne

struct bitmask nouvellement alloué, ou NULL en cas d'erreur.
