hid2hci(1) Administration système Linux hid2hci(1)

Nom

hid2hci - Utilitaire de commutation Bluetooth HID vers HCI

Syntaxe

hid2hci [OPTIONS]

Description

hid2hci(1) est utilisé pour configurer et basculer les périphériques Bluetooth pris en charge en mode HCI et inversement.

Options

--mode=[mode] Définit le mode dans lequel le périphérique doit être placé. Les valeurs possibles
pour mode sont hid, hci.
--method=[méthode] Quelle méthode du fournisseur utiliser pour basculer le périphérique.
Les valeurs possibles pour méthode sont csr, csr2, logitech-hdi, dell.
--devpath
Spécifie le chemin du périphérique dans /sys
--help
Donne une liste des options possibles.
