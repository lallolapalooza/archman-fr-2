NOM

hugo-convert-toJSON - Convertir le front matter en JSON

SYNTAXE

hugo convert toJSON [flags] [args]

DESCRIPTION

toJSON convertit tout le front matter du répertoire de contenu pour utiliser JSON pour le front matter.

OPTIONS

-h, --help[=false] aide pour toJSON

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de modules correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne crée pas de fichier .hugo_build.lock

-o, --output="" chemin du système de fichiers où écrire les fichiers

--quiet[=false] construire en mode silencieux

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers pour lire les fichiers relativement

--themesDir="" chemin du système de fichiers du répertoire des thèmes

--unsafe[=false] active les opérations moins sûres, veuillez sauvegarder d'abord

VOIR AUSSI
