NOM

hurlfmt - formate les fichiers Hurl

SYNTAXE

hurlfmt [options] [FICHIER...]

DESCRIPTION

hurlfmt formate les fichiers Hurl et les convertit depuis/vers d'autres formats.

Sans FICHIER, lit depuis l'entrée standard.

Par défaut, hurlfmt affiche une version formatée et colorisée du fichier hurl d'entrée.


$ hurl hello.hurl
GET http://localhost:8000/hello


HTTP/1.0 200

hurlfmt peut être utilisé pour convertir vers d'autres formats.


$ hurl hello.hurl --output json | jq
{
"entries": [
{
"request": {
"method": "GET",
"url": "http://localhost:8000/hello"
},
"response": {
"version": "HTTP/1.0",
"status": 200
}
}
]
}

hurlfmt peut également être utilisé pour convertir une commande curl en Hurl


$ echo "curl http://localhost:8000/custom-headers -H 'Fruit:Raspberry'" | hurlfmt --in curl
GET http://localhost:8000/custom-headers
Fruit: Raspberry

OPTIONS

--check

Exécute en mode vérification. Quitte avec 0 si l'entrée est correctement formatée, 1 sinon.

Ceci ne peut pas être utilisé avec --output.

Cette option n'est pas encore stable.

--color

Colorise la sortie.

Ceci ne peut pas être utilisé avec --in-place.

--in <FORMAT>

Spécifie le format d'entrée : hurl ou curl.

--in-place

Modifie le fichier en place.

Ceci ne peut être utilisé qu'avec une sortie texte.

--no-color

Ne pas coloriser la sortie.

--out <FORMAT>

Spécifie le format de sortie : hurl, json ou html.

-o, --output <FICHIER>

Écrit la sortie dans FICHIER au lieu de stdout.

--standalone

Produit un fichier html complet avec css au lieu d'un fragment html (par défaut).

Ceci ne peut être utilisé qu'avec une sortie html.

-h, --help

Aide d'utilisation.

-V, --version

Affiche les informations de version

CODES DE SORTIE

1

Échec de l'analyse des options de ligne de commande.

2

Erreur d'analyse du fichier d'entrée.
