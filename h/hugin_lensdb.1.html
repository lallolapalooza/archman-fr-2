NOM

hugin_lensdb - Outil pour la maintenance de la base de données d'objectifs

UTILISATION

hugin_lensdb [--recursive] --populate BASEPATH
Peuple la base de données avec les informations de tous les fichiers pto dans le BASEPATH donné. Avec l'option --recursive, tous les sous-dossiers/répertoires seront également recherchés.
hugin_lensdb --compress
Compresse la base de données en remplaçant les valeurs uniques par des valeurs moyennes.
hugin_lensdb --remove-lens=LENS
Supprime l'objectif donné de la base de données.
hugin_lensdb --remove-camera=MAKER|MODEL
Supprime l'appareil photo donné de la base de données.
hugin_lensdb --export-database=FILENAME
Export les données de la base de données vers un fichier externe.
hugin_lensdb --import-from-file=FILENAME
Importe les données depuis un fichier externe.
-h
Affiche l'aide.
