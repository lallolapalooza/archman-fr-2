Description détaillée

La manière habituelle d'ajouter des distances est :

hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}


Si err vaut 0 à la fin, l'ajout a réussi.

Documentation du Type Énumération

enum hwloc_distances_add_flag_e

Drapeaux pour l'ajout de nouvelles distances à une topologie.

Énumérateur

HWLOC_DISTANCES_ADD_FLAG_GROUP
Tente de regrouper les objets en se basant sur les nouvelles informations de distance fournies. Le regroupement n'est effectué que lorsque la structure de distances contient des latences, et lorsque tous les objets sont du même type.
HWLOC_DISTANCES_ADD_FLAG_GROUP_INACCURATE
Lors du regroupement, considère les valeurs de distance comme imprécises et assouplit les comparaisons pendant les algorithmes de regroupement. La précision réelle peut être modifiée via la variable d'environnement HWLOC_GROUPING_ACCURACY (voir Variables d'environnement).

Documentation des Fonctions

int hwloc_distances_add_commit (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned long flags)

Valide une nouvelle structure de distances. Cette fonction finalise la structure de distances et l'insère dans la topologie.

Paramètre handle a été précédemment retourné par hwloc_distances_add_create(). Puis les objets et les valeurs ont été spécifiés avec hwloc_distances_add_values().

flags configure le comportement de la fonction à l'aide d'un ensemble optionnel combiné par OR de hwloc_distances_add_flag_e. Il peut être utilisé pour demander le regroupement d'objets existants en fonction des distances.

En cas d'erreur, la structure de distances temporaire et son contenu sont détruits.

Renvoie

0 en cas de succès.

-1 en cas d'erreur.

hwloc_distances_add_handle_t hwloc_distances_add_create (hwloc_topology_t topology, const char * name, unsigned long kind, unsigned long flags)

Crée une nouvelle structure de distances vide. Crée une structure de distances vide à remplir avec hwloc_distances_add_values() puis validée avec hwloc_distances_add_commit().

Paramètre name est facultatif, il peut être NULL. Sinon, il sera copié en interne et pourra plus tard être libéré par l'appelant.

kind spécifie le type de distance sous forme d'un ensemble combiné par OR de hwloc_distances_kind_e. Un seul type de signification et un seul type de provenance peuvent être donnés si approprié (par ex. HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH et HWLOC_DISTANCES_KIND_FROM_USER). Le type HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES sera automatiquement défini en fonction des objets ayant des types différents dans hwloc_distances_add_values().

flags doit être 0 pour l'instant.

Renvoie

Un hwloc_distances_add_handle_t qui doit ensuite être passé à hwloc_distances_add_values() puis hwloc_distances_add_commit().

NULL en cas d'erreur.

int hwloc_distances_add_values (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned nbobjs, hwloc_obj_t * objs, hwloc_uint64_t * values, unsigned long flags)

Spécifie les objets et les valeurs dans une nouvelle structure de distances vide. Spécifie les objets et les valeurs pour une nouvelle structure de distances qui a été retournée sous forme de descripteur par hwloc_distances_add_create(). La structure doit ensuite être validée avec hwloc_distances_add_commit().

Le nombre d'objets est nbobjs et le tableau d'objets est objs. Les valeurs de distance sont stockées sous forme d'un tableau unidimensionnel dans values. La distance de l'objet i à l'objet j est à la position i*nbobjs+j.

nbobjs doit être au moins 2.

Les tableaux objs et values seront copiés en interne, ils pourront plus tard être libérés par l'appelant.

En cas d'erreur, la structure de distances temporaire et son contenu sont détruits.

flags doit être 0 pour l'instant.

Renvoie

0 en cas de succès.

-1 en cas d'erreur.
