hwlocality_gl - Interopérabilité avec les affichages OpenGL

Description détaillée

Cette interface offre des moyens de récupérer des informations de topologie sur les affichages OpenGL.

Seules les informations de localité d'affichage NVIDIA sont actuellement disponibles, en utilisant l'extension NV-CONTROL X11 et la bibliothèque NVCtrl.

Documentation des fonctions

int hwloc_gl_get_display_by_osdev (hwloc_topology_t topology, hwloc_obj_t osdev, unsigned * port, unsigned * device) [inline]

Obtenir le port et le périphérique d'affichage OpenGL correspondant à l'objet OS hwloc donné. Récupère le port d'affichage OpenGL (serveur) dans port et le périphérique (écran) dans screen qui correspondent à l'objet périphérique OS hwloc donné.

Retourne

0 en cas de succès.

-1 si aucun n'a pu être trouvé.

La topologie topology n'a pas nécessairement à correspondre à la machine actuelle. Par exemple, la topologie peut être une importation XML d'un hôte distant. La détection des périphériques d'E/S et le composant GL doivent être activés dans la topologie.

hwloc_obj_t hwloc_gl_get_display_osdev_by_name (hwloc_topology_t topology, const char * name) [inline]

Obtenir l'objet périphérique OS hwloc correspondant à l'affichage OpenGL donné par name.

Retourne

L'objet périphérique OS hwloc décrivant l'affichage OpenGL dont le nom est name, construit comme ':port.device' tel que ':0.0'.

NULL si aucun n'a pu être trouvé.

La topologie topology n'a pas nécessairement à correspondre à la machine actuelle. Par exemple, la topologie peut être une importation XML d'un hôte distant. La détection des périphériques d'E/S et le composant GL doivent être activés dans la topologie.

Note

L'objet périphérique PCI correspondant peut être obtenu en examinant l'objet parent du périphérique OS (sauf si les périphériques PCI sont filtrés).

hwloc_obj_t hwloc_gl_get_display_osdev_by_port_device (hwloc_topology_t topology, unsigned port, unsigned device) [inline]

Obtenir l'objet périphérique OS hwloc correspondant à l'affichage OpenGL donné par les indices de port et de périphérique.

Retourne

L'objet périphérique OS hwloc décrivant l'affichage OpenGL dont le port (serveur) est port et le périphérique (écran) est device.

NULL si aucun n'a pu être trouvé.

La topologie topology n'a pas nécessairement à correspondre à la machine actuelle. Par exemple, la topologie peut être une importation XML d'un hôte distant. La détection des périphériques d'E/S et le composant GL doivent être activés dans la topologie.

Note

L'objet périphérique PCI correspondant peut être obtenu en examinant l'objet parent du périphérique OS (sauf si les périphériques PCI sont filtrés).
