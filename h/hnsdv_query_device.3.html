NOM

hnsdv_query_device - Interroger les attributs spécifiques au périphérique hns

SYNTAXE

#include <infiniband/hnsdv.h>
int hnsdv_query_device(struct ibv_context *context,
                       struct hnsdv_context *attrs_out);

DESCRIPTION

hnsdv_query_device() interroge les attributs spécifiques au périphérique hns.

ARGUMENTS

Veuillez vous référer à la page de manuel ibv_query_device(3) pour context.

attrs_out

struct hnsdv_context {
        uint64_t comp_mask;
        uint64_t flags;
        uint8_t congest_type;
        uint8_t reserved[7];
};
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides :

HNSDV_CONTEXT_MASK_CONGEST_TYPE : L'algorithme de contrôle de congestion est pris en charge.

congest_type
Masque de bits des algorithmes de contrôle de congestion pris en charge.

HNSDV_QP_CREATE_ENABLE_DCQCN : Notification de congestion quantifiée pour centre de données HNSDV_QP_CREATE_ENABLE_LDCP : Protocole de contrôle à faible latence HNSDV_QP_CREATE_ENABLE_HC3 : Contrôle de congestion convergé Huawei HNSDV_QP_CREATE_ENABLE_DIP : Notification de congestion quantifiée basée sur l'IP de destination

VALEUR DE RETOUR

hnsdv_query_device() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI

ibv_query_device(3)

NOTES

•
flags est un champ de sortie et n'a actuellement aucune valeur.
