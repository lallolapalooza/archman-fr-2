Description Détaillée

Chaque type d'objet est soit Normal (c'est-à-dire que hwloc_obj_type_is_normal() renvoie 1), soit Mémoire (c'est-à-dire que hwloc_obj_type_is_memory() renvoie 1) soit E/S (c'est-à-dire que hwloc_obj_type_is_io() renvoie 1) soit Divers (c'est-à-dire égal à HWLOC_OBJ_MISC). Il ne peut pas être de plus d'un de ces genres.

Voir aussi Genre d'objet dans Termes et définitions.

Documentation des Fonctions

int hwloc_obj_type_is_cache (hwloc_obj_type_t type)

Vérifie si un type d'objet est un cache CPU (Données, Unifié ou Instructions). Les caches côté mémoire ne sont pas des caches CPU.

Retourne

1 si un objet de type type est un cache, 0 sinon.

int hwloc_obj_type_is_dcache (hwloc_obj_type_t type)

Vérifie si un type d'objet est un cache CPU Données ou Unifié. Les caches côté mémoire ne sont pas des caches CPU.

Retourne

1 si un objet de type type est un cache CPU Données ou Unifié, 0 sinon.

int hwloc_obj_type_is_icache (hwloc_obj_type_t type)

Vérifie si un type d'objet est un cache CPU d'Instructions,. Les caches côté mémoire ne sont pas des caches CPU.

Retourne

1 si un objet de type type est un cache CPU d'Instructions, 0 sinon.

int hwloc_obj_type_is_io (hwloc_obj_type_t type)

Vérifie si un type d'objet est E/S. Les objets E/S sont des objets attachés à leurs parents dans la liste des enfants E/S. Ceci inclut actuellement les Ponts, les périphériques PCI et OS.

Retourne

1 si un objet de type type est un objet E/S, 0 sinon.

int hwloc_obj_type_is_memory (hwloc_obj_type_t type)

Vérifie si un type d'objet est Mémoire. Les objets Mémoire sont des objets attachés à leurs parents dans la liste des enfants Mémoire. Ceci inclut actuellement les nœuds NUMA et les caches côté mémoire.

Retourne

1 si un objet de type type est un objet Mémoire, 0 sinon.

int hwloc_obj_type_is_normal (hwloc_obj_type_t type)

Vérifie si un type d'objet est Normal. Les objets Normaux sont des objets de la hiérarchie principale du CPU (Machine, Package, Cœur, PU, caches CPU, etc.), mais ils ne sont pas des nœuds NUMA, des périphériques E/S ou des objets Divers.

Ils sont attachés au parent en tant qu'enfants Normaux, pas en tant qu'enfants Mémoire, E/S ou Divers.

Retourne

1 si un objet de type type est un objet Normal, 0 sinon.
