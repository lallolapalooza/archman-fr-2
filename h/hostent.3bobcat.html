DESCRIPTIO

N

Les objets @CLASS sont des encapsulations autour de struct hostent qui peuvent être utilisées par d'autres objets. Une struct hostent est définie comme suit

: 
    struct hostent
    {
        char    *h_name;        // nom officiel de l'hôte
        char    **h_aliases;    // liste des alias
        int     h_addrtype;     // type d'adresse de l'hôte (toujours AF_INET)
        int     h_length;       // longueur de l'adresse
        char    **h_addr_list;  // liste des adresses
}

Les champs d'adresse sont des valeurs binaires des adresses, chaque adresse nécessitant h_length octets, la dernière adresse étant égale à 0. Les objets @CLASS offrent une interface de type C+

+ à cette
struct.

FONCTIONS

MEMBRES
o
size_t addressLength() const :
Ce membre renvoie la longueur des adresses binaires en
octets.
o
size_t addressType() const :
Ce membre renvoie le type de l'adresse. Actuellement, c'est toujours AF_INE
T.
o
char const *alias(size_t index) const :
Ce membre renvoie l'alias `index’ de l'hôte. Le premier alias a l'index 0. Si l'alias `index’ n'existe pas, 0 est
renvoyé.
o
char const * const *beginAlias() const :
Ce membre renvoie un itérateur vers le premier alias. Le nom d'hôte lui-même n'est pas inclus dans la liste des
alias.
o
char const *binaryAddress(size_t index) const :
Ce membre renvoie l'adresse binaire `index’ de l'hôte. La première adresse a l'index 0. Si l'adresse `index’ n'existe pas, 0 est renvoyé. Le pointeur vers l'adresse binaire pointe vers une série de addressLength() octets. Notez que l'adresse renvoyée est dans l' ordre des octets réseau. Elle peut être convertie en ordre des octets de l'hôte à l'aide des fonctions décrites dans byteorder
(3).
o
std::string dottedDecimalAddress(size_t index) const :
Ce membre renvoie l'adresse `index’ sous forme d'adresse décimale pointée dans une chaîne. La première adresse a l'index 0. Si l'adresse `index’ n'existe pas, une chaîne vide est
renvoyée.
o
char const * const *endAlias() const :
Ce membre renvoie un itérateur pointant au-delà du dernier
alias.
o
char const *hostname() const :
Ce membre renvoie le nom standard (premier) de
l'hôte.
o
size_t nAddresses() const :
Ce membre renvoie le nombre d'adresses disponibles. Lors de la demande d'une adresse particulière, l'index demandé doit être inférieur à la valeur renvoyée par ce
membre.
o
size_t nAliases() const :
Ce membre renvoie le nombre d'alias disponibles. Lors de la demande d'un alias particulier, l'index demandé doit être inférieur à la valeur renvoyée par ce
membre.
o
void swap(Hostent &other) :
Le contenu de l'objet Hostent actuel est échangé
avec le
contenu de l
'autre objet.

EXEMPL

E 
    #include <iostream>
    #include <algorithm>
    #include <iterator>
    #include <bobcat/hostent>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    {
        Hostent he(gethostbyname("localhost"));
        cout << "The local hostname = " << he.hostname() << endl;
        cout << "All aliases: " << endl;
        copy(he.beginAlias(), he.endAlias(),
                    ostream_iterator<char const *>(cout, "\n"));
        cout << "Addresses:\n";
        for (size_t idx = 0; idx < he.nAddresses(); idx++)
            cout << he.dottedDecimalAddress(idx) << endl;
}
