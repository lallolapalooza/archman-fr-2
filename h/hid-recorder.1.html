NOM

hid-recorder - Enregistreur d'entrées de périphérique HID

SYNTAXE

hid-recorder [--output=fichier_sortie] [/dev/hidrawX] [[/dev/hidrawX] [...]]

OPTIONS

--output=chemin/vers/fichier
Écrire la sortie dans le fichier spécifié. S'il est omis, hid-recorder affiche sur la sortie standard.

DESCRIPTION

hid-recorder capture les descripteurs de rapports et les rapports HID (événements) via le module noyau hidraw et les affiche dans un format standardisé (voir ci-dessous) pour le débogage et la relecture des périphériques HID.

Lorsqu'il est appelé sans arguments, hid-recorder affiche une liste des périphériques disponibles.

hid-recorder doit pouvoir lire depuis le périphérique hidraw ; cela signifie généralement qu'il doit être exécuté en tant que root.

FORMAT DU FICHIER

La sortie de hid-recorder a la syntaxe suivante :

•
# les lignes de commentaire sont ignorées lors de l'analyse
•
D: l'indice du périphérique, utilisé uniquement lors de l'enregistrement de plusieurs périphériques
•
R: la longueur du descripteur de rapport en octets, suivie des octets du descripteur de rapport en hexadécimal
•
N: le nom du périphérique
•
P: chemin physique
•
I: id_fournisseur id_produit du bus
•
E: horodatage taille rapport en hexadécimal

CODE DE SORTIE

hid-recorder retourne 1 en cas d'erreur.
