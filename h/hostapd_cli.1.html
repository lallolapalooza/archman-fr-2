HOSTAPD_CLI(1) interface en ligne de commande de hostapd HOSTAPD_CLI(1)

NOM

hostapd_cli - interface en ligne de commande de hostapd

SYNTAXE

hostapd_cli [-p<chemin>] [-i<nomif>] [-a<chemin>] [-hvB] [commande..]

DESCRIPTION

Cette page de manuel documente brièvement l'utilitaire hostapd_cli.

hostapd_cli est une interface en ligne de commande pour le démon hostapd.

hostapd est un démon en espace utilisateur pour les serveurs d'authentification et de point d'accès. Il implémente la gestion du point d'accès IEEE 802.11, les authentificateurs IEEE 802.1X/WPA/WPA2/EAP et le serveur d'authentification RADIUS. Pour plus d'informations sur hostapd, consultez la page de manuel hostapd(8).

OPTIONS

Un résumé des options est inclus ci-dessous. Pour une description complète, exécutez hostapd_cli en ligne de commande.

-p<chemin>
Chemin pour trouver les sockets de contrôle.

Par défaut : /var/run/hostapd

-i<nomif>
Interface sur laquelle écouter.

Par défaut : première interface trouvée dans le chemin du socket.

-a<chemin>
Exécuter en mode démon en exécutant le fichier d'action basé sur les événements de hostapd.
-B
Exécuter un démon en arrière-plan.
-h
Afficher l'utilisation.
-v
Afficher la version de hostapd_cli.

COMMANDES

Un résumé des commandes est inclus ci-dessous. Pour une description complète, exécutez hostapd_cli en ligne de commande.

mib
Obtenir les variables MIB (dot1x, dot11, radius).
sta <addr>
Obtenir les variables MIB pour une station.
all_sta
Obtenir les variables MIB pour toutes les stations.
help
Obtenir de l'aide sur l'utilisation.
interface [nomif]
Afficher les interfaces/sélectionner une interface.
level <niveau de débogage>
Changer le niveau de débogage.
license
Afficher la licence complète de hostapd_cli.
quit
Quitter hostapd_cli.
