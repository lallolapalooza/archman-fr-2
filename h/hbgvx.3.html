!>
!> CHBGVX calcule toutes les valeurs propres, et éventuellement les vecteurs propres
!> d'un problème aux valeurs propres bandé généralisé hermitien-défini de
!> la forme A*x=(lambda)*B*x. Ici, A et B sont supposés hermitiens
!> et bandés, et B est également défini positif. Les valeurs propres et

!> soit un intervalle de valeurs ou un intervalle d'indices pour les valeurs propres souhaitées.

!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I' : les valeurs propres de la IL-ième à la IU-ième seront trouvées.

!>          UPLO est CHARACTER*1

!>          ou le nombre de sous-diagonales si UPLO = 'L'. KA >= 0.

Objectif:

!>
!> DSBGVX calcule les valeurs propres sélectionnées, et optionnellement, les vecteurs propres
!> d'un problème aux valeurs propres généralisé symétrique-défini et bande réel,
!> de la forme A*x=(lambda)*B*x. Ici, A et B sont supposées symétriques
!> et bande, et B est également définie positive. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit toutes les valeurs propres,
!> une plage de valeurs ou une plage d'indices pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est de type CHARACTER*1
!>          = 'N':  Calcul des valeurs propres uniquement ;
!>          = 'V':  Calcul des valeurs propres et des vecteurs propres.
!>

RANGE

!>          RANGE est de type CHARACTER*1
!>          = 'A': toutes les valeurs propres seront calculées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront calculées.
!>          = 'I': les valeurs propres de rang IL à IU seront calculées.
!>

UPLO

!>          UPLO est de type CHARACTER*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est un entier (INTEGER)
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB est un entier (INTEGER)
!>          Le nombre de super-diagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KB >= 0.
!>

AB

!>          AB est un tableau de double précision (DOUBLE PRECISION), de dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          A, stocké dans les ka+1 premières lignes du tableau. La
!>          colonne j de A est stockée dans la colonne j du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+ka).
!>
!>          En sortie, le contenu de AB est détruit.
!>

!>          LDAB est un entier (INTEGER)
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

!>          BB est un tableau de double précision (DOUBLE PRECISION), de dimension (LDBB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          B, stocké dans les kb+1 premières lignes du tableau. La
!>          colonne j de B est stockée dans la colonne j du tableau BB
!>          comme suit :
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) pour max(1,j-kb) <= i <= j ;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) pour j <= i <= min(n,j+kb).

LDBB

!>          LDBB est un entier (INTEGER)

Q

!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
