Description

détaillée

Les applications qui manipulent de nombreuses topologies similaires, par exemple une pour chaque nœud d'un cluster homogène, peuvent vouloir compresser les topologies afin de réduire l'empreinte

mémoire.

Ce fichier propose un moyen de manipuler la différence entre les topologies et de l'exporter/la importer depuis/vers XML. La compression peut donc être réalisée en stockant une topologie entièrement tandis que les autres ne sont décrites que par leurs différences avec la première. La topologie réelle peut être reconstruite lorsque c'est nécessaire en appliquant la différence précalculée à la topologie de

référence.

Cette interface cible des nœuds très similaires. Seules des différences très simples entre les topologies sont réellement prises en charge, par exemple un changement de taille de mémoire, de nom d'objet ou de certains attributs d'information. Des différences plus complexes telles que l'ajout ou la suppression d'objets ne peuvent pas être représentées dans les structures de différence et renvoient donc des erreurs. Les différences entre ensembles d'objets ou ensembles autorisés au niveau de la topologie ne peuvent pas non plus être

représentées.

Cela signifie qu'il n'est pas nécessaire d'appliquer la différence lors de l'examen de l'organisation arborescente (combien de niveaux, co

mbien d'objets par niveau, quels types d'objets, ensembles de CPU et de nœuds, etc.) et lors de l'liaison aux objets. Cependant, la diffé
rence doit être appliquée lors de l'examen des attributs d'objets tels que le nom, la taille de la mémoire ou les attributs d'information.

int hwloc_topology_diff_apply (hwloc_topology_t topology, hwloc_topology_diff_t diff, unsigned long

flags)

Applique une différence de topologie à une topologie existante. flags est un ensemble de drapeaux combinés par l'opérateur OU logique de hwloc_topology_diff_apply_flags_e

.

La nouvelle topologie est modifiée sur place. hwloc_topology_dup() peut être utilisé pour la dupliquer avant de la

corriger.

Si la différence ne peut pas être appliquée entièrement, tous les éléments précédemment appliqués sont annulés avant de

renvoyer.

-N si l'application de la différence a échoué en ess

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t * diff)

Calcule la différence entre 2 topologies. La différence est stockée sous forme de liste d'entrées hwloc_topology_diff_t à partir de diff. Elle est calculée en effectuant un parcours en profondeur des deux arbres de topologies simultanément.

Si la différence entre 2 objets est trop complexe pour être représentée (par exemple si certains objets ont des types différents, ou un nombre différent d'enfants), une entrée de différence spéciale de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX est mise en file d'attente. Le calcul de la différence ne continue pas sous ces objets. Ainsi, chaque entrée de différence de ce type signifie que la différence entre deux sous-arbres n'a pas pu être calculée.

Retourne

0 si la différence peut être représentée correctement.

0 avec diff pointant vers NULL s'il n'y a pas de différence entre les topologies.

1 si la différence est trop complexe (voir ci-dessus). Certaines entrées de la liste seront de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 en cas d'autre erreur.

Note

flags n'est actuellement pas utilisé. Il doit être 0.

Le diff de sortie doit être libéré avec hwloc_topology_diff_destroy().

Le diff de sortie ne peut être exporté en XML ou passé à hwloc_topology_diff_apply() que si 0 a été retourné, c'est-à-dire si aucune entrée de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX n'est listée.

Le diff de sortie peut être modifié en supprimant certaines entrées de la liste. Les entrées supprimées doivent être libérées en les passant à hwloc_topology_diff_destroy() (possible sous forme d'une autre liste).

int hwloc_topology_diff_export_xml (hwloc_topology_diff_t diff, const char * refname, const char * xmlpath)

Exporte une liste de différences de topologies vers un fichier XML. Si pas NULL, refname définit une chaîne d'identifiant pour la topologie de référence qui a été utilisée comme base lors du calcul de cette différence. Cet identifiant est généralement le nom de l'autre fichier XML contenant la topologie de référence. Cet attribut est restitué lors de la lecture du diff à partir du XML.

Retourne

0 en cas de succès, -1 en cas d'erreur.

int hwloc_topology_diff_export_xmlbuffer (hwloc_topology_diff_t diff, const char * refname, char ** xmlbuffer, int * buflen)

Exporte une liste de différences de topologies vers un tampon XML. Si pas NULL, refname définit une chaîne d'identifiant pour la topologie de référence qui a été utilisée comme base lors du calcul de cette différence. Cet identifiant est généralement le nom de l'autre fichier XML contenant la topologie de référence. Cet attribut est restitué lors de la lecture du diff à partir du XML.

Le tampon retourné se termine par un caractère \0 qui est inclus dans la longueur retournée.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

Le tampon XML doit être libéré ultérieurement avec hwloc_free_xmlbuffer().

int hwloc_topology_diff_load_xml (const char * xmlpath, hwloc_topology_diff_t * diff, char ** refname)

Charge une liste de différences de topologies à partir d'un fichier XML. Si pas NULL, refname sera rempli avec la chaîne d'identifiant de la topologie de référence pour le fichier de différence, si elle a été spécifiée dans le fichier XML. Cet identifiant est généralement le nom de l'autre fichier XML contenant la topologie de référence.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

le pointeur retourné dans refname doit être libéré ultérieurement par l'appelant.

int hwloc_topology_diff_load_xmlbuffer (const char * xmlbuffer, int buflen, hwloc_topology_diff_t * diff, char ** refname)

Charge une liste de différences de topologies à partir d'un tampon XML. Construit une liste de différences à partir du tampon mémoire XML fourni dans xmlbuffer et de longueur buflen (y compris un \0 final). Ce tampon a pu être rempli précédemment avec hwloc_topology_diff_export_xmlbuffer().

Si pas NULL, refname sera rempli avec la chaîne d'identifiant de la topologie de référence pour le fichier de différence, si elle a été spécifiée dans le fichier XML. Cet identifiant est généralement le nom de l'autre fichier XML contenant la topologie de référence.

Retourne

0 en cas de succès, -1 en cas d'erreur.

le pointeur retourné dans refname doit être libéré ultérieurement par l'appelant.
