NAME

hpcdtoppm — convert Kodak Photo CD image to PPM

SYNOPSIS

hpcdtoppm [photo.cd -options ]

DESCRIPTION

This program converts a Photo CD image to the PPM image format. Photo CD images are encoded using a YCbCr color system, but this program converts them to RGB.

Photo CD images have a maximum resolution of 2048x3072 pixels. The format also contains lower resolution versions of the image. This program can extract any of these resolutions.

There is no way to specify which image on the Photo CD to convert, so this program is only useful if your Photo CD contains only one image, or if you only want to convert the first image.

OPTIONS

-center
Center the extracted image on the output page. This option is only meaningful for Postscript output.
-d
Use the default values.
-dpi n
Set the printer resolution to n dots per inch. This option is only meaningful for Postscript output.
-dummy widthxheight
Create a dummy image of the specified size. This option is useful for testing and to generate Postscript output for a given page size. This option is only meaningful for Postscript output.
-eps
Generate Encapsulated Postscript (EPS) instead of standard Postscript.
-epsg
Generate Encapsulated Postscript (EPS) for grayscale images.
-epsd
Generate Encapsulated Postscript (EPS) for dithered images.
-fak factor
Scale the output image by the given factor. This option is only meaningful for Postscript output.
-gray
Output a grayscale image.
-grey
Synonym for -gray.
-i
Invert the image.
-noicc
Do not write an ICC color profile.
-noscale
Do not scale the image. This option is only meaningful for Postscript output.
-pb n
Set the bottom margin to n points. This option is only meaningful for Postscript output.
-ph n
Set the image height to n points. This option is only meaningful for Postscript output.
-pl n
Set the left margin to n points. This option is only meaningful for Postscript output.
-ps
Generate Postscript output.
-psg
Generate Postscript output for grayscale images.
-psd
Generate Postscript output for dithered images.
-pw n
Set the image width to n points. This option is only meaningful for Postscript output.
-t n
Extract the nth image from the Photo CD. The first image is 1.
-verbose
Print verbose output to stderr.
-version
Print version information and exit.
-vms
Use VMS conventions for file names.
-w
Write the image in raw PPM format.
-ycc
Write the image in a variation on PPM format in which the samples are YCC instead of RGB.
-1|-Base/16|-128x192
Extract the Base/16 image.
-2|-Base/4|-256x384
Extract the Base/4 image.
-3|-Base|-512x768
Extract the Base image.
-4|-4Base|-1024x1536
Extract the 4Base image.
-5|-16Base|-2048x3072
Extract the 16Base image.
-6|-64Base|-4096x6144
Extract the 64Base image. This resolution can be extracted from ProPhotoCD images only. The path of the 64Base extension files is derived from the path to the image file. This means that it doesn't work on stdin an the directory structure must be the very same as on the ProPhotoCD.

Postcript Output

For Postscript output (options -ps, -eps, -psg, -epsg, -psd, -epsg) you can define both the resolution and placement of the image. Both size and position are specified in points (1/72 inch).

The position of the image (where the origin is assumed to be at the lower left corner of the page) is controlled by the -pl and -pb options (applicable at all resolutions).

The size of color and grayscale images is changed with the -pw and -ph options. Every image pixel is mapped onto one Postscript pixel.

There are three modes of control for dithered Postscript:

Image size

(-pw and -ph)
Printer resolution
(-dpi)
Scaling factor
(-fak)

These three factors are interdependent, hence no more then two can be specified simultaneously. Using -dpi and the -pw/-ph options together often yields pleasing results. Even using the default values for these options will produce results differing from those obtained without use of the options.

Limitations

The program ignores read protection.

The -i option is not working correctly.

Available information obout the Photo-CD format is vague; this program was developed by trial-and-error after staring at hex-dumps. Please send bugs reports and patches to the author.
