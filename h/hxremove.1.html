NOM

hxremove - supprime des éléments d'un fichier XML à l'aide d'un sélecteur CSS

SYNTAXE

hxremove [ -i ] [ -l langue ] sélecteurs

DESCRIPTION

hxremove lit un document XML bien formé depuis l'entrée standard et l'écrit sur la sortie standard sans les éléments qui correspondent à l'un des sélecteurs CSS fournis en argument. Par exemple :


hxremove ol li:first-child

supprime le premier élément `li` (élément de liste dans XHTML) de chaque élément `ol` (liste ordonnée).

S'il y a plusieurs sélecteurs, ils doivent être séparés par des virgules. Par exemple :


hxremove p + ul, blockquote ol

supprime tous les éléments `ul` qui suivent un élément `p` et également tous les éléments `ol` qui sont descendants d'un élément `blockquote`.

hxremove suppose que les sélecteurs de classe (`".foo"`) font référence à un attribut appelé `"class"`. Et suppose que les sélecteurs d'ID (`"#foo"`) font référence à un attribut appelé `"id"`.

Pour traiter des fichiers HTML, rendez-les d'abord en XML bien formé, par exemple avec hxnormalize -x.

Comparez avec hxselect, qui supprime tout sauf les éléments sélectionnés.

OPTIONS

Les options suivantes sont prises en charge :

-i
Correspondance insensible à la casse. Utile pour HTML et certains autres langages basés sur SGML.
-l langue
Définit la langue par défaut, si l'élément racine n'a pas d'attribut `xml:lang` (par défaut : aucun). Exemple : -l fr

OPÉRANDES

L'opérande suivant est pris en charge :

sélecteurs
Un ou plusieurs sélecteurs séparés par des virgules. La plupart des sélecteurs de la spécification CSS niveau 3 sont pris en charge.
