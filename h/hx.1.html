hx(1)

Paquet: hex

Licences: MIT

() ()

NOM

hx - Une approche futuriste de hexdump, créé en Rust.

SYNTAXE

hx [-tcfl][--color=0,1][--cols 0-9][--format oxXb] fichier_entree
hx [-a rcgpkjsf][--array=rcgpkjsf] fichier_entree
hx [-up][--func 0-9][--places 0-9]
hx [-hV]

OPTIONS

hx
Une approche futuriste de hexdump, créé en Rust.
SYNTAXE :
    hx [OPTIONS] [FICHIER_ENTREE]
    <stdin> hx [OPTIONS]
INDICATEURS :
    -h, --help       Affiche l'aide
    -V, --version    Affiche la version
OPTIONS :
    -a, --array <format_tableau>    Définit le format de sortie du code source : rust (r), C (c), golang (g), python (p), kotlin (k),
                                  java (j), swift (s), fsharp (f) [valeurs possibles : r, c, g, p, k, j, s, f]
    -t, --color <couleur>           Définit la couleur de la sortie du terminal. 0 pour désactiver, 1 pour activer [valeurs possibles : 0, 1]
    -c, --cols <colonnes>          Définit le nombre de colonnes
    -f, --format <format>         Définit le format de l'octet : Octal (o), Hexadécimal minuscule (x), Hexadécimal majuscule (X), Binaire (b) [valeurs
                                  possibles : o, x, X, b]
    -u, --func <longueur_fonction>      Définit la longueur d'onde de la fonction
    -l, --len <len>               Lit <len> octets
    -p, --places <décimales_fonction>    Définit les décimales de sortie de l'onde de la fonction
ARGUMENTS :
    <FICHIER_ENTREE>    Spécifiez le chemin du fichier en argument, ou les données d'entrée peuvent être passées via stdin

DESCRIPTION

hx affiche une représentation hexadécimale de l'entrée.

Par défaut, la sortie est colorisée, avec une option pour désactiver la couleur via le paramètre -t [0,1].

La variable d'environnement NO_COLOR est respectée si elle est définie.

VALEUR DE RETOUR

hx se termine avec la valeur 0 en cas de succès, et >0 si une erreur se produit.
