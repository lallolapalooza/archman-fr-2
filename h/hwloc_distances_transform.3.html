Description détaillée

Documentation du type d'énumération

enum hwloc_distances_kind_e

Genres de matrices de distances. L'attribut kind de la structure hwloc_distances_s est un ensemble OU'é de genres.

Chaque matrice de distances ne peut avoir qu'un seul genre parmi HWLOC_DISTANCES_KIND_FROM_* spécifiant d'où proviennent les informations de distance, et un genre parmi HWLOC_DISTANCES_KIND_MEANS_* spécifiant si les valeurs sont des latences ou des bande passantes.

Énumérateur

HWLOC_DISTANCES_KIND_FROM_OS
Ces distances ont été obtenues du système d'exploitation ou du matériel.
HWLOC_DISTANCES_KIND_FROM_USER
Ces distances ont été fournies par l'utilisateur.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Les valeurs de distance sont similaires aux latences entre objets. Les valeurs sont plus petites pour les objets plus proches, donc minimales sur la diagonale de la matrice (distance entre un objet et lui-même). Il peut également s'agir du nombre de sauts réseau entre objets, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Les valeurs de distance sont similaires aux bande passantes entre objets. Les valeurs sont plus élevées pour les objets plus proches, donc maximales sur la diagonale de la matrice (distance entre un objet et lui-même). De telles valeurs sont actuellement ignorées pour le regroupement basé sur la distance.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Cette structure de distances couvre des objets de types différents. Cela peut s'appliquer à la structure 'NVLinkBandwidth' en présence d'un NVSwitch ou d'un port NVLink de processeur POWER.

enum hwloc_distances_transform_e

Transformations des structures de distances.

Énumérateur

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Supprime les objets NULL de la structure de distances. Tout objet qui a été remplacé par NULL dans le tableau objs est supprimé et le tableau values est mis à jour en conséquence.

Au moins 2 objets doivent rester, sinon hwloc_distances_transform() retournera -1 avec errno mis à EINVAL.

kind sera mis à jour avec ou sans HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES selon les objets restants.

HWLOC_DISTANCES_TRANSFORM_LINKS
Remplace les valeurs de bande passante par un nombre de liens. Généralement, toutes les valeurs seront soit 0 (pas de lien), soit 1 (un lien). Cependant, certaines matrices peuvent avoir des valeurs plus grandes si certaines paires de pairs sont connectées par un nombre différent de liens.

Les valeurs sur la diagonale sont définies à 0.

Cette transformation ne s'applique qu'aux matrices de bande passante.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionne les commutateurs avec plusieurs ports en un seul objet. Cela ne s'applique actuellement qu'aux NVSwitches où les GPU semblent connectés à différents ports du commutateur. Les ports du commutateur doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Cette transformation remplacera tous les ports par le premier port seulement, maintenant connecté à tous les GPU. Les autres ports sont supprimés en appliquant HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL en interne.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Applique une fermeture transitive à la matrice pour connecter les objets à travers les commutateurs. Toutes les paires de GPU seront rapportées comme étant directement connectées au lieu que les GPU ne soient connectés qu'aux commutateurs.

Les ports de commutateur doivent être des objets de sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Documentation des fonctions

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupérer les matrices de distances. Récupérer les matrices de distances de la topologie dans le tableau distances.

flags est actuellement inutilisé, doit être 0.

kind sert de filtre. S'il est 0, toutes les matrices de distances sont retournées. S'il contient des HWLOC_DISTANCES_KIND_FROM_*, seules les matrices de distances dont le genre correspond à l'un de ceux-ci sont retournées. S'il contient des HWLOC_DISTANCES_KIND_MEANS_*, seules les matrices de distances dont le genre correspond à l'un de ceux-ci sont retournées.

En entrée, nr pointe vers le nombre de matrices de distances qui peuvent être stockées dans distances. En sortie, nr pointe vers le nombre de matrices de distances qui ont été effectivement trouvées, même si certaines d'entre elles n'ont pas pu être stockées dans distances. Les matrices de distances qui n'ont pas pu être stockées sont ignorées, mais le nombre total de matrices trouvées est toujours retourné.

Les matrices de distances sont retournées dans le tableau distances. L'appelant est responsable de libérer ce tableau en appelant hwloc_distances_release().

Il est possible que des matrices de distances supplémentaires soient disponibles mais ne correspondent pas aux filtres de kind. Elles ne sont pas retournées.

En cas d'erreur, -1 est retourné et errno est défini de manière appropriée.

int hwloc_distances_get_by_depth (hwloc_topology_t topology, int depth, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupérer les matrices de distances pour une profondeur donnée. Récupère les matrices de distances de la topologie qui correspondent à la profondeur spécifiée par depth.

Les autres arguments et valeurs de retour sont les mêmes que pour hwloc_distances_get().

Si la profondeur spécifiée n'existe pas, 0 matrices sont retournées et nr est mis à 0.

int hwloc_distances_get_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupérer les matrices de distances pour un type d'objet donné. Récupère les matrices de distances de la topologie qui couvrent les objets du type spécifié par type.

Les autres arguments et valeurs de retour sont les mêmes que pour hwloc_distances_get().

Si le type spécifié n'existe pas, 0 matrices sont retournées et nr est mis à 0.

int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Récupérer une matrice de distances spécifique par son nom. Récupère la matrice de distances nommée par name.

Le paramètre kind n'est pas utilisé ici car le nom identifie uniquement la matrice.

Les autres arguments et valeurs de retour sont les mêmes que pour hwloc_distances_get().

Si aucune matrice de distances avec le nom spécifié n'est trouvée, 0 matrices sont retournées et nr est mis à 0.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Obtenir le nom d'une matrice de distances. Retourne le nom de la matrice de distances spécifiée par distances.

Si la matrice de distances n'a pas de nom (par exemple, si elle a été fournie par l'utilisateur sans nom), une chaîne vide est retournée.

En cas d'erreur, NULL est retourné.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Libérer une matrice de distances précédemment récupérée. Libère la mémoire allouée pour le tableau distances récupéré par hwloc_distances_get(), hwloc_distances_get_by_depth(), hwloc_distances_get_by_type() ou hwloc_distances_get_by_name().

Si distances est NULL, cette fonction ne fait rien.
