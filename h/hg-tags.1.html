hg-tags(1)

Paquet: mercurial

Licences: GPL

HG(TAGS) HG(TAGS)

NOM

hg tags - lister les tags du dépôt

SYNTAXE

hg tags

DESCRIPTION

Ceci liste les tags réguliers et locaux. Lorsque le commutateur -v/--verbose est utilisé, une troisième colonne « local » est imprimée pour les tags locaux. Lorsque le commutateur -q/--quiet est utilisé, seul le nom du tag est imprimé.

Modèle :

Les mots-clés suivants sont pris en charge en plus des mots-clés et fonctions de modèle communs tels que {tag}. Voir également hg help templates.

type
Chaîne. local pour les tags locaux.

Retourne 0 en cas de succès.

OPTIONS

-T,--template <MODÈLE>
afficher avec un modèle
