heapsort(3bsd)

Paquet: libbsd

Licences: custom

heapsort(3bsd) 3bsd heapsort(3bsd)

NOM

heapsort, mergesort — fonctions de tri

BIBLIOTHÈQUE

bibliothèque “libbsd”

SYNTAXE

#include <stdlib.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
int
heapsort(void *base, size_t nmemb, size_t size, int (*compar)(const void *, const void *));

int
mergesort(void *base, size_t nmemb, size_t size, int (*compar)(const void *, const void *));

DESCRIPTION

La fonction heapsort() est un tri par sélection modifié. La fonction mergesort() est un tri fusion modifié avec recherche exponentielle destiné à trier des données ayant un ordre préexistant.

La fonction heapsort() trie un tableau de nmemb objets, dont le membre initial est pointé par base. La taille de chaque objet est spécifiée par size. La fonction mergesort() se comporte de manière similaire, mais exige que size soit supérieur à “sizeof(void *) / 2”.

Le contenu du tableau base est trié par ordre croissant selon une fonction de comparaison pointée par compar, qui nécessite deux arguments pointant vers les objets comparés.

La fonction de comparaison doit retourner un entier inférieur, égal ou supérieur à zéro si le premier argument est considéré respectivement comme inférieur, égal ou supérieur au second.

L'algorithme implémenté par heapsort() n'est pas stable, c'est-à-dire que si deux membres sont égaux lors de la comparaison, leur ordre dans le tableau trié est indéfini. L'algorithme mergesort() est stable.

La fonction heapsort() est une implémentation de l'algorithme « heapsort » de J.W.J. William, une variante du tri par sélection ; en particulier, voir l'Heapsort de D.E. Knuth. Heapsort prend un temps O N lg N dans le pire des cas. Son seul avantage par rapport à qsort() est qu'il utilise presque aucune mémoire supplémentaire ; tandis que qsort() n'alloue pas de mémoire, il est implémenté à l'aide de la récursivité.

La fonction mergesort() nécessite de la mémoire supplémentaire de taille nmemb * size octets ; elle ne doit être utilisée que lorsque l'espace n'est pas une contrainte. La fonction mergesort() est optimisée pour les données ayant un ordre préexistant ; son temps dans le pire des cas est O N lg N ; son meilleur cas est O N.

Normalement, qsort() est plus rapide que mergesort() qui est plus rapide que heapsort(). La disponibilité de la mémoire et l'ordre préexistant dans les données peuvent rendre cela faux.

VALEURS DE RETOUR

Les fonctions heapsort() et mergesort() retournent la valeur 0 en cas de succès ; sinon, la valeur -1 est retournée et la variable globale errno est définie pour indiquer l'erreur.

ERREURS

Les fonctions heapsort() et mergesort() réussissent sauf si :

[EINVAL]
L'argument size est zéro, ou l'argument size pour mergesort() est inférieur à “sizeof(void *) / 2”.
[ENOMEM]
Les fonctions heapsort() ou mergesort() n'ont pas pu allouer de mémoire.
