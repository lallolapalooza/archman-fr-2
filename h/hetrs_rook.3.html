CHETRS_ROOK calcule la solution d'un système d'équations linéaires A * X = B pour les matrices HE en utilisant la factorisation obtenue avec l'une des méthodes de pivotement diagonal bornées (max 2 interchanges)

But :

!>
!> CHETRS_ROOK résout un système d'équations linéaires A*X = B avec une
!> matrice hermitienne complexe A en utilisant la factorisation A = U*D*U**H ou
!> A = L*D*L**H calculée par CHETRF_ROOK.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' :  Triangulaire supérieure, la forme est A = U*D*U**H ;
!>          = 'L' :  Triangulaire inférieure, la forme est A = L*D*L**H.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L tels que calculés par CHETRF_ROOK.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des interchanges et de la structure par blocs de D
!>          tels que déterminés par CHETRF_ROOK.
!>

B

!>          B est un tableau COMPLEX, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice du second membre B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

NAME

                        
zsytrs_rook — The routine returns the solution to a complex symmetric system of linear equations Ax=B using the L/U factorization of A computed by ZSYTRF_ROOK.

                    

                    

                        
SYNOPSIS

                        

                            
SUBROUTINE ZSYTRS_ROOK( UPLO, N, NRHS, A, LDA, IPIV, B, LDB, INFO )

                            
CHARACTER * 1 UPLO

                            
INTEGER N, NRHS, LDA, LDB, INFO

                            
INTEGER IPIV(*) 

                            
COMPLEX*16 A(*), B(*)

                        

                    

                    

                        
Detailed Description

                        
This routine uses the previously computed factorization of a complex symmetric matrix A and it computes the solution to the system of linear equations: A * X = B

                        
The factorization is of the form:

                        
A = P * D * P**T

                        
where P is a permutation matrix, D is a block diagonal matrix and P**T is the transpose of P.

                        
The block diagonal matrix D is represented by its diagonal elements, and the multipliers used to obtain the factor U or L are also stored in the array A.

                        
The solution X is obtained by:

                        
X = (P**T)**-1 * D**-1 * P**-1 * B

                        
The array IPIV stores the details of the interchanges and the block structure of D.

                    

                    

                        
Function Documentation

                        
ZSYTRS_ROOK(UPLO, N, NRHS, A, LDA, IPIV, B, LDB, INFO)

                        
Computes the solution to a complex symmetric system of linear equations Ax=B.

                        
Arguments:

                        

                            
UPLO

                            
CHARACTER*1. 'U' specifies that the upper triangular factor of A is stored in A. 'L' specifies that the lower triangular factor of A is stored in A.

                            
N

                            
INTEGER. The order of the matrix A. N >= 0.

                            
NRHS

                            
INTEGER. The number of right hand sides, i.e., the number of columns of the matrix B. NRHS >= 0.

                            
A

                            
COMPLEX*16 array, dimension (LDA, N). On entry, the factorization of A as computed by ZSYTRF_ROOK. On exit, the array A contains the block diagonal matrix D and the multipliers used to obtain the factor U or L as computed by ZSYTRF_ROOK.

                            
LDA

                            
INTEGER. The leading dimension of the array A. LDA >= max(1,N).

                            
IPIV

                            
INTEGER array, dimension (N). Details of the interchanges and the block structure of D as determined by ZSYTRF_ROOK.

                            
B

                            
COMPLEX*16 array, dimension (LDB, NRHS). On entry, the right hand side matrix B. On exit, the solution matrix X.

                            
LDB

                            
INTEGER. The leading dimension of the array B. LDB >= max(1,N).

                            
INFO

                            
INTEGER. = 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value.
