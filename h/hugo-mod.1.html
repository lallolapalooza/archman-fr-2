NOM

hugo-mod - Gérer les modules

SYNOPSIS

hugo mod [commande] [options]

DESCRIPTION

Diverses aides pour gérer les modules dans le graphe de dépendances de votre projet. La plupart des opérations ici nécessitent une version de Go installée sur votre système (>= Go 1.12) et le client VCS pertinent (typiquement Git). Ce n'est pas nécessaire si vous n'opérez que sur des modules dans /themes ou si vous les avez intégrés via "hugo mod vendor".

Notez que Hugo commencera toujours par résoudre les composants définis dans la configuration du site, fournis par un répertoire _vendor (si aucun indicateur --ignoreVendorPaths n'est fourni), Go Modules, ou un dossier dans le répertoire themes, dans cet ordre.

Voir https://gohugo.io/hugo-modules/ pour plus d'informations.

OPTIONS

-h, --help[=false] aide pour mod

OPTIONS HÉRITÉES DES COMMANDES PARENT

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de module correspondant au motif Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne crée pas de fichier .hugo_build.lock

--quiet[=false] construit en mode silencieux

-M, --renderToMemory[=false] rend en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers à partir duquel lire les fichiers en relatif

--themesDir="" chemin du système de fichiers du répertoire des thèmes
