Description détaillée

Cette interface aide à convertir entre les masques unsigned long de libnuma sur Linux et les ensembles de CPU et de nœuds hwloc.

Remarque

La topologie topology doit correspondre à la machine actuelle.

Le comportement de libnuma est indéfini si le noyau n'est pas NUMA-aware. (lorsque CONFIG_NUMA n'est pas défini dans la configuration du noyau). Cet assistant et libnuma peuvent donc ne pas être strictement compatibles dans ce cas, ce qui peut être détecté en vérifiant si numa_available() renvoie -1.

Documentation des fonctions

int hwloc_cpuset_from_linux_libnuma_ulongs (hwloc_topology_t topology, hwloc_cpuset_t cpuset, const unsigned long * mask, unsigned long maxnode) [inline]

Convertit le tableau de mask unsigned long en ensemble de CPU hwloc. mask est un tableau de unsigned long qui sera lu. maxnode contient le numéro de nœud maximal qui peut être lu dans mask.

Cette fonction peut être utilisée après l'appel à get_mempolicy ou à toute autre fonction qui prend un tableau de unsigned long comme paramètre de sortie (et éventuellement un numéro de nœud maximal comme paramètre d'entrée).

Renvoie

0 en cas de succès.

-1 en cas d'erreur, par exemple si une réallocation interne échoue.

int hwloc_cpuset_to_linux_libnuma_ulongs (hwloc_topology_t topology, hwloc_const_cpuset_t cpuset, unsigned long * mask, unsigned long * maxnode) [inline]

Convertit l'ensemble de CPU hwloc cpuset en tableau de unsigned long mask. mask est le tableau de unsigned long qui sera rempli. maxnode contient le numéro de nœud maximal qui peut être stocké dans mask. maxnode sera défini au numéro de nœud maximal trouvé, plus un.

Cette fonction peut être utilisée avant l'appel à set_mempolicy, mbind, migrate_pages ou à toute autre fonction qui prend un tableau de unsigned long et un numéro de nœud maximal comme paramètres d'entrée.

Renvoie

0.

int hwloc_nodeset_from_linux_libnuma_ulongs (hwloc_topology_t topology, hwloc_nodeset_t nodeset, const unsigned long * mask, unsigned long maxnode) [inline]

Convertit le tableau de mask unsigned long en ensemble de nœuds NUMA hwloc. mask est un tableau de unsigned long qui sera lu. maxnode contient le numéro de nœud maximal qui peut être lu dans mask.

Cette fonction peut être utilisée après l'appel à get_mempolicy ou à toute autre fonction qui prend un tableau de unsigned long comme paramètre de sortie (et éventuellement un numéro de nœud maximal comme paramètre d'entrée).

Renvoie

0 en cas de succès.

-1 avec errno défini à ENOMEM si une réallocation interne a échoué.

Cette fonction peut être utilisée avant l'appel à set_mempolicy, mbind, migrate_pages ou à toute autre fonction qui prend un tableau de unsigned long et un numéro de nœud maximal comme paramètres d'entrée.
