NOM

hextrail - économiseur d'écran.

SYNTAXE

hextrail [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--delay nombre] [--speed nombre] [--count nombre] [--thickness nombre] [--no-wander] [--no-spin] [--wireframe] [--fps]

DESCRIPTION

Un réseau de lignes colorées se développe sur un substrat hexagonal.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou l'ID (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine sur une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--delay nombre
Taux de rafraîchissement. 0 - 100000. Défaut : 30000.
--speed nombre
Vitesse. 0.1 - 20. Défaut : 1.0.
--count nombre
Taille de l'hexagone. 2 - 80. Défaut : 20.
--thickness nombre
Épaisseur de la ligne. 0.01 - 0.5. Défaut : 0.15.
--no-wander | --no--no-wander
Errance. Booléen.
--no-spin | --no--no-spin
Rotation. Booléen.
--wireframe | --no--wireframe
Mode fil de fer. Booléen.
--fps | --no--fps
Afficher le taux d'images par seconde. Booléen.

ENVIRONNEMENT

DISPLAY
Pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
Pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
