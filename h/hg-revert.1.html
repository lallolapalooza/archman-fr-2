HG(REVERT) HG(REVERT)

NOM

hg revert - restaure les fichiers à leur état de checkout

SYNTAXE

hg revert [OPTION]... [-r REV] [NOM]...

DESCRIPTION

Note
Pour vérifier les révisions antérieures, utilisez hg update REV. Pour annuler une fusion non validée (et perdre vos modifications), utilisez hg merge --abort.

Sans révision spécifiée, restaure les fichiers ou répertoires spécifiés à leur contenu dans le parent du répertoire de travail. Cela restaure le contenu des fichiers à un état non modifié et désannule les ajouts, suppressions, copies et renommages. Si le répertoire de travail a deux parents, vous devez explicitement spécifier une révision.

En utilisant les options -r/--rev ou -d/--date, restaurez les fichiers ou répertoires donnés à leur état à une révision spécifique. Comme revert ne modifie pas les parents du répertoire de travail, cela fera apparaître ces fichiers comme modifiés. Cela peut être utile pour "annuler" tout ou partie d'un changement antérieur. Voir hg backout pour une méthode connexe.

Les fichiers modifiés sont sauvegardés avec un suffixe .orig avant la restauration. Pour désactiver ces sauvegardes, utilisez --no-backup. Il est possible de stocker les fichiers de sauvegarde dans un répertoire personnalisé relatif à la racine du dépôt en configurant l'option de configuration ui.origbackuppath.

Voir hg help dates pour une liste des formats valides pour -d/--date.

Voir hg help backout pour un moyen d'inverser l'effet d'un changeset antérieur.

Retourne 0 en cas de succès.

OPTIONS

-a, --all
restaure tout quand aucun argument n'est donné
-d,--date <DATE>
dernière révision correspondant à la date
-r,--rev <REV>
restaure à la révision spécifiée
-C, --no-backup
ne sauvegarde pas de copies de sauvegarde des fichiers
-i, --interactive
sélectionne interactivement les modifications
-I,--include <PATTERN[+]>
inclut les noms correspondant aux motifs donnés
-X,--exclude <PATTERN[+]>
exclut les noms correspondant aux motifs donnés
-n, --dry-run
n'effectue pas les actions, imprime seulement la sortie

[+] l'option marquée peut être spécifiée plusieurs fois
