HARVID(1) Commandes utilisateur HARVID(1)

NOM

harvid - serveur vidéo

SYNTAXE

harvid [OPTION] [document-root]

DESCRIPTION

harvid - http ardour video server

OPTIONS

-A <liste-cmd>, --admin <liste-cmd>
liste d'arguments séparés par des espaces des commandes d'administration autorisées. Un point d'exclamation avant une commande la désactive. Par défaut : 'flush_cache' ; disponibles : flush_cache, purge_cache, shutdown
-c <chemin>, --chroot <chemin>
changer la racine système - isole le serveur dans ce chemin
-C <images>
définit la taille initiale du cache d'images (par défaut : 128)
-D, --daemonize
fork en arrière-plan et détache du TTY
-g <nom>, --groupname <nom>
adopte ce groupe d'utilisateurs
-h, --help
affiche cette aide et quitte
-F <feat>, --features <feat>
liste d'arguments séparés par des espaces des fonctionnalités optionnelles. Un point d'exclamation avant une fonctionnalité la désactive. Par défaut : 'index' ; disponibles : index, seek, flatindex, keepraw
-l <chemin>, --logfile <chemin>
spécifie le fichier pour les messages de log
-M, --memlock
tente de verrouiller la mémoire (empêche la mise en cache)
-p <num>, --port <num>
port TCP sur lequel écouter (par défaut 1554)
-P <adresse-ecoute>
adresse IP sur laquelle écouter (par défaut 0.0.0.0)
-q, --quiet, --silent
inhibe la sortie habituelle (peut être utilisé trois fois)
-s, --syslog
envoie les messages à syslog
-t <limite-threads>
définit le nombre maximum de threads de décodage (par défaut : 8)
-T <sec>, --timeout <sec>
définit un délai après lequel le serveur se terminera si aucune nouvelle requête n'arrive
-u <nom>, --username <nom>
le serveur agira en tant que cet utilisateur
-v, --verbose
affiche plus d'informations (peut être utilisé deux fois)
-V, --version
affiche les informations de version et quitte

La valeur par défaut pour document-root (si non spécifiée) est la racine système : / ou C:\.

Si syslog et logfile sont tous deux spécifiés, la dernière option spécifiée sera utilisée.

--verbose et --quiet sont additifs. Par défaut, seuls les avertissements et les niveaux supérieurs sont affichés. Les niveaux de log disponibles sont 'mute', 'critical', 'error', 'warning' et 'info'.

L'option --features permet d'activer ou de désactiver les gestionnaires http /seek et /index et de modifier leur réponse : L'option 'flatindex' concerne /index&flatindex=1 qui indexe récursivement tous les fichiers vidéo. Elle est désactivée par défaut car une recherche récursive de la docroot par défaut / peut prendre très longtemps. Lors de la demande d'images png ou jpeg, harvid décode une image RVB brute puis la ré-encode. Si la fonctionnalité 'keepraw' est activée, l'image RVB brute et l'image encodée sont conservées en cache. Par défaut, l'image RVB brute est invalidée après l'encodage de l'image.

EXEMPLES

harvid -A '!flush_cache purge_cache shutdown' -C 256 /tmp/

sudo harvid -c /tmp/ -u nobody -g nogroup /
