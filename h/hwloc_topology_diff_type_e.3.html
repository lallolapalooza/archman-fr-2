( hwloc_topology_diff_t diff, const char *refname, char **xmlbuffer, int *buflen) Description détaillée Les applications qui
manipulent de nombreuses topologies similaires,par exemple une pour chaque nœud d'un cluster homogène, peuvent vouloir compresser les

topologies

pour

réduire l'empreinte mémoire. Ce fichier offre un moyen de manipuler la différence entre topologies et de l'exporter/ importer vers/ depuis XML. La compression peut donc être réalisée

en

stockant une topologie entièrement tandis que les autres ne sont décrites que par leurs différences avec la première. La topologie réelle peut être reconstruite lorsqu'elle est réellement nécessaire en appliquant la différence précalculée à la topologie de référence. Cette interface cible des nœuds très similaires. Seules des différences très simples entre topologies sont réellement prises

en

charge, par exemple un changement dans la taille de la mémoire, le nom de l'objet, ou un attribut info. Des différences plus complexes telles que l'ajout ou la suppression d'objets ne peuvent pas être représentées dans les structures de différence et renvoient donc des erreurs. Les différences entre ensembles d'objets ou ensembles autorisés à l'échelle de la topologie ne peuvent pas non plus être représentées. Cela signifie qu'il n'est pas nécessaire

d'appliquer

la différence lors de l'examination de l'organisation arborescente (combien de niveaux, combien d'objets par niveau,

quels types d'objets, ensembles CPU et nœuds, etc.) et lors de la liaison aux objets. Cependant, la différence doit êt
re appliquée lors de l'examination des attributs d'objet tels que le nom, la taille de la mémoire ou les attributs info.

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t *

diff)

Calcule la différence entre 2 topologies. La différence est stockée sous forme d'une liste d'entrées hwloc_topology_diff_t commençant à diff. Elle est calculée en effectuant simultanément une traversée en profondeur des deux arbres de

topologie.

Si la différence entre 2 objets est trop complexe pour être représentée (par exemple si certains objets ont des types différents, ou un nombre d'enfants différent), une entrée de diff spéciale de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX est mise en file d'attente. Le calcul du diff ne continue pas en dessous de ces objets. Ainsi, chaque entrée de diff de ce type signifie que la différence entre deux sous-arbres n'a pas pu être

calculée.

0 si la différence peut être correctement représentée.

0 avec diff pointant vers NULL s'il n'y a pas de différence entre les

topologies.

1 si la différence est trop complexe (voir ci-dessus). Certaines entrées dans la liste seront de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX

.

-1 pour t
