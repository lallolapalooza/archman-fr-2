NOM

hxunent - remplace les entités de caractères prédéfinies HTML par UTF-8

SYNTAXE

hxunent [ -b ] [ -f ] [ fichier ]

DESCRIPTION

La commande hxunent lit le fichier (ou l'entrée standard) et le copie vers la sortie standard en remplaçant les entités de caractères par leur caractère équivalent (encodé en UTF-8). Par exemple, &quot; est remplacé par " et &lt; est remplacé par <.

OPTIONS

Les options suivantes sont supportées :

-b
Les cinq entités intégrées de XML (&lt; &gt; &quot; &apos; &amp;) ne sont pas remplacées mais copiées telles quelles. Ceci est nécessaire si la sortie doit être du XML ou du SGML valide.
-f
Cette option change la manière dont les entités inconnues ou les esperluettes isolées sont traitées. Normalement, elles sont copiées telles quelles, mais cette option essaie de les "réparer" en remplaçant les esperluettes par &amp;. Souvent, ces esperluettes errantes sont le résultat de copier-coller d'URL dans un document, et dans ce cas, cette option les répare et rend le document valide.

DIAGNOSTICS

La valeur de sortie du programme est 0 si tout s'est bien passé, sinon :

1
L'entrée n'a pas pu être lue (fichier introuvable, fichier non lisible...)
2
Arguments de ligne de commande incorrects.

VOIR AUSSI

asc2xml(1), xml2asc(1), UTF-8 (RFC 2279)

BOGUES

Le programme suppose que les entités sont définies par HTML. Il ne lit pas la DTD d'un document pour trouver les définitions réelles utilisées dans ce document. Avec -f, il supprimera même toutes les entités qui ne sont pas des entités HTML.
