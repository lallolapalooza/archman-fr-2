NOM

halo - dessiner des motifs circulaires

SYNTAXE

halo [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visuel] [--count entier] [--delay usec] [--mode seuss | ramp | random ] [--animate] [--colors entier] [--fps]

DESCRIPTION

Le programme halo dessine des motifs intéressants basés sur des cercles.

OPTIONS

halo accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Sur un écran couleur, prétendre être sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--count entier
Nombre de cercles à dessiner. Par défaut 0, ce qui signifie aléatoire.
--mode seuss | ramp | random
En mode seuss, des courbes rayées alternées seront dessinées.

En mode ramp, une rampe de couleurs sera dessinée.

random signifie choisir le mode aléatoirement.

--delay microsecondes
Quel délai introduire entre les étapes de l'animation. Par défaut 100000, soit environ 0.1 seconde.
--colors entier
Nombre de couleurs à utiliser. Par défaut 100.
--animate
Si spécifié, alors les centres des cercles rebondiront. Sinon, les cercles seront dessinés une fois, effacés, et un nouvel ensemble de cercles sera dessiné.
--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.
