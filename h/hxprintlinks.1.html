NOM

hxprintlinks - ajoute une liste numérotée de liens à la fin d'un fichier HTML

SYNTAXE

hxprintlinks [ -b base ] fichier_ou_URL

DESCRIPTION

hxprintlinks ajoute une liste numérotée de toutes les URLs (liens) trouvées dans le fichier à la fin du fichier HTML.

OPTIONS

Les options suivantes sont supportées :

-b base
Rend les URLs de la liste absolues, en utilisant base comme URL de base.

OPÉRANDES

L'opérande suivante est supportée :

fichier_ou_URL
Le fichier à traiter. Si l'argument est absent, ou s'il s'agit d'un - (un simple tiret), le document est lu depuis l'entrée standard.

VOIR AUSSI

hxcopy(1)

BOGUES

L'option -b est probablement d'une utilité limitée. Elle rend les liens de la liste générée absolus, mais ne modifie pas les autres liens. Pour une solution plus flexible, utilisez hxcopy(1) sur la sortie de hxprintlinks. Par exemple, au lieu de


hxprintlinks -b http://example.org/base/ mon_fichier.html

utilisez


hxprintlinks mon_fichier.html | hxcopy -i http://example.org/base -o .
