NOM

highvoltage - tours de transmission haute tension.

SYNTAXE

highvoltage [--display hôte:écran.moniteur] [--visual visuel] [--window] [--root] [--delay nombre] [--speed nombre] [--spacing nombre] [--count nombre]

DESCRIPTION

Un vol tranquille devant quelques tours de transmission haute tension. Sentez l'ozone !

OPTIONS

--visual visuel
Spécifie le visuel à utiliser. Les valeurs autorisées sont le nom d'une classe de visuel, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--delay nombre
Délai par image, en microsecondes. Défaut : 30000 (0,03 seconde).
--speed nombre
Vitesse de l'animation. 2.0 signifie deux fois plus rapide, 0.5 signifie deux fois moins rapide.
--spacing nombre
Espacement entre les tours. 2.0 signifie deux fois plus loin, 0.5 signifie deux fois plus près.
--count nombre
Nombre de tours rendu. 1 - 40. Défaut : 7.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
