sous-routine chptrs (character uplo, integer n, integer nrhs, complex, dimension( * ) ap, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, integer

info)

CHPTR

S

But

: 
!>
!> CHPTRS résout un système d'équations linéaires A*X = B avec une matrice
!> hermitienne complexe A stockée au format compact en utilisant la factorisation
!> A = U*D*U**H ou A = L*D*L**H calculée par CHPTRF.
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : triangulaire supérieur, la forme est A = U*D*U**H ;
!>          = 'L' : triangulaire inférieur, la forme est A = L*D*L**H.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!
>

A

P 
!>          AP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L tels que calculés par CHPTRF, stockés sous la
!>          forme d'une matrice triangulaire compacte.
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des permutations et de la structure par blocs de D
!>          tels que déterminés par CHPTRF.
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice du second membre B.
!>          À la sortie, la matrice solution X.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!
>
