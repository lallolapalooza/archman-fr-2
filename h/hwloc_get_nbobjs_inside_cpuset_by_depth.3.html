hwloc_obj_t hwloc_get_first_largest_obj_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set) [inline]

Récupérer le premier objet le plus grand inclus dans l'ensemble de CPU donné set.

Renvoie

le premier objet qui est inclus dans set et dont le parent ne l'est pas.

NULL si un tel objet n'existe pas.

C'est pratique pour parcourir tous les plus grands objets à l'intérieur d'un ensemble de CPU en faisant une boucle qui récupère le premier objet le plus grand et efface son ensemble de CPU de l'ensemble de CPU restant.

int hwloc_get_largest_objs_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t *restrict objs, int max)

Obtenir l'ensemble des plus grands objets couvrant exactement un ensemble de CPU donné set.

Renvoie

le nombre d'objets renvoyés dans objs.

-1 si aucun ensemble d'objets ne peut couvrir cet ensemble de CPU.

unsigned hwloc_get_nbobjs_inside_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth) [inline]

Renvoyer le nombre d'objets à la profondeur depth inclus dans l'ensemble de CPU set.

Renvoie

le nombre d'objets.

0 si la profondeur est invalide.

Note

Les objets avec des ensembles de CPU vides sont ignorés (sinon ils seraient considérés comme inclus dans n'importe quel ensemble donné).

Cette fonction ne peut pas fonctionner si les objets à la profondeur donnée n'ont pas d'ensembles de CPU (objets E/S ou Divers).

Cette fonction ne peut pas fonctionner si les objets de ce type n'ont pas d'ensembles de CPU (objets E/S).

int hwloc_get_obj_index_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t obj) [inline]

Renvoyer l'index logique parmi les objets inclus dans l'ensemble de CPU set. Consulter tous les objets du même niveau que obj et à l'intérieur de l'ensemble de CPU set dans l'ordre logique, et renvoyer l'index de obj parmi eux. Si set couvre toute la topologie, c'est l'index logique de obj. Sinon, c'est similaire à un index logique à l'intérieur de la partie de la topologie définie par l'ensemble de CPU set.

NAME

hwloc_get_nbobjs_inside_cpuset_by_depth, hwloc_get_obj_inside_cpuset_by_depth, hwloc_get_obj_inside_cpuset_by_type — get objects inside a CPU set

SYNOPSIS

#include <hwloc.h>

int
hwloc_get_nbobjs_inside_cpuset_by_depth(hwloc_topology_t topology,
    hwloc_const_cpuset_t set, int depth);

hwloc_obj_t
hwloc_get_obj_inside_cpuset_by_depth(hwloc_topology_t topology,
    hwloc_const_cpuset_t set, int depth, unsigned idx);

hwloc_obj_t
hwloc_get_obj_inside_cpuset_by_type(hwloc_topology_t topology,
    hwloc_const_cpuset_t set, hwloc_obj_type_t type, unsigned idx);

Detailed Description

These functions return information about objects that are found inside a given CPU set.

The CPU set is given by parameter set.

hwloc_get_nbobjs_inside_cpuset_by_depth() returns the number of objects at depth depth that are included in CPU set set.

hwloc_get_obj_inside_cpuset_by_depth() returns the (logical) index among the objects included in the set if any.

-1 if the object is not included in the set.

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if obj does not have CPU sets (I/O objects).

hwloc_obj_t hwloc_get_obj_inside_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth, unsigned idx) [inline]

Return the (logical) idx -th object at depth depth included in CPU set set.

Returns

the object if any, NULL otherwise.

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if objects at the given depth do not have CPU sets (I/O or Misc objects).

hwloc_obj_t hwloc_get_obj_inside_cpuset_by_type (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type, unsigned idx) [inline]

Return the idx -th object of type type included in CPU set set.

Returns

the object if any.

NULL if there is no such object.

NULL if there is no depth for given type.

NULL if there are multiple depths for given type, the caller should fallback to hwloc_get_obj_inside_cpuset_by_depth().

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if objects of the given type do not have CPU sets (I/O or Misc objects).
