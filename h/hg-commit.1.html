HG(COMMIT) HG(COMMIT)

NOM

hg commit - valider les fichiers spécifiés ou toutes les modifications en attente

SYNTAXE

hg commit [OPTION]... [FICHIER]...

DESCRIPTION

Valide les modifications apportées aux fichiers spécifiés dans le dépôt. Contrairement à un SCM centralisé, cette opération est locale. Voir hg push pour un moyen de distribuer activement vos modifications.

Si une liste de fichiers est omise, toutes les modifications signalées par hg status seront validées.

Si vous validez le résultat d'une fusion, ne fournissez aucun nom de fichier ni aucun filtre -I/-X.

Si aucun message de validation n'est spécifié, Mercurial démarre votre éditeur configuré où vous pouvez entrer un message. En cas d'échec de votre validation, vous trouverez une sauvegarde de votre message dans .hg/last-message.txt.

L'option --close-branch peut être utilisée pour marquer comme fermée la tête de branche actuelle. Lorsque toutes les têtes d'une branche sont fermées, la branche sera considérée comme fermée et ne sera plus listée.

L'option --amend peut être utilisée pour modifier le parent du répertoire de travail avec une nouvelle validation qui contient les modifications du parent en plus de celles actuellement signalées par hg status, s'il y en a. L'ancienne validation est stockée dans un paquet de sauvegarde dans .hg/strip-backup (voir hg help bundle et hg help unbundle pour savoir comment la restaurer).

Le message, l'utilisateur et la date sont pris de la validation modifiée, sauf indication contraire. Lorsqu'un message n'est pas spécifié sur la ligne de commande, l'éditeur s'ouvre avec le message de la validation modifiée.

Il n'est pas possible de modifier des jeux de commits publics (voir hg help phases) ou des jeux de commits qui ont des enfants.

Voir hg help dates pour une liste des formats valides pour -d/--date.

Retourne 0 en cas de succès, 1 si rien n'a changé.

Exemples :

  • valider tous les fichiers se terminant par .py : 
    hg commit --include "set:**.py"
  • valider tous les fichiers non binaires : 
    hg commit --exclude "set:binary()"
  • modifier la validation actuelle et définir la date à maintenant : 
    hg commit --amend --date now

OPTIONS

-A, --addremove
marquer les nouveaux fichiers/fichiers manquants comme ajoutés/supprimés avant de valider
--close-branch
marquer une tête de branche comme fermée
--amend
modifier le parent du répertoire de travail
-s, --secret
utiliser la phase secrète pour la validation
--draft
utiliser la phase brouillon pour la validation
-e, --edit
invoquer l'éditeur sur les messages de validation
--force-close-branch
fermer de force une branche à partir d'un jeu de commits non-tête (AVANCÉ)
-i, --interactive
utiliser le mode interactif
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-m,--message <TEXTE>
utiliser le texte comme message de validation
-l,--logfile <FICHIER>
lire le message de validation depuis le fichier
-d,--date <DATE>
enregistrer la date spécifiée comme date de validation
-u,--user <UTILISATEUR>
enregistrer l'utilisateur spécifié comme committer
-S, --subrepos
récursion dans les sous-dépôts

[+] l'option marquée peut être spécifiée plusieurs fois
