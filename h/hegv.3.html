CHEGV

Objectif :

!>
!> CHEGV calcule toutes les valeurs propres, et éventuellement, les vecteurs propres
!> d'un problème généralisé Hermitien-défini complexe, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x.
!> Ici, A et B sont supposés Hermitiens et B est aussi
!> défini positif.
!>

Paramètres

ITYPE 
!>          ITYPE est INTEGER
!>          Spécifie le type de problème à résoudre :
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA, N)
!>          En entrée, la matrice Hermitienne A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de A contient
!>          la partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient la
!>          matrice Z des vecteurs propres.  Les vecteurs propres sont normalisés
!>          comme suit :
!>          si ITYPE = 1 ou 2, Z**H*B*Z = I ;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors en sortie, le triangle supérieur (si UPLO='U')
!>          ou le triangle inférieur (si UPLO='L') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX de dimension (LDB, N)
!>          En entrée, la matrice Hermitienne définie positive B.
!>          Si UPLO = 'U', la partie triangulaire supérieure N x N de B
!>          contient la partie triangulaire supérieure de la matrice B.
!>          Si UPLO = 'L', la partie triangulaire inférieure N x N de B
!>          contient la partie triangulaire inférieure de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          remplacée par le facteur triangulaire U ou L de la
!>          factorisation de Cholesky B = U**H*U ou B = L*L**H.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

W

!>          W est un tableau REAL de dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

WORK

!>          WORK est un tableau COMPLEX de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK.  LWORK >= max(1,2*N-1).
!>          Pour une efficacité optimale, LWORK >= (NB+1)*N,
!>          où NB est la taille du bloc pour CHETRD retournée par ILAENV.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL de dimension (max(1, 3*N-2))
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : ERREUR CPOTRF ou CHEEV ;
!>             <= N : si INFO = i, CHEEV n'a pas convergé ;
!>                    i éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                    n'ont pas convergé vers zéro ;
!>             > N :  si INFO = N + i, pour 1 <= i <= N, alors le mineur principal
!>                   de taille i de B n'est pas positif.
!>                   La factorisation de B n'a pas pu être complétée et
!>                   aucune valeur propre ou vecteur propre n'a été calculé.
!>
