hg-paths(1)

Paquet: mercurial

Licences: GPL

HG(CHEMINS) HG(CHEMINS)

NOM

hg paths - afficher les alias pour les dépôts distants

SYNTAXE

hg paths [NOM]

DESCRIPTION

Affiche la définition du nom de chemin symbolique NOM. Si aucun nom n'est donné, affiche la définition de tous les noms disponibles.

L'option -q/--quiet supprime toute sortie lors de la recherche de NOM et affiche uniquement les noms des chemins lors de la liste de toutes les définitions.

Les noms de chemins sont définis dans la section [paths] de votre fichier de configuration et dans /etc/mercurial/hgrc. Si exécuté à l'intérieur d'un dépôt, .hg/hgrc est également utilisé.

Les noms de chemins default et default-push ont une signification spéciale. Lors d'une opération de push ou de pull, ils sont utilisés comme solutions de secours si aucun emplacement n'est spécifié sur la ligne de commande. Lorsque default-push est défini, il sera utilisé pour le push et default sera utilisé pour le pull ; sinon default est utilisé comme solution de secours pour les deux. Lors du clonage d'un dépôt, la source du clone est écrite comme default dans .hg/hgrc.

Note
default et default-push s'appliquent à toutes les opérations entrantes (par exemple, hg incoming) et sortantes (par exemple, hg outgoing, hg email et hg bundle).

Voir hg help urls pour plus d'informations.

Modèle :

Les mots-clés suivants sont pris en charge. Voir également hg help templates.

name
Chaîne. Nom symbolique de l'alias de chemin.
pushurl
Chaîne. URL pour les opérations de push.
url
Chaîne. URL ou chemin du répertoire pour les autres opérations.

Retourne 0 en cas de succès.

OPTIONS

-T,--template <TEMPLATE>
afficher avec un modèle
