NOM

hg manifest - afficher le manifeste de la révision actuelle ou donnée

SYNTAXE

hg manifest [-r REV]

DESCRIPTION

Imprime une liste des fichiers sous contrôle de version pour la révision donnée. Si aucune révision n'est donnée, le premier parent du répertoire de travail est utilisé, ou la révision nulle si aucune révision n'est extraite.

Avec -v, imprime les permissions des fichiers, les bits de lien symbolique et exécutables. Avec --debug, imprime les hachages de révision des fichiers.

Si l'option --all est spécifiée, la liste de tous les fichiers de toutes les révisions est imprimée. Cela inclut les fichiers supprimés et renommés.

Retourne 0 en cas de succès.

OPTIONS

-r,--rev <REV>
révision à afficher
--all
lister les fichiers de toutes les révisions
-T,--template <TEMPLATE>
afficher avec un modèle
