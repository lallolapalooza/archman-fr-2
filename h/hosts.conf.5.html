NOM

hosts.conf - Contrôle d'accès pour les programmes CGI de Network UPS Tools

DESCRIPTION

Les programmes CGI (upsset.cgi(8), upsstats.cgi(8), upsimage.cgi(8)) utilisent ce fichier pour déterminer s'ils sont autorisés à communiquer avec un hôte. Cela empêche les visiteurs aléatoires d'utiliser votre serveur web pour importuner d'autres personnes en créant des connexions sortantes.

NOTES IMPORTANTES

•Le contenu de ce fichier doit être en ASCII pur (les codes caractères hors plage seront ignorés avec un message d'avertissement).
•Ce fichier ne contient pas de mots de passe. La surveillance en lecture seule dans NUT est anonyme, et le programme upsset(8) demande les identifiants dans la session du navigateur lors de la commande d'un onduleur spécifique (le serveur web doit être sécurisé, comme indiqué au programme par le fichier upsset.conf(5)).

DIRECTIVES

MONITOR onduleur description

L'élément onduleur est sous la forme nom_onduleur[@nom_hôte[:port]].

Pour autoriser les connexions à un onduleur nommé « snoopy » sur un système nommé « doghouse » qui exécute upsd sur le port 7877, cela ressemblerait à ceci :

MONITOR snoopy@doghouse:7877 "Joe Cool"

La description doit être un seul élément, donc si elle contient des espaces, elle doit être entourée de guillemets comme montré ci-dessus. Le nom d'hôte par défaut est « localhost ».

VOIR AUSSI

upsset.cgi(8), upsstats.cgi(8), upsimage.cgi(8)
