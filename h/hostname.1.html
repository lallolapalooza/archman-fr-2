HOSTNAME(1) Commandes utilisateur HOSTNAME(1)

NOM

hostname - afficher ou définir le nom d'hôte du système

SYNTAXE

hostname [OPTION...] [NOM]

DESCRIPTION

Affiche ou définit le nom d'hôte du système.

-a, --aliases
noms d'alias
-d, --domain
nom de domaine DNS
-f, --fqdn, --long
nom d'hôte DNS ou FQDN
-F, --file=FICHIER
définit le nom d'hôte ou le nom de domaine NIS à partir de FICHIER
-i, --ip-addresses
adresses du nom d'hôte
-s, --short
nom d'hôte court
-y, --yp, --nis
nom de domaine NIS/YP
-?, --help
affiche cette liste d'aide
--usage
affiche un court message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.
