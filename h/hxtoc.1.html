HXTOC(1) HTML-XML-utils HXTOC(1)

NOM

hxtoc - insère une table des matières dans un fichier HTML

SYNTAXE

hxtoc [ -x ] [ -l bas ] [ -h haut ] [ -t ] [ -d ] [ -c classe ] [ -f ] [ fichier-ou-URL ]

DESCRIPTION

La commande hxtoc lit un fichier HTML, insère les attributs ID manquants dans tous les éléments H1 à H6 entre les niveaux -l et -h (sauf si l'option -d est activée, voir ci-dessous). Sauf si l'option -t est donnée, elle insère également des éléments A avec des attributs NAME, car les anciens navigateurs ne reconnaissent pas les attributs ID comme ancres cibles. La sortie est écrite sur stdout.

S'il y a un commentaire de la forme


<!--toc-->

ou une paire de commentaires


<!--begin-toc-->
...
<!--end-toc-->

alors le commentaire, ou la paire avec tout ce qui est entre les deux, sera remplacé par une table des matières, consistant en une liste (UL) de liens vers tous les en-têtes du document.

Le texte des en-têtes est copié dans cette table des matières, y compris toute balise en ligne, sauf que les attributs ID, les balises DFN et les balises SPAN avec une CLASSE égale à "index" sont omis (mais le contenu des éléments est copié).

Le texte copié peut éventuellement être "aplatit" au préalable, voir l'option -f.

Si un en-tête a un attribut CLASS dont la valeur (ou l'une de ses valeurs) est le mot-clé "no-toc", alors cet en-tête n'apparaîtra pas dans la table des matières.

OPTIONS

Les options suivantes sont supportées :

-x
Utilise les conventions XML : les éléments vides sont écrits avec une barre oblique à la fin : <IMG />
-l bas
Définit l'en-tête numéroté le plus bas à apparaître dans la table des matières. La valeur par défaut est 1 (c'est-à-dire H1).
-h haut
Définit l'en-tête numéroté le plus haut à apparaître dans la table des matières. La valeur par défaut est illimitée.
-t
Normalement, hxtoc ajoute à la fois des attributs ID et des éléments A vides avec un attribut NAME et CLASS="bctarget", de sorte que les anciens navigateurs qui ne comprennent pas l'ID trouvent toujours la cible. Avec cette option, les éléments A ne seront pas générés.
-c classe
Les éléments UL générés dans la table des matières auront un attribut CLASS avec la valeur classe. La valeur par défaut est "toc".
-d
Tente d'utiliser les éléments de sectionnement comme cibles dans la table des matières au lieu de H1 à H6. Un élément de sectionnement est un élément DIV, SECTION, ARTICLE, ASIDE ou NAV qui contient au moins un élément d'en-tête (H1 à H6) ou HGROUP. L'élément de sectionnement recevra un ID s'il n'en a pas déjà un. Avec cette option, le niveau de tout H1 à H6 qui est le premier en-tête d'un élément de sectionnement n'est pas déterminé par son nom, mais par la profondeur d'imbrication des éléments de sectionnement. (Tout H1 à H6 qui n'est pas le premier en-tête d'un élément de sectionnement voit toujours son niveau déduit de son nom.)
-f
Aplatit le texte de la table des matières. Sans -f, le contenu des éléments d'en-tête est copié dans la table des matières presque inchangé, c'est-à-dire en incluant tous les éléments enfants et leurs attributs (à l'exception des attributs ID, des éléments DFN et de certains éléments SPAN, comme expliqué ci-dessus). Avec -f, le contenu est aplati à la place : tous les éléments enfants sont supprimés et seul leur contenu est copié dans la table des matières. De plus, les éléments avec un attribut ALT, tels que IMG, sont remplacés par le contenu de l'attribut ALT. Exception : les balises BDO sont copiées inchangées et les éléments avec un attribut DIR sont remplacés par un SPAN avec cet attribut DIR. (BDO et DIR peuvent apparaître dans les langues écrites de droite à gauche.)

OPÉRANDES

L'opérande suivant est supporté :

fichier-ou-URL
Le nom ou l'URL d'un fichier HTML. S'il est absent, l'entrée standard est lue à la place.

DIAGNOSTICS

Les valeurs de sortie suivantes sont retournées :

0
Achèvement réussi.
> 0
Une erreur s'est produite lors de l'analyse du fichier HTML. hxtoc essaiera de corriger l'erreur et de produire une sortie quand même.

VOIR AUSSI

asc2xml(1), hxnormalize(1), hxnum(1), xml2asc(1)

BOGUES

La récupération d'erreurs pour le HTML incorrect est primitive.
