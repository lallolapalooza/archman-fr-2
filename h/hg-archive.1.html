hg-archive(1)

Paquet: mercurial

Licences: GPL

HG(ARCHIVE) HG(ARCHIVE)

NOM

hg archive - créer une archive non versionnée d'une révision de dépôt

SYNOPSIS

hg archive [OPTION]... DEST

DESCRIPTION

Par défaut, la révision utilisée est celle du parent du répertoire de travail ; utilisez -r/--rev pour spécifier une révision différente.

Le type d'archive est automatiquement détecté en fonction de l'extension du fichier (pour outrepasser, utilisez -t/--type).

Exemples :

  • créer un fichier zip contenant la release 1.0 : 
    hg archive -r 1.0 projet-1.0.zip
  • créer une archive tar excluant les fichiers .hg : 
    hg archive projet.tar.gz -X ".hg*"

    Les types valides sont :

files

un répertoire contenant des fichiers (par défaut)

tar

archive tar, non compressée

tbz2

archive tar, compressée avec bzip2

tgz

archive tar, compressée avec gzip

txz

archive tar, compressée avec lzma (uniquement dans Python 3)

uzip

archive zip, non compressée

zip

archive zip, compressée avec deflate

Le nom exact de l'archive ou du répertoire de destination est donné en utilisant une chaîne de format ; voir hg help export pour plus de détails.

Chaque membre ajouté à un fichier archive a un préfixe de répertoire qui lui est ajouté. Utilisez -p/--prefix pour spécifier une chaîne de format pour le préfixe. Le préfixe par défaut est le nom de base de l'archive, avec les suffixes supprimés.

Retourne 0 en cas de succès.

OPTIONS

--no-decode
ne pas passer les fichiers par les décodeurs
-p,--prefix <PREFIX>
préfixe de répertoire pour les fichiers dans l'archive
-r,--rev <REV>
révision à distribuer
-t,--type <TYPE>
type de distribution à créer
-S, --subrepos
récursion dans les sous-dépôts
-I,--include <PATTERN[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <PATTERN[+]>
exclure les noms correspondant aux motifs donnés

[+] option marquée pouvant être spécifiée plusieurs fois
