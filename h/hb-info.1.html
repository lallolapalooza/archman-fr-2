NOM

hb-info - page de manuel pour hb-info 12.2.0

DESCRIPTION

Usage :

hb-info [OPTION?] [FICHIER-POLICE]

Interroger les informations de police.

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-face
Options pour la face de police
--help-font
Options pour l'instance de police
--help-variations
Options pour les variations de police utilisées
--help-misc
Options diverses affectant les requêtes
--help-query
Options pour interroger l'instance de police

Options de face de police :

--font-file=nom-fichier
Définir le nom du fichier de police
-y, --face-index=index
Définir l'index de face (par défaut : 0)
--face-loader=chargeur
Définir le chargeur de face à utiliser (par défaut : ot)
Les chargeurs de face pris en charge sont : ot/ft
--list-face-loaders
Lister les chargeurs de face disponibles et quitter

Options d'instance de police :

--font-size=1/2 entiers ou 'upem'
Taille de la police (par défaut : upem)
--font-ppem=1/2 entiers
Définir les pixels x,y par EM (par défaut : 0 ; désactivé)
--font-ptem=taille-point
Définir la taille en points de la police (par défaut : 0 ; désactivé)
--font-bold=1/2 nombres ; par exemple 0.05
Définir le gras synthétique (par défaut : 0)
--font-grade=1/2 nombres ; par exemple 0.05
Définir le grade synthétique (par défaut : 0)
--font-slant=inclinaison ratio ; par exemple 0.2
Définir l'inclinaison synthétique (par défaut : 0)
--font-funcs=impl
Définir l'implémentation des fonctions de police à utiliser (par défaut : ot)
Les implémentations des fonctions de police prises en charge sont : ot/ft
--list-font-funcs
Lister les fonctions de police disponibles et quitter
--ft-load-flags=entier
Définir les drapeaux de chargement FreeType (par défaut : 2)

Options de variations :

--named-instance=index
Définir l'index d'instance nommée (par défaut : aucun)
--variations=liste
Liste séparée par des virgules de variations de police
Les variations sont définies globalement. Le format pour spécifier les réglages de variation suit. Toutes les valeurs CSS valides font-variation-settings à l'exception de 'normal' et 'inherited' sont également acceptées, bien que non documentées ci-dessous.
Le format est une étiquette, suivie éventuellement d'un signe égal, suivi d'un nombre. Par exemple :
"wght=500" "slnt=-7.5"

Options diverses :

--direction=ltr/rtl/ttb/btt
Définir la direction (par défaut : ltr)
--script=étiquette ISO-15924 ; par exemple 'Latn'
Définir le script (par défaut : aucun)
--language=étiquette BCP 47 ; par exemple 'en'
Définir la langue (par défaut : $LANG)
--ot-script=étiquette ; par exemple 'latn'
Définir l'étiquette du script OpenType (par défaut : aucune)
--ot-language=étiquette ; par exemple 'ENG'
Définir l'étiquette de la langue OpenType (par défaut : aucune)

hb-info(1) — HarfBuzz utils

NAME

hb-info — Requête diverses informations d'un fichier de polices

SYNOPSIS

hb-info [options...] [face]

DESCRIPTION

Cette commande interroge un fichier de polices pour diverses informations. Si aucune option de requête n'est spécifiée, l'option --show-all est supposée.

Options de requête :

--list-axes
Lister les axes de variation de la police
--list-palettes
Lister les palettes de couleurs de la police
--list-meta
Lister les métadonnées

Options d'application :

-q, --quiet
Générer une sortie lisible par machine
--version
Afficher les numéros de version

CODES DE SORTIE

0 : Succès.
1 : Échec de l'analyse des options.
2 : Échec du chargement du visage de la police.
4 : Échec de la définition des fonctions de police.

ENVIRONNEMENT

HB_FACE_LOADER=face-loader ; Remplace le chargeur de visage par défaut.
HB_FONT_FUNCS=font-funcs ; Remplace les font-funcs par défaut.

VOIR AUSSI

hb-view(1), hb-shape(1), hb-subset(1), hb-info(1)
