hwlocality_api_error_reporting - Signalement des erreurs dans l'API

SYNTAXE

Description détaillée

La plupart des fonctions de l'API hwloc retournent une valeur entière. Sauf indication contraire, elles retournent 0 en cas de succès et -1 en cas d'erreur. Les fonctions qui retournent un type pointeur retournent NULL en cas d'erreur.

La variable errno sera définie avec une valeur significative chaque fois que possible. Cela inclut les valeurs habituelles EINVAL lorsque des paramètres de fonction invalides sont passés, ou ENOMEM lorsqu'une allocation interne échoue. Certaines valeurs spécifiques de errno sont également utilisées, par exemple pour les erreurs de liaison comme documenté dans Liaison de CPU.

Certains modules décrivent les valeurs de retour de leurs fonctions dans leur introduction, par exemple dans L'API bitmap.
