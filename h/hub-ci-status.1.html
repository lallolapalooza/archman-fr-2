NOM

hub-ci-status - Affiche le statut des vérifications GitHub pour un commit.

SYNTAXE

hub ci-status [-v] [COMMIT]

OPTIONS

-v, --verbose

Imprime un rapport détaillé de toutes les vérifications de statut et de leurs URL.

-f, --format FORMAT

Imprime joliment toutes les vérifications de statut en utilisant FORMAT (implique --verbose). Voir la section "FORMATS DE PRÉSENTATION" de git-log(1) pour des détails supplémentaires sur la façon dont les espaces réservés sont utilisés dans le format. Les espaces réservés disponibles pour les vérifications sont :

%U : l'URL de cette vérification de statut

%S : état de la vérification (par exemple "success", "failure")

%sC : couleur définie sur rouge, vert ou jaune, en fonction de l'état

%t : nom de la vérification de statut

--color[=QUAND]

Active la sortie colorée même si la sortie standard n'est pas un terminal. QUAND peut être l'un des "toujours" (par défaut pour --color), "jamais" ou "auto" (par défaut).

COMMIT

Un SHA de commit ou un nom de branche (par défaut : "HEAD").

Sorties et statuts de sortie possibles :

  • succès, neutre : 0
  • échec, erreur, action_requise, annulé, expiré : 1
  • en attente : 2
