NOM

hub-merge - Fusionne une pull request localement avec un message similaire au bouton de fusion de GitHub.

SYNOPSIS

hub merge URL-PULLREQ

Cela crée un commit de fusion local dans la branche actuelle, mais ne modifie pas réellement l'état de la pull request. Cependant, la pull request sera automatiquement fermée et marquée comme "fusionnée" dès que le nouveau commit de fusion créé sera poussé vers la branche par défaut du dépôt distant.

EXEMPLES

$ hub merge https://github.com/jingweno/gh/pull/73
> git fetch origin refs/pull/73/head
> git merge FETCH_HEAD --no-ff -m "Merge pull request #73 from jingweno/feature..."
