int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t *

diff)

Calcule la différence entre 2 topologies. La différence est stockée sous forme d'une liste d'entrées hwloc_topology_diff_t commençant à diff. Elle est calculée en effectuant simultanément une traversée en profondeur des deux arbres de

topologie.

Si la différence entre 2 objets est trop complexe pour être représentée (par exemple si certains objets ont des types différents, ou des nombres d'enfants différents), une entrée de diff spéciale de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX est mise en file. Le calcul du diff ne continue pas en dessous de ces objets. Ainsi, chaque entrée de diff de ce type signifie que la différence entre deux sous-arbres n'a pas pu être

calculée.
