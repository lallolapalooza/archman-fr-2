NOM

hts - serveur httptunnel

SYNTAXE

hts [options] [port]

DESCRIPTION

Cette page de manuel documente brièvement la commande hts.

hts écoute les connexions entrantes httptunnel sur le PORT (le port par défaut est 8888). Lorsqu'une connexion est établie, les entrées/sorties sont redirigées vers la destination spécifiée par le commutateur --device ou --forward-port.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-h, --help
Affiche le résumé des options.
-c, --content-length OCTETS
utilise des requêtes HTTP PUT de taille OCTETS (les suffixes k, M et G sont reconnus)
-d, --device PÉRIPH
utilise PÉRIPH pour les entrées et les sorties
-F, --forward-port HÔTE:PORT
se connecte au PORT sur HÔTE et l'utilise pour les entrées et les sorties
-k, --keep-alive SECONDES
envoie des octets de maintien de connexion toutes les SECONDES secondes (par défaut 5)
-M, --max-connection-age SEC
la durée maximale pendant laquelle une connexion restera ouverte est de SEC secondes (par défaut 300)
-S, --strict-content-length
écrit toujours les octets Content-Length dans les requêtes
-V, --version
affiche les informations de version et quitte
-p, --pid-file EMPLACEMENT
écrit un fichier PID à EMPLACEMENT
