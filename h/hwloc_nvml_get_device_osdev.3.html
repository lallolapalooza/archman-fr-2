Description détaillée

Cette interface offre des moyens de récupérer des informations topologiques sur les périphériques gérés par la bibliothèque de gestion NVIDIA (NVML).

Documentation des fonctions

int hwloc_nvml_get_device_cpuset (hwloc_topology_t topology, nvmlDevice_t device, hwloc_cpuset_t set) [inline]

Obtenir l'ensemble des processeurs (cpuset) physiquement proches du périphérique NVML device. Stocker dans set l'ensemble de CPU décrivant la localité du périphérique NVML device.

La topologie topology et le périphérique device doivent correspondre à la machine locale. La détection des périphériques d'E/S et le composant NVML ne sont pas nécessaires dans la topologie.

La fonction retourne uniquement la localité du périphérique. Si plus d'informations sur le périphérique sont nécessaires, des objets système devraient être utilisés à la place, voir hwloc_nvml_get_device_osdev() et hwloc_nvml_get_device_osdev_by_index().

Cette fonction n'est actuellement implémentée de manière significative que pour Linux ; les autres systèmes obtiendront simplement un cpuset complet.

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si les informations du périphérique n'ont pas pu être trouvées.

hwloc_obj_t hwloc_nvml_get_device_osdev (hwloc_topology_t topology, nvmlDevice_t device) [inline]

Obtenir l'objet périphérique système (OS device) hwloc correspondant au périphérique NVML device.

Retourne

L'objet périphérique système hwloc décrivant le périphérique NVML donné device.

NULL si aucun n'a pu être trouvé.

La topologie topology et le périphérique device doivent correspondre à la machine locale. La détection des périphériques d'E/S et le composant NVML doivent être activés dans la topologie. Sinon, la localité de l'objet peut toujours être trouvée en utilisant hwloc_nvml_get_device_cpuset().

Note

Le périphérique PCI hwloc correspondant peut être trouvé en examinant le pointeur parent du résultat (sauf si les périphériques PCI sont filtrés).

hwloc_obj_t hwloc_nvml_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtenir l'objet périphérique système hwloc correspondant au périphérique NVML dont l'index est idx.

Retourne

L'objet périphérique système hwloc décrivant le périphérique NVML dont l'index est idx.

NULL si aucun n'a pu être trouvé.

La topologie topology ne doit pas nécessairement correspondre à la machine actuelle. Par exemple, la topologie peut être une importation XML d'un hôte distant. La détection des périphériques d'E/S et le composant NVML doivent être activés dans la topologie.

Note

L'objet périphérique PCI correspondant peut être obtenu en examinant l'objet parent du périphérique système (sauf si les périphériques PCI sont filtrés).
