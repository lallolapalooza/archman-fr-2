hashkit_value(3)

Paquet: libmemcached-awesome

Licences: BSD

HASHKIT_VALUE(3) libmemcached-awesome HASHKIT_VALUE(3)

NOM

hashkit_value - Documentation libhashkit

SYNTAXE

#include <libhashkit-1.0/hashkit.h>
Compiler et lier avec -lhashkit
uint32_t hashkit_value(hashkit_st *hash, const char *key, size_t key_length)
Paramètres
  • hash -- pointeur vers une structure hashkit_st initialisée
  • key -- la clé pour laquelle générer un hash
  • key_length -- la longueur de la key sans aucun octet de fin nul

DESCRIPTION

La fonction hashkit_value() génère une valeur de hash de 32 bits à partir de la clé et de la longueur de clé fournies. L'argument hash est un objet hashkit initialisé, et le type de distribution ainsi que la fonction de hash sont utilisés à partir de cet objet lors de la génération de la valeur.

VALEUR DE RETOUR

Une valeur de hash de 32 bits.
