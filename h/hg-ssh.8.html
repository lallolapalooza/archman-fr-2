NOM

hg-ssh - shell de connexion ssh restreinte pour Mercurial

SYNTAXE

hg-ssh dépôts...

DESCRIPTION

hg-ssh est un wrapper pour l'accès ssh à un ensemble limité de dépôts mercurial.

À utiliser dans ~/.ssh/authorized_keys avec l'option "command", voir sshd(8) : command="hg-ssh chemin/vers/depot1 /chemin/vers/depot2 ~/depot3 ~utilisateur/depot4" ssh-dss ... (probablement avec ces autres options utiles : no-port-forwarding,no-X11-forwarding,no-agent-forwarding)

Cela permet les opérations pull/push via ssh depuis/vers les dépôts donnés en arguments.

Si tous vos dépôts sont des sous-répertoires d'un répertoire commun, vous pouvez autoriser des chemins plus courts avec : command="cd chemin/vers/mes/depots && hg-ssh depot1 depot/repo2"

Vous pouvez utiliser des motifs de votre shell normal, par exemple : command="cd depots && hg-ssh utilisateur/thomas/* projets/{mercurial,foo}"

Vous pouvez également ajouter un indicateur --read-only pour autoriser l'accès en lecture seule à une clé, par exemple : command="hg-ssh --read-only depots/*"
