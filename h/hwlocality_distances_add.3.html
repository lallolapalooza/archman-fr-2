Description

détaillée

La manière habituelle d'ajouter des distances est

: 
hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}

Énumérateur

HWLOC_DISTANCES_ADD_FLAG_GROUP
Tente de grouper les objets en fonction des informations de distance nouvellement fournies. Le groupement n'est effectué que lorsque la structure de distances contient des latences et lorsque tous les objets sont de même
type.
HWLOC_DISTANCES_ADD_FLAG_GROUP_INACCURATE
Lors d'un groupement, considère les valeurs de distance comme imprécises et assouplit les comparaisons pendant les algorithmes de groupement. La précision réelle peut être modifiée via la variable d'environnement HWLOC_GROUPING_ACCURACY (voir Variables

hwloc_distances_add_handle_t hwloc_distances_add_create (hwloc_topology_t topology, const char * name, unsigned long kind, unsigned long

Crée une nouvelle structure de distances vide. Crée une structure de distances vide à remplir avec hwloc_distances_add_values() puis à valider avec hwloc_distances_add

_commit().

Paramètre name est facultatif, il peut valoir NULL. Sinon, il sera copié en interne et pourra ensuite être libéré par

l'appelant.

kind spécifie le type de distance sous la forme d'un ensemble combiné par OR de hwloc_distances_kind_e. Un seul type de signification et un seul type de provenance peuvent être donnés si approprié (par ex. HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH et HWLOC_DISTANCES_KIND_FROM_USER). Le type HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES sera automatiquement défini en fonction des objets ayant des types différents dans hwloc_distances_add_values()

Spécifie les objets et les valeurs dans une nouvelle structure de distances vide. Spécifie les objets et les valeurs pour une nouvelle structure de distances qui a été renvoyée comme poignée par hwloc_distances_add_create(). La structure doit ensuite être validée avec hwloc_distances_add

Le nombre d'objets est nbobjs et le tableau d'objets est objs. Les valeurs de distance sont stockées sous forme d'un tableau à une dimension dans values. La distance de l'objet i à l'objet j se trouve à l'indice
