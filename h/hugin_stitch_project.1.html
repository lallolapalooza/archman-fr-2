NOM

hugin_stitch_project - Assembler un projet hugin

SYNTAXE

hugin_stitch_project [options] [<projet> <images> ...]

DESCRIPTION

Un outil graphique pour assembler un projet hugin unique.

OPTIONS

-h|--help
Afficher le message d'aide
-o|--output=<str>
Préfixe de sortie
-t|--threads=<num>
Nombre de threads
-d|--delete
Supprimer le fichier .pto après assemblage
