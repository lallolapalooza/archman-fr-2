HG(DIFF) HG(DIFF)

NOM

hg diff - diff le dépôt (ou des fichiers sélectionnés)

SYNOPIS

hg diff [OPTION]... ([-c REV] | [--from REV1] [--to REV2]) [FICHIER]...

DESCRIPTION

Affiche les différences entre les révisions pour les fichiers spécifiés.

Les différences entre les fichiers sont affichées en utilisant le format de différence unifiée.

Note
hg diff peut générer des résultats inattendus pour les fusions, car il comparera par défaut avec le premier parent du commit du répertoire de travail si aucune révision n'est spécifiée. Pour différencier les régions de conflit, vous pouvez utiliser --config diff.merge=yes.

Par défaut, les fichiers du répertoire de travail sont comparés à leur premier parent. Pour voir les différences avec une autre révision, utilisez --from. Pour voir la différence avec une autre révision, utilisez --to. Par exemple, hg diff --from .^ affichera les différences entre l'arrière-grand-parent du répertoire de travail et le répertoire de travail, hg diff --to . affichera la différence entre le répertoire de travail et son parent (c'est-à-dire l'inverse de la valeur par défaut), et hg diff --from 1.0 --to 1.2 affichera la différence entre ces deux révisions.

Alternativement, vous pouvez spécifier -c/--change avec une révision pour voir les modifications dans ce commit par rapport à son premier parent (c'est-à-dire que hg diff -c 42 équivaut à hg diff --from 42^ --to 42)

Sans l'option -a/--text, diff évitera de générer des différences pour les fichiers qu'il détecte comme binaires. Avec -a, diff générera une différence de toute façon, probablement avec des résultats indésirables.

Utilisez l'option -g/--git pour générer des différences au format étendu de git. Pour plus d'informations, lisez hg help diffs.

Exemples:

  • comparer un fichier dans le répertoire de travail actuel à son parent : 
    hg diff foo.c
  • comparer deux versions historiques d'un répertoire, avec informations de renommage : 
    hg diff --git --from 1.0 --to 1.2 lib/
  • obtenir des statistiques de modification par rapport à la dernière modification à une certaine date : 
    hg diff --stat --from "date('may 2')"
  • diff les fichiers nouvellement ajoutés contenant un mot-clé : 
    hg diff "set:added() and grep(GNU)"
  • comparer une révision et ses parents : 
    hg diff -c 9353                  # comparer avec le premier parent
hg diff --from 9353^ --to 9353   # identique en utilisant la syntaxe revset
hg diff --from 9353^2 --to 9353  # comparer avec le deuxième parent

    Retourne 0 en cas de succès.

OPTIONS

-r,--rev <REV[+]>
révision (OBSOLÈTE)
--from <REV1>
révision à comparer depuis
--to <REV2>
révision à comparer vers
-c,--change <REV>
changement effectué par la révision
--ignore-changes-from-ancestors
ne comparer que le changement effectué par la révision sélectionnée (EXPÉRIMENTAL)
-a, --text
traiter tous les fichiers comme du texte
-g, --git
utiliser le format de différence étendue de git (PAR DÉFAUT : diff.git)
--binary
générer des différences binaires en mode git (par défaut)
--nodates
omettre les dates des en-têtes de différence
--noprefix
omettre les préfixes a/ et b/ des noms de fichiers
-p, --show-function
afficher la fonction dans laquelle se trouve chaque changement (PAR DÉFAUT : diff.showfunc)
--reverse
produire une différence qui annule les changements
-w, --ignore-all-space
ignorer les espaces lors de la comparaison des lignes
-b, --ignore-space-change
ignorer les changements dans la quantité d'espaces
-B, --ignore-blank-lines
ignorer les changements dont les lignes sont entièrement vides
-Z, --ignore-space-at-eol
ignorer les changements d'espaces en fin de ligne
-U,--unified <NOMBRE>
nombre de lignes de contexte à afficher
--stat
afficher un résumé des changements de type diffstat
--root <RÉPERTOIRE>
produire des différences relatives au sous-répertoire
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-S, --subrepos
récursion dans les sous-dépôts

[+] option marquée peut être spécifiée plusieurs fois
