Documentation du type énuméré

enum hwloc_topology_export_synthetic_flags_e

Indicateurs pour l'exportation de topologies synthétiques. Indicateurs à passer comme un ensemble combiné par OU (OR) à hwloc_topology_export_synthetic().

Énumérateurs

HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_NO_EXTENDED_TYPES
Exporter les types étendus comme L2dcache sous forme de types basiques comme Cache. Ceci est nécessaire si la description synthétique est chargée avec hwloc < 1.9.
HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_NO_ATTRS
Ne pas exporter les attributs de niveau. Ignorer les attributs de niveau comme les tailles de mémoire/cache ou les index des PU. Ceci est nécessaire si la description synthétique est chargée avec hwloc < 1.10.
HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_V1
Exporter la hiérarchie de mémoire comme prévu dans hwloc 1.x. Au lieu d'attacher les enfants mémoire aux niveaux, exporter un seul enfant de nœud NUMA comme niveau intermédiaire normal, lorsque c'est possible. Ceci est nécessaire si la description synthétique est chargée avec hwloc 1.x. Cependant, cela peut échouer si certains objets ont plusieurs nœuds NUMA locaux.
HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_IGNORE_MEMORY
Ne pas exporter les informations mémoire. Exporter uniquement la hiérarchie réelle des objets normaux côté CPU et ignorer où la mémoire est attachée. Ceci est utile lorsque la hiérarchie des CPU est ce qui importe réellement, mais elle se comporte comme s'il y avait un seul nœud NUMA à l'échelle de la machine.

Documentation de la fonction

int hwloc_topology_export_synthetic (hwloc_topology_t topology, char * buffer, size_t buflen, unsigned long flags)

Exporter la topologie sous forme de chaîne synthétique. Au plus buflen caractères seront écrits dans buffer, y compris le terminateur \0.

Cette chaîne exportée peut être redonnée à hwloc_topology_set_synthetic().

flags est un ensemble combiné par OU des hwloc_topology_export_synthetic_flags_e.

Retourne

Le nombre de caractères qui ont été écrits, sans inclure le terminateur \0.

-1 si la topologie n'a pas pu être exportée, par exemple si elle n'est pas symétrique.

Note

Les enfants I/O et divers sont ignorés, la chaîne synthétique ne décrit que les enfants normaux.

Un tampon de 1024 octets devrait être suffisamment grand pour exporter les topologies dans la grande majorité des cas.
