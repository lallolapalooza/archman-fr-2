int hwloc_obj_add_info (hwloc_obj_t obj, const char * name, const char * value)

Ajoute la paire nom et valeur donnée aux attributs d'information de l'objet. La paire d'informations est ajoutée au tableau d'informations existant même si une autre paire portant le même nom existe déjà.

Les chaînes de caractères d'entrée sont copiées avant d'être ajoutées aux informations de l'objet.

Retourne

0 en cas de succès, -1 en cas d'erreur.

Note

Cette fonction peut être utilisée pour forcer les couleurs des objets dans la sortie graphique de lstopo en ajoutant 'lstopoStyle' comme nom et 'Background=#rrggbb' comme valeur. Voir COULEURS PERSONNALISÉES dans la page de manuel de lstopo(1) pour plus de détails.

Si name ou value contiennent des caractères non imprimables, ils seront supprimés lors de l'exportation en XML, voir hwloc_topology_export_xml() dans hwloc/export.h.

const char * hwloc_obj_get_info_by_name (hwloc_obj_t obj, const char * name) [inline]

Recherche le nom donné dans les informations de l'objet et renvoie la valeur correspondante. Si plusieurs attributs d'information correspondent au nom donné, seul le premier est renvoyé.

Retourne

Un pointeur vers la chaîne de valeur si elle existe.

NULL si aucun attribut d'information de ce type n'existe.

Note

La chaîne ne doit pas être libérée par l'appelant, elle appartient à la bibliothèque hwloc.

int hwloc_obj_set_subtype (hwloc_topology_t topology, hwloc_obj_t obj, const char * subtype)

Définit (ou remplace) le sous-type d'un objet. Le sous-type donné est copié en interne, l'appelant est responsable de la libération du sous-type d'origine si nécessaire.

Si un autre sous-type existe déjà dans l'objet, il est remplacé. Le sous-type donné peut être NULL pour supprimer le sous-type existant.

Note

Cette fonction est principalement destinée à initialiser le sous-type d'objets ajoutés par l'utilisateur tels que les groupes avec hwloc_topology_alloc_group_object().

Retourne

0 en cas de succès.

-1 avec errno défini sur ENOMEM en cas d'échec d'allocation de mémoire.
