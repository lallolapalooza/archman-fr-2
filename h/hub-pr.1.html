NOM

hub-pr - Gérer les requêtes Pull GitHub pour le dépôt courant.

SYNTAXE

hub pr list [-s ÉTAT] [-h HEAD] [-b BASE] [-o CLÉ_TRI [-^]] [-f FORMAT] [-L LIMITE]
hub pr checkout NUMÉRO_PR [BRANCHE]
hub pr show [-uc] [-f FORMAT] [-h HEAD]
hub pr show [-uc] [-f FORMAT] NUMÉRO_PR

COMMANDES

list

Liste les requêtes Pull dans le dépôt courant.

checkout

Extrait le head d'une requête Pull dans une nouvelle branche.

Pour mettre à jour la requête Pull avec de nouveaux commits, utilisez git push.

show

Ouvre une page de requête Pull dans un navigateur web. Lorsqu'aucun NUMÉRO_PR n'est spécifié, HEAD est utilisé pour rechercher les requêtes Pull ouvertes et prend par défaut le nom de la branche courante. Avec --format, affiche les informations sur la requête Pull au lieu de l'ouvrir.

OPTIONS

-s, --state ÉTAT

Filtre les requêtes Pull par ÉTAT. Les valeurs supportées sont : "open" (par défaut), "closed", "merged", ou "all".

-h, --head BRANCHE

Affiche les requêtes Pull démarrées depuis la BRANCHE spécifiée. Le format "PROPRIÉTAIRE:BRANCHE" doit être utilisé pour les requêtes Pull provenant de forks.

-b, --base BRANCHE

Affiche les requêtes Pull basées sur la BRANCHE spécifiée.

-f, --format FORMAT

Imprime joliment la liste des requêtes Pull en utilisant le format FORMAT (par défaut : "%pC%>(8)%i%Creset %t% l%n"). Consultez la section "FORMATS DE PRÉSENTATION" de git-log(1) pour quelques détails supplémentaires sur l'utilisation des espaces réservés dans le format. Les espaces réservés disponibles sont :

%I: numéro de la requête Pull

%i: numéro de la requête Pull préfixé par "#"

%U: l'URL de cette requête Pull

%S: état ("open" ou "closed")

%pS: état de la requête Pull ("open", "draft", "merged", ou "closed")

%sC: définit la couleur en rouge ou vert, selon l'état

%pC: définit la couleur selon l'état de la requête Pull

%t: titre

%l: étiquettes colorées

%L: étiquettes brutes, séparées par des virgules

%b: corps

%B: branche de base

%sB: SHA du commit de base

%H: branche head

%sH: SHA du commit head

%sm: SHA du commit de fusion

%au: nom de connexion de l'auteur

%as: liste d'assignés séparés par des virgules

%rs: liste de réviseurs demandés séparés par des virgules

%Mn: numéro de jalon

%Mt: titre du jalon

%cD: date de création (sans l'heure)

%cr: date de création, relative

%ct: date de création, timestamp UNIX

%cI: date de création, format ISO 8601

%uD: date de mise à jour (sans l'heure)

%ur: date de mise à jour, relative

%ut: date de mise à jour, timestamp UNIX

%uI: date de mise à jour, format ISO 8601

%mD: date de fusion (sans l'heure)

%mr: date de fusion, relative

%mt: date de fusion, timestamp UNIX

%mI: date de fusion, format ISO 8601

%n: nouvelle ligne

%%: un signe % littéral

--color[=QUAND]

Active la sortie colorée même si la sortie standard n'est pas un terminal. QUAND peut être l'une des valeurs suivantes : "always" (par défaut pour --color), "never", ou "auto" (par défaut).

-o, --sort CLÉ

Trie les requêtes Pull affichées par "created" (par défaut), "updated", "popularity", ou "long-running".

-^, --sort-ascending

Trie par dates croissantes au lieu de décroissantes.

-L, --limit LIMITE

Affiche seulement les LIMITE premières requêtes Pull.

-u, --url

Imprime l'URL de la requête Pull au lieu de l'ouvrir.

-c, --copy

Place l'URL de la requête Pull dans le presse-papiers au lieu de l'ouvrir.
