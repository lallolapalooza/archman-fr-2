HTAGS(1) Manuel des commandes générales HTAGS(1)

NOM

htags - générer un hypertexte à partir d'un ensemble de fichiers source

SYNTAXE

htags [-aDfFghInosTvw][-d chemin_base_de_données][-m nom][-t titre][répertoire]

DESCRIPTION

Htags génère un hypertexte à partir d'un ensemble de fichiers source C, Yacc, Java, PHP et assembleur.

Avant d'utiliser cette commande, vous devez exécuter gtags(1) dans le répertoire racine d'un projet source. Vous pouvez ensuite exécuter htags au même endroit. Htags crée un répertoire nommé « HTML« , et y place un hypertexte. Vous pouvez commencer la navigation à partir de « HTML/index.html« .

Comme htags génère un hypertexte statique tant que ni l'option -D ni l'option -f ne sont spécifiées, vous pouvez le déplacer où vous voulez et le parcourir avec n'importe quel navigateur sans aucun serveur HTTP. Si vous utilisez l'option -D ou -f, vous devez utiliser un serveur HTTP. Bien que n'importe quel serveur HTTP soit disponible, htags-server(1) est recommandé.

Cette commande possède de nombreuses options. Si vous débutez avec htags, il est recommandé d'utiliser l'option --suggest. Avec cette option, htags choisit des options populaires en votre nom.

OPTIONS

Les options suivantes sont disponibles :

-a, --alphabet
Crée un index alphabétique adapté à un grand projet.
--auto-completion[=limite]
Active la fonction d'auto-complétion pour le formulaire de saisie. Si limite est spécifié, le nombre de candidats est limité à cette valeur. Veuillez noter que cette fonction nécessite le langage javascript dans votre navigateur.
-C, --directory répertoire
Change le répertoire avant de réaliser tout le travail, y compris l'analyse des paramètres.
--caution
Affiche un message d'avertissement sur la page d'accueil.
--cflow fichier_cflow
Ajoute un arbre d'appels par cflow(1). fichier_cflow doit être au format posix. Si vous utilisez cflow GNU, invoquez la commande à la racine du projet avec l'option --format=posix. Cette option est obsolète ; utilisez plutôt --call-tree ou --callee-tree.
--call-tree fichier_appels
Ajoute un arbre d'appels par cflow(1) ; fichier_appels doit être au format posix. Si vous utilisez cflow GNU, invoquez la commande à la racine du projet avec l'option --format=posix.
--callee-tree fichier_appeles
Ajoute un arbre d'appelés par cflow(1) ; fichier_appelés doit être au format posix. Si vous utilisez cflow GNU, invoquez la commande à la racine du projet avec les options --format=posix et --reverse.
--colorize-warned-line
Utilise la couleur pour mettre en évidence les lignes averties.
--cvsweb url
Ajoute un lien vers cvsweb ; url est utilisé comme base de l'URL. Lorsque le répertoire « CVS«  existe à la racine du projet, le contenu de « CVS/Repository«  est utilisé comme chemin relatif à partir de la base.
--cvsweb-cvsroot cvsroot
Spécifie cvsroot dans l'URL cvsweb.
-D, --dynamic
Génère une liste de tags dynamiquement en utilisant un programme CGI. Bien que cette option réduise à la fois la taille et le temps de génération de l'hypertexte, vous devez démarrer un serveur HTTP.
-d, --dbpath chemin_base_de_données
Spécifie le répertoire dans lequel se trouve « GTAGS« . La valeur par défaut est le répertoire courant.
--disable-grep
Désactive grep dans le formulaire de recherche (-f, --form).
--disable-idutils
Désactive idutils dans le formulaire de recherche (-f, --form).
-F, --frame
Utilise des cadres pour la page d'accueil.
-f, --form
Ajoute un formulaire de recherche utilisant un programme CGI. Vous devez démarrer un serveur HTTP pour cela.
--fixed-guide
Place un guide fixe en bas de l'écran du navigateur.
--full-path
Utilise le nom de chemin complet dans l'index des fichiers. Par défaut, utilise seulement le dernier composant du chemin.
-g, --gtags
Exécute gtags(1) avant de commencer le travail. Les options -v, -w et chemin_base_de_données sont passées à gtags.
--gtagsconf fichier
Définit la variable d'environnement GTAGSCONF sur fichier.
--gtagslabel label
Définit la variable d'environnement GTAGSLABEL sur label.
-h, --func-header[=position]
Insère un en-tête de fonction pour chaque fonction. Par défaut, htags ne les génère pas. Vous pouvez choisir la position en utilisant position, qui permet l'une des valeurs « before« , « right«  ou « after«  (par défaut).
--help
Affiche un message d'utilisation.
--html-header fichier
Insère un enregistrement d'en-tête dérivé de fichier dans l'en-tête HTML de chaque fichier.
-I, --icon
Utilise des icônes au lieu de texte pour certains liens.
--insert-footer fichier
Insère un pied de page personnalisé dérivé de fichier avant la balise </body>.
--insert-header fichier
Insère un en-tête personnalisé dérivé de fichier après la balise <body>.
--item-order spécification
Spécifie l'ordre des éléments sur la page d'accueil. La spécification est une chaîne composée des signes d'éléments dans l'ordre. Chaque signe signifie ce qui suit : « c« : avertissement ; « s« : formulaire de recherche ; « m« : fonctions principales ; « d« : définitions ; « f« : fichiers ; « t« : arbre d'appels. Par défaut, c'est « csmdf« .
-m, --main-func nom
Spécifie le nom de la fonction de démarrage ; par défaut, c'est « main« .
--map-file
Génère le fichier « MAP« .
-n, --line-number[=colonnes]
Affiche les numéros de ligne. Par défaut, ne les affiche pas. La valeur par défaut de colonnes est 4.
--no-order-list
Les numéros ne sont pas donnés sous forme de liste.
-o, --other
Inclut non seulement les fichiers source mais aussi d'autres fichiers pour l'index des fichiers.
-s, --symbol
Crée des ancres non seulement pour les définitions et les références, mais aussi pour d'autres symboles.
--show-position
Affiche la chaîne de position par définition de fonction. La chaîne peut être interprétée par les éditeurs généraux sous UNIX. La valeur par défaut est false.
--statistics
Affiche des informations statistiques.
--suggest
Htags choisit des options populaires pour les débutants. C'est équivalent à -aghInosTxv --show-positi

--suggest2
Htags choisit des options populaires pour les débutants. Cette option active les fonctionnalités de cadre, AJAX et CGI en plus des fonctionnalités par --suggest option. C'est équivalent à --suggest -DfF --auto-completion --tree-view=filetree maintenant.
-T, --table-flist[=rows]
Utilise la balise <table> pour afficher l'index des fichiers. Vous pouvez spécifier le nombre de lignes en option ; la valeur par défaut est 5.
-t, --title title
Titre de l'hypertexte. La valeur par défaut est le dernier composant du chemin du répertoire courant.
--tabs cols
Arrêts de tabulation. La valeur par défaut est 8.
--table-list
Utilise la balise <table> pour afficher la liste des tags.
--tree-view[=type]
Utilise une vue en arbre pour l'index des fichiers. Veuillez noter que cette fonction nécessite le langage javascript dans votre navigateur. Les valeurs possibles de type sont les suivantes : treeview, filetree, treeview-red, treeview-black, treeview-gray, treeview-famfamfam. La valeur par défaut est treeview.
-v, --verbose
Mode verbeux.
--version
Affiche le numéro de version.
-w, --warning
Affiche les messages d'avertissement.
dir
Le répertoire dans lequel le résultat de cette commande est stocké. La valeur par défaut est le répertoire courant.

EXEMPLES

$ gtags -v
$ htags -sanohITvt 'Welcome to XXX source tour!'
$ firefox HTML/index.html
$ htags --suggest2
$ htags-server >& log &
$ firefox http://127.0.0.1:8000

FICHIERS

´GTAGS´
Fichier de tags pour les définitions.
´GRTAGS´
Fichier de tags pour les références.
´GPATH´
Fichier de tags pour les fichiers source.
´gtags.conf´, ´$HOME/.globalrc´
Données de configuration pour GNU Global. Voir gtags.conf(5).
´HTML/FILEMAP´
Fichier de correspondance pour convertir un nom de fichier en chemin du fichier.
´HTML/GTAGSROOT´
Si ce fichier existe, le programme CGI ´global.cgi´ définit la variable d'environnement GTAGSROOT avec son contenu. Si vous déplacez le répertoire ´HTML´ de son emplacement d'origine, veuillez créer ce fichier.
´HTML/.htaccess´
Fichier de configuration local pour Apache. Ce fichier est généré lorsque les -f ou -D options sont spécifiées.
´HTML/index.html´
Fichier de démarrage.
´HTML/MAP´
Fichier de correspondance pour convertir un nom de tag en chemin de la liste des tags.
´HTML/style.css´
Fichier de feuille de style.
´/usr/local/share/gtags/style.css.tmpl´
Le modèle du fichier de feuille de style (´HTML/style.css´).

ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution de htags:

GTAGSCACHE
La taille du cache B-tree. La valeur par défaut est 50000000 (octets).
GTAGSCONF
Fichier de configuration.
GTAGSLABEL
Étiquette de configuration. La valeur par défaut est ´default´.
HTAGS_OPTIONS
La valeur de cette variable est insérée au début des arguments.
TMPDIR
L'emplacement utilisé pour stocker les fichiers temporaires. La valeur par défaut est ´/tmp´.
GTAGSFORCECPP
Si cette variable est définie, chaque fichier dont le suffixe est ´.h´ est traité comme un fichier source C++.

CONFIGURATION

Les variables de configuration suivantes affectent l'exécution de htags:

datadir(string)
Répertoire de données partagé. La valeur par défaut est ´/usr/local/share´ mais vous pouvez changer la valeur en utilisant le script configure. Htags recherche les fichiers de modèle dans le répertoire ´gtags´ de ce répertoire de données.
include_file_suffixes(liste séparée par des virgules)
Suffixes des fichiers d'inclusion. La valeur par défaut est :
´h,hh,hxx,hpp,H,inc.php´.
langmap(liste séparée par des virgules)
Correspondance de langage. Chaque correspondance séparée par des virgules se compose du nom du langage, d'un deux-points et d'une liste d'extensions de fichiers. La correspondance par défaut est :
´c:.c.h,yacc:.y,asm:.s.S,java:.java,cpp:.c++.cc.hh.cpp.cxx.hxx.hpp.C.H,php:.php.php3.phtml´.

DIAGNOSTICS

Htags se termine avec une valeur non nulle si une erreur s'est produite, 0 sinon.

BOGUES

L'hypertexte généré est TRÈS VOLUMINEUX. Vérifiez à l'avance l'espace de votre disque.

Le support PHP est loin d'être complet.

Les -f et -D options génèrent des programmes CGI. Si vous ouvrez l'hypertexte au public, veuillez reconnaître les dangers de sécurité.

Htags ne supporte pas les analyseurs en plug-in.
