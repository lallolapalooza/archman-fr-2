NOM

hg export - exporter l'en-tête et les différences pour un ou plusieurs changesets

SYNOPSIS

hg export [OPTION]... [-o OUTFILESPEC] [-r] [REV]...

DESCRIPTION

Imprime l'en-tête du changeset et les différences pour une ou plusieurs révisions. Si aucune révision n'est donnée, le parent du répertoire de travail est utilisé.

Les informations affichées dans l'en-tête du changeset sont : auteur, date, nom de la branche (si non par défaut), hachage du changeset, parent(s) et commentaire de commit.

Note
hg export peut générer des résultats de différences inattendus pour les changesets de fusion, car il comparera le changeset de fusion uniquement à son premier parent.

La sortie peut être dirigée vers un fichier, auquel cas le nom du fichier est donné à l'aide d'une chaîne de modèle. Voir hg help templates. En plus des mots-clés de modèle courants, les règles de formatage suivantes sont prises en charge :

%%

caractère "%" littéral

%H

hachage du changeset (40 chiffres hexadécimaux)

%N

nombre de patchs générés

%R

numéro de révision du changeset

%b

nom de base du dépôt exporté

%h

hachage du changeset en forme courte (12 chiffres hexadécimaux)

%m

première ligne du message de commit (uniquement les caractères alphanumériques)

%n

numéro de séquence complété par des zéros, commençant à 1

%r

numéro de révision du changeset complété par des zéros

\

caractère "\" littéral

Sans l'option -a/--text, export évitera de générer des différences pour les fichiers qu'il détecte comme binaires. Avec -a, export générera quand même une différence, probablement avec des résultats indésirables.

Avec -B/--bookmark, les changesets joignables par le marqueur donné sont sélectionnés.

Utilisez l'option -g/--git pour générer les différences au format étendu des différences git. Voir hg help diffs pour plus d'informations.

Avec l'option --switch-parent, la différence sera effectuée par rapport au deuxième parent. Cela peut être utile pour examiner une fusion.

Modèle :

Les mots-clés suivants sont pris en charge en plus des mots-clés et fonctions de modèle courants. Voir également hg help templates.

diff
Chaîne de caractères. Contenu des différences.
parents
Liste de chaînes de caractères. Nœuds parents du changeset.

Exemples :

  • utiliser export et import pour transplanter un correctif sur la branche actuelle : 
    hg export -r 9353 | hg import -
  • exporter tous les changesets entre deux révisions vers un fichier avec des informations de renommage : 
    hg export --git -r 123:150 > changes.txt
  • diviser les modifications sortantes en une série de patchs avec des noms descriptifs : 
    hg export -r "outgoing()" -o "%n-%m.patch"

    Retourne 0 en cas de succès.

OPTIONS

-B,--bookmark <BOOKMARK>
exporter les changements uniquement joignables par le marqueur donné
-o,--output <FORMAT>
imprimer la sortie dans un fichier avec un nom formaté
--switch-parent
diff par rapport au deuxième parent
-r,--rev <REV[+]>
révisions à exporter
-a, --text
traiter tous les fichiers comme du texte
-g, --git
utiliser le format de différence étendu git (PAR DÉFAUT : diff.git)
--binary
générer des différences binaires en mode git (par défaut)
--nodates
omettre les dates des en-têtes de différence
-T,--template <TEMPLATE>
afficher avec un modèle

[+] L'option marquée peut être spécifiée plusieurs fois
