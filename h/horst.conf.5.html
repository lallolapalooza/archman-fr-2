HORST.CONF(5) Manuel des formats de fichiers HORST.CONF(5)

NOM

horst.conf - fichier de configuration pour horst(8)

SYNTAXE

/etc/horst.conf

DESCRIPTION

Le fichier /etc/horst.conf est le fichier de configuration par défaut. Le fichier de configuration se compose de zéro ligne ou plus. Chaque ligne doit être soit VIDE, COMMENTAIRE, soit OPTION et doit se terminer par un caractère de nouvelle ligne ('\n', ASCII 0xa).

Les lignes VIDE doivent contenir zéro espace ou plus (' ', ASCII 0x20).

Les lignes de COMMENTAIRE doivent commencer par un signe dièse ('#', ASCII 0x23).

Les lignes d'OPTION doivent être sous la forme suivante :

option[=valeur]

Les options et leurs valeurs acceptables sont décrites ci-dessous dans la section OPTIONS.

Les lignes ne correspondant pas au format décrit ci-dessus provoqueront la sortie de horst avec un statut différent de zéro.

OPTIONS

canal=NUMERO_DE_CANAL
Définit le numéro de canal initial sur lequel horst accorde la radio au démarrage.
duree_canal=MILLISECONDES
Définit le temps pendant lequel horst balaie chaque canal lorsque channel_scan=1 est défini.
balayage_canal
Fait en sorte que horst change/balaye les canaux automatiquement par ordre numérique croissant.
tours_balayage_canal=N
Définit le nombre de tours pendant lesquels horst balaie la plage de canaux lorsque channel_scan=1 est défini. Lorsque N est atteint, horst se termine avec un statut zéro. Si N est un nombre négatif, horst balaie la plage de canaux à l'infini.
canal_superieur=NUMERO_DE_CANAL
Définit le canal le plus élevé auquel horst accèdera lorsque channel_scan=1 est défini. Lorsque NUMERO_DE_CANAL est atteint, le canal suivant sera 1.
client=ADRESSE_SERVEUR
Exécute horst en mode client et se connecte à un serveur exécuté sur ADRESSE_SERVEUR.
tube_controle=CHEMIN_FICHIER
Accepte les commandes de contrôle sur un tube nommé.
intervalle_affichage=MILLISECONDES
Définit l'intervalle de rafraîchissement de l'affichage de l'interface utilisateur. Cette option peut être utilisée pour réduire la charge CPU en utilisant des intervalles plus longs.
vue_affichage=historique|essid|statistiques|spectre
Définit la vue d'affichage initiale.
filtrer_bssid=BSSID[,BSSID]...
Ignore tous les paquets sauf ceux appartenant à BSSID.
filtrer_mac=ADRESSE_MAC[,ADRESSE_MAC]...
Ignore tous les paquets sauf ceux provenant de ADRESSE_MAC.
filtrer_mode=MODE[,MODE]...
Ignore tous les paquets/nœuds sauf ceux de mode MODE.
filtrer_paquet=TYPE_PAQUET[,TYPE_PAQUET]...
Ignore tous les paquets sauf ceux de type TYPE_PAQUET.
interface=NOM_INTERFACE
Définit l'interface sans fil que horst utilise pour surveiller le spectre radio. Si l'interface NOM_INTERFACE n'est pas déjà en mode moniteur au démarrage, horst essaie d'abord de mettre l'interface en mode moniteur et si cela échoue, une interface moniteur virtuelle temporaire est ajoutée et utilisée à la place. Le nom de l'interface moniteur virtuelle temporaire est sous la forme horst[0-9]+. L'interface virtuelle créée par horst est supprimée à la sortie.
ajouter_moniteur
Ajoute toujours une interface moniteur virtuelle. N'essaie pas de mettre une interface existante en mode moniteur.
noms_mac=CHEMIN_FICHIER
Le fichier contenant une correspondance entre les adresses MAC et les noms d'hôtes. Le fichier peut être un fichier dhcp.leases de dnsmasq ou contenir des correspondances sous la forme "MAC<espace>nom" (par exemple : "00:01:02:03:04:05 test") ligne par ligne.
delai_noeud=SECONDES
Définit le temps après lequel les nœuds seront supprimés s'ils n'ont reçu aucun paquet.
fichier_sortie=CHEMIN_FICHIER
Écrit les informations sur chaque paquet reçu dans CHEMIN_FICHIER.
port=NUMERO_PORT
Définit le port sur lequel horst écoute lorsqu'il est exécuté en mode serveur ou le port auquel horst se connecte lorsqu'il est exécuté en mode client.
silencieux

Rend horst moins verbeux et supprime l'interface utilisateur.
tampon_reception=OCTETS
Définit la taille du tampon de réception. Cette option peut être utilisée pour ajuster la consommation de mémoire et réduire la perte de paquets en cas de forte charge.
serveur

Exécute horst en mode serveur.
