NOM

hub-fetch - Ajoute les dépôts distants manquants avant d'effectuer un git fetch.

SYNTAXE

hub fetch UTILISATEUR[,UTILISATEUR2...]

EXEMPLES

$ hub fetch --multiple jingweno mislav
> git remote add jingweno git://github.com/jingweno/REPO.git
> git remote add mislav git://github.com/mislav/REPO.git
> git fetch jingweno
> git fetch mislav
