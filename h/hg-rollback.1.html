NOM

hg rollback - annule la dernière transaction (DANGEREUX) (OBSOLÈTE)

SYNOPIS

hg rollback

DESCRIPTION

Veuillez utiliser hg commit --amend plutôt que rollback pour corriger les erreurs dans le dernier commit.

Cette commande doit être utilisée avec précaution. Il n'y a qu'un seul niveau d'annulation, et il n'y a aucun moyen d'annuler une annulation. Elle restaurera également l'état du répertoire au moment de la dernière transaction, perdant ainsi toute modification de l'état du répertoire depuis ce moment. Cette commande ne modifie pas le répertoire de travail.

Les transactions sont utilisées pour encapsuler les effets de toutes les commandes qui créent de nouveaux ensembles de changements ou propagent des ensembles de changements existants dans un dépôt.

Par exemple, les commandes suivantes sont transactionnelles, et leurs effets peuvent être annulés :

  • commit
  • import
  • pull
  • push (avec ce dépôt comme destination)
  • unbundle

    Pour éviter une perte de données permanente, rollback refusera d'annuler une transaction de commit si elle n'est pas extraite. Utilisez --force pour outrepasser cette protection.

    La commande rollback peut être entièrement désactivée en réglant le paramètre de configuration ui.rollback sur false. Si vous êtes ici parce que vous voulez utiliser rollback et qu'elle est désactivée, vous pouvez réactiver la commande en réglant ui.rollback sur true.

    Cette commande n'est pas destinée à être utilisée sur des dépôts publics. Une fois que les modifications sont visibles pour le téléchargement par d'autres utilisateurs, l'annulation d'une transaction localement est inefficace (quelqu'un d'autre a peut-être déjà téléchargé les modifications). De plus, une condition de concurrence est possible avec les lecteurs du dépôt ; par exemple, un téléchargement en cours depuis le dépôt peut échouer si une annulation est effectuée.

    Retourne 0 en cas de succès, 1 si aucune donnée d'annulation n'est disponible.

OPTIONS

-n, --dry-run
ne pas effectuer d'actions, juste afficher la sortie
-f, --force
ignorer les mesures de sécurité
