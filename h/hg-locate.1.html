NOM

hg locate - localiser les fichiers correspondant à des motifs spécifiques (OBSOLÈTE)

SYNTAXE

hg locate [OPTION]... [MOTIF]...

DESCRIPTION

Affiche les fichiers sous contrôle de Mercurial dans le répertoire de travail dont les noms correspondent aux motifs donnés.

Par défaut, cette commande recherche dans tous les répertoires du répertoire de travail. Pour rechercher uniquement dans le répertoire courant et ses sous-répertoires, utilisez "--include .".

Si aucun motif n'est donné pour correspondre, cette commande affiche les noms de tous les fichiers sous contrôle de Mercurial dans le répertoire de travail.

Si vous souhaitez passer la sortie de cette commande à la commande "xargs", utilisez l'option -0 à la fois pour cette commande et pour "xargs". Cela évitera le problème où "xargs" traite des noms de fichiers uniques contenant des espaces comme plusieurs noms de fichiers.

Consultez hg help files pour une commande plus polyvalente.

Retourne 0 si une correspondance est trouvée, 1 sinon.

OPTIONS

-r,--rev <REV>
rechercher dans le dépôt tel qu'il est dans REV
-0, --print0
terminer les noms de fichiers par NUL, pour utilisation avec xargs
-f, --fullpath
afficher les chemins complets depuis la racine du système de fichiers
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés

[+] l'option marquée peut être spécifiée plusieurs fois
