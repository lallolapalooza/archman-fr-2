Description détaillée

Cette interface offre des moyens de récupérer des informations de topologie sur les périphériques gérés par l'API Level Zero, à la fois pour les périphériques Core principaux (API ZE) et les périphériques Sysman (API ZES).

Documentation des fonctions

int hwloc_levelzero_get_device_cpuset (hwloc_topology_t topology, ze_device_handle_t device, hwloc_cpuset_t set) [inline]

Obtenir l'ensemble de CPU des processeurs logiques physiquement proches du périphérique Level Zero device. Stocker dans set l'ensemble de CPU décrivant la localité du périphérique Level Zero device.

La topologie topology et le périphérique device doivent correspondre à la machine locale. La bibliothèque Level Zero doit avoir été initialisée avec zeInit(). La détection des périphériques d'E/S et le composant Level Zero ne sont pas nécessaires dans la topologie.

La fonction ne renvoie que la localité du périphérique. Si plus d'informations sur le périphérique sont nécessaires, les objets système d'exploitation devraient être utilisés à la place, voir hwloc_levelzero_get_device_osdev().

Cette fonction n'est actuellement implémentée de manière significative que pour Linux ; les autres systèmes obtiendront simplement un cpuset complet.

Renvoie

0 en cas de succès.

-1 en cas d'erreur, par exemple si les informations sur le périphérique n'ont pas pu être trouvées.

Remarque

zeDevicePciGetPropertiesExt() doit être pris en charge, sinon la localité de toute la machine sera renvoyée.

hwloc_obj_t hwloc_levelzero_get_device_osdev (hwloc_topology_t topology, ze_device_handle_t device) [inline]

Obtenir l'objet périphérique du système d'exploitation hwloc correspondant au périphérique Level Zero device.

Renvoie

L'objet périphérique du système d'exploitation hwloc qui décrit le périphérique Level Zero devicedonné.

NULL si aucun n'a pu être trouvé.

La topologie topology et le périphérique dv_ind doivent correspondre à la machine locale. La bibliothèque Level Zero doit avoir été initialisée avec zeInit(). La détection des périphériques d'E/S et le composant Level Zero doivent être activés dans la topologie. Sinon, la localité de l'objet peut toujours être trouvée en utilisant hwloc_levelzero_get_device_cpuset().

Remarque

Si le périphérique ZE d'entrée est en fait un sous-périphérique, alors son parent (périphérique racine) est en fait traduit, c'est-à-dire que le périphérique du système d'exploitation hwloc principal est renvoyé au lieu de l'un de ses enfants.

Le périphérique PCI hwloc correspondant peut être trouvé en examinant le pointeur parent du résultat (sauf si les périphériques PCI sont filtrés).

zeDevicePciGetPropertiesExt() doit être pris en charge.
