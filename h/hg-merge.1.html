NOM

hg merge - fusionner une autre révision dans le répertoire de travail

SYNTAXE

hg merge [-P] [[-r] REV]

DESCRIPTION

Le répertoire de travail actuel est mis à jour avec toutes les modifications apportées dans la révision demandée depuis la dernière révision ancêtre commune. Les fichiers qui ont été modifiés entre les deux parents sont marqués comme modifiés pour le prochain commit, et un commit doit être effectué avant toute autre mise à jour du dépôt. Le prochain commit aura deux parents.

--tool peut être utilisé pour spécifier l'outil de fusion utilisé pour les fusions de fichiers. Il remplace la variable d'environnement HGMERGE et vos fichiers de configuration. Voir hg help merge-tools pour les options.

Si aucune révision n'est spécifiée, si le parent du répertoire de travail est une révision principale (head), et si la branche actuelle ne contient qu'une seule autre révision principale, alors cette autre révision principale est fusionnée par défaut. Sinon, une révision explicite avec laquelle fusionner doit être fournie.

Voir hg help resolve pour des informations sur la gestion des conflits de fichiers.

Pour annuler une fusion non commitée, utilisez hg merge --abort qui vérifiera une copie propre du parent de fusion original, perdant ainsi toutes les modifications.

Retourne 0 en cas de succès, 1 s'il y a des fichiers non résolus.

OPTIONS

-f, --force
forcer une fusion incluant les modifications en cours (OBSOLÈTE)
-r,--rev <REV>
révision à fusionner
-P, --preview
examiner les révisions à fusionner (aucune fusion n'est effectuée)
--abort
annuler la fusion en cours
-t,--tool <TOOL>
spécifier l'outil de fusion
