Description détaillée

Hwloc utilise des bitmaps pour représenter deux types distincts d'ensembles d'objets : les ensembles de processeurs (hwloc_cpuset_t) et les ensembles de nœuds NUMA (hwloc_nodeset_t). Ces types sont tous deux des typedefs vers un type de stockage commun (hwloc_bitmap_t), et par conséquent toutes les fonctions de bitmap de hwloc sont applicables à la fois à hwloc_cpuset_t et à hwloc_nodeset_t (voir L'API des bitmaps).

La raison d'être de ces deux types distincts est que, bien que les actions que l'on souhaite effectuer sur ces types soient les mêmes (par exemple, activer et désactiver des éléments individuels dans l'ensemble/masque), ils sont utilisés dans des contextes très différents : l'un pour spécifier quels processeurs utiliser et l'autre pour spécifier quels nœuds NUMA utiliser. Par conséquent, la différence de nom reflète simplement l'intention de l'endroit où le type est utilisé.

Un hwloc_nodeset_t non modifiable.

typedef hwloc_bitmap_t hwloc_cpuset_t

Un ensemble de processeurs est une bitmap dont les bits sont définis selon les index OS physiques des processeurs. Il peut être consulté et modifié avec l'API de bitmaps comme toute autre hwloc_bitmap_t (voir hwloc/bitmap.h).

Chaque bit peut être converti en objet PU en utilisant hwloc_get_pu_obj_by_os_index().

typedef hwloc_bitmap_t hwloc_nodeset_t

Un ensemble de nœuds est une bitmap dont les bits sont définis selon les index OS physiques des nœuds mémoire NUMA. Il peut être consulté et modifié avec l'API de bitmaps comme toute autre hwloc_bitmap_t (voir hwloc/bitmap.h). Chaque bit peut être converti en objet de nœud NUMA en utilisant hwloc_get_numanode_obj_by_os_index().

Lors de la liaison de la mémoire sur un système sans aucun nœud NUMA, la seule banque de mémoire principale est considérée comme le nœud NUMA n°0.

Voir aussi Conversion entre ensembles de processeurs et ensembles de nœuds.
