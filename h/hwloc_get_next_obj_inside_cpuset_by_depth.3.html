hwloc_obj_t hwloc_get_first_largest_obj_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set) [inline]

Obtenir le premier objet le plus grand inclus dans le jeu de CPU spécifié set.

Retourne

le premier objet inclus dans set et dont le parent ne l'est pas.

NULL s'il n'existe pas un tel objet.

Ceci est pratique pour itérer sur tous les objets les plus grands à l'intérieur d'un jeu de CPU en utilisant une boucle qui récupère le premier objet le plus grand et efface son jeu de CPU du jeu de CPU restant.

int hwloc_get_largest_objs_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t *restrict objs, int max)

Obtenir l'ensemble des objets les plus grands couvrant exactement un jeu de CPU donné set.

Retourne

le nombre d'objets retournés dans objs.

-1 si aucun ensemble d'objets ne peut couvrir ce jeu de CPU.

unsigned hwloc_get_nbobjs_inside_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth) [inline]

Retourne le nombre d'objets à la profondeur depth inclus dans le jeu de CPU set.

Retourne

le nombre d'objets.

0 si la profondeur est invalide.

Note

Les objets avec des jeux de CPU vides sont ignorés (sinon ils seraient considérés comme inclus dans n'importe quel jeu donné).

Cette fonction ne peut pas fonctionner si les objets à la profondeur donnée n'ont pas de jeux de CPU (objets d'E/S ou divers).

int hwloc_get_nbobjs_inside_cpuset_by_type (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type) [inline]

Retourne le nombre d'objets de type type inclus dans le jeu de CPU set.

Retourne

le nombre d'objets.

0 s'il n'y a pas d'objets de ce type dans la topologie.

-1 s'il y a plusieurs niveaux d'objets de ce type, l'appelant doit se rabattre sur hwloc_get_nbobjs_inside_cpuset_by_depth().

Note

Les objets avec des jeux de CPU vides sont ignorés (sinon ils seraient considérés comme inclus dans n'importe quel jeu donné).

Cette fonction ne peut pas fonctionner si les objets du type donné n'ont pas de jeux de CPU (objets d'E/S).

hwloc_obj_t hwloc_get_next_obj_inside_cpuset_by_type (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type, hwloc_obj_t prev) [inline]

Retourne le prochain objet de type type inclus dans le jeu de CPU set. L'invocation suivante doit passer la valeur retournée précédente dans prev afin d'obtenir le prochain objet dans set.

le premier objet de type type inclus dans set si prev est NULL.

le prochain objet de type type inclus dans set si prev est non NULL.

Note

Cette fonction ne peut pas fonctionner si les objets du type donné n'ont pas de jeux de CPU (objets d'E/S ou divers).

int hwloc_get_obj_index_inside_cpuset (hwloc_topology_t topology, hwloc_const_cpuset_t set, hwloc_obj_t obj) [inline]

Retourne l'indice logique parmi les objets inclus dans le jeu de CPU set. Consulter tous les objets du même niveau que obj et à l'intérieur du jeu de CPU set dans l'ordre logique, et retourner l'indice de obj parmi eux. Si set couvre toute la topologie, c'est l'indice logique de obj. Sinon, c'est similaire à un indice logique dans la partie de la topologie définie par le jeu de CPU set.

Retourne

l'index logique parmi les objets inclus dans l'ensemble s'il y en a un.

-1 si l'objet n'est pas inclus dans l'ensemble.

Note

Les objets avec des ensembles de CPU vides sont ignorés (sinon ils seraient considérés comme inclus dans n'importe quel ensemble).

Cette fonction ne peut pas fonctionner si obj n'a pas d'ensembles de CPU (objets d'E/S).

hwloc_obj_t hwloc_get_obj_inside_cpuset_by_depth (hwloc_topology_t topology, hwloc_const_cpuset_t set, int depth, unsigned idx) [inline]

Retourne l'objet (logiquement) idx -ème à la profondeur depth inclus dans l'ensemble de CPU set.

Retourne

l'objet s'il y en a un, NULL sinon.

Note

Les objets avec des ensembles de CPU vides sont ignorés (sinon ils seraient considérés comme inclus dans n'importe quel ensemble).

Cette fonction ne peut pas fonctionner si les objets à la profondeur donnée n'ont pas d'ensembles de CPU (objets d'E/S ou Divers).
