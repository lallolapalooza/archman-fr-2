NOM

hexyl - visualiseur hexadécimal en ligne de commande

SYNTAXE

hexyl [OPTIONS] [FICHIER]

DESCRIPTION

hexyl est un simple visualiseur hexadécimal pour le terminal. Il utilise une sortie colorée pour distinguer différentes catégories d'octets (octets NUL, caractères ASCII imprimables, caractères d'espacement ASCII, autres caractères ASCII et non-ASCII).

ARGUMENTS POSITIONNELS

FICHIER
Le fichier à afficher. Si aucun argument FICHIER n'est donné, lit depuis STDIN.

OPTIONS

-n, --length N
Ne lit que N octets de l'entrée. L'argument N peut également inclure une unité avec un préfixe décimal (kB, MB, ..) ou binaire (kiB, MiB, ..), ou peut être spécifié en utilisant un nombre hexadécimal.
Exemples :
Lire les 64 premiers octets :
$ hexyl --length=64
Lire les 4 kibioctets premiers :
$ hexyl --length=4KiB
Lire les 255 premiers octets (spécifiés en nombre hexadécimal) :
$ hexyl --length=0xff
-c, --bytes N
Un alias pour -n/--length.
-l N
Encore un alias pour -n/--length.
-s, --skip N
Saute les N premiers octets de l'entrée. L'argument N peut également inclure une unité (voir --length pour les détails). Une valeur négative est valide et cherchera depuis la fin du fichier.
--block-size TAILLE
Définit la taille de l'unité de bloc à TAILLE (par défaut : 512).
Exemples :
Définit la taille du bloc à 1024 octets :
$ hexyl --block-size=1024 --length=5block
Définit la taille du bloc à 4 kio :
$ hexyl --block-size=4kB --length=2block
-v, --no-squeezing
Affiche toutes les données d'entrée. Sinon, tout nombre de groupes de lignes de sortie qui seraient identiques au groupe de lignes précédent, est remplacé par une ligne composée d'un seul astérisque.
--color QUAND
Quand utiliser les couleurs. Le mode automatique n'affiche les couleurs que si la sortie est dirigée vers un terminal interactif.
Valeurs possibles :
•
always (par défaut)
•
auto
•
never
--border STYLE
Indique s'il faut dessiner une bordure avec des caractères Unicode, des caractères ASCII, ou aucune bordure.
Valeurs possibles :
•
unicode (par défaut)
•
ascii
•
none
-o, --display-offset N
Ajoute N octets à la position du fichier affichée. L'argument N peut également inclure une unité (voir --length pour les détails). Une valeur négative est valide et calcule un décalage par rapport à la fin du fichier.
-h, --help
Affiche l'aide.
-V, --version
Affiche les informations de version.

NOTES

Dépôt source :
https://github.com/sharkdp/hexyl

EXEMPLES

Afficher un fichier donné :
$ hexyl small.png
Afficher et visualiser un fichier donné dans le pagineur de terminal :
$ hexyl big.png | less -r
Afficher les 256 premiers octets d'un fichier spécial donné :
$ hexyl -n 256 /dev/urandom
