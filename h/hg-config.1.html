HG(CONFIG) HG(CONFIG)

NOM

hg config - afficher les paramètres de configuration combinés de tous les fichiers hgrc

SYNTAXE

hg config [-u] [NOM]...

DESCRIPTION

Sans arguments, affiche les noms et valeurs de tous les éléments de configuration.

Avec un argument de la forme section.nom, affiche uniquement la valeur de cet élément de configuration.

Avec plusieurs arguments, affiche les noms et valeurs de tous les éléments de configuration avec des noms de section ou des noms.sections correspondants.

Avec --edit, démarre un éditeur sur le fichier de configuration au niveau utilisateur. Avec --global, édite le fichier de configuration au niveau du système. Avec --local, édite le fichier de configuration au niveau du dépôt.

Avec --source, la source (nom du fichier et numéro de ligne) est affichée pour chaque élément de configuration.

Voir hg help config pour plus d'informations sur les fichiers de configuration.

L'indicateur --non-shared est utilisé pour éditer le fichier de configuration .hg/hgrc-not-shared. Ce fichier n'est pas partagé entre les partages lorsque le mode share-safe est activé.

Modèle :

Les mots-clés suivants sont pris en charge. Voir également hg help templates.

nom
Chaîne de caractères. Nom de la configuration.
source
Chaîne de caractères. Nom du fichier et numéro de ligne où l'élément est défini.
valeur
Chaîne de caractères. Valeur de la configuration.

L'indicateur --shared peut être utilisé pour éditer le fichier de configuration du dépôt source partagé. Il ne fonctionne que si vous avez partagé en utilisant la fonctionnalité expérimentale share-safe.

Retourne 0 en cas de succès, 1 si NOM n'existe pas.

OPTIONS

-u, --untrusted
afficher les options de configuration non fiables
--exp-all-known
afficher toutes les options de configuration connues (EXPÉRIMENTAL)
-e, --edit
éditer la configuration utilisateur
-l, --local
éditer la configuration du dépôt
--source
afficher la source de la valeur de configuration
--shared
éditer la configuration du dépôt source partagé
--non-shared
éditer la configuration non partagée
-g, --global
éditer la configuration globale
-T,--template <MODÈLE>
afficher avec un modèle

ALIAS

showconfig, debugconfig
