NOM

hBlock - page manuelle pour hBlock 3.5.1

SYNOPSIS

hblock [OPTION]...

DESCRIPTION

hBlock est un script shell conforme à POSIX qui récupère une liste de domaines servant des publicités, des scripts de suivi et des logiciels malveillants à partir de plusieurs sources et crée un fichier hosts, entre autres formats, qui empêche votre système de s'y connecter.

OPTIONS

-O, --output <FICHIER|->, ${HBLOCK_OUTPUT_FILE}

Emplacement du fichier de sortie.
S'il vaut « - », la sortie est imprimée sur stdout.
(par défaut : /etc/hosts)

-H, --header <FICHIER|builtin|none|->, ${HBLOCK_HEADER_FILE}

Fichier à inclure au début du fichier de sortie.
S'il vaut « builtin », la valeur intégrée est utilisée.
S'il vaut « none », une valeur vide est utilisée.
S'il vaut « - », le contenu de stdin est utilisé.
S'il n'est pas spécifié et que l'un des fichiers suivants existe, son contenu est utilisé.
${XDG_CONFIG_HOME}/hblock/header
/etc/hblock/header
(par défaut : builtin)

-F, --footer <FICHIER|builtin|none|->, ${HBLOCK_FOOTER_FILE}

Fichier à inclure à la fin du fichier de sortie.
S'il vaut « builtin », la valeur intégrée est utilisée.
S'il vaut « none », une valeur vide est utilisée.
S'il vaut « - », le contenu de stdin est utilisé.
S'il n'est pas spécifié et que l'un des fichiers suivants existe, son contenu est utilisé.
${XDG_CONFIG_HOME}/hblock/footer
/etc/hblock/footer
(par défaut : builtin)

-S, --sources <FICHIER|builtin|none|->, ${HBLOCK_SOURCES_FILE}

Fichier contenant des URL séparées par des lignes utilisées pour générer la liste de blocage.
S'il vaut « builtin », la valeur intégrée est utilisée.
S'il vaut « none », une valeur vide est utilisée.
S'il vaut « - », le contenu de stdin est utilisé.
S'il n'est pas spécifié et que l'un des fichiers suivants existe, son contenu est utilisé.
${XDG_CONFIG_HOME}/hblock/sources.list
/etc/hblock/sources.list
(par défaut : builtin)

-A, --allowlist <FICHIER|builtin|none|->, ${HBLOCK_ALLOWLIST_FILE}

Fichier contenant des entrées séparées par des lignes à retirer de la liste de blocage.
S'il vaut « builtin », la valeur intégrée est utilisée.
S'il vaut « none », une valeur vide est utilisée.
S'il vaut « - », le contenu de stdin est utilisé.
S'il n'est pas spécifié et que l'un des fichiers suivants existe, son contenu est utilisé.
${XDG_CONFIG_HOME}/hblock/allow.list
/etc/hblock/allow.list
(par défaut : builtin)

-D, --denylist <FICHIER|builtin|none|->, ${HBLOCK_DENYLIST_FILE}

Fichier contenant des entrées séparées par des lignes à ajouter à la liste de blocage.
S'il vaut « builtin », la valeur intégrée est utilisée.
S'il vaut « none », une valeur vide est utilisée.
S'il vaut « - », le contenu de stdin est utilisé.
S'il n'est pas spécifié et que l'un des fichiers suivants existe, son contenu est utilisé.
${XDG_CONFIG_HOME}/hblock/deny.list
/etc/hblock/deny.list
(par défaut : builtin)

-R, --redirection <REDIRECTION>, ${HBLOCK_REDIRECTION}

Redirection pour toutes les entrées de la liste de blocage.
(par défaut : 0.0.0.0)

-W, --wrap <NOMBRE>, ${HBLOCK_WRAP}

Interrompt les lignes de la liste de blocage après ce nombre d'entrées.
(par défaut : 1)

-T, --template <MODÈLE>, ${HBLOCK_TEMPLATE}

Modèle appliqué à chaque entrée.
%D = <DOMAINE>, %R = <REDIRECTION>
(par défaut : %R %D)

-C, --comment <COMMENTAIRE>, ${HBLOCK_COMMENT}

Caractère utilisé pour les commentaires.
(par défaut : #)

-l, --[no-]lenient, ${HBLOCK_LENIENT}

Correspond à toutes les entrées des sources quelle que soit leur IP, au lieu de 0.0.0.0, 127.0.0.1, ::, ::1 ou rien.
(par défaut : false)

-r, --[no-]regex, ${HBLOCK_REGEX}

Utilise des BRE POSIX dans la liste d'autorisation au lieu de chaînes fixes.
(par défaut : false)

-f, --[no-]filter-subdomains, ${HBLOCK_FILTER_SUBDOMAINS}

N'inclut pas les sous-domaines lorsque le domaine parent est également bloqué. Utile pour réduire la taille de la liste de blocage dans des cas tels que lorsque le blocage DNS rend ces sous-domaines redondants.
(par défaut : false)

-n, --retry <NOMBRE>, ${HBLOCK_RETRY}

Nombre de fois où réessayer un téléchargement échoué.
(par défaut : 0)

-c, --[no-]continue, ${HBLOCK_CONTINUE}

N'interrompt pas en cas d'erreur de téléchargement.
(par défaut : false)

-p, --parallel, ${HBLOCK_PARALLEL}

Concurrence maximale pour les téléchargements parallèles.
(par défaut : 4)

-q, --[no-]quiet, ${HBLOCK_QUIET}

Supprime les messages autres que les erreurs.
(par défaut : false)

-x, --color <auto|true|false>, ${HBLOCK_COLOR}

Colorise la sortie.
(par défaut : auto)

-v, --version

Affiche le numéro de version et quitte.

-h, --help

Affiche cette aide et quitte.

NAME

hblock - Block hosts with high latency.

SYNOPSIS

hblock [options] [host...]

DESCRIPTION

hblock is a tool that helps you block hosts that have high latency. It works by pinging a list of hosts and then blocking those that exceed a specified latency threshold. This can be useful for improving network performance by avoiding slow or unresponsive servers.

OPTIONS

-t, --threshold ms
Set the latency threshold in milliseconds. Hosts with an average latency greater than this value will be blocked. Default is 100ms.
-i, --interface interface
Specify the network interface to use for pinging. If not specified, the system's default interface will be used.
-c, --count n
Set the number of ping requests to send to each host. Default is 3.
-l, --list file
Read the list of hosts to check from the specified file. If not specified, a default list will be used.
-v, --verbose
Enable verbose output.
-h, --help
Display a help message and exit.

EXAMPLES

Block hosts with latency above 200ms using the default list: 

    hblock -t 200

Block hosts from a specific file using interface eth0: 

    hblock -i eth0 -l /etc/hblock/hosts.txt

FILES

/etc/hblock/hosts.txt - Default list of hosts to check.
