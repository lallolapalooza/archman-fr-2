NOM

hugo - Construire votre site

SYNTAXE

hugo [indicateurs]

DESCRIPTION

hugo est la commande principale, utilisée pour construire votre site Hugo.

Hugo est un générateur de site statique rapide et flexible construit avec amour par spf13 et ses amis en Go.

La documentation complète est disponible sur https://gohugo.io/.

OPTIONS

-b, --baseURL="" nom d'hôte (et chemin) vers la racine, par exemple https://spf13.com/

-D, --buildDrafts[=false] inclure le contenu marqué comme brouillon

-E, --buildExpired[=false] inclure le contenu expiré

-F, --buildFuture[=false] inclure le contenu avec une date de publication future

--cacheDir="" chemin du système de fichiers vers le répertoire de cache

--cleanDestinationDir[=false] supprimer les fichiers du répertoire de destination qui ne se trouvent pas dans les répertoires statiques

--clock="" définir l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-c, --contentDir="" chemin du système de fichiers vers le répertoire de contenu

-d, --destination="" chemin du système de fichiers où écrire les fichiers

--disableKinds=[] désactiver différents types de pages (accueil, RSS, etc.)

--enableGitInfo[=false] ajouter des informations de révision Git, de date, d'auteur et de CODEOWNERS aux pages

-e, --environment="" environnement de construction

--forceSyncStatic[=false] copier tous les fichiers lorsque statique est modifié.

--gc[=false] activer pour exécuter certaines tâches de nettoyage (supprimer les fichiers de cache inutilisés) après la construction

-h, --help[=false] aide pour hugo

--ignoreCache[=false] ignore le répertoire de cache

--ignoreVendorPaths="" ignore tout chemin de module _vendor correspondant au modèle Glob donné

-l, --layoutDir="" chemin du système de fichiers vers le répertoire de modèles

--logLevel="" niveau de journalisation (debug|info|warn|error)

--minify[=false] minifier tout format de sortie pris en charge (HTML, XML, etc.)

--noBuildLock[=false] ne pas créer de fichier .hugo_build.lock

--noChmod[=false] ne pas synchroniser les permissions des fichiers

--noTimes[=false] ne pas synchroniser l'heure de modification des fichiers

--panicOnWarning[=false] paniquer au premier avertissement

--poll="" définir ceci sur un intervalle de son- dage, par exemple --poll 700ms, pour utiliser une approche basée sur le son- dage pour surveiller les changements du système de fichiers

--printI18nWarnings[=false] afficher les traductions man- quantes

--printMemoryUsage[=false] afficher l'utilisation de la mémoire à l'écran à intervalles réguliers

--printPathWarnings[=false] afficher les avertissements sur les chemins cibles dupliqués, etc.

--printUnusedTemplates[=false] afficher les avertissements sur les modèles inutilisés.

--quiet[=false] construire en mode silencieux

--renderSegments=[] segments nommés à rendre (configurés dans la configuration des segments)

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers à lire à partir de

--templateMetrics[=false] afficher des métriques sur l'exé- cution des modèles

--templateMetricsHints[=false] calculer quelques indices d'amélioration lorsqu'ils sont combinés avec --templateMetrics

-t, --theme=[] thèmes à utiliser (situés dans /themes/NOMTHÈME/)

--themesDir="" chemin du système de fichiers vers le répertoire des thèmes

--trace="" écrire le traçage dans fichier (pas utile en général)

-w, --watch[=false] surveiller le système de fichiers pour les changements et recréer si nécessaire
