NOM

hxselect - extrait des éléments ou des attributs correspondant à un sélecteur (CSS)

SYNTAXE

hxselect [ -i ] [ -c ] [ -l langue ] [ -s séparateur ] sélecteurs

DESCRIPTION

hxselect lit un document XML bien formé et affiche tous les éléments et attributs qui correspondent à l'un des sélecteurs CSS fournis en argument. Par exemple :


hxselect ol li:first-child

sélectionne le premier li (élément de liste en XHTML) dans une ol (liste ordonnée).

S'il y a plusieurs sélecteurs, ils doivent être séparés par des virgules. Par exemple :


hxselect p + ul, blockquote ol

sélectionne tous les éléments ul qui suivent un p et tous les éléments ol qui sont descendants d'un élément blockquote.

La commande opère sur l'entrée standard.

hxselect suppose que les sélecteurs de classe (".foo") se réfèrent à un attribut appelé "class" et que les sélecteurs d'ID ("#foo") se réfèrent à un attribut appelé "id".

Le sélecteur expérimental de nœud d'attribut '::attr(nom)' est supporté et sélectionne l'attribut de ce nom.

Les commentaires et les instructions de traitement sont ignorés, c'est-à-dire qu'ils sont lus mais jamais écrits.

OPTIONS

Les options suivantes sont supportées :

-i
Correspondance insensible à la casse. Utile pour HTML et certains autres langages basés sur SGML.
-c
N'afficher que le contenu. Sans -c, la balise de début et la balise de fin de l'élément correspondant sont également affichées ; avec -c seul le contenu de l'élément correspondant est affiché. Si un attribut plutôt qu'un élément est sélectionné (sélecteur ::attr()), seule la valeur de l'attribut est affichée.
-l langue
Définit la langue par défaut, au cas où l'élément racine n'aurait pas d'attribut xml:lang (défaut : aucun). Exemple : -l fr
-s séparateur
Une chaîne de caractères à afficher après chaque correspondance (défaut : vide). Accepte les échappements de type C. Exemple : -s ' 0(aq pour afficher une ligne vide après chaque correspondance.

OPÉRANDES

L'opérande suivant est supporté :

sélecteurs
Un ou plusieurs sélecteurs séparés par des virgules. La plupart des sélecteurs de CSS niveau 3 sont supportés, à l'exception de ceux qui nécessitent une interaction (par ex. ':active') ou une mise en page (par ex. ':first-line').

BOGUES

Les sélecteurs insensibles à la casse (option -i) ne fonctionnent actuellement que pour les caractères ASCII ("a" correspond à "A"), pas pour les autres caractères ("ä" ne correspond pas à "Ä").

VOIR AUSSI

asc2xml(1), xml2asc(1), hxnormalize(1), hxremove(1), UTF-8 (RFC 2279)
