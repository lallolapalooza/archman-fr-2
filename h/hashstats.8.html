NOM

hashstats - Affiche des informations sur un fichier de hachage duperemove

SYNTAXE

hashstats options fichier_de_hachage

DESCRIPTION

fichier_de_hachage extrait des statistiques ou des données brutes d'un fichier de hachage. Le fichier de hachage doit être un fichier généré en exécutant duperemove(8) avec l'option --hashfile ou --write-hashes.

OPTIONS

-n NUM
Affiche les NUM meilleurs hachages, triés par taille de compartiment. La valeur par défaut est 10.
-a
Affiche tous les hachages (ignore -n ci-dessus)
-B
Affiche les hachages de blocs. Par défaut, les hachages d'étendues sont affichés.
-b
Affiche des informations sur chaque bloc dans nos compartiments de hachage.
-l
Affiche une liste de tous les fichiers.
