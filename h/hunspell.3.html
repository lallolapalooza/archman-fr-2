DESCRIPTION

Les routines de la bibliothèque Hunspell fournissent à l'utilisateur des fonctions linguistiques au niveau du mot : vérification orthographique et correction, racinisation, génération morphologique et analyse dans un style objet et arrangement.

L'en-tête C optionnel contient l'interface C de la bibliothèque C++ avec le constructeur et le destructeur Hunspell_create et Hunspell_destroy, et un paramètre HunHandle supplémentaire (l'objet alloué) dans les fonctions de wrapper (voir dans le fichier d'en-tête C hunspell.h).

Les fonctions de base de la vérification orthographique, spell() et suggest() peuvent être utilisées pour la racinisation, la génération morphologique et l'analyse par des textes d'entrée XML (voir l'API XML).

Constructeur et destructeur

Le constructeur de Hunspell a besoin des chemins des fichiers d'affixes et du dictionnaire. (Dans l'environnement WIN32, utilisez des chemins encodés en UTF-8 commençant par le préfixe de chemin long \\?\ pour gérer le codage de caractères indépendant du système et les noms de chemins très longs.) Voir la page du manuel de hunspell(4) pour le format du dictionnaire. Le paramètre key optionnel est destiné aux dictionnaires cryptés par l'outil hzip de la distribution Hunspell.

Dictionnaires supplémentaires

La fonction add_dic() charge un fichier de dictionnaire supplémentaire. Les dictionnaires supplémentaires utilisent le fichier d'affixes de l'objet Hunspell alloué. Le nombre maximal de dictionnaires supplémentaires est limité dans le code source (20).

Orthographe et correction

La fonction spell() renvoie une valeur non nulle si le mot d'entrée est reconnu par le vérificateur orthographique, et une valeur nulle sinon. Les variables de référence optionnelles renvoient un tableau de bits (info) et le mot racine du mot d'entrée. Les bits d'information vérifiés avec les macros SPELL_COMPOUND, SPELL_FORBIDDEN ou SPELL_WARN signalent les mots composés, explicitement interdits et probablement incorrects. À partir de la version 1.3, la valeur de retour non nulle est 2 pour les mots du dictionnaire portant le drapeau "WARN" (probablement incorrects).

La fonction suggest() a deux paramètres d'entrée, une variable de référence pour la liste de suggestions de sortie, et un mot d'entrée. La fonction renvoie le nombre de suggestions. La variable de référence contiendra l'adresse de la liste de suggestions nouvellement allouée ou NULL si la valeur de retour de suggest() est zéro. Le nombre maximal de suggestions est limité dans le code source.

spell() et suggest() peuvent reconnaître des entrées XML, voir la section API XML.

Fonctions morphologiques

Les fonctions simples stem() et analyze() sont similaires à suggest(), mais renvoient, au lieu de suggestions, des racines et les résultats de l'analyse morphologique. La fonction simple generate() attend également un second mot. Ce mot supplémentaire et son affixation serviront de modèle pour la génération morphologique des formes demandées du premier mot.

Les fonctions étendues stem() et generate() utilisent les résultats d'une analyse morphologique :

char ** result, result2;
int n1 = analyze(&result, "words");
int n2 = stem(&result2, result, n1);

L'annotation morphologique de la bibliothèque Hunspell a des identificateurs de champ fixes (deux lettres et un deux-points), voir la page du manuel de hunspell(4).

char ** result;
char * affix = "is:plural"; // la description dépend également des dictionnaires
int n = generate(&result, "word", &affix, 1);
for (int i = 0; i < n; i++) printf("%s\n", result[i]);

Désallocation de mémoire

La fonction free_list() libère la mémoire allouée par les fonctions suggest(), analyze, generate et stem().

Autres fonctions

Les fonctions add(), add_with_affix() et remove() sont des fonctions d'aide à l'implémentation d'un dictionnaire personnel pour ajouter et supprimer des mots du dictionnaire de base à l'exécution. La fonction add_with_affix() utilise un second mot racine comme modèle pour l'affixation et la composition du nouveau mot.

La fonction get_dic_encoding() renvoie "ISO8859-1" ou le codage de caractères défini dans le fichier d'affixes avec le mot-clé "SET".

La fonction get_csconv() renvoie la table des caractères majuscules/minuscules sur 8 bits du codage du dictionnaire.

Les fonctions get_wordchars() et get_wordchars_utf16() renvoient les caractères de mots supplémentaires définis dans le fichier d'affixes pour la tokenisation par le mot-clé "WORDCHARS".

La fonction get_version() renvoie la chaîne de version de la bibliothèque.

API XML

La fonction spell() renvoie une valeur non nulle pour l'entrée "< ?xml ? >" indiquant la prise en charge de l'API XML.

La fonction suggest() racinise, analyse et génère les formes du mot d'entrée, s'il a été ajouté par l'une des syntaxes "SPELLML" suivantes :

<?xml?>
<query type="analyze">
<word>dogs</word>
</query>
<?xml?>
<query type="stem">
<word>dogs</word>
</query>
<?xml?>
<query type="generate">
<word>dog</word>
<word>cats</word>
</query>
<?xml?>
<query type="generate">
<word>dog</word>
<code><a>is:pl</a><a>is:poss</a></code>
</query>
<?xml?>
<query type="add">
<word>word</word>
</query>
<?xml?>
<query type="add">
<word>word</word>
<word>model_word_for_affixation_and_compounding</word>
</query>

Les sorties de la requête de type "stem" et de la fonction de bibliothèque stem() sont identiques. La sortie de la requête de type "analyze" est une chaîne contenant un élément <code><a>result1</a><a>result2</a>...</code>. Cet élément peut être utilisé dans la seconde syntaxe de la requête de type "generate".

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <hunspell.h>

int main(int argc, char **argv) {
    Hunspell *pHunspell = NULL;
    char ** suggestions = NULL;
    int n = 0;

    pHunspell = Hunspell_create("./en_US", "./en_US");
    if (!pHunspell) {
        fprintf(stderr, "Could not create Hunspell object.\n");
        return 1;
    }

    if (argc > 1) {
        n = Hunspell_suggest(pHunspell, &suggestions, argv[1]);
        if (n > 0) {
            printf("Suggestions for '%s':\n", argv[1]);
            for (int i = 0; i < n; i++) {
                printf("  %s\n", suggestions[i]);
            }
            Hunspell_free_list(pHunspell, &suggestions, n);
        } else {
            printf("'%s' is spelled correctly.\n", argv[1]);
        }
    } else {
        printf("Usage: %s <word_to_check>\n", argv[0]);
    }

    Hunspell_destroy(pHunspell);
    return 0;
}
