hsearch(3) Manuel des fonctions de bibliothèque hsearch(3)

NOM

hcreate, hdestroy, hsearch, hcreate_r, hdestroy_r, hsearch_r - gestion de tables de hachage

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <search.h>
int hcreate(size_t nel);
void hdestroy(void);
ENTRY *hsearch(ENTRY item, ACTION action);
#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <search.h>
int hcreate_r(size_t nel, struct hsearch_data *htab);
void hdestroy_r(struct hsearch_data *htab);
int hsearch_r(ENTRY item, ACTION action, ENTRY **retval,
              struct hsearch_data *htab);

DESCRIPTION

Les trois fonctions hcreate(), hsearch() et hdestroy() permettent à l'appelant de créer et gérer une table de recherche par hachage contenant des entrées composées d'une clé (une chaîne de caractères) et de données associées. L'utilisation de ces fonctions ne permet d'utiliser qu'une seule table de hachage à la fois.

Les trois fonctions hcreate_r(), hsearch_r() et hdestroy_r() sont des versions réentrantes qui permettent à un programme d'utiliser plusieurs tables de recherche par hachage simultanément. Le dernier argument, htab, pointe vers une structure qui décrit la table sur laquelle la fonction doit opérer. Le programmeur doit considérer cette structure comme opaque (c'est-à-dire, ne pas tenter d'accéder ou de modifier directement les champs de cette structure).

Une table de hachage doit d'abord être créée en utilisant hcreate(). L'argument nel spécifie le nombre maximum d'entrées dans la table. (Ce maximum ne peut pas être modifié ultérieurement, il faut donc le choisir judicieusement.) L'implémentation peut ajuster cette valeur à la hausse pour améliorer les performances de la table de hachage résultante.

La fonction hcreate_r() effectue la même tâche que hcreate(), mais pour la table décrite par la structure *htab. La structure pointée par htab doit être initialisée à zéro avant le premier appel à hcreate_r().

La fonction hdestroy() libère la mémoire occupée par la table de hachage qui a été créée par hcreate(). Après avoir appelé hdestroy(), une nouvelle table de hachage peut être créée en utilisant hcreate(). La fonction hdestroy_r() effectue la tâche analogue pour une table de hachage décrite par *htab, qui a été précédemment créée en utilisant hcreate_r().

La fonction hsearch() recherche dans la table de hachage un élément ayant la même clé que item (où "la même" est déterminé en utilisant strcmp(3)), et si la recherche réussit, retourne un pointeur vers cet élément.

L'argument item est de type ENTRY, qui est défini dans <search.h> comme suit :


typedef struct entry {
    char *key;
    void *data;
} ENTRY;

Le champ key pointe vers une chaîne de caractères terminée par un caractère nul qui est la clé de recherche. Le champ data pointe vers des données associées à cette clé.

L'argument action détermine ce que fait hsearch() après une recherche infructueuse. Cet argument doit avoir la valeur ENTER, signifiant l'insertion d'une copie de item (et le retour d'un pointeur vers la nouvelle entrée de la table de hachage comme résultat de la fonction), ou la valeur FIND, signifiant que NULL doit être retourné. (Si action est FIND, alors data est ignoré.)

La fonction hsearch_r() est similaire à hsearch() mais opère sur la table de hachage décrite par *htab. La fonction hsearch_r() diffère de hsearch() en ce qu'un pointeur vers l'élément trouvé est retourné dans *retval, plutôt que comme résultat de la fonction.

VALEUR RENVOYEE

hcreate() et hcreate_r() retournent une valeur non nulle en cas de succès. Elles retournent 0 en cas d'erreur, avec errno défini pour indiquer l'erreur.

En cas de succès, hsearch() retourne un pointeur vers une entrée dans la table de hachage. hsearch() retourne NULL en cas d'erreur, c'est-à-dire, si action est ENTER et que la table de hachage est pleine, ou si action est FIND et que item ne peut pas être trouvée dans la table de hachage. hsearch_r() retourne une valeur non nulle en cas de succès, et 0 en cas d'erreur. En cas d'erreur, ces deux fonctions définissent errno pour indiquer l'erreur.

ERREURS

hcreate_r() et hdestroy_r() peuvent échouer pour les raisons suivantes :

EINVAL
htab est NULL.

hsearch() et hsearch_r() peuvent échouer pour les raisons suivantes :

ENOMEM
action était ENTER, key n'a pas été trouvée dans la table, et il n'y avait pas assez de place dans la table pour ajouter une nouvelle entrée.
ESRCH
action était FIND, et key n'a pas été trouvée dans la table.

POSIX.1 spécifie uniquement l'erreur ENOMEM.

NOTES

Les implémentations de tables de hachage sont généralement plus efficaces lorsque la table contient suffisamment d'espace libre pour minimiser les collisions. Généralement, cela signifie que nel doit être au moins 25 % plus grand que le nombre maximum d'éléments que l'appelant s'attend à stocker dans la table.

Les fonctions hdestroy() et hdestroy_r() ne libèrent pas les buffers pointés par les éléments key et data des entrées de la table de hachage. (Elles ne peuvent pas le faire car elles ne savent pas si ces buffers ont été alloués dynamiquement.) Si ces buffers doivent être libérés (peut-être parce que le programme crée et détruit des tables de hachage de manière répétée, plutôt que de créer une table unique dont la durée de vie correspond à celle du programme), alors le programme doit maintenir des structures de données de suivi qui lui permettent de les libérer.

EXEMPLE

S

Le programme suivant insère 24 éléments dans une table de hachage, puis en imprime

certains. 
#include <search.h>
#include <stdio.h>
#include <stdlib.h>
static char *data[] = { "alpha", "bravo", "charlie", "delta",
     "echo", "foxtrot", "golf", "hotel", "india", "juliet",
     "kilo", "lima", "mike", "november", "oscar", "papa",
     "quebec", "romeo", "sierra", "tango", "uniform",
     "victor", "whisky", "x-ray", "yankee", "zulu"
};
int
main(void)
{
    ENTRY e;
    ENTRY *ep;
    hcreate(30);
    for (size_t i = 0; i < 24; i++) {
        e.key = data[i];
        /* data is just an integer, instead of a
           pointer to something */
        e.data = (void *) i;
        ep = hsearch(e, ENTER);
        /* there should be no failures */
        if (ep == NULL) {
            fprintf(stderr, "entry failed\n");
            exit(EXIT_FAILURE);
        }
    }
    for (size_t i = 22; i < 26; i++) {
        /* print two entries from the table, and
           show that two are not in the table */
        e.key = data[i];
        ep = hsearch(e, FIND);
        printf("%9.9s -> %9.9s:%d\n", e.key,
               ep ? ep->key : "NULL", ep ? (int) ep->data : 0);
    }
    hdestroy();
    exit(EXIT_SUCCESS);
}
