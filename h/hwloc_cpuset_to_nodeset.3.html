int hwloc_cpuset_from_nodeset (hwloc_topology_t topology, hwloc_cpuset_t _cpuset, hwloc_const_nodeset_t nodeset) [inline]

Convertir un ensemble de nœuds NUMA en un ensemble de CPU. Pour chaque nœud NUMA inclus dans le nodeset d'entrée, définir les PU locaux correspondants dans le _cpuset de sortie.

Si certains CPU n'ont pas de nœuds NUMA locaux, cette fonction ne définit jamais leurs indices dans l'ensemble de CPU de sortie, même si un ensemble de nœuds complet est donné en entrée.

Par conséquent, l'ensemble de nœuds complet de la topologie est converti en l'ensemble de tous les CPU qui ont des nœuds NUMA locaux.

Retourne

0 en cas de succès.

-1 avec errno défini sur ENOMEM en cas d'échec de réallocation interne.

int hwloc_cpuset_to_nodeset (hwloc_topology_t topology, hwloc_const_cpuset_t _cpuset, hwloc_nodeset_t nodeset) [inline]

Convertir un ensemble de CPU en un ensemble de nœuds NUMA. Pour chaque PU incluse dans le _cpuset d'entrée, définir le(s) nœud(s) NUMA locaux correspondants dans le nodeset de sortie.

Si certains nœuds NUMA n'ont aucun CPU, cette fonction ne définit jamais leurs indices dans l'ensemble de nœuds de sortie, même si un ensemble de CPU complet est donné en entrée.

Par conséquent, l'ensemble de CPU complet de la topologie est converti en l'ensemble de tous les nœuds qui ont des CPU locaux.

Retourne

0 en cas de succès.

-1 avec errno défini sur ENOMEM en cas d'échec de réallocation interne.
