Description détaillée

Hwloc utilise des bitmaps pour représenter deux types distincts d'ensembles d'objets : les ensembles de CPU (hwloc_cpuset_t) et les ensembles de nœuds NUMA (hwloc_nodeset_t). Ces types sont tous deux des typedefs vers un type de backend commun (hwloc_bitmap_t), et par conséquent, toutes les fonctions de bitmap hwloc sont applicables aux deux types hwloc_cpuset_t et hwloc_nodeset_t (voir L'API des bitmaps).

La raison d'être de ces deux types différents est que, bien que les actions que l'on souhaite effectuer sur ces types soient les mêmes (par exemple, activer et désactiver des éléments individuels dans l'ensemble/le masque), ils sont utilisés dans des contextes très différents : l'un pour spécifier quels processeurs utiliser et l'autre pour spécifier quels nœuds NUMA utiliser. Par conséquent, la différence de nom reflète simplement l'intention de l'endroit où le type est utilisé.

typedef hwloc_bitmap_t hwloc_cpuset_t

Un ensemble de CPU est une bitmap dont les bits sont définis selon les index physiques des unités de traitement (PU) du système d'exploitation. Il peut être consulté et modifié avec l'API des bitmaps comme toute hwloc_bitmap_t (voir hwloc/bitmap.h).

Chaque bit peut être converti en objet PU en utilisant hwloc_get_pu_obj_by_os_index().

typedef hwloc_bitmap_t hwloc_nodeset_t

Un ensemble de nœuds est une bitmap dont les bits sont définis selon les index physiques des nœuds de mémoire NUMA du système d'exploitation. Il peut être consulté et modifié avec l'API des bitmaps comme toute hwloc_bitmap_t (voir hwloc/bitmap.h). Chaque bit peut être converti en objet nœud NUMA en utilisant hwloc_get_numanode_obj_by_os_index().

Lors de la liaison de mémoire sur un système sans aucun nœud NUMA, le seul banc de mémoire principal est considéré comme le nœud NUMA n° 0.

Voir également Conversion entre ensembles de CPU et ensembles de nœuds.
