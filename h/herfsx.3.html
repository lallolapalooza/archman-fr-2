!>
!>    CHERFSX améliore la solution calculée d'un système d'équations
!>    linéaires lorsque la matrice des coefficients est hermitienne
!>    indéfinie, et fournit des bornes d'erreur et des estimations
!>    d'erreur arrière pour la solution. En plus de la borne d'erreur
!>    au sens de la norme, le code fournit, si possible, la borne
!>    d'erreur maximale composante par composante. Voir les commentaires
!>    pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des bornes
!>    d'erreur.
!>
!>    Le système original d'équations linéaires peut avoir été
!>    équilibré avant l'appel de cette routine, comme décrit par les
!>    arguments EQUED et S ci-dessous. Dans ce cas, la solution et les
!>    bornes d'erreur renvoyées sont celles du système original non
!>    équilibré.
!
> 
!>     Certains paramètres optionnels sont regroupés dans le tableau
!>     PARAMS. Ces réglages déterminent la manière dont le raffinement
!>     est effectué, mais souvent les valeurs par défaut sont
!>     acceptables. Si les valeurs par défaut sont acceptables, les
!>     utilisateurs peuvent passer NPARAMS = 0, ce qui empêche le code
!>     source d'accéder à l'argument PARAMS.

!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : l'erreur directe estimée, presque
!>              certainement dans un facteur de 10 de l'erreur réelle

!>              doit être prise en compte que si le booléen précédent
!>              est vrai.
!>

!>              réciproque en norme estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si
!>              l'estimation d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour
!>              une matrice Z correctement mise à l'échelle.
!>              Soit Z = S*A, où S met chaque ligne à l'échelle par une
!>              puissance de la base de sorte que toutes les sommes
!>              absolues des lignes de Z soient approximativement 1.

!>     Voir Lapack Working Note 165 pour plus de détails et de
!>     précautions supplémentaires.

NAME


dsyrfsx — improve the computed solutions to a system of linear
    equations with a symmetric indefinite matrix, and provide error bounds
    and backward error estimates for the solution






SYNOPSIS


    SUBROUTINE DSYRFSX(UPLO, EQUED, N, NRHS, A, LDA, AF, LDAF, IPIV, S, B,
                        LDB, X, LDX, RCOND, BERR, N_ERR_BNDS, ERR_BNDS_NORM,
                        ERR_BNDS_COMP, NPARAMS, PARAMS, WORK, IWORK, INFO)

        CHARACTER uplo, equed
        INTEGER n, nrhs, lda, ldaf, ldb, ldx, n_err_bnds, nparams, info
        INTEGER ipiv(*)

                     err_bnds_comp(nrhs, *), params(*), work(*)

DESCRIPTION


DSYRFSX improves the computed solution to a system of linear
    equations when the coefficient matrix is symmetric indefinite, and
    provides error bounds and backward error estimates for the
    solution. In addition to normwise error bound, the code provides
    maximum componentwise error bound if possible. See comments for
    ERR_BNDS_NORM and ERR_BNDS_COMP for details of the error bounds.


The original system of linear equations may have been equilibrated
    before calling this routine, as described by arguments EQUED and S
    below. In this case, the solution and error bounds returned are
    for the original unequilibrated system.


Some optional parameters are bundled in the PARAMS array. These
    settings determine how refinement is performed, but often the
    defaults are acceptable. If the defaults are acceptable, users
    can pass NPARAMS = 0 which prevents the source code from accessing
    the PARAMS argument.






PARAMETERS




UPLO (CHARACTER*1)




Specifies whether the upper or lower triangular part of the
        symmetric matrix A is stored.


    

  • 'U': Upper triangle of A is stored.
    • 

  • 'L': Lower triangle of A is stored.
    • 





EQUED (CHARACTER*1)




Specifies the form of equilibration that was done to A
        before calling this routine. This is needed to compute
        the solution and error bounds correctly.


    

  • 'N': No equilibration.
    • 

  • 'Y': Both row and column equilibration, i.e., A has been
        replaced by diag(S) * A * diag(S). The right hand side B
        has been changed accordingly.
    •

The order of the matrix A. N >= 0.




NRHS (INTEGER)




The number of right hand sides, i.e., the number of columns
        of the matrices B and X. NRHS >= 0.

The symmetric matrix A. If UPLO = 'U', the leading N-by-N
        upper triangular part of A contains the upper triangular
        part of the matrix A, and the strictly lower triangular
        part of A is not referenced. If UPLO = 'L', the leading
        N-by-N lower triangular part of A contains the lower
        triangular part of the matrix A, and the strictly upper
        triangular part of A is not referenced.




LDA (INTEGER)




The leading dimension of the array A. LDA >= max(1, N).

The factored form of the matrix A. AF contains the block

LDAF (INTEGER)




The leading dimension of the array AF. LDAF >= max(1, N).

        products of the diagonal entries of the matrices D represented by
        LU decomposition if used, and diagonal entries of A otherwise.

The right-hand side vector, B, of dimension N x NRHS.




LDB (INTEGER)

        corresponding to the i-th column of B.

ERR_BNDS_NORM (REAL(kind=8), dimension(NRHS, *))




For each right hand side, this array contains information about
        various error bounds and condition numbers corresponding to the
        normwise relative error, which is defined as follows:


             max_i ( abs(XTRUE(i,j) - X(i,j)) / abs(X(i,j)) )

        componentwise accuracy is not requested (PARAMS(3) = 0.0), then
        ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most
        the first (:,N_ERR_BNDS) entries are returned.
