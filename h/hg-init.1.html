NOM

hg init - créer un nouveau dépôt dans le répertoire donné

SYNOPIS

hg init [-e CMD] [--remotecmd CMD] [DEST]

DESCRIPTION

Initialise un nouveau dépôt dans le répertoire spécifié. Si le répertoire donné n'existe pas, il sera créé.

Si aucun répertoire n'est spécifié, le répertoire courant est utilisé.

Il est possible de spécifier une URL ssh:// comme destination. Voir hg help urls pour plus d'informations.

Retourne 0 en cas de succès.

OPTIONS

-e,--ssh <CMD>
spécifier la commande ssh à utiliser
--remotecmd <CMD>
spécifier la commande hg à exécuter côté distant
--insecure
ne pas vérifier le certificat du serveur (ignore la configuration web.cacerts)
