Documentation du type énuméré

enum hwloc_topology_export_synthetic_flags_e

Indicateurs pour l'exportation des topologies synthétiques. Indicateurs à fournir sous forme d'un ensemble OR'é à hwloc_topology_export_synthetic().

Énumérateurs

HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_NO_EXTENDED_TYPES
Exporter les types étendus tels que L2dcache en types basiques tels que Cache. Ceci est requis pour charger la description synthétique avec hwloc < 1.9.
HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_NO_ATTRS
Ne pas exporter les attributs de niveau. Ignorer les attributs de niveau tels que les tailles de mémoire/cache ou les index des PU. Ceci est requis pour charger la description synthétique avec hwloc < 1.10.
HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_V1
Exporter la hiérarchie mémoire comme prévu dans hwloc 1.x. Au lieu d'attacher des enfants mémoire aux niveaux, exporter un seul nœud NUMA enfant comme des niveaux intermédiaires normaux, quand c'est possible. Ceci est requis pour charger la description synthétique avec hwloc 1.x. Cependant, cela peut échouer si certains objets ont plusieurs nœuds NUMA locaux.
HWLOC_TOPOLOGY_EXPORT_SYNTHETIC_FLAG_IGNORE_MEMORY
Ne pas exporter les informations mémoire. Exporter uniquement la hiérarchie réelle des objets normaux du côté CPU et ignorer où la mémoire est attachée. Ceci est utile lorsque la hiérarchie des CPUs est ce qui importe vraiment, mais cela se comporte comme s'il y avait un seul nœud NUMA à l'échelle de la machine.

Documentation de la fonction

int hwloc_topology_export_synthetic (hwloc_topology_t topology, char * buffer, size_t buflen, unsigned long flags)

Exporter la topologie sous forme de chaîne synthétique. Au maximum buflen caractères seront écrits dans buffer, y compris le caractère nul terminal.

Cette chaîne exportée peut être retransmise à hwloc_topology_set_synthetic().

flags est un ensemble OR'é de hwloc_topology_export_synthetic_flags_e.

Retourne

Le nombre de caractères qui ont été écrits, sans inclure le caractère nul terminal.

-1 si la topologie n'a pas pu être exportée, par exemple si elle n'est pas symétrique.

Note

Les enfants d'E/S et divers sont ignorés, la chaîne synthétique ne décrit que les enfants normaux.

Un tampon de 1024 octets devrait être suffisamment grand pour exporter les topologies dans la grande majorité des cas.
