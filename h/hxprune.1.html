NOM

hxprune - supprimer les éléments marqués d'un fichier HTML

SYNTAXE

hxprune [ -c classe ] [ -x ] [ fichier ]

DESCRIPTION

hxprune supprime les éléments spécialement marqués (avec leur contenu et leurs enfants) d'un fichier HTML. Par défaut, il supprime les éléments ayant un attribut de classe égal à "exclude". L'attribut de classe est analysé comme une liste de mots séparés par des espaces et si l'un de ces mots est "exclude", l'élément n'est pas copié dans la sortie.

OPTIONS

Les options suivantes sont prises en charge :

-c classe
Spécifier une classe différente de "exclude".
-x
Forcer la sortie au style XML, c'est-à-dire sans attributs courts et avec une barre oblique (/) pour marquer les éléments vides.
