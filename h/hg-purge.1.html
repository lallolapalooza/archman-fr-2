NOM

hg purge - supprime les fichiers non suivis par Mercurial

SYNOPIS

hg purge [OPTION]... [DIR]...

DESCRIPTION

Supprime les fichiers non connus de Mercurial. Ceci est utile pour tester les modifications locales et non validées dans un arbre source par ailleurs propre.

Cela signifie que purge supprimera par défaut les éléments suivants :

  • Fichiers inconnus : fichiers marqués d'un « ? » par hg status
  • Répertoires vides : en fait, Mercurial ignore les répertoires à moins qu'ils ne contiennent des fichiers sous gestion de contrôle de source

    Mais cela laissera intacts :

  • Fichiers modifiés et non modifiés suivis
  • Fichiers ignorés (sauf si -i ou --all est spécifié)
  • Nouveaux fichiers ajoutés au dépôt (avec hg add)

    Les options --files et --dirs peuvent être utilisées pour diriger purge afin de supprimer uniquement les fichiers, uniquement les répertoires, ou les deux. Si aucune des options n'est donnée, les deux seront supprimés.

    Si des répertoires sont donnés sur la ligne de commande, seuls les fichiers dans ces répertoires sont considérés.

    Soyez prudent avec purge, car vous pourriez supprimer définitivement certains fichiers que vous avez oublié d'ajouter au dépôt. Si vous voulez seulement imprimer la liste des fichiers que ce programme supprimerait, utilisez l'option --print.

OPTIONS

-a, --abort-on-err
abandonne en cas d'erreur
--all
supprime également les fichiers ignorés
-i, --ignored
supprime uniquement les fichiers ignorés
--dirs
supprime les répertoires vides
--files
supprime les fichiers
-p, --print
imprime les noms de fichiers au lieu de les supprimer
-0, --print0
termine les noms de fichiers par NUL, pour une utilisation avec xargs (implique -p/--print)
--confirm
demande avant de supprimer définitivement les fichiers
-I,--include <PATTERN[+]>
inclut les noms correspondant aux motifs donnés
-X,--exclude <PATTERN[+]>
exclut les noms correspondant aux motifs donnés

[+] l'option marquée peut être spécifiée plusieurs fois

ALIASES

clean
