hwloc_obj_type_t hwloc_get_depth_type (hwloc_topology_t topology, int depth)

Retourne le type des objets à la profondeur depth. depth doit être compris entre 0 et hwloc_topology_get_depth()-1, ou une profondeur virtuelle comme HWLOC_TYPE_DEPTH_NUMANODE.

Retourne

Le type des objets à la profondeur depth.

(hwloc_obj_type_t)-1 si la profondeur depth n'existe pas.

int hwloc_get_memory_parents_depth (hwloc_topology_t topology)

Retourne la profondeur des parents auxquels les objets mémoire sont attachés. Les objets mémoire ont des profondeurs négatives virtuelles car ils ne font pas partie de la hiérarchie principale des objets côté CPU. Cette profondeur ne doit pas être comparée à d'autres profondeurs de niveau.

Si tous les objets mémoire sont attachés à des parents Normaux à la même profondeur, cette profondeur parente peut être comparée à d'autres comme d'habitude, par exemple pour savoir si les nœuds NUMA sont attachés au-dessus ou en dessous des Processeurs.

Retourne

La profondeur des parents Normaux de tous les enfants mémoire si tous ces parents ont la même profondeur. Par exemple, la profondeur du niveau Processeur si tous les nœuds NUMA sont attachés à des objets Processeur.

HWLOC_TYPE_DEPTH_MULTIPLE si les parents Normaux de tous les enfants mémoire n'ont pas la même profondeur. Par exemple si certains nœuds NUMA sont attachés à des Processeurs alors que d'autres sont attachés à des Groupes.

unsigned hwloc_get_nbobjs_by_depth (hwloc_topology_t topology, int depth)

Detailed Description

hwloc_get_obj_by_depth

Returns the topology object at logical index idx from depth depth.

Returns

The object if it exists.

NULL if there is no object with this index and depth.

hwloc_get_obj_by_type

Returns the topology object at logical index idx with type type.

Returns

The object if it exists.

NULL if there is no object with this index and type.

NULL if there are multiple levels with objects of that type (e.g. HWLOC_OBJ_GROUP), the caller may fallback to hwloc_get_obj_by_depth().

hwloc_get_root_obj

Returns the top-object of the topology-tree. Its type is HWLOC_OBJ_MACHINE.

This function cannot return NULL.

hwloc_get_type_depth

Returns the depth of objects of type type.

Returns

The depth of objects of type type.

A negative virtual depth if a NUMA node, I/O or Misc object type is given. These objects are stored in special levels that are not CPU-related. This virtual depth may be passed to other hwloc functions such as hwloc_get_obj_by_depth() but it should not be considered as an actual depth by the application. In particular, it should not be compared with any other object depth or with the entire topology depth.

HWLOC_TYPE_DEPTH_UNKNOWN if no object of this type is present on the underlying architecture, or if the OS doesn't provide this kind of information.

HWLOC_TYPE_DEPTH_MULTIPLE if type HWLOC_OBJ_GROUP is given and multiple levels of Groups exist.

Note

If the type is absent but a similar type is acceptable, see also hwloc_get_type_or_below_depth() and hwloc_get_type_or_above_depth().

See also

hwloc_get_memory_parents_depth() for managing the depth of memory objects.

hwloc_type_sscanf_as_depth() for returning the depth of objects whose type is given as a string.

hwloc_get_type_or_above_depth

Returns the depth of objects of type type or above. If no object of this type is present on the underlying architecture, the function returns the depth of the first 'present' object typically containing type.

This function is only meaningful for normal object types. If a memory, I/O or Misc object type is given, the corresponding virtual depth is always returned (see hwloc_get_type_depth()).

May return HWLOC_TYPE_DEPTH_MULTIPLE for HWLOC_OBJ_GROUP just like hwloc_get_type_depth().

hwloc_get_type_or_below_depth

Returns the depth of objects of type type or below. If no object of this type is present on the underlying architecture, the function returns the depth of the first 'present' object typically found inside type.

This function is only meaningful for normal object types. If a memory, I/O or Misc object type is given, the corresponding virtual depth is always returned (see hwloc_get_type_depth()).

May return HWLOC_TYPE_DEPTH_MULTIPLE for HWLOC_OBJ_GROUP just like hwloc_get_type_depth().

hwloc_topology_get_depth

Get the depth of the hierarchical tree of objects. This is the depth of HWLOC_OBJ_PU objects plus one.

Returns

the depth of the object tree.

Note

NUMA nodes, I/O and Misc objects are ignored when computing the depth of the tree (they are placed on special levels).

hwloc_get_obj_by_depth

Retourne l'objet de topologie à l'index logique idx de la profondeur depth.

Retourne

L'objet s'il existe.

NULL s'il n'existe aucun objet avec cet index et cette profondeur.

hwloc_get_obj_by_type

Retourne l'objet de topologie à l'index logique idx de type type.

Retourne

L'objet s'il existe.

NULL s'il n'existe aucun objet avec cet index et ce type.

NULL s'il y a plusieurs niveaux avec des objets de ce type (par ex. HWLOC_OBJ_GROUP), l'appelant peut se rabattre sur hwloc_get_obj_by_depth().

hwloc_get_root_obj

Retourne l'objet supérieur de l'arbre de topologie. Son type est HWLOC_OBJ_MACHINE.

Cette fonction ne peut pas retourner NULL.

hwloc_get_type_depth

Retourne la profondeur des objets de type type.

Retourne

La profondeur des objets de type type.

Une profondeur virtuelle négative si un type de nœud NUMA, I/O ou Misc est donné. Ces objets sont stockés dans des niveaux spéciaux qui ne sont pas liés aux CPU. Cette profondeur virtuelle peut être passée à d'autres fonctions hwloc telles que hwloc_get_obj_by_depth() mais elle ne doit pas être considérée comme une profondeur réelle par l'application. En particulier, elle ne doit pas être comparée à une autre profondeur d'objet ou à la profondeur totale de la topologie.

HWLOC_TYPE_DEPTH_UNKNOWN si aucun objet de ce type n'est présent sur l'architecture sous-jacente, ou si le système d'exploitation ne fournit pas ce type d'information.

HWLOC_TYPE_DEPTH_MULTIPLE si le type HWLOC_OBJ_GROUP est donné et que plusieurs niveaux de Groupes existent.

Note

Si le type est absent mais qu'un type similaire est acceptable, voir aussi hwloc_get_type_or_below_depth() et hwloc_get_type_or_above_depth().

Voir aussi

hwloc_get_memory_parents_depth() pour la gestion de la profondeur des objets mémoire.

hwloc_type_sscanf_as_depth() pour retourner la profondeur des objets dont le type est donné sous forme de chaîne de caractères.

hwloc_get_type_or_above_depth

Retourne la profondeur des objets de type type ou au-dessus. Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, la fonction retourne la profondeur du premier objet 'présent' contenant typiquement type.

Cette fonction n'a de sens que pour les types d'objets normaux. Si un type d'objet mémoire, I/O ou Misc est donné, la profondeur virtuelle correspondante est toujours retournée (voir hwloc_get_type_depth()).

Peut retourner HWLOC_TYPE_DEPTH_MULTIPLE pour HWLOC_OBJ_GROUP tout comme hwloc_get_type_depth().

hwloc_get_type_or_below_depth

Retourne la profondeur des objets de type type ou en dessous. Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, la fonction retourne la profondeur du premier objet 'présent' trouvé typiquement à l'intérieur de type.

Cette fonction n'a de sens que pour les types d'objets normaux. Si un type d'objet mémoire, I/O ou Misc est donné, la profondeur virtuelle correspondante est toujours retournée (voir hwloc_get_type_depth()).

Peut retourner HWLOC_TYPE_DEPTH_MULTIPLE pour HWLOC_OBJ_GROUP tout comme hwloc_get_type_depth().

hwloc_topology_get_depth

Obtient la profondeur de l'arbre hiérarchique des objets. C'est la profondeur des objets HWLOC_OBJ_PU plus un.

la profondeur de l'arbre d'objets.
