NOM

heap2exec - génère un exécutable autonome à partir d'une image de tas *SML/NJ*.

SYNTAXE

heap2exec [ -32 | -64 ] [ MODELIAGE ] fichier

DESCRIPTION

En usage normal, SML/NJ représente un programme par un fichier d'image de tas dont le nom est de la forme foo.arch-opsys. Heap2exec génère un exécutable autonome à partir d'une image de tas. Vous avez la possibilité de spécifier un mode de liaison préféré.

Par défaut, la liaison est statique sur FreeBSD et Linux.

Notez que heap2exec est un composant *optionnel* du processus d'installation de SML/NJ et n'est pas inclus par défaut. Modifiez le fichier config/targets avant l'installation pour l'inclure.

OPTIONS

-32

exécute la version 32 bits du programme (actuellement par défaut).

-64

exécute la version 64 bits du programme. Cette option ne s'applique qu'à l'architecture x86-64 (également appelée amd64).

-static, -linkwith-a

lie statiquement le programme avec le système d'exécution. La liaison statique est le mode par défaut sous Linux et FreeBSD.

-dynamic, -linkwith-so

lie dynamiquement le programme avec le système d'exécution.

AUTEUR

Heap2exec a été écrit par Matthias Blume.

VOIR AUSSI

sml(1)

BOGUES

Heap2exec est limité aux architectures x86 et amd64, ainsi qu'aux systèmes d'exploitation macOS, Linux et FreeBSD.
