sous-routine chpsv (caractère uplo, entier n, entier nrhs, complexe, dimension( * ) ap, entier, dimension( * ) ipiv, complexe, dimension( ldb, * ) b, entier ldb, entier info)

CHPSV calcule la solution du système d'équations linéaires A * X = B pour des matrices HERMITIENNES

Objectif :

!>
!> CHPSV calcule la solution d'un système linéaire complexe
!>    A * X = B,
!> où A est une matrice hermitienne N x N stockée au format compact et X
!> et B sont des matrices N x NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A en
!>    A = U * D * U**H,  si UPLO = 'U', ou
!>    A = L * D * L**H,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et triangulaires unitaires supérieures (inférieures),
!> D est hermitienne et diagonale par blocs avec des blocs diagonaux de 1x1 et 2x2.
!> La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEXE, dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          A, stocké de manière compacte dans un tableau linéaire. La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, la matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L à partir de la factorisation
!>          A = U*D*U**H ou A = L*D*L**H calculée par CHPTRF, stockés comme
!>          une matrice triangulaire compactée dans le même format de stockage que A.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Détails des échanges et de la structure de blocs de D, tels que
!>          déterminés par CHPTRF.  Si IPIV(k) > 0, alors les lignes et colonnes
!>          k et IPIV(k) ont été échangées, et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0,
!>          alors les lignes et colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal 2x2.  Si UPLO = 'L' et
!>          IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1 et
!>          -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B du membre de droite N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro.  La factorisation
!>                a été complétée, mais la matrice diagonale par blocs D est
!>                exactement singulière, donc la solution n'a pas pu être
!>                calculée.
!>

NAME


cspsv - solves a system of linear equations A*X = B for a general
  matrix A when A is represented in a complex sparse compressed row storage
  format.






SYNOPSIS


    SUBROUTINE CSPSV( UPLO, N, NRHS, AP, IPIV, B, LDB, INFO )



SUBROUTINE CSPSV( UPLO, N, NRHS, AP, IPIV, B, LDB, INFO )






DESCRIPTION


CSPSV computes the solution to a complex system of linear
  equations A*X = B, where A is an N-by-N symmetric matrix stored in packed
  format and X and B are N-by-NRHS matrices.


The diagonal pivoting method is used to factor A as


    A = U * D * U**T,  if UPLO = 'U', or
    A = L * D * L**T,  if UPLO = 'L',



where U (or L) is a product of permutation and unit upper (lower)
  triangular matrices, D is symmetric and block diagonal with 1-by-1 and 2-by-2
  diagonal blocks. The factored form of A is then used to solve the system of
  equations A*X = B.


This routine calls the appropriate routines for:


    
  
  • characterizing the storage format of A
    • 
  
  • factorizing the matrix A
    • 
  
  • solving the system of equations using the factored form of A
    • 



The packed storage scheme is illustrated by the following example
  when N = 4, UPLO = 'U':


  Two-dimensional storage of the symmetric matrix A:

     a11 a12 a13 a14
         a22 a23 a24
             a33 a34     (aij = aji)
                 a44

  Packed storage of the upper triangle of A:

  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]







PARAMETERS



  
UPLO

  

    
UPLO is CHARACTER*1

    
= 'U': Upper triangle of A is stored;

    
= 'L': Lower triangle of A is stored.

  

  
N

  

    
N is INTEGER

    
The number of linear equations, i.e., the order of the matrix
      A. N >= 0.

  

  
NRHS

  

    
NRHS is INTEGER

    
The number of right hand sides, i.e., the number of columns
      of the matrix B. NRHS >= 0.

  

  
AP

  

    
AP is COMPLEX array, dimension (N*(N+1)/2)

    
On entry, the upper or lower triangle of the symmetric matrix
      A, packed columnwise in a linear array. The j-th column of A is stored in
      the array AP as follows:

    
if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;

    
if UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) for j<=i<=n.

    
See below for further details.

    
On exit, the block diagonal matrix D and the multipliers used
      to obtain the factor U or L from the factorization A = U*D*U**T or A =
      L*D*L**T as computed by CSPTRF, stored as a packed triangular matrix in
      the same storage format as A.

  

  
IPIV

  

    
IPIV is INTEGER array, dimension (N)

    
Details of the interchanges and the block structure of D, as
      determined by CSPTRF. If IPIV(k) > 0, then rows and columns k and
      IPIV(k) were interchanged, and D(k,k) is a 1-by-1 diagonal block. If
      UPLO = 'U' and IPIV(k) = IPIV(k-1) < 0, then rows and columns k-1
      and -IPIV(k) were interchanged and D(k-1:k,k-1:k) is a 2-by-2 diagonal
      block. If UPLO = 'L' and IPIV(k) = IPIV(k+1) < 0, then rows and
      columns k+1 and -IPIV(k) were interchanged and D(k:k+1,k:k+1) is a 2-by-2
      diagonal block.

  

  
B

  

    
B is COMPLEX array, dimension (LDB,NRHS)

    
On entry, the N-by-NRHS right hand side matrix B.

    
On exit, if INFO = 0, the N-by-NRHS solution matrix X.

  

  
LDB

  

    
LDB is INTEGER

    
The leading dimension of the array B. LDB >= max(1,N).

  

  
INFO

  

    
INFO is INTEGER

    
= 0: successful exit

    
< 0: if INFO = -i, the i-th argument had an illegal value

    
> 0: if INFO = i, D(i,i) is exactly zero. The factorization
      has been completed, but the block diagonal matrix D is exactly singular,
      so the solution could not be computed.

subroutine   dspsv (character uplo, integer n, integer nrhs, double precision, dimension( *   ) ap, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b,   integer ldb, integer info)


 DSPSV computes the solution to system of linear equations A *
    X = B for OTHER matrices


Purpose:




DSPSV computes the solution to a real system of linear equations
   A * X = B,
where A is an N-by-N symmetric matrix stored in packed format and X
and B are N-by-NRHS matrices.

The diagonal pivoting method is used to factor A as
   A = U * D * U**T,  if UPLO = 'U', or
   A = L * D * L**T,  if UPLO = 'L',
where U (or L) is a product of permutation and unit upper (lower)
triangular matrices, D is symmetric and block diagonal with 1-by-1
and 2-by-2 diagonal blocks.  The factored form of A is then used to
solve the system of equations A * X = B.





Parameters


UPLO

          UPLO is CHARACTER*1
          = 'U':  Upper triangle of A is stored;
          = 'L':  Lower triangle of A is stored.



N


          N is INTEGER
          The number of linear equations, i.e., the order of the
          matrix A.  N >= 0.



NRHS


          NRHS is INTEGER
          The number of right hand sides, i.e., the number of columns
          of the matrix B.  NRHS >= 0.



AP


          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
          On entry, the upper or lower triangle of the symmetric matrix
          A, packed columnwise in a linear array.  The j-th column of A
          is stored in the array AP as follows:
          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
          See below for further details.

          On exit, the block diagonal matrix D and the multipliers used
          to obtain the factor U or L from the factorization
          A = U*D*U**T or A = L*D*L**T as computed by DSPTRF, stored as
          a packed triangular matrix in the same storage format as A.



IPIV


          IPIV is INTEGER array, dimension (N)
          Details of the interchanges and the block structure of D, as
          determined by DSPTRF.  If IPIV(k) > 0, then rows and columns
          k and IPIV(k) were interchanged, and D(k,k) is a 1-by-1
          diagonal block.  If UPLO = 'U' and IPIV(k) = IPIV(k-1) < 0,
          then rows and columns k-1 and -IPIV(k) were interchanged and
          D(k-1:k,k-1:k) is a 2-by-2 diagonal block.  If UPLO = 'L' and
          IPIV(k) = IPIV(k+1) < 0, then rows and columns k+1 and
          -IPIV(k) were interchanged and D(k:k+1,k:k+1) is a 2-by-2
          diagonal block.



B


          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
          On entry, the N-by-NRHS right hand side matrix B.
          On exit, if INFO = 0, the N-by-NRHS solution matrix X.



LDB


          LDB is INTEGER
          The leading dimension of the array B.  LDB >= max(1,N).



INFO


          INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, D(i,i) is exactly zero.  The factorization
                has been completed, but the block diagonal matrix D is
                exactly singular, so the solution could not be
                computed.
