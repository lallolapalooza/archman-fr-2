hxextract(1)

Paquet: html-xml-utils

Licences: W3C

HXEXTRACT(1) HTML-XML-utils HXEXTRACT(1)

NOM

hxextract - extraire des éléments sélectionnés d'un fichier HTML ou XML

SYNTAXE

hxextract [ -h | -? ] [ -x ] [ -s texte ] [ -e texte ] [ -b base ] élément-ou-classe [ -c fichierconfig | fichier-ou-URL ]

DESCRIPTION

hxextract affiche tous les éléments ayant un nom et/ou une classe donné(e).

L'entrée doit être bien formée, car aucune heuristique HTML n'est appliquée.

OPTIONS

Les options suivantes sont prises en charge :

-x
Utiliser les conventions du format XML.
-s texte
Insérer texte au début de la sortie.
-e texte
Insérer texte à la fin de la sortie.
-b base
URL de base
-c fichierconfig
Lire les lignes @chapter depuis fichierconfig (les lignes doivent être de la forme "@chapter nomfichier") et extraire les éléments de chacun de ces fichiers.
-h, -?
Afficher l'aide de la commande.

OPÉRANDES

Les opérandes suivants sont pris en charge :

élément-ou-classe
Le nom d'un élément à extraire (par exemple, "H2"), ou le nom d'une classe précédé d'un "." (par exemple, ".exemple") ou une combinaison des deux (par exemple, "H2.exemple").
fichier-ou-URL
Un nom de fichier ou une URL. Pour lire depuis l'entrée standard, utilisez "-".

ENVIRONNEMENT

Pour utiliser un proxy afin de récupérer des fichiers distants, définissez les variables d'environnement http_proxy et ftp_proxy. Par exemple, http_proxy="http://localhost:8080/"

BOGUES

Les fichiers distants (spécifiés avec une URL) ne sont actuellement pris en charge que pour HTTP. Les fichiers protégés par mot de passe ou les fichiers qui dépendent des "cookies" HTTP ne sont pas gérés. (Vous pouvez utiliser des outils tels que curl(1) ou wget(1) pour récupérer de tels fichiers.)
