NOM

hxwls - lister les liens dans un fichier HTML

SYNTAXE

hxwls [ -l ] [ -t ] [ -r ] [ -h ] [ -a ] [ -b base ] [ fichier ]

DESCRIPTION

La commande hxwls lit un fichier HTML (l'entrée standard par défaut) et affiche tous les liens qu'elle trouve. La sortie est écrite sur la sortie standard.

OPTIONS

Les options suivantes sont prises en charge :

-l
Produire un listage long. Au lieu de seulement l'URI, hxwls affiche trois colonnes : le nom de l'élément, la valeur de l'attribut REL, et l'URI de destination.
-t
Produire un listage en tuple. hxwls affiche quatre colonnes : l'URI du document lui-même, le nom de l'élément, la valeur de l'attribut REL, et l'URI de destination.
-r
Afficher les URL relatives telles quelles, sans les convertir en URL absolues.
-b base
Utiliser base comme URL de base initiale. S'il y a un élément <base> dans le document, il remplacera l'option -b.
-h
Sortie au format HTML. La sortie sera listée sous la forme d'éléments <a>.
-a
Convertir les IRI (Identifiants de Ressources Internationalisés) en URI ASCII uniquement. Cela entraîne l'encodage des caractères non-ASCII dans le chemin d'un URI en octets échappés en pourcentage et des caractères non-ASCII dans le nom de domaine en punycode. (L'encodage punycode n'est disponible que si hxwls est compilé avec le support de libidn.)

OPÉRANDES

L'opérande suivant est pris en charge :

fichier
Le nom ou l'URL d'un fichier HTML. S'il est absent, l'entrée standard est lue à la place.

DIAGNOSTICS

Les valeurs de sortie suivantes sont retournées :

0
Achèvement réussi.
> 0
Une erreur s'est produite lors de l'analyse du fichier HTML. hxwls essayera de corriger l'erreur et produira quand même une sortie.
