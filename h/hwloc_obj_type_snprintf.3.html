int hwloc_obj_type_snprintf (char *restrict string, size_t size, hwloc_obj_t obj, int

verbose)

Convertit le type d'un objet de topologie donné en une forme lisible par l'homme. Contrairement à hwloc_obj_type_string(), cette fonction inclut les attributs spécifiques à l'objet (tels que la profondeur du groupe, le type de pont ou le type de périphérique OS) dans la sortie, et elle nécessite que l'appelant fournisse le tampon de

sortie.

La sortie est garantie identique pour tous les objets d'un même niveau de

topologie.

Si verbose vaut 1, des noms de types plus longs sont utilisés, par exemple L1Cache au lieu de

L1.

La chaîne de sortie peut être réanalyse par hwloc_type_ss

canf().

Si size vaut 0, string peut être NULL en toute sécurité

.

Renvoi

e
le nombre de caractères réellement écrits si aucune troncature n'a eu lieu, ou le nombre qui aurait été écrit (sans inclure le \0 final)
.

int hwloc_type_sscanf (const char * string, hwloc_obj_type_t * typep, union hwloc_obj_attr_u * attrp, size_t

attrsize)

Renvoie un type d'objet et ses attributs à partir d'une chaîne de type. Convertit des chaînes telles que 'Package' ou 'L1iCache' en types correspondants. La correspondance ne tient pas compte de la casse, et seules les premières lettres sont réellement requises pour

correspondre.

Le type d'objet correspondant est défini dans typep (qui ne peut pas être

NULL).

Les attributs spécifiques au type, par exemple le type de cache, la profondeur de cache, la profondeur de groupe, le type de pont ou le type de périphérique OS peuvent être renvoyés dans attrp. Les attributs qui ne sont pas spécifiés dans la chaîne (par exemple 'Group' sans profondeur, ou 'L2Cache' sans type de cache) sont définis à

-1.

attrp n'est rempli que s'il n'est pas NULL et si sa taille spécifiée dans attrsize est suffisamment grande. Elle doit être au moins aussi grande que union hwloc_obj_attr_u

.

Renvoi

e
0 si un type a été correctement identifié, sinon
-1.

int hwloc_type_sscanf_as_depth (const char * string, hwloc_obj_type_t * typep, hwloc_topology_t topology, int *

depthp)

Renvoie un type d'objet et la profondeur de son niveau à partir d'une chaîne de type. Convertit des chaînes telles que 'Package' ou 'L1iCache' en types correspondants et renvoie dans depthp la profondeur du niveau correspondant dans la

topologie topology.

Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, HWLOC_TYPE_DEPTH_UNKNOWN est

renvoyé.

Si plusieurs tels niveaux existent (par exemple si l'on donne Group sans aucune profondeur), la fonction peut renvoyer HWLOC_TYPE_DEPTH_MULTIPLE à la

place.

Le type d'objet correspondant est défini dans typep si typep n'est pas NULL

.
