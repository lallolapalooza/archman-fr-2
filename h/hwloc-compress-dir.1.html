HWLOC-COMPRESS-DIR(1) hwloc HWLOC-COMPRESS-DIR(1)

NOM

hwloc-compress-dir - Compresser un répertoire de topologies XML

SYNTAXE

hwloc-compress-dir [options] <rep_entree> <rep_sortie>

OPTIONS

-R --reverse
Décompresser un répertoire précédemment compressé.
-v --verbose
Afficher des messages détaillés.
--version
Afficher la version et quitter.
-h --help
Afficher le message d'aide et quitter.

DESCRIPTION

hwloc-compress-dir prend un répertoire d'entrée contenant des exportations XML et tente de le compresser en calculant les différences de topologies entre elles (avec le programme hwloc-diff). Chaque fichier est copié dans le répertoire de sortie, soit sous forme de différence s'il a pu être compressé, soit sous sa forme de fichier original complet sinon.

hwloc-compress-dir peut recompresser un répertoire qui a déjà été compressé. Tous les fichiers d'entrée déjà présents dans le répertoire de sortie, qu'ils soient compressés ou non, sont ignorés. Les nouveaux fichiers d'entrée sont compressés autant que possible comme d'habitude.

Pour chaque fichier du répertoire, le nom du fichier de sortie est identique à l'original s'il n'est pas compressé, sinon son extension est modifiée en .diff.xml.

Les fichiers différenciés générés sont basés sur une autre topologie non compressée. Son nom est stocké dans l'attribut de différence de topologie refname.

Les fichiers de sortie générés peuvent être utilisés avec hwloc-patch tout comme n'importe quel fichier généré par hwloc-diff.

EXEMPLES

Pour compresser les fichiers d'entrée du répertoire in dans le répertoire out :


$ hwloc-compress-dir in out

VALEUR DE RETOUR

Lors de l'exécution réussie, hwloc-compress-dir renvoie 0.

hwloc-compress-dir renverra une valeur non nulle si une erreur quelconque se produit, telle que (mais sans s'y limiter) l'échec de l'analyse de la ligne de commande.

VOIR AUSSI
