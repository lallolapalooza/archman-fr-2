HYPRPICKER(1) Manuel des commandes générales HYPRPICKER(1)

NOM

hyprpicker — sélecteur de couleur compatible wlroots pour Wayland

SYNOPSIS

hyprpicker [-anh] [-f fmt]

DESCRIPTION

L'utilitaire hyprpicker est un sélecteur de couleur prenant en charge divers formats de sortie. Lorsque hyprpicker est invoqué, le curseur se transforme en une loupe, et cliquer sur n'importe quel pixel de l'écran affichera la couleur de ce pixel sur la sortie standard. Le format de sortie par défaut est hexadécimal, mais cela peut être configuré avec l'option -f.

Les options sont les suivantes :

-a, --autocopy
Copie automatiquement la sortie de hyprpicker dans le presse-papiers. Cette option nécessite que la commande wl-copy(1) soit installée sur le système.
-f fmt, --format=fmt
Sélectionne le format dans lequel afficher la couleur du pixel sélectionné. L'argument fmt ne respecte pas la casse. Les options disponibles sont :
cmyk
(« C% M% Y% K% »)
hex
(« #RRGGBB »)
rgb
(« R G B »)
hsl
(« H S% L% »)
hsv
(« H S% V% »)

Le format par défaut est hex.

-n, --no-fancy
Désactive la sortie colorée. Le comportement par défaut est de colorer la sortie avec la même couleur que le pixel sélectionné.
-h, --help
Affiche un message d'aide et quitte le programme avec succès.

ENVIRONNEMENT

NO_COLOR
Si défini, désactive la sortie colorée.

ÉTAT DE SORTIE

L'utilitaire hyprpicker se termine avec un code de sortie de 0 en cas de succès, et un code supérieur à 0 en cas d'erreur.

EXEMPLES

Obtenir la couleur d'un pixel :

$ hyprpicker

Obtenir la couleur d'un pixel en HSL, encapsulée dans une fonction CSS hsl() :

$ hyprpicker -f hsl | sed 's/^/rgb(/; s/$/)/; y/ /,/'
