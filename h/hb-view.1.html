HB-VIEW(1) Commandes utilisateur HB-VIEW(1)

NOM

hb-view - page de manuel pour hb-view 12.2.0

DESCRIPTION

Usage :

hb-view [OPTION ???] [FICHIER-POLICE] [TEXTE]

Visualiser du texte avec la police donnée.

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-face
Options pour la face de police
--help-font
Options pour l'instance de police
--help-variations
Options pour les variations de police utilisées
--help-text
Options pour le texte d'entrée
--help-text-context
Options pour le texte de contexte d'entrée
--help-shape
Options pour le processus de mise en forme
--help-features
Options pour les fonctionnalités de police utilisées
--help-view
Options pour le rendu de la sortie
--help-output
Options pour la destination et la forme de la sortie

Options de face de police :

--font-file=nom-de-fichier
Définir le nom du fichier de police
-y, --face-index=index
Définir l'index de la face (par défaut : 0)
--face-loader=chargeur
Définir le chargeur de face à utiliser (par défaut : ot)
Les chargeurs de face pris en charge sont : ot/ft
--list-face-loaders
Lister les chargeurs de face disponibles et quitter

Options d'instance de police :

--font-size=1/2 entiers ou 'upem'
Taille de la police (par défaut : 256)
--font-ppem=1/2 entiers
Définir les pixels x, y par EM (par défaut : 0 ; désactivé)
--font-ptem=taille-en-points
Définir la taille de la police en points (par défaut : 0 ; désactivé)
--font-bold=1/2 nombres ; par ex. 0.05
Définir le gras synthétique (par défaut : 0)
--font-grade=1/2 nombres ; par ex. 0.05
Définir le grade synthétique (par défaut : 0)
--font-slant=ratio d'inclinaison ; par ex. 0.2
Définir l'inclinaison synthétique (par défaut : 0)
--font-funcs=impl
Définir l'implémentation des fonctions de police à utiliser (par défaut : ot)
Les implémentations des fonctions de police prises en charge sont : ot/ft
--list-font-funcs
Lister les fonctions de police disponibles et quitter
--ft-load-flags=entier
Définir les drapeaux de chargement FreeType (par défaut : 2)

Options de variations :

--named-instance=index
Définir l'index de l'instance nommée (par défaut : aucune)
--variations=liste
Liste de variations de police séparées par des virgules
Les variations sont définies globalement. Le format de spécification des paramètres de variation suit. Toutes les valeurs CSS font-variation-settings valides autres que 'normal' et 'inherited' sont également acceptées, bien que non documentées ci-dessous.
Le format est une étiquette, suivie éventuellement d'un signe égal, puis d'un nombre. Par exemple :
"wght=500" "slnt=-7.5"

Options de texte :

Si aucun texte n'est fourni, l'entrée standard est utilisée pour l'entrée.

--text=chaîne
Définir le texte d'entrée
--text-file=nom-de-fichier
Définir le nom du fichier texte d'entrée
-u, --unicodes=liste de nombres hexadécimaux
Définir les points de code Unicode d'entrée
--single-par
Traiter le texte comme un seul paragraphe

Options de contexte textuel :

--text-before=chaîne
Définir le contexte de texte avant chaque ligne
--text-after=chaîne
Définir le contexte de texte après chaque ligne
--unicodes-before=liste de nombres hexadécimaux
Définir le contexte des points de code Unicode avant chaque ligne
--unicodes-after=liste de nombres hexadécimaux
Définir le contexte des points de code Unicode après chaque ligne

Options de mise en forme :

--shapers=liste séparée par des virgules
Définir les façonneurs à utiliser (par défaut : graphite2)
Les façonneurs pris en charge sont : graphite2/ot/fallback
--list-shapers
Lister les façonneurs disponibles et quitter
--direction=ltr/rtl/ttb/btt
Définir la direction du texte (par défaut : auto)
--language=étiquette BCP 47
Définir la langue du texte (par défaut : $LANG)
--script=étiquette ISO-15924
Définir le script du texte (par défaut : auto)
--bot
Traiter le texte comme le début de paragraphe
--eot
Traiter le texte comme la fin de paragraphe
--preserve-default-ignorables
Conserver les caractères ignorables par défaut
--remove-default-ignorables
Supprimer les caractères ignorables par défaut
--invisible-glyph
Valeur de glyphe pour remplacer les caractères ignorables par défaut
--not-found-glyph
Valeur de glyphe pour remplacer les caractères non trouvés
--not-found-variation-selector-glyph
Valeur de glyphe pour remplacer les caractères non trouvés du sélecteur de variation
--utf8-clusters
Utiliser les indices d'octets UTF8, pas les indices de caractères
--cluster-level=0/1/2/3
Niveau de fusion des clusters (par défaut : 0)
--normalize-glyphs
Réorganiser les clusters de glyphes dans l'ordre nominal
--unsafe-to-concat
Produire le drapeau de glyphe non concaténable en toute sécurité
--safe-to-insert-tatweel
Produire le drapeau de glyphe sûr pour l'insertion de tatweel
--glyphs
Interpréter l'entrée comme une chaîne de glyphes
--ligatures=ALL/NONE/(NULL)
Option pour les ligatures (par défaut : aucune)
--kern
Appliquer le crénage
--vert
Utiliser la forme verticale des glyphes
--fvm
Utiliser des glyphes verticaux pour le texte vertical
--fwd
Utiliser des glyphes horizontaux pour le texte vertical
--fvb
Utiliser des glyphes horizontaux pour le texte horizontal
--mark-index=index
Index de glyphe pour les marques de combinaison (par défaut : 0)
--mark-fallback=index
Index de glyphe pour les marques de combinaison qui n'ont pas de glyphe (par défaut : 0)
--mark-glyph-status=0/1/2
Niveau de rapport pour les glyphes de marques (par défaut : 0)
--zero-width=ALL/NONE/(NULL)
Option pour les glyphes à largeur nulle (par défaut : aucune)

Options de fonctionnalités :

--feature=TAG[=VALUE]
Activer/désactiver/définir une fonctionnalité de police
--no-feature=TAG
Désactiver une fonctionnalité de police

Les fonctionnalités sont définies globalement.

Les étiquettes de fonctionnalité sont des chaînes de 4 caractères, comme 'kern', 'liga', 'calt'. Les valeurs sont des entiers. Par exemple :

--feature=kern=1
--feature=rlig
--no-feature=liga

Les fonctionnalités OpenType disponibles sont les suivantes :

--features
Liste des fonctionnalités de police disponibles et quitter
--gpos-table=TAG
Utiliser la table GPOS spécifiée
--gsub-table=TAG
Utiliser la table GSUB spécifiée

View options :

--output=destination
Définir la destination de la sortie
Les destinations possibles sont : stdout/ttf/png/svg
--output-file=nom-de-fichier
Définir le nom du fichier de sortie
--output-format=format
Définir le format de sortie (png/svg)
--output-background=couleur
Définir la couleur d'arrière-plan
--output-foreground=couleur
Définir la couleur de premier plan
--output-pad=entier
Définir le remplissage autour de la sortie
--output-width=entier
Définir la largeur de la sortie
--output-height=entier
Définir la hauteur de la sortie
--output-dpi=entier
Définir la résolution de sortie en DPI
--output-version=nombre
Définir la version du format de sortie
Les couleurs peuvent être spécifiées au format #RRGGBB, #RRGGBBAA ou par nom (par exemple, 'blanc', 'noir', 'rouge').
--no-ligatures
Ne pas utiliser les ligatures
--no-kern
Ne pas appliquer le crénage
--no-vert
Ne pas utiliser la forme verticale des glyphes
--no-fvm
Ne pas utiliser les glyphes verticaux pour le texte vertical
--no-fwd
Ne pas utiliser les glyphes horizontaux pour le texte vertical
--no-fvb
Ne pas utiliser les glyphes horizontaux pour le texte horizontal
--no-mark-glyph-status
Ne pas afficher le rapport pour les glyphes de marques
--no-zero-width
Ne pas afficher les glyphes à largeur nulle
--font-callbacks=impl
Définir l'implémentation des rappels de police à utiliser (par défaut : ot)
Les implémentations des rappels de police prises en charge sont : ot/ft
--list-font-callbacks
Lister les rappels de police disponibles et quitter
--debug=NIVEAU
Définir le niveau de débogage
Les niveaux de débogage possibles sont : 0/1/2/3/4/5
