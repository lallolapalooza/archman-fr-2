Description Détaillée

Chaque type d'objet est soit Normal (c'est-à-dire que hwloc_obj_type_is_normal() renvoie 1), soit Mémoire (c'est-à-dire que hwloc_obj_type_is_memory() renvoie 1) soit I/O (c'est-à-dire que hwloc_obj_type_is_io() renvoie 1) soit Divers (c'est-à-dire égal à HWLOC_OBJ_MISC). Il ne peut pas être de plus d'un de ces genres.

Voir aussi Genre d'objet dans Termes et Définitions.

Documentation des fonctions

int hwloc_obj_type_is_cache (hwloc_obj_type_t type)

Vérifie si un type d'objet est un Cache CPU (Données, Unifié ou Instructions). Les caches côté mémoire ne sont pas des caches CPU.

Retourne

1 si un objet de type type est un Cache, 0 sinon.

int hwloc_obj_type_is_dcache (hwloc_obj_type_t type)

Vérifie si un type d'objet est un Cache CPU de Données ou Unifié. Les caches côté mémoire ne sont pas des caches CPU.

Retourne

1 si un objet de type type est un Cache CPU de Données ou Unifié, 0 sinon.

int hwloc_obj_type_is_icache (hwloc_obj_type_t type)

Vérifie si un type d'objet est un Cache CPU d'Instructions. Les caches côté mémoire ne sont pas des caches CPU.

Retourne

1 si un objet de type type est un Cache CPU d'Instructions, 0 sinon.

int hwloc_obj_type_is_io (hwloc_obj_type_t type)

Vérifie si un type d'objet est de type I/O. Les objets I/O sont des objets attachés à leurs parents dans la liste des enfants I/O. Cela inclut actuellement les ponts, les périphériques PCI et les périphériques OS.

Retourne

1 si un objet de type type est un objet I/O, 0 sinon.

int hwloc_obj_type_is_memory (hwloc_obj_type_t type)

Vérifie si un type d'objet est de type Mémoire. Les objets Mémoire sont des objets attachés à leurs parents dans la liste des enfants Mémoire. Cela inclut actuellement les nœuds NUMA et les caches côté mémoire.

Retourne

1 si un objet de type type est un objet Mémoire, 0 sinon.

int hwloc_obj_type_is_normal (hwloc_obj_type_t type)

Vérifie si un type d'objet est Normal. Les objets Normaux sont des objets de la hiérarchie principale du CPU (Machine, Package, Cœur, PU, caches CPU, etc.), mais ils ne sont ni des nœuds NUMA, ni des périphériques I/O, ni des objets Divers.

Ils sont attachés à leur parent comme enfants Normaux, et non comme enfants Mémoire, I/O ou Divers.

Retourne

1 si un objet de type type est un objet Normal, 0 sinon.
