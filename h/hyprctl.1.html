NOM

hyprctl - Utilitaire pour contrôler des parties de Hyprland depuis une ligne de commande ou un script

SYNTAXE

hyprctl [(opt)flags] [commande] [(opt)arguments]

DESCRIPTION

hyprctl est un utilitaire permettant de contrôler certaines parties du compositeur depuis une ligne de commande ou un script.

COMMANDES DE CONTRÔLE

dispatch

Appelle un dispatcher avec un argument.

Un argument doit être présent. Pour les dispatchers sans paramètres, il peut s'agir de n'importe quoi.

Retourne : ok en cas de succès, et un message d'erreur en cas d'échec.

Exemples :
hyprctl dispatch exec kitty

hyprctl dispatch pseudo x

keyword

Définit dynamiquement un mot-clé de configuration.

Retourne : ok en cas de succès, et un message d'erreur en cas d'échec.

Exemples :
hyprctl keyword bind SUPER,0,pseudo

hyprctl keyword general:border_size 10

reload

Force le rechargement du fichier de configuration.

kill

Entre en mode kill, où vous pouvez tuer une application en cliquant dessus. Vous pouvez en sortir en appuyant sur ÉCHAP.

COMMANDES D'INFORMATION

version

Affiche la version de Hyprland, les flags, le commit et la branche de la compilation.

monitors

Liste toutes les sorties avec leurs propriétés.

workspaces

Liste tous les espaces de travail avec leurs propriétés.

clients

Liste toutes les fenêtres avec leurs propriétés.

devices

Liste tous les périphériques d'entrée connectés.

activewindow

Retourne le nom de la fenêtre active.

layers

Liste toutes les couches.

splash

Retourne le message d'accueil aléatoire actuel.

OPTIONS

--batch

Spécifie un lot de commandes à exécuter.

Exemple :
hyprctl --batch "keyword general:border_size 2 ; keyword general:gaps_out 20"

; sépare les commandes.

-j

Affiche les informations au format JSON.
