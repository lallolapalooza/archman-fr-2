attachment(1) Manuel des commandes générales attachment(1)

NOM

attachment - Télécharger les pièces jointes de vos messages

SYNTAXE

attachment [-h|--help] <sous-commandes>

DESCRIPTION

Télécharger les pièces jointes de vos messages.

Le corps d'un message peut être composé de plusieurs parties MIME. Une pièce jointe est la représentation d'une partie binaire du corps d'un message.

OPTIONS

-h, --help
Afficher l'aide (voir un résumé avec '-h')

SOUS-COMMANDES

attachment-download(1)
Télécharger toutes les pièces jointes trouvées dans le message donné
attachment-help(1)
Afficher ce message ou l'aide de la ou des sous-commandes données
attachment
