NOM

hugo-server - Démarrer le serveur web embarqué

SYNOPIS

hugo server [commande] [options]

DESCRIPTION

Hugo fournit son propre serveur web qui compile et sert le site. Bien que hugo server soit très performant, c'est un serveur web avec des options limitées.

La commande hugo server écrira et servira par défaut des fichiers depuis le disque, mais vous pouvez rendre en mémoire en utilisant l'option --renderToMemory. Cela peut être plus rapide dans certains cas, mais consommera plus de mémoire.

Par défaut, hugo surveillera également vos fichiers pour tout changement que vous effectuerez et reconstruira automatiquement le site. Il rechargera ensuite à chaud toutes les pages de navigateur ouvertes et leur fournira le contenu le plus récent. Comme la plupart des sites Hugo sont construits en une fraction de seconde, vous pourrez sauvegarder et voir vos changements presque instantanément.

OPTIONS

--appendPort[=true] ajouter le port à baseURL

-b, --baseURL="" nom d'hôte (et chemin) vers la racine, par exemple https://spf13.com/

--bind="127.0.0.1" interface sur laquelle le serveur se liera

-D, --buildDrafts[=false] inclure le contenu marqué comme brouillon

-E, --buildExpired[=false] inclure le contenu expiré

-F, --buildFuture[=false] inclure le contenu dont la date de publication est dans le futur

--cacheDir="" chemin du système de fichiers vers le répertoire de cache

--cleanDestinationDir[=false] supprimer les fichiers du répertoire de destination qui ne se trouvent pas dans les répertoires statiques

-c, --contentDir="" chemin du système de fichiers vers le répertoire de contenu

--disableBrowserError[=false] ne pas afficher les erreurs de compilation dans le navigateur

--disableFastRender[=false] active les re-compilations complètes lors des changements

--disableKinds=[] désactiver différents types de pages (accueil, RSS etc.)

--disableLiveReload[=false] surveiller sans activer le rechargement à chaud du navigateur lors de la recompilation

--enableGitInfo[=false] ajouter les informations de révision Git, de date, d'auteur et de CODEOWNERS aux pages

--forceSyncStatic[=false] copier tous les fichiers lorsque les fichiers statiques sont modifiés.

--gc[=false] activer pour effectuer des tâches de nettoyage (supprimer les fichiers de cache inutilisés) après la compilation

-h, --help[=false] aide pour server

--ignoreCache[=false] ignore le répertoire de cache

-l, --layoutDir="" chemin du système de fichiers vers le répertoire de mise en page

--liveReloadPort=-1 port pour le rechargement à chaud (par exemple 443 dans les situations de proxy HTTPS)

--minify[=false] minifier tout format de sortie pris en charge (HTML, XML etc.)

-N, --navigateToChanged[=false] naviguer vers le fichier de contenu modifié lors du rechargement à chaud du navigateur

--noChmod[=false] ne pas synchroniser le mode de permission des fichiers

--noHTTPCache[=false] empêcher la mise en cache HTTP

--noTimes[=false] ne pas synchroniser l'heure de modification des fichiers

-O, --openBrowser[=false] ouvrir le site dans un navigateur après le démarrage du serveur

--panicOnWarning[=false] paniquer au premier message d'avertissement (WARNING)

--poll="" définir ceci sur un intervalle de sondage, par exemple --poll 700ms, pour utiliser une approche basée sur le sondage pour surveiller les changements du système de fichiers

-p, --port=1313 port sur lequel le serveur écoutera

--pprof[=false] activer le serveur pprof (port 8080)

--printI18nWarnings[=false] afficher les traductions manquantes

--printMemoryUsage[=false] afficher l'utilisation de la mémoire à l'écran à intervalles réguliers

--printPathWarnings[=false] afficher les avertissements sur les chemins de destination dupliqués etc.

--printUnusedTemplates[=false] afficher les avertissements sur les modèles inutilisés.

--renderSegments=[] segments nommés à rendre (configurés dans la configuration des segments)

--renderStaticToDisk[=false] servir les fichiers statiques depuis le disque et les fichiers dynamiques depuis la mémoire

--templateMetrics[=false] afficher les métriques sur l'exécution des modèles

--templateMetricsHints[=false] calculer des indices d'amélioration lorsque combiné avec --templateMetrics

-t, --theme=[] thèmes à utiliser (situés dans /themes/NOM_DU_THEME/)

--tlsAuto[=false] générer et utiliser des certificats locaux de confiance.

--tlsCertFile="" chemin vers le fichier de certificat TLS

--tlsKeyFile="" chemin vers le fichier de clé TLS

--trace="" écrire la trace dans fichier (pas utile en général)

-w, --watch[=true] surveiller le système de fichiers pour les changements et recréer si nécessaire

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--clock="" définir l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de compilation

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de modules correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne pas créer de fichier .hugo_build.lock

--quiet[=false] compiler en mode silencieux

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers à partir duquel lire les fichiers relativement

--themesDir="" chemin du système de fichiers vers le répertoire des thèmes

VOIR AUSSI
