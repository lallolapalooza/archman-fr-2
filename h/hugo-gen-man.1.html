NOM

hugo-gen-man - Génère les pages de manuel pour l'interface en ligne de commande de Hugo

SYNOPSIS

hugo gen man [flags] [args]

DESCRIPTION

Cette commande génère automatiquement des pages de manuel à jour de l'interface en ligne de commande de Hugo. Par défaut, elle crée les fichiers de pages de manuel dans le répertoire "man" sous le répertoire courant.

OPTIONS

--dir="man/" le répertoire où écrire les pages de manuel.

-h, --help[=false] aide pour man

OPTIONS HÉRITÉES DES COMMANDES PARENT

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de module correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne pas créer le fichier .hugo_build.lock

--quiet[=false] construire en mode silencieux

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers à partir duquel lire les fichiers de manière relative

--themesDir="" chemin du système de fichiers du répertoire des thèmes
