hg-rename(1)

Paquet: mercurial

Licences: GPL

HG(RENAME) HG(RENAME)

NOM

hg rename - renomme des fichiers ; équivalent de copier + supprimer

SYNTAXE

hg rename [OPTION]... SOURCE... DEST

DESCRIPTION

Marque DEST comme copie de SOURCES ; marque SOURCES pour suppression. Si DEST est un répertoire, les copies y sont placées. Si DEST est un fichier, il ne peut y avoir qu'une seule source.

Par défaut, cette commande copie le contenu des fichiers tels qu'ils existent dans le répertoire de travail. Si elle est invoquée avec -A/--after, l'opération est enregistrée, mais aucune copie n'est effectuée.

Pour annuler le marquage d'un fichier de destination comme renommé, utilisez --forget. Avec cette option, tous les arguments positionnels donnés sont dé-marqués comme renommés. Le(s) fichier(s) de destination seront laissés en place (toujours suivis). Le(s) fichier(s) source ne seront pas restaurés. Notez que hg rename --forget se comporte de la même manière que hg copy --forget.

Cette commande prend effet avec la prochaine validation par défaut.

Retourne 0 en cas de succès, 1 en cas d'erreurs.

OPTIONS

--forget
dé-marque un fichier de destination comme renommé
-A, --after
enregistre un renommage qui s'est déjà produit
--at-rev <REV>
(dé-)marque les renommages dans la révision donnée (EXPÉRIMENTAL)
-f, --force
déplace de force par-dessus un fichier géré existant
-I,--include <PATTERN[+]>
inclut les noms correspondant aux motifs donnés
-X,--exclude <PATTERN[+]>
exclut les noms correspondant aux motifs donnés
-n, --dry-run
n'effectue pas les actions, affiche seulement la sortie

[+] option marquée pouvant être spécifiée plusieurs fois

ALIAS

move, mv
