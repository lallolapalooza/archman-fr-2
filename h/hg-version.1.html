hg-version(1)

Paquet: mercurial

Licences: GPL

HG(VERSION) HG(VERSION)

NOM

hg version - afficher la version et les informations de copyright

SYNTAXE

hg version

DESCRIPTION

Modèle :

Les mots-clés suivants sont pris en charge. Voir également hg help templates.

extensions
Liste des extensions.
ver
Chaîne. Numéro de version.

Et chaque entrée de {extensions} fournit les mots-clés suivants en plus de {ver}.

bundled
Booléen. Vrai si inclus dans la publication.
name
Chaîne. Nom de l'extension.

OPTIONS

-T,--template <TEMPLATE>
afficher avec un modèle
