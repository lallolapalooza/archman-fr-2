subroutine chesv_aa (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer

info)

CHESV_AA calcule la solution du système d'équations linéaires A * X = B pour les matrices

HE

But

: 
!>
!> CHESV_AA calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne N×N et X et B sont des matrices
!> N×NRHS.
!>
!> L'algorithme de Aasen est utilisé pour factoriser A comme
!>    A = U**H * T * U,  si UPLO = 'U', ou
!>    A = L * T * L**H,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et de matrices
!> triangulaires supérieures (inférieures) unitaires, et T est hermitienne
!> et tridiagonale. La forme factorisée de A est ensuite utilisée pour
!> résoudre le système d'équations A * X = B.
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!
>

N 
!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure principale N×N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie
!>          triangulaire strictement inférieure de A n'est pas référencée.
!>          Si UPLO = 'L', la partie triangulaire inférieure principale N×N
!>          de A contient la partie triangulaire inférieure de la matrice A,
!>          et la partie triangulaire strictement supérieure de A n'est pas
!>          référencée.
!>
!>          À la sortie, si INFO = 0, la matrice tridiagonale T et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à partir
!>          de la factorisation A = U**H*T*U ou A = L*T*L**H tels que
!>          calculés par CHETRF_AA.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          À la sortie, il contient les détails des échanges, c'est-à-dire
!>          que la ligne et la colonne k de A ont été échangées avec la
!>          ligne et la colonne IPIV(k).
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des seconds membres N×NRHS B.
!>          À la sortie, si INFO = 0, la matrice solution N×NRHS X.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= MAX(1,2*N,3*N-2), et pour de
!>          meilleures performances LWORK >= MAX(1,N*NB), où NB est la
!>          taille de bloc optimale pour CHETRF.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale du
!>          tableau WORK, renvoie cette valeur comme première entrée du
!>          tableau WORK, et aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement nul.  La factorisation
!>               a été complétée, mais la matrice diagonale par blocs D est
!>               exactement singulière, donc la solution n'a pas pu être
!>               calculée.
!
>

NAME

hesv_aa — Calculates the solution of a complex Hermitian positive definite system of linear equations with automatic detection of the type of matrix and equilibration.

SYNOPSIS

    SUBROUTINE HESV_AA( UPLO, N, NRHS, A, LDA, IPIV, B, LDB, INFO )

        CHARACTER * 1           UPLO
        INTEGER                 N
        INTEGER                 NRHS
        COMPLEX*16, DIMENSION( LDA, * )  A
        INTEGER, DIMENSION( * )         IPIV
        COMPLEX*16, DIMENSION( LDB, * )  B
        INTEGER                 LDA, LDB, INFO

Detailed Description

hesv_aa solves the complex Hermitian positive definite system of linear equations A*X = B, where A is an N x N complex Hermitian positive definite matrix, X is an N x NRHS matrix, and B is an N x NRHS matrix. hesv_aa uses the LAPACK routines to compute the solution.

Function Documentation

UPLO

CHARACTER*1. Specifies whether the matrix A is upper or lower triangular.

= 'U': Upper triangle of A is stored and used.

= 'L': Lower triangle of A is stored and used.

N

INTEGER. The order of the matrix A. N >= 0.

NRHS

INTEGER. The number of right-hand sides, i.e., the number of columns in the matrices B and X. NRHS >= 0.

A

COMPLEX*16. Dimension (LDA, N). On entry, the Hermitian matrix A. If UPLO = 'U', the upper triangle of A is used. If UPLO = 'L', the lower triangle of A is used.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1, N).

IPIV

INTEGER. Dimension (N). This array contains the pivot indices defined by the partial pivoting strategy used in the factorization routine.

B

COMPLEX*16. Dimension (LDB, NRHS). On entry, the right-hand side matrix B. On exit, the solution matrix X.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1, N).

INFO

INTEGER. = 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = i, the i-th diagonal element of the triangular factor is zero, so that A is singular.
