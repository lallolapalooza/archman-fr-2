NOM

hxname2id - déplace certains attributs NAME et ID d'un A vers son parent

SYNTAXE

hxname2id [ -x ] [ fichier ]

DESCRIPTION

La commande hxname2id lit un fichier HTML et recherche les éléments ayant un élément A comme premier enfant, sans texte intermédiaire autre que des espaces blancs. Si cet élément A possède un attribut ID ou NAME, il est déplacé vers l'élément parent et retiré de A.

Étant donné que Netscape 4 ne comprend pas les attributs ID, il était courant d'écrire <H2><A NAME="sect7">...</A></H2> au lieu de <H2 ID="sect7">. Ce programme peut être utilisé pour convertir de tels anciens fichiers HTML à la nouvelle convention.

D'autres programmes de cette suite, tels que hxmultitoc(1), requièrent des ID sur les en-têtes au lieu d'éléments A avec des attributs NAME. Il est donc utile d'exécuter hxname2id avant d'exécuter hxmultitoc et des programmes similaires. hxname2id peut être utilisé dans un pipe.

OPTIONS

Les options suivantes sont supportées :

-x
Utilise les conventions XML : les éléments vides sont écrits avec une barre oblique à la fin : <IMG />

OPÉRANDES

L'opérande suivant est supporté :

fichier
Le nom d'un fichier HTML. S'il est absent, l'entrée standard est lue à la place.

DIAGNOSTICS

Les valeurs de sortie suivantes sont retournées :

0
Exécution réussie.
> 0
Une erreur s'est produite lors de l'analyse du fichier HTML. hxname2id essaiera de corriger l'erreur et produira quand même une sortie.

VOIR AUSSI

asc2xml(1), hxmultitoc(1), hxnormalize(1), hxnum(1), hxtoc(1), xml2asc(1)

BOGUES

La récupération d'erreurs pour un HTML incorrect est primitive.
