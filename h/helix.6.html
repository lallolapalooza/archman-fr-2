NOM

helix - dessine des motifs artistiques hélicoïdaux

SYNTAXE

helix [--display hôte:écran] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--erase-speed usecs] [--erase-mode entier] [--delay secondes] [--install] [--visual visuel] [--fps]

DESCRIPTION

Le programme helix dessine des motifs intéressants composés de segments de ligne dans des couleurs aléatoires.

OPTIONS

helix accepte les options suivantes :

--window
Dessine sur une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, fait semblant d'être sur un écran monochrome.
--delay secondes
Définit le nombre de secondes pendant lesquelles l'hélice restera à l'écran.
--subdelay microsecondes
Définit le temps de pause périodique pendant le dessin.
--install
Installe une carte de couleurs privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle ou le numéro d'identification (décimal ou hexadécimal) d'un visuel spécifique.
--fps
Affiche le taux d'images par seconde actuel et la charge du processeur.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de fenêtre à utiliser avec --root.
