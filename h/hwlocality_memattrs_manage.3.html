Description

détaillée

Les attributs de mémoire sont identifiés par un ID (hwloc_memattr_id_t) et un nom. hwloc_memattr_get_name() et hwloc_memattr_get_by_name() convertissent entre les deux (ou renvoient une erreur si l'attribut n'existe pas)

.

L'ensemble des hwloc_memattr_id_t valides est un ensemble contigu commençant à 0. Il contient d'abord les attributs prédéfinis, comme listés dans hwloc_memattr_id_e (de 0 à HWLOC_MEMATTR_ID_MAX-1). Ensuite, des attributs personnalisés peuvent être enregistrés dynamiquement avec hwloc_memattr_register(). Ils obtiendront les IDs suivants (HWLOC_MEMATTR_ID_MAX pour le premier, etc.)

.

Pour parcourir tous les attributs valides (qu'ils soient prédéfinis ou enregistrés dynamiquement comme personnalisés), on peut parcourir les IDs à partir de 0 jusqu'à ce que hwloc_memattr_get_name() ou hwloc_memattr_get_flags() renvoie une

erreur.

Les valeurs d'un attribut existant ou d'attributs personnalisés enregistrés dynamiquement peuvent être définies ou modifiées avec hwloc_memattr

_set_va
lue().

NAME

hwlocality_memattrs_manage — Gérer les attributs de mémoire du système hôte

SYNOPSIS

#include <hwloc.h>

int hwloc_memattr_get_value(hwloc_topology_t topology, unsigned Pobjidx, hwloc_memattr_type_t type);
int hwloc_memattr_get_value_by_type(hwloc_topology_t topology, unsigned Pobjidx, hwloc_memattr_type_t type);
hwloc_memattr_type_t hwloc_memattr_type_get_id(hwloc_topology_t topology, const char *name);
const char *hwloc_memattr_type_get_name(hwloc_topology_t topology, hwloc_memattr_type_t type);
int hwloc_memattr_is_valid(hwloc_topology_t topology, unsigned Pobjidx, hwloc_memattr_type_t type);
int hwloc_memattr_set_value(hwloc_topology_t topology, unsigned Pobjidx, hwloc_memattr_type_t type, int value);
int hwloc_memattr_unset(hwloc_topology_t topology, unsigned Pobjidx, hwloc_memattr_type_t type);

Detailed Description

Ce manuel décrit les fonctions permettant de gérer les attributs de mémoire du système hôte.

Enumeration Type Documentation

Les attributs de mémoire sont représentés par des types énumérés (hwloc_memattr_type_t).

Function Documentation

  • hwloc_memattr_get_value: Obtient la valeur d'un attribut de mémoire pour un objet spécifique.

  • hwloc_memattr_get_value_by_type: Idem que hwloc_memattr_get_value.

  • hwloc_memattr_type_get_id: Obtient l'identifiant d'un type d'attribut de mémoire à partir de son nom.

  • hwloc_memattr_type_get_name: Obtient le nom d'un type d'attribut de mémoire à partir de son identifiant.

  • hwloc_memattr_is_valid: Vérifie si un attribut de mémoire est valide pour un objet donné.

  • hwloc_memattr_set_value: Définit la valeur d'un attribut de mémoire pour un objet spécifique.

  • hwloc_memattr_unset: Supprime un attribut de mémoire pour un objet spécifique.
