sous-routine sspgv (entier itype, caractere jobz, caractere uplo, entier n, reel, dimension( * ) ap, reel, dimension( * ) bp, reel, dimension( * ) w, reel, dimension( ldz, * ) z, entier ldz, reel, dimension( * ) work, entier info)

SSPGV

Objectif :

          SSPGV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
          d'un problème propre généralisé symétrique-défini réel, de la forme
          A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x.
          Ici, A et B sont supposés être symétriques, stockés en format compacté,
          et B est également défini positif.

Paramètres

ITYPE 
          ITYPE est un entier.
          Spécifie le type de problème à résoudre :
          = 1 :  A*x = (lambda)*B*x
          = 2 :  A*B*x = (lambda)*x
          = 3 :  B*A*x = (lambda)*x

JOBZ

          JOBZ est un CARACTERE*1.
          = 'N' : Calculer uniquement les valeurs propres ;
          = 'V' : Calculer les valeurs propres et les vecteurs propres.

UPLO

          UPLO est un CARACTERE*1.
          = 'U' : Les triangles supérieurs de A et B sont stockés ;
          = 'L' : Les triangles inférieurs de A et B sont stockés.

N

          N est un entier.
          L'ordre des matrices A et B. N >= 0.

AP

          AP est un tableau REEL, dimensionné (N*(N+1)/2).
          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
          A, compacté par colonne dans un tableau linéaire. La j-ème colonne de A
          est stockée dans le tableau AP comme suit :
          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.

          En sortie, le contenu de AP est détruit.

BP

          BP est un tableau REEL, dimensionné (N*(N+1)/2).
          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
          B, compacté par colonne dans un tableau linéaire. La j-ème colonne de B
          est stockée dans le tableau BP comme suit :
          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) pour 1<=i<=j ;
          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) pour j<=i<=n.

          En sortie, le facteur triangulaire U ou L de la factorisation de Cholesky
          B = U**T*U ou B = L*L**T, dans le même format de stockage
          que B.

W

          W est un tableau REEL, dimensionné (N).
          Si INFO = 0, les valeurs propres par ordre croissant.

Z

          Z est un tableau REEL, dimensionné (LDZ, N).
          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
          vecteurs propres. Les vecteurs propres sont normalisés comme suit :
          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
          si ITYPE = 3, Z**T*inv(B)*Z = I.
          Si JOBZ = 'N', alors Z n'est pas référencé.

LDZ

          LDZ est un entier.
          La dimension principale du tableau Z. LDZ >= 1, et si
          JOBZ = 'V', LDZ >= max(1,N).

WORK

          WORK est un tableau REEL, dimensionné (3*N).

INFO

          INFO est un entier.
          = 0 : sortie réussie.
          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
          > 0 : SPPTRF ou SSPEV a retourné un code d'erreur :
             <= N : si INFO = i, SSPEV n'a pas convergé ;
                    i éléments hors diagonale d'une forme
                    tridiagonale intermédiaire n'ont pas convergé vers zéro.
             > N : si INFO = n + i, pour 1 <= i <= n, alors le mineur
                    principal principal d'ordre i de B n'est pas positif.
                    La factorisation de B n'a pas pu être complétée et
                    aucune valeur propre ou vecteur propre n'a été calculé.
