NOM

hg files - lister les fichiers suivis

SYNTAXE

hg files [OPTION]... [FICHIER]...

DESCRIPTION

Affiche les fichiers sous contrôle de Mercurial dans le répertoire de travail ou pour la révision spécifiée pour les fichiers donnés (excluant les fichiers supprimés). Les fichiers peuvent être spécifiés par leur nom ou par des ensembles de fichiers.

Si aucun fichier n'est donné pour correspondre, cette commande affiche les noms de tous les fichiers sous contrôle de Mercurial.

Modèle :

Les mots-clés suivants sont pris en charge en plus des mots-clés et fonctions de modèle courants. Voir aussi hg help templates.

flags
Chaîne. Caractère dénotant les bits de lien symbolique et d'exécution du fichier.
path
Chaîne. Chemin absolu du fichier dans le dépôt.
size
Entier. Taille du fichier en octets.

Exemples :

  • lister tous les fichiers sous le répertoire courant : 
    hg files .
  • afficher les tailles et les indicateurs pour la révision courante : 
    hg files -vr .
  • lister tous les fichiers nommés README : 
    hg files -I "**/README"
  • lister tous les fichiers binaires : 
    hg files "set:binary()"
  • trouver les fichiers contenant une expression régulière : 
    hg files "set:grep('bob')"
  • rechercher dans le contenu des fichiers suivis avec xargs et grep : 
    hg files -0 | xargs -0 grep foo

    Voir hg help patterns et hg help filesets pour plus d'informations sur la spécification des modèles de fichiers.

    Retourne 0 si une correspondance est trouvée, 1 sinon.

OPTIONS

-r,--rev <REV>
rechercher dans le dépôt tel qu'il est dans REV
-0, --print0
terminer les noms de fichiers par NUL, pour utilisation avec xargs
-I,--include <PATTERN[+]>
inclure les noms correspondant aux modèles donnés
-X,--exclude <PATTERN[+]>
exclure les noms correspondant aux modèles donnés
-T,--template <TEMPLATE>
afficher avec le modèle
-S, --subrepos
répéter dans les sous-dépôts

[+] l'option marquée peut être spécifiée plusieurs fois
