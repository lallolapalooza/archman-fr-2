NOM

hopalong - dessine des fractales du plan réel

SYNTAXE

hopalong [--display hote:ecran] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id nombre] [--mono] [--install] [--visual visual] [--ncolors entier] [--delay microsecondes] [--cycles entier] [--count entier] [--jong] [--no-jong] [--sine] [--no-sine]

[--fps]

DESCRIPTION

Le programme hop génère des fractales du plan réel telles que décrites dans le numéro de septembre 1986 de Scientific American.

OPTIONS

hopalong accepte les options suivantes :

--window
Dessine dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id nombre
Dessine sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, fait semblant d'être sur un écran monochrome.
--install
Installe une palette de couleurs privée pour la fenêtre.
--visual visual
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--ncolors entier
Combien de couleurs utiliser (si possible). Par défaut 200. Les couleurs utilisées varient en teinte, faisant N arrêts autour de la roue chromatique.
--cycles entier
Combien de temps exécuter chaque lot. Par défaut 2500 pixels.
--count entier
Combien de pixels dessiner avant un changement de couleur. Par défaut 1000.
--jong entier
--no-jong entier
Si le format Jong doit être utilisé (par défaut, il est choisi aléatoirement).
--sine entier
--no-sine entier
Si le format Sine doit être utilisé (par défaut, il est choisi aléatoirement).
--fps
Affiche le taux de rafraîchissement actuel et la charge du processeur.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
