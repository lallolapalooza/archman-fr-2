DESCRIPTIO

N

Ce programme fournit un shell simple pour naviguer dans les fichiers « ruches » du Registre Windows. Il utilise la bibliothèque hivex pour accéder à ces fichiers

binaires.

Tout d'abord, vous devrez fournir un fichier ruche provenant d'un système d'exploitation Windows. Les fichiers ruche sont généralement situés dans « C:\Windows\System32\Config » et ont des noms comme « software », « system », etc. (sans aucune extension de fichier). Pour plus d'informations sur les fichiers ruche, lisez hivex(3). Pour des informations sur le téléchargement de fichiers à partir de machines virtuelles, lisez virt-cat(1) et guestfish

(1).

Vous pouvez fournir le nom du fichier ruche à examiner sur la ligne de commande. Par exemple

: 
hivexsh
software

Ou vous pouvez démarrer « hivexsh » sans aucun argument, et utiliser immédiatement la commande « load » pour charger une ruche

: 
$ hivexsh
Bienvenue dans hivexsh, le shell interactif hivex pour examiner
les fichiers ruches binaires du Registre Windows.
Tapez : 'help' pour de l'aide sur les commandes
      'quit' pour quitter le shell
> load software
software\>

Ajoute une sous-clé nommée « nom » sous le nœud courant. Le nom peut contenir des espaces et des caractères de ponctuation, et n'a pas besoin d'être entre guillemets.

La nouvelle clé n'aura ni sous-clés ni valeurs (voir « setval

»).

Il ne doit pas exister de sous-clé appelée « nom », sinon cette commande échouera. Pour remplacer une sous-clé existante, supprimez-la d'abord

comme ceci : 
cd

Change vers la sous-clé « chemin ». Utilisez des barres obliques inversées de style Windows pour séparer les éléments du chemin, et commencez par une barre oblique inversée pour démarrer depuis la racine de la ruche. Par exemple : 
cd
\Classes\*

se déplace du nœud racine, vers le nœud « Classes », vers le nœud « * ». Si vous étiez déjà au nœud racine, vous pourriez faire ceci à

la place : 
cd
Classes\*

ou

même : 
cd Classes
cd *

Les éléments du chemin (noms de nœuds) sont appariés sans tenir compte de la casse, et des caractères comme l'espace, « * », et « ? » n'ont aucune signification

particulière.

« cd .. » peut être utilisé pour aller au répertoire

parent.

« cd » sans aucun argument affiche le chemin

courant.

Soyez prudent avec « cd \ » car la bibliothèque readline a un comportement non documenté où elle pensera que la barre oblique inversée fina

le est une continuation (elle lit la ligne suivante de l'entrée et
l'ajoute). Mettez un espace après la barre oblique inversée.

Liste les sous-clés de la clé courante du Registre de la ruche. Notez que cette commande ne prend aucun
argument.
lsval [

Liste les paires (clé, valeur) de la clé courante du Registre de la ruche. Si aucun argument n'est donné, toutes les paires sont affichées. Si « clave » est donnée, la valeur de la clé nommée est affichée. Si « @ » est donnée, la valeur de la clé par défaut est
affichée.
setval
nbvaleurs
Cette commande remplace toutes les paires (clé, valeur) au nœud courant par les valeurs dans l'entrée suivante. « nbvaleurs » est le nombre de valeurs (c'est-à-dire de paires (clé, valeur)), et toutes les valeurs existantes à ce nœud sont supprimées. Ainsi « setval 0 » supprime simplement toutes les valeurs au nœud courant.

La commande lit 2 * nbvaleurs lignes d'entrée, chaque paire de lignes d'entrée correspondant à une clé et une valeur à

ajouter.

Par exemple, la commande setval suivante remplace ce qui se trouve au nœud courant par deux paires (clé, valeur). La clé par défaut est définie à la chaîne « abcd » encodée en UTF16-LE. L'autre valeur est nommée « ANumber » et est un DWORD little-endian

0x12345678. 
setval 2
@
string:abcd
ANumber
dword:
12345678

La première ligne de chaque paire est la clé (la clé spéciale « @ » signifie la clé par défaut, mais vous pouvez aussi utiliser une ligne

vide).

La deuxième ligne de chaque paire est la valeur, qui a un format spécial « type:valeur » avec les types possibles résumés dans le tableau

ci-dessous : 
none                 Aucune donnée n'est stockée, et le type est défini à 0.
string:abc           « abc » est stocké comme une chaîne
                     encodée en UTF16-LE (type 1). Notez que seules les chaînes
                     ASCII 7 bits sont prises en charge en entrée.
expandstring:...     Identique à string mais avec le type 2.
dword:0x01234567     Un DWORD (type 4) avec la valeur hexadécimale
                     0x01234567. Vous pouvez aussi utiliser une valeur décimale
                     ou octalel numbers here.
qword:0x0123456789abcdef
                     Un QWORD (type 11) avec la valeur hexadécimale
                     0x0123456789abcdef. Vous po
uvez aussi utiliser des nombres décimaux ou octaux ici. hex:<type>:<hexbytes> hex:1:41,00,42,00,43,00,44,00,00,00 C'
est la façon générique de saisir n'importe quelle valeur. <type> est le type de valeur entière. <hexbytes> est une
liste de paires de chiffres hexadécimaux traitées comme des octets. (Tous les caractères non hexadécimaux sont
ignorés, vous pouvez donc séparer les octets par des virgules ou des espaces si vous le souhaitez).
