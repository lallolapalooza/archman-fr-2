HYDROGEN(29) Commandes utilisateur HYDROGEN(29)

NOM

hydrogen - une boîte à rythmes / séquenceur pas à pas simple.

SYNTAXE

hydrogen [-v] [-h] -s fichier

DESCRIPTION

Hydrogen 1.2.6 [http://www.hydrogen-music.org]. Copyright 2002-2008 Alessandro Cominu, Copyright 2008-2025 L'équipe de développement Hydrogen.

Hydrogen est une boîte à rythmes avancée pour GNU/Linux. Son objectif principal est d'apporter une programmation de batterie basée sur des motifs, professionnelle, simple et intuitive.

Hydrogen est fourni SANS AUCUNE GARANTIE. C'est un logiciel libre, et vous êtes invité à le redistribuer sous certaines conditions. Voir le fichier COPYING pour les détails.

OPTIONS

-P, --data CHEMIN - Utiliser un chemin de données système alternatif

-d, --driver PILOTEAUDIO - Utiliser le pilote audio sélectionné (jack, alsa, oss)

-s, --song FICHIER - Charger une chanson (*.h2song) au démarrage

-p, --playlist FICHIER - Charger une liste de lecture (*.h2playlist) au démarrage

-k, --kit nom_batterie - Charger une batterie au démarrage

-i, --install FICHIER - installer une batterie (*.h2drumkit)

-O, --osc-port - Utiliser un port OSC personnalisé

-n, --nosplash - Masquer l'écran de démarrage

-V[Niveau], --verbose[=Niveau] - Afficher beaucoup d'informations de débogage

Niveau, s'il est présent, peut être None, Error, Warning, Info, Debug ou 0xHHHH

-L, --log-file - Utiliser un fichier journal personnalisé

-T, --log-timestamps - Ajouter des horodatages à tous les messages du journal

-v, --version - Afficher les informations de version

-h, --help - Afficher ce message d'aide

FICHIERS

hydrogen.conf

Paramètres par défaut et de démarrage pour Hydrogen.

data/*

Peut contenir les données de l'utilisateur telles que les batteries, les motifs, les listes de lecture, les chansons, ...

ENVIRONNEMENT

LADSPA_PATH

Chemin vers les plugins LADSPA.
