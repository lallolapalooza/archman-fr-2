HG(COPY) HG(COPY)

NOM

hg copy - marquer des fichiers comme copiés pour le prochain commit

SYNTAXE

hg copy [OPTION]... (SOURCE... DEST | --forget DEST...)

DESCRIPTION

Marque dest comme ayant des copies des fichiers source. Si dest est un répertoire, les copies sont placées dans ce répertoire. Si dest est un fichier, la source doit être un fichier unique.

Par défaut, cette commande copie le contenu des fichiers tel qu'il existe dans le répertoire de travail. Si elle est invoquée avec -A/--after, l'opération est enregistrée, mais aucune copie n'est effectuée.

Pour annuler le marquage d'un fichier de destination comme copié, utilisez --forget. Avec cette option, tous les arguments (positionnels) donnés sont désélectionnés comme copies. Les fichiers de destination seront laissés en place (toujours suivis). Notez que hg copy --forget se comporte de la même manière que hg rename --forget.

Cette commande prend effet avec le prochain commit par défaut.

Retourne 0 en cas de succès, 1 si des erreurs sont rencontrées.

OPTIONS

--forget
désélectionner un fichier de destination comme copié
-A, --after
enregistrer une copie qui s'est déjà produite
--at-rev <REV>
(désélectionner) marquer des copies dans la révision donnée (EXPÉRIMENTAL)
-f, --force
copier de force par-dessus un fichier géré existant
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-n, --dry-run
ne pas effectuer les actions, juste afficher la sortie

[+] l'option marquée peut être spécifiée plusieurs fois

ALIAS
