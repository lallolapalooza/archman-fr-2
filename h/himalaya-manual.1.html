NOM

manual - Génère les pages de manuel dans le répertoire donné

SYNTAXE

manual [-h|--help] <DIR>

DESCRIPTION

Génère les pages de manuel dans le répertoire donné.

Cette commande vous permet de générer des pages de manuel (en suivant le format des pages de manuel) dans le répertoire spécifié. Si le répertoire n'existe pas, il sera créé. Les pages de manuel existantes seront écrasées.

OPTIONS

-h, --help
Affiche l'aide (voir un résumé avec '-h')
<DIR>
Répertoire dans lequel les fichiers de manuel doivent être générés
