Description

détaillée

Le type hwloc_bitmap_t représente un ensemble d'entiers (positifs ou nuls). Un bitmap peut être de taille infinie (tous les bits sont définis après un certain point). Un bitmap peut même être complet si tous les bits sont

définis.

Les bitmaps sont utilisés par hwloc pour les ensembles de processeurs du système d'exploitation (qui peuvent en fait être des fils matériels) comme par hwloc_cpuset_t (un typedef pour hwloc_bitmap_t), ou les ensembles de nœuds de mémoire NUMA comme hwloc_nodeset_t (également un typedef pour hwloc_bitmap_t). Ceux-ci sont utilisés pour les champs cpuset et nodeset dans la structure hwloc_obj, voir Ensembles d'objets (hwloc_cpuset_t et

hwloc_nodeset_t).

Les ensembles de CPU et de nœuds sont toujours indexés par le numéro physique du système d'exploitation. Cependant, les utilisateurs ne devraient généralement pas construire manuellement les ensembles de CPU et de nœuds (par ex. avec hwloc_bitmap_set()). On devrait plutôt utiliser les ensembles d'objets existants et les combiner avec hwloc_bitmap_or(), etc. Par exemple, l'ancrage du thread courant sur une paire de cœurs peut être effectué avec

: 
hwloc_obj_t core1 = ... , core2 = ... ;
hwloc_bitmap_t set = hwloc_bitmap_alloc();
hwloc_bitmap_or(set, core1->cpuset, core2->cpuset);
hwloc_set_cpubind(topology, set, HWLOC_CPUBIND_THREAD);
hwloc_bitmap_free(set)
;

int hwloc_bitmap_singlify (hwloc_bitmap_t bitmap)

Garde un seul indice parmi ceux définis dans la bitmap bitmap. Peut être utile avant une liaison afin que le processus n'ait pas la possibilité de migrer entre plusieurs processeurs dans le masque d'origine. Au lieu de lancer la tâche sur n'importe quel PU à l'intérieur de l'ensemble de processeurs donné, le planificateur du système d'exploitation sera forcé de l'exécuter sur un seul de ces PUs. Cela évite une surcharge de migration et des "ping-pongs" de lignes de cache entre les PUs.

Note

Cette fonction n'est PAS destinée à distribuer plusieurs processus au sein d'un même ensemble de processeurs. Elle retourne toujours le même bit unique lorsqu'elle est appelée plusieurs fois sur le même ensemble d'entrée. hwloc_distrib() peut être utilisée pour générer des ensembles de processeurs afin de distribuer plusieurs tâches sous un seul objet multi-PU.

Cette fonction ne peut pas être appliquée directement à un ensemble d'objets. Elle doit être appliquée à une copie (qui peut être obtenue avec hwloc_bitmap_dup()).

Représente une bitmap sous forme de chaîne de caractères au format hwloc par défaut. Notez que si la bitmap est un CPU ou un ensemble de nœuds, elle contient des indices physiques.

Affiche les bits définis dans une bitmap sous forme de liste hexadécimale de blocs de 32 bits séparés par des virgules. Une bitmap contenant les bits 1, 33, 34 et tous les bits de 64 à 95 sera affichée sous la forme '0xffffffff,0x00000006,0x00000002'.

le nombre de caractères qui ont été effectivement écrits si la sortie n'est pas tronquée, ou qui auraient été écrits (sans inclure le '\0' final).

-1 en cas d'erreur.

int hwloc_bitmap_sscanf (hwloc_bitmap_t bitmap, const char *restrict string)

Analyse une chaîne de bitmap au format hwloc par défaut et la stocke dans la bitmap bitmap. Notez que si la bitmap est un CPU ou un ensemble de nœuds, la chaîne d'entrée doit contenir des indices physiques.

La chaîne d'entrée doit être une liste de blocs hexadécimaux de 32 bits séparés par des virgules. La chaîne '0xffffffff,0x6,0x2' est analysée comme une bitmap contenant tous les bits entre 64 et 95, ainsi que les bits 33, 34 et 1.

Retourne

Représente une bitmap sous forme de chaîne de caractères spécifique au format taskset, nouvellement allouée. Notez que si la bitmap est un CPU ou un ensemble de nœuds, elle contient des indices physiques.

Le programme taskset manipule des chaînes de bitmaps qui contiennent un seul nombre hexadécimal (potentiellement très long) commençant par 0x. Une bitmap contenant les bits 1, 33, 34 et tous les bits de 64 à 95 sera affichée sous la forme '0xffffffff0000000600000002'.

int hwloc_bitmap_taskset_sscanf (hwloc_bitmap_t bitmap, const char *restrict string)

Analyse une chaîne de bitmap spécifique à taskset et la stocke dans la bitmap bitmap. Notez que si la bitmap est un CPU ou un ensemble de nœuds, la chaîne d'entrée doit contenir des indices physiques.

Le programme taskset manipule des chaînes de bitmaps qui contiennent un seul nombre hexadécimal (potentiellement très long) commençant par 0x. La chaîne '0xffffffff0000000600000002' est analysée comme une bitmap contenant tous les bits entre 64 et 95, ainsi que les bits 33, 34 et 1.
