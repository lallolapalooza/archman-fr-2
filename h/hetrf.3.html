subroutine chetrf (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CHETRF

But :

!>
!> CHETRF calcule la factorisation d'une matrice hermitienne complexe A
!> en utilisant la méthode de pivotage diagonal de Bunch-Kaufman. La
!> forme de la factorisation est
!>
!>    A = U*D*U**H  ou  A = L*D*L**H
!>
!> où U (ou L) est un produit de matrices de permutation et de matrices
!> triangulaires supérieures (inférieures) unitaires, et D est
!> hermitienne et bloc-diagonale avec des blocs diagonaux de taille
!> 1-par-1 et 2-par-2.
!>
!> Il s'agit de la version par blocs de l'algorithme, qui appelle les
!> BLAS de niveau 3.
!>

Paramètres

UPLO 
!>          UPLO est de type CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est de type INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A. Si UPLO = 'U', la
!>          partie triangulaire supérieure de A de taille N-par-N
!>          contient la partie triangulaire supérieure de la matrice A,
!>          et la partie strictement triangulaire inférieure de A n'est
!>          pas référencée. Si UPLO = 'L', la partie triangulaire
!>          inférieure de A de taille N-par-N contient la partie
!>          triangulaire inférieure de la matrice A, et la partie
!>          strictement triangulaire supérieure de A n'est pas
!>          référencée.
!>
!>          À la sortie, la matrice bloc-diagonale D et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L
!>          (voir ci-dessous pour plus de détails).
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D.
!>          Si IPIV(k) > 0, alors les lignes et les colonnes k et
!>          IPIV(k) ont été échangées et D(k,k) est un bloc diagonal
!>          de taille 1-par-1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes
!>          et les colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal de taille 2-par-2.
!>          Si UPLO = 'L' et IPIV(k) = IPIV(k+1) < 0, alors les lignes
!>          et les colonnes k+1 et -IPIV(k) ont été échangées et
!>          D(k:k+1,k:k+1) est un bloc diagonal de taille 2-par-2.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La longueur de WORK. LWORK >= 1. Pour de meilleures
!>          performances, LWORK >= N*NB, où NB est la taille de bloc
!>          renvoyée par ILAENV.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur
!>                 illégale
!>          > 0 :  si INFO = i, D(i,i) est exactement nul. La
!>                 factorisation a été complétée, mais la matrice
!>                 bloc-diagonale D est exactement singulière, et une
!>                 division par zéro se produira si elle est utilisée
!>                 pour résoudre un système d'équations.
!>

!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  c.-à-d. U est un produit de termes P(k)*U(k), où k décroît de n à

!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  c.-à-d. L est un produit de termes P(k)*L(k), où k croît de 1 à
!>  n par pas de 1 ou 2, et D est une matrice bloc-diagonale avec des
!>  blocs diagonaux D(k) de taille 1-par-1 et 2-par-2. P(k) est une
!>  matrice de permutation telle que définie par IPIV(k), et L(k) est
!>  une matrice triangulaire inférieure unitaire, telle que si le bloc
!>  diagonal D(k) est d'ordre s (s = 1 ou 2), alors
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) écrase A(k,k), et v écrase A(k+1:n,k).
!>  Si s = 2, le triangle inférieur de D(k) écrase A(k,k), A(k+1,k)
!>  et A(k+1,k+1), et v écrase A(k+2:n,k:k+1).
!>

NAME


csytrf, dsytrf, ssytrf - factorize a real or complex symmetric matrix






SYNOPSIS


Standard `f2c` interfaces for this subroutine are not
  available.


The Fortran77 `csytrf`, `dsytrf`, `ssytrf` subroutines may be
  called directly by C code.  The interface is as follows:


void csytrf_(const char *uplo, const int *n,
           complex *a, const int *lda, int *ipiv,
           complex *work, const int *lwork, int *info);
void dsytrf_(const char *uplo, const int *n,
           double *a, const int *lda, int *ipiv,
           double *work, const int *lwork, int *info);
void ssytrf_(const char *uplo, const int *n,
           float *a, const int *lda, int *ipiv,
           float *work, const int *lwork, int *info);







DESCRIPTION


The subroutine computes the factorization of a real or complex
  symmetric matrix A using the Bunch-Kaufman diagonal pivoting method. The form
  of the factorization is


   A = U**T * D * U   or   A = L * D * L**T



where U (or L) is a product of permutation and unit upper (lower)
  triangular matrices, and D is symmetric and block diagonal with 1-by-1 and
  2-by-2 diagonal blocks.


This is the blocked version of the algorithm, calling Level 3 BLAS.


The symmetric matrix A is represented as follows:


   If UPLO = 'U', then the upper triangle of A is stored and the
   strictly lower triangle of A is not referenced.

   If UPLO = 'L', then the lower triangle of A is stored and the
   strictly upper triangle of A is not referenced.



On exit, the structure of A is as follows:


If UPLO = 'U', then


   The block diagonal matrix D is stored in the upper triangle of A.
   The multipliers which determine U are stored in the strictly lower
   triangle of A.

   If the diagonal block D(k) is of order s (s = 1 or 2), then the
   multipliers which determine U(k) are stored in the k-th column
   below the diagonal block D(k).



If UPLO = 'L', then


   The block diagonal matrix D is stored in the lower triangle of A.
   The multipliers which determine L are stored in the strictly upper
   triangle of A.

   If the diagonal block D(k) is of order s (s = 1 or 2), then the
   multipliers which determine L(k) are stored in the k-th row
   to the right of the diagonal block D(k).



The diagonal block D is not explicitly stored but is available
  implicitly in the array A.




subroutine   csytrf (character uplo, integer n, complex, dimension( lda, * ) a,   integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work,   integer lwork, integer info)


CSYTRF


Purpose:




!>
!> CSYTRF computes the factorization of a complex symmetric matrix A using
!> the Bunch-Kaufman diagonal pivoting method.  The form of the
!> factorization is
!>
!>    A = U * D * U**H   or   A = L * D * L**H
!>
!> where U (or L) is a product of permutation and unit upper (lower)
!> triangular matrices, and D is symmetric and block diagonal with
!> 1-by-1 and 2-by-2 diagonal blocks.
!>
!> This is the blocked version of the algorithm, calling Level 3 BLAS.
!> 




Parameters


UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!> 


N


!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!> 


A


!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.  If UPLO = 'U', the leading
!>          N-by-N upper triangular part of A contains the upper
!>          triangular part of the matrix A, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading N-by-N lower triangular part of A contains the lower
!>          triangular part of the matrix A, and the strictly upper
!>          triangular part of A is not referenced.
!>
!>          On exit, the block diagonal matrix D and the multipliers used
!>          to obtain the factor U or L (see below for further details).
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


IPIV


!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges and the block structure of D.
!>          If IPIV(k) > 0, then rows and columns k and IPIV(k) were
!>          interchanged and D(k,k) is a 1-by-1 diagonal block.
!>          If UPLO = 'U' and IPIV(k) = IPIV(k-1) < 0, then rows and
!>          columns k-1 and -IPIV(k) were interchanged and D(k-1:k,k-1:k)
!>          is a 2-by-2 diagonal block.  If UPLO = 'L' and IPIV(k) =
!>          IPIV(k+1) < 0, then rows and columns k+1 and -IPIV(k) were
!>          interchanged and D(k:k+1,k:k+1) is a 2-by-2 diagonal block.
!> 


WORK


!>          WORK is COMPLEX array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The length of WORK.  LWORK >=1.  For best performance
!>          LWORK >= N*NB, where NB is the block size returned by ILAENV.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, D(i,i) is exactly zero.  The factorization
!>                has been completed, but the block diagonal matrix D is
!>                exactly singular, and division by zero will occur if it
!>                is used to solve a system of equations.
!> 




Author


Univ. of Tennessee

Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.




Further Details:




!>
!>  If UPLO = 'U', then A = U*D*U**T, where
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  i.e., U is a product of terms P(k)*U(k), where k decreases from n to
!>  1 in steps of 1 or 2, and D is a block diagonal matrix with 1-by-1
!>  and 2-by-2 diagonal blocks D(k).  P(k) is a permutation matrix as
!>  defined by IPIV(k), and U(k) is a unit upper triangular matrix, such
!>  that if the diagonal block D(k) is of order s (s = 1 or 2), then
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  If s = 1, D(k) overwrites A(k,k), and v overwrites A(1:k-1,k).
!>  If s = 2, the upper triangle of D(k) overwrites A(k-1,k-1), A(k-1,k),
!>  and A(k,k), and v overwrites A(1:k-2,k-1:k).
!>
!>  If UPLO = 'L', then A = L*D*L**T, where
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  i.e., L is a product of terms P(k)*L(k), where k increases from 1 to
!>  n in steps of 1 or 2, and D is a block diagonal matrix with 1-by-1
!>  and 2-by-2 diagonal blocks D(k).  P(k) is a permutation matrix as
!>  defined by IPIV(k), and L(k) is a unit lower triangular matrix, such
!>  that if the diagonal block D(k) is of order s (s = 1 or 2), then
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  If s = 1, D(k) overwrites A(k,k), and v overwrites A(k+1:n,k).
!>  If s = 2, the lower triangle of D(k) overwrites A(k,k), A(k+1,k),
!>  and A(k+1,k+1), and v overwrites A(k+2:n,k:k+1).
!>
