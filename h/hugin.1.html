NOM

hugin - Créateur de panoramas Hugin

SYNTAXE

hugin fichier_projet|fichiers_image ...

DESCRIPTION

Hugin est un outil graphique pour la création de panoramas.

Cette page de manuel est une ébauche. La documentation complète de l'interface graphique est disponible dans le manuel en ligne accessible via le menu Aide. De plus, il existe des outils en ligne de commande connexes listés ci-dessous dans la section VOIR AUSSI.

OPTIONS

Hugin n'a pas d'options en ligne de commande.
