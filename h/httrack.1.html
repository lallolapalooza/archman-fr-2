DESCRIPTIO

N

httrack vous permet de télécharger un site du World Wide Web depuis Internet vers un répertoire local, en construisant récursivement tous les répertoires, en récupérant les fichiers HTML, les images et autres fichiers du serveur vers votre ordinateur. HTTrack organise la structure de liens rel

ative du site d'origine. Ouvrez simplement une page du site web « miroir » dans votre navigateur, et vous pouvez naviguer sur le site de lien en
lien, comme si vous l'affichiez en ligne. HTTrack peut également mettre à jour un site miroir existant et reprendre des téléchargements interrompus.

EXEMPLE

S
httrack www.someweb.
com/bob/

met en miroir le site www.someweb.com/bob/ et uniquement ce
site
httrack www.someweb.com/bob/ www.anothertest.com/mike/ +*.com/*.jpg -mime:
application/*

met les deux sites en miroir ensemble (avec liens partagés) et accepte tous les fichiers .jpg sur les sites .
com
httrack www.someweb.com/bob/bobby.html +*
-r6
signifie récupérer tous les fichiers à partir de bobby.html, avec une profondeur de liens de 6, et la possibilité d'aller partout sur le
web
httrack www.someweb.com/bob/bobby.html --spider -P proxy.myhost.com:
8080

LIMITE

S

Voici les principales limites de HTTrack pour le moment. Notez que nous n'avons pas connaissance d'une autre utilité qui les aurait

résolues.

- Plusieurs scripts générant des noms de fichiers complexes peuvent ne pas les trouver (ex : img.src='image'+a+Mobj.dst+'.

gif')

- Certaines classes java peuvent ne pas trouver certains fichiers sur elles (classe

incluse)

- Les liens cgi-bin peuvent ne pas fonctionner correct

ement dans certains cas (paramètres nécessaires). P
our les éviter : utilisez des filtres comme -*cgi-bin*
