NOM

hugo-new-site - Créer un nouveau site

SYNTAXE

hugo new site [chemin] [options]

DESCRIPTION

Crée un nouveau site au chemin spécifié.

OPTIONS

-f, --force[=false] initialise à l'intérieur d'un répertoire non vide

--format="toml" format de fichier préféré (toml, yaml ou json)

-h, --help[=false] aide pour site

OPTIONS HÉRITÉES DES COMMANDES PARENT

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers pour écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de module correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne crée pas de fichier .hugo_build.lock

--quiet[=false] construit en mode silencieux

-M, --renderToMemory[=false] rend en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers pour lire les fichiers à partir de la source

--themesDir="" chemin du système de fichiers pour le répertoire des thèmes
