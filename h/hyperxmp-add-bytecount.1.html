NOM

hyperxmp-add-bytecount - ajoute/met à jour la spécification byteCount dans le paquet XMP du fichier PDF.

SYNTAXE

hyperxmp-add-bytecount [options] nom_fichier.pdf...

DESCRIPTION

hyperxmp-add-bytecount ajoute/met à jour la spécification byteCount dans le paquet XMP d'un ou plusieurs fichiers PDF, avec byteCount = taille du fichier. Le paquet XMP doit être du format produit par un document utilisant le package LaTeX hyperxmp, ou être compatible avec celui-ci.

Si aucun paquet XMP d'un format compatible n'est trouvé dans le fichier PDF, aucune modification n'est apportée au fichier.

OPTIONS

-help
Écrit un résumé d'utilisation et quitte.
-version
Affiche les informations de version et quitte.

BOGUES
