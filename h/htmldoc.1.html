NOM

htmldoc - convertir des fichiers sources html en fichiers html, postscript ou pdf.

SYNTAXE

htmldoc [options] fichier1.{html,md} [ ... fichierN.{html,md} ]

htmldoc [options] -

htmldoc [fichier.book]

DESCRIPTION

Htmldoc(1) convertit les fichiers sources HTML et Markdown en fichiers HTML indexés, PostScript ou Portable Document Format (PDF) qui peuvent être visualisés en ligne ou imprimés. Sans aucune option, un document HTML est produit sur la sortie standard.

La seconde forme de htmldoc lit la source HTML depuis l'entrée standard, ce qui vous permet d'utiliser htmldoc comme un filtre.

La troisième forme de htmldoc lance une interface graphique qui vous permet de modifier les options et de générer des documents de manière interactive.

ERREURS COURANTES

Il existe deux types de fichiers HTML : les documents structurés utilisant des titres (H1, H2, etc.) que htmldoc appelle des "livres", et les documents non structurés n'utilisant pas de titres que htmldoc appelle des "pages web".

Une erreur très courante est d'essayer de convertir une page web en utilisant :

    htmldoc -f fichier.pdf fichier.html
qui produira probablement un fichier PDF sans pages. Pour convertir des fichiers de pages web, vous devez utiliser les options --webpage ou --continuous en ligne de commande ou choisir Web Page ou Continuous dans l'onglet d'entrée de l'interface graphique.

OPTIONS

Les options de ligne de commande suivantes sont supportées par htmldoc :

--batch fichier.book
Génère le fichier de livre spécifié sans ouvrir l'interface graphique.
--bodycolor couleur
Spécifie la couleur d'arrière-plan de toutes les pages.
--bodyfont {courier,helvetica,monospace,sans,serif,times}
--textfont {courier,helvetica,monospace,sans,serif,times}
Spécifie la police de caractères par défaut pour tout le texte normal.
--bodyimage nom_de_fichier
Spécifie l'image d'arrière-plan qui sera répétée sur toutes les pages.
--book
Spécifie que les sources HTML sont structurées (titres, chapitres, etc.)
--bottom marge
Spécifie la marge inférieure en points (pas de suffixe ou ##pt), pouces (##in), centimètres (##cm) ou millimètres (##mm).
--charset {cp-nnnn,iso-8859-1,...,iso-8859-15,utf-8}
Spécifie le jeu de caractères à utiliser pour la sortie. Note : Le support de UTF-8 est limité aux 128 premiers caractères Unicode trouvés dans l'entrée.
--color
Spécifie que la sortie PostScript ou PDF doit être en couleur.
--continuous
Spécifie que les sources HTML sont non structurées (pages web simples.) Aucun saut de page n'est inséré entre chaque fichier ou URL dans la sortie.
--datadir répertoire
Spécifie l'emplacement des fichiers de données de htmldoc, généralement /usr/share/htmldoc ou C:/Program Files/HTMLDOC.
--duplex
Spécifie que la sortie doit être formatée pour une impression recto-verso.
--effectduration {0.1...10.0}
Spécifie la durée en secondes des effets de transition de page PDF.
--embedfonts
Spécifie que les polices doivent être intégrées dans la sortie PDF et PostScript.
--encryption
Active le chiffrement des fichiers PDF.
--fontsize taille
Spécifie la taille de police par défaut pour le texte du corps.
--fontspacing espacement
Spécifie l'interlignage par défaut pour le texte du corps. L'interlignage est un multiplicateur de la taille de police, donc une valeur de 1.2 fournira un espace supplémentaire de 20% entre les lignes.
--footer fff
Définit le pied de page à utiliser sur les pages du corps. Voir la section FORMATS DES EN-TÊTES/PIEDS DE PAGE ci-dessous.
--format format
-t format
Spécifie le format de sortie : epub, html, htmlsep (fichiers HTML séparés pour chaque titre dans la table des matières), ps ou ps2 (PostScript Level 2), ps1 (PostScript Level 1), ps3 (PostScript Level 3), pdf11 (PDF 1.1/Acrobat 2.0), pdf12 (PDF 1.2/Acrobat 3.0), pdf ou pdf13 (PDF 1.3/Acrobat 4.0), ou pdf14 (PDF 1.4/Acrobat 5.0).
--gray
Spécifie que la sortie PostScript ou PDF doit être en niveaux de gris.
--header fff
Définit l'en-tête à utiliser sur les pages du corps. Voir la section FORMATS DES EN-TÊTES/PIEDS DE PAGE ci-dessous.
--header1 fff
Définit l'en-tête à utiliser sur la première page du corps/chapitre. Voir la section FORMATS DES EN-TÊTES/PIEDS DE PAGE ci-dessous.
--headfootfont police
Définit la police à utiliser pour les en-têtes et les pieds de page.
--headfootsize taille
Définit la taille de la police à utiliser pour les en-têtes et les pieds de page.
--headingfont typefaces
Définit le type de police à utiliser pour les titres.
--help
Affiche un résumé des options de ligne de commande.
--helpdir répertoire
Spécifie l'emplacement des fichiers d'aide en ligne de htmldoc, généralement /usr/share/doc/htmldoc ou C:/Program Files/HTMLDOC/DOC.
--hfimageN nom_de_fichier
Spécifie une image (numérotée de 1 à 10) à utiliser dans l'en-tête ou le pied de page dans un document PostScript ou PDF.
--jpeg[=qualité]
Définit le niveau de compression JPEG à utiliser pour les grandes images. Une valeur de 0 désactive la compression JPEG.
--left marge
Spécifie la marge gauche en points (pas de suffixe ou ##pt), pouces (##in), centimètres (##cm) ou millimètres (##mm).
--letterhead nom_de_fichier
Spécifie une image à utiliser comme papier à lettre dans l'en-tête ou le pied de page dans un document PostScript ou PDF. Notez que vous devez utiliser les options --header, --header1, et/ou --footer avec le paramètre L ou utiliser les commentaires de page HTML correspondants pour afficher l'image du papier à lettre dans l'en-tête ou le pied de page.
--linkcolor couleur
Définit la couleur des liens.
--links
Active la génération de liens dans les fichiers PDF (par défaut).
--linkstyle {plain,underline}
Définit le style des liens.
--logoimage nom_de_fichier
Spécifie une image à utiliser comme logo dans l'en-tête ou le pied de page dans un document PostScript ou PDF, et dans la barre de navigation d'un document HTML. Notez que vous devez utiliser les options --header, --header1, et/ou --footer avec le paramètre l ou utiliser les commentaires de page HTML correspondants pour afficher l'image du logo dans l'en-tête ou le pied de page.

OPTIONS

--no-compression
Désactive la compression des fichiers PostScript ou PDF.
--no-duplex
Désactive l'impression recto verso.
--no-embedfonts

Spécifie que les polices ne doivent pas être intégrées dans la sortie PDF et PostScript.
--no-encryption
Désactive le chiffrement du document.
--no-jpeg
Désactive la compression JPEG des grandes images.
--no-links
Désactive la génération de liens dans un document PDF.
--no-numbered
Désactive la numérotation automatique des titres.
--no-pscommands
Désactive la génération des commandes PostScript setpagedevice.
--no-strict
Désactive la vérification stricte de l'entrée HTML.
--no-title
Désactive la génération d'une page de titre.
--no-toc
Désactive la génération d'une table des matières.
--numbered
Numérote tous les titres d'un document.
--nup pages
Définit le nombre de pages placées sur chaque page de sortie. Les valeurs valides sont 1, 2, 4, 6, 9 et 16.
--outdir directory
-d directory
Spécifie que la sortie doit être envoyée dans un répertoire en plusieurs fichiers. (Non compatible avec la sortie PDF)
--outfile filename
-f filename
Spécifie que la sortie doit être envoyée dans un seul fichier.
--owner-password password
Définit le mot de passe propriétaire pour les fichiers PDF chiffrés.
--pageduration I{1.0...60.0}
Définit la durée d'affichage d'une page dans un document PDF.
--pageeffect effect
Spécifie l'effet de transition de page pour toutes les pages ; cet attribut est ignoré par tous les visualiseurs PDF Adobe.
--pagelayout {single,one,twoleft,tworight}
Spécifie la disposition initiale des pages pour un fichier PDF.
--pagemode {document,outlines,fullscreen}
Spécifie le mode de visualisation initial pour un fichier PDF.
--path
Spécifie un chemin de recherche pour les fichiers d'un document.
--permissions permission[,permission,...]
Spécifie les permissions du document pour les fichiers PDF chiffrés. Les permissions suivantes sont comprises : all, none, annotate, no-annotate, copy, no-copy, modify, no-modify, print, et no-print. Séparez les permissions multiples par des virgules.
--pre-indent distance
Spécifie l'indentation du texte pré-formaté en points (pas de suffixe ou ##pt), en pouces (##in), en centimètres (##cm) ou en millimètres (##mm).
--pscommands
Spécifie que les commandes PostScript setpagedevice doivent être incluses dans la sortie.
--quiet
Supprime tous les messages, même les messages d'erreur.
--referer url
Spécifie l'URL qui est passée dans le champ Referer: des requêtes HTTP.
--right margin
Spécifie la marge droite en points (pas de suffixe ou ##pt), en pouces (##in), en centimètres (##cm) ou en millimètres (##mm).
--size pagesize
Spécifie la taille de la page en utilisant un nom standard ou en points (pas de suffixe ou ##x##pt), en pouces (##x##in), en centimètres (##x##cm) ou en millimètres (##x##mm). Les tailles standard actuellement reconnues sont "letter" (8.5x11in), "legal" (8.5x14in), "a4" (210x297mm) et "universal" (8.27x11in).
--strict
Active la vérification stricte de l'entrée HTML.
--textcolor color
Spécifie la couleur par défaut de tout le texte.
--title
Active la génération d'une page de titre.
--titlefile filename
--titleimage filename
Spécifie le fichier à utiliser pour la page de titre. Si le fichier est une image, la page de titre est automatiquement générée en utilisant les métadonnées du document et l'image de titre.
--tocfooter fff
Définit le pied de page à utiliser sur les pages de la table des matières. Voir la section FORMATS D'EN-TÊTE/PIED DE PAGE ci-dessous.
--tocheader fff
Définit l'en-tête de page à utiliser sur les pages de la table des matières. Voir la section FORMATS D'EN-TÊTE/PIED DE PAGE ci-dessous.
--toclevels levels
Définit le nombre de niveaux dans la table des matières.
--toctitle string
Définit le titre de la table des matières.
--top margin
Spécifie la marge supérieure en points (pas de suffixe ou ##pt), en pouces (##in), en centimètres (##cm) ou en millimètres (##mm).
--user-password password
Spécifie le mot de passe utilisateur pour le chiffrement des fichiers PDF.
--verbose
-v
Fournit des messages détaillés.
--version
Affiche le numéro de version actuel.
--webpage
Spécifie que les sources HTML sont non structurées (pages Web simples). Une coupure de page est insérée entre chaque fichier ou URL dans la sortie.

STATUS DE SORTIE

Htmldoc renvoie un statut de sortie non nul si des erreurs sont rencontrées, zéro sinon.

FORMATS D'EN-TÊTE/PIED DE PAGE

L'en-tête et le pied de page de chaque page peuvent contenir jusqu'à trois valeurs pré-formatées. Ces valeurs sont spécifiées à l'aide d'un seul caractère pour la gauche, le milieu et la droite de la page, résultant en la notation fff indiquée précédemment.

Chaque caractère peut être l'un des suivants :

.
espace vide
/
numéros de page arabes n/N (1/3, 2/3, 3/3)
:
numéros de page arabes de chapitre c/C (1/2, 2/2, 1/4, 2/4, ...)
1
chiffres arabes (1, 2, 3, ...)
a
lettres minuscules
A
lettres majuscules
c
titre de chapitre actuel
C
numéro de page du chapitre actuel (arabe)
d
date actuelle
D
date et heure actuelles
h
titre actuel
i
chiffres romains minuscules
I
chiffres romains majuscules
l
image du logo
L
image du logo en en-tête - l'image est insérée à sa taille maximale
t
texte du titre
T
heure actuelle
u
nom de fichier ou URL actuel

ENVIRONNEMENT

HTMLDOC recherche plusieurs variables d'environnement qui peuvent remplacer les répertoires par défaut, afficher des informations de débogage supplémentaires et désactiver le mode CGI :

HTMLDOC_DATA
Cette variable d'environnement spécifie l'emplacement des répertoires de données et de polices de htmldoc, normalement /usr/share/htmldoc ou C:/Program Files/HTMLDOC.
HTMLDOC_DEBUG
Cette variable d'environnement active les informations de débogage qui sont envoyées sur stderr. La valeur est une liste de mots-clés parmi les suivants, séparés par des espaces : "all", "links", "memory", "remotebytes", "table", "tempfiles", et/ou "timing".
HTMLDOC_HELP
Cette variable d'environnement spécifie l'emplacement du répertoire de documentation de htmldoc, normalement /usr/share/doc/htmldoc ou C:/Program Files/HTMLDOC/doc.
HTMLDOC_NOCGI
Cette variable d'environnement, lorsqu'elle est définie (la valeur n'a pas d'importance), désactive le mode CGI. Elle est particulièrement utile pour utiliser htmldoc sur un serveur Web à partir d'un langage de scripting ou d'une invocation depuis un programme.

EX

EXEMPLES

Créer un fichier PDF à partir d'un site web :

    htmldoc --webpage -f example.pdf http://www.example.com/

Créer un livre PostScript à partir d'un répertoire de fichiers HTML

    htmldoc --book -f example.pdf *.html
