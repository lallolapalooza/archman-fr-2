NOM

hugo-new-theme - Créer un nouveau thème

SYNTAXE

hugo new theme [nom] [flags]

DESCRIPTION

Crée un nouveau thème avec le nom spécifié dans le répertoire ./themes. Ceci génère un thème fonctionnel comprenant des exemples de modèles et du contenu d'exemple.

OPTIONS

--format="toml" format de fichier préféré (toml, yaml ou json)

-h, --help[=false] aide pour theme

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--clock="" définit l'horloge utilisée par Hugo, par ex. --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers pour écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de modules correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne crée pas le fichier .hugo_build.lock

--quiet[=false] construction en mode silencieux

-M, --renderToMemory[=false] rendu en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers pour lire les fichiers relativement à

--themesDir="" chemin du système de fichiers du répertoire des thèmes
