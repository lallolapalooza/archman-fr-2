halp(1) Manuel des commandes générales halp(1)

NOM

halp - Un outil CLI pour obtenir de l'aide sur les outils CLI 🐙

SYNTAXE

halp [--check] [--no-version] [--no-help] [-c|--config] [-t|--timeout] [-v|--verbose] [-h|--help] [-V|--version] <CMD> [sous-commandes]

DESCRIPTION

Un outil CLI pour obtenir de l'aide sur les outils CLI 🐙

OPTIONS

--check=ARG
Définit l'argument à vérifier
--no-version
Désactive la vérification des informations de version
--no-help
Désactive la vérification des informations d'aide
-c, --config=CHEMIN
Définit le fichier de configuration
Peut également être spécifié avec la variable d'environnement HALP_CONFIG.
-t, --timeout=S
Définit le délai d'attente pour la commande
-v, --verbose
Active la journalisation détaillée
-h, --help
Affiche l'aide
-V, --version
Affiche la version
<CMD>
Nom de la commande ou du binaire

SOUS-COMMANDES

halp-plz(1)
Obtenir de l'aide supplémentaire
