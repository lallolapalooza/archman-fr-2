HG(SHELVE) HG(SHELVE)

NOM

hg shelve - sauvegarder et mettre de côté les modifications du répertoire de travail

SYNOPSIS

hg shelve [OPTION]... [FICHIER]...

DESCRIPTION

La mise en étagère (shelving) prend les fichiers que "hg status" indique comme non propres, sauvegarde les modifications dans un paquet (un changement mis en étagère), et restaure les fichiers de sorte que leur état dans le répertoire de travail devienne propre.

Pour restaurer ces modifications dans le répertoire de travail, utilisez "hg unshelve"; cela fonctionnera même si vous passez à un commit différent.

Lorsque aucun fichier n'est spécifié, "hg shelve" sauvegarde tous les fichiers non propres. Si des fichiers ou des répertoires spécifiques sont nommés, seules les modifications apportées à ces fichiers sont mises en étagère.

Dans la mise en étagère brute (lorsqu'aucun fichier n'est spécifié, sans les options interactive, include et exclude), la mise en étagère mémorise les informations si le répertoire de travail était sur une branche nouvellement créée, c'est-à-dire si le répertoire de travail était sur une branche différente de son premier parent. Dans cette situation, la désétagère restaure les informations de branche dans le répertoire de travail.

Chaque changement mis en étagère a un nom qui facilite sa recherche ultérieure. Le nom d'un changement mis en étagère est par défaut basé sur le marqueur actif, ou s'il n'y a pas de marqueur actif, sur la branche nommée actuelle. Pour spécifier un nom différent, utilisez --name.

Pour voir la liste des changements mis en étagère existants, utilisez l'option --list. Pour chaque changement mis en étagère, cela affichera son nom, son âge et sa description ; utilisez --patch ou --stat pour plus de détails.

Pour supprimer des changements spécifiques mis en étagère, utilisez --delete. Pour supprimer tous les changements mis en étagère, utilisez --cleanup.

OPTIONS

-A, --addremove
marquer les fichiers nouveaux/manquants comme ajoutés/supprimés avant la mise en étagère
-u, --unknown
stocker les fichiers inconnus dans l'étagère
--cleanup
supprimer tous les changements mis en étagère
--date <DATE>
mettre en étagère avec la date de commit spécifiée
-d, --delete
supprimer le(s) changement(s) mis en étagère nommé(s)
-e, --edit
invoquer l'éditeur sur les messages de commit
-k, --keep
mettre en étagère, mais garder les modifications dans le répertoire de travail
-l, --list
lister les étagères actuelles
-m,--message <TEXTE>
utiliser le texte comme message d'étagère
-n,--name <NOM>
utiliser le nom donné pour le commit mis en étagère
-p, --patch
afficher les patches pour les modifications (fournir les noms des changements mis en étagère comme arguments positionnels)
-i, --interactive
mode interactif
--stat
afficher un résumé des modifications de type diffstat (fournir les noms des changements mis en étagère comme arguments positionnels)
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés

[+] L'option marquée peut être spécifiée plusieurs fois
