NOM

hugo-config-mounts - Affiche les montages de fichiers configurés

SYNTAXE

hugo config mounts [indicateurs] [arguments]

DESCRIPTION

Affiche les montages de fichiers configurés

OPTIONS

-b, --baseURL="" nom d'hôte (et chemin) vers la racine, par exemple https://spf13.com/

--cacheDir="" chemin d'accès au répertoire de cache

-c, --contentDir="" chemin d'accès au répertoire de contenu

-h, --help[=false] aide pour mounts

--renderSegments=[] segments nommés à rendre (configurés dans la configuration des segments)

-t, --theme=[] thèmes à utiliser (situés dans /themes/NOM_THÈME/)

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut est hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin d'accès pour écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de modules correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne crée pas de fichier .hugo_build.lock

--quiet[=false] construction en mode silencieux

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin d'accès pour lire les fichiers relativement depuis

--themesDir="" chemin d'accès au répertoire des thèmes
