NOM

hwloc-diff - Calculer les différences entre deux topologies XML

SYNTAXE

hwloc-diff [options] <input1.xml> <input2.xml>

hwloc-diff [options] <input1.xml> <input2.xml> <output.xml>

OPTIONS

--refname <nom>
Utiliser <nom> comme identifiant pour la topologie de référence dans la différence XML de sortie. Il est destiné à indiquer quelle topologie doit être utilisée lors de l'application de la différence résultante. hwloc-patch peut utiliser ce nom pour charger automatiquement la topologie de référence XML pertinente. Par défaut, <input1.xml> est utilisé sans son chemin complet.
--version
Afficher la version et quitter.
-h --help
Afficher le message d'aide et quitter.

DESCRIPTION

hwloc-diff calcule la différence entre deux topologies XML et stocke le résultat dans <output.xml> si spécifié, sinon l'affiche sur la sortie standard.

La différence de sortie peut être appliquée ultérieurement à une autre topologie avec hwloc-patch.

hwloc-compress-dir peut être utilisé pour calculer les différences entre tous les fichiers XML d'un répertoire.

NOTE : Si des données utilisateur spécifiques à une application ont été exportées dans les fichiers XML d'entrée, elles seront ignorées et supprimées de la sortie car hwloc n'a aucun moyen de les comprendre et de les comparer.

NOTE : Il est fortement recommandé de lire la page d'aperçu de hwloc(7) avant de lire cette page de manuel. La plupart des concepts décrits dans hwloc(7) s'appliquent directement à l'utilitaire hwloc-diff.

EXEMPLES

Le fonctionnement de hwloc-diff est mieux décrit par plusieurs exemples.

Calculer la différence entre deux topologies XML et l'afficher sur la sortie standard :


$ hwloc-diff fourmi023.xml fourmi024.xml
11 différences trouvées, exportation vers stdout
<?xml version="1.0" encoding="UTF-8"?>
...

Afficher la différence dans le fichier diff.xml à la place :


$ hwloc-diff fourmi023.xml fourmi024.xml diff.xml
11 différences trouvées, exportation vers diff.xml

Lorsqu'une différence est trop complexe pour être représentée :


$ hwloc-diff fourmi023.xml avakas-frontend1.xml
1 différence trouvée, dont 1 trop complexe.
Impossible d'exporter les différences vers stdout

Calculer directement la différence entre deux topologies et l'appliquer à une autre :


$ hwloc-diff fourmi023.xml fourmi024.xml | hwloc-patch fourmi025.xml -

VALEUR DE RETOUR

En cas de succès, hwloc-diff affiche la différence. La valeur de retour est 0.

Si la différence est trop complexe pour être représentée, une erreur est retournée et la sortie n'est pas générée.

hwloc-diff retourne également une valeur non nulle si une erreur quelconque survient, telle que (mais sans s'y limiter) l'échec de l'analyse de la ligne de commande.
