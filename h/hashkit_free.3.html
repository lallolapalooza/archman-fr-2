hashkit_free(3)

HASHKIT_FREE(3) libmemcached-awesome HASHKIT_FREE(3)

NOM

hashkit_free - Documentation libhashkit

SYNTAXE

#include <libhashkit-1.0/hashkit.h>
Compiler et lier avec -lhashkit
typedef struct hashkit_st hashkit_st
hashkit_st *hashkit_create(hashkit_st *hash)
Paramètres
hash -- adresse mémoire d'une structure hashkit_st ; si un nullptr est passé, la structure sera allouée dynamiquement par libhashkit
Retourne
pointeur vers la structure hashkit_st initialisée
hashkit_st *hashkit_clone(hashkit_st *destination, const hashkit_st *ptr)
Paramètres
  • destination -- adresse mémoire d'une structure hashkit_st ; si un nullptr est passé, la structure sera allouée dynamiquement par libhashkit
  • ptr -- pointeur de la structure hashkit_st à copier
Retourne
pointeur vers une structure hashkit_st (destination, si non-nullptr), initialisée à partir de ptr
void hashkit_free(hashkit_st *hash)
Paramètres
hash -- pointeur vers une structure hashkit_st initialisée
bool hashkit_is_allocated(const hashkit_st *hash)
Paramètres
hash -- pointeur vers une structure hashkit_st initialisée
Retourne
bool, si la structure hash a été allouée dynamiquement

DESCRIPTION

La fonction hashkit_create() initialise un objet hashkit pour utilisation. Si vous passez un argument nullptr pour hash, la mémoire pour l'objet est allouée. Si vous spécifiez un espace mémoire pré-alloué, celui-ci est initialisé pour utilisation.

La fonction hashkit_clone() initialise un objet hashkit de manière similaire à hashkit_create(), mais au lieu d'utiliser les paramètres par défaut, elle utilisera les paramètres de l'objet hashkit ptr.

La fonction hashkit_free() libère toutes les ressources consommées par les objets hashkit qui ont été initialisés avec hashkit_create() ou hashkit_clone().

La fonction hashkit_is_allocated() signale si la mémoire a été allouée pour un objet hashkit.

VALEUR RETOURNÉE

hashkit_create() et hashkit_clone() retourneront nullptr en cas d'échec ou un pointeur vers hashkit_st en cas de succès.

hashkit_is_allocated() renvoie true si la mémoire pour l'objet hashkit a été allouée à l'intérieur de hashkit_create() ou hashkit_clone(), sinon elle est false et il s'agissait de mémoire fournie par l'utilisateur.
