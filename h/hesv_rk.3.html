Objectif:

!> CHESV_RK calcule la solution d'un système d'équations linéaires complexes A * X = B,
!> où A est une matrice hermitienne N x N et X et B sont des matrices N x NRHS.
!>
!> La méthode de pivotement diagonal bornée de Bunch-Kaufman (tour) est utilisée
!> pour factoriser A en
!>    A = P*U*D*(U**H)*(P**T),  si UPLO = 'U', ou
!>    A = P*L*D*(L**H)*(P**T),  si UPLO = 'L',
!> où U (ou L) est une matrice triangulaire supérieure (ou inférieure) unitaire,
!> U**H (ou L**H) est le conjugué de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est hermitienne et bloc-diagonale avec des blocs
!> diagonaux de 1x1 et 2x2.
!>
!> CHETRF_RK est appelée pour calculer la factorisation d'une matrice hermitienne complexe.
!> La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations
!> A * X = B en appelant la routine BLAS3 CHETRS_3.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' : La partie supérieure de A est stockée ;
!>          = 'L' : La partie inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA,N)
!>          En entrée, la matrice hermitienne A.
!>            Si UPLO = 'U' : la partie supérieure N x N de A contient la partie
!>            triangulaire supérieure de la matrice A, et la partie strictement
!>            inférieure de A n'est pas référencée.
!>
!>            Si UPLO = 'L' : la partie inférieure N x N de A contient la partie
!>            triangulaire inférieure de la matrice A, et la partie strictement
!>            supérieure de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, la diagonale de la matrice bloc-diagonale
!>          D et les facteurs U ou L tels que calculés par CHETRF_RK :
!>            a) SEULEMENT les éléments diagonaux de la matrice hermitienne
!>               bloc-diagonale D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>
!>          Pour plus d'informations, voir la description de la routine CHETRF_RK.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX de dimension (N)
!>          En sortie, contient la sortie calculée par la routine de factorisation
!>          CHETRF_RK, c'est-à-dire les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice hermitienne bloc-diagonale D avec des blocs diagonaux
!>          de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>
!>          Pour plus d'informations, voir la description de la routine CHETRF_RK.
!>

IPIV

!>          IPIV est un tableau INTEGER de dimension (N)
!>          Détails des échanges et de la structure des blocs de D,
!>          tels que déterminés par CHETRF_RK.
!>
!>          Pour plus d'informations, voir la description de la routine CHETRF_RK.
!>

B

!>          B est un tableau COMPLEX de dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B de dimension N x NRHS.
!>          En sortie, si INFO = 0, la matrice solution X de dimension N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX de dimension ( MAX(1,LWORK) ).
!>          Tableau de travail utilisé lors de l'étape de factorisation.
!>          En sortie, si INFO = 0, WORK(1) retourne la valeur LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur de WORK.  LWORK >= 1. Pour une performance optimale
!>          de l'étape de factorisation, LWORK >= max(1,N*NB), où NB est
!>          la taille de bloc optimale pour CHETRF_RK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK
!>          pour l'étape de factorisation, retourne cette valeur comme
!>          première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>
!>          < 0 : Si INFO = -k, le k-ième argument n'était pas valide
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient uniquement des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient uniquement des zéros.
!>
!>               Par conséquent, D(k,k) est exactement zéro, et les éléments
!>               superdiagonaux de la colonne k de U (ou les éléments
!>               sous-diagonaux de la colonne k de L) sont tous des zéros.
!>               La factorisation a été complétée, mais la matrice bloc-diagonale
!>               D est exactement singulière, et une division par zéro se produira
!>               si elle est utilisée pour résoudre un système d'équations.
!>
!>               NOTE : INFO ne stocke que la première occurrence
!>               d'une singularité ; toute occurrence ultérieure de singularité
!>               n'est pas stockée dans INFO, même si la factorisation
!>               s'achève toujours.
!>

NAME

CSYSV_RK, DSYSV_RK - solve a system of linear equations for symmetric matrices with the bounded Bunch-Kaufman (rook) diagonal pivoting method.

SYNOPSIS

SUBROUTINE CSYSV_RK(UPLO, N, NRHS, A, LDA, E, IPIV, B, LDB, WORK, LWORK, INFO)
    CHARACTER(LEN=1) UPLO
    INTEGER          N, NRHS, LDA, LDB, LWORK, INFO
    COMPLEX(KIND=8)  A(LDA, *), E(*), B(LDB, *), WORK(*)
    INTEGER          IPIV(*)

SUBROUTINE DSYSV_RK(UPLO, N, NRHS, A, LDA, E, IPIV, B, LDB, WORK, LWORK, INFO)
    CHARACTER(LEN=1) UPLO
    INTEGER          N, NRHS, LDA, LDB, LWORK, INFO
    DOUBLE PRECISION A(LDA, *), E(*), B(LDB, *), WORK(*)
    INTEGER          IPIV(*)

DESCRIPTION

CSYSV_RK and DSYSV_RK compute the solution to a complex/real system of linear equations Ax = B, where A is an N-by-N symmetric matrix and X and B are N-by-NRHS matrices.

The bounded Bunch-Kaufman (rook) diagonal pivoting method is used to factor A as

A = P*U*D*(Uᵀ)*(Pᵀ), if UPLO = 'U', or
A = P*L*D*(Lᵀ)*(Pᵀ), if UPLO = 'L',

where U (or L) is a unit upper (or lower) triangular matrix, Uᵀ (or Lᵀ) is the transpose of U (or L), P is a permutation matrix, Pᵀ is the transpose of P, and D is symmetric and block diagonal with 1-by-1 and 2-by-2 diagonal blocks. The routines CSYTRF_RK and DSYTRF_RK are called to compute the factorization of a complex/real symmetric matrix. The factored form of A is then used to solve the system of equations Ax = B by calling the BLAS3 routine CSYTRS_3 or DSYTRS_3.

The routines store the factors U (or L) and the block diagonal matrix D.

  • If UPLO = 'U', then U and D are stored in A and E.
  • If UPLO = 'L', then L and D are stored in A and E.

The array E stores the superdiagonal (or subdiagonal) elements of the symmetric block diagonal matrix D. For 1-by-1 diagonal blocks, the corresponding element in E is set to zero.

The array IPIV records the details of the interchanges and the block structure of D.

PARAMETERS

UPLO

CHARACTER*1. Specifies whether the upper or lower triangular part of the symmetric matrix A is stored.

UPLO = 'U': Upper triangle of A is stored.

UPLO = 'L': Lower triangle of A is stored.

N

INTEGER. The number of linear equations, i.e., the order of the matrix A. N ≥ 0.

NRHS

INTEGER. The number of right hand sides, i.e., the number of columns of the matrix B. NRHS ≥ 0.

A

COMPLEX(KIND=8) or DOUBLE PRECISION array, dimension (LDA,N).

On entry, the symmetric matrix A.

If UPLO = 'U', the leading N-by-N upper triangular part of A contains the upper triangular part of A, and the strictly lower triangular part of A is not referenced.

If UPLO = 'L', the leading N-by-N lower triangular part of A contains the lower triangular part of A, and the strictly upper triangular part of A is not referenced.

On exit, if INFO = 0, the diagonal of the block diagonal matrix D and factors U or L as computed by CSYTRF_RK or DSYTRF_RK:

  • Only the diagonal elements of the symmetric block diagonal matrix D are stored on the diagonal of A, i.e., D(k,k) = A(k,k). The superdiagonal (or subdiagonal) elements of D are stored in array E.
  • If UPLO = 'U', the factor U is stored in the superdiagonal part of A.
  • If UPLO = 'L', the factor L is stored in the subdiagonal part of A.

For more information, see the description of CSYTRF_RK or DSYTRF_RK.

LDA

INTEGER. The leading dimension of the array A. LDA ≥ max(1,N).

E

COMPLEX(KIND=8) or DOUBLE PRECISION array, dimension (N).

On exit, contains the output computed by the factorization routine CSYTRF_RK or DSYTRF_RK, i.e., the superdiagonal (or subdiagonal) elements of the symmetric block diagonal matrix D with 1-by-1 or 2-by-2 diagonal blocks. Specifically:

If UPLO = 'U': E(i) = D(i-1,i), i=2:N. E(1) is set to 0.

If UPLO = 'L': E(i) = D(i+1,i), i=1:N-1. E(N) is set to 0.

Note: For a 1-by-1 diagonal block D(k), where 1 ≤ k ≤ N, the element E(k) is set to 0 in both UPLO = 'U' and UPLO = 'L' cases.

For more information, see the description of CSYTRF_RK or DSYTRF_RK.

IPIV

INTEGER array, dimension (N).

Details of the interchanges and the block structure of D, as determined by CSYTRF_RK or DSYTRF_RK.

For more information, see the description of CSYTRF_RK or DSYTRF_RK.

B

COMPLEX(KIND=8) or DOUBLE PRECISION array, dimension (LDB,NRHS).

On entry, the N-by-NRHS right hand side matrix B.

On exit, if INFO = 0, the N-by-NRHS solution matrix X.

LDB

INTEGER. The leading dimension of the array B. LDB ≥ max(1,N).

WORK

COMPLEX(KIND=8) or DOUBLE PRECISION array, dimension (MAX(1,LWORK)).

Workspace array used in the factorization stage.

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

INTEGER.

The length of WORK. LWORK ≥ 1.

For best performance of the factorization stage, LWORK ≥ max(1,N*NB), where NB is the optimal blocksize for CSYTRF_RK or DSYTRF_RK.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array for the factorization stage, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

INFO

INTEGER.

= 0: Successful exit.

< 0: If INFO = -k, the k-th argument had an illegal value.

> 0: If INFO = k, the matrix A is singular, because:

  • If UPLO = 'U': column k in the upper triangular part of A contains all zeros.
  • If UPLO = 'L': column k in the lower triangular part of A contains all zeros.

Therefore D(k,k) is exactly zero, and the superdiagonal elements of column k of U (or subdiagonal elements of column k of L) are all zeros. The factorization has been completed, but the block diagonal matrix D is exactly singular, and division by zero will occur if it is used to solve a system of equations.

Note: INFO only stores the first occurrence of a singularity; any subsequent occurrence of singularity is not stored in INFO, even though the factorization always completes.

!> ZSYSV_RK calcule la solution d'un système d'équations linéaires
!> complexes A * X = B, où A est une matrice symétrique N par N
!> et X et B sont des matrices N par NRHS.
!>
!> La méthode de pivotage diagonal bornée de Bunch-Kaufman (rook) est
!> utilisée pour factoriser A comme suit :
!>    A = P*U*D*(U**T)*(P**T),  si UPLO = 'U', ou
!>    A = P*L*D*(L**T)*(P**T),  si UPLO = 'L',
!> où U (ou L) est une matrice triangulaire supérieure (ou inférieure)
!> unitaire, U**T (ou L**T) est la transposée de U (ou L), P est une
!> matrice de permutation, P**T est la transposée de P, et D est
!> symétrique et diagonale par blocs avec des blocs diagonaux 1 par 1
!> et 2 par 2.
!>
!> ZSYTRF_RK est appelée pour calculer la factorisation d'une matrice
!> symétrique complexe. La forme factorisée de A est ensuite utilisée
!> pour résoudre le système d'équations A * X = B en appelant la
!> routine BLAS3 ZSYTRS_3.
!
>
