HG(CAT) HG(CAT)

NOM

hg cat - afficher le contenu actuel ou celui d'une révision donnée de fichiers

SYNTAXE

hg cat [OPTION]... FICHIER...

DESCRIPTION

Affiche les fichiers spécifiés tels qu'ils étaient à la révision donnée. Si aucune révision n'est donnée, le parent du répertoire de travail est utilisé.

La sortie peut être redirigée vers un fichier, auquel cas le nom du fichier est donné en utilisant une chaîne de formatage. Voir hg help templates. En plus des mots-clés de modèle courants, les règles de formatage suivantes sont supportées :

%%

caractère "%" littéral

%s

nom de base du fichier en cours d'affichage

%d

nom du répertoire du fichier en cours d'affichage, ou '.' s'il est à la racine du dépôt

%p

nom du chemin relatif à la racine du fichier en cours d'affichage

%H

hash du changeset (40 chiffres hexadécimaux)

%R

numéro de révision du changeset

%h

hash du changeset en forme courte (12 chiffres hexadécimaux)

%r

numéro de révision du changeset complété par des zéros

%b

nom de base du dépôt exportateur

\

caractère "\" littéral

Modèle:

Les mots-clés suivants sont supportés en plus des mots-clés et fonctions de modèle courants. Voir aussi hg help templates.

data
Chaîne de caractères. Contenu du fichier.
path
Chaîne de caractères. Chemin absolu dans le dépôt du fichier.

Retourne 0 en cas de succès.

OPTIONS

-o,--output <FORMAT>
afficher la sortie dans un fichier avec un nom formaté
-r,--rev <REV>
afficher la révision donnée
--decode
appliquer le filtre de décodage correspondant
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-T,--template <MODÈLE>
afficher avec un modèle

[+] option marquée peut être spécifiée plusieurs fois
