DESC

De nombreux programmes lisent les entrées de l'utilisateur ligne par ligne. La bibliothèque d'historique GNU est capable de suivre ces lignes, d'associer des données arbitraires à chaque ligne et d'utiliser les informations des lignes précédentes lors de la composition

de nouvelles lignes.

La bibliothèque d'historique fournit des fonctions qui permettent aux applications de gérer

leur

historique, l'ensemble des lignes précédemment saisies, qu'elle conserve dans une liste. Les applications peuvent choisir quelles lignes enregistrer dans une liste d'historique, combien de commandes enregistrer, enregistrer une liste d'historique dans un fichier, lire une liste d'historique depuis un fichier et afficher des lignes de l'historique dans divers formats. La bibliothèque d'historique prend en charge une fonctionnalité d'expansion d'historique qui est identique à l'expansion d'historique

dans

bash. Cette section décrit quelles fonctionnalités syntaxiques sont disponibles. Les expansions d'historique introduisent des mots de la liste d'historique dans le flux d'entrée, ce qui facilite la répétition de commandes, l'insertion des arguments d'une commande précédente dans la ligne d'entrée courante ou la correction rapide d'erreurs dans les commandes

précédentes.

L'expansion d'historique est généralement effectuée immédiatement après qu'une ligne complète a été lue. Elle se déroule en deux parties. La première consiste à déterminer quelle entrée de la liste d'historique utiliser lors de la substitution. La seconde consiste à sélectionner des portions de cette entrée à inclure dans la

courante.

l'

événement, et les portions de cette entrée sur lesquelles on agit sont les mots. Divers modificateurs sont disponibles pour manipuler les mots sélectionnés. PROGRAMMATION AVEC LES FONCTIONS D'HISTORIQUE

Cette section décrit comment utiliser la bibliothèque d'historique dans d'autres programmes.

Introduction à l'historique

Un programmeur utilisant la bibliothèque d'historique dispose de fonctions pour mémoriser des lignes dans une liste d'historique, associer des données arbitraires à une ligne, supprimer des lignes de la liste, rechercher dans la liste une ligne contenant une chaîne de caractères arbitraire, et référencer directement n'importe quelle ligne de la liste. De plus, une fonction d'*expansion* d'historique est disponible, qui offre une interface utilisateur cohérente sur différents programmes.

L'utilisateur utilisant des programmes écrits avec la bibliothèque d'historique bénéficie d'une interface utilisateur cohérente avec un ensemble de commandes bien connues pour manipuler le texte des lignes précédentes et utiliser ce texte dans de nouvelles commandes. Les commandes de manipulation d'historique de base sont identiques à la substitution d'historique fournie par bash.

Le programmeur peut également utiliser la bibliothèque readline, qui inclut par défaut une certaine manipulation de l'historique, et présente l'avantage supplémentaire de l'édition de la ligne de commande.

Avant de déclarer des fonctions utilisant toute fonctionnalité que la bibliothèque d'historique fournit dans d'autres codes, un développeur d'application doit inclure le fichier <readline/history.h> dans tout fichier qui utilise les fonctionnalités de la bibliothèque d'historique. Il fournit des déclarations externes pour toutes les fonctions et variables publiques de la bibliothèque, et déclare toutes les structures de données publiques.

Stockage de l'historique

La liste d'historique est un tableau d'entrées d'historique. Une entrée d'historique est déclarée comme suit :

typedef void * histdata_t; 

typedef struct _hist_entry {
  char *line;
  char *timestamp;
  histdata_t data;
} HIST_ENTRY;

La liste d'historique elle-même pourrait donc être déclarée comme

HIST_ENTRY ** the_history_list;

L'état de la bibliothèque d'historique est encapsulé dans une seule structure :

/*
 * Une structure utilisée pour passer l'état actuel de l'historique.
 */
typedef struct _hist_state {
  HIST_ENTRY **entries; /* Pointeur vers les enregistrements d'entrée. */
  int offset;           /* L'enregistrement actuel. */
  int length;           /* Nombre d'enregistrements dans la liste. */
  int size;             /* Nombre d'enregistrements alloués. */
  int flags;
} HISTORY_STATE;

Si le membre flags inclut HS_STIFLED, l'historique a été étouffé.

Fonctions de l'historique

Cette section décrit la séquence d'appel des différentes fonctions exportées par la bibliothèque GNU History.

Initialisation de l'historique et gestion de l'état

Cette section décrit les fonctions utilisées pour initialiser et gérer l'état de la bibliothèque d'historique lorsque vous souhaitez utiliser les fonctions d'historique dans votre programme.

void using_history (void)
Démarre une session dans laquelle les fonctions d'historique peuvent être utilisées. Ceci initialise les variables interactives.

HISTORY_STATE * history_get_history_state (void)
Retourne une structure décrivant l'état actuel de l'historique d'entrée.

void history_set_history_state (HISTORY_STATE *state)
Définit l'état de la liste d'historique conformément à state.

Gestion de la liste d'historique

Ces fonctions gèrent les entrées individuelles de la liste d'historique, ou définissent les paramètres de gestion de la liste elle-même.

void add_history (const char *string)
Place string à la fin de la liste d'historique. Le champ de données associé (le cas échéant) est défini sur NULL. Si le nombre maximum d'entrées d'historique a été défini à l'aide de stifle_history(), et que le nouveau nombre d'entrées d'historique dépasserait ce maximum, la plus ancienne entrée d'historique est supprimée.

void add_history_time (const char *string)
Modifie l'horodatage associé à l'entrée d'historique la plus récente pour qu'il soit string.

HIST_ENTRY * remove_history (int which)
Supprime l'entrée d'historique à l'indice which de l'historique. L'élément supprimé est retourné afin que vous puissiez libérer la ligne, les données et la structure contenant.

histdata_t free_history_entry (HIST_ENTRY *histent)
Libère l'entrée d'historique histent et toutes les données privées de la bibliothèque d'historique qui y sont associées. Retourne les données spécifiques à l'application afin que l'appelant puisse s'en débarrasser.

HIST_ENTRY * replace_history_entry (int which, const char *line, histdata_t data)
Fait en sorte que l'entrée d'historique à l'indice which contienne line et data. Ceci retourne l'ancienne entrée afin que l'appelant puisse se débarrasser de toute donnée spécifique à l'application. Dans le cas d'un which invalide, un pointeur NULL est retourné.

void clear_history (void)
Vide la liste d'historique en supprimant toutes les entrées.

void stifle_history (int max)
Étouffe la liste d'historique, en ne conservant que les max dernières entrées. La liste d'historique ne contiendra que max entrées à la fois.

int unstifle_history (void)
Arrête l'étouffement de l'historique. Ceci retourne le nombre maximum d'entrées d'historique précédemment défini (tel que défini par stifle_history()). l'historique a été étouffé. La valeur est positive si l'historique a été étouffé, négative s'il ne l'a pas été.

int history_is_stifled (void)
Retourne une valeur non nulle si l'historique est étouffé, zéro s'il ne l'est pas.

Informations sur la liste d'historique

Ces fonctions retournent des informations sur la liste d'historique entière ou sur les entrées individuelles de la liste.

HIST_ENTRY ** history_list (void)
Retourne un tableau d'HIST_ENTRY * terminé par NULL qui est l'historique d'entrée actuel. L'élément 0 de cette liste est le début des temps. S'il n'y a pas d'historique, retourne NULL.

int where_history (void)
Retourne l'indice de l'élément d'historique actuel.

HIST_ENTRY * current_history (void)
Retourne l'entrée d'historique à la position actuelle, telle que déterminée par where_history(). S'il n'y a pas d'entrée à cet endroit, retourne un pointeur NULL.

HIST_ENTRY * history_get (int offset)
Retourne l'entrée d'historique à la position offset. La plage des valeurs valides de offset commence à history_base et se termine à history_length - 1. S'il n'y a pas d'entrée à cet endroit, ou si offset est en dehors de la plage valide, retourne un pointeur NULL.

time_t history_get_time (HIST_ENTRY *)
Retourne l'horodatage associé à l'entrée d'historique passée en argument.

int history_total_bytes (void)
Retourne le nombre d'octets utilisés par les entrées d'historique principales. Cette fonction retourne la somme des longueurs de toutes les lignes de l'historique.

Déplacement dans la liste d'historique

Ces fonctions permettent de définir ou de modifier l'index actuel dans la liste d'historique.

int history_set_pos (int pos)
Définit l'indice d'historique actuel à pos, un indice absolu dans la liste. Retourne 1 en cas de succès, 0 si pos est inférieur à zéro ou supérieur au nombre d'entrées d'historique.

HIST_ENTRY * previous_history (void)
Recule l'indice d'historique actuel à l'entrée d'historique précédente, et retourne un pointeur vers cette entrée. S'il n'y a pas d'entrée précédente, retourne un pointeur NULL.

HIST_ENTRY * next_history (void)
Si l'indice d'historique actuel fait référence à une entrée d'historique valide, incrémente l'indice d'historique actuel. Si l'indice d'historique potentiellement incrémenté fait référence à une entrée d'historique valide, retourne un pointeur vers cette entrée ; sinon, retourne un pointeur NULL.

Recherche dans la liste d'historique

Ces fonctions permettent de rechercher dans la liste d'historique des entrées contenant une chaîne spécifique. La recherche peut être effectuée à la fois en avant et en arrière depuis la position actuelle de l'historique. La recherche peut être ancrée, ce qui signifie que la chaîne doit correspondre au début de l'entrée d'historique.

int history_search (const char *string, int direction)
Recherche dans l'historique la chaîne string, en commençant à l'indice d'historique actuel. Si direction est inférieur à 0, la recherche s'effectue dans les entrées précédentes, sinon dans les entrées suivantes. Si string est trouvé, l'indice d'historique actuel est défini sur cette entrée d'historique, et la valeur retournée est l'indice dans la ligne de l'entrée où string a été trouvé. Sinon, rien n'est modifié et la fonction retourne -1.

int history_search_prefix (const char *string, int direction)
