Initialement, il y a un cadre. Chaque cadre a l'un des deux types suivants possibles

:
1.Il sert de conteneur pour les fenêtres, c'est-à-dire qu'il peut contenir de zéro à un nombre arbitraire de fenêtres. Lancez plusieurs terminaux supplémentaires pour voir ce qui se passe : S'il y a plusieurs fenêtres dans un cadre, elles sont alignées les unes sous les autres. Pour changer cet algorithme de disposition, appuyez sur Mod-space pour parcourir tous les algorithmes de disposition disponibles pour le cadre
focalisé.
2.Un cadre peut également être divisé en deux sous-cadres, qui peuvent être alignés côte à côte ou l'un sous l'autre. Appuyez sur Mod-o pour diviser horizontalement. Pour naviguer vers le nouveau cadre à droite de l'ancien, appuyez sur Mod-l. Appuyez sur Mod-u pour diviser verticalement. La navigation intuitive est :

 La notion de moniteur dans herbstluftwm est traitée de manière beaucoup plus abstraite et générale que dans d'autres gestionnaires de fenêtres : un moniteur est simplement une partie rectangulaire de votre écran qui affiche exactement une étiquette. Initialement, il n'y a qu'un seul grand moniteur couvrant l'intégralité de votre écran : $ herbstclient list_monitors
0: 1440x900+0+0 with tag "1" 
[FOCUS]

 La sortie montre qu'il n'y a qu'un seul moniteur avec l'index 0 à la position +0+0 de taille 1440x900 affichant l'étiquette 1. Dans la plupart des cas, les moniteurs de herbstluftwm correspondront à la liste des moniteurs physiques. Ainsi, pour ajouter un autre moniteur physique, vous devez effectuer plusieurs étapes :
