Description

détaillée

La manière habituelle d'ajouter des distances est

: 
hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}


Si err vaut 0 à la fin,

l'ajout a
réussi.

HWLOC_DISTANCES_ADD_FLAG_GROUP
Essayer de regrouper les objets en fonction des nouvelles informations de distance fournies. Le regroupement n'est effectué que lorsque la structure de distances contient des latences et lorsque tous les objets sont du même

int hwloc_distances_add_commit (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned long

flags)

Valider une nouvelle structure de distances. Cette fonction finalise la structure de distances et l'insère dans la

topologie.

Paramètre handle a été précédemment retourné par hwloc_distances_add_create(). Ensuite, les objets et les valeurs ont été spécifiés avec hwloc_distances_add_values()

.

flags configure le comportement de la fonction à l'aide d'un ensemble optionnel de drapeaux combinés par OR hwloc_distances_add_flag_e. Il peut être utilisé pour demander le regroupement des objets existants en fonction des

distances.

En cas d'erreur, la structure de distances temporaire et son contenu sont

détruits.

hwloc_distances_add_handle_t hwloc_distances_add_create (hwloc_topology_t topology, const char * name, unsigned long kind, unsigned long

flags)

Créer une nouvelle structure de distances vide. Créer une structure de distances vide à remplir avec hwloc_distances_add_values() puis à valider avec hwloc_distances_add

_commit().

Paramètre name est facultatif, il peut être NULL. Sinon, il sera copié en interne et pourra ensuite être libéré par

l'appelant.

kind spécifie le type de distance sous la forme d'un ensemble de drapeaux combinés par OR de hwloc_distances_kind_e. Un seul type de signification et un seul type de provenance peuvent être donnés si approprié (par ex. HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH et HWLOC_DISTANCES_KIND_FROM_USER). Le type HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES sera automatiquement défini en fonction des objets ayant des types différents dans hwloc_distances_add_values()

Spécifier les objets et les valeurs dans une nouvelle structure de distances vide. Spécifier les objets et les valeurs pour une nouvelle structure de distances qui a été retournée comme descripteur par hwloc_distances_add_create(). La structure doit ensuite être validée avec hwloc_distances_add

_commit().

Le nombre d'objets est nbobjs et le tableau d'objets est objs. Les valeurs de distance sont stockées sous la forme d'un tableau unidimensionnel dans values. La distance de l'objet i à l'objet j est à l'emplacement
