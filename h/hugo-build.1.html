NOM

hugo-build - Construire votre site

SYNTAXE

hugo build [indicateurs]

DESCRIPTION

build est la commande principale, utilisée pour construire votre site Hugo.

Hugo est un générateur de sites statiques rapide et flexible construit avec amour par spf13 et ses amis en Go.

La documentation complète est disponible sur https://gohugo.io/.

OPTIONS

-b, --baseURL="" nom d'hôte (et chemin) vers la racine, par exemple https://spf13.com/

-D, --buildDrafts[=false] inclure le contenu marqué comme brouillon

-E, --buildExpired[=false] inclure le contenu expiré

-F, --buildFuture[=false] inclure le contenu avec une date de publication dans le futur

--cacheDir="" chemin du système de fichiers vers le répertoire de cache

--cleanDestinationDir[=false] supprimer les fichiers du répertoire de destination qui ne se trouvent pas dans les répertoires statiques

--clock="" définir l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-c, --contentDir="" chemin du système de fichiers vers le répertoire de contenu

-d, --destination="" chemin du système de fichiers où écrire les fichiers

--disableKinds=[] désactiver différents types de pages (accueil, RSS, etc.)

--enableGitInfo[=false] ajouter des informations sur la révision Git, la date, l'auteur et CODEOWNERS aux pages

-e, --environment="" environnement de construction

--forceSyncStatic[=false] copier tous les fichiers lorsque le répertoire statique est modifié.

--gc[=false] activer pour exécuter des tâches de nettoyage (supprimer les fichiers de cache inutilisés) après la construction

-h, --help[=false] aide pour build

--ignoreCache[=false] ignore le répertoire de cache

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de modules correspondant au modèle Glob donné

-l, --layoutDir="" chemin du système de fichiers vers le répertoire de mise en page

--logLevel="" niveau de journalisation (debug|info|warn|error)

--minify[=false] minimiser tout format de sortie pris en charge (HTML, XML, etc.)

--noBuildLock[=false] ne pas créer le fichier .hugo_build.lock

--noChmod[=false] ne pas synchroniser le mode de permission des fichiers

--noTimes[=false] ne pas synchroniser l'heure de modification des fichiers

--panicOnWarning[=false] paniquer au premier avertissement enregistré

--poll="" définir ceci sur un intervalle de sondeo, par exemple --poll 700ms, pour utiliser une approche basée sur le sondeo afin de surveiller les changements du système de fichiers

--printI18nWarnings[=false] afficher les traductions manquantes

--printMemoryUsage[=false] afficher l'utilisation de la mémoire à l'écran à intervalles réguliers

--printPathWarnings[=false] afficher les avertissements sur les chemins de destination dupliqués, etc.

--printUnusedTemplates[=false] afficher les avertissements sur les modèles inutilisés.

--quiet[=false] construire en mode silencieux

--renderSegments=[] segments nommés à rendre (configurés dans la configuration des segments)

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers pour lire les fichiers relativement à

--templateMetrics[=false] afficher les métriques sur l'exécution des modèles

--templateMetricsHints[=false] calculer des indices d'amélioration lorsqu'ils sont combinés avec --templateMetrics

-t, --theme=[] thèmes à utiliser (situés dans /themes/NOM_DU_THEME/)

--themesDir="" chemin du système de fichiers vers le répertoire des thèmes

--trace="" écrire la trace dans fichier (pas utile en général)

-w, --watch[=false] surveiller le système de fichiers pour les changements et recréer si nécessaire
