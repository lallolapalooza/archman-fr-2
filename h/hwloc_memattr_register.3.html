Description

détaillée

Les attributs de mémoire sont identifiés par un ID (hwloc_memattr_id_t) et un nom. hwloc_memattr_get_name() et hwloc_memattr_get_by_name() convertissent entre les deux (ou retournent une erreur si l'attribut n'existe pas)

.

L'ensemble des hwloc_memattr_id_t valides est un ensemble contigu commençant à 0. Il contient d'abord les attributs prédéfinis, comme listés dans hwloc_memattr_id_e (de 0 à HWLOC_MEMATTR_ID_MAX-1). Ensuite, des attributs personnalisés peuvent être dynamiquement enregistrés avec hwloc_memattr_register(). Ils recevront les IDs suivants (HWLOC_MEMATTR_ID_MAX pour le premier, etc.)

.

Pour parcourir tous les attributs valides (qu'ils soient prédéfinis ou des attributs personnalisés enregistrés dynamiquement), on peut parcourir les IDs à partir de 0 jusqu'à ce que hwloc_memattr_get_name() ou hwloc_memattr_get_flags() retourne une

erreur.

Les valeurs d'un attribut existant ou d'attributs personnalisés enregistrés dynamiquement peuvent être définies ou modifiées avec hwloc_memattr

_set_va
lue().
