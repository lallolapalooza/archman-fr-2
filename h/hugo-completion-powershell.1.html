NOM

hugo-completion-powershell - Générer le script d'autocomplétion pour powershell

SYNTAXE

hugo completion powershell [options]

DESCRIPTION

Génère le script d'autocomplétion pour powershell.

Pour charger les complétions dans votre session shell actuelle:

hugo completion powershell | Out-String | Invoke-Expression

Pour charger les complétions pour chaque nouvelle session, ajoutez la sortie de la commande ci-dessus à votre profil powershell.

OPTIONS

-h, --help[=false] aide pour powershell

--no-descriptions[=false] désactive les descriptions de complétion

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--clock="" définit l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout chemin de module _vendor correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne crée pas le fichier .hugo_build.lock

--quiet[=false] construit en mode silencieux

-M, --renderToMemory[=false] rend en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers à partir duquel lire les fichiers en relatif

--themesDir="" chemin du système de fichiers pour le répertoire des thèmes
