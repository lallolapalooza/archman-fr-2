htsserver(1) Manuel des commandes générales htsserver(1)

NOM

htsserver - serveur de navigateur hors ligne : copie les sites web dans un répertoire local

SYNTAXE

htsserver [ chemin/ ] [ mot-clé valeur [ mot-clé valeur .. ] ]

DESCRIPTION

htsserver ce programme est un serveur frontal web pour httrack(1), un copieur de sites web, utilisé par webhttrack(1).

EXEMPLES

htsserver /usr/share/httrack/ chemin $HOME/websites langue 1

puis, naviguez sur http://localhost:8080/

FICHIERS

/etc/httrack.conf

Le fichier de configuration global du système.

ENVIRONNEMENT

HOME
Est utilisé si vous avez défini dans /etc/httrack.conf la ligne chemin ~/websites/#

DIAGNOSTICS

Les erreurs/avertissements sont signalés dans hts-log.txt situé dans le répertoire de destination.

BOGUES

Veuillez signaler les bogues à <bugs@httrack.com>. Incluez un exemple complet et autonome qui permettra de reproduire le bogue, et indiquez la version de (web)httrack que vous utilisez. N'oubliez pas de détailler les options utilisées, la version de l'OS et toute autre information que vous jugerez nécessaire.
