NOM

hivexml - Convertir une "ruche" binaire du registre Windows en XML

SYNTAXE

hivexml [-dk] fichier_ruche > sortie.xml

DESCRIPTION

Ce programme convertit un seul fichier de "ruche" binaire du registre Windows dans un format XML auto-descriptif.

OPTIONS

-d
Active de nombreux messages de débogage. Si vous trouvez un fichier de registre que ce programme ne peut pas analyser, veuillez activer cette option et publier la sortie complète *et* le fichier de registre dans votre rapport de bug.
-k
Continue même si des erreurs sont trouvées dans le fichier de registre. Ceci ignore toutes les parties du registre que nous ne pouvons pas lire.
-u
Utilise des heuristiques pour tolérer certains niveaux de corruption dans les ruches.

Ceci est non sécurisé mais peut permettre d'exporter/fusionner des clés/valeurs valides dans une ruche autrement corrompue.
