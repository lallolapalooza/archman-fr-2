NOM

hg addremove - ajouter tous les nouveaux fichiers, supprimer tous les fichiers manquants

SYNTAXE

hg addremove [OPTION]... [FICHIER]...

DESCRIPTION

Ajoute tous les nouveaux fichiers et supprime tous les fichiers manquants du dépôt.

Sauf si des noms sont spécifiés, les nouveaux fichiers seront ignorés s'ils correspondent à l'un des motifs dans .hgignore. Comme avec add, ces changements prendront effet lors du prochain commit.

Utilisez l'option -s/--similarity pour détecter les fichiers renommés. Cette option prend un pourcentage entre 0 (désactivé) et 100 (les fichiers doivent être identiques) comme paramètre. Avec un paramètre supérieur à 0, cela compare chaque fichier supprimé avec chaque fichier ajouté et enregistre ceux qui sont suffisamment similaires comme des renommages. La détection de fichiers renommés de cette manière peut être coûteuse. Après avoir utilisé cette option, hg status -C peut être utilisé pour vérifier quels fichiers ont été identifiés comme déplacés ou renommés. S'il n'est pas spécifié, -s/--similarity est par défaut à 100 et seuls les renommages de fichiers identiques sont détectés.

Exemples :

  • Un certain nombre de fichiers (bar.c et foo.c) sont nouveaux, tandis que foobar.c a été supprimé (sans utiliser hg remove) du dépôt : 
    $ ls
bar.c foo.c
$ hg status
! foobar.c
? bar.c
? foo.c
$ hg addremove
adding bar.c
adding foo.c
removing foobar.c
$ hg status
A bar.c
A foo.c
R foobar.c
  • Un fichier foobar.c a été déplacé vers foo.c sans utiliser hg rename. Ensuite, il a été légèrement modifié : 
    $ ls
foo.c
$ hg status
! foobar.c
? foo.c
$ hg addremove --similarity 90
removing foobar.c
adding foo.c
recording removal of foobar.c as rename to foo.c (94% similar)
$ hg status -C
A foo.c
  foobar.c
R foobar.c

    Retourne 0 si tous les fichiers sont ajoutés avec succès.

OPTIONS

-s,--similarity <SIMILARITÉ>
devine les fichiers renommés par similarité (0<=s<=100)
-S, --subrepos
récursion dans les sous-dépôts
-I,--include <MOTIF[+]>
inclut les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclut les noms correspondant aux motifs donnés
-n, --dry-run
ne pas effectuer d'actions, juste afficher la sortie

[+] option marquée peut être spécifiée plusieurs fois
