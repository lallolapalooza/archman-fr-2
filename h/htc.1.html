HTC(1) Manuel des commandes générales HTC(1)

NOM

htc - client httptunnel

SYNTAXE

htc [options] hôte[:port]

DESCRIPTION

Cette page de manuel documente brièvement la commande htc.

htc établit une connexion httptunnel vers le PORT sur l'HÔTE (port par défaut 8888). Lorsqu'une connexion est établie, les E/S sont redirigées depuis la source spécifiée par le commutateur --device ou --forward-port vers le tunnel.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-h, --help
Affiche un résumé des options.
-c, --content-length OCTETS
utilise des requêtes HTTP PUT de taille OCTETS (postfixes k, M et G reconnus)
-d, --device PÉRIPHÉRIQUE
utilise PÉRIPHÉRIQUE pour l'entrée et la sortie
-F, --forward-port PORT
utilise le port TCP PORT pour l'entrée et la sortie
-k, --keep-alive SECONDES
envoie des octets de maintien toutes les SECONDES secondes (par défaut 5)
-M, --max-connection-age SEC
la durée maximale d'une connexion ouverte est de SEC secondes (par défaut 300)
-S, --strict-content-length
écrit toujours OCTETS de longueur de contenu dans les requêtes
-A, --proxy-authorization UTILISATEUR:MOTDEPASSE
autorisation de proxy
--proxy-authorization-file FICHIER
fichier d'autorisation de proxy
-B, --proxy-buffer-size OCTETS
suppose une taille de tampon de proxy de OCTETS octets (postfixes k, M et G reconnus)
-P, --proxy HÔTE[:PORT]
utilise un proxy HTTP (port par défaut 8080)
-T, --timeout TEMPS
délai d'attente, en millisecondes, avant d'envoyer du remplissage à un proxy de mise en mémoire tampon
-U, --user-agent CHAÎNE
spécifie la valeur de l'agent utilisateur dans les requêtes HTTP
-V, --version
affiche les informations de version et quitte
