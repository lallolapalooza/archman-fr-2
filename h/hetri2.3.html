sous-routine chetri2 (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CHETRI2

But :

!>
!> CHETRI2 calcule l'inverse d'une matrice hermitienne indéfinie COMPLEXE
!> A en utilisant la factorisation A = U*D*U**T ou A = L*D*L**T calculée par
!> CHETRF. CHETRI2 définit la DIMENSION PRINCIPALE de l'espace de travail
!> avant d'appeler CHETRI2X qui calcule réellement l'inverse.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : triangulaire supérieur, la forme est A = U*D*U**T ;
!>          = 'L' : triangulaire inférieur, la forme est A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice diagonale par blocs D et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L tels que calculés par CHETRF.
!>
!>          À la sortie, si INFO = 0, l'inverse (symétrique) de la matrice
!>          originale.  Si UPLO = 'U', la partie triangulaire supérieure de
!>          l'inverse est formée et la partie de A sous la diagonale n'est pas
!>          référencée ; si UPLO = 'L', la partie triangulaire inférieure de
!>          l'inverse est formée et la partie de A au-dessus de la diagonale
!>          n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par CHETRF.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon LWORK >= (N+NB+1)*(NB+3).
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule :
!>              - la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK,
!>              - et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
