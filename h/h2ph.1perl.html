H2PH(1perl) Guide de référence pour programmeurs Perl H2PH(1perl)

NOM

h2ph - Convertit les fichiers d'en-tête C .h en fichiers d'en-tête Perl .ph

SYNTAXE

h2ph [-d répertoire de destination] [-r | -a] [-l] [-h] [-e] [-D] [-Q] [fichiers d'en-tête]

DESCRIPTION

h2ph convertit les fichiers d'en-tête C spécifiés au format de fichier d'en-tête Perl correspondant. Il est plus facile de l'exécuter dans /usr/include :

cd /usr/include; h2ph * sys/*

ou

cd /usr/include; h2ph * sys/* arpa/* netinet/*

ou

cd /usr/include; h2ph -r -l .

Les fichiers de sortie sont placés dans la hiérarchie dont la racine est le répertoire de bibliothèque dépendant de l'architecture de Perl. Vous pouvez spécifier une hiérarchie différente avec l'option -d.

S'il est exécuté sans arguments, filtre l'entrée standard vers la sortie standard.

OPTIONS

-d répertoire_destination
Place les fichiers .ph résultants sous répertoire_destination, au lieu de sous l'emplacement par défaut de la bibliothèque Perl ($Config{'installsitearch'}).
-r
Exécute récursivement ; si l'un des fichiers d'en-tête sont des répertoires, alors exécute h2ph sur tous les fichiers de ces répertoires (et leurs sous-répertoires, etc.). -r et -a sont mutuellement exclusifs.
-a
Exécute automatiquement ; convertit les fichiers d'en-tête, ainsi que tous les fichiers .h qu'ils incluent. Cette option recherche les fichiers .h dans tous les répertoires que votre compilateur C utilise habituellement. -a et -r sont mutuellement exclusifs.
-l
Les liens symboliques seront répliqués dans le répertoire de destination. Si -l n'est pas spécifié, les liens sont ignorés.
-h
Place des 'indices' dans les fichiers .ph qui aideront à localiser les problèmes avec h2ph. Dans les cas où vous requérez un fichier .ph contenant des erreurs de syntaxe, au lieu du cryptique 
[ une condition d'erreur ] à (eval mmm) ligne nnn

vous verrez le plus utilement

[ une condition d'erreur ] à filename.ph ligne nnn

Cependant, les fichiers .ph doublent presque de taille lorsqu'ils sont construits en utilisant -h.

-e
Si une erreur est rencontrée pendant la conversion, le fichier de sortie sera supprimé et un avertissement sera émis au lieu de terminer la conversion immédiatement.
-D
Inclut le code du fichier .h sous forme de commentaire dans le fichier .ph. Ceci est principalement utilisé pour le débogage de h2ph.
-Q
Mode 'silencieux' ; n'imprime pas les noms des fichiers en cours de conversion.

ENVIRONNEMENT

Aucune variable d'environnement n'est utilisée.

FICHIERS

/usr/include/*.h
/usr/include/sys/*.h

etc.

DIAGNOSTICS

Les avertissements habituels s'il ne peut pas lire ou écrire les fichiers concernés.

BOGUES

Ne construit pas le tableau %sizeof pour vous.

Il ne gère pas tous les construits C, mais il tente d'isoler les définitions à l'intérieur d'evals afin que vous puissiez accéder aux définitions qu'il peut traduire.

Ce n'est qu'un outil approximatif. Vous pourriez avoir besoin de modifier les fichiers produits.

Vous devez exécuter ce programme manuellement ; il n'est pas exécuté dans le cadre de l'installation de Perl.

Ne gère pas les expressions compliquées construites morceau par morceau, du type :

enum {
    FIRST_VALUE,
    SECOND_VALUE,
#ifdef ABC
    THIRD_VALUE
#endif
};

Ne localise pas nécessairement tous les symboles définis en interne par votre compilateur C.
