int hwloc_bitmap_singlify_per_core (hwloc_topology_t topology, hwloc_bitmap_t cpuset, unsigned which)

Supprime les PU de multithreading simultané d'un ensemble de CPU. Pour chaque cœur dans la topologie, si cpuset contient certaines PU de ce cœur, modifie cpuset pour ne conserver qu'une seule PU pour ce cœur.

which spécifie quelle PU sera conservée. Les PU sont considérées dans l'ordre des indices physiques. Si 0, pour chaque cœur, la fonction conserve la première PU qui était initialement définie dans cpuset.

Si which est supérieur au nombre de PU dans un cœur qui étaient initialement définies dans cpuset, aucune PU n'est conservée pour ce cœur.

Retourne

0.

Note

Les PU qui ne sont pas sous un objet Cœur sont ignorées (par exemple si la topologie ne contient aucun objet Cœur). Aucune d'entre elles n'est retirée de cpuset.

unsigned hwloc_get_closest_objs (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_t *restrict objs, unsigned max)

Effectue un parcours en profondeur de la topologie pour trouver et trier tous les objets qui sont à la même profondeur que src. Rapporte dans objs jusqu'à max objets physiquement les plus proches de src.

Retourne

le nombre d'objets retournés dans objs.

0 si src est un objet d'E/S.

Note

Cette fonction nécessite que l'objet src ait un ensemble de CPU.

hwloc_obj_t hwloc_get_numanode_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Retourne l'objet de type HWLOC_OBJ_NUMANODE avec os_index. Cette fonction est utile pour convertir un ensemble de nœuds en objets de nœuds NUMA qu'il contient. Lors de la récupération du binding actuel (par exemple avec hwloc_get_membind() avec HWLOC_MEMBIND_BYNODESET), on peut itérer sur les bits de l'ensemble de nœuds résultant avec hwloc_bitmap_foreach_begin(), et trouver les nœuds NUMA correspondants avec cette fonction.

Retourne

l'objet du nœud NUMA, ou NULL si aucun ne correspond.

hwloc_obj_t hwloc_get_obj_below_array_by_type (hwloc_topology_t topology, int nr, hwloc_obj_type_t * typev, unsigned * idxv) [inline]

Trouve un objet sous une chaîne d'objets spécifiés par des types et des indices. C'est une version généralisée de hwloc_get_obj_below_by_type().

Les tableaux typev et idxv doivent contenir nr types et indices.

Commence à l'objet système racine et parcourt les tableaux typev et idxv. Pour chaque couple type et indice logique dans les tableaux, recherche sous l'objet trouvé précédemment pour trouver le nième objet du type donné. Les indices sont spécifiés à l'intérieur du parent, pas dans l'ensemble du système.

Par exemple, si nr est 3, typev contient NODE, PACKAGE et CORE, et idxv contient 0, 1 et 2, renvoie le troisième objet de cœur sous le deuxième package sous le premier nœud NUMA.

Retourne

un objet correspondant s'il y en a un, NULL sinon.

Note

Cette fonction nécessite que tous ces objets et l'objet racine aient un ensemble de CPU.

hwloc_obj_t hwloc_get_obj_below_by_type (hwloc_topology_t topology, hwloc_obj_type_t type1, unsigned idx1, hwloc_obj_type_t type2, unsigned idx2) [inline]

Trouve un objet sous un autre objet, les deux spécifiés par des types et des indices. Commence à l'objet système racine et trouve l'objet de type type1 et d'indice logique idx1. Ensuite, recherche sous cet objet et trouve un autre objet de type type2 et d'indice logique idx2. Les indices sont spécifiés à l'intérieur du parent, pas dans l'ensemble du système.

Par exemple, si type1 est PACKAGE, idx1 est 2, type2 est CORE et idx2 est 3, renvoie le quatrième objet de cœur sous le troisième package.

Retourne

un objet correspondant s'il y en a un, NULL sinon.

Note

Cette fonction nécessite que ces objets aient un ensemble de CPU.

hwloc_obj_t hwloc_get_obj_with_same_locality (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_type_t type, const char * subtype, const char * nameprefix, unsigned long flags)

Retourne un objet d'un type différent avec la même localité. Si l'objet source src est d'un type normal ou mémoire, cette fonction retourne un objet de type type avec les mêmes ensembles de CPU et de nœuds, soit en dessous, soit au-dessus dans la hiérarchie.

Si l'objet source src est un périphérique PCI ou un périphérique du système d'exploitation au sein d'un périphérique PCI, la fonction peut retourner soit ce périphérique PCI, soit un autre périphérique du système d'exploitation dans le même parent PCI. Cela peut par exemple être utile pour convertir entre les périphériques du système d'exploitation tels que 'nvml0' ou 'rsmi1' utilisés dans les structures de distance en périphérique PCI, ou le périphérique du système d'exploitation CUDA ou OpenCL qui correspond à la même carte physique.

Si NULL n'est pas, le paramètre subtype ne sélectionne que les objets dont l'attribut subtype existe et est subtype (insensible à la casse), par exemple 'OpenCL' ou 'CUDA'.

Si NULL n'est pas, le paramètre nameprefix ne sélectionne que les objets dont l'attribut name existe et commence par nameprefix (insensible à la casse), par exemple 'rsmi' pour faire correspondre 'rsmi0'.

Si plusieurs objets correspondent, le premier est retourné.

Cette fonction ne parcourra pas la hiérarchie à travers les ponts car la localité PCI peut être différente. Cette fonction ne peut pas non plus convertir entre des objets normaux/mémoire et des objets d'E/S ou Divers.

flags doit être 0 pour l'instant.

Retourne

Un objet avec une localité identique, correspondant à subtype et nameprefix s'il y en a.

NULL si aucun objet correspondant n'a pu être trouvé, ou si l'objet source et le type cible sont incompatibles, par exemple lors de la conversion entre des objets CPU et d'E/S.

hwloc_obj_t hwloc_get_pu_obj_by_os_index (hwloc_topology_t topology, unsigned os_index) [inline]

Retourne l'objet de type HWLOC_OBJ_PU avec l'index du système d'exploitation os_index. Ceci est principalement utile pour convertir l'index d'une unité de traitement (PU) du système d'exploitation en un objet hwloc.

Retourne

l'objet PU, ou NULL si aucun ne correspond.
