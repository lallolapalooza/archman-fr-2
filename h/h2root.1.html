NOM

h2root - convertir des fichiers HBOOK de PAW en fichiers ROOT

SYNTAXE

h2root fichier.hbook fichier.root [compress] [tolower] [lrecl]

DESCRIPTION

h2root vous permet de convertir vos histogrammes ou fichiers ntuples HBOOK/PAW en fichiers ROOT. Pour utiliser ce programme, tapez la commande du script shell :

h2root fichier.hbook fichier.root

Si vous ne spécifiez pas le deuxième paramètre, un nom de fichier est automatiquement généré pour vous. Si fichier.hbook est de la forme fichier.hbook, alors le fichier ROOT sera nommé fichier.root.

Ce programme convertit les histogrammes HBOOK en objets ROOT de la classe TH1F. Les histogrammes de profil HBOOK sont convertis en histogrammes de profil ROOT (voir la classe TProfile). Les ntuples HBOOK ligne par ligne et colonne par colonne sont automatiquement convertis en arbres ROOT (voir TTree). Certains ntuples colonne par colonne de HBOOK peuvent ne pas être entièrement convertis si l'une des colonnes est un tableau avec des dimensions fixes (par exemple, `var[6]') ou un tableau multidimensionnel.

Les identifiants entiers HBOOK sont convertis en objets nommés ROOT en préfixant l'identifiant entier par la lettre `h' si l'identifiant est un entier positif, et par `h_' s'il s'agit d'un identifiant entier négatif.

Dans le cas des ntuples ligne par ligne ou colonne par colonne, chaque colonne est convertie en une branche d'un arbre. Notez que h2root est capable de convertir des fichiers HBOOK contenant plusieurs niveaux de sous-répertoires. Une fois que vous avez converti votre fichier, vous pouvez l'examiner et dessiner des histogrammes ou traiter des ntuples à l'aide du module interactif ROOT. Vous pouvez également utiliser le navigateur ROOT (voir TBrowser) pour inspecter ce fichier.

Le chapitre Comment lire un arbre explique deux méthodes pour lire un arbre. ROOT inclut la fonction TTree::MakeCode pour générer automatiquement le code d'une fonction d'analyse squelettique. Avec

OPTIONS

compress
= 1 par défaut (utiliser 0 pour aucune compression)
tolower
= 1 par défaut (utiliser 0 pour conserver la casse des noms de colonnes)
lrecl
= 0 par défaut (doit être spécifié si >8092)
