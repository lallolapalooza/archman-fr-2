HASH-EFI-SIG-LIST(1) Commandes utilisateur HASH-EFI-SIG-LIST(1)

NOM

hash-to-efi-sig-list - crée une entrée de liste de signatures EFI à partir d'un binaire

SYNTAXE

hash-to-efi-sig-list efi-binaire [efi-binaire ...] efi-signature-list

DESCRIPTION

Produit un fichier EFI Signature List contenant le hachage sha256 du binaire EFI fourni.

OPTIONS

aucune

EXEMPLES

Pour créer une liste de signatures EFI hachées dans le fichier hash.esl à partir du binaire HelloWorld.efi, exécutez :

hash-efi-sig-list HelloWorld.efi hash.esl

Ce fichier de hachage peut maintenant être placé directement (ou en mise à jour) dans les variables db avec UpdateVar.

VOIR AUSSI

sign-efi-sig-list(1) pour les détails sur la manière de produire des fichiers de mise à jour authentifiés pour la variable db.
