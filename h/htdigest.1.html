NOM

htdigest — gère les fichiers utilisateurs pour l'authentification digest

SYNTAXE

htdigest [ -c ] fichier_passwd domaine nom_utilisateur

RÉSUMÉ

htdigest est utilisé pour créer et mettre à jour les fichiers plats contenant les noms d'utilisateur, le domaine et le mot de passe pour l'authentification digest des utilisateurs HTTP. Les ressources accessibles depuis le serveur HTTP Apache peuvent être restreintes aux utilisateurs listés dans les fichiers créés par htdigest.

Cette page de manuel ne liste que les arguments de la ligne de commande. Pour les détails des directives nécessaires à la configuration de l'authentification digest dans httpd, consultez le manuel Apache, qui fait partie de la distribution Apache ou peut être trouvé à l'adresse http://httpd.apache.org/.

OPTIONS

-c
Crée le fichier_passwd. Si fichier_passwd existe déjà, il est d'abord supprimé.
fichier_passwd
Nom du fichier contenant le nom d'utilisateur, le domaine et le mot de passe. Si -c est donné, ce fichier est créé s'il n'existe pas, ou supprimé et recréé s'il existe.
domaine
Le nom du domaine auquel appartient le nom d'utilisateur. Voir http://tools.ietf.org/html/rfc2617#section-3.2.1 pour plus de détails.
nom_utilisateur
Le nom d'utilisateur à créer ou mettre à jour dans fichier_passwd. Si nom_utilisateur n'existe pas dans ce fichier, une entrée est ajoutée. S'il existe, le mot de passe est modifié.

CONSIDÉRATIONS DE SÉCURITÉ

Ce programme n'est pas sûr en tant qu'exécutable setuid. Ne le rendez *pas* setuid.
