hci(7) Administration système Linux hci(7)

Nom

hci - Protocole HCI Bluetooth

Syntaxe

#include <sys/socket.h>
#include <bluetooth/bluetooth.h>
#include <bluetooth/hci.h>
hci_socket = socket(PF_BLUETOOTH, SOCK_RAW, BTPROTO_HCI);

Description

L'interface de contrôle hôte (HCI) de Bluetooth est le protocole standard pour communiquer avec les adaptateurs Bluetooth. Le protocole HCI fournit une méthode de commande uniforme pour que l'Hôte accède aux capacités du Contrôleur et contrôle les connexions avec d'autres Contrôleurs.

Adresse Socket

struct sockaddr_hci {
    sa_family_t    hci_family;
    unsigned short hci_dev;
    unsigned short hci_channel;
};

Valeurs possibles pour hci_channel :

Définition Valeur Description
HCI_CHANNEL_RAW 0x00 Canal brut - Utilisé pour la communication HCI brute
HCI_CHANNEL_USER 0x01 Canal utilisateur - Utilisé pour la communication HCI en espace utilisateur (désactive le traitement du noyau)
HCI_CHANNEL_MONITOR 0x02 Canal de surveillance - Utilisé pour surveiller le trafic HCI (btmon(1))
HCI_CHANNEL_CONTROL 0x03 Canal de contrôle - Utilisé pour gérer les adaptateurs locaux (bluetoothd(7))
HCI_CHANNEL_LOGGING 0x04 Canal de journalisation - Utilisé pour injecter des messages de journalisation (bluetoothd(7))

Exemple :

struct sockaddr_hci addr;
memset(&addr, 0, sizeof(addr));
addr.hci_family = AF_BLUETOOTH;
addr.hci_dev = HCI_DEV_NONE;
addr.hci_channel = HCI_CHANNEL_CONTROL;

Options Socket

Les options de socket listées ci-dessous peuvent être définies en utilisant setsockopt(2) et lues avec getsockopt(2) avec le niveau de socket défini à SOL_BLUETOOTH ou SOL_HCI (HCI_FILTER).

HCI_FILTER (depuis Linux 2.6)

Filtrer par événements HCI, nécessite que hci_channel soit défini à HCI_CHANNEL_RAW, valeurs possibles :

struct hci_filter {
    uint32_t type_mask;
    uint32_t event_mask[2];
    uint16_t opcode;
};

Exemple :

struct hci_filter flt;
memset(&flt, 0, sizeof(flt));
flt.type_mask = 1 << BT_H4_EVT_PKT;
flt.event_mask[0] = 0xffffffff;
flt.event_mask[1] = 0xffffffff;
setsockopt(fd, SOL_HCI, HCI_FILTER, &flt, sizeof(flt));

BT_SNDBUF (depuis Linux 5.16)

Définir la taille du tampon d'envoi, nécessite que hci_channel soit défini à HCI_CHANNEL_MONITOR, HCI_CHANNEL_CONTROL ou HCI_CHANNEL_LOGGING.

La valeur par défaut est 1028.

Exemple :

uint16_t mtu = UINT16_MAX;
int err;
err = setsockopt(fd, SOL_BLUETOOTH, BT_SNDMTU, &mtu, sizeof(mtu));

BT_RCVBUF (depuis Linux 5.16)

Définir la taille du tampon de réception, nécessite que hci_channel soit défini à HCI_CHANNEL_MONITOR, HCI_CHANNEL_CONTROL ou HCI_CHANNEL_LOGGING.

La valeur par défaut est 1028.

Exemple :

uint16_t mtu;
socklen_t len;
int err;
len = sizeof(mtu);
err = getsockopt(sock, SOL_BLUETOOTH, BT_RCVMTU, mtu, &len);
