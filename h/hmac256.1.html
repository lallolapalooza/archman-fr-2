NOM

hmac256 - Calculer un MAC HMAC-SHA-256

SYNTAXE

hmac256 [--binary] clé [FICHIER]

DESCRIPTION

Ceci est une implémentation autonome de HMAC-SHA-256 utilisée pour calculer un code d'authentification de message HMAC-SHA-256. L'outil a été initialement développé comme une deuxième implémentation pour Libgcrypt afin de permettre la comparaison avec l'implémentation principale et d'être utilisé pour des vérifications de cohérence internes. Il ne doit pas être utilisé pour des données sensibles car aucun mécanisme pour effacer la pile, etc., n'est utilisé.

Le code a été écrit de manière très portable et ne nécessite que quelques définitions standard à fournir dans un fichier config.h.

hmac256 est généralement invoqué comme suit :

hmac256 "Ceci est ma clé" foo.txt

Ceci calcule le MAC sur le fichier ‘foo.txt’ en utilisant la clé donnée sur la ligne de commande.

OPTIONS

hmac256 comprend les options suivantes :

--binary
Imprimer le MAC sous forme de chaîne binaire. Par défaut, le MAC est imprimé codé en chiffres hexadécimaux minuscules.
--version
Afficher la version du programme et quitter.
