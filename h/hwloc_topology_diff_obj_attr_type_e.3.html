Description détaillée

Les applications qui manipulent de nombreuses topologies similaires, par exemple une pour chaque nœud d'un cluster homogène, peuvent vouloir compresser les topologies pour réduire l'empreinte mémoire.

Ce fichier offre un moyen de manipuler la différence entre topologies et de l'exporter/importer depuis/vers XML. La compression peut donc être réalisée en stockant une topologie entièrement tandis que les autres ne sont décrites que par leurs différences avec la première. La topologie réelle peut être reconstruite lorsqu'elle est réellement nécessaire en appliquant la différence précalculée à la topologie de référence.

Cette interface cible des nœuds très similaires. Seules des différences très simples entre topologies sont réellement supportées, par exemple un changement dans la taille de la mémoire, le nom de l'objet, ou un attribut d'information. Des différences plus complexes telles que l'ajout ou la suppression d'objets ne peuvent pas être représentées dans les structures de différence et retournent donc des erreurs. Les différences entre ensembles d'objets ou ensembles autorisés à l'échelle de la topologie ne peuvent pas non plus être représentées.

Cela signifie qu'il n'est pas nécessaire d'appliquer la différence lors de l'examen de l'organisation de l'arbre (nombre de niveaux, nombre d'objets par niveau, types d'objets, ensembles CPU et nœuds, etc.) et lors de la liaison aux objets. Cependant, la différence doit être appliquée lors de l'examen des attributs d'objet tels que le nom, la taille de la mémoire ou les attributs d'information.

int hwloc_topology_diff_apply (hwloc_topology_t topology, hwloc_topology_diff_t diff, unsigned long flags)

Applique une différence de topologie à une topologie existante. flags est un ensemble OR'é de hwloc_topology_diff_apply_flags_e.

La nouvelle topologie est modifiée en place. hwloc_topology_dup() peut être utilisée pour la dupliquer avant de la patcher.

Si la différence ne peut pas être entièrement appliquée, tous les éléments précédemment appliqués sont désappliqués avant de retourner.

Retourne

0 en cas de succès.

-N si l'application de la différence a échoué lors de la tentative d'application de la N-ième partie de la différence. Par exemple, -1 est retourné si le tout premier élément de différence n'a pas pu être appliqué.

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t *diff)

Construit une différence entre deux topologies. flags est un ensemble OR'é de hwloc_topology_diff_build_flags_e.

La différence est retournée dans *diff et peut être utilisée plus tard par hwloc_topology_diff_apply(). Elle doit être libérée par hwloc_topology_diff_destroy().

Si la différence est trop complexe pour être représentée, la fonction retourne 1 et *diff peut contenir une différence incomplète. Les différences entre ensembles CPU, ensembles de nœuds, ou les différences où des objets sont ajoutés ou supprimés ne sont pas supportées.

Retourne

0 sur succès, 1 si la différence est trop complexe pour être représentée.

-1 en cas d'erreur interne.

int hwloc_topology_diff_destroy (hwloc_topology_diff_t diff)

Libère une différence précédemment allouée par hwloc_topology_diff_build(), hwloc_topology_diff_load_xml(), ou hwloc_topology_diff_load_xmlbuffer().

Retourne

0 sur succès, -1 en cas d'erreur.

Calcule la différence entre 2 topologies. La différence est stockée sous forme d'une liste d'entrées hwloc_topology_diff_t commençant à diff. Elle est calculée en effectuant un parcours en profondeur des deux arbres de topologie simultanément.

Si la différence entre 2 objets est trop complexe pour être représentée (par exemple, si certains objets ont des types différents, ou un nombre différent d'enfants), une entrée de différence spéciale de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX est mise en file d'attente. Le calcul de la différence ne continue pas sous ces objets. Ainsi, chaque entrée de différence de ce type signifie que la différence entre deux sous-arbres n'a pas pu être calculée.

Retourne

0 si la différence peut être représentée correctement.

0 avec diff pointant vers NULL s'il n'y a pas de différence entre les topologies.

1 si la différence est trop complexe (voir ci-dessus). Certaines entrées de la liste seront de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 en cas d'autre erreur.

Note

flags n'est actuellement pas utilisé. Il doit être 0.

Le diff de sortie doit être libéré avec hwloc_topology_diff_destroy().

Le diff de sortie ne peut être exporté en XML ou passé à hwloc_topology_diff_apply() que si 0 a été retourné, c'est-à-dire si aucune entrée de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX n'est listée.

Le diff de sortie peut être modifié en retirant certaines entrées de la liste. Les entrées retirées doivent être libérées en les passant à hwloc_topology_diff_destroy() (possiblement sous forme d'une autre liste).
