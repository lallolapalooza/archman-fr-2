Description détaillée

Cette interface propose des moyens de récupérer des informations de topologie sur les périphériques OpenCL.

Seules les implémentations OpenCL d'AMD et de NVIDIA proposent actuellement des informations de localité utiles sur leurs périphériques.

Documentation des fonctions

int hwloc_opencl_get_device_cpuset (hwloc_topology_t topology, cl_device_id device, hwloc_cpuset_t set) [en_ligne]

Obtenir l'ensemble des processeurs CPU physiquement proches du périphérique OpenCL device. Stocker dans set l'ensemble CPU décrivant la localité du périphérique OpenCL device.

La topologie topology et le périphérique device doivent correspondre à la machine locale. La détection des périphériques d'E/S et le composant OpenCL ne sont pas nécessaires dans la topologie.

La fonction retourne uniquement la localité du périphérique. Si plus d'informations sur le périphérique sont nécessaires, les objets du système d'exploitation doivent être utilisés à la place, voir hwloc_opencl_get_device_osdev() et hwloc_opencl_get_device_osdev_by_index().

Cette fonction n'est actuellement implémentée de manière significative que pour Linux avec l'implémentation OpenCL d'AMD ou de NVIDIA ; les autres systèmes obtiendront simplement un cpuset complet.

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si le périphérique n'a pas pu être trouvé.

hwloc_obj_t hwloc_opencl_get_device_osdev (hwloc_topology_t topology, cl_device_id device) [en_ligne]

Obtenir l'objet périphérique OS de hwloc correspondant au périphérique OpenCL deviceX.

Retourne

L'objet périphérique OS de hwloc correspondant au périphérique OpenCL donné device.

NULL si aucun n'a pu être trouvé, par exemple si les attributs OpenCL requis ne sont pas disponibles.

Cette fonction ne fonctionne actuellement qu'avec les périphériques OpenCL d'AMD et de NVIDIA qui prennent en charge les extensions OpenCL pertinentes. hwloc_opencl_get_device_osdev_by_index() devrait être préférée dans la mesure du possible, c'est-à-dire lorsque l'index de plateforme et de périphérique sont connus.

La topologie topology et le périphérique device doivent correspondre à la machine locale. La détection des périphériques d'E/S et le composant OpenCL doivent être activés dans la topologie. Sinon, la localité de l'objet peut toujours être trouvée en utilisant hwloc_opencl_get_device_cpuset().

Note

Cette fonction ne peut pas fonctionner si les périphériques PCI sont filtrés.

Le périphérique PCI hwloc correspondant peut être trouvé en examinant le pointeur parent du résultat (sauf si les périphériques PCI sont filtrés).

hwloc_obj_t hwloc_opencl_get_device_osdev_by_index (hwloc_topology_t topology, unsigned platform_index, unsigned device_index) [en_ligne]

Obtenir l'objet périphérique OS de hwloc correspondant au périphérique OpenCL pour les index donnés.

Retourne

L'objet périphérique OS de hwloc décrivant le périphérique OpenCL dont l'index de plateforme est platform_index, et dont l'index de périphérique au sein de cette plateforme est device_index.

NULL s'il n'y en a pas.

La topologie topology ne doit pas nécessairement correspondre à la machine actuelle. Par exemple, la topologie peut être une importation XML d'un hôte distant. La détection des périphériques d'E/S et le composant OpenCL doivent être activés dans la topologie.

Note

L'objet périphérique PCI correspondant peut être obtenu en examinant l'objet parent du périphérique OS (sauf si les périphériques PCI sont filtrés).

int hwloc_opencl_get_device_pci_busid (cl_device_id device, unsigned * domain, unsigned * bus, unsigned * dev, unsigned * func) [en_ligne]

Retourner les ID de domaine, bus et périphérique du périphérique OpenCL device. Le périphérique device doit correspondre à la machine locale.

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si les informations du périphérique n'ont pas pu être trouvées.
