void hwloc_topology_set_userdata_export_callback (hwloc_topology_t topology, void(*)(void *reserved, hwloc_topology_t topology, hwloc_obj_t obj) export_cb)

Définit le rappel spécifique à l'application pour l'exportation des données utilisateur d'objet. Le pointeur des données utilisateur d'objet n'est pas exporté en XML par défaut car hwloc ne sait pas ce qu'il contient.

Cette fonction permet aux applications de définir export_cb comme une fonction de rappel qui convertit ces données utilisateur opaques en une chaîne exportable.

export_cb est appelée lors de l'exportation XML pour chaque objet dont le pointeur de données utilisateur n'est pas NULL. Le rappel doit utiliser hwloc_export_obj_userdata() ou hwloc_export_obj_userdata_base64() pour réellement exporter quelque chose vers XML (éventuellement plusieurs fois par objet).

export_cb peut être défini sur NULL si les données utilisateur ne doivent pas être exportées vers XML.

Note

Le pointeur de données utilisateur spécifique à la topologie est ignoré lors de l'exportation vers XML.

void hwloc_topology_set_userdata_import_callback (hwloc_topology_t topology, void(*)(hwloc_topology_t topology, hwloc_obj_t obj, const char *name, const void *buffer, size_t length) import_cb)

Définit le rappel spécifique à l'application pour l'importation des données utilisateur. Lors de l'importation XML, les données utilisateur sont ignorées par défaut car hwloc ne sait pas comment les stocker en mémoire.

Cette fonction permet aux applications de définir import_cb comme une fonction de rappel qui recevra les données utilisateur stockées en XML et les stockera dans l'objet comme prévu par l'application.

import_cb est appelée lors de hwloc_topology_load() autant de fois que hwloc_export_obj_userdata() a été appelée lors de l'exportation. La topologie n'est pas encore entièrement configurée. Les attributs des objets sont prêts à être consultés, mais les liens entre les objets ne le sont pas.

import_cb peut être NULL si les données utilisateur doivent être ignorées lors de l'importation.

Note

buffer contient length caractères suivis d'un byte nul ('\0').

Cette fonction doit être appelée avant hwloc_topology_load().

Le pointeur de données utilisateur spécifique à la topologie est ignoré lors de l'importation depuis XML.
