message(1) Manuel des commandes générales message(1)

NOM

message - Lire, écrire, envoyer, copier, déplacer et supprimer vos messages

SYNTAXE

message [-h|--help] <sous-commandes>

DESCRIPTION

Lire, écrire, envoyer, copier, déplacer et supprimer vos messages.

Un message est le contenu d'un e-mail. Il est composé d'en-têtes (situés en haut du message) et d'un corps (situé en bas du message). Les deux sont séparés par deux sauts de ligne. Cette sous-commande vous permet de les gérer.

OPTIONS

-h, --help
Afficher l'aide (voir un résumé avec '-h')

SOUS-COMMANDES

message-read(1)
Lire une version lisible par l'homme du message associé aux identifiants d'enveloppe donnés
message-export(1)
Exporter le message associé à l'identifiant d'enveloppe donné
message-thread(1)
Lire la version lisible par l'homme des messages associés au fil d'enveloppe donné
message-write(1)
Composer un nouveau message, à partir de zéro
message-reply(1)
Répondre au message associé à l'identifiant d'enveloppe donné
message-forward(1)
Faire suivre le message associé à l'identifiant d'enveloppe donné
message-edit(1)
Modifier le message associé à l'identifiant d'enveloppe donné
message-mailto(1)
Analyser et modifier un message à partir de la chaîne d'URL mailto donnée
message-save(1)
Enregistrer le message brut donné dans le dossier spécifié
message-send(1)
Envoyer le message brut donné
message-copy(1)
Copier le message associé aux identifiants d'enveloppe donnés dans le dossier de destination spécifié
message-move(1)
Déplacer le message associé aux identifiants d'enveloppe donnés dans le dossier de destination spécifié
message-delete(1)
Marquer comme supprimé le message associé aux identifiants d'enveloppe donnés
message-help(1)
Afficher ce message ou l'aide des sous-commandes spécifiées
message
