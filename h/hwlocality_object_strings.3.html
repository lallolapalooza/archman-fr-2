int hwloc_obj_attr_snprintf (char *restrict string, size_t size, hwloc_obj_t obj, const char *restrict separator, int verbose)

Convertit les attributs d'un objet topologique donné en une forme lisible par l'humain. Les valeurs des attributs sont séparées par separator.

Seuls les attributs principaux sont affichés en mode non verbeux.

Si size vaut 0, string peut être NULLsans danger.

Renvoie

le nombre de caractères réellement écrits si aucune troncature n'a eu lieu, ou le nombre qui aurait été écrit (sans inclure le \0final).

int hwloc_obj_type_snprintf (char *restrict string, size_t size, hwloc_obj_t obj, int verbose)

Convertit le type d'un objet topologique donné en une forme lisible par l'humain. Contrairement à hwloc_obj_type_string(), cette fonction inclut dans la sortie les attributs spécifiques à l'objet (comme la profondeur d'un groupe, le type de pont, ou le type de périphérique système), et elle nécessite que l'appelant fournisse le tampon de sortie.

La sortie est garantie identique pour tous les objets d'un même niveau topologique.

Si verbose vaut 1, des noms de types plus longs sont utilisés, par exemple L1Cache au lieu de L1.

La chaîne de sortie peut être analysée à nouveau par hwloc_type_sscanf().

Si size vaut 0, string peut être NULLsans danger.

Renvoie

le nombre de caractères réellement écrits si aucune troncature n'a eu lieu, ou le nombre qui aurait été écrit (sans inclure le \0final).

const char * hwloc_obj_type_string (hwloc_obj_type_t type)

Renvoie une chaîne constante représentant le type d'objet. Cette fonction est la manière de base de convertir un type générique en une chaîne. La chaîne de sortie peut être analysée à nouveau par hwloc_type_sscanf().

hwloc_obj_type_snprintf() peut renvoyer une sortie plus précise pour un objet spécifique, mais elle nécessite que l'appelant fournisse le tampon de sortie.

Renvoie

une chaîne constante contenant le nom du type d'objet ou 'Unknown'.

int hwloc_type_sscanf (const char * string, hwloc_obj_type_t * typep, union hwloc_obj_attr_u * attrp, size_t attrsize)

Renvoie un type d'objet et ses attributs à partir d'une chaîne de type. Convertit des chaînes comme 'Package' ou 'L1iCache' en les types correspondants. La correspondance ne tient pas compte de la casse, et seules les premières lettres doivent réellement correspondre.

Le type d'objet correspondant est défini dans typep (qui ne peut pas être NULL).

Les attributs spécifiques au type, par exemple le type de cache, la profondeur du cache, la profondeur d'un groupe, le type de pont ou le type de périphérique système peuvent être renvoyés dans attrp. Les attributs non spécifiés dans la chaîne (par exemple 'Group' sans profondeur, ou 'L2Cache' sans type de cache) sont définis à -1.

attrp n'est rempli que s'il n'est pas NULL et si sa taille spécifiée dans attrsize est suffisante. Elle doit être au moins aussi grande que l'union hwloc_obj_attr_u.

Renvoie

0 si un type a été correctement identifié, sinon -1.

Note

Cette fonction est garantie de correspondre à toute chaîne renvoyée par hwloc_obj_type_string() ou hwloc_obj_type_snprintf().

Ceci est une version étendue de la fonction désormais obsolète hwloc_obj_type_sscanf().

int hwloc_type_sscanf_as_depth (const char * string, hwloc_obj_type_t * typep, hwloc_topology_t topology, int * depthp)

Renvoie un type d'objet et la profondeur de son niveau à partir d'une chaîne de type. Convertit des chaînes comme 'Package' ou 'L1iCache' en les types correspondants et renvoie dans depthp la profondeur du niveau correspondant dans la topologie topology.

Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, HWLOC_TYPE_DEPTH_UNKNOWN est renvoyé.

Si plusieurs tels niveaux existent (par exemple si l'on donne Group sans aucune profondeur), la fonction peut renvoyer HWLOC_TYPE_DEPTH_MULTIPLE à la place.

Le type d'objet correspondant est défini dans typep si typep n'est pas NULL.

Note

Cette fonction est similaire à hwloc_type_sscanf() suivi de hwloc_get_type_depth() mais elle désambiguïse également automatiquement les multiples niveaux de groupes, etc.

Cette fonction est garantie de correspondre à toute chaîne renvoyée par hwloc_obj_type_string() ou hwloc_obj_type_snprintf().
