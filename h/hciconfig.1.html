Nom

hciconfig - Configurer les périphériques Bluetooth

SYNTAXE

hciconfig -h

hciconfig [-a]

hciconfig [-a] hciX [COMMANDE [PARAMÈTRES]]

DESCRIPTION

hciconfig(1) est utilisé pour configurer les périphériques Bluetooth. hciX est le nom d'un périphérique Bluetooth installé sur le système. Si hciX n'est pas donné, hciconfig affiche le nom et les informations de base de tous les périphériques Bluetooth installés sur le système.

Si hciX est donné mais qu'aucune commande n'est spécifiée, il affiche les informations de base sur le périphérique hciX uniquement. Les informations de base sont le type d'interface, l'adresse BD, le MTU ACL, le MTU SCO, les drapeaux (up, init, running, raw, page scan activé, inquiry scan activé, inquiry, authentification activée, chiffrement activé).

OPTIONS

-a, --all
Affiche les fonctionnalités, le type de paquet, la politique de liaison, le mode de liaison, la classe, la version en plus des informations de base.
-h, --help
Affiche les options d'aide.

COMMANDES

up
Ouvre et initialise le périphérique HCI.
down
Ferme le périphérique HCI.
reset
Réinitialise le périphérique HCI.
rstat
Réinitialise les compteurs statistiques.
auth
Active l'authentification (met le périphérique en mode sécurité 3).
noauth
Désactive l'authentification.
encrypt
Active le chiffrement (met le périphérique en mode sécurité 3).
noencrypt
Désactive le chiffrement.
secmgr
Active le gestionnaire de sécurité (le support actuel du noyau est limité).
nosecmgr
Désactive le gestionnaire de sécurité.
piscan
Active la recherche de page et d'interrogation.
noscan
Désactive la recherche de page et d'interrogation.
iscan
Active la recherche d'interrogation, désactive la recherche de page.
pscan
Active la recherche de page, désactive la recherche d'interrogation.
ptype [type]
Sans type, affiche les types de paquets actuels. Sinon, tous les types de paquets spécifiés par type sont définis. type est une liste séparée par des virgules de types de paquets, où les types de paquets possibles sont DM1, DM3, DM5, DH1, DH3, DH5, HV1, HV2, HV3.
name [nom]
Sans nom, affiche le nom local. Sinon, définit le nom local à nom.
class [classe]
Sans classe, affiche la classe du périphérique. Sinon, définit la classe du périphérique à classe. classe est un nombre hexadécimal de 24 bits décrivant la classe du périphérique, tel que spécifié dans la section 1.2 du document Bluetooth Assigned Numbers.
voice [voix]
Sans voix, affiche le paramètre vocal. Sinon, définit le paramètre vocal à voix. voix est un nombre hexadécimal de 16 bits décrivant le paramètre vocal.
iac [iac]
Sans iac, affiche le paramètre IAC actuel. Sinon, définit l'IAC à iac.
inqtpl [niveau]
Sans niveau, affiche le niveau de puissance de transmission actuel pour l'interrogation. Sinon, définit le niveau de puissance de transmission pour l'interrogation à niveau.
inqmode [mode]
Sans mode, affiche le mode d'interrogation actuel. Sinon, définit le mode d'interrogation à mode.
mode Description
0 Interrogation standard
1 Interrogation avec RSSI
2 Interrogation avec RSSI ou Interrogation étendue
inqdata [données]
Sans données, affiche les données d'interrogation actuelles. Sinon, définit les données d'interrogation à données.
inqtype [type]
Sans type, affiche le type de scan d'interrogation actuel. Sinon, définit le type de scan d'interrogation à type.
inqparams [fenêtre:intervalle]
Sans fenêtre:intervalle, affiche la fenêtre et l'intervalle de scan d'interrogation. Sinon, définit la fenêtre de scan d'interrogation à fenêtre slots et l'intervalle de scan d'interrogation à intervalle slots.
pageparms [fenêtre:intervalle]
Sans fenêtre:intervalle, affiche la fenêtre et l'intervalle de scan de page. Sinon, définit la fenêtre de scan de page à fenêtre slots et l'intervalle de scan de page à intervalle slots.
pageto [délai]
Sans délai, affiche le délai de mise en page. Sinon, définit le délai de mise en page délai en slots.
afhmode [mode]
Sans mode, affiche le mode AFH actuel. Sinon, définit le mode AFH à mode.
mode Description
0 Activer
1 Désactiver
sspmode [mode]
Sans mode, affiche le mode d'appairage simplifié actuel. Sinon, définit le mode d'appairage simplifié à mode.
mode Description
0 Activer
1 Désactiver
aclmtu mtu:paquets
Définit le MTU ACL à mtu octets et la taille du tampon ACL à paquets paquets.
scomtu mtu:paquets
Définit le MTU SCO à mtu octets et la taille du tampon SCO à paquets paquets.
delkey <adresse_bd>
Cette commande supprime la clé de liaison stockée pour adresse_bd du périphérique.
oobdata
Obtenir les données OOB locales (invalide les données lues précédemment).
commands
Affiche les commandes prises en charge.
features
Affiche les fonctionnalités du périphérique.
version
Affiche les informations de version.
evision">révision
Affiche les informations de
révision.

e]
Sans mode, affiche le mode de lien. CENTRAL ou PERIPHERAL signifient respectivement de demander à devenir central ou à rester périphérique lorsqu'une demande de connexion arrive. Le mot-clé supplémentaire ACCEPT signifie que les connexions de bande de base seront acceptées même s'il n'y a pas de AF_BLUETOOTH d'écoute. mode est NONE ou une liste de mots-clés séparés par des virgules, où les mots-clés possibles sont CENTRAL et ACCEPT. NONE définit la politique de lien sur le comportement par défaut de rester périphérique et de ne pas accepter les connexions de bande de base lorsqu'il n'y a pas de AF_BLUETOOTH d'écoute. Si CENTRAL est présent, le périphérique demandera à devenir central si une demande de connexion arrive. Si ACCEPT est présent, le périphérique acceptera les connexions de bande de base même lorsqu'il n'y a pas de AF_BLUETOOTH d'
écoute.
