int hwloc_bitmap_singlify_per_core (hwloc_topology_t topology, hwloc_bitmap_t cpuset, unsigned

which)

Supprime les PU de multithreading simultané d'un ensemble de CPU. Pour chaque cœur dans la topologie, si cpuset contient certains PU de ce cœur, modifier cpuset pour ne conserver qu'un seul PU pour ce

cœur.

which spécifie quel PU sera conservé. Les PU sont considérés dans l'ordre de leur index physique. Si 0, pour chaque cœur, la fonction co

nserve le premier PU qui était initialement défini dans cpuset.

Si which est supérieur au nombre de PU dans un cœur qui étaient initialement définis dans cpuset, aucun PU n'est conservé pour ce

cœur.

0
.

.

hwloc_obj_t hwloc_get_obj_below_array_by_type (hwloc_topology_t topology, int nr, hwloc_obj_type_t * typev, unsigned * idxv) [inline]

Trouve un objet sous une chaîne d'objets spécifiée par des types et des index. C'est une version généralisée de hwloc_get_obj_below_

by_type().

Les tableaux typev et idxv doivent contenir nr types et

index.

Commence à partir de l'objet système supérieur et parcourt les tableaux typev et idxv. Pour chaque couple type et index logique dans les tableaux, cherche sous l'objet précédemment trouvé l'objet de rang index du type donné. Les index sont spécifiés au sein du parent, et non au sein de tout le

système.

Par exemple, si nr vaut 3, typev contient NODE, PACKAGE et CORE, et idxv contient 0, 1 et 2, renvoie le troisième objet cœur sous le deuxième package sous le premier nœud

NUMA.

hwloc_obj_t hwloc_get_obj_with_same_locality (hwloc_topology_t topology, hwloc_obj_t src, hwloc_obj_type_t type, const char * subtype, const char * nameprefix, unsigned long

flags)

Renvoie un objet d'un type différent avec la même localité. Si l'objet source src est un type normal ou mémoire, cette fonction renvoie un objet de type type avec les mêmes ensembles de CPU et de nœuds, soit sous, soit au-dessus dans la

hiérarchie.

Si l'objet source src est un périphérique PCI ou un périphérique OS au sein d'un périphérique PCI, la fonction peut soit renvoyer ce périphérique PCI, soit un autre périphérique OS dans le même parent PCI. Cela peut par exemple être utile pour convertir entre des périphériques OS tels que 'nvml0' ou 'rsmi1' utilisés dans les structures de distance vers le périphérique PCI, ou le périphérique OS CUDA ou OpenCL qui correspond à la même carte

physique.

Si ce n'est pas NULL, le paramètre subtype ne sélectionne que les objets dont l'attribut subtype existe et vaut subtype (insensible à la casse), par exemple 'OpenCL' ou

'CUDA'.

Si ce n'est pas NULL, le paramètre nameprefix ne sélectionne que les objets dont l'attribut name existe et commence par nameprefix (insensible à la casse), par exemple 'rsmi' pour correspondre à

'rsmi0'.

Si plusieurs objets correspondent, le premier est

renvoyé.

Cette fonction ne parcourra pas la hiérarchie à travers les ponts car la localité PCI peut devenir différente. Cette fonction ne peut pas non plus convertir entre des objets normaux/mémoire et des objets d'E/S ou

Misc.

flags doit valoir 0 pour

l'instant.

Renvoi

e
Un objet avec une localité identique, correspondant à subtype et nameprefix le cas échéant.

NULL si aucun objet correspondant n'a pu être trouv

é, ou si l'objet source et le type cible
sont incompatibles, par exemple lors d'une co
nversion entre objets CPU et objets d'E/S.
