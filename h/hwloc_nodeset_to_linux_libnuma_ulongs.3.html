Description

détaillée

Cette interface aide à la conversion entre les masques unsigned long de libnuma sur Linux et les ensembles de processeurs (cpusets) et ensembles de nœuds (nodesets)

hwloc.

Remarq

ue
La topologie topology doit correspondre à la machine actuelle.

Le comportement de libnuma est indéfini si le noyau n'est pas NUMA-aware. (

lorsque CONFIG_NUMA n'est pas défini dans la configuration du noyau). Cet a
ssistant et libnuma peuvent donc ne pas être strictement compatibles dans ce
cas, ce qui peut être détecté en vérifiant si numa_available() renvoie -1.
