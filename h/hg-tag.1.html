Paquet: mercurial

HG(TAG) HG(TAG)

NOM

hg tag - ajouter une ou plusieurs étiquettes pour la révision actuelle ou spécifiée

SYNTAXE

hg tag [-f] [-l] [-m TEXT] [-d DATE] [-u USER] [-rREV] NOM...

DESCRIPTION

Nommer une révision particulière à l'aide de <nom>.

Les étiquettes sont utilisées pour nommer des révisions particulières du dépôt et sont très utiles pour comparer différentes révisions, revenir à des versions antérieures significatives ou marquer des points de branche comme des versions, etc. Modifier une étiquette existante est normalement interdit ; utilisez -f/--force pour outrepasser.

Si aucune révision n'est donnée, le parent du répertoire de travail est utilisé.

Pour faciliter le contrôle de version, la distribution et la fusion des étiquettes, elles sont stockées dans un fichier nommé ".hgtags" qui est géré de manière similaire aux autres fichiers du projet et peut être modifié manuellement si nécessaire. Cela signifie également que l'étiquetage crée un nouveau commit. Le fichier ".hg/localtags" est utilisé pour les étiquettes locales (non partagées entre les dépôts).

Les commits d'étiquettes sont généralement effectués à la tête d'une branche. Si le parent du répertoire de travail n'est pas une tête de branche, hg tag s'interrompt ; utilisez -f/--force pour forcer le commit d'étiquette à être basé sur un changeset non-tête.

Voir hg help dates pour une liste des formats valides pour -d/--date.

Étant donné que les noms d'étiquettes ont la priorité sur les noms de branches lors de la recherche de révision, l'utilisation d'un nom de branche existant comme nom d'étiquette est déconseillée.

Retourne 0 en cas de succès.

OPTIONS

-f, --force
forcer l'étiquette
-l, --local
rendre l'étiquette locale
-r,--rev <REV>
révision à étiqueter
--remove
supprimer une étiquette
-e, --edit
appeler l'éditeur sur les messages de commit
-m,--message <TEXTE>
utiliser le texte comme message de commit
-d,--date <DATE>
enregistrer la date spécifiée comme date de commit
-u,--user <UTILISATEUR>
enregistrer l'utilisateur spécifié comme committer
