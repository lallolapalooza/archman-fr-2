Description détaillée

Cette interface aide à la conversion entre les masques unsigned long de libnuma sous Linux et les ensembles de processeurs (cpusets) et ensembles de nœuds (nodesets) hwloc.

Note

Le topology doit correspondre à la machine actuelle.

Le comportement de libnuma est indéfini si le noyau n'est pas conscient de NUMA. (lorsque CONFIG_NUMA n'est pas défini dans la configuration du noyau). Cette aide et libnuma peuvent donc ne pas être strictement compatibles dans ce cas, ce qui peut être détecté en vérifiant si numa_available() retourne -1.

Documentation des fonctions

int hwloc_cpuset_from_linux_libnuma_ulongs (hwloc_topology_t topology, hwloc_cpuset_t cpuset, const unsigned long * mask, unsigned long maxnode) [inline]

Convertit le tableau de masques unsigned long mask en ensemble de processeurs hwloc. mask est un tableau d'unsigned long qui sera lu. maxnode contient le numéro de nœud maximal qui peut être lu dans mask.

Cette fonction peut être utilisée après avoir appelé get_mempolicy ou toute autre fonction qui prend un tableau d'unsigned long comme paramètre de sortie (et éventuellement un numéro de nœud maximal comme paramètre d'entrée).

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si une réallocation interne échoue.

int hwloc_cpuset_to_linux_libnuma_ulongs (hwloc_topology_t topology, hwloc_const_cpuset_t cpuset, unsigned long * mask, unsigned long * maxnode) [inline]

Convertit l'ensemble de processeurs hwloc cpuset en tableau de masques unsigned long mask. mask est le tableau d'unsigned long qui sera rempli. maxnode contient le numéro de nœud maximal qui peut être stocké dans mask. maxnode sera défini au numéro de nœud maximal trouvé, plus un.

Cette fonction peut être utilisée avant d'appeler set_mempolicy, mbind, migrate_pages ou toute autre fonction qui prend un tableau d'unsigned long et un numéro de nœud maximal comme paramètre d'entrée.

Retourne

0.

int hwloc_nodeset_from_linux_libnuma_ulongs (hwloc_topology_t topology, hwloc_nodeset_t nodeset, const unsigned long * mask, unsigned long maxnode) [inline]

Convertit le tableau de masques unsigned long mask en ensemble de nœuds NUMA hwloc. mask est un tableau d'unsigned long qui sera lu. maxnode contient le numéro de nœud maximal qui peut être lu dans mask.

Cette fonction peut être utilisée après avoir appelé get_mempolicy ou toute autre fonction qui prend un tableau d'unsigned long comme paramètre de sortie (et éventuellement un numéro de nœud maximal comme paramètre d'entrée).

Retourne

0 en cas de succès.

-1 avec errno défini à ENOMEM si une réallocation interne a échoué.

int hwloc_nodeset_to_linux_libnuma_ulongs (hwloc_topology_t topology, hwloc_const_nodeset_t nodeset, unsigned long * mask, unsigned long * maxnode) [inline]

Convertit l'ensemble de nœuds NUMA hwloc nodeset en tableau de masques unsigned long mask. mask est le tableau d'unsigned long qui sera rempli. maxnode contient le numéro de nœud maximal qui peut être stocké dans mask. maxnode sera défini au numéro de nœud maximal trouvé, plus un.

Cette fonction peut être utilisée avant d'appeler set_mempolicy, mbind, migrate_pages ou toute autre fonction qui prend un tableau d'unsigned long et un numéro de nœud maximal comme paramètre d'entrée.

Retourne

0.
