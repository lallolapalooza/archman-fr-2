NOM

hugin_hdrmerge - Fusionner des images superposées

SYNTAXE

hugin_hdrmerge [options] -o sortie.exr fichiers-entree

DESCRIPTION

À faire.

OPTIONS

-o préfixe
Fichier de sortie
-m mode
Mode de fusion, peut être l'un des suivants : avg, avg_slow, khan (par défaut), si avg, les options -i, -s ou -d ne s'appliquent pas
-i itérations
Nombre d'itérations à exécuter (par défaut 1)
-c
Ne considérer que les pixels définis dans toutes les images (mode avg uniquement)
-s fichier
Fichiers de débogage à enregistrer à chaque itération, peut être l'un des suivants :
a - tous les fichiers de débogage (ne peut être utilisé seul)
w - poids calculés à partir de chaque itération
r - image résultante de chaque itération
s - images sources avant traitement

Si verbose >= 3, tous les fichiers de débogage sont générés sauf indication contraire

-a calculs
Appliquer un ou plusieurs calculs avancés, peut être un ou plusieurs des suivants :
b - biais des poids logarithmiquement
c - choisir les pixels avec le poids le plus élevé au lieu de faire la moyenne (remplace les options -a b et -a d)
d - choisir un pixel avec le poids le plus élevé au lieu de faire la moyenne lorsque tous les poids de pixels sont à moins de 10 % les uns des autres
h - favoriser un rapport signal/bruit élevé
i - ignorer le canal alpha
-e
Exporter chaque poids initial vers <chemins_fichier_entree>_iw.<ext>
-l
Charger un poids initial précédemment exporté par rapport aux noms de fichiers d'entrée

NOTE : si les options -e et -l sont activées, le programme calculera et enregistrera les poids initiaux, puis attendra que l'utilisateur indique qu'il peut continuer en chargeant les poids précédemment enregistrés

-v
Verbeux, afficher les messages de progression, répéter pour une sortie encore plus verbeuse
-h
Afficher un résumé de l'aide.
