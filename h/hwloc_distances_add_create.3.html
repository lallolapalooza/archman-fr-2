Description détaillée

La manière habituelle d'ajouter des distances est la suivante :

hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}


Si err est 0 à la fin, alors l'ajout a réussi.

Documentation des définitions de types

typedef void* hwloc_distances_add_handle_t

Handle vers une nouvelle structure de distances lors de son ajout à la topologie.

Documentation du type énuméré

enum hwloc_distances_add_flag_e

Flags pour l'ajout de nouvelles distances à une topologie.

Énumérateur

HWLOC_DISTANCES_ADD_FLAG_GROUP
Essayer de grouper les objets en fonction des nouvelles informations de distance fournies. Le groupement n'est effectué que lorsque la structure des distances contient des latences, et lorsque tous les objets sont du même type.
HWLOC_DISTANCES_ADD_FLAG_GROUP_INACCURATE
Si groupement, considérer les valeurs de distance comme inexactes et assouplir les comparaisons lors des algorithmes de groupement. La précision réelle peut être modifiée via la variable d'environnement HWLOC_GROUPING_ACCURACY (voir Variables d'environnement).

Documentation des fonctions

int hwloc_distances_add_commit (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned long flags)

Valider une nouvelle structure de distances. Cette fonction finalise la structure de distances et l'insère dans la topologie.

Le paramètre handle était précédemment retourné par hwloc_distances_add_create(). Ensuite, les objets et valeurs ont été spécifiés avec hwloc_distances_add_values().

flags configure le comportement de la fonction en utilisant un ensemble optionnel OR'é de hwloc_distances_add_flag_e. Il peut être utilisé pour demander le groupement des objets existants en fonction des distances.

En cas d'erreur, la structure de distances temporaire et son contenu sont détruits.

Retourne

0 en cas de succès.

-1 en cas d'erreur.

hwloc_distances_add_handle_t hwloc_distances_add_create (hwloc_topology_t topology, const char * name, unsigned long kind, unsigned long flags)

Créer une nouvelle structure de distances vide. Crée une structure de distances vide qui sera remplie par hwloc_distances_add_values() et ensuite validée par hwloc_distances_add_commit().

Le paramètre name est optionnel, il peut être NULL. Sinon, il sera copié en interne et pourra être libéré ultérieurement par l'appelant.

kind spécifie la nature de la distance comme un ensemble OR'é de hwloc_distances_kind_e. Un seul type de signification et un seul type de provenance peuvent être donnés si approprié (par ex. HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH et HWLOC_DISTANCES_KIND_FROM_USER). Le type HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES sera automatiquement défini en fonction des objets ayant des types différents dans hwloc_distances_add_values().

flags doit être 0 pour l'instant.

Retourne

Un hwloc_distances_add_handle_t qui devrait ensuite être passé à hwloc_distances_add_values() et hwloc_distances_add_commit().

NULL en cas d'erreur.

int hwloc_distances_add_values (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned nbobjs, hwloc_obj_t * objs, hwloc_uint64_t * values, unsigned long flags)

Spécifier les objets et les valeurs dans une nouvelle structure de distances vide. Spécifie les objets et les valeurs pour une nouvelle structure de distances qui a été retournée comme handle par hwloc_distances_add_create(). La structure doit ensuite être validée avec hwloc_distances_add_commit().

Le nombre d'objets est nbobjs et le tableau d'objets est objs. Les valeurs de distance sont stockées dans un tableau unidimensionnel dans values. La distance de l'objet i à l'objet j se trouve à l'indice i*nbobjs+j.

nbobjs doit être au moins 2.

Les tableaux objs et values seront copiés en interne, ils peuvent être libérés ultérieurement par l'appelant.

En cas d'erreur, la structure de distances temporaire et son contenu sont détruits.

flags doit être 0 pour l'instant.

Retourne

0 en cas de succès.

-1 en cas d'erreur.
