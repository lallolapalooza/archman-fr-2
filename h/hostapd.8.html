NOM

hostapd - Point d'accès IEEE 802.11, authentificateur IEEE 802.1X/WPA/WPA2/EAP/RADIUS

SYNOPIS

hostapd [-hdBKtv] [-P <fichier PID>] <fichier(s) de configuration>

DESCRIPTION

Cette page de manuel documente brièvement le démon hostapd.

hostapd est un démon en espace utilisateur pour les points d'accès et les serveurs d'authentification. Il implémente la gestion des points d'accès IEEE 802.11, les authentificateurs IEEE 802.1X/WPA/WPA2/EAP et le serveur d'authentification RADIUS. La version actuelle prend en charge Linux (pilotes basés sur Host AP, mac80211) et FreeBSD (net80211).

hostapd est conçu pour être un programme de type "démon" qui s'exécute en arrière-plan et agit comme le composant backend contrôlant l'authentification. hostapd prend en charge des programmes frontaux séparés et un exemple de frontend basé sur texte, hostapd_cli, est inclus avec hostapd.

OPTIONS

Un résumé des options est inclus ci-dessous. Pour une description complète, exécutez hostapd depuis la ligne de commande.

-h
Afficher l'utilisation.
-d
Afficher plus de messages de débogage.
-dd
Afficher encore plus de messages de débogage.
-B
Exécuter le démon en arrière-plan.
-P <fichier PID>
Chemin vers le fichier PID.
-K
Inclure les données de clé dans les messages de débogage.
-t
Inclure des horodatages dans certains messages de débogage.
-v
Afficher la version de hostapd.
