subroutine chetd2 (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( * ) tau, integer

info)

CHETD2 réduit une matrice hermitienne en forme tridiagonale réelle symétrique par une transformation de similarité unitaire (algorithme non parallélisé)

.

But

: 
!>
!> CHETD2 réduit une matrice hermitienne complexe A en forme
!> tridiagonale réelle symétrique T par une transformation de similarité
!> unitaire : Q**H * A * Q = T.
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure de taille n par n de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie
!>          triangulaire strictement inférieure de A n'est pas référencée.
!>          Si UPLO = 'L', la partie triangulaire inférieure de taille n par n
!>          de A contient la partie triangulaire inférieure de la matrice A,
!>          et la partie triangulaire strictement supérieure de A n'est pas
!>          référencée.
!>          À la sortie, si UPLO = 'U', la diagonale et la première
!>          superdiagonale de A sont écrasées par les éléments correspondants
!>          de la matrice tridiagonale T, et les éléments au-dessus de la
!>          première superdiagonale, avec le tableau TAU, représentent la
!>          matrice unitaire Q comme un produit de réflecteurs élémentaires ;
!>          si UPLO = 'L', la diagonale et la première sous-diagonale de A
!>          sont écrasées par les éléments correspondants de la matrice
!>          tridiagonale T, et les éléments en dessous de la première
!>          sous-diagonale, avec le tableau TAU, représentent la matrice
!>          unitaire Q comme un produit de réflecteurs élémentaires. Voir
!>          Détails supplémentaires.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

D 
!>          D est un tableau REAL, dimension (N)
!>          Les éléments diagonaux de la matrice tridiagonale T :
!>          D(i) = A(i,i).
!
>

E 
!>          E est un tableau REAL, dimension (N-1)
!>          Les éléments hors diagonale de la matrice tridiagonale T :
!>          E(i) = A(i,i+1) si UPLO = 'U', E(i) = A(i+1,i) si UPLO = 'L'.
!
>

TA

U 
!>          TAU est un tableau COMPLEX, dimension (N-1)
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!
>

NAME


HETD2 -  This subroutine is intended to be called (for each
    subproblem) by ZHEHD2 .






SYNOPSIS


SUBROUTINE HETD2( UPLO, N, A, LDA, D, E, TAU, INFO )

CHARACTER * 1
UPLO
INTEGER N
COMPLEX*16 A( LDA, * )
INTEGER LDA
DOUBLE PRECISION D( * )
DOUBLE PRECISION E( * )
COMPLEX*16 TAU( * )
INTEGER INFO



A subroutine call is given below.






Detailed Description


This subroutine is intended to be called (for each subproblem)
    by ZHEHD2 .


This is the recursive panel function which has the recursive
    downward calls.


Arguments




UPLO    CHARACTER*1
        Specifies whether the matrix stored on the upper triangular
        part or the lower triangular part of the array A is to be
        processed.


UPLO = 'U' => process the upper triangular part


UPLO = 'L' => process the lower triangular part


N       INTEGER
        The order of the matrix A. N >= 0.


A       COMPLEX*16 array, dimension (LDA, N)
        On entry, the symmetric (or Hermitian) matrix A.


LDA     INTEGER
        The leading dimension of the array A. LDA >= max(1, N).


D       DOUBLE PRECISION array, dimension (N)
        On exit, the diagonal elements of the tridiagonal matrix T.


E       DOUBLE PRECISION array, dimension (N-1)
        On exit, the off-diagonal elements of the tridiagonal matrix T.


TAU     COMPLEX*16 array, dimension (N-1)
        On exit, the scalar factors of the elementary reflectors.


INFO    INTEGER
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value.








Author




Univ. of Tennessee


Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.




Further Details:




  If UPLO = 'U', the matrix Q is represented as a product of elementary
  reflectors
     Q = H(n-1) . . . H(2) H(1).
  Each H(i) has the form
     H(i) = I - tau * v * v**H
  where tau is a complex scalar, and v is a complex vector with
  v(i+1:n) = 0 and v(i) = 1; v(1:i-1) is stored on exit in
  A(1:i-1,i+1), and tau in TAU(i).
  If UPLO = 'L', the matrix Q is represented as a product of elementary
  reflectors
     Q = H(1) H(2) . . . H(n-1).
  Each H(i) has the form
     H(i) = I - tau * v * v**H
  where tau is a complex scalar, and v is a complex vector with
  v(1:i) = 0 and v(i+1) = 1; v(i+2:n) is stored on exit in A(i+2:n,i),
  and tau in TAU(i).
  The contents of A on exit are illustrated by the following examples
  with n = 5:
  if UPLO = 'U':                       if UPLO = 'L':
    (  d   e   v2  v3  v4 )              (  d                  )
    (      d   e   v3  v4 )              (  e   d              )
    (          d   e   v4 )              (  v1  e   d          )
    (              d   e  )              (  v1  v2  e   d      )
    (                  d  )              (  v1  v2  v3  e   d  )
  where d and e denote diagonal and off-diagonal elements of T, and vi
  denotes an element of the vector defining H(i).
