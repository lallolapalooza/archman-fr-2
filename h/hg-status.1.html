NOM

hg status - afficher les fichiers modifiés dans le répertoire de travail

SYNOPIS

hg status [OPTION]... [FICHIER]...

DESCRIPTION

Affiche le statut des fichiers du dépôt. Si des noms sont donnés, seuls les fichiers correspondants sont affichés. Les fichiers qui sont propres ou ignorés, ou qui sont la source d'une opération de copie/déplacement, ne sont pas listés à moins que -c/--clean, -i/--ignored, -C/--copies ou -A/--all ne soient donnés. Sauf si les options décrites avec « afficher seulement ... » sont données, les options -mardu sont utilisées.

L'option -q/--quiet masque les fichiers non suivis (inconnus et ignorés) sauf si explicitement demandés avec -u/--unknown ou -i/--ignored.

Note
hg status peut sembler être en désaccord avec diff si les permissions ont changé ou si une fusion s'est produite. Le format diff standard ne signale pas les changements de permissions et diff ne signale que les changements par rapport à un parent de fusion.

Si une révision est donnée, elle est utilisée comme révision de base. Si deux révisions sont données, les différences entre elles sont affichées. L'option --change peut également être utilisée comme raccourci pour lister les fichiers modifiés d'une révision par rapport à son premier parent.

Les codes utilisés pour afficher le statut des fichiers sont :

M = modifié
A = ajouté
R = supprimé
C = propre
! = manquant (supprimé par une commande non-hg, mais toujours suivi)
? = non suivi
I = ignoré
  = origine du fichier précédent (avec --copies)

L'option -t/--terse abrège la sortie en n'affichant que le nom du répertoire si tous les fichiers qu'il contient partagent le même statut. L'option prend un argument indiquant les statuts à abréger : 'm' pour 'modifié', 'a' pour 'ajouté', 'r' pour 'supprimé', 'd' pour 'supprimé', 'u' pour 'inconnu', 'i' pour 'ignoré' et 'c' pour propre.

Elle abrège seulement les statuts qui sont passés. Notez que les fichiers propres et ignorés ne sont pas affichés avec « --terse ic » sauf si les options -c/--clean et -i/--ignored sont également utilisées.

L'option -v/--verbose affiche des informations lorsque le dépôt est dans un état de fusion non terminée, de mise de côté, de rebase, etc. Vous pouvez activer ce comportement par défaut en activant l'option commands.status.verbose.

Vous pouvez empêcher l'affichage de certains de ces états en définissant commands.status.skipstates à un ou plusieurs des éléments suivants : 'bisect', 'graft', 'histedit', 'merge', 'rebase', ou 'unshelve'.

Template :

Les mots-clés suivants sont pris en charge en plus des mots-clés et fonctions de template communs. Voir aussi hg help templates.

path
Chaîne. Chemin absolu dans le dépôt du fichier.
source
Chaîne. Chemin absolu dans le dépôt d'où provient le fichier. Disponible si --copies est spécifié.
status
Caractère dénotant le statut du fichier.

Exemples :

  • afficher les changements dans le répertoire de travail par rapport à un changeset : 
    hg status --rev 9353
  • afficher les changements dans le répertoire de travail par rapport au répertoire courant (voir hg help patterns pour plus d'informations) : 
    hg status re:
  • afficher tous les changements, y compris les copies, dans un changeset existant : 
    hg status --copies --change 9353
  • obtenir une liste de fichiers ajoutés séparés par NUL, appropriée pour xargs : 
    hg status -an0
  • afficher plus d'informations sur le statut du dépôt, en abrégent les chemins ajoutés, supprimés, modifiés, effacés et non suivis : 
    hg status -v -t mardu

    Retourne 0 en cas de succès.

OPTIONS

-A, --all
afficher le statut de tous les fichiers
-m, --modified
afficher seulement les fichiers modifiés
-a, --added
afficher seulement les fichiers ajoutés
-r, --removed
afficher seulement les fichiers supprimés
-d, --deleted
afficher seulement les fichiers manquants
-c, --clean
afficher seulement les fichiers sans changements
-u, --unknown
afficher seulement les fichiers inconnus (non suivis)
-i, --ignored
afficher seulement les fichiers ignorés
-n, --no-status
masquer le préfixe de statut
-t,--terse <VALEUR>
afficher la sortie concise (EXPÉRIMENTAL) (par défaut : rien)
-C, --copies
afficher l'origine des fichiers copiés (PAR DÉFAUT : ui.statuscopies)
-0, --print0
terminer les noms de fichiers par NUL, pour utilisation avec xargs
--rev <REV[+]>
afficher la différence par rapport à la révision
--change <REV>
lister les fichiers modifiés d'une révision
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-S, --subrepos
récursion dans les sous-dépôts
-T,--template <TEMPLATE>
afficher avec un template

[+] l'option marquée peut être spécifiée plusieurs fois
