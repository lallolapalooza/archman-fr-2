NOM

hg bookmarks - créer un nouveau marque-page ou lister les marque-pages existants

SYNOPIS

hg bookmarks [OPTIONS]... [NAME]...

DESCRIPTION

Les marque-pages sont des étiquettes sur des changements pour aider à suivre les lignes de développement. Les marque-pages ne sont pas versionnés et peuvent être déplacés, renommés et supprimés. Supprimer ou déplacer un marque-page n'a aucun effet sur les changements associés.

La création ou la mise à jour vers un marque-page le marque comme 'actif'. Le marque-page actif est indiqué par un '*'. Lorsqu'un commit est effectué, le marque-page actif avancera vers le nouveau commit. Un simple hg update avancera également un marque-page actif, si possible. La mise à jour vers un autre marque-page le désactivera.

Les marque-pages peuvent être poussés et tirés entre les dépôts (voir hg help push et hg help pull). Si un marque-page partagé a divergé, un nouveau 'marque-page divergent' de la forme 'name@path' sera créé. L'utilisation de hg merge résoudra la divergence.

Spécifier un marque-page comme '.' dans les options -m/-d/-l est équivalent à spécifier le nom du marque-page actif.

Un marque-page nommé '@' a la propriété spéciale que hg clone l'extraira par défaut s'il existe.

Modèle :

Les mots-clés suivants sont supportés en plus des mots-clés et fonctions de modèle communs tels que {bookmark}. Voir aussi hg help templates.

active
Booléen. Vrai si le marque-page est actif.

Exemples :

  • créer un marque-page actif pour une nouvelle ligne de développement : 
    hg book new-feature
  • créer un marque-page inactif comme marqueur : 
    hg book -i reviewed
  • créer un marque-page inactif sur un autre changement : 
    hg book -r .^ tested
  • renommer le marque-page turkey en dinner : 
    hg book -m turkey dinner
  • déplacer le marque-page '@' d'une autre branche : 
    hg book -f @
  • afficher uniquement le nom du marque-page actif : 
    hg book -ql .

OPTIONS

-f, --force
forcer
-r,--rev <REV>
révision pour l'action du marque-page
-d, --delete
supprimer un marque-page donné
-m,--rename <OLD>
renommer un marque-page donné
-i, --inactive
marquer un marque-page comme inactif
-l, --list
lister les marque-pages existants
-T,--template <TEMPLATE>
afficher avec un modèle
