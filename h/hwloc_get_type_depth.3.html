int hwloc_get_type_depth (hwloc_topology_t topologie, hwloc_obj_type_t type)

Retourne la profondeur des objets de type type.

Retourne

La profondeur des objets de type type.

Une profondeur virtuelle négative si un type d'objet NUMA, I/O ou Misc est donné. Ces objets sont stockés dans des niveaux spéciaux qui ne sont pas liés aux processeurs. Cette profondeur virtuelle peut être passée à d'autres fonctions hwloc telles que hwloc_get_obj_by_depth() mais elle ne doit pas être considérée comme une profondeur réelle par l'application. En particulier, elle ne doit pas être comparée avec une autre profondeur d'objet ou avec la profondeur totale de la topologie.

HWLOC_TYPE_DEPTH_UNKNOWN si aucun objet de ce type n'est présent sur l'architecture sous-jacente, ou si le système d'exploitation ne fournit pas ce type d'information.

HWLOC_TYPE_DEPTH_MULTIPLE si le type HWLOC_OBJ_GROUP est donné et que plusieurs niveaux de Groupes existent.

Note

Si le type est absent mais qu'un type similaire est acceptable, voir aussi hwloc_get_type_or_below_depth() et hwloc_get_type_or_above_depth().

Voir aussi

hwloc_get_memory_parents_depth() pour la gestion de la profondeur des objets mémoire.

hwloc_type_sscanf_as_depth() pour retourner la profondeur des objets dont le type est donné sous forme de chaîne.

int hwloc_get_type_or_above_depth (hwloc_topology_t topologie, hwloc_obj_type_t type) [inline]

Retourne la profondeur des objets de type type ou au-dessus. Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, la fonction retourne la profondeur du premier objet 'présent' contenant typiquement type.

Cette fonction n'est significative que pour les types d'objets normaux. Si un type d'objet mémoire, I/O ou Misc est donné, la profondeur virtuelle correspondante est toujours retournée (voir hwloc_get_type_depth()).

Peut retourner HWLOC_TYPE_DEPTH_MULTIPLE pour HWLOC_OBJ_GROUP tout comme hwloc_get_type_depth().

int hwloc_get_type_or_below_depth (hwloc_topology_t topologie, hwloc_obj_type_t type) [inline]

Retourne la profondeur des objets de type type ou en dessous. Si aucun objet de ce type n'est présent sur l'architecture sous-jacente, la fonction retourne la profondeur du premier objet 'présent' trouvé typiquement à l'intérieur de type.

Cette fonction n'est significative que pour les types d'objets normaux. Si un type d'objet mémoire, I/O ou Misc est donné, la profondeur virtuelle correspondante est toujours retournée (voir hwloc_get_type_depth()).

Peut retourner HWLOC_TYPE_DEPTH_MULTIPLE pour HWLOC_OBJ_GROUP tout comme hwloc_get_type_depth().

int hwloc_topology_get_depth (hwloc_topology_t restrict topologie)

Obtient la profondeur de l'arbre hiérarchique des objets. C'est la profondeur des objets HWLOC_OBJ_PU plus un.

Retourne

la profondeur de l'arbre d'objets.

Note

Les objets NUMA, I/O et Misc sont ignorés lors du calcul de la profondeur de l'arbre (ils sont placés sur des niveaux spéciaux).
