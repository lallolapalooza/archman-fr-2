NOM

hg resolve - refaire les fusions ou définir/afficher l'état de fusion des fichiers

SYNTAXE

hg resolve [OPTION]... [FICHIER]...

DESCRIPTION

Les fusions avec des conflits non résolus sont souvent le résultat de fusions non interactives utilisant le paramètre de configuration internal:merge, ou un outil de fusion en ligne de commande comme diff3. La commande resolve est utilisée pour gérer les fichiers impliqués dans une fusion, après l'exécution de hg merge, et avant l'exécution de hg commit (c'est-à-dire que le répertoire de travail doit avoir deux parents). Voir hg help merge-tools pour des informations sur la configuration des outils de fusion.

La commande resolve peut être utilisée de la manière suivante :

  • hg resolve [--re-merge] [--tool TOOL] FICHIER... : tenter de refusionner les fichiers spécifiés, en ignorant toute tentative de fusion précédente. La refusion n'est pas effectuée pour les fichiers déjà marqués comme résolus. Utilisez --all/-a pour sélectionner tous les fichiers non résolus. --tool peut être utilisé pour spécifier l'outil de fusion utilisé pour les fichiers donnés. Il remplace la variable d'environnement HGMERGE et vos fichiers de configuration. Les contenus de fichiers précédents sont sauvegardés avec un suffixe .orig.
  • hg resolve -m [FICHIER] : marquer un fichier comme ayant été résolu (par exemple, après avoir corrigé manuellement les fichiers). Par défaut, tous les fichiers non résolus sont marqués.
  • hg resolve -u [FICHIER]... : marquer un fichier comme non résolu. Par défaut, tous les fichiers résolus sont marqués.
  • hg resolve -l : lister les fichiers qui avaient ou ont encore des conflits. Dans la liste imprimée, U = non résolu et R = résolu. Vous pouvez utiliser set:unresolved() ou set:resolved() pour filtrer la liste. Voir hg help filesets pour les détails.
Note
Mercurial ne vous permettra pas de valider des fichiers avec des conflits de fusion non résolus. Vous devez utiliser hg resolve -m ... avant de pouvoir valider après une fusion conflictuelle.

Modèle :

Les mots-clés suivants sont pris en charge en plus des mots-clés et fonctions de modèle courants. Voir également hg help templates.

mergestatus
Chaîne. Caractère indiquant les conflits de fusion, U ou R.
path
Chaîne. Chemin absolu du fichier dans le dépôt.

Retourne 0 en cas de succès, 1 si des fichiers échouent à une tentative de résolution.

OPTIONS

-a, --all
sélectionner tous les fichiers non résolus
-l, --list
lister l'état des fichiers nécessitant une fusion
-m, --mark
marquer les fichiers comme résolus
-u, --unmark
marquer les fichiers comme non résolus
-n, --no-status
masquer le préfixe d'état
--re-merge
refusionner les fichiers
-t,--tool <OUTIL>
spécifier l'outil de fusion
-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-T,--template <MODÈLE>
afficher avec le modèle

[+] l'option marquée peut être spécifiée plusieurs fois
