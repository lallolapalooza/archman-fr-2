CHETRS_3

Objectif:

!> CHETRS_3 résout un système d'équations linéaires A * X = B avec une matrice
!> complexe hermitienne A en utilisant la factorisation calculée
!> par CHETRF_RK ou CHETRF_BK:
!>
!>    A = P*U*D*(U**H)*(P**T) ou A = P*L*D*(L**H)*(P**T),
!>
!> où U (ou L) est une matrice triangulaire unitaire supérieure (ou inférieure),
!> U**H (ou L**H) est le conjugué de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est hermitienne et diagonale par blocs
!> avec des blocs diagonaux de 1x1 et 2x2.
!>
!> Cet algorithme utilise les BLAS de niveau 3.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure:
!>          = 'U':  Triangulaire supérieure, forme est A = P*U*D*(U**H)*(P**T);
!>          = 'L':  Triangulaire inférieure, forme est A = P*L*D*(L**H)*(P**T).
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA,N)
!>          Diagonale de la matrice diagonale par blocs D et facteurs U ou L
!>          tels que calculés par CHETRF_RK et CHETRF_BK:
!>            a) UNIQUEMENT les éléments diagonaux de la matrice hermitienne
!>               diagonale par blocs D sur la diagonale de A, c'est-à-dire
!>               D(k,k) = A(k,k);
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                doivent être fournis en entrée dans le tableau E), et
!>            b) Si UPLO = 'U': facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L': facteur L dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX de dimension (N)
!>          En entrée, contient les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice hermitienne diagonale par blocs D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) non référencé;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) non référencé.
!>
!>          NOTE: Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) n'est pas référencé dans les
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau INTEGER de dimension (N)
!>          Détails des échanges et de la structure des blocs de D
!>          tels que déterminés par CHETRF_RK ou CHETRF_BK.
!>

B

!>          B est un tableau COMPLEX de dimension (LDB,NRHS)
!>          En entrée, la matrice des membres de droite B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

CSYTRS_3 — Solve a complex symmetric system of linear equations

CSYTRS_3

Purpose:

!> CSYTRS_3 solves a system of linear equations A * X = B with a complex
!> symmetric matrix A using the factorization computed
!> by CSYTRF_RK or CSYTRF_BK:
!>
!>    A = P*U*D*(U**H)*(P**T) or A = P*L*D*(L**H)*(P**T),
!>
!> where U (or L) is unit upper (or lower) triangular matrix,
!> U**H (or L**H) is the conjugate transpose of U (or L), P is a permutation
!> matrix, P**T is the transpose of P, and D is symmetric and block
!> diagonal with 1-by-1 and 2-by-2 diagonal blocks.
!>
!> This algorithm is using Level 3 BLAS.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the details of the factorization are
!>          stored as an upper or lower triangular matrix:
!>          = 'U':  Upper triangular, form is A = P*U*D*(U**H)*(P**T);
!>          = 'L':  Lower triangular, form is A = P*L*D*(L**H)*(P**T).
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

A

!>          A is COMPLEX array, dimension (LDA,N)
!>          Diagonal of the block diagonal matrix D and factors U or L
!>          as computed by CSYTRF_RK and CSYTRF_BK:
!>            a) ONLY diagonal elements of the symmetric block diagonal
!>               matrix D on the diagonal of A, i.e. D(k,k) = A(k,k);
!>               (superdiagonal (or subdiagonal) elements of D
!>                should be provided on entry in array E), and
!>            b) If UPLO = 'U': factor U in the superdiagonal part of A.
!>               If UPLO = 'L': factor L in the subdiagonal part of A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

E

!>          E is COMPLEX array, dimension (N)
!>          On entry, contains the superdiagonal (or subdiagonal)
!>          elements of the symmetric block diagonal matrix D
!>          with 1-by-1 or 2-by-2 diagonal blocks, where
!>          If UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) not referenced;
!>          If UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) not referenced.
!>
!>          NOTE: For 1-by-1 diagonal block D(k), where
!>          1 <= k <= N, the element E(k) is not referenced in both
!>          UPLO = 'U' or UPLO = 'L' cases.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges and the block structure of D
!>          as determined by CSYTRF_RK or CSYTRF_BK.
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!>          On exit, the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
