NOM

httpie

SYNTAXE

httpie

DESCRIPTION

Interface de gestion pour HTTPie lui-même. https://httpie.io/docs#manager

Sachez que vous cherchez peut-être les commandes http/https pour envoyer des requêtes HTTP. Cette commande n'est disponible que pour gérer les plugins HTTPie et la configuration associée.

Si vous cherchez les pages man des commandes http/https, essayez l'une des commandes suivantes :
$ man http
$ man https

httpie cli export-args

Exporte les options disponibles pour l'interface en ligne de commande

-f, --format

Format dans lequel exporter.

httpie cli check-updates

Vérifie les mises à jour

httpie cli sessions upgrade

Met à jour la session HTTPie donnée avec la dernière structure. Une liste des changements entre les différentes versions de session se trouve dans la documentation officielle.

HOSTNAME

L'hôte auquel cette session appartient.

SESSION_NAME_OR_PATH

Le nom ou le chemin de la session qui sera mise à jour.

--bind-cookies

Associe les cookies sans domaine à l'hôte auquel la session appartient.

httpie cli sessions upgrade-all

Met à jour toutes les sessions nommées avec la dernière structure. Une liste des changements entre les différentes versions de session se trouve dans la documentation officielle.

--bind-cookies

Associe les cookies sans domaine à l'hôte auquel la session appartient.
