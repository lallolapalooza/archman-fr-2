NOM

hub-issue - Gérer les problèmes GitHub pour le dépôt actuel.

SYNTAXE

hub issue [-a ASSIGNE] [-c CREATEUR] [-@ UTILISATEUR] [-s ETAT] [-f FORMAT] [-M MARCHE_DE_PROGRES] [-l ETIQUETTES] [-d DATE] [-o CLE_TRI [-^]] [-L LIMITE]
hub issue show [-f FORMAT] NUMERO
hub issue create [-oc] [-m MESSAGE|-F FICHIER] [--edit] [-a UTILISATEURS] [-M MARCHE_DE_PROGRES] [-l ETIQUETTES]
hub issue update NUMERO [-m MESSAGE|-F FICHIER] [--edit] [-a UTILISATEURS] [-M MARCHE_DE_PROGRES] [-l ETIQUETTES] [-s ETAT]
hub issue labels [--color]
hub issue transfer NUMERO REPO

COMMANDES

Sans arguments, affiche une liste des problèmes ouverts.

show

Affiche un problème existant spécifié par NUMERO.

create

Ouvre un problème dans le dépôt actuel.

update

Met à jour les champs d'un problème existant spécifié par NUMERO. Utiliser --edit pour modifier interactivement le titre et le message dans l'éditeur de texte.

labels

Liste les étiquettes disponibles dans ce dépôt.

transfer

Transfère un problème vers un autre dépôt.

OPTIONS

-a, --assignee ASSIGNE

En mode liste, affiche uniquement les problèmes assignés à ASSIGNE.

-a, --assign UTILISATEURS

Une liste séparée par des virgules de pseudonymes GitHub à assigner au problème créé.

-c, --creator CREATEUR

Affiche uniquement les problèmes créés par CREATEUR.

-@, --mentioned UTILISATEUR

Affiche uniquement les problèmes mentionnant UTILISATEUR.

-s, --state ETAT

Affiche les problèmes avec l'état ETAT (défaut : "open").

-f, --format FORMAT

Imprime joliment le contenu des problèmes en utilisant le format FORMAT (défaut : "%sC%>(8)%i%Creset %t% l%n"). Voir la section "FORMATS DE MISE EN FORME" de git-log(1) pour plus de détails sur la façon dont les espaces réservés sont utilisés dans le format. Les espaces réservés disponibles pour les problèmes sont :

%I: numéro du problème

%i: numéro du problème préfixé par "#"

%U: l'URL de ce problème

%S: état (c'est-à-dire "ouvert", "fermé")

%sC: définit la couleur en rouge ou vert, selon l'état du problème.

%t: titre

%l: étiquettes colorées

%L: étiquettes brutes, séparées par des virgules

%b: corps

%au: nom de connexion de l'auteur

%as: liste des assignés séparée par des virgules

%Mn: numéro de la marche de progrès

%Mt: titre de la marche de progrès

%NC: nombre de commentaires

%Nc: nombre de commentaires encapsulé dans des parenthèses, ou une chaîne vide s'il est nul.

%cD: date de création seule (sans heure)

%cr: date de création, relative

%ct: date de création, timestamp UNIX

%cI: date de création, format ISO 8601

%uD: date de mise à jour seule (sans heure)

%ur: date de mise à jour, relative

%ut: date de mise à jour, timestamp UNIX

%uI: date de mise à jour, format ISO 8601

%n: nouvelle ligne

%%: un signe % littéral

--color[=QUAND]

Active la sortie colorée même si stdout n'est pas un terminal. QUAND peut être l'une des valeurs "always" (défaut pour --color), "never", ou "auto" (défaut).

-m, --message MESSAGE

Le texte jusqu'à la première ligne vide dans MESSAGE est traité comme le titre du problème, et le reste est utilisé comme description du problème au format Markdown.

Lorsque plusieurs --message sont passés, leurs valeurs sont concaténées avec une ligne vide entre elles.

Lorsque ni --message ni --file n'ont été fournis à issue create, un éditeur de texte s'ouvrira pour rédiger le titre et la description.

-F, --file FICHIER

Lit le titre et la description du problème depuis FICHIER. Passez "-" pour lire depuis l'entrée standard à la place. Voir --message pour les règles de formatage.

-e, --edit

Ouvre le titre et la description du problème dans un éditeur de texte avant la soumission. Peut être utilisé en combinaison avec --message ou --file.

-o, --browse

Ouvre le nouveau problème dans un navigateur web.

-c, --copy

Copie l'URL du nouveau problème dans le presse-papiers au lieu de l'afficher.

-M, --milestone NOM

Affiche uniquement les problèmes d'une marche de progrès GitHub du nom NOM.

Lors de l'ouverture d'un problème, ajoute ce problème à une marche de progrès GitHub du nom NOM. Passer le numéro de la marche de progrès est déprécié.

-l, --labels ETIQUETTES

Affiche uniquement les problèmes avec certaines étiquettes.

Lors de l'ouverture d'un problème, ajoute une liste d'étiquettes séparées par des virgules à ce problème.

-d, --since DATE

Affiche uniquement les problèmes mis à jour à partir du DATE au format ISO 8601.

-o, --sort CLE

Trie les problèmes affichés par "created" (défaut), "updated" ou "comments".

-^ --sort-ascending

Trie par dates croissantes au lieu de décroissantes.

-L, --limit LIMITE

Affiche uniquement les LIMITE premiers problèmes.

--include-pulls

Inclut les requêtes de tirage (pull requests) ainsi que les problèmes.

--color

Active la sortie colorée pour la liste des étiquettes.
