NOM

hugo-import-jekyll - importer depuis Jekyll avec Hugo

SYNTAXE

hugo import jekyll [indicateurs] [arguments]

DESCRIPTION

Importer depuis Jekyll.

L'importation depuis Jekyll nécessite deux chemins, par exemple hugo import jekyll chemin_racine_jekyll chemin_cible.

OPTIONS

--force[=false] autoriser l'importation dans un répertoire cible non vide

-h, --help[=false] aide pour jekyll

OPTIONS HERITÉES DES COMMANDES PARENT

--clock="" définir l'horloge utilisée par Hugo, par exemple --clock 2021-11-06T22:30:00.00+09:00

--config="" fichier de configuration (par défaut hugo.yaml|json|toml)

--configDir="config" répertoire de configuration

-d, --destination="" chemin du système de fichiers où écrire les fichiers

-e, --environment="" environnement de construction

--ignoreVendorPaths="" ignore tout _vendor pour les chemins de modules correspondant au modèle Glob donné

--logLevel="" niveau de journalisation (debug|info|warn|error)

--noBuildLock[=false] ne pas créer de fichier .hugo_build.lock

--quiet[=false] construire en mode silencieux

-M, --renderToMemory[=false] rendre en mémoire (principalement utile lors de l'exécution du serveur)

-s, --source="" chemin du système de fichiers à partir duquel lire les fichiers relativement

--themesDir="" chemin du système de fichiers du répertoire des thèmes
