NOM

hb-shape - page manuelle pour hb-shape 12.2.0

DESCRIPTION

Utilisation :

hb-shape [OPTION???] [FICHIER-POLICE] [TEXTE]

Met en forme du texte avec la police donnée.

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-face
Options pour la graisse de la police
--help-font
Options pour l'instance de la police
--help-variations
Options pour les variations de police utilisées
--help-text
Options pour le texte en entrée
--help-text-context
Options pour le texte de contexte en entrée
--help-shape
Options pour le processus de mise en forme
--help-features
Options pour les fonctionnalités de police utilisées
--help-output
Options pour la destination et la forme de la sortie
--help-output-syntax
Options pour la syntaxe de la sortie

Options de graisse de police :

--font-file=nom-de-fichier
Définir le nom du fichier de police
-y, --face-index=index
Définir l'index de la graisse (par défaut : 0)
--face-loader=chargeur
Définir le chargeur de graisse à utiliser (par défaut : ot)
Les chargeurs de graisse pris en charge sont : ot/ft
--list-face-loaders
Lister les chargeurs de graisse disponibles et quitter

Options d'instance de police :

--font-size=1/2 entiers ou 'upem'
Taille de police (par défaut : upem)
--font-ppem=1/2 entiers
Définir les pixels x,y par EM (par défaut : 0 ; désactivé)
--font-ptem=taille-en-points
Définir la taille en points de la police (par défaut : 0 ; désactivé)
--font-bold=1/2 nombres ; ex. 0.05
Définir le gras synthétique (par défaut : 0)
--font-grade=1/2 nombres ; ex. 0.05
Définir le grade synthétique (par défaut : 0)
--font-slant=inclinaison rapport ; ex. 0.2
Définir l'inclinaison synthétique (par défaut : 0)
--font-funcs=impl
Définir l'implémentation des fonctions de police à utiliser (par défaut : ot)
Les implémentations de fonctions de police prises en charge sont : ot/ft
--list-font-funcs
Lister les fonctions de police disponibles et quitter
--ft-load-flags=entier
Définir les drapeaux de chargement FreeType (par défaut : 2)

Options de variations :

--named-instance=index
Définir l'index de l'instance nommée (par défaut : aucune)
--variations=liste
Liste de variations de police séparées par des virgules
Les variations sont définies globalement. Le format pour spécifier les paramètres de variation est le suivant. Toutes les valeurs valides de font-variation-settings en CSS autres que 'normal' et 'inherited' sont également acceptées, bien qu'elles ne soient pas documentées ci-dessous.
Le format est une étiquette, éventuellement suivie d'un signe égal, suivie d'un nombre. Par exemple :
"wght=500" "slnt=-7.5"

Options de texte :

Si aucun texte n'est fourni, l'entrée standard est utilisée comme entrée.

--text=chaîne
Définir le texte en entrée
--text-file=nom-de-fichier
Définir le nom du fichier de texte en entrée
-u, --unicodes=liste de nombres hexadécimaux
Définir les points de code Unicode en entrée
--single-par
Traiter le texte comme un seul paragraphe

Options de contexte textuel :

--text-before=chaîne
Définir le texte de contexte avant chaque ligne
--text-after=chaîne
Définir le texte de contexte après chaque ligne
--unicodes-before=liste de nombres hexadécimaux
Définir le contexte des points de code Unicode avant chaque ligne
--unicodes-after=liste de nombres hexadécimaux
Définir le contexte des points de code Unicode après chaque ligne

Options de mise en forme :

--shapers=liste séparée par des virgules
Définir les moteurs de mise en forme à utiliser (par défaut : graphite2)
Les moteurs de mise en forme pris en charge sont : graphite2/ot/fallback
--list-shapers
Lister les moteurs de mise en forme disponibles et quitter
--direction=ltr/rtl/ttb/btt
Définir la direction du texte (par défaut : auto)
--language=étiquette BCP 47
Définir la langue du texte (par défaut : $LANG)
--script=étiquette ISO-15924
Définir l'écriture du texte (par défaut : auto)
--bot
Traiter le texte comme début de paragraphe
--eot
Traiter le texte comme fin de paragraphe
--preserve-default-ignorables
Préserver les caractères Default-Ignorable
--remove-default-ignorables
Supprimer les caractères Default-Ignorable
--invisible-glyph
Valeur de glyphe pour remplacer les Default-Ignorable
--not-found-glyph
Valeur de glyphe pour remplacer les caractères non trouvés
--not-found-variation-selector-glyph
Valeur de glyphe pour remplacer les caractères sélecteurs de variation non trouvés
--utf8-clusters
Utiliser les index d'octets UTF8, et non les index de caractères
--cluster-level=0/1/2/3
Niveau de fusion des grappes (par défaut : 0)
--normalize-glyphs
Réorganiser les grappes de glyphes dans l'ordre nominal
--unsafe-to-concat
Produire le drapeau de glyphe unsafe-to-concat
--safe-to-insert-tatweel
Produire le drapeau de glyphe safe-to-insert-tatweel
--glyphs
Interpréter l'entrée comme desyph
string
--veri
fy
Effectuer des vérif
