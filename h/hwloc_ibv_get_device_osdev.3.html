Description détaillée

Cette interface offre des moyens de récupérer des informations de topologie sur les périphériques OpenFabrics (InfiniBand, Omni-Path, usNIC, etc.).

Documentation des fonctions

int hwloc_ibv_get_device_cpuset (hwloc_topology_t topology, struct ibv_device * ibdev, hwloc_cpuset_t set) [inline]

Obtenir l'ensemble des processeurs CPU physiquement proches du périphérique ibdev. Stocker dans set l'ensemble de CPU décrivant la localité du périphérique OpenFabrics ibdev (InfiniBand, etc.).

La topologie topology et le périphérique ibdev doivent correspondre à la machine locale. La détection des périphériques d'E/S n'est pas nécessaire dans la topologie.

La fonction ne retourne que la localité du périphérique. Si des informations supplémentaires sur le périphérique sont nécessaires, il faut utiliser les objets du système d'exploitation à la place, voir hwloc_ibv_get_device_osdev() et hwloc_ibv_get_device_osdev_by_name().

Cette fonction n'est actuellement implémentée de manière significative que pour Linux ; les autres systèmes obtiendront simplement un ensemble de CPU complet.

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si les informations du périphérique n'ont pas pu être trouvées.

hwloc_obj_t hwloc_ibv_get_device_osdev (hwloc_topology_t topology, struct ibv_device * ibdev) [inline]

Obtenir l'objet de périphérique OS de hwloc correspondant au périphérique OpenFabrics ibdev.

Retourne

L'objet de périphérique OS de hwloc décrivant le périphérique OpenFabrics ibdev (InfiniBand, etc).

NULL si aucun n'a pu être trouvé.

La topologie topology et le périphérique ibdev doivent correspondre à la machine locale. La détection des périphériques d'E/S doit être activée dans la topologie. Sinon, la localité de l'objet peut toujours être trouvée en utilisant hwloc_ibv_get_device_cpuset().

Note

L'objet de périphérique PCI correspondant peut être obtenu en examinant l'objet parent du périphérique OS.

hwloc_obj_t hwloc_ibv_get_device_osdev_by_name (hwloc_topology_t topology, const char * ibname) [inline]

Obtenir l'objet de périphérique OS de hwloc correspondant au périphérique OpenFabrics nommé ibname.

Retourne

L'objet de périphérique OS de hwloc décrivant le périphérique OpenFabrics (InfiniBand, Omni-Path, usNIC, etc) dont le nom est ibname (mlx5_0, hfi1_0, usnic_0, qib0, etc).

NULL si aucun n'a pu être trouvé.

Le nom ibname est généralement obtenu à partir de ibv_get_device_name().

La topologie topology ne doit pas nécessairement correspondre à la machine actuelle. Par exemple, la topologie peut être une importation XML d'un hôte distant. La détection des périphériques d'E/S doit être activée dans la topologie.

Note

L'objet de périphérique PCI correspondant peut être obtenu en examinant l'objet parent du périphérique OS.
