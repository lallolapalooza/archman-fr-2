CHBGS

T

But

: 
!>
!> CHBGST réduit un problème généralisé de valeurs propres hermitien-défini
!> bandé  A*x = lambda*B*x  à la forme standard  C*y = lambda*y,
!> de telle sorte que C ait la même bande que A.
!>
!> B doit avoir été préalablement factorisé sous la forme S**H*S par CPBSTF, en utilisant une
!> factorisation de Cholesky scindée. A est écrasé par C = X**H*A*X, où
!> X = S**(-1)*Q et Q est une matrice unitaire choisie pour préserver la
!> bande de A.
!
>

Paramètre

s
VECT 
!>          VECT est CHARACTER*1
!>          = 'N' : ne pas former la matrice de transformation X ;
!>          = 'V' : former X.
!
>

UPL

O 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!
>

N 
!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!
>

K

A 
!>          KA est INTEGER
!>          Le nombre de surdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= 0.
!
>

K

B 
!>          KB est INTEGER
!>          Le nombre de surdiagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= KB >= 0.
!
>

A

B 
!>          AB est un tableau COMPLEX, dimension (LDAB,N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice
!>          bande hermitienne A, stocké dans les premières ka+1 lignes du tableau.  La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          À la sortie, la matrice transformée X**H*A*X, stockée dans le même
!>          format que A.
!
>

LDA

B 
!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!
>

B

B 
!>          BB est un tableau COMPLEX, dimension (LDBB,N)
!>          Le facteur bande S de la factorisation de Cholesky scindée de
!>          B, tel que retourné par CPBSTF, stocké dans les premières kb+1 lignes du
!>          tableau.
!
>

LDB

B 
!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!
>

X 
!>          X est un tableau COMPLEX, dimension (LDX,N)
!>          Si VECT = 'V', la matrice X de taille n par n.
!>          Si VECT = 'N', le tableau X n'est pas référencé.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>          LDX >= max(1,N) si VECT = 'V' ; LDX >= 1 sinon.
!
>

WOR

K
