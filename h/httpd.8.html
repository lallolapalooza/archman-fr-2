NOM

httpd - Serveur Apache Hypertext Transfer Protocol

SYNTAXE

httpd [ -d racine_serveur ] [ -f config ] [ -C directive ] [ -c directive ] [ -D parametre ] [ -e niveau ] [ -E fichier ] [ -k start|restart|graceful|stop|graceful-stop ] [ -h ] [ -l ] [ -L ] [ -S ] [ -t ] [ -v ] [ -V ] [ -X ] [ -M ] [ -T ]

Sur les systèmes Windows, les arguments supplémentaires suivants sont disponibles :

httpd [ -k install|config|uninstall ] [ -n nom ] [ -w ]

RESUME

httpd est le programme serveur Apache HyperText Transfer Protocol (HTTP). Il est conçu pour être exécuté comme un processus démon autonome. Lorsqu'il est utilisé de cette manière, il crée un pool de processus enfants ou de threads pour gérer les requêtes.

En général, httpd ne doit pas être appelé directement, mais plutôt via apachectl sur les systèmes basés sur Unix ou comme un service sous Windows NT, 2000 et XP, et comme une application console sous Windows 9x et ME.

OPTIONS

-d racine_serveur
Définit la valeur initiale de la directive ServerRoot à racine_serveur. Ceci peut être remplacé par la directive ServerRoot dans le fichier de configuration. La valeur par défaut est /usr/local/apache2.
-f config
Utilise les directives du fichier config au démarrage. Si config ne commence pas par un /, alors il est considéré comme un chemin relatif à la racine du serveur (ServerRoot). La valeur par défaut est conf/httpd.conf.
-k start|restart|graceful|stop|graceful-stop
Signale à httpd de démarrer, redémarrer ou s'arrêter. Voir Arrêter Apache httpd pour plus d'informations.
-C directive
Traite la directive de configuration avant de lire les fichiers de configuration.
-c directive
Traite la directive de configuration après avoir lu les fichiers de configuration.
-D parametre
Définit un parametre de configuration qui peut être utilisé avec les sections <IfDefine> dans les fichiers de configuration pour ignorer ou traiter conditionnellement des commandes au démarrage et au redémarrage du serveur. Peut également être utilisé pour définir certains paramètres de démarrage moins courants, notamment -DNO_DETACH (empêche le parent de créer un fork) et -DFOREGROUND (empêche le parent d'appeler setsid() et autres).
-e niveau
Définit le LogLevel à niveau pendant le démarrage du serveur. Ceci est utile pour augmenter temporairement la verbosité des messages d'erreur afin de trouver des problèmes lors du démarrage.
-E fichier
Envoie les messages d'erreur pendant le démarrage du serveur au fichier.
-h
Affiche un bref résumé des options de ligne de commande disponibles.
-l
Affiche une liste des modules compilés dans le serveur. Cela ne listera PAS les modules chargés dynamiquement inclus via la directive LoadModule.
-L
Affiche une liste des directives fournies par les modules statiques, ainsi que leurs arguments attendus et les endroits où la directive est valide. Les directives fournies par les modules partagés ne sont pas listées.
-M
Affiche une liste des modules statiques et partagés chargés.
-S
Affiche les paramètres tels qu'ils sont lus à partir du fichier de configuration (affiche actuellement uniquement les paramètres des hôtes virtuels).
-T (Disponible à partir de la version 2.3.8)
Ignore la vérification de la racine du document au démarrage/redémarrage.
-t
Exécute uniquement des tests de syntaxe pour les fichiers de configuration. Le programme se quitte immédiatement après ces tests d'analyse syntaxique avec un code de retour de 0 (Syntaxe OK) ou un code de retour différent de 0 (Erreur de syntaxe). Si -D DUMP_VHOSTS est également défini, des détails sur la configuration des hôtes virtuels seront affichés. Si -D DUMP_MODULES est défini, tous les modules chargés seront affichés.
-v
Affiche la version de httpd, puis quitte.
-V
Affiche la version et les paramètres de construction de httpd, puis quitte.
-X
Exécute httpd en mode débogage. Un seul worker sera démarré et le serveur ne se détachera pas de la console.

Les arguments suivants ne sont disponibles que sur la plateforme Windows :

-k install|config|uninstall
Installe Apache httpd en tant que service Windows NT ; modifie les options de démarrage du service Apache httpd ; et désinstalle le service Apache httpd.
-n nom
Le nom du service Apache httpd à signaler.
-w
Maintient la fenêtre de console ouverte en cas d'erreur afin que le message d'erreur puisse être lu.
