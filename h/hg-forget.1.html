NOM

hg forget - oublier les fichiers spécifiés lors du prochain commit

SYNTAXE

hg forget [OPTION]... FICHIER...

DESCRIPTION

Marque les fichiers spécifiés pour qu'ils ne soient plus suivis après le prochain commit.

Ceci ne retire les fichiers que de la branche actuelle, pas de l'historique complet du projet, et ne les supprime pas du répertoire de travail.

Pour supprimer le fichier du répertoire de travail, voir hg remove.

Pour annuler un oubli avant le prochain commit, voir hg add.

Exemples :

  • oublier les fichiers binaires nouvellement ajoutés : 
    hg forget "set:added() and binary()"
  • oublier les fichiers qui seraient exclus par .hgignore : 
    hg forget "set:hgignore()"

    Retourne 0 en cas de succès.

OPTIONS

-i, --interactif
utiliser le mode interactif
-I,--inclure <MODELE[+]>
inclure les noms correspondant aux modèles donnés
-X,--exclure <MODELE[+]>
exclure les noms correspondant aux modèles donnés
-n, --secou-run
ne pas effectuer les actions, juste afficher la sortie

[+] option marquée peut être spécifiée plusieurs fois
