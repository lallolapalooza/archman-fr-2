HG(BUNDLE) HG(BUNDLE)

NOM

hg bundle - créer un fichier de paquet

SYNTAXE

hg bundle [-f] [-t BUNDLESPEC] [-a] [-r REV]... [--base REV]... FICHIER [DEST]...

DESCRIPTION

Génère un fichier de paquet contenant des données à transférer vers un autre dépôt.

Pour créer un paquet contenant tous les changements, utilisez -a / --all (ou --base null). Sinon, hg suppose que la destination aura tous les nœuds que vous spécifiez avec les paramètres --base. Sinon, hg supposera que le dépôt a tous les nœuds dans la destination, ou le push/défaut par défaut si aucune destination n'est spécifiée, où destination est le dépôt que vous fournissez via l'option DEST.

Vous pouvez modifier le format du paquet avec l'option -t / --type. Voir hg help bundlespec pour la documentation sur ce format. Par défaut, le format le plus approprié est utilisé et la compression est par défaut bzip2.

Le fichier de paquet peut ensuite être transféré en utilisant des moyens conventionnels et appliqué à un autre dépôt avec la commande unbundle ou pull. Ceci est utile lorsque les push et pull directs ne sont pas disponibles ou lorsque l'exportation d'un dépôt entier est indésirable.

L'application des paquets préserve tous les contenus des changements, y compris les permissions, les informations de copie/renommage et l'historique des révisions.

Retourne 0 en cas de succès, 1 si aucun changement n'est trouvé.

OPTIONS

--exact
calculer la base à partir de la révision spécifiée
-f, --force
exécuter même lorsque la destination n'est pas liée
-r,--rev <REV[+]>
un changement destiné à être ajouté à la destination
-b,--branch <BRANCH[+]>
une branche spécifique que vous souhaitez empaqueter
--base <REV[+]>
un changement de base supposé être disponible à la destination
-a, --all
empaqueter tous les changements dans le dépôt
-t,--type <TYPE>
type de compression du paquet à utiliser (par défaut : bzip2)
-e,--ssh <CMD>
spécifier la commande ssh à utiliser
--remotecmd <CMD>
spécifier la commande hg à exécuter du côté distant
--insecure
ne pas vérifier le certificat du serveur (ignorant la configuration web.cacerts)

[+] l'option marquée peut être spécifiée plusieurs fois
