NOM

helix2solv - convertir le format hérité helixcode en fichier solv

SYNTAXE

helix2solv

DESCRIPTION

Le format helix était un format de métadonnées utilisé dans le gestionnaire de paquets RedCarpet. Il est toujours utilisé dans les cas de test de libzypp. L'outil helix2solv lit les données au format helix depuis l'entrée standard et les écrit au format fichier solv vers la sortie standard.
