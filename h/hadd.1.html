hadd(1) Manuel des commandes générales hadd(1)

SYNTAXE

utilisation : hadd [-a] [-f] [-f[0-9]] [-fk] [-ff] [-k] [-L] [-Ltype] [-O] [-T]
[-v V] [-j J] [-dbg] [-d D] [-n N] [-cachesize CACHESIZE]
[-experimental-io-features EXPERIMENTAL_IO_FEATURES]
TARGET SOURCES

DESCRIPTION

Ce programme ajoute des histogrammes, des arbres et d'autres objets à partir d'une liste de fichiers ROOT et les écrit dans un fichier ROOT cible. Le fichier cible est nouvellement créé et ne doit pas exister, ou s'il est donné -f (« forcer »), ne doit pas être l'un des fichiers source.

OPTIONS

-a
Ajouter au résultat
-f
Forcer l'écrasement du fichier de sortie
-f[0-9]
Permet de spécifier l'algorithme de compression i et le niveau j
du fichier cible, en passant le nombre i*100 + j, par exemple -f505. Le
dernier chiffre (j) peut être réglé de 0 = non compressé à 9 = hautement
compressé. Le premier chiffre (i) est 1 pour ZLIB, 2 pour LZMA, 4 pour LZ4
et 5 pour ZSTD. Les nombres recommandés sont 101 (ZLIB), 207 (LZMA), 404
(LZ4), 505 (ZSTD). La valeur par défaut pour ce drapeau est 101
(kDefaultZLIB). Voir la documentation de ROOT::RCompressionSetting et TFile::TFile
pour plus de détails.
-fk
Définit le fichier cible pour contenir les paniers avec la même compression
que les fichiers d'entrée (sauf si -O est spécifié). Compresse les métadonnées
en utilisant le niveau de compression spécifié dans la première entrée ou le
paramètre de compression après fk (par exemple 206 lors de l'utilisation de -fk206)
-ff
Le niveau de compression utilisé est celui spécifié dans la première entrée
-k
Ignorer les fichiers corrompus ou inexistants, ne pas quitter
-L
Lire la liste des objets du FICHIER et soit ne fusionner que, soit ignorer ceux
objets en fonction de la valeur de « -Ltype ». FICHIER doit contenir un
nom d'objet par ligne, qui ne peut pas contenir d'espaces blancs ou de '/'. Vous pouvez
également passer des noms de TDirectory, qui s'appliquent à l'ensemble du contenu
du répertoire. Les lignes commençant par '#' sont ignorées. Si ce drapeau est passé,
« -Ltype » DOIT également être passé.
-Ltype
Définit le type d'opération effectuée sur les objets listés dans FICHIER
fourni avec le drapeau « -L ». « SkipListed » ignorera tous les objets listés ;
« OnlyListed » ne fusionnera que ces objets. Si ce drapeau est
passé, « -L » doit être passé également.
-O
Réoptimiser la taille des paniers lors de la fusion de TTree
-T
Ne pas fusionner les Arbres
-v
Définir explicitement le niveau de verbosité : 0 demande aucune sortie, 99 est la
valeur par défaut
-j
Paralléliser l'exécution en 'J' processus. Si le nombre de processus
n'est pas spécifié, utiliser le maximum du système.
-dbg
Activer la verbosité. Si -j a été spécifié, ne pas supprimer les fichiers partiels
stockés dans le répertoire de travail.
-d
Effectuer l'exécution partielle multiprocessus dans le répertoire spécifié
-n
Ouvrir au maximum 'N' fichiers à la fois (utiliser 0 pour demander à utiliser le système
maximum)
-cachesize
Redimensionner le cache de préchargement utilisé pour accélérer les opérations d'E/S (utiliser 0 pour
désactiver)
-experimental-io-features
Utilisé avec un argument fourni, active la fonctionnalité expérimentale correspondante
pour les arbres de sortie. Voir ROOT::Experimental::EIOFeatures
CIBLE
Fichier cible
SOURCES
Fichiers sources
