DESCRIPTIO

N

hut est une utilitaire compagnon en ligne de commande pour interagir avec sr.

ht.

Les ressources (telles que les tâches de compilation, les tickets todo, les listes de patchsets, les dépôts git, etc.) peuvent être spécifiées sous plusieurs formes : nom, propriétaire et nom, ou URL complète. Par exemple, le dépôt hut appartenant à ~emersion sur git.sr.ht peut être référencé via

:
  • "hu
    • t"
  • "~emersion/h
    • ut"
  • "https://git.sr.ht/~emersion/hu
    • t
"

De plus, les listes de diffusion peuvent être référencées par leur adresse

e-mail.

Les commandes hut qui lisent des entrées, comme hut graphql ou hut builds user-webhook create, lisent l'entrée selon que leur entrée standard est sur un terminal ou non

:
•
Si l'entrée standard n'est pas sur un terminal, par exemple parce qu'elle est redirigée depuis un fichier ou depuis un pipe, hut lit l'entrée depu
is l'entrée
standard.
•
Sinon, si l'option --stdin est spécifiée à la commande, hut lit l'entrée depu
is l'entrée
standard.
•
Sinon, hut suppose s'exécuter dans un terminal et lance la commande fournie par la variable d'environnement $EDITOR pou
r lir
e l'en
trée.

CONFIGURATIO

N

Générer un nouveau jeton d'accès OAuth2 sur meta.sr

.ht.

Au démarrage, hut cherchera un fichier à $XDG_CONFIG_HOME/hut/config. Si non défini, $XDG_CONFIG_HOME vaut par défaut ~/.conf

ig/. 
instance "sr.ht" {
	access-token "<token>"
	# As an alternative you can specify a command whose first line of output
	# will be parsed as the token
	access-token-cmd pass token
	meta {
		# You can set the origin for each service. As fallback hut will
		# construct the origin from the instance name and the service.
		origin "https://meta.sr.ht"
}
}

Fichier de configuration du

projet

Le fichier de configuration du projet est un fichier de premier niveau appelé .hut.scfg dans un dépôt, où le tracker et la liste de diffusion de développement associés peuvent être spécifiés. Ces ressources seront utilisées chaque fois qu'une commande est appelée qui a besoin d'un tracker/liste de diffusion et qu'aucun n'est explicitement défini. De plus, il est possible de configurer que les patches contiennent le nom du dépôt dans leur préfixe. La hut git clone command configurera un dépôt fraîchement cloné pour faciliter les

contributions.
