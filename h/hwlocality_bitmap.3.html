int hwloc_bitmap_singlify (hwloc_bitmap_t bitmap)

Conserve un seul indice parmi ceux définis dans le bitmap bitmap. Peut être utile avant le binding afin que le processus n'ait pas de possibilité de migration entre plusieurs processeurs du masque original. Au lieu de lancer la tâche sur n'importe quelle PU à l'intérieur de l'ensemble CPU donné, le planificateur du système d'exploitation sera forcé de la lancer sur une seule de ces PUs. Cela évite un surcoût de migration et des échanges de lignes de cache entre les PUs.

Note

Cette fonction n'est PAS destinée à distribuer plusieurs processus au sein d'un même ensemble CPU. Elle renvoie toujours le même bit unique lorsqu'elle est appelée plusieurs fois sur le même ensemble d'entrée. hwloc_distrib() peut être utilisé pour générer des ensembles CPU afin de distribuer plusieurs tâches sous un objet multi-PU unique.

Cette fonction ne peut pas être appliquée directement à un ensemble d'objets. Elle doit être appliquée à une copie (qui peut être obtenue avec hwloc_bitmap_dup()).

int hwloc_bitmap_sscanf (hwloc_bitmap_t bitmap, const char *restrict string)

Analyse une chaîne de bitmap au format hwloc par défaut et la stocke dans le bitmap bitmap. Notez que si le bitmap est un ensemble de CPU ou de nœuds, la chaîne d'entrée doit contenir des indices physiques.

La chaîne d'entrée doit être une liste hexadécimale de blocs de 32 bits séparée par des virgules. La chaîne '0xffffffff,0x6,0x2' est analysée comme un bitmap contenant tous les bits entre 64 et 95, et les bits 33, 34 et 1.

int hwloc_bitmap_taskset_asprintf (char ** strp, hwloc_const_bitmap_t bitmap)

Convertit un bitmap en une chaîne de caractères allouée dynamiquement, spécifique au format taskset. Notez que si le bitmap est un ensemble de CPU ou de nœuds, il contient des indices physiques.
