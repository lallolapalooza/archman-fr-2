NOM

httpcfg - Gestion des certificats Mono pour HttpListener

SYNTAXE

httpcfg [options] certificat

DESCRIPTION

Cet outil est utilisé pour gérer les certificats utilisés par la classe de serveur intégrable HttpListener lorsque HttpListener est configuré comme un serveur HTTPS au lieu d'un serveur HTTP.

Vous devez sélectionner l'une des actions possibles : ajouter, supprimer ou lister.

Lors de l'ajout d'un certificat (-add), vous devez fournir les informations suivantes : un certificat (avec le drapeau -cert) un fichier de clé privée (avec l'argument -pvk, le nom du fichier est généralement "key") et un numéro de port (avec le drapeau -port).

Lors de la suppression d'un certificat (-del ou -delete) vous devez fournir le numéro de port.

PARAMETRES

-add
Ajoute une nouvelle combinaison certificat/clé privée à utiliser sur un port donné par l'API HttpListener.
-del, -delete
Supprime les certificats associés au port spécifié (doit être spécifié séparément).
-list
Liste tous les certificats connus.
-port PORT
Spécifie le port sur lequel ajouter ou supprimer des certificats.
-pvk FICHIER
Spécifie le fichier de clé privée.
-cert CERT
Spécifie le fichier de certificat à utiliser.

EXEMPLES

httpcfg -add -port 8081 -pvk myfile.pvk -cert MyCert

Pour plus de détails sur la création du fichier de certificat et de la clé privée, consultez la page Web suivante :

http://www.mono-project.com/docs/web/using-clientcertificates-with-xsp/

FICHIERS

Les certificats sont stockés dans le répertoire ~/.mono/httplistener
