NOM

hg serve - démarrer un serveur web autonome

SYNTAXE

hg serve [OPTION]

DESCRIPTION

Démarre un navigateur de dépôt HTTP local et un serveur de récupération. Vous pouvez l'utiliser pour le partage et la navigation ad hoc de dépôts. Il est recommandé d'utiliser un vrai serveur web pour servir un dépôt pendant de longues périodes.

Veuillez noter que le serveur n'implémente pas de contrôle d'accès. Cela signifie que, par défaut, n'importe qui peut lire depuis le serveur et personne ne peut y écrire par défaut. Définissez l'option web.allow-push à * pour autoriser tout le monde à pousser vers le serveur. Vous devriez utiliser un vrai serveur web si vous avez besoin d'authentifier des utilisateurs.

Par défaut, le serveur enregistre les accès sur stdout et les erreurs sur stderr. Utilisez les options -A/--accesslog et -E/--errorlog pour enregistrer dans des fichiers.

Pour que le serveur choisisse un port libre pour écouter, spécifiez un numéro de port de 0 ; dans ce cas, le serveur affichera le numéro de port qu'il utilise.

Retourne 0 en cas de succès.

OPTIONS

-A,--accesslog <FICHIER>
nom du fichier de log d'accès à écrire
-d, --daemon
exécuter le serveur en arrière-plan
--daemon-postexec <VALEUR[+]>
utilisé en interne par le mode daemon
-E,--errorlog <FICHIER>
nom du fichier de log d'erreurs à écrire
-p,--port <PORT>
port sur lequel écouter (par défaut : 8000)
-a,--address <ADDR>
adresse sur laquelle écouter (par défaut : toutes les interfaces)
--prefix <PREFIXE>
chemin préfixe à servir (par défaut : racine du serveur)
-n,--name <NOM>
nom à afficher dans les pages web (par défaut : répertoire de travail)
--web-conf <FICHIER>
nom du fichier de configuration hgweb (voir 'hg help hgweb')
--webdir-conf <FICHIER>
nom du fichier de configuration hgweb (OBSOLÈTE)
--pid-file <FICHIER>
nom du fichier où écrire l'ID du processus
--stdio
pour les clients distants (AVANCÉ)
--cmdserver <MODE>
pour les clients distants (AVANCÉ)
-t,--templates <TEMPLATE>
modèles web à utiliser
--style <STYLE>
style de modèle à utiliser
-6, --ipv6
utiliser IPv6 au lieu d'IPv4
--certificate <FICHIER>
fichier de certificat SSL
--print-url
démarrer et afficher uniquement l'URL
-S, --subrepos
récursivement dans les sous-dépôts

[+] option marquée peut être spécifiée plusieurs fois
