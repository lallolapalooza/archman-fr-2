NOM

hg add - ajouter les fichiers spécifiés lors du prochain commit

SYNOPIS

hg add [OPTION]... [FICHIER]...

DESCRIPTION

Planifie les fichiers à contrôler et à ajouter au dépôt.

Les fichiers seront ajoutés au dépôt lors du prochain commit. Pour annuler un ajout avant cela, voir hg forget.

Si aucun nom n'est donné, tous les fichiers sont ajoutés au dépôt (sauf ceux correspondant à .hgignore).

Exemples :

  • Les nouveaux fichiers (inconnus) sont ajoutés automatiquement par hg add : 
    $ ls
foo.c
$ hg status
? foo.c
$ hg add
adding foo.c
$ hg status
A foo.c
  • Des fichiers spécifiques à ajouter peuvent être spécifiés : 
    $ ls
bar.c  foo.c
$ hg status
? bar.c
? foo.c
$ hg add bar.c
$ hg status
A bar.c
? foo.c

    Retourne 0 si tous les fichiers sont ajoutés avec succès.

OPTIONS

-I,--include <MOTIF[+]>
inclure les noms correspondant aux motifs donnés
-X,--exclude <MOTIF[+]>
exclure les noms correspondant aux motifs donnés
-S, --subrepos
récursion dans les sous-dépôts
-n, --dry-run
ne pas effectuer d'actions, juste afficher la sortie

[+] option marquée peut être spécifiée plusieurs fois
