    NOM

    highlight — met en surbrillance le code source dans divers langages de programmation

    SYNTAXE

    highlight [OPTION]... [FICHIER]...

    DESCRIPTION

    highlight est un utilitaire de ligne de commande qui prend un ou plusieurs fichiers sources (ou l'entrée standard) et imprime le code source mis en surbrillance sur la sortie standard. La mise en surbrillance est effectuée à l'aide de règles définies dans des fichiers de définition de langage. Ces fichiers de définition se trouvent généralement dans le répertoire /usr/share/highlight/.

    OPTIONS

    -O, --out-format=FORMAT
    Définit le format de sortie. Les formats disponibles sont : ansi (par défaut), html, latex, svg, rtf.
    -S, --syntax=LANGAGE
    Définit explicitement le langage source. Si omis, highlight essaiera de deviner le langage à partir de l'extension du fichier.
    -c, --config=FICHIER
    Charge les paramètres de configuration à partir du FICHIER spécifié.
    -l, --list-languages
    Liste tous les langages pris en charge.
    -V, --version
    Affiche les informations de version.
    -h, --help
    Affiche un message d'aide.

    EXEMPLES

    Mettre en surbrillance un fichier C et imprimer la sortie au format ANSI :

    $ highlight -S c mon_fichier.c

    Mettre en surbrillance un fichier Python et imprimer la sortie au format HTML :

    $ highlight -O html mon_fichier.py

    Lister tous les langages pris en charge :

    $ highlight -l
