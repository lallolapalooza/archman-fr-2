!> plus petit conditionnement possible parmi tous les échelonnages diagonaux

!
>

>

!>          calculés.

>

A

!

S

!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!
>

SCON

D 
!>          SCOND est REAL
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et que AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle par S.

Nom


heequb — Calcule les facteurs de mise à l'échelle pour une matrice hermitienne.






Synopsis


SUBROUTINE HEEQUB( UPLO, N, A, LDA, S, SCOND, AMAX, WORK, INFO )

      CHARACTER * 1 UPLO
      INTEGER N, LDA, INFO
      COMPLEX*16 A( LDA, * )
      DOUBLE PRECISION S( * ), SCOND, AMAX
      COMPLEX*16 WORK( * )







Description Détaillée


HEEQUB calcule les facteurs de mise à l'échelle, S,
    pour une matrice hermitienne A afin que le rapport de la plus grande à la plus
    petite valeur absolue des éléments de chaque ligne soit minimisé. L'objectif
    est d'éviter le débordement ou le sous-débordement lors des calculs
    d'élimination de Gauss lorsque la matrice est utilisée dans une procédure
    numérique.


La mise à l'échelle est effectuée par la transformation diagonale
    :




D = diag(S(1), ..., S(N))


A' = D * A * conj(D)




où conj(D) est la matrice adjointe de D.


La procédure de mise à l'échelle consiste en une série de
    binormalisations.






Documentation des fonctions




UPLO


          UPLO est CHARACTER*1
          Indique si la matrice A est triangulaire supérieure ou inférieure :
          = 'U': A est triangulaire supérieure
          = 'L': A est triangulaire inférieure



N


          N est INTEGER
          L'ordre de la matrice A. N >= 0.



A


          A est COMPLEX*16 array, dimension (LDA,N)
          La matrice hermitienne symétrique N*N dont les facteurs de mise à
          l'échelle doivent être calculés.



LDA


          LDA est INTEGER
          La dimension principale du tableau A. LDA >= max(1,N).



S


          S est DOUBLE PRECISION array, dimension (N)
          Si INFO = 0, S contient les facteurs de mise à l'échelle pour A.



SCOND


          SCOND est DOUBLE PRECISION
          Si INFO = 0, S contient le rapport de la plus petite valeur de S(i) à
          la plus grande valeur de S(i). Si SCOND >= 0.1 et AMAX n'est ni
          trop grand ni trop petit, il n'est pas utile de mettre à l'échelle
          par S.



AMAX


          AMAX est DOUBLE PRECISION
          La plus grande valeur absolue d'un élément de matrice. Si AMAX est
          très proche du dépassement de capacité ou du sous-dépassement,
          la matrice doit être mise à l'échelle.



WORK


          WORK est COMPLEX*16 array, dimension (2*N)



INFO


          INFO est INTEGER
          = 0:  sortie réussie
          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
          > 0:  si INFO = i, le i-ème élément diagonal est non positif.
