Description détaillée

Cette interface offre des moyens de récupérer des informations de topologie sur les périphériques CUDA lors de l'utilisation de l'API du pilote CUDA.

Documentation des fonctions

int hwloc_cuda_get_device_cpuset (hwloc_topology_t topology, CUdevice cudevice, hwloc_cpuset_t set) [inline]

Obtenir l'ensemble CPU des processeurs physiquement proches du périphérique cudevice. Stocker dans set l'ensemble CPU décrivant la localité du périphérique CUDA cudevice.

La topologie topology et le périphérique cudevice doivent correspondre à la machine locale. La détection des périphériques d'E/S et le composant CUDA ne sont pas nécessaires dans la topologie.

La fonction ne retourne que la localité du périphérique. Si plus d'informations sur le périphérique sont nécessaires, les objets du système d'exploitation doivent être utilisés à la place, voir hwloc_cuda_get_device_osdev() et hwloc_cuda_get_device_osdev_by_index().

Cette fonction n'est actuellement implémentée de manière significative que pour Linux ; les autres systèmes obtiendront simplement un ensemble CPU complet.

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si les informations du périphérique n'ont pas pu être trouvées.

hwloc_obj_t hwloc_cuda_get_device_osdev (hwloc_topology_t topology, CUdevice cudevice) [inline]

Obtenir l'objet périphérique OS hwloc correspondant au périphérique CUDA cudevice.

Retourne

L'objet périphérique OS hwloc qui décrit le périphérique CUDA donné cudevice.

NULL si aucun n'a pu être trouvé.

La topologie topology et le périphérique cudevice doivent correspondre à la machine locale. La détection des périphériques d'E/S et le composant CUDA doivent être activés dans la topologie. Sinon, la localité de l'objet peut toujours être trouvée en utilisant hwloc_cuda_get_device_cpuset().

Note

Cette fonction ne peut pas fonctionner si les périphériques PCI sont filtrés.

Le périphérique PCI hwloc correspondant peut être trouvé en examinant le pointeur parent du résultat (sauf si les périphériques PCI sont filtrés).

hwloc_obj_t hwloc_cuda_get_device_osdev_by_index (hwloc_topology_t topology, unsigned idx) [inline]

Obtenir l'objet périphérique OS hwloc correspondant au périphérique CUDA dont l'indice est idx.

Retourne

L'objet périphérique OS hwloc décrivant le périphérique CUDA dont l'indice est idx.

NULL si aucun n'a pu être trouvé.

La topologie topology ne doit pas nécessairement correspondre à la machine actuelle. Par exemple, la topologie peut être une importation XML d'un hôte distant. La détection des périphériques d'E/S et le composant CUDA doivent être activés dans la topologie.

Note

L'objet périphérique PCI correspondant peut être obtenu en examinant l'objet parent du périphérique OS (sauf si les périphériques PCI sont filtrés).

Cette fonction est identique à hwloc_cudart_get_device_osdev_by_index().

int hwloc_cuda_get_device_pci_ids (hwloc_topology_t topology, CUdevice cudevice, int * domain, int * bus, int * dev) [inline]

Retourner les identifiants de domaine, de bus et de périphérique du périphérique CUDA cudevice. Le périphérique cudevice doit correspondre à la machine locale.

Retourne

0 en cas de succès.

-1 en cas d'erreur, par exemple si les informations du périphérique n'ont pas pu être trouvées.

hwloc_obj_t hwloc_cuda_get_device_pcidev (hwloc_topology_t topology, CUdevice cudevice) [inline]

Obtenir l'objet périphérique PCI hwloc correspondant au périphérique CUDA cudevice.

Retourne

L'objet périphérique PCI hwloc décrivant le périphérique CUDA cudevice.

NULL si aucun n'a pu être trouvé.

La topologie topology et le périphérique cudevice doivent correspondre à la machine locale. La détection des périphériques d'E/S doit être activée dans la topologie topology. Le composant CUDA n'est pas nécessaire dans la topologie.
