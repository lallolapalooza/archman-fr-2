integer function izamax (integer n, complex*16, dimension(*) zx, integer incx)

IZAMAX

Objectif :

!>
!>    IZAMAX trouve l'indice du premier élément ayant le maximum |Re(.)| + |Im(.)|
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         nombre d'éléments dans le vecteur d'entrée
!>

ZX

!>          ZX est un tableau COMPLEX*16, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un entier (INTEGER)
!>         pas de stockage entre les éléments de ZX
!>
