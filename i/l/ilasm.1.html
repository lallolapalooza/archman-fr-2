ilasm(1) Manuel des commandes générales ilasm(1)

NOM

ilasm, ilasm2 - Assembleur IL de Mono

SYNTAXE

ilasm [option] [fichiers-source]

ilasm2 [option] [fichiers-source]

DESCRIPTION

ilasm est l'assembleur Mono ILAsm. Vous pouvez passer une ou plusieurs options pour piloter le compilateur, et un ensemble de fichiers sources.

Utilisez ilasm pour générer des assemblies 1.0 et utilisez ilasm2 pour assembler des programmes qui utilisent les fonctionnalités 2.0 (génériques).

L'assembleur Mono ILAsm accepte les options commençant par / ou - pour la plupart des options.

L'assembleur Mono ILAsm génère des images (.exe et .dll) qui contiennent du code octet CIL qui peut être exécuté par tout système qui a implémenté une machine virtuelle Common Language Infrastructure.

OPTIONS

/output:<nom_fichier>
Spécifie le nom du fichier de sortie.
/exe
Génère un fichier exe.
/dll
Génère une bibliothèque.
/scan_only
Analyse uniquement le code IL et affiche les jetons.
/show_tokens
Affiche les jetons lors de leur analyse.
/show_method_def
Affiche les informations de méthode lorsqu'une méthode est définie.
/show_method_ref
Affiche les informations de méthode lorsqu'une méthode est référencée.
/key:CLÉFICHIER
Signature (strongname) l'assembly de sortie en utilisant la paire de clés présente dans le fichier de clé de nom fort spécifié (snk). Une paire de clés complète est requise (c'est-à-dire que la signature retardée est effectuée à l'aide d'une directive .publickey dans les sources).
/key:@CONTENEUR
Signature (strongname) l'assembly de sortie en utilisant la paire de clés présente dans le conteneur spécifié.
--about
Affiche des informations sur ilasm.
--version
Affiche la version d'ilasm.
