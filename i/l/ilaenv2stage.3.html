Documentation de la fonction

integer function ilaenv2stage (integer ispec, character*( * ) name, character*( * ) opts, integer n1, integer n2, integer n3, integer n4)

ILAENV2STAGE

Objectif :

!>
!> ILAENV2STAGE est appelé par les routines LAPACK pour choisir les paramètres
!> dépendants du problème pour l'environnement local. Voir ISPEC pour une
!> description des paramètres.
!> Il définit les paramètres dépendants du problème et de la machine utiles
!> pour *_2STAGE et les sous-routines associées.
!>
!> ILAENV2STAGE retourne un entier
!> si ILAENV2STAGE >= 0 : ILAENV2STAGE retourne la valeur du paramètre
!>                       spécifié par ISPEC
!> si ILAENV2STAGE < 0 :  si ILAENV2STAGE = -k, le k-ième argument avait une
!>                       valeur illégale.
!>
!> Cette version fournit un ensemble de paramètres qui devraient donner de
!> bonnes, mais pas optimales, performances sur plusieurs des ordinateurs
!> actuellement disponibles pour les solveurs en 2 étapes. Les utilisateurs
!> sont encouragés à modifier cette sous-routine pour définir les paramètres
!> d'optimisation pour leur machine particulière en utilisant les informations
!> d'option et de taille de problème dans les arguments.
!>
!> Cette routine ne fonctionnera pas correctement si elle est convertie en
!> minuscules. La convertir en majuscules est autorisé.
!>

Paramètres

ISPEC 
!>          ISPEC est un entier
!>          Spécifie le paramètre à retourner comme valeur de
!>          ILAENV2STAGE.
!>          = 1 : le bloc de taille optimal nb pour la réduction en bande
!>
!>          = 2 : le bloc de taille optimal ib pour la routine de mise à jour
!>               des vecteurs singuliers des vecteurs propres
!>
!>          = 3 : la longueur du tableau qui stocke la représentation de
!>               Housholder pour la deuxième étape
!>               Bande vers Triangulaire ou Bidiagonale
!>
!>          = 4 : l'espace de travail nécessaire pour la routine en entrée.
!>
!>          = 5 : Pour une future publication.
!>

NAME

!>          NAME est CHARACTER*(*)
!>          Le nom de la sous-routine appelante, en majuscules ou
!>          en minuscules.
!>

OPTS

!>          OPTS est CHARACTER*(*)
!>          Les options de caractères pour la sous-routine NAME, concaténées
!>          en une seule chaîne de caractères. Par exemple, UPLO = 'U',
!>          TRANS = 'T', et DIAG = 'N' pour une routine triangulaire seraient
!>          spécifiés comme OPTS = 'UTN'.
!>

N1

!>          N1 est un entier
!>

N2

!>          N2 est un entier
!>

N3

!>          N3 est un entier
!>

N4

!>          N4 est un entier
!>          Dimensions du problème pour la sous-routine NAME ; elles ne sont
!>          pas toutes nécessairement requises.
!>

Détails supplémentaires :

!>
!>  Les conventions suivantes ont été utilisées lors de l'appel à ILAENV2STAGE
!> depuis les routines LAPACK :
!>  1)  OPTS est une concaténation de toutes les options de caractères pour
!>      la sous-routine NAME, dans le même ordre qu'elles apparaissent dans
!>      la liste des arguments pour NAME, même si elles ne sont pas utilisées
!>      pour déterminer la valeur du paramètre spécifié par ISPEC.
!>  2)  Les dimensions du problème N1, N2, N3, N4 sont spécifiées dans l'ordre
!>      où elles apparaissent dans la liste des arguments pour NAME. N1 est
!>      utilisé en premier, N2 ensuite, et ainsi de suite, et les dimensions
!>      du problème non utilisées sont passées avec la valeur -1.
!>  3)  La valeur du paramètre retournée par ILAENV2STAGE est vérifiée pour
!>      sa validité dans la sous-routine appelante.
!>
!>
