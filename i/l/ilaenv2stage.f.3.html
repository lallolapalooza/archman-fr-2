integer function ilaenv2stage (integer ispec, character*( * ) name, character*( * ) opts, integer n1, integer n2, integer n3, integer n4)

ILAENV2STAGE

Objectif :

!>
!> ILAENV2STAGE est appelé depuis les routines LAPACK pour choisir des paramètres dépendants du problème
!> pour l'environnement local. Voir ISPEC pour une description des
!> paramètres.
!> Il définit des paramètres dépendants du problème et de la machine utiles pour *_2STAGE et
!> les sous-programmes associés.
!>
!> ILAENV2STAGE retourne un entier (INTEGER)
!> si ILAENV2STAGE >= 0 : ILAENV2STAGE retourne la valeur du paramètre
!>                       spécifié par ISPEC
!> si ILAENV2STAGE < 0 :  si ILAENV2STAGE = -k, le k-ième argument avait une valeur illégale.
!>
!> Cette version fournit un ensemble de paramètres qui devraient donner de bonnes,
!> mais pas optimales, performances sur de nombreux ordinateurs actuellement disponibles
!> pour les solveurs à 2 étages. Les utilisateurs sont encouragés à modifier cette
!> sous-routine pour définir les paramètres d'optimisation pour leur machine particulière en utilisant
!> les informations d'options et de taille de problème dans les arguments.
!>
!> Cette routine ne fonctionnera pas correctement si elle est convertie entièrement en minuscules.
!> La conversion en majuscules est autorisée.
!>

Paramètres

ISPEC 
!>          ISPEC est un entier (INTEGER)
!>          Spécifie le paramètre à retourner comme valeur de
!>          ILAENV2STAGE.
!>          = 1 : le blocsize optimal nb pour la réduction en BAND
!>
!>          = 2 : le blocsize optimal ib pour la sous-routine de mise à jour
!>               des vecteurs propres/singuliers
!>
!>          = 3 : La longueur du tableau qui stocke la représentation de Householder
!>               pour la seconde étape
!>               Bande vers Triangulaire ou Bidiagonale
!>
!>          = 4 : L'espace de travail nécessaire pour la routine en entrée.
!>
!>          = 5 : Pour une future version.
!>

NAME

!>          NAME est une chaîne de caractères (CHARACTER*(*))
!>          Le nom de la sous-routine appelante, en majuscules ou
!>          en minuscules.
!>

OPTS

!>          OPTS est une chaîne de caractères (CHARACTER*(*))
!>          Les options de caractères pour la sous-routine NAME, concaténées
!>          en une seule chaîne de caractères. Par exemple, UPLO = 'U',
!>          TRANS = 'T', et DIAG = 'N' pour une routine triangulaire seraient
!>          spécifiées comme OPTS = 'UTN'.
!>

N1

!>          N1 est un entier (INTEGER)
!>

N2

!>          N2 est un entier (INTEGER)
!>

N3

!>          N3 est un entier (INTEGER)
!>

N4

!>          N4 est un entier (INTEGER)
!>          Dimensions du problème pour la sous-routine NAME ; elles ne sont pas
!>          toutes nécessaires.
!>

Détails supplémentaires :

!>
!>  Les conventions suivantes ont été utilisées lors de l'appel à ILAENV2STAGE
!> depuis les routines LAPACK :
!>  1)  OPTS est une concaténation de toutes les options de caractères de la
!>      sous-routine NAME, dans le même ordre qu'elles apparaissent dans la
!>      liste d'arguments pour NAME, même si elles ne sont pas utilisées pour déterminer
!>      la valeur du paramètre spécifié par ISPEC.
!>  2)  Les dimensions du problème N1, N2, N3, N4 sont spécifiées dans l'ordre
!>      où elles apparaissent dans la liste d'arguments pour NAME.  N1 est utilisé
!>      en premier, N2 ensuite, et ainsi de suite, et les dimensions du problème inutilisées
!>      reçoivent la valeur -1.
!>  3)  La valeur du paramètre retournée par ILAENV2STAGE est vérifiée pour sa validité dans
!>      la sous-routine appelante.
!>
!>
