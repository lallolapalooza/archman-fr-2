sous-routine ilaver (integer vers_major, integer vers_minor, integer vers_patch)

ILAVER retourne la version de LAPACK.

Objectif :

!>
!>  Cette sous-routine retourne la version de LAPACK.
!>

Paramètres

VERS_MAJOR VERS_MAJOR est un INTEGER, retourne la version majeure de lapack
VERS_MINOR VERS_MINOR est un INTEGER, retourne la version mineure de lapack par rapport à la version majeure
VERS_PATCH VERS_PATCH est un INTEGER, retourne la version de correctif de lapack par rapport à la version mineure
