ilmid(1) Manuel des commandes générales ilmid(1)

NOM

ilmid - Daemon de l'interface de gestion locale intégrée

SYNTAXE

ilmid [ -b ] [ -d ] [ -v ] [ -l logfile ] [ -x ] [ -q qos ] [ -i local_ip ] [ -u uni ] <interface>

PARAMETRES

-b
Met le processus en arrière-plan.
-d
Active la sortie de débogage.
-v
Verbeux.
-l logfile
Définit l'emplacement du fichier journal.
-x
Pas de liaisons var ?
-q qos
Définit les paramètres qos à utiliser sur le VC ilmi.
-i local_ip
l'adresse qui doit être utilisée par le commutateur pour la gestion du réseau.
-u uni
version uni. Peut être 3.0, 3.1 ou 4.0.

DESCRIPTION

ilmid implémente SNMP sur un PVC ATM. Il est utilisé pour négocier les paramètres de fonctionnement avec un commutateur.
