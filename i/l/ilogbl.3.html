ilogbl(3) Manuel des fonctions de bibliothèque ilogbl(3)

NOM

ilogb, ilogbf, ilogbl - obtenir l'exposant entier d'une valeur à virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
int ilogb(double x);
int ilogbf(float x);
int ilogbl(long double x);
Exigences des macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

ilogb():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

ilogbf(), ilogbl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent la partie exposant de leur argument sous forme d'entier signé. Lorsqu'aucun erreur ne survient, ces fonctions sont équivalentes aux fonctions logb(3) correspondantes, converties en int.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent l'exposant de x, sous forme d'entier signé.

Si x est zéro, alors une erreur de domaine se produit, et les fonctions retournent FP_ILOGB0.

Si x est un NaN, alors une erreur de domaine se produit, et les fonctions retournent FP_ILOGBNAN.

Si x est l'infini négatif ou l'infini positif, alors une erreur de domaine se produit, et les fonctions retournent INT_MAX.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de domaine : x est 0 ou un NaN
Une exception de virgule flottante invalide (FE_INVALID) est levée, et errno est défini à EDOM (mais voir BUGS).
Erreur de domaine : x est un infini
Une exception de virgule flottante invalide (FE_INVALID) est levée, et errno est défini à EDOM (mais voir BUGS).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ilogb (), ilogbf (), ilogbl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

BOGUES

Avant glibc 2.16, les bogues suivants existaient dans l'implémentation de glibc de ces fonctions :

•
Le cas d'erreur de domaine où x est 0 ou un NaN ne provoquait pas la définition de errno ou (sur certaines architectures) le déclenchement d'une exception de virgule flottante.
•
Le cas d'erreur de domaine où x est un infini ne provoquait pas la définition de errno ou le déclenchement d'une exception de virgule flottante.

VOIR AUSSI

log(3), logb(3), significand(3)
