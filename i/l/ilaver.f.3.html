Paramètres

VERS_MAJOR VERS_MAJOR est un ENTIER retournant la version majeure de LAPACK
VERS_MINOR VERS_MINOR est un ENTIER retournant la version mineure de LAPACK depuis la version majeure
VERS_PATCH VERS_PATCH est un ENTIER retournant la version de correctif de LAPACK depuis la version mineure
