NOM

isql, iusql - outils de ligne de commande SQL interactif de unixODBC

SYNOPSIS

isql DSN [USER [PASSWORD]] [options]

iusql DSN [USER [PASSWORD]] [options]

iusql "ConnectionString" [options]

DESCRIPTION

isql et iusql sont des outils de ligne de commande permettant aux utilisateurs d'exécuter du SQL de manière interactive ou par lots.

Les outils fournissent plusieurs fonctionnalités utiles, y compris une option pour générer une sortie enveloppée dans un tableau HTML.

iusql est identique à isql mais inclut une prise en charge intégrée d'Unicode. Certaines sources de données ne fonctionnent qu'avec iusql. Une différence importante entre les deux outils est que isql se connecte en utilisant SQLConnect et iusql se connecte en utilisant SQLDriverConnect.

ARGUMENTS

DSN
Le nom de la source de données (DSN) utilisé pour se connecter à la base de données SQL. unixODBC recherche le DSN spécifié dans /etc/odbc.ini et $HOME/.odbc.ini, ce dernier ayant la priorité.

Lors de la recherche dans les fichiers de configuration, unixODBC recherche un nom simple. Si le DSN commence par un point-virgule, il est traité comme une chaîne de connexion. La chaîne de connexion peut contenir un DSN et/ou d'autres paramètres séparés par des points-virgules.

USER
Spécifie l'utilisateur ou le rôle de base de données sous lequel la connexion doit être établie.

Ce paramètre remplace tout UID spécifié dans les fichiers de configuration de la source de données.

PASSWORD
Mot de passe requis pour accéder à la base de données pour l' USERspécifié.

Ce paramètre remplace tout PASSWORD spécifié dans les fichiers de configuration de la source de données.

Lors de l'utilisation de iusql, les mots de passe contenant des points-virgules doivent être échappés avec des accolades (crochets) et terminés par un point-virgule. Consultez la section Exemples ci-dessous pour la syntaxe.

"ConnectionString"
Une chaîne de connexion commençant par DSN=, DRIVER= ou FILEDSN= sera passée inchangée à SQLDriverConnect. Cette option permet d'utiliser une syntaxe plus complexe dans une chaîne de connexion que ce qui serait possible en utilisant uniquement DSN, UID et PWD.

Elle permet également (et c'était la raison principale de son inclusion) aux mots de passe de contenir des points-virgules sans avoir à ajouter de syntaxe d'échappement complexe au code existant.

OPTIONS

-b
Exécute 'isql' en mode lot non interactif. Dans ce mode, 'isql' traite l'entrée standard, en attendant une commande SQL par ligne.
-dDELIMITER
Délimite les colonnes avec le délimiteurspécifié.
-xHEX
Délimite les colonnes avec le caractère représenté en hexadécimal par HEX. Le code hexadécimal doit être au format 0xNN (par exemple 0x09 pour le caractère TAB).
-w
Formate le résultat sous forme de tableau HTML.
-c
Affiche les noms des colonnes sur la première ligne. Cette option ne peut être utilisée qu'avec les options -d ou -x .
-mNUM
Limite la largeur d'affichage de la colonne à NUM caractères.
-lLOCALE
Définit la locale de caractères sur LOCALE.
-q
Enveloppe les champs de caractères entre guillemets doubles.
-3
Utilise les appels de la version 3 d'ODBC.
-n
Traite plusieurs lignes de SQL, terminées par la commande GO.
-e
Utilise SQLExecDirect au lieu de Prepare.
-k
Utilise SQLDriverConnect.
-v
Active le mode verbeux, décrivant complètement toutes les erreurs. Cette option est utile pour le débogage.
-i
Active le mode non verbeux, le texte d'aide disparaît mais ne désactive pas les invites comme l'option -b.
--version
Affiche la version du programme.
-LNUM
Définit le nombre maximum de caractères affichés à partir d'un champ de caractères à NUM. La valeur par défaut est de 300 caractères.

COMMANDES

Cette section décrit brièvement certaines commandes d'exécution isql et iusql .

help

Liste toutes les tables de la base de données.

help table

Liste toutes les colonnes de la table.

help help

Liste toutes les options d'aide.

EXEMPLES

Un DSN simple :
$ iusql WebDB MyID MyPWD -w -b < My.sql

Se connecte au DSN WebDB en tant qu'utilisateur MyID avec le mot de passe MyPWD, puis exécute les commandes du fichier My.sql et renvoie les résultats enveloppés dans un tableau HTML.

Chaque ligne de My.sql ne doit contenir qu'une seule commande SQL, sauf la dernière ligne, qui doit être vide (sauf si l'option -n est spécifiée).

Un DSN dans une chaîne de connexion :

Notez le point-virgule initial de la chaîne de connexion.

$ iusql ";DSN=WebDB" MyID MyPWD -w -b < My.sql

Les options du DSN peuvent être remplacées dans la chaîne de connexion :

$ iusql ";DSN=WebDB;Driver=PostgreSQL ODBC;UID=MyID;PASSWORD=secret;Debug=1;CommLog=1" -v
Un DSN sous forme de chaîne :

Un DSN sous forme de chaîne peut être fourni dans son intégralité, sans aucune référence à un fichier DSN :

$ iusql ";Driver=PostgreSQL Unicode;UID=MyID;PASSWORD=secret" -v
Un mot de passe contenant un point-virgule (iusql) :
$ iusql WebDB MyID '{My;PWD};'
$ iusql 'DSN=WebDB;UID=MyID;PWD={My;PWD};'

DÉPANNAGE

Messages d'erreur cryptiques

Relancez isql ou iusql avec l'indicateur -v pour obtenir plus d'informations sur les erreurs, et/ou activez le mode Trace dans odbcinst.ini.

Définition du pilote manquante

Vérifiez que le nom de pilote spécifié par l'entrée Driver dans la définition de la source de données odbc.ini est présent dans odbcinst.ini et correspond exactement au [nom de section ]d'odbcinst.ini.

Pilote non chargeable ou incompatible

Si le pilote ODBC est correctement spécifié pour la source de données, il est possible que le pilote ne soit pas chargeable. Vérifiez qu'il n'y a pas de confusion entre les pilotes Unicode et ANSI, et vérifiez les chemins des pilotes dans le [nom de section]d'odbcinst.ini.

Sources de données Unicode avec clients ANSI

Certaines sources de données sont uniquement Unicode et nécessitent l'utilisation de iusql. Si isql affiche

  [IM002][unixODBC][Driver Manager]Data source name not found and no default driver specified
  [ISQL]ERROR: Could not SQLConnect
mais que la source de données et le pilote requis sont listés par 
  odbcinst -q -d
et 
  odbcinst -q -s
alors iusql(1) — unixODBC documentation

NAME

iusql

Interactive SQL Interface for unixODBC

SYNOPSIS

iusql [-v] [-c connect-string] [-d dsn-name] [-u user-name] [-p password]

DESCRIPTION

The iusql utility provides an interactive SQL interface to any data source configured within unixODBC. It allows you to connect to a data source, execute SQL statements, and view the results.

ARGUMENTS

-v
Enables verbose mode, showing more detailed information during operation.
-c connect-string
Specifies the connection string to use for connecting to the data source. This can include DSN, UID, PWD, SERVER, DATABASE, etc.
-d dsn-name
Specifies the Data Source Name (DSN) to connect to. This DSN must be defined in your odbc.ini file.
-u user-name
The username to use for connecting to the data source.
-p password
The password for the specified username.

OPTIONS

See ARGUMENTS.

COMMANDS

Once connected, you can enter SQL commands directly. Some common commands include:

SELECT * FROM table_name;
Retrieves all columns and rows from a table.
DESCRIBE table_name;
Shows the structure of a table.
\q
Quits the iusql interface.
\h
Displays help information.

For a full list of commands, type \h at the prompt.

EXAMPLES

Connect to a DSN named 'mydatabase' using username 'myuser':

$ iusql -d mydatabase -u myuser

Connect using a full connection string:

$ iusql -c "DSN=myotherdb;UID=admin;PWD=secret;"

Connect with verbose output enabled:

$ iusql -v -d mydatabase -u myuser

TROUBLESHOOTING

If you encounter connection issues, ensure that your DSN is correctly defined in the odbc.ini file and that the necessary drivers are installed and configured in odbcinst.ini. Use the isql command-line utility for further diagnostics.

FILES

/etc/odbc.ini

Configuration file containing system-wide Data Source Name (DSN) definitions. See odbc.ini(5) for more information.

$HOME/.odbc.ini

Configuration file containing user-specific Data Source Name (DSN) definitions. See odbc.ini(5) for more information.
