iconv_open(3) Manuel des fonctions de bibliothèque iconv_open(3)

NOM

iconv_open - allouer un descripteur pour la conversion de jeu de caractères

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <iconv.h>
iconv_t iconv_open(const char *tocode, const char *fromcode);

DESCRIPTION

La fonction iconv_open() alloue un descripteur de conversion adapté à la conversion de séquences d'octets de l'encodage de caractères fromcode vers l'encodage de caractères tocode.

Les valeurs permises pour fromcode et tocode ainsi que les combinaisons supportées dépendent du système. Pour la bibliothèque C de GNU, les valeurs permises sont listées par la commande iconv --list, et toutes les combinaisons des valeurs listées sont supportées. De plus, la bibliothèque C de GNU et la bibliothèque GNU libiconv supportent les deux suffixes suivants :

//TRANSLIT
Lorsque la chaîne "//TRANSLIT" est ajoutée à tocode, la translittération est activée. Cela signifie que lorsqu'un caractère ne peut pas être représenté dans le jeu de caractères cible, il peut être approximé par un ou plusieurs caractères d'apparence similaire.
//IGNORE
Lorsque la chaîne "//IGNORE" est ajoutée à tocode, les caractères qui ne peuvent pas être représentés dans le jeu de caractères cible seront silencieusement supprimés.

Le descripteur de conversion résultant peut être utilisé avec iconv(3) un nombre quelconque de fois. Il reste valide jusqu'à ce qu'il soit désalloué en utilisant iconv_close(3).

Un descripteur de conversion contient un état de conversion. Après sa création par iconv_open(), l'état est dans l'état initial. L'utilisation de iconv(3) modifie l'état de conversion du descripteur. Pour ramener l'état à l'état initial, utilisez iconv(3) avec NULL comme argument inbuf.

VALEUR DE RETOUR

En cas de succès, iconv_open() retourne un descripteur de conversion fraîchement alloué. En cas d'échec, il retourne (iconv_t) -1 et définit errno pour indiquer l'erreur.

ERREURS

Les erreurs suivantes peuvent survenir, entre autres :

EINVAL
La conversion de fromcode vers tocode n'est pas supportée par l'implémentation.
