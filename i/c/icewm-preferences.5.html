NOM

icewm-preferences - fichier de configuration des préférences d'icewm

SYNOPSIS

$ICEWM_PRIVCFG/preferences
$XDG_CONFIG_HOME/icewm/preferences
$HOME/.icewm/preferences
/usr/etc/icewm/preferences
/usr/share/icewm/preferences

DESCRIPTION

Contient les paramètres généraux comme les chemins, les couleurs et les polices, mais aussi des options pour contrôler le icewm comportement de focus et les applets qui sont démarrés dans la barre des tâches. L'installation de icewm fournit un fichier par défaut preferences , qui peut être copié dans le répertoire de configuration icewm utilisateur et modifié.

MailBoxPath=""
Une liste de chemins de vos boîtes aux lettres séparés par des espaces. Si c'est vide, $MAILPATH ou $MAIL est utilisé à la place.

Chemin vers un fichier mbox. Les boîtes aux lettres distantes sont accessibles en spécifiant une URL en utilisant la syntaxe commune de schéma Internet (RFC 1738):

`scheme://[user[:password]@]server[:port][/path]`.

Les schémas pris en charge sont "pop3", "imap" et "file". Lorsque le schéma est omis, file:// est silencieusement ajouté. Les sous-dossiers IMAP peuvent être accédés en utilisant le composant chemin. Les caractères réservés tels que le *slash* ("/"), l'*arobase* ("@") et le *deux-points* (":") peuvent être spécifiés en utilisant des séquences d'échappement avec un encodage hexadécimal comme %2f pour le slash ou %40 pour l'arobase. Par exemple:

file:///var/spool/mail/captnmark
pop3://markus:%2f%40%3a@maol.ch/
imap://mathias@localhost/INBOX.Maillisten.icewm-user

TimeFormat="%X"
Le format de l'heure de l'horloge. Voir la page man de strftime pour la signification de toutes les options de pourcentage. Il est possible de définir plusieurs horloges pour différentes zones horaires dans un seul TimeFormat. Une nouvelle horloge est définie par le début de la chaîne et par chaque spécification de fuseau horaire qui commence par "TZ=...", suivie d'un espace. Par exemple, TimeFormat="%X TZ=Asia/Aden %T TZ=Asia/Baku %T" définit 3 horloges.
