NOM

icegridregistry - Le serveur d'enregistrement IceGrid.

SYNTAXE

icegridregistry [options] [commande...]

DESCRIPTION

L'enregistrement IceGrid est un dépôt centralisé d'informations, y compris les applications déployées et les objets bien connus. Un enregistrement peut être facultativement colocalisé avec un nœud IceGrid, ce qui permet d'économiser des ressources et peut être pratique pendant le développement et les tests. Le serveur d'enregistrement est implémenté par l'exécutable icegridregistry. La documentation complète d'icegridregistry est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/ice-services/icegrid/icegrid-server-reference/icegridregistry

OPTIONS

-h, --help

Affiche un message d'aide.
-v, --version
Affiche la version d'Ice.
--daemon

Exécute en tant que démon.
--pidfile FICHIER

Écrit l'identifiant du processus dans FICHIER.
--noclose

Ne ferme pas les descripteurs de fichiers ouverts.
--nochdir

Ne change pas le répertoire de travail actuel.
--nowarn

N'imprime pas les avertissements de sécurité.
--readonly

Démarre l'enregistrement maître en mode lecture seule.

TP --initdb-from-replica REPLICA
Initialise la base de données d'enregistrement à partir de la réplique donnée.

VOIR AUSSI

icegridadmin(1), icegriddb(1), icegridnode(1)
