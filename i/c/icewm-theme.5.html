NOM

icewm-theme - Fichier de configuration de thème icewm

SYNOPSIS

$ICEWM_PRIVCFG/theme
$XDG_CONFIG_HOME/icewm/theme
$HOME/.icewm/theme
/usr/etc/icewm/theme
/usr/share/icewm/theme

DESCRIPTION

Le fichier theme contient le nom du thème par défaut. Au démarrage, icewm lit ce fichier pour obtenir le nom du thème, sauf si icewm a été démarré avec l'option --theme. Chaque fois qu'un thème différent est sélectionné dans le Menu icewm, le fichier de thème est écrasé avec le nom du thème sélectionné.

FORMAT

Ce fichier de thème contient le mot-clé "Theme", suivi d'un signe égal, suivi d'une chaîne entre guillemets doubles avec le nom du thème. Le nom du thème est le nom du répertoire du thème, suivi d'une barre oblique, suivi du fichier de thème.

Généralement, le fichier de thème est juste default.theme, mais un thème peut avoir des alternatives. Les alternatives sont de petites modifications d'un thème. Celles-ci sont spécifiées dans leur propre fichier .theme, qui remplace default.theme.

Si aucun fichier de thème n'existe, icewm utilisera le paramètre par défaut "Theme="icedesert/default.theme"".

EXEMPLES

Voici un fichier theme. Les commentaires indiquent que icewm(1) conserve un historique des réglages de thème précédents.

Theme="CrystalBlue/default.theme"
#Theme="icedesert/default.theme"
##Theme="default/default.theme"

FICHIERS

Les emplacements du fichier theme sont les suivants :

$ICEWM_PRIVCFG/theme
$XDG_CONFIG_HOME/icewm/theme
$HOME/.icewm/theme
/usr/etc/icewm/theme
/usr/share/icewm/theme

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les autres sont ignorés.

VOIR AUSSI

icewm(1), icewm-preferences(5), icewm-prefoverride(5).
