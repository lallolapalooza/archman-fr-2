NOM

icebridge - Le démon IceBridge.

SYNTAXE

icebridge [options]

DESCRIPTION

IceBridge agit comme un pont entre un ou plusieurs clients et un serveur. La documentation complète pour IceBridge est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/ice-services/icebridge

OPTIONS

-h, --help

Affiche le message d'aide.
-v, --version
Affiche la version d'Ice.
--daemon

Exécuter en tant que démon.
--pidfile FICHIER

Écrit l'ID du processus dans FICHIER.
--noclose

Ne pas fermer les descripteurs de fichiers ouverts.
--nochdir

Ne pas changer le répertoire de travail courant.
