DESCRIPTIO

N

La fonction iconv() convertit une séquence de caractères dans un encodage de caractères en une séquence de caractères dans un autre encodage de caractères. Le argument cd est un descripteur de conversion, précédemment créé par un appel à iconv_open(3) ; le descripteur de conversion définit les encodages de caractères que iconv() utilise pour la conversion. L' argument inbuf est l'adresse d'une variable qui pointe vers le premier caractère de la séquence d'entrée ; inbytesleft indique le nombre d'octets dans ce tampon. L' argument outbuf est l'adresse d'une variable qui pointe vers le premier octet disponible dans le tampon de sortie ; outbytesleft indique le nombre d'octets disponibles dans le tampon de

sortie.

Le cas principal est lorsque inbuf n'est pas NULL et *inbuf n'est pas NULL. Dans ce cas, la fonction iconv() convertit la séquence multi-octets commençant à *inbuf en une séquence multi-octets commençant à *outbuf. Au plus *inbytesleft octets, commençant à *inbuf, seront lus. Au plus *outbytesleft octets, commençant à *outbuf, seront

écrits.

La fonction iconv() convertit un caractère multi-octets à la fois, et pour chaque conversion de caractère, elle incrémente *inbuf et décrémente *inbytesleft du nombre d'octets d'entrée convertis, elle incrémente *outbuf et décrémente *outbytesleft du nombre d'octets de sortie convertis, et elle met à jour l'état de conversion contenu dans cd. Si l'encodage de caractères de l'entrée est à état, la fonction iconv() peut aussi convertir une séquence d'octets d'entrée en une mise à jour de l'état de conversion sans produire d'octets de sortie ; une telle entrée est appelée une séquence de décalage. La conversion peut s'arrêter pour cinq raisons

:
•
Une séquence multi-octets invalide est rencontrée dans l'entrée. Dans ce cas, elle définit errno à EILSEQ et renvoie (size_t) -1. *inbuf reste pointant vers le début de la séquence multi-octets
invalide.
•
Une séquence multi-octets est rencontrée qui est valide mais qui ne peut pas être traduite vers l'encodage de caractères de la sortie. Cette condition dépend de l'implémentation et du descripteur de conversion. Dans la bibliothèque C GNU et GNU libiconv, si cd a été créé sans le suffixe //TRANSLIT ou //IGNORE, la conversion est stricte : les conversions avec perte produisent cette condition. Si le suffixe //TRANSLIT a été spécifié, la translittération peut éviter cette condition dans certains cas. Dans la bibliothèque C musl, cette condition ne peut pas se produire car une conversion vers '*' est utilisée comme solution de repli. Dans les implémentations de iconv() de FreeBSD, NetBSD et Solaris, cette condition ne peut pas non plus se produire, car une conversion vers '?' est utilisée comme solution de repli. Lorsque cette condition est rencontrée, iconv() définit errno à EILSEQ et renvoie (size_t) -1. *inbuf reste pointant vers le début de la séquence multi-octets non
convertible.
•
La séquence d'octets d'entrée a été entièrement convertie, c'est-à-dire que *inbytesleft est descendu à 0. Dans ce cas, iconv() renvoie le nombre de conversions non réversibles effectuées lors de cet
appel.
•
Une séquence multi-octets incomplète est rencontrée dans l'entrée, et la séquence d'octets d'entrée se termine après elle. Dans ce cas, elle définit errno à EINVAL et renvoie (size_t) -1. *inbuf reste pointant vers le début de la séquence multi-octets
incomplète.
•
Le tampon de sortie n'a plus de place pour le prochain caractère converti. Dans ce cas, elle définit errno à E2BIG et renvoie (size_
t)
-1.

Un cas différent est lorsque inbuf est NULL ou *inbuf est NULL, mais outbuf n'est pas NULL et *outbuf n'est pas NULL. Dans ce cas, la fonction iconv() tente de définir l'état de conversion de cd à l'état initial et de stocker une séquence de décalage correspondante à *outbuf. Au plus *outbytesleft octets, commençant à *outbuf, seront écrits. Si le tampon de sortie n'a plus de place pour cette séquence de réinitialisation, elle définit errno à E2BIG et renvoie (size_t) -1. Sinon, elle incrémente *outbuf et décrémente *outbytesleft du nombre d'octets

écrits.

Un troisième cas est lorsque inbuf est NULL ou *inbuf est NULL, et outbuf est NULL ou *outbuf est NULL. Dans ce cas, la fonction iconv() définit l'état de conversion de

cd à l'état
initial.

NOTE

S

Dans chaque série d'appels à iconv(), le dernier doit être un appel avec inbuf ou *inbuf égal à NULL, afin de vider toute entrée partiellement

convertie.

Bien que inbuf et outbuf soient typés comme char **, cela ne signifie pas que les objets qu'ils pointent peuvent être interprétés comme des chaînes C ou comme des tableaux de caractères : l'interprétation des séquences d'octets de caractères est gérée en interne par les fonctions de conversion. Dans certains encodages, un octet nul peut être une partie valide d'un caractère

multi-octets.

L'appelant de iconv() doit s'assurer que les pointeurs passés à la fonction sont adaptés à l'accès aux caractères dans le jeu de caractères

approprié. Cela inclut de s'assurer d'un alignement correct sur les
plateformes qui ont des restrictions strictes sur l'alignement.
