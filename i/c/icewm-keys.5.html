NOM

icewm-keys - fichier de configuration des touches d'icewm

SYNOPSIS

$ICEWM_PRIVCFG/keys
$XDG_CONFIG_HOME/icewm/keys
$HOME/.icewm/keys
/usr/etc/icewm/keys
/usr/share/icewm/keys

DESCRIPTION

Le fichier « keys » définit des raccourcis clavier globaux pour lancer des applications. Un raccourci clavier comporte trois parties : le mot key, une chaîne entre guillemets doubles contenant une combinaison de touches X11 et un programme avec ses arguments. Elles sont séparées par un ou plusieurs espaces. Les lignes vides sont autorisées. Les lignes de commentaire commencent par un dièse.

Par exemple, ce qui suit définit un raccourci pour redémarrer icewm:

key "Ctrl+Shift+r"      icesh restart

Consultez la sortie de « xmodmap -pk » pour obtenir la liste des nombreux noms de frappes que vous pouvez utiliser dans les définitions de touches d'icewm. Depuis la version 3.4.0 d'IceWM, les raccourcis peuvent être définis non seulement par leur nom de frappe, mais aussi par leur étiquette de touche. De plus, la touche avec majuscule est désormais également définissable. Par exemple, la touche portant + et = peut être liée de l'une des quatre manières suivantes, qui sont identiques :

key "Ctrl+Shift+equal"  xterm
key "Ctrl+Shift+="      xterm
key "Ctrl+plus"         xterm
key "Ctrl++"            xterm

Pour lier la souris, utilisez « Pointer_Button1 » pour le bouton 1, et ainsi de suite. Cela ne fonctionne que lorsque la souris se trouve sur la fenêtre racine. Voir les exemples ci-dessous.

Parfois, vous voudrez peut-être lancer une application une seule fois. Pour cela, utilisez le mot-clé « runonce » , qui accepte un argument de ressource supplémentaire.

La commande « icesh keys » indique à icewm de recharger ce fichier.

FORMAT

La syntaxe du fichier keys est la suivante :

key "key_combination" program options

Où,

key
Le mot key commence la définition d'un raccourci clavier.
key_combination
Une combinaison de modificateurs et d'une touche, comme « Ctrl+Alt+Delete ». Les modificateurs valides sont Alt, AltGr, Ctrl, Hyper, Meta, Shift, Super. Chaque modificateur doit être suivi d'un seul signe plus. La touche est soit un nom de frappe, soit une étiquette de touche. Au lieu d'une touche, les boutons du pointeur de la souris peuvent être spécifiés par « Pointer_Button1 » et au-delà, comme « Shift+Pointer_Button3 ».
program options
program est le nom de l'exécutable ou son chemin. Il peut commencer par un tilde ou une variable d'environnement, qui sera développée. Les options sont passées en arguments au programme.
runonce
Est une alternative à key. Sa syntaxe est :
runonce "hotkey" "wmclass" program options

Ici, wmclass est le nom et/ou la classe de la ressource. La classe doit être préfixée par un point. Le programme n'est exécuté que si aucune autre fenêtre d'application avec la même wmclass n'existe. IceWM ignore les événements de répétition de touche pour ce raccourci.

switchkey
Est une alternative à key. Dans ce cas, le programme doit imprimer sur la sortie standard la définition d'un icewm-menu(1)dynamique. Ce menu sera présenté sous forme de menu contextuel.

EXEMPLES

Voici l'exemple de fichier keys fourni avec icewm(1):

# Ceci est un exemple de fichier de définition des raccourcis d'IceWM.
#
# La liste de tous les symboles de clavier valides se trouve dans
# /usr/include/X11/keysymdef.h, XF86keysym.h, ...
# Omettez les préfixes XK_ et remplacez les préfixes XF86XK_ par XF86.
# Les modificateurs valides sont Alt, AltGr, Ctrl, Shift, Meta, Super, Hyper.
#
key "Alt+Ctrl+t" xterm
key "Alt+Ctrl+b" xdg-open about:blank
key "Alt+Ctrl+s" xdg-open https://www.google.com
key "Super+KP_Subtract" amixer sset PCM 5%-
key "Super+KP_Add" amixer sset PCM 5%+
# Raccourcis de « touches multimédia » pour XFree86. Rassemblez les
# keycodes de vos touches de fonctions avancées en observant la
# sortie de la commande xev tout en appuyant sur ces touches
# et mappez ces symboles à l'aide de xmodmap.
key "XF86AudioLowerVolume" amixer sset PCM 5%-
key "XF86AudioRaiseVolume" amixer sset PCM 5%+
key "XF86AudioMute" amixer sset PCM 0%
key "XF86HomePage" xdg-open about:blank
key "XF86Search" xdg-open https://www.google.com
key "XF86Eject" eject
# afficher et sélectionner les configurations de configuration des moniteurs
switchkey "Super+p" icewm-menu-xrandr
# afficher et sélectionner parmi tous les terminaux
switchkey "Super+q"     icesh -Z switchmenu

Ce qui suit montre comment ajouter des liaisons aux boutons de la souris sur la fenêtre racine pour changer de bureau de travail en faisant défiler la molette de la souris sur le bureau :

key "Pointer_Button4"   icesh goto prev
key "Pointer_Button5"   icesh goto next

Voici des liaisons de touches pour des opérations de pavage de fenêtre unique afin de remplacer les liaisons KeyWinArrange du fichier preferences :

key "Ctrl+Alt+KP_Home"  icesh -f sizeto 49% 49% top left
key "Ctrl+Alt+KP_Up"    icesh -f sizeto 100% 49% top left
key "Ctrl+Alt+KP_Prior" icesh -f sizeto 49% 49% top right
key "Ctrl+Alt+KP_Right" icesh -f sizeto 49% 100% top right
key "Ctrl+Alt+KP_Next"  icesh -f sizeto 49% 49% bottom right
key "Ctrl+Alt+KP_Down"  icesh -f sizeto 100% 49% bottom left
key "Ctrl+Alt+KP_End"   icesh -f sizeto 49% 49% bottom left
key "Ctrl+Alt+KP_Left"  icesh -f sizeto 49% 100% top left
key "Ctrl+Alt+KP_Begin" icesh -f sizeto 49% 49% center

FICHIERS

Les emplacements du fichier keys sont les suivants :

$ICEWM_PRIVCFG/keys
$XDG_CONFIG_HOME/icewm/keys
$HOME/.icewm/keys
/usr/etc/icewm/keys
/usr/share/icewm/keys

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les suivants sont ignorés.
