DESCRIPTIO

N

icu-config simplifie la tâche de compilation et de liaison avec ICU par rapport à la configuration manuelle des fichiers Makefile de l'utilisateur ou équivalent. Comme icu-config est un script exécutable, il résout également le problème de localisation de

s bibliothèques et des en-têtes d'ICU en
permettant au PATH du système de le localiser.

EXEMPLE

S

icu-config peut être utilisé sans fichier Makefile. La ligne de commande suivante est suffisante pour compiler un programme C++ à fichier unique avec ICU. (Par exemple, icu/source/samples/prop

s/props.cpp)
`icu-config --cxx --cxxflags --cppflags --ldflags` -o props props.
cpp

Plus généralement, icu-config sera appelé depuis un fichier Makefile et utilisé pour définir des variables. L'exemple suivant compile également l'exemple props

.
CC=$(shell icu-config --cc)

CXX=$(shell icu-config

--cxx)

CPPFLAGS=$(shell icu-config

--cppflags)

CXXFLAGS=$(shell icu-config

--cxxflags)

LDFLAGS =$(shell icu-config

--ldflags)

all:

props

props.

o: pro
ps.cpp

make(1) utilisera a

utomatiquement les v
ariables ci-dessus.

OPTION

S
--bind
ir
Affiche le chemin du répertoire des binaires (exécutables). Normalement équivalent à 'bin'. Les applications et scripts exécutables par l'utilisateur d'ICU se trouvent
ici.
--
cc
Affiche le compilateur C utilisé. Équivalent à la variable Makefile $(CC)
.
--cfla
gs
Affiche les drapeaux du compilateur C. Équivalent à la variable Makefile $(CFLAGS). N'inclut PAS les directives du préprocesseur telles que le chemin d'inclusion ou les symboles définis. Les exemples incluent les drapeaux de débogage (-g) et
d'optimisation.
--cppfla
gs
Affiche les drapeaux du préprocesseur C. Équivalent à la variable Makefile $(CPPFLAGS). Les exemples sont les chemins d'inclusion -I et les directives de définition
-D.
--cppflags-searchp
ath
Affiche les drapeaux du préprocesseur C, comme ci-dessus mais seulement les chemins de recherche
-I.
--c
xx
Affiche le compilateur C++. Équivalent à la variable Makefile $(CXX)
.
--cxxfla
gs
Affiche les drapeaux du compilateur C++. Équivalent à la variable Makefile $(CXXFLAGS)
.
--detect-pre
fix
Si ICU a été déplacé de son emplacement d'installation, préfixer ce drapeau aux autres appels à icu-config tentera de localiser ICU par rapport à l'emplacement où le script icu-config a été localisé. Peut être utilisé comme dernier recours si l'installation d'ICU a été
endommagée.
--exec-pref
ix
Affiche le préfixe utilisé pour les répertoires des programmes exécutables (tels que bin, sbin, etc). Normalement le même que le
préfixe.
--exis
ts
Le script renverra un statut de succès (0) si ICU semble être installé et localisé correctement, sinon un message d'erreur et un statut non nul seront
affichés.
--help, -?,--usa
ge
Affiche un message d'aide et
d'utilisation.
--icuda
ta
Affiche le nom court du fichier de données ICU. Cela n'inclut aucun suffixe tel que .dat, .dll, .so, .lib, .a, etc. ni aucun préfixe tel que 'lib'. Il peut être sous la forme icudt2
1b
--icudata-install-
dir
Affiche le répertoire où les données packagées d'ICU doivent être installées. Peut être utilisé comme option --install de pkgdata(1)
.
--icudata-mo
de
Affiche le mode pkgdata par défaut d'ICU, tel que dll ou common. Peut être utilisé comme option --mode de pkgdata(1)
.
--icudatad
ir
Affiche le chemin vers les données d'archive packagées. (devrait être l'endroit où $ICU_DATA ou le chemin par défaut équivalent pointe.) NE pointera PAS vers le
libdir.
--invo
ke
Si ICU n'est pas installé à un emplacement où le système d'exploitation localisera ses bibliothèques partagées, cette option affichera des commandes pour définir les variables d'environnement appropriées afin de charger les bibliothèques partagées d'ICU. Par exemple, sur de nombreux systèmes, une variable nommée LD_LIBRARY_PATH ou équivalente doit être
définie.
--invoke=pr
og
Identique à l'option --invoke, sauf qu'il inclut les options pour invoquer un programme nommé prog. Si prog est le nom d'un outil ICU, tel que genrb(1), alors icu-config inclura également le chemin complet vers cet
outil.
--ldfla
gs
Affiche tous les drapeaux qui doivent être passés au lieur. Ceux-ci peuvent inclure -L pour les chemins de recherche de bibliothèques, et -l pour inclure les bibliothèques ICU. Par défaut, cette option tentera de lier les bibliothèques "common" (libicuuc) et "i18n" (libicui18n), ainsi que la bibliothèque de données. Si des bibliothèques supplémentaires sont nécessaires, l'un des deux drapeaux suivants peut être ajouté en conjonction avec celui-ci, par exemple "--ldflags --ldflags-icuio" si la bibliothèque icuio est requise en plus des bibliothèques ICU standard. Équivalent à la variable Makefile $(LDFLAGS)
.
--ldflags-lay
out
Affiche l'option de liaison pour la bibliothèque de disposition
d'ICU.
--ldflags-ic
uio
Affiche l'option de liaison pour ajouter le paquet E/S
d'ICU.
--ldflags-libso
nly
Similaire à --ldflags mais n'inclut que les options
-l.
--ldflags-searchp
ath
Similaire à --ldflags mais n'inclut que les options de chemin de recherche
-L.
--ldflags-sys
tem
Similaire à --ldflags mais n'inclut que les bibliothèques système (telles que pthreads). --mandir Affiche l'emplacement des pages man d'ICU installées. Normalement
(man)
--pref
ix
Affiche le préfixe (répertoire de base) sous lequel l'ICU installé
réside.
--prefix=pref
ix
Définit le préfixe d'ICU à prefix pour le reste de cette ligne de commande. Teste si le nouveau préfixe est
valide.
--sbind
ir
Affiche l'emplacement des binaires système d'ICU, normalement
(sbin)
--shared-data
dir
Affiche l'emplacement des données partagées d'ICU, normalement
(share)
--sysconfd
ir
Affiche l'emplacement des données de configuration système d'ICU, normalement
(etc)
--unicode-vers
ion
Affiche la version de la norme Unicode utilisée par l'ICU
actuel.
--versi
on
Affiche la version actuelle
d'ICU.
--incfi
le
Affiche le chemin 'Makefi
le.inc', adapté pour une
utilisation avec l
'option -O de pkgdata(1).
