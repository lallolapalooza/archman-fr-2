NOM

icegriddb - L'utilitaire d'import/export de base de données IceGrid.

SYNTAXE

icegriddb [options]

DESCRIPTION

L'utilitaire icegriddb est un outil en ligne de commande pour importer et exporter des bases de données IceGrid. La documentation complète d'icegriddb est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/ice-services/icegrid/icegrid-database-utility

OPTIONS

-h, --help

Afficher l'aide du programme.
-v, --version

Afficher la version d'Ice.
--import FICHIER

Importer la base de données depuis le fichier spécifié.
--export FICHIER

Exporter la base de données vers le fichier spécifié.
--dbpath REP

Environnement de base de données source ou cible.
--mapsize VALEUR

Définir la taille de la carte LMDB en Mo (optionnel, importation uniquement).
--server-version VER

Définir la version d'Ice pour les serveurs IceGrid (optionnel, importation uniquement).
-d, --debug

Afficher les messages de débogage.

VOIR AUSSI

icegridadmin(1), icegridnode(1), icegridregistry(1)
