icepatch2calc(1) Manuel des commandes générales icepatch2calc(1)

NOM

icepatch2calc - Outil IcePatch2 pour compresser des fichiers et calculer des sommes de contrôle.

SYNTAXE

icepatch2calc [options] répertoire_données [fichier...]

DESCRIPTION

Outil IcePatch2 pour compresser des fichiers et calculer des sommes de contrôle. La documentation complète pour icepatch2calc est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/ice-services/icepatch2/using-icepatch2calc

OPTIONS

-h, --help

Affiche un message d'aide.
-v, --version
Affiche la version d'Ice.
-z, --compress

Normalement, icepatch2calc analyse le répertoire de données et compresse un fichier uniquement s'il n'existe pas de version compressée, ou si la version compressée d'un fichier a une date de modification antérieure à celle de la version non compressée. Si vous spécifiez -z, l'outil ré-analyse et re-compresse l'intégralité du répertoire de données, quelles que soient les horodatages des fichiers. Cette option est utile si vous suspectez que les horodatages du répertoire de données peuvent être incorrects.
-Z, --no-compress

Cette option vous permet de créer un fichier de somme de contrôle côté client. N'utilisez pas cette option lors de la création du fichier de somme de contrôle pour le serveur — cette option sert à créer un fichier IcePatch2.sum côté client pour les mises à jour de logiciels sur les supports de distribution.
-i, --case-insensitive

Cette option interdit les noms de fichiers qui ne diffèrent que par la casse. (Un message d'erreur sera imprimé si icepatch2calc rencontre des fichiers ne différant que par la casse.) Ceci est particulièrement utile pour les serveurs Unix avec des clients Windows, car Windows ne fait pas de distinction de casse pour les noms de fichiers, et par conséquent, de tels fichiers se remplaceraient mutuellement sur le client Windows.
-V, --verbose

Cette option affiche un message de progression pour chaque fichier compressé et pour chaque somme de contrôle calculée.
