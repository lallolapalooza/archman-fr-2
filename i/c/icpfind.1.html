NOM

icpfind - Utiliser des stratégies heuristiques de détection de points de contrôle

SYNTAXE

icpfind [options] -o sortie.pto entrée.pto

DESCRIPTION

icpfind est un outil en ligne de commande pour utiliser les différents détecteurs de points de contrôle et stratégies heuristiques de détecteurs de points de contrôle définis dans la boîte de dialogue Hugin Paramètres pour les détecteurs de points de contrôle. Il n'introduit pas de nouvelle fonctionnalité, il permet d'exécuter les différents détecteurs de points de contrôle depuis la ligne de commande et pas seulement dans l'interface graphique.

OPTIONS

-o, --output=fichier.pto
Fichier Hugin PTO de sortie. Obligatoire.
-s, --setting=NOMBRE
Paramètre à utiliser tel que défini par l'ordre dans les Préférences de l'interface graphique Hugin, attend un entier. Le premier paramètre dans les Préférences est le numéro 0, le suivant est 1, et ainsi de suite. S'il n'est pas défini, le paramètre défini par défaut dans les Préférences de Hugin est utilisé.
-m, --matches=NOMBRE
Nombre de points de contrôle par paire de photos.
-h, --help
Affiche l'aide.
