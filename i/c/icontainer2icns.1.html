ICONTAINER2ICNS(1) Commandes utilisateur ICONTAINER2ICNS(1)

NOM

icontainer2icns - extraire les fichiers icns des icontainers

SYNTAXE

icontainer2icns fichier.icontainer

DESCRIPTION

icontainer2icns extrait les fichiers icns des icontainers.

EXEMPLES

icontainer2icns archive.icontainer # Extrait tous les icns trouvés dans l'archive
