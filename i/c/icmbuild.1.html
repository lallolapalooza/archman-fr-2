ICM-DE

P

Les dépendances entre classes sont gérées par le programme de support d'icmake nommé icm-dep. Il peut être appelé depuis icmake en spécifiant l'option -d. Toutes les options et arguments suivant -d sont transmis à icm-dep

.

Le programme icm-dep est automatiquement appelé par icmbuild pour gérer les dépendances entre classes. Consultez la page de manuel icmake(1), section ICM-DEP pour une description du programme icm-dep

.

Par défaut icmbuild appelle icmake -d -V go: icm_dep est appelé pour effectuer ses tâches et pour afficher ses actions sur le flux de sortie standard. En spécifiant un paramètre #define ICM_DEP dans le fichier icmconf, cette valeur par défaut peut être remplacée (cf. icmcon

f(7
)).
