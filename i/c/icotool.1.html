DESCRIPTIO

N

Cette page de manuel documente la commande icotool

.

Le programme icotool convertit et crée des fichiers d'icônes (.ico) et de curseurs (.cur). Pour le moment, les icônes ne peuvent être créées qu'à partir de fichiers PNG et extraites dans des fichiers PNG. Cela est fait en utilisant

libpng.

Les fichiers d'icônes et de curseurs sont principalement utilisés sur la plateforme Microsoft Windows(R). Chaque fichier d'icône ou de curseur peut contenir plusieurs images de différentes résolutions et avec un nombre de couleurs différent. Les fichiers de curseurs diffèrent des fichiers d'icônes en ce qu'ils contiennent également des informations sur le point chaud (hotspot) de chaque

image.

Les versions récentes de l'Internet Explorer de Microsoft utilisent des icônes pour les petits logotypes de sites. Le navigateur récupère un fichier appelé favicon.ico depuis un site web et utilise les images de ce fichier pour représenter le site dans les menus et les listes de sites. (Ce fichier est placé dans le répertoire racine du site web, comme tout autre fichier.) Des navigateurs comme Galeon ont copié ce comportement et récupèrent désormais aussi les fichiers .ico pour les utiliser comme logotypes de

sites.

Comme chaque fichier d'icône ou de curseur peut contenir plusieurs images de différentes dimensions et de di

fférentes profondeurs de couleurs, une conversion peut entraîner la création de plusieurs fichiers PNG.
De même, plusieurs fichiers PNG peuvent être spécifiés lors de la création d'un fichier d'icône/de curseur.

OPTION

S

Ces programmes suivent la syntaxe de ligne de commande GNU habituelle, avec les options longues commençant par deux tirets (`-')

.
-x,
--extract
Cette option indique à icotool que les images de tous les fichiers icône/curseur donnés sur la ligne de commande doivent être extraites. Les options de filtrage (voir ci-dessous) peuvent être utilisées pour contrôler quelles images seront
extraites.
-l,
--list
Cette option indique à icotool que les images de tous les fichiers icône/curseur donnés doivent être listées. La sortie ressemblera à quelque chose comme ceci :


--icon --index=1 --width=16 --height=16 --bit-depth=4 --palette-size=16
--icon --index=2 --width=32 --height=32 --bit-depth=8

--palette-size=
256
-c,
--create
Cette option indique à icotool de créer un fichier icône/curseur en utilisant tous les fichiers PNG donnés sur la ligne de commande, dans l'ordre où ils ont été spécifiés. Le nombre de bits par pixel utilisé dans le fichier icône/curseur dépendra du nombre de couleurs utilisées dans le fichier PNG. (Si l'image PNG a une palette indexée, cela ne signifie pas nécessairement que la même palette sera utilisée dans le fichier icône/curseur créé.
)
-i, --index=
N
Lors de la liste ou de l'extraction des fichiers, cette option indique à icotool de lister ou d'extraire uniquement la Nième image de chaque fichier. La première image a l'index 1.

Cette option n'

a aucun effet en
mode création.
-w, --width=PIXE
LS
Similaire à --index, mais cette option permet de faire correspondre la largeur de l'image. Cette option n'a aucun effet en mode
création.
-h, --height=PIXE
LS
Similaire à --index, mais cette option permet de faire correspondre la hauteur de l'image. Cette option n'a aucun effet en mode
création.
-b, --bit-depth=COMP
TE
Similaire à --index, mais cette option permet de faire correspondre le nombre de bits par pixel de l'image. Les valeurs valides sont 1, 2, 4, 8, 16, 24 et 32.

En mode création, cette option vous permet de spécifier une profondeur de bits minimale pour les images du fichier d'icône. Si vous fournissez l'option une seule fois, elle s'appliquera à tous les fichiers d'entrée. Si vous la spécifiez plusieurs fois, elle s'appliquera à tous les fichiers d'entrée suivant une option particulière ; dans ce cas, vous devriez spécifier une profondeur de bits pour toutes les

images.
-p, --palette-size=PIXE
LS
Similaire à --index, mais cette option permet de faire correspondre le nombre de couleurs dans la palette de l'image. Les images avec 24 ou 32 bits dans les fichiers icône/curseur n'ont pas de palette et auront donc une taille de palette égale à 0.

Cette option n'

a aucun effet en
mode création.
-X, --hotspot-x=COO
RD
Similaire à --index, mais cette option permet de faire correspondre la coordonnée x du point chaud. Cette option n'a d'effet que sur les fichiers de curseurs.

En mode création, cela peut être utilisé pour spécifier la coordonnée x du point chaud. Si vous fournissez l'option une seule fois, el

le s'appliquera à tous les fichiers d'entrée. Si vous la spécifiez plusieurs fois, elle s'appliquera à tous les fichiers d'entr
ée suivant une option particulière ; dans ce cas, vous devriez spécifier une coordonnée de point chaud pour toutes les images.
-Y, --hotspot-y=COO
RD
Similaire à --index, mais cette option permet de faire correspondre la coordonnée y du point chaud. Cette option n'a d'effet que sur les fichiers de curseurs.

En mode création, cela peut être utilisé pour spécifier la coordonnée y du point chaud. Si vous fournissez l'option une seule fois, el

le s'appliquera à tous les fichiers d'entrée. Si vous la spécifiez plusieurs fois, elle s'appliquera à tous les fichiers d'entr
ée suivant une option particulière ; dans ce cas, vous devriez spécifier une coordonnée de point chaud pour toutes les images.
--ic
on
Cette option spécifie que seuls les fichiers d'icônes doivent être listés ou extraits. En mode création, cette option peut être utilisée pour spécifier qu'une icône (plutôt qu'un curseur) doit être créée. (C'est le comportement par défaut en mode création.
)
--curs
or
Cette option spécifie que seuls les fichiers de curseurs doivent être listés ou extraits. En mode création, cela peut être utilisé pour spécifier qu'un curseur (plutôt qu'une icône) doit être
créé.
-t, --alpha-threshold=NIVE
AU
Spécifie le niveau alpha maximal dans l'image PNG pour les portions qui doivent devenir transparentes dans l'icône créée. La valeur par défaut est 127. Cela n'est utilisé que lors de la création de fichiers
d'icônes.
-o, --output=CHE
MIN
En mode extraction, cette option spécifie un répertoire où les fichiers extraits doivent être créés. Si le CHEMIN n'existe pas, on suppose qu'il fait référence à un fichier inexistant. La première image correspondante sera extraite dans le fichier portant ce nom.

En mode création, cette option spécifie le nom du fichier de sortie. Par défaut, les données binaires sont écrites sur la sortie standard (ce qu'icotool refusera si la sortie standard est le terminal)

.

Si le CHEMIN est `-', alors toute la sortie sera imprimée sur la sortie

standard.

Cette option n

'a aucun effet
en mode liste.

--raw=NOMFICHIER

EXEMPLE

S

Lister toutes les images du fichier `demo.ico' :
$ icotool -l demo.ico
--icon --index=1 --width=16 --height=16 --bit-depth=4 --palette-size=16
--icon --index=2 --width=32 --height=32 --bit-depth=4 --palette-size=16
--icon --index=3 --width=48 --height=48 --bit-depth=4 --palette-size=16
--icon --index=4 --width=16 --height=16 --bit-depth=8 --palette-size=256
--icon --index=5 --width=32 --height=32 --bit-depth=8 --palette-size=256
--icon --index=6 --width=48 --height=48 --bit-depth=8 --palette-size=25

6

Lister uniquement les images 16 couleurs dans `demo.ico' :
$ icotool -l --palette-size=16 demo.ico
--icon --index=1 --width=16 --height=16 --bit-depth=4 --palette-size=16
--icon --index=2 --width=32 --height=32 --bit-depth=4 --palette-size=16
--icon --index=3 --width=48 --height=48 --bit-depth=4 --palette-size=1

6

Extraire toutes les images dans le répertoire courant, en nommant les fichiers de destination `demo.ico_I_WxHxD.xpm' :
$ icotool -x -o . demo.ico
$ ls *.png
demo_1_16x16x4.png demo_3_48x48x4.png demo_5_32x32x8.png
demo_2_32x32x4.png demo_4_16x16x8.png demo_6_48x48x8.

png

Extraire toutes les icônes 256 couleurssur les images de tous les fichiers .ico du répertoire courant, en plaçant les images extraites dans `img/'
$ icotool -x -o img/ -p 256 *.

Créer une icône nommée `favicon.ico' avec deux images :
$ icotool -c -o favico
