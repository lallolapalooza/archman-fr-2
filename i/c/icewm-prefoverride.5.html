NOM

icewm-prefoverride - fichier de préférences remplaçant le thème

SYNOPSIS

$ICEWM_PRIVCFG/prefoverride
$XDG_CONFIG_HOME/icewm/prefoverride
$HOME/.icewm/prefoverride
/usr/etc/icewm/prefoverride
/usr/share/icewm/prefoverride

DESCRIPTION

Paramètres qui remplacent les paramètres d'un thème. Certains des préférences de icewm qui contrôlent l'apparence peuvent être définis par le thème. Cependant, les paramètres de ce fichier prefoverride les remplacent. Il est sans danger de laisser ce fichier vide initialement. Notez que ce fichier est destiné aux préférences personnalisables par thème et que quelques paramètres de démarrage de icewm ne peuvent pas y être définis, comme "Splash".

FICHIERS

Les emplacements du fichier prefoverride sont les suivants :

$ICEWM_PRIVCFG/prefoverride
$XDG_CONFIG_HOME/icewm/prefoverride
$HOME/.icewm/prefoverride
/usr/etc/icewm/prefoverride
/usr/share/icewm/prefoverride

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les suivants sont ignorés.

VOIR AUSSI

icewm(1), icewm-preferences(5).
