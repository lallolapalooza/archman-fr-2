NOM

icegridnode - Le serveur de nœud IceGrid.

SYNTAXE

icegridnode [options]

DESCRIPTION

Un nœud IceGrid est un processus qui active, surveille et désactive les processus serveur enregistrés. Vous pouvez exécuter un nombre quelconque de nœuds dans un domaine, mais généralement, il y a un nœud par hôte. Un nœud doit être en cours d'exécution sur chaque hôte sur lequel les serveurs sont activés automatiquement, et les nœuds ne peuvent pas fonctionner sans un registre IceGrid. Le serveur de nœud IceGrid est implémenté par l'exécutable icegridnode. Si vous souhaitez exécuter un registre et un nœud dans un seul processus, icegridnode est l'exécutable que vous devez utiliser. La documentation complète d'icegridnode est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/ice-services/icegrid/icegrid-server-reference/icegridnode

OPTIONS

-h, --help

Affiche le message d'aide.
-v, --version
Affiche la version d'Ice.
--daemon

Exécuter en tant que démon.
--pidfile FICHIER

Écrit l'identifiant du processus dans FICHIER.
--noclose

Ne ferme pas les descripteurs de fichiers ouverts.
--nochdir

Ne change pas le répertoire de travail courant.
--nowarn

N'affiche pas les avertissements de sécurité.
--readonly

Démarre le registre maître colocalisé en mode lecture seule.
--initdb-from-replica REPLICA

Initialise la base de données du registre colocalisé à partir de la réplique spécifiée.
--deploy DESCRIPTEUR [CIBLE1 [CIBLE2 ...]]

Ajoute ou met à jour le descripteur dans le fichier DESCRIPTEUR, avec des cibles optionnelles.
