DESCRIPTIO

N

Le fichier programs est un fichier de configuration de menu généré automatiquement pour les programmes installés. Ce fichier devrait être généré autom

atiquement par xdg_menu, wmconfig (Redhat), menu (Debian), ou icewm-menu-fdo,
peut-être dans le cadre de la séquence de connexion ou de démarrage de X.

FORMA

T

Le format du fichier contient l'une des syntaxes de ligne suivantes

:
prog "titre" icône programme optio
ns
Spécifie un programme à exécuter lorsque l'élément de menu est
sélectionné.
restart "titre" icône programme optio
ns
Spécifie un programme pour remplacer le gestionnaire de fenêtres lorsque l'élément de menu est sélectionné. Cela sert à lancer d'autres gestionnaires de fenêtres depuis icewm(
1).
runonce "titre" icône "[nom][.classe]" programme optio
ns
Spécifie un programme à exécuter lorsque l'élément de menu est sélectionné ; cependant, si une fenêtre avec le nom et la classe spécifiés est présente, le programme ne sera pas
relancé.
menu "titre" icône { # éléments contenus
}
Spécifie un sous-menu. Les lignes qui apparaissent entre les accolades peuvent être n'importe quel élément de menu décrit
ici.
menufile "titre" icône "nomdefichier
"
Spécifie un fichier à partir duquel collecter des éléments de sous-menu (lignes) et les placer à cet endroit du
menu.
menuprog "titre" icône programme optio
ns
Spécifie un programme qui affichera les éléments de sous-menu sur la sortie standard et qui sera collecté et placé dans le sous-menu à cet
endroit.
menuprogreload "titre" icône délai programme optio
ns
Similaire à menuprog, mais après au moins délai secondes, le menu est
régénéré.
include "nomdefichier
"
Lire des entrées supplémentaires à partir du fichier nomdefich

EXEMPLE

S

Voici l'exemple de fichier programs fourni avec icewm(1)

: 
# Ce fichier est destiné à être personnalisé par les distributions.
# (elles devraient le placer dans /etc/X11/icewm)
#
# principalement obsolète, à corriger
menu Éditeurs folder {
    prog vim vim gvim
    prog emacs emacs emacs
    prog Lyx emacs lyx
}
menu "WWW" folder {
    prog Galeon galeon galeon
    prog Arena arena arena
    prog Lynx lynx xterm -e lynx
    prog Links lynx xterm -e links
}
menu "Visionneuses de documents" folder {
    prog "Prévisualiseur DVI" xdvi xdvi
    prog "Ghostview" ghostview gv
}
menu Graphisme folder
{ prog Gimp gimp gimp prog XV xv xv prog XPaint xpaint xpaint prog XFig xfig xfig } menu Jeux folder { prog Xboard xboard xboard prog "Tux Racer" tuxracer tuxracer } menu Système folder { prog "Panneau de contrôle" redhat control-panel } menu Utilitaires folder { prog XPlayCD xplaycd xplaycd prog XMixer xmixer xmixer prog Horloge xclock xclock prog Loupe xmag xmag prog Calculatrice xcalc xcalc prog Palette de couleurs xcolormap xcmap prog Presse-papiers xclipboard xclipboard
prog xkill bomb xkill prog xload xload xload prog xosview xosview xosview separator prog "Économiseur d'écran" xlock xlock -nolock prog "Verrouillage de l'écran" xlock xlock } menu "Gestionnaires de fenêtres" folder { restart icewm - icewm restart metacity - metacity restart wmaker - wmaker restart fluxbox - fluxbox restart blackbox - blackbox restart enlightenment - enlightenment restart fvwm2 - fvwm2 restart fvwm - fvwm restart sawfish - sawfish restart sawfish2 - sawfish2 }
