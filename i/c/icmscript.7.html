Les séquences d'échappement composées d'un x suivi de deux chiffres hexadécimaux représentent le caractère ascii correspondant à la valeur hexadécimale (par ex., ’\x4b’, représentant également ’K’) ; o

L'instruction d'expression
simple.
Des instructions d'expression d'insertion sont définies pour les fonctions fprintf et printf. Les instructions d'expression peuvent commencer par printf << ou fprintf << filename <<. Les valeurs de toutes les expressions suivantes, séparées par des opérateurs << (qui dans ce contexte sont appelés opérateurs d'insertion) sont écrites vers le flux de sortie standard (lors de l'utilisation de printf <<), ou vers le fichier dont le nom est fourni dans la chaîne filename (lors de l'utilisation de fprintf << filename <<). Exemples : 
    printf << "hello" << ’ ’ << "world" << ’\n’;
    fprintf << "out.txt" << "hello" << ’ ’ << "world"
<<
’\n’;
o
L'instruction composée
Des variables peuvent être définies et initialisées à l'intérieur d'instructions composées à des endroits où des instructions d'expression peuvent également être utilisées. La visibilité des variables commence à leurs points de définition
;
o
if ([definition;] condition) statement
La phrase [definition;] est optionnelle. Si elle est utilisée, elle définit un type suivi d'une liste de variables séparées par des virgules, qui peuvent être pourvues d'expressions
d'initialisation.
La phrase condition est requise, et peut définir et initialiser une variable. Par exemple, 
    if (string str = getText())
        process(str);
Dans cet exemple, process n'est pas appelé si getText() retourne une chaîne
vide.
Les variables définies dans les phrases de définition et de condition n'existent ni avant ni après l'instruction if
.
o
if ([definition;] condition) statement1 else statement2
Se comporte comme l'instruction précédente. Si la condition est vraie, statement1 est exécutée ; si la condition est fausse, statement2 est exécutée
;
o
for (init; condition; increment) statement
Des variables (d'un seul type) peuvent être initialisées (et éventuellement définies) dans la section init. La phrase condition peut définir et initialiser une variable. Les sections init, condition et increment peuvent rester vides. Une section condition vide est interprétée comme `toujours vrai'
;
o

À l'intérieur de la condition, une variable peut être définie et
initialisée.
Une instruction complémentaire do ... while() n'est pas disponible. Notez que lorsqu'une variable est définie et initialisée dans la section condition, l'expression d'initialisation est exécutée à chaque itération de l'instruction while. Ainsi l'instruction suivante ne se termine jamais et affiche un flux sans fin de valeurs 10 : 
    while (int x = 10)
        printf(x--,
"\n")

L'UTILISATEUR

En plus de main, des fonctions supplémentaires peuvent être définies. Une fois définies, elles peuvent être appelées. La référence avant pour les variables ou les fonctions n'est pas prise en charge, mais l'appel récursif des fonctions l'est. Comme les déclarations de fonctions ne sont pas prises en charge, la récursion indirecte ne peut pas être

utilisée.

Le surchargement de fonctions (basé sur des paramètres de types différents) est pris en

charge.

Les fonctions définies par l'utilisateur doivent avoir les éléments suivants

:
o
Le type de retour de la fonction, qui doit être void, int, string ou list. Il n'y a pas de type par défaut
;
o
Le nom de la fonction, par exemple, compil
e ;
o
Une liste de paramètres, définissant zéro ou plusieurs paramètres séparés par des virgules. Les paramètres eux-mêmes se composent d'un nom de type (int, string, ou list) suivi de l'identifiant du paramètre. Par exemple, (string outfile, strin
g source) ;
o
Un
corps entouré d'une paire d'accolades ( { et}). Les corps de fonctions peuvent contenir des définitions de variables (éventuellement initialisées à leur définition). Les définitions de variables commencent par un nom de type, suivi d'un ou plusieurs identifiants de variables séparés
par des virgules et
éventuellement initialisés.

Si une variable n'est pas explicitement initialisée, elle est initialisée par défaut

:

les variables int sont initialisées à 0, les variables string sont initialisées à des chaînes vides ( "") etles variables list sont initialisées à des listes vides. Les corps de fonctions peuvent également contenir zéro ou plusieurs instructions (cf. la

section

CONTRÔLE DE FLUX). Notez que les variables peuvent être définies (et éventuellement initialisées) n'importe où à l'intérieur des fonctions où des instructions d'expression peuvent être utilisées, et aussi dans les sections de condition des instructions if, for et while et dans les sections d'initialisation des instructions if et fo

EXEMPL

E

Dans l'exemple suivant, tous les fichiers source C++ du répertoire courant sont compilés sauf si leurs fichiers objets sont plus récents. La fonction main crée une liste de fichiers source et passe ensuite chacun d'eux à une fonction inspect. Cette fonction vérifie si le fichier source est plus récent que son fichier objet, et si oui, elle appelle compile. La fonction compile utilise exec pour appeler le compilateur. Si une compilation échoue, le script s'arrête afin que l'erreur puisse être

corrigée. 
    void compile(string src)
    {                           
        exec("g++ -c " + src);      // compile ’src’
    }
    void inspect(string src)
    {                               // get the obj-file’s name:
                                    // only compile if necessary
        if (src younger change_ext(src, ".o"))
            compile(src);
    }
    int main()
    {                               // find all .cc source files
        list sources = makelist("*.cc");
        for (                       // visit all source files
            int idx = 0, end = listlen(sources); 
                idx != end;
                    ++idx
        )
            inspect(sources[idx]);  // compile if needed
}
