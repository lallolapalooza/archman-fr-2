ICEWM-SESSION(1) Commandes utilisateur ICEWM-SESSION(1)

NOM

icewm-session - Fournisseur de gestionnaire de session X.Org avec IceWM

SYNTAXE

icewm-session [OPTIONS]

DESCRIPTION

icewm-session est une implémentation d'un gestionnaire de session X.Org et peut être lancé à partir d'une configuration de session X11. Il exécute icewm comme gestionnaire de fenêtres par défaut et contrôle le cycle de vie des applications de support associées.

OPTIONS

OPTIONS SPÉCIFIQUES

-c, --config=FICHIER
Laisser IceWM charger les préférences du FICHIER.
-t, --theme=FICHIER
Laisser IceWM charger le thème du FICHIER.
-i, --icewm=FICHIER
Utiliser le FICHIER comme gestionnaire de fenêtres IceWM.
-o, --output=FICHIER
Rediriger toute la sortie vers le FICHIER. Un tilde initial ou une variable d'environnement est développé.
-a, --alpha
Utiliser une visualisation 32 bits pour la translucidité.
-b, --nobg
Ne pas démarrer icewmbg.
-n, --notray
Ne pas démarrer icewmtray. Ceci n'est applicable que si IceWM a été explicitement configuré pour utiliser un processus icewmtray externe.
-s, --sound
Démarrer également icesound.
--replace
Remplacer un gestionnaire de fenêtres existant.

OPTIONS GÉNÉRALES

-d, --display=AFFICHAGE
Utiliser AFFICHAGE pour se connecter au serveur X. Si cette option est manquante, alors AFFICHAGE est lu à partir de la variable d'environnement "DISPLAY".
--sync
Utiliser une communication plus lente en mode synchrone avec le serveur X11.
-h, --help
Donner une liste de toutes les options prises en charge et quitter.
-V, --version
Afficher la version du programme et quitter.
-C, --copying
Afficher les permissions de copie et quitter.

OPTIONS DE DÉBOGAGE

-v, ---valgrind
Laisser "/usr/bin/valgrind" exécuter icewm. Examine en profondeur l'exécution d'icewm.
-g, ---catchsegv
Laisser "/usr/bin/catchsegv" exécuter icewm. Donne une trace d'appels si icewm plante avec un segment fault.

UTILISATION

Au démarrage, icewm-session exécute les étapes suivantes. À partir du fichier env dans le répertoire de configuration, il charge des variables d'environnement supplémentaires, si ce fichier existe. Ensuite, il démarrera icewmbg pour gérer les couleurs et les images d'arrière-plan de la racine. Il peut également démarrer icesound, si cela a été activé lors de la configuration. Ensuite, icewm est démarré.

S'il existe un script exécutable startup dans le répertoire de configuration, il sera exécuté. Il peut contenir des commandes pour initialiser les paramètres X11 avec xset, charger la configuration du clavier, démarrer un gestionnaire de composition comme compton et charger des applications de la barre système.

Lorsque icewm se termine, icewm-session exécute un script shutdown, s'il existe dans le répertoire de configuration. Une fois cela terminé, icewm-session terminera icewm, icewmbg et icesound. Enfin, icewm-session se terminera.

Si le processus icewm plante, icewm-session tentera de le redémarrer. Si deux plantages de ce type se produisent dans un court laps de temps, icewm-session tentera d'afficher une boîte de dialogue en utilisant soit yad, xmessage, kdialog ou zenity. Cette boîte de dialogue présente un choix entre redémarrer icewm, démarrer un terminal ou arrêter l'exécution d' icewm-session.

ENVIRONNEMENT

ICEWM_OPTIONS
Une liste d'options séparées par des espaces qui seront ajoutées à l'appel de ligne de commande d' icewm. Ceci peut être défini dans le fichier env.
