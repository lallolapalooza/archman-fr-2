ICEWM-ENV(5) Normes, environnements et macros ICEWM-ENV(5)

NOM

icewm-env - fichier de configuration de l'environnement icewm

SYNTAXE

$ICEWM_PRIVCFG/env
$XDG_CONFIG_HOME/icewm/env
$HOME/.icewm/env
/usr/etc/icewm/env
/usr/share/icewm/env

DESCRIPTION

icewm-session(1) charge les variables d'environnement supplémentaires depuis le fichier env avant toute autre action. Ces variables sont ensuite propagées à tous les autres processus, y compris icewm(1), via leur environnement.

FORMAT

Chaque ligne est soumise à une expansion shell POSIX par wordexp(3). Les lignes de commentaire commençant par un signe dièse ("#") sont ignorées. icewm-session(1) chargera ces lignes expansées qui contiennent un nom, suivi d'un signe égal, suivi de la valeur (qui peut être vide).

Le mot unset commence une ligne avec les noms à supprimer de l'environnement.

EXEMPLES

# Ceci est un commentaire.
# Et un autre.
XDG_CURRENT_DESKTOP="ICEWM"
XDG_MENU_PREFIX="unexicon-"
START_DATE=`date`
START_FROM=`pwd`

FICHIERS

icewm-session(1) recherche le fichier env dans les emplacements suivants :

$ICEWM_PRIVCFG/env
$XDG_CONFIG_HOME/icewm/env
$HOME/.icewm/env
/usr/etc/icewm/env
/usr/share/icewm/env

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les suivants sont ignorés.

VOIR AUSSI

icewm(1), icewm-session(1), icewm-startup(5).
