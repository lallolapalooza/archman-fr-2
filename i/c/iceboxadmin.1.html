NOM

iceboxadmin - L'utilitaire administratif d'IceBox.

SYNTAXE

iceboxadmin [options] [commande...]

DESCRIPTION

L'utilitaire administratif d'IceBox. La documentation complète pour iceboxadmin est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/icebox/icebox-administration

OPTIONS

-h, --help

Affiche un message d'aide.
-v, --version
Affiche la version d'Ice.

COMMANDES

start SERVICE

Démarre un service.
stop SERVICE

Arrête un service.
shutdown

Arrête le serveur.
