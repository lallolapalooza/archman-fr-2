integer function icamax (integer n, complex, dimension(*) cx, integer incx)

ICAMAX

But :

!>
!>    ICAMAX trouve l'indice du premier élément ayant une valeur maximale |Re(.)| + |Im(.)|
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

CX

!>          CX est un tableau de nombres complexes (COMPLEX array), dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un entier (INTEGER)
!>         espacement de stockage entre les éléments de CX
