ICEWM-TOOLBAR(5) Normes, Environnements et Macros ICEWM-TOOLBAR(5)

NOM

icewm-toolbar - fichier de configuration de la barre d'outils icewm

SYNOPIS

$ICEWM_PRIVCFG/toolbar
$XDG_CONFIG_HOME/icewm/toolbar
$HOME/.icewm/toolbar
/usr/etc/icewm/toolbar
/usr/share/icewm/toolbar

DESCRIPTION

Le fichier toolbar est responsable de la configuration des icônes d'application à lancement rapide qui sont placées sur le panneau de icewm(1). Il contient les noms des applications à lancer rapidement avec des icônes pour la barre des tâches. Chaque ligne non vide et non commentée commence par le mot-clé prog. Après un ou plusieurs espaces suit un nom, qui est affiché dans une info-bulle chaque fois que le curseur de la souris survole l'icône de la barre d'outils. Ce nom peut être une chaîne de caractères entre guillemets doubles. Suit ensuite le nom brut de l'icône à utiliser sans extensions. Cette icône sera affichée dans la barre d'outils. Le dernier composant est une ligne de commande shell qui sera exécutée chaque fois que l'utilisateur appuiera sur l'icône dans la barre d'outils. Par exemple, la ligne suivante dans toolbar créera un bouton avec l'info-bulle "Mozilla Firefox" avec l'icône firefox qui lance firefox(1) lorsqu'il est cliqué :

prog  "Mozilla Firefox"  firefox  /usr/bin/firefox --private-window

FORMAT

Le format du fichier contient l'une des syntaxes de ligne suivantes :

prog "titre" icône programme options

Où,

prog
La chaîne littérale prog.
"titre"
Le titre de l'élément de la barre d'outils, qui apparaîtra comme une info-bulle pour le bouton du programme, encadré de guillemets doubles (""").
icône
L'icône à afficher sur le bouton de la barre d'outils. Peut être spécifiée comme un simple tiret ("-") lorsqu'aucune icône n'est fournie. Lorsque aucune icône n'est fournie, le texte titre sera affiché sur le bouton à la place de l'icône.
programme
Le programme exécutable (chemin complet ou nom d'exécutable) à lancer lorsque le bouton est pressé.
options
Options et arguments passés au programme.

Les lignes commençant par un dièse ("#") sont des lignes de commentaire. Les lignes de commentaire et les lignes vides sont ignorées.

Veuillez noter que tous les mots-clés de icewm-menu(5) sont également autorisés ici.

EXEMPLES

Voici un exemple qui place un certain nombre de boutons de barre d'outils sur le panneau de icewm(1) :

prog "Gestionnaire de fichiers" file-manager.png pcmanfm
prog "Navigateur Web" web-browser.png /usr/lib/firefox/firefox
prog "Terminal" terminal.png roxterm
prog "Éditeur Graphique" text-editor.png gvim -f
prog "Calculatrice" accessories-calculator.png calculator
prog "Exécuter Commande" gtk-execute.png xde-run
prog "Réseau" gtk-network.png pcmanfm ~/Network
prog "Déconnexion" system-log-out.png xde-logout

FICHIERS

Les emplacements du fichier toolbar sont les suivants :

$ICEWM_PRIVCFG/toolbar
$XDG_CONFIG_HOME/icewm/toolbar
$HOME/.icewm/toolbar
/usr/etc/icewm/toolbar
/usr/share/icewm/toolbar

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les autres sont ignorés.
