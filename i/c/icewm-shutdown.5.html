ICEWM-SHUTDOWN(5) Normes, Environnements et Macros ICEWM-SHUTDOWN(5)

NOM

icewm-shutdown - fichier de configuration de fermeture d'icewm

SYNTAXE

$ICEWM_PRIVCFG/shutdown
$XDG_CONFIG_HOME/icewm/shutdown
$HOME/.icewm/shutdown
/usr/etc/icewm/shutdown
/usr/share/icewm/shutdown

DESCRIPTION

Contient les commandes à exécuter lors de la fermeture d'icewm. Il s'agit d'un script exécutable contenant les commandes à exécuter lors de la dernière étape de la terminaison d'icewm. Elles peuvent généralement annuler certains des effets du script startup. Il est exécuté par icewm-session(1) lorsque icewm se termine.

FICHIERS

Les emplacements du fichier shutdown sont les suivants :

$ICEWM_PRIVCFG/shutdown
$XDG_CONFIG_HOME/icewm/shutdown
$HOME/.icewm/shutdown
/usr/etc/icewm/shutdown
/usr/share/icewm/shutdown

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les suivants sont ignorés.

VOIR AUSSI

icewm-session(1), icewm-startup(5).
