NOM

icedtea-web-plugin - permet d'exécuter des applets Java dans votre navigateur préféré

SYNTAXE

icedtea-web-plugin fonctionne dans votre navigateur, une fois que votre navigateur connaît ces fichiers.

IcedTeaPlugin.so doit être placé, ou lié, dans des répertoires spécifiques. Voir http://icedtea.classpath.org/wiki/IcedTea-Web#Plugin

Les navigateurs compatibles Mozilla comme Firefox, Midori, Epiphany, Chrome ou Chromium utilisent :

$HOME/.mozilla/plugins
Emplacement de la bibliothèque de plugins pour les besoins de l'utilisateur sur un navigateur compatible Mozilla.
/usr/lib64/mozilla/plugins
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Mozilla, systèmes 64 bits.
/usr/lib/mozilla/plugins
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Mozilla, systèmes 32 bits.

Les navigateurs de la famille Opera comme Opera utilisent :

/usr/lib64/opera/plugins
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Opera, systèmes 64 bits.
/usr/lib/opera/plugins
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Opera, systèmes 32 bits.

Toutes les marques tierces sont la propriété de leurs détenteurs respectifs.

FICHIERS

$HOME/.mozilla/plugins/IcedTeaPlugin.so
Emplacement de la bibliothèque de plugins pour les besoins de l'utilisateur sur un navigateur compatible Mozilla.
$XDG_CACHE_HOME/icedtea-web/cache/recently_used
Informations supplémentaires sur les éléments du cache.
$XDG_CONFIG_HOME/icedtea-web/generated_jnlps
Emplacement où sont stockés les fichiers jnlp générés à partir des pages HTML pour les lanceurs d'applications javaws, les icônes de bureau/menu.
$XDG_RUNTIME_DIR/tmp/icedteaplugin-user-*
Contient les pipes d'entrée et de sortie pour la communication native2java et (si activé) le pipe de débogage.
/usr/lib/mozilla/plugins/IcedTeaPlugin.so
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Mozilla, systèmes 32 bits.
/usr/lib/opera/plugins/IcedTeaPlugin.so
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Opera, systèmes 32 bits.
/usr/lib64/mozilla/plugins/IcedTeaPlugin.so
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Mozilla, systèmes 64 bits.
/usr/lib64/opera/plugins/IcedTeaPlugin.so
Emplacement de la bibliothèque de plugins pour les besoins globaux sur un navigateur compatible Opera, systèmes 64 bits.

Où $XDG_CONFIG_DIR, $XDG_CACHE_DIR et $XDG_RUNTIME_DIR sont définis comme ~/.config, ~/.cache et /tmp ou /var/tmp s'ils ne sont pas définis.

BOGUES

Il n'y a pas de bogues connus. Si vous en rencontrez un, veuillez le signaler à :

http://icedtea.classpath.org/wiki/IcedTea-Web#Filing_bugs
http://icedtea.classpath.org/bugzilla

Veuillez exécuter en mode débogage (commutateur -verbose ou réglage itw-settings ou variable ICEDTEAPLUGIN_DEBUG définie à true) et inclure cette sortie (idéalement de la console Java) avec l'URL du fichier jnlp ou html (ou le fichier jnlp/html ou l'application elle-même) lors du signalement du rapport de bogue.
