NOM

icns2png - convertir les fichiers icns de Mac OS en images png

SYNTAXE

icns2png [-x|-l] [options] [fichier ... ]

DESCRIPTION

icns2png extrait les images des fichiers .icns de Mac et les exporte au format png.

OPTIONS

-l, --list
Lister le contenu d'une ou plusieurs images icns

-x, --extract Extraire une ou plusieurs icônes en images png

-o, --output
Où placer les fichiers extraits. Si non spécifié, les icônes seront extraites au même emplacement que le fichier source.
-d, --depth
Définit la profondeur de pixels des icônes à extraire. (1,4,8,32)
-s, --size
Définit la largeur et la hauteur des icônes à extraire. (16,48,etc) Les tailles 16x12, 16x16, 32x32, 48x48, 128x128, etc. sont également valides.
-h, --help
Affiche ce message d'aide.

-v, --version Affiche les informations de version

EXEMPLES

icns2png -x anicon.icns # Extrait toutes les icônes trouvées dans anicon.icns
icns2png -x -s 48 anicon.icns # Extrait toutes les icônes 32-bit de 48x48
icns2png -x -s 32 -d 1 anicon.icns # Extrait toutes les icônes 1-bit de 32x32
icns2png -l anicon.icns # Liste les icônes contenues dans anicon.icns
