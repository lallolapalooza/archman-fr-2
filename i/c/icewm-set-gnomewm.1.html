NOM

icewm-set-gnomewm - modifier les paramètres GNOME pour utiliser IceWM

SYNTAXE

icewm-set-gnomewm [OPTIONS]

DESCRIPTION

icewm-set-gnomewm est un script d'assistance qui instrumente GNOME pour remplacer son propre gestionnaire de fenêtres par icewm.

OPTIONS

OPTIONS GÉNÉRALES

-h, --help
Affiche un bref énoncé d'utilisation sur la sortie standard et quitte.
-V, --version
Affiche la version du programme sur la sortie standard et quitte.
