ICEWM-MENU(5) Normes, Environnements et Macros ICEWM-MENU(5)

NOM

icewm-menu - fichier de configuration des menus icewm

SYNTAXE

$ICEWM_PRIVCFG/menu
$XDG_CONFIG_HOME/icewm/menu
$HOME/.icewm/menu
/usr/etc/icewm/menu
/usr/share/icewm/menu

DESCRIPTION

Le fichier menu est responsable de la configuration de la majorité du menu racine et du menu de démarrage de icewm(1).

Un menu qui donne accès aux applications ; généralement personnalisé par l'utilisateur. Le programme icewm-menu-fdo(1) génère un menu par défaut qui contient la plupart des applications de bureau du système. Des programmes similaires sont xdg_menu(1), mmaker(1), xde-menu(1) et xdgmenumaker(1).

FORMAT

Le fichier contient des lignes avec la syntaxe suivante :

prog "titre" icône programme options
Spécifie un programme à exécuter lorsque l'élément de menu est sélectionné.
restart "titre" icône programme options
Spécifie un programme pour remplacer le gestionnaire de fenêtres lorsque l'élément de menu est sélectionné. Ceci sert à lancer d'autres gestionnaires de fenêtres depuis icewm(1).
runonce "titre" icône "[nom][.classe]" programme options
Spécifie un programme à exécuter lorsque l'élément de menu est sélectionné ; cependant, si une fenêtre du nom et de la classe spécifiés est présente, le programme ne sera pas exécuté à nouveau.
menu "titre" icône { # éléments contenus }
Spécifie un sous-menu. Les lignes qui apparaissent entre les accolades peuvent être tout élément de menu décrit ici.
menufile "titre" icône "nom_fichier"
Spécifie un fichier à partir duquel collecter les éléments de sous-menu (lignes) et les placer à cet endroit dans le menu.
menuprog "titre" icône programme options
Spécifie un programme qui affichera les éléments de sous-menu sur la sortie standard, qui seront collectés et placés dans le sous-menu à cet endroit.
menuprogreload "titre" icône délai programme options
Similaire à menuprog, mais après au moins délai secondes, le menu est régénéré.
include "nom_fichier"
Lire des entrées supplémentaires du fichier nom_fichier.
includeprog programme options
Lire des entrées supplémentaires de la sortie de programme options.
separator
Un séparateur pour les éléments de menu.

Où

prog, restart, runonce, menu, menufile, menuprog, menuprogreload, include, includeprog, separator
Ce sont des mots-clés littéraux.
"titre"
C'est la chaîne de titre associée à l'élément de menu qui est affichée dans le menu. Lorsque le titre contient des espaces, le titre doit être entouré de guillemets doubles ("").
icône
Est le nom du fichier d'icône (avec ou sans extension) ou le chemin complet vers un fichier d'icône.
"[nom][.classe]"
nom est le nom de ressource d'une fenêtre lancée par programme et classe est la classe de ressource de la fenêtre. Un seul des nom ou classe doit être spécifié. Ceci est utilisé pour déterminer si le programme est déjà en cours d'exécution et est utilisé avec le mot-clé runonce.
programme options
programme est le nom de l'exécutable ou le chemin complet du fichier exécutable qui sera exécuté en réponse à la sélection de l'élément de menu. Lorsqu'il est utilisé avec le mot-clé menuprog, le programme doit afficher sur la sortie standard le contenu du menu et est utilisé pour les menus dynamiques.

options sont les options et les arguments passés au programme tels quels.

nom_fichier
nom_fichier est le nom du fichier relatif à l'un des répertoires de configuration de icewm(1), ou le chemin complet vers un fichier. Le fichier est utilisé avec le mot-clé menufile et spécifie le fichier à partir duquel lire les éléments de menu supplémentaires.

EXEMPLES

Voici l'exemple de fichier menu fourni avec icewm(1) :

# Ceci est un exemple de fichier de définition de menu pour IceWM.
#
# Placez vos variantes dans /usr/etc/icewm ou dans $HOME/.icewm
# car les modifications apportées à ce fichier seront ignorées lors de la
# (ré)installation d'icewm.
#
prog xterm xterm xterm
prog rxvt xterm rxvt -bg black -cr green -fg white -C -fn 9x15 -sl 500
prog fte fte fte
prog NEdit nedit nedit
prog Mozilla mozilla mozilla
prog XChat xchat xchat
prog Gimp gimp gimp
separator
menuprog "Applications Bureau" folder icewm-menu-fdo
menufile Programmes folder programs
menufile Barre_outils folder toolbar

FICHIERS

Les emplacements du fichier menu sont les suivants :

$ICEWM_PRIVCFG/menu
$XDG_CONFIG_HOME/icewm/menu
$HOME/.icewm/menu
/usr/etc/icewm/menu
/usr/share/icewm/menu

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les autres sont ignorés.
