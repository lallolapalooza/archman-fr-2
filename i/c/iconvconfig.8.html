iconvconfig(8) Manuel de l'administrateur système iconvconfig(8)

NOM

iconvconfig - création d'un cache de configuration de modules iconv

SYNTAXE

iconvconfig [options] [répertoire]...

DESCRIPTION

La fonction iconv(3) utilise en interne des modules gconv pour convertir d'une représentation de caractères vers une autre. Un fichier de configuration est utilisé pour déterminer les modules nécessaires à une conversion. Le chargement et l'analyse d'un tel fichier de configuration ralentiraient les programmes qui utilisent iconv(3), c'est pourquoi un mécanisme de mise en cache est employé.

Le programme iconvconfig lit les fichiers de configuration des modules iconv et écrit un fichier cache de configuration de modules gconv rapide à charger.

En plus des modules gconv fournis par le système, l'utilisateur peut spécifier des répertoires de modules gconv personnalisés avec la variable d'environnement GCONV_PATH. Cependant, la mise en cache de la configuration des modules iconv n'est utilisée que lorsque la variable d'environnement GCONV_PATH n'est pas définie.

OPTIONS

--nostdlib
Ne pas rechercher le répertoire par défaut des modules gconv du système, mais seulement les répertoires fournis en ligne de commande.
--output=fichier_sortie
-o fichier_sortie
Utiliser fichier_sortie pour la sortie au lieu de l'emplacement par défaut du cache système.
--prefix=chemin
Définir le préfixe à ajouter aux chemins du système. Voir FICHIERS, ci-dessous. Par défaut, le préfixe est vide. Si le préfixe est défini sur foo, le fichier de configuration des modules gconv sera lu à partir de foo/usr/lib/gconv/gconv-modules et le cache sera écrit dans foo/usr/lib/gconv/gconv-modules.cache.
--help
-?
Afficher un résumé d'utilisation et quitter.
--usage
Afficher un bref résumé d'utilisation et quitter.
--version
-V
Afficher le numéro de version, la licence et le déni de garantie pour iconv.

CODE DE RETOUR

Zéro en cas de succès, une valeur non nulle en cas d'erreur.

FICHIERS

/usr/lib/gconv
Chemin par défaut habituel des modules gconv.
/usr/lib/gconv/gconv-modules
Fichier de configuration habituel par défaut des modules gconv du système.
/usr/lib/gconv/gconv-modules.cache
Cache habituel par défaut de la configuration des modules gconv du système.

Selon l'architecture, les fichiers ci-dessus peuvent également se trouver dans des répertoires avec le préfixe de chemin /usr/lib64.

VOIR AUSSI

iconv(1), iconv(3)
