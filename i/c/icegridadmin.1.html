NOM

icegridadmin - L'utilitaire administratif en ligne de commande d'IceGrid.

SYNTAXE

icegridadmin [options]

DESCRIPTION

L'utilitaire icegridadmin est un outil en ligne de commande pour administrer un domaine IceGrid. Le déploiement d'une application avec cet utilitaire nécessite un fichier XML qui définit les descripteurs. La documentation complète pour icegridadmin est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/ice-services/icegrid/icegridadmin-command-line-tool

OPTIONS

-h, --help

Affiche l'aide du programme.
-v, --version

Affiche la version de Ice.
-e COMMANDES

Exécute les COMMANDES.
-d, --debug

Affiche les messages de débogage.
-s, --server

Démarre icegridadmin en tant que serveur (pour analyser les fichiers XML).
-i, --instanceName

Se connecte au registre avec le nom d'instance donné.
-H, --host

Se connecte au registre à l'hôte donné.
-P, --port

Se connecte au registre en cours d'exécution sur le port donné.
-u, --username

Se connecte avec le nom d'utilisateur donné.
-p, --password

Se connecte avec le mot de passe donné.
-S, --ssl

S'authentifie via SSL.
-r, --replica NOM

Se connecte à la réplique NOM.

VOIR AUSSI
