NO

M

icedtea-web fournit un plugin de navigateur web libre exécutant des applets écrites dans le langage de programmation Java et une implémentation de Java Web Start, initialement basée sur le projet

NetX.

NetX permet de télécharger des applets et des applications Java via le réseau, de les mettre en cache et (par défaut) de les exécuter dans un environnement bac à sable sécurisé. Les exécutions ultérieures de l'applet téléchargent automatiquement la dernière version. Les paramètres de mise à jour et de sécurité, entre autres, peuvent être définis à l'aide de la commande itw-settings.
icedtea-web inclut également un plugin pour activer les applets Java (http://www.java.com/en/download/testjava.jsp) dans les navigateurs web.

Les noms et adresses e-mail des contributeurs à ce projet peuvent être trouvés dans le fichier AUTHORS à la racine du répertoire
IcedTea-Web.
La licence complète GPLv2 de ce projet peut être trouvée dans le fichier COPYING à la racine du répertoire
IcedTea-Web.
Les informations sur les versions de ce projet peuvent être trouvées dans le fichier NEWS à la racine du répertoire
IcedTea-Web.
