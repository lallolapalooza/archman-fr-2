NOM

icewm-menu-xrandr - Fournisseur de menu IceWM pour les raccourcis de configuration multi-moniteurs

SYNTAXE

icewm-menu-xrandr

DESCRIPTION

icewm-menu-xrandr est une aide à la gestion des configurations multi-écrans de manière semi-automatisée. C'est un générateur de menu icewm standard qui détecte les écrans xrandr disponibles (c'est-à-dire les moniteurs connectés) et crée des entrées de menu qui appellent la commande xrandr pour configurer cette configuration.

Optionnellement, le contenu des configurations générées peut être accédé à la volée via un menu de type "commutation rapide" qui apparaît lorsque l'on appuie sur la combinaison de touches Super-P (ou une touche configurée manuellement, voir icewm-keys(5) pour la configuration de la directive switchkey).

L'outil n'examine pas les résolutions exactes des moniteurs, les taux de rafraîchissement ou l'orientation de l'écran. Pour ces aspects, il utilise le mode sélectionné automatiquement par défaut. Cependant, il est possible de remplacer la sélection d'options personnalisées pour chaque sortie en utilisant les options xrandr dans un fichier de configuration personnalisé (voir CONFIGURATION ci-dessous). Il est également possible d'y ajuster des options spécifiques comme --brightness et --gamma.

Le nom affiché des moniteurs est construit en utilisant le nom de la sortie et les informations du moniteur provenant de ses données EDID. Soit depuis son champ "Display Name", soit depuis les champs "Unspecified ASCII text" (concaténés).

OPTIONS

--max
Option obsolète et inefficace. Utilisée pour sélectionner le mode xrandr avec le taux de rafraîchissement le plus élevé détecté. Cependant, le taux maximal peut causer des problèmes, par conséquent la configuration explicite dans le fichier INI doit être utilisée maintenant, voir CONFIGURATION.
--auto-number [ valeur initiale ]
Ajoute un préfixe numéroté à incrémentation automatique à chaque nom d'affichage, commençant éventuellement à la valeur spécifiée. Ceci est principalement utile pour la création de menus.
--xrandr commande
Remplacement pour la commande xrandr qui doit fournir des données équivalentes et accepter les mêmes options que xrandr.
--activate nom-combo
Un raccourci pour exécuter la commande d'activation du combo spécifié, de la même manière que IceWM exécuterait la commande lorsqu'elle est sélectionnée dans le menu ou dans la boîte de dialogue de commutation rapide. Le paramètre nom-combo doit correspondre exactement au nom affiché.

CONFIGURATION

Optionnellement, une configuration locale peut spécifier des options de ligne de commande pour les appels à xrandr, et d'autres commandes à exécuter après le changement de mode.

Se référer aux exemples de configuration (xrandr_menu) dans la documentation icewm ou dans son dossier contrib pour la syntaxe et les règles de ce fichier. Il peut être placé dans $HOME/.config/icewm ou dans $HOME/.icewm ou partout où $XDG_CONFIG_HOME/.config/icewm pourrait pointer.

VOIR AUSSI

icewm(1), xrandr(1).
