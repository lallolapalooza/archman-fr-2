ICEHELP(1) Commandes utilisateur ICEHELP(1)

NOM

icehelp - un navigateur HTML très simple

SYNTAXE

icehelp [OPTIONS] FICHIER

DESCRIPTION

icehelp est un navigateur HTML très simple, utilisé par icewm(1) pour afficher le Manuel IceWM et les pages de manuel.

Le document peut être parcouru à l'aide des touches fléchées, des touches de navigation et d'une barre de défilement. Pour trouver du texte, appuyez sur "Ctrl+F" pour ouvrir une fenêtre de recherche. Appuyez sur la touche de fonction "F3" pour répéter une recherche.

Le coin supérieur droit affiche un bouton qui ouvre un menu. Ce menu peut également être ouvert par un clic de souris droit.

ARGUMENTS

FICHIER
Spécifie le fichier à parcourir. Il peut également s'agir de l'URL d'un site web.

OPTIONS

OPTIONS SPÉCIFIQUES

-B
Affiche la page de manuel icewmbg d'IceWM.
-b, --bugs
Affiche les rapports de bogues d'IceWM (de manière primitive).
-f, --faq
Affiche la FAQ et le Howto d'IceWM.
-g
Affiche le site web Github d'IceWM.
-i, --icewm
Affiche la page de manuel icewm d'IceWM.
-m, --manual
Affiche le Manuel IceWM (par défaut).
-s
Affiche la page de manuel icesound d'IceWM.
-t, --theme
Affiche le Howto des thèmes d'IceWM.
-w, --website
Affiche le site web d'IceWM.

OPTIONS GÉNÉRALES

-d, --display=AFFICHAGE
Utilise AFFICHAGE pour se connecter au serveur X. Si cette option est absente, AFFICHAGE est lu à partir de la variable d'environnement "DISPLAY".
--sync
Utilise un mode de communication plus lent et synchrone avec le serveur X11.
-h, --help
Affiche un bref énoncé d'utilisation sur stdout et quitte.
-V, --version
Affiche la version du programme sur stdout et quitte.
-C, --copying
Affiche les permissions de copie sur stdout pour le programme et quitte.

BOGUES

Veuillez signaler les bogues à https://github.com/bbidulock/icewm/issues.
