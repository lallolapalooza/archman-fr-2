ICAT(1) Manuel des commandes générales ICAT(1)

NOM

icat - Affiche le contenu d'un fichier basé sur son numéro d'inode.

SYNTAXE

icat [-hrsvV] [-f fstype ] [-i imgtype ] [-o imgoffset ] [-b dev_sector_size] image [images] inode

DESCRIPTION

icat ouvre les images nommées et copie le fichier avec le numéro d'inode spécifié vers la sortie standard.

ARGUMENTS

-f fstype
Spécifie le type de système de fichiers. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-h
Ignore les trous dans les fichiers épars, de sorte que les informations d'adresse absolue sont perdues. Cette option permet d'économiser de l'espace lors de la copie de fichiers épars.
-r
Utilise des techniques de récupération de fichiers si le fichier est supprimé.
-s
Inclut l'espace de décalage (slack space) dans la sortie.
-i imgtype
Identifie le type de fichier image, comme brut. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o imgoffset
Le décalage de secteur où le système de fichiers commence dans l'image.
-b dev_sector_size
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Active le mode verbeux, sortie vers stderr.
-V
Affiche la version.
image [images]
L'image du disque ou de la partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, indiqué par une fin en '.001'), les segments d'image suivants seront inclus automatiquement.
inode
Numéro d'inode. icat concatène le contenu de tous les fichiers spécifiés.
