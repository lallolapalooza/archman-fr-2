NOM

icestormadmin - L'outil d'administration IceStorm.

SYNTAXE

icestormadmin [options] [fichier...]

DESCRIPTION

L'outil d'administration IceStorm est un programme en ligne de commande qui offre un contrôle administratif d'un serveur IceStorm. La documentation complète pour icestormadmin est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/ice-services/icestorm/icestorm-administration

OPTIONS

-h, --help

Affiche un message d'aide.
-v, --version
Affiche la version d'Ice.
-e COMMANDES

Exécute les COMMANDES.
-d, --debug

Affiche les messages de débogage.
