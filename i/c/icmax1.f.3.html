integer function icmax1 (integer n, complex, dimension(*) cx, integer incx)

ICMAX1 trouve l'indice du premier élément de vecteur de valeur absolue maximale.

Objectif :

!>
!> ICMAX1 trouve l'indice du premier élément de vecteur de valeur absolue maximale.
!>
!> Basé sur ICAMAX de Level 1 BLAS.
!> La modification consiste à utiliser la valeur absolue 'authentique'.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          Le nombre d'éléments dans le vecteur CX.
!>

CX

!>          CX est un tableau de type COMPLEX, de dimension (N)
!>          Le vecteur CX. La fonction ICMAX1 renvoie l'indice de son premier
!>          élément de valeur absolue maximale.
!>

INCX

!>          INCX est un entier (INTEGER)
!>          L'espacement entre les valeurs successives de CX.  INCX >= 1.
!>
