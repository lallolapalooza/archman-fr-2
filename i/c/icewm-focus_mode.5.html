NOM

icewm-focus_mode - Fichier de configuration du mode de focus d'icewm

SYNOPSIS

$ICEWM_PRIVCFG/focus_mode
$XDG_CONFIG_HOME/icewm/focus_mode
$HOME/.icewm/focus_mode
/usr/etc/icewm/focus_mode
/usr/share/icewm/focus_mode

DESCRIPTION

Définit la valeur initiale de "FocusMode". Sa valeur par défaut est "FocusMode=1" (Focus au clic). Ceci peut être modifié via le menu. icewm enregistrera le choix du menu Focus dans ce fichier.

FORMAT

Le fichier contient une seule ligne contenant l'affectation de préférence pour FocusMode.

EXEMPLES

Voici mon fichier focus_mode :

FocusMode=2

FICHIERS

Les emplacements du fichier focus_mode sont les suivants :

$ICEWM_PRIVCFG/focus_mode
$XDG_CONFIG_HOME/icewm/focus_mode
$HOME/.icewm/focus_mode
/usr/share/icewm/focus_mode
/usr/local/share/icewm/focus_mode

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est lu et les suivants sont ignorés.

VOIR AUSSI

icewm(1), icewm-preferences(5).
