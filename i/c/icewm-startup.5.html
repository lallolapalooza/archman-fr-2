ICEWM-STARTUP(5) Normes, environnements et macros ICEWM-STARTUP(5)

NOM

icewm-startup - Fichier de configuration de démarrage d'icewm

SYNTAXE

$ICEWM_PRIVCFG/startup
$XDG_CONFIG_HOME/icewm/startup
$HOME/.icewm/startup
/usr/etc/icewm/startup
/usr/share/icewm/startup

DESCRIPTION

Le fichier startup contient les commandes à exécuter au démarrage de icewm. Il s'agit d'un script exécutable. Généralement, les commandes ajustent les paramètres X11 et lancent des applications qui doivent toujours être actives. Il est exécuté par icewm-session(1) lors du démarrage de icewm.

EXEMPLES

#!/bin/bash
xset r rate 250 32
flameshot &
volumeicon &
redshift-gtk &
picom -b

N'oubliez pas de faire "chmod +x ~/.icewm/startup". La première ligne doit être un shebang (hash-bang), suivi du chemin vers votre interpréteur de script ou shell.

FICHIERS

Les emplacements du fichier startup sont les suivants :

$ICEWM_PRIVCFG/startup
$XDG_CONFIG_HOME/icewm/startup
$HOME/.icewm/startup
/usr/etc/icewm/startup
/usr/share/icewm/startup

Les emplacements sont recherchés dans l'ordre indiqué ; le premier fichier trouvé est exécuté et les autres sont ignorés.

VOIR AUSSI

icewm-session(1), icewm-shutdown(5).
