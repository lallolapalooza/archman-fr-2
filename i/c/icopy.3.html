Documentation de la fonction/sous-programme

sous-programme icopy (entier n, entier, dimension( * ) sx, entier incx, entier, dimension( * ) sy, entier incy)

ICOPY

But :

!>
!> ICOPY copie un vecteur entier x vers un vecteur entier y.
!> Utilise des boucles déroulées pour des incréments égaux à 1.
!>

Paramètres

N 
!>          N est un ENTIER
!>          La longueur des vecteurs SX et SY.
!>

SX

!>          SX est un tableau ENTIER, de dimension (1+(N-1)*abs(INCX))
!>          Le vecteur X.
!>

INCX

!>          INCX est un ENTIER
!>          L'espacement entre les éléments consécutifs de SX.
!>

SY

!>          SY est un tableau ENTIER, de dimension (1+(N-1)*abs(INCY))
!>          Le vecteur Y.
!>

INCY

!>          INCY est un ENTIER
!>          L'espacement entre les éléments consécutifs de SY.
!>
