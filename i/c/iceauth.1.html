ICEAUTH(1) Manuel des commandes générales ICEAUTH(1)

NOM

iceauth - utilitaire de fichier d'autorité ICE

SYNTAXE

iceauth [ -f fichier-auth ] [ -vqibuV ] [ commande arg ... ]

DESCRIPTION

Le programme iceauth est utilisé pour éditer et afficher les informations d'autorisation utilisées pour se connecter avec ICE. Ce programme est généralement utilisé pour extraire des enregistrements d'autorisation d'une machine et les fusionner sur une autre (comme c'est le cas lors de l'utilisation de connexions à distance ou de l'octroi d'accès à d'autres utilisateurs). Les commandes (décrites ci-dessous) peuvent être entrées interactivement, sur la ligne de commande iceauth, ou dans des scripts.

OPTIONS

-f fichier-auth Nom du fichier d'autorité à utiliser. Par défaut, il s'agira du fichier actuellement utilisé par la session.

-v Active les messages supplémentaires (mode verbeux)

-q Désactive les messages supplémentaires (mode silencieux)

-i Ignore les verrous sur le fichier d'autorité

-b Casse les verrous sur le fichier d'autorité

-u Affiche les instructions d'utilisation de base

-V Affiche la version et quitte

UTILISATION

Lorsque iceauth est exécuté, il permet d'entrer l'ensemble de commandes suivant de manière interactive ou dans des scripts.

?

Liste les commandes disponibles.

help

Affiche les informations d'aide. Vous pouvez fournir un nom de commande à help pour obtenir des informations spécifiques à son sujet.

info

Affiche des informations sur les entrées du fichier d'autorité.

list

Liste (affiche) les entrées du fichier d'autorité. Vous pouvez spécifier des modificateurs optionnels ci-dessous pour spécifier quelles entrées sont listées.

list [ nom-protocole ] [ données-protocole ] [ netid ] [ nom-auth ]

add

Ajoute une entrée au fichier d'autorité. Celle-ci doit être dans le format

add nom-protocole données-protocole netid nom-auth données-auth

remove

Supprime des entrées du fichier d'autorité.

remove [ nom-protocole ] [ données-protocole ] [ netid ] [ nom-auth ]

extract

Extrait les entrées du fichier d'autorité dans un fichier de destination. Vous devez fournir le chemin du fichier de destination à cette commande, comme suit. Des spécificateurs optionnels vous permettent de restreindre les entrées extraites.

extract nom-fichier [ nom-protocole ] [ données-protocole ] [ netid ] [ nom-auth ]

merge

Fusionne des entrées d'autres fichiers dans le fichier d'autorité sélectionné par le programme. Vous pouvez fournir n'importe quel nombre de chemins de fichier à cette commande comme suit :

merge fichier1 [ fichier2 ] [ fichier3 ] ...

exit

Sauvegarde les modifications et quitte le programme.

quit

Annule les modifications et quitte le programme sans sauvegarder.

source

Lit et exécute les commandes à partir d'un fichier.

source nom-fichier
