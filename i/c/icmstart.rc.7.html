NOM

icmstart.rc - Le fichier de ressources de icmstart(1)

DESCRIPTION

Le fichier icmstart.rc spécifie les fichiers à installer par icmstart(1).

Un icmstart.rc par défaut se trouve dans /etc/icmake/icmstart.rc, mais si $HOME/.icmake/icmstart.rc existe, ce dernier fichier est utilisé par icmstart(1). $HOME/.icmake/icmstart.rc est à son tour remplacé en spécifiant une option -c lors de l'appel à icmstart(1).

Le fichier de ressources par défaut contient les spécifications suivantes, préparant la construction d'un programme C++ à l'aide de icmbuild(1) :

    CLASSES
    icmconf
    P  main.cc 
    P  main.ih 
    Pb usage.cc
    Pb version.cc
    P ? scanner 
    P ? parser
Le fichier icmstart.rc peut contenir :
o
des lignes vides, qui sont ignorées ;
o
des lignes commençant par un caractère dièse (#), également ignorées ;
o
un mode d'installation optionnel suivi d'une spécification source-destination.

MODE D'INSTALLATION

Un mode d'installation consiste en une combinaison de :

o
soit un P (ne pas installer avec icmstart xxx bibliothèque) soit un L (ne pas installer avec icmstart xxx programme) ;
o
un D, indiquant que la source doit également être installée par défaut, c'est-à-dire si ni `programme' ni `bibliothèque' n'a été spécifié comme deuxième argument ;
o
un b, indiquant que le fichier ne doit *pas* être installé si l'option -b (installation basique) a été spécifiée lors de l'appel à icmstart ;
o
Suite au caractère optionnel P, L, D, ou b, un ? optionnel séparé par des espaces peut être spécifié. S'il est spécifié, l'installation du fichier ou du répertoire doit être confirmée par l'utilisateur.

SPÉCIFICATIONS SOURCE-DESTINATION

Les spécifications source-destination suivantes peuvent être utilisées dans un fichier icmstart.rc (en utilisant modèles ci-dessous pour faire référence au répertoire des fichiers modèles de icmstart) :

o
source
un fichier nommé source doit exister dans modèles. Il est installé dans le répertoire destination `dest' qui est spécifié lors de l'appel à icmstart(1). Exemple : 
    CLASSES
modèles/CLASSES est installé comme dest/CLASSES ;
o
specifchemindroit
si `specifchemindroit' ne commence pas par une barre oblique, il doit exister dans modèles. Il est installé comme `specifchemindroit' dans le répertoire destination spécifié lors de l'appel à icmstart(1). Exemple : 
    dir/file
modèles/dir/file est installé comme dest/dir/file ;
o
/specifchemindroit ou ~/specifchemindroit
le caractère ~ est développé en répertoire personnel de l'utilisateur. L'élément final de specifchemindroit est installé dans le répertoire destination spécifié lors de l'appel à icmstart(1). Exemple : 
    ~/.icmake/file
$HOME/.icmake/file est installé comme dest/file

Lorsque les spécifications source ci-dessus sont suivies d'une spécification de destination destspec (une spécification de fichier ou de répertoire non absolue), la spécification source est installée comme dest/destspec sous le répertoire destination spécifié lors de l'appel à icmstart(1). Exemples :

    CLASSES CLASSES             # modèles/CLASSES est installé comme 
                                #   dest/CLASSES
    dir/file dir/file           # modèles/dir/file est installé comme
                                #   dest/dir/file
    ~/.icmake/file .icmake/file # $HOME/.icmake/file est installé comme 
                                #   dest/.icmake/file
Icmstart convertit les spécifications de destination en chemins absolus. Si ces chemins absolus ne commencent pas par le chemin absolu de dest, un message d'erreur est affiché et icmstart se termine.

FICHIERS

Les chemins mentionnés sont indicatifs seulement et peuvent dépendre de l'installation :

o
/usr/share/icmake/icmconf : exemple de fichier de configuration icmbuild ;
o
/usr/share/icmake/CLASSES : exemple de fichier CLASSES d'icmbuild ;
o
/usr/share/icmake/icmstart.rc : fichier de ressources modèle par défaut.
