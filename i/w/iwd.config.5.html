DESCRIPTIO

Le fichier de configuration main.conf configure les paramètres système pour iwd. Ce fichier se trouve dans le répertoire de configuration spécifié par la variable d'environnement $CONFIGURATION_DIRECTORY, qui est normalement fournie par systemd. En l'absence d'une telle variable d'environnement, la valeur par défaut est /etc/iwd. Si aucun main.conf n'est présent, des valeurs par défaut sont choisies. La présence de main.conf n'

requise.

EnableNetworkConfiguraValeurs : true, false Activer la configuration réseau. Régler cette option à true permet à iwd de configurer les interfaces réseau avec les adresses IP. Deux types d'adressage IP sont pris en charge par iwd : statique et dynamique. Les adresses IP statiques sont configurées à travers les fichiers de configuration réseau. Si aucune configuration IP statique n'a été fournie pour un réseau, iwd essaiera d'obtenir les adresses dynamiques du réseau via le client DHCP intégré. Cela active également la configuration réseau et le serveur DHCP lorsque le mode AP est utilisé et que le profil AP activé ne le remplace pas. La fonctionnalité de configuration réseau est désactivée par défaut. Voir les paramètres [Network] pour des paramètre

Si AddressRandomization est défini à once, l'adresse MAC est aléatorisée une seule fois lorsque iwd démarre ou lorsque le matériel est détecté pour la première fois (à cause du hotplug, etc.).
