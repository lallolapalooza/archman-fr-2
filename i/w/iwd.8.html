NOM

iwd - démon sans fil Internet

SYNTAXE

iwd [options ...]

DESCRIPTION

Démon pour gérer les périphériques sans fil sous Linux.

Le projet iNet Wireless Daemon (iwd) vise à fournir une solution de connectivité Wi-Fi complète pour les appareils basés sur Linux. L'objectif principal du projet est d'optimiser l'utilisation des ressources : espace de stockage, mémoire vive et coûts de liaison. Ceci est accompli en ne dépendant d'aucune bibliothèque externe et en utilisant au maximum les fonctionnalités fournies par le noyau Linux. Le résultat est un environnement autonome qui ne dépend que du noyau Linux et de la bibliothèque C d'exécution.

OPTIONS

--version, -v
Afficher le numéro de version et quitter.
--help, -h
Afficher le message d'aide et quitter.

ENVIRONNEMENT

$STATE_DIRECTORY est utilisé pour les fichiers de configuration réseau. Voir iwd.network pour les détails.

$CONFIGURATION_DIRECTORY est utilisé pour les paramètres de configuration du démon. Seul le fichier main.conf est actuellement lu depuis ce répertoire. Voir iwd.config pour les détails.

Voir iwd.debug pour les variables d'environnement supplémentaires pour le débogage.
