NOM

iwpmd.conf - fichier de configuration du mappeur de ports iWARP.

SYNTAXE

iwpmd.conf

DESCRIPTION

Le fichier iwpmd.conf fournit les paramètres de configuration pour iwpmd. Les paramètres sont de la forme : param=valeur, un par ligne. Les paramètres incluent :

nl_sock_rbuf_size - La taille du tampon de socket du socket netlink utilisé pour communiquer avec le client de la carte de ports du noyau. La valeur par défaut est 400 Mo.

EXEMPLES

nl_sock_rbuf_size=419430400

FICHIERS

/etc/iwpmd.conf
