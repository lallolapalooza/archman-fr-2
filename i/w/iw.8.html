IW(8) Linux IW(8)

NOM

iw - afficher / manipuler les périphériques sans fil et leur configuration

SYNTAXE


iw [ OPTIONS ] { help [ commande ] | OBJET COMMANDE }

OBJET := { dev | phy | reg }

OPTIONS := { --version | --debug }

OPTIONS

--version
affiche les informations de version et quitte.
--debug
active le débogage des messages netlink.

IW - SYNTAXE DES COMMANDES

OBJET

dev <nom_interface>
- interface réseau.
phy <nom_phy>
- périphérique matériel sans fil (par nom).
phy#<indice_phy>
- périphérique matériel sans fil (par indice).
reg
- agent de réglementation.

COMMANDE

Spécifie l'action à effectuer sur l'objet. L'ensemble des actions possibles dépend du type d'objet. iw help affichera toutes les commandes supportées, tandis que iw help commande affichera l'aide pour toutes les commandes correspondantes.

VOIR AUSSI

ip(8), crda(8), regdbdump(8), regulatory.bin(5).
