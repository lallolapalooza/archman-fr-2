NOM

iwgetid - Signaler l'ESSID, le NWID ou l'adresse AP/Cellule du réseau sans fil

SYNOPSIS

iwgetid [interface] [--raw] [--scheme] [--ap] [--freq]
[--mode] [--protocol] [--channel]

DESCRIPTION

iwgetid est utilisé pour connaître le NWID, l'ESSID ou l'adresse AP/Cellule du réseau sans fil actuellement utilisé. Les informations rapportées sont les mêmes que celles affichées par iwconfig, mais iwgetid est plus facile à intégrer dans divers scripts.
Par défaut, iwgetid affichera l'ESSID du périphérique, et si le périphérique n'a pas d'ESSID, il affichera son NWID.
Le format de sortie par défaut est la présentation soignée.

OPTIONS

--raw
Cette option désactive la présentation soignée des informations. Cette option est orthogonale aux autres options (sauf --scheme), donc avec la combinaison appropriée d'options, vous pouvez afficher l'ESSID, l'adresse AP ou le mode brut.
Ce format est idéal pour stocker le résultat de iwgetid comme variable dans des scripts Shell ou Perl ou pour passer le résultat comme argument sur la ligne de commande de iwconfig.
--scheme
Cette option est similaire à la précédente, elle désactive la présentation soignée des informations et supprime tous les caractères qui ne sont pas alphanumériques (comme les espaces, la ponctuation et les caractères de contrôle).
La sortie résultante est un identifiant de schéma Pcmcia valide (qui peut être utilisé comme argument de la commande cardctl scheme). Ce format est également idéal pour utiliser le résultat de iwgetid comme sélecteur dans des scripts Shell ou Perl, ou comme nom de fichier.
--ap
Afficher l'adresse MAC du Point d'Accès sans fil ou de la Cellule.
--freq
Afficher la fréquence ou le canal actuel utilisé par l'interface.
--channel
Afficher le canal actuel utilisé par l'interface. Le canal est déterminé à l'aide de la fréquence actuelle et de la liste des fréquences fournies par l'interface.
--mode
Afficher le mode actuel de l'interface.
--protocol
Afficher le nom du protocole de l'interface. Ceci permet d'identifier toutes les cartes qui sont compatibles entre elles et qui acceptent le même type de configuration.
Ceci peut également être utilisé pour vérifier le support des extensions sans fil sur l'interface, car c'est le seul attribut que tous les pilotes supportant les extensions sans fil sont tenus de supporter.

VOIR AUSSI

iwconfig(8), ifconfig(8), iwspy(8), iwpriv(8).
