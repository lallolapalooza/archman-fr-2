NOM

iwctl - Utilitaire de contrôle sans fil Internet

SYNTAXE

iwctl [options ...] [commandes ...]

DESCRIPTION

Outil pour configurer le démon iwd via l'interface D-Bus. Il prend en charge à la fois le mode interactif et le mode ligne de commande.

OPTIONS

--nom-utilisateur, -u
Fournir le nom d'utilisateur.
--mot-de-passe, -p
Fournir le mot de passe.
--phrase-secret, -P
Fournir la phrase secrète.
--ne-pas-demander, -v
Ne pas demander les identifiants manquants.
--aide, -h
Afficher le message d'aide et quitter.

EXEMPLES

Mode interactif

Pour démarrer un mode interactif et lister toutes les commandes disponibles, faites : .. code-block:

$ iwctl
[iwd]# help

Pour vous connecter à un réseau : .. code-block:

[iwd]# device list
[iwd]# station DEVICE scan
[iwd]# station DEVICE get-networks
[iwd]# station DEVICE connect SSID

Mode ligne de commande

Pour lister toutes les commandes disponibles en mode ligne de commande et quitter, faites : .. code-block:

$ iwctl --help

Pour vous connecter à un réseau : .. code-block:

$ iwctl device list
$ iwctl station DEVICE scan
$ iwctl station DEVICE get-networks
$ iwctl --phrase-secret=PHRASE_SECRETE station DEVICE connect SSID
