NOM

ipq_errstr, ipq_perror — routines de gestion des erreurs de libipq

SYNTAXE

#include <linux/netfilter.h>
#include <libipq.h>

char *ipq_errstr(void);
void ipq_perror(const char *s);

DESCRIPTION

La fonction ipq_errstr renvoie un message d'erreur descriptif basé sur la valeur actuelle de la variable interne ipq_errno. Toutes les fonctions de l'API libipq définissent cette variable interne en cas d'échec.

La fonction ipq_perror imprime un message d'erreur sur stderr correspondant à la valeur actuelle de la variable interne ipq_error et à la variable globale errno (si elle est définie). Le message d'erreur est préfixé par la chaîne s fournie par l'application. Si s est NULL, le message d'erreur est préfixé par la chaîne "ERROR".

VALEUR RENVOYÉE

ipq_errstr renvoie un message d'erreur tel que décrit ci-dessus.

BOGUES
