IPTABLES-TRANSLATE(8) Manuel de l'administrateur système IPTABLES-TRANSLATE(8)

NOM

iptables-translate — outil de traduction pour migrer d'iptables vers nftables

ip6tables-translate — outil de traduction pour migrer d'ip6tables vers nftables

ebtables-translate — outil de traduction pour migrer d'ebtables vers nftables

arptables-translate — outil de traduction pour migrer d'arptables vers nftables

DESCRIPTION

Il existe un ensemble d'outils pour aider l'administrateur système à traduire un ensemble de règles donné depuis iptables(8), ip6tables(8), ebtables(8) et arptables(8) vers nftables(8).

Les commandes disponibles sont :

•
iptables-translate
•
iptables-restore-translate
•
ip6tables-translate
•
ip6tables-restore-translate
•
ebtables-translate
•
arptables-translate

UTILISATION

Ils prennent en entrée la syntaxe originale d'iptables(8)/ip6tables(8)/ebtables(8)/arptables(8) et produisent la syntaxe native de nftables(8).

L'outil iptables-restore-translate lit un ensemble de règles dans la syntaxe produite par iptables-save(8). De même, l'outil ip6tables-restore-translate lit un ensemble produit par ip6tables-save(8). Aucune modification des ensembles de règles n'est effectuée, ces outils ne sont que des convertisseurs de texte.

iptables-translate lit une ligne de commande comme si elle était entrée dans iptables(8), et ip6tables-translate lit une ligne de commande comme si elle était entrée dans ip6tables(8).

EXEMPLES

Exemples d'opération de base.

Traduction d'une seule commande :

root@machine:~# iptables-translate -A INPUT -p tcp --dport 22 -m conntrack --ctstate NEW -j ACCEPT
nft add rule ip filter INPUT tcp dport 22 ct state new counter accept
root@machine:~# ip6tables-translate -A FORWARD -i eth0 -o eth3 -p udp -m multiport --dports 111,222 -j ACCEPT
nft add rule ip6 filter FORWARD iifname eth0 oifname eth3 meta l4proto udp udp dport { 111,222} counter accept

Traduction d'un ensemble de règles complet :

root@machine:~# iptables-save > save.txt
root@machine:~# cat save.txt
# Generated by iptables-save v1.6.0 on Sat Dec 24 14:26:40 2016
*filter
:INPUT ACCEPT [5166:1752111]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [5058:628693]
-A FORWARD -p tcp -m tcp --dport 22 -m conntrack --ctstate NEW -j ACCEPT
COMMIT
# Completed on Sat Dec 24 14:26:40 2016
root@machine:~# iptables-restore-translate -f save.txt
# Translated by iptables-restore-translate v1.6.0 on Sat Dec 24 14:26:59 2016
add table ip filter
add chain ip filter INPUT { type filter hook input priority 0; }
add chain ip filter FORWARD { type filter hook forward priority 0; }
add chain ip filter OUTPUT { type filter hook output priority 0; }
add rule ip filter FORWARD tcp dport 22 ct state new counter accept
root@machine:~# iptables-restore-translate -f save.txt > ruleset.nft
root@machine:~# nft -f ruleset.nft
root@machine:~# nft list ruleset
table ip filter {
	chain INPUT {
		type filter hook input priority 0; policy accept;
	}
	chain FORWARD {
		type filter hook forward priority 0; policy accept;
		tcp dport ssh ct state new counter packets 0 bytes 0 accept
	}
	chain OUTPUT {
		type filter hook output priority 0; policy accept;
	}
}

LIMITATIONS

Certaines extensions (peu nombreuses) peuvent ne pas être prises en charge (ou pas entièrement) pour quelque raison que ce soit (par exemple, elles ont été considérées comme obsolètes, ou nous n'avons pas eu le temps de travailler dessus).

Il n'y a pas de traduction disponible pour arptables(8).

Pour obtenir des informations à jour à ce sujet, veuillez consulter https://wiki.nftables.org/.
