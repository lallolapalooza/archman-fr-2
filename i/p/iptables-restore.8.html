IPTABLES-RESTORE(8) iptables 1.8.11 IPTABLES-RESTORE(8)

NOM

iptables-restore — Restaurer les tables IP

ip6tables-restore — Restaurer les tables IPv6

SYNTAXE

iptables-restore [-chntvV] [-w secondes] [-M modprobe] [-T nom] [fichier]

ip6tables-restore [-chntvV] [-w secondes] [-M modprobe] [-T nom] [fichier]

DESCRIPTION

iptables-restore et ip6tables-restore sont utilisés pour restaurer les tables IP et IPv6 à partir de données spécifiées sur STDIN ou dans fichier. Utilisez la redirection d'I/O fournie par votre shell pour lire à partir d'un fichier ou spécifiez fichier comme argument.

-c, --compteurs
Restaurer les valeurs de tous les compteurs de paquets et d'octets.
-h, --aide
Afficher un court résumé des options.
-n, --sans-vidage
Ne pas vider le contenu précédent de la table. Si non spécifié, les deux commandes vident (suppriment) tout le contenu précédent de la table respective.
-t, --test
Seulement analyser et construire le jeu de règles, mais ne pas le valider.
-v, --verbeux
Afficher des informations de débogage supplémentaires pendant le traitement du jeu de règles. Spécifiez plusieurs fois pour augmenter le niveau de débogage.
-V, --version
Afficher le numéro de version du programme.
-w, --attendre [secondes]
Attendre le verrouillage xtables. Pour empêcher plusieurs instances du programme de s'exécuter simultanément, une tentative d'obtention d'un verrouillage exclusif sera effectuée au lancement. Par défaut, le programme se terminera si le verrouillage ne peut pas être obtenu. Cette option fera attendre le programme (indéfiniment ou pour secondes optionnel) jusqu'à ce que le verrouillage exclusif puisse être obtenu.
-M, --modprobe modprobe
Spécifier le chemin vers le programme modprobe(8). Par défaut, iptables-restore vérifiera /proc/sys/kernel/modprobe pour déterminer le chemin de l'exécutable.
-T, --table nom
Restaurer uniquement la table nommée même si le flux d'entrée en contient d'autres.

BOGUES

Aucun connu depuis la sortie iptables-1.2.1
