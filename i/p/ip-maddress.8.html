NOM

ip-maddress - gestion des adresses multicast

SYNTAXE


ip [ OPTIONS ] maddress { COMMANDE | help }

ip maddress [ add | del ] MULTIADDR dev NOM

ip maddress show [ dev NOM ]

DESCRIPTION

Les objets maddress sont des adresses multicast.

ip maddress show - lister les adresses multicast

dev NOM (défaut)
le nom du périphérique.
ip maddress add - ajouter une adresse multicast
ip maddress delete - supprimer une adresse multicast

Ces commandes attachent/détachent une adresse multicast statique de couche liaison à écouter sur l'interface. Notez qu'il est impossible de rejoindre des groupes multicast de protocole statiquement. Cette commande gère uniquement les adresses de couche liaison.

adresse LLADDRESS (défaut)
l'adresse multicast de couche liaison.
dev NOM
le périphérique pour rejoindre/quitter cette adresse multicast.
