DESCRIPTIO

N

Le fichier de configuration de ipmiseld configure le démon ipmi

seld.

Le fichier de configuration par défaut chargé est /etc/freeipmi//ipmiseld.

conf.

Les options de configuration qui peuvent être spécifiées dans le fichier de configuration sont listées ci-dessous. Chaque option de configuration doit être listée sur une ligne séparée. Les arguments d'une option sont séparés par une quantité quelconque d'espaces blancs. Les arguments multiples sont également séparés par des espaces blancs. Les commentaires peuvent être marqués en utilisant le caractère dièse ("#"), et les lignes peuvent être poursuivies sur la ligne suivante en utilisant la barre oblique inverse ("\")

.

Notez qu'il est possible de lister le nom d'utilisateur, le mot de passe et d'autres informatio

ns potentiellement sensibles dans le fichier de configuration. Si ces données sont stockées dans
un fichier de configuration, les administrateurs système doivent limiter l'accès à ce fichier.
