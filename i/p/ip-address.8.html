DESCRIPTIO

N

L' adresse est une adresse de protocole (IPv4 ou IPv6) attachée à un périphérique réseau. Chaque périphérique doit avoir au moins une adresse pour utiliser le protocole correspondant. Il est possible d'avoir plusieurs adresses différentes attachées à un même périphérique. Ces adresses ne sont pas discriminées, de sorte que le terme alias n'est pas tout à fait approprié pour elles et nous ne l'utilisons pas dans ce

document.

La commande ip address affiche les adresses et leurs propriétés, ajoute de nouvelles adresses et en supprime

d'anciennes.

ip address add - ajouter une nouvelle adresse de

protocole.

défaut)
l'adresse de l'interface. Le format de l'adresse dépend du protocole. C'est un quadruplet pointé pour IP et une séquence de demi-mots hexadécimaux séparés par des deux-points pour IPv6. Le ADDRESS peut être suivi d'un slash et d'un nombre décimal qui encode la longueur du préfixe
réseau.
peer ADDRES
S
l'adresse du point d'extrémité distant pour les interfaces pointopoint. Encore une fois, le ADDRESS peut être suivi d'un slash et d'un nombre décimal, encodant la longueur du préfixe réseau. Si une adresse pair est spécifiée, l'adresse locale ne peut pas avoir de longueur de préfixe. Le préfixe réseau est associé avec le pair plutôt qu'avec l'adresse
locale.

S
l'adresse de diffusion sur l'interface.

Il est possible d'utiliser les symboles spéciaux '+' et '-' à la place de l'adresse de diffusion. Dans ce cas, l'adresse de diffusion est

dérivée en définissant/réinitialisant les bi

la portée de la zone où cette adresse est valide. Les portées disponibles sont listées dans /usr/share/iproute2/rt_scopes ou /etc/iproute2/rt_scopes (a la priorité si elle existe). Les valeurs de portée prédéfinies sont :


global - l'adresse est globalement

valide.

site - (IPv6 uniquement, déprécié) l'adresse est locale au site, c'est-à-dire qu'elle est valide à l'intérieur de ce

link - l'adresse est locale au lien, c'est-à-dire qu'elle est valide uniquement sur ce

périphérique.

host - l'adresse n'est valide qu'à l'intérieur de cet hôte.

(IPv6 uniquement) fait en sorte que le noyau gère les adresses temporaires créées à partir de celle-ci comme modèle au nom des Extensions de confidentialité (RFC3041). Pour que cela devienne actif, le paramètre sysctl use_tempaddr doit être défini à une valeur supérieure à zéro. L'adresse donnée doit avoir une longueur de préfixe de 64. Ce drapeau permet d'utiliser les extensions de confidentialité dans un réseau configuré manuellement, comme si la configuration automatique sans état était

Ne pas créer automatiquement une route pour le préfixe réseau de l'adresse ajoutée, et ne pas en chercher une à supprimer lors de la suppression de l'adresse. Modifier une adresse pour ajouter ce drapeau supprimera la route de préfixe ajoutée automatiquement, la modifier pour retirer ce drapeau créera la route de préfixe
automatiquement.
autojo
in
La participation à des groupes de diffusion au niveau Ethernet via la commande ip maddr ne fonctionne pas si l'on est connecté à un commutateur Ethernet qui effectue l'écoute discrète IGMP, car le commutateur ne répliquerait pas les paquets de diffusion sur les ports qui n'ont pas de rapports IGMP pour les adresses de diffusion.

Les interfaces Linux VXLAN créées via ip link add vxlan ont l' option group qui leur permet d'effectuer la jointure

requise.

L'utilisation du drapeau autojoin lors de l'ajout d'une adresse de diffusion active une fonctionnalité similaire pour les interfaces V

XLAN d'Openvswitch ainsi que pour d'autres mécanismes d
