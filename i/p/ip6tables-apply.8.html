NOM

iptables-apply — une manière plus sûre de mettre à jour iptables à distance

SYNTAXE

iptables-apply [-hV] [-t délai] [-w fichier_sauvegarde] {[fichier_règles]|-c [commande_à_exécuter]}

DESCRIPTION

iptables-apply essaiera d'appliquer un nouveau fichier de règles (tel que généré par iptables-save, lu par iptables-restore) ou d'exécuter une commande pour configurer iptables, puis demandera à l'utilisateur si les changements sont acceptables. Si les nouvelles règles iptables coupent la connexion existante, l'utilisateur ne pourra pas répondre affirmativement. Dans ce cas, le script reviendra aux règles iptables précédentes fonctionnelles après expiration du délai.

Les règles appliquées avec succès peuvent également être écrites dans un fichier de sauvegarde et utilisées plus tard pour revenir à cet état. Ceci peut être utilisé pour implémenter un mécanisme de sauvegarde de la dernière configuration valide lors de l'expérimentation avec un script de configuration iptables : iptables-apply -w /etc/iptables/iptables.rules -c /etc/iptables/iptables.run

Lorsqu'il est appelé en tant que ip6tables-apply, le script utilisera ip6tables-save/-restore et les valeurs par défaut IPv6 à la place. La valeur par défaut pour le fichier de règles est '/etc/iptables/iptables.rules'.

OPTIONS

-t secondes, --timeout secondes
Définit le délai en secondes après lequel le script reviendra à l'ensemble de règles précédent (défaut : 10).
-w fichier_sauvegarde, --write fichier_sauvegarde
Spécifie le fichier de sauvegarde où les règles appliquées avec succès seront écrites (défaut si une chaîne vide est donnée : /etc/iptables/iptables.rules).
-c commande_à_exécuter, --command commande_à_exécuter
Exécute la commande commande_à_exécuter pour configurer iptables au lieu d'appliquer un fichier de règles (défaut : /etc/iptables/iptables.run).
-h, --help
Affiche les informations d'utilisation.
-V, --version
Affiche les informations de version.

VOIR AUSSI

iptables-restore(8), iptables-save(8), iptables(8).
