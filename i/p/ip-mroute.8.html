NOM

ip-mroute - gestion du cache de routage multicast

SYNTAXE


ip mroute show [ [ to ] PREFIX ] [ from PREFIX ] [ iif DEVICE ] [ table TABLE_ID ]

DESCRIPTION

Les objets mroute sont des entrées du cache de routage multicast créées par un démon de routage multicast utilisateur (par ex. pimd ou mrouted ).

En raison des limitations de l'interface actuelle du moteur de routage multicast, il est impossible de modifier administrativement les objets mroute, nous ne pouvons donc que les afficher. Cette limitation sera supprimée à l'avenir.

ip mroute show - lister les entrées du cache mroute

to PREFIX (par défaut)
le préfixe sélectionnant les adresses multicast de destination à lister.
iif NOM
l'interface sur laquelle les paquets multicast sont reçus.
from PREFIX
le préfixe sélectionnant les adresses IP source de la route multicast.
table ID_TABLE
l'ID de table sélectionnant la table multicast. Il peut s'agir de local, main, default, all ou d'un nombre.
