NOM

ipc_namespaces - aperçu des espaces de noms IPC Linux

DESCRIPTION

Les espaces de noms IPC isolent certaines ressources IPC, à savoir les objets IPC System V (voir sysvipc(7)) et (depuis Linux 2.6.30) les files de messages POSIX (voir mq_overview(7)). La caractéristique commune de ces mécanismes IPC est que les objets IPC sont identifiés par des mécanismes autres que les noms de fichiers.

Chaque espace de noms IPC possède son propre ensemble d'identifiants IPC System V et son propre système de fichiers de files de messages POSIX. Les objets créés dans un espace de noms IPC sont visibles par tous les autres processus membres de cet espace de noms, mais ne sont pas visibles par les processus des autres espaces de noms IPC.

Les interfaces /proc suivantes sont distinctes dans chaque espace de noms IPC :

•
Les interfaces de files de messages POSIX dans /proc/sys/fs/mqueue.
•
Les interfaces IPC System V dans /proc/sys/kernel, à savoir : msgmax, msgmnb, msgmni, sem, shmall, shmmax, shmmni, et shm_rmid_forced.
•
Les interfaces IPC System V dans /proc/sysvipc.

Lorsqu'un espace de noms IPC est détruit (c'est-à-dire lorsque le dernier processus membre de l'espace de noms se termine), tous les objets IPC de cet espace de noms sont automatiquement détruits.

L'utilisation des espaces de noms IPC nécessite un noyau configuré avec l'option CONFIG_IPC_NS.

VOIR AUSSI
