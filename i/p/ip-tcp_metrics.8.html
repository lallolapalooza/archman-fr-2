NOM

ip-tcp_metrics - gestion des métriques TCP

SYNOPSIS


ip [ OPTIONS ] tcp_metrics { COMMANDE | help }

ip tcp_metrics { show | flush } SECTEUR

ip tcp_metrics delete [ address ] ADRESSE

SECTEUR := [ [ address ] PRÉFIXE ]

DESCRIPTION

ip tcp_metrics est utilisé pour manipuler les entrées du noyau qui conservent les informations TCP pour les destinations IPv4 et IPv6. Les entrées sont créées lorsque les sockets TCP souhaitent partager des informations pour les destinations et sont stockées dans un cache indexé par l'adresse de destination. Les informations sauvegardées peuvent inclure des valeurs pour les métriques (initialement obtenues à partir des routes), TSVAL récent à des fins de recyclage TIME-WAIT, l'état de la fonction Fast Open, etc. Pour des raisons de performance, le cache ne peut pas dépasser la limite configurée et les anciennes entrées sont remplacées par des informations fraîches, parfois récupérées et utilisées pour de nouvelles destinations. Le noyau ne supprime jamais les entrées, elles ne peuvent être vidées qu'avec cet outil.

ip tcp_metrics show - afficher les entrées mises en cache

address PRÉFIXE (par défaut)
Préfixe ou adresse IPv4/IPv6. Si aucun préfixe n'est fourni, toutes les entrées sont affichées.

La sortie peut contenir les informations suivantes :

age <S.MMM>sec - temps écoulé depuis la création, la réinitialisation ou la mise à jour de l'entrée avec les métriques des sockets. L'entrée est réinitialisée et rafraîchie lors de l'utilisation avec les métriques de la route si les métriques ne sont pas mises à jour depuis une heure. Toutes les valeurs mises en cache ne réinitialisent pas l'âge lors de la mise à jour.

cwnd <N> - valeur de la métrique CWND

fo_cookie <CHAÎNE-HEX> - valeur du cookie reçue dans SYN-ACK à utiliser par Fast Open pour les prochains SYN

fo_mss <N> - valeur MSS reçue dans SYN-ACK à utiliser par Fast Open pour les prochains SYN

fo_syn_drops <N>/<S.MMM>sec ago - Nombre de suppressions des SYN Fast Open initiaux sortants avec données détectées par la surveillance du SYN-ACK reçu après la retransmission du SYN. Les secondes indiquent le temps écoulé depuis la dernière suppression de SYN et, avec le nombre de suppressions, peuvent être utilisés pour désactiver Fast Open pendant un certain temps.

reordering <N> - valeur de la métrique de réordonnancement

rtt <N>us - valeur de la métrique RTT

rttvar <N>us - valeur de la métrique RTTVAR

ssthresh <SSTHRESH> - valeur de la métrique SSTHRESH

tw_ts <TSVAL>/<SEC>sec ago - TSVAL récent et le nombre de secondes écoulées depuis sa sauvegarde dans le socket TIME-WAIT

ip tcp_metrics delete - supprimer une entrée unique

address ADRESSE (par défaut)
Adresse IPv4/IPv6. L'adresse est un argument obligatoire.

ip tcp_metrics flush - vider les entrées

Cette commande vide les entrées sélectionnées selon certains critères.

Cette commande a les mêmes arguments que show.

EXEMPLES

ip tcp_metrics show address 192.168.0.0/24

Affiche les entrées pour les destinations du sous-réseau

ip tcp_metrics show 192.168.0.0/24

Idem, mais le mot-clé address est optionnel

ip tcp_metrics

Afficher toutes les entrées est l'action par défaut

ip tcp_metrics delete 192.168.0.1

Supprime l'entrée pour 192.168.0.1 du cache.

ip tcp_metrics flush 192.168.0.0/24

Supprime les entrées pour les destinations du sous-réseau

ip tcp_metrics flush all

Supprime toutes les entrées du cache

ip -6 tcp_metrics flush all

Supprime toutes les entrées IPv6 du cache en conservant les entrées IPv4.
