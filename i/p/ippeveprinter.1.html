DESCRIPTIO

N

ippeveprinter est un serveur simple du protocole d'impression Internet (IPP) conforme à la spécification IPP Everywhere (PWG 5100.14). Il peut êtr

e utilisé pour tester des logiciels clients ou servir de serveur d'impressio
n très basique qui exécute une commande pour chaque travail d'impression.

me à la spécification I

ENVIRONNEMEN

T

ippeveprinter ajoute des variables d'environnement commençant par "IPP_" pour tous les attributs de travail IPP dans la requête d'impression. Par exemple, lors de l'exécution d'une commande pour un travail IPP contenant l'attribut de modèle de travail "media", la variable d'environnement "IPP_MEDIA" sera définie à la valeur de cet

attribut.

De plus, tous les attributs de description d'imprimante IPP "xxx-default" et "pwg-xxx" sont ajoutés à l'environnement. Par exemple, la variable d'environnement "IPP_MEDIA_DEFAULT" sera définie à la valeur par défaut de l'attribut de modèle de travail

"media".

Les valeurs énumérées sont converties en leurs équivalents par mot-clé. Par exemple, un attribut de modèle de travail "print-quality" avec une valeur enum de 3 deviendra la variable d'environnement "IPP_PRINT_QUALITY" avec la valeur "draft". Cette conversion de chaîne ne se produit que pour les attributs de modèle de travail standard, actuellement "finishings", "orientation-requested" et "print-quality"

.

Enfin, la variable d'environnement "CONTENT_TYPE" contient le type MIME de média du document en cours d'impression, la variable d'environn

ement "DEVICE_URI" contient l'URI du périphérique tel que spécifié avec l'option "-D", la variable d'environnement "OUTPUT_FORMAT" contient
le type MIME de média de sortie, et la variable d'environnement "PPD" contient le nom de fichier PPD tel que spécifié avec l'option "-P".

SORTIE DE LA

COMMANDE

À moins qu'ils ne communiquent directement avec une imprimante, les commandes d'impression envoient des données prêtes pour l'imprimante à ippeveprinter(1) — CUPS

COMMAND OUTPUT

Print commands can send messages back to ippeveprinter on the standard output.

Print commands can send messages back to ippeveprinter on the standard error with one of the following prefixes:

ATTR: attribute=value[ attribute=value]
Définit l'attribut (ou les attributs) nommé(s) aux valeurs données. Actuellement, seuls les attributs d'état de tâche "job-impressions" et "job-impressions-completed" ainsi que les attributs d'état d'imprimante "marker-xxx", "printer-alert", "printer-alert-description", "printer-supply" et "printer-supply-description" peuvent être définis.
DEBUG: Debugging message
Enregistre un message de débogage si au moins deux options -v ont été spécifiées.
ERROR: Error message
Enregistre un message d'erreur et copie le message dans l'attribut "job-state-message".
INFO: Informational message
Enregistre un message informatif/de progression si -v a été spécifié et copie le message dans l'attribut "job-state-message" à moins qu'une erreur n'ait été signalée.
STATE: keyword[,keyword,...]
Définit l'attribut "printer-state-reasons" de l'imprimante aux mots-clés listés.
STATE: -keyword[,keyword,...]
Supprime les mots-clés listés de l'attribut "printer-state-reasons" de l'imprimante.
STATE: +keyword[,keyword,...]
Ajoute les mots-clés listés à l'attribut "printer-state-reasons" de l'imprimante.

EXEMPLES

Exécute ippeveprinter avec un nom de service de Mon Imprimante Cool:

    ippeveprinter "My Cool Printer"

Exécute la commande file(1) chaque fois qu'un travail est envoyé au serveur:

    ippeveprinter -c /usr/bin/file "My Cool Printer"
