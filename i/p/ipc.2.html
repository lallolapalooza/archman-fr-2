ipc(2) Manuel des appels système ipc(2)

NOM

ipc - Appels système IPC System V

BIBLIOTHÉQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/ipc.h>        /* Définition des constantes nécessaires */
#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
int syscall(SYS_ipc, unsigned int call, int first,
            unsigned long second, unsigned long third, void *ptr,
            long fifth);

Note: glibc ne fournit pas d'enveloppe pour ipc(), nécessitant l'utilisation de syscall(2).

DESCRIPTION

ipc() est un point d'entrée commun du noyau pour les appels IPC System V pour les messages, les sémaphores et la mémoire partagée. call détermine quelle fonction IPC invoquer ; les autres arguments sont transmis à l'appel approprié.

Les programmes en espace utilisateur doivent appeler les fonctions appropriées par leurs noms habituels. Seuls les implémenteurs de bibliothèques standard et les hackers du noyau ont besoin de connaître ipc().

VERSIONS

Sur certaines architectures —par exemple x86-64 et ARM— il n'y a pas d'appel système ipc() ; au lieu de cela, msgctl(2), semctl(2), shmctl(2), etc. sont réellement implémentés comme des appels système distincts.

NORMES

Linux.

VOIR AUSSI

msgctl(2), msgget(2), msgrcv(2), msgsnd(2), semctl(2), semget(2), semop(2), semtimedop(2), shmat(2), shmctl(2), shmdt(2), shmget(2), sysvipc(7)
