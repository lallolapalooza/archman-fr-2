NOM

iptraf - Moniteur LAN IP interactif et coloré

SYNTAXE

iptraf-ng { [ -f ] [ { -i iface | -g | -d iface | -s iface | -z iface | -l iface } [ -t timeout ] [ -B [ -L logfile ] ] ] | [ -h ] }

DESCRIPTION

iptraf-ng est un moniteur IP LAN basé sur ncurses qui génère diverses statistiques réseau, y compris des informations TCP, des comptes UDP, des informations ICMP et OSPF, des informations de charge Ethernet, des statistiques de nœuds, des erreurs de checksum IP, et d'autres.

Si la commande iptraf-ng est appelée sans aucune option en ligne de commande, le programme s'exécute en mode interactif, les différentes fonctionnalités étant accessibles via le menu principal.

OPTIONS

Ces options peuvent également être fournies à la commande :

-i iface
démarrer immédiatement le moniteur de trafic IP sur l'interface spécifiée, ou toutes les interfaces si « -i all » est spécifié
-g
démarrer immédiatement les statistiques générales de l'interface
-d iface
permet de démarrer immédiatement les statistiques détaillées sur l'interface indiquée (iface)
-s iface
permet de surveiller immédiatement le trafic TCP et UDP sur l'interface spécifiée (iface)
-z iface
affiche le nombre de paquets par taille sur l'interface spécifiée
-l iface
démarrer le moniteur de stations LAN sur l'interface spécifiée, ou toutes les interfaces LAN si « -l all » est spécifié
-t timeout
indique à IPTraf-ng d'exécuter la fonctionnalité spécifiée pendant seulement timeout minutes. Cette option est utilisée uniquement avec l'un des paramètres ci-dessus.
-B
redirige la sortie standard vers /dev/null, ferme l'entrée standard et lance le programme en arrière-plan. Peut être utilisé uniquement avec l'un des paramètres d'invocation de fonctionnalité ci-dessus. Envoyer un signal USR2 au processus lancé en arrière-plan pour le terminer.
-L nom_fichier_journal
permet de spécifier un nom de fichier journal alternatif. Le nom de fichier journal par défaut est basé soit sur l'interface sélectionnée (statistiques détaillées de l'interface, statistiques de services TCP/UDP, ventilation par taille de paquet), soit sur l'instance de la fonctionnalité (moniteur de trafic IP, moniteur de stations LAN). Si aucun chemin n'est spécifié, le fichier journal est placé dans /var/log/iptraf-ng
-f
efface tous les verrous et compteurs, faisant croire à cette instance d'IPTraf-ng qu'elle est la première à s'exécuter. Ceci ne devrait être utilisé que pour récupérer d'une terminaison anormale ou d'un crash système.
-h
affiche un résumé des commandes

SIGNALS


SIGUSR1 - fait pivoter les fichiers journaux pendant que le programme est en cours d'exécution
SIGUSR2 - termine un processus IPTraf-ng s'exécutant en arrière-plan.

FICHIERS


/var/log/iptraf-ng/*.log - fichier journal
/var/lib/iptraf-ng/* - fichiers de données importants d'IPTraf-ng

VOIR AUSSI


Documentation/* - documentation complète écrite par l'auteur
