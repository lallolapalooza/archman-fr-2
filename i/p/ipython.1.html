NOM

ipython - Outils pour le calcul interactif en Python.

SYNTAXE

ipython [options] fichiers...

ipython sous-commande [options]...

DESCRIPTION

Un shell Python interactif avec historique automatique (entrées et sorties), introspection dynamique des objets, configuration plus facile, complétion de commandes, accès au shell système, intégration avec des outils de calcul numérique et scientifique, carnet web, console Qt, et plus.

Pour plus d'informations sur l'utilisation d'IPython, voir 'ipython --help', ou 'ipython --help-all' pour toutes les options de ligne de commande disponibles.

VARIABLES D'ENVIRONNEMENT

IPYTHONDIR

C'est l'emplacement où IPython stocke tous ses fichiers de configuration. Par défaut, c'est $HOME/.ipython si IPYTHONDIR n'est pas défini.

Vous pouvez voir la valeur calculée de IPYTHONDIR avec `ipython locate`.

FICHIERS

IPython utilise divers fichiers de configuration stockés dans des profils au sein de IPYTHONDIR. Pour générer les fichiers de configuration par défaut et commencer à configurer IPython, exécutez 'ipython profile create', et modifiez les fichiers '*_config.py' situés dans IPYTHONDIR/profile_default.
