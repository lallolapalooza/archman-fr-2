NOM

ip-ioam - IOAM (In-situ OAM) pour IPv6

SYNTAXE


ip ioam { COMMANDE | help }

ip ioam namespace show

ip ioam namespace add ID [ data DATA32 ] [ wide DATA64 ]

ip ioam namespace del ID

ip ioam schema show

ip ioam schema add ID DATA

ip ioam schema del ID

ip ioam namespace set ID schema { ID | none }

ip ioam monitor

DESCRIPTION

La commande ip ioam est utilisée pour configurer les paramètres internes de IOAM6 (In-situ OAM pour IPv6), à savoir les espaces de noms IOAM et les schémas.

Ces paramètres incluent également le mappage entre un espace de noms IOAM et un schéma IOAM.

La commande ip ioam monitor affiche les données IOAM reçues.

EXEMPLES

Configurer un espace de noms IOAM (ID = 1) avec des données (32 bits) et des données larges (64 bits)

# ip ioam namespace add 1 data 0xdeadbeef wide 0xcafec0caf00dc0de

Lier un schéma IOAM existant (ID = 7) à un espace de noms IOAM existant (ID = 1)

# ip ioam namespace set 1 schema 7
