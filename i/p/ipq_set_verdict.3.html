IPQ_SET_VERDICT(3) Manuel du programmeur Linux IPQ_SET_VERDICT(3)

NOM

ipq_set_verdict — émettre un verdict et éventuellement un paquet modifié vers le noyau

SYNTAXE

#include <linux/netfilter.h>
#include <libipq.h>

int ipq_set_verdict(const struct ipq_handle *h, ipq_id_t id, unsigned int verdict, size_t data_len, unsigned char *buf);

DESCRIPTION

La fonction ipq_set_verdict émet un verdict sur un paquet précédemment obtenu avec ipq_read, spécifiant la disposition prévue du paquet, et fournissant éventuellement une version modifiée des données de charge utile.

Le paramètre h est un handle de contexte qui doit avoir été retourné avec succès par un appel précédent à ipq_create_handle.

Le paramètre id est l'identifiant du paquet obtenu via ipq_get_packet.

Le paramètre verdict doit être l'une des valeurs suivantes :

NF_ACCEPT
Accepter le paquet et continuer le parcours dans le noyau.
NF_DROP
Rejeter le paquet.
NF_QUEUE
Remettre le paquet en file d'attente.

NF_STOLEN et NF_REPEAT sont des constantes internes au noyau et ne doivent pas être utilisées depuis l'espace utilisateur car leurs effets secondaires exacts n'ont pas été étudiés.

Le paramètre data_len est la longueur des données pointées par buf, les données de remplacement optionnelles de la charge utile.

Si vous souhaitez simplement définir un verdict sans modifier les données de charge utile, utilisez zéro pour data_len et NULL pour buf.

L'application est responsable du recalcul de toute somme de contrôle de paquet lors de la modification des paquets.

VALEUR DE RETOUR

En cas d'échec, -1 est retourné.
En cas de succès, une valeur positive non nulle est retournée.

ERREURS

En cas d'erreur, un message d'erreur descriptif sera disponible via la fonction ipq_errstr.

BOGUES

Aucun connu.
