NOM

ipmidetectd - démon de surveillance de détection de nœuds IPMI

SYNOPIS

ipmidetectd [OPTION...]

DESCRIPTION

Le démon ipmidetectd envoie régulièrement des pings IPMI pour déterminer si les nœuds ont des interfaces IPMI fonctionnelles ou non. Il est principalement utilisé pour identifier les nœuds du cluster qui ne fonctionnent pas correctement, permettant d'exécuter des commandes IPMI plus rapidement sur l'ensemble du cluster en ignorant ces nœuds qui expirerait automatiquement.

Le démon ipmidetectd doit être configuré à l'aide du fichier de configuration ipmidetectd. Tant que les hôtes à pinger ne sont pas configurés, ipmidetectd ne fonctionnera pas correctement.

Consultez la page man ipmidetectd.conf(5) pour plus d'informations.

OPTIONS

-c FICHIER, --config-file
Spécifier un fichier de configuration alternatif
-d, --debug
Activer le débogage et exécuter le démon au premier plan
-V, --version
Afficher la version

ERREURS

Les erreurs sont enregistrées dans syslog.

FICHIERS

/etc/freeipmi//ipmidetectd.conf

SIGNALER LES BOGUES

Signaler les bogues à <freeipmi-users@gnu.org> ou <freeipmi-devel@gnu.org>.
