POSITIVE-INT [[63 ]] DESCRIPTION Un espace de noms réseau est logiquement une autre copie de la pile réseau, avec ses propres routes, règles de pare-feu et périphériques

réseau.

Par défaut, un processus hérite de l'espace de noms réseau de son parent. Initialement, tous les processus partagent le même espace de noms réseau par défaut issu du processus init. Par convention, un espace de noms réseau nommé est un objet

situé dans

/var/run/netns/ NOM qui peut être ouvert. Le descripteur de fichier résultant de l'ouverture de

/var/run/netns/

NOM fait référence à l'espace de noms réseau spécifié. Le fait de maintenir ce descripteur de fichier ouvert conserve l'espace de noms réseau actif. Le descripteur de fichier peut être utilisé avec l'appel système setns(2) [[73]] pour changer l'espace de noms réseau associé à une tâche. Pour les applications qui prennent en charge les espaces de noms réseau, la convention consiste à rechercher d'abord les fichiers de configuration réseau

globaux dans

/etc/netns/

NOM

ip netns exec automatise la gestion de cette convention de configuration de fichier pour les applications qui ne prennent pas en charge les espaces de noms réseau, en créant un espace de noms de montage et en montant par liaison tous les fichiers de configuration propres à chaque espace de noms réseau vers leur emplacement traditionnel dans /etc. ip netns list - afficher tous les espaces de noms réseau nommés Cette commande affiche tous les espaces de noms réseau dans

/var/run/netns

ip netns add NOM - créer un nouvel espace de noms réseau nommé Si NOM est disponible dans /var/run/netns, cette commande crée un nouvel espace de noms réseau et lui attribue NOM.ip netns attach NOM PID - attribuer un nom à l'espace de noms réseau du processus Si NOM est disponible dans /var/run/netns, cette commande attache l'espace de noms réseau du processus PID à NOM comme s'il avait été créé avec ip netns. ip [-all] netns delete [ NOM ] - supprimer le nom d'un ou plusieurs espaces de noms réseau Si NOM est présent dans /var/run/netns, il est démonté et le point de montage est supprimé. Si c'est le dernier utilisateur de l'espace de noms réseau, l'espace de noms réseau sera libéré et tous les périphériques physiques seront déplacés vers l'espace par défaut, sinon l'espace de noms réseau persiste jusqu'à ce qu'il n'ait plus d'utilisateurs. ip netns delete peut échouer si le point de montage est utilisé dans un autre espace de

Cette commande attribue un identifiant à un espace de noms réseau pair. Cet identifiant n'est valide que dans l'espace de noms réseau courant. Si le mot-clé « auto » est spécifié, un nsid disponible sera choisi. Cet identifiant sera utilisé par le noyau dans certains messages netlink. Si aucun identifiant n'est attribué lorsque le noyau en a besoin, il sera automatiquement attribué par le noyau. Une fois attribué, il n'est
pas possible de le changer.
ip netns identify [PID] - Signaler les noms des espaces de noms réseau d'un
processus
Cette commande parcourt /var/run/netns et trouve tous les noms d'espaces de noms réseau pour l'espace de noms réseau du processus spécifié. Si PID n'est pas spécifié, le processus courant sera
utilisé.
ip netns pids NOM - Signaler les processus dans l'espace de noms réseau
nommé
Cette commande parcourt proc et trouve tous les processus qui ont l'espace de noms réseau nommé comme leur espace de noms réseau
principal.
ip [-all] netns exec [ NOM ] cmd ... - Exécuter cmd dans l'espace de noms réseau
nommé
