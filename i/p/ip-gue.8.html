NOM

ip-fou - Configuration de port de réception Foo-over-UDP

ip-gue - Configuration de port de réception Generic UDP Encapsulation

SYNTAXE


ip [ OPTIONS ] fou { COMMANDE | help }

ip fou add port PORT { gue | ipproto PROTO } [ local IFADDR ] [ peer IFADDR ] [ peer_port PORT ] [ dev IFNAME ]
ip fou del port PORT [ local IFADDR ] [ peer IFADDR ] [ peer_port PORT ] [ dev IFNAME ]
ip fou show

DESCRIPTION

Les commandes ip fou sont utilisées pour créer et supprimer des ports de réception pour Foo-over-UDP (FOU) ainsi que Generic UDP Encapsulation (GUE).

Foo-over-UDP permet d'encapsuler des paquets d'un protocole IP directement sur UDP. Le récepteur déduit le protocole d'un paquet reçu sur un port UDP FOU comme étant le protocole configuré pour le port.

Generic UDP Encapsulation (GUE) encapsule des paquets d'un protocole IP au sein d'UDP et d'un en-tête d'encapsulation. L'en-tête d'encapsulation contient le numéro de protocole IP du paquet encapsulé.

Lors de la création d'un port de réception FOU ou GUE, le numéro de port est spécifié dans l'argument PORT. Si FOU est utilisé, le numéro de protocole IP associé au port est spécifié dans l'argument PROTO. Vous pouvez lier un port à une adresse/interface locale, en spécifiant l'adresse dans l'argument IFADDR local ou le périphérique dans l'argument IFNAME. Si vous souhaitez connecter le port, vous pouvez spécifier l'adresse du pair dans l'argument IFADDR peer et le port du pair dans l'argument PORT peer_port.

Un port de réception FOU ou GUE est supprimé en spécifiant le PORT dans la commande de suppression, ainsi que l'adresse/interface locale ou l'adresse/port du pair (si défini).

EXEMPLES

Configurer un port de réception FOU pour GRE lié au port 7777

# ip fou add port 7777 ipproto 47

Configurer un port de réception FOU pour IPIP lié au port 8888

# ip fou add port 8888 ipproto 4

Configurer un port de réception GUE lié au port 9999

# ip fou add port 9999 gue

Supprimer le port de réception GUE lié au port 9999

# ip fou del port 9999

Configurer un port de réception FOU pour GRE lié au port 1.2.3.4:7777

# ip fou add port 7777 ipproto 47 local 1.2.3.4
