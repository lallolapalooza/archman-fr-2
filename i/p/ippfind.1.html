CODES DESTATUTS

ippfind renvoie 0 si le résultat de toutes les expressions traitées est vrai, 1 si le résultat de l'une des expressions traitées est faux, 2 si la recherche ou toute interrogation ou résolution a échoué, 3 si une option non définie ou une expression invalide a été spécifiée, et 4 s'il est à court de mémoire.

ENVIRONNEMENT

Lors de l'exécution d'un programme, ippfind définit les variables d'environnement suivantes pour l'enregistrement du service correspondant :

IPPFIND_SERVICE_DOMAIN
Nom de domaine, par ex., « example.com. », « local. », etc.
IPPFIND_SERVICE_HOSTNAME
Nom de domaine qualifié, par ex., « printer.example.com. », « printer.local. », etc.
IPPFIND_SERVICE_NAME
Nom de l'instance de service, par ex., « My Fine Printer ».
IPPFIND_SERVICE_PORT
Numéro de port du serveur, généralement 631 pour IPP et 80 pour HTTP.
IPPFIND_SERVICE_REGTYPE
Type d'enregistrement DNS-SD, par ex., « _ipp._tcp », « _http._tcp », etc.
IPPFIND_SERVICE_SCHEME
Schéma d'URI pour le type d'enregistrement DNS-SD, par ex., « ipp », « http », etc.
IPPFIND_SERVICE_URI
URI du service, par ex., « ipp://printer.local./ipp/print », «http://printer.local./», etc.
IPPFIND_TXT_KEY
Valeurs de l'enregistrement TXT KEY (en majuscules).

EXEMPLES

Pour afficher le statut de toutes les imprimantes IPP enregistrées sur votre réseau, exécutez :

    ippfind --ls

De même, pour envoyer une page de test PostScript à chaque imprimante PostScript, exécutez :

    ippfind --txt-pdl application/postscript --exec ipptool
      -f onepage-letter.ps '{}' print-job.test \;
