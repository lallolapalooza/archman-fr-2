IPMIPING(8) Commandes Système IPMIPING(8)

NOM

ipmiping - envoie une requête IPMI Get Authentication Capability aux hôtes réseau

SYNTAXE

ipmiping [OPTION...] destination

DESCRIPTION

ipmiping utilise le datagramme de requête IPMI Get Channel Authentication Capabilities pour obtenir une réponse IPMI Get Channel Authentication Capabilitiesl d'un hôte distant. L'utilitaire peut être utilisé pour vérifier si un hôte distant prend en charge IPMI. Le numéro de séquence initial sera randomisé. ipmiping retournera 0 à l'environnement s'il reçoit au moins 1 réponse de l'hôte distant. Sinon, il se termine avec la valeur 1.

OPTIONS

Les options suivantes sont disponibles :

-h
Affiche le menu d'aide.
-V
Affiche la version.
-c nombre
Arrêter après l'envoi de nombre paquets.
-i intervalle
Attendre intervalle secondes entre l'envoi de chaque paquet. Par défaut, attendre une seconde entre chaque paquet.
-I adresse interface
Définir l'adresse source à l'adresse de l'interface spécifiée. L'argument peut être une adresse IP numérique ou le nom du périphérique.
-t délai
Temps d'attente d'une réponse, en secondes. Par défaut, cinq secondes.
-v
Affichage verbeux.
-s num
Spécifier un numéro de séquence initial. Par défaut, un numéro de séquence initial aléatoire est utilisé.
-d
Activer le débogage.
-r version
Spécifier la version IPMI. Les options disponibles sont "1.5" et "2.0". Par défaut, "1.5" est utilisé. Notez que les paquets seront toujours envoyés avec le protocole IPMI 1.5, mais les champs pertinents IPMI 1.5 vs IPMI 2.0 seront communiqués dans le datagramme Get Channel Authentication Capabilities en fonction du choix de l'utilisateur.

PROBLÈMES CONNUS

Il a été observé que certains BMC distants peuvent être "confus" et retarder les réponses aux paquets si des paquets dupliqués (avec des numéros de séquence dupliqués) sont envoyés successivement très rapidement. Il n'existe aucun moyen connu de gérer proprement un BMC "confus" autre que d'attendre un certain temps.

Contrairement à ping(8), les périphériques réseau locaux (par exemple, 127.0.0.1) ne peuvent pas être "pingués".
