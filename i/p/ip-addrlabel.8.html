NOM

ip-addrlabel - gestion des étiquettes d'adresses de protocole

SYNOPSIS


ip addrlabel { COMMANDE | help }

ip addrlabel { add | del } prefix PREFIX [ dev DEV ] [ label NUMBER ]

ip addrlabel { list | flush }

DESCRIPTION

Les étiquettes d'adresses IPv6 sont utilisées pour la sélection d'adresses ; elles sont décrites dans la RFC 3484. La priorité est gérée par l'espace utilisateur, et seule l'étiquette elle-même est stockée dans le noyau.

ip addrlabel add - ajouter une étiquette d'adresse

Ajoute une entrée d'étiquette d'adresse au noyau.

prefix PREFIX
dev DEV
l'interface de sortie.
label NUMBER
l'étiquette pour le préfixe. 0xffffffff est réservé.

ip addrlabel del - supprimer une étiquette d'adresse

Supprime une entrée d'étiquette d'adresse du noyau. Arguments : correspondent aux arguments de ip addrlabel add mais l'étiquette n'est pas requise.

ip addrlabel list - lister les étiquettes d'adresse

Liste les entrées actuelles d'étiquettes d'adresse dans le noyau.

ip addrlabel flush - vider les étiquettes d'adresse

Vide toutes les étiquettes d'adresse dans le noyau. Cela ne restaure aucun paramètre par défaut.
