DESCRIPTIO

N

Le programme ipmi_ui se connecte à un système IPMI et permet l'accès aux entités et capteurs IPMI ainsi qu'aux contrôles OpenIPMI. C'est plutôt brut, et principalement destiné à tester OpenIPMI, mais il a une certaine utilité au-delà de cela, il est donc

fourni.

Normalement, ipmi_ui démarre en mode plein écran. La fenêtre de gauche affiche la sortie des commandes, la fenêtre de droite affiche les journaux d'OpenIPMI. Les deux fenêtres sont défilables avec les touches page up et page down, appuyez sur la touche "F1" pour sélectionner la fenêtre de gauche pour le défilement, la touche "F2" pour sélectionner la fenêtre de droite pour le

défilement.

Notez que vous devez définir votre variable d'environnement TERM correctement pour votre terminal, sinon ipmi_ui affichera du texte incohérent à

l'écran.

Notez que vous pouvez mettre deux spécifications de connexion sur la ligne de commande, et ipmi_ui établira deux connexions. Vous ne pouvez le faire que si les connexions son

t vers le même domaine IPMI via différents contrôleurs de gestion. De plus, chaque connexion LAN peut avoir deux adresses IP. Ce sont deux adresses différentes vers le même co
ntrôleur de gestion. Vous pouvez donc avoir un total de 4 adresses IP vers un domaine IPMI, deux contrôleurs de gestion et deux adresses IP pour chaque contrôleur de gestion.

ÉVÉNEMENT

S

Les événements sont des messages asynchrones provenant des capteurs qui indiquent à l'utilisateur qu'un capteur a fait quelque chose. Les événements sont généralement stockés dans un journal d'événements du système (SEL) ; OpenIPMI récupérera les événements depuis les SEL du

système.

Comme il peut exister plusieurs SEL, un

EVENTS

An event is specified by the MC it came from in the format "(channel addr)" and a log number. The same log number may exist in multiple MCs.

Events are displayed in the log window as they come in. If they can be correlated with a sensor, they will be display with as much information as possible.

delevent channel mc-addr log-num
Delete the given event. Note that many SELs do not support individual deletes, so this may only delete the local copy of the event, not the one in the SEL. In this case, to delete events in the SEL, you must delete all the events in the SEL and wait about 10 seconds for OpenIPMI to do a full SEL clear.
clear_sel
Delete all events in the SEL. This process may take some time, so if you do this and quit immediately it may not be complete.
list_sel
List all events in the local copy of the SELs. This is only the local copy, if the copies in the actual have change, this won't be reflected.
get_sel_time channel mc-num
Get the time in the SEL for the given MC.

GESTIONNAIRES DE CONTRÔLE (MC)

Dans OpenIPMI, vous n'interagissez normalement pas directement avec les gestionnaires de contrôle. Ils sont considérés comme internes au système. Cependant, pour le débogage, des informations à leur sujet sont fournies.

mcs
Lister tous les MC du système et leur état d'activité. Les MC sont affichés au format "(adresse du canal)".
mc channel mc-addr
Afficher une grande quantité d'informations sur le MC, provenant principalement de la commande get device id.
mccmd channel mc-addr LUN NetFN Cmd [data ...]
Envoyer une commande IPMI au MC donné. Le MC doit exister et être actif pour effectuer cette opération.
mc_reset channel mc-addr [warm | cold]
Envoyer une commande de réinitialisation à chaud ou à froid au MC donné. L'action effectuée par le MC est spécifique au système.
scan channel mc-addr
Analyser le canal pour trouver un MC à l'adresse donnée. Si le MC existe mais qu'OpenIPMI ne le connaissait pas, il sera ajouté. S'il n'existe plus, il sera supprimé.
mc_events_enable channel mc-num enabled
Activer ou désactiver la génération d'événements pour le MC donné.
mc_events_enabled channel mc-num
Indique si les événements sont activés pour le MC donné.

CONFIGURATION DES PARAMÈTRES LAN

OpenIPMI offre des fonctions pour faciliter la configuration des paramètres LAN d'une connexion réseau. Notez que les paramètres LAN disposent d'un verrou qu'OpenIPMI tente d'utiliser. Si vous lisez les paramètres LAN, ils resteront verrouillés jusqu'à ce que vous les écriviez ou que vous déverrouilliez le verrou.

readlanparm channel mc-num channel
Lire les informations lanparm d'un MC et les afficher dans la fenêtre d'affichage.
viewlanparm
Afficher les informations lanparm actuelles dans la fenêtre d'affichage.
writelanparm channel mc-num channel
Écrire les informations LANPARM actuelles dans un MC. Notez que cela doit être le MC à partir duquel les paramètres ont été lus.
clearlanparmlock [channel mc-num channel]
Effacer un verrou LANPARM. Si le MC est spécifié, le verrou LANPARM est directement effacé. Sinon, le verrou LANPARM pour les paramètres actuels est effacé.
setlanparm config [selector] value
Définir l'élément de configuration donné à la valeur spécifiée. Le sélecteur optionnel est utilisé pour les éléments qui nécessitent un sélecteur, comme "auth" ou tout élément dans "destination".

FILTRE D'ÉVÉNEMENTS DE PLATEFORME (PEF)

OpenIPMI contient des fonctions pour aider à gérer les paramètres PEF d'un BMC. Notez que les paramètres PEF disposent d'un verrou qu'OpenIPMI tente d'utiliser. Si vous lisez les paramètres PEF, ils seront verrouillés jusqu'à ce que vous les écriviez ou que vous déverrouilliez le verrou.

readpef channel mc-num
Lire les informations PEF d'un MC.
clearpeflock [channel mc-num]
Effacer un verrou PEF. Si le MC est spécifié, le verrou PEF sur ce MC est directement effacé. Si aucun MC n'est spécifié, le verrou du PEF actuel est effacé.
viewpef
Afficher les informations PEF actuelles dans la fenêtre d'affichage.
writepef channel mc-num
Écrire les informations PEF actuelles dans un MC.
setpef config [selector] value
Définir l'élément de configuration donné à la valeur spécifiée. Le sélecteur optionnel est utilisé pour les éléments qui nécessitent un sélecteur, comme tout ce qui concerne les filtres d'événements, les politiques d'alerte ou les chaînes d'alerte.
pet connection channel ip-addr mac_addr eft-selector policy-num apt-selector lan-dest-selector
Configurer la connexion pour que le domaine envoie des pièges PET depuis la connexion donnée à l'adresse IP/MAC donnée via le canal donné. Ceci effectue toute la configuration LAN et PEF nécessaire pour configurer un système afin qu'il envoie des pièges d'événements.

CONNEXIONS

OpenIPMI peut maintenir plusieurs connexions à un seul domaine. Il n'en utilisera généralement qu'une à la fois (bien que l'autre soit constamment testée). C'est la connexion "active". Vous pouvez interroger et définir quelle connexion est active.

Le numéro de connexion est celui spécifié depuis la ligne de commande. Vous pouvez spécifier deux connexions sur la ligne de commande (la partie commençant par "lan", "smi", etc.). La première connexion que vous spécifiez est la connexion zéro, la seconde est la connexion 1.

is_con_active connection
Indique si la connexion donnée est active ou non.
activate_con connection
Active la connexion donnée.

AUTRES COMMANDES

msg channel IPMB-addr LUN NetFN Cmd [data ...]
Envoyer une commande IPMI à l'adresse IPMB donnée. Ceci est disponible au cas où le MC donné ne pourrait pas être trouvé ou activé.
sdrs channel mc-addr do-sensors
Dumps tous les sdrs du MC donné. Si do-sensors est true, alors dumper le SDR du périphérique. S'il est false, dumper le dépôt SDR principal sur le MC.
scan channel IPMB-addr
Effectuer un balayage du bus IPMB pour l'IPMB donné, afin d'essayer de détecter un MC à l'adresse donnée. Le balayage du bus IPMB peut être lent, cela peut aider à accélérer les choses si vous connaissez déjà l'adresse.
quit
Quitter le programme.
reconnect
Tenter de se déconnecter et de se reconnecter au contrôleur IPMI. Ceci est principalement à des fins de test.
display_win
Définir la fenêtre d'affichage (fenêtre de gauche) pour le défilement, au cas où la touche "F1" ne fonctionnerait pas.
log_win
Définir la fenêtre de journalisation (fenêtre de droite) pour le défilement, au cas où la touche "F2" ne fonctionnerait pas.
help
Afficher une aide concise sur toutes les commandes.
