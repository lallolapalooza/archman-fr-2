NOM

ipv6calc - formater, calculer, afficher des informations, filtrer des adresses IPv6/IPv4/MAC

SYNTAXE

ipv6calc [OPTIONS] [<données d'entrée>]

DESCRIPTION

Ce programme formate et calcule des adresses IPv6/IPv4/MAC et peut faire beaucoup d'autres choses complexes, par exemple, il inclut une capacité de filtre par canalisation.

OPTIONS

Si aucune donnée n'est présentée en tant qu'arguments de ligne de commande, les données sont lues depuis l'entrée standard.

Options générales :

[-d|--debug VALEUR_DEBUG]
valeur de débogage (type bitmask) peut également être définie par la valeur d'environnement IPV6CALC_DEBUG
[-v|--version [-v [-v]]]
informations de version (2 niveaux de détail optionnels)
[-v|--version -h]
explication des jetons de fonctionnalités
[-V|--verbose]
être plus verbeux
[-h|--help|-?]
cette aide en ligne

Options de base de données externe (en fonction du support compilé) :

[--db-ip2location-disable]
support IP2Location désactivé
[--db-ip2location-dir RÉPERTOIRE]
répertoire de la base de données IP2Location (défaut : /usr/share/IP2Location)
[--db-geoip-disable]
support GeoIP désactivé
[--db-geoip-dir RÉPERTOIRE]
répertoire de la base de données GeoIP (défaut : /usr/share/GeoIP)

Options spéciales :

[-q|--quiet]
être plus silencieux (activé automatiquement en mode canalisation)
[-f|--flush]
vider chaque ligne en mode canalisation

Utilisation avec les options de style nouveau :

[--in|-I TYPE-ENTRÉE]
spécifier le type d'entrée (défaut : autodétection)
[--out|-O TYPE-SORTIE]
spécifier le type de sortie (parfois : autodétection)
[--action|-A ACTION]
spécifier l'action (défaut : conversion de format, parfois : autodétection)
[<option de format> ...]
spécifier les options de format
<données d'entrée> [...]
données d'entrée
Types d'entrée disponibles :
[-m] -I|--in -?|-h|--help
Types de sortie disponibles :
[-m] -O|--out -?|-h|--help
Types d'action disponibles :
[-m] -A|--action -?|-h|--help


Autre utilisation :

--showinfo|-i [--machine_readable|-m]
afficher des informations sur les données d'entrée
--showinfo|-i --show_types
afficher les types disponibles sur '-m'

Utilisation avec des options de raccourci : <option de raccourci> [<option de format> ...] <données d'entrée>

Pour plus d'informations et les options de format disponibles, utiliser  : <option de raccourci> -?|-h|--help

-r|--addr2ip6_int (-O revnibbles.int)

-r|--addr_to_ip6int (-O revnibbles.int)

-a|--addr2ip6_arpa (-O revnibbles.arpa)

-a|--addr_to_ip6arpa (-O revnibbles.arpa)

-b|--addr_to_bitstring (-O bitstring)

--addr2compaddr (--printcompressed)

--addr_to_compressed (--printcompressed)

--addr2uncompaddr (--printuncompressed)

--addr_to_uncompressed (--printuncompressed)

--addr_to_base85 (-I ipv6addr -O base85)

--base85_to_addr (-I base85 -O ipv6addr)

--mac_to_eui64 (-I mac -O eui64)

--addr2fulluncompaddr (--printfulluncompressed)

--addr_to_fulluncompressed (--printfulluncompressed)

--addr2if_inet6 (-I ipv6addr -O ifinet6)

--addr_to_ifinet6 (-I ipv6addr -O ifinet6)

--if_inet62addr (-I ifinet6 -O ipv6addr --printcompressed)

--ifinet6_to_compressed (-I ifinet6 -O ipv6addr --printcompressed)

--eui64_to_privacy (-I iid_token -O iid_token -A genprivacyiid)

--ipv4_to_6to4addr (-I ipv4 -O ipv6addr -A conv6to4)

Voir l'aide en ligne ou la documentation pour plus d'informations.

EXEMPLES

Pour exécuter ce programme de la manière standard, tapez :

ipv6calc --showinfo -i -m ::1

ipv6calc --showinfo -m 127.0.0.1

ipv6calc --showinfo --show_types

ipv6calc --ipv4_to_6to4addr 127.0.0.1

ipv6calc --addr_to_uncompressed ::1

Utilisation des filtres en mode canalisation :

cat <FichierJournalApache> | ipv6calc -E ipv6.db.cc=US,iid-random
