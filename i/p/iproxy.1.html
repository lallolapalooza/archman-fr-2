iproxy(1) Manuel des commandes générales iproxy(1)

NOM

iproxy - Un proxy qui lie les ports TCP locaux pour les rediriger vers les ports spécifiés sur un périphérique usbmux

SYNTAXE

iproxy [OPTIONS] PORT_LOCAL:PORT_APPAREIL [PORT_LOCAL2:PORT_APPAREIL2 ...]

DESCRIPTION

iproxy permet de lier des ports TCP locaux de sorte qu'une connexion à l'un (ou plusieurs) des ports locaux soit redirigée vers le port (ou les ports) spécifié(s) sur un périphérique usbmux.

OPTIONS

-u, --udid UDID
Cible un périphérique spécifique par UDID. Notez que si cette option n'est pas spécifiée, iproxy tentera de se connecter au premier périphérique trouvé.
-n, --network
Se connecter à un périphérique réseau. Le périphérique doit avoir la synchronisation WiFi activée et doit être appairé avec cet ordinateur pour que cela fonctionne. Notez qu'un périphérique peut fermer les connexions à tout moment pour économiser de l'énergie. Cette option fera en sorte qu'iproxy tente de se connecter uniquement aux périphériques connectés par réseau, à moins que -l ne soit également passé (voir ci-dessous).
-l, --local
Se connecter à un périphérique USB. C'est le comportement par défaut si aucune option n'est spécifiée. Si utilisé avec -n, iproxy tentera d'abord une connexion à un périphérique connecté via USB, et si celui-ci n'est pas disponible, tentera d'atteindre un périphérique via le réseau.
-s, --source ADDR
Permet de définir une adresse source pour le socket d'écoute. Par défaut, c'est 127.0.0.1 (connexions locales uniquement). Bien que cela ne soit pas nécessaire dans les configurations normales, cette option permet des connexions autres que locales, par exemple 0.0.0.0 rendrait le(s) port(s) proxy TCP accessible(s) depuis d'autres ordinateurs du réseau.

ATTENTION : À utiliser avec prudence, car cela pourrait exposer un périphérique sur le réseau !

-h, --help
Affiche les informations d'utilisation.
-d, --debug
Augmente le niveau de débogage.

EXEMPLES

iproxy 2222:44
Lie le port TCP local 2222 et le redirige vers le port 44 du premier périphérique connecté via USB.
iproxy -u 3fac232fbdd684bdb1e3b65973922ae8b7db174a 2222:44
Lie le port TCP local 2222 et le redirige vers le port 44 du périphérique avec l'UDID 3fac232fbdd684bdb1e3b65973922ae8b7db174a connecté via USB.
iproxy -n -u 3fac232fbdd684bdb1e3b65973922ae8b7db174a 2222:44 8080:8080
Lie les ports TCP locaux 2222 et 8080 et les redirige vers les ports 44 et 8080 respectivement du périphérique avec l'UDID 3fac232fbdd684bdb1e3b65973922ae8b7db174a connecté via le réseau.
