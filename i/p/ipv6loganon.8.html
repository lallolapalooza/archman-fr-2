DESCRIPTIO

N

Ce programme anonymise les adresses IPv4/IPv6 dans les fichiers de journal du serveur

HTTP

Prend les données de stdin, les traite et les écrit sur

stdout.

Selon la méthode d'anonymisation, les parties de l'adresse (préfixe/identifiant d'interface)

sont

1. simplement mises à zéro par les masques

donnés.

2. anonymisées en mettant à zéro uniquement les bits requis (partiellement en fonction des masques spécifiés)

.

3. anonymisées en essayant de conserver pour les adresses IPv4 et IPv6 (keep-type-asn-cc

)

Lors de la mise à zéro uniquement des bits requis (mode 2), les possibilités sont

:
IID
:
EUI-48/64
:
le numéro de série serait mis à zéro, en conservant l'OID ISATAP : l'adresse IPv4 du client serait anonymisée par le masque IPv4 donné TEREDO : l'adresse IPv4 du client serait anonymisée par le masque IPv4 donné, le port du client serait mis à
zéro
6to4(Microsoft)
:
l'adresse IPv4 du client serait anonymisée par le masque IPv4
donné
local
:
tout l'IID serait mis à zéro (sauf
si l'extension de confidentialité a
été détectée, auquel cas il est
remplacé par un jeton spécial)
Préfixe
:
Les adresses IPv6, y compris l'adre
sse IPv4 du client, seront anonymi
sées par le masque IPv4 donné

Lors de l'anonymisation avec keep (mode 3), les champs pertinents sont : le type d'adresse, le numéro de système autonome (ASN) et le code pays (CC

)

Cette méthode nécessite une résolution d'adresses IPv4/IPv6 vers les codes pays et les ASN, fournie par

GeoIP

Grand avantage : le résultat de ipv6logstats(8) devrait être identique à celui des données

brutes

Les adresses IPv4 anonymisées proviennent de la plage expérimentale 240.0.0.

0/8

Les adresses IPv6 anonymisées utilisent le préfixe (actuellement détourné) a909::

/16

L'IID IPv6 anonymisé commence par a9x9 (x = nibbles

anonymis
és du SLA)
