NOM

ip-stats - gérer et afficher les statistiques d'interface

SYNTAXE


ip stats { COMMANDE | help }

ip stats show [ dev DEV ] [ group GROUPE [ subgroup SOUS_GROUPE [ suite SUITE ] ... ] ... ] ...

ip stats set dev DEV l3_stats { on | off }

DESCRIPTION

ip stats set
est utilisé pour activer ou désactiver la collecte d'une certaine suite de statistiques matérielles sur un netdevice donné. Les suites de statistiques suivantes sont supportées :


l3_stats Les statistiques L3 reflètent le trafic qui se produit dans un périphérique matériel sur un objet correspondant au netdevice logiciel donné.

ip stats show
est utilisé pour afficher les statistiques sur un netdevice donné, ou pour vider les statistiques sur tous les netdevices. Par défaut, toutes les statistiques sont demandées. Il est possible de filtrer les statistiques demandées en utilisant les mots-clés group et subgroup.

Il est possible de spécifier plusieurs groupes, ou plusieurs sous-groupes pour un groupe. Lorsqu'aucun sous-groupe n'est donné pour un groupe, tous les sous-groupes sont demandés.

Les groupes suivants sont reconnus :

group link - Statistiques de liaison. La même suite que celle affichée par « ip -s link show ».

group offload - Un groupe contenant un certain nombre de statistiques orientées matériel. Voir ci-dessous pour les sous-groupes individuels de ce groupe.

group xstats - Statistiques étendues. Un sous-groupe identifie le type de netdevice pour lequel afficher les statistiques.

group xstats_slave - Statistiques étendues pour l'esclave d'un netdevice d'un type donné. Un sous-groupe identifie le type de netdevice maître.

group afstats - Un groupe pour les statistiques de netdevice spécifiques à une famille d'adresses.

sous-groupes group offload :

subgroup cpu_hit - La suite de statistiques cpu_hit est utile sur les périphériques réseau matériels. Les statistiques link sur ces périphériques reflètent le trafic de la dataplane matérielle et logicielle. Les statistiques cpu_hit ne reflètent alors que le trafic de la dataplane logicielle.

subgroup hw_stats_info - Cette suite n'inclut pas de statistiques de trafic, mais communique l'état d'autres statistiques. Grâce à ce sous-groupe, il est possible de découvrir si une statistique donnée a été activée, et si c'est le cas, si un pilote de périphérique a réellement configuré son périphérique pour collecter ces statistiques. Par exemple, l3_stats a été activé dans le cas suivant, mais aucun pilote ne l'a installé :

# ip stats show dev swp1 group offload subgroup hw_stats_info
56: swp1: group offload subgroup hw_stats_info
l3_stats on used off

Après qu'une adresse L3 a été ajoutée au netdevice, le compteur sera installé :

# ip addr add dev swp1 192.0.2.1/28
# ip stats show dev swp1 group offload subgroup hw_stats_info
56: swp1: group offload subgroup hw_stats_info
l3_stats on used on

subgroup l3_stats - Ces statistiques reflètent le trafic L3 qui se produit en matériel sur un objet correspondant au netdevice. Notez que cette suite est désactivée par défaut et doit d'abord être activée via ip stats set.

Par exemple :

# ip stats show dev swp2.200 group offload subgroup l3_stats
112: swp2.200: group offload subgroup l3_stats on used on
RX: bytes packets errors dropped mcast
8900 72 2 0 3
TX: bytes packets errors dropped
7176 58 0 0

Notez comment les l3_stats_info pour le groupe sélectionné font également partie du vidage.

sous-groupes group xstats et group xstats_slave :

subgroup bridge - Diverses statistiques sur les ponts et leurs esclaves.

suite stp - Statistiques STP
suite mcast - Statistiques IGMP / MLD
suite vlan - Statistiques de trafic par VLAN

subgroup bond [ suite 802.3ad ] - Statistiques pour le trafic LACP sur les périphériques bond et leurs esclaves.

sous-groupes group afstats :

subgroup mpls - Statistiques pour le trafic MPLS vu sur le netdevice. Par exemple :

# ip stats show dev veth01 group afstats subgroup mpls
3: veth01: group afstats subgroup mpls
RX: bytes packets errors dropped noroute
0 0 0 0 0
TX: bytes packets errors dropped
216 2 0 0

EXEMPLES

# ip stats set dev swp1 l3_stats on

Active la collecte des statistiques L3 matérielles sur swp1.

# ip stats show group offload

Affiche toutes les statistiques d'offload sur tous les netdevices.

# ip stats show dev swp1 group link

Affiche les statistiques de liaison sur le netdevice donné.
