NOM

ip-sr - Gestion du routage par segments IPv6

SYNTAXE


ip sr { COMMANDE | help }

ip sr hmac show

ip sr hmac set KEYID ALGO

ip sr tunsrc show

ip sr tunsrc set ADDRESS

DESCRIPTION

La commande ip sr est utilisée pour configurer les paramètres internes du routage par segments IPv6 (SRv6).

Ces paramètres incluent la correspondance entre un ID de clé HMAC et son algorithme de hachage et secret associés, ainsi que l'adresse IPv6 à utiliser comme source pour les paquets encapsulés.

La commande ip sr hmac set demande une "phrase secrète" terminée par un retour à la ligne qui sera utilisée comme secret HMAC pour l'ID de clé correspondant. Cette "phrase secrète" n'est pas étirée et est utilisée directement comme clé HMAC. Par conséquent, elle doit avoir suffisamment d'entropie pour être utilisée comme clé. Par exemple, une utilisation correcte serait d'utiliser une phrase secrète générée avec head -c 32 /dev/random | base64 -w 0.

Une "phrase secrète" vide supprime la correspondance.

Les algorithmes actuellement supportés pour ALGO sont sha1 et sha256.

Si la source du tunnel est définie à l'adresse :: (qui est la valeur par défaut), alors une adresse de l'interface de sortie sera sélectionnée. Comme cette opération peut nuire aux performances, il est recommandé de définir une adresse non par défaut.

EXEMPLES

Configurer une correspondance HMAC pour l'ID de clé 42 et l'algorithme de hachage SHA-256

# ip sr hmac set 42 sha256

Définir l'adresse source du tunnel à 2001:db8::1

# ip sr tunsrc set 2001:db8::1

BOGUES

ip sr hmac set n'étire pas la phrase secrète.
