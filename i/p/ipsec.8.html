NOM

ipsec - invoquer les utilitaires IPsec

SYNTAXE

ipsec commande [arguments] [options]

DESCRIPTION

L'utilitaire ipsec invoque plusieurs utilitaires impliqués dans le contrôle et la surveillance du système de chiffrement/authentification IPsec, en exécutant la commande spécifiée avec les arguments et les options comme s'ils avaient été invoqués directement. Cela élimine en grande partie les possibles collisions de noms avec d'autres logiciels et permet également certains services centralisés.

Toutes les commandes décrites dans cette page de manuel sont intégrées et utilisées pour contrôler et surveiller les connexions IPsec ainsi que le démon IKE.

Pour les autres commandes, ipsec fournit à la commande invoquée une variable d'environnement PATH appropriée, et fournit également les variables d'environnement listées sous ENVIRONNEMENT.

COMMANDES DE CONTRÔLE

start [options de démarrage]
appelle starter qui analyse ipsec.conf et démarre le démon IKE charon.
update
envoie un signal HUP à starter qui détermine ensuite les changements dans ipsec.conf et met à jour la configuration sur le démon IKE charon en cours d'exécution.
reload
envoie un signal USR1 à starter qui recharge ensuite toute la configuration du démon IKE charon en cours d'exécution en fonction du ipsec.conf actuel.
restart
équivaut à stop suivi de start après un délai de garde de 2 secondes.
stop
arrête toutes les connexions IPsec et arrête le démon IKE charon en envoyant un signal TERM à starter.
up nom
indique au démon IKE de démarrer la connexion nom.
down nom
indique au démon IKE de terminer la connexion nom.
down nom{n}
arrête l'instance de SA ENFANT IKEv1 en mode rapide et IKEv2 n de la connexion nom.
down nom{*}
arrête toutes les instances de SA ENFANT IKEv1 en mode rapide et IKEv2 de la connexion nom.
down nom[n]
arrête l'instance de SA IKE n de la connexion nom.
down nom[*]
arrête toutes les instances de SA IKE de la connexion nom.
down-srcip <début> [<fin>]
arrête toutes les instances de SA IKE avec des clients ayant des IP virtuelles dans la plage début-fin.
route nom
indique au démon IKE d'insérer une politique IPsec dans le noyau pour la connexion nom. Le premier paquet de charge utile correspondant à la politique IPsec déclenchera automatiquement la mise en place d'une connexion IKE.
unroute nom
supprime la politique IPsec dans le noyau pour la connexion nom.
status [nom]
renvoie des informations d'état concises soit sur la connexion nom, soit, si l'argument est absent, sur toutes les connexions.
statusall [nom]
renvoie des informations d'état détaillées soit sur la connexion nom, soit, si l'argument est absent, sur toutes les connexions.

COMMANDES DE LISTE

leases [<nom_pool> [<adresse>]]
renvoie l'état de tout le pool d'adresses IP sélectionné ou de l'adresse IP virtuelle unique.
listalgs
renvoie une liste des algorithmes cryptographiques pris en charge utilisables pour IKE, et leur plugin correspondant.
listpubkeys [--utc]
renvoie une liste des clés publiques RSA qui ont été chargées au format clé brute ou extraites de certificats X.509 et/ou OpenPGP.
listcerts [--utc]
renvoie une liste des certificats X.509 et/ou OpenPGP qui ont été chargés localement par le démon IKE ou reçus via le protocole IKE.
listcacerts [--utc]
renvoie une liste des certificats d'Autorité de Certification (CA) X.509 qui ont été chargés localement par le démon IKE depuis le répertoire /etc/ipsec.d/cacerts/ ou reçus via le protocole IKE.
listaacerts [--utc]
renvoie une liste des certificats d'Autorité d'Autorisation (AA) X.509 qui ont été chargés localement par le démon IKE depuis le répertoire /etc/ipsec.d/aacerts/.
listocspcerts [--utc]
renvoie une liste des certificats de signataire OCSP X.509 qui ont été chargés localement par le démon IKE depuis le répertoire /etc/ipsec.d/ocspcerts/ ou ont été envoyés par un serveur OCSP.
listacerts [--utc]
renvoie une liste des certificats d'attributs X.509 qui ont été chargés localement par le démon IKE depuis le répertoire /etc/ipsec.d/acerts/.
listgroups [--utc]
renvoie une liste des groupes utilisés pour définir les profils d'autorisation des utilisateurs.
listcainfos [--utc]
renvoie des informations sur l'autorité de certification (points de distribution CRL, URI OCSP, serveurs LDAP) définies par les sections ca dans ipsec.conf.
listcrls [--utc]
renvoie une liste des listes de révocation de certificats (CRL) qui ont été chargées par le démon IKE depuis le répertoire /etc/ipsec.d/crls ou récupérées depuis un point de distribution CRL basé sur HTTP ou LDAP.
listocsp [--utc]
renvoie les informations de révocation récupérées auprès des serveurs OCSP.
listplugins
renvoie une liste de toutes les fonctionnalités de plugin chargées.
listcounters [nom]
renvoie une liste des valeurs de compteur IKE globales ou spécifiques à la connexion collectées depuis le démarrage du démon.
listall [--utc]
renvoie toutes les informations générées par les commandes de liste ci-dessus. Chaque commande de liste peut être appelée avec l'option --utc qui affiche toutes les dates en UTC au lieu de l'heure locale.

COMMANDES DE RELISURE

rereadsecrets
vide et relit tous les secrets définis dans ipsec.secrets.
rereadcacerts
supprime les certificats CA chargés précédemment, lit tous les fichiers de certificat contenus dans le répertoire /etc/ipsec.d/cacerts et les ajoute à la liste des certificats d'Autorité de Certification (CA). Cela n'affecte pas les certificats explicitement définis dans une section ca de ipsec.conf(5), qui peuvent être mis à jour séparément à l'aide de la commande update.
rereadaacerts
supprime les certificats AA chargés précédemment, lit tous les fichiers de certificat contenus dans le répertoire /etc/ipsec.d/aacerts et les ajoute à la liste des certificats d'Autorité d'Autorisation (AA).
rereadcerts
supprime les certificats chargés précédemment, lit tous les fichiers de certificat contenus dans le répertoire /etc/ipsec.d/certs et les ajoute à la liste des certificats locaux.
rereadacerts
supprime les certificats d'attributs chargés précédemment, lit tous les fichiers de certificat contenus dans le répertoire /etc/ipsec.d/acerts et les ajoute à la liste des certificats d'attributs locaux.
rereadcrls
supprime les listes de révocation de certificats (CRL) chargées précédemment, lit tous les fichiers CRL contenus dans le répertoire /etc/ipsec.d/crls et les ajoute à la liste des CRL connues.
rereadocspcerts
supprime les certificats de signataire OCSP chargés précédemment, lit tous les fichiers de certificat contenus dans le répertoire /etc/ipsec.d/ocspcerts et les ajoute à la liste des certificats de signataire OCSP.
rereadgroups
supprime les groupes chargés précédemment, lit tous les groupes à partir des sections group dans ipsec.conf et les ajoute à la liste des groupes connus.
rereadall
exécute toutes les commandes reread* listées ci-dessus.

COMMANDES DIVERSES

setup
est un script shell qui est appelé au démarrage du système pour lancer IPsec. Il appelle la commande ipsec start.
initiate [connection]
déclenche une connexion IKE pour la connexion spécifiée, ou pour toutes les connexions si aucune n'est spécifiée. C'est l'inverse de la commande down.
create-certs
crée des certificats auto-signés pour les autorités de certification et les clés privées/publiques des pairs pour la configuration de test.
stroke-server
lance le démon stroke qui écoute les commandes de l'utilitaire ipsec.
getlog
récupère le journal du démon charon.
logrotate
fait pivoter le journal du démon charon. Applicable uniquement si logrotate est utilisé pour la rotation.
help [command]
affiche des informations d'aide pour toutes les commandes ou pour la commande spécifiée.

ENVIRONNEMENT

Les commandes ipsec peuvent définir les variables d'environnement suivantes.

IPSEC_CONFIG
Définit le répertoire où sont stockés les fichiers de configuration.
IPSEC_LOGDIR
Définit le répertoire pour les journaux.
IPSEC_PIDDIR
Définit le répertoire pour les fichiers PID.
IPSEC_RCDIR
Définit le répertoire pour les scripts de démarrage/arrêt.
IPSEC_CONFFILE
Définit le chemin vers le fichier de configuration ipsec.conf.
IPSEC_SECRETSFILE
Définit le chemin vers le fichier de configuration ipsec.secrets.

Il est possible de spécifier une autre valeur que celles par défaut en appelant ipsec avec le nom de la commande souhaitée et les options appropriées. Par exemple, pour utiliser un fichier de configuration différent :

ipsec --config /path/to/my/ipsec.conf start

VOIR AUSSI

ipsec.conf(5), ipsec.secrets(5), charon(8), starter(8)
