IPVSADM-SAVE(8) Guide d'administration Linux IPVSADM-SAVE(8)

NOM

ipvsadm-save - sauvegarde la table IPVS sur la sortie standard

SYNTAXE

ipvsadm-save [-n]

DESCRIPTION

ipvsadm-save affiche la table IPVS sur la sortie standard.

OPTIONS

L'option reconnue par ipvsadm-save est :

-n
affiche la table au format numérique.

VOIR AUSSI

ipvsadm(8), le LVS-HOWTO.
