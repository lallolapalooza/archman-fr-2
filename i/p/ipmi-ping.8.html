IPMIPING(8) Commandes système IPMIPING(8)

NOM

ipmiping - envoie une requête IPMI Get Authentication Capability aux hôtes du réseau

SYNTAXE

ipmiping [OPTION...] destination

DESCRIPTION

ipmiping utilise le datagramme de requête IPMI Get Channel Authentication Capabilities pour obtenir une réponse IPMI Get Channel Authentication Capabilities d'un hôte distant. L'utilitaire peut être utilisé pour vérifier si un hôte distant prend en charge IPMI. Le numéro de séquence initial sera aléatoire. ipmiping retournera 0 à l'environnement s'il reçoit au moins une réponse de l'hôte distant. Sinon, il se terminera avec la valeur 1.

OPTIONS

Les options suivantes sont disponibles :

-h
Affiche le menu d'aide.
-V
Affiche la version.
-c nombre
Arrête après l'envoi de nombre paquets.
-i intervalle
Attend intervalle secondes entre l'envoi de chaque paquet. Par défaut, une seconde est attendue entre chaque paquet.
-I adresse d'interface
Définit l'adresse source à l'adresse d'interface spécifiée. L'argument peut être une adresse IP numérique ou le nom d'un périphérique.
-t délai
Temps d'attente d'une réponse, en secondes. Par défaut, cinq secondes.
-v
Sortie verbeuse.
-s num
Spécifie un numéro de séquence de départ initial. Par défaut, un numéro de séquence initial aléatoire est utilisé.
-d
Active le débogage.
-r version
Spécifie la version IPMI. Les options disponibles sont « 1.5 » et « 2.0 ». Par défaut, utilise « 1.5 ». Notez que les paquets seront toujours envoyés avec le protocole IPMI 1.5, mais les champs pertinents IPMI 1.5 vs IPMI 2.0 seront communiqués dans le datagramme Get Channel Authentication Capabilities en fonction du choix de l'utilisateur.

PROBLÈMES CONNUS

Il a été observé que certains BMC distants peuvent être « confus » et retarder les réponses aux paquets si des paquets dupliqués (avec des numéros de séquence dupliqués) sont envoyés en succession très rapide. Il n'existe aucun moyen connu de gérer proprement un BMC « confus » autre que d'attendre un certain temps.

Contrairement à ping(8), les périphériques réseau locaux (par exemple 127.0.0.1) ne peuvent pas être « ping ».
