NOM

iptunnel - crée, modifie, supprime et affiche les tunnels configurés

SYNTAXE

iptunnel [<opération>] [<arguments>]

NOTE

Ce programme est obsolète. Veuillez utiliser ip tunnel à la place, et consulter ip-tunnel(8) pour plus d'informations.

DESCRIPTION

La commande iptunnel crée des tunnels configurés pour envoyer et recevoir des paquets IPv6 ou IPv4 qui sont encapsulés comme charge utile d'un datagramme IPv4.

La commande iptunnel peut effectuer l'une des opérations suivantes :

create - crée une interface de tunnel, que vous devez ensuite configurer.

change - modifie une interface de tunnel existante.

delete - supprime une interface de tunnel. Vous devez désactiver le tunnel avant de pouvoir le supprimer.

show - affiche les attributs du tunnel (nom, points d'extrémité du tunnel, prochaine passerelle pour les paquets tunnellisés).

VOIR AUSSI

ip-tunnel(8), ip(8)
