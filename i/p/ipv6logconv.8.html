NOM

ipv6logconv - convertisseur de fichiers journaux de serveurs HTTP pour les statistiques

SYNTAXE

cat /var/log/httpd/access_log | ipv6logconv [OPTIONS]

DESCRIPTION

Ce programme convertit les adresses IPv4/IPv6 dans les fichiers journaux de serveurs HTTP.

La sortie convertie peut être utilisée pour créer des statistiques avec analog.

Prend des données depuis stdin, les traite vers stdout.

OPTIONS

Options générales :

[-d|--debug VALEUR_DEBUG]
valeur de débogage (type bitwise), peut également être définie par la valeur d'environnement IPV6CALC_DEBUG.
[-v|--version [-v [-v]]]
informations de version (2 niveaux de détail optionnels).
[-v|--version -h]
explication des jetons de fonctionnalité.
[-V|--verbose]
soyez plus verbeux.
[-h|--help|-?]
aide en ligne.

Options de performance :

[-n|--nocache]
désactive la mise en cache.
[-c|--cachelimit VALEUR]
définit la limite de cache ; par défaut : 20, maximum : 200.

Options de sortie :

[--out TYPEDESORTIE]
Spécifie le type de sortie :
addrtype
Type d'adresse.
ouitype
Type OUI (IEEE).
ipv6addrtype
Type d'adresse IPv6.
any
tous types.
