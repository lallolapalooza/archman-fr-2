IPSET-TRANSLATE(8) Manuel de l'administrateur système IPSET-TRANSLATE(8)

NOM

ipset-translate — outil de traduction pour migrer d'ipset vers nftables

DESCRIPTION

Cet outil permet aux administrateurs système de traduire un fichier de jeux d'adresses IP donné vers nftables(8).

La seule commande disponible est :

•
ipset-translate restore < fichier.ipt

UTILISATION

L'outil ipset-translate lit un fichier de jeux d'adresses IP dans la syntaxe produite par la commande ipset(8) save. Aucune modification de jeu n'est effectuée, cet outil est un convertisseur de texte.

EXEMPLES

Exemples d'utilisation de base.

Traduction d'une seule commande, en supposant le fichier d'origine :

create test1 hash:ip,port family inet counters timeout 300 hashsize 1024 maxelem 65536 bucketsize 12 initval 0xb5c4be5d
add test1 1.1.1.1,udp:20
add test1 1.1.1.1,21
create test2 hash:ip,port family inet hashsize 1024 maxelem 65536 bucketsize 12 initval 0xb5c4be5d

Ce qui donne la traduction suivante :

root@machine:~# ipset-translate restore < fichier.ipt
add set inet global test1 { type ipv4_addr . inet_proto . inet_service; counter; timeout 300s; size 65536; }
add element inet global test1 { 1.1.1.1 . udp . 20 }
add element inet global test1 { 1.1.1.1 . tcp . 21 }
add set inet global test2 { type ipv4_addr . inet_proto . inet_service; size 65536; }

LIMITATIONS

Certaines options des jeux d'adresses IP peuvent ne pas être prises en charge car elles ne sont pas encore implémentées dans nftables(8).

Contrairement à nftables(8), les jeux d'adresses IP ne sont pas attachés à une table spécifique. L'utilitaire de traduction suppose que les jeux sont créés dans une table nommée global et de famille inet. Vous pourriez vouloir mettre à jour la traduction résultante pour utiliser un nom de table et une famille différents pour vos jeux.

Pour obtenir des informations à jour à ce sujet, veuillez consulter https://wiki.nftables.org/.
