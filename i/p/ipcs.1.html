IPCS(1) Commandes utilisateur IPCS(1)

NOM

ipcs - afficher des informations sur les facilités IPC

SYNTAXE

ipcs [options]

DESCRIPTION

ipcs affiche des informations sur les facilités de communication inter-processus System V. Par défaut, il affiche des informations sur les trois ressources : segments de mémoire partagée, files de messages et tableaux de sémaphores.

OPTIONS

-i, --id id

Affiche les détails complets sur un seul élément de ressource identifié par id. Cette option doit être combinée avec l'une des trois options de ressources : -m, -q ou -s.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

Options de ressources

-m, --shmems

Affiche des informations sur les segments de mémoire partagée actifs.

-q, --queues

Affiche des informations sur les files de messages actives.

-s, --semaphores

Affiche des informations sur les tableaux de sémaphores actifs.

-a, --all

Affiche des informations sur les trois ressources (par défaut).

Formats de sortie

Parmi ces options, une seule prend effet : la dernière spécifiée.

-c, --creator

Affiche le créateur et le propriétaire.

-l, --limits

Affiche les limites de ressources.

-p, --pid

Affiche les PID du créateur et du dernier opérateur.

-t, --time

Affiche les informations temporelles. L'heure de la dernière opération de contrôle ayant modifié les permissions d'accès pour toutes les facilités, l'heure des dernières opérations msgsnd(2) et msgrcv(2) sur les files de messages, l'heure des dernières opérations shmat(2) et shmdt(2) sur la mémoire partagée, et l'heure de la dernière opération semop(2) sur les sémaphores.

-u, --summary

Affiche un résumé de l'état.

Représentation

Celles-ci affectent uniquement l'option -l (--limits).

-b, --bytes

Affiche les tailles en octets plutôt que dans un format lisible par l'homme.

Par défaut, l'unité dans laquelle les tailles sont exprimées est l'octet, et les préfixes d'unité sont en puissance de 2^10 (1024). Les abréviations des symboles sont tronquées afin d'améliorer la lisibilité, en affichant seule la première lettre ; exemples : "1 KiB" et "1 MiB" sont respectivement affichés sous forme de "1 K" et "1 M", omettant ainsi volontairement la mention "iB", qui fait partie de ces abréviations.

--human

Affiche les tailles dans un format lisible par l'homme.

CONFORMITÉ

L'utilitaire ipcs de Linux n'est pas entièrement compatible avec l'utilitaire ipcs POSIX. La version Linux ne prend pas en charge les options POSIX -a, -b et -o, mais prend en charge les options -l et -u non définies par POSIX. Une application portable ne doit pas utiliser les options -a, -b, -o, -l et -u.

NOTES

L'implémentation actuelle de ipcs obtient des informations sur les ressources IPC disponibles en analysant les fichiers dans /proc/sysvipc. Avant la version v2.23 d'util-linux, un mécanisme alternatif était utilisé : la commande IPC_STAT de msgctl(2), semctl(2) et shmctl(2). Ce mécanisme est également utilisé dans les versions ultérieures d'util-linux dans le cas où /proc n'est pas disponible. Une limitation du mécanisme IPC_STAT est qu'il ne peut être utilisé que pour récupérer des informations sur les ressources IPC pour lesquelles l'utilisateur a la permission de lecture.
