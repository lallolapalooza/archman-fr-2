NOM

ipmidetectd.conf - Fichier de configuration de ipmidetectd

DESCRIPTION

Le fichier de configuration ipmidetectd.conf configure le démon ipmidetectd.

Le fichier de configuration par défaut chargé est /etc/freeipmi//ipmidetectd.conf.

Les options de configuration qui peuvent être spécifiées dans le fichier de configuration sont listées ci-dessous. Chaque option de configuration doit être listée sur une ligne séparée. Les arguments d'une option sont séparés par n'importe quelle quantité d'espaces blancs. Plusieurs arguments sont également séparés par des espaces blancs. Les commentaires peuvent être marqués en utilisant le caractère dièse (« # »), et les lignes peuvent être continuées sur la suivante en utilisant la barre oblique inverse (« \ »).

IPMIDETECTD OPTIONS DE CONFIGURATION

ipmiping_period num
Spécifiez la période en millisecondes pendant laquelle les pings IPMI doivent être envoyés régulièrement. La valeur par défaut est 15000.
ipmidetectd_server_port port
Spécifiez le port par défaut alternatif sur lequel le serveur ipmidetectd doit écouter les requêtes. La valeur par défaut est 9225.
host chaîne[:port]
Spécifiez un hôte ou une adresse IP auquel le démon ipmidetectd doit envoyer les pings IPMI. Peut être spécifié autant de fois que nécessaire. Un port optionnel peut être spécifié. Peut accepter des plages d'hôtes en entrée. Voir SUPPORT DES PLAGES D'HÔTES dans ipmidetect(8) pour des informations sur les formats de plages. Si vous spécifiez une adresse IPv6 et un port, utilisez le format [ADRESSE]:PORT.
