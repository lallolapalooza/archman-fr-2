Nom

ipv6logstats - Prend les données de log http depuis stdin et affiche un tableau de statistiques en sortie

Syntaxe

cat /var/log/httpd/access_log | ipv6logstats [OPTIONS]

Syntaxe du programme

ipv6logstats [fichier_log]

Description

Prend les données de log du serveur web (ou toute autre donnée comportant une adresse IPv4/v6 dans la première colonne) depuis stdin et affiche une table/liste de statistiques (selon l'option) en stdout.

Options

Options générales :

[-d|--debug VALEUR_DEBOGAGE]
valeur de débogage (type bit à bit), peut aussi être définie par la variable d'environnement IPV6CALC_DEBUG
[-v|--version [-v [-v]]]
informations de version (2 niveaux de détail optionnels)
[-v|--version -h]
explication des jetons de fonctionnalités
[-V|--verbose]
plus verbeux
[-h|--help|-?]
aide en ligne
[-q|--quiet]
plus silencieux

Options de base de données externe (selon le support compilé) :

[--db-ip2location-disable]
support IP2Location désactivé
[--db-ip2location-dir RÉPERTOIRE]
répertoire de la base de données IP2Location (par défaut : /usr/share/IP2Location)
[--db-geoip-disable]
support GeoIP désactivé
[--db-geoip-dir RÉPERTOIRE]
répertoire de la base de données GeoIP (par défaut : /usr/share/GeoIP)

Options spéciales :

[-u|--unknown]
affiche les adresses IP inconnues sur stderr
[-c|--columns]
affiche les statistiques en colonnes (1)
[-N|--column-numbers]
affiche les numéros de colonne
[-n|--noheader]
n'affiche pas l'en-tête en mode colonnes (1)
[-o|--onlyheader]
affiche seulement l'en-tête en mode colonnes (1)
[-p|--prefix JETON]
affiche le jeton comme préfixe (1)
[-s|--simple]
désactive les statistiques étendues (CodePays/ASN)
(1) non supporté pour les statistiques de CodePays et ASN
