IPQ_ERRSTR(3) Manuel du programmeur Linux IPQ_ERRSTR(3)

NOM

ipq_errstr, ipq_perror — routines de gestion d'erreurs de libipq

SYNTAXE

#include <linux/netfilter.h>
#include <libipq.h>

char *ipq_errstr(void);
void ipq_perror(const char *s);

DESCRIPTION

La fonction ipq_errstr renvoie un message d'erreur descriptif basé sur la valeur actuelle de la variable interne ipq_errno. Toutes les fonctions de l'API libipq définissent cette variable interne en cas d'échec.

La fonction ipq_perror affiche un message d'erreur sur stderr correspondant à la valeur actuelle de la variable interne ipq_error, et à la variable globale errno (si définie). Le message d'erreur est précédé de la chaîne s fournie par l'application. Si s est NULL, le message d'erreur est précédé de la chaîne "ERROR".

VALEUR DE RETOUR

ipq_errstr renvoie un message d'erreur tel que décrit ci-dessus.
