NOM

ip-netconf - surveillance de la configuration réseau

SYNTAXE


ip [ ip-OPTIONS ] netconf show [ dev NOM ]

DESCRIPTION

L'utilitaire ip netconf peut surveiller les paramètres IPv4 et IPv6 (voir /proc/sys/net/ipv[4|6]/conf/[all|DEV]/) tels que la transmission (forwarding), le filtre rp_filter, le proxy_neigh, ignore_routes_with_linkdown ou l'état de la transmission multicast (mc_forwarding).

Si aucune interface n'est spécifiée, l'entrée all est affichée.

ip netconf show - afficher les paramètres réseau

dev NOM
le nom du périphérique pour lequel afficher les paramètres réseau.
