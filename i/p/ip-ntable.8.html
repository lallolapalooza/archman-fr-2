NOM

ip-ntable - configuration de la table des voisins

SYNTAXE


ip [ OPTIONS ] ntable { COMMANDE | help }

ip ntable change name NOM [ dev DEV ] [ thresh1 VAL ] [ thresh2 VAL ] [ thresh3 VAL ] [ gc_int MSEC ] [ base_reachable MSEC ] [ retrans MSEC ] [ gc_stale MSEC ] [ delay_probe MSEC ] [ queue LEN ] [ app_probs VAL ] [ ucast_probes VAL ] [ mcast_probes VAL ] [ mcast_reprobes VAL ] [ anycast_delay MSEC ] [ proxy_delay MSEC ] [ proxy_queue LEN ] [ locktime MSEC ]

ip ntable show [ dev DEV ] [ name NOM ]

DESCRIPTION

ip ntable contrôle les paramètres des tables des voisins.

ip ntable show - lister les tables de voisins ip

Cette commande affiche les paramètres et statistiques des tables de voisins.

dev DEV
lister uniquement la table attachée à ce périphérique.
name NOM
lister uniquement la table avec le nom donné.

ip ntable change - modifier un paramètre de table

Cette commande permet de modifier les paramètres de la table tels que les temporisateurs et les longueurs de file d'attente.

name NOM
le nom de la table à modifier.
dev DEV
le nom du périphérique pour modifier les valeurs de la table.

EXEMPLES

ip ntable show dev eth0

Affiche les paramètres de la table des voisins (ARP pour IPv4 et ndisc pour IPv6) sur le périphérique eth0.

ip ntable change name arp_cache queue 8 dev eth0

Change le nombre de paquets mis en file d'attente pendant la résolution d'adresse de la valeur par défaut (3) à 8 paquets.
