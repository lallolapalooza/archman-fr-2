NOM

ipq_read — lire les messages de la file d'attente depuis ip_queue et les lire dans le tampon fourni

SYNTAXE

#include <linux/netfilter.h>
#include <libipq.h>

ssize_t ipq_read(const struct ipq_handle *h, unsigned char *buf, size_t len, int timeout);

DESCRIPTION

La fonction ipq_read lit un message de file d'attente depuis le noyau et le copie dans la mémoire pointée par buf, avec une longueur maximale de len.

Le paramètre h est un descripteur de contexte qui doit avoir été renvoyé avec succès précédemment par un appel à ipq_create_handle.

L'appelant est responsable de s'assurer que la mémoire pointée par buf est suffisamment grande pour contenir len octets.

Le paramètre timeout peut être utilisé pour définir un délai d'attente pour l'opération, spécifié en microsecondes. Ceci est implémenté en interne par la bibliothèque via l'appel système select. Une valeur de zéro fournit un comportement de blocage normal, rétrocompatible, sans délai d'attente. Une valeur négative provoque le retour immédiat de la fonction.

Les données renvoyées via buf ne doivent pas être accessibles directement. Utilisez les fonctions ipq_message_type, ipq_get_packet, et ipq_get_msgerr pour accéder au message de file d'attente dans le tampon.

VALEUR DE RETOUR

En cas d'échec, -1 est retourné.
En cas de succès, une valeur positive non nulle est retournée lorsqu'aucune valeur de délai d'attente n'est spécifiée.
En cas de succès avec une valeur de délai d'attente spécifiée, zéro est retourné si aucune donnée n'était disponible à lire, ou si un signal non bloqué a été capturé. Dans ce dernier cas, la valeur globale de errno sera définie à EINTR.

ERREURS

En cas d'erreur, un message d'erreur descriptif sera disponible via la fonction ipq_errstr.

DIAGNOSTICS

Bien que la fonction ipq_read puisse retourner avec succès, le message de file d'attente copié dans le tampon peut lui-même être un message d'erreur provenant d'un composant du noyau de niveau supérieur. Utilisez ipq_message_type pour déterminer s'il s'agit d'un message d'erreur, et ipq_get_msgerr pour accéder à la valeur du message.

BOGUES

Aucun connu.
