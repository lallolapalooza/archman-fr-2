ipmilan(8) Convertisseur d'interface système vers LAN IPMI ipmilan(8)

NOM

ipmilan - Convertisseur d'interface système vers LAN IPMI

SYNTAXE

ipmilan [-c fichier_config] [-i périph_ipmi] [-d] [-n]

DESCRIPTION

Le démon ipmilan permet d'accéder à une interface système IPMI utilisant le pilote de périphérique OpenIPMI via le protocole LAN IPMI 1.5 ou 2.0.

ipmilan prend en charge les capacités d'authentification complètes du protocole LAN IPMI.

ipmilan prend en charge plusieurs adresses IP pour la tolérance aux pannes. Notez que les messages arrivant sur une adresse sont toujours renvoyés sur la même adresse.

OPTIONS

-c fichier-config
Définit le fichier de configuration sur un autre que celui par défaut, /etc/ipmi_lan.conf.
-n
Empêche le démon de se détacher du terminal de contrôle. Ceci est utile pour le lancement depuis init.
-d
Active le débogage vers la sortie standard. Vous devez généralement utiliser -n avec cette option.

CONFIGURATION

La configuration se fait via le fichier /etc/ipmi_lan.conf. Un fichier portant un autre nom ou chemin peut être spécifié à l'aide de l'option -c. Voir la page de manuel du fichier de configuration ipmi_lan pour plus de détails.

SÉCURITÉ

ipmilan implémente la sécurité IPMI normale. Par défaut, personne n'a accès, donc le réglage par défaut est assez sûr, mais soyez prudent avec ce que vous ajoutez, car il s'agit d'un accès pour contrôler votre machine. Les autorisations straight et none ne sont pas recommandées, vous devriez probablement vous en tenir à md2 ou md5.

SIGNaux

SIGHUP
ipmilan devrait gérer SIGHUP et relire ses fichiers de configuration. Cependant, ce n'est pas le cas actuellement. Cela pourrait changer à l'avenir, pour l'instant vous devrez le tuer et le redémarrer. Les clients devraient gérer la reconnexion dans ce cas. S'ils ne le font pas, ils sont défectueux.

SORTIE ERREURS

Au démarrage, toutes les sorties d'erreur vont vers stderr. Après cela, toutes les sorties d'erreur vont vers syslog.

FICHIERS

/etc/ipmi_lan.conf

VOIR AUSSI

ipmi_lan(5),ipmi_ui(1),openipmish(1)

PROBLÈMES CONNUS

Actuellement, ipmilan n'implémente pas l'écriture du fichier de configuration. Les commandes IPMI pour modifier les options de configuration sont acceptées, mais l'écriture permanente des modifications ne fonctionne pas actuellement.
