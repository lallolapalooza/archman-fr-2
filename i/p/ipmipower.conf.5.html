DESCRIPTIO

N

Le fichier de configuration FreeIPMI peut être utilisé pour définir des valeurs par défaut alternatives pour de nombreux outils FreeIPMI afin que les valeurs n'aient pas à être configurées en ligne de commande. Cela permet aux utilisateurs d'éviter de saisir une longue liste d'options de ligne de commande à chaque fois qu'une commande est exécutée. Il peut également être utilisé pour masquer les noms d'utilisateur, les mots de passe et d'autres informations sensibles à la commande ps(1

).

Actuellement, les outils qui peuvent être configurés avec le fichier de configuration sont : bmc-device(8), bmc-info(8), bmc-watchdog(8), ipmi-chassis(8), ipmi-config(8), ipmi-fru(8), ipmi-oem(8), ipmi-pet(8), ipmi-raw(8), ipmi-sel(8), ipmi-sensors(8), ipmiconsole(8) et ipmipower(8)

.

Par défaut, le fichier de configuration est stocké dans /etc/freeipmi//freeipmi.conf. Mais les utilisateurs peuvent sélectionner un fichier de configuration différent en ligne de commande avec l'option

--config-file.

Les valeurs spécifiées en ligne de commande

remplacent les valeurs de configuration
spécifiées dans le fichier de configuration.

FORMA

T

Les options de configuration qui peuvent être spécifiées dans le fichier de configuration sont listées ci-dessous. Chaque option de configuration doit être listée sur une ligne séparée. Les arguments d'une option sont séparés par une quantité quelconque d'espaces. Les arguments multiples sont également séparés par des espaces. Les commentaires peuvent être marqués en utilisant le caractère dièse ("#"), et les lignes peuvent être poursuivies sur la ligne suivante en utilisant la barre oblique inverse ("\")

.

Notez qu'il est possible de lister le nom d'utilisateur, le mot de passe et d'autres informatio

ns potentiellement sensibles dans le fichier de configuration. Si ces données sont stockées dans
un fichier de configuration, les administrateurs système doivent limiter l'accès à ce fichier.
