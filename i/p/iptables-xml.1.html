NOM

iptables-xml — Convertir le format iptables-save en XML

SYNOPSIS

iptables-xml [-c] [-v]

DESCRIPTION

iptables-xml est utilisé pour convertir la sortie de iptables-save dans un format XML facilement manipulable vers STDOUT. Utilisez la redirection d'entrée/sortie fournie par votre shell pour écrire dans un fichier.

-c, --combine
combiner les règles consécutives avec les mêmes correspondances mais des cibles différentes. iptables ne prend pas en charge plus d'une cible par correspondance actuellement, donc cela simule cela en collectant les cibles des règles iptables consécutives en une balise d'action, mais seulement lorsque les correspondances de règle sont identiques. Les actions de terminaison comme RETURN, DROP, ACCEPT et QUEUE ne sont pas combinées avec les cibles suivantes.
-v, --verbose
Afficher des commentaires xml contenant la ligne iptables dont le XML est dérivé.

iptables-xml effectue une conversion mécanique vers un format xml très expressif ; les seules considérations sémantiques concernent les cibles -g et -j afin de différencier entre <call>, <goto> et <nom-de-la-cible> car cela aide les scripts de traitement xml s'ils peuvent faire la différence entre une cible comme SNAT et une autre chaîne.

Voici un exemple de sortie :

<iptables-rules>
<table name="mangle">
<chain name="PREROUTING" policy="ACCEPT" packet-count="63436" byte-count="7137573">
<rule>
<conditions>
<match>
<p>tcp</p>
</match>
<tcp>
<sport>8443</sport>
</tcp>
</conditions>
<actions>
<call>
<check_ip/>
</call>
<ACCEPT/>
</actions>
</rule>
</chain>
</table> </iptables-rules>

La conversion du XML au format iptables-save peut être effectuée à l'aide du script iptables.xslt et de xsltproc, ou d'un programme personnalisé utilisant libxsltproc ou similaire ; de cette manière :

xsltproc iptables.xslt my-iptables.xml | iptables-restore
