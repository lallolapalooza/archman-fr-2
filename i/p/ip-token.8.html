NOM

ip-token - prise en charge des identifiants d'interface tokenisés

SYNTAXE


ip token { COMMANDE | help }

ip token set TOKEN dev DEV

ip token del dev DEV

ip token get [ dev DEV ]

ip token [ list ]

DESCRIPTION

La prise en charge des identifiants d'interface IPv6 tokenisés est utilisée pour attribuer des adresses d'hôte bien connues aux nœuds tout en obtenant un préfixe réseau global à partir des annonces de routeur. La cible principale des identifiants tokenisés sont les plates-formes serveur où les adresses sont généralement configurées manuellement, plutôt que d'utiliser DHCPv6 ou SLAAC. En utilisant des identifiants tokenisés, les hôtes peuvent toujours déterminer leur préfixe réseau en utilisant SLAAC, mais peuvent être renumérotés plus facilement automatiquement si leur préfixe réseau change [1]. Les identifiants IPv6 tokenisés sont décrits dans la brouillon [1] : <draft-chown-6man-tokenised-ipv6-identifiers-02>.

ip token set - définir un jeton d'interface

définit le jeton d'interface dans le noyau.

TOKEN
le jeton d'identifiant d'interface.
dev DEV
l'interface réseau.

ip token del - supprimer un jeton d'interface

supprime le jeton d'interface du noyau.

dev DEV
l'interface réseau.

ip token get - obtenir le jeton d'interface du noyau

affiche un identifiant d'interface tokenisé d'un appareil réseau particulier. Arguments : coïncident avec les arguments de ip token set mais le TOKEN doit être omis.

ip token list - lister tous les jetons d'interface

liste tous les identifiants d'interface tokenisés pour les interfaces réseau à partir du noyau.
