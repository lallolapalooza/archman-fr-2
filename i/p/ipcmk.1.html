IPCMK(1) Commandes utilisateur IPCMK(1)

NOM

ipcmk - création de diverses ressources IPC

SYNTAXE

ipcmk [options]

DESCRIPTION

ipcmk permet de créer des objets de communication inter-processus (IPC) POSIX et System V : segments de mémoire partagée, files de messages et sémaphores (tableaux pour System V).

OPTIONS

Les ressources peuvent être spécifiées avec les options suivantes :

-M, --shmem taille

Crée un segment de mémoire partagée de taille octets. L'argument taille peut être suivi des suffixes multiplicatifs KiB (=1024), MiB (=1024*1024), et ainsi de suite pour GiB, etc. (le suffixe "iB" est optionnel, par exemple, "K" a la même signification que "KiB") ou des suffixes KB (=1000), MB (=1000*1000), et ainsi de suite pour GB, etc.

-m, --posix-shmem taille

Crée un segment de mémoire partagée POSIX de taille octets. L'argument taille peut être suivi des suffixes multiplicatifs KiB (=1024), MiB (=1024*1024), et ainsi de suite pour GiB, etc. (le suffixe "iB" est optionnel, par exemple, "K" a la même signification que "KiB") ou des suffixes KB (=1000), MB (=1000*1000), et ainsi de suite pour GB, etc.

-Q, --queue

Crée une file de messages.

-q, --posix-mqueue

Crée une file de messages POSIX.

-S, --semaphore nombre

Crée un tableau de sémaphores avec nombre éléments.

-s, --posix-semaphore

Crée un sémaphore nommé POSIX.

-n, --name nom

Nom de l'objet IPC POSIX. Cette option est obligatoire pour les objets IPC POSIX.

Autres options :

-p, --mode mode

Permissions d'accès pour la ressource. Par défaut : 0644.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.
