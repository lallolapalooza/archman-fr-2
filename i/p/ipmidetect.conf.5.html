NOM

ipmidetect.conf - spécifier des valeurs par défaut alternatives pour la bibliothèque ipmidetect

DESCRIPTION

Via un fichier de configuration, les administrateurs système peuvent remplacer les valeurs par défaut utilisées dans la fonction d'API ipmidetect_load_data(3).

Le fichier de configuration est stocké à /etc/freeipmi//ipmidetect.conf.

OPTIONS DE CONFIGURATION

Voici une liste des options de configuration qui peuvent être spécifiées dans le fichier de configuration. Chaque option de configuration doit être listée sur une ligne séparée. Les arguments d'une option sont séparés par n'importe quelle quantité d'espaces blancs. Plusieurs arguments sont également séparés par des espaces blancs. Les commentaires peuvent être marqués en utilisant le caractère dièse (« # »), et les lignes peuvent être continuées sur la ligne suivante en utilisant une barre oblique inverse (« \ »).

hostnames hôte1 hôte2 hôte3 ...
Spécifie le nom d'hôte du serveur à atteindre. Plusieurs noms d'hôtes peuvent être listés jusqu'à un maximum de 8.
port num
Spécifie le port.
timeout_len secondes
Spécifie la durée du délai d'attente en secondes.

FICHIERS

/etc/freeipmi//ipmidetect.conf
