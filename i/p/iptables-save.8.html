IPTABLES-SAVE(8) iptables 1.8.11 IPTABLES-SAVE(8)

NOM

iptables-save — vidage des règles iptables

ip6tables-save — vidage des règles iptables

SYNTAXE

iptables-save [-M modprobe] [-c] [-t table] [-f nom_fichier]

ip6tables-save [-M modprobe] [-c] [-t table] [-f nom_fichier]

DESCRIPTION

iptables-save et ip6tables-save sont utilisés pour vider le contenu des tables IP ou IPv6 dans un format facilement analysable, soit vers la sortie standard (STDOUT), soit vers un fichier spécifié.

-M, --modprobe modprobe
Spécifie le chemin vers le programme modprobe(8). Par défaut, iptables-save inspectera /proc/sys/kernel/modprobe pour déterminer le chemin de l'exécutable.
-f, --file nom_fichier
Spécifie un nom de fichier pour enregistrer la sortie. Si non spécifié, iptables-save enregistrera vers la sortie standard (STDOUT).
-c, --counters
Inclut les valeurs actuelles de tous les compteurs de paquets et d'octets dans la sortie.
-t, --table nom_table
Restreint la sortie à une seule table. Si le noyau est configuré avec le chargement automatique des modules, une tentative sera faite pour charger le module approprié pour cette table si elle n'est pas déjà présente.
Si non spécifié, la sortie inclut toutes les tables disponibles. Aucun chargement de module n'a lieu, donc pour inclure une table spécifique dans la sortie, le module respectif (quelque chose comme iptable_mangle ou ip6table_raw) doit être chargé au préalable.

BOGUES

Aucun connu depuis la version 1.2.1 d'iptables
