ipq_destroy_handle(3)

Paquet: iptables

IPQ_CREATE_HANDLE(3) Manuel du programmeur Linux IPQ_CREATE_HANDLE(3)

NOM

ipq_create_handle, ipq_destroy_handle — créer et détruire des descripteurs libipq.

SYNOPSIS

#include <linux/netfilter.h>
#include <libipq.h>

struct ipq_handle *ipq_create_handle(uint32_t flags, uint32_t protocol);
int ipq_destroy_handle(struct ipq_handle *h);

DESCRIPTION

La fonction ipq_create_handle initialise libipq pour une application, tente de se connecter au socket Netlink utilisé par ip_queue, et renvoie un descripteur de contexte opaque. Elle doit être la première fonction libipq appelée par une application. Le descripteur renvoyé doit être utilisé dans tous les appels ultérieurs à la bibliothèque qui nécessitent un paramètre de descripteur.

Le paramètre flags n'est actuellement pas utilisé et doit être mis à zéro par l'application pour une compatibilité future.

Le paramètre protocol est utilisé pour spécifier le protocole des paquets à mettre en file d'attente. Les valeurs valides sont NFPROTO_IPV4 pour IPv4 et NFPROTO_IPV6 pour IPv6. Actuellement, un seul protocole peut être mis en file d'attente à la fois pour un descripteur.

La fonction ipq_destroy_handle libère les ressources allouées par ipq_create_handle, et doit être utilisée lorsque le descripteur n'est plus requis par l'application.

VALEUR DE RETOUR

En cas de succès, ipq_create_handle renvoie un pointeur vers un descripteur de contexte.
En cas d'échec, NULL est renvoyé.

En cas de succès, ipq_destroy_handle renvoie zéro.
En cas d'échec, -1 est renvoyé.

ERREURS

En cas d'échec, un message d'erreur descriptif sera disponible via la fonction ipq_errstr.

BOGUES

Aucun connu.
