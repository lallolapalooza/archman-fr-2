ipq_get_packet(3)

Paquet: iptables

Licences: GPL-2.0-only

IPQ_MESSAGE_TYPE(3) Manuel du programmeur Linux IPQ_MESSAGE_TYPE(3)

NOM

ipq_message_type, ipq_get_packet, ipq_getmsgerr — interroger les messages de la file d'attente

SYNTAXE

#include <linux/netfilter.h>
#include <libipq.h>

int ipq_message_type(const unsigned char *buf);
ipq_packet_msg_t *ipq_get_packet(const unsigned char *buf);
int ipq_get_msgerr(const unsigned char *buf);

DESCRIPTION

La fonction ipq_message_type retourne le type de message de la file d'attente renvoyé à l'espace utilisateur via ipq_read.

ipq_message_type doit toujours être appelée après un appel réussi à ipq_read pour déterminer si le message est un message de paquet ou un message d'erreur. Le paramètre buf doit être le même que les données obtenues lors de l'appel précédent à ipq_read.

ipq_message_type retournera l'une des valeurs suivantes :

NLMSG_ERROR
Un message d'erreur généré par le transport Netlink.
IPQM_PACKET
Un message de paquet contenant les métadonnées du paquet et éventuellement les données de la charge utile du paquet.

La fonction ipq_get_packet doit être appelée si ipq_message_type retourne IPQM_PACKET. Le paramètre buf doit pointer vers les mêmes données utilisées pour l'appel à ipq_message_type. Le pointeur retourné par ipq_get_packet pointe vers un message de paquet, qui est déclaré comme suit :

typedef struct ipq_packet_msg {
	unsigned long packet_id;        /* ID du paquet mis en file d'attente */
	unsigned long mark;             /* Valeur de marquage Netfilter */
	long timestamp_sec;             /* Temps d'arrivée du paquet (secondes) */
	long timestamp_usec;            /* Temps d'arrivée du paquet (+ microsecondes) */
	unsigned int hook;              /* Crochet Netfilter sur lequel nous sommes passés */
	char indev_name[IFNAMSIZ];      /* Nom de l'interface entrante */
	char outdev_name[IFNAMSIZ];     /* Nom de l'interface sortante */
	unsigned short hw_protocol;     /* Protocole matériel (ordre réseau) */
	unsigned short hw_type;         /* Type matériel */
	unsigned char hw_addrlen;       /* Longueur de l'adresse matérielle */
	unsigned char hw_addr[8];       /* Adresse matérielle */
	size_t data_len;                /* Longueur des données du paquet */
	unsigned char payload[0];       /* Données optionnelles du paquet */
} ipq_packet_msg_t;

Chacun de ces champs peut être lu par l'application. Si le mode de file d'attente est IPQ_COPY_PACKET et que la valeur data_len est supérieure à zéro, le contenu de la charge utile du paquet peut être accédé dans la mémoire suivant la structure ipq_packet_msg_t jusqu'à une plage de data_len.

Le champ packet_id contient un identifiant de paquet à utiliser lors de l'appel à ipq_set_verdict.

La fonction ipq_get_msgerr doit être appelée si ipq_message_type retourne NLMSG_ERROR. Le paramètre buf doit pointer vers les mêmes données utilisées pour l'appel à ipq_message_type. La valeur retournée par ipq_get_msgerr est définie par le code noyau de niveau supérieur et correspond aux valeurs standard de errno.
