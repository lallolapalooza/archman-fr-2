import(1) Manuel des commandes générales import(1)

NOM

import - enregistre une fenêtre visible sur un serveur X et la sort en fichier image. Vous pouvez capturer une seule fenêtre, l'écran entier, ou toute portion rectangulaire de l'écran. La fenêtre à capturer est sélectionnée en cliquant sur la fenêtre désirée ou via une option du programme.

SYNTAXE

magick import [options] fichier-sortie

APERÇU

Le programme import fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour capturer tout ou partie de l'écran d'un serveur X et enregistrer l'image dans un fichier.

Pour plus d'informations sur la commande import, ouvrez file:///usr/share/doc/ImageMagick-7/www/import.html dans votre navigateur ou https://imagemagick.org/script/import.php.

DESCRIPTION

Paramètres de l'image :
-adjoin joindre les images dans un seul fichier multi-images
-border inclure la bordure de la fenêtre dans l'image de sortie
-colorspace type espace de couleurs alterné pour l'image
-comment chaîne annoter l'image avec un commentaire
-compress type type de compression des pixels lors de l'écriture de l'image
-define format:option
définir une ou plusieurs options de format d'image
-density géométrie densité horizontale et verticale de l'image
-depth valeur profondeur de l'image
-descend obtenir l'image en descendant la hiérarchie des fenêtres
-display serveur serveur X à contacter
-dispose méthode méthode de suppression de calque
-dither méthode appliquer la diffusion d'erreur à l'image
-delay centisecondes afficher l'image suivante après une pause
-encipher fichier convertir les pixels clairs en pixels chiffrés
-endian type boutisme (MSB ou LSB) de l'image
-encoding type type d'encodage du texte
-filter type utiliser ce filtre lors du redimensionnement d'une image
-format "chaîne" caractéristiques de l'image formatée en sortie
-frame inclure le cadre du gestionnaire de fenêtres
-gravity direction quelle direction privilégier
-identify identifier le format et les caractéristiques de l'image
-interlace type Aucun, Ligne, Plan, ou Partition
-interpolate méthode méthode d'interpolation des couleurs des pixels
-label chaîne attribuer une étiquette à une image
-limit type valeur limite de ressources Zone, Disque, Carte, ou Mémoire
-monitor surveiller la progression
-page géométrie taille et emplacement du canevas de l'image
-pause secondes délai en secondes entre les instantanés
-pointsize valeur taille de police en points
-quality valeur niveau de compression JPEG/MIFF/PNG
-quiet supprimer tous les messages d'avertissement
-regard-warnings prêter attention aux messages d'avertissement
-repage géométrie taille et emplacement du canevas de l'image
-respect-parentheses les paramètres restent en vigueur jusqu'à la limite des parenthèses
-sampling-factor géométrie
facteur d'échantillonnage horizontal et vertical
-scene valeur numéro de scène de l'image
-screen sélectionner l'image à partir de la fenêtre racine
-seed valeur initialiser une nouvelle séquence de nombres pseudo-aléatoires
-set propriété valeur définir une propriété de l'image
-silent fonctionner silencieusement, c'est-à-dire ne faire aucune sonnerie
-snaps valeur nombre d'instantanés de l'écran
-support facteur support de redimensionnement : > 1.0 est flou, < 1.0 est net
-synchronize synchroniser l'image avec le périphérique de stockage
-taint déclarer l'image comme modifiée
-transparent-color couleur
couleur transparente
-treedepth valeur profondeur de l'arbre de couleurs
-verbose afficher des informations détaillées sur l'image
-virtual-pixel méthode
Constant, Bord, Miroir, ou Tuile
-window id sélectionner la fenêtre avec cet id ou ce nom
root sélectionne tout l'écran

Opérateurs d'image :
-annotate géométrie texte
annoter l'image avec du texte
-channel mask définir le masque de canal de l'image
-colors valeur nombre préféré de couleurs dans l'image
-crop géométrie taille et emplacement préférés de l'image recadrée
-extent géométrie définir la taille de l'image
-geometry géométrie taille ou emplacement préférés de l'image
-help afficher les options du programme
-monochrome transformer l'image en noir et blanc
-negate remplacer chaque pixel par sa couleur complémentaire
-quantize colorspace réduire les couleurs dans cet espace de couleurs
-resize géométrie redimensionner l'image
-rotate degrés appliquer la rotation Paeth à l'image
-strip supprimer tous les profils et commentaires de l'image
-thumbnail géométrie créer une miniature de l'image
-transparent couleur rendre cette couleur transparente dans l'image
-trim rogner les bords de l'image
-type type type d'image

Options diverses :
-debug events afficher des informations de débogage abondantes
-help afficher les options du programme
-log format format des informations de débogage
-list type afficher une liste des arguments d'option pris en charge
-version afficher les informations sur la version

Par défaut, 'fichier' est écrit au format d'image Postscript. Pour spécifier un format d'image particulier, préfixez le nom de fichier avec un nom de format d'image et un deux-points (par ex. ps:image) ou spécifiez le type d'image comme suffixe du nom de fichier (par ex. image.ps). Spécifiez 'fichier' comme '-' pour l'entrée ou la sortie standard.
