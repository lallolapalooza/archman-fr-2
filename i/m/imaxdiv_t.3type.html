div_t(3type) div_t(3type)

NOM

div_t, ldiv_t, lldiv_t, imaxdiv_t - quotient et reste d'une division entière

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <stdlib.h>
typedef struct {
    int quot; /* Quotient */
    int rem;  /* Reste */
} div_t;
typedef struct {
    long quot; /* Quotient */
    long rem;  /* Reste */
} ldiv_t;
typedef struct {
    long long quot; /* Quotient */
    long long rem;  /* Reste */
} lldiv_t;
#include <inttypes.h>
typedef struct {
    intmax_t quot; /* Quotient */
    intmax_t rem;  /* Reste */
} imaxdiv_t;

DESCRIPTION

[[l]l]div_t est le type de la valeur retournée par la fonction [[l]l]div(3).

imaxdiv_t est le type de la valeur retournée par la fonction imaxdiv(3).

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C99, POSIX.1-2001.

VOIR AUSSI

div(3), imaxdiv(3), ldiv(3), lldiv(3)
