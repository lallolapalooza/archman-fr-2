NOM

imv - fichier de configuration de imv

DESCRIPTION

imv peut être personnalisé avec ce fichier de configuration, modifiant son comportement par défaut, ses raccourcis clavier et son apparence.

Le fichier de configuration de imv est un fichier de style ini, avec plusieurs paramètres clé = valeur, séparés en plusieurs sections '[section]'.

OPTIONS

La section [options] accepte les paramètres suivants :

background = <code-hexadécimal|carrés>

Définit l'arrière-plan dans imv. Peut être un code couleur hexadécimal à 6 chiffres, ou carrés pour un arrière-plan à damier. Par défaut : 000000

fullscreen = <true|false>

Lance imv en plein écran. Par défaut : false.

width = <largeur>

Largeur initiale de la fenêtre imv. Par défaut : 1280.

height = <hauteur>

Hauteur initiale de la fenêtre imv. Par défaut : 720.

initial_pan = <facteur_panoramique_x> <facteur_panoramique_y>

Position initiale panoramique/focus des images ouvertes. Une valeur de 50 représente le point milieu de l'image (50%). Par défaut : 50 50

list_files_at_exit = <true|false>

Affiche les fichiers ouverts sur la sortie standard à la sortie, chacun sur une ligne séparée. Par défaut : false.

loop_input = <true|false>

Retourne à la première image après avoir vu la dernière. Par défaut : true.

overlay = <true|false>

Lance avec la superposition visible. Par défaut : false.

overlay_font = <police:taille>

Utilise la police spécifiée dans la superposition. Par défaut : Monospace:24.

overlay_text = <texte>

Utilise le texte donné comme texte de la superposition. Le texte fourni est expansé par le shell, donc la sortie de commandes peut être utilisée (par exemple, $(ls)). Les variables d'environnement peuvent également être utilisées, y compris celles accessibles à la commande exec de imv.

overlay_text_color = <code-hexadécimal>

Définit la couleur du texte dans la superposition. C'est un code couleur hexadécimal à 6 chiffres. Par défaut : ffffff.

overlay_text_alpha = <code-hexadécimal>

Définit l'alpha du texte dans la superposition. C'est un code couleur hexadécimal à 2 chiffres. Par défaut : ff.

overlay_background_color = <code-hexadécimal>

Définit la couleur de l'arrière-plan de la superposition. C'est un code couleur hexadécimal à 6 chiffres. Par défaut : 000000.

overlay_background_alpha = <code-hexadécimal>

Définit l'alpha de l'arrière-plan de la superposition. C'est un code couleur hexadécimal à 2 chiffres. Par défaut : c3.

overlay_position_bottom = <true|false>

Affiche la superposition en bas de la fenêtre imv, au lieu d'en haut.

recursively = <true|false>

Charge les chemins d'entrée de manière récursive. Par défaut : false.

scaling_mode = <none|shrink|full|crop>

Définit le mode de mise à l'échelle à utiliser. none affichera chaque image à sa taille réelle. shrink mettra à l'échelle l'image pour qu'elle rentre dans la fenêtre. full mettra à l'échelle l'image vers le haut et vers le bas pour qu'elle rentre parfaitement dans la fenêtre. crop mettra à l'échelle et rognera l'image pour remplir la fenêtre. Par défaut : full.

slideshow_duration = <durée>

Lance imv en mode diaporama, et définit la durée d'affichage de chaque image en secondes. Par défaut : 0, c'est-à-dire pas de diaporama.

suppress_default_binds = <true|false>

Désactive les raccourcis intégrés de imv afin qu'ils n'entrent pas en conflit avec ceux personnalisés. Par défaut : false.

title_text = <texte>

Utilise le texte donné comme titre de la fenêtre. Le texte fourni est expansé par le shell, donc la sortie de commandes peut être utilisée : $(ls), tout comme les variables d'environnement, y compris celles accessibles à la commande exec de imv.

upscaling_method = <linear|nearest_neighbour>

Utilise la méthode spécifiée pour mettre à l'échelle les images vers le haut. Par défaut : linear.

ALIAS

La section [aliases] permet d'ajouter des alias pour les commandes intégrées de imv. Par exemple, x = close ajouterait une commande x qui exécute simplement la commande close. Tous les arguments fournis à un alias sont ajoutés à la commande configurée par l'alias.

BINDS

La section [binds] permet d'ajouter des raccourcis clavier personnalisés à imv.

Les raccourcis sont au format combinaison_clé = commande. Une combinaison de touches peut se composer de plusieurs touches successives. Plusieurs commandes pour une seule combinaison de touches peuvent être définies en séparant chaque commande par un ;. Les guillemets simples et doubles sont respectés, tout comme l'échappement avec une barre oblique inverse, pour permettre le bon encadrement des commandes shell.

Des touches uniques comme q sont simplement cela : q = quit liera la touche q à la commande quit.

Les touches modificatrices peuvent être spécifiées en les faisant précéder : Ctrl+q, Meta+f, Shift+G. Si plusieurs touches modificatrices sont souhaitées, elles sont spécifiées dans l'ordre Ctrl+Meta+Shift. Lorsqu'un nom de touche est plus qu'un seul caractère, ou qu'un modificateur est utilisé, il doit être entouré de < et >, par exemple : <Ctrl+q>.

Plusieurs touches successives peuvent être spécifiées en les listant dans l'ordre : gg = goto 1 liera deux pressions sur la touche g pour passer à la première image, et <Ctrl+a>p = exec echo hi liera la séquence de touches Ctrl+a suivie de p à l'exécution de la commande shell echo hi.

De nombreuses touches, comme < et >, ont des noms spéciaux. Sur X11, celles-ci peuvent être facilement trouvées avec la commande xev(1). Par exemple, ! est appelé exclam, < est appelé less, > est appelé greater.

Une liste complète des keysyms peut également être trouvée sur la plupart des systèmes avec la commande dumpkeys -l.
