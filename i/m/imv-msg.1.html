NOM

imv-msg - Utilitaire pour envoyer des commandes à une instance imv en cours d'exécution

DESCRIPTION

imv-msg est un outil pour simplifier l'envoi de commandes à une instance imv en cours d'exécution. Étant donné le pid de l'instance, il ouvre le socket unix correspondant et envoie la commande fournie.

SYNTAXE

imv-msg <pid> <commande>

AUTEURS

imv-msg est écrit et maintenu par Harry Jeffery <me@harry.pm>

Le code source complet et d'autres informations peuvent être trouvés sur https://sr.ht/~exec64/imv.
