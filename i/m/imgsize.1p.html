IMGSIZE(1p) Documentation Perl fournie par l'utilisateur IMGSIZE(1p)

NOM

imgsize - lire les dimensions d'une image dans plusieurs formats populaires

UTILISATION

imgsize [ -r | -a | -f fmt ] fichier [ fichier ... ]

DESCRIPTION

Facile pour obtenir la taille d'une image fournie en ligne de commande. Tout le travail réel est effectué par Image::Size.

ARGUMENTS REQUIS

imgsize attend des noms de fichiers sur la ligne de commande. Si plusieurs fichiers sont fournis, le nom du fichier sera inclus dans la sortie :

% imgsize dot.gif
width="16" height="16"
% imgsize dot.gif dash.gif
dot.gif: width="16" height="16"
dash.gif: width="32" height="8"

OPTIONS

Par défaut, la largeur et la hauteur sont retournées sous forme d'attributs pour une balise IMG en HTML, essentiellement "width="40" height="30"" ou similaire. Les options suivantes peuvent être utilisées pour renvoyer des formats alternatifs (tous rapportent d'abord la largeur, puis la hauteur) :

"-r"
Retourne les données au format "brut". Juste les nombres séparés par un seul espace.
"-a"
Retourne une liste d'attributs de style Perl appropriée pour être passée à la méthode img() du module CGI (voir CGI).
"-f" fmt
Passe la chaîne spécifiée dans fmt à "sprintf" et l'utilise donc pour formater les résultats à votre convenance. "sprintf" recevra deux nombres, donc toute autre directive de formatage sera perdue. Les nombres sont passés comme largeur d'abord, puis hauteur.

STATUT DE SORTIE

imgsize se termine toujours
