NOM

img_stat - Afficher les détails d'un fichier image

SYNTAXE

img_stat [-i imgtype] [-b taille_secteur_dev] [-tvV] image [images]

DESCRIPTION

img_stat affiche les détails associés à un fichier image. La sortie de cette commande est spécifique au format de l'image. Au minimum, la taille sera indiquée et la plage d'octets de chaque fichier sera donnée pour les formats d'image segmentés.

ARGUMENTS

-i imgtype
Identifie le type de fichier image, tel que 'raw'. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, les méthodes de détection automatique sont utilisées.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur du format d'image est utilisée (si elle existe) ou 512 octets sont supposés.
-t
N'afficher que le type de l'image.
-v
Affichage verbeux des messages de débogage sur stderr
-V
Afficher la version
image [images]
L'image disque ou partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul nom de fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par une terminaison en '.001'), les segments d'image suivants seront inclus automatiquement.
