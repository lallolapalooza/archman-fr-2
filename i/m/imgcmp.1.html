NOM

imgcmp - Utilitaire de comparaison d'images

SYNTAXE

imgcmp [options]

DESCRIPTION

La commande imgcmp compare deux images de même géométrie vis-à-vis d'une métrique donnée. Veuillez utiliser le commutateur de ligne de commande --help et le Manuel de référence logicielle JasPer pour plus d'informations.

MANUEL EN LIGNE

Pour des informations détaillées sur le logiciel JasPer, veuillez consulter le Manuel JasPer en ligne, disponible à l'adresse : https://jasper-software.github.io/jasper-manual

SITE WEB DU LOGICIEL JASPER

Pour des informations supplémentaires sur le logiciel JasPer, veuillez consulter le site web du logiciel JasPer à l'adresse : https://jasper-software.github.io/jasper
