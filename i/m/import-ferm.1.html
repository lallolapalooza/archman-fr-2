NOM

import-ferm - importer les règles de pare-feu existantes dans ferm

SYNOPSIS

import-ferm > ferm.conf

iptables-save | import-ferm > ferm.conf

import-ferm fichier_entrée > ferm.conf

DESCRIPTION

Ce script vous aide à porter une configuration de pare-feu IPv4 existante vers ferm. Il lit un fichier généré avec iptables-save et tente de suggérer un fichier de configuration ferm.

Si aucun fichier d'entrée n'est spécifié sur la ligne de commande, import-ferm exécute iptables-save.

BUGS

iptables-save antérieur à la version 1.3 est incapable d'écrire des sauvegardes valides - ce n'est pas un bug dans import-ferm.
