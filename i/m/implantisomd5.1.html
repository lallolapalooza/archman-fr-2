IMPLANTISOMD5(1) Manuel des commandes générales IMPLANTISOMD5(1)

NOM

implantisomd5 — implanter une somme de contrôle MD5 dans une image ISO9660

SYNTAXE

implantisomd5 [--force] [--supported-iso] [nom_fichier_iso]

DESCRIPTION

Cette page de manuel décrit brièvement la commande implantisomd5. implantisomd5 est un programme qui intègre une somme de contrôle MD5 dans une section inutilisée d'une image ISO9660 (.iso). Cette somme de contrôle peut être comparée ultérieurement à l'.iso, ou à un périphérique bloc, en utilisant la commande correspondante checkisomd5.

OPTIONS

--force
Forcer l'écrasement d'une somme de contrôle existante.
--supported-iso
Indiquer que l'image sera écrite sur un média « supporté », tel qu'un CD pressé. Sur les installateurs Anaconda basés sur Red Hat, cela contourne la demande de vérification du CD.

VOIR AUSSI

checkisomd5 (1).
