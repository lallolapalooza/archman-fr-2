fonction entière icmax1 (entier n, complexe, dimension(*) cx, entier incx)

ICMAX1 trouve l'indice du premier élément de vecteur de valeur absolue maximale.

Objectif :

!>
!> ICMAX1 trouve l'indice du premier élément de vecteur de valeur absolue maximale.
!>
!> Basé sur ICAMAX de BLAS de niveau 1.
!> Le changement consiste à utiliser la valeur absolue « authentique ».
!>

Paramètres

N 
!>          N est ENTIER
!>          Le nombre d'éléments dans le vecteur CX.
!>

CX

!>          CX est un tableau COMPLEXE, de dimension (N)
!>          Le vecteur CX. La fonction ICMAX1 renvoie l'indice de son premier
!>          élément de valeur absolue maximale.
!>

INCX

!>          INCX est ENTIER
!>          L'espacement entre les valeurs successives de CX. INCX >= 1.
!>
