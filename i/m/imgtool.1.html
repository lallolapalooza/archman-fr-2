IMGTOOL(1) Outil de manipulation d'images de médias MESS IMGTOOL(1)

NOM

imgtool - Outil de manipulation d'images de médias MESS

SYNTAXE

imgtool create format image [option ...]
imgtool dir format image [chemin]
imgtool get format image fichier [nouveau_nom] [--filter=filtre] [--fork=fork]
imgtool put format image fichier ... [nouveau_nom] [option ...] [--filter=filtre] [--fork=fork]
imgtool getall format image [chemin] [--filter=filtre]
imgtool del format image fichier ...
imgtool mkdir format image répertoire
imgtool rmdir format image répertoire ...
imgtool readsector|writesector format image piste tête secteur fichier
imgtool identify image
imgtool listformats|listfilters
imgtool listdriveroptions format

DESCRIPTION

imgtool est un outil pour la maintenance et la manipulation des disquettes et d'autres types d'images que les utilisateurs de MESS doivent manipuler. Les fonctions incluent la récupération et le stockage de fichiers, ainsi que la vérification et la validation des CRC. Les fichiers images peuvent également être contenus dans des fichiers .zip.

OPTIONS

create
Crée une image. Des paramètres optionnels spécifiques à l'image peuvent être spécifiés, voir la commande imgtool listdriveroptions pour une liste complète.
dir
Liste le contenu d'une image.
get
Récupère un seul fichier d'une image. Un filtre peut être spécifié pour convertir des formats de fichiers personnalisés en ASCII, voir la commande imgtool listfilters pour une liste complète. Le fichier peut éventuellement être renommé.
put
Place un ou plusieurs fichiers sur une image (prise en charge des caractères joker et du renommage). Des filtres sont fournis pour convertir des fichiers ASCII en formats de fichiers personnalisés, voir la commande imgtool listfilters pour une liste complète.
getall
Récupère tous les fichiers d'une image. Des filtres peuvent être spécifiés pour convertir des formats de fichiers personnalisés en ASCII, voir la commande imgtool listfilters pour une liste complète.
del
Supprime un fichier sur une image.
mkdir
Crée un répertoire sur une image.
rmdir
Supprime des répertoires sur une image.
readsector
Extrait le contenu d'un seul secteur d'une image vers un fichier.
writesector
Écrit le contenu d'un fichier dans un secteur spécifique d'une image.
identify
Tente de reconnaître le format d'un fichier image.
listformats
Liste tous les formats de fichiers image pris en charge par imgtool.
listfilters
Liste tous les filtres pris en charge par imgtool. Les filtres permettent de traiter les données écrites dans ou lues depuis une image d'une certaine manière.
listdriveroptions
Liste toutes les options spécifiques au format pour les commandes imgtool put et imgtool create.

EXEMPLES

imgtool dir coco_jvc_rsdos myimageinazip.zip

imgtool get coco_jvc_rsdos myimage.dsk myfile.bin mynewfile.txt

imgtool getall coco_jvc_rsdos myimage.dsk
