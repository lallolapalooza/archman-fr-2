image(n) Commandes intégrées Tk image(n)

NOM

image - Créer et manipuler des images

SYNTAXE

image option ?arg arg ...?

DESCRIPTION

La commande image est utilisée pour créer, supprimer et interroger des images. Elle peut prendre plusieurs formes différentes, en fonction de l'argument option. Les formes valides sont :

image create type ?nom? ?option valeur ...?
Crée une nouvelle image et une commande portant le même nom, et renvoie son nom. type spécifie le type de l'image, qui doit être l'un des types actuellement définis (par exemple, bitmap). nom spécifie le nom de l'image ; s'il est omis, Tk choisit un nom de la forme imagex, où x est un entier. Il peut y avoir n'importe quel nombre de paires option-valeur, qui fournissent des options de configuration pour la nouvelle image. L'ensemble des options légales est défini séparément pour chaque type d'image ; voir ci-dessous pour les détails des options pour les types d'images intégrées. Si une image existe déjà sous le nom donné, elle est remplacée par la nouvelle image et toutes les instances de cette image seront redessinées avec le nouveau contenu. Il est important de noter que la commande image écrasera silencieusement toute procédure pouvant être actuellement définie par le nom donné, alors choisissez le nom judicieusement. Il est recommandé d'utiliser un espace de noms distinct pour les noms d'images (par exemple, ::img::logo, ::img::large).
image delete ?nom nom ...?
Supprime chacune des images nommées et renvoie une chaîne vide. S'il y a des instances des images affichées dans des widgets, les images ne seront pas réellement supprimées tant que toutes les instances ne seront pas libérées. Cependant, l'association entre les instances et le gestionnaire d'images sera rompue. Les instances existantes conserveront leur taille mais se redessineront comme des zones vides. Si une image supprimée est recréée avec un autre appel à image create, les instances existantes utiliseront la nouvelle image.
image height nom
Renvoie une chaîne décimale donnant la hauteur de l'image nom en pixels.
image inuse nom
Renvoie une valeur booléenne indiquant si l'image donnée par nom est utilisée par des widgets.
image names
Renvoie une liste contenant les noms de toutes les images existantes.
image type nom
Renvoie le type de l'image nom (la valeur de l'argument type passé à image create lors de la création de l'image).
image types
Renvoie une liste dont les éléments sont tous les types d'images valides (c'est-à-dire toutes les valeurs qui peuvent être fournies pour l'argument type à image create).
image width nom
Renvoie une chaîne décimale donnant la largeur de l'image nom en pixels.

Des opérations supplémentaires (par exemple, écrire l'image dans un fichier) peuvent être disponibles en tant que sous-commandes de la commande d'instance d'image. Voir la page de manuel du type d'image particulier pour plus de détails.

TYPES D'IMPRIMERIE INTÉGRÉS

Les types d'images suivants sont définis par Tk, ils seront donc disponibles dans toute application Tk. Des applications ou extensions individuelles peuvent définir des types supplémentaires.

bitmap
Chaque pixel de l'image affiche une couleur de premier plan, une couleur d'arrière-plan ou rien. Voir l'entrée de manuel bitmap pour plus d'informations.
photo
Affiche une variété d'images en couleurs, utilisant la tramage pour approximer les couleurs sur les écrans avec des capacités de couleur limitées. Voir l'entrée de manuel photo pour plus d'informations.
