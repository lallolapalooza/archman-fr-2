NOM

io_uring_recvmsg_out - accéder aux données de recvmsg multishot

SYNTAXE

#include <liburing.h>
struct io_uring_recvmsg_out *io_uring_recvmsg_validate(void *buf,
                                                       int buf_len,
                                                       struct msghdr *msgh);
void *io_uring_recvmsg_name(struct io_uring_recvmsg_out *o);
struct cmsghdr *io_uring_recvmsg_cmsg_firsthdr(struct io_uring_recvmsg_out *o,
                                               struct msghdr *msgh);
struct cmsghdr *io_uring_recvmsg_cmsg_nexthdr(struct io_uring_recvmsg_out *o,
                                              struct msghdr *msgh,
                                              struct cmsghdr *cmsg);
void *io_uring_recvmsg_payload(struct io_uring_recvmsg_out *o,
                               struct msghdr *msgh);
unsigned int io_uring_recvmsg_payload_length(struct io_uring_recvmsg_out *o,
                                             int buf_len,
                                             struct msghdr *msgh);

DESCRIPTION

Ces fonctions sont utilisées pour accéder aux données dans la charge utile livrée par io_uring_prep_recvmsg_multishot(3).

msgh doit pointer vers le struct msghdr soumis avec la requête.

io_uring_recvmsg_validate(3) validera un tampon livré par io_uring_prep_recvmsg_multishot(3) et extraira le io_uring_recvmsg_out s'il est valide, retournant un pointeur vers celui-ci ou NULL sinon.

La structure est définie comme suit :


struct io_uring_recvmsg_out {
        __u32 namelen;    /* Taille en octets du nom tel qu'il aurait été
                           * rempli par recvmsg(2) */
        __u32 controllen; /* Taille en octets du contrôle */
        __u32 payloadlen; /* Taille en octets de la charge utile telle qu'elle
                           * aurait été retournée par recvmsg(2) */
        __u32 flags;      /* Résultat des flags tel qu'il aurait été rempli
                           * par recvmsg(2) */
};
  • io_uring_recvmsg_name(3)
retourne un pointeur vers le nom dans le tampon.
  • io_uring_recvmsg_cmsg_firsthdr(3)
retourne un pointeur vers le premier cmsg dans le tampon, ou NULL.
  • io_uring_recvmsg_cmsg_nexthdr(3)
retourne un pointeur vers le cmsg suivant dans le tampon, ou NULL.
  • io_uring_recvmsg_payload(3)
retourne un pointeur vers la charge utile dans le tampon.
  • io_uring_recvmsg_payload_length(3)
Calcule la longueur utilisable de la charge utile en octets.
