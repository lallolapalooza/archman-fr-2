NOM

io_uring_buf_ring_init - Initialiser un anneau de tampons

SYNTAXE

#include <liburing.h>
void io_uring_buf_ring_init(struct io_uring_buf_ring *br);

DESCRIPTION

io_uring_buf_ring_init(3) initialise br pour qu'il soit prêt à être utilisé. Elle peut être appelée après io_uring_register_buf_ring(3) mais doit être appelée avant que l'anneau de tampons ne soit utilisé d'une quelconque autre manière.

VALEUR DE RETOUR

Aucune

NOTES

Sauf si une configuration manuelle est nécessaire, il est recommandé d'utiliser io_uring_setup_buf_ring(3) car elle offre un moyen plus simple de configurer un anneau de tampons fourni.
