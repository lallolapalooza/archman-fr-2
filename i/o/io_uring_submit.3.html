NOM

io_uring_submit - soumettre des requêtes à la file d'attente de soumission

SYNOPSIS

#include <liburing.h>
int io_uring_submit(struct io_uring *ring);

DESCRIPTION

La fonction io_uring_submit(3) soumet les prochains événements à la file d'attente de soumission appartenant à ring.

Après que l'appelant a récupéré une entrée de file d'attente de soumission (SQE) avec io_uring_get_sqe(3) et préparé la SQE à l'aide de l'une des fonctions d'aide fournies, elle peut être soumise avec io_uring_submit(3).

VALEUR DE RETOUR

En cas de succès, io_uring_submit(3) retourne le nombre d'entrées de file d'attente de soumission soumises, si SQPOLL n'est pas utilisé. Si SQPOLL est utilisé, la valeur de retour peut indiquer un nombre plus élevé d'entrées soumises que celles réellement soumises. Si l'utilisateur a besoin d'informations précises sur le nombre d'entrées de file d'attente de soumission qui ont été soumises avec succès, tout en utilisant SQPOLL, l'utilisateur doit se rabattre sur la soumission répétée d'une seule entrée de file d'attente de soumission. En cas d'échec, il retourne -errno.

NOTES

Pour toute requête qui transmet des données dans une structure, ces données doivent rester valides jusqu'à ce que la requête ait été soumise avec succès. Elles n'ont pas besoin de rester valides jusqu'à l'achèvement. Une fois qu'une requête a été soumise, l'état dans le noyau est stable. Les noyaux très anciens (5.4 et antérieurs) nécessitaient que l'état soit stable jusqu'à ce que l'achèvement se produise. Les applications peuvent tester ce comportement en inspectant le drapeau IORING_FEAT_SUBMIT_STABLE renvoyé par io_uring_queue_init_params(3). En général, les pages de manuel des fonctions d'aide de préparation individuelles auront une note mentionnant ce fait également, si cela est requis pour la commande donnée.
