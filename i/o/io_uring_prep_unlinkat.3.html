NOM

io_uring_prep_unlinkat - prépare une requête unlinkat

SYNOPIS

#include <fcntl.h>
#include <unistd.h>
#include <liburing.h>
void io_uring_prep_unlinkat(struct io_uring_sqe *sqe,
                            int dirfd,
                            const char *path,
                            int flags);
void io_uring_prep_unlink(struct io_uring_sqe *sqe,
                          const char *path,
                          int flags);

DESCRIPTION

La fonction io_uring_prep_unlinkat(3) prépare une requête unlinkat. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier de répertoire pointé par dirfd afin de démarrer une opération unlinkat sur le chemin identifié par path et en utilisant les drapeaux donnés dans flags.

La fonction io_uring_prep_unlink(3) prépare une requête unlink. L'entrée de la file d'attente de soumission sqe est configurée pour démarrer une opération unlinkat sur le chemin identifié par path par rapport au répertoire de travail courant et en utilisant les drapeaux donnés dans flags.

Ces fonctions préparent une requête asynchrone unlinkat(2) ou unlink(2). Voir ces pages de manuel pour plus de détails.

VALEUR RENVOYÉE

Aucune

ERREURS

Le champ res de la CQE contiendra le résultat de l'opération. Voir la page de manuel associée pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones renvoient -1 en cas d'échec et définissent errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il renvoie le errno négativé directement dans le champ res de la CQE.

NOTES

Comme pour toute requête qui passe des données dans une structure, ces données doivent rester valides jusqu'à ce que la requête ait été soumise avec succès. Elles n'ont pas besoin de rester valides jusqu'à l'achèvement. Une fois qu'une requête a été soumise, l'état dans le noyau est stable. Les premiers noyaux (5.4 et antérieurs) exigeaient que l'état reste stable jusqu'à ce que l'achèvement se produise. Les applications peuvent tester ce comportement en inspectant le drapeau IORING_FEAT_SUBMIT_STABLE renvoyé par io_uring_queue_init_params(3).

VOIR AUSSI

io_uring_get_sqe(3), io_uring_submit(3), unlinkat(2), unlink(2)
