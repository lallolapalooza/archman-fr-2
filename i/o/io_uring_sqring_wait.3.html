NOM

io_uring_sqring_wait - attendre un espace libre dans le tampon d'achèvement de soumission (SQ ring)

SYNTAXE

#include <liburing.h>
int io_uring_sqring_wait(struct io_uring *ring);

DESCRIPTION

La fonction io_uring_sqring_wait(3) permet à l'appelant d'attendre qu'un espace se libère dans le tampon SQ ring appartenant au paramètre ring, ce qui se produit lorsque le thread côté noyau a consommé une ou plusieurs entrées. Si le tampon SQ ring est actuellement non plein, aucune action n'est entreprise.

Cette fonctionnalité ne peut être utilisée que lorsque le tampon a été configuré avec IORING_SETUP_SQPOLL et utilise donc une approche déchargée pour demander les soumissions.

VALEUR DE RETOUR

En cas de succès, renvoie l'espace libre. Si le noyau ne prend pas en charge cette fonctionnalité, renvoie -EINVAL.
