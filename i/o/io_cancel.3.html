NOM

io_cancel - Annuler les requêtes io

SYNTAXE

#include <errno.h>

#include <libaio.h>

int io_cancel(io_context_t ctx, struct iocb *iocb);

struct iocb {
	void		*data; /* Retourner dans l'événement de complétion io */
	unsigned	key;	/* À utiliser pour identifier les requêtes io */
	short		aio_lio_opcode;
	short		aio_reqprio; 	/* Non utilisé */
	int		aio_fildes;
};

DESCRIPTION

Tente d'annuler un iocb précédemment passé à io_submit(3). Si l'opération est annulée avec succès, l'événement résultant est copié dans la mémoire pointée par result sans être placé dans la file d'attente des complétions.

Lorsque plusieurs requêtes sont traitées de manière asynchrone, il peut être utile dans certaines situations d'annuler une opération sélectionnée, par exemple, s'il devient évident que les données écrites ne sont plus exactes et devraient être écrasées bientôt. Par exemple, supposez une application qui écrit des données dans des fichiers dans une situation où de nouvelles données entrantes devraient être écrites dans un fichier qui sera mis à jour par une requête mise en file d'attente.

VALEURS DE RETOUR

0 est retourné en cas de succès, sinon retourne errno.

ERREURS

EFAULT
Si une quelconque des structures de données pointées est invalide.
EINVAL
Si le aio_context spécifié par ctx est invalide.
EAGAIN
Si le iocb spécifié n'a pas été annulé.
ENOSYS
Si non implémenté.
