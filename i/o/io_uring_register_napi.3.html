NOM

io_uring_register_napi - enregistrer les paramètres du sondage actif NAPI

SYNTAXE

#include <liburing.h>
int io_uring_register_napi(struct io_uring *ring,
                           struct io_uring_napi *napi)

DESCRIPTION

La fonction io_uring_register_napi(3) enregistre les paramètres NAPI pour les opérations ultérieures. Les paramètres NAPI sont spécifiés dans la structure passée dans le paramètre napi. La structure comprend le délai d'attente NAPI busy_poll_to (délai d'attente du sondage actif NAPI en microsecondes) et prefer_busy_poll.

L'enregistrement d'un paramètre NAPI définit le mode lors de l'appel de la fonction napi_busy_loop et correspond à l'option de socket SO_PREFER_BUSY_POLL.

Le sondage actif NAPI peut réduire le temps de trajet aller-retour du réseau.

VALEUR DE RETOUR

En cas de succès, io_uring_register_napi(3) retourne 0. En cas d'échec, elle retourne -errno. Elle met également à jour la structure napi avec les valeurs actuelles.
