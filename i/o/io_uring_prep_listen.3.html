NOM

io_uring_prep_listen - préparer une requête d'écoute

SYNOPSIS

#include <sys/socket.h>
#include <liburing.h>
void io_uring_prep_listen(struct io_uring_sqe *sqe,
                          int sockfd,
                          intbacklog);

DESCRIPTION

La fonction io_uring_prep_listen(3) prépare une requête d'écoute. L'entrée de la file d'attente de soumission sqe est configurée pour placer le descripteur de fichier socket pointé par sockfd dans un état permettant d'accepter les connexions entrantes. Le paramètre backlog définit la longueur maximale de la file d'attente des connexions en attente.

Cette fonction prépare une requête listen(2) asynchrone. Voir cette page de manuel pour plus de détails.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res de la CQE contiendra le résultat de l'opération. Voir la page de manuel associée pour connaître les valeurs possibles. Notez que lorsque les appels système synchrones renvoient -1 en cas d'échec et définissent errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il renvoie l'errno négativé directement dans le champ res de la CQE.

VOIR AUSSI
