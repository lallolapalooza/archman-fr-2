io_uring_prep_msg_ring_fd(3) Manuel liburing io_uring_prep_msg_fd_ring(3)

NOM

io_uring_prep_msg_ring_fd - envoyer un descripteur direct à une autre boucle

SYNTAXE

#include <liburing.h>
void io_uring_prep_msg_ring_fd(struct io_uring_sqe *sqe,
                        int fd,
                        int source_fd,
                        int target_fd,
                        __u64 data,
                        unsigned int flags);
void io_uring_prep_msg_ring_fd_alloc(struct io_uring_sqe *sqe,
                        int fd,
                        int source_fd,
                        __u64 data,
                        unsigned int flags);

DESCRIPTION

io_uring_prep_msg_ring_fd(3) prépare une entrée de file d'attente de soumission (SQE) pour envoyer un descripteur de fichier direct à une autre boucle. L'entrée de file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier fd, qui doit identifier un contexte io_uring cible, pour envoyer le descripteur de fichier enregistré localement avec la valeur source_fd à la boucle de destination à l'index target_fd et passer data comme données utilisateur dans la réponse de file d'attente de complétion (CQE) cible avec les drapeaux modificateurs de requête définis par flags. Actuellement, il n'y a pas de modificateurs de drapeaux valides, ce champ doit contenir 0.

io_uring_prep_msg_ring_fd_alloc(3) est similaire à io_uring_prep_msg_ring_fd(3), mais ne spécifie pas d'index cible pour le descripteur direct. Au lieu de cela, cet index est alloué dans la boucle cible et renvoyé dans le champ res de la CQE.

VALEUR DE RETOUR

Aucune

ERREURS

Ce sont les erreurs qui sont signalées dans le champ res de la CQE.

-ENOMEM
Le noyau n'a pas pu allouer de mémoire pour la requête.
-EINVAL
L'un des champs définis dans la SQE était invalide.
-EINVAL
La boucle cible est identique à la boucle source.
-EBADFD
Le descripteur passé dans fd ne fait pas référence à un descripteur de fichier io_uring, ou la boucle est dans un état désactivé.
-EOVERFLOW
Le noyau n'a pas pu remplir une CQE sur la boucle cible. Cela peut se produire si la boucle CQ cible est dans un état de dépassement et que le noyau n'a pas pu allouer de mémoire pour une nouvelle entrée CQE.
-ENFILE
La table des descripteurs directs dans la boucle cible était pleine, aucun nouveau descripteur n'a pu être alloué avec succès.
