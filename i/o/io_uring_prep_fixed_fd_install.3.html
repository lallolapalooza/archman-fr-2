io_uring_prep_fixed_fd_install(3) Manuel liburing io_uring_prep_fixed_fd_install(3)

NOM

io_uring_prep_fixed_fd_install - prépare une requête d'installation de descripteur de fichier fixe

SYNTAXE

#include <liburing.h>
void io_uring_prep_fixed_fd_install(struct io_uring_sqe *sqe,
                                    int fd,
                                    unsigned int flags);

DESCRIPTION

L'assistant io_uring_prep_fixed_fd_install(3) prépare l'installation d'un descripteur de fichier fixe. L'entrée de la file d'attente de soumission sqe est configurée pour installer le descripteur de fichier direct/fixe fd avec les indicateurs d'installation de fichier spécifiés par flags.

Un cas d'utilisation des descripteurs de fichier directs/fixes est de transformer un descripteur de fichier ordinaire en un descripteur direct, réduisant ainsi la surcharge de toute requête nécessitant l'accès à ce fichier. Cet assistant fournit un moyen d'aller dans l'autre sens, en transformant un descripteur direct en un descripteur de fichier ordinaire qui peut ensuite être utilisé par des appels système ordinaires qui prennent un descripteur de fichier normal. Cela peut être utile si aucun descripteur de fichier ordinaire n'existe pour ce descripteur direct. Soit parce qu'il a été instancié directement comme un descripteur fixe, soit parce que le fichier ordinaire a été fermé avec close(2) après avoir été transformé en descripteur direct.

Lors du retour réussi de cette requête, un descripteur de fichier normal et un descripteur de fichier fixe existent pour le même fichier. L'un ou l'autre peut être utilisé pour accéder au fichier. L'un ou l'autre peut être fermé sans affecter l'autre.

flags peut être soit zéro, soit défini sur IORING_FIXED_FD_NO_CLOEXEC pour indiquer que le nouveau descripteur de fichier ordinaire ne doit pas être fermé lors de l'exécution. Par défaut, O_CLOEXEC sera défini sur le nouveau descripteur sinon. La définition de ce champ à autre chose que ces deux valeurs entraînera l'échec de la requête avec -EINVAL dans le champ res du CQE.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération, qui dans ce cas sera la valeur du nouveau descripteur de fichier ordinaire. En cas d'échec, une valeur négative est retournée.
