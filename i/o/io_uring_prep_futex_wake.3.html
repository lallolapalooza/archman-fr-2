NOM

io_uring_prep_futex_wake - prépare une requête d'éveil futex

SYNTAXE

#include <linux/futex.h>
#include <unistd.h>
#include <liburing.h>
void io_uring_prep_futex_wake(struct io_uring_sqe *sqe,
                              uint32_t *futex,
                              uint64_t val,
                              uint64_t mask,
                              uint32_t futex_flags,
                              unsigned int flags);

DESCRIPTION

La fonction io_uring_prep_futex_wake(3) prépare une requête d'éveil futex. L'entrée de la file d'attente de soumission sqe est configurée pour éveiller tout processus en attente sur le futex indiqué par futex et au maximum val futexes. futex_flags indique les indicateurs modificateurs de futex2(2), et les indicateurs futex de io_uring de flags.

Si un jeu de bits donné pour savoir qui éveiller est souhaité, alors il doit être défini dans mask. Utilisez FUTEX_BITSET_MATCH_ANY pour correspondre à n'importe quel processus en attente sur le futex donné.

flags sont actuellement inutilisés et donc 0 doit être passé.

Ceci prépare une requête d'éveil futex(2) asynchrone. Voir cette page de manuel pour plus de détails. Notez que la requête d'éveil futex de io_uring est similaire à l'opération FUTEX_WAKE_BITSET, car FUTEX_WAKE est un sous-ensemble strict de celle-ci.

Disponible depuis le noyau 6.7.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. En cas de succès, la valeur sera l'index dans futexv qui a reçu un éveil. Voir la page de manuel associée pour les détails sur les valeurs possibles pour les erreurs. Notez que là où les appels système synchrones retourneront -1 en cas d'échec et définiront errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il retourne l'errno négativé directement dans le champ res du CQE.
