NOM

io_uring_submit_and_wait - soumettre des requêtes à la file de soumission et attendre leur achèvement

SYNTAXE

#include <liburing.h>
int io_uring_submit_and_wait(struct io_uring *ring,
                             unsigned wait_nr);

DESCRIPTION

La fonction io_uring_submit_and_wait(3) soumet les prochaines requêtes de la file de soumission appartenant à ring et attend wait_nr événements d'achèvement.

Après que l'appelant récupère une entrée de file de soumission (SQE) avec io_uring_get_sqe(3) et prépare la SQE, elle peut être soumise avec io_uring_submit_and_wait(3).

Idéalement utilisée avec une file configurée avec IORING_SETUP_SINGLE_ISSUER|IORING_SETUP_DEFER_TASKRUN car cela réduira considérablement le nombre de changements de contexte que une application verra lors de l'attente de plusieurs requêtes.

VALEUR DE RETOUR

En cas de succès, io_uring_submit_and_wait(3) retourne le nombre d'entrées de file de soumission soumises. En cas d'échec, il retourne -errno.
