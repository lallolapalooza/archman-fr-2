NOM

io_prep_fsync - Synchroniser l'état complet d'un fichier en mémoire avec celui sur disque

SYNOPIS

#include <errno.h>

#include <libaio.h>

static inline void io_prep_fsync(struct iocb *iocb, int fd);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

DESCRIPTION

Ceci est une fonction utilitaire en ligne pour préparer un iocbv pour une requête FSYNC.

Le fichier pour lequel

iocb->aio_fildes = fd
est un descripteur est préparé avec la commande 
iocb->aio_lio_opcode = IO_CMD_FSYNC

La fonction io_prep_fsync() préparera une opération IO_CMD_FSYNC pour forcer de manière asynchrone toutes les opérations d'E/S associées au fichier indiqué par le descripteur de fichier aio_fildes membre de la structure iocb référencée par l'argument iocb et mises en file d'attente au moment de l'appel à io_submit() à l'état de achèvement d'E/S synchronisé. L'appel de fonction retournera lorsque la requête de synchronisation aura été initiée ou mise en file d'attente vers le fichier ou le périphérique (même si les données ne peuvent pas être synchronisées immédiatement).

Toutes les opérations d'E/S actuellement mises en file d'attente seront complétées comme par un appel à fsync(2) ; c'est-à-dire, tel que défini pour l'achèvement de l'intégrité des fichiers en E/S synchronisées. Si l'opération mise en file d'attente par io_prep_fsync() échoue, alors, comme pour fsync(2), les opérations d'E/S en attente ne sont pas garanties d'avoir été complétées.

Si io_prep_fsync() réussit, alors ce sont uniquement les E/S qui étaient mises en file d'attente au moment de l'appel à io_submit(3) qui sont garanties d'être forcées à l'état d'achèvement pertinent. L'achèvement des E/S subséquentes sur le descripteur de fichier n'est pas garanti d'être effectué de manière synchronisée.

Cette fonction retourne immédiatement. Pour planifier l'opération, la fonction io_submit(3) doit être appelée.

Les opérations asynchrones simultanées utilisant le même iocb produisent des résultats indéfinis.
