IOCTL-XFS-FSCOUNTS(2) Manuel des appels système IOCTL-XFS-FSCOUNTS(2)

NOM

ioctl_xfs_fscounts - interroger les informations des compteurs récapitulatifs XFS

SYNTAXE

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_FSCOUNTS, struct xfs_fsop_counts *arg);

DESCRIPTION

Interroge les compteurs récapitulatifs bruts du système de fichiers. Contrairement à statvfs(3), les valeurs retournées ici sont les valeurs brutes, qui ne reflètent aucune altération ou limite définie par les quotas de projet. Les informations des compteurs sont transmises dans une structure de la forme suivante :


struct xfs_fsop_counts {
	__u64   freedata;
	__u64   freertx;
	__u64   freeino;
	__u64   allocino;
};

Les champs de cette structure sont les suivants :

freedata est le nombre de blocs libres du système de fichiers sur le périphérique de données.

freertx est le nombre d'étendues libres sur le périphérique temps réel.

freeino est le nombre d'enregistrements d'inodes qui ne sont pas utilisés dans l'espace qui leur a été alloué.

allocino est le nombre d'enregistrements d'inodes pour lesquels de l'espace a été alloué.

VALEUR DE RETOUR

En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

Les codes d'erreur peuvent être, sans s'y limiter, les suivants :

EFSBADCRC
La validation du checksum des métadonnées a échoué lors de l'exécution de la requête.
EFSCORRUPTED
Une corruption des métadonnées a été rencontrée lors de l'exécution de la requête.
EINVAL
Le numéro du groupe d'allocation spécifié n'est pas valide pour ce système de fichiers.
EIO
Une erreur d'E/S a été rencontrée lors de l'exécution de la requête.

CONFORMITÉ

Cette API est spécifique au système de fichiers XFS sur le noyau Linux.
