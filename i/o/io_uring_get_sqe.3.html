NOM

io_uring_get_sqe - obtenir la prochaine entrée de file d'attente de soumission disponible à partir de la file d'attente de soumission

SYNTAXE

#include <liburing.h>
struct io_uring_sqe *io_uring_get_sqe(struct io_uring *ring);

DESCRIPTION

La fonction io_uring_get_sqe(3) obtient la prochaine entrée de file d'attente de soumission disponible à partir de la file d'attente de soumission appartenant au paramètre ring.

En cas de succès, io_uring_get_sqe(3) renvoie un pointeur vers l'entrée de file d'attente de soumission. En cas d'échec, NULL est renvoyé.

Si une entrée de file d'attente de soumission est renvoyée, elle doit être remplie via l'une des fonctions de préparation telles que io_uring_prep_read(3) et soumise via io_uring_submit(3).

Notez que ni io_uring_get_sqe ni les fonctions de préparation ne définissent (ou n'effacent) le champ user_data de la SQE. Si l'appelant s'attend à ce que io_uring_cqe_get_data(3) ou io_uring_cqe_get_data64(3) renvoie des données valides lors de la récupération des complétions d'E/S, soit io_uring_sqe_set_data(3), soit io_uring_sqe_set_data64(3) DOIT avoir été appelé avant la soumission de la requête.

VALEUR DE RETOUR

io_uring_get_sqe(3) renvoie un pointeur vers la prochaine entrée de la file d'attente de soumission en cas de succès et NULL en cas d'échec. Si NULL est renvoyé, la file d'attente de soumission est actuellement pleine et des entrées doivent être soumises pour traitement avant que de nouvelles puissent être allouées.

VOIR AUSSI

io_uring_submit(3), io_uring_sqe_set_data(3)
