NOM

io_uring_prep_ftruncate - prépare une requête ftruncate

SYNTAXE

#include <liburing.h>
void io_uring_prep_ftruncate(struct io_uring_sqe *sqe,
                             int fd,
                             loff_t len);

DESCRIPTION

La fonction io_uring_prep_ftruncate(3) prépare une requête ftruncate. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier fd qui doit être tronqué à la longueur indiquée par l'argument len.

Les applications doivent définir _GNU_SOURCE pour obtenir la définition de cette fonction utilitaire, car loff_t ne sera pas défini sans cela.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. Voir la page de manuel correspondante pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones retourneront -1 en cas d'échec et définiront errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il retourne le errno négatif directement dans le champ res du CQE.
