io_cancel(2) Manuel des appels système io_cancel(2)

NOM

io_cancel - annuler une opération d'E/S asynchrone en cours

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

Alternativement, bibliothèque d'E/S asynchrones (libaio, -laio) ; voir VERSIONS.

SYNTAXE

#include <linux/aio_abi.h>    /* Définition des types nécessaires */
#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
int syscall(SYS_io_cancel, aio_context_t ctx_id, struct iocb *iocb,
            struct io_event *result);

DESCRIPTION

Note : cette page décrit l'interface brute de l'appel système Linux. La fonction enveloppe fournie par libaio utilise un type différent pour l'argument ctx_id. Voir VERSIONS.

L'appel système io_cancel() tente d'annuler une opération d'E/S asynchrone précédemment soumise avec io_submit(2). L'argument iocb décrit l'opération à annuler et l'argument ctx_id est le contexte AIO auquel l'opération a été soumise. Si l'opération est annulée avec succès, l'événement sera copié dans la mémoire pointée par result sans être placé dans la file d'attente des complétions.

VALEUR DE RETOUR

En cas de succès, io_cancel() retourne 0. Pour les erreurs, voir VERSIONS.

ERREURS

EAGAIN
Le iocb spécifié n'a pas été annulé.
EFAULT
Une des structures de données pointe vers des données invalides.
EINVAL
Le contexte AIO spécifié par ctx_id est invalide.
ENOSYS
io_cancel() n'est pas implémenté sur cette architecture.

VERSIONS

Vous voudrez probablement utiliser la fonction enveloppe io_cancel() fournie par libaio.

Notez que la fonction enveloppe libaio utilise un type différent (io_context_t) pour l'argument ctx_id. Notez également que l'enveloppe libaio ne suit pas les conventions habituelles de la bibliothèque C pour indiquer les erreurs : en cas d'erreur, elle retourne un numéro d'erreur négatif (l'opposé d'une des valeurs listées dans ERREURS). Si l'appel système est invoqué via syscall(2), alors la valeur de retour suit les conventions habituelles pour indiquer une erreur : -1, avec errno défini à une valeur (positive) qui indique l'erreur.

NORMES

Linux.

HISTORIQUE

Linux 2.5.

VOIR AUSSI

io_destroy(2), io_getevents(2), io_setup(2), io_submit(2), aio(7)
