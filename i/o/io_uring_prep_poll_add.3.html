NOM

io_uring_prep_poll_add - préparer une requête de sondage

SYNTAXE

#include <poll.h>
#include <liburing.h>
void io_uring_prep_poll_add(struct io_uring_sqe *sqe,
                            int fd,
                            unsigned poll_mask);
void io_uring_prep_poll_multishot(struct io_uring_sqe *sqe,
                                  int fd,
                                  unsigned poll_mask);

DESCRIPTION

La fonction io_uring_prep_poll_add(3) prépare une requête de sondage. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier fd qui doit être sondé, avec les événements souhaités spécifiés dans l'argument poll_mask.

Le comportement par défaut est une requête de sondage unique. Lorsque l'événement spécifié s'est déclenché, un CQE de complétion est posté et aucun autre événement ne sera généré par la requête de sondage. io_uring_prep_poll_multishot(3) se comporte de manière identique en termes d'événements, mais elle persiste au-delà des notifications et publiera de manière répétée des notifications pour la même inscription. Un CQE posté à partir d'une requête de sondage multishot aura IORING_CQE_F_MORE défini dans le membre flags du CQE, indiquant que l'application doit s'attendre à d'autres complétions de cette requête. Si la requête de sondage multishot est terminée ou rencontre une erreur, ce drapeau ne sera pas défini dans le CQE. Si cela se produit, l'application ne doit pas s'attendre à d'autres CQE de la requête d'origine et doit en réémettre une nouvelle si elle souhaite toujours recevoir des notifications sur ce descripteur de fichier.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération, qui est un masque de bits des événements notifiés. Voir la page de manuel de poll(2) pour plus de détails. Notez que lorsque les appels système synchrones retourneront -1 en cas d'échec et définiront errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il renvoie l'errno nié directement dans le champ res du CQE.
