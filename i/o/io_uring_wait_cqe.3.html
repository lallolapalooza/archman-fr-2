NOM

io_uring_wait_cqe - attendre un événement de complétion io_uring

SYNTAXE

#include <liburing.h>
int io_uring_wait_cqe(struct io_uring *ring,
                      struct io_uring_cqe **cqe_ptr);

DESCRIPTION

La fonction io_uring_wait_cqe(3) attend une complétion d'E/S de la file d'attente appartenant au paramètre ring, attendant si nécessaire. Si un événement est déjà disponible dans la file d'attente lors de l'appel, aucune attente ne se produira. Le paramètre cqe_ptr est rempli en cas de succès.

Après que l'appelant a soumis une requête avec io_uring_submit(3), l'application peut récupérer la complétion avec io_uring_wait_cqe(3).

VALEUR DE RETOUR

En cas de succès, io_uring_wait_cqe(3) retourne 0 et le paramètre cqe_ptr est rempli. En cas d'échec, il retourne -errno. La valeur de retour indique le résultat de l'attente d'un CQE et n'a aucun rapport avec le résultat du CQE lui-même.

VOIR AUSSI

io_uring_submit(3), io_uring_wait_cqe_timeout(3), io_uring_wait_cqes(3)
