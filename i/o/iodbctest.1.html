iodbctest(1) Gestionnaire de pilotes iODBC iodbctest(1)

NOM

iodbctest, iodbctestw - Programmes de démonstration iODBC

SYNOPSIS

iodbctest ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=value]"]
iodbctestw ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=value]"]

DESCRIPTION

Les programmes iodbctest et iodbtestw sont des programmes simples d'exemple ODBC, montrant la puissance de l'API ODBC pour se connecter à n'importe quelle base de données compatible ODBC, émettre des commandes SQL et récupérer les résultats de la requête.

Le programme iodbctest utilise les appels API ODBC standard pour se connecter en utilisant n'importe quel DSN, mais récupère tous les résultats en mode ASCII.

Le programme iodbctestw utilise les appels API Unicode ODBC pour se connecter en utilisant n'importe quel DSN, et récupère tous les résultats en mode Unicode.

OPTIONS

Le programme iodbctest utilise la fonction SQLDriverConnect pour établir une connexion en utilisant n'importe quel pilote ODBC conforme disponible. Cela permet à l'utilisateur de remplacer n'importe quel attribut de connexion ODBC dans la chaîne DSN.

Les chaînes de connexion doivent commencer par un attribut DSN=xxx ou DRIVER=xxxx, suivi éventuellement d'autres attributs DSN séparés par un point-virgule, par exemple :

DSN=ora9;UID=scott;PWD=tiger;DATABASE=ora9u

Tous les attributs requis pour une connexion correcte qui ne sont pas entrants dans la chaîne de connexion DSN, doivent être présents dans le fichier odbc.ini.

Si la chaîne de connexion est passée comme argument au programme iodbctest, la chaîne doit être mise entre guillemets car la plupart des shells utilisent le point-virgule comme séparateur de commande. Si la chaîne de connexion est entrée à l'invite interactive, aucun guillemet ne doit être utilisé.

Après qu'une connexion réussie ait été établie, l'utilisateur est invité à entrer une commande SQL à envoyer à la base de données. Une commande SQL ne peut pas s'étendre sur plusieurs lignes.

Si la commande SQL renvoie un ou plusieurs ensembles de résultats, chaque ensemble de résultats est récupéré en utilisant des tampons de caractères et affiché dans un tableau.

De plus, le programme iodbctest comprend quelques commandes spéciales :

qualifiers

Affiche une liste de qualificateurs en utilisant l'appel catalogue SQLTables.
owners

Affiche une liste de propriétaires en utilisant l'appel catalogue SQLTables.
tables

Affiche une liste de tables en utilisant l'appel catalogue SQLTables.
types

Affiche une liste de types de tables en utilisant l'appel catalogue SQLTables.
datatypes

Affiche une liste de types de données en utilisant l'appel catalogue SQLGetTypeInfo.
reconnect

Effectue une déconnexion/reconnexion avec les informations sauvegardées lors du premier SQLDriverConnect.
quit (ou exit)

Quitte le programme et retourne au shell.

EXEMPLES

Lance le programme iodbctest et obtient une liste de DSNs avant d'établir une connexion :

    $ iodbctest
    OpenLink ODBC Demonstration program
    This program shows an interactive SQL processor
    Enter ODBC connect string (? shows list): ?
    DSN                              | Driver
    -----------------------------------------------------------------
    ora9                             | OpenLink Generic ODBC Driver
    mysql                            | OpenLink Generic ODBC Driver
    mysqllite                        | OpenLink Lite for MySQL
    myodbc                           | MyODBC Driver
    pgsql                            | OpenLink Generic ODBC Driver
    tds                              | OpenLink Generic ODBC Driver
    Enter ODBC connect string (? shows list): DSN=ora9;PWD=tiger
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>

Se connecte à une instance Oracle 9 qui a été précédemment configurée dans le fichier odbc.ini :

    $ iodbctest "DSN=ora9;UID=scott;PWD=tiger"
    iODBC Demonstration program
    This program shows an interactive SQL processor
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>select * from emp
    ID               |NAME
    -----------------+-------------------------------------------
    1                |Record 1
    2                |Record 2
    2                |Record 3
     result set 1 returned 3 rows.
    SQL> quit
