NOM

iodbc-config - script pour obtenir des informations sur la version installée d'iODBC

SYNTAXE

iodbc-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--cflags] [--libs] [--static-libs] [--libtool-libs] [--odbcini] [--odbcinstini]

DESCRIPTION

iodbc-config est un outil utilisé pour configurer et déterminer les indicateurs du compilateur et de l'éditeur de liens qui doivent être utilisés pour compiler et lier des programmes utilisant iODBC.

OPTIONS

iodbc-config accepte les options suivantes :

--version
Affiche la version actuellement installée de iODBC sur la sortie standard.
--cflags
Affiche les indicateurs du compilateur qui sont nécessaires pour compiler un programme iODBC.
--libs
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme iODBC en utilisant des bibliothèques dynamiques (si supporté).
--static-libs
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme iODBC en utilisant des bibliothèques statiques.
--libtool-libs
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme iODBC dans un environnement libtool.
--odbcini
Affiche le chemin du fichier odbc.ini système.
--odbcinstini
Affiche le chemin du fichier odbcinst.ini système.
--prefix[=PREFIX]
Si spécifié, utilise PREFIX au lieu du préfixe d'installation avec lequel iODBC a été compilé lors du calcul de la sortie pour les options --cflags et --libs. Cette option est également utilisée pour le préfixe d'exécution si --exec-prefix n'a pas été spécifié. Cette option doit être spécifiée avant toute option --libs ou --cflags.

Si PREFIX n'est pas spécifié, le drapeau --prefix indique où iODBC est actuellement installé.

--exec-prefix=PREFIX
Si spécifié, utilise PREFIX au lieu du préfixe d'exécution d'installation avec lequel iODBC a été compilé lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.

EXEMPLES

Pour compiler un programme qui appelle l'API iODBC, assurez-vous que le programme iodbc-config peut être trouvé dans la variable d'environnement PATH, avant d'utiliser le fragment Makefile suivant :

    CFLAGS=`iodbc-config --cflags`
    LDLIBS=`iodbc-config --libs`
    iodbctest: iodbctest.c
	    cc $(CFLAGS) -o iodbctest iodbctest.c $(LDLIBS)
