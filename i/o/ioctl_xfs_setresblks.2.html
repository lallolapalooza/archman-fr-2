ioctl_xfs_setresblks(2)

IOCTL-XFS-SETRESBLKS(2) Manuel des appels système IOCTL-XFS-SETRESBLKS(2)

NOM

ioctl_xfs_setresblks - interroger et définir les informations de réservation d'espace libre XFS

SYNTAXE

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_GET_RESBLKS, struct xfs_fsop_resblks *arg);
int ioctl(int fd, XFS_IOC_SET_RESBLKS, struct xfs_fsop_resblks *arg);

DESCRIPTION

Interroge ou définit les informations de réservation d'espace libre. Ces blocs sont réservés par le système de fichiers comme dernière tentative pour éviter les échecs de mise à jour des métadonnées dus à un manque d'espace. Seul l'administrateur système peut utiliser ces ioctls, car le dépassement des valeurs par défaut est extrêmement dangereux.

Cette fonctionnalité est destinée uniquement aux développeurs de systèmes de fichiers XFS.

Les informations de réservation sont transmises dans une structure de la forme suivante :


struct xfs_fsop_resblks {
	__u64  resblks;
	__u64  resblks_avail;
};

resblks est le nombre de blocs que le système de fichiers essaiera de maintenir pour éviter les situations critiques de manque d'espace.

resblks_avail est le nombre de blocs réservés restants.

VALEUR DE RETOUR

En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

Les codes d'erreur peuvent être, sans s'y limiter, les suivants :

EFSBADCRC
La validation de la somme de contrôle des métadonnées a échoué lors de l'interrogation.
EFSCORRUPTED
Une corruption des métadonnées a été rencontrée lors de l'interrogation.
EINVAL
Le numéro de groupe d'allocation spécifié n'est pas valide pour ce système de fichiers.
EIO
Une erreur d'E/S a été rencontrée lors de l'interrogation.
EPERM
L'appelant n'a pas la permission d'appeler cet ioctl.

CONFORMITÉ

Cette API est spécifique au système de fichiers XFS du noyau Linux.
