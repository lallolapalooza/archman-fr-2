NOM

io_uring_setup_buf_ring - configurer et enregistrer un anneau de tampons pour les tampons fournis

SYNTAXE

#include <liburing.h>
struct io_uring_buf_ring *io_uring_setup_buf_ring(struct io_uring *ring,
                                                  unsigned int nentries,
                                                  int bgid,
                                                  unsigned int flags,
                                                  int *err);

DESCRIPTION

La fonction io_uring_setup_buf_ring(3) enregistre un anneau de tampons partagé à utiliser avec les tampons fournis. Pour les types de requêtes qui le prennent en charge, les tampons fournis sont donnés à l'anneau et un est sélectionné par une requête si elle a IOSQE_BUFFER_SELECT défini dans les flags du SQE, lorsque la requête est prête à recevoir des données. Cela permet à la fois une propriété claire de la durée de vie du tampon, et un moyen d'avoir plus d'opérations de type lecture/réception en vol que de tampons disponibles.

L'argument ring doit être un pointeur vers l'anneau pour lequel l'anneau de tampons fournis est enregistré, nentries est le nombre d'entrées demandées dans l'anneau de tampons. Cet argument doit être une puissance de 2 en taille, et peut aller jusqu'à 32768. bgid est l'identifiant de groupe de tampons choisi, flags sont les indicateurs modificateurs pour l'opération, et *err est un pointeur vers un entier pour la valeur d'erreur si une partie de l'allocation et de l'enregistrement de l'anneau échoue.

L'argument flags peut être défini sur l'une des valeurs suivantes :

IOU_PBUF_RING_INC
Les tampons de cet anneau peuvent être consommés progressivement. Avec une consommation partielle, chaque achèvement d'un identifiant de tampon donné continuera là où le précédent s'est arrêté, ou depuis le début si aucun achèvement n'a encore été vu. Lorsque d'autres achèvements sont attendus pour un identifiant de tampon donné, le CQE aura IORING_CQE_F_BUF_MORE défini dans le membre flags. Disponible depuis la version 6.12.

En coulisses, cette fonction utilise io_uring_register_buf_ring(3) pour enregistrer l'anneau, et gère l'allocation de l'anneau plutôt que de laisser l'application le coder.

Pour désenregistrer et libérer un identifiant de groupe de tampons configuré avec cette fonction, l'application doit appeler io_uring_free_buf_ring(3).

Disponible depuis la version 5.19.

VALEUR DE RETOUR

En cas de succès, io_uring_setup_buf_ring(3) retourne un pointeur vers l'anneau de tampons. En cas d'échec, elle retourne NULL et définit *err sur -errno.

NOTES

Notez que même si le noyau prend en charge cette fonctionnalité, l'enregistrement d'un anneau de tampons fournis peut toujours échouer avec -EINVAL si l'hôte est une architecture 32 bits et que la mémoire passée réside dans la mémoire haute.
