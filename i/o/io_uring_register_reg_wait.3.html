NOM

io_uring_register_reg_wait - Enregistre des régions d'attente fixes

SYNTAXE

#include <liburing.h>
int io_uring_register_reg_wait(struct io_uring *ring,
                               struct io_uring_reg_wait *reg,
                               int nr);

DESCRIPTION

La fonction io_uring_register_reg_wait(3) enregistre une région d'attente fixe commençant à reg et contenant nr entrées auprès du ring indiqué par ring.

Cette fonction fonctionne comme io_uring_setup_reg_wait(3), sauf qu'elle n'alloue aucune mémoire pour le compte de l'application. L'application doit fournir de la mémoire précédemment allouée dans reg, qui doit avoir la bonne taille pour contenir nr entrées et être correctement alignée sur une limite de page.

La mémoire enregistrée ne doit pas être libérée tant que le ring pour lequel elle est enregistrée n'est pas fermé.

Une fois qu'une région d'attente a été configurée, elle persiste pendant toute la durée de vie du ring. Il n'est actuellement pas possible de désenregistrer ou de redimensionner une région d'attente. De plus, une région d'attente ne peut actuellement utiliser qu'une seule page de mémoire. Sur un système avec une taille de page de 4 Ko, cela signifie qu'une application est limitée à 64 régions d'attente. Cela devrait suffire, car chaque index d'attente peut être modifié selon les besoins. Avec au moins 64 index disponibles, les applications peuvent probablement simplement utiliser la région d'attente correctement configurée pour chaque type d'attente spécifique, avec des indices différents ayant des paramètres d'attente différents.

Disponible depuis le noyau 6.13.

VALEUR DE RETOUR

En cas de succès, io_uring_register_reg_wait(3) renvoie 0. En cas d'échec, elle renvoie une valeur -errno.
