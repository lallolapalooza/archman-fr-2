    NAME

    io_uring_prep_send, io_uring_prep_sendmsg, io_uring_prep_sendto — prepare a send request

    SYNOPSIS

    #include <linux/io_uring.h>

void io_uring_prep_send(struct io_uring_sqe *sqe, int sockfd,
                        const void *buf, size_t len, int flags);
int io_uring_prep_sendmsg(struct io_uring_sqe *sqe, int sockfd,
                          const struct msghdr *msg, int flags);
int io_uring_prep_sendto(struct io_uring_sqe *sqe, int sockfd,
                         const void *buf, size_t len, int flags,
                         const struct sockaddr *dest_addr, socklen_t addrlen);

    DESCRIPTION

    The io_uring_prep_send, io_uring_prep_sendmsg, and io_uring_prep_sendto functions are used to prepare a submission queue entry (SQE) for submitting a send operation. These functions do not perform the send operation directly, but rather fill in the necessary fields in the sqe structure for a subsequent submission to the kernel.

    io_uring_prep_send is a simplified interface for sending data. It takes the socket file descriptor, a buffer containing the data to be sent, the length of the data, and any flags to be passed to the send call.

    io_uring_prep_sendmsg prepares a send operation using the sendmsg(2) system call. This allows for more complex send operations, including sending data with associated control information or sending to a specific destination address if the socket is not connected.

    io_uring_prep_sendto prepares a send operation using the sendto(2) system call. This is suitable for datagram sockets where the destination address needs to be specified with each send operation.

    The arguments are:

    • sqe: A pointer to the submission queue entry to be prepared.
    • sockfd: The file descriptor of the socket to send data on.
    • buf: A pointer to the buffer containing the data to be sent.
    • len: The number of bytes to send from the buffer.
    • flags: Flags to be passed to the underlying send system call (e.g., MSG_DONTWAIT).
    • msg: A pointer to a struct msghdr for io_uring_prep_sendmsg.
    • dest_addr: A pointer to the destination address structure for io_uring_prep_sendto.
    • addrlen: The size of the destination address structure for io_uring_prep_sendto.

    After calling one of these preparation functions, the sqe should be submitted to the io_uring instance using io_uring_submit(). The result of the send operation will be reported back via a completion queue entry (CQE).

    RETURN VALUE

    These functions do not return a value. They modify the sqe in place.

    ERRORS

    These preparation functions do not return errors. Errors related to the send operation itself will be reported through the completion queue entry (CQE) when the operation completes.
