NOM

io_uring_prep_write - préparer une requête d'écriture d'E/S

SYNOPSIS

#include <liburing.h>
void io_uring_prep_write(struct io_uring_sqe *sqe,
                         int fd,
                         const void *buf,
                         unsigned nbytes,
                         __u64 offset);

DESCRIPTION

La fonction io_uring_prep_write(3) prépare une requête d'écriture d'E/S. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier fd afin de commencer à écrire nbytes depuis le tampon buf à l'emplacement offset spécifié.

Pour les fichiers qui supportent la recherche, si l'offset est réglé sur -1, l'opération d'écriture commence à l'offset de fichier actuel, et l'offset de fichier est incrémenté du nombre d'octets écrits. Voir write(2) pour plus de détails. Notez que pour une API asynchrone, la lecture et la mise à jour de l'offset de fichier actuel peuvent entraîner un comportement imprévisible, sauf si l'accès au fichier est sérialisé. Il est déconseillé d'utiliser cette fonctionnalité s'il est possible de fournir l'offset d'E/S souhaité depuis l'application ou la bibliothèque.

Pour les fichiers qui ne sont pas capables de recherche, l'offset doit être 0 ou -1.

Après la préparation de l'écriture, elle peut être soumise avec l'une des fonctions de soumission.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. Voir la page de manuel correspondante pour les détails sur les valeurs possibles. Notez que lorsque les appels système synchrones renvoient -1 en cas d'échec et définissent errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il renvoie le errno nié directement dans le champ res du CQE.
