DESCRIPTIO

N

Obtenir la table d'allocation des blocs pour un segment d'un fichier dans un système de fichiers XFS. Les informations de correspondance sont transmises via un tableau de structures de la forme suivante

: 


struct getbmap {
	__s64   bmv_offset;
	__s64   bmv_block;
	__s64   bmv_length;
	__s32   bmv_count;
	__s32   bmv_entries;
}
;

L'ioctl XFS_IOC_GETBMAPX utilise une version plus grande de cette structure

: 


struct getbmapx {
	__s64   bmv_offset;
	__s64   bmv_block;
	__s64   bmv_length;
	__s32   bmv_count;
	__s32   bmv_entries;
	__s32   bmv_iflags;
	__s32   bmv_oflags;
	__s32   bmv_unused1;
	__s32   bmv_unused2;
}
;

Toutes les tailles et les décalages dans la structure sont en unités de 512

octets.

La première structure du tableau est un en-tête et les structures restantes du tableau contiennent les informations de la table d'allocation des blocs au retour. L'en-tête contrôle les appels itératifs à la commande et doit être rempli comme suit

:
