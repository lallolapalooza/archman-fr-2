KDSETL
ED
Définit les LED. Les LED sont définies pour correspondre aux trois bits de poids faible de l'entier unsigned long dans argp. Cependant, si un bit de poids supérieur est défini, les LED reprennent leur comportement normal
: afficher l'état des fonctions clavier verrouillag
e majuscules, verrouillage numérique et défilement.

Avant Linux 1.1.54, les LED reflétaient simplement l'état des indicateurs de clavier correspondants, et KDGETLED/KDSETLED modifiaient également les indicateurs de clavier. Depuis Linux 1.1.54, les LED peuvent afficher des informations arbitraires, mais par défaut elles affichent les indicateurs de clavier. Les deux ioctls suivants sont utilisés pour accéder aux indicateurs de

clavier.
KDGKBL
ED
Récupère les indicateurs de clavier CapsLock, NumLock, ScrollLock (pas les lumières). argp pointe vers un char qui est défini avec l'état des indicateurs. Les trois bits de poids faible (masque 0x7) reçoivent l'état actuel des indicateurs, et les bits de poids faible du nibble suivant (masque 0x70) reçoivent l'état par défaut des indicateurs. (Depuis Linux 1.1.
54.)
KDSKBL
ED
Définit les indicateurs de clavier CapsLock, NumLock, ScrollLock (pas les lumières). argp est un entier unsigned long contenant l'état des indicateurs souhaité. Les trois bits de poids faible (masque 0x7) contiennent l'état des indicateurs, et les bits de poids faible du nibble suivant (masque 0x70) contiennent l'état par défaut des indicateurs. (Depuis Linux 1.1.
54.)

KDMKTO
NE
Génère un ton de durée spécifiée. Les 16 bits de poids faible de l'entier unsigned long dans argp spécifient la période en cycles d'horloge, et les 16 bits de poids supérieur donnent la durée en millisecondes. Si la durée est zéro, le son est désactivé. Le contrôle revient immédiatement. Par exemple, argp = (125<<16) + 0x637 spécifierait le bip normalement associé à un ctrl-G. (Ainsi, depuis Linux 0.99pl1 ; cassé dans Linux 2.1.49-50.
)
KIOCSOU
ND
Démarre ou arrête la génération de son. Les 16 bits de poids faible de argp spécifient la période en cycles d'horloge (c'est-à-dire, argp = 1193180/fréquence). argp = 0 désactive le son. Dans les deux cas, le contrôle revient
immédiatement.
GIO_CM
AP
Récupère la table de couleurs par défaut actuelle depuis le noyau. argp pointe vers un tableau de 48 octets. (Depuis Linux 1.3.
3.)
PIO_CM
AP
Modifie la table de couleurs par défaut du mode texte. argp pointe vers un tableau de 48 octets contenant, dans l'ordre, les valeurs Rouge, Vert et Bleu pour les 16 couleurs d'écran disponibles : 0 est éteint, et 255 est l'intensité maximale. Les couleurs par défaut sont, dans l'ordre : noir, rouge foncé, vert foncé, brun, bleu foncé, violet foncé, cyan foncé, gris clair, gris foncé, rouge vif, vert vif, jaune, bleu vif, violet vif, cyan vif et blanc. (Depuis Linux 1.3.
3.)
GIO_FO
NT
Récupère la police d'écran de 256 caractères sous forme étendue. argp pointe vers un tableau de 8192 octets. Échoue avec le code d'erreur EINVAL si la police actuellement chargée est une police de 512 caractères, ou si la console n'est pas en mode
texte.
GIO_FON
TX
Récupère la police d'écran et les informations associées. argp pointe vers une struct consolefontdesc (voir PIO_FONTX). Lors de l'appel, le champ charcount doit être défini au nombre maximal de caractères qui tiendraient dans le buffer pointé par chardata. Au retour, les champs charcount et charheight sont remplis avec les données respectives pour la police actuellement chargée, et le tableau chardata contient les données de la police si la valeur initiale de charcount indiquait qu'il y avait suffisamment d'espace disponible ; sinon, le buffer reste intact et errno est défini à ENOMEM. (Depuis Linux 1.3.
1.)
PIO_FO
NT
Définit la police d'écran de 256 caractères. Charge la police dans le générateur de caractères EGA/VGA. argp pointe vers une table de 8192 octets, avec 32 octets par caractère. Seuls les N premiers sont utilisés pour une police 8xN (0 < N <= 32). Cet appel invalide également le mappage
Unicode.

GIO_UNISCRNM
AP
Récupère le mappage d'écran Unicode complet depuis le noyau. argp pointe vers une zone de taille E_TABSZ*sizeof(unsigned short), qui est chargée avec les caractères Unicode représentés par chaque caractère. Un ensemble spécial de caractères Unicode, commençant à U+F000, est utilisé pour représenter les mappages « direct vers la police ». (Depuis Linux 1.
3.1.)
