NOM

io_uring_prep_madvise - préparer une requête madvise

SYNOPSIS

#include <sys/mman.h>
#include <liburing.h>
void io_uring_prep_madvise(struct io_uring_sqe *sqe,
                           void *addr,
                           __u32 len,
                           int advice);

void io_uring_prep_madvise64(struct io_uring_sqe *sqe,
                             void *addr,
                             off_t len,
                             int advice);

DESCRIPTION

La fonction io_uring_prep_madvise(3) prépare une requête madvise. L'entrée de la file d'attente de soumission sqe est configurée pour démarrer une opération madvise à l'adresse virtuelle de addr et d'une longueur de len octets, en lui donnant le conseil situé dans advice.

La fonction io_uring_prep_madvise64(3) fonctionne comme io_uring_prep_madvise(3), sauf qu'elle prend une longueur de 64 bits plutôt que seulement 32 bits. Les anciens noyaux peuvent ne pas prendre en charge la variante de longueur 64 bits. Si cette variante est tentée sur un noyau qui ne prend pas en charge les longueurs 64 bits, la requête échouera avec -EINVAL dans le champ des résultats du CQE.

Cette fonction prépare une requête madvise(2) asynchrone. Voir cette page de manuel pour les détails.

VALEUR RENVOYÉE

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. Voir la page de manuel correspondante pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones renvoient -1 en cas d'échec et définissent errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il renvoie le errno nié directement dans le champ res du CQE.
