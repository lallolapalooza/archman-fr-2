NOM

io_uring_wait_cqe_timeout - attend un événement de complétion io_uring avec délai d'attente

SYNOPSIS

#include <liburing.h>
int io_uring_wait_cqe_timeout(struct io_uring *ring,
                              struct io_uring_cqe **cqe_ptr,
                              struct __kernel_timespec *ts);

DESCRIPTION

La fonction io_uring_wait_cqe_timeout(3) attend qu'une complétion d'E/S soit disponible dans la file d'attente appartenant à ring, en attendant si nécessaire ou jusqu'à expiration du délai ts. Si un événement est déjà disponible dans la file d'attente lors de l'invocation, aucune attente ne sera effectuée.

Le paramètre cqe_ptr est rempli en cas de succès.

Si ts est spécifié et qu'un ancien noyau sans IORING_FEAT_EXT_ARG est utilisé, l'application n'a pas besoin d'appeler io_uring_submit(3) avant d'appeler io_uring_wait_cqes(3). Pour les noyaux plus récents avec ce drapeau de fonctionnalité activé, il n'y a pas de soumission implicite lors de l'attente d'une requête.

Si ts est NULL, cela se comporte comme io_uring_wait_cqe(3) en ce sens qu'il attendra indéfiniment un événement.

VALEUR DE RETOUR

En cas de succès, io_uring_wait_cqe_timeout(3) retourne 0 et le paramètre cqe_ptr est rempli. En cas d'échec, il retourne -errno. La valeur de retour indique le résultat de l'attente d'un CQE, et n'a aucun rapport avec le résultat du CQE lui-même. Si un délai d'attente se produit, il retournera -ETIME.
