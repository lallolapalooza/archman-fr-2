NOM

io_uring_prep_link_timeout - une requête de délai d'attente pour les sqes liées

SYNTAXE

#include <liburing.h>
void io_uring_prep_link_timeout(struct io_uring_sqe *sqe,
                                struct __kernel_timespec *ts,
                                unsigned flags);

DESCRIPTION

La fonction io_uring_prep_link_timeout(3) prépare une requête de délai d'attente pour les sqes liées. L'entrée de file d'attente de soumission sqe est configurée pour un délai d'attente spécifié par ts. L'argument flags contient des modificateurs flags pour le comportement du délai d'attente de la requête.

L'argument ts doit être rempli avec les informations appropriées pour le délai d'attente. Il se présente comme suit :


struct __kernel_timespec {
    __kernel_time64_t tv_sec;
    long long tv_nsec;
};

L'argument flags peut contenir :

IORING_TIMEOUT_ABS
La valeur spécifiée dans ts est une valeur absolue plutôt que relative.
IORING_TIMEOUT_BOOTTIME
La source d'horloge de démarrage doit être utilisée.
IORING_TIMEOUT_REALTIME
La source d'horloge temps réel doit être utilisée.
IORING_TIMEOUT_ETIME_SUCCESS
Considérer un délai d'attente expiré comme un succès en ce qui concerne l'achèvement posté.

Il est invalide de créer une chaîne (sqes liées) composée uniquement d'une requête de délai d'attente liée. Si toutes les requêtes de la chaîne sont terminées avant le délai d'attente, la requête de délai d'attente liée est annulée. En cas de dépassement du délai d'attente, toutes les requêtes non terminées de la chaîne sont annulées.

VALEUR DE RETOUR

Aucune

ERREURS

Ce sont les erreurs qui sont signalées dans le champ res du CQE. En cas de succès, 0 est retourné.

-ETIME
Le délai d'attente spécifié s'est produit et a déclenché l'événement d'achèvement.
-EINVAL
Un des champs définis dans le SQE était invalide. Par exemple, deux sources d'horloge ont été données, ou les secondes ou nanosecondes du délai d'attente spécifié étaient < 0.
-EFAULT
io_uring n'a pas pu accéder aux données spécifiées par ts.
-ECANCELED
Le délai d'attente a été annulé car toutes les requêtes soumises ont été terminées avec succès ou l'une des requêtes a résulté en un échec.
-ENOENT
La requête à laquelle le délai d'attente lié était lié s'est déjà terminée et n'a pas pu être trouvée lorsque le délai d'attente a expiré.
