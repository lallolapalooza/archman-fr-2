NOM

io_uring_unregister_files - désenregistrer les descripteurs de fichiers

SYNTAXE

#include <liburing.h>
int io_uring_unregister_files(struct io_uring *ring);

DESCRIPTION

La fonction io_uring_unregister_files(3) désenregistre les descripteurs de fichiers précédemment enregistrés auprès de ring.

VALEUR DE RETOUR

En cas de succès, io_uring_unregister_files(3) retourne 0. En cas d'échec, elle retourne -errno.
