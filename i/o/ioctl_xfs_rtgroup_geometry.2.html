IOCTL-XFS-RTGROUP-GEOMETRY(2) Manuel des appels système IOCTL-XFS-RTGROUP-GEOMETRY(2)

NOM

ioctl_xfs_rtgroup_geometry - interroger les informations de géométrie du groupe temps réel XFS

SYNTAXE

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_RTGROUP_GEOMETRY, struct xfs_rtgroup_geometry *arg);

DESCRIPTION

Cet appel ioctl XFS récupère les informations de géométrie pour un groupe temps réel donné. Les informations de géométrie sont transmises dans une structure de la forme suivante :


struct xfs_rtgroup_geometry {
	__u32  rg_number;
	__u32  rg_length;
	__u32  rg_sick;
	__u32  rg_checked;
	__u32  rg_flags;
	__u32  rg_reserved[27];
};
rg_number
L'appelant doit définir ce champ sur l'index du groupe temps réel sur lequel l'appelant souhaite obtenir des informations.
rg_length
La longueur du groupe temps réel est retournée dans ce champ, en unités de blocs de système de fichiers. rg_flags L'appelant peut définir ce champ pour modifier le comportement opérationnel de l'ioctl. Actuellement, aucun drapeau n'est défini, ce champ doit donc être zéro.
rg_reserved et rg_pad
Tous les champs réservés seront mis à zéro au retour.

Les champs rg_sick et rg_checked indiquent l'état relatif de diverses métadonnées du groupe temps réel :

•
Si un drapeau de défaut donné est défini dans rg_sick, alors cette partie des métadonnées a été observée comme étant endommagée. Le même bit sera défini dans rg_checked.
•
Si un drapeau de défaut donné est défini dans rg_checked et n'est pas défini dans rg_sick, alors cette partie des métadonnées a été vérifiée et n'est pas défectueuse.
•
Si un drapeau de défaut donné n'est pas défini dans rg_checked, alors aucune conclusion ne peut être faite.

Les drapeaux suivants s'appliquent à ces champs :

XFS_RTGROUP_GEOM_SICK_SUPER
Superbloc du groupe temps réel.
XFS_RTGROUP_GEOM_SICK_BITMAP
Map de bits temps réel pour ce groupe.
XFS_RTGROUP_GEOM_SICK_SUMMARY
Résumé temps réel pour ce groupe.
XFS_RTGROUP_GEOM_SICK_RTRMAPBT
Arbre binaire de mappage inversé pour ce groupe.

VALEUR DE RETOUR

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Les codes d'erreur peuvent être l'un des suivants, sans s'y limiter :

EFSBADCRC
La validation de la somme de contrôle des métadonnées a échoué lors de l'interrogation.
EFSCORRUPTED
Une corruption de métadonnées a été rencontrée lors de l'interrogation.
EINVAL
Le numéro du groupe temps réel spécifié n'est pas valide pour ce système de fichiers.
EIO
Une erreur d'E/S a été rencontrée lors de l'interrogation.

CONFORMITE

Cette API est spécifique au système de fichiers XFS du noyau Linux.
