ioctl_pipe(2) Manuel des appels système ioctl_pipe(2)

NOM

ioctl_pipe - opérations ioctl() pour un mécanisme de notification général

SYNTAXE

#include <linux/watch_queue.h>  /* Définition de IOC_WATCH_QUEUE_* */
#include <sys/ioctl.h>
int ioctl(int pipefd, IOC_WATCH_QUEUE_SET_SIZE, int size);
int ioctl(int pipefd, IOC_WATCH_QUEUE_SET_FILTER,
          struct watch_notification_filter *filter);

DESCRIPTION

Les opérations ioctl(2) suivantes sont fournies pour configurer les paramètres de la file d'attente de notifications générale. La file d'attente de notifications est construite sur un pipe(2) ouvert avec le drapeau O_NOTIFICATION_PIPE.

IOC_WATCH_QUEUE_SET_SIZE (depuis Linux 5.8)
Préalloue la mémoire du tampon du pipe pour qu'il puisse contenir size messages de notification. Actuellement, size doit être compris entre 1 et 512.
IOC_WATCH_QUEUE_SET_FILTER (depuis Linux 5.8)
Le filtre de file d'attente de surveillance peut limiter les événements reçus. Les filtres sont passés dans une struct watch_notification_filter et chaque filtre est décrit par une structure struct watch_notification_type_filter.

struct watch_notification_filter {
        __u32   nr_filters;
        __u32   __reserved;
        struct watch_notification_type_filter filters[];
};
struct watch_notification_type_filter {
        __u32   type;
        __u32   info_filter;
        __u32   info_mask;
        __u32   subtype_filter[8];
};
