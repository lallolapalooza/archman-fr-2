NOM

io_uring_for_each_cqe - itérer sur les événements de complétion en attente

SYNTAXE

#include <liburing.h>
io_uring_for_each_cqe(struct io_uring *ring,
                      unsigned head,
                      struct io_uring_cqe *cqe) { }

DESCRIPTION

La macro io_uring_for_each_cqe(3) est une aide macro qui itère sur les événements de complétion appartenant à ring en utilisant head comme itérateur temporaire, et pointe cqe vers chaque événement en attente lors de l'itération.

Cette aide fournit un moyen efficace d'itérer sur tous les événements en attente dans le ring, puis d'avancer le ring CQ en appelant io_uring_cq_advance(3) avec le nombre de CQE consommés lorsque terminé. Comme la mise à jour de l'état du ring CQ visible par le noyau implique une écriture ordonnée, le faire une seule fois pour un certain nombre d'événements est plus efficace que de traiter chaque complétion séparément et d'appeler io_uring_cqe_seen(3) pour chacun d'eux.

EXEMPLE

void handle_cqes(struct io_uring *ring)
{
	struct io_uring_cqe *cqe;
	unsigned head;
	unsigned i = 0;
	io_uring_for_each_cqe(ring, head, cqe) {
		/* gérer la complétion */
		printf("cqe: %d\n", cqe->res);
		i++;
	}
	io_uring_cq_advance(ring, i);
}

VALEUR DE RETOUR

Aucune
