NOM

io_uring_sqe_set_data - définir les données utilisateur pour une entrée de file d'attente de soumission

SYNTAXE

#include <liburing.h>
void io_uring_sqe_set_data(struct io_uring_sqe *sqe,
                           void *user_data);

void io_uring_sqe_set_data64(struct io_uring_sqe *sqe,
                             __u64 data);

DESCRIPTION

La fonction io_uring_sqe_set_data(3) stocke un pointeur user_data avec l'entrée de file d'attente de soumission sqe.

La fonction io_uring_sqe_set_data64(3) stocke une valeur de 64 bits data avec l'entrée de file d'attente de soumission sqe.

Une fois que l'appelant a demandé une entrée de file d'attente de soumission (SQE) avec io_uring_get_sqe(3), il peut associer un pointeur de données ou une valeur à la SQE. Une fois la complétion arrivée, la fonction io_uring_cqe_get_data(3) ou io_uring_cqe_get_data64(3) peut être appelée pour récupérer le pointeur de données ou la valeur associée à la requête soumise.

Notez que si aucune de ces fonctions n'est appelée, ou si le champ user_data dans la sqe n'est pas défini manuellement non plus, le champ peut contenir une valeur d'une utilisation précédente de cette sqe. Si une application repose sur la présence constante d'une valeur user_data valide, elle doit toujours lui en attribuer une pour chaque sqe.

VALEUR DE RETOUR

Aucune
