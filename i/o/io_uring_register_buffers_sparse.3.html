NOM

io_uring_register_buffers - enregistrer des tampons pour les opérations à tampons fixes

SYNOPSIS

#include <liburing.h>
int io_uring_register_buffers(struct io_uring *ring,
                              const struct iovec *iovecs,
                              unsigned nr_iovecs);
int io_uring_register_buffers_tags(struct io_uring *ring,
                                   const struct iovec *iovecs,
                                   const __u64 *tags,
                                   unsigned nr);
int io_uring_register_buffers_sparse(struct io_uring *ring,
                                     unsigned nr_iovecs);
int io_uring_register_buffers_update_tag(struct io_uring *ring,
                                         unsigned off,
                                         const struct iovec *iovecs,
                                         const __u64 *tags,
                                         unsigned nr);

DESCRIPTION

La fonction io_uring_register_buffers(3) enregistre nr_iovecs tampons définis par le tableau iovecs appartenant au ring.

La fonction io_uring_register_buffers_tags(3) se comporte de la même manière que la fonction io_uring_register_buffers(3) mais prend en plus le paramètre tags. Voir IORING_REGISTER_BUFFERS2 pour la description du marquage de ressources.

La fonction io_uring_register_buffers_sparse(3) enregistre nr_iovecs tampons vides appartenant au ring. Ces tampons doivent être mis à jour avant utilisation, par exemple avec io_uring_register_buffers_update_tag(3).

Après que l'appelant a enregistré les tampons, ceux-ci peuvent être utilisés avec une des fonctions de tampons fixes.

L'enregistrement des tampons est une optimisation utile en conjonction avec les lectures et écritures O_DIRECT, car elle mappe la plage spécifiée dans le noyau une fois lors de l'enregistrement du tampon au lieu de faire un mappage et un démappage pour chaque opération d'E/S chaque fois qu'une E/S est effectuée sur cette région. De plus, cela évite également la manipulation des comptes de références de page pour chaque E/S.

La fonction io_uring_register_buffers_update_tag(3) met à jour les tampons enregistrés avec de nouveaux tampons, transformant une entrée sparse en une entrée réelle ou remplaçant une entrée existante. off est le décalage auquel commencer la mise à jour de nr tampons définis par le tableau iovecs appartenant au ring. tags pointe vers un tableau d'étiquettes. Voir IORING_REGISTER_BUFFERS2 pour la description du marquage de ressources.

VALEUR DE RETOUR

En cas de succès, io_uring_register_buffers(3), io_uring_register_buffers_tags(3) et io_uring_register_buffers_sparse(3) retournent 0. io_uring_register_buffers_update_tag(3) retourne le nombre de tampons mis à jour. En cas d'échec, elles retournent -errno.
