NOM

io_uring_prep_sync_file_range - prépare une requête sync_file_range

SYNTAXE

#include <fcntl.h>
#include <liburing.h>
void io_uring_prep_sync_file_range(struct io_uring_sqe *sqe,
                                   int fd,
                                   unsigned len,
                                   __u64 offset,
                                   int flags);

DESCRIPTION

La fonction io_uring_prep_sync_file_range(3) prépare une requête sync_file_range. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier fd qui doit synchroniser len octets commençant à l'offset offset et avec les drapeaux modificateurs dans l'argument flags.

Cette fonction prépare une requête sync_file_range(2) asynchrone. Voir cette page de manuel pour les détails sur les arguments.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. Voir la page de manuel associée pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones retourneront -1 en cas d'échec et définiront errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il retourne le errno négativé directement dans le champ res du CQE.

VOIR AUSSI

io_uring_get_sqe(3), io_uring_submit(3), sync_file_range(2)
