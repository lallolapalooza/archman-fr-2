io_uring_wait_cqes(3) Manuel liburing io_uring_wait_cqes(3)

NOM

io_uring_wait_cqes - attendre un ou plusieurs événements de complétion io_uring

SYNTAXE

#include <liburing.h>
int io_uring_wait_cqes(struct io_uring *ring,
                       struct io_uring_cqe **cqe_ptr,
                       unsigned wait_nr,
                       struct __kernel_timespec *ts,
                       sigset_t *sigmask);

DESCRIPTION

La fonction io_uring_wait_cqes(3) retourne wait_nr comptes rendus de complétion IO depuis la file d'attente appartenant au paramètre ring, en attendant ces derniers si nécessaire ou jusqu'à l'expiration du délai ts.

Le paramètre sigmask spécifie l'ensemble des signaux à bloquer. S'il est défini, cela est équivalent à exécuter atomiquement les appels suivants :


sigset_t origmask;
pthread_sigmask(SIG_SETMASK, &sigmask, &origmask);
ret = io_uring_wait_cqes(ring, cqe, wait_nr, ts, NULL);
pthread_sigmask(SIG_SETMASK, &origmask, NULL);

Le paramètre cqe_ptr est rempli en cas de succès avec le premier CQE. Les appelants de cette fonction doivent utiliser io_uring_for_each_cqe(3) pour parcourir tous les CQE disponibles.

Si ts est spécifié et qu'un noyau plus ancien sans IORING_FEAT_EXT_ARG est utilisé, l'application n'a pas besoin d'appeler io_uring_submit(3) avant d'appeler io_uring_wait_cqes(3). Pour les noyaux plus récents avec ce drapeau de fonctionnalité activé, il n'y a pas de soumission implicite lors de l'attente d'une requête.

Si ts est NULL , alors cela se comporte comme io_uring_wait_cqe(3) en ce sens qu'il attendra indéfiniment un événement.

VALEUR DE RETOUR

En cas de succès, io_uring_wait_cqes(3) retourne 0 et le paramètre cqe_ptr est rempli. En cas d'échec, il retourne -errno. Si un délai expire, il retournera -ETIME.
