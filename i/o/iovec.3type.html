iovec(3type) iovec(3type)

NOM

iovec - Structure de données pour les entrées/sorties vectorielles

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <sys/uio.h>
struct iovec {
    void   *iov_base;  /* Adresse de départ */
    size_t  iov_len;   /* Taille de la mémoire pointée par iov_base. */
};

DESCRIPTION

Décrit une région de mémoire, commençant à l'adresse iov_base et avec la taille de iov_len octets. Les appels système utilisent des tableaux de cette structure, où chaque élément du tableau représente une région mémoire, et le tableau entier représente un vecteur de régions mémoire. Le nombre maximum de structures iovec dans ce tableau est limité par IOV_MAX (défini dans <limits.h>, ou accessible via l'appel sysconf(_SC_IOV_MAX)).

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

NOTES

L'en-tête suivant fournit également ce type : <sys/socket.h>.

VOIR AUSSI

process_madvise(2), readv(2)
