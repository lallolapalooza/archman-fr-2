NOM

io_uring_register_sync_cancel - émettre une requête d'annulation synchrone

SYNTAXE

#include <liburing.h>
int io_uring_register_sync_cancel(struct io_uring *ring,
                                  struct io_uring_sync_cancel_reg *reg);

DESCRIPTION

La fonction io_uring_register_sync_cancel(3) effectue une requête d'annulation synchrone basée sur les paramètres spécifiés dans reg.

L'argument reg doit être rempli avec les informations appropriées pour la requête d'annulation. Il se présente comme suit :


struct io_uring_sync_cancel_reg {
    __u64 addr;
    __s32 fd;
    __u32 flags;
    struct __kernel_timespec timeout;
    __u8 opcode;
    __u8 pad[7];
    __u64 pad2[3];
};

Les arguments reflètent largement ce que les fonctions de préparation asynchrones prennent en charge, voir io_uring_prep_cancel(3) pour les détails. De même, la valeur de retour est la même. La seule exception est l'argument timeout, qui peut être utilisé pour limiter le temps que le noyau attendra le succès des annulations. Si les valeurs tv_sec et tv_nsec sont définies sur autre chose que -1UL, elles indiquent un délai d'expiration relatif avant lequel les annulations doivent être terminées.

Les valeurs pad doivent être remplies de zéros.

VALEUR DE RETOUR

Voir io_uring_prep_cancel(3) pour les détails sur la valeur de retour. Si timeout est défini pour indiquer un délai d'attente, alors -ETIME sera renvoyé s'il est dépassé. Si une valeur inconnue est définie dans la requête, ou si les valeurs de remplissage ne sont pas effacées à zéro, alors -EINVAL est renvoyé.
