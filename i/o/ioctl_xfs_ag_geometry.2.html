NOM

ioctl_xfs_ag_geometry - interroger les informations de géométrie des groupes d'allocation XFS

SYNOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_AG_GEOMETRY, struct xfs_ag_geometry *arg);

DESCRIPTION

Cet ioctl XFS récupère les informations de géométrie pour un groupe d'allocation donné. Les informations de géométrie sont transmises dans une structure de la forme suivante :


struct xfs_ag_geometry {
	uint32_t  ag_number;
	uint32_t  ag_length;
	uint32_t  ag_freeblks;
	uint32_t  ag_icount;
	uint32_t  ag_ifree;
	uint32_t  ag_sick;
	uint32_t  ag_checked;
	uint32_t  ag_flags;
	uint64_t  ag_reserved[12];
};
ag_number
L'appelant doit définir ce champ sur l'indice du groupe d'allocation sur lequel l'appelant souhaite obtenir des informations.
ag_length
La longueur du groupe d'allocation est retournée dans ce champ, en unités de blocs du système de fichiers.
ag_freeblks
Le nombre de blocs libres dans le groupe d'allocation est retourné dans ce champ, en unités de blocs du système de fichiers.
ag_icount
Le nombre d'enregistrements d'inodes alloués dans ce groupe d'allocation est retourné dans ce champ.
ag_ifree
Le nombre d'enregistrements d'inodes inutilisés (de l'espace alloué) dans ce groupe d'allocation est retourné dans ce champ.
ag_flags
L'appelant peut définir ce champ pour modifier le comportement opérationnel de l'ioctl. Actuellement, aucun drapeau n'est défini, ce champ doit donc être nul.
ag_reserved
Tous les champs réservés seront mis à zéro au retour.

Les champs ag_sick et ag_checked indiquent la santé relative des différentes métadonnées du groupe d'allocation :

•
Si un drapeau de défaillance donné est défini dans ag_sick, alors cette pièce de métadonnée a été observée comme étant endommagée. Le même bit sera défini dans ag_checked.
•
Si un drapeau de défaillance donné est défini dans ag_checked et n'est pas défini dans ag_sick, alors cette pièce de métadonnée a été vérifiée et n'est pas défectueuse.
•
Si un drapeau de défaillance donné n'est pas défini dans ag_checked, alors aucune conclusion ne peut être tirée.

Les drapeaux suivants s'appliquent à ces champs :

XFS_AG_GEOM_SICK_SB
Superbloc du groupe d'allocation.
XFS_AG_GEOM_SICK_AGF
En-tête de l'espace libre.
XFS_AG_GEOM_SICK_AGFL
Liste de réserve d'espace libre.
XFS_AG_GEOM_SICK_AGI
En-tête des inodes.
XFS_AG_GEOM_SICK_BNOBT ou XFS_AG_GEOM_SICK_CNTBT
Arbres de blocs de l'espace libre.
XFS_AG_GEOM_SICK_INOBT ou XFS_AG_GEOM_SICK_FINOBT
Arbres d'inodes.
XFS_AG_GEOM_SICK_RMAPBT
Arbre de mappage inversé.
XFS_AG_GEOM_SICK_REFCNTBT
Arbre des comptes de référence.

VALEUR DE RETOUR

En cas d'erreur, -1 est retourné, et errno est définie pour indiquer l'erreur.

ERREURS

Les codes d'erreur peuvent être, sans s'y limiter, les suivants :

EFSBADCRC
La validation de la somme de contrôle des métadonnées a échoué lors de l'interrogation.
EFSCORRUPTED
Une corruption des métadonnées a été rencontrée lors de l'interrogation.
EINVAL
Le numéro du groupe d'allocation spécifié n'est pas valide pour ce système de fichiers.
EIO
Une erreur d'E/S a été rencontrée lors de l'interrogation.

CONFORMITÉ

Cette API est spécifique au système de fichiers XFS sur le noyau Linux.
