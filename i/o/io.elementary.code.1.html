NOM

io.elementary.code - éditeur de texte qui travaille pour vous

SYNTAXE

io.elementary.code [OPTION...] [FICHIER...]

DESCRIPTION

Code est l'éditeur de texte qui travaille pour vous. Il enregistre automatiquement vos fichiers, ce qui signifie qu'ils sont toujours à jour. De plus, il se souvient de vos onglets afin que vous ne perdiez jamais votre place, même entre les sessions.

Personnalisez-le. Code est écrit à partir de zéro pour être extensible. Gardez les choses super légères et simples, ou installez des extensions pour transformer Code en un environnement de développement intégré complet ; c'est votre choix. Et avec une poignée de préférences utiles, vous pouvez ajuster le comportement et l'interface à votre goût.

C'est élémentaire. Code est conçu pour être l'éditeur de texte parfait pour elementary OS, ce qui signifie qu'il suit de près les normes élevées de conception, de vitesse et de cohérence. Il est élégant, mais pas distrayant.

Fonctionne avec votre langage. Que vous créiez du code en Vala, que vous écriviez des scripts en PHP ou que vous balisiez en HTML, Code vous couvre. Bénéficiez de la coloration syntaxique complète avec presque tous les langages de programmation, de script et de balisage.

OPTIONS

-t, --new-tab
Ouvrir un nouvel onglet.
-n, --new-window
Ouvrir une nouvelle fenêtre.
-h, --help
Afficher un message d'aide et quitter.
-v, --version
Afficher les informations de version et quitter.
--display=AFFICHAGE
Affichage X à utiliser.
