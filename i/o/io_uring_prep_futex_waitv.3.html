io_uring_prep_futex_waitv(3) Manuel liburing io_uring_prep_futex_waitv(3)

NOM

io_uring_prep_futex_waitv - prépare une requête d'attente futexv

SYNTAXE

#include <linux/futex.h>
#include <unistd.h>
#include <liburing.h>
void io_uring_prep_futex_waitv(struct io_uring_sqe *sqe,
                               struct futex_waitv *futexv,
                               uint32_t nr_futex,
                               unsigned int flags);

DESCRIPTION

La fonction io_uring_prep_futex_waitv(3) prépare une requête d'attente futex pour plusieurs futex en même temps. L'entrée de la file de soumission sqe est configurée pour attendre sur tous les futex fournis par futexv et nr_futex est le nombre de futex dans ce tableau. flags doit être défini sur les drapeaux futex spécifiques à io_uring.

Contrairement à io_uring_prep_futex_wait(3), le masque de bits et les valeurs désirés sont passés dans futexv.

Les flags ne sont actuellement pas utilisés et par conséquent 0 doit être passé.

Ceci prépare une requête d'attente futexv asynchrone via futex(2). Voir la page de manuel correspondante pour les détails.

Disponible depuis le noyau 6.7.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. Voir la page de manuel associée pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones retournent -1 en cas d'échec et définissent errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il retourne le errno négativé directement dans le champ res du CQE.

NOTES

Contrairement aux appels système futex synchrones qui attendent sur un futex, io_uring ne prend pas en charge le passage d'un délai d'attente pour la requête. Au lieu de cela, il est conseillé aux applications d'utiliser un délai d'attente lié pour annuler la requête futex à un moment donné, si désiré.
