NOM

io_queue_run - Gérer les requêtes io complétées

SYNOPSIS

#include <errno.h>

#include <libaio.h>

int io_queue_run(io_context_t ctx);

DESCRIPTION

io_queue_run() tente de lire tous les événements de la file d'attente de complétion pour le contexte aio spécifié par ctx.

VALEUR DE RETOUR

Peut retourner 0 si aucun événement n'est disponible. Échouera avec -ENOSYS si non implémenté.

ERREURS

EFAULT
iocbs référence des données en dehors de l'espace d'adressage accessible du programme.
EINVAL
ctx fait référence à un contexte aio non initialisé, l'iocb pointé par iocbs contient un iocb mal initialisé.
ENOSYS
Non implémenté.
