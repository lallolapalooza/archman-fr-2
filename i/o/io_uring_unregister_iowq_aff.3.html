NOM

io_uring_register_iowq_aff - enregistrer les affinités CPU des workers asynchrones

SYNTAXE

#include <sched.h>
#include <liburing.h>
int io_uring_register_iowq_aff(struct io_uring *ring,
                               size_t cpusz,
                               const cpu_set_t *mask);
void io_uring_unregister_iowq_aff(struct io_uring *ring);

DESCRIPTION

La fonction io_uring_prep_register_iowq_aff(3) enregistre un ensemble d'affinités CPU à utiliser par les workers asynchrones de io_uring. Par défaut, les workers asynchrones de io_uring sont autorisés à s'exécuter sur n'importe quel CPU du système. Si cette fonction est appelée avec ring pointant vers le ring concerné et mask pointant vers une valeur cpu_set_t et cpusz indiquant la taille de l'ensemble CPU, alors les workers asynchrones ne seront autorisés à s'exécuter que sur les CPUs spécifiés dans le masque. Les workers existants peuvent avoir besoin d'atteindre un point de planification avant d'être migrés.

Pour la désinscription, io_uring_unregister_iowq_aff(3) peut être appelée pour restaurer les affinités CPU par défaut.

Les applications doivent définir _GNU_SOURCE pour obtenir la définition de cette aide, car cpu_set_t ne sera pas défini sans elle.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou l'une des valeurs suivantes en cas d'erreur.

-EFAULT
Le noyau n'a pas pu copier la mémoire pointée par mask car elle était invalide.
-ENOMEM
Le noyau n'a pas pu allouer de mémoire pour le nouveau masque CPU.
-EINVAL
cpusz ou mask était NULL/0, ou toute autre valeur spécifiée était invalide.
