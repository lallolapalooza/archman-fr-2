io_uring_submit_and_wait_timeout(3) Manuel liburing io_uring_submit_and_wait_timeout(3)

NOM

io_uring_submit_and_wait_timeout - soumettre des requêtes à la file de soumission et attendre leur achèvement avec un délai d'attente

SYNTAXE

#include <liburing.h>
int io_uring_submit_and_wait_timeout(struct io_uring *ring,
                                     struct io_uring_cqe **cqe_ptr,
                                     unsigned wait_nr,
                                     struct __kernel_timespec *ts,
                                     sigset_t *sigmask);

DESCRIPTION

La fonction io_uring_submit_and_wait_timeout(3) soumet les requêtes suivantes de la file de soumission appartenant à ring et attend wait_nr événements d'achèvement, ou jusqu'à ce que le délai d'attente ts expire. Les événements d'achèvement sont stockés dans le tableau cqe_ptr.

Le paramètre sigmask spécifie l'ensemble des signaux à bloquer. S'il est défini, cela équivaut à l'exécution atomique des appels suivants :


sigset_t origmask;
pthread_sigmask(SIG_SETMASK, &sigmask, &origmask);
ret = io_uring_submit_and_wait_timeout(ring, cqe, wait_nr, ts, NULL);
pthread_sigmask(SIG_SETMASK, &origmask, NULL);

Après que l'appelant ait récupéré une entrée de file de soumission (SQE) avec io_uring_get_sqe(3) et préparé la SQE, elle peut être soumise avec io_uring_submit_and_wait_timeout(3).

Idéalement utilisé avec un anneau configuré avec IORING_SETUP_SINGLE_ISSUER|IORING_SETUP_DEFER_TASKRUN car cela réduira considérablement le nombre de changements de contexte que une application verra lors de l'attente de plusieurs requêtes.

VALEUR DE RETOUR

En cas de succès, io_uring_submit_and_wait_timeout(3) retourne le nombre d'entrées de file de soumission soumises. En cas d'échec, il retourne -errno. Notez que dans les versions antérieures de la bibliothèque liburing, la valeur de retour était 0 en cas de succès. Le cas d'échec le plus courant est de ne pas recevoir d'achèvement dans le délai spécifié, -ETIME est retourné dans ce cas.
