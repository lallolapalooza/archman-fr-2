NOM

io_uring_prep_fsync - préparer une requête fsync

SYNTAXE

#include <liburing.h>
void io_uring_prep_fsync(struct io_uring_sqe *sqe,
                         int fd,
                         unsigned flags);

DESCRIPTION

La fonction io_uring_prep_fsync(3) prépare une requête fsync. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier fd qui doit être synchronisé, avec les indicateurs modificateurs indiqués par l'argument flags.

Cette fonction prépare une requête fsync. Elle peut agir soit comme une opération fsync(2), ce qui est le comportement par défaut. Si IORING_FSYNC_DATASYNC est défini dans l'argument flags, elle se comporte comme fdatasync(2). Si aucune plage n'est spécifiée, le fd sera synchronisé de 0 à la fin du fichier.

Il est possible de spécifier une plage à synchroniser, si désiré. Si le champ off du SQE est défini à une valeur non nulle, cela indique le décalage auquel commencer la synchronisation. Si len est défini dans le SQE, cela indique la taille en octets à synchroniser à partir du décalage. Notez que ces champs ne sont pas acceptés par cette fonction utilitaire, ils doivent donc être définis manuellement dans le SQE après avoir appelé cette fonction utilitaire de préparation.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res de la CQE contiendra le résultat de l'opération. Voir la page de manuel correspondante pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones retourneront -1 en cas d'échec et définiront errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il retourne le errno négativé directement dans le champ res de la CQE.
