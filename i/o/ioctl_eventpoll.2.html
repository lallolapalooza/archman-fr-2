ioctl_eventpoll(2) Manuel des appels système ioctl_eventpoll(2)

NOM

ioctl_eventpoll, EPIOCSPARAMS, EPIOCGPARAMS - opérations ioctl() pour les descripteurs de fichiers epoll

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/epoll.h>  /* Définition des constantes EPIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, EPIOCSPARAMS, const struct epoll_params *argp);
int ioctl(int fd, EPIOCGPARAMS, struct epoll_params *argp);
#include <sys/epoll.h>
struct epoll_params {
    uint32_t  busy_poll_usecs;   /* Nombre d'usecs pour le sondage actif */
    uint16_t  busy_poll_budget;  /* Nombre max de paquets par sondage */
    uint8_t   prefer_busy_poll;  /* Préférence booléenne  */
    /* rembourrage de la structure pour être un multiple de 64 bits */
    uint8_t   __pad;             /* Doit être zéro */
};

DESCRIPTION

EPIOCSPARAMS
Définit la structure epoll_params pour configurer le fonctionnement d'epoll. Se référer à la description de la structure ci-dessous pour connaître la configuration prise en charge.
EPIOCGPARAMS
Récupère les paramètres de configuration actuels d'epoll_params.

Toutes les opérations décrites ci-dessus doivent être effectuées sur un descripteur de fichier epoll, que l'on peut obtenir par un appel à epoll_create(2) ou epoll_create1(2).

La structure epoll_params

argp.busy_poll_usecs indique le nombre de microsecondes pendant lesquelles la pile réseau fera du sondage actif. Pendant cette période, le périphérique réseau sera sondé à plusieurs reprises pour les paquets. Cette valeur ne peut pas dépasser INT_MAX.

argp.busy_poll_budget indique le nombre maximum de paquets que la pile réseau récupérera à chaque tentative de sondage. Cette valeur ne peut pas dépasser NAPI_POLL_WEIGHT (qui est 64 depuis Linux 6.9), à moins que le processus ne soit exécuté avec CAP_NET_ADMIN.

argp.prefer_busy_poll est un champ booléen et doit être soit 0 (désactivé) soit 1 (activé). Si activé, cela indique à la pile réseau que le sondage actif est la méthode préférée pour traiter les données réseau et que la pile réseau doit donner à l'application la possibilité de faire du sondage actif. Sans cette option, les systèmes très sollicités peuvent continuer à faire le traitement réseau via la méthode normale des IRQ déclenchant les softIRQ et NAPI.

argp.__pad doit être zéro.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'échec, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EOPNOTSUPP
Le noyau n'a pas été compilé avec le support du sondage actif.
EINVAL
fd n'est pas un descripteur de fichier valide.
EINVAL
argp.__pad n'est pas zéro.
EINVAL
argp.busy_poll_usecs dépasse INT_MAX.
EINVAL
argp.prefer_busy_poll n'est ni 0 ni 1.
EPERM
Le processus est exécuté sans CAP_NET_ADMIN et le argp.busy_poll_budget spécifié dépasse NAPI_POLL_WEIGHT.
EFAULT
argp est une adresse invalide.

NORMES

Linux.

HISTORIQUE

Linux 6.9. glibc 2.40.

EXEMPLES

/* Code pour définir les paramètres epoll afin d'activer le sondage actif */
int epollfd = epoll_create1(0);
struct epoll_params params;
if (epollfd == -1) {
    perror("epoll_create1");
    exit(EXIT_FAILURE);
}
memset(&params, 0, sizeof(struct epoll_params));
params.busy_poll_usecs = 25;
params.busy_poll_budget = 8;
params.prefer_busy_poll = 1;
if (ioctl(epollfd, EPIOCSPARAMS, &params) == -1) {
    perror("ioctl");
    exit(EXIT_FAILURE);
}
/* Code pour montrer comment récupérer les paramètres actuels */
memset(&params, 0, sizeof(struct epoll_params));
if (ioctl(epollfd, EPIOCGPARAMS, &params) == -1) {
    perror("ioctl");
    exit(EXIT_FAILURE);
}
/* La structure params contient maintenant les paramètres actuels */
fprintf(stderr, "epoll usecs: %lu\n", params.busy_poll_usecs);
fprintf(stderr, "epoll packet budget: %u\n", params.busy_poll_budget);
fprintf(stderr, "epoll prefer busy poll: %u\n", params.prefer_busy_poll);
