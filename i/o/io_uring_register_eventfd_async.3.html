NOM

io_uring_register_eventfd - enregistre un eventfd avec un ring

SYNTAXE

#include <liburing.h>
int io_uring_register_eventfd(struct io_uring *ring,
                              int fd);
int io_uring_register_eventfd_async(struct io_uring *ring,
                                    int fd);
int io_uring_unregister_eventfd(struct io_uring *ring);

DESCRIPTION

io_uring_register_eventfd(3) enregistre le descripteur de fichier eventfd fd avec le ring identifié par ring.

Chaque fois que des complétions sont postées sur le ring CQ, une notification eventfd est générée avec le descripteur eventfd enregistré. Si io_uring_register_eventfd_async(3) est utilisé, seules les événements qui se sont terminés hors bande déclencheront une notification.

Si les notifications ne sont plus souhaitées, io_uring_unregister_eventfd(3) peut être appelé pour supprimer l'enregistrement eventfd. Aucun argument eventfd n'est nécessaire, car un ring ne peut avoir qu'un seul eventfd enregistré.

NOTES

Bien que io_uring prenne généralement soin d'éviter les événements erronés, ils peuvent se produire. De même, les complétions par lots de CQE peuvent déclencher une seule notification eventfd même si plusieurs CQE sont postés. L'application ne doit faire aucune supposition sur le fait que le nombre d'événements disponibles ait une corrélation directe avec les notifications eventfd postées. Une notification eventfd doit donc être traitée uniquement comme un indice pour vérifier le ring CQ pour les complétions.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -errno en cas d'erreur.
