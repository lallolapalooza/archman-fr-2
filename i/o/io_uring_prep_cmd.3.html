NOM

io_uring_prep_cmd_sock - prépare une requête de commande pour un socket

SYNOPSIS

#include <liburing.h>
void io_uring_prep_cmd_sock(struct io_uring_sqe *sqe,
                            int cmd_op,
                            int fd,
                            int level,
                            int optname,
                            void *optval,
                            int optlen);

DESCRIPTION

La fonction io_uring_prep_cmd_sock(3) prépare une requête de commande (cmd) pour un socket. L'entrée de file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier socket pointé par fd pour démarrer une opération de commande définie par cmd_op.

Ceci est une fonction générique, et chaque commande a ses propres valeurs level, optname, optval spécifiques. L'argument optlen définit la taille de ce qui est pointé par optval.

COMMANDES DISPONIBLES

SOCKET_URING_OP_SIOCINQ
Retourne la quantité de données non lues en attente dans le tampon de réception. Le socket ne doit pas être en état d'écoute (LISTEN), sinon une erreur -EINVAL est retournée dans le champ res du CQE. Les arguments suivants ne sont pas utilisés pour cette commande : level, optname, optval et optlen.

Une valeur de retour négative signifie une erreur.

Pour plus d'informations sur cette commande, veuillez consulter unix(7).

Disponible depuis la version 6.7.

SOCKET_URING_OP_SIOCOUTQ
Retourne la quantité de données non envoyées dans la file d'attente d'envoi du socket. Le socket ne doit pas être en état d'écoute (LISTEN), sinon une erreur -EINVAL est retournée dans le champ res du CQE. Les arguments suivants ne sont pas utilisés pour cette commande : level, optname, optval et optlen.

Une valeur de retour négative signifie une erreur.

Pour plus d'informations sur cette commande, veuillez consulter unix(7).

SOCKET_URING_OP_GETSOCKOPT
Commande pour obtenir les options du socket référencé par le descripteur de fichier socket fd. Les arguments sont similaires à ceux de l'appel système getsockopt(2).

La commande SOCKET_URING_OP_GETSOCKOPT est limitée au niveau SOL_SOCKET.

Contrairement à l'appel système getsockopt(2), la valeur mise à jour de optlen est retournée dans le champ res du CQE, en cas de succès. En cas d'échec, le CQE res contient un nombre d'erreur négatif.

SOCKET_URING_OP_SETSOCKOPT
Commande pour définir les options du socket référencé par le descripteur de fichier socket fd. Les arguments sont similaires à ceux de l'appel système setsockopt(2).

Disponible depuis la version 6.7.

NOTES

Le bloc mémoire pointé par optval doit être valide/vivant jusqu'à ce que le CQE soit retourné.

VALEUR DE RETOUR

Dépend de la commande.

ERREURS

Le champ res du CQE contiendra le résultat de l'opération.
