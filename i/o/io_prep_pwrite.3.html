NOM

io_prep_pwrite - Préparer un iocb pour des écritures asynchrones

SYNTAXE

#include <errno.h>

#include <libaio.h>

inline void io_prep_pwrite(struct iocb *iocb, int fd, void *buf, size_t count, long long offset);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

DESCRIPTION

io_prep_pwrite() est une fonction utilitaire pour préparer des écritures parallèles.

Les count premiers octets du fichier pour lequel fd est un descripteur sont écrits à partir du tampon commençant à buf. L'écriture commence à la position absolue offset dans le fichier.

Cette fonction retourne immédiatement. Pour planifier l'opération, la fonction io_submit(3) doit être appelée.

Les opérations asynchrones simultanées utilisant le même iocb produisent des résultats indéfinis.

VALEUR DE RETOUR

Aucune.

ERREURS

Aucune.
