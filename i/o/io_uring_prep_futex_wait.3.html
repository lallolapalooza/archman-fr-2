NOM

io_uring_prep_futex_wait - préparer une requête d'attente futex

SYNOPSIS

#include <linux/futex.h>
#include <unistd.h>
#include <liburing.h>
void io_uring_prep_futex_wait(struct io_uring_sqe *sqe,
                              uint32_t *futex,
                              uint64_t val,
                              uint64_t mask,
                              uint32_t futex_flags,
                              unsigned int flags);

DESCRIPTION

La fonction io_uring_prep_futex_wait(3) prépare une requête d'attente futex. L'entrée de la file d'attente de soumission sqe est configurée pour attendre un futex à l'adresse futex et qui a toujours la valeur val, avec les drapeaux futex2(2) de futex_flags et les drapeaux futex io_uring de flags.

mask peut être défini sur un ensemble de bits spécifique, qui sera mis en correspondance par le côté réveil pour décider qui réveiller. Pour être toujours réveillé, une application peut utiliser FUTEX_BITSET_MATCH_ANY.

futex_flags suit les drapeaux futex2(2), et non les drapeaux de l'interface v1 de futex(2).

flags est actuellement inutilisé et par conséquent 0 doit être passé.

Cette fonction prépare une requête d'attente futex asynchrone futex(2). Voir cette page de manuel pour plus de détails. Notez que la requête d'attente futex io_uring est similaire à l'opération FUTEX_WAIT_BITSET, car FUTEX_WAIT est un sous-ensemble strict de celle-ci.

Disponible depuis le noyau 6.7.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. Voir la page de manuel associée pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones renvoient -1 en cas d'échec et définissent errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il renvoie l'errno négativé directement dans le champ res du CQE.

NOTES

Contrairement aux appels système futex synchrones qui attendent sur un futex, io_uring ne prend pas en charge le passage d'un délai d'attente pour la requête. Au lieu de cela, les applications sont encouragées à utiliser un délai d'attente lié pour annuler la requête futex à un moment donné, si désiré.
