NOM

io_uring_register_ring_fd - enregistrer un descripteur de fichier de file d'attente

SYNOPSIS

#include <liburing.h>
int io_uring_register_ring_fd(struct io_uring *ring);

DESCRIPTION

io_uring_register_ring_fd(3) enregistre le descripteur de fichier de la file d'attente.

Chaque fois que io_uring_enter(2) est appelé pour soumettre une requête ou attendre des complétions, le noyau doit acquérir une référence au descripteur de fichier. Si l'application utilisant io_uring est multi-threadée, la table de fichiers est marquée comme partagée, et l'acquisition et la libération de la référence du compteur de descripteurs de fichiers sont plus coûteuses que pour une application non multi-threadée.

De même que io_uring permet l'enregistrement de fichiers, ceci permet l'enregistrement du descripteur de fichier de la file d'attente elle-même. Cela réduit la surcharge de l'appel système io_uring_enter(2).

Si une application utilisant liburing est multi-threadée, alors une application devrait appeler cette fonction pour enregistrer le descripteur de la file d'attente lorsqu'une file d'attente est configurée. Voir NOTES pour les restrictions lorsqu'une file d'attente est partagée.

Disponible depuis le noyau 5.18.

NOTES

Lorsque le descripteur de la file d'attente est enregistré, il est stocké interne dans la structure struct io_uring. Pour les applications qui partagent une file d'attente entre threads, par exemple ayant un thread qui fait les soumissions et un autre qui récupère les événements, alors cette optimisation ne peut pas être utilisée car chaque thread peut avoir un index différent pour le descripteur de fichier enregistré.

VALEUR DE RETOUR

Retourne 1 en cas de succès, indiquant qu'un descripteur de fichier a été enregistré, ou -errno en cas d'erreur.

VOIR AUSSI
