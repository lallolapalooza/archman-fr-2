io_getevents(3)

Paquet: libaio

io_getevents(3) Linux AIO io_getevents(3)

NOM

io_getevents, aio_pgetevents - Lire les événements résultants des requêtes io

SYNTAXE

#include <errno.h>

#include <libaio.h>

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

struct io_event {
        unsigned        PADDED(data, __pad1);
        unsigned        PADDED(obj,  __pad2);
        unsigned        PADDED(res,  __pad3);
        unsigned        PADDED(res2, __pad4);
};

int io_getevents(io_context_t ctx, long nr, struct io_event *events[], struct timespec *timeout);
int io_pgetevents(io_context_t ctx, long nr, struct io_event *events[], struct timespec *timeout, sigset_t *sigmask);

DESCRIPTION

Tente de lire jusqu'à nr événements de la file d'attente d'achèvement pour le contexte aio spécifié par ctx.

VALEURS DE RETOUR

Peut retourner 0 si aucun événement n'est disponible et que le délai spécifié par when a expiré, où when == NULL spécifie un délai infini. Notez que le délai pointé par when est relatif et sera mis à jour s'il n'est pas NULL et que l'opération bloque. Échoue avec ENOSYS si non implémenté.

io_pgetevents()

La relation entre io_getevents() et io_pgetevents() est analogue à la relation entre select(2) et pselect(2) : similaire à pselect(2), pgetevents() permet à une application d'attendre en toute sécurité jusqu'à ce qu'un événement d'achèvement aio se produise ou qu'un signal soit capturé.

L'appel io_pgetevents() suivant :


ret = io_pgetevents(ctx, min_nr, nr, events, timeout, sigmask);

est équivalent à l'exécution *atomique* des appels suivants :


sigset_t origmask;
pthread_sigmask(SIG_SETMASK, &sigmask, &origmask);
ret = io_getevents(ctx, min_nr, nr, events, timeout);
pthread_sigmask(SIG_SETMASK, &origmask, NULL);

Voir la description de pselect(2) pour une explication de la nécessité de io_pgetevents().

Si l'argument sigmask est spécifié comme NULL, aucune manipulation du masque de signal n'est effectuée (et donc io_pgetevents() se comporte de la même manière que io_getevents()).

ERREURS

EINVAL
Si ctx est invalide, si min_nr est hors limites, si nr est hors limites, si when est hors limites.
EFAULT
Si une partie de la mémoire spécifiée est invalide.
