ioctl_userfaultfd(2) Manuel des appels système ioctl_userfaultfd(2)

NOM

ioctl_userfaultfd - créer un descripteur de fichier pour gérer les erreurs de page en espace utilisateur

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <linux/userfaultfd.h>  /* Définition des constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, int op, ...);

DESCRIPTION

Diverses opérations ioctl(2) peuvent être effectuées sur un objet userfaultfd (créé par un appel à userfaultfd(2)) en utilisant des appels de la forme :


ioctl(fd, op, argp);

Dans ce qui précède, fd est un descripteur de fichier faisant référence à un objet userfaultfd, op est l'une des opérations listées ci-dessous, et argp est un pointeur vers une structure de données spécifique à op.

Les diverses opérations ioctl(2) sont décrites ci-dessous. Les opérations UFFDIO_API, UFFDIO_REGISTER et UFFDIO_UNREGISTER sont utilisées pour *configurer* le comportement de userfaultfd. Ces opérations permettent à l'appelant de choisir les fonctionnalités qui seront activées et les types d'événements qui seront envoyés à l'application. Les opérations restantes sont des opérations sur les *plages*. Ces opérations permettent à l'application appelante de résoudre les événements d'erreur de page.

UFFDIO_API(2const)
UFFDIO_REGISTER(2const)
UFFDIO_UNREGISTER(2const)
UFFDIO_COPY(2const)
UFFDIO_MOVE(2const)
UFFDIO_ZEROPAGE(2const)
UFFDIO_WAKE(2const)
UFFDIO_WRITEPROTECT(2const)
UFFDIO_CONTINUE(2const)
UFFDIO_POISON(2const)

VALEUR RETOUR

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

Les erreurs générales suivantes peuvent survenir pour toutes les opérations décrites ci-dessus :

EFAULT
argp ne pointe pas vers une adresse mémoire valide.
EINVAL
(Pour toutes les opérations sauf UFFDIO_API.) L'objet userfaultfd n'a pas encore été activé (via l'opération UFFDIO_API).

NORMES

Linux.

EXEMPLES

Voir userfaultfd(2).

VOIR AUSSI

ioctl(2), mmap(2), userfaultfd(2)
