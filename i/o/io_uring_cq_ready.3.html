NOM

io_uring_cq_ready - retourne le nombre d'entrées prêtes non consommées dans la file d'attente CQ

SYNTAXE

#include <liburing.h>
unsigned io_uring_cq_ready(const struct io_uring *ring);

DESCRIPTION

La fonction io_uring_cq_ready(3) retourne le nombre d'entrées prêtes non consommées appartenant au paramètre ring.

VALEUR DE RETOUR

Retourne le nombre d'entrées prêtes non consommées dans la file d'attente CQ.

VOIR AUSSI

io_uring_submit(3), io_uring_wait_cqe(3)
