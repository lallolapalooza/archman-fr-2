ioctl_fs(2) Manuel des appels système ioctl_fs(2)

NOM

ioctl_fs - opérations sur le système de fichiers

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/fs.h>  /* Définition des constantes d'opération */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, ...);

DESCRIPTION

Les valeurs de op suivantes sont disponibles.

Partager des données d'un fichier avec un autre fichier

FICLONE(2const)
FICLONERANGE(2const)
FIDEDUPERANGE(2const)

Opérations pour les indicateurs d’inode

FS_IOC_GETFLAGS(2const)
FS_IOC_SETFLAGS(2const)

Obtenir ou définir une étiquette de système de fichiers

FS_IOC_GETFSLABEL(2const)
FS_IOC_SETFSLABEL(2const)

Obtenir et/ou effacer les indicateurs de page

PAGEMAP_SCAN(2const)

VALEUR DE RETOUR

En cas de succès, une valeur non négative est retournée. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

NORMES

Linux.

VOIR AUSSI

ioctl(2)
