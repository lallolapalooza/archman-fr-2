NOM

io_uring_close_ring_fd - fermer un descripteur de fichier de file d'attente et l'utiliser uniquement via l'index enregistré

SYNTAXE

#include <liburing.h>
int io_uring_close_ring_fd(struct io_uring *ring);

DESCRIPTION

io_uring_close_ring_fd(3) ferme le descripteur de fichier de la file d'attente, qui doit avoir été précédemment enregistré. Le fichier restera ouvert, mais accessible uniquement via l'index enregistré, pas via un quelconque descripteur de fichier. Les appels liburing ultérieurs continueront de fonctionner, en utilisant le descripteur de fichier de la file d'attente enregistrée.

Le noyau doit prendre en charge IORING_FEAT_REG_REG_RING.

Les bibliothèques qui doivent éviter de perturber l'utilisation des descripteurs de fichiers par leurs utilisateurs, et qui doivent continuer à fonctionner même face à close_range(2) et des fonctions similaires, peuvent utiliser io_uring_close_ring_fd(3) pour fonctionner avec liburing sans avoir de descripteur de fichier ouvert.

NOTES

Chaque thread qui souhaite utiliser io_uring doit enregistrer le descripteur de fichier. Une bibliothèque qui peut être appelée depuis des threads arbitraires peut avoir besoin de détecter quand elle est appelée sur un thread jamais vu auparavant et de créer et enregistrer une file d'attente pour ce thread.

VALEUR DE RETOUR

Retourne 1 en cas de succès, ou -errno en cas d'erreur.
