NOM

io_uring_register_clock - définir la source d'horloge pour l'attente d'événements

SYNTAXE

#include <liburing.h>
int io_uring_register_clock(struct io_uring *ring,
                            struct io_uring_clock_register *arg);

DESCRIPTION

La fonction io_uring_register_clock(3) enregistre la source d'horloge à utiliser par io_uring lorsqu'une application attend des achèvements d'événements. L'argument ring doit pointer vers le ring concerné, et l'argument arg doit être un pointeur vers une structure io_uring_clock_register.

L'argument arg doit être rempli avec les informations appropriées. Il se présente comme suit :


struct io_uring_clock_register {
    __u32 clockid;
    __u32 __resv[3];
};

Le champ clockid doit contenir la source d'horloge, les sources valides étant :

CLOCK_MONOTONIC
une horloge système globale non modifiable qui représente le temps monotone.
CLOCK_BOOTTIME
Une horloge système globale non modifiable qui est identique à CLOCK_MONOTONIC, à la différence qu'elle inclut également le temps pendant lequel le système est suspendu.

Voir clock_gettime(3) pour plus de détails.

Les champs __resv doivent être remplis avec des zéros.

Disponible depuis la version 6.12.

VALEUR DE RETOUR

En cas de succès, io_uring_register_clock(3) renvoie 0. En cas d'échec, elle renvoie -errno.

VOIR AUSSI
