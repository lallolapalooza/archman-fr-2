NOM

io_prep_pread - Préparer une lecture asynchrone

SYNOPSIS

#include <errno.h>

#include <libaio.h>

inline void io_prep_pread(struct iocb *iocb, int fd, void *buf, size_t count, long long offset);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

DESCRIPTION

io_prep_pread() est une fonction utilitaire en ligne conçue pour faciliter l'initialisation de l'iocb pour une opération de lecture asynchrone.

Les count premiers octets du fichier pour lequel fd est un descripteur sont écrits dans le tampon à partir de buf. La lecture commence à la position absolue offset dans le fichier.

Cette fonction retourne immédiatement. Pour planifier l'opération, la fonction io_submit(3) doit être appelée.

Les opérations asynchrones simultanées utilisant le même iocb produisent des résultats indéfinis.

VALEURS DE RETOUR

Aucune.

ERREURS

Aucune.
