NOM

io_uring_prep_setxattr, io_uring_prep_fsetxattr - préparer une demande pour définir la valeur d'un attribut étendu

SYNTAXE

#include <liburing.h>
void io_uring_prep_setxattr(struct io_uring_sqe *sqe,
                            const char *name,
                            const char *value,
                            const char *path,
                            int flags,
                            unsigned int len);
void io_uring_prep_fsetxattr(struct io_uring_sqe *sqe,
                             int fd,
                             const char *name,
                             const char *value,
                             int flags,
                             unsigned int len);

DESCRIPTION

La fonction io_uring_prep_setxattr(3) prépare une demande pour définir la valeur d'un attribut étendu. L'entrée de la file d'attente de soumission sqe est configurée pour définir la value de l'attribut étendu identifié par name et associé au path donné dans le système de fichiers avec les indicateurs modificateurs flags. L'argument len spécifie la taille (en octets) de value.

io_uring_prep_fsetxattr(3) est identique à io_uring_prep_setxattr(3), seul l'attribut étendu est défini sur le fichier ouvert référencé par fd à la place de path.

Cette fonction prépare une demande asynchrone setxattr(2). Voir cette page de manuel pour les détails.

VALEUR DE RETOUR

Aucune

VOIR AUSSI

io_uring_get_sqe(3), setxattr(2)
