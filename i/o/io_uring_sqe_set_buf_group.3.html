NOM

io_uring_sqe_set_buf_group - définir le groupe de tampons pour un événement de file d'attente de soumission

SYNTAXE

#include <liburing.h>
void io_uring_sqe_set_buf_group(struct io_uring_sqe *sqe,
                                int bgid);

DESCRIPTION

La fonction io_uring_sqe_set_buf_group(3) définit le groupe de tampons associé (buf_group) de la sqe à bgid.

Après que l'appelant a demandé une entrée de file d'attente de soumission (SQE) avec io_uring_get_sqe(3), il peut associer un groupe de tampons (buf_group) à la SQE utilisée pour les opérations multishot.

Aucune
