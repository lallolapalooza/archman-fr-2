io_uring_cqe_get_data(3) Manuel liburing io_uring_cqe_get_data(3)

NOM

io_uring_cqe_get_data - obtenir les données utilisateur pour l'événement de complétion

SYNTAXE

#include <liburing.h>
void *io_uring_cqe_get_data(struct io_uring_cqe *cqe);

__u64 io_uring_cqe_get_data64(struct io_uring_cqe *cqe);

DESCRIPTION

La fonction io_uring_cqe_get_data(3) retourne les données utilisateur avec l'entrée de la file d'attente de complétion cqe en tant que pointeur de données.

La fonction io_uring_cqe_get_data64(3) retourne les données utilisateur avec l'entrée de la file d'attente de complétion cqe en tant que valeur de données 64 bits.

Après que l'appelant a reçu une entrée de la file d'attente de complétion (CQE) avec io_uring_wait_cqe(3), l'application peut appeler la fonction io_uring_cqe_get_data(3) ou io_uring_cqe_get_data64(3) pour récupérer la valeur user_data. Cela nécessite que user_data ait été défini précédemment avec la fonction io_uring_sqe_set_data(3) ou io_uring_sqe_set_data64(3).

VALEUR DE RETOUR

Si la valeur user_data a été définie avant la soumission de la requête, elle sera retournée. Sinon, la valeur de retour est indéfinie.

VOIR AUSSI

io_uring_get_sqe(3), io_uring_sqe_set_data(3), io_uring_sqe_submit(3)
