ioctl_tty(2) Manuel des appels système ioctl_tty(2)

NOM

ioctl_tty - ioctls pour terminaux et lignes série

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/termbits.h>  /* Définition des constantes */
#include <sys/ioctl.h>
int ioctl(int fd, int op, ...);

DESCRIPTION

L'appel ioctl(2) pour les terminaux et les ports série accepte de nombreux arguments d'opération possibles. La plupart nécessitent un troisième argument, de type variable, ici appelé argp ou arg.

L'utilisation de ioctl() rend les programmes non portables. Utilisez l'interface POSIX décrite dans termios(3) chaque fois que possible.

VALEUR DE RETOUR

En cas de succès, 0 est renvoyé. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.
