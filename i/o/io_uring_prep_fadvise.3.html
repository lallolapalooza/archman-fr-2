NOM

io_uring_prep_fadvise - prépare une requête fadvise

SYNTAXE

#include <fcntl.h>
#include <liburing.h>
void io_uring_prep_fadvise(struct io_uring_sqe *sqe,
                           int fd,
                           __u64 offset,
                           __u32 len,
                           int advice);

void io_uring_prep_fadvise64(struct io_uring_sqe *sqe,
                             int fd,
                             __u64 offset,
                             off_t len,
                             int advice);

DESCRIPTION

La fonction io_uring_prep_fadvise(3) prépare une requête fadvise. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser le descripteur de fichier pointé par fd pour démarrer une opération fadvise à partir de l'offset et d'une longueur de len octets, lui donnant l'avis situé dans advice.

La fonction io_uring_prep_fadvise64(3) fonctionne comme io_uring_prep_fadvise(3), sauf qu'elle prend une longueur de 64 bits plutôt qu'une simple longueur de 32 bits. Les anciens noyaux peuvent ne pas supporter la variante de longueur 64 bits. Si cette variante est tentée sur un noyau qui ne prend pas en charge les longueurs de 64 bits, la requête échouera avec -EINVAL dans le champ de résultat de la CQE.

Cette fonction prépare une requête asynchrone posix_fadvise(2). Voir cette page man pour plus de détails.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res de la CQE contiendra le résultat de l'opération. Voir la page man associée pour connaître les valeurs possibles. Notez que lorsque les appels système synchrones retourneront -1 en cas d'échec et définiront errno avec la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il renvoie directement le errno négativé dans le champ res de la CQE.
