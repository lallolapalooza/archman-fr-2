NOM

io_uring_register_file_alloc_range - définir la plage pour les allocations de fichiers fixes

SYNOPSIS

#include <liburing.h>
int io_uring_register_file_alloc_range(struct io_uring *ring,
                                       unsigned off,
                                       unsigned len);

DESCRIPTION

La fonction io_uring_register_file_alloc_range(3) définit la plage autorisée pour les allocations d'index de fichiers fixes dans le noyau. Lorsque les requêtes qui peuvent instancier un nouveau fichier fixe sont utilisées avec IORING_FILE_INDEX_ALLOC , l'application demande au noyau d'allouer un nouveau descripteur de fichier fixe plutôt que de passer une valeur spécifique pour celui-ci. Par défaut, le noyau choisira n'importe quel descripteur de fichier fixe disponible dans la plage disponible. En appelant cette fonction avec off défini à l'offset de début et len défini au nombre de descripteurs, l'application peut limiter les descripteurs alloués à cette plage particulière. Cela permet effectivement à l'application de réserver une plage juste pour les allocations dynamiques, le reste étant utilisé pour des valeurs spécifiques.

L'application doit avoir enregistré une table de fichiers fixes au préalable, par exemple via io_uring_register_files(3) ou io_uring_register_files_sparse(3).

Disponible depuis la version 6.0.

VALEUR DE RETOUR

En cas de succès, io_uring_register_file_alloc_range(3) renvoie 0. En cas d'échec, elle renvoie -errno.
