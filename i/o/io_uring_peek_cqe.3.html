NOM

io_uring_peek_cqe - vérifier si un événement de complétion io_uring est disponible

SYNTAXE

#include <liburing.h>
int io_uring_peek_cqe(struct io_uring *ring,
                      struct io_uring_cqe **cqe_ptr);
unsigned io_uring_peek_batch_cqe(struct io_uring *ring,
                                 struct io_uring_cqe **cqe_ptrs,
                                 unsigned count);

DESCRIPTION

La fonction io_uring_peek_cqe(3) renvoie une complétion d'E/S de la file d'attente appartenant au paramètre ring, si elle est immédiatement disponible. En cas de retour réussi, le paramètre cqe_ptr est rempli avec une entrée CQE valide.

Cette fonction n'entre pas dans le noyau pour attendre un événement, un événement n'est renvoyé que s'il est déjà disponible dans la file d'attente CQ.

La fonction io_uring_peek_batch_cqe(3) renvoie jusqu'à count complétions de requêtes dans cqe_ptrs appartenant au paramètre ring, si elles sont immédiatement disponibles. Elle n'entrera pas dans le noyau, sauf si la file d'attente CQ est en état de dépassement de capacité. Lors d'un retour réussi, cqe_ptrs est rempli avec le nombre d'événements indiqués par la valeur de retour.

VALEUR RENVOYÉE

En cas de succès, io_uring_peek_cqe(3) renvoie 0 et le paramètre cqe_ptr est rempli. En cas de succès, io_uring_peek_batch_cqe(3) renvoie le nombre de complétions remplies. En cas d'échec, io_uring_peek_cqe(3) peut renvoyer -EAGAIN.
