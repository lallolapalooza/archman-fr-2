NOM

io_uring_prep_waitid - préparer une requête waitid

SYNTAXE

#include <sys/wait.h>
#include <liburing.h>
void io_uring_prep_waitid(struct io_uring_sqe *sqe,
                          idtype_t idtype,
                          id_t id,
                          siginfo_t *infop,
                          int options,
                          unsigned int flags);

DESCRIPTION

La fonction io_uring_prep_waitid(3) prépare une requête waitid. L'entrée de la file d'attente de soumission sqe est configurée pour utiliser les arguments idtype et id pour sélectionner l'enfant ou les enfants, et options pour spécifier les changements d'état de l'enfant à attendre. En cas de retour réussi, elle remplit infop avec les informations du processus enfant, le cas échéant. flags sont des indicateurs modificateurs spécifiques à io_uring. Ils ne sont actuellement pas utilisés, et par conséquent, 0 doit être passé.

Cette fonction prépare une requête waitid(2) asynchrone. Voir la page de manuel correspondante pour plus de détails.

Disponible depuis le noyau 6.7.

VALEUR DE RETOUR

Aucune

ERREURS

Le champ res du CQE contiendra le résultat de l'opération. Voir la page de manuel associée pour les détails sur les valeurs possibles. Notez que là où les appels système synchrones retourneront -1 en cas d'échec et définiront errno à la valeur d'erreur réelle, io_uring n'utilise jamais errno. Au lieu de cela, il retourne errno nié directement dans le champ res du CQE.

VOIR AUSSI
