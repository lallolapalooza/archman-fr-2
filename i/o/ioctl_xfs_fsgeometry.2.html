NOM

ioctl_xfs_fsgeometry - rapporte la disposition et les caractéristiques d'un système de fichiers XFS

SYNOPSIS

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_FSGEOMETRY, struct xfs_fsop_geom *arg);
int ioctl(int fd, XFS_IOC_FSGEOMETRY_V4, struct xfs_fsop_geom_v4 *arg);
int ioctl(int fd, XFS_IOC_FSGEOMETRY_V1, struct xfs_fsop_geom_v1 *arg);

DESCRIPTION

Rapporte les détails de la disposition d'un système de fichiers XFS, de ses caractéristiques et d'autres éléments descriptifs. Ces informations sont transmises dans une structure de la forme suivante :


struct xfs_fsop_geom {
	__u32         blocksize;
	__u32         rtextsize;
	__u32         agblocks;
	__u32         agcount;
	__u32         logblocks;
	__u32         sectsize;
	__u32         inodesize;
	__u32         imaxpct;
	__u64         datablocks;
	__u64         rtblocks;
	__u64         rtextents;
	__u64         logstart;
	unsigned char uuid[16];
	__u32         sunit;
	__u32         swidth;
	__s32         version;
	__u32         flags;
	__u32         logsectsize;
	__u32         rtsectsize;
	__u32         dirblocksize;
	/* struct xfs_fsop_geom_v1 stops here. */
	__u32         logsunit;
	/* struct xfs_fsop_geom_v4 stops here. */
	__u32         sick;
	__u32         checked;
	__u64         rgextents;
	__u64	      rtstart;
	__u64         rtreserved;
	__u64         reserved[14];
};

blocksize est la taille d'un bloc fondamental du système de fichiers, en octets.

rtextsize est la taille d'un extent sur le volume temps réel, en octets.

agblocks est la taille d'un groupe d'allocation, en unités de blocs du système de fichiers.

agcount est le nombre de groupes d'allocation dans le système de fichiers.

logblocks est la taille du journal, en unités de blocs du système de fichiers.

sectsize est la plus petite quantité de données qui peut être écrite de façon atomique sur le périphérique de données, en octets.

inodesize est la taille d'un enregistrement d'inode, en octets.

imaxpct est le pourcentage maximal du système de fichiers qui peut être alloué aux blocs d'enregistrement d'inodes.

datablocks est la taille du périphérique de données, en unités de blocs du système de fichiers.

rtblocks est la taille du périphérique temps réel, en unités de blocs du système de fichiers.

rtextents est le nombre d'extents qui peuvent être alloués sur le périphérique temps réel.

logstart est le début du journal, en unités de blocs du système de fichiers. Si le système de fichiers a un journal externe, cette valeur sera zéro.

uuid est l'identifiant universel unique du système de fichiers.

sunit est ce que le système de fichiers a été informé être la taille d'une unité de bande RAID sur le périphérique de données sous-jacent, en blocs du système de fichiers.

swidth est ce que le système de fichiers a été informé être la largeur d'une bande RAID sur le périphérique de données sous-jacent, en unités d'unités de bande RAID.

version est la version de cette structure. Cette valeur sera XFS_FSOP_GEOM_VERSION.

flags indiquent quelles caractéristiques sont activées sur le système de fichiers. Consultez la section DRAPEAUX DE CARACTÉRISTIQUES DU SYSTÈME DE FICHIERS ci-dessous pour plus d'informations sur chaque caractéristique.

logsectsize est la plus petite quantité de données qui peut être écrite de façon atomique sur le périphérique de journal, en octets.

rtsectsize est la plus petite quantité de données qui peut être écrite de façon atomique sur le périphérique temps réel, en octets.

dirblocksize est la taille des blocs de répertoire, en octets.

logsunit est ce que le système de fichiers a été informé être la taille d'une unité de bande RAID sur le périphérique de journal sous-jacent, en blocs du système de fichiers. Ce champ n'est significatif que si le drapeau XFS_FSOP_GEOM_FLAGS_LOGV2 est défini.

Les champs sick et checked indiquent l'état de santé relatif de diverses métadonnées couvrant l'ensemble du système de fichiers. Veuillez consulter la section RAPPORT D'ÉTAT DE SANTÉ DES MÉTADONNÉES XFS pour plus de détails.

rgextents est le nombre d'extents RT dans chaque rtgroup.

rtstart Début du périphérique RT interne en fsblocks. 0 si un périphérique RT externe est utilisé. Ce champ n'est significatif que si le drapeau XFS_FSOP_GEOM_FLAGS_ZONED est défini.

rtreserved La quantité d'espace dans la section temps réel qui est réservée à l'usage interne par les algorithmes de collecte des orphelins et de réorganisation en fsblocks. Ce champ n'est significatif que si le drapeau XFS_FSOP_GEOM_FLAGS_ZONED est défini.

reserved est mis à zéro.

DRAPEAUX DE CARACTÉRISTIQUES DU SYSTÈME DE FICHIERS

Les caractéristiques du système de fichiers sont rapportées à l'espace utilisateur sous la forme d'une combinaison des drapeaux suivants :

XFS_FSOP_GEOM_FLAGS_ATTR
Les attributs étendus sont présents.
XFS_FSOP_GEOM_FLAGS_NLINK
Les fichiers de ce système de fichiers prennent en charge jusqu'à 2^32 liens physiques. Si ce drapeau n'est pas défini, les fichiers de ce système de fichiers ne prennent en charge que jusqu'à 2^16 liens physiques.
XFS_FSOP_GEOM_FLAGS_QUOTA
Les quotas sont activés.
XFS_FSOP_GEOM_FLAGS_IALIGN
Les inodes sont alignés pour de meilleures performances.
XFS_FSOP_GEOM_FLAGS_DALIGN
Le système de fichiers essaie d'aligner les allocations de blocs de données sur les unités de bande RAID pour de meilleures performances.
XFS_FSOP_GEOM_FLAGS_SHARED
Inutilisé.
XFS_FSOP_GEOM_FLAGS_EXTFLG
Le système de fichiers prend en charge les extents non écrits.
XFS_FSOP_GEOM_FLAGS_DIRV2
Les répertoires sont au format version 2 et maintiennent des données d'espace libre pour de meilleures performances. Les répertoires au format version 1 ne sont plus pris en charge.
XFS_FSOP_GEOM_FLAGS_LOGV2
Le journal utilise le format V2.
XFS_FSOP_GEOM_FLAGS_SECTOR
Le périphérique de journal a une taille de secteur supérieure à 512 octets.
XFS_FSOP_GEOM_FLAGS_ATTR2
Le système de fichiers contient des attributs étendus V2.
XFS_FSOP_GEOM_FLAGS_PROJID32
Les identifiants de projet peuvent atteindre 2^32. Si ce drapeau n'est pas défini, le système de fichiers ne prend en charge que 2^16 identifiants de projet.
XFS_FSOP_GEOM_FLAGS_DIRV2CI
Les recherches insensibles à la casse sont prises en charge sur les répertoires.
XFS_FSOP_GEOM_FLAGS_LAZYSB
Les compteurs du superbloc sur disque ne sont mis à jour qu'au moment du démontage.
XFS_FSOP_GEOM_FLAGS_V5SB
Les blocs de métadonnées sont auto-descriptifs et contiennent des sommes de contrôle.
XFS_FSOP_GEOM_FLAGS_FTYPE
Les répertoires contiennent les types d'inodes dans les entrées de répertoire.
XFS_FSOP_GEOM_FLAGS_FINOBT
Le système de fichiers maintient un index des inodes libres.
XFS_FSOP_GEOM_FLAGS_SPINODES
Le système de fichiers peut allouer des paquets d'inodes non contigus lorsque l'espace libre est fragmenté.
XFS_FSOP_GEOM_FLAGS_RMAPBT
Le système de fichiers stocke les correspondances inverses des blocs vers leurs propriétaires.
XFS_FSOP_GEOM_FLAGS_REFLINK
Le système de fichiers prend en charge le partage de blocs entre fichiers.
