IOCTL-XFS-FSINUMBERS(2) Manuel des appels système IOCTL-XFS-FSINUMBERS(2)

NOM

ioctl_xfs_fsinumbers - extrait une liste des numéros d'inode valides d'un système de fichiers XFS

SYNTAXE

#include <xfs/xfs_fs.h>

int ioctl(int fd, XFS_IOC_FSINUMBERS, struct xfs_fsop_bulkreq *arg);

DESCRIPTION

Interroge les informations d'allocation d'inode d'un système de fichiers XFS. Il est prévu d'être appelé de manière itérative pour obtenir l'ensemble complet des inodes. Ces ioctls utilisent struct xfs_fsop_bulkreq pour configurer un transfert en bloc avec le noyau :


struct xfs_fsop_bulkreq {
	__u64   *lastip;
	__s32   count;
	void    *ubuffer;
	__s32   *ocount;
};

lastip pointe vers une valeur qui recevra le numéro du "dernier inode." Ceci doit être défini à un de moins que le numéro du premier inode pour lequel l'appelant demande des informations, ou à zéro pour commencer avec le premier inode du système de fichiers. Après l'appel, cette valeur sera définie au numéro du dernier inode pour lequel des informations sont fournies. Ce champ ne sera pas mis à jour si ocount est NULL.

count est le nombre d'éléments dans le tableau ubuffer et par conséquent le nombre de groupes d'inodes pour lesquels renvoyer des informations d'allocation.

ocount pointe vers une valeur qui recevra le nombre d'enregistrements retournés. Une valeur de sortie de zéro signifie qu'il n'y a plus de groupes d'inodes à énumérer. Si cette valeur est NULL, alors ni ocount ni lastip ne seront mis à jour.

ubuffer pointe vers un tampon mémoire où les informations du groupe d'inodes seront copiées. Ce tampon doit être un tableau de struct xfs_inogrp qui est décrit ci-dessous. Le tableau doit avoir au moins count éléments.


struct xfs_inogrp {
	__u64   xi_startino;
	__s32   xi_alloccount;
	__u64   xi_allocmask;
}

Cette structure décrit les informations d'utilisation des inodes pour un groupe de 64 numéros d'inode consécutifs. Les champs sont les suivants :

xi_startino est le premier numéro d'inode de ce groupe.

xi_alloccount est le nombre de bits définis dans xi_allocmask. C'est le nombre d'inodes alloués dans ce groupe.

xi_allocmask est un masque de bits des inodes qui sont alloués dans ce groupe d'inodes. Le masque de bits a 64 bits de long, et le bit le moins significatif correspond à l'inode xi_startino.

VALEUR DE RETOUR

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Les codes d'erreur peuvent être l'un des suivants, mais ne s'y limitent pas :

EFAULT
Le noyau n'a pas pu copier dans le tampon utilisateur.
EFSBADCRC
La validation de la somme de contrôle des métadonnées a échoué lors de la requête.
EFSCORRUPTED
Une corruption des métadonnées a été rencontrée lors de la requête.
EINVAL
Un des arguments n'était pas valide.
EIO
Une erreur d'E/S a été rencontrée lors de la requête.
ENOMEM
Il y avait une mémoire insuffisante pour effectuer la requête.

CONFORME À

Cette API est spécifique au système de fichiers XFS sur le noyau Linux.
