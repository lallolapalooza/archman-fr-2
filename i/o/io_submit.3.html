NOM

io_submit - Soumettre des requêtes d'entrée/sortie

SYNTAXE

#include <errno.h>

#include <libaio.h>

int io_submit(io_context_t ctx, long nr, struct iocb *iocbs[]);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

DESCRIPTION

io_submit() soumet nr iocbs pour traitement pour un contexte d'E/S ctx donné.

La fonction io_submit() peut être utilisée pour mettre en file d'attente un nombre arbitraire de requêtes de lecture et d'écriture en une seule fois. Les requêtes peuvent toutes concerner le même fichier, toutes des fichiers différents, ou toute autre combinaison.

io_submit() récupère les nr requêtes à partir du tableau pointé par iocbs. L'opération à effectuer est déterminée par le membre aio_lio_opcode de chaque élément de iocbs. Si ce champ est IO_CMD_PREAD, une opération de lecture est mise en file d'attente, similaire à un appel à io_prep_pread pour cet élément du tableau (sauf que la manière dont la fin est signalée est différente, comme nous le verrons plus loin). Si le membre aio_lio_opcode est IO_CMD_PWRITE, une opération d'écriture est mise en file d'attente. Sinon, aio_lio_opcode doit être IO_CMD_NOP, auquel cas cet élément de iocbs est simplement ignoré. Cette « opération » est utile dans les situations où l'on dispose d'un tableau fixe d'éléments struct iocb dont seulement quelques-uns doivent être traités à la fois. Une autre situation est lorsque l'appel io_submit(3) a été annulé avant que toutes les requêtes ne soient traitées et que les requêtes restantes doivent être réémises.

Les autres membres de chaque élément du tableau pointé par iocbs doivent avoir des valeurs appropriées à l'opération, comme décrit dans la documentation de io_prep_pread(3) et io_prep_pwrite(3) ci-dessus.

La fonction retourne immédiatement après avoir mis en file d'attente toutes les requêtes. En cas de succès, io_submit() retourne le nombre d'iocbs soumis avec succès. Sinon, -error est retourné, où error est l'une des valeurs Exxx définies dans la section Erreurs.

Si une erreur est détectée, le comportement est indéfini.

Les opérations asynchrones simultanées utilisant le même iocb donnent des résultats indéfinis.

ERREURS

EFAULT
iocbs a référencé des données en dehors de l'espace d'adressage accessible du programme.
EINVAL
ctx fait référence à un contexte aio non initialisé, l'iocb pointé par iocbs contient un iocb mal initialisé,
EBADF
L'iocb contient un descripteur de fichier qui n'existe pas.
EINVAL
Le fichier spécifié dans l'iocb ne prend pas en charge l'opération d'E/S donnée.
