NOM

itcl::component - définir des composants pour extendedclass, widget ou widgetadaptor

Certaines parties de cette description sont « empruntées » à l'extension Tcl [snit], car la fonctionnalité est largement identique.

AVERTISSEMENT!

Il s'agit d'une nouvelle fonctionnalité dans [incr Tcl] où l'API peut encore changer !!

SYNTAXE

public component comp ?-inherit?
protected component comp ?-inherit?
private component comp ?-inherit?

DESCRIPTION

La commande component est utilisée à l'intérieur d'une définition extendedclass/widget/widgetadaptor [incr Tcl] pour définir des composants.

Déclare explicitement un composant nommé comp, et définit automatiquement la variable d'instance du composant.

Si l'option -inherit est spécifiée, alors toutes les méthodes et options inconnues seront déléguées à ce composant. Le nom -inherit implique que les instances de ce nouveau type héritent, dans un sens, des méthodes et options du composant. C'est-à-dire que -inherit yes équivaut à :

component mycomp
delegate option * to mycomp
delegate method * to mycomp

MOTS-CLÉS

component, widget, widgetadaptor, extendedclass
