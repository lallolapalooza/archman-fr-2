ITSTOOL(1) Manuel des commandes générales ITSTOOL(1)

NOM

itstool - convertir entre XML et PO en utilisant ITS

SYNTAXE

itstool [OPTIONS] FICHIERS_XML...
itstool -m <FICHIER_MO> [OPTIONS] FICHIERS_XML...
itstool -j <FICHIER_XML> [OPTIONS] FICHIERS_MO...

DESCRIPTION

itstool extrait les messages des fichiers XML et génère des fichiers modèles PO, puis fusionne les traductions des fichiers MO pour créer des fichiers XML traduits. Il détermine quoi traduire et comment le diviser en messages en utilisant le W3C Internationalization Tag Set (ITS).

Pour extraire les messages des fichiers XML FICHIERS_XML et les sortir dans OUT.pot :

itstool -o OUT.pot FICHIERS_XML

Après fusion avec des traductions existantes ou après traduction des chaînes, générez un fichier MO avec msgfmt(1), puis générez les fichiers traduits dans le répertoire DIR :

itstool -m OUT.mo -o DIR FICHIERS_XML

Vous pouvez également créer un fichier de sortie XML multilingue unique en utilisant un fichier XML d'entrée et un ensemble de fichiers MO :

itstool -j FICHIER.xml -o OUT.xml FICHIERS_MO

Les définitions ITS sont chargées à partir des règles intégrées, des règles intégrées dans les fichiers XML sources, des fichiers passés avec l'option -i, et des attributs ITS dans les fichiers XML sources. Les définitions ultérieures ont priorité. Vous pouvez désactiver les règles intégrées en passant l'option -n.

OPTIONS

Extraction

-o OUT.pot
--out OUT.pot
sortir le modèle PO dans le fichier OUT.pot

Fusion

-m FICHIER_MO FICHIERS_XML
--merge FICHIER_MO FICHIERS_XML
fusionner à partir d'un fichier MO FICHIER_MO et sortir les fichiers XML traduits pour les FICHIERS_XML sources
-l LANG
--lang LANG
définir explicitement le code de langue à sortir dans le XML
-o SORTIE
--out SORTIE
sortir les fichiers XML dans le répertoire SORTIE

Assemblage

-j FICHIER_XML FICHIERS_MO
--join FICHIER_XML FICHIERS_MO
assembler les traductions de FICHIERS_MO dans un fichier multilingue basé sur le fichier source FICHIER_XML
-o OUT.xml
--out OUT.xml
sortir dans le fichier XML OUT.xml

Commun

-i ITS
--its ITS
charger les règles ITS dans le fichier ITS (peut être spécifié plusieurs fois)
-n
--no-builtins
ne pas appliquer les règles ITS intégrées qui sont fournies avec itstool
-s
--strict
quitter avec une erreur lorsque les fichiers PO contiennent du XML invalide
-d
--load-dtd
charger les DTD externes utilisées par les fichiers XML d'entrée
-k
--keep-entities
conserver les références d'entités non développées dans les fichiers PO
-p NOM VALEUR
--param NOM VALEUR
définir le paramètre ITS NOM à la valeur VALEUR (peut être spécifié plusieurs fois)
