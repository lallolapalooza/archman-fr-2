NOM

itweb-settings - afficher et modifier les paramètres de javaws et du plugin de navigateur

SYNOPIS

itweb-settings
itweb-settings arguments de commande

DESCRIPTION

itweb-settings est un programme en ligne de commande et une interface graphique pour modifier et éditer les paramètres utilisés par l'implémentation IcedTea-Web de javaws et le plugin de navigateur

S'il est exécuté sans aucun argument, il démarre une interface graphique. Sinon, il essaie d'exécuter ce qui est spécifié dans l'argument.

La ligne de commande permet de rechercher rapidement, de faire une copie et de modifier des paramètres spécifiques sans avoir à parcourir une interface utilisateur.

DESCRIPTION

-check nom
Vérifie que tous les paramètres actuels ont des valeurs valides. (Aucun argument attendu)
-get nom
Affiche la valeur des paramètres spécifiés. (Un ou plusieurs arguments attendus)
-headless
Désactive la fenêtre de téléchargement et les autres interfaces utilisateur. (Aucun argument attendu)
-help
Affiche des informations sur les commandes prises en charge et l'utilisation de base. Peut également prendre un paramètre, auquel cas il affiche une aide détaillée pour cette commande. (Aucun argument attendu)
-info nom
Affiche des informations supplémentaires sur les paramètres nommés. Comprend une description, la valeur actuelle, les valeurs possibles et la source du paramètre. (Un ou plusieurs arguments attendus)
-list
Affiche une liste de tous les paramètres IcedTea-Web et de leurs valeurs actuelles. (Aucun argument attendu)
-reset nom
Réinitialise les paramètres spécifiés à leur valeur d'origine. (Un ou plusieurs arguments attendus)
-reset all
Réinitialise tous les paramètres à leurs valeurs d'origine. (Aucun argument attendu)
-set nom valeur
Définit les paramètres à la nouvelle valeur spécifiée, si c'est une valeur appropriée. (Nombre pair d'arguments attendu avec param=valeur comme argument valide)
-verbose
Active la sortie détaillée. (Aucun argument attendu)

EXEMPLES

itweb-settings
Affiche l'éditeur graphique
itweb-settings -reset deployment.proxy.type

Réinitialise la valeur du paramètre `deployment.proxy.type`.

FICHIERS

$JAVA_HOME/lib/deployment.config
Fichier de propriétés de déploiement global Java. Peut être affecté par deployment.jre.dir.
$XDG_CACHE_HOME/icedtea-web/cache
Contient les entrées du cache d'exécution. Contrôlé par deployment.user.cachedir
$XDG_CACHE_HOME/icedtea-web/cache/recently_used
Informations supplémentaires sur les éléments du cache
$XDG_CACHE_HOME/icedtea-web/pcache
Contient les données d'application sauvegardées. Contrôlé par deployment.user.pcachedir
$XDG_CACHE_HOME/icedtea-web/tmp
Contient les fichiers d'exécution temporaires. Contrôlé par deployment.user.tmp
$XDG_CONFIG_HOME/icedtea-web/.appletTrustSettings
Fichier responsable des actions diverses sur les applets et applications basées sur leur codebase, selon les actions de l'utilisateur.
$XDG_CONFIG_HOME/icedtea-web/deployment.properties
Fichier principal des propriétés de déploiement de l'utilisateur.
$XDG_CONFIG_HOME/icedtea-web/generated_jnlps
Emplacement où sont stockés les fichiers jnlp générés à partir des pages html pour les lanceurs d'applications javaws sur le bureau/menu.
$XDG_CONFIG_HOME/icedtea-web/icons
Emplacement où sont stockées les icônes des lanceurs d'applications javaws sur le bureau/menu.
$XDG_CONFIG_HOME/icedtea-web/log
Contient les fichiers journaux (si activés), itw-cplugin-date_time.log pour la partie native du plugin, itw-javantx-date_time.log pour le reste. Contrôlé par deployment.user.logdir
$XDG_DATA_HOME/applications/javaws
Sous-répertoire dans l'espace des menus de l'utilisateur, pour placer des raccourcis de menu personnalisés.
{%WINDIR/Sun/Java ou /etc/.java}/deployment/.appletTrustSettings
Fichier responsable des actions diverses sur les applets et applications basées sur leur codebase, selon les actions de l'administrateur.
{%WINDIR/Sun/Java ou /etc/.java}/deployment/deployment.config
Fichier de configuration global du déploiement.

Où $XDG_CONFIG_DIR, $XDG_CACHE_DIR et $XDG_RUNTIME_DIR sont définis comme ~/.config, ~/.cache et /tmp ou /var/tmp s'ils ne sont pas définis.

BOGUES

Il n'y a pas de bogues connus. Si vous en rencontrez un, veuillez le signaler à :
http://icedtea.classpath.org/wiki/IcedTea-Web#Filing_bugs
http://icedtea.classpath.org/bugzilla

Veuillez exécuter en mode débogage (commutateur -verbose ou réglage itw-settings ou variable ICEDTEAPLUGIN_DEBUG définie à true) et inclure cette sortie (idéalement de la console Java) avec l'URL du fichier jnlp ou html (ou le fichier jnlp/html lui-même) lors du signalement du bogue.
