UTILISATI

ON

Vous utilisez iio_writedev de la même manière que beaucoup des autres utilitaires libiio. Vous devez spécifier un périphérique IIO et le canal spécifique sur lequel écrire. Puisqu'il s'agit d'une écriture, les canaux doivent être en sortie. Si aucun canal n'est fourni, iio_writedev écrira sur tous les canaux de sortie. Si aucun périphérique n'est fourni, iio_writedev affichera quelques exemples

:
iio_writedev -a
Utilisation du contexte IIO détecté automatiquement à l'URI "usb:3.10.5"
Exemple : iio_writedev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-dds-core-lpc voltage0
Exemple : iio_writedev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-dds-core-lpc voltage1
Exemple : iio_writedev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-dds-core-lpc voltage2
Exemple : iio_writedev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-dds-core-lpc voltage3
Exemple : iio_writedev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-dds-core-lp
c

Cela envoie 1024 échantillons de données I et Q à l'AD9361 connecté en USB. Les données sont prises depuis l'entrée standard, dans un format

binaire.
iio_writedev -a -s 1024 c
f-ad9361-dds-core-lpc voltag
e0 voltage1 < ./samples.dat
