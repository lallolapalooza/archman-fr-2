NOM

iiod - Daemon IIO

SYNTAXE

iiod [ options ]

DESCRIPTION

iiod est un serveur basé sur Libiio qui peut partager un contexte Libiio sur le réseau, USB ou une liaison UART.

COMMANDES

-V, --version
Affiche la version de ce programme.
-d, --debug
Utilise une interface de débogage alternative (incompatible).
-D, --demux
Démultiplexe les canaux directement sur le serveur.
-i, --interactive
Exécute iiod dans le terminal de contrôle.
-a, --aio
Utilise les E/S asynchrones.
-F, --ffs <arg>
Utilise le point de montage FunctionFS spécifié pour servir sur USB.
-n, --nb-pipes <arg>
Spécifie le nombre de tuyaux USB (couples d'extrémités) à utiliser.
-s, --serial <arg>
Exécute iiod sur l'UART spécifié.
-p, --port <arg>
Port sur lequel écouter (défaut = 30431). Utiliser --port 0 choisira un port éphémère (dynamique / inutilisé dans la plage entre 32768 et 60999).
-u, --uri
L'identifiant uniforme de ressource (uri) pour se connecter aux périphériques, peut être l'un des suivants :
ip:[adresse]
adresse réseau, soit numérique (192.168.0.1), soit nom d'hôte réseau
ip:
vide, si compilé avec le support zeroconf, trouvera un périphérique IIO sur le réseau
usb:[périphérique:port:instance]
normalement retourné par iio_info -S
serial:[port],[débit],[paramètres]
qui sont contrôlés et doivent correspondre à iiod (ou tinyiiod) à l'autre bout du port série.
[port]
est quelque chose comme '/dev/ttyUSB0' sous Linux, et 'COM4' sous Windows.
[débit]
est normalement l'un de 110, 300, 600, 1200, 2400, 4800, 9600, 14400, 19200, 38400, 57600, 115200 [par défaut], 128000 ou 256000, mais peut varier d'un système à l'autre.
[paramètres]
serait normalement configuré comme '8n1', ceci est contrôlé par :
bits_de_données:
(5, 6, 7, 8 [par défaut], ou 9)
bits_de_parité:
('n' aucun [par défaut], 'o' impair, 'e' pair, 'm' marque, ou 's' espace)
bits_d_arrêt:
(1 [par défaut, ou 2)
contrôle_de_flux:
('0' aucun [par défaut], 'x' Xon Xoff, 'r' RTSCTS, ou 'd' DTRDSR)
local:
sans partie adresse. C'est le défaut.

VALEUR DE RETOUR

Si le périphérique spécifié n'est pas trouvé, un code de sortie non nul est retourné.
