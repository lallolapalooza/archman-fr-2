UTILISATI

ON

Vous utilisez iio_readdev de la même manière que beaucoup des autres utilitaires libiio. Vous devez spécifier un périphérique IIO et le canal spécifique à lire. Puisqu'il s'agit d'une lecture, les canaux doivent être en entrée. Si aucun canal n'est fourni, iio_readdev lira depuis tous les canaux d'entrée. Si aucun périphérique n'est fourni, iio_readdev affichera quelques exemples

:
iio_readdev -a
Utilisation du contexte IIO détecté automatiquement à l'URI "usb:3.10.5"
Exemple : iio_readdev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-lpc voltage0
Exemple : iio_readdev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-lpc voltage1
Exemple : iio_readdev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-lpc voltage2
Exemple : iio_readdev -u usb:3.10.5 -b 256 -s 1024 cf-ad9361-lpc voltage3
Exemple : iio_readdev -u usb:3.10.5 -b 256 -s 1024
cf-ad9361-lpc

Cela capture 1024 échantillons de données I et Q depuis l'AD9361 connecté en USB, et les stocke (en binaire brut) dans le fichier samples.

dat
iio_readdev -a -s 1024 cf-ad9361-lpc voltage0 voltage1 > samples.
dat

Et trace les données avec

gnuplot.
gnuplot -e "set term png; set output 'sample.png'; plot 'sample.dat' binary format='%short%short' using 1 with lines, 'sample.dat' binary format='%short%short' using 2 with lines;"
