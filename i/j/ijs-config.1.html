NOM

ijs-config - script pour obtenir des informations sur la version installée de ijs

SYNOPSIS

ijs-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--libs] [--cflags]

DESCRIPTION

ijs-config est un programme utilisé pour déterminer les indicateurs du compilateur et de l'éditeur de liens qui devraient être utilisés pour compiler et lier les programmes utilisant IJS.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

--help
Affiche un résumé des options. Cela peut lister des options de configuration de paquet avancées supplémentaires non détaillées dans cette page de manuel.
--version
Affiche la version installée de libijs.
--libs
Affiche les indicateurs de l'éditeur de liens nécessaires pour lier un programme IJS.
--cflags
Affiche les indicateurs du compilateur nécessaires pour compiler un programme IJS.
--prefix=PREFIX
S'il est spécifié, utilise PREFIX à la place du préfixe d'installation avec lequel IJS a été compilé lors du calcul de la sortie pour les options --cflags et --libs. Cette option est également utilisée pour le préfixe d'exécution si --exec-prefix n'a pas été spécifié. Cette option doit être spécifiée avant toute option --libs ou --cflags.
--exec-prefix=PREFIX
S'il est spécifié, utilise PREFIX à la place du préfixe d'exécution d'installation avec lequel IJS a été compilé lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.
