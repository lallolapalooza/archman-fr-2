ijq(1) Manuel des commandes générales ijq(1)

NOM

ijq - jq interactif

SYNTAXE

ijq [-cnsrRMSV] [-f fichier] [filtre] [fichiers ...]

DESCRIPTION

ijq est un remplacement presque direct de jq qui vous permet de voir interactivement les résultats de votre filtre au fur et à mesure que vous le construisez.

ijq contient deux volets et un champ de saisie : le volet de gauche contient les données d'entrée originales non modifiées et le volet de droite contient la sortie filtrée. Lorsque vous avez terminé, appuyez sur Entrée ou Ctrl-C pour quitter. La sortie filtrée sera écrite sur la sortie standard et le filtre lui-même sera écrit sur la sortie d'erreur standard.

ijq conserve un historique des filtres utilisés, sauf s'il est désactivé avec l'option -H. Supprimez tout le texte du champ de filtre pour parcourir l'historique disponible.

Si fichiers est omis, alors ijq lit les données depuis l'entrée standard.

Toutes les options reflètent leurs homologues dans jq. Les options sont :

-c

Utiliser la sortie compacte au lieu de la sortie formatée en beauté.

-n

Ne lire aucune entrée. Utile pour utiliser ijq comme calculateur ou pour construire des données JSON à partir de zéro.

-s

Lire toute l'entrée dans un seul tableau et lui appliquer le filtre donné.

-r

Si la sortie du filtre est une chaîne de caractères, elle sera écrite directement sur la sortie standard au lieu d'être formatée en tant que chaîne JSON avec des guillemets. Utile pour utiliser ijq dans un pipeline avec d'autres programmes qui attendent une entrée de chaîne normale.

-R

Ne pas analyser l'entrée comme JSON, mais passer chaque ligne d'entrée au filtre sous forme de chaîne. Si combiné avec -s, alors l'entrée entière est passée au filtre comme une seule longue chaîne.

-M

Désactiver la sortie colorée.

-S

Sortir les champs de chaque objet avec les champs dans un ordre trié.

-f fichier

Lire le filtre depuis fichier. Lorsque cette option est utilisée, tous les arguments positionnels (le cas échéant) sont interprétés comme des fichiers d'entrée.

ijq a quelques options qui influencent sa configuration et sa disposition de départ. Elles sont conçues pour éviter les conflits avec jq. Si jq ajoute à l'avenir une option qui entre en conflit avec l'une de celles-ci, elles pourraient changer ici.

-H fichier

Spécifiez le chemin pour stocker l'historique. S'il est défini sur '' (-H ''), alors l'historique ne sera pas capturé.

-hide-input-pane

Masque le volet de visualisation de l'entrée (gauche), qui affiche l'entrée originale.

#KEY_BINDINGSCHES'>GESTION DES TOUCHES

Maj + Haut, Maj + Gauche

Donne le focus au volet de visualisation de l'entrée (gauche).

Maj + Droite

Donne le focus au volet de visualisation de la sortie (droite).

Maj + Bas

Donne le focus au champ de saisie de texte.

Tab

Lorsque le champ de saisie de texte a le focus, navigue dans la liste d'autocomplétion. Lorsqu'un des volets de visualisation a le focus, bascule entre les différentes vues.

Maj + Tab

Comme Tab, mais se déplace dans la direction opposée.

Ctrl + A

Lorsque le champ de saisie de texte a le focus, déplace le curseur au début de l'entrée. Lorsqu'un des volets de visualisation a le focus, définit le décalage de colonne à 0.

Ctrl + E

Lorsque le champ de saisie de texte a le focus, déplace le curseur à la fin de l'entrée. Lorsqu'un des volets de visualisation a le focus, définit le décalage de colonne pour afficher la ligne visible la plus longue.

Ctrl + F

Lorsque le champ de saisie de texte a le focus, déplace le curseur d'un caractère vers l'avant. Lorsqu'un des volets de visualisation a le focus, fait défiler la page vers le bas.

Ctrl + B

Lorsque le champ de saisie de texte a le focus, déplace le curseur d'un caractère vers l'arrière. Lorsqu'un des volets de visualisation a le focus, fait défiler la page vers le haut.

Ctrl + D

Lorsque le champ de saisie de texte a le focus, supprime le caractère sous le curseur. Lorsqu'un des volets de visualisation a le focus, fait défiler la page d'une demi-page vers le bas.

Ctrl + U

Lorsque le champ de saisie de texte a le focus, supprime tout le texte du curseur jusqu'au début du champ. Lorsqu'un des volets de visualisation a le focus, fait défiler la page d'une demi-page vers le haut.

Ctrl + O

Active/désactive la visibilité du volet de visualisation de l'entrée (gauche).

u, d, f, b

Lorsqu'un des volets de visualisation a le focus, fait défiler la page d'une demi/pleine page vers le haut/bas.

Gauche, Bas, Haut, Droite h, j, k, l

Lorsqu'un des volets de visualisation a le focus, déplace la vue vers la gauche/bas/haut/droite.

Entrée

Ferme ijq. Écrit le contenu du volet de sortie sur stdout et le filtre d'entrée actuel sur stderr. Le filtre d'entrée actuel est également enregistré dans le fichier d'historique.

Ctrl + C

Quitte ijq immédiatement, en ignorant tout état.
