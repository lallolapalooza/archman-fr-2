IEEE1284_REF(3) Fonctions IEEE1284_REF(3)

NOM

ieee1284_ref, ieee1284_unref - modifier le compteur de références d'un port

SYNTAXE

#include <ieee1284.h>

int ieee1284_ref(struct parport *port);

int ieee1284_unref(struct parport *port);

DESCRIPTION

Si vous souhaitez libérer la liste des ports de ieee1284_find_ports mais ouvrir l'un des ports ultérieurement, vous devrez l'empêcher d'être détruit dans ieee1284_free_ports. Chaque port possède un compteur de références, et vous pouvez utiliser ieee1284_ref pour l'incrémenter et ieee1284_unref pour le décrémenter.

Si vous utilisez ieee1284_ref à un moment donné, vous devez appeler plus tard ieee1284_unref pour abandonner la référence supplémentaire. Si vous ne le faites pas, les ressources associées au port ne seront pas nettoyées.

Si vous n'avez pas déjà utilisé ieee1284_ref sur un port, vous ne devez pas utiliser ieee1284_unref sur celui-ci.

VALEUR DE RETOUR

Ces fonctions renvoient le nombre de références détenues après l'incrémentation ou la décrémentation.
