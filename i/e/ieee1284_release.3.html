NOM

ieee1284_release - libérer un port

SYNTAXE

#include <ieee1284.h>

void ieee1284_release(struct parport *port);

DESCRIPTION

Cette fonction annule l'effet de ieee1284_claim(3) en libérant le port pour une utilisation par d'autres pilotes. Il est de bonne pratique de libérer le port dès que possible. S'il n'est jamais pratique de le faire, le drapeau F1284_EXCL doit être spécifié lors de l'initialisation.
