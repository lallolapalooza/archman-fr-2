IEEECK

Objectif :

!>
!> IEEECK est appelé depuis ILAENV pour vérifier que l'arithmétique de l'Infini et
!> éventuellement du NaN est sûre (c'est-à-dire qu'elle ne déclenchera pas de piège).
!>

Paramètres

ISPEC 
!>          ISPEC est un ENTIER
!>          Spécifie s'il faut tester uniquement l'arithmétique de l'infini
!>          ou tester l'arithmétique de l'infini et du NaN.
!>          = 0 : Vérifier uniquement l'arithmétique de l'infini.
!>          = 1 : Vérifier l'arithmétique de l'infini et du NaN.
!>

ZERO

!>          ZERO est un REEL
!>          Doit contenir la valeur 0.0
!>          Ceci est passé pour empêcher le compilateur d'optimiser
!>          ce code.
!>

UN

!>          UN est un REEL
!>          Doit contenir la valeur 1.0
!>          Ceci est passé pour empêcher le compilateur d'optimiser
!>          ce code.
!>
!>  VALEUR DE RETOUR : ENTIER
!>          = 0 : L'arithmétique n'a pas produit les bonnes réponses
!>          = 1 : L'arithmétique a produit les bonnes réponses
!>
