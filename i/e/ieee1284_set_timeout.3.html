NOM

ieee1284_set_timeout - modifier le délai d'inactivité

SYNTAXE

#include <ieee1284.h>

struct timeval *ieee1284_set_timeout(struct parport *port, struct timeval *timeout);

DESCRIPTION

Cette fonction définit une nouvelle valeur pour le délai d'inactivité (utilisé pour les fonctions de transfert par bloc) et retourne l'ancienne valeur.

Le port doit être réclamé.

Le paramètre timeout peut être NULL, auquel cas l'ancienne valeur n'est pas modifiée.

VALEUR DE RETOUR

Cette fonction retourne un pointeur vers une structure timeval représentant l'ancienne valeur. Elle utilise le même espace de stockage que la structure port, et n'est donc pas valide après la fermeture du port.

NOTES

Notez qu'il s'agit d'un délai d'inactivité, et non d'un délai absolu. Lors d'un transfert de données, si le périphérique est inactif pendant la durée spécifiée, l'hôte abandonne.

Il est également consultatif ; aucune garantie n'est faite que le transfert s'achèvera un jour.
