NOM

iec16022 - programme pour générer des codes-barres 2D

SYNOPIS

iec16022 [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande iec16022.

iec16022 génère des codes-barres 2D conformes à la norme ISO/IEC 16022 (également connue sous le nom de Data Matrix et Semacode).

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-s, --size WxH
Définit la taille du code-barres généré.
-c, --barcode texte
Spécifie le texte à encoder.
--ecc 000|050|080|100|140|200
Définit le type d'ECC à utiliser (par défaut : 200).
-i, --infile nomfichier
Lit les données d'entrée depuis un fichier.
-o, --outfile nomfichier
Sauvegarde la sortie dans un fichier (au lieu de la sortie standard).
-f, --format Text|UTF-8|EPS|Bin|Hex|Stamp|PNG
Définit le type de sortie.
-?, --help
Affiche un résumé des options.
--usage
Affiche un bref aperçu des options.

EXEMPLE

Pour produire un code-barres DataMatrix pour "foobar" au format PNG, vous avez besoin des arguments suivants :

iec16022 -f PNG -c foobar -o foobar.png
