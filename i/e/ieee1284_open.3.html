IEEE1284_OPEN(3) Fonctions IEEE1284_OPEN(3)

NOM

ieee1284_open - ouvrir un port

SYNTAXE

#include <ieee1284.h>

int ieee1284_open(struct parport *port, int flags, int *capabilities);

DESCRIPTION

Afin de commencer à utiliser un port, il doit être ouvert. Toute initialisation du port est effectuée à ce stade. Lorsqu'un port ouvert n'est plus nécessaire, il doit être fermé avec ieee1284_close(3).

Les flags possibles sont :

F1284_EXCL

Ce périphérique ne peut pas partager le port avec un autre périphérique. S'il s'agit de ce cas, cela doit être déclaré à ce stade, afin que les autres pilotes essayant d'accéder au port sachent qu'il ne faut pas s'en occuper ; sinon, ils attendront que ce pilote libère le port, c'est-à-dire jamais.

Les méthodes d'accès iopl/dev-port ne prennent pas encore en charge cela, mais celles de ppdev le font.

Si capabilities n'est pas NULL, il doit pointer vers un espace de stockage pour un int, qui sera traité comme un ensemble de drapeaux, un par bit, que la bibliothèque définit ou efface de manière appropriée. Si une capacité est présente, elle sera utilisée lorsqu'elle sera demandée. Ce sont :

CAP1284_RAW

L'accès au niveau des broches est disponible. Si cette capacité est présente, les fonctions suivantes sont efficaces : ieee1284_write_data, ieee1284_read_status, ieee1284_wait_status, ieee1284_write_control, ieee1284_read_control, ieee1284_frob_control.

CAP1284_NIBBLE

Il existe une implémentation du mode nibble pour ce port.

CAP1284_BYTE

Il existe une implémentation du mode byte pour ce port.

CAP1284_COMPAT

Il existe une implémentation du mode compatibilité pour ce port.

CAP1284_ECP

Il existe une implémentation matérielle du mode ECP pour ce port.

CAP1284_ECPRLE

Il existe une implémentation du mode ECP tenant compte de RLE pour ce port (le drapeau F1284_RLE est reconnu par les fonctions de transfert ECP).

CAP1284_ECPSWE

Il existe une implémentation logicielle du mode ECP pour ce port.

CAP1284_BECP

Il existe une implémentation du mode ECP borné pour ce port.

CAP1284_EPP

Il existe une implémentation matérielle du mode EPP pour ce port.

CAP1284_EPPSWE

Il existe une implémentation logicielle du mode EPP pour ce port.

CAP1284_IRQ

Une ligne d'interruption est configurée pour ce port et des notifications d'interruption peuvent être reçues via ieee1284_get_irq_fd(3).

CAP1284_DMA

Un canal DMA est configuré pour ce port.

VALEUR DE RETOUR

E1284_OK

Le port est maintenant ouvert.

E1284_INIT

Il y a eu un problème lors de l'initialisation du port. Cela pourrait être dû au fait qu'un autre pilote a ouvert le port en mode exclusif, ou pour une autre raison.

E1284_NOMEM

Il n'y a pas assez de mémoire.

E1284_NOTAVAIL

Un ou plusieurs des drapeaux fournis ne sont pas pris en charge par ce type de port.

E1284_INVALIDPORT

Le paramètre port est invalide (par exemple, le port peut déjà être ouvert).

E1284_SYS

Il y a eu un problème au niveau du système d'exploitation. La variable globale errno a été définie de manière appropriée.

VOIR AUSSI

ieee1284_close(3)
