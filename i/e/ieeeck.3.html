Documentation de la fonction

fonction entière ieeeck (entier ispec, réel zero, réel un)

IEEECK

Objectif :

!>
!> IEEECK est appelé depuis ILAENV pour vérifier que l'arithmétique de l'infini et
!> éventuellement du NaN est sûre (c'est-à-dire qu'elle ne déclenchera pas d'exception).
!>

Paramètres

ISPEC 
!>          ISPEC est un ENTIER
!>          Spécifie s'il faut tester uniquement l'arithmétique de l'infini
!>          ou si l'on doit tester l'arithmétique de l'infini et du NaN.
!>          = 0 : Vérifier uniquement l'arithmétique de l'infini.
!>          = 1 : Vérifier l'arithmétique de l'infini et du NaN.
!>

ZERO

!>          ZERO est un RÉEL
!>          Doit contenir la valeur 0.0
!>          Ceci est passé pour empêcher le compilateur d'optimiser
!>          ce code et de le supprimer.
!>

UN

!>          UN est un RÉEL
!>          Doit contenir la valeur 1.0
!>          Ceci est passé pour empêcher le compilateur d'optimiser
!>          ce code et de le supprimer.
!>
!>  VALEUR DE RETOUR : ENTIER
!>          = 0 : L'arithmétique a échoué à produire les résultats corrects
!>          = 1 : L'arithmétique a produit les résultats corrects
!>
