Paquet: libieee1284

Licences: GPL-2.0-or-later

IEEE1284_DATA(3) Fonctions IEEE1284_DATA(3)

NOM

ieee1284_read_data, ieee1284_write_data, ieee1284_data_dir, ieee1284_wait_data - contrôler les lignes de données

SYNTAXE

#include <ieee1284.h>

int ieee1284_read_data(struct parport *port);

void ieee1284_write_data(struct parport *port, unsigned char dt);

int ieee1284_data_dir(struct parport *port, int reverse);

int ieee1284_wait_data(struct parport *port, unsigned char mask, unsigned char val, struct timeval *timeout);

DESCRIPTION

Ces fonctions manipulent les lignes de données du port parallèle associé à port (qui doit avoir été réclamé en utilisant ieee1284_claim(3)). Les lignes sont représentées par un nombre de 8 bits (une ligne par bit) et une direction. Les lignes de données sont pilotées en groupe ; elles peuvent être toutes pilotées par l'hôte (direction avant) ou non (direction inverse). Lorsque le périphérique les pilote, l'hôte ne doit pas le faire.

Pour ieee1284_data_dir, le paramètre reverse doit être à zéro pour activer les pilotes des lignes de données et non nul pour les désactiver. Certains types de ports peuvent ne pas être capables de désactiver les pilotes des lignes de données.

La définition des lignes de données peut avoir des effets secondaires sur certains types de ports (par exemple, certains ports Amiga impulsent nStrobe).

ieee1284_wait_data attend, jusqu'à l'expiration du timeout, que les bits de données spécifiés par mask aient les valeurs correspondantes dans val.

VALEUR DE RETOUR

ieee1284_read_data retourne le nombre de 8 bits représentant les lignes de données, sauf s'il n'est pas possible de retourner une telle valeur avec ce type de port, auquel cas elle retourne un code d'erreur. Codes d'erreur possibles :

E1284_NOTAVAIL

Les lignes de données bidirectionnelles ne sont pas disponibles sur ce système.

E1284_INVALIDPORT

Le paramètre port est invalide (peut-être n'a-t-il pas été réclamé, par exemple).

E1284_SYS

Il y a eu une erreur au niveau du système d'exploitation, et errno a été correctement défini.

E1284_TIMEDOUT

Le timeout a expiré.

Alors que ieee1284_read_data peut retourner E1284_NOTAVAIL lors de sa première invocation sur le port, si elle ne le fait pas, elle ne le pourra plus tant que ieee1284_close n'est pas appelé pour ce port.
