iecset(1) Manuel des commandes générales iecset(1)

NOM

iecset - Définir ou afficher les bits de statut IEC958

SYNTAXE

iecset [options] [commande arg...]

DESCRIPTION

iecset est un petit utilitaire pour définir ou afficher les bits de statut IEC958 (ou "S/PDIF") de la carte son spécifiée via l'API de contrôle ALSA.

Lorsque iecset est lancé sans arguments autres que les options, il affiche le statut IEC958 actuel sous une forme lisible par l'homme. Lorsque des commandes sont fournies en arguments, elles sont analysées et les bits de statut IEC958 sont mis à jour. Le statut résultant est également affiché.

Les commandes consistent en la directive de commande et l'argument. Comme argument booléen, yes, no, true, false, ou un nombre à un chiffre est autorisé.

EXEMPLES

iecset -Dhw:1
Affiche les bits de statut IEC958 actuels sur la deuxième carte. Ceci est équivalent à -c 1.
iecset -x
Affiche les bits de statut IEC958 actuels dans le style des arguments pour le flux PCM. La chaîne de sortie peut être passée au type PCM iec958 (ou spdif) comme argument optionnel.
iecset pro off audio off
Définit le statut actuel sur le mode consommateur et active le bit non-audio. Le statut modifié sera également affiché.

OPTIONS

-D pÃ©riphÃ©rique
Spécifie le nom du périphérique de contrôle à ouvrir.
-c carte
Spécifie l'index de la carte à ouvrir. Équivalent à -Dhw:x.
-n index
Spécifie l'index de l'élément de contrôle IEC958, au cas où vous auriez plusieurs périphériques IEC958 et que vous auriez besoin d'en choisir un.
-x
Affiche le statut sous forme d'octets AESx.
-i
Lit les séquences de commandes depuis stdin. Chaque ligne contient une seule commande.

COMMANDES

professionnel <bool>
Le mode professionnel (true) ou mode consommateur (false).
audio <bool>
Le mode audio (true) ou mode non-audio (false).
taux <int>
Le taux d'échantillonnage en Hz.
emphase <int>
L'emphase : 0 = aucune, 1 = 50/15us, 2 = CCITT.
verrou <bool>
Verrouillage du taux : verrouillé (true), déverrouillé (false). Cette commande est uniquement pour le mode professionnel.
bits-de-bit <int>
Bits d'échantillon : 2 = 20 bits, 4 = 24 bits, 6 = indéfini. Cette commande est uniquement pour le mode professionnel.
longueur-de-mot <int>
Longueur du mot : 0 = Non, 2 = 18-22 bits, 4 = 19-23 bits, 5 = 20-24 bits, 6 = 16-20 bits. Cette commande est uniquement pour le mode professionnel.
catégorie <int>
Catégorie : la valeur est de 0 à 0x7f. Cette commande est uniquement pour le mode consommateur.
droit-dauteur <bool>
Droit d'auteur : protégé par copyright (true), non protégé par copyright (false). Cette commande est uniquement pour le mode consommateur.
original <boo>
Indicateur original : original (true), 1ère génération (false). Cette commande est uniquement pour le mode consommateur.
