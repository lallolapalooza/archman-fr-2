ieee1284_get_irq_fd(3)

Paquet: libieee1284

Licences: GPL-2.0-or-later

IEEE1284_GET_IRQ_FD(3) Fonctions IEEE1284_GET_IRQ_FD(3)

NOM

ieee1284_get_irq_fd, ieee1284_clear_irq - notification d'interruption

SYNTAXE

#include <ieee1284.h>

int ieee1284_get_irq_fd(struct parport *port);

int ieee1284_clear_irq(struct parport *port, unsigned int *count);

DESCRIPTION

Si le port a une ligne d'interruption configurée et que le type de port prend en charge la notification d'interruption, il est possible d'obtenir un descripteur de fichier qui peut être utilisé pour select(2) ou poll(2). Tout événement (lisible, inscriptible ou exception) signifie qu'une interruption a été déclenchée. Aucune opération autre que select ou poll ne peut être effectuée sur le descripteur de fichier.

Le port doit être ouvert pour pouvoir appeler ieee1284_get_irq_fd, et doit être réclamé lors de l'utilisation de select ou poll.

L'appelant ne doit pas fermer le descripteur de fichier, et ne peut pas l'utiliser du tout lorsque le port n'est pas réclamé.

Lorsqu'une interruption a été détectée, l'appelant doit appeler ieee1284_clear_irq pour effacer la condition d'interruption, auquel cas le nombre d'interruptions déclenchées peut être obtenu en fournissant un count non-NULL.

VALEUR DE RETOUR

Pour ieee1284_get_irq_fd : si la valeur de retour est négative, il s'agit d'un code d'erreur listé ci-dessous. Sinon, c'est un descripteur de fichier valide.

E1284_NOTAVAIL

Aucun descripteur de fichier de ce type n'est disponible.

E1284_INVALIDPORT

Le paramètre port est invalide (par exemple, le port n'est peut-être pas ouvert).

Pour ieee1284_clear_irq :

E1284_OK

L'interruption a été effacée. Si count n'était pas NULL, le compte des interruptions a été atomiquement stocké dans count et réinitialisé.

E1284_NOTAVAIL

Le paramètre count n'était pas NULL mais le comptage des interruptions n'est pas pris en charge sur ce type de port. L'interruption a été effacée.

E1284_SYS

Il y a eu un problème pour effacer l'interruption.

E1284_INVALIDPORT

Le paramètre port est invalide (par exemple, le port n'est peut-être pas réclamé).
