IEEE1284_STATUS(3) Fonctions IEEE1284_STATUS(3)

NOM

ieee1284_read_status, ieee1284_wait_status - analyser les lignes d'état

SYNOPSIS

#include <ieee1284.h>

int ieee1284_read_status(struct parport *port);

int ieee1284_wait_status(struct parport *port, unsigned char mask, unsigned char val, struct timeval *timeout);

DESCRIPTION

Il existe cinq lignes d'état, dont l'une est généralement inversée sur les ports de type PC. Là où elles diffèrent, libieee1284 opère sur les valeurs IEEE 1284, pas sur les valeurs inversées de type PC. Les lignes d'état sont représentées par l'énumération suivante :

enum ieee1284_status_bits
{
  S1284_NFAULT = 0x08,
  S1284_SELECT = 0x10,
  S1284_PERROR = 0x20,
  S1284_NACK   = 0x40,
  S1284_BUSY   = 0x80,
  /* Pour convertir ces valeurs en valeurs de registre de type PC, utilisez ceci : */
  S1284_INVERTED = S1284_BUSY,
};

Ces fonctions agissent toutes sur le port parallèle associé à port, qui doit être réclamé.

Le but de ieee1284_wait_status est d'attendre que des lignes d'état particulières aient des valeurs spécifiées. Son paramètre timeout peut être modifié au retour.

VALEUR DE RETOUR

Pour ieee1284_read_status, la valeur de retour est un entier non négatif avec les bits définis de manière appropriée représentant les lignes d'état. Un résultat négatif indique une erreur.

Pour ieee1284_wait_status, la valeur de retour est E1284_OK si les lignes d'état reflètent maintenant les valeurs désirées (c'est-à-dire que status & mask est val), ou un résultat négatif indiquant une erreur.

Codes d'erreur possibles :

E1284_NOTIMPL

Le port n'a pas la capacité requise. Cela pourrait être dû à une limitation de cette version de libieee1284, ou à une limitation matérielle.

E1284_NOTAVAIL

L'accès aux lignes d'état n'est pas disponible sur ce type de port.

E1284_TIMEDOUT

Le timeout a expiré.

E1284_INVALIDPORT

Le paramètre port est invalide (par exemple, peut-être que le port n'est pas réclamé).

NOTES

La broche nAck peut souvent déclencher des interruptions sur la machine hôte. Avec l'aide du système d'exploitation, ces interruptions peuvent être visibles par l'application via le descripteur de fichier renvoyé par ieee1284_get_irq_fd.

Sous Linux, les conditions sont que le pilote de port parallèle sache quelle ligne d'interruption utiliser et qu'il l'utilise, et que le nœud de périphérique /dev/parport pertinent soit accessible et soutenu par un pilote de périphérique.
