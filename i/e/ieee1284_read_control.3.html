ieee1284_read_control(3)

Paquet: libieee1284

Licences: GPL-2.0-or-later

IEEE1284_CONTROL(3) Fonctions IEEE1284_CONTROL(3)

NOM

ieee1284_read_control, ieee1284_write_control, ieee1284_frob_control, ieee1284_do_nack_handshake - manipuler les lignes de contrôle

SYNTAXE

#include <ieee1284.h>

int ieee1284_read_control(struct parport *port);

void ieee1284_write_control(struct parport *port, unsigned char ct);

void ieee1284_frob_control(struct parport *port, unsigned char mask, unsigned char val);

int ieee1284_do_nack_handshake(struct parport *port, unsigned char ct_before, unsigned char ct_after, struct timeval *timeout);

DESCRIPTION

Il y a quatre lignes de contrôle, dont trois sont généralement inversées sur les ports de style PC. Là où elles diffèrent, libieee1284 opère sur les valeurs IEEE 1284, pas sur les valeurs inversées de style PC. Les lignes de contrôle sont représentées par l'énumération suivante :

enum ieee1284_control_bits
{
  C1284_NSTROBE   = 0x01,
  C1284_NAUTOFD   = 0x02,
  C1284_NINIT     = 0x04,
  C1284_NSELECTIN = 0x08,
  /* Pour convertir ces valeurs en valeurs de registre de style PC, utilisez ceci : */
  C1284_INVERTED = (C1284_NSTROBE|
                    C1284_NAUTOFD|
                    C1284_NSELECTIN),
};

Ces fonctions agissent toutes sur le port parallèle associé à port, qui doit être réclamé.

Les valeurs actuelles sur les lignes de contrôle sont disponibles en appelant ieee1284_read_control, et peuvent être définies en appelant ieee1284_write_control.

Pour ajuster les valeurs sur un ensemble de lignes de contrôle, utilisez ieee1284_frob_control. L'effet de ceci peut être exprimé par : ctr = ((ctr & ~mask) ^ val); c'est-à-dire que les bits dans mask sont désactivés, puis ceux dans val sont inversés.

La fonction spéciale ieee1284_do_nack_handshake est pour répondre très rapidement dans un protocole où le périphérique règle nAck et l'hôte doit répondre en réglant une ligne de contrôle. Son fonctionnement, qui repose sur le fait que la machine hôte sait quelle interruption génère nAck, est le suivant :

1.Réglez les lignes de contrôle comme indiqué dans ct_before.
2.Attendez l'interruption nAck. Si timeout est atteint, retournez E1284_TIMEDOUT.
3.Réglez les lignes de contrôle comme indiqué dans ct_after.

Sous Linux utilisant le pilote ppdev, cela est effectué par le pilote du périphérique dans le noyau, et est donc plus rapide qu'il n'est normalement possible dans une bibliothèque utilisateur.

VALEUR DE RETOUR

La valeur de retour de ieee1284_read_control, si elle est non négative, est un nombre représentant la valeur sur les lignes de contrôle.

Codes d'erreur possibles pour ieee1284_read_control :

E1284_NOTAVAIL

Les lignes de contrôle de ce port ne sont pas accessibles par l'application.

E1284_INVALIDPORT

Le paramètre port est invalide (par exemple, il n'est peut-être pas réclamé).

Codes d'erreur possibles pour ieee1284_do_nack_handshake :

E1284_OK

La poignée de main a réussi.

E1284_NOTAVAIL

Cette opération n'est pas disponible sur ce type de port ou ce système. Cela pourrait être parce que les interruptions du port ne sont pas disponibles, ou parce que le pilote sous-jacent ne prend pas en charge l'opération.

E1284_INVALIDPORT

Le paramètre port est invalide (par exemple, il n'est peut-être pas réclamé).
