NOM

iasecc-tool - affiche des informations sur les cartes IAS/ECC

SYNTAXE

iasecc-tool [OPTIONS]

DESCRIPTION

L'utilitaire iasecc-tool est utilisé pour afficher des informations sur les cartes à puce IAS/ECC v1.0.1.

OPTIONS

--reader arg,

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte insérée est utilisé. Si arg est une ATR, le lecteur avec une carte correspondante sera choisi.

--list-applications,

Obtenir la liste des applications sur la carte.

--aid hex-aid,

Sélectionner hex-aid avant le traitement.

--list-sdos sdo-type,

Lister les SDO du sdo-type donné, présents dans l'application par défaut ou sélectionnée.

--verbose, -v

Rend cardos-tool plus verbeux. Spécifiez ce drapeau plusieurs fois pour activer la sortie de débogage dans la bibliothèque opensc.

--wait, -w

Fait attendre iasecc-tool jusqu'à ce que le jeton soit inséré dans le lecteur.

AUTEURS
