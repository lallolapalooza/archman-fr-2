IAITO(1) Manuel des commandes générales IAITO(1)

NOM

iaito - page de manuel pour iaito

SYNTAXE

iaito [options] nom_de_fichier

DESCRIPTION

Une interface graphique Qt et C++ pour le framework d'ingénierie inverse radare2. iaito est la continuation de Iaito avant le fork de radare2 / rizin pour garder radare2 comme backend.
- Se concentre sur le support de la dernière version de radare2.
- Recommande l'utilisation des bibliothèques installées dans le système.
- Intégration plus étroite entre r2 et l'interface utilisateur.

OPTIONS

-h, --help
Affiche l'aide sur les options de la ligne de commande.
--help-all
Affiche l'aide, y compris les options spécifiques à Qt.
-v, --version
Affiche les informations de version.
-A, --analysis <niveau>
Ouvre automatiquement le fichier et démarre éventuellement l'analyse. Nécessite la spécification d'un nom de fichier. Peut être une valeur comprise entre 0 et 2 : 0 = pas d'analyse, 1 = aaa, 2 = aaaa (expérimental)
-F, --format <nom>
Force l'utilisation d'un format de fichier spécifique (plugin bin)
-B, --base <adresse_de_base>
Charge le binaire à une adresse de base spécifique
-i <fichier>
Exécute le fichier de script
-w, --writemode
Ouvre le fichier en mode écriture
--pythonhome <PYTHONHOME>
PYTHONHOME à utiliser pour l'interpréteur Python embarqué
--no-output-redirect
Désactive la redirection de sortie. Certaines sorties dans le widget console ne seront pas visibles. Utilisez cette option lors du débogage d'un crash ou d'un gel, et que la redirection de sortie cause la perte de certains messages.
--no-plugins
Ne charge pas les plugins
--no-iaito-plugins
Ne charge pas les plugins Iaito
--no-r2-plugins
Ne charge pas les plugins radare2

Arguments :

nom_de_fichier
Nom du fichier à ouvrir. S'il n'est pas spécifié, la boîte de dialogue de sélection de fichier sera affichée.

VOIR AUSSI

La documentation complète de iaito est maintenue dans le dossier docs du code source https://github.com/radareorg/iaito/tree/master/docs Dans votre distribution, vous pourriez la trouver compilée dans un paquet séparé iaito-doc.
