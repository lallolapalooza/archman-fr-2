fonction entière icamax (entier n, complexe, dimension(*) cx, entier incx)

ICAMAX

Objectif :

!>
!>    ICAMAX trouve l'indice du premier élément ayant le maximum |Re(.)| + |Im(.)|
!>

Paramètres

N 
!>          N est ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

CX

!>          CX est un tableau COMPLEXE, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est ENTIER
!>         espacement de stockage entre les éléments de CX
