NOM

windres - manipuler les ressources Windows

SYNOPSIS

windres [options] [fichier-entrée] [fichier-sortie]

DESCRIPTION

windres lit les ressources d'un fichier d'entrée et les copie dans un fichier de sortie. Chacun des deux fichiers peut être dans l'un des trois formats suivants :

"rc"
Un format texte lu par le compilateur de ressources.
"res"
Un format binaire généré par le compilateur de ressources.
"coff"
Un objet ou un exécutable COFF.

La description exacte de ces différents formats est disponible dans la documentation de Microsoft.

Quand windres convertit du format "rc" vers le format "res" , il se comporte comme le compilateur de ressources Windows. Quand windres convertit du format "res" vers le format "coff" , il se comporte comme le programme Windows "CVTRES" .

Quand windres génère un fichier "rc" , la sortie est similaire mais pas identique au format attendu en entrée. Quand un fichier "rc" d'entrée fait référence à un nom de fichier externe, un fichier "rc" de sortie inclura plutôt le contenu du fichier.

Si le format d'entrée ou de sortie n'est pas spécifié, windres le déduira à partir du nom du fichier ou, pour le fichier d'entrée, de son contenu. Un fichier avec l'extension .rc sera traité comme un fichier "rc" , un fichier avec l'extension .res sera traité comme un fichier "res" , et un fichier avec l'extension .o ou .exe sera traité comme un fichier "coff" .

Si aucun fichier de sortie n'est spécifié, windres affichera les ressources au format "rc" sur la sortie standard.

L'utilisation normale consiste à écrire un fichier "rc" , à utiliser windres pour le convertir en fichier objet COFF, puis à lier le fichier COFF à votre application. Cela rendra les ressources décrites dans le fichier "rc" disponibles pour Windows.

OPTIONS

-i nom-fichier
--input nom-fichier
Le nom du fichier d'entrée. Si cette option n'est pas utilisée, windres utilisera le premier argument non-option comme nom du fichier d'entrée. S'il n'y a pas d'argument non-option, windres lira depuis l'entrée standard. windres ne peut pas lire un fichier COFF depuis l'entrée standard.
-o nom-fichier
--output nom-fichier
Le nom du fichier de sortie. Si cette option n'est pas utilisée, windres utilisera le premier argument non-option, après ceux utilisés pour le nom du fichier d'entrée, comme nom du fichier de sortie. S'il n'y a pas d'argument non-option, windres écrira sur la sortie standard. windres ne peut pas écrire un fichier COFF sur la sortie standard. Notez que, pour des raisons de compatibilité avec rc , l'option -fo est également acceptée, mais son utilisation n'est pas recommandée.
-J format
--input-format format
Le format d'entrée à lire. format peut être res, rc, ou coff. Si aucun format d'entrée n'est spécifié, windres le déduira, comme décrit ci-dessus.
-O format
--output-format format
Le format de sortie à générer. format peut être res, rc, coff. Si aucun format de sortie n'est spécifié, windres le déduira, comme décrit ci-dessus.
-F cible
--target cible
Spécifie le format BFD à utiliser pour un fichier COFF en entrée ou en sortie. Il s'agit d'un nom de cible BFD ; vous pouvez utiliser l'option --help pour voir une liste des cibles prises en charge. Normalement, windres utilisera le format par défaut, qui est le premier de la liste affichée par l'option --help .
--preprocessor programme
Quand windres lit un fichier "rc" , il le fait d'abord passer par le préprocesseur C. Cette option peut être utilisée pour spécifier le préprocesseur à utiliser. Le préprocesseur par défaut est "gcc".
--preprocessor-arg option
Quand windres lit un fichier "rc" , il le fait d'abord passer par le préprocesseur C. Cette option peut être utilisée pour spécifier du texte supplémentaire à passer au préprocesseur sur sa ligne de commande. Cette option peut être utilisée plusieurs fois pour ajouter plusieurs options à la ligne de commande du préprocesseur. Si l'option --preprocessor n'a pas été spécifiée, un ensemble d'arguments de préprocesseur par défaut sera utilisé, avec les options --preprocessor-arg placées après elles sur la ligne de commande. Ces arguments par défaut sont "-E", "-xc-header" et "-DRC_INVOKED".
-I répertoire
--include-dir répertoire
Spécifie un répertoire d'inclusion à utiliser lors de la lecture d'un fichier "rc" . windres le transmettra au préprocesseur sous la forme d'une option -I . windres recherchera également dans ce répertoire lors de la recherche des fichiers nommés dans le fichier "rc" . Si l'argument passé à cette commande correspond à l'un des formats pris en charge (comme décrit dans l'option -J ), un avertissement de dépréciation sera émis, et il se comportera exactement comme l'option -J . Les nouveaux programmes ne devraient pas utiliser ce comportement. Si un répertoire correspond par hasard à un format, préfixez-le simplement par ./ pour désactiver la compatibilité ascendante.
-D cible
--define sym[=val]
Spécifie une option -D à passer au préprocesseur lors de la lecture d'un fichier "rc" .
-U cible
--undefine sym
Spécifie une option -U à passer au préprocesseur lors de la lecture d'un fichier "rc" .
-r
Ignoré pour des raisons de compatibilité avec rc.
-v
Active le mode verbeux. Cela vous indique quel est le préprocesseur si vous n'en avez pas spécifié.
-c val
--codepage val
Spécifie la page de code par défaut à utiliser lors de la lecture d'un fichier "rc" . val devrait être un code de page de code en hexadécimal préfixé par 0x ou en décimal. La plage valide va de zéro à 0xffff, mais la validité de la page de code dépend de l'hôte et de la configuration.
-l val
--language val
Spécifie la langue par défaut à utiliser lors de la lecture d'un fichier "rc" . val devrait être un code de langue en hexadécimal. Les huit bits de poids faible sont la langue, et les huit bits de poids fort sont la sous-langue.
--use-temp-file

NAME

windres

resource compiler for Windows

SYNOPSIS

windres [-o output_file] [-O format] [-v] [--target=bfdname] [-i input_file] [--use-temp-file|--no-use-temp-file] [-h|--help] [-V|--version] [--yydebug] [@file... ] input_files...

DESCRIPTION

The windres program is used to compile Windows resource files (.rc) into a binary format that can be linked into Windows programs.

This program is part of the GNU Binutils.

OPTIONS

-o output_file
Write output to output_file instead of standard output.
-O format
Interpret the input file as being in format format. The default is PE (Portable Executable).
-v
Display the version number of windres and exit.
--target=bfdname
Display the available targets and exit. The target specifies the executable file format for the output. It is often the same as the name of the compiler, e.g. pe.
-i input_file
Read input from input_file. If this option is not specified, windres will read from the standard input.
--use-temp-file
Use a temporary file to communicate with the preprocessor. This is required on some systems where popen might be buggy (known to have buggy popen where the output will instead go the console).
--no-use-temp-file
Use popen, not a temporary file, to read the output of the preprocessor. This is the default behaviour.
-h
--help
Prints a usage summary.
-V
--version
Prints the version number for windres.
--yydebug
If windres is compiled with "YYDEBUG" defined as 1, this will turn on parser debugging.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
