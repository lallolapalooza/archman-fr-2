NOM

innconfval - Récupérer les paramètres de configuration à partir des fichiers de configuration

SYNTAXE

innconfval [-pstv] [-f fichier] [-F typefichier] [-i fichierconfinn] [paramètre ...]

innconfval -C [-i fichierconfinn]

DESCRIPTION

innconfval affiche normalement les valeurs des paramètres spécifiés sur la ligne de commande, à partir de inn.conf. Par défaut, il affiche simplement les valeurs des paramètres, mais si -p, -s, ou -t sont utilisés, il affiche à la place le paramètre et sa valeur sous la forme d'une affectation de variable en Perl, Bourne shell, ou Tcl respectivement. Si aucun paramètre n'est spécifiquement demandé, innconfval affiche toutes les valeurs des paramètres (ce qui n'est pas particulièrement utile à moins que l'une des options -p, -s, ou -t n'ait été spécifiée).

Tous les paramètres sont tirés de inn.conf à l'exception de version, qui est toujours la chaîne de version d'INN.

Utilisez les options -f et -F pour spécifier un autre fichier de configuration à partir duquel afficher les valeurs des paramètres.

Si l'option -C est utilisée, innconfval vérifie plutôt inn.conf, signalant toute anomalie trouvée sur la sortie d'erreur standard.

OPTIONS

-C
Vérifie inn.conf plutôt que d'afficher les valeurs des paramètres, et quitte avec le statut 0 si aucun problème n'est trouvé et avec le statut 1 sinon.
-f fichier
Utilise fichier comme fichier de configuration source pour le type mentionné dans l'option -F. Si non défini, le fichier de configuration par défaut est utilisé (c'est-à-dire le fichier dans pathetc nommé comme le type fourni avec -F). fichier doit être un fichier de configuration valide de ce type et sera analysé de la même manière que ce type le serait.
-F typefichier
typefichier doit être "inn.conf" (par défaut) ou "inn-secrets.conf". Il définit le type de fichier de configuration à analyser.

Par exemple, exécutez "innconfval -F inn-secrets.conf canlockuser" pour récupérer la valeur canlockuser depuis inn-secrets.conf.

Le chemin par défaut vers le fichier de configuration du type demandé sera utilisé, sauf si -f est donné (ou si un fichier de configuration source spécifique pour inn.conf est défini avec -i et définit un autre emplacement pathetc).

-i fichierconfinn
Utilise fichierconfinn comme fichier de configuration source pour inn.conf plutôt que inn.conf dans pathetc. fichierconfinn doit être un fichier inn.conf valide et sera analysé de la même manière qu’inn.conf le serait.
-p
Affiche les paramètres sous forme d'instructions d'affectation Perl. Le nom de variable sera le même que le paramètre de configuration, et les valeurs de chaîne seront entourées d'apostrophes avec l'échappement approprié. Les valeurs booléennes seront mappées aux chaînes "true" ou "false". Les valeurs de liste seront mappées à un tableau de chaînes. Les valeurs NULL sont affichées avec la valeur "undef".

Voici un exemple :

$enableoverview = 'true';
@extraoverviewadvertised = ( 'Newsgroups', 'Injection-Info' );
@extraoverviewhidden = undef;
$organization = 'Let\'s try nasty "quotes"';
$maxforks = 10;

Si innconfval est appelé via le module Perl "INN::Config", toutes ces variables sont correctement exportées.

-s
Affiche les paramètres sous forme d'instructions d'affectation Bourne shell. Le nom de variable sera le nom du paramètre de configuration en majuscules, et toutes les variables seront exportées, si elles ne sont pas NULL. Les valeurs de chaîne seront entourées d'apostrophes avec l'échappement approprié, et les valeurs booléennes seront mappées à "true" ou "false". Les valeurs de liste seront mappées à une chaîne séparée par des espaces représentant un tableau de chaînes (comme le Bourne shell ne reconnaît pas les tableaux, contrairement à plusieurs autres shells, un tableau ne peut pas être retourné pour des raisons d'interopérabilité).

Voici un exemple :

ENABLEOVERVIEW=true; export ENABLEOVERVIEW;
EXTRAOVERVIEWADVERTISED='"Newsgroups" "Injection-Info"';
    export EXTRAOVERVIEWADVERTISED;
ORGANIZATION='Let'\''s try nasty "quotes"'; export ORGANIZATION;
MAXFORKS=10; export MAXFORKS;
-t
Affiche les paramètres sous forme d'instructions d'affectation Tcl. Le nom de variable sera le même que le nom du paramètre de configuration mais avec "inn_" préfixé, et les variables de chaîne seront correctement échappées. Les valeurs booléennes seront mappées aux chaînes "true" ou "false". Les valeurs de liste seront mappées à un tableau de chaînes. Les valeurs NULL ne sont pas affichées.

Voici un exemple :

set inn_enableoverview "true"
set inn_extraoverviewadvertised { "Newsgroups" "Injection-Info" }
set inn_organization "Let's try nasty \"quotes\""
set inn_maxforks 10
-v
Affiche la version d'INN et quitte. Ceci est équivalent à "innconfval version".
