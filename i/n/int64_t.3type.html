DESCRIPTION

intN_t sont des types entiers signés d'une largeur fixe de exactement N bits, N étant la valeur spécifiée dans le nom de son type. Ils sont capables de stocker des valeurs dans l'intervalle [INTN_MIN, INTN_MAX], en remplaçant N par le nombre approprié.

uintN_t sont des types entiers non signés d'une largeur fixe de exactement N bits, N étant la valeur spécifiée dans le nom de son type. Ils sont capables de stocker des valeurs dans l'intervalle [0, UINTN_MAX], en remplaçant N par le nombre approprié.

Selon POSIX, [u]int8_t, [u]int16_t et [u]int32_t sont requis ; [u]int64_t ne sont requis que dans les implémentations qui fournissent des types entiers de largeur 64 ; et tous les autres types de cette forme sont optionnels.

Les macros [U]INTN_WIDTH se développent à la largeur en bits de ces types (N).

Les macros [U]INTN_MAX se développent à la valeur maximale que ces types peuvent contenir.

Les macros INTN_MIN se développent à la valeur minimale que ces types peuvent contenir.

Les macros [U]INTN_C() développent leur argument en une constante entière de type [u]intN_t.

Les modificateurs de longueur pour les types [u]intN_t pour la famille de fonctions printf(3) sont développés par des macros des formes PRIdN, PRIiN, PRIuN, et PRIxN (définies dans <inttypes.h>) ; résultant par exemple en %"PRId64" ou %"PRIi64" pour l'impression des valeurs int64_t. Les modificateurs de longueur pour les types [u]intN_t pour la famille de fonctions scanf(3) sont développés par des macros des formes SCNdN, SCNiN, SCNuN, et SCNxN, (définies dans <inttypes.h>) ; résultant par exemple en %"SCNu8" ou %"SCNx8" pour la lecture des valeurs uint8_t.

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C99, POSIX.1-2001.

Les macros [U]INTN_WIDTH ont été ajoutées en C23.

NOTES

L'en-tête suivant fournit également ces types : <inttypes.h>. <arpa/inet.h> fournit également uint16_t et uint32_t.
