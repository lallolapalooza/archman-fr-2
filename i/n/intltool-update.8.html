INTLTOOL-UPDATE(8) Manuel de l'administrateur système INTLTOOL-UPDATE(8)

NOM

intltool-update - met à jour le fichier modèle PO et fusionne les traductions avec celui-ci

SYNTAXE

intltool-update [option]...
intltool-update CODE_LANGUE

DESCRIPTION

intltool-update génère de nouveaux modèles de fichiers po à partir du code source, et fusionne les traductions existantes avec ces nouveaux modèles po.

Vous devez changer de répertoire pour vous placer dans le sous-répertoire contenant les traductions (généralement « po/ ») avant d'exécuter intltool-update.

OPTIONS

Lorsque vous exécutez intltool-update, un seul mode de fonctionnement est autorisé à la fois.

Mode de fonctionnement

-p
--pot
Génère uniquement le modèle po (.pot).
-s
--headers
Exécute intltool-extract(8) pour extraire les chaînes de caractères des fichiers de style XML/INI listés dans POTFILES.in, et écrit les chaînes extraites dans des fichiers d'en-tête, afin que les chaînes puissent être reconnues par xgettext(1).
-m
--maintain
Recherche les fichiers omis qui auraient dû être listés dans POTFILES.in ou POTFILES.skip. Une liste de tous ces fichiers est écrite dans un autre fichier appelé « missing ».
-r
--report
Affiche un rapport d'état pour toutes les traductions du logiciel.
-d CODE_LANGUE
--dist CODE_LANGUE
Fusionne CODE_LANGUE.po avec le modèle PO existant.

Autres options

-g NOM
--gettext-package=NOM
Spécifie manuellement le nom du fichier modèle PO, au lieu de le déterminer automatiquement à partir de la source. Utile avec l'option -p/--pot. Cette option a un effet supplémentaire : le nom du répertoire de travail courant n'est plus limité à « po » ou « po-* ».
-o NOMFICHIER
--output-file=NOMFICHIER
Spécifie manuellement le nom du fichier de sortie NOMFICHIER après la fusion de l'ancienne traduction avec le modèle PO. Utile avec l'option -d/--dist ou sans aucune option.
-x
--verbose
Affiche beaucoup d'informations.
--version
Affiche les informations de version.
--help
Affiche l'utilisation et les informations d'aide de base.

EXEMPLES

Crée un nouveau modèle PO à partir du code source, et le nomme foo.pot :

intltool-update --pot --gettext-package=foo

Met à jour le fichier de traduction xy.po en utilisant le modèle po existant appelé « bar.pot », et écrit la sortie dans « xy1.po » :

intltool-update --dist --gettext-package=bar --output-file=xy1.po xy

Crée un nouveau modèle PO et met à jour le fichier de traduction xy.po (xy.po est écrasé par le nouveau contenu) :

intltool-update xy
(équivalent à intltool-update --pot && intltool-update --dist xy)

FICHIERS

po/POTFILES.in
Contient la liste des fichiers source qui contiennent des chaînes de caractères traduisibles, un fichier par ligne.
po/POTFILES.skip
po/POTFILES.ignore (obsolète)
Contient la liste des fichiers source qui doivent être ignorés lors de la recherche de chaînes de caractères traduisibles.
