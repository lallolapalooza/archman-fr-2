INNERNET(8) Outils d'administration système INNERNET(8)

NOM

innernet - page de manuel pour innernet 1.7.1

SYNTAXE

innernet [OPTIONS] [COMMANDE]

DESCRIPTION

Un client pour gérer les interfaces réseau innernet.

Commandes :

install
Installer une nouvelle configuration innernet
show
Énumérer toutes les connexions innernet
up
Monter votre interface locale, et la mettre à jour avec la dernière liste de pairs
fetch
Récupérer et mettre à jour votre interface locale avec la dernière liste de pairs
uninstall
Désinstaller un réseau innernet
down
Descendre l'interface (équivalent à « wg-quick down <interface> »)
add-peer
Ajouter un nouveau pair
rename-peer
Renommer un pair
add-cidr
Ajouter un nouveau CIDR
rename-cidr
Renommer un CIDR
delete-cidr
Supprimer un CIDR
list-cidrs
Lister les CIDRs
disable-peer
Désactiver un pair activé
enable-peer
Activer un pair désactivé
add-association
Ajouter une association entre CIDRs
delete-association
Supprimer une association entre CIDRs
list-associations
Lister les associations existantes entre CIDRs
set-listen-port
Définir le port d'écoute local
override-endpoint
Remplacer votre point d'accès externe que le serveur envoie aux autres pairs
completions
Générer des scripts de complétion de shell
help
Afficher ce message ou l'aide des sous-commandes données

OPTIONS

-v, --verbose...
Sortie verbeuse, utiliser -vv pour une verbosité encore plus grande
-c, --config-dir <RÉPERTOIRE_CONFIG>
[défaut : /etc/innernet]
-d, --data-dir <RÉPERTOIRE_DONNÉES>
[défaut : /var/lib/innernet]
--no-routing
Le routage doit-il être géré par innernet ou par un outil externe comme e.g. babeld
--backend <BACKEND>
Spécifier un backend WireGuard à utiliser. S'il n'est pas défini, innernet sélectionnera automatiquement en fonction de la disponibilité [défaut : kernel] [valeurs possibles : kernel, userspace]
--mtu <MTU>
Spécifier le MTU désiré pour votre interface (défaut : 1280)
-h, --help
Afficher l'aide
-V, --version
Afficher la version
