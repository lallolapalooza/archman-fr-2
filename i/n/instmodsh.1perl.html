NOM

instmodsh - Un shell pour examiner les modules installés

SYNTAXE

instmodsh

DESCRIPTION

Une petite interface à ExtUtils::Installed pour examiner les modules installés, valider vos listes de paquets et même créer une archive tar à partir d'un module installé.

VOIR AUSSI

ExtUtils::Installed
