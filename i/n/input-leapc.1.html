INPUTLEAPC(1) Commandes utilisateur INPUTLEAPC(1)

NOM

input-leapc - Client clavier/souris InputLeap

SYNTAXE

input-leapc [--yscroll <delta>] [--display <affichage>] [--daemon|--no-daemon] [--name <nom-ecran>] [--restart|--no-restart] [--debug <niveau>] <adresse-serveur>

DESCRIPTION

Lance le client InputLeap et se connecte à un composant serveur distant.

OPTIONS

-d, --debug <niveau>
filtre les messages de journalisation dont la priorité est inférieure au niveau spécifié. le niveau peut être : FATAL, ERROR, WARNING, NOTE, INFO, DEBUG, DEBUG1, DEBUG2.
-n, --name <nom-ecran> utilise nom-ecran au lieu du nom d'hôte pour identifier
cet écran dans la configuration.
-1, --no-restart
n'essaie pas de redémarrer en cas d'échec.
--restart
redémarre automatiquement le serveur en cas d'échec. (*)
-l, --log <fichier>
écrit les messages de journalisation dans fichier.
--no-tray
désactive l'icône de la barre d'état système.
--enable-drag-drop
active le glisser-déposer de fichiers.
--enable-crypto
active le plugin crypto (ssl).
--display <affichage>
se connecte au serveur X à l'adresse <affichage>
-f, --no-daemon
s'exécute au premier plan.
--daemon
s'exécute en tant que démon. (*)
--yscroll <delta>
définit le delta de défilement vertical, qui est de 120 par défaut.
-h, --help
affiche cette aide et quitte.
--version
affiche les informations de version et quitte.

Les options par défaut sont marquées d'un *

L'adresse du serveur est de la forme : [<nom-hote>][:<port>]. Le nom d'hôte doit être l'adresse ou le nom d'hôte du serveur. Les crochets autour d'une adresse IPv6 sont requis lorsque le numéro de port est également spécifié et facultatifs sinon. Le numéro de port par défaut est 24800.
