MODE Utiliser MODE pour définir le mode d'exécution du script exec : compat, event : - compat : exécuter le gestionnaire exec uniquement lors d'une mise à jour DDNS réussie, par défaut - event : exécuter le gestionnaire exec pour tout état de mise à jour. Les variables d'environnement suivantes sont définies : INADYN_EVENT, INADYN_ERROR, INADYN_ERROR_MESSAGE. INADYN_EVENT contient l'événement, l'un des suivants : nochg, update, error. L'événement nochg indique qu'aucune mise à jour n'a dû être envoyée, l'événement update indique qu'une mise à jour a été envoyée avec succès, l'événement error indique que la mise à jour a été envoyée et qu'une erreur s'est produite.
