infotocap(1M) Commandes utilisateur infotocap(1M)

NOM

infotocap - convertir une description terminfo en une description termcap

SYNTAXE

infotocap [option-tic] fichier...

infotocap -V

DESCRIPTION

infotocap traduit les descriptions de terminaux. Il recherche dans chaque fichier texte donné les entrées terminfo et, pour chacune trouvée, il écrit une description termcap analogue sur le flux de sortie standard. Les capacités terminfo “use” se traduisent en capacités termcap tc. Comme termcap est un format moins expressif que terminfo, certaines capacités ne peuvent pas être traduites.

Cet utilitaire est implémenté comme un lien vers tic(1M), avec l'option -C de ce dernier implicitement activée. Vous pouvez utiliser d'autres options de tic telles que -1, -f, -v, -w et -x. L'option -V affiche la version de ncurses associée à ce programme et se termine avec un statut de succès.

FICHIERS

/usr/share/terminfo
base de données compilée des descriptions de terminaux

PORTABILITÉ

Ni X/Open Curses, Issue 7 (2009), SVr4, ni NetBSD ne documentent cette application.

AUTEURS

Thomas E. Dickey <dickey@invisible-island.net>

VOIR AUSSI
