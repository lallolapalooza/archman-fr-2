NOM

/etc/incron.conf - fichier de configuration principal pour inotify cron (incron)

DESCRIPTION

Le fichier /etc/incron.conf contient les paramètres par défaut pour le programme incrond. Chaque ligne contient une paire option/valeur sous la forme option = valeur. Les lignes de commentaire doivent commencer par un signe dièse (#) en première position.

Les options de configuration valides sont :

system_table_dir
Ce répertoire est examiné par incrond pour les fichiers de table système. Par défaut : /etc/incron.d
user_table_dir
Ce répertoire est examiné par incrond pour les fichiers de table utilisateur. Par défaut : /var/spool/incron
allowed_users
Ce fichier contient les utilisateurs autorisés à utiliser incron. Par défaut : /etc/incron.allow
denied_users
Ce fichier contient les utilisateurs interdits d'utiliser incron. Par défaut : /etc/incron.deny
lockfile_dir
Ce répertoire est utilisé pour créer un verrou afin d'éviter d'exécuter plusieurs instances d'incrond. Par défaut : /var/run
lockfile_name
Ce nom (suffixé par '.pid') est utilisé pour créer un verrou afin d'éviter d'exécuter plusieurs instances d'incrond. Par défaut : incrond
editor
Ce nom ou chemin est utilisé pour exécuter un éditeur permettant de modifier les tables incron. Par défaut, aucun éditeur n'est donné, l'éditeur système est utilisé ; cette option surcharge ce comportement.
