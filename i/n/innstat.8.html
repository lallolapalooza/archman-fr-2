NOM

innstat - Afficher un instantané du système INN

SYNTAXE

innstat

DESCRIPTION

Le script innstat affiche un instantané du système INN. Il est notamment exécuté par news.daily, qui intègre sa sortie dans les rapports quotidiens d'Usenet.

innstat affiche les informations suivantes :

  • le mode de fonctionnement du serveur, tel que renvoyé par "ctlinnd mode" ;
  • l'utilisation du disque de plusieurs répertoires : patharticles, pathdb, pathetc, pathincoming, pathlog, pathoutgoing, pathoverview, et pathtmp. S'ils sont utilisés, l'utilisation du disque des répertoires patharchive et pathhttp est également signalée ;
  • l'utilisation du tampon d'aperçu, si l'aperçu indexé par tampon est utilisé ;
  • la taille de tous les fichiers batch dans pathoutgoing ;
  • la taille des fichiers journaux errlog, news, news.crit, news.err, et news.notice dans pathlog ;
  • la taille de tous les fichiers de verrouillage dans pathrun ;
  • les connexions ouvertes actuelles des serveurs distants à innd.
