NOM

intltool-prepare - Préparer un logiciel à utiliser intltool

SYNTAXE

intltool-prepare [option] [MOT-CLÉ]...

DESCRIPTION

Pour les paquets logiciels qui incluent un type spécifique de fichiers traduisibles (tels que .desktop et .soundlist), avant qu'ils n'utilisent intltool, les traducteurs doivent les parcourir un par un et ajouter leur localisation dans chaque fichier. Ce processus est sujet aux erreurs, car les traducteurs peuvent inclure des fautes de frappe, ou ajouter leur localisation dans le mauvais encodage. De plus, les traducteurs peuvent ne pas toujours savoir que d'autres fichiers (outre les fichiers .po) sont traduisibles.

intltool évite tous les problèmes ci-dessus en extrayant les chaînes de caractères à l'intérieur de ces fichiers traduisibles dans un fichier po template (.pot). Tout ce dont les traducteurs doivent se soucier est de traduire les fichiers po. Par la suite, intltool-merge(8) fusionnera les chaînes localisées dans ces fichiers.

Avant que votre logiciel ne soit conscient d'intltool, quelques problèmes doivent être résolus, et intltool-prepare essaie de s'en occuper. intltool-prepare va :

•
Extraire toutes les chaînes localisées dans les fichiers de style .desktop (y compris ".desktop", ".soundlist", ".keys" et ".directory") dans les fichiers po correspondants.
•
Convertir les fichiers traduisibles en modèles ne contenant aucune localisation.
•
Ajouter la liste des fichiers modèles ci-dessus dans POTFILES.in.
•
Ajouter la liste des anciens fichiers traduisibles dans .cvsignore (car ils seront générés par intltool plus tard).
•
Ajouter les règles pour générer ces fichiers dans Makefile.am.

NOTE : Vous devez changer le répertoire de travail pour le répertoire source de niveau supérieur avant d'exécuter intltool-prepare.

OPTIONS

MOT-CLÉ est une liste de mots-clés supplémentaires en plus de "Name", "Comment" et "description". intltool-prepare reconnaîtra toute ligne commençant par ces MOT-CLÉ et extraira les chaînes localisées après le signe égal ("=").

-x
--verbose
Être verbeux pour donner un retour d'information supplémentaire à l'utilisateur.
-v
--version
Afficher les informations de version.
-h
--help
Afficher l'utilisation et les informations d'aide de base.
