NOM

intltool-merge - fusionner les chaînes traduites dans divers types de fichiers

SYNTAXE

intltool-merge [option]... RÉPERTOIRE_PO NOM_FICHIER FICHIER_SORTIE

DESCRIPTION

Fusionne les chaînes traduites dans les fichiers po du répertoire RÉPERTOIRE_PO avec le fichier de l'application d'origine NOM_FICHIER, et produit le fichier FICHIER_SORTIE contenant les chaînes originales et localisées.

Si NOM_FICHIER est un fichier XML, FICHIER_SORTIE contiendra des nœuds xml répétés, chaque nœud contenant une des chaînes localisées avec l'attribut "xml:lang".

OPTIONS

Mode de fonctionnement

-b
--ba-style
Fusionne les fichiers dans le style bonobo-activation, utilisé pour les serveurs bonobo.
-d
--desktop-style
Fusionne les fichiers dans le style desktop, similaire au format de fichier .ini de Windows.
-k
--keys-style
Fusionne les fichiers dans le style de clés, utilisé pour les métadonnées.
-o
--oaf-style
(OBSOLÈTE) Identique à -b/--ba-style.
-r
--rfc822deb-style
Fusionne les fichiers dans le style RFC 822, généralement utilisé dans les fichiers de configuration Debian.
--quoted-style
Fusionne les fichiers dans le style de chaînes entre guillemets, qui traduit simplement toutes les chaînes entre guillemets.
-x
--xml-style
Fusionne les fichiers dans le style XML standard, à la fois comme attributs et comme pcdata brut.

Autres options

-u
--utf8
Convertit toutes les chaînes en UTF-8 avant la fusion.
-p
--pass-through
Utilise les chaînes telles quelles dans les fichiers .po sans conversion (FORTEMENT déconseillé avec -x).
-c
--cache
(À DÉFINIR)
-q
--quiet
Être silencieux pendant l'exécution.
-v
--version
Affiche les informations de version.
-h
--help
Affiche l'utilisation et les informations d'aide de base.

FICHIERS

po/.intltool-merge-cache
Fichier cache généré par intltool-merge, contenant toutes les chaînes de tous les fichiers po séparées par \01.
