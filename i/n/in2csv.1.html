NOM

in2csv - Documentation de in2csv

DESCRIPTION

Convertit divers formats de données tabulaires en CSV.

La conversion de largeur fixe nécessite de fournir un fichier de schéma avec l'option « -s ». Le fichier de schéma doit avoir le format suivant :

colonne,début,longueur
nom,0,30
date_naissance,30,10
âge,40,3

La ligne d'en-tête est requise bien que les colonnes puissent être dans n'importe quel ordre :

usage: in2csv [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
              [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
              [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
              [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
              [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
              [-f {csv,dbf,fixed,geojson,json,ndjson,xls,xlsx}] [-s SCHEMA]
              [-k KEY] [-n] [--sheet SHEET] [--write-sheets WRITE_SHEETS]
              [--use-sheet-names] [--reset-dimensions]
              [--encoding-xls ENCODING_XLS] [-y SNIFF_LIMIT] [-I]
              [FICHIER]
Convertit les formats de données tabulaires courants mais moins géniaux en CSV.
arguments positionnels :
  FICHIER               Le fichier CSV à traiter. S'il est omis, acceptera les
                        données d'entrée transmises via STDIN.
arguments optionnels :
  -h, --help            affiche ce message d'aide et quitte
  -f {csv,dbf,fixed,geojson,json,ndjson,xls,xlsx}, --format {csv,dbf,fixed,geojson,json,ndjson,xls,xlsx}
                        Le format du fichier d'entrée. S'il n'est pas spécifié,
                        il sera déduit du type de fichier.
  -s SCHEMA, --schema SCHEMA
                        Spécifiez un fichier de schéma au format CSV pour la
                        conversion de fichiers à largeur fixe. Voir la
                        documentation web.
  -k KEY, --key KEY     Spécifiez une clé de niveau supérieur dans laquelle
                        rechercher une liste d'objets à convertir lors du
                        traitement de JSON.
  -n, --names           Affiche les noms des feuilles du fichier Excel d'entrée.
  --sheet SHEET         Le nom de la feuille Excel à traiter.
  --write-sheets WRITE_SHEETS
                        Les noms des feuilles Excel à écrire dans des fichiers, ou
                        « - » pour écrire toutes les feuilles.
  --use-sheet-names     Utilise les noms des feuilles comme noms de fichiers
                        lorsque --write-sheets est défini.
  --reset-dimensions    Ignore les dimensions de feuille fournies par le fichier
                        XLSX.
  --encoding-xls ENCODING_XLS
                        Spécifie l'encodage du fichier XLS d'entrée.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limite l'inférence de dialecte CSV au nombre d'octets
                        spécifié. Spécifiez « 0 » pour désactiver
                        totalement l'inférence, ou « -1 » pour
                        analyser l'intégralité du fichier.
  -I, --no-inference    Désactive l'inférence de type (et --locale,
                        --date-format, --datetime-format, --no-leading-zeroes)
                        lors de l'analyse de l'entrée CSV.
 Certains indicateurs de ligne de commande ne s'appliquent qu'à des formats
 d'entrée spécifiques.

Voir aussi : Arguments communs à tous les outils.

NOTE :

Le format « ndjson » fait référence à « JSON délimité par des nouvelles lignes », tel qu'utilisé par de nombreuses API de streaming.

NOTE :

Si un XLS semble identique à un XLSX lorsqu'il est vu dans Excel, ils peuvent ne pas être identiques en tant que CSV. Par exemple, XLSX a un type entier, mais XLS n'en a pas. Les nombres qui ressemblent à des entiers provenant d'un XLS auront des décimales dans CSV, mais ceux d'un XLSX n'en auront pas.

NOTE :

Pour convertir à partir de HTML, considérez messytables.

EXEMPLES

Convertir le fichier d'en-têtes géographiques du recensement de 2000 de largeur fixe en CSV et de l'encodage latin-1 en utf8 :

in2csv -e iso-8859-1 -f fixed -s examples/realdata/census_2000/census2000_geo_schema.csv examples/realdata/census_2000/usgeo_excerpt.upl

NOTE :

Une bibliothèque de schémas à largeur fixe est maintenue dans le projet ffs :

https://github.com/wireservice/ffs

Convertir un fichier Excel .xls :

in2csv examples/test.xls

Standardiser le format d'un fichier CSV (guillemets, fins de ligne, etc.) :

in2csv examples/realdata/FY09_EDU_Recipients_by_State.csv

Récupérer les problèmes ouverts de csvkit de l'API GitHub, convertir la réponse JSON en CSV et l'écrire dans un fichier :

curl https://api.github.com/repos/wireservice/csvkit/issues?state=open | in2csv -f json -v

Convertir un fichier DBase DBF en un CSV équivalent :

in2csv examples/testdbf.dbf

Cet outil nomme les en-têtes sans nom. Pour éviter ce comportement, exécutez :

in2csv --no-header-row examples/test.xlsx | tail -n +2

DÉPANNAGE

Si une erreur telle que la suivante se produit lors de la fourniture d'un fichier d'entrée au format CSV ou Excel :

ValueError: Row 0 has 11 values, but Table only has 1 columns.

Alors le fichier d'entrée pourrait avoir des lignes initiales avant les lignes d'en-tête et de données. Vous pouvez ignorer ces lignes avec --skip-lines (-K) :

in2csv --skip-lines 3 examples/test_skip_lines.csv

Si un fichier XLSX produit trop peu de lignes ou trop peu de colonnes, alors l'application qui a créé le fichier pourrait avoir incorrectement défini les dimensions de la feuille de calcul. Essayez à nouveau avec l'option --reset-dimensions.
