DESCRIPTIO

N

innreport est un script Perl qui résume les fichiers de journalisation INN, avec sortie HTML et graphiques optionnels. Il est normalement invoqué par scanlogs(8) qui inclut la sortie de innreport dans les rapports Usenet

quotidiens.

Les programmes pris en charge sont batcher, cnfsstat, controlchan, innd, innfeed, innxbatch, innxmit, nnrpd, nntplink (un programme externe), overchan, perl-nocem et rnews

.

innreport met également à jour le décompte des groupes de discussion non diffusés localement par le serveur de news, et pour lesquels des articles ont été reçus, dans le fichier de journalisation unwanted.log. Si cette mise à jour ne doit pas être effectuée, car elle ne devrait survenir qu'une fois par jour lors de l'analyse des journaux quotidiens, l'indicateur -notdaily devrait être donné à innreport

.

Si vous voulez que innreport génère des graphiques dans ses rapports HTML, vous avez besoin de la bibliothèque graphique Perl GD.p

m.

Au moins un fichier journal non vide à analyser devrait être donné à la fin de la ligne de commande invoquant innre

por
t.

OPTION

S

Seule une option est obligatoire

:
-f fichier-de-co
nfig
Chemin complet vers le fichier de configuration. Il est généralement innreport.conf dans pathetc, mais il n'y a pas de valeur par défaut. Ce fichier liste les options à utiliser pour le rapport. Les options données en ligne de commande lors de l'appel de innreport priment sur celles du
fichier de
configuration.

Les autres options sont facultatives. Préfixer "no" devant des options booléennes permet de les désactiver. Par exemple, utilisez -nograph pour supprimer la fonctionnalité -graph

.
-archive ou -
a
Définit si les pages HTML et les graphiques doivent être archivés si les rapports HTML sont activés. Lorsque cette option est définie, ce qui est le défaut, une date sera ajoutée au nom de fichier de chaque rapport et de chaque graphique. Sinon, seul le dernier rapport HTML est
conservé.
-casesensiti
ve
Indique s'il faut effectuer des recherches sensibles à la casse dans les journaux de news pour des motifs prédéfinis. Cette option est activée par
défaut.
-conf
ig
Affiche sur la sortie standard les informations de configuration pour innreport, et se
termine.
-cycle ou -c num-cyc
le
Définit combien de fichiers de rapport doivent être conservés si les rapports HTML sont activés et archivés. La valeur par défaut est 0, ce qui signifie que toutes les archives sont
conservées.
-dir ou -d http-d
ir
Définit le répertoire pour les pages web si les rapports HTML sont activés. La valeur par défaut est la valeur de pathhttp telle que définie dans inn.co
nf.
-graph ou -
g
Si la bibliothèque graphique Perl GD.pm est installée et que les rapports HTML sont activés, des graphiques sont également générés en PNG si pris en charge par "GD", ce qui est le cas dans les versions modernes (sinon, du GIF sera généré). La valeur par défaut est d'activer la génération de
graphiques.
-help ou -
h
Affiche sur la sortie standard un message d'aide avec toutes les options reconnues par innreport, et se
termine.
-ht
ml
En plus du rapport en texte brut imprimé sur la sortie standard, innreport génère des rapports HTML si cette option est activée. Cette option est désactivée par défaut (c'est-à-dire que -nohtml est la valeur par défaut)
.
-html-unkno
wn
Indique s'il faut signaler les entrées inconnues des journaux de news dans les rapports HTML, lorsqu'activé. Cette option prend par défaut la même valeur que celle pour les rapports en texte brut (telle que définie avec l'option unknow
n).
-index ou -
i
Définit le nom de la page d'index web si les rapports HTML sont activés. La valeur par défaut est "index.ht
ml".
-maxunrec num-lign
es
Combien d'entrées non reconnues des journaux de news signaler, lorsque les options -unknown ou -html-unknown sont définies. La valeur par défaut est 50. Utiliser "-1" signifie qu'il n'y a pas de
limite.
-notdai
ly
Indique s'il faut reporter les actions quotidiennes pour cette exécution de innreport. Certaines actions ne doivent être effectuées qu'une fois par jour pour un fichier journal (notamment unwanted.log). Cette option est désactivée par défaut, ce qui signifie que toutes les actions sont toujours effectuées, car nous supposons une configuration par défaut d'exécution de scanlogs quotidie
nnement.
-path ou -p répertoire-ima
ges
Définit le répertoire pour les images si les rapports HTML sont activés, et que des graphiques sont souhaités. La valeur par défaut est pathhttp/pics.

Si à la fois -dir et -webpath sont utilisés, et que -path ne l'est pas, le répertoire utilisé pour les images par défaut est http-dir tel que défini avec -dir/pictures-path tel que défini avec -webpath

.
-separator ou -s ch
ar
Définit le séparateur entre les heures, les minutes et les secondes dans les noms de fichiers si les rapports HTML sont activés et archivés. La valeur par défaut est "." car ":" peut ne pas être correctement lu par tous les navigateurs web. Faites attention à ne pas utiliser "/" comme séparateur, et à n'utiliser qu'un caractère de nom de fichier
valide.
-unkno
wn
Indique s'il faut signaler les entrées inconnues des journaux de news dans les rapports en texte brut. Cette option est activée par
défaut.
-
v
Affiche sur la sortie standard le numéro de version de innreport, et se
termine.
-webpath ou -w chemin-imag
es
Définit le chemin web pour les images dans les pages HTML si les rapports HTML sont activés, et que des graphiques sont souhaités. La valeur par défaut est "pics". Il peut s'agir d'un chemin relatif ou d'un chemin absolu. Si un chemin absolu est utilisé, vous devez définir -path de manière approprié
e ; sinon, il n
e sera pas calcu
lé correctement.
