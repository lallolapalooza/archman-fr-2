NOM

incr - Incrémente la valeur d'une variable

SYNOPSIS

incr nomVariable ?incrément?

DESCRIPTION

Incrémente la valeur stockée dans la variable dont le nom est nomVariable. La valeur de la variable doit être un entier. Si incrément est fourni, sa valeur (qui doit être un entier) est ajoutée à la valeur de la variable nomVariable ; sinon, 1 est ajouté à nomVariable. La nouvelle valeur est stockée sous forme de chaîne décimale dans la variable nomVariable et est également retournée comme résultat.

À partir de la version Tcl 8.5, la variable nomVariable transmise à incr peut être non définie, et dans ce cas, elle sera définie à la valeur incrément ou à la valeur d'incrément par défaut de 1.

EXEMPLES

Ajouter un à contenu de la variable x :

incr x

Ajouter 42 au contenu de la variable x :

incr x 42

Ajouter le contenu de la variable y au contenu de la variable x :

incr x $y

Ne rien ajouter du tout à la variable x (souvent utile pour vérifier si un argument d'une procédure est effectivement intégral et générer une erreur si ce n'est pas le cas) :

incr x 0
