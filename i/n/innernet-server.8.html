NOM

innernet-server - page de manuel pour innernet-server 1.7.1

SYNOPSIS

innernet-server [OPTIONS] <COMMANDE>

DESCRIPTION

Un serveur pour coordonner les réseaux innernet.

Commandes :

new
Créer un nouveau réseau
uninstall
Désinstaller définitivement un réseau créé, le rendant inutilisable. À utiliser avec précaution
serve
Servir le serveur de coordination pour un réseau existant
add-peer
Ajouter un pair à un réseau existant
disable-peer
Désactiver un pair activé
enable-peer
Activer un pair désactivé
rename-peer
Renommer un pair existant
add-cidr
Ajouter un nouveau CIDR à un réseau existant
rename-cidr
Renommer un CIDR existant
delete-cidr
Supprimer un CIDR
completions
Générer des scripts de complétion de shell
help
Afficher ce message ou l'aide de la ou des sous-commandes données

OPTIONS

-c, --config-dir <REPERTOIRE_CONFIG>
[défaut : /etc/innernet-server]
-d, --data-dir <REPERTOIRE_DONNEES>
[défaut : /var/lib/innernet-server]
--no-routing
Si le routage doit être effectué par innernet ou par un outil externe tel que babeld
--backend <BACKEND>
Spécifier un backend WireGuard à utiliser. S'il n'est pas défini, innernet sélectionnera automatiquement en fonction de la disponibilité [défaut : kernel] [valeurs possibles : kernel, userspace]
--mtu <MTU>
Spécifier le MTU désiré pour votre interface (défaut : 1280)
-h, --help
Afficher l'aide
-V, --version
Afficher la version
