NOM

insmod - Programme simple pour insérer un module dans le noyau Linux

SYNTAXE

insmod [OPTIONS] [fichier] [options du module]

DESCRIPTION

insmod est un programme trivial pour insérer un module dans le noyau. La plupart des utilisateurs préféreront utiliser modprobe(8) à la place, qui est plus intelligent et peut gérer les dépendances des modules.

Seuls les messages d'erreur les plus généraux sont rapportés : comme le travail de liaison du module est maintenant effectué à l'intérieur du noyau, dmesg(1) donne généralement plus d'informations sur les erreurs.

OPTIONS

-f, --force

Cette option peut être extrêmement dangereuse : elle demande au noyau d'ignorer les champs de version du module et de vermagic lors du chargement. Avec cette option, vous pouvez charger des modules compilés localement ou par des tiers, bien que cela puisse entraîner une corruption de la mémoire, des plantages système et une perte de données.

-s, --syslog

Envoie les erreurs à syslog au lieu de la sortie standard d'erreur.

-v, --verbose

Affiche des messages sur ce que fait le programme. Habituellement, insmod n'affiche de messages que si quelque chose se passe mal.

-V, --version

Affiche la version du programme et quitte.

-h, --help

Affiche le message d'aide et quitte.

Veuillez adresser tout rapport de bogue à l'outil de suivi de kmod à https://github.com/kmod-project/kmod/issues/ ainsi que la version utilisée, les étapes pour reproduire le problème et le résultat attendu.
