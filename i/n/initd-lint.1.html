NOM

initd-lint - Un vérificateur de fichiers d'initialisation openrc fournis avec Alpine Linux

SYNTAXE

initd-lint <initd...>

DESCRIPTION

initd-lint est un vérificateur pour les fichiers d'initialisation openrc fournis avec Alpine Linux. Voir alint(5) sous la section initd-lint pour une explication de chaque violation que initd-lint vérifie.

initd-lint affichera les violations de politique trouvées et se terminera avec un code de sortie 1. Si aucune violation n'est trouvée, rien ne sera affiché et il se terminera avec un code de sortie 0.

SORTIE

initd-lint affichera sur la sortie standard chaque fois qu'une violation de politique est trouvée, dans le format suivant :

SEVERITECERTITUDE:[TAG]:CHEMIN::MSG
  • SEVERITE fait référence à la gravité d'une violation, allant de S à M.
  • CERTITUDE fait référence à la probabilité que ce ne soit pas un faux positif, allant de C à P.
  • TAG fait référence à l'étiquette de la violation, voir alint(5) pour plus de détails.
  • CHEMIN fait référence au chemin fourni à apkbuild-lint pour vérification.
  • MSG est un court message destiné aux humains pour indiquer quelle est la violation.
