NOM

sockaddr, sockaddr_storage, sockaddr_in, sockaddr_in6, sockaddr_un, socklen_t, in_addr, in6_addr, in_addr_t, in_port_t, - adresse de socket

Bibliothèque C standard (libc)

SYNTAXE

struct sockaddr {
    sa_family_t     sa_family;      /* Famille d'adresses */
    char            sa_data[];      /* Adresse de socket */
};

    sa_family_t     ss_family;      /* Famille d'adresses */
};
typedef /* ... */ socklen_t;
typedef /* ... */ sa_family_t;

Sockets du domaine Internet

#include <netinet/in.h>
struct sockaddr_in {
    sa_family_t     sin_family;     /* AF_INET */
    in_port_t       sin_port;       /* Numéro de port */
    struct in_addr  sin_addr;       /* Adresse IPv4 */
};
struct sockaddr_in6 {
    sa_family_t     sin6_family;    /* AF_INET6 */
    in_port_t       sin6_port;      /* Numéro de port */
    uint32_t        sin6_flowinfo;  /* Informations de flux IPv6 */
    struct in6_addr sin6_addr;      /* Adresse IPv6 */
    uint32_t        sin6_scope_id;  /* Ensemble d'interfaces pour une portée */
};
struct in_addr {
    in_addr_t s_addr;
};
struct in6_addr {
    uint8_t   s6_addr[16];
};
typedef uint32_t in_addr_t;
typedef uint16_t in_port_t;

Sockets du domaine UNIX

#include <sys/un.h>
struct sockaddr_un {
    sa_family_t     sun_family;     /* Famille d'adresses */
    char            sun_path[];     /* Chemin du socket */
};

DESCRIPTION

sockaddr
Décrit une adresse de socket.
sockaddr_storage
Une structure au moins aussi grande que toute autre structure d'adresse sockaddr_*. Elle est alignée de telle sorte qu'un pointeur vers elle puisse être converti en pointeur vers d'autres structures sockaddr_* et utilisé pour accéder à ses champs.
socklen_t
Décrit la longueur d'une adresse de socket. Il s'agit d'un type entier d'au moins 32 bits.
sa_family_t
Décrit la famille de protocoles d'un socket. Il s'agit d'un type entier non signé.

Sockets du domaine Internet

sockaddr_in
Décrit une adresse de socket du domaine Internet IPv4. Les membres sin_port et sin_addr sont stockés en ordre d'octets réseau.
sockaddr_in6
Décrit une adresse de socket du domaine Internet IPv6. Le tableau sin6_addr.s6_addr est utilisé pour contenir une adresse IPv6 de 128 bits, stockée en ordre d'octets réseau.

Sockets du domaine UNIX

sockaddr_un
Décrit une adresse de socket UNIX.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

socklen_t a été inventé par POSIX. Voir aussi accept(2).

Ces structures ont été inventées avant les règles strictes d'alias de l'ISO C moderne. Si les règles d'alias sont appliquées strictement, ces structures seraient extrêmement difficiles à utiliser sans invoquer un comportement indéfini. POSIX.1-2024 a corrigé cela en exigeant que les implémentations garantissent que ces structures puissent être utilisées en toute sécurité comme elles ont été conçues.

NOTES

socklen_t est également défini dans <netdb.h>.

sa_family_t est également défini dans <netinet/in.h> et <sys/un.h>.
