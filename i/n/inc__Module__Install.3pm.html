NOM

inc::Module::Install - Système de configuration de Module::Install

SYNOPSIS

use inc::Module::Install;

DESCRIPTION

Ce module vérifie d'abord si le répertoire inc/.author existe, et supprime tout le répertoire inc/ s'il le fait, de sorte que l'auteur du module obtienne toujours un inc frais à chaque fois qu'il exécute Makefile.PL. Ensuite, il ajoute "inc" à @INC, puis charge Module::Install à partir de là.

Ci-dessous une explication de la raison d'utiliser un module chargeur :

L'implémentation originale de CPAN::MakeMaker introduit des problèmes subtils pour les distributions se terminant par "CPAN" (par exemple, CPAN.pm, WAIT::Format::CPAN), car son placement dans ./CPAN/ duplique les vraies bibliothèques qui seront installées ; de plus, le nom de répertoire ./CPAN/ peut confondre les utilisateurs.

D'un autre côté, placer des bibliothèques incluses, uniquement pour le temps de construction, dans ./inc/ est une pratique normale, et il y a peu de chances qu'une distribution CPAN soit appelée "Something::inc", donc c'est beaucoup plus sûr à utiliser.

De plus, cela permet à d'autres modules d'aide comme Module::AutoInstall de résider également dans inc/, et de les utiliser.
