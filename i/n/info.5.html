INFO(5) Format de Fichier Manuel INFO(5)

NOM

info - documentation lisible en ligne

DESCRIPTION

Le format de fichier Info est une représentation facilement analysable pour les documents en ligne. Il peut être lu par emacs(1) et info(1) entre autres programmes.

Les fichiers Info sont généralement créés à partir de sources texinfo(5) par makeinfo(1) , mais peuvent être créés à partir de zéro si désiré.

Pour une description complète du langage Texinfo et des outils associés, veuillez consulter le manuel Texinfo (écrit en Texinfo lui-même). Le plus probablement, en exécutant cette commande depuis votre shell :

info texinfo
ou cette séquence de touches depuis Emacs : 
M-x info RET m texinfo RET
vous y mènera.

DISPONIBILITÉ

https://www.gnu.org/software/texinfo/

RAPPORT DE BOGUES

Veuillez envoyer les rapports de bogues à bug-texinfo@gnu.org, les questions générales et les discussions à help-texinfo@gnu.org.
