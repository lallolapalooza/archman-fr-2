NOM

infinoted - serveur dédié pour le protocole infinote (par ex. Gobby)

SYNTAXE

infinoted-0.7 [options]

DESCRIPTION

infinoted est un serveur dédié qui permet aux clients de modifier collaborativement des documents texte brut et des fichiers source sur un réseau. Les modifications apportées aux documents sont synchronisées instantanément avec les autres clients.

Ce serveur supporte le protocole infinote tel qu'implémenté par libinfinity. Les clients exemples incluent Gobby 0.5.x, Kobby et un plugin spécial pour gedit. Il n'est pas compatible avec l'ancien protocole libobby.

Il est fourni avec une liste de plugins comme autosave, l'intégration dbus et d'autres. Pour une liste complète, voir https://github.com/gobby/gobby/wiki/Dedicated%20Server. Le plugin par défaut est note-text. Il doit être ajouté avec tous les autres plugins que l'on pourrait vouloir activer.

OPTIONS

Options d'aide :

-h, --help
Afficher les options d'aide

Options d'application :

-c, --config-file=FICHIER-CONFIG
Charger le fichier de configuration donné au lieu de chercher dans les emplacements standard.
-k, --key-file=FICHIER-CLE
La clé privée du serveur
-c, --certificate-file=FICHIER-CERTIFICAT
Le certificat du serveur
--certificate-chain
La chaîne de certificats jusqu'au certificat racine, si elle n'est pas incluse dans le fichier spécifié par --certificate-file.
--create-key
Crée une nouvelle clé privée aléatoire
--create-certificate
Crée un nouveau certificat auto-signé en utilisant la clé donnée
-p, --port-number=PORT
Le numéro de port sur lequel écouter
--listen-address=ADRESSE
L'adresse IP sur laquelle écouter
--security-policy=no-tls|allow-tls|require-tls
Comment décider d'utiliser TLS
-r, --root-directory=REPERTOIRE
Un répertoire pour enregistrer l'arborescence des documents au format infinoted-xml. C'est l'emplacement où l'arborescence est conservée de manière persistante afin qu'elle soit à nouveau disponible après le redémarrage du serveur. Habituellement, les documents sont enregistrés dans cet arbre 60 secondes après le départ du dernier utilisateur de la session. En plus de cela, lorsque le plugin autosave est activé, il est possible de sauvegarder les sessions dans l'arbre périodiquement. Le répertoire par défaut est ~/.infinote.
--plugins=PLUGIN
Plugin supplémentaire à charger. Répétez l'option sur la ligne de commande pour spécifier plusieurs plugins et des points-virgules dans le fichier de configuration. Les options des plugins peuvent être configurées dans le fichier de configuration (une section pour chaque plugin), ou avec l'option --plugin-parameter.
--plugin-parameter=PLUGIN:CLE:VALEUR
Définit l'option CLE du plugin PLUGIN à la VALEUR donnée. Normalement, les options des plugins sont spécifiées dans le fichier de configuration, mais cette option en ligne de commande permet de définir ou de remplacer les options des plugins en ligne de commande.
-P, --password=MOTDEPASSE
Exiger le mot de passe donné lors des connexions
--pam-service=SERVICE
Authentifier les clients par rapport au service pam donné lors de la connexion
--pam-allow-user=UTILISATEURS
Utilisateurs autorisés à se connecter après authentification pam. Séparer les entrées par des points-virgules.
--pam-allow-group=GROUPES
Groupes autorisés à se connecter après authentification pam. Séparer les entrées par des points-virgules.
-d, --daemonize
Démoniser le serveur
-D, --kill-daemon
Tuer un démon en cours d'exécution
-v, --version
Afficher les informations de version et quitter
