inotify_init(2) Manuel des appels système inotify_init(2)

NOM

inotify_init, inotify_init1 - initialiser une instance inotify

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/inotify.h>
int inotify_init(void);
int inotify_init1(int flags);

DESCRIPTION

Pour un aperçu de l'API inotify, voir inotify(7).

inotify_init() initialise une nouvelle instance inotify et renvoie un descripteur de fichier associé à une nouvelle file d'attente d'événements inotify.

Si flags est 0, alors inotify_init1() est identique à inotify_init(). Les valeurs suivantes peuvent être combinées par un OU au niveau du bit dans flags pour obtenir un comportement différent :

IN_NONBLOCK
Définit l'indicateur d'état de fichier O_NONBLOCK sur la description de fichier ouverte (voir open(2)) référencée par le nouveau descripteur de fichier. L'utilisation de cet indicateur évite des appels supplémentaires à fcntl(2) pour obtenir le même résultat.
IN_CLOEXEC
Définit l'indicateur de fermeture lors de l'exécution (FD_CLOEXEC) sur le nouveau descripteur de fichier. Voir la description de l'indicateur O_CLOEXEC dans open(2) pour les raisons pour lesquelles cela peut être utile.

VALEUR DE RETOUR

En cas de succès, ces appels système renvoient un nouveau descripteur de fichier. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
(inotify_init1()) Une valeur invalide a été spécifiée dans flags.
EMFILE
La limite de l'utilisateur sur le nombre total d'instances inotify a été atteinte.
EMFILE
La limite par processus sur le nombre de descripteurs de fichiers ouverts a été atteinte.
ENFILE
La limite globale du système sur le nombre total de fichiers ouverts a été atteinte.
ENOMEM
Mémoire noyau insuffisante disponible.

NORMES

Linux.

HISTORIQUE

inotify_init()
Linux 2.6.13, glibc 2.4.
inotify_init1()
Linux 2.6.27, glibc 2.9.

VOIR AUSSI

inotify_add_watch(2), inotify_rm_watch(2), inotify(7)
