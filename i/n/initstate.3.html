random(3) Manuel des fonctions de bibliothèque random(3)

NOM

random, srandom, initstate, setstate - générateur de nombres aléatoires

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
long random(void);
void srandom(unsigned int seed);
char *initstate(size_t n;
                unsigned int seed, char state[n], size_t n);
char *setstate(char *state);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

random(), srandom(), initstate(), setstate():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

La fonction random() utilise un générateur de nombres aléatoires à rétroaction additive non linéaire employant une table par défaut de 31 entiers longs pour retourner des nombres pseudo-aléatoires successifs dans l'intervalle de 0 à 2^31 - 1. La période de ce générateur de nombres aléatoires est très grande, approximativement 16 * ((2^31) - 1).

La fonction srandom() utilise son argument comme germe pour une nouvelle séquence d'entiers pseudo-aléatoires à retourner par random(). Ces séquences sont répétables en appelant srandom() avec la même valeur de germe. Si aucune valeur de germe n'est fournie, la fonction random() est automatiquement ensemencée avec la valeur 1.

La fonction initstate() permet d'initialiser un tableau d'état state pour être utilisé par random(). La taille du tableau d'état n est utilisée par initstate() pour décider quel générateur de nombres aléatoires utiliser — plus le tableau d'état est grand, meilleurs seront les nombres aléatoires. Les valeurs actuelles "optimales" pour la taille du tableau d'état n sont de 8, 32, 64, 128 et 256 octets ; d'autres quantités seront arrondies à la baisse au montant connu le plus proche. L'utilisation de moins de 8 octets entraîne une erreur. seed est le germe pour l'initialisation, qui spécifie un point de départ pour la séquence de nombres aléatoires et permet de redémarrer au même point.

La fonction setstate() change le tableau d'état utilisé par la fonction random(). Le tableau d'état state est utilisé pour la génération de nombres aléatoires jusqu'au prochain appel à initstate() ou setstate(). state doit avoir été préalablement initialisé à l'aide de initstate() ou être le résultat d'un appel précédent à setstate().

VALEUR DE RETOUR

La fonction random() retourne une valeur comprise entre 0 et (2^31) - 1. La fonction srandom() ne retourne aucune valeur.

La fonction initstate() retourne un pointeur vers le tableau d'état précédent. En cas d'échec, elle retourne NULL et errno est défini pour indiquer l'erreur.

En cas de succès, setstate() retourne un pointeur vers le tableau d'état précédent. En cas d'échec, elle retourne NULL et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
L'argument state donné à setstate() était NULL.
EINVAL
Un tableau d'état de moins de 8 octets a été spécifié à initstate().

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, 4.3BSD.

NOTES

La génération de nombres aléatoires est un sujet complexe. Numerical Recipes in C: The Art of Scientific Computing (William H. Press, Brian P. Flannery, Saul A. Teukolsky, William T. Vetterling ; New York : Cambridge University Press, 2007, 3e éd.) fournit une excellente discussion sur les problèmes pratiques de génération de nombres aléatoires dans le chapitre 7 (Random Numbers).

Pour une discussion plus théorique qui couvre également de nombreux aspects pratiques en profondeur, voir le chapitre 3 (Random Numbers) de The Art of Computer Programming, volume 2 (Seminumerical Algorithms), 2e éd. ; Reading, Massachusetts : Addison-Wesley Publishing Company, 1981, par Donald E. Knuth.

MISE EN GARDE

La fonction random() ne doit pas être utilisée dans les programmes multithreadés où un comportement reproductible est requis. Utilisez random_r(3) à cette fin.

BOGUES

Selon POSIX, initstate() devrait retourner NULL en cas d'erreur. Dans l'implémentation glibc, errno est (comme spécifié) défini en cas d'erreur, mais la fonction ne retourne pas NULL.

VOIR AUSSI
