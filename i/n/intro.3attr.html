NOM

intro - attributs C/C++

SYNTAXE

[[attr]]
[[vendor::attr]]

DESCRIPTION

Les attributs modifient les propriétés d'un élément source, tel qu'un type, une variable ou une fonction.

La syntaxe standard permet de spécifier un *vendor* pour les attributs non standard.

VERSIONS

Les dialectes C et C++ ont fourni diverses formes d'attributs avant la standardisation.

__attribute__((attr))
Ceci est la syntaxe GNU pour les attributs. Elle est supportée par GCC et Clang.
__declspec(attr)
Ceci est la syntaxe MSVC pour les attributs. Elle est supportée par Clang.

NORMES

C23, C++23.

HISTORIQUE

[[attr]]
[[vendor::attr]]
C23, C++11.
[[attr]]
[[gnu::attr]]
gcc 10, g++ 9, clang 9, clang++ 9.
__attribute__((attr))
gcc, g++, clang, clang++.
__declspec(attr)
clang, clang++.
