DESCRIPTIO

N

Le fichier pathetc/innreport.conf permet de configurer le comportement de innreport. Il se compose d'une série de lignes ; les lignes vides et ce qui suit un signe dièse ("#") dans une ligne sont ignorés. La structure de ce fichier est

: 
section default {
    libpath             "/chemin/vers/les/bibliothèques";
    logpath             "/chemin/vers/les/journaux";
    module              "innreport_inn";
    display_conf_file   "innreport-display.conf";
    unwanted_log        "unwanted.log";
    text                true;
    html                true;  # Activer les rapports HTML.
    # Autres options à définir.
}
;

Seule cette section default a besoin d'être configurée. Elle commence avec "section default {" et se termine par "};". Chaque ligne de la section se compose d'un nom d'option suivi d'un ou plusieurs espaces ou tabulations, de sa valeur et d'un point-virgule ";"

.

L'option display_conf_file définit le nom du fichier de configuration d'affichage à utiliser. Ce fichier, situé dans libpath, a la même syntaxe que innreport.conf. Si vous souhaitez utiliser une configuration d'affichage personnalisée, renommez simplement le fichier par défaut innreport-display.conf sous un autre nom, et définissez-le dans display_conf_file (sinon, innreport-display.conf sera écrasé à chaque mise à jour d'INN)

.

Les sections définies dans le fichier de configuration d'affichage sont utilisées pour paramétrer l'affichage, la manière et le contenu des rapports, mais ne devraient normalement pas être modifiées (à moins que vous ne sachiez précisément ce que vous faites). Ces sections sont écrites dans un langage spécifique au domaine qui n'est pas destiné à être modifié (vous pourriez casser les rapports, surtout en modifiant les paramètres data, double, format, primary, sort, total ou value ). Les paramètres les plus faciles à modifier, si nécessaire, seraient

:
  • title (les titres des sections dans innrepo
    • rt),
  • name (les noms des colonnes)
    • ,
  • color (la couleur des courbes dans les graphiques)
    • ,
  • numbering (une valeur booléenne pour configurer si chaque ligne des rapports HTML est préfixée par un numéro de rang)
    • ,
  • text, html, et skip (valeurs booléennes pour configurer si une section donnée doit être présente respectivement dans les rapports texte, HTML ou les deux)
    • ,
  • top (le nombre maximal de valeurs à afficher) ; vous pouvez spécifier des valeurs différentes pour les rapports texte et HTML avec top_text et top_
    • h
tm
l.

Il s'agit d'une option obligatoire sans valeur par défaut. Elle sert à deux fins : générer des rapports HTML en plus du rapport en texte brut imprimé sur la sortie standard, et configurer dans les sections autres que default (dans le fichier de configuration d'affichage) si une section du rapport doit être présente dans la sortie HTML.

Si elle est définie à "true", et que le drapeau -nohtml n'est pas donné lors de l'appel de innreport, des rapports HTML seront générés. Ces rapports ne contiendront pas les sections ayant individuellement html défini à "false" dans le fichier de configuration d'affichage (par défaut, tout est présent dans les rapports HTML). Sinon, si le drapeau -nohtml est donné, aucun rapport HTML ne sera

généré.

Si elle est définie à "false", et que le drapeau -html n'est pas donné lors de l'appel de innreport, aucun rapport HTML ne sera généré. Sinon, si le drapeau -html est donné, des rapports HTML seront générés mais seules les sections ayant individuellement html défini à "true" dans le fichier de configuration
