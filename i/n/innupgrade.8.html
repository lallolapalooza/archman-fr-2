NOM

innupgrade - Met à jour les fichiers de configuration INN

SYNTAXE

innupgrade répertoire

innupgrade [-t type] -f fichier

DESCRIPTION

innupgrade est destiné à être exécuté lors d'une mise à jour majeure d'INN pour corriger les fichiers de configuration avec les modifications nécessaires. S'il reçoit un répertoire, il parcourt ce répertoire à la recherche de fichiers pour lesquels des mises à jour sont définies, tente d'appliquer ces mises à jour et remplace les fichiers par les versions mises à jour si l'application des mises à jour a entraîné des changements. Les anciennes versions des fichiers seront sauvegardées avec l'extension ".OLD".

Si l'option -f est utilisée, seul ce fichier sera mis à jour. Si le nom du fichier ne correspond pas au nom de fichier standard d'un fichier de configuration INN, l'option facultative -t peut être donnée pour spécifier le type. Voir "EXEMPLES" pour un exemple.

Actuellement, innupgrade sait appliquer les mises à jour suivantes :

incoming.conf
  • Renomme nolist et noresendid en respectivement list et resendid. Inverse les valeurs booléennes associées (depuis INN 2.7).
  • Commente les paramètres comment et email supprimés (depuis INN 2.7).
inn.conf
  • Met entre guillemets les valeurs contenant des espaces et commente les clés sans valeur, nécessaire pour le changement des analyseurs de configuration introduit dans INN 2.4. Le nouveau format n'est pas rétrocompatible avec le parseur précédent, car le parseur précédent inclura les guillemets doubles dans la valeur du paramètre.
  • Ajoute le paramètre hismethod s'il n'est pas trouvé (introduit dans INN 2.4, avec la valeur par défaut "hisv6").
  • Renomme nntpactsync en incominglogfrequency (depuis INN 2.5). Renomme addnntppostingdate et addnntppostinghost en respectivement addinjectiondate et addinjectionpostinghost (depuis INN 2.6).
  • Supprime les paramètres refusecybercancels et verifycancels (depuis INN 2.7).
  • Si le fichier overview.fmt existe, son contenu est fusionné dans les paramètres extraoverviewadvertised et extraoverviewhidden introduits dans INN 2.5. Le fichier est ensuite renommé en overview.fmt.OLD.
  • Si le fichier sasl.conf existe, son contenu est fusionné dans les paramètres tlscapath, tlscafile, tlscertfile et tlskeyfile introduits dans INN 2.5. Le fichier est ensuite renommé en sasl.conf.OLD.
inn-secrets.conf
•
Crée un fichier inn-secrets.conf non lisible par tous dans pathetc, s'il n'existe pas déjà (nouveau dans INN 2.7).
newsfeeds
  • Remplace l'utilisation de startinnfeed par l'invocation directe appropriée de innfeed ou imapfeed (startinnfeed a été supprimé dans INN 2.5).
  • Remplace l'utilisation de filechan par buffchan en mode non bufferisé (filechan a été supprimé dans INN 2.7).
readers.conf
•
Renomme require_ssl en require_encryption (depuis INN 2.7).

Quelques programmes ou fichiers de configuration obsolètes sont renommés avec une extension ".OLD" par innupgrade. Les pages de manuel obsolètes sont directement supprimées.

Normalement, innupgrade doit être exécuté au moins sur le répertoire pathetc après toute mise à niveau d'INN autre qu'une mise à jour mineure (toute mise à niveau qui modifie le premier ou le deuxième numéro de version). Cela peut se produire automatiquement pendant le processus de mise à niveau.

OPTIONS

-f fichier
Agit uniquement sur fichier plutôt que de traiter un répertoire entier.
-t type
Pour un fichier spécifié avec -f, analyse et met à jour comme s'il était nommé type. Utilisé pour mettre à jour des fichiers ayant la même syntaxe que les fichiers de configuration INN normaux mais avec des noms différents. N'a de sens qu'en combinaison avec -f.

EXEMPLES

Met à jour tous les fichiers de configuration trouvés dans pathetc et ajoute une extension ".OLD" aux fichiers obsolètes dans pathetc :

innupgrade <chemin vers etc d'inn.conf>

Met à jour uniquement /news/etc/inn.conf :

innupgrade -f /news/etc/inn.conf

Met à jour un fichier nommé inn-special.conf qui devrait avoir la même syntaxe que inn.conf :

innupgrade -t inn.conf -f inn-special.conf

Toutes les règles de mise à jour qui s'appliquent à inn.conf seront appliquées au fichier alternatif.
