INFO(1) Commandes utilisateur INFO(1)

NOM

info - lire les documents Info

SYNTAXE

info [OPTION]... [ELEMENT-MENU...]

DESCRIPTION

Lire la documentation au format Info.

Options fréquemment utilisées :

-a, --all
utiliser tous les manuels correspondants
-k, --apropos=CHAÎNE
rechercher CHAÎNE dans tous les index de tous les manuels
-d, --directory=DIR
ajouter DIR à INFOPATH
-f, --file=MANUEL
spécifier le manuel Info à visiter
-h, --help
afficher cette aide et quitter
--index-search=CHAÎNE
aller au nœud pointé par l'entrée d'index CHAÎNE
-n, --node=NOMNOEUD
spécifier des nœuds dans le premier fichier Info visité
-o, --output=FICHIER
sortir les nœuds sélectionnés vers FICHIER
--subnodes
sortir récursivement les éléments de menu
-v, --variable VAR=VALEUR
assigner VALEUR à la variable Info VAR
--version
afficher les informations de version et quitter
-w, --where, --location
imprimer l'emplacement physique du fichier Info

Le premier argument non-option, s'il est présent, est l'entrée de menu à partir de laquelle commencer ; il est recherché dans tous les fichiers 'dir' le long de INFOPATH. S'il n'est pas présent, info fusionne tous les fichiers 'dir' et affiche le résultat. Tous les arguments restants sont traités comme les noms d'éléments de menu relatifs au nœud initial visité.

Pour un résumé des raccourcis clavier, tapez H dans Info.

EXEMPLES

info
affiche le menu dir de niveau supérieur
info info-stnd
affiche le manuel de ce programme Info
info emacs
commence au nœud emacs depuis le menu dir de niveau supérieur
info emacs buffers
sélectionne l'entrée de menu buffers dans le manuel emacs
info emacs -n Files
commence au nœud Files dans le manuel emacs
info '(emacs)Files'
autre façon de commencer au nœud Files
info --subnodes -o out.txt emacs
sauvegarde l'intégralité du manuel emacs dans out.txt
info -f ./foo.info
affiche le fichier ./foo.info, sans chercher dans dir

info info

devrait vous donner accès au manuel complet. (Ou, si vous avez Emacs, M-x info mènera au manuel.)
