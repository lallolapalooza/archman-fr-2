INPLACE(3am) Modules d'extension GNU Awk INPLACE(3am)

NOM

inplace - émuler l'édition en place de sed/perl/ruby

SYNTAXE

gawk -i inplace ...

DESCRIPTION

L'extension inplace ajoute deux fonctions nommées inplace_begin() et inplace_end(). Ces fonctions sont destinées à être appelées à partir du wrapper inplace.awk qui est installé lors de l'installation de gawk.

Par défaut, chaque fichier nommé sur la ligne de commande est remplacé par un nouveau fichier du même nom dont le contenu est le résultat de l'exécution du programme AWK. Étant donné qu'un nouveau fichier est créé, si le fichier est un lien (symbolique ou physique), le lien sera rompu. Ce comportement est cohérent avec sed de GNU qui rompt également les liens lorsque le drapeau -i ou --in-place est utilisé. Si l'utilisateur fournit une variable AWK nommée inplace::suffix dans une règle BEGIN ou sur la ligne de commande, l'extension inplace concatène ce suffixe au nom du fichier original et utilise le résultat comme nom de fichier pour renommer l'original.

Pour des raisons de compatibilité ascendante, la variable vérifiera également INPLACE_SUFFIX (dans l'espace de noms awk) pour le suffixe à utiliser si inplace::suffix n'est pas défini.

On peut désactiver l'édition en place sélectivement en plaçant inplace::enable=0 sur la ligne de commande avant les fichiers qui doivent être traités normalement. On peut réactiver l'édition en place en plaçant inplace::enable=1 avant les fichiers qui doivent être soumis à l'édition en place.

BOGUES

Bien que l'extension tente de préserver la propriété et les permissions, elle ne fait aucun effort pour copier les ACL du fichier original.

Si le programme meurt prématurément, comme cela peut arriver si un signal non géré est reçu, un fichier temporaire peut être laissé derrière.

EXEMPLE

gawk -i inplace 'script' fichiers ...
gawk -i inplace -f scriptfile fichiers ...
