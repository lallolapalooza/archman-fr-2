INFECT(1) Manuel des commandes générales INFECT(1)

NOM

infect - insérer du code malveillant dans un binaire existant

SYNTAXE

infect FICHIER

DESCRIPTION

infect modifie un fichier exécutable en insérant du code supplémentaire à exécuter avant le programme d'origine, qui, lorsqu'il est appelé, crée un programme /bin/sh avec le bit set-user-ID activé.

infect ne fonctionne que sur les fichiers exécutables ELF 64 bits.

OPTIONS

Aucune.

NOTES

Afin de minimiser la taille du code à insérer, infect s'appuie sur plusieurs aspects non portables des exécutables ELF sous Linux. Ce programme n'est donc en aucun cas garanti de fonctionner avec les futures révisions du noyau Linux. Cependant, infect n'est pas vraiment destiné à être utilisé autant que son code source est destiné à être lu.
