inotify_add_watch(2) Manuel des appels système inotify_add_watch(2)

NOM

inotify_add_watch - ajouter une surveillance à une instance inotify initialisée

BIBLIOTHEQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/inotify.h>
int inotify_add_watch(int fd, const char *path, uint32_t mask);

DESCRIPTION

inotify_add_watch() ajoute une nouvelle surveillance, ou modifie une surveillance existante, pour le fichier dont l'emplacement est spécifié dans path ; l'appelant doit avoir la permission de lecture pour ce fichier. L'argument fd est un descripteur de fichier se référant à l'instance inotify dont la liste de surveillance doit être modifiée. Les événements à surveiller pour path sont spécifiés dans le masque de bits mask. Voir inotify(7) pour une description des bits qui peuvent être définis dans mask.

Un appel réussi à inotify_add_watch() renvoie un descripteur de surveillance unique pour cette instance inotify, pour l'objet du système de fichiers (inode) qui correspond à path. Si l'objet du système de fichiers n'était pas déjà surveillé par cette instance inotify, alors le descripteur de surveillance est nouvellement alloué. Si l'objet du système de fichiers était déjà surveillé (peut-être via un lien différent vers le même objet), alors le descripteur de la surveillance existante est renvoyé.

Le descripteur de surveillance est renvoyé par les futures lectures (read(2)) à partir du descripteur de fichier inotify. Ces lectures récupèrent des structures inotify_event (voir inotify(7)) indiquant les événements du système de fichiers ; le descripteur de surveillance à l'intérieur de cette structure identifie l'objet pour lequel l'événement s'est produit.

VALEUR DE RETOUR

En cas de succès, inotify_add_watch() renvoie un descripteur de surveillance (un entier non négatif). En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EACCES
L'accès en lecture au fichier donné n'est pas autorisé.
EBADF
Le descripteur de fichier donné n'est pas valide.
EEXIST
mask contient IN_MASK_CREATE et path se réfère à un fichier déjà surveillé par le même fd.
EFAULT
path pointe en dehors de l'espace d'adressage accessible du processus.
EINVAL
Le masque d'événements donné ne contient aucun événement valide ; ou mask contient à la fois IN_MASK_ADD et IN_MASK_CREATE ; ou fd n'est pas un descripteur de fichier inotify.
ENAMETOOLONG
path est trop long.
ENOENT
Un composant de répertoire dans path n'existe pas ou est un lien symbolique pendant.
ENOMEM
Une quantité insuffisante de mémoire noyau était disponible.
ENOSPC
La limite de l'utilisateur sur le nombre total de surveillances inotify a été atteinte ou le noyau n'a pas pu allouer une ressource nécessaire.
ENOTDIR
mask contient IN_ONLYDIR et path n'est pas un répertoire.

NORMES

Linux.

HISTORIQUE

Linux 2.6.13.

EXEMPLES

Voir inotify(7).

VOIR AUSSI

inotify_init(2), inotify_rm_watch(2), inotify(7)
