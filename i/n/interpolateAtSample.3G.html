NOM

interpolateAtSample - échantillonne une variable pour connaître sa valeur à l'emplacement d'un échantillon spécifié

DÉCLARATION

float interpolateAtSample(float interpolant, int sample);

vec2 interpolateAtSample(vec2 interpolant, int sample);

vec3 interpolateAtSample(vec3 interpolant, int sample);

vec4 interpolateAtSample(vec4 interpolant, int sample);

PARAMÈTRES

interpolant

Spécifie l'interpolant à échantillonner à l'emplacement de l'échantillon sample.

sample

Spécifie l'indice de l'échantillon dont l'emplacement sera utilisé pour échantillonner interpolant.

DESCRIPTION

interpolateAtSample retourne la valeur de la variable entrante interpolant échantillonnée à l'emplacement de l'échantillon numéro sample. Si les tampons multis Échantillons ne sont pas disponibles, la variable entrante sera évaluée au centre du pixel. Si l'échantillon sample n'existe pas, la position utilisée pour interpoler la variable entrante est indéfinie.
