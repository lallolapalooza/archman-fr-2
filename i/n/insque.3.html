insque(3) Manuel des fonctions de bibliothèque insque(3)

NOM

insque, remque — insérer/supprimer un élément d'une file d'attente

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <search.h>
void insque(void *elem, void *prev);
void remque(void *elem);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

insque(), remque() :

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE

DESCRIPTION

Les fonctions insque() et remque() manipulent des listes doublement chaînées. Chaque élément de la liste est une structure dont les deux premiers éléments sont un pointeur avant et un pointeur arrière. La liste chaînée peut être linéaire (c'est-à-dire un pointeur avant NULL à la fin de la liste et un pointeur arrière NULL au début de la liste) ou circulaire.

La fonction insque() insère l'élément pointé par elem immédiatement après l'élément pointé par prev.

Si la liste est linéaire, l'appel insque(elem, NULL) peut être utilisé pour insérer l'élément initial de la liste, et l'appel définit les pointeurs avant et arrière de elem à NULL.

Si la liste est circulaire, l'appelant doit s'assurer que les pointeurs avant et arrière du premier élément sont initialisés pour pointer vers cet élément, et que l'argument prev de l'appel insque() doit également pointer vers l'élément.

La fonction remque() supprime l'élément pointé par elem de la liste doublement chaînée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
insque (), remque () Sécurité des threads MT-Safe

VERSIONS

Sur les anciens systèmes, les arguments de ces fonctions étaient de type struct qelem *, défini comme :


struct qelem {
    struct qelem *q_forw;
    struct qelem *q_back;
    char          q_data[1];
};

C'est toujours ce que vous obtiendrez si _GNU_SOURCE est défini avant d'inclure <search.h>.

L'emplacement des prototypes de ces fonctions diffère selon les différentes versions d'UNIX. La version ci-dessus est la version POSIX. Certains systèmes les placent dans <string.h>.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

ANOMALIES

Dans glibc 2.4 et les versions antérieures, il n'était pas possible de spécifier prev comme NULL. Par conséquent, pour construire une liste linéaire, l'appelant devait construire une liste à l'aide d'un appel initial contenant les deux premiers éléments de la liste, avec les pointeurs avant et arrière dans chaque élément correctement initialisés.

EXEMPLES

Le programme ci-dessous illustre l'utilisation de insque(). Voici un exemple d'exécution du programme :


$ ./a.out -c a b c
Traversing completed list:
    a
    b
    c
That was a circular list

Source du programme

#include <search.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
struct element {
    struct element *forward;
    struct element *backward;
    char *name;
};
static struct element *
new_element(void)
{
    struct element *e;
    e = malloc(sizeof(*e));
    if (e == NULL) {
        fprintf(stderr, "malloc() failed\n");
        exit(EXIT_FAILURE);
    }
    return e;
}
int
main(int argc, char *argv[])
{
    struct element *first, *elem, *prev;
    int circular, opt, errfnd;
    /* The "-c" command-line option can be used to specify that the
       list is circular.  */
    errfnd = 0;
    circular = 0;
    while ((opt = getopt(argc, argv, "c")) != -1) {
        switch (opt) {
        case 'c':
            circular = 1;
            break;
        default:
            errfnd = 1;
            break;
        }
    }
    if (errfnd || optind >= argc) {
        fprintf(stderr,  "Usage: %s [-c] string...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Create first element and place it in the linked list.  */
    elem = new_element();
    first = elem;
    elem->name = argv[optind];
    if (circular) {
        elem->forward = elem;
        elem->backward = elem;
        insque(elem, elem);
    } else {
        insque(elem, NULL);
    }
    /* Add remaining command-line arguments as list elements.  */
    while (++optind < argc) {
        prev = elem;
        elem = new_element();
        elem->name = argv[optind];
        insque(elem, prev);
    }
    /* Traverse the list from the start, printing element names.  */
    printf("Traversing completed list:\n");
    elem = first;
    do {
        printf("    %s\n", elem->name);
        elem = elem->forward;
    } while (elem != NULL && elem != first);
    if (elem == first)
        printf("That was a circular list\n");
    exit(EXIT_SUCCESS);
}
