NOM

innochecksum - utilitaire de somme de contrôle hors ligne pour InnoDB

SYNTAXE

innochecksum [options] nom_fichier

DESCRIPTION

innochecksum affiche les sommes de contrôle pour les fichiers InnoDB. Cet outil lit un fichier d'espace de table InnoDB, calcule la somme de contrôle pour chaque page, compare la somme de contrôle calculée à la somme de contrôle stockée et signale les incohérences, qui indiquent des pages endommagées. Il a été initialement développé pour accélérer la vérification de l'intégrité des fichiers d'espace de table après des coupures de courant, mais il peut également être utilisé après des copies de fichiers. Étant donné que les incohérences de somme de contrôle entraîneront l'arrêt délibéré d'un serveur en cours d'exécution par InnoDB, il peut être préférable d'utiliser cet outil plutôt que d'attendre qu'un serveur en production rencontre les pages endommagées.

innochecksum ne peut pas être utilisé sur les fichiers d'espace de table que le serveur a déjà ouverts. Pour de tels fichiers, vous devriez utiliser CHECK TABLE pour vérifier les tables dans l'espace de table.

Si des incohérences de somme de contrôle sont trouvées, vous devriez normalement restaurer l'espace de table à partir d'une sauvegarde ou démarrer le serveur et tenter d'utiliser mariadb-dump pour sauvegarder les tables dans l'espace de table.

Appelez innochecksum comme suit :

shell> innochecksum [options] nom_fichier

innochecksum prend en charge les options suivantes. Pour les options qui font référence aux numéros de page, les numéros sont basés sur zéro.

•-?, --help

Affiche l'aide et quitte.

•-a num, --allow-mismatches=#

Nombre maximum d'incohérences de somme de contrôle autorisées avant que innochecksum ne se termine. La valeur par défaut est 0, ce qui termine à la première incohérence.

•-c, --count

Affiche le nombre de pages dans le fichier.

•-e num, --end-page=#

Termine à ce numéro de page.

•-i, --per-page-details

Affiche les détails par page.

•-I, --info

Synonyme de --help.

•-f, --leaf

Examine les pages d'index feuilles.

•-l fn, --log=fn

Journalise la sortie dans le fichier spécifié, fn.

•-m num, --merge=#

Nombre de pages feuilles si une fusion est donnée à un nombre de pages consécutives.

•-n, --no-check

Ignore la vérification de la somme de contrôle. Jusqu'à MariaDB 10.6, doit être utilisé avec l'option --write.

•-p num, --page-num=#

Vérifie uniquement ce numéro de page.

•-D name, --page-type-dump=name

Affiche les informations de type de page pour chaque page dans un espace de table.

•-S, --page-type-summary

Affiche un décompte de chaque type de page dans un espace de table.

•-s num, --start-page

Commence à ce numéro de page.

•-u, --skip-corrupt

Ignore les pages corrompues.

•-C name, --strict-check=name

Spécifie l'algorithme de somme de contrôle strict. L'un des éléments suivants : crc32, innodb, none. S'il n'est pas spécifié, valide par rapport à innodb, crc32 et none. Supprimé dans MariaDB 10.6.

•-w name, --write=name

Réécrit l'algorithme de somme de contrôle. L'un des éléments suivants : crc32, innodb, none. Un verrou exclusif est obtenu pendant l'utilisation. À utiliser conjointement avec l'option -no-check pour réécrire une somme de contrôle invalide. Supprimé dans MariaDB 10.6.

•-v, --verbose

Mode verbeux ; affiche un indicateur de progression toutes les cinq secondes.

•-V, --version

Affiche les informations de version et quitte.
