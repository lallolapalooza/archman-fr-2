INKVIEW(1) Manuel des commandes Inkview INKVIEW(1)

NOM

Inkview - un visualiseur SVG et un programme de diaporama.

SYNTAXE

"inkview [options] [fichier ...]"

options :

-h, --help
-V, --version
-f, --fullscreen
-r, --recursive
-t, --timer=NOMBRE
-s, --scale=NOMBRE
-p, --preload

DESCRIPTION

Inkview est un visualiseur Scalable Vector Graphics (SVG) qui peut également être utilisé pour des diaporamas ou des présentations. Un ou plusieurs FICHIERS ou DOSSIERS peuvent être spécifiés sur la ligne de commande pour l'ouverture. Inkview affichera tous les fichiers SVG dans l'ordre donné. Les dossiers seront développés en une liste de fichiers SVG contenus.

Vous pouvez également lancer Inkview sans aucun argument de ligne de commande, ce qui ouvrira un sélecteur de fichiers permettant de choisir des fichiers et des dossiers via une interface utilisateur graphique.

OPTIONS

-?, --help
Afficher les options d'aide.
-V, --version
Afficher la version d'Inkview et la date de compilation (cela correspond généralement à la version d'Inkscape).
-f, --fullscreen
Lancer Inkview en mode plein écran.
-r, --recursive
Rechercher récursivement les fichiers SVG dans les dossiers spécifiés sur la ligne de commande. Cela signifie que tous les fichiers SVG dans tous les sous-dossiers du dossier spécifié seront ouverts.
-t, --timer=NOMBRE
Passer à l'image suivante toutes les NOMBRE secondes.
-s, --scale=NOMBRE
Afficher l'image mise à l'échelle par un facteur de NOMBRE au lieu d'utiliser la taille native du fichier.
-p, --preload
Précharger tous les fichiers SVG. Inkview doit toujours rendre les images lorsqu'elles sont affichées, cependant cette option garantit que tous les fichiers SVG sont déjà analysés et chargés en mémoire. Cette option peut également être utilisée pour vérifier si tous les fichiers peuvent être ouverts correctement, sans avoir à les parcourir manuellement.

RACCOURCIS CLAVIER

  • Gauche, Page Précédente, ou Retour Arrière : afficher l'image précédente
  • Droite, Page Suivante, ou Espace : afficher l'image suivante
  • Haut, ou Début : aller à la première image
  • Bas, ou Fin : aller à la dernière image
  • Entrée : afficher la fenêtre de contrôle
  • F11 : basculer le mode plein écran
  • Échap ou Q : quitter

EXEMPLES

Afficher deux fichiers SVG :

inkview fichier1.svg fichier2.svg

Ouvrir tous les fichiers SVG dans le dossier d'exemples fourni avec Inkscape :

inkview B</usr/share>/inkscape/examples

Lancer un diaporama en plein écran qui passe automatiquement à l'image suivante toutes les 5 secondes :

inkview --fullscreen --timer=5 [fichiers/dossiers ...]
