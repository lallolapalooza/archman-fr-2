inet(3) Manuel des fonctions de la bibliothèque inet(3)

NOM

inet_aton, inet_addr, inet_network, inet_ntoa, inet_makeaddr, inet_lnaof, inet_netof - Routines de manipulation d'adresses Internet

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
int inet_aton(const char *cp, struct in_addr *inp);
in_addr_t inet_addr(const char *cp);
in_addr_t inet_network(const char *cp);

                                            in_addr_t host);

[[deprecated]] in_addr_t inet_netof(struct in_addr in);

DESCRIPTION

inet_aton() convertit l'adresse hôte Internet cp de la notation IPv4 nombres-et-points en forme binaire (dans l'ordre des octets du réseau) et la stocke dans la structure vers laquelle inp pointe. inet_aton() renvoie une valeur non nulle si l'adresse est valide, zéro sinon. L' adresse fournie dans cp peut avoir l'une des formes suivantes :

a.b.c.d
Chacune des quatre parties numériques spécifie un octet de l'adresse ; les octets sont assignés de gauche à droite pour produire l'adresse binaire.
a.b.c
Les parties a et b spécifient les deux premiers octets de l'adresse binaire. La partie c est interprétée comme une valeur sur 16 bits qui définit les deux octets de droite de l'adresse binaire. Cette notation convient pour spécifier des adresses de réseau de classe B (périmées).
a.b
La partie a spécifie le premier octet de l'adresse binaire. La partie b est interprétée comme une valeur sur 24 bits qui définit les trois octets de droite de l'adresse binaire. Cette notation convient pour spécifier des adresses de réseau de classe A (périmées).
a
La valeur a est interprétée comme une valeur sur 32 bits qui est stockée directement dans l'adresse binaire sans aucun réarrangement d'octets.

Dans toutes les formes ci-dessus, les composants de l'adresse en points peuvent être spécifiés en décimal, en octal (avec un 0initial), ou en hexadécimal, avec un 0Xinitial). Les adresses dans n'importe laquelle de ces formes sont collectivement appelées notation IPv4 nombres-et-points. La forme qui utilise exactement quatre nombres décimaux est désignée par notation IPv4 en points-décimaux (ou parfois : notation IPv4 en quadruplets).

inet_aton() renvoie 1 si la chaîne fournie a été interprétée avec succès, ou 0 si la chaîne est invalide (errno n'est pas défini en cas d'erreur).

La fonction inet_addr() convertit l'adresse hôte Internet cp de la notation IPv4 nombres-et-points en données binaires dans l'ordre des octets du réseau. Si l'entrée est invalide, INADDR_NONE (généralement -1) est renvoyé. L'utilisation de cette fonction est problématique car -1 est une adresse valide (255.255.255.255). Évitez de l'utiliser au profit de inet_aton(), inet_pton(3), ou getaddrinfo(3), qui fournissent une façon plus propre d'indiquer le retour d'erreur.

La fonction inet_network() convertit cp, une chaîne en notation IPv4 nombres-et-points, en un nombre dans l'ordre des octets de l'hôte adapté pour être utilisé comme adresse de réseau Internet. En cas de succès, l' adresse convertie est renvoyée. Si l'entrée est invalide, -1 est renvoyé.

La fonction inet_ntoa() convertit l'adresse hôte Internet in, donnée dans l'ordre des octets du réseau, en une chaîne en notation IPv4 en points-décimaux. La chaîne est renvoyée dans un tampon alloué statiquement, que les appels suivants écraseront.

La fonction inet_lnaof() renvoie la partie adresse réseau locale de l'adresse Internet in. La valeur renvoyée est dans l'ordre des octets de l'hôte.

La fonction inet_netof() renvoie la partie numéro de réseau de l'adresse Internet in. La valeur renvoyée est dans l'ordre des octets de l'hôte.

La fonction inet_makeaddr() est l'inverse de inet_netof() et inet_lnaof(). Elle renvoie une adresse hôte Internet dans l'ordre des octets du réseau, créée en combinant le numéro de réseau net avec l'adresse locale host, tous deux dans l'ordre des octets de l'hôte.

La structure in_addr telle qu'utilisée dans inet_ntoa(), inet_makeaddr(), inet_lnaof(), et inet_netof() est définie dans <netinet/in.h> comme :


typedef uint32_t in_addr_t;
struct in_addr {
    in_addr_t s_addr;
};

inet_lnaof(), inet_netof(), et inet_makeaddr() sont des fonctions héritées qui supposent traiter avec des adresses de réseau à classes. Le réseau à classes divise les adresses réseau IPv4 en composants hôte et réseau aux limites d'octets, comme suit :

Classe A
Ce type d'adresse est indiqué par la valeur 0 dans le bit de poids fort de l'adresse (dans l'ordre des octets du réseau). L'adresse réseau est contenue dans l'octet de poids fort, et l'adresse hôte occupe les trois octets restants.
Classe B
Ce type d'adresse est indiqué par la valeur binaire 10 dans les deux bits de poids fort de l'adresse. L'adresse réseau est contenue dans les deux octets de poids fort, et l'adresse hôte occupe les deux octets restants.
Classe C
Ce type d'adresse est indiqué par la valeur binaire 110 dans les trois bits de poids fort de l'adresse. L'adresse réseau est contenue dans les trois octets de poids fort, et l'adresse hôte occupe l'octet restant.

Les adresses de réseau à classes sont maintenant obsolètes, ayant été remplacées par le routage inter-domaines sans classe (CIDR), qui divise les adresses en composants réseau et hôte aux limites de bits arbitraires (plutôt que d' octets).

NOTES

Sur les architectures x86, l'ordre des octets de l'hôte est le moins significatif d'abord (little endian), tandis que l'ordre des octets du réseau, tel qu'utilisé sur Internet, est le plus significatif d'abord (big endian).

EXEMPLES

Un exemple d'utilisation de inet_aton() et inet_ntoa() est montré ci-dessous. Voici quelques exécutions d'exemple :


$ ./a.out 226.000.000.037      # Le dernier octet est en octal
226.0.0.31
$ ./a.out 0x7f.1               # Le premier octet est en hexadécimal
127.0.0.1

Source du programme

#define _DEFAULT_SOURCE
#include <arpa/inet.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    struct in_addr addr;
    if (argc != 2) {
        fprintf(stderr, "%s <adresse-point%c%c%c%c>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (inet_aton(argv[1], &addr) == 0) {
        fprintf(stderr, "Adresse invalide\n");
        exit(EXIT_FAILURE);
    }
    printf("%s\n", inet_ntoa(addr));
    exit(EXIT_SUCCESS);
}
