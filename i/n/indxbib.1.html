indxbib(1) Manuel des commandes générales indxbib(1)

Nom

indxbib - créer un index inversé pour les bases de données bibliographiques

Synopsis

indxbib [-w] [-c fichier-mots-communs] [-d rép] [-f fichier-liste] [-h taille-min-table-hachage] [-i champs-exclus] [-k max-clés-par-enregistrement] [-l longueur-min-clé] [-n seuil] [-o fichier] [-t longueur-max-clé] [fichier ...]
indxbib --help
indxbib -v
indxbib --version

Description

indxbib crée un index inversé pour les bases de données bibliographiques dans chaque fichier à utiliser avec refer(1), lookbib(1), et lkbib(1). Chaque index créé est nommé fichier.i ; l'écriture se fait dans un fichier temporaire qui est ensuite renommé. Si aucun opérande fichier n'est donné sur la ligne de commande car l'option -f a été utilisée, et qu'aucune option -o n'est donnée, l'index sera nommé Ind.i.

Les bases de données bibliographiques sont divisées en enregistrements par des lignes vides. Dans un enregistrement, chaque champ commence par un caractère % au début d'une ligne. Les champs ont un nom d'une lettre qui suit le caractère %.

Les valeurs définies par les options -c, -l, -n et -t sont stockées dans l'index : lorsque l'index est recherché, les clés seront écartées et tronquées d'une manière appropriée à ces options ; les clés originales seront utilisées pour vérifier que tout enregistrement trouvé à l'aide de l'index contient effectivement les clés. Cela signifie qu'un utilisateur d'un index n'a pas besoin de savoir si ces options ont été utilisées lors de la création de l'index, à condition que toutes les clés recherchées n'aient pas été écartées pendant l'indexation et que l'utilisateur fournisse au moins la partie de chaque clé qui serait restée après avoir été tronquée pendant l'indexation. La valeur définie par l'option -i est également stockée dans l'index et sera utilisée pour vérifier les enregistrements trouvés à l'aide de l'index.

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent les informations de version ; tous se terminent ensuite.

-c fichier-mots-communs
Lire la liste des mots courants depuis fichier-mots-communs au lieu de /usr/share/groff/1.23.0/eign.
-d rép
Utiliser rép comme nom du répertoire à stocker dans l'index, au lieu de celui retourné par getcwd(2). Typiquement, rép sera un lien symbolique dont la cible est le répertoire de travail courant.
-f fichier-liste
Lire les fichiers à indexer depuis fichier-liste. Si fichier-liste est -, les fichiers seront lus depuis le flux d'entrée standard. L'option -f ne peut être donnée qu'une seule fois.
-h taille-min-table-hachage
Utiliser le premier nombre premier supérieur ou égal à l'argument pour la taille de la table de hachage. Des valeurs plus grandes accéléreront généralement la recherche, mais rendront le fichier d'index plus volumineux et feront que indxbib utilisera plus de mémoire. La taille par défaut de la table de hachage est 997.
-i champs-exclus
Ne pas indexer le contenu des champs dont les noms sont dans champs-exclus. Les noms de champs sont d'un caractère chacun. Si cette option n'est pas présente, indxbib exclut les champs X, Y et Z.
-k max-clés-par-enregistrement
Ne pas utiliser plus de clés par enregistrement d'entrée que spécifié dans l'argument. Si cette option n'est pas présente, le maximum est de 100.
-l longueur-min-clé
Écarter toute clé dont la longueur en caractères est inférieure à la valeur de l'argument. Si cette option n'est pas présente, la longueur minimale de la clé est de 3.
-n seuil
Écarter les seuil mots les plus courants du fichier de mots courants. Si cette option n'est pas présente, les 100 mots les plus courants sont écartés.
-o nom-base
Nommer l'index nom-base.i.
-t longueur-max-clé
Tronquer les clés à longueur-max-clé caractères. Si cette option n'est pas présente, les clés sont tronquées à 6 caractères.
-w
Indexer les fichiers entiers. Chaque fichier est un enregistrement séparé.

Fichiers

Ind.i

/usr/share/groff/1.23.0/eign
