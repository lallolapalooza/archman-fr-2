INDOMCACHECTL(1) Manuel des commandes générales INDOMCACHECTL(1)

NOM

indomcachectl - gère les fichiers de cache de domaine d'instance

SYNTAXE

$PCP_BINADM_DIR/indomcachectl [-w] -l indom

$PCP_BINADM_DIR/indomcachectl [-w] [-m mode] [-g groupe] [-u utilisateur] indom

DESCRIPTION

indomcachectl aide à la gestion des fichiers de cache de domaine d'instance qui sont stockés dans $PCP_VAR_DIR/config/pmda.

Le paramètre obligatoire indom utilise un format à 2 points pour spécifier les champs domaine et série du numéro de domaine d'instance. Les valeurs requises peuvent être rapportées pour une métrique particulière en utilisant l'option -d de pminfo(1).

La liste des options disponibles peut être récupérée en utilisant l'option -?/--help, qui affiche un message d'utilisation et se termine.

Si l'option -l/--list est spécifiée, le contenu du fichier de cache du domaine d'instance est vidé sur stdout et indomcachectl se termine.

Sinon, un fichier de cache de domaine d'instance vide sera créé. La propriété utilisateur du fichier créé est attribuée à l'UID de l'appelant, mais peut éventuellement être attribuée à l'UID de utilisateur du fichier passwd(5) si l'option -u/--user est spécifiée. La propriété de groupe du fichier créé est attribuée au GID de l'appelant, sinon au GID par défaut de l'utilisateur utilisateur si l'option -u est spécifiée, sinon au GID de groupe du fichier group(5) si l'option -g/--group est spécifiée.

Le fichier de cache du domaine d'instance est créé avec le mode 0660 par défaut (certains PMDA utilisent la permission de lecture-écriture de groupe pour accéder et mettre à jour le contenu du fichier) - si cela ne convient pas, l'option -m/--mode peut être utilisée pour définir le mode à la valeur (octale) mode.

Étant donné que les fichiers de cache indom sont précieux pour le PMDA associé, indomcachectl n'écrasera pas un fichier de cache indom existant.

L'opération est généralement silencieuse, sauf en cas d'erreurs (ou d'avertissements si l'option -w/--warning est utilisée). Le code de sortie est 0 en cas de succès, 1 en cas d'échec.

AUTRES OPTIONS DE GESTION

Les fichiers dans $PCP_VAR_DIR/config/pmda sont tous des fichiers texte (un par domaine d'instance mis en cache) de sorte qu'une chirurgie judicieuse peut être utilisée pour apporter des modifications, voire supprimer les fichiers dans des cas extrêmes, **à condition** que le PMDA ne soit pas en cours d'exécution.

Voici un exemple pour le numéro de domaine d'instance 60.17 qui est associé aux métriques network.interface.*. 

$ cat /var/lib/pcp/config/pmda/60.17
2 0 2147483647
0 1712727825 ens33
1 1712727825 virbr0
2 1712727825 lo


La première ligne est un en-tête magique, ne la modifiez pas. Ensuite, il y a une ligne par instance avec l'identifiant d'instance (un entier) dans le premier champ, une valeur magique dans le deuxième champ (ne la modifiez pas) et le nom d'instance externe dans le troisième champ.

VOIR AUSSI

PCPIntro(1), chmod(1), pminfo(1), PMAPI(3), PMDA(3), pmdaCache(3), group(5) et passwd(5).
