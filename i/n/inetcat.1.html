NOM

inetcat - Ouvre une interface de lecture/écriture via STDIN/STDOUT vers un port TCP sur un périphérique usbmux

SYNTAXE

inetcat [OPTIONS] <PORT_TCP_DU_APPAREIL>

DESCRIPTION

inetcat est un outil simple similaire à netcat qui permet d'ouvrir une interface de lecture/écriture vers un port TCP sur un périphérique usbmux et de l'exposer via STDIN/STDOUT.

OPTIONS

-u, --udid UDID
Cible un périphérique spécifique par UDID. Notez que si cette option n'est *pas* spécifiée, inetcat se connectera au premier périphérique trouvé.
-n, --network
Se connecter à un périphérique réseau. Le périphérique doit avoir la synchronisation WiFi activée et être associé à cet ordinateur pour que cela fonctionne. Veuillez noter qu'un périphérique peut fermer les connexions à tout moment pour économiser de l'énergie. Cette option fera en sorte qu'inetcat se connecte uniquement aux périphériques connectés au réseau, sauf si -l est également passé (voir ci-dessous).
-l, --local
Se connecter à un périphérique USB. C'est la valeur par défaut si aucune option n'est passée. Si utilisé conjointement avec -n, inetcat tentera d'abord une connexion à un périphérique connecté via USB, et s'il n'est pas disponible, tentera de joindre un périphérique via le réseau.
-h, --help
Affiche les informations d'utilisation.
-d, --debug
Augmente le niveau de débogage.

EXEMPLE

Utiliser ssh ProxyCommand pour se connecter à un appareil iOS jailbreaké via SSH :

$ ssh -oProxyCommand="inetcat 22" root@localhost

Utilisé dans le fichier de configuration SSH pour se connecter à un appareil iOS :

$ cat ~/.ssh/config Host myiphone
User root
ProxyCommand "icat 22 UDID_de_mon_iphone" $ ssh myiphone
