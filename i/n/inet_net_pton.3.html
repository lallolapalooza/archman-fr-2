DESCRIPTIO

N

Ces fonctions convertissent les numéros de réseau entre le format de présentation (c'est-à-dire imprimable) et le format réseau (c'est-à-dire binaire)

.

Pour les deux fonctions, af spécifie la famille d'adresses pour la conversion ; la seule valeur prise en charge est AF_INET

.

inet_net_pton(

)

La fonction inet_net_pton() convertit pres, une chaîne terminée par un caractère nul contenant un numéro de réseau Internet au format de présentation, en format réseau. Le résultat de la conversion, qui est dans l'ordre des octets réseau, est placé dans le tampon pointé par netp. (L'argument netp pointe généralement vers une structure in_addr.) L'argument nsize spécifie le nombre d'octets disponibles dans netp

.

En cas de succès, inet_net_pton() renvoie le nombre de bits dans le champ de numéro de réseau du résultat placé dans netp. Pour une discussion sur le format de présentation en entrée et la valeur de retour, voir

NOTES.

Remarque : le tampon pointé par netp devrait être mis à zéro avant d'appeler inet_net_pton(), car l'appel n'écrit que le nombre d'octets requis pour le numéro de réseau (ou ceux explicitement spécifiés par pres), ce qui peut être moins que le nombre

d'octets d'une ad
resse réseau complète.

inet_net_ntop(

)

La fonction inet_net_ntop() convertit le numéro de réseau dans le tampon pointé par netp au format de présentation ; *netp est interprété comme une valeur dans l'ordre des octets réseau. L'argument bits spécifie le nombre de bits dans le numéro de réseau dans *netp

.

La chaîne de présentation terminée par un caractère nul est placée dans le tampon pointé par pres. L'argument psize spécifie le nombre d'octets disponibles dans pres. La chaîne de présentation est au format CIDR : un nombre déci

mal pointé représentant l'adresse ré
seau, suivi d'un slash et de la
taille du numéro de réseau en bits.

NOTE

S

Format de présentation en entrée pour

inet_net_pton()

Le numéro de réseau peut être spécifié soit comme une valeur hexadécimale, soit en notation décimale

pointée.

Les valeurs hexadécimales sont indiquées par un « 0x » ou « 0X » initial. Les chiffres hexadécimaux remplissent les nibbles (demi-octets) du numéro de réseau de gauche à droite dans l'ordre des octets

réseau.

En notation décimale pointée, jusqu'à quatre octets sont spécifiés, sous forme de nombres décimaux séparés par des points. Ainsi, l'une des formes suivantes est acceptée

: 


a.b.c.d
a.b.c
a.b
a

Chaque partie est un nombre compris entre 0 et 255 qui remplit un octet du numéro de réseau résultant, de gauche à droite, dans l'ordre des octets réseau (big endian). Lorsqu'une partie est omise, l'octet résultant dans le numéro de réseau est

zéro.

Pour le format hexadécimal comme pour le format décimal pointé, le numéro

de réseau peut être suivi, de manière facultative, d'un slash et d'un nombre
compris entre 0 et 32, qui spécifie la taille du numéro de réseau en bits.

Valeur renvoyée par

inet_net_pton()

La valeur renvoyée par inet_net_pton() est le nombre de bits dans le champ de numéro de réseau. Si la chaîne de présentation en entrée se termine par un slash et une valeur de taille explicite, alors cette taille devient la valeur renvoyée par inet_net_pton(). Sinon, la valeur renvoyée, bits, est déduite comme suit

:
•
Si l'octet de poids fort du numéro de réseau est supérieur ou égal à 240, alors bits vaut
32.
•
Sinon, si l'octet de poids fort du numéro de réseau est supérieur ou égal à 224, alors bits vaut
4.
•
Sinon, si l'octet de poids fort du numéro de réseau est supérieur ou égal à 192, alors bits vaut
24.
•
Sinon, si l'octet de poids fort du numéro de réseau est supérieur ou égal à 128, alors bits vaut
16.
•
Sinon, bits v
aut
8.

Si la valeur bits résultant des étapes ci-dessus est supérieure ou égale à 8, mais que le nombre d'octets spécifiés dans le numéro de réseau dépasse bits/8, alors bits est défini à 8 fois le

nombre d'
octets réellem
ent spécifiés.

EXEMPLE

S

Le programme ci-dessous illustre l'utilisation de inet_net_pton() et inet_net_ntop(). Il utilise inet_net_pton() pour convertir l'adresse réseau au format de présentation fournie dans son premier argument de ligne de commande en forme binaire, et affiche la valeur renvoyée par inet_net_pton(). Il utilise ensuite inet_net_ntop() pour reconvertir la forme binaire en format de présentation, et affiche la chaîne

résultante.

Afin de démontrer que inet_net_pton() peut ne pas écrire tous les octets de son argument netp, le programme accepte un deuxième argument de ligne de commande facultatif, un nombre utilisé pour initialiser le tampon avant l'appel de inet_net_pton(). En dernière ligne de sortie, le programme affiche tous les octets du tampon renvoyé par inet_net_pton() permettant à l'utilisateur de voir quels octets n'ont pas été touchés par inet_net_pt

on().

Un exemple d'exécution, montrant que inet_net_pton() déduit le nombre de bits dans le numéro de réseau

: 


$ ./a.out 193.168;
inet_net_pton() returned: 24
inet_net_ntop() yielded:  193.168.0/24
Raw address:
c1a80000

Démontrer que inet_net_pton() ne met pas à zéro les octets inutilisés dans son tampon de résultat

: 


$ ./a.out 193.168 0xffffffff;
inet_net_pton() returned: 24
inet_net_ntop() yielded:  193.168.0/24
Raw address:
c1a800ff

Démontrer que inet_net_pton() élargira la taille déduite du numéro de réseau, si le nombre de bits dans la chaîne de présentation dépasse la valeur déduite :


$ ./a.out 193.168.1.128;
inet_net_pton() returned: 32
inet_net_ntop() yielded:  193.168.1.128/32
Raw address:              c1a80180

Spécifier explicitement la taille du numéro de réseau remplacera toute déduction de sa taille (mais tout octet supplémentaire spécifié explicitement sera toujours utilisé par inet_net_pton() pour remplir le tampon de résultat) :


$ ./a.out 193.168.1.128/24;
inet_net_pton() returned: 24
inet_net_ntop() yielded:  193.168.1/24
Raw address:              c1a80180

Source du programme

/* Lier avec "-lresolv" */
#include <arpa/inet.h>
#include <err.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    char buf[100];
    struct in_addr addr;
    int bits;
    if (argc < 2) {
        fprintf(stderr,
                "Usage: %s presentation-form [addr-init-value]\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Si argv[2] est fourni (une valeur numérique), il est utilisé pour initialiser
       le tampon de sortie donné à inet_net_pton(), afin que nous puissions voir
       que inet_net_pton() n'initialise que les octets nécessaires au numéro de réseau.
       Si argv[2] n'est pas fourni, le tampon est initialisé à zéro (comme il est
       recommandé).  */
    addr.s_addr = (argc > 2) ? strtod(argv[2], NULL) : 0;
    /* Convertir le numéro de réseau en forme de présentation dans argv[1] en binaire.  */
    bits = inet_net_pton(AF_INET, argv[1], &addr, sizeof(addr));
    if (bits == -1)
        err(EXIT_FAILURE, "inet_net_ntop");
    printf("inet_net_pton() returned: %d\n", bits);
    /* Convertir le format binaire en forme de présentation, en utilisant 'bits'
       renvoyé par inet_net_pton().  */
    if (inet_net_ntop(AF_INET, &addr, bits, buf, sizeof(buf)) == NULL)
        err(EXIT_FAILURE, "inet_net_ntop");
    printf("inet_net_ntop() yielded:  %s\n", buf);
    /* Afficher 'addr' sous forme brute (en ordre d'octets réseau), afin que nous puissions
       voir les octets non affichés par inet_net_ntop() ; certains de ces octets
       peuvent ne pas avoir été touchés par inet_net_ntop(), et auront donc encore
       la valeur initiale spécifiée dans argv[2].  */
    printf("Raw address:              %x\n", htonl(addr.s_addr));
    exit(EXIT_SUCCESS);
}
