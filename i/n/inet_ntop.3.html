inet_ntop(3) Manuel des fonctions de bibliothèque inet_ntop(3)

NOM

inet_ntop - convertir les adresses IPv4 et IPv6 de la forme binaire en texte

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <arpa/inet.h>
const char *inet_ntop(socklen_t size,
                      int af, const void *restrict src,
                      char dst[restrict size], socklen_t size);

DESCRIPTION

Cette fonction convertit la structure d'adresse réseau src de la famille d'adresses af en une chaîne de caractères. La chaîne résultante est copiée dans le tampon pointé par dst, qui doit être un pointeur non nul. L'appelant spécifie le nombre d'octets disponibles dans ce tampon dans l'argument size.

inet_ntop() étend la fonction inet_ntoa(3) pour prendre en charge plusieurs familles d'adresses ; inet_ntoa(3) est maintenant considérée comme obsolète au profit de inet_ntop(). Les familles d'adresses suivantes sont actuellement prises en charge :

AF_INET
src pointe vers une struct in_addr (en ordre d'octets réseau) qui est convertie en une adresse réseau IPv4 au format décimal pointé, "ddd.ddd.ddd.ddd". Le tampon dst doit avoir une taille d'au moins INET_ADDRSTRLEN octets.
AF_INET6
src pointe vers une struct in6_addr (en ordre d'octets réseau) qui est convertie en une représentation de cette adresse dans le format d'adresse réseau IPv6 le plus approprié. Le tampon dst doit avoir une taille d'au moins INET6_ADDRSTRLEN octets.

VALEUR DE RETOUR

En cas de succès, inet_ntop() renvoie un pointeur non nul vers dst. NULL est renvoyé en cas d'erreur, avec errno défini pour indiquer l'erreur.

ERREURS

EAFNOSUPPORT
af n'était pas une famille d'adresses valide.
ENOSPC
La chaîne d'adresse convertie dépasserait la taille donnée par size.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
inet_ntop () Sécurité des threads MT-Safe locale

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

Notez que la RFC 2553 définit un prototype où le dernier argument size est de type size_t. De nombreux systèmes suivent la RFC 2553. glibc 2.0 et 2.1 ont size_t, mais 2.2 et les versions ultérieures ont socklen_t.

BOGUES

AF_INET6 convertit les adresses IPv6 mappées IPv4 en format IPv6.

EXEMPLES

Voir inet_pton(3).

VOIR AUSSI

getnameinfo(3), inet(3), inet_pton(3)
