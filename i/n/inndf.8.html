NOM

inndf - Rapporter l'espace disque libre, les inodes libres et les informations générales

SYNTAXE

inndf [-Fhi] [-f nom_fichier] répertoire [répertoire ...]

inndf -n

inndf -o

DESCRIPTION

inndf était à l'origine un remplacement pour "df | awk" dans innwatch.ctl(5) et innstat(8), et rapporte maintenant diverses autres informations d'utilisation du stockage de INN que df(1) ne comprend pas. inndf ne synchronise pas, ne fait pas autant de fork, et est généralement moins compliqué que df(1).

Son comportement par défaut est de rapporter les kilo-octets libres (pas les blocs disque), ou les inodes libres si -i est utilisé, dans les systèmes de fichiers contenant les répertoires donnés sur la ligne de commande. (Un kilo-octet dans ce cas est 1024 octets.) Si un seul répertoire est donné, la sortie sera un simple nombre ; si plus d'un répertoire est donné, la sortie sera formatée pour être lisible par l'homme.

Si enableoverview est défini sur true dans inn.conf, inndf peut également être utilisé pour obtenir des informations sur la base de données des aperçus. Avec l'option -n, il rapporte le nombre total d'enregistrements d'aperçus stockés. Avec -o, il rapporte le pourcentage d'espace utilisé dans la base de données des aperçus (pour les méthodes d'aperçus où cela a un sens).

OPTIONS

-f nom_fichier
nom_fichier doit contenir une liste de répertoires à utiliser en plus de ceux donnés par les arguments, un par ligne. Les lignes vides et tout ce qui suit "#" sur une ligne sont ignorés.
-F
Comme -f sauf que le nom de fichier est pathetc/filesystems et ce n'est pas une erreur si ce fichier n'existe pas. (Cette option est utilisée principalement par des éléments comme innstat(8), de sorte que l'administrateur des nouvelles puisse ajouter des systèmes de fichiers supplémentaires à vérifier dans pathetc/filesystems sans avoir à modifier le script.)
-h
Affiche un message d'utilisation et quitte.
-i
Rapporte le nombre d'inodes libres plutôt que la quantité d'espace disque libre.
-n
Rapporte le nombre total d'enregistrements dans la base de données des aperçus. Notez que les articles crosspostés auront un enregistrement d'aperçu pour chaque groupe de nouvelles vers lequel ils sont postés.
-o
Rapporte le pourcentage d'utilisation de l'espace de la base de données des aperçus. Ceci n'est pertinent que pour les méthodes d'aperçus qui pré-allouent une certaine quantité d'espace plutôt que de grandir pour accueillir plus d'enregistrements. Actuellement, ce drapeau n'est utile que pour la méthode d'aperçus buffindexed.

EXEMPLES

Imprime les kilo-octets libres dans pathspool sous forme de nombre simple :

inndf <cheminspool dans inn.conf>

Rapporte les inodes libres dans pathnews et pathspool dans un format conçu pour la lisibilité humaine :

inndf -i <cheminnews> <cheminspool>

Idem, mais en ajoutant tous les systèmes de fichiers dans pathetc/filesystems :

inndf -i -F <cheminnews> <cheminspool>

Affiche le nombre d'enregistrements d'aperçus et le pourcentage d'espace utilisé par une base de données d'aperçus buffindexed :

inndf -no
