NOM

inn-radius.conf - Configuration pour l'authentificateur RADIUS de nnrpd

DESCRIPTION

Ceci décrit le format et les attributs du fichier de configuration pour l'authentificateur RADIUS de nnrpd. Voir radius(8) pour plus d'informations sur le programme d'authentification. L'emplacement par défaut de ce fichier est inn-radius.conf dans pathetc.

Les lignes vides et les lignes commençant par "#" sont ignorées, tout comme tout ce qui suit un "#" sur une ligne. Toutes les autres lignes doivent commencer par un nom de paramètre suivi de deux points et de la valeur de cette clé, à l'exception près que chaque section de configuration pour un serveur particulier doit être entourée de :

server <nom> {
    # paramètres...
}

où <nom> est juste une étiquette pratique pour ce serveur.

PARAMÈTRES DE GROUPE SERVEUR

Les paramètres disponibles sont :

radhost
Le nom d'hôte du serveur RADIUS à utiliser pour l'authentification. Ce paramètre doit être défini.
radport
Le port à interroger sur le serveur RADIUS. Par défaut, 1645 s'il n'est pas défini.
lochost
Le nom d'hôte ou l'adresse IP effectuant la requête. Le serveur RADIUS attend une adresse IP ; un nom d'hôte sera traduit en adresse IP avec gethostbyname(). S'il n'est pas fourni, cette information n'est pas incluse dans la requête (toutes les configurations RADIUS n'exigent pas cette information).
locport
Le port auquel le client en cours d'authentification se connecte. S'il n'est pas fourni, la valeur par défaut est 119. Ceci n'a pas besoin d'être défini sauf si les lecteurs se connectent à un port non standard.
secret
Le secret partagé avec le serveur RADIUS. Si votre secret inclut des espaces, des tabulations ou "#", assurez-vous de l'inclure entre guillemets doubles. Ce paramètre doit être défini.
prefix
Ajoute le préfixe de la valeur de ce paramètre à tous les noms d'utilisateur avant de les passer au serveur RADIUS. Peut être utilisé pour ajouter quelque chose comme "news-" à tous les noms d'utilisateur afin de placer les utilisateurs de news dans un espace de noms différent de celui des autres comptes servis par le même serveur. S'il n'est pas défini, rien n'est ajouté en préfixe.
suffix
Ajoute le suffixe de la valeur de ce paramètre à tous les noms d'utilisateur avant de les passer au serveur RADIUS. Ceci est souvent quelque chose comme "@example.com", en fonction de la configuration de votre serveur RADIUS. S'il n'est pas défini, rien n'est ajouté en suffixe.
ignore-source
Peut être défini sur "true", "yes", "on", "false", "no" ou "off". S'il est défini sur false, l'authentificateur RADIUS vérifiera que la réponse reçue provient de la même adresse IP à laquelle la requête a été envoyée (pour une sécurité accrue). S'il est défini sur true, il ignorera cette vérification (si votre serveur RADIUS a plusieurs adresses IP ou si d'autres choses inhabituelles se produisent, il peut être tout à fait normal que la réponse provienne d'une adresse IP différente).

EXEMPLE

Voici une configuration pour un serveur de news nommé news.example.com, authentifiant les utilisateurs contre radius.example.com et ajoutant "@example.com" à tous les noms d'utilisateur fournis par le client avant de les passer au serveur RADIUS :

server example {
    radhost: radius.example.com
    lochost: news.example.com
    secret: IamARADIUSsecRET
    suffix: @example.com
}

Le secret partagé avec le serveur RADIUS est "IamARADIUSsecRET".
