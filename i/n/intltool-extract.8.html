INTLTOOL-EXTRACT(8) Manuel de l'administrateur système INTLTOOL-EXTRACT(8)

NOM

intltool-extract - génère des fichiers d'en-tête qui peuvent être lus par gettext

SYNTAXE

intltool-extract [options]... FICHIER_SOURCE

DESCRIPTION

intltool-extract extrait les chaînes du type de fichier XML/INI spécifié FICHIER_SOURCE et les écrit dans un fichier d'en-tête C. Ensuite, xgettext(1) peut fusionner ces chaînes du fichier d'en-tête dans un modèle po.

intltool-extract n'est généralement pas exécuté manuellement, mais appelé par intltool-update(8) à la place.

OPTIONS

-l
--local
Crée un sous-répertoire dans le répertoire de travail courant (nommé "tmp/") et y écrit les fichiers. Cette option ne peut pas être utilisée avec l'option --update.
--update
Écrit le fichier d'en-tête dans le même répertoire que le fichier source. Le nouveau nom de fichier est le nom du fichier source auquel est ajoutée l'extension ".h". Cette option ne peut pas être utilisée avec l'option -l/--local. De plus, cette option est l'option par défaut si ni --local ni --update n'est spécifié.
--type=TYPE
Spécifie le type de fichier source. Les types actuellement supportés sont :
"gettext/glade" (.glade, .glade2)
"gettext/gsettings" (.gschema.xml)
"gettext/ini" (Fichier INI générique)
"gettext/keys" (.keys)
"gettext/rfc822deb" (Fichier au format RFC 822)
"gettext/quoted" (toutes les chaînes entre "")
"gettext/schemas" (.schemas)
"gettext/scheme" (.scm)
"gettext/xml" (Fichier XML générique)
"gettext/qtdesigner" (Fichiers Qt Designer .ui)
-v
--version
Affiche les informations de version.
-h
--help
Affiche l'utilisation et les informations d'aide de base.
-q
--quiet
Soit silencieux pendant l'exécution.
