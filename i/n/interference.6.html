NOM

interference - ondes sinusoïdales décroissantes

SYNTAXE

interference [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id nombre] [--count nombre] [--gridsize nombre] [--delay nombre] [--speed nombre] [--radius nombre] [--ncolors nombre] [--color-shift nombre] [--hue nombre] [--no-db] [--fps]

DESCRIPTION

Une autre fantaisie de champ de couleur, celle-ci fonctionne en calculant des ondes sinusoïdales décroissantes et en les laissant interférer les unes avec les autres à mesure que leurs origines se déplacent.

OPTIONS

--visual visuel
Spécifiez quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine sur une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id nombre
Dessine sur la fenêtre spécifiée.
--count nombre
Nombre d'ondes. 0 - 20. Défaut : 3.
--gridsize nombre
Grossissement. 1 - 20. Défaut : 2.
--delay nombre
Délai par image, en microsecondes. Défaut : 30000 (0.03 secondes.).
--speed nombre
Vitesse de l'onde. 1 - 100. Défaut : 30.
--radius nombre
Taille de l'onde. 50 - 1500. Défaut : 800.
--ncolors nombre
Nombre de couleurs. Défaut : 192.
--color-shift nombre
Contraste des couleurs. 0 - 100. Défaut : 60.
--hue nombre
Teinte de la couleur de base (0-360, comme dans l'espace HSV.) Défaut : 0, signifiant aléatoire.
--db | --no-db
Indique s'il faut utiliser la double mise en mémoire tampon.
--fps
Affiche le taux d'images par seconde et la charge CPU actuels.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.
