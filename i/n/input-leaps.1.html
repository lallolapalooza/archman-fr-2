INPUTLEAPS(1) Commandes utilisateur INPUTLEAPS(1)

NOM

input-leap - Serveur de clavier/souris InputLeap

SYNTAXE

input-leap [--address <adresse>] [--config <chemin>] [--display <affichage>] [--daemon|--no-daemon] [--name <nom-écran>] [--restart|--no-restart] [--debug <niveau>]

DESCRIPTION

Lance le composant serveur d'InputLeap.

OPTIONS

-a, --address <adresse>
écoute les clients sur l'adresse donnée.
-c, --config <chemin>
utilise le fichier de configuration nommé à la place.
-d, --debug <niveau>
filtre les messages de log dont la priorité est inférieure au niveau. Le niveau peut être : FATAL, ERROR, WARNING, NOTE, INFO, DEBUG, DEBUG1, DEBUG2.
-n, --name <nom-écran> Utilise nom-écran au lieu du nom d'hôte pour identifier
cet écran dans la configuration.
-1, --no-restart
ne tente pas de redémarrer en cas d'échec.
--restart
redémarre automatiquement le serveur en cas d'échec. (*)
-l --log <fichier>
écrit les messages de log dans le fichier.
--no-tray
désactive l'icône de la barre système.
--enable-drag-drop
active le glisser-déposer de fichiers.
--enable-crypto
active le plugin crypto (ssl).
--display <affichage>
se connecte au serveur X à <affichage>
--screen-change-script <chemin>
chemin complet vers le script à exécuter lors d'un changement d'écran. Le premier argument est le nouveau nom de l'écran.
-f, --no-daemon
exécute en avant-plan.
--daemon
exécute en tant que démon. (*)
-h, --help
affiche cette aide et quitte.
--version
affiche les informations de version et quitte.

Les options par défaut sont marquées d'un *

L'argument pour --address est de la forme : [<nom-hôte>][:<port>]. Le nom d'hôte doit être l'adresse ou le nom d'hôte d'une interface sur le système. Les crochets entourant une adresse IPv6 sont requis lorsque le numéro de port est également spécifié et optionnels sinon. La valeur par défaut consiste à écouter sur toutes les interfaces en utilisant le numéro de port 24800.

FICHIERS

Si aucun chemin de fichier de configuration n'est fourni, le premier des éléments suivants qui se charge avec succès définit la configuration :

$HOME/.config/InputLeap/input-leap.conf
/etc/input-leap.conf
