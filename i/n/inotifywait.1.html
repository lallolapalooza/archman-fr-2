DESCRIPTIO

N

inotifywait attend efficacement les modifications de fichiers en utilisant par défaut l'interface inotify(7) de Linux. Il convient pour attendre des modifications de fichiers depuis des scripts shell. Il peut soit se terminer une fois qu'un événement se produit, soit s'exécuter continuellement et afficher les événements au fur et à mesure qu'ils se

produisent.

fsnotifywait est similaire à inotifywait mais il utilise par défaut l'interface fanotify(7) de Linux. Si spécifié explicitement, il utilise l'interface inotif

y(
7).

AVERTISSEMEN

TS

Lors de l'utilisation de inotifywait, le nom de fichier qui est affiché n'est pas garanti d'être à jour après un déplacement car c'es

t l'inode qui est surveillé. De plus, aucune des opérations observées n'est garantie d'avoir été effectuée sur le nom de fichier
que inotifywait a été instruit de surveiller dans les cas où le fichier est connu sous plusieurs noms dans le système de fichier.

BOGUE

S

Il existe des conditions de course dans le code de surveillance récursive des répertoires qui peuvent causer la perte d'événements s'ils se produisent dans un répertoire immédiatement après la création de celui- ci. C'est probablement

irréparable.

On suppose que la file d'at

tente des événements inoti
fy ne débordera jamais.
