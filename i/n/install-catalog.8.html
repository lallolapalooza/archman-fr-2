NOM

install-catalog - Gérer un catalogue SGML ou XML centralisé

SYNTAXE

install-catalog [ option ] action ... [ [ -d] [ --delegate] ] [ [ -a centralisé ordinaire] [ --add centralisé ordinaire]


[ -r centralisé ordinaire] [ --remove centralisé ordinaire]


[ -h] [ --help]


[ -v] [ --version] ]

DESCRIPTION

Ce script shell permet de gérer un catalogue centralisé référençant d'autres catalogues SGML ou XML "ordinaires".

Un catalogue ouvert contient un ensemble de directives définies par OASIS, principalement utilisées pour définir des équivalences entre les FPI (Formal Public Identifiers) et les noms de fichiers réels (voir TR9401:1997 sur http://www.oasis-open.org <URL:http://www.oasis-open.org>). Les catalogues ouverts résident généralement dans /usr/share/sgml.

Un catalogue centralisé est un catalogue ouvert spécial qui ne contient que des commentaires et des directives CATALOG pointant vers d'autres catalogues (ou des directives DELEGATE si elles sont prises en charge). Le catalogue centralisé peut être la clé de toutes les autres ressources SGML. Il réside généralement dans /etc/sgml.

Le catalogue centralisé peut être modifié manuellement ou via le script install-catalog pour ajouter ou supprimer des références à d'autres catalogues ordinaires. Ce script est principalement destiné aux scripts post-installation des progiciels.

Un exemple d'appel typique à install-catalog est :

      install-catalog --add \
        /usr/share/sgml/docbook/dsssl-stylesheets-1.54/catalog \
        /etc/sgml/sgml-docbook-4.0.cat

Cet appel installera dans /etc/sgml/sgml-docbook-4.0.cat une référence à /usr/share/sgml/docbook/dsssl-stylesheets-1.54/catalog.

OPTIONS

Voici la liste des options qui peuvent influencer le fonctionnement de install-catalog :


[ [ -d] [ --delegate] ]

Utiliser DELEGATE au lieu des directives CATALOG pour spécifier un pointeur.

ACTIONS

Voici la liste des actions qui peuvent être demandées à install-catalog :


[ [ -a centralisé ordinaire] [ --add centralisé ordinaire] ]

Déclarer un nouveau paquet SGML.


[ [ -r centralisé ordinaire] [ --remove centralisé ordinaire] ]

Supprimer un paquet SGML précédemment installé.


[ [ -h] [ --help] ]

Afficher un court message d'aide et quitter.


[ [ -v] [ --version] ]

Afficher l'identifiant de version et quitter.

FICHIERS

/etc/sgml/*
