ibidsverify(8) Diagnostics IB Ouvert ibidsverify(8)

Nom

ibidsverify - valide les identifiants IB dans le sous-réseau et signale les erreurs

Syntaxe

ibidsverify.pl [-h] [-R]

Description

ibidsverify.pl est un script perl qui utilise un fichier de topologie complet créé par ibnetdiscover, scanne le réseau pour valider les LID et GUID dans le sous-réseau. La validation consiste à vérifier qu'il n'y a pas d'identifiants nuls ou dupliqués.

Enfin, ibidsverify.pl réutilise également la sortie mise en cache d'ibnetdiscover provenant de certains autres outils de diagnostic, ce qui le rend un peu plus rapide que d'exécuter ibnetdiscover à partir de zéro.

Options

-R Recalculer les informations d'ibnetdiscover, c'est-à-dire ne pas utiliser les informations mises en cache. Cette option est plus lente mais devrait être utilisée si les outils de diagnostic n'ont pas été utilisés depuis un certain temps ou s'il y a d'autres raisons de croire que le réseau a changé.

-C <nom_ca> utiliser le nom_ca spécifié.

-P <port_ca> utiliser le port_ca spécifié.

Statut de sortie

Le statut de sortie est 1 si des erreurs sont trouvées, 0 sinon.

Fichiers

Fichier de configuration

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines des options communes à tous les outils. Voir le fichier de configuration fourni pour les détails.
