IBV_QUERY_QP(3) Manuel du programmeur Libibverbs IBV_QUERY_QP(3)

NOM

ibv_query_qp - obtenir les attributs d'une paire de files d'attente (QP)

SYNTAXE

#include <infiniband/verbs.h>

int ibv_query_qp(struct ibv_qp *qp, struct ibv_qp_attr *attr,
                 int attr_mask,
                 struct ibv_qp_init_attr *init_attr);

DESCRIPTION

ibv_query_qp() obtient les attributs spécifiés dans attr_mask pour le QP qp et les retourne via les pointeurs attr et init_attr. L'argument attr est une structure ibv_qp_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_qp_attr {
enum ibv_qp_state       qp_state;            /* État actuel du QP */
enum ibv_qp_state       cur_qp_state;        /* État actuel du QP - non pertinent pour ibv_query_qp */
enum ibv_mtu            path_mtu;            /* MTU du chemin (valide uniquement pour les QPs RC/UC) */
enum ibv_mig_state      path_mig_state;      /* État de migration du chemin (valide si le HCA supporte APM) */
uint32_t                qkey;                /* Clé Q du QP (valide uniquement pour les QPs UD) */
uint32_t                rq_psn;              /* PSN pour la file d'attente de réception (valide uniquement pour les QPs RC/UC) */
uint32_t                sq_psn;              /* PSN pour la file d'attente d'envoi */
uint32_t                dest_qp_num;         /* Numéro du QP de destination (valide uniquement pour les QPs RC/UC) */
unsigned int            qp_access_flags;     /* Masque des opérations d'accès à distance activées (valide uniquement pour les QPs RC/UC) */
struct ibv_qp_cap       cap;                 /* Capacités du QP */
struct ibv_ah_attr      ah_attr;             /* Vecteur d'adresse du chemin primaire (valide uniquement pour les QPs RC/UC) */
struct ibv_ah_attr      alt_ah_attr;         /* Vecteur d'adresse du chemin alternatif (valide uniquement pour les QPs RC/UC) */
uint16_t                pkey_index;          /* Index P_Key primaire */
uint16_t                alt_pkey_index;      /* Index P_Key alternatif */
uint8_t                 en_sqd_async_notify; /* Notification asynchrone de fin d'écoulement de SQD - non pertinent pour ibv_query_qp */
uint8_t                 sq_draining;         /* Le QP est-il en cours d'écoulement ? (Valide uniquement si qp_state est SQD) */
uint8_t                 max_rd_atomic;       /* Nombre de lectures RDMA & opérations atomiques en cours sur le QP de destination (valide uniquement pour les QPs RC) */
uint8_t                 max_dest_rd_atomic;  /* Nombre de ressources répondeuses pour la gestion des lectures RDMA & opérations atomiques entrantes (valide uniquement pour les QPs RC) */
uint8_t                 min_rnr_timer;       /* Temporisateur NAK RNR minimum (valide uniquement pour les QPs RC) */
uint8_t                 port_num;            /* Numéro de port primaire */
uint8_t                 timeout;             /* Temporisation d'acquittement local pour le chemin primaire (valide uniquement pour les QPs RC) */
uint8_t                 retry_cnt;           /* Compteur de tentatives (valide uniquement pour les QPs RC) */
uint8_t                 rnr_retry;           /* Tentatives RNR (valide uniquement pour les QPs RC) */
uint8_t                 alt_port_num;        /* Numéro de port alternatif */
uint8_t                 alt_timeout;         /* Temporisation d'acquittement local pour le chemin alternatif (valide uniquement pour les QPs RC) */
};

Pour plus de détails sur la structure ibv_qp_cap, voir la description de ibv_create_qp(). Pour plus de détails sur la structure ibv_ah_attr, voir la description de ibv_create_ah().

VALEUR DE RETOUR

ibv_query_qp() retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

NOTES

L'argument attr_mask est un indice qui spécifie la liste minimale d'attributs à récupérer. Certains périphériques RDMA peuvent retourner des attributs supplémentaires non demandés, par exemple si la valeur peut être retournée à moindre coût. Ceci a la même forme que dans ibv_modify_qp().

Les valeurs d'attribut sont valides si elles ont été définies en utilisant ibv_modify_qp(). La liste exacte des attributs valides dépend de l'état du QP.

Plusieurs appels à ibv_query_qp() peuvent produire certaines différences dans les valeurs retournées pour les attributs suivants : qp_state, path_mig_state, sq_draining, ah_attr (si APM est activé).
