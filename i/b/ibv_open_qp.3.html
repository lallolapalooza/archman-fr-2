IBV_OPEN_QP(3) Manuel du programmeur Libibverbs IBV_OPEN_QP(3)

NOM

ibv_open_qp - ouvrir une paire de files d'attente (QP) partageable

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_qp *ibv_open_qp(struct ibv_context *context,
                           struct ibv_qp_open_attr *qp_open_attr);

DESCRIPTION

ibv_open_qp() ouvre une paire de files d'attente (QP) existante associée au domaine de protection étendu xrcd. L'argument qp_open_attr est une structure ibv_qp_open_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_qp_open_attr {
uint32_t          comp_mask;  /* Identifie les champs valides */
uint32_t          qp_num;     /* Numéro de QP */
struct            *ibv_xrcd;  /* Domaine XRC */
void             *qp_context; /* Valeur opaque définie par l'utilisateur */
enum ibv_qp_type  qp_type;    /* Type de service de transport QP */

ibv_destroy_qp() ferme le QP ouvert et détruit le QP sous-jacent s'il n'a pas d'autres références. qp.

VALEUR DE RETOUR

ibv_open_qp() renvoie un pointeur vers le QP ouvert, ou NULL si la requête échoue. Vérifiez le numéro de QP (qp_num) dans le QP renvoyé.

NOTES

ibv_open_qp() échouera si on lui demande d'ouvrir un QP qui n'existe pas dans le xrcd avec le qp_num et le qp_type spécifiés.

VOIR AUSSI

ibv_alloc_pd(3), ibv_create_qp(3), ibv_create_qp_ex(3), ibv_modify_qp(3), ibv_query_qp(3)
