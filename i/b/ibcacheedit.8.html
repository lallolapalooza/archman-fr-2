Nom

ibcacheedit - modifier le cache ibnetdiscover

SYNOPSIS

ibcacheedit [options] <cache_orig> <cache_nouveau>

DESCRIPTION

ibcacheedit permet aux utilisateurs de modifier un cache ibnetdiscover créé via l'option --cache de ibnetdiscover(8).

OPTIONS

--switchguid GUIDAVANT:GUIDAPRES
Spécifie un GUID de commutateur à modifier. Le GUID avant et le GUID après doivent être séparés par un deux-points. Sur les commutateurs, les GUID de port sont identiques au GUID du commutateur, donc les GUID de port seront également ajustés sur les commutateurs.
--caguid GUIDAVANT:GUIDAPRES
Spécifie un GUID de CA (Channel Adapter) à modifier. Le GUID avant et le GUID après doivent être séparés par un deux-points.
--sysimgguid GUIDAVANT:GUIDAPRES
Spécifie un GUID d'image système à modifier. Le GUID avant et le GUID après doivent être séparés par un deux-points.
--portguid GUIDNODES:GUIDAVANT:GUIDAPRES
Spécifie un GUID de port à modifier. Le GUID du nœud (par exemple, le GUID du commutateur ou du CA) doit être spécifié en premier, suivi d'un deux-points, du GUID de port avant, d'un autre deux-points, puis du GUID de port après. Sur les commutateurs, les GUID de port sont identiques au GUID du commutateur, donc le GUID du commutateur sera également ajusté sur les commutateurs.

Drapeaux de débogage

-h, --help affiche le message d'utilisation

-V, --version affiche les informations de version.
