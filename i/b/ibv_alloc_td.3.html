IBV_ALLOC_TD(3) Manuel du programmeur Libibverbs IBV_ALLOC_TD(3)

NOM

ibv_alloc_td(), ibv_dealloc_td() - allouer et désallouer un objet domaine de thread

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_td *ibv_alloc_td(struct ibv_context *context,
                            struct ibv_td_init_attr *init_attr);

int ibv_dealloc_td(struct ibv_td *td);

DESCRIPTION

ibv_alloc_td() alloue un objet domaine de thread pour le contexte de périphérique RDMA context.

L'objet domaine de thread définit comment les bibliothèques de verbes et le fournisseur utiliseront les verrous et les capacités matérielles supplémentaires pour obtenir les meilleures performances pour la gestion de la protection multi-thread ou mono-thread. Une application attribue des ressources de verbes à un domaine de thread lors de la création d'un objet de verbes.

Si l'objet ibv_td est spécifié, alors tout objet créé sous ce domaine de thread désactivera le verrouillage interne conçu pour se protéger contre les accès concurrents à cet objet depuis plusieurs threads utilisateur. Par défaut, tous les objets de verbes sont sûrs pour un accès multi-thread, que le domaine de thread soit spécifié ou non.

Un struct ibv_td peut être ajouté à un domaine parent via ibv_alloc_parent_domain(), puis le domaine parent peut être utilisé pour créer des objets de verbes.

ibv_dealloc_td() désallouera le domaine de thread td. Toutes les ressources créées avec le td doivent être détruites avant de désallouer le td.

VALEUR DE RETOUR

ibv_alloc_td() renvoie un pointeur vers l'objet struct ibv_td alloué, ou NULL si la demande échoue (et définit errno pour indiquer la raison de l'échec).

ibv_dealloc_td() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).
