IBV_POST_SRQ_RECV(3) Manuel du programmeur Libibverbs IBV_POST_SRQ_RECV(3)

NOM

ibv_post_srq_recv - poster une liste de requêtes de travail (WRs) vers une file d'attente de réception partagée (SRQ)

SYNTAXE

#include <infiniband/verbs.h>

int ibv_post_srq_recv(struct ibv_srq *srq, struct ibv_recv_wr *wr,
                      struct ibv_recv_wr **bad_wr);

DESCRIPTION

ibv_post_srq_recv() poste la liste chaînée de requêtes de travail (WRs) commençant par wr à la file d'attente de réception partagée (SRQ) srq. Elle arrête le traitement des WRs de cette liste au premier échec (qui peut être détecté immédiatement lors de la publication des requêtes) et retourne cette WR échouée via bad_wr.

L'argument wr est une structure ibv_recv_wr, telle que définie dans <infiniband/verbs.h>.

struct ibv_recv_wr {
uint64_t                wr_id;     /* ID WR défini par l'utilisateur */
struct ibv_recv_wr     *next;      /* Pointeur vers la WR suivante dans la liste, NULL si c'est la dernière WR */
struct ibv_sge         *sg_list;   /* Pointeur vers le tableau s/g */
int                     num_sge;   /* Taille du tableau s/g */
};
struct ibv_sge {
uint64_t                addr;      /* Adresse de début du tampon mémoire local */
uint32_t                length;    /* Longueur du tampon */
uint32_t                lkey;      /* Clé de la Région Mémoire locale */
};

VALEUR REPOURNEE

ibv_post_srq_recv() retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

NOTES

Les tampons utilisés par une WR ne peuvent être réutilisés en toute sécurité qu'après que la requête est entièrement exécutée et qu'une complétion de travail a été récupérée de la file de complétion (CQ) correspondante.

Si une WR est publiée sur une UD QP, le Global Routing Header (GRH) du message entrant sera placé dans les 40 premiers octets du ou des tampons de la liste de dispersion. Si aucun GRH n'est présent dans le message entrant, les premiers octets seront indéfinis. Cela signifie que dans tous les cas, les données réelles du message entrant commenceront à un décalage de 40 octets dans le ou les tampons de la liste de dispersion.
