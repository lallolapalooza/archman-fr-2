FBB::IBase64Stream(3bobcat) Encodage/décodage base64 std::istream FBB::IBase64Stream(3bobcat)

NOM

FBB::IBase64Stream - flux std::istream effectuant un encodage et un décodage base64

SYNOPIS

#include <bobcat/ibase64stream>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::IBase64Stream peuvent être utilisés pour encoder ou décrypter des informations base64 qui sont disponibles sur un std::istream séparé.

La classe IBase64Stream est un modèle de classe, utilisant un paramètre non-type FBB::CryptType. Les objets de la classe FBB::IBase64Stream<FBB::ENCRYPT> encodent en base64 les informations qu'ils reçoivent, les objets de la classe FBB::IBase64Stream<FBB::DECRYPT> décodent en base64 les informations qu'ils reçoivent.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace nominal FBB.

HERITE DE

FBB::IBase64Buf (privé),
std::istream

CONSTRUCTEURS

o
IBase64Stream<CryptType>(std::istream &in, size_t bufSize = 1000):
Ce constructeur initialise un std::istream en lui fournissant un tampon de flux FBB::IBase64Buf. Le constructeur du IBase64Buf reçoit tous les arguments passés à ce constructeur.
- Les objets IBase64Stream<ENCRYPT> effectuent un encodage base64 ;
- Les objets IBase64Stream<DECRYPT> effectuent un décodage base64 ;
- Les objets IBase64Stream<CryptType> obtiennent les octets à encoder ou décoder depuis std::istream &in ;
- Le IFilterBuf utilisé en interne est initialisé avec un tampon de taille bufSize, avec une borne inférieure de 100.
Le constructeur utilise une taille de tampon configurable pour la lecture. Les caractères lus dans le tampon mais qui ne font pas partie des données réellement encodées en base64 ne seront pas disponibles après la fin du décryptage base64. Si des informations au-delà du bloc d'entrée base64 doivent rester disponibles, spécifiez une taille de tampon de 1.

Les constructeurs et opérateurs de copie et de déplacement ne sont pas disponibles.

MEMBRES HERITES

Étant donné que la classe hérite publiquement de std::istream, tous les membres de cette classe peuvent être utilisés.

EXEMPLE

#include "../ibase64stream"
#include <iostream>
using namespace std;
using namespace FBB;
int main()
{
    IBase64Stream<ENCRYPT> in(cin);
}
