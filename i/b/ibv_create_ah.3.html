IBV_CREATE_AH(3) Manuel du programmeur Libibverbs IBV_CREATE_AH(3)

NOM

ibv_create_ah, ibv_destroy_ah - créer ou détruire un handle d'adresse (AH)

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_ah *ibv_create_ah(struct ibv_pd *pd,
                             struct ibv_ah_attr *attr);

int ibv_destroy_ah(struct ibv_ah *ah);

DESCRIPTION

ibv_create_ah() crée un handle d'adresse (AH) associé au domaine de protection pd. L'argument attr est une structure ibv_ah_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_ah_attr {
struct ibv_global_route grh;            /* Attributs de l'en-tête de routage global (GRH) */
uint16_t                dlid;           /* LID de destination */
uint8_t                 sl;             /* Niveau de service */
uint8_t                 src_path_bits;  /* Bits du chemin source */
uint8_t                 static_rate;    /* Taux statique maximum */
uint8_t                 is_global;      /* Attributs GRH valides */
uint8_t                 port_num;       /* Numéro de port physique */
};
struct ibv_global_route {
union ibv_gid           dgid;           /* GID ou MGID de destination */
uint32_t                flow_label;     /* Étiquette de flux */
uint8_t                 sgid_index;     /* Index GID source */
uint8_t                 hop_limit;      /* Limite de sauts */
uint8_t                 traffic_class;  /* Classe de trafic */
};

ibv_destroy_ah() détruit l'AH ah.

VALEUR DE RETOUR

ibv_create_ah() renvoie un pointeur vers l'AH créé, ou NULL si la requête échoue.

NOTES

Si le drapeau de port IBV_QPF_GRH_REQUIRED est défini, ibv_create_ah() doit être créé avec la définition de 'struct ibv_ah_attr { .is_global = 1; .grh = {...}; }'.

ibv_destroy_ah() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).
