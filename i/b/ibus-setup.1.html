NOM

ibus-setup - programme de configuration pour ibus

SYNTAXE

ibus-setup

DESCRIPTION

IBus est un Bus d'Entrée Intelligent. C'est un nouveau framework d'entrée pour les systèmes d'exploitation Linux. Il fournit une interface utilisateur de méthode d'entrée complète et conviviale. Il peut également aider les développeurs à développer facilement des méthodes d'entrée.

ibus-setup est le programme de configuration pour IBus.

Page d'accueil : https://github.com/ibus/ibus/wiki

AVANCÉ

Utiliser la disposition du clavier du système
Si cette option est activée, utilisez votre disposition (keymap) système et IBus ne la modifiera pas avec un moteur de méthode d'entrée. La disposition système est décidée par votre session de bureau. IBus appelle la commande setxkbmap (1) en interne pour définir la disposition sélectionnée et remplacer la disposition système si cette option est désactivée. Vous pouvez vérifier la disposition actuelle avec la commande setxkbmap -query.
Partager la même méthode d'entrée entre toutes les applications
Si cette option est désactivée, vous pouvez choisir un moteur de méthode d'entrée par contexte d'entrée.
