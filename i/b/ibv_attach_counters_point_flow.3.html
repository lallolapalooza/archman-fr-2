NOM

ibv_attach_counters_point_flow - attacher une définition de compteur individuelle à un objet de flux

SYNOPIS

#include <infiniband/verbs.h>
int ibv_attach_counters_point_flow(struct ibv_counters *counters,
                                   struct ibv_counter_attach_attr *counter_attach_attr,
                                   struct ibv_flow *flow);

DESCRIPTION

Les points de compteurs sont une famille d'API permettant d'attacher une définition de compteur individuelle à un objet de verbe à un emplacement d'indice spécifique.

L'objet Compteurs commencera à collecter des valeurs une fois qu'il sera lié à la ressource de l'objet de verbe.

Une attache statique peut être créée lorsque NULL est fourni à la place de la référence à l'objet de verbes (par exemple, dans le cas d'un flux fournissant NULL au lieu de flow). Dans ce cas, cet objet de compteurs ne commencera à collecter des valeurs qu'après avoir été lié à la ressource de verbes ; pour un flux, cela se produit lorsqu'on référence le handle des compteurs lors de la création d'un flux avec ibv_create_flow().

Une fois qu'un ibv_counters est lié statiquement à une ressource de verbes, aucune attache supplémentaire n'est autorisée tant que l'objet compteur n'est pas délié de tout objet de verbes.

L'argument counter_desc spécifie quelle valeur de compteur doit être collectée. Il est défini dans verbs.h parmi les options de l'énumération ibv_counter_description.

Les capacités prises en charge des valeurs counter_desc spécifiques par objet de verbes peuvent être testées en vérifiant la valeur de retour pour succès ou l'erreur ENOTSUP.

L'attachement d'un handle de compteurs à plusieurs objets du même type accumulera les valeurs dans un seul indice. Par exemple, la création de plusieurs ibv_flow avec le même handle ibv_counters collectera les valeurs de tous les flux pertinents dans l'emplacement d'indice pertinent lors de la lecture des valeurs à partir de ibv_read_counters(). La définition de l'indice plus d'une fois avec un counter_desc différent ou identique agrègera les valeurs de tous les compteurs pertinents dans l'emplacement d'indice pertinent.

Les valeurs courantes des compteurs peuvent être lues depuis le matériel en appelant ibv_read_counters().

ARGUMENTS

counters
Compteurs existants sur lesquels attacher un nouveau point de compteur.
counter_attach_attr
Une structure ibv_counter_attach_attr, telle que définie dans verbs.h.
flow
Flux existant sur lequel attacher un nouveau point de compteurs (en mode statique, il doit être NULL).

Argument counter_attach_attr

struct ibv_counter_attach_attr {
    enum ibv_counter_description counter_desc;
    uint32_t index;
    uint32_t comp_mask;
};

Argument counter_desc

enum ibv_counter_description {
    IBV_COUNTER_PACKETS,
    IBV_COUNTER_BYTES,
};
index
Emplacement souhaité du compteur spécifique dans l'objet compteurs.
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides.

VALEUR DE RETOUR

ibv_attach_counters_point_flow() retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

ERREURS

EINVAL
argument(s) invalide(s) passé(s)
ENOTSUP
counter_desc n'est pas pris en charge sur l'objet demandé
EBUSY
l'objet compteur est déjà lié à un flux, des appels d'attache supplémentaires ne sont pas autorisés (valide pour l'attache statique uniquement)
ENOMEM
pas assez de mémoire

NOTES

Les valeurs des compteurs à chaque emplacement d'indice sont effacées lors de la création lors de l'appel à ibv_create_counters(). L'attachement de points de compteurs augmentera seulement ces valeurs en conséquence.

EXEMPLE

Un exemple d'utilisation de ibv_attach_counters_point_flow() est montré dans ibv_read_counters

VOIR AUSSI

ibv_create_counters, ibv_destroy_counters, ibv_read_counters, ibv_create_flow
