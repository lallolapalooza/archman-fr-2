IBV_GET_SRQ_NUM(3) Manuel du programmeur Libibverbs IBV_GET_SRQ_NUM(3)

NOM

ibv_get_srq_num - renvoyer le numéro srq associé à la file d'attente de réception partagée (SRQ) donnée

SYNTAXE

#include <infiniband/verbs.h>
int ibv_get_srq_num(struct ibv_srq *srq, uint32_t *srq_num);

DESCRIPTION

ibv_get_srq_num() renvoie le numéro srq associé à la file d'attente de réception partagée XRC donnée. L'argument srq est une structure ibv_srq, telle que définie dans <infiniband/verbs.h>. srq_num est un paramètre de sortie qui contient le numéro srq renvoyé.

VALEUR DE RETOUR

ibv_get_srq_num() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI

ibv_alloc_pd(3), ibv_create_srq_ex(3), ibv_modify_srq(3)
