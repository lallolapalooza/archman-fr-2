IBV_GET_CQ_EVENT(3) Manuel du programmeur Libibverbs IBV_GET_CQ_EVENT(3)

NOM

ibv_get_cq_event, ibv_ack_cq_events - obtenir et accuser réception des événements de file d'attente de complétion (CQ)

SYNOPHIS

#include <infiniband/verbs.h>

int ibv_get_cq_event(struct ibv_comp_channel *channel,
                     struct ibv_cq **cq, void **cq_context);

void ibv_ack_cq_events(struct ibv_cq *cq, unsigned int nevents);

DESCRIPTION

ibv_get_cq_event() attend le prochain événement de complétion dans le canal d'événements de complétion channel. Remplit les arguments cq avec la CQ qui a reçu l'événement et cq_context avec le contexte de la CQ.

ibv_ack_cq_events() accuse réception de nevents événements sur la CQ cq.

VALEUR DE RETOUR

ibv_get_cq_event() renvoie 0 en cas de succès, et -1 en cas d'erreur.

ibv_ack_cq_events() ne renvoie aucune valeur.

NOTES

Tous les événements de complétion que ibv_get_cq_event() retourne doivent être accusés réception en utilisant ibv_ack_cq_events(). Pour éviter les courses, la destruction d'une CQ attendra que tous les événements de complétion soient accusés réception ; cela garantit une correspondance univoque entre les accusés de réception et les appels réussis.

L'appel à ibv_ack_cq_events() peut être relativement coûteux dans le chemin de données, car il doit acquérir un mutex. Par conséquent, il peut être préférable d'amortir ce coût en conservant un décompte du nombre d'événements nécessitant un accusé de réception et en accusant réception de plusieurs événements de complétion en un seul appel à ibv_ack_cq_events().

EXEMPLES

L'exemple de code suivant démontre une manière possible de travailler avec les événements de complétion. Il effectue les étapes suivantes :

Étape I : Préparation
1. Crée une CQ
2. Demande une notification lors d'un nouvel événement de complétion (premier)

Étape II : Routine de traitement de complétion
3. Attend l'événement de complétion et l'accuse réception
4. Demande une notification lors du prochain événement de complétion
5. Vide la CQ

Notez qu'un événement supplémentaire peut être déclenché sans entrée de complétion correspondante dans la CQ. Cela se produit si une entrée de complétion est ajoutée à la CQ entre l'étape 4 et l'étape 5, et que la CQ est ensuite vidée (interrogée) à l'étape 5.

cq = ibv_create_cq(ctx, 1, ev_ctx, channel, 0);
if (!cq) {
        fprintf(stderr, "Échec de la création de CQ\n");
        return 1;
}
/* Demande de notification avant que toute complétion puisse être créée */
if (ibv_req_notify_cq(cq, 0)) {
        fprintf(stderr, "Impossible de demander la notification de CQ\n");
        return 1;
}
.
.
.
/* Attendre l'événement de complétion */
if (ibv_get_cq_event(channel, &ev_cq, &ev_ctx)) {
        fprintf(stderr, "Échec de l'obtention de cq_event\n");
        return 1;
}
/* Accuser réception de l'événement */
ibv_ack_cq_events(ev_cq, 1);
/* Demande de notification pour le prochain événement de complétion */
if (ibv_req_notify_cq(ev_cq, 0)) {
        fprintf(stderr, "Impossible de demander la notification de CQ\n");
        return 1;
}
/* Vider la CQ : interroger toutes les complétions de la CQ (s'il y en a) */
do {
        ne = ibv_poll_cq(cq, 1, &wc);
        if (ne < 0) {
                fprintf(stderr, "Échec de l'interrogation des complétions depuis la CQ\n");
                return 1;
        }
        /* il peut y avoir un événement supplémentaire sans complétion dans la CQ */
        if (ne == 0)
                continue;
        if (wc.status != IBV_WC_SUCCESS) {
                fprintf(stderr, "Complétion trouvée avec le statut 0x%x\n", wc.status);
                return 1;
        }
} while (ne);

L'exemple de code suivant démontre une manière possible de travailler avec les événements de complétion en mode non bloquant. Il effectue les étapes suivantes :

1. Configure le canal d'événements de complétion pour qu'il ne soit pas bloquant
2. Interroge le canal jusqu'à ce qu'il y ait un événement de complétion
3. Obtient l'événement de complétion et l'accuse réception

/* changer le mode bloquant du canal de complétion */
flags = fcntl(channel->fd, F_GETFL);
rc = fcntl(channel->fd, F_SETFL, flags | O_NONBLOCK);
if (rc < 0) {
	fprintf(stderr, "Échec du changement du descripteur de fichier du canal d'événements de complétion\n");
	return 1;
}
/*
 * interroger le canal jusqu'à ce qu'il ait un événement et attendre ms_timeout
 * millisecondes entre chaque itération
 */
my_pollfd.fd      = channel->fd;
my_pollfd.events  = POLLIN;
my_pollfd.revents = 0;
do {
	rc = poll(&my_pollfd, 1, ms_timeout);
} while (rc == 0);
if (rc < 0) {
	fprintf(stderr, "poll a échoué\n");
	return 1;
}
ev_cq = cq;
/* Attendre l'événement de complétion */
if (ibv_get_cq_event(channel, &ev_cq, &ev_ctx)) {
        fprintf(stderr, "Échec de l'obtention de cq_event\n");
        return 1;
}
/* Accuser réception de l'événement */
ibv_ack_cq_events(ev_cq, 1);
