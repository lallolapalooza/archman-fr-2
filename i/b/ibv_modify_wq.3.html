IBV_MODIFY_WQ(3) Manuel du programmeur Libibverbs IBV_MODIFY_WQ(3)

NOM

ibv_modify_wq - Modifier une file de travail (WQ).

SYNTAXE

#include <infiniband/verbs.h>

int ibv_modify_wq(struct ibv_wq *wq,
                             struct ibv_wq_attr *wq_attr);

DESCRIPTION

ibv_modify_wq() modifie une WQ wq. L'argument wq_attr est une structure ibv_wq_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_wq_attr {
uint32_t                attr_mask;     /* Utiliser enum ibv_wq_attr_mask */
enum ibv_wq_state       wq_state;      /* Passer à cet état */
enum ibv_wq_state       curr_wq_state; /* Supposer que c'est l'état actuel */
uint32_t                flags;         /* Valeurs des drapeaux à modifier, utiliser enum ibv_wq_flags */
uint32_t                flags_mask;    /* Quels drapeaux modifier, utiliser enum ibv_wq_flags */
};

La fonction ibv_modify_wq() modifiera la WQ en fonction de wq_attr->attr_mask donné.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).
