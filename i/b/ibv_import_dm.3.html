NOM

ibv_import_dm - importe une DM à partir d'un ibv_context donné

ibv_unimport_dm - désimporte une DM

SYNTAXE

#include <infiniband/verbs.h>
struct ibv_dm *ibv_import_dm(struct ibv_context *context, uint32_t dm_handle);
void ibv_unimport_dm(struct ibv_dm *dm)

DESCRIPTION

ibv_import_dm() renvoie une mémoire de périphérique (DM) associée au dm_handle donné dans le contexte RDMA.

La valeur du dm_handle en entrée doit être un handle valide du noyau pour un objet DM dans le contexte RDMA associé. Il peut être obtenu à partir de la DM d'origine en récupérant la valeur de son membre ibv_dm->handle.

ibv_unimport_dm() désimporte la DM. Une fois l'utilisation de la DM terminée, ibv_free_dm() ou ibv_unimport_dm() doit être appelée. La première contactera le noyau pour détruire l'objet, tandis que la seconde nettoiera ce qui est nécessaire/l'opposé de l'importation sans contacter le noyau.

Il incombe à l'application de coordonner tous les ibv_context(s) qui utilisent cette DM. Une fois la destruction effectuée, aucun autre processus ne peut toucher l'objet, sauf pour le désimportation. Tous les utilisateurs du contexte doivent collaborer pour garantir cela.

VALEUR RENVOYÉE

ibv_import_dm() renvoie un pointeur vers la DM allouée, ou NULL si la requête échoue et que errno est défini.
