ibv_alloc_dmah(3) Manuel du programmeur Libibverbs ibv_alloc_dmah(3)

NOM

ibv_alloc_dmah - alloue un handle DMA

int ibv_dealloc_dmah - désalloue un handle DMA

SYNTAXE

#include <infiniband/verbs.h>
struct ibv_dmah *ibv_alloc_dmah(struct ibv_context *context, struct ibv_dmah_init_attr *attr);
int ibv_dealloc_dmah(struct ibv_dmah *dmah);

DESCRIPTION

ibv_alloc_dmah() alloue un objet ibv_dmah associé au context donné et au paramètre d'entrée attr.

Le handle alloué peut être utilisé ultérieurement pour optimiser les opérations DMA et RDMA associées à une région mémoire enregistrée.

Une fois l'utilisation de ibv_dmah terminée, ibv_dealloc_dmah() doit être appelée.

Cet appel libérera les ressources précédemment allouées à l'aide de l'API ibv_alloc_dmah().

ARGUMENTS

attr

enum ibv_tph_mem_type {
    IBV_TPH_MEM_TYPE_VM, /* mémoire volatile */
    IBV_TPH_MEM_TYPE_PM, /* mémoire persistante */
};
enum ibv_dmah_init_attr_mask {
    IBV_DMAH_INIT_ATTR_MASK_CPU_ID = 1 << 0,
    IBV_DMAH_INIT_ATTR_MASK_PH = 1 << 1,
    IBV_DMAH_INIT_ATTR_MASK_TPH_MEM_TYPE = 1 << 2,
};
struct ibv_dmah_init_attr {
    uint32_t comp_mask; /* À partir de ibv_dmah_init_attr_mask */
    uint32_t cpu_id;
    uint8_t ph;
    uint8_t tph_mem_type; /* À partir de l'énum ibv_tph_mem_type */
};
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides.
cpu_id
L'identifiant du CPU auquel le handle DMA fait référence.
ph
Indices de traitement, utilisés pour aider à optimiser la gestion des transactions sur PCIe.
tph_mem_type
Le type de mémoire cible, parmi enum ibv_tph_mem_type.

VALEUR DE RETOUR

ibv_alloc_dmah() renvoie un pointeur vers l'objet de handle DMA alloué, ou NULL si la requête échoue.

ibv_dealloc_dmah() renvoie 0 en cas de succès, sinon la valeur errno.
