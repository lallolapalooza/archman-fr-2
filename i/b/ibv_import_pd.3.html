ibv_import_pd, ibv_unimport_pd(3) Manuel du programmeur Libibverbs ibv_import_pd, ibv_unimport_pd(3)

NOM

ibv_import_pd - importer un PD à partir d'un contexte ibv donné

ibv_unimport_pd - désimporter un PD

SYNTAXE

#include <infiniband/verbs.h>
struct ibv_pd *ibv_import_pd(struct ibv_context *context, uint32_t pd_handle);
void ibv_unimport_pd(struct ibv_pd *pd)

DESCRIPTION

ibv_import_pd() renvoie un domaine de protection (PD) qui est associé au pd_handle donné dans le context donné.

La valeur pd_handle d'entrée doit être un handle noyau valide pour un objet PD dans le context donné. Il peut être obtenu à partir du PD d'origine en récupérant la valeur de son membre ibv_pd->handle.

Le ibv_pd renvoyé peut être utilisé dans tous les verbes qui acceptent un domaine de protection.

ibv_unimport_pd() désimporte le PD. Une fois que l'utilisation du PD est terminée, ibv_dealloc_pd() ou ibv_unimport_pd() doit être appelé. Le premier ira au noyau pour détruire l'objet une fois que le second nettoiera ce qui est nécessaire/opposé à l'importation sans appeler le noyau.

Il incombe à l'application de coordonner tous les ibv_context qui utilisent ce PD. Une fois la destruction effectuée, aucun autre processus ne peut toucher l'objet, sauf pour la désimportation. Tous les utilisateurs du contexte doivent collaborer pour s'en assurer.

VALEUR RENVOYÉE

ibv_import_pd() renvoie un pointeur vers le PD alloué, ou NULL si la requête échoue.

VOIR AUSSI

ibv_alloc_pd(3), ibv_dealloc_pd(3),
