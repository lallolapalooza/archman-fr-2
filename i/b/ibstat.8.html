Nom

ibstat - interroger l'état de base des périphériques InfiniBand

Syntaxe

ibstat [options] <nom_ca> [num_port]

Description

ibstat est un binaire qui affiche des informations de base obtenues depuis le pilote IB local. La sortie inclut le LID, le SMLID, l'état du port, la largeur de lien active et l'état physique du port.

Il est similaire à l'utilitaire ibstatus mais implémenté en tant que binaire plutôt qu'un script. Il possède des options pour lister les CA et/ou les ports et affiche plus d'informations que ibstatus.

Options

-l, --list_of_cas
lister tous les périphériques IB
-s, --short
sortie courte
-p, --port_list
afficher la liste des ports
nom_ca
nom du périphérique InfiniBand
num_port
numéro du port du périphérique InfiniBand

Indicateurs de débogage

-d
augmenter le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).

-h, --help afficher le message d'utilisation

-v, --verbose
augmenter le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version afficher les informations de version.

Indicateurs de configuration

--config, -z <fichier_config> Spécifier un fichier de configuration alternatif.

Par défaut : /etc/infiniband-diags/ibdiag.conf

Exemples

ibstat            # afficher l'état de tous les ports sur tous les périphériques IB
ibstat -l         # lister tous les périphériques IB
ibstat -p         # afficher les GUID des ports
ibstat mthca0 2   # afficher l'état du port 2 de 'mthca0'
