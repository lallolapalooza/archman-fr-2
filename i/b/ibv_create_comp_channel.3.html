IBV_CREATE_COMP_CHANNEL(3) Manuel du programmeur Libibverbs IBV_CREATE_COMP_CHANNEL(3)

NOM

ibv_create_comp_channel, ibv_destroy_comp_channel - créer ou détruire un canal d'événements de complétion

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_comp_channel *ibv_create_comp_channel(struct ibv_context
                                                 *context);

int ibv_destroy_comp_channel(struct ibv_comp_channel *channel);

DESCRIPTION

ibv_create_comp_channel() crée un canal d'événements de complétion pour le contexte de périphérique RDMA context.

ibv_destroy_comp_channel() détruit le canal d'événements de complétion channel.

VALEUR DE RETOUR

ibv_create_comp_channel() retourne un pointeur vers le canal d'événements de complétion créé, ou NULL si la requête échoue.

ibv_destroy_comp_channel() retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

NOTES

Un "canal de complétion" est une abstraction introduite par libibverbs qui n'existe pas dans la spécification des verbes de l'Architecture InfiniBand ou la spécification des verbes RDMA. Un canal de complétion est essentiellement un descripteur de fichier qui est utilisé pour livrer les notifications de complétion à un processus userspace. Lorsqu'un événement de complétion est généré pour une file d'attente de complétion (CQ), l'événement est livré via le canal de complétion attaché à cette CQ. Cela peut être utile pour diriger les événements de complétion vers différents threads en utilisant plusieurs canaux de complétion.

ibv_destroy_comp_channel() échoue si des CQ sont encore associées au canal d'événements de complétion en cours de destruction.
