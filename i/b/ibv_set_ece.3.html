IBV_SET_ECE(3) Manuel du programmeur Libibverbs IBV_SET_ECE(3)

NOM

ibv_set_ece - définir les options ECE et les utiliser pour l'étape de configuration du QP.

SYNTAXE

#include <infiniband/verbs.h>
int ibv_set_ece(struct ibv_qp *qp, struct ibv_ece *ece);

DESCRIPTION

ibv_set_ece() définit les options ECE et les utilise pour l'étape de configuration du QP.

Les options ECE souhaitées seront utilisées lors des différentes étapes de modification du QP en fonction des options prises en charge dans l'état pertinent du QP.

ARGUMENTS

qp
La paire de files d'attente (QP) associée aux options ECE.
## Argument ece
Les valeurs ECE demandées. Il s'agit d'un champ ENTRÉE/SORTIE, les options acceptées seront retournées dans ce champ.
struct ibv_ece {
    uint32_t vendor_id;
    uint32_t options;
    uint32_t comp_mask;
};
vendor_id
Identifiant unique du fournisseur du fournisseur sur le réseau. Les fournisseurs définiront l'OUI IEEE ici pour se distinguer dans un réseau non homogène.
options
Attributs spécifiques au fournisseur qui sont pris en charge ou qui doivent être activés par les utilisateurs ECE.
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides.

VALEUR DE RETOUR

ibv_set_ece() retourne 0 lorsque l'appel a réussi, ou la valeur errno qui indique la raison de l'échec.

EOPNOTSUPP
libibverbs ou le pilote du fournisseur ne prend pas en charge le verbe ibv_set_ece().
EINVAL
Dans l'un des cas suivants : o Le QP est invalide. o Les options ECE sont invalides.
