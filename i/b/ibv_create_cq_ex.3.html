IBV_CREATE_CQ_EX(3) Manuel du programmeur Libibverbs IBV_CREATE_CQ_EX(3)

NOM

ibv_create_cq_ex - créer une file d'achèvement (CQ)

SYNOPSIS

#include <infiniband/verbs.h>

struct ibv_cq_ex *ibv_create_cq_ex(struct ibv_context *context,
                                   struct ibv_cq_init_attr_ex *cq_attr);

DESCRIPTION

ibv_create_cq_ex() crée une file d'achèvement (CQ) pour le contexte de périphérique RDMA context. L'argument cq_attr est un pointeur vers la structure ibv_cq_init_attr_ex telle que définie dans <infiniband/verbs.h>.

struct ibv_cq_init_attr_ex {
int                     cqe;               /* Nombre minimum d'entrées requises pour la CQ */
void                    *cq_context;       /* Contexte fourni par le consommateur retourné pour les événements d'achèvement */
struct ibv_comp_channel *channel;          /* Canal d'achèvement où les événements d'achèvement seront mis en file d'attente. Peut être NULL si les événements d'achèvement ne seront pas utilisés. */
int                     comp_vector;       /* Vecteur d'achèvement utilisé pour signaler les événements d'achèvement. Doit être >= 0 et < context->num_comp_vectors. */
uint64_t                wc_flags;          /* Les wc_flags qui doivent être retournés dans ibv_poll_cq_ex. Masque de bits OR de enum ibv_wc_flags_ex. */
uint32_t                comp_mask;         /* Masque de compatibilité (verbe étendu). */
uint32_t                flags              /* Un ou plusieurs drapeaux de enum ibv_create_cq_attr_flags */
struct ibv_pd           *parent_domain;    /* Domaine parent à utiliser par cette CQ */
};
enum ibv_wc_flags_ex {
        IBV_WC_EX_WITH_BYTE_LEN              = 1 << 0,  /* Nécessite la longueur en octets dans WC */
        IBV_WC_EX_WITH_IMM                   = 1 << 1,  /* Nécessite l'immédiat dans WC */
        IBV_WC_EX_WITH_QP_NUM                = 1 << 2,  /* Nécessite le numéro QP dans WC */
        IBV_WC_EX_WITH_SRC_QP                = 1 << 3,  /* Nécessite le QP source dans WC */
        IBV_WC_EX_WITH_SLID                  = 1 << 4,  /* Nécessite le SLID dans WC */
        IBV_WC_EX_WITH_SL                    = 1 << 5,  /* Nécessite le SL dans WC */
        IBV_WC_EX_WITH_DLID_PATH_BITS        = 1 << 6,  /* Nécessite les bits de chemin DLID dans WC */
        IBV_WC_EX_WITH_COMPLETION_TIMESTAMP  = 1 << 7,  /* Nécessite l'horodatage d'achèvement du périphérique dans WC /*
        IBV_WC_EX_WITH_CVLAN                 = 1 << 8,  /* Nécessite les informations VLAN dans WC */
        IBV_WC_EX_WITH_FLOW_TAG		     = 1 << 9,  /* Nécessite le tag de flux dans WC */
        IBV_WC_EX_WITH_COMPLETION_TIMESTAMP_WALLCLOCK  = 1 << 11, /* Nécessite l'horodatage d'achèvement de l'horloge murale dans WC */
};
enum ibv_cq_init_attr_mask {
        IBV_CQ_INIT_ATTR_MASK_FLAGS             = 1 << 0,
        IBV_CQ_INIT_ATTR_MASK_PD                = 1 << 1,
};
enum ibv_create_cq_attr_flags {
        IBV_CREATE_CQ_ATTR_SINGLE_THREADED      = 1 << 0, /* Cette CQ est utilisée à partir d'un seul thread, donc aucun verrouillage n'est requis */
        IBV_CREATE_CQ_ATTR_IGNORE_OVERRUN       = 1 << 1, /* Cette CQ ne passera pas à l'état d'erreur en cas de dépassement, CQE sera toujours écrit dans l'entrée suivante.
                                                           * Une application doit être conçue pour éviter de dépasser la CQ, sinon les CQE pourraient être perdus.
                                                           */
};

Sondage d'une CQ étendue

Afin de sonder une CQ étendue efficacement, un utilisateur peut utiliser les fonctions suivantes.

Fonctions d'itérateur d'achèvement

int ibv_start_poll(struct ibv_cq_ex *cq, struct ibv_poll_cq_attr *attr)
Démarre le sondage d'un lot d'achèvements de travail. attr est donné afin de rendre cette fonction facilement extensible à l'avenir. Cette fonction retourne 0 en cas de succès ou un code d'erreur sinon. Lorsqu'aucun achèvement n'est disponible sur la CQ, ENOENT est retourné, mais la CQ reste dans un état valide. En cas de succès, l'attribut de l'achèvement peut être interrogé en utilisant les fonctions de requête décrites ci-dessous. Si un code d'erreur est donné, end_poll ne doit pas être appelé.

int ibv_next_poll(struct ibv_cq_ex *cq)
Cette fonction est appelée afin d'obtenir le prochain achèvement de travail. Elle doit être appelée après start_poll et avant end_poll. Cette fonction retourne 0 en cas de succès ou un code d'erreur sinon. Lorsqu'aucun achèvement n'est disponible sur la CQ, ENOENT est retourné, mais la CQ reste dans un état valide. En cas de succès, l'attribut de l'achèvement peut être interrogé en utilisant les fonctions de requête décrites ci-dessous. Si un code d'erreur est donné, end_poll doit quand même être appelé, indiquant que c'est la fin du lot sondé.

void ibv_end_poll(struct ibv_cq_ex *cq)
Cette fonction indique la fin du lot de sondage des achèvements de travail. Après avoir appelé cette fonction, l'utilisateur doit démarrer un nouveau lot en appelant start_poll.

Sondage des champs dans l'achèvement
Les membres et fonctions ci-dessous sont utilisés pour sonder l'achèvement actuel. L'achèvement actuel est l'achèvement auquel pointe l'itérateur (start_poll et next_poll font avancer cet itérateur). Seuls les champs que l'utilisateur a demandés via wc_flags dans ibv_create_cq_ex peuvent être interrogés. De plus, certains champs ne sont valides que pour certains opcodes et codes d'état.

uint64_t wr_id - Peut être accédé directement depuis la structure ibv_cq_ex.

enum ibv_wc_status - Peut être accédé directement depuis la structure ibv_cq_ex.

enum ibv_wc_opcode ibv_wc_read_opcode(struct ibv_cq_ex *cq); Récupère l'opcode de l'achèvement actuel.

uint32_t ibv_wc_read_vendor_err(struct ibv_cq_ex *cq); Récupère l'erreur du fournisseur de l'achèvement actuel.

uint32_t ibv_wc_read_byte_len(struct ibv_cq_ex *cq); Récupère la longueur de la charge utile de l'achèvement actuel.

__be32 ibv_wc_read_imm_data(struct ibv_cq_ex *cq); Récupère le champ de données immédiates de l'achèvement actuel.

uint32_t ibv_wc_read_invalidated_rkey(struct ibv_cq_ex *cq); Récupère la rkey invalidée par SEND_INVAL de l'achèvement actuel.

uint32_t ibv_wc_read_qp_num(struct ibv_cq_ex *cq); Récupère le champ numéro QP de l'achèvement actuel.

uint32_t ibv_wc_read_src_qp(struct ibv_cq_ex *cq); Récupère le champ numéro QP source de l'achèvement actuel.

unsigned int ibv_wc_read_wc_flags(struct ibv_cq_ex *cq); Récupère le champ des drapeaux QP de l'achèvement actuel.

uint16_t ibv_wc_read_pkey_index(struct ibv_cq_ex *cq); Récupère le champ index pkey de l'achèvement actuel.

uint32_t ibv_wc_read_slid(struct ibv_cq_ex *cq); Récupère le champ SLID de l'achèvement actuel.

uint8_t ibv_wc_read_sl(struct ibv_cq_ex *cq); Récupère le champ SL de l'achèvement actuel.

uint8_t ibv_wc_read_dlid_path_bits(struct ibv_cq_ex *cq); Récupère le champ dlid_path_bits de l'achèvement actuel.

uint64_t ibv_wc_read_completion_ts(struct ibv_cq_ex *cq); Récupère l'horodatage d'achèvement de l'achèvement actuel dans les unités d'horloge HCA.

uint64_t ibv_wc_read_completion_wallclock_ns(struct ibv_cq_ex *cq); Récupère l'horodatage d'achèvement de l'achèvement actuel et le convertit des unités d'horloge HCA en nanosecondes d'horloge murale.

uint16_t ibv_wc_read_cvlan(struct ibv_cq_ex *cq); Récupère le champ CVLAN de l'achèvement actuel.

uint32_t ibv_wc_read_flow_tag(struct ibv_cq_ex *cq); Récupère le tag de flux de l'achèvement actuel.

void ibv_wc_read_tm_info(struct ibv_cq_ex *cq, struct ibv_wc_tm_info *tm_info); Récupère les informations de correspondance de tag de l'achèvement actuel.

struct ibv_wc_tm_info {
uint64_t tag;  /* tag de TMH */
uint32_t priv; /* données utilisateur opaques de TMH */
};

VALEUR DE RETOUR

ibv_create_cq_ex() retourne un pointeur vers la CQ, ou NULL si la requête échoue.

NOTES

ibv_create_cq_ex() peut créer une file d'attente de complétion (CQ) dont la taille est supérieure ou égale à la taille demandée. Vérifiez l'attribut cqe dans la CQ retournée pour connaître la taille réelle.

La CQ doit être détruite avec ibv_destroy_cq.
