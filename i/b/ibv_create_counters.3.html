ibv_create_counters(3) Manuel du programmeur Libibverbs ibv_create_counters(3)

NOM

ibv_create_counters, ibv_destroy_counters - Créer ou détruire une poignée de compteurs

SYNTAXE

#include <infiniband/verbs.h>
struct ibv_counters *
ibv_create_counters(struct ibv_context *context,
                    struct ibv_counters_init_attr *init_attr);
int ibv_destroy_counters(struct ibv_counters *counters);

DESCRIPTION

ibv_create_counters() crée une nouvelle poignée de compteurs pour le contexte de périphérique RDMA.

Une poignée ibv_counters peut être attachée statiquement à une ressource de verbes (par exemple : QP, WQ, Flow) lors de la création de celles-ci.

Par exemple, attacher un ibv_counters statiquement à un Flow (struct ibv_flow) lors de la création d'un nouveau Flow en appelant ibv_create_flow().

Les compteurs sont effacés lors de la création et leurs valeurs seront monotoniquement croissantes.

ibv_destroy_counters() libère la poignée de compteurs ; l'utilisateur doit détacher l'objet compteur avant de le détruire.

ARGUMENTS

context
Contexte du périphérique RDMA sur lequel créer les compteurs.
init_attr
Est une structure ibv_counters_init_attr, telle que définie dans verbs.h.

Argument init_attr

struct ibv_counters_init_attr {
    int comp_mask;
};
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides.

VALEUR DE RETOUR

ibv_create_counters() renvoie un pointeur vers l'objet ibv_counters alloué, ou NULL si la requête échoue (et définit errno pour indiquer la raison de l'échec)

ibv_destroy_counters() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec)

ERREURS

EOPNOTSUPP
ibv_create_counters() n'est pas actuellement supporté sur ce périphérique (ENOSYS peut parfois être renvoyé par d'anciennes versions de libibverbs).
ENOMEM
ibv_create_counters() n'a pas pu créer l'objet ibv_counters, mémoire insuffisante
EINVAL
paramètre invalide fourni à ibv_destroy_counters()

EXEMPLE

Un exemple d'utilisation de ibv_counters est montré dans ibv_read_counters

VOIR AUSSI

ibv_attach_counters_point_flow, ibv_read_counters, ibv_create_flow
