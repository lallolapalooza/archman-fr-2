IBV_MODIFY_CQ(3) Manuel du programmeur Libibverbs IBV_MODIFY_CQ(3)

NOM

ibv_modify_cq - modifier une file d'achèvement (CQ)

SYNTAXE

#include <infiniband/verbs.h>

int ibv_modify_cq(struct ibv_cq *cq, struct ibv_modify_cq_attr *cq_attr);

DESCRIPTION

ibv_modify_cq() modifie une CQ cq. L'argument cq_attr est une structure ibv_modify_cq_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_moderate_cq {
uint16_t cq_count;  /* nombre d'achèvements par événement */
uint16_t cq_period; /* en microsecondes */
};
struct ibv_modify_cq_attr {
	uint32_t attr_mask;
	struct ibv_moderate_cq moderate;
};

La fonction ibv_modify_cq() modifiera la CQ, en se basant sur le cq_attr->attr_mask donné.

VALEUR DE RETOUR

retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI
