IBPING(8) Diagnostics Open IB IBPING(8)

Nom

IBPING - ping une adresse InfiniBand

Syntaxe

ibping [options] <lid | guid de destination>

Description

ibping utilise des mads propriétaires pour valider la connectivité entre les nœuds IB. À la sortie, un affichage similaire à celui de ping (IP) est présenté. ibping fonctionne en mode client/serveur. Le mode client est sélectionné par défaut. Notez également qu'un serveur ping par défaut est implémenté dans le noyau.

Options

-c, --count arrêter après un nombre spécifié de paquets

-f, --flood inonder la destination : envoyer des paquets les uns à la suite des autres sans délai

-o, --oui utiliser le numéro OUI spécifié pour multiplexer les mads propriétaires

-S, --Server démarrer en mode serveur (ne pas retourner)

Flags d'adressage

-L, --Lid L'adresse spécifiée est un LID

-G, --Guid L'adresse spécifiée est un GUID de port

-s, --sm_port <smlid> utiliser 'smlid' comme LID cible pour les requêtes SA.

Flags de sélection de port

-C, --Ca <nom_ca> utiliser le nom_ca spécifié.

-P, --Port <port_ca> utiliser le port_ca spécifié.

Sélection du port local

Support multi-port/multi-CA : lorsque aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port ACTIF.
2.
si aucun trouvé, le premier port CONNECTÉ (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de répondre à la demande de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utiliser le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utiliser le deuxième port (actif/connecté) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser le port spécifié uniquement.

Flags de configuration

--config, -z <fichier_config> spécifier un fichier de configuration alternatif.

Par défaut : /etc/infiniband-diags/ibdiag.conf

-t, --timeout <timeout_ms> remplacer le délai d'attente par défaut pour les mads sollicités.

Flags de débogage

-h, --help afficher le message d'utilisation

-d
augmenter le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
afficher les erreurs d'envoi et de réception (erreurs de délai et autres)
-v, --verbose
augmenter le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version afficher les informations de version.

Fichiers

FICHIER DE CONFIGURATION

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines des options courantes pour tous les outils. Voir le fichier de configuration fourni pour plus de détails.
