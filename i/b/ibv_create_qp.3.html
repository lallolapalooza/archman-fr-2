IBV_CREATE_QP(3) Manuel du programmeur Libibverbs IBV_CREATE_QP(3)

NOM

ibv_create_qp, ibv_destroy_qp - créer ou détruire une paire de files d'attente (QP)

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_qp *ibv_create_qp(struct ibv_pd *pd,
                             struct ibv_qp_init_attr *qp_init_attr);

int ibv_destroy_qp(struct ibv_qp *qp);

DESCRIPTION

ibv_create_qp() crée une paire de files d'attente (QP) associée au domaine de protection pd. L'argument qp_init_attr est une structure ibv_qp_init_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_qp_init_attr {
void                   *qp_context;     /* Contexte associé du QP */
struct ibv_cq          *send_cq;        /* CQ à associer à la file d'attente d'envoi (SQ) */ 
struct ibv_cq          *recv_cq;        /* CQ à associer à la file d'attente de réception (RQ) */
struct ibv_srq         *srq;            /* Handle SRQ si le QP doit être associé à un SRQ, sinon NULL */
struct ibv_qp_cap       cap;            /* Capacités du QP */
enum ibv_qp_type        qp_type;        /* Type de service de transport du QP : IBV_QPT_RC, IBV_QPT_UC, IBV_QPT_UD, IBV_QPT_RAW_PACKET ou IBV_QPT_DRIVER */
int                     sq_sig_all;     /* Si défini, chaque Work Request (WR) soumis à la SQ génère une entrée de complétion */
};
struct ibv_qp_cap {
uint32_t                max_send_wr;    /* Nombre maximum demandé de WRs en attente dans la SQ */
uint32_t                max_recv_wr;    /* Nombre maximum demandé de WRs en attente dans la RQ */
uint32_t                max_send_sge;   /* Nombre maximum demandé d'éléments scatter/gather (s/g) dans un WR dans la SQ */
uint32_t                max_recv_sge;   /* Nombre maximum demandé d'éléments s/g dans un WR dans la RQ */
uint32_t                max_inline_data;/* Nombre maximum demandé de données (octets) pouvant être posté en ligne dans la SQ, sinon 0 */
};

La fonction ibv_create_qp() mettra à jour la structure qp_init_attr->cap avec les valeurs réelles du QP créé ; les valeurs seront supérieures ou égales aux valeurs demandées.

ibv_destroy_qp() détruit le QP qp.

VALEUR DE RETOUR

ibv_create_qp() retourne un pointeur vers le QP créé, ou NULL si la requête échoue. Vérifiez le numéro du QP (qp_num) dans le QP retourné.

ibv_destroy_qp() retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

NOTES

ibv_create_qp() échouera si une tentative de création d'un QP d'un type autre que IBV_QPT_RC ou IBV_QPT_UD associé à un SRQ est faite.

Les attributs max_recv_wr et max_recv_sge sont ignorés par ibv_create_qp() si le QP doit être associé à un SRQ.

ibv_destroy_qp() échoue si le QP est attaché à un groupe de multicast.

IBV_QPT_DRIVER ne représente pas un service spécifique et est utilisé pour une logique de QP spécifique au vendeur.
