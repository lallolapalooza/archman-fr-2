    ibase64buf(3bobcat)

    Créer un flux de sortie base64

    Nom

    ibase64buf — Créer un flux de sortie base64

    Synopsis

    #include <bobcat/ibase64buf>

    ibase64buf

    Description

    La classe ibase64buf permet de créer un flux de sortie qui encode les données en base64 au fur et à mesure qu'elles sont écrites. Elle hérite de std::streambuf et fournit une interface pour manipuler des données encodées en base64. Les données de sortie sont toujours remplies à 4 octets à la fois.

    Exemple

    
#include <iostream>
#include <string>
#include <bobcat/ibase64buf>

int main()
{
    std::string data = "Ceci est un test.";
    std::cout << "Données originales : " << data << std::endl;

    // Créer un flux de sortie avec un tampon de sortie base64
    bobcat::iBase64Buf i64buf(std::cout);
    std::ostream os(&i64buf);

    os << data;
    os.flush(); // Assurez-vous que toutes les données sont écrites et encodées

    std::cout << std::endl;

    return 0;
}
