IBV_DEVINFO(1) COMMANDES UTILISATEUR IBV_DEVINFO(1)

NOM

ibv_devinfo - interroger les périphériques RDMA

SYNTAXE

ibv_devinfo [-d appareil] [-i port] [-l] [-v]

DESCRIPTION

Afficher des informations sur les périphériques RDMA disponibles pour l'utilisation depuis l'espace utilisateur.

OPTIONS

-d, --ib-dev=APPAREIL
utiliser le périphérique IB APPAREIL (par défaut tous les périphériques)

-i, --ib-port=PORT interroger le port PORT (par défaut tous les ports)

-l, --list lister uniquement les noms des périphériques RDMA

-v, --verbose afficher toutes les informations disponibles sur les périphériques RDMA
