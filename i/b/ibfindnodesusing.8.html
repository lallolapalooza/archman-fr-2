ibfindnodesusing(8) Diagnostic Open IB ibfindnodesusing(8)

Nom

ibfindnodesusing - trouve une liste de nœuds finaux qui sont routés à travers le commutateur et le port spécifiés

SYNTAXE

ibfindnodesusing.pl [options] <guid_commutateur|nom_commutateur> <port>

DESCRIPTION

ibfindnodesusing.pl utilise ibroute et détecte les nœuds actuels qui sont routés à travers les deux directions du lien spécifié. Le lien est spécifié par une extrémité de port de commutateur ; le script trouve automatiquement l'extrémité distante.

OPTIONS

-h
afficher l'aide
-R
Recalculer les informations ibnetdiscover, c'est-à-dire ne pas utiliser les informations mises en cache. Cette option est plus lente mais devrait être utilisée si les outils de diagnostic n'ont pas été utilisés depuis un certain temps ou s'il y a d'autres raisons de croire que le réseau a changé.

-C <nom_ca> utiliser le nom_ca spécifié.

-P <port_ca> utiliser le port_ca spécifié.

FICHIERS

FICHIER DE CONFIGURATION

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines des options courantes pour tous les outils. Voir le fichier de configuration fourni pour les détails.

FORMAT DU FICHIER DE NOMMAGE DES NŒUDS

La carte des noms de nœuds est utilisée pour spécifier des noms conviviaux pour les nœuds dans la sortie. Les GUID sont utilisés pour effectuer la recherche.

Cette fonctionnalité est fournie par le paquet opensm-libs. Voir opensm(8) pour l'emplacement du fichier pour votre installation.

Généralement :

# commentaire
<guid> "<nom>"

# Spines

0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"

0x0008f10400400e31 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
