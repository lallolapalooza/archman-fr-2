IBCCQUERY(8) Diagnostics OpenIB IBCCQUERY(8)

Nom

IBCCQUERY - interroger les paramètres/informations de contrôle de congestion

Syntaxe

ibccquery [options_communes] [-c cckey] <op> <lid|guid> [port]

Description

ibccquery supporte l'interrogation des paramètres et autres informations liés au contrôle de congestion.

Options

Opérations actuellement supportées et leurs paramètres :
CongestionInfo (CI) <addr> CongestionKeyInfo (CK) <addr> CongestionLog (CL) <addr> SwitchCongestionSetting (SS) <addr> SwitchPortCongestionSetting (SP) <addr> [<portnum>] CACongestionSetting (CS) <addr> CongestionControlTable (CT) <addr> Timestamp (TI) <addr>

--cckey, -c <cckey> Spécifie une clé de contrôle de congestion (CC). Si aucune n'est spécifiée, la clé 0 est utilisée.

Indicateurs de débogage

-d
augmente le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
affiche les erreurs d'envoi et de réception (timeouts et autres)

-h, --help affiche le message d'utilisation

-v, --verbose
augmente le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version affiche les informations de version.

Indicateurs d'adressage

-G, --Guid L'adresse spécifiée est un GUID de port

-L, --Lid L'adresse spécifiée est un LID

-s, --sm_port <smlid> utilise 'smlid' comme LID cible pour les requêtes SA.

Indicateurs de sélection de port

-C, --Ca <nom_ca> utilise le nom_ca spécifié.

-P, --Port <port_ca> utilise le port_ca spécifié.

Sélection du port local

Support multi-port/multi-CA : lorsqu'aucun périphérique IB ou port n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port ACTIF.
2.
si non trouvé, le premier port ACTIF (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de répondre à la demande de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utilise le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # choisit le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utilise le deuxième port (actif/up) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utilise uniquement le port spécifié.

Indicateurs de configuration

-y, --m_key <clé>
utilise la M_key spécifiée pour les requêtes. Si une valeur non numérique (comme 'x') est spécifiée, une valeur sera demandée.

--config, -z <fichier_config> Spécifie un fichier de configuration alternatif.

Par défaut : /etc/infiniband-diags/ibdiag.conf

Fichiers

FICHIER DE CONFIGURATION

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines options communes à tous les outils. Voir le fichier de configuration fourni pour plus de détails.

Exemples

ibccquery CongestionInfo 3              # Informations de congestion par LID
ibccquery SwitchPortCongestionSetting 3 # Interroger tous les paramètres de congestion de port de commutateur
ibccquery SwitchPortCongestionSetting 3 1 # Interroger le paramètre de congestion de port de commutateur pour le port 1
