IBV_CREATE_SRQ(3) Manuel du programmeur Libibverbs IBV_CREATE_SRQ(3)

NOM

ibv_create_srq, ibv_destroy_srq - créer ou détruire une file de réception partagée (SRQ)

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_srq *ibv_create_srq(struct ibv_pd *pd, struct 
                               ibv_srq_init_attr *srq_init_attr);

int ibv_destroy_srq(struct ibv_srq *srq);

DESCRIPTION

ibv_create_srq() crée une file de réception partagée (SRQ) associée au domaine de protection pd. L'argument srq_init_attr est une structure ibv_srq_init_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_srq_init_attr {
void                   *srq_context;    /* Contexte associé à la SRQ */
struct ibv_srq_attr     attr;           /* Attributs de la SRQ */
};
struct ibv_srq_attr {
uint32_t                max_wr;         /* Nombre maximal de requêtes de travail (WR) en attente dans la SRQ demandé */
uint32_t                max_sge;        /* Nombre maximal d'éléments scatter par WR demandé */
uint32_t                srq_limit;      /* La valeur limite de la SRQ (non pertinent pour ibv_create_srq) */
};

La fonction ibv_create_srq() mettra à jour la structure srq_init_attr avec les valeurs d'origine de la SRQ qui a été créée ; les valeurs de max_wr et max_sge seront supérieures ou égales aux valeurs demandées.

ibv_destroy_srq() détruit la SRQ srq.

VALEUR RENVOYÉE

ibv_create_srq() renvoie un pointeur vers la SRQ créée, ou NULL si la demande échoue.

ibv_destroy_srq() renvoie 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

NOTES

ibv_destroy_srq() échoue si une paire de files d'attente est encore associée à cette SRQ.
