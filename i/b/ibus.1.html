IBUS(1) Commandes utilisateur IBUS(1)

NOM

ibus - utilitaire en ligne de commande pour ibus

SYNTAXE

ibus COMMANDE [OPTION]...

DESCRIPTION

IBus est un bus d'entrée intelligent. C'est un nouveau framework d'entrée pour le système d'exploitation Linux. Il fournit une interface utilisateur conviviale et complète pour les méthodes d'entrée. Il peut également aider les développeurs à créer facilement des méthodes d'entrée.

ibus est un utilitaire en ligne de commande qui peut redémarrer ou quitter ibus-daemon, obtenir ou définir le moteur ibus actuel ou lister les moteurs ibus.

Page d'accueil : https://github.com/ibus/ibus/wiki

COMMANDE

aide
Affiche la liste des commandes.
moteur [NOM_MOTEUR]
Affiche le moteur ibus actuel lorsque NOM_MOTEUR n'est pas fourni. Définit NOM_MOTEUR comme moteur ibus actuel.
quitter
Quitte ibus-daemon.
lister-moteur
Affiche la liste des moteurs ibus.
redemarrer [--type=TYPE|--verbose|--help]
Redémarre ibus-daemon. Cette commande essaie d'abord de redémarrer ibus-daemon via systemd, puis directement par défaut. Si --type=systemd est donné, elle tente de redémarrer uniquement via systemd. Si --type=direct est donné, elle tente de redémarrer uniquement avec une API IBus. Le bureau GNOME exécute ibus-daemon via systemd et les autres bureaux exécutent ibus-daemon directement.
demarrer [--type=TYPE|--verbose|--help]
Démarre ibus-daemon. Cette commande essaie d'abord de démarrer ibus-daemon via systemd, puis directement par défaut. Si --type=systemd est donné, elle tente de démarrer uniquement en tant que processus d'arrière-plan via systemd. Si --type=direct est donné, elle tente de démarrer directement uniquement en tant que processus de premier plan et les autres options de la commande ibus sont envoyées à ibus-daemon. Par exemple, ibus demarrer --type=direct --xim & Le bureau GNOME exécute ibus-daemon via systemd et les autres bureaux exécutent ibus-daemon directement.
version
Affiche la version d'ibus.
lire-cache [--system|--fichier=FICHIER|--help]
Affiche le contenu du cache du registre utilisateur si --system n'est pas donné. Affiche le contenu du cache du registre système si --system est donné. Affiche le contenu du cache du registre personnalisé FICHIER si --fichier=FICHIER est donné.
ecrire-cache [--system|--fichier=FICHIER|--help]
Enregistre le cache du registre utilisateur si --system n'est pas donné. Enregistre le cache du registre système si --system est donné. Enregistre le cache du registre personnalisé FICHIER si --fichier=FICHIER est donné.

Par défaut, il lit les fichiers XML des composants du répertoire standard des composants (/usr/share/ibus/component). Vous pouvez définir la variable d'environnement IBUS_COMPONENT_PATH pour des répertoires de composants personnalisés, séparés par ':'.

adresse
Affiche l'adresse D-Bus de ibus-daemon.
lire-config
Affiche les valeurs de configuration dans un fichier de configuration gsettings.
reinitialiser-config
Réinitialise les valeurs de configuration utilisateur aux valeurs par défaut dans un fichier de configuration gsettings.
surveiller
En cours de développement.
emoji [--font=POLICE|--lang=LANGUE|--help|--partial-match]
Lance IBus Emojier ( ibus-emoji (1) ) et enregistre l'emoji sélectionné dans votre presse-papiers. Peut choisir une police d'emoji avec l'option --font. Peut choisir une langue pour les annotations emoji avec l'option --lang. Si LANG="en", IBus Emojier charge /usr/share/ibus/dicts/emoji-en.dict . L'option --partial-match permet de faire correspondre les annotations avec une chaîne partielle. Ces paramètres sont disponibles avec l'utilitaire ibus-setup (1).
im-module [--type=TYPE|--help]
Affiche une valeur de module d'entrée interne dans une application GTK virtuelle. Si IBus est installé et configuré correctement, la sortie est "ibus". Cette sous-commande est utile pour certains utilisateurs qui compilent IBus à partir des codes sources et vérifient les configurations. Actuellement, la sous-commande prend en charge uniquement les applications GTK et la valeur par défaut est GTK3. Si vous souhaitez vérifier une application GTK4, vous pouvez spécifier l'option --type=gtk4 et choisir entre "gtk2", "gtk3" et "gtk4".
