IBCCCONFIG(8) Diagnostics OpenIB IBCCCONFIG(8)

Nom

IBCCCONFIG - configurer les paramètres de contrôle de congestion

Syntaxe

ibccconfig [options_communes] [-c cckey] <op> <lid|guid> [port]

Description

ibccconfig prend en charge la configuration des paramètres de contrôle de congestion sur les commutateurs et les HCA.

AVERTISSEMENT -- Vous devez comprendre ce que vous faites avant d'utiliser cet outil. Une mauvaise utilisation de cet outil pourrait entraîner une rupture du tissu.

Options

Opérations actuellement supportées et leurs paramètres :
CongestionKeyInfo (CK) <lid|guid> <cckey> <cckeyprotectbit> <cckeyleaseperiod> <cckeyviolations> SwitchCongestionSetting (SS) <lid|guid> <controlmap> <victimmask> <creditmask> <threshold> <packetsize> <csthreshold> <csreturndelay> <markingrate> SwitchPortCongestionSetting (SP) <lid|guid> <portnum> <valid> <control_type> <threshold> <packet_size> <cong_parm_marking_rate> CACongestionSetting (CS) <lid|guid> <port_control> <control_map> <ccti_timer> <ccti_increase> <trigger_threshold> <ccti_min> CongestionControlTable (CT) <lid|guid> <cctilimit> <index> <cctentry> <cctentry> ...

--cckey, -c, <cckey> Spécifier une clé de contrôle de congestion (CC). Si aucune n'est spécifiée, une clé de 0 est utilisée.

Drapeaux de débogage

-d
augmenter le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
afficher les erreurs d'envoi et de réception (timeouts et autres)

-h, --help afficher le message d'aide

-v, --verbose
augmenter le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version afficher les informations de version.

Drapeaux d'adressage

-G, --Guid L'adresse spécifiée est un GUID de port

-L, --Lid L'adresse spécifiée est un LID

-s, --sm_port <smlid> utiliser 'smlid' comme lid cible pour les requêtes SA.

Drapeaux de sélection de port

-C, --Ca <ca_name> utiliser le ca_name spécifié.

-P, --Port <ca_port> utiliser le ca_port spécifié.

Sélection de port local

Prise en charge de plusieurs ports/plusieurs CA : lorsqu'aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port ACTIF.
2.
sinon, le premier port HAUT (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de satisfaire la demande de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utiliser le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utiliser le deuxième port (actif/haut) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser le port spécifié uniquement.

Drapeaux de configuration

-y, --m_key <key>
utiliser la clé M spécifiée pour les requêtes. Si une valeur non numérique (comme 'x') est spécifiée, une valeur sera demandée.

--config, -z <fichier_config> Spécifier un fichier de configuration alternatif.

Défaut : /etc/infiniband-diags/ibdiag.conf

Exemples

ibccconfig SwitchCongestionSetting 2 0x1F 0x1FFFFFFFFF 0x0 0xF 8 0 0:0 1  # Configurer les paramètres de congestion du commutateur
ibccconfig CACongestionSetting 1 0 0x3 150 1 0 0                          # Configurer les paramètres de congestion CA vers SL 0 et SL 1
ibccconfig CACongestionSetting 1 0 0x4 200 1 0 0                          # Configurer les paramètres de congestion CA vers SL 2
ibccconfig CongestionControlTable 1 63 0 0:0 0:1 ...                      # Configurer le premier bloc de la table de contrôle de congestion
ibccconfig CongestionControlTable 1 127 0 0:64 0:65 ...                   # Configurer le deuxième bloc de la table de contrôle de congestion

Fichiers

FICHIER DE CONFIGURATION

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines des options communes à tous les outils. Voir le fichier de configuration fourni pour les détails.
