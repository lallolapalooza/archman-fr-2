NOM

ibv_import_mr - importer une MR à partir d'une ibv_pd donnée

ibv_unimport_mr - désimporter une MR

SYNTAXE

#include <infiniband/verbs.h>
struct ibv_mr *ibv_import_mr(struct ibv_pd *pd, uint32_t mr_handle);
void ibv_unimport_mr(struct ibv_mr *mr)

DESCRIPTION

ibv_import_mr() renvoie une région mémoire (MR) associée au mr_handle donné dans le contexte RDMA associé à la pd donnée.

La valeur du mr_handle en entrée doit être un handle valide du noyau pour un objet MR dans le contexte RDMA associé. Il peut être obtenu à partir de la MR d'origine en accédant à la valeur du membre ibv_mr->handle.

ibv_unimport_mr() désimporte la MR. Une fois l'utilisation de la MR terminée, ibv_dereg_mr() ou ibv_unimport_mr() doit être appelé. La première fonction contactera le noyau pour détruire l'objet, tandis que la seconde nettoiera ce qui est nécessaire/l'opposé de l'importation sans contacter le noyau.

Il incombe à l'application de coordonner tous les ibv_context(s) qui utilisent cette MR. Une fois la destruction effectuée, aucun autre processus ne peut toucher l'objet, sauf pour le désimportation. Tous les utilisateurs du contexte doivent collaborer pour garantir cela.

VALEUR DE RETOUR

ibv_import_mr() renvoie un pointeur vers la MR allouée, ou NULL si la requête échoue.

NOTES

Le champ addr dans la MR importée n'est pas applicable, une valeur NULL est attendue.
