NOM

ibv_rereg_mr - réenregistrer une région mémoire (MR)

SYNOPSIS

#include <infiniband/verbs.h>
int ibv_rereg_mr(struct ibv_mr *mr,
                 int flags,
                 struct ibv_pd *pd,
                 void *addr,
                 size_t length,
                 int access);

DESCRIPTION

ibv_rereg_mr() modifie les attributs d'une région mémoire (MR) existante mr. Conceptuellement, cet appel effectue les fonctions désenregistrer la région mémoire suivie de l'enregistrement de la région mémoire. Dans la mesure du possible, les ressources sont réutilisées au lieu d'être désallouées et réallouées.

flags est un masque de bits utilisé pour indiquer quelles propriétés de la région mémoire sont modifiées. Les drapeaux doivent être une combinaison (champ de bits) de :

IBV_REREG_MR_CHANGE_TRANSLATION
Changer la translation (emplacement et longueur)
IBV_REREG_MR_CHANGE_PD
Changer le domaine de protection
IBV_REREG_MR_CHANGE_ACCESS
Changer les drapeaux d'accès

Lorsque IBV_REREG_MR_CHANGE_PD est utilisé, pd représente le nouveau domaine de protection (PD) auquel cette MR doit être enregistrée.

Lorsque IBV_REREG_MR_CHANGE_TRANSLATION est utilisé, addr représente l'adresse virtuelle (pointeur dans l'espace utilisateur) de la nouvelle MR, tandis que length représente sa longueur.

Les drapeaux d'accès et autres sont représentés dans le champ access. Ce champ décrit les attributs de protection mémoire souhaités ; il est soit 0, soit le OU logique (OR bit à bit) d'un ou plusieurs des ibv_access_flags.

VALEUR RETOUR

ibv_rereg_mr() renvoie 0 en cas de succès, sinon une erreur s'est produite, enum ibv_rereg_mr_err_code représente l'erreur comme ci-dessous.

IBV_REREG_MR_ERR_INPUT - L'ancienne MR est valide, une erreur d'entrée a été détectée par libibverbs.

IBV_REREG_MR_ERR_DONT_FORK_NEW - L'ancienne MR est valide, échec via don’t fork sur une nouvelle plage d'adresses.

IBV_REREG_MR_ERR_DO_FORK_OLD - La nouvelle MR est valide, échec via do fork sur l'ancienne plage d'adresses.

IBV_REREG_MR_ERR_CMD - La MR ne doit pas être utilisée, erreur de commande.

IBV_REREG_MR_ERR_CMD_AND_DO_FORK_NEW - La MR ne doit pas être utilisée, erreur de commande, état de fork invalide sur la nouvelle plage d'adresses.

NOTES

Même en cas d'échec, l'utilisateur doit toujours appeler ibv_dereg_mr sur cette MR.

VOIR AUSSI

ibv_dereg_mr(3), ibv_reg_mr(3)
