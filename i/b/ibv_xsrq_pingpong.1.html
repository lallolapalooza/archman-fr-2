IBV_XSRQ_PINGPONG(1) COMMANDES UTILISATEUR IBV_XSRQ_PINGPONG(1)

NOM

ibv_xsrq_pingpong - Test simple d'InfiniBand avec file d'attente de réception partagée (SRQ)

SYNTAXE

ibv_xsrq_pingpong [-p port] [-d device] [-i port_ib] [-s taille] [-m mtu] [-c clients] [-n nb_tests] [-l sl] [-e] [-g index_gid] NOM_HOTE

ibv_xsrq_pingpong [-p port] [-d device] [-i port_ib] [-s taille] [-m mtu] [-c clients] [-n nb_tests] [-l sl] [-e] [-g index_gid]

DESCRIPTION

Exécute un test simple de ping-pong sur InfiniBand via le service de transport connecté fiable étendu (XRC), en utilisant une file d'attente de réception partagée (SRQ).

OPTIONS

-p, --port=PORT
utilise le port TCP PORT pour la synchronisation initiale (par défaut 18515)
-d, --ib-dev=APPAREIL
utilise le périphérique IB APPAREIL (par défaut le premier périphérique trouvé)
-i, --ib-port=PORT
utilise le port IB PORT (par défaut le port 1)
-s, --size=TAILLE
messages de ping-pong de taille TAILLE (par défaut 4096)
-m, --mtu=MTU
utilise une taille MTU de chemin de MTU (par défaut 2048)
-c, --clients=CLIENTS
nombre de clients CLIENTS (sur le serveur uniquement, par défaut 1)
-n, --num-tests=NB_TESTS
effectue NB_TESTS tests par client (par défaut 5)
-l, --sl=SL
utilise SL comme valeur de niveau de service (par défaut 0)
-e, --events
attend pendant la recherche d'événements de complétion de travail (par défaut, sondage pour les complétions)
-g, --gid-idx=INDEX_GID
port local INDEX_GID

VOIR AUSSI

ibv_rc_pingpong(1), ibv_uc_pingpong(1), ibv_ud_pingpong(1) ibv_srq_pingpong(1)

BOGUES

La synchronisation réseau entre les instances client et serveur est faible et n'empêche pas l'utilisation d'options incompatibles sur les deux instances. La méthode utilisée pour récupérer les complétions de travail n'est pas strictement correcte et des conditions de concurrence peuvent provoquer des échecs sur certains systèmes.
