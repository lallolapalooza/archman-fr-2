NOM

ibus-table-createdb - crée une base de données ibus-table à partir d'une source de table

SYNTAXE

ibus-table-createdb [ -n nom | --nom nom ] [ -s source | --source source ] [ -e extra | --extra extra ] [ -p pinyin | --pinyin pinyin ] [ -o ] [ --no-create-index ] [ -i ] [ --create-index-only ] [ -d ] [ --debug ]

DESCRIPTION

ibus-table-createdb crée une base de données pour ibus-table à partir d'une table source.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-n --nom fichier-base-de-donnees
fichier-base-de-donnees spécifie le nom du fichier pour la base de données binaire pour l'IME. La valeur par défaut est ''. Si le nom du fichier de la base de données n'est pas spécifié, le nom du fichier source avant le premier '.' sera suivi de '.db' et cela sera utilisé comme nom de fichier de la base de données.
-s --source fichier-source
fichier-source spécifie le fichier qui contient la source de l'IME. La valeur par défaut est ''.
-e --extra fichier-mots-supplementaires
fichier-mots-supplementaires spécifie le nom du fichier pour les mots supplémentaires pour l'IME. La valeur par défaut est ''.
-p --pinyin fichier-pinyin
fichier-pinyin spécifie le fichier source pour le pinyin. La valeur par défaut est '/usr/share/ibus-table/data/pinyin_table.txt.bz2'.
-o --no-create-index
Ne pas créer d'index pour une base de données (Uniquement à des fins de distribution, un utilisateur normal ne doit pas utiliser ce drapeau !)
-i --create-index-only
Créer uniquement un index pour une base de données existante. La spécification du nom du fichier de la base de données binaire avec l'option -n ou --nom est requise lorsque cette option est utilisée.
-d --debug
Afficher des messages de débogage supplémentaires.

EXEMPLES

ibus-table-createdb -n ipa-x-sampa.db -s ipa-x-sampa.txt
Crée la base de données binaire ``ipa-x-sampa.db'' à partir du fichier source ``ipa-x-sampa.txt''.
ibus-table-createdb -i -n ipa-x-sampa.db
Crée un index pour la base de données ``ipa-x-sampa.db''.
