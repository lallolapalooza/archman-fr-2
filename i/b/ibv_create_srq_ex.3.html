IBV_CREATE_SRQ_EX(3) Manuel du programmeur Libibverbs IBV_CREATE_SRQ_EX(3)

NOM

ibv_create_srq_ex, ibv_destroy_srq - créer ou détruire une file de réception partagée (SRQ)

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_srq *ibv_create_srq_ex(struct ibv_context *context, struct 
                               ibv_srq_init_attr_ex *srq_init_attr_ex);

int ibv_destroy_srq(struct ibv_srq *srq);

DESCRIPTION

ibv_create_srq_ex() crée une file de réception partagée (SRQ) supportant les modes basique et xrc. L'argument srq_init_attr_ex est une structure ibv_srq_init_attr_ex, telle que définie dans <infiniband/verbs.h>.

struct ibv_srq_init_attr_ex {
void                   *srq_context;    /* Contexte associé au SRQ */
struct ibv_srq_attr     attr;           /* Attributs du SRQ */
uint32_t                comp_mask;      /* Identifie les champs valides */
enum ibv_srq_type       srq_type;       /* Basique / XRC / correspondance de tags */
struct ibv_pd          *pd;             /* PD associé au SRQ */
struct ibv_xrcd        *xrcd;           /* Domaine XRC à associer au SRQ */
struct ibv_cq          *cq;             /* CQ à associer au SRQ pour le mode XRC */
struct ibv_tm_cap       tm_cap;         /* Attributs de correspondance de tags */
};
struct ibv_srq_attr {
uint32_t                max_wr;         /* Nombre maximal demandé de requêtes de travail (WRs) en attente dans le SRQ */
uint32_t                max_sge;        /* Nombre maximal demandé d'éléments de diffusion par WR */
uint32_t                srq_limit;      /* La valeur limite du SRQ */
};
struct ibv_tm_cap {
uint32_t                max_num_tags;   /* Taille de la liste de correspondance de tags */
uint32_t                max_ops;        /* Nombre d'opérations de liste de tags en attente */
};

La fonction ibv_create_srq_ex() mettra à jour la structure srq_init_attr_ex avec les valeurs originales du SRQ qui a été créé ; les valeurs de max_wr et max_sge seront supérieures ou égales aux valeurs demandées.

ibv_destroy_srq() détruit le SRQ srq.

VALEUR DE RETOUR

ibv_create_srq_ex() renvoie un pointeur vers le SRQ créé, ou NULL si la requête échoue.

ibv_destroy_srq() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

NOTES

ibv_destroy_srq() échoue si une paire de files d'attente est encore associée à ce SRQ.

VOIR AUSSI

ibv_alloc_pd(3), ibv_modify_srq(3), ibv_query_srq(3)
