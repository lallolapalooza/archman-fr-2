IBV_QUERY_GID_EX(3) Manuel du programmeur Libibverbs IBV_QUERY_GID_EX(3)

NOM

ibv_query_gid_ex - Interroger une entrée de la table GID du port InfiniBand

SYNTAXE

#include <infiniband/verbs.h>
int ibv_query_gid_ex(struct ibv_context *context,
                     uint32_t port_num,
                     uint32_t gid_index,
                     struct ibv_gid_entry *entry,
                     uint32_t flags);

DESCRIPTION

ibv_query_gid_ex() renvoie l'entrée GID à entry pour gid_index du port port_num pour le contexte de périphérique context.

ARGUMENTS

context
Le contexte du périphérique à interroger.
port_num
Le numéro du port dont la table GID doit être interrogée.
gid_index
L'index de l'entrée de la table GID à interroger.
## Argument entry
Une structure ibv_gid_entry, telle que définie dans <infiniband/verbs.h>.
struct ibv_gid_entry {
    union ibv_gid gid;
    uint32_t gid_index;
    uint32_t port_num;
    uint32_t gid_type;
    uint32_t ndev_ifindex;
};

gid

    L'entrée GID.

gid_index

    L'index de la table GID de cette entrée.

port_num

    Le numéro du port auquel ce GID appartient.

gid_type

    enum ibv_gid_type, peut être l'un de IBV_GID_TYPE_IB, IBV_GID_TYPE_ROCE_V1 ou IBV_GID_TYPE_ROCE_V2.

ndev_ifindex

    L'index de l'interface du périphérique réseau associé à ce GID.
    Il est à 0 s'il n'y a pas de périphérique réseau associé.
flags
Champs supplémentaires à interroger après ndev_ifindex, doit être 0 pour l'instant.

VALEUR DE RETOUR

ibv_query_gid_ex() renvoie 0 en cas de succès ou la valeur d'errno en cas d'erreur.

ERREURS

ENODATA
gid_index est dans la taille de la table GID du port port_num mais il n'y a pas de données dans cet index.

VOIR AUSSI

ibv_open_device(3), ibv_query_device(3), ibv_query_pkey(3), ibv_query_port(3), ibv_query_gid_table(3)
