ibsysstat(8) Diagnostic InfiniBand ibsysstat(8)

Nom

ibsysstat - état système sur une adresse InfiniBand

SYNOPSIS

ibsysstat [options] <lid | guid de destination> [<op>]

DESCRIPTION

ibsysstat utilise des MADS propriétaires pour valider la connectivité entre les nœuds IB et obtenir d'autres informations sur le nœud IB. ibsysstat fonctionne en mode client/serveur. Par défaut, il s'exécute en mode client.

OPTIONS

Opérations actuellement prises en charge :

ping \- vérifier la connectivité avec le serveur (par défaut)
host \- obtenir des informations sur l'hôte depuis le serveur
cpu  \- obtenir des informations sur le processeur depuis le serveur
-o, --oui
utilise le numéro OUI spécifié pour multiplexer les MADS propriétaires
-S, --Server
démarrer en mode serveur (ne pas retourner)

Flags d'adressage

-G, --Guid L'adresse spécifiée est un GUID de port

-L, --Lid L'adresse spécifiée est une LID

-s, --sm_port <smlid> utilise 'smlid' comme LID cible pour les requêtes SA.

Flags de sélection de port

-C, --Ca <nom_ca> utilise le nom_ca spécifié.

-P, --Port <port_ca> utilise le port_ca spécifié.

Sélection du port local

Prise en charge de plusieurs ports/plusieurs CA : lorsqu'aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port ACTIF.
2.
si non trouvé, le premier port HAUT (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de répondre à la demande de l'utilisateur et échouera si cela n'est pas possible.

Par exemple :

ibaddr                 # utilise le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # sélectionne uniquement le meilleur port de "mthca1".
ibaddr -P 2            # utilise le deuxième port (actif/haut) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utilise uniquement le port spécifié.

Flags de débogage

-d
augmente le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
affiche les erreurs d'envoi et de réception (timeouts et autres)

-h, --help affiche le message d'utilisation

-v, --verbose
augmente le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version affiche les informations de version.

Flags de configuration

-t, --timeout <timeout_ms> remplace le délai d'attente par défaut pour les MADS sollicités.

--config, -z <fichier_config> spécifie un fichier de configuration alternatif.

Défaut : /etc/infiniband-diags/ibdiag.conf

FICHIERS

FICHIER CONFIG

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines des options courantes pour tous les outils. Voir le fichier de configuration fourni pour plus de détails.
