IBV_QUERY_GID_TABLE(3) Manuel du programmeur Libibverbs IBV_QUERY_GID_TABLE(3)

NOM

ibv_query_gid_table - interroger la table GID d'un périphérique InfiniBand

SYNTAXE

#include <infiniband/verbs.h>
ssize_t ibv_query_gid_table(struct ibv_context *context,
                            struct ibv_gid_entry *entries,
                            size_t max_entries,
                            uint32_t flags);

DESCRIPTION

ibv_query_gid_table() renvoie les entrées valides de la table GID du contexte du périphérique RDMA context au pointeur entries.

L'appelant doit allouer le tableau entries pour les entrées de la table GID qu'il souhaite interroger. Cette API ne renvoie que les entrées valides de la table GID.

L'appelant doit passer un nombre d'entrées non nul à max_entries, correspondant à la taille du tableau entries.

Le tableau entries doit être alloué de manière à pouvoir contenir toutes les entrées valides de la table GID du périphérique. S'il y a plus d'entrées GID valides que la valeur fournie pour max_entries et le tableau entries, l'appel échouera. Par exemple, si un périphérique RDMA context a un total de 10 entrées GID valides, entries doit être alloué pour au moins 10 entrées, et max_entries doit être défini en conséquence.

ARGUMENTS

context
Le contexte du périphérique à interroger.
entries
Tableau de structures ibv_gid_entry où les entrées GID sont renvoyées. Veuillez consulter la page man ibv_query_gid_ex(3) pour ibv_gid_entry.
max_entries
Nombre maximum d'entrées pouvant être renvoyées.
flags
Champs supplémentaires à interroger après entries->ndev_ifindex, doit être 0 pour le moment.

VALEUR RENVOYÉE

ibv_query_gid_table() renvoie le nombre d'entrées qui ont été lues en cas de succès, ou une valeur errno négative en cas d'erreur. Le nombre d'entrées renvoyées est inférieur ou égal à max_entries.
