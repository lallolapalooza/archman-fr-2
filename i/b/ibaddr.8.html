IBADDR(8) Diagnostics OpenIB IBADDR(8)

Nom

IBADDR - interroger l'adresse (les adresses) InfiniBand

Syntaxe

ibaddr [options]

Description

Affiche le lid (et la plage) ainsi que l'adresse GID du port spécifié (par chemin DR, lid ou GUID) ou le port local par défaut.

Note : cet utilitaire peut être utilisé comme un simple résolveur d'adresses.

Options

--gid_show, -g afficher uniquement l'adresse gid

--lid_show, -l afficher uniquement la plage de lid

--Lid_show, -L afficher uniquement la plage de lid (en décimal)

Drapeaux d'adressage

-D, --Direct L'adresse spécifiée est une route dirigée

Exemples:
   [options] -D [options] "0"          # port local
   [options] -D [options] "0,1,2,1,4"  # sortie via le port 1, puis 2, ...
   (Notez que le deuxième nombre dans le chemin spécifié doit correspondre au port utilisé.
   Ceci peut être spécifié en utilisant le drapeau de sélection de port '-P' ou le
   port trouvé via le processus de sélection automatique.)

-G, --Guid L'adresse spécifiée est un GUID de port

-s, --sm_port <smlid> utiliser 'smlid' comme lid cible pour les requêtes SA.

Drapeaux de débogage

-d
augmenter le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
afficher les erreurs d'envoi et de réception (timeouts et autres)

-h, --help afficher le message d'utilisation

-v, --verbose
augmenter le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version afficher les informations de version.

Drapeaux de sélection de port

-C, --Ca <nom_ca> utiliser le nom_ca spécifié.

-P, --Port <ca_port> utiliser le ca_port spécifié.

Sélection du port local

Support multi-port/multi-CA : lorsqu'aucun périphérique IB ou port n'est spécifié (voir les "paramètres umad locaux" ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port qui est ACTIF.
2.
sinon, le premier port qui est HAUT (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de satisfaire la demande de l'utilisateur, et échouera si cela n'est pas possible.

Par exemple :

ibaddr                  # utiliser le premier port (critère #1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utiliser le deuxième port (actif/haut) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser uniquement le port spécifié.

Drapeaux de configuration

-y, --m_key <clé>
utiliser la M_key spécifiée pour les requêtes. Si une valeur non numérique (comme 'x') est spécifiée, une valeur sera demandée.

-t, --timeout <timeout_ms> remplacer le timeout par défaut pour les mads sollicités.

--config, -z <fichier_config> spécifier un fichier de configuration alternatif.

Défaut : /etc/infiniband-diags/ibdiag.conf

Fichiers

FICHIER DE CONFIG

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines options courantes pour tous les outils. Voir le fichier de configuration fourni pour les détails.

Exemples

ibaddr                  # adresse du port local
ibaddr 32               # afficher la plage de lid et le gid du lid 32
ibaddr -G 0x8f1040023   # idem mais en utilisant l'adresse guid
ibaddr -l 32            # afficher uniquement la plage de lid
ibaddr -L 32            # afficher uniquement la plage de lid en décimal
ibaddr -g 32            # afficher uniquement l'adresse gid
