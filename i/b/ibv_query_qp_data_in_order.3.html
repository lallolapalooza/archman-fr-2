NOM

ibv_query_qp_data_in_order - vérifier si les données qp sont garanties d'être dans l'ordre.

SYNTAXE

#include <infiniband/verbs.h>
int ibv_query_qp_data_in_order(struct ibv_qp *qp, enum ibv_wr_opcode op, uint32_t flags);

DESCRIPTION

ibv_query_qp_data_in_order() vérifie si les données WQE sont garanties d'être écrites dans l'ordre, et donc si le lecteur peut sonder les données au lieu de sonder l'achèvement. Cette fonction indique que les données sont écrites dans l'ordre au sein de chaque WQE, mais ne peut pas être utilisée pour déterminer l'ordre entre des WQE distincts. Cette fonction décrit l'ordre côté réception du QP, pas côté envoi.

ARGUMENTS

qp
La paire de files d'attente (QP) locale à interroger.
op
Le type d'opération à interroger. Différents types d'opérations peuvent écrire les données dans un ordre différent.
Pour les opérations de lecture RDMA : décrit l'ordre des lectures RDMA publiées sur ce QP local. Pour les opérations d'écriture RDMA : décrit l'ordre des écritures RDMA distantes effectuées dans ce QP local. Pour les opérations d'envoi RDMA : décrit l'ordre des envois RDMA distants effectués dans ce QP local. Cette fonction ne doit pas être utilisée pour déterminer l'ordre des autres types d'opérations.
flags
Les drapeaux sont utilisés pour sélectionner un type d'interrogation. Valeurs prises en charge :

IBV_QUERY_QP_DATA_IN_ORDER_RETURN_CAPS - Interroger les capacités prises en charge et renvoyer un vecteur de capacités.

IBV_QUERY_QP_DATA_IN_ORDER_DEVICE_ONLY - Permet d'interroger uniquement le support côté périphérique RDMA pour la sémantique data-in-order sans imposer de restrictions d'architecture CPU hôte. Il incombe à l'application de garantir le support de la sémantique data-in-order pour le CPU hôte ou le périphérique récepteur.

Passer 0 équivaut à utiliser IBV_QUERY_QP_DATA_IN_ORDER_RETURN_CAPS et à vérifier le support de IBV_QUERY_QP_DATA_IN_ORDER_WHOLE_MSG.

VALEUR DE RETOUR

La valeur de retour de ibv_query_qp_data_in_order() est déterminée par les drapeaux. Pour chaque bit de capacité, 1 est retourné si les données sont garanties d'être écrites dans l'ordre pour l'opération et le type sélectionnés, 0 sinon. Si le drapeau IBV_QUERY_QP_DATA_IN_ORDER_RETURN_CAPS est utilisé, la valeur de retour peut contenir les capacités suivantes :

IBV_QUERY_QP_DATA_IN_ORDER_WHOLE_MSG - Toutes les données sont écrites dans l'ordre.

IBV_QUERY_QP_DATA_IN_ORDER_ALIGNED_128_BYTES - Chaque bloc aligné sur 128 octets est écrit dans l'ordre.

Si les drapeaux valent 0, la fonction retournera 1 si IBV_QUERY_QP_DATA_IN_ORDER_WHOLE_MSG est pris en charge et 0 sinon.

NOTES

La valeur de retour n'est valide que lorsque les données sont lues par le CPU et que le MR à ordre relâché n'est pas la cible du transfert.
