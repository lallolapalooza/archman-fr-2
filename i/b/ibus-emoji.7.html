IBUS EMOJI(7) Commandes utilisateur IBUS EMOJI(7)

NOM

ibus-emoji - Appeler l'utilitaire d'emoji IBus par IBus Emojier

SYNTAXE

/usr/libexec/ibus-ui-emojier [OPTION]...

DESCRIPTION

IBus Emojier fournit une interface graphique pour sélectionner un emoji en tapant une annotation d'emoji ou en choisissant un caractère par un clic de souris. Il est conçu pour fonctionner comme une fenêtre de recherche IBus étendue utilisant les touches Espace, Entrée et les flèches. L'entrée de texte accepte une annotation d'emoji ou des points Unicode. Si le panneau IBus est lancé, le panneau IBus appelle IBus Emojier avec une touche de raccourci ou le menu clic droit et sort l'emoji sélectionné dans le texte précédemment focalisé d'une application. Si le panneau IBus n'est pas disponible, comme sur le bureau GNOME, vous pouvez toujours utiliser la commande ibus emoji pour lancer IBus Emojier, qui enregistre l'emoji sélectionné dans votre presse-papiers, vous permettant de le coller avec une touche de collage comme Ctrl-v.

Consultez la section emoji de ibus (1) pour les options de ligne de commande.

Page d'accueil : https://github.com/ibus/ibus/wiki

RÉGLAGES

LANGUE DES ANNOTATIONS
Vous pouvez choisir une langue pour les annotations d'emoji avec ibus-setup (1).
POLICE
Vous pouvez choisir une police d'emoji avec ibus-setup (1). Par exemple, la police "Noto Color Emoji", "Android Emoji".

OPÉRATIONS CLAVIER

Super-Majuscule-. ou Super-Majuscule-;
Lance IBus Emojier. La touche de raccourci peut être personnalisée via ibus-setup (1).
Flèches gauche, droite, Ctrl-b ou Ctrl-f
Sélectionne la catégorie ou l'emoji suivant à gauche ou à droite dans la liste si aucune annotation n'est tapée. Sinon, déplace le curseur immédiatement à gauche ou à droite dans l'annotation tapée.
Flèches bas, haut, Ctrl-n ou Ctrl-p
Sélectionne la catégorie ou l'emoji suivant en haut ou en bas dans la liste
Entrée
Valide l'emoji sélectionné.
Échap
Retourne à la liste des catégories depuis la liste des emojis, efface l'annotation tapée et ferme IBus Emojier.
Espace
Sélectionne la catégorie ou l'emoji suivant à gauche dans la liste. Si Shift-Espace est tapé, un caractère d'espace peut être inséré entre les mots d'une annotation ou des points Unicode. Par exemple, 1f466 Shift-Espace 1f3fb
PageSuivante, PagePrécédente, Ctrl-Maj-n ou Ctrl-Maj-p
Passe à la page suivante ou précédente dans la liste des catégories ou des emojis.
Début, Fin, Ctrl-h ou Ctrl-e
Sélectionne le premier ou le dernier emoji dans la liste si aucune annotation n'est tapée. Sinon, déplace le curseur au début ou à la fin de l'annotation tapée.
Ctrl-u
Efface l'annotation tapée.
Ctrl-x, Ctrl-v ou Ctrl-c
Coupe l'annotation sélectionnée vers le presse-papiers avec Ctrl-x. Colle le contenu du presse-papiers dans le champ de saisie de l'annotation avec Ctrl-v. Copie l'annotation sélectionnée dans le presse-papiers avec Ctrl-c.
Ctrl-Maj-c
Copie l'emoji sélectionné dans le presse-papiers.
