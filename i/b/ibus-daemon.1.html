NOM

ibus-daemon - programme démon pour ibus

SYNTAXE

ibus-daemon [OPTION]...

DESCRIPTION

IBus est un Intelligent Input Bus. C'est un nouveau framework d'entrée pour le système d'exploitation Linux. Il fournit une interface utilisateur de méthode d'entrée pleinement fonctionnelle et conviviale. Il peut également aider les développeurs à créer facilement des méthodes d'entrée.

ibus-daemon est un programme démon pour ibus et c'est aussi un programme de démarrage pour les utilisateurs afin d'activer le démon ibus, les moteurs et le panneau.

Options d'aide :

-h, --help
Affiche les options d'aide

Options d'application :

-d, --daemonize
exécute ibus en tant que processus d'arrière-plan.
-s, --single
n'exécute pas le panneau et le module de configuration.
-x, --xim
exécute le serveur XIM d'ibus.
-n, --desktop=nom
spécifie le nom de la session de bureau. [défaut=gnome]
-p, --panel=ligne_de_commande
spécifie la ligne de commande du programme du panneau.
-c, --config=ligne_de_commande
spécifie la ligne de commande du programme de configuration.
-a, --address=adresse
spécifie l'adresse du démon ibus.
-r, --replace
s'il existe un ancien ibus-daemon en cours d'exécution, il sera remplacé.
-t, --cache=mode [défaut=auto]
force le ré-analyse des composants et la recréation du cache d'enregistrement. auto, refresh, none sont disponibles.
-o, --timeout=délai [défaut=2000]
délai de réponse dbus en millisecondes.
-v, --verbose
verbeux.
