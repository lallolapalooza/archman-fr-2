IBV_MODIFY_QP_RATE_LIMIT(3) Manuel du programmeur Libibverbs IBV_MODIFY_QP_RATE_LIMIT(3)

NOM

ibv_modify_qp_rate_limit - modifier les attributs de limitation du débit d'envoi d'une paire de files d'attente (QP)

SYNTAXE

#include <infiniband/verbs.h>

int ibv_modify_qp_rate_limit(struct ibv_qp *qp, struct ibv_qp_rate_limit_attr *attr);

DESCRIPTION

ibv_modify_qp_rate_limit() modifie les attributs de façonnage des paquets de limitation du débit d'envoi du QP qp avec les attributs de attr. L'argument attr est une structure ibv_qp_rate_limit_attr, telle que définie dans <infiniband/verbs.h>.

Le rate_limit définit le débit d'envoi MAX que ce QP enverra tant que le lien n'est pas bloqué et qu'il y a des requêtes de travail dans la file d'attente d'envoi.

Un contrôle plus fin pour façonner la limitation du débit d'un QP est obtenu en définissant le max_burst_sz, la taille maximale des octets d'une seule rafale, et le typical_pkt_sz, la taille typique des octets des paquets. Ceux-ci permettent au périphérique d'ajuster le délai inter-rafales requis pour façonner correctement la planification des envois vers le fil pour atteindre les exigences de l'application demandées.

Définir une valeur de 0 pour max_burst_sz ou typical_pkt_sz utilisera les valeurs par défaut du périphérique. typical_pkt_sz utilisera par défaut la valeur MTU du port.

struct ibv_qp_rate_limit_attr {
uint32_t        rate_limit;     /* kbps */
uint32_t        max_burst_sz;   /* octets */
uint16_t        typical_pkt_sz; /* octets */
};

VALEUR DE RETOUR

ibv_modify_qp_rate_limit() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

ERREURS

EINVAL

Arguments invalides.

EOPNOTSUPP

La fonction n'est pas implémentée pour ce périphérique. (ENOSYS peut parfois être renvoyé par d'anciennes versions de libibverbs).
