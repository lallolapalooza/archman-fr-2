IBV_MODIFY_SRQ(3) Manuel du programmeur Libibverbs IBV_MODIFY_SRQ(3)

NOM

ibv_modify_srq - modifier les attributs d'une file de réception partagée (SRQ)

SYNTAXE

#include <infiniband/verbs.h>

int ibv_modify_srq(struct ibv_srq *srq,
                   struct ibv_srq_attr *srq_attr,
                   int srq_attr_mask);

DESCRIPTION

ibv_modify_srq() modifie les attributs de la SRQ srq avec les attributs de srq_attr conformément au masque srq_attr_mask. L'argument srq_attr est une structure ibv_srq_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_srq_attr {
uint32_t                max_wr;      /* nombre maximal de requêtes de travail (WR) en attente dans la SRQ */
uint32_t                max_sge;     /* nombre d'éléments de dispersion par WR (non pertinent pour ibv_modify_srq) */
uint32_t                srq_limit;   /* la valeur limite de la SRQ */
};

L'argument srq_attr_mask spécifie les attributs de la SRQ à modifier. L'argument est soit 0, soit le OU binaire d'un ou plusieurs des indicateurs suivants :

IBV_SRQ_MAX_WR Redimensionner la SRQ
IBV_SRQ_LIMIT Définir la limite de la SRQ

VALEUR DE RETOUR

ibv_modify_srq() renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

NOTES

Si l'un des attributs de modification est invalide, aucun des attributs ne sera modifié.

Tous les périphériques ne prennent pas en charge le redimensionnement des SRQ. Pour vérifier si un périphérique le prend en charge, vérifiez si le bit IBV_DEVICE_SRQ_RESIZE est défini dans les indicateurs de capacités du périphérique.

La modification de srq_limit active la SRQ pour produire un événement asynchrone IBV_EVENT_SRQ_LIMIT_REACHED de type "seuil bas" une fois que le nombre de WR dans la SRQ tombe en dessous de srq_limit.
