NOTE

S

Tous les événements asynchrones que ibv_get_async_event() retourne doivent être acquittés à l'aide de ibv_ack_async_event(). Afin d'éviter les conditions de course, la destruction d'un objet (CQ, SRQ ou QP) attendra que tous les événements associés à l'objet soient acquittés ; cela évite qu'une application récupère un événement associé après que l'objet correspondant a déjà été

détruit.

ibv_get_async_event() est une fonction bloquante. Si plusieurs threads appellent cette fonction simultanément, alors lorsqu'u

n événement asynchrone se produit, un seul thread le recevra,
et il n'est pas possible de prédire quel thread le recevra.

NAME

ibv_get_async_event - Retrieve an asynchronous event from a context

SYNOPSIS

            #include <infiniband/verbs.h>

            int ibv_get_async_event(struct ibv_context *context,
                                    struct ibv_async_event *event);

DESCRIPTION

The ibv_get_async_event() function retrieves the next asynchronous event queued for the specified context. Asynchronous events are events that occur independently of explicit requests made by the user, such as device errors, port state changes, or completion queue overflows.

The context argument is a pointer to the verb context, obtained via ibv_open_device(3).

The event argument is a pointer to an ibv_async_event structure, which will be filled with the event details upon successful retrieval.

The ibv_async_event structure contains the following fields:

            enum ibv_event_type event_type;  /* Type of the event */
            union {
                struct ibv_port_event port_event;      /* For IBV_EVENT_PORT_ACTIVE, IBV_EVENT_PORT_INACTIVE */
                struct ibv_wq_event wq_event;          /* For IBV_EVENT_WQ_CATASIS */
                struct ibv_srq_event srq_event;        /* For IBV_EVENT_SRQ_LIMIT_REACHED */
                struct ibv_qp_event qp_event;          /* For IBV_EVENT_QP_FATAL, IBV_EVENT_QP_REQ_ERR, IBV_EVENT_QP_ACCESS_ERR */
                struct ibv_cq_event cq_event;          /* For IBV_EVENT_CQ_ERR */
                /* Other event types may be added in the future */
            } element;

The event_type field indicates the type of the asynchronous event. Possible values include:

  • IBV_EVENT_PORT_ACTIVE: A port has become active.
  • IBV_EVENT_PORT_INACTIVE: A port has become inactive.
  • IBV_EVENT_WQ_CATASIS: A work queue has been catastrophically failed.
  • IBV_EVENT_SRQ_LIMIT_REACHED: The limit of a shared receive queue has been reached.
  • IBV_EVENT_QP_FATAL: A queue pair has encountered a fatal error.
  • IBV_EVENT_QP_REQ_ERR: An invalid request was received on a queue pair.
  • IBV_EVENT_QP_ACCESS_ERR: An access violation occurred on a queue pair.
  • IBV_EVENT_CQ_ERR: A completion queue has encountered an error.

The element union contains event-specific data based on the event_type.

RETURN VALUE

On success, ibv_get_async_event() returns 0. On failure, it returns a negative value and sets errno.

If no events are available, errno is set to EAGAIN.

NOTES

Applications should call ibv_get_async_event() periodically to check for asynchronous events. If errno is EAGAIN, the application should wait and try again later. This can be done using a timeout or by polling.

It is important to handle asynchronous events promptly, as failure to do so can lead to degraded performance or event loss.

After retrieving an event, the application should release it using ibv_ack_async_event(3).

EXAMPLES

The following example demonstrates how to retrieve and acknowledge an asynchronous event:

            struct ibv_context *context;
            struct ibv_async_event event;
            int ret;

            /* Assume context is already opened */

            ret = ibv_get_async_event(context, &event);
            if (ret == 0) {
                printf("Received async event: type %d\n", event.event_type);
                /* Process the event based on its type */
                ibv_ack_async_event(&event);
            } else if (errno == EAGAIN) {
                printf("No async events available.\n");
            } else {
                perror("ibv_get_async_event failed");
            }
