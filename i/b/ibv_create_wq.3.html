IBV_CREATE_WQ(3) Manuel du programmeur Libibverbs IBV_CREATE_WQ(3)

NOM

ibv_create_wq, ibv_destroy_wq - créer ou détruire une File de Travail (WQ).

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_wq *ibv_create_wq(struct ibv_context *context,
                                     struct ibv_wq_init_attr *wq_init_attr);

int ibv_destroy_wq(struct ibv_wq *wq);

DESCRIPTION

ibv_create_wq() crée une WQ associée au ibv_context context. L'argument wq_init_attr est une structure ibv_wq_init_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_wq_init_attr {
void                      *wq_context;    /* Contexte associé de la WQ */
enum ibv_wq_type           wq_type;       /* Type de WQ */
uint32_t                   max_wr;        /* Nombre maximal demandé de WR en attente dans la WQ */
uint32_t                   max_sge;       /* Nombre maximal demandé d'éléments scatter/gather (s/g) par WR dans la WQ */
struct  ibv_pd            *pd;            /* PD à associer à la WQ */
struct  ibv_cq            *cq;            /* CQ à associer à la WQ */
uint32_t                   comp_mask;     /* Identifie les champs valides. Utiliser ibv_wq_init_attr_mask */
uint32_t                   create_flags    /* Indicateurs de création pour cette WQ, utiliser enum ibv_wq_flags */
};
enum ibv_wq_flags {
IBV_WQ_FLAGS_CVLAN_STRIPPING            = 1 << 0, /* Le champ CVLAN sera retiré des paquets entrants */
IBV_WQ_FLAGS_SCATTER_FCS                = 1 << 1, /* Le champ FCS sera dispersé dans la mémoire hôte */
IBV_WQ_FLAGS_DELAY_DROP                 = 1 << 2, /* Les paquets ne seront pas abandonnés immédiatement s'il n'y a pas de WQE de réception */
IBV_WQ_FLAGS_PCI_WRITE_END_PADDING      = 1 << 3, /* Les paquets entrants seront complétés à la taille de la ligne de cache */
IBV_WQ_FLAGS_RESERVED                   = 1 << 4,
};

La fonction ibv_create_wq() mettra à jour les champs wq_init_attr->max_wr et wq_init_attr->max_sge avec les valeurs réelles de la WQ créée ; les valeurs seront supérieures ou égales aux valeurs demandées.

ibv_destroy_wq() détruit la WQ wq.

VALEUR RETOURNÉE

ibv_create_wq() retourne un pointeur vers la WQ créée, ou NULL si la demande échoue.

ibv_destroy_wq() retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).
