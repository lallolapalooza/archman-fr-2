IBV_QUERY_DEVICE(3) Manuel du programmeur Libibverbs IBV_QUERY_DEVICE(3)

NOM

ibv_query_device - interroger les attributs d'un périphérique RDMA

SYNOPSIS

#include <infiniband/verbs.h>

int ibv_query_device(struct ibv_context *context,
                     struct ibv_device_attr *device_attr);

DESCRIPTION

ibv_query_device() renvoie les attributs du périphérique avec le contexte context. L'argument device_attr est un pointeur vers une structure ibv_device_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_device_attr {
char                    fw_ver[64];             /* Version du firmware */
uint64_t                node_guid;              /* GUID du nœud (en ordre d'octets réseau) */
uint64_t                sys_image_guid;         /* GUID de l'image système (en ordre d'octets réseau) */
uint64_t                max_mr_size;            /* Plus grand bloc contigu pouvant être enregistré */
uint64_t                page_size_cap;          /* Tailles de décalage mémoire supportées */
uint32_t                vendor_id;              /* ID du vendeur, selon IEEE */
uint32_t                vendor_part_id;         /* ID de pièce fourni par le vendeur */
uint32_t                hw_ver;                 /* Version matérielle */
int                     max_qp;                 /* Nombre maximum de QP supportés */
int                     max_qp_wr;              /* Nombre maximum de WR en attente sur une file de travail */
unsigned int            device_cap_flags;       /* Masque des capacités HCA */
int                     max_sge;                /* Nombre maximum de s/g par WR pour SQ et RQ de QP pour les opérations de lecture non RDMA */
int                     max_sge_rd;             /* Nombre maximum de s/g par WR pour les opérations de lecture RDMA */
int                     max_cq;                 /* Nombre maximum de CQ supportés */
int                     max_cqe;                /* Capacité maximale de CQE par CQ */
int                     max_mr;                 /* Nombre maximum de MR supportés */
int                     max_pd;                 /* Nombre maximum de PD supportés */
int                     max_qp_rd_atom;         /* Nombre maximum d'opérations de lecture et atomiques RDMA en attente par QP */
int                     max_ee_rd_atom;         /* Nombre maximum d'opérations de lecture et atomiques RDMA en attente par EEC */
int                     max_res_rd_atom;        /* Nombre maximum de ressources utilisées pour les opérations de lecture et atomiques RDMA par ce HCA en tant que cible */
int                     max_qp_init_rd_atom;    /* Profondeur maximale par QP pour l'initiation des opérations de lecture et atomiques RDMA */ 
int                     max_ee_init_rd_atom;    /* Profondeur maximale par EEC pour l'initiation des opérations de lecture et atomiques RDMA */
enum ibv_atomic_cap     atomic_cap;             /* Niveau de support des opérations atomiques */
int                     max_ee;                 /* Nombre maximum de contextes EE supportés */
int                     max_rdd;                /* Nombre maximum de domaines RD supportés */
int                     max_mw;                 /* Nombre maximum de MW supportés */
int                     max_raw_ipv6_qp;        /* Nombre maximum de QP de datagrammes IPv6 bruts supportés */
int                     max_raw_ethy_qp;        /* Nombre maximum de QP de datagrammes Ethertype supportés */
int                     max_mcast_grp;          /* Nombre maximum de groupes multicast supportés */
int                     max_mcast_qp_attach;    /* Nombre maximum de QP par groupe multicast pouvant être attachés */
int                     max_total_mcast_qp_attach;/* Nombre maximum de QP pouvant être attachés aux groupes multicast */
int                     max_ah;                 /* Nombre maximum de descripteurs d'adresse supportés */
int                     max_fmr;                /* Nombre maximum de FMR supportés */
int                     max_map_per_fmr;        /* Nombre maximum de (ré)associations par FMR avant qu'une opération de désassociation ne soit requise */
int                     max_srq;                /* Nombre maximum de SRQ supportés */
int                     max_srq_wr;             /* Nombre maximum de WR par SRQ */
int                     max_srq_sge;            /* Nombre maximum de s/g par SRQ */
uint16_t                max_pkeys;              /* Nombre maximum de partitions */
uint8_t                 local_ca_ack_delay;     /* Délai d'accusé de réception CA local */
uint8_t                 phys_port_cnt;          /* Nombre de ports physiques */
};

VALEUR RETOUR

ibv_query_device() renvoie 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

NOTES

Les valeurs maximales renvoyées par cette fonction sont les limites supérieures des ressources supportées par le périphérique. Cependant, il peut ne pas être possible d'utiliser ces valeurs maximales, car le nombre réel de toute ressource pouvant être créée peut être limité par la configuration de la machine, la quantité de mémoire hôte, les permissions utilisateur et la quantité de ressources déjà utilisée par d'autres utilisateurs/processus.
