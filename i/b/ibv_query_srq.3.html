IBV_QUERY_SRQ(3) Manuel du programmeur Libibverbs IBV_QUERY_SRQ(3)

NOM

ibv_query_srq - obtenir les attributs d'une file de réception partagée (SRQ)

SYNTAXE

#include <infiniband/verbs.h>

int ibv_query_srq(struct ibv_srq *srq, struct ibv_srq_attr *srq_attr);

DESCRIPTION

ibv_query_srq() récupère les attributs de la SRQ srq et les retourne via le pointeur srq_attr. L'argument srq_attr est une structure ibv_srq_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_srq_attr {
uint32_t                max_wr;         /* nombre maximum de requêtes de travail (WR) en attente dans la SRQ */
uint32_t                max_sge;        /* nombre maximum d'éléments de dispersion par WR */
uint32_t                srq_limit;      /* valeur limite de la SRQ */
};

VALEUR DE RETOUR

ibv_query_srq() retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

NOTES

Si la valeur retournée pour srq_limit est 0, alors l'événement de limite atteinte de la SRQ (« seuil bas ») n'est pas (ou n'est plus) armé, et aucun événement asynchrone ne sera généré tant que l'événement ne sera pas réarmé.
