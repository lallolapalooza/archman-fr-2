IBSWITCHES(8) Diagnostics OpenIB IBSWITCHES(8)

Nom

IBSWITCHES - afficher les nœuds de commutateur InfiniBand dans la topologie

Syntaxe

ibswitches [options] [<fichier-topologie>]

Description

ibswitches est un script qui parcourt la topologie du sous-réseau IB ou utilise un fichier de topologie déjà sauvegardé et extrait les nœuds de commutateur.

Options

-C, --Ca <nom_ca> utiliser le nom_ca spécifié.

-P, --Port <port_ca> utiliser le port_ca spécifié.

-t, --timeout <timeout_ms> remplacer le délai d'attente par défaut pour les MAD sollicités.

-y, --m_key <clé>
utiliser la clé M spécifiée pour les requêtes. Si une valeur non numérique (comme 'x') est spécifiée, une valeur sera demandée.

-h, --help afficher le message d'utilisation

--config, -z <fichier_config> spécifier un fichier de configuration alternatif.

Défaut : /etc/infiniband-diags/ibdiag.conf

Sélection du port local

Prise en charge de plusieurs ports/plusieurs CA : lorsqu'aucun périphérique ou port IB n'est spécifié (voir les "paramètres umad locaux" ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port qui est ACTIF.
2.
si non trouvé, le premier port qui est ACTIF (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de répondre à la demande de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utiliser le premier port (critère #1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utiliser le deuxième port (actif/actif) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser le port spécifié uniquement.

Fichiers

Fichier de configuration

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines options communes à tous les outils. Voir le fichier de configuration fourni pour les détails.

Format du fichier de cartographie des noms de nœuds

La carte des noms de nœuds est utilisée pour spécifier des noms conviviaux pour les nœuds dans la sortie. Les GUID sont utilisés pour effectuer la recherche.

Cette fonctionnalité est fournie par le paquet opensm-libs. Voir opensm(8) pour l'emplacement du fichier pour votre installation.

Génériquement :

# commentaire
<guid> "<nom>"

Exemple :

# Cartes de ligne
0x0008f104003f125c "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"

0x0008f104003f10bf "IB1 (Rack 11 slot 12  ) ISR9288/ISR9096 Voltaire sLB-24D"
# Épines
0x0008f10400400e2d "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
