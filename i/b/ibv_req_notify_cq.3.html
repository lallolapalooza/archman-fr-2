NOM

ibv_req_notify_cq - demande une notification d'achèvement sur une file d'attente d'achèvement (CQ)

SYNTAXE

#include <infiniband/verbs.h>
int ibv_req_notify_cq(struct ibv_cq *cq, int solicited_only);

DESCRIPTION

ibv_req_notify_cq() demande une notification d'achèvement sur la file d'attente d'achèvement (CQ) cq.

Lors de l'ajout d'une nouvelle entrée de CQ (CQE) à cq, un événement d'achèvement sera ajouté au canal d'achèvement associé au CQ. Si l'argument solicited_only est zéro, un événement d'achèvement est généré pour toute nouvelle CQE. Si solicited_only est non nul, un événement n'est généré que pour une nouvelle CQE considérée comme « sollicitée ». Une CQE est sollicitée si elle est un achèvement de réception pour un message avec le bit d'en-tête d'événement sollicité activé, ou si le statut n'est pas réussi. Tous les autres achèvements de réception réussis, ou tout achèvement d'envoi réussi, sont non sollicités.

VALEUR DE RETOUR

ibv_req_notify_cq() retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

NOTES

La demande de notification est « unique ». Un seul événement d'achèvement sera généré pour chaque appel à ibv_req_notify_cq().
