CREATE_RWQ_IND_TBL(3) Manuel du programmeur Libibverbs CREATE_RWQ_IND_TBL(3)

NOM

ibv_create_rwq_ind_table, ibv_destroy_rwq_ind_table - créer ou détruire une table d'indirection de files d'attente de réception (RWQ IND TBL).

SYNOPIS

#include <infiniband/verbs.h>

struct ibv_rwq_ind_table *ibv_create_rwq_ind_table(struct ibv_context *context,
                                                           struct ibv_rwq_ind_table_init_attr *init_attr);

int ibv_destroy_rwq_ind_table(struct ibv_rwq_ind_table *rwq_ind_table);

DESCRIPTION

ibv_create_rwq_ind_table() crée une table RWQ IND TBL associée au contexte ibv_context context. L'argument init_attr est une struct ibv_rwq_ind_table_init_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_rwq_ind_table_init_attr {
uint32_t        log_ind_tbl_size;     /* Logarithme en base 2 de la taille de la table d'indirection */
struct          ibv_wq **ind_tbl;     /* Chaque entrée est un pointeur vers une file d'attente de réception */
uint32_t        comp_mask;            /* Identifie les champs valides. Utiliser ibv_ind_table_init_attr_mask */
};

La fonction ibv_create_rwq_ind_table() créera une table RWQ IND TBL qui contient une table de files d'attente de réception. Pour une utilisation ultérieure de l'objet créé, voir ci-dessous dans NOTES.

ibv_destroy_rwq_ind_table() détruit la table RWQ IND TBL rwq_ind_table.

VALEUR DE RETOUR

ibv_create_rwq_ind_table() retourne un pointeur vers la table RWQ IND TBL créée, ou NULL si la requête échoue.

ibv_destroy_rwq_ind_table() retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

NOTES

L'objet créé doit être utilisé dans le cadre de ibv_create_qp_ex() pour permettre la distribution des paquets entrants en fonction de certaines configurations de hachage RX.
