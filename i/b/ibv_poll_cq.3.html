IBV_POLL_CQ(3) Manuel du programmeur Libibverbs IBV_POLL_CQ(3)

NOM

ibv_poll_cq - interroger une file d'achèvement (CQ)

SYNTAXE

#include <infiniband/verbs.h>

int ibv_poll_cq(struct ibv_cq *cq, int num_entries,
                struct ibv_wc *wc);

DESCRIPTION

ibv_poll_cq() interroge la CQ cq pour les achèvements de travail et retourne les num_entries premières (ou tous les achèvements disponibles si la CQ contient moins que ce nombre) dans le tableau wc. L'argument wc est un pointeur vers un tableau de structures ibv_wc, tel que défini dans <infiniband/verbs.h>.

struct ibv_wc {
uint64_t                wr_id;          /* ID de la Requête de Travail (WR) achevée */
enum ibv_wc_status      status;         /* Statut de l'opération */
enum ibv_wc_opcode      opcode;         /* Type d'opération spécifié dans la WR achevée */
uint32_t                vendor_err;     /* Erreur de fournisseur */
uint32_t                byte_len;       /* Nombre d'octets transférés */
union {
__be32                  imm_data;         /* Données immédiates (en ordre d'octets réseau) */
uint32_t                invalidated_rkey; /* Clé RLocale invalide qui a été invalidée */
};
uint32_t                qp_num;         /* Numéro QP local de la WR achevée */
uint32_t                src_qp;         /* Numéro QP source (numéro QP distant) de la WR achevée (valide uniquement pour les QPs UD) */
unsigned int            wc_flags;       /* Indicateurs de la WR achevée */
uint16_t                pkey_index;     /* Index P_Key (valide uniquement pour les QPs GSI) */
uint16_t                slid;           /* LID source */
uint8_t                 sl;             /* Niveau de Service */
uint8_t                 dlid_path_bits; /* Bits du chemin DLID (non applicable aux messages multicast) */
};

L'attribut wc_flags décrit les propriétés de l'achèvement du travail. Il est soit 0, soit le OU logique de un ou plusieurs des indicateurs suivants :

IBV_WC_GRH Le GRH est présent (valide uniquement pour les QPs UD)
IBV_WC_WITH_IMM La valeur des données immédiates est valide
IBV_WC_WITH_INV La valeur des données de clé R invalide est valide (ne peut pas être combinée avec IBV_WC_WITH_IMM)
IBV_WC_IP_CSUM_OK La somme de contrôle TCP/UDP sur IPv4 et la somme de contrôle de l'en-tête IPv4 sont
vérifiées. Valide uniquement lorsque device_cap_flags dans device_attr indique que le QP actuel est pris en charge par la décharge de somme de contrôle.

Tous les attributs de wc ne sont pas toujours valides. Si le statut d'achèvement est autre que IBV_WC_SUCCESS, seuls les attributs suivants sont valides : wr_id, status, qp_num, et vendor_err.

VALEUR DE RETOUR

En cas de succès, ibv_poll_cq() retourne une valeur non négative égale au nombre d'achèvements trouvés. En cas d'échec, une valeur négative est retournée.

NOTES

Chaque achèvement interrogé est supprimé de la CQ et ne peut pas y être réinséré.

L'utilisateur doit consommer les achèvements de travail à un rythme qui empêche le débordement de la CQ. En cas de débordement de la CQ, l'événement asynchrone IBV_EVENT_CQ_ERR sera déclenché et la CQ ne pourra plus être utilisée.

IBV_WC_DRIVER1 sera rapporté en réponse à l'opcode IBV_WR_DRIVER1 ; IBV_WC_DRIVER2/IBV_WC_DRIVER3 sera rapporté sur des opérations spécifiques du pilote.
