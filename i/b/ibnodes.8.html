IBNODES(8) Diagnostics OpenIB IBNODES(8)

Nom

IBNODES - afficher les nœuds InfiniBand dans la topologie

Syntaxe

ibnodes [options] [<fichier-topologie>]

Description

ibnodes est un script qui parcourt la topologie du sous-réseau IB ou utilise un fichier de topologie déjà sauvegardé et en extrait les nœuds IB (cartes d'accès et commutateurs).

Options

-C, --Ca <nom_ca> utiliser le nom_ca spécifié.

-P, --Port <port_ca> utiliser le port_ca spécifié.

-t, --timeout <timeout_ms> remplacer le délai d'attente par défaut pour les MADS sollicités.

-h, --help afficher le message d'utilisation

--config, -z <fichier_config> spécifier un fichier de configuration alternatif.

Défaut : /etc/infiniband-diags/ibdiag.conf

Sélection du port local

Support multi-port/multi-CA : lorsqu'aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port qui est ACTIF.
2.
si aucun n'est trouvé, le premier port qui est ACTIF (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de satisfaire la requête de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utilise le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # choisit le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utilise le deuxième port (actif/en ligne) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utilise uniquement le port spécifié.

Fichiers

Fichier de configuration

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines options courantes pour tous les outils. Voir le fichier de configuration fourni pour les détails.

Format du fichier de carte des noms de nœuds

La carte des noms de nœuds est utilisée pour spécifier des noms conviviaux pour les nœuds dans la sortie. Les GUID sont utilisés pour effectuer la recherche.

Cette fonctionnalité est fournie par le paquet opensm-libs. Voir opensm(8) pour l'emplacement du fichier pour votre installation.

Génériquement :

# commentaire
<guid> "<nom>"
