Nom

ibstatus - interroger l'état de base des périphériques InfiniBand

SYNOPSIS

ibstatus [-h] [nom_dev[:port]]...

DESCRIPTION

ibstatus est un script qui affiche des informations de base obtenues du pilote IB local. La sortie comprend le LID, le SMLID, l'état du port, la largeur de liaison active et l'état physique du port.

OPTIONS

-h, --help afficher le message d'utilisation

nom_dev
Nom du périphérique InfiniBand
num_port
Numéro de port du périphérique InfiniBand

EXEMPLES

ibstatus                    # afficher l'état de tous les ports IB
ibstatus mthca1             # état des ports de mthca1
ibstatus mthca1:1 mthca0:2  # afficher l'état des ports spécifiés
