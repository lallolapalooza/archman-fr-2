IBV_QUERY_PORT(3) Manuel du programmeur Libibverbs IBV_QUERY_PORT(3)

NOM

ibv_query_port - interroger les attributs d'un port RDMA

SYNTAXE

#include <infiniband/verbs.h>

int ibv_query_port(struct ibv_context *context, uint8_t port_num,
                   struct ibv_port_attr *port_attr);

DESCRIPTION

ibv_query_port() renvoie les attributs du port port_num pour le contexte de périphérique context via le pointeur port_attr. L'argument port_attr est une structure ibv_port_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_port_attr {
enum ibv_port_state     state;          /* État logique du port */
enum ibv_mtu            max_mtu;        /* MTU maximal supporté par le port */
enum ibv_mtu            active_mtu;     /* MTU actuel */
int                     gid_tbl_len;    /* Longueur de la table GID source */
uint32_t                port_cap_flags; /* Capacités du port */
uint32_t                max_msg_sz;     /* Taille maximale du message */
uint32_t                bad_pkey_cntr;  /* Compteur de P_Key invalides */
uint32_t                qkey_viol_cntr; /* Compteur de violations de Q_Key */
uint16_t                pkey_tbl_len;   /* Longueur de la table de partitions */
uint16_t                lid;            /* LID de base du port */
uint16_t                sm_lid;         /* LID du SM */
uint8_t                 lmc;            /* LMC du LID */
uint8_t                 max_vl_num;     /* Nombre maximal de VL */
uint8_t                 sm_sl;          /* Niveau de service du SM */
uint8_t                 subnet_timeout; /* Délai de propagation du sous-réseau */
uint8_t                 init_type_reply;/* Type d'initialisation effectuée par le SM */
uint8_t                 active_width;   /* Largeur de lien active actuelle */
uint8_t                 active_speed;   /* Vitesse de lien active actuelle si vitesse<XDR,NDR sinon */
uint8_t                 phys_state;     /* État physique du port */
uint8_t                 link_layer;     /* Protocole de la couche liaison du port */
uint8_t                 flags;          /* Indicateurs du port */
uint16_t                port_cap_flags2;/* Capacités du port */
uint32_t                active_speed_ex;/* Vitesse de lien active actuelle, si elle est de 0, référez-vous à active_speed à la place */
};

valeurs possibles pour le champ link_layer : IBV_LINK_LAYER_INFINIBAND,
IBV_LINK_LAYER_ETHERNET, ou IBV_LINK_LAYER_UNSPECIFIED.

indicateurs de port pris en charge :
IBV_QPF_GRH_REQUIRED - Lorsque cet indicateur est défini, les applications doivent créer tous les AH avec GRH configuré.

VALEUR DE RETOUR

ibv_query_port() renvoie 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI

ibv_create_qp(3), ibv_destroy_qp(3), ibv_query_qp(3), ibv_create_ah(3)
