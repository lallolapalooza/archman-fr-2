NOM

IBUS - Fichier de base de données dconf pour IBus

SYNOPSIS

/etc/dconf/db/ibus

DESCRIPTION

IBus est un Intelligent Input Bus. C'est un nouveau framework d'entrée pour les systèmes d'exploitation Linux. Il fournit une interface utilisateur de méthode d'entrée complète et conviviale. Il peut également aider les développeurs à créer facilement des méthodes d'entrée.

/etc/dconf/db/ibus est un fichier de base de données dconf qui enregistre les paramètres par défaut d'IBus. Il peut être généré à partir de /etc/dconf/db/ibus.d/00-upstream-settings par la commande dconf update avec des privilèges d'écriture dans /etc/dconf/db. Les clés et valeurs enregistrées peuvent être lues par la commande dconf.

env DCONF_PROFILE=ibus dconf list /desktop/ibus/
