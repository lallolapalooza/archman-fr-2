IBV_GET_DEVICE_LIST(3) Manuel du programmeur Libibverbs IBV_GET_DEVICE_LIST(3)

NOM

ibv_get_device_list, ibv_free_device_list - obtenir et libérer la liste des périphériques RDMA disponibles

SYNTAXE

#include <infiniband/verbs.h>
struct ibv_device **ibv_get_device_list(int *num_devices);
void ibv_free_device_list(struct ibv_device **list);

DESCRIPTION

ibv_get_device_list() renvoie un tableau terminé par NULL des périphériques RDMA actuellement disponibles. L'argument num_devices est facultatif ; s'il n'est pas NULL, il est défini au nombre de périphériques renvoyés dans le tableau.

ibv_free_device_list() libère le tableau de périphériques list renvoyé par ibv_get_device_list().

VALEUR DE RETOUR

ibv_get_device_list() renvoie le tableau des périphériques RDMA disponibles, ou définit errno et renvoie NULL si la requête échoue. Si aucun périphérique n'est trouvé, num_devices est défini à 0 et une valeur non NULL est renvoyée.

ibv_free_device_list() ne renvoie aucune valeur.

ERREURS

EPERM
Permission refusée.
ENOSYS
Pas de support du noyau pour RDMA.
ENOMEM
Mémoire insuffisante pour terminer l'opération.

NOTES

Le code client doit ouvrir tous les périphériques qu'il a l'intention d'utiliser avec ibv_open_device() avant d'appeler ibv_free_device_list(). Une fois qu'il a libéré le tableau avec ibv_free_device_list(), il ne pourra utiliser que les périphériques ouverts ; les pointeurs vers les périphériques non ouverts ne seront plus valides.

Définir la variable d'environnement IBV_SHOW_WARNINGS entraînera l'émission d'avertissements sur stderr si un périphérique de verbes du noyau est découvert, mais qu'aucun pilote d'espace utilisateur correspondant ne peut être trouvé pour celui-ci.

LIAISON STATIQUE

Si libibverbs est lié statiquement à l'application, alors tous les pilotes fournisseurs doivent également être liés statiquement. La bibliothèque ne chargera pas les fournisseurs dynamiques lorsque la liaison statique est utilisée.

Pour lier les fournisseurs, définissez la macro RDMA_STATIC_PROVIDERS à la liste des fournisseurs souhaités, séparés par des virgules, lors de la compilation de l'application. Le mot-clé spécial « all » liera statiquement tous les fournisseurs libibverbs pris en charge.

Ceci est destiné à être utilisé avec pkg-config(1) pour définir les indicateurs appropriés pour la liaison de libibverbs.

Si cela n'est pas fait, ibv_get_device_list renverra toujours une liste vide.

L'utilisation de la liaison dynamique seule pour les applications libibverbs est fortement recommandée.
