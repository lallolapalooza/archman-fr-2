IBV_CREATE_CQ(3) Manuel du programmeur Libibverbs IBV_CREATE_CQ(3)

NOM

ibv_create_cq, ibv_destroy_cq - créer ou détruire une file d'attente de complétion (CQ)

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_cq *ibv_create_cq(struct ibv_context *context, int cqe,
                             void *cq_context,
                             struct ibv_comp_channel *channel,
                             int comp_vector);

int ibv_destroy_cq(struct ibv_cq *cq);

DESCRIPTION

ibv_create_cq() crée une file d'attente de complétion (CQ) avec au moins cqe entrées pour le contexte de périphérique RDMA context. Le pointeur cq_context sera utilisé pour définir le pointeur de contexte utilisateur de la structure CQ. L'argument channel est optionnel ; s'il n'est pas NULL, le canal de complétion channel sera utilisé pour retourner les événements de complétion. La CQ utilisera le vecteur de complétion comp_vector pour signaler les événements de complétion ; il doit être au moins zéro et inférieur à context->num_comp_vectors.

ibv_destroy_cq() détruit la CQ cq.

VALEUR DE RETOUR

ibv_create_cq() retourne un pointeur vers la CQ, ou NULL si la demande échoue.

ibv_destroy_cq() retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

NOTES

ibv_create_cq() peut créer une CQ dont la taille est supérieure ou égale à la taille demandée. Vérifiez l'attribut cqe dans la CQ retournée pour la taille réelle.

ibv_destroy_cq() échoue si une paire de files d'attente est toujours associée à cette CQ.
