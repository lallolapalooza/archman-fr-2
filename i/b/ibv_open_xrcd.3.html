IBV_OPEN_XRCD(3) Manuel du programmeur Libibverbs IBV_OPEN_XRCD(3)

NOM

ibv_open_xrcd, ibv_close_xrcd - ouvrir ou fermer un domaine de protection XRC (XRCDs)

SYNTAXE

#include <infiniband/verbs.h>

struct ibv_xrcd *ibv_open_xrcd(struct ibv_context *context,
                               struct ibv_xrcd_init_attr *xrcd_init_attr);

int ibv_close_xrcd(struct ibv_xrcd *xrcd);

DESCRIPTION

ibv_open_xrcd() ouvre un domaine XRC pour le contexte de périphérique RDMA context. xrcd_init_attr est une structure ibv_xrcd_init_attr, telle que définie dans <infiniband/verbs.h>.

struct ibv_xrcd_init_attr {
uint32_t         comp_mask;  /* Identifie les champs valides */
int              fd;
int              oflag;

fd est le descripteur de fichier à associer à l'XRCD. oflag décrit les attributs de création souhaités. C'est un OR bit à bit de zéro ou plusieurs des drapeaux suivants :

O_CREAT
Indique qu'un XRCD doit être créé et associé à l'inode référencé par le fd donné. Si l'XRCD existe, ce drapeau n'a aucun effet, sauf mention contraire sous O_EXCL ci-dessous.
O_EXCL
Si O_EXCL et O_CREAT sont définis, l'ouverture échouera si un XRCD associé à l'inode existe.

Si fd est égal à -1, aucun inode n'est associé à l'XRCD. Pour indiquer que l'XRCD doit être créé, utilisez oflag = O_CREAT.

ibv_close_xrcd() ferme l'XRCD xrcd. S'il s'agit de la dernière référence, l'XRCD sera détruit.

VALEUR DE RETOUR

ibv_open_xrcd() retourne un pointeur vers l'XRCD ouvert, ou NULL si la requête échoue.

ibv_close_xrcd() retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

NOTES

ibv_close_xrcd() peut échouer si toute autre ressource est encore associée à l'XRCD en cours de fermeture.
