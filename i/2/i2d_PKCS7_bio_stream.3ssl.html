I2D_PKCS7_BIO_STREAM(3ssl) OpenSSL I2D_PKCS7_BIO_STREAM(3ssl)

NOM

i2d_PKCS7_bio_stream - sortie la structure PKCS7 en format BER

SYNOPIS

#include <openssl/pkcs7.h>
int i2d_PKCS7_bio_stream(BIO *out, PKCS7 *p7, BIO *data, int flags);

DESCRIPTION

i2d_PKCS7_bio_stream() sort la structure PKCS7 en format BER.

Elle est par ailleurs identique à la fonction SMIME_write_PKCS7().

NOTES

Cette fonction est effectivement une version de d2i_PKCS7_bio() supportant le streaming.

BOGUES

Le préfixe « i2d » est discutablement incorrect car la fonction sort en format BER.

VALEUR DE RETOUR

i2d_PKCS7_bio_stream() retourne 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

ERR_get_error(3), PKCS7_sign(3), PKCS7_verify(3), PKCS7_encrypt(3) PKCS7_decrypt(3), SMIME_write_PKCS7(3), PEM_write_bio_PKCS7_stream(3)

HISTORIQUE

La fonction i2d_PKCS7_bio_stream() a été ajoutée dans OpenSSL 1.0.0.
