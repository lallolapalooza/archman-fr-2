NOM

i2pd - Implémentation C++ complète du client I2P.

SYNOPSIS

i2pd [OPTION1] [OPTION2]...

DESCRIPTION

i2pd est une implémentation C++ du routeur pour le réseau d'anonymisation I2P, offrant une couche simple que les applications sensibles à l'identité peuvent utiliser pour communiquer de manière sécurisée. Toutes les données sont chiffrées en plusieurs couches, et le réseau est à la fois distribué et dynamique, sans parties de confiance.

Toutes les options de configuration ci-dessous peuvent être utilisées dans la variable DAEMON_ARGS de /etc/default/i2pd.

OPTIONS

--help
Afficher les options disponibles.
--conf=
Fichier de configuration (par défaut : ~/.i2pd/i2pd.conf ou /var/lib/i2pd/i2pd.conf) Ce paramètre sera silencieusement ignoré si le fichier de configuration spécifié n'existe pas. Les options spécifiées sur la ligne de commande ont la priorité sur celles du fichier de configuration.
--tunconf=
Fichier de configuration des tunnels (par défaut : ~/.i2pd/tunnels.conf ou /var/lib/i2pd/tunnels.conf)
--pidfile=
Emplacement où écrire le fichier pid (ne pas écrire par défaut)
--log=
Destination des logs : stdout, file, syslog ( stdout si non défini, file sinon, pour la compatibilité)
--logfile=
Chemin vers le fichier de log (par défaut - auto-détection)
--loglevel=
Niveau des messages de log à afficher (debug, info, warn, error, none)
--logclftime
Afficher les messages de log avec la date et l'heure complètes au format CLF (désactivé par défaut)
--datadir=
Chemin vers le stockage des données i2pd (RI, clés, profils de pairs, ...)
--tunnelsdir=
Chemin vers les fichiers de configuration des tunnels (par défaut : ~/.i2pd/tunnels.d ou /var/lib/i2pd/tunnels.d)
--host=
L'adresse IP externe.
--port=
Le port sur lequel écouter les connexions entrantes.
--ifname=
L'interface réseau à laquelle se lier.
--ifname4=
L'interface réseau à laquelle se lier pour les connexions IPv4.
--ifname6=
L'interface réseau à laquelle se lier pour les connexions IPv6.
--ipv4=
Activer la communication via IPv4 (activé par défaut)
--ipv6
Activer la communication via IPv6 (désactivé par défaut)
--ntcp=
Activer l'utilisation du transport NTCP (activé par défaut)
--ntcpproxy=
Définir l'URL du proxy pour le transport NTCP.
--ssu=
Activer l'utilisation du transport SSU (activé par défaut)
--notransit
Le routeur n'acceptera pas les tunnels de transit au démarrage (désactivé par défaut)
--floodfill
Le routeur sera de type floodfill (désactivé par défaut)
--bandwidth=
Limite de bande passante : entier en Ko/s ou alias alphabétiques : L (32 Ko/s), O (256), P (2048), X (>9000)
--share=
Limite du trafic de transit en pourcentage de la bande passante maximale. (par défaut : 100)
--daemon
Le routeur passera en arrière-plan après le démarrage (désactivé par défaut)
--service
Le routeur utilisera les dossiers système comme /var/lib/i2pd (désactivé par défaut)
--family=
Nom de la famille à laquelle appartient le routeur.

Les commutateurs qui sont activés par défaut (comme --ssu, --ntcp, etc.) peuvent être désactivés dans le fichier de configuration.
Voir les paramètres spécifiques aux services dans le fichier de configuration d'exemple /usr/share/doc/i2pd/i2pd.conf.gz

FICHIERS

/etc/i2pd/i2pd.conf, /etc/i2pd/tunnels.conf, /etc/default/i2pd

Fichiers de configuration i2pd (lorsqu'exécuté comme service système)

/var/lib/i2pd/

Répertoire de profil i2pd (lorsqu'exécuté comme service système, voir --service ci-dessus)

$HOME/.i2pd/

Répertoire de profil i2pd (lorsqu'exécuté comme utilisateur normal)
