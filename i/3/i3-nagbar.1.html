I3-NAGBAR(1) Manuel i3 I3-NAGBAR(1)

NOM

i3-nagbar - affiche une barre d'erreur en haut de votre écran

SYNTAXE

i3-nagbar [-m <message>] [-b <bouton> <action>] [-B <bouton> <action>] [-t warning|error] [-f <police>] [-v] [-p]

OPTIONS

-v, --version

Affiche le numéro de version et quitte.

-h, --help

Affiche un court message d'aide et quitte.

-t, --type type

Affiche un message d'avertissement (warning) ou d'erreur (error). Cela ne change que le schéma de couleurs pour i3-nagbar. Défaut : error.

-m, --message message

Affiche le message sous forme de texte à gauche de i3-nagbar.

-f, --font police

Sélectionne la police utilisée.

-b, --button bouton action

Crée un bouton avec le texte bouton. L'action correspond aux commandes shell qui seront exécutées par ce bouton. Plusieurs boutons peuvent être définis. Lance les commandes shell dans un émulateur de terminal, en utilisant i3-sensible-terminal.

-B, --button-no-terminal bouton action

Identique à ci-dessus, mais exécutera les commandes shell directement, sans lancer d'émulateur de terminal.

-p, --primary

Ouvre toujours i3-nagbar sur le moniteur principal. Par défaut, il s'ouvre sur le moniteur focalisé.

DESCRIPTION

i3-nagbar est utilisé par i3 pour vous informer d'erreurs dans votre fichier de configuration (par exemple). Bien que ces erreurs soient enregistrées dans le fichier journal (si applicable), le passé a prouvé que les utilisateurs ignorent soit leur fichier journal, soit ne le vérifient pas après avoir modifié le fichier de configuration.

EXEMPLE

i3-nagbar -m 'Vous avez une erreur dans votre fichier de configuration i3!' \
-b 'éditer config' 'i3-sensible-editor ~/.config/i3/config'
