NOM

i3lock - verrouillage d'écran amélioré

SYNOPSIS

i3lock [-v] [-n] [-b] [-i image.png] [-c couleur] [-t] [-p pointeur] [-u] [-e] [-f]

UTILISATION RECOMMANDÉE

xss-lock --transfer-sleep-lock -- i3lock --nofork

L'utilisation de xss-lock garantit que votre écran est verrouillé avant la mise en veille de votre ordinateur portable.

Il est à noter que l'utilisation d'un fichier de service systemd n'est pas adéquat, car il ne retardera pas la mise en veille jusqu'à ce que votre écran soit verrouillé.

DESCRIPTION

i3lock est un verrouillage d'écran simple comme slock. Après son démarrage, vous verrez un écran blanc (vous pouvez configurer la couleur/une image). Vous pouvez revenir à votre écran en saisissant votre mot de passe.

AMÉLIORATIONS

•
i3lock se détache (fork), vous pouvez donc le combiner avec un alias pour la mise en veille (« i3lock && echo mem > /sys/power/state » pour obtenir un écran verrouillé après le réveil de votre ordinateur depuis la mise en veille)
•
Vous pouvez spécifier soit une couleur d'arrière-plan soit une image PNG qui sera affichée pendant que votre écran est verrouillé.
•
Vous pouvez spécifier si i3lock doit émettre un bip en cas de mot de passe erroné.
•
i3lock utilise PAM et est donc compatible avec LDAP, etc.

OPTIONS

-v, --version
Affiche la version de votre i3lock
-n, --nofork
Ne pas se détacher après le démarrage.
-b, --beep
Activer les bips. Assurez-vous de ne pas le faire lorsque vous risquez d'ennuyer d'autres personnes, comme en ouvrant votre ordinateur portable lors d'un cours ennuyeux.
-u, --no-unlock-indicator
Désactiver l'indicateur de déverrouillage. i3lock affichera par défaut un indicateur de déverrouillage après l'appui sur des touches. Cela donnera un retour pour chaque frappe et affichera l'état actuel de PAM (si votre mot de passe est en cours de vérification ou s'il est erroné).
-ichemin,--image=chemin
Affiche l'image PNG donnée au lieu d'un écran vide.
--raw=format
Lit l'image donnée par --image comme une image brute au lieu d'un PNG. L'argument est le format de l'image sous la forme <largeur>x<hauteur>:<pixfmt>. Les formats de pixels pris en charge sont : ´native', 'rgb', 'xrgb', 'rgbx', 'bgr', 'xbgr', et 'bgrx'. Le format de pixel "native" attend un pixel sous la forme d'un entier 32 bits (4 octets) dans l'endianness native de la machine, avec les 8 bits supérieurs inutilisés. Le rouge, le vert et le bleu sont stockés dans les bits restants, dans cet ordre.

Exemple :

--raw=1920x1080:rgb

Vous pouvez utiliser le programme convert(1) d'ImageMagick pour alimenter i3lock en images brutes :

convert wallpaper.jpg RGB:- | i3lock --raw 3840x2160:rgb --image /dev/stdin

Cela vous permet de charger une variété de formats d'image sans que i3lock ait à les prendre en charge explicitement.

-crrggbb,--color=rrggbb
Remplace l'écran par la couleur donnée au lieu du blanc. La couleur doit être donnée au format 3 octets : rrggbb (c'est-à-dire que ff0000 est rouge).
-t, --tiling
Si une image est spécifiée (via -i), elle sera affichée en mosaïque sur tout l'écran (s'il s'agit d'une configuration multi-écrans, l'image est visible sur tous les écrans).
-pwin|default,--pointer=win|default
Si vous spécifiez "default", i3lock ne cache pas votre pointeur de souris. Si vous spécifiez "win", i3lock affiche un pointeur Windows codé en dur (vous permettant ainsi d'amuser vos amis en utilisant une capture d'écran d'un bureau Windows comme écran de verrouillage).
-e, --ignore-empty-password
Lorsqu'un mot de passe vide est fourni par l'utilisateur, ne pas le valider. Sans cette option, le mot de passe vide sera fourni à PAM et, s'il est invalide, l'utilisateur devra attendre quelques secondes avant de pouvoir réessayer. Cela peut être utile si la touche XF86ScreenSaver est utilisée pour mettre un ordinateur portable en veille et le réveiller immédiatement, ou si vous réveillez votre ordinateur avec la touche entrée.
-f, --show-failed-attempts
Afficher le nombre de tentatives échouées, le cas échéant.
-k, --show-keyboard-layout
Afficher la disposition du clavier actuelle.
--debug
Active la journalisation de débogage. Notez que cela journalisera le mot de passe utilisé pour l'authentification sur la sortie standard.

DPMS

L'option -d (--dpms) a été retirée de i3lock dans la version 2.8. Il y avait de nombreux cas d'utilisation qui n'étaient pas correctement pris en charge, et de nombreux bugs entourant cette fonctionnalité. Bien que les fonctionnalités ne soient généralement pas retirées de i3 et de ses outils, nous avons ressenti le besoin de faire une exception dans ce cas.

Les utilisateurs qui souhaitent activer explicitement DPMS uniquement lorsque leur écran est verrouillé peuvent utiliser un script d'enveloppement autour de i3lock comme celui-ci :

#!/bin/sh
revert() {
  xset dpms 0 0 0
}
trap revert HUP INT TERM
xset +dpms dpms 5 5 5
i3lock -n
revert

L'option -I (--inactivity-timeout=secondes) a été retirée car elle n'a de sens qu'avec DPMS.
