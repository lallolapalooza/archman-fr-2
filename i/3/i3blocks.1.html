NOM

i3blocks - Générateur de flux pour barres d'état basées sur du texte

SYNOPIS

i3blocks [OPTION]...

DESCRIPTION

La commande i3blocks(1) génère une ligne de statut pour i3bar(1). Elle planifie des lignes de commande décrites dans un fichier de configuration simple à des intervalles de temps spécifiés, lors de la réception de signaux ou lors de clics.

OPTIONS

-h

Affiche le message d'aide et quitte.

-c FICHIER_CONFIG

Spécifie un chemin de fichier de configuration alternatif.

-v

Augmente le niveau de journalisation. Cette option est cumulative. Par défaut, seules les erreurs fatales sont affichées dans la barre d'état. Passer cette option une fois affichera également les messages d'erreur. Utiliser -vv et plus affichera plus de sortie de débogage sur la sortie standard d'erreur.

CONFIGURATION

i3blocks doit être défini comme la commande de ligne de statut du bloc bar décrit dans votre fichier de configuration i3(1) :

bar {
  status_command i3blocks
}

Par défaut, i3blocks recherche un fichier de configuration dans l'ordre suivant (notez que /etc peut être préfixé par /usr/local en fonction des indicateurs de compilation) :

1.$XDG_CONFIG_HOME/i3blocks/config (ou ~/.config/i3blocks/config)
2.~/.i3blocks.conf
3.$XDG_CONFIG_DIRS/i3blocks/config (ou /etc/xdg/i3blocks/config)
4./etc/i3blocks.conf

Pour le contenu du fichier de configuration, veuillez vous référer au site web d'i3blocks : https://vivien.github.io/i3blocks
