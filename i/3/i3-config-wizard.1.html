NOM

i3-config-wizard - crée un fichier de configuration basé sur les symboles de touches basé sur votre disposition

SYNTAXE

i3-config-wizard [-s socket] [-m modificateur] [-v] [-h]

OPTIONS

-s, --socket socket

Remplace le chemin vers le socket IPC de i3.

-m, --modifier modificateur

Génère le fichier de configuration sans interface graphique. Accepte win ou alt.

-v, --version

Affiche le numéro de version et quitte.

-h, --help

Affiche un court message d'aide et quitte.

FICHIERS

/etc/i3/config.keycodes

Ce fichier contient la configuration par défaut avec les codes de touches. Toutes les lignes bindcode seront transformées en bindsym et le modificateur spécifié par l'utilisateur sera utilisé.

DESCRIPTION

i3-config-wizard est lancé par i3 dans sa configuration par défaut, à moins que ~/.i3/config n'existe. i3-config-wizard crée un fichier de configuration i3 basé sur les symboles de touches (basé sur /etc/i3/config.keycodes) dans ~/.i3/config.

L'avantage d'utiliser des symboles de touches est que le fichier de configuration est facile à lire, comprendre et modifier. Cependant, si nous avions fourni un fichier de configuration par défaut basé sur les symboles de touches, les positions des touches ne seraient pas cohérentes sur les différentes dispositions de clavier (prenez par exemple la rangée du milieu pour les déplacements). Par conséquent, nous fournissons une configuration par défaut basée sur les codes de touches et laissons l'assistant la transformer selon votre disposition de clavier actuelle.
