Paquet: i3-wm

Licences: BSD

NOM

i3-dmenu-desktop - exécute des fichiers .desktop avec dmenu

SYNTAXE

i3-dmenu-desktop [--dmenu='dmenu -i'] [--entry-type=name] [--show-duplicates]

DESCRIPTION

i3-dmenu-desktop est un script qui extrait le nom (localisé) des fichiers .desktop d'applications, offre un choix à l'utilisateur via dmenu(1), puis lance l'application choisie via i3 (pour le support des notifications de démarrage). L'avantage d'utiliser des fichiers .desktop au lieu de dmenu_run(1) est que dmenu_run propose tous les binaires de votre $PATH, y compris les utilitaires non interactifs comme "sed". De plus, les fichiers .desktop contiennent un nom approprié, des informations sur l'exécution de l'application dans un terminal et sur le support des notifications de démarrage.

Les fichiers .desktop sont recherchés dans $XDG_DATA_HOME/applications (par défaut $HOME/.local/share/applications) et dans le sous-répertoire "applications" de chaque entrée de $XDG_DATA_DIRS (par défaut /usr/local/share/:/usr/share/).

Les fichiers portant le même nom dans $XDG_DATA_HOME/applications ont priorité sur les fichiers dans $XDG_DATA_DIRS, de sorte que vous pouvez remplacer des parties des fichiers .desktop système en les copiant dans votre répertoire local et en apportant des modifications.

i3-dmenu-desktop affiche la valeur "Name" dans la version localisée en fonction de LC_MESSAGES, comme spécifié dans la spécification Desktop Entry.

Vous pouvez passer un nom de fichier ou une URL (codes de champ %f/%F et %u/%U dans le fichier .desktop respectivement) en l'ajoutant au nom de l'application. Par exemple, si vous souhaitez lancer "GNU Emacs 24" avec le patch /tmp/foobar.txt, vous taperiez "emacs", appuyeriez sur TAB, taperiez " /tmp/foobar.txt" et appuieriez sur ENTRÉE.

Les fichiers .desktop avec Terminal=true sont démarrés en utilisant i3-sensible-terminal(1).

Les fichiers .desktop avec NoDisplay=true ou Hidden=true sont ignorés.

UTF-8 est bien sûr pris en charge, mais dmenu ne permet pas d'afficher tous les glyphes. Par exemple, le Name[fi]=Pääte de xfce4-terminal.desktop s'affichera correctement, mais pas son Name[ru]=Терминал.

OPTIONS

--dmenu=commande
Exécute la commande au lieu de 'dmenu -i'. Cette option peut être utilisée pour passer des paramètres personnalisés à dmenu, ou pour faire démarrer i3-dmenu-desktop une version personnalisée (patchée ?) de dmenu.
--entry-type=type
Affiche le "Name" (localisé) (type = name), la commande (type = command) ou le nom du fichier (*.desktop) (type = filename) dans dmenu. Cette option peut être spécifiée plusieurs fois. Les doublons seront supprimés, voir '--show-duplicates'.

Les exemples sont "GNU Image Manipulation Program" (type = name), "gimp" (type = command) et "libreoffice-writer" (type = filename).

--show-duplicates
Affiche les doublons si '--entry-type' est spécifié plusieurs fois.
