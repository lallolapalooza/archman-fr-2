NOM

i3-input - interagir pour prendre une commande pour le gestionnaire de fenêtres i3

SYNOPSIS

i3-input [-s <socket>] [-F <format>] [-l <limite>] [-P <invite>] [-f <police>] [-v]

DESCRIPTION

i3-input est un outil pour prendre des commandes (ou des parties d'une commande) composées par l'utilisateur, et les envoyer à i3. Ceci est utile, par exemple, pour la commande mark/goto.

Vous pouvez appuyer sur Échap pour fermer i3-input sans envoyer de commande.

OPTIONS

-s <socket>

Spécifiez le chemin vers le socket IPC d'i3 (il ne devrait pas être nécessaire d'utiliser cette option, i3-input trouvera le chemin par lui-même).

-F <format>

Chaque occurrence de « %s » dans la chaîne <format> est remplacée par l'entrée de l'utilisateur, et le résultat est envoyé à i3 comme une commande. La valeur par défaut est « %s ».

-l <limite>

Définir la longueur maximale autorisée de l'entrée de l'utilisateur à <limite> caractères. i3-input exécutera automatiquement la commande lorsque l'entrée de l'utilisateur atteindra cette longueur.

-P <invite>

Afficher la chaîne <invite> devant le champ de saisie de l'utilisateur. La chaîne d'invite n'est pas incluse dans l'entrée/la commande de l'utilisateur.

-f <police>

Utiliser la police principale X11 spécifiée (utilisez xfontsel pour choisir une police).

-v

Afficher la version et quitter.

EXEMPLES

Marquer un conteneur avec un seul caractère :

i3-input -F 'mark %s' -l 1 -P 'Marquer : '

Aller au conteneur marqué avec l'exemple ci-dessus :

i3-input -F '[con_mark="%s"] focus' -l 1 -P 'Aller à : '

ENVIRONNEMENT

I3SOCK

i3-input gère les différentes sources de chemins de socket dans l'ordre suivant :

• Variable d'environnement I3SOCK
• I3SOCK est écrasé par le paramètre -s, s'il est spécifié
• si aucun des deux n'est disponible, i3-input lit le chemin du socket à partir de la propriété X11, ce qui est la méthode recommandée
• si tout échoue, i3-input essaie /tmp/i3-ipc.sock

Le chemin du socket est nécessaire pour se connecter à i3 et effectivement exécuter la commande.
