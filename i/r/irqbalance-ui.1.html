NAME

irqbalance-ui - interface utilisateur pour irqbalance

SYNOPSIS

irqbalance-ui

DESCRIPTION

irqbalance-ui fournit une interface utilisateur textuelle basée sur ncurses pour irqbalance, un démon responsable de la distribution des IRQ sur les systèmes Linux. Il montre comment les IRQ sont distribuées sur les CPU à un moment donné, et permet de configurer l'intervalle de veille et le bannissement des IRQ et des CPU à l'exécution.
