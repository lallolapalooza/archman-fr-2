FBB::IRandStream(3bobcat) Flux d'entrée de nombres aléatoires FBB::IRandStream(3bobcat)

NOM

FBB::IRandStream - Flux d'entrée produisant des nombres aléatoires

SYNTAXE

#include <bobcat/irandstream>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::IRandStream peuvent être utilisés pour extraire des nombres aléatoires dans une plage donnée d'un flux.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::istream,
FBB::RandBuffer (privé)

CONSTRUCTEURS

o
IRandStream(int max):
Ce constructeur FBB::IRandStream() initialise le générateur aléatoire. La graine par défaut (c'est-à-dire 1) de la fonction srand(3) est utilisée, ce qui signifie que chaque nouvelle exécution du programme générera la même séquence de valeurs aléatoires. Un autre constructeur (voir ci-dessous) est fourni lorsque cela n'est pas considéré comme approprié. Des valeurs aléatoires entre 1 et max (inclus) sont retournées.
o
IRandStream(int min, int max):
Ce constructeur FBB::IRandStream() initialise le générateur aléatoire. La graine par défaut (c'est-à-dire 1) de la fonction srand(3) est utilisée, ce qui signifie que chaque nouvelle exécution du programme générera la même séquence de valeurs aléatoires. Un autre constructeur (voir ci-dessous) est fourni lorsque cela n'est pas considéré comme approprié. Des valeurs aléatoires entre min et max (inclus) sont retournées.
o
IRandStream(int min, int max, size_t seed):
Ce constructeur FBB::IRandStream() initialise le générateur aléatoire. La graine est utilisée pour initialiser le générateur de nombres aléatoires. Pour démarrer le générateur aléatoire à un point imprévisible, time(0) pourrait être utilisé. Des valeurs aléatoires entre min et max (inclus) sont retournées.

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

MEMBRES HERITES

Étant donné que la classe utilise une dérivation publique de std::istream, tous les membres de cette classe peuvent être utilisés.

EXEMPLE

#include <iostream>
#include <bobcat/irandstream>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    if (argc == 1)
        cout << "\n"
                "Affichage d’une valeur aléatoire entre 1 et 1000 (inclus).\n"
                "Si vous voulez plus de valeurs, spécifiez le nombre demandé\n"
                "de valeurs comme premier argument du programme.\n"
                "Lors d’appels répétés, les mêmes nombres sont générés.\n\n";
    IRandStream in(1000);
    for (size_t count = argc == 1? 1 : stoul(argv[1]); count--; )
    {
        size_t random;
        in >> random;
        cout << random << endl;
    }
}
