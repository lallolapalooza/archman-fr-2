irdb-get(1) Commandes utilisateur irdb-get(1)

NOM

irdb-get - lister, rechercher et télécharger des fichiers de configuration lirc.

SYNTAXE

irdb-get update

irdb-get find <chaîne>

irdb-get info <id>

irdb-get download <id>

irdb-get list [modèle]

irdb-get find-driver <chaîne>

irdb-get yaml-config

irdb-get <-h|--help|-v|--version>

DESCRIPTION

irdb-get peut lister, rechercher et télécharger des fichiers de configuration de télécommande lirc. Il fonctionne en téléchargeant un fichier d'index, rendant toutes les opérations, à l'exception du téléchargement réel, locales.

Les entrées de l'index sont identifiées par un id. Un tel id est de la forme répertoire/télécommande, par ex. x10/ati_remote_wonder_III

COMMANDES

update
Télécharge l'index depuis le dépôt distant.
find <chaîne>
Liste toutes les entrées dans le fichier d'index correspondant à <chaîne>. La correspondance est effectuée en utilisant la syntaxe de correspondance de shell standard (c'est-à-dire, pas des expressions régulières).
find-driver <chaîne>
Liste toutes les entrées dans l'index avec un pilote donné. La correspondance est exacte, sans caractères génériques.
info <id>
Affiche plus d'informations sur une entrée donnée.
download <id>
Télécharge le fichier de configuration pour une entrée donnée. Le nom du fichier est affiché sur stdout.
list <modèle>
Liste les entrées correspondant à <modèle>. <modèle> est de la forme répertoire/télécommande, par ex. x10/ati* ou */ati_remote_wonder* .

Le premier mot de la liste est quelque chose comme -RL- où les lettres représentent :

R
Configuration brute.
T
La télécommande a des informations de synchronisation, c'est-à-dire qu'elle peut être utilisée avec des périphériques de capture génériques.
L
La télécommande a un fichier de configuration lircmd.
P
La télécommande a une photo.
yaml-config
Affiche un fichier YAML sur stdout qui mappe les pilotes aux fichiers de télécommande avec l'attribut driver correspondant. Le format est instable et est principalement utilisé par lirc-setup(1).

OPTIONS

-h , --help
Affiche le message d'aide.
-v , --version
Affiche les informations de version.

ENVIRONNEMENT

LIRC_REMOTES_URL
L'URL de base utilisée lors du téléchargement des fichiers de configuration, par défaut https://sourceforge.net/p/lirc-remotes/code/ci/master/tree.
LIRC_REMOTES_LIST
URL d'un fichier listant toutes les télécommandes, tel que créé par lirc-lsremotes(1). Par défaut http://lirc-remotes.sourceforge.net/remotes.list.
LIRC_IRDB_CACHE_ID
S'il est défini, remplace la date autrement imprimée dans la sortie de yaml-config. Ignoré pour les autres commandes. Utile pour des builds reproductibles avec XDG_CACHE_HOME.
XDG_CACHE_HOME
S'il est défini, déplace le fichier de liste des télécommandes téléchargé et mis en cache vers $XDG_CACHE_HOME/remotes.list, voir FICHIERS.

FICHIERS

~/.cache/remotes.list
Le fichier d'index téléchargé à la demande ou par la commande update.

VOIR AUSSI
