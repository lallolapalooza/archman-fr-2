IRPTY(1) Commandes utilisateur IRPTY(1)

NOM

irpty - Pilote de pseudo tty.

SYNOPSIS

irpty [options] fichier_config -- programme [args ...]

DESCRIPTION

irpty se connecte à lircd pour recevoir des codes infrarouges et les convertit en frappes au clavier. Par exemple, tapez irpty ~/.config/lircrc -- workbone pour contrôler le programme lecteur CD workbone. Bien sûr, vous devrez d'abord créer un fichier de configuration approprié à cet effet. La chaîne de configuration sera passée à l'application souhaitée. Notez que vous pouvez utiliser des séquences d'échappement pour spécifier des caractères non imprimables. Consultez la description du format du fichier .lircrc pour plus de détails.

OPTIONS

-h --help
affiche le résumé de l'utilisation
-V --version
affiche la version
-e --no-echo
désactive l'écho
-i --ignore-eof
ignore EOF
-n --non-interactive
force le mode non interactif
-v --verbose
mode verbeux

VOIR AUSSI

La documentation de lirc est maintenue sous forme de pages html. Elles sont situées dans le répertoire html/ de la documentation.
