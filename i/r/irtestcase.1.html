irtestcase(1) Commandes utilisateur irtestcase(1)

NOM

irtestcase - Créer ou vérifier des cas de test de décodage.

SYNTAXE

irtestcase [-l fichier_lircrc -p programme] <socket>

irtestcase [-l fichier_lircrc -p programme] -t données_test <socket>

irtestcase [-v|-h]

DESCRIPTION

irtestcase est un outil qui peut enregistrer les pressions de boutons d'une télécommande ainsi que les valeurs décodées. À partir de la sortie d'une autre session, il peut également vérifier que le décodage fonctionne toujours comme prévu.

Dans la première forme, irtestcase attendra une entrée et créera des fichiers journaux pour celle-ci. Ce faisant, il affiche également les boutons reçus sur stdout. Il n'y a aucun moyen d'arrêter le programme proprement, utilisez simplement ctrl-C une fois terminé.

Dans la seconde forme, il alimentera les données du fichier données_test à lircd et enregistrera les données décodées comme d'habitude. Ceci permet de tester la sortie de la télécommande qui a généré les données_test. Dans cette forme, lircd doit être exécuté avec le pilote "file".

Le socket optionnel est le socket de sortie de lircd (lircd doit être en cours d'exécution). Il prend par défaut la valeur de LIRC_SOCKET_PATH dans l'environnement, puis une valeur par défaut codée en dur (/var/run/lirc/lircd).

OPTIONS

-l, --lircrc <fichier_config_lircrc>
Enregistrer également les chaînes d'application (comme ircat(1)) en utilisant un fichier de configuration de type lircrc.
-p, --prog <id_programme>
Lors de l'utilisation de -l/--lircrc, le nom du programme correspondant aux entrées PROG = dans lircrc.
-t, --testdata
Utiliser les données du fichier au lieu de l'entrée "en direct" de la télécommande. Il peut s'agir du fichier durations.log d'une exécution précédente, voir FICHIERS. Il peut également s'agir de la sortie enregistrée de mode2(1).
-v , --version
Afficher la version et quitter.
-h , --help
Afficher le message d'aide.

ENVIRONNEMENT

irtestcase respecte LIRC_SOCKET_PATH qui, s'il est défini, contient le chemin vers le socket de sortie de lircd à écouter.

FICHIERS

/tmp/irtestcase
irtestcase crée des fichiers dans /tmp/irtestcase (codé en dur, désolé). Après une exécution réussie, vous trouverez :
durations.log
Durées de pouls/espacement imprimables dans le même format que mode2(1). Ce fichier est utilisable comme entrée pour -t/--testdata.
codes.log
Les boutons décodés, dans le même format que irw(1).
app_strings.log
Les chaînes d'application, telles que présentées par ircat(1).
~/.cache/irtestcase.log
Journal de débogage. La définition de la variable d'environnement XDG_CACHE_HOME déplace ce fichier vers $XDG_CACHE_HOME/irtestcase.log. La quantité de journalisation respecte la variable d'environnement LIRC_LOGLEVEL, prenant par défaut la valeur de débogage dans la section [lircd] de lirc_options.conf.

VOIR AUSSI
