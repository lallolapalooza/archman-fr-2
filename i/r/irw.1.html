IRW(1) Commandes utilisateur IRW(1)

NOM

irw - Envoyer des données depuis un socket de domaine Unix vers la sortie standard

SYNTAXE

irw [socket]

DESCRIPTION

irw se connectera à n'importe quel socket de domaine Unix et affichera les données reçues sur la sortie standard. Sans argument socket, il surveillera /var/run/lirc/lircd. Utile pour le débogage.

Options :

-h --help
Afficher le résumé d'utilisation
-v --version
Afficher la version

SIGNaux

Lors de la réception de SIGUSR1, irw s'arrête proprement.

EXEMPLE

Sauvegarder le socket par défaut tout en appuyant sur un bouton :

    myhost $ irw
    0000000000f40bf0 00 KEY_POWER ANIMAX
    0000000000f40bf0 01 KEY_POWER ANIMAX
    0000000000f40bf0 02 KEY_POWER ANIMAX
    0000000000f40bf0 03 KEY_POWER ANIMAX
    0000000000f40bf0 04 KEY_POWER ANIMAX
    0000000000f40bf0 05 KEY_POWER ANIMAX
    ^C
    myhost $
Notez que le deuxième compteur est incrémenté pour chaque nouvel événement généré
par une seule pression de touche. Ceci est important pour le bon fonctionnement de lircd.

NOTES

Étant donné que le socket lircd prend en charge plusieurs clients, irw peut fonctionner en parallèle avec d'autres applications.

irw ne fait rien d'autre que de vider un socket de domaine Unix, une tâche que de nombreux outils standard peuvent également effectuer. Par exemple, l'outil ncat(1) peut être utilisé à la place d'irw pour plus de flexibilité (mais sans socket par défaut raisonnable) :

    ncat -U /var/run/lirc/lircd

VOIR AUSSI

La documentation de lirc est maintenue sous forme de pages html. Elles se trouvent sous html/ dans le répertoire de documentation.
