IRCAT(1) Commandes utilisateur IRCAT(1)

NOM

ircat - affiche des chaînes lors de la pression sur des boutons

SYNTAXE

ircat [options] <prog>

DESCRIPTION

Ce programme affiche des chaînes de configuration sur la sortie standard. Il peut être utilisé pour fournir une entrée de télécommande à des scripts et pour déboguer votre fichier .lircrc.

L'argument du programme est le nom du programme, tel qu'il apparaît dans les entrées prog de .lircrc.

-h --help
Affiche le résumé d'utilisation.
-v --version
Affiche la version.
-c --config=<fichier>
Définit le fichier de configuration.

EXEMPLES

Si .lircrc contient :

begin
        prog = myprog
        button = KEY_CHANNELUP
        config = next_file
end

alors

$ ircat myprog

affichera "next_file" (suivi d'un retour à la ligne) à chaque fois que le bouton associé à KEY_CHANNELUP est pressé.

ENVIRONNEMENT

LIRC_SOCKET_PATH
Le socket de sortie de lircd(8) utilisé pour récupérer les données. Par défaut, c'est /var/run/lirc/lircd

VOIR AUSSI

La documentation de lirc est maintenue sous forme de pages html. Elles sont situées dans le répertoire html/ du répertoire de documentation.
