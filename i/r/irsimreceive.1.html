irsimreceive(1) Commandes utilisateur irsimreceive(1)

NOM

irsimreceive - Décode les données de durée IR.

SYNTAXE

irsimreceive [options] <fichier de configuration> <fichier de données>

DESCRIPTION

Ceci est un outil de test simple qui décode les données de durée dans fichier de données en utilisant un fichier de configuration de type lircd.conf. Les données générées sont dans le même format que sur le socket de sortie de lircd.

OPTIONS

-U, --plugindir <répertoire>
Charge les pilotes depuis le <répertoire>.
-v , --version
Affiche la version et quitte.
-h , --help
Affiche le message d'aide.

FICHIERS

~/.cache/irsimreceive.log
Journal de débogage. La définition de la variable d'environnement XDG_CACHE_HOME déplace ce fichier vers $XDG_CACHE_HOME/irsimreceive.log. La quantité de journalisation respecte la variable d'environnement LIRC_LOGLEVEL, utilisant par défaut la valeur de débogage dans la section [lircd] de lirc_options.conf.

VOIR AUSSI
