IRSEND(1) Commandes utilisateur IRSEND(1)

NOM

irsend - programme LIRC basique pour envoyer des commandes infrarouges

SYNOPSIS

irsend [options] send_once <remote> <code> [code...]
irsend [options] send_start <remote> <code>
irsend [options] send_stop <remote> <code>
irsend [options] list <remote> <code>
irsend [options] set_transmitters <num> [num...]
irsend [options] simulate <bouton pression paquet>

DESCRIPTION

Demande au démon lircd d'envoyer une ou plusieurs commandes CIR (Consumer Infra-Red). Ceci est destiné au contrôle à distance des appareils électroniques tels que les boîtiers TV, les chaînes HiFi, etc.

irsend prend en charge six sous-commandes :

send_once         - envoyer un ou plusieurs code(s) une fois
send_start        - démarrer la répétition d'un code.
send_stop         - arrêter la répétition d'un code.
list              - lister les éléments distants configurés
set_transmitters  - définir les émetteurs actifs
simulate          - simuler un événement IR

remote est le nom d'une télécommande, tel que décrit dans le fichier de configuration lircd.

code est le nom d'une touche de télécommande de remote, tel qu'il apparaît dans le fichier de configuration lircd.conf.

num est le numéro de l'émetteur du périphérique matériel.

Pour la commande list, remote et/ou code peuvent être vides :

list   ""    ""   - lister tous les noms de télécommandes configurés
list remote  ""   - lister tous les codes de remote
list remote code  - lister seulement code de remote

La commande simulate ne fonctionne que si elle a été explicitement activée dans lircd en utilisant l'option --allow-simulate. Le bouton pression paquet requis doit être formaté comme un message de diffusion socket documenté dans lircd(8).

OPTIONS

-h --help
Afficher le résumé de l'utilisation.
-v --version
Afficher la version.
-d --device=périphérique
Utiliser le socket lircd donné [/var/run/lirc/lircd].
-a --address=hôte[:port]
Se connecter à lircd à cette adresse.
-# --count=n
Envoyer la commande n fois.

ENVIRONNEMENT

LIRC_SOCKET_PATH
Le socket lircd à connecter, par défaut une valeur codée en dur /var/run/lirc/lircd

FICHIERS

/etc/lirc/lircd.conf
Fichier de configuration par défaut de lircd. Il devrait contenir toutes les télécommandes, leurs codes infrarouges et les détails de synchronisation et de forme d'onde correspondants.

DIAGNOSTICS

Si lircd n'est pas en cours d'exécution (ou si /var/run/lirc/lircd manque de permissions d'écriture), irsend s'arrête avec les diagnostics suivants :

"irsend: unable to connect to socket"
"irsend: Connection refused" (ou "Permission denied").

EXEMPLES

irsend LIST DenonTuner ""
irsend SEND_ONCE  DenonTuner PROG-SCAN
irsend SEND_ONCE  OnkyoAmpli VOL-UP VOL-UP VOL-UP VOL-UP
irsend SEND_START OnkyoAmpli VOL-DOWN ; sleep 3
irsend SEND_STOP  OnkyoAmpli VOL-DOWN
irsend SET_TRANSMITTERS 1
irsend SET_TRANSMITTERS 1 3 4
irsend SIMULATE "0000000000000476 00 OK TECHNISAT_ST3004S"

CHARGEMENT DES PILOTES

Les pilotes sont chargés dynamiquement. Le répertoire utilisé à cet effet est déterminé par (priorité décroissante) :

  • La variable d'environnement LIRC_PLUGINDIR.
  • L'entrée 'plugindir' dans la section [lircd] du fichier lirc_options.conf.
  • Une valeur par défaut codée en dur (/usr/lib/lirc/plugins).
