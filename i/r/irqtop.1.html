IRQTOP(1) Commandes utilisateur IRQTOP(1)

NOM

irqtop - utilitaire pour afficher les informations sur les compteurs d'interruptions du noyau

SYNTAXE

irqtop [options]

DESCRIPTION

Affiche les informations des compteurs d'interruptions du noyau dans une vue de style top(1).

La sortie par défaut est sujette à modification. Par conséquent, lorsque cela est possible, vous devez éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant --output.

OPTIONS

-o, --output liste

Spécifie quelles colonnes de sortie afficher. Utilisez --help pour obtenir une liste de toutes les colonnes prises en charge. La liste par défaut des colonnes peut être étendue si la liste est spécifiée sous la forme +liste.

-c, --cpu-stat mode

Affiche les statistiques par CPU selon le mode spécifié. Les modes disponibles sont : auto, enable, disable. L'option par défaut auto détecte la largeur de la fenêtre, puis affiche les statistiques par CPU si la largeur de la fenêtre est suffisamment grande pour afficher une ligne complète de statistiques.

-C, --cpu-list liste

Spécifie les CPU dans un format de liste à afficher.

-d, --delay secondes

Met à jour la sortie des interruptions toutes les secondes.

-s, --sort colonne

Spécifie le critère de tri par nom de colonne. Voir la sortie de --help pour obtenir les noms des colonnes. Le critère de tri peut être modifié en mode interactif.

-S, --softirq

Affiche les informations sur les softirqs.

-t, --threshold min

N'affiche que les IRQ dont les compteurs dépassent le seuil spécifié. Les valeurs lisibles par l'homme sont prises en charge (par exemple, 1.2K).

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

COMMANDES CLAVIER EN MODE INTERACTIF

i

trie par nom court d'irq ou par champ numéro

t

trie par nombre total d'interruptions (par défaut)

d

trie par nombre delta d'interruptions

n

trie par champ de nom descriptif long

q Q

arrête les mises à jour et quitte le programme
