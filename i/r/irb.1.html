IRB(1) 1 (Guide de référence du programmeur Ruby) IRB(1)

NOM

irb — Console interactive Ruby

SYNTAXE

irb [--version] [-dfUw] [-I répertoire] [-r bibliothèque] [-E externe[:interne]] [-W[niveau]] [--[pas]inspect] [--[pas]multiline] [--[pas]singleline] [--[pas]echo] [--[pas]colorize] [--[pas]autocomplete] [--[pas]verbose] [--prompt mode] [--prompt-mode mode] [--inf-ruby-mode] [--simple-prompt] [--noprompt] [--tracer] [--back-trace-limit n] [--] [fichier_programme] [argument ...]

DESCRIPTION

irb est l'environnement REPL (read-eval-print loop) pour les programmes Ruby.

OPTIONS

--version
Affiche la version de irb.
-E externe[:interne]
 
--encoding externe[:interne]
Identique à `ruby -E' . Spécifie la ou les valeurs par défaut pour les encodages externes et l'encodage interne. Les valeurs doivent être séparées par deux-points (:).

Vous pouvez omettre celui pour les encodages internes, alors la valeur (Encoding.default_internal) sera nil.

-I chemin
Identique à `ruby -I' . Spécifie le répertoire de $LOAD_PATH.
-U
Identique à `ruby -U' . Définit la valeur par défaut pour les encodages internes (Encoding.default_internal) à UTF-8.
-d
Identique à `ruby -d' . Définit $DEBUG à vrai.
-f
Supprime la lecture de ~/.irbrc.
-w
Identique à `ruby -w'.
-W
Identique à `ruby -W'.
-h
 
--help
Affiche un résumé des options.
-r bibliothèque
Identique à `ruby -r'. Fait en sorte que irb charge la bibliothèque en utilisant require.
--inspect
Utilise `inspect' pour la sortie (par défaut sauf en mode bc)
--noinspect
N'utilise pas inspect pour la sortie.
--multiline
Utilise le module d'édition multiligne.
--nomultiline
N'utilise pas le module d'édition multiligne.
--singleline
Utilise le module d'édition à ligne unique.
--nosingleline
N'utilise pas le module d'édition à ligne unique.
--extra-doc-dir
Ajoute un répertoire de documentation supplémentaire pour la boîte de dialogue de documentation.
--echo
Affiche le résultat (par défaut).
--noecho
N'affiche pas le résultat.
--echo-on-assignment
Affiche le résultat lors d'une affectation.
--noecho-on-assignment
N'affiche pas le résultat lors d'une affectation.
--truncate-echo-on-assignment
Affiche un résultat tronqué lors d'une affectation (par défaut).
--colorize
Utilise la coloration.
--nocolorize
N'utilise pas la coloration.
--autocomplete
Utilise l'autocomplétion.
--noautocomplete
N'utilise pas l'autocomplétion.
--regexp-completor
Utilise la complétion basée sur les expressions régulières.
--type-completor
Utilise la complétion basée sur les types.
--verbose
Affiche les détails.
--noverbose
N'affiche pas les détails.
--prompt mode
 
--prompt-mode mode
Change le mode de prompt. Les modes de prompt prédéfinis sont `default', `simple', `xmp' et `inf-ruby'.
--inf-ruby-mode
Utilise un prompt approprié pour le mode inf-ruby sur emacs. Supprime --multiline et --singleline.
--simple-prompt
Rend les prompts simples.
--noprompt
Mode sans prompt.
--tracer
Affiche la trace de chaque exécution de commande.
--back-trace-limit n
Affiche le début du backtrace sur n éléments et la fin sur n éléments. La valeur par défaut est 16.

ENVIRONNEMENT

IRB_LANG
La locale utilisée pour irb.
IRBRC
Le chemin vers le fichier d'initialisation personnel.
XDG_CONFIG_HOME
irb respecte XDG_CONFIG_HOME. S'il est défini et IRBRC n'est pas défini, charge $XDG_CONFIG_HOME/irb/irbrc comme fichier d'initialisation personnel.
RI_PAGER
La commande spécifiée

De plus, irb dépend des mêmes variables que ruby(1).

FICHIERS

~/.irbrc
Initialisation personnelle de irb. Si IRBRC est défini, lire $IRBRC à la place. Si IRBRC n'est pas défini et XDG_CONFIG_HOME est défini, $XDG_CONFIG_HOME/irb/irbrc est chargé.

EXEMPLES

% irb
irb(main):001:0> 1 + 1
2
irb(main):002:0> def t(x)
irb(main):003:1> x + 1
irb(main):004:1> end
=> :t
irb(main):005:0> t(3)
=> 4
irb(main):006:0> if t(3) == 4
irb(main):007:1> p :ok
irb(main):008:1> end
:ok
=> :ok
irb(main):009:0> quit
%
