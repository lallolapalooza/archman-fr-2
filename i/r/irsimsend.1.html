irsimsend(1) Commandes utilisateur irsimsend(1)

NOM

irsimsend - Envoie des données IR simulées.

SYNTAXE

irsimsend [-k clef |-l fichierliste ] [autres options] <fichier>

irsimsend [-v |-h]

irsimsend <fichierconfig>

DESCRIPTION

irsimsend est un outil de test simple qui, à partir d'un fichier de configuration lircd, envoie toutes les clés définies dans ce fichier, les clés listées dans un autre fichier ou un symbole défini en ligne de commande.

Le programme utilise le pilote de fichier pour enregistrer toutes les données envoyées (durées des impulsions/espaces) dans un fichier 'simsend.out'. Les symboles envoyés sont affichés sur la sortie standard.

OPTIONS

-c, --count <compteur>
Répète chaque signal envoyé <compteur> fois.
-U, --plugindir <chemin>
Charge les pilotes depuis chemin, un chemin de recherche séparé par des ':' similaire à $PATH.
-l,--listfile <chemin>
Envoie les symboles listés dans le fichier au lieu des seuls symboles du fichier de configuration. Le fichier peut soit lister un seul symbole de clé par ligne, soit contenir une chaîne de code complète comme 000000000000a123 01 KEY_POWER brand sur chaque ligne.
-k, --keysym
Envoie un seul symbole de clé défini dans fichier.
-s, --start-space <microsecondes>
Envoie un espace initial avant d'envoyer les données.
-v , --version
Affiche la version et quitte.
-h , --help
Affiche le message d'aide.

FICHIERS

~/.cache/irsimsend.log
Journal de débogage. La définition de la variable d'environnement XDG_CACHE_HOME déplace ce fichier vers $XDG_CACHE_HOME/irsimsend.log. Le niveau de journalisation respecte la variable d'environnement LIRC_LOGLEVEL, qui utilise par défaut la valeur de débogage dans la section [lircd] de lirc_options.conf.
