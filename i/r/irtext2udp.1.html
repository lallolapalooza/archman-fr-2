irtext2udp(1) Commandes utilisateur irtext2udp(1)

NOM

irtext2udp - Convertir des données textuelles d'impulsions/espaces au format binaire du pilote UDP

SYNTAXE

irtext2udp [-r résolution] [fichier]

DESCRIPTION

irtext2udp est un filtre qui convertit des données textuelles imprimables d'impulsions/espaces, telles que celles générées par mode2(1), au format binaire utilisé par le pilote UDP de LIRC.

L'argument fichier est un fichier texte contenant des données d'impulsions/espaces. S'il n'est pas donné, l'entrée standard est utilisée. Les lignes ne commençant pas par space ou pulse sont silencieusement ignorées.

Le modèle d'utilisation normal consiste à combiner irtext2udp avec des outils standard tels que ncat(1) ou socat(1) pour envoyer les données binaires à une instance de lircd utilisant le pilote udp.

OPTIONS

-r, --résolution <résolution>
Les paquets UDP sont mesurés en « ticks ». La longueur de chaque tick est définie par la résolution. La valeur par défaut est 61, calculée comme 1000000/16384 et correspondant à 1/16384 secondes. Ceci est dérivé d'anciennes conceptions utilisant une horloge de 32 kHz.
-v , --version
Affiche la version et quitte.
-h , --help
Affiche le message d'aide.

EXEMPLES

Utiliser ncat(1) ou socat(1) pour envoyer des données à une instance de lircd utilisant le pilote udp, en écoute sur le port udp par défaut 8765 sur localhost :

    irtext2udp < fichier-entree | nc --udp localhost 8765
    irtext2udp < fichier-entree | socat STDIN UDP:localhost:8765
