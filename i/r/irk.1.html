NOM

irk - programme de test pour irkerd

SYNTAXE

irk [cible] [message texte]

DESCRIPTION

irk est un programme de test simple pour irkerd(8). Il construira un objet JSON simple et le passera au démon exécuté sur localhost.

OPTIONS

irk prend les options suivantes :

cible

Quel serveur et quel canal rejoindre pour annoncer le message. S'il n'est pas préfixé par "irc:", il préfixera "irc://chat.freenode.net/" à l'argument avant de le passer directement à irkerd. Cet argument est passé comme paramètre "to" dans l'objet JSON.

message

Quel message envoyer à la cible spécifiée ci-dessus. Si la chaîne est "-", le message sera lu depuis l'entrée standard, avec les sauts de ligne supprimés.

LIMITATIONS

irk n'a pas d'aide en ligne de commande et peut contenir des bogues.

irk ne sait pas comment communiquer avec votre VCS préféré. Vous voudrez généralement utiliser irkerhook(1) à la place

irk a également toutes les limitations d'irkerd.

VOIR AUSSI

irkerhook(1),

AUTEUR

Eric S. Raymond <esr@snark.thyrsus.com>. Voir la page du projet à http://www.catb.org/~esr/irker pour les mises à jour et autres ressources, y compris un script de hook de dépôt installable.
