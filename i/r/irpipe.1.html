IRPIPE(1) Commandes utilisateur IRPIPE(1)

NOM

irpipe - outil pour envoyer des données à lircd via le périphérique kernel /dev/irpipe.

SYNTAXE

irpipe [options] <fichier

irpipe --read [options] >fichier

irpipe --filter [options] <fichier_entree >fichier_sortie

DESCRIPTION

irpipe est conçu pour alimenter lircd(8) via un périphérique /dev/irpipe. C'est un outil pour entrer des données de test dans lircd d'une manière qui est identique aux données réelles provenant des périphériques /dev/lirc.

irpipe utilise deux formats : texte et binaire. Le format binaire est documenté dans la page de manuel lirc(4). Le format texte est tel que défini dans mode2(1).

Le pilote irpipe permet à l'utilisateur de définir les fonctionnalités renvoyées par l'appel système LIRC_GET_FEATURES. Celles-ci sont documentées dans lirc(4).

Le périphérique kernel irpipe n'est souvent pas compilé dans les versions packagées de lirc. Voir [PILOTE KERNEL] ci-dessous.

OPTIONS

-d --device=pilote
Définit le périphérique kernel, par défaut est /dev/irpipe0.
-b --bin2text
Convertit les données binaires en texte.
-t --text2bin
Convertit les données texte en binaire.
-s --add-sync
Ajoute une longue synchronisation initiale sur la sortie convertie. Ceci est souvent requis pour que lircd puisse décoder les données, en particulier si les touches ne sont pas répétées.
-f --filter
Envoie les données de stdin vers stdout.
-r --read
Envoie les données du périphérique kernel vers stdout. Cette option est expérimentale et non testée.
-l--length=bits
Définit la longueur du signal du périphérique kernel. Ceci n'est significatif que sur l'émulation de périphérique LIRCCODE.
-F--features=masque_bits
Définit le masque de bits des fonctionnalités, tel que renvoyé par l'appel système LIRC_GET_FEATURES. Voir lirc(4) pour plus d'informations.
-h --help
Affiche le résumé d'utilisation.
-v --version
Affiche la version.

PILOTE KERNEL

L'outil irpipe est conçu pour fonctionner avec le pilote kernel irpipe, bien que l'option --filter fonctionne sans lui. Ce pilote n'est souvent pas compilé dans les versions packagées. Si c'est le cas, le pilote peut être compilé à partir des sources dans le répertoire drivers/irpipe. Cela nécessite les sources du kernel installées. Le fichier README dans drivers/irpipe fournit des informations sur la compilation et l'installation du pilote.
