IXPLORE(1) Serveur Autoritatif PowerDNS IXPLORE(1)

NOM

ixplore - Un outil qui fournit des informations sur les IXFR

SYNOPIS

ixplore COMMANDE OPTION_COMMANDE...

ixplore diff ZONE AVANT APRÈS

ixplore track ADRESSE_IP PORT ZONE RÉPERTOIRE

DESCRIPTION

ixplore est un outil permettant de travailler avec les IXFR (transferts de zone incrémentaux) selon deux modes (spécifiés par COMMANDE) : diff ou track.

En mode 'diff', il affichera une sortie similaire à diff(1) entre AVANT et APRÈS.

En mode 'track', ixplore consomme les IXFR de ADRESSE_IP et écrit les fichiers de zone résultants dans RÉPERTOIRE/ZONE-numéro_de_série. Si aucun fichier de zone initial n'existe, un AXFR initial sera effectué en premier. ixplore vérifiera ensuite la série SOA sur ADRESSE_IP pour ZONE toutes les secondes de rafraîchissement SOA et effectuera un IXFR si la série a augmenté.

OPTIONS

MODE DIFF

ZONE
Le nom de la zone à partir de laquelle les IXFR sont consommés.
AVANT
Chemin vers le fichier de zone 'avant'.
APRÈS
Chemin vers le fichier de zone 'après'.

MODE TRACK

ADRESSE IP
L'adresse IP à partir de laquelle consommer les IXFR.
PORT
Le port à utiliser sur ADRESSE IP.
ZONE
Nom de la zone dont il faut suivre les changements.
RÉPERTOIRE
Répertoire où seront stockés les fichiers de zone.

VOIR AUSSI
