IXFRDIST(1) Serveur faisant autorité PowerDNS IXFRDIST(1)

NOM

ixfrdist - Un serveur exclusivement IXFR/AXFR qui redistribue les zones

SYNTAXE

ixfrdist [OPTION]...

DESCRIPTION

ixfrdist transfère des zones d'un serveur faisant autorité et redistribue ces zones via AXFR et IXFR. Il vérifie le numéro de série SOA pour tous les domaines configurés et télécharge les nouvelles versions sur disque.

Lorsqu'une requête SOA arrive et que l'adresse du client est autorisée par l'ACL, ixfrdist répond avec le dernier SOA pour la zone qu'il possède. Cette requête peut être suivie d'une requête IXFR ou AXFR, qui sera alors servie au client. Si un IXFR est servi, ixfrdist condensera toutes les différences qu'il a pour le domaine en un seul IXFR.

ixfrdist est configuré avec un fichier de configuration au format YAML. Veuillez consulter ixfrdist.yml(5) pour plus d'informations.

OPTIONS

--help
Afficher toutes les options prises en charge
--verbose
Journaliser les messages INFO
--debug
Journaliser les messages INFO et DEBUG
--version
Afficher la version de ixfrdist
--config <CHEMIN>
Charger la configuration depuis CHEMIN, un fichier YAML. Si non défini, un fichier ixfrdist.yml est tenté d'être lu depuis SYSCONFDIR.

VOIR AUSSI

ixplore(1), pdns_server(1), ixfrdist.yml(5)
