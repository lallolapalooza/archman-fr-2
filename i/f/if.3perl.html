if(3perl) Guide de référence du programmeur Perl if(3perl)

NOM

if - "use" un module Perl si une condition est remplie

SYNTAXE

use if CONDITION, "MODULE", ARGUMENTS;
no  if CONDITION, "MODULE", ARGUMENTS;

DESCRIPTION

"use if"

Le module "if" est utilisé pour charger conditionnellement un autre module. La construction :

use if CONDITION, "MODULE", ARGUMENTS;

... chargera "MODULE" seulement si "CONDITION" est évalué comme vrai ; elle n'a aucun effet si "CONDITION" est évalué comme faux. (Le nom du module, en supposant qu'il contienne au moins un "::", doit être mis entre guillemets lorsque 'use strict "subs";' est en vigueur.) Si la CONDITION est effectivement évaluée comme vraie, alors la ligne ci-dessus a le même effet que :

use MODULE ARGUMENTS;

Par exemple, la fonction charinfo du module Unicode::UCD utilisera deux fonctions de Unicode::Normalize seulement si une certaine condition est remplie :

use if defined &DynaLoader::boot_DynaLoader,
    "Unicode::Normalize" => qw(getCombinClass NFD);

Supposons que vous vouliez que "ARGUMENTS" soit une liste vide, c'est-à-dire que l'effet soit :

use MODULE ();

Vous ne pouvez pas le faire avec le pragma "if" ; cependant, vous pouvez obtenir exactement cet effet, au moment de la compilation, avec :

BEGIN { require MODULE if CONDITION }

"no if"

La construction "no if" est principalement utilisée pour désactiver certaines catégories d'avertissements lorsque ces catégories produiraient une sortie superflue sous certaines versions de perl.

Par exemple, la catégorie d'avertissements "redundant" a été introduite dans Perl-5.22. Cet avertissement signale certaines occurrences d'arguments superflus à "printf" et "sprintf". Mais si votre code fonctionnait sans avertissements sur les versions antérieures de perl et que vous ne vous souciez pas des avertissements "redundant" dans les versions plus récentes, vous pouvez appeler :

use warnings;
no if $] >= 5.022, q|warnings|, qw(redundant);
my $test    = { fmt  => "%s", args => [ qw( x y ) ] };
my $result  = sprintf $test->{fmt}, @{$test->{args}};

La construction "no if" suppose qu'un module ou un pragma a correctement implémenté une méthode unimport() -- mais la plupart des modules et pragmas ne l'ont pas fait. Cela explique pourquoi la construction "no if" a une applicabilité limitée.

BOGUES

L'implémentation actuelle ne permet pas de spécifier la version requise du module.

VOIR AUSSI

Module::Requires peut être utilisé pour charger conditionnellement un ou plusieurs modules, avec des contraintes basées sur la version du module. Contrairement à "if", cependant, Module::Requires n'est pas un module de base.

Module::Load::Conditional fournit un certain nombre de fonctions que vous pouvez utiliser pour interroger quels modules sont disponibles, puis en charger un ou plusieurs à l'exécution.

Le module provide de CPAN peut être utilisé pour sélectionner un parmi plusieurs modules possibles à charger en fonction de la version de Perl en cours d'exécution.
