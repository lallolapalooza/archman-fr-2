NOM

ifdata - obtenir des informations d'interface réseau sans analyser la sortie de ifconfig

SYNTAXE


ifdata
[options] {interface}

DESCRIPTION

ifdata peut être utilisé pour vérifier l'existence d'une interface réseau, ou pour obtenir des informations sur l'interface, comme son adresse IP. Contrairement à ifconfig ou ip, ifdata a une sortie simple à analyser, conçue pour être facilement utilisée par un script shell.

OPTIONS

-h
Affiche un résumé d'aide.
-e
Teste si l'interface existe, renvoie une sortie non nulle si elle n'existe pas.
-p
Affiche toute la configuration de l'interface.
-pe
Affiche "yes" ou "no" selon que l'interface existe ou non.
-pa
Affiche l'adresse IPv4 de l'interface.
-pn
Affiche le masque de réseau de l'interface.
-pN
Affiche l'adresse réseau de l'interface.
-pb
Affiche l'adresse de diffusion de l'interface.
-pm
Affiche le MTU de l'interface.

Les options suivantes sont réservées à Linux.

-ph
Affiche l'adresse matérielle de l'interface. S'arrête avec un code d'échec s'il n'y a pas d'adresse matérielle pour l'interface réseau donnée.
-pf
Affiche les drapeaux (flags) de l'interface.
-si
Affiche toutes les statistiques d'entrée de l'interface.
-sip
Affiche le nombre de paquets reçus.
-sib
Affiche le nombre d'octets reçus.
-sie
Affiche le nombre d'erreurs de réception.
-sid
Affiche le nombre de paquets reçus abandonnés.
-sif
Affiche le nombre de dépassements de capacité FIFO d'entrée.
-sic
Affiche le nombre de paquets reçus compressés.
-sim
Affiche le nombre de paquets multicast reçus.
-so
Affiche toutes les statistiques de sortie de l'interface.
-sop
Affiche le nombre de paquets transmis.
-sob
Affiche le nombre d'octets transmis.
-soe
Affiche le nombre d'erreurs de transmission.
-sod
Affiche le nombre de paquets transmis abandonnés.
-sof
Affiche le nombre de dépassements de capacité FIFO de sortie.
-sox
Affiche le nombre de collisions de transmission.
-soc
Affiche le nombre de pertes de porteuse de sortie.
-som
Affiche le nombre de paquets multicast transmis.
-bips
Affiche le nombre d'octets de trafic entrant mesuré en une seconde.
-bops
Affiche le nombre d'octets de trafic sortant mesuré en une seconde.
