DESCRIPTIO

N

Les objets FBB::IFilterBuf peuvent être utilisés comme un std::streambuf pour les objets std::istream, filtrant les informations produites par ces

objets.

Étant donné que IFilterBuf est un streambuf, son membre underflow est automatiquement appelé lorsque des opérations de lecture sont demandées à partir de l'objet flux utilisant IFilterBuf comme son streambuf. Si aucun caractère n'est actuellement disponible (c'est-à-dire srcBegin == srcEnd, voir la description du membre filter ci-dessous), alors filter est appelé, ce qui peut stocker des caractères dans un tampon (local) d'au plus maxSize caractères (voir la description du constructeur IFilterBuf ci-dessous). Une fois ce tampon rempli, filter met à jour les pointeurs *srcBegin et *srcEnd afin qu'ils pointent respectivement vers l'emplacement du premier caractère dans le tampon local et au-delà de l'emplacement du dernier caractère dans le tampon

local.

La classe IFilterBuf a été conçue en pensant au BIO openSSL (cf. bio(3ssl)). Puisque le concept de BIO a été développé dans le contexte du langage de programmation C, les BIO ne prennent pas en charge les flux C++. Néanmoins, le concept d'un dispositif de filtrage est attractif et est offert par la classe FBB::IFilte

rBuf.

En plus du filtrage, IFilterBuf offre une gestion flexible du tampon interne : les classes dérivées peuvent remettre des caractères sur le tampon interne jusqu'à ce que le début du tampon soit atteint, mais peuvent ensuite continuer à pousser des caractères sur le tampon jusqu'à ce que le tampon ait atteint sa taille maximale. Cette taille maximale est définie par le paramètre maxSize du constructeur (voir ci-dessous)

.

La classe IFilterBuf est une classe de base abstraite. Elle est utilisée via des classes dérivées de IFilterBuf, implémentant son membre virtuel pur load (voir ci-dessous à FONCTIONS MEMBRES V

IRTUELLES
PRIVÉES).

FONCTIONS MEMBRES VIRTUELLES

PRIVÉES
o
virtual bool filter(char const **srcBegin, char const **srcEnd) = 0 :
Le membre filter est déclaré comme un membre virtuel pur : les classes dérivées doivent remplacer filter par leur propre
implémentation.
Les objets des classes dérivées sont responsables de l'obtention d'informations (en quelque quantité que ce soit) du dispositif avec lequel elles interagissent. Ces informations sont ensuite transmises à IFilterBuf via deux pointeurs, pointant respectivement vers le premier caractère disponible et au-delà du dernier caractère disponible. Les caractères indiqués par cette plage sont ensuite transférés par l'objet IFilterBuf vers son propre tampon, d'où ils sont ensuite récupérés (ou vers lequel ils peuvent être repoussés) par
l'application.
Le membre filter permet aux implémentations de filtrer et/ou de modifier les informations obtenues par ce membre. La section EXEMPLE ci-dessous fournit un exemple filtrant un ensemble configurable de caractères à partir d'un std::istream fourni. Les classes ISymCryptStreambuf(3bobcat) et IBase64Buf(3bobcat) de Bobcat fournissent des exemples supplémentaires de classes dérivées de IFilterBu
f.
Le membre filter devrait retourner false si aucune information (plus) n'est disponible. Il devrait retourner true si de l'information est disponible, auquel cas *srcBegin et *srcEnd devraient pointer respectivement vers le premier caractère et au-delà du dernier caractère rendu disponible par filte

EXEMPL

E

Voici une classe, dérivée de IFilterBuf, filtrant un ensemble prédéfini de caractères. Elle est utilisée deux fois pour filtrer les chiffres et les voyelles, illustrant le chaînage des objets IFilterBuf

. 
#include <iostream>
#include <fstream>
#include <istream>
#include <string>
#include <bobcat/ifilterbuf>
using namespace std;
using namespace FBB;
class CharFilterStreambuf: public IFilterBuf
{
    istream &         // flux à lire
    string d_rmChars;      // caractères à supprimer
    string d_buffer;       // caractères tamponnés localement
    size_t const d_maxSize = 100;
    public:
        CharFilterStreambuf(istream &in, string const &rmChars);
    private:
        bool filter(char const **srcBegin,
                    char const **srcEnd) override;
};
CharFilterStreambuf::CharFilterStreambuf(istream &in,
                                         string const &rmChars)
:
    d_in(in),
    d_rmChars(rmChars)
{
    setBuffer();        // requis si peek() doit retourner le 1er
}                       // caractère disponible dès le départ
bool CharFilterStreambuf::filter(char const **srcBegin,
                                 char const **srcEnd)
{
    d_buffer.clear();
    while (d_buffer.size() != d_maxSize)
    {
        char ch;
        if (not d_in.get(ch))
            break;
        if (d_rmChars.find(ch) != string::npos) // found char to rm
            continue;
        d_buffer.push_back(ch);
    }
    if (d_buffer.empty())
        return false;
    *srcBegin = d_buffer.data();
    *srcEnd = d_buffer.data() + d_buffer.size();
    return true;
}
int main(int argc, char **argv)
{
    if (argc == 1)
    {
        cout << "arg[1]: file to process, arg[2]: processed file\n";
        return 0;
    }
    ifstream in{ argv[1] };
    CharFilterStreambuf buf1(in, "1234567890");
    istream in1(&buf1);
    CharFilterStreambuf buf2(in1, "AEIOUaeiou");
    istream in2(&buf2);
    ofstream out{ argv[2] };
    out << in2.rdbuf();
}
