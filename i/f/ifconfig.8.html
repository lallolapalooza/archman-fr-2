DESCRIPTIO

N

Ifconfig est utilisé pour configurer les interfaces réseau résidant dans le noyau. Il est utilisé au démarrage pour configurer les interfaces si nécessaire. Après cela, il n'est généralement nécessaire que pour le débogage ou lorsque l'ajustement du système est

requis.

Si aucun argument n'est donné, ifconfig affiche l'état des interfaces actuellement actives. Si un seul argument interface est donné, il affiche l'état de l'interface donnée uniquement ; si un seul argument -a est donné, il affiche l'état de toutes les interfaces, y co

mpris celles qui sont à l'arrêt. S
inon, il configure une interface.

Familles

d'adresses

Si le premier argument après le nom de l'interface est reconnu comme le nom d'une famille d'adresses prise en charge, cette famille d'adresses est utilisée pour décoder et afficher toutes les adresses de protocole. Les familles d'adresses actuellement prises en charge incluent inet (TCP/IP, par défaut), inet6 (IPv6), ax25 (radio paquet AMPR), ddp (Appletalk Phase 2), ipx (Novell IPX) et netrom (radio paquet AMPR). Tous les nombres fournis comme parties en notation décimale pointillée IPv4 peuvent être décimaux, octaux ou hexadécimaux, comme spécifié dans la norme ISO C (c'est-à-dire qu'un 0x ou 0X initial

implique hexadécimal ; sinon, un '0' initial implique octal ; sinon, le nombre est interprété comme décimal). L'
usage des nombres hexadécimaux et octaux n'est pas conforme aux RFC et son utilisation est donc déconseillée.

REMARQUE

S

Depuis la version 2.2 du noyau, il n'y a plus de statistiques explicites d'interface pour les interfaces alias. Les statistiques imprimées pour l'adresse d'origine sont partagées avec toutes les adresses alias sur le même périphérique. Si vous souhaitez des statistiques par adresse, vous devriez ajouter des règles de comptage explicites pour l'adresse en utilisant la commande iptables

(8).

Depuis net-tools 1.60-4, ifconfig affiche les compteurs d'octets et les compteurs lisibles par l'humain avec les unités IEC 60027-2. Ainsi, 1 KiB sont 2^10 octets. BOGUE

S

Ifconfig utilise la méthode d'accès ioctl pour obtenir les informations complètes sur les adresses, ce qui limite les adresses matérielles à 8 octets. Comme l'adresse matérielle Infiniband comporte 20 octets, seuls les 8 premiers octets sont affichés correctement. Veuillez utiliser la commande ip link du paquet iproute2 pour afficher les informations de la couche liaison, y compris l'adresse

matérielle.

Bien que les adresses appletalk DDP et

IPX soient affichées, elles ne peuvent
pas être modifiées par cette commande.
