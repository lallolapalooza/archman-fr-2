FBB::IFdStream(3bobcat) Flux d'entrée descripteur de fichier FBB::IFdStream(3bobcat)

NOM

FBB::Ifdstream - Flux d'entrée initialisé par un descripteur de fichier

SYNTAXE

#include <bobcat/ifdstream> (lors de l'utilisation de FBB::IFdStream
#include <bobcat/ifdstreams> (lors de l'utilisation de FBB::IFdStreamS

Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::IFdStream sont utilisés pour extraire des informations de périphériques dont les descripteurs de fichier sont disponibles.

Les objets FBB::IFdStreamS fonctionnent comme les objets FBB::IFdStream mais utilisent des objets FBB::Selector pour vérifier si des informations sur le descripteur de fichier de l'objet sont disponibles avant de lire des informations depuis le descripteur de fichier.

Les descripteurs de fichier ne sont pas définis dans le contexte de C++, mais ils peuvent être utilisés sur les systèmes d'exploitation qui supportent ce concept. Tenez compte du fait que l'utilisation de descripteurs de fichier introduit des dépendances au système d'exploitation.

Notez que les sockets peuvent être utilisés comme descripteurs de fichier.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace nominal FBB.

HERITE DE

std::istream

CONSTRUCTEURS

o
IFdStream(int fd, size_t n = 1) :
Le constructeur initialise l'objet pour lire à partir du descripteur fd, en utilisant un tampon de taille n, dont la taille est de 1 par défaut.
Utilisez IFdStreamS(int fd, size_t n = 1) pour construire un objet IFdStreamS.

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::istream sont disponibles, car FBB::IFdStream(S) en hérite. Il n'y a pas de membres supplémentaires.

EXEMPLE

Voir la page de manuel clientsocket(3bobcat) pour un exemple montrant comment utiliser IFdStream.

FICHIERS

bobcat/ifdstream - définit l'interface de la classe FBB::IFdStream
bobcat/ifdstreams - définit l'interface de la classe FBB::IFdStreamS

VOIR AUSSI

bobcat(7), ifdbuf(3bobcat), ofdstream(3bobcat), selector(3bobcat)

BOGUES

L'objet IFdStream(S) utilise un IFdBuf(S) pour son std::streambuf. Ce tampon est associé au descripteur de fichier passé au constructeur de IFdStream(S). Lorsque l'objet IFdStream(S) sort de sa portée, le périphérique (fichier, socket, etc.) auquel le descripteur de fichier qui a été passé au constructeur de IFdStream(S) est lié n'est pas fermé.
