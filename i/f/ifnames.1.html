NOM

ifnames - Extraire les conditions CPP d'un ensemble de fichiers

SYNTAXE

ifnames [OPTION]... [FICHIER]...

DESCRIPTION

Analyser tous les FICHIERS sources C (ou l'entrée standard, si aucun n'est donné) et écrire sur la sortie standard une liste triée de tous les identificateurs qui apparaissent dans ces fichiers dans les directives '#if', '#elif', '#ifdef', ou '#ifndef'. Imprimer chaque identificateur sur une ligne, suivi d'une liste séparée par des espaces des fichiers dans lesquels cet identificateur apparaît.

-h, --help
afficher cette aide, puis quitter
-V, --version
afficher le numéro de version, puis quitter
