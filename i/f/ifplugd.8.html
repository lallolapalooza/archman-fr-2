ifplugd - Un démon de dét

ection de liaison pour l
es périphériques ethernet

SYNOPSI

S

ifplugd [options]

DESCRIPTIO

N

ifplugd est un démon qui configurera automatiquement votre périphérique ethernet lorsqu'un câble est branché et le déconfigurera automatiquement si le câble est débranché. C'est utile sur les ordinateurs portables avec des adaptateurs réseau intégrés, car il ne configurera l'interface que lorsqu'un câble est réellement

connecté.

Il utilise les programmes natifs ifup/ifdown de votre distribution, mais peut être configuré pour faire ce que vous souhaitez lorsque l'état de l'interface change. Il peut ignorer les courtes périodes de débranchement (-d option) ou les périodes de branchement (-u option)

.

ifplugd peut être utilisé en « mode de compatibilité » en spécifiant -F sur

la ligne de commande. Dans ce cas, ifplugd traitera les pilotes réseau qui
ne prennent pas en charge l'interrogation de la liaison comme toujours en ligne.

FICHIER

S

/etc/ifplugd/ifplugd.conf : ce fichier est lu par le script d'initialisation /etc/init.d/ifplugd et contient l'interface à surveiller et les options à

utiliser.

/etc/ifplugd/ifplugd.action : c'est le script qui sera appelé par le démon chaque fois que l'état de l'interface change. Il prend deux arguments : le premier est le nom de l'interface (ex. eth0), le second est soit « up » soit « down »

.

/var/run/ifplugd.<iface>.pid : l

e fichier pid p
our ifplugd.

ENVIRONNEMEN

T

Le script d'action sera appelé avec deux variables d'environnement définies

:

IFPLUGD_PREVIOUS L'état de liaison précédent. Soit « up », « down », « error » ou « disabled ». Les valeurs précédentes devraient être évidentes, la dernière est définie au démarrage du

démon.

IFPLUGD_CURRENT L'état de liaison actuel. Vo

ir ci-dessus pour
les valeurs possibles.

SIGNAU

X

SIGINT, SIGTERM ifplugd quittera, exécutant éventuellement le script d'arrêt. C'est émis en passant -k à

ifplugd.

SIGQUIT ifplugd quittera, le script d'arrêt n'est jamais

exécuté.

SIGHUP ifplugd écrira ses informations d'état dans syslog. C'est émis par

-z.

SIGUSR1 ifplugd passera en mode suspendu.

(-S)

SIGUSR2 ifplugd reprendra de

puis le mode
suspendu. (-R)
