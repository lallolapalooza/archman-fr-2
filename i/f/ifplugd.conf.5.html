NOM

ifplugd.conf - fichier de configuration de ifplugd

SYNTAXE

/etc/ifplugd/ifplugd.conf

DESCRIPTION

ifplugd.conf est le fichier de configuration pour ifplugd. C'est un script shell qui est sourcé par le script d'initialisation démarrant le démon. Il doit être utilisé pour définir des variables d'environnement qui sont interprétées par le script d'initialisation :

OPTIONS

INTERFACES
Spécifie les interfaces réseau à surveiller. Il doit contenir une liste d'espaces séparant les noms des interfaces réseau. La plupart des utilisateurs utiliseront probablement "eth0" ici, cependant vous pouvez ajouter des interfaces supplémentaires pour surveiller plus d'un appareil. Une valeur spéciale est également prise en charge : "auto" activera une détection automatique plus ou moins fonctionnelle des périphériques réseau disponibles. Cela ne vous satisfera pas lors de l'utilisation du chargement automatique de modules réseau, car il ne peut pas détecter les périphériques réseau actuellement non chargés.
ARGS
Arguments de ligne de commande supplémentaires pour l'invocation de ifplugd. Voir ifplugd(8) pour plus d'informations.
ARGSiface
Si spécifié pour une interface, cette variable a la priorité sur ARGS. Cela peut être utile si plus d'un périphérique réseau est présent.
