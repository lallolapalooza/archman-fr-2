if_nameindex(3) Manuel des fonctions de bibliothèque if_nameindex(3)

NOM

if_nameindex, if_freenameindex - obtenir les noms et les index des interfaces réseau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <net/if.h>
struct if_nameindex *if_nameindex(void);
void if_freenameindex(struct if_nameindex *ptr);

DESCRIPTION

La fonction if_nameindex() renvoie un tableau de structures if_nameindex, contenant chacune des informations sur une des interfaces réseau du système local. La structure if_nameindex contient au moins les entrées suivantes :


unsigned int if_index;  /* Index de l'interface (1, 2, ...) */
char        *if_name;   /* Nom terminé par null ("eth0", etc.) */

Le champ if_index contient l'index de l'interface. Le champ if_name pointe vers le nom de l'interface terminé par un caractère null. La fin du tableau est indiquée par une entrée avec if_index mis à zéro et if_name mis à NULL.

La structure de données renvoyée par if_nameindex() est allouée dynamiquement et doit être libérée en utilisant if_freenameindex() lorsqu'elle n'est plus nécessaire.

VALEUR RENVOYÉE

En cas de succès, if_nameindex() renvoie un pointeur vers le tableau ; en cas d'erreur, NULL est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

if_nameindex() peut échouer et définir errno si :

ENOBUFS
Ressources insuffisantes disponibles.

if_nameindex() peut également échouer pour l'une des erreurs spécifiées pour socket(2), bind(2), ioctl(2), getsockname(2), recvmsg(2), sendto(2), ou malloc(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
if_nameindex (), if_freenameindex () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008, RFC 3493.

HISTORIQUE

glibc 2.1. POSIX.1-2001. BSDi.

Avant glibc 2.3.4, l'implémentation ne prenait en charge que les interfaces avec des adresses IPv4. La prise en charge des interfaces qui n'ont pas d'adresses IPv4 n'est disponible que sur les noyaux qui prennent en charge netlink.

EXEMPLES

Le programme ci-dessous démontre l'utilisation des fonctions décrites sur cette page. Un exemple de sortie que ce programme pourrait produire est le suivant :


$ ./a.out;
1: lo
2: wlan0
3: em1

Source du programme

#include <net/if.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(void)
{
    struct if_nameindex *if_ni, *i;
    if_ni = if_nameindex();
    if (if_ni == NULL) {
        perror("if_nameindex");
        exit(EXIT_FAILURE);
    }
    for (i = if_ni; !(i->if_index == 0 && i->if_name == NULL); i++)
        printf("%u: %s\n", i->if_index, i->if_name);
    if_freenameindex(if_ni);
    exit(EXIT_SUCCESS);
}
