IFIND(1) Manuel des commandes générales IFIND(1)

NOM

ifind - Trouver la structure de métadonnées qui a alloué une unité de disque ou un nom de fichier donné.

SYNTAXE

ifind [-avVl] [-f type_fs] [-d unité_données] [-n fichier] [-p inode_parent] [-z FUSEAU] [-i type_img] [-o décalage_img] [-b taille_secteur_dev] image [images]

DESCRIPTION

ifind trouve la structure de métadonnées qui a alloué unité_données à une unité de données ou qui a un nom de fichier donné. Dans certains cas, les structures peuvent être non allouées et cela trouvera quand même les résultats.

ARGUMENTS

Il existe plusieurs arguments obligatoires et optionnels. Les noms de fichiers image doivent être spécifiés à chaque fois :

image [images]
L'image du disque ou de la partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, indiqué par une terminaison en '.001'), les segments d'image suivants seront inclus automatiquement.

Vous devez également spécifier ce que vous recherchez et inclure l'une des options suivantes :

-d unité_données
Trouve la structure de métadonnées qui a alloué une unité de données (bloc, cluster, etc.) donnée.
-n fichier
Trouve la structure de métadonnées qui est pointée par le nom de fichier donné.
-p inode_parent
Trouve les entrées MFT non allouées dans une image NTFS qui ont l'inode donné comme parent. Peut être utilisé avec '-l et -z'.

Il existe également plusieurs arguments optionnels :

-a
Trouve toutes les structures de métadonnées (ne fonctionne qu'en cherchant avec une unité_données).
-f type_fs
Spécifie le type de système de fichiers. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. Si non donné, des méthodes d'autodétection sont utilisées.
-l
Liste les détails de chaque fichier trouvé avec '-p', comme 'fls -l'.
-i type_img
Identifie le type de fichier image, tel que brut. Utilisez '-i list' pour lister les types pris en charge. Si non donné, des méthodes d'autodétection sont utilisées.
-o décalage_img
Le décalage de secteur où le système de fichiers commence dans l'image.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non donné, la valeur du format d'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Sortie verbeuse vers stderr.
-V
Affiche la version.
-z FUSEAU
Si '-p -l' ont été donnés, cela définira le fuseau horaire pour les heures correctes.

EXEMPLES

# ifind -f fat -d 456 fat-img.dd

# ifind -f linux-ext2 -n "/etc/" linux-img.dd

# ifind -f ntfs -p 5 -l -z EST5EDT ntfs-img.dd
