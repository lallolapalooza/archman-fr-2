NOM

ifstat - utilitaire pratique pour lire les statistiques des interfaces réseau

SYNTAXE


ifstat [ OPTIONS ] [ LISTE_INTERFACES ]

LISTE_INTERFACES := LISTE_INTERFACES | interface

DESCRIPTION

ifstat affiche proprement les statistiques des interfaces réseau. L'utilitaire conserve les données précédentes affichées dans des fichiers d'historique et, par défaut, n'affiche que la différence entre l'appel précédent et l'appel actuel. L'emplacement des fichiers d'historique est par défaut /tmp/.ifstat.u$UID mais peut être outrepassé par la variable d'environnement IFSTAT_HISTORY. De même, l'emplacement par défaut pour xstat (statistiques étendues) est /tmp/.<nom_xstat>_ifstat.u$UID.

OPTIONS

-h, --help
Affiche un résumé des options.
-V, --version
Affiche la version du programme.
-a, --ignore
Ignore le fichier d'historique.
-d, --scan=SECS
Échantillonne les statistiques toutes les SECS secondes.
-e, --errors
Affiche les erreurs.
-n, --nooutput
N'affiche rien. Met à jour uniquement le fichier d'historique.
-r, --reset
Réinitialise l'historique.
-s, --noupdate
Ne met pas à jour le fichier d'historique.
-t, --interval=SECS
Rend compte de la moyenne sur les SECS dernières secondes.
-z, --zeros
Affiche les entrées avec activité zéro.
-j, --json
Affiche les résultats au format JSON
-p, --pretty
Si combiné avec --json, affiche la sortie de manière lisible.
-x, --extended=TYPE
Affiche les statistiques étendues du TYPE. Les types supportés sont :


cpu_hits - Compte uniquement les paquets passés par le CPU.

ENVIRONNEMENT

IFSTAT_HISTORY
Si défini, sa valeur est interprétée comme le chemin alternatif du fichier d'historique.
