NOM

ifplugstatus - Un outil de détection du battement de lien

SYNTAXE

ifplugstatus [options] [INTERFACE]

DESCRIPTION

ifplugstatus est un utilitaire qui peut être utilisé pour détecter l'état du lien d'un périphérique Ethernet Linux local, de manière similaire à mii-diag, mii-tool et ethtool. En fait, il prend en charge les trois API différentes utilisées par ces trois outils. De plus, il prend en charge la vérification du lien avec le drapeau d'interface IFF_RUNNING, que la plupart des pilotes modernes (pas seulement Ethernet) supportent, et la vérification de l'état d'association avec l'API d'extension sans fil pour les périphériques WLAN.

Les API sont essayées dans l'ordre suivant :

D'abord la nouvelle API : SIOCETHTOOL (alias API ethtool)

Ensuite l'API plus ancienne : SIOCGMIIREG (alias API mii-diag)

Puis l'API WLAN : extension sans fil (alias API iwconfig)

Suivie de l'API la plus propre : IFF_RUNNING (alias API ifconfig)

La plus ancienne API (SIOCPRIV alias API mii-tool) n'est pas testée car elle est obsolète.

ifplugstatus peut être utilisé dans un script shell car il renvoie l'état actuel comme valeur de retour. Il est particulièrement utile pour détecter les API disponibles sur le pilote réseau utilisé. (Option -v)

OPTIONS

Vous pouvez spécifier un périphérique Ethernet sur la ligne de commande. Sinon, ifplugstatus vérifiera toutes les interfaces réseau disponibles.

-a | --auto
Active automatiquement l'interface avant la requête (par défaut : désactivé)
-h | --help
Afficher l'aide
-q | --quiet
Diminue la verbosité d'un cran. Si la verbosité est < 0, aucun texte ne sera affiché, seule la valeur de retour est pertinente ; si la verbosité est = 0, un état concis sera affiché ; si la verbosité est > 0, des informations détaillées sur l'API utilisée seront retournées. (Par défaut, la verbosité est de 0)
-v | --verbose
Augmente la verbosité d'un cran. Voir l'option -q.
-V | --version
Afficher la version

VALEURS DE RETOUR

0 Succès

1 Échec

2 Battement de lien détecté (uniquement disponible lorsqu'une interface est spécifiée)

3 Débranché (idem ici)
