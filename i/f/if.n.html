if(n)

Paquet: tcl

if(n) Commandes intégrées Tcl if(n)

NOM

if - Exécuter des scripts conditionnellement

SYNTAXE

if expr1 ?then? corps1 elseif expr2 ?then? corps2 elseif ... ?else? ?corpsN?

DESCRIPTION

La commande if évalue expr1 comme une expression (de la même manière que expr évalue son argument). La valeur de l'expression doit être booléenne (une valeur numérique, où 0 est faux et tout le reste est vrai, ou une valeur de chaîne comme true ou yes pour vrai et false ou no pour faux) ; si elle est vraie, corps1 est exécuté en le passant à l'interpréteur Tcl. Sinon, expr2 est évaluée comme une expression et si elle est vraie, corps2 est exécuté, et ainsi de suite. Si aucune des expressions n'est évaluée comme vraie, corpsN est exécuté. Les arguments then et else sont des mots « bruit » optionnels pour rendre la commande plus facile à lire. Il peut y avoir un nombre quelconque de clauses elseif, y compris zéro. CorpsN peut également être omis tant que else est également omis. La valeur de retour de la commande est le résultat du script de corps qui a été exécuté, ou une chaîne vide si aucune des expressions n'était non nulle et qu'il n'y avait pas de corpsN.

EXEMPLES

Une condition simple :

if {$vbl == 1} { puts "vbl est un" }

Avec une clause else :

if {$vbl == 1} {
    puts "vbl est un"
} else {
    puts "vbl n'est pas un"
}

Avec également une clause elseif :

if {$vbl == 1} {
    puts "vbl est un"
} elseif {$vbl == 2} {
    puts "vbl est deux"
} else {
    puts "vbl n'est ni un ni deux"
}

Rappelez-vous, les expressions peuvent être sur plusieurs lignes, mais dans ce cas, il peut être judicieux d'utiliser le mot-clé optionnel then pour plus de clarté :

if {
    $vbl == 1
    || $vbl == 2
    || $vbl == 3
} then {
    puts "vbl est un, deux ou trois"
}
