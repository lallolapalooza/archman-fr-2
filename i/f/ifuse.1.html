ifuse(1) Manuel des commandes générales ifuse(1)

NOM

ifuse - Monter localement des répertoires d'un appareil iOS en utilisant fuse.

SYNTAXE

ifuse POINT_DE_MONTAGE [OPTIONS]

DESCRIPTION

Monte localement des répertoires d'un appareil iOS en utilisant fuse. Par défaut, le répertoire multimédia est monté, les options permettent également de monter le conteneur sandbox d'une application, le dossier de documents d'une application ou même le système de fichiers racine sur les appareils jailbreakés.

Exemple :

$ ifuse /media/iPhone --root

Cela monte le système de fichiers racine du premier appareil attaché sur cet ordinateur dans le répertoire /media/iPhone.

Les utilisateurs réguliers peuvent démonter les montages fuse en utilisant "fusermount -u POINT_DE_MONTAGE".

OPTIONS

-o opt,[opt...]
options de montage.
-u, --udid UDID
monter un appareil spécifique par UDID.
-n, --network
se connecter à un appareil réseau.
-h, --help
afficher les informations d'utilisation.
-V, --version
afficher la version.
-d, --debug
activer le débogage de la communication libimobiledevice.
--documents APPID
monter le dossier 'Documents' de l'application identifiée par APPID.
--container APPID
monter la racine sandbox d'une application identifiée par APPID.
--list-apps
lister les applications installées qui ont le partage de fichiers activé.
--root
monter le système de fichiers racine (appareil jailbreaké requis).
