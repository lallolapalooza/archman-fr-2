NOM

ifne - Exécute une commande si l'entrée standard n'est pas vide

SYNTAXE


ifne [-n] commande

DESCRIPTION

ifne exécute la commande suivante si et seulement si l'entrée standard n'est pas vide.

OPTIONS

-n
Opération inverse. Exécute la commande si l'entrée standard est vide.

Notez que si l'entrée standard n'est pas vide, elle est transmise à ifne dans ce cas.

EXEMPLE


find . -name core | ifne mail -E 'set escape' -s "Fichiers core trouvés" root
