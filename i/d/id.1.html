ID(1) Commandes utilisateur ID(1)

NOM

id - afficher les identifiants utilisateur et groupe réels et effectifs

SYNTAXE

id [OPTION]... [UTILISATEUR]...

DESCRIPTION

Affiche les informations utilisateur et groupe pour chaque UTILISATEUR spécifié, ou (lorsque UTILISATEUR est omis) pour le processus courant.

-a
ignore, pour compatibilité avec d'autres versions
-Z, --context
affiche uniquement le contexte de sécurité du processus
-g, --group
affiche uniquement l'identifiant de groupe effectif
-G, --groups
affiche tous les identifiants de groupe
-n, --name
affiche un nom au lieu d'un nombre, pour -u, -g, -G
-r, --real
affiche l'identifiant réel au lieu de l'identifiant effectif, avec -u, -g, -G
-u, --user
affiche uniquement l'identifiant utilisateur effectif
-z, --zero
délimite les entrées par des caractères NUL, et non par des espaces ; non autorisé dans le format par défaut
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Sans aucune OPTION, affiche un ensemble utile d'informations identifiées.
