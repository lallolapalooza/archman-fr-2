NOM

idn2_lookup_ul - fonction API

SYNTAXE

#include <idn2.h>

int idn2_lookup_ul(const char * src, char ** lookupname, int flags);

ARGUMENTS

const char * src
chaîne d'entrée terminée par zéro, encodée dans la locale.
char ** lookupname
variable de sortie nouvellement allouée avec le nom à rechercher dans le DNS.
int flags
optionnel idn2_flags pour modifier le comportement.

DESCRIPTION

Effectue la conversion de chaîne de recherche IDNA2008 sur le nom de domaine src , comme décrit dans la section 5 de la RFC 5891. Notez que l'entrée est supposée être encodée dans le système de codage par défaut de la locale, et sera transcrite en UTF-8 et normalisée NFC par cette fonction.

Passez IDN2_ALABEL_ROUNDTRIP dans flags pour convertir toutes les étiquettes A d'entrée en étiquettes U et effectuer des tests supplémentaires. Ceci est le comportement par défaut depuis la version 2.2. Pour désactiver ce comportement, passez IDN2_NO_ALABEL_ROUNDTRIP.

Passez IDN2_TRANSITIONAL pour activer le traitement transitionnel Unicode TR46, et IDN2_NONTRANSITIONAL pour activer le traitement non transitionnel Unicode TR46.

Plusieurs drapeaux peuvent être spécifiés en les combinant avec un opérateur OU binaire, par exemple IDN2_ALABEL_ROUNDTRIP | IDN2_NONTRANSITIONAL.

Le drapeau IDN2_NFC_INPUT est toujours activé dans cette fonction.

Après la version 0.11 : lookupname peut être NULL pour tester la recherche de src sans allouer de mémoire.

RETOUR

En cas de conversion réussie, IDN2_OK est retourné. Si la conversion de la locale vers UTF-8 échoue, IDN2_ICONV_FAIL est retourné. Si le domaine de sortie ou l'une de ses étiquettes était trop longue, IDN2_TOO_BIG_DOMAIN ou IDN2_TOO_BIG_LABEL est retourné, ou un autre code d'erreur est retourné.
