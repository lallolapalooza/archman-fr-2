IDS2NGRAM(1) Documentation Perl fournie par l'utilisateur IDS2NGRAM(1)

NOM

ids2ngram - génère un fichier de données n-gram à partir d'un fichier ids

SYNTAXE

ids2ngram [option]... fichier_ids...

DESCRIPTION

ids2ngram génère un fichier idngram, qui est un tableau trié [id1,..,idN,freq], à partir de fichiers de flux d'ids binaires. Ici, les fichiers de flux d'ids sont toujours générés par mmseg ou slmseg. Fondamentalement, il trouve toutes les occurrences de tuples de n-mots (c'est-à-dire le tuple (id1,..,idN)), et trie ces tuples par ordre lexicographique des ids composant les tuples, puis les écrit dans le fichier de sortie spécifié.

ENTRÉE

Le fichier d'entrée est présenté sous forme de flux d'ids binaires, qui ressemble à ceci :
[id0,...,idX]

OPTIONS

Toutes les options suivantes sont obligatoires.

-n,--NMax N
Génère le résultat de N-gram. ids2ngram ne prend en charge que les unigrammes, bigrammes et trigrammes, donc tout nombre non compris dans l'intervalle 1..3 n'est pas valide.
-s,--swap fichier_échange
Spécifie le fichier intermédiaire temporaire.
-o, --out fichier_sortie
Spécifie le fichier idngram résultant, par exemple le tableau de [id1, ..., idN, freq]
-p, --para N
Spécifie le nombre maximum d'éléments n-gram par paragraphe. ids2ngram écrit dans le fichier temporaire par paragraphe. Chaque fois qu'il écrit un paragraphe, il libère la mémoire correspondante qui lui était allouée. Lorsque le système de votre ordinateur le permet, un N plus élevé est suggéré. Cela peut accélérer le traitement en raison de moins d'E/S.

EXEMPLE

L'exemple suivant utilisera trois fichiers d'ids d'entrée idsfile[1,2,3] pour générer le fichier idngram all.id3gram. Chaque para (taille de map interne ou taille de hash) sera de 1024000, en utilisant un fichier d'échange pour le résultat temporaire. Tous les résultats de para temporaires seront finalement fusionnés pour obtenir le résultat final.

ids2ngram -n 3 -s /tmp/swap -o all.id3gram -p 1024000 idsfile1 idsfile2 idsfile3
