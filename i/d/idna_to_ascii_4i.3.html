idna_to_ascii_4i(3) libidn idna_to_ascii_4i(3)

NOM

idna_to_ascii_4i - Fonction API

SYNTAXE

#include <idna.h>

int idna_to_ascii_4i(const uint32_t * in, size_t inlen, char * out, int flags);

ARGUMENTS

const uint32_t * in
tableau d'entrée avec des points de code unicode.
size_t inlen
longueur du tableau d'entrée avec des points de code unicode.
char * out
chaîne de sortie terminée par un zéro qui doit avoir la place pour au moins 63 caractères plus le zéro terminant.
int flags
une valeur Idna_flags, par exemple, IDNA_ALLOW_UNASSIGNED ou IDNA_USE_STD3_ASCII_RULES.

DESCRIPTION

L'opération ToASCII prend une séquence de points de code Unicode qui composent une étiquette de domaine et la transforme en une séquence de points de code dans la plage ASCII (0..7F). Si ToASCII réussit, la séquence d'origine et la séquence résultante sont des étiquettes équivalentes.

Il est important de noter que l'opération ToASCII peut échouer. ToASCII échoue si une étape de celle-ci échoue. Si une étape de l'opération ToASCII échoue sur une étiquette d'un nom de domaine, ce nom de domaine NE DOIT PAS être utilisé comme nom de domaine internationalisé. La méthode pour gérer cet échec est spécifique à l'application.

Les entrées de ToASCII sont une séquence de points de code, le drapeau AllowUnassigned et le drapeau UseSTD3ASCIIRules. La sortie de ToASCII est soit une séquence de points de code ASCII, soit une condition d'échec.

ToASCII ne modifie jamais une séquence de points de code qui sont tous dans la plage ASCII pour commencer (bien qu'elle puisse échouer). Appliquer l'opération ToASCII plusieurs fois a exactement le même effet que de l'appliquer une seule fois.

Valeur de retour : renvoie 0 en cas de succès, ou un code d'erreur Idna_rc.
