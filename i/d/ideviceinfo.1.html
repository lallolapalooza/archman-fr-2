ideviceinfo(1) Manuel des commandes générales ideviceinfo(1)

NOM

ideviceinfo - Afficher les informations sur le premier appareil connecté.

SYNOPSIS

ideviceinfo [OPTIONS]

DESCRIPTION

Affiche les informations sur le premier appareil connecté.

OPTIONS

-s, --simple
utilise une connexion simple pour éviter l'appairage automatique avec l'appareil.
-u, --udid UDID
cible un appareil spécifique par son UDID.
-n, --network
se connecte à un appareil réseau.
-d, --debug
active le débogage de la communication.
-q, --domain NAME
définit le domaine de la requête sur NAME. Par défaut : Aucun.
-k, --key NAME
interroge uniquement la clé spécifiée par NAME. Par défaut : Toutes les clés.
-x, --xml
affiche les informations sous forme de plist XML au lieu de paires clé/valeur.
-h, --help
affiche les informations d'utilisation.
-v, --version
affiche les informations de version.
