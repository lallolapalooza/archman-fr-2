ID3INFO(1) Commande utilisateur ID3INFO(1)

NOM

id3info - Affiche les informations des tags id3.

SYNTAXE

id3info [ OPTION ] [ FICHIER ]

DESCRIPTION

Id3info affiche les informations des tags id3v1 et id3v2 pour un fichier. Id3info ne fera pas de distinction entre les deux types de tags.

OPTIONS

-h, --aide
Affiche l'aide et quitte
-v, --version
Affiche les informations de version et quitte

VOIR AUSSI

id3convert(1), id3tag(1), id3v2(1)
