NOM

idngram_merge - fusionner le fichier idngram en un seul

SYNTAXE

idngram_merge [option]... idngram_file...

DESCRIPTION

idngram_merge fusionne plusieurs fichiers idngram, chacun étant un tableau trié [id1,...,idN,freq], en un seul fichier idngram. Pour les id1..idN qui apparaissent dans plus d'un fichier, un seul élément apparaîtra dans le fichier final, et sa fréquence sera additionnée. Les fichiers idngram sont originellement générés par ids2ngram.

OPTIONS Toutes les options suivantes sont obligatoires.

-n, --NMax N
Spécifie le N-gram du fichier de données source.
-o, --out fichier-sortie
Spécifie le fichier idngram final fusionné.

EXEMPLE

L'exemple suivant fusionne 2 fichiers id3gram en un plus grand :

B<idngram_merge -n3 -o all.id3gram first.id3gram second.id3gram>
