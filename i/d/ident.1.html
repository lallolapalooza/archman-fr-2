IDENT(1) Manuel des commandes générales IDENT(1)

NOM

ident - identifier les chaînes de mots-clés RCS dans les fichiers

SYNTAXE

ident [ -q ] [ -V ] [ fichier ... ]

DESCRIPTION

ident recherche toutes les occurrences du motif $mot-clé: texte $ dans les fichiers nommés ou, si aucun fichier n'est nommé, dans l'entrée standard.

Ces motifs sont normalement insérés automatiquement par la commande RCS co(1), mais peuvent également être insérés manuellement. L'option -q supprime l'avertissement émis s'il n'y a pas de motifs dans un fichier. L'option -V affiche le numéro de version de RCS.

ident fonctionne sur les fichiers texte ainsi que sur les fichiers objets et les dumps. Par exemple, si le programme C dans f.c contient

#include <stdio.h>
static char const rcsid[] =
"$Id: f.c,v 5.4 1993/11/09 17:40:15 eggert Exp $";
int main() { return printf("%s\n", rcsid) == EOF; }

et si f.c est compilé en f.o, alors la commande

ident f.c f.o

affichera

f.c:
    $Id: f.c,v 5.4 1993/11/09 17:40:15 eggert Exp $
f.o:
    $Id: f.c,v 5.4 1993/11/09 17:40:15 eggert Exp $

Si un programme C définit une chaîne comme rcsid ci-dessus mais ne l'utilise pas, lint(1) peut se plaindre, et certains compilateurs C peuvent optimiser et supprimer la chaîne. La solution la plus fiable est que le programme utilise la chaîne rcsid, comme montré dans l'exemple ci-dessus.

ident trouve toutes les occurrences du motif $mot-clé: texte $, même si mot-clé n'est pas réellement un mot-clé pris en charge par RCS. Cela vous donne des informations sur les mots-clés non standards comme $XConsortium$.

Le motif nécessite normalement un deux-points et un espace juste après le mot-clé et un espace juste avant le $ de fin, mais pour la compatibilité avec Subversion 1.2 (et versions ultérieures), ident reconnaîtra également le motif $mot-clé:: texte $ (c'est-à-dire deux deux-points et un espace) et le motif $mot-clé:: texte #$ (de même, avec un dièse avant le $ de fin). Ce sont les syntaxes de mots-clés en largeur fixe. Pour résumer, les trois motifs reconnus sont :

$mot-clé: texte $
$mot-clé:: texte $
$mot-clé:: texte #$

MOTS-CLÉS

Voici la liste des mots-clés actuellement gérés par co(1). Toutes les heures sont données en Temps Universel Coordonné (UTC, parfois appelé GMT) par défaut, mais si les fichiers ont été extraits avec l'option -zzone de co, les heures sont données avec une indication numérique de fuseau horaire en suffixe.

$Author$
Le nom de connexion de l'utilisateur qui a validé la révision.
$Date$
La date et l'heure de validation de la révision.
$Header$
Un en-tête standard contenant le nom complet du fichier RCS, le numéro de révision, la date et l'heure, l'auteur, l'état et le verrouilleur (si verrouillé).
$Id$
Identique à $Header$, sauf que le nom du fichier RCS est sans les composantes du répertoire.
$Locker$
Le nom de connexion de l'utilisateur qui a verrouillé la révision (vide si pas verrouillé).
$Log$
Le message de journal fourni lors de la validation. Aux fins d'ident, cela équivaut à $RCSfile$.
$Name$
Le nom symbolique utilisé pour extraire la révision, le cas échéant.
$RCSfile$
Le nom du fichier RCS sans les composantes du répertoire.
$Revision$
Le numéro de révision attribué à la révision.
$Source$
Le nom complet du fichier RCS.
$State$
L'état attribué à la révision avec l'option -s de rcs(1) ou ci(1).

co(1) représente les caractères suivants dans les valeurs des mots-clés par des séquences d'échappement pour maintenir les chaînes de mots-clés valides.

caractère	séquence d'échappement
tab	\t
nouvelle ligne	\n
espace	\040
$	\044
\	\\
