IDN(1) Commandes utilisateur IDN(1)

NOM

idn - Outil en ligne de commande pour les noms de domaine internationalisés

SYNTAXE

idn [OPTION]... [CHAÎNES]...

DESCRIPTION

Convertit les noms de domaine internationalisés (IDN) des CHAÎNES, ou de l'entrée standard.

Interface en ligne de commande pour la bibliothèque de noms de domaine internationalisés.

Toutes les chaînes sont attendues dans le jeu de caractères préféré utilisé par votre locale. Utilisez --debug pour connaître ce jeu de caractères. Vous pouvez remplacer le jeu de caractères utilisé en définissant la variable d'environnement CHARSET.

Pour traiter une chaîne commençant par '-', par exemple '-foo', utilisez '--' pour signaler la fin des paramètres, comme ceci : idn --quiet -a -- -foo

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-h, --help
Affiche l'aide et quitte
-V, --version
Affiche la version et quitte
-s, --stringprep
Prépare la chaîne selon le profil nameprep
-d, --punycode-decode
Décode Punycode
-e, --punycode-encode
Encode Punycode
-a, --idna-to-ascii
Convertit en ACE selon IDNA (mode par défaut)
-u, --idna-to-unicode
Convertit depuis ACE selon IDNA
--allow-unassigned
Active/désactive le drapeau IDNA AllowUnassigned (désactivé par défaut)
--usestd3asciirules
Active/désactive le drapeau IDNA UseSTD3ASCIIRules (désactivé par défaut)
--no-tld
Ne vérifie pas les règles spécifiques aux TLD pour la chaîne. Uniquement pour --idna-to-ascii et --idna-to-unicode.
-n, --nfkc
Normalise la chaîne selon Unicode v3.2 NFKC
-p, --profile=CHAÎNE
Utilise le profil stringprep spécifié à la place. Profils stringprep valides : Nameprep iSCSI Nodeprep Resourceprep trace SASLprep
--debug
Affiche les informations de débogage
--quiet
Fonctionnement silencieux
