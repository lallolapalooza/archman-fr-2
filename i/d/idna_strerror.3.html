idna_strerror(3)

Paquet: libidn

Licences: GPL3, LGPL

idna_strerror(3) libidn idna_strerror(3)

NOM

idna_strerror - fonction d'API

SYNTAXE

#include <idna.h>

const char * idna_strerror(Idna_rc rc);

ARGUMENTS

Idna_rc rc
un code de retour Idna_rc.

DESCRIPTION

Convertit un code de retour entier en une chaîne de caractères. Cette chaîne peut être utilisée pour afficher un message de diagnostic à l'utilisateur.

IDNA_SUCCESS

Opération réussie. Cette valeur est garantie d'être toujours zéro, les autres valeurs sont seulement garanties d'avoir des valeurs non nulles, à des fins de comparaison logique.

IDNA_STRINGPREP_ERROR

Erreur lors de la préparation de la chaîne.

IDNA_PUNYCODE_ERROR

Erreur lors de l'opération Punycode.

IDNA_CONTAINS_NON_LDH

Pour IDNA_USE_STD3_ASCII_RULES, indique que la chaîne contient des caractères ASCII non-LDH.

IDNA_CONTAINS_MINUS

Pour IDNA_USE_STD3_ASCII_RULES, indique que la chaîne contient un trait d'union-moins (U+002D) en début ou en fin.

IDNA_INVALID_LENGTH

La chaîne de sortie finale n'est pas comprise dans la plage (inclusive) de 1 à 63 caractères.

IDNA_NO_ACE_PREFIX

La chaîne ne contient pas le préfixe ACE (pour ToUnicode).

IDNA_ROUNDTRIP_VERIFY_ERROR

L'opération ToASCII sur la chaîne de sortie n'est pas égale à l'entrée.

IDNA_CONTAINS_ACE_PREFIX

L'entrée contient le préfixe ACE (pour ToASCII).

IDNA_ICONV_ERROR

Erreur de conversion d'encodage de caractères.

IDNA_MALLOC_ERROR

Impossible d'allouer un tampon (c'est généralement une erreur fatale).

IDNA_DLOPEN_ERROR

Impossible de charger la DSO libcidn avec dlopen (utilisé uniquement en interne dans libc).

Valeur de retour : Renvoie un pointeur vers une chaîne allouée statiquement contenant une description de l'erreur avec le code de retour rc .
