NOM

idmap_tdb2 - Backend idmap_tdb2 de Samba pour Winbind

DESCRIPTION

Le plugin idmap_tdb2 est un substitut pour le backend par défaut idmap_tdb utilisé par winbindd pour stocker les tables de mappage SID/uid/gid dans des environnements clusterisés avec Samba et CTDB.

Contrairement aux backends en lecture seule comme idmap_rid, c'est un backend d'allocation : cela signifie qu'il doit allouer de nouveaux IDs utilisateur et groupe afin de créer de nouveaux mappages.

OPTIONS IDMAP

range = bas - haut

Définit la plage correspondante de uid et gid pour laquelle le backend est faisant autorité.

script

Cette option peut être utilisée pour configurer un programme externe pour effectuer les mappages d'ID au lieu d'utiliser le compteur tdb. Les mappages sont alors stockés dans la base de données d'idmap tdb2. Pour plus de détails, voir la section IDMAP SCRIPT ci-dessous.

SCRIPT IDMAP

Le backend idmap tdb2 supporte un programme externe pour effectuer les mappages d'ID via l'option idmap config * : script de smb.conf ou sa forme héritée dépréciée idmap : script.

Les mappages obtenus par le script sont alors stockés dans la base de données idmap tdb2 au lieu des mappages créés par les compteurs d'ID incrémentiels. Il est donc important que le script couvre la plage complète des SIDs qui peuvent être passés pour le mappage SID vers ID Unix, car sinon les SIDs non mappés par le script pourraient être mappés à des IDs qui avaient été précédemment mappés par le script.

Le script devrait accepter les options de ligne de commande suivantes.

SIDTOID S-1-xxxx
IDTOSID UID xxxx
IDTOSID GID xxxx

Et il devrait retourner l'une des réponses suivantes sous forme d'une ligne de texte.

UID:yyyy
GID:yyyy
SID:yyyy
ERR:yyyy

EXEMPLES

Cet exemple montre comment tdb2 est utilisé comme backend idmap par défaut.

[global]
idmap config * : backend = tdb2
idmap config * : range = 1000000-2000000

Cet exemple montre comment tdb2 est utilisé comme backend idmap par défaut en utilisant un programme externe via le paramètre script :

[global]
idmap config * : backend = tdb2
idmap config * : range = 1000000-2000000
idmap config * : script = /usr/local/samba/bin/idmap_script.sh
