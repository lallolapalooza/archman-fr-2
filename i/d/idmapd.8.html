RPC.IDMAPD(8) Manuel du responsable système RPC.IDMAPD(8)

NOM

rpc.idmapd — Mappeur ID <-> Nom pour NFSv4

SYNTAXE

rpc.idmapd [-h] [-f] [-v] [-C] [-S] [-p chemin] [-c chemin]

DESCRIPTION

rpc.idmapd est le démon de mappage ID <-> nom pour NFSv4. Il fournit des fonctionnalités au client et au serveur NFSv4, avec lesquels il communique via des appels en amont (upcalls), en traduisant les identifiants d'utilisateur et de groupe en noms, et vice-versa.

Le système dérive la partie utilisateur de la chaîne en effectuant une recherche dans le mot de passe ou le groupe. Le mécanisme de recherche est configuré dans /etc/idmapd.conf

Par défaut, la partie domaine de la chaîne est le nom de domaine DNS du système. Elle peut également être spécifiée dans /etc/idmapd.conf si le système est multi-homed, ou si le nom de domaine DNS du système ne correspond pas au nom du realm Kerberos du système.

Lorsque le domaine n'est pas spécifié dans /etc/idmapd.conf, le serveur DNS local sera interrogé pour l'enregistrement texte _nfsv4idmapdomain. Si l'enregistrement existe, il sera utilisé comme domaine. Lorsque l'enregistrement n'existe pas, la partie domaine du domaine DNS sera utilisée.

Notez que sur les noyaux plus récents, seul le serveur NFSv4 utilise rpc.idmapd. Le client NFSv4 utilise à la place nfsidmap(8), et ne se rabat sur rpc.idmapd que s'il y a eu un problème lors de l'exécution du programme nfsidmap(8).

Les options sont les suivantes :

-h
Affiche le message d'utilisation.
-v
Augmente le niveau de verbosité (peut être spécifié plusieurs fois).
-f
Exécute rpc.idmapd au premier plan et affiche toutes les sorties sur le terminal.
-p chemin
Spécifie l'emplacement du RPC pipefs comme étant chemin. La valeur par défaut est « /var/lib/nfs/rpc_pipefs ».
-c chemin
Utilise le fichier de configuration chemin. Cette option est obsolète.
-C
Client uniquement : n'effectue aucun mappage d'ID pour aucun serveur NFS, même s'il en est détecté un.
-S
Serveur uniquement : n'effectue aucun mappage d'ID pour aucun client NFS, même s'il en est détecté un.

FICHIERS DE CONFIGURATION

rpc.idmapd reconnaît la valeur suivante de la section [general] du fichier de configuration /etc/nfs.conf :

pipefs-directory
Équivalent à -p.

Tous les autres paramètres relatifs au mappage d'ID se trouvent dans le fichier de configuration /etc/idmapd.conf.

EXEMPLES

rpc.idmapd -f -vvv

Exécute rpc.idmapd en affichant tous les messages sur la console, et avec un niveau de verbosité de 3.

FICHIERS

/etc/idmapd.conf, /etc/nfs.conf

VOIR AUSSI

idmapd.conf(5), nfs.conf(5), nfsidmap(8)
