NOM

idevicenotificationproxy - Publier ou observer des notifications sur un appareil.

SYNTAXE

idevicenotificationproxy [OPTIONS] COMMANDE

DESCRIPTION

Publie ou observe des notifications sur un appareil iOS depuis la ligne de commande.

OPTIONS

-u, --udid UDID
Cibler un appareil spécifique par UDID.
-i, --insecure
Se connecter à un proxy de notification non sécurisé (pour les appareils non associés).
-n, --network
Se connecter à un appareil réseau.
-d, --debug
Activer le débogage de la communication.
-h, --help
Affiche les informations d'utilisation.
-v, --version
Affiche les informations sur la version.

COMMANDES

post ID [ID...]
Publie les ID de notification sur l'appareil et quitte.
observe ID [ID...]
Observe les ID de notification au premier plan jusqu'à ce que CTRL+C ou un signal soit reçu.
