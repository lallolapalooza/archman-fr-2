idevicebtlogger(1) Manuel des commandes générales idevicebtlogger(1)

NOM

idevicebtlogger - Capture le trafic HCI d'un appareil connecté.

SYNTAXE

idevicebtlogger [OPTIONS] <FICHIER>

DESCRIPTION

Capture le trafic HCI d'un appareil connecté. Nécessite que le profil de journalisation Bluetooth soit installé sur l'appareil avec iOS 13 ou une version ultérieure. Voir https://www.bluetooth.com/blog/a-new-way-to-debug-iosbluetooth-applications/ pour la configuration de l'appareil iOS.

Le trafic HCI peut être stocké dans le format natif PacketLogger d'Apple ou converti au format PCAP pour un retour en temps réel dans Wireshark.

OPTIONS

-u, --udid UDID
cibler un appareil spécifique par UDID
-n, --network
se connecter à un appareil réseau
-f, --format FORMAT
définir le format du journal : PacketLogger (par défaut) ou pcap
-x, --exit
quitter lorsque l'appareil se déconnecte
-d, --debug
activer le débogage de la communication
-h, --help
affiche les informations d'utilisation
-v, --version
affiche les informations de version.

EXEMPLES

idevicebtlogger -u 00008030-0000111ABC000DEF
Capture le trafic HCI de l'appareil avec l'UDID 00008030-0000111ABC000DEF.
idevicebtlogger -x
Capture le trafic HCI de l'appareil et quitte lorsque l'appareil est débranché.
idevicebtlogger -f pcap
Capture le trafic HCI de l'appareil au format PCAP.
idevicebtlogger -f pcap - | wireshark -k -i -
Capture le trafic HCI et le transmet à Wireshark pour un retour en temps réel.
