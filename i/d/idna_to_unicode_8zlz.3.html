NOM

idna_to_unicode_8zlz - Fonction API

SYNTAXE

#include <idna.h>

int idna_to_unicode_8zlz(const char * input, char ** output, int flags);

ARGUMENTS

const char * input
chaîne UTF-8 terminée par un caractère nul.
char ** output
pointeur vers une chaîne de sortie nouvellement allouée, encodée dans le jeu de caractères du locale courant.
int flags
une valeur Idna_flags, par exemple IDNA_ALLOW_UNASSIGNED ou IDNA_USE_STD3_ASCII_RULES.

DESCRIPTION

Convertit un nom de domaine potentiellement encodé en ACE au format UTF-8 en une chaîne encodée dans le jeu de caractères du locale courant. Le nom de domaine peut contenir plusieurs étiquettes, séparées par des points. Le tampon de sortie doit être désalloué par l'appelant.

Valeur de retour : Renvoie IDNA_SUCCESS en cas de succès, ou un code d'erreur.
