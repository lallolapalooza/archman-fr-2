NOM

idna_to_ascii_4z - fonction d'API

SYNOPSIS

#include <idna.h>

int idna_to_ascii_4z(const uint32_t * input, char ** output, int flags);

ARGUMENTS

const uint32_t * input
chaîne Unicode d'entrée terminée par un zéro.
char ** output
pointeur vers une chaîne de sortie nouvellement allouée.
int flags
une valeur Idna_flags, par exemple IDNA_ALLOW_UNASSIGNED ou IDNA_USE_STD3_ASCII_RULES.

DESCRIPTION

Convertit un nom de domaine UCS-4 en chaîne ASCII. Le nom de domaine peut contenir plusieurs étiquettes, séparées par des points. Le tampon de sortie doit être désalloué par l'appelant.

Valeur de retour : Renvoie IDNA_SUCCESS en cas de succès, ou un code d'erreur.
