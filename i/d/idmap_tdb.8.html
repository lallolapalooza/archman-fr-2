NOM

idmap_tdb - Backend idmap_tdb de Samba pour Winbind

DESCRIPTION

Le plugin idmap_tdb est le backend par défaut utilisé par winbindd pour stocker les tables de mappage SID/uid/gid.

Contrairement aux backends en lecture seule comme idmap_rid, c'est un backend d'allocation : cela signifie qu'il doit allouer de nouveaux identifiants d'utilisateur et de groupe afin de créer de nouveaux mappages.

OPTIONS IDMAP

range = bas - haut

Définit la plage uid et gid correspondante disponible pour laquelle le backend est faisant autorité.

EXEMPLES

Cet exemple montre comment tdb est utilisé comme backend idmap par défaut. Cette plage configurée est utilisée pour l'allocation des uid et gid.

[global]
# "backend = tdb" est redondant ici car c'est le défaut
idmap config * : backend = tdb
idmap config * : range = 1000000-2000000
