idevicescreenshot(1) Manuel des commandes générales idevicescreenshot(1)

NOM

idevicescreenshot - Obtient une capture d'écran du périphérique connecté.

SYNTAXE

idevicescreenshot [OPTIONS] [FICHIER]

DESCRIPTION

Obtient une capture d'écran du périphérique connecté.

La capture d'écran est sauvegardée sous forme d'image TIFF avec le nom de FICHIER donné, le nom par défaut étant "screenshot-DATE.tiff", par exemple : ./screenshot-2013-12-31-23-59-59.tiff

NOTE : Une image disque de développeur montée est requise sur le périphérique, sinon le service screenshotr n'est pas disponible.

OPTIONS

-u, --udid UDID
cibler un périphérique spécifique par son UDID.
-n, --network
se connecter à un périphérique réseau.
-d, --debug
activer le débogage de la communication.
-h, --help
affiche les informations d'utilisation
-v, --version
affiche les informations de version.
