Affiche une liste avec le PID et le nom de tous les processus actuellement en cours d'exécution sur

archive

Demande un logarchive à l'appareil. Il sera écrit au format tar dans PATH. Pour envoyer vers un autre processus, utilisez - comme PATH. Voici quelques options pour restreindre les données des messages de log.

Afin de visualiser le logarchive dans une visionneuse de log compatible, vous pouvez rediriger les données de sortie vers tar et le faire extraire dans un nouveau répertoire

:

mkdir test.logarchive && tools/idevicesyslog archive - |tar -C test.logarchive

-xv

dant l'extraction.
Autres options pour archiv

--start-time
VALUE
Heure de début des données de log sous forme d'horodatage UNIX. Les messages antérieurs seront
ignorés.
--age-limit
VALUE
Âge maximal des données de log, supposément en nombre de
jours.
--size-limit
VALUE
Limite la taille de l'archive. L'unité est actuellement inconnue, n'hésitez donc pas à
expérimenter.
Gardez à l'esprit que l'appareil n'a généralement qu'un arrière-plan de quelques minutes, les options pourraient donc ne pas avoir l'effet désiré. Ce n'est pas un
bogue.

OPTIONS DE

FILTRE
-m, --match
STRING
n'affiche que les messages contenant

STRING
affiche les messages ne contenant pas

-t, --trigger
STRING
démarre la journalisation lors de la correspondance avec STRING

Lorsque spécifié, la journalisation démarrera dès qu'un message de log contenant la chaîne donnée sera rencontré. Voir aussi -T, --untrigger. Les autres filtres s'appliquent toujours, mais les mess

ages filtrés ne sont évidemment affichés qu'
une fois la journalisation démarrée.
-T, --untrigger
STRING
arrête la journalisation lors de la correspondance avec STRING

Lorsque spécifié, la journalisation s'arrêtera dès qu'un message de log contenant la chaîne donnée sera rencontré. Voir aussi -t, --trigger. Les autres filtres s'appliquent toujours, mais les messages filtrés ne sont évidemment affichés qu'avant l'arrêt de la

journalisation.

REMARQUE : Si aucun --trigger n'est donné, idevicesyslog quittera ap

rès qu'un message de log co
rrespondant a été rencontré.
-p, --process
PROCESS
n'affiche que les messages du/des processus correspondant(s)

PROCESS est une chaîne qui peut être soit un pid numérique, soit un nom de

processus. Elle supporte également plusieurs noms de processus ou pids dans
une seule chaîne, séparés par | (assurez-vous d'utiliser des guillemets !).
-e, --exclude
PROCESS
affiche tous les messages sauf ceux du/des processus correspondant(s)

PROCESS est une chaîne qui peut être soit un pid numérique, soit un nom de

processus. Elle supporte également plusieurs noms de processus ou pids dans
une seule chaîne, séparés par | (assurez-vous d'utiliser des guillemets !).
-q,
--quiet
définit un filtre pour exclure les processus bruyants courants

Le syslog pouvant être assez bruyant, ce commutateur rapide de ligne de commande permet de faire taire un ensemble prédéfini de processus couramment connus. La liste des processus mis en sourdine peut être récupérée avec --quiet-l
