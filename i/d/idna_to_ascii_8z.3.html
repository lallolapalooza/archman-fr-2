NOM

idna_to_ascii_8z - Fonction d'API

SYNTAXE

#include <idna.h>

int idna_to_ascii_8z(const char * input, char ** output, int flags);

ARGUMENTS

const char * input
chaîne d'entrée UTF-8 terminée par un caractère nul.
char ** output
pointeur vers la chaîne de sortie nouvellement allouée.
int flags
une valeur Idna_flags, par exemple IDNA_ALLOW_UNASSIGNED ou IDNA_USE_STD3_ASCII_RULES.

DESCRIPTION

Convertit un nom de domaine UTF-8 en chaîne ASCII. Le nom de domaine peut contenir plusieurs étiquettes, séparées par des points. Le tampon de sortie doit être désalloué par l'appelant.

Valeur de retour : Renvoie IDNA_SUCCESS en cas de succès, ou un code d'erreur.
