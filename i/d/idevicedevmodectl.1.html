NOM

idevicedevmodectl - Activer le mode développeur sur les appareils iOS 16+ ou afficher le statut actuel.

SYNTAXE

idevicedevmodectl COMMANDE [OPTIONS]

DESCRIPTION

Activer le mode développeur sur les appareils iOS 16+ ou afficher le statut actuel.

NOTE

Les appareils protégés par un code d'accès NE permettront PAS l'activation du mode développeur depuis la ligne de commande. Il doit être activé sur l'appareil lui-même dans Réglages > Confidentialité et sécurité > Mode développeur. La commande enable essaiera de l'activer et vous indiquera si c'est le cas. Si le menu n'apparaît pas, vous pouvez utiliser la commande reveal pour le faire apparaître.

COMMANDES

list
Affiche le statut du mode développeur de tous les appareils connectés, ou d'un appareil spécifique si --udid est spécifié.
enable
Active le mode développeur (l'appareil redémarrera), et le confirme après le redémarrage de l'appareil.
arm
Arme le mode développeur (l'appareil redémarrera)
confirm
Confirme l'activation du mode développeur
reveal
Révèle le menu du mode développeur sur l'appareil dans Réglages > Confidentialité et sécurité

OPTIONS

-u, --udid UDID
cible un appareil spécifique par UDID
-n, --network
se connecte à un appareil réseau
-d, --debug
active le débogage de communication
-h, --help
affiche les informations d'utilisation
-v, --version
affiche les informations de version
