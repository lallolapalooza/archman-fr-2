IDENT(8) Documentation InterNetNews IDENT(8)

NOM

ident - résolveur ident pour nnrpd

SYNTAXE

ident [-p port] [-t]

DESCRIPTION

Ce programme tente de résoudre les noms d'utilisateur pour nnrpd en utilisant le protocole ident pour interroger l'hôte distant. Il contacte l'hôte distant en utilisant IPv4 ou IPv6 selon le protocole utilisé pour la connexion NNTP entrante.

OPTIONS

-p port
Si cette option est donnée, tente de contacter identd sur le port distant spécifié (qui peut être une spécification numérique ou symbolique). Les valeurs non numériques seront recherchées à l'aide de getservbyname(3). La valeur par défaut est le résultat de "getservbyname("ident")" si disponible, ou le port 113 sinon.
-t
Si cette option est donnée, l'identité retournée n'aura jamais de partie domaine. C'est-à-dire, si le serveur distant renvoie un résultat contenant un caractère "@", ident tronque la réponse au niveau du "@". Ceci est utile pour permettre au paramètre default-domain dans readers.conf de remplacer le domaine fourni par l'hôte distant (en particulier si la partie domaine fournie est un nom de machine locale non qualifié plutôt qu'un nom de domaine complet).

EXEMPLE

Le fragment suivant de readers.conf(5) indique à nnrpd de faire confiance aux informations ident pour les hôtes sur un réseau local, mais de remplacer le domaine renvoyé par la requête ident :

auth LAN {
    hosts: "192.168/16"
    res: "ident -t"
    default-domain: "internal.example.com"
}
access LAN {
    users: "*@internal.example.com"
    newsgroups: example.*
}

L'accès est accordé aux groupes example.* pour tous les utilisateurs du réseau local dont les machines répondent aux requêtes ident.
