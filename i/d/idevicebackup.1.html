NOM

idevicebackup - Créer ou restaurer une sauvegarde pour les appareils.

SYNOPSIS

idevicebackup [OPTIONS] CMD [RÉPERTOIRE]

DESCRIPTION

Crée ou restaure une sauvegarde dans/depuis le répertoire spécifié.

NOTE : Cet outil est obsolète. Voir idevicebackup2(1) pour un outil mis à jour.

OPTIONS

-u, --udid UDID
cibler un appareil spécifique par UDID.
-n, --network
se connecter à un appareil réseau.
-d, --debug
activer la débogage de communication.
-h, --help
affiche les informations d'utilisation.
-v, --version
affiche les informations de version.

COMMANDES

backup
sauvegarde un appareil dans RÉPERTOIRE.
restore
restaure une sauvegarde d'appareil depuis RÉPERTOIRE.
