NOM

idmap_rid - Backend idmap_rid de Samba pour Winbind

DESCRIPTION

Le backend idmap_rid fournit une méthode pour utiliser un schéma de mappage algorithmique pour mapper les UID/GID et les SID. Aucune base de données n'est nécessaire dans ce cas car le mappage est déterministe.

Actuellement, il doit y avoir une configuration idmap explicite pour chaque domaine qui doit utiliser le backend idmap_rid, en utilisant des plages disjointes.

NOTE : Le backend idmap_rid ne peut PAS être utilisé comme backend par défaut. On a généralement besoin de définir une plage idmap par défaut inscriptible, en utilisant un backend comme tdb ou ldap qui peut créer des identifiants Unix, afin de pouvoir mapper les SID BUILTIN et d'autres domaines, et aussi afin de pouvoir créer des mappages de groupes. Voir l'exemple ci-dessous.

OPTIONS IDMAP

range = bas - haut

Définit la plage correspondante d'uid et gid disponible pour laquelle le backend est faisant autorité. Notez que la plage agit comme un filtre. Si l'UID ou le GID déterminé algorithmiquement tombe en dehors de la plage, il est ignoré et le mappage correspondant est rejeté. Il est destiné à éviter les chevauchements accidentels d'UID/GID entre les identifiants locaux et distants définis.

base_rid = ENTIER

Définit l'entier de base utilisé pour construire les SID à partir d'un UID ou d'un GID, et pour rebaser l'UID ou le GID à obtenir à partir d'un SID. Cela signifie que les SID avec un RID inférieur au RID de base sont filtrés. La valeur par défaut est de ne pas restreindre les rids autorisés, c'est-à-dire une valeur base_rid de 0.

L'utilisation de ce paramètre est obsolète.

FORMULES DE MAPPAGE

L'ID Unix d'un RID est calculé comme suit :

ID = RID - BASE_RID + LOW_RANGE_ID.

En conséquence, la formule pour calculer le RID d'un ID Unix donné est la suivante :

RID = ID + BASE_RID - LOW_RANGE_ID.

EXEMPLES

Cet exemple montre comment configurer deux domaines avec idmap_rid, le domaine principal et un domaine de confiance, en laissant le schéma de mappage d'identifiants par défaut sur tdb. L'exemple démontre également l'utilisation du paramètre base_rid pour le domaine de confiance.

[global]
security = domain
workgroup = MAIN
idmap config * : backend        = tdb
idmap config * : range          = 1000000-1999999
idmap config MAIN : backend     = rid
idmap config MAIN : range       = 10000 - 49999
idmap config TRUSTED : backend  = rid
idmap config TRUSTED : range    = 50000 - 99999
idmap config TRUSTED : base_rid = 500000
