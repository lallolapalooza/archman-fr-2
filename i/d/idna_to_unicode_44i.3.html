NOM

idna_to_unicode_44i - Fonction API

SYNTAXE

#include <idna.h>

int idna_to_unicode_44i(const uint32_t * in, size_t inlen, uint32_t * out, size_t * outlen, int flags);

ARGUMENTS

const uint32_t * in
tableau d'entrée avec les points de code unicode.
size_t inlen
longueur du tableau d'entrée avec les points de code unicode.
uint32_t * out
tableau de sortie avec les points de code unicode.
size_t * outlen
à l'entrée, taille maximale du tableau de sortie avec les points de code unicode, à la sortie, taille réelle du tableau de sortie avec les points de code unicode.
int flags
une valeur Idna_flags, par exemple IDNA_ALLOW_UNASSIGNED ou IDNA_USE_STD3_ASCII_RULES.

DESCRIPTION

L'opération ToUnicode prend une séquence de points de code Unicode qui composent une étiquette de domaine et retourne une séquence de points de code Unicode. Si la séquence d'entrée est une étiquette sous forme ACE, le résultat est une étiquette internationalisée équivalente qui n'est pas sous forme ACE, sinon la séquence originale est retournée inchangée.

ToUnicode ne génère jamais d'erreur. Si une étape échoue, la séquence d'entrée originale est retournée immédiatement à cette étape.

Le décodeur Punycode ne peut jamais produire plus de points de code qu'il n'en reçoit en entrée, mais Nameprep le peut, et par conséquent ToUnicode le peut. Notez que le nombre d'octets nécessaires pour représenter une séquence de points de code dépend de l'encodage de caractères particulier utilisé.

Les entrées de ToUnicode sont une séquence de points de code, le drapeau AllowUnassigned et le drapeau UseSTD3ASCIIRules. La sortie de ToUnicode est toujours une séquence de points de code Unicode.

Valeur de retour : retourne une condition d'erreur Idna_rc, mais elle ne doit être utilisée qu'à des fins de débogage. Le tampon de sortie est toujours garanti de contenir les données correctes selon la spécification (hors erreurs induites par malloc). NB ! Cela signifie que vous ignorez normalement le code de retour de cette fonction, car sa vérification enfreint la norme.
