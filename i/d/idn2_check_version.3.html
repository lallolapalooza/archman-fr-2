idn2_check_version(3)

Paquet: libidn2

Licences: GPL2, LGPL3

idn2_check_version(3) libidn2 idn2_check_version(3)

NOM

idn2_check_version - Fonction de l'API

SYNOPSIS

#include <idn2.h>

const char * idn2_check_version(const char * req_version);

ARGUMENTS

const char * req_version
chaîne de version à comparer, ou NULL.

DESCRIPTION

Vérifie la version de la bibliothèque IDN2. Cette fonction peut également être utilisée pour lire la version du code de la bibliothèque utilisée. Voir IDN2_VERSION pour une chaîne req_version appropriée, elle correspond à la version du fichier d'en-tête idn2.h. Normalement, ces deux numéros de version correspondent, mais si vous utilisez une application construite avec une ancienne libidn2 avec une bibliothèque partagée libidn2 plus récente, ils seront différents.

Valeur de retour : vérifie que la version de la bibliothèque est au minimum celle donnée sous forme de chaîne dans req_version et retourne la chaîne de version réelle de la bibliothèque ; retourne NULL si la condition n'est pas satisfaite. Si NULL est passé à cette fonction, aucune vérification n'est effectuée et seule la chaîne de version est retournée.
