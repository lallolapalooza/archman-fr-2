idevicecrashreport(1) Manuel des commandes générales idevicecrashreport(1)

NOM

idevicecrashreport - Récupère les rapports de crash d'un appareil.

SYNTAXE

idevicecrashreport [OPTIONS] RÉPERTOIRE

DESCRIPTION

Utilititaire simple pour déplacer les rapports de crash d'un appareil vers un répertoire local.

L'utilitaire affiche des lignes préfixées par "Link:", "Copy:" ou "Move:" selon qu'un lien symbolique a été créé, qu'un fichier a été copié ou déplacé de l'appareil vers le RÉPERTOIRE cible.

OPTIONS

-u, --udid UDID
Cible un appareil spécifique par UDID.
-n, --network
Se connecte à un appareil réseau.
-e, --extract
Extrait le rapport de crash brut dans des fichiers '.crash' séparés.
-k, --keep
Copie les rapports de crash depuis l'appareil, mais ne les supprime pas.
-d, --debug
Active le débogage de la communication.
-f, --filter NOM
Filtre les rapports de crash par NOM (sensible à la casse).
--remove-all
Supprime tous les fichiers de log de crash sans les copier. Peut être utilisé avec -f pour ne supprimer que les fichiers correspondants.
-h, --help
Affiche les informations d'utilisation.
-v, --version
Affiche les informations de version.
