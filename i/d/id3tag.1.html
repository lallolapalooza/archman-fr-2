ID3TAG(1) Commande utilisateur ID3TAG(1)

NOM

id3tag - Ajoute des étiquettes id3v1 et/ou id3v2 à un fichier mp3.

SYNTAXE

id3tag [ OPTION ]... [ FICHIER ]...

DESCRIPTION

Id3tag rendra les deux types d'étiquettes par défaut. Seul le dernier type d'étiquette indiqué dans la liste des options sera utilisé. Les informations non rendues resteront inchangées dans le fichier d'origine. Il analysera et convertira également les trames Lyrics3 v2.0, mais ne les rendra pas.

OPTIONS

-1, --v1tag
Rendre uniquement l'étiquette id3v1
-2, --v2tag
Rendre uniquement l'étiquette id3v2
-h, --aide
Afficher l'aide et quitter
-v, --version
Afficher les informations de version et quitter
-a, --artiste ARTISTE
Définir les informations de l'artiste
-s, --chanson CHANSON
Définir le titre de la chanson
-A, --album ALBUM
Définir le titre de l'album
-c, --commentaire COMMENTAIRE
Définir les informations du commentaire
-C, --description DESCRIPTION
Définir la description du commentaire
-g, --genre num
Définir le numéro du genre
-y, --annee num
Définir l'année
-t, --piste num
Définir le numéro de la piste
-T, --total num
Définir le nombre total de pistes sur l'album

VOIR AUSSI

id3convert(1), id3info(1), id3v2(1)
