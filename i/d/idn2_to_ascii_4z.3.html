NOM

idn2_to_ascii_4z - fonction d'API

SYNTAXE

#include <idn2.h>

int idn2_to_ascii_4z(const uint32_t * input, char ** output, int flags);

ARGUMENTS

const uint32_t * input
chaîne Unicode (UCS-4) d'entrée terminée par zéro.
char ** output
pointeur vers une chaîne de sortie nouvellement allouée et terminée par zéro.
int flags
facultatif idn2_flags pour modifier le comportement.

DESCRIPTION

Convertit un nom de domaine UCS-4 en chaîne ASCII en utilisant les règles IDNA2008. Le nom de domaine peut contenir plusieurs étiquettes, séparées par des points. Le tampon de sortie doit être libéré par l'appelant.

Le comportement par défaut de cette fonction (lorsque les drapeaux sont nuls) est d'appliquer les règles IDNA2008 sans les amendements TR46. Comme le traitement non transitionnel de TR46 est aujourd'hui omniprésent, en cas de doute, il est recommandé d'appeler cette fonction avec les drapeaux IDN2_NONTRANSITIONAL et IDN2_NFC_INPUT pour la compatibilité avec d'autres logiciels.

Valeur de retour : retourne IDN2_OK en cas de succès, ou un code d'erreur.
