idn2_lookup_u8(3) libidn2 idn2_lookup_u8(3)

NOM

idn2_lookup_u8 - Fonction d'API

SYNTAXE

#include <idn2.h>

int idn2_lookup_u8(const uint8_t * src, uint8_t ** lookupname, int flags);

ARGUMENTS

const uint8_t * src
chaîne d'entrée terminée par zéro, encodée en UTF-8, sous forme normalisée Unicode NFC.
uint8_t ** lookupname
variable de sortie nouvellement allouée contenant le nom à rechercher dans le DNS.
int flags
facultatif, idn2_flags pour modifier le comportement.

DESCRIPTION

Effectue la conversion de nom de domaine pour la recherche IDNA2008 sur la chaîne src, telle que décrite dans la section 5 de la RFC 5891. Notez que la chaîne d'entrée doit être encodée en UTF-8 et être sous forme normalisée Unicode NFC.

Passez IDN2_NFC_INPUT dans flags pour convertir l'entrée en forme NFC avant tout traitement ultérieur. IDN2_TRANSITIONAL et IDN2_NONTRANSITIONAL impliquent déjà IDN2_NFC_INPUT.

Passez IDN2_ALABEL_ROUNDTRIP dans flags pour convertir les étiquettes A d'entrée en étiquettes U et effectuer des tests supplémentaires. Ceci est la valeur par défaut depuis la version 2.2. Pour désactiver ce comportement, passez IDN2_NO_ALABEL_ROUNDTRIP

Passez IDN2_TRANSITIONAL pour activer le traitement transitionnel Unicode TR46, et IDN2_NONTRANSITIONAL pour activer le traitement non-transitionnel Unicode TR46.

Plusieurs drapeaux peuvent être spécifiés en utilisant l'opérateur binaire OU (|).

Après la version 2.0.3 : IDN2_USE_STD3_ASCII_RULES est désactivé par défaut. Auparavant, nous éliminions les caractères non-STD3 des chaînes de domaine telles que _443._tcp.example.com, ou les adresses IP 1.2.3.4/24 fournies aux fonctions libidn2. C'était une régression inattendue pour les applications passant de libidn, et par conséquent, ce n'est plus appliqué par défaut. Utilisez IDN2_USE_STD3_ASCII_RULES pour réactiver ce comportement.

Après la version 0.11 : lookupname peut être NULL pour tester la recherche de src sans allouer de mémoire.

RETOUR

En cas de conversion réussie, IDN2_OK est retourné. Si le nom de domaine de sortie ou l'une de ses étiquettes était trop longue, IDN2_TOO_BIG_DOMAIN ou IDN2_TOO_BIG_LABEL est retourné, ou un autre code d'erreur est retourné.
