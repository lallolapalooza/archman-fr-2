NOM

idn2 - Outil de conversion des noms de domaine internationalisés de Libidn2

SYNTAXE

idn2 [OPTION]... [CHAÎNES]...

DESCRIPTION

L'outil idn2 convertit les domaines DNS de l'encodage UTF-8 vers l'encodage compatible ASCII (ACE), tel qu'utilisé dans le protocole DNS. Le format d'encodage est le format IDNA2008/TR46 (Internationalized Domain Name).

Convertit les noms de domaine internationalisés (IDNA2008) STRINGS, ou l'entrée standard.

Interface en ligne de commande pour l'implémentation Libidn2 de l'IDNA2008.

Toutes les chaînes sont censées être encodées dans le jeu de caractères de la locale.

Pour traiter une chaîne qui commence par `-', par exemple `-foo', utilisez `--' pour signaler la fin des paramètres, comme dans `idn2 --quiet -- -foo'.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-h, --help
Imprimer l'aide et quitter
-V, --version
Imprimer la version et quitter
-d, --decode
Décoder (punycode) le nom de domaine
-l, --lookup
Rechercher le nom de domaine (par défaut)
-r, --register
Enregistrer une étiquette
-T, --tr46t
Activer le traitement transitionnel TR46
-N, --tr46nt
Activer le traitement non transitionnel TR46
--no-tr46
Désactiver le traitement TR46
--usestd3asciirules
Activer les règles STD3 ASCII
--no-alabelroundtrip
Désactiver le retour aller-retour A-label pour les recherches
--debug
Imprimer les informations de débogage
--quiet
Opération silencieuse
