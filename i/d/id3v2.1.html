?[4mID3V2?[24m(1) Commande utilisateur ?[4mID3V2?[24m(1)

?[1mNOM?[0m
id3v2 - Ajoute/Modifie/Supprime/Affiche les étiquettes id3v2, convertit/liste les
étiquettes id3v1

?[1mSYNTAXE?[0m
?[1mid3v2 ?[22m[ ?[4mOPTION?[24m ] [ ?[4mFICHIER?[24m ]

?[1mOPTIONS?[0m
?[1m-h, --help?[0m
Affiche l'aide et quitte


?[1m-f, --list-frames?[0m
Affiche toutes les images possibles pour id3v2


?[1m-L, --list-genres?[0m
Liste tous les genres id3v1


?[1m-v, --version?[0m
Affiche les informations de version et quitte


?[1m-l, --list?[0m
Liste les étiquettes du ou des fichiers


?[1m-R, --list-rfc822?[0m
Liste en utilisant un format de style rfc822 pour la sortie


?[1m-d, --delete-v2?[0m
Supprime les étiquettes id3v2


?[1m-s, --delete-v1?[0m
Supprime les étiquettes id3v1


?[1m-D, --delete-all?[0m
Supprime les étiquettes id3v1 et id3v2


?[1m-C, --convert?[0m
Convertit l'étiquette id3v1 en id3v2


?[1m-a, --artist ARTISTE?[0m
Définit les informations de l'artiste


?[1m-A, --album ALBUM?[0m
Définit les informations du titre de l'album


?[1m-t, --song CHANSON?[0m
Définit les informations du titre de la chanson


?[1m-c, --comment DESCRIPTION:COMMENTAIRE?[0m
Définit les informations du commentaire


?[1m-g, --genre nombre?[0m
Définit le numéro du genre


?[1m-y, --year nombre?[0m
Définit l'année


?[1m-T, --track nombre/nombre?[0m
Définit le numéro de piste/(optionnel) nombre total de pistes

?[1mVOIR AUSSI?[0m
id3tag(1), id3info(1), id3convert(1)
