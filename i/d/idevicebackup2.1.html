idevicebackup2(1) Manuel des commandes générales idevicebackup2(1)

NOM

idevicebackup2 - Créer ou restaurer des sauvegardes pour les appareils exécutant iOS 4 ou une version ultérieure.

SYNTAXE

idevicebackup2 [OPTIONS] CMD [OPTIONS_CMD] RÉPERTOIRE

DESCRIPTION

Crée ou restaure une sauvegarde dans/depuis le répertoire spécifié.

OPTIONS

-u, --udid UDID
cible un appareil spécifique par UDID.
-s, --source UDID
utilise les données de sauvegarde de l'appareil spécifié par UDID.
-i, --interactive
demande les mots de passe de manière interactive sur la ligne de commande.
-n, --network
se connecte à un appareil réseau.
-d, --debug
active la débogage de la communication.
-h, --help
affiche les informations d'utilisation.
-v, --version
affiche les informations de version.

COMMANDES

backup
crée une sauvegarde pour l'appareil.
--full
force une sauvegarde complète depuis l'appareil.
restore
restaure la dernière sauvegarde sur l'appareil.
--system
restaure également les fichiers système.
--no-reboot
ne redémarre PAS le système une fois terminé.
--copy
crée une copie du dossier de sauvegarde avant la restauration.
--settings
restaure les paramètres de l'appareil à partir de la sauvegarde.
--remove
supprime les éléments qui ne sont pas restaurés.
--skip-apps
ne déclenche pas la réinstallation des applications après la restauration.
--password PWD
fournit le mot de passe pour la sauvegarde source chiffrée. Si omis, le mot de passe sera demandé en mode interactif (-i), ou il peut être transmis via la variable d'environnement BACKUP_PASSWORD.
info
affiche les détails de la dernière sauvegarde complète de l'appareil.
list
liste les fichiers de la dernière sauvegarde complète au format CSV.
unback
décompresse une sauvegarde complète dans DIRECTORY/_unback_/
encryption on|off [PWD]
active ou désactive le chiffrement des sauvegardes. Le mot de passe sera demandé en mode interactif (-i) s'il est omis, ou il peut être transmis via la variable d'environnement BACKUP_PASSWORD.
changepw [OLD NEW]
change le mot de passe de sauvegarde sur l'appareil cible. Les mots de passe seront demandés en mode interactif (-i) s'ils sont omis, ou ils peuvent être transmis via les variables d'environnement BACKUP_PASSWORD (ancien mot de passe) et BACKUP_PASSWORD_NEW (nouveau mot de passe) respectivement.
cloud on|off
active ou désactive l'utilisation du cloud (nécessite un compte iCloud).

CONSIDÉRATIONS DE SÉCURITÉ

Passer les mots de passe sur la ligne de commande n'est pas recommandé, car cela pourrait révéler le mot de passe de sauvegarde à d'autres utilisateurs via la liste des processus ou l'historique des commandes. Utilisez le mode interactif (-i) ou transmettez-les via la ou les variables d'environnement mentionnées dans la description des commandes respectives ci-dessus.
