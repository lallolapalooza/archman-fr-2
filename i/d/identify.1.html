identify(1) Manuel des commandes générales identify(1)

NOM

identify - décrit le format et les caractéristiques d'un ou plusieurs fichiers image.

SYNTAXE

magick identify [options] fichier-entree

VUE D'ENSEMBLE

Le programme identify fait partie de la suite d'outils ImageMagick(1). Il décrit le format et les caractéristiques d'un ou plusieurs fichiers image. Il signale également si une image est incomplète ou corrompue. Les informations retournées comprennent le numéro de l'image, le nom du fichier, la largeur et la hauteur de l'image, si l'image est mappée en couleurs ou non, le nombre de couleurs dans l'image (par défaut désactivé, utiliser l'option -define unique=true), le nombre d'octets dans l'image, le format de l'image (JPEG, PNM, etc.), et enfin le nombre de secondes qu'il a fallu pour lire et traiter l'image. De nombreux autres attributs sont disponibles avec l'option verbose.

Pour plus d'informations sur la commande identify, ouvrez votre navigateur sur file:///usr/share/doc/ImageMagick-7/www/identify.html ou https://imagemagick.org/script/identify.php.

DESCRIPTION

Paramètres de l'image :
-alpha option on, activate, off, deactivate, set, opaque, copy
transparent, extract, background, or shape
-antialias supprimer le pixellisation
-authenticate valeur déchiffrer l'image avec ce mot de passe
-clip découper le long du premier chemin du profil 8BIM
-clip-mask nom_fichier associer un masque de découpage à l'image
-clip-path id découper le long d'un chemin nommé du profil 8BIM
-colorspace type espace colorimétrique alternatif de l'image
-crop géométrie découper une région rectangulaire de l'image
-define format:option
définir une ou plusieurs options de format d'image
-define unique=true retourner le nombre de couleurs uniques dans l'image
-density géométrie densité horizontale et verticale de l'image
-depth valeur profondeur de l'image
-endian type boutisme (MSB ou LSB) de l'image
-extract géométrie extraire une zone de l'image
-features distance analyser les caractéristiques de l'image (par ex. contraste, corrélation)
-format "chaîne" afficher les caractéristiques formatées de l'image
-fuzz distance considérer les couleurs dans cette distance comme égales
-gamma valeur de correction gamma
-interlace type type de schéma d'entrelacement de l'image
-interpolate méthode méthode d'interpolation des couleurs des pixels
-limit type valeur limite de la ressource du cache de pixels
-list type Color, Configure, Delegate, Format, Magic, Module,
Resource, or Type
-matte stocker le canal alpha si l'image en a un
-moments rapporter les moments de l'image
-monitor surveiller la progression
-ping déterminer efficacement les attributs de l'image
-precision valeur nombre maximum de chiffres significatifs à imprimer
-quiet supprimer tous les messages d'avertissement
-read-mask nom_fichier associer un masque de lecture à l'image
-regard-warnings prêter attention aux messages d'avertissement
-respect-parentheses les paramètres restent en vigueur jusqu'à la limite des parenthèses
-sampling-factor géométrie
facteur d'échantillonnage horizontal et vertical
-seed valeur initialiser une nouvelle séquence de nombres pseudo-aléatoires
-set attribut valeur définir un attribut d'image
-size géométrie largeur et hauteur de l'image
-strip supprimer tous les profils et commentaires de l'image
-unique afficher le nombre de couleurs uniques dans l'image
-units type les unités de résolution de l'image
-verbose imprimer des informations détaillées sur l'image
-virtual-pixel méthode
méthode d'accès aux pixels virtuels

Opérateurs d'image :
-auto-orient orienter automatiquement l'image
-channel mask définir le masque du canal de l'image
-grayscale méthode convertir l'image en niveaux de gris
-negate remplacer chaque pixel par sa couleur complémentaire

Options diverses :
-debug events afficher des informations de débogage copieux
-help imprimer les options du programme
-list type imprimer une liste des arguments d'option pris en charge
-log format format des informations de débogage
-version imprimer les informations de version

Par défaut, le format de l'image `fichier' est déterminé par son numéro magique. Pour spécifier un format d'image particulier, précédez le nom du fichier d'un nom de format d'image et de deux-points (c'est-à-dire ps:image) ou spécifiez le type d'image comme suffixe du nom de fichier (c'est-à-dire image.ps). Spécifiez `fichier' comme '-' pour l'entrée ou la sortie standard.

NOTE

Bien que certaines options semblent modifier le fichier à identifier, la commande identify est strictement en lecture seule. Par exemple, l'option crop rogne l'image en mémoire puis décrit le résultat.
