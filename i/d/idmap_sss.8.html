NOM

idmap_sss - Backend idmap_sss de SSSD pour Winbind

DESCRIPTION

Le module idmap_sss fournit un moyen d'appeler SSSD pour mapper les UID/GID et les SID. Aucune base de données n'est nécessaire dans ce cas, car le mappage est effectué par SSSD.

OPTIONS IDMAP

range = low - high

Définit la plage correspondante disponible d'UID et de GID pour laquelle le backend est faisant autorité.

EXEMPLES

Cet exemple montre comment configurer idmap_sss comme module de mappage par défaut.

[global]
security = ads
workgroup = <NOM-COURT-DOMAINE-AD>
idmap config <NOM-COURT-DOMAINE-AD> : backend        = sss
idmap config <NOM-COURT-DOMAINE-AD> : range          = 200000-2147483647
idmap config * : backend        = tdb
idmap config * : range          = 100000-199999

Veuillez remplacer <NOM-COURT-DOMAINE-AD> par le nom de domaine NetBIOS du domaine AD. Si plusieurs domaines AD doivent être utilisés, chaque domaine a besoin d'une ligne de configuration idmap avec backend = sss et d'une ligne avec une plage appropriée.

Comme Winbind nécessite un backend par défaut inscriptible et que idmap_sss est en lecture seule, l'exemple inclut backend = tdb par défaut.
