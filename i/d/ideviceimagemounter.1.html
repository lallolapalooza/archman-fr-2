ideviceimagemounter(1) Manuel des commandes générales ideviceimagemounter(1)

NOM

ideviceimagemounter - Monter, lister ou démonter une image disque sur l'appareil.

SYNTAXE

ideviceimagemounter [OPTIONS] COMMANDE [OPTIONS COMMANDE]

DESCRIPTION

Monter, lister ou démonter une image disque sur l'appareil.

COMMANDES

monter CHEMIN
Monter l'image disque développeur à CHEMIN. Pour iOS 17+, CHEMIN est un répertoire contenant une image .dmg, un fichier BuildManifest.plist et un sous-répertoire Firmware.

Pour les versions plus anciennes, CHEMIN est un nom de fichier .dmg avec un fichier .dmg.signature dans le même répertoire, ou avec un autre paramètre pointant vers un fichier ailleurs.

lister
Lister les images disques montées.
démonter CHEMIN
Démonter l'image montée à CHEMIN.
devmodestatus
Interroger l'état du mode développeur (iOS 16+)

OPTIONS

-u, --udid UDID
Cibler un appareil spécifique par UDID.
-n, --network
se connecter à un appareil réseau.
-d, --debug
activer le débogage de la communication.
-t, --imagetype NOM
le type d'image à utiliser, par défaut 'Developer'
-x, --xml
utiliser la sortie XML
-h, --help
affiche les informations d'utilisation
-v, --version
affiche les informations de version.
