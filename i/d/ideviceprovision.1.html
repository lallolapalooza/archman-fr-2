ideviceprovision(1) Manuel des commandes générales ideviceprovision(1)

NOM

ideviceprovision - Gérer les profils de provisionnement sur un appareil.

SYNTAXE

ideviceprovision [OPTIONS] COMMANDE

DESCRIPTION

Gérer les profils de provisionnement sur un appareil.

OPTIONS

-u, --udid UDID
cible un appareil spécifique par UDID.
-n, --network
se connecte à un appareil réseau.
-x, --xml
affiche la sortie XML lors de l'utilisation de la commande 'dump'.
-d, --debug
active le débogage de la communication.
-h, --help
affiche les informations d'utilisation.
-v, --version
affiche les informations de version.

COMMANDES

install FICHIER
Installe le profil de provisionnement spécifié par FICHIER. Un fichier ".mobileprovision" valide est attendu.
list
Obtient une liste de tous les profils de provisionnement sur l'appareil.
copy CHEMIN
Récupère tous les profils de provisionnement de l'appareil et les stocke dans le répertoire existant spécifié par CHEMIN. Les fichiers seront stockés sous le nom "UUID.mobileprovision".
remove UUID
Supprime le profil de provisionnement identifié par UUID.
dump FICHIER
Affiche des informations détaillées sur le profil de provisionnement spécifié par FICHIER.
