NOM

idris - un langage de programmation fonctionnel pur à usage général avec des types dépendants.

SYNTAXE

idris [ options] [FICHIERS]

DESCRIPTION

Idris est un langage de programmation fonctionnel pur à usage général avec des types dépendants. Les types dépendants permettent de prédiquer les aspects du comportement d'un programme sur des valeurs, signifiant ainsi que certains aspects du comportement d'un programme peuvent être spécifiés précisément dans le type. Il est compilé, avec une évaluation stricte (eager evaluation). Ses caractéristiques sont influencées par Haskell et ML.

+ Types dépendants complets avec correspondance de motifs dépendants

+ Expressions `case` simples, clauses `where`, règle `with`

+ Correspondance de motifs pour les liaisons `let` et `lambda`

+ Surcharge via les Interfaces (similaire aux classes de types), compréhensions Monad

+ Notation `do`, crochets idiomatiques

+ Conventions syntaxiques pour les listes, tuples, paires dépendantes

+ Vérification de la totalité

+ Types coinductifs

+ Syntaxe significative de l'indentation, syntaxe extensible

+ Démonstration de preuve basée sur des tactiques (influencée par Coq)

+ Univers cumulatifs

+ Interface simple pour les fonctions étrangères (FFI)

+ Environnement interactif style Hugs

Il est important de noter qu'Idris est avant tout un outil et un projet de recherche. Par conséquent, les outils fournis et les programmes résultants créés ne doivent pas nécessairement être considérés comme prêts pour la production ni pour un usage industriel.

OPTIONS


--nobanner Supprimer la bannière
-q,--quiet Verbosité faible
--ide-mode Exécuter le REPL d'Idris avec une syntaxe lisible par machine
--ide-mode-socket Choisir une socket pour le mode IDE pour écouter
--ideslave Version obsolète de --ide-mode
--ideslave-socket Version obsolète de --ide-mode-socket
--log NIVEAU Niveau de journalisation de débogage
--logging-categories CATS
Catégories de journalisation séparées par des deux-points. Utiliser --listlogcats
pour voir la liste.
--nobasepkgs Ne pas utiliser le paquet de base donné
--noprelude Ne pas utiliser le prelude donné
--nobuiltins Ne pas utiliser les fonctions intégrées
--check Vérifier uniquement les types, ne pas démarrer le REPL
-o,--output FICHIER Spécifier le fichier de sortie
--interface Générer des fichiers d'interface à partir des listes d'exportation
--typeintype Désactiver la vérification de l'univers
--total Exiger par défaut que les fonctions soient totales
--warnpartial Avertir des fonctions partielles non déclarées
--warnreach Avertir des arguments accessibles mais inaccessibles
--listlogcats Afficher les catégories de journalisation
--link Afficher les indicateurs de lien
--listlibs Afficher les bibliothèques installées
--libdir Afficher le répertoire des bibliothèques
--include Afficher les indicateurs d'inclusion
--V2 Verbosité maximale
--V1 Verbosité accrue
-V, --V0, --verbose Verbosité élevée
--ibcsubdir FICHIER Écrire les fichiers IBC dans un sous-répertoire
-i,--idrispath ARG Ajouter un répertoire à la liste des chemins d'importation
--sourcepath ARG Ajouter un répertoire à la liste des chemins de recherche de source
-p,--package ARG Ajouter un paquet comme dépendance
--port PORT Port TCP du REPL
--build IPKG Construire un paquet
--install IPKG Installer un paquet
--repl IPKG Lancer le REPL, uniquement pour les exécutables
--clean IPKG Nettoyer un paquet
--mkdoc IPKG Générer IdrisDoc pour un paquet
--checkpkg IPKG Vérifier le paquet uniquement
--testpkg IPKG Exécuter les tests pour un paquet
-S,--codegenonly Ne pas effectuer d'autres compilations de la sortie du générateur de code
-c,--compileonly Compiler en fichiers objets plutôt qu'en exécutable
--codegen CIBLE Sélectionner le générateur de code : C, Javascript, Node et
bytecode sont inclus avec Idris
--cg-opt ARG Arguments à passer au générateur de code
-e,--eval EXPR Évaluer une expression sans charger le REPL
--execute Exécuter comme idris
--exec EXPR Exécuter comme idris
-X,--extension EXT Activer une extension de langage (TypeProviders ou
ErrorReflection)
--partial-eval Activer l'évaluation partielle
--target TRIPLE Si pris en charge, le générateur de code ciblera le triple nommé.
--cpu CPU Si pris en charge, le générateur de code ciblera le CPU nommé
par ex. corei7 ou cortex-m3.
--color,--colour Forcer la sortie en couleur
--nocolor,--nocolour Désactiver la sortie en couleur
--optimise-nat-like-types,--optimize-nat-like-types
Compiler les types Nat-like en entiers grands
--no-optimise-nat-like-types,--no-optimize-nat-like-types
Ne pas compiler les types Nat-like en entiers grands
--consolewidth LARGEUR Sélectionner la largeur de la console : auto, infinie, nat
--highlight Émettre la coloration du code source
--no-tactic-deprecation-warnings
Désactiver les avertissements de dépréciation pour l'ancien sous-langage
de tactique
-v,--version Afficher les informations de version
-h,--help Afficher ce texte d'aide
