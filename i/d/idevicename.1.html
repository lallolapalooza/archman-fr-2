NOM

idevicename - Affiche le nom de l'appareil ou le définit à NOM si spécifié.

SYNOPSIS

idevicename [OPTIONS] [NOM]

DESCRIPTION

Utilitaire simple pour gérer le nom de l'appareil.

S'il est appelé sans argument supplémentaire, cet outil affichera le nom actuel de l'appareil.

Si NOM est donné, le nom de l'appareil sera défini sur le nom spécifié.

OPTIONS

-u, --udid UDID
cible un appareil spécifique par UDID.
-n, --network
se connecte à un appareil réseau.
-d, --debug
active le débogage de communication.
-h, --help
affiche les informations d'utilisation
-v, --version
affiche les informations de version.
