NOM

idn2_to_unicode_8z4z - Fonction d'API

SYNTAXE

#include <idn2.h>

int idn2_to_unicode_8z4z(const char * input, uint32_t ** output, G_GNUC_UNUSED int flags);

ARGUMENTS

const char * input
Chaîne d'entrée UTF-8 terminée par un zéro.
uint32_t ** output
Chaîne de sortie UTF-32/UCS-4 nouvellement allouée.
G_GNUC_UNUSED int flags
Actuellement inutilisé.

DESCRIPTION

Convertit un nom de domaine potentiellement encodé ACE au format UTF-8 en une chaîne UTF-32 (décodage punycode). Le tampon de sortie sera terminé par un zéro et devra être désalloué par l'appelant.


output peut être NULL pour tester la recherche de input sans allouer de mémoire.
