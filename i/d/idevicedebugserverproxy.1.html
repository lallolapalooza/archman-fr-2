NOM

idevicedebugserverproxy - Proxy de débogage à distance.

SYNTAXE

idevicedebugserverproxy [OPTIONS] [PORT]

DESCRIPTION

Propose un proxy de connexion debugserver à partir d'un appareil pour le débogage à distance. Après le démarrage, les clients peuvent se connecter à PORT et communiquer avec le debugserver distant en utilisant le protocole de débogage série à distance LLVM. Ainsi, la connexion utilisant LLDB ou un gdb basé sur LLVM à ce port permettrait le débogage à distance. L'image disque de développement doit être montée pour que ce service soit disponible.

OPTIONS

-u, --udid UDID
Cible un appareil spécifique par UDID.
-n, --network
Se connecte à un appareil réseau.
-l, --lldb
Active le support lldb.
-d, --debug
Active le débogage de communication.
-h, --help
Affiche les informations d'utilisation.
-v, --version
Affiche les informations de version.

EMPLOI

PORT
Le port sous lequel le proxy doit écouter les connexions des clients. Si omis, le prochain port disponible sera utilisé et affiché sur stdout.
