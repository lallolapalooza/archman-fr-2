idevice_id(1) Manuel des commandes générales idevice_id(1)

NOM

idevice_id - Lister les appareils connectés ou afficher le nom de l'appareil donné.

SYNTAXE

idevice_id [OPTIONS] [UDID]

DESCRIPTION

idevice_id affiche une liste des appareils connectés. Si un UDID est fourni, le nom de l'appareil connecté avec cet UDID sera récupéré.

Sans aucune option, idevice_id listera tous les appareils disponibles, USB et réseau. La sortie peut être davantage contrôlée avec les OPTIONS suivantes.

OPTIONS

-l, --list
Lister les UDID de tous les appareils connectés via USB.
-n, --network
Lister les UDID de tous les appareils disponibles via le réseau.
-d, --debug
Activer le débogage de la communication.
-h, --help
Afficher les informations d'utilisation.
-v, --version
Afficher les informations de version.
