ISASET(8) Manuel de l'administrateur système ISASET(8)

NOM

isaset - définir les registres ISA

SYNTAXE

isaset [-y] [-W|-L] addrreg datareg address value [mask] #pour l'accès de type I2C
isaset -f [-y] [-W|-L] address value [mask] #pour l'espace d'adressage plat

DESCRIPTION

isaset est un petit programme d'aide pour définir les registres visibles via le bus ISA.

OPTIONS

-f
Activer le mode espace d'adressage plat.
-y
Désactiver le mode interactif. Par défaut, isaset attend une confirmation de l'utilisateur avant de modifier le bus ISA. Lorsque ce drapeau est utilisé, il effectue l'opération directement. Ceci est principalement destiné à être utilisé dans les scripts.
-W
Effectuer une écriture de 16 bits.
-L
Effectuer une écriture de 32 bits.

OPTIONS (mode d'accès de type I2C)

Quatre options doivent être fournies à isaset. addrreg contient l'adresse ISA du registre d'adresse pour la puce à sonder ; datareg contient l'adresse du registre de données. Les deux adresses sont des entiers compris entre 0x0000 et 0x3FFF. Généralement, si l'adresse de base de la puce est 0x0nn0, le registre d'adresse est à 0x0nn5 et le registre de données est à 0x0nn6. L'adresse de base la plus courante pour les puces de surveillance matérielle est 0x0290. Pour les puces Super-I/O, le registre d'adresse est typiquement à 0x2E avec le registre de données à 0x2F. Les paramètres address et value sont deux entiers compris entre 0x00 et 0xFF. isaset écrira la valeur value à l'adresse address. Un mask optionnel peut être fourni en tant que cinquième paramètre, préservant les bits non masqués à l'emplacement écrit.

OPTIONS (mode espace d'adressage plat)

En mode plat, deux paramètres doivent être fournis. address contient l'adresse ISA du registre à écrire ; c'est un entier compris entre 0x0000 et 0xFFFF. Fondamentalement, c'est la somme de l'adresse de base de la puce et de l'adresse du registre de la puce. isaset écrira la valeur value à cette adresse. Un mask optionnel peut être fourni en tant que troisième paramètre, préservant les bits non masqués à l'emplacement écrit.

ATTENTION

Manipuler l'espace de données ISA est extrêmement dangereux. Lancer isaset avec des paramètres aléatoires peut provoquer des plantages système, une perte de données et pire encore ! Soyez extrêmement prudent lors de l'utilisation de ce programme.
