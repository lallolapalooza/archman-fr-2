DESCRIPTIO

N

Ces fonctions vérifient si c, qui doit avoir la valeur d'un unsigned char ou EOF, appartient à une certaine classe de caractères selon la locale spécifiée. Les fonctions sans le suffixe « _l » effectuent la vérification en fonction de la locale

courante.

Les fonctions avec le suffixe « _l » effectuent la vérification en fonction de la locale spécifiée par l'objet locale locale. Le comportement de ces fonctions est indéfini si locale est l'objet locale spécial LC_GLOBAL_LOCALE (voir duplocale(3)) ou s'il ne s'agit pas d'un descripteur d'objet locale

valide.

La liste ci-dessous explique le fonctionnement des fonctions sans le suffixe « _l » ; les fonctions avec le suffixe « _l » diffèrent uniquement par l'utilisation de l'objet locale locale au lieu de la locale

NOM

ispunct, ispunct_l - tester si un caractère est un signe de ponctuation

BIBLIOTHQUE

«─» Standard C Library

«─» Libc

SYNOPSIS

#include <ctype.h>

int ispunct(int c);

#include <locale.h>

int ispunct_l(int c, locale_t locale);

DESCRIPTION

Les fonctions ispunct() et ispunct_l() testent si le caractère c est un caractère de ponctuation.

Le comportement des fonctions ispunct() et ispunct_l() dépend de la catégorie LC_CTYPE de la locale.

Une fonction de classification de caractères est implémentée par un macro avec le même nom, sauf pour isascii(), sauf si le compilateur ne prend pas en charge les macros avec des arguments.

La fonction ispunct_l() effectue la même vérification que ispunct() mais utilise la locale spécifiée par locale.

La locale C définit les caractères de ponctuation comme ceux qui sont imprimables, mais qui ne sont ni des lettres, ni des chiffres, ni des espaces blancs. Les caractères imprimables sont ceux pour lesquels isprint() est vrai. Les caractères de ponctuation sont ceux pour lesquels iscntrl(), isspace(), isdigit(), islower(), isupper() ou isgraph() sont faux.

Dans la locale C, le seul caractère de ponctuation est le caractère!,",#,$,%,&,',(,),*,+,,,-,.,/,:,;,<,=,>,?,@,[,\,],^,_,`,{,|,},~.

VALEUR RENVOYÉE

Les fonctions ispunct() et ispunct_l() renvoient une valeur non nulle si c est un caractère de ponctuation ; sinon, elles renvoient 0.

MAUX ATTENTION

Les normes exigent que l'argument c pour ces fonctions soit soit EOF, soit une valeur qui soit représentable dans le type unsigned char; sinon, le comportement est indéfini. Si l'argument c est de type char, il doit être converti en unsigned char, comme dans l'exemple suivant :


char c;
...
res = toupper((unsigned char) c);

Ceci est nécessaire car char peut être l'équivalent de signed char, auquel cas un octet dont le bit de poids fort est défini serait étendu en signe lors de la conversion en int, donnant une valeur qui est en dehors de la plage de unsigned char.

Les détails sur les caractères qui appartiennent à chaque classe dépendent de la locale. Par exemple, isupper() ne reconnaîtra pas un A-umlaut (&#x00C4;) comme une lettre majuscule dans la locale par défaut C.
