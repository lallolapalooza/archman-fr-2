NOM

iso_8859-10, iso8859-10, Latin-6 - jeu de caractères Latin-10

DESCRIPTION

Le jeu de caractères ISO/IEC 8859-10 définit 256 codes de caractères. Il s'agit d'une extension de l'ISO 8859-1 (Latin-1), qui couvre les langues d'Europe du Nord utilisant des caractères latins, y compris le suédois, le finnois, le norvégien, le danois, l'islandais et le sami.

Les codes 0-175 et 248-255 ne sont pas définis dans ISO/IEC 8859-10.

L'ENSEMBLE DE CARACTÈRES LATIN-10

Les lignes et colonnes suivantes indiquent la signification des codes de caractères ISO 8859-10. Les lignes sont les décimales 200 à 255. Les colonnes sont les décimales 0 à 15. Le code 200 est donc le premier caractère de la ligne 200, et le code 255 est le dernier caractère de la ligne 255.
