NOM

iscsi_iface_netdev_get - Récupérer le nom du périphérique réseau de l'interface iSCSI spécifiée

SYNTAXE

const char * iscsi_iface_netdev_get (struct iscsi_iface *iface);

ARGUMENTS

iface
Pointeur de 'struct iscsi_iface'. Si ce pointeur est NULL, votre programme sera terminé par un assert.

DESCRIPTION

Récupère le nom du périphérique réseau de l'interface iSCSI spécifiée.

RETOUR

const char *. Aucune libération de mémoire n'est nécessaire, les ressources seront libérées par iscsi_session_free ou iscsi_sessions_free.
