NOM

isogmt - Exécute une commande ou un script GMT en mode d'isolation

SYNTAXE

isogmt commande

DESCRIPTION

isogmt exécute une seule commande ou un script shell GMT en **mode d'isolation**. Cela signifie que les fichiers gmt.history et gmt.conf seront lus à partir des emplacements habituels (répertoire courant, ~/.gmt, ou répertoire personnel), mais les modifications ne seront écrites que dans un répertoire temporaire, qui sera supprimé après exécution. Le nom du répertoire temporaire sera disponible pour la commande ou le script via la variable d'environnement GMT_TMPDIR.

EXEMPLES

Exécuter le script shell script.gmt en mode d'isolation :

isogmt sh script.gmt

VOIR AUSSI
