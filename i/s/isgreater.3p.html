ISGREATER(3P) Manuel du programmeur POSIX ISGREATER(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

isgreater — teste si x est supérieur à y

SYNTAXE

#include <math.h>
int isgreater(real-floating x, real-floating y);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 renvoie à la norme ISO C.

La macro isgreater() détermine si son premier argument est supérieur à son second argument. La valeur de isgreater(x, y) est égale à (x) > (y); cependant, contrairement à (x) > (y), isgreater(x, y) ne déclenche pas l'exception de flottant invalide lorsque x et y ne sont pas ordonnés.

VALEUR DE RETOUR

En cas de succès, la macro isgreater() renvoie la valeur de (x) > (y).

Si x ou y est NaN, 0 est renvoyé.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

USAGE APPLICATIF

Les opérateurs relationnels et d'égalité supportent les relations mathématiques habituelles entre les valeurs numériques. Pour toute paire ordonnée de valeurs numériques, exactement une des relations (inférieur, supérieur, égal) est vraie. Les opérateurs relationnels peuvent déclencher l'exception de flottant invalide lorsque les valeurs des arguments sont des NaN. Pour un NaN et une valeur numérique, ou pour deux NaN, seule la relation non ordonnée est vraie. Cette macro est une version silencieuse (ne déclenchant pas d'exception de flottant) d'un opérateur relationnel. Elle facilite l'écriture de code efficace qui tient compte des NaN sans subir l'exception de flottant invalide. Dans la section SYNTAXE, real-floating indique que l'argument doit être une expression de type real-floating.
