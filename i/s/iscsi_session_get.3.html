NOM

iscsi_session_get - Récupérer les sessions iSCSI spécifiées.

SYNOPSIS

int iscsi_session_get (struct iscsi_context *ctx, uint32_t sid, struct iscsi_session **se);

ARGUMENTS

ctx
Pointeur vers 'struct iscsi_context'. Si ce pointeur est NULL, votre programme sera terminé par assert.
sid
uint32_t, identifiant de session iSCSI.
se
Pointeur de sortie vers un pointeur de 'struct iscsi_session'. Sa mémoire doit être libérée par iscsi_session_free. Si ce pointeur est NULL, votre programme sera terminé par assert. Si la session iSCSI spécifiée n'existe pas, ce pointeur sera défini à NULL et LIBISCSI_OK sera retourné.

DESCRIPTION

Récupère les sessions iSCSI spécifiées. Pour les propriétés de

RETOUR

int. Les codes d'erreur valides sont :

* LIBISCSI_OK

* LIBISCSI_ERR_BUG

* LIBISCSI_ERR_NOMEM

* LIBISCSI_ERR_ACCESS

* LIBISCSI_ERR_SYSFS_LOOKUP

* LIBISCSI_ERR_SESS_NOT_FOUND

Le numéro d'erreur peut être converti en chaîne de caractères par iscsi_strerror.
