ISWALNUM(3P) Manuel du programmeur POSIX ISWALNUM(3P)

PREAMBULE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

iswalnum, iswalnum_l — tester un code de caractère large (wide-character) alphanumérique

SYNTAXE

#include <wctype.h>
int iswalnum(wint_t wc);
int iswalnum_l(wint_t wc, locale_t locale);

DESCRIPTION

Pour iswalnum() : La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 s'en remet à la norme ISO C.

Les fonctions iswalnum() et iswalnum_l() testent si wc est un code de caractère large représentant un caractère de la classe alpha ou digit dans la locale actuelle, ou dans la locale représentée par locale, respectivement ; voir le volume des Définitions de base de POSIX.1-2017, Chapitre 7, Locale.

L'argument wc est un wint_t, dont la valeur doit être un code de caractère large correspondant à un caractère valide dans la locale utilisée par la fonction, ou égal à la valeur de la macro WEOF. Si l'argument a toute autre valeur, le comportement est indéfini.

Le comportement est indéfini si l'argument locale de iswalnum_l() est l'objet spécial LC_GLOBAL_LOCALE ou n'est pas un descripteur d'objet locale valide.

VALEUR DE RETOUR

Les fonctions iswalnum() et iswalnum_l() retournent une valeur non nulle si wc est un code de caractère large alphanumérique ; sinon, elles retournent 0.

ERREURS

Aucune erreur n'est définie.
