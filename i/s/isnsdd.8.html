NOM

isnsdd - démon de découverte iSNS

SYNOPIS

isnsdd [-f] [-c nom_fichier] [-d installation-debug]

DESCRIPTION

Isnsdd est un démon côté client pour iSNS. Il enregistre les nœuds de stockage et les portails auprès du service iSNS, et rafraîchit ces enregistrements en temps opportun.

Le démon s'enregistre également pour recevoir des notifications SCN (State Change Notifications) et les traite. Il peut être configuré pour appeler une application auxiliaire externe pour chaque notification de statut reçue. Le chemin d'accès à l'application auxiliaire peut être spécifié via l'option SCNCallout dans le fichier de configuration.

OPTIONS

Par défaut, isnsd prend la plupart de ses paramètres du fichier de configuration /etc/isns/isnsdd.conf, avec les options de ligne de commande suivantes ajoutées :

--config nom_fichier, -c nom_fichier
Cette option remplace le fichier de configuration par défaut.
--foreground,-f
Par défaut, isnsd se place en arrière-plan. En spécifiant cette option, vous pouvez lui dire de s'exécuter au premier plan. Tous les messages d'erreur ou les sorties de débogage seront imprimés sur la console plutôt que d'être envoyés à syslog.
--role rôle
Ceci indique au démon de découverte dans quelle capacité il doit s'enregistrer auprès du serveur iSNS. Rôle peut être soit initiator, soit control. Par défaut, il s'enregistre comme initiateur.
L'enregistrement des nœuds cibles nécessite l'utilisation d'un mécanisme différent, car le serveur cible iSCSI doit informer le démon de découverte de chaque cible exportée séparément. Ceci n'est pas encore implémenté.
--debug installation, -d installation
active le débogage. Les installations valides sont
socket envoi/réception réseau
auth informations liées à l'authentification et à la sécurité
message couche protocole iSNS
state état de la base de données
scn messages SCN (state change notification)
esi messages ESI (entity status inquiry)
all tout ce qui précède

VOIR AUSSI

RFC 4171, isnsd(8), isnsadm(8), isns_config(5).
