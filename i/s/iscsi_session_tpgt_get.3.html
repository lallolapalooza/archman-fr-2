NOM

iscsi_session_tpgt_get - Récupère le tag du groupe de portail cible d'une session spécifiée

SYNTAXE

int32_t iscsi_session_tpgt_get (struct iscsi_session *se);

ARGUMENTS

se
Pointeur vers 'struct iscsi_session'. Si ce pointeur est NULL, votre programme sera terminé par une assertion.

DESCRIPTION

Récupère le tag du groupe de portail cible de la session iSCSI spécifiée.

Le tag du groupe de portail cible est une valeur qui identifie de manière unique un groupe de portail au sein d'un nœud cible iSCSI. Cette clé contient la valeur du tag du groupe de portail qui dessert la requête de connexion. La cible iSCSI renvoie cette clé à l'initiateur dans la PDU de réponse de connexion à la première PDU de requête de connexion dont le bit C est défini sur 0 lorsque le TargetName est fourni par l'initiateur.

RETOUR

int32_t. -1 si non pris en charge.
