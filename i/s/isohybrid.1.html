NOM

isohybrid — Traiter une image ISO 9660 pour le démarrage en tant que disque dur.

SYNTAXE

isohybrid [OPTIONS] <boot.iso>

DESCRIPTION

L'utilitaire isohybrid modifie une image ISO 9660 générée avec mkisofs, genisoimage, ou des utilitaires compatibles, pour qu'elle soit démarrable en tant que CD-ROM ou en tant que disque dur.

OPTIONS

-h <X>

Nombre de têtes géométriques (défaut 64)
-s <X>

Nombre de secteurs géométriques (défaut 32)
-e <X>, --entry <X>
Spécifier le numéro de l'entrée de partition (1-4)
-o <X>, --offset <X>

Spécifier le décalage de partition (défaut 0)
-t <X>, --type <X>

Spécifier le type de partition (défaut 0x17)
-i <X>, --id <X>

Spécifier l'ID MBR (défaut aléatoire)
-u, --uefi
Construire une image démarrable EFI
-m, --mac
Ajouter le support de la table de partition Apple File Protocol
--forcehd0
Supposer que nous sommes chargés comme disque ID 0
--ctrlhd0
Supposer que le disque ID 0 est enfoncé si la touche Ctrl est pressée
--partok
Permettre le démarrage depuis une partition
-?, --help
Afficher l'aide
-v, --verbose
Afficher une sortie détaillée
-V, --version
Afficher les informations de version
