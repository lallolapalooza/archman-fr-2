ISWGRAPH(3P) Manuel du programmeur POSIX ISWGRAPH(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

iswgraph, iswgraph_l — tester un code de caractère large visible

SYNTAXE

#include <wctype.h>
int iswgraph(wint_t wc);
int iswgraph_l(wint_t wc, locale_t locale);

DESCRIPTION

Pour iswgraph() : Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions iswgraph() et iswgraph_l() vérifient si wc est un code de caractère large représentant un caractère de la classe graph dans la locale actuelle, ou dans la locale représentée par locale, respectivement ; voir le volume des Définitions de base de POSIX.1‐2017, Chapitre 7, Locale.

L'argument wc est un wint_t, dont la valeur doit être un code de caractère large correspondant à un caractère valide dans la locale utilisée par la fonction, ou égal à la valeur de la macro WEOF. Si l'argument a toute autre valeur, le comportement est indéfini.

Le comportement est indéfini si l'argument locale à iswgraph_l() est l'objet de locale spécial LC_GLOBAL_LOCALE ou n'est pas une poignée d'objet de locale valide.

VALEUR DE RETOUR

Les fonctions iswgraph() et iswgraph_l() renvoient une valeur non nulle si wc est un code de caractère large avec une représentation visible ; sinon, elles renvoient 0.

ERREURS

Aucune erreur n'est définie.
