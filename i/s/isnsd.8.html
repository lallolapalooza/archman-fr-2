NOM

isnsd - démon serveur iSNS

SYNTAXE

isnsd [-f] [-4] [-6] [-c nom_fichier] [-d installation-débogage] [--dump-db] [--init]

DESCRIPTION

Isnsd implémente le protocole iSNS tel que défini dans la RFC 4171. iSNS est un protocole de découverte pour iSCSI et iFCP.

OPTIONS

Par défaut, isnsd prendra la plupart de ses paramètres du fichier de configuration /etc/isns/isnsd.conf, à l'exception des options suivantes :

--config nom_fichier, -c nom_fichier
Cette option remplace le fichier de configuration par défaut.
--foreground,-f
Par défaut, isnsd se mettra en arrière-plan. En spécifiant cette option, vous pouvez lui demander de s'exécuter au premier plan. Tout message d'erreur ou sortie de débogage sera imprimé sur la console plutôt que d'être envoyé à syslog.
-4
indique à isnsd de créer uniquement un socket IPv4. Normalement, il utilise IPv6 par défaut (qui acceptera les connexions IPv4 et IPv6).
-6
indique explicitement à isnsd de créer uniquement un socket IPv6. Comme il utilise IPv6 par défaut de toute façon, ceci est en fait une opération nulle.
--debug installation, -d installation
active le débogage. Les installations valides sont
socket envoi/réception réseau
auth informations relatives à l'authentification et à la sécurité
message couche protocole iSNS
state état de la base de données
scn messages SCN (notification de changement d'état)
esi messages ESI (enquête sur l'état de l'entité)
all tous les éléments ci-dessus
--dump-db
Ceci est une fonction d'aide qui lira la base de données à partir du système de fichiers et l'affichera sous forme lisible par l'homme. En utilisant cette option, isnsd n'ouvrira aucun socket et se terminera immédiatement après avoir affiché la base de données.
Cette option est destinée à être utilisée par l'administrateur lorsqu'il soupçonne que la base de données contient des informations erronées/incohérentes.
--init
Cette option créera la clé d'authentification du serveur et les paramètres DSA requis. La clé privée est stockée dans le fichier spécifié par l'option AuthKey (généralement /etc/isns/auth_key). La partie publique de la clé est écrite dans le même répertoire, avec le suffixe .pub ajouté au nom du fichier de clé.

VOIR AUSSI

RFC 4171, isnsadm(8), isnsdd(8), isns_config(5).
