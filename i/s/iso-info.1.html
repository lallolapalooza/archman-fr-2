ISO-INFO(1) Commandes utilisateur ISO-INFO(1)

NOM

iso-info - affiche des informations sur une image ISO 9660

SYNTAXE

iso-info [OPTION...]

DESCRIPTION

-d, --debug=UINT
Définit le niveau de débogage à LEVEL
-i, --input[=FICHIER]
Nom du fichier à partir duquel lire l'image ISO-9960
-f
Génère une sortie similaire à 'find . -print'
-l, --iso9660
sortie similaire à 'ls -lR' pour un système de fichiers ISO 9660
-U, --udf
sortie similaire à 'ls -lR' pour un système de fichiers UDF
--no-header
Ne pas afficher l'en-tête et les droits d'auteur (pour la régression
--no-joliet
Ne pas utiliser les informations de l'extension Joliet
--no-rock-ridge
Ne pas utiliser les informations de l'extension Rock-Ridge
--no-xa
Ne pas utiliser les informations de l'extension XA
-r --show-rock-ridge UINT Affiche si l'image utilise les extensions Rock-Ridge
Un maximum de UINT fichiers sera considéré. Utilisez 0 pour tous les fichiers.
-q, --quiet
Ne pas produire de sortie d'avertissement
-V, --version
affiche les informations de version et de copyright, puis quitte

Options d'aide :

-?, --help
Affiche ce message d'aide
--usage
Affiche un bref message d'utilisation
