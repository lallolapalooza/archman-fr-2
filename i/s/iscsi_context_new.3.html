iscsi_context_new(3) Manuel API iscsi_context_new(3)

NOM

iscsi_context_new - Créer une structure iscsi_context.

SYNTAXE

struct iscsi_context * iscsi_context_new (void);

ARGUMENTS

void
aucun argument

DESCRIPTION

Le niveau de journalisation par défaut (LIBISCSI_LOG_PRIORITY_DEFAULT) est LIBISCSI_LOG_PRIORITY_WARNING, ce qui signifie que seuls les messages d'avertissement et d'erreur seront transmis à la fonction de gestionnaire de journalisation. La fonction de gestionnaire de journalisation par défaut imprime le message de journalisation sur STDERR. Pour modifier cela, veuillez utiliser iscsi_context_log_func_set pour définir votre propre gestionnaire de journalisation. Consultez la page man libopeniscsiusr.h(3) pour plus de détails.

RETOUR

Pointeur vers 'struct iscsi_context'. Doit être libéré par iscsi_context_free.
