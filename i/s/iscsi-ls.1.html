ISCSI-LS(1) iscsi-ls : lister les cibles iSCSI ISCSI-LS(1)

NOM

iscsi-ls - Utilitaire pour lister les cibles et les LUN iSCSI

SYNOPSIS

iscsi-ls [ OPTIONS ] <PORTAIL_ISCSI>

iscsi-ls [-i --nom-initiateur=<IQN>] [-s --afficher-luns] [-d --debug] [-? --aide] [--usage]

DESCRIPTION

iscsi-ls est un utilitaire pour lister toutes les cibles et LUNs d'un portail iSCSI.

FORMAT URL PORTAIL ISCSI

Le format du portail iSCSI est 'iscsi://[<nom_utilisateur>[%<mot_de_passe>]@]<hote>[:<port>]'

Le nom d'utilisateur et le mot de passe ne sont requis que si la cible nécessite une authentification CHAP. Optionnellement, vous pouvez spécifier le nom d'utilisateur et le mot de passe via les variables d'environnement LIBISCSI_CHAP_USERNAME et LIBISCSI_CHAP_PASSWORD.

L'hôte peut être spécifié soit comme un nom d'hôte, une adresse IPv4 ou une adresse IPv6. Exemples :

	iscsi://192.0.2.1
	iscsi://[2001:DB8::1]:3261
	iscsi://ronnie%password@iscsi.example.com

Le port est le port TCP sur la cible auquel se connecter. Par défaut, c'est 3260.

OPTIONS

-i --nom-initiateur=<IQN>

Ceci spécifie le nom d'initiateur qu'iscsi-ls utilisera lors de la connexion à la cible.

Le nom par défaut est 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-ls', mais vous pouvez utiliser cet argument pour le remplacer. Ceci est principalement nécessaire dans les cas où la cible est configurée avec un contrôle d'accès n'autorisant les connexions de découverte qu'à partir de noms d'initiateurs connus.

-s --afficher-luns

En plus de lister toutes les cibles au portail spécifié, liste également toutes les LUNs et leurs types sur chaque cible découverte.

Afin d'afficher le type de LUN, iscsi-ls doit être capable d'établir une connexion normale aux cibles. Si la cible utilise un contrôle d'accès, vous devrez spécifier un nom d'initiateur autorisant les connexions normales à la cible.

-d --debug

Affiche les informations de débogage.

-? --aide

Affiche le texte d'aide de base.

--usage

Affiche le texte d'utilisation de base.
