NOM

iscsi_strerror - Convertir un code d'erreur en chaîne de caractères.

SYNTAXE

const char * iscsi_strerror (int rc);

ARGUMENTS

rc
int. Code de retour des fonctions de libiscsiur. Lorsque le code d'erreur fourni n'est pas un code d'erreur valide, retourne "Invalid argument".

DESCRIPTION

Convertit un code d'erreur (int) en chaîne de caractères (const char *):

* LIBISCSI_OK -- "OK"

* LIBISCSI_ERR_BUG -- "BUG de la bibliothèque libopeniscsiusr"

* LIBISCSI_ERR_SESS_NOT_FOUND - "Session iSCSI spécifiée non trouvée"

* LIBISCSI_ERR_ACCESS - "Permission refusée"

* LIBISCSI_ERR_NOMEM - "Hors mémoire"

* LIBISCSI_ERR_SYSFS_LOOKUP - "Impossible de rechercher l'objet dans sysfs"

* Autre numéro d'erreur invalide -- "Invalid argument"

RETOUR

const char *. La signification du code d'erreur fourni. Ne libérez pas le pointeur retourné.
