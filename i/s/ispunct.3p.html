ISPUNCT(3P) Manuel du programmeur POSIX ISPUNCT(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

ispunct, ispunct_l — tester un caractère de ponctuation

SYNTAXE

#include <ctype.h>
int ispunct(int c);
int ispunct_l(int c, locale_t locale);

DESCRIPTION

Pour ispunct() : Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions ispunct() et ispunct_l() vérifient si c est un caractère de la classe punct dans la locale courante, ou dans la locale représentée par locale, respectivement ; voir le volume des Définitions de base de POSIX.1‐2017, Chapitre 7, Locale.

L'argument c est un int, dont la valeur doit être un caractère représentable sous forme de unsigned char ou égal à la valeur de la macro EOF. Si l'argument a toute autre valeur, le comportement est indéfini.

Le comportement est indéfini si l'argument locale à ispunct_l() est l'objet de locale spécial LC_GLOBAL_LOCALE ou n'est pas un handle d'objet de locale valide.

VALEUR DE RETOUR

Les fonctions ispunct() et ispunct_l() retournent une valeur non nulle si c est un caractère de ponctuation ; sinon, elles retournent 0.

ERREURS

Aucune erreur n'est définie.
