DESCRIPTIO

N

isql et iusql sont des outils en ligne de commande permettant aux utilisateurs d'exécuter du SQL de manière interactive ou par

lots.

Les outils fournissent plusieurs fonctionnalités utiles, notamment une option pour générer une sortie enveloppée dans un tableau

HTML.

iusql est identique à isql mais inclut une prise en charge intégrée d'Unicode. Certaines sources de données ne fonctionnent qu'avec iusql. Une différence importante entre les deux outils est que isql se connecte en utilisant SQLConnect et iusql se connecte en utilisant SQLDriverConnec

t
.

ARGUMENT

S
DS
N
Le nom de la source de données (DSN) utilisé pour se connecter à la base de données SQL. unixODBC recherche le DSN spécifié dans /etc/odbc.ini et $HOME/.odbc.ini, ce dernier étant prioritaire.

Lors de la recherche dans les fichiers de configuration, unixODBC recherche un nom simple. Si

le DSN commence par un point-virgule, il est traité comme une chaîne de connexion. La chaîne
de connexion peut contenir un DSN et/ou d'autres paramètres séparés par des points-virgules.
US
ER
Spécifie l'utilisateur ou le rôle de base de données sous lequel la connexion doit être établie.

Ce paramètre remplace tout UID spécifié dans les fichiers de configuration de la source

de
données.
PASSWO
RD
Mot de passe requis pour accéder à la base de données pour l' USER spécifié.

Ce paramètre remplace tout PASSWORD spécifié dans les fichiers de configuration de la source de

données.

Lors de l'utilisation de iusql, les mots de passe contenant des points-virgules doivent être échappés par des accolades (accolades courbes) et terminés par un point-virgule. Voir la section Exemples ci-dessous pour

la
syntaxe.
"ConnectionStri
ng"
Une chaîne de connexion commençant par DSN=, DRIVER= ou FILEDSN= sera transmise inchangée à SQLDriverConnect. Cette option permet l'utilisation d'une syntaxe plus complexe dans une chaîne de connexion que ce qui serait possible en utilisant uniquement DSN, UID et PWD.

Elle permet également (et c'était la raiso

n principale de son inclusion) aux
mots de passe de contenir des points-virgu
les sans avoir à ajouter de syntaxe
d'échappement complexe au code existant.

EXEMPLE

S
Un DSN simple
: 
$ iusql WebDB MyID MyPWD -w -b < My.
sql

Se connecte au DSN WebDB en tant qu'utilisateur MyID avec le mot de passe MyPWD, puis exécute les commandes du fichier My.sql et retourne les résultats enveloppés dans un tableau

HTML.

Chaque ligne dans My.sql ne doit contenir qu'une seule commande SQL, sauf la dernière ligne, qui doit être vide (sauf si l' option -n est

spécifiée)
.
Un DSN dans une chaîne de connexion
:

Notez le point-virgule initial de la chaîne de

connexion. 
$ iusql ";DSN=WebDB" MyID MyPWD -w -b <
My.sql

Les options dans le DSN peuvent être remplacées dans la chaîne de

connexion : 
$ iusql ";DSN=WebDB;Driver=PostgreSQL ODBC;UID=MyID;PASSWORD=secret;Debug=1;
CommLog=1"
-v

fichier DSN :

DÉPANNAG

E
Messages d'erreur
cryptiques

Relancez isql ou iusql avec l' drapeau -v pour obtenir plus d'informations sur les erreurs, et/ou activez le mode de trace dans odbcin

st.i
ni.
Définition de pilote
manquante

Vérifiez que le nom de pilote spécifié par l' entrée Driver dans la définition de source de données odbc.ini est présent dans odbcinst.ini et correspond exactement au nom de section [section nam

e] de odb
cinst.ini.
Pilote non chargeable ou
incompatible

Si le pilote ODBC est correctement spécifié pour la source de données, il est possible que le pilote ne soit pas chargeable. Vérifiez qu'il n'y a pas de confusion entre les pilotes Unicode et ANSI, et vérifiez les chemins des pilotes dans le [nom de section] de

odbcinst.
ini.
Sources de données Unicode avec clients
ANSI

Certaines sources de données sont uniquement Unicode et nécessitent l'utilisation de iusql. Si isql aff

iche 
  [IM002][unixODBC][Driver Manager]Data source name not found and no default driver specified
  [ISQL]ERROR: Could not SQLConnect
mais que la source de données et le pilote requis sont listés par 
  odbcinst -q
-d et 
  odbcinst -q -s
alors try iusql.

FICHIERS

/etc/odbc.ini

Fichier de configuration contenant les définitions de noms de sources de données (DSN) au niveau du système. Voir odbc.ini(5) pour plus d'informations.

$HOME/.odbc.ini

Fichier de configuration contenant les définitions de noms de sources de données (DSN) spécifiques à l'utilisateur. Voir odbc.ini(5) pour plus d'informations.
