ISOINFO(8) Manuel de l'administrateur système ISOINFO(8)

NOM

devdump, isoinfo, isovfy, isodump - Utilitaires pour extraire et vérifier des images iso9660.

SYNTAXE

devdump isoimage

isodump isoimage

isoinfo [ options ] [ find [ expression find ]]

isovfy isoimage

DESCRIPTION

devdump est un utilitaire rudimentaire pour afficher interactivement le contenu d'images de périphériques ou de systèmes de fichiers. L'écran initial affiche les 256 premiers octets du premier secteur de 2048 octets. Les commandes sont les mêmes qu'avec isodump.

isodump est un utilitaire rudimentaire pour afficher interactivement le contenu d'images iso9660 afin de vérifier l'intégrité des répertoires. L'écran initial affiche la première partie du répertoire racine, et l'invite indique le numéro d'étendue et le décalage dans l'étendue.

Vous pouvez utiliser les commandes 'a' et 'b' pour vous déplacer en arrière et en avant dans l'image. La commande 'g' permet d'aller à une étendue arbitraire, et la commande 'f' spécifie une chaîne de recherche à utiliser. La commande '+' recherche en avant la prochaine instance de la chaîne de recherche, et la commande 'q' quitte devdump ou isodump.

isoinfo est un utilitaire pour effectuer des listages de type répertoire d'images iso9660.

isovfy est un utilitaire pour vérifier l'intégrité d'une image iso9660. La plupart des tests dans isovfy ont été ajoutés après la découverte de bugs dans les premières versions de mkisofs. Il n'est pas très clair de l'utilité de cet outil aujourd'hui, mais cela ne fait pas de mal de l'avoir sous la main.

OPTIONS

Les options communes à tous les programmes sont -help,-h,-version, i=nom,dev=nom. Le programme isoinfo a des options de ligne de commande supplémentaires. Les options sont :

-help
-h
affiche un résumé de toutes les options.
-d
Affiche les informations du descripteur de volume primaire (PVD) de l'image iso9660. Cela inclut des informations sur les extensions Rock Ridge, Joliet et les informations de démarrage Eltorito si elles sont présentes.
-f
génère une sortie comme si une commande 'find . -print' avait été exécutée sur l'image iso9660. Vous ne devez pas utiliser l'image -l avec l'option -f. La même sortie est créée en appelant isoinfo avec -find -print.
-find expression find
Cette option agit comme un séparateur. Si elle est utilisée, toutes les options isoinfo doivent être à gauche de l'option -find. À droite de l'option -find, mkisofs accepte uniquement la syntaxe de commande find. Si l'expression find inclut une action primaire -print ou -ls, l'option -l de isoinfo est ignorée. Si l'expression find est évaluée comme vraie, l'action sélectionnée (par exemple, lister le répertoire ISO-9660) est effectuée.
-i iso_image
Spécifie le chemin de l'image iso9660 que nous souhaitons examiner. Les options -i et dev=cible sont mutuellement exclusives.
-ignore-error
Ignore les erreurs. Par défaut, les commandes s'arrêtent en cas de plusieurs erreurs, comme des erreurs de lecture. Avec cette option activée, les commandes essaient de continuer. À utiliser avec prudence.
dev=cible
Définit la cible SCSI pour le lecteur, voir les notes ci-dessus. Une spécification de périphérique typique est dev=6,0 . Si un nom de fichier doit être fourni avec la spécification numérique de la cible, le nom de fichier dépend de l'implémentation. Le nom de fichier correct dans ce cas peut être trouvé dans les manuels spécifiques au système d'exploitation cible. Sur un système FreeBSD sans prise en charge CAM, vous devez utiliser le périphérique de contrôle (par exemple, /dev/rcd0.ctl). Une spécification de périphérique correcte dans ce cas peut être dev=/dev/rcd0.ctl:@ .

Sous Linux, les lecteurs connectés à un adaptateur de port parallèle sont mappés sur un bus SCSI virtuel. Différents adaptateurs sont mappés sur différentes cibles de ce bus SCSI virtuel.

Si aucune option dev n'est présente, le programme essaiera d'obtenir le périphérique depuis la variable d'environnement CDR_DEVICE.

Si l'argument de l'option dev= ne contient pas les caractères ',', '/', '@' ou ':', il est interprété comme un nom d'étiquette qui peut être trouvé dans le fichier /etc/default/cdrecord (voir la section FICHIERS).

Les options -i et dev=cible sont mutuellement exclusives.

-debug
Affiche des informations de débogage supplémentaires. Cela permet par exemple d'afficher toutes les entrées de répertoire si un fichier a plus d'une entrée de répertoire et d'afficher plus d'informations du descripteur de volume primaire.

En mode débogage, les informations Rock Ridge sont analysées avec -R même si elles ne sont pas conformes aux normes.

-l
génère une sortie comme si une commande 'ls -lR' avait été exécutée sur l'image iso9660. Vous ne devez pas utiliser l'image -f avec l'option -l.

Les nombres entre crochets sont le numéro du secteur de départ en nombre décimal (basé sur 2048 octets par secteur) et les drapeaux du répertoire iso9660 en nombre hexadécimal comme suit :

0x00
Un fichier ordinaire (pas vraiment un drapeau).
0x01
Cacher le nom du fichier des listages de répertoire.
0x02
Un répertoire.
0x04
Un fichier associé (par exemple, une ressource fork Apple).
0x08
Le format d'enregistrement dans les attributs étendus est utilisé.
0x10
Aucune permission de lecture/exécution dans les attributs étendus.
0x20
réservé
0x40
réservé
0x80
Pas la dernière entrée d'un fichier multi-étendue.
-N secteur
Hack rapide pour aider à examiner des fichiers de session unique à écrire sur un disque multi-session. Le numéro de secteur spécifié est le numéro de secteur auquel l'image iso9660 doit être écrite lors de l'envoi au graveur de CD. Non utilisé pour la première session sur le disque.
-p
Affiche les informations de la table de chemin.
-R
Extrait les informations des extensions Rock Ridge (si présentes) pour les permissions, les noms de fichiers et les propriétaires.
-s
Affiche les informations de taille de fichier en multiples de la taille de secteur (2048 octets).
-J
Extrait les informations des extensions Joliet (si présentes) pour les noms de fichiers.
-j jeu_caractères
Convertit les noms de fichiers Joliet (si présents) vers le jeu de caractères fourni. Voir mkisofs(8) pour plus de détails.
-T secteur
Hack rapide pour aider à examiner des images multi-session déjà gravées sur un disque multi-session. Le numéro de secteur spécifié est le numéro de secteur pour le début de la session que nous souhaitons afficher.
-X
Extrait les fichiers de l'image et les place dans le système de fichiers. Si l'option -find n'est pas utilisée, tous les fichiers sont extraits.

Le programme isoinfo prend en charge l'extraction de tous les fichiers, même les fichiers multi-étendues (fichiers > 4 Go).

Avant d'extraire des fichiers en utilisant l'option -X, il est recommandé de changer de répertoire courant vers un répertoire vide afin d'éviter d'écraser des fichiers existants.

-x chemin
Extrait le fichier spécifié vers la sortie standard. Le chemin doit commencer par un slash ('/') et, dans le cas des noms iso9660, doit correspondre au chemin complet du fichier, y compris le numéro de version (généralement ';1'). Si l'option -R a été spécifiée et que le système de fichiers porte les attributs Rock Ridge, le chemin doit correspondre au chemin complet Rock Ridge du fichier.
