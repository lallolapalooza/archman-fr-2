NOM

isdnlog2dlf - convertir les journaux ISDN au format DLF

SYNOPSIS

isdnlog2dlf

DESCRIPTION

Ce script lit un fichier journal du noyau Linux ISDN, tel que produit par les modules du noyau Linux isdn4linux, et écrit par isdnlog(8) des utilitaires isdn4k-utils. Le script a été testé avec le paquet Debian isdnlog, version 4.57, tel qu'il est livré avec Debian GNU/Linux 3.0.

EXEMPLES

Pour traiter un journal tel que produit par isdnlog :

$ isdnlog2dlf < isdn-log

isdnlog2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report isdnlog < /var/log/isdn-log
