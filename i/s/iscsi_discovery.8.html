NOM

iscsi_discovery - découvrir les cibles iSCSI

SYNTAXE

iscsi_discovery <IP> [-p <port>] [-d] [ -t <tcp|iser> [-f] ] [-m] [-l]

DESCRIPTION

Effectuer une découverte send-targets vers l'IP spécifiée. Si un enregistrement de découverte est généré, essayer de se connecter au portail en utilisant le transport préféré (-t spécifie le type de transport demandé, TCP est le défaut). Si la connexion avec un certain transport réussit, marquer le portail pour une connexion automatique (sauf si l'indicateur -m est utilisé), et se déconnecter (sauf si l'indicateur -l est utilisé).

Pour que la découverte iSCSI fonctionne, les services open-iscsi doivent être en cours d'exécution. c'est-à-dire que iscsid doit être démarré et les modules iSCSI chargés. Ceci est mieux réalisé par le script de démarrage init.d.

[-p=]numéro-de-port
définir le numéro de port (par défaut 3260).
[-d]
afficher les informations de débogage.
[-t=]type-de-transport
définir le transport (par défaut tcp).
[-f]
forcer le transport spécifique - désactiver le repli vers tcp (par défaut le repli est activé). forcer le transport spécifié par l'argument de l'indicateur -t.
[-m]
démarrage manuel - définira le démarrage manuel (par défaut démarrage automatique).
[-l]
connexion - se connecter aux nouveaux nœuds découverts (par défaut false).
