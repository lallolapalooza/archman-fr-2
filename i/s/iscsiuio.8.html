NOM

iscsiuio - Pilote d'E/S en espace utilisateur iSCSI

SYNTAXE

iscsiuio [-d-f-v]

DESCRIPTION

iscsiuio est le pilote d'E/S en espace utilisateur pour les cartes réseau (NIC) Gigabit Ethernet QLogic NetXtreme II BCM5706/5708/5709 PCI/PCI-X et pour les cartes réseau Gigabit Ethernet QLogic NetXtreme II BCM57710/57711/57712/57800/57810/57840 PCI-E 10 Gigabit. Le pilote a été testé sur des noyaux 2.6.28 et supérieurs.

Consultez le fichier README.TXT du paquet de pilotes pour savoir comment compiler et installer le pilote.

Consultez diverses documentations Linux sur la manière de configurer le protocole réseau et l'adresse.

DÉPENDANCES DU PILOTE

PARAMÈTRES

Il y a très peu de paramètres lors de l'exécution de cette application.

-d|--debug<niveaude débogage>
Ceci permet d'activer le mode de débogage où les messages de débogage seront envoyés sur la sortie standard. Les modes de débogage suivants sont pris en charge.
DEBUG 4 - Afficher tous les messages

INFO 3 - Afficher les messages nécessaires pour suivre le code uIP (par défaut)

WARN 2 - Afficher les messages d'avertissement

ERROR 1 - N'afficher que les erreurs critiques

-f|--foreground
Ceci permet d'activer le mode de premier plan afin que cette application ne soit pas exécutée en arrière-plan.
-v|--version
Ceci permet d'afficher la version.
-p|--pid<pidfile>
Utiliser un fichier PID (par défaut /run/iscsiuio.pid)
-h|--help
Afficher cette aide et quitter.
