NOM

iscsi_session_password_in_get - Récupérer le mot de passe d'authentification de la session spécifiée.

SYNTAXE

const char * iscsi_session_password_in_get (struct iscsi_session *se);

ARGUMENTS

se
Pointeur vers 'struct iscsi_session'. Si ce pointeur est NULL, votre programme sera terminé par assert.

DESCRIPTION

Récupère le mot de passe d'authentification entrant de la session iSCSI spécifiée. Actuellement, open-iscsi ne prend en charge que la méthode d'authentification CHAP. L'authentification entrante ici signifie que l'initiateur iSCSI authentifie la cible iSCSI en utilisant CHAP. Ce paramètre est contrôlé dans iscsid.conf :

RETOUR

const char *. Chaîne vide si l'authentification CHAP entrante n'est pas utilisée ou si la lecture des informations d'authentification a échoué. Il n'est pas nécessaire de libérer cette mémoire, les ressources seront libérées par iscsi_session_free ou iscsi_sessions_free.
