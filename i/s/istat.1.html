ISTAT(1) Manuel des commandes générales ISTAT(1)

NOM

istat - Affiche les détails d'une structure de métadonnées (c'est-à-dire un inode)

SYNTAXE

istat [-B num ] [-f fstype ] [-i imgtype ] [-o imgoffset ] [-b dev_sector_size ] [-vV] [-z zone ] [-s seconds ] image [images] inode

DESCRIPTION

istat affiche l'identifiant utilisateur (uid), l'identifiant de groupe (gid), le mode, la taille, le nombre de liens, les dates de modification, d'accès et de changement, ainsi que toutes les unités de disque allouées à une structure.

Les options sont les suivantes :

-B num
Affiche les adresses de num unités de disque. Utile lorsque l'inode n'est pas alloué avec une taille de 0, mais qu'il a toujours des pointeurs de bloc.
-f fstype
Spécifie le type de système de fichiers. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-s secondes
Le décalage horaire du système d'origine en secondes. Par exemple, si le système d'origine était en retard de 100 secondes, cette valeur serait de -100.
-i imgtype
Identifie le type de fichier image, tel que 'raw'. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o imgoffset
Le décalage de secteur où le système de fichiers commence dans l'image.
-b dev_sector_size
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-v
Sortie verbeuse des déclarations de débogage vers stderr.
-V
Affiche la version.
-z zone
Une chaîne ASCII du fuseau horaire du système d'origine. Par exemple, EST5EDT ou GMT. Ces chaînes sont définies par le système d'exploitation et peuvent varier. NOTE : Ceci a changé depuis TCTUTILs.
image [images]
L'image du disque ou de la partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, se terminant par '.001'), les segments d'image suivants seront inclus automatiquement.
inode
Numéro de métadonnées dont afficher les statistiques.
