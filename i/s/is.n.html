is(n) [incr Tcl] is(n)

NOM

itcl::is - teste un argument pour voir s'il s'agit d'une classe ou d'un objet

SYNTAXE

itcl::is option ?arg arg ...?

DESCRIPTION

La commande is est utilisée pour vérifier si l'argument donné est une classe ou un objet ; selon l'option donnée. Si l'argument est une classe ou un objet, alors 1 est retourné. Sinon, 0 est retourné. La commande is reconnaît également les commandes encapsulées dans la commande code d'itcl.

L'argument option détermine quelle action est effectuée par la commande. Les options légales (qui peuvent être abrégées) sont :

is class commande
Retourne 1 si la commande est une classe, et retourne 0 sinon.

Le nom qualifié complet de la classe doit être donné comme argument commande. Ainsi, si une classe réside dans un espace de noms, alors l'espace de noms doit être spécifié également. Donc, si une classe C réside dans un espace de noms N, alors la commande doit être appelée comme suit :

is N::C
    ou
is ::N::C
is object ?-classe nomClasse? commande
Retourne 1 si commande est un objet, et retourne 0 sinon.

Si le paramètre optionnel "-classe" est spécifié, alors la commande sera vérifiée dans le contexte de la classe donnée. Notez que nomClasse doit exister. Sinon, une erreur sera signalée. Ainsi, si nomClasse n'est pas certaine d'être une classe, alors le programmeur devra vérifier son existence au préalable, ou l'encapsuler dans une instruction catch.

Donc, si c est un objet de la classe C, dans l'espace de noms N, alors voici les possibilités (toutes retournent 1) :

set obj [N::C c]
itcl::is object N::c
itcl::is object c
itcl::is object $obj
itcl::is object [itcl::code c]
