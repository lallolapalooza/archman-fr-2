ISPRINT(3P) Manuel du programmeur POSIX ISPRINT(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

isprint, isprint_l — tester un caractère imprimable

SYNTAXE

#include <ctype.h>
int isprint(int c);
int isprint_l(int c, locale_t locale);

DESCRIPTION

Pour isprint() : La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions isprint() et isprint_l() testent si c est un caractère de la classe print dans la locale actuelle, ou dans la locale représentée par locale, respectivement ; voir le volume des Définitions de base de POSIX.1‐2017, Chapitre 7, Locale.

L'argument c est un int, dont la valeur doit être un caractère représentable comme un unsigned char ou égal à la valeur de la macro EOF. Si l'argument a une autre valeur, le comportement est indéfini.

Le comportement est indéfini si l'argument locale de isprint_l() est l'objet de locale spécial LC_GLOBAL_LOCALE ou n'est pas une poignée d'objet de locale valide.

VALEUR DE RETOUR

Les fonctions isprint() et isprint_l() retournent une valeur non nulle si c est un caractère imprimable ; sinon, elles retournent 0.

ERREURS

Aucune erreur n'est définie.
