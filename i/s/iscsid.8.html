NOM

iscsid - Démon Open-iSCSI

SYNTAXE

iscsid [OPTION]

DESCRIPTION

Le programme iscsid implémente le chemin de contrôle du protocole iSCSI, ainsi que certaines facilités de gestion. Par exemple, le démon peut être configuré pour redémarrer automatiquement la découverte au démarrage, en se basant sur le contenu de la base de données iSCSI persistante.

OPTIONS

[-c|--config=]fichier-config
Lire la configuration à partir de fichier-config plutôt que du fichier par défaut /etc/iscsi/iscsid.conf.
[-i|--initiatorname=]fichier-nom-initiateur
Lire le nom de l'initiateur à partir de fichier-nom-initiateur plutôt que du fichier par défaut /etc/iscsi/initiatorname.iscsi.
[-f|--foreground]
exécuter iscsid au premier plan. Implique --no-pid-file.
[-d|--debug=]niveau-debug
afficher des informations de débogage. Les valeurs valides pour niveau-debug sont de 0 à 8.
[-u|--uid=]uid
exécuter sous l'ID utilisateur uid (par défaut, l'ID utilisateur actuel).
[-g|--gid=]gid
exécuter sous l'ID groupe utilisateur gid (par défaut, l'ID groupe utilisateur actuel).
[-n|--no-pid-file]
ne pas écrire de fichier PID. Entre en conflit avec l'option --pid=.
[-p|--pid=]fichier-pid
écrire le PID dans fichier-pid plutôt que dans le fichier par défaut /run/iscsid.pid. Entre en conflit avec l'option --no-pid-file.
[-h|--help]
afficher cette aide et quitter
[-v|--version]
afficher la version et quitter.

FICHIERS

/etc/iscsi/iscsid.conf
Le fichier de configuration lu par iscsid et iscsiadm au démarrage.
/etc/iscsi/initiatorname.iscsi
Le fichier contenant le nom de l'initiateur iSCSI et l'alias de l'initiateur lus par iscsid et iscsiadm au démarrage.
/var/lib/iscsi/nodes
Base de données de configuration persistante Open-iSCSI
