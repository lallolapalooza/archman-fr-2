ISCSI-INQ(1) iscsi-inq : Effectuer une requête INQUIRY sur ISCSI-INQ(1)

NOM

iscsi-inq - Utilitaire pour demander des données INQUIRY d'un LUN iSCSI

SYNTAXE

iscsi-inq [ OPTIONS ] <URL_ISCSI>

iscsi-inq [-i --nom-initiateur=<IQN>] [-e --evpd=<ENTIER>] [-c --code-page=<ENTIER>] [-d --debug=<ENTIER>] [-? --aide] [--utilisation] [<URL_ISCSI>]

DESCRIPTION

iscsi-inq est un utilitaire pour demander des données INQUIRY d'un LUN iSCSI.

FORMAT URL ISCSI

Le format de l'URL iSCSI est 'iscsi://[<nom-utilisateur>[%<mot-de-passe>]@]<hote>[:<port>]/<nom-iqn-cible>/<lun>'

Le nom d'utilisateur et le mot de passe ne sont requis que si la cible exige une authentification CHAP. Vous pouvez éventuellement spécifier le nom d'utilisateur et le mot de passe via les variables d'environnement LIBISCSI_CHAP_USERNAME et LIBISCSI_CHAP_PASSWORD.

L'hôte peut être spécifié soit comme un nom d'hôte, une adresse IPv4 ou une adresse IPv6. Exemples :

	iscsi://192.0.2.1/iqn.ronnie.test/1
	iscsi://[2001:DB8::1]:3261/iqn.ronnie.test/1
	iscsi://ronnie%motdepasse@iscsi.example.com/iqn.ronnie.test/1

Le port est le port TCP sur la cible auquel se connecter. Par défaut, il s'agit du port 3260.

Le nom-iqn-cible est le nom iqn de la cible. Un portail iSCSI peut avoir plusieurs cibles définies. Utilisez iscsi-ls pour lister toutes les cibles disponibles sur un portail spécifique.

LUN est le numéro de LUN pour lequel les données INQUIRY doivent être rapportées.

OPTIONS

-i --nom-initiateur=<IQN>

Ceci spécifie le nom d'initiateur que iscsi-inq utilisera lors de la connexion à la cible.

Le nom par défaut est 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-inq' mais vous pouvez utiliser cet argument pour le remplacer. Ceci est principalement nécessaire dans les cas où la cible est configurée avec un contrôle d'accès pour autoriser uniquement les connexions de découverte à partir de noms d'initiateur connus.

-e --evpd=<ENTIER>

Par défaut, iscsi-inq affiche les données d'interrogation standard. Spécifiez evpd à 1 pour afficher les pages VPD étendues.

-c --code-page=<ENTIER>

Cet argument spécifie quelle page VPD afficher lorsque evpd est demandé. Par défaut, il s'agit de 0x00, qui représente les pages VPD SUPPORTED.

Cet argument ne peut être utilisé que lorsque evpd est défini sur 1.

-d --debug=<ENTIER>

Niveau de débogage.

-? --aide

Afficher un texte d'aide de base.

--utilisation

Afficher un texte d'utilisation de base.

EXEMPLES

Pour afficher la page INQUIRY standard :

	iscsi-inq iscsi://192.0.2.1/iqn.ronnie.test/1

Pour lister les pages disponibles :

	iscsi-inq -e 1 iscsi://192.0.2.1/iqn.ronnie.test/1

Pour afficher une page spécifique :

	iscsi-inq -e 1 -c 0x80 iscsi://192.0.2.1/iqn.ronnie.test/1
