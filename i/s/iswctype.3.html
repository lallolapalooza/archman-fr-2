iswctype(3) Manuel des fonctions de bibliothèque iswctype(3)

NOM

iswctype — classification de caractères larges

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <wctype.h>
int iswctype(wint_t wc, wctype_t desc);

DESCRIPTION

Si wc est un caractère large possédant la propriété de caractère désignée par desc (ou en d'autres termes : appartient à la classe de caractères désignée par desc), alors la fonction iswctype() retourne une valeur non nulle. Sinon, elle retourne zéro. Si wc est WEOF, zéro est retourné.

desc doit être un descripteur de propriété de caractère renvoyé par la fonction wctype(3).

VALEUR DE RETOUR

La fonction iswctype() retourne une valeur non nulle si wc possède la propriété désignée. Sinon, elle retourne 0.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
iswctype () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de iswctype() dépend de la catégorie LC_CTYPE de la locale courante.
