NOM

iscsi_context_log_func_set - Définir la fonction de gestionnaire de journalisation.

SYNOPSIS

void iscsi_context_log_func_set (struct iscsi_context *ctx, void (*log_func) (struct iscsi_context *ctx, int priority, const char *file, int line, const char *func_name, const char *format, va_list args));

ARGUMENTS

ctx
Pointeur vers la structure 'iscsi_context'. Si ce pointeur est NULL, votre programme sera terminé par assert.
log_func
Pointeur vers la fonction de gestionnaire de journalisation.

DESCRIPTION

Définit un gestionnaire de journalisation personnalisé. Le gestionnaire de journalisation sera appelé lorsque le message de journal est égal ou plus important (valeur inférieure) que le réglage de priorité du journal. Veuillez consulter la page de manuel libopeniscsiusr.h(3) pour plus de détails sur l'utilisation.

RETOUR

void
