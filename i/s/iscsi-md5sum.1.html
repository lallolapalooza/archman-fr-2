ISCSI-MD5SUM(1) iscsi-md5sum : calculer MD5 ISCSI-MD5SUM(1)

NOM

iscsi-md5sum - Utilitaire pour calculer la valeur MD5 d'un LUN iSCSI dans la plage [LBAm, LBAn)

SYNTAXE

iscsi-md5sum [ OPTIONS ] <PORTAIL_ISCSI>

iscsi-md5sum [-i --nom-initiateur=<IQN>] [-o --decalage] [-l --longueur] [-d --debug] [-? --aide] [--utilisation]

DESCRIPTION

iscsi-md5sum est un utilitaire pour calculer la valeur MD5 d'un LUN iSCSI dans la plage [LBAm, LBAn).

FORMAT URL DU PORTAIL ISCSI

Le format du portail iSCSI est 'iscsi://[<nom_utilisateur>[%<mot_de_passe>]@]<hôte>[:<port>]'

Le nom d'utilisateur et le mot de passe ne sont requis que si la cible nécessite une authentification CHAP. Vous pouvez éventuellement spécifier le nom d'utilisateur et le mot de passe via les variables d'environnement LIBISCSI_CHAP_USERNAME et LIBISCSI_CHAP_PASSWORD.

L'hôte peut être spécifié soit comme un nom d'hôte, une adresse IPv4 ou une adresse IPv6. Exemples :

	iscsi://192.0.2.1
	iscsi://[2001:DB8::1]:3261
	iscsi://ronnie%password@iscsi.example.com

Le port est le port TCP de la cible auquel se connecter. Le port par défaut est 3260.

OPTIONS

-i --nom-initiateur=<IQN>

Ceci spécifie le nom de l'initiateur que iscsi-md5sum utilisera lors de la connexion à la cible.

Le nom par défaut est 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-md5sum', mais vous pouvez utiliser cet argument pour le remplacer. Ceci est principalement nécessaire dans les cas où la cible est configurée avec un contrôle d'accès n'autorisant les connexions de découverte qu'à partir de noms d'initiateur connus.

-o --decalage

Décalage en octets dans la cible à partir duquel commencer le calcul. La valeur fournie doit être alignée sur la taille du secteur de la cible. La valeur par défaut est zéro.

-l --longueur

Le nombre d'octets à calculer (en comptant à partir du point de départ). La valeur fournie doit être alignée sur la taille du secteur de la cible. Si la valeur spécifiée dépasse la fin du périphérique, iscsi-md5sum s'arrêtera à la limite de taille du périphérique. La valeur par défaut s'étend jusqu'à la fin du périphérique.

-d --debug

Afficher les informations de débogage.

-? --aide

Afficher le texte d'aide de base.

--utilisation

Afficher le texte d'utilisation de base.
