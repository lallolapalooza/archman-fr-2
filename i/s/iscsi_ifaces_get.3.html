NOM

iscsi_ifaces_get - Récupère toutes les interfaces iSCSI.

SYNTAXE

int iscsi_ifaces_get (struct iscsi_context *ctx, struct iscsi_iface ***ifaces, uint32_t *iface_count);

ARGUMENTS

ctx
Pointeur de 'struct iscsi_context'. Si ce pointeur est NULL, votre programme sera terminé par un assert.
ifaces
Pointeur de sortie d'un tableau de pointeurs 'struct iscsi_iface'. Sa mémoire doit être libérée par iscsi_ifaces_free. Si ce pointeur est NULL, votre programme sera terminé par un assert.
iface_count
Pointeur de sortie de uint32_t. Stockera la taille de

DESCRIPTION

Récupère toutes les interfaces iSCSI. Pour les propriétés de 'struct iscsi_iface', veuillez vous référer aux fonctions définies dans le fichier 'libopeniscsiusr_iface.h'. Les résultats retournés contiennent les interfaces iSCSI par défaut (iser et iscsi_tcp) et les interfaces iSCSI configurées dans "/etc/iscsi/ifaces/". Les fichiers de configuration illégaux seront ignorés et un avertissement sera émis. Pour générer la configuration de l'interface iSCSI lors de l'installation d'une nouvelle carte, utilisez iscsi_default_iface_setup.

RETOUR

int. Les codes d'erreur valides sont :

* LIBISCSI_OK

* LIBISCSI_ERR_BUG

* LIBISCSI_ERR_NOMEM

* LIBISCSI_ERR_ACCESS

* LIBISCSI_ERR_SYSFS_LOOKUP

Le numéro d'erreur peut être converti en chaîne de caractères par iscsi_strerror.
