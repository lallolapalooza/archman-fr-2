ISWPRINT(3P) Manuel du programmeur POSIX ISWPRINT(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

iswprint, iswprint_l — tester un code de caractère large imprimable

SYNOPIS

#include <wctype.h>
int iswprint(wint_t wc);
int iswprint_l(wint_t wc, locale_t locale);

DESCRIPTION

Pour iswprint() : La fonctionnalité décrite sur cette page de référence est conforme à la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions iswprint() et iswprint_l() vérifient si wc est un code de caractère large représentant un caractère de la classe print dans la locale courante, ou dans la locale représentée par locale, respectivement ; voir le volume des Définitions de base de POSIX.1‐2017, Chapitre 7, Locale.

L'argument wc est un wint_t, dont la valeur doit être un code de caractère large correspondant à un caractère valide dans la locale utilisée par la fonction, ou égal à la valeur de la macro WEOF. Si l'argument a toute autre valeur, le comportement est indéfini.

Le comportement est indéfini si l'argument locale de iswprint_l() est l'objet de locale spécial LC_GLOBAL_LOCALE ou s'il ne s'agit pas d'un descripteur d'objet de locale valide.

VALEUR RENVOYÉE

Les fonctions iswprint() et iswprint_l() renvoient une valeur non nulle si wc est un code de caractère large imprimable ; sinon, elles renvoient 0.

ERREURS

Aucune erreur n'est définie.
