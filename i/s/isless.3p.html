PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

isless — tester si x est inférieur à y

SYNOPSIS

#include <math.h>
int isless(real-floating x, real-floating y);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La macro isless() doit déterminer si son premier argument est inférieur à son second argument. La valeur de isless(x, y) doit être égale à (x) < (y) ; cependant, contrairement à (x) < (y), isless(x, y) ne doit pas déclencher l'exception de flottant invalide lorsque x et y sont non ordonnés.

VALEUR DE RETOUR

En cas de succès, la macro isless() doit retourner la valeur de (x) < (y).

Si x ou y est NaN, 0 doit être retourné.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR LES APPLICATIONS

Les opérateurs relationnels et d'égalité supportent les relations mathématiques habituelles entre valeurs numériques. Pour toute paire ordonnée de valeurs numériques, exactement une des relations (inférieur, supérieur, égal) est vraie. Les opérateurs relationnels peuvent déclencher l'exception de flottant invalide lorsque les valeurs des arguments sont des NaN. Pour un NaN et une valeur numérique, ou pour deux NaN, seule la relation non ordonnée est vraie. Cette macro est une version silencieuse (sans déclenchement d'exception de flottant) d'un opérateur relationnel. Elle facilite l'écriture de code efficace qui tient compte des NaN sans subir l'exception de flottant invalide. Dans la section SYNOPSIS, real-floating indique que l'argument doit être une expression de type real-floating.
