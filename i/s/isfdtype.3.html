isfdtype(3) Manuel des fonctions de bibliothèque isfdtype(3)

NOM

isfdtype - tester le type de fichier d'un descripteur de fichier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/stat.h>
#include <sys/socket.h>
int isfdtype(int fd, int fdtype);
Exigences pour les macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

isfdtype() :

    Depuis glibc 2.20 :
        _DEFAULT_SOURCE
    Avant glibc 2.20 :
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction isfdtype() teste si le descripteur de fichier fd fait référence à un fichier du type fdtype. L'argument fdtype spécifie l'une des constantes S_IF* définies dans <sys/stat.h> et documentées dans stat(2) (par exemple, S_IFREG).

VALEUR DE RETOUR

La fonction isfdtype() renvoie 1 si le descripteur de fichier fd est du type fdtype et 0 sinon. En cas d'échec, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

La fonction isfdtype() peut échouer avec les mêmes erreurs que fstat(2).

VERSIONS

Les applications portables devraient utiliser fstat(2) à la place.

NORMES

Aucune.

HISTORIQUE

Elle est apparue dans la version préliminaire de la norme POSIX.1g. Elle est présente sur OpenBSD et Tru64 UNIX (où le fichier d'en-tête requis dans les deux cas est juste <sys/stat.h>, comme montré dans la version préliminaire de POSIX.1g).

VOIR AUSSI

fstat(2)
