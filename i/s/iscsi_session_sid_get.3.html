iscsi_session_sid_get(3) Manuel de l'API iscsi_session_sid_get(3)

NOM

iscsi_session_sid_get - Récupère l'ID de session iSCSI de la session spécifiée.

SYNTAXE

uint32_t iscsi_session_sid_get (struct iscsi_session *se);

ARGUMENTS

se
Pointeur vers 'struct iscsi_session'. Si ce pointeur est NULL, votre programme sera terminé par assert.

DESCRIPTION

Récupère l'identifiant de session iSCSI. L'identifiant de session ici est l'entier utilisé dans '/sys/class/iscsi_session/session<session_id>/'

VALEUR

uint32_t.
