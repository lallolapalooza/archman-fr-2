isgreater(3) Manuel des fonctions de bibliothèque isgreater(3)

NOM

isgreater, isgreaterequal, isless, islessequal, islessgreater, isunordered - tests relationnels en virgule flottante sans exception pour NaN

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
int isgreater(x, y);
int isgreaterequal(x, y);
int isless(x, y);
int islessequal(x, y);
int islessgreater(x, y);
int isunordered(x, y);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):
    Toutes les fonctions décrites ici :
        _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Les opérations relationnelles normales (comme <, « inférieur à ») échouent si l'un des opérandes est NaN. Cela provoquera une exception. Pour éviter cela, C99 définit les macros listées ci-dessous.

Ces macros sont garanties d'évaluer leurs arguments une seule fois. Les arguments doivent être de type réel à virgule flottante (notez : ne pas passer de valeurs entières comme arguments à ces macros, car les arguments ne seront pas promus en types réels à virgule flottante).

isgreater()
détermine (x) > (y) sans exception si x ou y est NaN.
isgreaterequal()
détermine (x) >= (y) sans exception si x ou y est NaN.
isless()
détermine (x) < (y) sans exception si x ou y est NaN.
islessequal()
détermine (x) <= (y) sans exception si x ou y est NaN.
islessgreater()
détermine (x) < (y) || (x) > (y) sans exception si x ou y est NaN. Cette macro n'est pas équivalente à x != y car cette expression est vraie si x ou y est NaN.
isunordered()
détermine si ses arguments sont non ordonnés, c'est-à-dire si au moins l'un des arguments est un NaN.

VALEUR DE RETOUR

Les macros autres que isunordered() retournent le résultat de la comparaison relationnelle ; ces macros retournent 0 si l'un des arguments est un NaN.

isunordered() retourne 1 si x ou y est NaN et 0 sinon.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
isgreater (), isgreaterequal (), isless (), islessequal (), islessgreater (), isunordered () Sécurité des threads MT-Safe

VERSIONS

Tout le matériel ne prend pas en charge ces fonctions, et là où le support matériel n'est pas fourni, elles seront émulated par des macros. Cela entraînera une pénalité de performance. N'utilisez pas ces fonctions si NaN ne vous préoccupe pas.

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

VOIR AUSSI

fpclassify(3), isnan(3)
