ISWALPHA(3P) Manuel du programmeur POSIX ISWALPHA(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

iswalpha, iswalpha_l — tester un code de caractère large alphabétique

SYNOPSIS

#include <wctype.h>
int iswalpha(wint_t wc);
int iswalpha_l(wint_t wc, locale_t locale);

DESCRIPTION

Pour iswalpha() : La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions iswalpha() et iswalpha_l() testent si wc est un code de caractère large représentant un caractère de la classe alpha dans la catégorie de locale courante, ou dans la catégorie de locale représentée par locale, respectivement ; voir le volume Définitions de base de POSIX.1‐2017, Chapitre 7, Locale.

L'argument wc est un wint_t, dont la valeur doit être assurée par l'application comme étant un code de caractère large correspondant à un caractère valide dans la catégorie de locale utilisée par la fonction, ou égale à la valeur de la macro WEOF. Si l'argument a une autre valeur, le comportement est indéfini.

Le comportement est indéfini si l'argument locale à iswalpha_l() est l'objet spécial de catégorie de locale LC_GLOBAL_LOCALE ou n'est pas un descripteur valide d'objet de catégorie de locale.

VALEUR DE RETOUR

Les fonctions iswalpha() et iswalpha_l() renvoient une valeur non nulle si wc est un code de caractère large alphabétique ; sinon, elles renvoient 0.

ERREURS

Aucune erreur n'est définie.
