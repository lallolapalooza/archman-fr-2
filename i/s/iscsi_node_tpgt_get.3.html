iscsi_node_tpgt_get(3) Manuel de l'API iscsi_node_tpgt_get(3)

NOM

iscsi_node_tpgt_get - Récupérer le tag du groupe de portails cible d'un nœud iSCSI spécifié.

SYNTAXE

int32_t iscsi_node_tpgt_get (struct iscsi_node *node);

ARGUMENTS

node
Pointeur vers 'struct iscsi_node'. Si ce pointeur est NULL, votre programme sera terminé par assert.

DESCRIPTION

Récupérer le tag du groupe de portails cible du nœud iSCSI spécifié.

RETOUR

int32_t. -1 en cas d'inconnu.
