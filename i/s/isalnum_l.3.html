DESCRIPTIO

N

Ces fonctions vérifient si c, qui doit avoir la valeur d'un unsigned char ou EOF, appartient à une certaine classe de caractères selon la locale spécifiée. Les fonctions sans le suffixe « _l » effectuent la vérification en fonction de la locale

courante.

Les fonctions avec le suffixe « _l » effectuent la vérification en fonction de la locale spécifiée par l'objet locale locale. Le comportement de ces fonctions est indéfini si locale est l'objet locale spécial LC_GLOBAL_LOCALE (voir duplocale(3)) ou s'il ne s'agit pas d'un descripteur d'objet locale

valide.

La liste ci-dessous explique le fonctionnement des fonctions sans le suffixe « _l » ; les fonctions avec le suffixe « _l » ne diffèrent que par l'utilisation de l'objet locale locale au lieu de la locale

courante.

NAME

isalnum, isalpha, iscntrl, isdigit, isgraph, islower, isprint, ispunct, isspace, isupper, isxdigit, isblank - test for character class (locale-dependent)

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <ctype.h>

Character classification functions:

int isalnum(int c);
int isalpha(int c);
int iscntrl(int c);
int isdigit(int c);
int isgraph(int c);
int islower(int c);
int isprint(int c);
int ispunct(int c);
int isspace(int c);
int isupper(int c);
int isxdigit(int c);
int isblank(int c);

int isalnum_l(int c, locale_t locale);
int isalpha_l(int c, locale_t locale);
int isblank_l(int c, locale_t locale);
int iscntrl_l(int c, locale_t locale);

int isprint_l(int c, locale_t locale);
int ispunct_l(int c, locale_t locale);
int isspace_l(int c, locale_t locale);
int isupper_l(int c, locale_t locale);
int isxdigit_l(int c, locale_t locale);
int isascii_l(int c, locale_t locale);

DESCRIPTION

The functions described here are used to classify characters.

The first group of functions (isalnum(), isalpha(), etc.) test characters based on the current locale.

The second group of functions (isalnum_l(), isalpha_l(), etc.) perform the same tests, but use the provided locale object locale instead of the current locale.

The argument c is an int, which must be either EOF or representable as a `unsigned char'.

The classification is based on the character encoding and the properties assigned to characters in the current locale or the locale specified by locale.

The following are the character classes:

isalnum()
Tests for an alphanumeric character.
isalpha()
Tests for an alphabetic character.
isblank()
Tests for a blank character. Blank characters are space characters and those for which isspace() is true, except that isblank() does not recognize certain characters as blank which are recognized by isspace(). Specifically, in the default C locale, only space ( ) and horizontal tab ( ) are considered blank.
iscntrl()
Tests for a control character.
isdigit()
Tests for a digit character (0 to 9).
isgraph()
Tests for a printing character, excluding the space character.
islower()
Tests for a lowercase alphabetic character.
isprint()
Tests for any printable character including space.
ispunct()
Tests for any printing character, excluding space, digits, and alphabetic characters.
isspace()
Tests for a white-space character. In the default C locale, these are the space ( ), form feed ( ), newline ( ), carriage return ( ), horizontal tab ( ), and vertical tab ( ) characters.
isupper()
Tests for an uppercase alphabetic character.
isxdigit()
Tests for a hexadecimal digit character (0 to 9, A to F, a to f).
isascii()
Tests for an ASCII character (0 to 127). This function is not affected by the locale.

The `_l' variants take an explicit locale object.

CAVEATS

The standards require that the argument c for these functions is either EOF or a value that is representable in the type unsigned char; otherwise, the behavior is undefined. If the argument c is of type char, it must be cast to unsigned char, as in the following example:


char c;
...
res = toupper((unsigned char) c);

This is necessary because char may be the equivalent of signed char, in which case a byte where the top bit is set would be sign extended when converting to int, yielding a value that is outside the range of unsigned char.

The details of what characters belong to which class depend on the locale. For example, isupper() will not recognize an A-umlaut (Ä) as an uppercase letter in the default C locale.
