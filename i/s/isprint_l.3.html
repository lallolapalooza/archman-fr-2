DESCRIPTIO

N

Ces fonctions vérifient si c, qui doit avoir la valeur d'un unsigned char ou EOF, appartient à une certaine classe de caractères selon la locale spécifiée. Les fonctions sans le suffixe « _l » effectuent la vérification en fonction de la locale

courante.

Les fonctions avec le suffixe « _l » effectuent la vérification en fonction de la locale spécifiée par l'objet de locale locale. Le comportement de ces fonctions est indéfini si locale est l'objet de locale spécial LC_GLOBAL_LOCALE (voir duplocale(3)) ou s'il ne s'agit pas d'un descripteur d'objet de locale

valide.

La liste ci-dessous explique le fonctionnement des fonctions sans le suffixe « _l » ; les fonctions avec le suffixe « _l » ne diffèrent que par l'utilisation de l'objet de locale locale au lieu de la locale

courante.

NOM

isascii_l, isblank_l, iscntrl_l, isdigit_l, isgraph_l, islower_l, isprint_l, ispunct_l, isspace_l, isupper_l, isxdigit_l - classer les caractères en utilisant les paramètres régionaux.

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

#include <ctype.h>

int isgraph_l(int c, locale_t locale);

int isprint_l(int c, locale_t locale);

DESCRIPTION

Les fonctions isascii_l(), isblank_l(), iscntrl_l(), isdigit_l(), isgraph_l(), islower_l(), isprint_l(), ispunct_l(), isspace_l(), isupper_l() et isxdigit_l() testent si le caractère c (qui doit être soit la valeur EOF, soit un caractère de type unsigned char) appartient à la classe de caractères spécifiée par le nom de la fonction, en utilisant les informations de classe de caractères spécifiées par locale.

La valeur de locale doit être un descripteur de locale valide retourné par newlocale(3) ou par une valeur spéciale : LC_GLOBAL_LOCALE (pour utiliser la locale globale spécifiée par setlocale(3)) ou LC_C_LOCALE (pour utiliser la locale C).

isascii_l() teste si c est un caractère ASCII (0 à 127).

isblank_l() teste si c est un caractère de contrôle, un caractère d'espacement, ou un caractère de ponctuation. Dans la locale C, seuls les caractères d'espacement (espace, tabulation, saut de ligne, retour chariot, tabulation verticale, saut de page) et les caractères de contrôle sont considérés comme des blancs. Dans d'autres locales, d'autres caractères peuvent également être considérés comme des blancs.

iscntrl_l() teste si c est un caractère de contrôle.

isdigit_l() teste si c est un chiffre décimal (0 à 9).

isgraph_l() teste si c est un caractère imprimable, à l'exception de l'espace.

islower_l() teste si c est une lettre minuscule.

isprint_l() teste si c est un caractère imprimable ou un espace.

ispunct_l() teste si c est un caractère de ponctuation. Un caractère de ponctuation est un caractère imprimable qui n'est ni un espace, ni une lettre, ni un chiffre.

isspace_l() teste si c est un caractère d'espacement. Dans la locale C, ces caractères sont espace, tabulation ('\t'), saut de ligne ('\n'), retour chariot ('\r'), tabulation verticale ('\v'), et saut de page ('\f').

isupper_l() teste si c est une lettre majuscule.

isxdigit_l() teste si c est un chiffre hexadécimal. Les chiffres hexadécimaux sont 0-9, a-f, et A-F.

Si locale est LC_GLOBAL_LOCALE, le comportement de ces fonctions est identique à celui des fonctions sans le suffixe _l, qui utilisent la locale sélectionnée par setlocale(3).

VALEUR RENVOYÉE

Ces fonctions renvoient une valeur non nulle si la condition est remplie, et zéro sinon. La valeur renvoyée pour isascii_l() est toujours non nulle pour les entrées comprises entre 0 et 127.

Pour obtenir des informations sur les attributs, consulter pthreads(7).

Les fonctions avec le suffixe _l sont thread-safe. Les fonctions sans le suffixe _l ne le sont pas, car elles dépendent de l'état global de la locale.

NORMES

Les fonctions isascii_l(), isblank_l(), iscntrl_l(), isdigit_l(), isgraph_l(), islower_l(), isprint_l(), ispunct_l(), isspace_l(), isupper_l() et isxdigit_l() sont conformes à la norme POSIX.1-2008.

isascii_l() est une extension GNU.

HISTORIQUE

Les fonctions isascii_l(), isblank_l(), iscntrl_l(), isdigit_l(), isgraph_l(), islower_l(), isprint_l(), ispunct_l(), isspace_l(), isupper_l() et isxdigit_l() ont été introduites dans POSIX.1-2008.

isascii_l() a été introduite dans glibc 2.3.

POINTS D'ATTENTION

Les normes exigent que l'argument c pour ces fonctions soit soit EOF, soit une valeur qui peut être représentée dans le type unsigned char ; sinon, le comportement est indéfini. Si l'argument c est de type char, il doit être converti en unsigned char, comme dans l'exemple suivant :


char c;
...
res = toupper((unsigned char) c);

Ceci est nécessaire car char peut être l'équivalent de signed char, auquel cas un octet dont le bit de poids fort est défini serait étendu en signe lors de la conversion en int, résultant en une valeur qui est en dehors de la plage de unsigned char.

Les détails sur les caractères appartenant à chaque classe dépendent de la locale. Par exemple, isupper() ne reconnaîtra pas un A-umlaut (&#x00C4;) comme une lettre majuscule dans la locale par défaut C.
