ISADUMP(8) Manuel du responsable système ISADUMP(8)

NOM

isadump - examiner les registres ISA

SYNTAXE

isadump [-y] [-W|-L] [-k V1,V2...] registre_addr registre_donnees [banc [registre_banc]] # pour l'accès de type I2C
isadump -f [-y] [-W|-L] adresse [plage [banc [registre_banc]]] # pour l'espace d'adressage plat

DESCRIPTION

isadump est un petit programme d'aide pour examiner les registres visibles via le bus ISA. Il est destiné à sonder toute puce résidant sur le bus ISA fonctionnant avec un registre d'adresse et un registre de données (accès de type I2C) ou une plage plate (jusqu'à 256 octets).

OPTIONS

-f
Active le mode d'espace d'adressage plat.
-y
Désactive le mode interactif. Par défaut, isadump attend une confirmation de l'utilisateur avant de modifier le bus ISA. Lorsque cette option est utilisée, l'opération est effectuée directement. Ceci est principalement prévu pour être utilisé dans les scripts.
-k V1,V2...
Spécifie une liste d'octets séparés par des virgules à envoyer comme séquence de clés pour entrer en mode de configuration de puce. La plupart des puces Super-I/O en ont besoin. Les séquences de clés connues sont : 0x87,0x01,0x55,0x55 pour ITE, 0x55 pour SMSC, 0x87,0x87 pour Winbond et VIA, aucune nécessaire pour National Semiconductor.
-W
Effectue des lectures de 16 bits.
-L
Effectue des lectures de 32 bits.

OPTIONS (mode d'accès type I2C)

Au moins deux options doivent être fournies à isadump. registre_addr contient l'adresse ISA du registre d'adresse pour la puce à sonder ; registre_donnees contient l'adresse du registre de données. Les deux adresses sont des entiers compris entre 0x0000 et 0x3FFF. Généralement, si l'adresse de base de la puce est 0x0nn0, le registre d'adresse est à 0x0nn5 et le registre de données est à 0x0nn6. L'adresse de base la plus courante pour les puces de surveillance matérielle est 0x0290.

Pour les puces Super-I/O, le registre d'adresse est typiquement situé à 0x2E avec le registre de données à 0x2F.

Les paramètres banc et registre_banc sont utiles sur les puces Winbond ainsi que sur les puces Super-I/O. banc est un entier compris entre 0 et 31, et registre_banc est un entier compris entre 0x00 et 0xFF (valeur par défaut : 0x4E pour les puces Winbond, 0x07 pour les puces Super-I/O). La fiche technique du W83781D fournit plus d'informations sur la sélection du banc.

OPTIONS (mode d'espace d'adressage plat)

En mode plat, un seul paramètre est obligatoire. adresse contient l'adresse ISA de la puce à sonder ; c'est un entier compris entre 0x0000 et 0xFFFF. Si elle est fournie, plage indique le nombre d'octets à lire (doit être un multiple de 16). Si la plage n'est pas fournie, elle est par défaut à 256 octets et l'adresse est forcée à être alignée sur une frontière de 256 octets.

Les paramètres banc et registre_banc sont utiles sur les puces Super-I/O National Semiconductor PC87365 et PC87366. banc est un entier compris entre 0 et 31, et registre_banc est un entier compris entre 0x00 et 0xFF (valeur par défaut : 0x09 ; doit tenir dans la plage spécifiée). Voir la fiche technique du PC87365 pour plus d'informations sur la sélection du banc.

NOTES

Si aucun banc n'est spécifié, aucune opération de changement de banc n'est effectuée.

Si un banc est spécifié, la valeur d'origine est restaurée avant que isadump ne se termine.

Le vidage des puces Super-I/O est généralement un processus en deux étapes. Premièrement, vous devrez accéder à l'adresse principale Super-I/O en utilisant une commande telle que : isadump 0x2e 0x2f 0x09. Ceci sélectionnera le périphérique logique 9 (la valeur correcte dépend de la puce). À 0x60, vous trouverez le mot d'adresse du périphérique logique, par exemple « ec c0 ». Ensuite, vous pouvez utiliser une commande telle que : isadump -f 0xecc0 16. Ceci videra les registres du périphérique logique. La plage correcte dépend de la puce.

AVERTISSEMENT

Fouiller dans l'espace de données ISA est extrêmement dangereux. Exécuter isadump avec des paramètres aléatoires peut entraîner des plantages système, des pertes de données et pire encore ! Soyez extrêmement prudent lorsque vous utilisez ce programme.
