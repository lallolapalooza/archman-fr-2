NOM

isutf8 - vérifier si les fichiers sont en UTF-8 valide

SYNTAXE


isutf8
[-hqliv] [--help] [--quiet] [--list] [--invert] [--verbose] [fichier...]

DESCRIPTION

isutf8 vérifie si les fichiers sont syntaxiquement valides en UTF-8. L'entrée est constituée des fichiers nommés sur la ligne de commande ou de l'entrée standard. Les notifications concernant les fichiers avec un UTF-8 invalide sont imprimées sur la sortie standard.

OPTIONS

-h, --help
Affiche un résumé d'aide.
-q, --quiet
Ne pas afficher de messages indiquant quels fichiers ne sont pas en UTF-8 valide, simplement l'indiquer avec le code de sortie.
-l, --list
Afficher uniquement les noms des fichiers contenant un UTF-8 invalide.
-i, --invert
Inverser la sélection : lister les fichiers compatibles UTF-8.
-v, --verbose
Afficher également une vue de type hexdump de l'erreur et un peu de contexte.

STATUT DE SORTIE

Si le fichier est en UTF-8 valide, le code de sortie est zéro. Si le fichier n'est pas en UTF-8 valide, ou s'il y a une erreur, le code de sortie est non nul.
