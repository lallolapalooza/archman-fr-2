NOM

iscsi_iface_get - Récupérer une interface iSCSI spécifiée.

SYNTAXE

int iscsi_iface_get (struct iscsi_context *ctx, const char *iface_name, struct iscsi_iface **iface);

ARGUMENTS

ctx
Pointeur vers 'struct iscsi_context'. Si ce pointeur est NULL, votre programme sera terminé par assert.
iface_name
Chaîne de caractères. Nom de l'interface iSCSI. Également le nom du fichier de configuration "/etc/iscsi/iface/<iface_name>". Si ce pointeur est NULL ou une chaîne vide, votre programme sera terminé par assert.
iface
Pointeur de sortie vers 'struct iscsi_iface'. Sa mémoire doit être libérée par iscsi_iface_free. Si ce pointeur est NULL, votre programme sera terminé par assert.

DESCRIPTION

Récupère l'interface iSCSI spécifiée en lisant la configuration depuis "/etc/iscsi/iface/<iface_name>". Pour générer la configuration de l'interface iSCSI lors de l'installation d'une nouvelle carte, utilisez iscsi_default_iface_setup. Un fichier de configuration invalide sera traité comme une erreur LIBISCSI_ERR_IDBM. Un fichier de configuration non trouvé sera traité comme une erreur LIBISCSI_ERR_INVAL.

RETOUR

int. Les codes d'erreur valides sont :

* LIBISCSI_OK

* LIBISCSI_ERR_BUG

* LIBISCSI_ERR_NOMEM

* LIBISCSI_ERR_ACCESS

* LIBISCSI_ERR_SYSFS_LOOKUP

* LIBISCSI_ERR_IDBM

Le numéro d'erreur peut être converti en chaîne de caractères à l'aide de iscsi_strerror.
