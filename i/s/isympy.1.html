C'est simplement un shell python normal (shell ipython si vous avez le paquet ipython installé) qui exécute les commandes suivantes pour que vous n'ayez pas à le faire : >>> from __future__ import division >>> from sympy import * >>> x, y, z = symbols("x,y,z") >>> k, m, n = symbols("k,m,n", integer=True)

Ainsi, démarrer isympy est équivalent à démarrer python (ou ipython) et à exécuter manuellement les commandes ci-dessus. Il est destiné à une expérimentation facile et rapide avec SymPy. Pour des programmes plus complexes, il est recommandé d'écrire un script et d'importer explicitement les éléments (en utilisant l'idiome « from sympy import sin, log, Symbol, ... »).

ORDER

Configurer l'ordre des termes pour l'affichage. La valeur par défaut est lex, qui ordonne les termes lexicographiquement (par exemple, x**2 + x + 1). Vous pouvez choisir d'autres ordres, comme rev-lex, qui utilisera un ordre lexicographique inverse

Notez que pour les expressions très volumineuses, ORDER='none' peut accélérer considérablement l'affichage, au prix du fait que l'ordre des termes dans l'expression affichée n'aura pas d'ordre canonique. Exemple : isympy -o rev-lax ORDERdoit être l'un de 'lex', 'rev-lex', 'grlex', 'rev-grlex',

to
Créer automatiquement les symboles manquants. Normalement, taper le nom d'un Symbol qui n'a pas été instancié au préalable lèverait une NameError, mais avec cette option activée, tout nom non défini sera automatiquement créé comme Symbol. Cela ne fonctionne qu'avec IPython 0.11. Notez que ceci n'est destiné qu'à un usage interactif, de type calculatrice. Dans un script qui utilise SymPy, les Symbols devraient
être instanciés en haut, pour qu'il soit clair de quoi il s'agit.
Cela ne remplacera aucun nom déjà défini, ce qui inclut les lettres à un caractère représentées par le mnémonique QCOSINE (voir le document « Gotchas and Pitfalls » dans la documentation). Vous pouvez supprimer des noms existants en exécutant « del name » dans le shell lui-même. Vous pouvez voir si un nom est défini en tapant « 'name' in globals() ».

Les Symbols créés de cette manière ont des hypothèses par défaut. Si vous voulez placer des hypothèses sur les symboles, vous devriez les créer en utilisant symbols() ou

var().

Enfin, cela ne fonctionne qu'au niveau du namespace principal. Ainsi, par exemple, si vous définissez une fonction dans isympy avec un Symbol non défini, cela ne fonctionnera

pas.
