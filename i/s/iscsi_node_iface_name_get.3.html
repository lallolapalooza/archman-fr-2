NOM

iscsi_node_iface_name_get - Récupérer le nom de l'interface du nœud iSCSI spécifié.

SYNTAXE

const char * iscsi_node_iface_name_get (struct iscsi_node *node);

ARGUMENTS

node
Pointeur de type 'struct iscsi_node'. Si ce pointeur est NULL, votre programme sera terminé par un assert.

DESCRIPTION

Récupère le nom de l'interface du nœud iSCSI spécifié.

EXEMPLES

"default" pour l'interface TCP iSCSI.

RETOUR

const char *. Aucune libération de mémoire n'est nécessaire, les ressources seront libérées par iscsi_node_free ou iscsi_nodes_free.
