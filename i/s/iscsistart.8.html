NOM

iscsistart - outil de démarrage iSCSI

SYNTAXE

iscsistart [OPTION]

DESCRIPTION

iscsistart établira une session en utilisant les paramètres fournis, ou les informations de démarrage iBFT ou Open Firmware [OF]. Ce programme ne doit pas être utilisé pour gérer des sessions. Son utilisation principale est d'établir les sessions utilisées pour le démarrage de la racine iSCSI.

OPTIONS

[-c|--config=]fichier-config
Lire la configuration depuis fichier-config plutôt que le fichier par défaut /etc/iscsi/iscsid.conf.
[-i|--initiatorname=]nom
Définir InitiatorName à nom (Requis si non utilisation de iBFT ou OF)
[-t|--targetname=]nom
Définir TargetName à nom (Requis si non utilisation de iBFT ou OF)
[-g|--tgpt=]N
Définir le tag du groupe de portails cible à N (Requis si non utilisation de iBFT ou OF)
[-a|--address=]A.B.C.D
Définir l'adresse IP à A.B.C.D (Requis si non utilisation de iBFT ou OF)
[-p|--port=]N
Définir le port à N (Optionnel. Défaut 3260)
[-u|--username=]N
Définir le nom d'utilisateur à N (Optionnel)
[-w|--password=]N
Définir le mot de passe à N (Optionnel)
[-U|-username_in=]N
Définir le nom d'utilisateur entrant à N (Optionnel)
[-W|--password_in=]N
Définir le mot de passe entrant à N (Optionnel)
[-d|--debug=]niveau-debug
Afficher les informations de débogage
[-b|--fwparam_connect]
Créer une session vers la cible en utilisant les informations iBFT ou OF
[-N|--fwparam_network]
Activer le réseau tel que spécifié par iBFT ou OF
[-f|--fwparam_print]
Afficher les informations iBFT ou OF sur STDOUT
[-P|--param=]NOM=VALEUR
Définir le paramètre dont le nom est NOM à VALEUR. NOM est un des réglages dans l'enregistrement du nœud ou iscsid.conf. Plusieurs paramètres peuvent être passés.
[-h|--help]
Afficher cette aide et quitter
[-v|--version]
Afficher la version et quitter
