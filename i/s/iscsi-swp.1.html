ISCSI-SWP(1) iscsi-swp : obtenir/définir la protection en écriture logicielle ISCSI-SWP(1)

NOM

iscsi-swp - Utilitaire pour obtenir/définir la protection en écriture logicielle sur un LUN iSCSI

SYNTAXE

iscsi-swp [ OPTIONS ] <PORTAIL_ISCSI>

iscsi-ls [-i --nom-initiateur=<IQN>] [-s --swp {on|off}] [-d --debug=<ENTIER>] [-? --help] [--usage]

DESCRIPTION

iscsi-swp est un utilitaire permettant d'obtenir ou de définir la protection en écriture logicielle sur un LUN iSCSI.

FORMAT URL PORTAIL ISCSI

Le format du portail iSCSI est 'iscsi://[<nom_utilisateur>[%<mot_de_passe>]@]<hôte>[:<port>]'

Le nom d'utilisateur et le mot de passe ne sont requis que si la cible nécessite une authentification CHAP. Vous pouvez éventuellement spécifier le nom d'utilisateur et le mot de passe via les variables d'environnement LIBISCSI_CHAP_USERNAME et LIBISCSI_CHAP_PASSWORD.

L'hôte peut être spécifié soit comme un nom d'hôte, une adresse IPv4 ou une adresse IPv6. Exemples :

	iscsi://192.0.2.1
	iscsi://[2001:DB8::1]:3261
	iscsi://ronnie%password@iscsi.example.com

Le port est le port TCP sur la cible à connecter. Le port par défaut est 3260.

OPTIONS

-i --nom-initiateur=<IQN>

Ceci spécifie le nom_initiateur que iscsi-ls utilisera lors de la connexion à la cible.

Le nom par défaut est 'iqn.2007-10.com.github:sahlberg:libiscsi:iscsi-ls', mais vous pouvez utiliser cet argument pour le remplacer. Ceci est principalement nécessaire dans les cas où la cible est configurée avec un contrôle d'accès pour n'autoriser les connexions de découverte qu'à partir de noms_initiateur connus.

-s --swp {on|off}

Par défaut, iscsi-swp affichera uniquement le paramètre actuel du bit de protection en écriture logicielle. En utilisant cet argument, iscsi-swp tentera également de définir/effacer le drapeau sur le LUN cible. 
iscsi-swp iscsi://127.0.0.1/iqn.ronnie.test/1
SWP:0
iscsi-swp iscsi://127.0.0.1/iqn.ronnie.test/1 --swp on
SWP:0
Activation de SWP
iscsi-swp iscsi://127.0.0.1/iqn.ronnie.test/1 --swp off
SWP:0
Désactivation de SWP

-d --debug=<ENTIER>

Niveau de débogage.

-? --help

Afficher le texte d'aide de base.

--usage

Afficher le texte d'utilisation de base.
