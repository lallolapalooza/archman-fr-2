fpclassify(3) Manuel des fonctions de bibliothèque fpclassify(3)

NOM

fpclassify, isfinite, isnormal, isnan, isinf - macros de classification des nombres à virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
int fpclassify(x);
int isfinite(x);
int isnormal(x);
int isnan(x);
int isinf(x);
Exigences pour les macros de test de fonctionnalités de glibc (voir feature_test_macros(7)):

fpclassify(), isfinite(), isnormal():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

isnan():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

isinf():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Les nombres à virgule flottante peuvent avoir des valeurs spéciales, comme l'infini ou NaN (Not a Number). Avec la macro fpclassify(x), vous pouvez déterminer le type de x. La macro prend n'importe quelle expression à virgule flottante comme argument. Le résultat est l'une des valeurs suivantes :

FP_NAN
x est "Not a Number".
FP_INFINITE
x est soit l'infini positif, soit l'infini négatif.
FP_ZERO
x est zéro.
FP_SUBNORMAL
x est trop petit pour être représenté dans un format normalisé.
FP_NORMAL
si rien de ce qui précède n'est vrai, il doit s'agir d'un nombre à virgule flottante normal.

Les autres macros fournissent une réponse courte à certaines questions standard.

isfinite(x)
renvoie une valeur non nulle si
(fpclassify(x) != FP_NAN && fpclassify(x) != FP_INFINITE)
isnormal(x)
renvoie une valeur non nulle si (fpclassify(x) == FP_NORMAL)
isnan(x)
renvoie une valeur non nulle si (fpclassify(x) == FP_NAN)
isinf(x)
renvoie 1 si x est l'infini positif, et -1 si x est l'infini négatif.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fpclassify (), isfinite (), isnormal (), isnan (), isinf () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

Dans glibc 2.01 et versions antérieures, isinf() renvoie une valeur non nulle (en fait : 1) si x est l'infini positif ou l'infini négatif. (C'est tout ce que C99 exige.)

NOTES

Pour isinf(), les normes disent simplement que la valeur de retour est non nulle si et seulement si l'argument a une valeur infinie.
