NOM

iso-read - lit des portions d'une image ISO 9660

SYNOPSIS

iso-read [OPTION...]

DESCRIPTION

-d, --debug=INT
Définit le débogage au niveau LEVEL.
-i, --image=FICHIER
Lire depuis l'image ISO-9660. Cette option est obligatoire.
-e, --extract=FICHIER
Extraire FICHIER de l'image ISO-9660. Cette option est obligatoire.
-k, --ignore
Ignorer les erreurs de lecture, c'est-à-dire continuer.
--no-header
Ne pas afficher l'en-tête et le copyright (pour les tests de régression).
-o, --output-file=FICHIER
Fichier de sortie. Cette option est obligatoire.
-U --udf
Le contenu est au format UDF.
-V, --version
afficher les informations de version et de copyright et quitter.

Options d'aide :

-?, --help
Afficher ce message d'aide.
--usage
Afficher un bref message d'utilisation.
