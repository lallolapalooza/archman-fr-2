FBB::IQuotedPrintableStream(3bobcat) Encodage/décodage Quoted-Printable std::istream FBB::IQuotedPrintableStream(3bobcat)

NOM

FBB::IQuotedPrintableStream - Flux std::istream effectuant l'encodage et le décodage quoted-printable

SYNTAXE

#include <bobcat/iquotedprintablestream>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::IQuotedPrintableStream peuvent être utilisés pour encoder ou décoder des informations en quoted-printable, celles-ci étant disponibles sur un std::istream séparé.

La classe IQuotedPrintableStream est un modèle de classe, utilisant un paramètre non-type FBB::CodeType. Les objets de la classe FBB::IQuotedPrintableStream<FBB::ENCODE> encodent les informations qu'ils reçoivent, les objets de la classe FBB::IQuotedPrintableStream<FBB::DECODE> décodent les informations qu'ils reçoivent.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

FBB::IQuotedPrintableBuf (private),
std::istream

CONSTRUCTEURS

o
IQuotedPrintableStream<CodeType>(std::istream &in, size_t bufSize = 1000):
Ce constructeur initialise un std::istream en lui fournissant un tampon de flux FBB::IQuotedPrintableBuf. Le constructeur de IQuotedPrintableBuf reçoit tous les arguments passés à ce constructeur.
- Les objets IQuotedPrintableStream<ENCODE> effectuent l'encodage quoted-printable ;
- Les objets IQuotedPrintableStream<DECODE> effectuent le décodage quoted-printable ;
- Les objets IQuotedPrintableStream<CodeType> obtiennent les octets à encoder ou décoder à partir de std::istream &in ;
- Le IFilterBuf utilisé en interne est initialisé avec un tampon de taille bufSize, avec une borne inférieure de 100.
Le constructeur utilise une taille de tampon configurable pour la lecture. Les caractères lus dans le tampon mais ne faisant pas partie des données encodées quoted-printable réelles ne sont pas disponibles après l'achèvement du décodage quoted-printable. Si des informations au-delà du bloc d'entrée quoted-printable doivent rester disponibles, spécifiez une taille de tampon de 1.

Les constructeurs et opérateurs de copie/déplacement ne sont pas disponibles.

MEMBRES HERITES

Étant donné que la classe utilise une dérivation publique de std::istream, tous les membres de cette classe peuvent être utilisés.

EXEMPLE

#include <iostream>
#include <bobcat/iquotedprintablestream>
using namespace std;
using namespace FBB;
int main()
{
    IQuotedPrintableStream<ENCODE> in(cin);
    cout << in.rdbuf();         // Encodage quoted-printable des informations de
                                // cin.
}

Voir aussi l'exemple dans la page de manuel iquotedprintablebuf(3bobcat).
