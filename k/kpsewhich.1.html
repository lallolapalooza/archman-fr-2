KPSEWHICH(1) Manuel des commandes générales KPSEWHICH(1)

NOM

kpsewhich - recherche et expansion autonome de chemins pour kpathsea

SYNTAXE

kpsewhich [options] [noms de fichiers]

DESCRIPTION

Cette page de manuel n'a pas vocation à être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Kpathsea: A library for path searching.

kpsewhich est utilisé comme une interface autonome de la bibliothèque kpathsea qui peut être utilisée pour examiner les variables et trouver des fichiers. Lorsque l'option -format n'est pas donnée, le chemin de recherche utilisé lors de la recherche d'un fichier est déduit du nom donné, en recherchant une extension connue. Si aucune extension connue n'est trouvée, le chemin de recherche des fichiers source TeX est utilisé.

OPTIONS

kpsewhich accepte les options suivantes :

-debug num
Définit les indicateurs de débogage.
-D num
Utilise une résolution de base de num ; la valeur par défaut, définie par l'installateur, est généralement de 600.
-dpi num
Comme -D.
-engine string
Définit $engine dans l'environnement, qui est utilisé dans certains chemins de recherche.
-expand-braces string
Affiche l'expansion des variables et des accolades de string.
-expand-path string
Affiche l'expansion complète du chemin de string.
-expand-var string
Affiche l'expansion de la variable de string.
-format nom
Utilise le type de fichier nom. Voir le manuel info pour une liste des noms valides, ou utilisez l'option -help pour afficher la liste.
-help
Affiche un message d'aide et quitte.
-interactive
Demande des noms de fichiers supplémentaires à rechercher.
-mktex fmt
active la génération de mktexfmt. (fmt=pk/mf/tex/tfm)
-mode string
Définit le nom de l'appareil pour $MAKETEX_MODE à string ; pas de valeur par défaut.
-must-exist
Recherche également sur le disque en plus de ls-R si nécessaire.
-no-mktex fmt
désactive la génération de mktexfmt. (fmt=pk/mf/tex/tfm)
-path string
Recherche dans le chemin string.
-progname string
Définit le nom du programme à string.
-show-path nom
Affiche le chemin de recherche pour le type de fichier nom. Voir le manuel info pour une liste des noms valides, ou utilisez l'option -help pour afficher la liste.
-var-value variable
Affiche l'expansion de variable.
-version
Affiche les informations sur la version et quitte.

VOIR AUSSI

mktexlsr(1), mktexmf(1), mktexpk(1), mktextfm(1).
