NOM

kubeadm upgrade plan - Vérifier les versions disponibles pour une mise à niveau et valider si votre cluster actuel est améliorable.

SYNTAXE

kubeadm upgrade plan [OPTIONS]

DESCRIPTION

Vérifie les versions disponibles pour une mise à niveau et valide si votre cluster actuel est améliorable. Cette commande ne peut être exécutée que sur les nœuds du plan de contrôle où le fichier kubeconfig "admin.conf" existe. Pour ignorer la vérification Internet, passez le paramètre optionnel [version].

OPTIONS

--allow-experimental-upgrades=false Afficher les versions instables de Kubernetes comme alternative de mise à niveau et autoriser la mise à niveau vers des versions alpha/beta/release candidate de Kubernetes.

--allow-missing-template-keys=true Si vrai, ignorer toute erreur dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. S'applique uniquement aux formats de sortie golang et jsonpath.

--allow-release-candidate-upgrades=false Afficher les versions candidate à la publication de Kubernetes comme alternative de mise à niveau et autoriser la mise à niveau vers des versions candidate à la publication de Kubernetes.

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--etcd-upgrade=true Effectuer la mise à niveau d'etcd.

--ignore-preflight-errors=[] Une liste de vérifications dont les erreurs seront affichées sous forme d'avertissements. Exemple : 'IsPrivilegedUser,Swap'. La valeur 'all' ignore les erreurs de toutes les vérifications.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'indicateur n'est pas défini, un ensemble d'emplacements standard peut être recherché pour trouver un fichier kubeconfig existant.

-o, --output="text" Format de sortie. Un parmi : text|json|yaml|go-template|go-template-file|template|templatefile|jsonpath|jsonpath-as-json|jsonpath-file.

--print-config=false Spécifie si le fichier de configuration qui sera utilisé lors de la mise à niveau doit être imprimé ou non.

--show-managed-fields=false Si vrai, conserver les managedFields lors de l'impression d'objets aux formats JSON ou YAML.

OPTIONS INHERITÉE DES COMMANDES PARENTALES

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à effectuer un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée
