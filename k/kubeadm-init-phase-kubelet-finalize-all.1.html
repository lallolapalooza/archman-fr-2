NOM

kubeadm init phase kubelet-finalize all - Exécute toutes les phases de finalisation de kubelet

SYNTAXE

kubeadm init phase kubelet-finalize all [OPTIONS]

DESCRIPTION

Exécute toutes les phases de finalisation de kubelet

OPTIONS

--cert-dir="/etc/kubernetes/pki" Le chemin où enregistrer et stocker les certificats.

--config="" Chemin vers un fichier de configuration kubeadm.

--dry-run=false N'appliquez aucun changement ; affichez seulement ce qui serait fait.

OPTIONS HERITEES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela forcera kubeadm à utiliser le chemin fourni comme racine.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

EXEMPLE

  # Met à jour les paramètres pertinents pour le kubelet après le démarrage TLS"
  kubeadm init phase kubelet-finalize all --config

VOIR AUSSI
