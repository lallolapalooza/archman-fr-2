NOM

keybound - obtenir la définition d'un code de touche curses

SYNTAXE

#include <curses.h>
char * keybound(int keycode, int count);

DESCRIPTION

Ceci est une extension de la bibliothèque curses. Elle permet à une application de déterminer la chaîne qui est définie dans terminfo pour des codes de touche spécifiques.

VALEUR DE RETOUR

Le paramètre keycode doit être supérieur à zéro, sinon NULL est retourné. S'il ne correspond à aucune touche définie, alors NULL est retourné. Le paramètre count est utilisé pour permettre à l'application d'itérer à travers plusieurs définitions, en comptant à partir de zéro. En cas de succès, la fonction retourne une chaîne qui doit être libérée par l'appelant.

PORTABILITÉ

Cette routine est spécifique à ncurses. Elle n'était pas prise en charge sur les implémentations des versions 7, BSD ou System V. Il est recommandé que tout code dépendant de celles-ci soit conditionné en utilisant NCURSES_VERSION.
