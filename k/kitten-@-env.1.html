Nom

kitten-@-env - Changer les variables d'environnement vues par les enfants futurs

Utilisation

kitten @ env env_var1=val env_var2=val ...

Description

Change les variables d'environnement qui seront vues dans les nouvelles fenêtres lancées. Similaire à l'option env dans kitty.conf, mais affecte les instances kitty en cours d'exécution. Si aucun = n'est présent, la variable est retirée de l'environnement.

Options

--help, -h [=non]
Afficher l'aide pour cette commande

Options globales

--to
Une adresse pour l'instance kitty à contrôler. Correspond à l'adresse donnée à l'instance kitty via l'option --listen-on ou le réglage listen_on dans kitty.conf. Si non spécifié, la variable d'environnement KITTY_LISTEN_ON est vérifiée. Si celle-ci n'est pas non plus trouvée, les messages sont envoyés au terminal de contrôle pour ce processus, c'est-à-dire qu'ils ne fonctionneront que si ce processus est exécuté dans une fenêtre kitty.
--password
Un mot de passe à utiliser lors du contact avec kitty. Cela demandera à kitty la permission de l'utilisateur pour effectuer l'action spécifiée, à moins que le mot de passe n'ait été accepté auparavant ou ne soit préconfiguré dans kitty.conf. Pour utiliser un mot de passe vide, spécifiez --use-password comme toujours.
--password-file [=rc-pass]
Un fichier à partir duquel lire le mot de passe. Les espaces blancs en fin de ligne sont ignorés. Les chemins relatifs sont résolus à partir du répertoire de configuration de kitty. Utilisez - pour lire depuis STDIN. Utilisez fd:num pour lire depuis le descripteur de fichier num. Utilisé si aucun --password n'est fourni. Par défaut, vérifie le fichier rc-pass dans le répertoire de configuration de kitty.
--password-env [=KITTY_RC_PASSWORD]
Le nom d'une variable d'environnement à partir de laquelle lire le mot de passe. Utilisé si aucun --password-file n'est fourni. Par défaut, vérifie la variable d'environnement KITTY_RC_PASSWORD.
--use-password [=si-disponible]
Si aucun mot de passe n'est disponible, kitty enverra généralement la commande de contrôle à distance sans mot de passe. Cette option peut être utilisée pour forcer à utiliser toujours ou jamais le mot de passe fourni. S'il est défini sur always et qu'aucun mot de passe n'est fourni, le mot de passe vide est utilisé.

Choix : si-disponible, toujours, jamais
