NOM

katedec - décode les flux Kate en une description textuelle

SYNTAXE

katedec [-hVv] [-o fichier_sortie] [-t type] [ fichier_entree ]

DESCRIPTION

katedec décode les flux Kate dans le langage de description personnalisé de libkate.

OPTIONS

-h
Affiche l'aide de la ligne de commande.
-V
Affiche les informations de version.
-v
Augmente la verbosité.
-o fichier_sortie
Écrit le fichier de description de sortie dans le nom de fichier donné (écrit sur stdout si non spécifié). Il est possible d'écrire dans plusieurs fichiers (par exemple, si l'entrée contient plusieurs flux Kate) en passant des balises de formatage de style printf dans le nom de fichier. Les balises de formatage sont des chaînes commençant par un caractère '%', suivies de la balise elle-même. Les balises connues sont :
% remplacé par un caractère % verbatim
l remplacé par la langue du flux
c remplacé par la catégorie du flux
s remplacé par le numéro de série du flux, au format hexadécimal
i remplacé par l'index du flux dans le fichier d'entrée, commençant à 0
-t type
Définit le type de format de sortie :
kate: format de description Kate
srt: format SubRip (les informations non textuelles seront perdues)

EXEMPLES

Décode un flux Kate en une description textuelle :


katedec -o sortie.kate entree.ogg

Décode plusieurs flux Kate multiplexés en fichiers SubRip :


katedec -t srt -o sortie.%l.kate entree.ogg
