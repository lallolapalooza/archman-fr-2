NOM

kcutiltest - interface de ligne de commande pour tester les fonctions utilitaires

DESCRIPTION

La commande `kcutiltest' est un utilitaire pour le test fonctionnel et le test de performance des fonctions utilitaires. Cette commande s'utilise dans le format suivant. `rnum' spécifie le nombre d'itérations. `path' spécifie le chemin d'un fichier.


kcutiltest mutex [-th num] [-iv num] rnum
Effectue le test des primitives de verrouillage.
kcutiltest cond [-th num] [-iv num] rnum
Effectue le test des primitives de variables de condition.
kcutiltest para [-th num] [-iv num] rnum
Effectue le test du traitement parallèle.
kcutiltest file [-th num] [-rnd] [-msiz num] path rnum
Effectue le test de l'abstraction du système de fichiers.
kcutiltest lhmap [-rnd] [-bnum num] rnum
Effectue le test de la table de hachage doublement chaînée.
kcutiltest thmap [-rnd] [-bnum num] rnum
Effectue le test de la table de hachage économisant la mémoire.
kcutiltest talist [-rnd] rnum
Effectue le test de la liste de tableaux économisant la mémoire.
kcutiltest misc rnum
Effectue le test de mécanismes divers.

Les options comprennent les suivantes.

-th num : spécifie le nombre de threads de travail.
-iv num : spécifie l'intervalle entre les itérations.
-rnd : effectue un test aléatoire.
-msiz num : spécifie la taille de la région mappée en mémoire.
-bnum num : spécifie le nombre de compartiments de la table de hachage.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
