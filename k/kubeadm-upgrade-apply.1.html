NOM

kubeadm upgrade apply - Mettre à niveau votre cluster Kubernetes vers la version spécifiée

SYNTAXE

kubeadm upgrade apply [OPTIONS]

DESCRIPTION

Mettre à niveau votre cluster Kubernetes vers la version spécifiée

La commande "apply [version]" exécute les phases suivantes :

preflight        Exécuter les vérifications préliminaires avant la mise à niveau
control-plane    Mettre à niveau le plan de contrôle
upload-config    Télécharger les configurations kubeadm et kubelet vers des ConfigMaps
  /kubeadm         Télécharger la configuration du cluster kubeadm vers un ConfigMap
  /kubelet         Télécharger la configuration kubelet vers un ConfigMap
kubelet-config   Mettre à niveau la configuration kubelet pour ce nœud
bootstrap-token  Configurer le jeton d'amorçage et les règles RBAC pour les informations du cluster
addon            Mettre à niveau les addons kubeadm par défaut
  /coredns         Mettre à niveau l'addon CoreDNS
  /kube-proxy      Mettre à niveau l'addon kube-proxy
post-upgrade     Exécuter les tâches post-mise à niveau

OPTIONS

--allow-experimental-upgrades=false Afficher les versions instables de Kubernetes comme alternative de mise à niveau et permettre la mise à niveau vers des versions alpha/beta/release candidate de Kubernetes.

--allow-release-candidate-upgrades=false Afficher les versions release candidate de Kubernetes comme alternative de mise à niveau et permettre la mise à niveau vers des versions release candidate de Kubernetes.

--certificate-renewal=true Effectuer le renouvellement des certificats utilisés par les composants modifiés lors des mises à niveau.

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--dry-run=false Ne modifier aucun état, afficher seulement quelles actions seraient effectuées.

--etcd-upgrade=true Effectuer la mise à niveau d'etcd.

-f, --force=false Forcer la mise à niveau bien que certains prérequis ne soient pas remplis. Ceci implique également le mode non interactif.

--ignore-preflight-errors=[] Une liste de vérifications dont les erreurs seront affichées comme avertissements. Exemple : 'IsPrivilegedUser,Swap'. La valeur 'all' ignore les erreurs de toutes les vérifications.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standard peut être recherché pour trouver un fichier kubeconfig existant.

--patches="" Chemin d'accès à un répertoire qui contient des fichiers nommés "target[suffix][+patchtype].extension". Par exemple, "kube-apiserver0+merge.yaml" ou juste "etcd.json". "target" peut être l'un des "kube-apiserver", "kube-controller-manager", "kube-scheduler", "etcd", "kubeletconfiguration", "corednsdeployment". "patchtype" peut être l'un des "strategic", "merge" ou "json" et ils correspondent aux formats de patch pris en charge par kubectl. Le "patchtype" par défaut est "strategic". "extension" doit être soit "json" soit "yaml". "suffix" est une chaîne optionnelle qui peut être utilisée pour déterminer quels patchs sont appliqués en premier par ordre alphanumérique.

--print-config=false Spécifie si le fichier de configuration qui sera utilisé dans la mise à niveau doit être affiché ou non.

--skip-phases=[] Liste des phases à ignorer

-y, --yes=false Effectuer la mise à niveau sans demander de confirmation (mode non interactif).

OPTIONS HERITEES DES COMMANDES PARENTES

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à faire un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée
