NOM

kcforestmgr - interface en ligne de commande pour gérer la base de données de l'arborescence de répertoires

DESCRIPTION

La commande `kcforestmgr' est un utilitaire pour tester et déboguer la base de données de l'arborescence de fichiers et ses applications. `chemin' spécifie le chemin d'un fichier de base de données. `clé' spécifie la clé d'un enregistrement. `valeur' spécifie la valeur d'un enregistrement. `fichier' spécifie le fichier d'entrée/sortie.


kcforestmgr create [-otr] [-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-rcd|-rcld|-rcdd] chemin
Crée un fichier de base de données.
kcforestmgr inform [-onl|-otl|-onr] [-st] chemin
Affiche les informations de statut.
kcforestmgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] chemin clé valeur
Stocke un enregistrement.
kcforestmgr remove [-onl|-otl|-onr] [-sx] chemin clé
Supprime un enregistrement.
kcforestmgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] chemin clé
Affiche la valeur d'un enregistrement.
kcforestmgr list [-onl|-otl|-onr] [-des] [-max num] [-rm] [-sx] [-pv] [-px] chemin [clé]
Affiche les clés de tous les enregistrements, séparées par des sauts de ligne.
kcforestmgr clear [-onl|-otl|-onr] chemin
Supprime tous les enregistrements d'une base de données.
kcforestmgr import [-onl|-otl|-onr] [-sx] chemin [fichier]
Importe les enregistrements à partir d'un fichier TSV.
kcforestmgr copy [-onl|-otl|-onr] chemin fichier
Copie la base de données entière.
kcforestmgr dump [-onl|-otl|-onr] chemin [fichier]
Sauvegarde les enregistrements dans un fichier snapshot.
kcforestmgr load [-otr] [-onl|-otl|-onr] chemin [fichier]
Charge les enregistrements à partir d'un fichier snapshot.
kcforestmgr setbulk [-onl|-otl|-onr] chemin clé valeur ...
Stocke les enregistrements en bloc.
kcforestmgr removebulk [-onl|-otl|-onr] [-sx] chemin clé ...
Supprime les enregistrements en bloc.
kcforestmgr getbulk [-onl|-otl|-onr] [-sx] [-px] chemin clé ...
Récupère les enregistrements en bloc.
kcforestmgr check [-onl|-otl|-onr] chemin
Vérifie la cohérence.

Les options sont les suivantes.

-otr : ouvre la base de données avec l'option de troncature.
-onl : ouvre la base de données avec l'option de non-verrouillage.
-otl : ouvre la base de données avec l'option de tentative de verrouillage.
-onr : ouvre la base de données avec l'option de non-réparation automatique.
-tc : ajuste la base de données avec l'option de compression.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-psiz num : spécifie la taille de chaque page.
-rcd : utilise le comparateur décimal au lieu du comparateur lexical.
-rcld : utilise le comparateur lexical descendant au lieu du comparateur ascendant.
-rcdd : utilise le comparateur décimal descendant au lieu du comparateur lexical.
-st : affiche des informations diverses.
-add : effectue l'opération d'ajout.
-app : effectue l'opération d'ajout en fin.
-rep : effectue l'opération de remplacement.
-inci : effectue l'opération d'incrémentation d'entier.
-incd : effectue l'opération d'incrémentation de nombre réel.
-sx : les données d'entrée sont évaluées comme une chaîne de données hexadécimales.
-rm : supprime l'enregistrement.
-px : les données de sortie sont converties en une chaîne de données hexadécimales.
-pz : n'ajoute pas de saut de ligne à la fin de la sortie.
-des : parcourt les enregistrements dans l'ordre décroissant.
-max num : spécifie le nombre maximum d'enregistrements affichés.
-pv : affiche également les valeurs des enregistrements.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
