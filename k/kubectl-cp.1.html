kubectl-cp(1)

Paquet: kubectl

Licences: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

NOM

kubectl cp - Copier des fichiers et répertoires vers et depuis des conteneurs

SYNTAXE

kubectl cp [OPTIONS]

DESCRIPTION

Copie des fichiers et répertoires vers et depuis des conteneurs.

OPTIONS

-c, --container="" Nom du conteneur. Si omis, utilisez l'annotation kubectl.kubernetes.io/default-container pour sélectionner le conteneur auquel se connecter ou le premier conteneur du pod sera choisi

--no-preserve=false Les permissions et la propriété du fichier/répertoire copié ne seront pas préservées dans le conteneur

--retries=0 Définit le nombre de tentatives pour effectuer une opération de copie à partir d'un conteneur. Spécifiez 0 pour désactiver ou toute valeur négative pour une nouvelle tentative infinie. La valeur par défaut est 0 (pas de nouvelle tentative).

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Le nom du cluster kubeconfig à utiliser

--context="" Le nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la porte d'accès de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, le scope du namespace pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie pas de délai d'attente pour les requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton porteur pour l'authentification auprès du serveur API

--user="" Le nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et sortir avec un code de sortie non nul

EXEMPLE

  # !!!Note importante!!!
  # Nécessite que le binaire 'tar' soit présent dans votre image conteneur.
  # Si 'tar' n'est pas présent, 'kubectl cp' échouera.
  #
  # Pour des cas d'utilisation avancés, tels que les liens symboliques,
  # l'expansion des jokers ou la préservation des modes de fichier,
  # envisagez d'utiliser 'kubectl exec'.
  # Copie le fichier local /tmp/foo vers /tmp/bar dans un pod distant dans le namespace <some-namespace>
  tar cf - /tmp/foo | kubectl exec -i -n <some-namespace> <some-pod> -- tar xf - -C /tmp/bar
  # Copie /tmp/foo d'un pod distant vers /tmp/bar localement
  kubectl exec -n <some-namespace> <some-pod> -- tar cf - /tmp/foo | tar xf - -C /tmp/bar
  # Copie le répertoire local /tmp/foo_dir vers /tmp/bar_dir dans un pod distant dans le namespace par défaut
  kubectl cp /tmp/foo_dir <some-pod>:/tmp/bar_dir
  # Copie le fichier local /tmp/foo vers /tmp/bar dans un pod distant dans un conteneur spécifique
  kubectl cp /tmp/foo <some-pod>:/tmp/bar -c <specific-container>
  # Copie le fichier local /tmp/foo vers /tmp/bar dans un pod distant dans le namespace <some-namespace>
  kubectl cp /tmp/foo <some-namespace>/<some-pod>:/tmp/bar
  # Copie /tmp/foo d'un pod distant vers /tmp/bar localement
  kubectl cp <some-namespace>/<some-pod>:/tmp/foo /tmp/bar
