NOM

kcatalogprint - utilitaire d'impression du catalogue Knot DNS

SYNTAXE

kcatalogprint [option_config] [options]

DESCRIPTION

Le programme imprime le catalogue de zones stocké dans une base de données de catalogue.

Options de configuration

-c, --config fichier
Utilise un fichier de configuration textuel (par défaut /etc/knot/knot.conf).
-C, --confdb répertoire
Utilise un répertoire de base de données de configuration binaire (par défaut /var/lib/knot/confdb). La base de données de configuration par défaut, si elle existe, a la priorité sur le fichier de configuration par défaut.
-D, --dir chemin
Utilise le chemin spécifié de la base de données du catalogue et la configuration par défaut.

Options

-a, --catalog
Filtre la sortie par le nom de la zone du catalogue.
-m, --member
Filtre la sortie par le nom de la zone membre.
-h, --help
Affiche l'aide du programme.
-V, --version
Affiche la version du programme. L'option -VV permet au programme d'afficher le résumé de la configuration au moment de la compilation.

VALEURS DE RETOUR

Un statut de sortie de 0 signifie une opération réussie. Tout autre statut de sortie indique une erreur.

VOIR AUSSI

knotd(8), knot.conf(5).
