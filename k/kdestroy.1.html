NOM

kdestroy - détruit les tickets Kerberos

SYNTAXE

kdestroy [-A] [-q] [-c nom_cache] [-p nom_principal]

DESCRIPTION

L'utilitaire kdestroy détruit les tickets d'autorisation Kerberos actifs de l'utilisateur en écrasant et en supprimant le cache d'identification qui les contient. Si le cache d'identification n'est pas spécifié, le cache d'identification par défaut est détruit.

OPTIONS

-A
Détruit tous les caches de la collection, si une collection de caches est disponible. Peut être utilisé avec l'option -c pour spécifier la collection à détruire.
-q
Exécute silencieusement. Normalement, kdestroy émet un bip s'il ne parvient pas à détruire les tickets de l'utilisateur. Le drapeau -q supprime ce comportement.
-c nom_cache
Utilise nom_cache comme nom et emplacement du cache d'identification (ticket) ; si cette option n'est pas utilisée, le nom et l'emplacement par défaut sont utilisés.

Le cache d'identification par défaut peut varier entre les systèmes. Si la variable d'environnement KRB5CCNAME est définie, sa valeur est utilisée pour nommer le cache de tickets par défaut.

-p nom_principal
Si une collection de caches est disponible, détruit le cache pour nom_principal au lieu du cache principal. Peut être utilisé avec l'option -c pour spécifier la collection à rechercher.

NOTE

La plupart des installations recommandent de placer la commande kdestroy dans votre fichier .logout, afin que vos tickets soient détruits automatiquement lorsque vous vous déconnectez.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.

FICHIERS
