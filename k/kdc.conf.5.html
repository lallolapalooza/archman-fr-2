kdc.conf - Fichier de configuration du KDC Kerberos

V5

Le fichier kdc.conf complète krb5.conf(5) pour les programmes qui sont généralement uniquement utilisés sur un KDC, tels que les démons krb5kdc(8) et kadmind(8) et le programme kdb5_util(8). Les relations documentées ici peuvent également être spécifiées dans krb5.conf ; pour les programmes KDC mentionnés, krb5.conf et kdc.conf seront fusionnés en un seul profil de

configuration.

Normalement, le fichier kdc.conf se trouve dans le répertoire d'état du KDC, /var/lib/krb5kdc. Vous pouvez remplacer l'emplacement par défaut en définissant la variable d'environnement KRB5_KDC_PROFILE

Chaque balise de la section [realms] est le nom d'un realm Kerberos. La valeur de la balise est une sous-section où les relations définissent les paramètres du KDC pour ce realm particulier. L'exemple suivant montre comment définir un paramètre pour le realm ATHENA.MIT.EDU

[dbmodules

La section [dbmodules] contient les paramètres utilisés par la bibliothèque de base de données du KDC et les modules de base de données. Chaque balise dans la section [dbmodules] est le nom d'un royaume Kerberos ou un nom de section spécifié par le paramètre database_module d'un royaume. L'exemple suivant montre comment définir un paramètre de base de données pour le royaume ATHENA.MIT.EDU

    ATHENA.MIT.EDU = {
        disable_last_success = true
}

ldap_kdc_dn et ldap_kadmind
_dn
Ces balises spécifiques à LDAP indiquent le DN par défaut pour la liaison au serveur LDAP. Le démon krb5kdc(8) utilise ldap_kdc_dn, tandis que le démon kadmind(8) et les autres programmes d'administration utilisent ldap_kadmind_dn. Le DN de kadmind doit avoir les droits de lire et d'écrire les données Kerberos dans la base de données LDAP. Le DN du KDC doit avoir les mêmes droits, sauf si disable_lockout et disable_last_success sont à true, auquel cas il n'a besoin que des droits de lecture des données Kerberos. Ces balises sont ignorées si un mécanisme SASL est défini avec ldap_kdc_sasl_mech ou ldap_kadmind_sasl_me
ch.

cid
