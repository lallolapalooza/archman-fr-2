NOM

kubectl config - Modifier les fichiers kubeconfig

SYNOPSIS

kubectl config [OPTIONS]

DESCRIPTION

Modifie les fichiers kubeconfig à l'aide de sous-commandes comme "kubectl config set current-context my-context".

L'ordre de chargement suit ces règles :

1.
Si le drapeau --kubeconfig est défini, alors seul ce fichier est chargé. Le drapeau ne peut être défini qu'une seule fois et aucune fusion n'a lieu.
2.
Si la variable d'environnement $KUBECONFIG est définie, alors elle est utilisée comme liste de chemins (règles de délimitation de chemin normales pour votre système). Ces chemins sont fusionnés. Lorsqu'une valeur est modifiée, elle est modifiée dans le fichier qui définit la section. Lorsqu'une valeur est créée, elle est créée dans le premier fichier qui existe. Si aucun fichier de la chaîne n'existe, alors il crée le dernier fichier de la liste.
3.
Sinon, ${HOME}/.kube/config est utilisé et aucune fusion n'a lieu.

OPTIONS

--kubeconfig="" utilise un fichier kubeconfig particulier

OPTIONS HÉRITÉES DE COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur ordinaire ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Le nom du cluster kubeconfig à utiliser

--context="" Le nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes adressées au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la porte d'accès de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, la portée de l'espace de noms pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier où écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une requête serveur unique. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas interrompre les requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification Bearer auprès du serveur API

--user="" Le nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw imprime les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul
