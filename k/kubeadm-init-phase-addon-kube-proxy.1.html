kubeadm-init-phase-addon-kube-proxy(1)

Eric Paris Jan 2015

NOM

kubeadm init phase addon kube-proxy - Installe le module complémentaire kube-proxy dans un cluster Kubernetes

SYNTAXE

kubeadm init phase addon kube-proxy [OPTIONS]

DESCRIPTION

Installe les composants du module complémentaire kube-proxy via le serveur API.

OPTIONS

--apiserver-advertise-address="" L'adresse IP sur laquelle le serveur API annoncera qu'il écoute. S'il n'est pas défini, l'interface réseau par défaut sera utilisée.

--apiserver-bind-port=6443 Port sur lequel le serveur API se liera.

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--control-plane-endpoint="" Spécifie une adresse IP stable ou un nom DNS pour le plan de contrôle.

--dry-run=false N'applique aucune modification ; affiche seulement ce qui serait fait.

--image-repository="registry.k8s.io" Choisit un registre de conteneurs pour télécharger les images du plan de contrôle.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser pour communiquer avec le cluster. Si l'indicateur n'est pas défini, un ensemble d'emplacements standard sera recherché pour un fichier kubeconfig existant.

--kubernetes-version="stable-1" Choisit une version spécifique de Kubernetes pour le plan de contrôle.

--pod-network-cidr="" Spécifie la plage d'adresses IP pour le réseau des pods. Si définie, le plan de contrôle attribuera automatiquement des CIDR à chaque nœud.

--print-manifest=false Affiche les manifestes des modules complémentaires sur la sortie standard au lieu de les installer.

OPTIONS HERITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée.
