Nom

kitten-unicode-input - Parcourir et sélectionner des caractères unicode par nom

Utilisation

kitten unicode-input

Description

Entrer un caractère Unicode

Options

--emoji-variation [=none]
Indique si l'on doit utiliser la forme textuelle ou graphique pour les emojis. Par défaut, la forme par défaut spécifiée dans la norme Unicode pour le symbole est utilisée.

Choix : none, graphic, text

--tab [=previous]
L'onglet initial à afficher. Par défaut, utilise l'onglet de l'invocation précédente de kitten.

Choix : previous, code, emoticons, favorites, name

--help, -h [=no]
Afficher l'aide pour cette commande
