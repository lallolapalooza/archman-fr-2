KATE(1) Manuel de l'utilisateur de Kate KATE(1)

NOM

kate - Éditeur de texte avancé de KDE

SYNTAXE

kate [-s, --start nom] [--startanon] [-n, --new] [-b, --block] [-p, --pid pid] [-e, --encoding nom] [-l, --line ligne] [-c, --column colonne] [-i, --stdin] [--tempfile] [fichier]

DESCRIPTION

Kate est l'éditeur de texte avancé de KDE.

Kate fournit également le composant éditeur pour diverses applications, sous le nom de KWrite.

Certaines des nombreuses fonctionnalités de Kate incluent la coloration syntaxique configurable pour des langages allant de C et C++ à HTML et aux scripts bash, la capacité de créer et de maintenir des projets, une interface multi-documents (MDI) et un émulateur de terminal autonome.

Mais Kate est plus qu'un éditeur pour programmeurs. Sa capacité à ouvrir plusieurs fichiers simultanément le rend idéal pour éditer les nombreux fichiers de configuration d'UNIX®. Ce document a été rédigé dans Kate.

OPTIONS

-s, --start nom

Démarre Kate avec une session donnée.

--startanon

Démarre Kate avec une nouvelle session anonyme, implique -n.

-n, --new

Force le démarrage d'une nouvelle instance de Kate (est ignoré si start est utilisé et qu'une autre instance de Kate a déjà ouvert la session donnée), forcé si aucun paramètre et aucune URL ne sont donnés du tout.

-b, --block

Si une instance de Kate déjà en cours d'exécution est utilisée, bloque jusqu'à ce qu'elle se termine, si des URL sont données à ouvrir.

-p, --pid pid

Tente uniquement de réutiliser l'instance kate avec ce pid (est ignoré si start est utilisé et qu'une autre instance de Kate a déjà ouvert la session donnée).

-e, --encoding nom

Définit le codage pour le fichier à ouvrir.

Vous pouvez l'utiliser pour forcer un fichier à s'ouvrir en format utf-8, par exemple. (La commande iconv -l fournit une liste de codages, qui pourrait vous être utile.)

-l, --line ligne

Navigue jusqu'à cette ligne.

-c, --column colonne

Navigue jusqu'à cette colonne.

-i, --stdin

Lit le contenu de l'entrée standard.

--tempfile

Les fichiers/URL ouverts par l'application seront supprimés après utilisation.

fichier

Fichier à ouvrir.

EXEMPLES

Pour ouvrir un fichier nommé source.cpp à la colonne 15, ligne 25, dans une fenêtre Kate existante, vous pourriez utiliser :

kate -c 15 -l 25 source.cpp

Si vous avez une connexion Internet active, vous pouvez profiter de la transparence réseau de KDE pour ouvrir un fichier depuis un site FTP. Si vous n'avez pas les droits d'écriture sur le serveur distant, le fichier sera ouvert en lecture seule et vous serez invité à indiquer un nom de fichier local pour l'enregistrement si vous apportez des modifications. Si vous avez les droits d'écriture, les modifications seront enregistrées de manière transparente sur le réseau.

kate ftp://ftp.kde.org/pub/kde/README
