NOM

keyctl_session_to_parent - définir le porte-clés de session du processus parent

SYNTAXE

#include <keyutils.h>

long keyctl_session_to_parent();

DESCRIPTION

keyctl_session_to_parent() change le porte-clés de session auquel le parent du processus appelant est abonné pour qu'il devienne celui du processus appelant.

Le porte-clés doit avoir la permission link disponible pour le processus appelant, le processus parent doit avoir les mêmes UIDs/GIDs que le processus appelant, et le LSM ne doit pas rejeter le remplacement. De plus, ceci ne peut pas être utilisé pour affecter init ou un thread du noyau.

Notez que le remplacement n'entrera pas en vigueur immédiatement pour le processus parent, mais sera plutôt différé à la prochaine fois qu'il reviendra dans l'espace utilisateur depuis l'espace noyau.

VALEUR DE RETOUR

En cas de succès, keyctl_session_to_parent() retourne 0. En cas d'erreur, la valeur -1 sera retournée et errno aura été définie avec une erreur appropriée.

ERREURS

ENOMEM
Mémoire insuffisante pour créer une clé.
EPERM
Les identifiants du parent ne correspondent pas à ceux de l'appelant.
EACCES
Le porte-clés nommé existe, mais n'est pas linkable par le processus appelant.

LIAISON

Il s'agit d'une fonction de bibliothèque qui se trouve dans libkeyutils. Lors de la liaison, -lkeyutils doit être spécifié à l'éditeur de liens.
