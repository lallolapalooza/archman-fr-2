NOM

kubeadm join phase control-plane-prepare kubeconfig - Générer le fichier kubeconfig pour les nouveaux composants du plan de contrôle

SYNTAXE

kubeadm join phase control-plane-prepare kubeconfig [OPTIONS]

DESCRIPTION

Génère le fichier kubeconfig pour les nouveaux composants du plan de contrôle.

OPTIONS

--certificate-key="" Utilise cette clé pour déchiffrer les secrets de certificat téléchargés par init. La clé de certificat est une chaîne codée en hexadécimal qui représente une clé AES de 32 octets.

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--control-plane=false Crée une nouvelle instance de plan de contrôle sur ce nœud.

--discovery-file="" Pour la découverte basée sur des fichiers, un fichier ou une URL à partir duquel charger les informations du cluster.

--discovery-token="" Pour la découverte basée sur des jetons, le jeton utilisé pour valider les informations du cluster récupérées auprès du serveur API.

--discovery-token-ca-cert-hash=[] Pour la découverte basée sur des jetons, valide que la clé publique racine de l'AC correspond à ce hachage (format : ":").

--discovery-token-unsafe-skip-ca-verification=false Pour la découverte basée sur des jetons, permet de rejoindre sans épinglage de --discovery-token-ca-cert-hash.

--dry-run=false Ne pas appliquer de changements ; simplement afficher ce qui serait fait.

--tls-bootstrap-token="" Spécifie le jeton utilisé pour s'authentifier temporairement auprès du plan de contrôle Kubernetes lors de la jonction du nœud.

--token="" Utilise ce jeton pour discovery-token et tls-bootstrap-token lorsque ces valeurs ne sont pas fournies.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à effectuer un chroot dans le chemin fourni.

--version=false --version, --version=raw imprime les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée.
