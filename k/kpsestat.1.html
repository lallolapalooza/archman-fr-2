KPSESTAT(1) Manuel des commandes générales KPSESTAT(1)

NOM

kpsestat - calculer le mode octal à partir du mode d'un fichier existant

SYNTAXE

kpsestat mode fichier

DESCRIPTION

kpsestat imprime les permissions octales de fichier modifiées selon mode sur la sortie standard. Le paramètre mode accepte un sous-ensemble des permissions symboliques acceptées par chmod(1). Utiliser = comme mode pour obtenir les permissions inchangées.

OPTIONS

kpsestat accepte les options suivantes :

--help
Afficher le message d'aide et quitter.
--version
Afficher les informations de version et quitter.

VOIR AUSSI

chmod(1).
