NOM

kpseaccess - déterminer si un fichier peut être accédé

SYNTAXE

kpseaccess mode fichier

DESCRIPTION

Termine avec succès si fichier peut être accédé avec le mode spécifié. Le mode est un tiret optionnel (`-') suivi de zéro ou plusieurs lettres parmi rwx, où r signifie lisible, w signifie inscriptible, et x signifie exécutable.

La différence entre kpseaccess et test est que ce dernier examine les bits de permission, tandis que le premier vérifie en utilisant l'appel système access(2). Cela fait une différence lorsque les systèmes de fichiers ont été montés en lecture seule.

OPTIONS

kpseaccess accepte les options suivantes :

--help
Affiche le message d'aide et quitte.
--version
Affiche les informations de version et quitte.
