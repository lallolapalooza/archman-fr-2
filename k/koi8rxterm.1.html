KOI8RXTERM(1) Système X Window KOI8RXTERM(1)

NOM

koi8rxterm - émulateur de terminal X pour environnements KOI8-R

SYNTAXE

koi8rxterm [ options-xterm ]

DESCRIPTION

koi8rxterm est un wrapper autour du programme xterm(1) qui invoque ce dernier avec la classe de ressource X “KOI8RXTerm” définie. Tous les arguments passés à koi8rxterm sont transmis à xterm sans traitement ; les options -class et -k8 ne doivent pas être spécifiées car elles sont utilisées par le wrapper. Voir la page de manuel xterm pour plus d'informations sur options-xterm.

Les paramètres régionaux de l'environnement (voir “ENVIRONNEMENT” ci-dessous) sont utilisés pour déterminer le jeu de caractères de la langue. Si aucune langue courante ne peut être déterminée, la langue “ru_RU.KOI8-R” (langue russe telle qu'utilisée en Russie, avec le jeu de caractères KOI8-R) est supposée. L'utilitaire locale(1) est utilisé pour déterminer si le système supporte la langue sélectionnée. Si ce n'est pas le cas, koi8rxterm se terminera avec une erreur et rapportera la sortie de locale.

Note : koi8rxterm peut produire des résultats inattendus si la langue courante est définie sur une langue pour laquelle le codage de caractères KOI8-R n'est pas supporté, ou si les polices utilisant ce codage ne sont pas disponibles. Dans le système Debian, le paquet “xfonts-cyrillic” fournit les polices que koi8rxterm utilise par défaut. Pour changer les polices utilisées par koi8rxterm, éditez le fichier /usr/share/X11/app-defaults//KOI8RXTerm.

Un wrapper similaire, uxterm(1), est disponible pour les environnements Unicode UTF-8.

ENVIRONNEMENT

LC_ALL, LC_CTYPE, LANG
Les valeurs de ces variables sont vérifiées, dans l'ordre, pour déterminer le jeu de caractères utilisé par la langue courante.

AUTEURS

koi8rxterm a été écrit par Branden Robinson et est très fortement basé sur uxterm, par Thomas Dickey. L'aide de Jurij Smakov a été inestimable pour vérifier la logique de son fonctionnement.

VOIR AUSSI

locale(1), locale(7), uxterm(1), xterm(1)
