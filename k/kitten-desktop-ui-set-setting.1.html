Nom

kitten-desktop-ui-set-setting - Modifier un paramètre arbitraire

Utilisation

kitten desktop-ui set-setting clé [valeur]

Description

Définit un paramètre arbitraire. Si vous souhaitez définir le schéma de couleurs, utilisez la commande dédiée. Utilisez cette commande avec précaution car elle n'effectue aucune validation sur le type de valeur. La syntaxe pour spécifier les valeurs est décrite dans la documentation glib. Omettre la valeur ou spécifier une valeur vide supprimera le paramètre.

Options

--namespace, -n [=org.freedesktop.appearance]
L'espace de noms dans lequel modifier le paramètre.
--data-type
La signature du type de données DBUS de la valeur. Par défaut, on essaie de la deviner à partir de sa représentation textuelle, voir la documentation glib pour les détails.
--help, -h [=non]
Afficher l'aide pour cette commande
