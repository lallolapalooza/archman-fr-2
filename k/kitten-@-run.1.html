Nom

kitten-@-run - Exécute un programme sur l'ordinateur où kitty est en cours d'exécution et récupère la sortie

Utilisation

kitten @ run CMD ...

Description

Exécute le programme spécifié sur l'ordinateur où kitty est en cours d'exécution. Lorsque STDIN n'est pas un TTY, il est transmis au programme en tant que son STDIN. STDOUT et STDERR du programme lui sont transmis. Le code de sortie de cette invocation sera le code de sortie du programme exécuté. Si vous souhaitez simplement exécuter un programme sans attendre de réponse, utilisez plutôt @ launch --type=background.

Options

--env
Variables d'environnement à définir dans le processus enfant. Peut être spécifié plusieurs fois pour définir différentes variables d'environnement. Syntaxe : nom=valeur. Utiliser nom= définira une chaîne vide et juste nom supprimera la variable d'environnement.
--allow-remote-control [=no]
Le programme exécuté aura les privilèges pour exécuter des commandes de contrôle à distance dans kitty.
--remote-control-password
Restreint les actions que le contrôle à distance est autorisé à effectuer. Cela fonctionne comme remote_control_password. Vous pouvez spécifier un mot de passe et une liste d'actions tout comme pour remote_control_password. Par exemple ::


--remote-control-password '"ma phrase secrète" get-* set-colors'

Ce mot de passe sera en vigueur pour cette fenêtre uniquement. Notez que tous les mots de passe que vous avez définis pour remote_control_password dans kitty.conf sont également en vigueur. Vous pouvez les remplacer en utilisant le même mot de passe ici. Vous pouvez également désactiver tous les mots de passe globaux de remote_control_password pour cette fenêtre, en utilisant ::


--remote-control-password '!'

Cette option ne prend effet que si --allow-remote-control est également spécifié. Peut être spécifié plusieurs fois pour créer plusieurs mots de passe. Cette option a été ajoutée à kitty dans la version 0.26.0

--help, -h [=no]
Afficher l'aide pour cette commande

Options globales

--to
Une adresse pour l'instance kitty à contrôler. Correspond à l'adresse donnée à l'instance kitty via l'option --listen-on ou le paramètre listen_on dans kitty.conf. Si non spécifié, la variable d'environnement KITTY_LISTEN_ON est vérifiée. Si celle-ci n'est pas non plus trouvée, les messages sont envoyés au terminal de contrôle de ce processus, c'est-à-dire qu'ils ne fonctionneront que si ce processus est exécuté dans une fenêtre kitty.
--password
Un mot de passe à utiliser lors du contact avec kitty. Cela demandera à kitty la permission de l'utilisateur d'effectuer l'action spécifiée, à moins que le mot de passe n'ait été accepté auparavant ou qu'il ne soit préconfiguré dans kitty.conf. Pour utiliser un mot de passe vide, spécifiez --use-password comme toujours.
--password-file [=rc-pass]
Un fichier à partir duquel lire le mot de passe. Les espaces blancs de fin sont ignorés. Les chemins relatifs sont résolus à partir du répertoire de configuration de kitty. Utilisez - pour lire depuis STDIN. Utilisez fd:num pour lire depuis le descripteur de fichier num. Utilisé si aucun --password n'est fourni. Par défaut, vérifie le fichier rc-pass dans le répertoire de configuration de kitty.
--password-env [=KITTY_RC_PASSWORD]
Le nom d'une variable d'environnement à partir de laquelle lire le mot de passe. Utilisé si aucun fichier --password-file n'est fourni. Par défaut, vérifie la variable d'environnement KITTY_RC_PASSWORD.
--use-password [=if-available]
Si aucun mot de passe n'est disponible, kitty enverra généralement la commande de contrôle à distance sans mot de passe. Cette option peut être utilisée pour forcer l'utilisation systématique ou jamais du mot de passe fourni. Si défini sur always et qu'aucun mot de passe n'est fourni, le mot de passe vide est utilisé.

Choix : if-available, always, never
