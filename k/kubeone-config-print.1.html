NOM

kubeone-config-print - Affiche un manifeste de configuration d'exemple

SYNOPSIS

kubeone config print [flags]

DESCRIPTION

Affiche un manifeste de configuration d'exemple. En utilisant les indicateurs appropriés, vous pouvez personnaliser le manifeste de configuration. Pour la référence complète du manifeste de configuration, exécutez la commande print avec l'indicateur --full.

OPTIONS

--api-endpoint-alternative-names=[] Liste des noms alternatifs de point d'accès API séparés par des virgules, exemple : host.com,192.16.0.100

--api-endpoint-host="" Nom d'hôte ou adresse du point d'accès API

--api-endpoint-port=6443 Port du point d'accès API

-n, --cluster-name="demo-cluster" Nom du cluster

--container-log-max-files=5 ContainerLogMaxFiles

--container-log-max-size="100Mi" ContainerLogMaxSize

--control-plane-hosts="" Hôtes du plan de contrôle au format d'une liste clé:valeur séparée par des virgules, exemple : publicAddress:192.168.0.100,privateAddress:192.168.1.100,sshUsername:ubuntu,sshPort:22. Utilisez une chaîne entre guillemets de valeurs séparées par des espaces pour plusieurs hôtes.

--deploy-machine-controller[=true] Déploie le contrôleur de machine kubermatic

--enable-dynamic-audit-log[=false] Active DynamicAuditLog

--enable-encryption-providers[=false] Active les fournisseurs de chiffrement

--enable-metrics-server[=true] Active le serveur de métriques

--enable-openid-connect[=false] Active l'authentification OpenID Connect

--enable-pod-node-selector[=false] Active le plugin d'admission PodNodeSelector

--enable-pod-security-policy[=false] Active PodSecurityPolicy. NE FAIT RIEN : cette fonctionnalité est supprimée

--enable-static-audit-log[=false] Active StaticAuditLog

-f, --full[=false] affiche le manifeste complet

-h, --help[=false] aide pour print

-k, --kubernetes-version="v1.32.5" Version de Kubernetes

--node-port-range="" Plage de ports à utiliser pour NodePort

--pod-subnet="" Sous-réseau à utiliser pour le réseau des pods

-p, --provider="aws" nom du fournisseur cloud (aws, digitalocean, gce, hetzner, equinixmetal, openstack, vsphere, none)

--proxy-http="" Proxy HTTP à utiliser pour le provisionnement et Docker

--proxy-https="" Proxy HTTPS à utiliser pour le provisionnement et Docker

--proxy-no-proxy="" Aucun proxy à utiliser pour le provisionnement et Docker

--service-dns="" Nom de domaine à utiliser pour les Services

--service-subnet="" Sous-réseau à utiliser pour les Services

OPTIONS INHERITED FROM PARENT COMMANDS

-c, --credentials="" Fichier à partir duquel charger les identifiants et secrets

-d, --debug[=false] sortie de débogage avec trace de la pile

-l, --log-format="text" format pour la journalisation

-m, --manifest="./kubeone.yaml" Chemin d'accès à la configuration KubeOne

-t, --tfjson="" Source de la sortie terraform en JSON - à lire depuis stdin. Si le chemin est un fichier, le contenu sera utilisé. Si le chemin est un dictionnaire, terraform output -json est exécuté dans ce chemin

-v, --verbose[=false] sortie détaillée

EXEMPLE

kubeone config print --provider digitalocean --kubernetes-version v1.32.5 --cluster-name example
