Nom

kitten-@-load-config - (Re)charger un fichier de configuration

Utilisation

kitten @ load-config FICHIER_CONF ...

Description

(Re)charge le(s) fichier(s) de configuration kitty.conf spécifié(s). Si aucun fichier n'est spécifié, le fichier de configuration précédemment spécifié est rechargé. Notez que les chemins spécifiés doivent exister et être lisibles par le processus kitty sur l'ordinateur où le processus s'exécute. Les chemins relatifs sont résolus par rapport au répertoire de configuration de kitty sur l'ordinateur exécutant kitty.

Options

--ignore-overrides [=no]
Par défaut, les éventuels remplacements de configuration spécifiés lors de l'invocation de kitty en ligne de commande ou lors d'une commande load-config-file précédente sont respectés. Utilisez cette option pour les ignorer à la place.
--override, -o
Remplace des options de configuration individuelles, peut être spécifié plusieurs fois. Syntaxe : nom=valeur. Par exemple : -o font_size=20
--no-response [=no]
N'attendez pas de réponse indiquant le succès de l'action. Notez que l'utilisation de cette option signifie que vous ne serez pas informé des échecs.
--help, -h [=no]
Afficher l'aide pour cette commande

Options globales

--to
Une adresse pour l'instance kitty à contrôler. Correspond à l'adresse donnée à l'instance kitty via l'option --listen-on ou le réglage listen_on dans kitty.conf. Si non spécifié, la variable d'environnement KITTY_LISTEN_ON est vérifiée. Si celle-ci n'est pas trouvée non plus, les messages sont envoyés au terminal de contrôle de ce processus, c'est-à-dire qu'ils ne fonctionneront que si ce processus est exécuté dans une fenêtre kitty.
--password
Un mot de passe à utiliser lors du contact avec kitty. Cela amènera kitty à demander la permission à l'utilisateur pour effectuer l'action spécifiée, sauf si le mot de passe a été accepté auparavant ou est préconfiguré dans kitty.conf. Pour utiliser un mot de passe vide, spécifiez --use-password as always.
--password-file [=rc-pass]
Un fichier à partir duquel lire le mot de passe. Les espaces de fin sont ignorés. Les chemins relatifs sont résolus à partir du répertoire de configuration de kitty. Utilisez - pour lire depuis STDIN. Utilisez fd:num pour lire depuis le descripteur de fichier num. Utilisé si aucun --password n'est fourni. Par défaut, vérifie le fichier rc-pass dans le répertoire de configuration de kitty.
--password-env [=KITTY_RC_PASSWORD]
Le nom d'une variable d'environnement à partir de laquelle lire le mot de passe. Utilisé si aucun --password-file n'est fourni. Par défaut, vérifie la variable d'environnement KITTY_RC_PASSWORD.
--use-password [=if-available]
Si aucun mot de passe n'est disponible, kitty envoie généralement la commande de contrôle à distance sans mot de passe. Cette option peut être utilisée pour forcer l'utilisation ou non du mot de passe fourni. Si défini sur always et qu'aucun mot de passe n'est fourni, le mot de passe vide est utilisé.

Choix : if-available, always, never
