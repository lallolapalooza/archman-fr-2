NOM

kded6 - Démon KDE - déclenche les mises à jour de la base de données Sycoca au besoin.

SYNTAXE

kded6 [--check]

DESCRIPTION

kded6 consolide plusieurs petits services en un seul processus. Ce sont principalement des services D-Bus fournis par des modules KDED, mais il gère également sycoca (un cache binaire des types de services, types MIME et services utilisés par KService) et les scripts de mise à jour KConfig au besoin.

Pour sycoca, il surveille les répertoires contenant les fichiers .desktop. Lorsqu'un fichier est ajouté/supprimé, il attend 5 secondes (en cas de série de mises à jour), puis lance kbuildsycoca6 pour mettre à jour le sycoca.

Pour KConfig, il vérifie les fichiers de mise à jour nouvellement installés, c'est-à-dire les fichiers .upd utilisés pour mettre à jour les fichiers de configuration des utilisateurs lorsque les formats de fichiers de configuration changent, et exécute l'utilitaire de mise à jour KConfig pour effectuer les mises à jour.

Ces tâches sont également exécutées lorsque kded6 est lancé pour s'assurer que la configuration de l'utilisateur est à jour.

Vous n'avez normalement pas besoin d'exécuter kded6 directement ; les sessions de bureau Plasma l'exécutent automatiquement, et il est démarré à la demande lorsqu'une application tente d'utiliser une interface D-Bus qu'il fournit ou l'une de ses modules.

OPTIONS

--check

Vérifie la base de données sycoca, la met à jour si nécessaire, puis quitte.

CONFIGURATION

kded6 peut être configuré avec le fichier de configuration de style ini kded5rc. Sur les systèmes UNIX®, celui-ci se trouve dans $XDG_CONFIG_HOME/kded5rc ; si $XDG_CONFIG_HOME n'est pas défini, celui-ci est par défaut ~/.config/kded5rc.

Les entrées du fichier de configuration sont lues à la demande, donc des modifications peuvent être apportées pendant que kded6 est en cours d'exécution. Cependant, toutes les options de configuration actuelles n'affectent réellement que le comportement de démarrage de kded6.

La section [General] a les options suivantes :

CheckSycoca

Mise à jour de sycoca au démarrage (par défaut : true).

CheckUpdates

Effectue les mises à jour KConfig en attente au démarrage (par défaut : true).

CheckFileStamps

Vérifie les horodatages des fichiers lors de la mise à jour initiale de sycoca (par défaut : true). Voir la documentation de kbuildsycoca6 pour plus de détails.

DelayedCheck

Retarde la mise à jour initiale de sycoca jusqu'à environ une minute après le démarrage (par défaut : false).

Chaque module a également une section [Module-nom] dans kded5rc, où nom est le nom du fichier desktop du module sans l'extension .desktop. Celle-ci contient une option autoload qui spécifie si le module doit être chargé automatiquement lorsque kded6 est démarré (par défaut : false). Notez que ce paramètre peut également être modifié via l'interface D-Bus de kded6.
