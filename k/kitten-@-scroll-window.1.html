Nom

kitten-@-scroll-window - Fait défiler les fenêtres spécifiées

Utilisation

kitten @ scroll-window QUANTITÉ_DE_DÉFILEMENT

Description

Fait défiler les fenêtres spécifiées. Si aucune fenêtre n'est spécifiée, fait défiler la fenêtre dans laquelle cette commande est exécutée. QUANTITÉ_DE_DÉFILEMENT peut être les mots-clés start (début) ou end (fin), ou un argument de la forme <nombre>[unité][+-]. L'unité peut être l pour les lignes, p pour les pages, u pour annuler le défilement et r pour défiler vers l'invite. Si elle n'est pas spécifiée, l est la valeur par défaut. Par exemple, 30 fera défiler vers le bas de 30 lignes, 2p- fera défiler vers le haut de 2 pages et 0.5p fera défiler vers le bas d'une demi-page. 3u *annulera* le défilement de 3 lignes, ce qui signifie que 3 lignes passeront du tampon de défilement vers le haut de l'écran. 1r- fera défiler vers l'invite précédente et 1r vers l'invite suivante. Voir scroll_to_prompt pour plus de détails sur le fonctionnement du défilement vers l'invite.

Options

--match, -m
La fenêtre à faire correspondre. Les spécifications de correspondance sont de la forme : champ:requête. Où champ peut être l'un des éléments suivants : id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session et recent. requête est l'expression à faire correspondre. Les expressions peuvent être soit un nombre, soit une expression régulière, et peuvent être combinées à l'aide d'opérateurs booléens.

La valeur spéciale all correspond à toutes les fenêtres.

Pour les champs numériques : id, pid, num et recent, l'expression est interprétée comme un nombre, pas comme une expression régulière. Les valeurs négatives pour id correspondent à partir du plus grand numéro d'id vers le bas, en particulier, -1 est la fenêtre la plus récemment créée.

Le champ num fait référence à la position de la fenêtre dans l'onglet actuel, en commençant par zéro et en comptant dans le sens des aiguilles d'une montre (c'est le même ordre que celui dans lequel les fenêtres sont rapportées par la commande kitten @ ls).

L'id de la fenêtre de la fenêtre actuelle est disponible sous forme de la variable d'environnement KITTY_WINDOW_ID.

Le champ recent fait référence aux fenêtres récemment actives dans l'onglet actif actuel, zéro étant la fenêtre active actuelle, un étant la fenêtre précédemment active, et ainsi de suite.

Le champ neighbor fait référence à un voisin de la fenêtre active dans la direction spécifiée, qui peut être : left (gauche), right (droite), top (haut) ou bottom (bas).

Le champ session correspond aux fenêtres qui ont été créées dans la session spécifiée. Utilisez l'expression ^$ pour correspondre aux fenêtres qui n'ont pas été créées dans une session et . pour correspondre à la session active actuelle et ~ pour correspondre soit à la session active actuelle, soit à la dernière session active lorsqu'aucune session n'est active.

Lorsque vous utilisez le champ env pour correspondre aux variables d'environnement, vous pouvez spécifier uniquement le nom de la variable d'environnement ou un nom et une valeur, par exemple, env:MY_ENV_VAR=2.

De même, le champ var correspond aux variables utilisateur définies sur la fenêtre. Vous pouvez spécifier le nom ou le nom et la valeur comme avec le champ env.

Le champ state correspond à l'état de la fenêtre. Les états pris en charge sont : active, focused (concentrée), needs_attention (nécessite une attention), parent_active, parent_focused, focused_os_window, self, overlay_parent. Les fenêtres actives sont les fenêtres actives dans leur onglet parent. Il n'y a qu'une seule fenêtre concentrée et c'est la fenêtre à laquelle les événements clavier sont délivrés. Si aucune fenêtre n'est concentrée, la dernière fenêtre concentrée est mise en correspondance. La valeur focused_os_window correspond à toutes les fenêtres de la fenêtre OS actuellement concentrée. La valeur self correspond à la fenêtre dans laquelle la commande de contrôle à distance est exécutée. La valeur overlay_parent correspond à la fenêtre qui se trouve sous la fenêtre self, lorsque la fenêtre self est une superposition.

Notez que vous pouvez utiliser la commande kitten @ ls pour obtenir une liste des fenêtres.

--no-response [=no]
N'attendez pas de réponse indiquant le succès de l'action. Notez que l'utilisation de cette option signifie que vous ne serez pas informé des échecs.
--help, -h [=no]
Afficher l'aide pour cette commande

Options globales

--to
Une adresse pour l'instance kitty à contrôler. Correspond à l'adresse donnée à l'instance kitty via l'option --listen-on ou le paramètre listen_on dans kitty.conf. Si elle n'est pas spécifiée, la variable d'environnement KITTY_LISTEN_ON est vérifiée. Si elle n'est pas non plus trouvée, les messages sont envoyés au terminal de contrôle de ce processus, c'est-à-dire qu'ils ne fonctionneront que si ce processus est exécuté dans une fenêtre kitty.
--password
Un mot de passe à utiliser lors du contact avec kitty. Cela incitera kitty à demander à l'utilisateur la permission d'effectuer l'action spécifiée, sauf si le mot de passe a été accepté auparavant ou est préconfiguré dans kitty.conf. Pour utiliser un mot de passe vide, spécifiez --use-password comme toujours.
--password-file [=rc-pass]
Un fichier à partir duquel lire le mot de passe. Les espaces de fin sont ignorés. Les chemins relatifs sont résolus à partir du répertoire de configuration de kitty. Utilisez - pour lire depuis STDIN. Utilisez fd:num pour lire depuis le descripteur de fichier num. Utilisé si aucun --password n'est fourni. La valeur par défaut est de vérifier le fichier rc-pass dans le répertoire de configuration de kitty.
--password-env [=KITTY_RC_PASSWORD]
Le nom d'une variable d'environnement à partir de laquelle lire le mot de passe. Utilisé si aucun --password-file n'est fourni. La valeur par défaut est de vérifier la variable d'environnement KITTY_RC_PASSWORD.
--use-password [=if-available]
Si aucun mot de passe n'est disponible, kitty enverra généralement la commande de contrôle à distance sans mot de passe. Cette option peut être utilisée pour forcer l'utilisation systématique ou jamais du mot de passe fourni. Si défini sur always et qu'aucun mot de passe n'est fourni, le mot de passe vide est utilisé.

Choix : if-available, always, never
