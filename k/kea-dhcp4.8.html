NOM

kea-dhcp4 - Serveur DHCPv4 dans Kea

SYNTAXE

kea-dhcp4 [-v] [-V] [-W] [-d] [-c fichier-config] [-t fichier-config] [-p numéro-port-serveur] [-P numéro-port-client]

DESCRIPTION

Le démon kea-dhcp4 fournit l'implémentation du serveur DHCPv4.

ARGUMENTS

Les arguments sont les suivants :

-v
Affiche la version de Kea.
-V
Affiche la version étendue de Kea.
-W
Affiche le rapport de configuration.
-d
Active le mode de débogage avec une verbosité supplémentaire.
-c fichier-config
Spécifie le fichier de configuration pour le serveur DHCPv4. Il peut également contenir des entrées de configuration pour d'autres services Kea.
-t fichier-config
Vérifie le fichier de configuration et signale la première erreur, le cas échéant. Notez que tous les paramètres ne sont pas complètement vérifiés ; en particulier, les sockets de service et de canal de contrôle ne sont pas ouverts, et les bibliothèques de hooks ne sont pas chargées.
-T fichier-config
Vérifie le fichier de configuration et signale la première erreur, le cas échéant. Il effectue des vérifications supplémentaires au-delà de ce qu'offre -t, comme l'établissement de connexions à la base de données (pour le backend de baux, le backend de réservations d'hôtes, le backend de configuration et le backend de journalisation forensique), le chargement des bibliothèques de hooks, l'analyse des configurations de bibliothèques de hooks, etc. Il n'ouvre pas de sockets UNIX ou TCP/UDP, et n'ouvre ni ne fait pivoter de fichiers, car chacune de ces actions pourrait interférer avec un processus en cours d'exécution sur la même machine.
-p numéro-port-serveur
Spécifie le numéro de port du serveur (1-65535) sur lequel le serveur écoute. Ceci est utile uniquement à des fins de test.
-P numéro-port-client
Spécifie le numéro de port client (1-65535) auquel le serveur répond. Ceci est utile uniquement à des fins de test.

DOCUMENTATION

Kea est livré avec un manuel de référence complet pour l'administrateur Kea qui couvre tous les aspects de l'exécution du logiciel Kea - compilation, installation, configuration, exemples de configuration, et bien plus encore. Kea dispose également d'un manuel des messages Kea, qui liste tous les messages possibles que Kea peut afficher avec une brève description pour chacun d'eux. Les deux documents sont disponibles dans divers formats (.txt, .html, .pdf) avec la distribution Kea. La documentation Kea est disponible à l'adresse https://kea.readthedocs.io.

Le code source de Kea est documenté dans le guide du développeur Kea, disponible à l'adresse https://reports.kea.isc.org/dev_guide/.

Le site web du projet Kea est disponible à l'adresse https://kea.isc.org.

LISTES DE DIFFUSION ET SUPPORT

Il existe deux listes de diffusion publiques disponibles pour le projet Kea. kea-users (kea-users at lists.isc.org) est destinée aux utilisateurs de Kea, tandis que kea-dev (kea-dev at lists.isc.org) est destinée aux développeurs de Kea, aux contributeurs potentiels et à d'autres utilisateurs avancés. Les deux listes sont disponibles à l'adresse https://lists.isc.org. La communauté fournit un support au meilleur effort sur ces deux listes.

ISC fournit un support professionnel pour les services Kea. Voir https://www.isc.org/kea/ pour plus de détails.

HISTORIQUE

Le démon b10-dhcp4 a été codé pour la première fois en novembre 2011 par Tomek Mrugalski.

Mi-2014, Kea a été découplé du framework BIND 10 et est devenu un serveur DHCP autonome. L'exécutable du serveur DHCPv4 a été renommé en kea-dhcp4. Kea 1.0.0 est sorti en décembre 2015.
