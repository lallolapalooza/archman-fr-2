NOM

Kaleidescope - segments de ligne en rotation

SYNOPHIS

kaleidescope [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--install] [--visual visuel] [--color_mode mono | nice | greedy] [-nsegments int] [--ntrails int] [--local_rotation int] [--global_rotation int] [--delay usecs] [--redmin int] [--greenmin int] [--bluemin int] [--redrange int] [--greenrange int] [--bluerange int] [--fps]

DESCRIPTION

Le programme kaleidescope dessine des segments de ligne dans un motif symétrique qui évolue avec le temps.

OPTIONS

kaleidescope accepte les options suivantes :

--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--color_mode mono | nice | greedy
Spécifier comment kaleidescope utilise les couleurs. Mono utilise uniquement les couleurs par défaut de premier plan et d'arrière-plan. Nice utilise une couleur pour chaque segment (spécifiée par nsegments). Greedy utilise (ntrails * nsegments) + 1 couleurs.
--install
Installer une carte de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou l'identifiant numérique (décimal ou hexadécimal) d'un visuel spécifique.
--nsegments entier
Le nombre de segments à dessiner. La valeur par défaut est 7.
--ntrails entier
Le nombre de traînées à dessiner. La valeur par défaut est 100.
--local_rotation entier
La vitesse à laquelle les segments tournent autour de leur centre. La valeur par défaut est -59.
--global_rotation entier
La vitesse à laquelle les segments tournent autour du centre de la fenêtre. La valeur par défaut est 1.
--redmin, --greenmin, --bluemin, --redrange, --greenrange, --bluerange
Prennent tous un argument entier. Lorsque les couleurs sont choisies aléatoirement, elles sont choisies dans l'intervalle min à min plus range. Les minimums par défaut sont de 30000. Les ranges par défaut sont de 20000.
--delay microsecondes
Quel délai introduire entre les étapes de l'animation. La valeur par défaut est 20000, soit environ 5 images par seconde.
--fps
Afficher la fréquence d'images actuelle et la charge du CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
