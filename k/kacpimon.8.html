NOM

kacpimon - Moniteur d'événements ACPI du noyau

SYNOPIS

kacpimon

DESCRIPTION

kacpimon est un programme de surveillance qui se connecte à trois sources d'événements ACPI :

1. /proc/acpi/event
2. netlink
3. la couche d'entrée (/dev/input/event*)

kacpimon rend ensuite compte de ce qu'il voit pendant qu'il est connecté.

Utilisez kacpimon pour vous assurer que votre noyau envoie les événements liés à l'ACPI via les trois sources mentionnées ci-dessus.

Comme acpid(8) et kacpimon se connectent aux mêmes sources, assurez-vous d'arrêter acpid(8) avant d'exécuter kacpimon. Si vous utilisez upstart(7), utilisez initctl(8) pour arrêter acpid(8). Si vous utilisez systemd(1), utilisez systemctl(1) pour arrêter acpid(8). Si vous n'utilisez aucun de ceux-ci, vous pouvez essayer killall(1) pour arrêter acpid(8).

Assurez-vous d'exécuter kacpimon en tant que root, sinon il ne pourra pas ouvrir /proc/acpi/event ou la couche d'entrée :

sudo kacpimon

Si vous souhaitez rediriger la sortie de kacpimon vers un fichier, assurez-vous d'utiliser la touche "Esc" pour quitter plutôt que Ctrl-C. L'utilisation de Ctrl-C entraînera la perte de sortie.

FICHIERS

/proc/acpi/event
fichier d'événements ACPI du noyau
/dev/input/event*
fichiers d'événements de la couche d'entrée

VOIR AUSSI

acpi_listen(8), acpid(8)
