key_setsecret(3) Manuel des fonctions de bibliothèque key_setsecret(3)

NOM

key_decryptsession, key_encryptsession, key_setsecret, key_gendes, key_secretkey_is_set - interfaces vers le démon keyserver rpc

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <rpc/rpc.h>
int key_decryptsession(char *remotename, des_block *deskey);
int key_encryptsession(char *remotename, des_block *deskey);
int key_gendes(des_block *deskey);
int key_setsecret(char *key);
int key_secretkey_is_set(void);

DESCRIPTION

Les fonctions ici sont utilisées dans le mécanisme d'authentification sécurisé de RPC (AUTH_DES). Les programmes utilisateur n'ont normalement pas besoin d'utiliser ces fonctions.

La fonction key_decryptsession() utilise le nom de réseau (distant) du serveur et prend la clé DES pour le déchiffrement. Elle utilise la clé publique du serveur et la clé secrète associée à l'UID effectif du processus appelant.

La fonction key_encryptsession() est l'inverse de key_decryptsession(). Elle chiffre les clés DES avec la clé publique du serveur et la clé secrète associée à l'UID effectif du processus appelant.

La fonction key_gendes() est utilisée pour demander au keyserver une clé de conversation sécurisée.

La fonction key_setsecret() est utilisée pour définir la clé pour l'UID effectif du processus appelant.

La fonction key_secretkey_is_set() peut être utilisée pour déterminer si une clé a été définie pour l'UID effectif du processus appelant.

VALEUR DE RETOUR

Ces fonctions retournent 1 en cas de succès et 0 en cas d'échec.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
key_decryptsession (), key_encryptsession (), key_gendes (), key_setsecret (), key_secretkey_is_set () Sécurité des threads MT-Safe

NOTES

Notez que nous parlons ici de deux types de chiffrement. L'un est asymétrique utilisant une clé publique et une clé secrète. L'autre est symétrique, le DES 64 bits.

Ces routines faisaient partie du projet Linux/Doors, abandonné maintenant.
