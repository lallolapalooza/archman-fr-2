NOM

kubectl plugin list - Lister tous les exécutables de plugin visibles sur le PATH de l'utilisateur

SYNTAXE

kubectl plugin list [OPTIONS]

DESCRIPTION

Lister tous les fichiers de plugin disponibles sur le PATH de l'utilisateur. Pour voir les noms des binaires des plugins sans le chemin complet, utilisez l'option --name-only.

Les fichiers de plugin disponibles sont ceux qui sont : - exécutables - n'importe où sur le PATH de l'utilisateur - commencent par « kubectl- »

OPTIONS

--name-only=false Si vrai, affiche uniquement le nom binaire de chaque plugin, plutôt que son chemin complet

OPTIONS HERITEES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes vers le serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Cela peut être désactivé en exportant KUBECTL_KUBERC=false, un porteur de fonctionnalité, ou en désactivant le porteur de fonctionnalité KUBERC=off.

--match-server-version=false Exige que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, l'espace de noms de portée pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. L'un des suivants (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" Durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie pas de délai d'attente pour les requêtes.

-s, --server="" Adresse et port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification Bearer auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée

--warnings-as-errors=false Traite les avertissements reçus du serveur comme des erreurs et sort avec un code de sortie non nul

EXEMPLE

  # Lister tous les plugins disponibles
  kubectl plugin list
  # Lister uniquement les noms binaires des plugins disponibles sans chemins
  kubectl plugin list --name-only
