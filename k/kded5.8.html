KDED5(8) Manuel de l'utilisateur kded5 KDED5(8)

NOM

kded5 - démon KDE - déclenche les mises à jour de la base de données Sycoca si nécessaire.

SYNTAXE

kded5 [--check]

DESCRIPTION

kded5 consolide plusieurs petits services dans un seul processus. Il s'agit principalement de services D-Bus fournis par les modules KDED, mais il gère également sycoca (un cache binaire des types de services, des types MIME et des services utilisés par KService) et les scripts de mise à jour KConfig au besoin.

Pour sycoca, il surveille les répertoires contenant des fichiers .desktop. Lorsqu'un fichier est ajouté/supprimé, il attend 5 secondes (en cas de série de mises à jour), puis lance kbuildsycoca5 pour mettre à jour le sycoca.

Pour KConfig, il vérifie les fichiers de mise à jour nouvellement installés, c'est-à-dire les fichiers *.upd utilisés pour mettre à jour les fichiers de configuration des utilisateurs lorsque les formats de fichiers de configuration changent, et exécute l'utilitaire de mise à jour KConfig pour effectuer les mises à jour.

Ces tâches sont également exécutées lorsque kded5 est lancé pour s'assurer que la configuration de l'utilisateur est à jour.

Normalement, vous n'avez pas besoin de lancer kded5 directement; les sessions de bureau Plasma le lancent automatiquement, et il est démarré à la demande lorsqu'une application tente d'utiliser une interface D-Bus fournie par lui ou l'un de ses modules.

OPTIONS

--check

Vérifie la base de données sycoca, la met à jour si nécessaire, puis quitte.

CONFIGURATION

kded5 peut être configuré avec le fichier de configuration style ini kded5rc. Sur les systèmes UNIX®, on le trouve dans $XDG_CONFIG_HOME/kded5rc; si $XDG_CONFIG_HOME n'est pas défini, il s'agit par défaut de ~/.config/kded5rc.

Les entrées du fichier de configuration sont lues à la demande, ainsi des modifications peuvent être apportées pendant que kded5 est en cours d'exécution. Cependant, toutes les options de configuration actuelles n'affectent réellement que le comportement de démarrage de kded5.

La section [General] a les options suivantes :

CheckSycoca

Si sycoca doit être mis à jour au démarrage (par défaut : true).

CheckUpdates

Si les mises à jour KConfig en attente doivent être effectuées au démarrage (par défaut : true).

CheckFileStamps

Si les horodatages des fichiers doivent être vérifiés lors de la mise à jour initiale de sycoca (par défaut : true). Voir la documentation de kbuildsycoca5 pour plus de détails.

DelayedCheck

Si la mise à jour initiale de sycoca doit être retardée jusqu'à environ une minute après le démarrage (par défaut : false).

Chaque module a également une section [Module-name] dans kded5rc, où name est le nom du fichier desktop du module sans l'extension .desktop. Elle contient une option autoload qui spécifie si le module doit être chargé automatiquement au démarrage de kded5 (par défaut : false). Notez que ce paramètre peut également être modifié via l'interface D-Bus de kded5.

VOIR AUSSI

kbuildsycoca5(8), kdeinit5(8)
