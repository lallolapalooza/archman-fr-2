NOM

keymod - Modifie les paramètres de clé dans un fichier keyrec de DNSSEC-Tools

SYNOPIS

keymod [options] keyrec1 ... keyrecN

DESCRIPTION

keymod modifie les paramètres de clé dans un fichier keyrec utilisés pour générer les clés cryptographiques servant à signer les zones. Les nouveaux paramètres seront utilisés par zonesigner lors de la génération de nouvelles clés. Cela n'a aucun effet sur les clés existantes.

zonesigner utilisera le nouveau paramètre pour une zone la prochaine fois qu'il générera une clé nécessitant ce paramètre. Cela signifie que, par exemple, une nouvelle longueur de ZSK ne sera pas utilisée lors de la prochaine invocation de zonesigner si cette invocation effectue des actions de rotation de KSK.

Les champs suivants peuvent être modifiés :

kskcount - nombre de clés KSK
ksklength - longueur des clés KSK
ksklife - durée de vie des clés KSK
random - fichier de périphérique du générateur de nombres aléatoires
revperiod - période de révocation des clés KSK
zskcount - nombre de clés ZSK
zsklength - longueur des clés ZSK
zsklife - durée de vie des clés ZSK

De nouveaux champs clé/valeur seront ajoutés à un fichier keyrec de zone pour informer zonesigner que de nouvelles valeurs doivent être utilisées. La partie clé des champs ajoutés commencera par "new_". Par exemple, une nouvelle longueur de KSK de 2048 sera écrite dans le fichier keyrec comme suit :

new_ksklength        2048

Tous les enregistrements de zone dans le fichier keyrec spécifié seront modifiés, sauf si l'option -zone est donnée. Dans ce cas, seule la zone nommée sera modifiée.

Si un fichier keyrec de zone contient déjà un nouveau champ clé/valeur, la valeur sera modifiée lors des exécutions ultérieures de keymod.

OPTIONS

keymod reconnaît les options suivantes. Plusieurs options peuvent être combinées lors d'une seule exécution de keymod.

Toutes les valeurs numériques doivent être positives ou nulles.

Si un nouveau champ clé/valeur doit être supprimé d'un keyrec de zone, une valeur nulle ou une chaîne vide doit être spécifiée pour l'option appropriée.

-zone nom_zone
Le fichier keyrec de zone dont le nom correspond à nom_zone est sélectionné comme seul keyrec à modifier. Si ce nom n'est pas donné, tous les enregistrements keyrec de zone seront modifiés.
-ksklength longueur_ksk
Le champ longueur_ksk sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ numérique dont les valeurs dépendent de l'algorithme cryptographique à utiliser pour générer les clés de la zone.
-kskcount nombre_ksk
Le champ nombre_ksk sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ numérique.
-ksklife duree_vie_ksk
Le champ duree_vie_ksk sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ numérique.
-random aleatoire
Le champ aleatoire sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ texte qui sera passé au générateur de clés.
-revperiod periode_revocation
Le champ periode_revocation sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ numérique.
-zskcount nombre_zsk
Le champ nombre_zsk sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ numérique.
-zsklength longueur_zsk
Le champ longueur_zsk sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ numérique dont les valeurs dépendent de l'algorithme cryptographique à utiliser pour générer les clés de la zone.
-zsklife duree_vie_zsk
Le champ duree_vie_zsk sera modifié dans les enregistrements keyrec sélectionnés pour prendre la valeur donnée. Il s'agit d'un champ numérique.
-nocheck
Si cette option est donnée, la commande krfcheck ne sera pas exécutée sur le fichier keyrec modifié.
-verbose
Affiche des informations sur chaque modification apportée au fichier keyrec.
-Version
Affiche les informations de version pour keymod et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.
