Nom

kitten-quick-access-terminal - Un terminal d'accès rapide que vous pouvez faire apparaître instantanément par une combinaison de touches ou une commande.

Aperçu

Ajouté dans la version 0.42.0 : Voir ici sur quelles plateformes il fonctionne <#panel-compat>.

Ce kitten peut être utilisé pour créer un terminal d'accès rapide, qui apparaît et disparaît sur une pression de touche. Pour ce faire, utilisez la commande suivante :

kitten quick-access-terminal

Exécutez cette commande dans un terminal, et une fenêtre kitty d'accès rapide apparaîtra en haut de votre écran. Exécutez-la à nouveau, et la fenêtre sera masquée.

Pour faire apparaître et disparaître le terminal par une pression de touche :

Sous Linux, associez simplement la commande ci-dessus à un raccourci global dans votre gestionnaire de fenêtres. Sous macOS, allez dans Préférences Système->Clavier->Raccourcis Clavier->Services->Général et définissez un raccourci pour l'entrée Accès rapide à kitty.

Configuration

Vous pouvez configurer l'apparence et le comportement de la fenêtre d'accès rapide en créant un fichier quick-access-terminal.conf dans votre dossier de configuration kitty <#confloc>. En particulier, vous pouvez utiliser l'option kitty_conf pour modifier divers paramètres de kitty, uniquement pour la fenêtre d'accès rapide.

Remarque :

Ce kitten utilise le kitten de panneau <> en arrière-plan. Vous pouvez utiliser les techniques décrites là <#remote-control-panel> pour le contrôle à distance de la fenêtre d'accès rapide, n'oubliez pas d'ajouter kitty_override allow_remote_control=socket-only et kitty_override listen_on=unix:/tmp/quelquechose à quick-access-terminal.conf.

Voir ci-dessous pour les directives de configuration prises en charge :

Apparence de la fenêtre

lignes
lignes 25

Le nombre de lignes affichées dans le panneau. Ignoré pour les panneaux d'arrière-plan, centrés et verticaux. S'il a le suffixe px, il définit la hauteur du panneau en pixels plutôt qu'en lignes.

colonnes
colonnes 80

Le nombre de colonnes affichées dans le panneau. Ignoré pour les panneaux d'arrière-plan, centrés et horizontaux. S'il a le suffixe px, il définit la largeur du panneau en pixels plutôt qu'en colonnes.

bord
bord supérieur

Quel bord de l'écran placer le panneau. Notez que certains gestionnaires de fenêtres (comme i3) ne prennent pas en charge le placement des fenêtres ancrées sur les bords gauche et droit. La valeur background signifie faire du panneau le "fond d'écran". Notez qu'en utilisant sway, si vous définissez un arrière-plan dans votre configuration sway, il couvrira l'arrière-plan dessiné avec ce kitten. De plus, il existe trois autres valeurs : center, center-sized et none. La valeur center ancre le panneau à tous les bords et couvre tout l'écran (sur macOS, la partie de l'écran non couverte par la barre de titre et le dock). Le panneau peut être réduit et placé à l'aide des paramètres de marge. La valeur none ancre le panneau dans le coin supérieur gauche et doit être placé à l'aide des paramètres de marge. Sa taille est définie par lines et columns. La valeur center-sized est identique à none sauf que le panneau est centré au lieu d'être dans le coin supérieur gauche et que les marges n'ont aucun effet.

opacité_arrière_plan
opacité_arrière_plan 0.85

L'opacité de l'arrière-plan de la fenêtre. Cela fonctionne de la même manière que l'option kitty du même nom, elle est présente ici car elle a une valeur par défaut différente pour le terminal d'accès rapide.

masquer_perte_focus
masquer_perte_focus non

Masquer la fenêtre lorsqu'elle perd automatiquement le focus du clavier. L'utilisation de cette option forcera focus_policy à on-demand.

capture_clavier
capture_clavier non

Capture le clavier. Cela signifie que les raccourcis globaux définis dans le système d'exploitation seront envoyés à kitty à la place. Utile si vous souhaitez créer une fenêtre modale du système d'exploitation. L'efficacité de cette fonction dépend du système d'exploitation/gestionnaire de fenêtres/environnement de bureau. Sur Wayland, cela ne fonctionne que si le compositeur implémente le protocole d'inhibition des raccourcis clavier https://wayland.app/protocols/keyboard-shortcuts-inhibit-unstable-v1. Sur macOS, Apple n'autorise pas les applications à capturer le clavier sans autorisations spéciales, donc cela ne fonctionne pas.

marge_gauche
marge_gauche 0

Définit la marge gauche du panneau, en pixels. N'a aucun effet sur les panneaux du bord droit. Fonctionne uniquement sur macOS et les compositeurs Wayland qui prennent en charge le protocole wlr layer shell.

marge_droite
marge_droite 0

Définit la marge droite du panneau, en pixels. N'a aucun effet sur les panneaux du bord gauche. Fonctionne uniquement sur macOS et les compositeurs Wayland qui prennent en charge le protocole wlr layer shell.

marge_haut
marge_haut 0

Définit la marge supérieure du panneau, en pixels. N'a aucun effet sur les panneaux du bord inférieur. Fonctionne uniquement sur macOS et les compositeurs Wayland qui prennent en charge le protocole wlr layer shell.

marge_bas
marge_bas 0

Définit la marge inférieure du panneau, en pixels. N'a aucun effet sur les panneaux du bord supérieur. Fonctionne uniquement sur macOS et les compositeurs Wayland qui prennent en charge le protocole wlr layer shell.

kitty_conf

Chemin vers le fichier de configuration à utiliser pour kitty lors du dessin de la fenêtre. Peut être spécifié plusieurs fois. Par défaut, kitty.conf normal est utilisé. Les chemins relatifs sont résolus par rapport au répertoire de configuration kitty.

kitty_override

Remplace des options de configuration kitty individuelles, peut être spécifié plusieurs fois. Syntaxe : kitty_override nom=valeur. Par exemple : kitty_override font_size=20.

app_id
app_id kitty-quick-access

Sur Wayland, définit l'espace de noms de la surface de la couche shell. Sur X11, définit le WM_CLASS attribué à la fenêtre d'accès rapide. (Linux uniquement)

nom_sortie

Le panneau ne peut être affiché que sur un seul moniteur (sortie) à la fois. Cela vous permet de spécifier quelle sortie est utilisée, par nom. Si non spécifié, le compositeur choisira automatiquement une sortie, généralement la dernière sortie avec laquelle l'utilisateur a interagi ou le moniteur principal. Exécutez

kitten-quick-access-terminal(7) — kitty 0.44.0

Name

kitten quick_access_terminal — quick access terminal kitten

Overview

This kitten provides a quick access terminal window that you can bring up instantly with a keypress or a command.

Configuration

The quick access terminal can be configured in the kitty.conf file. The kitten also has its own configuration file, which can be specified using the --config option. If not specified, it is searched for in the usual kitty configuration locations.

kitty-quick-access-terminal.conf

The configuration file is a text file with key-value pairs. Each option can be set to a value. For example:

width 0.5

This sets the width of the quick access terminal to 50% of the screen width.

You can use kitten --list-outputs to get a list of available outputs. Use list-json for a JSON encoded output. Note that on Wayland, the output can only be set at panel creation time, it cannot be changed after creation, nor is there any way to display a single panel on all outputs. Please complain to the Wayland developers about this.

start_as_hidden
start_as_hidden no

Whether to start the quick access terminal hidden. Useful if you are starting it as part of system startup.

focus_policy
focus_policy exclusive

On a Wayland compositor that supports the wlr layer shell protocol, specify the focus policy for keyboard interactivity with the panel. Please refer to the wlr layer shell protocol documentation for more details. Note that different Wayland compositors behave very differently with exclusive, your mileage may vary. On macOS, exclusive and on-demand are currently the same.

Window appearance

The appearance of the quick access terminal window can be controlled by the following options:

width
width 0.5

The width of the window, as a fraction of the screen width. Default is 0.5.

height
height 0.5

The height of the window, as a fraction of the screen height. Default is 0.5.

position
position top

The position of the window. Can be top, bottom, left, or right. Default is top.

margin
margin 10

The margin around the window, in pixels. Default is 10.

background
background #282a36

The background color of the window. Can be a color name or a hex value. Default is the kitty theme background color.

foreground
foreground #f8f8f2

The foreground color of the window. Can be a color name or a hex value. Default is the kitty theme foreground color.

Source code for quick_access_terminal

The source code for this kitten is available on GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/quick_access_terminal.

Command line interface

kitten quick_access_terminal [options] [cmdline-to-run ...]

A quick access terminal window that you can bring up instantly with a keypress or a command.

Options

--config <CONFIG>, -c <CONFIG>
Specify a path to the configuration file(s) to use. All configuration files are merged onto the builtin quick-access-terminal.conf, overriding the builtin values. This option can be specified multiple times to read multiple configuration files in sequence, which are merged. Use the special value NONE to not load any config file.

If this option is not specified, config files are searched for in the order: $XDG_CONFIG_HOME/kitty/quick-access-terminal.conf, ~/.config/kitty/quick-access-terminal.conf, $XDG_CONFIG_DIRS/kitty/quick-access-terminal.conf. The first one that exists is used as the config file.

If the environment variable KITTY_CONFIG_DIRECTORY <#envvar-KITTY_CONFIG_DIRECTORY> is specified, that directory is always used and the above searching does not happen.

If /etc/xdg/kitty/quick-access-terminal.conf exists, it is merged before (i.e. with lower priority) than any user config files. It can be used to specify system-wide defaults for all users. You can use either - or /dev/stdin to read the config from STDIN.

--override <OVERRIDE>, -o <OVERRIDE>
Override individual configuration options, can be specified multiple times. Syntax: name=value. For example: -o lines=12
--detach [=no]
Detach from the controlling terminal, if any, running in an independent child process, the parent process exits immediately.
--detached-log <DETACHED_LOG>
Path to a log file to store STDOUT/STDERR when using --detach
--instance-group <INSTANCE_GROUP>
The unique name of this quick access terminal Use a different name if you want multiple such terminals. Default: quick-access
--debug-rendering [=no]
For debugging interactions with the compositor/window manager.
--debug-input [=no]
For debugging interactions with the compositor/window manager.
