NOM

kjournalprint - Utilitaire d'impression de journal Knot DNS

SYNTAXE

kjournalprint [option_config] [options] nom_zone

kjournalprint [option_config] -z

DESCRIPTION

Le programme imprime l'historique de zone stocké dans une base de données de journal. Par défaut, les modifications sont colorisées pour le terminal.

Paramètres

nom_zone
Nom de la zone pour laquelle imprimer l'historique.

Options de configuration

-c, --config fichier
Utiliser un fichier de configuration textuel (par défaut /etc/knot/knot.conf).
-C, --confdb répertoire
Utiliser un répertoire de base de données de configuration binaire (par défaut /var/lib/knot/confdb). La base de données de configuration par défaut, si elle existe, a une préférence pour le fichier de configuration par défaut.
-D, --dir chemin
Utiliser le chemin de base de données du journal spécifié et la configuration par défaut.

Options

-z, --zone-list
Au lieu de lire le journal, afficher la liste des zones dans la base de données.
-l, --limit limite
Limite le nombre de modifications affichées.
-s, --serial soa
Commencer à un numéro de série SOA spécifique.
-M, --merge
Imprimer les jeux de modifications fusionnés en un seul jeu. Si la zone dans le journal est présente, le contenu stocké avec tous les jeux de modifications appliqués sera imprimé.
-H, --check
Activer des vérifications sémantiques supplémentaires du journal pendant l'impression.
-d, --debug
Mode débogage, sortie brève.
-x, --mono
Ne pas générer de sortie colorisée.
-X, --color
Forcer la sortie colorisée.
-h, --help
Afficher l'aide du programme.
-V, --version
Afficher la version du programme. L'option -VV fait imprimer au programme le résumé de la configuration au moment de la compilation.

VALEURS DE RETOUR

Un statut de sortie de 0 signifie une opération réussie. Tout autre statut de sortie indique une erreur.

EXEMPLES

Les 5 dernières modifications (les plus récentes) sans couleurs :

$ kjournalprint -xl 5 /var/lib/knot/journal example.com.

VOIR AUSSI

knotd(8), knot.conf(5).
