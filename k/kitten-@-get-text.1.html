Nom

kitten-@-get-text - Récupérer le texte de la fenêtre spécifiée

Utilisation

kitten @ get-text

Description

Récupérer le texte de la fenêtre spécifiée

Options

--match, -m
La fenêtre à faire correspondre. Les spécifications de correspondance sont de la forme : champ:requête. Où champ peut être l'un des suivants : id, title, pid, cwd, cmdline, num, env, var, state, neighbor, session et recent. requête est l'expression à faire correspondre. Les expressions peuvent être soit un nombre, soit une expression régulière, et peuvent être combinées à l'aide d'opérateurs booléens.

La valeur spéciale all correspond à toutes les fenêtres.

Pour les champs numériques : id, pid, num et recent, l'expression est interprétée comme un nombre, et non comme une expression régulière. Les valeurs négatives pour id correspondent à partir du numéro d'id le plus élevé vers le bas ; en particulier, -1 est la fenêtre créée le plus récemment.

Le champ num fait référence à la position de la fenêtre dans l'onglet courant, en commençant à zéro et en comptant dans le sens des aiguilles d'une montre (c'est le même que l'ordre dans lequel les fenêtres sont rapportées par la commande kitten @ ls).

L'identifiant de fenêtre de la fenêtre courante est disponible en tant que la variable d'environnement KITTY_WINDOW_ID.

Le champ recent fait référence aux fenêtres récemment actives dans l'onglet actuellement actif, où zéro est la fenêtre actuellement active, un est la fenêtre active précédente, et ainsi de suite.

Le champ neighbor fait référence à un voisin de la fenêtre active dans la direction spécifiée, qui peut être : left, right, top ou bottom.

Le champ session correspond aux fenêtres qui ont été créées dans la session spécifiée. Utilisez l'expression ^$ pour correspondre aux fenêtres qui n'ont pas été créées dans une session et . pour correspondre à la session actuellement active et ~ pour correspondre soit à la session actuellement active, soit à la dernière session active lorsque aucune session n'est active.

Lorsque vous utilisez le champ env pour faire correspondre des variables d'environnement, vous pouvez spécifier soit le nom de la variable d'environnement seul, soit un nom et une valeur, par exemple env:MY_ENV_VAR=2.

De même, le champ var correspond aux variables utilisateur définies sur la fenêtre. Vous pouvez spécifier un nom ou un nom et une valeur comme avec le champ env.

Le champ state correspond à l'état de la fenêtre. Les états pris en charge sont : active, focused, needs_attention, parent_active, parent_focused, focused_os_window, self, overlay_parent. Les fenêtres actives sont les fenêtres qui sont actives dans leur onglet parent. Il n'y a qu'une seule fenêtre focalisée et c'est la fenêtre à laquelle les événements clavier sont livrés. Si aucune fenêtre n'est focalisée, la dernière fenêtre focalisée est correspondue. La valeur focused_os_window correspond à toutes les fenêtres de la fenêtre OS actuellement focalisée. La valeur self correspond à la fenêtre dans laquelle la commande de contrôle à distance est exécutée. La valeur overlay_parent correspond à la fenêtre qui se trouve sous la fenêtre self, lorsque la fenêtre self est un superposition (overlay).

Notez que vous pouvez utiliser la commande kitten @ ls pour obtenir une liste de fenêtres.

--extent [=screen]
Quel texte récupérer. La valeur par défaut screen signifie tout le texte actuellement à l'écran. all signifie tout l'écran + le défilement (scrollback) et selection signifie le texte actuellement sélectionné. first_cmd_output_on_screen signifie la sortie de la première commande qui a été exécutée dans la fenêtre à l'écran. last_cmd_output signifie la sortie de la dernière commande qui a été exécutée dans la fenêtre. last_visited_cmd_output signifie la sortie de la première commande en dessous de la dernière position de défilement via scroll_to_prompt. last_non_empty_output est la sortie de la dernière commande exécutée dans la fenêtre qui avait une sortie non vide. Les quatre dernières nécessitent que shell_integration soit activé.

Choix : screen, all, first_cmd_output_on_screen, last_cmd_output, last_non_empty_output, last_visited_cmd_output, selection

--ansi [=no]
Par défaut, seul le texte brut est renvoyé. Avec cet indicateur, le texte inclura les codes d'échappement de formatage ANSI pour les couleurs, le gras, l'italique, etc.
--add-cursor [=no]
Ajouter les codes d'échappement ANSI spécifiant la position et le style du curseur à la fin du texte.
--add-wrap-markers [=no]
Ajouter des retours à la ligne à chaque endroit où une ligne est coupée (où les lignes longues sont coupées aux bords de l'écran).
--clear-selection [=no]
Effacer la sélection dans la fenêtre correspondante, le cas échéant.
--self [=no]
Récupérer le texte de la fenêtre dans laquelle cette commande est exécutée, plutôt que de la fenêtre active.
--help, -h [=no]
Afficher l'aide pour cette commande

Options globales

--to
Une adresse de l'instance de kitty à contrôler. Correspond à l'adresse donnée à l'instance de kitty via l'option --listen-on ou le paramètre listen_on dans kitty.conf. Si non spécifiée, la variable d'environnement KITTY_LISTEN_ON est vérifiée. Si elle n'est pas trouvée non plus, les messages sont envoyés au terminal contrôleur pour ce processus, c'est-à-dire qu'ils ne fonctionneront que si ce processus est exécuté dans une fenêtre kitty.
--password
Un mot de passe à utiliser lors de la connexion à kitty. Cela fera demander à kitty la permission à l'utilisateur d'effectuer l'action spécifiée, sauf si le mot de passe a été accepté auparavant ou est préconfiguré dans kitty.conf. Pour utiliser un mot de passe vide, spécifiez --use-password comme always.
--password-file [=rc-pass]
Un fichier à partir duquel lire le mot de passe. Les espaces en fin de ligne sont ignorés. Les chemins relatifs sont résolus à partir du répertoire de configuration de kitty. Utilisez - pour lire depuis STDIN. Utilisez fd:num pour lire depuis le descripteur de fichier num. Utilisé si aucun --password n'est fourni. Par défaut, vérifie la présence du fichier rc-pass dans le répertoire de configuration de kitty.
--password-env [=KITTY_RC_PASSWORD]
Le nom d'une variable d'environnement à partir de laquelle lire le mot de passe. Utilisé si aucun --password-file n'est fourni. Par défaut, vérifie la variable d'environnement KITTY_RC_PASSWORD.
--use-password [=if-available]
Si aucun mot de passe n'est disponible, kitty enverra généralement la commande de contrôle à distance sans mot de passe. Cette option peut être utilisée pour forcer l'utilisation du mot de passe fourni, soit toujours, soit jamais. Si définie à always et qu'aucun mot de passe n'est fourni, le mot de passe vide est utilisé.

Choix : if-available, always, never
