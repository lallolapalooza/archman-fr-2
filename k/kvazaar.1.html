KVAZAAR(1) Commandes utilisateur KVAZAAR(1)

NOM

kvazaar - encodeur HEVC open source

SYNTAXE

kvazaar -i <entrée> --input-res <largeur>x<hauteur> -o <sortie>

DESCRIPTION

Requis :

-i, --input <nom_fichier>
Fichier d'entrée
--input-res <res>
Résolution d'entrée [auto]
- auto : Détecter à partir du nom du fichier.
- <int>x<int> : largeur fois hauteur
-o, --output <nom_fichier>
Fichier de sortie

Presets :

--preset <preset>
Définir les options sur un preset [medium]
- ultrafast, superfast, veryfast, faster,
fast, medium, slow, slower, veryslow
placebo

Entrée :

-n, --frames <entier>
Nombre d'images à coder [toutes]
--seek <entier>
Première image à coder [0]
--input-fps <num>[/<denom>]
Fréquence d'images de la vidéo d'entrée [25]
--source-scan-type <chaine>
Type de scan source [progressive]
- progressive : Balayage progressif
- tff : Champ supérieur en premier
- bff : Champ inférieur en premier
--input-format <chaine>
P420 ou P400 [P420]
--input-bitdepth <entier>
8-16 [8]
--loop-input
Relire le fichier d'entrée indéfiniment.
--input-file-format <chaine>
Format du fichier d'entrée [auto]
- auto : Vérifier l'extension du fichier pour le format
- y4m (saute les en-têtes d'image)
- yuv

Options :

--help
Afficher ce message d'aide et quitter.
--version
Afficher les informations de version et quitter.
--(no-)aud
Utiliser les délimiteurs d'unité d'accès. [désactivé]
--debug <nom_fichier>
Sortie de la reconstruction interne.
--(no-)cpuid
Activer les optimisations CPU à l'exécution. [activé]
--hash <chaine>
Hash de l'image décodée [checksum]
- none: 0 octets
- checksum: 18 octets
- md5: 56 octets
--(no-)psnr
Calculer le PSNR pour les images. [activé]
--(no-)info
Ajouter des informations sur l'encodeur SEI. [activé]
--(no-)enable-logging
Activer la journalisation pour les performances régulières de l'encodeur, les messages d'erreur sont toujours affichés. [activé]
--crypto <chaine>
Chiffrement sélectif. Le support crypto doit être activé à la compilation. Peut être 'on' ou 'off' ou une liste de fonctionnalités séparées par '+'. [off]
- on : Activer toutes les fonctionnalités de chiffrement.
- off : Désactiver le chiffrement sélectif.
- mvs : Magnitudes des vecteurs de mouvement.
- mv_signs : Signes des vecteurs de mouvement.
- trans_coeffs : Magnitudes des coefficients.
- trans_coeff_signs : Signes des coefficients.
- intra_pred_modes : Modes de prédiction intra.
--key <chaine>
Clé de chiffrement [16,213,27,56,255,127,242,112,
97,126,197,204,25,59,38,30]
--stats-file-prefix
Un préfixe utilisé pour les fichiers de statistiques qui incluent les bits, lambda, la distorsion et le qp pour chaque ctu. Ceux-ci sont destinés au débogage et ne sont pas écrits sauf si le préfixe est défini.

Structure vidéo :

-q, --qp <entier>
Paramètre de quantification [22]
-p, --period <entier>
Période des images intra [64]
- 0 : Seule la première image est intra.
- 1 : Toutes les images sont intra.
- N : Toutes les N images sont intra.
--vps-period <entier>
Fréquence d'envoi de l'ensemble de paramètres vidéo [0]
- 0 : Envoyer le VPS uniquement avec la première image.
- N : Envoyer le VPS avec chaque N-ième image intra.
-r, --ref <entier>
Nombre d'images de référence, dans la plage 1..15 [4]
--gop <chaine>
Structure GOP [16]
- 0 : Désactivé
- 8 : Pyramide d'images B de longueur 8
- 16 : Pyramide d'images B de longueur 16
- lp-<chaine> : GOP P/B à faible latence
(par exemple, lp-g8d4t2, voir README)
--intra-qp-offset <entier>: Décalage QP pour les images intra [-51..51] [auto]

- N : Définir le décalage QP à N.
- auto : Sélectionner le décalage automatiquement en fonction
de la longueur du GOP.
--(no-)open-gop
Utiliser la configuration GOP ouverte. [activé]
--cqmfile <nom_fichier>
Lire les matrices de quantification personnalisées à partir d'un fichier.
--scaling-list <chaine>: Définir le mode de liste de mise à l'échelle. [off]

- off : Désactiver les listes de mise à l'échelle.
- custom : utiliser la liste personnalisée (avec --cqmfile).
- default : Utiliser les listes par défaut.
--bitrate <entier>
Débit cible [0]
- 0 : Désactiver le contrôle de débit.
- N : Débit cible de N bits par seconde.
--rc-algorithm <chaine>: Sélectionner l'algorithme rc utilisé. [lambda]

- lambda : contrôle de débit de :
DOI: 10.1109/TIP.2014.2336550
- oba : DOI: 10.1109/TCSVT.2016.2589878
--(no-)intra-bits
Utiliser l'allocation basée sur le coût de Hadamard pour les images intra. Par défaut activé pour gop 8 et désactivé pour lp-gop
--(no-)clip-neighbour
Pour le contrôle de débit basé sur oba, si le clipping des valeurs lambda aux ctus de la même image ou de l'image précédente. Par défaut activé pour les GOP RA et désactivé pour LP.
--(no-)lossless
Utiliser le codage sans perte. [désactivé]
--mv-constraint <chaine>
Contraindre les vecteurs de mouvement. [none]
- none : Aucune contrainte
- frametile : Contraindre à l'intérieur du carreau.
- frametilemargin : Contraindre encore plus.
--roi <nom_fichier>
Utiliser une carte de QP delta pour la région d'intérêt. Lit un tableau de valeurs QP delta à partir d'un fichier. Les fichiers texte et binaires sont pris en charge et détectés à partir de l'extension du fichier (.txt/.bin). Si une extension connue n'est pas trouvée, le fichier est traité comme un fichier texte. Le fichier peut contenir une ou plusieurs images ROI chacune dans le format suivant : largeur et hauteur de la carte delta QP suivies de largeur * hauteur valeurs delta QP en ordre raster. En format binaire, la largeur et la hauteur sont des entiers 32 bits tandis que les valeurs delta QP sont des valeurs signées 8 bits. La carte peut avoir n'importe quelle taille et sera mise à l'échelle vers la taille de la vidéo. La lecture du fichier bouclera si la fin du fichier est atteinte. Voir roi.txt dans le dossier examples.
--set-qp-in-cu
Définir le QP au niveau CU en gardant pic_init_qp_minus26. dans PPS et slice_qp_delta dans l'en-tête de slice à zéro.

(no-)erp-aqp
Utiliser l'AQP adaptatif pour la vidéo à 360 degrés avec projection équirectangulaire. [désactivé]
--level <nombre>
Utiliser le niveau HEVC donné en sortie et générer une erreur si les limites de niveau sont dépassées. [6.2]
- 1, 2, 2.1, 3, 3.1, 4, 4.1, 5, 5.1, 5.2, 6,
6.1, 6.2
--force-level <nombre>
Identique à --level mais avec des avertissements au lieu d'erreurs.
--high-tier
Utilisé avec --level. Utiliser les limites de débit de la tier haute au lieu des limites de la tier principale pendant l'encodage. La tier haute nécessite un niveau de 4 ou supérieur.
--(no-)vaq <entier>
Activer la quantification adaptative de variance avec la force donnée, dans la plage 1..20. Recommandé : 5. [désactivé]

Outils de compression :

--(no-)deblock <beta:tc>
Filtre de déblocage. [0:0]
- beta : Entre -6 et 6
- tc : Entre -6 et 6
--sao <chaîne>
Compensation adaptative d'échantillon [full]
- off : SAO désactivé
- band : Décalage de bande uniquement
- edge : Décalage de bord uniquement
- full : SAO complet
--(no-)rdoq
Quantification optimisée par taux-distorsion [activé]
--(no-)rdoq-skip
Sauter RDOQ pour les blocs 4x4. [désactivé]
--(no-)signhide
Cachage de signe [désactivé]
--(no-)smp
Partition de mouvement symétrique [désactivé]
--(no-)amp
Partition de mouvement asymétrique [désactivé]
--rd <entier>
Complexité de recherche de mode [0]
- 0 : Sauter intra si inter est suffisant.
- 1 : Recherche de mode intra approximative avec SATD.
- 2 : Affiner la recherche de mode avec SSE.
- 3 : Plus de candidats SSE pour inter et
recherche de mode chroma pour intra 4x4.
- 4 : Encore plus de candidats SSE pour les deux.
- 5 : Essayer tous les modes intra.
--(no-)mv-rdo
Coûts de vecteurs de mouvement optimisés par taux-distorsion [désactivé]
--(no-)zero-coeff-rdo
Si un CU est réglé sur inter, vérifier si forcer une résiduelle nulle améliore le coût RD. [activé]
--(no-)full-intra-search
Essayer tous les modes intra pendant la recherche approximative. [désactivé]
--(no-)intra-chroma-search
Tester les modes intra chroma non dérivés.
[désactivé]
--(no-)transform-skip
Essayer le saut de transformée [désactivé]
--me <chaîne>
Algorithme d'estimation de mouvement entier [hexbs]
- hexbs : Recherche basée sur l'hexagone
- tz : Recherche par zone de test
- full : Recherche complète
- full8, full16, full32, full64
- dia : Recherche par diamant
--me-steps <entier>
Limite des étapes de recherche d'estimation de mouvement. N'affecte que 'hexbs' et 'dia'. [-1]
--subme <entier>
Niveau d'estimation de mouvement à pixels fractionnaires [4]
- 0 : Estimation de mouvement entier uniquement
- 1 : + 1/2 pixel horizontal et vertical
- 2 : + 1/2 pixel diagonal
- 3 : + 1/4 pixel horizontal et vertical
- 4 : + 1/4 pixel diagonal
--(no-)fast-bipred
Effectuer uniquement une recherche rapide bipred. [activé]
--pu-depth-inter <int>-<int>
Tailles des unités de prédiction inter [0-3]
- 0, 1, 2, 3 : de 64x64 à 8x8
- Accepte une liste de valeurs séparées par ','
pour définir des profondeurs distinctes par couche GOP
(les valeurs peuvent être omises pour utiliser la première
valeur pour la couche respective).
--pu-depth-intra <int>-<int>
Tailles des unités de prédiction intra [1-4]
- 0, 1, 2, 3, 4 : de 64x64 à 4x4
- Accepte une liste de valeurs séparées par ','
pour définir des profondeurs distinctes par couche GOP
(les valeurs peuvent être omises pour utiliser la première
valeur pour la couche respective).
--ml-pu-depth-intra
Prédire le pu-depth-intra en utilisant des arbres
d'apprentissage automatique, remplace le
paramètre --pu-depth-intra. [désactivé]
--(no-)combine-intra-cus: Indique si l'encodeur essaie de coder un cu

à une profondeur inférieure même si la recherche n'est pas
effectuée à cette profondeur. Ne devrait être
désactivé que si les cu ne doivent absolument pas
être plus grands que ce qui est limité par la recherche.
[activé]
--force-inter
Forcer l'encodeur à utiliser toujours inter. Ceci est principalement pour le débogage et n'est pas garanti de produire un flux binaire cohérent ou de fonctionner du tout. [désactivé]
--tr-depth-intra <int>
Profondeur de division de transformée pour les blocs intra [0]
--(no-)bipred
Bi-prédiction [activé]
--cu-split-termination <chaîne>
Terminaison de la recherche de division CU [zero]
- off : Ne pas terminer prématurément.
- zero : Terminer lorsque la résiduelle est nulle.
--me-early-termination <chaîne>
Terminaison de l'estimation de mouvement [on]
- off : Ne pas terminer prématurément.
- on : Terminer prématurément.
- sensitive : Terminer encore plus tôt.
--fast-residual-cost <int>
Sauter le coût CABAC pour les coefficients résiduels
lorsque le QP est inférieur à la limite. [0]
--fast-coeff-table <chaîne>
Lire les poids personnalisés pour les résiduels
coefficients à partir d'un fichier au lieu d'utiliser
les valeurs par défaut [default]
--fast-rd-sampling
Activer l'échantillonnage des données d'apprentissage pour la génération rapide de table
de coefficients
--fastrd-accuracy-check
Évaluer la précision de la prédiction rapide des coefficients
--fastrd-outdir
Répertoire dans lequel sortir les données échantillonnées ou les données de précision
, dans <fastrd-outdir>/0.txt à 50.txt, un fichier
pour chaque QP sur lequel les blocs ont été estimés
--(no-)intra-rdo-et
Vérifier les modes intra dans l'étape RDO uniquement jusqu'à ce qu'un CU avec des coefficients nuls soit trouvé. [désactivé]
--(no-)early-skip
Essayer de trouver un CU de saut à partir des candidats de fusion. Ne pas effectuer de recherche supplémentaire si un saut est trouvé. Pour rd=0..1 : Essayer le premier candidat. Pour rd=2.. Essayer le meilleur candidat basé
sur le coût satd de luminance. [activé]
--max-merge <entier>
Nombre maximum de candidats de fusion, 1..5 [5]
--(no-)implicit-rdpcm
DPCM résiduel implicite. Actuellement pris en charge uniquement avec l'encodage sans perte. [désactivé]
--(no-)tmvp
Prédiction de vecteur de mouvement temporel [activé]

Traitement parallèle :

--threads <entier>
Nombre de threads à utiliser [auto]
- 0 : Traiter tout avec le thread principal.
- N : Utiliser N threads pour l'encodage.
- auto : Sélectionner automatiquement.
--owf <entier>
Parallélisme au niveau de l'image [auto]
- N : Traiter N+1 images à la fois.
- auto : Sélectionner automatiquement.
--(no-)wpp
Traitement parallèle par front d'onde. [activé] L'activation des tuiles désactive automatiquement WPP. Pour activer WPP avec des tuiles, réactivez-le après avoir activé les tuiles. L'activation de wpp avec des tuiles est cependant une fonctionnalité expérimentale car elle n'est pas prise en charge dans aucun profil HEVC.
--tiles <int>x<int>
Diviser l'image en tuiles uniformes de largeur x hauteur.
--tiles-width-split <chaîne>|u<int>

- <chaîne> : Une liste d'ordonnées de pixels de colonnes
de tuiles séparées par des virgules.
- u<int> : Nombre de colonnes de tuiles de largeur
uniforme.
--tiles-height-split <chaîne>|u<int>

- <chaîne> : Une liste d'ordonnées de pixels de lignes
de colonnes de tuiles séparées par des virgules.
- u<int> : Nombre de lignes de tuiles de hauteur
uniforme.
--slices <chaîne>
Contrôler comment les tranches sont utilisées.
- tiles : Placer les tuiles dans des tranches indépendantes.
- wpp : Placer les lignes dans des tranches dépendantes.
- tiles+wpp : Faire les deux.
--partial-coding <décalage-x>!<décalage-y>!<largeur-tranche>!<hauteur-tranche>

Encoder une image partielle. Les parties doivent être fusionnées pour former un flux binaire valide. X et Y sont des décalages CTU. La largeur et la hauteur de la tranche doivent être divisibles par le CTU en pixels sauf s'il s'agit de la dernière ligne/colonne CTU. Ce paramètre est utilisé par kvaShare.
