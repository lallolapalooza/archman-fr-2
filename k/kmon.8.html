kmon(1) Manuel des commandes générales kmon(1)

NOM

kmon - kmon 1.7.1 Orhun Parmaksız <orhunparmaksiz@gmail.com> gestionnaire et moniteur d'activité du noyau Linux

Appuyez sur '?' pendant l'exécution de l'interface utilisateur du terminal pour voir les raccourcis clavier.

SYNTAXE

kmon [-a|--accent-color] [-c|--color] [-t|--tickrate] [-r|--reverse] [-u|--unicode] [-E|--regex] [-h|--help] [-V|--version] [sous-commandes]

DESCRIPTION

kmon 1.7.1 Orhun Parmaksız <orhunparmaksiz@gmail.com> gestionnaire et moniteur d'activité du noyau Linux

Appuyez sur '?' pendant l'exécution de l'interface utilisateur du terminal pour voir les raccourcis clavier.

OPTIONS

-a, --accent-color=COULEUR [défaut : white]
Définit la couleur d'accentuation à l'aide d'un code hexadécimal ou d'un nom de couleur
-c, --color=COULEUR [défaut : darkgray]
Définit la couleur principale à l'aide d'un code hexadécimal ou d'un nom de couleur
-t, --tickrate=MS [défaut : 250]
Définit le taux de rafraîchissement du terminal
-r, --reverse
Inverse la liste des modules du noyau
-u, --unicode
Affiche les symboles Unicode pour les titres des blocs
-E, --regex
Interprète la requête de recherche de module comme une expression régulière
-h, --help
Imprime l'aide
-V, --version
Imprime la version

SOUS-COMMANDES

kmon-sort(1)
Trie les modules du noyau
kmon-help(1)
Imprime ce message ou l'aide des sous-commandes spécifiées
