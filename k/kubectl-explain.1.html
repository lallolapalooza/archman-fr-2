NOM

kubectl explain - Obtenir la documentation d'une ressource

SYNTAXE

kubectl explain [OPTIONS]

DESCRIPTION

Décrit les champs et la structure de diverses ressources.

Cette commande décrit les champs associés à chaque ressource d'API prise en charge. Les champs sont identifiés à l'aide d'un identifiant JSONPath simple :

    <type>.<nomDuChamp>[.<nomDuChamp>]

Les informations sur chaque champ sont récupérées depuis le serveur au format OpenAPI.

Utilisez "kubectl api-resources" pour obtenir une liste complète des ressources prises en charge.

OPTIONS

--api-version="" Obtenir des explications différentes pour une version d'API particulière (groupe/version d'API)

-o, --output="plaintext" Format dans lequel rendre le schéma (plaintext, plaintext-openapiv2)

--recursive=false Afficher les champs des champs (actuellement, seulement 1 niveau de profondeur)

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Le nom du cluster kubeconfig à utiliser

--context="" Le nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactiver la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant le signalement de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, l'espace de noms pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. Un des choix (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une requête serveur individuelle. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas expirer les requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton Bearer pour l'authentification auprès du serveur API

--user="" Le nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Obtenir la documentation de la ressource et de ses champs
  kubectl explain pods
  # Obtenir tous les champs de la ressource
  kubectl explain pods --recursive
  # Obtenir l'explication du déploiement dans les versions d'API prises en charge
  kubectl explain deployments --api-version=apps/v1
  # Obtenir la documentation d'un champ spécifique d'une ressource
  kubectl explain pods.spec.containers
  # Obtenir la documentation des ressources dans un format différent
  kubectl explain deployment --output=plaintext-openapiv2
