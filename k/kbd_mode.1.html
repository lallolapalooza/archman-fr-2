KBD_MODE(1) Manuel des commandes générales KBD_MODE(1)

NOM

kbd_mode - signaler ou définir le mode du clavier

SYNOPSIS

kbd_mode [ -a | -u | -k | -s | -d ] [ -f ] [ -C CONSOLE ]

DESCRIPTION

Sans argument, kbd_mode affiche le mode actuel du clavier (RAW, MEDIUMRAW ou XLATE). En utilisant les options, il est possible de changer le mode du clavier de la console actuelle ou de la console spécifiée.

OPTIONS

-a, --ascii
définir le mode ASCII (XLATE).
-k, --keycode
définir le mode keycode (MEDIUMRAW).
-s, --scancode
définir le mode scancode (RAW).
-u, --unicode
définir le mode UTF-8 (UNICODE).
-d, --disable
définir le mode Désactivation (OFF).
-f, --force
changer le mode même si cela rend le clavier inutilisable.
-C, --console=DEV
le périphérique console à utiliser.

Bien sûr, le « -a » n'est que traditionnel, et le code utilisé peut être n'importe quel jeu de caractères 8 bits. Avec « -u », un jeu de caractères 16 bits est attendu, et ces caractères sont transmis au noyau en 1, 2 ou 3 octets (en suivant le codage UTF-8). Dans ces deux derniers modes, le mappage des touches défini par loadkeys(1) est utilisé.

Le mode Désactivation pour le clavier de la console virtuelle OFF complète RAW, dans lequel tous les événements de touches sont ignorés. Le mode empêche les tampons d'entrée vt de déborder lorsqu'un programme s'ouvre mais ne lit pas à partir d'un tty, comme Xorg utilisant uniquement evdev pour l'entrée.

kbd_mode opère sur la console spécifiée par l'option « -C » ; s'il n'y en a pas, la console associée à stdin est utilisée.

Avertissement : changer le mode du clavier, sauf entre ASCII et Unicode, rendra probablement votre clavier inutilisable. Définissez l'option « -f » pour forcer de tels changements. Cette commande est destinée à être utilisée (par exemple, via une connexion à distance) lorsqu'un programme a laissé votre clavier dans le mauvais état. Notez que dans certaines versions obsolètes de ce programme, l'option « -u » était synonyme de « -s » et les anciennes versions de ce programme pourraient ne pas reconnaître l'option « -f ».
