NOM

key.dns_resolver.conf - Configuration du résolveur DNS du noyau

DESCRIPTION

Ce fichier est utilisé par le programme key.dns_resolver(5) pour définir les paramètres. Sauf indication contraire avec l'option -c, le programme lit :

/etc/key.dns_resolver.conf

Les options de configuration sont sous forme clé[=valeur], où valeur est optionnelle. Si présente, la valeur peut être entourée d'une paire de guillemets simples ('') ou doubles ("") qui seront supprimés. Les caractères spéciaux dans la valeur peuvent être échappés avec une barre oblique inverse pour les transformer en caractères ordinaires.

Les lignes commençant par un '#' sont considérées comme des commentaires et ignorées. Un symbole '#' n'importe où après le '=' transforme le reste de la ligne en commentaire, sauf si le '#' se trouve dans une section entre guillemets ou s'il est échappé.

Les espaces de début et de fin, ainsi que les espaces autour du symbole '=' seront supprimés.

Les options disponibles incluent :

default_ttl=<nombre>
Le nombre de secondes à définir comme expiration pour un enregistrement mis en cache. Ceci sera remplacé si le programme parvient à récupérer des informations TTL avec les adresses (si, par exemple, il accède directement au DNS). La valeur par défaut est de 5 secondes. La valeur doit être comprise entre 1 et INT_MAX.

Le fichier peut également inclure des commentaires commençant par un caractère '#' sauf s'ils sont supprimés en se trouvant dans une valeur entre guillemets ou s'ils sont échappés avec une barre oblique inverse.
