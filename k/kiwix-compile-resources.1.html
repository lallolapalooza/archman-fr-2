KIWIX-COMPILE-RESOURCES(1) Commandes utilisateur KIWIX-COMPILE-RESOURCES(1)

NOM

kiwix-compile-resources - utilitaire pour compiler et générer certaines ressources Kiwix

SYNOPSIS

kiwix-compile-resources [-h] [--cxxfile CXXFILE] [--hfile HFILE] resource_file ...

DESCRIPTION

resource_file
La liste des ressources à compiler.
-h, --help
affiche un message d'aide et quitte
--cxxfile CXXFILE
Le nom du fichier Cpp à générer
--hfile HFILE
Le nom du fichier h à générer
