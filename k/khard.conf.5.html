NOM

khard.conf - fichier de configuration pour khard

RÉSUMÉ

Le fichier de configuration de khard est un fichier texte brut avec une syntaxe de type ini. De nombreuses options ont une option de ligne de commande correspondante. La seule section obligatoire dans le fichier de configuration est la définition des carnets d'adresses disponibles.

EMPLACEMENT

Le fichier est recherché dans $XDG_CONFIG_HOME/khard/khard.conf. Si la variable d'environnement $XDG_CONFIG_HOME n'est pas définie, ~/.config/ est utilisé à sa place.

L'emplacement peut être modifié par la variable d'environnement $KHARD_CONFIG ou par l'option de ligne de commande -c (qui a la priorité).

SYNTAXE

Il prend en charge les sections marquées de crochets et les sections imbriquées avec plus de crochets. Chaque section contient plusieurs clés avec des valeurs délimitées par des signes d'égalité. Les valeurs sont typées et leur type est vérifié.

OPTIONS

Le fichier de configuration se compose de ces quatre sections :

addressbooks
Cette section contient plusieurs sous-sections, mais au moins une. Chaque sous-section peut avoir un nom arbitraire qui sera le nom d'un carnet d'adresses connu de khard. Chacune de ces sous-sections doit avoir une clé path avec le chemin vers le répertoire contenant les fichiers vCard pour ce carnet d'adresses. Optionnellement, vous pouvez définir la valeur type à soit discover soit vdir, qui est la valeur par défaut. La valeur path prend en charge les variables d'environnement et les préfixes tilde. Lors de l'utilisation du type discover, il prend également en charge les globes. khard s'attend à ce que les fichiers vCard ne contiennent qu'un seul enregistrement VCARD chacun et se terminent par une extension .vcf.
general
Cette section permet de configurer certaines fonctionnalités générales de khard. Les clés suivantes sont disponibles dans cette section :
  • debug : une indication booléenne indiquant si le niveau de journalisation doit être défini sur debug par défaut (même effet que l'option --debug sur la ligne de commande)
  • default_action : l'action/sous-commande par défaut à utiliser si le premier argument n'étant pas une option ne correspond à aucune des sous-commandes disponibles
  • editor : l'éditeur de texte à utiliser pour modifier les entrées du carnet d'adresses, sinon $EDITOR sera utilisé
  • merge_editor : une commande utilisée pour fusionner interactivement deux cartes, sinon $MERGE_EDITOR sera utilisé
contact table
Cette section est utilisée pour configurer le comportement des différentes listes de sortie de khard. Les clés suivantes sont disponibles :
  • display : quelle partie du nom utiliser dans les listes ; cela peut être first_name, last_name ou formatted_name
  • group_by_addressbook : si les contacts doivent être regroupés par carnet d'adresses dans les listes
  • localize_dates : si les dates doivent être localisées ou si des formats de date ISO doivent être utilisés
  • preferred_email_address_type : libellés des adresses e-mail à préférer
  • preferred_phone_number_type : libellés des numéros de téléphone à préférer
  • reverse : si l'ordre des listes de contacts doit être inversé ou non
  • show_nicknames : si les surnoms doivent être affichés
  • show_uids : si les uids doivent être affichés
  • show_kinds : si les types doivent être affichés
  • sort : le champ par lequel trier les listes de contacts
vcard
  • private_objects : une liste de chaînes de caractères, ce sont les noms des champs vCard privés (commençant par X-) qui seront chargés et affichés par khard
  • search_in_source_files : si la recherche doit être effectuée dans les fichiers vCard avant leur analyse afin d'accélérer les recherches
  • skip_unparsable : si les vCard non analysables doivent être ignorées, sinon khard se termine à la première carte non analysable qu'il rencontre
  • preferred_version : la version vCard préférée à utiliser pour les nouvelles cartes

EXEMPLE

Ceci est le fichier de configuration d'exemple :

# exemple de fichier de configuration pour khard version > 0.14.0
# placez-le sous ~/.config/khard/khard.conf
# Ce fichier est analysé par la bibliothèque configobj. La syntaxe est décrite sur
# https://configobj.readthedocs.io/en/latest/configobj.html#the-config-file-format
[addressbooks]
[[family]]
path = ~/.contacts/family/
[[friends]]
path = ~/.contacts/friends/
[[work]]
path = ~/.work/**/client-*-contacts/
type = discover
[general]
debug = no
default_action = list
# Ce sont soit des chaînes de caractères, soit des listes séparées par des virgules
editor = vim, -i, NONE
merge_editor = vimdiff
[contact table]
# afficher les noms par prénom ou nom : first_name / last_name / formatted_name
display = first_name
# regrouper par carnet d'adresses : yes / no
group_by_addressbook = no
# inverser l'ordre de la table : yes / no
reverse = no
# ajouter les surnoms au nom de la colonne : yes / no
show_nicknames = no
# afficher la colonne uid : yes / no
show_uids = yes
# afficher la colonne kind : yes / no
show_kinds = no
# trier par prénom ou nom : first_name / last_name / formatted_name
sort = last_name
# localiser les dates : yes / no
localize_dates = yes
# définir une liste séparée par des virgules des types de numéros de téléphone préférés dans l'ordre de priorité décroissante
# ou rien pour un ordre alphabétique non filtré
preferred_phone_number_type = pref, cell, home
# définir une liste séparée par des virgules des types d'adresses e-mail préférés dans l'ordre de priorité décroissante
# ou rien pour un ordre alphabétique non filtré
preferred_email_address_type = pref, work, home
[vcard]
# étendre les contacts avec vos propres objets privés
# ces objets sont stockés avec un préfixe "X-" avant le nom de l'objet dans les fichiers vcard
# chaque libellé d'objet ne peut contenir que des lettres, des chiffres et le caractère -
# exemple :
#   private_objects = Jabber, Skype, Twitter
# par défaut : , (la liste vide)
private_objects = Jabber, Skype, Twitter
# version vcard préférée : 3.0 / 4.0
preferred_version = 3.0
# rechercher dans les fichiers source vcf pour accélérer les requêtes de recherche : yes / no
search_in_source_files = no
# ignorer les fichiers vcard non analysables : yes / no
skip_unparsable = no
