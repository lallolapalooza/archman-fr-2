NOM

kubeone-config - Commandes pour travailler avec les manifestes de configuration KubeOneCluster

SYNTAXE

kubeone config [options]

DESCRIPTION

Commandes pour travailler avec les manifestes de configuration KubeOneCluster.

OPTIONS

-h, --help[=false] aide pour config

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-c, --credentials="" Fichier à partir duquel sourcer les informations d'identification et les secrets.

-d, --debug[=false] Sortie de débogage avec trace de la pile.

-l, --log-format="text" Format pour la journalisation.

-m, --manifest="./kubeone.yaml" Chemin vers la configuration KubeOne.

-t, --tfjson="" Source pour la sortie terraform en JSON - pour lire depuis stdin. Si le chemin est un fichier, son contenu sera utilisé. Si le chemin est un répertoire, terraform output -json sera exécuté dans ce chemin.

-v, --verbose[=false] Sortie détaillée.
