NOM

kf6options - Options communes de la ligne de commande pour toutes les applications basées sur KDE Frameworks 6

SYNTAXE

Application KDE [-h, --help] [-v, --version] [--author] [--license] [--desktopfile nom de fichier]

OPTIONS

Les options suivantes s'appliquent à toutes les applications KDE :

-h --help

Liste les options disponibles en ligne de commande.

-v --version

Liste les informations de version pour Application KDE.

--author

Liste les auteurs de Application KDE dans la fenêtre du terminal.

--license

Affiche les informations de licence.

--desktopfile nom de fichier

Le nom de fichier de base de l'entrée de bureau pour cette application.

Ceci est particulièrement utile pour les applications enveloppantes et les applications ayant généralement plusieurs fichiers de bureau. Ainsi, chaque fichier de bureau peut insérer son propre nom dans la commande exec.
