KOI8-R(7) Manuel d'informations diverses KOI8-R(7)

NOM

koi8-r - jeu de caractères russe codé en octal, décimal et hexadécimal

DESCRIPTION

RFC 1489 définit un jeu de caractères à 8 bits, KOI8-R. KOI8-R code les caractères utilisés en russe.
