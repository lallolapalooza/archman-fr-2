NOM

kubeadm init phase - Utiliser cette commande pour invoquer une phase unique du flux de travail "init"

SYNTAXE

kubeadm init phase [OPTIONS]

DESCRIPTION

Utiliser cette commande pour invoquer une phase unique du flux de travail "init"

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine du "vrai" hôte. Cela amènera kubeadm à effectuer un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
