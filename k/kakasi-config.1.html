NOM

kakasi-config - script pour obtenir des informations sur la version installée de KAKASI

SYNTAXE

kakasi-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--help] [--version] [--libs] [--cflags]

DESCRIPTION

kakasi-config est un outil utilisé pour configurer les indicateurs du compilateur et de l'éditeur de liens qui doivent être utilisés pour compiler et lier des programmes qui utilisent KAKASI. Il est également utilisé en interne par les macros .m4 pour GNU autoconf qui sont incluses avec KAKASI.

OPTIONS

kakasi-config accepte les options suivantes :
--help
Affiche le message d'aide et quitte.
--version
Affiche la version actuellement installée de KAKASI sur la sortie standard.
--libs
Affiche les indicateurs de l'éditeur de liens nécessaires pour lier un programme KAKASI.
--cflags
Affiche les indicateurs du compilateur nécessaires pour compiler un programme KAKASI.
--prefix=PREFIX
Si spécifié, utilise PREFIX à la place du préfixe d'installation avec lequel KAKASI a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option est également utilisée pour le préfixe d'exécution si --exec-prefix n'a pas été spécifié. Cette option doit être spécifiée avant toute option --libs ou --cflags.
--exec-prefix=PREFIX
Si spécifié, utilise PREFIX à la place du préfixe d'exécution d'installation avec lequel GTK+ a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.
