NOM

keyok - activer ou désactiver un code de touche curses

SYNTAXE

#include <curses.h>
int keyok(int keycode, bool enable);

DESCRIPTION

Ceci est une extension de la bibliothèque curses. Elle permet à une application de désactiver des codes de touches spécifiques, plutôt que d'utiliser la fonction keypad pour désactiver tous les codes de touches. Les touches qui ont été désactivées peuvent être réactivées.

VALEUR DE RETOUR

Le code de touche doit être supérieur à zéro, sinon ERR est retourné. S'il ne correspond à aucune touche définie, ERR est retourné. Si le paramètre enable est vrai, alors la touche doit avoir été désactivée, et vice versa. Sinon, la fonction retourne OK.

PORTABILITÉ

Cette routine est spécifique à ncurses. Elle n'était pas prise en charge sur les implémentations Version 7, BSD ou System V. Il est recommandé que tout code dépendant d'elles soit conditionné en utilisant NCURSES_VERSION.
