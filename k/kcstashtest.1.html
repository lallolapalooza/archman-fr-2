NOM

kcstashtest - interface en ligne de commande pour tester la base de données stash

DESCRIPTION

La commande `kcstashtest' est un utilitaire pour les tests de fonctionnalités et de performances de la base de données stash. Cette commande s'utilise dans le format suivant. `rnum' spécifie le nombre d'itérations.


kccachetest order [-th num] [-rnd] [-etc] [-tran] [-bnum num] [-lv] rnum
Effectue des tests en ordre.
kccachetest queue [-th num] [-it num] [-rnd] [-bnum num] [-lv] rnum
Effectue des opérations de mise en file d'attente.
kccachetest wicked [-th num] [-it num] [-bnum num] [-lv] rnum
Effectue des opérations mixtes sélectionnées aléatoirement.
kccachetest tran [-th num] [-it num] [-bnum num] [-lv] rnum
Effectue des tests de transactions.

Les options comprennent les suivantes.

-th num : spécifie le nombre de threads de travail.
-rnd : effectue un test aléatoire.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-lv : signale toutes les erreurs.
-it num : spécifie le nombre de répétitions.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
