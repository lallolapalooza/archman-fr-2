NOM

kubeadm join phase wait-control-plane - Attend que le plan de contrôle démarre

SYNTAXE

kubeadm join phase wait-control-plane [OPTIONS]

DESCRIPTION

Attend que le plan de contrôle démarre

OPTIONS HÉRITÉES DES COMMANDES PARENT

--rootfs="" Le chemin vers le système de fichiers racine de l'hôte 'réel'. Cela amènera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
