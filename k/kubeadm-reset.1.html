NOM

kubeadm reset - Effectue une tentative de retour des modifications apportées à cet hôte par 'kubeadm init' ou 'kubeadm join'

SYNTAXE

kubeadm reset [OPTIONS]

DESCRIPTION

Effectue une tentative de retour des modifications apportées à cet hôte par 'kubeadm init' ou 'kubeadm join'

La commande "reset" exécute les phases suivantes :

preflight           Exécute les vérifications préalables de réinitialisation
remove-etcd-member  Supprime un membre etcd local.
cleanup-node        Exécute le nettoyage du nœud.

OPTIONS

--cert-dir="/etc/kubernetes/pki" Le chemin vers le répertoire où sont stockés les certificats. Si spécifié, nettoie ce répertoire.

--cleanup-tmp-dir=false Nettoie le répertoire "/etc/kubernetes/tmp"

--config="" Chemin vers un fichier de configuration kubeadm.

--cri-socket="" Chemin vers la socket CRI pour se connecter. Si vide, kubeadm essaiera de détecter automatiquement cette valeur ; utilisez cette option uniquement si vous avez plus d'une installation CRI ou si vous avez une socket CRI non standard.

--dry-run=false N'appliquez aucune modification ; affichez seulement ce qui serait fait.

-f, --force=false Réinitialise le nœud sans demander de confirmation.

--ignore-preflight-errors=[] Une liste de vérifications dont les erreurs seront affichées sous forme d'avertissements. Exemple : 'IsPrivilegedUser,Swap'. La valeur 'all' ignore les erreurs de toutes les vérifications.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, plusieurs emplacements standards peuvent être recherchés pour trouver un fichier kubeconfig existant.

--skip-phases=[] Liste des phases à ignorer

OPTIONS HERITEES DES COMMANDES PARENT

--rootfs="" Le chemin vers le système de fichiers root 'réel' de l'hôte. Cela amènera kubeadm à utiliser un chroot sur le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée.
