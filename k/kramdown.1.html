KRAMDOWN(1) Manuel des commandes générales KRAMDOWN(1)

NOM

kramdown - un convertisseur Markdown-superset rapide, écrit en pur Ruby

SYNOPHIS

kramdown [options] [FICHIER...]

DESCRIPTION

kramdown est principalement utilisé pour analyser un superset de Markdown et le convertir en différents formats de sortie. Il prend en charge le Markdown standard (avec quelques modifications mineures) et diverses extensions telles que les tableaux et les listes de définition. Grâce à son architecture modulaire, il permet également d'utiliser d'autres formats d'entrée que Markdown, par exemple, HTML ou Github Flavored Markdown.

Si FICHIER n'est pas spécifié, kramdown lit depuis l'entrée standard. Le résultat est écrit sur la sortie standard.

Il existe deux ensembles d'options que kramdown accepte : Le premier comprend les options utilisées directement par le binaire kramdown. Le second ensemble d'options contrôle la manière dont kramdown analyse et convertit son entrée.

Les valeurs par défaut pour ce second ensemble peuvent être définies en utilisant YAML via le fichier de configuration kramdownrc. Notez que les noms des options de configuration utilisent des tirets bas (_), et non des tirets (-) (les tirets sont uniquement utilisés dans les noms des options de la ligne de commande), et les options booléennes n'ont pas de variante no mais une valeur de true ou false. Ce fichier doit se trouver dans XDG_CONFIG_HOME sous Linux/Unix, ~/Library/Preferences sur macOS et ~/AppData/Local sous Windows.

OPTIONS POUR LA LIGNE DE COMMANDE UNIQUEMENT

-i FORMAT, --input FORMAT
Spécifie le format d'entrée. Formats d'entrée disponibles : kramdown (c'est la valeur par défaut), markdown, ou html. Le format d'entrée GFM est disponible via le gem kramdown-parser-gfm.
-o FORMAT, --output FORMAT
Spécifie un ou plusieurs formats de sortie séparés par des virgules : html (par défaut), kramdown, latex, man ou remove_html_tags. Le convertisseur pdf est disponible via le gem kramdown-converter-pdf.
-x EXT, --extension EXT
Charge une ou plusieurs extensions. Le nom de l'extension ne doit pas inclure le préfixe kramdown-, par exemple, juste parser-gfm. Plusieurs extensions peuvent être chargées en les séparant par des virgules.

Note : Cette option doit être utilisée avant toute autre option qui dépend de l'extension déjà chargée.

--no-config-file
Ne lit aucun fichier de configuration. Le comportement par défaut est de vérifier l'existence d'un fichier de configuration et de le lire s'il existe.
--config-file FICHIER
Remplace le chemin et le nom par défaut du fichier de configuration.
-v, --version
Affiche la version de kramdown.
-h, --help
Affiche l'aide.

OPTIONS KRAMDOWN

--auto-id-prefix ARG
Préfixe utilisé pour les identifiants d'en-tête générés automatiquement

Cette option peut être utilisée pour définir un préfixe pour les identifiants d'en-tête générés automatiquement afin d'éviter les conflits lors du rendu de plusieurs documents kramdown dans un même fichier de sortie séparément. Le préfixe ne doit contenir que des caractères valides dans un ID !

Par défaut : ‘’ Utilisé par : Convertisseur HTML/Latex

--[no-]auto-id-stripping
Supprime toute mise en forme du texte de l'en-tête pour la génération automatique d'ID

Si cette option est true, seuls les éléments de texte d'un en-tête sont utilisés pour générer l'ID ultérieurement (par opposition à la simple utilisation de la ligne de texte brute de l'en-tête).

Cette option sera supprimée dans la version 2.0 car ce sera alors le comportement par défaut.

Par défaut : false Utilisé par : analyseur kramdown

--[no-]auto-ids
Utilise la génération automatique d'ID d'en-tête

Si cette option est true, les valeurs d'ID pour tous les en-têtes sont générées automatiquement s'il n'y a pas d'ID explicitement spécifié.

Par défaut : true Utilisé par : Convertisseur HTML/Latex

--entity-output ARG
Définit comment les entités sont sorties

Les valeurs possibles sont :as_input (les entités sont sorties dans la même forme que celles trouvées dans l'entrée), :numeric (les entités sont sorties sous forme numérique), :symbolic (les entités sont sorties sous forme symbolique si possible) ou :as_char (les entités sont sorties sous forme de caractères si possible, uniquement disponible sur Ruby 1.9).

Par défaut : :as_char Utilisé par : Convertisseur HTML, convertisseur kramdown

--footnote-backlink ARG
Définit le texte qui doit être utilisé pour les liens de retour des notes de bas de page

Le lien de retour de la note de bas de page est juste du texte, donc les caractères HTML spéciaux seront échappés.

Si le texte du lien de retour de la note de bas de page est une chaîne vide, aucun lien de retour de note de bas de page ne sera généré.

Par défaut : ‘&8617;’ Utilisé par : Convertisseur HTML

--[no-]footnote-backlink-inline
Spécifie si le lien de retour de la note de bas de page doit toujours être en ligne

Avec la valeur par défaut false, le lien de retour de la note de bas de page est placé à la fin du dernier paragraphe s'il y en a un, ou un paragraphe supplémentaire contenant uniquement le lien de retour de la note de bas de page est créé.

La définition de cette option sur true tente de placer le lien de retour de la note de bas de page dans le dernier paragraphe ou en-tête, potentiellement imbriqué. Si cela échoue (par exemple, dans le cas d'un tableau), un paragraphe supplémentaire contenant uniquement le lien de retour de la note de bas de page est créé.

Par défaut : false Utilisé par : Convertisseur HTML

--footnote-nr ARG
Le numéro de la première note de bas de page

Cette option peut être utilisée pour spécifier le numéro utilisé pour la première note de bas de page.

Par défaut : 1 Utilisé par : Convertisseur HTML

--footnote-prefix ARG
Préfixe utilisé pour les ID de notes de bas de page

Cette option peut être utilisée pour définir un préfixe pour les ID de notes de bas de page. Ceci est utile lors du rendu de plusieurs documents dans le même fichier de sortie pour éviter les ID dupliqués. Le préfixe ne doit contenir que des caractères valides dans un ID !

Par défaut : ‘’ Utilisé par : HTML

--forbidden-inline-options ARG
Définit les options qui ne peuvent pas être définies à l'aide de l'extension {::options}

La valeur doit être un tableau de noms d'options.

Par défaut : [template] Utilisé par : Convertisseur HTML

--header-offset ARG
Définit le décalage de sortie pour les en-têtes

Si cette option est c (peut aussi être négative), alors un en-tête de niveau n sera sorti comme un en-tête de niveau c+n. Si c+n est inférieur à 1, le niveau 1 sera utilisé. Si c+n est supérieur à 6, le niveau 6 sera utilisé.

Par défaut : 0 Utilisé par : Convertisseur HTML, convertisseur Kramdown, convertisseur Latex

--[no-]html-to-native
Convertit les éléments HTML en éléments natifs

Si cette option est true, l'analyseur convertit les éléments HTML en éléments natifs. Par exemple, lors de l'analyse de <em>hallo</em>, la balise d'emphase serait normalement convertie en un élément :html de type de balise :em. Si html_to_native est true, alors l'emphase serait convertie en un élément natif :em.

Ceci est utile pour les convertisseurs qui ne peuvent pas gérer les éléments HTML.

Par défaut : false Utilisé par : analyseur kramdown

--latex-headers ARG
Définit les commandes LaTeX pour différents niveaux d'en-tête

OPTIONS

--header-levels ARG
Les commandes pour les niveaux d'en-tête un à six peuvent être spécifiées en les séparant par des virgules.

Défaut : section,subsection,subsubsection,paragraph,subparagraph,subparagraph Utilisé par : Convertisseur Latex

--line-width ARG
Définit la largeur de ligne à utiliser lors de la sortie d'un document

Défaut : 72 Utilisé par : Convertisseur kramdown

--link-defs ARG
Pré-définit les définitions de liens

Cette option peut être utilisée pour pré-définir les définitions de liens. La valeur doit être un Hash où les clés sont les identifiants de lien et les valeurs sont des tableaux à deux éléments contenant l'URL du lien et le titre du lien.

Si la valeur est une chaîne de caractères, elle doit contenir un hachage YAML valide et le hachage doit suivre les directives ci-dessus.

Défaut : {} Utilisé par : Analyseur kramdown

--list-indent ARG
Définit le nombre d'espaces à utiliser pour l'indentation des listes

Défaut : 2 Utilisé par : Convertisseur Kramdown

--math-engine ARG
Définit le moteur mathématique

Spécifie le moteur mathématique qui doit être utilisé pour convertir les blocs/segments mathématiques. Si cette option est définie à nil, aucun moteur mathématique n'est utilisé et les blocs/segments mathématiques sont produits tels quels.

Les options pour le moteur mathématique sélectionné peuvent être définies avec l'option de configuration math_engine_opts.

Défaut : mathjax Utilisé par : Convertisseur HTML

--math-engine-opts ARG
Définit les options du moteur mathématique

Spécifie les options pour le moteur mathématique défini via l'option de configuration math_engine.

La valeur doit être un hachage avec des paires clé-valeur comprises par le moteur mathématique utilisé.

Défaut : {} Utilisé par : Convertisseur HTML

--[no-]parse-block-html
Traiter la syntaxe kramdown dans les balises HTML de bloc

Si cette option est true, l'analyseur kramdown traite le contenu des balises HTML de bloc comme du texte contenant des éléments de niveau bloc. Comme ce n'est normalement pas souhaité, la valeur par défaut est false. Il est normalement préférable d'activer sélectivement le traitement kramdown via l'attribut markdown.

Défaut : false Utilisé par : Analyseur kramdown

--[no-]parse-span-html
Traiter la syntaxe kramdown dans les balises HTML de segment

Si cette option est true, l'analyseur kramdown traite le contenu des balises HTML de segment comme du texte contenant des éléments de niveau segment.

Défaut : true Utilisé par : Analyseur kramdown

--[no-]remove-block-html-tags
Supprimer les balises HTML de bloc

Si cette option est true, le convertisseur RemoveHtmlTags supprime les balises HTML de bloc.

Défaut : true Utilisé par : Convertisseur RemoveHtmlTags

--[no-]remove-line-breaks-for-cjk
Spécifie si les sauts de ligne doivent être supprimés entre les caractères CJK

Défaut : false Utilisé par : Convertisseur HTML

--[no-]remove-span-html-tags
Supprimer les balises HTML de segment

Si cette option est true, le convertisseur RemoveHtmlTags supprime les balises HTML de segment.

Défaut : false Utilisé par : Convertisseur RemoveHtmlTags

--smart-quotes ARG
Définit les noms d'entités HTML ou les points de code pour la sortie des guillemets intelligents

Les entités identifiées par nom d'entité ou point de code qui doivent être utilisées pour, respectivement, un guillemet simple ouvrant, un guillemet simple fermant, un guillemet double ouvrant et un guillemet double fermant sont spécifiées en les séparant par des virgules.

Défaut : lsquo,rsquo,ldquo,rdquo Utilisé par : Convertisseur HTML/Latex

--syntax-highlighter ARG
Définit le surligneur de syntaxe

Spécifie le surligneur de syntaxe qui doit être utilisé pour surligner les blocs et segments de code. Si cette option est définie à nil, aucune coloration syntaxique n'est effectuée.

Les options pour le surligneur de syntaxe peuvent être définies avec l'option de configuration syntax_highlighter_opts.

Défaut : rouge Utilisé par : Convertisseur HTML/Latex

--syntax-highlighter-opts ARG
Définit les options du surligneur de syntaxe

Spécifie les options pour le surligneur de syntaxe défini via l'option de configuration syntax_highlighter.

La valeur doit être un hachage avec des paires clé-valeur comprises par le surligneur de syntaxe utilisé.

Défaut : {} Utilisé par : Convertisseur HTML/Latex

--template ARG
Le nom d'un fichier modèle ERB qui doit être utilisé pour envelopper la sortie ou le modèle ERB lui-même.

Ceci est utilisé pour envelopper la sortie dans un environnement afin que la sortie puisse être utilisée comme un document autonome. Par exemple, un modèle HTML fournirait les balises d'en-tête et de corps nécessaires afin que l'ensemble de la sortie soit un fichier HTML valide. Si aucun modèle n'est spécifié, la sortie sera uniquement le texte converti.

Lors de la recherche du fichier modèle, le nom de modèle donné est utilisé en premier. Si un tel fichier n'est pas trouvé, l'extension du convertisseur (la même que le nom du convertisseur) est ajoutée. Si le fichier ne peut toujours pas être trouvé, le nom du modèle est interprété comme un nom de modèle fourni par kramdown (sans l'extension du convertisseur). Si le fichier est toujours introuvable, le nom du modèle est vérifié s'il commence par ‘string://’ et si c'est le cas, ce préfixe est supprimé et le reste est utilisé comme contenu du modèle.

kramdown fournit un modèle par défaut nommé ‘document’ pour chaque convertisseur.

Défaut : ‘’ Utilisé par : tous les convertisseurs

--toc-levels ARG
Définit les niveaux utilisés pour la table des matières

Les niveaux individuels peuvent être spécifiés en les séparant par des virgules (par exemple, 1,2,3) ou en utilisant la syntaxe de plage (par exemple, 1..3). Seuls les niveaux spécifiés sont utilisés pour la table des matières.

Défaut : 1..6 Utilisé par : Convertisseur HTML/Latex

--[no-]transliterated-header-ids
Translitère le texte de l'en-tête avant de générer l'ID

Seuls les caractères ASCII sont utilisés dans les ID d'en-tête. Ce n'est pas idéal pour les langues comportant de nombreux caractères non ASCII. En activant cette option, le texte de l'en-tête est translittéré en ASCII autant que possible afin que l'ID d'en-tête résultant soit plus utile.

La bibliothèque stringex doit être installée pour que cette fonctionnalité fonctionne !

Défaut : false Utilisé par : Convertisseur HTML/Latex

--typographic-symbols ARG
Définit un mappage des symboles typographiques aux caractères de sortie

Les symboles typographiques sont normalement affichés à l'aide de leur point de code Unicode équivalent. Cependant, il est parfois souhaitable de modifier la sortie, principalement pour revenir à une séquence de caractères ASCII.

Cette option le permet en spécifiant un mappage du symbole typographique à sa chaîne de sortie. Par exemple, le mappage {hellip: ...} afficherait la représentation ASCII standard d'une ellipse.

Les noms de symboles typographiques disponibles sont :

  • hellip : ellipse
  • mdash : tiret cadratin
  • ndash : tiret demi-cadratin
  • laquo : guillemet français ouvrant
  • raquo : guillemet français fermant
  • laquo_space : guillemet français ouvrant suivi d'un espace
  • raquo_space : guillemet français fermant précédé d'un espace

Défaut : {} Utilisé par : Convertisseur HTML/Latex

STATUT DE SORTIE

Le statut de sortie est 0 si aucune erreur ne s'est produite. Sinon, il est de 1.
