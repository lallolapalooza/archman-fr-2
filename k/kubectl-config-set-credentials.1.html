NOM

kubectl config set-credentials - Définit une entrée utilisateur dans kubeconfig

SYNOPIS

kubectl config set-credentials [OPTIONS]

DESCRIPTION

Définit une entrée utilisateur dans kubeconfig.

Spécifier un nom qui existe déjà fusionnera les nouveaux champs par-dessus les valeurs existantes.

    Indicateurs de certificat client :
    --client-certificate=certfile --client-key=keyfile
    Indicateurs de jeton porteur :
    --token=bearer_token
    Indicateurs d'authentification basique :
    --username=basic_user --password=basic_password

Le jeton porteur et l'authentification basique s'excluent mutuellement.

OPTIONS

--auth-provider="" Fournisseur d'authentification pour l'entrée utilisateur dans kubeconfig

--auth-provider-arg=[] Arguments 'clé=valeur' pour le fournisseur d'authentification

--client-certificate="" Chemin vers le fichier certificat client pour l'entrée utilisateur dans kubeconfig

--client-key="" Chemin vers le fichier clé client pour l'entrée utilisateur dans kubeconfig

--embed-certs=false Intègre le certificat/la clé client pour l'entrée utilisateur dans kubeconfig

--exec-api-version="" Version API du plugin de crédentiels exec pour l'entrée utilisateur dans kubeconfig

--exec-arg=[] Nouveaux arguments pour la commande du plugin de crédentiels exec pour l'entrée utilisateur dans kubeconfig

--exec-command="" Commande pour le plugin de crédentiels exec pour l'entrée utilisateur dans kubeconfig

--exec-env=[] Valeurs d'environnement 'clé=valeur' pour le plugin de crédentiels exec

--exec-interactive-mode="" Mode interactif des crédentiels exec pour l'entrée utilisateur dans kubeconfig

--exec-provide-cluster-info=false FournirClusterInfo des crédentiels exec pour l'entrée utilisateur dans kubeconfig

--password="" mot de passe pour l'entrée utilisateur dans kubeconfig

--token="" jeton pour l'entrée utilisateur dans kubeconfig

--username="" nom d'utilisateur pour l'entrée utilisateur dans kubeconfig

OPTIONS HERITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, cet indicateur peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--cluster="" Le nom du cluster kubeconfig à utiliser

--context="" Le nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" utiliser un fichier kubeconfig particulier

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, la portée du namespace pour cette requête CLI

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier où écrire le profil

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--user="" Le nom de l'utilisateur kubeconfig à utiliser

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Définit uniquement le champ "client-key" sur l'entrée "cluster-admin",
  # sans toucher aux autres valeurs
  kubectl config set-credentials cluster-admin --client-key=~/.kube/admin.key
  # Définit l'authentification basique pour l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --username=admin --password=uXFGweU9l35qcif
  # Intègre les données du certificat client dans l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --client-certificate=~/.kube/admin.crt --embed-certs=true
  # Active le fournisseur d'authentification Google Compute Platform pour l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --auth-provider=gcp
  # Active le fournisseur d'authentification OpenID Connect pour l'entrée "cluster-admin" avec des arguments supplémentaires
  kubectl config set-credentials cluster-admin --auth-provider=oidc --auth-provider-arg=client-id=foo --auth-provider-arg=client-secret=bar
  # Supprime la valeur de configuration "client-secret" pour le fournisseur d'authentification OpenID Connect pour l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --auth-provider=oidc --auth-provider-arg=client-secret-
  # Active le nouveau plugin d'authentification exec pour l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-command=/path/to/the/executable --exec-api-version=client.authentication.k8s.io/v1beta1
  # Active le nouveau plugin d'authentification exec pour l'entrée "cluster-admin" avec mode interactif
  kubectl config set-credentials cluster-admin --exec-command=/path/to/the/executable --exec-api-version=client.authentication.k8s.io/v1beta1 --exec-interactive-mode=Never
  # Définit de nouveaux arguments de plugin d'authentification exec pour l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-arg=arg1 --exec-arg=arg2
  # Crée ou met à jour des variables d'environnement de plugin d'authentification exec pour l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-env=key1=val1 --exec-env=key2=val2
  # Supprime les variables d'environnement de plugin d'authentification exec pour l'entrée "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-env=var-to-remove-
