NOM

kcpolytest - interface de ligne de commande pour tester la base de données polymorphique

DESCRIPTION

La commande `kcpolytest' est un utilitaire pour les tests de fonctionnalité et les tests de performance de la base de données polymorphique. Cette commande est utilisée dans le format suivant. `path' spécifie le chemin d'un fichier de base de données. `rnum' spécifie le nombre d'itérations.


kcpolytest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Effectue des tests en ordre.
kcpolytest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Effectue des opérations de mise en file d'attente.
kcpolytest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Effectue des opérations mixtes sélectionnées aléatoirement.
kcpolytest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Effectue des tests de transaction.
kcpolytest mapred [-rnd] [-ru] [-oat|-onl|-onl|-otl|-onr] [-lv] [-tmp str] [-dbnum num] [-clim num] [-cbnum num] [-xnl] [-xpm] [-xpr] [-xpf] [-xnc] path rnum
Effectue des opérations MapReduce.
kcpolytest index [-th num] [-rnd] [-set|-get|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-lv] path rnum
Effectue des opérations d'indexation.
kcpolytest misc path
Effectue des tests divers.

Les options comprennent les suivantes.

-th num : spécifie le nombre de threads de travail.
-rnd : effectue un test aléatoire.
-set : effectue uniquement une opération de définition.
-get : effectue uniquement une opération d'obtention.
-getw : effectue uniquement une opération d'obtention avec un tampon.
-rem : effectue uniquement une opération de suppression.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-oat : ouvre la base de données avec l'option de transaction automatique.
-oas : ouvre la base de données avec l'option de synchronisation automatique.
-onl : ouvre la base de données avec l'option de verrouillage désactivé.
-otl : ouvre la base de données avec l'option de tentative de verrouillage.
-onr : ouvre la base de données avec l'option de réparation automatique désactivée.
-lv : signale toutes les erreurs.
-it num : spécifie le nombre de répétitions.
-hard : effectue une synchronisation physique.
-ru : réutilise la base de données existante.
-tmp str : spécifie le chemin d'un répertoire pour le stockage temporaire.
-dbnum num : spécifie le nombre de bases de données temporaires.
-clim num : spécifie la taille limite de la mémoire cache.
-cbnum num : spécifie le nombre de buckets de la mémoire cache.
-xnl : exécute avec l'option de verrouillage désactivé.
-xpm : exécute avec l'option de mapper parallèle.
-xpr : exécute avec l'option de réduire parallèle.
-xpf : exécute avec l'option de flusher parallèle.
-xnc : exécute avec l'option de compression désactivée.

Cette commande renvoie 0 en cas de succès, une autre valeur en cas d'échec.
