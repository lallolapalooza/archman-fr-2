NOM

kubeadm token generate - Génère et affiche un jeton de démarrage, mais ne le crée pas sur le serveur

SYNOPIS

kubeadm token generate [OPTIONS]

DESCRIPTION

Cette commande affichera un jeton de démarrage généré aléatoirement qui peut être utilisé avec les commandes « init » et « join ».

Vous n'avez pas besoin d'utiliser cette commande pour générer un jeton. Vous pouvez le faire vous-même tant qu'il respecte le format « [a-z0-9]{6}.[a-z0-9]{16} ». Cette commande est fournie pour plus de commodité afin de générer des jetons dans le format donné.

Vous pouvez également utiliser « kubeadm init » sans spécifier de jeton et il en générera et en affichera un pour vous.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--dry-run=false Activer ou non le mode simulation

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standard peut être recherché pour un fichier kubeconfig existant.

--rootfs="" Le chemin vers le « vrai » système de fichiers racine de l'hôte. Cela amènera kubeadm à faire un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
