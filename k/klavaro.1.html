NOM

Klavaro - Tutoriel de frappe flexible utilisant GTK+3

SYNTAXE

klavaro

DESCRIPTION

Klavaro est un programme qui vous apprend la frappe au clavier et/ou vous aide à améliorer vos compétences avec le clavier.

Vous trouverez plus d'informations sur :

https://klavaro.sourceforge.io/

OPTIONS

En plus de celles relatives à GTK, quelques options sont disponibles.
-h, --help : afficher une aide en ligne de commande.
-v, --version : afficher la version du programme.
-x, --velotxt : force le module de vitesse à utiliser des textes complets avec des paragraphes, tout comme le module de fluidité.

COULEURS

Certaines couleurs peuvent être configurées via le fichier « preferences.ini ». Il est généralement situé à : $HOME/.config/klavaro/
Vous devriez y créer une section nommée [colors] et définir certaines couleurs en utilisant la syntaxe internet/html (#RRGGBB). Par exemple :

[colors]
key_fg=#332200
key_1=#112233
key_9=#213243
text_intro_fg=#222222
char_untouched_bg=#fffaf8
char_wrong_fg=#880000
char_correct_fg=#009900
char_retouched_fg=#bbbbaa
cursor_blink_bg=#ff88ff

Et aussi, un fichier alternatif peut être défini pour basculer toutes ces couleurs : « altcolor.ini », en plus du fichier « preferences.ini ».

Voici la liste complète des mots-clés pour définir les couleurs.

Arrière-plan et premier plan pour les textes d'introduction du tutoriel :
text_intro_bg
text_intro_fg

Arrière-plan et premier plan pour les textes du tutoriel avant qu'ils ne soient tapés :
char_untouched_bg
char_untouched_fg

Les mêmes pour les textes du tutoriel après qu'ils aient été tapés correctement :
char_correct_bg
char_correct_fg

Même chose pour les textes du tutoriel après qu'ils aient été tapés de manière incorrecte :
char_wrong_bg
char_wrong_fg

Même chose pour les textes du tutoriel après qu'ils aient été retapés correctement, en corrigeant les erreurs (uniquement dans le module de fluidité) :
char_retouched_bg
char_retouched_fg

Couleur clignotante du curseur bloc dans les tests du tutoriel :
cursor_blink_bg
cursor_blink_fg

Premier plan des touches du clavier virtuel :
key_fg

Arrière-plan des touches, selon le doigt responsable, de gauche à droite (key_5 est valide pour les deux pouces, c'est la touche espace) :
key_1
key_2
key_3
key_4
key_5
key_6
key_7
key_8
key_9
