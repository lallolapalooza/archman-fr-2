NOM

kpackagetool6 - Installer, lister, supprimer des paquets Plasma

SYNTAXE

kpackagetool6 [-v, --version] [-h, --help] [--hash chemin] [-g, --global] [-t, --type type] [-i, --install chemin] [-s, --show nom] [-u, --upgrade chemin] [-l, --list] [--list-types] [-r, --remove nom] [-p, --packageroot chemin] [--generate-index]

DESCRIPTION

kpackagetool6 est un outil en ligne de commande pour installer, lister et supprimer des paquets Plasma.

OPTIONS

-v, --version

Affiche les informations de version.

-h, --help

Affiche cette aide.

--hash chemin

Génère un hachage SHA1 pour le paquet situé dans « chemin ».

-g, --global

Pour l'installation ou la suppression, opère sur les paquets installés pour tous les utilisateurs.

-t, --type type

Le type de paquet, correspondant au type de service du plugin de paquet, par exemple : KPackage/Generic, Plasma/Theme, Plasma/Wallpaper, Plasma/Applet, etc.

-i, --install chemin

Installe le paquet situé dans « chemin ».

-s, --show nom

Affiche les informations du paquet « nom ».

-u, --upgrade chemin

Met à jour le paquet situé dans « chemin ».

-l, --list

Liste les paquets installés.

--list-types

Liste tous les types de paquets connus qui peuvent être installés.

-r, --remove nom

Supprime le paquet nommé « nom ».

-p, --packageroot chemin

Chemin absolu vers la racine du paquet. Si omis, les répertoires de données standards de cette session Plasma seront recherchés à la place.

--generate-index chemin

Recrée l'index des plugins. À utiliser en conjonction avec l'option -t ou -g. Recrée l'index pour le type donné ou la racine du paquet. Opère dans le répertoire utilisateur, sauf si -g est utilisé.

VOIR AUSSI

Une documentation utilisateur plus détaillée est disponible sur help:/plasma-desktop (entrez cette URL dans Konqueror ou exécutez khelpcenter help:/plasma-desktop).
