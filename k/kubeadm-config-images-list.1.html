NOM

kubeadm config images list - Affiche la liste des images que kubeadm utilisera. Le fichier de configuration est utilisé au cas où des images ou des dépôts d'images seraient personnalisés.

SYNOPIS

kubeadm config images list [OPTIONS]

DESCRIPTION

Affiche la liste des images que kubeadm utilisera. Le fichier de configuration est utilisé au cas où des images ou des dépôts d'images seraient personnalisés.

OPTIONS

--allow-missing-template-keys=true Si vrai, ignore toute erreur dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. Ne s'applique qu'aux formats de sortie golang et jsonpath.

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--feature-gates="" Un ensemble de paires clé=valeur décrivant les portes de fonctionnalité pour diverses fonctionnalités. Les options sont : ControlPlaneKubeletLocalMode=true|false (BETA - par défaut=true) NodeLocalCRISocket=true|false (BETA - par défaut=true) PublicKeysECDSA=true|false (OBSOLÈTE - par défaut=false) RootlessControlPlane=true|false (ALPHA - par défaut=false) WaitForAllControlPlaneComponents=true|false (par défaut=true)

--image-repository="registry.k8s.io" Choisir un registre de conteneurs pour extraire les images du plan de contrôle.

--kubernetes-version="stable-1" Choisir une version Kubernetes spécifique pour le plan de contrôle.

-o, --output="text" Format de sortie. L'un des suivants : text|json|yaml|go-template|go-template-file|template|templatefile|jsonpath|jsonpath-as-json|jsonpath-file.

--show-managed-fields=false Si vrai, conserver les champs gérés lors de l'affichage des objets au format JSON ou YAML.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standard peut être recherché pour un fichier kubeconfig existant.

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée.
