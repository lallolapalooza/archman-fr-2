NOM

kstats - afficher les votes de l'algorithme FMS statistiques pour un dump ivs et une clé WEP spécifiée

SYNTAXE

kstats <fichier ivs> <clé 104 bits>

DESCRIPTION

kstats est un outil conçu pour afficher les votes de l'algorithme FMS pour un dump d'vecteurs d'initialisation (ivs) avec une clé WEP spécifiée. Le dump d'ivs peut être obtenu en utilisant la combinaison de airodump(1) et ivstools(1).

EXEMPLE

kstats kstats out.ivs 123456789ABCDEF123456789AB
