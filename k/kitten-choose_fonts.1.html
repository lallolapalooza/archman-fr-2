Nom

kitten-choose_fonts - Choisir les polices utilisées par kitty

Usage

kitten choose_fonts

Options

--reload-in [=parent]
Par défaut, ce kitten signalera uniquement l'instance parente de kitty dans laquelle il s'exécute pour recharger sa configuration, après avoir apporté des modifications. Utilisez cette option pour ne pas recharger la configuration du tout, ou pour la recharger dans toutes les instances de kitty en cours d'exécution.

Choix possibles : parent, all, none

--config-file-name [=kitty.conf]
Le nom ou le chemin du fichier de configuration à éditer. Les chemins relatifs sont interprétés par rapport au répertoire de configuration de kitty. Par défaut, le fichier de configuration de kitty, kitty.conf, est édité. Ceci est particulièrement utile si vous ajoutez `include fonts.conf` à votre kitty.conf et que le kitten opère alors uniquement sur fonts.conf, permettant à kitty.conf de rester inchangé.
