Nom

kitten-hints - Sélectionner du texte à l'écran avec le clavier

Aperçu

kitty a un mode d'indices pour sélectionner et agir sur des fragments de texte arbitraires actuellement visibles à l'écran. Par exemple, vous pouvez appuyer sur ctrl+shift+e <#shortcut-kitty.Open-URL> pour choisir n'importe quelle URL visible à l'écran et l'ouvrir ensuite avec votre navigateur web par défaut.

Mode d'indices d'URL (images non prises en charge)

De même, vous pouvez appuyer sur ctrl+shift+p>f <#shortcut-kitty.Insert-selected-path> pour sélectionner tout ce qui ressemble à un chemin ou un nom de fichier, puis l'insérer dans le terminal, très utile pour choisir des fichiers dans la sortie d'une commande git ou ls et les ajouter à la ligne de commande pour la commande suivante.

Vous pouvez également appuyer sur ctrl+shift+p>n <#shortcut-kitty.Open-the-selected-file-at-the-selected-line> pour sélectionner tout ce qui ressemble à un chemin ou un nom de fichier suivi d'un deux-points et d'un numéro de ligne, puis ouvrir le fichier dans votre éditeur par défaut à la ligne spécifiée (l'ouverture à un numéro de ligne ne fonctionnera que si votre éditeur prend en charge la syntaxe de ligne de commande +linenum ou est un éditeur « connu »). Les modèles et l'éditeur à utiliser peuvent être modifiés à l'aide d'options passées au kitten. Par exemple :

map ctrl+g kitten hints --type=linenum --linenum-action=tab nvim +{line} {path}

ouvrira le fichier sélectionné dans un nouvel onglet Neovim https://neovim.io/ lorsque vous appuierez sur Ctrl+G.

Appuyer sur ctrl+shift+p>y <#shortcut-kitty.Open-the-selected-hyperlink> ouvrira les hyperliens <#term-hyperlinks>, c'est-à-dire une URL qui a été marquée comme telle par le programme exécuté dans le terminal, par exemple par ls --hyperlink=auto. Si ls fourni avec votre système d'exploitation ne prend pas en charge les hyperliens, vous devrez peut-être installer GNU Coreutils https://www.gnu.org/software/coreutils/.

Vous pouvez également personnaliser les actions entreprises pour différents types d'URL <>.

Remarque :

S'il y a plus d'indices que de lettres, les indices utiliseront plusieurs lettres. Dans ce cas, lorsque vous appuyez sur la première lettre, seuls les indices commençant par cette lettre sont affichés. Appuyer sur la deuxième lettre sélectionnera cet indice ou appuyer sur Entrée ou Espace pour sélectionner l'indice vide.

Pour les amateurs de souris, le kitten d'indices permet également de cliquer sur n'importe quel texte correspondant pour le sélectionner au lieu de taper le caractère d'indice.

Le kitten d'indices est très puissant. Pour plus d'aide détaillée sur ses diverses options et modes de fonctionnement, voir ci-dessous. Vous pouvez utiliser ces options pour créer des mappages dans kitty.conf afin de sélectionner divers fragments de texte. Voir insert_selected_path <#shortcut-kitty.Insert-selected-path> pour des exemples.

Personnalisation complète de la correspondance et des actions du kitten

Le kitten d'indices prend en charge l'écriture de scripts Python simples qui peuvent être utilisés pour personnaliser entièrement la manière dont il trouve les correspondances et ce qui se passe lorsqu'une correspondance est sélectionnée. Cela permet au kitten d'indices de fournir l'interface utilisateur, tandis que vous pouvez fournir la logique pour trouver les correspondances et effectuer des actions sur elles. Ceci est mieux illustré par un exemple. Créez le fichier custom-hints.py dans le répertoire de configuration de kitty <#confloc> avec le contenu suivant :

import re
def mark(text, args, Mark, extra_cli_args, *a):
    # Cette fonction est responsable de trouver tout
    # le texte correspondant. extra_cli_args sont tous les arguments supplémentaires
    # passés sur la ligne de commande lors de l'invocation du kitten.
    # Nous marquons chaque mot individuel pour une sélection potentielle
    for idx, m in enumerate(re.finditer(r'\w+', text)):
        start, end = m.span()
        mark_text = text[start:end].replace('\n', '').replace('\0', '')
        # Le dictionnaire vide ci-dessous sera disponible sous forme de groupdicts
        # dans handle_result() et peut contenir des clés de chaîne et des valeurs arbitraires
        # sérialisables en JSON.
        yield Mark(idx, start, end, mark_text, {})
def handle_result(args, data, target_window_id, boss, extra_cli_args, *a):
    # Cette fonction est responsable de l'exécution d'une
    # action sur le texte sélectionné.
    # matches est une liste des entrées sélectionnées et groupdicts contient
    # les données arbitraires associées à chaque entrée dans mark() ci-dessus
    matches, groupdicts = [], []
    for m, g in zip(data['match'], data['groupdicts']):
        if m:
            matches.append(m), groupdicts.append(g)
    for word, match_data in zip(matches, groupdicts):
        # Rechercher le mot dans un dictionnaire, la fonction open_url
        # ouvrira l'URL fournie dans le navigateur système
        boss.open_url(f'https://www.google.com/search?q=define:{word}')

Maintenant, exécutez kitty avec :

kitty -o 'map f1 kitten hints --customize-processing custom-hints.py'

Lorsque vous appuierez sur la touche F1, vous pourrez sélectionner un mot pour le rechercher dans le dictionnaire Google.

Le code source de ce kitten est disponible sur GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/hints.

Interface en ligne de commande

kitten hints [options]

Sélectionne du texte à l'écran à l'aide du clavier. Par défaut, recherche les URL.

Options

--program <PROGRAMME>
Quel programme utiliser pour ouvrir le texte correspondant. Par défaut, le programme d'ouverture par défaut du système d'exploitation. Diverses valeurs spéciales sont prises en charge :
-
coller la correspondance dans la fenêtre du terminal.
@
copier la correspondance dans le presse-papiers
*
copier la correspondance dans la sélection primaire (sur les systèmes qui prennent en charge les sélections primaires)
@NOM
copier la correspondance dans le tampon spécifié, par exemple @a
default
exécuter le programme d'ouverture par défaut. Notez que lors de l'utilisation du type d'hyperlien --type, la valeur par défaut est d'utiliser les installations de gestion des hyperliens de kitty <>.
launch
exécuter la commande launch <> pour ouvrir le programme dans un nouvel onglet, une nouvelle fenêtre, une superposition, etc. de kitty. Par exemple :
--program "launch --type=tab vim"

Peut être spécifié plusieurs fois pour exécuter plusieurs programmes.

--type <TYPE>
Le type de texte à rechercher. Une valeur de linenum est spéciale, elle recherche les messages d'erreur en utilisant le modèle spécifié avec --regex, qui doit avoir les groupes nommés : path et line. Si non spécifié, recherchera path:line. L'option --linenum-action contrôle où afficher le message d'erreur sélectionné, les autres options sont ignorées. Par défaut : url Choix : hash, hyperlink, ip, line, linenum, path, regex, url, word
--regex <REGEX>
L'expression régulière à utiliser lorsque l'option --type est définie sur regex, en syntaxe Perl 5. Si vous spécifiez un groupe numéroté dans l'expression régulière, seul le groupe sera mis en correspondance. Cela vous permet de mettre en correspondance du texte en ignorant un préfixe/suffixe, selon les besoins. L'expression par défaut met en correspondance les lignes. Pour mettre en correspondance du texte sur plusieurs lignes, les choses deviennent un peu délicates, car les fins de ligne sont une séquence de zéro ou plusieurs octets nuls suivie d'un retour chariot ou d'un caractère de nouvelle ligne. Pour qu'un modèle corresponde à travers les fins de ligne, vous devrez faire correspondre l'ensemble de caractères [\0\r\n]. Les nouvelles lignes et les octets nuls sont automatiquement supprimés du texte renvoyé. Si vous spécifiez des groupes nommés et un --program, alors le programme se verra passer des arguments
s correspondants à chaque groupe nommé de la forme clé=valeur. Défaut : (?m)^\s*(.+?)\s*$
--linenum-action <ACTION_NUMERO_LIGNE>
Où effectuer l'action sur les erreurs correspondantes. self signifie la fenêtre actuelle, window une nouvelle fenêtre kitty, tab un nouvel onglet, os_window une nouvelle fenêtre du système d'exploitation et background exécute en arrière-plan. remote-control est similaire à background, mais le programme peut utiliser le contrôle à distance de kitty sans avoir besoin d'activer le contrôle à distance globalement. L'action réelle est constituée des arguments fournis au kitten, par exemple : kitten hints --type=linenum --linenum-action=tab vim +{line} {path} ouvrira le chemin correspondant à la ligne correspondante dans vim dans un nouvel onglet kitty. Notez que pour utiliser --program pour copier ou coller les arguments fournis, vous devez utiliser la valeur spéciale self. Défaut : self Choix : background, os_window, remote-control, self, tab, window
--url-prefixes <PREFIXES_URLS>
Liste des préfixes d'URL reconnus, séparés par des virgules. Par défaut, la liste des préfixes définis par l'option url_prefixes <#opt-kitty.url_prefixes> dans kitty.conf. Par défaut : default
--url-excluded-characters <CARACTERES_EXCLUS_URLS>
Caractères à exclure lors de la correspondance des URL. Par défaut, la liste des caractères définis par l'option url_excluded_characters <#opt-kitty.url_excluded_characters> dans kitty.conf. La syntaxe de cette option est la même que celle de url_excluded_characters <#opt-kitty.url_excluded_characters>. Par défaut : default
--word-characters <CARACTERES_MOT>
Caractères à considérer comme faisant partie d'un mot. De plus, tous les caractères marqués comme alphanumériques dans la base de données Unicode seront considérés comme des caractères de mot. Par défaut, l'option select_by_word_characters <#opt-kitty.select_by_word_characters> de kitty.conf.
--minimum-match-length <LONGUEUR_MINIMALE_CORRESPONDANCE>
Le nombre minimum de caractères à considérer comme une correspondance. Défaut : 3
--multiple [=no]
Sélectionne plusieurs correspondances et effectue l'action sur toutes à la fin. En ce mode, appuyez sur Échap pour terminer la sélection.
--multiple-joiner <JOINER_MULTIPLE>
Chaîne pour joindre plusieurs sélections lors de la copie dans le presse-papiers ou de l'insertion dans le terminal. Les valeurs spéciales sont : space - un espace, newline - un saut de ligne, empty - un jointure vide, json - une liste sérialisée JSON, auto - un choix automatique, basé sur le type de texte sélectionné. De plus, les entiers sont interprétés comme des indices basés sur zéro dans la liste des sélections. Vous pouvez utiliser 0 pour la première sélection et -1 pour la dernière. Défaut : auto
--add-trailing-space <AJOUTER_ESPACE_FIN>
Ajoute un espace final après le texte correspondant. Par défaut, auto, qui ajoute l'espace lorsqu'il est utilisé avec --multiple. Défaut : auto Choix : always, auto, never
--hints-offset <DECALE_INDICATIONS>
Le décalage (à partir de zéro) où commencer la numérotation des indications. Notez que seuls les nombres supérieurs ou égaux à zéro sont respectés. Défaut : 1
--alphabet <ALPHABET>
La liste des caractères à utiliser pour les indications. Par défaut, ce sont les chiffres et les alphabets minuscules anglais. Spécifiez votre préférence sous forme d'une chaîne de caractères. Notez que vous devez spécifier --hints-offset à zéro pour utiliser le premier caractère afin de mettre en surbrillance la première correspondance, sinon cela commencera par le deuxième caractère par défaut.
--ascending [=no]
Fait augmenter les indications de haut en bas, au lieu de les faire diminuer de haut en bas.
--hints-foreground-color <COULEUR_FOND_INDICATIONS>
La couleur de premier plan des indications. Vous pouvez utiliser des noms de couleurs ou des valeurs hexadécimales. Pour les huit couleurs de terminal nommées de base, vous pouvez également utiliser le préfixe bright- pour obtenir la variante lumineuse de la couleur. Défaut : black
--hints-background-color <COULEUR_ARRIERE_PLAN_INDICATIONS>
La couleur d'arrière-plan des indications. Vous pouvez utiliser des noms de couleurs ou des valeurs hexadécimales. Pour les huit couleurs de terminal nommées de base, vous pouvez également utiliser le préfixe bright- pour obtenir la variante lumineuse de la couleur. Défaut : green
--hints-text-color <COULEUR_TEXTE_INDICATIONS>
La couleur de premier plan du texte pointé par les indications. Vous pouvez utiliser des noms de couleurs ou des valeurs hexadécimales. Pour les huit couleurs de terminal nommées de base, vous pouvez également utiliser le préfixe bright- pour obtenir la variante lumineuse de la couleur. Par défaut, une couleur appropriée est choisie automatiquement. Défaut : auto
--customize-processing <PERSONNALISER_TRAITEMENT>
Nom d'un fichier python dans le répertoire de configuration kitty qui sera importé pour fournir des implémentations personnalisées pour la recherche de motifs et l'exécution d'actions sur les correspondances sélectionnées. Vous pouvez également spécifier des chemins absolus pour charger le script depuis ailleurs. Voir https://sw.kovidgoyal.net/kitty/kittens/hints/ pour plus de détails.
--window-title <TITRE_FENETRE>
Le titre de la fenêtre des indications, le titre par défaut est basé sur le type de texte concerné par les indications.

Note :

Pour éviter d'avoir à spécifier les mêmes options de ligne de commande à chaque invocation, vous pouvez utiliser l'option action_alias <#opt-kitty.action_alias> dans kitty.conf, en créant des alias qui ont des ensembles d'options communs. Par exemple : 
action_alias mes_indications kitten hints --alphabet qfjdkslaureitywovmcxzpq1234567890
map f1 mes_indications --customize-processing custom-hints.py
