KEYCTL_READ(3) Appels de gestion de clés Linux KEYCTL_READ(3)

NOM

keyctl_read - lire une clé

SYNOPSIS

#include <keyutils.h>

long keyctl_read(key_serial_t key, char *buffer, size_t buflen);

long keyctl_read_alloc(key_serial_t key, void **_buffer);

DESCRIPTION

keyctl_read() lit la charge utile d'une clé si le type de clé le supporte.

L'appelant doit avoir l'autorisation de lecture sur une clé pour pouvoir la lire.

buffer et buflen spécifient le tampon dans lequel les données de la charge utile seront placées. Si le tampon est trop petit, la taille complète de la charge utile sera retournée, et le contenu du tampon peut être écrasé de manière indéfinie.

keyctl_read_alloc() est similaire à keyctl_read() sauf qu'il alloue un tampon suffisamment grand pour contenir les données de la charge utile et y place les données. En cas de succès, un pointeur vers le tampon est placé dans *_buffer. L'appelant doit libérer le tampon.

keyctl_read_alloc() ajoute un caractère NUL après les données qu'il récupère, bien que cela ne soit pas compté dans la valeur de taille qu'il retourne.

LECTURE DES KEYRINGS

Cet appel peut être utilisé pour lister le contenu d'un keyring. Les données sont présentées à l'utilisateur comme un tableau de key_serial_t, chacun correspondant à une clé à laquelle le keyring détient un lien.

La taille du keyring est sizeof(key_serial_t) multipliée par le nombre de clés. La taille de key_serial_t est invariante selon les tailles de mot, bien que l'ordre des octets soit approprié pour le noyau.

VALEUR DE RETOUR

En cas de succès, keyctl_read() retourne la quantité de données placées dans le tampon. Si le tampon était trop petit, la taille du tampon requis sera retournée, et le contenu du tampon peut avoir été écrasé de manière indéfinie.

En cas de succès, keyctl_read_alloc() retourne la quantité de données dans le tampon.

En cas d'erreur, les deux fonctions définissent errno à un code approprié et retournent la valeur -1.

ERREURS

ENOKEY
La clé spécifiée est invalide.
EKEYEXPIRED
La clé spécifiée a expiré.
EKEYREVOKED
La clé spécifiée a été révoquée.
EACCES
La clé existe, mais elle n'est pas lisible par le processus appelant.
EOPNOTSUPP
Le type de clé ne supporte pas la lecture des données de la charge utile.

LIAISON

C'est une fonction de bibliothèque qui se trouve dans libkeyutils. Lors de la liaison, -lkeyutils doit être spécifié à l'éditeur de liens.
