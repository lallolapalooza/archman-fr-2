NOM

kubeadm upgrade apply phase addon kube-proxy - Mise à jour du addon kube-proxy

SYNOPSIS

kubeadm upgrade apply phase addon kube-proxy [OPTIONS]

DESCRIPTION

Mise à jour du addon kube-proxy

OPTIONS

--config="" Chemin vers un fichier de configuration kubeadm.

--dry-run=false Ne pas modifier l'état, afficher seulement les actions qui seraient effectuées.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'option n'est pas définie, un ensemble d'emplacements standard peut être recherché pour un fichier kubeconfig existant.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela forcera kubeadm à utiliser chroot sur le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

VOIR AUSSI

kubeadm-upgrade-apply-phase-addon(1),
