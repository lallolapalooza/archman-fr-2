NOM

kbuildsycoca6 - Reconstruit le cache de configuration des fichiers de bureau KService

SYNTAXE

kbuildsycoca6 [OPTIONS...]

DESCRIPTION

kbuildsycoca6 crée un cache binaire des données stockées dans les fichiers .desktop et les fichiers XML de types MIME que le framework KService utilise pour trouver des plugins, des applications et d'autres services.

La bibliothèque KService utilise cette base de données pour fournir efficacement les informations qui lui sont demandées.

Les utilisateurs n'ont normalement pas besoin d'exécuter cette application directement ; KService l'exécutera si nécessaire, lorsque l'une des fichiers dont les données sont mises en cache sera modifiée.

OPTIONS

--global

Ignore les fichiers définis par l'utilisateur (dans XDG_DATA_HOME). Ceci n'est actuellement pris en charge que sur les systèmes UNIX®.

--noincremental

Au lieu d'utiliser le cache existant et de ne mettre à jour que les informations qui ont été modifiées ou ajoutées, commencez avec un cache vide. Ignoré si --global est défini.

--menutest

Teste la génération de la base de données du menu des applications. Ne reconstruit pas le cache.

--testmode

Utilise le « mode test » de QStandardPaths pour éviter d'interférer avec les données utilisateur. Ceci est destiné à être utilisé avec les tests unitaires.

--track menu-id

Suivre un ID de menu pour le débogage.

--author

Afficher les informations sur l'auteur.

--license

Afficher les informations sur la licence.

-h, --help

Afficher un bref texte d'aide.

-v , --version

Afficher les informations sur la version.

FICHIERS

cachedir/ksycoca6_[lang]_[sha1-of-dirs]

Le cache KService généré par kbuildsycoca6. Sur les systèmes UNIX®, cachedir est généralement XDG_CACHE_HOME.
