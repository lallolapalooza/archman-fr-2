NOM

ksshaskpass - demande une phrase de passe à l'utilisateur en utilisant KDE

SYNTAXE

ksshaskpass

DESCRIPTION

ksshaskpass est une boîte de dialogue de phrase de passe basée sur KDE pour être utilisée avec OpenSSH. Elle est destinée à être appelée par le programme ssh-add(1) et non invoquée directement. Elle permet à ssh-add(1) d'obtenir une phrase de passe d'un utilisateur, même s'il n'est pas connecté à un terminal (en supposant qu'un écran X est disponible). Cela se produit automatiquement dans le cas où ssh-add est invoqué depuis le ~/.xsession de l'utilisateur ou comme l'un des programmes de démarrage de KDE, par exemple.

Afin d'être appelée automatiquement par ssh-add, ksshaskpass devrait être installé sous le nom de /usr/bin/ssh-askpass.

AUTEUR
