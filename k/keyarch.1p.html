NOM

keyarch - Démon DNSSEC-Tools pour archiver les anciennes clés KSK et ZSK

SYNTAXE

keyarch [options] <keyrec_file | rollrec_file>

DESCRIPTION

Le programme keyarch archive les anciennes clés KSK et ZSK. Les clés sont considérées comme anciennes si elles sont révoquées ou obsolètes. Les clés marquées comme kskrev ou zskrev sont révoquées ; les clés marquées comme kskobs ou zskobs sont obsolètes. Les clés archivées sont préfixées par les secondes depuis l'époque afin de distinguer les clés d'une zone qui portent le même numéro à cinq chiffres.

Si l'argument de fichier requis est un fichier keyrec, alors les clés expirées listées dans ce fichier sont archivées. Si l'argument est un fichier rollrec, les fichiers keyrec des zones contenues dans ce fichier sont vérifiés pour détecter les clés expirées.

Si l'option -zone est fournie, alors seules les clés révoquées et obsolètes appartenant à la zone spécifiée seront archivées.

Le répertoire d'archive est soit spécifique à la zone (listé dans l'enregistrement keyrec de la zone dans le fichier keyrec de la zone) soit le répertoire d'archive par défaut donné dans le fichier de configuration DNSSEC-Tools.

Le nombre de clés archivées est donné comme code de sortie du programme. Les codes de sortie d'erreur sont négatifs.

OPTIONS

Les options suivantes sont reconnues :

-zone zone_file
Nom de la zone dont les KSK seront archivées. Si ceci n'est pas donné, alors toutes les zones définies dans le fichier rollrec seront vérifiées.
-kskonly
Archiver uniquement les clés KSK.
-zskonly
Archiver uniquement les clés ZSK.
-dtconfig config_file
Nom d'un fichier de configuration DNSSEC-Tools alternatif à traiter. Si spécifié, ce fichier de configuration est utilisé à la place du fichier de configuration DNSSEC-Tools normal, pas en complément. De plus, il sera traité avant les fichiers keyrec, les fichiers rollrec et les options en ligne de commande.
-quiet
Aucune sortie ne sera produite.
-verbose
Une sortie détaillée sera produite.
-help
Afficher un message d'utilisation.
-Version
Affiche les informations de version pour keyarch et le paquet DNSSEC-Tools.

VALEURS DE RETOUR

En cas de succès, le code de retour de keyarch est le nombre de clés archivées.

keyarch a un code de retour de 0 si le message d'aide est affiché.

keyarch a un code de retour négatif si une erreur est rencontrée.
