Eric Paris Jan 2015

NOM

kubectl completion - Génère le code de complétion du shell pour le shell spécifié (bash, zsh, fish, ou powershell)

SYNTAXE

kubectl completion [OPTIONS]

DESCRIPTION

Génère le code de complétion du shell pour le shell spécifié (bash, zsh, fish, ou powershell). Le code du shell doit être évalué pour fournir une complétion interactive des commandes kubectl. Cela peut être fait en le sourçant depuis le .bash_profile.

Des instructions détaillées sur la façon de procéder sont disponibles ici :

    pour macOS :
    https://kubernetes.io/docs/tasks/tools/install-kubectl-macos/#enable-shell-autocompletion
    pour linux :
    https://kubernetes.io/docs/tasks/tools/install-kubectl-linux/#enable-shell-autocompletion
    pour windows :
    https://kubernetes.io/docs/tasks/tools/install-kubectl-windows/#enable-shell-autocompletion

Note pour les utilisateurs de zsh : [1] les complétions zsh ne sont supportées que dans les versions de zsh >= 5.2.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, ce flag peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Le nom du cluster kubeconfig à utiliser

--context="" Le nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes vers le serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exige que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, le namespace de portée pour cette requête CLI

--password="" Mot de passe pour l'authentification basique auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier où écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas atteindre la limite de temps des requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification Bearer pour le serveur API

--user="" Le nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification basique auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée

--warnings-as-errors=false Traite les avertissements reçus du serveur comme des erreurs et quitte avec un code de sortie non nul

EXEMPLE

  # Installation de la complétion bash sur macOS avec homebrew
  ## Si vous utilisez Bash 3.2 inclus avec macOS
  brew install bash-completion
  ## Ou, si vous utilisez Bash 4.1+
  brew install bash-completion@2
  ## Si kubectl est installé via homebrew, cela devrait fonctionner immédiatement
  ## Si vous l'avez installé par d'autres moyens, vous devrez peut-être ajouter la complétion à votre répertoire de complétion
  kubectl completion bash > $(brew --prefix)/etc/bash_completion.d/kubectl
  # Installation de la complétion bash sous Linux
  ## Si bash-completion n'est pas installé sous Linux, installez le paquet 'bash-completion'
  ## via le gestionnaire de paquets de votre distribution.
  ## Chargez le code de complétion kubectl pour bash dans le shell actuel
  source <(kubectl completion bash)
  ## Écrivez le code de complétion bash dans un fichier et sourcez-le depuis .bash_profile
  kubectl completion bash > ~/.kube/completion.bash.inc
  printf "
  # kubectl shell completion
  source '$HOME/.kube/completion.bash.inc'
  " >> $HOME/.bash_profile
  source $HOME/.bash_profile
  # Chargez le code de complétion kubectl pour zsh[1] dans le shell actuel
  source <(kubectl completion zsh)
  # Configurez le code de complétion kubectl pour zsh[1] pour qu'il se charge au démarrage
  kubectl completion zsh > "${fpath[1]}/_kubectl"
  # Chargez le code de complétion kubectl pour fish[2] dans le shell actuel
  kubectl completion fish | source
  # Pour charger les complétions pour chaque session, exécutez une fois :
  kubectl completion fish > ~/.config/fish/completions/kubectl.fish
  # Chargez le code de complétion kubectl pour powershell dans le shell actuel
  kubectl completion powershell | Out-String | Invoke-Expression
  # Configurez la complétion kubectl pour powershell pour qu'elle s'exécute au démarrage
  ## Enregistrez le code de complétion dans un script et exécutez-le dans le profil
  kubectl completion powershell > $HOME\.kube\completion.ps1
  Add-Content $PROFILE "$HOME\.kube\completion.ps1"
  ## Exécutez le code de complétion dans le profil
  Add-Content $PROFILE "if (Get-Command kubectl -ErrorAction SilentlyContinue) {
  kubectl completion powershell | Out-String | Invoke-Expression
  }"
  ## Ajoutez le code de complétion directement au script $PROFILE
  kubectl completion powershell >> $PROFILE
