NOM

kubeadm init phase addon coredns - Installer l'extension CoreDNS dans un cluster Kubernetes

SYNTAXE

kubeadm init phase addon coredns [OPTIONS]

DESCRIPTION

Installe les composants de l'extension CoreDNS via le serveur API. Veuillez noter que bien que le serveur DNS soit déployé, il ne sera planifié qu'après l'installation de CNI.

OPTIONS

--config="" Chemin vers un fichier de configuration kubeadm.

--dry-run=false N'appliquez aucun changement ; affichez simplement ce qui serait fait.

--feature-gates="" Un ensemble de paires clé=valeur décrivant les portails de fonctionnalités pour diverses fonctionnalités. Les options sont : ControlPlaneKubeletLocalMode=true|false (BÊTA - par défaut=true) NodeLocalCRISocket=true|false (BÊTA - par défaut=true) PublicKeysECDSA=true|false (OBSOLÈTE - par défaut=false) RootlessControlPlane=true|false (ALPHA - par défaut=false) WaitForAllControlPlaneComponents=true|false (par défaut=true)

--image-repository="registry.k8s.io" Choisissez un registre de conteneurs pour extraire les images du plan de contrôle.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'indicateur n'est pas défini, un ensemble d'emplacements standard peut être recherché pour trouver un fichier kubeconfig existant.

--kubernetes-version="stable-1" Choisissez une version spécifique de Kubernetes pour le plan de contrôle.

--print-manifest=false Affiche les manifestes de l'extension sur STDOUT au lieu de les installer.

--service-cidr="10.96.0.0/12" Utilisez une plage alternative d'adresses IP pour les VIP de service.

--service-dns-domain="cluster.local" Utilisez un domaine alternatif pour les services, par exemple "myorg.internal".

OPTIONS INHERITÉS DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée.
