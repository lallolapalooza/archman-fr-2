NOM

kchashmgr - interface en ligne de commande pour gérer la base de données de hachage de fichiers

DESCRIPTION

La commande `kchashmgr' est un utilitaire pour tester et déboguer la base de données de hachage de fichiers et ses applications. `chemin' spécifie le chemin d'un fichier de base de données. `clé' spécifie la clé d'un enregistrement. `valeur' spécifie la valeur d'un enregistrement. `fichier' spécifie le fichier d'entrée/sortie.


kchashmgr create [-otr] [-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] chemin
Crée un fichier de base de données.
kchashmgr inform [-onl|-otl|-onr] [-st] chemin
Affiche des informations d'état.
kchashmgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] chemin clé valeur
Stocke un enregistrement.
kchashmgr remove [-onl|-otl|-onr] [-sx] chemin clé
Supprime un enregistrement.
kchashmgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] chemin clé
Affiche la valeur d'un enregistrement.
kchashmgr list [-onl|-otl|-onr] [-max num] [-rm] [-sx] [-pv] [-px] chemin [clé]
Affiche les clés de tous les enregistrements, séparées par des sauts de ligne.
kchashmgr clear [-onl|-otl|-onr] chemin
Supprime tous les enregistrements d'une base de données.
kchashmgr import [-onl|-otl|-onr] [-sx] chemin [fichier]
Importe des enregistrements à partir d'un fichier TSV.
kchashmgr copy [-onl|-otl|-onr] chemin fichier
Copie la base de données entière.
kchashmgr dump [-onl|-otl|-onr] chemin [fichier]
Exporté des enregistrements dans un fichier instantané.
kchashmgr load [-otr] [-onl|-otl|-onr] chemin [fichier]
Charge des enregistrements à partir d'un fichier instantané.
kchashmgr defrag [-onl|-otl|-onr] chemin
Effectue la défragmentation.
kchashmgr setbulk [-onl|-otl|-onr] chemin clé valeur ...
Stocke des enregistrements en une fois.
kchashmgr removebulk [-onl|-otl|-onr] [-sx] chemin clé ...
Supprime des enregistrements en une fois.
kchashmgr getbulk [-onl|-otl|-onr] [-sx] [-px] chemin clé ...
Récupère des enregistrements en une fois.
kchashmgr check [-onl|-otl|-onr] chemin
Vérifie la cohérence.

Les options sont les suivantes.

-otr : ouvre la base de données avec l'option de troncature.
-onl : ouvre la base de données avec l'option sans verrouillage.
-otl : ouvre la base de données avec l'option de tentative de verrouillage.
-onr : ouvre la base de données avec l'option de réparation automatique désactivée.
-apow num : spécifie la puissance de l'alignement de la taille des enregistrements.
-fpow num : spécifie la puissance de la capacité du pool de blocs libres.
-ts : ajuste la base de données avec l'option petite.
-tl : ajuste la base de données avec l'option linéaire.
-tc : ajuste la base de données avec l'option de compression.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-st : affiche des informations diverses.
-add : effectue une opération d'ajout.
-app : effectue une opération d'ajout.
-rep : effectue une opération de remplacement.
-inci : effectue une opération d'incrémentation entière.
-incd : effectue une opération d'incrémentation de nombre réel.
-sx : les données d'entrée sont évaluées comme une chaîne de données hexadécimales.
-rm : supprime l'enregistrement.
-px : les données de sortie sont converties en une chaîne de données hexadécimales.
-pz : n'ajoute pas de saut de ligne à la fin de la sortie.
-max num : spécifie le nombre maximum d'enregistrements à afficher.
-pv : affiche également les valeurs des enregistrements.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
