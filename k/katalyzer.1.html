NOM

katalyzer - analyse les flux Kate et affiche diverses informations à leur sujet.

SYNTAXE

katalyzer [-hV] [-l types] [-l!] [ fichier_entree ]

DESCRIPTION

katalyzer analyse les flux Kate et affiche des informations à leur sujet. Le type d'informations à sélectionner est choisi sur la ligne de commande. Plusieurs flux Kate multiplexés peuvent être analysés simultanément.

OPTIONS

-h
Affiche l'aide de la ligne de commande.
-V
Affiche les informations de version.
-l types
Sélectionne les types d'informations à enregistrer, parmi la liste ci-dessous. Ces caractères peuvent être concaténés dans une seule option -l, comme le fait par exemple ls (ex: katalyzer -l Ttv). Référez-vous à l'aide en ligne de commande de katalyzer pour une liste à jour complète des types.
e: erreurs
p: paquet
c: informations spécifiques au conteneur
T: Timing (Synchronisation)
t: texte
v: événement
d: dump de la page et des paquets
S: statistiques
-: informations diverses n'appartenant à aucun autre type
-l!
Raccourci pour sélectionner toutes les informations à enregistrer.

EXEMPLES

Analyse tout flux Kate dans un fichier Ogg :


katalyzer input.ogg

Analyse tout flux Kate dans un fichier Ogg, affichant uniquement les erreurs :


katalyzer -l e input.ogg
