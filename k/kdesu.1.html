KDESU(1) Manuel de l'utilisateur KDE KDESU(1)

NOM

kdesu - Lance un programme avec des privilèges élevés

SYNTAXE

kdesu [-c commande] [-d] [-f fichier] [-i nom icône] [-n] [-p priorité] [-r] [-s] [-t] [-u utilisateur] [--noignorebutton] [--attach winid]

kdesu [Options génériques KDE] [Options génériques Qt™]

DESCRIPTION

KDE su est une interface graphique pour la commande UNIX® su pour l'environnement de bureau K. Elle vous permet d'exécuter un programme en tant qu'un utilisateur différent en fournissant le mot de passe de cet utilisateur. KDE su est un programme non privilégié ; il utilise le su du système.

KDE su possède une fonctionnalité supplémentaire : elle peut facultativement mémoriser les mots de passe pour vous. Si vous utilisez cette fonctionnalité, vous n'avez besoin d'entrer le mot de passe qu'une seule fois pour chaque commande.

Ce programme est destiné à être lancé depuis la ligne de commande ou à partir de fichiers .desktop.

Étant donné que kdesu n'est plus installé dans $(kf5-config --prefix)/bin mais dans kf5-config --path libexec et par conséquent pas dans votre Path, vous devez utiliser $(kf5-config --path libexec)kdesu pour lancer kdesu.

OPTIONS

-c commande

Ceci spécifie la commande à exécuter en tant que root. Elle doit être passée en un seul argument. Ainsi, par exemple, si vous souhaitez lancer un nouveau gestionnaire de fichiers, vous entrerez à l'invite : $(kf5-config --path libexec)kdesu -c Dolphin

-d

Affiche les informations de débogage.

-f fichier

Cette option permet une utilisation efficace de KDE su dans les fichiers .desktop. Elle indique à KDE su d'examiner le fichier spécifié par fichier. Si ce fichier est inscriptible par l'utilisateur actuel, KDE su exécutera la commande en tant qu'utilisateur actuel. S'il n'est pas inscriptible, la commande est exécutée en tant qu'utilisateur utilisateur (par défaut root).

fichier est évalué ainsi : si fichier commence par un /, il est considéré comme un nom de fichier absolu. Sinon, il est considéré comme le nom d'un fichier de configuration global KDE.

-i nom icône

Spécifie l'icône à utiliser dans la boîte de dialogue du mot de passe. Vous pouvez spécifier seulement le nom, sans aucune extension.

-n

Ne pas conserver le mot de passe. Ceci désactive la case à cocher "conserver le mot de passe" dans la boîte de dialogue du mot de passe.

-p priorité

Définit la valeur de priorité. La priorité est un nombre arbitraire entre 0 et 100, où 100 signifie la priorité la plus haute, et 0 la plus basse. La valeur par défaut est 50.

-r

Utiliser la planification temps réel.

-s

Arrête le démon kdesu. C'est le démon qui met en cache les mots de passe réussis en arrière-plan. Cette fonctionnalité peut également être désactivée avec -n lorsque KDE su est lancé initialement.

-t

Active la sortie terminal. Ceci désactive la conservation du mot de passe. Ceci est largement à des fins de débogage ; si vous souhaitez exécuter une application en mode console, utilisez plutôt le su standard.

-u utilisateur

Bien que l'utilisation la plus courante de KDE su soit d'exécuter une commande en tant que superutilisateur, vous pouvez fournir n'importe quel nom d'utilisateur et le mot de passe approprié.

--noignorebutton

N'affiche pas de bouton ignorer.

--attach winid

Rend la boîte de dialogue transitoire pour une application X spécifiée par winid.

VOIR AUSSI

su(1)

Une documentation utilisateur plus détaillée est disponible sur help:/kdesu (soit en entrant cette URL dans Konqueror, soit en exécutant khelpcenter help:/kdesu).

EXEMPLES

Exécutez kfmclient en tant qu'utilisateur jim, et affichez l'icône Konqueror dans la boîte de dialogue du mot de passe :

$(kf5-config --path libexec)kdesu -u jim -i konqueror kfmclient
