NOM

ktutil - utilitaire de maintenance de fichier keytab Kerberos

SYNOPSIS

ktutil

DESCRIPTION

La commande ktutil invoque une interface de commande à partir de laquelle un administrateur peut lire, écrire ou modifier des entrées dans un keytab. (Les fichiers srvtab Kerberos V4 ne sont plus pris en charge.)

COMMANDES

lister

lister [-t] [-k] [-e]

Affiche la liste de clés actuelle. Si -t, -k et/ou -e sont spécifiés, affiche également le horodatage, le contenu de la clé ou le type de chiffrement (respectivement).

Alias : l

lire_kt

lire_kt keytab

Lit le fichier keytab Kerberos V5 keytab dans la liste de clés actuelle.

Alias : rkt

ecrire_kt

ecrire_kt keytab

Écrit la liste de clés actuelle dans le fichier keytab Kerberos V5 keytab.

Alias : wkt

vider_liste

vider_liste

Vide la liste de clés actuelle.

Alias : clear

supprimer_entree

supprimer_entree slot

Supprime l'entrée dans la position slot de la liste de clés actuelle.

Alias : delent

ajouter_entree

ajouter_entree {-cle|-motdepasse} -p principal -k kvno [-e type_chiffrement] [-f|-s sel]

Ajoute principal à la liste de clés en utilisant la clé ou le mot de passe. Si le drapeau -f est spécifié, les informations de sel seront récupérées auprès du KDC ; dans ce cas, le drapeau -e peut être omis, ou il peut être fourni pour forcer un type de chiffrement particulier. Si le drapeau -f n'est pas spécifié, le drapeau -e doit être spécifié, et le sel par défaut sera utilisé sauf s'il est remplacé avec l'option -s.

Alias : addent

lister_demandes

lister_demandes

Affiche une liste des commandes disponibles.

Alias : lr, ?

quitter

quitter

Quitte ktutil.

Alias : exit, q

EXEMPLE

ktutil:  ajouter_entree -motdepasse -p alice@BLEEP.COM -k 1 -e
    aes128-cts-hmac-sha1-96
Mot de passe pour alice@BLEEP.COM :
ktutil:  ajouter_entree -motdepasse -p alice@BLEEP.COM -k 1 -e
    aes256-cts-hmac-sha1-96
Mot de passe pour alice@BLEEP.COM :
ktutil:  ecrire_kt alice.keytab
ktutil:
