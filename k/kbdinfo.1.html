KBDINFO(1) Manuel des commandes générales KBDINFO(1)

NOM

kbdinfo - lire des informations sur l'état du clavier

SYNTAXE

kbdinfo [options] getmode [text|graphics]
kbdinfo [options] gkbmode [raw|xlate|mediumraw|unicode]
kbdinfo [options] gkbmeta [metabit|escprefix]
kbdinfo [options] gkbled [scrolllock|numlock|capslock]

DESCRIPTION

L'utilitaire permet de lire et de vérifier divers paramètres du clavier et de la console virtuelle.

getmode
Obtenir ou vérifier le mode de la console virtuelle.
gkbmode
Obtient le mode actuel du clavier.
raw
Mode brut (scancode). Ce sont les codes bruts générés par le clavier.
mediumraw
Mode moyen brut (scancode). C'est un mode moyen brut étendu, avec les touches supérieures à 127 encodées comme 0, 7 bits de poids fort, 7 bits de poids faible, le 0 portant le drapeau 'haut' si nécessaire. 0 est réservé, donc cela ne devrait pas interférer avec d'autres choses. Les deux octets après 0 auront toujours le drapeau haut réglé pour ne pas interférer avec les anciennes applications. Cela permet 16384 codes de touches différents, ce qui devrait être suffisant.
xlate
Traduit les codes de touches en utilisant la table de correspondance. Ce sont les codes générés via le mappage de symboles de touches actuel.
unicode
Mode Unicode.
gkbmeta
Obtient le mode de gestion de la touche méta.
escprefix
Spécifie si l'appui sur la touche méta (alt) génère un préfixe ESC (\033) suivi du symbole de touche.
metabit
Le symbole de touche avec le bit de poids fort défini.
gkbled
Obtient les indicateurs du clavier Verr. Maj, Verr. Num, Arrêt Défil (pas les lumières).
scrolllock
L'indicateur Arrêt Défil est activé.
numlock
L'indicateur Verr. Num est activé.
capslock
L'indicateur Verr. Maj est activé.

OPTIONS

-C, --console=DEV
le périphérique console à utiliser.
-V, --version
affiche le numéro de version.
-h, --help
affiche ce message d'utilisation.
