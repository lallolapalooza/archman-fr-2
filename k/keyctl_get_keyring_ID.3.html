KEYCTL_GET_KEYRING_ID(3) Appels de gestion de clés Linux KEYCTL_GET_KEYRING_ID(3)

NOM

keyctl_get_keyring_ID - obtenir l'ID d'un keyring spécial

SYNTAXE

#include <keyutils.h>

key_serial_t keyctl_get_keyring_ID(key_serial_t key,
 int create);

DESCRIPTION

keyctl_get_keyring_ID() fait correspondre une clé spéciale ou un ID de keyring à l'identifiant série de la clé représentant réellement cette fonctionnalité. L'identifiant série sera retourné si cette clé existe.

Si la clé ou le keyring n'existe pas encore, alors si create est non nul, la clé ou le keyring sera créé s'il est approprié de le faire.

Les identifiants de clés spéciaux suivants peuvent être spécifiés comme key :

KEY_SPEC_THREAD_KEYRING
Ceci spécifie le keyring propre au thread de l'appelant.
KEY_SPEC_PROCESS_KEYRING
Ceci spécifie le keyring propre au processus de l'appelant.
KEY_SPEC_SESSION_KEYRING
Ceci spécifie le keyring propre à la session de l'appelant.
KEY_SPEC_USER_KEYRING
Ceci spécifie le keyring propre à l'UID de l'appelant.
KEY_SPEC_USER_SESSION_KEYRING
Ceci spécifie le keyring propre à la session de l'UID de l'appelant.
KEY_SPEC_REQKEY_AUTH_KEY
Ceci spécifie la clé d'autorisation créée par request_key() et passée au processus qu'il lance pour générer une clé.

Si un ID de keyring valide est passé, celui-ci sera simplement retourné si la clé existe ; une erreur sera générée si elle n'existe pas.

VALEUR RE tourNEE

En cas de succès, keyctl_get_keyring_ID() retourne l'identifiant série de la clé trouvée. En cas d'erreur, la valeur -1 sera retournée et errno aura été définie à une erreur appropriée.

ERREURS

ENOKEY
Aucune clé correspondante n'a été trouvée.
ENOMEM
Mémoire insuffisante pour créer une clé.
EDQUOT
Le quota de clés pour cet utilisateur serait dépassé en créant cette clé ou en la liant au keyring.

LIAISON

C'est une fonction de bibliothèque qui peut être trouvée dans libkeyutils. Lors de la liaison, -lkeyutils doit être spécifié à l'éditeur de liens.
