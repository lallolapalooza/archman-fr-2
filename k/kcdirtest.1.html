NOM

kcdirtest - interface en ligne de commande pour tester la base de données de hachage de répertoires

DESCRIPTION

La commande `kcdirtest' est un utilitaire pour les tests de fonctionnalité et les tests de performance de la base de données de hachage de répertoires. Cette commande est utilisée dans le format suivant. `path' spécifie le chemin d'un fichier de base de données. `rnum' spécifie le nombre d'itérations.


kcdirtest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Effectue des tests en ordre.
kcdirtest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Effectue des opérations de mise en file d'attente.
kcdirtest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Effectue des opérations mixtes sélectionnées au hasard.
kcdirtest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-tc] [-lv] path rnum
Effectue des tests de transaction.

Les options comprennent les suivantes.

-th num : spécifie le nombre de threads de travail.
-rnd : effectue des tests aléatoires.
-set : effectue uniquement une opération de réglage.
-get : effectue uniquement une opération d'obtention.
-getw : effectue uniquement une opération d'obtention avec un tampon.
-rem : effectue uniquement une opération de suppression.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-oat : ouvre la base de données avec l'option de transaction automatique.
-oas : ouvre la base de données avec l'option de synchronisation automatique.
-onl : ouvre la base de données avec l'option de non verrouillage.
-otl : ouvre la base de données avec l'option de verrouillage conditionnel.
-onr : ouvre la base de données avec l'option de non réparation automatique.
-tc : optimise la base de données avec l'option de compression.
-lv : signale toutes les erreurs.
-it num : spécifie le nombre de répétitions.
-hard : effectue une synchronisation physique.

Cette commande renvoie 0 en cas de succès, autre chose en cas d'échec.
