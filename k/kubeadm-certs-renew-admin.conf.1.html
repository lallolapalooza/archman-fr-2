NOM

kubeadm certs renew admin.conf - Renouveler le certificat intégré dans le fichier kubeconfig pour l'administrateur et pour kubeadm lui-même

SYNTAXE

kubeadm certs renew admin.conf [OPTIONS]

DESCRIPTION

Renouveler le certificat intégré dans le fichier kubeconfig pour l'administrateur et pour kubeadm lui-même.

Les renouvellements s'exécutent sans condition, quelle que soit la date d'expiration du certificat ; les attributs supplémentaires tels que les SAN seront basés sur le fichier/les certificats existants, il n'est pas nécessaire de les réintroduire.

Le renouvellement par défaut tente d'utiliser l'autorité de certification dans le PKI local géré par kubeadm ; en alternative, il est possible d'utiliser l'API de certificat de K8s pour le renouvellement du certificat, ou en dernier recours, de générer une requête CSR.

Après le renouvellement, pour que les modifications soient effectives, il est nécessaire de redémarrer les composants du plan de contrôle et éventuellement de redistribuer le certificat renouvelé si le fichier est utilisé ailleurs.

OPTIONS

--cert-dir="/etc/kubernetes/pki" Le chemin où enregistrer les certificats

--config="" Chemin vers un fichier de configuration kubeadm.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'indicateur n'est pas défini, un ensemble d'emplacements standard peut être recherché pour trouver un fichier kubeconfig existant.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela forcera kubeadm à utiliser chroot sur le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
