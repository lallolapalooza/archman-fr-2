NOM

kubeone-local - Réconcilier le cluster local un-nœud-tout-en-un

SYNTAXE

kubeone local [indicateurs]

DESCRIPTION

Initialise le cluster tout-en-un sur une machine locale.

OPTIONS

--apiendpoint="" point de terminaison kube-apiserver à initier, par défaut autodétection

-y, --auto-approve[=false] approuver automatiquement le plan

-b, --backup="" chemin vers lequel le fichier .tar.gz de sauvegarde du PKI doit être placé (par défaut : emplacement du fichier de configuration du cluster)

--force-install[=false] utiliser la force pour installer de nouvelles versions binaires (!dangereux !)

--force-upgrade[=false] forcer le lancement du processus de mise à niveau

-h, --help[=false] aide pour local

--kubernetes-version="v1.32.5" version de kubernetes à installer en l'absence de manifeste

--no-init[=false] ne pas initialiser le cluster (seulement installer les binaires)

OPTIONS HERITEES DES COMMANDES PARENTES

-c, --credentials="" Fichier à partir duquel charger les identifiants et secrets

-d, --debug[=false] sortie de débogage avec pile d'appels

-l, --log-format="text" format pour la journalisation

-m, --manifest="./kubeone.yaml" Chemin vers la configuration KubeOne

-t, --tfjson="" Source de la sortie terraform en JSON - à lire depuis stdin. Si le chemin est un fichier, son contenu sera utilisé. Si le chemin est un répertoire, terraform output -json sera exécuté dans ce répertoire

-v, --verbose[=false] sortie détaillée

EXEMPLE

kubeone local
