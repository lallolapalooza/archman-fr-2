krb5-config(1)

Paquet: krb5

Licences: custom

KRB5-CONFIG(1) Kerberos MIT KRB5-CONFIG(1)

NOM

krb5-config - outil pour lier les programmes aux bibliothèques MIT Kerberos

SYNOPIS

krb5-config [--help | --all | --version | --vendor | --prefix | --exec-prefix | --defccname | --defktname | --defcktname | --cflags | --libs [bibliothèques]]

DESCRIPTION

krb5-config indique au programmeur quelles options utiliser pour compiler et lier les programmes aux bibliothèques Kerberos installées.

OPTIONS

--help
affiche un message d'utilisation. C'est le comportement par défaut lorsqu'aucune option n'est spécifiée.
--all
affiche la version, le fournisseur, le préfixe et le préfixe d'exécution.
--version
affiche le numéro de version de l'installation Kerberos.
--vendor
affiche le nom du fournisseur de l'installation Kerberos.
--prefix
affiche le préfixe pour lequel l'installation Kerberos a été compilée.
--exec-prefix
affiche le préfixe pour les exécutables pour lesquels l'installation Kerberos a été compilée.
--defccname
affiche l'emplacement du cache d'identification par défaut intégré.
--defktname
affiche l'emplacement du fichier keytab par défaut intégré.
--defcktname
affiche l'emplacement du fichier keytab client (initiateur) par défaut intégré.
--cflags
affiche les options de compilation utilisées pour construire l'installation Kerberos.
--libs [bibliothèque]
affiche les options du compilateur nécessaires pour lier bibliothèque. Les valeurs autorisées pour bibliothèque sont :
krb5 Applications Kerberos 5 (par défaut)
gssapi Applications GSSAPI avec liaisons Kerberos 5
kadm-client Client Kadmin
kadm-server Serveur Kadmin
kdb Applications accédant à la base de données Kerberos

EXEMPLES

krb5-config est particulièrement utile pour compiler avec une installation Kerberos installée dans un emplacement non standard. Par exemple, une installation Kerberos installée dans /opt/krb5/ mais utilisant des bibliothèques dans /usr/local/lib/ pour la localisation textuelle produirait la sortie suivante :

shell% krb5-config --libs krb5
-L/opt/krb5/lib -Wl,-rpath -Wl,/opt/krb5/lib -L/usr/local/lib -lkrb5 -lk5crypto -lcom_err
