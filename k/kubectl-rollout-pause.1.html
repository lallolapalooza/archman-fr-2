Paquet: kubectl

Licences: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

NOM

kubectl rollout pause - Marquer la ressource fournie comme en pause

SYNTAXE

kubectl rollout pause [OPTIONS]

DESCRIPTION

Marquer la ressource fournie comme en pause.

Les ressources mises en pause ne seront pas réconciliées par un contrôleur. Utilisez "kubectl rollout resume" pour reprendre une ressource mise en pause. Actuellement, seuls les déploiements peuvent être mis en pause.

OPTIONS

--allow-missing-template-keys=true Si vrai, ignorer toutes les erreurs dans les modèles lorsqu'un champ ou une clé de mappage est manquant dans le modèle. Ne s'applique qu'aux formats de sortie golang et jsonpath.

--field-manager="kubectl-rollout" Nom du gestionnaire utilisé pour suivre la propriété des champs.

-f, --filename=[] Nom du fichier, répertoire ou URL vers des fichiers identifiant la ressource à obtenir auprès d'un serveur.

-k, --kustomize="" Traiter le répertoire kustomization. Cette option ne peut pas être utilisée conjointement avec -f ou -R.

-o, --output="" Format de sortie. L'un des suivants : (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

-R, --recursive=false Traiter le répertoire utilisé dans -f, --filename de manière récursive. Utile lorsque vous souhaitez gérer des manifestes liés organisés dans le même répertoire.

-l, --selector="" Sélecteur (requête d'étiquette) pour filtrer, prend en charge '=', '==', '!=', 'in', 'notin'. (par exemple, -l key1=value1,key2=value2,key3 in (value3)). Les objets correspondants doivent satisfaire toutes les contraintes d'étiquettes spécifiées.

--show-managed-fields=false Si vrai, conserver les champs gérés lors de l'affichage des objets au format JSON ou YAML.

--template="" Chaîne de modèle ou chemin vers un fichier modèle à utiliser lorsque -o=go-template, -o=go-template-file. Le format du modèle est le modèle golang [http://golang.org/pkg/text/template/#pkg-overview].

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, refuser la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié quant à sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la porte de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, le scope du namespace pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. L'un des suivants : (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" Durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas utiliser de délai d'attente pour les requêtes.

-s, --server="" Adresse et port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton porteur pour l'authentification auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Marquer le déploiement nginx comme en pause
  # Tout état actuel du déploiement continuera de fonctionner ; les nouvelles mises à jour
  # du déploiement n'auront pas d'effet tant que le déploiement est en pause
  kubectl rollout pause deployment/nginx
