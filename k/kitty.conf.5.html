Nom

kitty.conf - Fichier de configuration pour kitty

Aperçu

kitty est hautement personnalisable, de la personnalisation des raccourcis clavier au rendu par image. Voir ci-dessous pour un aperçu de toutes les possibilités de personnalisation.

Vous pouvez ouvrir le fichier de configuration dans kitty en appuyant sur ctrl+shift+f2 (⌘+, sur macOS). Un fichier kitty.conf avec des configurations par défaut commentées et des descriptions sera créé si le fichier n'existe pas. Vous pouvez recharger le fichier de configuration dans kitty en appuyant sur ctrl+shift+f5 (⌃+⌘+, sur macOS) ou en envoyant le signal SIGUSR1 à kitty avec kill -SIGUSR1 $KITTY_PID. Vous pouvez également afficher la configuration actuelle en appuyant sur ctrl+shift+f6 (⌥+⌘+, sur macOS).

kitty recherche un fichier de configuration dans les répertoires de configuration du système d'exploitation (généralement ~/.config/kitty/kitty.conf) mais vous pouvez passer un chemin spécifique via l'option kitty --config <#cmdoption-kitty-config> ou utiliser la variable d'environnement KITTY_CONFIG_DIRECTORY <#envvar-KITTY_CONFIG_DIRECTORY>. Voir kitty --config <#cmdoption-kitty-config> pour plus de détails.

Les commentaires peuvent être ajoutés au fichier de configuration sous forme de lignes commençant par le caractère #. Cela ne fonctionne que si le caractère # est le premier caractère de la ligne.

Les lignes peuvent être divisées en commençant la ligne suivante par le caractère \. Tous les espaces blancs en tête et le caractère \ sont supprimés.

Vous pouvez inclure des fichiers de configuration secondaires via la directive include. Si vous utilisez un chemin relatif pour include, il est résolu par rapport à l'emplacement du fichier de configuration actuel. Notez que les variables d'environnement sont développées, donc ${USER}.conf devient name.conf si USER=name. Une variable d'environnement spéciale KITTY_OS <#envvar-KITTY_OS> est disponible, pour détecter le système d'exploitation. Il s'agit de linux, macos ou bsd. De plus, vous pouvez utiliser globinclude pour inclure des fichiers correspondant à un modèle glob de shell et envinclude pour inclure la configuration à partir des variables d'environnement. Enfin, vous pouvez générer dynamiquement la configuration en exécutant un programme à l'aide de geninclude. Par exemple :

# Inclure other.conf
include other.conf
# Inclure les fichiers *.conf de tous les sous-répertoires de kitty.d dans le répertoire de configuration de kitty
globinclude kitty.d/**/*.conf
# Inclure le *contenu* de toutes les variables d'environnement commençant par KITTY_CONF_
envinclude KITTY_CONF_*
# Exécuter le script dynamic.py placé dans le même répertoire que ce fichier de configuration
# et inclure son :file:`STDOUT`. Notez que les scripts Python sont les plus rapides
# car ils utilisent l'interpréteur Python intégré, mais tout script exécutable
# ou programme est pris en charge, dans n'importe quel langage. N'oubliez pas de rendre le script
# exécutable.
geninclude dynamic.py

Remarque :

La coloration syntaxique pour kitty.conf dans vim est disponible via vim-kitty https://github.com/fladson/vim-kitty.

Polices

kitty dispose d'une gestion des polices très puissante. Vous pouvez configurer des graisses de polices individuelles et même spécifier des polices spéciales pour des caractères particuliers.

font_family, bold_font, italic_font, bold_italic_font
font_family      monospace
bold_font        auto
italic_font      auto
bold_italic_font auto

Vous pouvez spécifier différentes polices pour les variantes gras/italique/gras-italique. Le moyen le plus simple de sélectionner des polices est d'exécuter la commande kitten choose-fonts qui présentera une interface conviviale pour sélectionner les polices souhaitées avec des aperçus et la prise en charge de la sélection des polices variables et des fonctionnalités de police. Si vous souhaitez apprendre à sélectionner les polices manuellement, lisez la syntaxe de spécification des polices <#font-spec-syntax>.

font_size
font_size 11.0

Taille de la police (en points).

force_ltr
force_ltr no

kitty ne prend pas en charge le BIDI (texte bidirectionnel), cependant, pour les scripts RTL, les mots sont automatiquement affichés en RTL. C'est-à-dire que dans un script RTL, les mots "BONJOUR LE MONDE" s'affichent dans kitty comme "LE MONDE BONJOUR", et si vous essayez de sélectionner une sous-chaîne d'une chaîne en forme RTL, vous obtiendrez le caractère qui s'y trouverait si la chaîne était LTR. Par exemple, en supposant que le mot hébreu ירושלים, la sélection du caractère qui apparaît à l'écran comme ם écrit en fait dans le tampon de sélection le caractère י. Le comportement par défaut de kitty est utile en conjonction avec un filtre pour inverser l'ordre des mots, cependant, si vous souhaitez manipuler des glyphes RTL, cela peut être très difficile à travailler, donc cette option est fournie pour la désactiver. De plus, cette option peut être utilisée avec le programme de ligne de commande GNU FriBidi https://github.com/fribidi/fribidi#executable pour obtenir la prise en charge BIDI, car cela forcera kitty à toujours traiter le texte comme LTR, ce que FriBidi attend pour les terminaux.

symbol_map

N'a pas de valeurs par défaut. Des exemples de valeurs sont montrés ci-dessous :

symbol_map U+E0A0-U+E0A3,U+E0C0-U+E0C7 PowerlineSymbols

Mappe les points de code Unicode spécifiés vers une police particulière. Utile si vous avez besoin d'un rendu spécial pour certains symboles, comme pour Powerline. Évite le besoin de polices patchées. Chaque point de code Unicode est spécifié sous la forme U+<code point en hexadécimal>. Vous pouvez spécifier plusieurs points de code, séparés par des virgules et des plages séparées par des traits d'union. Cette option peut être spécifiée plusieurs fois. La syntaxe est :

symbol_map points de code Nom de la famille de polices
narrow_symbols

N'a pas de valeurs par défaut. Des exemples de valeurs sont montrés ci-dessous :

narrow_symbols U+E0A0-U+E0A3,U+E0C0-U+E0C7 1

Habituellement, pour les caractères Unicode à usage privé et certains caractères symboles/dingbats, si le caractère est suivi d'un ou plusieurs espaces, kitty utilisera ces cellules supplémentaires pour rendre le caractère plus grand, si le caractère dans la police a un rapport largeur/hauteur large. En utilisant cette option, vous pouvez forcer kitty à restreindre les points de code spécifiés pour qu'ils soient rendus dans le nombre spécifié de cellules (par défaut une cellule). Cette option peut être spécifiée plusieurs fois. La syntaxe est :

narrow_symbols points de code [facultativement le nombre de cellules]
disable_ligatures
disable_ligatures never

Choisissez comment vous souhaitez gérer les ligatures multi-caractères. Par défaut, elles sont toujours rendues. Vous pouvez dire à kitty de ne pas les rendre lorsque le curseur est dessus en utilisant cursor pour faciliter l'édition, ou faire en sorte que kitty ne les rende jamais en utilisant always, si vous ne les aimez pas. La stratégie de ligature peut être définie par fenêtre soit en utilisant la facilité de contrôle à distance de kitty, soit en définissant des raccourcis pour celle-ci dans kitty.conf, par exemple :

map alt+1 disable_ligatures_in active always
map alt+2 disable_ligatures_in all never
map alt+3 disable_ligatures_in tab cursor

Notez que cela fait référence aux ligatures de programmation, généralement implémentées à l'aide de la fonctionnalité OpenType calt. Pour désactiver les ligatures générales, utilisez l'option font_features.

font_features

N'a pas de valeurs par défaut. Des exemples de valeurs sont montrés ci-dessous :

font_features none

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

Choisissez exactement quelles fonctionnalités OpenType activer ou désactiver. Notez que pour les polices principales, les fonctionnalités peuvent être spécifiées lors de la sélection de la police à l'aide du chaton choose-fonts. Ce paramètre est utile pour les polices de secours.

Certaines polices peuvent avoir des fonctionnalités intéressantes dans un terminal. Par exemple, Fira Code inclut une fonctionnalité discrétionnaire, zero, qui dans cette police modifie l'apparence du zéro (0), pour le distinguer plus facilement de Ø. Fira Code inclut également d'autres fonctionnalités discrétionnaires connues sous le nom de jeux stylistiques qui ont les balises ss01 à ss20.

Pour la syntaxe exacte à utiliser pour les fonctionnalités individuelles, consultez la documentation HarfBuzz https://harfbuzz.github.io/harfbuzz-hb-common.html#hb-feature-from-string.

Notez que ce code est indexé par le nom PostScript, et non par la famille de polices. Cela vous permet de définir des paramètres de fonctionnalités très précis ; par exemple, vous pouvez désactiver une fonctionnalité dans la police italique mais pas dans la police normale.

Sous Linux, les fonctionnalités de police sont d'abord lues à partir de la base de données FontConfig, puis cette option est appliquée, de sorte qu'elles peuvent être configurées en un seul endroit centralisé.

Pour obtenir le nom PostScript d'une police, utilisez la commande fc-scan file.ttf sous Linux ou l'outil Font Book sous macOS https://apple.stackexchange.com/questions/79875/how-can-i-get-the-postscript-name-of-a-ttf-font-installed-in-os-x.

Activer le zéro alternatif et les numéraux anciens :

font_features FiraCode-Retina +zero +onum

Activer uniquement le zéro alternatif dans la police grasse :

font_features FiraCode-Bold +zero

Désactiver les ligatures normales, mais conserver la fonctionnalité calt qui (dans cette police) rompt la monotonie :

font_features TT2020StyleB-Regular -liga +calt

En conjonction avec force_ltr, vous pourriez vouloir désactiver complètement le façonnage arabe, et ne regarder que leurs formes isolées si elles apparaissent dans un document. Vous pouvez le faire par exemple avec :

font_features UnifontMedium +isol -medi -fina -init
modify_font

Modifier les caractéristiques de la police telles que la position ou l'épaisseur du soulignement et du barré. Les modifications peuvent avoir le suffixe px pour les pixels ou % pour le pourcentage de la valeur d'origine. Pas de suffixe signifie utiliser des points. Par exemple :

modify_font underline_position -2
modify_font underline_thickness 150%
modify_font strikethrough_position 2px

De plus, vous pouvez modifier la taille de la cellule dans laquelle chaque glyphe de police est rendu et la ligne de base sur laquelle le glyphe est placé dans la cellule. Par exemple :

modify_font cell_width 80%
modify_font cell_height -2px
modify_font baseline 3

Notez que la modification de la ligne de base ajustera automatiquement les positions du soulignement et du barré du même montant. Augmenter la ligne de base élève les glyphes à l'intérieur de la cellule et la diminuer les abaisse. La diminution de la taille de la cellule peut provoquer des artefacts d'affichage, alors utilisez avec précaution.

box_drawing_scale
box_drawing_scale 0.001, 1, 1.5, 2

Les tailles des lignes utilisées pour les caractères Unicode de dessin de boîte. Ces valeurs sont en points. Elles seront mises à l'échelle par la résolution du moniteur pour obtenir une valeur en pixels. Il doit y avoir quatre valeurs correspondant aux lignes fines, normales, épaisses et très épaisses.

undercurl_style
undercurl_style thin-sparse

Le style avec lequel les boucles de surlignement sont rendues. Cette option prend la forme (thin|thick)-(sparse|dense). Thin et thick contrôlent l'épaisseur de la boucle de surlignement. Sparse et dense contrôlent la fréquence d'oscillation de la boucle. Avec sparse, la boucle atteindra son pic une fois par caractère, avec dense, deux fois. La modification dynamique de cette option en rechargeant la configuration ou par télécommande est indéfinie.

underline_exclusion
underline_exclusion 1

Par défaut, kitty rend des espaces dans les soulignements lorsqu'ils chevauchent les descendances (les parties des lettres sous la ligne de base, comme pour y, q, p etc.). Cette option contrôle l'épaisseur des espaces. Il peut s'agir d'un nombre sans unité, auquel cas il s'agit d'une fraction de l'épaisseur du soulignement telle que spécifiée dans la police, ou il peut avoir un suffixe px pour les pixels ou pt pour les points. Définissez à zéro pour désactiver les espaces. La modification dynamique de cette option en rechargeant la configuration ou par télécommande est indéfinie.

text_composition_strategy
text_composition_strategy platform

Contrôlez comment kitty compose les glyphes de texte sur la couleur d'arrière-plan. La valeur par défaut de platform vise un rendu de texte aussi proche que possible du rendu "natif" pour la plateforme sur laquelle kitty s'exécute.

Une valeur de legacy utilise l'ancienne stratégie (avant kitty 0.28) pour la composition des glyphes. Cela rendra le texte foncé sur des arrière-plans clairs plus épais et le texte clair sur des arrière-plans foncés plus fin. Cela peut également rendre certains textes comme si les traits étaient inégaux.

Vous pouvez affiner la courbe de contraste réelle utilisée pour la composition des glyphes en spécifiant jusqu'à deux nombres séparés par des espaces pour ce paramètre.

Le premier nombre est le réglage gamma, qui contrôle l'épaisseur du texte foncé sur des arrière-plans clairs. Augmenter la valeur rendra le texte plus épais. La valeur par défaut est 1.0 sous Linux et 1.7 sous macOS. Les valeurs valides sont 0.01 et plus. Le résultat est mis à l'échelle en fonction de la différence de luminance entre l'arrière-plan et le premier plan. Le texte foncé sur des arrière-plans clairs reçoit l'impact total de la courbe tandis que le texte clair sur des arrière-plans foncés est très peu affecté.

Le second nombre est un contraste multiplicateur supplémentaire. C'est un pourcentage allant de 0 à 100. La valeur par défaut est 0 sous Linux et 30 sous macOS.

Si vous souhaitez obtenir une épaisseur d'aspect similaire dans les thèmes clairs et foncés, une bonne façon d'expérimenter est de commencer par définir la valeur à 1.0 0 et d'utiliser un thème foncé. Ensuite, ajustez le second paramètre jusqu'à ce qu'il soit correct. Ensuite, basculez vers un thème clair et ajustez le premier paramètre jusqu'à ce que l'épaisseur perçue corresponde au thème foncé.

text_fg_override_threshold
text_fg_override_threshold 0

Un paramètre pour éviter un faible contraste entre les couleurs du premier plan et de l'arrière-plan. Utile lorsque vous travaillez avec des applications qui utilisent des couleurs qui ne contrastent pas bien avec votre schéma de couleurs préféré. La valeur par défaut est 0, ce qui signifie qu'aucun remplacement de couleur n'est effectué. Il existe deux modes de fonctionnement :

Une valeur avec le suffixe ratio représente le rapport de contraste minimum accepté entre la couleur du premier plan et celle de l'arrière-plan. Les valeurs possibles vont de 0.0 ratio à 21.0 ratio. Par exemple, pour respecter le niveau AA des WCAG https://en.wikipedia.org/wiki/Web_Content_Accessibility_Guidelines, une valeur de 4.5 ratio peut être fournie. L'algorithme est implémenté à l'aide de HSLuv https://www.hsluv.org/, ce qui lui permet de modifier la luminosité perçue d'une couleur autant que nécessaire sans changer réellement sa teinte et sa saturation.

Une valeur avec le suffixe % représente la différence de luminance minimum acceptée entre la couleur du premier plan et celle de l'arrière-plan, en dessous de laquelle kitty remplacera la couleur du premier plan. Il s'agit d'un pourcentage allant de 0 % à 100 %. Si la différence de luminance du premier plan et de l'arrière-plan est inférieure à ce seuil, la couleur du premier plan sera définie sur blanc si l'arrière-plan est foncé, ou sur noir si l'arrière-plan est clair.

AVERTISSEMENT : Certains programmes utilisent des caractères (comme les caractères de bloc) pour l'affichage graphique et peuvent s'attendre à pouvoir définir le premier plan et l'arrière-plan sur la même couleur (ou des couleurs similaires). Si vous voyez des rayures, des points, des lignes inattendus, une couleur incorrecte, aucune couleur là où vous attendez de la couleur, ou tout type de problème d'affichage graphique, essayez de définir text_fg_override_threshold sur 0 pour voir si c'est la cause du problème ou envisagez d'utiliser le mode de fonctionnement ratio décrit ci-dessus au lieu du mode de fonctionnement %.

Personnalisation du curseur de texte

cursor
cursor #cccccc

Couleur par défaut du curseur de texte. Si défini sur la valeur spéciale none, le curseur sera rendu avec un effet de "vidéo inversée". Sa couleur sera la couleur du texte dans la cellule qu'il recouvre et le texte sera rendu avec la couleur d'arrière-plan de la cellule. Notez que si le programme s'exécutant dans le terminal définit une couleur de curseur, celle-ci a la priorité. De plus, les couleurs du curseur sont modifiées si les couleurs d'arrière-plan et de premier plan de la cellule ont un contraste très faible. Notez que certains thèmes définissent cette valeur, donc si vous souhaitez la remplacer, placez votre valeur après les lignes où le fichier de thème est inclus.

cursor_text_color
cursor_text_color #111111

La couleur du texte sous le curseur. Si vous voulez qu'il soit rendu avec la couleur d'arrière-plan de la cellule en dessous à la place, utilisez la clé spéciale

Curseur

Le curseur peut être désactivé en utilisant l'option background. Notez que si le cursor est défini sur none, cette option est ignorée. Notez que certains thèmes définissent cette valeur, donc si vous souhaitez la remplacer, placez votre valeur après les lignes où le fichier de thème est inclus.

cursor_shape
cursor_shape block

La forme du curseur peut être block, beam ou underline. Notez que lors du rechargement de la configuration, cela ne sera modifié que si la forme du curseur n'a pas été définie par le programme exécuté dans le terminal. Ceci définit la forme par défaut du curseur, les applications exécutées dans le terminal peuvent la remplacer. En particulier, l'intégration shell <#shell-integration> dans kitty définit la forme du curseur sur beam aux invites shell. Vous pouvez éviter cela en définissant shell_integration sur no-cursor.

cursor_shape_unfocused
cursor_shape_unfocused hollow

Définit la forme du curseur de texte lorsque la fenêtre du système d'exploitation n'est pas focalisée. La forme du curseur non focalisé peut être block, beam, underline, hollow et unchanged (laisser la forme du curseur telle quelle).

cursor_beam_thickness
cursor_beam_thickness 1.5

L'épaisseur du curseur en forme de faisceau (en points).

cursor_underline_thickness
cursor_underline_thickness 2.0

L'épaisseur du curseur en forme de soulignement (en points).

cursor_blink_interval
cursor_blink_interval -1

L'intervalle de clignotement du curseur (en secondes). Définissez sur zéro pour désactiver le clignotement. Les valeurs négatives utilisent par défaut le système. Notez que l'intervalle minimum sera limité à repaint_delay. Vous pouvez également animer le clignotement du curseur en spécifiant une fonction d'interpolation <#term-easing-function>. Par exemple, définir cette option sur 0.5 ease-in-out fera clignoter le curseur sur une seconde, dans la première moitié de la seconde il passera de l'opacité à la transparence puis reviendra en arrière sur la moitié suivante. Vous pouvez spécifier différentes fonctions d'interpolation pour les deux moitiés, par exemple : -1 linear ease-out. kitty prend en charge toutes les fonctions d'interpolation CSS https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function. Notez que l'activation des animations consomme plus d'énergie car cela signifie que l'écran est redessiné plusieurs fois par intervalle de clignotement. Voir aussi, cursor_stop_blinking_after. Ce paramètre contrôle également le texte clignotant, qui clignote en rythme exact avec le curseur.

cursor_stop_blinking_after
cursor_stop_blinking_after 15.0

Arrête le clignotement du curseur après le nombre de secondes d'inactivité du clavier spécifié. Définissez sur zéro pour ne jamais arrêter le clignotement. Ce paramètre contrôle également le texte clignotant, qui clignote en rythme exact avec le curseur.

cursor_trail
cursor_trail 0

Définissez cette option sur une valeur supérieure à zéro pour activer une animation de "trace de curseur". Il s'agit d'une animation qui montre une "trace" suivant le mouvement du curseur de texte. Cela facilite le suivi des sauts de curseur importants et crée un effet visuel sympa du curseur zoomant sur l'écran. La valeur réelle de cette option contrôle quand l'animation est déclenchée. C'est un nombre de millisecondes. L'animation de trace suit uniquement les curseurs qui sont restés immobiles pendant plus du nombre de millisecondes spécifié. Cela empêche l'apparition de traces pour les curseurs qui changent rapidement de position lors des mises à jour de l'interface utilisateur dans des applications complexes. Voir cursor_trail_decay pour contrôler la vitesse de l'animation et cursor_trail_start_threshold pour contrôler quand une trace de curseur est initiée.

cursor_trail_decay
cursor_trail_decay 0.1 0.4

Contrôle les temps de décroissance pour l'effet de trace de curseur lorsque cursor_trail est activé. Cette option accepte deux valeurs flottantes positives spécifiant les temps de décroissance les plus rapides et les plus lents en secondes. La première valeur correspond au temps de décroissance le plus rapide (minimum) et la deuxième valeur correspond au temps de décroissance le plus lent (maximum). La deuxième valeur doit être égale ou supérieure à la première valeur. Des valeurs plus petites entraînent une décroissance plus rapide de la trace du curseur. Ajustez ces valeurs pour contrôler la rapidité avec laquelle la trace du curseur s'estompe.

cursor_trail_start_threshold
cursor_trail_start_threshold 2

Définit le seuil de distance pour le démarrage de la trace du curseur. Cette option accepte une valeur entière positive qui représente le nombre minimum de cellules que le curseur doit parcourir avant le démarrage de la trace. Lorsque le curseur se déplace moins que ce seuil, la trace est ignorée, réduisant ainsi les animations de trace de curseur inutiles.

cursor_trail_color
cursor_trail_color none

Définit la couleur de la trace du curseur lorsque cursor_trail est activé. Si défini sur 'none' (par défaut), la trace du curseur utilisera la couleur d'arrière-plan du curseur. Sinon, spécifiez une valeur de couleur (par exemple, #ff0000 pour rouge, ou une couleur nommée comme 'red'). Cela vous permet de personnaliser l'apparence de la trace du curseur indépendamment de la couleur du curseur.

Défilement

scrollback_lines
scrollback_lines 2000

Nombre de lignes d'historique à conserver en mémoire pour le défilement arrière. La mémoire est allouée à la demande. Les nombres négatifs signifient un défilement arrière (effectivement) infini. Notez qu'il est déconseillé d'utiliser un défilement arrière très important car cela peut ralentir les performances du terminal et consommer beaucoup de RAM. Envisagez plutôt d'utiliser scrollback_pager_history_size. Notez que lors du rechargement de la configuration, si cette valeur est modifiée, elle n'affectera que les nouvelles fenêtres, pas celles existantes.

scrollbar
scrollbar scrolled

Contrôle quand la barre de défilement est affichée.

scrolled
signifie lorsque le défilement arrière a commencé.
hovered
signifie lorsque la souris survole le bord droit de la fenêtre.
scrolled-and-hovered
signifie lorsque la souris est sur la zone de défilement et que le défilement arrière a commencé.
always
signifie chaque fois qu'un défilement est présent.
never
signifie désactiver la barre de défilement.
scrollbar_interactive
scrollbar_interactive yes

Si désactivé, la barre de défilement ne sera pas contrôlable par la souris et tous les événements de souris passeront par la barre de défilement.

scrollbar_jump_on_click
scrollbar_jump_on_click yes

Lorsqu'il est activé, cliquer dans la piste de la barre de défilement fera sauter la position de défilement à l'emplacement cliqué, sinon la position de défilement ne se déplacera vers la position que d'une seule fenêtre, ce qui est le comportement des barres de défilement traditionnelles.

scrollbar_width
scrollbar_width 0.5

La largeur de la barre de défilement en unités de largeur de cellule.

scrollbar_hover_width
scrollbar_hover_width 1

La largeur de la barre de défilement lorsque la souris la survole, en unités de largeur de cellule.

scrollbar_handle_opacity
scrollbar_handle_opacity 0.5

L'opacité de la poignée de la barre de défilement, 0 étant complètement transparent et 1 étant complètement opaque.

scrollbar_radius
scrollbar_radius 0.3

Le rayon (courbure) de la poignée de la barre de défilement en unités de largeur de cellule. Devrait être inférieur à scrollbar_width.

scrollbar_gap
scrollbar_gap 0.1

L'espace entre la barre de défilement et le bord de la fenêtre en unités de largeur de cellule.

scrollbar_min_handle_height
scrollbar_min_handle_height 1

La hauteur minimale de la poignée de la barre de défilement en unités de hauteur de cellule. Empêche la poignée de devenir trop petite lorsqu'il y a beaucoup de scrollback.

souris

Les boutons de la souris peuvent être associés à l'exécution d'actions arbitraires. La syntaxe est

: 
mouse_map b
utton-name
event-type m
odes action

Où button-name est l'un des suivants : left, middle, right, b1 ... b8 avec des modificateurs clavier ajoutés. Par exemple : ctrl+shift+left fait référence à la combinaison des touches Ctrl+Shift tout en cliquant avec le bouton gauche de la souris. La valeur b1 ... b8 peut être utiliséeédité pour faire référence à jusqu'à huit boutons sur une souris.

event-type est l'un des press, release, doublepress, triplepress, click, doubleclick. modes indique si l'action est effectuée lorsque la souris est capturée par le programme exécuté dans le terminal, ou non. Les valeurs sont grabbed ou ungrabbed ou une combinaison séparée par des virgules de celles-ci. grabbed fait référence au moment où le programme exécuté dans le terminal a demandé des événements de souris. Notez que les événements click et doubleclick ont un délai de click_interval pour éviter toute confusion avec les appuis doubles et triples.

Vous pouvez exécuter kitty avec l'option de ligne de commande kitty --debug-input <#cmdoption-kitty-debug-input> pour voir les événements de souris. Voir les actions intégrées ci-dessous pour avoir une idée de ce qui est possible.

Si vous souhaitez désassocier un bouton, associez-le à rien. Par exemple, pour désactiver l'ouverture d'URL avec un simple clic :

mouse_map left click ungrabbed

Voir toutes les actions associables, y compris les actions de souris, ici <>.

Optimisation des performances

repaint_delay
repaint_delay 10

Délai entre les mises à jour de l'écran (en millisecondes). Le diminuer augmente le nombre d'images par seconde (FPS) au détriment d'une utilisation accrue du processeur. La valeur par défaut produit environ 100 FPS, ce qui est largement suffisant pour la plupart des usages. Notez que pour atteindre réellement 100 FPS, vous devez soit définir sync_to_monitor sur no, soit utiliser un moniteur avec un taux de rafraîchissement élevé. De plus, pour minimiser la latence lorsqu'il y a des entrées en attente de traitement, cette option est ignorée.

input_delay
input_delay 3

Délai avant que les entrées du programme exécuté dans le terminal ne soient traitées (en millisecondes). Notez que le diminuer augmentera la réactivité, mais augmentera également l'utilisation du processeur et pourrait provoquer un scintillement dans les programmes en plein écran qui redessinent tout l'écran à chaque boucle, car kitty est si rapide que les mises à jour partielles de l'écran seront dessinées. Ce réglage est ignoré lorsque le tampon d'entrée est presque plein.

Synchronise les mises à jour de l'écran avec le taux de rafraîchissement du moniteur. Cela empêche le déchirement de l'écran https://en.wikipedia.org/wiki/Screen_tearing lors du défilement. Cependant, cela limite la vitesse de rendu au taux de rafraîchissement de votre moniteur. Avec une souris très rapide / un taux de répétition de clavier élevé, vous pourriez remarquer une légère latence des entrées. Si

so, définissez ceci à non.

Spécifie les règles pour filtrer les notifications envoyées par les applications en cours d'exécution dans kitty. Peut être spécifié plusieurs fois pour créer plusieurs règles de filtre. Affiche une notification de bureau lorsqu'une commande de longue durée se termine (nécessite shell_integration). Les valeurs possibles sont :

never
N'envoie jamais de notification.
unfocused
N'envoie une notification que lorsque la fenêtre n'a pas le focus clavier.
invisible
N'envoie une notification que lorsque la fenêtre est à la fois sans focus et non visible pour l'utilisateur, par exemple, parce qu'elle est dans un onglet inactif ou que sa fenêtre système n'est pas actuellement visible (sur les plateformes qui prennent en charge la requête de visibilité des fenêtres système, une fenêtre système est considérée comme visible si elle est active).

Envoie toujours une notification, quel que soit l'état de la fenêtre.

Il y a deux arguments optionnels :

Premièrement, la durée minimale pour ce qui est considéré comme une commande de longue durée. La valeur par défaut est de 5 secondes. Spécifiez un deuxième argument pour définir la durée. Par exemple : invisible 15. Ne définissez pas la valeur trop bas, sinon une commande qui lance une nouvelle fenêtre système et se termine spammera une notification.

Deuxièmement, l'action à effectuer. La valeur par défaut est notify. Les valeurs possibles sont :

notify
Envoie une notification de bureau. Les arguments suivants sont optionnels et spécifient quand la notification est automatiquement effacée. L'ensemble des événements possibles pour l'effacement de la notification sont : focus et next. focus signifie que lorsque la politique de notification est unfocused ou invisible, la notification est automatiquement effacée lorsque la fenêtre regagne le focus. bell
Fait sonner la cloche du terminal.
notify-bell
Envoie une notification de bureau et fait sonner la cloche du terminal. Les arguments sont les mêmes que pour notify.
command
Exécute une commande personnalisée. Tous les arguments suivants constituent la ligne de commande à exécuter.

term
term xterm-kitty

La valeur de la variable d'environnement TERM <#envvar-TERM> à définir. Changer cela peut casser de nombreux programmes de terminal, ne le changez que si vous savez ce que vous faites, pas parce que vous avez lu un conseil sur "Stack Overflow" pour le changer. La variable TERM <#envvar-TERM> est utilisée par divers programmes pour obtenir des informations sur les capacités et le comportement du terminal. Si vous la changez, en fonction des programmes que vous exécutez et de la différence avec le terminal auquel vous la changez, diverses choses, des combinaisons de touches aux couleurs en passant par diverses fonctionnalités avancées, peuvent ne pas fonctionner. Changer cette option en rechargeant la configuration n'affectera que les nouvelles fenêtres créées.

terminfo_type
terminfo_type path

La valeur de la variable d'environnement TERMINFO <#envvar-TERMINFO> à définir. Cette variable est utilisée par les programmes exécutés dans le terminal pour rechercher les bases de données terminfo. La valeur par défaut de path amène kitty à la définir sur un emplacement système de fichiers contenant la base de données terminfo de kitty. Une valeur de direct signifie insérer la base de données entière directement dans la variable d'environnement. Cela peut être utile lors de la connexion à des conteneurs, par exemple. Mais, notez que tous les logiciels ne prennent pas en charge cela. Une valeur de none signifie ne pas toucher à la variable.

forward_stdio
forward_stdio no

Transmet la sortie standard (STDOUT) et l'erreur standard (STDERR) du processus kitty aux processus enfants. Ceci est utile pour le débogage car cela permet aux processus enfants d'imprimer directement sur la sortie standard de kitty. Par exemple, echo hello world >&$KITTY_STDIO_FORWARDED dans un shell imprimera sur la sortie standard du processus kitty parent. Définit la variable d'environnement KITTY_STDIO_FORWARDED=fdnum afin que les processus enfants soient informés du transfert. Notez que sur macOS, cela empêche l'exécution du shell via l'utilitaire de connexion, donc getlogin() ne fonctionnera pas dans les programmes exécutés dans cette session.

Spécifie les entrées pour divers menus dans kitty. Actuellement, seul le menu global sur macOS est pris en charge. Par exemple :

Ceci créera une entrée de menu nommée "Lancer quelque chose de spécial" dans un menu "Actions" dans la barre de menu globale de macOS. Les sous-menus peuvent être créés en ajoutant plus de niveaux séparés par les caractères ::.

Utilise la touche Option comme touche Alt sur macOS. Avec cette option définie sur no, kitty utilisera le comportement natif de macOS Option+Touche pour entrer des caractères Unicode. Cela cassera tous les raccourcis clavier Alt+Touche dans vos programmes de terminal, mais vous pourrez utiliser la technique de saisie Unicode de macOS. Raccourcis clavier

Les touches sont identifiées simplement par leur caractère Unicode en minuscules. Par exemple : a pour la touche A, [ pour la touche crochet ouvrant, etc. Pour les touches fonctionnelles, telles que Entrée ou Échap, les noms sont présents dans la section Définitions des touches fonctionnelles <#functional>. Pour les touches modificatrices, les noms sont ctrl (control, ⌃), shift (⇧), alt (opt, option, ⌥), super (cmd, command, ⌘).

Le mappage de raccourcis simple se fait avec la directive map. Pour plus de détails sur le mappage avancé, y compris les maps modales et par application, consultez Faire danser votre clavier <>. Quelques exemples rapides pour illustrer les tâches courantes :

# annuler le mappage d'un raccourci clavier, le passant au programme exécuté dans kitty
map kitty_mod+space
# ignorer complètement un événement clavier
map ctrl+alt+f1 discard_event
# combiner plusieurs actions
map kitty_mod+e combine : new_window : next_layout
# raccourcis multi-touches
map ctrl+x>ctrl+y>z action

La liste complète des actions qui peuvent être mappées sur des appuis de touches est disponible ici <>.

N'a pas de valeurs par défaut. Des exemples de valeurs sont montrés ci-dessous :

Par exemple, l'alias ci-dessus vous permet de créer des mappages pour lancer un nouvel onglet dans le répertoire de travail actuel sans duplication :

kitten_alias

N'a pas de valeurs par défaut. Des exemples de valeurs sont montrés ci-dessous :

Comme action_alias ci-dessus, mais spécifiquement pour les kittens. En général, préférez utiliser action_alias. Cette option est une version héritée, présente pour des raisons de compatibilité ascendante. Elle provoque la substitution de toutes les invocations du kitten aliasé. Envoyer du texte arbitraire lors de la pression de touches

Vous pouvez dire à kitty d'envoyer du texte arbitraire (encodé en UTF-8) au programme client lors de la pression de touches de raccourci spécifiées. Par exemple :

map ctrl+alt+a send_text all Texte spécial

Cela enverra "Texte spécial" lorsque vous appuierez sur la combinaison de touches Ctrl+Alt+A. Le texte à envoyer décode les séquences d'échappement ANSI C https://www.gnu.org/software/bash/manual/html_node/ANSI_002dC-Quoting.html, vous pouvez donc utiliser des échappements comme \e pour envoyer des codes de contrôle ou \u21fb pour envoyer des caractères Unicode (ou vous pouvez simplement saisir directement les caractères Unicode en tant que texte UTF-8). Vous pouvez utiliser kitten show-key pour obtenir les codes d'échappement de touches que vous souhaitez émuler.

Le premier argument de send_text est les modes de clavier dans lesquels activer le raccourci. Les valeurs possibles sont normal, application, kitty ou une combinaison séparée par des virgules de ceux-ci. Les modes normal et application font référence au mode de touches curseur DECCKM pour les terminaux, et kitty fait référence au protocole de clavier étendu de kitty. La valeur spéciale all signifie tous.

scroll_to_prompt

Faire défiler vers l'invite de commande shell précédente/suivante

Permet de passer facilement d'une commande à l'autre. Nécessite une intégration Shell fonctionnelle <#shell-integration>. Prend deux nombres optionnels comme arguments :

Le premier est le nombre d'invites à sauter ; les valeurs négatives sautent vers le haut et les valeurs positives vers le bas. Une valeur de zéro sautera à la dernière invite visitée par cette action. Par défaut : -1

Le second est le nombre de lignes à afficher au-dessus de l'invite vers laquelle on a sauté. C'est un peu comme l'option --jump-target de less ou le réglage scrolloff de vim. Par défaut : 0.

Par exemple :

map ctrl+p scroll_to_prompt -1 3  # sauter à la précédente, affichant 3 lignes avant
map ctrl+n scroll_to_prompt 1     # sauter à la suivante
map ctrl+o scroll_to_prompt 0     # sauter à la dernière visitée

Raccourcis par défaut utilisant cette action : ctrl+shift+x <#shortcut-kitty.Scroll-to-next-shell-prompt>, ctrl+shift+z <#shortcut-kitty.Scroll-to-previous-shell-prompt>
