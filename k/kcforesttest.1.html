NOM

kcforesttest - interface en ligne de commande pour tester la base de données arborescente

DESCRIPTION

La commande `kcforesttest' est un utilitaire pour les tests de fonctionnalités et de performances de la base de données arborescente. Cette commande s'utilise selon le format suivant. `path' spécifie le chemin d'un fichier de base de données. `rnum' spécifie le nombre d'itérations.


kcforesttest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Effectue des tests en ordre.
kcforesttest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Effectue des opérations de mise en file d'attente.
kcforesttest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Effectue des opérations mixtes sélectionnées aléatoirement.
kcforesttest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Teste les transactions.

Les options sont les suivantes.

-th num : spécifie le nombre de threads de travail.
-rnd : effectue un test aléatoire.
-set : effectue uniquement une opération de définition.
-get : effectue uniquement une opération d'obtention.
-getw : effectue uniquement une opération d'obtention avec un tampon.
-rem : effectue uniquement une opération de suppression.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-oat : ouvre la base de données avec l'option de transaction automatique.
-oas : ouvre la base de données avec l'option de synchronisation automatique.
-onl : ouvre la base de données avec l'option de non-verrouillage.
-otl : ouvre la base de données avec l'option de tentative de verrouillage.
-onr : ouvre la base de données avec l'option de non-réparation automatique.
-tc : ajuste la base de données avec l'option de compression.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-psiz num : spécifie la taille de chaque page.
-pccap num : spécifie la taille de capacité du cache de pages.
-rcd : utilise le comparateur décimal au lieu du comparateur lexical.
-rcld : utilise le comparateur lexical descendant au lieu du comparateur ascendant.
-rcdd : utilise le comparateur décimal descendant au lieu du comparateur lexical.
-lv : signale toutes les erreurs.
-it num : spécifie le nombre de répétitions.
-hard : effectue une synchronisation physique.

Cette commande retourne 0 en cas de succès, un autre code en cas d'échec.
