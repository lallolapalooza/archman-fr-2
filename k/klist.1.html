NOM

klist - lister les tickets Kerberos mis en cache

SYNTAXE

klist [-e] [[-c] [-l] [-A] [-f] [-s] [-a [-n]]] [-C] [-k [-i] [-t] [-K]] [-V] [-d] [nom_cache|nom_keytab]

DESCRIPTION

klist liste le principal Kerberos et les tickets Kerberos détenus dans un cache d'informations d'identification, ou les clés détenues dans un fichier keytab.

OPTIONS

-e
Affiche les types de chiffrement de la clé de session et du ticket pour chaque information d'identification dans le cache d'informations d'identification, ou chaque clé dans le fichier keytab.
-l
Si une collection de caches est disponible, affiche un tableau résumant les caches présents dans la collection.
-A
Si une collection de caches est disponible, affiche le contenu de tous les caches de la collection.
-c
Lister les tickets détenus dans un cache d'informations d'identification. C'est l'option par défaut si ni -c ni -k n'est spécifié.
-f
Affiche les drapeaux présents dans les informations d'identification, en utilisant les abréviations suivantes :
F    Transférable
f    transféré
P    Utilisable pour proxy
p    proxy
D    Date de publication possible
d    postdaté
R    Renouvelable
I    Initial
i    invalide
H    Authentifié par matériel
A    pré-authentifié
T    Vérification de la politique de transit
O    OK comme délégué
a    anonyme
-s
Fait en sorte que klist s'exécute silencieusement (ne produit aucune sortie). klist se terminera avec le statut 1 si le cache d'informations d'identification ne peut pas être lu ou s'il est expiré, et avec le statut 0 sinon.
-a
Affiche la liste des adresses dans les informations d'identification.
-n
Affiche les adresses numériques au lieu de résoudre inversement les adresses.
-C
Affiche les données de configuration qui ont été stockées dans le cache d'informations d'identification lorsque klist les rencontre. Par défaut, les données de configuration ne sont pas listées.
-k
Liste les clés détenues dans un fichier keytab.
-i
En combinaison avec -k, utilise par défaut le keytab client par défaut au lieu du keytab accepteur par défaut, si aucun nom n'est donné.
-t
Affiche les horodatages de chaque entrée de keytab dans le fichier keytab.
-K
Affiche la valeur de la clé de chiffrement de chaque entrée de keytab dans le fichier keytab.
-d
Affiche les types d'authdata (s'il y en a) pour chaque entrée.
-V
Affiche le numéro de version de Kerberos et quitte.

Si nom_cache ou nom_keytab n'est pas spécifié, klist affichera les informations d'identification dans le cache d'informations d'identification par défaut ou le fichier keytab par défaut, selon le cas. Si la variable d'environnement KRB5CCNAME est définie, sa valeur est utilisée pour localiser le cache de tickets par défaut.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.

FICHIERS

FICHIER:/tmp/krb5cc_%{uid}
Emplacement par défaut du cache d'informations d'identification Kerberos 5
FICHIER:/etc/krb5.keytab
Emplacement par défaut pour le fichier keytab de l'hôte local.

VOIR AUSSI

kinit(1), kdestroy(1), kerberos(7)
