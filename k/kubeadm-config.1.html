NAME

kubeadm config - Gérer la configuration d'un cluster kubeadm persistante dans une ConfigMap dans le cluster

SYNOPSIS

kubeadm config [OPTIONS]

DESCRIPTION

Il existe une ConfigMap dans l'espace de noms kube-system nommée "kubeadm-config" que kubeadm utilise pour stocker la configuration interne du cluster. La CLI kubeadm v1.8.0+ crée automatiquement cette ConfigMap avec la configuration utilisée par 'kubeadm init', mais si vous avez initialisé votre cluster en utilisant kubeadm v1.7.x ou une version inférieure, vous devez utiliser la commande 'kubeadm init phase upload-config' pour créer cette ConfigMap. Ceci est nécessaire afin que 'kubeadm upgrade' puisse configurer correctement votre cluster mis à niveau.

OPTIONS

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standards peut être recherché pour un fichier kubeconfig existant.

OPTIONS INHERITED FROM PARENT COMMANDS

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela forcera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée.
