NOM

kubeadm upgrade node phase post-upgrade - Exécuter les tâches post-mise à niveau

SYNTAXE

kubeadm upgrade node phase post-upgrade [OPTIONS]

DESCRIPTION

Exécuter les tâches post-mise à niveau

OPTIONS

--config="" Chemin vers un fichier de configuration kubeadm.

--dry-run=false Ne pas modifier d'état, seulement afficher les actions qui seraient effectuées.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standard peut être recherché pour un fichier kubeconfig existant.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers root 'réel' de l'hôte. Cela amènera kubeadm à faire un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
