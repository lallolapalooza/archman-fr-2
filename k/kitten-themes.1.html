Nom

kitten-themes - Gérez facilement les thèmes de couleurs de kitty

Aperçu

Le kitten themes permet de changer facilement les thèmes de couleurs, parmi une collection de plus de trois cents thèmes pré-faits disponibles sur kitty-themes https://github.com/kovidgoyal/kitty-themes. Pour l'utiliser, exécutez simplement :

kitten themes

Le kitten permet de choisir un thème, avec des aperçus en direct des couleurs. Vous pouvez choisir entre les thèmes clairs et sombres et rechercher par nom de thème en tapant simplement quelques caractères du nom.

Le kitten maintient une liste des thèmes récemment utilisés pour permettre un changement rapide.

Si vous souhaitez restaurer les couleurs par défaut, vous pouvez le faire en choisissant le thème Default.

Ajouté dans la version 0.23.0 : Le kitten themes

Comment ça marche

Un thème dans kitty est juste un fichier .conf contenant les paramètres de kitty. Lorsque vous sélectionnez un thème, le kitten copie simplement le fichier .conf vers ~/.config/kitty/current-theme.conf et ajoute une inclusion pour current-theme.conf dans kitty.conf. Il commente également tous les paramètres de couleur existants dans kitty.conf afin qu'ils n'interfèrent pas.

Une fois cela fait, le kitten envoie un signal à kitty pour qu'il recharge sa configuration.

Note :

Si vous souhaitez avoir des paramètres de couleur dans votre kitty.conf que le kitten themes ne remplace pas, déplacez-les dans un fichier conf séparé et incluez-le dans kitty.conf. L'inclusion doit être placée après l'inclusion de current-theme.conf afin que les paramètres qu'elle contient remplacent les paramètres conflictuels de current-theme.conf.

Changer les thèmes de couleurs automatiquement lorsque le système passe du clair au sombre

Ajouté dans la version 0.38.0.

Vous pouvez faire en sorte que kitty change automatiquement son thème de couleurs lorsque le système d'exploitation passe des modes sombre, clair et sans préférence. Pour ce faire, exécutez le kitten themes normalement et à l'écran final, sélectionnez l'option pour sauvegarder votre thème choisi comme sombre, clair ou sans préférence. Répétez jusqu'à ce que vous ayez choisi un thème pour chacun des trois modes. Ensuite, une fois que vous redémarrez kitty, il utilisera automatiquement vos thèmes choisis en fonction du schéma de couleurs du système d'exploitation.

Cela fonctionne en créant trois fichiers : dark-theme.auto.conf, light-theme.auto.conf et no-preference-theme.auto.conf dans le répertoire de configuration de kitty. Lorsque ces fichiers existent, kitty interroge le système d'exploitation sur son schéma de couleurs et utilise le fichier approprié. Notez que les couleurs de ces fichiers remplacent toutes les autres couleurs, ainsi que tous les paramètres d'image d'arrière-plan, même ceux spécifiés à l'aide de l'option de ligne de commande kitty --override <#cmdoption-kitty-override>. kitty changera également automatiquement les couleurs lorsque le schéma de couleurs du système d'exploitation change, par exemple, lors des transitions nuit/jour.

Lors de l'utilisation de ces couleurs, vous pouvez toujours changer dynamiquement les couleurs, mais la prochaine fois que le système d'exploitation changera son mode couleur, toutes les modifications dynamiques seront remplacées.

Note :

Sur le bureau GNOME, le bureau signale la préférence de couleur comme sans préférence lorsque le "style sombre" n'est pas activé. Utilisez donc no-preference-theme.auto.conf pour sélectionner les couleurs pour le mode clair sur GNOME. Vous pouvez activer manuellement le style clair avec gsettings set org.gnome.desktop.interface color-scheme prefer-light, auquel cas GNOME signalera le schéma de couleurs comme clair et kitty utilisera light-theme.auto.conf.

Utilisation de vos propres thèmes

Vous pouvez également créer vos propres thèmes sous forme de fichiers .conf. Placez-les dans le sous-répertoire themes du répertoire de configuration de kitty <#confloc>, généralement ~/.config/kitty/themes. Le kitten les ajoutera automatiquement à la liste des thèmes. Vous pouvez l'utiliser pour modifier les thèmes intégrés, en donnant au fichier conf le nom Nom de thème.conf pour remplacer le thème intégré de ce nom. Ici, Nom de thème est le nom du thème intégré réel, pas son nom de fichier. Notez qu'après avoir fait cela, vous devez exécuter le kitten et choisir ce thème une fois pour que vos modifications soient appliquées.

Contribution de nouveaux thèmes

Si vous souhaitez contribuer un nouveau thème au dépôt de thèmes kitty, commencez par vous rendre sur le dépôt kitty-themes https://github.com/kovidgoyal/kitty-themes. Forkez-le https://docs.github.com/en/get-started/quickstart/fork-a-repo, et utilisez le fichier template.conf comme modèle lors de la création de votre thème. Une fois que vous êtes satisfait de son apparence, soumettez une pull request https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request pour que votre thème soit fusionné dans le dépôt kitty-themes https://github.com/kovidgoyal/kitty-themes, ce qui le rendra automatiquement disponible dans ce kitten.

Changer le thème de manière non interactive

Vous pouvez spécifier le nom du thème comme argument lors de l'invocation du kitten pour qu'il passe à ce thème instantanément. Par exemple :

kitten themes --reload-in=all Dimmed Monokai

Cela changera le thème en Dimmed Monokai dans toutes les instances kitty en cours d'exécution. Voir ci-dessous pour plus de détails sur le fonctionnement non interactif.

Code source des thèmes

Le code source de ce kitten est disponible sur GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/themes.

Interface de ligne de commande

kitten themes [options] [nom du thème à changer]

Change le thème kitty. Si aucun nom de thème n'est fourni, s'exécute interactivement, sinon change le thème courant pour le nom de thème spécifié.

Options

--cache-age <CACHE_AGE>
Vérifie les nouveaux thèmes uniquement après le nombre de jours spécifié. Une valeur de zéro vérifiera toujours les nouveaux thèmes. Une valeur négative ne vérifiera jamais les nouveaux thèmes, levant plutôt une erreur si une copie locale des thèmes n'est pas disponible. Par défaut : 1
--reload-in <RELOAD_IN>
Par défaut, ce kitten signalera uniquement l'instance kitty parente dans laquelle il s'exécute pour recharger sa configuration, après avoir effectué des modifications. Utilisez cette option pour plutôt soit ne pas recharger la configuration du tout, soit dans toutes les instances kitty en cours d'exécution. Par défaut : parent Choix : all, none, parent
--dump-theme [=no]
Lors de l'exécution de manière non interactive, affiche le thème spécifié sur STDOUT au lieu de modifier kitty.conf. Par défaut : false
--config-file-name <CONFIG_FILE_NAME>
Le nom ou le chemin du fichier de configuration à éditer. Les chemins relatifs sont interprétés par rapport au répertoire de configuration de kitty. Par défaut, le fichier de configuration kitty, kitty.conf est édité. C'est plus utile si vous ajoutez include themes.conf à votre kitty.conf et que vous faites ensuite fonctionner le kitten uniquement sur themes.conf, permettant à kitty.conf de rester inchangé. Par défaut : kitty.conf
