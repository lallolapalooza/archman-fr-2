NOM

kateenc - crée des flux Kate à partir d'une entrée texte

SYNTAXE

kateenc [-hVM] [-o fichier_sortie] [-l langue] [-c catégorie] [-s numéro_séquentiel] [-C étiquette=valeur] [-R seuil] [-K seuil] -t type_fichier [ fichier_entree ]

DESCRIPTION

kateenc crée des flux Kate à partir de fichiers d'entrée (sous-titres SubRip SRT, paroles LRC et langage de description personnalisé de libkate). Lorsqu'il est enregistré dans un flux Ogg (comportement par défaut), un flux Kate peut ensuite être fusionné avec d'autres flux Ogg (par exemple, une vidéo Theora) à l'aide des outils oggz.

OPTIONS

-h
Affiche l'aide de la ligne de commande.
-V
Affiche les informations de version.
-M
Permet un marquage simple de type HTML dans les fichiers SRT. Si ce paramètre est utilisé, des chaînes telles que « <i> » seront interprétées comme signifiant l'italique, plutôt que d'apparaître telles quelles. Notez que divers lecteurs interprètent un ensemble de balises HTML légèrement différent, et certains ne le font pas.
-o fichier_sortie
Écrit le flux Kate de sortie dans le nom de fichier donné (écrit sur la sortie standard si non spécifié).
-l langue
Définit la langue pour le flux (la valeur par défaut est la langue spécifiée dans l'entrée, ou aucune).
-c catégorie
Définit la catégorie pour le flux (la valeur par défaut est la catégorie spécifiée dans l'entrée, ou aucune).
-s numéro_séquentiel
Définit le numéro séquentiel pour le flux Kate de sortie (ne s'applique pas aux flux bruts).
-C étiquette=valeur
Ajoute un commentaire à encoder dans le flux Kate de sortie. Le commentaire doit être de la forme étiquette=valeur, et être conforme aux règles des commentaires Vorbis (par exemple, l'étiquette est composée d'un sous-ensemble particulier de caractères ASCII, et la valeur est en UTF-8 valide). Notez que vous devrez peut-être échapper ou mettre entre guillemets le commentaire pour qu'il soit considéré comme un seul paramètre de ligne de commande.
-t type_fichier
Spécifie le type de l'entrée (srt, lrc, kate)
-R seuil
Utilise des paquets répétés, avec le seuil donné (en secondes). Les paquets de données seront répétés à des intervalles d'environ threshold secondes, lorsqu'ils sont actifs.
-K seuil
Utilise des paquets keepalive, avec le seuil donné (en secondes). Des paquets keepalive seront émis lorsqu'aucun autre paquet n'a été émis pendant environ threshold secondes.

EXEMPLES

Créer un flux Kate pour des sous-titres gallois à partir d'un fichier SubRip :


kateenc -t srt -l cy -c SUB -o output.ogg input.srt
