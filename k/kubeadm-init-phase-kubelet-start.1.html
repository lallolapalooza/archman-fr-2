NOM

kubeadm init phase kubelet-start - Écrit les paramètres du kubelet et (ré)démarre le kubelet

SYNTAXE

kubeadm init phase kubelet-start [OPTIONS]

DESCRIPTION

Écrit un fichier avec KubeletConfiguration et un fichier d'environnement avec les paramètres du kubelet spécifiques au nœud, puis (ré)démarre le kubelet.

OPTIONS

--config="" Chemin vers un fichier de configuration kubeadm.

--cri-socket="" Chemin vers la socket CRI pour se connecter. Si vide, kubeadm tentera de détecter automatiquement cette valeur ; utilisez cette option uniquement si vous avez plusieurs CRI installés ou si vous avez une socket CRI non standard.

--dry-run=false N'appliquez aucune modification ; affichez uniquement ce qui serait fait.

--image-repository="registry.k8s.io" Choisissez un registre de conteneurs pour télécharger les images du plan de contrôle

--node-name="" Spécifiez le nom du nœud.

--patches="" Chemin vers un répertoire contenant des fichiers nommés "target[suffix][+patchtype].extension". Par exemple, "kube-apiserver0+merge.yaml" ou juste "etcd.json". "target" peut être l'un des suivants : "kube-apiserver", "kube-controller-manager", "kube-scheduler", "etcd", "kubeletconfiguration", "corednsdeployment". "patchtype" peut être l'un des suivants : "strategic", "merge" ou "json" et ils correspondent aux formats de patch pris en charge par kubectl. Le "patchtype" par défaut est "strategic". "extension" doit être soit "json", soit "yaml". "suffix" est une chaîne facultative qui peut être utilisée pour déterminer quels patchs sont appliqués en premier par ordre alphabétique.

OPTIONS HÉRITÉES DE COMMANDES PARENT

--rootfs="" Le chemin vers le système de fichiers root réel de l'hôte. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée

EXEMPLE

  # Écrit un fichier d'environnement dynamique avec les drapeaux kubelet à partir d'un fichier InitConfiguration.
  kubeadm init phase kubelet-start --config config.yaml
