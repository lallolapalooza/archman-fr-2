KIWIX-MANAGE(1) Manuel des commandes générales KIWIX-MANAGE(1)

NOM

kiwix-manage - Gestionnaire de bibliothèques Kiwix

SYNTAXE

kiwix-manage CHEMIN_BIBLIOTHEQUE add CHEMIN_ZIM ...
kiwix-manage CHEMIN_BIBLIOTHEQUE show [ID_ZIM_1] [ID_ZIM_2] ...
kiwix-manage CHEMIN_BIBLIOTHEQUE remove ID_ZIM_1 [ID_ZIM_2] ...
kiwix-manage --version
kiwix-manage --help

DESCRIPTION

kiwix-manage est un outil en ligne de commande pour manipuler une bibliothèque XML Kiwix.

kiwix-manage permet de gérer les entrées de la bibliothèque Kiwix. Le fichier de bibliothèque est un fichier XML plat listant les fichiers ZIM avec toutes les informations nécessaires telles que l'id, l'icône, la date, le créateur, la description, le chemin du fichier, le titre, l'URL, etc.

ACTIONS

add
Ajoute FICHIER_ZIM à FICHIER_BIBLIOTHEQUE. Crée le fichier de bibliothèque si nécessaire.
remove
Supprime l'ID_ZIM donné de FICHIER_BIBLIOTHEQUE. Au moins un ID_ZIM doit être spécifié.
show
Affiche l'ID_ZIM donné de FICHIER_BIBLIOTHEQUE. Si aucun ID_ZIM n'est donné, alors tout le contenu de FICHIER_BIBLIOTHEQUE est affiché.

OPTIONS

Options à utiliser avec l'action add :
--url=URL_HTTP
Définit l'URL HTTP(S) en ligne du ZIM.
--zimPathToSave=AUTRE_CHEMIN_FS
Définit un chemin de système de fichiers ZIM arbitraire (au lieu du CHEMIN_ZIM).
Autres options (à utiliser seules) :
--help | -h
Affiche l'aide de kiwix-manage.
--version | -v
Affiche la version de kiwix-manage et de toutes ses dépendances.
