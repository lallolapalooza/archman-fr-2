NOM

kubectl replace - Remplace une ressource par son nom de fichier ou l'entrée standard

SYNOPIS

kubectl replace [OPTIONS]

DESCRIPTION

Remplace une ressource par son nom de fichier ou l'entrée standard.

Les formats JSON et YAML sont acceptés. Si vous remplacez une ressource existante, la spécification complète de la ressource doit être fournie. Celle-ci peut être obtenue en utilisant

    $ kubectl get TYPE NAME -o yaml

OPTIONS

--allow-missing-template-keys=true Si vrai, ignorez toutes les erreurs dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. S'applique uniquement aux formats de sortie golang et jsonpath.

--cascade="background" Doit être "background", "orphan" ou "foreground". Sélectionne la stratégie de suppression en cascade pour les dépendants (par exemple, les Pods créés par un ReplicationController). Par défaut, background.

--dry-run="none" Doit être "none", "server" ou "client". Si la stratégie est client, affiche uniquement l'objet qui serait envoyé, sans l'envoyer. Si la stratégie est server, soumet une requête côté serveur sans persister la ressource.

--field-manager="kubectl-replace" Nom du gestionnaire utilisé pour suivre la propriété des champs.

-f, --filename=[] Les fichiers contenant les configurations à remplacer.

--force=false Si vrai, supprime immédiatement les ressources de l'API et contourne la suppression normale. Notez que la suppression immédiate de certaines ressources peut entraîner une incohérence ou une perte de données et nécessite une confirmation.

--grace-period=-1 Période de temps en secondes accordée à la ressource pour se terminer normalement. Ignoré si négatif. Défini à 1 pour un arrêt immédiat. Ne peut être réglé sur 0 que lorsque --force est vrai (suppression forcée).

-k, --kustomize="" Traite un répertoire kustomization. Ce drapeau ne peut pas être utilisé avec -f ou -R.

-o, --output="" Format de sortie. Un parmi : (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--raw="" URI brute à PUT sur le serveur. Utilise le transport spécifié par le fichier kubeconfig.

-R, --recursive=false Traite le répertoire utilisé dans -f, --filename de manière récursive. Utile lorsque vous souhaitez gérer des manifestes liés organisés dans le même répertoire.

--save-config=false Si vrai, la configuration de l'objet actuel sera sauvegardée dans son annotation. Sinon, l'annotation restera inchangée. Ce drapeau est utile lorsque vous souhaitez effectuer kubectl apply sur cet objet à l'avenir.

--show-managed-fields=false Si vrai, conserve les champs gérés lors de l'impression des objets au format JSON ou YAML.

--subresource="" Si spécifié, replace opérera sur la sous-ressource de l'objet demandé.

--template="" Chaîne de modèle ou chemin vers un fichier de modèle à utiliser lorsque -o=go-template, -o=go-template-file. Le format du modèle est un modèle golang [http://golang.org/pkg/text/template/#pkg-overview].

--timeout=0s La durée d'attente avant d'abandonner une suppression, zéro signifie déterminer un délai d'attente à partir de la taille de l'objet

--validate="strict" Doit être l'un des suivants : strict (ou true), warn, ignore (ou false). "true" ou "strict" utilisera un schéma pour valider l'entrée et échouera la requête si elle est invalide. Il effectuera une validation côté serveur si ServerSideFieldValidation est activé sur le serveur API, mais se rabattra sur une validation côté client moins fiable si ce n'est pas le cas. "warn" émettra un avertissement concernant les champs inconnus ou dupliqués sans bloquer la requête si la validation des champs côté serveur est activée sur le serveur API, et se comportera comme "ignore" sinon. "false" ou "ignore" n'effectueront aucune validation de schéma, ignorant silencieusement tous les champs inconnus ou dupliqués.

--wait=false Si vrai, attendez que les ressources aient disparu avant de retourner. Cela attend les finaliseurs.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Cela peut être désactivé en exportant la feature gate KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, la portée de l'espace de noms pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier où écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une requête serveur unique. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas dépasser le délai d'attente des requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification Bearer auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw imprime les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Remplace un pod en utilisant les données de pod.json
  kubectl replace -f ./pod.json
  # Remplace un pod basé sur le JSON passé à l'entrée standard
  cat pod.json | kubectl replace -f -
  # Met à jour l'image (tag) d'un pod à conteneur unique vers la version v4
  kubectl get pod mypod -o yaml | sed 's/\(image: myimage\):.*$/\1:v4/' | kubectl replace -f -
  # Remplace de force, supprime puis recrée la ressource
  kubectl replace --force -f ./pod.json

kubectl-replace(1) a man page for kubectl-replace

NOM

kubectl-replace - Replace a resource by filename or stdin

SYNTAXE

kubectl replace -f FILENAME [-f FILENAME ...]

kubectl replace --src

DESCRIPTION

Replace a resource by filename or stdin.

This command takes a filename or stdin, finds the resource specified by the file and replaces it with the version in the file. Unlike 'create', 'replace' does not create the resource if it does not exist.

The command will not replace the resource if the version in the file is older than the version on the server.

If you want to replace the resource regardless of its current version, use the --force flag.

OPTIONS

-f, --filename=[FILENAME,...]

Filename, directory, or URL to files identifying the resource to replace.

--force

Force replacement of the resource if the version in the file is older than the version on the server.

--grace-period int

Period of time in seconds given to the resource to terminate gracefully. Ignored if negative. Placed in ascending order of 32-bit int.

--help=false:boolean

Help for kubectl-replace.

-o, --output='':string

Output format. One of: json|yaml|wide|name|custom-columns=KEY=VALUE,KEY=VALUE|custom-columns-file=FILENAME|go-template=GO_TEMPLATE|go-template-file=FILENAME|template=TEMPLATE|templatefile=FILENAME

--recursive=false:boolean

Processed the directory recursively.

--src='':string

Filename or stdin to use to replace the resource.

--template='':string

Template string or path to template file to use when -o=go-template, -o=go-template-file, -o=template, or -o=templatefile is specified.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as string

Username to impersonate for the operation.

--as-group strings

Group is impersonated for the operation, this flag is used by admin.

--cache-dir string

Default cache directory.

--certificate-authority string

Path to a cert file for the certificate authority.

--client-certificate string

Path to a client certificate file for TLS.

--client-key string

Path to a client key file for TLS.

--cluster string

The name of the kubeconfig cluster to use.

--context string

The name of the kubeconfig context to use.

--insecure-skip-tls-verify=false:boolean

If true, the server's certificate will not be checked for validity. This is dangerous. By default, the server's certificate is checked.

--kubeconfig string

Path to the kubeconfig file.

--match-server-version=false:boolean

Require server version to match client version.

--namespace string

If present, the namespace scope for this CLI request.

--request-timeout string

The length of time to wait before giving up on a single server request. Non-zero values should contain a corresponding time unit (e.g. 1s, 2m, 3h). A value of zero means don't timeout servers.

--server string

The address and port for the Kubernetes API server.

--tls-server-name string

Server name to use for server certificate validation.

--token string

Bearer token for authentication.

--user string

The name of the kubeconfig user to use.

--username string

Username for basic authentication to the API server.

EXEMPLE

Replace a deployment named 'my-dep' in 'my-namespace' using the data in 'my-dep.yaml':

kubectl replace -f my-dep.yaml --namespace my-namespace

Replace the pod 'my-pod' using the data in 'my-pod.json':

kubectl replace -f my-pod.json
