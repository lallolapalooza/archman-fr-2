NOM

kmymoney - le gestionnaire de finances personnelles de KDE

SYNTAXE

kmymoney [--lang] [-n] [--timers colonne] [--nocatch] [--trace] [fichier]

DESCRIPTION

KMyMoney est le gestionnaire de finances personnelles de KDE. Il fournit les fonctions nécessaires pour équilibrer vos comptes bancaires, gérer vos prêts personnels et catégoriser vos revenus et dépenses à l'aide d'une interface utilisateur graphique de style chéquier.

OPTIONS

--lang

Langue à utiliser

-n

Ne pas ouvrir le dernier fichier utilisé

--timers

Activer les chronomètres de performance

--nocatch

Ne pas intercepter globalement les exceptions non gérées

--trace

Activer le traçage du programme. Cette option n'est disponible que lorsque KMyMoney est compilé en mode débogage.

--dump-actions

Afficher les noms de tous les objets QAction définis sur la sortie standard et quitter. Cette option n'est disponible que lorsque KMyMoney est compilé en mode débogage.

VOIR AUSSI


La documentation complète de KMyMoney est maintenue sous forme de manuel docbook. Si le
programme KHelpCenter est correctement installé chez vous, la commande
khelpcenter help:/kmymoney
devrait vous donner accès au manuel complet. Alternativement, le manuel peut être
consulté dans Konqueror en lui donnant l'URL help:/kmymoney
