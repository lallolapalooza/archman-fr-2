NOM

kronometer - application chronomètre

SYNTAXE

kronometer

DESCRIPTION

Kronometer est une application chronomètre (minuteur/chronomètre).

Les principales fonctionnalités de Kronometer sont les suivantes :

•Démarrer/mettre en pause/reprendre le widget chronomètre ;
•Enregistrement des tours : vous pouvez capturer le temps du chronomètre quand vous le souhaitez ;
•Tri des temps de tour : vous pouvez facilement trouver le temps de tour le plus court ou le plus long ;
•Réinitialiser le widget chronomètre et les temps de tour ;
•Paramètres du format horaire : vous pouvez choisir la granularité du chronomètre ;
•Sauvegarde et reprise des temps : vous pouvez sauvegarder l'état du chronomètre et le reprendre plus tard ;
•Personnalisation des polices : vous pouvez choisir les polices pour chacun des chiffres du chronomètre ;
•Personnalisation des couleurs : vous pouvez choisir la couleur des chiffres du chronomètre et de l'arrière-plan du chronomètre ;
•Exportation des temps de tour : vous pouvez exporter les temps de tour dans un fichier en utilisant le format JSON ou CSV.
