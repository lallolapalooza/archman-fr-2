NOM

kubeone-kubeconfig - Télécharger le fichier kubeconfig depuis le maître

SYNOPIS

kubeone kubeconfig [options]

DESCRIPTION

Télécharge le fichier kubeconfig depuis le maître.

Cette commande prend le manifeste KubeOne qui contient des informations sur les hôtes. Il est possible de sourcer des informations sur les hôtes à partir de la sortie Terraform, en utilisant l'option '--tfjson'.

OPTIONS

-h, --help[=false] aide pour kubeconfig

OPTIONS HÉRITÉES DES COMMANDES PARENT

-c, --credentials="" Fichier à partir duquel sourcer les identifiants et les secrets

-d, --debug[=false] sortie de débogage avec trace de la pile

-l, --log-format="text" format pour la journalisation

-m, --manifest="./kubeone.yaml" Chemin vers la configuration KubeOne

-t, --tfjson="" Source de la sortie terraform en JSON - à lire depuis stdin. Si le chemin est un fichier, le contenu sera utilisé. Si le chemin est un dictionnaire, terraform output -json est exécuté dans ce chemin

-v, --verbose[=false] sortie détaillée

EXEMPLE

kubeone kubeconfig -m mycluster.yaml -t terraformoutput.json

VOIR AUSSI

kubeone(1), kubeone-kubeconfig-generate(1)
