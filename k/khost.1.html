NOM

khost - Utilitaires de recherche DNS simple

SYNTAXE

khost [options] nom [serveur]

DESCRIPTION

Cet utilitaire envoie une requête DNS pour le nom au serveur et affiche la réponse sous une forme plus lisible par l'utilisateur. Pour des requêtes DNS plus avancées, utilisez plutôt kdig.

Paramètres

nom
Est un nom de domaine à rechercher. Si le nom est une adresse IPv4 ou IPv6, le type de requête PTR est utilisé.
serveur
Est un nom ou une adresse du serveur de noms auquel envoyer une requête. L'adresse peut être spécifiée en utilisant la notation [adresse]:port. Si aucun serveur n'est spécifié, les serveurs de /etc/resolv.conf sont utilisés.

Si aucun argument n'est fourni, khost affiche une aide concise.

Options

-4
Utiliser uniquement le protocole IPv4.
-6
Utiliser uniquement le protocole IPv6.
-a
Envoyer une requête ANY avec le mode verbeux.
-d
Activer les messages de débogage.
-h, --help
Afficher l'aide du programme.
-r
Désactiver la récursion.
-T
Utiliser le protocole TCP.
-v
Activer la sortie verbeuse.
-V, --version
Afficher la version du programme. L'option -VV fait afficher au programme le résumé de la configuration de compilation.
-w
Attendre indéfiniment la réponse.
-c classe
Définir la classe de requête (par exemple CH, CLASS4). La classe par défaut est IN.
-t type
Définir le type de requête (par exemple NS, IXFR=12345, TYPE65535). Par défaut, 3 requêtes sont envoyées (A, AAAA et MX).
-R réessais
Le nombre (>=0) de réessais UDP pour interroger un serveur de noms. La valeur par défaut est 1.
-W attente
Le temps d'attente d'une réponse en secondes. Ce délai s'applique à chaque tentative de requête. La valeur par défaut est 2 secondes.

VALEURS DE RETOUR

Le statut de sortie 0 signifie une opération réussie. Tout autre statut de sortie indique une erreur.

EXEMPLES

1.
Obtenir les enregistrements A, AAAA et MX pour example.com :
$ khost example.com
2.
Obtenir l'enregistrement inverse pour l'adresse 192.0.2.1 :
$ khost 192.0.2.1
3.
Effectuer un transfert de zone verbeux pour la zone example.com :
$ khost -t AXFR -v example.com

FICHIERS

/etc/resolv.conf
