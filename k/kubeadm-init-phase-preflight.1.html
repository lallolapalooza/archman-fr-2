NOM

kubeadm init phase preflight - Exécute les vérifications préliminaires

SYNTAXE

kubeadm init phase preflight [OPTIONS]

DESCRIPTION

Exécute les vérifications préliminaires pour kubeadm init.

OPTIONS

--config="" Chemin vers un fichier de configuration kubeadm.

--cri-socket="" Chemin vers le socket CRI à connecter. S'il est vide, kubeadm essaiera de détecter automatiquement cette valeur ; utilisez cette option seulement si vous avez plus d'un CRI installé ou si vous avez un socket CRI non standard.

--dry-run=false N'appliquez aucun changement ; affichez seulement ce qui serait fait.

--ignore-preflight-errors=[] Une liste de vérifications dont les erreurs seront affichées sous forme d'avertissements. Exemple : 'IsPrivilegedUser,Swap'. La valeur 'all' ignore les erreurs de toutes les vérifications.

--image-repository="registry.k8s.io" Choisissez un registre de conteneurs pour télécharger les images du plan de contrôle

OPTIONS RECUEILLIES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

EXEMPLE

  # Exécute les vérifications préliminaires pour kubeadm init à l'aide d'un fichier de configuration.
  kubeadm init phase preflight --config kubeadm-config.yaml
