NOM

KdumpID - Un outil pour identifier les vidages de mémoire noyau

SYNOPIS

kdumpid [-v] <fichier_vidage>

DESCRIPTION

kdumpid fournit une méthode rapide et fiable pour obtenir les informations les plus importantes concernant un vidage de crash noyau inconnu, telles que l'architecture et la version du noyau. Considérez-le comme une sorte d'utilitaire "file" pour les vidages noyau.

Actuellement, kdumpid peut lire :

- Fichiers LKCD
- Fichiers DISKDUMP/KDUMP
- Vidages ELF (y compris le support pour Xen Dom0 et DomU).

Les architectures suivantes sont entièrement prises en charge :

- x86
- x86-64
- ppc
- ppc64
- s390
- s390x.

D'autres architectures peuvent produire une sortie si l'information peut être trouvée dans l'en-tête du fichier.

FONCTIONNEMENT

Par défaut, kdumpid affichera le format du vidage noyau, l'architecture et la version.

OPTIONS

-v
Tente d'extraire et d'afficher des informations supplémentaires du vidage mémoire, telles que : le type de machine, la chaîne complète de la bannière du noyau et le type de configuration du noyau.

VOIR AUSSI

crash(8), makedumpfile(8), kdump(7).
