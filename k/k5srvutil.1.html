Paquet: krb5

NOM

k5srvutil - utilitaire de manipulation de la table des clés d'hôte (keytab)

SYNTAXE

k5srvutil opération [-i] [-f nom_fichier] [-e clefsels]

DESCRIPTION

k5srvutil permet à un administrateur de lister les clés actuellement dans une keytab, d'obtenir de nouvelles clés pour un principal actuellement dans une keytab, ou de supprimer les clés non actuelles d'une keytab.

opération doit être l'une des suivantes :

list
Liste les clés d'une keytab, en affichant le numéro de version et le nom du principal.
change
Utilise le protocole kadmin pour mettre à jour les clés dans la base de données Kerberos avec de nouvelles clés générées aléatoirement, et met à jour les clés dans la keytab pour qu'elles correspondent. Si le numéro de version d'une clé ne correspond pas au numéro de version stocké dans la base de données du serveur Kerberos, l'opération échouera. Si le drapeau -i est donné, k5srvutil demandera une confirmation avant de changer chaque clé. Si l'option -k est donnée, les anciennes et nouvelles clés seront affichées. Normalement, les clés seront générées avec les types de chiffrement et les sels de clé par défaut. Cela peut être remplacé avec l'option -e. Les anciennes clés sont conservées dans la keytab afin que les tickets existants continuent de fonctionner, mais delold devrait être utilisé après l'expiration de ces tickets, pour éviter les attaques contre les anciennes clés.
delold
Supprime les clés qui ne sont pas la version la plus récente de la keytab. Cette opération doit être utilisée quelque temps après une opération de changement pour supprimer les anciennes clés, une fois que les tickets existants émis pour le service ont expiré. Si le drapeau -i est donné, alors k5srvutil demandera une confirmation pour chaque principal.
delete
Supprime des clés particulières dans la keytab, en demandant interactivement pour chaque clé.

Dans tous les cas, la keytab par défaut est utilisée, sauf si elle est remplacée par l'option -f.

k5srvutil utilise le programme kadmin(1) pour modifier la keytab sur place.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.

VOIR AUSSI

kadmin(1), ktutil(1), kerberos(7)
