NOM

korgdump - Lister les informations sur les fichiers sonores au format des synthétiseurs KORG.

SYNTAXE

korgdump [ -v ] FICHIER

DESCRIPTION

Affiche des informations détaillées sur les fichiers sonores basés sur des échantillons (avec l'extension de fichier .KMP ou .KSF) utilisés avec les claviers synthétiseurs KORG tels que Trinity, Triton, OASYS, M3 ou Kronos.

Il n'y a pas encore de prise en charge des fichiers .PCG dans cette version de korgdump.

OPTIONS

 FICHIER
nom du fichier sonore basé sur des échantillons tel qu'utilisé avec les claviers synthétiseurs KORG (.KMP ou .KSF)
 -v
affiche la version et quitte
