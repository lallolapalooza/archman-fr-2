KBACKUP(1) Manuel de l'utilisateur KBackup KBACKUP(1)

NOM

kbackup - Programme de sauvegarde avec une interface facile à utiliser

SYNTAXE

kbackup [OPTIONS...] [nom de module | nom d'ensemble de modules...]

DESCRIPTION

Kbackup est un programme qui vous permet de sauvegarder n'importe quels répertoires ou fichiers. Il utilise une arborescence de répertoires facile à utiliser pour sélectionner les éléments à sauvegarder et vous permet de sauvegarder vos paramètres dans des fichiers de "profil". Ce sont des fichiers texte simples contenant des définitions pour les répertoires et les fichiers à inclure ou exclure du processus de sauvegarde.

OPTIONS

-v, --version

Affiche les informations sur la version.

-h, --help

Affiche l'aide sur les options de la ligne de commande.

--help-all

Affiche l'aide, y compris les options spécifiques à Qt.

--help-all --qmljsdebugger valeur

Active le débogueur QML/JS avec un port spécifié. La valeur doit être au format port:1234[,block]. "block" fait attendre l'application pour une connexion.

--script fichier

Script à exécuter après avoir terminé une tranche d'archive.

--auto profil

Exécute automatiquement la sauvegarde avec le profil donné et se termine une fois terminée.

--autobg profil

Exécute automatiquement la sauvegarde avec le profil donné en arrière-plan (sans afficher de fenêtre) et se termine une fois terminée.

--verbose profil

En mode autobg, soit verbeux et imprime chaque nom de fichier pendant la sauvegarde.

--forceFull

En mode auto/autobg, force la sauvegarde à être une sauvegarde complète au lieu d'agir sur les paramètres du profil.

--author

Affiche les informations sur l'auteur.

--license

Affiche les informations sur la licence.

--desktopfile fichier

Le nom de fichier de base de l'entrée de bureau pour cette application.

ENVIRONNEMENT

FICHIERS

Fichiers de profil .kbp. Générés par l'utilisateur lors de la sauvegarde du profil.

EXEMPLES
