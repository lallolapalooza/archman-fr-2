NOM

kubeadm init phase upload-config kubeadm - Téléverse la configuration du cluster kubeadm dans un ConfigMap

SYNTAXE

kubeadm init phase upload-config kubeadm [OPTIONS]

DESCRIPTION

Téléverse la configuration du cluster kubeadm dans un ConfigMap nommé kubeadm-config dans l'espace de noms kube-system. Ceci permet une configuration correcte des composants système et une expérience utilisateur transparente lors des mises à niveau.

Alternativement, vous pouvez utiliser kubeadm config.

OPTIONS

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--cri-socket="" Chemin d'accès à la socket CRI pour se connecter. Si vide, kubeadm tentera de détecter automatiquement cette valeur ; utilisez cette option uniquement si vous avez plus d'une installation CRI ou si vous avez une socket CRI non standard.

--dry-run=false N'appliquez aucune modification ; affichez simplement ce qui serait fait.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser pour communiquer avec le cluster. Si l'option n'est pas définie, un ensemble d'emplacements standard peuvent être recherchés pour un fichier kubeconfig existant.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée

EXEMPLE

  # téléverse la configuration de votre cluster
  kubeadm init phase upload-config kubeadm --config=myConfig.yaml
