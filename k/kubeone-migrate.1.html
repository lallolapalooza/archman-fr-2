NOM

kubeone-migrate - Commandes pour exécuter différentes migrations

SYNTAXE

kubeone migrate [options]

DESCRIPTION

Commandes pour exécuter différentes migrations

OPTIONS

-h, --help[=false] aide pour migrate

OPTIONS HÉRITÉES DES COMMANDES PARENT

-c, --credentials="" Fichier pour obtenir les identifiants et les secrets

-d, --debug[=false] sortie de débogage avec trace de la pile

-l, --log-format="text" format pour la journalisation

-m, --manifest="./kubeone.yaml" Chemin vers la configuration KubeOne

-t, --tfjson="" Source pour la sortie terraform en JSON - pour lire depuis stdin. Si le chemin est un fichier, son contenu sera utilisé. Si le chemin est un dictionnaire, terraform output -json est exécuté dans ce chemin

-v, --verbose[=false] sortie détaillée

VOIR AUSSI
