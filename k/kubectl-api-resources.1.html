Eric Paris Jan 2015

NOM

kubectl api-resources - Afficher les ressources d'API prises en charge sur le serveur

SYNTAXE

kubectl api-resources [OPTIONS]

DESCRIPTION

Affiche les ressources d'API prises en charge sur le serveur.

OPTIONS

--api-group="" Limiter aux ressources du groupe d'API spécifié.

--cached=false Utiliser la liste mise en cache des ressources si disponible.

--categories=[] Limiter aux ressources appartenant aux catégories spécifiées.

--namespaced=true Si faux, les ressources non-namespacées seront retournées, sinon retournées par défaut des ressources namespacées.

--no-headers=false Lors de l'utilisation du format de sortie par défaut ou de colonnes personnalisées, ne pas imprimer les en-têtes (imprimer les en-têtes par défaut).

-o, --output="" Format de sortie. L'un des suivants : (json, yaml, name, wide).

--show-managed-fields=false Si vrai, conserver les champs gérés lors de l'impression des objets au format JSON ou YAML.

--sort-by="" Si non vide, trier la liste des ressources en utilisant le champ spécifié. Le champ peut être 'name' ou 'kind'.

--verbs=[] Limiter aux ressources qui prennent en charge les verbes spécifiés.

OPTIONS INHERITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur normal ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, ce flag peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Le nom du cluster kubeconfig à utiliser

--context="" Le nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactiver la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la feature gate KUBECTL_KUBERC=false ou en désactivant la feature KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, le scope du namespace pour cette requête CLI

--password="" Mot de passe pour l'authentification basique auprès du serveur API

--profile="none" Nom du profil à capturer. L'un des suivants (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" Le temps d'attente avant d'abandonner une requête serveur unique. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas expirer les requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification Bearer pour le serveur API

--user="" Le nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification basique auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Afficher les ressources d'API prises en charge
  kubectl api-resources
  # Afficher les ressources d'API prises en charge avec plus d'informations
  kubectl api-resources -o wide
  # Afficher les ressources d'API prises en charge triées par une colonne
  kubectl api-resources --sort-by=name
  # Afficher les ressources namespacées prises en charge
  kubectl api-resources --namespaced=true
  # Afficher les ressources non-namespacées prises en charge
  kubectl api-resources --namespaced=false
  # Afficher les ressources d'API prises en charge avec un APIGroup spécifique
  kubectl api-resources --api-group=rbac.authorization.k8s.io
