KDIFF3(1) Manuel de l'utilisateur KDiff3 KDIFF3(1)

NOM

kdiff3 - Outil de comparaison et de fusion de fichiers et de dossiers

SYNOPSIS

kdiff3 [-u, --ignore] [--query] [--html] [--abort] [-m, --merge] [-b, --base fichier] [-o, --output fichier] [--out fichier] [--noauto] [--auto] [--L1 alias1] [--L2 alias2] [--L3 alias3] [-L, --fname alias] [--cs chaine] [--confighelp] [--config fichier] [Fichier1] [Fichier2] [Fichier3]

DESCRIPTION

Compare deux ou trois fichiers ou dossiers d'entrée.

OPTIONS

-u, --ignore

Ignoré. (Défini par l'utilisateur.)

--query

Ignoré. (Défini par l'utilisateur.)

--html

Ignoré. (Défini par l'utilisateur.)

--abort

Ignoré. (Défini par l'utilisateur.)

-m, --merge

Fusionner l'entrée.

-b, --base fichier

Fichier de base explicite. Pour la compatibilité avec certains outils.

-o, --output fichier

Fichier de sortie. Implique -m. par exemple : -o nouveau_fichier.txt

--out fichier

Fichier de sortie, à nouveau. (Pour la compatibilité avec certains outils.)

--auto

Pas d'interface graphique si tous les conflits sont résolubles automatiquement. (Nécessite -o fichier)

--noauto

Ignorer --auto et toujours afficher l'interface graphique.

--L1 alias1

Remplacement du nom visible pour le fichier d'entrée 1 (base).

--L2 alias2

Remplacement du nom visible pour le fichier d'entrée 2.

--L3 alias3

Remplacement du nom visible pour le fichier d'entrée 3.

-L, --fname alias

Remplacement alternatif du nom visible. Fournir ceci une fois pour chaque entrée.

--cs chaine

Remplacer un paramètre de configuration. Utiliser une fois pour chaque paramètre. par exemple : --cs AutoAdvance=1.

--confighelp

Afficher la liste des paramètres de configuration et leurs valeurs actuelles.

--config fichier

Utiliser un fichier de configuration différent.

Fichier1

fichier1 à ouvrir (base, si non spécifié via --base)

Fichier2

fichier2 à ouvrir

Fichier3

fichier3 à ouvrir
