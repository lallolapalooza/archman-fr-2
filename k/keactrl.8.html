NOM

keactrl - Script shell pour gérer Kea

SYNOPIS

keactrl [commande] [-c fichier-config-keactrl] [-s serveur[,serveur,...]] [-v]

DESCRIPTION

keactrl est un script shell qui contrôle le démarrage, l'arrêt et la reconfiguration des serveurs Kea (kea-dhcp4, kea-dhcp6, kea-dhcp-ddns, kea-ctrl-agent et kea-netconf). Il permet également de vérifier l'état actuel des serveurs et de déterminer les fichiers de configuration utilisés.

FICHIER DE CONFIGURATION

Selon les besoins de l'utilisateur, tous les serveurs disponibles ne doivent pas nécessairement être exécutés. Le fichier de configuration keactrl spécifie quels serveurs sont activés et lesquels sont désactivés. Par défaut, le fichier de configuration est [kea-install-dir]/etc/kea/keactrl.conf.

Consultez le Manuel de référence de l'administrateur Kea pour la documentation des paramètres du fichier de configuration de keactrl.

OPTIONS

commande
Spécifie la commande à émettre aux serveurs. Il peut s'agir de l'une des suivantes :
start
Démarre les serveurs.
stop
Arrête les serveurs.
reload
Demande aux serveurs de relire le fichier de configuration Kea. Cette commande n'est pas prise en charge par l'agent NETCONF.
status
Affiche l'état des serveurs.
-c|--ctrl-config fichier-config-keactrl
Spécifie le fichier de configuration de keactrl. Sans cette option, keactrl utilise le fichier [kea-install-dir]/etc/kea/keactrl.conf.
-s|--server serveur[,serveur,...]
Spécifie un sous-ensemble des serveurs activés auxquels la commande doit être émise. La liste des serveurs doit être séparée par des virgules, sans espaces intermédiaires. Les valeurs acceptables sont :
dhcp4
Serveur DHCPv4 (kea-dhcp4).
dhcp6
Serveur DHCPv6 (kea-dhcp6).
dhcp_ddns
Serveur DHCP DDNS (kea-dhcp-ddns).
ctrl_agent
Agent de contrôle (kea-ctrl-agent).
netconf
Agent NETCONF (kea-netconf).
all
Tous les serveurs, y compris NETCONF s'il a été configuré pour être compilé. C'est la valeur par défaut.
-v|--version
Affiche la version de Kea.
-V
Affiche la version étendue de Kea.

DOCUMENTATION

Kea est livré avec un Manuel de référence de l'administrateur Kea exhaustif qui couvre tous les aspects de l'exécution du logiciel Kea - compilation, installation, configuration, exemples de configuration, et bien plus encore. Kea propose également un Manuel des messages Kea, qui liste tous les messages possibles que Kea peut afficher avec une brève description pour chacun d'eux. Les deux documents sont disponibles dans divers formats (.txt, .html, .pdf) avec la distribution Kea. La documentation Kea est disponible à l'adresse https://kea.readthedocs.io.

Le code source de Kea est documenté dans le Guide du développeur Kea, disponible à l'adresse https://reports.kea.isc.org/dev_guide/.

Le site web du projet Kea est disponible à l'adresse https://kea.isc.org.

LISTES DE DIFFUSION ET SUPPORT

Deux listes de diffusion publiques sont disponibles pour le projet Kea. kea-users (kea-users at lists.isc.org) est destinée aux utilisateurs de Kea, tandis que kea-dev (kea-dev at lists.isc.org) est destinée aux développeurs de Kea, aux contributeurs potentiels et aux autres utilisateurs avancés. Les deux listes sont disponibles à l'adresse https://lists.isc.org. La communauté fournit un support au mieux de ses capacités sur ces deux listes.

ISC fournit un support professionnel pour les services Kea. Voir https://www.isc.org/kea/ pour plus de détails.
