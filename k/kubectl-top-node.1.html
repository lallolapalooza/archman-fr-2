NOM

kubectl top node - Afficher l'utilisation des ressources (CPU/mémoire) des nœuds

SYNTAXE

kubectl top node [OPTIONS]

DESCRIPTION

Affiche l'utilisation des ressources (CPU/mémoire) des nœuds.

La commande top-node permet de visualiser la consommation des ressources des nœuds.

OPTIONS

--no-headers=false Si présent, afficher la sortie sans les en-têtes

-l, --selector="" Sélecteur (requête d'étiquette) pour filtrer, supporte '=', '==', '!=', 'in', 'notin'. (par exemple : -l clé1=valeur1,clé2=valeur2,clé3 in (valeur3)). Les objets correspondants doivent satisfaire toutes les contraintes d'étiquette spécifiées.

--show-capacity=false Afficher les ressources des nœuds basées sur la capacité au lieu des ressources allouables (par défaut) des nœuds.

--show-swap=false Afficher les ressources des nœuds relatives à la mémoire swap.

--sort-by="" Si non vide, trier la liste des nœuds en utilisant le champ spécifié. Le champ peut être 'cpu' ou 'memory'.

--use-protocol-buffers=true Active l'utilisation des buffers de protocole pour accéder à l'API Metrics.

OPTIONS HERITEES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce flag peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant le gate de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, l'espace de noms pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. L'un des choix suivants : (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie qu'il n'y a pas de délai d'attente pour les requêtes.

-s, --server="" Adresse et port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification Bearer pour l'authentification auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Afficher les métriques de tous les nœuds
  kubectl top node
  # Afficher les métriques d'un nœud donné
  kubectl top node NOM_DU_NOEUD
