KDESVN(1) Manuel utilisateur kdesvn KDESVN(1)

NOM

kdesvn - Un client Subversion par KDE (application autonome)

SYNTAXE

kdesvn [options] exec <commande> [URL]

DESCRIPTION

Un client Subversion par KDE (application autonome)

OPTIONS

Arguments :

exec <commande>

Exécute une commande subversion ("exec help" pour plus d'informations, ouvre le Centre d'aide KDE)

URL

Chemin vers la copie de travail locale ou un dépôt.

Options :

-r debut[:fin]

Exécute une seule commande subversion sur une révision (-plage) spécifique

-R

Demande la révision lors de l'exécution d'une commande unique

-f

Force l'opération

-o <fichier>

Sauvegarde la sortie de la commande subversion (par ex. « cat ») dans le fichier <fichier>

-l <nombre>

Limite la sortie du log à <nombre>

EXEMPLE

kdesvn file:///chemin/vers/copie/de/travail/locale

kdesvn http://projet/svn/distant/trunk

VOIR AUSSI

La documentation complète de l'utilisateur est disponible via le Centre d'aide KHelpCenter. Vous pouvez également entrer l'URL help:/kdesvn/ directement dans Konqueror ou exécuter `khelpcenter help:/kdesvn/' depuis la ligne de commande.
