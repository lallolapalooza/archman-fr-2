NOM

kubeadm upgrade apply phase kubelet-config - Met à jour la configuration du kubelet pour ce nœud

SYNTAXE

kubeadm upgrade apply phase kubelet-config [OPTIONS]

DESCRIPTION

Met à jour la configuration du kubelet pour ce nœud en la téléchargeant à partir du ConfigMap kubelet-config stocké dans le cluster

OPTIONS

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--dry-run=false Ne modifie aucun état, affiche seulement les actions qui seraient effectuées.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'indicateur n'est pas défini, un ensemble d'emplacements standard peut être recherché pour trouver un fichier kubeconfig existant.

--patches="" Chemin d'accès à un répertoire contenant des fichiers nommés "target[suffix][+patchtype].extension". Par exemple, "kube-apiserver0+merge.yaml" ou simplement "etcd.json". "target" peut être l'un de "kube-apiserver", "kube-controller-manager", "kube-scheduler", "etcd", "kubeletconfiguration", "corednsdeployment". "patchtype" peut être l'un de "strategic", "merge" ou "json" et correspond aux formats de patch pris en charge par kubectl. Le "patchtype" par défaut est "strategic". "extension" doit être soit "json", soit "yaml". "suffix" est une chaîne facultative qui peut être utilisée pour déterminer quels patchs sont appliqués en premier par ordre alphabétique.

OPTIONS HERITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée
