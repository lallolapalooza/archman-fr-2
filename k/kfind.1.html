NOM

kfind - utilitaire de recherche de fichiers par KDE

SYNTAXE

kfind [chemin-de-recherche] [options]

DESCRIPTION

L'outil Rechercher des fichiers est une méthode utile pour rechercher des fichiers spécifiques sur votre ordinateur, ou pour rechercher des fichiers qui correspondent à un modèle. Un exemple pourrait inclure la recherche de fichiers d'un type particulier ou avec certaines lettres dans le nom de fichier, ou qui contiennent un certain morceau de texte dans leur contenu.

KFind est un outil graphique, et n'est normalement pas exécuté depuis la ligne de commande.

OPTIONS

chemin-de-recherche

Vous pouvez éventuellement fournir un chemin pour pré-remplir la boîte de dialogue où commencer la recherche.
