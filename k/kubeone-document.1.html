NOM

kubeone-document - Génère la documentation

SYNTAXE

kubeone document [options]

DESCRIPTION

La documentation peut être générée sous forme de pages man, de fichiers markdown, de documents restructured text ou de fichiers yaml.

OPTIONS

-h, --help[=false] Aide pour document

-o, --output-dir="/tmp/" Répertoire dans lequel la documentation sera générée.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-c, --credentials="" Fichier à partir duquel extraire les identifiants et secrets.

-d, --debug[=false] Sortie de débogage avec trace de pile.

-l, --log-format="text" Format pour la journalisation.

-m, --manifest="./kubeone.yaml" Chemin vers la configuration KubeOne.

-t, --tfjson="" Source pour la sortie terraform au format JSON - à lire depuis l'entrée standard. Si le chemin est un fichier, son contenu sera utilisé. Si le chemin est un répertoire, terraform output -json sera exécuté dans ce répertoire.

-v, --verbose[=false] Sortie détaillée.

EXEMPLE

kubeone document man
