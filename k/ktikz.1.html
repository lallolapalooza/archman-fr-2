NOM

ktikz - éditeur pour le langage TikZ

SYNTAXE

ktikz [options Qt] [options KDE] [url | fichier]

DESCRIPTION

KtikZ est une petite application conçue pour aider à la création de diagrammes et de dessins utilisant les macros TikZ du paquet LaTeX « pgf ». Elle se compose d'un panneau d'édition de texte où le code TikZ du dessin est édité et d'un panneau de prévisualisation montrant le dessin tel que rendu par latex. Le panneau de prévisualisation peut être mis à jour en temps réel. Des outils de dessin courants, des options et des styles sont disponibles dans les menus pour faciliter le processus de codage.

OPTIONS

Options génériques :

--help
Afficher l'aide sur les options
--help-qt
Afficher les options spécifiques à Qt
--help-kde
Afficher les options spécifiques à KDE
--help-all
Afficher toutes les options
--author
Afficher les informations sur l'auteur
-v, --version
Afficher les informations sur la version
--license
Afficher les informations sur la licence

VOIR AUSSI

La documentation complète pour l'utilisateur est disponible via le Centre d'aide KDE. Vous pouvez également saisir directement l'URL help:/ktikz/ dans konqueror ou lancer `khelpcenter help:/ktikz/' depuis la ligne de commande.
