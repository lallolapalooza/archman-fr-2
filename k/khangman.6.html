KHANGMAN(6) Manuel de l'utilisateur KHangMan KHANGMAN(6)

NOM

khangman - Le jeu du pendu classique de KDE

DESCRIPTION

KHangMan est un jeu basé sur le célèbre jeu du pendu. Il s'adresse aux enfants de 6 ans et plus. Il propose plusieurs catégories de mots comme Animaux, Vêtements, Ordinateurs, Monnaies, etc.

Un mot est choisi au hasard et les lettres sont cachées. Vous devez deviner le mot en essayant une lettre après l'autre. Chaque fois que vous devinez une mauvaise lettre, une partie de l'image d'un pendu est dessinée. Vous devez deviner le mot avant d'être pendu ! Vous avez 10 essais.

Cette application fait partie du module KDE Edutainment.

VOIR AUSSI

Une documentation utilisateur plus détaillée est disponible à l'adresse help:/khangman (entrez cette URL dans Konqueror, ou exécutez khelpcenter help:/khangman).

Des informations supplémentaires sont également disponibles sur le site web KDE Edutainment[1].
