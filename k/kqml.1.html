NOM

kqml - Runtime QML avec KLocalizedContext

SYNTAXE

kqml [-v, --version] [-h, --help] [-d, --domaindomaine] [fichiers...] [-- args...]

DESCRIPTION

kqml est un runtime QML avec KLocalizedContext initialisé.

Contrairement à l'outil qml fourni avec le paquet qt-declarative, kqml initialise KLocalizedContext, ce qui permet de tester des applications du monde réel et des fichiers temporaires avec des appels i18n dans leur code et leurs bibliothèques importées.

OPTIONS

-v, --version

Affiche les informations de version.

-d, --domain domaine

Le domaine de localisation principal.

-h, --help

Affiche cette aide.

fichiers...

N'importe quel nombre de fichiers QML peut être chargé. Ils partageront le même moteur.

args...

Les arguments après '--' sont ignorés, mais transmis à la variable arguments de l'application en QML.

VOIR AUSSI

Une documentation utilisateur plus détaillée est disponible à l'adresse help:/plasma-desktop (entrez cette URL dans Konqueror ou exécutez khelpcenter help:/plasma-desktop).
