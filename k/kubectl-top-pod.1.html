NOM

kubectl top pod - Afficher l'utilisation des ressources (CPU/mémoire) des pods

SYNOPIS

kubectl top pod [OPTIONS]

DESCRIPTION

Affiche l'utilisation des ressources (CPU/mémoire) des pods.

La commande 'top pod' vous permet de voir la consommation des ressources des pods.

En raison du délai du pipeline de métriques, elles peuvent être indisponibles pendant quelques minutes depuis la création du pod.

OPTIONS

-A, --all-namespaces=false Si présent, lister les objets demandés dans tous les namespaces. Le namespace du contexte actuel est ignoré même s'il est spécifié avec --namespace.

--containers=false Si présent, afficher l'utilisation des conteneurs au sein d'un pod.

--field-selector="" Sélecteur (requête de champ) pour filtrer, supporte '=', '==', et '!='.(ex: --field-selector clef1=valeur1,clef2=valeur2). Le serveur ne supporte qu'un nombre limité de requêtes de champs par type.

--no-headers=false Si présent, afficher la sortie sans en-têtes.

-l, --selector="" Sélecteur (requête d'étiquette) pour filtrer, supporte '=', '==', '!=', 'in', 'notin'.(ex: -l clef1=valeur1,clef2=valeur2,clef3 in (valeur3)). Les objets correspondants doivent satisfaire toutes les contraintes d'étiquettes spécifiées.

--show-swap=false Afficher les ressources des pods liées à la mémoire swap.

--sort-by="" Si non vide, trier la liste des pods en utilisant le champ spécifié. Le champ peut être soit 'cpu' soit 'memory'.

--sum=false Afficher la somme de l'utilisation des ressources

--use-protocol-buffers=true Active l'utilisation des protocol-buffers pour accéder à l'API Metrics.

OPTIONS HERITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Le nom du cluster kubeconfig à utiliser

--context="" Le nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactiver la compression des réponses pour toutes les requêtes vers le serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la porte d'accès de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, la portée du namespace pour cette requête CLI

--password="" Mot de passe pour l'authentification basique auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas expirer les requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification (Bearer token) pour l'authentification auprès du serveur API

--user="" Le nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification basique auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Afficher les métriques pour tous les pods dans le namespace par défaut
  kubectl top pod
  # Afficher les métriques pour tous les pods dans le namespace donné
  kubectl top pod --namespace=NAMESPACE
  # Afficher les métriques pour un pod donné et ses conteneurs
  kubectl top pod NOM_DU_POD --containers
  # Afficher les métriques pour les pods définis par l'étiquette name=myLabel
  kubectl top pod -l name=myLabel
