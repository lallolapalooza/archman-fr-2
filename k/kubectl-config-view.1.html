NOM

kubectl config view - Afficher les paramètres kubeconfig fusionnés ou un fichier kubeconfig spécifié

SYNTAXE

kubectl config view [OPTIONS]

DESCRIPTION

Affiche les paramètres kubeconfig fusionnés ou un fichier kubeconfig spécifié.

Vous pouvez utiliser --output jsonpath={...} pour extraire des valeurs spécifiques à l'aide d'une expression jsonpath.

OPTIONS

--allow-missing-template-keys=true Si vrai, ignorez toutes les erreurs dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. S'applique uniquement aux formats de sortie golang et jsonpath.

--flatten=false Aplatir le fichier kubeconfig résultant dans une sortie autonome (utile pour créer des fichiers kubeconfig portables)

--merge=true Fusionner la hiérarchie complète des fichiers kubeconfig

--minify=false Supprimer toutes les informations non utilisées par le contexte actuel de la sortie

-o, --output="yaml" Format de sortie. Un parmi : (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--raw=false Afficher les données brutes en octets et les données sensibles

--show-managed-fields=false Si vrai, conserver les managedFields lors de l'impression des objets au format JSON ou YAML.

--template="" Chaîne de modèle ou chemin vers un fichier modèle à utiliser lorsque -o=go-template, -o=go-template-file. Le format du modèle est le modèle golang [http://golang.org/pkg/text/template/#pkg-overview].

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur ordinaire ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactiver la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" utiliser un fichier kubeconfig particulier

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Cela peut être désactivé en exportant la fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, la portée de l'espace de noms pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier où écrire le profil

--request-timeout="0" La durée pendant laquelle attendre avant d'abandonner une requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas expirer les requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton Bearer pour l'authentification auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Afficher les paramètres kubeconfig fusionnés
  kubectl config view
  # Afficher les paramètres kubeconfig fusionnés, les données de certificat brutes et les secrets exposés
  kubectl config view --raw
  # Obtenir le mot de passe de l'utilisateur e2e
  kubectl config view -o jsonpath='{.users[?(@.name == "e2e")].user.password}'
