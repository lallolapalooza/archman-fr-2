NOM

kpsereadlink - afficher le contenu d'un lien symbolique

SYNTAXE

kpsereadlink fichier

DESCRIPTION

Si fichier est un lien symbolique, affiche son contenu (ce vers quoi il pointe), et se termine avec succès. Se termine avec une erreur dans le cas contraire.

Sur les systèmes qui ne supportent pas les liens symboliques, kpsereadlink échouera toujours.

OPTIONS

kpsereadlink accepte les options suivantes :

--help
Affiche un message d'aide et se termine.
--version
Affiche des informations sur la version et se termine.
