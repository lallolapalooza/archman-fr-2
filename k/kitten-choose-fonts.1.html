Nom

kitten-choose-fonts - Documentation de kitten

Aperçu

Les amateurs de terminaux passent toute la journée à regarder du texte, c'est pourquoi il est très important d'obtenir un rendu de texte juste comme il faut. kitty dispose de facilités extrêmement puissantes pour affiner le rendu du texte. Il prend en charge les fonctionnalités OpenType https://en.wikipedia.org/wiki/List_of_typographic_features pour sélectionner des glyphes alternatifs, et les polices variables https://en.wikipedia.org/wiki/Variable_font pour contrôler précisément l'épaisseur ou l'espacement d'une police. Vous pouvez également sélectionner quelle police est utilisée pour rendre des points de code Unicode particuliers <#opt-kitty.symbol_map> et vous pouvez modifier les métriques de police <#opt-kitty.modify_font> et même ajuster les courbes gamma <#opt-kitty.text_composition_strategy> utilisées pour rendre le texte sur la couleur de fond.

La première étape consiste à sélectionner les graisses de police que kitty utilisera pour le rendu du texte normal, gras et italique. kitty est livré avec une interface utilisateur pratique pour choisir les polices, sous la forme du kitten choose-fonts. Lancez simplement :

kitten choose-fonts

et suivez les instructions à l'écran.

D'abord, choisissez la famille que vous voulez, la liste des familles peut être facilement filtrée en tapant quelques lettres du nom de famille que vous recherchez. L'écran de sélection de la famille vous montre un aperçu de l'apparence de la famille.

Une fois que vous avez sélectionné une famille en appuyant sur la touche Entrée, vous verrez des aperçus de l'apparence des graisses normale, grasse et italique pour cette famille. Vous pouvez choisir d'affiner n'importe laquelle des graisses. Commencez par affiner la graisse normale en appuyant sur la touche R. Les autres styles seront automatiquement ajustés en fonction de ce que vous sélectionnez pour la graisse normale.

Vous pouvez choisir un style ou une fonctionnalité de police spécifique en cliquant dessus. Une valeur précise pour tous les axes variables peut être sélectionnée à l'aide du curseur, dans la capture d'écran ci-dessus, la police prend en charge l'ajustement précis de l'épaisseur. Si vous avez de la chance, le concepteur de polices a inclus des noms descriptifs pour les fonctionnalités de police, qui seront affichés, sinon, consultez la documentation de la police pour voir ce que fait chaque fonctionnalité.

La syntaxe de spécification de police

Si vous n'aimez pas le kitten choose fonts ou si vous voulez simplement comprendre et écrire vous-même les options de sélection de polices dans kitty.conf, lisez la suite.

Il existe quatre clés de sélection de graisse de police : font_family, bold_font, italic_font et bold_italic_font. Chacune d'elles prend en charge la syntaxe décrite ci-dessous. Leurs valeurs peuvent être de trois types : soit un nom de famille de police, le mot-clé auto, soit une syntaxe étendue clé=valeur pour spécifier précisément la sélection de la police.

Si un nom de famille de police est spécifié, kitty utilisera les API du système d'exploitation pour rechercher une police correspondante. Le mot-clé auto signifie que kitty choisira une police de manière totalement automatique, c'est généralement utilisé pour sélectionner automatiquement les variantes grasses/italiques une fois que font_family <#opt-kitty.font_family> est défini. Les variantes grasses et italiques utiliseront alors automatiquement le même ensemble de fonctionnalités que la graisse principale.

Pour spécifier la sélection de la graisse de police plus précisément, une syntaxe clé=valeur est utilisée. Tout d'abord, examinons quelques exemples :

# Sélectionner par famille uniquement, la sélection réelle de la graisse est automatique
font_family family="Fira Code"
# Sélectionner une graisse exacte par son nom PostScript
font_family postscript_name=FiraCode
# Sélectionner une graisse exacte par famille avec des fonctionnalités et une épaisseur variable
font_family family=SourceCodeVF variable_name=SourceCodeUpright features="+zero cv01=2" wght=380

Voici les clés connues, toute autre clé est le nom d'un axe variable, c'est-à-dire qu'elle est utilisée pour définir la valeur variable d'une caractéristique de la police.

family
Un nom de famille de police. Une famille a généralement plusieurs graisses de police réelles, telles que des variantes grasses et italiques. Une ou plusieurs des graisses peuvent même être variables, permettant un réglage fin des caractéristiques de la police.
style
Un nom de style pour choisir une police particulière dans une famille donnée. Utile uniquement avec la clé family, lorsqu'aucune méthode plus précise de sélection de graisse n'est spécifiée. Peut également être utilisé pour spécifier un style variable nommé pour les polices variables.
postscript_name
Le nom PostScript réel d'une graisse de police. Cela permet de sélectionner une variante particulière au sein d'une famille de polices. Mais notez que les noms PostScript sont généralement insuffisants pour sélectionner les polices variables.
full_name
Ceci peut être utilisé pour sélectionner une graisse de police particulière dans une famille. Cependant, c'est moins précis que postscript_name et ne devrait généralement pas être utilisé.
variable_name
Certaines familles de polices variables contiennent en réalité plusieurs fichiers de polices. Par exemple, une famille pourrait avoir des épaisseurs variables avec un fichier de police contenant des graisses verticales variables et un autre contenant des graisses italiques variables. Les polices bien conçues utilisent un nom variable pour distinguer de tels fichiers. Doit être utilisé conjointement avec family pour sélectionner un fichier de police variable particulier.
features
Une liste séparée par des espaces de fonctionnalités de police OpenType à activer/désactiver ou à sélectionner une valeur pour cette police. Consultez la documentation de la famille de polices pour voir quelles fonctionnalités elle prend en charge et leurs effets. La syntaxe exacte pour spécifier les fonctionnalités est documentée par HarfBuzz https://harfbuzz.github.io/harfbuzz-hb-common.html#hb-feature-from-string
system
Ceci peut être utilisé pour passer une chaîne arbitraire, généralement un nom de famille ou un nom complet, aux API de sélection de polices du système d'exploitation. Ne doit pas être utilisé conjointement avec d'autres clés. Est équivalent à spécifier simplement le nom de la police sans aucune clé.

En plus de ces clés, toute clé de quatre lettres est traitée comme le nom d'une caractéristique variable de la police. Sa valeur est utilisée pour définir la valeur du nom.
