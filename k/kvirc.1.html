NOM

KVIrc - un client Internet Relay Chat.

SYNTAXE

kvirc [options] [serveur [port]] [ircurl [ircurl [...]]]

DESCRIPTION

KVIrc est un client Visual Internet Relay Chat basé sur la bibliothèque Qt.

Il vise à être une interface conviviale pour le protocole IRC (voir RFC1459) et ses extensions.

OPTIONS

KVIrc accepte les options suivantes :

-h, --help
Affiche une liste de toutes les options de la ligne de commande et quitte.
-v, --version
Affiche les informations de version.
-c <fichier>
Utilise <fichier> comme fichier de configuration au lieu de ~/.kvirc4.rc. La valeur par défaut est $HOME/.kvirc4.rc si <fichier> n'existe pas.
-n <fichier>
Utilise <fichier> comme fichier de configuration au lieu de ~/.kvirc4.rc. Crée <fichier> s'il n'existe pas.
-f
Force une nouvelle session KVIrc, même si une session est déjà en cours d'exécution.
-e <commandes>
Si une session KVIrc est déjà en cours d'exécution, exécute les <commandes> dans cette session, sinon démarre normalement et exécute <commandes>. <commandes> doit être un seul jeton shell. Vous pouvez éventuellement utiliser ce commutateur plus d'une fois.
-x <commandes>
Si une session KVIrc est déjà en cours d'exécution, exécute les <commandes> dans cette session, sinon ne fait rien et quitte. <commandes> doit être un seul jeton shell. Vous pouvez éventuellement utiliser ce commutateur plus d'une fois.
-r <commandes>
Si une session KVIrc est déjà en cours d'exécution, exécute les <commandes> dans cette session, sinon démarre normalement (n'exécute pas). <commandes> doit être un seul jeton shell. Vous pouvez éventuellement utiliser ce commutateur plus d'une fois.
-m
Si une session KVIrc est déjà en cours d'exécution, affiche une boîte de dialogue d'information au lieu d'écrire dans la console. Ceci est utile lors du lancement de KVIrc depuis un bouton de la barre des tâches graphique.
[serveur]
Se connecte à ce serveur après le démarrage.
[port]
Utilise ce port pour la connexion. Cette option nécessite également un nom de serveur.
[ircurl]
Une URL de la forme suivante :


irc[6]://<serveur>[:<port>][/<canal>[?<mot_de_passe>]]

Pour chaque URL sur la ligne de commande, crée un nouveau contexte IRC et tente de se connecter à <serveur> sur le <port> spécifié. Le <canal> optionnel est rejoint juste après l'établissement de la connexion.

ENVIRONNEMENT

KVIRC_LANG
Paramètre de langue. S'il n'est pas défini, KVIrc vérifie $LANG.
LANG
Paramètre de langue. S'il n'est pas défini (ou défini sur 'EN', 'POSIX' ou 'C'), KVIrc utilise la langue par défaut (anglais).

FICHIERS

$PREFIX/share/kvirc/VERSION/* Répertoire contenant les paramètres globaux de KVIrc, les modules, etc.

$HOME/.kvirc4.rc. C'est le premier fichier que KVIrc recherche. Si l'option de ligne de commande -c est spécifiée, le fichier passé comme paramètre de l'option est utilisé à la place. Si le fichier est trouvé, KVIrc lit la première ligne non vide et la traite comme le chemin d'accès au répertoire local de KVIrc. Si le fichier ne peut pas être trouvé ou si le répertoire local de KVIrc n'existe pas, KVIrc entre en mode de configuration et permet de sélectionner un nouveau répertoire local de KVIrc.

Répertoire local de KVIrc/* Répertoire contenant les paramètres locaux (par utilisateur) de KVIrc. Similaire au répertoire global.
