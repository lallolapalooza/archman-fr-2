NOM

kcutilmgr - interface en ligne de commande d'utilitaires divers

DESCRIPTION

La commande `kcutilmgr' est un outil d'utilitaires divers, et permet d'afficher la configuration. Cette commande est utilisée dans le format suivant. `fichier' spécifie un fichier d'entrée. S'il est omis, l'entrée standard est lue. S'il commence par "@", la sous-chaîne restante est traitée comme l'entrée. `modèle' spécifie un modèle correspondant.


kcutilmgr hex [-d] [fichier]
Effectue l'encodage hexadécimal et son décodage.
kcutilmgr enc [-hex|-url|-quote] [-d] [fichier]
Effectue l'encodage et le décodage Base64.
kcutilmgr ciph [-key str] [fichier]
Effectue le chiffrement et le déchiffrement Arcfour.
kcutilmgr comp [-def|-gz|-lzo|-lzma] [-d] [fichier]
Effectue l'encodage et le décodage ZLIB. Par défaut, utilise le format brut.
kcutilmgr hash [-fnv|-path|-crc] [fichier]
Calcule la valeur de hachage. Par défaut, utilise le hachage MurMur.
kcutilmgr regex [-alt str] [-ic] modèle [fichier]
Imprime les lignes correspondant à une expression régulière.
kcutilmgr conf [-v|-i|-l|-p]
Affiche la configuration de Kyoto Cabinet.
kcutilmgr version
Affiche les informations de version de Kyoto Cabinet.

Les options incluent :

-d : effectue le décodage (déséchappement), pas l'encodage (échappement).
-hex : utilise l'encodage hexadécimal.
-url : utilise l'encodage URL.
-quote : utilise l'encodage Quoted-printable.
-key str : définit la clé de chiffrement.
-def : utilise le format deflate.
-gz : utilise le format gzip.
-lzo : utilise l'encodage LZO.
-lzma : utilise l'encodage LZMA.
-fnv : utilise le hachage FNV.
-path : utilise le hachage de chemin de la base de données de répertoire.
-crc : calcule la somme de contrôle CRC32.
-alt str : remplace la sous-chaîne correspondante par la chaîne alternative.
-ic : ignore la différence entre les majuscules et les minuscules.
-v : affiche le numéro de version de Kyoto Cabinet.
-i : affiche les options pour inclure les en-têtes de Tokyo Cabinet.
-l : affiche les options pour lier la bibliothèque de Tokyo Cabinet.
-p : affiche le chemin du répertoire des commandes.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
