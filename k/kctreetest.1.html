NOM

kctreetest - interface en ligne de commande pour tester la base de données d'arbres de fichiers

DESCRIPTION

La commande `kctreetest' est un utilitaire pour les tests de facilité et de performance de la base de données d'arbres de fichiers. Cette commande est utilisée dans le format suivant. `path' spécifie le chemin d'un fichier de base de données. `rnum' spécifie le nombre d'itérations.


kctreetest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Effectue des tests en ordre.
kctreetest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Effectue des opérations de mise en file d'attente.
kctreetest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Effectue des opérations mixtes sélectionnées aléatoirement.
kctreetest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-msiz num] [-dfunit num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] path rnum
Effectue des tests de transaction.

Les options comprennent les suivantes.

-th num : spécifie le nombre de threads de travail.
-rnd : effectue un test aléatoire.
-set : effectue uniquement l'opération de réglage.
-get : effectue uniquement l'opération d'obtention.
-getw : effectue uniquement l'opération d'obtention avec un tampon.
-rem : effectue uniquement l'opération de suppression.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-oat : ouvre la base de données avec l'option de transaction automatique.
-oas : ouvre la base de données avec l'option de synchronisation automatique.
-onl : ouvre la base de données avec l'option sans verrouillage.
-otl : ouvre la base de données avec l'option de verrouillage par tentative.
-onr : ouvre la base de données avec l'option de non-réparation automatique.
-apow num : spécifie la puissance de l'alignement de la taille de l'enregistrement.
-fpow num : spécifie la puissance de la capacité du pool de blocs libres.
-ts : ajuste la base de données avec l'option petite.
-tl : ajuste la base de données avec l'option linéaire.
-tc : ajuste la base de données avec l'option de compression.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-psiz num : spécifie la taille de chaque page.
-msiz num : spécifie la taille de la région mappée en mémoire.
-dfunit num : spécifie le nombre d'unités d'incrémentation de la défragmentation automatique.
-pccap num : spécifie la capacité du cache de pages.
-rcd : utilise le comparateur décimal au lieu du comparateur lexical.
-rcld : utilise le comparateur lexical descendant au lieu du comparateur ascendant.
-rcdd : utilise le comparateur décimal descendant au lieu du comparateur lexical.
-lv : signale toutes les erreurs.
-it num : spécifie le nombre de répétitions.
-hard : effectue une synchronisation physique.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
