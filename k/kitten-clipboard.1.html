Nom

kitten-clipboard - Copier/coller avec le presse-papiers système, même via SSH

Aperçu

Copier/coller dans le presse-papiers système depuis des scripts shell

Le kitten clipboard peut être utilisé pour lire ou écrire dans le presse-papiers système depuis le shell. Il fonctionne même via SSH. Son utilisation est aussi simple que :

echo hooray | kitten clipboard

Tout texte reçu sur STDIN est copié dans le presse-papiers.

Pour obtenir du texte du presse-papiers :

kitten clipboard --get-clipboard

Le texte sera écrit sur STDOUT. Notez que par défaut, kitty demande la permission lorsqu'un programme tente de lire le presse-papiers. Ceci peut être contrôlé via clipboard_control <#opt-kitty.clipboard_control>.

Ajouté dans la version 0.27.0 : Prise en charge de la copie de types de données arbitraires

Le kitten clipboard peut être utilisé pour envoyer/recevoir plus que du simple texte du presse-papiers système. Vous pouvez transférer des types de données arbitraires. Mieux illustré par quelques exemples :

# Copier une image dans le presse-papiers :
kitten clipboard picture.png
# Copier une image et du texte dans le presse-papiers :
kitten clipboard picture.jpg text.txt
# Copier du texte de STDIN et une image dans le presse-papiers :
echo hello | kitten clipboard picture.png /dev/stdin
# Copier toute image raster disponible dans le presse-papiers vers un fichier PNG :
kitten clipboard -g picture.png
# Copier une image vers un fichier et du texte vers STDOUT :
kitten clipboard -g picture.png /dev/stdout
# Lister les formats disponibles dans le presse-papiers système
kitten clipboard -g -m . /dev/stdout

Normalement, le kitten devine les types MIME en fonction des noms de fichiers. Pour contrôler précisément les types MIME, utilisez l'option --mime.

Ce kitten utilise un nouveau protocole développé par kitty pour fonctionner, pour plus de détails, voir Copier tous les types de données dans le presse-papiers <>.

Code source pour clipboard

Le code source de ce kitten est disponible sur GitHub https://github.com/kovidgoyal/kitty/tree/master/kittens/clipboard.

Interface en ligne de commande

kitten clipboard [options] [fichiers à copier vers/depuis]

Lire ou écrire dans le presse-papiers système.

Ce kitten fonctionne plus simplement en mode filtre. Pour définir le texte du presse-papiers, redirigez le nouveau texte sur STDIN. Utilisez l'option --get-clipboard pour afficher le contenu actuel du presse-papiers sur STDOUT. Notez que la copie depuis le presse-papiers déclenchera une boîte de dialogue de permission, voir clipboard_control <#opt-kitty.clipboard_control> pour les détails.

Pour plus de contrôle, spécifiez des arguments de nom de fichier. Ainsi, différents types MIME peuvent être copiés vers/depuis le presse-papiers. Quelques exemples :

# Copier une image dans le presse-papiers :
kitten clipboard picture.png
# Copier une image et du texte dans le presse-papiers :
kitten clipboard picture.jpg text.txt
# Copier du texte de STDIN et une image dans le presse-papiers :
echo hello | kitten clipboard picture.png /dev/stdin
# Copier toute image raster disponible dans le presse-papiers vers un fichier PNG :
kitten clipboard -g picture.png
# Copier une image vers un fichier et du texte vers STDOUT :
kitten clipboard -g picture.png /dev/stdout
# Lister les formats disponibles dans le presse-papiers système
kitten clipboard -g -m . /dev/stdout

Options

--get-clipboard [=no], -g [=no]
Affiche le contenu actuel du presse-papiers sur STDOUT. Notez que par défaut, kitty demandera la permission d'accéder au presse-papiers. Peut être contrôlé par clipboard_control <#opt-kitty.clipboard_control>.
--use-primary [=no], -p [=no]
Utilise la sélection primaire plutôt que le presse-papiers sur les systèmes qui le prennent en charge, comme Linux.
--mime <MIME>, -m <MIME>
Le mimetype du fichier spécifié. Utile lorsque le mimetype détecté automatiquement est susceptible d'être incorrect ou lorsque le nom de fichier n'a pas d'extension et donc aucun mimetype ne peut être détecté. Si plus d'un fichier est spécifié, cette option doit être spécifiée plusieurs fois, une fois pour chaque fichier spécifié. Lors de la copie de données depuis le presse-papiers, vous pouvez utiliser des jokers pour faire correspondre les types MIME. Par exemple : --mime 'text/*' correspondra à tout type MIME textuel disponible dans le presse-papiers, généralement le premier type MIME correspondant est copié. Le type MIME spécial . retournera la liste des types MIME disponibles actuellement dans le presse-papiers système.
--alias <ALIAS>, -a <ALIAS>
Spécifie des alias pour les types MIME. Les types MIME aliasés sont considérés comme équivalents. Lors de la copie vers le presse-papiers, l'original et l'alias sont rendus disponibles dans le presse-papiers. Lors de la copie depuis le presse-papiers, si l'original n'est pas trouvé, l'alias est utilisé, en secours. Peut être spécifié plusieurs fois pour créer plusieurs alias. Par exemple : --alias text/plain=text/x-rst fait de text/plain un alias de text/rst. Les alias ne sont pas utilisés en mode filtre. Un alias pour text/plain est automatiquement créé si text/plain n'est pas présent dans les données d'entrée, mais qu'un autre type MIME text/* est présent.
--wait-for-completion [=no]
Attend la fin de la copie dans le presse-papiers avant de se terminer. Utile si le kitten est exécuté dans une fenêtre dédiée et éphémère. Nécessaire uniquement en mode filtre.
--password <PASSWORD>
Un mot de passe à utiliser lors de l'accès au presse-papiers. Si l'utilisateur choisit d'accepter le mot de passe, les invocations futures du kitten ne demanderont plus de permission dans cette session tty. Ne fonctionne pas en mode filtre. Doit être sous la forme : text:mot-de-passe-réel ou fd:entier (un numéro de descripteur de fichier pour lire le mot de passe) ou file:chemin-vers-fichier (un fichier à partir duquel lire le mot de passe). Notez que vous devez également spécifier un nom convivial à l'aide de l'indicateur --human-name.
--human-name <HUMAN_NAME>
Un nom convivial à afficher à l'utilisateur lors de la demande de permission d'accéder au presse-papiers.

NOM

kitten-clipboard — Un utilitaire pour copier et coller des données du presse-papiers.

SYNTAXE

kitten-clipboard [-i | -o] [-f FORMAT] [-c CLIPBOARD] [-t TARGET] [FILE]

DESCRIPTION

kitten-clipboard est un outil en ligne de commande conçu pour interagir avec le presse-papiers du système. Il permet aux utilisateurs de copier des données dans le presse-papiers ou de coller des données depuis celui-ci, en spécifiant le format et le presse-papiers à utiliser.

OPTIONS

  • -i, --input : Coller les données du presse-papiers.
  • -o, --output : Copier les données dans le presse-papiers.
  • -f, --format FORMAT : Spécifie le format des données (par exemple, text/plain, image/png). La valeur par défaut est text/plain.
  • -c, --clipboard CLIPBOARD : Spécifie le presse-papiers à utiliser (par exemple, primary, clipboard). La valeur par défaut est clipboard.
  • -t, --target TARGET : Spécifie la cible pour le collage (par exemple, un nom de fichier ou un gestionnaire de fenêtres).
  • FILE : Le fichier à lire pour copier des données (utilisé avec -o) ou le fichier dans lequel écrire les données collées (utilisé avec -i). S'il n'est pas spécifié, l'entrée/sortie standard sera utilisée.

EXEMPLES

Copier le contenu du fichier data.txt dans le presse-papiers : 

kitten-clipboard -o -f text/plain data.txt

Coller le contenu du presse-papiers dans le fichier output.txt : 

kitten-clipboard -i -f text/plain -o output.txt

Copier une image dans le presse-papiers : 

kitten-clipboard -o -f image/png my_image.png

NOTES

La disponibilité des formats et des presse-papiers peut dépendre de votre environnement de bureau et des bibliothèques installées.

FICHIERS

Aucun fichier spécifique n'est utilisé par défaut, l'entrée et la sortie sont gérées via l'entrée/sortie standard ou les arguments de ligne de commande.
