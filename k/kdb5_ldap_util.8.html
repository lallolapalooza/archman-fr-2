NOM

kdb5_ldap_util - Utilitaire de configuration Kerberos

SYNOPSIS

kdb5_ldap_util [-D user_dn [-w passwd]] [-H ldapuri] commande [options_de_commande]

DESCRIPTION

kdb5_ldap_util permet à un administrateur de gérer les domaines, les services Kerberos et les politiques de tickets.

OPTIONS DE LIGNE DE COMMANDE

-r realm
Spécifie le domaine sur lequel opérer.
-D user_dn
Spécifie le Nom Distinctif (DN) de l'utilisateur disposant des droits suffisants pour effectuer l'opération sur le serveur LDAP.
-w passwd
Spécifie le mot de passe de user_dn. Cette option n'est pas recommandée.
-H ldapuri
Spécifie l'URI du serveur LDAP.

Par défaut, kdb5_ldap_util opère sur le domaine par défaut (tel que spécifié dans krb5.conf(5)) et se connecte et s'authentifie au serveur LDAP de la même manière que :ref:kadmind(8)` le ferait avec les paramètres dbdefaults dans kdc.conf(5).

COMMANDES

create

create [-subtrees subtree_dn_list] [-sscope search_scope] [-containerref container_reference_dn] [-k mkeytype] [-kv mkeyVNO] [-M mkeyname] [-m|-P password|-sf stashfilename] [-s] [-maxtktlife max_ticket_life] [-maxrenewlife max_renewable_ticket_life] [ticket_flags]

Crée un domaine dans l'annuaire. Options :

-subtrees subtree_dn_list
Spécifie la liste des sous-arbres contenant les principaux d'un domaine. La liste contient les DN des objets sous-arbre séparés par deux-points (:).
-sscope search_scope
Spécifie la portée de recherche des principaux sous le sous-arbre. Les valeurs possibles sont 1 ou one (un seul niveau), 2 ou sub (sous-arbres).
-containerref container_reference_dn
Spécifie le DN de l'objet conteneur dans lequel les principaux d'un domaine seront créés. Si la référence de conteneur n'est pas configurée pour un domaine, les principaux seront créés dans le conteneur du domaine.
-k mkeytype
Spécifie le type de clé de la clé maître dans la base de données. La valeur par défaut est donnée par la variable master_key_type dans kdc.conf(5).
-kv mkeyVNO
Spécifie le numéro de version de la clé maître dans la base de données ; la valeur par défaut est 1. Notez que 0 n'est pas autorisé.
-M mkeyname
Spécifie le nom du principal pour la clé maître dans la base de données. Si non spécifié, le nom est déterminé par la variable master_key_name dans kdc.conf(5).
-m
Indique que le mot de passe de la base de données maître doit être lu depuis le TTY plutôt que récupéré depuis un fichier sur le disque.
-P password
Spécifie le mot de passe de la base de données maître. Cette option n'est pas recommandée.
-sf stashfilename
Spécifie le fichier de stockage du mot de passe de la base de données maître.
-s
Indique que le fichier de stockage doit être créé.
-maxtktlife max_ticket_life
(chaîne getdate) Spécifie la durée de vie maximale des tickets pour les principaux de ce domaine.
-maxrenewlife max_renewable_ticket_life
(chaîne getdate) Spécifie la durée de renouvellement maximale des tickets pour les principaux de ce domaine.
ticket_flags
Spécifie les indicateurs de ticket globaux pour le domaine. Les indicateurs autorisés sont documentés dans la description de la commande add_principal dans kadmin(1).

Exemple :

kdb5_ldap_util -D cn=admin,o=org -H ldaps://ldap-server1.mit.edu
    -r ATHENA.MIT.EDU create -subtrees o=org -sscope SUB

Il est important que vous N'OUBLIEZ PAS ce mot de passe.
Entrez la clé maître de la base de données KDC :

modify

modify [-subtrees subtree_dn_list] [-sscope search_scope] [-containerref container_reference_dn] [-maxtktlife max_ticket_life] [-maxrenewlife max_renewable_ticket_life] [ticket_flags]

Modifie les attributs d'un domaine. Options :

-subtrees subtree_dn_list
Spécifie la liste des sous-arbres contenant les principaux d'un domaine. La liste contient les DN des objets sous-arbre séparés par deux-points (:). Cette liste remplace la liste existante.
-sscope search_scope
Spécifie la portée de recherche des principaux sous les sous-arbres. Les valeurs possibles sont 1 ou one (un seul niveau), 2 ou sub (sous-arbres).
-containerref container_reference_dn Spécifie le DN de l'objet
conteneur dans lequel les principaux d'un domaine seront créés.
-maxtktlife max_ticket_life
(chaîne getdate) Spécifie la durée de vie maximale des tickets pour les principaux de ce domaine.
-maxrenewlife max_renewable_ticket_life
(chaîne getdate) Spécifie la durée de renouvellement maximale des tickets pour les principaux de ce domaine.
ticket_flags
Spécifie les indicateurs de ticket globaux pour le domaine. Les indicateurs autorisés sont documentés dans la description de la commande add_principal dans kadmin(1).

Exemple :

shell% kdb5_ldap_util -r ATHENA.MIT.EDU -D cn=admin,o=org -H
    ldaps://ldap-server1.mit.edu modify +requires_preauth
Mot de passe pour "cn=admin,o=org" :
shell%

stashsrvpw

stashsrvpw [-f nom_de_fichier] nom

Permet à un administrateur de stocker le mot de passe de l'objet service dans un fichier afin que KDC et le serveur d'administration puissent l'utiliser pour s'authentifier auprès du serveur LDAP. Options :

-f nom_de_fichier
Spécifie le chemin complet du fichier de mot de passe du service. Par défaut, /usr/local/var/service_passwd est utilisé.
nom
Spécifie le nom de l'objet dont le mot de passe doit être stocké. Si krb5kdc(8) ou kadmind(8) est configuré pour la liaison simple, il s'agira du nom distinctif qu'il utilisera, tel que donné par la variable ldap_kdc_dn ou ldap_kadmind_dn dans kdc.conf(5). Si le KDC ou kadmind est configuré pour la liaison SASL, il s'agira du nom d'authentification qu'il utilisera, tel que donné par la variable ldap_kdc_sasl_authcid ou ldap_kadmind_sasl_authcid.

Exemple :

kdb5_ldap_util stashsrvpw -f /home/andrew/conf_keyfile
    cn=service-kdc,o=org

create_policy

create_policy [-maxtktlife durée_max_ticket] [-maxrenewlife durée_max_ticket_renouvelable] [indicateurs_ticket] nom_politique

Crée une politique de ticket dans le répertoire. Options :

-maxtktlife durée_max_ticket
(chaîne getdate) Spécifie la durée maximale des tickets pour les principaux.
-maxrenewlife durée_max_ticket_renouvelable
(chaîne getdate) Spécifie la durée maximale de renouvellement des tickets pour les principaux.
indicateurs_ticket
Spécifie les indicateurs de ticket. Si cette option n'est pas spécifiée, par défaut, aucune restriction ne sera définie par la politique. Les indicateurs autorisés sont documentés dans la description de la commande add_principal dans kadmin(1).
nom_politique
Spécifie le nom de la politique de ticket.

Exemple :

kdb5_ldap_util -D cn=admin,o=org -H ldaps://ldap-server1.mit.edu
    -r ATHENA.MIT.EDU create_policy -maxtktlife "1 jour"
    -maxrenewlife "1 semaine" -allow_postdated +needchange
    -allow_forwardable tktpolicy
Mot de passe pour « cn=admin,o=org » :

modify_policy

modify_policy [-maxtktlife durée_max_ticket] [-maxrenewlife durée_max_ticket_renouvelable] [indicateurs_ticket] nom_politique

Modifie les attributs d'une politique de ticket. Les options sont les mêmes que pour create_policy.

Exemple :

kdb5_ldap_util -D cn=admin,o=org -H
    ldaps://ldap-server1.mit.edu -r ATHENA.MIT.EDU modify_policy
    -maxtktlife "60 minutes" -maxrenewlife "10 heures"
    +allow_postdated -requires_preauth tktpolicy
Mot de passe pour « cn=admin,o=org » :

destroy_policy

destroy_policy [-force] nom_politique

Détruit une politique de ticket existante. Options :

-force

nom_politique
Spécifie le nom de la politique de ticket.

Exemple :

    -r ATHENA.MIT.EDU destroy_policy tktpolicy
