NOM

kea-ctrl-agent - Agent de contrôle dans Kea

SYNOPIS

kea-ctrl-agent [-v] [-V] [-W] [-d] [-c fichier-config] [-t fichier-config]

DESCRIPTION

Le kea-ctrl-agent fournit un service REST pour contrôler les services Kea. Les requêtes HTTP reçues sont décapsulées et transmises aux services Kea respectifs au format JSON. Les réponses JSON reçues sont encapsulées dans des réponses HTTP et renvoyées à l'entité de contrôle. Certaines commandes peuvent être traitées directement par l'Agent de contrôle, sans être transmises à aucun service Kea.

ARGUMENTS

Les arguments sont les suivants :

-v
Affiche la version.
-V
Affiche la version étendue.
-W
Affiche le rapport de configuration.
-d
Définit le niveau de journalisation sur débogage avec une verbosité supplémentaire. Ceci est principalement destiné au développement en mode autonome.
-c fichier-config
Spécifie le fichier contenant la configuration du serveur Control Agent. Il peut également contenir des entrées de configuration pour d'autres services Kea.
-t fichier-config
Vérifie la syntaxe du fichier de configuration et signale la première erreur, le cas échéant. Notez que tous les paramètres ne sont pas entièrement vérifiés ; en particulier, les sockets de service et de client ne sont pas ouverts, et les bibliothèques de hooks ne sont pas chargées.

DOCUMENTATION

Kea est livré avec un manuel de référence complet de l'administrateur Kea qui couvre tous les aspects de l'exécution du logiciel Kea - compilation, installation, configuration, exemples de configuration, et bien plus encore. Kea propose également un manuel des messages Kea, qui répertorie tous les messages possibles que Kea peut imprimer avec une brève description pour chacun d'eux. Ces deux documents sont disponibles dans divers formats (.txt, .html, .pdf) avec la distribution Kea. La documentation Kea est disponible sur https://kea.readthedocs.io.

Le code source de Kea est documenté dans le guide du développeur Kea, disponible sur https://reports.kea.isc.org/dev_guide/.

Le site web du projet Kea est disponible sur https://kea.isc.org.

LISTES DE DIFFUSION ET SUPPORT

Il existe deux listes de diffusion publiques disponibles pour le projet Kea. kea-users (kea-users at lists.isc.org) est destinée aux utilisateurs de Kea, tandis que kea-dev (kea-dev at lists.isc.org) est destinée aux développeurs de Kea, aux contributeurs potentiels et aux autres utilisateurs avancés. Les deux listes sont disponibles sur https://lists.isc.org. La communauté offre un support au mieux de ses capacités sur ces deux listes.

ISC fournit un support professionnel pour les services Kea. Voir https://www.isc.org/kea/ pour plus de détails.

HISTORIQUE

Le kea-ctrl-agent a été codé pour la première fois en décembre 2016 par Marcin Siodelski.
