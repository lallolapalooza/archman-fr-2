NOM

kubeadm join phase control-plane-join - Joindre une machine en tant qu'instance de plan de contrôle

SYNOPSIS

kubeadm join phase control-plane-join [OPTIONS]

DESCRIPTION

Joindre une machine en tant qu'instance de plan de contrôle

OPTIONS HÉRITÉES DES COMMANDESPARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à effectuer un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

EXEMPLE

  # Joint une machine en tant qu'instance de plan de contrôle
  kubeadm join phase control-plane-join all

VOIR AUSSI

kubeadm-join-phase(1), kubeadm-join-phase-control-plane-join-all(1), kubeadm-join-phase-control-plane-join-etcd(1), kubeadm-join-phase-control-plane-join-mark-control-plane(1),
