NOM

kcprototest - interface de ligne de commande pour tester la base de données prototype

DESCRIPTION

La commande `kcprototest' est un utilitaire pour le test de fonctionnalité et le test de performance de la base de données prototype. Cette commande est utilisée dans le format suivant. `rnum' spécifie le nombre d'itérations.


kcprototest order [-tree] [-th num] [-rnd] [-etc] [-tran] rnum
Effectue des tests en ordre.
kcprototest queue [-tree] [-th num] [-it num] [-rnd] rnum
Effectue des opérations de file d'attente.
kcprototest wicked [-tree] [-th num] [-it num] rnum
Effectue des opérations mixtes sélectionnées aléatoirement.
kcprototest tran [-tree] [-th num] [-it num] rnum
Effectue le test de transaction.

Les options comprennent ce qui suit.

-tree : teste la base de données arborescente prototype au lieu de la base de données de hachage prototype.
-th num : spécifie le nombre de threads de travail.
-rnd : effectue un test aléatoire.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-it num : spécifie le nombre de répétitions.

Cette commande renvoie 0 en cas de succès, autre chose en cas d'échec.
