NOM

kanshi - fichier de configuration

DESCRIPTION

Un fichier de configuration kanshi est une liste de profils. Chaque profil a un nom optionnel et contient des directives de profil délimitées par des crochets ({ et }).

Exemple :

include /etc/kanshi/config.d/*
profile {
	output LVDS-1 disable
	output "Some Company ASDF 4242" {
		mode 1600x900
		position 0,0
	}
}
profile nomad {
	output LVDS-1 enable scale 2
}

DIRECTIVES

profile [<nom>] { <directives de profil...> }

Définit un nouveau profil en utilisant les directives de profil spécifiées délimitées par des crochets. Un nom peut être spécifié mais est optionnel.

output <critères> <directive de sortie...>

Définit les valeurs par défaut pour les directives de sortie à l'intérieur des définitions de profil.

Ces valeurs par défaut ne s'appliquent que lorsque la sortie respective est mentionnée dans un profil spécifique. Par exemple, les deux profils suivants sont équivalents :

output eDP-1 scale 2
profile manual {
	output eDP-1 scale 2
}
profile uses-defaults {
	output eDP-1
}

Les directives de sortie peuvent également être spécifiées dans un bloc délimité par des crochets.

include <chemin>

Inclut un autre fichier à partir de chemin. Développe la syntaxe shell (voir wordexp(3) pour plus de détails).

DIRECTIVES DE PROFIL

Les directives de profil sont suivies d'arguments séparés par des espaces. Les arguments peuvent être mis entre guillemets (avec ") s'ils contiennent des espaces.

output <critères> <directive de sortie...>

Une directive de sortie ajoute une sortie au profil.

Les critères peuvent être l'un des suivants :

  • Un nom de sortie (par exemple, "DP-1"). Notez que les noms de sortie peuvent ne pas être stables : ils peuvent changer entre les redémarrages (en fonction de l'ordre de détection du pilote du noyau) ou l'ordre de création (typiquement pour les docks USB-C).
  • Une chaîne de caractères séparée par des espaces contenant le fabricant, le modèle et le numéro de série de la sortie (par exemple, "Foocorp ASDF 1234"). Un motif joker peut être utilisé (par exemple, "Foocorp ASDF *"), voir glob(7). Si l'un de ces champs est manquant, il doit être rempli avec la chaîne "Unknown" (par exemple, "Foocorp ASDF Unknown").
  • Un alias de sortie (par exemple, "$work-desk3") défini par une directive d'alias de sortie. Les alias de sortie ne peuvent être utilisés que dans la portée du profil.
  • Un joker "*", pour correspondre à n'importe quelle sortie. Les jokers ne peuvent être utilisés que dans la portée du profil et ne correspondront qu'à une seule sortie.

Les directives de sortie peuvent également être spécifiées dans un bloc délimité par des crochets.

Sur sway(1), les noms et identifiants de sortie peuvent être obtenus via "swaymsg -t get_outputs".

exec <commande>

Une directive exec exécute une commande lorsque le profil a été appliqué avec succès. Ceci peut être utilisé pour mettre à jour l'état du compositeur au profil lorsqu'il n'est pas fait automatiquement.

Les commandes sont exécutées de manière asynchrone et leur ordre peut ne pas être conservé. Si vous devez exécuter des commandes séquentielles, vous devriez les regrouper dans une seule instruction exec ou dans un script séparé.

Sur sway(1) par exemple, exec peut être utilisé pour déplacer des espaces de travail vers la sortie appropriée :

profile multihead {
	output eDP-1 enable
	output DP-1 enable transform 270
	exec swaymsg workspace 1, move workspace to eDP-1
}

Notez qu'il faut prendre des précautions supplémentaires avec les sorties identifiées par une description de sortie car le nom réel peut changer :

profile complex {
	output "Some Other Company GTBZ 2525" mode 1920x1200
	exec swaymsg workspace 1, move workspace to output '"Some Other Company GTBZ 2525"'
}

DIRECTIVES DE SORTIE

enable|disable

Active ou désactive la sortie spécifiée.

mode [--custom] <largeur>x<hauteur>[@<taux>[Hz]]

Configure la sortie spécifiée pour utiliser le mode spécifié. Les modes sont une combinaison de largeur et de hauteur (en pixels) et d'un taux de rafraîchissement (en Hz) que votre écran peut être configuré pour utiliser.

Exemples :

output HDMI-A-1 mode 1920x1080
output HDMI-A-1 mode 1920x1080@60Hz
output HDMI-A-1 mode --custom 1280x720@60Hz

position <x>,<y>

Place la sortie à la position spécifiée dans l'espace de coordonnées global.

Exemple :

output HDMI-A-1 position 1600,0

scale <facteur>

Met à l'échelle la sortie par le facteur d'échelle spécifié.

transform <transform>

Définit la transformation de la sortie. Peut être l'un des "90", "180", "270" pour une rotation ; ou "flipped", "flipped-90", "flipped-180", "flipped-270" pour une rotation et un retournement ; ou "normal" pour aucune transformation.

adaptive_sync on|off

Active ou désactive la synchronisation adaptative (également appelée Taux de Rafraîchissement Variable).

alias $<nom>

Définit un alias pour cette sortie. Les alias de sortie ne peuvent être définis que dans la portée globale.
