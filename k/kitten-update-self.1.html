Nom

kitten-update-self - Mettre à jour ce binaire kitten

Usage

kitten update-self [options]

Description

Met à jour ce binaire kitten sur place vers la dernière version disponible.

Options

--fetch-version [=latest]
La version à télécharger. Les mots spéciaux latest et nightly téléchargent la dernière version stable et la version nocturne respectivement. D'autres valeurs peuvent être, par exemple : 0.44.0.
--help, -h [=no]
Afficher l'aide pour cette commande
3 novembre 2025 0.44.0
