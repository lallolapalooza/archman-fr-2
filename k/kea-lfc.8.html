NOM

kea-lfc - Processus de Nettoyage des Baux dans Kea

SYNTAXE

kea-lfc [-4**|-6**] [-c fichier-config] [-p fichier-pid] [-x fichier-precedent] [-i fichier-copie] [-o fichier-sortie] [-f fichier-fin] [-v] [-V] [-W] [-d] [-h]

DESCRIPTION

Le service kea-lfc supprime les informations redondantes des fichiers utilisés pour fournir un stockage persistant au backend de base de données memfile. Le service est conçu pour s'exécuter comme un processus autonome. Bien qu'il puisse être démarré extérieurement, il n'est généralement pas nécessaire de le faire. Il est exécuté périodiquement par les serveurs DHCP Kea.

ARGUMENTS

Les arguments sont les suivants :

-4 | -6
Indique la version du protocole des fichiers de baux ; doit être soit 4, soit 6.
-c fichier-config
Spécifie le fichier contenant la configuration du processus kea-lfc. Il peut également contenir des entrées de configuration pour d'autres services Kea. Actuellement, kea-lfc obtient tous ses arguments de la ligne de commande.
-p fichier-pid
Spécifie le fichier PID. Lorsque le processus kea-lfc démarre, il tente de déterminer si une autre instance du processus est déjà en cours d'exécution, en examinant le fichier PID. Si une instance est déjà en cours d'exécution, le nouveau processus est terminé. Si aucune instance n'est en cours d'exécution, Kea écrit son PID dans le fichier PID.
-x fichier-precedent
Spécifie le fichier de baux précédent ou ex-baux. Au démarrage de kea-lfc, c'est le résultat de toute exécution précédente de kea-lfc ; à la fin de kea-lfc, c'est le résultat de l'exécution actuelle. Si kea-lfc est interrompu avant d'être terminé, ce fichier peut ne pas exister.
-i fichier-copie
Spécifie le fichier de baux d'entrée ou de copie. Avant que le serveur DHCP n'invoque kea-lfc, il déplace le fichier de baux actuel ici, puis appelle kea-lfc avec ce fichier.
-o fichier-sortie
Spécifie le fichier de baux de sortie, qui est le fichier temporaire que kea-lfc doit utiliser pour écrire les baux. Une fois que ce fichier est entièrement écrit, il est déplacé vers le fichier de fin (voir ci-dessous).
-f fichier-fin
Spécifie le fichier de fin ou d'achèvement, un autre fichier temporaire que kea-lfc utilise pour la tenue de registres. Lorsque kea-lfc a fini d'écrire le fichier de sortie, il le déplace vers ce nom de fichier. Après que kea-lfc ait fini de supprimer les autres fichiers (précédent et entrée), il déplace ce fichier vers le fichier de baux précédent. En déplaçant les fichiers de cette manière, les processus kea-lfc et le serveur DHCP peuvent déterminer le fichier correct à utiliser, même si l'un des processus a été interrompu avant d'avoir terminé sa tâche.
-v
Affiche la version de Kea.
-V
Affiche la version étendue de Kea.
-W
Affiche le rapport de configuration.
-d
Définit le niveau de journalisation sur débogage avec une verbosité supplémentaire. Ceci est principalement destiné au développement en mode autonome.
-h
Affiche la chaîne d'utilisation.

DOCUMENTATION

Kea est livré avec un manuel de référence complet pour les administrateurs Kea qui couvre tous les aspects de l'exécution du logiciel Kea : compilation, installation, configuration, exemples de configuration, et bien plus encore. Kea propose également un manuel des messages Kea, qui liste tous les messages possibles que Kea peut imprimer avec une brève description pour chacun d'eux. Ces deux documents sont disponibles dans différents formats (.txt, .html, .pdf) avec la distribution Kea. La documentation Kea est disponible à l'adresse https://kea.readthedocs.io.

Le code source de Kea est documenté dans le Guide du développeur Kea, disponible à l'adresse https://reports.kea.isc.org/dev_guide/.

Le site web du projet Kea est disponible à l'adresse https://kea.isc.org.

LISTES DE DIFFUSION ET SUPPORT

Il existe deux listes de diffusion publiques pour le projet Kea. kea-users (kea-users at lists.isc.org) est destinée aux utilisateurs de Kea, tandis que kea-dev (kea-dev at lists.isc.org) est destinée aux développeurs de Kea, aux contributeurs potentiels et aux autres utilisateurs avancés. Les deux listes sont disponibles à l'adresse https://lists.isc.org. La communauté offre un support basé sur les meilleurs efforts sur ces deux listes.

ISC fournit un support professionnel pour les services Kea. Voir https://www.isc.org/kea/ pour plus de détails.

HISTORIQUE

Le processus kea-lfc a été codé pour la première fois en janvier 2015 par l'équipe ISC Kea/DHCP.
