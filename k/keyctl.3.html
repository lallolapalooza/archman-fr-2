KEYCTL(3) Appels de gestion de clés Linux KEYCTL(3)

NOM

keyctl_*() - Wrappers pour les fonctions de gestion de clés

DESCRIPTION

L'appel système keyctl() est un multiplexeur pour un certain nombre de fonctions de gestion de clés. Celles-ci doivent être appelées via les wrappers de la bibliothèque libkeyutils.

Les fonctions peuvent être compilées en incluant le fichier d'en-tête keyutils :

#include <keyutils.h>
et en indiquant à l'éditeur de liens qu'il doit lier la bibliothèque :
-lkeyutils
