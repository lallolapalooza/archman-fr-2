kbuffer_read_event(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

kbuffer_read_event, kbuffer_next_event, kbuffer_missed_events, kbuffer_event_size, kbuffer_curr_size, kbuffer_curr_offset, kbuffer_curr_index, kbuffer_read_buffer - Fonctions pour parcourir le sous-tampon kbuffer.

SYNTAXE

#include <kbuffer.h>
void *kbuffer_read_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_next_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_read_at_offset(struct kbuffer *kbuf, int offset, unsigned long long *ts);
int kbuffer_missed_events(struct kbuffer *kbuf);
int kbuffer_event_size(struct kbuffer *kbuf);
int kbuffer_curr_size(struct kbuffer *kbuf);
int kbuffer_curr_offset(struct kbuffer *kbuf);
int kbuffer_curr_index(struct kbuffer *kbuf);
int kbuffer_read_buffer(struct kbuffer *kbuf, void *buffer, int len);

DESCRIPTION

La fonction kbuffer_read_event() lit l'événement suivant dans le descripteur kbuf et si ts n'est pas NULL, y placera son horodatage. Ceci ne modifie pas le descripteur kbuf, et l'appel répété de cette fonction renverra le même résultat.

La fonction kbuffer_next_event() renverra l'événement suivant dans le descripteur kbuf. Elle mettra également ts à l'horodatage de l'événement renvoyé. NULL est renvoyé s'il n'y a plus d'événements et ts sera indéfini. Notez que si cette fonction est appelée directement après un kbuffer_load_subbuffer(), elle donnera probablement un résultat inattendu, car elle renverra le deuxième événement et non le premier. Habituellement, cette fonction est uniquement utilisée pour passer à l'événement suivant et pour savoir s'il y a d'autres événements à lire, et kbuffer_read_event() est toujours appelée en premier.

La fonction kbuffer_read_at_offset() renvoie l'événement situé à un offset donné depuis le début du sous-tampon. Cet offset peut être récupéré par kbuffer_curr_offset(). Si ts pointe vers un unsigned long long, alors il sera défini à l'horodatage de l'événement à l'offset donné.

Si le sous-tampon avait des événements manqués avant lui, alors kbuffer_missed_events() renverra une valeur non nulle. Si elle renvoie -1, cela signifie qu'il y a eu des événements manqués, mais le nombre exact d'événements manqués est inconnu. Si elle renvoie un nombre positif, alors le nombre d'événements manqués est la valeur de retour.

La fonction kbuffer_event_size() renvoie la taille des données de l'événement courant (celui qui serait renvoyé par kbuffer_read_event().

La fonction kbuffer_curr_size() renvoie la taille totale de l'enregistrement de l'événement courant (celui qui serait renvoyé par kbuffer_read_event(). La différence ici est que la valeur de retour inclut la taille des métadonnées de l'enregistrement de l'événement qui ne font pas partie de ce qui est renvoyé par kbuffer_read_event().

La fonction kbuffer_curr_offset() renvoie l'offset depuis le début du sous-tampon où commencent les métadonnées de l'enregistrement de l'événement courant. Le premier événement ne sera pas à l'offset zéro. Cet offset peut être utilisé pour récupérer l'événement avec kbuffer_read_at_offset().

La fonction kbuffer_curr_index() renvoie l'index depuis le début de la portion de données du sous-tampon où se trouvent les métadonnées de l'événement courant. Le premier événement sera probablement zéro, mais pas forcément s'il y a un horodatage qui lui est attaché.

La fonction kbuffer_read_buffer() remplira le buffer fourni à partir du kbuf de la même manière que le noyau effectue un appel système de lecture. C'est-à-dire, si la longueur len est inférieure à la taille du sous-tampon, ou si l'index courant du kbuffer n'est pas nul, elle commencera à copier depuis l'événement courant du kbuf et créera buffer comme un nouveau sous-tampon (avec un horodatage et un en-tête de commit) contenant cet événement trouvé et incluant tous les événements suivants qui peuvent tenir dans len. Le len doit inclure la taille de l'en-tête du sous-tampon ainsi que les événements à inclure. C'est-à-dire, len est la taille allouée de buffer qui peut être remplie. Le retour de cette fonction est l'index de la fin du dernier événement qui a été ajouté. S'il n'y a plus d'événements, zéro est renvoyé, et si le tampon ne peut copier aucun événement parce que len était trop petit, alors -1 est renvoyé.

VALEUR DE RETOUR

kbuffer_read_event() renvoie l'événement sur lequel le descripteur kbuf est actuellement positionné, ou NULL si le dernier événement a été dépassé (par kbuffer_next_event()).

kbuffer_next_event() renvoie l'événement suivant l'événement courant ou NULL s'il n'y a plus d'événements.

kbuffer_read_at_offset() renvoie l'événement à un offset donné depuis le début du sous-tampon stocké dans kbuf, ou NULL s'il n'existe pas d'événement. Notez que l'offset doit seulement être un offset qui tombe sur l'enregistrement, ou est au début de celui-ci. Il n'a pas besoin d'être exactement au début de l'enregistrement.

kbuffer_missed_events() renvoie 0 s'il n'y a pas eu d'événements manqués avant le sous-tampon chargé. Renvoie -1 s'il y a eu un nombre inconnu d'événements manqués, ou si le nombre d'événements manqués est connu, ce nombre sera renvoyé.

kbuffer_event_size() renvoie la taille de la charge utile de données de l'événement courant de kbuf.

kbuffer_curr_size() renvoie la taille de l'enregistrement complet de l'événement courant de kbuf. Cela inclut la taille des métadonnées pour cet enregistrement.

kbuf_curr_offset() renvoie l'offset de l'enregistrement courant par rapport au début du sous-tampon de kbuf.

kbuf_curr_index() renvoie l'index de l'enregistrement courant par rapport au début de la section de données de kbuf.

kbuf_read_buffer() renvoie l'index de la fin du dernier événement qui a été rempli dans buffer. S'il n'y a plus d'événements à copier à partir de start, alors 0 est renvoyé. Si len n'est pas assez grand pour contenir d'événements, alors -1 est renvoyé.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int save_offset = -1;
        int record_size;
        int offset;
        int index;
        int size;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("usage: %s page-sous-tampon-brute\n", argv[0]);
                printf(" Essayez : dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Allocation du tampon");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Lecture du tampon");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Création du kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Chargement du sous-tampon");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer est plus grand que la taille brute %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        ret = kbuffer_missed_events(kbuf);
        if (ret) {
                if (ret > 0)
                        printf("Manqué %d événements avant ce tampon\n", ret);
                else
                        printf("Manqué un nombre inconnu d'événements avant ce tampon\n");
        }
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        record_size = kbuffer_curr_size(kbuf);
                        offset = kbuffer_curr_offset(kbuf);
                        index = kbuffer_curr_index(kbuf);
                        size = kbuffer_event_size(kbuf);
                        if (i == 20)
save_offset = offset; printf(" événement %3d ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n", i++, ts, record_size, size, index, offset); event = kbuffer_next_event(kbuf, NULL); } } while (event); if (!event) printf("Fin du sous-buffer\n"); if (save_offset > 0) { event = kbuffer_read_at_offset(kbuf, save_offset, &ts); if (!event) { fprintf(stderr, "Étrange, impossible de trouver l'événement 20 à l'offset %d\n", save_offset); exit(-1); } record_size = kbuffer_curr_size(kbuf); offset = kbuffer_curr_offset(kbuf); index = kbuffer_curr_index(kbuf); size = kbuffer_event_size(kbuf); printf("\n événement 20 sauvegardé ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n\n", ts, record_size, size, index, offset); } kbuffer_free(kbuf); return 0; }
