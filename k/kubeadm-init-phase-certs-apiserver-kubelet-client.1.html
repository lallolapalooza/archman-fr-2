NOM

kubeadm init phase certs apiserver-kubelet-client - Générer le certificat pour que l'API server se connecte à kubelet

SYNOPSIS

kubeadm init phase certs apiserver-kubelet-client [OPTIONS]

DESCRIPTION

Générer le certificat pour que l'API server se connecte à kubelet, et les sauvegarder dans les fichiers apiserver-kubelet-client.crt et apiserver-kubelet-client.key.

Si les deux fichiers existent déjà, kubeadm saute l'étape de génération et les fichiers existants seront utilisés.

OPTIONS

--cert-dir="/etc/kubernetes/pki" Le chemin où sauvegarder et stocker les certificats.

--config="" Chemin vers un fichier de configuration kubeadm.

--dry-run=false Ne pas appliquer de changements ; afficher seulement ce qui serait fait.

--kubernetes-version="stable-1" Choisir une version spécifique de Kubernetes pour le plan de contrôle.

OPTIONS HERITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à faire un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
