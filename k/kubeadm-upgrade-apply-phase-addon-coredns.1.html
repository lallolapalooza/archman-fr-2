NOM

kubeadm upgrade apply phase addon coredns - Met à jour l'addon CoreDNS

SYNTAXE

kubeadm upgrade apply phase addon coredns [OPTIONS]

DESCRIPTION

Met à jour l'addon CoreDNS

OPTIONS

--config="" Chemin vers un fichier de configuration kubeadm.

--dry-run=false Ne pas modifier l'état, afficher seulement les actions qui seraient effectuées.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'option n'est pas définie, un ensemble d'emplacements standards peut être recherché pour un fichier kubeconfig existant.

--patches="" Chemin vers un répertoire contenant des fichiers nommés "target[suffix][+patchtype].extension". Par exemple, "kube-apiserver0+merge.yaml" ou juste "etcd.json". "target" peut être l'un de "kube-apiserver", "kube-controller-manager", "kube-scheduler", "etcd", "kubeletconfiguration", "corednsdeployment". "patchtype" peut être l'un de "strategic", "merge" ou "json" et ils correspondent aux formats de patch supportés par kubectl. Le "patchtype" par défaut est "strategic". "extension" doit être soit "json" soit "yaml". "suffix" est une chaîne optionnelle qui peut être utilisée pour déterminer quels patchs sont appliqués en premier alphanumériquement.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela forcera kubeadm à faire un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
