NOM

kzonesign - utilitaire de signature de zone DNSSEC

SYNTAXE

kzonesign [option_config] [options] nom_zone

DESCRIPTION

Cet utilitaire lit le fichier de zone, signe la zone conformément à la configuration donnée, et réécrit le fichier de zone signé. Un mode alternatif est la validation DNSSEC de la zone donnée. La signature ou la validation peut s'exécuter en parallèle si elle est activée dans la configuration (voir policy.signing-threads et zone.adjust-threads).

Paramètres

nom_zone
Nom de la zone à signer.

Options de configuration

-c, --config fichier
Utiliser un fichier de configuration textuel (par défaut : /etc/knot/knot.conf).
-C, --confdb répertoire
Utiliser un répertoire de base de données de configuration binaire (par défaut : /var/lib/knot/confdb). La base de données de configuration par défaut, si elle existe, a la préférence sur le fichier de configuration par défaut.

Options

-o, --outdir nom_répertoire
Écrire le fichier de zone de sortie dans le répertoire spécifié au lieu de celui configuré.
-r, --rollover
Autoriser les changements de clés (rollovers) et le re-salage de NSEC3. Pour terminer la soumission possible de KSK, définissez l'horodatage actif du KSK à maintenant (+0) en utilisant keymgr.
-v, --verify
Au lieu de (re-)signer la zone, simplement vérifier que la zone est correctement signée.
-t, --time horodatage
Signer/vérifier la zone (et changer les clés si nécessaire) comme si elle était à l'heure spécifiée par l'horodatage.
-h, --help
Afficher l'aide du programme.
-V, --version
Afficher la version du programme. L'option -VV permet au programme d'afficher le résumé de la configuration à la compilation.

VALEURS DE RETOUR

Le statut de sortie 0 signifie une opération réussie. Tout autre statut de sortie indique une erreur.

VOIR AUSSI

knot.conf(5), keymgr(8).
