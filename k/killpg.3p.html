KILLPG(3P) Manuel du programmeur POSIX KILLPG(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

killpg — envoyer un signal à un groupe de processus

SYNTAXE

#include <signal.h>
int killpg(pid_t pgrp, int sig);

DESCRIPTION

La fonction killpg() envoie le signal spécifié par sig au groupe de processus spécifié par pgrp.

Si pgrp est supérieur à 1, killpg(pgrp, sig) est équivalent à kill(-pgrp, sig). Si pgrp est inférieur ou égal à 1, le comportement de killpg() est indéfini.

VALEUR DE RETOUR

Voir kill().

ERREURS

Voir kill().

EXEMPLES

Envoi d'un signal aux autres membres d'un groupe de processus

L'exemple suivant montre comment le processus appelant pourrait envoyer un signal à tous les autres membres de son groupe de processus. Pour éviter de recevoir lui-même le signal, il se rend d'abord immunisé contre le signal en l'ignorant.

#include <signal.h>
#include <unistd.h>
...
    if (signal(SIGUSR1, SIG_IGN) == SIG_ERR)
        /* Gérer l'erreur */;
    if (killpg(getpgrp(), SIGUSR1) == -1)
        /* Gérer l'erreur */;
