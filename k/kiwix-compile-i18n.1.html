KIWIX-COMPILE-I18N(1) Commandes utilisateur KIWIX-COMPILE-I18N(1)

NOM

kiwix-compile-i18n - utilitaire pour compiler les données i18n (internationalisation) de Kiwix

SYNTAXE

kiwix-compile-i18n [-h] --cxxfile FICHIERCXX fichiers_ressources_i18n ...

DESCRIPTION

fichiers_ressources_i18n ...
La liste des ressources i18n à compiler.
-h, --help
afficher un message d'aide et quitter
--cxxfile FICHIERCXX
Le nom du fichier Cpp à générer
