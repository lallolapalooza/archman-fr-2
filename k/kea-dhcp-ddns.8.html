NOM

kea-dhcp-ddns - Processus DHCP-DDNS dans Kea

SYNTAXE

kea-dhcp-ddns [-v] [-V] [-W] [-d] [-c fichier-config] [-t fichier-config]

DESCRIPTION

Le service kea-dhcp-ddns traite les requêtes de mise à jour de mappage DNS basées sur les événements de changement de bail DHCP. Il s'exécute en tant que processus distinct qui s'attend à recevoir des Requêtes de Changement de Nom des serveurs DHCP Kea.

ARGUMENTS

Les arguments sont les suivants :

-v
Affiche la version.
-V
Affiche la version étendue.
-W
Affiche le rapport de configuration.
-d
Définit le niveau de journalisation sur débogage avec une verbosité supplémentaire. Ceci est principalement destiné au développement en mode autonome.
-c fichier-config
Spécifie le fichier de configuration contenant la configuration du serveur DHCP-DDNS. Il peut également contenir des entrées de configuration pour d'autres services Kea.
-t fichier-config
Vérifie la syntaxe du fichier de configuration et signale la première erreur, le cas échéant. Notez que tous les paramètres ne sont pas entièrement vérifiés ; en particulier, un socket de service n'est pas ouvert.

DOCUMENTATION

Kea est livré avec un manuel de référence complet pour administrateurs Kea (Kea Administrator Reference Manual) qui couvre tous les aspects de l'exécution du logiciel Kea - compilation, installation, configuration, exemples de configuration, et bien plus encore. Kea propose également un manuel des messages Kea (Kea Messages Manual), qui liste tous les messages possibles que Kea peut imprimer avec une brève description pour chacun d'eux. Ces deux documents sont disponibles dans divers formats (.txt, .html, .pdf) avec la distribution Kea. La documentation Kea est disponible sur https://kea.readthedocs.io.

Le code source de Kea est documenté dans le guide du développeur Kea (Kea Developer's Guide), disponible sur https://reports.kea.isc.org/dev_guide/.

Le site web du projet Kea est disponible sur https://kea.isc.org.

LISTES DE DIFFUSION ET SUPPORT

Il existe deux listes de diffusion publiques disponibles pour le projet Kea. kea-users (kea-users at lists.isc.org) est destinée aux utilisateurs de Kea, tandis que kea-dev (kea-dev at lists.isc.org) est destinée aux développeurs Kea, aux contributeurs potentiels et à d'autres utilisateurs avancés. Les deux listes sont disponibles sur https://lists.isc.org. La communauté fournit un support au mieux de ses capacités sur ces deux listes.

ISC fournit un support professionnel pour les services Kea. Voir https://www.isc.org/kea/ pour plus d'informations.

HISTORIQUE

Le processus b10-dhcp-ddns a été codé pour la première fois en mai 2013 par Thomas Markwalder.

Kea est devenu un serveur autonome et le framework BIND 10 a été supprimé. L'exécutable du serveur DHCP-DDNS a été renommé en kea-dhcp-ddns en juillet 2014. Kea 1.0.0 est sorti en décembre 2015.
