KUPFER(1) Manuel des commandes générales KUPFER(1)

NOM

kupfer - Outil d'accès et de commande pratique pour les applications et les documents

SYNTAXE

kupfer [ OPTIONS | FICHIER ... ]
kupfer-exec FICHIER ...

DESCRIPTION

Kupfer est une interface pour un accès rapide et pratique aux applications et à leurs documents.

L'utilisation la plus courante consiste à trouver une application spécifique et à la lancer. Nous avons essayé de rendre Kupfer facile à étendre avec des plugins afin que ce paradigme d'accès rapide puisse être étendu à bien plus d'objets que les seules applications.

kupfer-exec est un script d'aide qui peut exécuter des commandes enregistrées dans un fichier, mais uniquement en se connectant à une instance déjà en cours d'exécution de Kupfer.

LANCEMENT

Lancer kupfer en ligne de commande (sans options) tentera d'afficher le programme s'il est déjà en cours d'exécution.

Kupfer peut être invoqué avec une liste de fichiers

kupfer FICHIER ...

Les chemins des fichiers seront envoyés et sélectionnés dans une instance déjà en cours d'exécution du programme.

Vous pouvez également envoyer du texte via un pipe à kupfer pour le transmettre à une instance en cours d'exécution.

OPTIONS

--no-splash
Lancer sans présenter l'interface principale
--debug
Activer une sortie plus verbeuse qui peut aider à comprendre le fonctionnement du programme.
--list-plugins
Lister tous les plugins installés par leur identifiant, leur version et leur description.

Les options suivantes sont à usage interne

--exec-helper=HELPER
Exécuter le programme d'aide de plugin, qui devrait être le nom d'un module à l'intérieur de kupfer.

Les options génériques suivantes sont disponibles

--help
Afficher les informations d'utilisation
--version
Afficher les informations de version

CONFIGURATION

Les plugins personnalisés sont ajoutés à kupfer en les installant dans le répertoire ~/.local/share/kupfer/plugins, ou dans n'importe quel répertoire kupfer/plugins de $XDG_DATA_DIRS.

VARIABLES D'ENVIRONNEMENT

Si KUPFER_NO_CUSTOM_PLUGINS est défini, autoriser uniquement le chargement des plugins intégrés (installés dans le paquet python du programme).

Si KUPFER_NO_CACHE est défini, ne pas charger ou écrire dans les fichiers de cache source.

Si KUPFER_NO_KEYBINDER est défini, ne pas utiliser Keybinder même s'il est installé.

DÉPANNAGE / BOGUES CONNUS

Wayland

Définir la variable d'environnement GDK_BACKEND à x11 résout le problème de mauvaise position de fenêtre.

Certains plugins (par exemple Windows) ne fonctionnent pas en raison du manque de support de la bibliothèque Wnck.
