NOM

kubectl uncordon - Marquer un nœud comme planifiable

SYNTAXE

kubectl uncordon [OPTIONS]

DESCRIPTION

Marquer un nœud comme planifiable.

OPTIONS

--dry-run="none" Doit être "none", "server", ou "client". Si la stratégie est client, affiche seulement l'objet qui serait envoyé, sans l'envoyer. Si la stratégie est serveur, soumet une requête côté serveur sans persister la ressource.

-l, --selector="" Sélecteur (requête d'étiquette) pour filtrer, supporte '=', '==', '!=', 'in', 'notin'. (par ex. -l clé1=valeur1,clé2=valeur2,clé3 in (valeur3)). Les objets correspondants doivent satisfaire toutes les contraintes d'étiquette spécifiées.

OPTIONS HERITEES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce flag peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes vers le serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la feature gate KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, l'espace de noms pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" La durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par ex. 1s, 2m, 3h). Une valeur nulle signifie pas de timeout pour les requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton Bearer pour l'authentification auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Marquer le nœud "foo" comme planifiable
  kubectl uncordon foo
