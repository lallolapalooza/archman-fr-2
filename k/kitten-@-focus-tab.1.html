Nom

kitten-@-focus-tab - Focalise l'onglet spécifié

Utilisation

kitten @ focus-tab

Description

La fenêtre active de l'onglet spécifié sera focalisée.

Options

--match, -m
L'onglet à faire correspondre. Les spécifications de correspondance sont du type : champ:requête. Où champ peut être l'un des éléments suivants : id, index, title, window_id, window_title, pid, cwd, cmdline env, var, state, session et recent. requête est l'expression à faire correspondre. Les expressions peuvent être un nombre ou une expression régulière, et peuvent être combinées à l'aide d'opérateurs booléens.

La valeur spéciale all correspond à tous les onglets.

Pour les champs numériques : id, index, window_id, pid et recent, l'expression est interprétée comme un nombre, et non comme une expression régulière. Les valeurs négatives pour id/window_id correspondent à partir du nombre d'id le plus élevé vers le bas, en particulier, -1 est l'onglet/la fenêtre créée le plus récemment.

Lors de l'utilisation de title ou id, une correspondance d'onglet est d'abord recherchée, et si aucune n'est trouvée, une correspondance de fenêtre est recherchée, et l'onglet de cette fenêtre est utilisé.

Vous pouvez également utiliser window_id et window_title pour faire correspondre l'onglet qui contient la fenêtre avec l'id ou le titre spécifié.

Le numéro d'index est utilisé pour faire correspondre le n-ième onglet dans la fenêtre système active. Le numéro recent correspond aux onglets récemment actifs dans la fenêtre système active, zéro étant l'onglet actif, un l'onglet précédemment actif, etc.

Le champ session correspond aux onglets créés dans la session spécifiée. Utilisez l'expression ^$ pour faire correspondre les fenêtres qui n'ont pas été créées dans une session et . pour faire correspondre la session active et ~ pour faire correspondre soit la session active, soit la dernière session active lorsqu'aucune session n'est active.

Lors de l'utilisation du champ env pour faire correspondre des variables d'environnement, vous pouvez spécifier uniquement le nom de la variable d'environnement ou un nom et une valeur, par exemple, env:MY_ENV_VAR=2. Les onglets contenant toute fenêtre avec les variables d'environnement spécifiées sont correspondants. De même, var correspond aux onglets contenant toute fenêtre avec la variable utilisateur spécifiée.

Le champ state correspond à l'état de l'onglet. Les états pris en charge sont : active, focused, needs_attention, parent_active, parent_focused et focused_os_window. Les onglets actifs sont les onglets qui sont actifs dans leur fenêtre système parente. Il n'y a qu'un seul onglet focalisé et c'est l'onglet auquel les événements clavier sont délivrés. Si aucun onglet n'est focalisé, le dernier onglet focalisé est correspondant. La valeur focused_os_window correspond à tous les onglets dans la fenêtre système actuellement focalisée.

Notez que vous pouvez utiliser la commande kitten @ ls pour obtenir une liste des onglets.

--no-response [=no]
N'attendez pas de réponse indiquant le succès de l'action. Notez que l'utilisation de cette option signifie que vous ne serez pas informé des échecs.
--help, -h [=no]
Afficher l'aide pour cette commande

Options globales

--to
Une adresse pour l'instance kitty à contrôler. Correspond à l'adresse fournie à l'instance kitty via l'option --listen-on ou le paramètre listen_on dans kitty.conf. Si elle n'est pas spécifiée, la variable d'environnement KITTY_LISTEN_ON est vérifiée. Si celle-ci n'est pas non plus trouvée, les messages sont envoyés au terminal de contrôle de ce processus, c'est-à-dire qu'ils ne fonctionneront que si ce processus est exécuté dans une fenêtre kitty.
--password
Un mot de passe à utiliser lors du contact avec kitty. Cela amènera kitty à demander la permission à l'utilisateur d'effectuer l'action spécifiée, à moins que le mot de passe n'ait été accepté auparavant ou ne soit pré-configuré dans kitty.conf. Pour utiliser un mot de passe vide, spécifiez --use-password comme toujours.
--password-file [=rc-pass]
Un fichier à partir duquel lire le mot de passe. Les espaces blancs de fin sont ignorés. Les chemins relatifs sont résolus à partir du répertoire de configuration de kitty. Utilisez - pour lire depuis STDIN. Utilisez fd:num pour lire depuis le descripteur de fichier num. Utilisé si aucun --password n'est fourni. Par défaut, vérifie le fichier rc-pass dans le répertoire de configuration de kitty.
--password-env [=KITTY_RC_PASSWORD]
Le nom d'une variable d'environnement à partir de laquelle lire le mot de passe. Utilisé si aucun --password-file n'est fourni. Par défaut, vérifie la variable d'environnement KITTY_RC_PASSWORD.
--use-password [=if-available]
Si aucun mot de passe n'est disponible, kitty enverra généralement la commande de contrôle à distance sans mot de passe. Cette option peut être utilisée pour forcer à toujours ou jamais utiliser le mot de passe fourni. S'il est défini sur always et qu'aucun mot de passe n'est fourni, le mot de passe vide est utilisé.

Choix : if-available, always, never
