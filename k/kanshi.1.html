NOM

kanshi - configuration dynamique des sorties

SYNTAXE

kanshi [options...]

OPTIONS

-h, --help

Affiche le message d'aide et quitte.

-c, --config <config>

Spécifie un fichier de configuration.

-l, --listen-fd <fd>

Écoute sur le descripteur de fichier spécifié pour l'IPC.

DESCRIPTION

kanshi est un démon Wayland qui configure automatiquement les sorties.

kanshi est configuré avec une liste de profils de sortie. Chaque profil contient un ensemble de sorties. Un profil sera activé automatiquement si toutes les sorties spécifiées sont actuellement connectées. Un profil contient la configuration pour chaque sortie.

Si kanshi reçoit un signal SIGHUP, il relira son fichier de configuration.

CONFIGURATION

kanshi lit sa configuration à partir de $XDG_CONFIG_HOME/kanshi/config. Si non définie, $XDG_CONFIG_HOME devient ~/.config par défaut.

Une erreur est générée si aucun fichier de configuration n'est trouvé.

Pour plus d'informations sur le format du fichier de configuration, voir kanshi(5).

AUTEURS

Maintenu par Simon Ser <contact@emersion.fr>, qui est assisté par d'autres contributeurs open-source. Pour plus d'informations sur le développement de kanshi, voir https://gitlab.freedesktop.org/emersion/kanshi.
