NOM

kubeadm init phase kubeconfig kubelet - Génère un fichier kubeconfig pour que le kubelet l'utilise uniquement à des fins d'amorçage du cluster

SYNTAXE

kubeadm init phase kubeconfig kubelet [OPTIONS]

DESCRIPTION

Génère le fichier kubeconfig pour que le kubelet l'utilise et l'enregistre dans le fichier kubelet.conf.

Veuillez noter que cela ne doit être utilisé que pour l'amorçage du cluster. Une fois votre plan de contrôle opérationnel, vous devriez demander tous les identifiants kubelet via l'API CSR.

OPTIONS

--apiserver-advertise-address="" L'adresse IP sur laquelle l'API Server annoncera son écoute. Si non défini, l'interface réseau par défaut sera utilisée.

--apiserver-bind-port=6443 Port sur lequel le serveur API doit se lier.

--cert-dir="/etc/kubernetes/pki" Le chemin où enregistrer et stocker les certificats.

--config="" Chemin vers un fichier de configuration kubeadm.

--control-plane-endpoint="" Spécifie une adresse IP stable ou un nom DNS pour le plan de contrôle.

--dry-run=false N'applique aucune modification ; affiche seulement ce qui serait fait.

--kubeconfig-dir="/etc/kubernetes" Le chemin où enregistrer le fichier kubeconfig.

--kubernetes-version="stable-1" Choisit une version spécifique de Kubernetes pour le plan de contrôle.

--node-name="" Spécifie le nom du nœud.

OPTIONS INHERITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine de l'hôte 'réel'. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée
