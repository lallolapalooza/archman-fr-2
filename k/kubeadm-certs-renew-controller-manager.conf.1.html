NOM

kubeadm certs renew controller-manager.conf - Renouveler le certificat intégré dans le fichier kubeconfig pour le gestionnaire de contrôleur

SYNTAXE

kubeadm certs renew controller-manager.conf [OPTIONS]

DESCRIPTION

Renouveler le certificat intégré dans le fichier kubeconfig pour le gestionnaire de contrôleur.

Les renouvellements s'exécutent sans condition, indépendamment de la date d'expiration du certificat ; les attributs supplémentaires tels que les SAN seront basés sur le fichier/certificats existants, il n'est pas nécessaire de les fournir à nouveau.

Le renouvellement tente par défaut d'utiliser l'autorité de certification dans le PKI local géré par kubeadm ; comme alternative, il est possible d'utiliser l'API de certification K8s pour le renouvellement de certificat, ou en dernier recours, de générer une demande CSR.

Après le renouvellement, afin de rendre les changements effectifs, il est nécessaire de redémarrer les composants du plan de contrôle et éventuellement de redistribuer le certificat renouvelé si le fichier est utilisé ailleurs.

OPTIONS

--cert-dir="/etc/kubernetes/pki" Le chemin où enregistrer les certificats

--config="" Chemin vers un fichier de configuration kubeadm.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standard peut être recherché pour un fichier kubeconfig existant.

OPTIONS HERITEES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
