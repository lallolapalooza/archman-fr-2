NOM

kubeadm upgrade apply phase addon - Mise à jour des modules kubeadm par défaut

SYNTAXE

kubeadm upgrade apply phase addon [OPTIONS]

DESCRIPTION

Mise à jour des modules kubeadm par défaut

OPTIONS HÉRITÉES DES COMMANDES PARENT

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à effectuer un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

VOIR AUSSI

kubeadm-upgrade-apply-phase(1), kubeadm-upgrade-apply-phase-addon-all(1), kubeadm-upgrade-apply-phase-addon-coredns(1), kubeadm-upgrade-apply-phase-addon-kube-proxy(1),

HISTORIQUE

Janvier 2015, Compilé initialement par Eric Paris (eparis at redhat dot com) à partir du matériel source de kubernetes, mais ils ont probablement été générés automatiquement depuis !
