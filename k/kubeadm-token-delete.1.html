NOM

kubeadm token delete - Supprime les jetons de démarrage sur le serveur

SYNTAXE

kubeadm token delete [OPTIONS]

DESCRIPTION

Cette commande supprimera une liste de jetons de démarrage pour vous.

La valeur [token-value] est le jeton complet de la forme "[a-z0-9]{6}.[a-z0-9]{16}" ou l'identifiant du jeton de la forme "[a-z0-9]{6}" à supprimer.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--dry-run=false Si le mode simulation doit être activé ou non

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser pour communiquer avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standards peut être recherché pour un fichier kubeconfig existant.

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à utiliser chroot sur le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée
