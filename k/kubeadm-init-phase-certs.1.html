NOM

kubeadm init phase certs - Génération de certificats

SYNTAXE

kubeadm init phase certs [OPTIONS]

DESCRIPTION

Génération de certificats

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine du système hôte 'réel'. Cela amènera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée
