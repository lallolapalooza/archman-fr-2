NOM

kubectl rollout — Gérer le déploiement d'une ressource

SYNTAXE

kubectl rollout [OPTIONS]

DESCRIPTION

Gère le déploiement d'une ou plusieurs ressources.

Les types de ressources valides incluent :

  • deployments
  • daemonsets
  • statefulsets

OPTIONS HÉRITÉES DES COMMANDES PARENT

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, ce flag peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression de réponse pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Cela peut être désactivé en exportant la porteuse de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la fonctionnalité KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, le scope du namespace pour cette requête CLI

--password="" Mot de passe pour l'authentification basique auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier où écrire le profil

--request-timeout="0" Durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie pas de timeout pour les requêtes.

-s, --server="" Adresse et port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton Bearer pour l'authentification auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification basique auprès du serveur API

--version=false --version, --version=raw imprime les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Revenir au déploiement précédent
  kubectl rollout undo deployment/abc
  # Vérifier l'état du déploiement d'un daemonset
  kubectl rollout status daemonset/foo
  # Redémarrer un déploiement
  kubectl rollout restart deployment/abc
  # Redémarrer les déploiements avec le label 'app=nginx'
  kubectl rollout restart deployment --selector=app=nginx
