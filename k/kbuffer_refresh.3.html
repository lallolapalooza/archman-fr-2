kbuffer_refresh(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

kbuffer_alloc, kbuffer_dup, kbuffer_free, kbuffer_load_subbuffer, kbuffer_subbuffer, kbuffer_refresh, kbuffer_subbuffer_size, kbuffer_start_of_data - Création d'un élément kbuffer pour analyser le tampon circulaire de traçage du noyau Linux

SYNOPIS

#include <kbuffer.h>
enum kbuffer_endian {
        KBUFFER_ENDIAN_BIG,
        KBUFFER_ENDIAN_LITTLE,
        KBUFFER_ENDIAN_SAME_AS_HOST,
};
enum kbuffer_long_size {
        KBUFFER_LSIZE_4,
        KBUFFER_LSIZE_8,
        KBUFFER_LSIZE_SAME_AS_HOST,
};
struct kbuffer;
struct tep_handle;
struct kbuffer *kbuffer_alloc(enum kbuffer_long_size size, enum kbuffer_endian endian);
struct kbuffer *kbuffer_dup(struct kbuffer *kbuf);
void kbuffer_free(struct kbuffer *kbuf);
int kbuffer_load_subbuffer(struct kbuffer *kbuf, void *subbuffer);
int kbuffer_subbuffer_size(struct kbuffer *kbuf);
int kbuffer_refresh(struct kbuffer *kbuf);
int kbuffer_start_of_data(struct kbuffer *kbuf);
void *kbuffer_subbuffer(struct kbuffer *_kbuf);

DESCRIPTION

Ces fonctions créent un descripteur kbuffer qui peut être utilisé pour analyser les sous-tampons bruts du tampon circulaire de traçage du noyau Linux. Le tampon circulaire se trouve dans le répertoire tracefs, et peut être récupéré par tracefs_instance_get_file(3) à l'emplacement per_cpu/cpuX/trace_pipe_raw où X est remplacé par le numéro par CPU du tampon circulaire spécifié. Le tampon circulaire dans le noyau est divisé par CPU, de sorte que le tampon circulaire brut doit également être récupéré par CPU.

kbuffer_alloc() créera un descripteur qui peut être utilisé pour gérer un sous-tampon lu par le tampon circulaire. Le paramètre size indique la taille du mot pour le tampon donné (notez que cela fonctionne à partir de la lecture de données brutes à partir de machines autres que celle qui appelle cette fonction). L' endian indique l'endianness de la machine.

Si endian est défini sur KBUFFER_ENDIAN_SAME_AS_HOST, l'endianness sera définie sur la même que celle de l'hôte, ce qui est utile lorsque l'application lit directement les données du tampon circulaire à partir de la même machine sur laquelle elle s'exécute.

Si size est défini sur KBUFFER_LSIZE_SAME_AS_HOST, si la taille du mot est de 8, il définira le descripteur kbuffer sur une taille longue de 8. Mais si la taille est de 4, il effectuera alors un appel à uname(2), et si le champ machine contient la chaîne "64", il sera défini sur une taille de 8 octets et non 4 octets. Ceci est dû au fait que la taille longue du tampon circulaire dépend du noyau et non de l'espace utilisateur.

La fonction kbuffer_dup() dupliquera une structure kbuffer existante avec une nouvelle structure allouée. Elle aura toutes les propriétés de kbuf passé, y compris le pointage vers le même sous-tampon qui a été chargé dans kbuf. Elle doit être libérée avec kbuffer_free().

La fonction kbuffer_free() libérera les ressources créées par kbuffer_alloc().

kbuffer_load_subbuffer() prendra un subbuffer qui est un blob de données brutes du fichier trace_pipe_raw de tracefs. Le tampon circulaire de traçage Linux est divisé en sous-tampons. Chaque sous-tampon est un segment de données autonome qui contient toutes les informations nécessaires pour séparer les événements individuels et les horodatages. Ce sous-tampon est ce que kbuffer utilise pour parcourir les événements.

kbuffer_subbuffer_size() renvoie l'emplacement de la fin du dernier événement dans le sous-tampon. Elle ne renvoie pas la taille du sous-tampon lui-même.

kbuffer_refresh() doit être utilisée si des écritures supplémentaires ont été effectuées sur le kbuffer chargé, où la taille du kbuffer doit être rafraîchie pour pouvoir lire les nouveaux événements qui ont été écrits depuis le dernier appel à kbuffer_load_subbuffer() sur celui-ci.

Notez qu'aucune barrière de mémoire n'est implémentée avec cette fonction et toute synchronisation avec l'écrivain est sous la responsabilité de l'application.

La fonction kbuffer_start_of_data() renvoie le décalage de l'endroit où commence le chargement réel des données du sous-tampon.

La fonction kbuffer_subbuffer() renvoie un pointeur vers le sous-tampon actuellement chargé. C'est-à-dire le dernier sous-tampon qui a été chargé par kbuffer_load_subbuffer(). Si aucun sous-tampon n'a été chargé, NULL est renvoyé.

VALEUR DE RETOUR

kbuffer_alloc() renvoie un descripteur kbuffer alloué ou NULL en cas d'erreur. Le descripteur renvoyé doit être libéré avec kbuffer_free()

kbuffer_load_subbuffer() renvoie 0 en cas de succès et -1 en cas d'erreur.

kbuffer_subbuffer_size() renvoie l'index sur le sous-tampon où se trouve la fin du dernier événement.

kbuffer_start_of_data() renvoie le décalage de l'endroit où les données commencent sur le sous-tampon chargé dans kbuf.

kbuffer_subbuffer() renvoie le dernier sous-tampon chargé vers kbuf qui a été chargé par kbuffer_load_subbuffer() ou NULL si aucun n'a été chargé.

kbuffer_refresh() renvoie 0 en cas de succès et -1 si kbuf est NULL ou s'il n'a pas de sous-tampon chargé via kbuffer_load_subbuffer().

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("usage: %s raw-subbuffer-page\n", argv[0]);
                printf(" Essayez : dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Allocation du tampon");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Lecture du tampon");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Création de kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Chargement du sous-tampon");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer est plus grand que la taille brute %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        printf("Les données Kbuffer commencent à %d\n", kbuffer_start_of_data(kbuf));
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        printf(" événement %3d ts:%lld\n", i++, ts);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Fin du sous-tampon\n");
        kbuffer_free(kbuf);
        return 0;
}
