NOM

kswitch - change le cache de ticket principal

SYNTAXE

kswitch {-c nomcache|-p principal}

DESCRIPTION

kswitch fait du cache d'identification spécifié le cache primaire pour la collection, si une collection de caches est disponible.

OPTIONS

-c nomcache
Spécifie directement le cache d'identification à rendre primaire.
-p principal
Fait rechercher dans la collection de caches un cache contenant les identifications pour principal. Si un est trouvé, cette collection est rendue primaire.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.

FICHIERS

FICHIER:/tmp/krb5cc_%{uid}
Emplacement par défaut du cache d'identification Kerberos 5
