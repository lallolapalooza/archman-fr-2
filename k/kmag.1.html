KMAG(1) Manuel de l'utilisateur de KMagnifier KMAG(1)

NOM

kmag - Loupe d'écran

SYNTAXE

kmag

DESCRIPTION

kmag, aussi connu sous le nom de KMagnifier, est une loupe d'écran. Vous pouvez utiliser KMagnifier pour agrandir une partie de l'écran comme vous utiliseriez une lentille pour agrandir les petits caractères d'un journal ou une photographie. Cette application est utile pour une variété de personnes : des chercheurs aux artistes, en passant par les concepteurs Web ou les personnes malvoyantes.

VOIR AUSSI

Une documentation utilisateur plus détaillée est disponible à l'adresse help:/kmag (entrez cette URL dans Konqueror, ou exécutez khelpcenter help:/kmag).
