NOM

kpasswd - changer le mot de passe d'un utilisateur Kerberos

SYNOPSIS

kpasswd [principal]

DESCRIPTION

La commande kpasswd est utilisée pour changer le mot de passe d'un principal Kerberos. kpasswd demande d'abord le mot de passe Kerberos actuel, puis demande à l'utilisateur deux fois le nouveau mot de passe, et le mot de passe est changé.

Si le principal est régi par une politique qui spécifie la longueur et/ou le nombre de classes de caractères requis dans le nouveau mot de passe, le nouveau mot de passe doit être conforme à la politique. (Les cinq classes de caractères sont les minuscules, les majuscules, les chiffres, la ponctuation et tous les autres caractères.)

OPTIONS

principal
Change le mot de passe pour le principal Kerberos principal. Sinon, kpasswd utilise le nom de principal d'un ccache existant s'il y en a un ; sinon, le principal est dérivé de l'identité de l'utilisateur qui invoque la commande kpasswd.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.
