kpsetool(1) Manuel des commandes générales kpsetool(1)

NOM

kpsetool - script pour rendre disponibles kpsetool, kpsexpand et kpsepath de style teTeX

SYNTAXE

kpsetool [ OPTIONS... ] COMMANDE

kpsexpand [ OPTIONS... ] CHAÎNE

kpsepath [ OPTIONS... ] TYPEDEPATHE

DESCRIPTION

kpsetool est un script Bourne shell qui rend disponibles kpsetool, kpsexpand et kpsepath de style teTeX. kpsetool utilise le binaire kpsexpand (nouveau) de web2c, donc la syntaxe de kpsexpand est incompatible avec celle de teTeX à partir de la version 0.4.

OPTIONS

-m mode
définit le mode Metafont
-n nomprog
fait semblant d'être nomprog pour kpathsea
-p
agit comme kpsepath(1)
-v
agit comme kpsexpand(1)
-w
agit comme kpsewhich(1)

UTILISATION

TYPEDEPATHE peut être

base
dump mémoire Metafont
bib
source bibliographique BibTeX
bst
fichiers de style BibTeX
cnf
fichiers de configuration d'exécution Kpathsea
dvips_config
fichiers de configuration dvips
dvips_header
fichiers d'en-tête dvips
fmt
dump mémoire TeX
gf
polices bitmap génériques
mem
dump mémoire MetaPost
mf
source Metafont
mfpool
chaînes de programmes Metafont
mp
source MetaPost
mppool
chaînes de programmes MetaPost
mpsupport
fichiers de support MetaPost
pict
autres types de figures
pk
police bitmap compressée
tex
source TeX
texpool
chaînes de programmes TeX
tfm
métriques de police TeX
troff_font
polices troff
vf
police virtuelle
