Nom

kitten-ask - Demande une entrée à l'utilisateur

Utilisation

kitten ask

Description

Demande une entrée à l'utilisateur

Options

--type, -t [=ligne]
Type d'entrée. Par défaut, demande une ligne de texte.

Choix : ligne, choix, fichier, mot de passe, oui/non

--message, -m
Le message à afficher à l'utilisateur. Si non spécifié, un message par défaut est affiché.
--name, -n
Le nom de cette question. Utilisé pour stocker l'historique des réponses précédentes qui peuvent être utilisées pour les complétions et via les raccourcis clavier de readline pour naviguer dans l'historique.
--title, --window-title
Le titre de la fenêtre dans laquelle la question est affichée. Implémenté uniquement pour les types oui/non et choix.
--choice, -c
Un choix pour le type « choix ». Peut être spécifié plusieurs fois. Chaque choix a la syntaxe : « lettre[;couleur]:texte », où texte est le texte du choix et lettre est la touche de sélection. lettre est une seule lettre appartenant à texte. Cette lettre est mise en évidence dans le texte du choix. Il peut y avoir une spécification de couleur optionnelle après la lettre pour indiquer sa couleur. Par exemple : y:Oui et n;rouge:Non
--default, -d
Un choix ou un texte par défaut. S'il n'est pas spécifié, c'est « o » pour le type oui/non, le premier choix pour les choix et vide pour les autres types. Le choix par défaut est sélectionné lorsque l'utilisateur appuie sur la touche Entrée.
--prompt, -p [="> "]
L'invite à utiliser lors de la saisie d'une ligne de texte ou d'un mot de passe.
--unhide-key [=u]
La touche à appuyer pour afficher le texte caché
--hidden-text-placeholder
Le texte dans le message à remplacer par le texte caché. Le texte caché est lu via STDIN.
--help, -h [=non]
Afficher l'aide pour cette commande
