NOM

kea-netconf - Agent NETCONF pour la configuration de Kea

SYNTAXE

kea-netconf [-v] [-V] [-W] [-d] [-c fichier-config] [-t fichier-config]

DESCRIPTION

L'agent kea-netconf fournit une interface YANG/NETCONF pour l'environnement Kea.

ARGUMENTS

Les arguments sont les suivants :

-v
Affiche la version de Kea.
-V
Affiche la version étendue de Kea.
-W
Affiche le rapport de configuration.
-d
Active le mode de débogage avec une verbosité accrue.
-c fichier-config
Spécifie le fichier contenant la configuration de l'agent NETCONF.
-t fichier-config
Vérifie la syntaxe du fichier de configuration et signale la première erreur, le cas échéant. Notez que tous les paramètres ne sont pas entièrement vérifiés ; en particulier, les sockets de service et client ne sont pas ouverts, et les bibliothèques de hooks ne sont pas chargées.

DOCUMENTATION

Kea est livré avec un manuel de référence complet pour l'administrateur de Kea qui couvre tous les aspects de l'exécution du logiciel Kea - compilation, installation, configuration, exemples de configuration, et bien plus encore. Kea propose également un manuel des messages Kea, qui liste tous les messages possibles que Kea peut afficher avec une brève description pour chacun d'eux. Ces deux documents sont disponibles dans divers formats (.txt, .html, .pdf) avec la distribution Kea. La documentation de Kea est disponible à l'adresse https://kea.readthedocs.io.

Le code source de Kea est documenté dans le guide du développeur de Kea, disponible à l'adresse https://reports.kea.isc.org/dev_guide/.

Le site web du projet Kea est disponible à l'adresse https://kea.isc.org.

LISTES DE DIFFUSION ET SUPPORT

Deux listes de diffusion publiques sont disponibles pour le projet Kea. kea-users (kea-users at lists.isc.org) est destinée aux utilisateurs de Kea, tandis que kea-dev (kea-dev at lists.isc.org) est destinée aux développeurs de Kea, aux contributeurs potentiels et à d'autres utilisateurs avancés. Les deux listes sont disponibles à l'adresse https://lists.isc.org. La communauté fournit un support au mieux de ses capacités sur ces deux listes.

ISC fournit un support professionnel pour les services Kea. Voir https://www.isc.org/kea/ pour plus de détails.

HISTORIQUE

Les premiers prototypes de l'implémentation de kea-netconf ont été écrits lors des Hackathons de l'IETF à Berlin, Londres et Montréal. Une implémentation prête pour la production a été commencée en août 2018 par Tomek Mrugalski et Francis Dupont.
