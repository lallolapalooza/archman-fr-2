DESCRIPTIO

N

Ces fonctions créent un descripteur kbuffer qui peut être utilisé pour analyser les sous-tampons bruts du tampon circulaire de traçage du noyau Linux. Le tampon circulaire se trouve dans le répertoire tracefs et peut être récupéré par tracefs_instance_get_file(3) à per_cpu/cpuX/trace_pipe_raw où X est remplacé par le numéro de CPU correspondant du tampon circulaire spécifié. Le tampon circulaire à l'intérieur du noyau est divisé par CPU, de sorte que le tampon circulaire brut doit également être récupéré par

CPU.

La fonction kbuffer_alloc() créera un descripteur qui peut être utilisé pour gérer un sous-tampon lu par le tampon circulaire. Le paramètre size indique la taille de mot pour le tampon donné (notez que cela fonctionne en lisant des données brutes provenant d'autres machines que celle qui appelle cette fonction). Le paramètre endian indique l'endianness de la

machine.

Si endian est défini à KBUFFER_ENDIAN_SAME_AS_HOST, l'endianness sera définie comme étant la même que celle de l'hôte, ce qui est utile lorsque l'application lit les données du tampon circulaire directement depuis la même machine sur laquelle elle

s'exécute.

Si size est défini à KBUFFER_LSIZE_SAME_AS_HOST, si la taille de mot est 8, le descripteur kbuffer sera défini avec une taille longue de 8. Mais si la taille est 4, alors il effectuera un appel uname(2), et si le champ machine contient la chaîne "64", il sera défini à une taille longue de 8 octets et non 4. Cela est dû au fait que la taille longue du tampon circulaire dépend du noyau et non de l'espace

utilisateur.

La fonction kbuffer_dup() dupliquera une structure kbuffer existante avec une nouvelle structure allouée. Elle aura toutes les propriétés du kbuf passé, y compris le pointage vers le même sous-tampon qui a été chargé dans le kbuf. Elle doit être libérée avec kbuffer_fr

ee().

La fonction kbuffer_free() libérera les ressources créées par kbuffer_all

oc().

La fonction kbuffer_load_subbuffer() prendra un sous-tampon qui est un bloc de données brut du fichier tracefs trace_pipe_raw. Le tampon circulaire de traçage de Linux est divisé en sous-tampons. Chaque sous-tampon est un segment de données autonome qui contient toutes les informations nécessaires pour extraire les événements individuels et les horodatages. C'est ce sous-tampons que kbuffer utilise pour parcourir les

événements.

La fonction kbuffer_subbuffer_size() renvoie la position de la fin du dernier événement sur le sous-tampon. Elle ne renvoie pas la taille du sous-tampon

lui-même.

La fonction kbuffer_refresh() doit être utilisée si d'autres écritures ont été effectuées sur le kbuffer chargé et que la taille du kbuffer doit être actualisée pour pouvoir lire les nouveaux événements qui ont été écrits depuis le dernier appel à kbuffer_load_subb

uffer().

Notez qu'aucune barrière mémoire n'est implémentée avec cette fonction et que toute synchronisation avec l'écrivain est de la responsabilité de

l'application.

La fonction kbuffer_start_of_data() renvoie le décalage où commence le chargement effectif des données du

sous-tampon.

La fonction kbuffer_subbuffer() renvoie le pointeur vers le sous-tampon actuellement chargé. C'est-à-dire le dernier sous-tampon chargé par kbuffer_load_subbuffer(). Si aucun sous-ta

mpon n'a été char
gé, NULL est renvoyé.

VALEUR DE

RETOUR

kbuffer_alloc() renvoie un descripteur kbuffer alloué ou NULL en cas d'erreur. Le descripteur renvoyé doit être libéré avec kbuffer_free(

)

kbuffer_load_subbuffer() renvoie 0 en cas de succès et -1 en cas

d'erreur.

kbuffer_subbuffer_size() renvoie l'index sur le sous-tampon où se trouve la fin du dernier

événement.

kbuffer_start_of_data() renvoie le décalage où commencent les données sur le sous-tampon chargé dans kbuf

.

kbuffer_subbuffer() renvoie le dernier sous-tampon chargé dans kbuf, qui a été chargé par kbuffer_load_subbuffer(), ou NULL si aucun n'a été

chargé.

kbuffer_refresh() renvoie 0 en cas de succès et -1 si kbuf est NULL ou s'il n'a pas de sous-tampon chargé via kbuffer_load

_subbuf
fer().

EXEMPL

E 
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("usage: %s raw-subbuffer-page\n", argv[0]);
                printf(" Try: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Allocating buffer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Reading buffer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creating kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Loading sub bufer");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer is bigger than raw size %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        printf("Kbuffer data starts at %d\n", kbuffer_start_of_data(kbuf));
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        printf(" event %3d ts:%lld\n", i++, ts);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Finished sub buffer\n");
        kbuffer_free(kbuf);
        return
0;
}
