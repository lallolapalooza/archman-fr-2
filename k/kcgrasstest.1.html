NOM

kcgrasstest - interface en ligne de commande pour tester la base de données de l'arbre de cache

DESCRIPTION

La commande `kcgrasstest' est un utilitaire pour les tests de fonctionnalité et les tests de performance de la base de données de l'arbre de cache. Cette commande est utilisée dans le format suivant. `rnum' spécifie le nombre d'itérations.


kcgrasstest order [-th num] [-rnd] [-etc] [-tran] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Effectue des tests en ordre.
kcgrasstest queue [-th num] [-it num] [-rnd] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Effectue des opérations de mise en file d'attente.
kcgrasstest wicked [-th num] [-it num] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Effectue des opérations mixtes sélectionnées aléatoirement.
kcgrasstest tran [-th num] [-it num] [-tc] [-bnum num] [-psiz num] [-pccap num] [-rcd|-rcld|-rcdd] [-lv] rnum
Effectue le test de transaction.

Les options comprennent les suivantes.

-th num : spécifie le nombre de threads de travail.
-rnd : effectue un test aléatoire.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-tc : optimise la base de données avec l'option de compression.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-psiz num : spécifie la taille de chaque page.
-pccap num : spécifie la taille de capacité du cache de pages.
-rcd : utilise le comparateur décimal au lieu du lexical.
-rcld : utilise le comparateur lexical descendant au lieu de l'ascendant.
-rcdd : utilise le comparateur décimal descendant au lieu du lexical.
-lv : signale toutes les erreurs.
-it num : spécifie le nombre de répétitions.

Cette commande renvoie 0 en cas de succès, une autre valeur en cas d'échec.
