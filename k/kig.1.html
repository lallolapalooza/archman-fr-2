NOM

kig - Un programme de géométrie interactive de KDE

SYNTAXE

kig [-c, --convert-to-native [-o, --outfile nom_fichier]] [options]

DESCRIPTION

Kig est une application de géométrie interactive. Elle est destinée à servir deux objectifs :

•Permettre aux étudiants d'explorer interactivement des figures et des concepts mathématiques à l'aide de l'ordinateur ;
•Servir d'outil WYSIWYG pour dessiner des figures mathématiques et les inclure dans d'autres documents.

Avec ce programme, vous pouvez faire de la géométrie sur un ordinateur tout comme vous le feriez sur un tableau noir dans une salle de classe. Cependant, le programme vous permet de déplacer et de modifier des parties d'un dessin géométrique afin que vous puissiez voir comment les autres parties changent en conséquence.

Kig prend en charge les lieux et les macros définies par l'utilisateur. Il importe et exporte également des formats de fichiers étrangers, notamment Cabri, Dr. Geo, KGeo, KSeg et XFig.

Cette application fait partie du module de divertissement éducatif officiel de KDE.

OPTIONS

-c, --convert-to-native

Ne pas afficher d'interface graphique. Convertir plutôt le fichier spécifié au format natif Kig. Le fichier Kig natif sera écrit dans la sortie standard sauf si --outfile est passé.

-o, --outfile nom_fichier

Utilisé avec --convert-to-native pour spécifier où enregistrer le nouveau fichier Kig créé. Ne pas spécifier cette option, ou fournir un nom de fichier de - affichera le fichier dans la sortie standard.

VOIR AUSSI

Une documentation utilisateur plus détaillée est disponible à l'adresse help:/kig (entrez cette URL dans Konqueror, ou exécutez khelpcenter help:/kig).

Des informations supplémentaires sont également disponibles sur le **site Web de l'éducation KDE**[1].
