KEYUTILS(7) Gestion de clés du noyau KEYUTILS(7)

NOM

keyutils - utilitaires de gestion de clés dans le noyau

DESCRIPTION

Le paquet keyutils est une bibliothèque et un ensemble d'utilitaires pour accéder à la fonctionnalité keyrings du noyau.

Un fichier d'en-tête est fourni pour définir et déclarer les éléments requis pour accéder à la bibliothèque :

#include <keyutils.h>

Pour lier la bibliothèque, le paramètre suivant :

-lkeyutils

doit être spécifié à l'éditeur de liens.

Trois appels système sont fournis :

add_key(2)
Fournit une nouvelle clé au noyau.
request_key(2)
Trouve une clé existante pour utilisation, ou, optionnellement, en crée une si elle n'existe pas.
keyctl(2)
Contrôle une clé de diverses manières. La bibliothèque fournit une variété de wrappers autour de cet appel système et ceux-ci devraient être utilisés plutôt que de l'appeler directement.

Consultez les pages de manuel add_key(2), request_key(2) et keyctl(2) pour plus d'informations.

Les wrappers de keyctl() sont listés sur la page de manuel keyctl(3).

UTILITAIRES

Un programme est fourni pour interagir avec la fonctionnalité du noyau par un certain nombre de sous-commandes, par ex. :

keyctl add user foo bar @s

Consultez la page de manuel keyctl(1) pour des informations à ce sujet.

Le noyau a la capacité d'appeler l'espace utilisateur pour fabriquer de nouvelles clés. Ceci peut être déclenché par request_key(), mais l'espace utilisateur ferait mieux d'utiliser add_key() à la place si possible.

Le mécanisme d'appel est généralement acheminé via le programme request-key(8). Ce que cela fait avec une clé particulière est configurable dans :

/etc/request-key.conf
/etc/request-key.d/

Consultez les pages de manuel request-key.conf(5) et request-key(8) pour plus d'informations.
