NOM

kubeadm config print reset-defaults - Imprime la configuration de réinitialisation par défaut, utilisable pour 'kubeadm reset'

SYNTAXE

kubeadm config print reset-defaults [OPTIONS]

DESCRIPTION

Cette commande imprime des objets tels que la configuration de réinitialisation par défaut utilisée par 'kubeadm reset'.

Notez que les valeurs sensibles telles que les champs du jeton de démarrage sont remplacés par des valeurs fictives comme "abcdef.0123456789abcdef" afin de passer la validation mais sans effectuer le calcul réel pour créer un jeton.

OPTIONS TRANSMISES DES COMMANDES PARENTES

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'indicateur n'est pas défini, un ensemble d'emplacements standard peut être recherché pour trouver un fichier kubeconfig existant.

--rootfs="" Le chemin vers le système de fichiers root 'réel' de l'hôte. Cela amènera kubeadm à utiliser chroot sur le chemin fourni.

--version=false --version, --version=raw imprime les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée.
