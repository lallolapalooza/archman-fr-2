Nom

kitten-run-shell - Exécute le shell de l'utilisateur avec l'intégration du shell activée

Utilisation

kitten run-shell [options] [commande optionnelle à exécuter avant de lancer le shell ...]

Description

Exécute le shell configuré par l'utilisateur. Si le shell prend en charge l'intégration du shell, celle-ci est activée en fonction du paramètre shell_integration configuré par l'utilisateur.

Options

--shell-integration
Spécifie une valeur pour l'option shell_integration, remplaçant celle de kitty.conf.
--shell [=.]
Spécifie la commande shell à exécuter. La valeur par défaut de . utilisera le shell parent s'il est reconnu, sinon il utilisera la valeur de l'option shell de kitty.conf.
--env
Spécifie une variable d'environnement à définir avant d'exécuter le shell. De la forme CLE=VALEUR. Peut être spécifié plusieurs fois. Si aucun = n'est présent, CLE est désactivé.
--cwd
Le répertoire de travail à utiliser lors de l'exécution du shell.
--inject-self-onto-path [=always]
Ajoute le répertoire contenant ce binaire kitten à PATH. Le répertoire est ajouté seulement s'il n'est pas déjà présent.

Choix : always, never, unless-root
