NOM

kubectl auth whoami - Expérimental : Vérifie les attributs du sujet soi-même

SYNTAXE

kubectl auth whoami [OPTIONS]

DESCRIPTION

Expérimental : Vérifie qui vous êtes et vos attributs (groupes, extra).

    Cette commande est utile pour se familiariser avec les attributs de l'utilisateur courant,
    surtout lorsque l'authentification dynamique, par exemple le webhook de jeton, le proxy d'authentification ou le fournisseur OIDC,
    est activée dans le cluster Kubernetes.

OPTIONS

--allow-missing-template-keys=true Si vrai, ignore toutes les erreurs dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. S'applique uniquement aux formats de sortie golang et jsonpath.

-o, --output="" Format de sortie. L'un des choix suivants : (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--show-managed-fields=false Si vrai, conserve les champs gérés lors de l'impression des objets au format JSON ou YAML.

--template="" Chaîne de modèle ou chemin vers un fichier de modèle à utiliser lorsque -o=go-template, -o=go-template-file. Le format du modèle est celui des modèles golang [http://golang.org/pkg/text/template/#pkg-overview].

OPTIONS HERITEES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur régulier ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactive la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié quant à sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la feature gate KUBECTL_KUBERC=false ou en désactivant la feature KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, l'espace de noms de portée pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. L'un des choix suivants : (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" Durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur nulle signifie pas de délai d'attente pour les requêtes.

-s, --server="" Adresse et port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification Bearer auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traite les avertissements reçus du serveur comme des erreurs et quitte avec un code de sortie non nul

EXEMPLE

  # Obtenez vos attributs de sujet
  kubectl auth whoami
  # Obtenez vos attributs de sujet au format JSON
  kubectl auth whoami -o json
