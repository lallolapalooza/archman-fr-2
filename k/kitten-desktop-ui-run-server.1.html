Nom

kitten-desktop-ui-run-server - Lance les différents serveurs utilisés pour l'intégration avec le bureau Linux

Utilisation

kitten desktop-ui run-server

Description

Ceci doit être exécuté très tôt dans la séquence de démarrage de votre gestionnaire de fenêtres, avant que tout autre programme ne soit lancé.

Options

--override, -o
Surcharge des options de configuration individuelles, peut être spécifié plusieurs fois. Syntaxe : nom=valeur. Par exemple : -o color_scheme=dark
--config, -c
Spécifie un chemin vers le(s) fichier(s) de configuration à utiliser. Tous les fichiers de configuration sont fusionnés avec le fichier intégré desktop-ui-portal.conf, surchargeant les valeurs intégrées. Cette option peut être spécifiée plusieurs fois pour lire plusieurs fichiers de configuration en séquence, qui sont ensuite fusionnés. Utilisez la valeur spéciale NONE pour ne charger aucun fichier de configuration.

Si cette option n'est pas spécifiée, les fichiers de configuration sont recherchés dans l'ordre : $XDG_CONFIG_HOME/kitty/desktop-ui-portal.conf, ~/.config/kitty/desktop-ui-portal.conf, $XDG_CONFIG_DIRS/kitty/desktop-ui-portal.conf. Le premier qui existe est utilisé comme fichier de configuration.

Si la variable d'environnement KITTY_CONFIG_DIRECTORY est spécifiée, ce répertoire est toujours utilisé et la recherche ci-dessus ne se produit pas.

Si /etc/xdg/kitty/desktop-ui-portal.conf existe, il est fusionné avant (c'est-à-dire avec une priorité plus faible) tout fichier de configuration utilisateur. Il peut être utilisé pour spécifier des valeurs par défaut système pour tous les utilisateurs. Vous pouvez utiliser - ou /dev/stdin pour lire la configuration depuis STDIN.
