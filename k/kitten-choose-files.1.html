Nom

kitten-choose-files - Choisir des fichiers, rapidement

Vue d'ensemble

Ajouté dans la version 0.43.0.

Le kitten choose-files est conçu pour vous permettre de sélectionner des fichiers, très rapidement, avec quelques frappes seulement. Il fonctionne comme fzf https://github.com/junegunn/fzf/ et des rechercheurs flous similaires, sauf qu'il est spécialisé dans la recherche de fichiers. À ce titre, il prend en charge des fonctionnalités telles que le filtrage par type de fichier, les icônes de type de fichier, les aperçus de contenu, etc., dès la sortie de la boîte. Il peut être utilisé comme un remplacement direct (mais beaucoup plus efficace et adapté au clavier) des boîtes de dialogue d'ouverture et de sauvegarde de fichiers courantes dans les programmes graphiques. Sous Linux, avec l'aide du kitten desktop-ui <>, vous pouvez même convaincre la plupart des programmes graphiques de votre ordinateur d'utiliser ce kitten au lieu des dialogues de fichiers classiques.

Exécutez-le simplement comme ceci :

kitten choose-files

pour sélectionner un seul fichier dans l'arborescence racine du répertoire de travail actuel. Tapez quelques lettres du nom de fichier et une fois qu'il devient la sélection principale, appuyez sur Entrée. Vous pouvez changer de répertoire en sélectionnant un répertoire et en appuyant sur la touche Tabulation. Maj+Tabulation permet de remonter d'un niveau dans l'arborescence.

Créer des raccourcis vers des répertoires favoris/fréquemment utilisés

Vous pouvez créer des raccourcis clavier pour basculer rapidement vers n'importe quel répertoire dans choose-files.conf. Par exemple :

map ctrl+t cd /tmp
map alt+p  cd ~/my/project

Sélectionner plusieurs fichiers

Lorsque vous souhaitez sélectionner plusieurs fichiers, démarrez le kitten avec --mode=files. Ensuite, au lieu d'appuyer sur Entrée, appuyez sur Maj+Entrée et le fichier sera ajouté à la liste des sélections. Vous pouvez également maintenir la touche Ctrl enfoncée et cliquer sur les fichiers pour les ajouter aux sélections. De même, vous pouvez maintenir la touche Alt enfoncée et cliquer pour sélectionner des plages de fichiers (similaire à l'utilisation de Maj+clic dans une application graphique). Appuyez sur Entrée sur le dernier fichier sélectionné pour terminer. La liste des fichiers sélectionnés s'affiche en bas du kitten et vous pouvez cliquer dessus pour désélectionner un fichier. De même, appuyer sur Maj+Entrée désélectionnera un fichier précédemment sélectionné.

Fichiers cachés et ignorés

Par défaut, le kitten ne traite pas les fichiers et répertoires cachés (dont le nom commence par un point). Cela peut être modifié dans la configuration ainsi qu'à l'exécution via le lien cliquable à droite de la zone de recherche.

De même, le kitten respecte par défaut les fichiers .gitignore et .ignore. Cela peut également être modifié dans la configuration ou à l'exécution. Notez que les fichiers .gitignore ne sont respectés que s'il existe également un répertoire .git. Le kitten prend également en charge le fichier .gitignore global, bien qu'il ne s'applique qu'à l'intérieur des arbres de travail git. Vous pouvez spécifier des motifs d'ignorance globaux, qui s'appliquent partout dans choose-files.conf.

Sélectionner des fichiers inexistants (noms de fichiers d'enregistrement)

Ce kitten peut également être utilisé pour sélectionner des fichiers inexistants, c'est-à-dire un nouveau fichier pour une boîte de dialogue de type "Enregistrer sous" en utilisant --mode=save-file. Une fois que vous avez accédé au répertoire où vous souhaitez que le fichier se trouve (en utilisant la touche Tabulation), appuyez sur Ctrl+Entrée et vous pourrez taper le nom du fichier.

Sélectionner des répertoires

Ce kitten peut également être utilisé pour sélectionner des répertoires, pour une boîte de dialogue de type "Ouvrir un répertoire" en utilisant --mode=dir. Une fois que vous avez accédé au répertoire souhaité, appuyez sur Ctrl+Entrée pour l'accepter. Ou si vous êtes dans un répertoire parent, vous pouvez sélectionner un répertoire descendant en appuyant sur Entrée, de la même manière que vous le feriez pour sélectionner un fichier à ouvrir.

Configuration

Vous pouvez configurer divers aspects du fonctionnement du kitten en créant un fichier choose-files.conf dans votre dossier de configuration kitty <#confloc>. Voir ci-dessous pour les directives de configuration prises en charge.

Balayage du système de fichiers

show_hidden
show_hidden last

Indique s'il faut afficher les fichiers cachés. La valeur par défaut de last signifie se souvenir de la dernière valeur utilisée. Ce paramètre peut être activé/désactivé dans le programme.

sort_by_last_modified
sort_by_last_modified last

Indique s'il faut trier la liste des entrées par date de dernière modification, au lieu du nom. Notez que le tri ne s'applique qu'avant la saisie de toute requête. Une fois qu'une requête est entrée, les entrées sont triées par leur score de correspondance. La valeur par défaut de last signifie se souvenir de la dernière valeur utilisée. Ce paramètre peut être activé/désactivé dans le programme.

respect_ignores
respect_ignores last

Indique s'il faut respecter les fichiers et le paramètre ignore de type .gitignore et .ignore. La valeur par défaut de last signifie se souvenir de la dernière valeur utilisée. Ce paramètre peut être activé/désactivé dans le programme.

ignore

Un motif d'ignorance pour ignorer les fichiers correspondants. Utilise la même syntaxe que les fichiers .gitignore (voir man gitignore). Les motifs ancrés correspondent par rapport au répertoire actuellement affiché. Peut être spécifié plusieurs fois pour utiliser plusieurs motifs. Notez que chaque motif doit être vérifié contre chaque fichier, utilisez donc avec parcimonie.

Apparence

show_preview
show_preview last

Indique s'il faut afficher un aperçu du fichier/répertoire actuel. La valeur par défaut de last signifie se souvenir de la dernière valeur utilisée. Ce paramètre peut être activé/désactivé dans le programme.

pygments_style
pygments_style default

Le schéma de couleurs pygments à utiliser pour la coloration syntaxique des aperçus de fichiers. Voir les styles intégrés de pygments https://pygments.org/styles/ pour une liste des schémas. Cela définit les couleurs utilisées pour les schémas de couleurs clairs, utilisez dark_pygments_style pour changer les couleurs des schémas de couleurs sombres.

dark_pygments_style
dark_pygments_style github-dark

Le schéma de couleurs pygments à utiliser pour la coloration syntaxique avec des couleurs sombres. Voir les styles intégrés de pygments https://pygments.org/styles/ pour une liste des schémas. Cela définit les couleurs utilisées pour les schémas de couleurs sombres, utilisez pygments_style pour changer les couleurs des schémas de couleurs clairs.

cache_size
cache_size 0.5

La taille maximale de t

le cache disque, en gigaoctets, utilisé pour les aperçus. Les valeurs nulles ou négatives signifient aucune limite.

syntax_aliases
syntax_aliases pyj:py pyi:py recipe:py

Alias d'extension de fichier pour la coloration syntaxique. Par exemple, pour colorier syntaxiquement file.xyz comme file.abc, utilisez un réglage de xyz:abc. Plusieurs alias doivent être séparés par des espaces.

Raccourcis clavier

Quit
map esc quit
map ctrl+c quit
Accepter le résultat actuel
map enter accept
Sélectionner le résultat actuel
map shift+enter select

Lors de la sélection de plusieurs fichiers, cela ajoutera le fichier actuel à la liste des fichiers sélectionnés. Vous pouvez également basculer le statut sélectionné d'un fichier en maintenant la touche Ctrl enfoncée et en cliquant dessus. De même, la touche Alt peut être maintenue enfoncée pour cliquer et étendre la plage de fichiers sélectionnés.

Taper le nom du fichier
map ctrl+enter typename

Tapez un nom/chemin de fichier plutôt que de filtrer la liste des fichiers existants. Utile lors de la spécification d'un nom de fichier ou de répertoire pour l'enregistrement qui n'existe pas encore. Lors de la sélection de répertoires existants, le répertoire dont le contenu est actuellement affiché sera accepté comme choix. Ne fonctionne pas lors de la sélection de fichiers à ouvrir plutôt qu'à enregistrer.

Interface de ligne de commande

kitten choose_files [options] [répertoire à partir duquel choisir les fichiers]

Sélectionnez un ou plusieurs fichiers, rapidement, à l'aide de la recherche floue, en tapant seulement quelques caractères du nom du fichier. Parcourez les fichiers correspondants, en utilisant les touches fléchées pour naviguer dans les correspondances et appuyez sur Entrée pour sélectionner. La touche Tab peut être utilisée pour changer de sous-dossier. Voir la documentation en ligne <> pour tous les détails.

Options

--mode <MODE>
Le type d'objet(s) à sélectionner. Par défaut : file. Choix : dir, dirs, file, files, save-dir, save-file, save-files
--file-filter <FILE_FILTER>
Une liste de filtres pour restreindre les fichiers affichés. Peut être des mimetypes ou des motifs de style glob. Peut être spécifié plusieurs fois. La syntaxe est type:expression:Nom descriptif. Par exemple : mime:image/png:Images et mime:image/gif:Images et glob:*.[tT][xX][Tt]:Fichiers texte. Notez que les motifs glob sont sensibles à la casse. La spécification du mimetype est également traitée comme une expression glob, vous pouvez donc, par exemple, utiliser mime:text/* pour correspondre à tous les fichiers texte. Le premier filtre de la liste sera appliqué par défaut. Utilisez un filtre tel que glob:*:Tous pour correspondre à tous les fichiers. Notez que le filtrage ne s'applique qu'aux fichiers, pas aux répertoires.
--suggested-save-file-name <SUGGESTED_SAVE_FILE_NAME>
Un nom suggéré lors de la sélection d'un fichier à enregistrer.
--suggested-save-file-path <SUGGESTED_SAVE_FILE_PATH>
Chemin d'accès à un fichier existant à utiliser comme fichier à enregistrer.
--title <TITLE>
Titre de la fenêtre à utiliser pour ce sélecteur.
--display-title [=no]
Affiche le titre de la fenêtre en haut, utile lorsque ce kitten est utilisé dans une fenêtre de système d'exploitation sans barre de titre.
--override <OVERRIDE>, -o <OVERRIDE>
Remplace les options de configuration individuelles, peut être spécifié plusieurs fois. Syntaxe : nom=valeur.
--config <CONFIG>
Spécifie un chemin vers le(s) fichier(s) de configuration à utiliser. Tous les fichiers de configuration sont fusionnés sur le fichier intégré choose-files.conf, en remplaçant les valeurs intégrées. Cette option peut être spécifiée plusieurs fois pour lire plusieurs fichiers de configuration en séquence, qui sont fusionnés. Utilisez la valeur spéciale NONE pour ne pas charger de fichier de configuration.

Si cette option n'est pas spécifiée, les fichiers de configuration sont recherchés dans l'ordre : $XDG_CONFIG_HOME/kitty/choose-files.conf, ~/.config/kitty/choose-files.conf, $XDG_CONFIG_DIRS/kitty/choose-files.conf. Le premier qui existe est utilisé comme fichier de configuration.

Si la variable d'environnement KITTY_CONFIG_DIRECTORY <#envvar-KITTY_CONFIG_DIRECTORY> est spécifiée, ce répertoire est toujours utilisé et la recherche ci-dessus n'a pas lieu.

Si /etc/xdg/kitty/choose-files.conf existe, il est fusionné avant (c'est-à-dire avec une priorité plus faible) que tout fichier de configuration utilisateur. Il peut être utilisé pour spécifier des valeurs par défaut à l'échelle du système pour tous les utilisateurs. Vous pouvez utiliser soit

kitten-choose-files(1) — Kitty

Name

kitten-choose-files — GUI pour sélectionner des fichiers et des répertoires

Overview

kitten-choose-files est un programme de type "kitten" qui affiche une interface graphique pour sélectionner des fichiers et des répertoires. Il est conçu pour être utilisé dans des scripts ou des flux de travail où une sélection de fichiers interactive est nécessaire.

Creating shortcuts to favorite/frequently used directories

Vous pouvez créer des raccourcis vers vos répertoires favoris ou fréquemment utilisés en utilisant le paramètre --shortcut. Ces raccourcis apparaîtront dans la barre latérale de l'interface, vous permettant de naviguer rapidement vers ces emplacements.

--shortcut <LABEL>:<PATH>
Ajoute un raccourci à la barre latérale. <LABEL> est le texte qui sera affiché pour le raccourci, et <PATH> est le chemin absolu vers le répertoire.

Selecting multiple files

Par défaut, kitten-choose-files permet la sélection de plusieurs fichiers. Vous pouvez sélectionner plusieurs éléments en cliquant dessus tout en maintenant la touche Maj ou Ctrl enfoncée. La sélection de plusieurs fichiers est utile pour les opérations par lots.

Hidden and ignored files

Les fichiers et répertoires cachés (ceux dont le nom commence par un point) sont généralement ignorés par défaut, sauf si l'option --show-hidden est spécifiée. Les fichiers spécifiés dans le fichier de configuration de kitty sous la section [kitten_options] et l'option ignore seront également ignorés.

--show-hidden
Affiche les fichiers et répertoires cachés.

Selecting non-existent files (save file names)

Si l'option --allow-non-existent est activée, vous pourrez sélectionner des noms de fichiers qui n'existent pas encore sur le système de fichiers. Ceci est utile lorsque vous souhaitez que l'utilisateur fournisse un nom de fichier pour un nouveau fichier à créer.

--allow-non-existent
Permet la sélection de noms de fichiers qui n'existent pas encore.

Selecting directories

Par défaut, vous pouvez sélectionner à la fois des fichiers et des répertoires. Si vous souhaitez limiter la sélection uniquement aux répertoires, vous pouvez utiliser l'option --select-dirs.

--select-dirs
Permet uniquement la sélection de répertoires.

Configuration

Le comportement de kitten-choose-files peut être configuré via le fichier de configuration de kitty. Les options pertinentes se trouvent dans la section [kitten_options].

--config-dir <CONFIG_DIR>
Spécifie le répertoire de configuration à utiliser. Si non spécifié, le répertoire de configuration par défaut de kitty sera utilisé.

Utilisez - ou /dev/stdin pour lire la configuration depuis STDIN.

Filesystem scanning

kitten-choose-files peut parcourir le système de fichiers pour afficher les fichiers et répertoires disponibles. L'étendue du balayage peut être limitée ou étendue à l'aide des options de ligne de commande ou de la configuration.

Appearance

L'apparence de l'interface graphique peut être personnalisée via les thèmes et les paramètres de kitty.

Keyboard shortcuts

Des raccourcis clavier sont disponibles pour une navigation et une sélection efficaces. Les raccourcis spécifiques peuvent être personnalisés dans le fichier de configuration de kitty.

Source code for choose_files

Le code source de kitten-choose-files fait partie du projet kitty et est disponible sur le dépôt GitHub de kitty.

Command line interface

L'interface de ligne de commande de kitten-choose-files comprend plusieurs options pour contrôler son comportement et son apparence.

--write-output-to <WRITE_OUTPUT_TO>
Chemin d'accès à un fichier dans lequel la sortie est écrite en plus de STDOUT.
--output-format <OUTPUT_FORMAT>
Le format dans lequel écrire la sortie. Par défaut : text Choix : json, text
--write-pid-to <WRITE_PID_TO>
Chemin d'accès à un fichier dans lequel écrire l'identifiant du processus (PID) de ce processus.
