KDENLIVE_RENDER(1) Programme de rendu pour Kdenlive. KDENLIVE_RENDER(1)

NOM

kdenlive_render - Programme de rendu pour Kdenlive.

SYNTAXE

kdenlive_render [-erase] [in=pos] [out=pos] [render] [profile] [rendermodule] [player] [src] [dest] [[arg1] [arg2] ...]

DESCRIPTION

Programme de rendu pour Kdenlive. Rend les projets kdenlive indépendamment de Kdenlive, tout en fournissant un retour d'information via kuiserver. Ce programme n'est pas destiné à être appelé directement par les utilisateurs, mais est appelé depuis Kdenlive, lorsqu'un processus de rendu est démarré.

OPTIONS

Options :

-erase
Si présent, le fichier source sera effacé après le rendu
in=pos
Démarre le rendu à la position d'image pos
out=pos
Termine le rendu à la position d'image pos
render
Chemin vers le programme de rendu MLT melt
profile
Le profil vidéo MLT
rendermodule
Le consommateur MLT utilisé pour le rendu, généralement avformat
player
Chemin vers le lecteur vidéo à utiliser une fois le rendu terminé, utilisez '-' pour désactiver la lecture
src
Fichier source - généralement une playlist MLT
dest
Fichier de destination
args
Arguments libavformat séparés par des espaces

ENVIRONNEMENT

KDENLIVE_RENDER_LOG
Si $KDENLIVE_RENDER_LOG est défini, un journal sera écrit dans /tmp/kdenlive_render.log.XXXXXXXX, contenant des informations sur le résultat de l'appel de melt, ffmpeg, etc. Ceci peut être utilisé pour le débogage.

VOIR AUSSI

Veuillez consulter la page d'accueil à l'adresse http://www.kdenlive.org/
