KNOTD(8) Serveur DNS Knot KNOTD(8)

NOM

knotd - démon du serveur DNS Knot

SYNTAXE

knotd [option_config] [options]

DESCRIPTION

Knot DNS est un serveur DNS faisant autorité haute performance. Le programme knotd est le démon du serveur DNS.

Options de configuration

-c, --config fichier
Utilise un fichier de configuration textuel (par défaut /etc/knot/knot.conf).
-C, --confdb répertoire
Utilise un répertoire de base de données de configuration binaire (par défaut /var/lib/knot/confdb). La base de données de configuration par défaut, si elle existe, a la préférence sur le fichier de configuration par défaut.

Options

-m, --max-conf-size Mio
Définit la taille maximale de la base de données de configuration (par défaut 500 Mio, maximum 10000 Mio).
-s, --socket chemin
Utilise un chemin de socket UNIX de contrôle à distance (par défaut /run/knot/knot.sock).
-d, --daemonize [répertoire]
Exécute le serveur comme un démon. Un nouveau répertoire racine peut être spécifié (par défaut /).
-v, --verbose
Active la sortie de débogage.
-h, --help
Affiche l'aide du programme.
-V, --version
Affiche la version du programme. L'option -VV permet au programme d'afficher le résumé de la configuration au moment de la compilation.

Signaux

Si le processus knotd reçoit un signal SIGHUP, il recharge sa configuration et rouvre les fichiers journaux, s'ils sont configurés. Lorsque knotd reçoit un signal SIGUSR1, il recharge toutes les zones configurées. Lors de la réception d'un signal SIGINT, knotd se termine.

VALEURS DE RETOUR

Un statut de sortie de 0 signifie une opération réussie. Tout autre statut de sortie indique une erreur.

VOIR AUSSI

knot.conf(5), knotc(8), keymgr(8), kjournalprint(8).
