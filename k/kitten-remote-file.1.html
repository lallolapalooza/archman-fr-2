Nom

kitten-remote-file - Documentation de kitten

Aperçu

kitty a la capacité d'éditer, d'ouvrir ou de télécharger facilement des fichiers depuis un ordinateur auquel vous êtes connecté via SSH. Dans votre session SSH, exécutez :

ls --hyperlink=auto

Maintenez ensuite Ctrl+Shift enfoncés et cliquez sur le nom du fichier.

Actions sur les fichiers distants (images non prises en charge)

kitty vous demandera ce que vous souhaitez faire avec le fichier distant. Vous pouvez choisir de l'éditer, auquel cas kitty le téléchargera et l'ouvrira localement dans votre EDITOR <#envvar-EDITOR>. Lorsque vous apportez des modifications au fichier, elles sont automatiquement transférées vers l'ordinateur distant. Notez que cela se produit sans avoir à installer *aucun* logiciel spécial sur le serveur, au-delà de ls qui prend en charge les hyperliens.

Voir aussi :

Voir la commande edit-in-kitty <#edit-file>

Voir aussi :

Voir le kitten Transfer files <>

Ajouté dans la version 0.19.0.

Note :

Pour de meilleurs résultats, utilisez ce kitten avec le kitten ssh <>. Sinon, les sessions SSH imbriquées ne sont pas prises en charge. Le kitten essaiera toujours de copier les fichiers distants depuis le premier hôte SSH. En effet, sans le kitten ssh, il n'y a aucun moyen pour kitty de détecter et de suivre une session SSH imbriquée de manière robuste. Utilisez le kitten Transfer files <> pour de telles situations.

Note :

Si vous n'avez pas configuré d'accès SSH sans mot de passe automatique, et que vous n'utilisez pas le kitten ssh, alors, lors du début de l'édition, il vous sera demandé d'entrer votre mot de passe une seule fois, puis la connexion SSH sera réutilisée.

De même, vous pouvez choisir de sauvegarder le fichier sur votre ordinateur local, ou de le télécharger et de l'ouvrir avec son gestionnaire de fichiers par défaut.
