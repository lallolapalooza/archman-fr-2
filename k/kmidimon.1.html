KMIDIMON(1) Moniteur MIDI Drumstick KMIDIMON(1)

NOM

kmidimon - Moniteur MIDI Drumstick utilisant le séquenceur ALSA et une interface utilisateur QT

SYNTAXE

kmidimon [ options ] [ fichier ]

DESCRIPTION

Drumstick MIDI Monitor enregistre les événements provenant d'un port MIDI externe ou d'une application via le séquenceur ALSA, ou stockés dans des fichiers Standard MIDI Files (SMF), RIFF MIDI (RMI) ou Cakewalk (WRK). Il est particulièrement utile si vous souhaitez déboguer un logiciel MIDI ou votre configuration MIDI. Il dispose d'une interface utilisateur graphique agréable, de filtres d'événements personnalisables et de paramètres de séquenceur, de la prise en charge de tous les messages MIDI et de certains messages ALSA, et permet d'enregistrer la liste des événements enregistrés dans un fichier texte ou un fichier SMF.

Options générales

--help
Afficher l'aide sur les options
--help-all
Afficher toutes les options
-v,--version
Afficher les informations de version

Options QT

Les options suivantes s'appliquent à toutes les applications Qt5.

-style= style / -style style
Définir le style GUI de l'application. Les valeurs possibles dépendent de la configuration du système. Si Qt est compilé avec des styles supplémentaires ou dispose de styles supplémentaires en tant que plugins, ceux-ci seront disponibles pour l'option de ligne de commande -style.
-stylesheet= stylesheet / -stylesheet stylesheet
Définir la feuille de style de l'application. La valeur doit être un chemin vers un fichier contenant la feuille de style.
-widgetcount
Imprimer un message de débogage à la fin sur le nombre de widgets laissés non détruits et le nombre maximal de widgets existants en même temps.
-reverse
Définir la direction de la mise en page de l'application sur Qt::RightToLeft. Cette option est destinée à faciliter le débogage et ne doit pas être utilisée en production. La valeur par défaut est automatiquement détectée à partir de la locale de l'utilisateur (voir également QLocale::textDirection()).
-platform platformName[:options]
Spécifier le plugin d'abstraction de plateforme Qt (QPA).
-platformpluginpath path
Spécifier le chemin vers les plugins de plateforme.
-platformtheme platformTheme
Spécifier le thème de la plateforme.
-plugin plugin
Spécifier des plugins supplémentaires à charger. L'argument peut apparaître plusieurs fois.
-qwindowgeometry geometry
Spécifier la géométrie de la fenêtre principale en utilisant la syntaxe X11. Par exemple : -qwindowgeometry 100x100+50+50
-qwindowicon icon
Définir l'icône de fenêtre par défaut.
-qwindowtitle title
Définir le titre de la première fenêtre.
-session session
Restaurer l'application à partir d'une session précédente.
-display hostname:screen_number
Changer d'écran sur X11. Remplace la variable d'environnement DISPLAY.
-geometry geometry
Spécifier la géométrie de la fenêtre principale sur X11. Par exemple : -geometry 100x100+50+50
-fontengine= freetype
Utiliser le moteur de polices FreeType.

Arguments

fichier
Nom du fichier SMF/RMI/KAR/WRK d'entrée.
