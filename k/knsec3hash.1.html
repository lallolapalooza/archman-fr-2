NOM

knsec3hash - Utilitaire simple pour calculer le hachage NSEC3

SYNTAXE

knsec3hash sel algorithme itérations nom

knsec3hash algorithme drapeaux itérations sel nom

knsec3hash [-h] [-V]

DESCRIPTION

Cet utilitaire génère un hachage NSEC3 pour un nom de domaine donné et les paramètres du hachage NSEC3.

Paramètres

sel
Spécifie un sel binaire encodé sous forme de chaîne hexadécimale.
algorithme
Spécifie un algorithme de hachage par son numéro. Actuellement, le seul algorithme pris en charge est SHA-1 (numéro 1).
itérations
Spécifie le nombre d'itérations supplémentaires de l'algorithme de hachage.
nom
Spécifie le nom de domaine à hacher.
drapeaux
Spécifie les drapeaux NSEC3 sous forme d'entier non signé.

Options

-h, --help
Affiche l'aide du programme.
-V, --version
Affiche la version du programme. L'option -VV permet au programme d'afficher le résumé de la configuration de compilation.

VALEURS DE RETOUR

Un code de retour de 0 signifie une opération réussie. Tout autre code de retour indique une erreur.

EXEMPLES

knotc(8), knotd(8).
