NOM

kubeadm kubeconfig user - Afficher un fichier kubeconfig pour un utilisateur supplémentaire

SYNTAXE

kubeadm kubeconfig user [OPTIONS]

DESCRIPTION

Afficher un fichier kubeconfig pour un utilisateur supplémentaire.

OPTIONS

--client-name="" Le nom de l'utilisateur. Il sera utilisé comme CN si des certificats client sont créés.

--config="" Chemin vers un fichier de configuration kubeadm.

--org=[] Les organisations du certificat client. Elles seront utilisées comme O si des certificats client sont créés.

--token="" Le jeton qui sera utilisé comme mécanisme d'authentification pour ce kubeconfig, au lieu des certificats client.

--validity-period=8760h0m0s La période de validité du certificat client. C'est un décalage par rapport à l'heure actuelle.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée.

EXEMPLE

  # Afficher un fichier kubeconfig pour un utilisateur supplémentaire nommé foo
  kubeadm kubeconfig user --client-name=foo
  # Afficher un fichier kubeconfig pour un utilisateur supplémentaire nommé foo en utilisant un fichier de configuration kubeadm bar
  kubeadm kubeconfig user --client-name=foo --config=bar
