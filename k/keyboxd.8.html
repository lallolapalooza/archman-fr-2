KEYBOXD(1) Commandes utilisateur KEYBOXD(1)

NOM

keyboxd - Gestion des clés publiques pour GnuPG

SYNTAXE

keyboxd [OPTIONS] [COMMANDE]

DESCRIPTION

keyboxd est un service de gestion des clés publiques pour GnuPG.

COMMANDES

Les commandes ne sont pas distinguées des options, à l'exception du fait qu'une seule commande est autorisée.

--version
Affiche la version du programme et les informations de licence.
--help
Affiche un message d'utilisation résumant les options de ligne de commande les plus utiles.
--server
S'exécute en mode serveur et attend les commandes sur stdin. Le mode par défaut consiste à créer un socket et à y écouter les commandes. Ceci est uniquement utilisé pour les tests.
--daemon
S'exécute en mode démon en arrière-plan et écoute les commandes sur un socket. C'est ainsi que keyboxd est lancé à la demande par les autres composants GnuPG. Pour forcer le lancement de keyboxd, il est généralement préférable d'utiliser gpgconf --launch keyboxd.
--supervised
S'exécute en premier plan, envoie les journaux à stderr, et écoute sur le descripteur de fichier 3, qui doit déjà être lié à un socket d'écoute. Ceci est utile lorsqu'il est exécuté sous systemd ou d'autres schémas de supervision de processus similaires. Cette option n'est pas prise en charge sous Windows.

OPTIONS

Notez que toutes les options longues, à l'exception de --options et --homedir, peuvent également être spécifiées dans le fichier de configuration après suppression des deux tirets initiaux.

--options fichier
Lit la configuration à partir de fichier au lieu du fichier de configuration personnel par défaut. Le fichier de configuration par défaut est nommé ‘keyboxd.conf’ et est attendu dans le répertoire personnel.
--homedir dir
Définit le nom du répertoire personnel à dir. Cette option n'est effective que lorsqu'elle est utilisée en ligne de commande. Le défaut est le répertoire nommé ‘.gnupg’ directement sous le répertoire personnel de l'utilisateur, à moins que la variable d'environnement GNUPGHOME n'ait été définie, auquel cas sa valeur sera utilisée. De nombreux types de données sont stockés dans ce répertoire.
-v
--verbose
Affiche des informations supplémentaires pendant l'exécution. Vous pouvez augmenter la verbosité en donnant plusieurs commandes verbose à keyboxd, telles que -vv.
--log-file fichier
Ajoute toutes les sorties de journalisation à fichier. Ceci est très utile pour voir ce que l'agent fait réellement. Utilisez ‘socket://’ pour journaliser sur un socket.
--debug-level niveau
Sélectionne le niveau de débogage pour enquêter sur les problèmes. niveau peut être une valeur numérique ou un mot-clé :
none
Aucun débogage. Une valeur inférieure à 1 peut être utilisée à la place du mot-clé.
basic
Quelques messages de débogage de base. Une valeur comprise entre 1 et 2 peut être utilisée à la place du mot-clé.
advanced
Messages de débogage plus verbeux. Une valeur comprise entre 3 et 5 peut être utilisée à la place du mot-clé.
expert
Messages encore plus détaillés. Une valeur comprise entre 6 et 8 peut être utilisée à la place du mot-clé.
guru
Tous les messages de débogage que vous pouvez obtenir. Une valeur supérieure à 8 peut être utilisée à la place du mot-clé. La création de fichiers de suivi de hachage n'est activée que si le mot-clé est utilisé.

La manière dont ces messages sont mappés aux indicateurs de débogage réels n'est pas spécifiée et peut changer avec les versions ultérieures de ce programme. Ils sont cependant soigneusement sélectionnés pour aider au mieux au débogage.

--debug flags
Définit les indicateurs de débogage. Cette option n'est utile que pour le débogage et son comportement peut changer avec une nouvelle version. Tous les indicateurs sont combinés par OU et peuvent être donnés en syntaxe C (par exemple, 0x0042) ou sous forme de liste d'indicateurs séparés par des virgules. Pour obtenir une liste de tous les indicateurs pris en charge, le mot seul "help" peut être utilisé.
--debug-all
Identique à --debug=0xffffffff

FICHIERS

Keyboxd utilise un fichier de configuration qui contrôle le fonctionnement de keyboxd. Par défaut, ils peuvent tous se trouver dans le répertoire personnel courant (voir : [option --homedir]).

keyboxd.conf
C'est le fichier de configuration standard lu par keyboxd au démarrage. Il peut contenir n'importe quelle option longue valide ; les deux tirets initiaux ne peuvent pas être saisis et l'option ne peut pas être abrégée. Ce fichier est également lu après un SIGHUP, cependant toutes les options n'auront pas d'effet. Ce nom par défaut peut être modifié en ligne de commande (voir : [option --options]). Vous devriez sauvegarder ce fichier.
pubring.db
Ce fichier est une base de données au format SQLite, pour le matériel des clés publiques. Vous devriez sauvegarder ce fichier.
