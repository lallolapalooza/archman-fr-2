NOM

kubeadm init phase show-join-command - Afficher la commande de jonction pour le nœud de contrôle et le nœud worker

SYNOPIS

kubeadm init phase show-join-command [OPTIONS]

DESCRIPTION

Afficher la commande de jonction pour le nœud de contrôle et le nœud worker

OPTIONS INHERITÉE DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine du système réel. Cela amènera kubeadm à utiliser chroot sur le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

VOIR AUSSI

kubeadm-init-phase(1),
