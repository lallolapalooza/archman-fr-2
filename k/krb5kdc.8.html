NOM

krb5kdc - Kerberos V5 KDC

SYNOPSIS

krb5kdc [-x db_args] [-d dbname] [-k keytype] [-M mkeyname] [-p portnum] [-m] [-r realm] [-n] [-w numworkers] [-P pid_file] [-T time_offset]

DESCRIPTION

krb5kdc est le service d'authentification et le centre de distribution des clés (AS/KDC) de Kerberos version 5.

OPTIONS

L'option -r realm spécifie le realm pour lequel le serveur doit fournir le service. Cette option peut être spécifiée plusieurs fois pour servir plusieurs realms. Si aucune option -r n'est donnée, le realm par défaut (tel que spécifié dans krb5.conf(5)) sera servi.

L'option -d dbname spécifie le nom sous lequel la base de données des principaux peut être trouvée. Cette option ne s'applique pas à la base de données LDAP.

L'option -k keytype spécifie le type de clé de la clé maîtresse à entrer manuellement sous forme de mot de passe lorsque -m est donné ; la valeur par défaut est aes256-cts-hmac-sha1-96.

L'option -M mkeyname spécifie le nom du principal pour la clé maîtresse dans la base de données (généralement K/M dans le realm du KDC).

L'option -m spécifie que le mot de passe de la base de données maîtresse doit être récupéré du clavier plutôt que d'un fichier de stash.

L'option -n spécifie que le KDC ne se met pas en arrière-plan et ne se dissocie pas du terminal.

L'option -P pid_file indique au KDC d'écrire son PID dans pid_file après son démarrage. Ceci peut être utilisé pour identifier si le KDC est toujours en cours d'exécution et pour permettre aux scripts d'initialisation de stopper le processus correct.

L'option -p portnum spécifie les numéros de port UDP et TCP par défaut sur lesquels le KDC doit écouter les requêtes Kerberos version 5, sous forme de liste séparée par des virgules. Cette valeur remplace les numéros de port spécifiés dans la section kdcdefaults de kdc.conf(5), mais peut être remplacée par des valeurs spécifiques au realm. Si aucune valeur n'est donnée par une quelconque source, le port par défaut est 88.

L'option -w numworkers indique au KDC de créer numworkers processus pour écouter les ports KDC et traiter les requêtes en parallèle. Le processus KDC de haut niveau (dont le PID est enregistré dans le fichier PID si l'option -P est également donnée) agit comme un superviseur. Le superviseur relaye les signaux SIGHUP aux sous-processus workers, et termine les sous-processus workers si lui-même est terminé ou si un autre processus worker se termine.

L'option -x db_args spécifie des arguments spécifiques à la base de données. Voir les Options de base de données dans kadmin(1) pour les arguments pris en charge.

L'option -T offset spécifie un décalage horaire, en secondes, sous lequel le KDC fonctionnera. Elle est destinée uniquement à des fins de test.

EXEMPLE

Le KDC peut servir des requêtes pour plusieurs realms (maximum 32 realms). Les realms sont listés sur la ligne de commande. Les options par realm qui peuvent être spécifiées sur la ligne de commande s'appliquent à chaque realm qui les suit et sont remplacées par des définitions ultérieures de la même option.

Par exemple :

krb5kdc -p 2001 -r REALM1 -p 2002 -r REALM2 -r REALM3

spécifie que le KDC écoute sur le port 2001 pour REALM1 et sur le port 2002 pour REALM2 et REALM3. De plus, des paramètres par realm peuvent être spécifiés dans le fichier kdc.conf(5). L'emplacement de ce fichier peut être spécifié par la variable d'environnement KRB5_KDC_PROFILE. Les paramètres par realm spécifiés dans ce fichier ont la priorité sur les options spécifiées sur la ligne de commande. Voir la description de kdc.conf(5) pour plus de détails.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.
