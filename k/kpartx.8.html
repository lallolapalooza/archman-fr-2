KPARTX(8) Manuel du gestionnaire système KPARTX(8)

NOM

kpartx - Créer des mappages de périphériques à partir de tables de partitions.

SYNTAXE

kpartx [-a|-d|-u|-l] [-r] [-p] [-f] [-g] [-s|-n] [-v] disquedur

DESCRIPTION

Cet outil, dérivé de partx de util-linux, lit les tables de partitions sur le périphérique spécifié et crée des mappages de périphériques sur les segments de partitions détectés. Il est appelé par hotplug lors de la création et de la suppression de mappages de périphériques.

OPTIONS

-a
Ajouter des mappages de partitions.
-d
Supprimer des mappages de partitions.
-u
Mettre à jour des mappages de partitions.
-l
Lister les mappages de partitions qui seraient ajoutés par -a.
-r
Mappages de partitions en lecture seule.
-p
Définir le délimiteur nom_de_périphérique-numéro_de_partition.
-f
Forcer la création de mappages ; ignore la fonctionnalité 'no_partitions'.
-g
Forcer la table de partitions GUID (GPT).
-s
Mode synchrone (par défaut). Ne pas retourner tant que les partitions ne sont pas créées.
-n
Mode non synchrone. Retourner avant la création des partitions.
-v
Fonctionner de manière détaillée.

EXEMPLE

Pour monter toutes les partitions dans une image de disque brute :

kpartx -av disk.img

Ceci affichera des lignes telles que :

add map loop1p1 (254:4): 0 409597 linear 7:1 3

loop1p1 est le nom d'un fichier périphérique sous /dev/mapper que vous pouvez utiliser pour accéder à la partition, par exemple pour la vérifier :

fsck /dev/mapper/loop1p1

Lorsque vous avez terminé, vous devez supprimer les périphériques :

kpartx -d disk.img
