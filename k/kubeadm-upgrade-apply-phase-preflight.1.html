NOM

kubeadm upgrade apply phase preflight - Exécute les vérifications préliminaires avant la mise à niveau

SYNTAXE

kubeadm upgrade apply phase preflight [OPTIONS]

DESCRIPTION

Exécute les vérifications préliminaires avant la mise à niveau

OPTIONS

--allow-experimental-upgrades=false Affiche les versions instables de Kubernetes comme alternative de mise à niveau et permet la mise à niveau vers des versions alpha/beta/release candidate de Kubernetes.

--allow-release-candidate-upgrades=false Affiche les versions release candidate de Kubernetes comme alternative de mise à niveau et permet la mise à niveau vers des versions release candidate de Kubernetes.

--config="" Chemin d'accès à un fichier de configuration kubeadm.

--dry-run=false Ne modifie aucun état, affiche seulement les actions qui seraient effectuées.

-f, --force=false Force la mise à niveau même si certains prérequis ne sont pas satisfaits. Ceci implique également un mode non interactif.

--ignore-preflight-errors=[] Une liste de vérifications dont les erreurs seront affichées comme avertissements. Exemple : 'IsPrivilegedUser,Swap'. La valeur 'all' ignore les erreurs de toutes les vérifications.

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'option n'est pas définie, un ensemble d'emplacements standards peut être recherché pour un fichier kubeconfig existant.

-y, --yes=false Effectue la mise à niveau et ne demande pas de confirmation (mode non interactif).

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version affichée
