KAFFEINE(1) Manuel de l'utilisateur Kaffeine KAFFEINE(1)

NOM

kaffeine - Lecteur multimédia de KDE avec support de la TV numérique

SYNTAXE

kaffeine [-d, --debug] [--tempfile] [-f, --fullscreen] [-m, --minimal] [-t, --alwaysontop] [--audiocd] [--videocd] [--aspectratio rapport_hauteur] [--dvd] [--dumpdvb] [--channel nom / numéro] [--tv canal] [--lastchannel] [fichiers]

Veuillez noter que --channel, --tv, --lastchannel, --audiocd, --videocd, --dvd et fichiers sont mutuellement exclusifs.

DESCRIPTION

Kaffeine est un lecteur multimédia. Ce qui le différencie des autres, c'est son excellent support de la télévision numérique (DVB). Kaffeine possède une interface conviviale, de sorte que même les nouveaux utilisateurs peuvent commencer immédiatement à lire leurs films : depuis DVD (y compris les menus DVD, titres, chapitres, etc.), VCD ou un fichier.

Kaffeine utilise libVLC comme backend de lecture audio/vidéo.

OPTIONS

-d --debug

Active tous les messages de débogage. Veuillez noter que Kaffeine permet également un réglage fin des messages de débogage, en activant les messages par catégorie, en utilisant la variable d'environnement :

QT_LOGGING_RULES=kaffeine.categorie.debug=true

où categorie peut être :

cam

pour les logs DVB CAM

dev

pour les logs DVB device et libdvbv5

dvbsi

pour les logs d'analyse DVB MPEG-TS SI

epg

pour les logs DVB EPG

dvb

pour les autres logs DVB

config

pour les logs de configuration

mediawidget

pour les logs du widget média

playlist

pour les logs de la playlist

sql

pour les logs SQL lite

vlc

pour les logs libVlc

--tempfile

Les fichiers/URL ouverts par l'application seront supprimés après utilisation.

-f --fullscreen

Démarrer en mode plein écran. En mode plein écran, tous les menus sont masqués par défaut. Pour les afficher, déplacez la souris vers les emplacements des menus, par exemple en haut/en bas ou sur le côté de l'écran.

-m --minimal

Démarrer en mode minimal. En mode minimal, la décoration de la fenêtre avec la barre de titre est affichée. Tous les autres menus sont masqués par défaut. Pour les afficher, déplacez la souris vers les emplacements des menus, par exemple en haut/en bas ou sur le côté de la fenêtre Kaffeine.

Démarre en mode minimal.

-t --alwaysontop

Indique au gestionnaire de fenêtres de démarrer la fenêtre principale de Kaffeine toujours au-dessus des autres fenêtres. Cette option peut être désactivée ultérieurement via le gestionnaire de fenêtres, généralement en cliquant sur la barre de titre avec le bouton droit de la souris et en désélectionnant la case toujours au premier plan.

--aspectratio rapport_hauteur

Force Kaffeine à démarrer avec un rapport hauteur/largeur spécifique, désactivant le mode automatique. Cela peut être utile sur les écrans larges et ultra-larges, où l'utilisateur souhaite toujours voir la vidéo en plein écran en utilisant la résolution maximale possible. Les valeurs valides sont : 1:1, 4:3, 5:4, 16:9, 16:10, 2.21:1, 2.35:1 et 2.39:1. Si une valeur invalide est passée, ou si cette option n'est pas utilisée, elle reviendra par défaut au mode automatique.

--audiocd

Lire le CD Audio

--videocd

Lire le CD Vidéo

--dvd

Lire le DVD

--dumpdvb

Exporter les données DVB (option de débogage)

--channel nom / numéro

Lire un canal TV

--tv canal

(option obsolète)

--lastchannel

Lire le dernier canal TV syntonisé

fichiers

Fichiers ou URL à lire

FICHIERS

Kaffeine utilise le fichier scanfile.dvb avec une liste de canaux connus par localité et par satellite (pour DVB-S).

Lorsque de nouveaux canaux sont ajoutés dans une ville, ou lorsque de nouveaux faisceaux satellites sont ajoutés qui ne sont pas disponibles dans Kaffeine, utilisez dvbv5-scan ou w_scan pour générer un nouveau fichier (dans ce dernier cas, converti au format approprié à l'aide de dvb-format-convert), et soumettez-le à <linux-media@vger.kernel.org>, avec le sujet « [PATCH] dtv-scan-tables: une description ». Le nouveau patch sera ajouté à scanfile.dvb et le fichier mis à jour sera disponible pour être mis à jour depuis Internet dans l'application Kaffeine.
