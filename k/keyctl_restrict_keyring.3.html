KEYCTL_RESTRICT_KEYRING(3) Appels de gestion de clés Linux KEYCTL_RESTRICT_KEYRING(3)

NOM

keyctl_restrict_keyring - restreindre les clés qui peuvent être liées à un keyring

SYNOPSIS

#include <keyutils.h>

long keyctl_restrict_keyring(key_serial_t keyring,
const char *type, const char *restriction);

DESCRIPTION

keyctl_restrict_keyring() limite la liaison des clés au keyring donné en utilisant un schéma de type et de restriction fourni. Les options disponibles varient en fonction du type de clé, et contiennent typiquement un nom de restriction potentiellement suivi d'identifiants de clés ou d'autres données pertinentes pour la restriction. Si le type et la restriction sont tous deux NULL, le keyring rejettera tous les liens.

VALEUR DE RETOUR

En cas de succès, keyctl_restrict_keyring() retourne 0. En cas d'erreur, la valeur -1 sera retournée et errno aura été défini sur une erreur appropriée.

ERREURS

EDEADLK
Un cycle de restriction a été évité. Deux keyrings ne peuvent pas se restreindre mutuellement.
EEXIST
Le keyring est déjà restreint.
EINVAL
La chaîne de restriction est invalide ou trop grande.
ENOKEY
Le type de clé dans la restriction est invalide ou non disponible.
ENOTDIR
L'identifiant de clé fourni référence un élément qui n'est pas un keyring.
ENOENT
Le type de clé existe mais ne prend pas en charge les restrictions.

LIAISON

Il s'agit d'une fonction de bibliothèque qui peut être trouvée dans libkeyutils. Lors de la liaison, -lkeyutils doit être spécifié à l'éditeur de liens.

VOIR AUSSI
