KEYCTL_UPDATE(3) Appels de gestion de clés Linux KEYCTL_UPDATE(3)

NOM

keyctl_update - mettre à jour une clé

SYNTAXE

#include <keyutils.h>

long keyctl_update(key_serial_t key, const void *payload,
size_t plen);

DESCRIPTION

keyctl_update() met à jour la charge utile (payload) d'une clé si le type de clé le permet.

L'appelant doit avoir la permission d'**écriture** sur une clé pour pouvoir la mettre à jour.

payload et plen spécifient les données pour la nouvelle charge utile. payload peut être NULL et plen peut être zéro si le type de clé le permet. Le type de clé peut rejeter les données si elles sont dans le mauvais format ou invalides d'une autre manière.

VALEUR DE RETOUR

En cas de succès, keyctl_update() retourne 0. En cas d'erreur, la valeur -1 sera retournée et errno aura été défini vers une erreur appropriée.

ERREURS

ENOKEY
La clé spécifiée est invalide.
EKEYEXPIRED
La clé spécifiée a expiré.
EKEYREVOKED
La clé spécifiée a été révoquée.
EINVAL
Les données de la charge utile sont invalides.
ENOMEM
Mémoire insuffisante pour stocker la nouvelle charge utile.
EDQUOT
Le quota de clés pour cet utilisateur serait dépassé en augmentant la taille de la clé pour accueillir la nouvelle charge utile.
EACCES
La clé existe, mais n'est pas **modifiable** par le processus appelant.
EOPNOTSUPP
Le type de clé ne supporte pas l'opération de mise à jour sur ses clés.

LIAISON

Ceci est une fonction de bibliothèque qui se trouve dans libkeyutils. Lors de la liaison, -lkeyutils doit être spécifié au lieur.
