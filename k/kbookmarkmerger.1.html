DESCRIPTIO

N

kbookmarkmerger est un programme pour fusionner un ensemble donné de signets dans l'ensemble de signets de l'utilisateur ; si l'utilisateur n'a pas encore de signets créés, une nouvelle liste de signets est créée et les signets donnés y sont insérés. Ce faisant, kbookmarkmerger garde une trace des fichiers déjà fusionnés lors d'une exécution précédente, afin qu'aucun signet ne soit installé dans les signets de l'utilisateur plus d'une

fois.

L'approche traditionnellement utilisée pour obtenir un résultat similaire consistait à utiliser des répertoires home squelettes soigneusement conçus lors de la création d'un nouveau compte utilisateur, afin de fournir à l'utilisateur un ensemble standard de signets. Le problème avec cette approche est qu'une fois le compte utilisateur créé, aucun nouveau signet ne peut être

propagé.

Ce mécanisme est utile pour les administrateurs système qui souhaitent propager un signet pointant vers un certain document (par exemple, des notes importantes sur le système) à tous les utilisateurs. Les distributeurs pourraient également le trouver utile, par exemple en augmentant les paquets logiciels qu'ils fournissent avec des fichiers de signets que kbookmarkmerger fusionne dans la liste de signets de l'utilisateur lorsque le paquet est installé. De cette façon, la documentation fournie avec un paquet logiciel est facilement et visiblement accessible juste après l'installation du

paquet.

Le seul paramètre requis par kbookmarkmerger est le nom d'un répertoire qui doit être analysé à la recherche de fichiers de signets. Tous les fichiers du répertoire donné se

ront considérés pour être fusionnés dans la configuration de l'utilisateur.
Les fichiers du répertoire donné doivent être des fichiers XBEL valides.

RESTRICTION

S

Lors de la détermination de savoir si un fichier de signets donné a déjà été fusionné dans les signets de l'utilisateur ou non, kbookmarkmerger se contente de regarder le nom de fichier du fichier de signets - le contenu n'est pas vérifié du tout. Cela signifie que modifier un fichier de signets qui a déjà été fusionné dans les signets d'un utilisateur ne déclenchera pas sa fusion à

nouveau.

Notez également que si un utilisateur modifie un s

ignet qui a été fusionné dans sa configuration,
le fichier de signets d'origine restera inchangé.
