NOM

kubeone-reset - Annuler les modifications

SYNOPIS

kubeone reset [flags]

DESCRIPTION

Annuler toutes les modifications effectuées par KubeOne sur les machines configurées.

Cette commande prend un manifeste KubeOne qui contient des informations sur les hôtes. Il est possible de sourcer les informations sur les hôtes à partir de la sortie Terraform, en utilisant le drapeau '--tfjson'.

OPTIONS

-y, --auto-approve[=false] approuver automatiquement la réinitialisation

--destroy-workers[=true] détruire toutes les machines travailleuses avant de réinitialiser le cluster

-h, --help[=false] aide pour reset

--remove-binaries[=false] supprimer les binaires Kubernetes après la réinitialisation du cluster

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-c, --credentials="" Fichier pour sourcer les identifiants et les secrets

-d, --debug[=false] sortie de débogage avec trace de pile

-l, --log-format="text" format pour la journalisation

-m, --manifest="./kubeone.yaml" Chemin vers la configuration KubeOne

-t, --tfjson="" Source pour la sortie terraform en JSON - à lire depuis stdin. Si le chemin est un fichier, son contenu sera utilisé. Si le chemin est un dictionnaire, terraform output -json est exécuté dans ce chemin

-v, --verbose[=false] sortie détaillée

EXEMPLE

kubeone reset -m mycluster.yaml -t terraformoutput.json
