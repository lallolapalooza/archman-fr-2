DESCRIPTIO

N

kea-admin est un script shell qui offre la maintenance des bases de données. En particulier, il permet l'initialisation de la

base de données, la vérification de la version de la base de
données et la mise à niveau du schéma de la base de données.

DOCUMENTATIO

N

Kea est livré avec un manuel de référence de l'administrateur Kea étendu qui couvre tous les aspects de l'exécution du logiciel Kea - compilation, installation, configuration, exemples de configuration, et bien plus encore. Kea comprend également un manuel des messages Kea, qui liste tous les messages possibles que Kea peut imprimer avec une brève description pour chacun d'eux. Les deux documents sont disponibles dans divers formats (.txt, .html, .pdf) avec la distribution Kea. La documentation de Kea est disponible à l'adresse https://kea.readth

edocs.io.

Le code source de Kea est documenté dans le guide du développeur de Kea, disponible à l'adresse https://reports.kea.isc.or

g/dev_guide/.

Le site web du projet Kea est disponible à l'adresse https://ke

a.isc
.org.

LISTES DE DIFFUSION ET

SUPPORT

Il y a deux listes de diffusion publiques disponibles pour le projet Kea. kea-users (kea-users at lists.isc.org) est destinée aux utilisateurs de Kea, tandis que kea-dev (kea-dev at lists.isc.org) est destinée aux développeurs de Kea, aux contributeurs potentiels et aux autres utilisateurs avancés. Les deux listes sont disponibles à l'adresse https://lists.isc.org. La communauté fournit un support au mieux de ses moyens sur ces deux

listes.

ISC fournit un support professionnel pour les services Kea. Voir https://www.isc.org/kea

/ pour plus
de détails.
