NOM

keyanalyze - Analyse du web de confiance

SYNTAXE

keyanalyze [ -h1 ] [ -i infile ] [ -o outdir ]

DESCRIPTION

keyanalyze analyse le web de confiance au sein d'un groupe de clés. Il prend en entrée des clés prétraitées (voir process_keys(1)) et produit un répertoire de sortie contenant des statistiques sur les clés.

Généralement appelé comme suit :
$ pgpring -S -k ./keyring.gpg | process_keys > preprocess.keys
$ keyanalyze

OPTIONS

-i infile
Lire depuis infile au lieu de preprocess.keys.
-o outdir
Placer les résultats dans outdir au lieu de output/. Le répertoire sera créé s'il n'existe pas déjà.
-h
Afficher l'aide.
-1
Par défaut, keyanalyze écrit la sortie dans des sous-répertoires nommés d'après les deux premiers caractères de l'ID de la clé. Cette option désactive cette fonction ; utile pour les petits annuaires de clés.
