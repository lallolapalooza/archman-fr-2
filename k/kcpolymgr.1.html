NOM

kcpolymgr - interface en ligne de commande pour gérer la base de données polymorphique

DESCRIPTION

La commande `kcpolymgr' est un utilitaire pour tester et déboguer la base de données polymorphique et ses applications. `path' spécifie le chemin d'un fichier de base de données. `key' spécifie la clé d'un enregistrement. `value' spécifie la valeur d'un enregistrement. `file' spécifie le fichier d'entrée/sortie. `src' spécifie d'autres fichiers de base de données.


kcpolymgr create [-otr] [-onl|-otl|-onr] path
Crée un fichier de base de données.
kcpolymgr inform [-onl|-otl|-onr] [-st] path
Affiche des informations d'état.
kcpolymgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] path key value
Stocke un enregistrement.
kcpolymgr remove [-onl|-otl|-onr] [-sx] path key
Supprime un enregistrement.
kcpolymgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] path key
Affiche la valeur d'un enregistrement.
kcpolymgr list [-onl|-otl|-onr] [-mp|-mr|-ms] [-des] [-max num] [-rm] [-sx] [-pv] [-px] path [key]
Affiche les clés de tous les enregistrements, séparées par des sauts de ligne.
kcpolymgr clear [-onl|-otl|-onr] path
Supprime tous les enregistrements d'une base de données.
kcpolymgr import [-onl|-otl|-onr] [-sx] path [file]
Importe des enregistrements à partir d'un fichier TSV.
kcpolymgr copy [-onl|-otl|-onr] path file
Copie la base de données entière.
kcpolymgr dump [-onl|-otl|-onr] path [file]
Sauvegarde les enregistrements dans un fichier snapshot.
kcpolymgr load [-otr] [-onl|-otl|-onr] path [file]
Charge les enregistrements à partir d'un fichier snapshot.
kcpolymgr merge [-onl|-otl|-onr] [-add|-app|-rep] path src...
Fusionne des enregistrements d'autres bases de données.
kcpolymgr setbulk [-onl|-otl|-onr] path key value ...
Stocke des enregistrements en une seule fois.
kcpolymgr removebulk [-onl|-otl|-onr] [-sx] path key ...
Supprime des enregistrements en une seule fois.
kcpolymgr getbulk [-onl|-otl|-onr] [-sx] [-px] path key ...
Récupère des enregistrements en une seule fois.
kcpolymgr check [-onl|-otl|-onr] path
Vérifie la cohérence.

Les options incluent les éléments suivants.

-otr : ouvre la base de données avec l'option de troncature.
-onl : ouvre la base de données avec l'option sans verrouillage.
-otl : ouvre la base de données avec l'option de tentative de verrouillage.
-onr : ouvre la base de données avec l'option sans réparation automatique.
-st : affiche des informations diverses.
-add : effectue une opération d'ajout.
-app : effectue une opération d'ajout.
-rep : effectue une opération de remplacement.
-inci : effectue une opération d'incrémentation entière.
-incd : effectue une opération d'incrémentation de nombre réel.
-sx : les données d'entrée sont évaluées comme une chaîne de données hexadécimales.
-rm : supprime l'enregistrement.
-px : les données de sortie sont converties en une chaîne de données hexadécimales.
-pz : n'ajoute pas de saut de ligne à la fin de la sortie.
-mp : effectue une correspondance de préfixe au lieu d'un balayage normal.
-mr : effectue une correspondance d'expression régulière au lieu d'un balayage normal.
-ms : effectue une correspondance similaire au lieu d'un balayage normal.
-des : visite les enregistrements dans l'ordre décroissant.
-max num : spécifie le nombre maximum d'enregistrements affichés.
-pv : affiche également les valeurs des enregistrements.

Cette commande renvoie 0 en cas de succès, une autre valeur en cas d'échec.
