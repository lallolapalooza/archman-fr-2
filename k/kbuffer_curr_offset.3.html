kbuffer_curr_offset(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel de libtraceevent LIBTRACEEVENT(3)

NOM

kbuffer_read_event, kbuffer_next_event, kbuffer_missed_events, kbuffer_event_size, kbuffer_curr_size, kbuffer_curr_offset, kbuffer_curr_index, kbuffer_read_buffer - Fonctions pour lire à travers le sous-buffer kbuffer.

SYNOPSIS

#include <kbuffer.h>
void *kbuffer_read_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_next_event(struct kbuffer *kbuf, unsigned long long *ts);
void *kbuffer_read_at_offset(struct kbuffer *kbuf, int offset, unsigned long long *ts);
int kbuffer_missed_events(struct kbuffer *kbuf);
int kbuffer_event_size(struct kbuffer *kbuf);
int kbuffer_curr_size(struct kbuffer *kbuf);
int kbuffer_curr_offset(struct kbuffer *kbuf);
int kbuffer_curr_index(struct kbuffer *kbuf);
int kbuffer_read_buffer(struct kbuffer *kbuf, void *buffer, int len);

DESCRIPTION

La fonction kbuffer_read_event() lit l'événement suivant dans le descripteur kbuf et si ts n'est pas NULL, y place son horodatage. Cela ne modifie pas le descripteur kbuf et appeler cette fonction plusieurs fois renverra le même résultat.

La fonction kbuffer_next_event() renverra le prochain événement dans le descripteur kbuf . Elle définira également ts sur l'horodatage de l'événement renvoyé. NULL est renvoyé s'il n'y a plus d'événements et ts sera indéfini. Notez que si cette fonction est appelée directement après un kbuffer_load_subbuffer() , elle donnera probablement un résultat inattendu, car elle renverra le deuxième événement et non le premier événement. Habituellement, cette fonction n'est utilisée que pour passer à l'événement suivant et savoir s'il reste des événements à lire, et kbuffer_read_event() est toujours appelée en premier.

La fonction kbuffer_read_at_offset() renvoie l'événement situé à un décalage donné depuis le début du sous-buffer. Ce décalage peut être récupéré par kbuffer_curr_offset(). Si ts pointe vers un unsigned long long, il sera défini sur l'horodatage de l'événement au décalage donné.

Si le sous-buffer avait des événements manquants avant lui, alors kbuffer_missed_events() renverra une valeur non nulle. Si elle renvoie -1, cela signifie qu'il y a eu des événements manquants, mais le nombre exact d'événements manquants est inconnu. Si elle renvoie un nombre positif, alors le nombre d'événements manquants est la valeur de retour.

La kbuffer_event_size() fonction renvoie la taille de la partie données de l'événement actuel (celui qui serait renvoyé par kbuffer_read_event().

La kbuffer_curr_size() fonction renvoie la taille d'enregistrement complète de l'événement actuel (celui qui serait renvoyé par kbuffer_read_event(). La différence ici est que la valeur de retour inclut la taille des métadonnées de l'enregistrement d'événement qui ne fait pas partie de ce qui est renvoyé par kbuffer_read_event().

La kbuffer_curr_offset() fonction renvoie le décalage depuis le début du sous-buffer où commencent les métadonnées de l'enregistrement de l'événement actuel. Le premier événement ne sera pas au décalage zéro. Ce décalage peut être utilisé pour récupérer l'événement avec kbuffer_read_at_offset().

La kbuffer_curr_index() fonction renvoie l'index depuis le début de la partie données du sous-buffer où se trouvent les métadonnées de l'événement actuel. Le premier événement sera probablement zéro, mais peut ne pas l'être s'il y a un horodatage qui lui est attaché.

La kbuffer_read_buffer() fonction remplira le buffer donné à partir du kbuf de la même manière que le noyau le ferait avec un appel système read. C'est-à-dire que si la longueur len est inférieure à la taille du sous-buffer, ou si l'index courant du kbuffer n'est pas nul, elle commencera à copier à partir de l'événement courant de kbuf et créera buffer comme un nouveau sous-buffer (avec un en-tête d'horodatage et de commit) avec l'événement trouvé et incluant tous les événements suivants qui peuvent tenir dans len. La len doit inclure la taille de l'en-tête du sous-buffer ainsi que les événements à inclure. C'est-à-dire que len est la taille allouée de buffer qui peut être remplie. Le retour de cette fonction est l'index de la fin du dernier événement qui a été ajouté. S'il n'y a plus d'événements, zéro est renvoyé, et si le buffer ne peut copier aucun événement parce que len était trop petit, alors -1 est renvoyé.

VALEUR DE RETOUR

kbuffer_read_event() renvoie l'événement sur lequel le descripteur kbuf se trouve actuellement, ou NULL si le dernier événement a été dépassé (par kbuffer_next_event()).

kbuffer_next_event() renvoie l'événement suivant après l'événement courant ou NULL s'il n'y a plus d'événements.

kbuffer_read_at_offset() renvoie l'événement à un décalage donné depuis le début du sous-buffer stocké dans kbuf, ou NULL s'il n'existe aucun événement. Notez que offset n'a besoin que d'être un décalage qui tombe sur l'enregistrement, ou qui est à son début. Il n'a pas besoin d'être exactement au début de l'enregistrement.

kbuffer_missed_events() renvoie 0 s'il n'y a pas eu d'événements manquants avant le sous-buffer chargé. Renvoie -1 s'il y a eu un nombre inconnu d'événements manquants, ou si le nombre d'événements manquants est connu, ce nombre sera renvoyé.

kbuffer_event_size() renvoie la taille de la charge utile de données de l'événement courant de kbuf.

kbuffer_curr_size() renvoie la taille de l'enregistrement entier de l'événement courant de kbuf. Cela inclut la taille des métadonnées pour cet enregistrement.

kbuf_curr_offset() renvoie le décalage de l'enregistrement courant depuis le début du sous-buffer kbuf .

kbuf_curr_index() renvoie l'index de l'enregistrement courant depuis le début de la section de données kbuf .

kbuf_read_buffer() renvoie l'index de la fin du dernier événement qui a été rempli dans buffer. S'il n'y a plus d'événements à copier à partir de start , alors 0 est renvoyé. Si len n'est pas assez grand pour contenir des événements, alors -1 est renvoyé.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <kbuffer.h>
int main (int argc, char **argv)
{
        unsigned long long ts;
        struct kbuffer *kbuf;
        struct stat st;
        char *buf;
        void *event;
        int save_offset = -1;
        int record_size;
        int offset;
        int index;
        int size;
        int ret;
        int fd;
        int i = 0;
        if (argc < 2) {
                printf("usage: %s raw-subbuffer-page\n", argv[0]);
                printf(" Essayez: dd count=1 bs=4096 if=/sys/kernel/tracing/per_cpu/cpu0/trace_pipe_raw of=/tmp/file\n");
                exit(0);
        }
        if (stat(argv[1], &st) < 0) {
                perror("stat");
                exit(-1);
        }
        buf = malloc(st.st_size);
        if (!buf) {
                perror("Allocating buffer");
                exit(-1);
        }
        fd = open(argv[1], O_RDONLY);
        if (fd < 0) {
                perror(argv[1]);
                exit(-1);
        }
        ret = read(fd, buf, st.st_size);
        if (ret < 0) {
                perror("Reading buffer");
                exit(-1);
        }
        close(fd);
        kbuf = kbuffer_alloc(KBUFFER_ENDIAN_SAME_AS_HOST,
                             KBUFFER_LSIZE_SAME_AS_HOST);
        if (!kbuf) {
                perror("Creating kbuffer");
                exit(-1);
        }
        ret = kbuffer_load_subbuffer(kbuf, buf);
        if (ret < 0) {
                perror("Loading sub bufer");
                exit(-1);
        }
        if (kbuffer_subbuffer_size(kbuf) > st.st_size) {
                fprintf(stderr, "kbuffer is bigger than raw size %d > %ld\n",
                        kbuffer_subbuffer_size(kbuf), st.st_size);
                exit(-1);
        }
        ret = kbuffer_missed_events(kbuf);
        if (ret) {
                if (ret > 0)
                        printf("Missed %d events before this buffer\n", ret);
                else
                        printf("Missed unknown number of events before this buffer\n");
        }
        do {
                event = kbuffer_read_event(kbuf, &ts);
                if (event) {
                        record_size = kbuffer_curr_size(kbuf);
                        offset = kbuffer_curr_offset(kbuf);
                        index = kbuffer_curr_index(kbuf);
                        size = kbuffer_event_size(kbuf);
                        if (i == 20)
                                save_offset = offset;
                        printf(" event %3d ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n",
                               i++, ts, record_size, size, index, offset);
                        event = kbuffer_next_event(kbuf, NULL);
                }
        } while (event);
        if (!event)
                printf("Finished sub buffer\n");
        if (save_offset > 0) {
                event = kbuffer_read_at_offset(kbuf, save_offset, &ts);
                if (!event) {
                        fprintf(stderr, "Funny, can't find event 20 at offset %d\n", save_offset);
                        exit(-1);
                }
                record_size = kbuffer_curr_size(kbuf);
                offset = kbuffer_curr_offset(kbuf);
                index = kbuffer_curr_index(kbuf);
                size = kbuffer_event_size(kbuf);
                printf("\n saved event 20 ts:%lld\trecord_size:%d size:%d\tindex:%d offset:%d\n\n",
                       ts, record_size, size, index, offset);
        }
        kbuffer_free(kbuf);
        return 0;
}
