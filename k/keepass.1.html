NOM

keepass - gestionnaire de mots de passe

SYNTAXE

keepass

DESCRIPTION

KeePass est un gestionnaire de mots de passe libre/open-source ou coffre-fort qui vous aide à gérer vos mots de passe de manière sécurisée. Vous pouvez stocker tous vos mots de passe dans une seule base de données, qui est verrouillée avec une clé maîtresse unique ou un fichier clé. Vous n'avez ainsi qu'à retenir un seul mot de passe maître pour déverrouiller toute la base de données. Les bases de données sont chiffrées en utilisant AES-256.

OPTIONS

--auto-type
invoque la saisie automatique globale
--lock-all
verrouille les bases de données de toutes les instances KeePass
--unlock-all
déverrouille les bases de données de toutes les instances KeePass
--exit-all
quitte toutes les instances KeePass
