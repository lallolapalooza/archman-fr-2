NOM

kiwix-serve - Serveur HTTP Kiwix

SYNTAXE

kiwix-serve --library [OPTIONS] CHEMIN_FICHIER_BIBLIOTHEQUE
kiwix-serve [OPTIONS] FICHIER_ZIM ...

DESCRIPTION

La commande kiwix-serve est utilisée pour exécuter un serveur HTTP autonome pour servir du contenu ZIM sur le réseau.

ARGUMENTS

CHEMIN_FICHIER_BIBLIOTHEQUE
Chemin d'un fichier XML de bibliothèque listant les fichiers ZIM à servir. À utiliser uniquement avec l'option --library. Plusieurs fichiers de bibliothèque peuvent être fournis sous forme d'une liste séparée par des points-virgules (;).
FICHIER_ZIM ...
Chemin(s) du fichier ZIM. Plusieurs arguments sont autorisés.

OPTIONS

--library
Par défaut, kiwix-serve attend une liste de fichiers ZIM comme arguments de la ligne de commande. L'option --library indique à kiwix-serve que l'argument de la ligne de commande est plutôt un fichier XML de bibliothèque.
-i ADDR, --address=ADDR
Écouter uniquement sur cette adresse IP. Par défaut, le serveur écoute sur toutes les adresses IP disponibles. Alternativement, vous pouvez utiliser des valeurs spéciales pour définir quels types de connexions accepter :

all : Écouter les connexions sur toutes les adresses IP (IPv4 et IPv6).
ipv4 : Écouter les connexions sur toutes les adresses IPv4.
ipv6 : Écouter les connexions sur toutes les adresses IPv6.

-p PORT, --port=PORT
Port TCP sur lequel écouter les requêtes HTTP (défaut : 80).
-r ROOT, --urlRootLocation=ROOT
Préfixe d'URL sur lequel le contenu sera rendu disponible (défaut : vide).
-d, --daemon
Détacher le démon du serveur HTTP du processus principal.
-a PID, --attachToProcess=PID
Sortir lorsque le processus avec l'ID PID cesse de fonctionner.
-M, --monitorLibrary
Surveiller le fichier XML de la bibliothèque et le recharger automatiquement lorsqu'il change.

Le rechargement de la bibliothèque peut être forcé à tout moment en envoyant un signal SIGHUP au processus « kiwix-serve » (cela fonctionne indépendamment de la présence de l'option « --monitorLibrary »/« -M »).

-m, --nolibrarybutton
Désactiver le bouton d'accueil de la bibliothèque dans la barre d'outils du visualiseur ZIM.
-n, --nosearchbar
Désactiver la barre de recherche dans la barre d'outils du visualiseur ZIM.
-b, --blockexternal
Empêcher les utilisateurs de naviguer directement vers des ressources externes via des liens dans le contenu ZIM.
-t N, --threads=N
Nombre de threads à exécuter en parallèle (défaut : 4).
-s N, --searchLimit=N
Nombre maximum de fichiers ZIM dans une recherche multi-ZIM en texte intégral (défaut : aucune limite).
-z, --nodatealiases
Créer des alias d'URL pour chaque contenu en supprimant la date intégrée dans le nom du fichier.

Le format attendu de la date dans le nom de fichier est « _YYYY-MM ». Par exemple, un fichier ZIM nommé « wikipedia_en_all_2020-08.zim » sera accessible à la fois sous « wikipedia_en_all_2020-08 » et « wikipedia_en_all ».

-c PATH, --customIndex=PATH
Remplacer la page d'accueil par un fichier HTML personnalisé.
-L N, --ipConnectionLimit=N
Nombre maximum de connexions (simultanées) par IP (défaut : infini, recommandé : >= 6).
-k, --skipInvalid
Démarrer même lorsque les fichiers ZIM sont invalides (ceux-ci seront ignorés)
-v, --verbose
Afficher le journal de débogage sur STDOUT.
-V, --version
Afficher la version du logiciel.
-h, --help
Afficher un message d'aide.

EXEMPLES

Servir un seul fichier ZIM :

kiwix-serve myzim.zim

Servir plusieurs fichiers ZIM :

kiwix-serve zim1.zim zim2.zim zim3.zim

Servir des fichiers ZIM à partir d'une bibliothèque :

kiwix-serve --library library.xml
