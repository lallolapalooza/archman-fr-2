NOM

kubeone-apply - Réconcilier le cluster

SYNOPSIS

kubeone apply [flags]

DESCRIPTION

Réconcilie (installe/met à niveau/répare/restaure) le cluster Kubernetes sur des machines préexistantes. Les MachineDeployments sont initialisés mais ne seront pas modifiés par défaut, voir '--upgrade-machine-deployments'.

Cette commande prend un manifeste KubeOne qui contient des informations sur les hôtes et la manière dont le cluster doit être provisionné. Il est possible de sourcer les informations des hôtes à partir de la sortie Terraform, en utilisant l'option '--tfjson'.

OPTIONS

-y, --auto-approve[=false] Approuver automatiquement le plan

-b, --backup="" Chemin où le fichier PKI de sauvegarde .tar.gz doit être placé (défaut : emplacement du fichier de configuration du cluster)

--create-machine-deployments[=true] créer des objets MachineDeployments

--force-install[=false] utiliser la force pour installer de nouvelles versions de binaires (!dangereux !)

--force-upgrade[=false] forcer le démarrage du processus de mise à niveau

-h, --help[=false] aide pour apply

--no-init[=false] ne pas initialiser le cluster (seulement installer les binaires)

--prune-images[=false] supprimer les images de conteneurs inutilisées sur les nœuds de contrôle et les nœuds workers statiques

--rotate-encryption-key[=false] faire pivoter la clé de chiffrement du fournisseur de chiffrement

--upgrade-machine-deployments[=false] mettre à niveau les objets MachineDeployments

OPTIONS HÉRITÉES DES COMMANDES PARENTES

-c, --credentials="" Fichier pour sourcer les identifiants et les secrets

-d, --debug[=false] sortie de débogage avec la pile d'appels

-l, --log-format="text" format pour la journalisation

-m, --manifest="./kubeone.yaml" Chemin vers la configuration KubeOne

-t, --tfjson="" Source pour la sortie terraform en JSON - pour lire depuis stdin. Si le chemin est un fichier, son contenu sera utilisé. Si le chemin est un répertoire, terraform output -json sera exécuté dans ce répertoire.

-v, --verbose[=false] sortie détaillée

EXEMPLE

kubeone apply -m mycluster.yaml -t terraformoutput.json
