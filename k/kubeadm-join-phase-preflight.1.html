NOM

kubeadm join phase preflight - Exécute les vérifications préalables à la jonction

SYNTAXE

kubeadm join phase preflight [OPTIONS]

DESCRIPTION

Exécute les vérifications préalables pour kubeadm join.

OPTIONS

--apiserver-advertise-address="" Si le nœud doit héberger une nouvelle instance de plan de contrôle, l'adresse IP à laquelle le serveur API annoncera qu'il écoute. Si non défini, l'interface réseau par défaut sera utilisée.

--apiserver-bind-port=6443 Si le nœud doit héberger une nouvelle instance de plan de contrôle, le port sur lequel le serveur API se liera.

--certificate-key="" Utilisez cette clé pour décrypter les secrets de certificat téléchargés par init. La clé de certificat est une chaîne codée en hexadécimal qui représente une clé AES de 32 octets.

--config="" Chemin vers un fichier de configuration kubeadm.

--control-plane=false Crée une nouvelle instance de plan de contrôle sur ce nœud.

--cri-socket="" Chemin vers le socket CRI pour se connecter. S'il est vide, kubeadm tentera de détecter automatiquement cette valeur ; utilisez cette option uniquement si vous avez plus d'un CRI installé ou si vous avez un socket CRI non standard.

--discovery-file="" Pour la découverte basée sur des fichiers, un fichier ou une URL à partir de laquelle charger les informations du cluster.

--discovery-token="" Pour la découverte basée sur des jetons, le jeton utilisé pour valider les informations du cluster récupérées depuis le serveur API.

--discovery-token-ca-cert-hash=[] Pour la découverte basée sur des jetons, vérifie que la clé publique racine du certificat CA correspond à ce hachage (format : ":").

--discovery-token-unsafe-skip-ca-verification=false Pour la découverte basée sur des jetons, permet de rejoindre sans épinglage de --discovery-token-ca-cert-hash.

--dry-run=false N'appliquez aucun changement ; affichez seulement ce qui serait fait.

--ignore-preflight-errors=[] Une liste des vérifications dont les erreurs seront affichées comme avertissements. Exemple : 'IsPrivilegedUser,Swap'. La valeur 'all' ignore les erreurs de toutes les vérifications.

--node-name="" Spécifie le nom du nœud.

--tls-bootstrap-token="" Spécifie le jeton utilisé pour s'authentifier temporairement auprès du plan de contrôle Kubernetes lors de la jonction du nœud.

--token="" Utilise ce jeton pour les jetons de découverte et d'amorçage TLS lorsque ces valeurs ne sont pas fournies.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à utiliser chroot sur le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée.

EXEMPLE

  # Exécute les vérifications préalables à la jonction en utilisant un fichier de configuration.
  kubeadm join phase preflight --config kubeadm-config.yaml
