NOM

kresd.systemd - gestion de Knot Resolver 5.7.5 via systemd.

SYNOPSIS

kresd@.service
kresd.target
system-kresd.slice

DESCRIPTION

Cette page de manuel décrit comment gérer kresd à l'aide des unités systemd.

DÉMARRAGE RAPIDE

systemctl start kresd@1 - une instance unique de kresd, répondant sur localhost

DAEMONS CONCURRENTS

Le démon kresd peut être exécuté dans plusieurs processus indépendants, qui sont gérés par systemd via des modèles systemd (voir systemd.unit(5)). Chaque instance de service systemd de kresd (kresd@.service) représente un seul processus kresd indépendant.

Si vous avez plusieurs cœurs de processeur disponibles, un seul démon kresd fonctionnant ne pourra utiliser qu'un seul cœur à la fois, laissant les autres cœurs inactifs. Si vous souhaitez que kresd tire parti de tous les cœurs disponibles, tout en partageant le cache et les sockets, vous devriez activer et démarrer autant d'instances de kresd@.service que vous avez de cœurs. Typiquement, chaque instance est simplement nommée kresd@N.service, où N est un nombre décimal. Par exemple, pour activer et démarrer 3 démons concurrents :

systemctl enable --now kresd@1.service kresd@2.service kresd@3.service

L'ensemble de services kresd géré par systemd est regroupé dans la tranche system-kresd.slice. La tranche inclut tous les démons en cours d'exécution (instances de kresd@.service).

EXEMPLES

Pour démarrer une instance unique de kresd et l'activer au démarrage :

systemctl enable --now kresd@1.service

Pour redémarrer (ou arrêter) toutes les instances en cours d'exécution, vous pouvez utiliser une expression générique. Veuillez noter que les expressions génériques ne peuvent pas être utilisées pour démarrer ou activer des instances.

systemctl restart 'kresd@*'

Les utilisateurs de Bash peuvent également utiliser l'expansion des accolades pour activer ou démarrer plusieurs instances, au lieu de les lister manuellement.

systemctl enable --now kresd@{1..4}.service

Pour démarrer tous les démons kresd activés, vous pouvez également utiliser le fichier kresd.target fourni :

systemctl start kresd.target
