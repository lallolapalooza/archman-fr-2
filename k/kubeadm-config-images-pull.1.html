NOM

kubeadm config images pull - Télécharge les images utilisées par kubeadm

SYNOPIS

kubeadm config images pull [OPTIONS]

DESCRIPTION

Télécharge les images utilisées par kubeadm

OPTIONS

--config="" Chemin vers un fichier de configuration kubeadm.

--cri-socket="" Chemin vers la socket CRI à connecter. Si vide, kubeadm essaiera de détecter automatiquement cette valeur ; utilisez cette option uniquement si vous avez plusieurs CRI installés ou si vous avez une socket CRI non standard.

--feature-gates="" Un ensemble de paires clé=valeur qui décrivent les portails de fonctionnalités pour diverses fonctionnalités. Les options sont : ControlPlaneKubeletLocalMode=true|false (BETA - par défaut=true) NodeLocalCRISocket=true|false (BETA - par défaut=true) PublicKeysECDSA=true|false (OBSOLÈTE - par défaut=false) RootlessControlPlane=true|false (ALPHA - par défaut=false) WaitForAllControlPlaneComponents=true|false (par défaut=true)

--image-repository="registry.k8s.io" Choisissez un registre de conteneurs pour télécharger les images du plan de contrôle.

--kubernetes-version="stable-1" Choisissez une version spécifique de Kubernetes pour le plan de contrôle.

OPTIONS INHERITées DES COMMANDES PARENTES

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si l'option n'est pas définie, un ensemble d'emplacements standard peut être recherché pour trouver un fichier kubeconfig existant.

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée.
