NOM

kubeadm token list - Lister les jetons de démarrage sur le serveur

SYNTAXE

kubeadm token list [OPTIONS]

DESCRIPTION

Cette commande listera tous les jetons de démarrage pour vous.

OPTIONS

--allow-missing-template-keys=true Si vrai, ignorer toutes les erreurs dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. Ne s'applique qu'aux formats de sortie golang et jsonpath.

-o, --output="text" Format de sortie. Un parmi : text|json|yaml|go-template|go-template-file|template|templatefile|jsonpath|jsonpath-as-json|jsonpath-file.

--show-managed-fields=false Si vrai, conserver les managedFields lors de l'impression des objets au format JSON ou YAML.

OPTIONS HERITEES DES COMMANDES PARENTES

--dry-run=false Activer ou non le mode simulation

--kubeconfig="/etc/kubernetes/admin.conf" Le fichier kubeconfig à utiliser lors de la communication avec le cluster. Si le drapeau n'est pas défini, un ensemble d'emplacements standard peut être recherché pour un fichier kubeconfig existant.

--rootfs="" Le chemin d'accès au système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à faire un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
