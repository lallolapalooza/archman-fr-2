NOM

kclangctest - interface en ligne de commande pour tester la liaison C

DESCRIPTION

La commande `kclangctest' est un utilitaire pour les tests de fonctionnalité et de performance de la liaison C. Cette commande est utilisée dans le format suivant. `path' spécifie le chemin d'un fichier de base de données. `rnum' spécifie le nombre d'itérations.


kclangctest order [-rnd] [-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] path rnum
Effectue des tests en ordre.
kclangctest index [-rnd] [-etc] [-oat|-onl|-onl|-otl|-onr] path rnum
Effectue des opérations d'indexation.
kclangctest map [-rnd] [-etc] [-bnum num] rnum
Effectue un test de table de hachage économisant la mémoire.
kclangctest list [-rnd] [-etc] rnum
Effectue un test de liste d'arrays économisant la mémoire.

Les options sont les suivantes.

-rnd : effectue un test aléatoire.
-etc : effectue des opérations diverses.
-tran : effectue une transaction.
-oat : ouvre la base de données avec l'option de transaction automatique.
-oas : ouvre la base de données avec l'option de synchronisation automatique.
-onl : ouvre la base de données avec l'option sans verrouillage.
-otl : ouvre la base de données avec l'option de verrouillage d'essai.
-onr : ouvre la base de données avec l'option de réparation automatique désactivée.
-bnum num : spécifie le nombre de buckets de la table de hachage.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
