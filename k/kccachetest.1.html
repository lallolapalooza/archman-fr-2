NOM

kccachetest - interface en ligne de commande pour tester la base de données de hachage de cache

DESCRIPTION

La commande `kccachetest' est un utilitaire pour les tests de fonctionnalité et les tests de performance de la base de données de hachage de cache. Cette commande est utilisée dans le format suivant. `rnum' spécifie le nombre d'itérations.


kccachetest order [-th num] [-rnd] [-etc] [-tran] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Effectue des tests en ordre.
kccachetest queue [-th num] [-it num] [-rnd] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Effectue des opérations de mise en file d'attente.
kccachetest wicked [-th num] [-it num] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Effectue des opérations mixtes sélectionnées au hasard.
kccachetest tran [-th num] [-it num] [-tc] [-bnum num] [-capcnt num] [-capsiz num] [-lv] rnum
Effectue le test de transaction.

Les options incluent les suivantes.

-th num : spécifie le nombre de threads de travail.
-rnd : effectue un test aléatoire.
-etc : effectue diverses opérations.
-tran : effectue une transaction.
-tc : optimise la base de données avec l'option de compression.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-capcnt num : spécifie le nombre maximum d'enregistrements.
-capsiz num : spécifie la taille maximale d'utilisation de la mémoire.
-lv : signale toutes les erreurs.
-it num : spécifie le nombre de répétitions.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
