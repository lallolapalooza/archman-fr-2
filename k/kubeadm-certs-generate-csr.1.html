NOM

kubeadm certs generate-csr - Générer des clés et des requêtes de signature de certificat

SYNOPSIS

kubeadm certs generate-csr [OPTIONS]

DESCRIPTION

Génère les clés et les requêtes de signature de certificat (CSR) pour tous les certificats requis pour exécuter le plan de contrôle. Cette commande génère également des fichiers kubeconfig partiels avec des données de clé privée dans le champ "users > user > client-key-data", et pour chaque fichier kubeconfig, un fichier ".csr" est créé.

Cette commande est conçue pour être utilisée dans le mode CA externe de Kubeadm ⟨https://kubernetes.io/docs/tasks/administer-cluster/kubeadm/kubeadm-certs/#external-ca-mode⟩. Elle génère des CSR que vous pouvez ensuite soumettre à votre autorité de certification externe pour signature.

Les certificats signés encodés en PEM doivent ensuite être enregistrés aux côtés des fichiers de clés, en utilisant l'extension de fichier ".crt", ou dans le cas des fichiers kubeconfig, le certificat signé encodé en PEM doit être encodé en base64 et ajouté au fichier kubeconfig dans le champ "users > user > client-certificate-data".

OPTIONS

--cert-dir="" Le chemin où enregistrer les certificats

--config="" Chemin vers un fichier de configuration kubeadm.

--kubeconfig-dir="/etc/kubernetes" Le chemin où enregistrer le fichier kubeconfig.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine réel de l'hôte. Cela amènera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée

EXEMPLE

  # La commande suivante générera les clés et les CSR pour tous les certificats du plan de contrôle et les fichiers kubeconfig :
  kubeadm certs generate-csr --kubeconfig-dir /tmp/etc-k8s --cert-dir /tmp/etc-k8s/pki
