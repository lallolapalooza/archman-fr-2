NOM

kctreemgr - interface en ligne de commande pour gérer la base de données de l'arborescence de fichiers

DESCRIPTION

La commande `kctreemgr' est un utilitaire pour le test et le débogage de la base de données de l'arborescence de fichiers et de ses applications. `chemin' spécifie le chemin d'un fichier de base de données. `clé' spécifie la clé d'un enregistrement. `valeur' spécifie la valeur d'un enregistrement. `fichier' spécifie le fichier d'entrée/sortie.


kctreemgr create [-otr] [-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-rcd|-rcld|-rcdd] chemin
Crée un fichier de base de données.
kctreemgr inform [-onl|-otl|-onr] [-st] chemin
Affiche des informations d'état.
kctreemgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] chemin clé valeur
Stocke un enregistrement.
kctreemgr remove [-onl|-otl|-onr] [-sx] chemin clé
Supprime un enregistrement.
kctreemgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] chemin clé
Affiche la valeur d'un enregistrement.
kctreemgr list [-onl|-otl|-onr] [-des] [-max num] [-rm] [-sx] [-pv] [-px] chemin [clé]
Affiche les clés de tous les enregistrements, séparées par des sauts de ligne.
kctreemgr clear [-onl|-otl|-onr] chemin
Supprime tous les enregistrements d'une base de données.
kctreemgr import [-onl|-otl|-onr] [-sx] chemin [fichier]
Importe des enregistrements à partir d'un fichier TSV.
kctreemgr copy [-onl|-otl|-onr] chemin fichier
Copie la base de données entière.
kctreemgr dump [-onl|-otl|-onr] chemin [fichier]
Extrait des enregistrements dans un fichier snapshot.
kctreemgr load [-otr] [-onl|-otl|-onr] chemin [fichier]
Charge des enregistrements à partir d'un fichier snapshot.
kctreemgr defrag [-onl|-otl|-onr] chemin
Effectue la défragmentation.
kctreemgr setbulk [-onl|-otl|-onr] chemin clé valeur ...
Stocke des enregistrements en une fois.
kctreemgr removebulk [-onl|-otl|-onr] [-sx] chemin clé ...
Supprime des enregistrements en une fois.
kctreemgr getbulk [-onl|-otl|-onr] [-sx] [-px] chemin clé ...
Récupère des enregistrements en une fois.
kctreemgr check [-onl|-otl|-onr] chemin
Vérifie la cohérence.

Les options comprennent :

-otr : ouvre la base de données avec l'option de troncature.
-onl : ouvre la base de données avec l'option pas de verrouillage.
-otl : ouvre la base de données avec l'option d'essai de verrouillage.
-onr : ouvre la base de données avec l'option pas de réparation automatique.
-apow num : spécifie la puissance de l'alignement de la taille des enregistrements.
-fpow num : spécifie la puissance de la capacité du pool de blocs libres.
-ts : ajuste la base de données avec l'option petite.
-tl : ajuste la base de données avec l'option linéaire.
-tc : ajuste la base de données avec l'option de compression.
-bnum num : spécifie le nombre de buckets de la table de hachage.
-psiz num : spécifie la taille de chaque page.
-rcd : utilise le comparateur décimal au lieu du lexical.
-rcld : utilise le comparateur lexical descendant au lieu de l'ascendant.
-rcdd : utilise le comparateur décimal descendant au lieu du lexical.
-st : affiche des informations diverses.
-add : effectue une opération d'ajout.
-app : effectue une opération d'ajout en fin de liste.
-rep : effectue une opération de remplacement.
-inci : effectue une opération d'incrémentation entière.
-incd : effectue une opération d'incrémentation de nombre réel.
-sx : les données d'entrée sont évaluées comme une chaîne de données hexadécimales.
-rm : supprime l'enregistrement.
-px : les données de sortie sont converties en une chaîne de données hexadécimales.
-pz : n'ajoute pas de saut de ligne à la fin de la sortie.
-des : parcourt les enregistrements dans l'ordre décroissant.
-max num : spécifie le nombre maximum d'enregistrements affichés.
-pv : affiche également les valeurs des enregistrements.

Cette commande retourne 0 en cas de succès, une autre valeur en cas d'échec.
