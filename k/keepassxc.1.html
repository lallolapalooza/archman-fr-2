KEEPASSXC(1) Manuel des commandes générales KEEPASSXC(1)

NOM

keepassxc - un gestionnaire de mots de passe open-source moderne

SYNTAXE

keepassxc [options] [nom de fichier(s)]

DESCRIPTION

KeePassXC est un gestionnaire de mots de passe ou un coffre-fort libre et open-source qui vous aide à gérer vos mots de passe de manière sécurisée. La base de données complète est toujours chiffrée avec l'algorithme de chiffrement AES (alias Rijndael) standard de l'industrie, utilisant une clé de 256 bits. KeePassXC utilise un format de base de données compatible avec KeePass Password Safe. Votre portefeuille fonctionne hors ligne et ne nécessite aucune connexion Internet.

OPTIONS

-h, --help

Affiche cette aide.

-v, --version

Affiche les informations de version.

--config <config>

Chemin vers un fichier de configuration personnalisé.

--keyfile <fichier clé>

Fichier clé de la base de données.

--pw-stdin

Lit le mot de passe de la base de données depuis stdin.

--minimized

Lance KeePassXC minimisé dans la barre d'état système.

--debug-info

Affiche les informations de débogage.
