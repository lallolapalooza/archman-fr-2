NOM

knock - client de port-knock

SYNTAXE

knock [options] <hôte> <port[:proto]> [port[:proto]] ...

DESCRIPTION

knock est un client de port-knock. Il envoie des paquets TCP/UDP vers chaque port spécifié sur l'hôte, créant ainsi une séquence de frappe spéciale sur le serveur d'écoute (voir la page de manuel de knockd pour plus d'informations à ce sujet).

OPTIONS

-u, --udp
Utilise UDP pour tous les ports frappés (par défaut TCP). Si vous souhaitez que chaque port utilise un protocole différent (TCP ou UDP), vous pouvez spécifier le protocole port par port. Voir l'exemple ci-dessous.
-d <t>, --delay <t>
Attend <t> millisecondes entre chaque frappe de port. Ceci peut être utile dans les situations où un routeur interprète votre flux de paquets SYN comme un scan de ports et les bloque. En ralentissant le débit des paquets avec --delay, le routeur devrait laisser passer les paquets.
-4, --ipv4 <version>
Force l'utilisation d'IPv4.
-6, --ipv6 <version>
Force l'utilisation d'IPv6.
-v, --verbose
Affiche des messages de statut détaillés.
-V, --version
Affiche la version.
-h, --help
Aide à la syntaxe.

EXEMPLES

knock myserver.example.com 123:tcp 456:udp 789:tcp
knock -u myserver.example.com 8284 4721 18592 42912

VOIR AUSSI

knockd est le serveur de port-knock associé.
