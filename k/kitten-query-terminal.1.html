Nom

kitten-query-terminal - Interroger le terminal pour diverses capacités

Utilisation

kitten query-terminal [options] [requête1 requête2 ...]

Description

Interroge le terminal dans lequel ce kitten est exécuté pour diverses capacités. Cela envoie des codes d'échappement au terminal et, en fonction de sa réponse, affiche des données sur les capacités prises en charge. Notez qu'il s'agit d'une opération bloquante, car elle doit attendre une réponse du terminal. Vous pouvez contrôler le temps d'attente maximum via l'option --wait-for.

La sortie est constituée de lignes de la forme ::


requête : données

Si une requête particulière n'est pas prise en charge par la version de kitty en cours d'exécution, les données seront vides.

Notez que lors de l'appel à partir d'un autre programme, il faut être très prudent de ne pas effectuer d'opérations d'E/S sur le périphérique terminal tant que ce kitten n'est pas terminé.

Les requêtes disponibles sont :

name :
Nom du terminal (par ex. xterm-kitty)

version :
Version du terminal (par ex. 0.44.0)

allow_hyperlinks :
L'option de configuration allow_hyperlinks dans kitty.conf pour autoriser les hyperliens peut être yes, no ou ask

font_family :
Nom PostScript de la police actuelle

bold_font :
Nom PostScript de la police en gras actuelle

italic_font :
Nom PostScript de la police en italique actuelle

bold_italic_font :
Nom PostScript de la police en gras italique actuelle

font_size :
Taille actuelle de la police en points

dpi_x :
DPI actuel sur l'axe des x

dpi_y :
DPI actuel sur l'axe des y

foreground :
Couleur de premier plan actuelle sous forme de code couleur # 24 bits

background :
Couleur d'arrière-plan actuelle sous forme de code couleur # 24 bits

background_opacity :
Opacité actuelle de l'arrière-plan sous forme d'un nombre compris entre 0 et 1

clipboard_control :
L'option de configuration clipboard_control dans kitty.conf pour autoriser les lectures/écritures dans/depuis le presse-papiers

os_name :
Le nom du système d'exploitation sur lequel le terminal est en cours d'exécution. kitty renvoie les valeurs : bsd, linux, macos, unknown

Options

--wait-for [=10]
Le temps (en secondes) à attendre pour une réponse du terminal, après l'avoir interrogé.
--help, -h [=non]
Afficher l'aide pour cette commande
