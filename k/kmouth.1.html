KMOUTH(1) Manuel utilisateur KMouth KMOUTH(1)

NOM

kmouth - Interface de frappe-et-parle pour synthétiseurs vocaux

SYNTAXE

kmouth [nom_fichier]

DESCRIPTION

KMouth est une application qui permet aux personnes incapables de parler de laisser leur ordinateur parler. Il inclut un historique de phrases prononcées à partir duquel l'utilisateur peut sélectionner des phrases à répéter.

Notez que KMouth n'inclut pas de synthétiseur vocal. Il nécessite au contraire un synthétiseur vocal installé dans le système.

OPTIONS

nom_fichier

Le fichier d'historique à ouvrir.

VOIR AUSSI

espeak(1), festival(1), mbrola(1), freetts(1)

Une documentation utilisateur plus détaillée est disponible à l'adresse help:/kmouth (entrez cette URL dans Konqueror ou exécutez khelpcenter help:/kmouth).

Des informations supplémentaires sont également disponibles sur le site web du projet KDE Accessibilité[1].
