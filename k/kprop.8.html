NOM

kprop - propage une base de données de principaux Kerberos V5 à un serveur répliqué

SYNTAXE

kprop [-r domaine] [-f fichier] [-d] [-P port] [-s keytab] hôte_répliqué

DESCRIPTION

kprop est utilisé pour propager de manière sécurisée un fichier de vidage de la base de données Kerberos V5 depuis le serveur Kerberos principal vers un serveur Kerberos répliqué, spécifié par hôte_répliqué. Le fichier de vidage doit être créé par kdb5_util(8).

OPTIONS

-r domaine
Spécifie le domaine du serveur principal.
-f fichier
Spécifie le nom du fichier où le fichier de la base de données des principaux vidés doit être trouvé ; par défaut, le fichier de la base de données vidés est normalement /var/lib/krb5kdc/replica_datatrans.
-P port
Spécifie le port à utiliser pour contacter le serveur kpropd(8) sur l'hôte distant.
-d
Affiche des informations de débogage.
-s keytab
Spécifie l'emplacement du fichier keytab.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.

VOIR AUSSI

kpropd(8), kdb5_util(8), krb5kdc(8), kerberos(7)
