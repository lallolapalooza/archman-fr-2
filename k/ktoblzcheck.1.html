KTOBLZCHECK(1) Manuel des commandes générales KTOBLZCHECK(1)

NOM

ktoblzcheck - Vérifier un compte et un BLZ (code de routage bancaire)

SYNTAXE

ktoblzcheck [--returncode] [--file=<fichier de données>] <identifiant de banque> <identifiant de compte>

DESCRIPTION

Cette page de manuel documente brièvement l'application ktoblzcheck.

ktoblzcheck est un programme qui vérifie la validité d'un compte et d'un BLZ (Bankleitzahl - code de routage bancaire) pour la banque spécifiée, ainsi que la validité du compte lui-même, en utilisant des calculs de somme de contrôle, si cela est pris en charge pour cette banque particulière. La sortie est le nom en clair de la banque spécifiée par <identifiant de banque>, et si le <identifiant de compte> fourni est un numéro de compte valide dans cette banque.

OPTIONS

<identifiant de banque>
Il s'agit du Bankleitzahl (identifiant de routage bancaire), il s'agit en fait de l'identifiant du compte de cette banque particulière à la Deutsche Bundesbank.
<identifiant de compte>
C'est le numéro de compte que vous souhaitez vérifier. Si la méthode de somme de contrôle de la banque spécifiée par <identifiant de banque> est prise en charge, vous obtiendrez la vérification de l'identifiant du compte, c'est-à-dire s'il s'agit d'un identifiant de compte valide dans cette banque particulière.
--returncode
Si fourni, le résultat est renvoyé via le code de retour et aucune sortie sur le terminal. Les codes de retour suivants sont possibles : 0 : compte et banque sont ok 1 : inconnu, par exemple somme de contrôle non implémentée ou similaire 2 : compte et/ou banque non ok 3 : banque introuvable
--file=<fichier de données>
Spécifie le fichier contenant les données bancaires. Ce fichier peut être obtenu via Internet auprès de la Deutsche Bundesbank à l'adresse http://www.bundesbank.de/zahlungsverkehr/zahlungsverkehr_bankleitzahlen_download.php Attention ! Cette page est uniquement en allemand.

BOGUES

Aucun bogue connu à ce jour. Seuls certains algorithmes de somme de contrôle sont pris en charge pour le moment, veuillez donc ne pas vous plaindre si vous obtenez toujours "inconnu" comme valeur de retour.
