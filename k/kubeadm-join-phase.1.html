NOM

kubeadm join phase - Utiliser cette commande pour invoquer une phase unique du flux de travail "join"

SYNTAXE

kubeadm join phase [OPTIONS]

DESCRIPTION

Utiliser cette commande pour invoquer une phase unique du flux de travail "join"

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine 'réel' de l'hôte. Cela amènera kubeadm à faire un chroot dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée
