Nom

kitten-show-key - Affiche les codes générés par le terminal pour les pressions de touches dans divers modes de clavier

Utilisation

kitten show-key

Description

Affiche les codes générés par le terminal pour les pressions de touches dans divers modes de clavier.

Options

--mode-clavier, -m [=normal]
Le mode clavier à utiliser lors de l'affichage des touches. Le mode normal est avec DECCKM réinitialisé et le mode application est avec DECCKM activé. kitty est le protocole de clavier étendu complet de kitty.

Choix : normal, application, kitty, inchangé

--aide, -h [=non]
Affiche l'aide pour cette commande.
