NOM

kubeadm completion - Génère le code de complétion pour le shell spécifié (bash ou zsh)

SYNTAXE

kubeadm completion [OPTIONS]

DESCRIPTION

Génère le code de complétion pour le shell spécifié (bash ou zsh). Le code du shell doit être évalué pour fournir une complétion interactive des commandes kubeadm. Cela peut être fait en le sourçant depuis le fichier `.bash_profile`.

Note : cela nécessite le framework bash-completion.

Pour l'installer sur Mac, utilisez homebrew :
$ brew install bash-completion Une fois installé, bash_completion doit être évalué. Cela peut être fait en ajoutant la ligne suivante au fichier `.bash_profile` :
$ source $(brew --prefix)/etc/bash_completion

Si bash-completion n'est pas installé sur Linux, veuillez installer le paquet 'bash-completion' via le gestionnaire de paquets de votre distribution.

Note pour les utilisateurs de zsh : [1] les complétions zsh ne sont prises en charge que dans les versions de zsh >= 5.2.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine de l'hôte 'réel'. Cela provoquera l'exécution de kubeadm en utilisant chroot sur le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

EXEMPLE

# Installer la complétion bash sur un Mac en utilisant homebrew
brew install bash-completion
printf "\n# Bash completion support\nsource $(brew --prefix)/etc/bash_completion\n" >> $HOME/.bash_profile
source $HOME/.bash_profile
# Charger le code de complétion kubeadm pour bash dans le shell actuel
source <(kubeadm completion bash)
# Écrire le code de complétion bash dans un fichier et le sourcer depuis .bash_profile
kubeadm completion bash > ~/.kube/kubeadm_completion.bash.inc
printf "\n# Kubeadm shell completion\nsource '$HOME/.kube/kubeadm_completion.bash.inc'\n" >> $HOME/.bash_profile
source $HOME/.bash_profile
# Charger le code de complétion kubeadm pour zsh[1] dans le shell actuel
source <(kubeadm completion zsh)
