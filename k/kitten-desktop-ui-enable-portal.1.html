Nom

kitten-desktop-ui-enable-portal - Crée ou modifie les divers fichiers nécessaires pour que le portail de ce kitten soit utilisé par xdg-desktop-portal

Utilisation

kitten desktop-ui enable-portal

Description

Une fois cette commande exécutée, ajoutez `kitten desktop-ui run-server` à la séquence de démarrage de votre gestionnaire de fenêtres et redémarrez votre ordinateur (ou déconnectez-vous et redémarrez votre session). Normalement, xdg-desktop-portal devrait maintenant déléguer à kitty pour les portails implémentés ici. Si ce n'est pas le cas, essayez d'exécuter `/usr/lib/xdg-desktop-portal -r -v`. Cela fournira beaucoup de journaux sur les raisons pour lesquelles il choisit différents backends de portail. Combiné à une lecture attentive de `man portals.conf`, cela devrait suffire pour convaincre xdg-desktop-portal d'utiliser kitty.

Vous pouvez changer le schéma de couleurs du système dynamiquement en exécutant :

kitten desktop-ui set-color-scheme dark
