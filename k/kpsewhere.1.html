NOM

kpsewhere - Extension de kpsewhich pour itérer séparément sur chaque arborescence texmf listée dans $TEXMF.

SYNTAXE

kpsewhere [ OPTIONS-de-kpsewhich... ] COMMANDE

DESCRIPTION

kpsewhere est une extension de kpsewhich (comme where l'est pour which dans tcsh). L'intention est de fournir un moyen de vérifier les conflits/fichiers masqués. Il ne trouvera cependant qu'un seul fichier par arborescence TEXMF.

OPTIONS

-h|--aide
affiche un court message d'aide
*
toutes les autres options sont directement transmises à kpsewhich

VOIR AUSSI

kpsewhich(1)

Kpathsea: A library for path searching (fichier info ou DVI )
