KEY.DNS_RESOLVER(8) Utilitaires de gestion de clés Linux KEY.DNS_RESOLVER(8)

NOM

key.dns_resolver - appel de remontée pour request-key afin de gérer les clés dns_resolver

SYNTAXE

/sbin/key.dns_resolver <clé>
/sbin/key.dns_resolver --dump-config [-c <fichier_config>]
/sbin/key.dns_resolver -D [-v] [-v] [-c <fichier_config>] <description>
<informations_appelant>

DESCRIPTION

Ce programme est appelé par request-key pour le compte du noyau lorsque les services du noyau (tels que NFS, CIFS et AFS) souhaitent effectuer une résolution de nom d'hôte et que le noyau n'a pas la clé en cache. Il n'est pas prévu d'être appelé directement.

Ce programme possède des paramètres internes qui peuvent être modifiés via un fichier de configuration (voir key.dns_resolver.conf(5) pour plus d'informations). Le fichier de configuration par défaut se trouve dans /etc, mais cela peut être remplacé par l'option -c.

Le programme peut être appelé en mode débogage pour tester sa fonctionnalité en passant une option -D ou --debug sur la ligne de commande. Pour que cela fonctionne, la description de la clé et les informations d'appelant doivent être fournies. La verbosité peut être augmentée en fournissant une ou plusieurs options -v.

Le programme peut également être appelé avec --dump-config pour afficher les valeurs que les paramètres configurables auront après l'analyse du fichier de configuration.

ERREURS

Toutes les erreurs seront enregistrées dans syslog.

VOIR AUSSI

key.dns_resolver.conf(5), request-key.conf(5), keyrings(7), request-key(8)
