KEYCTL_SET_TIMEOUT(3) Appels de gestion de clés Linux KEYCTL_SET_TIMEOUT(3)

NOM

keyctl_set_timeout - définit le délai d'expiration d'une clé

SYNTAXE

#include <keyutils.h>

long keyctl_set_timeout(key_serial_t key, unsigned timeout);

DESCRIPTION

keyctl_set_timeout() définit le minuteur d'expiration d'une clé à timeout secondes dans le futur. Définir timeout à zéro annule l'expiration, en supposant que la clé n'a pas déjà expiré.

Lorsque la clé expire, les tentatives ultérieures d'y accéder seront reçues avec l'erreur EKEYEXPIRED.

L'appelant doit avoir la permission setattr sur une clé pour pouvoir modifier son masque de permissions.

VALEUR DE RETOUR

En cas de succès, keyctl_set_timeout() retourne 0. En cas d'erreur, la valeur -1 sera retournée et errno aura été défini à une erreur appropriée.

ERREURS

ENOKEY
La clé spécifiée n'existe pas.
EKEYEXPIRED
La clé spécifiée a déjà expiré.
EKEYREVOKED
La clé spécifiée a été révoquée.
EACCES
La clé nommée existe, mais n'accorde pas la permission setattr au processus appelant.

LIAISON

Ceci est une fonction de bibliothèque qui peut être trouvée dans libkeyutils. Lors de la liaison, -lkeyutils doit être spécifié à l'éditeur de liens.
