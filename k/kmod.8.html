NOM

kmod - Programme pour gérer les modules du noyau Linux

SYNTAXE

kmod [OPTIONS...] [COMMANDE] [OPTIONS_COMMANDE...]

DESCRIPTION

kmod est un binaire multi-appels qui implémente les programmes utilisés pour contrôler les modules du noyau Linux. La plupart des utilisateurs ne l'exécuteront qu'en utilisant ses autres noms.

OPTIONS

-V, --version

Affiche la version du programme et quitte.

-h, --help

Affiche le message d'aide.

COMMANDES

help

Affiche le message d'aide.

list

Liste les modules actuellement chargés.

static-nodes

Affiche les informations sur les nœuds de périphériques statiques fournies par les modules de la version actuelle du noyau en cours d'exécution.

AUTEUR

Le projet kmod a été lancé par Lucas De Marchi en tant que remplacement direct de module-init-tools qui était maintenu par Jon Masters, en ajoutant une bibliothèque (libkmod) et des fonctionnalités supplémentaires.

De nombreuses contributions proviennent de la liste de diffusion linux-modules <linux-modules@vger.kernel.org> et de Github. Si vous disposez d'un clone de kmod.git lui-même, la sortie de git-shortlog(1) et git-blame(1) peut vous montrer les auteurs des parties spécifiques du projet.

Lucas De Marchi <lucas.de.marchi@gmail.com> est le mainteneur actuel du projet.
