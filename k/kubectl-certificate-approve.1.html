NOM

kubectl certificate approve - Approuver une demande de signature de certificat

SYNTAXE

kubectl certificate approve [OPTIONS]

DESCRIPTION

Approuve une demande de signature de certificat.

kubectl certificate approve permet à un administrateur de cluster d'approuver une demande de signature de certificat (CSR). Cette action demande à un contrôleur de signature de certificat d'émettre un certificat au demandeur avec les attributs demandés dans la CSR.

AVIS DE SÉCURITÉ : Selon les attributs demandés, le certificat émis peut potentiellement accorder au demandeur l'accès aux ressources du cluster ou l'authentification en tant qu'identité demandée. Avant d'approuver une CSR, assurez-vous de comprendre ce que le certificat signé peut faire.

OPTIONS

--allow-missing-template-keys=true Si vrai, ignore toute erreur dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. S'applique uniquement aux formats de sortie golang et jsonpath.

-f, --filename=[] Nom du fichier, répertoire ou URL vers des fichiers identifiant la ressource à mettre à jour

--force=false Met à jour la CSR même si elle est déjà approuvée.

-k, --kustomize="" Traite le répertoire kustomize. Ce drapeau ne peut pas être utilisé avec -f ou -R.

-o, --output="" Format de sortie. Un parmi: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

-R, --recursive=false Traite le répertoire utilisé dans -f, --filename récursivement. Utile lorsque vous souhaitez gérer des manifestes liés organisés dans le même répertoire.

--show-managed-fields=false Si vrai, conserve les managedFields lors de l'impression des objets aux formats JSON ou YAML.

--template="" Chaîne de modèle ou chemin vers un fichier modèle à utiliser lorsque -o=go-template, -o=go-template-file. Le format du modèle est celui des modèles golang [http://golang.org/pkg/text/template/#pkg-overview].

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur ordinaire ou un compte de service dans un namespace.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactiver la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Cela peut être désactivé en exportant la porte d'accès aux fonctionnalités KUBECTL_KUBERC=false ou en désactivant la porte d'accès KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, la portée du namespace pour cette requête CLI

--password="" Mot de passe pour l'authentification de base auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier où écrire le profil

--request-timeout="0" Durée d'attente avant d'abandonner une seule requête serveur. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur nulle signifie ne pas expirer les requêtes.

-s, --server="" Adresse et port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé

--token="" Jeton d'authentification (Bearer token) pour l'authentification auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification de base auprès du serveur API

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Approuver la CSR 'csr-sqgzp'
  kubectl certificate approve csr-sqgzp
