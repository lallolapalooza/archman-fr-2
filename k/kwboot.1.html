KWBOOT(1) Manuel des commandes générales KWBOOT(1)

NOM

kwboot - Démarrer les SoC Marvell Kirkwood (et autres 32 bits) via un lien série.

SYNTAXE

kwboot [-b image] [-t] [-B débit] TTY

DESCRIPTION

Le programme kwboot démarre les cartes basées sur les plateformes 32 bits de Marvell, y compris Kirkwood, Dove, Avanta, A370, AXP, A375, A38x et A39x via leur UART intégré. Les fichiers image de démarrage contiennent généralement un chargeur de démarrage de second niveau, tel que U-Boot. Le fichier image doit être conforme au format d'image du firmware Marvell BootROM (kwbimage v0 ou v1), créé à l'aide d'un outil tel que mkimage.

Après la mise sous tension ou une réinitialisation du système, le code BootROM du système interroge l'UART pendant une courte période, détectant un message de poignée de main qui initie un téléchargement d'image. Ce programme envoie ce message de démarrage jusqu'à ce qu'il reçoive un accusé de réception positif. L'image est transférée en utilisant Xmodem.

De plus, ce programme implémente un mode terminal minimal, qui peut être utilisé seul ou activé immédiatement après la complétion du transfert de l'image de démarrage. Ceci est souvent utile pour capturer les premiers messages de démarrage, ou pour interrompre manuellement une procédure de démarrage par défaut effectuée par le chargeur de second niveau.

OPTIONS

-b image
Poignée de main ; puis télécharge le fichier image via TTY.

Notez que pour que le code de démarrage encapsulé soit exécuté, image doit être de type « UART boot » (0x69). Le programme kwboot change automatiquement ce type, à moins que l'image ne soit signée, auquel cas il ne peut pas être modifié.

Ce mode affiche le statut de la poignée de main et l'indication de progression du téléchargement sur la sortie standard. Il est possible que image contienne un code binaire optionnel dans son en-tête qui peut également afficher une sortie via UART (par exemple, U-Boot SPL fait cela). Dans ce cas, cette sortie est également écrite sur la sortie standard après l'envoi de l'en-tête.

-b
Effectue uniquement la poignée de main sur TTY sans télécharger de fichier. Le téléchargement de fichier peut être effectué ultérieurement via l'option -D ou via toute autre application Xmodem, comme sx(1).
-d
Effectue une poignée de main spéciale sur TTY pour le mode de débogage console.

Cela demandera au BootROM d'entrer dans le mode de débogage console simple intégré. Doit être combiné avec l'option -t.

Pour obtenir de l'aide de BootROM, tapez cette commande suivie de la touche ENTRÉE :

?

Le BootROM d'Armada 38x contient un bug qui fait que la sortie standard du BootROM est désactivée sur UART lorsque l'emplacement de démarrage par défaut contient une image de démarrage valide. Néanmoins, l'entrée standard du BootROM et l'écho du terminal du BootROM sont actifs et fonctionnent correctement. Pour contourner ce bug du BootROM concernant la sortie standard, il est possible d'écraser manuellement les variables du BootROM stockées en SRAM que le BootROM utilise pour vérifier si la sortie standard est activée ou non. Pour activer la sortie standard du BootROM sur UART, tapez cette commande suivie de la touche ENTRÉE :

w 0x40034100 1
-D image
Télécharge le fichier image via TTY sans poignée de main initiale.

Cette méthode est principalement utilisée sur les plateformes Dove, où le BootROM ne prend pas en charge la poignée de main initiale pour entrer en mode de téléchargement UART et où des broches de configuration (exposées par exemple par des boutons) sont utilisées à la place.

-p
Obsolète. Ne fait rien.

Auparavant, lors de l'utilisation de cette option, le programme patchait l'en-tête de l'image avant le téléchargement, pour le type « UART boot ». Ceci est maintenant fait par défaut.

-q
Obsolète. Ne fait rien.

On ne sait pas si cela faisait quelque chose par le passé.

-s délai-réponse
Spécifie un délai de réponse personnalisé lors de la poignée de main. La valeur par défaut est de 50 ms. Il s'agit du délai entre l'envoi de deux motifs de poignée de main consécutifs, c'est-à-dire le temps d'attente d'une réponse du BootROM. N'affecte que l'option -b avec un fichier image et l'option -d.

L'option -a spécifie un délai de réponse adapté au BootROM Armada XP et est actuellement de 1000 ms.

Certains tests ont montré que la spécification de 24 ms comme délai de réponse rend la poignée de main avec le BootROM Armada 385 plus stable.

-t
Exécute un programme terminal, connectant l'entrée et la sortie standard à TTY.

Si utilisé en combinaison avec les options -b, -D ou -d, le mode terminal est activé immédiatement après un téléchargement d'image réussi ou une poignée de main réussie (si aucun téléchargement d'image n'est effectué).

Si les flux d'E/S standard sont connectés à une console, ce mode se terminera après réception de ctrl-\ suivi de c depuis l'entrée de la console.

-B débit
Si utilisé en combinaison avec -b, injecte dans le code d'en-tête de l'image qui change le débit à débit après le téléchargement de l'en-tête de l'image, et un code qui rétablit le débit à la valeur par défaut (115200 Bd) avant d'exécuter la charge utile, et ajuste également le débit sur TTY en conséquence. Cela peut rendre le téléchargement beaucoup plus rapide.

Si utilisé en combinaison avec -t, ajuste le débit à débit sur TTY avant de démarrer le terminal.

Si -b et -t sont tous deux utilisés, le débit est rétabli à 115200 après le téléchargement.

Les valeurs testées pour débit pour Armada 38x incluent : 115200, 230400, 460800, 500000, 576000, 921600, 1000000, 1152000, 1500000, 2000000, 2500000, 3125000, 4000000 et 5200000.

EXEMPLES

Demander au BootROM d'entrer en mode de démarrage Xmodem, d'envoyer le fichier kwbimage u-boot-with-spl.kwb via Xmodem sur /dev/ttyUSB0 à 115200 Bd et d'exécuter le programme terminal :

kwboot -b u-boot-with-spl.kwb -t /dev/ttyUSB0

Demander au BootROM d'entrer en mode de démarrage Xmodem, d'envoyer l'en-tête du fichier kwbimage u-boot-with-spl.kwb via Xmodem à 115200 Bd, puis demander au BootROM de changer le débit à 5200000 Bd, d'envoyer la partie données du fichier kwbimage via Xmodem à haute vitesse, puis de rétablir le débit à 115200 Bd, et enfin d'exécuter le programme terminal :

kwboot -b u-boot-with-spl.kwb -B 5200000 -t /dev/ttyUSB0

Envoyer uniquement le fichier kwbimage u-boot-with-spl.kwb via Xmodem sur /dev/ttyUSB0 à 115200 Bd :

kwboot -D u-boot-with-spl.kwb /dev/ttyUSB0

Demander au BootROM d'entrer en mode de débogage console et d'exécuter le programme terminal sur /dev/ttyUSB0 à 115200 Bd :

kwboot -d -t /dev/ttyUSB0

Exécuter uniquement le programme terminal sur /dev/ttyUSB0 à 115200 Bd :

kwboot -t /dev/ttyUSB0
