killpg(3) Manuel des fonctions de bibliothèque killpg(3)

NOM

killpg - envoyer un signal à un groupe de processus

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <signal.h>
int killpg(int pgrp, int sig);
Conditions requises pour les macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

killpg() :

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE

DESCRIPTION

killpg() envoie le signal sig au groupe de processus pgrp. Voir signal(7) pour une liste des signaux.

Si pgrp est 0, killpg() envoie le signal au groupe de processus de processus appelant. (POSIX dit : si pgrp est inférieur ou égal à 1, le comportement est indéfini.)

Pour les permissions requises pour envoyer un signal à un autre processus, voir kill(2).

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
sig n'est pas un numéro de signal valide.
EPERM
Le processus n'a pas la permission d'envoyer le signal à l'un des processus cibles. Pour les permissions requises, voir kill(2).
ESRCH
Aucun processus ne peut être trouvé dans le groupe de processus spécifié par pgrp.
ESRCH
Le groupe de processus a été donné comme 0 mais le processus d'envoi n'a pas de groupe de processus.

VERSIONS

Il existe diverses différences entre la vérification des permissions sur les systèmes de type BSD et les systèmes de type System V. Voir le raisonnement POSIX pour kill(3p). Une différence non mentionnée par POSIX concerne la valeur de retour EPERM : BSD documente qu'aucun signal n'est envoyé et EPERM est retourné lorsque la vérification des permissions a échoué pour au moins un processus cible, tandis que POSIX documente EPERM uniquement lorsque la vérification des permissions a échoué pour tous les processus cibles.

Différences bibliothèque C/noyau

Sous Linux, killpg() est implémenté comme une fonction de bibliothèque qui effectue l'appel kill(-pgrp, sig).

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, SVr4, 4.4BSD (est apparu pour la première fois dans 4BSD).

VOIR AUSSI

getpgrp(2), kill(2), signal(2), capabilities(7), credentials(7)
