NOM

kbuildsycoca5 - Reconstruit le cache de configuration du système de fichiers des fichiers de bureau KService

SYNTAXE

kbuildsycoca5 [OPTIONS...]

DESCRIPTION

kbuildsycoca5 construit un cache binaire des données stockées dans les fichiers .desktop et les fichiers .xml de types MIME que le framework KService utilise pour trouver les plugins, les applications et autres services.

La bibliothèque KService utilise cette base de données pour fournir efficacement les informations qui lui sont demandées.

Normalement, les utilisateurs n'ont pas besoin de lancer cette application directement ; KService la lancera si nécessaire, lorsque l'un des fichiers dont les données sont mises en cache sera modifié.

OPTIONS

--global

Ignore tous les fichiers définis par l'utilisateur (dans XDG_DATA_HOME). Ceci n'est actuellement pris en charge que sur les systèmes UNIX®.

--noincremental

Au lieu d'utiliser le cache existant et de mettre à jour uniquement les informations qui ont changé ou ont été ajoutées, commence avec un cache vide. Ignoré si --global est défini.

--nosignal

Normalement, kbuildsycoca5 envoie un signal via D-Bus une fois le cache mis à jour à toutes les applications qui utilisent KService afin qu'elles travaillent toujours avec les informations les plus récentes. Cette option supprime ce comportement.

--menutest

Teste la génération de la base de données du menu des applications. Ne construit pas réellement le cache.

--testmode

Utilise le mode test de QStandardPaths pour éviter d'interférer avec les données utilisateur. Ceci est destiné à être utilisé avec des tests unitaires.

--track menu-id

Suit un identifiant de menu pour le débogage.

--author

Affiche les informations sur l'auteur.

--license

Affiche les informations sur la licence.

-h, --help

Affiche un bref texte d'aide.

-v , --version

Affiche les informations sur la version.

FICHIERS

cachedir/ksycoca5_[lang]_[sha1-of-dirs]

Le cache KService généré par kbuildsycoca5. Sur les systèmes UNIX®, cachedir est généralement XDG_CACHE_HOME.
