NOM

kubectl cluster-info dump - Vider les informations pertinentes pour le débogage et le diagnostic

SYNTAXE

kubectl cluster-info dump [OPTIONS]

DESCRIPTION

Vider les informations du cluster adaptées au débogage et au diagnostic des problèmes du cluster. Par défaut, vide tout vers la sortie standard. Vous pouvez facultativement spécifier un répertoire avec --output-directory. Si vous spécifiez un répertoire, Kubernetes construira un ensemble de fichiers dans ce répertoire. Par défaut, ne vide que les éléments dans l'espace de noms actuel et l'espace de noms 'kube-system', mais vous pouvez basculer vers un autre espace de noms avec le drapeau --namespaces, ou spécifier --all-namespaces pour vider tous les espaces de noms.

La commande vide également les journaux de tous les pods du cluster ; ces journaux sont vidés dans des répertoires différents basés sur l'espace de noms et le nom du pod.

OPTIONS

-A, --all-namespaces=false Si vrai, vider tous les espaces de noms. Si vrai, --namespaces est ignoré.

--allow-missing-template-keys=true Si vrai, ignorer toutes les erreurs dans les modèles lorsqu'un champ ou une clé de carte est manquant dans le modèle. S'applique uniquement aux formats de sortie golang et jsonpath.

--namespaces=[] Une liste d'espaces de noms séparés par des virgules à vider.

-o, --output="json" Format de sortie. Un parmi : (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--output-directory="" Où sortir les fichiers. Si vide ou '-', utilise la sortie standard, sinon crée une hiérarchie de répertoires dans ce répertoire.

--pod-running-timeout=20s La durée (comme 5s, 2m ou 3h, supérieure à zéro) pendant laquelle attendre qu'au moins un pod soit en cours d'exécution.

--show-managed-fields=false Si vrai, conserver les managedFields lors de l'impression des objets au format JSON ou YAML.

--template="" Chaîne de modèle ou chemin vers un fichier de modèle à utiliser lorsque -o=go-template, -o=go-template-file. Le format de modèle est un modèle golang [http://golang.org/pkg/text/template/#pkg-overview].

OPTIONS INHERITÉES DES COMMANDES PARENTES

--as="" Nom d'utilisateur à usurper pour l'opération. L'utilisateur peut être un utilisateur ordinaire ou un compte de service dans un espace de noms.

--as-group=[] Groupe à usurper pour l'opération, ce drapeau peut être répété pour spécifier plusieurs groupes.

--as-uid="" UID à usurper pour l'opération.

--cache-dir="/home/username/.kube/cache" Répertoire de cache par défaut

--certificate-authority="" Chemin vers un fichier de certificat pour l'autorité de certification

--client-certificate="" Chemin vers un fichier de certificat client pour TLS

--client-key="" Chemin vers un fichier de clé client pour TLS

--cluster="" Nom du cluster kubeconfig à utiliser

--context="" Nom du contexte kubeconfig à utiliser

--disable-compression=false Si vrai, désactiver la compression des réponses pour toutes les requêtes au serveur

--insecure-skip-tls-verify=false Si vrai, le certificat du serveur ne sera pas vérifié pour sa validité. Cela rendra vos connexions HTTPS non sécurisées.

--kubeconfig="" Chemin vers le fichier kubeconfig à utiliser pour les requêtes CLI.

--kuberc="" Chemin vers le fichier kuberc à utiliser pour les préférences. Ceci peut être désactivé en exportant la porte d'accès de fonctionnalité KUBECTL_KUBERC=false ou en désactivant la porte d'accès KUBERC=off.

--match-server-version=false Exiger que la version du serveur corresponde à la version du client

-n, --namespace="" Si présent, la portée de l'espace de noms pour cette requête CLI

--password="" Mot de passe pour l'authentification basique auprès du serveur API

--profile="none" Nom du profil à capturer. Un parmi (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" Nom du fichier dans lequel écrire le profil

--request-timeout="0" La durée à attendre avant d'abandonner une requête serveur unique. Les valeurs non nulles doivent contenir une unité de temps correspondante (par exemple, 1s, 2m, 3h). Une valeur de zéro signifie ne pas dépasser le délai des requêtes.

-s, --server="" L'adresse et le port du serveur API Kubernetes

--tls-server-name="" Nom du serveur à utiliser pour la validation du certificat du serveur. S'il n'est pas fourni, le nom d'hôte utilisé pour contacter le serveur est utilisé.

--token="" Jeton Bearer pour l'authentification auprès du serveur API

--user="" Nom de l'utilisateur kubeconfig à utiliser

--username="" Nom d'utilisateur pour l'authentification basique auprès du serveur API

--version=false --version, --version=raw imprime les informations de version et quitte ; --version=vX.Y.Z... définit la version rapportée

--warnings-as-errors=false Traiter les avertissements reçus du serveur comme des erreurs et quitter avec un code de sortie non nul

EXEMPLE

  # Vider l'état actuel du cluster vers la sortie standard
  kubectl cluster-info dump
  # Vider l'état actuel du cluster vers /path/to/cluster-state
  kubectl cluster-info dump --output-directory=/path/to/cluster-state
  # Vider tous les espaces de noms vers la sortie standard
  kubectl cluster-info dump --all-namespaces
  # Vider un ensemble d'espaces de noms vers /path/to/cluster-state
  kubectl cluster-info dump --namespaces default,kube-system --output-directory=/path/to/cluster-state
