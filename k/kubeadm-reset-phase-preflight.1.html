NOM

kubeadm reset phase preflight - Exécute les vérifications préliminaires de réinitialisation

SYNOPIS

kubeadm reset phase preflight [OPTIONS]

DESCRIPTION

Exécute les vérifications préliminaires pour kubeadm reset.

OPTIONS

--dry-run=false Ne pas appliquer de modifications ; se contenter d'afficher ce qui serait fait.

-f, --force=false Réinitialise le nœud sans demander de confirmation.

--ignore-preflight-errors=[] Une liste de vérifications dont les erreurs seront affichées sous forme d'avertissements. Exemple : 'IsPrivilegedUser,Swap'. La valeur 'all' ignore les erreurs de toutes les vérifications.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--rootfs="" Le chemin vers le système de fichiers racine réel de l'hôte. Cela obligera kubeadm à chrooter dans le chemin fourni.

--version=false --version, --version=raw affiche les informations de version et quitte ; --version=vX.Y.Z... définit la version signalée

VOIR AUSSI
