scalb(3) Manuel des fonctions de bibliothèque scalb(3)

NOM

scalb, scalbf, scalbl - mise à l'échelle par une puissance entière du radix (OBSOLÈTE)

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
[[deprecated]] double scalb(double x, double e);
[[deprecated]] float scalbf(float x, float e);
[[deprecated]] long double scalbl(long double x, long double e);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

scalb() :

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

scalbf(), scalbl() :

    _XOPEN_SOURCE >= 600
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions multiplient leur premier argument x par FLT_RADIX (probablement 2) à la puissance e, c'est-à-dire :

    x * FLT_RADIX ** e

La définition de FLT_RADIX peut être obtenue en incluant <float.h>.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent x * FLT_RADIX ** e.

Si x ou e est un NaN, un NaN est retourné.

Si x est l'infini positif (l'infini négatif), et e n'est pas l'infini négatif, l'infini positif (l'infini négatif) est retourné.

Si x est +0 (-0), et e n'est pas l'infini positif, +0 (-0) est retourné.

Si x est zéro, et e est l'infini positif, une erreur de domaine se produit, et un NaN est retourné.

Si x est un infini, et e est l'infini négatif, une erreur de domaine se produit, et un NaN est retourné.

Si le résultat déborde, une erreur de plage se produit, et les fonctions retournent HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement, avec un signe identique à x.

Si le résultat sous-dépasse, une erreur de plage se produit, et les fonctions retournent zéro, avec un signe identique à x.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est 0, et e est l'infini positif, ou x est l'infini positif et e est l'infini négatif et l'autre argument n'est pas un NaN
errno est mis à EDOM. Une exception à virgule flottante invalide (FE_INVALID) est levée.
Erreur de plage, débordement
errno est mis à ERANGE. Une exception à virgule flottante de débordement (FE_OVERFLOW) est levée.
Erreur de plage, sous-dépassement
errno est mis à ERANGE. Une exception à virgule flottante de sous-dépassement (FE_UNDERFLOW) est levée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
scalb (), scalbf (), scalbl () Sécurité des threads MT-Safe

NORMES

Aucune.

HISTORIQUE

scalb()
4.3BSD. Obsolète dans POSIX.1-2001 ; Supprimé dans POSIX.1-2008, recommandant l'utilisation de scalbln(3), scalblnf(3), ou scalblnl(3) à la place.

BOGUES

Avant glibc 2.20, ces fonctions ne définissaient pas errno pour les erreurs de domaine et de plage.

VOIR AUSSI

ldexp(3), scalbln(3)
