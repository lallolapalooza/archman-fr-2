NOM

scsi_readcap - effectue la commande SCSI READ CAPACITY sur les disques

SYNTAXE

scsi_readcap [--brief] [--help] [--long] [--verbose] PÉRIPHÉRIQUE [PÉRIPHÉRIQUE]*

DESCRIPTION

Ce script shell bash appelle l'utilitaire sg_readcap sur chaque PÉRIPHÉRIQUE donné. Cela enverra une commande SCSI READ CAPACITY à chaque PÉRIPHÉRIQUE.

L'action par défaut de ce script est d'envoyer la commande READ CAPACITY(10) avec un CDB de 10 octets à chaque PÉRIPHÉRIQUE. Si une réponse indique que le nombre de blocs est supérieur ou égal à '2**32 - 1', alors la commande READ CAPACITY(16) est envoyée et sa réponse est affichée.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-b, --brief
raccourcit la sortie à deux nombres hexadécimaux, tous deux précédés de '0x'. Le premier nombre est le nombre de blocs disponibles et le second est la taille de chaque bloc en octets (par exemple, '0x12a19eb0 0x200'). Si une erreur est détectée, '0x0 0x0' est affiché et le script continue s'il y a d'autres PÉRIPHÉRIQUEs.
-h, --help
affiche le message d'utilisation puis quitte.
-l, --long
par défaut, la commande READ CAPACITY(10) est envoyée (c'est-à-dire la variante de CDB de 10 octets). Lorsque cette option est donnée, la commande READ CAPACITY(16) est envoyée. Cette dernière commande fournit plus d'informations dans sa réponse.
-v, --verbose
augmente le niveau de verbosité.

STATUT DE SORTIE

Le statut de sortie de ce script est 0 en cas de succès. Sinon, le statut de sortie est celui du dernier utilitaire sg_readcap appelé. Voir la page de manuel sg3_utils(8).
