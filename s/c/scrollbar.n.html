scrollbar(n) Commandes intégrées Tk scrollbar(n)

NOM

scrollbar - Créer et manipuler les widgets de contrôle de défilement et d'indicateur 'scrollbar'

SYNOPIS

scrollbar nomFenetre ?options?

OPTIONS STANDARD

-activebackground	-highlightcolor	-repeatdelay
-background	-highlightthickness	-repeatinterval
-borderwidth	-jump	-takefocus
-cursor	-orient	-troughcolor
-highlightbackground	-relief

Voir l'entrée de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-activerelief
Nom de la base de données :	activeRelief
Classe de la base de données :	ActiveRelief
Spécifie le relief à utiliser lors de l'affichage de l'élément actif, le cas échéant. Les éléments autres que l'élément actif sont toujours affichés avec un relief élevé.
Nom de ligne de commande :	-command
Nom de la base de données :	command
Classe de la base de données :	Command
Spécifie le préfixe d'une commande Tcl à invoquer pour changer la vue dans le widget associé à la barre de défilement. Lorsqu'un utilisateur demande un changement de vue en manipulant la barre de défilement, une commande Tcl est invoquée. La commande réelle consiste en cette option suivie d'informations supplémentaires comme décrit plus loin. Cette option a presque toujours une valeur telle que .t xview ou .t yview, composée du nom d'un widget et de xview (si la barre de défilement est pour le défilement horizontal) ou yview (pour le défilement vertical). Tous les widgets déroulables ont des commandes xview et yview qui prennent exactement les arguments supplémentaires ajoutés par la barre de défilement, comme décrit dans la section COMMANDES DE DÉFILEMENT ci-dessous.
Nom de ligne de commande :	-elementborderwidth
Nom de la base de données :	elementBorderWidth
Classe de la base de données :	BorderWidth
Spécifie la largeur des bordures dessinées autour des éléments internes de la barre de défilement (les deux flèches et le curseur). La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Si cette valeur est inférieure à zéro, la valeur de l'option -borderwidth est utilisée à la place.
Nom de ligne de commande :	-width
Nom de la base de données :	width
Classe de la base de données :	Width
Spécifie la dimension étroite souhaitée de la fenêtre de la barre de défilement, non compris la bordure 3D, le cas échéant. Pour les barres de défilement verticales, ce sera la largeur et pour les barres de défilement horizontales, ce sera la hauteur. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels.

DESCRIPTION

La commande scrollbar crée une nouvelle fenêtre (donnée par l'argument nomFenetre) et en fait un widget barre de défilement. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer les aspects de la barre de défilement tels que ses couleurs, son orientation et son relief. La commande scrollbar retourne son argument nomFenetre. Au moment où cette commande est invoquée, aucune fenêtre nommée nomFenetre ne doit exister, mais le parent de nomFenetre doit exister.

Une barre de défilement est un widget qui affiche deux flèches, une à chaque extrémité de la barre, et un curseur dans la partie centrale de la barre. Elle fournit des informations sur ce qui est visible dans une fenêtre associée qui affiche un document d'une sorte (tel qu'un fichier en cours d'édition ou un dessin). La position et la taille du curseur indiquent quelle partie du document est visible dans la fenêtre associée. Par exemple, si le curseur d'une barre de défilement verticale couvre le tiers supérieur de la zone entre les deux flèches, cela signifie que la fenêtre associée affiche le tiers supérieur de son document.

Les barres de défilement peuvent être utilisées pour ajuster la vue dans la fenêtre associée en cliquant ou en faisant glisser la souris. Voir la section LIENS ci-dessous pour plus de détails.

ÉLÉMENTS

Une barre de défilement affiche cinq éléments, qui sont référencés dans les commandes du widget pour la barre de défilement :

flèche1
La flèche supérieure ou gauche de la barre de défilement.
gouttière1
La région entre le curseur et flèche1.
curseur
Le rectangle qui indique ce qui est visible dans le widget associé.
gouttière2
La région entre le curseur et flèche2.
flèche2
La flèche inférieure ou droite de la barre de défilement.

COMMANDE WIDGET

La commande scrollbar crée une nouvelle commande Tcl dont le nom est nomFenetre. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

nomFenetre option ?arg ...?
Option et les arg déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets barre de défilement :
nomFenetre activer ?element?
Marque l'élément indiqué par element comme actif, ce qui provoque son affichage tel que spécifié par les options -activebackground et -activerelief. Les seules valeurs d'élément comprises par cette commande sont arrow1, slider, ou arrow2. Si une autre valeur est spécifiée, aucun élément de la barre de défilement ne sera actif. Si element n'est pas spécifié, la commande retourne le nom de l'élément qui est actuellement actif, ou une chaîne vide si aucun élément n'est actif.
nomFenetre cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande scrollbar.
nomFenetre configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour nomFenetre (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie l'option(s) de widget donnée(s) pour avoir la ou les valeur(s) donnée(s) ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande scrollbar.
nomFenetre delta deltaX deltaY
Retourne un nombre réel indiquant le changement fractionnaire dans le réglage de la barre de défilement qui correspond à un changement donné de la position du curseur. Par exemple, si la barre de défilement est horizontale, le résultat indique de combien le réglage de la barre de défilement doit changer pour déplacer le curseur de deltaX pixels vers la droite (deltaY est ignoré dans ce cas). Si la barre de défilement est verticale, le résultat indique de combien le réglage de la barre de défilement doit changer pour déplacer le curseur de deltaY pixels vers le bas. Les arguments et le résultat peuvent être nuls ou négatifs.
nomFenetre fraction x y
Retourne un nombre réel compris entre 0 et 1 indiquant où le point donné par x et y se situe dans la zone de gouttière de la barre de défilement. La valeur 0 correspond au haut ou à la gauche de la gouttière, la valeur 1 correspond au bas ou à la droite, 0.5 correspond au milieu, etc. X et y doivent être des coordonnées en pixels relatives au widget barre de défilement. Si x et y font référence à un point en dehors de la gouttière, le point le plus proche dans la gouttière est utilisé.
nomFenetre get
Retourne les réglages de la barre de défilement sous forme de liste dont les éléments sont les arguments de la commande set la plus récente.
nomFenetre set first ?last?
Cette commande est utilisée pour mettre à jour la barre de défilement afin qu'elle reflète la nouvelle vue dans le widget associé. First et last sont des valeurs comprises entre 0 et 1, indiquant la première et la dernière fraction de la fenêtre associée qui est visible. Par exemple, si la moitié supérieure d'un document est visible, first sera 0.0 et last sera 0.5. Si la barre de défilement est configurée avec une option -command, cette commande invoquera le interpréteur Tcl pour mettre à jour le widget associé. Si last n'est pas spécifié, il est supposé être égal à first. Cela n'est généralement utilisé que pour des raisons de compatibilité descendante ; les nouvelles applications devraient utiliser la commande moveto ou scroll pour des mises à jour plus efficaces.

LIENS

Les barres de défilement utilisent des liens pour modifier le contenu du widget associé. Les actions des liens sont les suivantes :

<Button-1> (sur une flèche)
Déplace le curseur dans la direction de la flèche et répète le mouvement jusqu'à ce que le bouton soit relâché.
<ButtonRelease-1> (sur une flèche)
Arrête le défilement répété.
<Button-1> (sur la gouttière)
Déplace le curseur vers le centre du clic dans la gouttière.
<B1-Motion> (sur le curseur)
Déplace le curseur et le contenu de la fenêtre associée en conséquence.

Les valeurs des options -jump et -repeatdelay influencent le comportement de ces liens.

EXEMPLE

Crée une barre de défilement verticale et un widget de texte, puis les relie :

	set sb [scrollbar .vscroll -orient vertical]
	text .txt -yscrollcommand "$sb set"
	$sb -command ".txt yview"
	pack .vscroll -side right -fill y
	pack .txt -side left -fill both -expand yes

NOM

scrollbar - widget de barre de défilement

SYNTAXIS

scrollbar ?pathName? ?options?

La syntaxe de la commande scrollbar est la suivante : elle peut être utilisée pour créer une nouvelle fenêtre de barre de défilement ou pour faire référence à une fenêtre de barre de défilement existante.

OPTIONS STANDARD

La barre de défilement prend en charge les options standard suivantes ; voir la page de manuel Tk options(n) pour plus de détails sur les options communes à tous les widgets Tk. Les options -class, -colormap, -cursor, -disabledforeground, -exportselection, -font, -foreground, -highlightcolor, -highlightthickness, -menu, -orient, -relief, -repeatdelay, -repeatinterval, -takefocus, -xscrollcommand, -yscrollcommand.

OPTIONS SPÉCIFIQUES AU WIDGET

-jump boolean
Active ou désactive le mode de saut. Si cette option est vraie, le curseur ne se déplacera que lorsque le bouton de la souris sera relâché. Si elle est fausse, le curseur se déplacera avec le pointeur de la souris. La valeur par défaut est fausse.
-command script
Définit le script Tcl à exécuter lorsque l'utilisateur interagit avec la barre de défilement. Ce script est généralement utilisé pour faire défiler le widget associé. Le script est appelé avec des arguments spéciaux qui décrivent la nouvelle position de la vue. Voir la section COMMANDES DE DÉFILEMENT ci-dessous pour plus de détails.

DESCRIPTION

Le widget scrollbar fournit des commandes de défilement à d'autres widgets. Il est généralement utilisé en combinaison avec un autre widget, tel que text ou listbox, pour fournir un mécanisme de défilement. Le widget scrollbar informe le widget associé de la position actuelle de la vue via son option -command, et le widget associé informe le scrollbar de la taille du contenu et de la portion visible via ses options -xscrollcommand et -yscrollcommand.

ÉLÉMENTS

Un widget scrollbar est composé de plusieurs éléments interactics :

arrow1
La flèche aux extrémités supérieure ou gauche de la barre de défilement.
trough1
La gouttière où le curseur se déplace, avant le curseur.
slider
Le curseur qui représente la portion visible du contenu.
trough2
La gouttière où le curseur se déplace, après le curseur.
arrow2
La flèche aux extrémités inférieure ou droite de la barre de défilement.

L'orientation de la barre de défilement détermine si les éléments sont disposés horizontalement ou verticalement.

COMMANDE WIDGET

La commande de widget scrollbar est utilisée pour interroger ou modifier les propriétés du widget scrollbar. Elle peut également être utilisée pour interagir avec le widget associé.

pathName identify x y
Renvoie le nom de l'élément sous le point donné par x et y (tel que arrow1), ou une chaîne vide si le point ne se trouve dans aucun élément de la barre de défilement. X et y doivent être des coordonnées en pixels relatives au widget de barre de défilement.
pathName set first last
Cette commande est invoquée par le widget associé à la barre de défilement pour informer la barre de défilement de la vue actuelle dans le widget. La commande prend deux arguments, chacun étant une fraction réelle comprise entre 0 et 1. Les fractions décrivent la plage du document qui est visible dans le widget associé. Par exemple, si first est 0.2 et last est 0.4, cela signifie que la première partie du document visible dans la fenêtre se situe à 20 % du document, et la dernière partie visible se situe à 40 % du document.

COMMANDES DE DÉFILEMENT

Lorsque l'utilisateur interagit avec la barre de défilement, par exemple en faisant glisser le curseur, la barre de défilement notifie le widget associé qu'il doit changer sa vue. La barre de défilement effectue la notification en évaluant une commande Tcl générée à partir de l'option -command de la barre de défilement. La commande peut prendre l'une des formes suivantes. Dans chaque cas, prefix est le contenu de l'option -command, qui a généralement une forme telle que « .t yview ».

prefix moveto fraction
Fraction est un nombre réel compris entre 0 et 1. Le widget doit ajuster sa vue de manière à ce que le point donné par fraction apparaisse au début du widget. Si fraction est 0, il fait référence au début du document. 1.0 fait référence à la fin du document, 0.333 fait référence à un point un tiers du document, et ainsi de suite.
prefix scroll number units
Le widget doit ajuster sa vue de number unités. Les unités sont définies de manière à ce qu'elles aient du sens pour le widget, telles que des caractères ou des lignes dans un widget de texte. Number est soit 1, ce qui signifie qu'une unité doit sortir du haut ou de la gauche de la fenêtre, soit -1, ce qui signifie qu'une unité doit sortir du bas ou de la droite de la fenêtre.
prefix scroll number pages
Le widget doit ajuster sa vue de number pages. Il appartient au widget de définir la signification d'une page ; généralement, elle est légèrement inférieure à ce qui rentre dans la fenêtre, de sorte qu'il y ait un léger chevauchement entre les anciennes et les nouvelles vues. Number est soit 1, ce qui signifie que la page suivante doit devenir visible, soit -1, ce qui signifie que la page précédente doit devenir visible.

ANCIENNE SYNTAXIS DES COMMANDES

Dans les versions de Tk antérieures à la version 4.0, les commandes de widget set et get utilisaient une forme différente. Cette forme est toujours prise en charge pour des raisons de compatibilité ascendante, mais elle est dépréciée. Dans l'ancienne syntaxe des commandes, la commande de widget set a la forme suivante :

pathName set totalUnits windowUnits firstUnit lastUnit
Dans cette forme, les arguments sont tous des entiers. TotalUnits donne la taille totale de l'objet affiché dans le widget associé. La signification d'une unité dépend du widget associé ; par exemple, dans un widget d'éditeur de texte, les unités peuvent correspondre à des lignes de texte. WindowUnits indique le nombre total d'unités pouvant rentrer dans la fenêtre associée à la fois. FirstUnit et lastUnit donnent les indices des premières et dernières unités actuellement visibles dans la fenêtre associée (zéro correspond à la première unité de l'objet).

Dans l'ancienne syntaxe, la commande de widget get renvoie une liste de quatre entiers, composée des valeurs totalUnits, windowUnits, firstUnit et lastUnit de la dernière commande de widget set.

Les commandes générées par les barres de défilement ont également une forme différente lorsque l'ancienne syntaxe est utilisée :

prefix unit
Unit est un entier qui indique ce qui doit apparaître en haut ou à gauche de la fenêtre du widget associé. Il a la même signification que les arguments firstUnit et lastUnit de la commande de widget set.

La dernière commande de widget set détermine si l'ancienne syntaxe doit être utilisée ou non. Si elle reçoit deux arguments réels, alors la nouvelle syntaxe sera utilisée à l'avenir, et si elle reçoit quatre arguments entiers, alors l'ancienne syntaxe sera utilisée.

LIAISONS

Tk crée automatiquement des liaisons de classe pour les barres de défilement qui leur donnent le comportement par défaut suivant. Si le comportement est différent pour les barres de défilement verticales et horizontales, le comportement horizontal est décrit entre parenthèses.

[1]
Appuyer sur le bouton 1 sur arrow1 fait défiler la vue dans le widget associé vers le haut (à gauche) d'une unité, de sorte que le document semble se déplacer vers le bas (à droite) d'une unité. Si le bouton est maintenu enfoncé, l'action se répète automatiquement.
[2]
Appuyer sur le bouton 1 sur trough1 fait défiler la vue dans le widget associé vers le haut (à gauche) d'un écran, de sorte que le document semble se déplacer vers le bas (à droite) d'un écran. Si le bouton est maintenu enfoncé, l'action se répète automatiquement.
[3]
Appuyer sur le bouton 1 sur le curseur et le faire glisser fait défiler la vue avec le curseur. Si l'option jump est vraie, la vue ne suit pas le curseur ; elle ne change que lorsque le bouton de la souris est relâché.
[4]
Appuyer sur le bouton 1 sur trough2 fait défiler la vue dans le widget associé vers le bas (à droite) d'un écran, de sorte que le document semble se déplacer vers le haut (à gauche) d'un écran. Si le bouton est maintenu enfoncé, l'action se répète automatiquement.
[5]
Appuyer sur le bouton 1 sur arrow2 fait défiler la vue dans le widget associé vers le bas (à droite) d'une unité, de sorte que le document semble se déplacer vers le haut (à gauche) d'une unité. Si le bouton est maintenu enfoncé, l'action se répète automatiquement.
[6]
Si le bouton 2 est enfoncé sur la gouttière ou le curseur, il positionne la vue en fonction de la position de la souris ; faire glisser la souris avec le bouton 2 enfoncé fait défiler la vue avec la souris. Si le bouton 2 est enfoncé sur l'une des flèches, il produit le même comportement qu'en appuyant sur le bouton 1.
[7]
Si le bouton 1 est enfoncé avec la touche Control enfoncée, alors si la souris est sur arrow1 ou trough1, la vue se déplace vers le tout début (gauche) du document ; si la souris est sur arrow2 ou trough2, la vue se déplace vers le tout fin (droite) du document ; si la souris est ailleurs, le clic du bouton n'a aucun effet.
[8]
Dans les barres de défilement verticales, les touches Haut et Bas ont le même comportement que les clics de souris sur arrow1 et arrow2, respectivement. Dans les barres de défilement horizontales, ces touches n'ont aucun effet.
[9]
Dans les barres de défilement verticales, Control-Haut et Control-Bas ont le même comportement que les clics de souris sur trough1 et trough2, respectivement. Dans les barres de défilement horizontales, ces touches n'ont aucun effet.
[10]
Dans les barres de défilement horizontales, les touches Haut et Bas ont le même comportement que les clics de souris sur arrow1 et arrow2, respectivement. Dans les barres de défilement verticales, ces touches n'ont aucun effet.
[11]
Dans les barres de défilement horizontales, Control-Haut et Control-Bas ont le même comportement que les clics de souris sur trough1 et trough2, respectivement. Dans les barres de défilement verticales, ces touches n'ont aucun effet.
[12]
Les touches Page précédente et Page suivante ont le même comportement que les clics de souris sur trough1 et trough2, respectivement.
[13]
La touche Début ajuste la vue au début (bord gauche) du document.
[14]
La touche Fin ajuste la vue à la fin (bord droit) du document.

EXEMPLE

Créez une fenêtre avec un widget text défilant :

toplevel .tl
text .tl.t -yscrollcommand {.tl.s set}
scrollbar .tl.s -command {.tl.t yview}
grid .tl.t .tl.s -sticky nsew
grid columnconfigure .tl 0 -weight 1
grid rowconfigure .tl 0 -weight 1

NOM

scrollbar - Configuration et contrôle des barres de défilement du système.

SYNOPSIS

scrollbar [options]

DESCRIPTION

Le programme scrollbar est utilisé pour configurer et contrôler le comportement des barres de défilement dans l'ensemble du système. Il permet d'ajuster la largeur, la couleur, la forme et d'autres propriétés visuelles des barres de défilement pour améliorer l'accessibilité et l'esthétique.

OPTIONS

--width <largeur>
Définit la largeur de la barre de défilement en pixels.
--color <couleur>
Définit la couleur de la barre de défilement. Peut être un nom de couleur (par exemple, "blue") ou un code hexadécimal (par exemple, "#0000FF").
--style <style>
Définit le style de la barre de défilement. Les options possibles incluent "flat", "rounded", "gradient".
--show-arrows
Affiche les flèches de défilement aux extrémités de la barre.
--hide-arrows
Masque les flèches de défilement.
--default
Rétablit les paramètres par défaut des barres de défilement.
-h, --help
Affiche l'aide et quitte.
-v, --version
Affiche les informations de version et quitte.

EXEMPLES

Pour définir la largeur de la barre de défilement à 15 pixels et sa couleur à bleu :

scrollbar --width 15 --color blue

Pour rétablir les paramètres par défaut :

scrollbar --default

FICHIERS

~/.config/scrollbar/config Le fichier de configuration utilisateur pour les préférences de la barre de défilement.
