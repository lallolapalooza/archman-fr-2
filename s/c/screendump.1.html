SCREENDUMP(1) Manuel des commandes générales SCREENDUMP(1)

NOM

screendump - vider le contenu d'une console virtuelle vers la sortie standard

SYNTAXE

screendump [options] [N]

DESCRIPTION

La commande screendump vide le contenu de la console virtuelle N, (ou de la console courante si N est omis) vers la sortie standard.

Le simple fait de taper

cat /dev/vcsN
a un effet similaire.

OPTIONS

-V, --version
affiche le numéro de version.
-h, --help
affiche ce message d'utilisation.

NOTES

Pour des raisons de sécurité, screendump utilise les périphériques Linux « écran de console virtuelle » et « écran de console virtuelle avec attributs » pour donner accès à la vidange d'écran.

Assurez-vous que ces fichiers existent, en utilisant

cd /dev for i in 0 1 2 3 ...; do
mknod vcs$i c 7 $i
mknod vcsa$i c 7 `expr 128 + $i`
done

(en remplissant les points de suspension) et donnez aux fichiers de périphérique les permissions appropriées, ou exécutez screendump en tant que root.
