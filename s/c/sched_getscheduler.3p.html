SCHED_GETSCHEDULER(3P) Manuel du programmeur POSIX SCHED_GETSCHEDULER(3P)

PROLOG

Cette page de manuel fait partie du manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sched_getscheduler — obtenir la politique de planification (TEMPS RÉEL)

SYNTAXE

#include <sched.h>
int sched_getscheduler(pid_t pid);

DESCRIPTION

La fonction sched_getscheduler() renvoie la politique de planification du processus spécifié par pid. Si la valeur de pid est négative, le comportement de la fonction sched_getscheduler() n'est pas spécifié.

Les valeurs pouvant être retournées par sched_getscheduler() sont définies dans l'en-tête <sched.h>.

Si un processus spécifié par pid existe, et si le processus appelant a les permissions nécessaires, la politique de planification sera renvoyée pour le processus dont l'identifiant de processus est égal à pid.

Si pid est zéro, la politique de planification sera renvoyée pour le processus appelant.

VALEUR DE RETOUR

En cas de succès, la fonction sched_getscheduler() renvoie la politique de planification du processus spécifié. En cas d'échec, la fonction renvoie -1 et positionne errno pour indiquer l'erreur.

ERREURS

La fonction sched_getscheduler() échouera si :

EPERM
Le processus demandeur n'a pas la permission de déterminer la politique de planification du processus spécifié.
ESRCH
Aucun processus correspondant à celui spécifié par pid ne peut être trouvé.
