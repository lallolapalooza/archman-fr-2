NOM

scor2prt - programme de séparation de partitions pour pmx, un préprocesseur de MusiXTeX

SYNTAXE

scor2prt basename[.pmx]

DESCRIPTION

scor2prt fait partie de pmx(1), un préprocesseur pour MusiXTeX. Il peut créer automatiquement des parties à partir d'une partition en générant un ensemble de fichiers .pmx, un pour chaque partie, à partir d'un seul fichier .pmx pour la partition. L'apparence des parties peut être contrôlée par des commandes spéciales dans le fichier principal. Lisez le manuel PMX pour plus d'informations à ce sujet.

VOIR AUSSI

pmx(1), pmxab(1), musixtex(1), Manuel PMX
