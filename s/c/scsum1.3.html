real function scsum1 (integer n, complex, dimension( * ) cx, integer incx)

SCSUM1 forme la 1-norme du vecteur complexe en utilisant la valeur absolue réelle.

Objectif :

!>
!> SCSUM1 prend la somme des valeurs absolues d'un vecteur complexe
!> et renvoie un résultat en précision simple.
!>
!> Basé sur SCASUM du BLAS de Niveau 1.
!> La modification consiste à utiliser la valeur absolue 'authentique'.
!>

Paramètres

N 
!>          N est ENTIER
!>          Le nombre d'éléments dans le vecteur CX.
!>

CX

!>          CX est un tableau COMPLEXE, dimension (N)
!>          Le vecteur dont les éléments seront additionnés.
!>

INCX

!>          INCX est ENTIER
!>          L'espacement entre les valeurs successives de CX.  INCX > 0.
!>
