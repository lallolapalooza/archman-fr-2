NOM

sctp_recvmsg - Recevoir un message d'un socket SCTP.

SYNOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_recvmsg(int sd, void * msg, size_t len,
                 struct sockaddr * from, socklen_t * fromlen,
                 struct sctp_sndrcvinfo * sinfo, int * msg_flags);

DESCRIPTION

sctp_recvmsg est une fonction de bibliothèque wrapper qui peut être utilisée pour recevoir un message d'un socket tout en utilisant les fonctionnalités avancées de SCTP. sd est le descripteur de socket sur lequel le message pointé par msg d'une longueur de len est reçu.

Si from n'est pas NULL, l'adresse source du message est remplie. L'argument fromlen est un paramètre valeur-résultat, initialisé à la taille du tampon associé à from, et modifié au retour pour indiquer la taille réelle de l'adresse stockée.

sinfo est un pointeur vers une structure sctp_sndrcvinfo qui sera remplie lors de la réception du message. msg_flags est un pointeur vers un entier qui est rempli avec tous les indicateurs de message comme MSG_NOTIFICATION ou MSG_EOR. La valeur du pointeur msg_flags doit être initialisée à 0 pour éviter un comportement inattendu ; msg_flags est également utilisé comme argument d'entrée flags pour la fonction recvmsg.

VALEUR RENVOYÉE

En cas de succès, sctp_recvmsg renvoie le nombre d'octets reçus ou -1 si une erreur s'est produite.
