NOM

schroot-setup - scripts de configuration de schroot

DESCRIPTION

schroot utilise des scripts pour configurer puis nettoyer l'environnement chroot. Le répertoire /etc/schroot/setup.d contient les scripts exécutés lors de la création et de la destruction d'un chroot. Plusieurs variables d'environnement sont définies pendant l'exécution des scripts, ce qui permet de personnaliser leur comportement, en fonction, par exemple, du type de chroot utilisé.

Les scripts sont exécutés dans l'ordre alphabétique de leurs noms, comme ceux exécutés par init(8), en utilisant le même style d'exécution que run-parts(8).

Les scripts de configuration sont tous invoqués avec deux options :

1
L'action à effectuer.
Lorsqu'une session démarre pour la première fois, le chroot est configuré en exécutant les scripts de /etc/schroot/setup.d avec l'option ‘setup-start’. Lorsque la session se termine, les scripts de /etc/schroot/setup.d sont exécutés dans l'ordre inverse avec l'option ‘setup-stop’.
2
L'état du chroot.
Ceci est soit ‘ok’ s'il n'y a pas de problèmes, soit ‘fail’ si quelque chose s'est mal passé. Par exemple, des actions particulières peuvent être ignorées en cas d'échec.

Notez que les scripts doivent être idempotents. Ils doivent être idempotents pendant la phase ‘setup-stop’, car ils peuvent être exécutés plus d'une fois, par exemple en cas d'échec.

ENVIRONNEMENT

Variables générales

AUTH_USER
Le nom d'utilisateur sous lequel les commandes dans le chroot s'exécuteront.
CHROOT_NAME
Le nom du chroot. Notez qu'il s'agit du nom du chroot d'origine avant la création de la session ; vous voudrez probablement plutôt utiliser SESSION_ID.
LIBEXEC_DIR
Le répertoire sous lequel se trouvent les programmes d'aide.
MOUNT_DIR
Le répertoire sous lequel les chroots non-systèmes de fichiers sont montés (par exemple, périphériques bloc et snapshots LVM).
PID
L'identifiant du processus schroot.
PLATFORM
La plateforme système d'exploitation sur laquelle schroot s'exécute. Ceci peut être utilisé pour introduire un comportement spécifique à la plateforme dans les scripts de configuration lorsque nécessaire. Notez que les variables HOST sont probablement ce dont vous avez besoin. Dans le contexte de schroot, la plateforme est la configuration et le comportement supportés pour une architecture donnée, et peut être identique entre différentes architectures.
SESSION_ID
L'identifiant de la session.
VERBOSE
Mis à ‘quiet’ si seuls les messages d'erreur doivent être affichés, ‘normal’ si d'autres messages peuvent être affichés également, et ‘verbose’ si tous les messages peuvent être affichés. Précédemment appelé AUTH_VERBOSITY.
CHROOT_SESSION_CREATE
Mis à ‘true’ si une session sera créée, sinon ‘false’.
CHROOT_SESSION_CLONE
Mis à ‘true’ si une session sera clonée, sinon ‘false’.
CHROOT_SESSION_PURGE
Mis à ‘true’ si une session sera purgée, sinon ‘false’.
CHROOT_SESSION_SOURCE
Mis à ‘true’ si une session sera créée à partir d'un chroot source, sinon ‘false’.
CHROOT_TYPE
Le type du chroot. Ceci est utile pour restreindre une tâche de configuration à des types de chroot particuliers (par exemple, seulement les périphériques bloc ou les snapshots LVM).
CHROOT_NAME
Le nom du chroot. Ceci est utile pour restreindre une tâche de configuration à un chroot particulier, ou à un ensemble de chroots.
CHROOT_ALIAS
Le nom de l'alias utilisé pour sélectionner le chroot. Ceci est utile pour spécialiser une tâche de configuration basée sur l'un de ses noms d'alias alternatifs, ou le nom de chroot par défaut. Par exemple, il pourrait être utilisé pour spécifier des sources supplémentaires dans /etc/apt/sources.list, telles qu'un alias stable-sécurité pour un chroot stable, ou un alias expérimental pour un chroot instable.
CHROOT_DESCRIPTION
La description du chroot.
CHROOT_MOUNT_LOCATION
L'emplacement où monter le chroot. Il est utilisé pour la création et le montage du point de montage.
CHROOT_LOCATION
L'emplacement du chroot à l'intérieur du point de montage. Ceci permet plusieurs chroots sur un seul système de fichiers. Défini pour tous les types de chroots montables.
CHROOT_PATH
Le chemin absolu vers le chroot. C'est typiquement la concaténation de CHROOT_MOUNT_LOCATION et CHROOT_LOCATION. C'est le chemin qui devrait être utilisé pour accéder aux chroots.

Variables chroot simples et de répertoire

Ces types de chroot utilisent uniquement des variables générales.

Variables de fichier

CHROOT_FILE
Le fichier contenant les fichiers du chroot.
CHROOT_FILE_REPACK
Mis à ‘true’ pour reconditionner le chroot dans un fichier archive lors de la fin d'une session, sinon ‘false’.

Variables de chroot montables

Ces variables ne sont définies que pour les types de chroot directement montables.

CHROOT_MOUNT_DEVICE
Le périphérique à monter contenant le chroot.
CHROOT_MOUNT_OPTIONS
Options à passer à mount(8).
CHROOT_LOCATION
L'emplacement du chroot à l'intérieur du point de montage. Ceci permet l'existence de plusieurs chroots sur un seul système de fichiers.

Variables d'union de systèmes de fichiers

CHROOT_UNION_TYPE
Type du système de fichiers d'union.
CHROOT_UNION_MOUNT_OPTIONS
Options de montage du système de fichiers d'union.
CHROOT_UNION_OVERLAY_DIRECTORY

Répertoire de sous-couche du système de fichiers d'union (lecture seule).

schroot-setup(5) — schroot setup configuration

NAME

schroot-setup - Chroot setup scripts

DESCRIPTION

The schroot-setup package provides scripts which are used to setup and configure a chroot environment. The scripts are executed by schroot when a chroot is entered and exited.

The chroot setup scripts are located in the directory /etc/schroot/setup.d. The scripts are executed in alphanumerical order.

The setup scripts are executed with the chroot entered and are expected to perform any necessary setup tasks for the chroot. When exiting the chroot, the scripts are executed again with the chroot exited, and are expected to perform any necessary cleanup tasks.

When a chroot is entered, the chroot setup scripts are executed in the following order:

  1. /etc/schroot/setup.d/00check
  2. /etc/schroot/setup.d/05file
  3. /etc/schroot/setup.d/05fsunion
  4. /etc/schroot/setup.d/05lvm
  5. /etc/schroot/setup.d/10mount
  6. /etc/schroot/setup.d/15binfmt
  7. /etc/schroot/setup.d/15killprocs
  8. /etc/schroot/setup.d/20copyfiles
  9. /etc/schroot/setup.d/20nssdatabases
  10. /etc/schroot/setup.d/50chrootname

When a chroot is exited, the chroot setup scripts are executed in the reverse order:

  1. /etc/schroot/setup.d/50chrootname
  2. /etc/schroot/setup.d/20nssdatabases
  3. /etc/schroot/setup.d/20copyfiles
  4. /etc/schroot/setup.d/15killprocs
  5. /etc/schroot/setup.d/15binfmt
  6. /etc/schroot/setup.d/10mount
  7. /etc/schroot/setup.d/05lvm
  8. /etc/schroot/setup.d/05fsunion
  9. /etc/schroot/setup.d/05file
  10. /etc/schroot/setup.d/00check

The setup scripts are executed with the following environment variables set:

SCHROOT_SESSION_ID
The session id for the current chroot session.
SCHROOT_USER_NAME
The user name that the chroot session is being run as.
SCHROOT_CHROOT_NAME
The name of the chroot.
SCHROOT_CHROOT_DIR
The root directory of the chroot.
SCHROOT_CHROOT_SOURCE
The source for the chroot.
SCHROOT_CHROOT_TYPE
The type of the chroot.
SCHROOT_SETUP_TYPE
The type of setup operation being performed (enter or exit).

ENVIRONMENT

The chroot setup scripts are executed with the environment variables described above. In addition, custom variables set in schroot.conf will be uppercased and set in the environment.

LVM snapshot variables

CHROOT_LVM_SNAPSHOT_NAME
Snapshot name to pass to lvcreate(8).
CHROOT_LVM_SNAPSHOT_DEVICE
The name of the LVM snapshot device.
CHROOT_LVM_SNAPSHOT_OPTIONS
Options to pass to lvcreate(8).

Custom variables

Custom keys set in schroot.conf will be uppercased and set in the environment as described in schroot.conf(5).

FILES

Setup script configuration

The directory /etc/schroot/default contains the default settings used by setup scripts.

config
Main configuration file read by setup scripts. The format of this file is described in schroot-script-config(5). This is the default value for the script-config key. Note that this was formerly named /etc/schroot/script-defaults. The following files are referenced by default:
copyfiles
A list of files to copy into the chroot from the host system. Note that this was formerly named /etc/schroot/copyfiles-defaults.
fstab
A file in the format described in fstab(5), used to mount filesystems inside the chroot. The mount location is relative to the root of the chroot. Note that this was formerly named /etc/schroot/mount-defaults.
nssdatabases
System databases (as described in /etc/nsswitch.conf on GNU/Linux systems) to copy into the chroot from the host. Note that this was formerly named /etc/schroot/nssdatabases-defaults.

Setup scripts

The directory /etc/schroot/setup.d contains the chroot setup scripts.

00check
Print debugging diagnostics and perform basic sanity checking.
05file
Unpack, clean up, and repack file-based chroots.
05fsunion
Create and remove union filesystems.
05lvm
Create and remove LVM snapshots.
10mount
Mount and unmount filesystems.
15binfmt
Sets up the QEMU user emulator using binfmt-support. This permits a chroot for a different CPU architecture to be used transparently, providing an alternative to cross-compiling or whole-machine emulation.
15killprocs
Kill processes still running inside the chroot when ending a session, which would prevent unmounting of filesystems and cleanup of any other resources.
20copyfiles
Copy files from the host system into the chroot. Configure networking by copying hosts and resolv.conf, for example.
20nssdatabases
Configure system databases by copying passwd, shadow, group etc. into the chroot.
50chrootname
Set the chroot name (/etc/debian_chroot) in the chroot. This may be used by the shell prompt to display the current chroot.
