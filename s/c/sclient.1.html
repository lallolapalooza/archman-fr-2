NOM

sclient - exemple de client Kerberos version 5

SYNTAXE

sclient hôte_distant

DESCRIPTION

sclient est une application d'exemple, principalement utile à des fins de test. Elle contacte un serveur d'exemple sserver(8) et s'authentifie auprès de celui-ci à l'aide de tickets Kerberos version 5, puis affiche la réponse du serveur.

ENVIRONNEMENT

Voir kerberos(7) pour une description des variables d'environnement Kerberos.

VOIR AUSSI

kinit(1), sserver(8), kerberos(7)
