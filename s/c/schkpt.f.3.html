Documentation de la fonction/sous-programme

sous-programme schkpt (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nns, entier, dimension( * ) nsval, réel thresh, logique tsterr, réel, dimension( * ) a, réel, dimension( * ) d, réel, dimension( * ) e, réel, dimension( * ) b, réel, dimension( * ) x, réel, dimension( * ) xact, réel, dimension( * ) work, réel, dimension( * ) rwork, entier nout)

SCHKPT

Objectif :

!>
!> SCHKPT teste SPTTRF, -TRS, -RFS et -CON
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de la matrice N.
!>

NNS

!>          NNS est un ENTIER
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau d'ENTIERS, dimension (NNS)
!>          Les valeurs du nombre de membres de droite NRHS.
!>

THRESH

!>          THRESH est un RÉEL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui signale si les sorties d'erreur doivent être testées.
!>

A

!>          A est un tableau de RÉELS, dimension (NMAX*2)
!>

D

!>          D est un tableau de RÉELS, dimension (NMAX*2)
!>

E

!>          E est un tableau de RÉELS, dimension (NMAX*2)
!>

B

!>          B est un tableau de RÉELS, dimension (NMAX*NSMAX)
!>          où NSMAX est la plus grande entrée dans NSVAL.
!>

X

!>          X est un tableau de RÉELS, dimension (NMAX*NSMAX)
!>

XACT

!>          XACT est un tableau de RÉELS, dimension (NMAX*NSMAX)
!>

WORK

!>          WORK est un tableau de RÉELS, dimension
!>                      (NMAX*max(3,NSMAX))
!>

RWORK

!>          RWORK est un tableau de RÉELS, dimension
!>                      (max(NMAX,2*NSMAX))
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité pour la sortie.
!>
