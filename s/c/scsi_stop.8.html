NOM

scsi_stop - arrête (désactive) un ou plusieurs disques SCSI

SYNTAXE

scsi_stop [--aide] [--verbeux] [--attendre] PÉRIPHÉRIQUE [PÉRIPHÉRIQUE]*

DESCRIPTION

Ce script shell bash appelle l'utilitaire sg_start sur chaque PÉRIPHÉRIQUE donné. Le but est de désactiver (arrêter) chaque PÉRIPHÉRIQUE donné.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-h, --aide
affiche le message d'utilisation puis quitte.
-v, --verbeux
augmente le niveau de verbosité.
-w, --attendre
attend que l'arrêt (désactivation) sur chaque PÉRIPHÉRIQUE donné soit terminé. L'action par défaut est d'effectuer chaque arrêt en mode immédiat.

NOTES

L'utilitaire sg_start appelle la commande SCSI START STOP UNIT et peut soit démarrer (activer) soit arrêter (désactiver) un disque SCSI en fonction des options de ligne de commande données.

STATUT DE SORTIE

Le statut de sortie de ce script est 0 en cas de succès. Sinon, le statut de sortie est celui de la dernière commande sg_start appelée. Voir la page de manuel sg3_utils(8).
