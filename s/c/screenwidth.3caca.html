NAME

caca_conio_text_info - structure holding console text information

SYNOPSIS

struct caca_conio_text_info {
  unsigned char attr;
  unsigned char curx;
  unsigned char cury;
};

Detailed Description

This structure is used by caca_get_console_info(3) to return information about the console text.
