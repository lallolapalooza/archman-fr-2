SCHKQL

Objectif :

!>
!> SCHKQL teste SGEQLF, SORGQL et SORMQL.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau logique, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NM

!>          NM est un entier
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'entiers, dimension (NM)
!>          Les valeurs de la dimension de ligne de la matrice M.
!>

NN

!>          NN est un entier
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice N.
!>

NNB

!>          NNB est un entier
!>          Le nombre de valeurs de NB et NX contenues dans les
!>          vecteurs NBVAL et NXVAL. Les paramètres de blocage sont utilisés
!>          par paires (NB,NX).
!>

NBVAL

!>          NBVAL est un tableau d'entiers, dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NXVAL

!>          NXVAL est un tableau d'entiers, dimension (NNB)
!>          Les valeurs du point de croisement NX.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un réel
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour obtenir
!>          l'impression de chaque ratio de test, utiliser THRESH = 0.
!>

TSTERR

!>          TSTERR est une logique
!>          Indicateur qui signale si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un entier
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau réel, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau réel, dimension (NMAX*NMAX)
!>

AQ

!>          AQ est un tableau réel, dimension (NMAX*NMAX)
!>

AL

!>          AL est un tableau réel, dimension (NMAX*NMAX)
!>

AC

!>          AC est un tableau réel, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau réel, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau réel, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau réel, dimension (NMAX*NRHS)
!>

TAU

!>          TAU est un tableau réel, dimension (NMAX)
!>

WORK

!>          WORK est un tableau réel, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau réel, dimension (NMAX)
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité pour la sortie.
!>
