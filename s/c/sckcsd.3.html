SCKCSD

Objectif:

!>
!> SCKCSD teste SORCSD :
!>        le CSD d'une matrice orthogonale M par M, X, partitionnée en
!>        [ X11 X12; X21 X22 ]. X11 est P par Q.
!>

Paramètres

NM 
!>          NM est un entier (INTEGER)
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'entiers (INTEGER array), dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

PVAL

!>          PVAL est un tableau d'entiers (INTEGER array), dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice P.
!>

QVAL

!>          QVAL est un tableau d'entiers (INTEGER array), dimension (NM)
!>          Les valeurs de la dimension des colonnes de la matrice Q.
!>

NMATS

!>          NMATS est un entier (INTEGER)
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrice. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour le test. Si NMATS < NTYPES, une ligne d'entrée
!>          supplémentaire est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'entiers (INTEGER array), dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires. Les
!>          éléments du tableau doivent être compris entre 0 et 4095, sinon
!>          ils seront réduits modulo 4096, et ISEED(4) doit être impair.
!>          En sortie, la graine suivante dans la séquence aléatoire après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un réel (REAL)
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

MMAX

!>          MMAX est un entier (INTEGER)
!>          La valeur maximale autorisée pour M, utilisée pour dimensionner
!>          les tableaux de travail.
!>

X

!>          X est un tableau de réels (REAL array), dimension (MMAX*MMAX)
!>

XF

!>          XF est un tableau de réels (REAL array), dimension (MMAX*MMAX)
!>

U1

!>          U1 est un tableau de réels (REAL array), dimension (MMAX*MMAX)
!>

U2

!>          U2 est un tableau de réels (REAL array), dimension (MMAX*MMAX)
!>

V1T

!>          V1T est un tableau de réels (REAL array), dimension (MMAX*MMAX)
!>

V2T

!>          V2T est un tableau de réels (REAL array), dimension (MMAX*MMAX)
!>

THETA

!>          THETA est un tableau de réels (REAL array), dimension (MMAX)
!>

IWORK

!>          IWORK est un tableau d'entiers (INTEGER array), dimension (MMAX)
!>

WORK

!>          WORK est un tableau de réels (REAL array)
!>

RWORK

!>          RWORK est un tableau de réels (REAL array)
!>

NIN

!>          NIN est un entier (INTEGER)
!>          Le numéro de l'unité pour l'entrée.
!>

NOUT

!>          NOUT est un entier (INTEGER)
!>          Le numéro de l'unité pour la sortie.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : Sortie réussie
!>          > 0 : Si SLAROR retourne un code d'erreur, sa valeur absolue est retournée.
!>
