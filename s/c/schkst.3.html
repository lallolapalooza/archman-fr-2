!>
!> SCHKST  vérifie les routines du problème de valeurs propres symétriques.
!>
!>    SSYTRD factorise A en  U S U' , où ' signifie transposée,
!>    S est symétrique tridiagonale, et U est orthogonale.
!>    SSYTRD peut utiliser soit seulement le triangle inférieur, soit seulement le triangle
!>    supérieur de A ; SCHKST vérifie les deux cas.
!>    U est représentée comme un produit de transformations de Householder
!>    dont les vecteurs sont stockés dans les n-1 premières colonnes de V,
!>    et dont les facteurs d'échelle sont dans TAU.
!>
!>    SSPTRD fait la même chose que SSYTRD, sauf que A et V sont stockées
!>    au format  .
!>
!>    SORGTR construit la matrice U à partir du contenu de V et TAU.
!>
!>    SOPGTR construit la matrice U à partir du contenu de VP et TAU.
!>
!>    SSTEQR factorise S en  Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale.  D2 est la matrice des
!>    valeurs propres calculées lorsque Z n'est pas calculée.
!>
!>    SSTERF calcule D3, la matrice des valeurs propres, par la
!>    méthode PWK, qui ne produit pas de vecteurs propres.
!>
!>    SPTEQR factorise S en  Z4 D4 Z4' , pour une
!>    matrice tridiagonale symétrique définie positive.
!>    D5 est la matrice des valeurs propres calculées lorsque Z n'est pas
!>    calculée.
!>
!>    SSTEBZ calcule des valeurs propres sélectionnées.  WA1, WA2 et
!>    WA3 désigneront les valeurs propres calculées avec une grande
!>    précision absolue, avec différentes options de plage.
!>    WR désignera les valeurs propres calculées avec une grande
!>    précision relative.
!>
!>    SSTEIN calcule Y, les vecteurs propres de S, étant donné les
!>    valeurs propres.
!>
!>    SSTEDC factorise S en Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale (option 'I'). Elle peut aussi
!>    mettre à jour une matrice orthogonale d'entrée, généralement la sortie
!>    de SSYTRD/SORGTR ou SSPTRD/SOPGTR (option 'V'). Elle peut
!>    aussi simplement calculer les valeurs propres (option 'N').
!>
!>    SSTEMR factorise S en Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale (option 'I').  SSTEMR
!>    utilise la Représentation Relativement Robuste lorsque cela est possible.
!>
!> Lorsque SCHKST est appelée, un certain nombre de tailles de matrices () et un
!> certain nombre de types de matrices sont spécifiés.  Pour chaque taille ()
!> et chaque type de matrice, une matrice sera générée et utilisée
!> pour tester les routines de valeurs propres symétriques. Pour chaque matrice, un certain nombre
!> de tests seront effectués :
!>
!> (1)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='U', ... )
!>
!> (2)     | I - UV' | / ( n ulp )        SORGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='L', ... )
!>
!> (4)     | I - UV' | / ( n ulp )        SORGTR( UPLO='L', ... )
!>
!> (5-8)   Identique à 1-4, mais pour SSPTRD et SOPGTR.
!>
!> (9)     | S - Z D Z' | / ( |S| n ulp ) SSTEQR('V',...)
!>
!> (10)    | I - ZZ' | / ( n ulp )        SSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        SSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si les vraies valeurs propres (calculées par comptage de sturm)
!>         de S sont dans THRESH de
!>         celles dans D1.  2*THRESH si elles ne le sont pas.  (Testé à l'aide de
!>         SSTECH)
!>
!> Pour S définie positive,
!>
!> (14)    | S - Z4 D4 Z4' | / ( |S| n ulp ) SPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4' | / ( n ulp )        SPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       SPTEQR('N',...)
!>
!> Lorsque S est également diagonalement dominante par le facteur gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          SSTEBZ( 'A', 'E', ...)

!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              SSTEBZ( 'I', 'E', ...)
!>

!>

!>
!> (22)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('I')
!>
!> (23)    | I - ZZ' | / ( n ulp )           SSTEDC('I')
!>
!> (24)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('V')
!>
!> (25)    | I - ZZ' | / ( n ulp )           SSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           SSTEDC('V') et
!>                                              SSTEDC('N')
!>

!> une haute précision relative.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,

!> (30)    | I - ZZ' | / ( n ulp )           SSTEMR('V', 'I')

SCHKST - détection d'erreurs et comparaison de routines de calcul de valeurs propres

SCHKST

La routine SCHKST vérifie les routines de calcul de valeurs propres et de vecteurs propres d'une matrice symétrique creuse. Elle teste la précision des résultats en comparant différentes méthodes de calcul et en calculant un indicateur d'erreur. 

SUBROUTINE SCHKST( NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT, A, LDA, AP, SD, SE, D1, D2, D3, D4, D5, WA1, WA2, WA3, WR, U, LDU, V, VP, TAU, Z, WORK, LWORK, IWORK, LIWORK )

En gros, le test est l'un des suivants : 

( max { min | WA2(i)-WA3(j) | } +
   i     j
   max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
      i     j
     SSTEMR('N', 'A') vs. SSTEMR('V', 'A')

Les sont spécifiés par un tableau NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.

Les sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si DOTYPE(j) est .VRAI., alors la matrice de type sera générée.

Actuellement, la liste des types possibles est :

  1. La matrice nulle.
  2. La matrice identité.
  3. Une matrice diagonale avec des entrées régulièrement espacées 1, ..., ULP et des signes aléatoires. (ULP = (premier nombre supérieur à 1) - 1 )
  4. Une matrice diagonale avec des entrées géométriquement espacées 1, ..., ULP et des signes aléatoires.
  5. Une matrice diagonale avec des entrées 1, ULP, ..., ULP et des signes aléatoires.
  6. Identique à (4), mais multiplié par SQRT( seuil de débordement )
  7. Identique à (4), mais multiplié par SQRT( seuil de sous-dépassement )
  8. Une matrice de la forme U' D U, où U est orthogonale et D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires sur la diagonale.
  9. Une matrice de la forme U' D U, où U est orthogonale et D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires sur la diagonale.
  10. Une matrice de la forme U' D U, où U est orthogonale et D a des entrées 1, ULP,..., ULP avec des signes aléatoires sur la diagonale.
  11. Identique à (8), mais multiplié par SQRT( seuil de débordement )
  12. Identique à (8), mais multiplié par SQRT( seuil de sous-dépassement )
  13. Matrice symétrique avec des entrées aléatoires choisies parmi (-1,1).
  14. Identique à (13), mais multiplié par SQRT( seuil de débordement )
  15. Identique à (13), mais multiplié par SQRT( seuil de sous-dépassement )
  16. Identique à (8), mais les éléments diagonaux sont tous positifs.
  17. Identique à (9), mais les éléments diagonaux sont tous positifs.
  18. Identique à (10), mais les éléments diagonaux sont tous positifs.
  19. Identique à (16), mais multiplié par SQRT( seuil de débordement )
  20. Identique à (16), mais multiplié par SQRT( seuil de sous-dépassement )
  21. Une matrice tridiagonale à dominante diagonale avec des entrées diagonales géométriquement espacées 1, ..., ULP.

Paramètres

NSIZES 
NSIZES est un entier
     Le nombre de tailles de matrices à utiliser. S'il est zéro,
     SCHKST ne fait rien. Il doit être au moins zéro.

NN 

NN est un tableau d'entiers, dimension (NSIZES)
     Un tableau contenant les tailles à utiliser pour les matrices.
     Les valeurs nulles seront ignorées. Les valeurs doivent être au moins
     zéro.

NTYPES 

NTYPES est un entier
     Le nombre d'éléments dans DOTYPE. S'il est zéro, SCHKST
     ne fait rien. Il doit être au moins zéro. S'il est MAXTYP+1
     et que NSIZES est 1, alors un type supplémentaire, MAXTYP+1, est
     défini, qui consiste à utiliser la matrice présente dans A. Ceci
     n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
     DOTYPE(MAXTYP+1) est .VRAI. .

DOTYPE 

DOTYPE est un tableau logique, dimension (NTYPES)
     Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN, une
     matrice de cette taille et de type j sera générée.
     Si NTYPES est inférieur au nombre maximum de types
     définis (PARAMÈTRE MAXTYP), alors les types NTYPES+1 à
     MAXTYP ne seront pas générés. Si NTYPES est supérieur
     à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
     seront ignorés.

ISEED 

ISEED est un tableau d'entiers, dimension (4)
     À l'entrée, ISEED spécifie la graine du générateur de nombres
     aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
     sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
     être impair. Le générateur de nombres aléatoires utilise une séquence
     linéaire congruente limitée à de petits entiers, et devrait donc
     produire des nombres aléatoires indépendants de la machine. Les
     valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées dans
     l'appel suivant à SCHKST pour continuer la même séquence de nombres
     aléatoires.

THRESH 

THRESH est un nombre réel
     Un test sera compté comme si l'indicateur d'erreur, calculé comme
     décrit ci-dessus, dépasse THRESH. Notez que l'erreur
     est mise à l'échelle pour être O(1), donc THRESH devrait être un multiple raisonnablement
     petit de 1, par exemple, 10 ou 100. En particulier,
     il ne doit pas dépendre de la précision (simple ou double)
     ou de la taille de la matrice. Il doit être au moins zéro.

NOUNIT 

NOUNIT est un entier
     Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
     (par exemple, si une routine renvoie IINFO différent de 0.)

A 

A est un tableau réel de
                                   dimension ( LDA , max(NN) )
     Utilisé pour contenir la matrice dont les valeurs propres doivent être
     calculées. À la sortie, A contient la dernière matrice réellement
     utilisée.

LDA 

LDA est un entier
     La dimension principale de A. Elle doit être
     au moins 1 et au moins max( NN ).

AP 

AP est un tableau réel de
                       dimension( max(NN)*max(NN+1)/2 )
     La matrice A stockée au format compacté.

SD 

SD est un tableau réel de
                          dimension( max(NN) )
     La diagonale de la matrice tridiagonale calculée par SSYTRD.
     À la sortie, SD et SE contiennent la forme tridiagonale de
     la matrice dans A.

SE 

SE est un tableau réel de
                          dimension( max(NN) )
     La sous-diagonale de la matrice tridiagonale calculée par
     SSYTRD. À la sortie, SD et SE contiennent la forme tridiagonale de
     la matrice dans A.

D1 

D1 est un tableau réel de
                          dimension( max(NN) )
     Les valeurs propres de A, calculées par SSTEQR simultanément
     avec Z. À la sortie, les valeurs propres dans D1 correspondent à la
     matrice dans A.

D2 

D2 est un tableau réel de
                          dimension( max(NN) )
     Les valeurs propres de A, calculées par SSTEQR si Z n'est pas
     calculé. À la sortie, les valeurs propres dans D2 correspondent à la
     matrice dans A.

D3 

D3 est un tableau réel de
                          dimension( max(NN) )
     Les valeurs propres de A, calculées par SSTERF. À la sortie, les
     valeurs propres dans D3 correspondent à la matrice dans A.

D4 

D4 est un tableau réel de
                          dimension( max(NN) )
     Les valeurs propres de A, calculées par SPTEQR(V).
     ZPTEQR décompose S en Z4 D4 Z4*
     À la sortie, les valeurs propres dans D4 correspondent à la matrice dans A.

D5 

D5 est un tableau réel de
                          dimension( max(NN) )
     Les valeurs propres de A, calculées par SPTEQR(N)
     lorsque Z n'est pas calculé. À la sortie, les
     valeurs propres dans D4 correspondent à la matrice dans A.

WA1 

WA1 est un tableau réel de
                          dimension( max(NN) )
     Toutes les valeurs propres de A, calculées avec une haute précision
     absolue, avec différentes options de plage.
     calculées par SSTEBZ.

WA2 

WA2 est un tableau réel de
                          dimension( max(NN) )
     Valeurs propres sélectionnées de A, calculées avec une haute précision
     absolue, avec différentes options de plage.
     calculées par SSTEBZ.
     Choisir des valeurs aléatoires pour IL et IU, et demander les
     valeurs propres de rang IL à IU.

WA3 

WA3 est un tableau réel de
                          dimension( max(NN) )
     Valeurs propres sélectionnées de A, calculées avec une haute précision
     absolue, avec différentes options de plage.
     calculées par SSTEBZ.
     Déterminer les valeurs VL et VU des valeurs propres de rang IL et IU
     et demander toutes les valeurs propres dans cette plage.

WR 

WR est un tableau réel de
                          dimension( max(NN) )
     Toutes les valeurs propres de A, calculées avec une haute précision
     absolue, avec différentes options.
     calculées par SSTEBZ.

U 

U est un tableau réel de
                             dimension( LDU, max(NN) ).
     La matrice orthogonale calculée par SSYTRD + SORGTR.

LDU 

LDU est un entier
     La dimension principale de U, Z et V. Elle doit être au moins 1
     et au moins max( NN ).

V 

V est un tableau réel de
                             dimension( LDU, max(NN) ).
     Les vecteurs de Householder calculés par SSYTRD pour réduire A en
     forme tridiagonale. Les vecteurs calculés avec UPLO='U' sont
     dans le triangle supérieur, et les vecteurs calculés avec UPLO='L'
     sont dans le triangle inférieur. (Comme décrit dans SSYTRD, la
     sous- et sur-diagonale ne sont pas mises à 1, bien que le
     vecteur de Householder réel ait un 1 à cette position. Les
     routines qui utilisent V, comme SORGTR, placent ces entrées à
     1 avant de les utiliser, puis les restaurent plus tard.)

VP 

VP est un tableau réel de
                       dimension( max(NN)*max(NN+1)/2 )
     La matrice V stockée au format compacté.

TAU 

TAU est un tableau réel de
                          dimension( max(NN) )
     Les facteurs de Householder calculés par SSYTRD pour réduire A
     en forme tridiagonale.

Z 

Z est un tableau réel de
                             dimension( LDU, max(NN) ).
     La matrice orthogonale de vecteurs propres calculée par SSTEQR,
     SPTEQR, et SSTEIN.

WORK 

WORK est un tableau réel de
                      dimension( LWORK )

LWORK 

LWORK est un entier
     Le nombre d'éléments dans WORK. Il doit être au moins
     1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2
     où Nmax = max( NN(j), 2 ) et lg = log base 2.

IWORK 

IWORK est un tableau d'entiers,
     Espace de travail.

LIWORK 

LIWORK est un entier
GER !> Le nombre d'entrées dans IWORK. Il doit être au moins !> 6 + 6*Nmax + 5 * Nmax * lg Nmax !> où Nmax = max( NN(j), 2 ) et lg = log base 2. !>

RESULT
