But:

!>
!> SCSDTS teste SORCSD, qui, étant donné une matrice orthogonale partitionnée M-par-M
!> X,
!>              Q  M-Q
!>       X = [ X11 X12 ] P   ,
!>           [ X21 X22 ] M-P
!>
!> calcule la CSD
!>
!>       [ U1    ]**T * [ X11 X12 ] * [ V1    ]
!>       [    U2 ]      [ X21 X22 ]   [    V2 ]
!>
!>                             [  I  0  0 |  0  0  0 ]
!>                             [  0  C  0 |  0 -S  0 ]
!>                             [  0  0  0 |  0  0 -I ]
!>                           = [---------------------] = [ D11 D12 ] .
!>                             [  0  0  0 |  I  0  0 ]   [ D21 D22 ]
!>                             [  0  S  0 |  0  C  0 ]
!>                             [  0  0  I |  0  0  0 ]
!>
!> et aussi SORCSD2BY1, qui, étant donné
!>          Q
!>       [ X11 ] P   ,
!>       [ X21 ] M-P
!>
!> calcule la CSD 2-par-1
!>
!>                                     [  I  0  0 ]
!>                                     [  0  C  0 ]
!>                                     [  0  0  0 ]
!>       [ U1    ]**T * [ X11 ] * V1 = [----------] = [ D11 ] ,
!>       [    U2 ]      [ X21 ]        [  0  0  0 ]   [ D21 ]
!>                                     [  0  S  0 ]
!>                                     [  0  0  I ]
!>

!>          RESULT(11) = norm( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(12) = norm( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(13) = norm( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(14) = norm( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(15) = 0        si THETA est en ordre croissant et
!>                               tous les angles sont dans [0,pi/2] 
!>                     = ULPINV   sinon.
!>          ( EPS2 = MAX( norm( I - X'*X ) / M, ULP ). )
!>

NOM

scsdts - Implémente la conversion de chaînes de caractères de valeurs booléennes en chaînes de caractères de valeurs entières.

SYNTAXE

SUBROUTINE SCSDTS(
        in: INTEGER,
        out: CHARACTER(LEN=*)
    )

Documentation de fonction/sous-routine

La sous-routine SCSDTS convertit une valeur entière représentant une valeur booléenne en une chaîne de caractères représentant la même valeur booléenne.

Dans ce contexte, une valeur entière de 0 est considérée comme fausse (.FALSE.) et toute autre valeur entière est considérée comme vraie (.TRUE.).

La chaîne de caractères de sortie contiendra l'une des chaînes suivantes :

  • ".FALSE." si l'entrée est 0.
  • ".TRUE." si l'entrée est différente de 0.

La chaîne de caractères de sortie est supposée être suffisamment longue pour contenir la chaîne résultante. Si elle est trop courte, le comportement n'est pas spécifié.

in

Un entier représentant la valeur booléenne à convertir.

  • 0 : Faux
  • Non-zéro : Vrai
out

Une chaîne de caractères de longueur variable qui contiendra la représentation textuelle de la valeur booléenne d'entrée.
