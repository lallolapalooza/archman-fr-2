Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NM

!>          NM est un ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'ENTIERS, de dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, de dimension (NN)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NNS

!>          NNS est un ENTIER
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau d'ENTIERS, de dimension (NNS)
!>          Les valeurs du nombre de membres de droite NRHS.
!>

NNB

!>          NNB est un ENTIER
!>          Le nombre de valeurs de NB et NX contenues dans les
!>          tableaux NBVAL et NXVAL. Les paramètres de blocage sont utilisés
!>          par paires (NB,NX).
!>

NBVAL

!>          NBVAL est un tableau d'ENTIERS, de dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NXVAL

!>          NXVAL est un tableau d'ENTIERS, de dimension (NNB)
!>          Les valeurs du point de croisement NX.
!>

THRESH

!>          THRESH est un RÉEL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          imprimer tous les ratios de test, utilisez THRESH = 0.
!>

A

!>          A est un tableau de RÉELS, de dimension (MMAX*NMAX)
!>          où MMAX est la valeur maximale de M dans MVAL et NMAX est la
!>          valeur maximale de N dans NVAL.
!>

COPYA

!>          COPYA est un tableau de RÉELS, de dimension (MMAX*NMAX)
!>

B

!>          B est un tableau de RÉELS, de dimension (MMAX*NSMAX)
!>          où MMAX est la valeur maximale de M dans MVAL et NSMAX est la
!>          valeur maximale de NRHS dans NSVAL.
!>

COPYB

!>          COPYB est un tableau de RÉELS, de dimension (MMAX*NSMAX)
!>

S

!>          S est un tableau de RÉELS, de dimension
!>                      (min(MMAX,NMAX))
!>

TAU

!>          TAU est un tableau de RÉELS, de dimension (MMAX)
!>

WORK

!>          WORK est un tableau de RÉELS, de dimension
!>                      (MMAX*NMAX + 4*NMAX + MMAX)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, de dimension (2*NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>
