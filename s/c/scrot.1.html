scrot(1) utilitaire de capture d'écran en ligne de commande scrot(1)

NOM

scrot - utilitaire de capture d'écran en ligne de commande

SYNTAXE

scrot [-bcfhimopuvz] [-a X,Y,L,H] [-C NOM] [-D AFFICHAGE] [-d SEC] [-e COMMANDE]
      [-k OPT] [-l STYLE] [-M NUM] [-n OPTS] [-q NUM] [-s OPTS] [-t % | LxH]
      [-w NUM] [[-F] FICHIER]

DESCRIPTION

scrot (SCReenshOT) est un utilitaire simple de capture d'écran en ligne de commande, il utilise imlib2 pour capturer et sauvegarder des images.

scrot possède de nombreuses fonctionnalités utiles :

  • Prise en charge de multiples formats d'image : JPG, PNG, GIF, et autres.
  • La qualité de la capture d'écran est configurable.
  • Il est possible de capturer une fenêtre spécifique ou une zone rectangulaire à l'écran.

Comme scrot est un utilitaire en ligne de commande, il peut facilement être utilisé dans des scripts et pour des usages novateurs. Par exemple, scrot peut être utilisé pour surveiller un serveur X en l'absence d'un utilisateur.

scrot est un logiciel libre sous licence MIT-feh.

OPTIONS

-a, --autoselect X,Y,L,H
Choisir de manière non interactive un rectangle commençant à la position X,Y et de résolution L par H.
-b, --border
Lors de la sélection d'une fenêtre, capturer également la bordure du gestionnaire de fenêtres (WM). Utiliser avec -s pour activer la fenêtre de mise au point.
-C, --class NOM
NOM est le nom de la classe de la fenêtre. Associé avec -k.
-c, --count
Afficher un compte à rebours lorsqu'utilisé avec -d.
-D, --display AFFICHAGE
AFFICHAGE est le périphérique d'affichage à utiliser ; voir X(7).
-d, --delay [b]SEC
Attendre SEC secondes avant de prendre une capture. Lorsque le préfixe `b` est donné, par exemple `-d b8`, le délai sera appliqué avant la sélection.
-e, --exec COMMANDE
Exécuter COMMANDE sur l'image sauvegardée.
-F, --file FICHIER
Spécifier le fichier de sortie. Si FICHIER est "-", scrot enverra l'image sur la sortie standard. Le nom du fichier est développé selon le format spécifié dans CHAINES SPÉCIALES. Le fichier de sortie peut être spécifié via l'option -F, ou comme argument sans option.
-f, --freeze
Geler l'écran lorsque -s est utilisé.
-h, --help
Afficher l'aide et quitter.
-i, --ignorekeyboard
Ne pas sortir suite à une entrée clavier. ESC permet toujours de sortir.
-k, --stack[=OPT]
Capturer les fenêtres empilées/superposées et les joindre. Un gestionnaire de composition (Composite Manager) en cours d'exécution est nécessaire pour que cela fonctionne correctement. OPT est une lettre de jointure optionnelle : v/h (verticale/horizontale). Par défaut : h
-l, --line STYLE
STYLE indique le style de la ligne lorsque l'option -s est utilisée ; voir STYLE DE SÉLECTION.
-M, --monitor NUM
Capturer le moniteur Xinerama numéro NUM.
-m, --multidisp
Pour les écrans multiples, capturer tous les écrans dans l'ordre.
-o, --overwrite
Par défaut, scrot n'écrase pas le fichier de sortie FICHIER, utilisez cette option pour l'activer.
-p, --pointer
Capturer le pointeur de la souris.
-q, --quality NUM
NUM doit être compris entre [1, 100]. Une valeur plus élevée représente une meilleure qualité d'image et une valeur plus basse une qualité d'image médiocre. L'effet de ce drapeau dépend du format de fichier, voir la section QUALITÉ DE COMPRESSION. Par défaut : 75.
-s, --select[=OPTS]
Sélectionner interactivement une fenêtre ou un rectangle avec la souris, utiliser les touches fléchées pour redimensionner. Voir les options -l et -f. OPTS est optionnel ; voir MODE DE SÉLECTION.
-t, --thumb % | LxH
Générer également une miniature. L'argument représente la résolution de la miniature : si l'argument est un seul nombre, il représente un pourcentage de la résolution de la capture d'écran complète ; s'il s'agit de 2 nombres séparés par un caractère "x", il s'agit d'une résolution. Si l'une des dimensions de la résolution est 0, elle est remplacée par un nombre qui maintient le rapport d'aspect de la capture d'écran complète. Exemples : 10, 25, 320x240, 500x200, 100x0, 0x480.
-u, --focused, --focussed
Utiliser la fenêtre actuellement focalisée.
-v, --version
Afficher les informations de version et quitter.
-w, --window WID
Identifiant de la fenêtre à capturer. WID doit être un identifiant valide (voir xwininfo(1)).
-Z, --compression LVL
Niveau de compression à utiliser, LVL doit être compris entre [0, 9]. Un niveau de compression plus élevé offre une taille de fichier plus petite au détriment d'une vitesse d'encodage/sauvegarde plus lente. L'effet de ce drapeau dépend du format de fichier, voir la section QUALITÉ DE COMPRESSION. Par défaut : 7.
-z, --silent
Empêcher les bips sonores.
--format FMT
Spécifier le format du fichier de sortie. Par exemple "--format png". Si aucun format n'est spécifié, scrot utilisera l'extension du fichier pour déterminer le format. Si le nom du fichier n'a pas non plus d'extension, PNG sera utilisé comme solution de repli.
--list-options[=OPT]
Lister toutes les options du programme. Si l'argument est "tsv", il renvoie une liste séparée par des TAB destinée aux scripts. Par défaut, c'est "human". Notez que le format TSV n'est pas stable et peut changer dans le futur.

CHAINES SPÉCIALES

Les paramètres -e, -F et FICHIER peuvent accepter des spécificateurs de format qui sont développés par scrot lorsqu'ils sont rencontrés. Il existe deux types de spécificateurs de format : les caractères précédés d'un '%' sont interprétés par strftime(3). Le second type est interne à scrot et est précédé d'un '$'. Les spécificateurs suivants sont reconnus par scrot :

    $$   Un '$' littéral.
    $a   Le nom d'hôte du système.
    $F   Le format du fichier de sortie.
    $f   Le chemin complet de l'image (ignoré lorsqu'utilisé dans le nom de fichier).
    $h   La hauteur de l'image.
    $m   Le chemin complet de la miniature (ignoré lorsqu'utilisé dans le nom de fichier).
    $n   Le nom de base de l'image (ignoré lorsqu'utilisé dans le nom de fichier).
    $p   La taille en pixels de l'image.
    $s   La taille de l'image en octets (ignoré lorsqu'utilisé dans le nom de fichier).
    $t   Le format de fichier de l'image (ignoré lorsqu'utilisé dans le nom de fichier).
    $w   La largeur de l'image.
    $W   Le nom de la fenêtre (uniquement pour --select, --focused et --window).
    \n   Un saut de ligne littéral (ignoré lorsqu'utilisé dans le nom de fichier).
Exemple : 
    $ scrot '%Y-%m-%d_$wx$h.png' -e 'du -h $f'
Ceci créerait un fichier PNG avec un nom similaire à 2000-10-30_2560x1024.png et afficherait l'utilisation du disque avec du(1).

MODE DE SÉLECTION

Lors de l'utilisation de -s, vous pouvez facultativement indiquer l'action à effectuer avec la zone de sélection. Certaines actions autorisent également des paramètres optionnels.

    capture             Capturer la zone de sélection, cette action est par défaut

scrot(1) - Page de manuel

NOM

scrot - capture d'écran simple

SYNOPIS

scrot [OPTIONS] [FILE]

DESCRIPTION

scrot est un utilitaire de capture d'écran simple et sans dépendances, basé sur imlib2. Il est conçu pour être rapide et facile à utiliser.

Par défaut, scrot capture l'intégralité de l'écran et enregistre l'image dans un fichier nommé selon un format de date et d'heure (par exemple, 2022-10-27-14-15-30.png) dans le répertoire courant.

Si un nom de fichier est spécifié, il est utilisé pour enregistrer l'image. Sinon, un nom de fichier généré par défaut est utilisé.

OPTIONS

GÉNÉRALES

-b, --border
Dessine une bordure autour de la capture d'écran.
-c, --cursor
Inclut le curseur de la souris dans la capture d'écran.
-d, --daemon
Démarre scrot en tant que démon. Utile pour prendre des captures d'écran programmées.
-e, --exec COMMAND
Exécute la commande spécifiée après la capture d'écran. Le nom de fichier de la capture d'écran est passé en argument à la commande sous la forme $f. Par défaut, la commande est vide.
-F, --format FORMAT
Spécifie le format de sortie de l'image. Les formats pris en charge dépendent des bibliothèques installées (par exemple, png, jpg, gif, etc.). Par défaut, png.
-f, --focused
Capture la fenêtre active (celle qui a le focus). Utile avec la sélection de fenêtre.
-h, --help
Affiche un message d'aide et quitte.
-l, --line STYLE
Spécifie le style de la ligne de sélection. Voir la section SELECTION STYLE pour plus de détails.
-m, --multidisplay
Capture tous les écrans connectés. Ignoré si un seul écran est présent.
-o, --overwrite
Écrase les fichiers existants portant le même nom.
-p, --program
Utilise le nom du programme appelant comme nom de fichier. Utile lorsque scrot est appelé par un autre programme.
-q, --quality NUM
Spécifie la qualité de compression pour les formats où elle est applicable (par exemple, JPEG). Le niveau de qualité est compris entre 1 et 100. Par défaut: 75.
-s, --select
Permet de sélectionner une zone de l'écran pour la capture. Voir la section SELECTION MODE pour plus de détails.
-t, --thumb WIDTHxHEIGHT
Crée une miniature de la capture d'écran avec les dimensions spécifiées. Les dimensions sont au format WxH (par exemple, 150x100). Le nom du fichier de la miniature sera préfixé par "thumb-".
-u, --use-locale
Utilise les paramètres régionaux du système pour le nom de fichier généré. Par défaut, les noms de fichiers utilisent le format UTC.
-v, --version
Affiche les informations de version et quitte.
-D, --display DISPLAY
Spécifie le serveur d'affichage X à utiliser.
-x, --remove-shadow
Supprime les ombres des fenêtres capturées (si le compositeur le prend en charge).

CHAÎNES SPÉCIALES

Dans le nom de fichier de sortie, les chaînes spéciales suivantes peuvent être utilisées :

%Y Année (par exemple, 2022)
%m Mois (par exemple, 10)
%d Jour (par exemple, 27)
%H Heure (par exemple, 14)
%M Minute (par exemple, 15)
%S Seconde (par exemple, 30)
%L Milliseconde (par exemple, 123)
%T Fuseau horaire (par exemple, +0200)
%W Semaine de l'année (par exemple, 43)
%w Jour de la semaine (0=Dimanche, 6=Samedi) (par exemple, 4)

Ces chaînes peuvent être utilisées dans le nom de fichier spécifié sur la ligne de commande. Si aucun nom de fichier n'est spécifié, scrot utilise par défaut le format %Y-%m-%d-%H-%M-%S.png.

MODE DE SÉLECTION

Lorsque l'option -s est utilisée, scrot entre en mode de sélection. Plusieurs modes de sélection sont disponibles :

hole
Crée un trou dans la capture d'écran, ne montrant que la zone sélectionnée. Le reste de la capture d'écran est transparent.
hide,IMAGE
Masque la zone de sélection en dessinant une zone de couleur (ou une image) par-dessus. Le nom de l'image à utiliser comme couverture peut être spécifié optionnellement. L'image a priorité sur la couleur.
blur,MONTANT
Floute la zone de sélection. Le niveau de flou peut être spécifié optionnellement. Le montant doit être compris entre 1 et 30. Par défaut: 18.

Dans les modes 'hole' et 'hide', la couleur de la zone est indiquée par la propriété 'color' du style de ligne, et l'opacité de la couleur (ou de l'image) est indiquée par la propriété 'opacity'.

Si le mode 'hide' utilise une image qui n'a pas de canal alpha, le paramètre d'opacité sera ignoré et l'image sera dessinée de manière totalement opaque.

Exemples :

    $ scrot --select=hide
    $ scrot -shole --line color="Dark Salmon",opacity=200
    $ scrot -sblur,10
    $ scrot -shide,stamp.png --line opacity=120

STYLE DE SÉLECTION

En utilisant -s, vous pouvez spécifier le style de la ligne avec -l.

-l prend une liste de spécificateurs séparés par des virgules comme argument :

    style=STYLE     STYLE est soit "solid" soit "dash" sans guillemets.
    width=NUM       NUM est un nombre de pixels compris entre 1 et 8.
    color="COULEUR"   La couleur est un code hexadécimal HTML ou le nom d'une
                    couleur. Les codes couleur HTML sont composés d'un signe dièse
                    '#' suivi d'une séquence de 3 nombres hexadécimaux à 2 chiffres
                    qui représentent respectivement le rouge, le vert et le bleu.
                    Exemples : #FF0000 (rouge), #E0FFFF (cyan clair), #000000 (noir).
    opacity=NUM     NUM est compris entre 0 et 255. 255 signifie 100% opaque, 0
                    signifie 100% transparent. Pour l'opacité de la ligne, cela
                    n'est efficace que si le compositeur prend en charge
                    _NET_WM_WINDOW_OPACITY.
    mode=MODE       MODE peut être "auto", "edge" ou "classic" sans guillemets.
                    "edge" est la nouvelle sélection, "classic" utilise l'ancienne.
                    "auto" utilise "edge" si aucun compositeur ne fonctionne et que
                    l'indicateur -f n'est pas actif, sinon "classic". "edge" ignore
                    le spécificateur de style, "classic" ignore le spécificateur
                    d'opacité.
Sans l'option -l, un style par défaut est utilisé : 
    mode=auto,style=solid,width=1,opacity=100
Exemple : 
    $ scrot -l style=dash,width=3,color="red" -s

QUALITÉ DE COMPRESSION

Pour les formats sans perte (par exemple PNG), l'option de qualité est ignorée. Pour les formats avec perte où la qualité et la compression sont liées (par exemple JPEG), la compression sera ignorée. Et pour les formats d'image où la qualité et la compression peuvent être définies indépendamment (par exemple WebP, JXL), les deux indicateurs sont respectés.

EXEMPLES

Voici quelques exemples d'utilisation de scrot avec d'autres utilitaires.

Copier la capture d'écran dans le presse-papiers en utilisant xclip(1) :

  $ scrot - | xclip -selection clipboard -target image/png
Prendre une capture d'écran et optimiser sa taille avec optipng(1) : 
  $ scrot -e 'optipng -o4 $f'
Sélectionner une fenêtre par PID avec xdo(1) : 
  $ scrot -w $(xdo id -p PID)
Prendre une capture d'écran et l'annoter avec ImageMagick(1) : 
  $ scrot - | convert -pointsize 64 -gravity North -annotate '+16+16' 'hello, world!' - out.png
