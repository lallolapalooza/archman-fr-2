Objectif :

!>
!> SCHKBD vérifie les routines de décomposition en valeurs singulières (SVD).
!>
!> SGEBRD réduit une matrice réelle générale m par n, A, en une forme
!> bidiagonale supérieure ou inférieure B par une transformation orthogonale :
!> Q' * A * P = B (ou A = Q * B * P'). La matrice B est bidiagonale supérieure
!> si m >= n et bidiagonale inférieure si m < n.
!>
!> SORGBR génère les matrices orthogonales Q et P' à partir de SGEBRD.
!> Notez que Q et P ne sont pas nécessairement carrées.
!>
!> SBDSQR calcule la décomposition en valeurs singulières de la matrice
!> bidiagonale B comme B = U S V'. Il est appelé trois fois pour calculer :
!>    1) B = U S1 V', où S1 est la matrice diagonale des valeurs singulières
!>       et les colonnes des matrices U et V sont les vecteurs singuliers
!>       gauches et droits, respectivement, de B.
!>    2) Identique à 1), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>    3) A = (UQ) S (P'V'), la SVD de la matrice d'origine A.
!> De plus, SBDSQR a une option pour appliquer la matrice orthogonale gauche
!> U à une matrice X, utile dans les applications de moindres carrés.
!>
!> SBDSDC calcule la décomposition en valeurs singulières de la matrice
!> bidiagonale B comme B = U S V' en utilisant la méthode diviser pour régner.
!> Il est appelé deux fois pour calculer :
!>    1) B = U S1 V', où S1 est la matrice diagonale des valeurs singulières
!>       et les colonnes des matrices U et V sont les vecteurs singuliers
!>       gauches et droits, respectivement, de B.
!>    2) Identique à 1), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>
!> SBDSVDX calcule la décomposition en valeurs singulières de la matrice
!> bidiagonale B comme B = U S V' en utilisant la dichotomie et l'itération
!> inverse. Il est appelé six fois pour calculer :
!>    1) B = U S1 V', RANGE='A', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    2) Identique à 1), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>    3) B = U S1 V', RANGE='I', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    4) Identique à 3), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>    5) B = U S1 V', RANGE='V', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    6) Identique à 5), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>
!> Pour chaque paire de dimensions de matrice (M,N) et chaque type de matrice
!> sélectionné, une matrice A de taille m par n et une matrice X de taille
!> m par NRHS sont générées. Les dimensions du problème sont les suivantes :
!>    A :        M x N
!>    Q :        M x min(M,N) (mais M x M si NRHS > 0)
!>    P :        min(M,N) x N
!>    B :        min(M,N) x min(M,N)
!>    U, V :     min(M,N) x min(M,N)
!>    S1, S2 :   diagonale, ordre min(M,N)
!>    X :        M x NRHS
!>
!> Pour chaque matrice générée, 14 tests sont effectués :
!>
!> Tests SGEBRD et SORGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Test SBDSQR sur la matrice bidiagonale B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), où Y = Q' X
!>                                                  et   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contient min(M,N) valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (9)   | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                   calculer U et V.
!>
!> (10)  0 si les vraies valeurs singulières de B sont dans THRESH
!>      de celles de S1.  2*THRESH si ce n'est pas le cas.  (Testé en utilisant
!>      SSVDCH)
!>
!> Test SBDSQR sur la matrice A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Test SBDSDC sur la matrice bidiagonale B

!> (15)  | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'

!> (16)  | I - U' U | / ( min(M,N) ulp )
!>
!> (17)  | I - VT VT' | / ( min(M,N) ulp )
!>
!> (18)  S1 contient min(M,N) valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (19)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                   calculer U et V.
!>  Test SBDSVDX sur la matrice bidiagonale B
!>
!>  (20)  | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!>  (21)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (22)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (23)  S1 contient min(M,N) valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!>  (24)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                    calculer U et V.
!>
!>  (25)  | S1 - U' B VT' | / ( |S| n ulp )    SBDSVDX('V', 'I')
!>
!>  (26)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (27)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (28)  S1 contient min(M,N) valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!>  (29)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                    calculer U et V.
!>
!>  (30)  | S1 - U' B VT' | / ( |S1| n ulp )   SBDSVDX('V', 'V')
!>
!>  (31)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (32)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (33)  S1 contient min(M,N) valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!>  (34)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans

HKBD(3)

HKBD — Interface du clavier matériel.

SYNOPSIS

#include <hkbd.h>

DESCRIPTION

La bibliothèque hkbd fournit des fonctions pour interagir avec le clavier matériel. Elle permet de lire les entrées du clavier et de contrôler certaines de ses fonctionnalités.

Fonctions

  • hkbd_init(): Initialise le clavier.
  • hkbd_get_key(): Lit une touche pressée.
  • hkbd_set_leds(int leds): Contrôle les LEDs du clavier.
  • hkbd_shutdown(): Ferme le clavier.

EXEMPLES

#include <stdio.h>
#include <hkbd.h>

int main() {
    hkbd_init();
    printf("Appuyez sur une touche (Ctrl+C pour quitter) :\n");
    char key = hkbd_get_key();
    printf("Touche pressée : %c\n", key);
    hkbd_shutdown();
    return 0;
}
