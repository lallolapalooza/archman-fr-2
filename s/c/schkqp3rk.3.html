Documentation de la fonction/sous-routine

sous-routine schkqp3rk (logique, dimension( * ) dotype, entier nm, entier, dimension( * ) mval, entier nn, entier, dimension( * ) nval, entier nns, entier, dimension( * ) nsval, entier nnb, entier, dimension( * ) nbval, entier, dimension( * ) nxval, réel thresh, réel, dimension( * ) a, réel, dimension( * ) copya, réel, dimension( * ) b, réel, dimension( * ) copyb, réel, dimension( * ) s, réel, dimension( * ) tau, réel, dimension( * ) work, entier, dimension( * ) iwork, entier nout)

SCHKQP3RK

Purpose:

!>
!> SCHKQP3RK teste SGEQP3RK.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NM

!>          NM est un entier
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'entiers, dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

NN

!>          NN est un entier
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NNS

!>          NNS est un entier
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau d'entiers, dimension (NNS)
!>          Les valeurs du nombre de membres du côté droit NRHS.
!>

NNB

!>          NNB est un entier
!>          Le nombre de valeurs de NB et NX contenues dans les
!>          vecteurs NBVAL et NXVAL. Les paramètres de blocage sont utilisés
!>          par paires (NB,NX).
!>

NBVAL

!>          NBVAL est un tableau d'entiers, dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NXVAL

!>          NXVAL est un tableau d'entiers, dimension (NNB)
!>          Les valeurs du point de croisement NX.
!>

THRESH

!>          THRESH est un nombre réel
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

A

!>          A est un tableau réel, dimension (MMAX*NMAX)
!>          où MMAX est la valeur maximale de M dans MVAL et NMAX est la
!>          valeur maximale de N dans NVAL.
!>

COPYA

!>          COPYA est un tableau réel, dimension (MMAX*NMAX)
!>

B

!>          B est un tableau réel, dimension (MMAX*NSMAX)
!>          où MMAX est la valeur maximale de M dans MVAL et NSMAX est la
!>          valeur maximale de NRHS dans NSVAL.
!>

COPYB

!>          COPYB est un tableau réel, dimension (MMAX*NSMAX)
!>

S

!>          S est un tableau réel, dimension
!>                      (min(MMAX,NMAX))
!>

TAU

!>          TAU est un tableau réel, dimension (MMAX)
!>

WORK

!>          WORK est un tableau réel, dimension
!>                      (MMAX*NMAX + 4*NMAX + MMAX)
!>

IWORK

!>          IWORK est un tableau d'entiers, dimension (2*NMAX)
!>

NOUT

!>          NOUT est un entier
!>          Le numéro de l'unité de sortie.
!>
