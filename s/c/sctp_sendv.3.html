sctp_sendv(3)

NOM

sctp_sendv - Envoyer des messages depuis un socket SCTP de manière extensible.

SYNOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_sendv(int sd, const struct iovec * iov, int iovcnt,
               struct sockaddr *addrs, int addrcnt, void * info,
               socklen_t infolen, unsigned int infotype, int flags);

DESCRIPTION

sctp_sendv offre un moyen extensible pour une application de communiquer différents attributs d'envoi à la pile SCTP lors de l'envoi d'un message. Il existe trois types d'attributs qui peuvent être utilisés pour décrire un message à envoyer. Ce sont les structures sctp_sndinfo, sctp_prinfo et sctp_authinfo. La structure suivante, sctp_sendv_spa, est définie pour être utilisée lorsque plus d'un des attributs ci-dessus sont nécessaires pour décrire un message à envoyer.


struct sctp_sendv_spa {
uint32_t sendv_flags;
struct sctp_sndinfo sendv_sndinfo;
struct sctp_prinfo sendv_prinfo;
struct sctp_authinfo sendv_authinfo;
};

Le champ sendv_flags contient un OU bit à bit de SCTP_SEND_SNDINFO_VALID, SCTP_SEND_PRINFO_VALID, et SCTP_SEND_AUTHINFO_VALID indiquant si les champs sendv_sndinfo/sendv_prinfo/sendv_authinfo contiennent des informations valides.

sd est le descripteur de socket. iov est le tampon de collecte, les données dans le tampon sont traitées comme un seul message utilisateur. iovcnt est le nombre d'éléments dans iov. addrs est un tableau d'adresses à utiliser pour établir une association ou une seule adresse à utiliser pour envoyer le message, et NULL est passé si l'appelant ne souhaite ni établir d'association ni envoyer le message à une adresse spécifique. addrcnt est le nombre d'adresses dans le tableau addrs. info est un pointeur vers le tampon contenant l'attribut associé au message à envoyer, et le type est indiqué par le paramètre info_type. infolen est la longueur de info, en octets. infotype identifie le type des informations fournies dans info, et les valeurs actuellement définies sont les suivantes :

SCTP_SENDV_NOINFO
Aucune information n'est fournie. Le paramètre info est un pointeur NULL, et infolen est 0.
SCTP_SENDV_SNDINFO
Le paramètre info pointe vers une structure sctp_sndinfo.
SCTP_SENDV_PRINFO
Le paramètre info pointe vers une structure sctp_prinfo.
SCTP_SENDV_AUTHINFO
Le paramètre info pointe vers une structure sctp_authinfo.
SCTP_SENDV_SPA
Le paramètre info pointe vers une structure sctp_sendv_spa.

flags Les mêmes drapeaux que ceux utilisés par les drapeaux de l'appel sendmsg() (par exemple, MSG_DONTROUTE).

VALEUR RENVOYÉE

En cas de succès, sctp_sendv renvoie le nombre d'octets envoyés ou -1 si une erreur s'est produite.
