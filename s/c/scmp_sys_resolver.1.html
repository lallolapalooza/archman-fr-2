NOM

scmp_sys_resolver - Résoudre les appels système

SYNTAXE

scmp_sys_resolver [-h] [-a ARCH ] [-t] NOM_APPEL_SYSTÈME | NUMÉRO_APPEL_SYSTÈME

DESCRIPTION

Cette commande résout les noms et les numéros d'appels système par rapport à l'architecture donnée fournie dans l'argument optionnel ARCH. Si l'architecture n'est pas fournie en ligne de commande, l'architecture native est utilisée. Si l'argument "-t" est spécifié avec un nom d'appel système, l'appel système sera traduit si nécessaire pour l'architecture donnée. L'argument "-t" n'a aucun effet si un numéro d'appel système est spécifié.

Dans certaines combinaisons d'architecture et d'appel système, un numéro d'appel système négatif sera affiché. Un numéro d'appel système négatif indique que l'appel système n'est pas défini pour l'architecture donnée et est traité de manière spéciale par libseccomp en fonction de l'opération.

-a ARCH
L'architecture à utiliser pour résoudre l'appel système. Les valeurs valides pour ARCH sont "x86", "x86_64", "x32", "arm", "aarch64", "mips", "mipsel", "mips64", "mipsel64", "mips64n32", "mipsel64n32", "parisc", "parisc64", "ppc", "ppc64", "ppc64le", "s390" et "s390x".
-t
Si nécessaire, traduisez le nom de l'appel système vers le numéro d'appel système approprié, même si le nom de l'appel système est différent, par exemple socket(2) sur x86.
-h
Un simple affichage d'utilisation sur une ligne.

VALEUR DE RETOUR

Retourne zéro en cas de succès, des valeurs errno en cas d'échec.

NOTES

Le site du projet libseccomp, avec plus d'informations et le dépôt de code source, peut être trouvé sur https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, est actuellement en cours de développement, veuillez signaler tout bug sur le site du projet ou directement à l'auteur.
