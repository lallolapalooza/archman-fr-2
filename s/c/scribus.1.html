scribus(1) Manuel des commandes générales scribus(1)

NOM

scribus - application de publication assistée par ordinateur WYSIWYG multiplateforme

SYNOPSIS

scribus [-h|--help] [-v|--version] [-l|--lang langue] [-la|--langs-available] [-f|--file|--] [nom_de_fichier]

DESCRIPTION

Scribus est un logiciel de publication assistée par ordinateur open source. Il offre une édition WYSIWYG authentique, d'excellentes fonctionnalités d'exportation PDF, et une large gamme d'autres options d'entrée et de sortie.

Veuillez consulter la documentation de Scribus à l'adresse http://docs.scribus.net/ ou l'aide intégrée du programme pour une documentation plus complète et à jour.

Cette page de manuel ne fournit que des résumés de certains aspects de l'utilisation du programme. Son objectif principal est de vous permettre de trouver rapidement et facilement la documentation complète.

OPTIONS

Les options définitives se trouvent dans l'énoncé d'utilisation du programme. Exécutez : scribus --help pour afficher l'énoncé d'utilisation.

-l, --lang xx
Remplace la locale système et lance Scribus dans la langue xx. La langue est spécifiée avec les mêmes codes de langue POSIX que ceux utilisés dans les variables d'environnement LANG et LC_ALL. Par exemple, l'anglais peut être sélectionné avec 'en' (anglais générique), 'en_GB' (anglais britannique), 'en_US' (anglais américain), etc. De même, l'allemand peut être sélectionné avec 'de' ou 'de_DE'.
-la, --langs-available
Affiche une liste des langues pour lesquelles des traductions de l'interface utilisateur sont disponibles. Pour utiliser cette langue, exécutez Scribus en tant que 'scribus -l xx' où xx est le code court de la langue, ou définissez les variables d'environnement de locale comme décrit ci-dessous.
-v, --version
Affiche le numéro de version de Scribus et quitte.
-f, --file
Ouvre le fichier spécifié. Il est possible de passer simplement le nom du fichier comme argument non qualifié au lieu d'utiliser cette option, bien que si le nom commence par un -, vous devrez utiliser --, par ex. 'scribus -- -monfichier.sla'.
-h, --help
Affiche un bref résumé d'utilisation.
-fi, --font-info
Affiche la liste des fichiers de polices lors du démarrage de Scribus. Ceci peut être utilisé pour diagnostiquer les glyphes manquants dans les polices ou les fichiers de polices potentiellement corrompus.
-pi, --profile-info
Affiche la liste des profils de couleur que Scribus peut utiliser. Ceci peut être utilisé pour diagnostiquer les profils de couleur manquants ou corrompus.
-pr, --prefs <nom_de_fichier>
Utilise nom_de_fichier comme chemin pour les préférences données par l'utilisateur.
-py, --python-script <script> [arguments ...]
Exécute le script en Python [avec des arguments optionnels]. Cette option doit être la dernière utilisée.
-ns, --no-splash
Supprime l'affichage de l'écran de démarrage pendant le lancement de Scribus.
-nns, --never-splash
Arrête l'affichage de l'écran de démarrage. Crée un fichier vide appelé .neversplash dans ~/.config/scribus.
-sb, --swap-buttons
Utilise un ordre des boutons de dialogue de droite à gauche (par ex. Annuler/Non/Oui au lieu de Oui/Non/Annuler).
-u, --upgradecheck
Télécharge un fichier depuis notre serveur scribus indiquant les dernières versions disponibles.

ENVIRONNEMENT

Scribus respecte les variables d'environnement de locale standard. D'autres peuvent être utilisées par le biais des bibliothèques sous-jacentes, comme Qt, ou par les programmes utilisés par Scribus. http://docs.scribus.net/ et la documentation du programme peuvent mentionner d'autres variables d'environnement utilisées par Scribus ou les programmes et bibliothèques qu'il utilise.

LC_ALL, LC_MESSAGES, LANG
Locale POSIX. Voir locale(1). Scribus utilise ces trois variables d'environnement, dans l'ordre de priorité indiqué, pour sélectionner la langue (y compris la traduction de l'interface utilisateur) à utiliser. Si aucune n'est définie, il se rabattra sur la locale définie par la bibliothèque Qt sous-jacente.
PATH
Scribus peut rechercher dans le PATH des outils externes si leurs chemins ne sont pas spécifiés absolument. Cela est actuellement le plus susceptible de vous affecter si vous avez plusieurs copies de gs(1) installées. Vous pouvez définir un chemin absolu vers la bonne version de gs(1) dans vos préférences Scribus et contourner la recherche PATH.

Quelques variables d'environnement importantes d'autres programmes sont résumées ici pour plus de commodité, bien que vous devriez vérifier la documentation du programme original si vous rencontrez des problèmes.

GS_FONTPATH
Chemin des polices GhostScript. Affecte le chemin de recherche des polices pour GhostScript, un composant que Scribus utilise pour certaines opérations PostScript. Ajoutez de nouveaux répertoires contenant des polices à cette liste séparée par des deux-points pour aider GhostScript à trouver les polices dans des emplacements non standard. Voir gs(1) et la documentation HTML de GhostScript pour plus d'informations.
GS_LIB
Chemin de la bibliothèque GhostScript. GhostScript recherche dans ce chemin les fichiers Fontmap. Comme GS_FONTPATH, c'est une liste de répertoires séparée par des deux-points. Vous voudrez généralement utiliser GS_FONTPATH à la place, bien que la création d'un fichier Fontmap et l'utilisation de GS_LIB puisse accélérer les choses si vous avez *beaucoup* de polices. Voir gs(1) et la documentation HTML de GhostScript pour plus d'informations.

FICHIERS

$HOME/.config/scribus/
Les préférences utilisateur sont stockées dans $HOME/.config/scribus/ sur Unix ou Linux. La plupart des autres chemins sont configurables depuis les préférences de Scribus. Les préférences de Scribus 1.5 sont distinctes de celles de Scribus 1.3.x. Les préférences utilisateur pour Mac OS X, OS/2 et Windows sont documentées dans les docs d'aide (F1) de Scribus. $HOME/.config/scribus/scribus150.rc Fichier de préférences Scribus - formaté dans un schéma XML personnalisé. Pourrait éventuellement être retiré au profit d'un fichier de préférences au nouveau format. $HOME/.config/scribus/prefs150.xml Les préférences de Scribus 1.5.x sont distinctes de celles de Scribus 1.3.x
$HOME/.fonts/
$HOME/.fonts.conf
/etc/fonts
Fontconfig, la bibliothèque utilisée par Scribus pour localiser les polices, est normalement configurée avec des fichiers dans /etc/fonts, principalement /etc/fonts/fonts.conf et /etc/fonts/local.conf. Elle peut également utiliser un fichier de configuration $HOME/.fonts.conf et des polices dans $HOME/.fonts/. Voir fonts.conf(5) et la documentation de fontconfig pour plus d'informations. Notez que Scribus peut également utiliser son chemin de polices interne pour localiser d'autres polices - voir la boîte de dialogue Préférences et l'aide de scribus.
