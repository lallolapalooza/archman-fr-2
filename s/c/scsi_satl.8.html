NOM

scsi_satl - vérifie le support des périphériques de traduction SCSI vers ATA (SAT)

SYNTAXE

scsi_satl [--help] [--log] [--quiet] [--verbose] PÉRIPHÉRIEQUE

DESCRIPTION

Ce script bash appelle plusieurs commandes SCSI sur le PÉRIPHÉRIEQUE donné, qui est supposé être un périphérique ATA derrière une couche de traduction SCSI vers ATA (SATL). Les résultats de chaque test et un compte de succès/échec sont affichés.

OPTIONS

Les arguments des options longues sont obligatoires, même pour les options courtes.

-h, --help
affiche le message d'utilisation puis quitte.
-L, --log
la sortie vers stderr (de chaque commande SCSI exécutée) est ajoutée à un fichier nommé 'scsi_satl.err' dans le répertoire de travail courant.
-q, --quiet
le niveau de sortie est réduit et affiche généralement uniquement le compte de succès/échec.
-v, --verbose
augmente le niveau de verbosité.

STATUT DE SORTIE

Le statut de sortie de ce script est le nombre d'erreurs "mauvaises" trouvées. Ainsi, un statut de sortie de 0 signifie que toutes les commandes SCSI obligatoires ont fonctionné comme prévu.
