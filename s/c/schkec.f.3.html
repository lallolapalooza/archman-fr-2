sous-routine schkec (real thresh, logical tsterr, integer nin, integer nout)

SCHKEC

But:

!>
!> SCHKEC teste les routines d'estimation de condition des valeurs propres
!>        SLALN2, SLASY2, SLANV2, SLAQTR, SLAEXC,
!>        STRSYL, STREXC, STRSNA, STRSEN, STGEXC
!>
!> Dans tous les cas, la routine parcourt un ensemble fixe d'exemples numériques,
!> les soumet à divers tests et compare les résultats des tests à un seuil THRESH.
!> De plus, STREXC, STRSNA et STRSEN sont testés en lisant des exemples pré-calculés
!> à partir d'un fichier (sur l'unité d'entrée NIN). La sortie est écrite sur
!> l'unité de sortie NOUT.
!>

Paramètres

THRESH 
!>          THRESH est REAL
!>          Seuil pour les tests de résidu. Un rapport de test calculé passe
!>          le seuil s'il est inférieur à THRESH.
!>

TSTERR

!>          TSTERR est LOGICAL
!>          Indicateur qui spécifie si les sorties d'erreur doivent être testées.
!>

NIN

!>          NIN est INTEGER
!>          Le numéro logique de l'unité d'entrée.
!>

NOUT

!>          NOUT est INTEGER
!>          Le numéro logique de l'unité de sortie.
!>
