NOM

sctp_recvv - Recevoir un message d'un socket SCTP de manière extensible.

SYNTAXE

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_recvv(int sd, const struct iovec * iov, int iovlen,
               struct sockaddr * from, socklen_t * fromlen, void * info,
               socklen_t * infolen, unsigned int * infotype, int * flags);

DESCRIPTION

sctp_recvv offre un moyen extensible pour la pile SCTP de transmettre différentes attributs SCTP associés à un message reçu à une application. Il existe deux types d'attributs qui peuvent être retournés par cet appel : l'attribut du message reçu et l'attribut du message suivant dans le tampon de réception. L'appelant active respectivement les options de socket SCTP_RECVRCVINFO et SCTP_RECVNXTINFO pour recevoir ces attributs. Les attributs du message reçu sont retournés dans struct sctp_rcvinfo, et les attributs du message suivant sont retournés dans struct sctp_nxtinfo. Si les deux options sont activées, les deux attributs sont retournés en utilisant la structure suivante.


struct sctp_recvv_rn {
struct sctp_rcvinfo recvv_rcvinfo;
struct sctp_nxtinfo recvv_nxtinfo;
};

sd est le descripteur de socket. iov est le tampon dispersé, et un seul message utilisateur est retourné dans ce tampon. iovlen est le nombre d'éléments dans iov. from est un pointeur vers un tampon qui sera rempli avec l'adresse de l'expéditeur du message reçu. fromlen est un paramètre d'entrée/sortie décrivant la longueur de l'adresse d'origine. info est un pointeur vers le tampon qui contiendra les attributs du message reçu, le type de structure de info est déterminé par le paramètre info_type. infolen est un paramètre d'entrée/sortie décrivant la taille du tampon info. Au retour, infotype est défini sur le type du tampon info, et les valeurs actuellement définies sont les suivantes :

SCTP_RECVV_NOINFO
Si les options SCTP_RECVRCVINFO ou SCTP_RECVNXTINFO ne sont pas activées, aucun attribut ne sera retourné. Si seule l'option SCTP_RECVNXTINFO est activée mais qu'il n'y a pas de message suivant dans le tampon, aucun attribut ne sera retourné. Dans ces cas, *info_type sera défini sur SCTP_RECVV_NOINFO.
SCTP_RECVV_RCVINFO
Le type de info est struct sctp_rcvinfo, et l'attribut concerne le message reçu.
SCTP_RECVV_NXTINFO
Le type de info est struct sctp_nxtinfo, et l'attribut concerne le message suivant dans le tampon de réception. Ceci se produit lorsque seule l'option SCTP_RECVNXTINFO est activée et qu'il y a un message suivant dans le tampon.
SCTP_RECVV_RN
Le type de info est struct sctp_recvv_rn. Le champ recvv_rcvinfo est l'attribut du message reçu, et le champ recvv_nxtinfo est l'attribut du message suivant dans le tampon. Ceci se produit lorsque les deux options SCTP_RECVRCVINFO et SCTP_RECVNXTINFO sont activées et qu'il y a un message suivant dans le tampon de réception.

flags est un pointeur vers un entier qui sera rempli avec tous les drapeaux de message (par exemple, MSG_NOTIFICATION).

VALEUR RETOURNÉE

En cas de succès, sctp_recvv retourne le nombre d'octets reçus ou -1 si une erreur s'est produite.
