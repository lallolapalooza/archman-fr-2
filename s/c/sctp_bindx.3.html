SCTP_BINDX(3) Manuel du programmeur Linux SCTP_BINDX(3)

NOM

sctp_bindx - Ajoute ou supprime des adresses de liaison sur une socket.

SYNOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_bindx(int sd, struct sockaddr * addrs, int addrcnt,
               int flags);

DESCRIPTION

sctp_bindx ajoute ou supprime un ensemble d'adresses de liaison passées dans le tableau addrs à/depuis la socket sd. addrcnt est le nombre d'adresses dans le tableau et le paramètre flags indique si les adresses doivent être ajoutées ou supprimées.

Si sd est une socket IPv4, les adresses passées doivent être des adresses IPv4. Si sd est une socket IPv6, les adresses passées peuvent être des adresses IPv4 ou IPv6.

addrs est un pointeur vers un tableau d'une ou plusieurs adresses de socket. Chaque adresse est contenue dans sa structure appropriée (c'est-à-dire struct sockaddr_in ou struct sockaddr_in6). La famille du type d'adresse doit être utilisée pour distinguer la longueur de l'adresse. L'appelant spécifie le nombre d'adresses dans le tableau avec addrcnt.

Le paramètre flags peut être SCTP_BINDX_ADD_ADDR ou SCTP_BINDX_REM_ADDR. Une application peut utiliser SCTP_BINDX_ADD_ADDR pour associer des adresses supplémentaires à un point d'extrémité après avoir appelé bind(2). SCTP_BINDX_REM_ADDR demande à SCTP de supprimer les adresses données de l'association. Un appelant ne peut pas supprimer toutes les adresses d'une association. Cela échouera avec EINVAL.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'échec, -1 est retourné et errno est correctement défini.

ERREURS

EBADF
sd n'est pas un descripteur valide.
ENOTSOCK
sd est un descripteur de fichier, pas une socket.
EFAULT
Erreur lors de la copie dans ou hors de l'espace d'adressage utilisateur.
EINVAL
Port ou adresse invalide ou tentative de suppression de toutes les adresses d'une association.
EACCES
L'adresse est protégée et l'utilisateur n'est pas le super-utilisateur.
