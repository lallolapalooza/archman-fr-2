SCHKST2STG

Objectif :

!>
!> SCHKST2STG  vérifie les routines du problème de valeurs propres symétriques
!> en utilisant les techniques de réduction en 2 étapes. Comme la génération
!> de Q ou des vecteurs n'est pas disponible dans cette version, nous comparons seulement
!> la valeur propre résultante lors de l'utilisation de la 2 étapes à
!> celle considérée comme référence en utilisant la réduction standard en 1 étape
!> SSYTRD. Pour cela, nous appelons le SSYTRD standard et calculons D1 en
!> utilisant SSTEQR, puis nous appelons le SSYTRD_2STAGE en 2 étapes avec Supérieur et Inférieur
!> et nous calculons D2 et D3 en utilisant SSTEQR puis nous avons remplacé les tests
!> 3 et 4 par les tests 11 et 12. Les tests 1 et 2 restent pour vérifier que
!> les résultats en 1 étape sont corrects et peuvent être considérés comme fiables.
!> Cette routine de test convergera vers le SCHKST dans la prochaine
!> version lorsque les vecteurs et la génération de Q seront implémentés.
!>
!>    SSYTRD factorise A en  U S U' , où ' signifie transposé,
!>    S est symétrique tridiagonale, et U est orthogonale.
!>    SSYTRD peut utiliser soit seulement le triangle inférieur, soit seulement le triangle
!>    supérieur de A ; SCHKST2STG vérifie les deux cas.
!>    U est représenté comme un produit de transformations de Householder,
!>    dont les vecteurs sont stockés dans les n-1 premières colonnes de V, et dont
!>    les facteurs d'échelle sont dans TAU.
!>
!>    SSPTRD fait la même chose que SSYTRD, sauf que A et V sont stockés
!>    en format .
!>
!>    SORGTR construit la matrice U à partir du contenu de V et TAU.
!>
!>    SOPGTR construit la matrice U à partir du contenu de VP et TAU.
!>
!>    SSTEQR factorise S en  Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale.  D2 est la matrice des
!>    valeurs propres calculées lorsque Z n'est pas calculé.
!>
!>    SSTERF calcule D3, la matrice des valeurs propres, par la
!>    méthode PWK, qui ne produit pas de vecteurs propres.
!>
!>    SPTEQR factorise S en  Z4 D4 Z4' , pour une
!>    matrice tridiagonale symétrique définie positive.
!>    D5 est la matrice des valeurs propres calculées lorsque Z n'est pas
!>    calculé.
!>
!>    SSTEBZ calcule des valeurs propres sélectionnées.  WA1, WA2, et
!>    WA3 représenteront les valeurs propres calculées avec une grande
!>    précision absolue, avec différentes options de plage.
!>    WR représentera les valeurs propres calculées avec une grande
!>    précision relative.
!>
!>    SSTEIN calcule Y, les vecteurs propres de S, étant donné les
!>    valeurs propres.
!>
!>    SSTEDC factorise S en Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale (option 'I'). Elle peut également
!>    mettre à jour une matrice orthogonale d'entrée, généralement la sortie
!>    de SSYTRD/SORGTR ou SSPTRD/SOPGTR (option 'V'). Elle peut
!>    également simplement calculer les valeurs propres (option 'N').
!>
!>    SSTEMR factorise S en Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale (option 'I').  SSTEMR
!>    utilise la Représentation Relativement Robuste chaque fois que possible.
!>
!> Lorsque SCHKST2STG est appelée, un certain nombre de matrices  () et un
!> certain nombre de matrices  sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une matrice sera générée et utilisée
!> pour tester les routines de valeurs propres symétriques. Pour chaque matrice, un certain
!> nombre de tests seront effectués :
!>
!> (1)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='U', ... )
!>
!> (2)     | I - UV' | / ( n ulp )        SORGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='L', ... )
!>         remplacé par | D1 - D2 | / ( |D1| ulp ) où D1 est la
!>         matrice des valeurs propres calculée en utilisant S et D2 est la
!>         matrice des valeurs propres calculée en utilisant S_2stage la sortie de
!>         SSYTRD_2STAGE(, ,....). D1 et D2 sont calculées
!>         via SSTEQR('N',...)
!>
!> (4)     | I - UV' | / ( n ulp )        SORGTR( UPLO='L', ... )
!>         remplacé par | D1 - D3 | / ( |D1| ulp ) où D1 est la
!>         matrice des valeurs propres calculée en utilisant S et D3 est la
!>         matrice des valeurs propres calculée en utilisant S_2stage la sortie de
!>         SSYTRD_2STAGE(, ,....). D1 et D3 sont calculées
!>         via SSTEQR('N',...)
!>
!> (5-8)   Identique à 1-4, mais pour SSPTRD et SOPGTR.
!>
!> (9)     | S - Z D Z' | / ( |S| n ulp ) SSTEQR('V',...)
!>
!> (10)    | I - ZZ' | / ( n ulp )        SSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        SSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si les vraies valeurs propres (calculées par comptage sturm)
!>         de S sont dans THRESH de
!>         celles dans D1.  2*THRESH si elles ne le sont pas.  (Testé en utilisant
!>         SSTECH)
!>
!> Pour S définie positive,
!>
!> (14)    | S - Z4 D4 Z4' | / ( |S| n ulp ) SPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4' | / ( n ulp )        SPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       SPTEQR('N',...)
!>
!> Lorsque S est également à dominante diagonale par le facteur gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          SSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              SSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y' | / ( |S| n ulp )  SSTEBZ, SSTEIN
!>
!> (21)    | I - Y Y' | / ( n ulp )          SSTEBZ, SSTEIN
!>
!> (22)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('I')
!>
!> (23)    | I - ZZ' | / ( n ulp )           SSTEDC('I')
!>
!> (24)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('V')
!>
!> (25)    | I - ZZ' | / ( n ulp )           SSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           SSTEDC('V') et
!>                                              SSTEDC('N')
!>
!> Le test 27 est désactivé pour le moment car SSTEMR ne garantit pas une haute précision relative.
!>
!> (27)    max | D6(i) - WR(i)

Paramètres

NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          SCHKST2STG ne fait rien. Il doit être supérieur ou égal à zéro.
!>

NN

!>          NN est un tableau INTEGER, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être supérieures ou égales à
!>          zéro.
!>

NTYPES

!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, SCHKST2STG
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMÈTRE MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau INTEGER, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans le
!>          prochain appel à SCHKST2STG pour continuer la même séquence de nombres aléatoires.
!>

THRESH

!>          THRESH est REAL
!>          Un test sera considéré comme  si la , calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être de l'ordre de O(1), donc THRESH devrait être un multiple raisonnable
!>          de 1, par exemple 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être supérieur ou égal à zéro.
!>

NOUNIT

!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'affichage des messages d'erreur
!>          (par exemple, si une routine renvoie IINFO différent de 0.)
!>

A

!>          A est un tableau REAL de
!>                                  dimension ( LDA , max(NN) )
!>          Utilisé pour contenir la matrice dont les valeurs propres doivent être
!>          calculées. À la sortie, A contient la dernière matrice effectivement
!>          utilisée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. Elle doit être au moins
!>          1 et au moins max( NN ).
!>

AP

!>          AP est un tableau REAL de
!>                      dimension( max(NN)*max(NN+1)/2 )
!>          La matrice A stockée au format compacté.
!>

SD

!>          SD est un tableau REAL de
!>                             dimension( max(NN) )
!>          La diagonale de la matrice tridiagonale calculée par SSYTRD.
!>          À la sortie, SD et SE contiennent la forme tridiagonale de
!>          la matrice dans A.
!>

SE

!>          SE est un tableau REAL de
!>                             dimension( max(NN) )
!>          La sous-diagonale de la matrice tridiagonale calculée par
!>          SSYTRD. À la sortie, SD et SE contiennent la forme tridiagonale de
!>          la matrice dans A.
!>

D1

!>          D1 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par SSTEQR simultanément
!>          avec Z. À la sortie, les valeurs propres dans D1 correspondent à la
!>          matrice dans A.
!>

D2

!>          D2 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par SSTEQR si Z n'est pas
!>          calculée. À la sortie, les valeurs propres dans D2 correspondent à la
!>          matrice dans A.
!>

D3

!>          D3 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par SSTERF. À la sortie, les
!>          valeurs propres dans D3 correspondent à la matrice dans A.
!>

D4

!>          D4 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par SPTEQR(V).
!>          SPTEQR factorise S comme  Z4 D4 Z4*
!>          À la sortie, les valeurs propres dans D4 correspondent à la matrice dans A.
!>

D5

!>          D5 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Les valeurs propres de A, calculées par SPTEQR(N)
!>          lorsque Z n'est pas calculée. À la sortie, les
!>          valeurs propres dans D4 correspondent à la matrice dans A.
!>

WA1

!>          WA1 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Toutes les valeurs propres de A, calculées avec une haute
!>          précision absolue, avec différentes options de plage.
!>          calculées par SSTEBZ.
!>

WA2

!>          WA2 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Valeurs propres sélectionnées de A, calculées avec une haute
!>          précision absolue, avec différentes options de plage.
!>          calculées par SSTEBZ.
!>          Choisir des valeurs aléatoires pour IL et IU, et demander les
!>          valeurs propres de l'indice IL à IU.
!>

WA3

!>          WA3 est un tableau REAL de
!>                             dimension( max(NN) )
!>          Valeurs propres sélectionnées de A, calculées avec une haute
!>          précision absolue, avec différentes options de plage.
!>          calculées par SSTEBZ.
!>          Déterminer les valeurs VL et VU des IL-ème et IU-ème
!>          valeurs propres et demander toutes les valeurs propres dans cette plage.
!>

WR

!>          WR est un tableau REAL de
!>                             dimension( max(NN) )
!>          Toutes les valeurs propres de A, calculées avec une haute
!>          précision absolue, avec différentes options.
!>          calculées par SSTEBZ.
!>

U

!>          U est un tableau REAL de
!>                             dimension( LDU, max(NN) ).
!>          La matrice orthogonale calculée par SSYTRD + SORGTR.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale de U, Z et V. Elle doit être au moins 1
!>          et au moins max( NN ).
!>

V

!>          V est un tableau REAL de
!>                             dimension( LDU, max(NN) ).
!>          Les vecteurs de Householder calculés par SSYTRD lors de la réduction de A en
!>          forme tridiagonale. Les vecteurs calculés avec UPLO='U' sont
!>          dans le triangle supérieur, et les vecteurs calculés avec UPLO='L'
!>          sont dans le triangle inférieur. (Comme décrit dans SSYTRD, les
!>          sous- et super-diagonales ne sont pas mises à 1, bien que le
!>          véritable vecteur de Householder ait un 1 à cette position. La
!>          routine
es qui utilisent V, telles que SORGTR, les définissent à
!>          1 avant de les utiliser, puis les restaurent plus tard.)
!>

VP

!>          VP est un tableau REAL de
!>                      dimension( max(NN)*max(NN+1)/2 )
!>          La matrice V stockée au format compacté.
!>

TAU

!>          TAU est un tableau REAL de
!>                             dimension( max(NN) )
!>          Les facteurs de Householder calculés par SSYTRD lors de la réduction de A
!>          en forme tridiagonale.
!>

Z

!>          Z est un tableau REAL de
!>                             dimension( LDU, max(NN) ).
!>          La matrice orthogonale des vecteurs propres calculée par SSTEQR,
!>          SPTEQR et SSTEIN.
!>

WORK

!>          WORK est un tableau REAL de
!>                      dimension( LWORK )
!>

LWORK

!>          LWORK est un entier
!>          Le nombre d'éléments dans WORK. Cela doit être au moins
!>          1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2
!>          où Nmax = max( NN(j), 2 ) et lg = log base 2.
!>

IWORK

!>          IWORK est un tableau INTEGER
!>          Espace de travail.
!>

LIWORK

!>          LIWORK est un entier
!>          Le nombre d'éléments dans IWORK. Cela doit être au moins
!>                  6 + 6*Nmax + 5 * Nmax * lg Nmax
!>          où Nmax = max( NN(j), 2 ) et lg = log base 2.
!>

RESULT

!>          RESULT est un tableau REAL, dimension (26)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          les dépassements de capacité.
!>

INFO

!>          INFO est un entier
!>          Si 0, alors tout s'est déroulé correctement.
!>           -1: NSIZES < 0
!>           -2: Certains NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 ou LDA < NMAX, où NMAX est max( NN(j) ).
!>          -23: LDU < 1 ou LDU < NMAX.
!>          -29: LWORK trop petit.
!>          Si SLATMR, SLATMS, SSYTRD, SORGTR, SSTEQR, SSTERF,
!>              ou SORMC2 renvoie un code d'erreur, la
!>              valeur absolue est retournée.
!>
