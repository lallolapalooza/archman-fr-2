programme sblat2

SBLAT2

Objectif :

!>
!> Programme de test pour les BLAS de niveau 2 en RÉEL.
!>
!> Le programme doit être piloté par un fichier de données court. Les 18 premiers
!> enregistrements du fichier sont lus à l'aide d'une entrée par listes, les 16 derniers
!> enregistrements sont lus à l'aide du format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 34 lignes suivantes :
!> 'sblat2.out'      NOM DU FICHIER DE SORTIE RÉCAPITULATIF
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉCAPITULATIF
!> 'SBLAT2.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR S'ARRÊTER en cas d'échec.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUILE DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> 0.0 1.0 0.7       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 0.9       VALEURS DE BETA
!> SGEMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SGBMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SSBMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SSPMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> STRMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> STBMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> STPMV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> STRSV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> STBSV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> STPSV  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SGER   T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYR   T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SSPR   T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SSYR2  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!> SSPR2  T INDIQUER F POUR PAS DE TEST. MÊMES COLONNES.
!>
