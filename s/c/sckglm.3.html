Documentation de la fonction/sous-routine

subroutine sckglm (integer nn, integer, dimension( * ) mval, integer, dimension( * ) pval, integer, dimension( * ) nval, integer nmats, integer, dimension( 4 ) iseed, real thresh, integer nmax, real, dimension( * ) a, real, dimension( * ) af, real, dimension( * ) b, real, dimension( * ) bf, real, dimension( * ) x, real, dimension( * ) work, real, dimension( * ) rwork, integer nin, integer nout, integer info)

SCKGLM

Objectif :

!>
!> SCKGLM teste SGGGLM - sous-routine pour résoudre le problème du modèle linéaire généralisé.
!>

Paramètres

NN 
!>          NN est un entier
!>          Le nombre de valeurs de N, M et P contenues dans les vecteurs
!>          NVAL, MVAL et PVAL.
!>

MVAL

!>          MVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice M.
!>

PVAL

!>          PVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice P.
!>

NVAL

!>          NVAL est un tableau d'entiers, dimension (NN)
!>          Les valeurs de la dimension de ligne de matrice N.
!>

NMATS

!>          NMATS est un entier
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximal
!>          de types de matrices), alors tous les types différents sont
!>          générés pour les tests. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la prochaine graine de la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un réel
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESID >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un entier
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau de réels, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau de réels, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau de réels, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau de réels, dimension (NMAX*NMAX)
!>

X

!>          X est un tableau de réels, dimension (4*NMAX)
!>

RWORK

!>          RWORK est un tableau de réels, dimension (NMAX)
!>

WORK

!>          WORK est un tableau de réels, dimension (NMAX*NMAX)
!>

NIN

!>          NIN est un entier
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          > 0 : Si SLATMS renvoie un code d'erreur, sa valeur absolue
!>                 est retournée.
!>
