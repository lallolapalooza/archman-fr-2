sous-programme schklqtp (real thresh, logical tsterr, integer nm, integer, dimension( * ) mval, integer nn, integer, dimension( * ) nval, integer nnb, integer, dimension( * ) nbval, integer nout)

SCHKLQTP

Objectif :

!>
!> SCHKLQTP teste STPLQT et STPMLQT.
!>

Paramètres

THRESH 
!>          THRESH est REAL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est LOGICAL
!>          Indicateur qui détermine si les sorties d'erreur doivent être testées.
!>

NM

!>          NM est INTEGER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau de type INTEGER, de dimension (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

NN

!>          NN est INTEGER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau de type INTEGER, de dimension (NN)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NNB

!>          NNB est INTEGER
!>          Le nombre de valeurs de NB contenues dans le vecteur NBVAL.
!>

NBVAL

!>          NBVAL est un tableau de type INTEGER, de dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NOUT

!>          NOUT est INTEGER
!>          Le numéro d'unité pour la sortie.
!>
