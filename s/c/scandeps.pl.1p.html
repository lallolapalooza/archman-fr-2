NOM

scandeps.pl - Analyser les prérequis de fichiers

SYNTAXE

% scandeps.pl *.pm          # Affiche la section PREREQ_PM pour *.pm
% scandeps.pl -e 'CHAINE'   # Analyse une ligne de commande
% scandeps.pl -B *.pm       # Inclure les modules de base
% scandeps.pl -V *.pm       # Afficher les fichiers de partage/données/autoload
% scandeps.pl -R *.pm       # Ne pas récursionner
% scandeps.pl -C FICHIERCASCADE # Utiliser FICHIERCASCADE pour mettre en cache les dépendances

DESCRIPTION

scandeps.pl est un utilitaire simple qui affiche la section "PREREQ_PM" nécessaire aux modules.

Si l'option "-T" est spécifiée et que vous avez CPANPLUS installé, les modules qui font partie de la distribution d'un module antérieur seront indiqués par "S" ; les modules sans nom de distribution sur CPAN sont marqués par "?".

De plus, si l'option "-B" est spécifiée, les modules appartenant à une distribution perl sur CPAN (et donc non désinstallables par "CPAN.pm" ou "CPANPLUS.pm") sont marqués par "C".

Enfin, les modules qui ont des fichiers d'objet partagé chargeables (nécessitant généralement un compilateur pour l'installation) sont marqués par "X" ; avec l'indicateur "-V", ces fichiers (et tous les autres fichiers trouvés) seront listés avant la sortie principale. De plus, tous les fichiers de module dont le code analysé dépend mais qui n'ont pas été trouvés (et donc pas analysés récursivement) sont listés. Ceux-ci peuvent inclure des modules manquants ou de faux positifs. C'est-à-dire, des modules dont votre code ne dépend pas (sur cette plateforme particulière) mais qui ont été capturés par l'heuristique de toute façon.

OPTIONS

-e, --eval=CHAINE
Analyse la CHAINE comme une chaîne contenant du code perl.
-c, --compile
Compile le code et inspecte son %INC, en plus de l'analyse statique.
-x, --execute
Exécute le code et inspecte son %INC, en plus de l'analyse statique. Vous pouvez utiliser --xargs pour spécifier @ARGV lors de l'exécution du code.
--xargs=CHAINE
Si -x est donné, divise la "CHAINE" en utilisant la fonction "shellwords" de Text::ParseWords et passe le résultat comme @ARGV lors de l'exécution du code.
-B, --bundle
Inclut les modules de base dans la sortie et la liste de recherche récursive.
-R, --no-recurse
Affiche uniquement les dépendances trouvées dans les fichiers listés et ne récursionne pas.
-V, --verbose
Mode verbeux : Affiche tous les fichiers trouvés pendant le processus ; affiche les dépendances entre les modules et leur disponibilité.

De plus, signale les dépendances manquantes. Si vous trouvez des dépendances manquantes qui n'en sont pas vraiment, vous avez probablement trouvé des faux positifs.

-C, --cachedeps=FICHIERCASCADE
Utilise FICHIERCASCADE pour accélérer le processus d'analyse en mettant en cache les dépendances. Crée FICHIERCASCADE s'il n'existe pas encore.
-T, --modtree
Récupère les informations sur les modules depuis CPAN si vous avez CPANPLUS installé.
