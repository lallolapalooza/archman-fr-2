NOM

sctp_sendmsg - Envoyer un message à partir d'un socket SCTP.

SYNOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_sendmsg(int sd, const void * msg, size_t len,
                 struct sockaddr *to, socklen_t tolen,
                 uint32_t ppid, uint32_t flags,
                 uint16_t stream_no, uint32_t timetolive,
                 uint32_t context);

DESCRIPTION

sctp_sendmsg est une fonction de bibliothèque wrapper qui peut être utilisée pour envoyer un message depuis un socket tout en utilisant les fonctionnalités avancées de SCTP. sd est le descripteur de socket à partir duquel le message pointé par msg de longueur len est envoyé. to est l'adresse de destination du message et tolen est la longueur de l'adresse de destination. stream_no identifie le numéro de flux vers lequel l'application souhaite envoyer ce message. Le paramètre flags est composé d'un OU binaire des valeurs suivantes.

SCTP_UNORDERED
Ce drapeau demande la livraison non ordonnée du message.
SCTP_ADDR_OVER
Ce drapeau, dans le style un-à-plusieurs, demande à la pile SCTP de remplacer l'adresse de destination primaire par l'adresse spécifiée dans to.
SCTP_ABORT
Définir ce drapeau provoque l'interruption de l'association spécifiée en envoyant un message ABORT au pair (style un-à-plusieurs uniquement). Le bloc ABORT contiendra une cause d'erreur 'User Initiated Abort' avec le code de cause 12. Les informations spécifiques à la cause de cette erreur sont fournies dans msg.
SCTP_EOF
Définir ce drapeau déclenche la procédure d'arrêt normal de SCTP sur l'association spécifique (style un-à-plusieurs uniquement).
SCTP_SENDALL
Ce drapeau, s'il est défini, amènera un socket de style un-à-plusieurs à envoyer le message à toutes les associations actuellement établies sur ce socket. Pour un socket de style un-à-un, ce drapeau n'a aucun effet.
SCTP_SACK_IMMEDIATELY
Ce drapeau permet à l'application de définir le bit I du dernier bloc DATA lors de l'envoi de chaque message utilisateur pour s'assurer que le SACK correspondant peut être envoyé par le pair sans délai.
SCTP_PR_SCTP_{TTL|RTX|PRIO}
Une de ces 3 politiques pr_policies peut être utilisée via ce drapeau avec sa pr_value définie dans le paramètre timetolive pour ce message. Notez que sctp_sendv(3) avec infotype SCTP_SENDV_PRINFO fonctionne également pour PR-SCTP.

timetolive spécifie la durée en millisecondes. Le côté émetteur expirera le message s'il n'a pas été envoyé au pair dans ce délai. Une valeur de 0 indique qu'aucun délai d'expiration ne devrait se produire pour ce message. Il fonctionne également comme pr_value si le paramètre flags est défini à pr_policy. ppid est une valeur opaque non signée qui est transmise à l'extrémité distante avec le message. context est une valeur opaque de 32 bits qui est renvoyée à la couche supérieure avec le message non livré si une erreur se produit lors de l'envoi du message.

VALEUR DE RETOUR

En cas de succès, sctp_sendmsg renvoie le nombre d'octets envoyés ou -1 si une erreur s'est produite.
