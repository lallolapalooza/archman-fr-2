NOM

scanmacho - utilitaire en espace utilisateur pour scanner les fichiers Mach-O

SYNOPIS

scanmacho [options] Mach-Os ou répertoires

DESCRIPTION

scanmacho est un utilitaire en espace utilisateur permettant de scanner rapidement des fichiers Mach-O, des répertoires ou des chemins système courants pour diverses informations. Cela peut inclure les types Mach-O, leurs install_names, etc...

Étant donné que les fichiers Mach-O peuvent être « fat » (universels), un seul fichier peut retourner plusieurs lignes. Chaque ligne représente une architecture unique, contenue dans le fichier fat (universel). Bien qu'il n'y ait pas de restrictions réelles, en pratique, les entrées peuvent être distinguées par leur type d'architecture, par exemple ppc, ppc64, i386, x86_64, arm, ...

OPTIONS

-A, --archives

Scanner les archives (.a files)

-a, --all

Afficher toutes les informations utiles/simples

-B, --nobanner

Ne pas afficher l'en-tête

-b, --bind

Afficher les drapeaux de mach_header

-D, --endian

Afficher l'endianness du Mach-O

-E, --etype filetype

Afficher uniquement les fichiers Mach-O correspondant au type spécifié (comme MH_EXECUTABLE, MH_DYLIB, etc.)

-F, --format FORMAT

Utiliser le format spécifié pour la sortie ; voir la section FORMAT pour plus d'informations.

-f, --from FILE

Lire le flux d'entrée depuis le fichier spécifié

-g, --gmatch

Utiliser strncmp pour faire correspondre les bibliothèques (à utiliser avec -N). Ou expression régulière avec correspondance de symboles

-h, --help

Afficher l'aide condensée et quitter

-i, --interp

Afficher les informations de l'interpréteur (LC_LOAD_DYLINKER)

-M, --bits BITS

Afficher uniquement les fichiers Mach-O correspondant aux bits numériques spécifiés (comme 32/64)

-m, --mount

Ne pas traverser récursivement les points de montage

-N, --lib INSTALLNAME

Trouver les Mach-O qui nécessitent l'INSTALL_NAME spécifié

-n, --needed

Afficher les bibliothèques auxquelles le Mach-O est lié (LC_LOAD_DYLIB).

-O, --perms PERMS

Afficher uniquement les fichiers Mach-O avec les bits octaux spécifiés correspondants (comme 755).

-o, --file FILE

Écrire le flux de sortie dans le fichier spécifié.

-p, --path

Scanner tous les répertoires de la variable d'environnement PATH.

-q, --quiet

N'afficher que les choses « mauvaises ».

-R, --recursive

Scanner les répertoires récursivement

-r, --rpath

Afficher le RPATH encodé dans le Mach-O (LC_RPATH)

-S, --soname

Afficher le nom de la bibliothèque partagée du Mach-O (install_name).

-V, --version

Afficher la version et quitter

-v, --verbose

Être verbeux (peut être utilisé plusieurs fois)

-y, --symlink

Ne pas scanner les liens symboliques

-Z, --size SIZE

Afficher la taille du fichier Mach-O

FORMAT

La chaîne de format est similaire à une chaîne printf en ce sens qu'il s'agit d'une chaîne littérale avec des indicateurs demandant différentes informations. Par exemple, vous pourriez utiliser une chaîne de format et attendre les résultats suivants.

  # scanmacho -BF "fichier %f a besoin de %n; temps funky" /bin/bash
  fichier bash a besoin de /usr/lib/libncurses.5.4.dylib,/usr/lib/libSystem.B.dylib; temps funky

Notez que lorsque vous utilisez une chaîne de format, les options relatives aux informations doivent généralement être omises. En d'autres termes, vous ne voudrez pas essayer de demander une sortie NEEDED (-n) et spécifier une sortie de format en même temps, car ces opérations sont mutuellement exclusives. Chaque option liée aux informations a un spécificateur de conversion correspondant, utilisez donc ceux-ci à la place. Vous pouvez bien sûr continuer à utiliser des options non liées aux informations (telles que --verbose).

Il existe trois caractères qui introduisent les spécificateurs de conversion.

• % - remplacer par des informations

•
# - correspondance booléenne silencieuse
•
+ - correspondance verbeuse

Et il existe un certain nombre de spécificateurs de conversion. Nous essayons de faire correspondre le spécificateur à l'option correspondante.

• a - type d'architecture

•
b - drapeaux mach_header
•
D - endian
•
F - nom de fichier long
•
f - nom de fichier court
•
i - dyld
•
M - classe CPU_TYPE
•
N - besoin spécifié
•
n - bibliothèques nécessaires
•
p - nom de fichier (sans chemin)
•
o - type mh
•
O - permissions
•
r - rpaths
•
S - install_name

TYPES DE FICHIERS MACH-O

Vous pouvez affiner votre recherche en spécifiant le type de fichier objet Mach-O. L'option de ligne de commande prend le nom symbolique du type. Plusieurs valeurs peuvent être passées séparées par des virgules. Exemple -E MH_EXECUTE,MH_DYLIB

Voici la liste normale disponible pour votre plaisir.

• MH_OBJECT - fichier objet intermédiaire (.o)

•
MH_EXECUTE - programme exécutable standard
•
MH_BUNDLE - plugin dlopen (.bundle)
•
MH_DYLIB - bibliothèque partagée dynamique (.dylib)
•
MH_PRELOAD - exécutable non chargé par le noyau Mac OS X (ROM)
•
MH_CORE - fichier de vidage mémoire (core dump) d'un programme
•
MH_DYLINKER - bibliothèque partagée de l'éditeur de liens dynamique (dyld)
•
MH_DYLIB_STUB - stub de bibliothèque partagée uniquement pour statique, sans sections
•
MH_DSYM - fichier de symboles de débogage (dans le répertoire .dSYM)

BITS MACH-O

Vous pouvez également affiner votre recherche en spécifiant la taille en bits du Mach-O. Spécifiez la valeur numérique.

• 32 - mach_header 32 bits

•
64 - mach_header_64 64 bits
