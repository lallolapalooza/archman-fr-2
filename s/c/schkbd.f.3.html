SCHKBD

Objectif :

!>
!> SCHKBD teste les routines de décomposition en valeurs singulières (SVD).
!>
!> SGEBRD réduit une matrice réelle générale m par n, A, à une forme
!>idiagonale supérieure ou inférieure B par une transformation orthogonale :
!> Q' * A * P = B (ou A = Q * B * P'). La matrice B est współpragonale
!> si m >= n et sous-diagona le si m < n.
!>
!> SORGBR génère les matrices orthogonales Q et P' à partir de SGEBRD.
!> Notez que Q et P ne sont pas nécessairement carrées.
!>
!> SBDSQR calcule la décomposition en valeurs singulières de la matrice
!> biçidiagonale B sous la forme B = U S V'. Elle est appelée trois fois
!> pour calculer :
!>    1) B = U S1 V', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    2) Identique à 1), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>    3) A = (UQ) S (P'V'), la SVD de la matrice originale A.
!> De plus, SBDSQR a une option pour appliquer la matrice orthogonale gauche
!> U à une matrice X, utile dans les applications aux moindres carrés.
!>
!> SBDSDC calcule la décomposition en valeurs singulières de la matrice
!> biçidiagonale B sous la forme B = U S V' en utilisant la méthode diviser
!> pour régner. Elle est appelée deux fois pour calculer :
!>    1) B = U S1 V', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    2) Identique à 1), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>
!> SBDSVDX calcule la décomposition en valeurs singulières de la matrice
!> biçidiagonale B sous la forme B = U S V' en utilisant la dichotomie et
!> l'itération inverse. Elle est appelée six fois pour calculer :
!>    1) B = U S1 V', RANGE='A', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    2) Identique à 1), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>    3) B = U S1 V', RANGE='I', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    4) Identique à 3), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>    5) B = U S1 V', RANGE='V', où S1 est la matrice diagonale des valeurs
!>       singulières et les colonnes des matrices U et V sont les vecteurs
!>       singuliers gauches et droits, respectivement, de B.
!>    6) Identique à 5), mais les valeurs singulières sont stockées dans S2
!>       et les vecteurs singuliers ne sont pas calculés.
!>
!> Pour chaque paire de dimensions de matrice (M,N) et chaque type de matrice
!> sélectionné, une matrice A de dimension M par N et une matrice X de
!> dimension M par NRHS sont générées. Les dimensions du problème sont les
!> suivantes :
!>    A:          M x N
!>    Q:          M x min(M,N) (mais M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonale, ordre min(M,N)
!>    X:          M x NRHS
!>
!> Pour chaque matrice générée, 14 tests sont effectués :
!>
!> Tests SGEBRD et SORGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Test SBDSQR sur la matrice biçidiagonale B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), où Y = Q' X
!>                                                  et   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contient min(M,N) valeurs non négatives dans l'ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (9)   | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                   calculer U et V.
!>
!> (10)  0 si les vraies valeurs singulières de B sont dans THRESH de
!>       celles dans S1.  2*THRESH si ce n'est pas le cas.  (Testé en utilisant
!>       SSVDCH)
!>
!> Test SBDSQR sur la matrice A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Test SBDSDC sur la matrice biçidiagonale B
!>
!> (15)  | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (16)  | I - U' U | / ( min(M,N) ulp )
!>
!> (17)  | I - VT VT' | / ( min(M,N) ulp )
!>
!> (18)  S1 contient min(M,N) valeurs non négatives dans l'ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (19)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                   calculer U et V.
!>  Test SBDSVDX sur la matrice biçidiagonale B
!>
!>  (20)  | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!>  (21)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (22)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (23)  S1 contient min(M,N) valeurs non négatives dans l'ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!>  (24)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                    calculer U et V.
!>
!>  (25)  | S1 - U' B VT' | / ( |S1| n ulp )    SBDSVDX('V', 'I')
!>
!>  (26)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (27)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (28)  S1 contient min(M,N) valeurs non négatives dans l'ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!>  (29)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                    calculer U et V.
!>
!>  (30)  | S1 - U' B VT' | / ( |S1| n ulp )   SBDSVDX('V', 'V')
!>
!>  (31)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (32)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (33)  S1 contient min(M,N) valeurs non négatives dans l'ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!>  (34)  | S1 - S2 | / ( |S1| ulp ), où S2 est calculé sans
!>                                    calculer U et V.
!>
!> Les types de matrices possibles sont :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale

SCHKBD

NAME

SCHKBD — The general meaning of SCHKBD is to check the bidiagonal reduction and bidiagonal QR decomposition routines.

SYNOPSIS

SUBROUTINE SCHKBD( NSIZES, MVAL, NVAL, NTYPES, DOTYPE, NRHS,
 &                   ISEED, THRESH, A, LDA, BD, BE, S1, S2,
 &                   X, LDX, Y, Z, Q, LDQ, PT, LDPT, U, VT,
 &                   WORK, LWORK, IWORK, NOUT, INFO )

Where the following parameters are functions of the problem size and type:

CHARACTER*(*)  DOTYPE
INTEGER        MVAL( * ), NVAL( * )
INTEGER        ISEED( 4 )
REAL           A( LDA, * ), BD( * ), BE( * ), S1( * ), S2( * ),
               X( LDX, * ), Y( LDX, * ), Z( LDX, * ), Q( LDQ, * ),
               PT( LDPT, * ), U( LDPT, * ), VT( LDPT, * ), WORK( * )

Function/Subroutine Documentation

The following are the matrix types for SCHKBD:

Matrix types:

(1) A rectangular matrix with random entries chosen from (-1,1). !> (2) A rectangular matrix with random entries chosen from (-1,1), !> multiplied by SQRT( overflow threshold ). !> (3) A rectangular matrix with random entries chosen from (-1,1), !> multiplied by SQRT( underflow threshold ). !> (4) A diagonal matrix with entries 1, ..., ULP and random signs. !> (5) A diagonal matrix with entries 1, ULP, ..., ULP !> and random signs. !> !> (6) Same as (3), but multiplied by SQRT( overflow threshold ) !> (7) Same as (3), but multiplied by SQRT( underflow threshold ) !> !> (8) A matrix of the form U D V, where U and V are orthogonal and !> D has evenly spaced entries 1, ..., ULP with random signs !> on the diagonal. !> !> (9) A matrix of the form U D V, where U and V are orthogonal and !> D has geometrically spaced entries 1, ..., ULP with random !> signs on the diagonal. !> !> (10) A matrix of the form U D V, where U and V are orthogonal and !> D has entries 1, ULP,..., ULP with random !> signs on the diagonal. !> !> (11) Same as (8), but multiplied by SQRT( overflow threshold ) !> (12) Same as (8), but multiplied by SQRT( underflow threshold ) !> !> (13) Rectangular matrix with random entries chosen from (-1,1). !> (14) Same as (13), but multiplied by SQRT( overflow threshold ) !> (15) Same as (13), but multiplied by SQRT( underflow threshold ) !> !> Special case: !> (16) A bidiagonal matrix with random entries chosen from a !> logarithmic distribution on [ulp^2,ulp^(-2)] (I.e., each !> entry is e^x, where x is chosen uniformly on !> [ 2 log(ulp), -2 log(ulp) ] .) For *this* type: !> (a) SGEBRD is not called to reduce it to bidiagonal form. !> (b) the bidiagonal is min(M,N) x min(M,N); if M<N, the !> matrix will be lower bidiagonal, otherwise upper. !> (c) only tests 5--8 and 14 are performed. !> !> A subset of the full set of matrix types may be selected through !> the logical array DOTYPE.

Parameters

NSIZES 
!>          NSIZES is INTEGER
!>          The number of values of M and N contained in the vectors
!>          MVAL and NVAL.  The matrix sizes are used in pairs (M,N).

MVAL

!>          MVAL is INTEGER array, dimension (NM)
!>          The values of the matrix row dimension M.

NVAL

!>          NVAL is INTEGER array, dimension (NM)
!>          The values of the matrix column dimension N.

NTYPES

!>          NTYPES is INTEGER
!>          The number of elements in DOTYPE.   If it is zero, SCHKBD
!>          does nothing.  It must be at least zero.  If it is MAXTYP+1
!>          and NSIZES is 1, then an additional type, MAXTYP+1 is
!>          defined, which is to use whatever matrices are in A and B.
!>          This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!>          DOTYPE(MAXTYP+1) is .TRUE. .

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size (m,n), a matrix
!>          of type j will be generated.  If NTYPES is smaller than the
!>          maximum number of types defined (PARAMETER MAXTYP), then
!>          types NTYPES+1 through MAXTYP will not be generated.  If
!>          NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through
!>          DOTYPE(NTYPES) will be ignored.

NRHS

!>          NRHS is INTEGER
!>          The number of columns in the  matrices X, Y,
!>          and Z, used in testing SBDSQR.  If NRHS = 0, then the
!>          operations on the right-hand side will not be tested.
!>          NRHS must be at least 0.

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The values of ISEED are changed on exit, and can be
!>          used in the next call to SCHKBD to continue the same random
!>          number sequence.

THRESH

!>          THRESH is REAL
!>          The threshold value for the test ratios.  A result is
!>          included in the output file if RESULT >= THRESH.  To have
!>          every test ratio printed, use THRESH = 0.  Note that the
!>          expected value of the test ratios is O(1), so THRESH should
!>          be a reasonably small multiple of 1, e.g., 10 or 100.

A

!>          A is REAL array, dimension (LDA,NMAX)
!>          where NMAX is the maximum value of N in NVAL.

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,MMAX),
!>          where MMAX is the maximum value of M in MVAL.

BD

!>          BD is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))

BE

!>          BE is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))

S1

!>          S1 is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))

S2

!>          S2 is REAL array, dimension
!>                      (max(min(MVAL(j),NVAL(j))))

X

!>          X is REAL array, dimension (LDX,NRHS)

LDX

!>          LDX is INTEGER
!>          The leading dimension of the arrays X, Y, and Z.
!>          LDX >= max(1,MMAX)

Y

!>          Y is REAL array, dimension (LDX,NRHS)

Z

!>          Z is REAL array, dimension (LDX,NRHS)

Q

!>          Q is REAL array, dimension (LDQ,MMAX)

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q.  LDQ >= max(1,MMAX).

PT

!>          PT is REAL array, dimension (LDPT,NMAX)

LDPT

!>          LDPT is INTEGER
!>          The leading dimension of the arrays PT, U, and V.
!>          LDPT >= max(1, max(min(MVAL(j),NVAL(j)))).

U

!>          U is REAL array, dimension
!>                      (LDPT,max(min(MVAL(j),NVAL(j))))

VT

!>          VT is REAL array, dimension
!>                      (LDPT,max(min(MVAL(j),NVAL(j))))

WORK

!>          WORK is REAL array, dimension (LWORK)

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          3(M+N) and  M(M + max(M,N,k) + 1) + N*min(M,N)  for all
!>          pairs  (M,N)=(MM(j),NN(j))

IWORK

!>          IWORK is INTEGER array, dimension at least 8*min(M,N)

NOUT

!>          NOUT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)

INFO

!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>           -1: NSIZES < 0
!>           -2: Some MM(j) < 0
!>           -3: Some NN(j) < 0
!>           -4: NTYPES < 0
!>           -6: NRHS  < 0
!>           -8: THRESH < 0
!>          -11: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
!>          -17: LDB < 1 or LDB < MMAX.
!>          -21: LDQ < 1 or LDQ < MMAX.
!>          -23: LDPT< 1 or LDPT< MNMAX.
!>          -27: LWORK too small.
!>          If  SLATMR, SLATMS, SGEBRD, SORGBR, or SBDSQR,
!>              returns an error code, the
!>              absolute value of it is returned.
!>

!>     Some Local Variables and Parameters:

!>     MNMIN           min(MM(j), NN(j)) (the dimension of the bidiagonal

!>     MNMAX           The maximum value of MNMIN for j=1,...,NSIZES.
!>     NFAIL           The number of tests which have exceeded THRESH

!>     KMODE(j)        The MODE value to be passed to the matrix
