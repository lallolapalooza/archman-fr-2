NOM

screenFetch - L'outil d'information de capture d'écran Bash

SYNOPSIS

screenfetch [OPTIONS OPTIONNELLES]

DESCRIPTION

Ce script Bash pratique peut être utilisé pour générer l'une de ces nifty informations sur le thème du terminal + logos ASCII de distribution que vous voyez dans les captures d'écran de tout le monde de nos jours. Il détecte automatiquement votre distribution et affiche une version ASCII du logo de cette distribution ainsi que des informations précieuses sur la droite. Il existe des options pour spécifier l'absence d'art ASCII, les couleurs, la prise d'une capture d'écran lors de l'affichage des informations, et même la personnalisation de la commande de capture d'écran ! Ce script est très facile à étendre.

OPTIONS

-v
Sortie verbeuse.
-o 'OPTIONS'
Permet de définir des variables du script en ligne de commande. Doit être au format suivant : 'OPTION1="OPTIONARG1";OPTION2="OPTIONARG2"'
-d '+var;-var;var'
Permet de définir les informations qui seront affichées en ligne de commande. Vous pouvez ajouter des affichages avec +var,var. Vous pouvez supprimer des affichages avec -var,var. La définition sans + ou - définira l'affichage sur cette combinaison explicite. Les instructions d'ajout et de suppression peuvent être utilisées conjointement en plaçant un ; entre elles comme ceci : +var,var,var;-var,var.
-n
N'affiche pas le logo ASCII de la distribution.
-L
Affiche uniquement le logo ASCII de la distribution.
-N
Supprime toute couleur de la sortie.
-w
Retour à la ligne des lignes longues.
-t
Tronque la sortie en fonction de la largeur du terminal (Expérimental !).
-p
Sortie en mode portrait, avec le logo au-dessus des informations.
-s [-u IMGHOST]
L'utilisation de ce drapeau indique au script que vous souhaitez qu'il prenne une capture d'écran. Utilisez le drapeau -u si vous souhaitez télécharger les captures d'écran vers l'un des emplacements préconfigurés. Ceux-ci incluent : teknik, imgur, mediacrush et hmp.
-c chaine
Vous pouvez modifier les couleurs de sortie avec -c. Le format est le suivant : [0-9][0-9],[0-9][0-9]. Le premier argument contrôle les couleurs du logo ASCII et les couleurs des étiquettes. Le second argument contrôle les couleurs des informations trouvées. Un seul argument peut être utilisé sans l'autre.
-a 'CHEMIN'
Vous pouvez spécifier un art ASCII personnalisé en passant le chemin d'un script Bash, en définissant les variables startline et fulloutput, et éventuellement labelcolor et textcolor. Voir la fonction asciiText dans le code source pour plus d'informations sur le format des variables.
-S 'COMMANDE'
Ici, vous pouvez spécifier une commande de capture d'écran personnalisée que le script exécutera. Les guillemets environnants sont requis.
-D 'DISTRO'
Ici, vous pouvez spécifier votre distribution pour que le script l'utilise. Les guillemets environnants sont requis.
-A 'DISTRO'
Ici, vous pouvez spécifier l'art de la distribution que vous souhaitez afficher. Ceci est utile lorsque vous souhaitez que votre distribution soit détectée mais que vous voulez afficher un logo différent.
-E
Supprime l'affichage des erreurs.
-V, --version
Affiche la version actuelle du script.
-h, --help
Affiche cette aide.
