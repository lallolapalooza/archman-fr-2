NOM

scanlogs - Résume et archive les fichiers journaux INN

SYNTAXE

scanlogs [norotate]

DESCRIPTION

scanlogs résume les informations enregistrées dans les fichiers journaux INN qui résident dans le répertoire pathlog défini dans inn.conf (voir newslog(5) pour plus de détails sur ces fichiers journaux). Il est normalement appelé par le script news.daily(8) qui effectue les tâches de maintenance quotidiennes du serveur.

Il appelle "ctlinnd flushlogs" pour fermer les fichiers journaux des nouvelles et des erreurs, les renommer en ajoutant ".old" aux noms de fichiers et ouvrir de nouveaux journaux de nouvelles et d'erreurs ; le fichier active est également vidé sur disque, ainsi que la base de données d'historique.

Par défaut, scanlogs archive et nettoie les journaux. Il conserve jusqu'à logcycles anciens fichiers journaux compressés dans pathlog/OLD (le paramètre logcycles peut être défini dans inn.conf). scanlogs conserve également des archives du fichier active dans ce répertoire.

Il appelle tally.control si newgroup.log ou rmgroup.log existe dans pathlog (voir l'entrée control.log de newslog(5) pour plus d'informations à ce sujet).

scanlogs affiche les 50 premières lignes de errlog, news.err et news.crit, s'ils ne sont pas vides, et exécute innreport pour résumer le contenu de news, news.notice et perl-nocem.log, et pour mettre à jour unwanted.log entre autres choses (voir plus d'informations à ce sujet dans innreport(8)).

OPTIONS

Une seule option est actuellement acceptée :

norotate
L'utilisation de cette option désactive l'aspect d'archivage et de nettoyage du traitement des journaux : les fichiers journaux sont uniquement analysés pour obtenir des informations et aucun contenu n'est modifié. Si scanlogs est appelé plus d'une fois par jour, l'option norotate doit être utilisée pour éviter un nettoyage prématuré des journaux.

FICHIERS

Voir newslog(5) pour la liste des fichiers journaux traités par scanlogs.
