sous-programme schkbb (integer nsizes, integer, dimension( * ) mval, integer, dimension( * ) nval, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer nrhs, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) bd, real, dimension( * ) be, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldp, * ) p, integer ldp, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldc, * ) cc, real, dimension( * ) work, integer lwork, real, dimension( * ) result, integer info)

SCHKBB

Objectif :

!>
!> SCHKBB teste la réduction d'une matrice bande rectangulaire générale réelle
!> en forme bidiagonale.
!>
!> SGBBRD factorise une matrice bande générale A en Q B P* , où * signifie
!> transposée, B est supérieure bidiagonale, et Q et P sont orthogonales ;
!> SGBBRD peut également écraser une matrice C donnée par Q* C .
!>
!> Pour chaque paire de dimensions de matrice (M,N) et chaque type de matrice sélectionné,
!> une matrice A de taille M x N et une matrice C de taille M x NRHS sont générées.
!> Les dimensions du problème sont les suivantes :
!>    A :          M x N
!>    Q :          M x M
!>    P :          N x N
!>    B :          min(M,N) x min(M,N)
!>    C :          M x NRHS
!>
!> Pour chaque matrice générée, 4 tests sont effectués :
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> (4)   | Y - Q' C | / ( |Y| max(M,NRHS) ulp ), où Y = Q' C.
!>
!> Les sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!> si DOTYPE(j) est .VRAI., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> Les types de matrices possibles sont
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!>
!> (3)  Une matrice diagonale avec des entrées régulièrement espacées
!>      1, ..., ULP  et des signes aléatoires.
!>      (ULP = (premier nombre supérieur à 1) - 1 )
!> (4)  Une matrice diagonale avec des entrées géométriquement espacées
!>      1, ..., ULP  et des signes aléatoires.
!> (5)  Une matrice diagonale avec des entrées 1, ULP, ..., ULP
!>      et des signes aléatoires.
!>
!> (6)  Identique à (3), mais multiplié par SQRT( seuil de débordement )
!> (7)  Identique à (3), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (8)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (9)  Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (10) Une matrice de la forme  U D V, où U et V sont orthogonales et
!>      D a des entrées 1, ULP,..., ULP avec des signes aléatoires
!>      sur la diagonale.
!>
!> (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!> (12) Identique à (8), mais multiplié par SQRT( seuil de sous-dépassement )
!>
!> (13) Matrice rectangulaire avec des entrées aléatoires choisies dans (-1,1).
!> (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!> (15) Identique à (13), mais multiplié par SQRT( seuil de sous-dépassement )
!>

Paramètres

NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de valeurs de M et N contenues dans les vecteurs
!>          MVAL et NVAL. Les tailles de matrice sont utilisées par paires (M,N).
!>          Si NSIZES est zéro, SCHKBB ne fait rien. NSIZES doit être
!>          au moins zéro.
!>

MVAL

!>          MVAL est un tableau INTEGER, dimension (NSIZES)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

NVAL

!>          NVAL est un tableau INTEGER, dimension (NSIZES)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NWDTHS

!>          NWDTHS est INTEGER
!>          Le nombre de largeurs de bande à utiliser. Si elle est nulle,
!>          SCHKBB ne fait rien. Elle doit être au moins nulle.
!>

KK

!>          KK est un tableau INTEGER, dimension (NWDTHS)
!>          Un tableau contenant les largeurs de bande à utiliser pour les matrices bande.
!>          Les valeurs doivent être au moins nulles.
!>

NTYPES

!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. Si il est nul, SCHKBB
!>          ne fait rien. Il doit être au moins nul. Si il est MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes dans la matrice C.
!>          Si NRHS = 0, alors les opérations sur le second membre ne
!>          seront pas testées. NRHS doit être au moins 0.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc produire
!>          des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans
!>          l'appel suivant à SCHKBB pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est REAL
!>          Un test sera considéré comme  si le , calculé comme
!>          décrit ci-dessus, dépasse THRESH. Noter que l'erreur
!>          est mise à l'échelle pour être de l'ordre de 1, donc THRESH devrait être un multiple raisonnablement
!>          petit de 1, par exemple 10 ou 100. En particulier,
!>          il ne devrait pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. Il doit être au moins nul.
!>

NOUNIT

!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine retourne IINFO différent de 0.)
!>

A

!>          A est un tableau REAL, dimension
!>                            (LDA, max(NN))
!>          Utilisé pour contenir la matrice A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. Elle doit être au moins 1
!>          et au moins max( NN ).
!>

AB

!>          AB est un tableau REAL 


NAME


SCHKBB


 LAPACK routine (usually called by xsxckb) to check the
    bidiagonal reduction routines.






SYNOPSIS


 CALL SCHKBB( NMAX, NTYPES, THRESH, TSTSWT, A, LDA, BD, BE, Q, LDQ, P,
               LDP, C, LDC, CC, WORK, LWORK, INFO )






Function/Subroutine
    Documentation


This is a generic part of the testing program for the LAPACK
    routines.


The main data structure is the array of types defined by the
    parameters KTYPE, KMODE, KMAGN, and KDIAG.


This file defines the default values for the parameters used in
    testing.


The types of matrices are:




1. General rectangular (KTYPE=1)





    SGEBAL is used to compute the packed storage for the matrix. The
    packed storage is then used in the routines.




2. General bidiagonal (KTYPE=2)





    SGEBD is used to compute the packed storage for the matrix.




3. General triangular (KTYPE=3)





    SPPBAL is used to compute the packed storage for the matrix.




4. General upper triangular (KTYPE=4)





    SPPBD is used to compute the packed storage for the matrix.




5. General lower triangular (KTYPE=5)





    SPPBD is used to compute the packed storage for the matrix.




6. General block-triangular (KTYPE=6)





    SPPBD is used to compute the packed storage for the matrix.




7. General block-upper triangular (KTYPE=7)





    SPPBD is used to compute the packed storage for the matrix.




8. General block-lower triangular (KTYPE=8)





    SPPBD is used to compute the packed storage for the matrix.




9. General block-diagonal (KTYPE=9)





    SPPBD is used to compute the packed storage for the matrix.




10. General block-anti-diagonal (KTYPE=10)





    SPPBD is used to compute the packed storage for the matrix.






The subroutines tested are SGBBRD, SGGBRD, STGBBRD, SSGBBRD,
    CSGBBRD, ZGBBRD, and others.


The routines compute the bidiagonal decomposition of a general
    band matrix.


The following parameter descriptions are taken from the LAPACK
    User's Guide.


NMAX


!>          NMAX is INTEGER
!>          The maximum size of the matrices.
!> 


NTYPES


!>          NTYPES is INTEGER
!>          The number of matrix types to be tested.
!> 


THRESH


!>          THRESH is REAL
!>          The threshold to use for testing the error bounds.
!> 


TSWFT


!>          TSWFT is LOGICAL
!>          If TSWFT is true, then the test routines will be run.
!> 


A


!>          A is REAL array, dimension (LDA, max(NN))
!>          Used to hold A in band storage format.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of AB.  It must be at least 2 (not 1!)
!>          and at least max( KK )+1.
!> 


BD


!>          BD is REAL array, dimension (max(NN))
!>          Used to hold the diagonal of the bidiagonal matrix computed
!>          by SGBBRD.
!> 


BE


!>          BE is REAL array, dimension (max(NN))
!>          Used to hold the off-diagonal of the bidiagonal matrix
!>          computed by SGBBRD.
!> 


Q


!>          Q is REAL array, dimension (LDQ, max(NN))
!>          Used to hold the orthogonal matrix Q computed by SGBBRD.
!> 


LDQ


!>          LDQ is INTEGER
!>          The leading dimension of Q.  It must be at least 1
!>          and at least max( NN ).
!> 


P


!>          P is REAL array, dimension (LDP, max(NN))
!>          Used to hold the orthogonal matrix P computed by SGBBRD.
!> 


LDP


!>          LDP is INTEGER
!>          The leading dimension of P.  It must be at least 1
!>          and at least max( NN ).
!> 


C


!>          C is REAL array, dimension (LDC, max(NN))
!>          Used to hold the matrix C updated by SGBBRD.
!> 


LDC


!>          LDC is INTEGER
!>          The leading dimension of U.  It must be at least 1
!>          and at least max( NN ).
!> 


CC


!>          CC is REAL array, dimension (LDC, max(NN))
!>          Used to hold a copy of the matrix C.
!> 


WORK


!>          WORK is REAL array, dimension (LWORK)
!> 


LWORK


!>          LWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          max( LDA+1, max(NN)+1 )*max(NN).
!> 


RESULT


!>          RESULT is REAL array, dimension (4)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid
!>          overflow.
!> 


INFO


!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>
!>-----------------------------------------------------------------------
!>
!>       Some Local Variables and Parameters:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 and 1.
!>       MAXTYP          The number of types defined.
!>       NTEST           The number of tests performed, or which can
!>                       be performed so far, for the current matrix.
!>       NTESTT          The total number of tests performed so far.
!>       NMAX            Largest value in NN.
!>       NMATS           The number of matrices generated so far.
!>       NERRS           The number of tests which have exceeded THRESH
!>                       so far.
!>       COND, IMODE     Values to be passed to the matrix generators.
!>       ANORM           Norm of A; passed to matrix generators.
!>
!>       OVFL, UNFL      Overflow and underflow thresholds.
!>       ULP, ULPINV     Finest relative precision and its inverse.
!>       RTOVFL, RTUNFL  Square roots of the previous 2 values.
!>               The following four arrays decode JTYPE:
!>       KTYPE(j)        The general type (1-10) for type .
!>       KMODE(j)        The MODE value to be passed to the matrix
!>                       generator for type .
!>       KMAGN(j)        The order of magnitude ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
