sched.h(0P) Manuel du programmeur POSIX sched.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sched.h — ordonnancement d'exécution

SYNOPIS

#include <sched.h>

DESCRIPTION

L'en-tête <sched.h> définira le type pid_t tel que décrit dans <sys/types.h>.

L'en-tête <sched.h> définira le type time_t tel que décrit dans <sys/types.h>.

L'en-tête <sched.h> définira la structure timespec telle que décrite dans <time.h>.

L'en-tête <sched.h> définira la structure sched_param, qui inclura les paramètres d'ordonnancement requis pour l'implémentation de chaque politique d'ordonnancement prise en charge. Cette structure inclura au moins le membre suivant :

int       sched_priority        Priorité d'ordonnancement d'exécution du processus ou du fil d'exécution.

La structure sched_param définie dans <sched.h> inclura les membres suivants en plus de ceux spécifiés ci-dessus :

int             sched_ss_low_priority Priorité basse d'ordonnancement pour
                                      le serveur sporadique.
struct timespec sched_ss_repl_period  Période de réapprovisionnement pour
                                      le serveur sporadique.
struct timespec sched_ss_init_budget  Budget initial pour le serveur sporadique.
int             sched_ss_max_repl     Réapprovisionnements en attente maximum pour
                                      le serveur sporadique.

Chaque processus ou fil d'exécution est contrôlé par une politique d'ordonnancement et une priorité associées. Associée à chaque politique se trouve une plage de priorités. Chaque définition de politique spécifie la plage de priorités minimale pour cette politique. Les plages de priorités pour chaque politique peuvent chevaucher les plages de priorités des autres politiques.

Quatre politiques d'ordonnancement sont définies ; d'autres peuvent être définies par l'implémentation. Les quatre politiques standard sont indiquées par les valeurs des constantes symboliques suivantes :

SCHED_FIFO
Politique d'ordonnancement premier entré, premier sorti (FIFO).
SCHED_RR
Politique d'ordonnancement round robin.
SCHED_SPORADIC
Politique d'ordonnancement du serveur sporadique.
SCHED_OTHER
Une autre politique d'ordonnancement.

Les valeurs de ces constantes sont distinctes.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonctions seront fournis.

int    sched_get_priority_max(int);
int    sched_get_priority_min(int);
int    sched_getparam(pid_t, struct sched_param *);
int    sched_getscheduler(pid_t);
int    sched_rr_get_interval(pid_t, struct timespec *);
int    sched_setparam(pid_t, const struct sched_param *);
int    sched_setscheduler(pid_t, int, const struct sched_param *);
int    sched_yield(void);

L'inclusion de l'en-tête <sched.h> peut rendre visibles tous les symboles de l'en-tête <time.h>.
