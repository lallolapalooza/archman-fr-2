SCKGQR

Objectif :

!>
!> SCKGQR teste
!> SGGQRF : factorisation GQR pour la matrice A de taille N par M et la matrice B de taille N par P,
!> SGGRQF : factorisation GRQ pour la matrice A de taille M par N et la matrice B de taille P par N.
!>

Paramètres

NM 
!>          NM est un INTEGER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'INTEGER, dimension (NM)
!>          Les valeurs de la dimension M (ligne/colonne) de la matrice.
!>

NP

!>          NP est un INTEGER
!>          Le nombre de valeurs de P contenues dans le vecteur PVAL.
!>

PVAL

!>          PVAL est un tableau d'INTEGER, dimension (NP)
!>          Les valeurs de la dimension P (ligne/colonne) de la matrice.
!>

NN

!>          NN est un INTEGER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'INTEGER, dimension (NN)
!>          Les valeurs de la dimension N (colonne/ligne) de la matrice.
!>

NMATS

!>          NMATS est un INTEGER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions matricielles. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour les tests. Si NMATS < NTYPES, une ligne d'entrée
!>          supplémentaire est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'INTEGER, dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          En sortie, la prochaine graine dans la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un REAL
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un INTEGER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau REAL, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau REAL, dimension (NMAX*NMAX)
!>

AQ

!>          AQ est un tableau REAL, dimension (NMAX*NMAX)
!>

AR

!>          AR est un tableau REAL, dimension (NMAX*NMAX)
!>

TAUA

!>          TAUA est un tableau REAL, dimension (NMAX)
!>

B

!>          B est un tableau REAL, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau REAL, dimension (NMAX*NMAX)
!>

BZ

!>          BZ est un tableau REAL, dimension (NMAX*NMAX)
!>

BT

!>          BT est un tableau REAL, dimension (NMAX*NMAX)
!>

BWK

!>          BWK est un tableau REAL, dimension (NMAX*NMAX)
!>

TAUB

!>          TAUB est un tableau REAL, dimension (NMAX)
!>

WORK

!>          WORK est un tableau REAL, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau REAL, dimension (NMAX)
!>

NIN

!>          NIN est un INTEGER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un INTEGER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : sortie réussie
!>          > 0 : Si SLATMS renvoie un code d'erreur, sa valeur absolue
!>                 est retournée.
!>
