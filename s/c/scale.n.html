scale(n) Commandes intégrées Tk scale(n)

NOM

scale - Créer et manipuler des widgets curseurs contrôlés par des valeurs 'scale'

SYNTAXE

scale nomChemin ?options?

OPTIONS STANDARDS

-activebackground	-foreground	-relief
-background	-highlightbackground	-repeatdelay
-borderwidth	-highlightcolor	-repeatinterval
-cursor	-highlightthickness	-takefocus
-font	-orient	-troughcolor

Voir l'entrée de manuel options pour plus de détails sur les options standards.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-bigincrement
Nom de base de données :	bigIncrement
Classe de base de données :	BigIncrement
Certaines interactions avec le curseur provoquent un changement de sa valeur par incréments "importants" ; cette option spécifie la taille des incréments importants. Si elle est spécifiée à 0, les incréments importants par défaut sont de 1/10 de la plage du curseur.
Nom de ligne de commande :	-command
Nom de base de données :	command
Classe de base de données :	Command
Spécifie le préfixe d'une commande Tcl à invoquer chaque fois que la valeur du curseur est modifiée via une commande de widget. La commande réelle se compose de cette option suivie d'un espace et d'un nombre réel indiquant la nouvelle valeur du curseur.
Nom de ligne de commande :	-digits
Nom de base de données :	digits
Classe de base de données :	Digits
Un entier spécifiant combien de chiffres significatifs doivent être conservés lors de la conversion de la valeur du curseur en chaîne de caractères. Si le nombre est inférieur ou égal à zéro, alors le curseur choisit la plus petite valeur qui garantit que chaque position possible du curseur s'affiche comme une chaîne de caractères différente.
Nom de ligne de commande :	-from
Nom de base de données :	from
Classe de base de données :	From
Une valeur réelle correspondant à l'extrémité gauche ou supérieure du curseur.
Nom de ligne de commande :	-label
Nom de base de données :	label
Classe de base de données :	Label
Une chaîne de caractères à afficher comme étiquette du curseur. Pour les curseurs verticaux, l'étiquette est affichée juste à droite de l'extrémité supérieure du curseur. Pour les curseurs horizontaux, l'étiquette est affichée juste au-dessus de l'extrémité gauche du curseur. Si l'option est spécifiée comme une chaîne vide, aucune étiquette n'est affichée.
Nom de ligne de commande :	-length
Nom de base de données :	length
Classe de base de données :	Length
Spécifie la dimension longue souhaitée du curseur en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels). Pour les curseurs verticaux, c'est la hauteur du curseur ; pour les curseurs horizontaux, c'est la largeur du curseur.
Nom de ligne de commande :	-resolution
Nom de base de données :	resolution
Classe de base de données :	Resolution
Une valeur réelle spécifiant la résolution du curseur. Si cette valeur est supérieure à zéro, la valeur du curseur sera toujours arrondie à un multiple pair de cette valeur, de même que les extrémités du curseur. Si la valeur est inférieure à zéro, aucun arrondi n'est effectué. Par défaut, elle vaut 1 (c'est-à-dire que la valeur sera entière).
Nom de ligne de commande :	-showvalue
Nom de base de données :	showValue
Classe de base de données :	ShowValue
Spécifie une valeur booléenne indiquant si la valeur actuelle du curseur doit ou non être affichée.
Nom de ligne de commande :	-sliderlength
Nom de base de données :	sliderLength
Classe de base de données :	SliderLength
Spécifie la taille du curseur, mesurée en unités d'écran le long de la dimension longue du curseur. La valeur peut être spécifiée dans toute forme acceptable par Tk_GetPixels.
Nom de ligne de commande :	-sliderrelief
Nom de base de données :	sliderRelief
Classe de base de données :	SliderRelief
Spécifie le relief à utiliser lors du dessin du curseur, tel que raised (relevé) ou sunken (enfoncé).
Nom de ligne de commande :	-state
Nom de base de données :	state
Classe de base de données :	State
Spécifie l'un des trois états du curseur : normal, active, ou disabled (désactivé). Si le curseur est désactivé, la valeur ne peut pas être modifiée et le curseur ne s'activera pas. Si le curseur est actif, le curseur est affiché en utilisant la couleur spécifiée par l'option -activebackground.
Nom de ligne de commande :	-tickinterval
Nom de base de données :	tickInterval
Classe de base de données :	TickInterval
Doit être une valeur réelle. Détermine l'espacement entre les graduations numériques affichées sous ou à gauche du curseur. Les valeurs seront toutes affichées avec le même nombre de décimales, suffisant pour garantir qu'elles sont toutes précises à 20% d'un intervalle de graduation près. Si la valeur est 0, aucune graduation ne sera affichée.
Nom de ligne de commande :	-to
Nom de base de données :	to
Classe de base de données :	To
Spécifie une valeur réelle correspondant à l'extrémité droite ou inférieure du curseur. Cette valeur peut être inférieure ou supérieure à l'option -from.
Nom de ligne de commande :	-variable
Nom de base de données :	variable
Classe de base de données :	Variable
Spécifie le nom d'une variable globale à lier au curseur. Chaque fois que la valeur de la variable change, le curseur se met à jour pour refléter cette valeur. Chaque fois que le curseur est manipulé interactivement, la variable sera modifiée pour refléter la nouvelle valeur du curseur.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie la dimension étroite souhaitée du curseur en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels). Pour les curseurs verticaux, c'est la largeur du curseur ; pour les curseurs horizontaux, c'est la hauteur du curseur.

DESCRIPTION

La commande scale crée une nouvelle fenêtre (donnée par l'argument nomChemin) et en fait un widget curseur. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du curseur tels que ses couleurs, son orientation et son relief. La commande scale renvoie son argument nomChemin. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée nomChemin, mais le parent de nomChemin doit exister.

Un curseur est un widget qui affiche un *canal* rectangulaire et un petit *curseur*. Le canal correspond à une plage de valeurs réelles (déterminée par les options -from, -to et -resolution), et la position du curseur sélectionne une valeur réelle particulière. La position du curseur (et donc la valeur du curseur) peut être ajustée avec la souris ou le clavier comme décrit dans la section LIAISONS ci-dessous. Chaque fois que la valeur du curseur est modifiée, une commande Tcl est invoquée (en utilisant l'option -command) pour informer les autres widgets intéressés du changement. De plus, la valeur du curseur peut être liée à une variable Tcl (en utilisant l'option -variable), de sorte que les changements dans l'un soient reflétés dans l'autre.

Trois annotations peuvent être affichées dans un widget curseur : une étiquette apparaissant en haut à droite du widget (en haut à gauche pour les curseurs horizontaux), un nombre affiché juste à gauche du curseur (juste au-dessus du curseur pour les curseurs horizontaux), et une collection de graduations numériques juste à gauche de la valeur actuelle (juste en dessous du canal pour les curseurs horizontaux). Chacune de ces trois annotations peut être activée ou désactivée à l'aide des options de configuration.

COMMANDE WIDGET

La commande scale crée une nouvelle commande Tcl dont le nom est nomChemin. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

nomChemin option ?arg arg ...?
Option et les args déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets curseurs :
nomChemin cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir n'importe laquelle des valeurs acceptées par la commande scale.
nomChemin configure ?option? ?

scale(n) — Tk manuals

NOM

scale — un widget curseur

SYNOPIS

scale ?nomChemin?

Options de la ligne de commande : -activebackground -activeforeground -background -borderwidth -command -digits -exportselection -font -foreground -from -height -highlightbackground -highlightcolor -highlightthickness -label -length -orient -repeatdelay -repeatinterval -resolution -showvalue -sliderrelief -sliderwidth -state -takefocus -tickinterval -to -variable -width

DESCRIPTION

Le widget scale (curseur) permet à l'utilisateur de sélectionner une valeur numérique en déplaçant un curseur le long d'une piste. Les curseurs peuvent être orientés horizontalement ou verticalement.

La première ligne de la syntaxe décrit la commande de création du widget scale. Les curseurs peuvent être créés avec la commande scale et le nom d'un widget parent. Les options peuvent être spécifiées en ligne de commande, tout comme pour la plupart des widgets Tk. La commande scale ?nomChemin? sera discutée plus bas.

La section STANDARD OPTIONS décrit les options communes à la plupart des widgets Tk. La section WIDGET-SPECIFIC OPTIONS décrit les options spécifiques au widget scale.

STANDARD OPTIONS

Les options suivantes sont communes à la plupart des widgets Tk : -activebackground, -background, -borderwidth, -exportselection, -font, -foreground, -highlightbackground, -highlightcolor, -highlightthickness, -padx, -pady, -relief, -takefocus, -visual et -width. Voir la page de manuel Tk_GetConfig pour plus d'informations sur ces options.

WIDGET-SPECIFIC OPTIONS

Les options spécifiques au widget scale sont les suivantes : Dans la mesure du possible, les options communes aux widgets Tk sont spécifiées en utilisant la syntaxe standard Tk. Le tableau ci-dessous liste les options spécifiques au widget scale :

-activebackground couleur
Spécifie la couleur d'arrière-plan à utiliser pour le curseur et les marques lorsque le curseur de la souris se trouve dessus.
-activeforeground couleur
Spécifie la couleur de premier plan à utiliser pour le curseur et les marques lorsque le curseur de la souris se trouve dessus.
-background couleur
Spécifie la couleur d'arrière-plan du widget scale. Voir aussi -activebackground.
-borderwidth nombre
Spécifie la largeur de la bordure autour du widget scale. Voir aussi -relief.
-command procédure
Spécifie une procédure à appeler chaque fois que la valeur du curseur change. La procédure sera appelée avec un seul argument, la nouvelle valeur du curseur sous forme de chaîne de caractères. Cette option est généralement utilisée en conjonction avec l'option -variable.
-digits nombre
Spécifie le nombre de chiffres à afficher pour la valeur actuelle du curseur. Cela n'affecte que l'affichage de la valeur si -showvalue est vrai.
-exportselection booléen
Si cette option est vraie, la valeur du curseur est exportée vers la sélection du système lorsque le curseur a le focus. Si elle est fausse, la valeur n'est pas exportée.
-font police
Spécifie la police à utiliser pour afficher la valeur du curseur si -showvalue est vrai.
-foreground couleur
Spécifie la couleur de premier plan du widget scale. Voir aussi -activeforeground.
-from nombre
Spécifie la valeur la plus basse de la plage du curseur. La valeur par défaut est 0.
-height nombre
Spécifie la hauteur du widget scale en unités de texte (voir -width).
-highlightbackground couleur
Couleur du cadre de mise en évidence lorsque le widget n'a pas le focus.
-highlightcolor couleur
Couleur du cadre de mise en évidence lorsque le widget a le focus.
-highlightthickness nombre
Spécifie la largeur du cadre de mise en évidence autour du widget.
-label texte
Spécifie une chaîne de caractères à afficher au-dessus ou à gauche du curseur, en fonction de l'orientation. Ceci est généralement utilisé pour étiqueter le curseur.
-length nombre
Spécifie la longueur du widget scale en pixels. La longueur par défaut est de 100 pixels.
-orient orientation
Spécifie l'orientation du curseur. Les valeurs possibles sont vertical et horizontal (la valeur par défaut).
-repeatdelay nombre
Spécifie le délai en millisecondes avant que le mouvement automatique ne commence lorsque le bouton 1 est maintenu enfoncé dans la piste. La valeur par défaut est de 500 millisecondes.
-repeatinterval nombre
Spécifie l'intervalle en millisecondes entre les mouvements automatiques successifs lorsque le bouton 1 est maintenu enfoncé dans la piste. La valeur par défaut est de 100 millisecondes.
-resolution nombre
Spécifie la résolution du curseur. Chaque fois que le curseur est déplacé, sa valeur est arrondie à l'entier le plus proche multiple de cette résolution. La valeur par défaut est 1.
-showvalue booléen
Si cette option est vraie, la valeur actuelle du curseur est affichée à côté du curseur. La valeur par défaut est vraie.
-sliderrelief relief
Spécifie le style de relief du curseur. Les valeurs possibles sont flat, raised, sunken, groove et ridge. La valeur par défaut est raised.
-sliderwidth nombre
Spécifie la largeur du curseur en pixels. La valeur par défaut est de 20 pixels.
-state état
Spécifie l'état du widget. Les valeurs possibles sont normal et disabled. La valeur par défaut est normal.
-takefocus booléen
Indique si le widget doit recevoir le focus du clavier. La valeur par défaut est vraie.
-tickinterval nombre
Spécifie l'intervalle entre les marques affichées sur la piste du curseur. Si cette option est définie sur 0 (la valeur par défaut), aucune marque n'est affichée. Les marques sont affichées uniquement si cette option est définie sur une valeur positive.
-to nombre
Spécifie la valeur la plus élevée de la plage du curseur. La valeur par défaut est 100.
-variable variable
Associe une variable Tcl à la valeur du curseur. Lorsque la valeur du curseur change, la variable est mise à jour, et vice versa. Si la variable est modifiée, le curseur est mis à jour pour refléter la nouvelle valeur.

WIDGET COMMAND

La commande associée à un widget scale peut être utilisée de plusieurs manières différentes pour interroger ou modifier les propriétés du widget. Les commandes disponibles sont :

nomChemin configure ?option? ?valeur?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options disponibles pour nomChemin (voir Tk_ConfigureInfo pour plus d'informations sur le format de cette liste). Si une option est spécifiée sans valeur, la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie l'option (les options) du widget donné pour avoir la (les) valeur(s) donnée(s) ; dans ce cas, la commande renvoie une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande scale.
nomChemin coords ?valeur?
Renvoie une liste dont les éléments sont les coordonnées x et y du point le long de la ligne médiane de la piste qui correspond à valeur. Si valeur est omis, la valeur actuelle du curseur est utilisée.
nomChemin get ?x y?
Si x et y sont omis, renvoie la valeur actuelle du curseur. Si x et y sont spécifiés, ils donnent les coordonnées en pixels dans le widget ; la commande renvoie la valeur du curseur correspondant au pixel donné. Une seule des coordonnées x ou y est utilisée : pour les curseurs horizontaux, y est ignoré, et pour les curseurs verticaux, x est ignoré.
nomChemin identify x y
Renvoie une chaîne de caractères indiquant quelle partie du curseur se trouve sous les coordonnées données par x et y. Une valeur de retour de slider signifie que le point est au-dessus du curseur ; trough1 signifie que le point est au-dessus de la partie du curseur au-dessus ou à gauche du curseur ; et trough2 signifie que le point est au-dessus de la partie du curseur en dessous ou à droite du curseur. Si le point n'est pas au-dessus de l'un de ces éléments, une chaîne vide est renvoyée.
nomChemin set valeur
Cette commande est invoquée pour changer la valeur actuelle du curseur, et donc la position à laquelle le curseur est affiché. Valeur donne la nouvelle valeur pour le curseur. La commande n'a aucun effet si le curseur est désactivé.

BINDINGS

Tk crée automatiquement des liaisons de classe pour les curseurs qui leur donnent le comportement par défaut suivant. Lorsque le comportement est différent pour les curseurs verticaux et horizontaux, le comportement horizontal est décrit entre parenthèses.

[1]
Si le bouton 1 est pressé dans la piste, la valeur du curseur sera incrémentée ou décrémentée de la valeur de l'option -resolution de sorte que le curseur se déplace dans la direction du curseur de la souris. Si le bouton est maintenu enfoncé, l'action se répète automatiquement.
[2]
Si le bouton 1 est pressé sur le curseur, le curseur peut être déplacé avec la souris.
[3]
Si le bouton 1 est pressé dans la piste avec la touche Control enfoncée, le curseur se déplace jusqu'à l'extrémité de sa plage, dans la direction du curseur de la souris.
[4]
Si le bouton 2 est pressé, la valeur du curseur est définie sur la position de la souris. Si la souris est déplacée avec le bouton 2 enfoncé, la valeur du curseur change avec le déplacement.
[5]
Les touches Haut et Gauche déplacent le curseur vers le haut (à gauche) de la valeur de l'option -resolution.
[6]
Les touches Bas et Droite déplacent le curseur vers le bas (à droite) de la valeur de l'option -resolution.
[7]
Control-Haut et Control-Gauche déplacent le curseur vers le haut (à gauche) de la valeur de l'option -bigincrement.
[8]
Control-Bas et Control-Droite déplacent le curseur vers le bas (à droite) de la valeur de l'option -bigincrement.
[9]
La touche Début déplace le curseur vers l'extrémité supérieure (gauche) de sa plage.
[10]
La touche Fin déplace le curseur vers l'extrémité inférieure (droite) de sa plage.

Si le curseur est désactivé à l'aide de l'option -state, aucune des liaisons ci-dessus n'a d'effet.

Le comportement des curseurs peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.
