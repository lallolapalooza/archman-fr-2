sched_setparam(2) Manuel des appels système sched_setparam(2)

NOM

sched_setparam, sched_getparam - définir et obtenir les paramètres de planification

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sched.h>
int sched_setparam(pid_t pid, const struct sched_param *param);
int sched_getparam(pid_t pid, struct sched_param *param);
struct sched_param {
    ...
    int sched_priority;
    ...
};

DESCRIPTION

sched_setparam() définit les paramètres de planification associés à la politique de planification pour le thread dont l'identifiant de thread est spécifié dans pid. Si pid est zéro, alors les paramètres du thread appelant sont définis. L'interprétation de l'argument param dépend de la politique de planification du thread identifié par pid. Voir sched(7) pour une description des politiques de planification prises en charge sous Linux.

sched_getparam() récupère les paramètres de planification pour le thread identifié par pid. Si pid est zéro, alors les paramètres du thread appelant sont récupérés.

sched_setparam() vérifie la validité de param pour la politique de planification du thread. La valeur param->sched_priority doit se situer dans la plage donnée par sched_get_priority_min(2) et sched_get_priority_max(2).

Pour une discussion sur les privilèges et les limites de ressources liés à la priorité et à la politique de planification, voir sched(7).

Les systèmes POSIX pour lesquels sched_setparam() et sched_getparam() sont disponibles définissent _POSIX_PRIORITY_SCHEDULING dans <unistd.h>.

VALEUR DE RETOUR

En cas de succès, sched_setparam() et sched_getparam() renvoient 0. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
Arguments invalides : param est NULL ou pid est négatif.
EINVAL
(sched_setparam()) L'argument param n'a pas de sens pour la politique de planification actuelle.
EPERM
(sched_setparam()) L'appelant n'a pas les privilèges appropriés (Linux : n'a pas la capacité CAP_SYS_NICE).
ESRCH
Le thread dont l'identifiant est pid n'a pas pu être trouvé.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.
