SCTP_GETPADDRS(3) Manuel du programmeur Linux SCTP_GETPADDRS(3)

NOM

sctp_getpaddrs - Renvoie toutes les adresses de pair dans une association.

SYNTAXE

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_getpaddrs(int sd, sctp_assoc_t assoc_id,
                   struct sockaddr **addrs);

void sctp_freepaddrs(struct sockaddr *addrs);

DESCRIPTION

sctp_getpaddrs renvoie toutes les adresses de pair dans une association. Au retour, addrs pointera vers un tableau compact alloué dynamiquement de structures sockaddr du type approprié pour chaque adresse. L'appelant doit utiliser sctp_freepaddrs pour libérer la mémoire. Notez que le paramètre d'entrée/sortie addrs ne doit pas être NULL.

Si sd est une socket IPv4, les adresses renvoyées seront toutes des adresses IPv4. Si sd est une socket IPv6, les adresses renvoyées peuvent être un mélange d'adresses IPv4 ou IPv6.

Pour les sockets de style un-à-plusieurs, id spécifie l'association à interroger. Pour les sockets de style un-à-un, id est ignoré.

sctp_freepaddrs libère toutes les ressources allouées par sctp_getpaddrs.

VALEUR DE RETOUR

En cas de succès, sctp_getpaddrs renvoie le nombre d'adresses de pair dans l'association. S'il n'y a pas d'association sur cette socket, 0 est renvoyé et la valeur de *addrs est indéfinie. En cas d'erreur, sctp_getpaddrs renvoie -1 et la valeur de *addrs est indéfinie.
