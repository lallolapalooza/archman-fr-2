NOM

sc-hsm-tool - utilitaire de carte à puce pour SmartCard-HSM

SYNTAXE

sc-hsm-tool [OPTIONS]

L'utilitaire sc-hsm-tool peut être utilisé depuis la ligne de commande pour effectuer des tâches de maintenance étendues non disponibles via PKCS#11 ou d'autres outils du paquet OpenSC. Il peut être utilisé pour interroger l'état d'un SmartCard-HSM, initialiser un appareil, générer et importer des parts de DKEK (Device Key Encryption Key) et pour encapsuler et désencapsuler des clés.

OPTIONS

--initialize, -X

Initialise le jeton, supprimant toutes les clés, certificats et fichiers existants.

Utilisez --so-pin pour définir le SO-PIN lors de la première initialisation ou pour le vérifier lors des initialisations ultérieures.

Utilisez --pin pour définir la valeur initiale du PIN utilisateur.

Utilisez --pin-retry pour définir le nombre maximum de présentations erronées du PIN utilisateur.

Utilisez avec --dkek-shares pour activer l'encapsulation/désencapsulation de clés.

Utilisez avec --label pour définir une étiquette de jeton.

Utilisez avec --public-key-auth et --required-pub-keys pour exiger l'authentification par clé publique pour la connexion.

--create-dkek-share nom_fichier, -C nom_fichier

Crée une part de DKEK chiffrée sous un mot de passe et l'enregistre dans le fichier spécifié en paramètre.

Utilisez --password pour fournir un mot de passe pour le chiffrement plutôt que de le demander.

Utilisez --pwd-shares-threshold et --pwd-shares-total pour générer aléatoirement un mot de passe et le diviser en utilisant un schéma de seuil (t, n).

--import-dkek-share nom_fichier, -I nom_fichier

Demande le mot de passe utilisateur, lit et déchiffre la part de DKEK et l'importe dans le SmartCard-HSM.

Utilisez --password pour fournir un mot de passe pour le déchiffrement plutôt que de le demander.

Utilisez --pwd-shares-total pour spécifier le nombre de parts qui doivent être saisies pour reconstruire le mot de passe.

--wrap-key nom_fichier, -W nom_fichier

Encapsule la clé référencée dans --key-reference et l'enregistre avec la description de la clé et le certificat dans le fichier donné.

Utilisez --pin pour fournir le PIN utilisateur sur la ligne de commande.

--unwrap-key nom_fichier, -U nom_fichier

Lit la clé encapsulée, la description et le certificat depuis le fichier et les importe dans le SmartCard-HSM sous la référence de clé indiquée dans --key-reference.

Déterminez la référence de clé à l'aide de la sortie de pkcs15-tool -D.

Utilisez --pin pour fournir un PIN utilisateur sur la ligne de commande.

Utilisez --force pour supprimer toute clé, description de clé ou certificat qui serait sur le chemin.

--dkek-shares nombre-de-parts, -s nombre-de-parts

Définit le nombre de parts de DKEK à utiliser pour recréer le DKEK.

Ceci est un paramètre optionnel. Utiliser --initialize sans --dkek-shares désactivera complètement le DKEK.

Utiliser --dkek-shares avec 0 part demande au SmartCard-HSM de générer un DKEK aléatoire. Les clés encapsulées avec ce DKEK ne pourront être désencapsulées que sur le même SmartCard-HSM.

Après avoir utilisé --initialize avec une ou plusieurs parts de DKEK, le SmartCard-HSM restera dans l'état initialisé jusqu'à ce que toutes les parts de DKEK aient été importées. Pendant cette phase, aucune nouvelle clé ne peut être générée ou importée.

--pin pin, --so-pin sopin,

Ces options peuvent être utilisées pour spécifier les valeurs des PIN sur la ligne de commande. Si la valeur est définie sur env:VARIABLE, la valeur de la variable d'environnement spécifiée est utilisée. Par défaut, le code est demandé sur la ligne de commande si nécessaire.

Notez que sur la plupart des systèmes d'exploitation, n'importe quel utilisateur peut afficher la ligne de commande de n'importe quel processus sur le système en utilisant des utilitaires tels que ps(1). Par conséquent, vous devriez préférer passer les codes via une variable d'environnement sur un système non sécurisé.

--pin-retry valeur

Définit le nombre de tentatives de PIN pour le PIN utilisateur pendant l'initialisation. La valeur par défaut est 3.

--bio-server1 valeur

L'AID hexadécimal du serveur biométrique pour le modèle 1. Active l'utilisation du PIN utilisateur comme PIN de session.

--bio-server2 valeur

L'AID hexadécimal du serveur biométrique pour le modèle 2. Active l'utilisation du PIN utilisateur comme PIN de session.

--password valeur

Définit le mot de passe pour le chiffrement des parts de DKEK. S'il est défini sur env:VARIABLE, la valeur de la variable d'environnement VARIABLE est utilisée.

--pwd-shares-threshold valeur

Définit le seuil pour le nombre de parts de mot de passe requises pour la reconstruction.

--pwd-shares-total valeur

Définit le nombre de parts de mot de passe.

--force

Force la suppression de la clé, de la description et du certificat existants.

--label etiquette, -l etiquette

Définit l'étiquette du jeton à utiliser pour --initialize.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte insérée est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--public-key-auth nombre-total-de-clés-publiques, -K nombre-total-de-clés-publiques

Définit le nombre total de clés publiques à utiliser pour l'authentification par clé publique lors de l'utilisation de --initialize. --public-key-auth est facultatif, mais s'il est présent, il doit être utilisé avec --required-pub-keys.

Lorsque le SmartCard-HSM est initialisé avec ces options, il exigera l'utilisation de l'authentification par clé publique M sur N, où --required-pub-keys définit M et --public-key-auth définit N. Après l'initialisation, l'utilisateur doit utiliser --register-public-key pour enregistrer les N clés publiques avant que le SmartCard-HSM puisse être utilisé.

--required-pub-keys nombre-requis-de-clés-publiques, -n nombre-requis-de-clés-publiques

Définit le nombre requis de clés publiques à utiliser pour l'authentification par clé publique lors de l'utilisation de --initialize. C'est le M dans l'authentification par clé publique M sur N. Voir --public-key-auth pour plus d'informations.

--register-public-key fichier-clé-publique-entrée, -g fichier-clé-publique-entrée

Enregistre une clé publique à utiliser pour l'authentification par clé publique M sur N. Le fichier peut être exporté depuis un autre SmartCard-HSM avec --export-for-pub-key-auth. Ceci ne peut être utilisé que lorsque le SmartCard-HSM a été initialisé avec --public-key-auth et --required-pub-keys et que moins de N clés publiques ont été enregistrées. Utilisez --public-key-auth-status pour vérifier combien de clés publiques ont été enregistrées.

--export-for-pub-key-auth fichier-clé-publique-sortie, -e fichier-clé-publique-sortie

Export une clé publique à utiliser pour l'authentification par clé publique M sur N. Ceci doit être utilisé avec --key-reference pour choisir la clé à exporter. Le fichier doit être enregistré sur un autre SmartCard-HSM en utilisant --register-public-key.

--public-key-auth-status -S

Affiche l'état de l'authentification par clé publique. Ceci n'est valide que si le SmartCard-HSM a été initialisé pour utiliser l'authentification par clé publique M sur N.

--wait, -w

Attend qu'une carte soit insérée.

--verbose, -v

Rend sc-hsm-tool plus verbeux. Spécifiez cet indicateur plusieurs fois pour activer la sortie de débogage dans la bibliothèque opensc.

EXEMPLES

Créer une part de DKEK :

sc-hsm-tool --create-dkek-share dkek-share-1.pbe

Créer une part de DKEK avec un mot de passe aléatoire divisé en utilisant un schéma de seuil (3, 5) :

sc-hsm-tool --create-dkek-share dkek-share-1.pbe --pwd-shares-threshold 3 --pwd-shares-total 5

Initialiser le SmartCard-HSM pour utiliser une seule part de DKEK :

sc-hsm-tool --initialize --so-pin 3537363231383830 --pin 648219 --dkek-shares 1 --label monjeton

Importer une part de DKEK :

sc-hsm-tool --import-dkek-share dkek-share-1.pbe

sc-hsm-tool(1) - opensc

NAME

sc-hsm-tool - Tool for configuring the SafeNet/Thales Luna (formerly)Rockey/SCM Smartcard-HSM

SYNOPSIS

sc-hsm-tool [OPTIONS]...

OPTIONS

This tool supports the following options:

--initialize
Initialize the SmartCard-HSM. Requires authentication. The default PIN is 00000000. This command will wipe all data from the HSM and set it to factory defaults. WARNING: All data will be lost!
--pin PIN
Specify the PIN for authentication.
--login PIN
Specify the PIN for login.
--pwd-shares-total N
Set the total number of password shares for password-based encryption (PBE). The default is 1, meaning no PBE.
--import-dkek-share FILE
Import a DKEK share from FILE. The DKEK is used for encrypting transport keys. Requires authentication.
--wrap-key FILE
Export a key from the HSM, encrypt it using the DKEK and save it to FILE. Requires authentication.
--unwrap-key FILE
Import an encrypted key from FILE into the HSM. Requires authentication.
--key-reference N
Specify the key reference number (1-100) for operations involving key wrapping/unwrapping or M-of-N public key authentication.
--wrap-pubkey FILE
Export a public key from the HSM, encrypt it using the DKEK and save it to FILE. Requires authentication.
--unwrap-pubkey FILE
Import an encrypted public key from FILE into the HSM. Requires authentication.
--initialize-key-storage
Initialize the key storage. This must be done before any keys can be stored on the HSM. Requires authentication.
--wrap-key-storage FILE
Export the encrypted key storage from the HSM. Requires authentication.
--unwrap-key-storage FILE
Import the encrypted key storage into the HSM. Requires authentication.
--required-pub-keys M
Set the number of required public keys (M) for M-of-N public key authentication. Requires initialization. Requires authentication.
--public-key-auth N
Set the total number of public keys (N) for M-of-N public key authentication. Requires initialization. Requires authentication.
--export-for-pub-key-auth FILE
Export a public key for M-of-N public key authentication to FILE. Requires authentication.
--register-public-key FILE
Register a public key from FILE for M-of-N public key authentication. Requires authentication.
--delete-key N
Delete the key with reference N from the HSM. Requires authentication.
--delete-all-keys
Delete all keys from the HSM. Requires authentication.
--list-keys
List all keys stored on the HSM.
--change-pin OLD_PIN NEW_PIN
Change the user PIN.
--change-admin-pin OLD_PIN NEW_PIN
Change the admin PIN. Requires administrator privileges.
--factory-reset
Reset the SmartCard-HSM to factory defaults. This is irreversible and will erase all data. Requires administrator privileges.
--force
Force the operation. Use with caution.
-h, --help
Display help message and exit.
-v, --version
Display version information and exit.

EXAMPLES

Import DKEK share using a password split up using a (3, 5) threshold scheme for encryption:

sc-hsm-tool --import-dkek-share dkek-share-1.pbe --pwd-shares-total 3

Wrap referenced key, description and certificate:

sc-hsm-tool --wrap-key wrap-key.bin --key-reference 1 --pin 648219

Unwrap key into same or in different SmartCard-HSM with the same DKEK:

sc-hsm-tool --unwrap-key wrap-key.bin --key-reference 10 --pin 648219 --force

Initialize SmartCard-HSM to use M-of-N public key authentication with M=2 and N=5

sc-hsm-tool --initialize --required-pub-keys 2 --public-key-auth 5

Export a public key for M-of-N public key authentication to a file

sc-hsm-tool --key-reference 1 --export-for-pub-key-auth ./public_key1.asn1

Register a public key for M-of-N public key authentication from a file

sc-hsm-tool --register-public-key ./public_key1.asn1
