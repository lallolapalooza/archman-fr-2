scalbln(3) Manuel des fonctions de bibliothèque scalbln(3)

NOM

scalbn, scalbnf, scalbnl, scalbln, scalblnf, scalblnl - mise à l'échelle par une puissance entière du radix

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double scalbln(double x, long e);
float scalblnf(float x, long e);
long double scalblnl(long double x, long e);
double scalbn(double x, int e);
float scalbnf(float x, int e);
long double scalbnl(long double x, int e);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

scalbln(), scalblnf(), scalblnl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE

scalbn(), scalbnf(), scalbnl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions multiplient leur premier argument x par FLT_RADIX (probablement 2) élevé à la puissance e, c'est-à-dire :

    x * FLT_RADIX ** e

La définition de FLT_RADIX peut être obtenue en incluant <float.h>.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent x * FLT_RADIX ** e.

Si x est un NaN, un NaN est retourné.

Si x est l'infini positif (infini négatif), l'infini positif (l'infini négatif) est retourné.

Si x est +0 (-0), +0 (-0) est retourné.

Si le résultat dépasse les limites (overflow), une erreur de plage se produit, et les fonctions retournent HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement, avec un signe identique à celui de x.

Si le résultat est inférieur aux limites (underflow), une erreur de plage se produit, et les fonctions retournent zéro, avec un signe identique à celui de x.

ERREURS

Voir math_error(7) pour des informations sur la façon de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de plage, dépassement (overflow)
Une exception à virgule flottante de dépassement (FE_OVERFLOW) est déclenchée.
Erreur de plage, sous-dépassement (underflow)
errno est défini sur ERANGE. Une exception à virgule flottante de sous-dépassement (FE_UNDERFLOW) est déclenchée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
scalbn (), scalbnf (), scalbnl (), scalbln (), scalblnf (), scalblnl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

HISTORIQUE

Ces fonctions diffèrent des fonctions obsolètes décrites dans scalb(3) par le type de leur deuxième argument. Les fonctions décrites sur cette page ont un deuxième argument de type entier, tandis que celles de scalb(3) ont un deuxième argument de type double.

NOTES

Si FLT_RADIX est égal à 2 (ce qui est habituel), alors scalbn() est équivalent à ldexp(3).

BOGUES

Avant glibc 2.20, ces fonctions ne définissaient pas errno pour les erreurs de plage.

VOIR AUSSI

ldexp(3), scalb(3)
