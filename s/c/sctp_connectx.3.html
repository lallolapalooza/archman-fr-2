SCTP_CONNECTX(3) Manuel du programmeur Linux SCTP_CONNECTX(3)

NOM

sctp_connectx - initier une connexion sur une socket SCTP utilisant plusieurs adresses de destination.

SYNOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_connectx(int sd, struct sockaddr * addrs, int addrcnt,
                  sctp_assoc_t  * id);

DESCRIPTION

sctp_connectx initie une connexion vers un ensemble d'adresses passées dans le tableau addrs depuis/vers la socket sd. addrcnt est le nombre d'adresses dans le tableau.

Si sd est une socket IPv4, les adresses passées doivent être des adresses IPv4. Si sd est une socket IPv6, les adresses passées peuvent être des adresses IPv4 ou IPv6.

addrs est un pointeur vers un tableau d'une ou plusieurs adresses de socket. Chaque adresse est contenue dans sa structure appropriée (c'est-à-dire, struct sockaddr_in ou struct sockaddr_in6). La famille du type d'adresse doit être utilisée pour distinguer la longueur de l'adresse. L'appelant spécifie le nombre d'adresses dans le tableau avec addrcnt.

id est un pointeur vers l'identifiant de l'association et, s'il est fourni, sera défini avec l'identifiant de la nouvelle association créée.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. En cas d'échec, -1 est retourné et errno est défini de manière appropriée.

ERREURS

EBADF
sd n'est pas un descripteur valide.
ENOTSOCK
sd est un descripteur de fichier, pas de socket.
EFAULT
Erreur lors de la copie dans ou hors de l'espace d'adressage utilisateur.
EINVAL
Port ou adresse invalide.
EACCES
L'adresse est protégée et l'utilisateur n'est pas le super-utilisateur.
EISCONN
La socket est déjà connectée.
ECONNREFUSED
Personne n'écoute sur l'adresse distante.
ETIMEDOUT
Délai d'attente dépassé lors de la tentative de connexion. Le serveur est peut-être trop occupé pour accepter de nouvelles connexions. Notez que pour les sockets IP, le délai d'attente peut être très long lorsque les syncookies sont activés sur le serveur.
ENETUNREACH
Le réseau est inaccessible.
EADDRINUSE
L'adresse locale est déjà utilisée.
EINPROGRESS
La socket n'est pas bloquante et la connexion ne peut pas être terminée immédiatement. Il est possible d'select(2) ou poll(2) pour l'achèvement en sélectionnant la socket pour l'écriture. Après que select indique l'aptitude à l'écriture, utilisez getsockopt(2) pour lire l'option SO_ERROR au niveau SOL_SOCKET afin de déterminer si connect s'est terminée avec succès (SO_ERROR est zéro) ou avec un échec (SO_ERROR est l'un des codes d'erreur usuels listés ici, expliquant la raison de l'échec).
EALREADY
La socket n'est pas bloquante et une précédente tentative de connexion n'a pas encore été terminée.
EAGAIN
Plus de ports locaux libres ou entrées insuffisantes dans le cache de routage. Pour PF_INET, voir le sysctl net.ipv4.ip_local_port_range dans ip(7) sur la façon d'augmenter le nombre de ports locaux.
EAFNOSUPPORT
L'adresse passée n'avait pas la bonne famille d'adresses dans son champ sa_family.
EACCES, EPERM
L'utilisateur a tenté de se connecter à une adresse de diffusion sans avoir l'indicateur de diffusion de la socket activé ou la requête de connexion a échoué en raison d'une règle de pare-feu local.
