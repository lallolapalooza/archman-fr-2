NOM

scsi_temperature - récupérer la température d'un périphérique SCSI

SYNOPIS

scsi_temperature [--aide] [--verbeux] PÉRIPHÉRIOUE [PÉRIPHÉRIOUE]*

DESCRIPTION

Ce script shell bash appelle l'utilitaire sg_logs sur chaque PÉRIPHÉRIOUE donné afin de trouver la température du périphérique. La page de journal de température est vérifiée en premier et si elle n'est pas disponible, alors la page de journal des exceptions d'information est vérifiée.

OPTIONS

Les arguments pour les options longues sont obligatoires, même pour les options courtes.

-h, --aide
afficher le message d'utilisation puis quitter.
-v, --verbeux
augmenter le niveau de verbosité.

STATUT DE SORTIE

Le statut de sortie de ce script est 0 en cas de succès. Sinon, le statut de sortie est celui de la dernière commande sg_logs appelée. Voir la page de manuel sg3_utils(8).
