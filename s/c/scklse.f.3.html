Documentation de la fonction/sous-routine

subroutine scklse (integer nn, integer, dimension( * ) mval, integer, dimension( * ) pval, integer, dimension( * ) nval, integer nmats, integer, dimension( 4 ) iseed, real thresh, integer nmax, real, dimension( * ) a, real, dimension( * ) af, real, dimension( * ) b, real, dimension( * ) bf, real, dimension( * ) x, real, dimension( * ) work, real, dimension( * ) rwork, integer nin, integer nout, integer info)

SCKLSE

But :

!>
!> SCKLSE teste SGGLSE - une sous-routine pour résoudre le problème des moindres carrés linéaires à contraintes (LSE).
!>

Paramètres

NN 
!>          NN est un ENTIER
!>          Le nombre de valeurs de (M,P,N) contenues dans les vecteurs
!>          (MVAL, PVAL, NVAL).
!>

MVAL

!>          MVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension M (lignes/colonnes) de la matrice.
!>

PVAL

!>          PVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension P (lignes/colonnes) de la matrice.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>          Les valeurs de la dimension N (colonnes/lignes) de la matrice.
!>

NMATS

!>          NMATS est un ENTIER
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour les tests. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          À la sortie, la graine suivante dans la séquence aléatoire après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un REEL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau REEL, dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau REEL, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau REEL, dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau REEL, dimension (NMAX*NMAX)
!>

X

!>          X est un tableau REEL, dimension (5*NMAX)
!>

WORK

!>          WORK est un tableau REEL, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau REEL, dimension (NMAX)
!>

NIN

!>          NIN est un ENTIER
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Sortie réussie
!>          > 0 : Si SLATMS renvoie un code d'erreur, sa valeur absolue
!>                 est renvoyée.
!>
