SCRIPTLIVE(1) Commandes utilisateur SCRIPTLIVE(1)

NOM

scriptlive - relire des enregistrements de session, en utilisant les informations de synchronisation

SYNOPSIS

scriptlive [options] fichier_synchronisation enregistrement

DESCRIPTION

Ce programme relit un enregistrement, en utilisant l'enregistrement stdin et les informations de synchronisation pour s'assurer que les entrées se produisent dans le même rythme qu'elles sont apparues à l'origine lorsque le script a été enregistré.

La session est exécutée dans un pseudo-terminal nouvellement créé avec le $SHELL de l'utilisateur (ou par défaut /bin/bash).

Soyez prudent ! L'enregistrement peut contenir des commandes arbitraires. Il est recommandé d'utiliser "scriptreplay --stream in --log-in enregistrement" (ou avec --log-io au lieu de --log-in) pour vérifier l'enregistrement avant qu'il ne soit exécuté avec scriptlive.

Les informations de synchronisation sont ce que script(1) sort vers le fichier spécifié par --log-timing. L'enregistrement doit contenir les informations stdin, et c'est ce que script(1) sort vers le fichier spécifié par --log-in ou --log-io.

OPTIONS

-I, --log-in fichier

Fichier contenant l'entrée du terminal de script.

-B, --log-io fichier

Fichier contenant la sortie et l'entrée du terminal de script.

-E, --echo quand

Cette option contrôle le drapeau ECHO pour l'extrémité esclave du pseudo-terminal de la session. Les modes supportés sont always, never, et auto.

Le défaut est auto — dans ce cas, ECHO est activé. Ce comportement par défaut est susceptible de changer.

-t, --timing fichier

Fichier contenant la sortie de synchronisation de script. Cette option remplace l'argument positionnel fichier_synchronisation.

-T, --log-timing fichier

Un alias pour -t ; maintenu pour la compatibilité avec les options de ligne de commande de script(1).

-d, --divisor nombre

Accélérer la relecture en affichant ce nombre de fois. L'argument est un nombre à virgule flottante. Il est appelé diviseur car il divise les timings par ce facteur. Cette option remplace les arguments à l'ancienne.

-m, --maxdelay nombre

Définir le délai maximum entre les mises à jour à nombre secondes. L'argument est un nombre à virgule flottante. Ceci peut être utilisé pour éviter de longues pauses dans la relecture de l'enregistrement.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

EXEMPLES

% script --log-timing fichier.tm --log-in script.in
Script started, file is script.out
% date
<etc, etc>
% exit
Script done, file is script.out
% scriptlive --log-timing fichier.tm --log-in script.in
