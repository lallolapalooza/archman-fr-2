NOM

scummvm — interpréteur de jeux d'aventure et de rôle

SYNTAXE

scummvm [OPTIONS] [JEU]

DESCRIPTION

scummvm est un interpréteur qui permet de jouer à de nombreux jeux d'aventure et de rôle basés sur divers moteurs de jeu.

JEU est un nom court du jeu à charger. Il peut s'agir soit d'un identifiant de jeu intégré (tel que donné par --list-games), soit d'une cible configurée par l'utilisateur (telle que donnée par --list-targets).

OPTIONS

Le sens de la plupart des options longues (c'est-à-dire celles commençant par un double trait d'union) peut être inversé en les faisant précéder de no-. Par exemple, --no-aspect-ratio désactivera la correction du rapport d'aspect. Ceci est utile si vous souhaitez outrepasser un paramètre du fichier de configuration.

-a | --ajouter
Ajoute tous les jeux du répertoire actuel ou spécifié (avec --chemin=CHEMIN). Si --jeu=ID est passé, seul le jeu avec l'id ID est ajouté.

--[no-]alt-intro
Active/désactive l'introduction alternative pour les versions CD de Beneath a Steel Sky et Flight of the Amazon Queen (par défaut : désactivé).
--[no-]aspect-ratio
Active/désactive la correction du rapport d'aspect.
--auto-detect
Affiche une liste de jeux du répertoire courant ou spécifié, et démarre le premier. Utilisez --path=PATH pour spécifier un répertoire.
--cdrom=DRIVE
Définit le lecteur à utiliser pour lire l'audio CD ; peut être un lecteur, un chemin ou un index numérique (par défaut : 0 = lecteur le mieux adapté).
--[no-]copy-protection
Active la protection contre la copie dans les jeux, lorsque ScummVM la désactive par défaut.
--[no-]dirtyrects
Active/désactive l'optimisation des rectangles sales dans le rendu logiciel (par défaut : activé).
--debug-channels-only
N'affiche que les canaux de débogage spécifiés.
--debugflags=FLAGS
Active les drapeaux de débogage spécifiques au moteur (séparés par des virgules).
--[no-]demo-mode
Active/désactive le mode démo de Maniac Mansion ou The 7th Guest (par défaut : désactivé).
--detect
Affiche une liste de jeux avec leur ID du répertoire courant ou spécifié sans l'ajouter au fichier de configuration. Utilisez --path=PATH pour spécifier un répertoire.
--dump-midi
Vide les événements MIDI dans dump.mid (en l'écrasant), jusqu'à la sortie du jeu.
--enable-gs
Active les mappages de patch pour émuler un MT-32 sur un appareil Roland GS pour la lecture MIDI.
--engine=ID
En combinaison avec --list-games, --list-all-games, --list-targets, ou --stats, ne liste que les jeux pour ce moteur. Plusieurs moteurs peuvent être listés séparés par une virgule.
--engine-speed=NUM
Définit la limite d'images par seconde (0-100) pour les jeux 3D, 0 = pas de limite (par défaut : 60).
--[no-]exit
En combinaison avec les commandes qui se terminent après leur exécution, comme --add ou --list-engines, bascule entre l'ouverture du lanceur et la sortie.
--extrapath=PATH
Définit le chemin supplémentaire pour les données de jeu et ScummVM additionnelles.
--[no-]filtering
Force le mode graphique filtré/non filtré. Le mode graphique filtré utilise l'interpolation bilinéaire tandis que le mode graphique non filtré utilise le voisin le plus proche.
--game=ID
En combinaison avec --add ou --detect, ajoute ou tente de détecter uniquement le jeu avec l'ID ID.
--gui-theme=THEME
Sélectionne un thème d'interface graphique, tel que donné par --list-themes.
--joystick[=NUM]
Active l'entrée joystick (par défaut : 0 = premier joystick).
--iconspath=PATH
Définit le chemin vers les icônes supplémentaires pour la vue de la grille du lanceur.
--list-all-debugflags
Affiche la liste de tous les drapeaux de débogage des moteurs et quitte.
--list-all-engines
Affiche la liste de tous les moteurs de détection et quitte.
--list-all-games
Affiche la liste de tous les jeux détectés et quitte.
--list-audio-devices
Liste tous les périphériques audio disponibles et quitte.
--list-debugflags[=ENGINE]
Affiche la liste des drapeaux de débogage spécifiés pour le moteur et quitte. Si l'argument ENGINE est « global » ou s'il n'est pas spécifié, liste les drapeaux de débogage globaux.
--list-engines
Affiche la liste des moteurs supportés et quitte.
--list-saves
Affiche une liste des sauvegardes pour la cible spécifiée avec --game=TARGET, ou toutes les cibles si aucune n'est spécifiée, et quitte.
--list-themes
Affiche la liste de tous les thèmes d'interface graphique utilisables et quitte.
--md5
Affiche le hachage MD5 du fichier donné par --md5-path=PATH. Si --md5-length=NUM est passé, alors affiche le hachage MD5 des NUM premiers octets (si positif) ou derniers (si négatif) du fichier donné par PATH. Si --md5-engine=ENGINE_ID est passé, récupère automatiquement la longueur MD5, remplaçant --md5-length.
--md5mac
Similaire à --md5, mais pour les anciens fichiers Macintosh. Affiche le hachage MD5 pour la fourche de ressources et la fourche de données du fichier.
--midi-gain=NUM
Définit le gain pour la lecture MIDI, 0-1000 (par défaut : 100). Uniquement supporté par certains pilotes MIDI.
--multi-midi
Active la combinaison d'AdLib et de MIDI natif.
--native-mt32
Indique à ScummVM que le périphérique MIDI est un véritable Roland MT-32 ou un appareil compatible. Cela désactive toute émulation GM.
--opl-driver=DRIVER
Sélectionne l'émulateur AdLib (OPL) (alsa, db, mame, nuked, opl2lpt).
--output-channels=RATE
Définit le nombre de canaux de sortie (par ex. 2 pour stéréo).
--output-rate=RATE
Définit le taux d'échantillonnage de sortie en Hz (par ex. 22050).
--platform=PLATFORM
Spécifie la plateforme du jeu (2gs, 3do, acorn, amiga, android, apple2, atari, atari8, beos, c64, cdi, coco, coco3, cpc, fmtowns, ios, linux, macintosh, macintosh2, megadrive, nes, os2, pc, pc98, pce, pippin, playstation, playstation2, ppc, saturn, segacd, shockwave, ti994, wii, windows, xbox, zx).

OPTIONS

--[no-]save-seed
Définit le nombre de graines aléatoires utilisé pour initialiser l'entropie.
--[no-]recursive
En combinaison avec --add ou --detect, parcourt récursivement tous les sous-répertoires (par défaut : désactivé).
--render-mode=MODE
Active des modes de rendu supplémentaires (2gs, amiga, atari, c64, cga, cgaBW, cgaComp, cpc, ega, fmtowns, hercAmber, hercGreen, macintosh, macintoshbw, pc9801, pc9821, vga, zx).
--renderer=RENDERER
Sélectionne le moteur de rendu 3D (opengl, opengl_shaders, software).
--savepath=PATH
Spécifie où les sauvegardes de jeux sont stockées.
--scale-factor=FACTOR
Définit le facteur de mise à l'échelle des graphismes.
--scaler=MODE
Sélectionne le mode de mise à l'échelle graphique (normal, hq, edge, advmame, sai, supersai, supereagle, pm, dotmatrix, tv2x).
--screenshotpath=PATH
Spécifie le chemin où les captures d'écran sont créées.
--[no-]show-fps
Affiche/masque les informations FPS dans les jeux 3D.
--soundfont=FILE
Sélectionne le SoundFont pour la lecture MIDI (uniquement pris en charge par certains pilotes MIDI).
--start-movie=NAME@NUM
Démarre le film à une image spécifique pour Director. Chaque argument peut être spécifié indépendamment de l'autre.
--stats
Affiche les statistiques sur les moteurs et les jeux, puis quitte.
--stretch-mode=MODE
Sélectionne le mode d'étirement (center, even-pixels, fit, fit_force_aspect, pixel-perfect, stretch).
--talkspeed=NUM
Définit le délai de dialogue pour les jeux SCUMM, ou la vitesse de dialogue pour les autres jeux.
--tempo=NUM
Définit le tempo de la musique (en pourcentage, 50–200) pour les jeux SCUMM (par défaut : 100).
--themepath=PATH
Définit le chemin d'accès aux thèmes de l'interface graphique.
--window-size=W,H
Définit la taille de la fenêtre aux dimensions spécifiées (OpenGL uniquement).

ENVIRONNEMENT

SCUMMVM_MIDI
Le périphérique séquenceur à utiliser avec le pilote MIDI ‘seq’.
SCUMMVM_MIDIPORT
Le numéro du séquenceur à utiliser avec le pilote MIDI ‘seq’.
SCUMMVM_PORT
Le port ALSA à ouvrir en sortie avec le pilote MIDI ‘alsa’.
SCUMMVM_SAVEPATH
Remplace le chemin de sauvegarde par défaut (systèmes POSIX).

FICHIERS

$HOME/.config/scummvm/scummvm.ini
Fichier de configuration sur la plupart des systèmes Unix. Les variables d'environnement XDG ont la priorité, si elles sont définies.
$HOME/Library/Preferences/ScummVM Preferences
Fichier de configuration sur macOS.

EXEMPLES

Lancement du lanceur de jeu intégré :

$ scummvm

Lancement de Day of the Tentacle, en spécifiant le chemin :

$ scummvm -p /usr/local/share/games/tentacle scumm:tentacle

Lancement de The Dig avec le filtre advmame2x et les sous-titres (la cible dig-steam étant déjà définie dans le fichier de configuration) :

$ scummvm --scaler=advmame --scale-factor=2 -n dig-steam

Lancement de la version italienne de Maniac Mansion en plein écran, depuis le contenu du répertoire courant :

$ scummvm -q it -f scumm:maniac
