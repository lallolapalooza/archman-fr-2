programme sblat2

SBLAT2

Objectif :

!>
!> Programme de test pour le BLAS réel de niveau 2.
!>
!> Le programme doit être piloté par un fichier de données court. Les 18 premières lignes
!> du fichier sont lues en utilisant une entrée dirigée par liste, les 16 dernières lignes
!> sont lues en utilisant le format ( A6, L2 ). Un exemple annoté de fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 34 lignes suivantes :
!> 'sblat2.out'      NOM DU FICHIER DE SORTIE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉSUMÉ
!> 'SBLAT2.SNAP'     NOM DU FICHIER DE CONSERVATION INSTANTANÉE
!> -1                NUMÉRO D'UNITÉ DU FICHIER DE CONSERVATION INSTANTANÉE (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner le FICHIER DE CONSERVATION INSTANTANÉE APRÈS CHAQUE LIGNE.
!> F        INDICATEUR LOGIQUE, T POUR S'ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUILE DU RATIO DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> 0.0 1.0 0.7       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 0.9       VALEURS DE BETA
!> SGEMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SGBMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SSYMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SSBMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SSPMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> STRMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> STBMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> STPMV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> STRSV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> STBSV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> STPSV  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SGER   T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SSYR   T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SSPR   T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SSYR2  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!> SSPR2  T POUR EFFECTUER LE TEST. MÊMES COLONNES.
!>
!> Détails supplémentaires

!>       Dongarra J. J., Du Croz J. J., Hammarling S. et Hanson R. J..
