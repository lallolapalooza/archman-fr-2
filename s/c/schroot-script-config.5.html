NOM

schroot-script-config - configuration des scripts de configuration de chroot schroot

DESCRIPTION

schroot utilise des scripts pour configurer puis nettoyer l'environnement chroot. Ces scripts peuvent être personnalisés en utilisant la clé script-config dans /etc/schroot/schroot.conf. Cette clé spécifie un fichier que les scripts de configuration sourceront lorsqu'ils seront exécutés. Le fichier est un script shell Bourne, et par conséquent, il peut contenir tout code shell valide, en plus des simples affectations de variables. Cela permettra, par exemple, de personnaliser le comportement en fonction du type ou du nom spécifique du chroot.

Ce fichier est déprécié, mais il est toujours utilisé s'il est présent ; il sera obsolète et supprimé dans une future version. Tous les paramètres de ce fichier peuvent maintenant être définis à l'aide de clés de configuration dans schroot.conf, comme détaillé ci-dessous. La configuration existante doit être modifiée pour utiliser ces clés à la place de ce fichier.

ENVIRONNEMENT

L'environnement est le même que pour tous les scripts de configuration, décrit dans schroot-setup(5).

VARIABLES

Les variables suivantes peuvent être définies pour configurer le comportement des scripts de configuration. Notez que de nouvelles variables pourront être ajoutées dans les futures versions. Les extensions tierces de schroot qui ajoutent leurs propres scripts de configuration peuvent ajouter des variables supplémentaires non documentées ici ; consultez la documentation de l'extension pour plus de détails.

SETUP_COPYFILES
Un fichier contenant une liste de fichiers à copier dans le chroot (un fichier par ligne). Le fichier aura le même emplacement absolu à l'intérieur du chroot. Notez que ceci est configurable en utilisant la clé setup.copyfiles.
SETUP_FSTAB
Le fichier de table des systèmes de fichiers à utiliser pour monter les systèmes de fichiers dans le chroot. Le format de ce fichier est le même que pour /etc/fstab, documenté dans fstab(5). La seule différence est que le chemin du point de montage fs_dir est relatif au chroot, plutôt qu'à la racine. Notez que ceci est configurable en utilisant la clé setup.fstab. Notez également que les points de montage sont canonisés sur l'hôte, ce qui garantira que les liens symboliques absolus pointent à l'intérieur du chroot, mais les chemins complexes contenant plusieurs liens symboliques peuvent être résolus incorrectement ; il est conseillé de ne pas utiliser de liens symboliques imbriqués comme points de montage.
SETUP_NSSDATABASES
Un fichier listant les bases de données système à copier dans le chroot. Les bases de données par défaut sont ‘passwd’, ‘shadow’, ‘group’, ‘services’, ‘protocols’, ‘networks’, et ‘hosts’. ‘gshadow’ n'est pas encore copié par défaut, car il n'est pas supporté par toutes les versions de la bibliothèque C GNU sauf les plus récentes. Les bases de données sont copiées à l'aide de getent(1), donc toutes les sources de bases de données listées dans /etc/nsswitch.conf seront utilisées pour chaque base de données. Notez que ceci est configurable en utilisant la clé setup.nssdatabases.
