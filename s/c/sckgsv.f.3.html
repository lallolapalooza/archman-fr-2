sous-routine sckgsv (integer nm, integer, dimension( * ) mval, integer, dimension( * ) pval, integer, dimension( * ) nval, integer nmats, integer, dimension( 4 ) iseed, real thresh, integer nmax, real, dimension( * ) a, real, dimension( * ) af, real, dimension( * ) b, real, dimension( * ) bf, real, dimension( * ) u, real, dimension( * ) v, real, dimension( * ) q, real, dimension( * ) alpha, real, dimension( * ) beta, real, dimension( * ) r, integer, dimension( * ) iwork, real, dimension( * ) work, real, dimension( * ) rwork, integer nin, integer nout, integer info)

SCKGSV

Objectif :

!>
!> SCKGSV teste SGGSVD :
!>        la GSVD pour la matrice A de M x N et la matrice B de P x N.
!>

Paramètres

NM 
!>          NM est un entier
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'entiers, dimensionné (NM)
!>          Les valeurs de la dimension des lignes de la matrice M.
!>

PVAL

!>          PVAL est un tableau d'entiers, dimensionné (NP)
!>          Les valeurs de la dimension des lignes de la matrice P.
!>

NVAL

!>          NVAL est un tableau d'entiers, dimensionné (NN)
!>          Les valeurs de la dimension des colonnes de la matrice N.
!>

NMATS

!>          NMATS est un entier
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions de matrices. Si NMATS >= NTYPES (le nombre maximal
!>          de types de matrices), alors tous les types différents sont
!>          générés pour les tests. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimensionné (4)
!>          En entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          En sortie, la prochaine graine dans la séquence de nombres aléatoires
!>          après la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un réel
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un entier
!>          La valeur maximale permise pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau de réels, dimensionné (NMAX*NMAX)
!>

AF

!>          AF est un tableau de réels, dimensionné (NMAX*NMAX)
!>

B

!>          B est un tableau de réels, dimensionné (NMAX*NMAX)
!>

BF

!>          BF est un tableau de réels, dimensionné (NMAX*NMAX)
!>

U

!>          U est un tableau de réels, dimensionné (NMAX*NMAX)
!>

V

!>          V est un tableau de réels, dimensionné (NMAX*NMAX)
!>

Q

!>          Q est un tableau de réels, dimensionné (NMAX*NMAX)
!>

ALPHA

!>          ALPHA est un tableau de réels, dimensionné (NMAX)
!>

BETA

!>          BETA est un tableau de réels, dimensionné (NMAX)
!>

R

!>          R est un tableau de réels, dimensionné (NMAX*NMAX)
!>

IWORK

!>          IWORK est un tableau d'entiers, dimensionné (NMAX)
!>

WORK

!>          WORK est un tableau de réels, dimensionné (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau de réels, dimensionné (NMAX)
!>

NIN

!>          NIN est un entier
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un entier
!>          = 0 :  sortie réussie
!>          > 0 :  Si SLATMS renvoie un code d'erreur, sa valeur absolue
!>                 est retournée.
!>
