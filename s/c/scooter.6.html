NOM

scooter - affiche un voyage à travers un tunnel spatial et des étoiles

SYNTAXE

scooter [--display hôte:écran.numéro] [--mono] [--delay millisecondes] [--cycles cycles] [--count nombre] [--size taille] [--ncolors couleurs] [--window] [--root] [--window-id numéro][--install | --noinstall] [--visual visuel] [--fps | --no-fps] [--pair]

DESCRIPTION

scooter est un économiseur d'écran qui montre un voyage sans fin à travers un tunnel spatial et des étoiles.

OPTIONS

scooter accepte les options suivantes :

--window
Dessiner sur une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--delay millisecondes
Quel délai introduire entre les étapes de l'animation. Par défaut 10, soit environ 1/100ème de seconde.
--cycles cycles
La vitesse de l'économiseur d'écran. cycles prend le nombre de cycles. La valeur par défaut est 5 cycles.
--count nombre
Spécifie combien de portes dans un tunnel peuvent être rendues. Le minimum est 4. La valeur par défaut est 24.
--size taille
Spécifie combien d'étoiles à l'extérieur du tunnel peuvent être rendues. La valeur par défaut est 100.
--ncolors couleurs
Spécifie le nombre de couleurs. Un nombre inférieur ou égal à 2 signifie monochrome. --mono permet d'obtenir le même résultat.
--pair
Démarrer l'économiseur d'écran en paires (Non recommandé)
--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.

VOIR AUSSI
