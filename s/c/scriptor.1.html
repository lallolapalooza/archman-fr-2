NOM

scriptor - Script Perl pour envoyer des commandes à une carte à puce

SYNTAXE

scriptor [-h] [-r lecteur] [-p protocole] [-u] [fichier]

DESCRIPTION

Cette page de manuel décrit brièvement la commande scriptor.

scriptor est un programme qui envoie des commandes à une carte à puce en utilisant un fichier batch ou l'entrée standard.

OPTIONS

Une description des options est incluse ci-dessous.

-h
Afficher un résumé des options.
-r lecteur
Utiliser le lecteur indiqué. Par défaut, le premier lecteur PC/SC est utilisé.
-p protocole
Utiliser le protocole indiqué. Les valeurs acceptées sont T=0 et T=1. Par défaut, T=0 est utilisé.
-u
Utiliser la sortie standard non mise en tampon.
fichier
Utiliser le fichier au lieu de l'entrée standard pour lire les commandes (APDU)

Les commandes sont de la forme :
CLA INS P1 P2 Lc [données] [le]
reset
# commentaire

Exemple :


# réinitialiser la carte
reset


# Sélectionner MF 3F00
A0 A4 00 00 02 3F 00


# Obtenir la réponse
# 17 est la valeur du second SW de la commande précédente
A0 C0 00 00 17


# Sélectionner DF Telecom (7F10)
A0 A4 00 00 02 7F 10


# Obtenir la réponse
A0 C0 00 00 17


# Sélectionner EF_ADN (6F3A) (Numéros de numérotation abrégée)
A0 A4 00 00 02 6F 3A


# Obtenir la réponse
A0 C0 00 00 0F
