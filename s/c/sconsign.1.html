NOM

sconsign - afficher les informations du fichier de signature SCons

SYNTAXE

sconsign [options...] [fichier...]

DESCRIPTION

Affiche le contenu d'un ou plusieurs fichiers sconsign, la base de données de signatures/dépendances utilisée par l'outil de construction SCons. La base de données contient tous les Nœuds connus de la construction, soit par déclaration dans la configuration de construction, soit produits comme effets secondaires, soit détectés par inspection.

Par défaut, sconsign déverse tout le contenu des fichiers sconsign. Sans options, les entrées de dépendance individuelles sont imprimées selon le format suivant :

fichierdep: signature-contenu timestamp taille
        dépendance-implicite-1: signature-contenu timestamp taille
        dépendance-implicite-2: signature-contenu timestamp taille
        ...
        signature-construction [chaîne-action]

signature-contenu est le hachage du contenu du fichier (csig) et signature-construction est le hachage de la ligne de commande ou de l'autre action de construction utilisée pour construire une cible (bactsig). Si fourni, chaîne-action est la chaîne d'action non développée ou la fonction appelée. None est imprimé à la place de toute date, csig ou bactsig manquante pour une entrée ou l'une de ses dépendances. Si l'entrée n'a pas de dépendances implicites, ou pas d'action de construction, les lignes correspondantes sont omises.

Une ligne indicatrice est imprimée pour chaque répertoire, car les répertoires n'ont pas de signatures dans la base de données et ne seraient donc pas affichés autrement.

Par défaut, sconsign suppose que tout argument fichier se terminant par le suffixe .dblite contient des entrées de signature pour plus d'un répertoire (c'est-à-dire qu'il a été spécifié par la fonction SCons SConsignFile). Tout argument fichier sans suffixe est supposé être un fichier sconsign ancien style (déprécié) contenant les entrées de signature pour un seul répertoire. Si aucune de ces conditions n'est remplie, sconsign tente de deviner le format. Si cela échoue, un format explicite peut être spécifié à l'aide des options -f ou --format=.

S'il n'y a pas d'arguments fichier, le nom .sconsign.dblite est supposé par défaut.

OPTIONS

Diverses options contrôlent les informations imprimées et le format :

-a, --act, --action

Imprime uniquement les informations d'action de construction pour toutes les entrées ou les entrées spécifiées.

-c, --csig

Imprime uniquement les informations de signature de contenu (csig) pour toutes les entrées ou les entrées spécifiées.

-d RÉPERTOIRE, --dir=RÉPERTOIRE

Lorsque les signatures sont lues à partir d'un fichier .dblite, ou que les options -f dblite ou --format=dblite sont utilisées, imprime les informations relatives uniquement aux signatures des entrées du RÉPERTOIRE spécifié.

-e ENTRÉE, --entry=ENTRÉE

Imprime les informations relatives uniquement à l'ENTRÉE spécifiée. Plusieurs options -e peuvent être utilisées, auquel cas les informations relatives à chaque ENTRÉE sont imprimées dans l'ordre où les options sont spécifiées sur la ligne de commande.

-f FORMAT, --format=FORMAT

Les fichiers à imprimer sont dans le FORMAT spécifié. Les valeurs légales sont dblite (le format SCons.dblite utilisé par défaut, ainsi que lorsque la fonction SConsignFile est appelée, sauf lorsqu'un argument de nom de fichier None est donné) et sconsign (le format utilisé pour un fichier .sconsign individuel dans chaque répertoire).

-h, --help

Imprime un message d'aide et quitte.

-i, --implicit

Imprime la liste des dépendances implicites mises en cache pour toutes les entrées ou pour les entrées spécifiées.

--raw

Imprime une représentation formatée joliment du dictionnaire Python brut qui contient les informations de construction relatives aux entrées individuelles (l'entrée elle-même et ses dépendances implicites). L'action de construction d'une entrée est toujours imprimée dans son format habituel.

-r, --readable

Imprime les horodatages sous forme de chaîne lisible par l'homme, entourée d'apostrophes simples.

-t, --timestamp

Imprime les informations d'horodatage pour toutes les entrées ou les entrées spécifiées.

-v, --verbose

Imprime des étiquettes identifiant chaque champ en cours d'impression.

ENVIRONNEMENT

SCONS_LIB_DIR

Spécifie le répertoire contenant le répertoire du module Python SCons (par exemple, /home/aroach/scons-src/SCons).
