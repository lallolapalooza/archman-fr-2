CREATEPYMB(1) Manuel des commandes générales CREATEPYMB(1)

NOM

createPYMB, readPYBase, readPYMB, mb2org, scel2org - Outils liés au Pinyin de fcitx

SYNOPIS

createPYMB <FichierPinyin> <FichierPhrase>

readPYBase [-b <FichierMB_Pinyin>] [-h]

readPYMB [-f <FichierMB_Phrase>] [-s] [-h]

mb2org [-b <FichierMB_Pinyin>] [-f <FichierMB_Phrase>] [-s] [-h]

scel2org [-o <Fichier Phrase>] [-h]

DESCRIPTION

-b <FichierMB_Pinyin>
Si non spécifié, lit le pybase.mb par défaut du système.
-f <FichierMB_Phrase>
Si non spécifié, lit le fichier PhraseMB utilisateur par défaut, qui est ~/.config/fcitx/pyusrphrase.mb.
-s
Si spécifié, lit le PhraseMBFile au format système, sinon le lit au format utilisateur.
-h
affiche l'aide et quitte
Fichier Pinyin
Le Fichier Pinyin est un fichier contenant des pinyins et un caractère par ligne, séparés par un espace. Un fichier disponible se trouve dans les sources de fcitx, nommé gbkpy.org.
Fichier Phrase
Le Fichier Phrase est un fichier avec des pinyins complets séparés par ' et la phrase correspondante. Le fichier de phrases par défaut de fcitx peut être téléchargé à l'adresse http://fcitx.googlecode.com/files/pinyin.tar.gz.
Fichier MB Pinyin
Le Fichier MB Pinyin est le format binaire du Fichier Pinyin.
Fichier MB Phrase
Le Fichier MB Phrase est le format binaire du Fichier Pinyin, le fichier de phrases utilisateur de l'historique est ~/.config/fcitx/pyuserphrase.mb. Il existe deux formats différents, l'un est le format système qui ne peut être généré que par createPYMB, et l'autre est le format utilisateur qui ne peut être généré qu'en saisissant avec le IM Pinyin de fcitx.
La sortie de createPYMB sera pybase.mb, qui est le Fichier MB Pinyin, et pyphrase.mb, qui est le Fichier MB Phrase.
La sortie de mb2org, readPYBase et readPYMB sera sur la sortie standard. readPYBase et readPYMB sont conçus pour afficher plus de messages de débogage du Fichier MB Pinyin et du Fichier MB Phrase. mb2org affichera au format du Fichier Phrase.
scel2org est utilisé pour transformer un fichier Sogou Scel en Fichier Phrase de fcitx. La sortie de scel2org sera sur la sortie standard si -o n'est pas utilisé.

VOIR AUSSI

Veuillez consulter la page d'accueil à l'adresse https://fcitx-im.org/
