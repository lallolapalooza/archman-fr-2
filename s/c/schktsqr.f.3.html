sous-programme schktsqr (real thresh, logical tsterr, integer nm, integer, dimension( * ) mval, integer nn, integer, dimension( * ) nval, integer nnb, integer, dimension( * ) nbval, integer nout)

SCHKQRT

But :

!>
!> SCHKTSQR teste SGETSQR et SORMTSQR.
!>

Paramètres

THRESH 
!>          THRESH est REAL
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          imprimer chaque rapport de test, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est LOGICAL
!>          Indicateur qui signale si les sorties d'erreur doivent être testées.
!>

NM

!>          NM est INTEGER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau INTEGER, dimension (NM)
!>          Les valeurs de la dimension de ligne de la matrice M.
!>

NN

!>          NN est INTEGER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau INTEGER, dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice N.
!>

NNB

!>          NNB est INTEGER
!>          Le nombre de valeurs de NB contenues dans le vecteur NBVAL.
!>

NBVAL

!>          NBVAL est un tableau INTEGER, dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NOUT

!>          NOUT est INTEGER
!>          Le numéro d'unité pour la sortie.
!>
