NOM

schemagen - Génère un schéma pour chaque espace de noms référencé dans vos classes Java.

SYNOPSIS

schemagen [ options ] fichiers-java
options
Les options de ligne de commande. Voir Options.
fichiers-java
Les fichiers de classe Java à traiter.

DESCRIPTION

Le générateur de schéma crée un fichier de schéma pour chaque espace de noms référencé dans vos classes Java. Actuellement, vous ne pouvez pas contrôler le nom des fichiers de schéma générés. Pour contrôler les noms des fichiers de schéma, voir Utilisation de SchemaGen avec Ant à http://jaxb.java.net/nonav/2.2.3u1/docs/schemagenTask.html

Lancez le générateur de schéma avec le script shell schemagen approprié dans le répertoire bin pour votre plateforme. Le générateur de schéma actuel peut traiter des fichiers source Java ou des fichiers de classe.

schemagen.sh Foo.java Bar.java ...
Note : Écriture de schema1.xsd

Si vos fichiers java référencent d'autres classes, ces classes doivent être accessibles dans votre variable d'environnement CLASSPATH système, ou elles doivent être spécifiées dans la ligne de commande schemagen avec les options de chemin de classe. Voir Options. Si les fichiers référencés ne sont pas accessibles ou spécifiés, vous obtiendrez des erreurs lors de la génération du schéma.

OPTIONS

-d chemin

L'emplacement où la commande schemagen place les fichiers de classe générés par le processeur et par javac.
-cp chemin

L'emplacement où la commande schemagen place les fichiers spécifiés par l'utilisateur.
-classpath chemin

L'emplacement où la commande schemagen place les fichiers spécifiés par l'utilisateur.
-encoding encodage

Spécifie l'encodage à utiliser pour les invocations de commande apt ou javac.
-episode fichier

Génère un fichier d'épisode pour la compilation séparée.
-version

Affiche les informations de version.
-help

Affiche un message d'aide.
