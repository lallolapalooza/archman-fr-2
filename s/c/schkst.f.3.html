sous-routine schkst (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( * ) ap, real, dimension( * ) sd, real, dimension( * ) se, real, dimension( * ) d1, real, dimension( * ) d2, real, dimension( * ) d3, real, dimension( * ) d4, real, dimension( * ) d5, real, dimension( * ) wa1, real, dimension( * ) wa2, real, dimension( * ) wa3, real, dimension( * ) wr, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldu, * ) v, real, dimension( * ) vp, real, dimension( * ) tau, real, dimension( ldu, * ) z, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, real, dimension( * ) result, integer info)

SCHKST

Objectif :

!>
!> SCHKST  vérifie les routines de problème de valeurs propres symétriques.
!>
!>    SSYTRD factorise A en  U S U' , où ' signifie transposée,
!>    S est une tridiagonale symétrique, et U est orthogonale.
!>    SSYTRD peut utiliser soit uniquement le triangle inférieur, soit uniquement le triangle supérieur
!>    de A ; SCHKST vérifie les deux cas.
!>    U est représentée comme un produit de transformations de Householder,
!>    dont les vecteurs sont stockés dans les n-1 premières colonnes de V, et dont les facteurs d'échelle sont dans TAU.
!>
!>    SSPTRD fait la même chose que SSYTRD, sauf que A et V sont stockés
!>    au format .
!>
!>    SORGTR construit la matrice U à partir du contenu de V et TAU.
!>
!>    SOPGTR construit la matrice U à partir du contenu de VP et TAU.
!>
!>    SSTEQR factorise S en  Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale.  D2 est la matrice des
!>    valeurs propres calculées lorsque Z n'est pas calculée.
!>
!>    SSTERF calcule D3, la matrice des valeurs propres, par la
!>    méthode PWK, qui ne produit pas de vecteurs propres.
!>
!>    SPTEQR factorise S en  Z4 D4 Z4' , pour une
!>    matrice tridiagonale symétrique définie positive.
!>    D5 est la matrice des valeurs propres calculées lorsque Z n'est pas
!>    calculée.
!>
!>    SSTEBZ calcule des valeurs propres sélectionnées.  WA1, WA2 et
!>    WA3 désigneront les valeurs propres calculées avec une grande
!>    précision absolue, avec différentes options de plage.
!>    WR désignera les valeurs propres calculées avec une grande
!>    précision relative.
!>
!>    SSTEIN calcule Y, les vecteurs propres de S, étant donné les
!>    valeurs propres.
!>
!>    SSTEDC factorise S en Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale (option 'I'). Elle peut aussi
!>    mettre à jour une matrice orthogonale d'entrée, généralement la sortie
!>    de SSYTRD/SORGTR ou SSPTRD/SOPGTR (option 'V'). Elle peut aussi
!>    simplement calculer les valeurs propres (option 'N').
!>
!>    SSTEMR factorise S en Z D1 Z' , où Z est la matrice orthogonale
!>    des vecteurs propres et D1 est une matrice diagonale avec
!>    les valeurs propres sur la diagonale (option 'I').  SSTEMR
!>    utilise la Représentation Relativement Robuste lorsque cela est possible.
!>
!> Lorsque SCHKST est appelée, un nombre de matrices  () et un
!> nombre de matrices  sont spécifiés.  Pour chaque taille ()
!> et chaque type de matrice, une matrice sera générée et utilisée
!> pour tester les routines propres symétriques.  Pour chaque matrice, un nombre
!> de tests seront effectués :
!>
!> (1)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='U', ... )
!>
!> (2)     | I - UV' | / ( n ulp )        SORGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='L', ... )
!>
!> (4)     | I - UV' | / ( n ulp )        SORGTR( UPLO='L', ... )
!>
!> (5-8)   Identique à 1-4, mais pour SSPTRD et SOPGTR.
!>
!> (9)     | S - Z D Z' | / ( |S| n ulp ) SSTEQR('V',...)
!>
!> (10)    | I - ZZ' | / ( n ulp )        SSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        SSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si les vraies valeurs propres (calculées par comptage de Sturm)
!>         de S sont dans THRESH de
!>         celles de D1.  2*THRESH si ce n'est pas le cas.  (Testé en utilisant
!>         SSTECH)
!>
!> Pour S définie positive,
!>
!> (14)    | S - Z4 D4 Z4' | / ( |S| n ulp ) SPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4' | / ( n ulp )        SPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       SPTEQR('N',...)
!>
!> Lorsque S est également à dominante diagonale par le facteur gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          SSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              SSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y' | / ( |S| n ulp )  SSTEBZ, SSTEIN
!>
!> (21)    | I - Y Y' | / ( n ulp )          SSTEBZ, SSTEIN
!>
!> (22)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('I')
!>
!> (23)    | I - ZZ' | / ( n ulp )           SSTEDC('I')
!>
!> (24)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('V')
!>
!> (25)    | I - ZZ' | / ( n ulp )           SSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           SSTEDC('V') et
!>                                              SSTEDC('N')
!>
!> Le test 27 est désactivé pour le moment car SSTEMR ne garantit pas une haute précision relative.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEMR('V', 'I')
!>
!> Les tests 29 à 34 sont désactivés pour le moment car SSTEMR
!> ne gère pas les requêtes de spectre partiel.
!>
!> (29)    | S - Z D Z' | / ( |S| n ulp )    SSTEMR('V', 'I')
!>
!> (30)    | I - ZZ' | / ( n ulp )           SSTEMR('V', 'I')
!>
!> (31)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         SSTEMR('N', 'I') vs. SSTEMR('V', 'I')
!>
!> (32)    | S - Z D Z' | / ( |S| n ulp )    SSTEMR('V', 'V')
!>
!> (33)    | I - ZZ' | / ( n ulp )           SSTEMR('V', 'V')
!>
!> (34)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         SSTEMR('N', 'V') vs. SSTEMR('V', 'V')
!>
!> (35)    | S - Z D Z' | / ( |S| n ulp )    SSTEMR('V', 'A')
!>
!> (36)    | I - ZZ' | / ( n ulp )           SSTEMR('V', 'A')
!>
!> (

!>          NSIZES est un entier (INTEGER)
!>          Le nombre de tailles de matrices à utiliser. Si il est zéro,
!>          SCHKST ne fait rien. Il doit être au moins zéro.

NN

!>          NN est un tableau d'entiers (INTEGER), de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs zéro seront ignorées. Les valeurs doivent être au moins

!>          NTYPES est un entier (INTEGER)
!>          Le nombre d'éléments dans DOTYPE. Si il est zéro, SCHKST
!>          ne fait rien. Il doit être au moins zéro. Si il est MAXTYP+1
!>          et NSIZES est 1, alors un type additionnel, MAXTYP+1 est

!>          n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .

!>          DOTYPE est un tableau logique (LOGICAL), de dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.

!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095;

!>      $                   LDA, LDU, IWORK, WORK, RESULT, INFO )

!>  *==*==================================================================*
!>  *==*                                                                  *
!>  *==*           THE LAPACK DRIVER ROUTINE FOR TESTING ALL              *

!>  *==*                                                                  *
!>  *==*==================================================================*
!>
!>  *Purpose*
!>  ========
!>  SCHKST is a driver routine for testing all the routines for
!>  SYMMETRIC eigenvalue computations in the LAPACK library.
!>
!>  Arguments
!>  =========
!>
!>  NN     (input) INTEGER array, dimension (NSIZES)
!>         Defines the sizes of the matrices to be generated. NN(j)
!>         is the dimension of the matrix of type j.
!>
!>  NSIZES (input) INTEGER
!>         The number of values in NN. This must be at least 1.
!>
!>  NMAX   (input) INTEGER
!>         The maximum dimension of the matrices to be generated.
!>         NMAX must be at least max( NN(j) ).
!>
!>  NTYPES (input) INTEGER
!>         The number of matrix types to be tested. This must be at
!>         least 1.
!>

!>         Result .GE. THRESH and if the result is not consistent
!>         with the error bounds.
!>
!>  LDA    (input) INTEGER
!>         The leading dimension of the arrays A and S. LDA must be
!>         at least max(1, NMAX).
!>
!>  LDU    (input) INTEGER
!>         The leading dimension of the array U. LDU must be at least
!>         max(1, NMAX).
!>
!>  IWORK  (workspace) INTEGER array, dimension (LIWORK)

!>  WORK   (workspace) REAL array, dimension (LWORK)
!>
