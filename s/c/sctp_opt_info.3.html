NOM

sctp_optinfo - Obtenir des options sur une socket SCTP.

SYNOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_opt_info(int sd, sctp_assoc_t id, int opt,
                  void * arg, socklen_t * size);

DESCRIPTION

sctp_opt_info est une fonction de bibliothèque enveloppante qui peut être utilisée pour obtenir des options au niveau SCTP sur une socket. sd est le descripteur de socket pour lequel l'option est demandée. Pour les sockets de style un-à-plusieurs, id spécifie l'association à interroger. Pour les sockets de style un-à-un, id est ignoré. opt spécifie l'option de socket SCTP à obtenir. arg est un tampon de structure spécifique à l'option fourni par l'appelant. size est un paramètre de valeur-résultat, contenant initialement la taille du tampon pointé par arg et modifié au retour pour indiquer la taille réelle de la valeur retournée.

VALEUR DE RETOUR

En cas de succès, sctp_opt_info retourne 0 et en cas d'échec, -1 est retourné avec errno défini au code d'erreur approprié.
