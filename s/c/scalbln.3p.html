SCALBLN(3P) Manuel du programmeur POSIX SCALBLN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

scalbln, scalblnf, scalblnl, scalbn, scalbnf, scalbnl — calculer l'exposant en utilisant FLT_RADIX

SYNOPSIS

#include <math.h>
double scalbln(double x, long n);
float scalblnf(float x, long n);
long double scalblnl(long double x, long n);
double scalbn(double x, int n);
float scalbnf(float x, int n);
long double scalbnl(long double x, int n);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions doivent calculer x * FLT_RADIXn efficacement, normalement sans calculer explicitement FLT_RADIXn.

Une application souhaitant vérifier les situations d'erreur doit définir errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno n'est pas nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) n'est pas nul, une erreur s'est produite.

VALEUR RENVOYÉE

En cas de succès, ces fonctions doivent renvoyer x * FLT_RADIXn.

Si le résultat entraînait un dépassement de capacité (overflow), une erreur de plage doit se produire et ces fonctions doivent renvoyer ±HUGE_VAL, ±HUGE_VALF, et ±HUGE_VALL (selon le signe de x) de manière appropriée pour le type de retour de la fonction.

Si la valeur correcte entraînait un sous-dépassement de capacité (underflow) et n'est pas représentable, une erreur de plage peut se produire et scalbln(), scalblnf(), scalblnl(), scalbn(), scalbnf(), et scalbnl() doivent renvoyer 0.0, ou (si le calcul en virgule flottante IEC 60559 n'est pas pris en charge) une valeur définie par l'implémentation n'excédant pas en magnitude DBL_MIN, FLT_MIN, LDBL_MIN, DBL_MIN, FLT_MIN, et LDBL_MIN, respectivement.

Si x est NaN, un NaN doit être renvoyé.

Si x est ±0 ou ±Inf, x doit être renvoyé.

Si n est 0, x doit être renvoyé.

Si la valeur correcte entraînait un sous-dépassement de capacité et est représentable, une erreur de plage peut se produire et la valeur correcte doit être renvoyée.

ERREURS

Ces fonctions doivent échouer si :

Erreur de plage
Le résultat dépasse la capacité de représentation (overflow).

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno doit être défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante de dépassement de capacité doit être levée.

Ces fonctions peuvent échouer si :

Erreur de plage
Le résultat est inférieur au plus petit nombre représentable (underflow).

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno doit être défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante de sous-dépassement de capacité doit être levée.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'entre elles doit être non nulle.

RATIONALE

Ces fonctions sont nommées de manière à éviter les conflits avec la définition historique de la fonction scalb() de la Single UNIX Specification. La différence est que la fonction scalb() a un second argument de type double au lieu de int. La fonction scalb() ne fait pas partie de la norme ISO C. Les trois fonctions dont le deuxième type est long sont fournies car le facteur nécessaire pour passer de la plus petite valeur flottante positive à la plus grande valeur finie, dans de nombreuses implémentations, est trop grand pour être représenté dans le format int de largeur minimale.
