sched_rr_get_interval(2) Manuel des appels système sched_rr_get_interval(2)

NOM

sched_rr_get_interval - obtenir l'intervalle SCHED_RR pour le processus nommé

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sched.h>
int sched_rr_get_interval(pid_t pid, struct timespec *tp);

DESCRIPTION

sched_rr_get_interval() écrit dans la structure timespec(3) pointée par tp la tranche de temps round-robin pour le processus identifié par pid. Le processus spécifié doit être exécuté sous la politique d'ordonnancement SCHED_RR.

Si pid est zéro, la tranche de temps du processus appelant est écrite dans *tp.

VALEUR DE RETOUR

En cas de succès, sched_rr_get_interval() retourne 0. En cas d'erreur, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

EFAULT
Problème lors de la copie d'informations vers l'espace utilisateur.
EINVAL
pid invalide.
ENOSYS
L'appel système n'est pas encore implémenté (uniquement sur des noyaux plutôt anciens).
ESRCH
Impossible de trouver un processus avec l'ID pid.

VERSIONS

Linux

Linux 3.9 a ajouté un nouveau mécanisme pour ajuster (et visualiser) l'intervalle SCHED_RR : le fichier /proc/sys/kernel/sched_rr_timeslice_ms expose l'intervalle en millisecondes, dont la valeur par défaut est 100. Écrire 0 dans ce fichier réinitialise l'intervalle à la valeur par défaut.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

Linux

POSIX ne spécifie aucun mécanisme pour contrôler la taille de l'intervalle de temps round-robin. Les anciens noyaux Linux fournissent une méthode (non portable) pour le faire. L'intervalle peut être contrôlé en ajustant la valeur de "nice" du processus (voir setpriority(2)). Attribuer une valeur de "nice" négative (c'est-à-dire élevée) entraîne un intervalle plus long ; attribuer une valeur de "nice" positive (c'est-à-dire faible) entraîne un intervalle plus court. L'intervalle par défaut est de 0.1 seconde ; la mesure dans laquelle le changement de la valeur de "nice" affecte l'intervalle a varié quelque peu selon les versions du noyau. Cette méthode d'ajustement de l'intervalle a été supprimée à partir de Linux 2.6.24.

NOTES

Les systèmes POSIX sur lesquels sched_rr_get_interval() est disponible définissent _POSIX_PRIORITY_SCHEDULING dans <unistd.h>.

VOIR AUSSI

timespec(3), sched(7)
