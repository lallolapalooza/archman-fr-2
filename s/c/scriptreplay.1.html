SCRIPTREPLAY(1) Commandes utilisateur SCRIPTREPLAY(1)

NOM

scriptreplay - rejoue des saisies de terminal, en utilisant les informations de chronométrage

SYNOPHIS

scriptreplay [options] fichierdetiming [fichièredesaisie [diviseur]]

DESCRIPTION

Ce programme rejoue une saisie de terminal, en utilisant les informations de chronométrage pour s'assurer que la sortie se produit au même rythme qu'elle est apparue à l'origine lors de l'enregistrement du script.

La relecture affiche simplement à nouveau les informations ; les programmes qui ont été exécutés lors de l'enregistrement de la saisie de terminal ne sont pas réexécutés. Étant donné que les mêmes informations sont simplement affichées, scriptreplay n'est garanti de fonctionner correctement que s'il est exécuté sur le même type de terminal que celui sur lequel la saisie de terminal a été enregistrée. Sinon, les caractères d'échappement présents dans la saisie de terminal peuvent être interprétés différemment par le terminal sur lequel scriptreplay envoie sa sortie.

Les informations de chronométrage sont ce que script(1) génère dans le fichier spécifié par l'option --log-timing.

Par défaut, le fichier de saisie à afficher est supposé être nommé typescript, mais d'autres noms de fichiers peuvent être spécifiés, comme deuxième paramètre ou avec l'option --log-out.

Si le troisième paramètre ou l'option --divisor est spécifié, il est utilisé comme multiplicateur d'accélération. Par exemple, une accélération de 2 fait que scriptreplay va deux fois plus vite, et un ralentissement de 0.1 le fait aller dix fois plus lentement que la session d'origine.

Pendant la relecture, vous pouvez accélérer, ralentir ou mettre en pause la lecture de manière interactive en utilisant les touches Haut, Bas et Espace.

OPTIONS

-I, --log-in fichier

Fichier contenant l'entrée du terminal de script.

-O, --log-out fichier

Fichier contenant la sortie du terminal de script.

-B, --log-io fichier

Fichier contenant la sortie et l'entrée du terminal de script.

-t, --timing fichier

Fichier contenant la sortie de chronométrage de script. Cette option remplace l'argument positionnel fichierdetiming.

-T, --log-timing fichier

C'est un alias pour -t, maintenu pour la compatibilité avec les options de ligne de commande de script(1).

-s, --typescript fichier

Alias obsolète de --log-out.

-c, --cr-mode mode

Spécifie comment gérer le caractère CR (retour chariot, 0x0D) des fichiers journaux. Le mode par défaut est auto, auquel cas CR est remplacé par un saut de ligne pour le journal stdin, car sinon scriptreplay écraserait la même ligne. Les autres modes sont never et always.

-d, --divisor nombre

Accélère la relecture en l'affichant nombre de fois. L'argument est un nombre à virgule flottante. Il est appelé diviseur car il divise les chronométrages par ce facteur. Cette option remplace les arguments de style ancien.

-m, --maxdelay nombre

Définit le délai maximum entre les mises à jour à nombre secondes. L'argument est un nombre à virgule flottante. Ceci peut être utilisé pour éviter de longues pauses dans la relecture du script.

--summary

Affiche les détails sur la session enregistrée dans le fichier de chronométrage spécifié et quitte. La session doit avoir été enregistrée en utilisant le format advanced (voir l'option --logging-format de script(1) pour plus de détails).

-x, --stream type

Force scriptreplay à n'imprimer que le flux spécifié. Les types de flux pris en charge sont in, out, signal et info. Cette option est recommandée pour les journaux multi-flux (créés avec --log-io) afin de n'imprimer que les données souhaitées.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

EXEMPLES

% script --log-timing file.tm --log-out script.out
Script started, file is script.out
% ls
<etc, etc>
% exit
Script done, file is script.out
% scriptreplay --log-timing file.tm --log-out script.out

RACCORCIS CLAVIER

Les touches suivantes contrôlent la lecture du script :

•Espace : Bascule entre la pause et la reprise. Appuyez sur cette touche pour mettre la lecture en pause, puis appuyez à nouveau pour reprendre.
•Flèche Haut : Augmente la vitesse de lecture. Chaque pression sur cette touche rendra la relecture du script 0.1 fois plus rapide.
•Flèche Bas : Diminue la vitesse de lecture. Chaque pression sur cette touche ralentira la relecture du script de 0.1 fois.

scriptreplay - Rejouer une session enregistrée avec script

SYNOPSIS

scriptreplay [OPTION]... TIMING_FILE SCRIPT_FILE

DESCRIPTION

scriptreplay est un utilitaire permettant de rejouer une session shell enregistrée précédemment avec l'utilitaire script. Il utilise un fichier de timing (TIMING_FILE) pour reproduire les délais exacts entre les frappes et les sorties, et un fichier script (SCRIPT_FILE) qui contient le contenu de la session.

Ceci est particulièrement utile pour créer des démonstrations, des tutoriels ou pour analyser le comportement d'une session enregistrée.

OPTIONS

Il existe plusieurs options pour contrôler le comportement de scriptreplay :

  • -p, --playback-time : Définit le temps de lecture global. Par défaut, le temps de lecture est déduit du fichier de timing.
  • -t, --timing-file : Spécifie le fichier de timing. Si ce n'est pas fourni, scriptreplay essaiera de le trouver en changeant l'extension de SCRIPT_FILE en.timing.
  • -s, --script-file : Spécifie le fichier script. Si ce n'est pas fourni, scriptreplay essaiera de le trouver en changeant l'extension de TIMING_FILE en.script.
  • -d, --delay : Ajoute un délai fixe (en secondes) avant de commencer la lecture.
  • -D, --delay-exact : Utilise le délai exact du fichier de timing sans le multiplier par le facteur de lecture global.
  • -M, --max-delay : Définit un délai maximum entre les frappes/sorties pour éviter des pauses trop longues.
  • -m, --min-delay : Définit un délai minimum entre les frappes/sorties.
  • -h, --help : Affiche un message d'aide et quitte.
  • -V, --version : Affiche les informations de version et quitte.

EXEMPLES

Pour rejouer une session enregistrée avec script :

scriptreplay timing.log script.log

Pour rejouer une session avec un temps de lecture global de 50% :

scriptreplay -p 0.5 timing.log script.log
