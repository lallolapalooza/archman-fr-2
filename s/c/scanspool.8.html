NOM

scanspool - Effectue une vérification de cohérence sur tous les articles du spool d'actualités

SYNTAXE

scanspool [-cnrv] [-a fichier-active] [-s répertoire-spool]

DESCRIPTION

scanspool est un script Perl utilisable avec un spool d'articles de type tradspool. Il parcourt le fichier active ainsi que tous les articles du spool et signale les erreurs rencontrées. Comme cela peut prendre du temps, il est recommandé d'utiliser l'option -v pour voir la progression du programme.

scanspool ignorera tout fichier dont le nom n'est pas uniquement composé de chiffres lors du traitement du contenu du spool d'actualités.

En premier lieu, scanspool analyse le fichier active, notant les problèmes tels que :

  • lignes malformées ;
  • entrées en double ;
  • groupes de news aliasés vers un groupe de news inexistant ;
  • groupes de news aliasés vers un groupe qui est lui-même aliasé.

Ensuite, il examine tous les articles sous le répertoire de votre spool d'actualités, signalant les articles qui :

  • ont un nom de base commençant par un 0 ;
  • ont un nom de base hors de la plage définie par les marques basses et hautes du fichier active ;
  • ne contiennent pas de champ d'en-tête Newsgroups ;
  • sont dans un répertoire pour lequel il n'existe aucun groupe de news dans le fichier active ;
  • sont dans un groupe de news auquel ils n'appartiennent pas.

scanspool signalera également les répertoires dont le composant est entièrement numérique, au cas où le répertoire parent serait un groupe de news avec une marque haute inférieure à ce composant numérique, car le nom de tels répertoires entrerait en conflit avec un futur fichier d'article portant le même nom.

scanspool prend en compte les groupes de news aliasés. Ainsi, si un article est posté dans foo.old.name qui est aliasé vers foo.bar, il sera attendu de le trouver sous foo.bar et non foo.old.name.

scanspool suppose que le chemin d'un répertoire de groupe de news valide, à partir de la racine de l'arborescence du spool, ne contiendra aucun caractère ".". Ainsi, les répertoires tels que out.going, tmp.dir, in.coming et news.archive ne seront pas recherchés. Ce programme suppose également que les noms de base des articles ne contiennent que des chiffres décimaux. Enfin, les fichiers sous le répertoire de niveau supérieur lost+found ne sont pas analysés.

OPTIONS

-a fichier-active
Le fichier active à utiliser ; pathdb/active est la valeur par défaut.
-c
Vérifier uniquement les noms de fichiers des articles. scanspool n'analysera donc pas le champ d'en-tête Newsgroups des articles.
-n
Ne pas limiter innd pendant l'analyse.
-r
Supprimer les articles signalés comme ayant un problème. Pour voir la liste des articles concernés, exécutez d'abord scanspool sans cette option.

Attention : l'utilisation de cette option peut entraîner la suppression d'articles accessibles alors qu'ils sont parfaitement valides. Examinez-les pour vous assurer qu'ils peuvent être supprimés en toute sécurité, puis utilisez cette option.

-s répertoire-spool
La racine de l'arborescence du spool ; patharticles est la valeur par défaut.
-v
Activer le mode verbeux. scanspool affichera alors quel groupe de news est actuellement traité. Il listera tous les articles trouvés dans des répertoires non active (c'est-à-dire des articles triés dans des groupes qui n'existent plus dans le fichier active), plutôt que de n'afficher le groupe qu'une seule fois.

DIAGNOSTICS

La sortie de scanspool commencera par l'une des formes suivantes :

"FATAL:" (vers stderr)
Erreur fatale ou interne.
"WARNING:" (vers stderr)
Problème de format active ou d'article, problème d'alias de groupe de news, erreur find(1), erreur d'ouverture d'article.
"chemin/123:" (vers stdout)
Problèmes tels que :
  • le nom de base commence par 0 ;
  • le numéro d'article est hors plage ;
  • l'article est dans le mauvais répertoire ;
  • l'article est dans un répertoire non lié à un groupe de news non aliasé dans le fichier active.
"\t ..." (vers stdout)
Les messages verbeux commencent par une tabulation.
