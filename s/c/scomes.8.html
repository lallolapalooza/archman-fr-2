scomes(8) Outil de surveillance des ressources système scomes(8)

NOM

scomes - outil de surveillance des ressources système

SYNTAXE

scomes -c "binaire [arguments du binaire ...]" [minuteur]

DESCRIPTION

scomes est un script systemtap simple pour surveiller l'activité d'un processus. Les appels système, les ticks en espace utilisateur et noyau, les octets lus et écrits, les octets transmis et reçus, ainsi que les appels système de polling sont mesurés.

binaire
Fichier binaire à exécuter. Ce processus sera surveillé.
minuteur
Le réglage de cette option entraîne l'impression de statistiques toutes les N secondes. Si elle n'est pas fournie, les statistiques sont imprimées uniquement lorsque le processus surveillé se termine.

VOIR AUSSI
