SCASUM

Objectif :

!>
!>    SCASUM prend la somme des (|Re(.)| + |Im(.)|) d'un vecteur complexe et
!>    renvoie un résultat en précision simple.
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

CX

!>          CX est un tableau COMPLEXE, de dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un ENTIER
!>         espacement de stockage entre les éléments de SX
!>
