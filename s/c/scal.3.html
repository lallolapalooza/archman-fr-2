NAME

scal - scale a vector by a complex number

SYNOPSIS

   SUBROUTINE SCAL( N, ZA, ZX, INCX )

C interface:

   void scals_( integer* n, complex*16* za, complex*16* zx, integer* incx );

Description

SCAL scales a vector,z, by the complex number alpha. The complex version of the operation is applied:

    z(i) = alpha * z(i),    for i = 1, 2, ..., n

Parameters

N
 N is INTEGER
         number of elements in input vector(s)
ZA
 ZA is COMPLEX*16
          On entry, ZA specifies the scalar alpha.
ZX
 ZX is COMPLEX*16 array, dimension ( 1 + ( N - 1 )*abs( INCX ) )
INCX
 INCX is INTEGER
         storage spacing between elements of ZX

Author

Univ. of Tennessee

Univ. of California Berkeley

NAG Ltd.
