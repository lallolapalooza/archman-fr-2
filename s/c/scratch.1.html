NOM

Scratch - Un environnement de programmation interactif facile à utiliser pour les 8 ans et plus.

DESCRIPTION

Scratch est un environnement de programmation facile, interactif et collaboratif conçu pour la création d'histoires interactives, d'animations, de jeux, de musique et d'art -- et leur partage sur le web. Scratch est conçu pour aider les jeunes (8 ans et plus) à développer des compétences d'apprentissage du 21e siècle. En créant des projets Scratch, les jeunes acquièrent des idées mathématiques et informatiques importantes, tout en développant une compréhension plus approfondie du processus de conception. Cette page de manuel contient des informations de base sur Scratch. Pour plus d'informations, consultez le site web de Scratch à l'adresse http://scratch.mit.edu.

OPTIONS

Les options sont définies via le fichier .scratch.ini dans le répertoire personnel de l'utilisateur. Pour savoir comment modifier ce fichier, consultez http://info.scratch.mit.edu/Network_Installation.

BOGUES

Veuillez signaler les bogues au responsable du paquet. Pour la version la plus récente de ce paquet, consultez http://info.scratch.mit.edu/Linux_installer

FICHIERS

/usr/bin/scratch - script de démarrage de scratch
/usr/lib/scratch/ - Contient Scratch.image (image Squeak contenant le code Scratch), et le fichier scratch.ini
/usr/share/scratch/- Contient des sous-répertoires avec la bibliothèque multimédia de Scratch, des projets d'exemple et des fichiers de langue.
