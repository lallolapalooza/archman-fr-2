NOM

sctp_send - Envoie un message depuis un socket SCTP.

SYNTAXE

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_send(int sd, const void * msg, size_t len,
                 const struct sctp_sndrcvinfo *sinfo,
                 uint32_t flags);

DESCRIPTION

sctp_send est une fonction de la bibliothèque wrapper qui peut être utilisée pour envoyer un message depuis un socket sans utiliser les structures d'en-tête CMSG. sd est le descripteur de socket depuis lequel le message pointé par msg de longueur len est envoyé. sinfo est un pointeur vers une structure sctp_sndrcvinfo. Le paramètre flags est composé d'un OU logique des indicateurs qui peuvent être passés comme 3ème argument d'un appel standard sendmsg().

VALEUR DE RETOUR

En cas de succès, sctp_sendmsg renvoie le nombre d'octets envoyés ou -1 si une erreur s'est produite.
