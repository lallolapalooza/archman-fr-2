SCTP_GETLADDRS(3) Manuel du programmeur Linux SCTP_GETLADDRS(3)

NOM

sctp_getladdrs - Renvoie toutes les adresses localement liées à un socket.

SYNTAXE

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_getladdrs(int sd, sctp_assoc_t assoc_id,
                   struct sockaddr **addrs);

void sctp_freeladdrs(struct sockaddr *addrs);

DESCRIPTION

sctp_getladdrs renvoie toutes les adresses localement liées à un socket. Au retour, addrs pointera vers un tableau dynamique alloué de structures sockaddr du type approprié pour chaque adresse locale. L'appelant doit utiliser sctp_freeladdrs pour libérer la mémoire. Notez que le paramètre in/out addrs ne doit pas être NULL.

Si sd est un socket IPv4, les adresses renvoyées seront toutes les adresses IPv4. Si sd est un socket IPv6, les adresses renvoyées peuvent être un mélange d'adresses IPv4 ou IPv6.

Pour les sockets de style un-à-plusieurs, id spécifie l'association à interroger. Pour les sockets de style un-à-un, id est ignoré.

Si le champ id est défini à 0, alors les adresses localement liées sont renvoyées sans tenir compte d'une association particulière.

sctp_freeladdrs libère toutes les ressources allouées par sctp_getladdrs.

VALEUR DE RETOUR

En cas de succès, sctp_getladdrs renvoie le nombre d'adresses locales liées au socket. Si le socket n'est pas lié, 0 est renvoyé et la valeur de *addrs est indéfinie. En cas d'erreur, sctp_getladdrs renvoie -1 et la valeur de *addrs est indéfinie.
