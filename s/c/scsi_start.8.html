NOM

scsi_start - démarrer un ou plusieurs disques SCSI

SYNTAXE

scsi_start [--help] [--verbose] [--wait] PÉRIPHÉRIQUE [PÉRIPHÉRIQUE]*

DESCRIPTION

Ce script shell bash appelle l'utilitaire sg_start sur chaque PÉRIPHÉRIQUE donné. Le but est de faire tourner (démarrer) chaque PÉRIPHÉRIQUE donné.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-h, --help
affiche le message d'utilisation puis quitte.
-v, --verbose
augmente le niveau de verbosité.
-w, --wait
attend que le démarrage (spin up) de chaque PÉRIPHÉRIQUE donné soit terminé. L'action par défaut est d'effectuer chaque démarrage en mode immédiat.

NOTES

Si un grand nombre de disques sont démarrés en même temps (c'est-à-dire sans l'option --wait) alors l'alimentation électrique pourrait être surchargée.

STATUT DE SORTIE

Le statut de sortie de ce script est 0 lorsqu'il réussit. Sinon, le statut de sortie est celui du dernier utilitaire sg_start appelé. Voir la page man sg3_utils(8).
