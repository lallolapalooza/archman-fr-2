scandir(3) Manuel des fonctions de bibliothèque scandir(3)

NOM

scandir, scandirat, alphasort, versionsort - scanner un répertoire pour les entrées correspondantes

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <dirent.h>
int scandir(const char *restrict dirp,
            struct dirent ***restrict namelist,
            typeof(int (const struct dirent *)) *filter,
            typeof(int (const struct dirent **, const struct dirent **))
                *compar);
int alphasort(const struct dirent **a, const struct dirent **b);
int versionsort(const struct dirent **a, const struct dirent **b);
#include <fcntl.h>          /* Définition des constantes AT_* */
#include <dirent.h>
int scandirat(int dirfd, const char *restrict dirp,
            struct dirent ***restrict namelist,
            typeof(int (const struct dirent *)) *filter,
            typeof(int (const struct dirent **, const struct dirent **))
                *compar);

DESCRIPTION

La fonction scandir() scanne le répertoire dirp, appelant filter() sur chaque entrée de répertoire. Les entrées pour lesquelles filter() retourne une valeur non nulle sont stockées dans des chaînes allouées via malloc(3), triées en utilisant qsort(3) avec la fonction de comparaison compar(), et collectées dans le tableau namelist qui est alloué via malloc(3). Si filter est NULL, toutes les entrées sont sélectionnées.

Les fonctions alphasort() et versionsort() peuvent être utilisées comme fonction de comparaison compar(). La première trie les entrées de répertoire en utilisant strcoll(3), la seconde en utilisant strverscmp(3) sur les chaînes (*a)->d_name et (*b)->d_name.

scandirat()

La fonction scandirat() fonctionne exactement de la même manière que scandir(), à l'exception des différences décrites ici.

Si dirp est relatif, alors il est interprété par rapport au répertoire référencé par le descripteur de fichier dirfd (plutôt que par rapport au répertoire de travail actuel du processus appelant, comme le fait scandir() pour un chemin relatif).

Si dirp est relatif et dirfd est la valeur spéciale AT_FDCWD, alors dirp est interprété par rapport au répertoire de travail actuel du processus appelant (comme scandir()).

Si dirp est absolu, alors dirfd est ignoré.

Voir openat(2) pour une explication du besoin de scandirat().

VALEUR DE RETOUR

La fonction scandir() retourne le nombre d'entrées de répertoire sélectionnées. En cas d'erreur, -1 est retourné, avec errno défini pour indiquer l'erreur.

Les fonctions alphasort() et versionsort() retournent un entier inférieur, égal ou supérieur à zéro si le premier argument est considéré respectivement comme inférieur, égal ou supérieur au second.

ERREURS

EBADF
(scandirat()) dirp est relatif mais dirfd n'est ni AT_FDCWD ni un descripteur de fichier valide.
ENOENT
Le chemin dans dirp n'existe pas.
ENOMEM
Mémoire insuffisante pour terminer l'opération.
ENOTDIR
Le chemin dans dirp n'est pas un répertoire.
ENOTDIR
(scandirat()) dirp est relatif et dirfd est un descripteur de fichier faisant référence à un fichier autre qu'un répertoire.

NOTES

Depuis glibc 2.1, alphasort() appelle strcoll(3) ; auparavant, il utilisait strcmp(3).

Avant glibc 2.10, les deux arguments de alphasort() et versionsort() étaient typés comme const void *. Lorsque alphasort() a été standardisé dans POSIX.1-2008, le type d'argument a été spécifié comme const struct dirent **, et glibc 2.10 a modifié la définition de alphasort() (et le non-standard versionsort()) pour correspondre à la norme.

EXEMPLES

Le programme ci-dessous affiche la liste des fichiers dans le répertoire actuel dans l'ordre inverse.

Source du programme

#define _DEFAULT_SOURCE
#include <dirent.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    struct dirent **namelist;
    int n;
    n = scandir(".", &namelist, NULL, alphasort);
    if (n == -1) {
        perror("scandir");
        exit(EXIT_FAILURE);
    }
    while (n--) {
        printf("%s\n", namelist[n]->d_name);
        free(namelist[n]);
    }
    free(namelist);
    exit(EXIT_SUCCESS);
}
