Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI.; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NM

!>          NM est un ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau d'ENTIERS de dimension (NM)
!>          Les valeurs de la dimension de ligne de la matrice M.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS de dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice N.
!>

NNB

!>          NNB est un ENTIER
!>          Le nombre de valeurs de NB et NX contenues dans les
!>          vecteurs NBVAL et NXVAL. Les paramètres de bloc sont utilisés
!>          par paires (NB,NX).
!>

NBVAL

!>          NBVAL est un tableau d'ENTIERS de dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NXVAL

!>          NXVAL est un tableau d'ENTIERS de dimension (NNB)
!>          Les valeurs du point de croisement NX.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de membre droit à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un RELATIF
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= SEUIL. Pour avoir
!>          chaque ratio de test imprimé, utilisez SEUIL = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui signale si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale permise pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau RELATIF de dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau RELATIF de dimension (NMAX*NMAX)
!>

AQ

!>          AQ est un tableau RELATIF de dimension (NMAX*NMAX)
!>

AL

!>          AL est un tableau RELATIF de dimension (NMAX*NMAX)
!>

AC

!>          AC est un tableau RELATIF de dimension (NMAX*NMAX)
!>

B

!>          B est un tableau RELATIF de dimension (NMAX*NRHS)
!>

X

!>          X est un tableau RELATIF de dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau RELATIF de dimension (NMAX*NRHS)
!>

TAU

!>          TAU est un tableau RELATIF de dimension (NMAX)
!>

WORK

!>          WORK est un tableau RELATIF de dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK est un tableau RELATIF de dimension (NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>
