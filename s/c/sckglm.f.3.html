sous-routine sckglm (integer nn, integer, dimension( * ) mval, integer, dimension( * ) pval, integer, dimension( * ) nval, integer nmats, integer, dimension( 4 ) iseed, real thresh, integer nmax, real, dimension( * ) a, real, dimension( * ) af, real, dimension( * ) b, real, dimension( * ) bf, real, dimension( * ) x, real, dimension( * ) work, real, dimension( * ) rwork, integer nin, integer nout, integer info)

SCKGLM

But :

!>
!> SCKGLM teste SGGGLM - sous-routine pour la résolution du problème du modèle linéaire généralisé.
!>

Paramètres

NN 
!>          NN est un entier (INTEGER)
!>          Le nombre de valeurs de N, M et P contenus dans les vecteurs
!>          NVAL, MVAL et PVAL.
!>

MVAL

!>          MVAL est un tableau d'entiers (INTEGER array), dimension (NN)
!>          Les valeurs de la dimension M des colonnes de la matrice.
!>

PVAL

!>          PVAL est un tableau d'entiers (INTEGER array), dimension (NN)
!>          Les valeurs de la dimension P des colonnes de la matrice.
!>

NVAL

!>          NVAL est un tableau d'entiers (INTEGER array), dimension (NN)
!>          Les valeurs de la dimension N des lignes de la matrice.
!>

NMATS

!>          NMATS est un entier (INTEGER)
!>          Le nombre de types de matrices à tester pour chaque combinaison
!>          de dimensions matricielles. Si NMATS >= NTYPES (le nombre maximum
!>          de types de matrices), alors tous les différents types sont
!>          générés pour le test. Si NMATS < NTYPES, une autre ligne d'entrée
!>          est lue pour obtenir les numéros des types de matrices à utiliser.
!>

ISEED

!>          ISEED est un tableau d'entiers (INTEGER array), dimension (4)
!>          En entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095, sinon ils seront
!>          réduits modulo 4096, et ISEED(4) doit être impair.
!>          En sortie, la prochaine graine dans la séquence de nombres aléatoires après
!>          la génération de toutes les matrices de test.
!>

THRESH

!>          THRESH est un réel (REAL)
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESID >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

NMAX

!>          NMAX est un entier (INTEGER)
!>          La valeur maximale autorisée pour M ou N, utilisée pour dimensionner
!>          les tableaux de travail.
!>

A

!>          A est un tableau réel (REAL array), dimension (NMAX*NMAX)
!>

AF

!>          AF est un tableau réel (REAL array), dimension (NMAX*NMAX)
!>

B

!>          B est un tableau réel (REAL array), dimension (NMAX*NMAX)
!>

BF

!>          BF est un tableau réel (REAL array), dimension (NMAX*NMAX)
!>

X

!>          X est un tableau réel (REAL array), dimension (4*NMAX)
!>

RWORK

!>          RWORK est un tableau réel (REAL array), dimension (NMAX)
!>

WORK

!>          WORK est un tableau réel (REAL array), dimension (NMAX*NMAX)
!>

NIN

!>          NIN est un entier (INTEGER)
!>          Le numéro d'unité pour l'entrée.
!>

NOUT

!>          NOUT est un entier (INTEGER)
!>          Le numéro d'unité pour la sortie.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          > 0 : Si SLATMS retourne un code d'erreur, sa valeur absolue est retournée.
!>
