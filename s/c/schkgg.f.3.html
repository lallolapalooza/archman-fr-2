SCHKGG

But:

!>
!> SCHKGG  vérifie les routines du problème de valeurs propres généralisé non symétrique.
!>                                T          T        T
!> SGGHRD factorise A et B en U H V  et U T V , où   signifie
!> transposée, H est de Hessenberg, T est triangulaire et U et V sont
!> orthogonales.
!>                                 T          T
!> SHGEQZ factorise H et T en  Q S Z  et Q P Z , où P est triangulaire supérieure,
!> S est sous forme de Schur généralisée (triangulaire supérieure par blocs,
!> avec des blocs 1x1 et 2x2 sur la diagonale, les blocs 2x2 correspondant à des paires
!> de valeurs propres généralisées complexes conjuguées), et Q et Z sont orthogonales.
!> Il calcule également les valeurs propres généralisées (alpha(1),beta(1)),...,(alpha(n),beta(n)),
!> où alpha(j)=S(j,j) et beta(j)=P(j,j) -- ainsi,
!> w(j) = alpha(j)/beta(j) est une racine du problème de valeurs propres généralisé
!>
!>     det( A - w(j) B ) = 0
!>
!> et m(j) = beta(j)/alpha(j) est une racine du problème essentiellement équivalent
!>
!>     det( m(j) A - B ) = 0
!>
!> STGEVC calcule la matrice L des vecteurs propres gauches et la matrice R
!> des vecteurs propres droits pour la paire de matrices ( S, P ). Dans la
!> description ci-dessous,  l et r sont les vecteurs propres gauches et droits
!> correspondant aux valeurs propres généralisées (alpha,beta).
!>
!> Lorsque SCHKGG est appelée, un nombre de matrices  () et un
!> nombre de matrices  sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une matrice sera générée et utilisée
!> pour tester les routines de valeurs propres non symétriques. Pour chaque matrice, 15
!> tests seront effectués. Les douze premiers  doivent être
!> petits -- O(1). Ils seront comparés au seuil THRESH :
!>
!>                  T
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  T
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               T
!> (3)   | I - UU  | / ( n ulp )
!>
!>               T
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  T
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  T
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               T
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               T
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   max pour toutes les paires de valeurs propres/vecteurs propres gauches (beta/alpha,l) de
!>
!>    | l**H * (beta S - alpha P) | / ( ulp max( |beta S|, |alpha P| ) )
!>
!> (10)  max pour toutes les paires de valeurs propres/vecteurs propres gauches (beta/alpha,l') de
!>                           T
!>   | l'**H * (beta H - alpha T) | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       où les vecteurs propres l est le résultat du passage de Q à
!>       STGEVC et de la rétro-transformation (HOWMNY='B').
!>
!> (11)  max pour toutes les paires de valeurs propres/vecteurs propres droits (beta/alpha,r) de
!>
!>       | (beta S - alpha T) r | / ( ulp max( |beta S|, |alpha T| ) )
!>
!> (12)  max pour toutes les paires de valeurs propres/vecteurs propres droits (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       où les vecteurs propres r' sont le résultat du passage de Z à
!>       STGEVC et de la rétro-transformation (HOWMNY='B').
!>
!> Les trois derniers rapports de test seront généralement petits, mais il n'y a pas
!> d'exigence mathématique pour qu'il en soit ainsi. Ils sont donc
!> comparés à THRESH uniquement si TSTDIF est .TRUE.
!>
!> (13)  | S(Q,Z calculé) - S(Q,Z non calculé) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculé) - P(Q,Z non calculé) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z calculé) - alpha(Q,Z non calculé)|/|S| ,
!>            |beta(Q,Z calculé) - beta(Q,Z non calculé)|/|P| ) / ulp
!>
!> De plus, la normalisation de L et R est vérifiée, et comparée
!> au seuil THRSHN.
!>
!> Matrices de Test
!> ---- ------------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES); la valeur de chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) est .TRUE., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  ( 0, 0 )         (une paire de matrices zéro)
!>
!> (2)  ( I, 0 )         (une matrice identité et une matrice zéro)
!>
!> (3)  ( 0, I )         (une matrice zéro et une matrice identité)
!>
!> (4)  ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5)  ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       ; k=(N-1)/2
!>
!> (7)  ( D, I )         où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                       avec ces entrées diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) où  est proche de l'infini et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) U ( J , J ) V     où U et V sont des matrices orthogonales aléatoires.
!>
!> (17) U ( T1, T2 ) V    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées aléatoires O(1) au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) U ( T1, T2 ) V    diag(T1) = ( 0, 0, 1,

Paramètres

NSIZES 
!>          NSIZES est un entier
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          SCHKGG ne fait rien. Il doit être supérieur ou égal à zéro.
!>

NN

!>          NN est un tableau d'entiers, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être supérieures ou égales à zéro.
!>

NTYPES

!>          NTYPES est un entier
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, SCHKGG
!>          ne fait rien. Il doit être supérieur ou égal à zéro. S'il est MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!>

DOTYPE

!>          DOTYPE est un tableau logique, de dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximum de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>

ISEED

!>          ISEED est un tableau d'entiers, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées
!>          dans l'appel suivant à SCHKGG pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est un réel
!>          Un test sera comptabilisé comme un succès si le rapport d'erreur, calculé
!>          comme décrit ci-dessus, dépasse THRESH. Notez que l'erreur est
!>          mise à l'échelle pour être de l'ordre de O(1), donc THRESH devrait être un
!>          multiple raisonnablement petit de 1, par exemple 10 ou 100. En particulier, il
!>          ne doit pas dépendre de la précision (simple ou double) ou de la taille
!>          de la matrice. Il doit être supérieur ou égal à zéro.
!>

TSTDIF

!>          TSTDIF est un logique
!>          Spécifie si les rapports de test 13-15 seront calculés et
!>          comparés avec THRESH.
!>          = .FALSE.: Seuls les rapports de test 1-12 seront calculés et testés.
!>                     Les rapports 13-15 seront mis à zéro.
!>          = .TRUE.:  Tous les rapports de test 1-15 seront calculés et
!>                     testés.
!>

THRSHN

!>          THRSHN est un réel
!>          Seuil pour signaler l'erreur de normalisation du vecteur propre.
!>          Si la normalisation d'un vecteur propre diffère de 1 de plus de THRSHN*ulp,
!>          alors un message d'erreur spécial sera imprimé. (Ceci est géré séparément des autres tests,
!>          car seule une erreur de compilateur ou de programmation devrait provoquer un message d'erreur,
!>          au moins si THRSHN est supérieur ou égal à 5-10.)
!>

NOUNIT

!>          NOUNIT est un entier
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie IINFO différent de 0.)
!>

A

!>          A est un tableau réel, de dimension
!>                            (LDA, max(NN))
!>          Utilisé pour contenir la matrice A originale. Utilisé en entrée uniquement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA est un entier
!>          La dimension principale de A, B, H, T, S1, P1, S2, et P2.
!>          Elle doit être supérieure ou égale à 1 et supérieure ou égale à max( NN ).
!>

B

!>          B est un tableau réel, de dimension
!>                            (LDA, max(NN))
!>          Utilisé pour contenir la matrice B originale. Utilisé en entrée uniquement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

H

!>          H est un tableau réel, de dimension (LDA, max(NN))
!>          La matrice de Hessenberg supérieure calculée à partir de A par SGGHRD.
!>

T

!>          T est un tableau réel, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de B par SGGHRD.
!>

S1

!>          S1 est un tableau réel, de dimension (LDA, max(NN))
!>          La matrice de Schur (bloc triangulaire supérieur) calculée à partir de H par
!>          SHGEQZ lorsque Q et Z sont également calculées.
!>

S2

!>          S2 est un tableau réel, de dimension (LDA, max(NN))
!>          La matrice de Schur (bloc triangulaire supérieur) calculée à partir de H par
!>          SHGEQZ lorsque Q et Z ne sont pas calculées.
!>

P1

!>          P1 est un tableau réel, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de T par SHGEQZ
!>          lorsque Q et Z sont également calculées.
!>

P2

!>          P2 est un tableau réel, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de T par SHGEQZ
!>          lorsque Q et Z ne sont pas calculées.
!>

U

!>          U est un tableau réel, de dimension (LDU, max(NN))
!>          La matrice orthogonale (gauche) calculée par SGGHRD.
!>

LDU

!>          LDU est un entier
!>          La dimension principale de U, V, Q, Z, EVECTL, et EVECTR. Elle
!>          doit être supérieure ou égale à 1 et supérieure ou égale à max( NN ).
!>

V

!>          V est un tableau réel, de dimension (LDU, max(NN))
!>          La matrice orthogonale (droite) calculée par SGGHRD.
!>

Q

!>          Q est un tableau réel, de dimension (LDU, max(NN))
!>          La matrice orthogonale (gauche) calculée par SHGEQZ.
!>

Z

!>          Z est un tableau réel, de dimension (LDU, max(NN))
!>          La matrice orthogonale (gauche) calculée par SHGEQZ.
!>

ALPHR1

!>          ALPHR1 est un tableau réel, de dimension (max(NN))
!>

ALPHI1

!>          ALPHI1 est un tableau réel, de dimension (max(NN))
!>

BETA1

!>          BETA1 est un tableau réel, de dimension (max(NN))
!>
!>          Les valeurs propres généralisées de (A,B) calculées par SHGEQZ
!>          lorsque Q, Z et les matrices de Schur complètes sont calculées.
!>          À la sortie, ( ALPHR1(k)+ALPHI1(k)*i ) / BETA1(k) est la k-ième
!>          valeur propre généralisée des matrices dans A et B.
!>

ALPHR3

!>          ALPHR3 est un tableau réel, de dimension (max(NN))
!>

ALPHI3

!>          ALPHI3 est un tableau réel, de dimension (max(NN))
!>

BETA3

!>          BETA3 est un tableau réel, de dimension (max(NN))
!>

EVECTL

!>          EVECTL est un tableau réel, de dimension (LDU, max(NN))
!>          La matrice des vecteurs propres gauches (bloc triangulaire inférieur) pour
!>          les matrices dans S1 et P1. (Voir STGEVC pour le format.)
!>

EVECTR

!>          EVECTR est un tableau réel, de dimension (LDU, max(NN))
!>          La matrice des vecteurs propres droits (bloc triangulaire supérieur) pour
!>          les matrices dans S1 et P1. (Voir STGEVC pour le format.)
!>

WORK

!>          WORK est un tableau réel, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          Le nombre d'entrées dans WORK. Il doit être supérieur ou égal à
!>          max( 2 * N**2, 6*N, 1 ), pour tous les N=NN(j).
!>

LLWORK

!>          LLWORK est un tableau logique, de dimension (max(NN))
!>

RESULT

!>          RESULT est un tableau réel, de dimension (15)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter
!>          le débordement.
!>

INFO

!>          INFO est un entier
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  Une routine a renvoyé un code d'erreur. INFO est la valeur
!>                absolue de la valeur INFO renvoyée.
!>
