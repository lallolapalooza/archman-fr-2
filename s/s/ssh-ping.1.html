SSH-PING(1) Commandes utilisateur SSH-PING(1)

NOM

ssh-ping

SYNTAXE

ssh-ping [OPTIONS] [utilisateur@]hôte

DESCRIPTION

vérifie si l'hôte est joignable en utilisant ssh_config

OPTIONS

-4
Utiliser uniquement IPv4
-6
Utiliser uniquement IPv6
-c compte
Arrêter après l'envoi de <compte> paquets de requête
-C
Se connecter dès que l'hôte répond
et essayer de se reconnecter après la fin d'une session SSH (par exemple, lors d'un redémarrage).
Utile également pour les périphériques IDRAC, IPMI, ILO, les commutateurs, etc.
qui n'ont pas d'environnement shell complet.
CTRL+C arrête les tentatives de reconnexion.
-E
Quitter immédiatement après le premier ping réussi
(peut être utilisé pour déclencher une tâche de suivi comme rsync)
-F fichier_config
Spécifie un fichier de configuration par utilisateur alternatif.
Si un fichier de configuration est donné en ligne de commande,
le fichier de configuration système ( /etc/ssh/ssh_config ) sera ignoré.
Par défaut, le fichier de configuration par utilisateur est ~/.ssh/config.
-h
Afficher ce message
-i intervalle
Attendre <intervalle> secondes entre l'envoi de chaque requête.
Par défaut, c'est 1 seconde.
-l utilisateur
Essayer de se connecter avec <utilisateur> comme nom d'utilisateur. Par défaut, c'est la valeur actuelle de $USER.
-D
Afficher l'horodatage (heure Unix + microsecondes comme dans gettimeofday) avant chaque ligne
-H
Afficher l'horodatage (lisible par l'homme) avant chaque ligne
-W délai
Délai d'attente pour une réponse, en secondes
-p port
Port de connexion sur l'hôte distant.
Ceci peut être spécifié par hôte dans le fichier de configuration.
-q
Mode silencieux.
Rien n'est affiché à part les lignes de résumé au démarrage et à la fin
-n
Pas de couleurs.
(par exemple, pour les terminaux noir sur blanc)
-v
Mode verbeux
--version
afficher les informations de version

COMPLETIONS TABULATION

Ubuntu (et peut-être d'autres distributions) fournissent déjà
des complétions shell pour ssh qui peuvent être utilisées :

Bash
compléter -F _known_hosts ssh-ping
Zsh
compdef _ssh_hosts ssh-ping
Fish
compléter -c ssh-ping -a "(__fish_print_hostnames)"

ENVIRONNEMENT

SSH_PING_NO_COLORS
si défini, aucune couleur n'est affichée (comme -n)

CODES RETOUR

0
Aucune requête perdue
1
Plus d'une requête perdue
2
Toutes les requêtes perdues

EXEMPLES

ssh-ping -E nom_hote && echo "Premier ping réussi. Démarrage de rsync..."
ssh-ping -q -c 1 nom_hote >/dev/null && echo "Hôte actif !"
ssh-ping -q -c 1 nom_hote >/dev/null || echo "Hôte inactif !"
SSH_PING_NO_COLORS=true ssh-ping -c 1 nom_hote
