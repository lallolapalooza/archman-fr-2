sous-programme ssyevd_2stage (jobz, uplo, n, a, lda, w, work, lwork, iwork, liwork, info)
SSYEVD_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices SY

Documentation de la fonction/sous-programme

sous-programme ssyevd_2stage (caractère jobz, caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) w, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

SSYEVD_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres pour les matrices SY en utilisant la technique 2stage pour la réduction à la forme tridiagonale. Si des vecteurs propres sont requis, il utilise un algorithme de type diviser pour régner.

Objectif :

!>
!> SSYEVD_2STAGE calcule toutes les valeurs propres et, éventuellement, les vecteurs
!> propres d'une matrice symétrique réelle A en utilisant la technique 2stage pour
!> la réduction à la forme tridiagonale. Si des vecteurs propres sont requis,
!> il utilise un algorithme de type diviser pour régner.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA, N)
!>          En entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N de A contient la partie
!>          supérieure triangulaire de la matrice A. Si UPLO = 'L',
!>          la partie inférieure triangulaire N x N de A contient la partie
!>          inférieure triangulaire de la matrice A.
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient les
!>          vecteurs propres orthonormés de la matrice A.
!>          Si JOBZ = 'N', alors en sortie, le triangle inférieur (si UPLO='L')
!>          ou le triangle supérieur (si UPLO='U') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

W

!>          W est un tableau REEL, dimension (N)
!>          Si INFO = 0, les valeurs propres sont triées par ordre croissant.
!>

WORK

!>          WORK est un tableau REEL,
!>                                         dimension (LWORK)
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 2*N+1
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N+1
!>                                   où KD est la taille du bloc de la réduction,
!>                                   FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ
!>                                   généralement FACTOPTNB=128 est un bon choix
!>                                   NTHREADS est le nombre de threads utilisés lorsque
!>                                   la compilation openMP est activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être au moins
!>                                                1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK et IWORK,
!>          renvoie ces valeurs comme premières entrées des tableaux WORK et IWORK,
!>          et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!>

LIWORK

!>          LIWORK est ENTIER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK doit être au moins 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK doit être au moins 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK et
!>          IWORK, et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i et JOBZ = 'N', alors l'algorithme n'a pas réussi
!>                à converger ; i éléments hors diagonale d'une forme
!>                tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>                si INFO = i et JOBZ = 'V', alors l'algorithme n'a pas réussi
!>                à calculer une valeur propre lors du traitement de la sous-matrice
!>                située dans les lignes et colonnes INFO/(N+1) à
!>                mod(INFO,N+1).
!>
