SSYGVD

But :

!>
!> SSYGVD calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème eigen-valeur généralisé symétrique réel défini, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici A et
!> B sont supposés symétriques et B est aussi définie positive.
!> Si des vecteurs propres sont désirés, il utilise un algorithme de type diviser pour régner.
!>
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          Spécifie le type de problème à résoudre :
!>          = 1 :  A*x = (lambda)*B*x
!>          = 2 :  A*B*x = (lambda)*x
!>          = 3 :  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CARACTERE*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U' : Les triangles supérieurs de A et B sont stockés ;
!>          = 'L' : Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est tableau REEL, dimension (LDA, N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de A contient la
!>          partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient la
!>          matrice Z des vecteurs propres.  Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors en sortie, le triangle supérieur (si UPLO='U')
!>          ou le triangle inférieur (si UPLO='L') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est tableau REEL, dimension (LDB, N)
!>          En entrée, la matrice symétrique B. Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de B contient la
!>          partie triangulaire supérieure de la matrice B. Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de B contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**T*U ou B = L*L**T.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

W

!>          W est tableau REEL, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

WORK

!>          WORK est tableau REEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' et N > 1, LWORK >= 2*N+1.
!>          Si JOBZ = 'V' et N > 1, LWORK >= 1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est tableau ENTIER, dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!>

LIWORK

!>          LIWORK est ENTIER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à
!>          LWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  Sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  SPOTRF ou SSYEVD a retourné un code d'erreur :
!>             <= N :  si INFO = i et JOBZ = 'N', alors l'algorithme
!>                    n'a pas réussi à converger ; i éléments hors diagonale d'une
!>                    forme tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>                    si INFO = i et JOBZ = 'V', alors l'algorithme
!>                    n'a pas réussi à calculer une valeur propre tout en travaillant sur
!>                    la sous-matrice située dans les lignes et colonnes INFO/(N+1)
!>                    jusqu'à mod(INFO,N+1) ;
!>             > N :   si INFO = N + i, pour 1 <= i <= N, alors le mineur
!>                    principal de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>

NAME
ssygvd - computes the inverse of a real symmetric definite tridiagonal matrix
SYNOPSIS

    call ssygvd(n, v, ldv, p, q, ..., info)
DESCRIPTION
ssygvd computes the eigenvalues and, optionally, eigenvectors of a real symmetric tridiagonal matrix $A$ in the generalized eigenvalue problem: $A x = \lambda B x$ where $B$ is a real symmetric tridiagonal matrix, which may be positive definite. The problem is first reduced to the standard eigenvalue problem: $C z = \lambda z$ where $C$ is a real symmetric tridiagonal matrix. The eigenvalues and eigenvectors of $C$ are then computed. The arguments are: * n: The order of the matrices $A$ and $B$. * v: A real array of dimension $(ldv, n)$. On exit, v contains the matrix of eigenvectors, with the $i$-th column of v representing the eigenvector of $C$ corresponding to the $i$-th eigenvalue. * ldv: The leading dimension of the array v. * p: A real array of dimension $(n)$. On exit, p contains the eigenvalues of $C$ in ascending order. * q: A real array of dimension $(n)$. On exit, q contains the eigenvalues of $A$ in ascending order. * info: An integer. info is 0 on exit, and the routine will exit with info $< 0$ if an error has occurred.
