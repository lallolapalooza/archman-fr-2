SSR(1) Commandes utilisateur SSR(1)

NOM

SSR - page de manuel pour le rendu BRS

SYNOPSIS

ssr-brs [OPTIONS] <fichier-scène>

DESCRIPTION

Le SoundScape Renderer (SSR) est un outil de reproduction audio spatiale en temps réel fournissant une variété d'algorithmes de rendu.

OPTIONS

Options spécifiques au rendu :

--hrirs=FICHIER
Charge les HRIR pour le rendu binaural depuis FICHIER
--hrir-size=N
Tronque les HRIR à la longueur N
--prefilter=FICHIER
Charge le préfiltre WFS depuis FICHIER
-o, --ambisonics-order=VALEUR
Ordre d'ambisonie à utiliser pour AAP (défaut : maximum)
--in-phase-rendering
Utilise le rendu en phase pour le rendu AAP

Options JACK :

-n, --name=NOM
Définit le nom du client JACK à NOM
--input-prefix=PREFIXE
Préfixe des ports d'entrée (défaut : "system:capture_")
--output-prefix=PREFIXE
Préfixe des ports de sortie (défaut : "system:playback_")
-f, --freewheel
Utilise JACK en mode freewheeling

Options générales :

-c, --config=FICHIER
Lit la configuration depuis FICHIER
-s, --setup=FICHIER
Charge la configuration de reproduction depuis FICHIER
--threads=N
Nombre de threads audio (défaut : auto)
-r, --record=FICHIER
Enregistre la sortie audio du rendu dans FICHIER
--decay-exponent=VALEUR
Exposant déterminant la décroissance d'amplitude (défaut : 1) (désactivé à la compilation !)
--loop
Boucle tous les fichiers audio
--master-volume-correction=VALEUR
Correction du volume maître en dB (défaut : 0 dB)
--auto-rotation Rotation automatique de l'orientation des sources sonores vers le
référentiel
--no-auto-rotation
Ne pas faire pivoter automatiquement l'orientation des sources sonores vers le référentiel
-i, --ip-server
Démarre le serveur IP (non activé à la compilation !)
-I, --no-ip-server
Ne pas démarrer le serveur IP (défaut)
--websocket-server
Démarre le serveur WebSocket (non activé à la compilation !)
--no-websocket-server
Ne pas démarrer le serveur WebSocket (défaut)
--fudi-server
Démarre le serveur FUDI (non activé à la compilation !)
--no-fudi-server
Ne pas démarrer le serveur FUDI (défaut)
--follow
Attend qu'une autre instance SSR se connecte
--no-follow
Ne pas suivre une autre instance SSR (défaut)
-g, --gui
Démarre l'interface graphique (non activé à la compilation !)
-G, --no-gui
Ne pas démarrer l'interface graphique (défaut)
-t, --tracker=TYPE
Sélectionne le trackeur de tête, valeurs possibles : fastrak patriot razor
--tracker-port=PORT
Nom ou numéro de port du trackeur de tête, par ex. /dev/ttyS1
-T, --no-tracker
N'utilise pas de trackeur de tête (défaut)
-h, --help
Affiche l'aide et quitte
-v, --verbose
Augmente le niveau de verbosité (jusqu'à -vvv)
-V, --version
Affiche les informations de version et quitte
