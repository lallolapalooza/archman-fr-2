NOM

sssctl - Utilitaire de contrôle et de statut SSSD

SYNTAXE

sssctl COMMANDE [options]

DESCRIPTION

sssctl fournit un moyen simple et unifié d'obtenir des informations sur le statut de SSSD, telles que le serveur actif, les serveurs auto-découverts, les domaines et les objets mis en cache. De plus, il peut gérer les fichiers de données SSSD pour le dépannage, de manière à pouvoir y accéder en toute sécurité pendant que SSSD est en cours d'exécution.

COMMANDES DISPONIBLES

Pour lister toutes les commandes disponibles, exécutez sssctl sans aucun paramètre. Pour afficher l'aide d'une commande sélectionnée, exécutez sssctl COMMANDE --help.

OPTIONS COMMUNES

Ces options sont disponibles avec toutes les commandes.

--debug NIVEAU

SSSD prend en charge deux représentations pour spécifier le niveau de débogage. La plus simple consiste à spécifier une valeur décimale de 0 à 9, ce qui signifie activer ce niveau et tous les messages de débogage de niveau inférieur. L'option la plus complète consiste à spécifier un masque de bits hexadécimal pour activer ou désactiver des niveaux spécifiques (par exemple, si vous souhaitez supprimer un niveau).

Niveaux de débogage actuellement pris en charge :

0, 0x0010 : Échecs fatals. Tout ce qui pourrait empêcher SSSD de démarrer ou le faire s'arrêter.

1, 0x0020 : Échecs critiques. Une erreur qui ne tue pas SSSD, mais qui indique qu'au moins une fonctionnalité majeure ne fonctionnera pas correctement.

2, 0x0040 : Échecs graves. Une erreur annonçant qu'une requête ou une opération particulière a échoué.

3, 0x0080 : Échecs mineurs. Ce sont les erreurs qui remonteront pour provoquer l'échec de l'opération 2.

4, 0x0100 : Paramètres de configuration.

5, 0x0200 : Données de fonction.

6, 0x0400 : Messages de trace pour les fonctions d'opération.

7, 0x1000 : Messages de trace pour les fonctions de contrôle internes.

8, 0x2000 : Contenu des variables internes des fonctions qui peuvent être intéressantes.

9, 0x4000 : Informations de trace de très bas niveau.

10, 0x10000 : Informations de trace libldb encore plus de bas niveau. Presque jamais vraiment nécessaires.

Pour journaliser les niveaux de débogage requis par masque de bits, il suffit d'additionner leurs nombres comme indiqué dans les exemples suivants :

Exemple : Pour journaliser les échecs fatals, les échecs critiques, les échecs graves et les données de fonction, utilisez 0x0270.

Exemple : Pour journaliser les échecs fatals, les paramètres de configuration, les données de fonction, les messages de trace pour les fonctions de contrôle internes, utilisez 0x1310.

Note : Le format de masque de bits des niveaux de débogage a été introduit dans la version 1.7.0.

Défaut : 0x0070 (c'est-à-dire échecs fatals, critiques et graves ; correspond au réglage 2 en notation décimale)
