Documentation de la fonction/sous-programme

sous-programme sstev (caractère jobz, entier n, réel, dimension( * ) d, réel, dimension( * ) e, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier info)

SSTEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour d'AUTRES matrices

Objectif :

!>
!> SSTEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice symétrique tridiagonale réelle A.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau REEL, de dimension (N)
!>          En entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          En sortie, si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

E

!>          E est un tableau REEL, de dimension (N-1)
!>          En entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A, stockés dans les éléments 1 à N-1 de E.
!>          En sortie, le contenu de E est détruit.
!>

Z

!>          Z est un tableau REEL, de dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs
!>          propres orthonormés de la matrice A, la i-ème colonne de Z
!>          contenant le vecteur propre associé à D(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, de dimension (max(1,2*N-2))
!>          Si JOBZ = 'N', WORK n'est pas référencé.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, l'algorithme a échoué à converger ; i
!>                éléments hors diagonale de E n'ont pas convergé vers zéro.
!>
