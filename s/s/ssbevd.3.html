sous-routine ssbevd (jobz, uplo, n, kd, ab, ldab, w, z, ldz, work, lwork, iwork, liwork, info)
SSBEVD calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour d'autres matrices

Documentation de la fonction/sous-routine

sous-routine ssbevd (caractere jobz, caractere uplo, entier n, entier kd, reel, dimension( ldab, * ) ab, entier ldab, reel, dimension( * ) w, reel, dimension( ldz, * ) z, entier ldz, reel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

SSBEVD calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour des matricesbandes symétriques réelles. Si des vecteurs propres sont souhaités, elle utilise un algorithme de « diviser pour régner ».

Objectif :

!>
!> SSBEVD calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice bande symétrique réelle A. Si des vecteurs propres sont souhaités,
!> elle utilise un algorithme de diviser pour régner.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau REAL de dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les KD+1 premières lignes du tableau. La
!>          colonne j de A est stockée dans la colonne j du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par les valeurs générées lors de la
!>          réduction en forme tridiagonale. Si UPLO = 'U', la première
!>          superdiagonale et la diagonale de la matrice tridiagonale T
!>          sont renvoyées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont renvoyées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!>

W

!>          W est un tableau REAL de dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau REAL de dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormés de la matrice A, avec la i-ème colonne de Z
!>          contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL,
!>                                         dimension (LWORK)
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          SI N <= 1,                LWORK doit être au moins 1.
!>          Si JOBZ  = 'N' et N > 2, LWORK doit être au moins 2*N.
!>          Si JOBZ  = 'V' et N > 2, LWORK doit être au moins
!>                         ( 1 + 5*N + 2*N**2 ).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK et IWORK,
!>          renvoie ces valeurs comme premières entrées des tableaux WORK
!>          et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 2, LIWORK doit être au moins 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des tableaux
!>          WORK et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : fin réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>
