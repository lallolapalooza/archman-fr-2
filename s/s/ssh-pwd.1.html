SSH-PWD(1) Commandes utilisateur SSH-PWD(1)

NOM

ssh-pwd

SYNOPIS

ssh-pwd [PATH]

DESCRIPTION

écho rapidement le chemin à utiliser pour scp, rsync

FICHIERS

/etc/ssh-tools/ssh-pwd/targets
~/.config/ssh-tools/ssh-pwd/targets

Il suffit d'y insérer des adresses IP, des FQDN
et ils seront également affichés dans la sortie
