sous-programme ssyevx (caractère jobz, caractère range, caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel vl, réel vu, entier il, entier iu, réel abstol, entier m, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

SSYEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices SY

Objectif :

!>
!> SSYEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice symétrique réelle A. Les valeurs propres et les vecteurs propres peuvent être
!> sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle demi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les IL-èmes à IU-èmes valeurs propres seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL de dimension (LDA, N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de A contient
!>          la partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec le plus de précision lorsque ABSTOL
!>          est défini à deux fois le seuil de sous-flux 2*SLAMCH('S'), pas zéro.
!>          Si cette routine se termine avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REAL de dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les valeurs propres sélectionnées
!>          par ordre croissant.
!>

Z

!>          Z est un tableau REAL de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une limite supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK.  LWORK >= 1, lorsque N <= 1 ;
!>          sinon 8*N.
!>          Pour une efficacité optimale, LWORK >= (NB+3)*N,
!>          où NB est le maximum de la taille de bloc pour SSYTRD et SORMTR
!>          retourné par ILAENV.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  fin de l'exécution réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!>

NAME

ssyevx - computes the eigenvalues and eigenvectors of a real symmetric matrix.

SYNOPSIS

        subroutine ssyevx(matrix_layout, jobz, range, uplo, n, a, lda, vl, vu, il, iu,
                          abstol, m, w, z, ldz, work, lwork, iwork, info)

        character(len=1)          :: jobz, range, uplo
        integer                   :: n, lda, il, iu, m, ldz, lwork, info
        real(kind=4), dimension(:), intent(inout) :: a
        real(kind=4), dimension(:), intent(in)    :: vl, vu
        real(kind=4), dimension(:), intent(out)   :: w, work
        integer, dimension(:), intent(out)        :: iwork
        integer                   :: matrix_layout

Function/Subroutine Documentation

ssyevx is a subroutine in LAPACK that computes the eigenvalues and eigenvectors of a real symmetric matrix. It offers flexibility in choosing which eigenvalues and eigenvectors to compute based on a specified range or indices.

Arguments:

matrix_layout
Specifies the storage format of the matrices (row-major or column-major).
jobz
Specifies whether to compute only eigenvalues ('N') or both eigenvalues and eigenvectors ('V').
range
Specifies the range of eigenvalues to be computed:
  • 'A': all eigenvalues.
  • 'V': eigenvalues in the interval (vl, vu].
  • 'I': the il-th through iu-th eigenvalues.
uplo
Specifies whether the upper ('U') or lower ('L') triangle of the symmetric matrix a is stored.
n
The order of the matrix a. n ≥ 0.
a
The n x n symmetric matrix. On exit, a is overwritten.
lda
The leading dimension of the array a. lda ≥ max(1, n).
vl
The lower bound of the interval for the desired eigenvalues. Not used if range = 'I' or 'A'.
vu
The upper bound of the interval for the desired eigenvalues. Not used if range = 'I' or 'A'.
il
The starting index for the desired eigenvalues. Not used if range = 'A' or 'V'.
iu
The ending index for the desired eigenvalues. Not used if range = 'A' or 'V'.
abstol
The absolute tolerance for the eigenvalues. If abstol ≤ 0, then the machine precision is used.
m
The total number of eigenvalues found.
w
The array containing the computed eigenvalues in ascending order. The dimension of w must be at least max(1, n).
z
The array containing the computed eigenvectors. If jobz = 'V', then the eigenvectors are stored column-by-column in the array z. The dimension of z must be at least max(1, ldz*n).
ldz
The leading dimension of the array z. ldz ≥ n if jobz = 'V', and ldz ≥ 1 otherwise.
work
A workspace array of dimension at least max(1, lwork). Used for intermediate computations.
lwork
The dimension of the array work. lwork ≥ 1. If lwork = -1, then lwork is determined automatically, and the subroutine returns.
iwork
A workspace array of dimension at least max(1, 5*n). Used for integer workspace.
info
  • 0: successful exit
  • < 0: if info = -i, then the i-th argument had an illegal value
  • > 0: if info = i, then the algorithm did not converge; i eigenvectors could not be found.
