Documentation de la fonction/sous-programme

sous-programme ssytrs (caractère uplo, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, réel, dimension( ldb, * ) b, entier ldb, entier info)

SSYTRS

But:

!>
!> SSYTRS résout un système d'équations linéaires A*X = B avec une matrice symétrique réelle A
!> en utilisant la factorisation A = U*D*U**T ou A = L*D*L**T calculée par SSYTRF.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U': Triangulaire supérieure, forme A = U*D*U**T;
!>          = 'L': Triangulaire inférieure, forme A = L*D*L**T.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L calculés par SSYTRF.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Détails des échanges et de la structure de blocs de D
!>          tels que déterminés par SSYTRF.
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice du côté droit B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
