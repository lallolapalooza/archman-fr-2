Documentation de fonction/sous-routine

sous-routine ssygvx (integer itype, character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSYGVX

Objectif :

!>
!> SSYGVX calcule des valeurs propres sélectionnées, et éventuellement, des vecteurs propres
!> d'un problème propre symétrique-défini généralisé réel, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici, A
!> et B sont supposés symétriques et B est également défini positif.
!> Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une
!> plage de valeurs, soit une plage d'indices pour les valeurs propres souhaitées.
!>

Paramètres

ITYPE 
!>          ITYPE est un entier (INTEGER)
!>          Spécifie le type de problème à résoudre :
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est un caractère (CHARACTER*1)
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est un caractère (CHARACTER*1)
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs propres de rang IL à IU seront trouvées.
!>

UPLO

!>          UPLO est un caractère (CHARACTER*1)
!>          = 'U':  La partie triangulaire supérieure de A et B est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A et B est stockée.
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre du faisceau de matrices (A,B).  N >= 0.
!>

A

!>          A est un tableau de réels (REAL array), dimension (LDA, N)
!>          En entrée, la matrice symétrique A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de A contient
!>          la partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau de réels (REAL array), dimension (LDB, N)
!>          En entrée, la matrice symétrique B. Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de B contient
!>          la partie triangulaire supérieure de la matrice B. Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de B contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**T*U ou B = L*L**T.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

VL

!>          VL est un réel (REAL)
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est un réel (REAL)
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est un entier (INTEGER)
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est un entier (INTEGER)
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est un réel (REAL)
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est considérée comme convergée
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant C à forme tridiagonale, où C est la matrice symétrique
!>          du problème symétrique standard auquel le problème généralisé
!>          est transformé.
!>
!>          Les valeurs propres seront calculées avec une précision maximale lorsque ABSTOL est
!>          défini à deux fois le seuil de sous-dépassement 2*DLAMCH('S'), et non à zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>

M

!>          M est un entier (INTEGER)
!>          Le nombre total de valeurs propres trouvées. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau de réels (REAL array), dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les
!>          valeurs propres sélectionnées par ordre croissant.
!>

Z

!>          Z est un tableau de réels (REAL array), dimension (LDZ, max(1,M))
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est un entier (INTEGER)
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de réels (REAL array), dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale LWORK.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La longueur du tableau WORK. LWORK >= max(1,8*N).
!>          Pour une efficacité optimale, LWORK >= (NB+3)*N,
!>          où NB est la taille de bloc pour SSYTRD retournée par ILAENV.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail
est supposé ; la routine
!> ne calcule que la taille optimale du tableau WORK, retourne
!> cette valeur comme première entrée du tableau WORK, et aucun message
!> d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau de type INTEGER, de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro.  Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : SPOTRF ou SSYEVX a retourné un code d'erreur :
!>             <= N : si INFO = i, SSYEVX n'a pas convergé ;
!>                    i vecteurs propres n'ont pas convergé. Leurs indices
!>                    sont stockés dans le tableau IFAIL.
!>             > N :  si INFO = N + i, pour 1 <= i <= N, alors le mineur
!>                    principal de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
