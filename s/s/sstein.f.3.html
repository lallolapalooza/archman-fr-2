sous-programme sstein (integer n, real, dimension( * ) d, real, dimension( * ) e, integer m, real, dimension( * ) w, integer, dimension( * ) iblock, integer, dimension( * ) isplit, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSTEIN

But:

!>
!> SSTEIN calcule les vecteurs propres d'une matrice tridiagonale symétrique réelle
!> T correspondant à des valeurs propres spécifiées, en utilisant l'itération inverse.
!>
!> Le nombre maximum d'itérations autorisées pour chaque vecteur propre est
!> spécifié par un paramètre interne MAXITS (actuellement réglé à 5).
!>

Paramètres

N 
!>          N est un entier (INTEGER).
!>          L'ordre de la matrice. N >= 0.
!>

D

!>          D est un tableau réel (REAL), de dimension (N).
!>          Les N éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau réel (REAL), de dimension (N-1).
!>          Les N-1 éléments sous-diagonaux de la matrice tridiagonale
!>          T, dans les éléments 1 à N-1.
!>

M

!>          M est un entier (INTEGER).
!>          Le nombre de vecteurs propres à trouver. 0 <= M <= N.
!>

W

!>          W est un tableau réel (REAL), de dimension (N).
!>          Les M premiers éléments de W contiennent les valeurs propres
!>          pour lesquelles les vecteurs propres doivent être calculés. Les valeurs propres
!>          devraient être groupées par blocs séparés et ordonnées de la plus petite à la plus grande
!>          au sein du bloc. ( Le tableau de sortie W de SSTEBZ avec ORDER = 'B' est attendu ici. )
!>

IBLOCK

!>          IBLOCK est un tableau entier (INTEGER), de dimension (N).
!>          Les indices de sous-matrice associés aux valeurs propres correspondantes
!>          dans W ; IBLOCK(i)=1 si la valeur propre W(i) appartient à
!>          la première sous-matrice vue de dessus, =2 si W(i) appartient à
!>          la deuxième sous-matrice, etc. ( Le tableau de sortie IBLOCK
!>          de SSTEBZ est attendu ici. )
!>

ISPLIT

!>          ISPLIT est un tableau entier (INTEGER), de dimension (N).
!>          Les points de séparation, où T se décompose en sous-matrices.
!>          La première sous-matrice consiste en les lignes/colonnes 1 à
!>          ISPLIT( 1 ), la deuxième en les lignes/colonnes ISPLIT( 1 )+1
!>          jusqu'à ISPLIT( 2 ), etc.
!>          ( Le tableau de sortie ISPLIT de SSTEBZ est attendu ici. )
!>

Z

!>          Z est un tableau réel (REAL), de dimension (LDZ, M).
!>          Les vecteurs propres calculés. Le vecteur propre associé
!>          à la valeur propre W(i) est stocké dans la i-ème colonne de
!>          Z. Tout vecteur qui ne converge pas est mis à sa dernière
!>          itération après MAXITS itérations.
!>

LDZ

!>          LDZ est un entier (INTEGER).
!>          La dimension principale du tableau Z. LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau réel (REAL), de dimension (5*N).
!>

IWORK

!>          IWORK est un tableau entier (INTEGER), de dimension (N).
!>

IFAIL

!>          IFAIL est un tableau entier (INTEGER), de dimension (M).
!>          En cas de sortie normale, tous les éléments de IFAIL sont zéro.
!>          Si un ou plusieurs vecteurs propres ne convergent pas après
!>          MAXITS itérations, leurs indices sont stockés dans
!>          le tableau IFAIL.
!>

INFO

!>          INFO est un entier (INTEGER).
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, alors i vecteurs propres n'ont pas convergé
!>               en MAXITS itérations. Leurs indices sont stockés dans
!>               le tableau IFAIL.
!>

Paramètres internes:

!>  MAXITS  INTEGER, par défaut = 5
!>          Le nombre maximum d'itérations effectuées.
!>
!>  EXTRA   INTEGER, par défaut = 2
!>          Le nombre d'itérations effectuées après que le critère de croissance de la norme
!>          soit satisfait, doit être au moins 1.
!>
