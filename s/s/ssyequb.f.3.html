Documentation de la fonction/sous-programme

sous-routine ssyequb (caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) s, réel scond, réel amax, réel, dimension( * ) work, entier info)

SSYEQUB

Objectif :

!>
!> SSYEQUB calcule les facteurs d'échelle de lignes et de colonnes destinés à
!> équilibrer une matrice symétrique A (par rapport à la norme euclidienne)
!> et à réduire son nombre de conditionnement. Les facteurs d'échelle S
!> sont calculés par l'algorithme BIN (voir les références) de sorte que
!> la matrice mise à l'échelle B avec les éléments B(i,j) = S(i)*A(i,j)*S(j)
!> ait un nombre de conditionnement dans un facteur N du plus petit
!> nombre de conditionnement possible sur toutes les mises à l'échelle
!> diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': le triangle supérieur de A est stocké ;
!>          = 'L': le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau de REEL, dimension (LDA,N)
!>          La matrice symétrique N x N dont les facteurs d'échelle doivent être
!>          calculés.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

S

!>          S est un tableau de REEL, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est REEL
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est REEL
!>          La plus grande valeur absolue d'un élément de la matrice. Si AMAX est
!>          très proche du dépassement (overflow) ou du sous-dépassement (underflow),
!>          la matrice doit être mise à l'échelle.
!>

WORK

!>          WORK est un tableau de REEL, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, le i-ème élément diagonal est non positif.
!>
