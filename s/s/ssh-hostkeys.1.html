SSH-HOSTKEYS(1) Commandes utilisateur SSH-HOSTKEYS(1)

NOM

ssh-hostkeys

SYNOPIS

ssh-hostkeys [OPTIONS] nom-hote

DESCRIPTION

affiche les clés d'hôte du serveur dans plusieurs formats

OPTIONS

-4
Utiliser uniquement IPv4
-6
Utiliser uniquement IPv6
-h
Afficher ce message
-T délai
Délai d'attente d'une réponse, en secondes
-p port
Port de connexion sur l'hôte distant.
