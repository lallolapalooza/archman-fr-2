NOM

sscg - Outil pour générer des certificats x.509

SYNTAXE

sscg [OPTION...]

DESCRIPTION

-V, --version
Affiche le numéro de version et quitte.
-f, --force
Écrase tous les fichiers préexistants aux emplacements demandés. DANGER : Vous ne voudrez probablement pas utiliser ceci !

Options d'aide :

-?, --help
Affiche ce message d'aide
--usage
Affiche un bref message d'utilisation

Options de verbosité

-q, --quiet
N'affiche aucune sortie sauf en cas d'erreur.
-v, --verbose
Affiche les messages de progression.
-d, --debug
Active la journalisation des messages de débogage. Implique verbose. Attention ! Ceci affichera des informations de clé privée à l'écran !

Options du sujet du certificat

--lifetime=1-3650
Durée de vie du certificat (en jours). (défaut : 398)
--country=FR, CH, etc.
DN du certificat : Pays (C). (défaut : "US")
--state=Île-de-France, Québec, etc.
DN du certificat : État ou Province (ST).
--locality=Paris, Lyon, etc.
DN du certificat : Localité (L).
--organization=Mon Entreprise
DN du certificat : Organisation (O). (défaut : "Unspecified")
--organizational-unit=Ingénierie, etc.
DN du certificat : Unité organisationnelle (OU).
--email=monnom@example.com
DN du certificat : Adresse e-mail (Email).
--hostname=serveur.example.com
Le nom d'hôte valide du certificat. Doit être un FQDN. (défaut : FQDN du système actuel)
--subject-alt-name alt.example.com
Noms d'hôte valides supplémentaires optionnels pour le certificat. En plus des noms d'hôte, cette option accepte également des valeurs explicites supportées par la RFC 5280, telles que IP:xxx.xxx.xxx.xxx Peut être spécifiée plusieurs fois.

Options de cryptographie de la clé du certificat

--key-type={rsa,ecdsa,mldsa}
Type de clé à utiliser pour les clés privées du certificat. (défaut : rsa)
--key-strength=2048 ou plus
Force des clés privées du certificat en bits. Cet argument n'est valide que si --key-type est réglé sur rsa. (défaut : 2048)
--ec-curve={secp224r1,secp256r1,secp384r1,secp521r1}
Courbe EC à utiliser pour les clés privées du certificat. Cet argument n'est valide que si --key-type est réglé sur ecdsa.
--mldsa-nist-level={2,3,5}
Niveau NIST à utiliser pour la clé ML-DSA. Cet argument n'est valide que si --key-type est réglé sur mldsa. (défaut : 2)
--hash-alg={sha256,sha384,sha512}
Algorithme de hachage à utiliser pour la signature des clés RSA et ECDSA. Cet argument n'est valide que si --key-type est rsa ou ecdsa. (défaut : "sha256")
--cipher-alg={des-ede3-cbc,aes-256-cbc}
Chiffrement à utiliser pour crypter les fichiers de clé. (défaut : "aes-256-cbc")

Options du fichier d'autorité de certification

--ca-file=CHAÎNE
Chemin où le certificat public de l'AC sera stocké. (défaut : "./ca.crt")
--ca-mode=0644
Mode de fichier du certificat d'AC créé.
--ca-key-file=CHAÎNE
Chemin où la clé privée de l'AC sera stockée. Si non spécifié, la clé sera détruite plutôt que écrite sur le disque.
--ca-key-mode=0600
Mode de fichier de la clé d'AC créée.
--ca-key-password=CHAÎNE
Fournit un mot de passe pour le fichier de clé d'AC. Notez que celui-ci sera visible dans la table des processus pour tous les utilisateurs, il doit donc être utilisé uniquement à des fins de test. Utilisez --ca-keypassfile ou --ca-key-password-prompt pour une saisie sécurisée du mot de passe.
--ca-key-passfile=CHAÎNE
Un fichier contenant le mot de passe pour crypter le fichier de clé d'AC.
-C, --ca-key-password-prompt
Invite à entrer un mot de passe pour le fichier de clé d'AC.

Options du fichier de liste de révocation de certificats

--crl-file=CHAÎNE
Chemin où un fichier de liste de révocation de certificats (vide) sera créé, pour les applications qui s'attendent à ce qu'un tel fichier existe. Si non spécifié, aucun fichier ne sera créé.
--crl-mode=0644
Mode de fichier de la liste de révocation de certificats créée.

Options du fichier de certificat de service

--cert-file=CHAÎNE
Chemin où le certificat public de service sera stocké. (défaut "./service.pem")
--cert-mode=0644
Mode de fichier du certificat créé.
--cert-key-file=CHAÎNE
Chemin où la clé privée du service sera stockée. (défaut "service-key.pem")
--cert-key-mode=0600
Mode de fichier de la clé de certificat créée.
-p, --cert-key-password=CHAÎNE
Fournit un mot de passe pour le fichier de clé de service. Notez que celui-ci sera visible dans la table des processus pour tous les utilisateurs, ce flag doit donc être utilisé uniquement à des fins de test. Utilisez --cert-keypassfile ou --cert-key-password-prompt pour une saisie sécurisée du mot de passe.
--cert-key-passfile=CHAÎNE
Un fichier contenant le mot de passe pour crypter le fichier de clé de service.
-P, --cert-key-password-prompt
Invite à entrer un mot de passe pour le fichier de clé de service.

Options du fichier de certificat d'authentification client

--client-file=CHAÎNE
Chemin où un certificat d'authentification client sera stocké.
--client-mode=0644
Mode de fichier du certificat créé.
--client-key-file=CHAÎNE
Chemin où la clé privée du client sera stockée. (défaut est le client-file)
--client-key-mode=0600
Mode de fichier de la clé de certificat créée.
--client-key-password=CHAÎNE
Fournit un mot de passe pour le fichier de clé client. Notez que celui-ci sera visible dans la table des processus pour tous les utilisateurs, ce flag doit donc être utilisé uniquement à des fins de test. Utilisez --client-keypassfile ou --client-key-password-prompt pour une saisie sécurisée du mot de passe.
--client-key-passfile=CHAÎNE
Un fichier contenant le mot de passe pour crypter le fichier de clé client.

NAME

sscg - Secure Shell Client Generator

SYNOPSIS 

sscg [OPTIONS]... PROFILE

DESCRIPTION

Generate SSH client configuration files for multiple SSH servers.

OPTIONS

Key File Options

-p, --password=STRING
The password for the client key file.
--prompt
Prompt to enter a password for the client key file.

Diffie-Hellman Parameter File Options

--dhparams-file=STRING
A file to contain a set of Diffie-Hellman parameters. (Default: not created)
--dhparams-named-group=STRING
Output well-known DH parameters. The available named groups are: ffdhe2048, ffdhe3072, ffdhe4096, ffdhe6144, ffdhe8192, modp_2048, modp_3072, modp_4096, modp_6144, modp_8192, modp_1536, dh_1024_160, dh_2048_224, dh_2048_256. (Default: "ffdhe4096")
--dhparams-generator={2,3,5}
The generator value for dhparams. (default: 2)
