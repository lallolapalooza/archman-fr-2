SSH-SIG(1) Commandes utilisateur SSH-SIG(1)

NOM

ssh-sig

SYNTAXE

ssh-sig COMMANDE OPTION

DESCRIPTION

simplifie ssh-keygen -Y

OPTIONS

-h --help

  --version

COMMANDES

sign
créer une signature
check
vérifier une signature

AIDE

sign
--help
check
--help

EXEMPLES

ssh-sig sign fichier.txt
ssh-sig check -s fichier.txt.sig < fichier.txt

cat fichier.txt | ssh-sig sign > fichier.txt.sig
cat fichier.txt | ssh-sig check -s fichier.txt.sig

# Signer plusieurs fichiers
ssh-sig sign fichier1.txt fichier2.txt [...]

# Utiliser une autre clé pour la signature
ssh-sig sign -f ~/.ssh/id_rsa fichier.txt

# Utiliser une clé publique. La clé privée pour la signature provient de ssh-agent
ssh-sig sign -f ~/.ssh/id_rsa.pub fichier.txt
