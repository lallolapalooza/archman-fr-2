NOM

sshmitm - Homme du milieu SSH

SYNTAXE

sshmitm [-d] [-I] [-p port] hôte [port]

DESCRIPTION


sshmitm relaie et renifle le trafic SSH redirigé par dnsspoof(8), capturant les connexions SSH par mot de passe et, éventuellement, piratant les sessions interactives. Seule la version 1 du protocole SSH est (ou sera jamais) prise en charge - ce programme est déjà bien assez malveillant.

OPTIONS

-d
Activer la sortie de débogage détaillée.
-I
Surveiller / pirater une session interactive.
-p port
Spécifier le port local sur lequel écouter.
hôte
Spécifier l'hôte distant vers lequel relayer les connexions.
port
Spécifier le port distant vers lequel relayer les connexions.
