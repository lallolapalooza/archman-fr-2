Documentation de la fonction/sous-routine

sous-routine sstedc (caractere compz, entier n, reel, dimension( * ) d, reel, dimension( * ) e, reel, dimension( ldz, * ) z, entier ldz, reel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

SSTEDC

But :

!>
!> SSTEDC calcule toutes les valeurs propres et, optionnellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique en utilisant la méthode diviser pour régner.
!> Les vecteurs propres d'une matrice symétrique dense ou bande peuvent aussi être
!> trouvés si SSYTRD ou SSPTRD ou SSBTRD a été utilisé pour réduire cette
!> matrice à une forme tridiagonale.
!>
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres.
!>          = 'I' : Calculer également les vecteurs propres de la matrice tridiagonale.
!>          = 'V' : Calculer également les vecteurs propres de la matrice symétrique d'origine.
!>                  À l'entrée, Z contient la matrice orthogonale utilisée pour réduire
!>                  la matrice d'origine à une forme tridiagonale.
!>

N

!>          N est INTEGER
!>          La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres en ordre croissant.
!>

E

!>          E est un tableau REEL, dimension (N-1)
!>          À l'entrée, les éléments sous-diagonaux de la matrice tridiagonale.
!>          À la sortie, E est détruit.
!>

Z

!>          Z est un tableau REEL, dimension (LDZ,N)
!>          À l'entrée, si COMPZ = 'V', alors Z contient la matrice orthogonale
!>          utilisée dans la réduction à la forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormaux de la matrice symétrique d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormaux
!>          de la matrice tridiagonale symétrique.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si des vecteurs propres sont désirés, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si COMPZ = 'N' ou N <= 1, LWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LWORK doit être au moins
!>                         ( 1 + 3*N + 2*N*lg N + 4*N**2 ),
!>                         où lg( N ) = le plus petit entier k tel que
!>                         2**k >= N.
!>          Si COMPZ = 'I' et N > 1, LWORK doit être au moins
!>                         ( 1 + 4*N + N**2 ).
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou égal
!>          à la taille minimale de division, généralement 25, alors LWORK
!>          doit seulement être max(1,2*(N-1)).
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient la taille LIWORK optimale.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si COMPZ = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LIWORK doit être au moins
!>                         ( 6 + 6*N + 5*N*lg N ).
!>          Si COMPZ = 'I' et N > 1, LIWORK doit être au moins
!>                         ( 3 + 5*N ).
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou égal
!>          à la taille minimale de division, généralement 25, alors LIWORK
!>          doit seulement être 1.
!>
!>          Si LIWORK = -1, une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement la taille optimale du tableau IWORK,
!>          renvoie cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme n'a pas réussi à calculer une valeur propre lors
!>                du traitement de la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) jusqu'à mod(INFO,N+1).
!>
