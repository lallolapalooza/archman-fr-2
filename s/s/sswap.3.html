sous-programme sswap (integer n, real, dimension(*) sx, integer incx, real, dimension(*) sy, integer incy)

SSWAP

Objectif :

!>
!>    SSWAP échange deux vecteurs.
!>    utilise des boucles déroulées pour des incréments égaux à 1.
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

SX

!>          SX est un tableau REEL, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un ENTIER
!>         espacement de stockage entre les éléments de SX
!>

SY

!>          SY est un tableau REEL, dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est un ENTIER
!>         espacement de stockage entre les éléments de SY
!>
