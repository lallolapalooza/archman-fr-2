sous-programme sspgvx (integer itype, character jobz, character range, character uplo, integer n, real, dimension( * ) ap, real, dimension( * ) bp, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSPGVX

Objectif :

!>
!> SSPGVX calcule les valeurs propres sélectionnées, et éventuellement, les vecteurs propres
!> d'un problème généralisé symétrique-défini réel, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici, A
!> et B sont supposés symétriques, stockés en stockage compressé, et B
!> est aussi définie positive. Les valeurs propres et les vecteurs propres peuvent être
!> sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres désirées.
!>

Paramètres

ITYPE 
!>          ITYPE est INTEGER
!>          Spécifie le type de problème à résoudre :
!>          = 1 :  A*x = (lambda)*B*x
!>          = 2 :  A*B*x = (lambda)*x
!>          = 3 :  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle ouvert à droite (VL,VU]
!>                  seront trouvées.
!>          = 'I' : les valeurs propres de l'indice IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A et B est stocké ;
!>          = 'L' : le triangle inférieur de A et B est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre du faisceau de matrices (A,B).  N >= 0.
!>

AP

!>          AP est tableau REAL, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, compressé par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          En sortie, le contenu de AP est détruit.
!>

BP

!>          BP est tableau REAL, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          B, compressé par colonne dans un tableau linéaire. La j-ème colonne de B
!>          est stockée dans le tableau BP comme suit :
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) pour j<=i<=n.
!>
!>          En sortie, le facteur triangulaire U ou L de la factorisation de Cholesky
!!>          B = U**T*U ou B = L*L**T, dans le même format de stockage que B.
!>

VL

!>          VL est REAL
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>          lorsqu'elle est déterminée comme se situant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision de la machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Les valeurs propres seront calculées le plus précisément lorsque ABSTOL
!>          est défini à deux fois le seuil de débordement inférieur 2*SLAMCH('S'),
!>          et non à zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est tableau REAL, dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les valeurs propres
!>          sélectionnées par ordre croissant.
!>

Z

!>          Z est tableau REAL, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vecteur propre échoue à converger, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une limite supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est tableau REAL, dimension (8*N)
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL est tableau INTEGER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui ont échoué à converger.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : SPPTRF ou SSPEVX ont retourné un code d'erreur :
!>             <= N : si INFO = i, SSPEVX n'a pas convergé ;
!>                    i vecteurs propres n'ont pas convergé. Leurs indices
!!>                    sont stockés dans le tableau IFAIL.
!>             > N : si INFO = N + i, pour 1 <= i <= N, alors le principal m de tête
sspgvx(3) — LAPACK

NAME

sspgvx — Computes the eigenvalues and eigenvectors of a complex system of linear equations A*x = lambda*B*x, A*x = lambda*B**T*x, or A**H*x = lambda*B*x, where A and B are real symmetric (or complex Hermitian) matrices, and B is positive definite.

SYNOPSIS

SUBROUTINE SSPGVX( ITYPE, JOBZ, RANGE, UPLO, N, AP, BP, VL, VU, IL,
                        IU, OFFPRT, WORK, LWORK, IWORK, LIWORK,
                        RESVEC, INFO )
        INTEGER INFO, IL, IU, ITYPE, LWORK, LIWORK, N
        REAL VL, VU
        CHARACTER JOBZ, RANGE, UPLO
        REAL AP( * ), BP( * ), OFFPRT( * ), RESVEC( * ), WORK( * )
        INTEGER IWORK( * )

Function/Subroutine Documentation

This subroutine computes the eigenvalues and eigenvectors of a real symmetric generalized eigenvalue problem of the form:

        A*x = lambda*B*x
        A*x = lambda*B**T*x
        A**H*x = lambda*B*x

where A and B are real symmetric (or complex Hermitian) matrices, and B is positive definite. Here A**H denotes the conjugate transpose of A.

Parameters:

ITYPE
(Input) INTEGER
Specifies the equations to be solved:
  • ITYPE = 1: A*x = lambda*B*x
  • ITYPE = 2: A*x = lambda*B**T*x
  • ITYPE = 3: A**H*x = lambda*B*x
JOBZ
(Input) CHARACTER*1
  • JOBZ = 'N': Compute only the eigenvalues and no eigenvectors.
  • JOBZ = 'V': Compute the eigenvalues and eigenvectors of the symmetric/Hermitian matrix A.
RANGE
(Input) CHARACTER*1
  • RANGE = 'A': All eigenvalues will be found.
  • RANGE = 'V': All eigenvalues between VL and VU will be found.
  • RANGE = 'I': The IL-th to IU-th eigenvalues will be found.
UPLO
(Input) CHARACTER*1
  • UPLO = 'U': Upper triangle of A and B will be used.
  • UPLO = 'L': Lower triangle of A and B will be used.
N
(Input) INTEGER
The order of the matrices A and B. N >= 0.
AP
(Input) REAL array, dimension (N*(N+1)/2)
The upper or lower triangular part of the symmetric/Hermitian matrix A, packed columnwise in a linear array. For example, if UPLO = 'U' and N = 3, the array AP contains the column elements of the upper triangle and is given by:
AP = [ a11, a12, a22, a13, a23, a33 ]
BP
(Input) REAL array, dimension (N*(N+1)/2)
The upper or lower triangular part of the symmetric/Hermitian positive definite matrix B, packed columnwise in a linear array. For example, if UPLO = 'U' and N = 3, the array BP contains the column elements of the upper triangle and is given by:
BP = [ b11, b12, b22, b13, b23, b33 ]
VL
(Input) REAL
If RANGE = 'V', the lower bound of the interval for the desired eigenvalues.
VU
(Input) REAL
If RANGE = 'V', the upper bound of the interval for the desired eigenvalues.
IL
(Input) INTEGER
If RANGE = 'I', the index of the lowest eigenvalue in the select range, with 1 to N corresponding to the ordered eigenvalues.
IU
(Input) INTEGER
If RANGE = 'I', the index of the highest eigenvalue in the select range, with 1 to N corresponding to the ordered eigenvalues.
OFFPRT
(Output) REAL array, dimension (N)
If JOBZ = 'V', then the offsets of the eigenvectors in the array RESVEC. OFFPRT(i) is the offset of the i-th eigenvector.
WORK
(Workspace) REAL array, dimension (LWORK)
LWORK
(Input) INTEGER
The dimension of the array WORK. LWORK >= 1.
If LWORK = -1, then a workspace query is implemented, and the subroutine only calculates the optimal size of the array WORK. The optimal size is returned as the first entry of WORK, and no value is returned by SSPGVX.
IWORK
(Workspace) INTEGER array, dimension (LIWORK)
LIWORK
(Input) INTEGER
The dimension of the array IWORK. LIWORK >= 1.
If LIWORK = -1, then a workspace query is implemented, and the subroutine only calculates the optimal size of the array IWORK. The optimal size is returned as the first entry of IWORK, and no value is returned by SSPGVX.
RESVEC
(Output) REAL array, dimension (N, N) or (N, M)
If JOBZ = 'N', then RESVEC is not used.
If JOBZ = 'V', then RESVEC contains the eigenvectors of the problem. The eigenvectors are stored in the columns of RESVEC. The i-th column of RESVEC contains the eigenvector corresponding to the i-th eigenvalue of the problem. If ITYPE = 1 or 3, the eigenvectors are normalized so that the first element of each is real and non-negative, and the other elements are complex. If ITYPE = 2, the eigenvectors are normalized to have Euclidean norm equal to 1.
INFO
(Output) INTEGER
  • INFO = 0: Successful exit
  • INFO < 0: If INFO = -i, the i-th argument had an illegal value.
  • INFO > 0: If INFO = i, then the algorithm failed to converge; i eigenvectors failed to converge.

Description:

The subroutine SSPGVX calls the routines SSPGST, SSPGTR, SSTEGR, and SSTEDC to compute the eigenvalues and eigenvectors.

SSPGST reduces the symmetric generalized eigenvalue problem A*x = lambda*B*x to the standard eigenvalue problem.

SSPGTR computes the eigenvalues and eigenvectors of the reduced problem.

SSTEGR computes the eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

SSTEDC computes the eigenvalues and eigenvectors of a symmetric tridiagonal matrix using divide and conquer.

The factorization of B could not be completed and no eigenvalues or eigenvectors were computed.
