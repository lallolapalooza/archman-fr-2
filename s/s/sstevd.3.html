sous-routine sstevd (jobz, n, d, e, z, ldz, work, lwork, iwork, liwork, info)
SSTEVD calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour D'AUTRES matrices

Documentation de la fonction/sous-routine

sous-routine sstevd (character jobz, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSTEVD calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une matrice tridiagonale symétrique réelle. Si les vecteurs propres sont désirés, il utilise un algorithme de diviser pour régner.

Objectif :

!>
!> SSTEVD calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique réelle. Si les vecteurs propres sont désirés,
!> il utilise un algorithme de diviser pour régner.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calcule les valeurs propres seulement ;
!>          = 'V':  Calcule les valeurs propres et les vecteurs propres.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          À la sortie, si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

E

!>          E est un tableau REEL, dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice tridiagonale
!>          A, stockés dans les éléments 1 à N-1 de E.
!>          À la sortie, le contenu de E est détruit.
!>

Z

!>          Z est un tableau REEL, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormés de la matrice A, avec la i-ème colonne de Z
!>          contenant le vecteur propre associé à D(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL,
!>                                         dimension (LWORK)
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si JOBZ  = 'N' ou N <= 1 alors LWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1 alors LWORK doit être au moins
!>                         ( 1 + 4*N + N**2 ).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement les tailles optimales des tableaux WORK et IWORK,
!>          renvoie ces valeurs comme premières entrées des tableaux WORK
!>          et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1 alors LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1 alors LIWORK doit être au moins 3+5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à
!>          LWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale de E n'ont pas convergé vers zéro.
!>
