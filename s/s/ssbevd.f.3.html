Documentation de la fonction/sous-routine

sous-routine ssbevd (caractère jobz, caractère uplo, entier n, entier kd, réel, dimension( ldab, * ) ab, entier ldab, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

SSBEVD calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour d'autres matrices

Objectif :

!>
!> SSBEVD calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice bande symétrique réelle A. Si les vecteurs propres sont désirés, il
!> utilise un algorithme de type « diviser pour régner ».
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau de REEL, dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          En sortie, AB est écrasé par les valeurs générées lors de la
!>          réduction en forme tridiagonale. Si UPLO = 'U', la première
!>          super-diagonale et la diagonale de la matrice tridiagonale T
!>          sont retournées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont retournées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD + 1.
!>

W

!>          W est un tableau de REEL, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau de REEL, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormés de la matrice A, la i-ième colonne de Z
!>          contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de REEL,
!>                                         dimension (LWORK)
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          Si N <= 1,                LWORK doit être au moins 1.
!>          Si JOBZ  = 'N' et N > 2, LWORK doit être au moins 2*N.
!>          Si JOBZ  = 'V' et N > 2, LWORK doit être au moins
!>                         ( 1 + 5*N + 2*N**2 ).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement les tailles optimales des tableaux WORK et
!>          IWORK, retourne ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) contient la valeur optimale de LIWORK.
!>

LIWORK

!>          LIWORK est un ENTIER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 2, LIWORK doit être au moins 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement les tailles optimales des tableaux WORK et
!>          IWORK, retourne ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : Terminaison réussie
!>          < 0 : Si INFO = -i, alors le i-ième argument avait une valeur illégale
!>          > 0 : Si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>
