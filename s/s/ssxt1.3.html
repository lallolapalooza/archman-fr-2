real function ssxt1 (integer ijob, real, dimension( * ) d1, integer n1, real, dimension( * ) d2, integer n2, real abstol, real ulp, real unfl)

SSXT1

But :

!>
!> SSXT1  calcule la différence entre un ensemble de valeurs propres.
!> Le résultat est retourné comme valeur de la fonction.
!>
!> IJOB = 1:   Calcule   max { min | D1(i)-D2(j) | }
!>                         i     j
!>
!> IJOB = 2:   Calcule   max { min | D1(i)-D2(j) | /
!>                         i     j
!>                              ( ABSTOL + |D1(i)|*ULP ) }
!>

Paramètres

IJOB 
!>          IJOB est un entier (INTEGER)
!>          Spécifie le type de tests à effectuer. (Voir ci-dessus.)
!>

D1

!>          D1 est un tableau de réels (REAL array), dimension (N1)
!>          Le premier tableau. D1 doit être en ordre croissant, c'est-à-dire
!>          D1(j) <= D1(j+1).
!>

N1

!>          N1 est un entier (INTEGER)
!>          La longueur de D1.
!>

D2

!>          D2 est un tableau de réels (REAL array), dimension (N2)
!>          Le second tableau. D2 doit être en ordre croissant, c'est-à-dire
!>          D2(j) <= D2(j+1).
!>

N2

!>          N2 est un entier (INTEGER)
!>          La longueur de D2.
!>

ABSTOL

!>          ABSTOL est un réel (REAL)
!>          La tolérance absolue, utilisée comme mesure de l'erreur.
!>

ULP

!>          ULP est un réel (REAL)
!>          La précision machine.
!>

UNFL

!>          UNFL est un réel (REAL)
!>          Le plus petit nombre positif dont l'inverse ne provoque pas de
!>          dépassement.
!>
