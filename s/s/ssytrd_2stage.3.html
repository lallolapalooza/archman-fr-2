SSYTRD_2STAGE

But :

!>
!> SSYTRD_2STAGE réduit une matrice symétrique réelle A à la forme tridiagonale symétrique réelle T
!> par une transformation de similarité orthogonale :
!> Q1**T Q2**T* A * Q2 * Q1 = T.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'N':  Pas besoin de la représentation de Householder,
!>                  en particulier pour la deuxième étape (Bande à
!>                  tridiagonale) et donc LHOUS2 est de taille max(1, 4*N) ;
!>          = 'V':  la représentation de Householder est nécessaire pour
!>                  générer Q1 Q2 ou pour appliquer Q1 Q2,
!>                  alors LHOUS2 doit être interrogé et calculé.
!>                  (PAS DISPONIBLE DANS CETTE VERSION).
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire N x N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>          À la sortie, si UPLO = 'U', la bande superdiagonale
!>          de A est écrasée par les éléments correspondants de la
!>          matrice bande-diagonale interne AB, et les éléments au-dessus
!>          de la KD-superdiagonale, avec le tableau TAU, représentent la matrice
!>          orthogonale Q1 comme un produit de réflexions élémentaires ; si UPLO
!>          = 'L', la diagonale et la sous-diagonale de bande de A sont écrasées
!>          par les éléments correspondants de la matrice bande-diagonale
!>          interne AB, et les éléments sous la KD-sous-diagonale, avec
!>          le tableau TAU, représentent la matrice orthogonale Q1 comme un produit
!>          de réflexions élémentaires. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

D

!>          D est un tableau REAL, de dimension (N)
!>          Les éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau REAL, de dimension (N-1)
!>          Les éléments hors diagonale de la matrice tridiagonale T.
!>

TAU

!>          TAU est un tableau REAL, de dimension (N-KD)
!>          Les facteurs scalaires des réflexions élémentaires de
!>          la première étape (voir Détails supplémentaires).
!>

HOUS2

!>          HOUS2 est un tableau REAL, de dimension (MAX(1,LHOUS2))
!>          Stocke la représentation de Householder de l'étape 2
!>          bande vers tridiagonale.
!>

LHOUS2

!>          LHOUS2 est INTEGER
!>          La dimension du tableau HOUS2.
!>          LHOUS2 >= 1.
!>
!>          Si LWORK = -1, ou LHOUS2 = -1,
!>          alors une interrogation est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau HOUS2, renvoie
!>          cette valeur comme première entrée du tableau HOUS2, et aucun message
!>          d'erreur lié à LHOUS2 n'est émis par XERBLA.
!>          Si VECT='N', LHOUS2 = max(1, 4*n) ;
!>          si VECT='V', option pas encore disponible.
!>

WORK

!>          WORK est un tableau REAL, de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon LWORK = MAX(1, dimension).
!>
!>          Si LWORK = -1, ou LHOUS2 = -1,
!>          alors une interrogation de l'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>          LWORK = MAX(1, dimension) où
!>          dimension   = max(etape1,etape2) + (KD+1)*N
!>                      = N*KD + N*max(KD+1,FACTOPTNB)
!>                        + max(2*KD*KD, KD*NTHREADS)
!>                        + (KD+1)*N
!>          où KD est la taille du bloc de la réduction,
!>          FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ
!>          généralement FACTOPTNB=128 est un bon choix
!>          NTHREADS est le nombre de threads utilisés lors de la
!>          compilation openMP activée, sinon =1.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

NAME

ssytrd_2stage - performs a symmetric tridiagonal reduction of a general matrix

SYNOPSIS

SUBROUTINE SSYTRD_2STAGE(ITYPE, UPLO, N, A, LDA, D, E, TAU, WORK, LWORK, INFO)

INTEGER ITYPE

CHARACTER *(*) UPLO

INTEGER N, LDA, LWORK, INFO

REAL A(LDA,*)

REAL D(*), E(*), TAU(*)

REAL WORK(*)

Function/Subroutine Documentation

This subroutine reduces a real symmetric matrix A to tridiagonal form T:

A = Q * T * Q**T

where Q is an orthogonal matrix. The reduction is performed in two stages:

Stage 1: A is reduced to a condensed form R by an orthogonal matrix Q1:

A = Q1 * R * Q1**T

where R is a bidiagonal matrix.

Stage 2: R is reduced to a tridiagonal matrix T by an orthogonal matrix Q2:

R = Q2 * T * Q2**T

The overall reduction is then:

A = (Q1 * Q2) * T * (Q1 * Q2)**T

The matrix Q is given by Q = Q1 * Q2.

The diagonal elements of T are stored in the array D, and the subdiagonal elements are stored in the array E.

The array TAU contains the scalar factors of the elementary reflectors.

The array WORK is used for temporary storage.

The parameter ITYPE specifies the type of reduction:

  • ITYPE = 1: A is reduced to tridiagonal form T.
  • ITYPE = 2: A is reduced to bidiagonal form R.

The parameter UPLO specifies whether the upper or lower triangular part of A is used:

  • UPLO = 'U': Upper triangular part is used.
  • UPLO = 'L': Lower triangular part is used.

The parameter N is the order of the matrix A.

The parameter LDA is the leading dimension of the array A.

The parameter LWORK is the dimension of the array WORK. LWORK must be at least 2*N.

The parameter INFO is an integer output parameter:

  • INFO = 0: successful exit
  • INFO < 0: if INFO = -i, the i-th argument had an illegal value

Documentation de la fonction/sous-routine

Cette sous-routine réduit une matrice symétrique réelle A à une forme tridiagonale T :

A = Q * T * Q**T

où Q est une matrice orthogonale. La réduction est effectuée en deux étapes :

Étape 1 : A est réduite à une forme condensée R par une matrice orthogonale Q1 :

A = Q1 * R * Q1**T

où R est une matrice bidiagonale.

Étape 2 : R est réduite à une matrice tridiagonale T par une matrice orthogonale Q2 :

R = Q2 * T * Q2**T

La réduction globale est alors :

A = (Q1 * Q2) * T * (Q1 * Q2)**T

La matrice Q est donnée par Q = Q1 * Q2.

Les éléments diagonaux de T sont stockés dans le tableau D, et les éléments sous-diagonaux sont stockés dans le tableau E.

Le tableau TAU contient les facteurs scalaires des réflecteurs élémentaires.

Le tableau WORK est utilisé pour le stockage temporaire.

Le paramètre ITYPE spécifie le type de réduction :

  • ITYPE = 1 : A est réduite à la forme tridiagonale T.
  • ITYPE = 2 : A est réduite à la forme bidiagonale R.

Le paramètre UPLO spécifie si la partie triangulaire supérieure ou inférieure de A est utilisée :

  • UPLO = 'U' : La partie triangulaire supérieure est utilisée.
  • UPLO = 'L' : La partie triangulaire inférieure est utilisée.

Le paramètre N est l'ordre de la matrice A.

Le paramètre LDA est la dimension principale du tableau A.

Le paramètre LWORK est la dimension du tableau WORK. LWORK doit être au moins 2*N.

Le paramètre INFO est un paramètre de sortie entier :

  • INFO = 0 : sortie réussie
  • INFO < 0 : si INFO = -i, le i-ème argument était invalide
