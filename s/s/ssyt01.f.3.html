sous-routine ssyt01 (caractere uplo, entier n, reel, dimension( lda, * ) a, entier lda, reel, dimension( ldafac, * ) afac, entier ldafac, entier, dimension( * ) ipiv, reel, dimension( ldc, * ) c, entier ldc, reel, dimension( * ) rwork, reel resid)

SSYT01

Purpose:

!>
!> SSYT01 reconstruit une matrice symétrique indéfinie A à partir de sa
!> factorisation bloc L*D*L' ou U*D*U' et calcule la norme du résidu
!>    norm( C - A ) / ( N * norm(A) * EPS ),
!> où C est la matrice reconstruite et EPS est la partie fractionnaire de la machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice symétrique originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau REEL, dimension (LDAFAC,N)
!>          La forme factorisée de la matrice A. AFAC contient la matrice
!>          diagonale bloc D et les multiplicateurs utilisés pour obtenir
!>          le facteur L ou U à partir de la factorisation bloc L*D*L' ou U*D*U'
!>          calculée par SSYTRF.
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC.  LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de SSYTRF.
!>

C

!>          C est un tableau REEL, dimension (LDC,N)
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RESID

!>          RESID est REEL
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
