sous-routine sspt21 (integer itype, character uplo, integer n, integer kband, real, dimension( * ) ap, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) vp, real, dimension( * ) tau, real, dimension( * ) work, real, dimension( 2 ) result)

SSPT21

But :

!>
!> SSPT21 vérifie généralement une décomposition de la forme
!>
!>         A = U S U**T
!>
!> où **T signifie transposée, A est symétrique (stockée en format compacté), U
!> est orthogonale, et S est diagonale (si KBAND=0) ou symétrique
!> tridiagonale (si KBAND=1). Si ITYPE=1, alors U est représentée comme une
!> matrice dense, sinon U est exprimée comme un produit de
!> transformations de Householder, dont les vecteurs sont stockés dans le tableau
!>  et dont les constantes de mise à l'échelle sont dans  
 nous utiliserons la
!> lettre  pour désigner le produit des transformations de Householder
!> (qui doit être égal à U).
!>
!> Spécifiquement, si ITYPE=1, alors :
!>
!>         RESULT(1) = | A - U S U**T | / ( |A| n ulp ) et
!>         RESULT(2) = | I - U U**T | / ( n ulp )
!>
!> Si ITYPE=2, alors :
!>
!>         RESULT(1) = | A - V S V**T | / ( |A| n ulp )
!>
!> Si ITYPE=3, alors :
!>
!>         RESULT(1) = | I - V U**T | / ( n ulp )
!>
!> Le stockage compacté signifie que, par exemple, si UPLO='U', les colonnes
!> du triangle supérieur de A sont stockées les unes après les autres, de sorte que
!> A(1,j+1) suit immédiatement A(j,j) dans le tableau AP. De même, si
!> UPLO='L', les colonnes du triangle inférieur de A sont stockées les unes après les autres
!> dans AP, de sorte que A(j+1,j+1) suit immédiatement A(n,j)
!> dans le tableau AP.
!> Cela signifie que A(i,j) est stocké dans :
!>
!>    AP( i + j*(j-1)/2 )                 si UPLO='U'
!>
!>    AP( i + (2*n-j)*(j-1)/2 )           si UPLO='L'
!>
!> Le tableau VP a la même relation avec la matrice V que AP avec A.
!>
!> Pour ITYPE > 1, la transformation U est exprimée comme un produit
!> de transformations de Householder :
!>
!>    Si UPLO='U', alors  V = H(n-1)...H(1),  où
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**T
!>
!>    et les j-1 premiers éléments de v(j) sont stockés dans V(1:j-1,j+1),
!>    (c'est-à-dire VP( j*(j+1)/2 + 1 : j*(j+1)/2 + j-1 ) ),
!>    le j-ème élément est 1, et les n-j derniers éléments sont 0.
!>
!>    Si UPLO='L', alors  V = H(1)...H(n-1),  où
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**T
!>
!>    et les j premiers éléments de v(j) sont 0, le (j+1)-ème est 1, et les
!!>    éléments j+2 à n sont stockés dans V(j+2:n,j) (c'est-à-dire
!>    dans VP( (2*n-j)*(j-1)/2 + j+2 : (2*n-j)*(j-1)/2 + n ) .)
!>

Paramètres

ITYPE 
!>          ITYPE est un entier
!>          Spécifie le type de tests à effectuer.
!>          1 : U exprimée comme une matrice orthogonale dense :
!>             RESULT(1) = | A - U S U**T | / ( |A| n ulp ) et
!>             RESULT(2) = | I - U U**T | / ( n ulp )
!>
!>          2 : U exprimée comme un produit V de transformations de Housholder :
!>             RESULT(1) = | A - V S V**T | / ( |A| n ulp )
!>
!>          3 : U exprimée à la fois comme une matrice orthogonale dense et
!>             comme un produit de transformations de Housholder :
!>             RESULT(1) = | I - V U**T | / ( n ulp )
!>

UPLO

!>          UPLO est un caractère
!>          Si UPLO='U', AP et VP sont considérés comme contenant le triangle supérieur
!>          de A et V.
!>          Si UPLO='L', AP et VP sont considérés comme contenant le triangle inférieur
!>          de A et V.
!>

N

!>          N est un entier
!>          La taille de la matrice. Si elle est nulle, SSPT21 ne fait rien.
!>          Elle doit être supérieure ou égale à zéro.
!>

KBAND

!>          KBAND est un entier
!>          La largeur de bande de la matrice. Elle ne peut être que zéro ou un.
!>          Si elle est zéro, S est diagonale et E n'est pas référencée. Si
!>          elle est un, S est symétrique tridiagonale.
!>

AP

!>          AP est un tableau REAL, de dimension (N*(N+1)/2)
!>          La matrice originale (non factorisée). Elle est supposée être
!>          symétrique et contient les colonnes du triangle supérieur
!>          (UPLO='U') ou seulement du triangle inférieur (UPLO='L'),
!>          compactées les unes après les autres.
!>

D

!>          D est un tableau REAL, de dimension (N)
!>          La diagonale de la matrice (symétrique tri-) diagonale.
!>

E

!>          E est un tableau REAL, de dimension (N-1)
!>          La partie sous-diagonale de la matrice (symétrique tri-) diagonale.
!>          E(1) est l'élément (1,2) et (2,1), E(2) est l'élément (2,3) et
!>          (3,2), etc.
!>          Non référencée si KBAND=0.
!>

U

!>          U est un tableau REAL, de dimension (LDU, N)
!>          Si ITYPE=1 ou 3, il contient la matrice orthogonale dans
!>          la décomposition, exprimée comme une matrice dense. Si ITYPE=2,
!>          alors il n'est pas référencé.
!>

LDU

!>          LDU est un entier
!>          La dimension principale de U. LDU doit être au moins N et
!>          au moins 1.
!>

VP

!>          VP est un tableau REAL, de dimension (N*(N+1)/2)
!>          Si ITYPE=2 ou 3, les colonnes de ce tableau contiennent les
!>          vecteurs de Householder utilisés pour décrire la matrice orthogonale
!>          dans la décomposition, comme décrit dans le but.
!>          *NOTE* Si ITYPE=2 ou 3, V est modifié et restauré. La
!>          sous-diagonale (si UPLO='L') ou la super-diagonale (si UPLO='U')
!>          est mise à un, et plus tard remise à sa valeur d'origine, pendant
!>          le déroulement du calcul.
!>          Si ITYPE=1, alors il n'est ni référencé ni modifié.
!>

TAU

!>          TAU est un tableau REAL, de dimension (N)
!>          Si ITYPE >= 2, alors TAU(j) est le facteur scalaire de
!>          v(j) v(j)**T dans la transformation de Householder H(j) du
!>          produit  U = H(1)...H(n-2)
!>          Si ITYPE < 2, alors TAU n'est pas référencé.
!>

WORK

!>          WORK est un tableau REAL, de dimension (N**2+N)
!>          Espace de travail.
!>

RESULT

!>          RESULT est un tableau REAL, de dimension (2)
!>          Les valeurs calculées par les deux tests décrits ci-dessus. Les
!>          valeurs sont actuellement limitées à 1/ulp, pour éviter les dépassements.
!>          RESULT(1) est toujours modifié. RESULT(2) est modifié uniquement
!>          si ITYPE=1.
!>
