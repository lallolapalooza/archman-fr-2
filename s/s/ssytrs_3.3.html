SSYTRS_3

But :

!> SSYTRS_3 résout un système d'équations linéaires A * X = B avec une matrice
!> symétrique réelle A en utilisant la factorisation calculée
!> par SSYTRF_RK ou SSYTRF_BK :
!>
!>    A = P*U*D*(U**T)*(P**T) ou A = P*L*D*(L**T)*(P**T),
!>
!> où U (ou L) est une matrice triangulaire unitaire supérieure (ou inférieure),
!> U**T (ou L**T) est la transposée de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est une matrice symétrique et bloc-diagonale
!> avec des blocs diagonaux de 1x1 et 2x2.
!>
!> Cet algorithme utilise le niveau 3 de BLAS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure :
!>          = 'U' : Triangulaire supérieure, forme est A = P*U*D*(U**T)*(P**T) ;
!>          = 'L' : Triangulaire inférieure, forme est A = P*L*D*(L**T)*(P**T).
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau de type REAL, dimension (LDA,N)
!>          Diagonale de la matrice bloc-diagonale D et facteurs U ou L
!>          tels que calculés par SSYTRF_RK et SSYTRF_BK :
!>            a) SEULEMENT les éléments diagonaux de la matrice symétrique bloc-diagonale
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                doivent être fournis en entrée dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau de type REAL, dimension (N)
!>          En entrée, contient les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice symétrique bloc-diagonale D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) non référencé ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) non référencé.
!>
!>          NOTE : Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) n'est référencé dans aucun des cas
!>          UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau de type INTEGER, dimension (N)
!>          Détails des échanges et de la structure bloc de D
!>          tels que déterminés par SSYTRF_RK ou SSYTRF_BK.
!>

B

!>          B est un tableau de type REAL, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
