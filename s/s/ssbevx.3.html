SSBEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour d'AUTRES matrices

Documentation de la fonction/sous-programme

sous-programme ssbevx (caractere jobz, caractere range, caractere uplo, entier n, entier kd, reel, dimension( ldab, * ) ab, entier ldab, reel, dimension( ldq, * ) q, entier ldq, reel vl, reel vu, entier il, entier iu, reel abstol, entier m, reel, dimension( * ) w, reel, dimension( ldz, * ) z, entier ldz, reel, dimension( * ) work, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

SSBEVX calcule des valeurs propres sélectionnées et, éventuellement, des vecteurs propres d'une matrice bande symétrique réelle A. Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les valeurs propres désirées.

Objectif :

!>
!> SSBEVX calcule des valeurs propres sélectionnées et, éventuellement, des vecteurs propres
!> d'une matrice bande symétrique réelle A. Les valeurs propres et les vecteurs propres peuvent
!> être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les
!> valeurs propres souhaitées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle ouvert à droite (VL,VU]
!>                 seront trouvées ;
!>          = 'I': les valeurs propres de l'indice IL à l'indice IU seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB est un tableau de type REAL, de dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par les valeurs générées pendant la
!>          réduction en matrice tridiagonale. Si UPLO = 'U', la première
!>          superdiagonale et la diagonale de la matrice tridiagonale T
!>          sont retournées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont retournées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB. LDAB >= KD + 1.
!>

Q

!>          Q est un tableau de type REAL, de dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice orthogonale N x N utilisée dans la
!>                         réduction en matrice tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. Si JOBZ = 'V', alors
!>          LDQ >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergente
!>          lorsqu'il est déterminé qu'elle se trouve dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant AB en matrice tridiagonale.
!>
!>          Les valeurs propres seront calculées avec la plus grande précision lorsque ABSTOL
!>          est défini à deux fois le seuil de sous-flux 2*SLAMCH('S'), et non zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>
!>          Voir par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau de type REAL, de dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées par ordre
!>          croissant.
!>

Z

!>          Z est un tableau de type REAL, de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (7*N)
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau de type INTEGER, de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, alors i vecteurs propres n'ont pas convergé.

ssbevx(3) — LAPACK — Arch Linux

NAME

ssbevx — Diagonalizes a real symmetric tridiagonal matrix.

SYNOPSIS

       SUBROUTINE SSBEVX( JOBZ, RANGE, UPLO, N, KD, AB, LDAB, Q, LDQ, VL,
                          VU, IL, IU, GENCE, M, NZ, EPS, WORK, IWORK,
                          JA, WKDIM, INFO )


Arguments

JOBZ
CHARACTER*1. Must be ‘N’ or ‘V’. If JOBZ = ‘N’, then only the eigenvalues are computed. If JOBZ = ‘V’, then the eigenvalues and the corresponding eigenvectors are computed.
RANGE
CHARACTER*1. Must be ‘A’, ‘V’ or ‘I’.
If RANGE = ‘A’, all eigenvalues are computed.
If RANGE = ‘V’, all eigenvalues in the interval (VL, VU] are computed.
If RANGE = ‘I’, the computed eigenvalues are those in the index range [IL, IU).
UPLO
CHARACTER*1. Must be ‘U’ or ‘L’.
If UPLO = ‘U’, AB stores the upper triangular part of the symmetric matrix.
If UPLO = ‘L’, AB stores the lower triangular part of the symmetric matrix.
N
INTEGER. The order of the matrix AB. N >= 0.
KD
INTEGER. The number of super- or sub-diagonals of the matrix AB. KD >= 0.
AB
DOUBLE PRECISION array, dimension (LDAB, N).
LDAB
INTEGER. The leading dimension of the array AB. LDAB >= KD + 1.
Q
DOUBLE PRECISION array, dimension (LDQ, N).
LDQ
INTEGER. The leading dimension of the array Q. If JOBZ = ‘V’, then LDQ >= max(1, N). Otherwise, LDQ is not used.
VL
DOUBLE PRECISION.
VU
DOUBLE PRECISION.
IL
INTEGER.
IU
INTEGER.
GENCE
CHARACTER*1. Array of dimension max(1,N).
M
INTEGER. The number of eigenvalues found.
NZ
INTEGER. The number of eigenvectors that were computed.
EPS
DOUBLE PRECISION. Workspace array of dimension max(1,N).
WORK
DOUBLE PRECISION array, dimension (LWKDIM).
IWORK
INTEGER array, dimension (NIWORK).
JA
INTEGER array, dimension (max(1,N)).
WKDIM
INTEGER.

Dimension of WORK. LWKDIM >= max(1, 5*N).

NIWORK. Dimension of IWORK. NIWORK >= max(1, 3*N).

INFO
INTEGER.

Function/Subroutine Documentation

The subroutine SSBEVX computes the eigenvalues and optionally the eigenvectors of a real symmetric tridiagonal matrix A. The eigenvalues are computed in one of three modes:

  • all eigenvalues,
  • all eigenvalues in a given range (VL, VU],
  • all eigenvalues in an index range [IL, IU).

The eigenvalues are returned in the non-decreasing order. If an eigenvector computation is requested, then the corresponding eigenvectors are returned in the same order.

The routine must be called with appropriate values for the arguments. For example, if JOBZ = ‘N’, then Q, VL, VU, IL, IU, GENCE, NZ, EPS, JA, and WKDIM are not used.

If RANGE = ‘A’, then VL, VU, IL, and IU are not used.

If RANGE = ‘V’, then IL and IU are not used.

If RANGE = ‘I’, then VL and VU are not used.

The matrix AB is stored in packed form. The lower triangle of AB is stored in the first KD+1 rows of the array AB. The upper triangle of AB is stored in the last KD+1 rows of the array AB.

INFO = 0: successful exit.
INFO < 0: if INFO = -i, then the i-th argument had an illegal value.
INFO > 0: if INFO = i, then the algorithm did not converge; i eigenvectors could not be computed.

!>            Their indices are stored in array IFAIL.
!>
