NOM

ssh_filter_btrbk - script de filtrage de commandes SSH pour btrbk

SYNTAXE

ssh_filter_btrbk.sh [-s|--source] [-t|--target] [-d|--delete]
    [-i|--info] [--snapshot] [--send] [--receive]
    [-p|--restrict-path <chemin>] [-l|--log] [--sudo]

DESCRIPTION

ssh_filter_btrbk.sh restreint les commandes SSH aux commandes utilisées par btrbk. Il examine la variable d'environnement SSH_ORIGINAL_COMMAND (définie par sshd) et ne l'exécute que si elle contient des commandes utilisées par btrbk.

Les commandes acceptées sont spécifiées par les options "--source", "--target", "--delete" et "--info".

Les commandes suivantes sont toujours autorisées :

•"btrfs subvolume show" (non affecté par "--restrict-path")
•"btrfs subvolume list" (non affecté par "--restrict-path")
•"readlink"
•"test -d" (uniquement si l'option de configuration "compat busybox" est définie)
•"cat /proc/self/mountinfo"
•tuyaux via "gzip", "pigz", "bzip2", "pbzip2", "bzip3", "xz", "lzop", "lz4", "zstd" (stream_compress)
•tuyaux via "mbuffer" (stream_buffer, rate_limit)

Exemple de ligne dans /root/.ssh/authorized_keys sur un hôte cible de sauvegarde :

command="ssh_filter_btrbk.sh --target --delete --restrict-path /mnt/btr_backup",restrict ssh-rsa AAAAB3NzaC1...hwumXFRQBL btrbk@example.org

OPTIONS

-s, --source

Autorise les commandes pour la source de sauvegarde : "btrfs subvolume snapshot", "btrfs send". Équivalent à "--snapshot --send".

-t, --target

Autorise les commandes pour la cible de sauvegarde et d'archivage : "btrfs receive", "mkdir".

-d, --delete

Autorise les commandes de suppression de sous-volume : "btrfs subvolume delete". Ceci est utilisé pour la source de sauvegarde si snapshot_preserve_daily n'est pas défini sur “all”, et pour les cibles de sauvegarde si target_preserve_daily n'est pas défini sur “all”.

-i, --info

Autorise les commandes informatives : "btrfs subvolume find-new", "btrfs filesystem usage". Ceci est utilisé par les commandes info et diff de btrbk.

--snapshot

Autorise la commande btrfs snapshot : "btrfs subvolume snapshot".

--send

Autorise la commande btrfs send : "btrfs send".

--receive

Autorise la commande btrfs receive : "btrfs receive".

-p, --restrict-path <chemin>

Restreint les commandes au <chemin>. Notez que "btrfs subvolume show", "btrfs subvolume list" ne sont PAS affectés par cette option.

Il n'est pas possible de restreindre les commandes à des noms de sous-volumes exacts, car btrfs-receive(8) prend un <chemin> comme argument (répertoire, sans inclure le nom du fichier de sous-volume à créer, celui-ci étant encodé dans le flux d'envoi).

-l, --log

Enregistre les messages ACCEPT et REJECT dans le journal système.

--sudo

Autorise l'appel des commandes btrfs via sudo. Activez cette option si vous avez "backend btrfs-progs-sudo" dans votre fichier de configuration btrbk.

DISPONIBILITÉ

Veuillez consulter la page du projet btrbk https://digint.ch/btrbk/ pour plus de détails.
