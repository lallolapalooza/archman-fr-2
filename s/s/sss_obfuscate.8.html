NOM

sss_obfuscate - Obfusquer un mot de passe en clair

SYNTAXE

sss_obfuscate [options] [MOTDEPASSE]

DESCRIPTION

sss_obfuscate convertit un mot de passe donné en un format illisible par l'homme et le place dans la section de domaine appropriée du fichier de configuration SSSD.

Le mot de passe en clair est lu depuis l'entrée standard ou saisi interactivement. Le mot de passe obfusqué est placé dans le paramètre “ldap_default_authtok” d'un domaine SSSD donné et le paramètre “ldap_default_authtok_type” est défini sur “obfuscated_password”. Référez-vous à sssd-ldap(5) pour plus de détails sur ces paramètres.

Veuillez noter que l'obfuscation du mot de passe n'apporte aucun avantage réel en matière de sécurité car il est toujours possible pour un attaquant de retrouver le mot de passe. L'utilisation de mécanismes d'authentification meilleurs tels que les certificats côté client ou GSSAPI est fortement recommandée.

OPTIONS

-h,--help

Affiche le message d'aide et quitte.

-s,--stdin

Le mot de passe à obfusquer sera lu depuis l'entrée standard.

-d,--domain DOMAINE

Le domaine SSSD à utiliser pour le mot de passe. Le nom par défaut est “default”.

-f,--file FICHIER

Lit le fichier de configuration spécifié par le paramètre positionnel.

Par défaut : /etc/sssd/sssd.conf
