Documentation de la fonction/sous-routine

sous-routine ssptri (caractère uplo, entier n, réel, dimension( * ) ap, entier, dimension( * ) ipiv, réel, dimension( * ) work, entier info)

SSPTRI

But :

!>
!> SSPTRI calcule l'inverse d'une matrice symétrique réelle indéfinie
!> A en stockage compact en utilisant la factorisation A = U*D*U**T ou
!> A = L*D*L**T calculée par SSPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme A = U*D*U**T ;
!>          = 'L':  Triangulaire inférieure, forme A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est tableau REEL, dimension (N*(N+1)/2)
!>          À l'entrée, la matrice diagonale par blocs D et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L calculés par SSPTRF,
!>          stockés sous forme de matrice triangulaire compactée.
!>
!>          À la sortie, si INFO = 0, l'inverse (symétrique) de la matrice originale,
!>          stocké sous forme de matrice triangulaire compactée. La j-ième colonne
!>          de inv(A) est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = inv(A)(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L',
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) pour j<=i<=n.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par SSPTRF.
!>

WORK

!>          WORK est tableau REEL, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
