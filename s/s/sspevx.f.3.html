sous programme sspevx (jobz, range, uplo, n, ap, vl, vu, il, iu, abstol, m, w, z, ldz, work, iwork, ifail, info)
SSPEVX calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour d'AUTRES matrices

Documentation de la fonction/sous routine

sous routine sspevx (caractère jobz, caractère range, caractère uplo, entier n, réel, dimension( * ) ap, réel vl, réel vu, entier il, entier iu, réel abstol, entier m, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

SSPEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres d'une matrice symétrique réelle A en stockage groupé. Les valeurs/vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les valeurs propres désirées.

Objectif :

!>
!> SSPEVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice symétrique réelle A en stockage groupé. Les valeurs propres/vecteurs propres
!> peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres souhaitées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront calculées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront calculées ;
!>          = 'I': les valeurs propres de l'indice IL à IU seront calculées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  le triangle supérieur de A est stocké ;
!>          = 'L':  le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau REEL, de dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, groupé par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          À la sortie, AP est écrasé par des valeurs générées lors de la
!>          réduction à une forme tridiagonale. Si UPLO = 'U', la diagonale
!>          et la première superdiagonale de la matrice tridiagonale T écrasent
!>          les éléments correspondants de A, et si UPLO = 'L', la
!>          diagonale et la première sous-diagonale de T écrasent les
!>          éléments correspondants de A.
!>

VL

!>          VL est REEL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REEL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REEL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée comme se trouvant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant AP à une forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec la plus grande précision lorsque ABSTOL est
!>          défini à deux fois le seuil de sous-flux 2*SLAMCH('S'), et non zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REEL, de dimension (N)
!>          Si INFO = 0, les valeurs propres sélectionnées par ordre croissant.
!>

Z

!>          Z est un tableau REEL, de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, de dimension (8*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER, de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro.  Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!>
