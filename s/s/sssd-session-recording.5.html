NOM

sssd-session-recording - Configuration de l'enregistrement de session avec SSSD

DESCRIPTION

Cette page de manuel décrit comment configurer sssd(8) pour fonctionner avec tlog-rec-session(8), une partie du paquet tlog, pour implémenter l'enregistrement de session utilisateur sur les terminaux texte. Pour une référence détaillée de la syntaxe de configuration, consultez la section « FORMAT DE FICHIER » de la page de manuel de sssd.conf(5).

SSSD peut être configuré pour activer l'enregistrement de tout ce que les utilisateurs spécifiques voient ou tapent pendant leurs sessions sur les terminaux texte. Par exemple, lorsque les utilisateurs se connectent sur la console, ou via SSH. SSSD lui-même n'enregistre rien, mais s'assure que tlog-rec-session est démarré lors de la connexion de l'utilisateur, afin qu'il puisse enregistrer conformément à sa configuration.

Pour les utilisateurs pour lesquels l'enregistrement de session est activé, SSSD remplace le shell de l'utilisateur par tlog-rec-session dans les réponses NSS, et ajoute une variable spécifiant le shell d'origine à l'environnement de l'utilisateur, lors de la configuration de la session PAM. De cette façon, tlog-rec-session peut être démarré à la place du shell de l'utilisateur, et savoir quel shell réel démarrer, une fois qu'il a configuré l'enregistrement.

OPTIONS DE CONFIGURATION

Ces options peuvent être utilisées pour configurer l'enregistrement de session.

scope (chaîne)

L'une des chaînes suivantes spécifiant la portée de l'enregistrement de session :

"none"

Aucun utilisateur n'est enregistré.

"some"

Les utilisateurs/groupes spécifiés par les options users et groups sont enregistrés.

"all"

Tous les utilisateurs sont enregistrés.

Par défaut : « none »

users (chaîne)

Une liste d'utilisateurs séparés par des virgules qui devraient avoir l'enregistrement de session activé. Correspond aux noms d'utilisateur tels que retournés par NSS. C'est-à-dire, après le remplacement possible d'espaces, les changements de casse, etc.

Par défaut : Vide. Ne correspond à aucun utilisateur.

groups (chaîne)

Une liste de groupes séparés par des virgules, dont les membres devraient avoir l'enregistrement de session activé. Correspond aux noms de groupe tels que retournés par NSS. C'est-à-dire, après le remplacement possible d'espaces, les changements de casse, etc.

NOTE : l'utilisation de cette option (l'avoir définie sur n'importe quoi) a un coût de performance considérable, car chaque requête non mise en cache pour un utilisateur nécessite la récupération et la comparaison des groupes dont l'utilisateur est membre.

Par défaut : Vide. Ne correspond à aucun groupe.

exclude_users (chaîne)

Une liste d'utilisateurs séparés par des virgules à exclure de l'enregistrement, applicable uniquement avec « scope=all ».

Par défaut : Vide. Aucun utilisateur exclu.

exclude_groups (chaîne)

Une liste de groupes séparés par des virgules, dont les membres devraient être exclus de l'enregistrement. Applicable uniquement avec « scope=all ».

NOTE : l'utilisation de cette option (l'avoir définie sur n'importe quoi) a un coût de performance considérable, car chaque requête non mise en cache pour un utilisateur nécessite la récupération et la comparaison des groupes dont l'utilisateur est membre.

Par défaut : Vide. Aucun groupe exclu.

EXEMPLE

L'extrait suivant de sssd.conf active l'enregistrement de session pour les utilisateurs « contractor1 » et « contractor2 », et le groupe « students ».

[session_recording]
scope = some
users = contractor1, contractor2
groups = students
