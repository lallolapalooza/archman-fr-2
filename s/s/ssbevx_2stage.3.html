sous-routine ssbevx_2stage (caractère jobz, caractère range, caractère uplo, entier n, entier kd, réel, dimension( ldab, * ) ab, entier ldab, réel, dimension( ldq, * ) q, entier ldq, réel vl, réel vu, entier il, entier iu, réel abstol, entier m, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

SSBEVX_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres pour d'AUTRES matrices

Objectif :

!>
!> SSBEVX_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice bande symétrique réelle A en utilisant la technique 2stage pour
!> la réduction en matrice tridiagonale. Les valeurs propres et les vecteurs propres peuvent
!> être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées ;
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I' : les valeurs propres de l'indice IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau RÉEL, dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par les valeurs générées lors de la
!>          réduction en forme tridiagonale. Si UPLO = 'U', la première
!>          super-diagonale et la diagonale de la matrice tridiagonale T
!>          sont retournées dans les lignes KD et KD+1 de AB, et si UPLO = 'L',
!>          la diagonale et la première sous-diagonale de T sont retournées dans les
!>          deux premières lignes de AB.
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension de tête du tableau AB.  LDAB >= KD + 1.
!>

Q

!>          Q est un tableau RÉEL, dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice orthogonale N-par-N utilisée dans la
!!>                         réduction en matrice tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension de tête du tableau Q.  Si JOBZ = 'V', alors
!>          LDQ >= max(1,N).
!>

VL

!>          VL est un RÉEL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est un RÉEL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est un RÉEL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée comme se situant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou égal à zéro,
!>          alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant AB en forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec la plus grande précision lorsque ABSTOL est
!>          défini à deux fois le seuil de sous-dépassement 2*SLAMCH('S'), et non zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>
!>          Voir par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est un ENTIER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau RÉEL, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées dans
!>          ordre croissant.
!>

Z

!>          Z est un tableau RÉEL, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ième
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient l'approximation la plus récente du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension de tête du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau RÉEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK. LWORK >= 1, lorsque N <= 1 ;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, 7*N, dimension) où
!>                                   dimension = (2KD+1)*N + KD*NTHREADS + 2*N
!>                                   où KD est la taille de la bande.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (N)
!>

IFAIL

!>          IFAIL est un tableau ENTIER, dimension (N)
!>          Si JOBZ = 'V', la liste des indices des valeurs propres pour lesquelles
!>          les vecteurs propres n'ont pas convergé. Les vecteurs propres correspondants
!>          sont retournés dans les colonnes correspondantes de Z.
!>          Non référencé si JOBZ = 'N' ou si tous les vecteurs propres convergent.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : succès ;
!>          > 0 : un problème est survenu lors de la convergence des valeurs propres ;
!>               le nombre de valeurs propres qui n'ont pas convergé est INFO.
!>               Si JOBZ = 'V', les colonnes IFAIL(1), ..., IFAIL(INFO) de Z contiennent
!>               des approximations de vecteurs propres non convergés.
!>          < 0 : le i-ième argument vers l'appel était d'erreur, i.e. l'abs(I) -
!>               th argument.
!>
NTHREADS est le nombre de threads utilisés lorsque !> la compilation openMP est activée, sinon =1. !> Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Non encore disponible !> !> Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine !> calcule seulement la taille optimale du tableau WORK, renvoie !> cette valeur comme première entrée du tableau WORK, et aucun message d'erreur !> relatif à LWORK n'est émis par XERBLA. !>

IWORK

!>          IWORK est un tableau d'entiers, de dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau d'entiers, de dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!>
