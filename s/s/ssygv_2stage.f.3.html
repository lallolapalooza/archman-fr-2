Documentation de la fonction/sous-programme

sous-routine ssygv_2stage (entier itype, caractere jobz, caractere uplo, entier n, reelle, dimension( lda, * ) a, entier lda, reelle, dimension( ldb, * ) b, entier ldb, reelle, dimension( * ) w, reelle, dimension( * ) work, entier lwork, entier info)

SSYGV_2STAGE

But :

!>
!> SSYGV_2STAGE calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème propre généralisé symétrique-défini réel, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x.
!> Ici A et B sont supposées symétriques et B est aussi
!> définie positive.
!> Cette routine utilise la technique 2stage pour la réduction à la forme tridiagonale,
!> qui a montré des performances supérieures sur les architectures récentes et pour de grandes
!> tailles N>2000.
!>

Paramètres

ITYPE 
!>          ITYPE est un ENTIER
!>          Spécifie le type de problème à résoudre :
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est un CARACTERE*1
!>          = 'N':  Calcul des valeurs propres uniquement ;
!>          = 'V':  Calcul des valeurs propres et des vecteurs propres.
!>                  Non disponible dans cette version.
!>

UPLO

!>          UPLO est un CARACTERE*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est un ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA, N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U',
!>          la partie triangulaire supérieure de A de taille N x N contient
!>          la partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure de A de taille N x N contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          À la sortie, si JOBZ = 'V', alors si INFO = 0, A contient la
!>          matrice Z des vecteurs propres. Les vecteurs propres sont normalisés
!>          comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors à la sortie, le triangle supérieur (si UPLO='U')
!>          ou le triangle inférieur (si UPLO='L') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau REEL, dimension (LDB, N)
!>          À l'entrée, la matrice symétrique définie positive B.
!>          Si UPLO = 'U', la partie triangulaire supérieure de B de taille N x N contient
!>          la partie triangulaire supérieure de la matrice B.
!>          Si UPLO = 'L', la partie triangulaire inférieure de B de taille N x N contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          À la sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**T*U ou B = L*L**T.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

W

!>          W est un tableau REEL, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la LWORK optimale.
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK. LWORK >= 1, quand N <= 1 ;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, dimension) où
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 2*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N
!>                                   où KD est la taille de bloc de la réduction,
!>                                   FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ
!>                                   , généralement FACTOPTNB=128 est un bon choix
!>                                   NTHREADS est le nombre de threads utilisés quand
!>                                   la compilation openMP est activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  SPOTRF ou SSYEV ont renvoyé un code d'erreur :
!>             <= N:  si INFO = i, SSYEV n'a pas convergé ;
!>                    i éléments hors diagonale d'une forme
!>                    tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>             > N:   si INFO = N + i, pour 1 <= i <= N, alors le mineur
!>                    principal de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
