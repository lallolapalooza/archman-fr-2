sous-routine sscal (integer n, real sa, real, dimension(*) sx, integer incx)

SSCAL

Objectif :

!>
!>    SSCAL met à l'échelle un vecteur par une constante.
!>    utilise des boucles déroulées pour un incrément égal à 1.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

SA

!>          SA est un réel (REAL)
!>           À l'entrée, SA spécifie le scalaire alpha.
!>

SX

!>          SX est un tableau de réels (REAL), de dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un entier (INTEGER)
!>         espacement de stockage entre les éléments de SX
!>
