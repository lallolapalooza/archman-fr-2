NOM

sssd-ifp - Répondeur InfoPipe de SSSD

DESCRIPTION

Cette page de manuel décrit la configuration du répondeur InfoPipe pour sssd(8). Pour une référence syntaxique détaillée, consultez la section « FORMAT DE FICHIER » de la page de manuel sssd.conf(5).

Le répondeur InfoPipe fournit une interface publique D-Bus accessible sur le bus système. L'interface permet à l'utilisateur d'interroger des informations sur les utilisateurs et groupes distants via le bus système.

TROUVER PAR CERTIFICAT VALIDE

Les options suivantes peuvent être utilisées pour contrôler la façon dont les certificats sont validés lors de l'utilisation de l'API FindByValidCertificate() :

•ca_db
•p11_child_timeout
•certificate_verification

Pour plus de détails sur les options, voir sssd.conf(5).

OPTIONS DE CONFIGURATION

Ces options peuvent être utilisées pour configurer le répondeur InfoPipe.

allowed_uids (chaîne de caractères)

Spécifie la liste séparée par des virgules des valeurs d'UID ou des noms d'utilisateur autorisés à accéder au répondeur InfoPipe. Les noms d'utilisateur sont résolus en UID au démarrage.

Par défaut : 0 (seul l'utilisateur root est autorisé à accéder au répondeur InfoPipe)

Veuillez noter que bien que l'UID 0 soit utilisé par défaut, il sera écrasé par cette option. Si vous souhaitez toujours autoriser l'accès de l'utilisateur root au répondeur InfoPipe, ce qui serait le cas typique, vous devez également ajouter 0 à la liste des UID autorisés.

user_attributes (chaîne de caractères)

Spécifie la liste séparée par des virgules d'attributs autorisés (liste blanche) ou interdits (liste noire).

Par défaut, le répondeur InfoPipe n'autorise que l'ensemble par défaut d'attributs POSIX à être demandé. Cet ensemble est le même que celui renvoyé par getpwnam(3) et comprend :

name

nom de connexion de l'utilisateur

uidNumber

identifiant utilisateur (UID)

gidNumber

identifiant du groupe principal (GID)

gecos

informations sur l'utilisateur, généralement le nom complet

homeDirectory

répertoire personnel

loginShell

shell de connexion de l'utilisateur

Il est possible d'ajouter un autre attribut à cet ensemble en utilisant « +nom_attr » ou de supprimer explicitement un attribut en utilisant « -nom_attr ». Par exemple, pour autoriser « telephoneNumber » mais interdire « loginShell », vous utiliseriez la configuration suivante :

user_attributes = +telephoneNumber, -loginShell

Par défaut : non défini. Seul l'ensemble par défaut d'attributs POSIX est autorisé.

wildcard_limit (entier)

Spécifie une limite supérieure sur le nombre d'entrées téléchargées lors d'une recherche par joker qui remplace la limite fournie par l'appelant.

Par défaut : 0 (laisser l'appelant définir une limite supérieure)
