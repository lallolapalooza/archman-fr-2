subroutine ssyev (jobz, uplo, n, a, lda, w, work, lwork, info)
SSYEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauche et/ou droite pour les matrices SY

Documentation de la fonction/sous-routine

sous-routine ssyev (caractère jobz, caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) w, réel, dimension( * ) work, entier lwork, entier info)

SSYEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une matrice symétrique réelle A.

Objectif:

!>
!> SSYEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice symétrique réelle A.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA, N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N principale de A contient
!>          la partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N principale de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient les
!>          vecteurs propres orthonormés de la matrice A.
!>          Si JOBZ = 'N', alors en sortie le triangle inférieur (si UPLO='L')
!>          ou le triangle supérieur (si UPLO='U') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

W

!>          W est un tableau REEL, de dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.  LWORK >= max(1,3*N-1).
!>          Pour une efficacité optimale, LWORK >= (NB+2)*N,
!>          où NB est la taille de bloc pour SSYTRD renvoyée par ILAENV.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>
