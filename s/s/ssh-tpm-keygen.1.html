SSH-TPM-KEYGEN(1) Manuel de ssh-tpm-keygen SSH-TPM-KEYGEN(1)

NOM

ssh-tpm-keygen - Utilitaire de création de clés ssh-tpm-agent

SYNTAXE

ssh-tpm-keygen [OPTIONS]...

ssh-tpm-keygen --wrap CHEMIN --wrap-with CHEMIN

ssh-tpm-keygen --import CHEMIN

ssh-tpm-keygen --print-pubkey CHEMIN

ssh-tpm-keygen --supported

ssh-tpm-keygen -p [-f fichier_clé] [-P ancienne phrase secrète] [-N nouvelle phrase secrète]

ssh-tpm-keygen -A [-f préfixe du chemin] [--hierarchy hiérarchie]

DESCRIPTION

ssh-tpm-keygen est un programme qui permet la création de clés enveloppées par TPM pour ssh-tpm-agent.

OPTIONS

-A

Générer des clés d'hôte pour tous les types de clés (rsa et ecdsa).

-b BITS

Nombre de bits dans la clé à créer.
•rsa: 2048 (par défaut)
•ecdsa: 256 (par défaut) | 384 | 521

-C COMMENTAIRE

Fournir un commentaire avec la clé.

-f CHEMIN

Chemin du fichier de sortie de la clé.

-N PHRASE_SECRETE

Phrase secrète pour la clé.

-o, --owner-password PHRASE_SECRETE

Demander le mot de passe du propriétaire.

-t [ecdsa | rsa]

Spécifier le type de clé à créer. Par défaut, ecdsa

-I, --import CHEMIN

Importer une clé existante dans ssh-tpm-agent.

--parent-handle HIERARCHIE

Parent pour la clé TPM. Peut être une hiérarchie ou un descripteur persistant.

Hiérarchies disponibles : - owner, o (par défaut) - endorsement, e - null, n - platform, p

--print-pubkey CHEMIN

Afficher la clé publique étant donné une clé privée TPM.

--supported

Lister les types de clés pris en charge par le TPM.

--hierarchy HIERARCHIE

Créer une clé publique. Ne peut être utilisé qu'avec -A.

Voir Clés de hiérarchie dans ssh-tpm-agent(1) pour l'utilisation.

Hiérarchies disponibles :

•owner, o
•endorsement, e
•null, n
•platform, p

--wrap CHEMIN

Une clé SSH à envelopper pour l'importation sur la machine distante.

--wrap-with CHEMIN

Clé parente pour envelopper la clé SSH.

EXEMPLES

Création de clé

Créer une clé avec ssh-tpm-keygen.

$ ssh-tpm-keygen

Enter passphrase (empty for no passphrase):
Enter same passphrase again:
Your identification has been saved in /home/user/.ssh/id_ecdsa.tpm
Your public key has been saved in /home/user/.ssh/id_ecdsa.pub
The key fingerprint is:
SHA256:NCMJJ2La+q5tGcngQUQvEOJP3gPH8bMP98wJOEMV564
The key's randomart image is the color of television, tuned to a dead channel.
$ cat /home/user/.ssh/id_ecdsa.pub

Importation de clé existante

Utile si vous souhaitez sauvegarder la clé dans un stockage distant sécurisé tout en utilisant la clé au quotidien à partir du TPM.

Créez une clé, ou utilisez une clé existante.

$ ssh-keygen -t ecdsa -f id_ecdsa
Generating public/private ecdsa key pair.
Enter passphrase (empty for no passphrase):
Enter same passphrase again:
Your identification has been saved in id_ecdsa
Your public key has been saved in id_ecdsa.pub
The key fingerprint is:
SHA256:bDn2EpX6XRX5ADXQSuTq+uUyia/eV3Z6MW+UtxjnXvU user@localhost
The key's randomart image is:
+---[ECDSA 256]---+
|           .+=o..|
|           o. oo.|
|          o... .o|
|       . + ..  ..|
|        S .   . o|
|       o * . oo=*|
|        ..+.oo=+E|
|        .++o...o=|
|       .++++. .+ |
+----[SHA256]-----+

Importez la clé en utilisant le commutateur --import.

$ ssh-tpm-keygen --import id_ecdsa
Sealing an existing public/private ecdsa key pair.
Enter passphrase (empty for no passphrase):
Enter same passphrase again:
Your identification has been saved in id_ecdsa.tpm
The key fingerprint is:
SHA256:bDn2EpX6XRX5ADXQSuTq+uUyia/eV3Z6MW+UtxjnXvU
The key's randomart image is the color of television, tuned to a dead channel.

Créer et envelopper une clé privée pour la machine client sur le serveur distant

Du côté client, créez une clé primaire sous une hiérarchie. Cet exemple utilisera la hiérarchie propriétaire avec une SRK.

Le fichier de sortie srk.pem doit être transféré à l'extrémité distante qui crée la clé. Cela pourrait être fait dans le cadre de la mise en service du client.

$ tpm2_createprimary -C o -G ecc -g sha256 -c prim.ctx -a 'restricted|decrypt|fixedtpm|fixedparent|sensitivedataorigin|userwithauth|noda' -f pem -o srk.pem

À l'extrémité distante, nous créons une clé ssh p256, sans mot de passe, et nous l'enveloppons avec ssh-tpm-keygen avec le srk.pem du côté client.

$ ssh-keygen -t ecdsa -b 256 -N "" -f ./ecdsa.key

OU avec openssl

$ openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:prime256v1 -out ecdsa.key

Envelopper avec ssh-tpm-keygen

$ ssh-tpm-keygen --wrap-with srk.pub --wrap ecdsa.key -f wrapped_id_ecdsa

Du côté client, nous pouvons déballer wrapped_id_ecdsa pour obtenir une clé chargeable.

$ ssh-tpm-keygen --import ./wrapped_id_ecdsa.tpm --output id_ecdsa.tpm
$ ssh-tpm-add id_ecdsa.tpm

FICHIERS

~/ssh/id_rsa.tpm, ~/ssh/id_ecdsa.tpm

Contient les clés privées ssh utilisées par ssh-tpm-agent. Ce sont des fichiers de clés TPM 2.0 TSS et sont enveloppés de manière sécurisée par le TPM. Ils peuvent être partagés publiquement car ils ne peuvent être utilisés que par le TPM sur lequel ils ont été créés. Cependant, il est probablement préférable de ne pas le faire.

~/ssh/id_rsa.pub, ~/ssh/id_ecdsa.pub

Contient les clés publiques ssh. Celles-ci peuvent être partagées publiquement et sont dans le même format que celles créées par ssh-keygen(1).
