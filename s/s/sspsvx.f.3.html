sous-routine sspsvx (caractere fact, caractere uplo, entier n, entier nrhs, reel, dimension( * ) ap, reel, dimension( * ) afp, entier, dimension( * ) ipiv, reel, dimension( ldb, * ) b, entier ldb, reel, dimension( ldx, * ) x, entier ldx, reel rcond, reel, dimension( * ) ferr, reel, dimension( * ) berr, reel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SSPSVX calcule la solution d'un système d'équations linéaires A * X = B pour les matrices OTHER

Objectif :

!>
!> SSPSVX utilise la factorisation par pivot de diagonale A = U*D*U**T ou
!> A = L*D*L**T pour calculer la solution d'un système d'équations linéaires
!> réelles A * X = B, où A est une matrice symétrique N x N stockée
!> au format compacté et X et B sont des matrices N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la méthode de pivot de diagonale est utilisée pour factoriser A en
!>       A = U * D * U**T,  si UPLO = 'U', ou
!>       A = L * D * L**T,  si UPLO = 'L',
!>    où U (ou L) est un produit de matrices de permutation et triangulaires
!>    supérieures (inférieures) unitaires et D est une matrice diagonale
!>    par blocs symétrique avec des blocs diagonaux de taille 1x1 et 2x2.
!>
!> 2. Si certains D(i,i)=0, de sorte que D est exactement singulière, la routine
!>    retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée
!>    pour estimer le nombre de condition de la matrice A. Si la
!>    réciproque du nombre de condition est inférieure à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. L'affinage itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie ou non à l'entrée.
!>          = 'F' : À l'entrée, AFP et IPIV contiennent la forme factorisée de
!>                  A. AP, AFP et IPIV ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFP et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AP

!>          AP est un tableau REEL, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice symétrique A, compacté
!>          par colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>

AFP

!>          AFP est un tableau REEL, dimension (N*(N+1)/2)
!>          Si FACT = 'F', alors AFP est un argument d'entrée et contient à l'entrée
!>          la matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T, tels que calculés par SSPTRF, stockés sous
!>          forme de matrice triangulaire compactée dans le même format de stockage que A.
!>
!>          Si FACT = 'N', alors AFP est un argument de sortie et contient à la sortie
!>          la matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T, tels que calculés par SSPTRF, stockés sous
!>          forme de matrice triangulaire compactée dans le même format de stockage que A.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient à l'entrée
!>          les détails des échanges et la structure de blocs
!>          de D, tels que déterminés par SSPTRF.
!>          Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>          échangées et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes et
!>          colonnes k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k)
!>          est un bloc diagonal 2x2. Si UPLO = 'L' et IPIV(k) =
!>          IPIV(k+1) < 0, alors les lignes et colonnes k+1 et -IPIV(k) ont été
!>          échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient à la sortie
!>          les détails des échanges et la structure de blocs
!>          de D, tels que déterminés par SSPTRF.
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          La matrice B du membre de droite N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REEL, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X N x NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REEL
!>          L'estimation du nombre de condition réciproque de la matrice
!>          A. Si RCOND est inférieur à la précision de la machine (en
!>          particulier, si RCOND = 0), la matrice est singulière à la
!>          précision de travail. Cette condition est indiquée par un code de retour
!>          de INFO > 0.
!>

FERR

!>          FERR est un tableau REEL, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisé par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau REEL, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau REEL, dimension (3*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, et i est
!>                <= N :  D(i,i) est exactement zéro. La factorisation
!>                       a été complétée mais le facteur D est exactement
!>                       singulier, donc la solution et l'erreur b

sspsvx.f(3)

NAME

sspsvx - sSPSVX computes the solution to a symmetric linear system of equations Ax = B, where A is a real symmetric, packed matrix, and x and B are real vectors. Various condition estimates are also provided, and the factored matrix is returned.

SYNOPSIS

 SUBROUTINE SSPSVX( FACT, UPLO, N, NRHS, AP, AFP, LDFP, IPIV, B, LDB, X,
 LDX, RCOND, FERR, BERR, WORK, INFO )

 INTEGER NRHS, LDFP, LDB, LDX, INFO
 REAL AP( * ), AFP( * ), WORK( * )
 CHARACTER UPLO, FACT
 INTEGER IPIV( * )
 REAL B( * ), X( * ), RCOND, FERR( * ), BERR( * )

Function/Subroutine Documentation

SSPSVX SRISKS THE SOLUTION TO A REAL SYMMETRIC AND POSITIVE DEFINITE SYSTEM OF LINEAR EQUATIONS,

       A * X = B

USING THE LEFT LOWER TRIANGULAR FACTORED FORM OF A.

Here A is an N x N symmetric, positive definite matrix, UPLO = 'L', or 'U' respectively if A is stored in lower or upper triangular packed form; B is an N x NRHS matrix; X is the N x NRHS solution matrix; and AP is an array, dimension at least N*(N+1)/2, which contains the packed triangular factored form of A. Various condition estimates are also provided.

Before entry if FACT = 'N', then the above matrix A must contain the symmetric, positive definite matrix, and if UPLO = 'L', the packed data must be the lower triangle of A, and if UPLO = 'U', the packed data must be the upper triangle of A. If FACT = 'F', then the factored form of A must have been computed and stored in AFP. Only the diagonal and upper triangle of AFP need to be a valid factorization (e.g., computed by SSPSRF).

Return values

!>  INFO:
!>       = 0:  Successful exit. The solution to the system of equations has
!>              been computed. RCOND >= machine epsilon.
!>
!>       > 0:  If INFO = K and K > 0, the diagonal element K of the
!>              triangular factor of A is zero, and thus the factored
!>              matrix is singular. The solution and error bounds are
!>              undetermined. RCOND = 0 is returned.
!>
!>       < 0:  If INFO = -K, the K-th argument had an illegal value.
!>

Further Details:

!>
!>  The value of the condition number is returned in RCOND. RCOND is an
!>  estimate of the reciprocal of the condition number of the matrix A.
!>  The estimate is computed after the L/U factorization of A, and is the
!>  reciprocal of the ratio between the smallest and the largest positive
!>  diagonal elements of A, with respect to the norm determined by the
!>  routine.
!>
!>  If RCOND is small, then the matrix A is close to singular and will
!>  nearly fail to satisfy the current problem. The solution X is computed
!>  nevertheless, but you should try to avoid this situation, or choose
!>  a different precision.
!>
!>  RCOND = 0 is returned if the

  • >                       ne peuvent pas être calculés. RCOND = 0 est retourné.
!>                = N+1 : D est non singulier, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est
!>                       singulière à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car il
!>                       existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
