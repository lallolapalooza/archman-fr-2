SSYEVR calcule les valeurs propres et, optionnellement, les vecteurs propres pour les matrices SY

Objectif :

!>
!> SSYEVR calcule les valeurs propres sélectionnées et, optionnellement, les vecteurs propres
!> d'une matrice symétrique réelle A. Les valeurs propres et les vecteurs propres peuvent être
!> sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres désirées. Des invocations avec des choix différents pour
!> ces paramètres peuvent entraîner le calcul de valeurs propres et/ou de vecteurs propres légèrement différents
!> pour la même matrice. La raison de ce comportement est qu'il existe une variété d'algorithmes (chacun
!> fonctionnant au mieux pour un ensemble particulier d'options) et que SSYEVR
!> tente de sélectionner le meilleur en fonction des différents paramètres. Dans tous les cas,
!> les valeurs calculées sont précises dans les limites de l'arithmétique à précision finie.
!>
!> SSYEVR réduit d'abord la matrice A à la forme tridiagonale T avec un appel
!> à SSYTRD. Ensuite, lorsque c'est possible, SSYEVR appelle SSTEMR pour calculer
!> le spectre propre en utilisant des Représentations Relativement Robustes.
!> SSTEMR calcule les valeurs propres par l'algorithme dqds, tandis que les vecteurs propres orthogonaux
!> sont calculés à partir de diverses représentations L D L^T
!> (également connues sous le nom de Représentations Relativement Robustes). L'orthogonalisation de Gram-Schmidt
!> est évitée autant que possible. Plus spécifiquement,
!> les différentes étapes de l'algorithme sont les suivantes.
!>
!> Pour chaque bloc non réduit (sous-matrice) de T,
!>    (a) Calculer T - sigma I = L D L^T, de sorte que L et D
!>        définissent toutes les valeurs propres recherchées avec une haute précision relative.
!>        Cela signifie que de petits changements relatifs dans les entrées de D et L
!>        entraînent seulement de petits changements relatifs dans les valeurs propres et
!>        les vecteurs propres. La représentation standard (non factorisée) de la
!>        matrice tridiagonale T n'a généralement pas cette propriété.
!>    (b) Calculer les valeurs propres avec une précision appropriée.
!>        Si les vecteurs propres sont désirés, l'algorithme atteint la pleine
!>        précision des valeurs propres calculées juste avant
!>        que les vecteurs correspondants ne doivent être calculés, voir les étapes c) et d).
!>    (c) Pour chaque cluster de valeurs propres proches, sélectionner un nouveau
!>        décalage proche du cluster, trouver une nouvelle factorisation, et raffiner
!>        les valeurs propres décalées avec une précision appropriée.
!>    (d) Pour chaque valeur propre avec une séparation relative suffisamment grande, calculer
!>        le vecteur propre correspondant en formant une factorisation torsadée révélatrice de rang. Revenir à (c) pour tous les clusters restants.
!>
!> La précision souhaitée des sorties peut être spécifiée par le paramètre d'entrée
!> ABSTOL.
!>
!> Pour plus de détails, voir la documentation de SSTEMR et :
!> - Inderjit S. Dhillon et Beresford N. Parlett : 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, août 2004.
!> - Inderjit Dhillon et Beresford Parlett :  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  Également LAPACK Working Note 154.
!> - Inderjit Dhillon : ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mai 1997.
!>
!>
!> Note 1 : SSYEVR appelle SSTEMR lorsque le spectre complet est demandé
!> sur les machines conformes à la norme de virgule flottante ieee-754.
!> SSYEVR appelle SSTEBZ et SSTEIN sur les machines non-ieee et
!> lorsque des requêtes de spectre partiel sont faites.
!>
!> L'exécution normale de SSTEMR peut créer des NaNs et des infinis et
!> peut donc être interrompue en raison d'une exception de virgule flottante dans les environnements
!> qui ne gèrent pas les NaNs et les infinis selon la manière par défaut de la norme ieee.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>
!>          Ce paramètre influence le choix de l'algorithme et
!>          peut modifier les valeurs calculées.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs propres de rang IL à IU seront trouvées.
!>          Pour RANGE = 'V' ou 'I' et IU - IL < N - 1, SSTEBZ et
!>          SSTEIN sont appelés.
!>
!>          Ce paramètre influence le choix de l'algorithme et
!>          peut modifier les valeurs calculées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA, N)
!>          En entrée, la matrice symétrique A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N de A contient la
!>          partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N par N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision de la machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si une haute précision relative est importante, réglez ABSTOL sur
!>

NAME

ssyevr - Computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

SUBROUTINE SSYEVR(
   JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL,
   M, W, Z, LDZ, ISUPPZ, WORK, LWORK, IWORK, LIWORK, INFO )

CHARACTER(1) JOBZ
CHARACTER(1) RANGE
CHARACTER(1) UPLO
INTEGER N
REAL A( LDA, * )
INTEGER LDA
REAL VL, VU
INTEGER IL, IU
REAL ABSTOL
INTEGER M
REAL W( * )
REAL Z( LDZ, * )
INTEGER LDZ
INTEGER ISUPPZ( * )
REAL WORK( * )
INTEGER LWORK
INTEGER IWORK( * )
INTEGER LIWORK
INTEGER INFO

Function/Subroutine Documentation

This subroutine computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix. It is a simplified interface to the LAPACK routines SSYEVR (for dense matrices) and SSTEVD (for tridiagonal matrices).

The routine computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix A.

Arguments:

JOBZ

!> JOBZ is CHARACTER*1
!>   = 'N':  Compute only the eigenvalues of A.
!>   = 'V':  Compute the eigenvalues and eigenvectors of A.

RANGE

!> RANGE is CHARACTER*1
!>   = 'A': all eigenvalues will be found.
!>   = 'V': all eigenvalues in the interval (VL,VU] will be found.
!>   = 'I': all eigenvalues in the open interval (IL, IU] will be found.

UPLO

!> UPLO is CHARACTER*1
!>   = 'U':  Upper triangle of A is stored.
!>   = 'L':  Lower triangle of A is stored.

N

!> N is INTEGER
!>   The order of the matrix A.  N >= 0.

A

!> A is REAL array, dimension (LDA, N)
!>   On entry, the N-by-N symmetric tridiagonal matrix A.
!>   The lower or upper triangle of A may be stored.

LDA

!> LDA is INTEGER
!>   The leading dimension of the array A. LDA >= max(1,N).

VL

!> VL is REAL
!>   If RANGE = 'V', the lower bound of the interval to be selected.
!>   If RANGE = 'A' or 'I', VL is not used.

VU

!> VU is REAL
!>   If RANGE = 'V', the upper bound of the interval to be selected.
!>   If RANGE = 'A' or 'I', VU is not used.

IL

!> IL is INTEGER
!>   If RANGE = 'I', the index of the first eigenvalue to be found.
!>   If RANGE = 'A' or 'V', IL is not used.

IU

!> IU is INTEGER
!>   If RANGE = 'I', the index of the last eigenvalue to be found.
!>   If RANGE = 'A' or 'V', IU is not used.

ABSTOL

!> ABSTOL is REAL
!>   The absolute tolerance for determining the selected eigenvalues.
!>   For example, if ABSTOL is positive, then eigenvalues w(i) satisfying
!>   VL < w(i) <= VU or IL < i <= IU are selected if they are greater than
!>   ABSTOL.
!>   If ABSTOL is negative, the tolerance is set to SLAMCH('Safe minimum').
!>   Doing so will guarantee that eigenvalues are computed to high relative
!>   accuracy when possible in future releases. The current code does not
!>   make any guarantees about high relative accuracy, but future releases
!>   will. See J. Barlow and J. Demmel, , LAPACK Working Note #7, for a
!>   discussion of which matrices define their eigenvalues to high relative
!>   accuracy.

M

!> M is INTEGER
!>   The total number of eigenvalues found. 0 <= M <= N.
!>   If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.

W

!> W is REAL array, dimension (N)
!>   The first M elements contain the selected eigenvalues in
!>   ascending order.

Z

!> Z is REAL array, dimension (LDZ, max(1,M))
!>   If JOBZ = 'V', then if INFO = 0, the first M columns of Z
!>   contain the orthonormal eigenvectors of the matrix A
!>   corresponding to the selected eigenvalues, with the i-th
!>   column of Z holding the eigenvector associated with W(i).
!>   If JOBZ = 'N', then Z is not referenced.
!>   Note: the user must ensure that at least max(1,M) columns are
!>   supplied in the array Z; if RANGE = 'V', the exact value of M
!>   is not known in advance and an upper bound must be used.
!>   Supplying N columns is always safe.

LDZ

!> LDZ is INTEGER
!>   The leading dimension of the array Z. LDZ >= 1, and if
!>   JOBZ = 'V', LDZ >= max(1,N).

ISUPPZ

!> ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>   The support of the eigenvectors in Z, i.e., the indices
!>   indicating the nonzero elements in Z. The i-th eigenvector
!>   is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>   ISUPPZ( 2*i ). This is an output of SSTEMR (tridiagonal
!>   matrix). The support of the eigenvectors of A is typically
!>   1:N because of the orthogonal transformations applied by SORMTR.
!>   Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1

WORK

!> WORK is REAL array, dimension (MAX(1,LWORK))
!>   On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

!> LWORK is INTEGER
!>   The dimension of the array WORK.
!>   If N <= 1, LWORK >= 1, else LWORK >= 26*N.
!>   For optimal efficiency, LWORK >= (NB+6)*N,
!>   where NB is the max of the blocksize for SSYTRD and SORMTR
!>   returned by ILAENV.
!>
!>   If LWORK = -1, then a workspace query is assumed; the routine
!>   only calculates the optimal sizes of the WORK and IWORK
!>   arrays, returns these values as the first entries of the WORK
!>   and IWORK arrays, and no error message related to LWORK or
!>   LIWORK is issued by XERBLA.

IWORK

!> IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>   On exit, if INFO = 0, IWORK(1) returns the optimal LWORK.

LIWORK

!> LIWORK is INTEGER
!>   The dimension of the array IWORK.
!>   If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.
!>
!>   If LIWORK = -1, then a workspace query is assumed; the
!>   routine only calculates the optimal sizes of the WORK and
!>   IWORK arrays, returns these values as the first entries of
!>   the WORK and IWORK arrays, and no error message related to
!>   LWORK or LIWORK is issued by XERBLA.

INFO

!> INFO is INTEGER
!>   = 0:  successful exit
!>   < 0:  if INFO = -i, the i-th argument had an illegal value
!>   > 0:  Internal error
