NOM

sss_ssh_knownhosts - obtenir les clés publiques OpenSSH des hôtes connus

SYNTAXE

sss_ssh_knownhosts [options] HOTE

DESCRIPTION

sss_ssh_knownhosts acquiert les clés publiques SSH pour l'hôte HOTE et les affiche au format de clé known_hosts d'OpenSSH (voir la section « FORMAT DE FICHIER SSH_KNOWN_HOSTS » de sshd(8) pour plus d'informations).

ssh(1) peut être configuré pour utiliser sss_ssh_knownhosts pour l'authentification par clé publique de l'hôte en utilisant l'option « KnownHostsCommand » :

                KnownHostsCommand /usr/bin/sss_ssh_knownhosts %H

Veuillez vous référer à la page de manuel ssh_config(5) pour plus de détails sur cette option.

Cet outil nécessite que le service ssh de SSSD soit activé pour fonctionner correctement.

OPTIONS

-d,--domain DOMAINE

Recherche les clés publiques de l'hôte dans le domaine SSSD DOMAINE.

-o,--only-host-name

Lorsque les clés récupérées du backend n'incluent pas le nom d'hôte, cet outil ajoutera le nom d'hôte non modifié tel que fourni par l'appelant. Si cette option est activée, seul le nom d'hôte (sans le numéro de port) sera ajouté aux clés.

-?,--help

Affiche le message d'aide et quitte.

RECUPERATION DES CLES

Les lignes de clés récupérées du backend sont censées respecter le format de clé tel que décrit dans la section « FORMAT DE FICHIER SSH_KNOWN_HOSTS » de sshd(8). Cependant, il est toléré de retourner uniquement le type de clé et la clé elle-même, auquel cas, le nom d'hôte reçu en paramètre sera ajouté avant le type de clé pour produire une ligne correctement formatée. Le nom d'hôte sera ajouté tel quel ou simplement le nom d'hôte (sans le numéro de port), selon que l'option -o,--only-host-name ait été fournie ou non.

Lorsque le serveur SSH écoute sur un port non standard, le backend DOIT fournir le nom d'hôte incluant le numéro de port dans le format et la position corrects en tant que partie de la ligne de clé. Par exemple, la ligne de clé minimale serait :

                [nom.hote.canonique]:2222 <type_de_cle> <cle-encodee-en-base64>

ETAT DE SORTIE

En cas d'exécution réussie, même si aucune clé n'a été trouvée pour cet hôte ou si le répondeur ssh n'a pas pu être contacté, 0 est retourné. 1 est retourné en cas de toute autre erreur.
