sous-programme ssytrs_aa_2stage (caractère uplo, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) tb, entier ltb, entier, dimension( * ) ipiv, entier, dimension( * ) ipiv2, réel, dimension( ldb, * ) b, entier ldb, entier info)

SSYTRS_AA_2STAGE

But:

!>
!> SSYTRS_AA_2STAGE résout un système d'équations linéaires A*X = B avec une matrice
!> symétrique réelle A en utilisant la factorisation A = U**T*T*U ou
!> A = L*T*L**T calculée par SSYTRF_AA_2STAGE.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme A = U**T*T*U;
!>          = 'L':  Triangulaire inférieure, forme A = L*T*L**T.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          Détails des facteurs calculés par SSYTRF_AA_2STAGE.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

TB

!>          TB est un tableau REEL, dimension (LTB)
!>          Détails des facteurs calculés par SSYTRF_AA_2STAGE.
!>

LTB

!>          LTB est INTEGER
!>          La taille du tableau TB. LTB >= 4*N.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges calculés par
!>          SSYTRF_AA_2STAGE.
!>

IPIV2

!>          IPIV2 est un tableau INTEGER, dimension (N)
!>          Détails des échanges calculés par
!>          SSYTRF_AA_2STAGE.
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          En entrée, la matrice des membres de droite B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
