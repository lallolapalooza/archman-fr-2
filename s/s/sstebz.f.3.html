SSTEBZ

But :

!>
!> SSTEBZ calcule les valeurs propres d'une matrice tridiagonale symétrique
!> T. L'utilisateur peut demander toutes les valeurs propres, toutes les valeurs propres
!> dans l'intervalle semi-ouvert (VL, VU], ou les valeurs propres IL-ième à IU-ième.
!>
!> Pour éviter le dépassement de capacité, la matrice doit être mise à l'échelle de manière à ce que son
!> plus grand élément n'excède pas overflow**(1/2) * underflow**(1/4) en valeur absolue, et pour une précision maximale,
!> elle ne doit pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan, Rapport CS41, Département d'Informatique, Université de Stanford,
!> 21 juillet 1966.
!>

Paramètres

RANGE 
!>          RANGE est CHARACTER*1
!>          = 'A': ()   toutes les valeurs propres seront calculées.
!>          = 'V': () toutes les valeurs propres dans l'intervalle semi-ouvert
!>                           (VL, VU] seront calculées.
!>          = 'I': () les valeurs propres de l'indice IL à IU (de la
!>                           matrice entière) seront calculées.
!>

ORDER

!>          ORDER est CHARACTER*1
!>          = 'B': () les valeurs propres seront regroupées par
!>                              bloc de séparation (voir IBLOCK, ISPLIT) et
!>                              ordonnées de la plus petite à la plus grande au sein du
!>                              bloc.
!>          = 'E': ()
!>                              les valeurs propres de la matrice entière
!>                              seront ordonnées de la plus petite à la plus grande.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice tridiagonale T.  N >= 0.
!>

VL

!>          VL est REAL
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. Les valeurs propres inférieures ou égales
!>          à VL, ou supérieures à VU, ne seront pas retournées.  VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. Les valeurs propres inférieures ou égales
!>          à VL, ou supérieures à VU, ne seront pas retournées.  VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance absolue pour les valeurs propres. Une valeur propre
!>          (ou un cluster) est considérée comme située si elle a été
!>          déterminée à se trouver dans un intervalle dont la largeur est ABSTOL ou
!>          inférieure. Si ABSTOL est inférieur ou égal à zéro, alors ULP*|T|
!>          sera utilisé, où |T| signifie la norme 1 de T.
!>
!>          Les valeurs propres seront calculées de manière la plus précise lorsque ABSTOL est
!>          défini à deux fois le seuil de sous-dépassement 2*SLAMCH('S'), et non zéro.
!>

D

!>          D est tableau REAL, dimension (N)
!>          Les N éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est tableau REAL, dimension (N-1)
!>          Les (N-1) éléments hors diagonale de la matrice tridiagonale T.
!>

M

!>          M est INTEGER
!>          Le nombre réel de valeurs propres trouvées. 0 <= M <= N.
!>          (Voir aussi la description de INFO=2,3.)
!>

NSPLIT

!>          NSPLIT est INTEGER
!>          Le nombre de blocs diagonaux dans la matrice T.
!>          1 <= NSPLIT <= N.
!>

W

!>          W est tableau REAL, dimension (N)
!>          À la sortie, les M premiers éléments de W contiendront les
!>          valeurs propres.  (SSTEBZ peut utiliser les N-M éléments restants comme
!>          espace de travail.)
!>

IBLOCK

!>          IBLOCK est tableau INTEGER, dimension (N)
!>          À chaque ligne/colonne j où E(j) est nul ou faible, la
!>          matrice T est considérée comme se divisant en une matrice diagonale par blocs.
!>          À la sortie, si INFO = 0, IBLOCK(i) spécifie à quel
!>          bloc (de 1 au nombre de blocs) appartient la valeur propre W(i).
!>          (SSTEBZ peut utiliser les N-M éléments restants comme
!>          espace de travail.)
!>

ISPLIT

!>          ISPLIT est tableau INTEGER, dimension (N)
!>          Les points de division, où T se décompose en sous-matrices.
!>          La première sous-matrice consiste en les lignes/colonnes 1 à ISPLIT(1),
!>          la seconde en les lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et la NSPLIT-ième consiste en les lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>          (Seuls les NSPLIT premiers éléments seront effectivement utilisés, mais
!>          comme l'utilisateur ne peut pas savoir a priori quelle valeur NSPLIT aura,
!>          N mots doivent être réservés pour ISPLIT.)
!>

WORK

!>          WORK est tableau REAL, dimension (4*N)
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (3*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : certaines ou toutes les valeurs propres n'ont pas convergé ou
!>                n'ont pas été calculées :
!>                =1 ou 3 : La dichotomie n'a pas convergé pour certaines
!>                        valeurs propres ; ces valeurs propres sont signalées par un
!>                        numéro de bloc négatif. L'effet est que les
!>                        valeurs propres peuvent ne pas être aussi précises que les
!>                        tolérances absolue et relative. Ceci est
!>                        généralement causé par une arithmétique de précision
!>                        inattendue.
!>                =2 ou 3 : UNIQUEMENT RANGE='I' : Toutes les valeurs propres
!>                        IL:IU n'ont pas été trouvées.
!>                        Effet : M < IU+1-IL
!>                        Cause : arithmétique non monotone, provoquant la
!>                                non-monotonie de la séquence de Sturm.
!>                        Remède : recalculer, en utilisant RANGE='A', et extraire
!>                                les valeurs propres IL:IU. Dans certains cas,
!>                                augmenter le PARAMETRE  peut
!>                                faire fonctionner les choses.
!>                =4 :    RANGE='I', et l'intervalle de Gershgorin
!>                        initialement utilisé était trop petit. Aucune valeur propre
!>                        n'a été calculée.
!>                        Cause probable : votre machine a une arithmétique
!>                                        en virgule flottante imprécise.
!>                        Remède : Augmenter le PARAMETRE ,
!>                              recompiler et réessayer.
!>

!>  RELFAC  REAL, par défaut = 2.0e0
!>          La tolérance relative. Un intervalle (a,b] se trouve dans
!>           si  b-a < RELFAC*ulp*max(|a|,|b|),
!>          où  est la précision machine (distance de 1 au
!>          prochain nombre flottant supérieur.)
!>
!>  FUDGE   REAL, par défaut = 2
!>          Un  pour élargir les intervalles de Gershgorin. Idéalement,
!>          une valeur de 1 devrait fonctionner, mais sur des machines avec une
!>          arithmétique laxiste, celle-ci doit être plus grande. La valeur par défaut pour
!>          les versions publiées publiquement devrait être suffisamment grande pour gérer
!>          la pire machine existante. Notez que cela n'a aucun effet
!>          sur la précision de la solution.
!>
