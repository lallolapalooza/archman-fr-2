sous-routine ssygvd (integer itype, character jobz, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) w, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSYGVD

But :

!>
!> SSYGVD calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème eigenvaleur généralisé symétrique réel défini, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x. Ici, A et
!> B sont supposés symétriques et B est également définie positive.
!> Si des vecteurs propres sont désirés, il utilise un algorithme de « diviser pour régner ».
!>
!>

Paramètres

ITYPE 
!>          ITYPE est de type INTEGER
!>          Spécifie le type de problème à résoudre :
!>          = 1 :  A*x = (lambda)*B*x
!>          = 2 :  A*B*x = (lambda)*x
!>          = 3 :  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est de type CHARACTER*1
!>          = 'N' :  Calculer uniquement les valeurs propres ;
!>          = 'V' :  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est de type CHARACTER*1
!>          = 'U' :  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L' :  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est de type INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA, N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N de A contient la
!>          partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N par N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          À la sortie, si JOBZ = 'V', alors si INFO = 0, A contient la
!>          matrice Z des vecteurs propres.  Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors à la sortie, le triangle supérieur (si UPLO='U')
!>          ou le triangle inférieur (si UPLO='L') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau de type REAL, de dimension (LDB, N)
!>          À l'entrée, la matrice symétrique B.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N de B contient la
!>          partie triangulaire supérieure de la matrice B.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N par N de B contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          À la sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**T*U ou B = L*L**T.
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

W

!>          W est un tableau de type REAL, de dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur LWORK optimale.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' et N > 1, LWORK >= 2*N+1.
!>          Si JOBZ = 'V' et N > 1, LWORK >= 1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie la valeur LIWORK optimale.
!>

LIWORK

!>          LIWORK est de type INTEGER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à
!>          LWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 :  fin de l'exécution réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  SPOTRF ou SSYEVD a renvoyé un code d'erreur :
!>             <= N :  si INFO = i et JOBZ = 'N', alors l'algorithme
!>                    n'a pas réussi à converger ; i éléments hors diagonale d'une
!>                    forme tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>                    si INFO = i et JOBZ = 'V', alors l'algorithme
!>                    n'a pas réussi à calculer une valeur propre lors du travail sur
!>                    la sous-matrice située dans les lignes et colonnes INFO/(N+1)
!>                    jusqu'à mod(INFO,N+1) ;
!>             > N :   si INFO = N + i, pour 1 <= i <= N, alors le mineur
!>                    principal de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>

ssygvd — routine for generalized symmetric eigenvalue problem.

NAME

ssygvd - routine for generalized symmetric eigenvalue problem.

SYNOPSIS

SUBROUTINE SSYGVD(
 AGAIN, UPLO, N, A, LDA, B, LDB, W, WORK, LWORK, IWORK, LIWORK, INFO )

      INTEGER INFO
      INTEGER LIWORK, LWORK, N
      REAL    A( LDA, * ), B( LDB, * ), W( * ), WORK( * )
      CHARACTER                              AGAIN, UPLO

Function/Subroutine Documentation

SSYGVD computes the eigenvalues and, optionally, the eigenvectors of a real generalized symmetric-definite eigenvalue problem A*x = lambda*B*x or A*B*x = lambda*x or B*A*x = lambda*x.

Here lambda and x are the eigenvalues and eigenvectors, respectively. A and B are assumed to be symmetric and B is also assumed to be positive definite.

AGAIN (Input) CHARACTER*1 Specifies the problem to be solved: = 'E': computes only the eigenvalues, and optionally, the eigenvectors of the matrix A in the equation A*x = lambda*B*x. = 'V': computes the eigenvalues and eigenvectors of the matrix A in the equation A*x = lambda*B*x. = 'N': computes the eigenvalues and eigenvectors of the matrix A in the equation A*B*x = lambda*x.

UPLO (Input) CHARACTER*1 Specifies whether the upper or lower triangular part of the matrix A is stored and will be used in the computation. = 'U': Upper triangle of A is stored. = 'L': Lower triangle of A is stored.

N (Input) INTEGER The order of the matrices A and B. N >= 0.

A (Input/Output) REAL array, dimension (LDA, N) On entry, the upper or lower triangle of the symmetric matrix A. On exit, if AGAIN = 'N', the values k(i) in the diagonal entries of A, where k(i) are the roots of the characteristic polynomial det(A - lambda*inv(B)) = 0.

LDA (Input) INTEGER The leading dimension of the array A. LDA >= max(1, N).

B (Input/Output) REAL array, dimension (LDB, N) On entry, the upper or lower triangle of the symmetric positive definite matrix B. On exit, the factorization of B.

LDB (Input) INTEGER The leading dimension of the array B. LDB >= max(1, N).

W (Output) REAL array, dimension (N) On exit, the eigenvalues, sorted in an unspecified order.

WORK (Workspace) REAL array, dimension (LWORK)

LWORK (Input) INTEGER The dimension of the array WORK. LWORK >= 1. For optimum performance, LWORK >= 2*N.

IWORK (Workspace) INTEGER array, dimension (LIWORK)

LIWORK (Input) INTEGER The dimension of the array IWORK. LIWORK >= 1. For optimum performance, LIWORK >= max(1, 3*N).

INFO (Output) INTEGER = 0: successful exit. < 0: if INFO = -i, then the i-th argument had an illegal value. > 0: if INFO = i, then the algorithm did not converge; i off-diagonal elements of an intermediate tridiagonal form did not have the correct sign.
