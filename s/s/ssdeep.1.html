NOM

ssdeep - Calcule des hachages par morceaux déclenchés par le contexte (hachages flous)

SYNTAXE

ssdeep [-m <fichier>] [-k <fichier>] [-vdprgsblcxa] [-t <valeur>] [FICHIERS]
ssdeep [-V|h]

DESCRIPTION

Calcule une signature basée sur des hachages par morceaux déclenchés par le contexte pour chaque fichier d'entrée, également appelé hachage flou. Si demandé, le programme compare ces signatures à un fichier de signatures connues et signale toutes les correspondances possibles. Il peut également examiner un ou plusieurs fichiers de signatures et trouver toutes les correspondances dans ces fichiers. La sortie est écrite sur la sortie standard et les erreurs sur la sortie d'erreur standard.

-m <fichier>
Charge le fichier spécifié de hachages connus à utiliser pour la comparaison. Ce fichier doit être une sortie précédente du programme. Le programme hache ensuite chaque entrée des FICHIERS et compare ces signatures aux signatures connues. Toutes les correspondances dont le score dépasse le seuil sont affichées. Cette option peut être utilisée plusieurs fois pour charger davantage de signatures connues. Cette option ne peut pas être utilisée avec les options -k ou -x.
-k <fichier>
Charge le fichier spécifié de hachages connus à utiliser pour la comparaison. Ce fichier doit être une sortie précédente du programme. Le programme traite ensuite chaque entrée des FICHIERS comme un ensemble de hachages connus également. Les hachages dans ces FICHIERS sont comparés aux hachages connus de ce fichier. Les correspondances dont le score dépasse le seuil sont affichées. Le fichier spécifié ici et les FICHIERS d'entrée doivent contenir des hachages flous. Cette option peut être utilisée plusieurs fois pour charger davantage de signatures connues. Cette option ne peut pas être utilisée avec les options -m, -d ou -p.
-v
Mode verbeux. Le nom de chaque fichier est imprimé sur la sortie d'erreur standard au fur et à mesure de son hachage.
-d
Calcule une signature pour chaque entrée des FICHIERS et la compare à l'ensemble des signatures connues. Les correspondances dont le score dépasse le seuil sont affichées. La signature calculée est ensuite ajoutée à l'ensemble des signatures connues. Cette option ne peut pas être utilisée avec les options -k ou -x.
-p
Fonctionne comme l'option -d, mais affiche toutes les correspondances pour chaque fichier. C'est-à-dire, pour deux fichiers A et B qui correspondent avec un score supérieur au seuil, affiche « A correspond à B » et « B correspond à A ». Cette option ne peut pas être utilisée avec les options -k ou -x.
-r
Active le mode récursif. Tous les sous-répertoires sont parcourus. Veuillez noter que le mode récursif ne peut pas être utilisé pour examiner tous les fichiers d'une extension de fichier donnée. Par exemple, l'invocation du programme avec -r *.txt examinera tous les fichiers dans les répertoires se terminant par .txt. Si vous souhaitez traiter tous les fichiers d'une arborescence de répertoires avec le suffixe .txt, essayez d'utiliser la commande find(1).
-g
Les fichiers similaires sont regroupés en clusters. Cela peut être utile pour trouver des fichiers plus similaires. C'est-à-dire, si vous recherchez le fichier A, qui correspond à B, tout ce qui correspond à B sera également inclus dans le cluster.
-s
Mode silencieux. Tous les messages d'erreur sont supprimés.
-b
Active le mode nu. Supprime toutes les informations de répertoire de début des noms de fichiers affichés. Cette option ne peut pas être utilisée en conjonction avec l'option -l.
-l
Active les chemins de fichiers relatifs. Au lieu d'imprimer le chemin absolu pour chaque fichier, affiche le chemin de fichier relatif tel qu'indiqué sur la ligne de commande. Cette option ne peut pas être utilisée en conjonction avec l'option -b.
-c
Active le mode de sortie séparée par des virgules. Dans tous les modes de comparaison -d, -p ou -m, affiche les résultats sous la forme fichier d'entrée, fichier connu, score de correspondance.
-x
Comparaison de fichiers de signatures. Chaque entrée des FICHIERS doit contenir des signatures générées par une sortie précédente du programme. Chaque signature est chargée et comparée à l'ensemble des hachages connus. Les scores de correspondance supérieurs au seuil sont affichés. Chaque signature est ensuite ajoutée à l'ensemble des connaissances. Cette option ne peut pas être utilisée avec les options -m, -d ou -p.
-a
Affiche toutes les correspondances dans tous les modes de comparaison, quel que soit le score. L'utilisation de l'option -a affiche tous les résultats, même si le score de correspondance est zéro.
-t <valeur>
Dans tous les modes de comparaison, n'affiche les correspondances que lorsque le score de correspondance est supérieur à la valeur donnée. La valeur seuil par défaut est zéro.
-h
Affiche un écran d'aide et quitte.
-V
Affiche le numéro de version et quitte.

VALEUR DE RETOUR

Retourne 0 en cas de succès, 1 en cas de problème. Les erreurs de lecture, les refus d'accès et la rencontre de répertoires en mode non récursif sont toujours considérés comme des succès. Les problèmes sont des choses comme l'impossibilité de charger le fichier de comparaison, la spécification de chemins à la fois nus et relatifs, etc.
