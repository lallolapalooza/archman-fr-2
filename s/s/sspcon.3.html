sous-programme sspcon (caractère uplo, entier n, réel, dimension( * ) ap, entier, dimension( * ) ipiv, réel anorm, réel rcond, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SSPCON

Objectif:

!>
!> SSPCON estime l'inverse du nombre de conditionnement (en norme 1)
!> d'une matrice symétrique réelle compactée A, en utilisant la factorisation
!> A = U*D*U**T ou A = L*D*L**T calculée par SSPTRF.
!>
!> Une estimation est obtenue pour norm(inv(A)), et l'inverse du nombre
!> de conditionnement est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, la forme est A = U*D*U**T ;
!>          = 'L':  Triangulaire inférieure, la forme est A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau REAL, dimension (N*(N+1)/2)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>          obtenir le facteur U ou L, tels que calculés par SSPTRF, stockés sous
!>          forme de matrice triangulaire compactée.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D,
!>          tels que déterminés par SSPTRF.
!>

ANORM

!>          ANORM est REAL
!>          La norme 1 de la matrice originale A.
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de conditionnement de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée par cette routine.
!>

WORK

!>          WORK est un tableau REAL, dimension (2*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
