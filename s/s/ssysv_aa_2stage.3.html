SSYSV_AA_2STAGE calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

Objectif :

!>
!> SSYSV_AA_2STAGE calcule la solution d'un système réel d'équations
!> linéaires
!>    A * X = B,
!> où A est une matrice symétrique de taille N par N et X et B sont des matrices
!> de taille N par NRHS.
!>
!> L'algorithme en 2 étapes d'Aasen est utilisé pour factoriser A comme
!>    A = U**T * T * U,  si UPLO = 'U', ou
!>    A = L * T * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et triangulaires unitaires
!> supérieures (inférieures), et T est symétrique et bande. La matrice T est
!> ensuite factorisée LU avec pivotement partiel. La forme factorisée de A
!> est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>
!> C'est la version bloquée de l'algorithme, qui appelle BLAS de niveau 3.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire N par N de A contient la partie supérieure
!>          triangulaire de la matrice A, et la partie strictement inférieure
!>          triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire N par N de A contient la partie inférieure
!>          triangulaire de la matrice A, et la partie strictement supérieure
!>          triangulaire de A n'est pas référencée.
!>
!>          À la sortie, L est stocké sous (ou au-dessus) les blocs sous-diagonaux,
!>          lorsque UPLO est 'L' (ou 'U').
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

TB

!>          TB est un tableau de type REAL, de dimension (MAX(1,LTB))
!>          À la sortie, détails de la factorisation LU de la matrice bande.
!>

LTB

!>          LTB est INTEGER
!>          La taille du tableau TB. LTB >= MAX(1,4*N), utilisé en interne
!>          pour sélectionner NB tel que LTB >= (3*NB+1)*N.
!>
!>          Si LTB = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale de LTB,
!>          renvoie cette valeur dans la première entrée de TB, et
!>          aucun message d'erreur relatif à LTB n'est émis par XERBLA.
!>

IPIV

!>          IPIV est un tableau de type INTEGER, de dimension (N)
!>          À la sortie, il contient les détails des échanges, c'est-à-dire
!>          que la ligne et la colonne k de A ont été échangées avec la
!>          ligne et la colonne IPIV(k).
!>

IPIV2

!>          IPIV2 est un tableau de type INTEGER, de dimension (N)
!>          À la sortie, il contient les détails des échanges, c'est-à-dire
!>          que la ligne et la colonne k de T ont été échangées avec la
!>          ligne et la colonne IPIV(k).
!>

B

!>          B est un tableau de type REAL, de dimension (LDB,NRHS)
!>          À l'entrée, le second membre B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un espace de travail de type REAL de taille (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La taille de WORK. LWORK >= MAX(1,N), utilisé en interne
!>          pour sélectionner NB tel que LWORK >= N*NB.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur dans la première entrée du tableau WORK, et
!>          aucun message d'erreur relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, la factorisation LU bande a échoué sur la i-ème colonne
!>
