NOM

sshare - Outil pour lister les parts des associations d'un cluster.

SYNTAXE

sshare [OPTIONS...]

DESCRIPTION

sshare est utilisé pour visualiser les informations de parts Slurm. Cette commande n'est viable que lorsqu'elle est exécutée avec le plugin priority/multifactor. Les informations sshare sont dérivées d'une base de données dont l'interface est fournie par slurmdbd (démon de base de données Slurm), qui est lue par slurmctld et utilisée pour traiter les parts disponibles pour une association donnée. sshare fournit des informations de parts Slurm sur les comptes, les utilisateurs, les parts brutes, les parts normalisées, l'utilisation brute, l'utilisation normalisée, l'utilisation effective, le facteur de partage équitable, la limite GrpTRESMins, les partitions et les minutes TRES accumulées en cours d'exécution pour chaque association.

OPTIONS

-A, --comptes=<compte>
Affiche les informations pour des comptes spécifiques (liste séparée par des virgules).
-a, --tous
Affiche les informations pour tous les utilisateurs.
-M, --clusters=<chaîne>
Clusters sur lesquels exécuter les commandes. Notez que slurmdbd doit être en cours d'exécution pour que cette option fonctionne correctement, sauf si vous exécutez en fédération avec FederationParameters=fed_display configuré.
-o, --format=<format_sortie>
Liste des champs séparés par des virgules (utilisez "--helpformat" pour une liste des champs disponibles).
--aide
Affiche une description des options et commandes sshare.
-l, --long
Affichage long - inclut les informations d'utilisation normalisée.
--json, --json=liste, --json=<analyseur_donnees>
Affiche les informations au format JSON en utilisant le plugin analyseur_donnees par défaut ou un analyseur_donnees explicite avec des paramètres. Les arguments de tri et de formatage seront ignorés.
-n, --pasentete
Aucun en-tête ne sera ajouté au début de la sortie.
-p, --parsable
La sortie sera délimitée par '|' avec un '|' à la fin.
-P, --parsable2
La sortie sera délimitée par '|' sans '|' à la fin.
-m, --partition
S'il existe des partitions basées sur les associations dans le système, affichez leurs noms.
--usage
Affiche une description des options et commandes sshare.
-u, --utilisateurs=<liste_utilisateurs>
Affiche les informations pour des utilisateurs spécifiques (liste séparée par des virgules).
-U, --Utilisateurs
Si spécifié, seules les informations des utilisateurs sont affichées, les parents et les ancêtres ne sont pas affichés.
-v, --verbeux
Affiche plus d'informations sur les options spécifiées.
-V, --version
Affiche le numéro de version de sshare.
--yaml, --yaml=liste, --yaml=<analyseur_donnees>
Affiche les informations au format YAML en utilisant le plugin analyseur_donnees par défaut ou un analyseur_donnees explicite avec des paramètres. Les arguments de tri et de formatage seront ignorés.

CHAMPS SORTIE SSHARE

Compte
Le compte.
Utilisateur
L'utilisateur.
Parts brutes
Les parts brutes assignées à l'utilisateur ou au compte.
Parts normalisées
Les parts assignées à l'utilisateur ou au compte normalisées par le nombre total de parts assignées.
Utilisation brute
Le nombre de tres-secondes (secondes CPU si TRESBillingWeights n'est pas défini) de tous les jobs facturés au compte ou à l'utilisateur. Ce nombre décroîtra avec le temps si PriorityDecayHalfLife est défini.
Utilisation normalisée (apparaît uniquement avec l'option sshare -l)
L'utilisation brute normalisée par le nombre total de tres-secondes de tous les jobs exécutés sur le cluster, sous réserve de la décroissance PriorityDecayHalfLife lorsqu'elle est définie.
Utilisation effective
L'utilisation effective augmente l'utilisation normalisée pour tenir compte de l'utilisation des comptes frères.
Partage équitable
Le facteur de partage équitable, basé sur les parts assignées d'un utilisateur ou d'un compte et l'utilisation effective qui leur est facturée ou à leurs comptes.
GrpTRESMins
La limite de minutes TRES définie sur le compte. Le nombre total de minutes CPU qui peuvent être utilisées par les jobs passés, présents et futurs provenant de ce compte et de ses enfants.
GrpTRESRaw
L'utilisation brute de TRES utilisée par les jobs provenant de ce compte et de ses enfants.
TRESRunMins
Le nombre de minutes TRES allouées par les jobs en cours d'exécution sur le compte. Utilisé pour limiter le nombre total de minutes TRES utilisées par tous les jobs s'exécutant avec ce compte et ses enfants. Cela prend en compte la limite de temps des jobs en cours et la consomme. Si la limite est atteinte, aucun nouveau job n'est démarré tant que d'autres jobs ne sont pas terminés pour libérer du temps.

sshare(1) — Arch Linux

NOM

sshare — affiche les informations sur les parts équitables

SYNOPIS

sshare [options]

DESCRIPTION

La commande sshare affiche les informations sur les parts équitables pour les utilisateurs, les comptes, les partitions, les jobs et les configurations de Slurm. Les informations sur les parts équitables sont collectées à partir de la base de données de Slurm, qui est gérée par slurmdbd. Les informations sur les parts équitables sont généralement collectées dans la table `Shares` de la base de données.

Les informations sur les parts équitables sont utilisées pour allouer des ressources aux utilisateurs et aux comptes en fonction de leurs besoins et de leurs priorités. Les parts équitables sont calculées en utilisant un algorithme appelé « arbre équitable », qui prend en compte les besoins de tous les utilisateurs et de tous les comptes pour déterminer les parts équitables de chacun.

OPTIONS

Veuillez consulter la page de manuel de sshare pour une liste complète des options.

CHAMPS DE SORTIE DE SSHARE

Account
Nom du compte.
User
Nom de l'utilisateur.
Partition
Nom de la partition.
Jobs
Nombre de jobs en cours d'exécution pour le compte, l'utilisateur ou la partition.
Share
Nombre total de parts attribuées au compte, à l'utilisateur ou à la partition.
Usage
Utilisation actuelle des ressources par le compte, l'utilisateur ou la partition, exprimée en pourcentage du total.
Priority
Priorité du compte, de l'utilisateur ou de la partition.
Fairshare
Valeur de part équitable calculée pour le compte, l'utilisateur ou la partition.

MODIFICATIONS DE L'ARBRE ÉQUITABLE

Les calculs de part équitable sont effectués différemment. En conséquence, les champs suivants sont ajoutés ou modifiés :

Parts normalisées
Les parts attribuées à l'utilisateur ou au compte, normalisées par rapport au nombre total de parts attribuées au niveau.
Utilisation effective
L'Utilisation effective est l'utilisation de l'association normalisée par rapport à son parent.
Part Équitable Niveau (n'apparaît qu'avec l'option sshare -l)
C'est la valeur de part équitable de l'association comparée à ses frères et sœurs, calculée comme Parts Normalisées / Utilisation Effective. Si une association est sur-desservie, la valeur est comprise entre 0 et 1. Si une association est sous-desservie, la valeur est supérieure à 1. Les associations sans utilisation reçoivent la valeur la plus élevée possible, l'infini.

Plus d'informations sur l'arbre équitable sont disponibles dans doc/html/fair_tree.html ou sur https://slurm.schedmd.com/fair_tree.html

PERFORMANCE

L'exécution de sshare envoie un appel de procédure distante à slurmctld. Si un nombre suffisant d'appels provenant de sshare ou d'autres commandes client Slurm qui envoient des appels de procédure distante au démon slurmctld arrivent en même temps, cela peut entraîner une dégradation des performances du démon slurmctld, entraînant potentiellement un déni de service.

N'exécutez pas sshare ou d'autres commandes client Slurm qui envoient des appels de procédure distante à slurmctld à partir de boucles dans des scripts shell ou d'autres programmes. Assurez-vous que les programmes limitent les appels à sshare au minimum nécessaire pour les informations que vous essayez de collecter.

VARIABLES D'ENVIRONNEMENT

Certaines options de sshare peuvent être définies via des variables d'environnement. Ces variables d'environnement, ainsi que leurs options correspondantes, sont listées ci-dessous. (Note : les options de ligne de commande remplacent toujours ces paramètres.)

SLURM_CONF
L'emplacement du fichier de configuration de Slurm.
SLURM_DEBUG_FLAGS
Spécifie les indicateurs de débogage à utiliser par sshare. Voir DebugFlags dans la page de manuel de slurm.conf(5) pour une liste complète des indicateurs. La variable d'environnement a la priorité sur le paramètre dans slurm.conf.
SLURM_JSON
Contrôle la sérialisation JSON :
compact
Produit la sortie JSON aussi compacte que possible.
pretty
Produit la sortie JSON au format pretty pour la rendre plus lisible.
SLURM_YAML
Contrôle la sérialisation YAML :
compact Produit la sortie YAML aussi compacte que possible.
pretty Produit la sortie YAML au format pretty pour la rendre plus lisible.

EXEMPLES

Afficher des informations sur les utilisateurs dans un compte particulier :
$ sshare -A <Compte>
Afficher des informations sur un utilisateur spécifique dans un format analysable :
$ sshare --parsable --users=<Utilisateur>
