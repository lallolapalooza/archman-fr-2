sous-programme ssycon (caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, réel anorm, réel rcond, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SSYCON

But :

!>
!> SSYCON estime l'inverse du nombre de condition (en norme 1) d'une matrice
!> symétrique réelle A, en utilisant la factorisation A = U*D*U**T ou
!> A = L*D*L**T calculée par SSYTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre de
!> condition est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U': Triangulaire supérieure, forme est A = U*D*U**T ;
!>          = 'L': Triangulaire inférieure, forme est A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de REAL, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L calculés par SSYTRF.
!>

LDA

!>          LDA est INTEGER
!>          Dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau de INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par SSYTRF.
!>

ANORM

!>          ANORM est REAL
!>          La norme 1 de la matrice originale A.
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau de REAL, dimension (2*N)
!>

IWORK

!>          IWORK est un tableau de INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
