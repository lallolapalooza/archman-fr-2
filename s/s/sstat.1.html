sstat(1) Commandes Slurm sstat(1)

NOM

sstat - Afficher les informations d'état d'un job/étape en cours.

SYNTAXE

sstat [OPTIONS...]

DESCRIPTION

Informations d'état pour les jobs en cours lancés avec Slurm.

La commande sstat affiche les informations d'état du job pour votre analyse. La commande sstat affiche des informations relatives au CPU, aux tâches, aux nœuds, à la taille du jeu résident (RSS) et à la mémoire virtuelle (VM). Vous pouvez adapter la sortie en utilisant l'option --fields= pour spécifier les champs à afficher.

Pour l'utilisateur root, la commande sstat affiche les données d'état des jobs pour tout job en cours d'exécution sur le système.

Pour l'utilisateur non root, la sortie de sstat est limitée aux jobs de l'utilisateur.

NOTE : La commande sstat nécessite que le plugin jobacct_gather soit installé et opérationnel.

NOTE : La disponibilité des métriques dépend du plugin jobacct_gather utilisé. Par exemple, jobacct_gather/cgroup en combinaison avec cgroup/v2 ne fournit pas de métriques de mémoire virtuelle en raison des limitations des interfaces cgroups du noyau et affichera 0 pour les champs associés.

OPTIONS

-a, --allsteps
Imprimer toutes les étapes pour le(s) job(s) donné(s) lorsqu'aucune étape n'est spécifiée.
-o, --format, --fields
Liste des champs séparés par des virgules. (utiliser '--helpformat' pour une liste des champs disponibles).

NOTE : Lors de l'utilisation de l'option de format pour lister divers champs, vous pouvez ajouter %NOMBRE après pour spécifier le nombre de caractères à imprimer.

par exemple, format=name%30 imprimera 30 caractères du champ nom justifiés à droite. Un -30 imprimera 30 caractères justifiés à gauche.

-h, --help
Affiche un message d'aide général.
-e, --helpformat
Imprime une liste des champs qui peuvent être spécifiés avec l'option '--format'.
-j, --jobs
Le format est <job(.étape)>. Statistique cette étape de job ou liste d'étapes de job séparées par des virgules. Cette option est requise. La partie étape sera par défaut la plus basse numérotée (pas batch, extern, etc.) en cours si elle n'est pas spécifiée, sauf si le drapeau --allsteps est défini où ne pas spécifier d'étape résultera à l'affichage de toutes les étapes en cours. NOTE : Une ID d'étape 'batch' affichera les informations concernant l'étape batch. NOTE : Une ID d'étape 'extern' affichera les informations concernant l'étape extern. Cette étape n'est disponible que lors de l'utilisation de PrologFlags=contain
--noconvert
Ne pas convertir les unités de leur type d'origine (par exemple, 2048M ne sera pas converti en 2G).
-n, --noheader
Aucun en-tête ne sera ajouté à la sortie. L'action par défaut est d'afficher un en-tête.
-p, --parsable
La sortie sera délimitée par '|' avec un '|' à la fin
-P, --parsable2
La sortie sera délimitée par '|' sans '|' à la fin
-i, --pidformat
Format prédéfini pour lister les PID en cours d'exécution pour chaque étape de job. (JobId, Nodes, Pids)
--usage
Affiche un résumé de l'utilisation de la commande.
-v, --verbose
Principalement à des fins de débogage, rapporte l'état de diverses variables pendant le traitement.
-V, --version
Imprime la version.

Champs d'état du job

Les descriptions de chaque option de champ se trouvent ci-dessous. Notez que les champs de comptabilité Ave*, Max* et Min* examinent les valeurs de toutes les tâches de chaque étape d'un job et renvoient les valeurs moyennes, maximales ou minimales de la tâche pour cette étape de job. Par exemple, pour MaxRSS, la valeur renvoyée est la consommation de mémoire maximale observée par l'une des tâches de l'étape, et MaxRSSTask indique de quelle tâche il s'agit.

AllocTRES
TRES alloués de toutes les tâches du job.
AveCPU
Temps CPU moyen (système + utilisateur) de toutes les tâches du job.
AveCPUFreq
Fréquence CPU pondérée moyenne de toutes les tâches du job, en kHz.
AveDiskRead
Nombre moyen d'octets lus par toutes les tâches du job.
AveDiskWrite
Nombre moyen d'octets écrits par toutes les tâches du job.
AvePages
Nombre moyen de fautes de page de toutes les tâches du job.
AveRSS
Taille moyenne du jeu résident de toutes les tâches du job.
AveVMSize
Taille moyenne de la mémoire virtuelle de toutes les tâches du job.
ConsumedEnergy
Énergie totale consommée par toutes les tâches du job, en joules. Note : Ce n'est qu'en cas d'allocation de job exclusive que cette valeur reflète la consommation d'énergie réelle des jobs.
JobID
Le numéro du job ou de l'étape du job. Il est sous la forme : job.jobstep
MaxDiskRead
Nombre maximal d'octets lus par toutes les tâches du job.
MaxDiskReadNode
Le nœud sur lequel maxdiskread s'est produit.
MaxDiskReadTask
L'ID de la tâche où maxdiskread s'est produit.
MaxDiskWrite
Nombre maximal d'octets écrits par toutes les tâches du job.
MaxDiskWriteNode
Le nœud sur lequel le maxdiskwrite s'est produit.
MaxDiskWriteTask
L'identifiant de la tâche où le maxdiskwrite s'est produit.
MaxPages
Nombre maximum de fautes de page de toutes les tâches du job.
MaxPagesNode
Le nœud sur lequel le maxpages s'est produit.
MaxPagesTask
L'identifiant de la tâche où le maxpages s'est produit.
MaxRSS
Taille maximale de l'ensemble résident de toutes les tâches du job.
MaxRSSNode
Le nœud sur lequel le maxrss s'est produit.
MaxRSSTask
L'identifiant de la tâche où le maxrss s'est produit.
MaxVMSize
Taille maximale de la mémoire virtuelle de toutes les tâches du job.
MaxVMSizeNode
Le nœud sur lequel le maxvsize s'est produit.
MaxVMSizeTask
L'identifiant de la tâche où le maxvsize s'est produit.
MinCPU
Temps CPU minimum (système + utilisateur) de toutes les tâches du job.
MinCPUNode
Le nœud sur lequel le mincpu s'est produit.
MinCPUTask
L'identifiant de la tâche où le mincpu s'est produit.
NTasks
Nombre total de tâches dans un job ou une étape.
ReqCPUFreq
Fréquence CPU demandée pour l'étape, en kHz.
TresUsageInAve
Utilisation moyenne des TRES entrantes par toutes les tâches du job. NOTE: Si TresUsageInMaxTask correspondant est -1, la métrique est centrée sur le nœud au lieu de la tâche.
TresUsageInMax
Utilisation maximale des TRES entrantes par toutes les tâches du job. NOTE: Si TresUsageInMaxTask correspondant est -1, la métrique est centrée sur le nœud au lieu de la tâche.
TresUsageInMaxNode
Nœud pour lequel chaque utilisation maximale de TRES entrante s'est produite.
TresUsageInMaxTask
Tâche pour laquelle chaque utilisation maximale de TRES entrante s'est produite.
TresUsageOutAve
Utilisation moyenne des TRES sortantes par toutes les tâches du job. NOTE: Si TresUsageOutMaxTask correspondant est -1, la métrique est centrée sur le nœud au lieu de la tâche.
TresUsageOutMax
Utilisation maximale des TRES sortantes par toutes les tâches du job. NOTE: Si TresUsageOutMaxTask correspondant est -1, la métrique est centrée sur le nœud au lieu de la tâche.
TresUsageOutMaxNode
Nœud pour lequel chaque utilisation maximale de TRES sortante s'est produite.
TresUsageOutMaxTask
Tâche pour laquelle chaque utilisation maximale de TRES sortante s'est produite.

PERFORMANCE

L'exécution de sstat envoie un appel de procédure distante à slurmctld. Si suffisamment d'appels de sstat ou d'autres commandes client Slurm envoyant des appels de procédure distante au démon slurmctld arrivent en même temps, cela peut entraîner une dégradation des performances du démon slurmctld, résultant potentiellement en un déni de service.

N'exécutez pas sstat ou d'autres commandes client Slurm envoyant des appels de procédure distante à slurmctld depuis des boucles dans des scripts shell ou d'autres programmes. Assurez-vous que les programmes limitent les appels à sstat au minimum nécessaire pour les informations que vous essayez de collecter.

VARIABLES D'ENVIRONNEMENT

Certaines options de sstat peuvent être définies via des variables d'environnement. Ces variables d'environnement, ainsi que leurs options correspondantes, sont listées ci-dessous. (Note: les options de ligne de commande remplaceront toujours ces paramètres.)

SLURM_CONF
L'emplacement du fichier de configuration Slurm.
SLURM_DEBUG_FLAGS
Spécifie les indicateurs de débogage que sstat doit utiliser. Voir DebugFlags dans la page de manuel slurm.conf(5) pour une liste complète des indicateurs. La variable d'environnement a la priorité sur le paramètre dans slurm.conf.

EXEMPLES

Affiche les informations sur les étapes de job pour le job 11 avec les champs spécifiés :
$ sstat --format=AveCPU,AvePages,AveRSS,AveVMSize,JobID -j 11
25:02.000  0K         1.37M      5.93M      9.0
Affiche les informations sur les étapes de job pour le job 11 avec les champs spécifiés dans un format analysable :
$ sstat -p --format=AveCPU,AvePages,AveRSS,AveVMSize,JobID -j 11
25:02.000|0K|1.37M|5.93M|9.0|
