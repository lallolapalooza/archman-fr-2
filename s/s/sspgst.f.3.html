subroutine sspgst (itype, uplo, n, ap, bp, info)
SSPGST

Documentation de fonction/sous programme

sous programme sspgst (entier itype, caractere uplo, entier n, reel, dimension( * ) ap, reel, dimension( * ) bp, entier info)

SSPGST

Objectif:

!>
!> SSPGST réduit un problème généralisé d' valeurs propres symétrique-définie réel
!> à forme standard, en utilisant un stockage compact.
!>
!> Si ITYPE = 1, le problème est A*x = lambda*B*x,
!> et A est écrasé par inv(U**T)*A*inv(U) ou inv(L)*A*inv(L**T)
!>
!> Si ITYPE = 2 ou 3, le problème est A*B*x = lambda*x ou
!> B*A*x = lambda*x, et A est écrasé par U*A*U**T ou L**T*A*L.
!>
!> B doit avoir été préalablement factorisé en U**T*U ou L*L**T par SPPTRF.
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          = 1 : calculer inv(U**T)*A*inv(U) ou inv(L)*A*inv(L**T) ;
!>          = 2 ou 3 : calculer U*A*U**T ou L**T*A*L.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U' : Le triangle supérieur de A est stocké et B est factorisé comme
!>                  U**T*U ;
!>          = 'L' : Le triangle inférieur de A est stocké et B est factorisé comme
!>                  L*L**T.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B. N >= 0.
!>

AP

!>          AP est un tableau REEL, de dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, stocké en colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          En sortie, si INFO = 0, la matrice transformée, stockée dans le
!>          même format que A.
!>

BP

!>          BP est un tableau REEL, de dimension (N*(N+1)/2)
!>          Le facteur triangulaire de la factorisation de Cholesky de B,
!>          stocké dans le même format que A, tel que retourné par SPPTRF.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était illégal
!>
