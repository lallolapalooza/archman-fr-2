sous-programme ssygv (entier itype, caractère jobz, caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) w, réel, dimension( * ) work, entier lwork, entier info)

SSYGV

But :

!>
!> SSYGV calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème propre général symétrique-défini réel, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x.
!> Ici, A et B sont supposées symétriques et B est aussi
!> définie positive.
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          Spécifie le type de problème à résoudre :
!>          = 1 :  A*x = (lambda)*B*x
!>          = 2 :  A*B*x = (lambda)*x
!>          = 3 :  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CARACTÈRE*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CARACTÈRE*1
!>          = 'U' : Les triangles supérieurs de A et B sont stockés ;
!>          = 'L' : Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

A

!>          A est tableau RÉEL, dimension (LDA, N)
!>          En entrée, la matrice symétrique A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de A contient
!>          la partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient la
!>          matrice Z des vecteurs propres. Les vecteurs propres sont normalisés
!>          comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors en sortie, le triangle supérieur (si UPLO='U')
!>          ou le triangle inférieur (si UPLO='L') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est tableau RÉEL, dimension (LDB, N)
!>          En entrée, la matrice symétrique définie positive B.
!>          Si UPLO = 'U', la partie triangulaire supérieure N-par-N de B
!>          contient la partie triangulaire supérieure de la matrice B.
!>          Si UPLO = 'L', la partie triangulaire inférieure N-par-N de B
!>          contient la partie triangulaire inférieure de la matrice B.
!>
!>          En sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation de Cholesky
!>          B = U**T*U ou B = L*L**T.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

W

!>          W est tableau RÉEL, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

WORK

!>          WORK est tableau RÉEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur du tableau WORK. LWORK >= max(1,3*N-1).
!>          Pour une efficacité optimale, LWORK >= (NB+2)*N,
!>          où NB est la taille du bloc pour SSYTRD renvoyée par ILAENV.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0 : SPOTRF ou SSYEV ont retourné un code d'erreur :
!>             <= N : si INFO = i, SSYEV n'a pas convergé ;
!>                    i éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                    n'ont pas convergé vers zéro ;
!>             > N :   si INFO = N + i, pour 1 <= i <= N, alors le mineur principal
!>                    de tête d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculée.
!>
