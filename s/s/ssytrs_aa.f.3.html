sous-programme ssytrs_aa (caractère uplo, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, entier lwork, entier info)

SSYTRS_AA

But:

!>
!> SSYTRS_AA résout un système d'équations linéaires A*X = B avec une matrice symétrique réelle A en utilisant la factorisation A = U**T*T*U ou
!> A = L*T*L**T calculée par SSYTRF_AA.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme est A = U**T*T*U;
!>          = 'L':  Triangulaire inférieure, forme est A = L*T*L**T.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          Détails des facteurs calculés par SSYTRF_AA.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Détails des échanges calculés par SSYTRF_AA.
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          Si MIN(N,NRHS) = 0, LWORK >= 1, sinon LWORK >= 3*N-2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille minimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
