sous-routine ssyevd (jobz, uplo, n, a, lda, w, work, lwork, iwork, liwork, info)
SSYEVD calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices SY

Documentation de la fonction/sous-routine

sous-routine ssyevd (caractère jobz, caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) w, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

SSYEVD calcule les valeurs propres et, éventuellement, les vecteurs propres d'une matrice symétrique réelle A. Si les vecteurs propres sont désirés, elle utilise un algorithme de diviser pour régner.

Objectif :

!>
!> SSYEVD calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice symétrique réelle A. Si des vecteurs propres sont désirés,
!> elle utilise un algorithme de diviser pour régner.
!>
!> En raison de l'utilisation intensive de BLAS de niveau 3, SSYEVD nécessite N**2
!> d'espace de travail supplémentaire par rapport à SSYEVX.
!>

Paramètres

JOBZ 
!>          JOBZ est CARACTÈRE*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CARACTÈRE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau RÉEL, de dimension (LDA, N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de A contient la
!>          partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient la
!>          partie triangulaire inférieure de la matrice A.
!>          À la sortie, si JOBZ = 'V', alors si INFO = 0, A contient les
!>          vecteurs propres orthonormés de la matrice A.
!>          Si JOBZ = 'N', alors à la sortie, le triangle inférieur (si UPLO='L')
!>          ou le triangle supérieur (si UPLO='U') de A, y compris la
!>          diagonale, est détruit.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

W

!>          W est un tableau RÉEL, de dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

WORK

!>          WORK est un tableau RÉEL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LWORK doit être au moins 2*N+1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être au moins
!>                                                1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK et IWORK,
!>          renvoie ces valeurs comme premières entrées des tableaux WORK et IWORK,
!>          et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient la valeur optimale de LIWORK.
!>

LIWORK

!>          LIWORK est ENTIER
!>          La dimension du tableau IWORK.
!>          Si N <= 1,                LIWORK doit être au moins 1.
!>          Si JOBZ  = 'N' et N > 1, LIWORK doit être au moins 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK doit être au moins 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement les tailles optimales des tableaux WORK et
!>          IWORK, renvoie ces valeurs comme premières entrées des tableaux WORK et
!>          IWORK, et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i et JOBZ = 'N', alors l'algorithme n'a pas convergé ;
!>                i éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro ;
!>                si INFO = i et JOBZ = 'V', alors l'algorithme n'a pas réussi à
!>                calculer une valeur propre tout en travaillant sur la sous-matrice
!>                située dans les lignes et colonnes INFO/(N+1) à
!>                mod(INFO,N+1).
!>
