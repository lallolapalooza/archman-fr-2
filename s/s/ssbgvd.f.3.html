SSBGVD

But :

!>
!> SSBGVD calcule toutes les valeurs propres, et optionnellement, les vecteurs
!> propres d'un problème aux valeurs propres généralisé symétrique-défini
!> réel et bande, de la forme A*x=(lambda)*B*x. Ici A et B sont supposées
!> symétriques et bande, et B est aussi définie positive. Si les vecteurs
!> propres sont désirés, il utilise un algorithme de type diviser pour régner.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer seulement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB est INTEGER
!>          Le nombre de super-diagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KB >= 0.
!>

AB

!>          AB est tableau REEL, dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les ka+1 premières lignes du tableau. Le
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          En sortie, le contenu de AB est détruit.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

BB

!>          BB est tableau REEL, dimension (LDBB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique B, stocké dans les kb+1 premières lignes du tableau. Le
!>          j-ème colonne de B est stockée dans la j-ème colonne du tableau BB
!>          comme suit :
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) pour max(1,j-kb)<=i<=j ;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) pour j<=i<=min(n,j+kb).
!>
!>          En sortie, le facteur S de la factorisation de Cholesky éclatée
!>          B = S**T*S, tel que retourné par SPBSTF.
!>

LDBB

!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!>

W

!>          W est tableau REEL, dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

Z

!>          Z est tableau REEL, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres, avec la i-ème colonne de Z contenant le
!>          vecteur propre associé à W(i).  Les vecteurs propres sont
!>          normalisés de telle sorte que Z**T*B*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est tableau REEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' et N > 1, LWORK >= 3*N.
!>          Si JOBZ = 'V' et N > 1, LWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement les tailles optimales des tableaux WORK et IWORK,
!>          retourne ces valeurs comme premières entrées des tableaux WORK
!>          et IWORK, et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (MAX(1,LIWORK))
!>          En sortie, si LIWORK > 0, IWORK(1) retourne le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement les tailles optimales des tableaux WORK et
!>          IWORK, retourne ces valeurs comme premières entrées des tableaux
!>          WORK et IWORK, et aucun message d'erreur lié à LWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, et i est :
!>             <= N:  l'algorithme n'a pas convergé :
!>                    i éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                    n'ont pas convergé vers zéro ;
!>             > N :   si INFO = N + i, pour 1 <= i <= N, alors SPBSTF
!>                    a retourné INFO = i : B n'est pas définie positive.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>

    NOM

    ssbgvd - Sépare une matrice en valeurs propres réelles et vecteurs propres.

    SYNOPSIS

    SUBROUTINE SSBGVD(
   JOBZ, UPLO, N, KA, KB, AB, LDAB, BB, LDBB, W, Z, LDZ, WORK, LWORK, IWORK, LIWORK, INFO
)
INTEGER INFO
REAL W( * ), WORK( * )
COMPLEX Z( * )
INTEGER IWORK( * )
CHARACTER JOBZ, UPLO
INTEGER N, KA, KB, LDAB, LDBB, LDZ, LWORK, LIWORK
REAL AB( LDAB, * ), BB( LDBB, * )

    SSBGVD (caractères généraux)

    Calcule les valeurs propres et, optionnellement, les vecteurs propres d'une paire de matrices symétriques/Hermitiennes et définies positives réelles. Les matrices sont dans des formats bandeaux généraux.

    Documentation de fonction/sous-routine

    SSBGVD

    JOBZ : CHARACTER*1. Indique s'il faut calculer les vecteurs propres. = 'N': seulement les valeurs propres seront calculées. = 'V': les valeurs propres et les vecteurs propres seront calculés.

    UPLO : CHARACTER*1. Indique si la partie supérieure ou inférieure des matrices est stockée. = 'U': la partie supérieure est stockée. = 'L': la partie inférieure est stockée.

    N : INTEGER. L'ordre des matrices.N >= 0.

    KA : INTEGER. Le nombre de super/sous-diagonales deA.KA >= 0.

    KB : INTEGER. Le nombre de super/sous-diagonales deB.KB >= 0.

    AB : REAL tableau(LDAB, KA+1). Sur l'entrée,AB contient la partie bande de la matriceA. Sur la sortie,AB est écrasé.

    LDAB : INTEGER. La largeur de la bande deAB.LDAB >=KA+1.

    BB : REAL tableau(LDBB, KB+1). Sur l'entrée,BB contient la partie bande de la matriceB. Sur la sortie,BB est écrasé.

    LDBB : INTEGER. La largeur de la bande deBB.LDBB >=KB+1.

    W : REAL tableau(N). Sur la sortie,W contient les valeurs propres triées par ordre croissant.

    Z : COMPLEX tableau(LDZ, N). SiJOBZ = 'V', alorsZ contient les vecteurs propres normalisés, avec le vecteur propre correspondant àW(I) stocké dans laI-ème colonne deZ. SiJOBZ = 'N', alorsZ n'est pas utilisé.

    LDZ : INTEGER. La largeur de la bande deZ.LDZ >= 1 siJOBZ = 'N';LDZ >=MAX(1, N) siJOBZ = 'V'.

    WORK : REAL tableau(LWORK). Sur la sortie,WORK(1) contient la taille requise deLWORK.

    LWORK : INTEGER. La taille de la mémoire de travailWORK. LWORK >= 1. Pour le calcul des vecteurs propres,LWORK >=2*N. SiLWORK = -1, alorsWORK(1) est rempli avec la taille requise.

    IWORK : INTEGER tableau(LIWORK). Tableau de travail d'entiers.

    LIWORK : INTEGER. La taille deIWORK.LIWORK >=N.

    INFO : INTEGER. = 0 : succès. < 0 : siINFO = -i, alors lei-ème argument était invalide. > 0 : SiINFO = 1, une décomposition de valeurs propres a échoué et lesN premiers éléments deW ne sont pas tous corrects. SiINFO = 2, la réorganisation des valeurs propres a échoué et lesN premiers éléments deW ne sont pas tous corrects.
