sous-routine sspsv (caractere uplo, entier n, entier nrhs, reel, dimension( * ) ap, entier, dimension( * ) ipiv, reel, dimension( ldb, * ) b, entier ldb, entier info)

SSPSV calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> SSPSV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique de taille N x N stockée au format compressé et X
!> et B sont des matrices de taille N x NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A en
!>    A = U * D * U**T,  si UPLO = 'U', ou
!>    A = L * D * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de permutations et de matrices triangulaires supérieures (inférieures) unitaires,
!> D est une matrice diagonale symétrique par blocs avec des blocs diagonaux de taille 1x1
!> et 2x2. La forme factorisée de A est ensuite utilisée pour
!> résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

AP

!>          AP est un tableau de type REAL, de dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, compressé par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, la matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L à partir de la factorisation
!>          A = U*D*U**T ou A = L*D*L**T calculée par SSPTRF, stockés comme
!>          une matrice triangulaire compressée dans le même format de stockage que A.
!>

IPIV

!>          IPIV est un tableau de type INTEGER, de dimension (N)
!>          Détails des échanges et de la structure par blocs de D, tels que
!>          déterminés par SSPTRF. Si IPIV(k) > 0, alors les lignes et colonnes
!>          k et IPIV(k) ont été échangées, et D(k,k) est un bloc diagonal de taille 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0,
!>          alors les lignes et colonnes k-1 et -IPIV(k) ont été échangées et
!>          D(k-1:k,k-1:k) est un bloc diagonal de taille 2x2. Si UPLO = 'L' et
!>          IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes k+1 et
!>          -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal de taille 2x2.
!>

B

!>          B est un tableau de type REAL, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de taille N x NRHS du second membre.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension de tête du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro. La factorisation
!>                a été complétée, mais la matrice diagonale par blocs D est
!>                exactement singulière, donc la solution n'a pas pu être
!>                calculée.
!>

!>

!>

!>         a22 a23 a24
!>             a33 a34     (aij = aji)
!>                 a44
!>
!>  Stockage compressé du triangle supérieur de A :
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
