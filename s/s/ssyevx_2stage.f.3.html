Documentation de la fonction/sous-routine

sous-routine ssyevx_2stage (caractère jobz, caractère range, caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel vl, réel vu, entier il, entier iu, réel abstol, entier m, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

SSYEVX_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices SY

Objectif :

!>
!> SSYEVX_2STAGE calcule des valeurs propres sélectionnées et, éventuellement, des vecteurs
!> propres d'une matrice symétrique réelle A en utilisant la technique 2stage pour
!> la réduction en matrice tridiagonale. Les valeurs propres et les vecteurs
!> propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices
!> pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' :  Calcule uniquement les valeurs propres ;
!>          = 'V' :  Calcule les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de l'indice IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' :  Le triangle supérieur de A est stocké ;
!>          = 'L' :  Le triangle inférieur de A est stocké.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA, N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N de A contient la
!>          partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N par N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          À la sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est REEL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REEL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est un ENTIER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REEL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine.  Si ABSTOL est inférieur ou
!>          égal à zéro, alors  EPS*|T|  sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          par la réduction de A en forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec le plus de précision lorsque ABSTOL
!>          est réglé sur deux fois le seuil de sous-flux 2*SLAMCH('S'), et non zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de régler ABSTOL sur
!>          2*SLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est un ENTIER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REEL, de dimension (N)
!>          À la sortie normale, les M premiers éléments contiennent les valeurs propres
!>          sélectionnées dans l'ordre croissant.
!>

Z

!>          Z est un tableau REEL, de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne parvient pas à converger, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK. LWORK >= 1, lorsque N <= 1 ;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, 8*N, dimension) où
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 3*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 3*N
!>                                   où KD est la taille du bloc de la réduction,
!>                                   FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ
!>                                   , généralement FACTOPTNB=128 est un bon choix
!>                                   NTHREADS est le nombre de threads utilisés lors de la
!>                                   compilation openMP est activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (5*N)
!>

IFAIL

!>          IFAIL

NAME

ssyevx_2stage - Ssyevx computes the eigenvalues and eigenvectors of a real symmetric matrix.

SYNOPSIS

CALL ssyevx_2stage( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, M, W, Z, LDZ, ISUPPZ, WORK, LWORK, IWORK, LIWORK, INFO )

  CHARACTER          JOBZ
  CHARACTER          RANGE
  CHARACTER          UPLO
  INTEGER            N
  REAL               A( LDA, * )
  INTEGER            LDA
  REAL               VL
  REAL               VU
  INTEGER            IL
  INTEGER            IU
  REAL               ABSTOL
  INTEGER            M
  REAL               W( * )
  REAL               Z( LDZ, * )
  INTEGER            LDZ
  INTEGER            ISUPPZ( * )
  REAL               WORK( * )
  INTEGER            LWORK
  INTEGER            IWORK( * )
  INTEGER            LIWORK
  INTEGER            INFO

Function/Subroutine Documentation

JOBZ defines whether to compute the eigenvectors of A or only the eigenvalues.

If JOBZ = 'N', then only the eigenvalues need to be computed.

If JOBZ = 'V', then the eigenvalues and the corresponding eigenvectors of A are computed.

RANGE specifies the range of eigenvalues to be computed. This is specified by all possible values of RANGE:

If RANGE = 'A', then all eigenvalues will be included.

If RANGE = 'V', then all eigenvalues lambda in the interval (VL, VU], with VL < VU, will be included.

If RANGE = 'I', then only the eigenvalues with indices IL to IU will be included, where IL and IU are integers such that 1 <= IL <= IU <= N.

Constraints:

If RANGE = 'A' or 'I', then VL and VU are not referenced.

UPLO specifies whether the matrix A is upper triangular or lower triangular. The real symmetric matrix A may be symmetric positive definite, symmetric positive semi-definite or non-symmetric definite. For UPLO = 'U' only the upper triangle of A may be referenced, and for UPLO = 'L' only the lower triangle of A may be referenced.

N is the number of columns and rows of the matrix A. N >= 0.

A is the matrix A. The dimension is LDA,N.

LDA is the leading dimension of the array A.

VL and VU specify the values bounding the interval (VL, VU] for RGINIA = 'V'.

IL and IU specify the indices of the desired eigenvalues in the range IL to IU for RGINIA = 'I'.

ABSTOL is the absolute tolerance for the eigenvalues.

M is the number of eigenvalues found.

W is the array W containing the eigenvalues.

Z is the matrix Z containing the eigenvectors.

LDZ is the leading dimension of the array Z.

ISUPPZ contains the supporting elements of the eigenvectors.

WORK is a real array used for workspace.

LWORK is the dimension of the array WORK.

IWORK is an integer array used for workspace.

LIWORK is the dimension of the array IWORK.

INFO is an integer output

If JOBZ = 'V', then if INFO = 0, the first M elements of IFAIL are zero. If INFO > 0, then IFAIL contains the indices of the eigenvectors that failed to converge. If JOBZ = 'N', then IFAIL is not referenced.

INFO

INFO is INTEGER
= 0:  successful exit
< 0:  if INFO = -i, the i-th argument had an illegal value
> 0:  if INFO = i, then i eigenvectors failed to converge.
                Their indices are stored in array IFAIL.
