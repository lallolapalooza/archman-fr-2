SSYEVR_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices SY

Documentation de fonction/sous-programme

sous-programme ssyevr_2stage (caractère jobz, caractère range, caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel vl, réel vu, entier il, entier iu, réel abstol, entier m, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, entier, dimension( * ) isuppz, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier liwork, entier info)

SSYEVR_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres pour les matrices SY en utilisant la technique des 2 étapes pour la réduction à la forme tridiagonale. Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les valeurs propres désirées.

Objectif:

!>
!> SSYEVR_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice symétrique réelle A en utilisant la technique des 2 étapes pour
!> la réduction à la forme tridiagonale. Les valeurs propres et les vecteurs propres peuvent être
!> sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les
!> valeurs propres désirées.
!>
!> SSYEVR_2STAGE réduit d'abord la matrice A à la forme tridiagonale T avec un appel
!> à SSYTRD. Ensuite, lorsque cela est possible, SSYEVR_2STAGE appelle SSTEMR pour calculer
!> le spectre des valeurs propres en utilisant des représentations relativement robustes.
!> SSTEMR calcule les valeurs propres par l'algorithme dqds, tandis que les vecteurs propres
!> orthogonaux sont calculés à partir de diverses représentations L D L^T
!> (également connues sous le nom de représentations relativement robustes). L'orthogonalisation
!> de Gram-Schmidt est évitée autant que possible. Plus précisément,
!> les différentes étapes de l'algorithme sont les suivantes.
!>
!> Pour chaque bloc non réduit (sous-matrice) de T,
!>    (a) Calculer T - sigma I  = L D L^T, de sorte que L et D
!>        définissent toutes les valeurs propres recherchées avec une haute précision relative.
!>        Cela signifie que de petites modifications relatives des entrées de D et L
!>        entraînent de petites modifications relatives des valeurs propres et
!>        des vecteurs propres. La représentation standard (non factorisée) de la
!>        matrice tridiagonale T n'a pas cette propriété en général.
!>    (b) Calculer les valeurs propres avec une précision appropriée.
!>        Si les vecteurs propres sont désirés, l'algorithme atteint une précision complète
!>        des valeurs propres calculées uniquement juste avant
!>        que les vecteurs correspondants ne doivent être calculés, voir les étapes c) et d).
!>    (c) Pour chaque cluster de valeurs propres proches, sélectionner un nouveau
!>        décalage proche du cluster, trouver une nouvelle factorisation et affiner
!>        les valeurs propres décalées avec une précision appropriée.
!>    (d) Pour chaque valeur propre avec une séparation relative suffisamment grande, calculer
!>        le vecteur propre correspondant en formant une factorisation tordue révélatrice de rang. Retourner à (c) pour les clusters restants.
!>
!> La précision souhaitée des sorties peut être spécifiée par le paramètre d'entrée
!> ABSTOL.
!>
!> Pour plus de détails, voir la documentation de SSTEMR et :
!> - Inderjit S. Dhillon et Beresford N. Parlett :
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, août 2004.
!> - Inderjit Dhillon et Beresford Parlett :  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. Également LAPACK Working Note 154.
!> - Inderjit Dhillon : ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mai 1997.
!>
!>
!> Note 1 : SSYEVR_2STAGE appelle SSTEMR lorsque le spectre complet est demandé
!> sur les machines conformes à la norme de virgule flottante ieee-754.
!> SSYEVR_2STAGE appelle SSTEBZ et SSTEIN sur les machines non-ieee et
!> lorsque des requêtes de spectre partiel sont faites.
!>
!> Une exécution normale de SSTEMR peut créer des NaNs et des infinis et
!> peut donc provoquer une erreur due à une exception de virgule flottante dans les environnements
!> qui ne gèrent pas les NaNs et les infinis selon la manière par défaut de la norme ieee.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : Toutes les valeurs propres seront trouvées.
!>          = 'V' : Toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                  seront trouvées.
!>          = 'I' : Les valeurs propres de l'indice IL à l'indice IU seront trouvées.
!>          Pour RANGE = 'V' ou 'I' et IU - IL < N - 1, SSTEBZ et
!>          SSTEIN sont appelés
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA, N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure N-par-N de A contient la
!>          partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N-par-N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>           lorsqu'il est déterminé qu'elle se situe dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors  EPS*|T|  sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si une haute précision relative est importante, réglez ABSTOL sur
!>          SLAMCH( 'Safe minimum' ). Cela garantira que
!>          les valeurs propres sont calculées avec une haute précision relative lorsque
!>          cela est possible dans les futures versions. Le code actuel ne
!>          fait aucune garantie concernant une haute précision relative, mais
!>          les futures versions le feront. Voir J. Barlow et J. Demmel,
!>          , LAPACK Working Note #7, pour une discussion
!>          sur quelles matrices définissent leurs valeurs propres avec une haute précision relative.
!>

M

p> 
!>          M est un ENTIER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REEL, de dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées par
!>          ordre croissant.
!>

Z

!>          Z est un tableau REEL, de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une limite supérieure doit être utilisée.
!>          Fournir N colonnes est toujours sûr.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ est un tableau ENTIER, de dimension ( 2*max(1,M) )
!>          Le support des vecteurs propres dans Z, c'est-à-dire les indices
!>          indiquant les éléments non nuls dans Z. Le i-ème vecteur propre
!>          n'est non nul que dans les éléments ISUPPZ( 2*i-1 ) à
!>          ISUPPZ( 2*i ). C'est une sortie de SSTEMR (matrice tridiagonale).
!>          Le support des vecteurs propres de A est typiquement 1:N en raison des
!>          transformations orthogonales appliquées par SORMTR.
!>          Implémenté uniquement pour RANGE = 'A' ou 'I' et IU - IL = N - 1
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, 26*N, dimension) où
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 5*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 5*N
!>                                   où KD est la taille de bloc de la réduction,
!>                                   FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ
!>                                   généralement FACTOPTNB=128 est un bon choix
!>                                   NTHREADS est le nombre de threads utilisés lorsque la
!>                                   compilation openMP est activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible.
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) renvoie LIWORK optimal.
!>

LIWORK

!>          LIWORK est un ENTIER
!>          La dimension du tableau IWORK.
!>          Si N <= 1, LIWORK >= 1, sinon LIWORK >= 10*N.
!>
!>          Si LIWORK = -1, alors une interrogation d'espace de travail est supposée ; la
!>          routine calcule uniquement la taille optimale du tableau IWORK,
!>          renvoie cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  Erreur interne
!>
