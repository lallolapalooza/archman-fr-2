NOM

sssd-ldap-attributes - Fournisseur LDAP SSSD : Mappage des attributs

DESCRIPTION

Cette page de manuel décrit les attributs de mappage du fournisseur LDAP de SSSD sssd-ldap(5). Reportez-vous à la page de manuel sssd-ldap(5) pour plus de détails sur les options de configuration du fournisseur LDAP SSSD.

ATTRIBUTS UTILISATEUR

ldap_user_object_class (string)

La classe d'objet d'une entrée utilisateur dans LDAP.

Par défaut : posixAccount

ldap_user_name (string)

L'attribut LDAP qui correspond au nom de connexion de l'utilisateur.

Par défaut : uid (rfc2307, rfc2307bis et IPA), sAMAccountName (AD)

ldap_user_uid_number (string)

L'attribut LDAP qui correspond à l'identifiant de l'utilisateur.

Par défaut : uidNumber

ldap_user_gid_number (string)

L'attribut LDAP qui correspond à l'identifiant du groupe principal de l'utilisateur.

Par défaut : gidNumber

ldap_user_primary_group (string)

Attribut de groupe principal Active Directory pour le mappage des identifiants. Notez que cet attribut ne doit être défini manuellement que si vous utilisez le fournisseur "ldap" avec le mappage des identifiants.

Par défaut : non défini (LDAP), primaryGroupID (AD)

ldap_user_gecos (string)

L'attribut LDAP qui correspond au champ gecos de l'utilisateur.

Par défaut : gecos

ldap_user_home_directory (string)

L'attribut LDAP qui contient le nom du répertoire personnel de l'utilisateur.

Par défaut : homeDirectory (LDAP et IPA), unixHomeDirectory (AD)

ldap_user_shell (string)

L'attribut LDAP qui contient le chemin d'accès au shell par défaut de l'utilisateur.

Par défaut : loginShell

ldap_user_uuid (string)

L'attribut LDAP qui contient l'UUID/GUID d'un objet utilisateur LDAP.

Par défaut : non défini dans le cas général, objectGUID pour AD et ipaUniqueID pour IPA

ldap_user_objectsid (string)

L'attribut LDAP qui contient l'objectSID d'un objet utilisateur LDAP. Ceci n'est généralement nécessaire que pour les serveurs Active Directory.

Par défaut : objectSid pour Active Directory, non défini pour les autres serveurs.

ldap_user_modify_timestamp (string)

L'attribut LDAP qui contient l'horodatage de la dernière modification de l'objet parent.

Par défaut : modifyTimestamp

ldap_user_shadow_last_change (string)

Lors de l'utilisation de ldap_pwd_policy=shadow, ce paramètre contient le nom d'un attribut LDAP correspondant à son homologue shadow(5) (date du dernier changement de mot de passe).

Par défaut : shadowLastChange

ldap_user_shadow_min (string)

Lors de l'utilisation de ldap_pwd_policy=shadow, ce paramètre contient le nom d'un attribut LDAP correspondant à son homologue shadow(5) (âge minimum du mot de passe).

Par défaut : shadowMin

ldap_user_shadow_max (string)

Lors de l'utilisation de ldap_pwd_policy=shadow, ce paramètre contient le nom d'un attribut LDAP correspondant à son homologue shadow(5) (âge maximum du mot de passe).

Par défaut : shadowMax

ldap_user_shadow_warning (string)

Lors de l'utilisation de ldap_pwd_policy=shadow, ce paramètre contient le nom d'un attribut LDAP correspondant à son homologue shadow(5) (période d'avertissement de mot de passe).

Par défaut : shadowWarning

ldap_user_shadow_inactive (string)

Lors de l'utilisation de ldap_pwd_policy=shadow, ce paramètre contient le nom d'un attribut LDAP correspondant à son homologue shadow(5) (période d'inactivité du mot de passe).

Par défaut : shadowInactive

ldap_user_shadow_expire (string)

Lors de l'utilisation de ldap_pwd_policy=shadow ou ldap_account_expire_policy=shadow, ce paramètre contient le nom d'un attribut LDAP correspondant à son homologue shadow(5) (date d'expiration du compte).

Par défaut : shadowExpire

ldap_user_krb_last_pwd_change (string)

Lors de l'utilisation de ldap_pwd_policy=mit_kerberos, ce paramètre contient le nom d'un attribut LDAP stockant la date et l'heure du dernier changement de mot de passe dans Kerberos.

Par défaut : krbLastPwdChange

ldap_user_krb_password_expiration (string)

Lors de l'utilisation de ldap_pwd_policy=mit_kerberos, ce paramètre contient le nom d'un attribut LDAP stockant la date et l'heure d'expiration du mot de passe actuel.

Par défaut : krbPasswordExpiration

ldap_user_ad_account_expires (string)

Lors de l'utilisation de ldap_account_expire_policy=ad, ce paramètre contient le nom d'un attribut LDAP stockant l'heure d'expiration du compte.

Par défaut : accountExpires

ldap_user_ad_user_account_control (string)

Lors de l'utilisation de ldap_account_expire_policy=ad, ce paramètre contient le nom d'un attribut LDAP stockant le champ de bits du contrôle du compte utilisateur.

Par défaut : userAccountControl

ldap_ns_account_lock (string)

Lors de l'utilisation de ldap_account_expire_policy=rhds ou équivalent, ce paramètre détermine si l'accès est autorisé ou non.

Par défaut : nsAccountLock

ldap_user_nds_login_disabled (string)

Lors de l'utilisation de ldap_account_expire_policy=nds, cet attribut détermine si l'accès est autorisé ou non.

Par défaut : loginDisabled

ldap_user_nds_login_expiration_time (string)

Lors de l'utilisation de ldap_account_expire_policy=nds, cet attribut détermine jusqu'à quelle date l'accès est accordé.

Par défaut : loginDisabled

ldap_user_nds_login_allowed_time_map (string)

Lors de l'utilisation de ldap_account_expire_policy=nds, cet attribut détermine les heures de la journée, dans la semaine, où l'accès est accordé.

Par défaut : loginAllowedTimeMap

ldap_user_principal (string)

L'attribut LDAP qui contient le nom principal d'utilisateur Kerberos (UPN) de l'utilisateur.

Par défaut : krbPrincipalName

ldap_user_extra_attrs (string)

Liste d'attributs LDAP séparés par des virgules que SSSD récupérera en plus de l'ensemble habituel d'attributs utilisateur.

La liste peut soit contenir uniquement des noms d'attributs LDAP, soit des tuples séparés par des deux-points du nom d'attribut SSSD et du nom d'attribut LDAP. Dans le cas où seul le nom de l'attribut LDAP est spécifié, l'attribut est enregistré dans le cache tel quel. L'utilisation d'un nom d'attribut SSSD personnalisé peut être requise par les environnements qui configurent plusieurs domaines SSSD avec des schémas LDAP différents.

Veuillez noter que plusieurs noms d'attributs sont réservés par SSSD, notamment l'attribut "name". SSSD signalera une erreur si l'un des noms d'attributs réservés est utilisé comme nom d'attribut supplémentaire.

Exemples :

ldap_user_extra_attrs = telephoneNumber

Enregistre l'attribut "telephoneNumber" de LDAP sous le nom "telephoneNumber" dans le cache.

ldap_user_extra_attrs = phone:telephoneNumber

Enregistre l'attribut "telephoneNumber" de LDAP sous le nom "phone" dans le cache.

Par défaut : non défini

ldap_user_ssh_public_key (string)

L'attribut LDAP qui contient les clés publiques SSH de l'utilisateur.

Par défaut : sshPublicKey

ldap_user_fullname (string)

L'attribut LDAP qui correspond au nom complet de l'utilisateur.

Par défaut : cn

ldap_user_member_of (string)

L'attribut LDAP qui liste les appartenances aux groupes de l'utilisateur.

Par défaut : memberOf

ldap_user_authorized_service (string)

Veuillez noter que l'option de configuration ldap_access_order *doit* inclure “authorized_service” pour que l'option ldap_user_authorized_service fonctionne.

Certaines distributions (telles que Fedora-29+ ou RHEL-8) incluent toujours le service PAM “systemd-user” dans le processus de connexion. Par défaut : authorizedService

ldap_user_authorized_host (string)

Si access_provider=ldap et ldap_access_order=host, SSSD utilisera la présence de l'attribut host dans l'entrée LDAP de l'utilisateur pour déterminer le privilège d'accès.

Un déni explicite (!host) est résolu en premier. Ensuite, SSSD recherche les autorisations explicites (host) et enfin allow_all (*).

Veuillez noter que l'option de configuration ldap_access_order *doit* inclure “host” pour que l'option ldap_user_authorized_host fonctionne.

Par défaut : host

ldap_user_authorized_rhost (string)

Si access_provider=ldap et ldap_access_order=rhost, SSSD utilisera la présence de l'attribut rhost dans l'entrée LDAP de l'utilisateur pour déterminer le privilège d'accès. Similairement au processus de vérification d'hôte.

Un déni explicite (!rhost) est résolu en premier. Ensuite, SSSD recherche les autorisations explicites (rhost) et enfin allow_all (*).

Veuillez noter que l'option de configuration ldap_access_order *doit* inclure “rhost” pour que l'option ldap_user_authorized_rhost fonctionne.

Par défaut : rhost

ldap_user_certificate (string)

Nom de l'attribut LDAP contenant le certificat X509 de l'utilisateur.

Par défaut : userCertificate;binary

ldap_user_email (string)

Nom de l'attribut LDAP contenant l'adresse e-mail de l'utilisateur.

Note : Si l'adresse e-mail d'un utilisateur entre en conflit avec une adresse e-mail ou un nom de domaine complet d'un autre utilisateur, alors SSSD ne sera pas en mesure de servir correctement ces utilisateurs. Cette option permet aux utilisateurs de se connecter par (1) nom d'utilisateur et (2) adresse e-mail. Si pour une raison quelconque plusieurs utilisateurs doivent partager la même adresse e-mail, définissez cette option sur un nom d'attribut inexistant afin de désactiver la recherche/connexion utilisateur par e-mail.

Par défaut : mail

ldap_user_passkey (string)

Nom de l'attribut LDAP contenant les données de mappage passkey de l'utilisateur.

Par défaut : passkey (LDAP), ipaPassKey (IPA), altSecurityIdentities (AD)

ATTRIBUTS DES GROUPES

ldap_group_object_class (string)

La classe d'objet d'une entrée de groupe dans LDAP.

Par défaut : posixGroup

ldap_group_name (string)

L'attribut LDAP qui correspond au nom du groupe. Dans un environnement avec des groupes imbriqués, cette valeur doit être un attribut LDAP qui a un nom unique pour chaque groupe. Cette exigence inclut les groupes non-POSIX dans l'arbre des groupes imbriqués.

Par défaut : cn (rfc2307, rfc2307bis et IPA), sAMAccountName (AD)

ldap_group_gid_number (string)

L'attribut LDAP qui correspond à l'identifiant du groupe.

Par défaut : gidNumber

ldap_group_member (string)

L'attribut LDAP qui contient les noms des membres du groupe.

Par défaut : memberuid (rfc2307) / member (rfc2307bis)

ldap_group_uuid (string)

L'attribut LDAP qui contient l'UUID/GUID d'un objet de groupe LDAP.

Par défaut : non défini dans le cas général, objectGUID pour AD et ipaUniqueID pour IPA

ldap_group_objectsid (string)

L'attribut LDAP qui contient l'objectSID d'un objet de groupe LDAP. Ceci n'est généralement nécessaire que pour les serveurs ActiveDirectory.

Par défaut : objectSid pour ActiveDirectory, non défini pour les autres serveurs.

ldap_group_modify_timestamp (string)

L'attribut LDAP qui contient l'horodatage de la dernière modification de l'objet parent.

Par défaut : modifyTimestamp

ldap_group_type (string)

L'attribut LDAP qui contient une valeur entière indiquant le type du groupe et éventuellement d'autres drapeaux.

Cet attribut est actuellement utilisé uniquement par le fournisseur AD pour déterminer si un groupe est un groupe local au domaine et doit être filtré pour les domaines de confiance.

Par défaut : groupType dans le fournisseur AD, sinon non défini

ldap_group_external_member (string)

L'attribut LDAP qui référence les membres de groupe définis dans un domaine externe. Pour le moment, seuls les membres externes d'IPA sont pris en charge.

Par défaut : ipaExternalMember dans le fournisseur IPA, sinon non défini.

ATTRIBUTS NETGROUP

ldap_netgroup_object_class (string)

La classe d'objet d'une entrée netgroup dans LDAP.

Dans le fournisseur IPA, ipa_netgroup_object_class doit être utilisé à la place.

Par défaut : nisNetgroup

ldap_netgroup_name (string)

L'attribut LDAP qui correspond au nom du netgroup.

Dans le fournisseur IPA, ipa_netgroup_name doit être utilisé à la place.

Par défaut : cn

ldap_netgroup_member (string)

L'attribut LDAP qui contient les noms des membres du netgroup.

Dans le fournisseur IPA, ipa_netgroup_member doit être utilisé à la place.

Par défaut : memberNisNetgroup

ldap_netgroup_triple (string)

L'attribut LDAP qui contient les triples (hôte, utilisateur, domaine) du netgroup.

Cette option n'est pas disponible dans le fournisseur IPA.

Par défaut : nisNetgroupTriple

ldap_netgroup_modify_timestamp (string)

L'attribut LDAP qui contient l'horodatage de la dernière modification de l'objet parent.

Cette option n'est pas disponible dans le fournisseur IPA.

Par défaut : modifyTimestamp

ATTRIBUTS HÔTE

ldap_host_object_class (string)

La classe d'objet d'une entrée hôte dans LDAP.

Par défaut : ipService

ldap_host_name (string)

L'attribut LDAP qui correspond au nom de l'hôte.

Par défaut : cn

ldap_host_fqdn (string)

L'attribut LDAP qui correspond au nom de domaine complet (FQDN) de l'hôte.

Par défaut : fqdn

ldap_host_serverhostname (string)

L'attribut LDAP qui correspond au nom de l'hôte.

Par défaut : serverHostname

ldap_host_member_of (string)

L'attribut LDAP qui liste les appartenances de l'hôte aux groupes.

Par défaut : memberOf

ldap_host_ssh_public_key (string)

L'attribut LDAP qui contient les clés publiques SSH de l'hôte.

Par défaut : sshPublicKey

ldap_host_uuid (string)

L'attribut LDAP qui contient l'UUID/GUID d'un objet hôte LDAP.

Par défaut : non défini

ATTRIBUTS SERVICE

ldap_service_object_class (string)

La classe d'objet d'une entrée de service dans LDAP.

Par défaut : ipService

ldap_service_name (string)

L'attribut LDAP qui contient le nom des attributs de service et leurs alias.

Par défaut : cn

ldap_service_port (string)

L'attribut LDAP qui contient le port géré par ce service.

Par défaut : ipServicePort

ldap_service_proto (string)

L'attribut LDAP qui contient les protocoles compris par ce service.

Par défaut : ipServiceProtocol

ATTRIBUTS SUDO

ldap_sudorule_object_class (string)

La classe d'objet d'une règle sudo dans LDAP.

Par défaut : sudoRole

ldap_sudorule_name (string)

L'attribut LDAP qui correspond au nom de la règle sudo.

Par défaut : cn

ldap_sudorule_command (string)

L'attribut LDAP qui correspond au nom de la commande.

Par défaut : sudoCommand

ldap_sudorule_host (string)

L'attribut LDAP qui correspond au nom d'hôte (ou adresse IP d'hôte, réseau IP d'hôte, ou netgroup d'hôte)

Par défaut : sudoHost

ldap_sudorule_user (string)

L'attribut LDAP qui correspond au nom d'utilisateur (ou UID, nom de groupe, ou netgroup de l'utilisateur)

Par défaut : sudoUser

ldap_sudorule_option (string)

L'attribut LDAP qui correspond aux options sudo.

Par défaut : sudoOption

ldap_sudorule_runasuser (string)

L'attribut LDAP qui correspond au nom d'utilisateur sous lequel les commandes peuvent être exécutées.

Par défaut : sudoRunAsUser

ldap_sudorule_runasgroup (string)

L'attribut LDAP qui correspond au nom de groupe ou GID de groupe sous lequel les commandes peuvent être exécutées.

Par défaut : sudoRunAsGroup

ldap_sudorule_notbefore (string)

L'attribut LDAP qui correspond à la date/heure de début pendant laquelle la règle sudo est valide.

Par défaut : sudoNotBefore

ldap_sudorule_notafter (string)

L'attribut LDAP qui correspond à la date/heure d'expiration, après laquelle la règle sudo ne sera plus valide.

Par défaut : sudoNotAfter

ldap_sudorule_order (string)

L'attribut LDAP qui correspond à l'indice d'ordre de la règle.

Par défaut : sudoOrder

AUTOFS ATTRIBUTS

ldap_autofs_map_object_class (string)

La classe d'objet d'une entrée de carte automount dans LDAP.

Par défaut : nisMap (rfc2307, autofs_provider=ad), sinon automountMap

ldap_autofs_map_name (string)

Le nom d'une entrée de la carte automount dans LDAP.

Par défaut : nisMapName (rfc2307, autofs_provider=ad), sinon automountMapName

ldap_autofs_entry_object_class (string)

La classe d'objet d'une entrée automount dans LDAP. L'entrée correspond généralement à un point de montage.

Par défaut : nisObject (rfc2307, autofs_provider=ad), sinon automount

ldap_autofs_entry_key (string)

La clé d'une entrée automount dans LDAP. L'entrée correspond généralement à un point de montage.

Par défaut : cn (rfc2307, autofs_provider=ad), sinon automountKey

ldap_autofs_entry_value (string)

La clé d'une entrée automount dans LDAP. L'entrée correspond généralement à un point de montage.

Par défaut : nisMapEntry (rfc2307, autofs_provider=ad), sinon automountInformation

ldap_iphost_object_class (string)

ldap_iphost_name (string)

Par défaut : cn

ldap_iphost_number (string)

L'attribut LDAP qui contient l'adresse IP de l'hôte.

Par défaut : ipHostNumber

ldap_ipnetwork_object_class (string)

La classe d'objet d'une entrée ipnetwork dans LDAP.

Par défaut : ipNetwork

ldap_ipnetwork_name (string)

L'attribut LDAP qui contient le nom des attributs IP réseau et leurs alias.

ldap_ipnetwork_number (string)

Par défaut : ipNetworkNumber
