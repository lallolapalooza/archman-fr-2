Documentation de la fonction/sous-programme

sous-programme sstech (integer n, real, dimension( * ) a, real, dimension( * ) b, real, dimension( * ) eig, real tol, real, dimension( * ) work, integer info)

SSTECH

Objectif :

!>
!>    Soit T la matrice tridiagonale avec les entrées diagonales A(1) ,...,
!>    A(N) et les entrées non diagonales B(1) ,..., B(N-1)).  SSTECH vérifie
!>    si EIG(1) ,..., EIG(N) sont bien des valeurs propres précises de T.
!>    Il le fait en développant chaque EIG(I) dans un intervalle
!>    [SVD(I) - EPS, SVD(I) + EPS], en fusionnant les intervalles qui se
!>    chevauchent le cas échéant, et en utilisant des suites de Sturm pour
!>    compter et vérifier si chaque intervalle résultant contient le bon
!>    nombre de valeurs propres (en utilisant SSTECT). Ici EPS = TOL*MACHEPS*MAXEIG,
!>    où MACHEPS est la précision machine et MAXEIG est la valeur absolue
!>    de la plus grande valeur propre. Si chaque intervalle contient le bon
!>    nombre de valeurs propres, INFO = 0 est renvoyé, sinon INFO est
!>    l'indice de la première valeur propre dans le premier intervalle incorrect.
!>

Paramètres

N 
!>          N est un entier
!>          La dimension de la matrice tridiagonale T.
!>

A

!>          A est un tableau REEL, dimension (N)
!>          Les entrées diagonales de la matrice tridiagonale T.
!>

B

!>          B est un tableau REEL, dimension (N-1)
!>          Les entrées non diagonales de la matrice tridiagonale T.
!>

EIG

!>          EIG est un tableau REEL, dimension (N)
!>          Les valeurs propres présumées à vérifier.
!>

TOL

!>          TOL est un REEL
!>          Tolérance d'erreur pour la vérification, un multiple de la
!>          précision machine.
!>

WORK

!>          WORK est un tableau REEL, dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          0  si toutes les valeurs propres sont correctes (à +/-
!>             1 * TOL*MACHEPS*MAXEIG)
!>          >0 si l'intervalle contenant la INFO-ème valeur propre
!>             contient le mauvais nombre de valeurs propres.
!>
