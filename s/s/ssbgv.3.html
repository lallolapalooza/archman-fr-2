sous-programme ssbgv (caractère jobz, caractère uplo, entier n, entier ka, entier kb, réel, dimension( ldab, * ) ab, entier ldab, réel, dimension( ldbb, * ) bb, entier ldbb, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier info)

SSBGV

But:

!>
!> SSBGV calcule toutes les valeurs propres, et éventuellement, les vecteurs propres
!> d'un problème de valeurs propres généralisé symétrique-défini réel
!> de la forme A*x=(lambda)*B*x. Ici A et B sont supposés symétriques
!> et à bande, et B est également définie positive.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer seulement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KA >= 0.
!>

KB

!>          KB est INTEGER
!>          Le nombre de superdiagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KB >= 0.
!>

AB

!>          AB est tableau de type REAL, dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les ka+1 premières lignes du tableau. La
!>          colonne j de A est stockée dans la colonne j du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          En sortie, le contenu de AB est détruit.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

BB

!>          BB est tableau de type REAL, dimension (LDBB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique B, stocké dans les kb+1 premières lignes du tableau. La
!>          colonne j de B est stockée dans la colonne j du tableau BB
!>          comme suit :
!>          si UPLO = 'U', BB(kb+1+i-j,j) = B(i,j) pour max(1,j-kb)<=i<=j ;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) pour j<=i<=min(n,j+kb).
!>
!>          En sortie, le facteur S de la factorisation Cholesky éclatée
!>          B = S**T*S, tel que retourné par SPBSTF.
!>

LDBB

!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!>

W

!>          W est tableau de type REAL, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est tableau de type REAL, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres, avec la colonne i de Z contenant le
!>          vecteur propre associé à W(i). Les vecteurs propres sont
!>          normalisés de telle sorte que Z**T*B*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= N.
!>

WORK

!>          WORK est tableau de type REAL, dimension (3*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, et i est :
!>             <= N:  l'algorithme n'a pas convergé :
!>                    i éléments hors diagonale d'une forme
!>                    triangulaire intermédiaire n'ont pas convergé vers zéro ;
!>             > N:   si INFO = N + i, pour 1 <= i <= N, alors SPBSTF
!>                    a retourné INFO = i : B n'est pas définie positive.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
