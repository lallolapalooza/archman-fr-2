SSTT21

Documentation de la fonction/sous-routine

sous-routine sstt21 (integer n, integer kband, real, dimension( * ) ad, real, dimension( * ) ae, real, dimension( * ) sd, real, dimension( * ) se, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) work, real, dimension( 2 ) result)

SSTT21

Objectif :

!>
!> SSTT21 vérifie une décomposition de la forme
!>
!>    A = U S U'
!>
!> où ' signifie transposée, A est tridiagonale symétrique, U est orthogonale,
!> et S est diagonale (si KBAND=0) ou tridiagonale symétrique (si KBAND=1).
!> Deux tests sont effectués :
!>
!>    RESULT(1) = | A - U S U' | / ( |A| n ulp )
!>
!>    RESULT(2) = | I - UU' | / ( n ulp )
!>

Paramètres

N 
!>          N est un entier (INTEGER).
!>          La taille de la matrice. Si elle est nulle, SSTT21 ne fait rien.
!>          Elle doit être au moins zéro.
!>

KBAND

!>          KBAND est un entier (INTEGER).
!>          La largeur de bande de la matrice S. Elle ne peut être que zéro ou un.
!>          Si elle est zéro, alors S est diagonale et SE n'est pas référencé. Si
!>          elle est un, alors S est tridiagonale symétrique.
!>

AD

!>          AD est un tableau de réels (REAL array), dimension (N).
!>          La diagonale de la matrice A originale (non factorisée). A
!>          est supposée être tridiagonale symétrique.
!>

AE

!>          AE est un tableau de réels (REAL array), dimension (N-1).
!>          La sous-diagonale de la matrice A originale (non factorisée). A
!>          est supposée être tridiagonale symétrique. AE(1) est l'élément (1,2)
!>          et (2,1), AE(2) est l'élément (2,3) et (3,2), etc.
!>

SD

!>          SD est un tableau de réels (REAL array), dimension (N).
!>          La diagonale de la matrice S (tri-)diagonale symétrique.
!>

SE

!>          SE est un tableau de réels (REAL array), dimension (N-1).
!>          La sous-diagonale de la matrice S (tri-)diagonale symétrique.
!>          Non référencé si KBSND=0. Si KBAND=1, alors AE(1) est l'élément
!>          (1,2) et (2,1), SE(2) est l'élément (2,3) et (3,2), etc.
!>

U

!>          U est un tableau de réels (REAL array), dimension (LDU, N).
!>          La matrice orthogonale dans la décomposition.
!>

LDU

!>          LDU est un entier (INTEGER).
!>          La dimension principale de U. LDU doit être au moins N.
!>

WORK

!>          WORK est un tableau de réels (REAL array), dimension (N*(N+1)).
!>

RESULT

!>          RESULT est un tableau de réels (REAL array), dimension (2).
!>          Les valeurs calculées par les deux tests décrits ci-dessus. Les
!>          valeurs sont actuellement limitées à 1/ulp, pour éviter les dépassements.
!>          RESULT(1) est toujours modifié.
!>
