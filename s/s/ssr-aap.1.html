NOM

SSR - page de manuel pour le rendu AAP

SYNTAXE

ssr-aap [OPTIONS] <fichier-scène>

DESCRIPTION

Le SoundScape Renderer (SSR) est un outil de reproduction audio spatiale en temps réel fournissant une variété d'algorithmes de rendu.

OPTIONS

Options spécifiques au rendeur :

--hrirs=FICHIER
Charge les HRIRs pour le rendu binaural depuis FICHIER
--hrir-size=N
Tronque les HRIRs à la longueur N
--prefilter=FICHIER
Charge le préfiltre WFS depuis FICHIER
-o, --ambisonics-order=VALEUR
Ordre d'ambisonie à utiliser pour AAP (défaut : maximum)
--in-phase-rendering
Utilise le rendu en phase pour le rendeur AAP

Options JACK :

-n, --name=NOM
Définit le nom du client JACK à NOM
--input-prefix=PREFIXE
Préfixe des ports d'entrée (défaut : "system:capture_")
--output-prefix=PREFIXE
Préfixe des ports de sortie (défaut : "system:playback_")
-f, --freewheel
Utilise JACK en mode freewheeling

Options générales :

-c, --config=FICHIER
Lit la configuration depuis FICHIER
-s, --setup=FICHIER
Charge la configuration de reproduction depuis FICHIER
--threads=N
Nombre de threads audio (défaut : auto)
-r, --record=FICHIER
Enregistre la sortie audio du rendeur dans FICHIER
--decay-exponent=VALEUR
Exposant déterminant la décroissance de l'amplitude (défaut : 1) (désactivé à la compilation !)
--loop
Répète tous les fichiers audio en boucle
--master-volume-correction=VALEUR
Correction du volume master en dB (défaut : 0 dB)
--auto-rotation Fait pivoter automatiquement l'orientation des sources sonores vers la
référence
--no-auto-rotation
Ne pas faire pivoter automatiquement l'orientation des sources sonores vers la référence
-i, --ip-server
Démarre le serveur IP (non activé à la compilation !)
-I, --no-ip-server
Ne pas démarrer le serveur IP (défaut)
--websocket-server
Démarre le serveur WebSocket (non activé à la compilation !)
--no-websocket-server
Ne pas démarrer le serveur WebSocket (défaut)
--fudi-server
Démarre le serveur FUDI (non activé à la compilation !)
--no-fudi-server
Ne pas démarrer le serveur FUDI (défaut)
--follow
Attend qu'une autre instance de SSR se connecte
--no-follow
Ne pas suivre une autre instance de SSR (défaut)
-g, --gui
Démarre l'interface graphique (non activée à la compilation !)
-G, --no-gui
Ne pas démarrer l'interface graphique (défaut)
-t, --tracker=TYPE
Sélectionne le tracker de tête, valeur(s) possible(s) : fastrak patriot razor
--tracker-port=PORT
Nom/numéro de port du tracker de tête, ex: /dev/ttyS1
-T, --no-tracker
N'utilise pas de tracker de tête (défaut)
-h, --help
Affiche l'aide et quitte
-v, --verbose
Augmente le niveau de verbosité (jusqu'à -vvv)
-V, --version
Affiche les informations de version et quitte

    NOM

    ssr-aap - utility for managing Secure Socket Relay (SSR) configurations

    SYNOPIS

    ssr-aap [OPTIONS] <commande> [arguments]

    DESCRIPTION

    ssr-aap is a command-line utility for managing Secure Socket Relay (SSR) configurations. It allows users to easily create, modify, delete, and manage SSR configuration files and profiles.

    SSR is a proxy application that can bypass network censorship and restrictions. ssr-aap simplifies the process of setting up and using SSR.

    OPTIONS

    -h, --help
    Show help message and exit.
    -v, --version
    Show program's version number and exit.
    --config <fichier>
    Specify a custom configuration file path.

    COMMANDES

    ssr-aap supports the following commands:

    add
    Add a new SSR configuration.
    list
    List all available SSR configurations.
    edit <nom>
    Edit an existing SSR configuration.
    remove <nom>
    Remove an SSR configuration.
    start <nom>
    Start an SSR client with the specified configuration.
    stop
    Stop the running SSR client.
    status
    Show the status of the SSR client.

    EXEMPLES

    # Add a new SSR configuration
ssr-aap add

# List all SSR configurations
ssr-aap list

# Start an SSR client with a configuration named 'my_ssr'
ssr-aap start my_ssr

# Stop the SSR client
ssr-aap stop
