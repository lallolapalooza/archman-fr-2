NOM

sssd_krb5_localauth_plugin - Plugin d'autorisation locale Kerberos

DESCRIPTION

Le plugin d'autorisation locale Kerberos sssd_krb5_localauth_plugin est utilisé par libkrb5 pour trouver le nom local d'un principal Kerberos donné ou pour vérifier si un nom local donné et un principal Kerberos donné sont liés l'un à l'autre.

SSSD gère les noms locaux des utilisateurs provenant d'une source distante et peut également lire le nom du principal utilisateur Kerberos depuis la source distante. Avec ces informations, SSSD peut facilement gérer les correspondances mentionnées ci-dessus, même si le nom local et le principal Kerberos diffèrent considérablement.

De plus, avec les informations lues depuis la source distante, SSSD peut aider à prévenir des correspondances inattendues ou indésirables si la partie utilisateur du principal Kerberos correspond accidentellement à un nom local d'un utilisateur différent. Par défaut, libkrb5 pourrait simplement supprimer la partie domaine du principal Kerberos pour obtenir le nom local, ce qui entraînerait de mauvaises correspondances dans ce cas.

CONFIGURATION

Le plugin d'autorisation locale Kerberos doit être explicitement activé dans la configuration Kerberos, voir krb5.conf(5). SSSD créera un extrait de configuration avec un contenu tel que, par exemple :

[plugins]
 localauth = {
  module = sssd:/usr/lib64/sssd/modules/sssd_krb5_localauth_plugin.so
 }

automatiquement dans le répertoire des extraits de configuration Kerberos public de SSSD. Si ce répertoire est inclus dans la configuration Kerberos locale, le plugin sera activé automatiquement.
