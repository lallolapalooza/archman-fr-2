Documentation de la fonction/sous-routine

sous-routine ssyconvf (caractère uplo, caractère way, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) e, entier, dimension( * ) ipiv, entier info)

SSYCONVF

Objectif:

!> Si le paramètre WAY = 'C':
!> SSYCONVF convertit le format de sortie de factorisation utilisé dans
!> SSYTRF fourni en entrée dans le paramètre A vers le format de sortie de factorisation
!> utilisé dans SSYTRF_RK (ou SSYTRF_BK) qui est stocké en sortie dans les paramètres A et E.
!> Il convertit également sur place les détails des échanges stockés dans IPIV
!> du format utilisé dans SSYTRF vers le format utilisé dans SSYTRF_RK (ou SSYTRF_BK).
!>
!> Si le paramètre WAY = 'R':
!> SSYCONVF effectue la conversion en sens inverse, c'est-à-dire qu'il convertit
!> le format de sortie de factorisation utilisé dans SSYTRF_RK
!> (ou SSYTRF_BK) fourni en entrée dans les paramètres A et E vers le format de sortie de factorisation
!> utilisé dans SSYTRF qui est stocké en sortie dans le paramètre A.
!> Il convertit également sur place les détails des échanges stockés dans IPIV
!> du format utilisé dans SSYTRF_RK (ou SSYTRF_BK) vers le format utilisé dans SSYTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure A.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

WAY

!>          WAY est CHARACTER*1
!>          = 'C': Convertir
!>          = 'R': Revert (Annuler la conversion)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est tableau de REAL, dimension (LDA,N)
!>
!>          1) Si WAY ='C':
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF:
!>            a) tous les éléments de la matrice symétrique bloc-diagonale
!>               D sur la diagonale de A et sur la surdiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U': multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie surdiagonale de A.
!>               Si UPLO = 'L': multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sous-diagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF_RK ou SSYTRF_BK:
!>            a) SEULEMENT les éléments diagonaux de la matrice symétrique bloc-diagonale
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U': le facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L': le facteur L dans la partie sous-diagonale de A.
!>
!>          2) Si WAY = 'R':
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF_RK ou SSYTRF_BK:
!>            a) SEULEMENT les éléments diagonaux de la matrice symétrique bloc-diagonale
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U': le facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L': le facteur L dans la partie sous-diagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF:
!>            a) tous les éléments de la matrice symétrique bloc-diagonale
!>               D sur la diagonale de A et sur la surdiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U': multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie surdiagonale de A.
!>               Si UPLO = 'L': multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est tableau de REAL, dimension (N)
!>
!>          1) Si WAY ='C':
!>
!>          En entrée, juste un espace de travail.
!>
!>          En sortie, contient les éléments surdiagonaux (ou sous-diagonaux)
!>          de la matrice symétrique bloc-diagonale D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) est mis à 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          2) Si WAY = 'R':
!>
!>          En entrée, contient les éléments surdiagonaux (ou sous-diagonaux)
!>          de la matrice symétrique bloc-diagonale D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) non référencé;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) non référencé.
!>
!>          En sortie, n'est pas modifié.
!>

IPIV

!>          IPIV est tableau de INTEGER, dimension (N)
!>
!>          1) Si WAY ='C':
!>          En entrée, détails des échanges et de la structure bloc de D dans le format utilisé dans SSYTRF.
!>          En sortie, détails des échanges et de la structure bloc de D dans le format utilisé dans SSYTRF_RK
!>          ( ou SSYTRF_BK).
!>
!>          1) Si WAY ='R':
!>          En entrée, détails des échanges et de la structure bloc de D dans le format utilisé dans SSYTRF_RK
!>          ( ou SSYTRF_BK).
!>          En sortie, détails des échanges et de la structure bloc de D dans le format utilisé dans SSYTRF.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
