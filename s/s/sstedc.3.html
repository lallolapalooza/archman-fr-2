SSTEDC

Documentation de la fonction/sous-routine

sous-routine sstedc (character compz, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSTEDC

Objectif :

!>
!> SSTEDC calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique en utilisant la méthode diviser pour régner.
!> Les vecteurs propres d'une matrice symétrique pleine ou bande peuvent également
!> être trouvés si SSYTRD ou SSPTRD ou SSBTRD a été utilisé pour réduire cette
!> matrice à une forme tridiagonale.
!>
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres.
!>          = 'I':  Calculer également les vecteurs propres de la matrice tridiagonale.
!>          = 'V':  Calculer également les vecteurs propres de la matrice symétrique
!>                  originale dense. À l'entrée, Z contient la matrice orthogonale
!>                  utilisée pour réduire la matrice originale à une forme tridiagonale.
!>

N

!>          N est INTEGER
!>          La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres en ordre croissant.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>          À l'entrée, les éléments sous-diagonaux de la matrice tridiagonale.
!>          À la sortie, E a été détruit.
!>

Z

!>          Z est un tableau REAL, dimension (LDZ,N)
!>          À l'entrée, si COMPZ = 'V', alors Z contient la matrice orthogonale
!>          utilisée dans la réduction à la forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormés de la matrice symétrique originale,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormés
!>          de la matrice tridiagonale symétrique.
!>          Si  COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1.
!>          Si des vecteurs propres sont désirés, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si COMPZ = 'N' ou N <= 1 alors LWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1 alors LWORK doit être au moins
!>                         ( 1 + 3*N + 2*N*lg N + 4*N**2 ),
!>                         où lg( N ) = plus petit entier k tel que
!>                         2**k >= N.
!>          Si COMPZ = 'I' et N > 1 alors LWORK doit être au moins
!>                         ( 1 + 4*N + N**2 ).
!>          Noter que pour COMPZ = 'I' ou 'V', alors si N est inférieur ou
!>          égal à la taille minimale de division, généralement 25, alors LWORK doit
!>          seulement être max(1,2*(N-1)).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient la valeur optimale de LIWORK.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si COMPZ = 'N' ou N <= 1 alors LIWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1 alors LIWORK doit être au moins
!>                         ( 6 + 6*N + 5*N*lg N ).
!>          Si COMPZ = 'I' et N > 1 alors LIWORK doit être au moins
!>                         ( 3 + 5*N ).
!>          Noter que pour COMPZ = 'I' ou 'V', alors si N est inférieur ou
!>          égal à la taille minimale de division, généralement 25, alors LIWORK
!>          doit seulement être 1.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement la taille optimale du tableau IWORK,
!>          renvoie cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  terminaison réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  L'algorithme n'a pas réussi à calculer une valeur propre lors de
!>                l'exécution sur la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) jusqu'à mod(INFO,N+1).
!>
