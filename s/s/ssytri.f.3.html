Documentation de la fonction/sous-programme

sous-routine ssytri (caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, réel, dimension( * ) work, entier info)

SSYTRI

Objectif :

!>
!> SSYTRI calcule l'inverse d'une matrice réelle symétrique indéfinie
!> A en utilisant la factorisation A = U*D*U**T ou A = L*D*L**T calculée par
!> SSYTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure, forme A = U*D*U**T ;
!>          = 'L' : Triangulaire inférieure, forme A = L*D*L**T.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          À l'entrée, la matrice diagonale par blocs D et les multiplicateurs
!>          utilisés pour obtenir le facteur U ou L calculés par SSYTRF.
!>
!>          À la sortie, si INFO = 0, l'inverse (symétrique) de la matrice
!>          originale. Si UPLO = 'U', la partie triangulaire supérieure de
!>          l'inverse est formée et la partie de A sous la diagonale n'est
!>          pas référencée ; si UPLO = 'L', la partie triangulaire inférieure
!>          de l'inverse est formée et la partie de A au-dessus de la
!>          diagonale n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et structure du bloc D
!>          tels que déterminés par SSYTRF.
!>

WORK

!>          WORK est un tableau REEL, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
