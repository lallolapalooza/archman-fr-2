SSH-VERSION(1) Commandes utilisateur SSH-VERSION(1)

NOM

ssh-version

SYNTAXE

ssh-version [OPTIONS] nom_hote

DESCRIPTION

affiche la version du serveur SSH auquel vous vous connectez

EXEMPLES

ssh-version 127.0.0.1
ssh-version -p 35007 127.0.0.1
