Documentation de Fonction/Sous-programme

subroutine ssyconvf_rook (character uplo, character way, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) e, integer, dimension( * ) ipiv, integer info)

SSYCONVF_ROOK

But:

!> Si le paramètre WAY = 'C':
!> SSYCONVF_ROOK convertit le format de sortie de la factorisation utilisé dans
!> SSYTRF_ROOK fourni en entrée dans le paramètre A en format de sortie de la factorisation utilisé dans
!> SSYTRF_RK (ou SSYTRF_BK) qui est stocké en sortie dans les paramètres A et E. Le format IPIV pour SSYTRF_ROOK et
!> SSYTRF_RK (ou SSYTRF_BK) est le même et n'est pas converti.
!>
!> Si le paramètre WAY = 'R':
!> SSYCONVF_ROOK effectue la conversion en sens inverse, c'est-à-dire
!> convertit le format de sortie de la factorisation utilisé dans SSYTRF_RK
!> (ou SSYTRF_BK) fourni en entrée dans les paramètres A et E en
!> format de sortie de la factorisation utilisé dans SSYTRF_ROOK qui est stocké
!> en sortie dans le paramètre A. Le format IPIV pour SSYTRF_ROOK et
!> SSYTRF_RK (ou SSYTRF_BK) est le même et n'est pas converti.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure A.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

WAY

!>          WAY est CHARACTER*1
!>          = 'C': Convertir
!>          = 'R': Revertir
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, de dimension (LDA,N)
!>
!>          1) Si WAY ='C':
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF_ROOK:
!>            a) tous les éléments de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A et sur la surdiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U': multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie surdiagonale de A.
!>               Si UPLO = 'L': multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie surdiagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF_RK ou SSYTRF_BK:
!>            a) UNIQUEMENT les éléments diagonaux de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U': facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L': facteur L dans la partie sous-diagonale de A.
!>
!>          2) Si WAY = 'R':
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF_RK ou SSYTRF_BK:
!>            a) UNIQUEMENT les éléments diagonaux de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U': facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L': facteur L dans la partie sous-diagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          SSYTRF_ROOK:
!>            a) tous les éléments de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A et sur la surdiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U': multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie surdiagonale de A.
!>               Si UPLO = 'L': multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie surdiagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau REAL, de dimension (N)
!>
!>          1) Si WAY ='C':
!>
!>          En entrée, simplement un espace de travail.
!>
!>          En sortie, contient les éléments surdiagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) est mis à 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          2) Si WAY = 'R':
!>
!>          En entrée, contient les éléments surdiagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) non référencé;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) non référencé.
!>
!>          En sortie, n'est pas modifié.
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          En entrée, détails des échanges et de la structure par blocs de D tels que déterminés:
!>          1) par SSYTRF_ROOK, si WAY ='C';
!>          2) par SSYTRF_RK (ou SSYTRF_BK), si WAY ='R'.
!>          Le format IPIV est le même pour toutes ces routines.
!>
!>          En sortie, n'est pas modifié.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
