NOM

ssconvert - un convertisseur de format de tableur en ligne de commande

SYNTAXE

ssconvert [OPTIONS] infile outfile

ssconvert [OPTIONS] --merge-to outfile infile1 infile2 ...

DESCRIPTION

ssconvert est un utilitaire en ligne de commande pour convertir des fichiers de tableur entre divers formats de fichiers de tableur. C'est un utilitaire compagnon de Gnumeric, le puissant programme tableur créé par le projet GNOME.

ssconvert accepte des noms de fichiers ou des URI comme infile et outfile. Les URI spéciales fd://0 et fd://1 peuvent être utilisées pour l'entrée standard et la sortie standard respectivement.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options d'une seule lettre commençant par un tiret (`-') et des options plus longues commençant par deux tirets (`--').

Options principales

--recalc
Recalculer toutes les cellules avant d'écrire le résultat.
--set CELL=CONTENTS
Définir la valeur de CELL à CONTENTS. Pour mettre une expression dans une cellule, ajoutez un signe égal supplémentaire, par exemple --set "A11==A10+1". Cette option peut être répétée autant de fois que nécessaire. Le classeur sera recalculé après que toutes les cellules aient été définies, à condition que le classeur soit configuré pour le recalcul automatique. Sinon, le recalcul peut être forcé avec --recalc.
-v, --verbose
Être un peu plus bavard sur ce qui se passe.
--list-exporters
Lister les exportateurs disponibles (formats de fichiers pouvant être écrits).
-T, --export-type=ID
Spécifier quel exportateur utiliser ; voir ci-dessous pour une liste. Ceci n'est nécessaire que lorsque le bon format ne découle pas du nom du fichier de sortie. La liste des formats d'exportation disponibles peut être générée en utilisant l'option --list-exporters. Cependant, lorsque l'exportation d'images est demandée en utilisant l'option --export-graphs, la liste des formats d'image doit être consultée à la place. Cette liste peut être générée en utilisant l'option --list-image-formats.
-O, --export-options=optionsstring
Spécifier des paramètres pour l'exportateur choisi. optionsstring est une liste de paires paramètre=valeur, séparées par des espaces. Les noms des paramètres et les valeurs autorisées sont spécifiques à l'exportateur et sont documentés ci-dessous. Plusieurs paramètres peuvent être spécifiés
--export-graphs
Exporter les graphiques (ou diagrammes) à l'intérieur du tableur d'entrée vers des fichiers image numérotés (SVG par défaut). La liste des formats d'image disponibles peut être imprimée avec --list-image-formats
--list-importers
Lister les importateurs disponibles (formats de fichiers pouvant être lus). -I, --import-type=ID Spécifier quel importateur utiliser ; voir ci-dessous pour une liste. Ceci n'est nécessaire que lorsque le bon format ne découle pas du nom du fichier d'entrée.
--list-image-formats
Lister les formats d'image disponibles pour l'exportation de graphiques
-E, --import-encoding=STRING
Spécifier un encodage pour le contenu importé.
-M, --merge-to=FILENAME
Fusionner une collection de classeurs en un seul. La taille des feuilles sera étendue pour correspondre à la plus grande de tous les classeurs. Les noms dans la portée des classeurs individuels se retrouveront dans la portée du classeur fusionné. La fusion sera annulée en cas de conflits de noms.
-S, --export-file-per-sheet
Exporter un fichier pour chaque feuille si l'exportateur ne prend en charge qu'une seule feuille à la fois. Le nom du fichier de sortie est traité comme un modèle dans lequel le numéro de feuille est substitué par %n, le nom de la feuille est substitué par %s, et le nom de l'objet de la feuille est substitué par %o en cas d'exportation de graphique. S'il n'y a pas de substitutions, un défaut de ".%n" est ajouté.

Options d'aide

--version
Afficher la version de ssconvert.
-h, --help, --usage
Afficher un bref message d'utilisation.
--help-all
Afficher toutes les options d'aide.
--help-libspreadsheet
Afficher les options de Gnumeric.

OPTIONS POUR LE FORMAT DE DOCUMENT PORTABLE (*.pdf) EXPORTATEUR

sheet
Nom de la feuille du classeur sur laquelle opérer. Vous pouvez spécifier plusieurs feuilles en répétant cette option. Ceci est ignoré si l'option object est donnée.
active-sheet
Sélectionne la feuille active sur laquelle opérer. La valeur de cette option est sans importance, mais le signe égal est obligatoire.
object
Nom de l'objet de feuille à imprimer. Si cette option est donnée, toute option sheet est ignorée. Seul le premier object donné est exporté.
paper
Taille du papier. Les valeurs valides incluent "A4" pour ISO A4 et "na_letter_8.5x11in" pour US Letter. Si un graphique individuel est spécifié via l'option object, alors une taille de papier "fit" réduit la taille du papier à celle du graphique.

OPTIONS POUR L'EXPORTATEUR TEXTE CONFIGURABLE (*.txt)

sheet
Nom de la feuille du classeur sur laquelle opérer. Vous pouvez spécifier plusieurs feuilles en répétant cette option.
active-sheet
Sélectionne la feuille active sur laquelle opérer. La valeur de cette option est sans importance, mais le signe égal est obligatoire.
eol
Convention de fin de ligne ; comment les lignes sont terminées. "unix" pour linefeed, "mac" pour retour chariot ; "windows" pour retour chariot plus linefeed.
charset
Le codage des caractères de la sortie. Par défaut UTF-8.
locale
La locale à utiliser pour le formatage des nombres et des dates. Par défaut, la locale actuelle telle que rapportée par locale(1). Consultez la sortie de locale -a pour connaître les valeurs acceptables.
quote
Le caractère ou la chaîne utilisée pour l'encadrement des champs. Par défaut, "\"" (guillemet double).
separator
La chaîne utilisée pour séparer les champs. Par défaut, l'espace.
format
Comment les cellules doivent être formatées. Valeurs acceptables : "automatic" (appliquer le formatage automatique ; par défaut), "raw" (afficher les données brutes, non formatées), ou "preserve" (préserver le formatage du document source).

Ceci traite de la différence entre le contenu d'une cellule et la manière dont ce contenu est formaté.

Considérez une cellule dans un document d'entrée Gnumeric qui a été entrée comme "4/19/73" dans une locale américaine, avec un format défini sur "d-mmm-yyyy" et donc formatée en "19-Apr-1973".

Avec le réglage par défaut format de "automatic", elle sera affichée sous forme de "1973/04/19". Avec "preserve", le formatage sera préservé et elle sera affichée sous forme de "19-Apr-1973". Avec "raw", elle sera affichée sous forme de "26773" (représentation interne de Gnumeric : jours depuis une époque).

transliterate-mode
Comment gérer les caractères non représentables, c'est-à-dire les caractères qui ne peuvent pas être représentés dans le jeu de caractères de sortie choisi. Valeurs acceptables : "transliterate" ou "escape". La première réécrit les caractères qui ne peuvent pas être représentés dans le jeu de caractères de sortie en une approximation avec un ou plusieurs caractères qui le peuvent. Voir iconv(1) pour plus de détails. Par défaut, "escape" remplacera un caractère non représentable par une séquence d'échappement identifiant le point de code unicode.
quoting-mode
Quand les données doivent-elles être mises entre guillemets ? "never", "auto" (met des guillemets là où c'est nécessaire), ou "always". Par défaut "auto".
quoting-on-whitespace
Contrôle si les espaces blancs initiaux ou terminaux forcent la mise entre guillemets. Par défaut TRUE.

EXEMPLE

Pour convertir le fichier Gnumeric foo.gnumeric en un fichier au format Microsoft Excel(TM) foo.xls :

ssconvert foo.gnumeric foo.xls

Le format d'exportation peut être spécifié explicitement, pour outrepasser le défaut (qui est basé sur l'extension du fichier) :

ssconvert --export-type=Gnumeric_stf:stf_csv foo.xls foo.txt

Pour convertir un fichier au format Excel statfuns.xls en un fichier texte, en spécifiant le point-virgule comme caractère séparateur :

ssconvert -O 'separator=; format=raw' samples/excel/statfuns.xls statfuns.txt

Pour exporter les graphiques du fichier d'entrée input.gnumeric en fichiers SVG numérotés :

ssconvert --export-graphs input.gnumeric 'output.%n.svg'

Pour exporter les graphiques du fichier d'entrée input.gnumeric en fichiers PNG numérotés

:

ssconvert --export-type=png --export-graphs input.gnumeric 'output.%n.png'
