Documentation Fonction/Sous-routine

sous-routine sspt01 (caractère uplo, entier n, réel, dimension( * ) a, réel, dimension( * ) afac, entier, dimension( * ) ipiv, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) rwork, réel resid)

SSPT01

But:

!>
!> SSPT01 reconstruit une matrice indéfinie symétrique A à partir de sa
!> factorisation bloc L*D*L' ou U*D*U' et calcule le résidu
!>      norm( C - A ) / ( N * norm(A) * EPS ),
!> où C est la matrice reconstruite et EPS est la machine epsilon.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée:
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (N*(N+1)/2)
!>          La matrice symétrique originale A, stockée sous forme de matrice
!>          triangulaire compactée.
!>

AFAC

!>          AFAC est un tableau REEL, dimension (N*(N+1)/2)
!>          La forme factorisée de la matrice A, stockée sous forme de matrice
!>          triangulaire compactée. AFAC contient la matrice diagonale bloc D
!>          et les multiplicateurs utilisés pour obtenir le facteur L ou U de
!>          la factorisation bloc L*D*L' ou U*D*U' telle que calculée par SSPTRF.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de SSPTRF.
!>

C

!>          C est un tableau REEL, dimension (LDC,N)
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RESID

!>          RESID est REEL
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
