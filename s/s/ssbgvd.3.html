Documentation de la fonction/sous-programme

subroutine ssbgvd (character jobz, character uplo, integer n, integer ka, integer kb, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldbb, * ) bb, integer ldbb, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSBGVD

Purpose:

!>
!> SSBGVD calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème aux valeurs propres généralisé symétrique-défini et bande réel,
!> de la forme A*x=(lambda)*B*x. Ici A et B sont supposés symétriques et
!> bande, et B est aussi définie positive. Si les vecteurs propres sont
!> désirés, il utilise un algorithme de type diviser pour régner.
!>
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer seulement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

KA

!>          KA est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KA >= 0.
!>

KB

!>          KB est INTEGER
!>          Le nombre de super-diagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KB >= 0.
!>

AB

!>          AB est tableau REAL, dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          A, stocké dans les ka+1 premières lignes du tableau. La
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+ka).
!>
!>          En sortie, le contenu de AB est détruit.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB. LDAB >= KA+1.
!>

BB

!>          BB est tableau REAL, dimension (LDBB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          B, stocké dans les kb+1 premières lignes du tableau. La
!>          j-ème colonne de B est stockée dans la j-ème colonne du tableau BB
!>          comme suit :
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) pour max(1,j-kb) <= i <= j ;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) pour j <= i <= min(n,j+kb).
!>
!>          En sortie, le facteur S de la factorisation de Cholesky scindée
!>          B = S**T*S, tel que retourné par SPBSTF.
!>

LDBB

!>          LDBB est INTEGER
!>          La dimension principale du tableau BB. LDBB >= KB+1.
!>

W

!>          W est tableau REAL, dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

Z

!>          Z est tableau REAL, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres, avec la i-ème colonne de Z contenant le
!>          vecteur propre associé à W(i). Les vecteurs propres sont
!>          normalisés de sorte que Z**T*B*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est tableau REAL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N <= 1, LWORK >= 1.
!>          Si JOBZ = 'N' et N > 1, LWORK >= 3*N.
!>          Si JOBZ = 'V' et N > 1, LWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement les tailles optimales des tableaux WORK et
!>          IWORK, retourne ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à LWORK ou
!>          LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (MAX(1,LIWORK))
!>          En sortie, si LIWORK > 0, IWORK(1) contient le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOBZ  = 'N' ou N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' et N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement les tailles optimales des tableaux WORK et
!>          IWORK, retourne ces valeurs comme premières entrées des
!>          tableaux WORK et IWORK, et aucun message d'erreur lié à
!>          LWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  Terminaison réussie
!>          < 0 :  Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  Si INFO = i, et i est :
!>             <= N :  L'algorithme n'a pas convergé :
!>                    i éléments hors-diagonale d'une forme tridiagonale intermédiaire
!>                    n'ont pas convergé à zéro ;
!>             > N :   Si INFO = N + i, pour 1 <= i <= N, alors SPBSTF
!>                    a retourné INFO = i : B n'est pas définie positive.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculé.
!>
