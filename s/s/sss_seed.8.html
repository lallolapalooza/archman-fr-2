NOM

sss_seed - Initialise le cache SSSD avec un utilisateur

SYNOPIS

sss_seed [options] -D DOMAINE -n UTILISATEUR

DESCRIPTION

sss_seed initialise le cache SSSD avec une entrée utilisateur et un mot de passe temporaire. Si une entrée utilisateur est déjà présente dans le cache SSSD, elle est mise à jour avec le mot de passe temporaire.

OPTIONS

-D,--domain DOMAINE

Fournit le nom du domaine dont l'utilisateur est membre. Le domaine est également utilisé pour récupérer les informations de l'utilisateur. Le domaine doit être configuré dans sssd.conf. L'option DOMAINE doit être fournie. Les informations récupérées du domaine remplacent celles fournies dans les options.

-n,--username UTILISATEUR

Le nom d'utilisateur de l'entrée à créer ou modifier dans le cache. L'option UTILISATEUR doit être fournie.

-u,--uid UID

Définit l'UID de l'utilisateur à UID.

-g,--gid GID

Définit le GID de l'utilisateur à GID.

-c,--gecos COMMENTAIRE

Toute chaîne de caractères décrivant l'utilisateur. Souvent utilisé comme champ pour le nom complet de l'utilisateur.

-h,--home HOME_DIR

Définit le répertoire personnel de l'utilisateur à HOME_DIR.

-s,--shell SHELL

Définit le shell de connexion de l'utilisateur à SHELL.

-i,--interactive

Mode interactif pour saisir les informations utilisateur. Cette option ne demandera que les informations non fournies dans les options ou récupérées du domaine.

-p,--password-file PASS_FILE

Spécifie le fichier à lire pour le mot de passe de l'utilisateur. (si non spécifié, le mot de passe est demandé).

-?,--help

Affiche le message d'aide et quitte.

NOTES

La longueur du mot de passe (ou la taille du fichier spécifié avec l'option -p ou --password-file) doit être inférieure ou égale à PASS_MAX octets (64 octets sur les systèmes sans valeur PASS_MAX définie globalement).
