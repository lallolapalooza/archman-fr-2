SSR(1) Commandes utilisateur SSR(1)

NOM

SSR - page de manuel pour le rendu générique

SYNTAXE

ssr-generic [OPTIONS] <fichier-scène>

DESCRIPTION

Le SoundScape Renderer (SSR) est un outil de reproduction audio spatiale en temps réel offrant une variété d'algorithmes de rendu.

OPTIONS

Options spécifiques au rendu :

--hrirs=FICHIER
Charge les HRIR pour le rendu binaural depuis FICHIER
--hrir-size=N
Tronque les HRIR à la longueur N
--prefilter=FICHIER
Charge le préfiltre WFS depuis FICHIER
-o, --ambisonics-order=VALEUR
Ordre des ambisoniques à utiliser pour l'AAP (par défaut : maximum)
--in-phase-rendering
Utilise le rendu en phase pour le rendu AAP

Options JACK :

-n, --name=NOM
Définit le nom du client JACK à NOM
--input-prefix=PREFIXE
Préfixe des ports d'entrée (par défaut : "system:capture_")
--output-prefix=PREFIXE
Préfixe des ports de sortie (par défaut : "system:playback_")
-f, --freewheel
Utilise JACK en mode freewheeling

Options générales :

-c, --config=FICHIER
Lit la configuration depuis FICHIER
-s, --setup=FICHIER
Charge la configuration de reproduction depuis FICHIER
--threads=N
Nombre de threads audio (par défaut : auto)
-r, --record=FICHIER
Enregistre la sortie audio du rendu dans FICHIER
--decay-exponent=VALEUR
Exposant déterminant la décroissance de l'amplitude (par défaut : 1) (désactivé à la compilation !)
--loop
Boucle tous les fichiers audio
--master-volume-correction=VALEUR
Correction du volume master en dB (par défaut : 0 dB)
--auto-rotation Fait pivoter automatiquement l'orientation des sources sonores vers le
référentiel
--no-auto-rotation
Ne fait pas pivoter automatiquement l'orientation des sources sonores vers le référentiel
-i, --ip-server
Démarre le serveur IP (non activé à la compilation !)
-I, --no-ip-server
Ne démarre pas le serveur IP (par défaut)
--websocket-server
Démarre le serveur WebSocket (non activé à la compilation !)
--no-websocket-server
Ne démarre pas le serveur WebSocket (par défaut)
--fudi-server
Démarre le serveur FUDI (non activé à la compilation !)
--no-fudi-server
Ne démarre pas le serveur FUDI (par défaut)
--follow
Attend qu'une autre instance SSR se connecte
--no-follow
Ne suit pas une autre instance SSR (par défaut)
-g, --gui
Démarre l'interface graphique (non activé à la compilation !)
-G, --no-gui
Ne démarre pas l'interface graphique (par défaut)
-t, --tracker=TYPE
Sélectionne le traqueur de tête, valeur(s) possible(s) : fastrak patriot razor
--tracker-port=PORT
Nom/numéro du port du traqueur de tête, par exemple /dev/ttyS1
-T, --no-tracker
N'utilise pas de traqueur de tête (par défaut)
-h, --help
Affiche l'aide et quitte
-v, --verbose
Augmente le niveau de verbosité (jusqu'à -vvv)
-V, --version
Affiche les informations de version et quitte
