SSYSV calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

Documentation de la fonction/sous-programme

sous-programme ssysv (caractère uplo, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, entier lwork, entier info)

SSYSV calcule la solution du système d'équations linéaires A * X = B pour les matrices SY

Objectif :

!>
!> SSYSV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique N x N et X et B sont des matrices N x NRHS.
!>
!> La méthode de pivotement diagonal est utilisée pour factoriser A comme suit :
!>    A = U * D * U**T,  si UPLO = 'U', ou
!>    A = L * D * L**T,  si UPLO = 'L',
!> où U (ou L) est un produit de matrices de permutation et triangulaires unitaires supérieures (inférieures), et D est une matrice symétrique et bloc-diagonale avec des blocs diagonaux de 1x1 et 2x2. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau RÉEL, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N de A contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire N x N de A contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, la matrice bloc-diagonale D et les
!>          multiplicateurs utilisés pour obtenir le facteur U ou L à partir de la
!>          factorisation A = U*D*U**T ou A = L*D*L**T calculée par
!>          SSYTRF.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimension (N)
!>          Détails des échanges et de la structure de blocs de D, tels que
!>          déterminés par SSYTRF. Si IPIV(k) > 0, alors les lignes et colonnes
!>          k et IPIV(k) ont été échangées, et D(k,k) est un bloc diagonal 1x1.
!>          Si UPLO = 'U' et IPIV(k) = IPIV(k-1) < 0, alors les lignes et colonnes
!>          k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>          Si UPLO = 'L' et IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes
!>          k+1 et -IPIV(k) ont été échangées et D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>

B

!>          B est un tableau RÉEL, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice membre de droite B de dimension N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de dimension N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau RÉEL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur de WORK.  LWORK >= 1, et pour de meilleures performances
!>          LWORK >= max(1,N*NB), où NB est la taille de bloc optimale pour
!>          SSYTRF.
!>          pour LWORK < N, TRS sera effectué avec BLAS de Niveau 2
!>          pour LWORK >= N, TRS sera effectué avec BLAS de Niveau 3
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) est exactement zéro. La factorisation
!>               a été complétée, mais la matrice bloc-diagonale D est
!>               exactement singulière, donc la solution n'a pas pu être calculée.
!>
