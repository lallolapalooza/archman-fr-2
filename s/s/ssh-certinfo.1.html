SSH-CERTINFO(1) Commandes utilisateur SSH-CERTINFO(1)

NOM

ssh-certinfo

SYNTAXE

ssh-certinfo [OPTIONS] FICHIER-CERT [...]

DESCRIPTION

affiche la validité et les informations des certificats SSH

OPTIONS

-c
afficher les couleurs
-h
afficher ce message
-w jours
seuil d'alerte (défaut : 30)
-v
sortie détaillée
--version
afficher les informations de version

EXEMPLES

# Défaut
ssh-certinfo ~/.ssh/id_rsa-cert.pub
ssh-certinfo ~/.ssh/*.pub
# Certificats qui expirent dans les 2 prochains mois (sortie colorée) :
ssh-certinfo -c -w 60 ~/.ssh/id_rsa-cert.pub
ssh-certinfo -c -w 60 ~/.ssh/*.pub
