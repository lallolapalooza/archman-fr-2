Objectif :

!>
!> SSTEMR calcule certains valeurs propres et, éventuellement, vecteurs propres
!> d'une matrice tridiagonale symétrique réelle T. Toute matrice non réduite
!> de ce type a un ensemble bien défini de valeurs propres réelles, deux à deux
!> distinctes. Les vecteurs propres réels correspondants sont deux à deux orthogonaux.
!>
!> Le spectre peut être calculé soit complètement, soit partiellement en spécifiant
!> soit un intervalle (VL,VU], soit une plage d'indices IL:IU pour les valeurs propres désirées.
!>
!> Selon le nombre de valeurs propres désirées, celles-ci sont calculées soit
!> par bissection, soit par l'algorithme dqds. Des vecteurs propres numériquement orthogonaux sont
!> calculés par l'utilisation de diverses factorisations L D L^T appropriées à proximité de clusters
!> de valeurs propres proches (appelés RRR, Représentations Relativement Robustes). Un aperçu informel de l'algorithme suit.
!>
!> Pour chaque bloc non réduit (sous-matrice) de T,
!>    (a) Calculer T - sigma I = L D L^T, de sorte que L et D
!>        définissent toutes les valeurs propres recherchées avec une haute précision relative.
!>        Cela signifie que de petits changements relatifs dans les entrées de D et L
!>        entraînent seulement de petits changements relatifs dans les valeurs propres et
!>        les vecteurs propres. La représentation standard (non factorisée) de la
!>        matrice tridiagonale T n'a généralement pas cette propriété.
!>    (b) Calculer les valeurs propres avec une précision appropriée.
!>        Si les vecteurs propres sont désirés, l'algorithme atteint la pleine
!>        précision des valeurs propres calculées juste avant
!>        que les vecteurs correspondants ne doivent être calculés, voir les étapes c) et d).
!>    (c) Pour chaque cluster de valeurs propres proches, sélectionner un nouveau
!>        décalage proche du cluster, trouver une nouvelle factorisation, et affiner
!>        les valeurs propres décalées avec une précision appropriée.
!>    (d) Pour chaque valeur propre avec une séparation relative suffisamment grande, calculer
!>        le vecteur propre correspondant en formant une factorisation torsadée révélant le rang. Revenir à (c) pour les clusters restants.
!>
!> Pour plus de détails, voir :
!> - Inderjit S. Dhillon et Beresford N. Parlett : 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, août 2004.
!> - Inderjit Dhillon et Beresford Parlett :  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. Également LAPACK Working Note 154.
!> - Inderjit Dhillon : ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mai 1997.
!>
!> Détails supplémentaires
!> 1. SSTEMR fonctionne uniquement sur les machines qui suivent la norme de
!>    point flottant IEEE-754 dans leur gestion des infinis et des NaNs.
!>    Cela permet l'utilisation de boucles internes efficaces évitant la vérification des
!>    diviseurs nuls.
!>

Paramètres :

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs propres d'indice IL à IU seront trouvées.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau REAL, de dimension (N)
!>          À l'entrée, les N éléments diagonaux de la matrice tridiagonale
!>          T. À la sortie, D est écrasé.
!>

E

!>          E est un tableau REAL, de dimension (N)
!>          À l'entrée, les (N-1) éléments sous-diagonaux de la matrice tridiagonale
!>          T dans les éléments 1 à N-1 de E. E(N) n'a pas besoin d'être défini à l'entrée,
!>          mais est utilisé en interne comme espace de travail.
!>          À la sortie, E est écrasé.
!>

VL

!>          VL est REAL
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REAL, de dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées dans
!>          l'ordre croissant.
!>

Z

!>          Z est un tableau REAL, de dimension (LDZ, max(1,M) )
!>          Si JOBZ = 'V', et si INFO = 0, alors les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice T
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et peut être calculée avec une requête
!>          d'espace de travail en définissant NZC = -1, voir ci-dessous.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', alors LDZ >= max(1,N).
!>

NZC

!>          NZC est INTEGER
!>          Le nombre de vecteurs propres à contenir dans le tableau Z.
!>          Si RANGE = 'A', alors NZC >= max(1,N).
!>          Si RANGE = 'V', alors NZC >= le nombre de valeurs propres dans (VL,VU].
!>          Si RANGE = 'I', alors NZC >= IU-IL+1.
!>          Si NZC = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule le nombre de colonnes du tableau Z qui
!>          sont nécessaires pour contenir les vecteurs propres.
!>          Cette valeur est retournée dans la première entrée du tableau Z, et
!>          aucun message d'erreur relatif à NZC n'est émis par XERBLA.
!>

ISUPPZ

!>          ISUPPZ est un tableau INTEGER, de dimension ( 2*max(1,M) )
!>          Le support des vecteurs propres dans Z, c'est-à-dire les indices
!>          indiquant les éléments non nuls dans Z. Le i-ème vecteur propre
!>          calculé est non nul uniquement dans les éléments ISUPPZ( 2*i-1 ) jusqu'à
!>          ISUPPZ( 2*i ). Ceci est pertinent dans le cas où la matrice
!>          est scindée. ISUPPZ n'est accédé que lorsque JOBZ est 'V' et N > 0.
!>

NAME

sstemr - Computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

     SUBROUTINE SSTEMR(
         JOBZ, RANGE, N, D, E, VL, VU, IL, IU, ABSTOL, M, NS,
         WORK, LWORK, IWORK, LIWORK, INFO
     )

         CHARACTER          JOBZ, RANGE
         INTEGER            N, M, NS, LWORK, LIWORK, INFO, IL, IU
         REAL               D( * ), E( * ), VL, VU, ABSTOL
         INTEGER            IWORK( * )
         REAL               WORK( * )

Function/Subroutine Documentation

JOBZ
CHARACTER*1.
          = 'N':  Compute eigenvalues only.
          = 'V':  Compute eigenvalues and eigenvectors.

JOBZ = 'N' or 'V'.

RANGE
CHARACTER*1.
          = 'A':  All eigenvalues will be found.
          = 'V':  All eigenvalues between VL and VU will be found.
          = 'I':  The IL-th to IU-th eigenvalues will be found.

RANGE = 'A', 'V', or 'I'.

N
INTEGER.
          The order of the matrix.  N >= 0.
D
REAL array, dimension (N).
          On entry, the diagonal elements of the tridiagonal matrix
          T.
          On exit, the eigenvalues, sorted in increasing order.  If
          RANGE = 'I' or RANGE = 'V', only the
          first M entries of D are relevant.
E
REAL array, dimension (N-1).
          On entry, the subdiagonal elements of the tridiagonal matrix
          T. `E(i)` contains the element `T(i+1,i)`.
          On exit, E is overwritten by the elements of the Schur
          vectors, and if RANGE = 'I' or RANGE =
          'V', only the first M-1 entries are relevant.
          If RANGE = 'A', E is not used.
VL
REAL.
          If RANGE = 'V', the lower bound of the interval for
          the eigenvalues.
          If RANGE = 'A' or RANGE = 'I', VL is not
          used.
VU
REAL.
          If RANGE = 'V', the upper bound of the interval for
          the eigenvalues.
          If RANGE = 'A' or RANGE = 'I', VU is not
          used.
IL
INTEGER.
          If RANGE = 'I', the index of the smallest eigenvalue
          to be computed.
          If RANGE = 'A' or RANGE = 'V', IL is not
          used.
IU
INTEGER.
          If RANGE = 'I', the index of the largest eigenvalue
          to be computed.
          If RANGE = 'A' or RANGE = 'V', IU is not
          used.
ABSTOL
REAL.
          The absolute tolerance for the eigenvalues.  An eigenvalue W
          will be considered to be greater in absolute value than ABSTOL
          if ABS(W) > ABSTOL.  If ABSTOL is set to 0, then the default
          tolerance ABSTOL = EPS * MAX(|D(i)|, |E(i)|) is used where
          EPS is the machine precision.
M
INTEGER.
          The total number of eigenvalues found.
          If RANGE = 'A', M = N.
          If RANGE = 'I' or RANGE = 'V', M is the
          number of eigenvalues between VL and VU, or between IL
          and IU.
NS
INTEGER.
          The number of eigenvalues in each block of the algorithm.
          If RANGE = 'A', NS = N.
          If RANGE = 'I' or RANGE = 'V', NS is the
          number of eigenvalues between VL and VU, or between IL
          and IU.
WORK
REAL array, dimension (LWORK).
          Workspace array.
LWORK
INTEGER.
          The dimension of the array WORK. LWORK >= max(1,18*N)
          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal size of the WORK array, returns
          this value as the first entry of the WORK array, and no error
          message related to LWORK is issued by XERBLA.
IWORK
INTEGER array, dimension (LIWORK).
          Workspace array.
          If LIWORK = -1, then a workspace query is assumed; the
          routine only calculates the optimal size of the IWORK array,
          returns this value as the first entry of the IWORK array, and
          no error message related to LIWORK is issued by XERBLA.
LIWORK
INTEGER.
          The dimension of the array IWORK.  LIWORK >= max(1,10*N)
          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
          if only the eigenvalues are to be computed.
INFO
INTEGER.
          On exit, INFO
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = 1, internal error: LWORK was too small.
          if INFO = 2, internal error: LIWORK was too small.
          if INFO = 3, internal error: recursion depth exceeded.
          if INFO = 4, internal error: algorithm did not converge.

TRYRAC

!>          LOGICAL.
!>          On entry, TRYRAC specifies whether the routine should try to
!>          compute the eigenvalues to high relative accuracy.
!>          On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix
!>          does not define its eigenvalues to high relative accuracy.
!>
!>          If TRYRAC = .TRUE. (the default), the code checks whether
!>          the tridiagonal matrix defines its eigenvalues to high relative
!>          accuracy. If so, the code uses relative-accuracy preserving
!>          algorithms that might be (a bit) slower depending on the matrix.
!>          If the matrix does not define its eigenvalues to high relative
!>          accuracy, the code can uses possibly faster algorithms.
!>          If TRYRAC = .FALSE., the code is not required to guarantee
!>          relatively accurate eigenvalues and can use the fastest possible
!>          techniques.
!>          On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix
!>          does not define its eigenvalues to high relative accuracy.
!>

WORK

!>          WORK is REAL array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) returns the optimal
!>          (and minimal) LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,18*N)
!>          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (LIWORK)
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.  LIWORK >= max(1,10*N)
!>          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
!>          if only the eigenvalues are to be computed.
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          On exit, INFO
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = 1X, internal error in SLARRE,
!>                if INFO = 2X, internal error in SLARRV.
!>                Here, the digit X = ABS( IINFO ) < 10, where IINFO is
!>                the nonzero error code returned by SLARRE or
!>                SLARRV, respectively.
!>
