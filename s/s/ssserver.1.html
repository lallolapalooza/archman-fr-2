SHADOWSOCKS(1) Manuel des commandes générales SHADOWSOCKS(1)

NOM

shadowsocks - Proxy tunnel rapide qui aide à contourner les pare-feux

SYNTAXE

ssserver [options]
sslocal [options]

DESCRIPTION

shadowsocks est un proxy tunnel qui aide à contourner les pare-feux. ssserver est la partie serveur, et sslocal est la partie locale.

OPTIONS

-h, --help
Affiche ce message d'aide et quitte.
-s ADRESSE_SERVEUR
Adresse du serveur, par défaut : 0.0.0.0.
-p PORT_SERVEUR
Port du serveur, par défaut : 8388.
-k MOT_DE_PASSE
Mot de passe.
-m METHODE
Méthode de chiffrement, par défaut : aes-256-cfb.
-t DELAI
Délai en secondes, par défaut : 300.
-c FICHIER_CONFIG
Chemin d'accès au fichier de configuration.
--fast-open
Utilise TCP_FASTOPEN, nécessite Linux 3.7+.
--workers TRAVAILLEURS
Nombre de travailleurs, disponible sur Unix/Linux.
-v, -vv
Mode verbeux.
-q, -qq
Mode silencieux, affiche uniquement les avertissements/erreurs.
