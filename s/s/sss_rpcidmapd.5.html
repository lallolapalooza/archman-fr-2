NOM

sss_rpcidmapd - directives de configuration du plugin sss pour rpc.idmapd

FICHIER DE CONFIGURATION

Le fichier de configuration de rpc.idmapd se trouve généralement à /etc/idmapd.conf. Voir idmapd.conf(5) pour plus d'informations.

EXTENSION DE CONFIGURATION SSS

Activer le plugin SSS

Dans la section “[Translation]”, modifiez/définissez l'attribut “Method” pour qu'il contienne sss.

Section de configuration [sss]

Afin de modifier la valeur par défaut de l'un des attributs de configuration du plugin sss listés ci-dessous, vous devrez créer une section de configuration pour celui-ci, nommée “[sss]”.

Attributs de configuration

memcache (bool)

Indique s'il faut utiliser ou non la technique d'optimisation memcache.

Par défaut : True

INTEGRATION SSSD

Le plugin sss requiert que le NSS Responder soit activé dans sssd.

L'attribut “use_fully_qualified_names” doit être activé sur tous les domaines (les clients NFSv4 s'attendent à ce qu'un nom entièrement qualifié soit envoyé sur le réseau).

EXEMPLE

L'exemple suivant montre un idmapd.conf minimal qui utilise le plugin sss.

[General]
Verbosity = 2
# le domaine doit être synchronisé entre le serveur NFSv4 et les clients
# Solaris/Illumos/AIX utilisent "localdomain" par défaut !
Domain = default
[Mapping]
Nobody-User = nfsnobody
Nobody-Group = nfsnobody
[Translation]
Method = sss
