SSH-DIFF(1) Commandes utilisateur SSH-DIFF(1)

NOM

ssh-diff

SYNTAXE

ssh-diff [OPTIONS] FICHIER [utilisateur@]hôte[:FICHIER]

DESCRIPTION

diff un fichier sur SSH

Il y a un aller-retour supplémentaire vers le système distant
pour vérifier l'existence du fichier à comparer.
Donc, si vous n'utilisez pas de clés SSH
vous pourriez être invité deux fois pour un mot de passe.

Utilisez "CHECK_REMOTE_FILE_EXISTS=NO ssh-diff" pour désactiver ce comportement

OPTIONS DIFF

Toutes les options que votre commande diff locale supporte (sauf '-r').
Voir 'man diff' et 'diff --help' pour plus d'informations.

OPTIONS SSH

-4
Utiliser IPv4 uniquement
-6
Utiliser IPv6 uniquement
-p port
Port de connexion sur l'hôte distant.
Ceci peut être spécifié par hôte dans le fichier de configuration.

ENVIRONNEMENT

CHECK_REMOTE_FILE_EXISTS NO|YES vérification du fichier distant

EXEMPLES

# Par défaut
ssh-diff /etc/hosts 192.168.1.10
ssh-diff /etc/hosts root@192.168.1.10
ssh-diff /etc/hosts root@192.168.1.10:/etc/hosts.old
# Côte à côte
ssh-diff -y /etc/hosts 192.168.1.10
ssh-diff -y /etc/hosts root@192.168.1.10
ssh-diff -y /etc/hosts root@192.168.1.10:/etc/hosts.old
# Unifié
ssh-diff -u /etc/hosts 192.168.1.10
ssh-diff -u /etc/hosts root@192.168.1.10
ssh-diff -u /etc/hosts root@192.168.1.10:/etc/hosts.old
