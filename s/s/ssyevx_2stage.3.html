Documentation de la Fonction/Sous-programme

sous-programme ssyevx_2stage (character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSYEVX_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres d'une matrice symétrique réelle A en utilisant la technique à 2 étapes pour la réduction en tridiagonale. Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les valeurs propres souhaitées.

Objectif :

!>
!> SSYEVX_2STAGE calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'une matrice symétrique réelle A en utilisant la technique à 2 étapes pour
!> la réduction en tridiagonale. Les valeurs propres et les vecteurs propres peuvent être
!> sélectionnés en spécifiant soit une plage de valeurs, soit une plage d'indices pour les
!> valeurs propres souhaitées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs propres de l'indice IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  le triangle supérieur de A est stocké ;
!>          = 'L':  le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA, N)
!>          En entrée, la matrice symétrique A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N x N de A contient
!>          la partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient
!>          la partie triangulaire inférieure de la matrice A.
!>          En sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>          lorsqu'elle est déterminée comme étant dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          par la réduction de A en tridiagonale.
!>
!>          Les valeurs propres seront calculées de manière plus précise lorsque ABSTOL
!>          est défini à deux fois le seuil de sous-flux 2*SLAMCH('S'), et non zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau de type REAL, de dimension (N)
!>          En cas de sortie normale, les M premiers éléments contiennent les valeurs propres sélectionnées
!>          par ordre croissant.
!>

Z

!>          Z est un tableau de type REAL, de dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormés de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une limite supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= 1, lorsque N <= 1 ;
!>          sinon
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, 8*N, dimension) où
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 3*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 3*N
!>                                   où KD est la taille du bloc de la réduction,
!>                                   FACTOPTNB est le bloc utilisé par l'algorithme QR ou LQ,
!>                                   généralement FACTOPTNB=128 est un bon choix
!>                                   NTHREADS est le nombre de threads utilisés lorsque
!>                                   la compilation openMP est activée, sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore disponible
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (5*N)
!>

IFAIL

!>          IFAIL est

NOM

ssyevx_2stage - Ce sous-programme calcule les valeurs propres et les vecteurs propres d'une matrice symétrique réelle.

SYNTAXE

  CALL SSYEVX_2STAGE(
     JOBZ, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, M, NSUPP, WORK, LWORK,
     IWORK, INFO )

  CALL SSYEVX_2STAGE(
     JOBZ, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, M, NSUPP, WORK, LWORK,
     IWORK, INFO )

PARAMETRES

JOBZ CHARACTER*1

   = 'N': Ne calculer que les valeurs propres.
   = 'V': Calculer les valeurs propres et les vecteurs propres.

UPLO CHARACTER*1

   = 'U': Uniquement la partie supérieure de A est utilisée.
   = 'L': Uniquement la partie inférieure de A est utilisée.

N INTEGER

   La taille de la matrice A. N >= 0.

A REAL*8 array, dimension (LDA,N)

   Le premier argument.

LDA INTEGER

   Le deuxième argument.

VL REAL*8

   La borne inférieure des valeurs propres à calculer.

VU REAL*8

   La borne supérieure des valeurs propres à calculer.

IL INTEGER

   L'indice de la première valeur propre à calculer.

IU INTEGER

   L'indice de la dernière valeur propre à calculer.

ABSTOL REAL*8

   Tolérance absolue pour la convergence.

M INTEGER

   Le nombre de valeurs propres calculées. 0 <= M <= N.

NSUPP INTEGER array, dimension (N)

   Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
   IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
   indices des vecteurs propres qui n'ont pas convergé.
   Si JOBZ = 'N', alors IFAIL n'est pas référencé.

INFO

   INFO est INTEGER
   = 0:  terminaison réussie
   < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
   > 0:  si INFO = i, alors i vecteurs propres n'ont pas convergé.
         Leurs indices sont stockés dans le tableau IFAIL.
