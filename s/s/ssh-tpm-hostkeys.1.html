NOM

ssh-tpm-hostkeys - Utilitaire de clé hôte ssh-tpm-agent

SYNOPSIS

ssh-tpm-hostkeys

ssh-tpm-hostkeys --install-system-units

ssh-tpm-hostkeys --install-sshd-config

DESCRIPTION

ssh-tpm-hostkeys affiche les clés hôtes du système, et peut installer les unités systemd et la configuration sshd pertinentes pour utiliser des clés hôtes sauvegardées par TPM.

OPTIONS

--install-system-units

Installe les unités système systemd pour utiliser ssh-tpm-agent comme agent de clé hôte.

--install-sshd-config

Installe la configuration sshd pour le socket ssh-tpm-agent.

VOIR AUSSI

ssh-tpm-agent(1), ssh-agent(1)
