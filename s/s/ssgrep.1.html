NOM

ssgrep - rechercher des chaînes dans des feuilles de calcul

SYNTAXE

ssgrep [OPTIONS] [FICHIERS]

DESCRIPTION

Cette page de manuel documente brièvement la commande ssgrep.

ssgrep est un utilitaire en ligne de commande pour rechercher des chaînes dans des feuilles de calcul de n'importe quel format supporté par gnumeric. Sans aucune option modifiant la sortie, ssgrep affiche une ligne pour chaque correspondance. Une correspondance consiste en le contenu correspondant d'une cellule ou, si l'option -R est donnée, le résultat de l'expression correspondante d'une cellule.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options d'une seule lettre commençant par un tiret (`-') et des options plus longues commençant par deux tirets (`--').

Options contrôlant la gestion des fichiers d'entrée

--recalc
Recalculer toutes les cellules

Options contrôlant les modèles et la correspondance des modèles

-f, --keyword-file=FICHIER
Le chemin vers un fichier texte contenant une clé par ligne
-i, --ignore-case
Ignorer les différences de casse
-w, --word-regexp
Ne faire correspondre que des mots entiers
-F, --fixed-strings
Le modèle est un ensemble de chaînes fixes
-R, --search-results
Rechercher également les résultats des expressions
-v, --invert-match
Rechercher les cellules qui ne correspondent pas

Options contrôlant la sortie en général

-c, --count
N'afficher qu'un compte des correspondances par fichier
-L, --files-without-matches
Afficher les noms de fichiers sans correspondances
-l, --files-with-matches
Afficher les noms de fichiers avec correspondances
-q, --quiet
Supprimer toute sortie normale
-H, --with-filename
Afficher le nom de fichier pour chaque correspondance
-h, --without-filename
Ne pas afficher le nom de fichier pour chaque correspondance
-n, --print-locus
Afficher la localisation de chaque correspondance
-T, --print-type
Afficher le type de localisation de chaque correspondance

Options d'aide

-V, --version
Afficher la version de ssgrep
-?, --help
Afficher les options supportées
--usage
Afficher un bref message d'utilisation

EXEMPLE

Pour rechercher la chaîne "SUM" dans le fichier foo.gnumeric :

ssgrep SUM foo.gnumeric

Pour rechercher les chaînes du fichier keywords dans la feuille de calcul foo.xls :

ssgrep --keyword-file=keywords foo.xls
