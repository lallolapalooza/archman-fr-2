sous-routine ssbgst (caractère vect, caractère uplo, entier n, entier ka, entier kb, réel, dimension( ldab, * ) ab, entier ldab, réel, dimension( ldbb, * ) bb, entier ldbb, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( * ) work, entier info)

SSBGST

Purpose:

!>
!> SSBGST réduit un problème aux valeurs propres généralisé symétrique-défini
!> réel à bande  A*x = lambda*B*x  à la forme standard  C*y = lambda*y,
!> tel que C ait la même bande passante que A.
!>
!> B doit avoir été préalablement factorisé comme S**T*S par SPBSTF, en utilisant
!> une factorisation de Cholesky divisée. A est écrasé par C = X**T*A*X, où
!> X = S**(-1)*Q et Q est une matrice orthogonale choisie pour préserver la
!> bande passante de A.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'N':  ne pas former la matrice de transformation X ;
!>          = 'V':  former X.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  le triangle supérieur de A est stocké ;
!>          = 'L':  le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB est INTEGER
!>          Le nombre de super-diagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KA >= KB >= 0.
!>

AB

!>          AB est un tableau REEL, dimension (LDAB,N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les KA+1 premières lignes du tableau. Le
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          À la sortie, la matrice transformée X**T*A*X, stockée dans le même
!>          format que A.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

BB

!>          BB est un tableau REEL, dimension (LDBB,N)
!>          Le facteur bande S de la factorisation de Cholesky divisée de
!>          B, tel que retourné par SPBSTF, stocké dans les KB+1 premières lignes
!>          du tableau.
!>

LDBB

!>          LDBB est INTEGER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!>

X

!>          X est un tableau REEL, dimension (LDX,N)
!>          Si VECT = 'V', la matrice X de taille n*n.
!>          Si VECT = 'N', le tableau X n'est pas référencé.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>          LDX >= max(1,N) si VECT = 'V' ; LDX >= 1 sinon.
!>

WORK

!>          WORK est un tableau REEL, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
