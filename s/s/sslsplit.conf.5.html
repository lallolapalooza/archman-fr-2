NOM

sslsplit.conf - Fichier de configuration pour SSLsplit

DESCRIPTION

Le fichier sslsplit.conf configure SSLsplit, sslsplit(1).

FORMAT DU FICHIER

Le fichier se compose de commentaires et d'options avec des arguments. Chaque ligne qui commence par un symbole dièse (#) est ignorée par l'analyseur. Les options et les arguments sont de la forme Option Argument. Les arguments sont des types suivants :

BOOL
Valeur booléenne (oui/non).
STRING
Chaîne de caractères.

DIRECTIVES

Lorsqu'une option n'est pas utilisée (commentée ou inexistante dans le fichier de configuration), sslsplit adopte une action par défaut. Si une option n'a pas d'équivalent en ligne de commande, l'option -o opt=val peut être utilisée pour la remplacer en ligne de commande.

CACert STRING
Utilise le certificat CA (et la clé) pour signer les certificats falsifiés. Équivalent à l'option en ligne de commande -c.
CAKey STRING
Utilise la clé CA (et le certificat) pour signer les certificats falsifiés. Équivalent à l'option en ligne de commande -k.
ClientCert STRING
Utilise le certificat du fichier pem lorsque la destination demande des certificats client. Équivalent à l'option en ligne de commande -a.
ClientKey STRING
Utilise la clé du fichier pem lorsque la destination demande des certificats client. Équivalent à l'option en ligne de commande -b.
CAChain STRING
Utilise la chaîne CA du fichier pem (certificats CA intermédiaires et racine). Équivalent à l'option en ligne de commande -C.
LeafKey STRING
Utilise la clé du fichier pem pour générer les certificats feuille. Équivalent à l'option en ligne de commande -K.
Par défaut : générer
LeafCRLURL STRING
Utilise l'URL comme point de distribution CRL pour tous les certificats feuille falsifiés. Équivalent à l'option en ligne de commande -q.
LeafCertDir STRING
Utilise des fichiers PEM de certificat+chaîne+clé du répertoire de certificats pour toutes les cibles correspondant aux noms communs (non correspondants : générer si CA). Équivalent à l'option en ligne de commande -t.
DefaultLeafCert STRING
Utilise le certificat+chaîne+clé du fichier PEM pour les certificats feuille s'il n'y a pas de correspondance dans LeafCertDir. Équivalent à l'option en ligne de commande -A.
WriteGenCertsDir STRING
Écrit la clé feuille et uniquement les certificats générés dans le répertoire de génération. Équivalent à l'option en ligne de commande -w.
WriteAllCertsDir STRING
Écrit la clé feuille et tous les certificats dans le répertoire de génération. Équivalent à l'option en ligne de commande -W.
DenyOCSP BOOL
Refuse toutes les requêtes OCSP sur tous les proxyspecs. Équivalent à l'option en ligne de commande -O.
Passthrough BOOL
Passe les connexions SSL si elles ne peuvent pas être séparées en raison de l'authentification par certificat client ou de l'absence de certificat correspondant et de CA. Équivalent à l'option en ligne de commande -P.
Par défaut : abandonner
DHGroupParams STRING
Utilise les paramètres de groupe DH du fichier pem. Équivalent à l'option en ligne de commande -g.
Par défaut : fichiers clés ou automatique
ECDHCurve STRING
Utilise la courbe nommée ECDH. Équivalent à l'option en ligne de commande -G.
Par défaut : prime256v1
SSLCompression BOOL
Active/désactive la compression SSL/TLS sur toutes les connexions. Équivalent à l'option en ligne de commande -Z.
ForceSSLProto STRING
Force uniquement la version du protocole SSL/TLS. Équivalent à l'option en ligne de commande -r.
Par défaut : tout
DisableSSLProto STRING
Désactive la version du protocole SSL/TLS. Équivalent à l'option en ligne de commande -R.
Par défaut : aucun
Ciphers STRING
Utilise la spécification de suite de chiffrement OpenSSL donnée. Équivalent à l'option en ligne de commande -s.
Par défaut : ALL:-aNULL
OpenSSLEngine STRING
Moteur OpenSSL à activer, soit l'ID, soit le chemin complet vers la bibliothèque partagée implémentant le moteur. Si un ID est donné, le moteur doit être connu de la configuration OpenSSL globale. Uniquement disponible si compilé avec une version d'OpenSSL prenant en charge les moteurs. Équivalent à l'option en ligne de commande -x.
NATEngine STRING
Spécifie le moteur NAT par défaut à utiliser. Équivalent à l'option en ligne de commande -e.
User STRING
Fait chuter les privilèges à l'utilisateur. Équivalent à l'option en ligne de commande -u.
Par défaut : nobody, si exécuté en tant que root
Group STRING
Fait chuter les privilèges au groupe. Équivalent à l'option en ligne de commande -m.
Par défaut : groupe primaire de l'utilisateur
Chroot STRING
Chroot() dans jaildir (affecte les proxyspecs sni, voir sslsplit(1)). Équivalent à l'option en ligne de commande -j.
PidFile STRING
Écrit le pid dans un fichier. Équivalent à l'option en ligne de commande -p.
ConnectLog STRING
Journal des connexions : enregistre un résumé d'une ligne par connexion dans le fichier journal. Équivalent à l'option en ligne de commande -l.
ContentLog STRING
Journal du contenu : données complètes vers un fichier ou un pipe nommé (exclut ContentLogDir/ContentLogPathSpec). Équivalent à l'option en ligne de commande -L.
ContentLogDir STRING
Journal du contenu : données complètes dans des fichiers séparés dans le répertoire (exclut ContentLog/ContentLogPathSpec). Équivalent à l'option en ligne de commande -S.
ContentLogPathSpec STRING
Journal du contenu : données complètes dans des fichiers séparés avec substitution de % (exclut ContentLog/ContentLogDir). Équivalent à l'option en ligne de commande -F.
LogProcInfo BOOL
Recherche le processus local propriétaire de chaque connexion pour la journalisation. Équivalent à l'option en ligne de commande -i.
PcapLog STRING
Journal Pcap : paquets vers un fichier pcap (exclut PcapLogDir/PcapLogPathSpec). Équivalent à l'option en ligne de commande -X.
PcapLogDir STRING
Journal Pcap : paquets vers des fichiers séparés dans le répertoire (exclut PcapLog/PcapLogPathSpec). Équivalent à l'option en ligne de commande -Y.
PcapLogPathSpec STRING
Journal Pcap : paquets vers des fichiers séparés avec substitution de % (exclut PcapLog/PcapLogDir). Équivalent à l'option en ligne de commande -y.
MirrorIf STRING
Miroir des paquets vers l'interface. Équivalent à l'option en ligne de commande -I.
MirrorTarget STRING
Miroir des paquets vers l'adresse cible (utilisé avec MirrorIf). Équivalent à l'option en ligne de commande -T.
MasterKeyLog STRING
Journalise les clés maîtres dans un fichier journal au format SSLKEYLOGFILE. Équivalent à l'option en ligne de commande -M.
Daemon BOOL
Mode démon : s'exécute en arrière-plan, enregistre les messages d'erreur dans syslog. Équivalent à l'option en ligne de commande -d.
Debug BOOL
Mode débogage : s'exécute en premier plan, enregistre les messages d'erreur

sslsplit.conf(5) — SSLsplit 0.5.5

NAME

sslsplit.conf

configuration file format

DESCRIPTION

The configuration file allows you to change the default behaviour of sslsplit(1). The configuration file is organised in sections, each starting with a name enclosed in square brackets. For example, [Connection].

Within each section, directives are specified as name=value.

Directives are not case-sensitive. Comments start with a hash sign (#) and extend to the end of the line.

If a configuration directive is specified multiple times, the last one takes precedence.

Directives can also be specified on the command line using the -c option. Command line options override the configuration file settings.

FILE FORMAT

The configuration file syntax is loosely based on the syntax used by nginx(8).

Directives can be grouped within sections. Each section begins with a line containing the section name enclosed in square brackets, e.g. [Logger]. The directives within the section follow, one per line. Each directive is specified in the format name=value.

DIRECTIVES

verbose
Enable debug messages on stderr. Equivalent to -D command line option.
VerifyPeer BOOL
Verify peer using default certificates.
Default: no
AddSNIToCertificate BOOL
When disabled, never add the SNI to forged certificates, even if the SNI provided by the client does not match the server certificate's CN/SAN. Helps pass the wrong.host test at https://badssl.com.
Default: yes
ProxySpec STRING
Proxy specification: type listenaddr+port [natengine|targetaddr+port|"sni"+port]. Multiple specs are allowed, one on each line.

FILES

/etc/sslsplit/sslsplit.conf
