sgetmask(2) Manuel des appels système sgetmask(2)

NOM

sgetmask, ssetmask - manipulation du masque de signaux (obsolète)

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
[[deprecated]] long syscall(SYS_sgetmask, void);
[[deprecated]] long syscall(SYS_ssetmask, long nouveau_masque);

DESCRIPTION

Ces appels système sont obsolètes. Ne les utilisez pas ; utilisez sigprocmask(2) à la place.

sgetmask() retourne le masque de signaux du processus appelant.

ssetmask() définit le masque de signaux du processus appelant à la valeur donnée dans nouveau_masque. Le masque de signaux précédent est retourné.

Les masques de signaux gérés par ces deux appels système sont de simples masques de bits (contrairement au type sigset_t utilisé par sigprocmask(2)) ; utilisez sigmask(3) pour créer et inspecter ces masques.

VALEUR DE RETOUR

sgetmask() retourne toujours avec succès le masque de signaux. ssetmask() réussit toujours et retourne le masque de signaux précédent.

ERREURS

Ces appels système réussissent toujours.

NORMES

Linux.

HISTORIQUE

Depuis Linux 3.16, la prise en charge de ces appels système est facultative, selon que le noyau a été compilé avec l'option CONFIG_SGETMASK_SYSCALL.

NOTES

Ces appels système ne tiennent pas compte des numéros de signaux supérieurs à 31 (c'est-à-dire les signaux temps réel).

Ces appels système n'existent pas sur x86-64.

Il n'est pas possible de bloquer SIGSTOP ou SIGKILL.

VOIR AUSSI

sigprocmask(2), signal(7)
