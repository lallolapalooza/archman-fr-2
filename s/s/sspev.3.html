subroutine sspev (jobz, uplo, n, ap, w, z, ldz, work, info)
SSPEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauche et/ou droite pour LES AUTRES matrices

Documentation de la fonction/sous-programme

sous-programme sspev (caractère jobz, caractère uplo, entier n, réel, dimension( * ) ap, réel, dimension( * ) w, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier info)

SSPEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une matrice réelle symétrique A en stockage compact.

Objectif :

!>
!> SSPEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice réelle symétrique A en stockage compact.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres ;
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau REAL, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, stocké en colonne dans un tableau linéaire. La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          En sortie, AP est écrasé par des valeurs générées lors de la
!>          réduction à une forme tridiagonale. Si UPLO = 'U', la diagonale
!>          et la première superdiagonale de la matrice tridiagonale T écrasent
!>          les éléments correspondants de A, et si UPLO = 'L', la
!>          diagonale et la première sous-diagonale de T écrasent les
!>          éléments correspondants de A.
!>

W

!>          W est un tableau REAL, dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau REAL, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormaux de la matrice A, où la i-ième colonne de Z
!>          contient le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (3*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>
