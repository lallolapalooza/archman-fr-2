SSYTRI_3

Documentation de la fonction/sous-routine

sous-routine ssytri_3 (caractere uplo, entier n, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) e, entier, dimension( * ) ipiv, reel, dimension( * ) work, entier lwork, entier info)

SSYTRI_3

Objectif :

!> SSYTRI_3 calcule l'inverse d'une matrice réelle symétrique indéfinie
!> A en utilisant la factorisation calculée par SSYTRF_RK ou SSYTRF_BK :
!>
!>     A = P*U*D*(U**T)*(P**T) ou A = P*L*D*(L**T)*(P**T),
!>
!> où U (ou L) est une matrice triangulaire unitaire supérieure (ou inférieure),
!> U**T (ou L**T) est la transposée de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est symétrique et diagonale par blocs
!> avec des blocs diagonaux de 1x1 et 2x2.
!>
!> SSYTRI_3 définit la dimension principale de l'espace de travail avant d'appeler
!> SSYTRI_3X qui calcule réellement l'inverse. C'est la version bloquée
!> de l'algorithme, faisant appel à BLAS de niveau 3.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U' : La partie triangulaire supérieure de A est stockée ;
!>          = 'L' : La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau REEL, de dimensions (LDA,N)
!>          À l'entrée, la diagonale de la matrice diagonale par blocs D et
!>          les facteurs U ou L calculés par SSYTRF_RK et SSYTRF_BK :
!>            a) SEULEMENT les éléments diagonaux de la matrice symétrique diagonale par blocs
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments supradiagonaux (ou subdiagonaux) de D
!>                doivent être fournis en entrée dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie supradiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie subdiagonale de A.
!>
!>          À la sortie, si INFO = 0, l'inverse symétrique de la matrice originale.
!>             Si UPLO = 'U' : la partie triangulaire supérieure de l'inverse
!>             est formée et la partie de A sous la diagonale n'est pas
!>             référencée ;
!>             Si UPLO = 'L' : la partie triangulaire inférieure de l'inverse
!>             est formée et la partie de A au-dessus de la diagonale n'est pas
!>             référencée.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

E

!>          E est un tableau REEL, de dimensions (N)
!>          À l'entrée, contient les éléments supradiagonaux (ou subdiagonaux)
!>          de la matrice symétrique diagonale par blocs D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) non référencé ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) non référencé.
!>
!>          NOTE : Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) n'est pas référencé dans les deux
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau ENTIER, de dimensions (N)
!>          Détails des échanges et de la structure par blocs de D
!>          tels que déterminés par SSYTRF_RK ou SSYTRF_BK.
!>

WORK

!>          WORK est un tableau REEL, de dimensions (MAX(1,LWORK)).
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur de WORK.
!>          Si N = 0, LWORK >= 1, sinon LWORK >= (N+NB+1)*(NB+3).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale de l'espace de travail optimal
!>          du tableau WORK, renvoie cette valeur comme première entrée du
!>          tableau WORK, et aucun message d'erreur lié à
!>          LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, D(i,i) = 0 ; la matrice est singulière et son
!>               inverse n'a pas pu être calculé.
!>
