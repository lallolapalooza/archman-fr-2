Documentation de la fonction/sous-programme

sous-routine ssteqr (caractère compz, entier n, réel, dimension( * ) d, réel, dimension( * ) e, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier info)

SSTEQR

But :

!>
!> SSTEQR calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique en utilisant la méthode implicite QL ou QR.
!> Les vecteurs propres d'une matrice symétrique pleine ou bande peuvent également
!> être trouvés si SSYTRD ou SSPTRD ou SSBTRD a été utilisé pour réduire cette
!> matrice à la forme tridiagonale.
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N' : Calcule uniquement les valeurs propres.
!>          = 'V' : Calcule les valeurs propres et les vecteurs propres de la
!>                  matrice symétrique d'origine. En entrée, Z doit contenir la
!>                  matrice orthogonale utilisée pour réduire la matrice d'origine
!>                  à la forme tridiagonale.
!>          = 'I' : Calcule les valeurs propres et les vecteurs propres de la
!>                  matrice tridiagonale. Z est initialisée à la matrice identité.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N >= 0.
!>

D

!>          D est un tableau de REAL de dimension (N)
!>          En entrée, les éléments diagonaux de la matrice tridiagonale.
!>          En sortie, si INFO = 0, les valeurs propres par ordre croissant.
!>

E

!>          E est un tableau de REAL de dimension (N-1)
!>          En entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale.
!>          En sortie, E a été détruit.
!>

Z

!>          Z est un tableau de REAL de dimension (LDZ, N)
!>          En entrée, si COMPZ = 'V', alors Z contient la matrice orthogonale
!>          utilisée dans la réduction à la forme tridiagonale.
!>          En sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormés de la matrice symétrique d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormés
!>          de la matrice tridiagonale symétrique.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          des vecteurs propres sont désirés, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de REAL de dimension (max(1,2*N-2))
!>          Si COMPZ = 'N', alors WORK n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : l'algorithme n'a pas réussi à trouver toutes les valeurs propres
!>                en un total de 30*N itérations ; si INFO = i, alors i
!>                éléments de E n'ont pas convergé vers zéro ; en sortie, D
!>                et E contiennent les éléments d'une matrice tridiagonale
!>                symétrique qui est orthogonalement similaire à la matrice
!>                d'origine.
!>
