Documentation de fonction/sous-routine

sous-routine ssyl01 (real thresh, integer, dimension( 3 ) nfail, real, dimension( 2 ) rmax, integer, dimension( 2 ) ninfo, integer knt)

SSYL01

Objectif :

!>
!> SSYL01 teste STRSYL et STRSYL3, des routines pour résoudre l'équation matricielle de Sylvester
!>
!>    op(A)*X + ISGN*X*op(B) = scale*C,
!>
!> où A et B sont supposées être sous forme canonique de Schur, op() représente une
!> transposition optionnelle, et ISGN peut être -1 ou +1. Scale est une sortie
!> inférieure ou égale à 1, choisie pour éviter le débordement dans X.
!>
!> Le code de test vérifie que le résidu suivant ne dépasse pas
!> le seuil fourni :
!>
!>    norm(op(A)*X + ISGN*X*op(B) - scale*C) /
!>        (EPS*max(norm(A),norm(B))*norm(X))
!>
!> Cette routine complète SGET35 en testant avec des matrices plus grandes et aléatoires, dont certaines nécessitent un rééchelonnement de X pour éviter le débordement.
!>
!>

Paramètres

THRESH 
!>          THRESH est REAL
!>          Un test sera compté comme réussi si le résidu, calculé comme
!>          décrit ci-dessus, dépasse THRESH.
!>

NFAIL

!>          NFAIL est un tableau INTEGER, dimension (3)
!>          NFAIL(1) = Nombre de fois où le résidu STRSYL dépasse le seuil THRESH
!>          NFAIL(2) = Nombre de fois où le résidu STRSYL3 dépasse le seuil THRESH
!>          NFAIL(3) = Nombre de fois où STRSYL3 et STRSYL divergent
!>

RMAX

!>          RMAX est REAL, dimension (2)
!>          RMAX(1) = Valeur du plus grand ratio de test de STRSYL
!>          RMAX(2) = Valeur du plus grand ratio de test de STRSYL3
!>

NINFO

!>          NINFO est un tableau INTEGER, dimension (2)
!>          NINFO(1) = Nombre de fois où STRSYL retourne un INFO attendu
!>          NINFO(2) = Nombre de fois où STRSYL3 retourne un INFO attendu
!>

KNT

!>          KNT est INTEGER
!>          Nombre total d'exemples testés.
!>

Définition à la ligne 88 du fichier ssyl01.f.
