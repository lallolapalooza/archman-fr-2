NOM

systemd-ac-power - Signaler si nous sommes connectés à une source d'alimentation externe

SYNTAXE

systemd-ac-power [OPTIONS...]

DESCRIPTION

systemd-ac-power peut être utilisé pour vérifier si le système fonctionne sur l'alimentation secteur ou non. Par défaut, il renvoie simplement un succès (si nous pouvons détecter que nous fonctionnons sur l'alimentation secteur) ou un échec, sans aucune sortie. Cela peut être utile par exemple pour déboguer ConditionACPower= (voir systemd.unit(5)).

OPTIONS

Les options suivantes sont comprises :

-v, --verbose

Affiche le résultat sous forme de texte au lieu de simplement renvoyer un succès ou un échec.

Ajouté dans la version 253.

--low

Au lieu d'afficher l'état de l'alimentation secteur, affiche l'état de la batterie faible. Dans ce cas, renvoie zéro si toutes les batteries se déchargent actuellement et sont en dessous de 5% de leur charge maximale. Renvoie une valeur non nulle sinon.

Ajouté dans la version 254.

-h, --help

Affiche un court texte d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.

STATUT DE SORTIE

En cas de succès (fonctionnement sur l'alimentation secteur), 0 est renvoyé, un code d'échec non nul sinon.
