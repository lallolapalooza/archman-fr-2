SYD-X(1) Manuel des commandes générales SYD-X(1)

NOM

syd-x - Vérifie l'exécutabilité des fichiers, liste les exécutables des processus

SYNTAXE

syd-x [-hcv] [-l pid...] [fichiers...]

DESCRIPTION

syd-x vérifie l'exécutabilité des fichiers donnés ou liste les exécutables des processus donnés. La vérification de l'exécutabilité des fichiers utilise l'appel système execveat(2) avec le drapeau "AT_EXECVE_CHECK" sur Linux>=6.14 et se rabat sur l'appel système faccessat(2) avec le drapeau "X_OK" sur les versions plus anciennes de Linux. Si l'option -l est spécifiée, le mode liste est activé : tous les arguments suivants sont interprétés comme des identifiants de processus, et non comme des fichiers. En mode liste, le listage des fichiers exécutables est effectué à l'aide de la requête d'appel système ioctl(2) "PROCMAP_QUERY" sur Linux>=6.11 et se rabat sur l'analyse du fichier proc_pid_maps(5) textuellement sur les versions plus anciennes de Linux.

OPTIONS

-h Affiche l'aide.
-c Termine avec succès si le drapeau "AT_EXECVE_CHECK" est supporté.
-l pid Spécifie un identifiant de processus dont il faut lister les exécutables, peut être répété.
-v Affiche les informations sur le statut de vérification du fichier sur la sortie d'erreur standard.

STATUT DE SORTIE

syd-x se termine avec 0 en cas de succès ou avec le numéro d'errno en cas d'échec.

VOIR AUSSI
