SYSTEMD-NETWORKD-WAIT-ONLINE.SERVICE(8) systemd-networkd-wait-online.service SYSTEMD-NETWORKD-WAIT-ONLINE.SERVICE(8)

NOM

systemd-networkd-wait-online.service, systemd-networkd-wait-online@.service, systemd-networkd-wait-online - Attendre que le réseau soit en ligne

SYNTAXE

systemd-networkd-wait-online.service

systemd-networkd-wait-online@.service

/usr/lib/systemd/systemd-networkd-wait-online

DESCRIPTION

systemd-networkd-wait-online est un service système oneshot (voir systemd.service(5)) qui attend la configuration du réseau. Par défaut, il attend que toutes les interfaces qu'il connaît et qui sont gérées par systemd-networkd.service(8) soient complètement configurées ou en échec, et qu'au moins une interface soit en ligne. Ici, en ligne signifie que l'état opérationnel de l'interface est égal ou supérieur à "degraded". Le seuil peut être configuré avec l'option --operational-state=.

Le service systemd-networkd-wait-online.service invoque systemd-networkd-wait-online sans aucune option. Ainsi, il attend que toutes les interfaces gérées soient configurées ou en échec, et qu'au moins une soit en ligne.

Le service systemd-networkd-wait-online@.service prend le nom d'une interface et invoque systemd-networkd-wait-online avec -i et le nom d'interface spécifié. Ainsi, il attend que l'interface spécifiée soit configurée et en ligne. Par exemple, systemd-networkd-wait-online@eth0.service attend que eth0 soit configurée par systemd-networkd et en ligne.

OPTIONS

Les options suivantes sont comprises :

-i INTERFACE[:MIN_OPERSTATE[:MAX_OPERSTATE]], --interface=INTERFACE[:MIN_OPERSTATE[:MAX_OPERSTATE]]

Interface réseau à surveiller avant de décider si le système est en ligne. Ceci est utile lorsqu'un système possède plusieurs interfaces qui seront configurées, mais qu'une interface particulière est nécessaire pour accéder à certaines ressources réseau. Lorsqu'elle est utilisée, toutes les autres interfaces sont ignorées. Cette option peut être utilisée plus d'une fois pour surveiller plusieurs interfaces réseau. Lorsque cette option est spécifiée plusieurs fois, systemd-networkd-wait-online attend que toutes les interfaces spécifiées soient en ligne. Optionnellement, les états opérationnels minimum et maximum requis peuvent être spécifiés après un deux-points ":". Voir networkctl(1) pour les états opérationnels possibles. Si l'état opérationnel n'est pas spécifié ici, alors la valeur de RequiredForOnline= du fichier .network correspondant est utilisée s'il est présent, sinon "degraded".

Ajouté dans la version 213.

--ignore=INTERFACE

Interfaces réseau à ignorer lors de la décision si le système est en ligne. Par défaut, seule l'interface de bouclage est ignorée. Cette option peut être utilisée plus d'une fois pour ignorer plusieurs interfaces réseau.

Ajouté dans la version 219.

-o MIN_OPERSTATE[:MAX_OPERSTATE], --operational-state=MIN_OPERSTATE[:MAX_OPERSTATE]

Prend un état opérationnel minimum et un état opérationnel maximum optionnel. Voir networkctl(1) pour les états opérationnels possibles. S'il est défini, la valeur spécifiée remplace les paramètres RequiredForOnline= dans les fichiers .network. Mais cela ne remplace pas les états opérationnels spécifiés dans l'option --interface=.

Ajouté dans la version 242.

-4, --ipv4

Attente d'une adresse IPv4 de chaque interface réseau pour qu'elle soit configurée. Si cette option est spécifiée avec --any, alors systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne et possède une adresse IPv4. Si l'état opérationnel minimum requis est inférieur à "routable", alors chaque liaison (ou au moins une liaison avec --any) doit avoir une adresse IPv4 de liaison locale ou routable. Si l'état opérationnel minimum requis est "routable", alors chaque liaison doit avoir une adresse IPv4 routable.

Si ni --ipv4 ni --ipv6 n'est spécifié, alors la valeur de RequiredFamilyForOnline= dans le fichier .network correspondant est utilisée si elle est présente.

Ajouté dans la version 249.

-6, --ipv6

Attente d'une adresse IPv6 de chaque interface réseau pour qu'elle soit configurée. Si cette option est spécifiée avec --any, alors systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne et possède une adresse IPv6. Si l'état opérationnel minimum requis est inférieur à "routable", alors chaque liaison (ou au moins une liaison avec --any) doit avoir une adresse IPv6 de liaison locale ou routable. Si l'état opérationnel minimum requis est "routable", alors chaque liaison doit avoir une adresse IPv6 routable.

Si ni --ipv4 ni --ipv6 n'est spécifié, alors la valeur de RequiredFamilyForOnline= dans le fichier .network correspondant est utilisée si elle est présente.

Ajouté dans la version 249.

--dns

Attente que les serveurs DNS soient accessibles sur chaque interface. Si cette option est spécifiée avec --any, alors systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne et possède un serveur DNS accessible.

Si une liaison a la propriété DefaultRoute=yes (soit parce que la propriété réseau DNSDefaultRoute= est explicitement configurée, soit parce que la liaison n'a aucun domaine "routing-only"), ou si le domaine de recherche "." est configuré, alors attendre que les serveurs DNS spécifiques à la liaison soient accessibles. Sinon, permettre aux serveurs DNS globaux de satisfaire la condition.

Ajouté dans la version 258.

--any

Même si plusieurs interfaces sont en état de configuration, systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne. Lorsque cette option est spécifiée avec --interface=, systemd-networkd-wait-online attend qu'une des interfaces spécifiées soit en ligne. Cette option est utile lorsque certaines interfaces peuvent ne pas avoir de porteuse au démarrage.

Ajouté dans la version 242.

--timeout=SECS

Faire échouer le service si le réseau n'est pas en ligne lorsque le délai d'attente est écoulé. Un délai de 0 désactive le délai d'attente. Par défaut, 120 secondes.

Ajouté dans la version 219.

-q, --quiet

Supprimer les messages de log.

Ajouté dans la version 242.

-h, --help

Afficher un bref texte d'aide et quitter.

--version

Afficher une courte chaîne de version et quitter.
