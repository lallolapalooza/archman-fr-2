sys_time.h(0P) Manuel du programmeur POSIX sys_time.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/time.h — types de temps

SYNTAXE

#include <sys/time.h>

DESCRIPTION

L'en-tête <sys/time.h> définit la structure timeval, qui comprend au moins les membres suivants :

time_t         tv_sec      Secondes.
suseconds_t    tv_usec     Microsecondes.

L'en-tête <sys/time.h> définit la structure itimerval, qui comprend au moins les membres suivants :

struct timeval it_interval Intervalle du timer.
struct timeval it_value    Valeur actuelle.

L'en-tête <sys/time.h> définit les types time_t et suseconds_t tels que décrits dans <sys/types.h>.

L'en-tête <sys/time.h> définit le type fd_set tel que décrit dans <sys/select.h>.

L'en-tête <sys/time.h> définit les constantes symboliques suivantes pour l'argument which de getitimer() et setitimer() :

ITIMER_REAL
Décrémente en temps réel.
ITIMER_VIRTUAL
Décrémente en temps virtuel du processus.
ITIMER_PROF
Décrémente à la fois en temps virtuel du processus et lorsque le système s'exécute pour le compte du processus.

L'en-tête <sys/time.h> définit les éléments suivants tels que décrits dans <sys/select.h> : FD_CLR() FD_ISSET() FD_SET() FD_ZERO() FD_SETSIZE

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonctions seront fournis.

int   getitimer(int, struct itimerval *);
int   gettimeofday(struct timeval *restrict, void *restrict);
int   setitimer(int, const struct itimerval *restrict,
          struct itimerval *restrict);
int   select(int, fd_set *restrict, fd_set *restrict, fd_set *restrict,
          struct timeval *restrict);
int   utimes(const char *, const struct timeval [2]);

L'inclusion de l'en-tête <sys/time.h> peut rendre visibles tous les symboles de l'en-tête <sys/select.h>.
