sys_uio.h(0P) Manuel du programmeur POSIX sys_uio.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/uio.h — définitions pour les opérations d'E/S vectorielles

SYNOPSIS

#include <sys/uio.h>

DESCRIPTION

L'en-tête <sys/uio.h> définit la structure iovec, qui comprendra au moins les membres suivants :

void   *iov_base  Adresse de base d'une région mémoire pour l'entrée ou la sortie.
size_t  iov_len   La taille de la mémoire pointée par iov_base.

L'en-tête <sys/uio.h> utilise la structure iovec pour les opérations d'E/S par paquets (scatter/gather).

L'en-tête <sys/uio.h> définit les types ssize_t et size_t tels que décrits dans <sys/types.h>.

Les éléments suivants seront déclarés comme des fonctions et pourront également être définis comme des macros. Les prototypes de fonctions seront fournis.

ssize_t readv(int, const struct iovec *, int);
ssize_t writev(int, const struct iovec *, int);

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

L'implémentation peut imposer une limite sur le nombre d'éléments de paquets (scatter/gather) pouvant être traités en un seul appel. Le symbole {IOV_MAX} défini dans <limits.h> doit toujours être utilisé pour connaître les limites au lieu de supposer une valeur fixe.

RATIONNELLE

Traditionnellement, le nombre maximum d'éléments de paquets que le système peut traiter en un seul appel était décrit par la valeur symbolique {UIO_MAXIOV}. Dans IEEE Std 1003.1‐2001, cette valeur est remplacée par la constante {IOV_MAX} qui se trouve dans <limits.h>.
