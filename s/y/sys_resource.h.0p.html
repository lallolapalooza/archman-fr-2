sys_resource.h(0P) Manuel du programmeur POSIX sys_resource.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/resource.h — définitions pour les opérations de ressources XSI

SYNTAXE

#include <sys/resource.h>

DESCRIPTION

L'en-tête <sys/resource.h> définira les constantes symboliques suivantes comme valeurs possibles pour l'argument which de getpriority() et setpriority():

PRIO_PROCESS
Identifie l'argument who comme un identifiant de processus.
PRIO_PGRP
Identifie l'argument who comme un identifiant de groupe de processus.
PRIO_USER
Identifie l'argument who comme un identifiant utilisateur.

L'en-tête <sys/resource.h> définira le type suivant par le biais d'un typedef :

rlim_t
Type entier non signé utilisé pour les valeurs de limite.

L'en-tête <sys/resource.h> définira les constantes symboliques suivantes, qui auront des valeurs appropriées pour être utilisées dans des directives de préprocesseur #if :

RLIM_INFINITY
Une valeur de rlim_t indiquant aucune limite.
RLIM_SAVED_MAX
Une valeur de type rlim_t indiquant une limite matérielle sauvegardée non représentable.
RLIM_SAVED_CUR
Une valeur de type rlim_t indiquant une limite souple sauvegardée non représentable.

Sur les implémentations où toutes les limites de ressources sont représentables dans un objet de type rlim_t, RLIM_SAVED_MAX et RLIM_SAVED_CUR n'ont pas besoin d'être distincts de RLIM_INFINITY.

L'en-tête <sys/resource.h> définira les constantes symboliques suivantes comme valeurs possibles pour le paramètre who de getrusage():

RUSAGE_SELF
Retourne des informations sur le processus courant.
RUSAGE_CHILDREN
Retourne des informations sur les enfants du processus courant.

L'en-tête <sys/resource.h> définira la structure rlimit, qui inclura au moins les membres suivants :

rlim_t rlim_cur  La limite courante (souple).
rlim_t rlim_max  La limite matérielle.

L'en-tête <sys/resource.h> définira la structure rusage, qui inclura au moins les membres suivants :

struct timeval ru_utime  Temps utilisateur utilisé.
struct timeval ru_stime  Temps système utilisé.

L'en-tête <sys/resource.h> définira la structure timeval telle que décrite dans <sys/time.h>.

L'en-tête <sys/resource.h> définira les constantes symboliques suivantes comme valeurs possibles pour l'argument resource de getrlimit() et setrlimit():

RLIMIT_CORE
Limite de la taille du fichier core.
RLIMIT_CPU
Limite du temps CPU par processus.
RLIMIT_DATA
Limite de la taille du segment de données.
RLIMIT_FSIZE
Limite de la taille des fichiers.
RLIMIT_NOFILE
Limite du nombre de fichiers ouverts.
RLIMIT_STACK
Limite de la taille de la pile.
RLIMIT_AS
Limite de la taille de l'espace d'adressage.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonction seront fournis.

int  getpriority(int, id_t);
int  getrlimit(int, struct rlimit *);
int  getrusage(int, struct rusage *);
int  setpriority(int, id_t, int);
int  setrlimit(int, const struct rlimit *);

L'en-tête <sys/resource.h> définira le type id_t par le biais d'un typedef, tel que décrit dans <sys/types.h>.

L'inclusion de l'en-tête <sys/resource.h> pourra également rendre visibles tous les symboles de <sys/time.h>.
