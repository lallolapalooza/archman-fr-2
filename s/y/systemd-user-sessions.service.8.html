NOM

systemd-user-sessions.service, systemd-user-sessions - Permettre les connexions utilisateur après le démarrage, interdire les connexions utilisateur à l'arrêt

SYNOPSIS

systemd-user-sessions.service

/usr/lib/systemd/systemd-user-sessions

DESCRIPTION

systemd-user-sessions.service est un service qui contrôle les connexions utilisateur via pam_nologin(8). Une fois l'initialisation de base du système terminée, il supprime le fichier /run/nologin, autorisant ainsi les connexions. Avant l'arrêt du système, il crée le fichier /run/nologin, interdisant ainsi les connexions ultérieures.

VOIR AUSSI

systemd(1), systemd-logind.service(8), pam_nologin(8)
