SYD-SYS(1) Manuel des commandes générales SYD-SYS(1)

NOM

syd-sys - Rechercher les appels système, les numéros d'erreur, les requêtes ioctl, les drapeaux open et les signaux par numéro ou par expression régulière

SYNTAXE

syd-sys [-heios] [-a arch] numéro|regex

syd-sys -a list

syd-sys [-uU]

DESCRIPTION

Étant donné un numéro, syd-sys affiche le nom de l'appel système correspondant.

Étant donné une expression régulière, syd-sys affiche les noms d'appels système correspondants sans tenir compte de la casse.

Utilisez -e pour interroger les numéros de errno(3).

Utilisez -i pour interroger les requêtes ioctl(2).

Utilisez -o pour interroger les drapeaux open(2).

Utilisez -s pour interroger les numéros de signal(7).

Utilisez -u pour lister les inodes de sockets de domaine UNIX en utilisant netlink(7).

Utilisez -U pour lister les inodes de sockets de domaine UNIX en utilisant proc_net(5).

OPTIONS

-h Afficher l'aide.
-a Spécifier une architecture alternative, telle que x86, x86_64 et aarch64.
Utilisez list pour afficher la liste des architectures prises en charge par libseccomp.
-e Interroger les numéros de errno(3)
-i Interroger les requêtes ioctl(2)
-o Interroger les drapeaux open(2)
-s Interroger les numéros de signal(7)
-u Lister les inodes de sockets de domaine UNIX en utilisant netlink(7)
-U Lister les inodes de sockets de domaine UNIX en utilisant proc_net(5)

VOIR AUSSI

syd(1), syd(2), syd(5), errno(3), ioctl(2), open(2), syscall(2), signal(7), netlink(7)
