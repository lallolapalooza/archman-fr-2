SYD-PATH(1) Manuel des commandes générales SYD-PATH(1)

NOM

syd-path - Écrit les règles de sandboxing Force pour les binaires et liste les exécutables dans PATH

SYNTAXE

syd-path [-h1235cCeklmpsw]

DESCRIPTION

Écrit les règles de sandboxing Force pour les binaires dans PATH.

Si au moins une des options -e est spécifiée, liste les exécutables avec les informations spécifiées sous PATH.

OPTIONS

-h Affiche l'aide.
-c Calcule la somme de contrôle CRC64 (insécurisé).
-C Calcule la somme de contrôle CRC32 (insécurisé).
-m Calcule la somme de contrôle MD5 (insécurisé, compatible vdb portage/paludis).
-1 Calcule la somme de contrôle SHA1 (insécurisé).
-2 Calcule la somme de contrôle SHA3-256.
-3 Calcule la somme de contrôle SHA3-384.
-5 Calcule la somme de contrôle SHA3-512 (par défaut).
-k Utilise l'action kill (par défaut).
-w Utilise l'action warn.
-l num Limite par nombre d'entrées.
-p path Spécifie un PATH alternatif.
-s Précède les règles de "/dev/syd/".
-e32 Liste les exécutables ELF 32 bits dans PATH (entre en conflit avec -e64).
-e64 Liste les exécutables ELF 64 bits dans PATH (entre en conflit avec -e32).
-ed Liste les exécutables ELF liés dynamiquement dans PATH (entre en conflit avec -es).
-es Liste les exécutables ELF liés statiquement dans PATH (entre en conflit avec -ed).
-ep Liste les exécutables PIE dans PATH (entre en conflit avec -eP).
-eP Liste les exécutables non-PIE dans PATH (entre en conflit avec -ep).
-ex Liste les scripts dans PATH.
-eX Liste les binaires avec pile exécutable dans PATH.

BOGUES

Cet outil ignorera silencieusement toute erreur.
