NOM

syncsnoop.bt - Trace les appels système de la variété sync(). Utilise bpftrace/eBPF.

SYNTAXE

syncsnoop.bt

DESCRIPTION

syncsnoop trace les appels aux appels système sync() (sync(), fsync(), msync(), etc.), qui vident le cache du système de fichiers et les tampons vers les périphériques de stockage. Ces appels peuvent entraîner des perturbations de performance, et il peut être utile de savoir s'ils se produisent, quand ils se produisent et à quelle fréquence.

Cela fonctionne en traçant la variété des appels système sync() via les points de trace.

Ce programme est également un exemple basique de eBPF/bcc.

Puisque cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

PRÉREQUIS

CONFIG_BPF et bpftrace.

EXEMPLES

Trace les appels aux appels système sync():
# syncsnoop.bt

CHAMPS

HEURE
Une horodatage sur la sortie, au format "HH:MM:SS".
PID
L'ID du processus qui était sur le CPU pendant l'événement.
COMM
Le nom du processus qui était sur le CPU pendant l'événement.
ÉVÉNEMENT
Le nom du point de trace pour l'événement sync.

SURCHARGE

Cela trace les appels système sync et affiche la sortie pour chaque événement. Comme le taux de cela est généralement attendu comme étant faible (<< 100/s), la surcharge est également attendue comme étant négligeable.
