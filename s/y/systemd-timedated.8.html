NOM

systemd-timedated.service, systemd-timedated - Mécanisme d'horloge et de date par bus

SYNTAXE

systemd-timedated.service

/usr/lib/systemd/systemd-timedated

DESCRIPTION

systemd-timedated.service est un service système qui peut être utilisé comme mécanisme pour changer l'horloge système et le fuseau horaire, ainsi que pour activer/désactiver la synchronisation de l'heure via le réseau. systemd-timedated est activé automatiquement sur demande et se termine lorsqu'il n'est plus utilisé.

L'outil timedatectl(1) est un client en ligne de commande pour ce service.

systemd-timedated offre actuellement un accès aux quatre réglages suivants :

•L'heure système
•Le fuseau horaire système
•Un booléen contrôlant si l'horloge temps réel (RTC) système est en fuseau horaire local ou UTC
•Si le service de synchronisation horaire est activé/démarré ou désactivé/arrêté, voir la section suivante.

Voir org.freedesktop.timedate1(5) et org.freedesktop.LogControl1(5) pour des informations sur l'API D-Bus.

LISTE DES SERVICES DE SYNCHRONISATION HORAIRE RÉSEAU

systemd-timedated recherche des fichiers avec l'extension « .list » dans les répertoires ntp-units.d/. Chaque fichier est analysé comme une liste de noms d'unités, un par ligne. Les lignes vides et les lignes contenant des commentaires (« # ») sont ignorées. Les fichiers sont lus depuis /usr/lib/systemd/ntp-units.d/ et les répertoires correspondants sous /etc/, /run/, /usr/local/lib/. Les fichiers dans /etc/ remplacent les fichiers du même nom dans /run/, /usr/local/lib/, et /usr/lib/. Les fichiers dans /run/ remplacent les fichiers du même nom sous /usr/. Les paquets doivent installer leurs fichiers de configuration dans /usr/lib/ (paquets de distribution) ou /usr/local/lib/ (installations locales).

Exemple 1. Entrée ntp-units.d/ pour systemd-timesyncd

# /usr/lib/systemd/ntp-units.d/80-systemd-timesync.list
systemd-timesyncd.service

Si la variable d'environnement $SYSTEMD_TIMEDATED_NTP_SERVICES est définie, systemd-timedated analyse le contenu de cette variable comme une liste de noms d'unités séparés par des deux-points. Lorsqu'elle est définie, cette variable remplace la liste basée sur les fichiers décrite ci-dessus.

Exemple 2. Un remplacement spécifiant que chronyd doit être utilisé s'il est disponible

SYSTEMD_TIMEDATED_NTP_SERVICES=chronyd.service:systemd-timesyncd.service
