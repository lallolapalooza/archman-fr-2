syslog.h(0p) Manuel du programmeur POSIX syslog.h(0p)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

syslog.h — définitions pour la journalisation des erreurs système

SYNOPSIS

#include <syslog.h>

DESCRIPTION

L'en-tête <syslog.h> définit les constantes symboliques suivantes, dont zéro ou plusieurs peuvent être combinées avec un OU pour former l'option logopt de openlog():

LOG_PID
Journalise l'identifiant du processus avec chaque message.
LOG_CONS
Journalise sur la console système en cas d'erreur.
LOG_NDELAY
Se connecte immédiatement au démon syslog.
LOG_ODELAY
Retarde l'ouverture jusqu'à ce que syslog() soit appelé.
LOG_NOWAIT
N'attend pas les processus fils.

L'en-tête <syslog.h> définit les constantes symboliques suivantes pour être utilisées comme argument facility de openlog():

LOG_KERN
Réservé pour les messages générés par le système.
LOG_USER
Messages générés par un processus.
LOG_MAIL
Réservé pour les messages générés par le système de messagerie.
LOG_NEWS
Réservé pour les messages générés par le système de news.
LOG_UUCP
Réservé pour les messages générés par le système UUCP.
LOG_DAEMON
Réservé pour les messages générés par un démon système.
LOG_AUTH
Réservé pour les messages générés par un démon d'autorisation.
LOG_CRON
Réservé pour les messages générés par le démon d'horloge.
LOG_LPR
Réservé pour les messages générés par le système d'impression.
LOG_LOCAL0
Réservé pour un usage local.
LOG_LOCAL1
Réservé pour un usage local.
LOG_LOCAL2
Réservé pour un usage local.
LOG_LOCAL3
Réservé pour un usage local.
LOG_LOCAL4
Réservé pour un usage local.
LOG_LOCAL5
Réservé pour un usage local.
LOG_LOCAL6
Réservé pour un usage local.
LOG_LOCAL7
Réservé pour un usage local.

L'en-tête <syslog.h> définit les constantes symboliques suivantes pour construire l'argument maskpri de setlogmask(). Les macros suivantes s'étendent à une expression de type int lorsque l'argument pri est une expression de type int:

LOG_MASK(pri)
Un masque pour la priorité pri.

L'en-tête <syslog.h> définit les constantes symboliques suivantes pour être utilisées comme argument priority de syslog():

LOG_EMERG
Une condition de panique a été signalée à tous les processus.
LOG_ALERT
Une condition qui devrait être corrigée immédiatement.
LOG_CRIT
Une condition critique.
LOG_ERR
Un message d'erreur.
LOG_WARNING
Un message d'avertissement.
LOG_NOTICE
Une condition nécessitant une gestion spéciale.
LOG_INFO
Un message d'information générale.
LOG_DEBUG
Un message utile pour le débogage des programmes.

Les fonctions suivantes seront déclarées et pourront également être définies comme macros. Les prototypes de fonctions seront fournis.

void  closelog(void);
void  openlog(const char *, int, int);
int   setlogmask(int);
void  syslog(int, const char *, ...);
