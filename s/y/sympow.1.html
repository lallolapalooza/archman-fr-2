NOM

sympow - Programme SYMPOW

SYNTAXE

sympow [options]

DESCRIPTION

Package mathématique pour calculer les valeurs spéciales des fonctions L des courbes elliptiques SYMmetric POWer (jusqu'à environ 64 chiffres de précision).

OPTIONS

-borne #
une BORNE supérieure pour le nombre de ap à calculer
-info [] []
ne rapporter que les informations locales pour les nombres premiers/sympow ; le 1er argument est la plage de nombres premiers, le 2ème la plage de sympow
-local
ne rapporter que les informations locales (nombres premiers problématiques)
-courbe []
entrer une courbe sous forme [a1,a2,a3,a4,a6]
-etiquette []
obtenir une étiquette pour la courbe donnée
-discret
désactiver certains messages : par défaut
-concis
activer certains messages
-verbeux
activer des messages supplémentaires
-racinen #
calculer le nombre racine de la #ème puissance symétrique
-degmod
calculer le degré modulaire
-rankanal
calculer le rang analytique
-brouillon []
pour être utilisé avec -rankanal ; avoir X chiffres approximatifs
-pascm
abandonner si la courbe a une multiplication complexe
-pascarr
ignorer les puissances paires des twists quadratiques non minimaux
-pasqd
ne pas vérifier si les fonctions quad-double fonctionnent
-vitessmd []
vitesse pour degmod ; 2.0 est la valeur par défaut, 0.0 est la preuve
-hecke
calculer les puissances symétriques de Hecke pour une courbe CM
-maxitable
définir la taille maximale des tables de facteurs : 2^27 par défaut
-sp []
argument pour spécifier quelles puissances, c'est une liste séparée par des virgules dans chaque entrée, la 1ère donnée est le sympow, puis peut suivre b qui active Bloch-Kato, puis peut suivre w# qui spécifie le nombre de tests, puis peut suivre s# qui indique # chiffres approximatifs, puis doit suivre p# qui spécifie la précision ou P# qui dit d'ignorer BOUND pour cette puissance, puis doit suivre d# qui indique la borne de dérivée ou D# qui dit de ne faire que cette dérivée (ni l'un ni l'autre n'a besoin d'être indiqué pour les puissances paires) par défaut c'est 2w3s1p32,3bp16d1,4p8
-nouvelles_donnees []
calculera le maillage de la transformée de Mellin inverse pour les données données : le format est [sp]d[dv]{h,c} sp est la puissance symétrique, dv est la dérivée, h indique les puissances de Hecke, et c indique le cas CM d[dv] est donné uniquement pour les puissances impaires ou de Hecke Exemples : 1d3 2 2d1h 3d2 4 4c 5d0 6 7d0h 11d1 12c NOTE : nouvelles_donnees exécute un script shell qui utilise GP
-sauvegarder-tuple_endian
affiche le tuple endian, utilisé comme composant dans les chemins des données binaires, puis quitte

-sauvegarder-tuple_version affiche le tuple de version (Majeur.mineur.micro) et quitte

-version
affiche la version du programme et quitte
-aide
affiche cette aide et quitte

Les autres options sont utilisées en interne/récursivement par -nouvelles_donnees
