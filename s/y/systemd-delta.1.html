NOM

systemd-delta - Trouver les fichiers de configuration substitués

SYNTAXE

systemd-delta [OPTIONS...] [PRÉFIXE | PRÉFIXE/SUFFIXE | SUFFIXE...]

DESCRIPTION

systemd-delta peut être utilisé pour identifier et comparer les fichiers de configuration qui en substituent d'autres. Les fichiers dans /etc/ ont la priorité la plus élevée, les fichiers dans /run/ ont la seconde priorité la plus élevée, ..., les fichiers dans /usr/lib/ ont la priorité la plus basse. Les fichiers dans un répertoire de priorité plus élevée substituent les fichiers portant le même nom dans les répertoires de priorité plus basse. De plus, certains fichiers de configuration peuvent avoir des répertoires ".d" qui contiennent des fichiers "drop-in" avec des extraits de configuration qui augmentent le fichier de configuration principal. Les fichiers "drop-in" peuvent être substitués de la même manière en plaçant des fichiers portant le même nom dans un répertoire de priorité plus élevée (sauf que, dans le cas des fichiers "drop-in", le nom du fichier "drop-in" et le nom du répertoire conteneur, qui correspond au nom du fichier de configuration principal, doivent correspondre). Pour une explication plus complète, voir systemd.unit(5).

L'argument de la ligne de commande sera divisé en un préfixe et un suffixe. L'un ou l'autre est optionnel. Le préfixe doit être l'un des répertoires contenant des fichiers de configuration (/etc/, /run/, /usr/lib/, ...). S'il est donné, seuls les fichiers de substitution contenus dans ce répertoire seront affichés. Sinon, tous les fichiers de substitution seront affichés. Le suffixe doit être le nom d'un sous-répertoire contenant des fichiers de configuration comme tmpfiles.d, sysctl.d ou systemd/system. S'il est donné, seuls les fichiers de configuration dans ce sous-répertoire (sur tous les chemins de configuration) seront analysés. Sinon, tous les fichiers de configuration seront analysés. Si l'argument de la ligne de commande n'est pas donné du tout, tous les fichiers de configuration seront analysés. Voir ci-dessous pour quelques exemples.

OPTIONS

Les options suivantes sont comprises :

-t, --type=

Lors de la liste des différences, ne lister que celles qui sont demandées. La liste elle-même est une liste séparée par des virgules des types de différence désirés.

Types reconnus :

masked

Afficher les fichiers masqués

equivalent

Afficher les fichiers substitués qui, bien que substitués, ne diffèrent pas en contenu.

redirected

Afficher les fichiers qui sont redirigés vers un autre.

overridden

Afficher les fichiers substitués et modifiés.

extended

Afficher les fichiers *.conf dans les répertoires drop-in pour les unités.

Ajouté dans la version 205.

unchanged

Afficher également les fichiers inchangés.

--diff=

Lors de l'affichage des fichiers modifiés, afficher également un diff lorsqu'un fichier est substitué. Cette option prend un argument booléen. S'il est omis, il est par défaut à true.

-h, --help

Afficher un court texte d'aide et quitter.

--version

Afficher une courte chaîne de version et quitter.

--no-pager

Ne pas utiliser de pagineur pour la sortie.

EXEMPLES

Pour voir toute la configuration locale :

systemd-delta

Pour voir toute la configuration d'exécution :

systemd-delta /run

Pour voir toutes les modifications de configuration des unités système :

systemd-delta systemd/system

Pour voir toutes les modifications des "drop-in" d'exécution pour les unités système :

systemd-delta --type=extended /run/systemd/system

STATUT DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.
