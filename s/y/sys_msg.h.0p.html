sys_msg.h(0P) Manuel du programmeur POSIX sys_msg.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/msg.h — Structures de files de messages XSI

SYNOPSIS

#include <sys/msg.h>

DESCRIPTION

L'en-tête <sys/msg.h> définit les types de données suivants par le biais de typedef :

msgqnum_t
Utilisé pour le nombre de messages dans la file de messages.
msglen_t
Utilisé pour le nombre d'octets autorisés dans une file de messages.

Ces types sont des types d'entiers non signés capables de stocker des valeurs au moins aussi grandes qu'un type unsigned short.

L'en-tête <sys/msg.h> définit la constante symbolique suivante comme indicateur d'opération de message :

MSG_NOERROR
Pas d'erreur si le message est trop gros.

L'en-tête <sys/msg.h> définit la structure msqid_ds, qui inclut les membres suivants :

struct ipc_perm msg_perm   Structure de permissions d'opération.
msgqnum_t       msg_qnum   Nombre de messages actuellement dans la file.
msglen_t        msg_qbytes Nombre maximum d'octets autorisés dans la file.
pid_t           msg_lspid  ID du processus du dernier msgsnd().
pid_t           msg_lrpid  ID du processus du dernier msgrcv().
time_t          msg_stime  Heure du dernier msgsnd().
time_t          msg_rtime  Heure du dernier msgrcv().
time_t          msg_ctime  Heure du dernier changement.

L'en-tête <sys/msg.h> définit les types pid_t, size_t, ssize_t et time_t tels que décrits dans <sys/types.h>.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Des prototypes de fonctions seront fournis.

int       msgctl(int, int, struct msqid_ds *);
int       msgget(key_t, int);
ssize_t   msgrcv(int, void *, size_t, long, int);
int       msgsnd(int, const void *, size_t, int);

De plus, l'en-tête <sys/msg.h> inclura l'en-tête <sys/ipc.h>.
