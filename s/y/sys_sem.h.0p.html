sys_sem.h(0P) Manuel du programmeur POSIX sys_sem.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/sem.h — Installation de sémaphores XSI

SYNOPIS

#include <sys/sem.h>

DESCRIPTION

L'en-tête <sys/sem.h> définira la constante symbolique suivante pour être utilisée comme drapeau d'opération de sémaphore :

SEM_UNDO
Mettre en place une entrée de correction à la sortie.

L'en-tête <sys/sem.h> définira les constantes symboliques suivantes pour être utilisées comme commandes pour la fonction semctl() :

GETNCNT
Obtenir semncnt.
GETPID
Obtenir sempid.
GETVAL
Obtenir semval.
GETALL
Obtenir tous les cas de semval.
GETZCNT
Obtenir semzcnt.
SETVAL
Définir semval.
SETALL
Définir tous les cas de semval.

L'en-tête <sys/sem.h> définira la structure semid_ds, qui comprendra les membres suivants :

struct ipc_perm  sem_perm  Structure de permission d'opération.
unsigned short   sem_nsems Nombre de sémaphores dans l'ensemble.
time_t           sem_otime Dernier temps de semop().
time_t           sem_ctime Dernier temps modifié par semctl().

L'en-tête <sys/sem.h> définira les types pid_t, size_t et time_t tels que décrits dans <sys/types.h>.

Un sémaphore sera représenté par une structure anonyme, qui comprendra les membres suivants :

unsigned short  semval   Valeur du sémaphore.
pid_t           sempid   ID du processus de la dernière opération.
unsigned short  semncnt  Nombre de processus attendant que semval
                         devienne supérieur à la valeur actuelle.
unsigned short  semzcnt  Nombre de processus attendant que semval
                         devienne 0.

L'en-tête <sys/sem.h> définira la structure sembuf, qui comprendra les membres suivants :

unsigned short  sem_num   Numéro du sémaphore.
short           sem_op    Opération sur le sémaphore.
short           sem_flg   Drapeaux d'opération.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonction seront fournis.

int   semctl(int, int, int, ...);
int   semget(key_t, int, int);
int   semop(int, struct sembuf *, size_t);

De plus, l'en-tête <sys/sem.h> inclura l'en-tête <sys/ipc.h>.
