NOM

systemd-path — Lister et interroger les chemins système et utilisateur

SYNTAXE

systemd-path [OPTIONS...] [NOM...]

DESCRIPTION

systemd-path peut être utilisé pour interroger les chemins système et utilisateur. L'outil rend disponibles pour l'interrogation de nombreux chemins décrits dans file-hierarchy(7).

Lorsqu'il est invoqué sans arguments, une liste des chemins connus et de leurs valeurs actuelles est affichée. Lorsqu'au moins un argument est passé, le chemin portant ce nom est interrogé et sa valeur est affichée. Les variables dont le nom commence par "search-" ne font pas référence à des chemins individuels, mais plutôt à une liste de chemins de recherche séparés par des deux-points, dans leur ordre de priorité.

Notez que les chemins qui dépendent des variables d'environnement sont calculés avec l'environnement dans lequel systemd-path est invoqué, et non avec l'environnement du gestionnaire système ou utilisateur. Ainsi, la sortie de systemd-path peut ne pas refléter le comportement des processus de gestion.

OPTIONS

Les options suivantes sont comprises :

--suffix=

Les chemins imprimés sont suffixés par la chaîne spécifiée.

Ajouté dans la version 215.

--no-pager

Ne pas utiliser de pagineur pour la sortie.

-h, --help

Afficher un court message d'aide et quitter.

--version

Afficher une courte chaîne de version et quitter.

STATUT DE SORTIE

En cas de succès, 0 est retourné, un code d'erreur non nul sinon.
