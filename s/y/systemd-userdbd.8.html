NOM

systemd-userdbd.service, systemd-userdbd - Multiplexeur de requêtes d'enregistrements d'utilisateurs/groupes / Compatibilité NSS

SYNOPSIS

systemd-userdbd.service

/usr/lib/systemd/systemd-userdbd

DESCRIPTION

systemd-userdbd est un service système qui multiplexe les recherches d'utilisateurs/groupes vers tous les services locaux qui fournissent des définitions d'enregistrements d'utilisateurs/groupes JSON au système. De plus, il synthétise des enregistrements d'utilisateurs/groupes JSON à partir des enregistrements classiques UNIX/glibc NSS afin d'assurer une compatibilité rétroactive complète. Il peut également récupérer des enregistrements d'utilisateurs/groupes JSON définis statiquement dans les fichiers de /etc/userdb/, /run/userdb/, /run/host/userdb/ et /usr/lib/userdb/ avec l'extension ".user" ou ".group". Pour plus de détails sur les extensions, lisez la page de manuel de nss-systemd(8).

La majeure partie des fonctionnalités de systemd-userdbd sont accessibles via la commande userdbctl(1).

Les enregistrements d'utilisateurs et de groupes auxquels ce service donne accès suivent les définitions Enregistrements d'utilisateurs JSON[1] et Enregistrement de groupe JSON[2]. Ce service implémente l'API Recherche d'enregistrements d'utilisateurs/groupes via Varlink[3], et multiplexe également l'accès aux autres services implémentant cette API. Il est donc à la fois serveur et client de cette API.

Ce service fournit trois services Varlink[4] distincts : io.systemd.Multiplexer fournit une API unique et unifiée pour interroger les enregistrements d'utilisateurs et de groupes JSON. En interne, il communique en parallèle avec tous les autres services d'enregistrements d'utilisateurs/groupes en cours d'exécution sur le système et transmet toute information découverte. Cela simplifie considérablement les clients puisqu'ils n'ont besoin de communiquer qu'avec un seul service au lieu de tous en parallèle. io.systemd.NameServiceSwitch assure la compatibilité avec les enregistrements d'utilisateurs classiques UNIX/glibc NSS, c'est-à-dire qu'il convertit les enregistrements struct passwd et struct group tels qu'acquis avec des API comme getpwnam(1) en enregistrements d'utilisateurs/groupes JSON, masquant ainsi autant que possible les différences entre les services. io.systemd.DropIn rend disponibles les enregistrements d'utilisateurs/groupes JSON provenant des répertoires drop-in mentionnés précédemment.
