sync(2) Manuel des appels système sync(2)

NOM

sync, syncfs - valider les caches du système de fichiers sur le disque

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
void sync(void);
int syncfs(int fd);
Macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

sync():

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE

syncfs():

    _GNU_SOURCE

DESCRIPTION

sync() provoque l'écriture de toutes les modifications en attente des métadonnées du système de fichiers et des données de fichiers mises en cache sur les systèmes de fichiers sous-jacents.

syncfs() est similaire à sync(), mais synchronise uniquement le système de fichiers contenant le fichier référencé par le descripteur de fichier ouvert fd.

VALEUR DE RETOUR

syncfs() renvoie 0 en cas de succès ; en cas d'erreur, il renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

sync() réussit toujours.

syncfs() peut échouer pour au moins les raisons suivantes :

EBADF
fd n'est pas un descripteur de fichier valide.
EIO
Une erreur s'est produite lors de la synchronisation. Cette erreur peut être liée à des données écrites sur n'importe quel fichier du système de fichiers, ou aux métadonnées relatives au système de fichiers lui-même.
ENOSPC
L'espace disque a été épuisé pendant la synchronisation.
ENOSPC
EDQUOT
Des données ont été écrites sur un fichier sur NFS ou un autre système de fichiers qui n'alloue pas d'espace au moment d'un appel système write(2), et une écriture précédente a échoué en raison d'un espace de stockage insuffisant.

VERSIONS

Selon la spécification standard (c'est-à-dire POSIX.1), sync() planifie les écritures, mais peut renvoyer avant que l'écriture réelle ne soit effectuée. Cependant, Linux attend les complétions d'E/S, et donc sync() ou syncfs() fournissent les mêmes garanties que fsync() appelé sur chaque fichier du système ou du système de fichiers respectivement.

NORMES

sync()
POSIX.1-2024.
syncfs()
Linux.

HISTORIQUE

sync()
POSIX.1-2001, SVr4, 4.3BSD.
syncfs()
Linux 2.6.39, glibc 2.14.

Depuis glibc 2.2.2, le prototype Linux pour sync() est tel que listé ci-dessus, suivant les diverses normes. Dans glibc 2.2.1 et antérieur, il était de type "int sync(void)", et sync() renvoyait toujours 0.

Dans les versions du noyau principales avant Linux 5.8, syncfs() échoue uniquement lorsqu'il reçoit un descripteur de fichier invalide (EBADF). Depuis Linux 5.8, syncfs() signalera également une erreur si un ou plusieurs inodes n'ont pas pu être écrits depuis le dernier appel à syncfs().

BOGUES

Avant Linux 1.3.20, Linux n'attendait pas la fin des E/S avant de retourner.

VOIR AUSSI

sync(1), fdatasync(2), fsync(2)
