syndaemon(1) Manuel des commandes générales syndaemon(1)

NOM

syndaemon - un programme qui surveille l'activité du clavier et désactive le touchpad lorsque le clavier est utilisé.

SYNTAXE

syndaemon [-i temps-inactivité] [-m intervalle-sonde] [-d] [-p fichier-pid] [-t] [-k] [-K] [-R]

DESCRIPTION

Désactiver le touchpad pendant la frappe évite les mouvements indésirables du pointeur qui pourraient donner le focus à la mauvaise fenêtre.

OPTIONS

-i <temps-inactivité>
Combien de secondes attendre après la dernière pression de touche avant d'activer le touchpad. (par défaut 2.0s).
-m <intervalle-sonde>
Combien de millisecondes attendre entre deux intervalles de sondage. Si cette valeur est trop basse, cela provoquera des réveils inutiles. Si cette valeur est trop haute, certaines pressions de touches (pression et relâchement entre deux intervalles) peuvent ne pas être remarquées. Ce commutateur n'a aucun effet lorsqu'il est utilisé avec -R. Par défaut, 200ms.
-d
Démarrer en tant que démon, c'est-à-dire en arrière-plan.
-p <fichier-pid>
Créer un fichier pid avec le nom spécifié. Un fichier pid ne sera créé que si le programme est démarré en mode démon.
-t
Désactiver uniquement les taps et le défilement, pas les mouvements de souris, en réponse à l'activité du clavier.
-k
Ignorer les touches modificatrices lors de la surveillance de l'activité du clavier.
-K
Comme -k mais ignorer également les combinaisons Modificateur+Touche.
-R
Utiliser l'extension XRecord pour détecter l'activité du clavier au lieu de sonder l'état du clavier.
-?
Afficher le message d'aide.

VARIABLES D'ENVIRONNEMENT

DISPLAY
Spécifie le serveur X à contacter.

CODES DE SORTIE

Si syndaemon se termine avec un code de retour différent de 0, l'erreur rencontrée est la suivante.

Code de sortie 1
Argument de ligne de commande invalide.
Code de sortie 2
La connexion au serveur X n'a pas pu être établie ou aucun périphérique touchpad n'a pu être trouvé.
Code de sortie 3
L'appel système fork en mode démon a échoué ou le fichier pid n'a pas pu être créé.
Code de sortie 4
XRECORD demandé mais non disponible ou utilisable sur le serveur.

AVERTISSEMENTS

Il n'est pas très logique de se connecter à un serveur X distant, car le démon surveillera alors le serveur distant pour l'activité du clavier, mais désactivera le touchpad sur la machine locale.
