sympol(1) Commandes utilisateur sympol(1)

NOM

sympol - outil pour les polyèdres symétriques

SYNTAXE

sympol [OPTIONS] [FICHIER_ENTREE]

DESCRIPTION

SymPol calcule les automorphismes restreints des polyèdres et effectue la conversion des descriptions polyédriques jusqu'à un groupe de symétrie donné ou calculé.

SymPol utilise principalement le format de fichier .ine/.ext utilisé par cddlib et lrslib ; (http://cgm.cs.mcgill.ca/~avis/C/lrslib/USERGUIDE.html#File%20Formats). Cependant, contrairement à cddlib, SymPol exige que chaque inégalité (représentation H) ou chaque sommet et rayon (représentation V) occupe une seule ligne. De plus, SymPol offre une extension au format.

L'extension permet d'inclure le groupe d'automorphismes d'un polyèdre, ou des parties de celui-ci, dans le fichier. Elle est donnée après la fin de la représentation H ou V d'un groupe de permutations, comme suit.

groupe de permutations
p
{ liste de #p générateurs de groupe }
q
{ #q points de base séparés par des espaces }

Les générateurs du groupe p doivent être donnés sous forme de cycle, où les virgules séparent les cycles. La valeur q peut être réglée à zéro si aucune base du groupe n'est connue.

OPTIONS

-h, --help
Affiche un message d'aide.
-v, --verbose[=N]
Définit le niveau de verbosité, 0 par défaut. Si N est omis, 1 est supposé.
-t, --time
Active la mesure du temps.
-i, --input-file FICHIER
Lit un fichier d'entrée (.ine ou .ext). Le fichier peut également être listé en dernier sur la ligne de commande.
--automorphisms-only
Calcule uniquement les automorphismes restreints puis quitte.
--no-automorphisms
Ignore le groupe de symétrie donné et n'essaie pas de calculer les automorphismes restreints.
--bliss
Utilise l'outil d'automorphisme de graphe bliss pour calculer les automorphismes restreints (par défaut si bliss est disponible).
--permlibmatrix
Utilise PermLib matrix pour la recherche d'automorphismes et calculer les automorphismes restreints.
--eigen
Utilise l'arithmétique à virgule flottante basée sur Eigen pour calculer les automorphismes restreints.
-e, --estimation-only
Calcule uniquement l'estimation LRS puis quitte.
-d, --direct
Calcule directement la description duale.
-a, --adm
Utilise un niveau de décomposition d'adjacence, résout les sous-problèmes directement.
--idm-adm-level niveau-idm niveau-adm
Utilise une stratégie combinée IDM/ADM avec les niveaux indiqués.
--adm-idm-level niveau-adm niveau-idm
Utilise une stratégie combinée ADM/IDM avec les niveaux indiqués.
--adm-estimate seuil
Utilise la méthode de décomposition d'adjacence jusqu'au seuil d'estimation indiqué.
--adm-dim seuil
Utilise la méthode de décomposition d'adjacence jusqu'au seuil de dimension indiqué.
--adm-incidence seuil
Utilise la méthode de décomposition d'adjacence jusqu'au seuil de nombre d'incidences indiqué.
--idm-adm seuil-idm seuil-adm
Utilise une stratégie combinée IDM/ADM avec les seuils indiqués.
--cdd
Utilise cdd pour la conversion de description duale centrale (EXPÉRIMENTAL).
--adjacencies
Enregistre les adjacences de facettes. Nécessite la méthode ADM au niveau 0.

PARAMETRES

--conf-lrs-estimates=N
Le nombre d'estimations effectuées par LRS (défaut : 8).
--conf-lrs-estimate-maxdepth=N
La profondeur maximale autorisée pour les estimations LRS (défaut : 3).
--conf-compute-invariants=N
Le degré maximal des polynômes invariants de groupe de permutations à utiliser (défaut : 0).
--conf-compute-orbit-limit=N
Limite de mémoire en mégaoctets pour le calcul de l'orbite complète (défaut : 1024).
--conf-compute-canonical-representatives=N
Non nul pour calculer les représentants canoniques des faces (défaut : 0).
--conf-intermediate-poly-fileprefix=PREFIXE
Préfixe pour les noms de fichiers dans lesquels les polyèdres intermédiaires sont sauvegardés. Ceci est utile pour le débogage et l'analyse des instances. Défaut : préfixe vide.
