sysv_signal(3) Manuel des fonctions de bibliothèque sysv_signal(3)

NOM

sysv_signal - gestion des signaux avec sémantique System V

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <signal.h>
typedef typeof(void (int))  *sighandler_t;
sighandler_t sysv_signal(int signum, sighandler_t handler);

DESCRIPTION

La fonction sysv_signal() prend les mêmes arguments et effectue la même tâche que signal(2).

Cependant, sysv_signal() fournit la sémantique de signaux non fiables de System V, c'est-à-dire : a) la disposition du signal est réinitialisée à la valeur par défaut lorsque le gestionnaire est invoqué ; b) la livraison des instances ultérieures du signal n'est pas bloquée pendant l'exécution du gestionnaire de signal ; et c) si le gestionnaire interrompt (certains) appels système bloquants, alors l'appel système n'est pas automatiquement redémarré.

VALEUR DE RETOUR

La fonction sysv_signal() renvoie la valeur précédente du gestionnaire de signal, ou SIG_ERR en cas d'erreur.

ERREURS

Comme pour signal(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sysv_signal () Thread safety MT-Safe

VERSIONS

L'utilisation de sysv_signal() devrait être évitée ; utilisez sigaction(2) à la place.

Sur les anciens systèmes Linux, sysv_signal() et signal(2) étaient équivalents. Mais sur les systèmes plus récents, signal(2) fournit une sémantique de signaux fiables ; voir signal(2) pour plus de détails.

L'utilisation de sighandler_t est une extension GNU ; ce type n'est défini que si la macro de test de fonctionnalité _GNU_SOURCE est définie.

NORMES

Aucune.

VOIR AUSSI

sigaction(2), signal(2), bsd_signal(3), signal(7)
