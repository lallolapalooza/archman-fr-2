sys_select.h(0P) Manuel du programmeur POSIX sys_select.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails sur le comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/select.h — types de select

SYNTAXE

#include <sys/select.h>

DESCRIPTION

L'en-tête <sys/select.h> définit la structure timeval, qui doit contenir au moins les membres suivants :

time_t         tv_sec      Secondes.
suseconds_t    tv_usec     Microsecondes.

L'en-tête <sys/select.h> définit les types time_t et suseconds_t tels que décrits dans <sys/types.h>.

L'en-tête <sys/select.h> définit le type sigset_t tel que décrit dans <signal.h>.

L'en-tête <sys/select.h> définit la structure timespec telle que décrite dans <time.h>.

L'en-tête <sys/select.h> définit le type fd_set comme une structure.

L'en-tête <sys/select.h> définit la constante symbolique suivante, qui doit avoir une valeur appropriée pour être utilisée dans les directives de préprocesseur #if :

FD_SETSIZE
Nombre maximum de descripteurs de fichiers dans une structure fd_set.

Les éléments suivants doivent être déclarés comme fonctions, définis comme macros, ou les deux. Si des fonctions sont déclarées, des prototypes de fonctions doivent être fournis.

void FD_CLR(int, fd_set *);
int  FD_ISSET(int, fd_set *);
void FD_SET(int, fd_set *);
void FD_ZERO(fd_set *);

S'ils sont implémentés comme des macros, ceux-ci peuvent évaluer leurs arguments plus d'une fois, donc les applications doivent s'assurer que les arguments qu'elles fournissent ne sont jamais des expressions avec des effets de bord.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme des macros. Des prototypes de fonctions doivent être fournis.

int  pselect(int, fd_set *restrict, fd_set *restrict, fd_set *restrict,
         const struct timespec *restrict, const sigset_t *restrict);
int  select(int, fd_set *restrict, fd_set *restrict, fd_set *restrict,
         struct timeval *restrict);

L'inclusion de l'en-tête <sys/select.h> peut rendre visibles tous les symboles des en-têtes <signal.h> et <time.h>.
