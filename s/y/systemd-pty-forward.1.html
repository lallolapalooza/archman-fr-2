NOM

systemd-pty-forward - Exécute une commande avec une couleur de fond de terminal ou un titre personnalisés

SYNTAXE

systemd-pty-forward [OPTIONS...] {COMMANDE}

DESCRIPTION

systemd-pty-forward peut être utilisé pour exécuter une commande avec une couleur de fond de terminal ou un titre personnalisés.

OPTIONS

Les options suivantes sont comprises :

--background=COULEUR

Change la couleur de fond du terminal à la couleur ANSI spécifiée tant que la commande s'exécute. La couleur spécifiée doit être une couleur de fond SGR (Select Graphic Rendition) d'ANSI X3.64, c'est-à-dire des chaînes comme « 40 », « 41 », ..., « 47 », « 48;2;... », « 48;5;... ». Voir Code d'échappement ANSI (Wikipedia)[1] pour plus de détails.

Exemple : « --background=44 » pour un fond bleu.

Ajouté dans la version 258.

--title=TITRE

Change le titre du terminal à la chaîne spécifiée tant que la commande s'exécute.

Ajouté dans la version 258.

--quiet, -q

Supprime les informations supplémentaires pendant l'exécution.

Ajouté dans la version 258.

--read-only

N'accepte aucune entrée utilisateur sur l'entrée standard.

Ajouté dans la version 258.

-h, --help

Affiche un court message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.
