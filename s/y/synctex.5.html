SYNCTEX(5) Formats de fichiers SYNCTEX(5)

NOM

synctex — Fichier d'aide Synchronize TeXnology

DESCRIPTION

Le fichier d'aide Synchronize TeXnology (synctexs) est un fichier texte qui aide à la synchronisation entrée/sortie lors de la préparation de documents avec le système de composition TeX.

BASES

La structure de ce fichier ne doit pas être considérée comme publique, dans le sens où personne ne devrait avoir besoin d'analyser son contenu, à l'exception de l'utilitaire de ligne de commande synctex, et de la bibliothèque synctex_parser qui sont toutes deux disponibles publiquement. Sauf si cela est absolument inévitable, l'accès au contenu du fichier synctex ne devrait être effectué qu'à travers des requêtes adressées à l'utilitaire de ligne de commande synctex.

STRUCTURE

La structure des éléments d'un fichier synctex est une liste d'enregistrements de lignes de texte comme suit. Les caractères '*', '+', et '?' ont leurs significations EBNF habituelles : '*' signifie zéro ou plusieurs, '+' signifie un ou plusieurs, et '?' signifie zéro ou un (c'est-à-dire facultatif).

  • <SyncTeX> ::= (Le contenu entier en 4 sections)
    • <Préambule>
    • <Contenu>
    • <Postambule>
    • <Post-scriptum>

Chaque section commence par la première occurrence d'une ligne de sectionnement et se termine par la section suivante, le cas échéant. Dans les définitions suivantes, nous ne mentionnons pas la condition de fin de section.

Le préambule

  • <Préambule> ::=
    • "SyncTeX Version :" <Numéro de Version> <EOL>
    • <Ligne d'entrée>*
    • "Magnification :" <Magnification TeX> <EOL>
    • "Unit :" <unité en point mis à l'échelle> <EOL>
    • "X Offset :" <décalage horizontal en point mis à l'échelle> <EOL>
    • "Y Offset :" <décalage vertical en point mis à l'échelle> <EOL>
  • <Ligne d'entrée> ::= "Input :" <tag> ":" <Nom de fichier> <EOL>

Le contenu

  • <Contenu> ::=
    • <enregistrement de décalage d'octet>
    • "Content :" <EOL>
    • (<Forme(k)>|<Ligne d'entrée>)*
    • <feuille(1)>
    • (<Forme(k)>|<Ligne d'entrée>)*
    • <feuille(2)>
    • (<Forme(k)>|<Ligne d'entrée>)*
    • ...
    • <feuille(N)>
    • (<Forme(k)>|<Ligne d'entrée>)*
  • <enregistrement de décalage d'octet> ::= "!" <décalage d'octet> <fin d'enregistrement>
  • <feuille(n)> ::=
    • <enregistrement de décalage d'octet>
    • "{" <l'entier n> <fin d'enregistrement>
    • <section vbox>|<section hbox>
    • <enregistrement de décalage d'octet>
    • "}" <l'entier n> <fin d'enregistrement>
  • <Forme> ::=
    • <enregistrement de décalage d'octet>
    • "<" <étiquette de forme> <fin d'enregistrement>
    • <section vbox>|<section hbox>
    • <enregistrement de décalage d'octet>
    • ">" <fin d'enregistrement>
  • <étiquette de forme> ::= <entier>

Les formes sont disponibles avec pdfTeX. Tous les nombres sont des entiers encodés en utilisant la représentation décimale avec la locale "C". Le <contenu de boîte> décrit ce qui se trouve à l'intérieur d'une boîte. C'est soit une boîte verticale, soit une boîte horizontale, avec quelques enregistrements liés aux nœuds de collage, de crénage ou mathématiques.

  • <contenu de boîte> ::=
    • <section vbox>|<section hbox>
    • |<enregistrement de vbox vide>|<enregistrement de hbox vide>
    • |<enregistrement courant>|<enregistrement de collage>|<enregistrement de crénage>
    • |<enregistrement math>|<enregistrement de référence de forme>|<Forme>
  • <section vbox> ::=
    • "[" <lien> ":" <point> ":" <taille> <fin d'enregistrement>
    • <contenu de boîte>*
    • "]" <fin d'enregistrement>
  • <section hbox> ::=
    • ( <lien> ":" <point> ":" <taille> <fin d'enregistrement>
    • <contenu de boîte>*
    • ")" <fin d'enregistrement>

Boîtes vides :

  • <enregistrement de vbox vide> ::= "v" <lien> ":" <point> ":" <taille> <fin d'enregistrement>
  • <enregistrement de hbox vide> ::= "h" <lien> ":" <point> ":" <taille> <fin d'enregistrement>
  • <lien> ::= <étiquette> "," <ligne>( "," <colonne>)?
  • <point> ::= <point complet>|<point compressé>
  • <point complet> ::= <entier> ( etc. (le reste de la description est tronqué dans l'extrait fourni)

synctex.5.en — synctex

NAME

synctex - Support file format specification

DESCRIPTION

The synctex program provides support for synchronous editing between a TeX document and its associated viewer. This manual page describes the format of the synctex support file (.synctex.gz).

The synctex file is a compressed text file that contains geometric information about the typesetting process. This information is used to enable forward and backward navigation between the source code and the typeset document.

The synctex file format

The synctex file is composed of a header, a body, and a postamble. The header contains metadata about the document, the body contains the geometric information, and the postamble contains a summary of the file.

BASICS

The synctex file is a compressed file. It can be decompressed using gzip or gunzip.

The synctex file is composed of records. Each record starts with a tag that indicates its type.

STRUCTURE

The synctex file is composed of several sections.

The header

The header is composed of several records:

  • <Synctex>::=
    • "SyncTeX version:" <integer> <EOL>
    • "Author:" <string> <EOL>
    • "Input:" <string> <EOL>
    • "Output:" <string> <EOL>
    • "Target" <string> <EOL>

The preamble

The preamble contains information about the document's structure and formatting.

  • <Preamble>::=
    • <byte offset record>
    • "Source files:" <Number of source files> <EOL>
    • <source record>
    • "Magnification:" <number> <EOL>
    • "X offset:" <dimension> <EOL>
    • "Y offset:" <dimension> <EOL>
  • <source record> ::= <string> <EOL>

The content

The content section contains the geometric information about the document's structure. It is composed of records that represent different elements of the document, such as pages, lines, and words.

The following are the definitions of the basic elements:

  • <byte offset record> ::= <integer>
  • <string> ::= <character>+
  • <number> ::= <integer>
  • <dimension> ::= <integer>
  • <EOL> ::= "\n"
  • <integer> ::= Digit+
  • <link> ::= <integer>
  • <form tag> ::= <integer>
  • <point> ::= <integer> ",=" | <integer> "," <integer>
  • <compressed point> ::= <integer> ",="
  • <line> ::= <integer>
  • <column> ::= <integer>
  • <size> ::= <Width> "," <Height> "," <Depth>
  • <Width> ::= <integer>
  • <Height> ::= <integer>
  • <Depth> ::= <integer>

Les enregistrements suivants sont des lignes simples.

  • <current record> ::= "x" <link> ":" <point> <end of record>
  • <kern record> ::= "k" <link> ":" <point> ":" <Width> <end of record>
  • <glue record> ::= "g" <link> ":" <point> <end of record>
  • <math record> ::= "$" <link> ":" <point> <end of record>
  • <form ref record> ::= "f" <form tag> ":" <point> <end of record>

The postamble

The postamble closes the file If there is no postamble, it means that the typesetting process did not end correctly.

  • <Postamble>::=
    • <byte offset record>
    • "Count:" <Number of records> <EOL>

The post scriptum

The post scriptum contains material possibly added by 3rd parties. It allows one to append some transformation (shift and magnify). Typically, one applies a dvi to pdf filter with offset options and magnification, then he appends the same options to the synctex file, for example

synctex update -o foo.pdf -m 0.486 -x 9472573sp -y 13.3dd source.dvi
  • <Post Scriptum>::=
    • <byte offset record>
    • "Post Scriptum:" <EOL>
    • "Magnification:" <number> <EOL> (Set additional magnification)
    • "X Offset:" <dimension> <EOL> (Set horizontal offset)
    • "Y Offset:" <dimension> <EOL> (Set vertical offset)
This second information will override the offset and magnification previously available in the preamble section. All the numbers are encoded using the decimal representation with "C" locale.

USAGE

The <current record> is used to compute the visible size of hbox's. The byte offset is an implicit anchor to navigate the synctex file from sheet to sheet. The second coordinate of a compressed point has been replaced by a "=" character which means that it is the second coordinate of the last full point available above.
