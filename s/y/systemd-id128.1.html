NOM

systemd-id128 - Générer et afficher des identifiants sd-128

SYNTAXE

systemd-id128 [OPTIONS...] new

systemd-id128 [OPTIONS...] machine-id

systemd-id128 [OPTIONS...] boot-id

systemd-id128 [OPTIONS...] invocation-id

systemd-id128 [OPTIONS...] var-partition-uuid

systemd-id128 [OPTIONS...] show [NOM|UUID...]

DESCRIPTION

id128 peut être utilisé pour afficher de manière pratique les UUIDs sd-id128(3). L'identifiant affiché dépend du verbe spécifique.

Avec new, un nouvel identifiant aléatoire sera généré.

Avec machine-id, l'identifiant de la machine actuelle sera affiché. Voir machine-id(5).

Avec boot-id, l'identifiant du démarrage actuel sera affiché.

Avec invocation-id, l'identifiant de l'invocation de service actuelle sera affiché. Ceci est disponible dans les services systemd. Voir systemd.exec(5).

Avec show, des IDs bien connus sont affichés (pour l'instant, seulement les UUIDs de type de partition GPT), ainsi que des chaînes d'identifiants brèves. Lorsque aucun argument n'est spécifié, tous les IDs connus sont affichés. Lorsque des arguments sont spécifiés, il peut s'agir des identifiants ou des valeurs d'ID d'un ou plusieurs IDs connus, qui sont alors affichés avec leur nom, ou d'IDs arbitraires, qui sont alors affichés avec un nom placeholder. Combiner avec --uuid pour lister les IDs au format UUID, c'est-à-dire la manière dont les UUIDs de type de partition GPT sont généralement affichés.

machine-id, boot-id et show peuvent être combinés avec le commutateur --app-specific=app-id pour générer des IDs spécifiques à l'application. Voir sd_id128_get_machine(3) pour la discussion de l'utilité de cette option.

var-partition-uuid affiche un UUID qui, conformément à la Discoverable Partitions Specification[1], doit être utilisé comme UUID de partition GPT pour /var/, dérivé du type de partition GPT, indexé par le local /etc/machine-id. Ajouté dans la version 257.

OPTIONS

Les options suivantes sont comprises :

-p, --pretty

Génère la sortie sous forme d'extraits de langage de programmation.

Ajouté dans la version 240.

-P, --value

Affiche uniquement la valeur. Peut être combiné avec -u/--uuid.

Ajouté dans la version 255.

-a app-id, --app-specific=app-id

Avec cette option, des identifiants seront affichés qui sont le résultat du hachage de l'identifiant d'application app-id et d'un autre ID. L'argument app-id doit être une chaîne sd-id128 valide identifiant l'application. Utilisé avec machine-id, l'autre ID sera l'ID de la machine tel que décrit dans machine-id(5), utilisé avec boot-id, l'autre ID sera l'ID du démarrage, et utilisé avec show, l'autre ID ou IDs doit être spécifié via les arguments positionnels.

Ajouté dans la version 240.

-u, --uuid

Génère la sortie sous forme d'UUID formaté en "représentation canonique", avec cinq groupes de chiffres séparés par des tirets. Voir l'entrée Wikipedia sur les Universally Unique Identifiers[2] pour plus de détails.

Ajouté dans la version 244.

--no-pager

Ne pas utiliser de pagineur pour la sortie.

--no-legend

Ne pas imprimer la légende, c'est-à-dire les en-têtes de colonne et le pied de page avec des indications.

--json=MODE

Affiche la sortie formatée en JSON. Attend l'un des modes suivants : "short" (pour la sortie la plus courte possible sans espaces blancs superflus ni sauts de ligne), "pretty" (pour une version formatée de la même sortie, avec indentation et sauts de ligne) ou "off" (pour désactiver la sortie JSON, par défaut).

-j

Équivalent à --json=pretty si exécuté dans un terminal, et --json=short sinon.

-h, --help

Affiche un court message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.

CODES DE RETOUR

En cas de succès, 0 est retourné, et un code d'échec non nul sinon.

EXEMPLES

Exemple 1. Afficher un UUID bien connu

$ systemd-id128 show --value user-home
773f91ef66d449b5bd83d683bf40ad16
$ systemd-id128 show --value --uuid user-home
773f91ef-66d4-49b5-bd83-d683bf40ad16
$ systemd-id128 show 773f91ef-66d4-49b5-bd83-d683bf40ad16
NOM      ID
user-home 773f91ef66d449b5bd83d683bf40ad16

Exemple 2. Générer un UUID spécifique à une application

$ systemd-id128 machine-id -u
3a9d668b-4db7-4939-8a4a-5e78a03bffb7
$ systemd-id128 new -u
1fb8f24b-02df-458d-9659-cc8ace68e28a
$ systemd-id128 machine-id -u -a 1fb8f24b-02df-458d-9659-cc8ace68e28a
47b82cb1-5339-43da-b2a6-1c350aef1bd1
$ systemd-id128 -Pu show 3a9d668b-4db7-4939-8a4a-5e78a03bffb7 \
    -a 1fb8f24b-02df-458d-9659-cc8ace68e28a
47b82cb1-5339-43da-b2a6-1c350aef1bd1

Sur une machine donnée avec l'ID 3a9d668b-4db7-4939-8a4a-5e78a03bffb7, pour l'application 1fb8f24b-02df-458d-9659-cc8ace68e28a, nous générons un ID machine spécifique à l'application (47b82cb1-5339-43da-b2a6-1c350aef1bd1). Si nous voulons recréer ultérieurement le même calcul sur une machine différente, nous devons spécifier les deux IDs explicitement en tant que paramètres à show.
