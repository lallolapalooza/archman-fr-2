sysctl(2) Manuel des appels système sysctl(2)

NOM

sysctl - lire/écrire les paramètres système

SYNOPSIS

#include <unistd.h>
#include <linux/sysctl.h>
[[deprecated]] int _sysctl(struct __sysctl_args *args);

DESCRIPTION

Cet appel système n'existe plus sur les noyaux actuels ! Voir NOTES.

L'appel _sysctl() lit et/ou écrit des paramètres du noyau. Par exemple, le nom d'hôte ou le nombre maximum de fichiers ouverts. L'argument a la forme


struct __sysctl_args {
    int    *name;    /* vecteur d'entiers décrivant la variable */
    int     nlen;    /* nombre d'éléments de ce vecteur */
    void   *oldval;  /* 0 ou adresse où stocker l'ancienne valeur */
    size_t *oldlenp; /* espace disponible pour l'ancienne valeur,
                        écrasé par la taille réelle de l'ancienne valeur */
    void   *newval;  /* 0 ou adresse de la nouvelle valeur */
    size_t  newlen;  /* taille de la nouvelle valeur */
};

Cet appel effectue une recherche dans une structure arborescente, ressemblant éventuellement à une arborescence de répertoires sous /proc/sys, et si l'élément demandé est trouvé, appelle une routine appropriée pour lire ou modifier la valeur.

VALEUR DE RETOUR

En cas de succès, _sysctl() retourne 0. Sinon, une valeur de -1 est retournée et errno est définie pour indiquer l'erreur.

ERREURS

EACCES
EPERM
Aucune permission de recherche sur l'un des « répertoires » rencontrés, ou aucune permission de lecture là où oldval était non NULL, ou aucune permission d'écriture là où newval était non NULL.
EFAULT
L'appel demandait la valeur précédente en mettant oldval à non NULL, mais autorisait zéro espace dans oldlenp.
ENOTDIR
name n'a pas été trouvé.

NORMES

Linux.

HISTORIQUE

Linux 1.3.57. Supprimé dans Linux 5.5, glibc 2.32.

Il est originaire de 4.4BSD. Seul Linux dispose du miroir /proc/sys, et les schémas de nommage d'objets diffèrent entre Linux et 4.4BSD, mais la déclaration de la fonction sysctl() est identique dans les deux.

NOTES

L'utilisation de cet appel système était depuis longtemps déconseillée : depuis Linux 2.6.24, les utilisations de cet appel système entraînent des avertissements dans le journal du noyau, et dans Linux 5.5, l'appel système a finalement été supprimé. Utilisez l'interface /proc/sys à la place.

Notez que sur les anciens noyaux où cet appel système existe encore, il n'est disponible que si le noyau a été configuré avec l'option CONFIG_SYSCTL_SYSCALL. De plus, glibc ne fournit pas d'enveloppe pour cet appel système, ce qui nécessite l'utilisation de syscall(2).

BOGUES

Les noms des objets varient entre les versions du noyau, rendant cet appel système inutile pour les applications.

Tous les objets disponibles ne sont pas correctement documentés.

Il n'est pas encore possible de changer le système d'exploitation en écrivant dans /proc/sys/kernel/ostype.

EXEMPLES

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/syscall.h>
#include <unistd.h>
#include <linux/sysctl.h>
#define NITEMS(arr)  (sizeof(arr) / sizeof((arr)[0]))
int _sysctl(struct __sysctl_args *args);
#define OSNAMESZ 100
int
main(void)
{
    int                   name[] = { CTL_KERN, KERN_OSTYPE };
    char                  osname[OSNAMESZ];
    size_t                osnamelth;
    struct __sysctl_args  args;
    memset(&args, 0, sizeof(args));
    args.name = name;
    args.nlen = NITEMS(name);
    args.oldval = osname;
    args.oldlenp = &osnamelth;
    osnamelth = sizeof(osname);
    if (syscall(SYS__sysctl, &args) == -1) {
        perror("_sysctl");
        exit(EXIT_FAILURE);
    }
    printf("This machine is running %*s\n", (int) osnamelth, osname);
    exit(EXIT_SUCCESS);
}
