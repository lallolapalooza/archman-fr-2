synapse(1) Manuel des commandes générales synapse(1)

NOM

synapse - Utilitaire pour lancer tout sur votre ordinateur.

SYNTAXE

synapse [OPTIONS]

DESCRIPTION

Synapse est un utilitaire pour lancer tout ce que vous avez sur votre ordinateur. Il utilise zeitgeist pour rechercher dans l'activité de l'utilisateur.

OPTIONS

-s, --startup=
Mode de démarrage (masquer l'interface utilisateur jusqu'à activation).
