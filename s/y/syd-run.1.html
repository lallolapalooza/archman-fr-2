SYD-RUN(1) Manuel des commandes générales SYD-RUN(1)

NOM

syd-run - Exécute un programme dans un conteneur avec l'ID de processus donné

SYNTAXE

syd-run [-hvacimnptuU] pid {commande [arg...]}

DESCRIPTION

L'utilitaire syd-run(2) exécute un programme dans un conteneur syd(1) avec l'ID de processus donné. Cela nécessite l'utilisation des appels système setns(2) et pidfd_open(2) qui nécessitent Linux-5.8 ou plus récent. Notez que l'entrée dans les espaces de noms pid_namespaces(7) et time_namespaces(7) est une opération privilégiée, tandis que l'entrée dans les espaces de noms cgroup_namespaces(7), ipc_namespaces(7), mount_namespaces(7), network_namespaces(7) et uts_namespaces(7) n'est pas privilégiée lorsqu'elle est combinée avec les user_namespaces(7), à condition que la prise en charge des user_namespaces(7) non privilégiés soit activée dans le noyau Linux.

OPTIONS

-h Afficher l'aide.
-v Être verbeux. Afficher des messages d'information sur la sortie d'erreur standard.
-a Détecter automatiquement les espaces de noms à entrer. Les espaces de noms PID et Temps sont exclus. C'est le comportement par défaut.
-c Entrer dans l'espace de noms CGroup.
-i Entrer dans l'espace de noms IPC.
-m Entrer dans l'espace de noms de montage.
-n Entrer dans l'espace de noms réseau.
-p Entrer dans l'espace de noms PID.
-t Entrer dans l'espace de noms de temps.
-u Entrer dans l'espace de noms UTS.
-U Entrer dans l'espace de noms utilisateur.

STATUT DE SORTIE

En cas de sortie propre, syd-run(1) se termine avec le même code que le processus enfant. En cas de terminaison non propre, le code de sortie est défini sur 128 plus le numéro de signal. En cas d'échec de l'exécution du processus enfant, syd-run(1) se termine avec le numéro d'errno(3).
