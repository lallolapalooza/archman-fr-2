sys_wait.h(0P) Manuel du programmeur POSIX sys_wait.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/wait.h — déclarations pour attendre

SYNTAXE

#include <sys/wait.h>

DESCRIPTION

L'en-tête <sys/wait.h> définit les constantes symboliques suivantes pour une utilisation avec waitpid() :

WCONTINUED
Signaler le statut du processus enfant continué.
WNOHANG
Ne pas bloquer si aucun statut n'est disponible ; retourner immédiatement.
WUNTRACED
Signaler le statut du processus enfant arrêté.

L'en-tête <sys/wait.h> définit les macros suivantes pour l'analyse des valeurs de statut de processus :

WEXITSTATUS
Retourne le code de sortie.
WIFCONTINUED
Vrai si l'enfant a été continué.
WIFEXITED
Vrai si l'enfant s'est terminé normalement.
WIFSIGNALED
Vrai si l'enfant s'est terminé suite à un signal non intercepté.
WIFSTOPPED
Vrai si l'enfant est actuellement arrêté.
WSTOPSIG
Retourne le numéro du signal qui a provoqué l'arrêt du processus.
WTERMSIG
Retourne le numéro du signal qui a provoqué la terminaison du processus.

L'en-tête <sys/wait.h> définit les constantes symboliques suivantes comme valeurs possibles pour l'argument options de waitid() :

WEXITED
Attendre les processus qui se sont terminés.
WNOWAIT
Garder le processus dont le statut est retourné dans infop dans un état d'attente.
WSTOPPED
Le statut est retourné pour tout enfant qui s'est arrêté en recevant un signal.

Les constantes WCONTINUED et WNOHANG, décrites ci-dessus pour waitpid(), peuvent également être utilisées avec waitid().

Le type idtype_t sera défini comme un type énuméré dont les valeurs possibles incluront au moins les suivantes : P_ALL P_PGID P_PID

L'en-tête <sys/wait.h> définira les types id_t et pid_t tels que décrits dans <sys/types.h>.

L'en-tête <sys/wait.h> définira le type siginfo_t et l'union sigval tels que décrits dans <signal.h>.

L'inclusion de l'en-tête <sys/wait.h> peut également rendre visibles tous les symboles de <signal.h>.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonctions seront fournis.

pid_t  wait(int *);
int    waitid(idtype_t, id_t, siginfo_t *, int);
pid_t  waitpid(pid_t, int *, int);
