synclient(1) Manuel des commandes générales synclient(1)

NOM

synclient - utilitaire en ligne de commande pour interroger et modifier les options du pilote Synaptics.

SYNTAXE

synclient [-lV?] [var1=valeur1 [var2=valeur2] ...]

DESCRIPTION

Ce programme vous permet de modifier les paramètres du pilote Synaptics pour pavé tactile pour le serveur XOrg/XFree86 pendant que X est en cours d'exécution.

OPTIONS

-l
Liste les paramètres utilisateur actuels. C'est le comportement par défaut si aucune option n'est donnée.
-V
Affiche le numéro de version et quitte.
-?
Affiche le message d'aide.
var=valeur
Définit le paramètre utilisateur var à valeur.

FICHIERS

/etc/X11/xorg.conf

EXEMPLES

Pour désactiver EdgeMotionMinSpeed :

synclient EdgeMotionMinSpeed=0
