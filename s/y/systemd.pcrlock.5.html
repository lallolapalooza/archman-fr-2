NOM

systemd.pcrlock, systemd.pcrlock.d - Fichiers de prédiction de mesure PCR

SYNTAXE

/etc/pcrlock.d/*.pcrlock
/etc/pcrlock.d/*.pcrlock.d/*.pcrlock
/run/pcrlock.d/*.pcrlock
/run/pcrlock.d/*.pcrlock.d/*.pcrlock
/var/lib/pcrlock.d/*.pcrlock
/var/lib/pcrlock.d/*.pcrlock.d/*.pcrlock
/usr/local/lib/pcrlock.d/*.pcrlock
/usr/local/lib/pcrlock.d/*.pcrlock.d/*.pcrlock
/usr/lib/pcrlock.d/*.pcrlock
/usr/lib/pcrlock.d/*.pcrlock.d/*.pcrlock

DESCRIPTION

Les fichiers *.pcrlock définissent les mesures PCR attendues du TPM2 pour les composants impliqués dans le processus de démarrage. systemd-pcrlock(8) utilise ces fichiers pcrlock pour analyser et prédire les mesures PCR du TPM2. Les fichiers pcrlock sont des tableaux JSON qui suivent un sous-ensemble de la spécification du TCG Canonical Event Log Format (CEL-JSON)[1]. Plus précisément, les champs d'enregistrement "recnum", "content" et "content_type" ne sont pas utilisés et sont ignorés s'ils sont présents. Chaque fichier pcrlock définit un ensemble de mesures PCR attendues et ordonnées d'un composant spécifique du démarrage.

Les fichiers *.pcrlock peuvent être placés dans divers répertoires de drop-in .d/ (voir ci-dessus pour une liste complète). Tous les fichiers correspondants découverts dans ces répertoires sont triés par ordre alphabétique selon leur nom de fichier (sans prendre en compte le répertoire réel dans lequel ils ont été trouvés) : les fichiers pcrlock avec des noms alphabétiquement plus anciens sont censés couvrir les mesures effectuées avant ceux avec des noms alphabétiquement plus récents. Afin de faciliter le positionnement des fichiers pcrlock dans le processus de démarrage, les fichiers sont attendus (par convention, ceci n'est pas imposé) d'être nommés "NNN-composant.pcrlock" (où NNN est un nombre décimal à trois chiffres), par exemple 750-enter-initrd.pcrlock.

Pour divers composants du processus de démarrage, plus d'un fichier pcrlock alternatif sera pris en charge (c'est-à-dire des "variantes"). Par exemple, pour couvrir plusieurs noyaux installés en parallèle dans la politique d'accès, ou plusieurs versions du chargeur de démarrage. Cela peut être fait en plaçant *.pcrlock.d/*.pcrlock dans les répertoires de drop-in, c'est-à-dire un répertoire commun pour un composant spécifique, qui contient un ou plusieurs fichiers pcrlock, chacun couvrant une variante du composant. Exemple : 650-kernel.pcrlock.d/6.5.5-200.fc38.x86_64.pcrlock et 650-kernel.pcrlock.d/6.5.7-100.fc38.x86_64.pcrlock

Utilisez systemd-pcrlock list-components pour lister tous les fichiers pcrlock actuellement installés.

Utilisez les différentes commandes lock-* de systemd-pcrlock pour générer automatiquement des fichiers pcrlock adéquats pour divers types de ressources.

COMPOSANTS BIEN CONNUS

Les composants du processus de démarrage peuvent être définis librement par l'administrateur ou le fournisseur du système d'exploitation. Cependant, les composants suivants sont bien connus et définis par systemd. La liste ci-dessous est utile pour ordonner correctement les fichiers pcrlock locaux par rapport à ces composants du démarrage.

240-secureboot-policy.pcrlock

La politique SecureBoot, telle qu'enregistrée dans le PCR 7. Peut être générée via systemd-pcrlock lock-secureboot-policy.

Ajouté dans la version 255.

250-firmware-code-early.pcrlock

Mesures du code du firmware, telles qu'enregistrées dans les PCR 0 et 2, jusqu'à la mesure du séparateur (voir 400-secureboot-separator.pcrlock ci-dessous). Peut être généré via systemd-pcrlock lock-firmware-code.

Ajouté dans la version 255.

250-firmware-config-early.pcrlock

Mesures de configuration du firmware, telles qu'enregistrées dans les PCR 1 et 3, jusqu'à la mesure du séparateur (voir 400-secureboot-separator.pcrlock ci-dessous). Peut être généré via systemd-pcrlock lock-firmware-config.

Ajouté dans la version 255.

350-action-efi-application.pcrlock

La mesure EFI "Application" effectuée une fois par le firmware. Définie statiquement.

Ajouté dans la version 255.

400-secureboot-separator.pcrlock

Le séparateur EFI "separator" sur le PCR 7 effectué une fois par le firmware pour indiquer où le contrôle du firmware passe au contrôle du chargeur de démarrage/système d'exploitation. Défini statiquement.

Ajouté dans la version 255.

500-separator.pcrlock

Les séparateurs EFI "separator" sur les PCR 0-6 effectués une fois par le firmware pour indiquer où le contrôle du firmware passe au contrôle du chargeur de démarrage/système d'exploitation. Défini statiquement.

Ajouté dans la version 255.

550-firmware-code-late.pcrlock

Mesures du code du firmware, telles qu'enregistrées dans les PCR 0 et 2, après la mesure du séparateur (voir 400-secureboot-separator.pcrlock ci-dessus). Peut être généré via systemd-pcrlock lock-firmware-code.

Ajouté dans la version 255.

550-firmware-config-late.pcrlock

Mesures de configuration du firmware, telles qu'enregistrées dans les PCR 1 et 3, après la mesure du séparateur (voir 400-secureboot-separator.pcrlock ci-dessus). Peut être généré via systemd-pcrlock lock-firmware-config.

Ajouté dans la version 255.

600-gpt.pcrlock

La table de partitions GPT du média démarré, telle qu'enregistrée dans le PCR 5 par le firmware. Peut être générée via systemd-pcrlock lock-gpt.

Ajouté dans la version 255.

620-secureboot-authority.pcrlock

L'autorité SecureBoot, telle qu'enregistrée dans le PCR 7. Peut être générée via systemd-pcrlock lock-secureboot-authority.

Ajouté dans la version 255.

700-action-efi-exit-boot-services.pcrlock

L'action EFI générée lorsque ExitBootServices() est appelée, c'est-à-dire lorsque l'environnement UEFI est quitté et que le système d'exploitation prend le contrôle. Couvre la mesure PCR 5. Défini statiquement.

Ajouté dans la version 255.

710-kernel-cmdline.pcrlock

La ligne de commande du noyau, telle que mesurée par le noyau Linux dans le PCR 9. Peut être générée via systemd-pcrlock lock-kernel-cmdline.

Ajouté dans la version 255.

720-kernel-initrd.pcrlock

L'initrd du noyau, tel que mesuré par le noyau Linux dans le PCR 9. Peut être généré via systemd-pcrlock lock-kernel-initrd.

Ajouté dans la version 255.

750-enter-initrd.pcrlock

La mesure effectuée par systemd-pcrphase-initrd.service(8) dans le PCR 11 lors de l'initialisation de l'initrd. Défini statiquement.

Ajouté dans la version 255.

800-leave-initrd.pcrlock

La mesure effectuée par systemd-pcrphase-initrd.service(8) dans le PCR 11 lors de la fin de l'initialisation de l'initrd. Défini statiquement.

Ajouté dans la version 255.

820-machine-id.pcrlock

La mesure effectuée par systemd-pcrmachine.service(8) dans le PCR 15 au démarrage, couvrant le contenu de /etc/machine-id. Peut être généré via systemd-pcrlock lock-machine-id.

Ajouté dans la version 255.

830-root-file-system.pcrlock

La mesure effectuée par systemd-pcrfs-root.service(8) dans le PCR 15 au démarrage, couvrant l'identité du système de fichiers racine. Peut être généré via systemd-pcrlock lock-file-system.

Ajouté dans la version 255.

850-sysinit.pcrlock

La mesure effectuée par systemd-pcrphase-sysinit.service(8) dans le PCR 11 lorsque l'espace utilisateur principal a effectué une initialisation de base et procédera maintenant au démarrage des services système réguliers. Défini statiquement.

Ajouté dans la version 255.

900-ready.pcrlock

La mesure effectuée par systemd-pcrphase.service(8) dans le PCR 11 lorsque le système a complètement démarré. Défini statiquement.

Ajouté dans la version 255.

950-shutdown.pcrlock

La mesure effectuée par systemd-pcrphase.service(8) dans le PCR 11 lorsque le système commence son arrêt. Défini statiquement.

Ajouté dans la version 255.

990-final.pcrlock

La mesure effectuée par systemd-pcrphase-sysinit.service(8) dans le PCR 11 à la fin de l'initialisation du système. Défini statiquement.

Ajouté dans la version 255.

1000-leave-userspace.pcrlock

La mesure effectuée par systemd-pcrphase-userspace.service(8) dans le PCR 11 lors de la sortie de l'espace utilisateur. Défini statiquement.

Ajouté dans la version 255.

1050-kernel-module-loading.pcrlock

La mesure du chargement des modules du noyau dans le PCR 10. Peut être généré via systemd-pcrlock lock-kernel-modules.

Ajouté dans la version 255.

1100-bootloader.pcrlock

La mesure du chargeur de démarrage, telle qu'enregistrée dans le PCR 4 par le firmware. Peut être générée via systemd-pcrlock lock-bootloader.

Ajouté dans la version 255.

1200-efi-runtime.pcrlock

La mesure de l'interface EFI runtime, telle qu'enregistrée dans le PCR 5 par le firmware. Peut être générée via systemd-pcrlock lock-efi-runtime.

Ajouté dans la version 255.

1300-nvram.pcrlock

La mesure du contenu de la NVRAM EFI, telle qu'enregistrée dans le PCR 5 par le firmware. Peut être générée via systemd-pcrlock lock-nvram.

Ajouté dans la version 255.

1400-kernel-command-line-late.pcrlock

La ligne de commande du noyau, telle qu'enregistrée par le noyau Linux dans le PCR 9, une fois que l'initrd a été déchargé. Peut être générée via systemd-pcrlock lock-kernel-cmdline-late.

Ajouté dans la version 255.

1500-root-file-system-late.pcrlock

L'identité du système de fichiers racine, telle qu'enregistrée par le noyau Linux dans le PCR 15, une fois que l'initrd a été déchargé. Peut être générée via systemd-pcrlock lock-file-system-late.

Ajouté dans la version 255.

1550-userspace-config.pcrlock

La mesure des configurations de l'espace utilisateur, par exemple les fichiers dans /etc, enregistrée dans le PCR 15. Peut être générée via systemd-pcrlock lock-userspace-config.

Ajouté dans la version 255.

2000-policy-config.pcrlock

Mesure de la configuration des politiques de sécurité, par exemple les fichiers dans /etc/systemd/system/pcrlock.d/. Peut être généré via systemd-pcrlock lock-policy-config.

Ajouté dans la version 255.

2400-secureboot-policy-late.pcrlock

La politique SecureBoot, telle qu'enregistrée dans le PCR 7, après que le démarrage a progressionné. Peut être générée via systemd-pcrlock lock-secureboot-policy.

Ajouté dans la version 255.

EXEMPLES

Pour créer un fichier pcrlock qui enregistre le contenu du système de fichiers racine dans le PCR 15 :


# systemd-pcrlock lock-file-system /
# mv /usr/share/pcrlock/root-file-system.pcrlock /etc/pcrlock.d/830-root-file-system.pcrlock

Pour créer un fichier pcrlock qui enregistre la ligne de commande du noyau dans le PCR 9 :


# systemd-pcrlock lock-kernel-cmdline
# mv /usr/share/pcrlock/kernel-cmdline.pcrlock /etc/pcrlock.d/710-kernel-cmdline.pcrlock

Pour créer un fichier pcrlock qui enregistre la politique SecureBoot dans le PCR 7 :


# systemd-pcrlock lock-secureboot-policy
# mv /usr/share/pcrlock/secureboot-policy.pcrlock /etc/pcrlock.d/240-secureboot-policy.pcrlock

Pour créer un fichier pcrlock qui enregistre le code du firmware dans les PCR 0 et 2 (avant le séparateur) :


# systemd-pcrlock lock-firmware-code
# mv /usr/share/pcrlock/firmware-code.pcrlock /etc/pcrlock.d/250-firmware-code-early.pcrlock

Pour créer un fichier pcrlock qui enregistre le code du firmware dans les PCR 0 et 2 (après le séparateur) :


# systemd-pcrlock lock-firmware-code --after-separator
# mv /usr/share/pcrlock/firmware-code.pcrlock /etc/pcrlock.d/550-firmware-code-late.pcrlock

Pour créer un fichier pcrlock qui enregistre le chargeur de démarrage dans le PCR 4 :


# systemd-pcrlock lock-bootloader
# mv /usr/share/pcrlock/bootloader.pcrlock /etc/pcrlock.d/1100-bootloader.pcrlock

Pour créer un fichier pcrlock qui enregistre la configuration NVRAM EFI dans le PCR 5 :


# systemd-pcrlock lock-nvram
# mv /usr/share/pcrlock/nvram.pcrlock /etc/pcrlock.d/1300-nvram.pcrlock

Pour créer un fichier pcrlock qui enregistre les modules du noyau dans le PCR 10 :


# systemd-pcrlock lock-kernel-modules
# mv /usr/share/pcrlock/kernel-modules.pcrlock /etc/pcrlock.d/1050-kernel-module-loading.pcrlock

Pour créer un fichier pcrlock qui enregistre la configuration de l'espace utilisateur dans le PCR 15 :


# systemd-pcrlock lock-userspace-config
# mv /usr/share/pcrlock/userspace-config.pcrlock /etc/pcrlock.d/1550-userspace-config.pcrlock
