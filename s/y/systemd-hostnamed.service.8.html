NOM

systemd-hostnamed.service, systemd-hostnamed - Démon pour contrôler le nom d'hôte du système à partir de programmes

SYNTAXE

systemd-hostnamed.service

/usr/lib/systemd/systemd-hostnamed

DESCRIPTION

systemd-hostnamed.service est un service système qui peut être utilisé pour modifier le nom d'hôte du système et les métadonnées de machine associées à partir de programmes utilisateurs. Il est activé automatiquement sur demande et se termine lorsqu'il n'est pas utilisé.

Il offre actuellement un accès à cinq variables :

•Le nom d'hôte actuel (Exemple : "dhcp-192-168-47-11")
•Le nom d'hôte statique (configuré) (Exemple : "lennarts-computer")
•Le nom d'hôte convivial (Exemple : "L'ordinateur de Lennart")
•Un nom d'icône approprié pour l'hôte local (Exemple : "ordinateur-portable")
•Un type de châssis (Exemple : "tablette")

Le nom d'hôte statique est stocké dans /etc/hostname, voir hostname(5) pour plus d'informations. Le nom d'hôte convivial, le type de châssis et le nom d'icône sont stockés dans /etc/machine-info, voir machine-info(5).

L'outil hostnamectl(1) est un client en ligne de commande pour ce service.

Voir org.freedesktop.hostname1(5) et org.freedesktop.LogControl1(5) pour une description de l'API D-Bus.

VOIR AUSSI

systemd(1), hostname(5), machine-info(5), hostnamectl(1), sethostname(2), org.freedesktop.hostname1(5)
