NOM

systemd-binfmt.service, systemd-binfmt - Configure des formats binaires supplémentaires pour les exécutables au démarrage

SYNOPSIS

systemd-binfmt.service

/usr/lib/systemd/systemd-binfmt

DESCRIPTION

systemd-binfmt.service est un service de démarrage précoce qui enregistre des formats binaires supplémentaires pour les exécutables dans le noyau.

Voir binfmt.d(5) pour des informations sur la configuration de ce service.

OPTIONS

--unregister

Si passé, au lieu d'enregistrer les formats binaires configurés dans le noyau, l'opération inverse est exécutée : tous les formats binaires actuellement enregistrés sont désenregistrés du noyau.

Ajouté dans la version 246.

--cat-config

Copie le contenu des fichiers de configuration sur la sortie standard. Avant chaque fichier, le nom du fichier est affiché sous forme de commentaire.

--tldr

Copie le contenu des fichiers de configuration sur la sortie standard. Seules les parties « intéressantes » des fichiers de configuration sont affichées, les commentaires et les lignes vides sont ignorés. Avant chaque fichier, le nom du fichier est affiché sous forme de commentaire.

--no-pager

Ne pas rediriger la sortie vers un pagineur.

-h, --help

Affiche un court message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.
