PROLOGUE

Cette page de manuel fait partie du manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/times.h — structure des temps d'accès et de modification de fichier

SYNTAXE

#include <sys/times.h>

DESCRIPTION

L'en-tête <sys/times.h> définira la structure tms, qui est retournée par times() et qui contiendra au moins les membres suivants :

clock_t  tms_utime  Temps CPU utilisateur.
clock_t  tms_stime  Temps CPU système.
clock_t  tms_cutime Temps CPU utilisateur des processus enfants terminés.
clock_t  tms_cstime Temps CPU système des processus enfants terminés.

L'en-tête <sys/times.h> définira le type clock_t tel que décrit dans <sys/types.h>.

Ce qui suit sera déclaré comme une fonction et pourra également être défini comme une macro. Un prototype de fonction sera fourni.

clock_t times(struct tms *);
