NOM

syslog-ng-debun --- Générateur de paquet de débogage syslog-ng

SYNOPSIS

syslog-ng-debun [options]

DESCRIPTION

NOTE : L'application syslog-ng-debun est distribuée avec l'application de journalisation système syslog-ng OSE, et fait généralement partie du paquet syslog-ng OSE. La dernière version de l'application syslog-ng OSE est disponible sur la page syslog-ng OSE.

Cette page de manuel est seulement un résumé.

L'outil syslog-ng-debun collecte et sauvegarde des informations sur votre installation de syslog-ng OSE, facilitant ainsi le dépannage, surtout si vous demandez de l'aide concernant votre problème lié à syslog-ng OSE.

OPTIONS GÉNÉRALES

•
-r

Exécute syslog-ng-debun. Utiliser cette option est requis pour exécuter réellement la collecte de données avec syslog-ng-debun. Elle est nécessaire pour éviter d'exécuter accidentellement syslog-ng-debun.

•
-h

Affiche la page d'aide.

•
-l

Ne collecte pas de données sensibles à la vie privée, par exemple, l'arbre des processus, fstab, etc. Si vous l'utilisez avec -d, alors les paramètres suivants seront utilisés pour le mode de débogage : -Fev

•
-R <répertoire>

Le répertoire où syslog-ng PE est installé, au lieu de /opt/syslog-ng.

•
-W <répertoire>

Définit le répertoire de travail, où le paquet de débogage sera sauvegardé. Valeur par défaut : /tmp. Le nom du fichier créé est syslog.debun.${hôte}.${date}.${3-caractères-aléatoires-ou-pid}.tgz

OPTIONS DE MODE DE DÉBOGAGE

•
-d

Démarre syslog-ng OSE en mode débogage, en utilisant les options -Fedv --enable-core.

[](/assets/images/caution.png) ATTENTION : L'utilisation de cette option sous une forte charge de messages peut augmenter les E/S disque pendant le débogage, et le paquet de débogage résultant peut être énorme. Pour quitter le mode débogage, appuyez sur Entrée.

•
-D <options>

Démarre syslog-ng OSE en mode débogage, en utilisant les options de ligne de commande spécifiées. Pour quitter le mode débogage, appuyez sur Entrée.

•
-t <secondes>

Exécute syslog-ng OSE en mode débogage non interactif pendant <secondes>, et quitte automatiquement le mode débogage après le nombre de secondes spécifié.

•
-w <secondes>

Attend <secondes> secondes avant de démarrer le mode débogage.

TRAÇAGE DES APPELS SYSTÈME

•
-s

Active le traçage des appels système (strace -f ou truss -f). Notez que l'utilisation de -s n'active pas elle-même le mode débogage, elle trace seulement les appels système d'un processus syslog-ng OSE déjà en cours d'exécution. Pour tracer les appels système en mode débogage, utilisez les options -s et -d.

OPTIONS DE CAPTURE DE PAQUETS

La capture de paquets nécessite un outil de capture de paquets sur l'hôte. L'outil syslog-ng-debun tente d'utiliser tcpdump sur la plupart des plateformes, sauf pour Solaris, où il utilise snoop.

•
-i <interface>

Capture les paquets uniquement sur l'interface spécifiée, par exemple, eth0.

•
-p

Capture les paquets entrants en utilisant le filtre suivant : port 514 ou port 601 ou port 53

•
-P <options>

Capture les paquets entrants en utilisant le filtre spécifié.

•
-t <secondes>

Exécute syslog-ng OSE en mode débogage non interactif pendant <secondes>, et quitte automatiquement le mode débogage après le nombre de secondes spécifié.

Exemples

syslog-ng-debun -r

Crée un paquet de débogage simple, collectant des informations sur votre environnement, par exemple, la liste des paquets contenant le mot : syslog, ldd de votre binaire syslog, etc.

syslog-ng-debun -r -l

Similaire à syslog-ng-debun -r, mais sans informations sensibles à la vie privée. Par exemple, les éléments suivants ne sont PAS collectés : fstab, sortie de df, informations de montage, configuration de l'interface réseau / ip, informations de résolution DNS, et arbre des processus.

syslog-ng-debun -r -d

Similaire à syslog-ng-debun -r, mais il arrête également syslog-ng OSE, puis le redémarre en mode débogage (-Fedv --enable-core). Pour arrêter le mode débogage, appuyez sur Entrée. La sortie du mode débogage est collectée dans un fichier séparé, et ajoutée également au paquet de débogage.

syslog-ng-debun -r -s

Trace les appels système (en utilisant strace ou truss) d'un processus syslog-ng OSE déjà en cours d'exécution.

syslog-ng-debun -r -d -s

Redémarre syslog-ng OSE en mode débogage, et trace également les appels système (en utilisant strace ou truss) du processus syslog-ng OSE.

syslog-ng-debun -r -p

Exécute la capture de paquets (pcap) avec le filtre : port 514 ou port 601 ou port 53 Attend également l'appui sur Entrée, comme le mode débogage.

syslog-ng-debun -r -p -t 10

Mode débogage non interactif : Similaire à syslog-ng-debun -r -p, mais quitte automatiquement après 10 secondes.

syslog-ng-debun -r -P "host 1.2.3.4"  -D "-Fev --enable-core"

Modifie le filtre de capture de paquets du défaut à host 1.2.3.4. Modifie également les paramètres de débogage du défaut à -Fev --enable-core. Puisqu'un délai d'attente (-t) n'est pas donné, attend l'appui sur Entrée.

syslog-ng-debun -r -p -d -w 5 -t 10

Collecte la sortie pcap et du mode débogage en suivant ce scénario :

  • Démarre la capture de paquets avec les paramètres par défaut (-p)
  • Attend 5 secondes (-w 5)
  • Arrête syslog-ng
  • Démarre syslog-ng OSE en mode débogage avec les paramètres par défaut (-d)
  • Attend 10 secondes (-t 10)
  • Arrête le débogage de syslog-ng OSE
  • Démarre syslog-ng OSE
  • Arrête la capture de paquets
