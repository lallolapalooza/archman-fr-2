NOM

systemd-mountfsd.service, systemd-mountfsd - Service de montage de système de fichiers d'images disque

SYNOPIS

systemd-mountfsd.service

/usr/lib/systemd/systemd-mountfsd

DESCRIPTION

systemd-mountfsd est un service système qui dissèque des images disque et renvoie des descripteurs de fichiers de montage pour les systèmes de fichiers qu'elles contiennent aux clients, via une API Varlink IPC.

Les images disque fournies doivent contenir une image de système de fichiers brute ou suivre la Spécification des partitions détectables[1]. Avant de monter tout système de fichiers, l'authenticité de l'image disque est établie d'une ou plusieurs des manières suivantes :

1. Si l'image disque se trouve dans un fichier régulier dans l'un des répertoires /var/lib/machines/, /var/lib/portables/, /var/lib/extensions/, /var/lib/confexts/ ou leurs équivalents dans /etc/, /run/, /usr/lib/, elle est considérée comme fiable.
2. Si l'image disque contient une image disque activée par Verity, ainsi qu'une partition de signature avec une clé dans l'anneau de clés du noyau ou dans /etc/verity.d/ (et les répertoires associés), l'image disque est considérée comme fiable.

Ce service fournit un service Varlink[2] : io.systemd.MountFileSystem qui accepte un descripteur de fichier vers un fichier régulier ou un périphérique bloc, et renvoie un certain nombre de descripteurs de fichiers faisant référence à un descripteur de fichier fsmount() que le client peut ensuite attacher à un chemin de son choix.

Les montages renvoyés sont automatiquement ajoutés à la liste blanche dans la liste blanche par espace de noms d'utilisateur gérée par systemd-nsresourced.service(8).

Les systèmes de fichiers sont automatiquement vérifiés avec fsck(8) avant le montage.
