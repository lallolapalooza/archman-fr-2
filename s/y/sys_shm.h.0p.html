sys_shm.h(0p) Manuel du programmeur POSIX sys_shm.h(0p)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/shm.h — facilité de mémoire partagée XSI

SYNOPSIS

#include <sys/shm.h>

DESCRIPTION

L'en-tête <sys/shm.h> définit les constantes symboliques suivantes :

SHM_RDONLY
Attacher en lecture seule (sinon lecture-écriture).
SHM_RND
Arrondir l'adresse d'attachement à SHMLBA.
SHMLBA
Multiple de la limite inférieure de segment.

L'en-tête <sys/shm.h> définit le type de données suivant via typedef :

shmatt_t
Entier non signé utilisé pour le nombre d'attaches actuelles, qui doit pouvoir stocker des valeurs au moins aussi grandes qu'un type unsigned short.

L'en-tête <sys/shm.h> définit la structure shmid_ds, qui inclura les membres suivants :

struct ipc_perm shm_perm   Structure de permission d'opération.
size_t          shm_segsz  Taille du segment en octets.
pid_t           shm_lpid   Identifiant du processus de la dernière opération de mémoire partagée.
pid_t           shm_cpid   Identifiant du processus du créateur.
shmatt_t        shm_nattch Nombre d'attaches actuelles.
time_t          shm_atime  Heure de la dernière shmat().
time_t          shm_dtime  Heure de la dernière shmdt().
time_t          shm_ctime  Heure de la dernière modification par shmctl().

L'en-tête <sys/shm.h> définit les types pid_t, size_t et time_t tels que décrits dans <sys/types.h>.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Des prototypes de fonctions seront fournis.

void *shmat(int, const void *, int);
int   shmctl(int, int, struct shmid_ds *);
int   shmdt(const void *);
int   shmget(key_t, size_t, int);

De plus, l'en-tête <sys/shm.h> inclura l'en-tête <sys/ipc.h>.
