SYNTHV1(1) Manuel des commandes générales SYNTHV1(1)

NOM

synthv1 - un synthétiseur polyphonique à l'ancienne

SYNTAXE

synthv1_jack [options] [fichier-preset]

DESCRIPTION

Cette page de manuel documente brièvement la commande synthv1_jack.

synthv1 est un synthétiseur polyphonique soustractif 4 oscillateurs à l'ancienne avec effets stéréo.

Fonctionnalités :

un client JACK autonome pur avec support JACK-session, NSM et entrée MIDI JACK ainsi que MIDI ALSA ;
un plugin instrument LV2. URI : http://synthv1.sourceforge.net/lv2

OPTIONS

-g, --no-gui

Désactive l'interface graphique utilisateur (GUI)

-n, --client-name=[label]

Définit le nom du client JACK (par défaut : synthv1)

-h, --help

Affiche l'aide sur les options de la ligne de commande

-v, --version

Affiche les informations sur la version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/synthv1.conf
