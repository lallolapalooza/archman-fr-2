sys_statvfs.h(0P) Manuel du programmeur POSIX sys_statvfs.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/statvfs.h — Structure d'information du système de fichiers VFS

SYNOPIS

#include <sys/statvfs.h>

DESCRIPTION

L'en-tête <sys/statvfs.h> définira la structure statvfs, qui contiendra au moins les membres suivants :

unsigned long f_bsize    Taille des blocs du système de fichiers.
unsigned long f_frsize   Taille fondamentale des blocs du système de fichiers.
fsblkcnt_t    f_blocks   Nombre total de blocs sur le système de fichiers en unités de f_frsize.
fsblkcnt_t    f_bfree    Nombre total de blocs libres.
fsblkcnt_t    f_bavail   Nombre de blocs libres disponibles pour
                         un processus non privilégié.
fsfilcnt_t    f_files    Nombre total de numéros de série de fichiers.
fsfilcnt_t    f_ffree    Nombre total de numéros de série de fichiers libres.
fsfilcnt_t    f_favail   Nombre de numéros de série de fichiers disponibles pour
                         un processus non privilégié.
unsigned long f_fsid     Identifiant du système de fichiers.
unsigned long f_flag     Masque de bits des valeurs de f_flag.
unsigned long f_namemax  Longueur maximale du nom de fichier.

L'en-tête <sys/statvfs.h> définira les types fsblkcnt_t et fsfilcnt_t tels que décrits dans <sys/types.h>.

L'en-tête <sys/statvfs.h> définira les constantes symboliques suivantes pour le membre f_flag :

ST_RDONLY
Système de fichiers en lecture seule.
ST_NOSUID
Ne supporte pas la sémantique des bits de mode de fichier ST_ISUID et ST_ISGID.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonctions seront fournis.

int fstatvfs(int, struct statvfs *);
int statvfs(const char *restrict, struct statvfs *restrict);
