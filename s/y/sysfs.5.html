sysfs(5) Manuel des formats de fichiers sysfs(5)

NOM

sysfs - un système de fichiers pour exporter des objets du noyau

DESCRIPTION

Le système de fichiers sysfs est un pseudo-système de fichiers qui fournit une interface aux structures de données du noyau. (Plus précisément, les fichiers et répertoires dans sysfs fournissent une vue des structures kobject définies en interne dans le noyau.) Les fichiers sous sysfs fournissent des informations sur les périphériques, les modules du noyau, les systèmes de fichiers et d'autres composants du noyau.

Le système de fichiers sysfs est généralement monté sur /sys. Typiquement, il est monté automatiquement par le système, mais il peut également être monté manuellement en utilisant une commande telle que :


mount -t sysfs sysfs /sys

Beaucoup de fichiers dans le système de fichiers sysfs sont en lecture seule, mais certains fichiers sont inscriptibles, permettant de modifier des variables du noyau. Pour éviter la redondance, des liens symboliques sont largement utilisés pour connecter des entrées dans l'arborescence du système de fichiers.

Fichiers et répertoires

La liste suivante décrit certains des fichiers et répertoires sous la hiérarchie /sys.

/sys/block
Ce sous-répertoire contient un lien symbolique pour chaque périphérique bloc qui a été découvert sur le système. Les liens symboliques pointent vers des répertoires correspondants sous /sys/devices.
/sys/bus
Ce répertoire contient un sous-répertoire pour chacun des types de bus dans le noyau. À l'intérieur de chacun de ces répertoires se trouvent deux sous-répertoires :
devices
Ce sous-répertoire contient des liens symboliques vers des entrées dans /sys/devices qui correspondent aux périphériques découverts sur ce bus.
drivers
Ce sous-répertoire contient un sous-répertoire pour chaque pilote de périphérique chargé sur ce bus.
/sys/class
Ce sous-répertoire contient une seule couche de sous-répertoires supplémentaires pour chacune des classes de périphériques qui ont été enregistrées sur le système (par exemple, terminaux, périphériques réseau, périphériques bloc, périphériques graphiques, périphériques sonores, etc.). À l'intérieur de chacun de ces sous-répertoires se trouvent des liens symboliques pour chacun des périphériques de cette classe. Ces liens symboliques font référence à des entrées dans le répertoire /sys/devices.
/sys/class/net
Chacune des entrées de ce répertoire est un lien symbolique représentant l'un des périphériques réseau réels ou virtuels visibles dans l'espace de noms réseau du processus qui accède au répertoire. Chacun de ces liens symboliques fait référence à des entrées dans le répertoire /sys/devices.
/sys/dev
Ce répertoire contient deux sous-répertoires block/ et char/, correspondant respectivement aux périphériques bloc et caractère du système. À l'intérieur de chacun de ces sous-répertoires se trouvent des liens symboliques nommés sous la forme major-ID:minor-ID, où les valeurs ID correspondent aux ID majeur et mineur d'un périphérique spécifique. Chaque lien symbolique pointe vers le répertoire sysfs d'un périphérique. Les liens symboliques dans /sys/dev offrent ainsi un moyen simple de rechercher l'interface sysfs en utilisant les ID de périphérique renvoyés par un appel à stat(2) (ou similaire).
La session shell suivante montre un exemple de /sys/dev :

$ stat -c "%t %T" /dev/null;
1 3
$ readlink /sys/dev/char/1\:3;
../../devices/virtual/mem/null
$ ls -Fd /sys/devices/virtual/mem/null;
/sys/devices/virtual/mem/null/
$ ls -d1 /sys/devices/virtual/mem/null/*;
/sys/devices/virtual/mem/null/dev
/sys/devices/virtual/mem/null/power/
/sys/devices/virtual/mem/null/subsystem@
/sys/devices/virtual/mem/null/uevent

/sys/devices
Ceci est un répertoire qui contient une représentation système de fichiers de l'arborescence des périphériques du noyau, qui est une hiérarchie de structures de périphériques au sein du noyau.
/sys/firmware
Ce sous-répertoire contient des interfaces pour visualiser et manipuler des objets et des attributs spécifiques au firmware.
/sys/fs
Ce répertoire contient des sous-répertoires pour certains systèmes de fichiers. Un système de fichiers aura un sous-répertoire ici uniquement s'il a choisi de créer explicitement ce sous-répertoire.
/sys/fs/cgroup
Ce répertoire est conventionnellement utilisé comme point de montage pour un système de fichiers tmpfs(5) contenant des points de montage pour les systèmes de fichiers cgroups(7).
/sys/fs/smackfs
Le répertoire contient les fichiers de configuration du LSM SMACK. Voir le fichier source du noyau Documentation/admin-guide/LSM/Smack.rst.

/sys/kernel
Ce sous-répertoire contient divers fichiers et sous-répertoires qui fournissent des informations sur le noyau en cours d'exécution.
/sys/kernel/cgroup/
Pour des informations sur les fichiers de ce répertoire, voir cgroups(7).
/sys/kernel/debug/tracing
Point de montage pour le système de fichiers tracefs utilisé par le mécanisme ftrace du noyau. (Pour des informations sur ftrace, voir le fichier source du noyau Documentation/trace/ftrace.txt.)
/sys/kernel/mm
Ce sous-répertoire contient divers fichiers et sous-répertoires qui fournissent des informations sur le sous-système de gestion de la mémoire du noyau.
/sys/kernel/mm/hugepages
Ce sous-répertoire contient un sous-répertoire pour chacune des tailles de pages immenses prises en charge par le système. Le nom du sous-répertoire indique la taille de la page immense (par exemple, hugepages-2048kB). Dans chacun de ces sous-répertoires se trouve un ensemble de fichiers qui peuvent être utilisés pour visualiser et (dans certains cas) modifier les paramètres associés à cette taille de page immense. Pour plus d'informations, voir le fichier source du noyau Documentation/admin-guide/mm/hugetlbpage.rst.
