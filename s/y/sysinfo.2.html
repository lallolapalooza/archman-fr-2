sysinfo(2) Manuel des appels système sysinfo(2)

NOM

sysinfo - retourner des informations système

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/sysinfo.h>
int sysinfo(struct sysinfo *info);

DESCRIPTION

sysinfo() retourne certaines statistiques sur l'utilisation de la mémoire et du swap, ainsi que la charge moyenne.

Jusqu'à Linux 2.3.16, sysinfo() retournait les informations dans la structure suivante :


struct sysinfo {
    long uptime;             /* Secondes depuis le démarrage */
    unsigned long loads[3];  /* Moyennes de charge sur 1, 5 et 15 minutes */
    unsigned long totalram;  /* Taille totale de la mémoire principale utilisable */
    unsigned long freeram;   /* Taille de la mémoire disponible */
    unsigned long sharedram; /* Quantité de mémoire partagée */
    unsigned long bufferram; /* Mémoire utilisée par les tampons */
    unsigned long totalswap; /* Taille totale de l'espace d'échange */
    unsigned long freeswap;  /* Espace d'échange encore disponible */
    unsigned short procs;    /* Nombre de processus actuels */
    char _f[22];             /* Rembourrage de la structure à 64 octets */
};

Dans la structure ci-dessus, les tailles des champs mémoire et swap sont données en octets.

Depuis Linux 2.3.23 (i386) et Linux 2.3.48 (toutes architectures), la structure est :


struct sysinfo {
    long uptime;             /* Secondes depuis le démarrage */
    unsigned long loads[3];  /* Moyennes de charge sur 1, 5 et 15 minutes */
    unsigned long totalram;  /* Taille totale de la mémoire principale utilisable */
    unsigned long freeram;   /* Taille de la mémoire disponible */
    unsigned long sharedram; /* Quantité de mémoire partagée */
    unsigned long bufferram; /* Mémoire utilisée par les tampons */
    unsigned long totalswap; /* Taille totale de l'espace d'échange */
    unsigned long freeswap;  /* Espace d'échange encore disponible */
    unsigned short procs;    /* Nombre de processus actuels */
    unsigned long totalhigh; /* Taille totale de la mémoire haute */
    unsigned long freehigh;  /* Taille de la mémoire haute disponible */
    unsigned int mem_unit;   /* Taille de l'unité mémoire en octets */
    char _f[20-2*sizeof(long)-sizeof(int)];
                             /* Rembourrage à 64 octets */
};

Dans la structure ci-dessus, les tailles des champs mémoire et swap sont données en multiples de mem_unit octets.

VALEUR DE RETOUR

En cas de succès, sysinfo() retourne zéro. En cas d'erreur, -1 est retourné et errno est positionné pour indiquer l'erreur.

ERREURS

EFAULT
info n'est pas une adresse valide.

NORMES

Linux.

HISTORIQUE

Linux 0.98.pl6.

NOTES

Toutes les informations fournies par cet appel système sont également disponibles via /proc/meminfo et /proc/loadavg.

VOIR AUSSI

proc(5)
