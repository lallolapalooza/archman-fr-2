NOM

systeroid-tui - gérer les paramètres du noyau avec une interface utilisateur terminale

SYNTAXE

systeroid-tui [options]

DESCRIPTION

systeroid-tui est utilisé pour configurer et visualiser les paramètres du noyau avec une interface utilisateur terminale.

PARAMETRES

-t, --tick-rate <ms>
Utilisez cette option pour définir la fréquence de rafraîchissement du terminal. [défaut : 250]
-D, --docs <chemin>
Utilisez cette option pour définir un chemin personnalisé pour la documentation du noyau.
--save-path <chemin>
Utilisez cette option pour définir le chemin de sauvegarde des paramètres modifiés.
-l, --log-file <chemin>
Utilisez cette option pour définir le fichier où enregistrer les journaux.
-s, --section <section>
Utilisez cette option pour définir la section à filtrer.

-q, --query <requête> définit la requête de recherche.

--bg-color <couleur>
Utilisez cette option pour définir la couleur d'arrière-plan. [défaut : noir]
--fg-color <couleur>
Utilisez cette option pour définir la couleur du premier plan. [défaut : blanc]
-n, --no-docs
Ne pas afficher la documentation du noyau.
--deprecated
Inclure les variables obsolètes lors de la liste.
-h, --help
Afficher le texte d'aide et quitter.
-V, --version
Afficher les informations de version et quitter.

EXEMPLES

systeroid-tui -t 500
systeroid-tui -s kernel
systeroid-tui -q "fs.quota"
systeroid-tui --fg-color blue
systeroid-tui --bg-color ffff99 --fg-color 003366
systeroid-tui -D /usr/share/doc/linux
systeroid-tui --save-path 99-local.conf
systeroid-tui --log-file systeroid.log
systeroid-tui -n
