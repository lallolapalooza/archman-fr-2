NOM

systemd-vpick - Résoudre les chemins vers des répertoires versionnés ".v/"

SYNTAXE

systemd-vpick [OPTIONS...] [CHEMIN...]

DESCRIPTION

systemd-vpick résout un chemin de système de fichiers faisant référence à un répertoire versionné ".v/" en un chemin vers le fichier le plus récent (par version) qu'il contient. Cet outil fournit une interface en ligne de commande pour la logique de systemd.v(7).

L'outil attend un chemin vers un répertoire ".v/" comme argument (soit directement, soit avec un modèle de triple trait de soulignement comme composant final). Il détermine ensuite le fichier le plus récent contenu dans ce répertoire, et écrit son chemin sur la sortie standard.

À moins que le modèle de triple trait de soulignement ne soit passé comme dernier composant du chemin, il est généralement nécessaire de spécifier au moins l'option --suffix= pour configurer le suffixe de fichier à rechercher.

Si le chemin spécifié ne fait pas référence à un chemin ".v/" (c'est-à-dire si ni le dernier composant ne se termine par ".v", ni l'avant-dernier ne le fait ou si le dernier ne contient pas de triple trait de soulignement) son chemin spécifié est écrit sans modification sur la sortie standard.

OPTIONS

Les options suivantes sont comprises:

--basename=, -B

Remplace le "nom de base" des fichiers à rechercher, c'est-à-dire la partie à gauche de la partie variable des noms de fichier. Normalement, cela est dérivé automatiquement du nom de fichier du composant ".v" du chemin spécifié, ou du modèle de triple trait de soulignement dans le dernier composant du chemin spécifié.

Ajouté dans la version 256.

-V

Configure explicitement la version à sélectionner. Si spécifié, un nom de fichier avec la chaîne de version spécifiée sera recherché, au lieu de la version la plus récente disponible.

Ajouté dans la version 256.

-A

Configure explicitement l'architecture à sélectionner. Si spécifié, un nom de fichier avec l'identifiant d'architecture spécifié sera recherché. Si non spécifié, seuls les noms de fichier avec une architecture localement prise en charge sont considérés, ou ceux sans identifiant d'architecture.

Ajouté dans la version 256.

--suffix=, -S

Configure le suffixe des noms de fichier à considérer. Pour la logique ".v/", il est nécessaire de spécifier le suffixe à rechercher, et le composant ".v/" doit également porter le suffixe immédiatement avant ".v" dans son nom.

Ajouté dans la version 256.

--type=, -t

Configure le type d'inode à rechercher dans le répertoire ".v/". Prend l'une des valeurs suivantes : "reg", "dir", "sock", "fifo", "blk", "chr", "lnk" comme argument, chacune identifiant un type d'inode. Voir inode(7) pour les détails sur les types d'inodes. Si cette option est utilisée, les inodes ne correspondant pas au type spécifié sont filtrés et ne sont pas pris en considération.

Ajouté dans la version 256.

--print=, -p

Configure ce qui doit être écrit sur la sortie standard. Si non spécifié, imprime le chemin complet et résolu du fichier correspondant le plus récent dans le répertoire ".v/". Ce commutateur peut être défini sur l'une des valeurs suivantes :
•S'il est défini sur "filename", n'imprimera que le nom du fichier au lieu du chemin complet du fichier résolu.
•S'il est défini sur "version", n'imprimera que la version du fichier résolu.
•S'il est défini sur "type", n'imprimera que le type d'inode du fichier résolu (c'est-à-dire une chaîne comme "reg" pour les fichiers réguliers, ou "dir" pour les répertoires).
•S'il est défini sur "arch", n'imprimera que l'architecture du fichier résolu.
•S'il est défini sur "tries", n'imprimera que le nombre d'essais restants/effectués du fichier résolu.
•S'il est défini sur "all", imprimera tout ce qui précède dans un format tabulaire simple.

Ajouté dans la version 256.

--resolve=

Prend un argument booléen. Si vrai, le chemin vers le fichier versionné est entièrement canonisé (c'est-à-dire que les liens symboliques sont résolus et les composants de chemin redondants sont supprimés) avant d'être affiché. Si faux (par défaut), cela n'est pas fait et le chemin est affiché sans canonicalisation.

Ajouté dans la version 256.

-h, --help

Imprime un court texte d'aide et quitte.

--version

Imprime une courte chaîne de version et quitte.

EXEMPLES

Utilisez une commande comme la suivante pour sélectionner automatiquement l'image disque brute la plus récente d'un répertoire ".v/" :

$ systemd-vpick --suffix=.raw --type=reg /var/lib/machines/quux.raw.v/

Ceci énumérera tous les fichiers réguliers correspondant à /var/lib/machines/quux.raw.v/quux*.raw, les filtrera et les triera selon les règles décrites dans systemd.v(7), puis écrira le chemin du fichier le plus récent (par version) sur la sortie standard.

Utilisez une commande comme la suivante pour sélectionner automatiquement l'arborescence de répertoire d'OS la plus récente d'un répertoire ".v/" :

$ systemd-vpick --type=dir /var/lib/machines/waldo.v/

Ceci énumérera tous les inodes de répertoire correspondant à /var/lib/machines/waldo.v/waldo*, les filtrera et les triera selon les règles décrites dans systemd.v(7), puis écrira le chemin du répertoire le plus récent (par version) sur la sortie standard.

Pour d'autres exemples, voir systemd.v(7).

STATUT DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.
