NOM

syncplay-server - serveur pour héberger des salons syncplay

SYNTAXE

syncplay-server [options] [fichier] [options_lecteur]

DESCRIPTION

Cette page de manuel documente brièvement la commande syncplay-server.

syncplay-server est un programme auquel les clients syncplay se connectent et qui héberge des salons.

Pour héberger des salons pour des spectateurs sur Internet, assurez-vous que le serveur est accessible depuis Internet, c'est-à-dire que son port d'écoute n'est pas bloqué par un NAT ou un pare-feu.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-h, --help
Afficher le résumé des options.
--port [port]
Port TCP pour écouter les connexions.
--password [mot-de-passe]
Mot de passe du serveur.
--isolate-rooms
Indique si les salons doivent être isolés.
--disable-ready
Désactiver la fonctionnalité "prêt".
--disable-chat
Désactiver la fonction de chat.
--salt [sel]
Chaîne aléatoire utilisée pour générer les mots de passe des salons gérés.
--motd-file [fichier]
Chemin vers un fichier à partir duquel le message du jour (MOTD) sera lu.
--rooms-db-file [fichier]
Active la persistance des salons. Le chemin pointe vers l'emplacement où un fichier de base de données doit être chargé/créé, où les données des salons seront écrites et lues. Cela permettra aux salons de persister sans observateurs et à travers les redémarrages. Ne fonctionnera pas si --isolate-rooms est utilisé.
--permanent-rooms-file [fichier]
Spécifie une liste de salons qui seront toujours répertoriés même si leur liste de lecture est vide. Le chemin pointe vers un fichier texte avec un salon par ligne. Cela nécessitera que les salons persistants soient activés.
--max-chat-message-length [longueurMaxMessageChat]
Nombre maximum de caractères dans un message de chat (par défaut est 150).
--max-username-length [longueurMaxNomUtilisateur]
Nombre maximum de caractères dans un nom d'utilisateur (par défaut est 150).
--stats-db-file [fichier]
Activer les statistiques du serveur en utilisant le fichier de base de données SQLite.
--tls [chemin]
Activer les connexions TLS en utilisant les fichiers de certificat dans le chemin spécifié.
