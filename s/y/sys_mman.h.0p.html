sys_mman.h(0p) Manuel du programmeur POSIX sys_mman.h(0p)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sys/mman.h — déclarations de gestion de la mémoire

SYNOPIS

#include <sys/mman.h>

DESCRIPTION

L'en-tête <sys/mman.h> définit les constantes symboliques suivantes pour une utilisation comme options de protection :

PROT_EXEC
La page peut être exécutée.
PROT_NONE
La page ne peut pas être accédée.
PROT_READ
La page peut être lue.
PROT_WRITE
La page peut être écrite.

L'en-tête <sys/mman.h> définit les constantes symboliques suivantes pour une utilisation comme options de drapeau :

MAP_FIXED
Interpréter addr exactement.
MAP_PRIVATE
Les modifications sont privées.
MAP_SHARED
Partager les modifications.

L'en-tête <sys/mman.h> définit les constantes symboliques suivantes pour la fonction msync() :

MS_ASYNC
Effectuer des écritures asynchrones.
MS_INVALIDATE
Invalider les mappages.
MS_SYNC
Effectuer des écritures synchrones.

L'en-tête <sys/mman.h> définit les constantes symboliques suivantes pour la fonction mlockall() :

MCL_CURRENT
Verrouiller les pages actuellement mappées.
MCL_FUTURE
Verrouiller les pages qui deviennent mappées.

L'en-tête <sys/mman.h> définit la constante symbolique MAP_FAILED qui doit avoir le type void * et être utilisée pour indiquer un échec de la fonction mmap() .

Si l'option Informations Consultatives est prise en charge, l'en-tête <sys/mman.h> définira les constantes symboliques pour l'argument advice de la fonction posix_madvise() comme suit :

POSIX_MADV_DONTNEED

L'application s'attend à ne pas accéder à la plage spécifiée dans un avenir proche.
POSIX_MADV_NORMAL

L'application n'a aucun conseil à donner concernant son comportement vis-à-vis de la plage spécifiée. C'est la caractéristique par défaut si aucun conseil n'est donné pour une plage de mémoire.
POSIX_MADV_RANDOM

L'application s'attend à accéder à la plage spécifiée dans un ordre aléatoire.
POSIX_MADV_SEQUENTIAL

L'application s'attend à accéder à la plage spécifiée séquentiellement des adresses basses vers les adresses hautes.
POSIX_MADV_WILLNEED

L'application s'attend à accéder à la plage spécifiée dans un avenir proche.

L'en-tête <sys/mman.h> définit les constantes symboliques suivantes pour une utilisation comme drapeaux pour la fonction posix_typed_mem_open() :

POSIX_TYPED_MEM_ALLOCATE

Allouer sur mmap().
POSIX_TYPED_MEM_ALLOCATE_CONTIG

Allouer de manière contiguë sur mmap().
POSIX_TYPED_MEM_MAP_ALLOCATABLE

Mapper sur mmap(), sans affecter l'allocabilité.

L'en-tête <sys/mman.h> définit les types mode_t, off_t, et size_t tels que décrits dans <sys_types.h>.

L'en-tête <sys/mman.h> définit la structure posix_typed_mem_info, qui inclura au moins le membre suivant :

size_t  posix_tmi_length  Longueur maximale pouvant être allouée
                          à partir d'un objet mémoire typé.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonctions seront fournis.

int    mlock(const void *, size_t);
int    mlockall(int);
void  *mmap(void *, size_t, int, int, int, off_t);
int    mprotect(void *, size_t, int);
int    msync(void *, size_t, int);
int    munlock(const void *, size_t);
int    munlockall(void);
int    munmap(void *, size_t);
int    posix_madvise(void *, size_t, int);
int    posix_mem_offset(const void *restrict, size_t, off_t *restrict,
           size_t *restrict, int *restrict);
int    posix_typed_mem_get_info(int, struct posix_typed_mem_info *);
int    posix_typed_mem_open(const char *, int, int);
int    shm_open(const char *, int, mode_t);
int    shm_unlink(const char *);
