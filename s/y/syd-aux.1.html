NOM

syd-aux - Afficher les informations du vecteur auxiliaire

SYNTAXE

syd-aux [-hrs]

DESCRIPTION

Affiche les informations du vecteur auxiliaire.

Si -r est donné, affiche le cookie AT_RANDOM encodé en hexadécimal.

Si -s est donné, sort avec succès si AT_SECURE est défini.

OPTIONS

-h Affiche l'aide et quitte.
-r Affiche le cookie AT_RANDOM encodé en hexadécimal.
-s Sort avec succès si AT_SECURE est défini.

VOIR AUSSI
