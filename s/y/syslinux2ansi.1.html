SYSLINUX2ANSI(1) Manuel des commandes générales SYSLINUX2ANSI(1)

NOM

syslinux2ansi - convertit un écran au format syslinux en pc-ansi

SYNTAXE

syslinux2ansi < nom_fichier.input > nom_fichier.output

DESCRIPTION

Syslinux2ansi est un filtre qui convertit un écran formaté pour syslinux en un écran compatible avec PC ANSI. Il ne lit qu'à partir de l'entrée standard et n'a pas d'options en ligne de commande.

BOGUES

Les options de commande pour l'aide et la version seraient utiles.

La possibilité de spécifier les noms de fichiers d'entrée et de sortie en ligne de commande pourrait également être une bonne chose.

Rapports de bogues

J'apprécierais d'être informé de tout problème que vous pourriez rencontrer avec SYSLINUX. J'aimerais également avoir de vos nouvelles si vous avez utilisé SYSLINUX avec succès, surtout si vous l'utilisez pour une distribution.

Si vous signalez des problèmes, veuillez inclure toutes les informations possibles sur votre système et votre BIOS ; la grande majorité de tous les problèmes signalés s'avèrent être des bogues de BIOS ou de matériel, et j'ai besoin d'autant d'informations que possible pour diagnostiquer les problèmes.

Il existe une liste de diffusion pour les discussions entre les utilisateurs de SYSLINUX et pour les annonces de nouvelles versions et de versions de test. Pour vous inscrire, envoyez un message à majordomo@linux.kernel.org avec la ligne :

subscribe syslinux

dans le corps du message. L'adresse de soumission est syslinux@linux.kernel.org.
