NOM

systemd-ssh-issue - Générateur de fichiers drop-in pour l'invite de connexion SSH

SYNTAXE

/usr/lib/systemd/systemd-ssh-issue --make-vsock
/usr/lib/systemd/systemd-ssh-issue --rm-vsock

DESCRIPTION

systemd-ssh-issue est un petit outil qui génère un fichier drop-in /run/issue.d/50-ssh-vsock.issue au cas où le support AF_VSOCK serait disponible dans le noyau et dans l'environnement VM. Le fichier contient de brèves informations sur la manière de contacter le système local via SSH-over-AF_VSOCK, il rapporte en particulier le CID AF_VSOCK du système. Le fichier est généralement lu et affiché par agetty(8) sur les invites de connexion console ou série.

Cet outil est automatiquement utilisé par systemd-ssh-generator(8) dans les unités de sockets AF_VSOCK qu'il génère.

OPTIONS

Les options suivantes sont comprises :

--make-vsock

Génère le fichier issue. Cette commande n'a aucun effet si elle est appelée sur des systèmes dépourvus de support AF_VSOCK.

Ajouté dans la version 258.

--rm-vsock

Supprime le fichier issue s'il existe.

Ajouté dans la version 258.

--issue-path=

Change le chemin du fichier issue à écrire/supprimer. S'il n'est pas spécifié, la valeur par défaut est /run/issue.d/50-ssh-vsock.issue. S'il est spécifié comme une chaîne vide ou "-", le contenu du fichier issue est écrit sur la sortie standard.

Ajouté dans la version 258.

-h, --help

Affiche un court message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.

STATUT DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.
