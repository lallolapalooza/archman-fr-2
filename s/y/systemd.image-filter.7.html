NOM

systemd.image-filter - Filtre de dissection d'images disque

DESCRIPTION

Dans systemd, chaque fois qu'une image disque (DDI) implémentant la Spécification des partitions découvrables est activée, un filtre peut être spécifié pour contrôler quelles partitions doivent être prises en compte pour le montage. Un tel filtre de dissection d'image disque est une chaîne qui contient des motifs par type de partition, séparés par des deux-points (":"). Les règles individuelles consistent en un identifiant de partition, un signe égal ("="), et un motif de shell globbing appliqué à la chaîne de libellé GPT de la partition. Voir glob(7) pour les détails sur le shell globbing.

Les identifiants de partition actuellement définis sont : root, usr, home, srv, esp, xbootldr, swap, root-verity, root-verity-sig, usr-verity, usr-verity-sig, tmp, var. Ces identifiants correspondent aux types de partition pertinents dans la Spécification des partitions découvrables, mais sont indépendants des architectures CPU.

UTILISATION

Divers composants de systemd qui supportent l'opération avec des images disque supportent une option de ligne de commande --image-filter= pour spécifier le filtre d'image à utiliser. Si aucun filtre n'est spécifié, toutes les partitions de la table de partition sont prises en compte et aucun filtrage par libellé n'est appliqué (sauf que les partitions avec le libellé "_empty" sont toujours ignorées).

Pour l'image du système de fichiers racine de l'hôte lui-même, systemd-gpt-auto-generator(8) est responsable du traitement de la table de partitions GPT et de l'utilisation des partitions découvrables incluses. Il accepte un filtre d'image via l'option de ligne de commande du noyau systemd.image_filter=.

EXEMPLES

La chaîne de filtre d'image suivante dicte que pour la partition du système de fichiers racine, seules les partitions dont le libellé commence par "ParticleOS-" doivent être considérées. Pour la partition /usr/, le libellé précis "ParticleOS_47110815" est requis.

root=ParticleOS-*:usr=ParticleOS_47110815
