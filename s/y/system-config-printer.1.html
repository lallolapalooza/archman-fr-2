NAME

system-config-printer - configurer un serveur CUPS

SYNOPSIS

system-config-printer [[--show-jobs imprimante] | [--debug] | [--help]]

DESCRIPTION

system-config-printer configure un serveur CUPS. Il utilise l'API CUPS (liée à Python avec pycups) pour ce faire. La communication avec le serveur est effectuée via IPP. Par conséquent, il est également capable de configurer un serveur CUPS distant comme un serveur local.

OPTIONS

--help

Affiche un court message d'utilisation.

--show-jobs imprimante

Affiche la file d'attente d'impression nommée.

--debug

Active la sortie de débogage.
