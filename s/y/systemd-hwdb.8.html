NOM

systemd-hwdb - outil de gestion de la base de données matérielle

SYNTAXE

systemd-hwdb [options] update

systemd-hwdb [options] query modalias

DESCRIPTION

systemd-hwdb attend une commande et des arguments spécifiques à la commande. Il gère la base de données matérielle binaire.

OPTIONS

--usr

Génère dans /usr/lib/udev au lieu de /etc.

Ajouté dans la version 219.

-r, --root=CHEMIN

Chemin racine alternatif dans le système de fichiers.

Ajouté dans la version 219.

-s, --strict

Lors de la mise à jour, retourne une valeur de sortie non nulle en cas d'erreur d'analyse.

Ajouté dans la version 239.

-h, --help

Affiche un court message d'aide et quitte.

systemd-hwdb [options] update

Met à jour la base de données binaire.

systemd-hwdb [options] query MODALIAS

Interroge la base de données et affiche le résultat.

VOIR AUSSI
