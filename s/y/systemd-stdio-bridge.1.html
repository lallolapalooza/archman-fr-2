NOM

systemd-stdio-bridge - Proxy D-Bus

SYNTAXE

systemd-stdio-bridge [OPTIONS...]

DESCRIPTION

systemd-stdio-bridge implémente un proxy entre STDIN/STDOUT et un bus D-Bus. Il s'attend à recevoir une connexion ouverte via STDIN/STDOUT lorsqu'il est démarré, et créera une nouvelle connexion vers le bus spécifié. Il transférera ensuite les messages entre les deux connexions. Ce programme convient à l'activation par socket : la première connexion peut être un pipe ou un socket et doit être passée soit en entrée standard, soit comme descripteur de fichier ouvert selon le protocole décrit dans sd_listen_fds(3). La seconde connexion sera établie par défaut avec le bus système local, mais cela peut être influencé par les options --user, --system, --machine=, et --bus-path= décrites ci-dessous.

sd-bus(3) utilise systemd-stdio-bridge pour transférer les connexions D-Bus via ssh(1), ou pour se connecter au bus d'un autre utilisateur, voir sd_bus_set_address(3).

OPTIONS

Les options suivantes sont comprises :

--user

Parler au gestionnaire de services de l'utilisateur appelant, plutôt qu'au gestionnaire de services du système.

--system

Parler au gestionnaire de services du système. C'est le choix par défaut implicite.

-M, --machine=

Exécuter l'opération sur un conteneur local. Spécifiez un nom de conteneur pour se connecter, éventuellement préfixé par un nom d'utilisateur pour se connecter et un caractère "@" séparateur. Si la chaîne spéciale ".host" est utilisée à la place du nom du conteneur, une connexion au système local est établie (ce qui est utile pour se connecter au bus d'un utilisateur spécifique : "--user --machine=lennart@.host"). Si la syntaxe "@" n'est pas utilisée, la connexion est établie en tant qu'utilisateur root. Si la syntaxe "@" est utilisée, le côté gauche ou le côté droit peut être omis (mais pas les deux), auquel cas le nom d'utilisateur local et ".host" sont implicites.

-p PATH, --bus-path=PATH

Chemin vers l'adresse du bus. Défaut : "unix:path=/run/dbus/system_bus_socket"

Ajouté dans la version 251.

-h, --help

Afficher un court message d'aide et quitter.

--version

Afficher une courte chaîne de version et quitter.

CODES DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.
