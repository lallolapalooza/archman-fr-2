NOM

syd-mdwe - Exécuter un programme sous les protections Mémoire-Interdiction-Écriture-Exécution

SYNTAXE

syd-mdwe [-hms] {commande [args...]}

DESCRIPTION

L'utilitaire syd-mdwe exécute un programme sous les protections Mémoire-Interdiction-Écriture-Exécution (MDWE). Les protections peuvent être appliquées à l'aide de prctl(2) et seccomp(2). Ces protections sont identiques à celles que Syd applique par défaut.

OPTIONS

-h Afficher l'aide.
-m Activer les protections MDWE à l'aide de prctl(2) PR_SET_MDWE (par défaut : les deux).
-s Activer les protections MDWE à l'aide de seccomp(2) (par défaut : les deux).

STATUT DE SORTIE

En cas de sortie propre, syd-mdwe se termine avec le même code que le processus enfant. En cas de terminaison anormale, le code de sortie est défini sur 128 plus le numéro du signal. En cas d'échec de l'exécution du processus enfant, syd-mdwe se termine avec le numéro d'errno(3).

CAVEATS

Par défaut, l'erreur de prctl(2) lors de la définition de PR_SET_MDWE(2const) n'est pas fatale. Utilisez l'option -m pour rendre cette erreur fatale. Cet utilitaire ne fonctionne pas sur les architectures MIPS où Linux exige une pile exécutable.
