NOM

system-config-printer-applet - gestionnaire de travaux d'impression

SYNTAXE

system-config-printer-applet [--help] [--version] [--debug]

DESCRIPTION

system-config-printer-applet est un gestionnaire d'impression pour CUPS. Normalement, il affiche une icône d'imprimante dans la zone de notification, grisée lorsqu'il n'y a pas de travaux d'impression pour l'utilisateur actuel. Cliquer sur l'icône affiche un gestionnaire de travaux d'impression simple pour annuler ou réimprimer les travaux.

Pour économiser de la mémoire, l'applet attend d'abord que l'utilisateur ait imprimé un travail avant de placer l'icône dans la zone de notification. Pour invoquer le gestionnaire de travaux d'impression avant qu'un travail n'ait été imprimé, exécutez l'applet avec l'option --no-tray-icon : un fichier de bureau est fourni pour cela, de sorte qu'il devrait apparaître dans le menu système.

En plus d'afficher une icône d'imprimante dans la zone de notification, l'applet fournit également un serveur D-BUS pour l'interface com.redhat.PrintDriverSelection, afin d'aider à configurer une nouvelle imprimante lorsqu'elle est branchée.

OPTIONS

--help

Affiche un court message d'utilisation.

--version

Affiche la version de l'applet.

--debug

Affiche les informations de débogage.
