NOM

symlinks - utilitaire de maintenance des liens symboliques

SYNTAXE

symlinks [ -cdorstv ] liste_de_répertoires

DESCRIPTION

symlinks analyse les répertoires à la recherche de liens symboliques et les liste sur la sortie standard, révélant souvent des liens cassés dans l'arborescence du système de fichiers.

Chaque lien est affiché avec une classification relative, absolue, dangling, messy, lengthy, ou other_fs.

Les liens relatifs sont ceux exprimés sous forme de chemins relatifs au répertoire dans lequel résident les liens, généralement indépendamment du point de montage du système de fichiers.

Les liens absolus sont ceux donnés sous forme de chemin absolu à partir du répertoire racine indiqué par une barre oblique initiale (/).

Les liens dangling (pendants) sont ceux dont la cible n'existe pas actuellement. Cela se produit couramment pour les liens absolus lorsque le système de fichiers racine est monté ailleurs que sur son point de montage habituel (par exemple, lorsque le système de fichiers racine normal est monté sur /mnt après le démarrage à partir d'un média alternatif).

Les liens messy (désordonnés) sont des liens qui contiennent des barres obliques ou des points inutiles dans le chemin. Ceux-ci sont également nettoyés lorsque -c est spécifié.

Les liens lengthy (trop longs) sont des liens qui utilisent "../" plus que nécessaire dans le chemin (par exemple, /bin/vi -> ../bin/vim). Ceux-ci ne sont détectés que lorsque -s est spécifié, et ne sont nettoyés que lorsque -c est également spécifié.

Les liens other_fs sont ceux dont la cible se trouve actuellement sur un système de fichiers différent de celui où symlinks a été exécuté (plus utile avec -r ).

OPTIONS

-c
convertit les liens absolus (dans le même système de fichiers) en liens relatifs. Cela permet aux liens de conserver leur validité quel que soit le point de montage utilisé pour le système de fichiers -- une configuration souhaitable dans la plupart des cas. Cette option provoque également le nettoyage de tous les liens messy, et, si -s a également été spécifié, les liens lengthy sont également raccourcis. Les liens affectés par -c sont précédés de changed dans la sortie.
-d
provoque la suppression des liens dangling.
-o
répare les liens sur d'autres systèmes de fichiers rencontrés lors de la récursion. Normalement, les autres systèmes de fichiers rencontrés ne sont pas modifiés par symlinks.
-r
opère récursivement sur les sous-répertoires du même système de fichiers.
-s
détecte les liens lengthy.
-t
est utilisé pour tester ce que symlinks ferait si -c était spécifié, mais sans rien changer réellement.
-v
affiche tous les liens symboliques. Par défaut, les liens relatifs ne sont pas affichés à moins que -v ne soit spécifié.

BOGUES

symlinks ne récurse pas et ne modifie pas les liens sur différents systèmes de fichiers.
