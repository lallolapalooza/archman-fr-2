NOM

systemd-tty-ask-password-agent - Lister ou traiter les requêtes de mot de passe systemd en attente

SYNTAXE

systemd-tty-ask-password-agent [OPTIONS...] [VARIABLE=VALEUR...]

DESCRIPTION

systemd-tty-ask-password-agent est un agent de mot de passe qui gère les requêtes de mot de passe du système, par exemple pour les mots de passe de chiffrement de disque dur ou les mots de passe de certificats SSL qui doivent être interrogés au démarrage ou pendant l'exécution.

systemd-tty-ask-password-agent implémente la Spécification des Agents de Mot de Passe[1], et est l'un des nombreux agents de réponse possibles qui répondent aux requêtes formulées avec systemd-ask-password(1).

OPTIONS

Les options suivantes sont comprises :

--list

Liste toutes les requêtes de mot de passe système actuellement en attente.

Ajouté dans la version 186.

--query

Traite toutes les requêtes de mot de passe système actuellement en attente en interrogeant l'utilisateur sur le TTY appelant.

Ajouté dans la version 186.

--watch

Traite en continu les requêtes de mot de passe.

Ajouté dans la version 186.

--wall

Transmet les requêtes de mot de passe à wall(1) au lieu d'interroger l'utilisateur sur le TTY appelant.

Ajouté dans la version 186.

--plymouth

Pose la question avec plymouth(8) au lieu d'interroger l'utilisateur sur le TTY appelant.

Ajouté dans la version 186.

--console[=PÉRIPHÉRIQUE]

Pose la question sur le TTY PÉRIPHÉRIQUE au lieu d'interroger l'utilisateur sur le TTY appelant. Si PÉRIPHÉRIQUE n'est pas spécifié, /dev/console sera utilisé.

Ajouté dans la version 186.

-h, --help

Affiche un court message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.

CODES DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.

VOIR AUSSI
