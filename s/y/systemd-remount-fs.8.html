NOM

systemd-remount-fs.service, systemd-remount-fs - Remonter les systèmes de fichiers racine et du noyau

SYNTAXE

systemd-remount-fs.service

/usr/lib/systemd/systemd-remount-fs

DESCRIPTION

systemd-remount-fs.service est un service de démarrage précoce qui applique les options de montage listées dans fstab(5), ou collectées à partir de la table de partitions (lorsque systemd-gpt-auto-generator(8) est actif) au système de fichiers racine, au système de fichiers /usr/, et aux systèmes de fichiers API du noyau. Ceci est nécessaire afin que les options de montage de ces systèmes de fichiers — qui sont pré-montés par le noyau, l'initrd, les environnements de conteneur ou le code du gestionnaire système — soient mises à jour avec celles configurées dans /etc/fstab et les autres sources. Ce service ignore les systèmes de fichiers normaux et ne modifie que le système de fichiers racine (c'est-à-dire /), /usr/, et les systèmes de fichiers API virtuels du noyau tels que /proc/, /sys/ ou /dev/. Ce service n'effectue aucune opération si aucune configuration n'est trouvée (/etc/fstab n'existe pas ou ne liste aucune entrée pour les systèmes de fichiers mentionnés, ou la table de partitions ne contient aucune entrée pertinente).

Pour une discussion plus approfondie sur les systèmes de fichiers API du noyau, voir Systèmes de fichiers API[1].

Remarque : systemd-remount-fs.service est généralement appelé par systemd-fstab-generator(8), il est donc également affecté par l'option de ligne de commande du noyau fstab=, qui peut être utilisée pour désactiver le générateur. Il peut également être appelé par systemd-gpt-auto-generator(8), qui est affecté par systemd.gpt_auto et d'autres options.
