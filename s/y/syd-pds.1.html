NOM

syd-pds - Exécute une commande avec le signal de mort du parent défini

SYNTAXE

syd-pds [-h] [-s signal] {commande [args...]}

DESCRIPTION

L'utilitaire syd-pds(1) exécute une commande avec le signal de mort du parent défini. Lorsque le processus parent meurt, le signal spécifié sera délivré à la commande. Le signal par défaut est SIGKILL.

OPTIONS

-h Affiche l'aide.
-s signal Définit le signal de mort du parent au signal spécifié. La valeur par défaut est SIGKILL.

CODE DE RETOUR

syd-pds se termine avec le même code que le processus enfant.
