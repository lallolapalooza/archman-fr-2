sous-routine csyconvf (character uplo, character way, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, integer info)

CSYCONVF

Objectif :

!> Si le paramètre WAY = 'C' :
!> CSYCONVF convertit le format de sortie de la factorisation utilisé dans
!> CSYTRF, fourni en entrée dans le paramètre A, au format de sortie de la factorisation
!> utilisé dans CSYTRF_RK (ou CSYTRF_BK), qui est stocké en sortie dans les paramètres A et E.
!> Il convertit également sur place les détails des échanges stockés dans IPIV
!> du format utilisé dans CSYTRF au format utilisé dans CSYTRF_RK (ou CSYTRF_BK).
!>
!> Si le paramètre WAY = 'R' :
!> CSYCONVF effectue la conversion dans la direction inverse, c'est-à-dire
!> convertit le format de sortie de la factorisation utilisé dans CSYTRF_RK
!> (ou CSYTRF_BK), fourni en entrée dans les paramètres A et E, au format de sortie de la factorisation
!> utilisé dans CSYTRF, qui est stocké en sortie dans le paramètre A.
!> Il convertit également sur place les détails des échanges stockés dans IPIV
!> du format utilisé dans CSYTRF_RK (ou CSYTRF_BK) au format utilisé dans CSYTRF.
!>
!> CSYCONVF peut également convertir dans le cas de matrices hermitiennes, c'est-à-dire
!> entre les formats utilisés dans CHETRF et CHETRF_RK (ou CHETRF_BK).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont
!>          stockés sous forme de matrice triangulaire supérieure ou inférieure A.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

WAY

!>          WAY est CHARACTER*1
!>          = 'C' : Convertir
!>          = 'R' : Rétablir (Revert)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA,N)
!>
!>          1) Si WAY = 'C' :
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF :
!>            a) tous les éléments de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A et sur la surdiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U' : multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sous-diagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF_RK ou CSYTRF_BK :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : facteur L dans la partie sous-diagonale de A.
!>
!>          2) Si WAY = 'R' :
!>
!>          En entrée, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF_RK ou CSYTRF_BK :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments surdiagonaux (ou sous-diagonaux) de D
!>                sont stockés en sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : facteur U dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : facteur L dans la partie sous-diagonale de A.
!>
!>          En sortie, contient les détails de la factorisation dans le format utilisé dans
!>          CSYTRF :
!>            a) tous les éléments de la matrice diagonale par blocs symétrique
!>               D sur la diagonale de A et sur la surdiagonale
!>               (ou sous-diagonale) de A, et
!>            b) Si UPLO = 'U' : multiplicateurs utilisés pour obtenir le facteur U
!>               dans la partie surdiagonale de A.
!>               Si UPLO = 'L' : multiplicateurs utilisés pour obtenir le facteur L
!>               dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX de dimension (N)
!>
!>          1) Si WAY = 'C' :
!>
!>          En entrée, juste un espace de travail.
!>
!>          En sortie, contient les éléments surdiagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          2) Si WAY = 'R' :
!>
!>          En entrée, contient les éléments surdiagonaux (ou sous-diagonaux)
!>          de la matrice diagonale par blocs symétrique D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i),i=2:N, E(1) non référencé ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i),i=1:N-1, E(N) non référencé.
!>
!>          En sortie, n'est pas modifié.
!>

IPIV

!>          IPIV est un tableau INTEGER de dimension (N)
!>
!>          1) Si WAY = 'C' :
!>          En entrée, détails des échanges et de la structure par blocs de D dans le format utilisé dans CSYTRF.
!>          En sortie, détails des échanges et de la structure par blocs de D dans le format utilisé dans CSYTRF_RK
!>          (ou CSYTRF_BK).
!>
!>          1) Si WAY = 'R' :
!>          En entrée, détails des échanges et de la structure par blocs de D dans le format utilisé dans CSYTRF_RK
!>          (ou CSYTRF_BK).
!>          En sortie, détails des échanges et de la structure par blocs de D dans le format utilisé dans CSYTRF.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : Sortie réussie
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>

subroutine checonvf (character uplo, character way, integer n, complex*16, dimension( lda, * ) a, integer lda, real, dimension( * ) e, integer, dimension( * ) ipiv, integer info)

CHECONVF

Purpose:

!> If parameter WAY = 'C':
!> CHECONVF converts the factorization output format used in
!> CHETRF provided on entry in parameter A into the factorization
!> output format used in CHETRF_RK (or CHETRF_BK) that is stored
!> on exit in parameters A and E. It also converts in place details of
!> the interchanges stored in IPIV from the format used in CHETRF into
!> the format used in CHETRF_RK (or CHETRF_BK).
!>
!> If parameter WAY = 'R':
!> CHECONVF performs the conversion in reverse direction, i.e.
!> converts the factorization output format used in CHETRF_RK
!> (or CHETRF_BK) provided on entry in parameters A and E into
!> the factorization output format used in CHETRF that is stored
!> on exit in parameter A. It also converts in place details of
!> the interchanges stored in IPIV from the format used in CHETRF_RK
!> (or CHETRF_BK) into the format used in CHETRF.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the details of the factorization are

!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

WAY

!>          WAY is CHARACTER*1
!>          = 'C': Convert
!>          = 'R': Revert
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>
!>          1) If WAY ='C':
!>
!>          On entry, contains factorization details in format used in
!>          CHETRF:

!>               matrix D on the diagonal of A and on superdiagonal
!>               (or subdiagonal) of A, and

!>               in the superdiagonal part of A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

E

!>          E is REAL array, dimension (N)
!>
!>          1) If WAY ='C':
!>

DSYCONVF

Purpose:

!> If parameter WAY = 'C':
!> DSYCONVF converts the factorization output format used in
!> DSYTRF provided on entry in parameter A into the factorization
!> output format used in DSYTRF_RK (or DSYTRF_BK) that is stored

!> (or DSYTRF_BK) into the format used in DSYTRF.
