NOM

systemd-hibernate-resume-generator - Générateur d'unité pour le paramètre du noyau resume=

SYNTAXE

/usr/lib/systemd/system-generators/systemd-hibernate-resume-generator

DESCRIPTION

systemd-hibernate-resume-generator est un générateur qui initie la procédure de reprise du système depuis l'hibernation. Lorsque l'option de ligne de commande du noyau resume= ou la variable EFI HibernateLocation est détectée, il active l'unité systemd-hibernate-resume.service(8), qui demandera au noyau de reprendre le système à partir de l'image d'hibernation.

LIGNE DE COMMANDE DU NOYAU

systemd-hibernate-resume-generator comprend les paramètres de ligne de commande du noyau suivants :

resume=

Prend un chemin vers le périphérique de reprise. Les chemins de périphérique bloc persistants comme /dev/disk/by-foo/bar et les spécificateurs de style fstab(5) comme "FOO=bar" sont pris en charge.

Ajouté dans la version 217.

resume_offset=

Prend le décalage de page de l'espace d'échange du périphérique de reprise. La valeur par défaut est "0".

Ajouté dans la version 254.

resumeflags=

Prend les options de montage du périphérique de reprise à utiliser. Les valeurs par défaut sont rootflags= si elles ne sont pas spécifiées.

Ajouté dans la version 243.

noresume

N'essaie pas de reprendre depuis l'hibernation. Si ce paramètre est présent, resume= est ignoré.

Ajouté dans la version 240.

VOIR AUSSI
