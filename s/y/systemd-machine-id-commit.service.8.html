NOM

systemd-machine-id-commit.service - Valider un ID de machine transitoire sur disque

SYNTAXE

systemd-machine-id-commit.service

DESCRIPTION

systemd-machine-id-commit.service est un service de démarrage précoce responsable de la validation des fichiers temporaires /etc/machine-id sur un système de fichiers de disque inscriptible. Voir machine-id(5) pour plus d'informations sur les ID de machine.

Ce service est démarré après local-fs.target au cas où /etc/machine-id serait son propre point de montage (généralement à partir d'un système de fichiers en mémoire tel que « tmpfs ») et que /etc est inscriptible. Le service invoquera systemd-machine-id-setup --commit, qui écrit l'ID de machine transitoire actuel sur disque et démonte le fichier /etc/machine-id d'une manière sans concurrence pour garantir que le fichier est toujours valide et accessible par d'autres processus. Voir systemd-machine-id-setup(1) pour plus de détails.

Le cas d'utilisation principal de ce service concerne les systèmes où /etc/machine-id est en lecture seule et initialement non initialisé. Dans ce cas, le gestionnaire de système générera un fichier d'ID de machine transitoire sur un système de fichiers en mémoire, et le montera sur /etc/machine-id, pendant la phase de démarrage précoce. Ce service est ensuite invoqué à une phase de démarrage ultérieure, dès que /etc/ a été remonté en mode inscriptible et que l'ID peut ainsi être validé sur disque pour le rendre permanent.

VOIR AUSSI

systemd(1), systemd-machine-id-setup(1), machine-id(5), systemd-firstboot(1)
