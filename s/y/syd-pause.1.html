SYD-PAUSE(1) Manuel des commandes générales SYD-PAUSE(1)

NOM

syd-pause - Bloque indéfiniment (jusqu'à réception d'un signal), en ignorant éventuellement certains signaux

SYNTAXE

syd-pause [ -t ] [ -h ] [ -a ] [ -q ] [ -b ] [ -i ] [ -p signaux ]

DESCRIPTION

syd-pause est un processus minuscule, de longue durée, qui attend simplement d'être terminé par un signal. Par défaut, il respecte tous les signaux de terminaison standards ; les options permettent d'ignorer des signaux spécifiques afin que le processus continue de s'exécuter lorsqu'ils sont délivrés. Ceci est utile comme espace réservé minimal, cible de supervision, ou comme sentinelle de synchronisation dans des pipelines de services et des bacs à sable.

OPTIONS

--help Affiche l'aide.
-t Ignore SIGTERM.
-h Ignore SIGHUP.
-a Ignore SIGALRM.
-q Ignore SIGQUIT.
-b Ignore SIGABRT.
-i Ignore SIGINT.
-p signaux Ignore la liste des numéros de signaux séparés par des virgules donnée dans signaux (par ex. -p 1,2,3,15).
Les numéros doivent être valides selon signal(7). Ce drapeau peut être combiné avec les drapeaux courts ci-dessus.

STATUT DE SORTIE

Lors d'une terminaison normale par un signal, syd-pause se termine avec le code 0. En cas d'erreurs, syd-pause se termine avec la valeur errno(3) correspondante.
