SYNC(3P) Manuel du programmeur POSIX SYNC(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sync — planifie les mises à jour du système de fichiers

SYNOPIS

#include <unistd.h>
void sync(void);

DESCRIPTION

La fonction sync() planifie l'écriture de toutes les informations en mémoire qui mettent à jour les systèmes de fichiers vers tous les systèmes de fichiers.

L'écriture, bien que planifiée, n'est pas nécessairement terminée au retour de sync().

VALEUR DE RETOUR

La fonction sync() ne retourne aucune valeur.

ERREURS

Aucune erreur n'est définie.
