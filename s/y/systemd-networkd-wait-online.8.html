NOM

systemd-networkd-wait-online.service, systemd-networkd-wait-online@.service, systemd-networkd-wait-online - Attendre la mise en ligne du réseau

SYNTAXE

systemd-networkd-wait-online.service

systemd-networkd-wait-online@.service

/usr/lib/systemd/systemd-networkd-wait-online

DESCRIPTION

systemd-networkd-wait-online est un service système oneshot (voir systemd.service(5)) qui attend la configuration du réseau. Par défaut, il attend que toutes les interfaces qu'il connaît et qui sont gérées par systemd-networkd.service(8) soient complètement configurées ou en échec, et qu'au moins une interface soit en ligne. Ici, en ligne signifie que l'état opérationnel de l'interface est égal ou supérieur à "dégradé". Le seuil peut être configuré par l'option --operational-state=.

Le service systemd-networkd-wait-online.service appelle systemd-networkd-wait-online sans aucune option. Ainsi, il attend que toutes les interfaces gérées soient configurées ou en échec, et qu'au moins une soit en ligne.

Le service systemd-networkd-wait-online@.service prend un nom d'interface et appelle systemd-networkd-wait-online avec -i et le nom de l'interface spécifié. Ainsi, il attend que l'interface spécifiée soit configurée et en ligne. Par exemple, systemd-networkd-wait-online@eth0.service attend que eth0 soit configuré par systemd-networkd et soit en ligne.

OPTIONS

Les options suivantes sont comprises :

-i INTERFACE[:MIN_OPERSTATE[:MAX_OPERSTATE]], --interface=INTERFACE[:MIN_OPERSTATE[:MAX_OPERSTATE]]

Interface réseau à attendre avant de décider si le système est en ligne. Ceci est utile lorsqu'un système possède plusieurs interfaces qui seront configurées, mais qu'une en particulier est nécessaire pour accéder à certaines ressources réseau. Lorsque utilisé, toutes les autres interfaces sont ignorées. Cette option peut être utilisée plusieurs fois pour attendre plusieurs interfaces réseau. Lorsque cette option est spécifiée plusieurs fois, alors systemd-networkd-wait-online attend que toutes les interfaces spécifiées soient en ligne. Optionnellement, les états opérationnels minimum et maximum requis peuvent être spécifiés après deux-points ":". Voir networkctl(1) pour les états opérationnels possibles. Si l'état opérationnel n'est pas spécifié ici, alors la valeur de RequiredForOnline= dans le fichier .network correspondant est utilisée s'il est présent, et "dégradé" sinon.

Ajouté dans la version 213.

--ignore=INTERFACE

Interfaces réseau à ignorer lors de la décision si le système est en ligne. Par défaut, seule l'interface de bouclage est ignorée. Cette option peut être utilisée plusieurs fois pour ignorer plusieurs interfaces réseau.

Ajouté dans la version 219.

-o MIN_OPERSTATE[:MAX_OPERSTATE], --operational-state=MIN_OPERSTATE[:MAX_OPERSTATE]

Prend un état opérationnel minimum et un état opérationnel maximum optionnel. Voir networkctl(1) pour les états opérationnels possibles. S'il est défini, la valeur spécifiée remplace les paramètres RequiredForOnline= dans les fichiers .network. Mais cela ne remplace pas les états opérationnels spécifiés dans l'option --interface=.

Ajouté dans la version 242.

-4, --ipv4

Attend qu'une adresse IPv4 de chaque interface réseau soit configurée. Si cette option est spécifiée avec --any, alors systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne et possède une adresse IPv4. Si l'état opérationnel minimum requis est inférieur à "routable", alors chaque lien (ou au moins un lien avec --any) doit avoir une adresse IPv4 link-local ou routable. Si l'état opérationnel minimum requis est "routable", alors chaque lien doit avoir une adresse IPv4 routable.

Si ni --ipv4 ni --ipv6 n'est spécifié, alors la valeur de RequiredFamilyForOnline= dans le fichier .network correspondant est utilisée si elle est présente.

Ajouté dans la version 249.

-6, --ipv6

Attend qu'une adresse IPv6 de chaque interface réseau soit configurée. Si cette option est spécifiée avec --any, alors systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne et possède une adresse IPv6. Si l'état opérationnel minimum requis est inférieur à "routable", alors chaque lien (ou au moins un lien avec --any) doit avoir une adresse IPv6 link-local ou routable. Si l'état opérationnel minimum requis est "routable", alors chaque lien doit avoir une adresse IPv6 routable.

Si ni --ipv4 ni --ipv6 n'est spécifié, alors la valeur de RequiredFamilyForOnline= dans le fichier .network correspondant est utilisée si elle est présente.

Ajouté dans la version 249.

--dns

Attend que les serveurs DNS soient accessibles sur chaque interface. Si cette option est spécifiée avec --any, alors systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne et possède un serveur DNS accessible.

Si un lien a la propriété DefaultRoute=yes (soit parce que la propriété réseau DNSDefaultRoute= est explicitement configurée, soit parce que le lien n'a aucun domaine "de routage uniquement"), ou si le domaine de recherche "." est configuré, alors attendre que les serveurs DNS spécifiques au lien soient accessibles. Sinon, permettre aux serveurs DNS globaux de satisfaire la condition.

Ajouté dans la version 258.

--any

Même si plusieurs interfaces sont en état de configuration, systemd-networkd-wait-online se termine avec succès lorsqu'au moins une interface devient en ligne. Lorsque cette option est spécifiée avec --interface=, alors systemd-networkd-wait-online attend qu'une des interfaces spécifiées soit en ligne. Cette option est utile lorsque certaines interfaces peuvent ne pas avoir de port physique actif au démarrage.

Ajouté dans la version 242.

--timeout=SECS

Échouer le service si le réseau n'est pas en ligne avant que le délai d'expiration ne soit écoulé. Un délai de 0 désactive le délai d'expiration. Par défaut, 120 secondes.

Ajouté dans la version 219.

-q, --quiet

Supprimer les messages de journalisation.

Ajouté dans la version 242.

-h, --help

Afficher un court texte d'aide et quitter.

--version

Afficher une courte chaîne de version et quitter.

DESCRIPTION

systemd-networkd-wait-online est un utilitaire qui attend jusqu'à ce que l'une ou plusieurs des interfaces réseau configurées par systemd-networkd(8) soient en ligne. Il est conçu pour être utilisé dans les scripts d'initialisation des systèmes afin de s'assurer que le réseau est disponible avant de continuer.

OPTIONS

-i, --interface=
Spécifie les interfaces réseau à attendre. Par défaut, toutes les interfaces configurées par systemd-networkd sont attendues.
-t, --timeout=
Spécifie le délai d'attente maximal en secondes. Si le délai est dépassé, l'utilitaire se terminera avec un code de sortie non nul.
-q, --quiet
Supprime la sortie de l'utilitaire.

CODE DE SORTIE

0 en cas de succès (toutes les interfaces réseau attendues sont en ligne).

Non nul en cas d'échec (délai d'attente dépassé ou erreur).

EXEMPLES

Attendre que toutes les interfaces réseau soient en ligne avec un délai de 30 secondes :

systemd-networkd-wait-online -t 30

Attendre que l'interface eth0 soit en ligne :

systemd-networkd-wait-online -i eth0
