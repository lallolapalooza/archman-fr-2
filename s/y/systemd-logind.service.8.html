NOM

systemd-logind.service, systemd-logind - Gestionnaire de connexion

SYNTAXE

systemd-logind.service

/usr/lib/systemd/systemd-logind

DESCRIPTION

systemd-logind est un service système qui gère les connexions des utilisateurs. Il est responsable de :

•Garder une trace des utilisateurs et des sessions, de leurs processus et de leur état d'inactivité. Ceci est implémenté en allouant une unité de slice systemd pour chaque utilisateur sous user.slice, et une unité de scope en dessous pour chaque session concurrente d'un utilisateur. De plus, un gestionnaire de services par utilisateur est démarré en tant qu'instance de service système de user@.service pour chaque utilisateur connecté.
•Générer et gérer les identifiants de session. Si l'audit est disponible et qu'un identifiant de session d'audit est déjà défini pour une session, alors cet identifiant est réutilisé comme identifiant de session. Sinon, un compteur de session indépendant est utilisé.
•Fournir un accès basé sur polkit[1] pour les utilisateurs pour des opérations telles que l'arrêt du système ou la mise en veille.
•Implémenter une logique d'inhibition de l'arrêt/veille pour les applications.
•Gérer les touches matérielles d'alimentation/veille.
•Gestion multi-siège.
•Gestion du changement de session.
•Gestion de l'accès aux périphériques pour les utilisateurs.
•Lancement automatique des connexions texte (getty) lors de l'activation de la console virtuelle et gestion du répertoire d'exécution des utilisateurs.
•Arrêt programmé.
•Envoi des messages "wall".

Les sessions utilisateur sont enregistrées auprès de logind via le module PAM pam_systemd(8).

Voir logind.conf(5) pour des informations sur la configuration de ce service.

Voir sd-login(3) pour des informations sur les concepts de base de logind tels que les utilisateurs, les sessions et les sièges.

Voir org.freedesktop.login1(5) et org.freedesktop.LogControl1(5) pour des informations sur les API D-Bus fournies par systemd-logind.

Pour plus d'informations, voir Verrous d'inhibition[2].

Si vous souhaitez écrire un gestionnaire d'affichage qui utilise logind, veuillez consulter Écrire des gestionnaires d'affichage[3]. Si vous souhaitez écrire un environnement de bureau qui utilise logind, veuillez consulter Écrire des environnements de bureau[4].
