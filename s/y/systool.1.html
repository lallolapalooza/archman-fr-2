NOM

systool - afficher les informations des périphériques système par bus, classe et topologie

SYNTAXE

systool [options [périphérique]]

DESCRIPTION

Appeler systool sans paramètres présentera tous les types de bus, classes de périphériques et périphériques racine disponibles.

Lorsque périphérique est fourni, les informations demandées par options ne sont affichées que pour le périphérique spécifié, sinon tous les périphériques présents sont affichés.

systool utilise les API fournies par libsysfs pour collecter les informations. systool ne fonctionne que sur les systèmes Linux exécutant des noyaux 2.5 ou plus récents, avec le système de fichiers sysfs monté.

OPTIONS

-a
Afficher les attributs de la ressource demandée.
-b bus
Afficher les informations pour un bus spécifique.
-c classe
Afficher les informations pour une classe spécifique.
-d
Afficher uniquement les périphériques.
-h
Afficher l'aide.
-m nom_module
Afficher les informations pour un module spécifique.
-p
Afficher le chemin sysfs absolu vers la ressource.
-v
Afficher tous les attributs avec leurs valeurs.
-A attribut
Afficher la valeur de l'attribut pour la ressource demandée.
-D
Afficher uniquement les pilotes.
-P
Afficher le parent du périphérique.

VOIR AUSSI

La page web de libsysfs à http://linux-diag.sourceforge.net/Sysfsutils.html.
