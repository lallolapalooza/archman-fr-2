NOM

systemd-cgls - Afficher récursivement le contenu des groupes de contrôle

SYNTAXE

systemd-cgls [OPTIONS...] [CGROUP...]

systemd-cgls [OPTIONS...] --unit|--user-unit [UNIT...]

DESCRIPTION

systemd-cgls affiche récursivement le contenu de la hiérarchie sélectionnée des groupes de contrôle Linux sous forme d'arbre. Si des arguments sont spécifiés, il affiche tous les processus membres des groupes de contrôle spécifiés ainsi que tous leurs sous-groupes et leurs membres. Les groupes de contrôle peuvent être spécifiés par leurs chemins de fichiers complets ou sont supposés être dans la hiérarchie des groupes de contrôle systemd. Si aucun argument n'est spécifié et que le répertoire de travail actuel se trouve sous le point de montage du groupe de contrôle /sys/fs/cgroup/, il affiche le contenu du groupe de contrôle auquel le répertoire de travail fait référence. Sinon, la hiérarchie complète des groupes de contrôle systemd est affichée.

Par défaut, les groupes de contrôle vides ne sont pas affichés.

OPTIONS

Les options suivantes sont comprises :

--all

Ne pas masquer les groupes de contrôle vides dans la sortie.

-l, --full

Ne pas tronquer les membres de l'arbre des processus.

Ajouté dans la version 198.

-u, --unit

Afficher les sous-arbres de cgroup pour les unités spécifiées.

Ajouté dans la version 233.

--user-unit

Afficher les sous-arbres de cgroup pour les unités utilisateur spécifiées.

Ajouté dans la version 233.

-k

Inclure les threads du noyau dans la sortie.

-M MACHINE, --machine=MACHINE

Limiter les groupes de contrôle affichés à la partie correspondant au conteneur MACHINE.

Ajouté dans la version 203.

-x, --xattr=

Contrôle si les informations sur les attributs étendus des groupes de contrôle listés doivent être incluses dans la sortie. Avec l'option longue, attend une valeur booléenne. Par défaut : non.

Ajouté dans la version 250.

-c, --cgroup-id=

Contrôle si l'ID numérique des groupes de contrôle listés doit être inclus dans la sortie. Avec l'option longue, attend une valeur booléenne. Par défaut : non.

Ajouté dans la version 250.

-h, --help

Afficher un court message d'aide et quitter.

--version

Afficher une courte chaîne de version et quitter.

--no-pager

Ne pas utiliser de pagineur pour la sortie.

CODES DE SORTIE

En cas de succès, 0 est retourné, sinon un code d'échec non nul.
