NOM

systemd-bsod.service, systemd-bsod - Affiche les messages d'erreur d'amorçage en plein écran

SYNOPSIS

systemd-bsod.service

/usr/lib/systemd/systemd-bsod [OPTIONS...]

DESCRIPTION

systemd-bsod.service est utilisé pour afficher un écran bleu contenant un message relatif à une défaillance d'amorçage, y compris un code QR qui peut être scanné pour obtenir des informations utiles sur la défaillance.

OPTIONS

Les options suivantes sont comprises par systemd-bsod :

-h, --help

Affiche un court message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.

-c, --continuous

Lorsqu'elle est spécifiée, systemd-bsod attend en continu les changements dans le journal si elle ne trouve aucun message d'urgence lors de la tentative initiale.

Ajouté dans la version 255.

--tty=

Spécifie le TTY de sortie. Par défaut, systemd-bsod trouvera automatiquement un VT libre pour afficher le message. Si cette option est spécifiée, un TTY peut être sélectionné explicitement. Utilisez --tty=/dev/tty pour diriger la sortie vers le terminal sur lequel la commande est invoquée.

Ajouté dans la version 256.

CODES DE RETOUR

En cas de succès (affichage réussi du message du journal), 0 est retourné, un code d'échec non nul sinon.
