NOM

systemd-modules-load.service, systemd-modules-load - Charger les modules du noyau au démarrage

SYNTAXE

systemd-modules-load.service

/usr/lib/systemd/systemd-modules-load

DESCRIPTION

systemd-modules-load.service est un service de démarrage précoce qui charge les modules du noyau. Il lit la configuration statique des fichiers dans /usr/ et /etc/, mais aussi la configuration d'exécution depuis /run/ et la ligne de commande du noyau (voir ci-dessous).

Voir modules-load.d(5) pour des informations sur le format de configuration de ce service et les chemins où les fichiers de configuration peuvent être créés.

LIGNE DE COMMANDE DU NOYAU

systemd-modules-load.service comprend les paramètres suivants de la ligne de commande du noyau :

modules_load=, rd.modules_load=

Prend une liste de modules du noyau séparés par des virgules à charger statiquement lors du démarrage précoce. L'option préfixée par "rd." est lue uniquement dans l'initrd.

Ajouté dans la version 187.
