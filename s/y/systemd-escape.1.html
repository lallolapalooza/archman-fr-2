NOM

systemd-escape - Échapper des chaînes pour les utiliser dans les noms d'unités systemd

SYNTAXE

systemd-escape [OPTIONS...] [CHAÎNE...]

DESCRIPTION

systemd-escape peut être utilisé pour échapper des chaînes de caractères afin de les inclure dans les noms d'unités systemd. La commande peut être utilisée pour échapper et déséchapper des chaînes.

La commande prend un nombre quelconque de chaînes sur la ligne de commande, et les traitera individuellement, une par une. Elle les affichera séparées par des espaces sur la sortie standard.

Par défaut, cette commande échappera les chaînes passées, sauf si --unescape est passé, ce qui entraînera l'opération inverse. Si --mangle est donné, un mode d'échappement spécial est appliqué à la place, qui suppose que la chaîne est déjà échappée mais échappera tout ce qui apparaît manifestement non échappé.

Pour plus de détails sur les algorithmes d'échappement et de déséchappement, consultez la section pertinente de systemd.unit(5).

OPTIONS

Les options suivantes sont comprises :

--suffix=

Ajoute le suffixe de type d'unité spécifié à la chaîne échappée. Prend l'un des types d'unités pris en charge par systemd, tel que "service" ou "mount". Ne peut pas être utilisé en conjonction avec --template=, --unescape ou --mangle.

Ajouté dans la version 216.

--template=

Insère les chaînes échappées dans un modèle de nom d'unité. Prend un modèle de nom d'unité tel que foobar@.service. Avec --unescape, attend des noms d'unités instanciés pour ce modèle et extrait et déséchappe uniquement la partie instance. Ne peut pas être utilisé en conjonction avec --suffix=, --instance ou --mangle.

Ajouté dans la version 216.

--path, -p

Lors de l'échappement ou du déséchappement d'une chaîne, suppose qu'elle fait référence à un chemin de système de fichiers. Cela simplifie le chemin (les caractères "/" initiaux, finaux et dupliqués sont supprimés, les composants de chemin "." qui ne font rien sont supprimés, et pour les chemins absolus, les composants ".." initiaux sont supprimés). Après la simplification, le chemin ne doit pas contenir "..".

Ceci est particulièrement utile pour générer des chaînes appropriées pour être déséchappées avec le spécificateur "%f" dans les fichiers d'unité, voir systemd.unit(5).

Ajouté dans la version 216.

--unescape, -u

Au lieu d'échapper les chaînes spécifiées, annule l'échappement, inversant l'opération. Ne peut pas être utilisé en conjonction avec --suffix= ou --mangle.

Ajouté dans la version 216.

--mangle, -m

Comme --escape, mais n'échappe que les caractères qui ne sont manifestement pas encore échappés, et ajoute éventuellement automatiquement un suffixe de type d'unité approprié à la chaîne. Ne peut pas être utilisé en conjonction avec --suffix=, --template= ou --unescape.

Ajouté dans la version 216.

--instance

Avec --unescape, déséchappe et affiche uniquement la partie instance d'un nom d'unité modèle instancié. Provoque une erreur pour un modèle non instancié comme ssh@.service ou un nom non modèle comme ssh.service. Doit être utilisé en conjonction avec --unescape et ne peut pas être utilisé en conjonction avec --template.

Ajouté dans la version 240.

-h, --help

Affiche un bref message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.

EXEMPLES

Pour échapper une seule chaîne :

$ systemd-escape 'Hallöchen, Meister'
Hall\xc3\xb6chen\x2c\x20Meister

Pour annuler l'échappement d'une seule chaîne :

$ systemd-escape -u 'Hall\xc3\xb6chen\x2c\x20Meister'
Hallöchen, Meister

Pour générer l'unité de montage pour un chemin :

$ systemd-escape -p --suffix=mount "/tmp//waldi/foobar/"
tmp-waldi-foobar.mount

Pour générer les noms d'instance de trois chaînes :

$ systemd-escape --template=systemd-nspawn@.service 'My Container 1' 'containerb' 'container/III'
systemd-nspawn@My\x20Container\x201.service systemd-nspawn@containerb.service systemd-nspawn@container-III.service

Pour extraire la partie instance d'une unité instanciée :

$ systemd-escape -u --instance 'systemd-nspawn@My\x20Container\x201.service'
My Container 1

Pour extraire la partie instance d'une instance d'un modèle particulier :

$ systemd-escape -u --template=systemd-nspawn@.service 'systemd-nspawn@My\x20Container\x201.service'
My Container 1

CODE DE RET

En cas de succès, 0 est retourné, un code d'erreur non nul sinon.
