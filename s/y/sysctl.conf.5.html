SYSCTL.CONF(5) Manuel des formats de fichiers SYSCTL.CONF(5)

NOM

sysctl.conf - paramètres de configuration du noyau Linux

DESCRIPTION

sysctl.conf est un ensemble de fichiers de configuration qui contiennent les paramètres de configuration du noyau Linux à lire et à définir par sysctl(8).

Cette page de manuel décrit les fichiers de configuration pour sysctl(8) de procps. Si vous utilisez systemd-sysctl(8), référez-vous à sysctl.d(5) et notez qu'il n'utilisera pas le fichier /etc/sysctl.conf.

Format de configuration

Chaque ligne d'un fichier lu par sysctl de procps décrit un paramètre du noyau dans le format suivant.

token = valeur

Les lignes vides et les lignes commençant par “#” ou “;” sont ignorées.

Si une ligne commence par un seul “-”, une tentative échouée de définir la valeur est ignorée.

FICHIERS

sysctl de procps, lorsqu'il est exécuté avec l'option --system, lit les fichiers des répertoires dans l'ordre indiqué ci-dessous.

/etc/sysctl.d/*.conf
/run/sysctl.d/*.conf
/usr/local/lib/sysctl.d/*.conf
/usr/lib/sysctl.d/*.conf
/lib/sysctl.d/*.conf

Enfin, sysctl de procps lit /etc/sysctl.conf. Ce fichier n'est pas utilisé par systemd-sysctl, ce qui signifie que certains paramètres du noyau ne sont pas définis en fonction de l'implémentation de sysctl installée.

BOGUES

La longueur maximale prise en charge de valeur est de 4096 caractères en raison d'une limitation sur la longueur des entrées /proc dans le noyau Linux.

EXEMPLES

#
#
kernel.domainname = example.com
; Une valeur contenant un espace est écrite dans le sysctl.
kernel.modprobe = /sbin/mod probe

VOIR AUSSI

sysctl.d(5), sysctl(8), systemd-sysctl(8)
