NOM

systemd-ask-password-console.service, systemd-ask-password-console.path, systemd-ask-password-wall.service, systemd-ask-password-wall.path - Interroger l'utilisateur pour les mots de passe système sur la console et via wall

SYNTAXE

systemd-ask-password-console.service
systemd-ask-password-console.path
systemd-ask-password-wall.service
systemd-ask-password-wall.path

DESCRIPTION

systemd-ask-password-console.service est un service système qui interroge l'utilisateur pour obtenir les mots de passe système (tels que les clés de chiffrement de disque dur et les phrases de passe de certificats SSL) sur la console. Il est destiné à être utilisé pendant le démarrage pour assurer une gestion appropriée des mots de passe nécessaires au démarrage. systemd-ask-password-wall.service est un service système qui informe tous les utilisateurs connectés pour les mots de passe système via wall(1). Il est destiné à être utilisé après le démarrage pour s'assurer que les utilisateurs sont correctement notifiés.

Voir la documentation pour les développeurs[1] pour plus d'informations sur la logique des mots de passe système.

Notez que ces services invoquent systemd-tty-ask-password-agent(1) avec les paramètres de ligne de commande --watch --console ou --watch --wall.
