SYSTEMD-TPM2-GENERATOR(8) systemd-tpm2-generator SYSTEMD-TPM2-GENERATOR(8)

NOM

systemd-tpm2-generator - Générateur pour insérer un point de synchronisation TPM2 dans le processus de démarrage

SYNTAXE

/usr/lib/systemd/system-generators/systemd-tpm2-generator

DESCRIPTION

systemd-tpm2-generator est un générateur qui ajoute une dépendance Wants= de sysinit.target à tpm2.target lorsqu'il détecte que le firmware a découvert un périphérique TPM2 mais que le noyau du système d'exploitation ne l'a pas encore fait. tpm2.target est censé servir de point de synchronisation pour tous les services qui nécessitent un accès au périphérique TPM2. Voir systemd.special(7) pour plus de détails.

L'option de ligne de commande du noyau systemd.tpm2_wait= peut être utilisée pour outrepasser le comportement du générateur. Elle accepte une valeur booléenne : si elle est vraie, tpm2.target sera ajouté comme point de synchronisation même si le firmware n'a pas détecté de périphérique TPM2. Si elle est fausse, le target ne sera pas inséré même si le firmware a signalé un périphérique mais que le noyau du système d'exploitation n'en expose pas encore. Ce dernier peut être utile dans des environnements où un pilote TPM2 approprié pour le matériel disponible n'est pas disponible.

systemd-tpm2-generator implémente systemd.generator(7).
