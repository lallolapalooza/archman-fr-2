sysvipc(7) Manuel d'informations diverses sysvipc(7)

NOM

sysvipc - Mécanismes de communication interprocessus System V

DESCRIPTION

IPC System V est le nom donné à trois mécanismes de communication interprocessus largement disponibles sur les systèmes UNIX : files d'attente de messages, sémaphores et mémoire partagée.

Files d'attente de messages

Les files d'attente de messages System V permettent d'échanger des données en unités appelées messages. Chaque message peut avoir une priorité associée. Les files d'attente de messages POSIX fournissent une API alternative pour obtenir le même résultat ; voir mq_overview(7).

L'API des files d'attente de messages System V comprend les appels système suivants :

msgget(2)
Crée une nouvelle file d'attente de messages ou obtient l'identifiant d'une file d'attente existante. Cet appel renvoie un identifiant qui est utilisé dans les API restantes.
msgsnd(2)
Ajoute un message à une file d'attente.
msgrcv(2)
Retire un message d'une file d'attente.
msgctl(2)
Effectue diverses opérations de contrôle sur une file d'attente, y compris sa suppression.

Ensembles de sémaphores

Les sémaphores System V permettent aux processus de synchroniser leurs actions. Les sémaphores System V sont alloués en groupes appelés ensembles ; chaque sémaphore dans un ensemble est un sémaphore de comptage. Les sémaphores POSIX fournissent une API alternative pour obtenir le même résultat ; voir sem_overview(7).

L'API des sémaphores System V comprend les appels système suivants :

semget(2)
Crée un nouvel ensemble ou obtient l'identifiant d'un ensemble existant. Cet appel renvoie un identifiant qui est utilisé dans les API restantes.
semop(2)
Effectue des opérations sur les sémaphores d'un ensemble.
semctl(2)
Effectue diverses opérations de contrôle sur un ensemble, y compris sa suppression.

Segments de mémoire partagée

La mémoire partagée System V permet aux processus de partager une région de mémoire (un "segment"). La mémoire partagée POSIX est une API alternative pour obtenir le même résultat ; voir shm_overview(7).

L'API de mémoire partagée System V comprend les appels système suivants :

shmget(2)
Crée un nouveau segment ou obtient l'identifiant d'un segment existant. Cet appel renvoie un identifiant qui est utilisé dans les API restantes.
shmat(2)
Attache un objet de mémoire partagée existant dans l'espace d'adressage du processus appelant.
shmdt(2)
Détache un segment de l'espace d'adressage du processus appelant.
shmctl(2)
Effectue diverses opérations de contrôle sur un segment, y compris sa suppression.

Namespaces IPC

Pour une discussion sur l'interaction des objets IPC System V et des namespaces IPC, voir ipc_namespaces(7).
