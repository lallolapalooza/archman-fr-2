NOM

s1ms2dlf - convertir les fichiers journaux SMTP de SunONE Messaging Server au format DLF de Lire

SYNTAXE

nms2dlf

DESCRIPTION

Ce programme convertit un fichier journal de SunONE Messaging Server généré par le service SMTP au format DLF de Lire. Le fichier journal est attendu sur l'entrée standard (stdin), le fichier DLF est imprimé sur la sortie standard (stdout).

Pour traiter correctement le fichier journal, vous devez activer la journalisation des canaux suivants :

À COMPLÉTER

LIMITATIONS

Ce convertisseur DLF a été développé pour la version 5.2 de SunONE Messaging Server. D'autres versions peuvent fonctionner ou non. Contactez les développeurs de LogReport si vous rencontrez des problèmes avec ce convertisseur.

Vous pouvez trouver des informations sur le format de journalisation utilisé par SunONE Messaging Server à l'URL suivante :

http://docs.sun.com/source/816-6009-10/logging.htm

CONFIGURATION DE LA JOURNALISATION DU MODULE MAILBOX-DELIVER

Nous avons constaté qu'il n'y avait pas de journaux provenant du module Mailbox-Delivery par défaut. Pour résoudre ce problème, assurez-vous de faire ce qui suit :

1.
Allez sur le MTA ou le Message Store de SunONE Messaging Server.
2.
Connectez-vous en tant qu'utilisateur du serveur de messagerie (généralement ce ne devrait pas être root, mais typiquement un utilisateur comme mailsrv ou celui défini lors de l'installation, vérifiez la propriété des fichiers dans votre instance de serveur de messagerie, par exemple).
3.
Allez à l'emplacement correct, quelque chose comme : server-root/msg-instance

Par exemple, cela pourrait être : /opt/sunone/s1ms5/msg-mymailserver

4.
Faites : 
À ÉCRIRE

EXEMPLES

Pour traiter un journal tel que produit par Netscape Messaging Server

$ s1ms2dlf < mail.log

s1ms2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report nms < /var/log/mail.log
