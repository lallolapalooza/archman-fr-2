NOM

sfparse - analyseur de fichier de chaînes

SYNTAXE

sfparse [ --utf8 | --unicode ] nom_de_fichier

DESCRIPTION

Cet outil a deux fonctions différentes. Lorsqu'il est appelé avec uniquement un nom de fichier comme argument, il vérifie qu'un fichier est un fichier de chaînes valide, ce qui revient essentiellement à vérifier si le fichier est au format NSDictionary sérialisé approprié (voir la section "defaults plist" pour plus d'informations à ce sujet).

D'autre part, si l'une des deux options est donnée, aucune vérification de ce type n'est effectuée, mais le fichier EST converti dans le codage nommé.

OPTIONS

--unicode - convertir un fichier ASCII ou UTF8 en Unicode

--utf8 - convertir un fichier ASCII ou Unicode en UTF8
