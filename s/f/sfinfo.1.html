NOM

sfinfo - afficher des informations sur les fichiers audio

SYNTAXE

sfinfo [options] fichiers audio...

DESCRIPTION

sfinfo affiche des informations sur les fichiers audio spécifiés, notamment le format du fichier, la fréquence d'échantillonnage, la durée et le format des données audio.

Par défaut, sfinfo affiche les informations dans un format plus long, sur plusieurs lignes ; spécifier l'option --short ou -s produit un résumé court, sur une seule ligne.

Tous les fichiers qui ne sont pas reconnus comme des fichiers audio valides seront ignorés, sauf si l'option --reporterror ou -r est donnée. Les formats de fichiers actuellement pris en charge par sfinfo sont AIFF, AIFF-C, NeXT/Sun .snd/.au, WAVE, Berkeley/IRCAM/CARL Sound File, AVR, Amiga IFF/8SVX, Sample Vision, Creative Voice File, NIST SPHERE et Core Audio Format.

OPTIONS

--short, -s

Affiche un résumé court sur une seule ligne de chaque fichier audio reconnu.

--reporterror, -r

Affiche un message d'erreur si l'un des fichiers spécifiés n'est pas reconnu comme un fichier audio valide.

--help, -h

Affiche le message d'aide.

--version, -v

Affiche les informations sur la version.

EXEMPLES

Afficher le résumé d'un fichier audio :

% sfinfo drum.aiff
Nom du fichier      drum.aiff
Format du fichier    Audio Interchange File Format (aiff)
Format des données   Entier 16 bits (complément à deux, big endian)
Données audio      1569972 octets commencent à l'offset 54 (36 hex)
                   2 canaux, 392493 images
Fréquence d'échantillonnage  44100.00 Hz
Durée              8.900 secondes

Lister tous les fichiers audio reconnus dans le répertoire courant en utilisant le format de sortie court :

% sfinfo -s *
    9.60s 44100.00 aiff  1ch 16b -- bass.aiff
    8.90s 44100.00 aiff  2ch 16b -- drum.aiff
