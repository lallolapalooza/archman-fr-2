NOM

sfizz_jack - Lance une instance sfizz en tant que client JACK

SYNTAXE

sfizz_jack [FICHIER] [OPTIONS...]

DESCRIPTION

sfizz_jack encapsule la bibliothèque sfizz SFZ dans un client JACK qui peut être contrôlé par une interface texte.

OPTIONS

FICHIER
Nom d'un fichier SFZ optionnel à charger en premier.
--nom_client
Nom pour le client JACK.
--nb_voix NOMBRE
Change la polyphonie maximale.
--taille_preload NOMBRE
Octets à précharger dans le cache pour les échantillons.
--etat
Sort l'état dans la boucle JACK.
--jack_autoconnect
Connecte automatiquement les sorties JACK.

INTERFACE TEXTE

Il est possible d'interagir avec le client JACK via l'entrée standard. Les commandes possibles sont :

charger_instrument FICHIER
Charge un instrument.
definir_taille_preload NOMBRE
Définit le nombre d'octets à précharger dans le cache pour les échantillons.
definir_voix NOMBRE
Change la polyphonie maximale.
quitter
Quitte.
