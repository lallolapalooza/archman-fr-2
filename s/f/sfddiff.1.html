SFDDIFF(1) Manuel des commandes générales SFDDIFF(1)

NOM

sfddiff - comparer deux fichiers de polices

SYNTAXE

sfddiff [--help] [--ignorehints] [--ignorenames] [--ignoregpos] [--ignoregsub] [--ignorebitmaps] [--exact] [--warn] [--merge fichier_sortie] [--usage] [--version] fichier_police1 fichier_police2

DESCRIPTION

Le programme sfddiff compare deux fichiers de polices, qui peuvent être dans n'importe quel format que fontforge(1) peut lire. Il signalera les différences suivantes :

1)
Caractères présents dans une police mais pas dans l'autre.
2)
Caractères présents dans les deux polices mais ayant des ensembles de contours ou de références différents. Les contours peuvent être comparés de sorte que seules les correspondances exactes soient acceptées, ou qu'une correspondance plus floue soit utilisée. De même, les références peuvent devoir correspondre exactement, ou peuvent être mises en correspondance après un découplage. Cette comparaison floue est utile lors de la comparaison de polices TrueType et PostScript, ou lors de la comparaison d'une police avec des références et d'une autre sans.
3)
Les indications PostScript ou les instructions TrueType sont différentes.
4)
Les noms des polices (les tables 'name' de TrueType) diffèrent.
5)
Le crénage (et autres informations 'gpos') diffère.
6)
Les ligatures (et autres informations 'gsub') diffèrent.
7)
Toutes les couches de bitmaps présentes dans une police mais pas dans l'autre.
8)
Tous les caractères bitmap présents dans une couche d'une police mais pas dans la couche équivalente de l'autre.
9)
Tous les caractères bitmap qui diffèrent.

OPTIONS

--help
Fournit une description avec une liste des options disponibles.
--ignorehints
Supprime le signalement des différences d'indications/instructions.
--ignoregpos
Supprime le signalement des différences de crénage (et autres 'gpos').
--ignoregsub
Supprime le signalement des différences de ligatures (et autres 'gsub').
--ignorenames
Supprime le signalement des différences de chaînes de noms.
--ignorebitmaps
Supprime le signalement des différences de bitmaps.
--exact
Exige que les contours correspondent exactement.
--warn
Avertit si les contours/références sont légèrement différents.
--merge fichier_sortie
Stocke une version fusionnée des deux polices dans le fichier de sortie spécifié. Les données fusionnées seront basées sur fichier_sfd1, tous les caractères présents dans fichier_sfd2 mais pas dans fichier_sfd1 seront ajoutés, et les contours de fichier_sfd2 seront placés en arrière-plan. Enfin, pour tous les caractères avec des contours ou des références différents, l'arrière-plan du caractère contiendra les contours de fichier_sfd2 (les références seront découplées en contours et ces contours seront également ajoutés).
--usage
Affiche la description d'utilisation.
--version
Affiche la version actuelle.
