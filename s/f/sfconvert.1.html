NOM

sfconvert - convertir des fichiers audio

SYNTAXE

sfconvert fichier_entree fichier_sortie [options_sortie]

DESCRIPTION

La commande sfconvert convertit un fichier audio vers un autre format de fichier ou un autre format de données.

OPTIONS

Les mots-clés suivants spécifient le format du fichier sonore de sortie :

format f

Format du fichier de sortie. f doit être l'un des suivants :
aiff Audio Interchange File Format
aifc AIFF-C
next Format NeXT/Sun .snd/.au
wave MS RIFF WAVE
bicsf Berkeley/IRCAM/CARL Sound File Format
smp Sample Vision Format
voc Creative Voice File Format
nist NIST SPHERE Format
caf Core Audio Format
flac FLAC

compression c

ulaw G.711 mu-law
alaw G.711 A-law
ima IMA ADPCM
msadpcm Microsoft ADPCM
flac FLAC
alac Apple Lossless Audio Codec

byteorder e

Ordre des octets de sortie. e peut être big ou little.

channels n

Nombre de canaux de sortie. n est 1 pour mono, et 2 pour stéréo.

integer n s

Convertir en données audio entières. n indique la largeur d'échantillon de sortie en bits. s spécifie le format d'échantillon et peut être soit 2scomp pour les données signées en complément de deux, soit unsigned pour les données non signées.

float m

Convertir en données audio flottantes avec une amplitude maximale de m (généralement 1.0). Les options integer et float sont mutuellement exclusives.

Les options suivantes ne prennent pas d'arguments supplémentaires :

--help, -h

Afficher le message d'aide.

--version, -v

Afficher les informations de version.
