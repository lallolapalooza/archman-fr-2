SFTP(1) Manuel des commandes générales SFTP(1)

NOM

sftp — Transfert sécurisé de fichiers OpenSSH

SYNTAXE

sftp [-46AaCfNpqrv] [-B taille_tampon] [-b fichier_batch] [-c chiffrement] [-D commande_sftp_serveur] [-F config_ssh] [-i fichier_identite] [-J destination] [-l limite] [-o option_ssh] [-P port] [-R nb_requetes] [-S programme] [-s sous_systeme | serveur_sftp] [-X option_sftp] destination

DESCRIPTION

sftp est un programme de transfert de fichiers, similaire à ftp(1), qui effectue toutes les opérations sur un transport ssh(1) chiffré. Il peut également utiliser de nombreuses fonctionnalités de ssh, comme l'authentification par clé publique et la compression.

La destination peut être spécifiée soit sous la forme [utilisateur@]hôte[:chemin] soit sous la forme d'une URI du type sftp://[utilisateur@]hôte[:port][/chemin].

Si la destination inclut un chemin et que celui-ci n'est pas un répertoire, sftp récupérera automatiquement les fichiers si une méthode d'authentification non interactive est utilisée ; sinon, il le fera après une authentification interactive réussie.

Si aucun chemin n'est spécifié, ou si le chemin est un répertoire, sftp se connectera à l'hôte spécifié et entrera en mode commande interactif, en changeant de répertoire distant si un répertoire a été spécifié. Une barre oblique finale optionnelle peut être utilisée pour forcer le chemin à être interprété comme un répertoire.

Comme les formats de destination utilisent des deux-points pour délimiter les noms d'hôte des noms de chemins ou des numéros de port, les adresses IPv6 doivent être entourées de crochets pour éviter toute ambiguïté.

Les options sont les suivantes :

-4
Force sftp à n'utiliser que les adresses IPv4.
-6
Force sftp à n'utiliser que les adresses IPv6.
-A
Permet le transfert de l ssh-agent(1) vers le système distant. Par défaut, aucun agent d'authentification n'est transféré.
-a
Tente de reprendre les transferts interrompus au lieu d'écraser les copies partielles ou complètes existantes des fichiers. Si le contenu partiel diffère de celui en cours de transfert, le fichier résultant sera probablement corrompu.
-B taille_tampon
Spécifie la taille du tampon que sftp utilise lors du transfert de fichiers. Des tampons plus grands nécessitent moins d'allers-retours au prix d'une consommation mémoire plus élevée. La valeur par défaut est de 32768 octets.
-b fichier_batch
Le mode batch lit une série de commandes depuis un fichier_batch d'entrée au lieu de l'entrée standard. Comme il manque d'interaction utilisateur, il doit être utilisé conjointement avec une authentification non interactive pour éviter d'avoir à entrer un mot de passe lors de la connexion (voir sshd(8) et ssh-keygen(1) pour plus de détails).

Un fichier_batch de ‘-’ peut être utilisé pour indiquer l'entrée standard. sftp s'interrompra si l'une des commandes suivantes échoue : get, put, reget, reput, rename, ln, rm, mkdir, chdir, ls, lchdir, copy, cp, chmod, chown, chgrp, lpwd, df, symlink, et lmkdir.

La terminaison en cas d'erreur peut être supprimée commande par commande en préfixant la commande avec un caractère ‘-’ (par exemple, -rm /tmp/blah*). L'écho de la commande peut être supprimé en préfixant la commande avec un caractère ‘@’. Ces deux préfixes peuvent être combinés dans n'importe quel ordre, par exemple -@ls /bsd.

-C
Active la compression (via le drapeau -C de ssh).
-c chiffrement
Sélectionne le chiffrement à utiliser pour crypter les transferts de données. Cette option est directement transmise à ssh(1).
-D commande_sftp_serveur
Se connecte directement à un serveur sftp local (plutôt qu'via ssh(1)). Une commande et ses arguments peuvent être spécifiés, par exemple "/chemin/sftp-server -el debug3". Cette option peut être utile pour le débogage du client et du serveur.
-F config_ssh
Spécifie un fichier de configuration utilisateur alternatif pour ssh(1). Cette option est directement transmise à ssh(1).
-f
Demande que les fichiers soient vidés sur disque immédiatement après le transfert. Lors du téléversement de fichiers, cette fonctionnalité n'est activée que si le serveur implémente l'extension "fsync@openssh.com".
-i fichier_identite
Sélectionne le fichier à partir duquel l'identité (clé privée) pour l'authentification par clé publique est lue. Cette option est directement transmise à ssh(1).
-J destination
Se connecte à l'hôte cible en établissant d'abord une connexion sftp à l'hôte de saut décrit par destination, puis en établissant un transfert TCP vers la destination finale à partir de là. Plusieurs sauts peuvent être spécifiés, séparés par des virgules. C'est un raccourci pour spécifier une directive de configuration ProxyJump. Cette option est directement transmise à ssh(1).
-l limite
Limite la bande passante utilisée, spécifiée en Kbit/s.
-N
Désactive le mode silencieux, par exemple pour outrepasser le mode silencieux implicite défini par le drapeau -b.
-o option_ssh
Peut être utilisé pour passer des options à ssh dans le format utilisé dans ssh_config(5). C'est utile pour spécifier des options pour

-P port
Spécifie le port à utiliser pour la connexion à l'hôte distant.
-p
Conserve les heures de modification, les heures d'accès et les modes des fichiers d'origine transférés.
-q
Mode silencieux : désactive la barre de progression ainsi que les messages d'avertissement et de diagnostic de ssh(1).
-R num_requêtes
Spécifie le nombre de requêtes pouvant être en cours simultanément. Une augmentation de cette valeur peut légèrement améliorer la vitesse de transfert de fichiers, mais augmentera l'utilisation de la mémoire. La valeur par défaut est de 64 requêtes en cours.
-r
Copie récursivement des répertoires entiers lors du téléchargement et de l'envoi. Notez que sftp ne suit pas les liens symboliques rencontrés lors de la traversée de l'arborescence.
-S programme
Nom du programme à utiliser pour la connexion chiffrée. Le programme doit comprendre les options de ssh(1).
-s sous-système | sftp_server
Spécifie le sous-système SSH2 ou le chemin d'accès d'un serveur sftp sur l'hôte distant. Un chemin d'accès est utile lorsque le sshd(8) distant n'a pas de sous-système sftp configuré.
-v
Augmente le niveau de journalisation. Cette option est également transmise à ssh.
-X sftp_option
Spécifie une option qui contrôle certains aspects du comportement du protocole SFTP. Les options valides sont :
nrequests=valeur
Contrôle le nombre de requêtes SFTP de lecture ou d'écriture concurrentes pouvant être en cours à tout moment pendant un téléchargement ou un envoi. Par défaut, 64 requêtes peuvent être actives simultanément.
buffer=valeur
Contrôle la taille maximale du tampon pour une seule opération de lecture/écriture SFTP utilisée lors d'un téléchargement ou d'un envoi. Par défaut, un tampon de 32 Ko est utilisé.

COMMANDES INTERACTIVES

Une fois en mode interactif, sftp comprend un ensemble de commandes similaires à celles de ftp(1). Les commandes ne sont pas sensibles à la casse. Les noms de fichiers contenant des espaces doivent être entourés de guillemets. Tous les caractères spéciaux contenus dans les noms de fichiers qui sont reconnus par glob(3) doivent être échappés avec des barres obliques inverses (‘\’).

bye
Quitte sftp.
cd [chemin]
Change le répertoire distant vers chemin. Si chemin n'est pas spécifié, alors le répertoire est changé pour celui où la session a commencé.

n.
chgrp [-h] grp path
Change le groupe du fichier path en grp. path peut contenir des caractères glob(7) et peut correspondre à plusieurs fichiers. grp doit être un GID numérique.

Si le drapeau -h est spécifié, les liens symboliques ne seront pas suivis. Notez que cela n'est pris en charge que par les serveurs qui implémentent l'extension « lsetstat@openssh.com ».

chmod [-h] mode path
Change les permissions du fichier path en mode. path peut contenir des caractères glob(7) et peut correspondre à plusieurs fichiers.

Si le drapeau -h est spécifié, les liens symboliques ne seront pas suivis. Notez que cela n'est pris en charge que par les serveurs qui implémentent l'extension « lsetstat@openssh.com ».

chown [-h] own path
Change le propriétaire du fichier path en own. path peut contenir des caractères glob(7) et peut correspondre à plusieurs fichiers. own doit être un UID numérique.

Si le drapeau -h est spécifié, les liens symboliques ne seront pas suivis. Notez que cela n'est pris en charge que par les serveurs qui implémentent l'extension « lsetstat@openssh.com ».

copy oldpath newpath
Copie un fichier distant de oldpath vers newpath.

Notez que cela n'est pris en charge que par les serveurs qui implémentent l'extension « copy-data ».

cp oldpath newpath
Alias de la commande copy.
df [-hi] [path]
Affiche des informations d'utilisation pour le système de fichiers contenant le répertoire courant (ou path si spécifié). Si le drapeau -h est spécifié, les informations de capacité seront affichées à l'aide de suffixes « lisibles par l'homme ». Le drapeau -i demande l'affichage des informations sur les inodes en plus des informations de capacité. Cette commande n'est prise en charge que sur les serveurs qui implémentent l'extension « statvfs@openssh.com ».
exit
Quitte sftp.
get [-afpR] remote-path [local-path]
Récupère le remote-path et le stocke sur la machine locale. Si le nom du chemin local n'est pas spécifié, il prend le même nom qu'il a sur la machine distante. remote-path peut contenir des caractères glob(7) et peut correspondre à plusieurs fichiers. S'il le fait et que local-path est spécifié, alors local-path doit spécifier un répertoire.

Si le drapeau -a est spécifié, alors on tente de reprendre les transferts partiels de fichiers existants. Notez que la reprise suppose qu'une copie partielle du fichier local correspond à la copie distante. Si le contenu du fichier distant diffère de la copie locale partielle, le fichier résultant sera probablement corrompu.

Si le drapeau -f est spécifié, alors fsync(2) sera appelé une fois le transfert de fichier terminé pour forcer l'écriture du fichier sur le disque.

Si le drapeau -p est spécifié, les permissions complètes du fichier et les heures d'accès sont également copiées.

Si le drapeau -R est spécifié, les répertoires seront copiés récursivement. Notez que sftp ne suit pas les liens symboliques lors des transferts récursifs.

help
Affiche le texte d'aide.
lcd [path]
Change le répertoire local en path. Si path n'est pas spécifié, alors change le répertoire vers le répertoire personnel de l'utilisateur local.
lls [ls-options [path]]
Affiche la liste du répertoire local de path ou du répertoire courant si path n'est pas spécifié. ls-options peut contenir tous les drapeaux pris en charge par la commande ls(1) du système local. path peut contenir des caractères glob(7) et peut correspondre à plusieurs fichiers.
lmkdir path
Crée le répertoire local spécifié par path.
ln [-s] oldpath newpath
Crée un lien de oldpath vers newpath. Si le drapeau -s est spécifié, le lien créé est un lien symbolique, sinon c'est un lien physique.
lpwd
Affiche le répertoire de travail local.
ls [-1afhlnrSt] [path]
Affiche une liste du répertoire distant de path ou du répertoire courant si path n'est pas spécifié. path peut contenir des caractères glob(7) et peut correspondre à plusieurs fichiers.

Les drapeaux suivants sont reconnus et modifient le comportement de ls en conséquence :

-1
Produit une sortie en une seule colonne.
-a
Liste les fichiers commençant par un point (‘.’).
-f
Ne trie pas la liste. L'ordre de tri par défaut est lexicographique.
-h
Lorsqu'il est utilisé avec une option de format long, utilise des suffixes d'unité : Byte, Kilooctet, Mégaoctet, Gigaoctet, Téraoctet, Pétaoctet et Exaoctet afin de réduire le nombre de chiffres à quatre ou moins en utilisant des puissances de 2 pour les tailles (K=1024, M=1048576, etc.).
-l
Affiche des détails supplémentaires, y compris les informations de permissions et de propriété.
-n
Produit une liste longue avec les informations d'utilisateur et de groupe présentées numériquement.
-r
Inverse l'ordre de tri de la liste.
-S
Trie la liste par taille de fichier.
-t
Trie la liste par heure de dernière modification.
lumask umask
Définit l'umask locale à umask.
mkdir path
Crée le répertoire distant spécifié par path.
progress
Active/désactive l'affichage du compteur de progression.
put [-afpR] local-path [remote-path]
Télécharge local-path et le stocke sur la machine distante. Si le nom du chemin distant n'est pas spécifié, il prend le même nom qu'il a sur la machine locale. local-path peut contenir des caractères glob(7) et peut correspondre à plusieurs fichiers. S'il le fait et que remote-path est spécifié, alors remote-path doit spécifier un répertoire.

Si le drapeau -a est spécifié, alors on tente de reprendre les transferts partiels de fichiers existants. Notez que la reprise suppose qu'une copie partielle du fichier distant correspond à la copie locale. Si le contenu du fichier local diffère de la copie locale distante, le fichier résultant sera probablement corrompu.

Si le drapeau -f est spécifié, alors une requête sera envoyée au serveur pour appeler fsync(2) après le transfert du fichier. Notez que cela n'est pris en charge que par les serveurs qui implémentent l'extension « fsync@openssh.com ».

Si le drapeau -p est spécifié, les permissions complètes du fichier et les heures d'accès sont également copiées.

Si le drapeau -R est spécifié, les répertoires seront copiés récursivement. Notez que sftp ne suit pas les liens symboliques lors des transferts récursifs.

pwd
Affiche le répertoire de travail distant.
quit
Quitte sftp.
reget [-fpR] remote-path [local-path]
Reprend le téléchargement de remote-path. Équivalent à get avec le drapeau -a sftp(1) — Arch manual pages

INTERACTIVE COMMANDS

cd path
Change the remote working directory to path. The default path is the user's home directory. If the path is not specified, the remote working directory is changed to the user's home directory.
chgrp group path
Change the group of file path to group. The group must be a numeric GID.
chmod mode path
Change the permissions of file path to mode. The mode is a octal number.
chown owner path
Change the owner of file path to owner. The owner must be a numeric UID.
get [-afRpr] remote-path [local-path]
Download remote-path from the remote machine to the current directory or to local-path if specified. The options are the same as for put.
help [command]
Display help for command, or a list of commands if no command is specified.
lcd [path]
Change the local working directory to path. If the path is not specified, the local working directory is changed to the user's home directory.
ln path
Create a symbolic link on the remote system named link-name which points to the file path.
lls [ls-options]
Display a listing of the local current directory, formatted like ls(1).
lmkdir path
Create a local directory named path.
ln oldpath newpath
Create a symbolic link on the remote system named newpath which points to the file oldpath.
lpwd
Print the local working directory.
ls [ls-options path]
Display a listing of the remote directory, formatted like ls(1). If path is specified, it lists the contents of that directory. Otherwise, it lists the contents of the current working directory. ls-options are options that are passed to the remote server's ls command.
lumask [umask]
Set the local umask. If umask is specified, the local umask is set to that value. Otherwise, the current local umask is printed.
mkdir path
Create a remote directory named path.
progress mode
Turn file transfer progress meter on or off. The default is on. mode can be off or on.
put [-afRpr] local-path [remote-path]
Upload local-path from the current directory or from local-path if specified to the remote machine. If remote-path is specified, it is renamed to that. The available options are:
-a
Use "append" mode, resuming previous transfer. If the remote file exists, the transfer will resume from the end of the remote file. If the remote file does not exist, it will be created. This is equivalent to the reput command. It is useful for transferring large files that may be interrupted.

The file is opened with the appropriate flags for resuming a transfer.

-f
Force overwrite of the remote file if it exists.
-p
Preserve modification times, access times, and modes from the original file.
-R
Recursively copy entire directory structures.
-r
Recursively copy entire directory structures. This is equivalent to -R.
pwd
Print the remote working directory.
quit
Exit sftp.
reget [-afRpr] remote-path [local-path]
Resume download of remote-path. Equivalent to get with the -a flag set.
reput [-fpR] local-path [remote-path]
Resume upload of local-path. Equivalent to put with the -a flag set.
rename oldpath newpath
Rename remote file from oldpath to newpath.
rm path
Delete remote file specified by path.
rmdir path
Remove remote directory specified by path.
symlink oldpath newpath
Create a symbolic link from oldpath to newpath.
version
Display the sftp protocol version.
!command
Execute command in local shell.
!
Escape to local shell.
?
Synonym for help.
