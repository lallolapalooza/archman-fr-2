Description détaillée

Fait partie de RTTI.

La classe type_info décrit les informations de type générées par une implémentation.

Documentation du constructeur & destructeur

virtual std::type_info::~type_info () [virtual]

Destructeur en premier. Étant la première fonction virtuelle non en ligne, cela contrôle dans quelle unité de traduction la vtable est émise. Le compilateur utilise ces informations pour savoir où émettre les structures type_info requises par l'exécution dans le nouveau-abi.

Documentation des fonctions membres

bool std::type_info::before (const type_info & __arg) const [noexcept]

Retourne vrai si *this précède __arg dans l'ordre de tri de l'implémentation.

const char * std::type_info::name () const [inline], [noexcept]

Retourne une chaîne d'octets définie par l'implémentation ; ceci n'est pas portable entre les compilateurs !
