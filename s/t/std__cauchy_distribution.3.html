std::cauchy_distribution

Nom

cauchy_distribution – distribution de Cauchy

Synopsis

#include <random>

template<typename RealType = double>
class cauchy_distribution;

Description

La distribution de Cauchy est une distribution de probabilité continue.

Elle est caractérisée par la fonction de densité de probabilité suivante :

$$ f(x; x_0, \gamma) = \frac{1}{\pi \gamma \left[ 1 + \left( \frac{x - x_0}{\gamma} \right)^2 \right]} $$

où \( x_0 \) est le paramètre de localisation et \( \gamma > 0 \) est le paramètre d'échelle.

Paramètres

La distribution de Cauchy a deux paramètres :

  • x0 : Le paramètre de localisation. La valeur par défaut est 0.0.
  • gamma : Le paramètre d'échelle. La valeur par défaut est 1.0.
