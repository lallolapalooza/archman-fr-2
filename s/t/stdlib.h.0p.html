stdlib.h(0P) Manuel du programmeur POSIX stdlib.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

stdlib.h — définitions de la bibliothèque standard

SYNTAXE

#include <stdlib.h>

DESCRIPTION

Certaines des fonctionnalités décrites dans cette page de référence étendent la norme ISO C. Les applications doivent définir la macro de test de fonctionnalité appropriée (voir le volume Interfaces système de POSIX.1‐2017, Section 2.2, L'environnement de compilation) pour activer la visibilité de ces symboles dans cet en-tête.

L'en-tête <stdlib.h> doit définir les macros suivantes qui seront développées en expressions constantes entières :

EXIT_FAILURE
Terminaison sans succès pour exit() ; évalue à une valeur non nulle.
EXIT_SUCCESS
Terminaison avec succès pour exit() ; évalue à 0.
{RAND_MAX}
Valeur maximale retournée par rand() ; au moins 32767.

L'en-tête <stdlib.h> doit définir la macro suivante qui sera développée en une expression entière positive de type size_t :

{MB_CUR_MAX}
Nombre maximal d'octets dans un caractère spécifié par l'environnement local actuel (catégorie LC_CTYPE).

Dans l'environnement local POSIX, la valeur de {MB_CUR_MAX} sera 1.

L'en-tête <stdlib.h> doit définir NULL comme décrit dans <stddef.h>.

L'en-tête <stdlib.h> doit définir les types de données suivants par le biais de typedef :

div_t
Type de structure retourné par la fonction div().
ldiv_t
Type de structure retourné par la fonction ldiv().
lldiv_t
Type de structure retourné par la fonction lldiv().
size_t
Tel que décrit dans <stddef.h>.
wchar_t
Tel que décrit dans <stddef.h>.

De plus, l'en-tête <stdlib.h> doit définir les constantes symboliques et macros suivantes telles que décrites dans <sys/wait.h> :

WEXITSTATUS
WIFEXITED
WIFSIGNALED
WIFSTOPPED
WNOHANG
WSTOPSIG
WTERMSIG
WUNTRACED
