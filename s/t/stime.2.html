stime(2) Manuel des appels système stime(2)

NOM

stime - régler l'heure

SYNTAXE

#include <time.h>
[[deprecated]] int stime(const time_t *t);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

stime() :

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _SVID_SOURCE

DESCRIPTION

NOTE : Cette fonction est dépréciée ; utilisez clock_settime(2) à la place.

stime() règle l'idée de l'heure et de la date par le système. L'heure, pointée par t, est mesurée en secondes depuis l'Époque, le 1er janvier 1970 00:00:00 +0000 (UTC). stime() ne peut être exécuté que par le superutilisateur.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
Erreur lors de l'obtention d'informations depuis l'espace utilisateur.
EPERM
Le processus appelant n'a pas les privilèges suffisants. Sous Linux, le privilège CAP_SYS_TIME est requis.

NORMES

Aucune.

HISTORIQUE

SVr4.

À partir de glibc 2.31, cette fonction n'est plus disponible pour les applications nouvellement liées et n'est plus déclarée dans <time.h>.

VOIR AUSSI

date(1), settimeofday(2), capabilities(7)
