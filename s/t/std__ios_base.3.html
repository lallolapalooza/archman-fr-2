std::ios_base - C++ Reference

Description

The std::ios_base class is the base class for all input/output stream classes. It defines everything that can be defined about I/O that does not depend on the type of characters being input or output. Most people will only see ios_base when they need to specify the full name of the various I/O flags (e.g., the openmodes).

Member Typedef Documentation

typedef void(* std::ios_base::event_callback) (event __e, ios_base &__b, int __i)

Le type d'une fonction de rappel d'événement.

Paramètres

__e Un des membres de l'énumération event.
__b Référence à l'objet ios_base.
__i L'entier fourni lors de l'enregistrement du rappel.

Les fonctions de rappel d'événement sont des fonctions définies par l'utilisateur qui sont appelées lors de plusieurs fonctions de ios_base et basic_ios, spécifiquement imbue(), copyfmt() et ~ios().

typedef _Ios_Iostate std::ios_base::iostate

Ceci est un type de masque de bits. _Ios_Iostate est défini par l'implémentation, mais il est valide d'effectuer des opérations bit à bit sur ces valeurs et de s'attendre à ce que la bonne chose se produise. Les objets définis de type iostate sont :

  • badbit
  • eofbit
  • failbit
  • goodbit

typedef _Ios_Openmode std::ios_base::openmode

Ceci est un type de masque de bits. _Ios_Openmode est défini par l'implémentation, mais il est valide d'effectuer des opérations bit à bit sur ces valeurs et de s'attendre à ce que la bonne chose se produise. Les objets définis de type openmode sont :

  • app
  • ate
  • binary
  • in
  • out
  • trunc

typedef _Ios_Seekdir std::ios_base::seekdir

Ceci est un type énuméré. _Ios_Seekdir est défini par l'implémentation. Les valeurs définies de type seekdir sont :

  • beg
  • cur, équivalent à SEEK_CUR dans la bibliothèque standard C.
  • end, équivalent à SEEK_END dans la bibliothèque standard C.

Member Enumeration Documentation

enum std::ios_base::event

L'ensemble des événements qui peuvent être passés à une fonction de rappel d'événement. erase_event est utilisé pendant ~ios() et copyfmt(). imbue_event est utilisé pendant imbue(). copyfmt_event est utilisé pendant copyfmt().

Constructor & Destructor Documentation

virtual std::ios_base::~ios_base () [virtual]

Appelle chaque rappel avec erase_event. Détruit le stockage local.

Notez que l'objet ios_base des flux standards n'est jamais détruit. Par conséquent, les rappels enregistrés avec les flux standards ne seront pas appelés avec erase_event (sauf si copyfmt est utilisé).

long & std::ios_base::iword (int __ix) [inline]

Accès au tableau d'entiers.

Paramètres

__ix Index dans le tableau.

Retourne

Une référence à un entier associé à l'index.

La fonction iword fournit un accès à un tableau d'entiers qui peut être utilisé à n'importe quelle fin. Le tableau s'agrandit si nécessaire pour contenir l'index fourni. Tous les entiers du tableau sont initialisés à 0.

L'implémentation réserve plusieurs index. Vous devriez utiliser xalloc pour obtenir un index sûr à utiliser. Notez également que, comme le tableau peut croître dynamiquement, il n'est pas sûr de conserver la référence.

int std::ios_base::xalloc () [static]

Accès à des indices uniques.

Retour

Un entier différent de tous les appels précédents.

Cette fonction retourne un entier unique à chaque appel. Elle peut être utilisée à n'importe quelle fin, mais est principalement destinée à être un indice unique pour les fonctions iword et pword. L'attente est qu'une application appelle xalloc afin d'obtenir un indice dans les tableaux iword et pword qui peut être utilisé sans crainte de conflit.

L'implémentation maintient une variable statique qui est incrémentée et retournée à chaque invocation. xalloc est garanti de retourner un indice sûr à utiliser dans les tableaux iword et pword.
