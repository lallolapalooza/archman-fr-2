NOM

statgrab - Interface de type sysctl pour les statistiques système

SYNTAXE


statgrab
[OPTION]... [STAT]...

DESCRIPTION

statgrab fournit une interface de type sysctl à toutes les statistiques système disponibles via libstatgrab. Ceci est utile pour les applications qui ne souhaitent pas faire d'appels de bibliothèque, mais qui veulent néanmoins accéder aux statistiques.

Un exemple d'application de ce type est mrtg, pour lequel des scripts sont fournis pour générer des fichiers de configuration.

OPTIONS

Les options suivantes sont supportées.

-l
Sortie de type sysctl Linux (par défaut)
-b
Sortie de type sysctl BSD
-m
Sortie compatible MRTG
-u
Sortie simple (afficher uniquement les valeurs)
-n
Afficher les statistiques cumulées une fois (par défaut)
-s
Afficher les différences de statistiques de manière répétée
-o
Afficher les différences de statistiques une fois
-t DELAI
Lors de la répétition, attendre DELAI secondes entre les mises à jour (par défaut 1)
-p
Afficher les différences d'utilisation du CPU en pourcentages plutôt qu'en valeurs absolues
-f FACTEUR
Afficher les valeurs flottantes sous forme d'entiers mis à l'échelle par FACTEUR
-K
Afficher les tailles en kibioctets
-M
Afficher les tailles en mébioctets
-G
Afficher les tailles en gibioctets

Si aucune option STAT n'est donnée, toutes seront affichées. Spécifiez 'STAT.' pour afficher toutes les statistiques commençant par ce préfixe.
