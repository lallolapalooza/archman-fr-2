Description détaillée

template<typename _Tp, typename _Sequence = deque<_Tp>>

class std::queue< _Tp, _Sequence >"Un conteneur standard offrant un comportement FIFO.

Paramètres de template

_Tp Type de l'élément.
_Sequence Type de la séquence sous-jacente, par défaut deque<_Tp>.

Respecte de nombreuses exigences d'un conteneur, mais ne définit rien concernant les itérateurs. Très peu d'autres interfaces de conteneurs standard sont définies.

Ce n'est pas un vrai conteneur, mais un adaptateur. Il contient un autre conteneur et fournit une interface enveloppante à ce conteneur. L'enveloppe est ce qui impose un comportement de file strict premier entré, premier sorti.

Le deuxième paramètre de template définit le type de la séquence/du conteneur sous-jacent. Il est par défaut std::deque, mais peut être tout type qui prend en charge front, back, push_back et pop_front, comme std::list ou un type défini par l'utilisateur approprié.

Les membres qui ne se trouvent pas dans les conteneurs *normaux* sont container_type, qui est un alias de type pour le second paramètre Sequence, et push et pop, qui sont des opérations standard de file/FIFO.

template<typename _Tp, typename _Sequence = deque<_Tp>> void std::queue< _Tp, _Sequence >::pop () [inline]

Supprime le premier élément. C'est une opération de file typique. Elle réduit la taille de la file de un. La complexité temporelle de l'opération dépend de la séquence sous-jacente.

Notez qu'aucune donnée n'est retournée, et si les données du premier élément sont nécessaires, elles doivent être récupérées avant d'appeler pop().

Detailed Description

The class template queue implements a first-in, first-out (FIFO) data structure. Elements are added to the back of the queue and removed from the front.

The interface requires that the underlying container supports:

  • front()
  • back()
  • push_back()
  • pop_front()
  • empty()
  • size()

The default underlying container is std::deque.
