strverscmp(3) Manuel des fonctions de bibliothèque strverscmp(3)

NOM

strverscmp - comparer deux chaînes de versions

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <string.h>
int strverscmp(const char *s1, const char *s2);

DESCRIPTION

Pour un ensemble de données comme jan1, jan2, ..., jan9, jan10, ..., le tri lexicographique donne jan1, jan10, ..., jan2, ..., jan9. La tâche de strverscmp() est de comparer deux chaînes de caractères en produisant l'ordre précédent, tandis que strcmp(3) ne trouve que l'ordre lexicographique. Cette fonction n'utilise pas la catégorie locale LC_COLLATE, elle est donc principalement destinée aux situations où les chaînes de caractères sont censées être en ASCII. Ceci est différent de l'ordre produit par sort(1) -V.

Ce que fait cette fonction est le suivant. Si les deux chaînes sont égales, retourne 0. Sinon, trouve la position entre deux octets telle que avant cette position les deux chaînes sont égales, et juste après il y a une différence. Trouve les chaînes de chiffres consécutives les plus grandes contenant (ou commençant à, ou se terminant à) cette position. Si l'une ou l'autre de ces chaînes est vide, retourne ce que strcmp(3) aurait retourné (ordre numérique des valeurs des octets). Sinon, compare numériquement les deux chaînes de chiffres, où les chaînes de chiffres avec un ou plusieurs zéros en tête sont interprétées comme si elles avaient un point décimal devant (de sorte qu'en particulier les chaînes de chiffres avec plus de zéros en tête viennent avant les chaînes de chiffres avec moins de zéros en tête). Ainsi, l'ordre est 000, 00, 01, 010, 09, 0, 1, 9, 10.

VALEUR DE RETOUR

La fonction strverscmp() retourne un entier inférieur à, égal à, ou supérieur à zéro si s1 est trouvé, respectivement, comme étant avant, égal à, ou après s2.

ATTRIBUTS

NORMES

GNU.

EXEMPLES

Le programme ci-dessous peut être utilisé pour démontrer le comportement de strverscmp(). Il utilise strverscmp() pour comparer les deux chaînes données comme arguments de ligne de commande. Un exemple de son utilisation est le suivant :


$ ./a.out jan1 jan10;
jan1 < jan10

Source du programme

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(int argc, char *argv[])
{
    int res;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <chaine1> <chaine2>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    res = strverscmp(argv[1], argv[2]);
    printf("%s %s %s\n", argv[1],
           (res < 0) ? "<" : (res == 0) ? "==" : ">", argv[2]);
    exit(EXIT_SUCCESS);
}
