template<typename _CharT> string std::numpunct< _CharT >::grouping () const [inline], [hérité]

Retourne la spécification de groupement. Cette fonction retourne une chaîne de caractères représentant les groupements de la partie entière d'un nombre. Les groupements indiquent où les séparateurs de milliers doivent être insérés dans la partie entière d'un nombre.

Chaque caractère de la chaîne retournée est interprété comme un entier plutôt qu'un caractère. Ces nombres représentent le nombre de chiffres dans un groupe. Le premier caractère de la chaîne représente le nombre de chiffres dans le groupe le moins significatif. Si un caractère est négatif, il indique un nombre illimité de chiffres pour le groupe. Si plus de caractères de la chaîne sont nécessaires pour grouper un nombre, le dernier caractère est utilisé de manière répétée.

NAME

std::numpunct_byname — localization of numeric punctuation

SYNOPSIS

#include <locale>

template<typename _CharT> class numpunct_byname : public std::numpunct<_CharT>

Description

The class numpunct_byname is derived from std::numpunct, and is used to specialize numeric formatting according to a named locale.

A template specialization of numpunct needs to be instantiated for each character type used in the program. The default instantiations are for char and wchar_t.

Constructor

template<typename _CharT> std::numpunct_byname

Constructs an object of class numpunct_byname.

The constructor takes a string representing the name of the locale, e.g. "en_US", "fr_FR", etc.

template<typename _CharT> string_type std::numpunct_byname< _CharT >::do_facets_grouping () const [inline], [inherited]

Return grouping specification. This function returns a string_type representing the grouping of digits in numbers. The grouping is specified as a sequence of integers. Each integer specifies the number of digits in a group. The first group is the least significant digits. If the last integer is 0, it indicates that the preceding group size should be used for all remaining digits. If the last integer is CHAR_MAX, it indicates that no further grouping should be applied.

For example, if the grouping string is "\003\002" and is applied to the number 123456789, this corresponds to 12,34,56,789. Note that if the string was "32", this would put more than 50 digits into the least significant group if the character set is ASCII.

The string is returned by calling numpunct<char_type>::do_grouping().

Returns

string representing grouping specification.
