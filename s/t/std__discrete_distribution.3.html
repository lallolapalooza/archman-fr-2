NAME

std::discrete_distribution - Distribution producing discrete quantiles

SYNOPSIS

#include <random>

    template<typename _IntType = int>
    class discrete_distribution;

Detailed Description

A discrete distribution is a distribution that produces distribution probabilities for a finite number of discrete integer quantiles.

The default probabilities are uniform, meaning that each of the possible outcomes has an equal chance of being selected. This can be modified by providing a list of weights to the constructor.

The possible outcomes are the integers in the range [0, N), where N is the number of weights provided to the constructor.
