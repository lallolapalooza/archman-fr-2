Toutes les fonctions operator>> (également appelées fonctions d'entrée formatée) ont un comportement commun. Chacune commence par construire un objet temporaire de type std::basic_istream::sentry avec le deuxième argument (noskipws) défini à false. Cela a plusieurs effets, le dernier étant la définition d'un indicateur de statut ; voir la documentation de sentry pour plus de détails.

Si le statut de sentry est bon, la fonction tente d'extraire les données appropriées au type de l'argument.

Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer le lancement d'une exception ios_base::failure) et l'exception d'origine sera relancée si badbit est défini dans le masque d'exceptions.

Toutes les fonctions d'entrée non formatées ont un comportement commun. Chacune commence par construire un objet temporaire de type std::basic_istream::sentry avec le deuxième argument (noskipws) défini à true. Cela a plusieurs effets, se terminant par la définition d'un indicateur de statut ; voir la documentation de sentry pour plus de détails.

Le nombre de caractères extraits est stocké pour une récupération ultérieure par gcount().

Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer le lancement d'une exception ios_base::failure) et l'exception d'origine sera relancée si badbit est activé dans le masque d'exceptions.

Paramètres du template

_CharT Type du flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

Cette classe supporte la lecture à partir de fichiers nommés, en utilisant les fonctions héritées de std::basic_istream. Pour contrôler la séquence associée, une instance de std::basic_filebuf est utilisée, à laquelle cette page fait référence en tant que sb.

template<typename _CharT, typename _Traits> basic_ios< _CharT, _Traits > & std::basic_ios< _CharT, _Traits >::copyfmt (const basic_ios< _CharT, _Traits > & __rhs) [inherited]

Copie les champs de __rhs dans celui-ci.

Paramètres

__rhs Les valeurs sources pour les copies.

Retourne

Une référence à cet objet.

Tous les champs de __rhs sont copiés dans cet objet, à l'exception de rdbuf() et rdstate() qui restent inchangés. Toutes les valeurs des tableaux pword et iword sont copiées.
