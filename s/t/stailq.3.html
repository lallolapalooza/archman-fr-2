STAILQ(3) Manuel des fonctions de bibliothèque STAILQ(3)

NOM

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implémentation d'une file d'attente chaînée simple avec queue

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *head,
                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note : Des macros identiques préfixées par SIMPLEQ au lieu de STAILQ existent ; voir VERSIONS.

DESCRIPTION

Ces macros définissent et opèrent sur des files d'attente chaînées simples avec queue.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type STAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro STAILQ_HEAD().

Création

Une file d'attente chaînée simple avec queue est dirigée par une structure définie par la macro STAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file d'attente et l'autre vers le dernier élément de la file d'attente. Les éléments sont chaînés simplement pour une surcharge minimale d'espace et de manipulation de pointeurs, au prix d'une suppression en O(n) pour des éléments arbitraires. De nouveaux éléments peuvent être ajoutés à la file d'attente après un élément existant, en tête de la file d'attente ou à la fin de la file d'attente. Une structure STAILQ_HEAD est déclarée comme suit :


STAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file d'attente. Un pointeur vers la tête de la file d'attente peut ensuite être déclaré comme suit :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

STAILQ_ENTRY() déclare une structure qui relie les éléments de la file d'attente.

STAILQ_HEAD_INITIALIZER() est évalué à un initialiseur pour la file d'attente head.

STAILQ_INIT() initialise la file d'attente référencée par head.

STAILQ_EMPTY() est évalué à vrai s'il n'y a aucun élément dans la file d'attente.

Insertion

STAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file d'attente.

STAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file d'attente.

STAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

STAILQ_FIRST() retourne le premier élément de la file d'attente ou NULL si la file d'attente est vide.

STAILQ_NEXT() retourne l'élément suivant dans la file d'attente, ou NULL si cet élément est le dernier.

STAILQ_FOREACH() parcourt la file d'attente référencée par head dans le sens avant, attribuant chaque élément successivement à var.

Suppression

STAILQ_REMOVE() supprime l'élément elm de la file d'attente.

STAILQ_REMOVE_HEAD() supprime l'élément en tête de la file d'attente. Pour une efficacité optimale, les éléments supprimés de la tête de la file d'attente devraient utiliser explicitement cette macro plutôt que la macro générique STAILQ_REMOVE().

Autres fonctionnalités

STAILQ_CONCAT() concatène la file d'attente dirigée par head2 à la fin de celle dirigée par head1, supprimant toutes les entrées de la première.

VALEUR DE RETOUR

STAILQ_EMPTY() retourne non nul si la file est vide, et zéro si la file contient au moins une entrée.

STAILQ_FIRST() et STAILQ_NEXT() retournent un pointeur vers la structure TYPE première ou suivante, respectivement.

STAILQ_HEAD_INITIALIZER() retourne un initialiseur qui peut être assigné à la file head.

VERSIONS

Certains BSD fournissent SIMPLEQ à la place de STAILQ. Ils sont identiques, mais pour des raisons historiques ils ont été nommés différemment sur différents BSD. STAILQ est originaire de FreeBSD, et SIMPLEQ est originaire de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception d'un équivalent SIMPLEQ manquant à STAILQ_CONCAT().

BOGUES

STAILQ_FOREACH() ne permet pas à var d'être retiré ou libéré dans la boucle, car cela interférerait avec le parcours. STAILQ_FOREACH_SAFE(), qui est présent sur les BSD mais n'est pas présent dans glibc, corrige cette limitation en permettant à var d'être retiré en toute sécurité de la liste et libéré depuis la boucle sans interférer avec le parcours.

NORMES

BSD.

HISTORIQUE

EXEMPLES

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* File chaînée simple avec queue */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Tête de file chaînée simple avec queue
                                               */
    STAILQ_INIT(&head);                     /* Initialiser la file */
    n1 = malloc(sizeof(struct entry));      /* Insertion en tête */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertion en queue */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertion après */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Suppression */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Suppression depuis la tête */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
