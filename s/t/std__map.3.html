Description Détaillée

template<typename _Clé, typename _Tp, typename _Compare = std::less<_Clé>, typename _Alloc = std::allocator<std::pair<const _Clé, _Tp> >>

class std::map< _Clé, _Tp, _Compare, _Alloc >"Un conteneur standard composé de paires (clé, valeur), qui peuvent être récupérées en fonction d'une clé, en temps logarithmique.

Depuis

C++98

Paramètres du template

_Clé Type des objets clé.
_Tp Type des objets mappés.
_Compare Type de l'objet fonction de comparaison, par défaut less<_Clé>.
_Alloc Type de l'allocateur, par défaut allocator<pair<const _Clé, _Tp>.

Respecte les exigences d'un conteneur, d'un conteneur réversible et d'un conteneur associatif (utilisant des clés uniques). Pour un map<Clé,T>, le key_type est Clé, le mapped_type est T, et le value_type est std::pair<const Clé,T>.

Les maps prennent en charge les itérateurs bidirectionnels.

Les données de l'arbre privé sont déclarées exactement de la même manière pour map et multimap ; la distinction est entièrement faite dans la manière dont les fonctions de l'arbre sont appelées (*_unique versus *_equal, identique à la norme).

Tente de construire et d'insérer une std::pair dans la map.

Paramètres

__args Arguments utilisés pour générer une nouvelle instance de paire (voir std::piecewise_contruct pour passer des arguments à chaque partie du constructeur de paire).

Retourne

Une paire, dont le premier élément est un itérateur qui pointe vers la paire éventuellement insérée, et le second est un booléen qui est vrai si la paire a été effectivement insérée.

Cette fonction tente de construire et d'insérer une paire (clé, valeur) dans la map. Une map repose sur des clés uniques et donc une paire n'est insérée que si son premier élément (la clé) n'est pas déjà présent dans la map.

L'insertion nécessite un temps logarithmique.

__args Arguments utilisés pour générer une nouvelle instance de paire (voir std::piecewise_contruct pour passer des arguments à chaque partie du constructeur de paire).

Retourne

Un itérateur qui pointe vers l'élément dont la clé est celle de la std::pair construite à partir de __args (peut être ou ne pas être cette std::pair).

Cette fonction ne se soucie pas de savoir si l'insertion a eu lieu, et ne retourne donc pas un booléen comme le fait emplace() à un seul argument. Notez que le premier paramètre n'est qu'un indice et peut potentiellement améliorer les performances du processus d'insertion. Un mauvais indice n'apporterait aucun gain d'efficacité.
