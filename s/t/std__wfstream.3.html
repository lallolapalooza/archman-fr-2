Toutes les fonctions operator>> (également appelées fonctions d'entrée formatée) ont un comportement commun. Chacune commence par construire un objet temporaire de type std::basic_istream::sentry avec le second argument (noskipws) mis à false. Cela a plusieurs effets, se terminant par la définition d'un indicateur de statut ; voir la documentation de sentry pour plus de détails.
Si le statut de sentry est bon, la fonction essaie d'extraire les données appropriées pour le type de l'argument.
Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer la levée d'une ios_base::failure) et l'exception d'origine sera relancée si badbit est activé dans le masque des exceptions.

Flags Contraste

This group of flags all deal with the formatting of numbers. Some of them are mutually exclusive.

adjustfield
A mask of `internal' | `left' | `right'. Useful for the 2-arg form of setf(3).
basefield
A mask of `dec' | `hex' | `oct'. Useful for the 2-arg form of setf(3).
defaultfloat
The default floating format.
floatfield
A mask of `scientific' | `fixed'. Useful for the 2-arg form of setf(3).
fmtflags
The set of formatting flags. Defined values are:
  • skipws - Skips leading white space before certain input operations.
  • left - Adds fill characters on the right (final positions) of certain generated output. (I.e., the thing you print is flush left.).
  • right - Adds fill characters on the left (initial positions) of certain generated output. (I.e., the thing you print is flush right.).
  • internal - Adds fill characters at a designated internal point in certain generated output, or identical to right if no such point is designated.
  • dec - Converts integer input or generates integer output in decimal base.
  • oct - Converts integer input or generates integer output in octal base.
  • hex - Converts integer input or generates integer output in hexadecimal base.
  • showbase - Generates a prefix indicating the numeric base of generated integer output.
  • showpoint - Generates a decimal-point character unconditionally in generated floating-point output.
  • showpos - Generates a + sign in non-negative generated numeric output.
  • uppercase - Replaces certain lowercase letters with their uppercase equivalents in generated output.
  • scientific - Generates floating-point output in scientific notation.
  • fixed - Generate floating-point output in fixed-point notation.
  • unitbuf - Flushes output after each output operation.
  • noboolalpha - Use ``true'' or ``false'' for boolean values (default).
  • boolalpha - Use ``true'' or ``false'' for boolean values.
  • noskipws - Does not skip leading whitespace.
  • nouppercase - Use default case for letters (default).
  • octbase - The default for octal.
  • hexbase - The default for hex.
  • decbase - The default for decimal.
iostate
The set of state flags. Defined values are:
  • goodbit - Indicates all is well.
  • eofbit - Indicates that an input operation reached the end of the input sequence.
  • failbit - Indicates that an input operation failed to read the expected characters, or that an output operation failed to generate the desired characters.
  • badbit - Indicates that a read or write error occurred (e.g., a file system error).
openmode
The set of flags for opening streams. Defined values are:
  • in - Open for input. Default for basic_ifstream and basic_fstream.
  • out - Open for output. Default for basic_ofstream and basic_fstream.
  • app - All output operations are performed at the end of the file, so nothing can be seen by input operations that take place after it.
  • ate - Seek to the end of the stream upon opening.
  • trunc - Truncate an existing stream when opening. Default for basic_ofstream.
  • binary - Indicates that the stream is to be opened in binary mode.
seekdir
The set of directions for seeking. Defined values are:
  • beg - Seek relative to the beginning of the stream.
  • cur - Seek relative to the current position.
  • end - Seek relative to the end of the stream.

"Controlling input and output for files.

Template Parameters

This class supports reading from and writing to named files, using the inherited functions from std::basic_iostream. To control the associated sequence, an instance of std::basic_filebuf is used, which this page refers to as sb.
