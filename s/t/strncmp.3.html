strcmp(3) Manuel des fonctions de bibliothèque strcmp(3)

NOM

strcmp, strncmp - comparer deux chaînes

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
int strcmp(const char *s1, const char *s2);
int strncmp(size_t n;
            const char s1[n], const char s2[n], size_t n);

DESCRIPTION

La fonction strcmp() compare les deux chaînes s1 et s2. L'environnement local n'est pas pris en compte (pour une comparaison tenant compte de l'environnement local, voir strcoll(3)). La comparaison est effectuée en utilisant des caractères non signés.

strcmp() renvoie un entier indiquant le résultat de la comparaison, comme suit :

•
0, si s1 et s2 sont égales ;
•
une valeur négative si s1 est inférieure à s2 ;
•
une valeur positive si s1 est supérieure à s2.

La fonction strncmp() est similaire, à l'exception près qu'elle ne compare que les n premiers octets (au plus) de s1 et s2.

VALEUR DE RETOUR

Les fonctions strcmp() et strncmp() renvoient un entier inférieur à, égal à, ou supérieur à zéro si s1 (ou les n premiers octets de celle-ci) est trouvée, respectivement, inférieure à, égale à, ou supérieure à s2.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strcmp (), strncmp () Sécurité des threads MT-Safe

VERSIONS

POSIX.1 spécifie uniquement que :

Le signe d'une valeur de retour non nulle doit être déterminé par le signe de la différence entre les valeurs de la première paire d'octets (tous deux interprétés comme des caractères unsigned char) qui diffèrent dans les chaînes comparées.

Dans glibc, comme dans la plupart des autres implémentations, la valeur de retour est le résultat arithmétique de la soustraction du dernier octet comparé dans s2 du dernier octet comparé dans s1. (Si les deux caractères sont égaux, cette différence est 0.)

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89, SVr4, 4.3BSD.

EXEMPLES

Le programme ci-dessous peut être utilisé pour démontrer le fonctionnement de strcmp() (lorsqu'il est appelé avec deux arguments) et de strncmp() (lorsqu'il est appelé avec trois arguments). Tout d'abord, quelques exemples utilisant strcmp() :


$ ./string_comp ABC ABC;
<str1> et <str2> sont égales
$ ./string_comp ABC AB;      # 'C' est ASCII 67 ; 'C' - '\0' = 67
<str1> est supérieur à <str2> (67)
$ ./string_comp ABA ABZ;     # 'A' est ASCII 65 ; 'Z' est ASCII 90
<str1> est inférieur à <str2> (-25)
$ ./string_comp ABJ ABC;
<str1> est supérieur à <str2> (7)
$ ./string_comp $'\201' A;   # 0201 - 0101 = 0100 (ou 64 décimal)
<str1> est supérieur à <str2> (64)

Le dernier exemple utilise la syntaxe spécifique à bash(1) pour produire une chaîne contenant un code ASCII 8 bits ; le résultat démontre que la comparaison de chaînes utilise des caractères non signés.

Et ensuite, quelques exemples utilisant strncmp() :


$ ./string_comp ABC AB 3;
<str1> est supérieur à <str2> (67)
$ ./string_comp ABC AB 2;
<str1> et <str2> sont égales dans les 2 premiers octets

Source du programme

/* string_comp.c
   Sous licence GNU General Public License v2 ou ultérieure.
*/
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(int argc, char *argv[])
{
    int res;
    if (argc < 3) {
        fprintf(stderr, "Usage: %s <str1> <str2> [<n>]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (argc == 3)
        res = strcmp(argv[1], argv[2]);
    else
        res = strncmp(argv[1], argv[2], atoi(argv[3]));
    if (res == 0) {
        printf("<str1> et <str2> sont égales");
        if (argc > 3)
            printf(" dans les %d premiers octets\n", atoi(argv[3]));
        printf("\n");
    } else if (res < 0) {
        printf("<str1> est inférieur à <str2> (%d)\n", res);
    } else {
        printf("<str1> est supérieur à <str2> (%d)\n", res);
    }
    exit(EXIT_SUCCESS);
}
