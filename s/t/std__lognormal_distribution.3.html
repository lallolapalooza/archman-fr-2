Description

The class template std::lognormal_distribution models a lognormal distribution.

The default type for the parameters and the return type is double.

The default mean (m) is 0 and the default standard deviation (s) is 1.

A lognormal distribution is a distribution of a random variable whose logarithm is normally distributed. That is, if X is a lognormal random variable, then Y = ln(X) is normally distributed.

The probability density function is:

f(x; m, s) = 1/(x*s*sqrt(2*pi)) * exp(-(ln(x)-m)^2 / (2*s^2)) for x > 0.

The parameters m and s are the mean and standard deviation of the random variable Y = ln(X).
