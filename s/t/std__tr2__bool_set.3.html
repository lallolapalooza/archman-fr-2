Description détaillée

bool_set

Voir N2136, Bool_set: logique multi-valuée par Hervé Brönnimann, Guillaume Melquiond, Sylvain Pion.

La conversion implicite en booléen est délicate ! Je peux utiliser la nouvelle conversion explicite. Ceci a été spécialisé dans le langage de telle sorte que dans les contextes nécessitant un booléen, la conversion se produit implicitement. Ainsi, la plupart des objections devraient être éliminées.
