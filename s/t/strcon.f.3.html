sous-programme strcon (caractère norme, caractère uplo, caractère diag, entier n, réel, dimension( lda, * ) a, entier lda, réel rcond, réel, dimension( * ) travail, entier, dimension( * ) itravail, entier info)

STRCON

Objectif

!>
!> STRCON estime le réciproque du nombre de condition d'une matrice
!> triangulaire A, dans la norme 1 ou la norme infini.
!>
!> La norme de A est calculée et une estimation est obtenue pour
!> norme(inv(A)), puis le réciproque du nombre de condition est
!> calculé comme suit :
!>    RCOND = 1 / ( norme(A) * norme(inv(A)) ).
!>

Paramètres

NORME 
!>          NORME est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infini est requis :
!>          = '1' ou 'O' :  norme 1 ;
!>          = 'I' :         norme infini.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure ;
!>          = 'L' :  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N' :  A est triangulaire non-unitaire ;
!>          = 'U' :  A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, de dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure supérieure N par N du tableau A
!>          contient la matrice triangulaire supérieure, et la partie
!>          strictement triangulaire inférieure de A n'est pas référencée.
!>          Si UPLO = 'L', la partie triangulaire inférieure N par N
!>          du tableau A contient la matrice triangulaire inférieure,
!>          et la partie strictement triangulaire supérieure de A n'est
!>          pas référencée.  Si DIAG = 'U', les éléments diagonaux
!>          de A ne sont pas non plus référencés et sont supposés
!>          être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          Le réciproque du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norme(A) * norme(inv(A))).
!>

TRAVAIL

!>          TRAVAIL est un tableau REAL, de dimension (3*N)
!>

ITRAVAIL

!>          ITRAVAIL est un tableau INTEGER, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>
