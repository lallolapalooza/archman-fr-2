Paquet: tcl

string(n) Commandes intégrées Tcl string(n)

NOM

string - Manipuler les chaînes de caractères

SYNTAXE

string option arg ?arg ...?

DESCRIPTION

Effectue l'une des plusieurs opérations sur les chaînes, en fonction de option. Les options légales (qui peuvent être abréviées) sont :

string cat ?string1? ?string2...?
Concatène les strings données, tout comme les placer directement les unes à côté des autres, et retourne la chaîne composée résultante. S'il n'y a pas de strings, le résultat est une chaîne vide.

Cette primitive est parfois plus pratique que la juxtaposition de chaînes lorsqu'une combinaison de guillemets est souhaitée, ou lorsque l'objectif est de retourner le résultat d'une concaténation sans recourir à return -level 0, et est plus efficace que de construire une liste d'arguments et d'utiliser join avec une chaîne de jointure vide.

string compare ?-nocase? ?-length longueur? string1 string2
Effectue une comparaison caractère par caractère des chaînes string1 et string2. Retourne -1, 0 ou 1, selon que string1 est lexicographiquement inférieure, égale ou supérieure à string2. Si -length est spécifié, seuls les longueur premiers caractères sont utilisés dans la comparaison. Si -length est négatif, il est ignoré. Si -nocase est spécifié, les chaînes sont comparées de manière insensible à la casse.
string equal ?-nocase? ?-length longueur? string1 string2
Effectue une comparaison caractère par caractère des chaînes string1 et string2. Retourne 1 si string1 et string2 sont identiques, ou 0 sinon. Si -length est spécifié, seuls les longueur premiers caractères sont utilisés dans la comparaison. Si -length est négatif, il est ignoré. Si -nocase est spécifié, les chaînes sont comparées de manière insensible à la casse.
string first aiguilleChaine filChaine ?indexDebut?
Recherche dans filChaine une séquence de caractères qui correspond exactement aux caractères de aiguilleChaine. Si trouvée, retourne l'index du premier caractère de la première correspondance trouvée dans filChaine. Si non trouvée, retourne -1. Si indexDebut est spécifié (sous l'une des formes décrites dans INDEX DE CHAÎNE), la recherche est limitée au caractère de filChaine spécifié par l'index. Par exemple,
string first a 0a23456789abcdef 5

retournera 10, mais

string first a 0123456789abcdef 11

retournera -1.

string index chaine indexCaractere
Retourne le indexCaractere-ème caractère de l'argument chaine. Un indexCaractere de 0 correspond au premier caractère de la chaîne. indexCaractere peut être spécifié comme décrit dans la section INDEX DE CHAÎNE.

Si indexCaractere est inférieur à 0 ou supérieur ou égal à la longueur de la chaîne, cette commande retourne une chaîne vide.

string is classe ?-strict? ?-failindex nomVar? chaine
Retourne 1 si chaine est un membre valide de la classe de caractères spécifiée, sinon retourne 0. Si -strict est spécifié, une chaîne vide retourne 0, sinon une chaîne vide retournera 1 pour n'importe quelle classe. Si -failindex est spécifié, alors si la fonction retourne 0, l'index dans la chaîne où la classe n'était plus valide sera stocké dans la variable nommée nomVar. Le nomVar ne sera pas défini si string is retourne 1. Les classes de caractères suivantes sont reconnues (le nom de la classe peut être abrégé) :
alnum
Tout caractère alphabétique ou numérique Unicode.
alpha
Tout caractère alphabétique Unicode.
ascii
Tout caractère avec une valeur inférieure à \u0080 (ceux qui sont dans la plage ASCII 7 bits).
boolean
Toutes les formes autorisées pour Tcl_GetBoolean.
control
Tout caractère de contrôle Unicode.
digit
Tout caractère numérique Unicode. Notez que cela inclut des caractères en dehors de la plage [0-9].
double
Toutes les formes autorisées pour Tcl_GetDoubleFromObj.
entier
Tous les formats de chaînes valides pour une valeur entière de taille arbitraire en Tcl, avec des espaces blancs optionnels autour. Les formats acceptés sont exactement ceux acceptés par la routine C Tcl_GetBignumFromObj.
false
Toutes les formes autorisées pour Tcl_GetBoolean où la valeur est fausse.
graph
Tout caractère imprimable Unicode, à l'exception de l'espace.
integer
Toutes les formes valides pour une valeur entière de 32 bits en Tcl, avec des espaces blancs optionnels autour. En cas de dépassement de la valeur, 0 est retourné et nomVar contiendra -1.
list
Toute structure de liste valide, avec des espaces blancs optionnels autour. En cas de structure de liste incorrecte, 0 est retourné et nomVar contiendra l'index de "l'élément" où l'analyse de la liste échoue, ou -1 si cela ne peut pas être déterminé.
lower
Tout caractère alphabétique Unicode en minuscules.
print
Tout caractère imprimable Unicode, y compris l'espace.
punct
Tout caractère de ponctuation Unicode.
space
Tout caractère d'espacement Unicode, séparateur de voyelle mongole (U+180e), espace sans chasse (U+200b), jointure de mots (U+2060) ou espace insécable sans chasse (U+feff) (=BOM).
true
Toutes les formes autorisées pour Tcl_GetBoolean où la valeur est vraie.
upper
Tout caractère alphabétique majuscule de l'ensemble de caractères Unicode.
wideinteger
Toutes les formes valides pour un entier large en Tcl, avec des espaces blancs optionnels autour. En cas de dépassement de la valeur, 0 est retourné et nomVar contiendra -1.
wordchar
Tout caractère de mot Unicode. C'est-à-dire tout caractère alphanumérique et tout caractère de ponctuation de connexion Unicode (par exemple, le tiret bas).
xdigit
Tout caractère hexadécimal ([0-9A-Fa-f]).

Dans le cas de boolean, true et false, si la fonction retourne 0, alors nomVar sera toujours défini sur 0, en raison de la nature variée d'une valeur booléenne valide.

string length string
Retourne une chaîne décimale indiquant le nombre de caractères dans string. Notez que ce n'est pas nécessairement la même chose que le nombre d'octets utilisés pour stocker la chaîne. Si la valeur est un tableau d'octets (comme ceux renvoyés par la lecture d'un canal encodé en binaire), cette commande retournera la longueur réelle en octets de la valeur.
string map ?-nocase? mapping string
Remplace des sous-chaînes dans string en fonction des paires clé-valeur dans mapping. mapping est une liste de clé valeur clé valeur ... telle que retournée par array get. Chaque occurrence d'une clé dans la chaîne sera remplacée par sa valeur correspondante. Si -nocase est spécifié, la correspondance est effectuée sans tenir compte des différences de casse. La clé et la valeur peuvent contenir plusieurs caractères. Le remplacement est effectué de manière ordonnée, de sorte que la clé apparaissant en premier dans la liste sera vérifiée en premier, et ainsi de suite. La chaîne string n'est parcourue qu'une seule fois, donc les remplacements de clés antérieurs n'auront aucun effet sur les correspondances de clés ultérieures. Par exemple,
string map {abc 1 ab 2 a 3 1 0} 1abcaababcabababc

retournera la chaîne 01321221.

Notez que si une clé antérieure est un préfixe d'une clé ultérieure, elle masquera complètement cette dernière. Ainsi, si l'exemple précédent est réorganisé comme suit,

string map {1 0 ab 2 a 3 abc 1} 1abcaababcabababc

la chaîne retournée sera 02c322c222c.

string match ?-nocase? pattern string
Vérifie si pattern correspond à string; retourne 1 si c'est le cas, 0 sinon. Si -nocase est spécifié, le motif tente de correspondre à la chaîne de manière insensible à la casse. Pour que les deux chaînes correspondent, leur contenu doit être identique, à l'exception des séquences spéciales suivantes qui peuvent apparaître dans pattern :
*
Correspond à toute séquence de caractères dans string, y compris une chaîne nulle.
?
Correspond à un seul caractère dans string.
[chars]
Correspond à n'importe quel caractère de l'ensemble donné par chars. Si une séquence de la forme x-y apparaît dans chars, alors tout caractère entre x et y, inclus, correspondra. Lorsqu'elle est utilisée avec -nocase, les points terminaux de la plage sont d'abord convertis en minuscules. Alors que {[A-z]} correspond à “_” lors d'une correspondance sensible à la casse (car “_” se situe entre “Z” et “a”), avec -nocase, cela est considéré comme {[A-Za-z]} (et est probablement ce qui était prévu à l'origine).
\x
Correspond au caractère unique x. Ceci fournit un moyen d'éviter l'interprétation spéciale des caractères *?[]\ dans pattern.
string range string first last
Retourne une plage de caractères consécutifs de string, commençant par le caractère dont l'indice est first et se terminant par le caractère dont l'indice est last. Un indice de 0 fait référence au premier caractère de la chaîne. first et last peuvent être spécifiés comme pour la méthode index. Si first est inférieur à zéro, il est traité comme s'il était zéro, et si last est supérieur ou égal à la longueur de la chaîne, il est traité comme s'il était end. Si first est supérieur à last, une chaîne vide est retournée.
string repeat string count
Retourne string répété count fois.
string replace string first last ?newstring?
Supprime une plage de caractères consécutifs de string, commençant par le caractère dont l'indice est first et se terminant par le caractère dont l'indice est last. Un indice de 0 fait référence au premier caractère de la chaîne. first et last peuvent être spécifiés comme pour la méthode index. Si newstring est spécifié, il est inséré dans la plage de caractères supprimés. Si first est inférieur à zéro, il est traité comme s'il était zéro, et si last est supérieur ou égal à la longueur de la chaîne, il est traité comme s'il était end. La chaîne initiale est retournée intacte, si first est supérieur à last, ou si first est égal ou supérieur à la longueur de la chaîne initiale, ou si last est inférieur à 0.
string reverse string
Retourne une chaîne de même longueur que string mais avec ses caractères dans l'ordre inverse.
string tolower string ?first? ?last?
Retourne une valeur égale à string, sauf que toutes les lettres majuscules (ou titres) ont été converties en minuscules. Si first est spécifié, il fait référence à l'indice du premier caractère de la chaîne où commencer la modification. Si last est spécifié, il fait référence à l'indice du caractère de la chaîne où s'arrêter (inclus). first et last peuvent être spécifiés en utilisant les formes décrites dans STRING INDICES.
string totitle string ?first? ?last?
Retourne une valeur égale à string, sauf que le premier caractère de string est converti en sa variante de titre Unicode (ou majuscule s'il n'y a pas de variante de titre) et le reste de la chaîne est converti en minuscules. Si first est spécifié, il fait référence à l'indice du premier caractère de la chaîne où commencer la modification. Si last est spécifié, il fait référence à l'indice du caractère de la chaîne où s'arrêter (inclus). first et last peuvent être spécifiés en utilisant les formes décrites dans STRING INDICES.
string toupper string ?first? ?last?
Retourne une valeur égale à string, sauf que toutes les lettres minuscules (ou titres) ont été converties en majuscules. Si first est spécifié, il fait référence à l'indice du premier caractère de la chaîne où commencer la modification. Si last est spécifié, il fait référence à l'indice du caractère de la chaîne où s'arrêter (inclus). first et last peuvent être spécifiés en utilisant les formes décrites dans STRING INDICES.
string trim string ?chars?
Retourne une valeur égale à string, sauf que tous les caractères principaux ou finaux présents dans la chaîne donnée par chars sont supprimés. Si chars n'est pas spécifié, les espaces blancs sont supprimés (tout caractère pour lequel string is space retourne 1, et "\0").
string trimleft string ?chars?
Retourne une valeur égale à string, sauf que tous les caractères principaux présents dans la chaîne donnée par chars sont supprimés. Si chars n'est pas spécifié, les espaces blancs sont supprimés (tout caractère pour lequel string is space retourne 1, et "\0").
string trimright string ?chars?
Retourne une valeur égale à string, sauf que tous les caractères finaux présents dans la chaîne donnée par chars sont supprimés. Si chars n'est pas spécifié, les espaces blancs sont supprimés (tout caractère pour lequel string is space retourne 1, et "\0").

SOUS-COMMANDES OBSOLÈTES

Ces sous-commandes sont actuellement prises en charge, mais sont susceptibles d'être supprimées dans une future version car leur fonctionnalité est soit quasiment jamais utilisée, soit très trompeuse.

string bytelength string
Retourne une chaîne décimale indiquant le nombre d'octets utilisés pour représenter string en mémoire lorsqu'elle est encodée en UTF-8 modifiée interne de Tcl; Tcl peut utiliser d'autres encodages pour string également, et ne garantit pas d'utiliser un seul encodage pour une string donnée. Comme l'UTF-8 utilise un nombre variable d'octets pour représenter les caractères Unicode, la longueur en octets ne sera pas généralement identique à la longueur en caractères. Les cas où un script se soucie de la longueur en octets sont rares.

Dans presque tous les cas, vous devriez utiliser l'opération string length (y compris pour déterminer la longueur d'une valeur de tableau d'octets Tcl). Reportez-vous à la notice Tcl_NumUtfChars pour plus de détails sur la représentation UTF-8.

Formellement, l'opération string bytelength retourne le contenu du champ length de la structure Tcl_Obj, après avoir appelé Tcl_GetString pour s'assurer que le champ bytes est rempli. Il est très peu probable que ce soit utile pour les scripts Tcl, car l'encodage interne de Tcl n'est pas un UTF-8 strict, mais plutôt un CESU-8 modifié avec un NUL dénormalisé (identique à celui utilisé dans un certain nombre d'endroits par le mécanisme de sérialisation de Java) pour permettre un traitement de base avec des fonctions C non conscientes de Unicode. Comme cette représentation ne devrait jamais être utilisée que par l'implémentation de Tcl, le nombre d'octets utilisés pour stocker la représentation a très peu de valeur (sauf pour le code d'extension C, qui y a un accès direct dans le but de la gestion de la mémoire, etc.).

Note de compatibilité : il est probable que cette sous-commande soit retirée dans une future version de Tcl. Il est préférable d'utiliser la commande encoding convertto pour convertir une chaîne en un encodage connu, puis d'appliquer string length à celui-ci.

SYNTAXIS

string ?interpréteur? commande ?arg...?

DESCRIPTION

La commande string prend en charge un certain nombre de commandes de manipulation de chaînes de caractères.

string bytelength string
Renvoie le nombre d'octets dans string.
string cat string?string...?
Concatène les string spécifiées en une seule chaîne.
string char integer?integer...?
Renvoie une chaîne constituée des caractères Unicode correspondant aux valeurs d'entiers spécifiées.
string compare ?«-modificateur»...? s1 s2
Compare les chaînes s1 et s2 et renvoie -1 si s1 est inférieure à s2, 0 si elles sont égales, et 1 si s1 est supérieure à s2. Les modificateurs suivants sont disponibles :
-ascii
Compare les chaînes octet par octet.
-nocase
Compare les chaînes sans tenir compte de la casse.
-nocompare
Compare les chaînes en utilisant la même sémantique que la commande string equal.
string equal ?«-modificateur»...? s1 s2
Renvoie 1 si les chaînes s1 et s2 sont égales, 0 sinon. Les modificateurs disponibles sont les mêmes que pour string compare.
string first needle haystack?N?
Renvoie l'indice de la première occurrence de la sous-chaîne needle dans la chaîne haystack. Si l'argument optionnel N est spécifié, la recherche commence à l'indice N. Si needle n'est pas trouvé, renvoie -1.
string index string charIndex
Renvoie le caractère à l'indice spécifié charIndex dans string. charIndex peut être spécifié en utilisant les formes décrites dans STRING INDICES.
string is ?«-ctype»...? string
Renvoie 1 si tous les caractères de string appartiennent à la catégorie spécifiée par ctype, 0 sinon. Les catégories suivantes sont disponibles :
alnum
Caractères alphanumériques.
alpha
Caractères alphabétiques.
ascii
Caractères ASCII.
control
Caractères de contrôle.
digit
Chiffres décimaux.
graph
Caractères imprimables, sauf l'espace.
lower
Caractères minuscules.
print
Caractères imprimables, y compris l'espace.
punct
Caractères de ponctuation.
space
Caractères d'espacement.
upper
Caractères majuscules.
xdigit
Chiffres hexadécimaux.
string length string
Renvoie le nombre de caractères dans string.
string last needle haystack?N?
Renvoie l'indice de la dernière occurrence de la sous-chaîne needle dans la chaîne haystack. Si l'argument optionnel N est spécifié, la recherche commence à l'indice N et remonte vers le début. Si needle n'est pas trouvé, renvoie -1.
string match ?«-modificateur»...? pattern string
Renvoie 1 si string correspond au pattern, 0 sinon. Les modificateurs disponibles sont les mêmes que pour string compare. Le pattern utilise la syntaxe des jokers Tcl : * (correspond à zéro ou plusieurs caractères), ? (correspond à un seul caractère), [abc] (correspond à l'un des caractères a, b ou c), [a-c] (correspond à l'un des caractères dans la plage a à c).
string range string first last
Renvoie la sous-chaîne de string commençant à l'indice first et se terminant à l'indice last (inclus). first et last peuvent être spécifiés en utilisant les formes décrites dans STRING INDICES.
string repeat string count
Renvoie une nouvelle chaîne constituée de string répétée count fois.
string replace string first last ?N? ...
Renvoie une nouvelle chaîne où les sous-chaînes spécifiées par les paires d'indices first et last sont remplacées par les chaînes qui les suivent. Si une chaîne de remplacement n'est pas fournie, la sous-chaîne est simplement supprimée. Si first est supérieur à last, la commande ajoute les chaînes de remplacement à l'indice first.
string reverse string
Renvoie une nouvelle chaîne qui est l'inverse de string.
string tolower string
Renvoie une nouvelle chaîne où tous les caractères alphabétiques de string ont été convertis en minuscules.
string toupper string
Renvoie une nouvelle chaîne où tous les caractères alphabétiques de string ont été convertis en majuscules.
string trim ?«-modificateur»...? string ?chars?
Renvoie une nouvelle chaîne obtenue en supprimant les caractères spécifiés dans chars (ou les espaces blancs par défaut) du début et de la fin de string. Les modificateurs suivants sont disponibles :
-left
Supprime les caractères uniquement du début de la chaîne.
-right
Supprime les caractères uniquement de la fin de la chaîne.
string trimleft ?«-modificateur»...? string ?chars?
Identique à string trim -left.
string trimright ?«-modificateur»...? string ?chars?
Identique à string trim -right.
string word string charIndex
Renvoie le mot contenant le caractère à l'indice charIndex de string. charIndex peut être spécifié en utilisant les formes décrites dans STRING INDICES. Un mot est considéré comme une plage contiguë de caractères alphanumériques (lettres Unicode ou chiffres décimaux) ou de traits de soulignement (ponctuation de connexion Unicode), ou tout caractère unique autre que ceux-ci.
string wordend string charIndex
Renvoie l'indice du caractère suivant le dernier caractère du mot contenant le caractère à l'indice charIndex de string. charIndex peut être spécifié en utilisant les formes décrites dans STRING INDICES. Un mot est considéré comme une plage contiguë de caractères alphanumériques (lettres Unicode ou chiffres décimaux) ou de traits de soulignement (ponctuation de connexion Unicode), ou tout caractère unique autre que ceux-ci.
string wordstart string charIndex
Renvoie l'indice du premier caractère du mot contenant le caractère à l'indice charIndex de string. charIndex peut être spécifié en utilisant les formes décrites dans STRING INDICES. Un mot est considéré comme une plage contiguë de caractères alphanumériques (lettres Unicode ou chiffres décimaux) ou de traits de soulignement (ponctuation de connexion Unicode), ou tout caractère unique autre que ceux-ci.

INDICES DE CHAÎNE

Lorsqu'on se réfère à des indices dans une chaîne (par exemple, pour string index ou string range) les formats suivants sont pris en charge :

entier
Pour toute valeur d'indice qui passe string is integer -strict, le caractère spécifié à cet indice entier (par exemple, 2 ferait référence au « c » dans « abcd »).
end
Le dernier caractère de la chaîne (par exemple, end ferait référence au « d » dans « abcd »).
end-N
Le dernier caractère de la chaîne moins le décalage entier spécifié N (par exemple, « end-1 » ferait référence au « c » dans « abcd »).
end+N
Le dernier caractère de la chaîne plus le décalage entier spécifié N (par exemple, « end+-1 » ferait référence au « c » dans « abcd »).
M+N
Le caractère spécifié à l'indice entier qui est la somme des valeurs entières M et N (par exemple, « 1+1 » ferait référence au « c » dans « abcd »).
M-N
Le caractère spécifié à l'indice entier qui est la différence des valeurs entières M et N (par exemple, « 2-1 » ferait référence au « b » dans « abcd »).

Dans les spécifications ci-dessus, la valeur entière M ne contient pas d'espaces blancs finaux et la valeur entière N ne contient pas d'espaces blancs initiaux.

EXEMPLE

Tester si la chaîne dans la variable string est un préfixe non vide correct de la chaîne foobar.

set length [string length $string]
if {$length == 0} {
    set isPrefix 0
} else {
    set isPrefix [string equal -length $length $string "foobar"]
}
