STAP-MERGE(1) Manuel des commandes générales STAP-MERGE(1)

NOM

stap-merge - fusionneur binaire par CPU systemtap

SYNTAXE

stap-merge [ OPTIONS ] [ NOMS_FICHIERS_ENTRÉE ]

DESCRIPTION

L'exécutable stap-merge s'applique lorsque l'option -b a été utilisée lors de l'exécution d'un script stap. L'option -b générera des fichiers par CPU, basés sur le champ d'horodatage. Ensuite, stap-merge fusionnera et triera les fichiers par CPU en se basant sur le champ d'horodatage.

OPTIONS

L'exécutable de fusion de systemtap prend en charge les options suivantes.

-v
Mode verbeux, affiche trois champs supplémentaires par ensemble de données collectées.
[cpunuméro,séquencenumérodedonnées,longueurdel'ensemblededonnées]
-o NOM_FICHIER_SORTIE

Spécifiez le nom du fichier dans lequel vous souhaitez que la sortie soit redirigée. Si cette option n'est pas spécifiée, la sortie sera envoyée à la sortie standard.

EXEMPLES

$ stap -v -b -e 'probe syscall.open { printf("%s(%d) open\n",
execname(), pid()) }'

Cela devrait générer plusieurs fichiers stpd_cpu (chacun étiqueté avec un numéro représentant le CPU à partir duquel le fichier a été produit).

$ stap-merge -v stpd_cpu0 stpd_cpu1

L'exécution du programme stap-merge dans le même répertoire que le script stap de l'exemple précédent produira une séquence ordonnée de paquets avec le label en trois parties pour chaque ensemble de données. Ce résultat sera envoyé via la sortie standard. Un fichier de sortie aurait pu être spécifié en utilisant l'option « -o ».
