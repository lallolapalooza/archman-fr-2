NOM

st-util - Exécute le serveur GDB pour interagir avec un périphérique STM32

SYNOPIS

st-util [<ARGUMENTS>...]

DESCRIPTION

Démarre un serveur GDB pour interagir avec un périphérique STM32. Exécute le binaire principal du paquet local (src/main.rs).

Si aucun numéro de port n'est spécifié à l'aide de l'option –listen_port, le port par défaut 4242 sera utilisé.

La version 2 de Stlink est utilisée par défaut, sauf si l'option –stlinkv1 est donnée.

OPTIONS

-h, --help
Affiche ce message.
--version
Affiche les informations de version.
-v XX, --verbose=XX
Spécifie un niveau de verbosité spécifique (0..99).
-v, --verbose
Spécifie une journalisation généralement détaillée.
-s X, --stlink_version=X
Choisit la version de stlink à utiliser (par défaut 2).
-1, --stlinkv1
Force la version 1 de stlink.
-p 4242, --listen_port=1234
Définit le port d'écoute du serveur gdb (port par défaut : 4242).
-m, --multi
Définit le serveur gdb en mode étendu. st-util continuera à écouter les connexions après la déconnexion.
-n, --no-reset
Ne réinitialise pas la carte lors de la connexion.
--semihosting
Active la sortie ARM Semihosting sur stdout.

EXEMPLES

Exécute le serveur GDB sur le port 4500 et s'y connecte.

$ st-util -p 4500
$ gdb
(gdb) target extended-remote localhost:4500
