STRCOLL(3P) Manuel du programmeur POSIX STRCOLL(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

strcoll, strcoll_l — comparaison de chaînes en utilisant les informations de classement

SYNOPSIS

#include <string.h>
int strcoll(const char *s1, const char *s2);
int strcoll_l(const char *s1, const char *s2,
    locale_t locale);

DESCRIPTION

Pour strcoll(): La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions strcoll() et strcoll_l() comparent la chaîne pointée par s1 à la chaîne pointée par s2, toutes deux interprétées de manière appropriée pour la catégorie LC_COLLATE de la locale actuelle, ou de la locale représentée par locale, respectivement.

Les fonctions strcoll() et strcoll_l() ne modifient pas le réglage de errno en cas de succès.

Comme aucune valeur de retour n'est réservée pour indiquer une erreur, une application souhaitant vérifier les situations d'erreur doit définir errno à 0, puis appeler strcoll(), ou strcoll_l() puis vérifier errno.

Le comportement est indéfini si l'argument locale passé à strcoll_l() est la locale spéciale LC_GLOBAL_LOCALE ou n'est pas un descripteur de locale valide.

VALEUR DE RETOUR

En cas de succès, strcoll() renvoie un entier supérieur, égal ou inférieur à 0, selon que la chaîne pointée par s1 est supérieure, égale ou inférieure à la chaîne pointée par s2 lorsque les deux sont interprétées de manière appropriée pour la locale actuelle. En cas d'erreur, strcoll() peut définir errno, mais aucune valeur de retour n'est réservée pour indiquer une erreur.

En cas de succès, strcoll_l() renvoie un entier supérieur, égal ou inférieur à 0, selon que la chaîne pointée par s1 est supérieure, égale ou inférieure à la chaîne pointée par s2 lorsque les deux sont interprétées de manière appropriée pour la locale représentée par locale. En cas d'erreur, strcoll_l() peut définir errno, mais aucune valeur de retour n'est réservée pour indiquer une erreur.

ERREURS

Ces fonctions peuvent échouer si :

EINVAL
Les arguments s1 ou s2 contiennent des caractères en dehors du domaine de la séquence de classement.

Les sections suivantes sont informatives.

EXEMPLES

Comparaison de noeuds

L'exemple suivant utilise une fonction définie par l'application, node_compare(), pour comparer deux nœuds en fonction d'un ordre alphabétique du champ string.

#include <string.h>
...
struct node { /* Ce sont les éléments stockés dans la table. */
    char *string;
    int length;
};
...
int node_compare(const void *node1, const void *node2)
{
    return strcoll(((const struct node *)node1)->string,
        ((const struct node *)node2)->string);
}
...

USAGE PAR L'APPLICATION

Les fonctions strxfrm() et strcmp() devraient être utilisées pour trier de grandes listes.
