sous-programme strt03 (caractère uplo, caractère trans, caractère diag, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel scale, réel, dimension( * ) cnorm, réel tscal, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, réel resid)

STRT03

Objectif :

!>
!> STRT03 calcule le résidu pour la solution d'un système triangulaire 
!> mis à l'échelle d'équations A*x = s*b  ou  A'*x = s*b.
!> Ici A est une matrice triangulaire, A' est la transposée de A, s est un
!> scalaire, et x et b sont des matrices de N par NRHS.  Le rapport de test est le
!> maximum sur le nombre de membres de droite de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> où op(A) désigne A ou A' et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  A *x = s*b  (Pas de transposée)
!>          = 'T':  A'*x = s*b  (Transposée)
!>          = 'C':  A'*x = s*b  (Transposée conjuguée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Non-unitaire triangulaire
!>          = 'U':  Unitaire triangulaire
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire principale de dimension n par n du tableau A contient
!>          la matrice triangulaire supérieure, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire principale de dimension n par n du
!>          tableau A contient la matrice triangulaire inférieure, et la partie
!>          strictement supérieure triangulaire de A n'est pas référencée.
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas non plus
!>          référencés et sont supposés être 1.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

SCALE

!>          SCALE est REEL
!>          Le facteur de mise à l'échelle s utilisé pour résoudre le système
!>          triangulaire.
!>

CNORM

!>          CNORM est un tableau REEL, de dimension (N)
!>          Les normes 1 des colonnes de A, sans compter la diagonale.
!>

TSCAL

!>          TSCAL est REEL
!>          Le facteur de mise à l'échelle utilisé pour calculer les normes 1
!>          dans CNORM.  CNORM contient en fait les normes de colonne de TSCAL*A.
!>

X

!>          X est un tableau REEL, de dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau REEL, de dimension (LDB,NRHS)
!>          Les vecteurs du membre de droite pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, de dimension (N)
!>

RESID

!>          RESID est REEL
!>          Le maximum sur le nombre de membres de droite de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
