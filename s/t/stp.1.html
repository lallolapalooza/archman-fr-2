STP(1) Commandes utilisateur STP(1)

NOM

stp - Simple Theorem Prover résolveur SMT

DESCRIPTION

UTILISATION : stp [options] <fichier-entrée>

où l'entrée est SMTLIB1/2 ou CVC selon les options et l'extension du fichier

Options les plus importantes :

-h [ --help ]
affiche cette aide
--version
affiche le numéro de version

Simplifications :

--disable-simplifications
désactive toutes les simplifications
-w [ --switch-word ]
désactive le solveur de niveau mot
-a [ --disable-opt-inc ]
désactive le simplificateur de réécriture
--disable-cbitp
désactive la propagation de bits constants
--disable-equality
désactive la propagation d'égalité
--size-reducing-only
simplifications uniquement réductrices de taille
--unconstrained-variable-elimination arg (=1)
Les variables sans contrainte sont éliminées.
--aig-rewrite-passes arg (=0)
Itérations de réécriture d'AIG à effectuer
--flattening arg (=0)
Active l'aplatissement partagé pour les nœuds d'arité > 2
--rewriting arg (=1)
Active la réécriture partagée
--split-extracts arg (=1)
Crée de nouvelles variables pour certains extraits
--ite-context-simplifications arg (=0)
Utilise ce qui est connu pour être vrai dans un nœud si-alors-sinon pour simplifier les branches vrai ou faux
--aig-core-simplification arg (=0)
Simplifie le cœur propositionnel avec des AIG
--use-intervals arg (=1)
Simplifie avec l'analyse d'intervalles
--pure-literals arg (=1)
Les littéraux purs sont remplacés.
--always-true arg (=0)
Les nœuds qui sont toujours vrais (par ex. affirmés) sont remplacés dans tout le problème par vrai
--merge-same arg (=0)
Utilise des règles simples d'algèbre booléenne pour combiner les conjonctions au niveau supérieur
--bit-blasting-simplification arg (=0)
À mi-chemin de la simplification, convertit en AIG et recherche les bits que les AIG déterminent comme vrais/faux ou identiques à un autre nœud. Si la difficulté est inférieure à ce nombre. -1 signifie toujours.
--size-reducing-fixed-point-limit arg (=0)
Si le nombre de nœuds non-feuilles est inférieur à ce nombre, exécute les simplifications réductrices de taille jusqu'à un point fixe. -1 signifie toujours.
--simplify-to-constants-only arg (=0) Utilise uniquement les simplifications de la
suite potentiellement augmentatrice de taille qui transforme les nœuds en constantes
--difficulty-reversion arg (=1)
Annule les simplifications augmentatrices de taille si elles n'ont pas rendu le problème plus simple

Options du solveur SAT :

--cryptominisat
utilise cryptominisat comme solveur. Utilise uniquement CryptoMiniSat 5.0 ou supérieur (par défaut).
--threads arg (=1)
Nombre de threads pour cryptominisat
--simplifying-minisat
utilise la version de minisat simplifiant installée comme solveur
--minisat
utilise la version de minisat installée comme solveur

Options de raffinement :

-r [ --ackermanize ]
encode avidement les axiomes de lecture de tableau (Ackermannisation)

Options de bit-blasting :

--bb.div-v1 arg (=1)
variante 1 de l'encodage de division non signée
--bb.div-v2 arg (=1)
variante 2 de l'encodage de division non signée
--bb.div-v3 arg (=0)
variante 3 de l'encodage de division non signée
--bb.add-v1 arg (=1)
variante 1 de l'encodage d'addition
--bb.add-v2 arg (=1)
variante 2 de l'encodage d'addition
--bb.vle-v1 arg (=1)
variante 1 de l'encodage de comparaison
--bb.mult-variant arg (=1)
variante de multiplication non signée
--bb.mult-v2 arg (=0)
variante 2 de multiplication non signée
--bb.conjoin-constant arg (=0)
Lorsque la propagation de bits constants détecte un bit constant pendant la construction d'AIG, affirme le nœud AIG et le remplace, dans l'AIG, par le bit constant

Options d'affichage :

-b [ --print-stpinput ]
affiche l'entrée STP sur la sortie standard
--print-back-CVC
affiche l'entrée en format CVC, puis quitte
--print-back-SMTLIB2
affiche l'entrée en format SMT-LIB2, puis quitte
--print-back-SMTLIB1
affiche l'entrée en format SMT-LIB1, puis quitte
--print-back-GDL
affiche le format graphique d'AiSee, puis quitte
--print-back-dot
affiche le format graphique de dotty/neato, puis quitte
-p [ --print-counterex ]
affiche l'exemple de contre-exemple
-y [ --print-counterexbin ]
affiche l'exemple de contre-exemple en binaire
-q [ --print-arrayval ]
affiche l'ordre déclaré des valeurs de tableau
-s [ --print-functionstat ]
affiche les statistiques de fonction
-t [ --print-quickstat ]
affiche des statistiques rapides
-v [ --print-nodes ]
affiche les nœuds
-n [ --print-output ]
Affiche la sortie

Options d'entrée :

-m [ --SMTLIB1 ]
utilise l'analyseur de format SMT-LIB1
--SMTLIB2
utilise l'analyseur de format SMT-LIB2
--CVC
utilise l'analyseur de format CVC

Options de sortie :

--output-CNF
Enregistre le CNF dans output_[0..n].cnf. REMARQUE : les variables ne peuvent pas être remappées, et les problèmes résolus uniquement par le simplificateur de prétraitement ne généreront aucun CNF car le solveur SAT n'est jamais appelé.
--output-bench
Enregistre au format bench d'ABC dans output.bench

Options de sortie :

--exit-after-CNF
Quitte après la génération du CNF.
-g [ --max-num-confl ] arg (=-1)
Nombre de conflits après lesquels le solveur SAT abandonne. -1 signifie jamais.
-k [ --max-time ] arg (=-1)
Nombre de secondes après lequel le solveur SAT abandonne. -1 signifie jamais.
-d [ --check-sanity ]
Construit un contre-exemple et le vérifie.

Options cachées :

--file arg
Fichier d'entrée.

VOIR AUSSI

La documentation complète de stp est maintenue sous forme de manuel Texinfo. Si les programmes info et stp sont correctement installés sur votre site, la commande

info stp

devrait vous donner accès au manuel complet.
