Description Détaillée

template<typename _CharT>

class std::messages< _CharT >"Gabarit de classe primaire messages.

Cette facette encapsule le code pour récupérer les messages à partir des catalogues de messages. La seule chose définie par la norme pour cette facette est l'interface. Toutes les fonctionnalités sous-jacentes sont définies par l'implémentation.

Cette bibliothèque implémente actuellement 3 versions de la facette de message. La première version (gnu) est un wrapper autour de gettext, fourni par libintl. La deuxième version (ieee) est un wrapper autour de catgets. La dernière version (par défaut) n'effectue aucune traduction réelle. Ces implémentations ne sont fournies que pour les instanciations char et wchar_t.

Le gabarit de messages utilise des fonctions virtuelles protégées pour fournir les résultats réels. Les accesseurs publics transmettent l'appel aux fonctions virtuelles. Ces fonctions virtuelles sont des points d'ancrage pour que les développeurs implémentent le comportement requis de la facette de messages.
