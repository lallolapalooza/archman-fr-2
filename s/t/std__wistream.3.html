Toutes les fonctions operator>> (aussi appelées fonctions d'entrée formatée) ont un comportement commun. Chacune commence par construire un objet temporaire de type std::basic_istream::sentry avec le second argument (noskipws) défini à false. Cela a plusieurs effets, se terminant par la définition d'un indicateur de statut ; voir la documentation de sentry pour plus de détails.

Si le statut de sentry est valide, la fonction tente d'extraire les données appropriées pour le type de l'argument.

Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer la levée d'une ios_base::failure) et l'exception d'origine sera relancée si badbit est défini dans le masque d'exceptions.

class std::basic_istream< _CharT, _Traits >"Classe de modèle basic_istream.

Paramètres de modèle

_CharT Type du flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

C'est la classe de base pour tous les flux d'entrée. Elle fournit le formatage texte de tous les types intégrés et communique avec toute classe dérivée de basic_streambuf pour effectuer l'entrée réelle.

template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lancer des exceptions en cas d'erreurs.

Paramètres

__except Le nouveau masque d'exceptions.

Par défaut, les indicateurs d'erreur sont définis silencieusement. Vous pouvez définir un masque d'exceptions pour chaque flux ; si un bit du masque est défini dans les indicateurs d'erreur, une exception de type std::ios_base::failure est lancée.

Si l'indicateur d'erreur est déjà défini lorsque le masque d'exceptions est ajouté, l'exception est immédiatement lancée. Essayez d'exécuter le code suivant sous GCC 3.1 ou version ultérieure :

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

Vérification rapide des erreurs.

Retourne
