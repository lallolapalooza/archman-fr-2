NOM

st-info - Fournit des informations sur les périphériques STLink et STM32 connectés

SYNTAXE

st-info [OPTIONS]

DESCRIPTION

Fournit des informations sur les programmeurs STLink connectés et les périphériques STM32 : code série, openocd, mémoire flash, sram, taille de page, identifiant de puce, description.

OPTIONS

–version
Affiche les informations de version
--flash
Affiche la quantité de mémoire flash disponible sur le périphérique
--sram
Affiche la quantité de mémoire sram disponible sur le périphérique
--descr
Affiche la description textuelle du périphérique
--pagesize
Affiche la taille de page du périphérique
--chipid
Affiche l'identifiant de la puce du périphérique
--serial
Affiche le code série du périphérique
--probe
Affiche les informations résumées des programmeurs et périphériques connectés

EXEMPLES

Afficher les informations sur les programmeurs et périphériques connectés

$ st-info --probe
