STAT(1) Commandes utilisateur STAT(1)

NOM

stat - affiche l'état d'un fichier ou d'un système de fichiers

SYNTAXE

stat [OPTION]... FICHIER...

DESCRIPTION

Affiche l'état d'un fichier ou d'un système de fichiers.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-L, --dereference
suit les liens symboliques
-f, --file-system
affiche l'état du système de fichiers au lieu de l'état du fichier
--cached=MODE
spécifie comment utiliser les attributs mis en cache ; utile sur les systèmes de fichiers distants. Voir MODE ci-dessous
-c --format=FORMAT
utilise le FORMAT spécifié au lieu du format par défaut ; affiche une nouvelle ligne après chaque utilisation de FORMAT
--printf=FORMAT
similaire à --format, mais interprète les séquences d'échappement par barre oblique inverse et n'affiche pas la nouvelle ligne finale obligatoire ; si vous voulez une nouvelle ligne, incluez \n dans FORMAT
-t, --terse
affiche les informations sous forme concise
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

L'argument MODE de --cached peut être : always, never, ou default. 'always' utilisera les attributs mis en cache s'ils sont disponibles, tandis que 'never' essaiera de synchroniser avec les derniers attributs, et 'default' laissera le système de fichiers sous-jacent décider.

Les séquences de format valides pour les fichiers (sans --file-system) :

%a
bits de permission en octal (voir les indicateurs printf '#' et '0')
%A
bits de permission et type de fichier sous forme lisible par l'homme
%b
nombre de blocs alloués (voir %B)
%B
la taille en octets de chaque bloc signalée par %b
%C
contexte de sécurité SELinux en chaîne
%d
numéro de périphérique en décimal (st_dev)
%D
numéro de périphérique en hexadécimal (st_dev)
%Hd
numéro de périphérique principal en décimal
%Ld
numéro de périphérique secondaire en décimal
%f
mode brut en hexadécimal
%F
type de fichier
%g
identifiant de groupe du propriétaire
%G
nom du groupe du propriétaire
%h
nombre de liens physiques
%i
numéro d'inode
%m
point de montage
%n
nom du fichier
%N
nom de fichier entre guillemets avec déréférencement si c'est un lien symbolique
%o
indication de la taille de transfert d'E/S optimale
%s
taille totale, en octets
%r
type de périphérique en décimal (st_rdev)
%R
type de périphérique en hexadécimal (st_rdev)
%Hr
type de périphérique principal en décimal, pour les fichiers spéciaux de caractères/blocs
%Lr
type de périphérique secondaire en décimal, pour les fichiers spéciaux de caractères/blocs
%t
type de périphérique principal en hexadécimal, pour les fichiers spéciaux de caractères/blocs
%T
type de périphérique secondaire en hexadécimal, pour les fichiers spéciaux de caractères/blocs
%u
identifiant utilisateur du propriétaire
%U
nom de l'utilisateur propriétaire
%w
date de création du fichier, lisible par l'homme ; - si inconnue
%W
date de création du fichier, secondes depuis l'Epoch ; 0 si inconnue
%x
date du dernier accès, lisible par l'homme
%X
date du dernier accès, secondes depuis l'Epoch
%y
date de la dernière modification des données, lisible par l'homme
%Y
date de la dernière modification des données, secondes depuis l'Epoch
%z
date du dernier changement d'état, lisible par l'homme
%Z
date du dernier changement d'état, secondes depuis l'Epoch

Séquences de format valides pour les systèmes de fichiers :

%a
blocs libres disponibles pour les non-superutilisateurs
%b
blocs de données totaux dans le système de fichiers
%c
nœuds de fichiers totaux dans le système de fichiers
%d
nœuds de fichiers libres dans le système de fichiers
%f
blocs libres dans le système de fichiers
%i
identifiant du système de fichiers en hexadécimal
%l
longueur maximale des noms de fichiers
%n
nom du fichier
%s
taille du bloc (pour des transferts plus rapides)
%S
taille de bloc fondamentale (pour les comptes de blocs)
%t
type de système de fichiers en hexadécimal
%T
type de système de fichiers sous forme lisible par l'homme

--terse est équivalent au FORMAT suivant :

%n %s %b %f %u %g %D %i %h %t %T %X %Y %Z %W %o

--terse --file-system est équivalent au FORMAT suivant :

%n %i %l %t %s %S %b %f %a %c %d

Votre shell peut avoir sa propre version de stat, qui remplace généralement celle décrite ici. Veuillez consulter la documentation de votre shell pour connaître les options qu'il prend en charge.
