STAPREF(1) Manuel des commandes générales STAPREF(1)

NOM

stapref - référence du langage de script systemtap

SYNOPSIS

stapref

DESCRIPTION

La référence du langage de script systemtap.

LANGAGE

Mots-clés 

• break
• continue
• delete
• else
• exit
• foreach
• for
• function
• global
• private
• if
• in
• next
• probe
• return
• try/catch
• while

Types de données et opérateurs 

Entiers
• var1 = 5
• global var2 = 10
Chaînes de caractères
• var1 = "string1"
• global var2 = "string2"
Tableaux associatifs
• global array1[]
• global array2[SIZE]
• array[index] = 5
Variables de contexte
• $var
• $var$  (forme de chaîne joliment imprimée)
Opérateurs numériques binaires
• * / % + - << >> >>> & ^ | && ||
Opérateurs de chaînes binaires
• . (concaténation de chaînes)
Opérateurs d'affectation numériques
• = += -= *= /= %= >>= <<= &= ^= |= 
Opérateurs d'affectation de chaînes
• = .= 
Opérateurs numériques unaires
• + - ! ~ ++ -- 
Opérateurs de comparaison numériques et de chaînes
• < > <= >= == != 
Opérateurs de correspondance d'expressions régulières
• =~ !~ 
Opérateur ternaire
• cond ? exp1 : exp2
Opérateur d'agroupement
• ( expression )
Opérateurs de tableau
• array[index] (lecture/écriture de tableau)
• [index] in array
Opérateur d'agrégation
• var <<< value

Instructions 

Instructions de saut
• continue
• break
• next  (retour anticipé d'une sonde)
• return expression (d'une fonction)
• try statement catch (message) statement
Instructions de sélection
• if (expression) statement 
• else statement
Instructions d'itération
• foreach (variable in array) statement
• foreach ([var1,var2,...] in array) statement
• for (expression; expression; expression) statement
• while (expression) statement
Instructions de déclaration
• function name (variable : type, ...) { statement }
• function name : type (variable : type, ...) { statement }
• function name : type (variable : type, ...) %{ c_statement %}
• probe probepoint { statement }
• probe label = probepoint { statement }

Structure lexicale 

Commentaires
• # ... commentaire
• // ... commentaire
• /* ... commentaire ... */
Préprocesseur
• %( expression %? true_tokens %: false_tokens %)
• @define label (variable, ...) %{ statement %}

Fonctions intégrées 

Fonctions intégrées d'agrégation
• @avg (variable)
• @count (variable)
• @hist_linear (variable, N, N, N)
• @hist_log (variable)
• @max (variable)
• @min (variable)
• @sum (variable)
Fonctions intégrées de sortie
• print (variable)
• printf (format:string, variable, ...) 
  où format est de la forme : %[flags][width][.precision][length]specifier
• printd (delimiter:string, variable, ...)
• printdln (delimiter:string, variable, ...)
• println ()
• sprint:string (variable)
• sprintf:string (format:string, variable, ...)
Fonctions intégrées d'accès aux variables
• @var ("varname[@src/FILE.c]"[, "module"]) (statique ou global)
• @cast (variable, "type_name"[, "module"])
• @defined (variable)
• @probewrite (variable)
