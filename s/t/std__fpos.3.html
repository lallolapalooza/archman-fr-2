Description détaillée

template<typename _StateT>

class std::fpos< _StateT >"Classe représentant les positions de flux.

La norme ne place aucune exigence sur le paramètre de modèle StateT. Dans cette implémentation, StateT doit être DefaultConstructible, CopyConstructible et Assignable. La norme exige seulement que fpos contienne un membre de type StateT. Dans cette implémentation, il contient également un décalage stocké sous forme d'entier signé.

Paramètres

StateT Type passé à et retourné par state().
