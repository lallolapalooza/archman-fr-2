Objectif :

!>
!> STRSEN réorganise la factorisation de Schur réelle d'une matrice réelle
!> A = Q*T*Q**T, de sorte qu'un cluster sélectionné de valeurs propres apparaisse dans
!> les blocs diagonaux principaux de la matrice quasi-triangulaire supérieure T,
!> et que les colonnes principales de Q forment une base orthonormée de la
!> sous-espace invariant correspondant.
!>
!> Optionnellement, la routine calcule les nombres de condition réciproques des
!> cluster de valeurs propres et/ou du sous-espace invariant.
!>
!> T doit être sous forme canonique de Schur (telle que retournée par SHSEQR), c'est-à-dire
!> bloc triangulaire supérieur avec des blocs diagonaux de 1x1 et 2x2 ; chaque
!> bloc diagonal 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonale de signe opposé.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour le
!>          cluster de valeurs propres (S) ou pour le sous-espace invariant (SEP) :
!>          = 'N' : aucun ;
!>          = 'E' : pour les valeurs propres uniquement (S) ;
!>          = 'V' : pour le sous-espace invariant uniquement (SEP) ;
!>          = 'B' : pour les valeurs propres et le sous-espace invariant (S et
!>                 SEP).
!>

COMPQ

!>          COMPQ est CHARACTER*1
!>          = 'V' : met à jour la matrice Q des vecteurs de Schur ;
!>          = 'N' : ne met pas à jour Q.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, dimension (N)
!>          SELECT spécifie les valeurs propres dans le cluster sélectionné. Pour
!>          sélectionner une valeur propre réelle w(j), SELECT(j) doit être mis à
!>          .TRUE.. Pour sélectionner une paire de valeurs propres complexes conjuguées
!>          w(j) et w(j+1), correspondant à un bloc diagonal 2x2,
!>          soit SELECT(j), soit SELECT(j+1), soit les deux doivent être mis à
!>          .TRUE. ; une paire de valeurs propres complexes conjuguées doit être
!>          soit incluse dans le cluster, soit exclue.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau RÉEL, dimension (LDT,N)
!>          À l'entrée, la matrice quasi-triangulaire supérieure T, sous forme canonique
!>          de Schur.
!>          À la sortie, T est écrasé par la matrice réorganisée T, à nouveau sous forme
!>          canonique de Schur, avec les valeurs propres sélectionnées dans les
!>          blocs diagonaux principaux.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau RÉEL, dimension (LDQ,N)
!>          À l'entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          À la sortie, si COMPQ = 'V', Q a été post-multiplié par la
!>          matrice de transformation orthogonale qui réorganise T ; les
!>          M colonnes principales de Q forment une base orthonormée pour le
!>          sous-espace invariant spécifié.
!>          Si COMPQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q.
!>          LDQ >= 1 ; et si COMPQ = 'V', LDQ >= N.
!>

WR

!>          WR est un tableau RÉEL, dimension (N)
!>

WI

!>          WI est un tableau RÉEL, dimension (N)
!>
!>          Les parties réelle et imaginaire, respectivement, des valeurs propres réorganisées
!>          de T. Les valeurs propres sont stockées dans le même ordre que sur la diagonale
!>          de T, avec WR(i) = T(i,i) et, si
!>          T(i:i+1,i:i+1) est un bloc diagonal 2x2, WI(i) > 0 et
!>          WI(i+1) = -WI(i). Notez que si une valeur propre complexe est
!>          suffisamment mal conditionnée, sa valeur peut différer
!>          significativement de sa valeur avant réorganisation.
!>

M

!>          M est un ENTIER
!>          La dimension du sous-espace invariant spécifié.
!>          0 < = M <= N.
!>

S

!>          S est un RÉEL
!>          Si JOB = 'E' ou 'B', S est une borne inférieure du nombre de condition réciproque
!>          pour le cluster de valeurs propres sélectionné.
!>          S ne peut pas sous-estimer le nombre de condition réciproque vrai
!>          de plus d'un facteur sqrt(N). Si M = 0 ou N, S = 1.
!>          Si JOB = 'N' ou 'V', S n'est pas référencé.
!>

SEP

!>          SEP est un RÉEL
!>          Si JOB = 'V' ou 'B', SEP est le nombre de condition réciproque estimé
!>          du sous-espace invariant spécifié. Si
!>          M = 0 ou N, SEP = norm(T).
!>          Si JOB = 'N' ou 'E', SEP n'est pas référencé.
!>

WORK

!>          WORK est un tableau RÉEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          Si JOB = 'N', LWORK >= max(1,N) ;
!>          si JOB = 'E', LWORK >= max(1,M*(N-M)) ;
!>          si JOB = 'V' ou 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) retourne le LIWORK optimal.
!>

LIWORK

!>          LIWORK est un ENTIER
!>          La dimension du tableau IWORK.
!>          Si JOB = 'N' ou 'E', LIWORK >= 1 ;
!>          si JOB = 'V' ou 'B', LIWORK >= max(1,M*(N-M)).
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement la taille optimale du tableau IWORK,
!>          retourne cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur lié à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : la réorganisation de T a échoué car certaines valeurs propres sont trop
!>               proches pour être séparées (le problème est très mal conditionné) ;
!>               T peut avoir été partiellement réorganisée, et WR et WI
!>               contiennent les valeurs propres dans le même ordre qu'en T ; S et
!>               SEP (si demandés) sont mis à zéro.
!>

Détails supplémentaires :

!>
!>  STRSEN collecte d'abord les valeurs propres sélectionnées en calculant une
!>  transformation orthogonale Z pour les déplacer dans le coin supérieur gauche de T.
!>  Autrement dit, les valeurs propres sélectionnées sont les valeurs propres de T11
!>  dans :
!>
!>          Z**T * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  où N = n1+n2 et Z**T signifie la transposée de Z. Les n1 premières colonnes
!>  de Z engendrent le sous-espace invariant spécifié.
!>

NAME

strsen — computes the Schur factorization of a real matrix with selected blocks of eigenvalues.

SYNOPSIS

    SUBROUTINE STRSEN( JOB, COMPQ, SELECT, N, A, LDA, LDWORK, S, SEP, WORK,
                      INFO )
    LOGICAL            SELECT( * )
    CHARACTER          JOB, COMPQ
    INTEGER            N, LDA, LDWORK, INFO
    REAL               A( LDA, * ), S, SEP, WORK( * )

Function/Subroutine Documentation

STRSEN is a real version of the subroutine `ZTRSEN'.

It computes the Schur factorization of a real matrix A with selected blocks of eigenvalues. The matrix A is overwritten by its Schur form T.

The function can reorder the Schur decomposition so that the selected eigenvalues are in the top left n1 block of the matrix T.

The function can also compute the reciprocal condition numbers of the invariant subspace corresponding to the selected eigenvalues and the reciprocal condition number of the average of the eigenvalues.

The selected eigenvalues are those for which SELECT(i) is true.

The matrix A must be in upper Schur form.

For a matrix A = Q*T*Q**T, where T is in real Schur form, STRSEN reorders T to T = Z**T*T*Z and computes the Schur decomposition of A as A = (Q*Z)*(Z**T*T*Z)*(Q*Z)**T.

The first n1 columns of Q*Z are the orthonormal basis of the invariant subspace associated with the selected eigenvalues.

Arguments

JOB
(input) CHARACTER*1
Specifies the Schur form.
If JOB = 'E', then only the eigenvalues are computed.
If JOB = 'N', then the overwritten matrix A is the Schur form T.
COMPQ
(input) CHARACTER*1
Specifies whether to compute the matrix Q.
If COMPQ = 'V', then the matrix Q is computed.
If COMPQ = 'N', then Q is not computed.
SELECT
(input) LOGICAL array, dimension (N)
Specifies which eigenvalues are to be selected.
To select the i-th eigenvalue, SELECT(i) must be true.
N
(input) INTEGER
The order of the matrix A.
A
(input/output) REAL array, dimension (LDA, N)
On entry, the upper triangular matrix A. On exit, A is overwritten by its Schur form T.
LDA
(input) INTEGER
The leading dimension of the array A.
LDWORK
(input) INTEGER
The dimension of the workspace array WORK. LDWORK must be at least max(N, 1).
WORK
(workspace) REAL array, dimension (LDWORK).
S
(output) REAL
Reciprocal condition number of the average of the eigenvalues of T11.
SEP
(output) REAL
Reciprocal condition number of the right invariant subspace.
INFO
(output) INTEGER
0
Successful exit.
> 0
If INFO = i, the i-th eigenvalue could not be brought into the upper left corner, and the Schur decomposition is not perturbed.

Information about the computation

The function computes the Schur factorization of a real matrix A.

The eigenvalues selected are those for which SELECT(i) is true.

If JOB = 'N', the matrix A is overwritten by its Schur form T. The eigenvalues corresponding to TRUE values in SELECT are moved to the leading diagonal of T. The corresponding invariant subspace is spanned by the first n1 columns of T.

If COMPQ = 'V', the matrix Q is computed.

If JOB = 'N', the matrix A is overwritten by its Schur form T. The eigenvalues are sorted in descending order on the diagonal.

The invariant subspace of A corresponding to the selected eigenvalues is returned in the first n1 columns of Q.

The reciprocal condition number of the average of the eigenvalues of T11 is returned in S.

The reciprocal condition number of the right invariant subspace spanned by the first n1 columns of Q is returned in SEP.

An approximate error bound for the computed average of the eigenvalues of T11 is given by EPS*norm(A)/S, where EPS is the machine precision.

An approximate bound on the maximum angular error in the computed right invariant subspace is given by EPS*norm(A)/SEP.

The matrix T is partitioned as follows:

                         P = ( T11  T12 ) n1
                             (  0   T22 ) n2
                               n1   n2

T11 is n1xn1 and T22 is n2xn2. The eigenvalues of T11 are those selected by SELECT.

The reciprocal condition number of the average of the eigenvalues

The reciprocal condition number of the average of the eigenvalues of T11 may be returned in S. S lies between 0 (very badly conditioned) and 1 (very well conditioned). It is computed as follows. First we compute R so that

                         P = ( I  R ) n1
                             ( 0  0 ) n2
                               n1 n2

is the projector on the invariant subspace associated with T11. R is the solution of the Sylvester equation:

                        T11*R - R*T22 = T12.

Let F-norm(M) denote the Frobenius-norm of M and 2-norm(M) denote the two-norm of M. Then S is computed as the lower bound

                      (1 + F-norm(R)**2)**(-1/2)

on the reciprocal of 2-norm(P), the true reciprocal condition number. S cannot underestimate 1 / 2-norm(P) by more than a factor of sqrt(N).

An approximate error bound for the computed average of the eigenvalues of T11 is

                         EPS * norm(T) / S

where EPS is the machine precision.

The reciprocal condition number of the invariant subspace

The reciprocal condition number of the right invariant subspace spanned by the first n1 columns of Z (or of Q*Z) is returned in SEP. SEP is defined as the separation of T11 and T22:

                     sep( T11, T22 ) = sigma-min( C )

where sigma-min(C) is the smallest singular value of the n1*n2-by-n1*n2 matrix

     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )

I(m) is an m by m identity matrix, and kprod denotes the Kronecker product. We estimate sigma-min(C) by the reciprocal of an estimate of the 1-norm of inverse(C). The true reciprocal 1-norm of inverse(C) cannot differ from sigma-min(C) by more than a factor of sqrt(n1*n2).

When SEP is small, small changes in T can cause large changes in the invariant subspace. An approximate bound on the maximum angular error in the computed right invariant subspace is

                      EPS * norm(T) / SEP
