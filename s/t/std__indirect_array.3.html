Description détaillée

template<class _Tp>

class std::indirect_array< _Tp >"Référence à un sous-ensemble arbitraire d'un tableau.

Un indirect_array est une référence aux éléments réels d'un tableau spécifiés par un tableau ordonné d'indices. La façon d'obtenir un indirect_array est d'appeler operator[](valarray<size_t>) sur un valarray. L'indirect_array retourné permet ensuite d'effectuer des opérations sur le sous-ensemble d'éléments référencés dans le valarray d'origine.

Par exemple, si un indirect_array est obtenu en utilisant le tableau (4,2,0) comme argument, et qu'il est ensuite assigné à un tableau contenant (1,2,3), alors le tableau sous-jacent aura array[0]==3, array[2]==2 et array[4]==1.

NOM

std::indirect_array — Représente un tableau d'éléments accédés via des indices indirects.

SYNOPIS

#include <iterator>

template< class RandomIt >
class indirect_array {
public:
    // types
    using value_type = std::iter_value_t<RandomIt>;
    using reference = std::iter_reference_t<RandomIt>;
    using const_reference = std::iter_reference_t<RandomIt>;
    using iterator = RandomIt;
    using const_iterator = RandomIt;
    using size_type = std::ptrdiff_t;
    using difference_type = std::ptrdiff_t;

    // constructeurs
    constexpr indirect_array( RandomIt first, RandomIt last );

    // opérateurs
    constexpr reference operator[]( size_type n ) const;
};

DESCRIPTION

La classe std::indirect_array est une classe de conteneur d'adaptateur qui représente un tableau d'éléments d'une autre séquence (par exemple, std::vector, std::array) qui sont accédés via des indices indirects. Elle est principalement utilisée pour le sous-verrouillage de tableaux par l'intermédiaire d'un autre tableau, qui contient les indices des éléments qui doivent être accédés.

PARAMÈTRES DE MODÈLE

  • RandomIt : un type d'itérateur aléatoire vers le début de la séquence sous-jacente.

FONCTIONS MEMBRES

  • indirect_array( RandomIt first, RandomIt last ) : Constructeur. Construit un objet indirect_array qui référence les éléments de la séquence située entre first (inclus) et last (exclus).
  • reference operator[]( size_type n ) const : Accès aux éléments. Retourne une référence à l'élément à l'indice n de la séquence sous-jacente, en utilisant le tableau d'indices indirects.

DESCRIPTION DÉTAILLÉE

La classe std::indirect_array n'est pas une classe de conteneur standard à utiliser directement pour stocker des éléments. Il s'agit plutôt d'un adaptateur d'itérateur qui permet de créer une vue d'un autre conteneur, où les éléments sont accédés via un ensemble de positions spécifiées par un autre conteneur (généralement un tableau d'entiers).

Son utilisation principale est lors de l'application d'opérations de type « tri par sélection » ou de re-ordonnancement où les indices des éléments à modifier ou à lire sont stockés dans une structure de données séparée.

DOCUMENTATION DES FONCTIONS MEMBRES

constexpr indirect_array( RandomIt first, RandomIt last )

Ce constructeur initialise un objet indirect_array. first et last sont des itérateurs aléatoires qui définissent la plage d'indices indirects. Le constructeur suppose que ces indices sont valides pour la séquence sous-jacente.

constexpr reference operator[]( size_type n ) const

Cet opérateur retourne une référence à l'élément de la séquence sous-jacente qui est spécifié par le n-ième indice dans la plage d'indices indirects.
