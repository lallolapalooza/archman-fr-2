strfromd(3) Manuel des fonctions de bibliothèque strfromd(3)

NOM

strfromd, strfromf, strfroml - convertir une valeur à virgule flottante en chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int strfromd(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, double fp);
int strfromf(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, float fp);
int strfroml(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, long double fp);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

strfromd(), strfromf(), strfroml():

    __STDC_WANT_IEC_60559_BFP_EXT__

DESCRIPTION

Ces fonctions convertissent une valeur à virgule flottante, fp, en une chaîne de caractères, str, avec une chaîne de format configurable. Au plus n caractères sont stockés dans str.

L'octet nul de terminaison ('\0') est écrit si et seulement si n est suffisamment grand, sinon la chaîne écrite est tronquée à n caractères.

Les fonctions strfromd(), strfromf(), et strfroml() sont équivalentes à


snprintf(str, n, format, fp);

à l'exception de la chaîne de format.

Format de la chaîne de format

La chaîne de format doit commencer par le caractère '%'. Ceci est suivi d'une précision optionnelle qui commence par le caractère point (.), suivi d'un entier décimal optionnel. Si aucun entier n'est spécifié après le caractère point, une précision de zéro est utilisée. Enfin, la chaîne de format doit avoir l'un des spécificateurs de conversion a, A, e, E, f, F, g, ou G.

Le spécificateur de conversion est appliqué en fonction du type à virgule flottante indiqué par le suffixe de la fonction. Par conséquent, contrairement à snprintf(), la chaîne de format n'a pas de caractère modificateur de longueur. Voir snprintf(3) pour une description détaillée de ces spécificateurs de conversion.

L'implémentation est conforme à la norme C99 sur la conversion des valeurs NaN (Not a Number) et infini :

Si fp est un NaN, +NaN, ou -NaN, et que f (ou a, e, g) est le spécificateur de conversion, la conversion se fait en "nan", "nan", ou "-nan", respectivement. Si F (ou A, E, G) est le spécificateur de conversion, la conversion se fait en "NAN" ou "-NAN".

De même, si fp est infini, il est converti en [-]inf ou [-]INF.

Une chaîne de format malformée entraîne un comportement indéfini.

VALEUR DE RETOUR

Les fonctions strfromd(), strfromf(), et strfroml() retournent le nombre de caractères qui auraient été écrits dans str si n avait été suffisamment grand, sans compter l'octet nul de terminaison. Ainsi, une valeur de retour de n ou plus signifie que la sortie a été tronquée.

NOTES

Ces fonctions tiennent compte de la catégorie LC_NUMERIC de la locale actuelle.

EXEMPLES

Pour convertir la valeur 12.1 en type float en chaîne de caractères en utilisant la notation décimale, résultant en "12.100000" :


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%f", 12.1);

Pour convertir la valeur 12.3456 en type float en chaîne de caractères en utilisant la notation décimale avec deux chiffres de précision, résultant en "12.35" :


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%.2f", 12.3456);

Pour convertir la valeur 12.345e19 en type double en chaîne de caractères en utilisant la notation scientifique avec zéro chiffre de précision, résultant en "1E+20" :


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromd(s, ssize, "%.E", 12.345e19);

VOIR AUSSI

atof(3), snprintf(3), strtod(3)

    strfromd

    strfromd - Formater un nombre flottant en une chaîne de caractères

    Nom

    strfromd, strfromf, strfroml - Formater un nombre flottant en une chaîne de caractères

    Bibliothèque

    Bibliothèque C standard (libc, -lc)

    Syntaxe

    #include <stdio.h>

char *strfromd(char *restrict s, size_t n,
              const char *restrict format, double fp);
char *strfromf(char *restrict s, size_t n,
              const char *restrict format, float fp);
char *strfroml(char *restrict s, size_t n,
              const char *restrict format, long double fp);

    Description

    Les fonctions strfromd(), strfromf() et strfroml() génèrent une représentation de chaîne de caractères en virgule flottante de la valeur fp (de type double, float ou long double respectivement), et stockent le résultat dans le tampon s qui a une taille de n octets. Le format de la chaîne résultante est spécifié par la chaîne format.

    La chaîne format doit être une chaîne de spécification de format de printf(3) valide qui commence par %. Les spécificateurs de conversion a, A, e, E, f, F, g, G, n, N, x, X, u, U, o, O, s, S, c, C, p, P, % sont autorisés. Les spécificateurs de longueur hh, h, l, ll, j, z, t, L, q, I, IL32, IL64 ne sont pas autorisés.

    Si la chaîne format ne produit pas une chaîne de longueur inférieure à n, y compris le caractère nul de fin, les fonctions retournent une chaîne vide (c'est-à-dire qu'elles écrivent '\0' dans s) et retournent NULL.

    Si n est égal à zéro, le comportement est indéfini.

    Si s est NULL, le comportement est indéfini.

    Les fonctions retournent un pointeur vers la chaîne résultante, qui est toujours s.

    La valeur fp est convertie en une chaîne de caractères en virgule flottante selon le format spécifié. Les valeurs spéciales telles que NaN (Not a Number) et l'infini sont gérées.

    Valeur de retour

    Les fonctions strfromd(), strfromf() et strfroml() retournent un pointeur vers la chaîne s. Si la génération de la chaîne échoue en raison d'une troncature ou d'une chaîne de format invalide, elles retournent NULL et s contient une chaîne vide.

    Exemples

    #include <stdio.h>

int main(void)
{
    char buf[50];
    double pi = 3.14159265358979323846;

    // Formatage en notation scientifique
    if (strfromd(buf, sizeof(buf), "%.15e", pi) != NULL) {
        printf("Pi en notation scientifique: %s\n", buf);
    }

    // Formatage en notation fixe
    if (strfromd(buf, sizeof(buf), "%.10f", pi) != NULL) {
        printf("Pi en notation fixe: %s\n", buf);
    }

    // Formatage automatique (g ou G)
    if (strfromd(buf, sizeof(buf), "%g", pi) != NULL) {
        printf("Pi en format automatique: %s\n", buf);
    }

    // Exemple de troncature
    if (strfromd(buf, 5, "%.15e", pi) != NULL) {
        printf("Ce message ne devrait pas apparaître.\n");
    } else {
        printf("Échec du formatage en raison d'une troncature.\n");
    }

    return 0;
}

    Conformité

    Ces fonctions ont été introduites dans la norme C11.
