sous-programme stgsja (character jobu, character jobv, character jobq, integer m, integer p, integer n, integer k, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real tola, real tolb, real, dimension( * ) alpha, real, dimension( * ) beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) work, integer ncycle, integer info)

STGSJA

Objectif :

!>
!> STGSJA calcule la décomposition en valeurs singulières généralisée (GSVD)
!> de deux matrices réelles triangulaires supérieures (ou trapézoïdales) A et B.
!>
!> À l'entrée, on suppose que les matrices A et B ont les formes suivantes,
!> qui peuvent être obtenues par le sous-programme de prétraitement SGGSVP
!> à partir d'une matrice générale M par N, A, et d'une matrice P par N, B :
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0 ;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0 ;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> où la matrice K par K, A12, et la matrice L par L, B13, sont triangulaires
!> supérieures non singulières ; A23 est triangulaire supérieure L par L si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure (M-K) par L.
!>
!> À la sortie,
!>
!>        U**T *A*Q = D1*( 0 R ),    V**T *B*Q = D2*( 0 R ),
!>
!> où U, V et Q sont des matrices orthogonales.
!> R est une matrice triangulaire supérieure non singulière, et D1 et D2 sont
!> des matrices « diagonales », qui sont des structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> où
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N) et R33 est stocké
!>     (  0  R22 R23 )
!> dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> Le calcul des matrices de transformation orthogonales U, V ou Q
!> est optionnel. Ces matrices peuvent soit être formées explicitement, soit être
!> post-multipliées dans les matrices d'entrée U1, V1, ou Q1.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U' : U doit contenir une matrice orthogonale U1 à l'entrée, et
!>                  le produit U1*U est retourné ;
!>          = 'I' : U est initialisé à la matrice identité, et la
!>                  matrice orthogonale U est retournée ;
!>          = 'N' : U n'est pas calculé.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V' : V doit contenir une matrice orthogonale V1 à l'entrée, et
!>                  le produit V1*V est retourné ;
!>          = 'I' : V est initialisé à la matrice identité, et la
!>                  matrice orthogonale V est retournée ;
!>          = 'N' : V n'est pas calculé.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q' : Q doit contenir une matrice orthogonale Q1 à l'entrée, et
!>                  le produit Q1*Q est retourné ;
!>          = 'I' : Q est initialisé à la matrice identité, et la
!>                  matrice orthogonale Q est retournée ;
!>          = 'N' : Q n'est pas calculé.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B. P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B. N >= 0.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          K et L spécifient les sous-blocs dans les matrices d'entrée A et B :
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) et B13 = B(1:L,N-L+1:N)
!>          de A et B, dont la GSVD va être calculée par STGSJA.
!>          Voir Détails supplémentaires.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)

!>          À la sortie, A(N-K+1:N,1:MIN(K+L,M) ) contient la matrice
!>          triangulaire R ou une partie de R. Voir Objectif pour les détails.
!>

LDA

!>          LDA est INTEGER

!>

B

!>          B est un tableau REAL, dimension (LDB,N)

!>          une partie de R. Voir Objectif pour les détails.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).

TOLA

!>          TOLA est REAL
!>

!>
!>          TOLA et TOLB sont les critères de convergence pour la procédure

!>              TOLB = max(P,N)*norm(B)*MACHEPS.
!>

ALPHA

!>          ALPHA est un tableau REAL, dimension (N)
!>

BETA

!>          BETA est un tableau REAL, dimension (N)
!>
!>          À la sortie, ALPHA et BETA contiennent les paires de valeurs
!>          singulières généralisées de A et B ;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          et si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          ou si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          De plus, si K+L < N,
!>            ALPHA(K+L+1:N) = 0 et
!>            BETA(K+L+1:N)  = 0.
!>

U

!>          U est un tableau REAL, dimension (LDU,M)
!>          À l'entrée, si JOBU = 'U', U doit contenir une matrice U1 (généralement
!>          la matrice orthogonale retournée par SGGSVP).
!>          À la sortie,
!>          si JOBU = 'I', U contient la matrice orthogonale U ;
!>          si JOBU = 'U', U contient le produit U1*U.
!>          Si JOBU = 'N', U n'est pas référencé.
!>
