strfry(3) Manuel des fonctions de bibliothèque strfry(3)

NOM

strfry - mélanger une chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <string.h>
char *strfry(char *string);

DESCRIPTION

La fonction strfry() mélange le contenu de string en échangeant aléatoirement des caractères dans la chaîne. Le résultat est un anagramme de string.

VALEUR DE RETOUR

La fonction strfry() retourne un pointeur vers la chaîne mélangée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strfry () Sécurité des threads MT-Safe

NORMES

GNU.

VOIR AUSSI
