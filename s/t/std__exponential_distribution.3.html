Description détaillée

Classe modèle pour la distribution exponentielle.

Cette distribution produit des nombres aléatoires avec la fonction de densité de probabilité

f(x; \lambda) = \lambda e^{-\lambda x}

pour x \ge 0 et \lambda > 0.

Le paramètre \lambda est appelé paramètre de taux. Le paramètre de modèle _RealType désigne le type du nombre à virgule flottante à utiliser pour la distribution. Le type par défaut est double.
