strfmon(3) Manuel des fonctions de bibliothèque strfmon(3)

NOM

strfmon, strfmon_l - convertir une valeur monétaire en chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <monetary.h>
ssize_t strfmon(size_t size;
                char s[restrict size], size_t size,
                const char *restrict format, ...);
ssize_t strfmon_l(size_t size;
                char s[restrict size], size_t size, locale_t l,
                const char *restrict format, ...);

DESCRIPTION

La fonction strfmon() formate le montant monétaire spécifié conformément à la locale actuelle et à la spécification de format format, et place le résultat dans le tableau de caractères s d'une taille de size octets.

La fonction strfmon_l() effectue la même tâche, mais utilise la locale spécifiée par l. Le comportement de strfmon_l() est indéfini si l est l'objet de locale spécial LC_GLOBAL_LOCALE (voir duplocale(3)) ou s'il ne s'agit pas d'un handle d'objet de locale valide.

Les caractères ordinaires dans format sont copiés dans s sans conversion. Les spécificateurs de conversion sont introduits par un caractère '%'. Immédiatement après, il peut y avoir zéro ou plusieurs des flags suivants :

=f
Le caractère à un octet f est utilisé comme caractère de remplissage numérique (à utiliser avec une précision à gauche, voir ci-dessous). Lorsqu'il n'est pas spécifié, le caractère espace est utilisé.
^
N'utilise aucun caractère de regroupement qui pourrait être défini pour la locale actuelle. Par défaut, le regroupement est activé.
( ou +
Le flag ( indique que les montants négatifs doivent être placés entre parenthèses. Le flag + indique que les signes doivent être gérés de la manière par défaut, c'est-à-dire que les montants sont précédés de l'indication de signe de la locale, par exemple, rien pour le positif, "-" pour le négatif.
!
Omet le symbole monétaire.
-
Justifie à gauche tous les champs. La justification par défaut est à droite.

Ensuite, il peut y avoir une largeur de champ : une chaîne de chiffres décimaux spécifiant une largeur de champ minimale en octets. La valeur par défaut est 0. Un résultat plus petit que cette largeur est rempli avec des espaces (à gauche, sauf si le flag de justification à gauche a été donné).

Ensuite, il peut y avoir une précision à gauche de la forme "#" suivie d'une chaîne de chiffres décimaux. Si le nombre de chiffres à gauche du séparateur décimal est inférieur à cela, la représentation est remplie à gauche avec le caractère de remplissage numérique. Les caractères de regroupement ne sont pas comptés dans cette largeur de champ.

Ensuite, il peut y avoir une précision à droite de la forme "." suivie d'une chaîne de chiffres décimaux. Le montant formaté est arrondi au nombre spécifié de chiffres avant le formatage. La valeur par défaut est spécifiée dans les éléments frac_digits et int_frac_digits de la locale actuelle. Si la précision à droite est de 0, aucun séparateur décimal n'est imprimé. (Le séparateur décimal ici est déterminé par LC_MONETARY, et peut différer de celui spécifié par LC_NUMERIC.)

Enfin, la spécification de conversion doit être terminée par un caractère de conversion. Les trois caractères de conversion sont

%
(Dans ce cas, la spécification entière doit être exactement "%%".) Insère un caractère '%' dans la chaîne de résultat.
i
Un argument de type double est converti en utilisant le format de monnaie internationale de la locale.
n
Un argument de type double est converti en utilisant le format de monnaie nationale de la locale.

VALEUR DE RETOUR

La fonction strfmon() renvoie le nombre de caractères placés dans le tableau s, sans inclure le octet nul de terminaison, à condition que la chaîne, y compris l'octet nul de terminaison, tienne. Sinon, elle définit errno à E2BIG, renvoie -1, et le contenu du tableau est indéfini.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strfmon () Sécurité des threads Locale MT-Safe
strfmon_l () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

EXEMPLES

L'appel


strfmon(buf, sizeof(buf), "[%^=*#6n] [%=*#6i]",
        1234.567, 1234.567);

produit


[€ **1234,57] [EUR **1 234,57]

dans la locale nl_NL. Les locales de_DE, de_CH, en_AU et en_GB produisent


[ **1234,57 €] [ **1.234,57 EUR]
[ Fr. **1234.57] [ CHF **1'234.57]
[ $**1234.57] [ AUD**1,234.57]
[ £**1234.57] [ GBP**1,234.57]
