STRCPY(3P) Manuel du programmeur POSIX STRCPY(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

stpcpy, strcpy — copie une chaîne et renvoie un pointeur vers la fin du résultat

SYNTAXE

#include <string.h>
char *stpcpy(char *restrict s1, const char *restrict s2);
char *strcpy(char *restrict s1, const char *restrict s2);

DESCRIPTION

Pour strcpy() : Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions stpcpy() et strcpy() copient la chaîne pointée par s2 (y compris le caractère NUL de fin) dans le tableau pointé par s1.

Si la copie a lieu entre des objets qui se chevauchent, le comportement est indéfini.

VALEUR RENVOYÉE

La fonction stpcpy() renvoie un pointeur vers le caractère NUL de fin copié dans le tampon s1.

La fonction strcpy() renvoie s1.

Aucune valeur de retour n'est réservée pour indiquer une erreur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Construction d'un message multipartite dans un seul tampon

#include <string.h>
#include <stdio.h>
int
main (void)
{
    char buffer [10];
    char *name = buffer;
    name = stpcpy (stpcpy (stpcpy (name, "glace"),"-"), "crème");
    puts (buffer);
    return 0;
}

Initialisation d'une chaîne

L'exemple suivant copie la chaîne "----------" dans la variable permstring.

#include <string.h>
...
static char permstring[11];
...
strcpy(permstring, "----------");
...

Stockage d'une clé et de données

L'exemple suivant alloue de l'espace pour une clé à l'aide de malloc() puis utilise strcpy() pour y placer la clé. Ensuite, il alloue de l'espace pour les données à l'aide de malloc(), et utilise strcpy() pour y placer les données. (La fonction définie par l'utilisateur dbfree() libère la mémoire précédemment allouée à un tableau de type struct element *.)

#include <string.h>
#include <stdlib.h>
#include <stdio.h>
...
/* Structure utilisée pour lire et stocker des données. */
struct element {
    char *key;
    char *data;
};
struct element *tbl, *curtbl;
char *key, *data;
int count;
...
void dbfree(struct element *, int);
...
if ((curtbl->key = malloc(strlen(key) + 1)) == NULL) {
    perror("malloc"); dbfree(tbl, count); return NULL;
}
strcpy(curtbl->key, key);
if ((curtbl->data = malloc(strlen(data) + 1)) == NULL) {
    perror("malloc"); free(curtbl->key); dbfree(tbl, count); return NULL;
}
strcpy(curtbl->data, data);
...

UTILISATION PAR L'APPLICATION

Les mouvements de caractères sont effectués différemment selon les implémentations. Ainsi, les déplacements qui se chevauchent peuvent réserver des surprises.

Cette version est alignée sur la norme ISO C ; cela n'affecte pas la compatibilité avec les applications XPG3. La détection fiable des erreurs par cette fonction n'a jamais été garantie.
