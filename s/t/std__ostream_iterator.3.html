Description détaillée

template<typename _Tp, typename _CharT = char, typename _Traits = char_traits<_CharT>>

class std::ostream_iterator< _Tp, _CharT, _Traits >"Fournit des sémantiques d'itérateur de sortie pour les flux.

Cette classe fournit un itérateur pour écrire dans un ostream. Le type Tp est le seul type écrit par cet itérateur et un operator<<(Tp) doit être défini.

Paramètres de modèle

_Tp Le type à écrire dans l'ostream.
_CharT Le type de caractère de l'ostream.
_Traits Les traits de caractère de l'ostream.
