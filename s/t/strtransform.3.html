NOM

strtransform - convertir une chaîne en sa valeur mappée

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

void strtransform(char * dest, char const * src);

DESCRIPTION

Chaque caractère de la chaîne d'entrée est mappé et le caractère mappé est placé dans la sortie. Le nom de cette fonction est mappé sur option_strtransform afin de ne pas entrer en conflit avec l'espace de noms POSIX.

La source et la destination peuvent être les mêmes.

dest
chaîne de sortie
src
chaîne d'entrée

aucune.
