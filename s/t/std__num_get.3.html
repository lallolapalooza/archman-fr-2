DESCRIPTION DÉTAILLÉE

template<typename _CharT, typename _InIter>

class std::num_get< _CharT, _InIter >"Gabarit de classe principal num_get.

Ce facet encapsule le code permettant d'analyser et de retourner un nombre à partir d'une chaîne. Il est utilisé par les opérateurs d'extraction numérique des flux d'entrée.

Le gabarit num_get utilise des fonctions virtuelles protégées pour fournir les résultats réels. Les accesseurs publics transmettent l'appel aux fonctions virtuelles. Ces fonctions virtuelles sont des points d'accroche permettant aux développeurs d'implémenter le comportement requis du facet num_get.

template<typename _CharT, typename _InIter> iter_type std::num_get< _CharT, _InIter >::get (iter_type __in, iter_type __end, ios_base & __io, ios_base::iostate & __err, bool & __v) const [inline]

Analyse numérique. Analyse le flux d'entrée dans la variable booléenne v. Elle le fait en appelant num_get::do_get().

Si ios_base::boolalpha est défini, tente de lire ctype<CharT>::truename() ou ctype<CharT>::falsename(). Définit v à vrai ou faux en cas de succès. Définit err à ios_base::failbit si la lecture de la chaîne échoue. Définit err à ios_base::eofbit si le flux est vidé.

Si ios_base::boolalpha n'est pas défini, procède comme pour la lecture d'un long, sauf si la valeur est 1, auquel cas v est défini à vrai, si la valeur est 0, v est défini à faux, et sinon err est défini à ios_base::failbit.

Analyse numérique. Analyse le flux d'entrée dans la variable entière v. Elle le fait en appelant num_get::do_get().

Les caractères d'entrée sont analysés comme le spécificateur g de scanf. Le modificateur de longueur de type correspondant est également utilisé.

Le caractère de point décimal utilisé est numpunct::decimal_point(). Le regroupement des chiffres est interprété selon numpunct::grouping() et numpunct::thousands_sep(). Si le motif des groupes de chiffres n'est pas cohérent, err est défini à ios_base::failbit.

Si l'analyse de la chaîne produit une valeur valide pour v, v est définie. Sinon, err est défini à ios_base::failbit et v reste inchangée. err est défini à ios_base::eofbit si le flux est vidé.

Analyse numérique. Analyse le flux d'entrée dans la variable entière v. Elle le fait en appelant num_get::do_get().

L'analyse est affectée par les paramètres définis dans io.

L'analyse de base est affectée par la valeur de io.flags() & ios_base::basefield. Si elle est égale à ios_base::oct, analyse comme le spécificateur o de scanf. Sinon si égale à ios_base::hex, analyse comme le spécificateur X. Sinon si basefield est égal à 0, analyse comme le spécificateur i. Sinon, analyse comme d pour les types signés et u pour les types non signés. Le modificateur de longueur de type correspondant est également utilisé.

Le regroupement des chiffres est interprété selon numpunct::grouping() et numpunct::thousands_sep(). Si le motif des groupes de chiffres n'est pas cohérent, err est défini à ios_base::failbit.

Si l'analyse de la chaîne produit une valeur valide pour v, v est définie. Sinon, err est défini à ios_base::failbit et v reste inchangée. err est défini à ios_base::eofbit si le flux est vidé.

La classe std::num_get est une facette de locale qui effectue le formatage numérique d'entrées.

Le modèle de classe prend deux arguments :

_CharT
Le type de caractère utilisé par le flux.
_InIter
Le type d'itérateur utilisé pour lire le flux.

La facette num_get est utilisée par les fonctions d'extraction d'entrée d'E/S C++ pour lire les valeurs numériques à partir des flux. Par exemple, l'opérateur operator>> pour int, long, double, etc., appelle num_get::get.

La fonction do_get est la fonction virtuelle pure qui doit être implémentée par les spécialisations de num_get.

template<typename _CharT, typename _InIter> iter_type std::num_get< _CharT, _InIter >::get (iter_type __in, iter_type __end, ios_base & __io, ios_base::iostate & __err, bool& __v) const [inline]

Analyse numérique. Analyse le flux d'entrée dans la variable booléenne v. Elle le fait en appelant num_get::do_get().

L'analyse est affectée par les paramètres du drapeau dans io.

L'analyse de base est affectée par la valeur de io.flags() & ios_base::basefield. Si égal à ios_base::oct, analyse comme le spécificateur o de scanf. Sinon si égal à ios_base::hex, analyse comme le spécificateur X. Sinon si basefield est égal à 0, analyse comme le spécificateur i. Sinon, analyse comme d pour les types signés et u pour les types non signés. Le modificateur de longueur de type correspondant est également utilisé.

Le groupement des chiffres est interprété selon numpunct::grouping() et numpunct::thousands_sep(). Si le modèle de groupes de chiffres n'est pas cohérent, définit err sur ios_base::failbit.

Si l'analyse de la chaîne produit une valeur valide pour v, v est définie. Sinon, définit err sur ios_base::failbit et laisse v inchangé. Définit err sur ios_base::eofbit si le flux est vidé.
