stationlist.xml(5) Manuel des formats de fichiers stationlist.xml(5)

NOM

stationlist.xml - fichier de configuration des stations de tvtime

SYNTAXE

~/.tvtime/stationlist.xml

DESCRIPTION

Le fichier stationlist.xml contient la configuration des informations de chaînes pour les cartes d'acquisition avec tuners. Il contient une liste des chaînes actives ainsi que leurs fréquences, informations de renumérotation et nom de la chaîne. Le fichier stationlist.xml est mis à jour par tvtime à l'exécution pour sauvegarder les paramètres entre les sessions. Pour cette raison, vous ne devez pas modifier ce fichier pendant que tvtime est en cours d'exécution, car vos modifications pourraient être écrasées.

Ce fichier est créé ou mis à jour chaque fois que les informations de chaînes sont modifiées dans tvtime. Cela se produit lors de la renumérotation d'une chaîne, de l'utilisation du scanner de chaînes ou de l'activation ou désactivation manuelle d'une chaîne spécifique dans la liste.

Les paramètres des chaînes sont enregistrés spécifiquement pour la norme et la table de fréquences.


<?xml version="1.0"?>
<!DOCTYPE stationlist PUBLIC "-//tvtime//DTD stationlist 1.0//EN"
"http://tvtime.sourceforge.net/DTD/stationlist.dtd">
<stationlist xmlns="http://tvtime.sourceforge.net/DTD/">
<list norm="NTSC" frequencies="US-Cable">
<station ... />
... liste de stations
</list>
</stationlist>

C'est-à-dire que chaque combinaison norme/fréquence aura sa propre section dans le fichier de configuration. Le nom des fréquences n'est pas spécial, vous pouvez avoir frequencies="foobar" et lancer
tvtime -f foobar
fera ce qu'il faut. La norme, cependant, doit correspondre à la norme utilisée.

Les entrées dans une liste sont de la forme suivante :


<station name="CNN" active="1" position="18"
band="US Cable" channel="18"/>
<station name="DSF" active="1" position="12"
band="VHF E2-E12" channel="E12"/>

STATIONS

Chaque station a ses propres propriétés qui doivent être définies.

nom
Le nom lisible par l'homme de la station actuelle.
actif
Lorsqu'il est défini sur 1, le canal est actif. Pour désactiver le canal, définissez cette valeur sur 0.
position
Ce réglage spécifie la position qu'occupe le canal sur le cadran. Cela permet aux utilisateurs de mapper arbitrairement un canal particulier à une position particulière sur le cadran.
bande
canal

Des canaux personnalisés peuvent être inclus manuellement en spécifiant la fréquence en mégahertz :


<station name="2" active="1" position="0"
band="Custom" channel="55.69MHz"/>

norme
Une norme par canal peut être spécifiée dans stationlist. Ceci est pour les stations qui reçoivent à la fois des stations PAL et SECAM, de sorte qu'elles puissent choisir le format d'encodage couleur par canal. Les seules valeurs valides ici sont PAL ou SECAM.
reseau
Définit le nom du réseau pour l'affichage OSD. Dans les régions NTSC, ceci est défini à partir des informations XDS dans la VBI si le décodage VBI est activé.
appel
Définit les lettres d'appel du réseau pour l'affichage OSD. Dans les régions NTSC, ceci est défini à partir des informations XDS dans la VBI si le décodage VBI est activé.
xmltvid
Définit l'identifiant de chaîne XMLTV pour associer cette chaîne si tvtime ne peut pas faire l'association automatiquement. Pour la définition de chaîne suivante dans un fichier XMLTV :


<channel id="I10119.labs.zap2it.com">
<display-name>CICA</display-name>
<display-name>TV Ontario (CICA)</display-name>
<display-name>Canadian Independent</display-name>
</channel>

Une entrée stationlist associée serait :


<station name="2" active="1" position="0"
band="Custom" channel="55.69MHz"
xmltvid="I10119.labs.zap2it.com"/>
