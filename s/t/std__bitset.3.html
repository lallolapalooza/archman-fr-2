class std::bitset< _Nb >"La classe bitset représente une séquence de bits de taille fixe.

(Notez que bitset ne répond *pas* aux exigences formelles d'un conteneur. Principalement, il lui manque des itérateurs.)

L'argument de template, Nb, peut être n'importe quel nombre non négatif, spécifiant le nombre de bits (par exemple, "0", "12", "1024*1024").

Dans le cas général non optimisé, le stockage est alloué par blocs de taille mot. Soit B le nombre de bits dans un mot, alors (Nb+(B-1))/B mots seront utilisés pour le stockage. B - Nb bits ne sont pas utilisés. (Ce sont les bits de poids fort dans le mot le plus élevé.) C'est un invariant de classe que ces bits inutilisés soient toujours à zéro.

Si vous considérez bitset comme un simple tableau de bits, soyez conscient que votre image mentale est inversée : un bitset se comporte de la même manière

Introduction

Bitsets are a fairly obvious means of manipulating binary data. The conceptually simplest way to handle binary data is to make it an integer. However, integers are not flexible enough for arbitrary-length binary data; for example, a 64-bit integer cannot represent a sequence of 100 bits. A bitset is a direct representation of a sequence of bits, which can be arbitrarily long.

Bitsets behave like other standard containers in that they have a size and are addressable by an index. However, they differ from other containers in the way that bits are indexed. The bit at index 0 is the least significant / right-hand bit, and the bit at index Nb-1 is the most significant / left-hand bit. Thus, unlike other containers, a bitset's index counts from right to left, to put it very loosely.

This behavior is preserved when translating to and from strings. For example, the first line of the following program probably prints b('a') is 0001100001 on a modern ASCII system.

#include <bitset>
#include <iostream>
#include <sstream>
using namespace std;
int main()
{
    long         a = 'a';
    bitset<10>   b(a);
    cout << "b('a') is " << b << endl;
    ostringstream s;
    s << b;
    string  str = s.str();
    cout << "index 3 in the string is " << str[3] << " but\n"
         << "index 3 in the bitset is " << b[3] << endl;
}

Also see: https://gcc.gnu.org/onlinedocs/libstdc++/manual/ext_containers.html for a description of extensions.

Most of the actual code isn't contained in bitset<> itself, but in the base class _Base_bitset. The base class works with whole words, not with individual bits. This allows us to specialize _Base_bitset for the important special case where the bitset is only a single word.

Extra confusion can result due to the fact that the storage for _Base_bitset is a regular array, and is indexed as such. This is carefully encapsulated.

Detailed Description

The template class bitset provides a way to store and manipulate a sequence of bits.

The bits are indexed from 0, starting from the least significant bit. The size of the bitset is fixed at compile time by the template parameter.

For example:

  bitset<16> b; // A 16-bit bitset, all initialized to 0.
  b[0] = 1;       // Set the least significant bit to 1.
  b[15] = b[0];   // Set the most significant bit to the value of the least significant bit.

The character representation of the bitset is a string of `0`s and `1`s. The character at index 0 corresponds to the most significant bit, and the character at index size()-1 corresponds to the least significant bit.
