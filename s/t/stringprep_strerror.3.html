stringprep_strerror(3)

Paquet: libidn

Licences: GPL3, LGPL

stringprep_strerror(3) libidn stringprep_strerror(3)

NOM

stringprep_strerror - fonction API

SYNTAXE

#include <stringprep.h>

const char * stringprep_strerror(Stringprep_rc rc);

ARGUMENTS

Stringprep_rc rc
un code de retour Stringprep_rc.

DESCRIPTION

Convertit un code d'erreur entier en une chaîne de texte. Cette chaîne peut être utilisée pour afficher un message de diagnostic à l'utilisateur.

STRINGPREP_OK

Opération réussie. Cette valeur est garantie d'être toujours zéro, les autres sont garanties de contenir des valeurs non nulles, à des fins de comparaison logique.

STRINGPREP_CONTAINS_UNASSIGNED

La chaîne contient des points de code Unicode non assignés, ce qui est interdit par le profil.

STRINGPREP_CONTAINS_PROHIBITED

La chaîne contient des points de code interdits par le profil.

STRINGPREP_BIDI_BOTH_L_AND_RAL

La chaîne contient des points de code avec une catégorie bidirectionnelle contradictoire.

STRINGPREP_BIDI_LEADTRAIL_NOT_RAL

Le caractère de début et de fin de la chaîne n'est pas de la bonne catégorie bidirectionnelle.

STRINGPREP_BIDI_CONTAINS_PROHIBITED

Contient des points de code interdits détectés par le code bidirectionnel.

STRINGPREP_TOO_SMALL_BUFFER

Le tampon fourni à la fonction était trop petit. Cela indique généralement un problème dans l'application appelante.

STRINGPREP_PROFILE_ERROR

Le profil stringprep était incohérent. Cela indique généralement une erreur interne dans la bibliothèque.

STRINGPREP_FLAG_ERROR

Le drapeau fourni entrait en conflit avec le profil. Cela indique généralement un problème dans l'application appelante.

STRINGPREP_UNKNOWN_PROFILE

Le nom de profil fourni n'était pas connu de la bibliothèque.

STRINGPREP_ICONV_ERROR

Erreur de conversion de l'encodage des caractères.

STRINGPREP_NFKC_FAILED

L'opération NFKC de Unicode a échoué. Cela indique généralement une erreur interne dans la bibliothèque.

STRINGPREP_MALLOC_ERROR

L'appel à malloc() a manqué de mémoire. C'est généralement une erreur fatale.

Valeur de retour : Retourne un pointeur vers une chaîne allouée statiquement contenant une description de l'erreur associée au code de retour rc.
