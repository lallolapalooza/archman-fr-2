!>
!> STRSEN réorganise la factorisation de Schur réelle d'une matrice réelle
!> A = Q*T*Q**T, de sorte qu'un cluster sélectionné de valeurs propres apparaisse dans
!> les blocs diagonaux principaux de la matrice quasi-triangulaire supérieure T,
!> et que les colonnes principales de Q forment une base orthonormée du
!> sous-espace invariant correspondant.
!>
!> Optionnellement, la routine calcule les réciproques des nombres de condition
!> du cluster de valeurs propres et/ou du sous-espace invariant.
!>
!> T doit être sous forme canonique de Schur (telle que retournée par SHSEQR), c'est-à-dire,
!> bloc triangulaire supérieur avec des blocs diagonaux de 1x1 et 2x2 ; chaque
!> bloc diagonal de 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonale de signe opposé.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour le
!>          cluster de valeurs propres (S) ou pour le sous-espace invariant (SEP) :
!>          = 'N': aucun ;
!>          = 'E': pour les valeurs propres uniquement (S) ;
!>          = 'V': pour le sous-espace invariant uniquement (SEP) ;
!>          = 'B': pour les valeurs propres et le sous-espace invariant (S et
!>                 SEP).
!>

COMPQ

!>          COMPQ est CHARACTER*1
!>          = 'V': mettre à jour la matrice Q des vecteurs de Schur ;
!>          = 'N': ne pas mettre à jour Q.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          SELECT spécifie les valeurs propres du cluster sélectionné. Pour
!>          sélectionner une valeur propre réelle w(j), SELECT(j) doit être mis à
!>          .TRUE.. Pour sélectionner une paire de valeurs propres complexes conjuguées
!>          w(j) et w(j+1), correspondant à un bloc diagonal de 2x2,
!>          soit SELECT(j) soit SELECT(j+1), soit les deux, doivent être mis à
!>          .TRUE. ; une paire de valeurs propres complexes conjuguées doit être
!>          soit incluse dans le cluster, soit exclue.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau REAL, de dimension (LDT,N)
!>          À l'entrée, la matrice quasi-triangulaire supérieure T, sous forme canonique
!>          de Schur.
!>          À la sortie, T est écrasé par la matrice réorganisée T, à nouveau sous forme canonique
!>          de Schur, avec les valeurs propres sélectionnées dans les blocs diagonaux principaux.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau REAL, de dimension (LDQ,N)
!>          À l'entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          À la sortie, si COMPQ = 'V', Q a été post-multipliée par la
!>          matrice de transformation orthogonale qui réorganise T ; les
!>          M colonnes principales de Q forment une base orthonormée pour le
!>          sous-espace invariant spécifié.
!>          Si COMPQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.
!>          LDQ >= 1 ; et si COMPQ = 'V', LDQ >= N.
!>

WR

!>          WR est un tableau REAL, de dimension (N)
!>

WI

!>          WI est un tableau REAL, de dimension (N)
!>
!>          Les parties réelle et imaginaire, respectivement, des valeurs propres réorganisées
!>          de T. Les valeurs propres sont stockées dans le même ordre que sur la diagonale de T,
!>          avec WR(i) = T(i,i) et, si T(i:i+1,i:i+1) est un bloc diagonal de 2x2, WI(i) > 0 et
!>          WI(i+1) = -WI(i). Notez que si une valeur propre complexe est suffisamment mal conditionnée,
!>          sa valeur peut différer significativement de sa valeur avant réorganisation.
!>

M

!>          M est INTEGER
!>          La dimension du sous-espace invariant spécifié.
!>          0 <= M <= N.
!>

S

!>          S est REAL
!>          Si JOB = 'E' ou 'B', S est une borne inférieure du réciproque du nombre de condition
!>          pour le cluster sélectionné de valeurs propres.
!>          S ne sous-estime pas le véritable réciproque du nombre de condition
!>          de plus d'un facteur de sqrt(N). Si M = 0 ou N, S = 1.
!>          Si JOB = 'N' ou 'V', S n'est pas référencé.
!>

SEP

!>          SEP est REAL
!>          Si JOB = 'V' ou 'B', SEP est une estimation du réciproque du nombre de condition
!>          du sous-espace invariant spécifié. Si
!>          M = 0 ou N, SEP = norm(T).
!>          Si JOB = 'N' ou 'E', SEP n'est pas référencé.
!>

WORK

!>          WORK est un tableau REAL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si JOB = 'N', LWORK >= max(1,N) ;
!>          si JOB = 'E', LWORK >= max(1,M*(N-M)) ;
!>          si JOB = 'V' ou 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) retourne la valeur optimale LIWORK.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si JOB = 'N' ou 'E', LIWORK >= 1 ;
!>          si JOB = 'V' ou 'B', LIWORK >= max(1,M*(N-M)).
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement la taille optimale du tableau IWORK,
!>          retourne cette valeur dans la première entrée du tableau IWORK, et
!>          aucun message d'erreur relatif à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          = 1 : la réorganisation de T a échoué car certaines valeurs propres sont trop
!>               proches pour être séparées (le problème est très mal conditionné) ;
!>               T a peut-être été partiellement réorganisée, et WR et WI
!>               contiennent les valeurs propres dans le même ordre qu'en T ; S et
!>               SEP (si demandés) sont mis à zéro.
!>

strsen(3)

NAME

strsen — computes the Schur factorization of a general matrix T and reorders the Schur factorization so that some eigenvalues are in the top-left corner of T.

SYNOPSIS

  SUBROUTINE STRSEN( JOB, COMPQ, SELECT, N, T, LDT, WR, WI, Q, LDQ,
                      SL, SR, SEP, WORK, LWORK, INFO )
      CHARACTER          * 1
      INTEGER            N, LDT, LDQ, LWORK, INFO
      REAL               T( LDT, * ), Q( LDQ, * ), WR( * ), WI( * ),
                         SL, SR, SEP, WORK( * )
      LOGICAL            SELECT( * )

Function/Subroutine Documentation

STRSEN reorders the Schur factorization of a general matrix T in accordance with the given selection criteria, and computes the number of selected and non-selected eigenvalues. It also computes the cluster of selected eigenvalues, and optionally, the matrix Q and the reciprocal condition numbers for the cluster of eigenvalues and the corresponding right invariant subspace.

T must be an upper triangular matrix.

Uses the algorithm from.

If A is a general matrix, then T is its Schur factor, obtained from the Schur factorization A = Q*T*Q**T.

If the Schur factorization is A = Q*T*Q**T, then the reordered Schur factorization is given by A = (Q*Z)*(Z**T*T*Z)*(Q*Z)**T.

The matrix Z is obtained from the call to STRSEN. The first n1 columns of Z form an orthonormal basis of the right invariant subspace corresponding to the selected eigenvalues.

The matrix Q*Z is updated by STRSER in the call to STRSEN.

The selected eigenvalues are the diagonal elements of the updated upper triangular matrix T.

The function computes the reciprocal condition number for the cluster of eigenvalues.

The reciprocal condition number is defined by the separation of the matrices T11 and T22, where

                         T = ( T11  T12 ) n1
                             (  0   T22 ) n2
                               n1  n2

Here n1 is the number of selected eigenvalues.

The function computes the reciprocal condition number for the right invariant subspace.

This subroutine is not guaranteed to work if the selected eigenvalues are not contained in a contiguous block on the diagonal of T.

Arguments:

[In] JOB
CHARACTER*1. Specifies whether to compute the reciprocal condition numbers for the cluster of eigenvalues.
JOB = 'N': do not compute the reciprocal condition numbers.
JOB = 'Y': compute the reciprocal condition numbers.
[In] COMPQ
CHARACTER*1. Specifies whether to compute the matrix Q.
COMPQ = 'N': do not compute Q.
COMPQ = 'V': compute Q.
[In] SELECT
LOGICAL array, dimension (N).
On input, SELECT declares which eigenvalues are to be selected. For each i, if SELECT(i) is true, then T(i,i) corresponds to an eigenvalue to be selected.
On output, SELECT(i) is true if T(i,i) is in the selected cluster. If JOB = 'Y', then the output value of SELECT is the same as the input value.
[In] N
INTEGER. The order of the matrix T. N >= 0.
If N = 0, STRSER does nothing.
[In,Out] T
REAL array, dimension (LDT, N).
On input, the upper triangular matrix T.
On output, T is reordered according to the selection criterion specified by SELECT. The selected eigenvalues are moved to the leading diagonal positions.
[In] LDT
INTEGER. The leading dimension of the array T. LDT >= max(1, N).
[Out] WR
REAL array, dimension (N).
WR(i) is the real part of the i-th eigenvalue of the original matrix T.
On output, WR contains the reordered eigenvalues.
[Out] WI
REAL array, dimension (N).
WI(i) is the imaginary part of the i-th eigenvalue of the original matrix T.
On output, WI contains the reordered eigenvalues.
[In,Out] Q
REAL array, dimension (LDQ, N).
On input, Q is an N x N matrix. If COMPQ = 'V', then Q must contain the orthogonal matrix Q of the original Schur factorization.
On output, if COMPQ = 'V', then Q has been updated to the matrix Z*Q, where Z is the orthogonal matrix representing the permutation.
[In] LDQ
INTEGER. The leading dimension of the array Q.
If COMPQ = 'V', LDQ >= max(1, N).
[Out] SL
REAL.
If JOB = 'Y', SL is the reciprocal condition number for the cluster of eigenvalues. SL lies between 0 and 1. SL = 1.0 means that the cluster of eigenvalues is well-conditioned.
[Out] SR
REAL.
If JOB = 'Y', SR is the reciprocal condition number for the corresponding right invariant subspace. SR lies between 0 and 1. SR = 1.0 means that the subspace is well-conditioned.
[Out] SEP
REAL.
If JOB = 'Y', SEP is the reciprocal condition number for the right invariant subspace. SEP lies between 0 and 1. SEP = 1.0 means that the subspace is well-conditioned.
[Out] WORK
REAL array, dimension (LWORK).
On exit, WORK(1) contains the minimum value of LWORK.
[In] LWORK
INTEGER. The dimension of the array WORK.
LWORK >= max(1, N).
[Out] INFO
INTEGER.
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value.
= 1: the Schur form could not be reordered to put all the selected eigenvalues in the top-left corner. This may happen if the problem is ill-conditioned. INC = 1 indicates that the eigenvalues cannot be reordered. INC = 0 means that the eigenvalues can be reordered.

If T has been obtained from the real Schur factorization of a matrix A = Q*T*Q**T, then the reordered real Schur factorization of A is given by A = (Q*Z)*(Z**T*T*Z)*(Q*Z)**T, and the first n1 columns of Q*Z span the corresponding invariant subspace of A.

The reciprocal condition number of the average of the eigenvalues of T11 may be returned in S. S lies between 0 (very badly conditioned) and 1 (very well conditioned). It is computed as follows. First we compute R so that

                                P = ( I  R ) n1
                                    ( 0  0 ) n2
                                      n1 n2

is the projector on the invariant subspace associated with T11. R is the solution of the Sylvester equation:

                                T11*R - R*T22 = T12.

Let F-norm(M) denote the Frobenius-norm of M and 2-norm(M) denote the two-norm of M. Then S is computed as the lower bound

                                 (1 + F-norm(R)**2)**(-1/2)

on the reciprocal of 2-norm(P), the true reciprocal condition number. S cannot underestimate 1 / 2-norm(P) by more than a factor of sqrt(N).

An approximate error bound for the computed average of the eigenvalues of T11 is

                                         EPS * norm(T) / S

where EPS is the machine precision.

The reciprocal condition number of the right invariant subspace spanned by the first n1 columns of Z (or of Q*Z) is returned in SEP. SEP is defined as the separation of T11 and T22:

                                     sep( T11, T22 ) = sigma-min( C )

where sigma-min(C) is the smallest singular value of the n1*n2-by-n1*n2 matrix

                             C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )

I(m) is an m by m identity matrix, and kprod denotes the Kronecker product. We estimate sigma-min(C) by the reciprocal of an estimate of the 1-norm of inverse(C). The true reciprocal 1-norm of inverse(C) cannot differ from sigma-min(C) by more than a factor of sqrt(n1*n2).

When SEP is small, small changes in T can cause large changes in the invariant subspace. An approximate bound on the maximum angular error in the computed right invariant subspace is

                                         EPS * norm(T) / SEP
