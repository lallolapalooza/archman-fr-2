Description détaillée

Un pointeur opaque vers une exception arbitraire.

Le nom réel de ce type n'est pas spécifié, donc l'alias std::exception_ptr doit être utilisé pour y faire référence.

Depuis

C++11 (mais utilisable en C++98 comme extension GCC)
