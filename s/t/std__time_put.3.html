Description détaillée

template<typename _CharT, typename _OutIter>

class std::time_put< _CharT, _OutIter >"Modèle de classe primaire time_put.

Cette facette encapsule le code pour formater et afficher les dates et heures selon les formats utilisés par strftime().

Le modèle time_put utilise des fonctions virtuelles protégées pour fournir les résultats réels. Les accesseurs publics transmettent l'appel aux fonctions virtuelles. Ces fonctions virtuelles sont des points d'ancrage pour les développeurs afin d'implémenter le comportement requis de la facette time_put.

Detailed Description

This is the base class for time formatting facets. This class is an abstract base class. You instantiate derived classes like std::time_put_byname.

Derived classes must implement the do_put virtual function.

This class also serves as a namespace for id, which is a locale::id object used to identify the facet.
