NOM

stellarium - Un planétarium réaliste en temps réel

SYNOPSIS

stellarium [OPTIONS]

DESCRIPTION

Stellarium est un logiciel libre sous GPL qui rend des ciels réalistes en temps réel avec OpenGL. Il est disponible pour Linux/Unix, Windows et MacOSX. Avec Stellarium, vous voyez réellement ce que vous pouvez voir à l'œil nu, avec des jumelles ou un petit télescope.

OPTIONS

-v, --version
Affiche le nom du programme et la version, puis quitte.
-h, --help
Affiche un bref synopsis des options du programme, puis quitte.
-c, --config-file fichier
Utilise fichier pour le nom du fichier de configuration au lieu du fichier par défaut config.ini.
-u, --user-dir répertoire
Utilise répertoire au lieu du répertoire de données utilisateur par défaut ($HOME/.stellarium/ sur les systèmes d'exploitation *nix).
--verbose
Sortie de diagnostic encore plus détaillée dans le fichier journal (en particulier pour la gestion multimédia).
--scale-gui facteur d'échelle
Met à l'échelle l'interface graphique selon le facteur d'échelle.
-d, --dump-opengl-details
Affiche des informations sur le support d'OpenGL dans le fichier journal. Utilisez ceci si vous avez des problèmes graphiques et que vous souhaitez envoyer un rapport de bug.
-f, --full-screen oui|non
Avec l'argument oui ou non, remplace le paramètre de plein écran dans le fichier de configuration. Le paramètre est enregistré dans le fichier de configuration et sera donc le défaut pour les exécutions ultérieures de Stellarium.
--screenshot-dir répertoire
Définit le répertoire dans lequel les captures d'écran seront sauvegardées sur répertoire, au lieu du défaut (qui est $HOME sur les systèmes d'exploitation *nix).
--startup-script script
Spécifie le nom du script de démarrage.
--home-planet nom-planète
Spécifie la planète d'observation. nom-planète est un nom en anglais et doit faire référence à un objet défini dans le fichier ssystem.ini.
--altitude alt
Spécifie l'altitude initiale de l'observateur, où alt est l'altitude en mètres.
--longitude lon
Spécifie la longitude initiale de l'observateur, où lon est la longitude. Le format est illustré par cet exemple : +4d16'12" qui fait référence à 4 degrés, 16 minutes et 12 secondes d'arc Est. Les longitudes Ouest doivent être préfixées par "-".
--latitude lat
Spécifie la latitude initiale de l'observateur, où lat est la latitude. Le format est illustré par cet exemple : +53d58'16.65" qui fait référence à 53 degrés, 58 minutes et 16.65 secondes d'arc Nord. Les latitudes Sud doivent être préfixées par "-".
--list-landscapes
Affiche une liste de noms de paysages et quitte.
--landscape nom
Démarre Stellarium en utilisant le paysage nom. Référez-vous à --list-landscapes pour les noms possibles.
--sky-date date
Spécifie la date du ciel au format AAAAMMJJ.
--sky-time heure
Spécifie l'heure du ciel au format HH:MM:SS.
--fov fov
Spécifie le champ de vision (fov degrés).
--projection-type p
Spécifie le type de projection, p. Les valeurs permises pour p sont : equalarea, stereographic, fisheye, cylinder, mercator, perspective, et orthographic.
--restore-defaults
Supprime le fichier config.ini existant et utilise les valeurs par défaut.

VALEUR DE RETOUR

0
Terminé avec succès.
non 0
Une sorte d'erreur.

FICHIERS

Remarque : les emplacements des fichiers sur les systèmes d'exploitation non-*nix (y compris OSX) peuvent varier. Veuillez vous référer au Guide de l'utilisateur de Stellarium pour plus de détails, ainsi qu'à des informations sur la façon de personnaliser les fichiers de données de Stellarium.

/usr/share/stellarium/
Ceci est le répertoire des données d'installation défini à la compilation.
$HOME/.stellarium/
Ceci est le répertoire des données utilisateur, qui peut être remplacé en utilisant l'option de ligne de commande -u. Il contient les paramètres de l'utilisateur, les paysages supplémentaires, les scripts, et peut aussi être utilisé pour remplacer les fichiers de données fournis avec l'installation par défaut.
$HOME/.stellarium/config.ini
Le fichier de configuration principal par défaut est config.ini. Reportez-vous à -c ci-dessus pour utiliser un nom de fichier différent et à -u pour utiliser un répertoire de données utilisateur différent.
$HOME/
Le répertoire de captures d'écran par défaut. Référez-vous à --screenshot-dir pour utiliser un chemin différent.
