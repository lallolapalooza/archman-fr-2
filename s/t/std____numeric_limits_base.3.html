Description Détaillée

Partie de std::numeric_limits.

Les membres statiques constants peuvent être utilisés comme des expressions constantes entières.

Note

Il s'agit d'une classe distincte pour des raisons d'efficacité ; vous ne devriez accéder à ces membres qu'en tant qu'instanciation de la classe std::numeric_limits.

Documentation des Données Membres

int std::__numeric_limits_base::digits [static], [constexpr]

Le nombre de chiffres de base qui peuvent être représentés sans changement : pour les types entiers, le nombre de bits non signe dans la mantisse ; pour les types flottants, le nombre de chiffres de base dans la mantisse.

Référencé par std::generate_canonical(), std::independent_bits_engine< _RandomNumberEngine, __w, _UIntType >::operator()(), std::operator<<(), et std::linear_congruential_engine< uint_fast32_t, 16807UL, 0UL, 2147483647UL >::seed().

bool std::__numeric_limits_base::is_bounded [static], [constexpr]

Vrai si l'ensemble des valeurs représentables par le type est fini. Tous les types intégrés sont bornés, cette membre serait fausse pour les types à précision arbitraire.

bool std::__numeric_limits_base::is_exact [static], [constexpr]

Vrai si le type utilise une représentation exacte. Tous les types entiers sont exacts, mais tous les types exacts ne sont pas entiers. Par exemple, les représentations rationnelles et à exposant fixe sont exactes mais pas entières.

bool std::__numeric_limits_base::is_iec559 [static], [constexpr]

Vrai si et seulement si le type respecte la norme IEC 559, aussi connue sous le nom de IEEE 754. (Ne concerne que les types flottants.)

bool std::__numeric_limits_base::is_integer [static], [constexpr]

Vrai si le type est entier.

bool std::__numeric_limits_base::is_modulo [static], [constexpr]

Vrai si le type est modulo. Un type est modulo si, pour toute opération impliquant +, -, ou * sur des valeurs de ce type dont le résultat tomberait en dehors de l'intervalle [min(),max()], la valeur retournée diffère de la valeur réelle par un multiple entier de max() - min() + 1. Sur la plupart des machines, c'est faux pour les types flottants, vrai pour les entiers non signés, et vrai pour les entiers signés. Voir PR22200 concernant les entiers signés.

bool std::__numeric_limits_base::is_signed [static], [constexpr]

Vrai si le type est signé.

bool std::__numeric_limits_base::is_specialized [static], [constexpr]

Ce sera vrai pour tous les types fondamentaux (qui ont des spécialisations), et faux pour tout le reste.

Detailed Description

This structure is the base class for std::numeric_limits. It defines constants and enumerations that are common to all numeric types.

Member Data Documentation

int std::__numeric_limits_base::max_digits10 [static], [constexpr]

Le nombre de chiffres en base 10 requis pour garantir que les valeurs qui diffèrent soient toujours différenciées.

int std::__numeric_limits_base::max_exponent [static], [constexpr]

Le plus grand entier positif tel que le radical élevé à la puissance (un moins cet entier) soit un nombre à virgule flottante fini représentable.

int std::__numeric_limits_base::max_exponent10 [static], [constexpr]

Le plus grand entier positif tel que 10 élevé à cette puissance soit dans la plage des nombres à virgule flottante finis représentables.

int std::__numeric_limits_base::min_exponent [static], [constexpr]

Le plus petit entier négatif tel que le radical élevé à la puissance (un moins cet entier) soit un nombre à virgule flottante normalisé.

int std::__numeric_limits_base::min_exponent10 [static], [constexpr]

Le plus petit entier négatif tel que 10 élevé à cette puissance soit dans la plage des nombres à virgule flottante normalisés.

int std::__numeric_limits_base::radix [static], [constexpr]

Pour les types entiers, spécifie la base de la représentation. Pour les types flottants, spécifie la base de la représentation de l'exposant.

float_round_style std::__numeric_limits_base::round_style [static], [constexpr]

Voir std::float_round_style pour plus d'informations. Ceci n'est significatif que pour les types flottants ; les types entiers seront tous round_toward_zero.

bool std::__numeric_limits_base::tinyness_before [static], [constexpr]

Vrai si la petitesse est détectée avant l'arrondi. (voir IEC 559)

bool std::__numeric_limits_base::traps [static], [constexpr]

Vrai si le piégeage est implémenté pour ce type.
