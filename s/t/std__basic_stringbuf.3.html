classe std::basic_stringbuf< _CharT, _Traits, _Alloc >"Le travail réel d'entrée et de sortie (pour std::string).

Paramètres du modèle

_CharT Type de flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.
_Alloc Type d'allocateur, par défaut allocator<_CharT>.

Cette classe associe une ou deux de ses séquences d'entrée et de sortie à une séquence de caractères, qui peut être initialisée à partir d'une std::basic_string, ou rendue disponible sous forme de celle-ci. (Paraphrasé de [27.7.1]/1.)

Pour cette classe, les modes d'ouverture (de type ios_base::openmode) ont 'in' défini si la séquence d'entrée peut être lue, et 'out' défini si la séquence de sortie peut être écrite.

template<class _CharT, class _Traits, class _Alloc> basic_stringbuf< _CharT, _Traits, _Alloc >::int_type std::basic_stringbuf< _CharT, _Traits, _Alloc >::overflow (int_type __c = traits_type::eof()) [protected], [virtual]

Consomme des données du tampon ; écrit dans la séquence contrôlée.

Paramètres

__c Un caractère supplémentaire à consommer.

Retourne

eof() pour indiquer un échec, autre chose (généralement __c, ou not_eof())

Informellement, cette fonction est appelée lorsque le tampon de sortie est plein (ou n'existe pas, car la mise en tampon n'est pas nécessairement effectuée). Si un tampon existe, il est consommé, avec un certain effet sur la séquence contrôlée. (Typiquement, le tampon est écrit dans la séquence verbatim.) Dans les deux cas, le caractère c est également écrit, si __c n'est pas eof().

Pour une définition formelle de cette fonction, consultez un bon texte tel que Langer & Kreft, ou [27.5.2.4.5]/3-7.

Un streambuf de sortie fonctionnel peut être créé en redéfinissant uniquement cette fonction (aucune zone de tampon ne sera utilisée).

Note

La version de la classe de base ne fait rien, retourne eof().

std::basic_stringbuf(3) — libstdc++ — French

libstdc++ — Français

NOM

std::basic_stringbuf — Interface de tampon de chaîne.

SYNOPSIS

#include <streambuf>

template<typename _CharT, typename _Traits = std::char_traits<_CharT> >
class std::basic_stringbuf : public std::basic_streambuf<_CharT, _Traits>;

Description

L'interface de classe de modèle std::basic_stringbuf dérive de std::basic_streambuf et implémente un tampon de flux qui utilise un tableau de caractères comme stockage.

Le tampon de chaîne est géré en utilisant des pointeurs vers le début, le courant et la fin de la zone de lecture et de la zone d'écriture. Cela permet à la chaîne d'être soit allouée dynamiquement, soit d'être fournie par l'appelant. Les zones de lecture et d'écriture peuvent partager ou non le même stockage sous-jacent.
