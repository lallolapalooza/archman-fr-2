NOM

stringprep_profile - fonction API

SYNTAXE

#include <stringprep.h>

int stringprep_profile(const char * in, char ** out, const char * profile, Stringprep_profile_flags flags);

ARGUMENTS

const char * in
tableau d'entrée avec la chaîne UTF-8 à préparer.
char ** out
variable de sortie avec pointeur vers une chaîne nouvellement allouée.
const char * profile
nom du profil stringprep à utiliser.
Stringprep_profile_flags flags
une valeur Stringprep_profile_flags, ou 0.

DESCRIPTION

Prépare la chaîne UTF-8 nulle terminée en entrée selon le profil stringprep, et retourne le résultat dans une variable nouvellement allouée.

Notez que vous devez convertir les chaînes entrées dans la locale du système en UTF-8 avant d'utiliser cette fonction, voir stringprep_locale_to_utf8().

La variable de sortie out doit être désallouée par l'appelant.

Les flags sont l'une des valeurs de Stringprep_profile_flags, ou 0.

Le profile spécifie le nom du profil stringprep à utiliser. Il doit s'agir d'un des profils stringprep pris en charge en interne.

Valeur de retour : Retourne STRINGPREP_OK en cas de succès, ou un code d'erreur.
