Description

The std::forward_list class is a container that supports forward iteration. It is a doubly linked list, meaning that each element contains a pointer to the next element and a pointer to the previous element. This allows for constant time insertion and deletion of elements anywhere in the list. However, it does not provide random access to elements, so subscripting (operator[]) is not supported.

The std::forward_list class is defined in the <forward_list> header.

Template parameters

_Tp Type of element.

_Alloc Allocator type, defaults to allocator<_Tp>.

Meets the requirements of a container, a sequence, including the optional sequence requirements with the exception of at and operator[].

This is a singly linked list. Traversal up the list requires linear time, but adding and removing elements (or nodes) is done in constant time, regardless of where the change takes place. Unlike std::vector and std::deque, random-access iterators are not provided, so subscripting ([]) access is not allowed. For algorithms which only need sequential access, this lack makes no difference.

Also unlike the other standard containers, std::forward_list provides specialized algorithms unique to linked lists, such as splicing, sorting, and in-place reversal.

Detailed Description

The std::forward_list class template is a container that supports forward iteration and efficient insertion and erasure of elements. It is a singly linked list. It has O(1) complexity for insertion and erasure.

The interface supports the following operations:

  • Insertion of elements at the front.
  • Insertion of elements after a specified element.
  • Erasing elements from the front.
  • Erasing elements after a specified element.
  • Resizing the list.
  • Sorting the list.
  • Removing elements from the list.
  • Removing duplicate elements.
  • Reversing the list.
  • Merging lists.
  • Splicing lists.
  • Swapping lists.
