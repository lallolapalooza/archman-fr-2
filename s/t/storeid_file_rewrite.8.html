NOM

storeid_file_rewrite - Aide pour Store-ID basée sur fichier pour Squid

SYNTAXE

storeid_file_rewrite filepath

DESCRIPTION

Ce programme agit comme un programme d'aide pour store_id, réécrivant les URLs transmises par Squid en store-ids qui peuvent être utilisés pour améliorer la mise en cache des sites web qui utilisent différentes URLs pour le même contenu.

Il prend un fichier texte avec deux colonnes séparées par des tabulations. Colonne 1 : Expression régulière pour correspondre à l'URL. Colonne 2 : Règle de réécriture pour générer un Store-ID. Exemple : ^http:\/\/[^\.]+\.dl\.sourceforge\.net\/(.*) http://dl.sourceforge.net.squid.internal/$1

Les règles de réécriture sont correspondantes dans le même ordre qu'elles apparaissent dans le fichier de règles. Donc pour une meilleure performance, triez-le par ordre de fréquence d'occurrence.

Ce programme détectera automatiquement l'existence d'un canal de concurrence (channel-ID) et s'ajustera en conséquence. Il peut être utilisé avec n'importe quelle valeur de 0 ou supérieure pour le paramètre de concurrence de store_id_children (concurrency=).

OPTIONS

Le seul paramètre de ligne de commande que cette aide accepte est le nom du fichier de règles regex.
