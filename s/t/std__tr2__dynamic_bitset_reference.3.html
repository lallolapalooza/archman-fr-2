Description détaillée

template<typename _WordT = unsigned long long, typename _Alloc = std::allocator<_WordT>>

class std::tr2::dynamic_bitset< _WordT, _Alloc >::reference"Ceci encapsule le concept d'un seul bit. Une instance de cette classe est un proxy pour un bit réel ; de cette façon, les opérations sur les bits individuels sont effectuées comme des instructions bit à bit de la taille d'un mot, plus rapides.

La plupart des utilisateurs n'auront jamais besoin d'utiliser cette classe directement ; les conversions depuis et vers bool sont automatiques et devraient être transparentes. Les opérateurs surchargés aident à préserver l'illusion.

(Sur un système typique, cette « référence de bit » est 64 fois plus grande qu'un bit réel. Ha.)
