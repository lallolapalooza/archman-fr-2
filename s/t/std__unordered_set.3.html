Description détaillée

template<typename _Value, typename _Hash = hash<_Value>, typename _Pred = equal_to<_Value>, typename _Alloc = allocator<_Value>>

class std::unordered_set< _Value, _Hash, _Pred, _Alloc >"Un conteneur standard composé de clés uniques (contenant au plus une fois chaque valeur de clé) dans lequel les clés des éléments sont les éléments eux-mêmes.

Depuis

C++11

Paramètres de template

_Value Type des objets clés.
_Hash Type de l'objet fonction de hachage, par défaut hash<_Value>.
_Pred Type de l'objet fonction prédicat, par défaut equal_to<_Value>.
_Alloc Type de l'allocateur, par défaut allocator<_Key>.

Satisfait les exigences d'un conteneur, et d'un conteneur associatif non ordonné.

La base est _Hashtable, dispatchée au moment de la compilation via l'alias de template __uset_hashtable.
