NOM

str_to_gensio_accepter - Créer un accepteur gensio à partir d'une chaîne de caractères

SYNTAXE

#include <gensio/gensio.h>

int str_to_gensio_accepter(const char *str,

struct gensio_os_funcs *o,
gensio_accepter_event cb,
void *user_data,
struct gensio_accepter **acc);
int str_to_gensio_accepter_child(struct gensio_accepter *child,

const char *str,
struct gensio_os_funcs *o,
gensio_accepter_event cb,
void *user_data,
struct gensio_accepter **acc);
int gensio_terminal_acc_alloc(const char *gensiotype,

const void *gdata,
const char * const args[],
struct gensio_os_funcs *o,
gensio_accepter_event cb, void *user_data,
struct gensio_accepter **accepter);
int gensio_filter_acc_alloc(const char *gensiotype,

struct gensio_accepter *child,
const char * const args[],
struct gensio_os_funcs *o,
gensio_accepter_event cb, void *user_data,
struct gensio_accepter **accepter);

DESCRIPTION

str_to_gensio_accepter alloue une nouvelle pile d'accepteurs gensio basée sur la chaîne de caractères str donnée.

str_to_gensio_accepter_child alloue une nouvelle pile d'accepteurs gensio basée sur la chaîne de caractères str donnée et la superpose sur l'accepteur enfant donné.

Pour allouer un accepteur directement, utilisez soit gensio_terminal_acc_alloc soit gensio_filter_acc_alloc. Un accepteur terminal est celui qui se trouve en bas de la pile. Le paramètre gdata dépend du gensio particulier. Par exemple, pour tcp, c'est un pointeur vers une structure gensio_addr. Pour stdio, c'est un tableau argv. Voir gensio.5 sous "Allocation directe" pour connaître la valeur de gdata pour un gensio particulier.

Un accepteur de filtre est celui qui a un enfant. Vous pouvez utiliser ces deux fonctions pour allouer une pile d'accepteurs directement, sans utiliser de format de chaîne de caractères.

Les paramètres cb et user_data définissent une fonction qui sera appelée lorsque des événements arriveront sur l'accepteur gensio. user_data n'est pas utilisé par la pile gensio elle-même, il est là pour l'utilisateur et peut être n'importe quoi que l'utilisateur souhaite.

Le nouvel accepteur gensio est retourné dans acc. Il sera dans l'état d'arrêt.

VALEUR DE RETOUR

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.

VOIR AUSSI

gensio_acc_set_callback(3), gensio_err(3), gensio(5)
