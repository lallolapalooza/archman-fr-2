Documentation de fonction/sous-routine

sous-routine strsyl (character trana, character tranb, integer isgn, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldc, * ) c, integer ldc, real scale, integer info)

STRSYL

But :

!>
!> STRSYL résout l'équation matricielle de Sylvester réelle :
!>
!>    op(A)*X + X*op(B) = scale*C ou
!>    op(A)*X - X*op(B) = scale*C,
!>
!> où op(A) = A ou A**T, et A et B sont toutes deux quasi-triangulaires supérieures.
!> A est de taille M par M et B est de taille N par N ; C, le membre de droite, et X,
!> la solution, sont de taille M par N ; et scale est un facteur d'échelle en sortie,
!> défini <= 1 pour éviter les dépassements de capacité dans X.
!>
!> A et B doivent être sous forme canonique de Schur (telles que renvoyées par SHSEQR),
!> c'est-à-dire, triangulaires supérieures par blocs avec des blocs diagonaux de taille 1x1 et 2x2 ;
!> chaque bloc diagonal 2x2 a ses éléments diagonaux égaux et ses éléments hors diagonaux de signe opposé.
!>

Paramètres

TRANA 
!>          TRANA est CHARACTER*1
!>          Spécifie l'option op(A) :
!>          = 'N': op(A) = A    (Pas de transposée)
!>          = 'T': op(A) = A**T (Transposée)
!>          = 'C': op(A) = A**H (Conjuguée transposée = Transposée)
!>

TRANB

!>          TRANB est CHARACTER*1
!>          Spécifie l'option op(B) :
!>          = 'N': op(B) = B    (Pas de transposée)
!>          = 'T': op(B) = B**T (Transposée)
!>          = 'C': op(B) = B**H (Conjuguée transposée = Transposée)
!>

ISGN

!>          ISGN est INTEGER
!>          Spécifie le signe dans l'équation :
!>          = +1 : résout op(A)*X + X*op(B) = scale*C
!>          = -1 : résout op(A)*X - X*op(B) = scale*C
!>

M

!>          M est INTEGER
!>          L'ordre de la matrice A, et le nombre de lignes des matrices X et C. M >= 0.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B, et le nombre de colonnes des matrices X et C. N >= 0.
!>

A

!>          A est un tableau de REAL, dimension (LDA,M)
!>          La matrice quasi-triangulaire supérieure A, sous forme canonique de Schur.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau de REAL, dimension (LDB,N)
!>          La matrice quasi-triangulaire supérieure B, sous forme canonique de Schur.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

C

!>          C est un tableau de REAL, dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N, membre de droite.
!>          À la sortie, C est écrasé par la matrice solution X.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M)
!>

SCALE

!>          SCALE est REAL
!>          Le facteur d'échelle, scale, défini <= 1 pour éviter les dépassements
!>          de capacité dans X.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : A et B ont des valeurs propres communes ou très proches ; des valeurs
!>               perturbées ont été utilisées pour résoudre l'équation (mais les matrices
!>               A et B ne sont pas modifiées).
!>
