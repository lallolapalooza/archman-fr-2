DSTEBZ

Objectif :

!>
!> DSTEBZ calcule les valeurs propres d'une matrice tridiagonale symétrique
!> T. L'utilisateur peut demander toutes les valeurs propres, toutes les valeurs propres
!> dans l'intervalle demi-ouvert (VL, VU], ou les valeurs propres IL-ième à IU-ième.
!>
!> Pour éviter le débordement, la matrice doit être mise à l'échelle de sorte que son
!> élément le plus grand ne soit pas supérieur à overflow**(1/2) * underflow**(1/4) en valeur absolue, et pour une précision maximale, elle ne doit pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan , Rapport CS41, Département d'Informatique, Université de Stanford
!> , 21 juillet 1966.
!>

Paramètres

RANGE 
!>          RANGE est de type CARACTERE*1
!>          = 'A': ()   toutes les valeurs propres seront trouvées.
!>          = 'V': () toutes les valeurs propres dans l'intervalle
!>                           demi-ouvert (VL, VU] seront trouvées.
!>          = 'I': () les valeurs propres de l'indice IL à IU (de
!>                           la matrice entière) seront trouvées.
!>

ORDER

!>          ORDER est de type CARACTERE*1
!>          = 'B': () les valeurs propres seront groupées par
!>                              bloc de séparation (voir IBLOCK, ISPLIT) et
!>                              ordonnées de la plus petite à la plus grande dans
!>                              le bloc.
!>          = 'E': ()
!>                              les valeurs propres de la matrice entière
!>                              seront ordonnées de la plus petite à la
!>                              plus grande.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice tridiagonale T. N >= 0.
!>

VL

!>          VL est de type DOUBLE PRÉCISION
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          parcourir pour trouver les valeurs propres. Les valeurs propres inférieures ou égales
!>          à VL, ou supérieures à VU, ne seront pas retournées. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est de type DOUBLE PRÉCISION
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          parcourir pour trouver les valeurs propres. Les valeurs propres inférieures ou égales
!>          à VL, ou supérieures à VU, ne seront pas retournées. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est un ENTIER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est un ENTIER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est de type DOUBLE PRÉCISION
!>          La tolérance absolue pour les valeurs propres. Une valeur propre
!>          (ou un cluster) est considérée comme localisée si elle a été
!>          déterminée comme se trouvant dans un intervalle dont la largeur est ABSTOL ou
!>          inférieure. Si ABSTOL est inférieur ou égal à zéro, alors ULP*|T|
!>          sera utilisé, où |T| représente la norme 1 de T.
!>
!>          Les valeurs propres seront calculées de manière la plus précise lorsque ABSTOL est
!>          défini sur deux fois le seuil de sous-dépassement 2*DLAMCH('S'), et non zéro.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Les N éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau de DOUBLE PRÉCISION, dimension (N-1)
!>          Les N-1 éléments hors diagonaux de la matrice tridiagonale T.
!>

M

!>          M est un ENTIER
!>          Le nombre réel de valeurs propres trouvées. 0 <= M <= N.
!>          (Voir aussi la description de INFO=2,3.)
!>

NSPLIT

!>          NSPLIT est un ENTIER
!>          Le nombre de blocs diagonaux dans la matrice T.
!>          1 <= NSPLIT <= N.
!>

W

!>          W est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          En sortie, les M premiers éléments de W contiendront les
!>          valeurs propres. (DSTEBZ peut utiliser les N-M éléments restants comme
!>          espace de travail.)
!>

IBLOCK

!>          IBLOCK est un tableau d'ENTIERS, dimension (N)
!>          À chaque ligne/colonne j où E(j) est nul ou petit, la
!>          matrice T est considérée comme se divisant en une matrice diagonale par blocs
!>          . En sortie, si INFO = 0, IBLOCK(i) spécifie à quel
!>          bloc (de 1 au nombre de blocs) appartient la valeur propre W(i).
!>          (DSTEBZ peut utiliser les N-M éléments restants comme
!>          espace de travail.)
!>

ISPLIT

!>          ISPLIT est un tableau d'ENTIERS, dimension (N)
!>          Les points de séparation, où T se divise en sous-matrices.
!>          La première sous-matrice comprend les lignes/colonnes 1 à ISPLIT(1),
!>          la deuxième les lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et la NSPLIT-ième comprend les lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>          (Seuls les NSPLIT premiers éléments seront effectivement utilisés, mais
!>          comme l'utilisateur ne peut pas savoir a priori quelle valeur NSPLIT aura,
!>          N mots doivent être réservés pour ISPLIT.)
!>

WORK

!>          WORK est un tableau de DOUBLE PRÉCISION, dimension (4*N)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (3*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : tout ou partie des valeurs propres n'ont pas convergé ou
!>                n'ont pas été calculées :
!>                =1 ou 3 : Bisection n'a pas convergé pour certaines
!>                        valeurs propres ; ces valeurs propres sont marquées par un
!>                        numéro de bloc négatif. L'effet est que les
!>                        valeurs propres peuvent ne pas être aussi précises que les
!>                        tolérances absolue et relative. Ceci est
!>                        généralement causé par une arithmétique inattendument imprécise.
!>                =2 ou 3 : UNIQUEMENT RANGE='I' : toutes les valeurs propres
!>                        IL:IU n'ont pas été trouvées.
!>                        Effet : M < IU+1-IL
!>                        Cause : arithmétique non monotone, causant la
!>                                séquence de Sturm à être non monotone.
!>                        Remède : recalculer, en utilisant RANGE='A', et extraire
!>                                les valeurs propres IL:IU. Dans certains cas,
