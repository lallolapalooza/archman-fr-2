std::unordered_map

Unordered associative container.

Header

#include <unordered_map>

Description

std::unordered_map is an unordered associative container that contains elements formed by a combination of a key and a mapped value, and which provides fast average time complexity for insertion, erasure and search operations (average O(1)). Search, insertion, and deletion of an element have average time complexity O(1), and worst-case time complexity O(N), where N is the number of elements in the container.

Elements are not ordered. A hash function is used to order elements, and comparisons are made by the key equality predicate.

When the average number of elements per bucket exceeds a specified threshold, the hash table is automatically rehashed.

It is implemented as a hash table.

Template parameters

Key
The type of the keys stored in the container. Each key must be unique. The key type must be hashable (using the Hash parameter) and comparable for equality (using the Pred parameter).
Tp
The type of the mapped values.
Hash
The type of the hash function object. It defaults to std::hash<Key>. The function must be able to hash objects of type Key.
Pred
The type of the comparison function object. It defaults to std::equal_to<Key>. The function must be able to compare objects of type Key for equality.
Alloc
The type of the allocator object used to manage memory. It defaults to std::allocator<std::pair<const Key, Tp>>.
