STRNCPY(3P) Manuel du programmeur POSIX STRNCPY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

stpncpy, strncpy — copie une chaîne de longueur fixe, retournant un pointeur vers la fin du tableau

SYNTAXE

#include <string.h>
char *stpncpy(char *restrict s1, const char *restrict s2, size_t n);
char *strncpy(char *restrict s1, const char *restrict s2, size_t n);

DESCRIPTION

Pour strncpy() : La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions stpncpy() et strncpy() doivent copier au maximum n octets (les octets qui suivent un caractère NUL ne sont pas copiés) du tableau pointé par s2 vers le tableau pointé par s1.

Si le tableau pointé par s2 est une chaîne plus courte que n octets, des caractères NUL seront ajoutés à la copie dans le tableau pointé par s1, jusqu'à ce que n octets au total soient écrits.

Si la copie a lieu entre des objets qui se chevauchent, le comportement est indéfini.

VALEUR DE RETOUR

Si un caractère NUL est écrit dans la destination, la fonction stpncpy() retournera l'adresse de ce premier caractère NUL. Sinon, elle retournera &s1[n].

La fonction strncpy() retournera s1.

Aucune valeur de retour n'est réservée pour indiquer une erreur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Les applications doivent prévoir l'espace dans s1 pour les n octets à transférer, et s'assurer que les tableaux s2 et s1 ne se chevauchent pas.

Le déplacement des caractères est effectué différemment selon les implémentations. Ainsi, les déplacements qui se chevauchent peuvent réserver des surprises.

S'il n'y a pas de caractère NUL dans les n premiers octets du tableau pointé par s2, le résultat n'est pas terminé par un NUL.
