Documentation de la fonction/sous-routine

sous-routine stgsyl (caractère trans, entier ijob, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( ldd, * ) d, entier ldd, réel, dimension( lde, * ) e, entier lde, réel, dimension( ldf, * ) f, entier ldf, réel scale, réel dif, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier info)

STGSYL

Objectif :

!>
!> STGSYL résout l'équation de Sylvester généralisée :
!>
!>             A * R - L * B = scale * C                 (1)
!>             D * R - L * E = scale * F
!>
!> où R et L sont des matrices m-par-n inconnues, (A, D), (B, E) et
!> (C, F) sont des paires de matrices données de tailles m-par-m, n-par-n et m-par-n,
!> respectivement, avec des entrées réelles. (A, D) et (B, E) doivent être sous
!> forme canonique généralisée (réelle) de Schur, c'est-à-dire A, B sont quasi
!> triangulaires supérieures et D, E sont triangulaires supérieures.
!>
!> La solution (R, L) écrase (C, F). 0 <= SCALE <= 1 est un facteur d'échelle de sortie
!> choisi pour éviter le débordement.
!>
!> En notation matricielle, (1) est équivalente à la résolution de Zx = scale b, où
!> Z est définie comme
!>
!>            Z = [ kron(In, A)  -kron(B**T, Im) ]         (2)
!>                [ kron(In, D)  -kron(E**T, Im) ].
!>
!> Ici Ik est la matrice identité de taille k et X**T est la transposée de
!> X. kron(X, Y) est le produit de Kronecker entre les matrices X et Y.
!>
!> Si TRANS = 'T', STGSYL résout le système transposé Z**T*y = scale*b,
!> ce qui est équivalent à résoudre pour R et L dans
!>
!>             A**T * R + D**T * L = scale * C           (3)
!>             R * B**T + L * E**T = scale * -F
!>
!> Ce cas (TRANS = 'T') est utilisé pour calculer une estimation basée sur la norme unitaire de
!> Dif[(A,D), (B,E)], la séparation entre les paires de matrices (A,D)
!> et (B,E), en utilisant SLACON.
!>
!> Si IJOB >= 1, STGSYL calcule une estimation basée sur la norme de Frobenius
!> de Dif[(A,D),(B,E)]. C'est-à-dire, l'inverse d'une borne inférieure de
!> l'inverse de la plus petite valeur singulière de Z. Voir [1-2] pour plus
!> d'informations.
!>
!> Il s'agit d'un algorithme BLAS de niveau 3.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : résout l'équation de Sylvester généralisée (1).
!>          = 'T' : résout le système 'transposé' (3).
!>

IJOB

!>          IJOB est INTEGER
!>          Spécifie le type de fonctionnalité à effectuer.
!>          = 0 : résout (1) uniquement.
!>          = 1 : Les fonctionnalités de 0 et 3.
!>          = 2 : Les fonctionnalités de 0 et 4.
!>          = 3 : Une estimation de Dif[(A,D), (B,E)] est calculée uniquement.
!>               (la stratégie d'anticipation IJOB = 1 est utilisée).
!>          = 4 : Une estimation de Dif[(A,D), (B,E)] est calculée uniquement.
!>               (SGECON sur les sous-systèmes est utilisé).
!>          Non référencé si TRANS = 'T'.
!>

M

!>          M est INTEGER
!>          L'ordre des matrices A et D, et la dimension de ligne
!>          des matrices C, F, R et L.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices B et E, et la dimension de colonne
!>          des matrices C, F, R et L.
!>

A

!>          A est un tableau REEL, dimension (LDA, M)
!>          La matrice quasi triangulaire supérieure A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1, M).
!>

B

!>          B est un tableau REEL, dimension (LDB, N)
!>          La matrice quasi triangulaire supérieure B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1, N).
!>

C

!>          C est un tableau REEL, dimension (LDC, N)
!>          À l'entrée, C contient le membre de droite de la première matrice
!>          équation dans (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, C a été écrasé par
!>          la solution R. Si IJOB = 3 ou 4 et TRANS = 'N', C contient R,
!>          la solution obtenue pendant le calcul de l'estimation
!>          de Dif.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1, M).
!>

D

!>          D est un tableau REEL, dimension (LDD, M)
!>          La matrice triangulaire supérieure D.
!>

LDD

!>          LDD est INTEGER
!>          La dimension principale du tableau D. LDD >= max(1, M).
!>

E

!>          E est un tableau REEL, dimension (LDE, N)
!>          La matrice triangulaire supérieure E.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale du tableau E. LDE >= max(1, N).
!>

F

!>          F est un tableau REEL, dimension (LDF, N)
!>          À l'entrée, F contient le membre de droite de la seconde matrice
!>          équation dans (1) ou (3).
!>          À la sortie, si IJOB = 0, 1 ou 2, F a été écrasé par
!>          la solution L. Si IJOB = 3 ou 4 et TRANS = 'N', F contient L,
!>          la solution obtenue pendant le calcul de l'estimation
!>          de Dif.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale du tableau F. LDF >= max(1, M).
!>

DIF

!>          DIF est REEL
!>          À la sortie, DIF est l'inverse d'une borne inférieure de
!>          l'inverse de la fonction Dif, c'est-à-dire DIF est une borne supérieure de
!>          Dif[(A,D), (B,E)] = sigma_min(Z), où Z est comme en (2).
!>          SI IJOB = 0 ou TRANS = 'T', DIF n'est pas touché.
!>

SCALE

!>          SCALE est REEL
!>          À la sortie, SCALE est le facteur d'échelle dans (1) ou (3).
!>          Si 0 < SCALE < 1, C et F contiennent les solutions R et L, respectivement,
!>          d'un système légèrement perturbé mais les matrices d'entrée A, B, D
!>          et E n'ont pas été modifiées. Si SCALE = 0, C et F contiennent les
!>          solutions R et L, respectivement, du système homogène
!>          avec C = F = 0. Normalement, SCALE = 1.
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK > = 1.
!>          Si IJOB = 1 ou 2 et TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (M+N+6)
!>

INFO

!>          INFO est INTEGER
!>            =0 : fin de l'exécution réussie
!>            <0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>            >0 : (A, D) et (B, E) ont des valeurs propres communes ou proches.
!>
