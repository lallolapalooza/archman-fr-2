strnstr(3bsd)

Paquet: libbsd

Licences: custom

strstr(3bsd) 3bsd strstr(3bsd)

NOM

strnstr — localise une sous-chaîne dans une chaîne

BIBLIOTHQUE

bibliothèque « libbsd »

SYNTAXE

#include <string.h> (Voir libbsd(7) pour l'utilisation des includes.)
char *
strnstr(const char *big, const char *little, size_t len);

DESCRIPTION

La fonction strnstr() localise la première occurrence de la chaîne terminée par un nul little dans la chaîne big, où pas plus de len caractères sont recherchés. Les caractères qui apparaissent après un caractère ‘\0’ ne sont pas recherchés. Étant donné que la fonction strnstr() est une API spécifique à FreeBSD, elle ne devrait être utilisée que lorsque la portabilité n'est pas une préoccupation.

VALEURS DE RETOUR

Si little est une chaîne vide, big est retourné ; si little n'est trouvé nulle part dans big, NULL est retourné ; sinon, un pointeur vers le premier caractère de la première occurrence de little est retourné.

EXEMPLES

L'exemple suivant assigne NULL au pointeur ptr, car seuls les 4 premiers caractères de largestring sont recherchés :

const char *largestring = "Foo Bar Baz";
const char *smallstring = "Bar";
char *ptr;

ptr = strnstr(largestring, smallstring, 4);

VOIR AUSSI

strstr(3), strcasestr(3), memchr(3), memmem(3), strchr(3), strcspn(3), strpbrk(3), strrchr(3), strsep(3), strspn(3), strtok(3), wcsstr(3)

HISTORIQUE

La fonction strnstr() est originaire de FreeBSD.
