Documentation de la fonction/sous-programme

sous-programme stpmqrt (caractère side, caractère trans, entier m, entier n, entier k, entier l, entier nb, réel, dimension( ldv, * ) v, entier ldv, réel, dimension( ldt, * ) t, entier ldt, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, entier info)

STPMQRT

Objectif:

!>
!> STPMQRT applique une matrice orthogonale réelle Q obtenue à partir d'un
!>  réflecteur de bloc réel H à une matrice réelle générale
!> C, qui se compose de deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q^T à gauche ;
!>          = 'R': appliquer Q ou Q^T à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'T': Transposée, appliquer Q^T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est INTEGER
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0. Voir Détails supplémentaires.
!>

NB

!>          NB est INTEGER
!>          La taille du bloc utilisée pour le stockage de T. K >= NB >= 1.
!>          Doit être la même valeur de NB utilisée pour générer T
!>          dans CTPQRT.
!>

V

!>          V est un tableau REAL, de dimension (LDV,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CTPQRT dans B. Voir Détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si SIDE = 'L', LDV >= max(1,M) ;
!>          Si SIDE = 'R', LDV >= max(1,N).
!>

T

!>          T est un tableau REAL, de dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par CTPQRT, stockés sous forme de matrice NBxK.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= NB.
!>

A

!>          A est un tableau REAL, de dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice KxN ou MxK A.
!>          À la sortie, A est écrasé par le bloc correspondant de
!>          Q*C ou Q^T*C ou C*Q ou C*Q^T. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDC >= max(1,K) ;
!>          Si SIDE = 'R', LDC >= max(1,M).
!>

B

!>          B est un tableau REAL, de dimension (LDB,N)
!>          À l'entrée, la matrice M x N B.
!>          À la sortie, B est écrasé par le bloc correspondant de
!>          Q*C ou Q^T*C ou C*Q ou C*Q^T. Voir Détails supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau REAL. La dimension de WORK est
!>           N*NB si SIDE = 'L', ou M*NB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!>  élémentaires H(1), H(2), ..., H(K) ; V est composé d'un bloc rectangulaire V1 et d'un
!>  bloc trapézoïdal V2 :
!>
!>        V = [V1]
!>            [V2].
!>
!>  La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!>  où 0 <= L <= K ; V2 est trapézoïdale supérieure, composée des L premières
!>  lignes d'une matrice triangulaire supérieure KxK. Si L=K, V2 est triangulaire supérieure ;
!>  si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!>  Si SIDE = 'L' : C = [A] où A est KxN, B est MxN et V est MxK.
!>                      [B]
!>
!>  Si SIDE = 'R' : C = [A B] où A est MxK, B est MxN et V est NxK.
!>
!>  La matrice orthogonale réelle Q est formée à partir de V et T.
!>
!>  Si TRANS='N' et SIDE='L', C est remplacé à la sortie par Q * C.
!>
!>  Si TRANS='T' et SIDE='L', C est remplacé à la sortie par Q^T * C.
!>
!>  Si TRANS='N' et SIDE='R', C est remplacé à la sortie par C * Q.
!>
!>  Si TRANS='T' et SIDE='R', C est remplacé à la sortie par C * Q^T.
!>
