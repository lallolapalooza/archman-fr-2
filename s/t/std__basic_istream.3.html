Toutes les fonctions operator>> (également appelées fonctions d'entrée formatée) ont un comportement commun. Chacune commence par construire un objet temporaire de type std::basic_istream::sentry avec le second argument (noskipws) réglé sur false. Cela a plusieurs effets, se terminant par la définition d'un indicateur de statut ; voir la documentation de sentry pour plus de détails.

Si le statut de sentry est bon, la fonction tente d'extraire les données appropriées au type de l'argument.

Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer la levée d'une exception ios_base::failure) et l'exception d'origine sera relancée si badbit est défini dans le masque d'exceptions.

Description détaillée

La classe basic_istream fournit l'interface pour les flux d'entrée formatés.

template<typename _CharT, typename _Traits>

class std::basic_istream< _CharT, _Traits >

Classe de modèle pour les flux d'entrée.

Paramètres du modèle

_CharT Type de caractère du flux.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

C'est la classe de base pour tous les flux d'entrée. Elle fournit le formatage de texte de tous les types intégrés et communique avec toute classe dérivée de basic_streambuf pour effectuer l'entrée réelle.

template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lancer des exceptions en cas d'erreur.

Paramètres

__except Le nouveau masque d'exceptions.

Par défaut, les indicateurs d'erreur sont définis silencieusement. Vous pouvez définir un masque d'exceptions pour chaque flux ; si un bit du masque est défini dans les indicateurs d'erreur, une exception de type std::ios_base::failure est levée.

Si l'indicateur d'erreur est déjà défini lors de l'ajout du masque d'exceptions, l'exception est immédiatement levée. Essayez d'exécuter ce qui suit sous GCC 3.1 ou une version ultérieure :

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

Vérification rapide des erreurs.

Retourne

Détaillée Description

La classe `std::basic_stream` est une classe de base abstraite qui définit l'interface pour les flux d'entrée. Elle gère la lecture de caractères à partir d'une source et fournit des opérations telles que la lecture de chaînes, de nombres et d'autres types de données.

Elle dérive de `std::basic_ios`, qui fournit des fonctionnalités de gestion d'état et de formatage.
