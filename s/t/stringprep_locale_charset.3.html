stringprep_locale_charset(3) libidn stringprep_locale_charset(3)

NOM

stringprep_locale_charset - fonction API

SYNTAXE

#include <stringprep.h>

const char * stringprep_locale_charset( void);

ARGUMENTS

void

DESCRIPTION

Codes de retour énumérés des fonctions de vérification TLD. La valeur 0 est garantie de correspondre toujours à un succès.

Découvrir le jeu de caractères du locale actuel. La fonction respecte la variable d'environnement CHARSET, mais utilise typiquement nl_langinfo(CODESET) lorsqu'il est pris en charge. Elle se rabat sur "ASCII" si CHARSET n'est pas défini et que nl_langinfo n'est pas pris en charge ou ne renvoie rien.

Notez que cette fonction renvoie le jeu de caractères préféré du locale de l'application (ou du locale du thread, si votre système prend en charge les locales spécifiques aux threads). Elle ne renvoie pas ce que le système peut utiliser. Ainsi, si vous recevez des données de sources externes, vous ne pouvez généralement pas utiliser cette fonction pour deviner dans quel jeu de caractères elles sont encodées. Utilisez stringprep_convert pour convertir de la représentation externe vers le jeu de caractères renvoyé par cette fonction, afin d'avoir des données dans l'encodage du locale.

Valeur de retour : Renvoie le jeu de caractères utilisé par le locale courant. Il ne renverra jamais NULL, mais utilisera "ASCII" comme solution de secours.
