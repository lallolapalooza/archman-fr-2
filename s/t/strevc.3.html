subroutine strevc (side, howmny, select, n, t, ldt, vl, ldvl, vr, ldvr, mm, m, work, info)
STREVC

Documentation de la fonction/sous-routine

sous-routine strevc (caractere side, caractere howmny, logique, dimension( * ) select, entier n, reel, dimension( ldt, * ) t, entier ldt, reel, dimension( ldvl, * ) vl, entier ldvl, reel, dimension( ldvr, * ) vr, entier ldvr, entier mm, entier m, reel, dimension( * ) work, entier info)

STREVC

But :

!>
!> STREVC calcule certains ou tous les vecteurs propres droits et/ou gauches
!> d'une matrice T quasi-triangulaire réelle.
!> Les matrices de ce type sont produites par la factorisation de Schur d'une
!> matrice générale réelle : A = Q*T*Q**T, comme calculé par SHSEQR.
!>
!> Les vecteurs propres droits x et gauches y de T correspondant à une
!> valeur propre w sont définis par :
!>
!>    T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> où y**H désigne la transposée conjuguée de y.
!> Les valeurs propres ne sont pas des entrées de cette routine, mais sont lues
!> directement à partir des blocs diagonaux de T.
!>
!> Cette routine retourne les matrices X et/ou Y de vecteurs propres droits et
!> gauches de T, ou les produits Q*X et/ou Q*Y, où Q est une matrice d'entrée.
!> Si Q est le facteur orthogonal qui réduit une matrice A en forme de Schur T,
!> alors Q*X et Q*Y sont les matrices des vecteurs propres droits et gauches de A.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer les vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer tous les vecteurs propres droits et/ou gauches ;
!>          = 'B' : calculer tous les vecteurs propres droits et/ou gauches,
!>                  rétro-transformés par les matrices dans VR et/ou VL ;
!>          = 'S' : calculer des vecteurs propres droits et/ou gauches sélectionnés,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Si w(j) est une valeur propre réelle, le vecteur propre réel
!>          correspondant est calculé si SELECT(j) est .VRAI..
!>          Si w(j) et w(j+1) sont les parties réelle et imaginaire d'une
!>          valeur propre complexe, le vecteur propre complexe correspondant
!>          est calculé si SELECT(j) ou SELECT(j+1) est .VRAI., et à la sortie,
!>          SELECT(j) est mis à .VRAI. et SELECT(j+1) est mis à .FAUX..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau REEL, dimension (LDT,N)
!>          La matrice quasi-triangulaire supérieure T sous forme canonique de Schur.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau REEL, dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N x N (généralement la matrice
!>          orthogonale Q des vecteurs de Schur retournée par SHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres gauches de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres gauches de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VL, dans le même ordre que leurs valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle, et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL. LDVL >= 1, et si
!>          SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau REEL, dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Q de taille N x N (généralement la matrice
!>          orthogonale Q des vecteurs de Schur retournée par SHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres droits de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres droits de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VR, dans le même ordre que leurs valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR. LDVR >= 1, et si
!>          SIDE = 'R' ou 'B', LDVR >= N.
!>

MM

!>          MM est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR effectivement
!>          utilisées pour stocker les vecteurs propres.
!>          Si HOWMNY = 'A' ou 'B', M est mis à N.
!>          Chaque vecteur propre réel sélectionné occupe une colonne et chaque
!>          vecteur propre complexe sélectionné occupe deux colonnes.
!>

WORK

!>          WORK est un tableau REEL, dimension (3*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

!>  inverse (directe), avec mise à l'échelle pour rendre le code robuste contre
!>  d'éventuels débordements.
!>
!>  Chaque vecteur propre est normalisé de telle sorte que l'élément de plus
!>  grande magnitude ait une magnitude de 1 ; ici, la magnitude d'un nombre
!>  complexe (x,y) est prise comme |x| + |y|.
!>
