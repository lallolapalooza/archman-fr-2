STRINGS(1) Outils de développement GNU STRINGS(1)

NOM

strings - affiche les séquences de caractères imprimables dans les fichiers

SYNTAXE

strings [-afovV] [-longueur-min]
[-n longueur-min] [--bytes=longueur-min]
[-t base] [--radix=base]
[-e encodage] [--encoding=encodage]
[-U methode] [--unicode=methode]
[-] [--all] [--print-file-name]
[-T nom-bfd] [--target=nom-bfd]
[-w] [--include-all-whitespace]
[-s] [--output-separator chaine-sep]
[--help] [--version] fichier...

DESCRIPTION

Pour chaque fichier donné, GNU strings affiche les séquences de caractères imprimables d'au moins 4 caractères de long (ou le nombre spécifié avec les options ci-dessous) suivies d'un caractère non imprimable.

Selon la configuration du programme strings, il affichera par défaut toutes les séquences imprimables qu'il peut trouver dans chaque fichier, ou seulement celles qui se trouvent dans les sections de données initialisées et chargées. Si le type de fichier est non reconnaissable, ou si strings lit depuis stdin, il affichera toujours toutes les séquences imprimables qu'il peut trouver.

Par souci de compatibilité ascendante, tout fichier survenant après une option de ligne de commande constituée uniquement de - sera également scanné en intégralité, indépendamment de la présence de l'option -d.

strings est principalement utile pour déterminer le contenu des fichiers non textuels.

OPTIONS

-a
--all
-
Scanne le fichier entier, quelles que soient les sections qu'il contient ou qu'elles soient chargées ou initialisées. Normalement, c'est le comportement par défaut, mais strings peut être configuré de manière à ce que -d soit le comportement par défaut.

L'option - dépend de la position et force strings à effectuer des scans complets de tout fichier mentionné après le - sur la ligne de commande, même si l'option -d a été spécifiée.

-d
--data
N'affiche que les chaînes des sections de données initialisées et chargées du fichier. Cela peut réduire la quantité d'informations inutiles dans la sortie, mais expose également le programme strings aux éventuelles failles de sécurité présentes dans la bibliothèque BFD utilisée pour scanner et charger les sections. Strings peut être configuré de manière à ce que cette option soit le comportement par défaut. Dans ce cas, l'option -a peut être utilisée pour éviter d'utiliser la bibliothèque BFD et afficher plutôt toutes les chaînes trouvées dans le fichier.
-f
--print-file-name
Affiche le nom du fichier avant chaque chaîne.
--help
Affiche un résumé de l'utilisation du programme sur la sortie standard et quitte.
-longueur-min
-n longueur-min
--bytes=longueur-min
Affiche les séquences de caractères affichables d'au moins longueur-min caractères de long. Si non spécifié, une longueur minimale par défaut de 4 est utilisée. La distinction entre caractères affichables et non affichables dépend du paramétrage des options -e et -U. Les séquences sont toujours terminées par des caractères de contrôle tels que new-line et carriage-return, mais pas par le caractère tab.
-o
Comme -t o. Certaines autres versions de strings font agir -o comme -t d. Comme nous ne pouvons pas être compatibles des deux manières, nous en avons simplement choisi une.
-t base
--radix=base
Affiche le décalage dans le fichier avant chaque chaîne. L'argument d'un seul caractère spécifie la base du décalage : o pour octal, x pour hexadécimal, ou d pour décimal.
-e encodage
--encoding=encodage
Sélectionne l'encodage des caractères des chaînes à rechercher. Les valeurs possibles pour encodage sont : s = caractères d'octet unique de 7 bits (par défaut), S = caractères d'octet unique de 8 bits, b = 16 bits bigendian, l = 16 bits littleendian, B = 32 bits bigendian, L = 32 bits littleendian. Utile pour trouver des chaînes de caractères larges. (l et b s'appliquent par exemple aux encodages Unicode UTF-16/UCS-2).
-U [d|i|l|e|x|h]
--unicode=[default|invalid|locale|escape|hex|highlight]
Contrôle l'affichage des caractères multibytes encodés en UTF-8 dans les chaînes. Par défaut (--unicode=default), aucun traitement spécial ne leur est appliqué, et le réglage de l'option --encoding est utilisé. Les autres valeurs de cette option activent automatiquement --encoding=S.

L'option --unicode=invalid les traite comme des caractères non graphiques et donc non faisant partie d'une chaîne valide. Toutes les autres options les traitent comme des caractères de chaîne valides.

L'option --unicode=locale les affiche dans la locale actuelle, qui peut ou non supporter l'encodage UTF-8. L'option --unicode=hex les affiche sous forme de séquences d'octets hexadécimaux encadrées par des caractères <>. L'option --unicode=escape les affiche sous forme de séquences d'échappement (\uxxxx) et l'option --unicode=highlight les affiche sous forme de séquences d'échappement mises en surbrillance en rouge (si le périphérique de sortie le supporte). La coloration est destinée à attirer l'attention sur la présence de séquences unicode là où elles ne seraient pas attendues.

-T nom-bfd
--target=nom-bfd
Spécifie un format de code objet autre que le format par défaut de votre système.
-v
-V
--version
Affiche le numéro de version du programme sur la sortie standard et quitte.
-w
--include-all-whitespace
Par défaut, les caractères tabulation et espace sont inclus dans les chaînes affichées, mais les autres caractères d'espacement, tels que les sauts de ligne et retours chariot, ne le sont pas. L'option -w modifie ce comportement pour que tous les caractères d'espacement soient considérés comme faisant partie d'une chaîne.
-s
--output-separator
Par défaut, les chaînes de sortie sont délimitées par un saut de ligne. Cette option vous permet de fournir n'importe quelle chaîne à utiliser comme séparateur d'enregistrement de sortie. Utile avec --include-all-whitespace où les chaînes peuvent contenir des sauts de ligne en interne.
@fichier
Lit les options de ligne de commande depuis fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas, ou ne peut pas être lu, alors l'option sera traitée littéralement, et ne sera pas supprimée.
