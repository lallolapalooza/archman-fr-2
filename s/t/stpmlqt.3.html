sous-routine stpmlqt (caractère side, caractère trans, entier m, entier n, entier k, entier l, entier mb, réel, dimension( ldv, * ) v, entier ldv, réel, dimension( ldt, * ) t, entier ldt, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, entier info)

STPMLQT

But :

!>
!> STPMLQT applique une matrice orthogonale réelle Q obtenue à partir d'un
!>  réflecteur de bloc réel H à une matrice réelle générale
!> C, qui consiste en deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T à gauche ;
!>          = 'R': appliquer Q ou Q**T à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'T':  Transposée, appliquer Q**T.
!>

M

!>          M est un ENTIER
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est un ENTIER
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0.  Voir Détails supplémentaires.
!>

MB

!>          MB est un ENTIER
!>          La taille de bloc utilisée pour le stockage de T.  K >= MB >= 1.
!>          Cela doit être la même valeur de MB utilisée pour générer T
!>          dans STPLQT.
!>

V

!>          V est un tableau RÉEL, dimension (LDV,K)
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          STPLQT dans B.  Voir Détails supplémentaires.
!>

LDV

!>          LDV est un ENTIER
!>          La dimension principale du tableau V. LDV >= K.
!>

T

!>          T est un tableau RÉEL, dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par STPLQT, stockés sous forme de matrice MB par K.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T.  LDT >= MB.
!>

A

!>          A est un tableau RÉEL, dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice A de K par N ou M par K.
!>          À la sortie, A est écrasé par le bloc correspondant de
!>          Q*C ou Q**T*C ou C*Q ou C*Q**T.  Voir Détails supplémentaires.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,K) ;
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B est un tableau RÉEL, dimension (LDB,N)
!>          À l'entrée, la matrice B de M par N.
!>          À la sortie, B est écrasé par le bloc correspondant de
!>          Q*C ou Q**T*C ou C*Q ou C*Q**T.  Voir Détails supplémentaires.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau RÉEL. La dimension de WORK est
!>           N*MB si SIDE = 'L', ou  M*MB si SIDE = 'R'.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  terminaison réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!>  élémentaires H(1), H(2), ..., H(K) ; V est composé d'un bloc rectangulaire V1 et d'un
!>  bloc trapézoïdal V2 :
!>
!>        V = [V1] [V2].
!>
!>
!>  La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!>  où 0 <= L <= K ; V2 est trapézoïdal inférieur, composé des L premières
!>  lignes d'une matrice triangulaire supérieure K par K.  Si L=K, V2 est triangulaire inférieure ;
!>  si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!>  Si SIDE = 'L' : C = [A]  où A est K par N,  B est M par N et V est K par M.
!>                      [B]
!>
!>  Si SIDE = 'R' : C = [A B]  où A est M par K, B est M par N et V est K par N.
!>
!>  La matrice orthogonale réelle Q est formée à partir de V et T.
!>
!>  Si TRANS='N' et SIDE='L', C est remplacé en sortie par Q * C.
!>
!>  Si TRANS='T' et SIDE='L', C est remplacé en sortie par Q**T * C.
!>
!>  Si TRANS='N' et SIDE='R', C est remplacé en sortie par C * Q.
!>
!>  Si TRANS='T' et SIDE='R', C est remplacé en sortie par C * Q**T.
!>
