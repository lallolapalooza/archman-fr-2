sous-programme stpt03 (caractère uplo, caractère trans, caractère diag, entier n, entier nrhs, réel, dimension( * ) ap, réel scale, réel, dimension( * ) cnorm, réel tscal, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, réel resid)

STPT03

Objectif :

!>
!> STPT03 calcule le résidu de la solution d'un système d'équations
!> triangulaires mis à l'échelle A*x = s*b  ou  A'*x = s*b  lorsque la
!> matrice triangulaire A est stockée au format compact. Ici A' est la
!> transposée de A, s est un scalaire, et x et b sont des matrices de
!> taille N par NRHS. Le rapport de test est le maximum sur le nombre de
!> membres de droite de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> où op(A) désigne A ou A' et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou
!>          inférieure.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N' : A *x = s*b  (Pas de transposée)
!>          = 'T' : A'*x = s*b  (Transposée)
!>          = 'C' : A'*x = s*b  (Transposée conjuguée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N' : Triangulaire non unitaire
!>          = 'U' : Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de
!>          colonnes des matrices X et B.  NRHS >= 0.
!>

AP

!>          AP est un tableau REAL, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, stockée
!>          en format compact par colonnes dans un tableau linéaire. La
!>          j-ième colonne de A est stockée dans le tableau AP comme
!>          suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

SCALE

!>          SCALE est REAL
!>          Le facteur d'échelle s utilisé pour résoudre le système
!>          triangulaire.
!>

CNORM

!>          CNORM est un tableau REAL, dimension (N)
!>          Les normes 1 des colonnes de A, sans compter la diagonale.
!>

TSCAL

!>          TSCAL est REAL
!>          Le facteur d'échelle utilisé pour calculer les normes 1 dans
!>          CNORM. CNORM contient en fait les normes de colonne de
!>          TSCAL*A.
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          Les vecteurs du membre de droite pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (N)
!>

RESID

!>          RESID est REAL
!>          Le maximum sur le nombre de membres de droite de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
