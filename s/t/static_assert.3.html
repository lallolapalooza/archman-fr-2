static_assert(3) Manuel des fonctions de bibliothèque static_assert(3)

NOM

static_assert, _Static_assert - Échouer la compilation si l'assertion est fausse

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <assert.h>
void static_assert(bool expression-constante, const char *msg);
/* Depuis C23 : */
void static_assert(bool expression-constante);

DESCRIPTION

Cette macro est similaire à assert(3), mais elle fonctionne au moment de la compilation, générant une erreur de compilation (avec un message facultatif) lorsque l'entrée est fausse (c'est-à-dire qu'elle est égale à zéro).

Si l'entrée est non nulle, aucun code n'est généré.

msg doit être une chaîne littérale. Depuis C23, cet argument est facultatif.

Il existe un mot-clé, _Static_assert(), qui se comporte de manière identique et peut être utilisé sans inclure <assert.h>.

VALEUR DE RETOUR

Aucune valeur n'est retournée.

VERSIONS

En C11, le deuxième argument (msg) était obligatoire ; depuis C23, il peut être omis.

NORMES

C11 et versions ultérieures.

EXEMPLES

static_assert() ne peut pas être utilisé dans certains endroits, par exemple à la portée globale. Pour cela, une macro must_be() peut être écrite en termes de static_assert(). Le programme suivant utilise la macro pour obtenir la taille d'un tableau en toute sécurité.


#include <assert.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
/*
 * Cette macro se comporte comme static_assert(), échouant à
 * compiler si son argument n'est pas vrai. Cependant, elle retourne
 * toujours 0, ce qui permet de l'utiliser partout où une expression
 * peut être utilisée.
 */
#define must_be(e)                                        \
(                                                         \
    0 * (int) sizeof(                                     \
        struct {                                          \
            static_assert(e);                             \
            int  ISO_C_forbids_a_struct_with_no_members;  \
        }                                                 \
    )                                                     \
)
#define is_same_type(a, b)  \
    __builtin_types_compatible_p(typeof(a), typeof(b))
#define is_array(arr)       (!is_same_type((arr), &*(arr)))
#define must_be_array(arr)  must_be(is_array(arr))
#define sizeof_array(arr)   (sizeof(arr) + must_be_array(arr))
#define NITEMS(arr)         (sizeof((arr)) / sizeof((arr)[0]) \
                             + must_be_array(arr))
int     foo[10];
int8_t  bar[sizeof_array(foo)];
int
main(void)
{
    for (size_t i = 0; i < NITEMS(foo); i++) {
        foo[i] = i;
    }
    memcpy(bar, foo, sizeof_array(bar));
    for (size_t i = 0; i < NITEMS(bar); i++) {
        printf("%d,", bar[i]);
    }
    exit(EXIT_SUCCESS);
}
