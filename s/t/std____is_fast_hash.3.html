DESCRIPTION Détaillée

template<typename _Hash>

struct std::__is_fast_hash< _Hash >"Indice sur les performances des fonctions de hachage.

Si un objet fonction de hachage donné n'est pas rapide, les conteneurs basés sur le hachage mettront en cache le code de hachage. Le comportement par défaut est de considérer que les fonctions de hachage sont rapides sauf indication contraire.

Les utilisateurs peuvent spécialiser cela pour leurs propres fonctions de hachage afin de forcer la mise en cache des codes de hachage dans les conteneurs non ordonnés. La spécialisation de ce trait affecte l'ABI des conteneurs non ordonnés, alors utilisez-la avec précaution.
