Description détaillée

Les opérateurs relationnels générés sont stockés ici.

Les en-têtes Libstdc++ ne doivent pas utiliser le contenu de rel_ops. Le code utilisateur doit également l'éviter, car les modèles de fonctions non contraints sont trop voraces et peuvent facilement causer des ambiguïtés.

Les comparaisons par défaut C++20 constituent une meilleure solution.
