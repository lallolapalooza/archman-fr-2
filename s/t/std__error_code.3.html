Description détaillée

Classe error_code

Cette classe est une valeur stockant un numéro d'erreur entier et une catégorie qui donne un sens au numéro d'erreur. Généralement, cela est fait à proximité du point où l'erreur se produit, pour capturer la valeur d'erreur originale.

Un objet error_code peut être utilisé pour stocker la valeur d'erreur originale émise par un sous-système, avec une catégorie pertinente pour le sous-système. Par exemple, les erreurs des fonctions de bibliothèque POSIX peuvent être représentées par une valeur errno et la catégorie "générique", mais les erreurs d'une bibliothèque HTTP pourraient être représentées par un code de statut de réponse HTTP (par exemple, 404) et une catégorie personnalisée définie par la bibliothèque.
