NOM

st-flash - Flasher des fichiers binaires sur un appareil STM32

SYNTAXE

st-flash [OPTIONS] {read|write|erase} [FICHIER] <ADDR> <TAILLE>

DESCRIPTION

Flasher des fichiers binaires sur des sections arbitraires de la mémoire, ou lire des adresses arbitraires de la mémoire vers un fichier binaire.

Vous pouvez utiliser cette commande à la place de st-util(1) si vous préférez, mais n'oubliez pas d'utiliser l'image .bin, plutôt que le fichier .elf.

Utilisez le format hexadécimal pour ADDR et TAILLE.

COMMANDES

write FICHIER ADDR
Écrit le micrologiciel FICHIER sur l'appareil à partir de ADDR
read FICHIER ADDR TAILLE
Lit le micrologiciel depuis l'appareil à partir de ADDR jusqu'à TAILLE octets vers FICHIER
erase
Effectue une effacement complet du micrologiciel de l'appareil
reset
Réinitialise la cible

OPTIONS

--version
Affiche les informations de version
--debug
TODO
--reset
Déclenche une réinitialisation avant et après le flashage
--opt
Active l'optimisation d'ignorance des octets finaux vides
--serial iSerial
TODO
--flash=fsize
Où fsize est la taille en décimal, octal ou hexadécimal suivie d'un multiplicateur optionnel `k' pour KB, ou `m' pour MB. Utilisez un préfixe “0x” pour spécifier l'hexadécimal, ou un zéro initial pour l'octal.

EXEMPLES

Flasher firmware.bin sur l'appareil

$ st-flash write firmware.bin 0x8000000

Lire le micrologiciel depuis l'appareil (4096 octets)

$ st-flash read firmware.bin 0x8000000 0x1000

Effacer le micrologiciel de l'appareil

$ st-flash erase
