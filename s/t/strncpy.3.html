stpncpy(3) Manuel des fonctions de bibliothèque stpncpy(3)

NOM

stpncpy, strncpy - remplir un tampon de taille fixe avec des octets non nuls d'une chaîne, en complétant avec des octets nuls si nécessaire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
char *strncpy(size_t dsize;
              char dst[restrict dsize], const char *restrict src,
              size_t dsize);
char *stpncpy(size_t dsize;
              char dst[restrict dsize], const char *restrict src,
              size_t dsize);
Exigences pour les macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

stpncpy():

    Depuis glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Avant glibc 2.10:
        _GNU_SOURCE

DESCRIPTION

Ces fonctions copient les octets non nuls de la chaîne pointée par src dans le tableau pointé par dst. Si la source a trop peu d'octets non nuls pour remplir la destination, les fonctions complètent la destination avec des octets nuls finaux. Si le tampon de destination, limité par sa taille, n'est pas assez grand pour contenir la copie, la séquence de caractères résultante est tronquée. Pour la différence entre les deux fonctions, voir VALEUR RENVOYÉE.

Une implémentation de ces fonctions pourrait être :


char *
strncpy(char *restrict dst, const char *restrict src, size_t dsize)
{
    stpncpy(dst, src, dsize);
    return dst;
}
char *
stpncpy(char *restrict dst, const char *restrict src, size_t dsize)
{
    size_t  dlen;
    dlen = strnlen(src, dsize);
    return memset(mempcpy(dst, src, dlen), 0, dsize - dlen);
}

VALEUR RENVOYÉE

strncpy()
renvoie dst.
stpncpy()
renvoie un pointeur vers le caractère large non nul qui suit le dernier caractère écrit, c'est-à-dire, dest + strnlen(src, n).

AVERTISSEMENTS

Le nom de ces fonctions est déroutant. Ces fonctions produisent une séquence de caractères complétée par des zéros, pas une chaîne (voir string_copying(7)). Par exemple :


strncpy(buf, "1", 5);       // { '1',   0,   0,   0,   0 }
strncpy(buf, "1234", 5);    // { '1', '2', '3', '4',   0 }
strncpy(buf, "12345", 5);   // { '1', '2', '3', '4', '5' }
strncpy(buf, "123456", 5);  // { '1', '2', '3', '4', '5' }

Il est impossible de distinguer un troncage par le résultat de l'appel, d'une séquence de caractères qui rentre juste dans le tampon de destination ; le troncage doit être détecté en comparant la longueur de la chaîne d'entrée avec la taille du tampon de destination.

Si vous comptez utiliser cette fonction dans des appels chaînés, il serait utile de développer une fonction similaire qui accepte un pointeur vers la fin (un élément après le dernier) du tampon de destination au lieu de sa taille.

EXEMPLES

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(void)
{
    char    *p;
    char    buf1[20];
    char    buf2[20];
    size_t  len;
    if (sizeof(buf2) < strlen("Bonjour le monde !"))
        errx("strncpy: troncage de la séquence de caractères");
    strncpy(buf2, "Bonjour le monde !", sizeof(buf2));
    len = strnlen(buf2, sizeof(buf2));
    printf("[len = %zu]: ", len);
    fwrite(buf2, 1, len, stdout);
    putchar('\n');
    if (sizeof(buf1) < strlen("Bonjour le monde !"))
        errx("stpncpy: troncage de la séquence de caractères");
    p = stpncpy(buf1, "Bonjour le monde !", sizeof(buf1));
    len = p - buf1;
    printf("[len = %zu]: ", len);
    fwrite(buf1, 1, len, stdout);
    putchar('\n');
    exit(EXIT_SUCCESS);
}
