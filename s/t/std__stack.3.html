Description détaillée

template<typename _Tp, typename _Sequence = deque<_Tp>>

class std::stack< _Tp, _Sequence >"Un conteneur standard offrant un comportement FILO.

Paramètres de template

_Tp Type d'élément.
_Sequence Type de séquence sous-jacente, par défaut deque<_Tp>.

Satisfait de nombreuses exigences d'un conteneur, mais ne définit rien concernant les itérateurs. Très peu d'autres interfaces de conteneurs standard sont définies.

Ce n'est pas un conteneur au sens strict, mais un *adaptateur*. Il contient un autre conteneur et fournit une interface enveloppante à ce conteneur. L'enveloppe est ce qui impose le comportement strict de pile premier entré, dernier sorti.

Le second paramètre de template définit le type de la séquence/conteneur sous-jacent. Il est de type std::deque par défaut, mais il peut s'agir de n'importe quel type supportant back, push_back et pop_back, tel que std::list, std::vector, ou un type défini par l'utilisateur approprié.

Les membres non trouvés dans les conteneurs *normaux* sont container_type, qui est un typedef pour le second paramètre Sequence, et push, pop, et top, qui sont les opérations standard de pile/FILO.

template<typename _Tp, typename _Sequence = deque<_Tp>> void std::stack< _Tp, _Sequence >::pop () [inline]

Supprime le premier élément. Ceci est une opération typique de pile. Elle réduit la pile d'un élément. La complexité temporelle de l'opération dépend de la séquence sous-jacente.

Notez qu'aucune donnée n'est retournée, et si les données du premier élément sont nécessaires, elles devraient être récupérées avant d'appeler pop().
