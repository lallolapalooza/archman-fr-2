STEADYFLOW(1) Commandes utilisateur STEADYFLOW(1)

NOM

steadyflow - gestionnaire de téléchargement GTK+

SYNTAXE

steadyflow [commande [args...] [-option1=valeur1] [-option2=valeur2]...]

DESCRIPTION

Steadyflow est un gestionnaire de téléchargement basé sur GTK+ qui vise le minimalisme, la facilité d'utilisation et une base de code propre et malléable. Il devrait être facile à contrôler, que ce soit depuis l'interface graphique, la ligne de commande ou D-Bus.

steadyflow ajouter [url]
Ajoute un fichier à télécharger. Si l'url est omise, remplit la boîte de dialogue d'ajout avec le contenu du presse-papiers s'il s'agit d'une URL valide.
steadyflow afficher
Affiche la fenêtre principale.
steadyflow masquer
Masque la fenêtre principale.
steadyflow aide
Affiche l'écran d'aide.
steadyflow version
Affiche les informations de version.
