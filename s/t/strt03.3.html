But:

!>
!> STRT03 calcule le résidu pour la solution d'un système d'équations triangulaire mis à l'échelle
!> A*x = s*b  ou  A'*x = s*b.
!> Ici A est une matrice triangulaire, A' est la transposée de A, s est un
!> scalaire, et x et b sont des matrices N par NRHS. Le ratio de test est le
!> maximum sur le nombre de seconds membres de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> où op(A) dénote A ou A' et EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  A *x = s*b  (Pas de transposée)
!>          = 'T':  A'*x = s*b  (Transposée)
!>          = 'C':  A'*x = s*b  (Transposée conjuguée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.  NRHS >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure n par n de premier plan du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          triangulaire inférieure n par n de premier plan du tableau A contient
!>          la matrice triangulaire inférieure, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.  Si DIAG = 'U',
!>          les éléments diagonaux de A ne sont pas non plus référencés et sont
!>          supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

SCALE

!>          SCALE est REAL
!>          Le facteur de mise à l'échelle s utilisé pour résoudre le système
!>          triangulaire.
!>

CNORM

!>          CNORM est un tableau de type REAL, de dimension (N)
!>          Les normes 1 des colonnes de A, sans compter la diagonale.
!>

TSCAL

!>          TSCAL est REAL
!>          Le facteur de mise à l'échelle utilisé pour calculer les normes 1 dans CNORM.
!>          CNORM contient en fait les normes de colonne de TSCAL*A.
!>

X

!>          X est un tableau de type REAL, de dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau de type REAL, de dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (N)
!>

RESID

!>          RESID est REAL
!>          Le maximum sur le nombre de seconds membres de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
