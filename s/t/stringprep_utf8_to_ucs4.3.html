NOM

stringprep_utf8_to_ucs4 - Fonction API

SYNTAXE

#include <stringprep.h>

uint32_t * stringprep_utf8_to_ucs4(const char * str, ssize_t len, size_t * items_written);

ARGUMENTS

const char * str
une chaîne encodée en UTF-8
ssize_t len
la longueur maximale de str à utiliser. Si len < 0, alors la chaîne est terminée par un caractère nul.
size_t * items_written
l'emplacement où stocker le nombre de caractères dans le résultat, ou NULL.

DESCRIPTION

Convertit une chaîne de UTF-8 vers une représentation UCS-4 fixe de 32 bits. La fonction effectue maintenant une vérification pour s'assurer que l'entrée est du UTF-8 valide (auparavant, il était documenté qu'elle ne vérifiait pas les erreurs).

Valeur de retour : un pointeur vers une chaîne UCS-4 nouvellement allouée. Cette valeur doit être libérée par l'appelant.
