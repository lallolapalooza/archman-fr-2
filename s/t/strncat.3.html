strncat(3) Manuel des fonctions de bibliothèque strncat(3)

NOM

strncat - ajoute au plus le nombre d'octets non nuls spécifié d'une source à une chaîne, et termine le résultat par un caractère nul

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <string.h>
char *strncat(size_t ssize;
              char *restrict dst, const char src[restrict ssize],
              size_t ssize);

DESCRIPTION

Cette fonction ajoute au plus ssize octets non nuls du tableau pointé par src, suivi d'un caractère nul, à la fin de la chaîne pointée par dst. dst doit pointer vers une chaîne contenue dans un tampon suffisamment grand, c'est-à-dire que la taille du tampon doit être au moins égale à strlen(dst) + strnlen(src, ssize) + 1.

Une implémentation de cette fonction pourrait être :


char *
strncat(char *restrict dst, const char *restrict src, size_t ssize)
{
    #define strnul(s)  (s + strlen(s))
    stpcpy(mempcpy(strnul(dst), src, strnlen(src, ssize)), "");
    return dst;
}

VALEUR RENVOYÉE

strncat() renvoie dst.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strncat () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89, SVr4, 4.3BSD.

ATTENTION

Le nom de cette fonction est trompeur ; elle n'a aucun rapport avec strncpy(3).

Si le tampon de destination ne contient pas déjà une chaîne, ou n'est pas suffisamment grand, le comportement est indéfini. Voir _FORTIFY_SOURCE dans feature_test_macros(7).

BOGUES

Cette fonction peut être très inefficace. Lire sur Shlemiel the painter.

EXEMPLES

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define NITEMS(arr)  (sizeof((arr)) / sizeof((arr)[0]))
int
main(void)
{
    size_t  n;
    // Séquences de caractères de taille fixe, complétées par des zéros
    char    pre[4] = "pre.";
    char    new_post[50] = ".foo.bar";
    // Chaînes
    char    post[] = ".post";
    char    src[] = "some_long_body.post";
    char    *dest;
    n = NITEMS(pre) + strlen(src) - strlen(post) + NITEMS(new_post) + 1;
    dest = malloc(sizeof(*dest) * n);
    if (dest == NULL)
        err(EXIT_FAILURE, "malloc()");
    dest[0] = '\0';  // Il n'y a pas de fonction 'cpy' pour ce 'cat'.
    strncat(dest, pre, NITEMS(pre));
    strncat(dest, src, strlen(src) - strlen(post));
    strncat(dest, new_post, NITEMS(new_post));
    puts(dest);  // "pre.some_long_body.foo.bar"
    free(dest);
    exit(EXIT_SUCCESS);
}
