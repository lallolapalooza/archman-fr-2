Description Détaillée

template<typename _Key, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<_Key>>

class std::multiset< _Key, _Compare, _Alloc >"Un conteneur standard composé d'éléments qui peuvent être récupérés en temps logarithmique.

Depuis

C++98

Paramètres de modèle

_Key Type des objets clés.
_Compare Type de l'objet fonction de comparaison, par défaut less<_Key>.
_Alloc Type de l'allocateur, par défaut allocator<_Key>.

Répond aux exigences d'un conteneur, d'un conteneur réversible et d'un conteneur associatif (utilisant des clés équivalentes). Pour un multiset<Key> le key_type et le value_type sont Key.

Les multisets supportent les itérateurs bidirectionnels.

Les données de l'arbre privé sont déclarées exactement de la même manière pour set et multiset ; la distinction est entièrement faite dans la manière dont les fonctions de l'arbre sont appelées (*_unique versus *_equal, identique au standard).

Cette fonction insère un élément dans le multiset. Contrairement à un std::set, le multiset ne repose pas sur des clés uniques et donc plusieurs copies du même élément peuvent être insérées.

DESCRIPTION

La classe std::multiset est un conteneur associatif qui stocke des éléments d'un type donné dans un ordre spécifié par une fonction de comparaison. Contrairement à std::set, std::multiset permet la présence de plusieurs éléments ayant la même valeur (clé).

Les éléments sont toujours triés selon la fonction de comparaison fournie lors de la construction du conteneur. Par défaut, il s'agit de std::less, ce qui signifie que les éléments sont triés en ordre croissant.

Les opérations d'insertion et de suppression maintiennent l'ordre des éléments. Les recherches sont efficaces et ont une complexité logarithmique par rapport au nombre d'éléments.

Les principaux avantages de std::multiset sont :

  • Maintient automatiquement les éléments triés.
  • Permet les doublons.
  • Recherche, insertion et suppression efficaces (complexité O(log n)).

Le principal inconvénient est la surcharge de mémoire et de temps due à la nécessité de maintenir la structure de données triée.

Utilisez std::multiset lorsque vous avez besoin de stocker des éléments triés et que vous devez pouvoir retrouver rapidement des éléments ou des plages d'éléments, et que vous avez la possibilité d'avoir des doublons.

EXEMPLE

Voici un exemple simple d'utilisation de std::multiset :

#include <iostream>
#include <set>
#include <string>

int main()
{
    std::multiset<int> numbers;

    // Insertion d'éléments
    numbers.insert(40);
    numbers.insert(20);
    numbers.insert(60);
    numbers.insert(20); // Insertion d'un doublon
    numbers.insert(50);

    // Affichage des éléments triés
    std::cout << "Elements in the multiset:" << std::endl;
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    // Sortie : 20 20 40 50 60

    // Recherche d'un élément
    int key_to_find = 20;
    auto it = numbers.find(key_to_find);
    if (it != numbers.end()) {
        std::cout << "Found " << key_to_find << " in the multiset." << std::endl;
    }

    // Compte du nombre d'occurrences d'un élément
    std::cout << "Count of " << key_to_find << ": " << numbers.count(key_to_find) << std::endl;
    // Sortie : Count of 20: 2

    // Utilisation de lower_bound et upper_bound
    std::cout << "Elements greater than or equal to 30:" << std::endl;
    auto lb = numbers.lower_bound(30);
    for (auto current_it = lb; current_it != numbers.end(); ++current_it) {
        std::cout << *current_it << " ";
    }
    std::cout << std::endl;
    // Sortie : 40 50 60

    std::cout << "Elements greater than 30:" << std::endl;
    auto ub = numbers.upper_bound(30);
     for (auto current_it = ub; current_it != numbers.end(); ++current_it) {
        std::cout << *current_it << " ";
    }
    std::cout << std::endl;
    // Sortie : 40 50 60

    // Suppression d'un élément
    numbers.erase(key_to_find); // Supprime une occurrence de 20
    std::cout << "After erasing one " << key_to_find << ":" << std::endl;
     for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    // Sortie : 20 40 50 60

    return 0;
}

Cela échange les éléments entre deux multiset en temps constant. (Il ne fait que permuter un pointeur, un entier et une instance du type Compare (qui est souvent sans état et vide), donc cela devrait être assez rapide.) Notez que la fonction globale std::swap() est spécialisée de telle sorte que std::swap(s1,s2) appellera cette fonction.

Le fait que les allocateurs soient échangés dépend des caractéristiques de l'allocateur.

Référencé par std::swap().
