Description détaillée

template<typename _CharT, typename _Traits, typename _Alloc> class basic_stringbuf< _CharT, _Traits, _Alloc >

Cette classe est une spécialisation des basic_streambuf qui gère une chaîne basic_string comme son tampon d'entrée/sortie.

Elle est la classe de base pour std::stringbuf et std::wstringbuf.

Regarde en avant dans le flux.

Retourne

Le nombre de caractères disponibles.

Si une position de lecture est disponible, retourne le nombre de caractères disponibles pour la lecture avant que le tampon ne doive être rempli à nouveau. Sinon, retourne le showmanyc() dérivé.

template<class _CharT, class _Traits, class _Alloc> basic_stringbuf< _CharT, _Traits, _Alloc >::int_type std::basic_stringbuf< _CharT, _Traits, _Alloc >::overflow (int_type __c = traits_type::eof()) [protected], [virtual]

Consomme les données du tampon ; écrit dans la séquence contrôlée.

Paramètres

__c Un caractère supplémentaire à consommer.

Retourne

eof() pour indiquer un échec, autre chose (généralement __c, ou not_eof())

Informellement, cette fonction est appelée lorsque le tampon de sortie est plein (ou n'existe pas, car la mise en tampon n'est pas nécessairement effectuée). Si un tampon existe, il est *consommé*, avec un *effet quelconque* sur la séquence contrôlée. (Typiquement, le tampon est écrit dans la séquence tel quel.) Dans les deux cas, le caractère *c* est également écrit, si *__c* n'est pas eof().

Pour une définition formelle de cette fonction, voir un bon ouvrage comme Langer & Kreft, ou [27.5.2.4.5]/3-7.

Un streambuf de sortie fonctionnel peut être créé en surchargeant uniquement cette fonction (aucune zone tampon ne sera utilisée).

Note

La version de la classe de base ne fait rien, retourne eof().

Réimplémenté à partir de std::basic_streambuf< _CharT, _Traits >.

Essaie de reculer dans la séquence d'entrée.

Paramètres
