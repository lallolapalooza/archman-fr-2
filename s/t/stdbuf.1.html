STDBUF(1) Commandes utilisateur STDBUF(1)

NOM

stdbuf - Exécute COMMAND, avec des opérations de mise en tampon modifiées pour ses flux standards.

SYNTAXE

stdbuf OPTION... COMMAND

DESCRIPTION

Exécute COMMAND, avec des opérations de mise en tampon modifiées pour ses flux standards.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-i, --input=MODE
ajuste la mise en tampon du flux d'entrée standard
-o, --output=MODE
ajuste la mise en tampon du flux de sortie standard
-e, --error=MODE
ajuste la mise en tampon du flux d'erreur standard
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Si MODE est 'L', le flux correspondant sera mis en tampon par ligne. Cette option est invalide avec l'entrée standard.

Si MODE est '0', le flux correspondant ne sera pas mis en tampon.

Sinon, MODE est un nombre qui peut être suivi de l'un des éléments suivants : KB 1000, K 1024, MB 1000*1000, M 1024*1024, et ainsi de suite pour G, T, P, E, Z, Y, R, Q. Les préfixes binaires peuvent également être utilisés : KiB=K, MiB=M, et ainsi de suite. Dans ce cas, le flux correspondant sera entièrement mis en tampon avec une taille de tampon définie à MODE octets.

REMARQUE : Si COMMAND ajuste la mise en tampon de ses flux standards (ce que fait 'tee', par exemple), cela remplacera les modifications correspondantes de 'stdbuf'. De plus, certains filtres (comme 'dd' et 'cat', etc.) n'utilisent pas de flux pour les entrées/sorties et sont donc affectés par les paramètres de 'stdbuf'.

Code de sortie :

125
si la commande stdbuf elle-même échoue
126
si COMMAND est trouvé mais ne peut pas être invoqué
127
si COMMAND ne peut pas être trouvé
-
le code de sortie de COMMAND sinon

EXEMPLES

tail -f access.log | stdbuf -oL cut -d ' ' -f1 | uniq
Ceci affichera immédiatement les entrées uniques d'access.log

BOGUES

Sur les plateformes GLIBC, spécifier une taille de tampon, c'est-à-dire utiliser le mode entièrement tamponné, entraînera un comportement indéfini.
