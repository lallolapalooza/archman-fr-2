template<typename _CharT, typename _Traits> std::basic_istream< _CharT, _Traits >::sentry::sentry (basic_istream< _CharT, _Traits > & __is, bool __noskipws = false) [explicit]

Paramètres

__is Le flux d'entrée à protéger.
__noskipws Indique s'il faut consommer les espaces blancs ou non.

Si l'état du flux est bon (__is.good() est vrai), alors les actions suivantes sont effectuées, sinon l'état du sentry est faux (pas bon) et failbit est défini dans l'état du flux.

Les actions préparatoires du sentry sont :

1.
si le flux est lié à un flux de sortie, is.tie()->flush() est appelé pour synchroniser la séquence de sortie
2.
si __noskipws est faux, et ios_base::skipws est défini dans is.flags(), le sentry extrait et ignore les caractères d'espacement du flux. La locale actuellement imbriquée est utilisée pour déterminer si chaque caractère est un espace blanc.

Si l'état du flux est toujours bon, alors l'état du sentry devient vrai (bon).

Références std::basic_istream< _CharT, _Traits >::basic_istream(), std::ios_base::badbit, std::basic_ios< _CharT, _Traits >::good(), et std::ios_base::goodbit.
