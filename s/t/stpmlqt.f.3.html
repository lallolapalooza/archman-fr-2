Documentation de la fonction/sous-routine

sous-routine stpmlqt (caractère side, caractère trans, entier m, entier n, entier k, entier l, entier mb, réel, dimension( ldv, * ) v, entier ldv, réel, dimension( ldt, * ) t, entier ldt, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) work, entier info)

STPMLQT

Objectif :

!>
!> STPMLQT applique une matrice orthogonale réelle Q obtenue à partir d'un
!>  réflecteur bloc réel H à une matrice réelle générale
!> C, qui est composée de deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est CARACTERE*1
!>          = 'L': applique Q ou Q**T depuis la gauche ;
!>          = 'R': applique Q ou Q**T depuis la droite.
!>

TRANS

!>          TRANS est CARACTERE*1
!>          = 'N': Pas de transposition, applique Q ;
!>          = 'T': Transposition, applique Q**T.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est ENTIER
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0. Voir Détails supplémentaires.
!>

MB

!>          MB est ENTIER
!>          La taille de bloc utilisée pour le stockage de T. K >= MB >= 1.
!>          Doit être la même valeur de MB utilisée pour générer T
!>          dans STPLQT.
!>

V

!>          V est un tableau REEL, dimension (LDV,K)
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          STPLQT dans B. Voir Détails supplémentaires.
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale du tableau V. LDV >= K.
!>

T

!>          T est un tableau REEL, dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs blocs
!>          tels que retournés par STPLQT, stockés sous forme de matrice MBxK.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= MB.
!>

A

!>          A est un tableau REEL, dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice A de taille KxN ou MxK.
!>          À la sortie, A est écrasé par le bloc correspondant de
!>          Q*C ou Q**T*C ou C*Q ou C*Q**T. Voir Détails supplémentaires.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,K) ;
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B est un tableau REEL, dimension (LDB,N)
!>          À l'entrée, la matrice B de taille MxN.
!>          À la sortie, B est écrasé par le bloc correspondant de
!>          Q*C ou Q**T*C ou C*Q ou C*Q**T. Voir Détails supplémentaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau REEL. La dimension de WORK est
!>           N*MB si SIDE = 'L', ou M*MB si SIDE = 'R'.
!>

INFO

!>          INFO est ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument était invalide
!>

Détails supplémentaires :

!>
!>  Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!>  élémentaires H(1), H(2), ..., H(K) ; V est composée d'un bloc rectangulaire V1 et d'un
!>  bloc trapézoïdal V2 :
!>
!>        V = [V1] [V2].
!>
!>
!>  La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!>  où 0 <= L <= K ; V2 est trapézoïdal inférieure, constituée des L
!>  premières lignes d'une matrice triangulaire supérieure KxK. Si L=K, V2 est triangulaire inférieure ;
!>  si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!>  Si SIDE = 'L' : C = [A] où A est KxN, B est MxN et V est KxM.
!>                      [B]
!>
!>  Si SIDE = 'R' : C = [A B] où A est MxK, B est MxN et V est KxN.
!>
!>  La matrice orthogonale réelle Q est formée à partir de V et T.
!>
!>  Si TRANS='N' et SIDE='L', C est remplacé à la sortie par Q * C.
!>
!>  Si TRANS='T' et SIDE='L', C est remplacé à la sortie par Q**T * C.
!>
!>  Si TRANS='N' et SIDE='R', C est remplacé à la sortie par C * Q.
!>
!>  Si TRANS='T' et SIDE='R', C est remplacé à la sortie par C * Q**T.
!>
