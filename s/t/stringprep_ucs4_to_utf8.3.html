NOM

stringprep_ucs4_to_utf8 - fonction d'API

SYNTAXE

#include <stringprep.h>

char * stringprep_ucs4_to_utf8(const uint32_t * str, ssize_t len, size_t * items_read, size_t * items_written);

ARGUMENTS

const uint32_t * str
une chaîne encodée en UCS-4
ssize_t len
la longueur maximale de str à utiliser. Si len < 0, alors la chaîne est terminée par un caractère 0.
size_t * items_read
emplacement pour stocker le nombre de caractères lus, ou NULL.
size_t * items_written
emplacement pour stocker le nombre d'octets écrits ou NULL. La valeur stockée ici n'inclut pas l'octet 0 de terminaison.

DESCRIPTION

Convertit une chaîne d'une représentation UCS-4 à largeur fixe de 32 bits en UTF-8. Le résultat sera terminé par un octet 0.

Valeur de retour : un pointeur vers une nouvelle chaîne UTF-8 allouée. Cette valeur doit être désallouée par l'appelant. En cas d'erreur, NULL sera retourné.
