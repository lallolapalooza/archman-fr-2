class std::basic_stringbuf< _CharT, _Traits, _Alloc >"Le travail réel d'entrée et de sortie (pour std::string).

Paramètres du modèle

_CharT Type de flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.
_Alloc Type d'allocateur, par défaut allocator<_CharT>.

Cette classe associe une ou les deux de ses séquences d'entrée et de sortie à une séquence de caractères, qui peut être initialisée à partir de, ou rendue disponible comme, une std::basic_string. (Paraphrasé de [27.7.1]/1.)

Pour cette classe, les modes ouverts (de type ios_base::openmode) ont le bit in défini si la séquence d'entrée peut être lue, et le bit out défini si la séquence de sortie peut être écrite.

template<class _CharT, class _Traits, class _Alloc> basic_stringbuf< _CharT, _Traits, _Alloc >::int_type std::basic_stringbuf< _CharT, _Traits, _Alloc >::overflow (int_type __c = traits_type::eof()) [protected], [virtual]

Consomme les données du tampon ; écrit dans la séquence contrôlée.

Paramètres

__c Un caractère supplémentaire à consommer.

Retourne

eof() pour indiquer un échec, autre chose (généralement __c, ou not_eof())

Informellement, cette fonction est appelée lorsque le tampon de sortie est plein (ou n'existe pas, car la mise en tampon n'est pas nécessairement effectuée). Si un tampon existe, il est consommé, avec un certain effet sur la séquence contrôlée. (Typiquement, le tampon est écrit dans la séquence tel quel.) Dans les deux cas, le caractère c est également écrit, si __c n'est pas eof().

Pour une définition formelle de cette fonction, consultez un bon ouvrage tel que Langer & Kreft, ou [27.5.2.4.5]/3-7.

Un tampon de flux de sortie fonctionnel peut être créé en remplaçant uniquement cette fonction (aucune zone de tampon ne sera utilisée).

Note

La version de la classe de base ne fait rien, retourne eof().

Réimplémenté à partir de std::basic_streambuf< _CharT, _Traits >.

Récupère des données supplémentaires de la séquence contrôlée.

Retourne

Le premier caractère de la séquence en attente.

Informellement, cette fonction est appelée lorsque le tampon d'entrée est épuisé (ou n'existe pas, car la mise en tampon n'est pas nécessairement effectuée).
