Extracteurs
Toutes les fonctions operator>> (également appelées _fonctions d'entrée formatée_) ont un comportement commun. Chacune commence par construire un objet temporaire de type std::basic_istream::sentry avec le second argument (noskipws) défini sur false. Cela a plusieurs effets, aboutissant à la définition d'un indicateur d'état ; voir la documentation de sentry pour plus de détails.

Si l'état du sentry est bon, la fonction essaie d'extraire les données appropriées au type de l'argument.

Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer la levée d'une ios_base::failure) et l'exception originale sera relancée si badbit est activé dans le masque des exceptions.

template<typename _CharT, typename _Traits, typename _Alloc>

class std::basic_stringstream< _CharT, _Traits, _Alloc >

Contrôle l'entrée et la sortie pour std::string.

Paramètres du modèle

_CharT Type du flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.
_Alloc Type d'allocateur, par défaut allocator<_CharT>.

Cette classe prend en charge la lecture et l'écriture d'objets de type std::basic_string, en utilisant les fonctions héritées de std::basic_iostream. Pour contrôler la séquence associée, une instance de std::basic_stringbuf est utilisée, à laquelle cette page fait référence sous le nom de sb.

Documentation des typedefs membres

typedef void(* std::ios_base::event_callback) (event __e, ios_base &__b, int __i) [inherited]

Le type d'une fonction de rappel d'événement.

Paramètres

__e L'un des membres de l'énumération event.
__b Référence à l'objet ios_base.
__i L'entier fourni lors de l'enregistrement du rappel.

Les rappels d'événements sont des fonctions définies par l'utilisateur qui sont appelées lors de plusieurs fonctions ios_base et basic_ios, spécifiquement imbue(), copyfmt(), et ~ios().

typedef _Ios_Iostate std::ios_base::iostate [inherited]

Ceci est un type de masque de bits. _Ios_Iostate est défini par l'implémentation, mais il est valide d'effectuer des opérations bit à bit sur ces valeurs et de s'attendre à ce que la bonne chose se produise. Les objets définis de type iostate sont :

  • badbit
  • eofbit
  • failbit
  • goodbit

typedef _Ios_Openmode std::ios_base::openmode [inherited]

Ceci est un type de masque de bits. _Ios_Openmode est défini par l'implémentation, mais il est valide d'effectuer des opérations bit à bit sur ces valeurs et de s'attendre à ce que la bonne chose se produise. Les objets définis de type openmode sont :

  • app
  • ate
  • binary
  • in
  • out
  • trunc

typedef _Ios_Seekdir std::ios_base::seekdir [inherited]

Ceci est un type énuméré. _Ios_Seekdir est défini par l'implémentation. Les valeurs définies de type seekdir sont :

  • beg
  • cur, équivalent à SEEK_CUR dans la bibliothèque standard C.
  • end, équivalent à SEEK_END dans la bibliothèque standard C.
