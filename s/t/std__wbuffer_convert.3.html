DESCRIPTION

The std::basic_streambuf class template is the base class for stream buffers. Stream buffers are used by input and output streams to handle their I/O. This class template provides a common interface for derived classes and implements some basic functionality.

A stream buffer is conceptually divided into two parts: the input sequence and the output sequence. For each sequence, there are three pointers maintained: the beginning of the buffer, the next character to be read or written, and the end of the buffer.

Derived classes must override the following virtual protected member functions:

  • underflow(): Returns the next input character, refilling the buffer if necessary.

  • overflow(): Called when the output buffer is full or needs to be written.

  • seekoff(): Changes the stream position.

  • seekpos(): Changes the stream position.

  • sync(): Flushes the output buffer.

  • imbue(): Called when the stream's locale is changed.

The following member functions are the public interface to the stream buffer operations:
