Documentation de la fonction/sous-programme

sous-programme strttp (caractere uplo, entier n, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) ap, entier info)

STRTTP copie une matrice triangulaire du format complet standard (TR) au format compact standard (TP).

Objectif :

!>
!> STRTTP copie une matrice triangulaire A du format complet (TR) au format compact
!> standard (TP).
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U':  A est triangulaire supérieure.
!>          = 'L':  A est triangulaire inférieure.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices AP et A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          En sortie, la matrice triangulaire A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire de taille N x N d'A contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire d'A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire de taille N x N d'A contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire d'A n'est pas référencée.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AP

!>          AP est un tableau REEL, dimension (N*(N+1)/2)
!>          En sortie, la matrice triangulaire supérieure ou inférieure A,
!>          compactée par colonne dans un tableau linéaire. La j-ème colonne de A est
!>          stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
