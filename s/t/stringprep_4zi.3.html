NOM

stringprep_4zi - Fonction API

SYNTAXE

#include <stringprep.h>

int stringprep_4zi(uint32_t * ucs4, size_t maxucs4len, Stringprep_profile_flags flags, const Stringprep_profile * profile);

ARGUMENTS

uint32_t * ucs4
chaîne à préparer, terminée par un caractère nul, en entrée/sortie.
size_t maxucs4len
longueur maximale du tableau d'entrée/sortie.
Stringprep_profile_flags flags
une valeur Stringprep_profile_flags, ou 0.
const Stringprep_profile * profile
pointeur vers le Stringprep_profile à utiliser.

DESCRIPTION

Prépare la chaîne d'entrée UCS-4 terminée par un caractère nul selon le profil stringprep, et réécrit le résultat dans la chaîne d'entrée.

Comme l'opération stringprep peut étendre la chaîne, maxucs4len indique la taille du tampon contenant la chaîne. Cette fonction ne lira ni n'écrira de points de code en dehors de cette taille.

Les flags sont l'une des valeurs de Stringprep_profile_flags, ou 0.

Le profile contient les instructions Stringprep_profile à exécuter. Votre application peut définir de nouveaux profils, en réutilisant éventuellement les tables stringprep génériques qui feront toujours partie de la bibliothèque, ou utiliser l'un des profils actuellement pris en charge.

Valeur de retour : Renvoie STRINGPREP_OK en cas de succès, ou un code d'erreur Stringprep_rc.
