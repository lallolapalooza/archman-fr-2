Documentation de la fonction/sous-routine

sous-routine stgsy2 (caractère trans, entier ijob, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( ldd, * ) d, entier ldd, réel, dimension( lde, * ) e, entier lde, réel, dimension( ldf, * ) f, entier ldf, réel scale, réel rdsum, réel rdscal, entier, dimension( * ) iwork, entier pq, entier info)

STGSY2 résout l'équation de Sylvester généralisée (algorithme non bloqué).

Objectif :

!>
!> STGSY2 résout l'équation de Sylvester généralisée :
!>
!>             A * R - L * B = scale * C                (1)
!>             D * R - L * E = scale * F,
!>
!> en utilisant les routines BLAS de niveau 1 et 2. Où R et L sont des matrices inconnues de taille M-par-N,
!> (A, D), (B, E) et (C, F) sont des paires de matrices données de tailles M-par-M,
!> N-par-N et M-par-N, respectivement, avec des entrées réelles. (A, D) et (B, E)
!> doivent être en forme canonique quasi-Schur généralisée, c'est-à-dire que A, B sont quasi-triangulaires supérieures
!> et D, E sont triangulaires supérieures. La solution (R, L)
!> écrase (C, F). 0 <= SCALE <= 1 est un facteur d'échelle de sortie
!> choisi pour éviter les débordements.
!>
!> En notation matricielle, la résolution de l'équation (1) correspond à la résolution de
!> Z*x = scale*b, où Z est défini comme
!>
!>        Z = [ kron(In, A)  -kron(B**T, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**T, Im) ],
!>
!> Ik est la matrice identité de taille k et X**T est la transposée de X.
!> kron(X, Y) est le produit de Kronecker entre les matrices X et Y.
!> Dans le processus de résolution de (1), nous résolvons un certain nombre de systèmes de ce type
!> où Dim(In), Dim(In) = 1 ou 2.
!>
!> Si TRANS = 'T', résout le système transposé Z**T*y = scale*b pour y,
!> ce qui équivaut à résoudre pour R et L dans
!>
!>             A**T * R  + D**T * L   = scale * C           (3)
!>             R  * B**T + L  * E**T  = scale * -F
!>
!> Ce cas est utilisé pour calculer une estimation de Dif[(A, D), (B, E)] =
!> sigma_min(Z) en utilisant la communication inverse avec SLACON.
!>
!> STGSY2 contribue également (IJOB >= 1) au calcul dans STGSYL
!> d'une borne supérieure de la séparation entre deux paires de matrices. Alors
!> les entrées (A, D), (B, E) sont des sous-pencils de la paire de matrices dans
!> STGSYL. Voir STGSYL pour les détails.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N': résout l'équation de Sylvester généralisée (1).
!>          = 'T': résout le système 'transposé' (3).
!>

IJOB

!>          IJOB est INTEGER
!>          Spécifie le type de fonctionnalité à effectuer.
!>          = 0: résout (1) seulement.
!>          = 1: Une contribution de ce sous-système à une estimation basée sur la norme de Frobenius
!>               de la séparation entre deux paires de matrices est calculée. (la stratégie de prévisualisation est utilisée).
!>          = 2: Une contribution de ce sous-système à une estimation basée sur la norme de Frobenius
!>               de la séparation entre deux paires de matrices est calculée. (SGECON sur les sous-systèmes est utilisé.)
!>          Non référencé si TRANS = 'T'.
!>

M

!>          M est INTEGER
!>          À l'entrée, M spécifie l'ordre de A et D, et la dimension de ligne
!>          de C, F, R et L.
!>

N

!>          N est INTEGER
!>          À l'entrée, N spécifie l'ordre de B et E, et la dimension de colonne
!>          de C, F, R et L.
!>

A

!>          A est un tableau REEL, dimension (LDA, M)
!>          À l'entrée, A contient une matrice quasi-triangulaire supérieure.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de la matrice A. LDA >= max(1, M).
!>

B

!>          B est un tableau REEL, dimension (LDB, N)
!>          À l'entrée, B contient une matrice quasi-triangulaire supérieure.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de la matrice B. LDB >= max(1, N).
!>

C

!>          C est un tableau REEL, dimension (LDC, N)
!>          À l'entrée, C contient le membre de droite de la première matrice
!>          de l'équation (1).
!>          À la sortie, si IJOB = 0, C a été écrasé par la solution R.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale de la matrice C. LDC >= max(1, M).
!>

D

!>          D est un tableau REEL, dimension (LDD, M)
!>          À l'entrée, D contient une matrice triangulaire supérieure.
!>

LDD

!>          LDD est INTEGER
!>          La dimension principale de la matrice D. LDD >= max(1, M).
!>

E

!>          E est un tableau REEL, dimension (LDE, N)
!>          À l'entrée, E contient une matrice triangulaire supérieure.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale de la matrice E. LDE >= max(1, N).
!>

F

!>          F est un tableau REEL, dimension (LDF, N)
!>          À l'entrée, F contient le membre de droite de la deuxième matrice
!>          de l'équation (1).
!>          À la sortie, si IJOB = 0, F a été écrasé par la solution L.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale de la matrice F. LDF >= max(1, M).
!>

SCALE

!>          SCALE est REEL
!>          À la sortie, 0 <= SCALE <= 1. Si 0 < SCALE < 1, les solutions
!>          R et L (C et F à l'entrée) contiendront les solutions d'un
!>          système légèrement perturbé mais les matrices d'entrée A, B, D et
!>          E n'ont pas été modifiées. Si SCALE = 0, R et L contiendront
!>          les solutions du système homogène avec C = F = 0. Normalement,
!>          SCALE = 1.
!>

RDSUM

!>          RDSUM est REEL
!>          À l'entrée, la somme des carrés des contributions calculées à
!>          l'estimation de Dif en cours de calcul par STGSYL, où le
!>          facteur d'échelle RDSCAL (voir ci-dessous) a été extrait.
!>          À la sortie, la somme des carrés correspondante mise à jour avec les
!>          contributions du sous-système actuel.
!>          Si TRANS = 'T', RDSUM n'est pas modifié.
!>          NOTE : RDSUM n'a de sens que lorsque STGSY2 est appelé par STGSYL.
!>

RDSCAL

!>          RDSCAL est REEL
!>          À l'entrée, le facteur d'échelle utilisé pour éviter les débordements dans RDSUM.
!>          À la sortie, RDSCAL est mis à jour par rapport aux contributions actuelles
!>          dans RDSUM.
!>          Si TRANS = 'T', RDSCAL n'est pas modifié.
!>          NOTE : RDSCAL n'a de sens que lorsque STGSY2 est appelé par
!>                STGSYL.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (M+N+2)
!>

PQ

!>          PQ est INTEGER
!>          À la sortie, le nombre de sous-systèmes (de taille 2x2, 4x4 et
!>          8x8) résolus par cette routine.
!>

INFO

!>          INFO est INTEGER
!>          À la sortie, si INFO est défini comme
!>            =0: Sortie réussie
!>            <0: Si INFO = -i, le i-ème argument n'était pas valide.
!>            >0: Les paires de matrices (A, D) et (B, E) ont des valeurs propres communes ou très
!>                proches.
!>

stgsy2 -

SYNOPSIS

Functions/Subroutines

 SUBROUTINE STGSY2( TRANA, TRANS, N, NB, A, LDA, B, LDB, C, LDC, R, GDR, LDR, LDGDR, IFAIL )

Function/Subroutine Documentation

stgsy2

Purpose:

STGSY2 solves the real generalized Sylvester equation

A*R - S*B = C

or

A*R - S*B = C

where R and S are unknown matrices, and A, B, C are given matrices.

A, B, C are assumed to be in real Schur form, i.e.,

A = Q*A'*Q**T

B = Q*B'*Q**T

where Q is orthogonal and A', B' are upper quasi-triangular.

C is an arbitrary real matrix. Q is the orthogonal matrix computed by

DGEES, DGESVD or DHGESDD.

A' and B' are the matrices in real Schur form, obtained by

DTGSEN. STGSY2 expects matrices A and B to be in real Schur form.

If TRANS = 'N', the equation is

A*R - S*B = C

If TRANS = 'T', the equation is

A**T*R - S*B**T = C

If TRANS = 'C', the equation is

A**C*R - S*B**C = C

This subroutine is an internal routine. It is used to solve the

generalized Sylvester equation for the LMI control design.

Arguments:

TRANA
CHARACTER*1.

On entry, TRANA specifies whether to transpose A.

'N': Do not transpose A.

'T': Transpose A.

'C': Transpose A (conjugate). In this case, A is real, so

A' is A**T.

TRANS
CHARACTER*1.

On entry, TRANS specifies whether to transpose B.

'N': Do not transpose B.

'T': Transpose B.

'C': Transpose B (conjugate). In this case, B is real, so

B' is B**T.

N
INTEGER.

On entry, N is the order of the matrices A and B.

NB
INTEGER.

On entry, NB is the blocking size for the matrix R and S.

A
DOUBLE PRECISION array, dimension (LDA, N).

On entry, A is N x N matrix in real Schur form.

LDA
INTEGER.

On entry, LDA is the leading dimension of the array A.

B
DOUBLE PRECISION array, dimension (LDB, N).

On entry, B is N x N matrix in real Schur form.

LDB
INTEGER.

On entry, LDB is the leading dimension of the array B.

C
DOUBLE PRECISION array, dimension (LDC, N).

On entry, C is the right hand side matrix N x N.

On exit, C has been overwritten by the solution R.

LDC
INTEGER.

On entry, LDC is the leading dimension of the array C.

R
DOUBLE PRECISION array, dimension (LDR, N).

On exit, R is the N x N solution matrix.

GDR
DOUBLE PRECISION array, dimension (LDGDR, N).

On exit, GDR is the N x N solution matrix S.

LDR
INTEGER.

On entry, LDR is the leading dimension of the array R.

LDGDR
INTEGER.

On entry, LDGDR is the leading dimension of the array GDR.

IFAIL
INTEGER array, dimension (N).

On exit, IFAIL indicates how the equation was solved for each

subproblem.

0: Subproblem solved successfully.

1: The subproblem is singular, and the solution could not be

computed.

2: The solution to the subproblem is not unique.
