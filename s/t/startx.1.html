STARTX(1) Manuel des commandes générales STARTX(1)

NOM

startx - initialiser une session X

SYNTAXE

startx [ [ client ] options ... ] [ -- [ serveur ] [ affichage ] options ... ]

DESCRIPTION

Le script startx est une interface pour xinit(1) qui fournit une interface utilisateur un peu plus agréable pour exécuter une seule session du système X Window. Il est souvent exécuté sans arguments.

Les arguments suivant immédiatement la commande startx sont utilisés pour démarrer un client de la même manière que xinit(1). L'argument spécial '--' marque la fin des arguments du client et le début des options du serveur. Il peut être pratique de spécifier des options serveur avec startx pour les modifier sur une base par session. Certains exemples de spécification d'arguments serveur suivent ; consultez la page de manuel de votre serveur X pour déterminer quels arguments sont légaux.

startx -- -depth 16

startx -- -dpi 100

startx -- -layout Multihead

Pour déterminer le client à exécuter, startx vérifie d'abord la variable d'environnement XINITRC pour un nom de fichier. Si cette variable est non définie, ou ne contient pas de nom de fichier, il recherche un fichier appelé .xinitrc dans le répertoire personnel de l'utilisateur. Si celui-ci n'est pas trouvé, il utilise le fichier xinitrc dans le répertoire de bibliothèque xinit. Si des options client en ligne de commande sont données, elles remplacent ce comportement et reviennent au comportement de xinit(1). Pour déterminer le serveur à exécuter, startx vérifie la variable d'environnement XSERVERRC pour un nom de fichier. Si cette variable est non définie, ou ne contient pas de nom de fichier, il recherche un fichier appelé .xserverrc dans le répertoire personnel de l'utilisateur. S'il n'est pas trouvé, il utilise le fichier xserverrc dans le répertoire de bibliothèque xinit. Si des options serveur en ligne de commande sont données, elles remplacent ce comportement et reviennent au comportement de xinit(1). Les utilisateurs ont rarement besoin de fournir un fichier .xserverrc. Voir la page de manuel de xinit(1) pour plus de détails sur les arguments.

Les fichiers xinitrc et xserverrc à l'échelle du système se trouvent dans le répertoire /etc/X11/xinit.

Le fichier .xinitrc est généralement un script shell qui démarre plusieurs clients selon les préférences de l'utilisateur. Lorsque ce script shell se termine, startx tue le serveur et effectue toute autre opération de fermeture de session nécessaire. La plupart des clients démarrés par .xinitrc devraient être exécutés en arrière-plan. Le dernier client devrait s'exécuter au premier plan ; lorsqu'il se termine, la session se termine. Les gens choisissent souvent un gestionnaire de session, un gestionnaire de fenêtres ou xterm comme client « magique ».

EXEMPLE

Ci-dessous un exemple de fichier .xinitrc qui démarre plusieurs applications et laisse le gestionnaire de fenêtres en cours d'exécution comme « dernière » application. En supposant que le gestionnaire de fenêtres a été correctement configuré, l'utilisateur choisit ensuite l'option de menu « Quitter » pour arrêter X.


xrdb -load $HOME/.Xresources
xsetroot -solid gray &
xbiff -geometry -430+5 &
oclock -geometry 75x75-0-0 &
xload -geometry -80-0 &
xterm -geometry +0+60 -ls &
xterm -geometry +0-100 &
xconsole -geometry -0+0 -fn 5x7 &
exec twm

VARIABLES D'ENVIRONNEMENT

DISPLAY
Cette variable est définie avec le nom de l'affichage auquel les clients doivent se connecter. Notez qu'elle est définie, pas lue.
XAUTHORITY
Cette variable, si elle n'est pas déjà définie, est définie sur $(HOME)/.Xauthority. Ceci afin d'empêcher le serveur X, s'il ne reçoit pas l'argument -auth, de configurer automatiquement une authentification non sécurisée basée sur l'hôte pour la machine locale. Voir les pages de manuel de Xserver(1) et Xsecurity(7) pour plus d'informations sur l'authentification client/serveur X.
XINITRC
Cette variable doit contenir l'emplacement d'un fichier xinitrc. Si elle n'est pas définie, $(HOME)/.xinitrc ou /etc/X11/xinit/xinitrc sera utilisé.
XSERVERRC
Cette variable doit contenir l'emplacement d'un fichier xserverrc. Si elle n'est pas définie, $(HOME)/.xserverrc ou /etc/X11/xinit/xserverrc sera utilisé.

FICHIERS

$(HOME)/.xinitrc
Client à exécuter. Généralement un script shell qui exécute de nombreux programmes en arrière-plan.
$(HOME)/.xserverrc
Serveur à exécuter. Par défaut, c'est X.
/etc/X11/xinit/xinitrc
Client à exécuter si l'utilisateur n'a pas de fichier .xinitrc.
/etc/X11/xinit/xserverrc
Serveur à exécuter si l'utilisateur n'a pas de fichier .xserverrc.
