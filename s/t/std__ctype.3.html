Description détaillée

template<typename _CharT>

class std::ctype< _CharT >"Facette ctype primaire du modèle de classe.

Ce modèle de classe définit des fonctions de classification et de conversion pour les jeux de caractères. Il encapsule la fonctionnalité de cctype. Ctype est utilisé par les flux pour de nombreuses opérations d'E/S.

Ce modèle fournit les fonctions virtuelles protégées que le développeur devra remplacer dans une classe dérivée ou une spécialisation pour créer une facette fonctionnelle. Les fonctions publiques qui y accèdent sont définies dans __ctype_abstract_base, pour permettre une flexibilité d'implémentation. Voir ctype<wchar_t> pour un exemple. Les fonctions sont documentées dans __ctype_abstract_base.

Note : des implémentations sont fournies pour toutes les fonctions virtuelles protégées, mais elles ne seront probablement pas utiles.

Description

Les fonctions de la bibliothèque standard C++ <cctype> et <cwctype> fournissent des fonctionnalités pour classer et convertir des caractères.

Les fonctions de <cctype> opèrent sur des entiers représentant des caractères ASCII. Les fonctions de <cwctype> opèrent sur des caractères larges (wint_t).

Classification des caractères

Les fonctions de classification renvoient une valeur non nulle si le caractère correspond à la catégorie spécifiée, et zéro sinon. La catégorie est déterminée par la locale courante.

  • islower(c) : vrai si c est une lettre minuscule.
  • isupper(c) : vrai si c est une lettre majuscule.
  • isdigit(c) : vrai si c est un chiffre décimal (0-9).
  • isxdigit(c) : vrai si c est un chiffre hexadécimal (0-9, a-f, A-F).
  • isalnum(c) : vrai si c est une lettre ou un chiffre.
  • isalpha(c) : vrai si c est une lettre alphabétique.
  • isspace(c) : vrai si c est un caractère d'espacement (espace, tabulation, nouvelle ligne, etc.).
  • ispunct(c) : vrai si c est un caractère de ponctuation.
  • isgraph(c) : vrai si c est un caractère imprimable autre qu'un espace.
  • isprint(c) : vrai si c est un caractère imprimable, y compris l'espace.
  • iscntrl(c) : vrai si c est un caractère de contrôle.
  • isblank(c) : vrai si c est un espace ou une tabulation.

Les fonctions isw... correspondent aux fonctions is... mais opèrent sur des caractères larges.

isctype(c, type) et iswctype(c, desc) sont des fonctions plus générales qui vérifient si un caractère appartient à une catégorie spécifiée par type ou desc.

Conversion de caractères

Les fonctions de conversion renvoient la version convertie du caractère si la conversion est possible, sinon elles renvoient le caractère d'origine.

  • toupper(c) : convertit c en majuscule.
  • tolower(c) : convertit c en minuscule.

Les fonctions towupper(c) et towlower(c) correspondent aux fonctions toupper(c) et tolower(c) mais opèrent sur des caractères larges.

Paramètres

  • c : l'entier représentant le caractère à tester ou convertir.
  • type (pour isctype) : un entier représentant le type de caractère à vérifier. Les valeurs possibles sont définies dans <cctype> (par exemple, LC_CTYPE).
  • desc (pour iswctype) : un descripteur de type de caractère large obtenu via wctype().

Valeur de retour

Les fonctions de classification renvoient une valeur non nulle si le caractère satisfait la condition, et zéro sinon.

Les fonctions de conversion renvoient le caractère converti ou le caractère d'origine si la conversion n'est pas possible.

Erreurs

Aucune erreur spécifique n'est documentée pour ces fonctions. Cependant, le comportement peut être indéfini si l'entrée c n'est pas un caractère valide ou EOF.

Exemple

#include <iostream>
#include <cctype>

int main() {
    char ch = 'a';
    if (std::islower(ch)) {
        std::cout << ch << " est une lettre minuscule." << std::endl;
        std::cout << "En majuscule: " << (char)std::toupper(ch) << std::endl;
    }

    ch = '5';
    if (std::isdigit(ch)) {
        std::cout << ch << " est un chiffre." << std::endl;
    }

    return 0;
}
