strtol(3) Manuel des fonctions de bibliothèque strtol(3)

NOM

strtol, strtoll, strtoq - convertir une chaîne en un entier long

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
long strtol(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
long long strtoll(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

strtoll():

    _ISOC99_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

La fonction strtol() convertit la partie initiale de la chaîne dans nptr en une valeur entière longue selon la base donnée, qui doit être comprise entre 2 et 36 inclusivement, ou être la valeur spéciale 0.

La chaîne peut commencer par une quantité arbitraire d'espaces blancs (tels que déterminés par isspace(3)) suivie d'un signe optionnel '+' ou '-'. Si base est zéro ou 16, la chaîne peut alors inclure un préfixe "0x" ou "0X", et le nombre sera lu en base 16 ; si base est zéro ou 2, la chaîne peut alors inclure un préfixe "0b" ou "0B", et le nombre sera lu en base 2 ; sinon, une base zéro est prise comme 10 (décimal) à moins que le caractère suivant ne soit '0', auquel cas elle est prise comme 8 (octal).

Le reste de la chaîne est converti en une valeur long de la manière évidente, s'arrêtant au premier caractère qui n'est pas un chiffre valide dans la base donnée. (Dans les bases supérieures à 10, la lettre 'A' en majuscule ou en minuscule représente 10, 'B' représente 11, et ainsi de suite, 'Z' représentant 35.)

Si endptr n'est pas NULL, et que la base est supportée, strtol() stocke l'adresse du premier caractère invalide dans *endptr. S'il n'y avait aucun chiffre, strtol() stocke la valeur originale de nptr dans *endptr (et retourne 0). En particulier, si *nptr n'est pas '\0' mais que **endptr est '\0' au retour, toute la chaîne est valide.

La fonction strtoll() fonctionne de la même manière que la fonction strtol() mais retourne une valeur entière long long.

VALEUR DE RETOUR

La fonction strtol() retourne le résultat de la conversion, sauf si la valeur provoque un sous-dépassement (underflow) ou un dépassement (overflow). Si un sous-dépassement se produit, strtol() retourne LONG_MIN. Si un dépassement se produit, strtol() retourne LONG_MAX. Dans les deux cas, errno est défini à ERANGE. Exactement la même chose s'applique à strtoll() (avec LLONG_MIN et LLONG_MAX au lieu de LONG_MIN et LONG_MAX).

ERREURS

Cette fonction ne modifie pas errno en cas de succès.

EINVAL
(pas dans C99) La base fournie contient une valeur non supportée.
ERANGE
La valeur résultante était hors limites.

L'implémentation peut également définir errno à EINVAL si aucune conversion n'a été effectuée (aucun chiffre trouvé, et 0 retourné).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strtol (), strtoll (), strtoq () Sécurité des threads MT-Safe locale

VERSIONS

Selon POSIX.1, dans les locales autres que "C" et "POSIX", ces fonctions peuvent accepter d'autres chaînes numériques, définies par l'implémentation.

BSD a également


quad_t strtoq(const char *nptr, char **endptr, int base);

avec une définition complètement analogue. Selon la taille du mot de l'architecture actuelle, cela peut être équivalent à strtoll() ou à strtol().

NORMES

C23, POSIX.1-2024.

HISTORIQUE

ATTENTION

Vérifications des limites

Étant donné que strtol() peut légitimement retourner 0, LONG_MAX ou LONG_MIN (LLONG_MAX ou LLONG_MIN pour strtoll()) en cas de succès comme en cas d'échec, le programme appelant devrait définir errno à 0 avant l'appel, puis déterminer si une erreur s'est produite en vérifiant si errno == ERANGE après l'appel.


errno = 0;
n = strtol(s, &end, base);
if (end == s)
	goto no_number;
if ((errno == ERANGE && n == LONG_MIN) || n < min)
	goto too_low;
if ((errno == ERANGE && n == LONG_MAX) || n > max)
	goto too_high;

base

Si la base doit être testée, elle doit l'être dans un appel où la chaîne est connue pour réussir. Sinon, il est impossible de différencier les erreurs de manière portable.


errno = 0;
strtol("0", NULL, base);
if (errno == EINVAL)
    goto unsupported_base;

BOGUES

Espaces blancs

Ces fonctions acceptent silencieusement les espaces blancs initiaux. Pour rejeter les espaces blancs, appelez isspace(3) avant strtol().

strtoll(3) - Manuel Linux

NAME

strtoll, strtoll_l - convertir une chaîne de caractères en valeur long long

LIBRARY

Bibliothèque C standard (libc), - démarré avec _POSIX_C_SOURCE >= 200809L.

SYNOPSIS

#include <stdlib.h>

long long
strtoll(const char *nptr, char **endptr, int base);

#define _GNU_SOURCE
#include <stdlib.h>

long long
strtoll_l(const char *nptr, char **endptr, int base, locale_t locale);

DESCRIPTION

strtoll() convertit la chaîne pointée par nptr en une valeur long long. La recherche de nombre s'arrête au premier caractère non numérique. Les caractères d'espace blancs initiaux sont ignorés.

Si base est égale à zéro, la base est inférée à partir du format de la chaîne : préfixe « 0x » ou « 0X » pour l'hexadécimal, préfixe « 0 » pour l'octal, et base 10 par défaut. Si base est comprise entre 2 et 36, alors elle est utilisée comme base.

Si endptr n'est pas NULL, alors strtoll() stocke un pointeur vers le premier caractère non converti dans cette variable. Si aucun caractère n'a pu être converti, endptr pointera vers la chaîne nptr. Si un caractère de fin de chaîne est rencontré, endptr pointera vers ce caractère.

La fonction strtoll_l() est identique à strtoll() mais opère selon la locale locale.

RETURN VALUE

En cas de succès, strtoll() renvoie la valeur convertie. Si la valeur à convertir est trop grande ou trop petite pour un long long, strtoll() renvoie ERANGE et définit errno à ERANGE.

Si la conversion ne peut pas être effectuée, strtoll() renvoie 0 et définit errno à EINVAL.

ERRORS

EINVAL

La conversion n'a pas pu être effectuée.

ERANGE

La valeur convertie était trop grande ou trop petite.

ATTRIBUTES

Pour obtenir une explication des termes utilisés dans cette section, voir attributes(7).

               ┌─────────┬───────────────────────────┐
               │ Callee  │        Attribute          │
               ├─────────┼───────────────────────────┤
               │ strtoll │ no-capture, read-only     │
               └─────────┴───────────────────────────┘

VERSIONS

strtoll_l() est disponible depuis la version 2.16 de glibc.

STANDARDS

La fonction strtoll() est conforme à POSIX.1-2008.

La fonction strtoll_l() est conforme à POSIX.1-2008.

HISTORY

La fonction strtoll() est apparue dans la bibliothèque C de BSD. Elle a été standardisée par POSIX.1-2001.

CAVEATS

L'analyse des chaînes dans des bases autres que 10 peut être trompeuse. Par exemple, une chaîne « 010 » est interprétée comme 8 en base 8, mais comme 10 en base 10. La base 0 tente de deviner la base, mais peut être déroutante.

Il est préférable d'utiliser strtol() avec base définie explicitement à 10.

BUGS

Si nptr pointe vers une chaîne vide, et que base est 0, strtoll() renvoie 0 et définit errno à EINVAL. Ceci est conforme à la norme POSIX.

Cependant, il existe des situations où strtoll() renvoie 0 (ce qui peut aussi indiquer une erreur) sans définir errno à EINVAL. Par exemple, si nptr pointe vers « 0 » et que base est 10.

Pour distinguer ces cas, il faut vérifier si endptr pointe vers nptr. Si c'est le cas, et que le caractère pointé par endptr n'est pas '\0', alors une erreur s'est produite.

EXAMPLES

// Exemple d'utilisation de strtoll()
// Convertit la chaîne "12345" en long long.
// endptr pointera vers le caractère nul final.
// La valeur retournée sera 12345.

char *str = "12345";
char *endptr;
long long val = strtoll(str, &endptr, 10);

if (val == 0 && endptr == str) {
    // Aucune conversion n'a pu être effectuée
    fprintf(stderr, "Erreur: Pas de chiffres valides trouvés\n");
    exit(EXIT_FAILURE);
}

// Si nous sommes arrivés ici, strtoll() a réussi à analyser un nombre.
printf("strtoll() a retourné %lld\n", val);

if (*endptr != '\0')        // Pas nécessairement une erreur.
    printf("Caractères supplémentaires après le nombre : \"%s\"\n", endptr);

exit(EXIT_SUCCESS);
