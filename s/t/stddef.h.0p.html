stddef.h(0p) Manuel du programmeur POSIX stddef.h(0p)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

stddef.h — définitions de types standards

SYNTAXE

#include <stddef.h>

DESCRIPTION

La fonctionnalité décrite dans cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 s'en remet à la norme ISO C.

L'en-tête <stddef.h> doit définir les macros suivantes :

NULL
Constante de pointeur nul. La macro doit s'étendre à une expression constante entière de valeur 0 castée en type void *.
offsetof(type, member-designator)

Expression constante entière de type size_t, dont la valeur est le décalage en octets par rapport au membre de structure (member-designator), depuis le début de sa structure (type).

L'en-tête <stddef.h> doit définir les types suivants :

ptrdiff_t
Type entier signé résultant de la soustraction de deux pointeurs.
wchar_t
Type entier dont la plage de valeurs peut représenter des codes distincts pour tous les membres du plus grand jeu de caractères étendus spécifié parmi les locales prises en charge ; le caractère nul doit avoir la valeur de code zéro. Chaque membre du jeu de caractères de base doit avoir une valeur de code égale à sa valeur lorsqu'il est utilisé comme seul caractère dans une constante de caractère entière si une implémentation ne définit pas __STDC_MB_MIGHT_NEQ_WC__.
size_t
Type entier non signé résultant de l'opérateur sizeof.

L'implémentation doit prendre en charge un ou plusieurs environnements de programmation dans lesquels les largeurs de ptrdiff_t, size_t et wchar_t ne dépassent pas la largeur du type long. Les noms de ces environnements de programmation peuvent être obtenus à l'aide de la fonction confstr() ou de l'utilitaire getconf.

Les sections suivantes sont informatives.

USAGE APPLICATIF

Aucun.

RATIONALE

La norme ISO C n'exige pas que la macro NULL inclue le cast en type void * et spécifie que la macro NULL est définie par l'implémentation. POSIX.1-2008 exige le cast et n'a donc pas besoin d'être définie par l'implémentation.
