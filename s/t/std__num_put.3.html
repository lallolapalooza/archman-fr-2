Description détaillée

template<typename _CharT, typename _OutIter>

class std::num_put< _CharT, _OutIter >"Gabarit de classe primaire num_put.

Cette facette encapsule le code permettant de convertir un nombre en chaîne de caractères. Elle est utilisée par les opérateurs d'insertion numériques de ostream.

Le gabarit num_put utilise des fonctions virtuelles protégées pour fournir les résultats réels. Les accesseurs publics transmettent l'appel aux fonctions virtuelles. Ces fonctions virtuelles sont des points d'ancrage permettant aux développeurs d'implémenter le comportement requis de la facette num_put.

template<typename _CharT, typename _OutIter> iter_type std::num_put< _CharT, _OutIter >::put (iter_type __s, ios_base & __io, char_type __fill, double __v) const [inline]

Formatage numérique. Formate la valeur à virgule flottante v et l'insère dans un flux. Ceci est fait en appelant num_put::do_put().

Le formatage est affecté par les paramètres des indicateurs dans io.

Le format de base est affecté par la valeur de io.flags() & ios_base::floatfield. S'il est égal à ios_base::fixed, le formatage est similaire au spécificateur f de printf. Sinon, s'il est égal à ios_base::scientific, le formatage est similaire à e ou E avec ios_base::uppercase non défini ou défini respectivement. Sinon, le formatage est similaire à g ou G selon que uppercase est défini ou non. Notez que si fixed et scientific sont tous deux définis, l'effet sera également similaire à g ou G.

La précision de la sortie est donnée par io.precision(). Cette précision est plafonnée à numeric_limits::digits10 + 2 (différent pour double et long double). La précision par défaut est 6.

Si ios_base::showpos est défini, un '+' est affiché avant les valeurs positives. Si ios_base::showpoint est défini, un point décimal sera toujours affiché.

Le caractère du point décimal utilisé est numpunct::decimal_point(). Les séparateurs de milliers sont insérés conformément à numpunct::grouping() et numpunct::thousands_sep().

Si io.width() est différent de zéro, suffisamment de caractères de remplissage sont insérés pour que le résultat ait au moins cette largeur. Si (io.flags() & ios_base::adjustfield) == ios_base::left, le résultat est rempli à la fin. Si ios_base::internal, alors le remplissage se produit immédiatement après un '+' ou '-' ou après '0x' ou '0X'. Sinon, le remplissage se produit au début.

template<typename _CharT, typename _OutIter> iter_type std::num_put< _CharT, _OutIter >::put

Formatting numeric values. Formats the given numeric value and inserts it into the stream represented by the output iterator __s.

The formatting behavior is controlled by the locale facet std::numpunct and the format flags set in the std::ios_base object __io.

This function is a wrapper that calls the virtual function do_put() with the appropriate arguments derived from the input parameters.

Formatting integral types

For integral types (e.g., int, long, long long, unsigned long, unsigned long long), the formatting is influenced by io.flags():

  • ios_base::basefield:

    • ios_base::oct: Formats the number in octal (base 8), similar to the o specifier in printf.

    • ios_base::hex: Formats the number in hexadecimal (base 16). If ios_base::uppercase is set, uses X; otherwise, uses x. This is similar to the x or X specifiers in printf.

    • Otherwise (default): Formats the number in decimal (base 10). For signed types, it's similar to d, ld, or lld. For unsigned types, it's similar to u, lu, or llu.

    Note: If both ios_base::oct and ios_base::hex are set, neither takes effect, and decimal formatting is used.

  • ios_base::showpos: If set, a + sign is prepended to positive numbers.

  • ios_base::showbase: If set:

    • For octal numbers (and not zero), 0 is prepended.

    • For hexadecimal numbers, 0x (or 0X if ios_base::uppercase is set) is prepended.

The decimal point character is determined by std::numpunct::decimal_point(). Thousands separators are inserted according to std::numpunct::grouping() and std::numpunct::thousands_sep().

Formatting floating-point types

For floating-point types (e.g., double, long double), the formatting is influenced by io.flags():

  • ios_base::floatfield:

    • ios_base::fixed: Formats the number in fixed-point notation, similar to the f specifier in printf.

    • ios_base::scientific: Formats the number in scientific notation. If ios_base::uppercase is set, uses E; otherwise, uses e. This is similar to the e or E specifiers in printf.

    • Otherwise: Formats the number using either fixed-point or scientific notation, chosen to represent the value more compactly. This is similar to the g or G specifiers in printf.

    Note: If both ios_base::fixed and ios_base::scientific are set, the effect is the same as the default (like g or G).

  • io.precision(): Determines the number of digits after the decimal point for ios_base::fixed and ios_base::scientific, or the total number of significant digits for the default format. The default precision is 6. This value is capped at numeric_limits::digits10 + 2.

  • ios_base::showpos: If set, a + sign is prepended to positive numbers.

  • ios_base::showpoint: If set, a decimal point character is always included in the output, even if there are no fractional digits.

The decimal point character is determined by std::numpunct::decimal_point(). Thousands separators are inserted according to std::numpunct::grouping() and std::numpunct::thousands_sep().

Field width and fill character

The output is padded with the fill character __fill if the formatted number is narrower than the specified field width given by io.width().

  • ios_base::adjustfield:

    • ios_base::left: The output is left-justified; padding is added to the right.

    • ios_base::internal: For integral types, padding occurs after the sign (if any) or the base indicator (like 0x). For floating-point types, padding occurs after the sign.

    • Default (usually ios_base::right): The output is right-justified; padding is added to the left.

If io.width() is 0, no padding is performed.

std::num_put - Insère des nombres dans un flux

#include <locale>

Description Détaillée

La classe std::num_put est une facette de std::locale qui fournit des services pour l'insertion de nombres dans des flux.

Elle gère la mise en forme des nombres entiers et à virgule flottante selon les conventions locales, notamment pour le séparateur de milliers et le séparateur décimal.
