Extracteurs
Toutes les fonctions operator>> (également appelées fonctions d'entrée formatée) ont un comportement commun. Chacune commence par construire un objet temporaire de type std::basic_istream::sentry avec le second argument (noskipws) défini à false. Cela a plusieurs effets, se terminant par la définition d'un indicateur de statut; voir la documentation de sentry pour plus de détails.

Si le statut de sentry est bon, la fonction essaie d'extraire les données appropriées au type de l'argument.

Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer la levée d'une exception ios_base::failure) et l'exception originale sera relancée si badbit est défini dans le masque d'exceptions.

Paramètres du modèle

_CharT Type du flux de caractères.

Cette classe hérite de manière multiple des classes de flux d'entrée et de sortie pour simplement fournir une interface unique.

typedef _Ios_Iostate std::ios_base::iostate [hérité]

C'est un type de masque de bits. _Ios_Iostate est défini par l'implémentation, mais il est valide d'effectuer des opérations bit à bit sur ces valeurs et d'attendre que la bonne chose se produise. Les objets définis de type iostate sont :

  • badbit
  • eofbit
  • failbit
  • goodbit

typedef _Ios_Openmode std::ios_base::openmode [hérité]

C'est un type de masque de bits. _Ios_Openmode est défini par l'implémentation, mais il est valide d'effectuer des opérations bit à bit sur ces valeurs et d'attendre que la bonne chose se produise. Les objets définis de type openmode sont :

  • app
  • ate
  • binary
  • in
  • out
  • trunc

typedef _Ios_Seekdir std::ios_base::seekdir [hérité]

C'est un type énuméré. _Ios_Seekdir est défini par l'implémentation. Les valeurs définies de type seekdir sont :

  • beg
  • cur, équivalent à SEEK_CUR dans la bibliothèque standard C.
  • end, équivalent à SEEK_END dans la bibliothèque standard C.

    int std::ios_base::xalloc () [statique], [hérité]

    Accès aux indices uniques.

    Retourne

    Un entier différent de tous les appels précédents.

    Cette fonction retourne un entier unique à chaque appel. Il peut être utilisé à n'importe quelle fin, mais est principalement destiné à être un indice unique pour les fonctions iword et pword. L'attente est qu'une application appelle xalloc afin d'obtenir un indice dans les tableaux iword et pword qui peut être utilisé sans crainte de conflit.

    L'implémentation maintient une variable statique qui est incrémentée et retournée à chaque invocation. xalloc est garanti de retourner un indice sûr à utiliser dans les tableaux iword et pword.
