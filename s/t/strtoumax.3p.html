Ce manuel est une partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

strtoumax — convertir une chaîne en un type entier

SYNOPSIS

#include <inttypes.h>
