CSTEIN

Objectif :

!>
!> CSTEIN calcule les vecteurs propres d'une matrice tridiagonale symétrique
!> réelle T correspondant à des valeurs propres spécifiées, en utilisant
!> l'itération inverse.
!>
!> Le nombre maximal d'itérations autorisées pour chaque vecteur propre est
!> spécifié par un paramètre interne MAXITS (actuellement réglé à 5).
!>
!> Bien que les vecteurs propres soient réels, ils sont stockés dans un
!> tableau complexe, qui peut être passé à CUNMTR ou CUPMTR pour une
!> rétro-transformation vers les vecteurs propres d'une matrice hermitienne
!> complexe qui a été réduite à une forme tridiagonale.
!>
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice. N >= 0.
!>

D

!>          D est un tableau RÉEL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau RÉEL, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale
!>          T, stockés dans les éléments 1 à N-1.
!>

M

!>          M est un ENTIER
!>          Le nombre de vecteurs propres à trouver. 0 <= M <= N.
!>

W

!>          W est un tableau RÉEL, dimension (N)
!>          Les M premiers éléments de W contiennent les valeurs propres
!>          pour lesquelles les vecteurs propres doivent être calculés. Les
!>          valeurs propres doivent être groupées par bloc séparé et ordonnées
!>          de la plus petite à la plus grande au sein du bloc. (Le tableau
!>          de sortie W de SSTEBZ avec ORDER = 'B' est attendu ici.)
!>

IBLOCK

!>          IBLOCK est un tableau ENTIER, dimension (N)
!>          Les indices des sous-matrices associés aux valeurs propres
!>          correspondantes dans W ; IBLOCK(i)=1 si la valeur propre W(i)
!>          appartient à la première sous-matrice par le haut, =2 si W(i)
!>          appartient à la deuxième sous-matrice, etc. (Le tableau de
!>          sortie IBLOCK de SSTEBZ est attendu ici.)
!>

ISPLIT

!>          ISPLIT est un tableau ENTIER, dimension (N)
!>          Les points de séparation, où T se décompose en sous-matrices.
!>          La première sous-matrice comprend les lignes/colonnes 1 à
!>          ISPLIT( 1 ), la seconde des lignes/colonnes ISPLIT( 1 )+1
!>          jusqu'à ISPLIT( 2 ), etc.
!>          (Le tableau de sortie ISPLIT de SSTEBZ est attendu ici.)
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ, M)
!>          Les vecteurs propres calculés. Le vecteur propre associé à
!>          la valeur propre W(i) est stocké dans la i-ème colonne de
!>          Z. Tout vecteur qui n'arrive pas à converger est mis à son
!>          itéré actuel après MAXITS itérations.
!>          Les parties imaginaires des vecteurs propres sont mises à zéro.
!>

LDZ

!>          LDZ est un ENTIER
!>          La dimension principale du tableau Z. LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau RÉEL, dimension (5*N)
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (N)
!>

IFAIL

!>          IFAIL est un tableau ENTIER, dimension (M)
!>          Lors d'une sortie normale, tous les éléments de IFAIL sont zéro.
!>          Si un ou plusieurs vecteurs propres ne convergent pas après
!>          MAXITS itérations, leurs indices sont stockés dans le
!>          tableau IFAIL.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, alors i vecteurs propres n'ont pas convergé
!>               en MAXITS itérations. Leurs indices sont stockés dans
!>               le tableau IFAIL.
!>

Paramètres internes :

!>  MAXITS  ENTIER, défaut = 5
!>          Le nombre maximal d'itérations effectuées.
!>
!>  EXTRA   ENTIER, défaut = 2
!>          Le nombre d'itérations effectuées après que le critère de
!>          croissance de la norme soit satisfait, doit être au moins 1.
!>

DSTEIN


Purpose:




!>
!> DSTEIN computes the eigenvectors of a real symmetric tridiagonal
!> matrix T corresponding to specified eigenvalues, using inverse
!> iteration.
!>
!> The maximum number of iterations allowed for each eigenvector is
!> specified by an internal parameter MAXITS (currently set to 5).
!> 




Parameters


N

!>          N is INTEGER
!>          The order of the matrix.  N >= 0.
!> 


D


!>          D is DOUBLE PRECISION array, dimension (N)
!>          The n diagonal elements of the tridiagonal matrix T.
!> 


E


!>          E is DOUBLE PRECISION array, dimension (N-1)
!>          The (n-1) subdiagonal elements of the tridiagonal matrix
!>          T, stored in elements 1 to N-1.
!> 


M


!>          M is INTEGER
!>          The number of eigenvectors to be found.  0 <= M <= N.
!> 


W


!>          W is DOUBLE PRECISION array, dimension (N)
!>          The first M elements of W contain the eigenvalues for
!>          which eigenvectors are to be computed.  The eigenvalues
!>          should be grouped by split-off block and ordered from
!>          smallest to largest within the block.  ( The output array
!>          W from DSTEBZ with ORDER = 'B' is expected here. )
!> 


IBLOCK


!>          IBLOCK is INTEGER array, dimension (N)
!>          The submatrix indices associated with the corresponding
!>          eigenvalues in W; IBLOCK(i)=1 if eigenvalue W(i) belongs to
!>          the first submatrix from the top, =2 if W(i) belongs to
!>          the second submatrix, etc.  ( The output array IBLOCK
!>          from DSTEBZ is expected here. )
!> 


ISPLIT


!>          ISPLIT is INTEGER array, dimension (N)
!>          The splitting points, at which T breaks up into submatrices.
!>          The first submatrix consists of rows/columns 1 to
!>          ISPLIT( 1 ), the second of rows/columns ISPLIT( 1 )+1
!>          through ISPLIT( 2 ), etc.
!>          ( The output array ISPLIT from DSTEBZ is expected here. )
!> 


Z


!>          Z is DOUBLE PRECISION array, dimension (LDZ, M)
!>          The computed eigenvectors.  The eigenvector associated
!>          with the eigenvalue W(i) is stored in the i-th column of
!>          Z.  Any vector which fails to converge is set to its current
!>          iterate after MAXITS iterations.
!> 


LDZ


!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= max(1,N).
!> 


WORK


!>          WORK is DOUBLE PRECISION array, dimension (5*N)
!> 


IWORK


!>          IWORK is INTEGER array, dimension (N)
!> 


IFAIL


!>          IFAIL is INTEGER array, dimension (M)
!>          On normal exit, all elements of IFAIL are zero.
!>          If one or more eigenvectors fail to converge after
!>          MAXITS iterations, then their indices are stored in
!>          array IFAIL.
!> 


INFO


!>          INFO is INTEGER
!>          = 0: successful exit.
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0: if INFO = i, then i eigenvectors failed to converge
!>               in MAXITS iterations.  Their indices are stored in
!>               array IFAIL.
!> 




Internal Parameters:




!>  MAXITS  INTEGER, default = 5
!>          The maximum number of iterations performed.
!>
!>  EXTRA   INTEGER, default = 2
!>          The number of iterations performed after norm growth
!>          criterion is satisfied, should be at least 1.
!>

NAME


stein


– computes the eigenvectors of a symmetric tridiagonal matrix.







SYNOPSIS


  SUBROUTINE ZSTEIN( N, D, E, NK, K, RCONV, Z, LDZ, WORK, IWORK,
 &                   ICIWORK, INFO )
      INTEGER        ICIWORK(*)
      INTEGER        IWORK(*)
      INTEGER        INFO
      INTEGER        K(*)
      INTEGER        NK
      INTEGER        N
      REAL           RCONV(*)
      COMPLEX*16     D(*)
      COMPLEX*16     E(*)
      COMPLEX*16     Z( LDZ, * )
      INTEGER        LDZ
      DOUBLE PRECISION WORK(*)








Detailed Description


  This routine computes the eigenvectors of a symmetric tridiagonal
  matrix T using the divide and conquer method.

  The input matrix T must be in the form:
  T =          D
             E   E
                D
               E   E
                  D
  where D is a vector of length N and E is a vector of length N-1.

  The routine uses the output from DSTEBZ.

  Arguments:
  N: INTEGER. The order of the tridiagonal matrix T. N >= 0.

  D: COMPLEX*16 array, dimension (N).
     On entry, the diagonal elements of T.
     On exit, D is unspecified.

  E: COMPLEX*16 array, dimension (N-1).
     On entry, the off-diagonal elements of T.
     On exit, E is unspecified.

  NK: INTEGER. The number of desired eigenvectors. NK >= 0.

  K: INTEGER array, dimension (NK).
     On entry, the indices of the desired eigenvectors.
     The eigenvalues are sorted in ascending order.
     1 <= K(i) <= N for all i.

  RCONV: REAL array, dimension (NK).
     On exit, RCONV(i) is the relative error in the computed
     eigenvector Z(i). If RCONV(i) is greater than 1.0, then the
     eigenvector may not be of high accuracy.

  Z: COMPLEX*16 array, dimension (LDZ, NK).
     On exit, the computed eigenvectors. The eigenvector associated
     with the i-th desired eigenvalue (in sorted order) is stored
     in the i-th column of Z. Any vector which fails to converge
     is set to its current iterate after MAXITS iterations.

  LDZ: INTEGER. The leading dimension of the array Z. LDZ >= max(1,N).

  WORK: DOUBLE PRECISION array, dimension (5*N).
     Workspace.

  IWORK: INTEGER array, dimension (N).
     Workspace.

  ICIWORK: INTEGER array, dimension (N).
     Workspace.

  INFO: INTEGER.
     = 0: successful exit
     < 0: if INFO = -i, the i-th argument had an illegal value
     > 0: if INFO = i, then i eigenvectors failed to converge.
          The indices of the eigenvectors that failed to converge
          are stored in array IFAIL. (Note: This implementation
          does not return IFAIL explicitly, but INFO indicates
          the number of failures.)



Internal Parameters:




  MAXITS  INTEGER, default = 5
          The maximum number of iterations performed.

  EXTRA   INTEGER, default = 2
          The number of iterations performed after norm growth
          criterion is satisfied, should be at least 1.
