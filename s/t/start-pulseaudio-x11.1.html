NOM

start-pulseaudio-x11 - Script de démarrage du serveur sonore PulseAudio pour X11

SYNTAXE

start-pulseaudio-x11 [options pulseaudio]

DESCRIPTION

Ce script démarre pulseaudio (s'il n'est pas déjà en cours d'exécution) et charge les modules pour publier les identifiants d'accès au serveur PulseAudio dans la fenêtre racine X11 et pour synthétiser les événements de touches multimédias X11 lors des requêtes de mise en veille/réveil (cork/uncork). De plus, il enregistre PulseAudio auprès du gestionnaire de session X11.

Tous les arguments sont directement transmis à pulseaudio.

AUTEURS

Les développeurs de PulseAudio <pulseaudio-discuss (at) lists (dot) freedesktop (dot) org> ; PulseAudio est disponible sur http://pulseaudio.org/
