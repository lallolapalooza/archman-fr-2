STEST(1) Manuel des commandes générales STEST(1)

NOM

stest - filtre une liste de fichiers par propriétés

SYNTAXE

stest [-abcdefghlpqrsuwx] [-n fichier] [-o fichier] [fichier...]

DESCRIPTION

stest prend une liste de fichiers et les filtre en fonction de leurs propriétés, de manière analogue à test(1). Les fichiers qui satisfont tous les tests sont affichés sur la sortie standard. Si aucun fichier n'est donné, stest lit les fichiers depuis l'entrée standard.

OPTIONS

-a
Teste les fichiers cachés.
-b
Teste que les fichiers sont des périphériques de bloc.
-c
Teste que les fichiers sont des périphériques de caractères.
-d
Teste que les fichiers sont des répertoires.
-e
Teste que les fichiers existent.
-f
Teste que les fichiers sont des fichiers réguliers.
-g
Teste que les fichiers ont leur bit set-group-ID activé.
-h
Teste que les fichiers sont des liens symboliques.
-l
Teste le contenu d'un répertoire donné en argument.
-n fichier
Teste que les fichiers sont plus récents que fichier.
-o fichier
Teste que les fichiers sont plus anciens que fichier.
-p
Teste que les fichiers sont des tubes nommés.
-q
Aucun fichier n'est affiché, seul le code de sortie est retourné.
-r
Teste que les fichiers sont lisibles.
-s
Teste que les fichiers ne sont pas vides.
-u
Teste que les fichiers ont leur bit set-user-ID activé.
-v
Inverse le sens des tests, seuls les fichiers échouant passent.
-w
Teste que les fichiers sont inscriptibles.
-x
Teste que les fichiers sont exécutables.

CODE DE SORTIE

0
Au moins un fichier a satisfait tous les tests.
1
Aucun fichier n'a satisfait tous les tests.
2
Une erreur s'est produite.
