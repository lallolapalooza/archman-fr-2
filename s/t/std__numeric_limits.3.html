Description détaillée

template<typename _Tp>

struct std::numeric_limits< _Tp >"Propriétés des types fondamentaux.

Cette classe permet à un programme d'obtenir des informations sur la représentation d'un type fondamental sur une plateforme donnée. Pour les types non fondamentaux, les fonctions retourneront 0 et les membres de données seront tous à false.

Documentation des fonctions membres

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::denorm_min () [inline], [static], [constexpr], [noexcept]

La plus petite valeur dénormalisée positive. Pour les types où has_denorm est false, il s'agit de la plus petite valeur normalisée positive.

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::epsilon () [inline], [static], [constexpr], [noexcept]

L'epsilon machine : la différence entre 1 et la plus petite valeur supérieure à 1 qui est représentable.

Fait référence à std::generate_canonical(), std::binomial_distribution< _IntType >::operator()(), std::poisson_distribution< _IntType >::operator()(), et std::operator<<().

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::infinity () [inline], [static], [constexpr], [noexcept]

La représentation de l'infini positif, si has_infinity.

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::lowest () [inline], [static], [constexpr], [noexcept]

Une valeur finie x telle qu'il n'existe aucune autre valeur finie y où y < x.

Fait référence à std::cauchy_distribution< _RealType >::min(), std::extreme_value_distribution< _RealType >::min(), std::normal_distribution< _RealType >::min(), et std::student_t_distribution< _RealType >::min().

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::max () [inline], [static], [constexpr], [noexcept]

La valeur finie maximale.

Fait référence à __gnu_parallel::__parallel_random_shuffle_drs(), std::bernoulli_distribution::max(), std::cauchy_distribution< _RealType >::max(), std::chi_squared_distribution< _RealType >::max(), std::exponential_distribution< _RealType >::max(), std::extreme_value_distribution< _RealType >::max(), std::fisher_f_distribution< _RealType >::max(), std::gamma_distribution< _RealType >::max(), std::geometric_distribution< _IntType >::max(), std::lognormal_distribution< _RealType >::max(), std::negative_binomial_distribution< _IntType >::max(), std::normal_distribution< _RealType >::max(), std::poisson_distribution< _IntType >::max(), std::student_t_distribution< _RealType >::max(), std::weibull_distribution< _RealType >::max(), std::tr2::dynamic_bitset< _WordT, _Alloc >::max_size(), std::binomial_distribution< _IntType >::operator()(), std::independent_bits_engine< _RandomNumberEngine, __w, _UIntType >::operator()(), std::poisson_distribution< _IntType >::operator()(), et std::operator<<().

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::min () [inline], [static], [constexpr], [noexcept]

La valeur finie minimale, ou pour les types flottants avec dénormalisation, la valeur normalisée positive minimale.

Fait référence à std::bernoulli_distribution::min().

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::quiet_NaN () [inline], [static], [constexpr], [noexcept]

La représentation d'un Not a Number (NaN) silencieux, si has_quiet_NaN.

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::round_error () [inline], [static], [constexpr], [noexcept]

La mesure maximale de l'erreur d'arrondi (voir LIA-1).

template<typename _Tp> constexpr _Tp std::numeric_limits< _Tp >::signaling_NaN () [inline], [static], [constexpr], [noexcept]

La représentation d'un Not a Number (NaN) de signalement, si has_signaling_NaN.

Documentation des données membres

int std::__numeric_limits_base::digits [static], [constexpr], [inherited]

Le nombre de chiffres de radix qui peuvent être représentés sans changement : pour les types entiers, le nombre de bits non signe dans la mantisse ; pour les types flottants, le nombre de chiffres de radix dans la mantisse.

Fait référence à std::generate_canonical(), std::independent_bits_engine< _RandomNumberEngine, __w, _UIntType >::operator()(), std::operator<<(), et std::linear_congruential_engine< uint_fast32_t, 16807UL, 0UL, 2147483647UL >::seed().

int std::__numeric_limits_base::digits10 [static], [constexpr], [inherited]

Le nombre de chiffres en base 10 qui peuvent être représentés sans changement.
