subroutine stgsna (character job, character howmny, logical, dimension( * ) select, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) s, real, dimension( * ) dif, integer mm, integer m, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

But :

!>
!> STGSNA estime les nombres de condition réciproques pour des valeurs
!> propres et/ou vecteurs propres spécifiés d'une paire de matrices (A, B)
!> sous forme canonique généralisée de Schur réelle (ou de toute paire
!> de matrices (Q*A*Z**T, Q*B*Z**T) avec des matrices orthogonales Q et Z,
!> où Z**T dénote la transposée de Z.
!>
!> (A, B) doit être sous forme de Schur généralisée réelle (comme retournée par SGGES),
!> c'est-à-dire que A est quasi-triangulaire par blocs avec des blocs diagonaux
!> de taille 1x1 et 2x2. B est triangulaire supérieure.
!>
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (DIF):
!>          = 'E': pour les valeurs propres uniquement (S);
!>          = 'V': pour les vecteurs propres uniquement (DIF);
!>          = 'B': pour les valeurs propres et les vecteurs propres (S et DIF).
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A': calculer les nombres de condition pour toutes les paires propres;
!>          = 'S': calculer les nombres de condition pour les paires propres sélectionnées
!>                 spécifiées par le tableau SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour lesquelles
!>          les nombres de condition sont requis. Pour sélectionner les nombres de condition
!>          correspondant à une valeur propre réelle w(j),
!>          SELECT(j) doit être mis à .TRUE.. Pour sélectionner les nombres de condition
!>          correspondant à une paire de valeurs propres conjuguées complexes w(j)
!>          et w(j+1), soit SELECT(j) soit SELECT(j+1), ou les deux, doivent être
!>          mis à .TRUE..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est un entier (INTEGER)
!>          L'ordre de la paire de matrices carrées (A, B). N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          La matrice quasi-triangulaire supérieure A dans la paire (A,B).
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau REEL, de dimension (LDB,N)
!>          La matrice triangulaire supérieure B dans la paire (A,B).
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

VL

!>          VL est un tableau REEL, de dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres gauches
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des colonnes
!>          consécutives de VL, comme retourné par STGEVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un entier (INTEGER)
!>          La dimension principale du tableau VL. LDVL >= 1.
!>          Si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau REEL, de dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres droits
!>          de (A, B), correspondant aux paires propres spécifiées par HOWMNY
!>          et SELECT. Les vecteurs propres doivent être stockés dans des colonnes
!>          consécutives de VR, comme retourné par STGEVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un entier (INTEGER)
!>          La dimension principale du tableau VR. LDVR >= 1.
!>          Si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau REEL, de dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments consécutifs
!>          du tableau. Pour une paire de valeurs propres conjuguées complexes,
!>          deux éléments consécutifs de S sont mis à la même valeur. Ainsi,
!>          S(j), DIF(j), et les colonnes j de VL et VR correspondent tous
!>          à la même paire propre (mais pas en général à la j-ème paire propre,
!>          à moins que toutes les paires propres ne soient sélectionnées).
!>          Si JOB = 'V', S n'est pas référencé.
!>

DIF

!>          DIF est un tableau REEL, de dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés des
!>          vecteurs propres sélectionnés, stockés dans des éléments consécutifs
!>          du tableau. Pour un vecteur propre complexe, deux
!>          éléments consécutifs de DIF sont mis à la même valeur. Si
!>          les valeurs propres ne peuvent pas être réorganisées pour calculer DIF(j), DIF(j)
!>          est mis à 0 ; cela ne peut se produire que lorsque la valeur réelle serait
!>          déjà très petite.
!>          Si JOB = 'E', DIF n'est pas référencé.
!>

MM

!>          MM est un entier (INTEGER)
!>          Le nombre d'éléments dans les tableaux S et DIF. MM >= M.
!>

M

!>          M est un entier (INTEGER)
!>          Le nombre d'éléments des tableaux S et DIF utilisés pour stocker
!>          les nombres de condition spécifiés ; pour chaque valeur propre réelle sélectionnée,
!>          un élément est utilisé, et pour chaque paire de valeurs propres complexes conjuguées
!>          sélectionnées, deux éléments sont utilisés.
!>          Si HOWMNY = 'A', M est mis à N.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' ou 'B', LWORK >= 2*N*(N+2)+16.
!>
!>          Si LWORK = -1, alors une requête de dimension de mémoire est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau d'entiers (INTEGER), de dimension (N + 6)
!>          Si JOB = 'E', IWORK n'est pas référencé.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          =0: Exécution réussie
!>          <0: Si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La réciproque du nombre de condition d'une valeur propre généralisée
!>  w = (a, b) est définie comme
!>
!>       S(w) = (|u**TAv|**2 + |u**TBv|**2)**(1/2) / (norm(u)*norm(v))
!>
!>  où u et v sont les vecteurs propres gauche et droit de (A, B)
!>  correspondant à w ; |z| dénote la valeur absolue du nombre complexe,
!>  et norm(u) dénote la norme 2 du vecteur u.
!>  La paire (a, b) correspond à une valeur propre w = a/b (= u**TAv/u**TBv)
!>  de la paire de matrices (A, B). Si a et b sont tous deux égaux à zéro, alors (A B) est
!>  singulière et S(I) = -1 est retourné.
!&g

STGSNA(3)

NAME

STGSNA

estimate the norm of the reciprocal condition number for the generalized eigenvalue problem

An approximate error bound on the chordal distance between the i-th computed generalized eigenvalue w and the corresponding exact eigenvalue lambda is

chord(w, lambda) <= EPS * norm(A, B) / S(I)

where EPS is the machine precision.

The reciprocal of the condition number DIF(i) of right eigenvector u and left eigenvector v corresponding to the generalized eigenvalue w is defined as follows:

a) If the i-th eigenvalue w = (a,b) is real

Suppose U and V are orthogonal transformations such that

U**T*(A, B)*V = (S, T) = ( a * ) ( b * ) 1

( 0 S22 ),( 0 T22 ) n-1

1 n-1 1 n-1

Then the reciprocal condition number DIF(i) is

Difl((a, b), (S22, T22)) = sigma-min( Zl ),

where sigma-min(Zl) denotes the smallest singular value of the 2(n-1)-by-2(n-1) matrix

Zl = [ kron(a, In-1) -kron(1, S22) ]

[ kron(b, In-1) -kron(1, T22) ] .

Here In-1 is the identity matrix of size n-1. kron(X, Y) is the Kronecker product between the matrices X and Y.

Note that if the default method for computing DIF(i) is wanted (see SLATDF), then the parameter DIFDRI (see below) should be changed from 3 to 4 (routine SLATDF(IJOB = 2 will be used)). See STGSYL for more details.

b) If the i-th and (i+1)-th eigenvalues are complex conjugate pair,

Suppose U and V are orthogonal transformations such that

U**T*(A, B)*V = (S, T) = ( S11 * ) ( T11 * ) 2

( 0 S22 ),( 0 T22) n-2

2 n-2 2 n-2

and (S11, T11) corresponds to the complex conjugate eigenvalue pair (w, conjg(w)). There exist unitary matrices U1 and V1 such that

U1**T*S11*V1 = ( s11 s12 ) and U1**T*T11*V1 = ( t11 t12 )

( 0 s22 ) ( 0 t22 )

where the generalized eigenvalues w = s11/t11 and conjg(w) = s22/t22.

Then the reciprocal condition number DIF(i) is bounded by

min( d1, max( 1, |real(s11)/real(s22)| )*d2 )

where, d1 = Difl((s11, t11), (s22, t22)) = sigma-min(Z1), where Z1 is the complex 2-by-2 matrix

Z1 = [ s11 -s22 ]

[ t11 -t22 ],

This is done by computing (using real arithmetic) the roots of the characteristical polynomial det(Z1**T * Z1 - lambda I), where Z1**T denotes the transpose of Z1 and det(X) denotes the determinant of X.

and d2 is an upper bound on Difl((S11, T11), (S22, T22)), i.e. an upper bound on sigma-min(Z2), where Z2 is (2n-2)-by-(2n-2)

Z2 = [ kron(S11**T, In-2) -kron(I2, S22) ]

[ kron(T11**T, In-2) -kron(I2, T22) ]

Note that if the default method for computing DIF is wanted (see SLATDF), then the parameter DIFDRI (see below) should be changed from 3 to 4 (routine SLATDF(IJOB = 2 will be used)). See STGSYL for more details.

For each eigenvalue/vector specified by SELECT, DIF stores a Frobenius norm-based estimate of Difl.

An approximate error bound for the i-th computed eigenvector VL(i) or VR(i) is given by

EPS * norm(A, B) / DIF(i).

See ref. [2-3] for more details and further references.

Une borne d'erreur approximative sur la distance chordale entre la i-ème valeur propre généralisée calculée w et la valeur propre exacte correspondante lambda est

chord(w, lambda) <= EPS * norm(A, B) / S(I)

a) Si la i-ème valeur propre w = (a,b) est réelle

U**T*(A, B)*V = (S, T) = ( a * ) ( b * ) 1

( 0 S22 ),( 0 T22 ) n-1

Difl((a, b), (S22, T22)) = sigma-min( Zl ),

Zl = [ kron(a, In-1) -kron(1, S22) ]
