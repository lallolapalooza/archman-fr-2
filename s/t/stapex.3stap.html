NOM

stapex - exemples de systemtap

BASES DU LANGAGE

Ces exemples donnent une idée de la syntaxe et des structures de contrôle de base de systemtap.

global odds, evens
probe begin {
  # "no" et "ne" sont des entiers locaux
  for (i=0; i<10; i++) {
    if (i % 2) odds [no++] = i
    else evens [ne++] = i 
  }
  delete odds[2]
  delete evens[3]
  exit ()
}
probe end {
  foreach (x+ in odds) {
    printf ("odds[%d] = %d\n", x, odds[x])
  }
  foreach (x in evens-) {
    printf ("evens[%d] = %d\n", x, evens[x])
  }
}

Ceci affiche :

odds[1] = 1
odds[3] = 5
odds[4] = 7
odds[5] = 9
evens[5] = 8
evens[4] = 6
evens[2] = 2
evens[1] = 0

Notez que tous les types de variables sont inférés et que toutes les variables locales et globales sont initialisées automatiquement.

Ce script affiche les nombres premiers entre 0 et 49.

function isprime (x) {
  if (x < 2) return 0
  for (i=2; i<x; i++) {
    if (x % i == 0) return 0
    if (i * i > x) break
  }
  return 1
}
probe begin {
  for (i=0; i<50; i++)
    if (isprime (i)) printf("%d\n", i)
  exit()
}

Ce script démontre les fonctions récursives.

function fibonacci(i) {
  if (i < 1) error ("mauvais nombre")
  if (i == 1) return 1
  if (i == 2) return 2
  return fibonacci (i-1) + fibonacci (i-2)
}
probe begin {
  printf ("11ème nombre de Fibonacci : %d\n", fibonacci (11))
  exit ()
}

Tout nombre plus grand peut dépasser les limites MAXACTION ou MAXNESTING et entraîner une erreur.

SONDAGE

Pour tracer l'entrée et la sortie d'une fonction, utilisez une paire de sondes :

probe kernel.function("sys_mkdir") { println ("entrée") }
probe kernel.function("sys_mkdir").return { println ("sortie") }

Pour lister les fonctions sondables du noyau, utilisez le mode de listage.

% stap -l 'kernel.function("*")'

Pour lister les fonctions sondables et les variables locales du noyau, utilisez un autre mode de listage.

% stap -L 'kernel.function("*")'
