Description détaillée

template<size_t _Nb>

class std::bitset< _Nb >::reference"Encapsule le concept d'un bit unique. Une instance de cette classe est un proxy pour un bit réel ; de cette façon, les opérations sur les bits individuels sont effectuées comme des instructions de manipulation de bits plus rapides à la taille du mot.

La plupart des utilisateurs n'auront jamais besoin d'utiliser cette classe directement ; les conversions depuis et vers bool sont automatiques et devraient être transparentes. Les opérateurs surchargés aident à préserver l'illusion.

(Sur un système typique, cette référence de bit a une taille 64 fois supérieure à celle d'un bit réel. Ha.)
