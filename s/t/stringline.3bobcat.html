FBB::StringLine(3bobcat) Extracteur de ligne FBB::StringLine(3bobcat)

NOM

FBB::StringLine - extraction de lignes via l'opérateur >>

SYNTAXE

#include <bobcat/stringline>

DESCRIPTION

L'opérateur standard d'extraction de chaîne operator>>(std::istream &, std::string &) extrait le premier « mot » d'un flux. Dans les cas où l'intention est d'extraire des lignes du flux, cet opérateur ne peut pas être utilisé, mais getline(std::istream &, std::string &) est généralement appelé.

Cependant, getline n'est pas appelé par de nombreux outils d'algorithmes génériques, comme l’istream_iterator.

La classe (en fait : struct) StringLine hérite simplement de std::string et définit son propre operator>>, qui lit la ligne suivante du std::istream spécifié.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::string

CONSTRUCTEURS

StringLine est une coquille vide autour de std::string. Il ne définit pas explicitement de constructeurs.

Les constructeurs et opérateurs d'affectation par copie et par déplacement sont disponibles.

OPERATEUR REDEFINI

o
std::istream &operator>>(std::istream &in, StringLine &str) :
L'opérateur d'extraction place la ligne suivante de in dans str, en appelant getline(std::istream &, std::string &).

FONCTIONS MEMBRES

Tous les membres de std::string sont disponibles, car FBB::StringLine hérite de ces classes.

EXEMPLE

L'exemple suivant extrait toutes les lignes de std::cin et les ajoute au std::vector<std::string> lines :

#include <iostream>
#include <algorithm>
#include <iterator>
#include <vector>
#include <bobcat/stringline>
using namespace std;
using namespace FBB;
int main()
{
    vector<string> lines;
    copy(
        istream_iterator<StringLine>(cin), istream_iterator<StringLine>(),
        back_inserter(lines)
    );
}

FICHIERS

bobcat/stringline - définit l'interface de la classe et l’operator>>.

Il existe des fichiers objets StringLine dans la bibliothèque Bobcat, il n'est donc pas nécessaire de lier à Bobcat lors de l'utilisation de StringLine.
