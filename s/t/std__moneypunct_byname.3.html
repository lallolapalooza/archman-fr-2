template<typename _CharT, bool _Intl> string std::moneypunct< _CharT, _Intl >::grouping () const [inline], [inherited]

Retourne la spécification de regroupement. Cette fonction retourne une chaîne représentant les regroupements de la partie entière d'un montant. Les regroupements indiquent où les séparateurs de milliers doivent être insérés.

Chaque caractère de la chaîne retournée est interprété comme un entier plutôt qu'un caractère. Ces nombres représentent le nombre de chiffres dans un groupe. Le premier caractère de la chaîne représente le nombre de chiffres dans le groupe le moins significatif. Si un caractère est négatif, il indique un nombre illimité de chiffres pour le groupe. Si d'autres caractères de la chaîne sont nécessaires pour regrouper un nombre, le dernier caractère est utilisé de manière répétée.

Par exemple, si grouping() retourne \003\002 et est appliqué au nombre 123456789, cela correspond à 12 345 6789. Notez que si la chaîne était 32, cela placerait plus de 50 chiffres dans le groupe le moins significatif si le jeu de caractères est ASCII.

La chaîne est retournée en appelant moneypunct<char_type>::do_grouping().

Retourne

Chaîne représentant la spécification de regroupement.

template<typename _CharT, bool _Intl> pattern std::moneypunct< _CharT, _Intl >::neg_format () const [inline], [inherited]

Retourne le motif des valeurs monétaires. Cette fonction retourne un motif décrivant le formatage d'un montant monétaire positif ou négatif. Elle le fait en retournant moneypunct<char_type>::do_pos_format() ou moneypunct<char_type>::do_neg_format().

Le motif comporte 4 champs décrivant l'ordre du symbole, du signe, de la valeur, et aucun ou espace. Il doit y avoir un de chaque dans le motif. Les énumérations none et space ne peuvent pas apparaître dans le premier champ et space ne peut pas apparaître dans le dernier champ.

Les parties d'une chaîne monétaire doivent apparaître dans l'ordre indiqué par les champs du motif. Le champ symbole indique que la valeur de curr_symbol() peut être présente. Le champ signe indique que la valeur de positive_sign() ou negative_sign() doit être présente. Le champ valeur indique que la valeur absolue du montant monétaire est présente. none indique 0 ou plusieurs caractères d'espacement, sauf à la fin, où il ne permet aucun espace. space indique que 1 ou plusieurs caractères d'espacement doivent être présents.

Par exemple, pour la locale US et le motif pos_format() {symbol,sign,value,none}, curr_symbol() == '$' positive_sign() == '+', et une valeur de 10.01, et les options définies pour forcer le symbole, la chaîne correspondante est $+10.01.

Detailed Description

template<typename _CharT, bool _Intl>

The class template std::moneypunct_byname provides locale-specific information about the formatting of monetary values.

This class is a C++ locale facet which is bound to a specific locale. The locale is specified in the constructor of the class. For example, to get the monetary punctuation for the US locale, you would instantiate this class as:

std::moneypunct_byname<char, true> mylocale("en_US");

The second template parameter _Intl determines whether the locale is international. If it is true, then the international representation of monetary values is used. This means that the currency symbol is not used, but rather the ISO 4217 currency code.

The template parameter _CharT specifies the character type to be used. This can be char or wchar_t.

Description détaillée

template<typename _CharT, bool _Intl>

La classe modèle std::moneypunct_byname fournit des informations spécifiques à la locale sur le formatage des valeurs monétaires.

Cette classe est une facette de locale C++ liée à une locale spécifique. La locale est spécifiée dans le constructeur de la classe. Par exemple, pour obtenir la ponctuation monétaire pour la locale américaine, vous instancieriez cette classe comme suit :

std::moneypunct_byname<char, true> mylocale("en_US");

Le deuxième paramètre de modèle _Intl détermine si la locale est internationale. Si elle est vraie, alors la représentation internationale des valeurs monétaires est utilisée. Cela signifie que le symbole de la devise n'est pas utilisé, mais plutôt le code de la devise ISO 4217.

Le paramètre de modèle _CharT spécifie le type de caractère à utiliser. Il peut s'agir de char ou wchar_t.
