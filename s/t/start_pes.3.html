start_pes(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

START_PES(3) Open MPI START_PES(3)

shmem_init, start_pes - Alloue un bloc de mémoire à partir du tas symétrique.

SYNTAXE

C ou C++:

void shmem_init(void)
void start_pes(int npes)

Fortran:

CALL SHMEM_INIT()
CALL START_PES(npes)

DESCRIPTION

La routine start_pes doit être la première instruction d'un programme parallèle SHMEM.

La routine start_pes accepte l'argument suivant :

npes
Non utilisé. Doit être défini à 0.

Cette routine initialise l'API SHMEM, elle doit donc être appelée avant d'appeler toute autre routine SHMEM. Cette routine est responsable entre autres de la mise en place du tas symétrique sur le PE appelant, et de la création des numéros de PE virtuels. Après un retour réussi de cette routine, le PE appelant sera capable de communiquer et de transférer des données vers d'autres PEs.

Les appels multiples à cette fonction ne sont pas autorisés.

Pour un aperçu de la programmation avec les routines de communication SHMEM, des exemples de programmes SHMEM et des instructions pour compiler des programmes SHMEM, consultez la page de manuel intro_shmem(3).

EXEMPLES

Ceci est un programme simple qui appelle shmem_integer_put(3) :

PROGRAM PUT
  INCLUDE "mpp/shmem.fh"
  INTEGER TARG, SRC, RECEIVER, BAR
  COMMON /T/ TARG
  PARAMETER (RECEIVER=1)
  CALL SHMEM_INIT()
  IF (MY_PE() .EQ. 0) THEN
    SRC = 33
    CALL SHMEM_INTEGER_PUT(TARG, SRC, 1, RECEIVER)
  ENDIF
  CALL SHMEM_BARRIER_ALL ! SYNCHRONIZES SENDER AND RECEIVER
  IF (MY_PE() .EQ. RECEIVER) THEN
    PRINT *,'PE ', MY_PE(),' TARG=',TARG,' (expect 33)'
  ENDIF
END

NOTES

Si l'appel à start_pes n'est pas la première instruction d'un programme, des résultats inattendus peuvent se produire sur certaines architectures.
