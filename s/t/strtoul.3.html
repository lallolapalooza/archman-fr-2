strtoul(3) Manuel des fonctions de bibliothèque strtoul(3)

NOM

strtoul, strtoull, strtouq - convertir une chaîne en entier non signé long

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdlib.h>
unsigned long strtoul(const char *restrict nptr,
                      char **_Nullable restrict endptr, int base);
unsigned long long strtoull(const char *restrict nptr,
                      char **_Nullable restrict endptr, int base);
Exigences pour le macro de test de fonctionnalité de glibc (voir feature_test_macros(7)):

strtoull():

    _ISOC99_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

La fonction strtoul() convertit la partie initiale de la chaîne dans nptr en une valeur unsigned long selon la base donnée, qui doit être comprise entre 2 et 36 inclusivement, ou être la valeur spéciale 0.

La chaîne peut commencer par une quantité arbitraire d'espaces blancs (tels que déterminés par isspace(3)) suivie d'un seul signe '+' ou '-' optionnel. Si base est zéro ou 16, la chaîne peut ensuite inclure un préfixe "0x" ou "0X", et le nombre sera lu en base 16 ; si base est zéro ou 2, la chaîne peut ensuite inclure un préfixe "0b" ou "0B", et le nombre sera lu en base 2 ; sinon, une base de zéro est prise comme 10 (décimal) à moins que le caractère suivant ne soit '0', auquel cas elle est prise comme 8 (octal).

Le reste de la chaîne est converti en une valeur unsigned long de la manière évidente, s'arrêtant au premier caractère qui n'est pas un chiffre valide dans la base donnée. (Dans les bases supérieures à 10, la lettre 'A' en majuscule ou en minuscule représente 10, 'B' représente 11, et ainsi de suite, jusqu'à 'Z' qui représente 35.)

Si endptr n'est pas NULL, et que la base est prise en charge, strtoul() stocke l'adresse du premier caractère invalide dans *endptr. S'il n'y avait aucun chiffre, strtoul() stocke la valeur originale de nptr dans *endptr (et renvoie 0). En particulier, si *nptr n'est pas '\0' mais que **endptr est '\0' au retour, toute la chaîne est valide.

La fonction strtoull() fonctionne de la même manière que la fonction strtoul() mais renvoie une valeur unsigned long long.

VALEUR DE RETOUR

La fonction strtoul() renvoie soit le résultat de la conversion, soit, s'il y avait un signe moins initial, la négation du résultat de la conversion représentée comme une valeur non signée, à moins que la valeur originale (non négativée) ne déborde ; dans ce dernier cas, strtoul() renvoie ULONG_MAX et définit errno à ERANGE. Exactement la même chose s'applique à strtoull() (avec ULLONG_MAX au lieu de ULONG_MAX).

ERREURS

Cette fonction ne modifie pas errno en cas de succès.

EINVAL
(pas dans C99) La base fournie contient une valeur non prise en charge.
ERANGE
La valeur résultante était hors limites.

L'implémentation peut également définir errno à EINVAL si aucune conversion n'a été effectuée (aucun chiffre trouvé, et 0 renvoyé).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strtoul (), strtoull (), strtouq () Thread safety MT-Safe locale

VERSIONS

Dans les locales autres que la locale "C", d'autres chaînes peuvent être acceptées. (Par exemple, le séparateur de milliers de la locale actuelle peut être pris en charge.)

BSD a également


u_quad_t strtouq(const char *nptr, char **endptr, int base);

avec une définition complètement analogue. Selon la taille du mot de l'architecture actuelle, cela peut être équivalent à strtoull() ou à strtoul().

NORMES

C23, POSIX.1-2024.

HISTORIQUE

strtoul()
POSIX.1-2001, C89, SVr4.
strtoull()
POSIX.1-2001, C99.
"0b", "0B"
C23. glibc 2.38. (Pas dans POSIX.)

AVERTISSEMENTS

Puisque strtoul() peut légitimement renvoyer 0 ou ULONG_MAX (ULLONG_MAX pour strtoull()) à la fois en cas de succès et d'échec, le programme appelant doit définir errno à 0 avant l'appel, puis déterminer si une erreur s'est produite en vérifiant si errno a une valeur non nulle après l'appel.

BOGUES

Nombres signés

Certaines valeurs négatives sont considérées comme une entrée valide et sont silencieusement converties en unsigned long.

Espaces blancs

Ces fonctions acceptent silencieusement les espaces blancs en tête.

isalnum(3)

Pour rejeter les espaces blancs et/ou un signe, appelez isalnum(3) avant strtoul().

EXEMPLES

Voir l'exemple sur la page de manuel de strtol(3) ; l'utilisation des fonctions décrites dans cette page de manuel est similaire.

VOIR AUSSI

strtoul(3)

strtoul

strtoul, strtoull, strtoumax - convertir une chaîne en entier non signé

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <stdlib.h>

unsigned long int strtoul(const char *nptr, char **endptr, int base);

unsigned long long int strtoull(const char *nptr, char **endptr, int base);

unsigned long long int strtoumax(const char *nptr, char **endptr, int base);

DESCRIPTION

The strtoul(), strtoull(), and strtoumax() functions convert the initial portion of the string pointed to by nptr to an unsigned long int, unsigned long long int, and unsigned quadmax_t (which is typically the same as unsigned long long int) respectively. They are similar to atoi(3) and atol(3) but offer more control.

The conversion is done following an unsigned interpretation of the numeral system indicated by base. Characters that do not form a valid number in the given base are ignored (after the initial numeric characters).

If base is zero, the numeric interpretation is determined by the characters following the usual C literal suffix: a leading ‘0x’ or ‘0X’ indicates hexadecimal, a leading ‘0’ indicates octal, and any other character indicates decimal. If base is between 2 and 36, then it is used as the base of the numeral system. The digits are 0-9 and the letters a-z (case insensitive).

If endptr is not NULL, a pointer to the character after the last character used in the conversion is stored in the location pointed to by endptr. If no conversion could be performed, nptr is stored in the location pointed to by endptr. If the converted value would overflow, the value is unchanged and ERANGE is set in errno. If no characters were converted, errno is set to EINVAL and 0 is returned.

RETURN VALUE

On success, these functions return the converted value. If the correct value is out of range, the function returns the maximum representable value for the return type, and errno is set to ERANGE. If no characters were converted, 0 is returned and errno is set to EINVAL.

ERRORS

EINVAL
No conversion could be performed.
ERANGE
The value is out of range for the return type.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

┌────────────┬───────────────────────────────┐
│ Interface  │ Attribute                     │
├────────────┼───────────────────────────────┤
│ strtoul    │ robust, no-unlock             │
│ strtoull   │ robust, no-unlock             │
│ strtoumax  │ robust, no-unlock             │
└────────────┴───────────────────────────────┘

VERSIONS

The strtoull() and strtoumax() functions were added in glibc 2.0.

STANDARDS

The strtoul() function conforms to C99 and POSIX.1-2001. The strtoull() function conforms to C99. The strtoumax() function conforms to C99.

HISTORY

The strtoul() function first appeared in 4.3BSD.

CAVEATS

These functions do not handle signed integer conversions. For signed conversions, use strtol(3), strtoll(3), or strtoimax(3).

BUGS

None known.

EXAMPLES

Convert the string "12345" to an unsigned long integer:

char *str = "12345";
char *endptr;
unsigned long int val;

val = strtoul(str, &endptr, 10);

if (endptr == str) {
    printf("No digits were found\n");
} else if (*endptr != '\0') {
    printf("Trailing characters: %s\n", endptr);
}

printf("Converted value: %lu\n", val);
