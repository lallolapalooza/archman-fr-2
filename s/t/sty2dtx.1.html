DESCRIPTION

Convertit un fichier .sty (paquet LaTeX) en format .dtx (source LaTeX documentée), en entourant les définitions de macros avec les environnements 'macro' et 'macrocode'. Le nom de la macro est automatiquement inséré comme argument de l'environnement 'macro'. Les lignes de code hors des définitions de macros sont seulement enveloppées dans des environnements 'macrocode'. Les lignes vides sont supprimées. Le script n'est pas censé être infaillible et précis à 100% mais plutôt un bon point de départ pour convertir des fichiers de style non documentés en fichiers .dtx.

Usage de base

perl sty2dtx.pl infile [infile ...] outfile

ou

perl sty2dtx.pl < file.sty > file.dtx

Définitions supportées

Les définitions de macros suivantes sont détectées lorsqu'elles sont au début d'une ligne (peuvent être préfixées par \global, \long, \protected et/ou \outer) :

\def   \edef   \gdef   \xdef
\newcommand{\name}     \newcommand*{\name}
\newcommand\name       \newcommand*\name
\renewcommand{\name}   \renewcommand*{\name}
\renewcommand\name     \renewcommand*\name
\providecommand{\name} \providecommand*{\name}
\providecommand\name   \providecommand*\name
\@namedef{\name}       \@namedef\name

Les définitions d'environnements suivantes sont détectées lorsqu'elles sont au début d'une ligne :

\newenvironment{name}  \renewenvironemnt{name}  \provideenvironment{name}

La macro et la définition d'environnement doivent soit se terminer sur la même ligne, soit avec un '"}"' seul sur une ligne.

UTILISATION

sty2dtx [<options>] [--<VAR>=<VALEUR> ...] [--] [<infile(s)>] [<outfile>]

Fichiers

  • peut être '"-"' pour STDIN ou STDOUT, ce qui est la valeur par défaut si aucun fichier n'est donné
  • plusieurs fichiers d'entrée sont fusionnés en un seul fichier de sortie

Variables

Les variables peuvent être définies en utilisant

--<VAR>=<VALEUR>

ou

--<VAR> <VALEUR>

et seront utilisées pour les substitutions dans le fichier modèle.

Variables courantes :

author, email, maintainer, year (pour le copyright),
version, date, description (du paquet/de la classe),
type (soit 'package' par défaut, soit 'class'),
filebase (automatiquement défini à partir du nom du fichier de sortie ou d'entrée),

Options

-h           Affiche cette aide
-H           Affiche l'aide étendue
-V           Affiche la version et le copyright
-v           Mode verbeux
-o sortie    Utilise le fichier donné comme sortie
-O           Écrase les fichiers de sortie déjà existants
-B           Utilise le nom de base du fichier d'entrée unique pour le fichier de sortie
-I           Crée également un fichier .ins (installation)
-c           N'utilise que la section code (comme v1.0)
-r           Supprime les environnements 'macro', 'macrocode', etc. existants.
-R           Ne supprime pas les environnements 'macro', 'macrocode', etc. existants.
-i fichier-ins  Crée un fichier .ins avec le nom donné
-t modèle  Utilise ce fichier comme modèle au lieu du modèle par défaut
-T modèle  Utilise ce fichier comme modèle pour le fichier .ins
-e fichier      Exporte le modèle .dtx par défaut dans le fichier et quitte
-E fichier      Exporte le modèle .ins par défaut dans le fichier et quitte
-D           Utilise la date actuelle comme date de fichier
-F fichier      Lit plus d'options et de variables à partir du fichier.
-N           Ne lit pas le fichier de configuration par défaut ; doit être la première option

Fichiers de configuration

Un fichier de configuration par défaut nommé soit 'sty2dtx.cfg' soit '.sty2dtx.cfg' est recherché dans le répertoire courant, le répertoire personnel de l'utilisateur et le répertoire de ce script, dans cet ordre. Le premier trouvé est chargé. Si aucun n'est trouvé, l'arborescence 'texmf' est recherchée pour un fichier de configuration 'sty2dtx.cfg'. Comme avec les fichiers -F, le fichier de configuration doit contenir une option ou une variable par ligne. Les lignes commençant par '"%"' ou '"#"' sont ignorées.

Exemples

Produire 'file.dtx' à partir de 'file.sty' :

sty2dtx.pl < file.sty > file.dtx

ou

sty2dtx.pl file.sty file.dtx

ou

sty2dtx.pl -B file.sty

Produire 'file.dtx' et 'file.ins' à partir de 'file.sty' :

sty2dtx.pl -I file.sty file.dtx

ou

sty2dtx.pl file.sty -i file.sty file.dtx

ou

sty2dtx.pl -IB file.sty

Définir des valeurs de variables personnalisées :

sty2dtx.pl --author Moi --email moi@là.com mypkg.sty my

DESCRIPTION

This script converts a LaTeX style file (.sty) into a DocStrip (.dtx) file. This is useful to package a LaTeX package for distribution along with its source code and documentation.

USAGE

The basic syntax is:

sty2dtx.pl [options] <input.sty> <output.dtx>

Common options include:

  • --type class: Produce a DTX file for a class instead of a package.

  • --comment string: Add a custom comment to the DTX file.

  • --help: Display help message and exit.

  • --version: Display version information and exit.

Examples

Produce DTX file for a package:

sty2dtx.pl mypkg.sty mypkg.dtx

Produce DTX file for a class:

sty2dtx.pl --type class mycls.sty mycls.dtx
