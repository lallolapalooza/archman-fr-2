Description détaillée

template<typename _Key, typename _Tp, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<std::pair<const _Key, _Tp> >>

class std::multimap< _Key, _Tp, _Compare, _Alloc >"Un conteneur standard composé de paires (clé, valeur), qui peuvent être récupérées en fonction d'une clé, en temps logarithmique.

Depuis

C++98

Paramètres de modèle

_Key Type des objets clés.
_Tp Type des objets mappés.
_Compare Type de fonction de comparaison, par défaut less<_Key>.
_Alloc Type d'allocateur, par défaut allocator<pair<const _Key, _Tp>.

Respecte les exigences d'un conteneur, d'un conteneur réversible et d'un conteneur associatif (utilisant des clés équivalentes). Pour un multimap<Key,T>, le type de clé est Key, le type mappé est T, et le type de valeur est std::pair<const Key,T>.

Les multimaps prennent en charge les itérateurs bidirectionnels.

L'arbre de données privé est déclaré exactement de la même manière pour map et multimap ; la distinction est entièrement faite dans la façon dont les fonctions de l'arbre sont appelées (*_unique par rapport à *_equal, identique à la norme).

Cette fonction construit et insère une paire (clé, valeur) dans le multimap. Contrairement à un std::map, le multimap ne repose pas sur des clés uniques et permet donc d'insérer plusieurs paires avec la même clé.

__args Arguments utilisés pour générer une nouvelle instance de paire (voir std::piecewise_contruct pour passer des arguments au constructeur de chaque partie de la paire).

Un itérateur qui pointe vers la paire (clé, valeur) insérée.

Cette fonction insère une paire (clé, valeur) dans le multimap. Contrairement à un std::map, le multimap ne repose pas sur des clés uniques et permet donc d'insérer plusieurs paires avec la même clé. Notez que le premier paramètre n'est qu'un indice et peut potentiellement améliorer les performances du processus d'insertion. Un mauvais indice n'entraînerait aucun gain d'efficacité.

Pour en savoir plus sur l'*indication* (hinting), voir : https://gcc.gnu.org/onlinedocs/libstdc++/manual/associative.html#containers.associative.insert_hints

L'insertion nécessite un temps logarithmique (si l'indice n'est pas utilisé).
