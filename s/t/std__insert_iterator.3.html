Description détaillée

template<typename _Container>

class std::insert_iterator< _Container >"Transforme l'affectation en insertion.

Ce sont des itérateurs de sortie, construits à partir d'un conteneur-de-T. Affecter un T à l'itérateur l'insère dans le conteneur à la position de l'itérateur, plutôt que d'écraser la valeur à cette position.

(Les séquences inséreront en fait une copie de la valeur avant la position de l'itérateur.)

Astuce : Utiliser la fonction inserter pour créer ces itérateurs peut faire gagner du temps de frappe.

Retourne

Cet itérateur, pour les opérations chaînées.

Ce type d'itérateur maintient sa propre position dans le conteneur. Affecter une valeur à l'itérateur insérera la valeur dans le conteneur à l'emplacement précédant l'itérateur.

La position est maintenue de telle sorte que les affectations ultérieures inséreront les valeurs immédiatement les unes après les autres. Par exemple,

// vector v contient A et Z
insert_iterator i (v, ++v.begin());
i = 1;
i = 2;
i = 3;
// vector v contient A, 1, 2, 3, et Z

std::insert_iterator

std::insert_iterator - Un itérateur d'insertion.

Syntaxe

#include <iterator>

template<
    class Container>
class insert_iterator;

Description

L'itérateur d'insertion std::insert_iterator est un itérateur de sortie qui peut être utilisé pour insérer des éléments dans un conteneur à l'aide de la méthode insert du conteneur.

Lorsque vous assignez une valeur à un itérateur d'insertion, la valeur est insérée dans le conteneur à la position spécifiée par l'itérateur.

Constructeur et destructeur

insert_iterator(Container& c, typename Container::iterator i);

Construit un itérateur d'insertion qui insère des éléments dans le conteneur c à la position spécifiée par l'itérateur i.

Fonctions membres

insert_iterator& operator=(const typename Container::value_type& value);

Insère la value dans le conteneur c à la position spécifiée par l'itérateur i, puis avance l'itérateur i.

insert_iterator& operator*();

Retourne une référence à l'itérateur d'insertion lui-même. Ceci est nécessaire pour satisfaire les exigences des itérateurs.

insert_iterator& operator++();

Avance l'itérateur d'insertion. L'itérateur d'insertion pointe toujours vers la même position dans le conteneur. Cette fonction ne fait rien d'autre que retourner une référence à l'itérateur.

insert_iterator& operator++(int);

Avance l'itérateur d'insertion. Cette fonction ne fait rien d'autre que retourner une référence à l'itérateur.
