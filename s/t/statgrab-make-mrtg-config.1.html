NOM

statgrab-make-mrtg-config - génère une configuration MRTG

SYNTAXE


statgrab-make-mrtg-config
[OPTION]...

DESCRIPTION

statgrab-make-mrtg-config génère une configuration MRTG à partir de la sortie de statgrab et l'écrit sur la sortie standard.

OPTIONS

Les options suivantes sont prises en charge.

--no-header
N'imprime pas les options globales de MRTG ; utile si vous souhaitez inclure la sortie de ce script dans un autre fichier de configuration MRTG
--workdir CHEMIN
Utilise CHEMIN pour l'option WorkDir de MRTG
--statgrab CHEMIN
Spécifie l'emplacement du binaire statgrab (par défaut "statgrab")
--help
Affiche l'aide et quitte
