NOM

strip-nondeterminism - Supprime les informations non déterministes des fichiers

SYNTAXE

strip-nondeterminism [-t typefichier] nomfichier ...

DESCRIPTION

strip-nondeterminism est un outil pour supprimer des éléments d'information non déterministes, tels que les horodatages, des fichiers. Il peut être utilisé comme étape de post-traitement pour rendre une compilation reproductible, lorsque le processus de compilation lui-même ne peut être rendu déterministe.

OPTIONS

-t typefichier, --type typefichier
Utilise le normaliseur pour le type de fichier donné (ar, gzip, jar, zip). Si cette option n'est pas spécifiée, le type de fichier est détecté automatiquement en fonction de l'extension du nom de fichier.
-T secondes, --timestamp secondes
Au lieu de supprimer les horodatages des fichiers, définissez-les au nombre de secondes donné depuis le 1er janvier 1970.
--clamp-timestamp
Remplace les horodatages uniquement s'ils sont postérieurs à l'heure spécifiée avec --timestamp. Vous pouvez utiliser cette option pour vous assurer que seuls les horodatages introduits dans le cadre du processus de compilation sont remplacés. NON IMPLÉMENTÉ POUR TOUS LES FORMATS DE FICHIERS POUR LE MOMENT.
--normalizers SPEC
Active ou désactive des normaliseurs spécifiques séparés par une virgule (par exemple, +foo,-bar. Les valeurs magiques +all et -all activeront et désactiveront tous les normaliseurs.
-h, --help
Affiche ce message d'aide.
-V, --version
Affiche uniquement la chaîne de version, puis quitte.
