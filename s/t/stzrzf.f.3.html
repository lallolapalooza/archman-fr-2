sous-routine stzrzf (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

STZRZF

Purpose:

!>
!> STZRZF réduit la matrice réelle supérieure trapézoïdale A de taille M x N ( M<=N )
!> en forme triangulaire supérieure par des transformations orthogonales.
!>
!> La matrice trapézoïdale supérieure A est factorisée comme suit :
!>
!>    A = ( R  0 ) * Z,
!>
!> où Z est une matrice orthogonale de taille N x N et R est une matrice
!> triangulaire supérieure de taille M x M.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A.  N >= M.
!>

A

!>          A est un tableau de réels (REAL), dimension (LDA,N)
!>          En entrée, la partie supérieure trapézoïdale de taille M x N de
!>          la matrice A doit contenir la matrice à factoriser.
!>          En sortie, la partie supérieure triangulaire de taille M x M
!>          de A contient la matrice triangulaire supérieure R, et les
!>          éléments M+1 à N des M premières lignes de A, avec le tableau
!>          TAU, représentent la matrice orthogonale Z comme un produit
!>          de M réflecteurs élémentaires.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de réels (REAL), dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau de réels (REAL), dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK.  LWORK >= max(1,M).
!>          Pour des performances optimales, LWORK >= M*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  La matrice Z de taille N x N peut être calculée comme suit :
!>
!>     Z =  Z(1)*Z(2)* ... *Z(M)
!>
!>  où chaque Z(k) de taille N x N est donné par :
!>
!>     Z(k) = I - tau(k)*v(k)*v(k)**T
!>
!>  avec v(k) le k-ième vecteur ligne de la matrice A de taille M x N
!>
!>     V = ( I   A(:,M+1:N) )
!>
!>  I est la matrice identité de taille M x M, A(:,M+1:N)
!>  est la sortie stockée dans A à la sortie de STZRZF,
!>  et tau(k) est le k-ième élément du tableau TAU.
!>
!>

Définition à la ligne 150 du fichier stzrzf.f.
