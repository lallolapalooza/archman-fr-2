sous-routine stpmqrt (character side, character trans, integer m, integer n, integer k, integer l, integer nb, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldt, * ) t, integer ldt, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, integer info)

STPMQRT

But :

!>
!> STPMQRT applique une matrice orthogonale réelle Q obtenue à partir d'un
!> réflecteur de bloc réel H à une matrice générale
!> réelle C, qui consiste en deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q^T à Gauche ;
!>          = 'R': appliquer Q ou Q^T à Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'T': Transposée, appliquer Q^T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est INTEGER
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0. Voir Détails supplémentaires.
!>

NB

!>          NB est INTEGER
!>          La taille du bloc utilisée pour le stockage de T. K >= NB >= 1.
!>          Cette valeur de NB doit être la même que celle utilisée pour générer T
!>          dans CTPQRT.
!>

V

!>          V est un tableau REAL, dimension (LDV,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CTPQRT dans B. Voir Détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si SIDE = 'L', LDV >= max(1,M) ;
!>          si SIDE = 'R', LDV >= max(1,N).
!>

T

!>          T est un tableau REAL, dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par CTPQRT, stockés sous forme de matrice NB-par-K.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= NB.
!>

A

!>          A est un tableau REAL, dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice A de taille K-par-N ou M-par-K.
!>          À la sortie, A est écrasée par le bloc correspondant de
!>          Q*C ou Q^T*C ou C*Q ou C*Q^T. Voir Détails supplémentaires.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDC >= max(1,K) ;
!>          Si SIDE = 'R', LDC >= max(1,M).
!>

B

!>          B est un tableau REAL, dimension (LDB,N)
!>          À l'entrée, la matrice B de taille M-par-N.
!>          À la sortie, B est écrasée par le bloc correspondant de
!>          Q*C ou Q^T*C ou C*Q ou C*Q^T. Voir Détails supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau REAL. La dimension de WORK est
!>           N*NB si SIDE = 'L', ou M*NB si SIDE = 'R'.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!>  élémentaires H(1), H(2), ..., H(K) ; V est composé d'un bloc rectangulaire V1 et d'un
!>  bloc trapézoïdal V2 :
!>
!>        V = [V1]
!>            [V2].
!>
!>  La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!>  où 0 <= L <= K ; V2 est trapézoïdal supérieur, consistant en les L premières
!>  lignes d'une matrice triangulaire supérieure KxK. Si L=K, V2 est triangulaire supérieure ;
!>  si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!>  Si SIDE = 'L' : C = [A] où A est KxN, et B est MxN et V est MxK.
!>                      [B]
!>
!>  Si SIDE = 'R' : C = [A B] où A est MxK, B est MxN et V est NxK.
!>
!>  La matrice orthogonale réelle Q est formée à partir de V et T.
!>
!>  Si TRANS='N' et SIDE='L', C est remplacé en sortie par Q * C.
!>
!>  Si TRANS='T' et SIDE='L', C est remplacé en sortie par Q^T * C.
!>
!>  Si TRANS='N' et SIDE='R', C est remplacé en sortie par C * Q.
!>
!>  Si TRANS='T' et SIDE='R', C est remplacé en sortie par C * Q^T.
!>
