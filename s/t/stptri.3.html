sous-routine stptri (caractere uplo, caractere diag, entier n, reEL, dimension( * ) ap, entier info)

STPTRI

But :

!>
!> STPTRI calcule l'inverse d'une matrice triangulaire réelle supérieure ou inférieure
!> stockée au format compacté.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CARACTERE*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau REEL, de dimension (N*(N+1)/2)
!>          À l'entrée, la matrice triangulaire supérieure ou inférieure A,
!>          stockée colonne par colonne dans un tableau linéaire. La j-ième colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*((2*n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>          À la sortie, l'inverse (triangulaire) de la matrice d'origine, dans
!>          le même format de stockage compacté.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, A(i,i) est exactement zéro. La matrice triangulaire
!>                est singulière et son inverse ne peut pas être calculé.
!>

Détails supplémentaires :

!>
!>  Une matrice triangulaire A peut être transférée en stockage compacté en utilisant l'un des
!>  segments de programme suivants :
!>
!>  UPLO = 'U' :                      UPLO = 'L' :
!>
!>        JC = 1                           JC = 1
!>        DO 2 J = 1, N                    DO 2 J = 1, N
!>           DO 1 I = 1, J                    DO 1 I = J, N
!>              AP(JC+I-1) = A(I,J)              AP(JC+I-J) = A(I,J)
!>      1    CONTINUE                    1    CONTINUE
!>           JC = JC + J                      JC = JC + N - J + 1
!>      2 CONTINUE                       2 CONTINUE
!>
