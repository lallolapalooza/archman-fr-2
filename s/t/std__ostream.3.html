template<typename _CharT, typename _Traits>

class std::basic_ostream< _CharT, _Traits >"Classe de modèle basic_ostream.

Paramètres de modèle

_CharT Type du flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

C'est la classe de base pour tous les flux de sortie. Elle fournit la mise en forme de texte de tous les types intégrés et communique avec toute classe dérivée de basic_streambuf pour effectuer la sortie réelle.

template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lancement d'exceptions en cas d'erreur.

Paramètres

__except Le nouveau masque d'exceptions.

Par défaut, les indicateurs d'erreur sont définis silencieusement. Vous pouvez définir un masque d'exceptions pour chaque flux ; si un bit du masque est défini dans les indicateurs d'erreur, une exception de type std::ios_base::failure est lancée.

Si l'indicateur d'erreur est déjà défini lors de l'ajout du masque d'exceptions, l'exception est immédiatement lancée. Essayez d'exécuter le code suivant sous GCC 3.1 ou une version ultérieure :

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

int std::ios_base::xalloc () [static], [inherited]

Access to unique indices.

Returns

An integer different from all previous calls.

This function returns a unique integer every time it is called. It can be used for any purpose, but is primarily intended to be a unique index for the iword and pword functions. The expectation is that an application calls xalloc in order to obtain an index in the iword and pword arrays that can be used without fear of conflict.

The implementation maintains a static variable that is incremented and returned on each invocation. xalloc is guaranteed to return an index that is safe to use in the iword and pword arrays.
