NOM

stoken-gui - Jeton logiciel GTK+

SYNTAXE

stoken-gui [options]

DESCRIPTION

stoken-gui est un jeton logiciel compatible avec les jetons RSA SecurID 128 bits (AES). L'interface graphique utilisateur offre un support limité pour la saisie de mot de passe et l'affichage du jeton courant. L'importation initiale du jeton et d'autres éléments de configuration sont gérés via l'interface en ligne de commande, stoken(1).

Après avoir utilisé stoken import pour remplir ~/.stokenrc, stoken-gui peut être appelé pour afficher le code du jeton et le compteur. Le code du jeton change une fois par minute ; stoken-gui peut rester lancé indéfiniment et copiera le code du jeton courant dans le presse-papiers sur demande.

Si un mot de passe et/ou un PIN est requis, stoken-gui affichera une boîte de dialogue demandant les informations appropriées.

OPTIONS

--small
Affiche une fenêtre minimale qui affiche uniquement un code de jeton et une barre de progression. Cliquer sur le code du jeton le copie dans le presse-papiers.
--rcfile=fichier
Utilise un fichier .stokenrc alternatif. Ceci est typiquement utilisé pour supporter plusieurs jetons sur le même compte utilisateur.
--password=mot_de_passe, -p mot_de_passe
Utilise un mot de passe fourni en ligne de commande, au lieu de demander à l'utilisateur. Voir les notes dans CONSIDÉRATIONS DE SÉCURITÉ sur la page de manuel de stoken(1).
--pin=pin, -n pin
Utilise un PIN fourni en ligne de commande, au lieu de demander à l'utilisateur. Voir les notes dans CONSIDÉRATIONS DE SÉCURITÉ sur la page de manuel de stoken(1).
--force, -f
Ignore la vérification de la date d'expiration du jeton.
--file=fichier
Utilise un jeton depuis fichier au lieu du fichier .stokenrc. À des fins de test uniquement.
--token=chaine_jeton
Utilise un jeton depuis la ligne de commande au lieu du fichier .stokenrc. Voir les notes ci-dessus concernant --file.
--random
Génère un jeton aléatoire à la volée. Utilisé uniquement pour les tests ou les démonstrations. Ces jetons ne devraient pas être utilisés pour une authentification réelle.
--help, -h
Affiche les informations d'utilisation de base.
--version, -v
Affiche les informations de version.

VOIR AUSSI

stoken(1).

FICHIERS

Fichier de configuration par défaut.
