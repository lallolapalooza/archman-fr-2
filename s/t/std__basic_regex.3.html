Description Détaillée

template<typename _Ch_type, typename _Rx_traits = regex_traits<_Ch_type>>

class std::basic_regex< _Ch_type, _Rx_traits > "Une expression régulière.

Les spécialisations de ce modèle de classe représentent des expressions régulières construites à partir de séquences de type de caractère _Ch_type. Utilisez le typedef std::regex pour std::basic_regex<char>.

Une séquence de caractères passée au constructeur sera analysée selon la grammaire choisie et utilisée pour créer une machine à états représentant l'expression régulière. L'objet regex peut ensuite être passé à des algorithmes tels que std::regex_match pour faire correspondre des séquences de caractères.

Le drapeau syntax_option_type passé au constructeur sélectionne l'une des grammaires d'expressions régulières prises en charge. La valeur par défaut est ECMAScript, et les autres sont basic, extended, awk, grep et egrep, qui sont des variations des expressions régulières POSIX.

Constantes Statiques

Ces drapeaux sont utilisés pour spécifier la grammaire et les options de recherche pour les expressions régulières.

static constexpr flag_type basic

Grammaire d'expression régulière POSIX de base.

static constexpr flag_type collate

Respecte les règles de tri de la locale courante pour les comparaisons d'intervalles.

static constexpr flag_type ECMAScript

Grammaire d'expression régulière ECMAScript (JavaScript). C'est la valeur par défaut.

static constexpr flag_type egrep

Grammaire d'expression régulière POSIX étendue (équivalent à extended ou grep | multiline).

static constexpr flag_type extended

Grammaire d'expression régulière POSIX étendue.

static constexpr flag_type grep

Grammaire d'expression régulière grep.

static constexpr flag_type icase

Ignore la casse lors de la correspondance.

static constexpr flag_type multiline

Permet aux ancres ^ et $ de correspondre au début/à la fin de chaque ligne dans une chaîne multi-lignes.

static constexpr flag_type nosubs

N'enregistre pas les correspondances des sous-expressions.

static constexpr flag_type optimize

Optimise l'expression régulière pour une recherche plus rapide, potentiellement au détriment d'un temps de compilation plus long.

Detailed Description

This class template represents a regular expression. The template parameter _Ch_type specifies the character type, and _Rx_traits specifies the traits class, which provides character traits, locale-dependent information, and the interface to the regex engine.

The default value for _Rx_traits is regex_traits< _Ch_type >.
