Description détaillée

Un conteneur type-safe pour tout type.

Un objet any est soit vide, soit il contient un objet du type CopyConstructible.

std::experimental::any est un type contenant une valeur d'un type CopyConstructible. Il peut contenir un objet d'un type quelconque ou être vide. S'il contient un objet, celui-ci peut être accédé par le biais de std::experimental::any_cast.

Une valeur est stockée dans std::experimental::any si elle a été transmise à un constructeur ou à un opérateur d'affectation qui prend un argument de type T, où T est un type autre que std::experimental::any lui-même.

Si std::experimental::any ne contient pas d'objet, il est dit "vide".

std::experimental::any::cast 

template <typename T> T* cast() noexcept;
template <typename T> const T* cast() const noexcept;
template <typename T> T& cast();
template <typename T> const T& cast() const;

La fonction cast() tente de convertir l'objet contenu dans std::experimental::any en un pointeur ou une référence vers le type T.

Si le type contenu correspond à T, la fonction retourne un pointeur ou une référence vers l'objet contenu. Sinon, elle retourne un pointeur nul ou lance une exception std::bad_any_cast.
