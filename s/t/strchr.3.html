strchr(3) Manuel des fonctions de bibliothèque strchr(3)

NOM

strchr, strrchr, strchrnul - localiser un caractère dans une chaîne

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
char *strchr(const char *s, int c);
char *strrchr(const char *s, int c);
#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <string.h>
char *strchrnul(const char *s, int c);

DESCRIPTION

La fonction strchr() renvoie un pointeur vers la première occurrence du caractère c dans la chaîne s.

La fonction strrchr() renvoie un pointeur vers la dernière occurrence du caractère c dans la chaîne s.

La fonction strchrnul() est similaire à strchr() sauf que si c n'est pas trouvé dans s, elle renvoie un pointeur vers l'octet nul à la fin de s, au lieu de NULL.

Ici, « caractère » signifie « octet » ; ces fonctions ne fonctionnent pas avec des caractères larges ou multibytes.

VALEUR DE RETOUR

Les fonctions strchr() et strrchr() renvoient un pointeur vers le caractère correspondant ou NULL si le caractère n'est pas trouvé. L'octet nul terminateur est considéré comme faisant partie de la chaîne, de sorte que si c est spécifié comme '\0', ces fonctions renvoient un pointeur vers le terminateur.

La fonction strchrnul() renvoie un pointeur vers le caractère correspondant, ou un pointeur vers l'octet nul à la fin de s (c'est-à-dire s+strlen(s)) si le caractère n'est pas trouvé.
