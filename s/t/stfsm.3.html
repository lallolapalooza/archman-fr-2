Fonctions/Sous-routines


sous-routine stfsm (transr, side, uplo, trans, diag, m, n, alpha, a, b, ldb)
STFSM résout une équation matricielle (un opérande est une matrice triangulaire au format RFP).

Documentation de la fonction/sous-routine

sous-routine stfsm (character transr, character side, character uplo, character trans, character diag, integer m, integer n, real alpha, real, dimension( 0: * ) a, real, dimension( 0: ldb-1, 0: * ) b, integer ldb)

STFSM résout une équation matricielle (un opérande est une matrice triangulaire au format RFP).

Objectif :

!>
!> Routine de niveau 3 BLAS pour A au format RFP.
!>
!> STFSM résout l'équation matricielle
!>
!>    op( A )*X = alpha*B  ou  X*op( A ) = alpha*B
!>
!> où alpha est un scalaire, X et B sont des matrices m par n, A est une matrice
!> triangulaire unitaire ou non unitaire, supérieure ou inférieure, et op( A ) est
!> l'une des suivantes :
!>
!>    op( A ) = A   ou   op( A ) = A**T.
!>
!> A est au format Rectangular Full Packed (RFP).
!>
!> La matrice X est écrasée sur B.
!>

Paramètres

TRANSR 
!>          TRANSR est CHARACTER*1
!>          = 'N':  La Forme Normale de RFP A est stockée ;
!>          = 'T':  La Forme Transposée de RFP A est stockée.
!>

SIDE

!>          SIDE est CHARACTER*1
!>           À l'entrée, SIDE spécifie si op( A ) apparaît à gauche
!>           ou à droite de X comme suit :
!>
!>              SIDE = 'L' ou 'l'   op( A )*X = alpha*B.
!>
!>              SIDE = 'R' ou 'r'   X*op( A ) = alpha*B.
!>
!>           Inchangé à la sortie.
!>

UPLO

!>          UPLO est CHARACTER*1
!>           À l'entrée, UPLO spécifie si la matrice RFP A provient
!>           d'une matrice triangulaire supérieure ou inférieure comme suit :
!>           UPLO = 'U' ou 'u' RFP A provient d'une matrice triangulaire supérieure
!>           UPLO = 'L' ou 'l' RFP A provient d'une matrice triangulaire inférieure
!>
!>           Inchangé à la sortie.
!>

TRANS

!>          TRANS est CHARACTER*1
!>           À l'entrée, TRANS spécifie la forme de op( A ) à utiliser
!>           dans la multiplication matricielle comme suit :
!>
!>              TRANS  = 'N' ou 'n'   op( A ) = A.
!>
!>              TRANS  = 'T' ou 't'   op( A ) = A'.
!>
!>           Inchangé à la sortie.
!>

DIAG

!>          DIAG est CHARACTER*1
!>           À l'entrée, DIAG spécifie si RFP A est unitaire ou non
!>           triangulaire comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée être unitaire triangulaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée être unitaire
!>                                  triangulaire.
!>
!>           Inchangé à la sortie.
!>

M

!>          M est INTEGER
!>           À l'entrée, M spécifie le nombre de lignes de B. M doit être
!>           supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie le nombre de colonnes de B. N doit être
!>           supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

ALPHA

!>          ALPHA est REAL
!>           À l'entrée, ALPHA spécifie le scalaire alpha. Lorsque alpha est
!>           zéro, A n'est pas référencé et B n'a pas besoin d'être défini avant
!>           l'entrée.
!>           Inchangé à la sortie.
!>

A

!>          A est un tableau de REAL, dimension (NT)
!>           NT = N*(N+1)/2 si SIDE='R' et NT = M*(M+1)/2 sinon.
!>           À l'entrée, la matrice A au format RFP.
!>           Le format RFP est décrit par TRANSR, UPLO et N comme suit :
!>           Si TRANSR='N' alors RFP A est (0:N,0:K-1) si N est pair ;
!>           K=N/2. RFP A est (0:N-1,0:K) si N est impair ; K=N/2. Si
!>           TRANSR = 'T' alors RFP est la transposée de RFP A telle que
!>           définie lorsque TRANSR = 'N'. Le contenu de RFP A est défini
!>           par UPLO comme suit : Si UPLO = 'U', RFP A contient les NT
!>           éléments de A supérieur empaqueté soit en format normal soit
!>           en format transposé. Si UPLO = 'L', RFP A contient
!>           les NT éléments de A inférieur empaqueté soit en format normal soit
!>           en format transposé. La LDA de RFP A est (N+1)/2 lorsque
!>           TRANSR = 'T'. Lorsque TRANSR est 'N', la LDA est N+1 si N est
!>           pair et N si N est impair.
!>           Voir la note ci-dessous pour plus de détails. Inchangé à la sortie.
!>

B

!>          B est un tableau de REAL, dimension (LDB,N)
!>           Avant l'entrée, la partie principale m par n du tableau B doit
!>           contenir la matrice B du second membre, et à la sortie elle est
!>           écrasée par la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>           À l'entrée, LDB spécifie la première dimension de B telle que déclarée
!>           dans le (sous-)programme appelant. LDB doit être supérieur ou égal
!>           à max( 1, m ).
!>           Inchangé à la sortie.
!>
