Description Détaillée

template<typename _UIntType, _UIntType __a, _UIntType __c, _UIntType __m>

class std::linear_congruential_engine< _UIntType, __a, __c, __m >"Un modèle de générateur de nombres pseudo-aléatoires congruentielles linéaires.

Un générateur de nombres aléatoires qui produit des nombres pseudo-aléatoires via la fonction linéaire : x_{i+1} ]

Le paramètre de modèle _UIntType doit être un type intégral non signé assez grand pour stocker des valeurs jusqu'à (__m-1). Si le paramètre de modèle __m est 0, le module __m utilisé est std::numeric_limits<_UIntType>::max() plus 1. Sinon, les paramètres de modèle __a et __c doivent être inférieurs à __m.

La taille de l'état est de $1$.
