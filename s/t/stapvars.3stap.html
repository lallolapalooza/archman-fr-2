NOM

stapvars - variables systemtap

DESCRIPTION

Les sections suivantes énumèrent les variables publiques fournies par les tapsets standards installés (le chemin d'installation est indiqué dans la page de manuel stappaths (7)). Chaque variable est décrite avec un type, et son comportement/ses restrictions. La syntaxe est la même que celle imprimée avec l'option stap -p2. Exemples :

exemple1:long
La variable "exemple1" contient un entier.
exemple2:string [long]
La variable "exemple2" est un tableau de chaînes de caractères, indexé par des entiers.

ARGV

argc:long
Contient la valeur de $# : le nombre d'arguments de ligne de commande passés au script systemtap. Il est initialisé avec une sonde implicite begin(-1).
argv:string [long]
Contient chaque argument de ligne de commande sous forme de chaîne de caractères. argv[1] sera égal à @1 s'il y avait au moins un argument de ligne de commande. Les arguments au-delà de #32 ne sont pas transcrits et produisent un message d'avertissement dans la sonde begin(-1) qui initialise ce tableau.

NULL

NULL:long
Simplement défini comme le nombre 0.
