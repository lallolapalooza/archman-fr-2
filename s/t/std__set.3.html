Description détaillée

template<typename _Key, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<_Key>>

class std::set< _Key, _Compare, _Alloc >"Un conteneur standard composé de clés uniques, qui peuvent être récupérées en temps logarithmique.

Depuis

C++98

Paramètres de template

_Key Type des objets clé.
_Compare Type de l'objet fonction de comparaison, par défaut less<_Key>.
_Alloc Type de l'allocateur, par défaut allocator<_Key>.

Satisfait les exigences d'un conteneur, d'un conteneur réversible et d'un conteneur associatif (utilisant des clés uniques).

Les ensembles supportent les itérateurs bidirectionnels.

La structure de données de l'arbre privé est déclarée exactement de la même manière pour set et multiset ; la distinction est entièrement faite dans la façon dont les fonctions de l'arbre sont appelées (*_unique versus *_equal, comme dans le standard).

template<typename _Key, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<_Key>> template<typename... _Args> std::pair< iterator, bool > std::set< _Key, _Compare, _Alloc >::emplace (_Args &&... __args) [inline]

Tente de construire et d'insérer un élément dans le jeu.

Paramètres

__args Arguments utilisés pour générer un élément.

Retourne

Une paire, dont le premier élément est un itérateur qui pointe vers l'élément potentiellement inséré, et le second est un booléen qui est vrai si l'élément a été effectivement inséré.

Cette fonction tente de construire et d'insérer un élément dans le jeu. Un jeu repose sur des clés uniques, et donc un élément n'est inséré que s'il n'est pas déjà présent dans le jeu.

L'insertion nécessite un temps logarithmique.

template<typename _Key, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<_Key>> template<typename... _Args> iterator std::set< _Key, _Compare, _Alloc >::emplace_hint (const_iterator __pos, _Args &&... __args) [inline]

Tente d'insérer un élément dans le jeu.

Paramètres

__pos Un itérateur qui sert d'indice quant à l'endroit où l'élément devrait être inséré.
__args Arguments utilisés pour générer l'élément à insérer.

Retourne

Un itérateur qui pointe vers l'élément dont la clé est équivalente à celle générée à partir de __args (peut être ou non l'élément lui-même).

Cette fonction ne se soucie pas de savoir si l'insertion a eu lieu, et ne retourne donc pas de booléen comme le fait emplace() avec un seul argument. Notez que le premier paramètre n'est qu'un indice et peut potentiellement améliorer les performances du processus d'insertion. Un mauvais indice n'apporterait aucun gain d'efficacité.

Pour en savoir plus sur les *indices*, consultez : https://gcc.gnu.org/onlinedocs/libstdc++/manual/associative.html#containers.associative.insert_hints

L'insertion nécessite un temps logarithmique (si l'indice n'est pas pris en compte).
