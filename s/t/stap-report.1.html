NOM

stap-report - collecter des informations système utiles pour le débogage des bugs de systemtap

SYNTAXE

stap-report

DESCRIPTION

L'exécutable stap-report collecte les informations système qui sont utiles pour le débogage des bugs de systemtap. Il est conseillé d'inclure un tel rapport dans les rapports de bugs, en particulier si vous les envoyez directement à l'équipe de développement. stap-report peut être exécuté soit en tant qu'utilisateur normal, soit en tant que root. Le rapport sera plus complet si stap-report est exécuté en tant que root.

EXEMPLES

$ stap-report > rapport.txt
$ head rapport.txt
== id ==
uid=1000(utilisateur) gid=1000(utilisateur) groups=122(stapdev),123(stapusr),129(stapsys)
== stap -V ==
Traducteur/pilote Systemtap (version 2.2.1/0.153, version Debian 2.2.1-1)
Copyright (C) 2005-2013 Red Hat, Inc. et autres
Ceci est un logiciel libre ; voir la source pour les conditions de copie.
fonctionnalités activées : AVAHI LIBSQLITE3 NSS TR1_UNORDERED_MAP NLS
== which stap ==
/usr/bin/stap
== locate --regex '/stap(run)?$' | xargs ls -ald ==
