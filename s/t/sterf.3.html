sous-routine dsterf (entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, entier info)

DSTERF

Objectif :

!>
!> DSTERF calcule toutes les valeurs propres d'une matrice tridiagonale symétrique
!> en utilisant la variante Pal-Walker-Kahan de l'algorithme QL ou QR.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres en ordre croissant.
!>

E

!>          E est un tableau DOUBLE PRÉCISION, dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale.
!>          À la sortie, E a été détruit.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  l'algorithme n'a pas réussi à trouver toutes les valeurs propres
!>                en un total de 30*N itérations ; si INFO = i, alors i
!>                éléments de E n'ont pas convergé vers zéro.
!>
