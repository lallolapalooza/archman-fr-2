NOM

startlazarus - démarre le programme lazarus. fpdoc.

SYNOPSIS

lazarus

Description

startlazarus est utilisé pour démarrer le programme lazarus. Il vérifie automatiquement si l'utilisateur a construit un lazarus personnalisé et le lance. Il est également utilisé pour redémarrer l'IDE, lorsque l'utilisateur clique sur redémarrer dans l'IDE.

Usage

Vous pouvez invoquer startlazarus sans aucun argument.
