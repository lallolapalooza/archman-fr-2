Documentation de la fonction/sous-routine

sous-routine stbtrs (character uplo, character trans, character diag, integer n, integer kd, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldb, * ) b, integer ldb, integer info)

STBTRS

But:

!>
!> STBTRS résout un système triangulaire de la forme
!>
!>    A * X = B  ou  A**T * X = B,
!>
!> où A est une matrice triangulaire bande d'ordre N, et B est une matrice N-par-NRHS.
!>
!> Cette sous-routine vérifie que A est non singulière, mais les appelants doivent noter que
!> seule la singularité exacte est détectée. Il est concevable qu'un ou plusieurs éléments diagonaux
!> de A soient des nombres anormalement petits sans que cette sous-routine ne signale une erreur.
!>
!> Si une perte possible de précision numérique due à des matrices proches de la singularité
!> est une préoccupation, l'appelant doit vérifier que A est non singulière dans une certaine
!> tolérance avant d'appeler cette sous-routine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N':  A * X = B  (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Conjuguée transposée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales ou de sous-diagonales de la
!>          matrice triangulaire bande A.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AB

!>          AB est tableau REAL, dimension (LDAB,N)
!>          La matrice triangulaire bande supérieure ou inférieure A, stockée
!>          dans les KD+1 premières lignes de AB.  La j-ème colonne de A est stockée
!>          dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+kd).
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés être 1.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

B

!>          B est tableau REAL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice du côté droit B.
!>          À la sortie, si INFO = 0, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, le i-ème élément diagonal de A est exactement zéro,
!>                indiquant que la matrice est singulière et que les
!>                solutions X n'ont pas été calculées.
!>
