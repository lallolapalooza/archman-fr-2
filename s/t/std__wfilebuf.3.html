classe std::basic_filebuf< _CharT, _Traits >"Le travail réel d'entrée et de sortie (pour les fichiers).

Paramètres de modèle

_CharT Type de flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

Cette classe associe ses séquences d'entrée et de sortie à un fichier externe sur disque, et maintient une position de fichier commune pour les deux séquences. Beaucoup de ses sémantiques sont décrites en termes de comportement similaire dans les flux FILE de la bibliothèque C standard.

Exigences sur traits_type, spécifiques à cette classe :

  • traits_type::pos_type doit être fpos<traits_type::state_type>
  • traits_type::off_type doit être streamoff
  • traits_type::state_type doit être Assignable et DefaultConstructible,
  • traits_type::state_type() doit être l'état initial pour codecvt.

template<typename _CharT, typename _Traits> void std::basic_filebuf< _CharT, _Traits >::_M_set_buffer (streamsize __off) [inline], [protected]

Cette fonction définit les pointeurs du tampon interne, pour les zones de lecture et d'écriture. Typiquement :

__off == egptr() - eback() lors d'un underflow/uflow (mode lecture) ; __off == 0 lors d'un overflow (mode écriture) ; __off == -1 lors d'une ouverture, setbuf, seekoff/pos (mode non validé).

NB : epptr() - pbase() == _M_buf_size - 1, puisque _M_buf_size reflète la mémoire allouée réelle et la dernière cellule est réservée pour le caractère de débordement d'une zone d'écriture complète.

template<typename _CharT, typename _Traits> basic_filebuf< _CharT, _Traits >::int_type std::basic_filebuf< _CharT, _Traits >::overflow (int_type __c = _Traits::eof()) [protected], [virtual]

Consomme les données du tampon ; écrit dans la séquence contrôlée.

Paramètres

__c Un caractère supplémentaire à consommer.

Retourne

eof() pour indiquer un échec, une autre valeur (généralement __c, ou not_eof())

Informellement, cette fonction est appelée lorsque le tampon de sortie est plein (ou n'existe pas, car la mise en tampon n'est pas obligatoirement effectuée). Si un tampon existe, il est consommé, avec un certain effet sur la séquence contrôlée. (Typiquement, le tampon est écrit dans la séquence brute.) Dans les deux cas, le caractère c est également écrit, si __c n'est pas eof().

Pour une définition formelle de cette fonction, consultez un bon ouvrage tel que Langer & Kreft, ou [27.5.2.4.5]/3-7.

Un streambuf de sortie fonctionnel peut être créé en redéfinissant uniquement cette fonction (aucune zone de tampon ne sera utilisée).

Note

La version de la classe de base ne fait rien, renvoie eof().

template<typename _CharT, typename _Traits> std::basic_filebuf< _CharT, _Traits >::showmanyc () [protected], [virtual]

Investigation des données disponibles.

Retourne

Une estimation du nombre de caractères disponibles dans la séquence d'entrée, ou -1.

Si elle retourne une valeur positive, alors les appels successifs à underflow() ne retourneront pas traits::eof() tant qu'au moins ce nombre de caractères n'aura pas été fourni. Si showmanyc() retourne -1, alors les appels à underflow() ou uflow() échoueront. [27.5.2.4.3]/1

La norme ajoute que l'intention n'est pas seulement que les appels [à underflow ou uflow] ne retourneront pas eof() mais qu'ils retourneront immédiatement.

La norme ajoute que les morphèmes de showmanyc sont es-how-many-see, pas show-manic.

Récupère plus de données de la séquence contrôlée.

Retourne

Le premier caractère de la séquence en attente .

Informellement, cette fonction est appelée lorsque le tampon d'entrée est épuisé (ou n'existe pas, car la mise en tampon n'est pas réellement obligatoire).
