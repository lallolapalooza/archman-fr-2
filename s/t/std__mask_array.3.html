Description détaillée

template<class _Tp>

class std::mask_array< _Tp >"Référence à un sous-ensemble sélectionné d'un tableau.

Une mask_array est une référence aux éléments réels d'un tableau spécifiés par un masque de bits sous la forme d'un tableau de bool. La manière d'obtenir une mask_array est d'appeler operator[](valarray<bool>) sur un valarray. La mask_array retournée permet alors d'effectuer des opérations sur le sous-ensemble d'éléments référencés dans le valarray d'origine.

Par exemple, si une mask_array est obtenue en utilisant le tableau (false, true, false, true) comme argument, la mask_array contient deux éléments référençant array[1] et array[3] dans le tableau sous-jacent.

std::mask_array

Synopsis

std::mask_array est une classe dans la bibliothèque standard C++ qui fournit un moyen de sélectionner et de modifier des éléments dans un tableau en utilisant un masque booléen.

Description

La classe std::mask_array est conçue pour fonctionner avec des tableaux (comme std::vector ou std::array) et permet d'appliquer des opérations conditionnelles basées sur un masque. Le masque est lui-même un tableau de booléens de la même taille que le tableau cible. Les éléments du tableau cible dont la valeur correspondante dans le masque est true sont affectés ou accessibles.

Fonctions membres

Constructeurs

  • mask_array(Container& data, const MaskContainer& mask): Constructeur qui prend une référence au conteneur de données et une référence constante au conteneur de masque.

Opérateurs

  • operator[](std::size_t i): Retourne une référence proxy à l'élément à l'indice i du tableau de données si le masque est vrai à cet indice. Sinon, le comportement est indéfini.
  • operator=(const T& value): Assigne une valeur à tous les éléments du tableau de données sélectionnés par le masque.
  • operator+=(const T& value), operator-=(const T& value), etc. : Opérateurs arithmétiques combinés qui appliquent l'opération aux éléments sélectionnés.

Exemple


#include <iostream>
#include <vector>
#include <iterator>
#include <algorithm>
#include <experimental/mask_array> // Note: L'en-tête peut varier selon l'implémentation

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5, 6};
    std::vector<bool> mask = {true, false, true, false, true, false};

    // Crée un mask_array pour les éléments où le masque est vrai
    auto masked_data = std::experimental::make_mask_array(data, mask);

    // Modifie les éléments sélectionnés
    masked_data = 10; 

    // Affiche les éléments modifiés
    for (const auto& val : data) {
        std::cout << val << " ";
    }
    std::cout << std::endl; // Affiche: 10 2 10 4 10 6

    return 0;
}
