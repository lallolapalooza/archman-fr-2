strerror(3) Manuel des fonctions de bibliothèque strerror(3)

NOM

strerror, strerrorname_np, strerrordesc_np, strerror_r, strerror_l - retourner une chaîne décrivant un numéro d'erreur

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <string.h>
char *strerror(int errnum);
const char *strerrorname_np(int errnum);
const char *strerrordesc_np(int errnum);
int strerror_r(size_t size;
               int errnum, char buf[size], size_t size);
               /* Conforme XSI */
char *strerror_r(size_t size;
               int errnum, char buf[size], size_t size);
               /* Spécifique à GNU */
char *strerror_l(int errnum, locale_t locale);
Exigences pour les macros de test de fonctionnalité de glibc (voir feature_test_macros(7)) :

strerrorname_np(), strerrordesc_np() :

    _GNU_SOURCE

strerror_r() :

    La version conforme XSI est fournie si :
        (_POSIX_C_SOURCE >= 200112L) && ! _GNU_SOURCE
    Sinon, la version spécifique à GNU est fournie.

DESCRIPTION

La fonction strerror() renvoie un pointeur vers une chaîne qui décrit le code d'erreur passé dans l'argument errnum, en utilisant éventuellement la partie LC_MESSAGES de la locale courante pour sélectionner la langue appropriée. (Par exemple, si errnum est EINVAL, la description renvoyée sera "Argument invalide".) Cette chaîne ne doit pas être modifiée par l'application, et le pointeur renvoyé deviendra invalide lors d'un appel ultérieur à strerror() ou strerror_l(), ou si le thread qui a obtenu la chaîne se termine. Aucune autre fonction de bibliothèque, y compris perror(3), ne modifiera cette chaîne.

Comme strerror(), la fonction strerrordesc_np() renvoie un pointeur vers une chaîne qui décrit le code d'erreur passé dans l'argument errnum, à la différence que la chaîne renvoyée n'est pas traduite selon la locale courante.

La fonction strerrorname_np() renvoie un pointeur vers une chaîne contenant le nom du code d'erreur passé dans l'argument errnum. Par exemple, en donnant EPERM comme argument, cette fonction renvoie un pointeur vers la chaîne "EPERM". En donnant 0 comme argument, cette fonction renvoie un pointeur vers la chaîne "0".

strerror_r()

strerror_r() est similaire à strerror(), mais peut utiliser le tampon fourni buf au lieu d'en allouer un en interne. Cette fonction est disponible en deux versions : une version conforme XSI spécifiée dans POSIX.1-2001 (disponible depuis glibc 2.3.4, mais non conforme POSIX avant glibc 2.13), et une version spécifique à GNU (disponible depuis glibc 2.0). La version conforme XSI est fournie avec les paramètres des macros de test de fonctionnalité indiqués dans SYNOPSIS ; sinon la version spécifique à GNU est fournie. Si aucune macro de test de fonctionnalité n'est explicitement définie, alors (depuis glibc 2.4) _POSIX_C_SOURCE est défini par défaut avec la valeur 200112L, de sorte que la version conforme XSI de strerror_r() est fournie par défaut.

La version conforme XSI de strerror_r() est préférée pour les applications portables. Elle renvoie la chaîne d'erreur dans le tampon fourni par l'utilisateur buf de taille size.

La version spécifique à GNU de strerror_r() renvoie un pointeur vers une chaîne contenant le message d'erreur. Il peut s'agir soit d'un pointeur vers une chaîne que la fonction stocke dans buf, soit d'un pointeur vers une chaîne statique (immuable) (auquel cas buf n'est pas utilisé). Si la fonction stocke une chaîne dans buf, alors au maximum size octets sont stockés (la chaîne peut être tronquée si size est trop petit et errnum est inconnu). La chaîne comprend toujours un octet nul de fin ('\0').

strerror_l()

strerror_l() est similaire à strerror(), mais mappe errnum à un message d'erreur dépendant de la locale dans la locale spécifiée par locale. Le comportement de strerror_l() est indéfini si locale est l'objet de locale spécial LC_GLOBAL_LOCALE ou n'est pas un handle d'objet de locale valide.

VALEUR DE RETOUR

Les fonctions strerror(), strerror_l() et la version spécifique à GNU de strerror_r() renvoient la chaîne de description d'erreur appropriée, ou un message "Erreur inconnue nnn" si le numéro d'erreur est inconnu.

En cas de succès, strerrorname_np() et strerrordesc_np() renvoient la chaîne de description d'erreur appropriée. Si errnum est un numéro d'erreur invalide, ces fonctions renvoient NULL.

En cas de succès, la fonction strerror_r() conforme XSI renvoie 0. En cas d'erreur, un numéro d'erreur (positif) est renvoyé (depuis glibc 2.13), ou -1 est renvoyé et errno est défini pour indiquer l'erreur (avant glibc 2.13).

POSIX.1-2001 et POSIX.1-2008 exigent qu'un appel réussi à strerror() ou strerror_l() laisse errno inchangé, et notent que, puisqu'aucune valeur de retour n'est réservée pour indiquer une erreur, une application qui souhaite vérifier les erreurs doit initialiser errno à zéro avant l'appel, puis vérifier errno après l'appel.

ERREURS

EINVAL
La valeur de errnum n'est pas un numéro d'erreur valide.
ERANGE
Un espace de stockage insuffisant a été fourni pour contenir la chaîne de description d'erreur.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strerror () Sécurité des threads MT-Safe
strerrorname_np (), strerrordesc_np () Sécurité des threads MT-Safe
strerror_r (), strerror_l () Sécurité des threads MT-Safe

Avant glibc 2.32, strerror() n'est pas MT-Safe.

POSIX.1-2001.

strerrorname_np()
strerrordesc_np()
GNU.

POSIX.1-2001 permet à strerror() de définir errno si l'appel rencontre une erreur, mais ne spécifie pas quelle valeur doit être renvoyée comme résultat de fonction en cas d'erreur. Sur certains systèmes, strerror() renvoie NULL si le numéro d'erreur est inconnu. Sur d'autres systèmes, strerror() renvoie une chaîne ressemblant à "Une erreur nnn s'est produite" et définit errno à EINVAL si le numéro d'erreur est inconnu. C99 et POSIX.1-2008 exigent que la valeur de retour ne soit pas NULL.
