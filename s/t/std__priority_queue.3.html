Description détaillée

template<typename _Tp, typename _Sequence = vector<_Tp>, typename _Compare = less<typename _Sequence::value_type>>

class std::priority_queue< _Tp, _Sequence, _Compare >"Un conteneur standard triant automatiquement son contenu.

Paramètres du modèle

_Tp Type de l'élément.
_Sequence Type de la séquence sous-jacente, par défaut vector<_Tp>.
_Compare Type de l'objet fonction de comparaison, par défaut less<_Sequence::value_type>.

Ce n'est pas un vrai conteneur, mais un adaptateur. Il contient un autre conteneur et fournit une interface d'encapsulation à ce conteneur. L'encapsulation est ce qui impose le tri basé sur la priorité et le comportement de file d'attente. Très peu des exigences de l'interface de conteneur/séquence standard sont satisfaites (par exemple, les itérateurs).

Le deuxième paramètre de modèle définit le type de la séquence/conteneur sous-jacent. Il est par défaut std::vector, mais il peut s'agir de tout type qui supporte front(), push_back, pop_back et les itérateurs d'accès aléatoire, comme std::deque ou un type défini par l'utilisateur approprié.

Le troisième paramètre de modèle fournit les moyens de faire des comparaisons de priorité. Il est par défaut less<value_type> mais peut être tout ce qui définit un ordre faible strict.

Les membres qui ne se trouvent pas dans les conteneurs normaux sont container_type, qui est un typedef pour le second paramètre Sequence, et push, pop et top, qui sont des opérations de file d'attente standard.

Note

Aucun opérateur d'égalité/comparaison n'est fourni pour priority_queue.

Le tri des éléments a lieu au fur et à mesure de leur ajout et de leur retrait de la priority_queue à l'aide des fonctions membres de la priority_queue. Si vous accédez aux éléments par d'autres moyens et modifiez leurs données de telle sorte que l'ordre de tri serait différent, la priority_queue ne triera pas les éléments pour vous. NAME

std::priority_queue - template class

SYNOPSIS

#include <queue>

template<typename   _Tp, typename _Sequence = vector<_Tp>, typename _Compare =   less<typename _Sequence::value_type>>
class std::priority_queue

Description

A priority queue is a container adapter that provides constant time lookup of the largest (by default) element, at the expense of logarithmic insertion and extraction. It is implemented on top of a sequence container, most likely a std::vector.

A Compare type defaults to std::less, which creates a max-heap (the largest element is retrieved by top()). If you want a min-heap, you'll need to provide std::greater as the Compare type.

Template Parameters

_Tp
The type of the elements stored in the queue.
_Sequence
The type of the underlying sequence container. Defaults to std::vector<_Tp>.
_Compare
The comparison functor used to order the elements. Defaults to std::less<typename _Sequence::value_type>.

Supprime le premier élément. C'est une opération typique de file d'attente. Elle réduit la file d'attente d'une unité. La complexité temporelle de l'opération dépend de la séquence sous-jacente.
