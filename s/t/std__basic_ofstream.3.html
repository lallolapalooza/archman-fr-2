Fonctions de sortie non formatée

Toutes les fonctions de sortie non formatée ont un comportement commun. Chacune commence par construire un objet temporaire de type `std::basic_ostream::sentry`. Cela a plusieurs effets, y compris la définition d'un indicateur d'état ; voir la documentation de `sentry` pour plus de détails.

Si l'état du `sentry` est bon, la fonction essaie de générer les données appropriées pour le type de l'argument.

Si une exception est levée pendant l'insertion, `ios_base::badbit` sera activé dans l'état d'erreur du flux. Si `badbit` est activé dans le masque d'exceptions du flux, l'exception sera relancée sans terminer ses actions.
