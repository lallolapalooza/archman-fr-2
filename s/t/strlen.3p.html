STRLEN(3P) Manuel du programmeur POSIX STRLEN(3P)

PROLOGUE

Ce manuel est une page du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page man Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

strlen, strnlen — obtenir la longueur d'une chaîne de taille fixe

SYNOPSIS

#include <string.h>
size_t strlen(const char *s);
size_t strnlen(const char *s, size_t maxlen);

DESCRIPTION

Pour strlen() : La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction strlen() calcule le nombre d'octets dans la chaîne pointée par s, sans inclure le caractère NUL de fin.

La fonction strnlen() calcule la plus petite valeur entre le nombre d'octets dans le tableau pointé par s, sans inclure le caractère NUL de fin, et la valeur de l'argument maxlen. La fonction strnlen() n'examinera jamais plus de maxlen octets du tableau pointé par s.

VALEUR DE RETOUR

La fonction strlen() retourne la longueur de s ; aucune valeur de retour n'est réservée pour indiquer une erreur.

La fonction strnlen() retourne le nombre d'octets précédant le premier octet nul dans le tableau pointé par s, si s contient un octet nul dans les maxlen premiers octets ; sinon, elle retourne maxlen.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Obtenir les longueurs de chaîne

L'exemple suivant définit la longueur maximale de key et data en utilisant strlen() pour obtenir les longueurs de ces chaînes.

#include <string.h>
...
struct element {
    char *key;
    char *data;
};
...
char *key, *data;
int len;
*keylength = *datalength = 0;
...
if ((len = strlen(key)) > *keylength)
    *keylength = len;
if ((len = strlen(data)) > *datalength)
    *datalength = len;
...
