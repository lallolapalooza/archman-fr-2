template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lancer des exceptions en cas d'erreur.

Paramètres

__except Le nouveau masque d'exceptions.

Par défaut, les indicateurs d'erreur sont définis silencieusement. Vous pouvez définir un masque d'exceptions pour chaque flux ; si un bit du masque devient défini dans les indicateurs d'erreur, une exception de type std::ios_base::failure est levée.

Si l'indicateur d'erreur est déjà défini lorsque le masque d'exceptions est ajouté, l'exception est immédiatement levée. Essayez d'exécuter le code suivant sous GCC 3.1 ou une version ultérieure :

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}
