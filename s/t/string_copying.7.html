string_copying(7) Manuel d'informations diverses string_copying(7)

NOM

stpcpy, strcpy, strcat, stpecpy, strtcpy, strlcpy, strlcat, stpncpy, strncpy, strncat - copie de chaînes et séquences de caractères

SYNTAXE

Chaînes

// Copie en chaîne une chaîne.
char *stpcpy(char *restrict dst, const char *restrict src);
// Copie/concatène une chaîne.
char *strcpy(char *restrict dst, const char *restrict src);
char *strcat(char *restrict dst, const char *restrict src);
// Copie en chaîne une chaîne avec troncature.
char *stpecpy(char *dst, char end[0], const char *restrict src);
// Copie/concatène une chaîne avec troncature.
ssize_t strtcpy(size_t dsize;
               char dst[restrict dsize], const char *restrict src,
               size_t dsize);
size_t strlcpy(size_t dsize;
               char dst[restrict dsize], const char *restrict src,
               size_t dsize);
size_t strlcat(size_t dsize;
               char dst[restrict dsize], const char *restrict src,
               size_t dsize);

Séquences de caractères complétées par des null

// Remplit un tampon de taille fixe avec les caractères d'une chaîne
// et complète avec des octets nuls.
char *strncpy(size_t dsize;
              char dst[restrict dsize], const char *restrict src,
               size_t dsize);
char *stpncpy(size_t dsize;
              char dst[restrict dsize], const char *restrict src,
               size_t dsize);
// Copie en chaîne une séquence de caractères complétée par des null dans une séquence de caractères.
mempcpy(dst, src, strnlen(src, NITEMS(src)));
// Copie en chaîne une séquence de caractères complétée par des null dans une chaîne.
stpcpy(mempcpy(dst, src, strnlen(src, NITEMS(src))), "");
// Concatène une séquence de caractères complétée par des null dans une chaîne.
char *strncat(size_t ssize;
               char *restrict dst, const char src[restrict ssize],
               size_t ssize);
// Duplique une séquence de caractères complétée par des null dans une chaîne.
char *strndup(size_t ssize;
               const char src[ssize], size_t ssize);

Séquences de caractères bornées par leur longueur

// Copie en chaîne une séquence de caractères bornée par sa longueur.
void *mempcpy(size_t len;
               void dst[restrict len], const void src[restrict len],
               size_t len);
// Copie en chaîne une séquence de caractères bornée par sa longueur dans une chaîne.
stpcpy(mempcpy(dst, src, len), "");

DESCRIPTION

Termes (et abréviations)

chaîne (str)
est une séquence de zéro ou plusieurs caractères non nuls suivie d'un caractère nul.
séquence de caractères
est une séquence de zéro ou plusieurs caractères non nuls. Un programme ne devrait jamais utiliser une séquence de caractères là où une chaîne est requise. Cependant, avec les précautions appropriées, une chaîne peut être utilisée à la place d'une séquence de caractères.
séquence de caractères complétée par des null
Les séquences de caractères peuvent être contenues dans des tampons de taille fixe, qui contiennent des octets nuls de remplissage après la séquence de caractères, pour remplir le reste du tampon sans affecter la séquence de caractères ; cependant, ces octets nuls de remplissage ne font pas partie de la séquence de caractères. Ne pas confondre complété par des null et terminé par un null : complété par des null signifie 0 ou plusieurs octets nuls de remplissage, tandis que terminé par un null signifie exactement 1 caractère nul de terminaison.
séquence de caractères bornée par sa longueur
Séquence de caractères délimitée par sa longueur. Il peut s'agir d'une tranche d'une séquence de caractères plus grande, voire d'une chaîne.
longueur (len)
est le nombre de caractères non nuls dans une chaîne ou une séquence de caractères. C'est la valeur de retour de strlen(str) et de strnlen(buf, size).
taille
fait référence à l'ensemble du tampon où la chaîne ou la séquence de caractères est contenue.
fin
est le nom d'un pointeur vers le dernier élément d'un tampon. Il est équivalent à &str[size]. Il est utilisé comme valeur sentinelle, pour pouvoir tronquer les chaînes ou les séquences de caractères au lieu de dépasser la capacité du tampon contenant.
copie
Ce terme est utilisé lorsque l'écriture commence au premier élément pointé par dst.
concatène
Ce terme est utilisé lorsqu'une fonction trouve d'abord le caractère nul de terminaison dans dst, puis commence à écrire à cette position.
chaîne-copie
Ce terme est utilisé lorsqu'il appartient au programmeur de fournir un pointeur vers le caractère nul de terminaison dans la chaîne dst (ou un après le dernier caractère d'une séquence de caractères), et que la fonction commence à écrire à cet emplacement. La fonction renvoie un pointeur vers le nouvel emplacement du caractère nul de terminaison (ou un après le dernier caractère d'une séquence de caractères) après l'appel, afin que le programmeur puisse l'utiliser pour chaîner de tels appels.
duplique
Alloue un nouveau tampon où une copie est placée.

Copie, concatène, et chaîne-copie

À l'origine, il y avait une distinction entre les fonctions qui copient et celles qui concatènent. Cependant, les fonctions plus récentes qui copient tout en permettant le chaînage couvrent les deux cas d'utilisation avec une seule API. Elles sont également algorithmiquement plus rapides, car elles n'ont pas besoin de rechercher le caractère nul de terminaison de la chaîne existante. Cependant, les fonctions qui concatènent ont une utilisation beaucoup plus simple, donc si la performance n'est pas importante, il peut être judicieux de les utiliser pour améliorer la lisibilité.

Le pointeur renvoyé par les fonctions qui permettent le chaînage est un sous-produit de l'opération de copie, il n'a donc pas de coût de performance. Les fonctions qui renvoient un tel pointeur, et qui peuvent donc être chaînées, ont des noms de la forme *stp*(), car il est courant de nommer le pointeur simplement p.

Les fonctions de copie en chaîne qui tronquent devraient accepter un pointeur vers la fin du tampon de destination, et avoir des noms de la forme *stpe*(). Cela permet de ne pas avoir à recalculer la taille restante après chaque appel.

Tronquer ou pas?

La première chose à noter est que les programmeurs doivent faire attention avec les tampons, afin qu'ils aient toujours la bonne taille, et que la troncature ne soit pas nécessaire.

Dans la plupart des cas, la troncature n'est pas souhaitée, et il est plus simple de faire simplement la copie. Un code plus simple est un code plus sûr. La programmation contre les erreurs de programmation en ajoutant plus de code ajoute simplement plus de points où des erreurs peuvent être commises.

De nos jours, les compilateurs peuvent détecter la plupart des erreurs de programmation grâce à des fonctionnalités comme les avertissements du compilateur, les analyseurs statiques et _FORTIFY_SOURCE (voir ftm(7)). Garder le code simple aide ces fonctionnalités de détection de dépassement à être plus précises.

Lors de la validation des entrées utilisateur, le code ne devrait normalement pas tronquer, mais plutôt échouer et empêcher la copie du tout.

Dans certains cas, cependant, il est judicieux de tronquer.

stpecpy()

strtcpy()

Séquences de caractères complétées par des zéros

Pour des raisons historiques, certaines API standard et formats de fichiers, tels que utmpx(5) et tar(1), utilisent des séquences de caractères complétées par des zéros dans des tampons de taille fixe. Pour interagir avec eux, des fonctions spécialisées doivent être utilisées.

Pour copier des octets de chaînes dans ces tampons, utilisez strncpy(3) ou stpncpy(3).

Pour lire une séquence de caractères complétée par des zéros, utilisez strnlen(src, NITEMS(src)), et vous pourrez ensuite la traiter comme une séquence de caractères de longueur bornée ; ou utilisez directement strncat(3) ou strndup(3).

Séquences de caractères de longueur bornée

La fonction de copie de séquences de caractères la plus simple est mempcpy(3). Elle nécessite de connaître toujours la longueur de vos séquences de caractères, pour lesquelles des structures peuvent être utilisées. Cela rend le code beaucoup plus rapide, car vous connaissez toujours la longueur de vos séquences de caractères et pouvez effectuer les copies et les mesures de longueur minimales. mempcpy(3) copie des séquences de caractères, vous devez donc explicitement définir le caractère nul de terminaison si vous avez besoin d'une chaîne.

Dans les programmes qui utilisent considérablement des chaînes ou des séquences de caractères, et qui ont besoin des meilleures performances, l'utilisation de séquences de caractères qui se chevauchent peut faire une grande différence. Elle permet de conserver des sous-séquences d'une séquence de caractères plus grande, sans dupliquer la mémoire ni perdre de temps à copier.

Cependant, c'est délicat, car cela nécessite l'utilisation de séquences de caractères. Les API de la bibliothèque C utilisent des chaînes, donc les programmes qui utilisent des séquences de caractères devront faire attention à différencier les chaînes des séquences de caractères.

Pour copier une séquence de caractères de longueur bornée, utilisez mempcpy(3).

Pour copier une séquence de caractères de longueur bornée dans une chaîne, utilisez stpcpy(mempcpy(dst, src, len), "").

Une chaîne est également acceptée en entrée, car mempcpy(3) demande la longueur, et une chaîne est composée d'une séquence de caractères de même longueur plus un caractère nul de terminaison.

Chaîne vs séquence de caractères

Certaines fonctions opèrent uniquement sur des chaînes. Celles-ci exigent que la source src soit une chaîne et garantissent une chaîne de sortie (même en cas de troncature). Les fonctions qui concatènent exigent également que dst contienne une chaîne avant l'appel. Liste des fonctions :

•
stpcpy(3)
•
strcpy(3), strcat(3)
•
stpecpy()
•
strtcpy()
•
strlcpy(3bsd), strlcat(3bsd)

D'autres fonctions exigent une chaîne d'entrée, mais créent une séquence de caractères en sortie. Ces fonctions ont des noms trompeurs et une longue histoire d'utilisation abusive. Liste des fonctions :

•
stpncpy(3)
•
strncpy(3)

D'autres fonctions opèrent sur une séquence de caractères d'entrée et créent une chaîne de sortie. Les fonctions qui concatènent exigent également que dst contienne une chaîne avant l'appel. strncat(3) a un nom encore plus trompeur que les fonctions ci-dessus. Liste des fonctions :

•
strncat(3)
•
strndup(3)

D'autres fonctions opèrent sur une séquence de caractères d'entrée pour créer une séquence de caractères de sortie. Liste des fonctions :

Fonctions

stpcpy(3)
Copie la chaîne d'entrée dans une chaîne de destination. Le programmeur est responsable de l'allocation d'un tampon suffisamment grand. Elle retourne un pointeur adapté à l'enchaînement.
strcpy(3)
strcat(3)
Copie et concatène la chaîne d'entrée dans une chaîne de destination. Le programmeur est responsable de l'allocation d'un tampon suffisamment grand. La valeur de retour est inutile.
stpcpy(3) est une alternative plus rapide à ces fonctions.
stpecpy()
Copie en chaîne la chaîne d'entrée dans une chaîne de destination. Si le tampon de destination, limité par un pointeur vers sa fin, n'est pas assez grand pour contenir la copie, la chaîne résultante est tronquée (mais il est garanti qu'elle est terminée par un caractère nul). Elle retourne un pointeur adapté à l'enchaînement. La troncature doit être détectée une seule fois après le dernier appel en chaîne.
Cette fonction n'est fournie par aucune bibliothèque ; voir EXAMPLES pour une implémentation de référence.
strtcpy()
Copie la chaîne d'entrée dans une chaîne de destination. Si le tampon de destination n'est pas assez grand pour contenir la copie, la chaîne résultante est tronquée (mais il est garanti qu'elle est terminée par un caractère nul). Elle retourne la longueur de la chaîne, ou -1 si elle a tronqué.
Cette fonction n'est fournie par aucune bibliothèque ; voir EXAMPLES pour une implémentation de référence.
strlcpy(3bsd)
strlcat(3bsd)
Copie et concatène la chaîne d'entrée dans une chaîne de destination. Si le tampon de destination, limité par sa taille, n'est pas assez grand pour contenir la copie, la chaîne résultante est tronquée (mais il est garanti qu'elle est terminée par un caractère nul). Elles retournent la longueur de la chaîne totale qu'elles ont tenté de créer.
Vérifiez BUGS avant d'utiliser ces fonctions.
strtcpy() et stpecpy() sont de meilleures alternatives à ces fonctions.
stpncpy(3)
Copie la chaîne d'entrée dans une séquence de caractères de destination complétée par des zéros dans un tampon de taille fixe. Si le tampon de destination, limité par sa taille, n'est pas assez grand pour contenir la copie, la séquence de caractères résultante est tronquée. Comme elle crée une séquence de caractères, elle n'a pas besoin d'écrire un caractère nul de terminaison. Il est impossible de distinguer une troncature par le résultat de l'appel, d'une séquence de caractères qui remplit juste le tampon de destination ; la troncature doit être détectée en comparant la longueur de la chaîne d'entrée avec la taille du tampon de destination.
strncpy(3)
Cette fonction est identique à stpncpy(3) sauf pour la valeur de retour inutile.
stpncpy(3) est une alternative plus utile à cette fonction.
strncat(3)
Concatène la séquence de caractères d'entrée, contenue dans un tampon de taille fixe complété par des zéros, dans une chaîne de destination. Le programmeur est responsable de l'allocation d'un tampon suffisamment grand. La valeur de retour est inutile.
Ne pas confondre cette fonction avec strncpy(3) ; elles ne sont pas du tout liées.
stpcpy(mempcpy(dst, src, strnlen(src, NITEMS(src))), "") est une alternative plus rapide à cette fonction.
strndup(3)
Duplique la séquence de caractères d'entrée, contenue dans un tampon de taille fixe complété par des zéros, dans une chaîne de destination nouvellement allouée.
La chaîne doit être libérée avec free(3).
mempcpy(3)
Copie la séquence de caractères d'entrée, limitée par sa longueur, dans une séquence de caractères de destination. Le programmeur est responsable de l'allocation d'un tampon suffisamment grand. Elle retourne un pointeur adapté à l'enchaînement.

VALEUR DE RETOUR

stpcpy(3)
Un pointeur vers le caractère nul de terminaison dans la chaîne de destination.
stpecpy()
Un pointeur vers le caractère nul de terminaison dans la chaîne de destination, en cas de succès. En cas d'erreur, NULL est retourné et errno est défini pour indiquer l'erreur.
mempcpy(3)
stpncpy(3)
Un pointeur après le dernier caractère de la séquence de caractères de destination.
strtcpy()
La longueur de la chaîne, en cas de succès. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.
strlcpy(3bsd)
strlcat(3bsd)
La longueur de la chaîne totale qu'elles ont tenté de créer (comme si la troncature ne s'était pas produite).
strcpy(3)
strcat(3)
strncpy(3)
strncat(3)
Le pointeur dst, qui est inutile.
strndup(3)
La chaîne nouvellement allouée.

NOTES

Le noyau Linux possède une fonction interne pour copier des chaînes, strscpy(9), qui est identique à strtcpy(), à l'exception qu'elle renvoie -E2BIG au lieu de -1 et qu'elle ne définit pas errno.

CAVEATS

Ne mélangez pas les appels en chaîne à des fonctions tronquées et non tronquées. C'est conceptuellement incorrect, sauf si vous savez que la première partie d'une copie rentrera toujours. Quoi qu'il en soit, la différence de performance sera probablement négligeable, il sera donc probablement plus clair d'utiliser des sémantiques cohérentes : soit tronquées, soit non tronquées. Appeler une fonction non tronquée après une fonction tronquée est nécessairement incorrect.

BUGS

Toutes les fonctions de concaténation partagent le même problème de performance : Shlemiel the painter. Comme atténuation, les compilateurs peuvent transformer certains appels à des fonctions de concaténation en fonctions de copie normales, car strlen(dst) est généralement un sous-produit de la copie précédente.

strlcpy(3) et strlcat(3) doivent lire la chaîne src entière, même si le tampon de destination est petit. Cela les rend vulnérables aux attaques par déni de service (DoS) si un attaquant peut contrôler la longueur de la chaîne src. Et sinon, elles sont toujours inutilement lentes.

Implémentations

Voici des implémentations de référence pour les fonctions non fournies par libc.


/* Ce code est dans le domaine public.  */
char *
stpecpy(char *dst, char end[0], const char *restrict src)
{
    size_t  dlen;
    if (dst == NULL)
        return NULL;
    dlen = strtcpy(dst, src, end - dst);
    return (dlen == -1) ? NULL : dst + dlen;
}
ssize_t
strtcpy(char *restrict dst, const char *restrict src, size_t dsize)
{
    bool    trunc;
    size_t  dlen, slen;
    if (dsize == 0) {
        errno = ENOBUFS;
        return -1;
    }
    slen = strnlen(src, dsize);
    trunc = (slen == dsize);
    dlen = slen - trunc;
    stpcpy(mempcpy(dst, src, dlen), "");
    if (trunc)
        errno = E2BIG;
    return trunc ? -1 : slen;
}
