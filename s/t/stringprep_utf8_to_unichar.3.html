NOM

stringprep_utf8_to_unichar - Fonction API

SYNTAXE

#include <stringprep.h>

uint32_t stringprep_utf8_to_unichar(const char * p);

ARGUMENTS

const char * p
un pointeur vers un caractère Unicode encodé en UTF-8

DESCRIPTION

Convertit une séquence d'octets encodée en UTF-8 en un caractère Unicode. Si p ne pointe pas vers un caractère valide encodé en UTF-8, les résultats ne sont pas définis.

Valeur de retour : le caractère résultant.
