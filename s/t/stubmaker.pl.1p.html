NOM

stubmaker.pl - Génère des stubs clients à partir d'un fichier WSDL.

OPTIONS

-d <nom_répertoire>
Spécifie le répertoire dans lequel vous souhaitez sortir les fichiers. Le répertoire doit déjà exister.
-v
Active la sortie « verbeuse » pendant le processus de génération des stubs de code. Pour être honnête, il n'y a pas grand-chose que le programme affiche, mais si vous devez voir quelque chose s'afficher sur la console, cela convient.
--help
Affiche un court message d'aide.
--version
Affiche la version actuelle de stubmaker.pl.

FICHIERS DE STUBS

SOUS_PROGRAMMES DE STUBS

La « classe » ou le « paquet » créé par stubmaker.pl est en réalité une sous-classe de l'objet cœur SOAP::Lite. Par conséquent, toutes les méthodes que l'on peut appeler sur SOAP::Lite peuvent également être appelées sur les stubs générés.

Par exemple, supposez que vous souhaitiez obtenir une sortie lisible à partir du stub généré, appelez simplement readable(1) sur l'instance du stub. Voir l'exemple ci-dessous.

Les sous-programmes suivants sont uniques aux classes de stubs générés et aident l'utilisateur à contrôler et configurer la classe de stub.

want_som(booléen)
Lorsqu'il est défini sur 1, SOAP::Lite renverra des objets SOAP::SOM à l'utilisateur lors de l'invocation d'une méthode sur un service distant. Ceci est très utile lorsque vous devez vérifier si la valeur de retour est un SOAP::Fault ou non. Lorsqu'il est défini sur 0, SOAP::Lite renverra la valeur de retour de la méthode.

EXEMPLES

Invocation de stubmaker.pl depuis la ligne de commande

> perl stubmaker.pl http://www.xmethods.net/sd/StockQuoteService.wsdl Ou : > perl "-MStockQuoteService qw(:all)" -le "print getQuote('MSFT')"

Travail avec les classes de stubs

Ligne de commande : > perl stubmaker.pl http://ws1.api.re2.yahoo.com/ws/soap-demo/full.wsdl

Fichier : echo.pl > use full ; > use SOAP::Lite +trace => qw( debug ) ; > my $f = new full ; > $f->use_prefix(0) ; > $f->readable(1) ; > $f->want_som(1) ; > $som = $f->echoViaBase64("foo") ;
