Documentation de la fonction/sous-programme

sous-programme stbmv (caractère uplo, caractère trans, caractère diag, entier n, entier k, réel, dimension(lda,*) a, entier lda, réel, dimension(*) x, entier incx)

STBMV

But :

!>
!> STBMV  effectue l'une des opérations matrice-vecteur suivantes :
!>
!>    x := A*x,   ou   x := A**T*x,
!>
!> où x est un vecteur de n éléments et  A est une matrice bande triangulaire
!> de dimension n par n, unitaire ou non, supérieure ou inférieure, avec ( k + 1 )
!> diagonales.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>           À l'entrée, UPLO spécifie si la matrice est supérieure ou
!>           inférieure, comme suit :
!>
!>              UPLO = 'U' ou 'u'   A est une matrice triangulaire supérieure.
!>
!>              UPLO = 'L' ou 'l'   A est une matrice triangulaire inférieure.
!>

TRANS

!>          TRANS est CARACTÈRE*1
!>           À l'entrée, TRANS spécifie l'opération à effectuer comme suit :
!>
!>              TRANS = 'N' ou 'n'   x := A*x.
!>
!>              TRANS = 'T' ou 't'   x := A**T*x.
!>
!>              TRANS = 'C' ou 'c'   x := A**T*x.
!>

DIAG

!>          DIAG est CARACTÈRE*1
!>           À l'entrée, DIAG spécifie si A est unitaire ou non, comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée être unitaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée être unitaire.
!>

N

!>          N est ENTIER
!>           À l'entrée, N spécifie l'ordre de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>

K

!>          K est ENTIER
!>           À l'entrée, lorsque UPLO = 'U' ou 'u', K spécifie le nombre de
!>           super-diagonales de la matrice A.
!>           À l'entrée, lorsque UPLO = 'L' ou 'l', K spécifie le nombre de
!>           sous-diagonales de la matrice A.
!>           K doit satisfaire  0 .le. K.
!>

A

!>          A est un tableau RÉEL, de dimension ( LDA, N )
!>           Avant l'appel, lorsque UPLO = 'U' ou 'u', la partie principale
!>           ( k + 1 ) par n du tableau A doit contenir la partie bande
!>           triangulaire supérieure de la matrice des coefficients, fournie
!>           colonne par colonne, avec la diagonale principale de la matrice
!>           dans la ligne ( k + 1 ) du tableau, la première super-diagonale
!>           commençant à la position 2 dans la ligne k, et ainsi de suite. Le
!>           triangle supérieur gauche de dimension k par k du tableau A
!>           n'est pas référencé.
!>           Le segment de programme suivant transfère une matrice bande
!>           triangulaire supérieure du stockage conventionnel complet vers le
!>           stockage bande :
!>
!>                 DO 20, J = 1, N
!>                    M = K + 1 - J
!>                    DO 10, I = MAX( 1, J - K ), J
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Avant l'appel, lorsque UPLO = 'L' ou 'l', la partie principale
!>           ( k + 1 ) par n du tableau A doit contenir la partie bande
!>           triangulaire inférieure de la matrice des coefficients, fournie
!>           colonne par colonne, avec la diagonale principale de la matrice
!>           dans la ligne 1 du tableau, la première sous-diagonale commençant
!>           à la position 1 dans la ligne 2, et ainsi de suite. Le triangle
!>           inférieur droit de dimension k par k du tableau A n'est pas
!>           référencé.
!>           Le segment de programme suivant transfère une matrice bande
!>           triangulaire inférieure du stockage conventionnel complet vers le
!>           stockage bande :
!>
!>                 DO 20, J = 1, N
!>                    M = 1 - J
!>                    DO 10, I = J, MIN( N, J + K )
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Notez que lorsque DIAG = 'U' ou 'u', les éléments du tableau A
!>           correspondant aux éléments diagonaux de la matrice ne sont pas
!>           référencés, mais sont supposés être égaux à un.
!>

LDA

!>          LDA est ENTIER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (sous-programme). LDA doit être au moins
!>           ( k + 1 ).
!>

X

!>          X est un tableau RÉEL, de dimension au moins
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Avant l'appel, le tableau X incrémenté doit contenir le vecteur x
!>           de n éléments. À la sortie, X est écrasé par le vecteur transformé x.
!>

INCX

!>          INCX est ENTIER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être zéro.
!>
