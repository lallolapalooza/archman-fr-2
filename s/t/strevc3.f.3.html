But :

!>
!> STREVC3 calcule certains ou tous les vecteurs propres droits et/ou gauches
!> d'une matrice T quasi-triangulaire réelle.
!> Les matrices de ce type sont produites par la factorisation de Schur
!> d'une matrice générale réelle :  A = Q*T*Q**T, comme calculé par SHSEQR.
!>
!> Les vecteurs propres droits x et gauches y de T correspondant
!> à une valeur propre w sont définis par :
!>
!>    T*x = w*x,     (y**T)*T = w*(y**T)
!>
!> où y**T désigne la transposée du vecteur y.
!> Les valeurs propres ne sont pas fournies à cette routine, mais sont lues directement
!> à partir des blocs diagonaux de T.
!>
!> Cette routine renvoie les matrices X et/ou Y des vecteurs propres droits et gauches
!> de T, ou les produits Q*X et/ou Q*Y, où Q est une matrice d'entrée. Si Q est le facteur orthogonal qui réduit une matrice
!> A en forme de Schur T, alors Q*X et Q*Y sont les matrices des vecteurs propres droits et
!> gauches de A.
!>
!> Ceci utilise une version BLAS de niveau 3 de la rétro-transformation.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer les deux vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer tous les vecteurs propres droits et/ou gauches ;
!>          = 'B' : calculer tous les vecteurs propres droits et/ou gauches,
!>                  rétro-transformés par les matrices dans VR et/ou VL ;
!>          = 'S' : calculer les vecteurs propres droits et/ou gauches sélectionnés,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un TABLEAU LOGIQUE, dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Si w(j) est une valeur propre réelle, le vecteur propre réel
!>          correspondant est calculé si SELECT(j) est .VRAI..
!>          Si w(j) et w(j+1) sont les parties réelle et imaginaire d'une
!>          valeur propre complexe, le vecteur propre complexe
!>          correspondant est calculé si SELECT(j) ou SELECT(j+1) est .VRAI., et
!>          à la sortie, SELECT(j) est mis à .VRAI. et SELECT(j+1) est mis à
!>          .FAUX..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un TABLEAU RÉEL, dimension (LDT,N)
!>          La matrice T quasi-triangulaire supérieure sous forme canonique de Schur.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un TABLEAU RÉEL, dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N x N (généralement la matrice orthogonale Q
!>          des vecteurs de Schur retournée par SHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres gauches de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres gauches de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VL, dans le même ordre que leurs
!>                           valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est ENTIER
!>          La dimension principale du tableau VL.
!>          LDVL >= 1, et si SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un TABLEAU RÉEL, dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Q de taille N x N (généralement la matrice orthogonale Q
!>          des vecteurs de Schur retournée par SHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres droits de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres droits de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VR, dans le même ordre que leurs
!>                           valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est ENTIER
!>          La dimension principale du tableau VR.
!>          LDVR >= 1, et si SIDE = 'R' ou 'B', LDVR >= N.
!>

MM

!>          MM est ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR effectivement
!>          utilisées pour stocker les vecteurs propres.
!>          Si HOWMNY = 'A' ou 'B', M est mis à N.
!>          Chaque vecteur propre réel sélectionné occupe une colonne et chaque
!>          vecteur propre complexe sélectionné occupe deux colonnes.
!>

WORK

!>          WORK est un TABLEAU RÉEL, dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,3*N).
!>          Pour une performance optimale, LWORK >= N + 2*N*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

strevc3.f(3)

NOM

strevc3 - Calcule les vecteurs propres gauches de tous les sous-espaces propres (unitaires) d'une matrice triangulaire supérieure réelle.

SYNTAXE

  SUBROUTINE STREVC3(SIDE, HOWMNY, SELECT, N, A, LDA, VL, LDVL, VR, LDVR, MM, M, WORK, INFO)

    LOGICAL SELECT( * )
    INTEGER N, LDA, LDVL, LDVR, MM, M, INFO
    CHARACTER*1 SIDE, HOWMNY
    REAL A( LDA, * ), VL( LDVL, * ), VR( LDVR, * ), WORK( * )

Description

STREVC3 calcule les vecteurs propres gauches et/ou droits de tous les sous-espaces propres (unitaires) d'une matrice triangulaire supérieure réelle. Les vecteurs propres sont calculés de manière à ce que les vecteurs propres gauches et droits soient orthogonaux les uns aux autres.

Pour un sous-espace propre unitaire V d'une matrice A, si la partie imaginaire de la matrice est nulle, alors les vecteurs propres gauches peuvent être calculés à partir des vecteurs propres droits en utilisant la transformation de transposée conjuguée, et vice versa.

STREVC3 est une version révisée de STREVC.

Paramètres

SIDE (CHARACTER*1)

Indique si l'on calcule les vecteurs propres gauches, les vecteurs propres droits ou les deux.

  • 'L' : vecteurs propres gauches seulement.
  • 'R' : vecteurs propres droits seulement.
  • 'B' : vecteurs propres gauches et droits.
HOWMNY (CHARACTER*1)

Indique si les vecteurs propres de tous les sous-espaces propres sont calculés ou seulement ceux qui sont sélectionnés.

  • 'A' : tous les vecteurs propres sont calculés.
  • 'S' : les vecteurs propres sont sélectionnés par le tableau LOGICAL SELECT.
SELECT (LOGICAL, dimension(*))

Indique quels vecteurs propres doivent être calculés si HOWMNY = 'S'. Pour chaque colonne i, si SELECT(i) est vrai, alors le vecteur propre correspondant à la i-ème valeur propre est calculé.

N (INTEGER)

L'ordre de la matrice A. N >= 0.

A (REAL, dimension(LDA,*))

Le tableau de dimension (LDA, N) contient la matrice triangulaire supérieure.

LDA (INTEGER)

Le premier indice de A. LDA >= max(1, N).

VL (REAL, dimension(LDVL,*))

Si SIDE = 'L' ou 'B', VL contient les vecteurs propres gauches calculés. Les vecteurs propres gauches sont stockés dans les colonnes de VL, de telle sorte que VL(i,j) contienne le i-ème composant du j-ème vecteur propre gauche. Les vecteurs propres gauches sont normalisés de telle sorte que le 1-norme soit égale à 1.

LDVL (INTEGER)

Le premier indice de VL. LDVL >= max(1, N).

VR (REAL, dimension(LDVR,*))

Si SIDE = 'R' ou 'B', VR contient les vecteurs propres droits calculés. Les vecteurs propres droits sont stockés dans les colonnes de VR, de telle sorte que VR(i,j) contienne le i-ème composant du j-ème vecteur propre droit. Les vecteurs propres droits sont normalisés de telle sorte que le 1-norme soit égale à 1.

LDVR (INTEGER)

Le premier indice de VR. LDVR >= max(1, N).

MM (INTEGER)

Le nombre de colonnes réservées dans VL et VR pour stocker les vecteurs propres. MM >= M.

M (INTEGER)

Le nombre de vecteurs propres calculés. M <= MM.

WORK (REAL, dimension(*))

Tableau de travail.

INFO (INTEGER)

  • 0 : succès.
  • < 0 : si INFO = -i, alors le i-ème argument était invalide.
