STRIP(1P) Manuel du programmeur POSIX STRIP(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

strip — supprime les informations inutiles des fichiers désérialisables (DÉVELOPPEMENT)

SYNTAXE

strip fichier...

DESCRIPTION

Un fichier désérialisable est défini comme un fichier déplaçable, objet ou exécutable. Sur les systèmes conformes XSI, un fichier désérialisable peut également être une archive de fichiers objets ou déplaçables.

L'utilitaire strip doit supprimer des fichiers désérialisables nommés par les opérandes fichier toutes les informations que l'implémenteur juge inutiles à l'exécution de ces fichiers. La nature de ces informations n'est pas spécifiée. L'effet de strip sur les fichiers objets et exécutables doit être similaire à l'utilisation de l'option -s de c99 ou fort77. L'effet de strip sur une archive de fichiers objets doit être similaire à l'utilisation de l'option -s de c99 ou fort77 pour chaque fichier objet de l'archive.

OPTIONS

Aucune.

OPÉRANDES

L'opérande suivant doit être pris en charge :

fichier
Un chemin d'accès faisant référence à un fichier désérialisable.

ENTRÉE STANDARD

Non utilisé.

FICHIERS D'ENTRÉE

Les fichiers d'entrée doivent être sous forme de fichiers désérialisables produits avec succès par tout compilateur défini par ce volume de POSIX.1‐2017 ou produits en créant ou en mettant à jour une archive de tels fichiers à l'aide de l'utilitaire ar.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes doivent affecter l'exécution de strip :

LANG
Fournir une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume des Définitions de Base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si défini à une chaîne de caractères non vide, remplacer les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Déterminer la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Déterminer la locale qui devrait être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Déterminer l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

Non utilisé.

ERREUR STANDARD

La sortie d'erreur standard ne doit être utilisée que pour les messages de diagnostic.

FICHIERS DE SORTIE

L'utilitaire strip doit produire des fichiers désérialisables de format non spécifié.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes doivent être retournées :

 0
Terminaison réussie.
>0
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

Par défaut.

Les sections suivantes sont informatives.

USAGE APPLICATION

Aucun.

EXEMPLES

Aucun.

RATIONALE

Historiquement, cet utilitaire était utilisé pour supprimer la table des symboles d'un fichier désérialisable. Il a été inclus car on sait que la quantité d'informations symboliques peut atteindre plusieurs mégaoctets ; la capacité de la supprimer de manière portable a été jugée importante, en particulier pour les petits systèmes.

Le comportement de strip sur les fichiers objets et exécutables est dit être le même que l'option -s d'un compilateur. Bien que le résultat final soit essentiellement le même, il n'est pas requis d'être identique.

Les systèmes conformes XSI prennent en charge l'utilisation de strip sur des fichiers d'archive contenant des fichiers objets ou déplaçables.
