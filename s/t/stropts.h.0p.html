stropts.h(0p) Manuel du programmeur POSIX stropts.h(0p)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

stropts.h — Interface STREAMS (STREAMS)

SYNOPIS

#include <stropts.h>

DESCRIPTION

L'en-tête <stropts.h> définit la structure bandinfo, qui inclura au moins les membres suivants :

int            bi_flag  Type de vidage.
unsigned char  bi_pri   Bande de priorité.

L'en-tête <stropts.h> définit la structure strpeek, qui inclura au moins les membres suivants :

struct strbuf  ctlbuf   La partie contrôle du message.
struct strbuf  databuf  La partie données du message.
t_uscalar_t    flags    RS_HIPRI ou 0.

L'en-tête <stropts.h> définit la structure strbuf, qui inclura au moins les membres suivants :

char  *buf     Pointeur vers le tampon.
int    len     Longueur des données.
int    maxlen  Longueur maximale du tampon.

L'en-tête <stropts.h> définit la structure strfdinsert, qui inclura au moins les membres suivants :

struct strbuf  ctlbuf   La partie contrôle du message.
struct strbuf  databuf  La partie données du message.
int            fildes   Descripteur de fichier de l'autre STREAM.
t_uscalar_t    flags    RS_HIPRI ou 0.
int            offset   Emplacement relatif de la valeur stockée.

L'en-tête <stropts.h> définit la structure strioctl, qui inclura au moins les membres suivants :

int    ic_cmd     Commande ioctl().
char  *ic_dp      Pointeur vers le tampon.
int    ic_len     Longueur des données.
int    ic_timout  Délai d'attente pour la réponse.

L'en-tête <stropts.h> définit la structure strrecvfd, qui inclura au moins les membres suivants :

int    fd   Descripteur de fichier reçu.
gid_t  gid  GID de l'expéditeur.
uid_t  uid  UID de l'expéditeur.

L'en-tête <stropts.h> définit les types uid_t et gid_t via typedef, comme décrit dans <sys/types.h>.

L'en-tête <stropts.h> définit les types t_scalar_t et t_uscalar_t, respectivement, comme types opaques signés et non signés d'une longueur égale d'au moins 32 bits.

L'en-tête <stropts.h> définit la structure str_list, qui inclura au moins les membres suivants :

struct str_mlist  *sl_modlist  Noms de modules STREAMS.
int                sl_nmods    Nombre de noms de modules STREAMS.

L'en-tête <stropts.h> définit la structure str_mlist, qui inclura au moins le membre suivant :

char  l_name[FMNAMESZ+1]  Un nom de module STREAMS.

L'en-tête <stropts.h> définit au moins les constantes symboliques suivantes pour être utilisées comme argument request de ioctl :

I_ATMARK
Le message du haut est-il ``marqué'' ?
I_CANPUT
Une bande est-elle écrivable ?
I_CKBAND
Vérifier si des messages existent dans une bande.
I_FDINSERT
Envoyer des informations définies par l'implémentation sur un autre STREAM.
I_FIND
Rechercher un module STREAMS.
I_FLUSH
Vider un STREAM.
I_FLUSHBAND
Vider une bande d'un STREAM.
I_GETBAND
Obtenir la bande du message du haut sur un STREAM.
I_GETCLTIME
Obtenir le délai de fermeture.
I_GETSIG
Récupérer les signaux de notification actuels.
I_GRDOPT
Obtenir le mode de lecture.
I_GWROPT
Obtenir le mode d'écriture.
I_LINK
Connecter deux STREAMs.
I_LIST
Obtenir tous les noms de modules sur un STREAM.
I_LOOK
Obtenir le nom du module du haut.
I_NREAD
Taille du message du haut.
I_PEEK
Observer le message du haut sur un STREAM.
I_PLINK
Connecter de manière persistante deux STREAMs.
I_POP
Dépiler un module STREAMS.
I_PUNLINK
Démonter une liaison STREAMS persistante.
I_PUSH
Empiler un module STREAMS.
I_RECVFD
Obtenir un descripteur de fichier envoyé via I_SENDFD.
I_SENDFD
Transmettre un descripteur de fichier via un tube STREAMS.
I_SETCLTIME
Définir le délai de fermeture.
I_SETSIG
Demander des signaux de notification.
I_SRDOPT
Définir le mode de lecture.
I_STR
Envoyer un ioctl() STREAMS.
I_SWROPT
Définir le mode d'écriture.
I_UNLINK
Déconnecter deux STREAMs.

L'en-tête <stropts.h> définit au moins la constante symbolique suivante pour utilisation avec I_LOOK :

FMNAMESZ
La taille minimale en octets du tampon référencé par l'argument arg.

L'en-tête <stropts.h> définit au moins les constantes symboliques suivantes pour utilisation avec I_FLUSH :

FLUSHR
Vider les files d'attente de lecture.
FLUSHRW
Vider les files d'attente de lecture et d'écriture.
FLUSHW
Vider les files d'attente d'écriture.

L'en-tête <stropts.h> définit au moins les constantes symboliques suivantes pour utilisation avec I_SETSIG :

S_BANDURG
Lorsqu'utilisé en conjonction avec S_RDBAND, SIGURG est généré au lieu de SIGPOLL lorsqu'un message de priorité atteint le début de la file d'attente de lecture de la tête de STREAM.
S_ERROR
Une notification d'une condition d'erreur atteint la tête de STREAM.
S_HANGUP
Une notification de déconnexion atteint la tête de STREAM.
S_HIPRI
Un message de haute priorité est présent dans la file d'attente de lecture de la tête de STREAM.
S_INPUT
Un message, autre qu'un message de haute priorité, est arrivé en tête de la file d'attente de lecture de la tête de STREAM.
S_MSG
Un message de signal STREAMS contenant le signal SIGPOLL atteint le début de la file d'attente de lecture de la tête de STREAM.
S_OUTPUT
La file d'attente d'écriture pour les données normales (bande de priorité 0) juste en dessous de la tête de STREAM n'est plus pleine. Ceci notifie au processus qu'il y a de la place dans la file pour envoyer (ou écrire) des données normales en aval.
S_RDBAND
Un message avec une bande de priorité non nulle est arrivé

S_RDNORM
Un message normal (bande de priorité définie sur 0) est arrivé en tête de la file d'attente de lecture d'un STREAM.
S_WRBAND
La file d'attente d'écriture pour une bande de priorité non nulle juste en dessous de la tête du STREAM n'est plus pleine.
S_WRNORM
Équivalent à S_OUTPUT.

L'en-tête <stropts.h> doit définir au moins la constante symbolique suivante pour une utilisation avec I_PEEK:

RS_HIPRI
Rechercher uniquement les messages de haute priorité.

L'en-tête <stropts.h> doit définir au moins les constantes symboliques suivantes pour une utilisation avec I_SRDOPT:

RMSGD
Mode de rejet de message.
RMSGN
Mode de non-rejet de message.
RNORM
Mode flux d'octets (Byte-STREAM), par défaut.
RPROTDAT
Livrer la partie contrôle d'un message en tant que données lorsqu'un processus appelle read().
RPROTDIS
Rejeter la partie contrôle d'un message, en livrant la partie données, lorsqu'un processus appelle read().
RPROTNORM
Échouer read() avec [EBADMSG] si un message contenant une partie contrôle se trouve en tête de la file d'attente de lecture du STREAM.

L'en-tête <stropts.h> doit définir au moins la constante symbolique suivante pour une utilisation avec I_SWOPT:

SNDZERO
Envoyer un message de longueur nulle vers l'aval lors d'une opération write() de 0 octet qui se produit.

L'en-tête <stropts.h> doit définir au moins les constantes symboliques suivantes pour une utilisation avec I_ATMARK:

ANYMARK
Vérifier si le message est marqué.
LASTMARK
Vérifier si le message est le dernier marqué dans la file d'attente.

L'en-tête <stropts.h> doit définir au moins la constante symbolique suivante pour une utilisation avec I_UNLINK:

MUXID_ALL
Délier tous les STREAMs liés au STREAM associé à fildes.

L'en-tête <stropts.h> doit définir les constantes symboliques suivantes pour getmsg(), getpmsg(), putmsg(), et putpmsg():

MORECTL
Plus d'informations de contrôle restent dans le message.
MOREDATA
Plus de données restent dans le message.
MSG_ANY
Recevoir n'importe quel message.
MSG_BAND
Recevoir un message de la bande spécifiée.
MSG_HIPRI
Envoyer/recevoir un message de haute priorité.

L'en-tête <stropts.h> peut rendre visibles tous les symboles de <unistd.h>.

L'en-tête <stropts.h> peut également définir des macros pour les types de messages en utilisant des noms commençant par M_.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme macros. Les prototypes de fonctions doivent être fournis.

int    fdetach(const char *);
int    getmsg(int, struct strbuf *restrict, struct strbuf *restrict,
           int *restrict);
int    getpmsg(int, struct strbuf *restrict, struct strbuf *restrict,
           int *restrict, int *restrict);
int    ioctl(int, int, ...);
int    isastream(int);
int    putmsg(int, const struct strbuf *, const struct strbuf *, int);
int    putpmsg(int, const struct strbuf *, const struct strbuf *, int,
           int);
