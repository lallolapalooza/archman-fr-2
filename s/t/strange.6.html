strange(6) Manuel XScreenSaver strange(6)

NOM

strange - dessine des attracteurs étranges

SYNTAXE

strange [--display hôte:écran] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id nombre][--mono] [--install] [--visual visuel] [--ncolors entier] [--delay microsecondes]

[--fps]

DESCRIPTION

Le programme strange dessine des attracteurs étranges

OPTIONS

strange accepte les options suivantes :

--window
Dessine dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id nombre
Dessine sur la fenêtre spécifiée.
--mono
S'il est sur un écran couleur, fait comme si c'était un écran monochrome.
--install
Installe une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--ncolors entier
Combien de couleurs utiliser (si possible). Par défaut 100. Les couleurs sont choisies aléatoirement.
--points entier
Change le nombre de points/itérations par image. Par défaut 5500. Plus de 6000 active l'accumulateur, ce qui rend certaines parties de l'image plus ou moins lumineuses selon la fréquence à laquelle l'attracteur touche chaque pixel.
--point-size entier
Change la taille des points individuels. Par défaut 1.
--zoom flottant
Zoom avant ou arrière. Par défaut 0.9.
--brightness flottant
Ajuste la luminosité pour le mode accumulateur. Par défaut 1.0.
--motion-blur flottant
Ajoute un flou de mouvement. Par défaut 3.0, 1.0 signifie pas de flou de mouvement.
--fps
Affiche le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1), xlock(1)
