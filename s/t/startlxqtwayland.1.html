STARTLXQTWAYLAND(1) Session Wayland LXQt STARTLXQTWAYLAND(1)

NOM

startlxqtwayland - script pour initialiser et lancer les sessions LXQt Wayland

SYNTAXE

startlxqtwayland

DESCRIPTION

startlxqtwayland est un script shell destiné à initialiser et lancer les sessions LXQt Wayland.

Ses tâches principales sont d'exporter les variables d'environnement, en partie après avoir effectué des vérifications correspondantes, et de lancer le compositeur configuré qui lancera lxqt-session, le gestionnaire de session LXQt. Il copie le(s) fichier(s) de configuration de base vers $XDG_CONFIG_USER pour le compositeur configuré dans lxqt-config-session s'ils ne sont pas présents et essaie de définir la disposition du clavier en conséquence à $LANG.

Il peut être exécuté directement depuis tty mais est plutôt appelé par des gestionnaires d'affichage comme SDDM ou LightDM.

Les gestionnaires d'affichage utilisent des scripts comme startlxqtwayland automatiquement. Les informations sur les environnements de bureau disponibles sont fournies par les fichiers $XDG_DATA_DIRS/wayland-sessions/*.desktop, typiquement /usr/share/wayland-sessions/*.desktop.

BOGUES


Les bogues peuvent être signalés sur https://github.com/lxqt/lxqt-wayland-session/issues.
