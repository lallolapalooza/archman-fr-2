Cette facette encapsule le code pour comparer des chaînes de manière localisée.

Le template collate utilise des fonctions virtuelles protégées pour fournir les résultats réels. Les accesseurs publics transmettent l'appel aux fonctions virtuelles. Ces fonctions virtuelles sont des crochets pour que les développeurs implémentent le comportement requis de la facette collate.

std::__cxx11::collate - Facet for character comparison and hashing.

Detailed Description

The class collate provides a base class for character comparison, hashing, and transformation.

The behavior of these functions is dependent on the locale being used.

The collate facet is part of the locale. It is used by certain standard library functions, such as string comparison functions.

template<typename _CharT> string_type std::__cxx11::collate< _CharT >::transform (const _CharT * __lo, const _CharT * __hi) const [inline]

Transform string to comparable form. This function is a wrapper for strxfrm functionality. It takes the input string and returns a modified string that can be directly compared to other transformed strings. In the C locale, this function just returns a copy of the input string. In some other locales, it may replace two chars with one, change a char for another, etc. It does so by returning collate::do_transform().
