Description Détaillée

template<typename _CharT, typename _InIter>

class std::time_get< _CharT, _InIter >"Modèle de classe principal time_get.

Ce facet encapsule le code pour analyser et retourner une date ou une heure à partir d'une chaîne. Il est utilisé par les opérateurs d'extraction numérique des flux.

Le modèle time_get utilise des fonctions virtuelles protégées pour fournir les résultats réels. Les accesseurs publics transmettent l'appel aux fonctions virtuelles. Ces fonctions virtuelles sont des points d'accroche pour les développeurs afin d'implémenter le comportement requis du facet time_get.

Description détaillée

La classe std::time_get est une facette de locale qui permet de convertir des chaînes de caractères en valeurs de temps en utilisant les conventions de locale. Elle fournit des méthodes pour analyser les chaînes de date, d'heure, de noms de mois et de jours de la semaine.
