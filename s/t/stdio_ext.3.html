stdio_ext(3) Manuel des fonctions de bibliothèque stdio_ext(3)

NOM

__fbufsize, __flbf, __fpending, __fpurge, __freadable, __freading, __fsetlocking, __fwritable, __fwriting, _flushlbf - interfaces avec la structure stdio FILE

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
#include <stdio_ext.h>
size_t __fbufsize(FILE *stream);
size_t __fpending(FILE *stream);
int __flbf(FILE *stream);
int __freadable(FILE *stream);
int __fwritable(FILE *stream);
int __freading(FILE *stream);
int __fwriting(FILE *stream);
int __fsetlocking(FILE *stream, int type);
void _flushlbf(void);
void __fpurge(FILE *stream);

DESCRIPTION

Solaris a introduit des routines pour permettre un accès portable aux internes de la structure FILE, et glibc a également implémenté ces routines.

La fonction __fbufsize() renvoie la taille du tampon actuellement utilisé par le flux donné.

La fonction __fpending() renvoie le nombre de caractères dans le tampon de sortie. Pour les flux orientés larges, l'unité est le caractère large. Cette fonction n'est pas définie pour les tampons en mode lecture, ou ouverts en lecture seule.

La fonction __flbf() renvoie une valeur non nulle si le flux est tamponné par ligne, et zéro sinon.

La fonction __freadable() renvoie une valeur non nulle si le flux autorise la lecture, et zéro sinon.

La fonction __fwritable() renvoie une valeur non nulle si le flux autorise l'écriture, et zéro sinon.

La fonction __freading() renvoie une valeur non nulle si le flux est en lecture seule, ou si la dernière opération sur le flux était une opération de lecture, et zéro sinon.

La fonction __fwriting() renvoie une valeur non nulle si le flux est en écriture seule (ou ajout seulement), ou si la dernière opération sur le flux était une opération d'écriture, et zéro sinon.

La fonction __fsetlocking() peut être utilisée pour sélectionner le type de verrouillage souhaité sur le flux. Elle renvoie le type actuel. L'argument type peut prendre les trois valeurs suivantes :

FSETLOCKING_INTERNAL
Effectue un verrouillage implicite autour de chaque opération sur le flux donné (à l'exception des fonctions *_unlocked). C'est le comportement par défaut.
FSETLOCKING_BYCALLER
L'appelant prendra en charge le verrouillage (éventuellement à l'aide de flockfile(3) s'il y a plus d'un thread), et les routines stdio ne feront pas de verrouillage jusqu'à ce que l'état soit réinitialisé à FSETLOCKING_INTERNAL.
FSETLOCKING_QUERY
Ne change pas le type de verrouillage. (Seulement le renvoie.)

La fonction _flushlbf() vide tous les flux tamponnés par ligne. (Probablement pour forcer la sortie vers un terminal, par exemple avant de lire une entrée clavier.)

La fonction __fpurge() écarte le contenu du tampon du flux.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).
