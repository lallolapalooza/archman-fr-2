sous-routine strsna (character job, character howmny, logical, dimension( * ) select, entier n, réel, dimension( ldt, * ) t, entier ldt, réel, dimension( ldvl, * ) vl, entier ldvl, réel, dimension( ldvr, * ) vr, entier ldvr, réel, dimension( * ) s, réel, dimension( * ) sep, entier mm, entier m, réel, dimension( ldwork, * ) work, entier ldwork, entier, dimension( * ) iwork, entier info)

STRSNA

Objectif :

!>
!> STRSNA estime les nombres de condition réciproques pour des valeurs
!> propres et/ou des vecteurs propres droits spécifiés d'une matrice réelle
!> quasi-triangulaire T (ou de toute matrice Q*T*Q**T avec Q orthogonale).
!>
!> T doit être sous forme canonique de Schur (tel que retourné par SHSEQR),
!> c'est-à-dire triangulaire par blocs avec des blocs diagonaux de taille 1x1
!> et 2x2 ; chaque bloc diagonal de 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonaux de signes opposés.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (SEP) :
!>          = 'E' : pour les valeurs propres uniquement (S) ;
!>          = 'V' : pour les vecteurs propres uniquement (SEP) ;
!>          = 'B' : pour les deux, valeurs propres et vecteurs propres (S et SEP).
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer les nombres de condition pour toutes les paires propres ;
!>          = 'S' : calculer les nombres de condition pour les paires propres sélectionnées
!>                 spécifiées par le tableau SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour lesquelles
!>          les nombres de condition sont requis. Pour sélectionner les nombres de condition
!>          correspondant à une valeur propre réelle w(j),
!>          SELECT(j) doit être mis à .TRUE.. Pour sélectionner les nombres de condition
!>          correspondant à une paire complexe conjuguée de valeurs propres w(j)
!>          et w(j+1), soit SELECT(j) soit SELECT(j+1), ou les deux, doivent être
!>          mis à .TRUE..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau REEL, dimension (LDT,N)
!>          La matrice T supérieure quasi-triangulaire, sous forme canonique de Schur.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau REEL, dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres gauches de T
!>          (ou de toute matrice Q*T*Q**T avec Q orthogonale), correspondant aux
!>          paires propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VL, tels que retournés par
!>          SHSEIN ou STREVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL.
!>          LDVL >= 1 ; et si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau REEL, dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres droits de T
!>          (ou de toute matrice Q*T*Q**T avec Q orthogonale), correspondant aux
!>          paires propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VR, tels que retournés par
!>          SHSEIN ou STREVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR.
!>          LDVR >= 1 ; et si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau REEL, dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments consécutifs du
!>          tableau. Pour une paire complexe conjuguée de valeurs propres, deux
!>          éléments consécutifs de S sont mis à la même valeur. Ainsi
!>          S(j), SEP(j), et les colonnes j de VL et VR correspondent tous
!>          à la même paire propre (mais pas en général à la j-ième paire propre,
!>          sauf si toutes les paires propres sont sélectionnées).
!>          Si JOB = 'V', S n'est pas référencé.
!>

SEP

!>          SEP est un tableau REEL, dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés des
!>          vecteurs propres sélectionnés, stockés dans des éléments consécutifs du
!>          tableau. Pour un vecteur propre complexe, deux
!>          éléments consécutifs de SEP sont mis à la même valeur. Si
!>          les valeurs propres ne peuvent pas être réordonnées pour calculer SEP(j), SEP(j)
!>          est mis à 0 ; cela ne peut se produire que lorsque la vraie valeur serait
!>          très petite de toute façon.
!>          Si JOB = 'E', SEP n'est pas référencé.
!>

MM

!>          MM est un ENTIER
!>          Le nombre d'éléments dans les tableaux S (si JOB = 'E' ou 'B')
!>           et/ou SEP (si JOB = 'V' ou 'B'). MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre d'éléments des tableaux S et/ou SEP réellement
!>          utilisés pour stocker les nombres de condition estimés.
!>          Si HOWMNY = 'A', M est mis à N.
!>

WORK

!>          WORK est un tableau REEL, dimension (LDWORK,N+6)
!>          Si JOB = 'E', WORK n'est pas référencé.
!>

LDWORK

!>          LDWORK est un ENTIER
!>          La dimension principale du tableau WORK.
!>          LDWORK >= 1 ; et si JOB = 'V' ou 'B', LDWORK >= N.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (2*(N-1))
!>          Si JOB = 'E', IWORK n'est pas référencé.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

!>
!> Le réciproque du nombre de condition d'une valeur propre lambda est
!> défini comme suit :
!>
!>          S(lambda) = |v**T*u| / (norm(u)*norm(v))
!>
!> où u et v sont les vecteurs propres droit et gauche de T correspondant
!> à lambda ; v**T désigne la transposée de v, et norm(u)
!> désigne la norme euclidienne. Ces nombres de condition réciproques varient
!> toujours entre zéro (très mal conditionné) et un (très bien
!> conditionné). Si n = 1, S(lambda) est défini comme étant 1.
!>
!> Une borne d'erreur approximative pour une valeur propre calculée W(i) est donnée par
!>
!>                      EPS * norm(T) / S(i)
!>
!> où EPS est la précision machine.
!>
!> Le réciproque du nombre de condition du vecteur propre droit u
!> correspondant à lambda est défini comme suit. Supposons que
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!> Alors le nombre de condition réciproque est
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )

strsna

SUBROUTINE STR SNA ( JOB, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, ABSTOL, RTOL, TOL, MAXR, MINR, DWORK, LWORK, IWORK, INFO )

strsna computes the norm of the separation between the i-th eigenvalue and the rest of the eigenvalues for the triangular matrix T.

The separation is defined as the smallest singular value of the matrix ( T(i:i, i:i) - mu_j(i) * I ), where mu_j(i) is the j-th eigenvalue of T and j is not equal to i.

The approximate error bound for a computed right eigenvector VR(i) is given by 

                      EPS * norm(T) / SEP(i)

Documentation de la fonction/sous-routine

strsna

SOUS-ROUTINE STR SNA ( JOB, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, ABSTOL, RTOL, TOL, MAXR, MINR, DWORK, LWORK, IWORK, INFO )

strsna calcule la norme de la séparation entre la i-ème valeur propre et le reste des valeurs propres pour la matrice triangulaire T.

La séparation est définie comme la plus petite valeur singulière de la matrice ( T(i:i, i:i) - mu_j(i) * I ), où mu_j(i) est la j-ème valeur propre de T et j est différent de i.

La borne d'erreur approximative pour un vecteur propre droit calculé VR(i) est donnée par 

                      EPS * norm(T) / SEP(i)
