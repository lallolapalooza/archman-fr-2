NOM

startfluxbox - démarrer une session fluxbox

SYNTAXE

startfluxbox

DESCRIPTION

startfluxbox est un script qui exécute le fichier ~/.fluxbox/startup S'il n'existe pas, il sera généré.

startfluxbox devrait être lancé depuis votre ~/.xinitrc si vous utilisez startx, ou ~/.xsession si vous utilisez un gestionnaire d'affichage, comme xdm.

FICHIERS

~/.fluxbox/startup

Ce fichier contient toutes les commandes qui devraient être exécutées avant le démarrage de fluxbox. Le fichier initial contient des commentaires utiles pour les débutants. Il démarre également fluxbox.

EXEMPLES

Le fichier ~/.fluxbox/startup par défaut est le suivant :

#!/bin/sh
#
# script de démarrage fluxbox:
#
# Les lignes commençant par '#' sont ignorées.
# Changez votre disposition de clavier :
xmodmap "$HOME/.Xmodmap"
# Applications que vous voulez lancer avec fluxbox.
# ASSUREZ-VOUS QUE LES APPLICATIONS QUI RESTENT ACTIVES SE TERMINENT PAR UN ''&''.
#
# unclutter -idle 2 &
# wmnd &
# wmsmixer -w &
# idesk &
# Et enfin, nous lançons fluxbox.
# Comme c'est la dernière application, vous devez la lancer avec ''exec'' avant elle.
exec fluxbox
# ou si vous voulez garder un journal :
# exec fluxbox -log "$fluxdir/log"

Si vous avez besoin de lancer des applications après fluxbox, vous pouvez modifier la ligne exec fluxbox ci-dessus pour quelque chose comme ceci :

exec fluxbox &
fbpid=$!
sleep 1
{
    xsetroot -cursor_name left_ptr -fg white -bg black &
    ipager &
    gkrellm2 &
} &
wait $fbpid

Ainsi, xsetroot, ipager et gkrellm2 seront tous lancés après fluxbox, après avoir laissé à fluxbox 1 seconde pour démarrer.

Pour plus de détails sur ce que vous pouvez faire d'autre dans ce script, consultez sh(1), ou la documentation de votre shell.
