DESCRIPTION Détaillée

Le type mutex récursif standard.

Un mutex récursif peut être verrouillé plus d'une fois par le même thread. Les autres threads ne peuvent pas verrouiller le mutex tant que le thread propriétaire ne l'a pas déverrouillé autant de fois qu'il a été verrouillé.
