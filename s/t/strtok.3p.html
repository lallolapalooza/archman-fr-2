STRTOK(3P) Manuel du programmeur POSIX STRTOK(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

strtok, strtok_r — diviser une chaîne en jetons

SYNTAXE

#include <string.h>
char *strtok(char *restrict s, const char *restrict sep);
char *strtok_r(char *restrict s, const char *restrict sep,
    char **restrict state);

DESCRIPTION

Pour strtok() : La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Une séquence d'appels à strtok() décompose la chaîne pointée par s en une séquence de jetons, chacun étant délimité par un octet de la chaîne pointée par sep. Le premier appel de la séquence a s comme premier argument, et est suivi d'appels avec un pointeur nul comme premier argument. La chaîne de séparateurs pointée par sep peut être différente d'un appel à l'autre.

Le premier appel de la séquence recherche dans la chaîne pointée par s le premier octet qui n'est pas contenu dans la chaîne de séparateurs actuelle pointée par sep. Si aucun octet de ce type n'est trouvé, alors il n'y a pas de jetons dans la chaîne pointée par s et strtok() doit renvoyer un pointeur nul. Si un tel octet est trouvé, il est le début du premier jeton.

La fonction strtok() recherche ensuite à partir de là un octet qui est contenu dans la chaîne de séparateurs actuelle. Si aucun octet de ce type n'est trouvé, le jeton actuel s'étend jusqu'à la fin de la chaîne pointée par s, et les recherches ultérieures d'un jeton doivent renvoyer un pointeur nul. Si un tel octet est trouvé, il est remplacé par un caractère NUL, qui termine le jeton actuel. La fonction strtok() enregistre un pointeur vers l'octet suivant, à partir duquel la prochaine recherche de jeton doit commencer.

Chaque appel ultérieur, avec un pointeur nul comme valeur du premier argument, commence la recherche à partir du pointeur enregistré et se comporte comme décrit ci-dessus.

L'implémentation doit se comporter comme si aucune fonction définie dans ce volume de POSIX.1‐2017 n'appelait strtok().

La fonction strtok() n'a pas besoin d'être thread-safe.

La fonction strtok_r() est équivalente à strtok(), sauf que strtok_r() est thread-safe et que l'argument state pointe vers un pointeur fourni par l'utilisateur qui permet à strtok_r() de maintenir l'état entre les appels qui analysent la même chaîne. L'application doit s'assurer que le pointeur pointé par state est unique pour chaque chaîne (s) traitée simultanément par des appels à strtok_r(). L'application n'a pas besoin d'initialiser le pointeur pointé par state à une valeur particulière. L'implémentation ne doit pas mettre à jour le pointeur pointé par state pour pointer (directement ou indirectement) vers des ressources, autres qu'à l'intérieur de la chaîne s, qui doivent être libérées par l'appelant.

VALEUR DE RETOUR

En cas de succès, strtok() doit renvoyer un pointeur vers le premier octet d'un jeton. Sinon, s'il n'y a pas de jeton, strtok() doit renvoyer un pointeur nul.

La fonction strtok_r() renvoie un pointeur vers le jeton trouvé, ou un pointeur nul lorsqu'aucun jeton n'est trouvé.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Recherche de séparateurs de mots

L'exemple suivant recherche des jetons séparés par des caractères d'espace.

#include <string.h>
...
char *token;
char line[] = "LINE TO BE SEPARATED";
char *search = " ";
/* Token pointera vers "LINE". */
token = strtok(line, search);
/* Token pointera vers "TO". */
token = strtok(NULL, search);

Trouver les deux premiers champs dans un tampon

L'exemple suivant utilise strtok() pour trouver deux chaînes de caractères (une clé et les données associées à cette clé) séparées par toute combinaison de caractères d'espace, de tabulation ou de nouvelle ligne au début du tableau de caractères pointé par buffer.

#include <string.h>
...
char    *buffer;
...
struct element {
    char *key;
    char *data;
} e;
...
// Charger le tampon...
...
// Obtenir la clé et ses données...
e.key = strtok(buffer, " \t\n");
e.data = strtok(NULL, " \t\n");
// Traiter le reste du contenu du tampon...
...

UTILISATION APPLICATIVE

Notez que si sep est une chaîne vide, strtok() et strtok_r() renvoient un pointeur vers le reste de la chaîne en cours de tokenisation.

La fonction strtok_r() est thread-safe et stocke son état dans un tampon fourni par l'utilisateur au lieu d'utiliser potentiellement une zone de données statique qui pourrait être écrasée par un appel non lié provenant d'un autre thread.

JUSTIFICATION

La fonction strtok() recherche une chaîne de séparateurs dans une chaîne plus grande. Elle renvoie un pointeur vers la dernière sous-chaîne entre les chaînes de séparateurs. Cette fonction utilise un stockage statique pour suivre la position actuelle de la chaîne entre les appels. La nouvelle fonction, strtok_r(), prend un argument supplémentaire, state, pour suivre la position actuelle dans la chaîne.
