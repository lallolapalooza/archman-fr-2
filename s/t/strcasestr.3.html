strstr(3) Manuel des fonctions de bibliothèque strstr(3)

NOM

strstr, strcasestr - localiser une sous-chaîne

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
char *strstr(const char *haystack, const char *needle);
#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <string.h>
char *strcasestr(const char *haystack, const char *needle);

DESCRIPTION

La fonction strstr() trouve la première occurrence de la sous-chaîne needle dans la chaîne haystack. Les octets de fin nuls ('\0') ne sont pas comparés.

La fonction strcasestr() est similaire à strstr(), mais ignore la casse des deux arguments.

VALEUR DE RETOUR

Ces fonctions retournent un pointeur vers le début de la sous-chaîne localisée, ou NULL si la sous-chaîne n'est pas trouvée.

Si needle est une chaîne vide, la valeur de retour est toujours haystack lui-même.
