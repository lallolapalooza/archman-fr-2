Formate et affiche une valeur monétaire. Cette fonction formate digits comme une valeur monétaire selon les facets moneypunct et ctype récupérées de io.getloc(), et écrit les caractères résultants dans __s. Par exemple, la chaîne 1001 dans une locale US écrirait $10.01 dans __s.

Cette fonction est un point d'accroche pour les classes dérivées afin de changer la valeur retournée.

std::money_put — Facet to format monetary values.

Description

This class is a locale facet, used to format monetary values.

The money_put facet is templated on the character type and the output iterator type.

The default constructor initializes the facet with a reference count of 0.

The do_put() virtual functions are responsible for the actual formatting and output of the monetary value.

Derived classes can override the do_put() functions to change the way monetary values are formatted.

Format and output a monetary value. This function formats digits as a monetary value according to moneypunct and ctype facets retrieved from io.getloc(), and writes the resulting characters to __s. For example, the string 1001 in a US locale would write $10.01 to __s.

This function is a hook for derived classes to change the value returned.
