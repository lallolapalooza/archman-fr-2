Documentation de la fonction/sous-programme

sous-programme strmv (character uplo, character trans, character diag, integer n, real, dimension(lda,*) a, integer lda, real, dimension(*) x, integer incx)

STRMV

Objectif :

!>
!> STRMV  effectue l'une des opérations matrice-vecteur suivantes :
!>
!>    x := A*x,   ou   x := A**T*x,
!>
!> où x est un vecteur de n éléments et A est une matrice triangulaire
!> unitaire ou non, supérieure ou inférieure, de taille n x n.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>           En entrée, UPLO spécifie si la matrice est supérieure ou
!>           inférieure, comme suit :
!>
!>              UPLO = 'U' ou 'u'   A est une matrice triangulaire supérieure.
!>
!>              UPLO = 'L' ou 'l'   A est une matrice triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>           En entrée, TRANS spécifie l'opération à effectuer comme suit :
!>
!>              TRANS = 'N' ou 'n'   x := A*x.
!>
!>              TRANS = 'T' ou 't'   x := A**T*x.
!>
!>              TRANS = 'C' ou 'c'   x := A**T*x.
!>

DIAG

!>          DIAG est CHARACTER*1
!>           En entrée, DIAG spécifie si A est unitaire ou non, comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée être triangulaire unitaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée être triangulaire
!>                                  unitaire.
!>

N

!>          N est INTEGER
!>           En entrée, N spécifie l'ordre de la matrice A.
!>           N doit être au moins zéro.
!>

A

!>          A est un tableau de REAL, dimension ( LDA, N )
!>           Avant l'entrée avec UPLO = 'U' ou 'u', la partie supérieure
!>           triangulaire de taille n x n du tableau A doit contenir la
!>           matrice triangulaire supérieure, et la partie strictement
!>           inférieure triangulaire de A n'est pas référencée.
!>           Avant l'entrée avec UPLO = 'L' ou 'l', la partie inférieure
!>           triangulaire de taille n x n du tableau A doit contenir la
!>           matrice triangulaire inférieure, et la partie strictement
!>           supérieure triangulaire de A n'est pas référencée.
!>           Notez que lorsque DIAG = 'U' ou 'u', les éléments diagonaux
!>           de A ne sont pas non plus référencés, mais sont supposés être
!>           l'unité.
!>

LDA

!>          LDA est INTEGER
!>           En entrée, LDA spécifie la première dimension de A telle que
!>           déclarée dans le programme appelant (sous-programme). LDA doit
!>           être au moins max( 1, n ).
!>

X

!>          X est un tableau de REAL, dimension au moins
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Avant l'entrée, le tableau incrémenté X doit contenir le vecteur
!>           x de n éléments. En sortie, X est écrasé par le vecteur
!>           transformé x.
!>

INCX

!>          INCX est INTEGER
!>           En entrée, INCX spécifie l'incrément pour les éléments de X.
!>           INCX ne doit pas être zéro.
!>
