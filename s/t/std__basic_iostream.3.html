Unformatted Input Functions


All the unformatted input functions have some common behavior. Each starts by constructing a temporary object of type std::basic_istream::sentry with the second argument (noskipws) set to true. This has several effects, concluding with the setting of a status flag; see the sentry documentation for more.

If the sentry status is good, the function tries to extract whatever data is appropriate for the type of the argument.

The number of characters extracted is stored for later retrieval by gcount().

If an exception is thrown during extraction, ios_base::badbit will be turned on in the stream's error state (without causing an ios_base::failure to be thrown) and the original exception will be rethrown if badbit is set in the exceptions mask.

    Description

    La classe std::basic_iostream est le modèle de classe de base pour les flux d'entrée et de sortie. Elle hérite à la fois de std::basic_istream et de std::basic_ostream. Un objet de ce type contient un objet de flux tampons (std::basic_streambuf) et gère les opérations d'E/S sur celui-ci.

    Les classes de flux de bibliothèque standard C++ sont organisées dans une hiérarchie de classes :

    std::ios_base
    Gère les informations indépendantes des caractères (indicateurs d'état, formatage, pointeurs de fonctions, etc.).
    std::basic_ios
    Gère un pointeur vers un objet std::basic_streambuf et des informations dépendantes des caractères (pointeurs de caractères, etc.).
    std::basic_istream
    Définit les opérations d'entrée à partir d'un flux.
    std::basic_ostream
    Définit les opérations de sortie vers un flux.
    std::basic_iostream
    Combine les opérations d'entrée et de sortie d'une classe de flux.

    Les spécialisations de modèle pour les types de caractères courants sont disponibles via des alias de type :

    std::iostream
    Un alias pour std::basic_iostream<char>.
    std::wiostream
    Un alias pour std::basic_iostream<wchar_t>.
