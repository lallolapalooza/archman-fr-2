Description détaillée

template<typename _Bi_iter, typename _Ch_type = typename iterator_traits<_Bi_iter>::value_type, typename _Rx_traits = regex_traits<_Ch_type>>

class std::regex_token_iterator< _Bi_iter, _Ch_type, _Rx_traits >"Itère sur les sous-correspondances dans une plage (ou divise une chaîne de texte).

Le but de cet itérateur est d'énumérer toutes les correspondances, ou toutes les correspondances spécifiées, d'une expression régulière dans une plage de texte. La valeur déréférencée d'un itérateur de cette classe est un objet std::sub_match.

Construit un regex_token_iterator...

Paramètres

__a [IN] Le début du texte à rechercher.
__b [IN] Un cran après la fin du texte à rechercher.
__re [IN] L'expression régulière à rechercher.
__submatch [IN] Quelle sous-correspondance retourner. Il y a des valeurs spéciales pour ce paramètre :
  • -1 chaque sous-expression énumérée ne correspond PAS à l'expression régulière (aka division par champs)
  • 0 la chaîne entière correspondant à la sous-expression est retournée pour chaque correspondance dans le texte.
  • >0 énumère uniquement la sous-expression indiquée d'une correspondance dans le texte.

__m [IN] Indicateurs de politique pour les règles de correspondance.
