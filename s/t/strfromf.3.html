strfromd(3) Manuel des fonctions de bibliothèque strfromd(3)

NOM

strfromd, strfromf, strfroml - convertir une valeur à virgule flottante en chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int strfromd(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, double fp);
int strfromf(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, float fp);
int strfroml(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, long double fp);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

strfromd(), strfromf(), strfroml() :

    __STDC_WANT_IEC_60559_BFP_EXT__

DESCRIPTION

Ces fonctions convertissent une valeur à virgule flottante, fp, en une chaîne de caractères, str, avec une chaîne de format configurable. Au plus n caractères sont stockés dans str.

L'octet nul de terminaison ('\0') est écrit si et seulement si n est suffisamment grand, sinon la chaîne écrite est tronquée à n caractères.

Les fonctions strfromd(), strfromf() et strfroml() sont équivalentes à


snprintf(str, n, format, fp);

sauf pour la chaîne de format.

Format de la chaîne de format

La chaîne de format doit commencer par le caractère '%'. Celui-ci est suivi d'une précision optionnelle qui commence par le caractère point (.), suivi d'un entier décimal optionnel. Si aucun entier n'est spécifié après le caractère point, une précision de zéro est utilisée. Enfin, la chaîne de format doit avoir l'un des spécificateurs de conversion a, A, e, E, f, F, g ou G.

Le spécificateur de conversion est appliqué en fonction du type à virgule flottante indiqué par le suffixe de la fonction. Par conséquent, contrairement à snprintf(), la chaîne de format n'a pas de caractère de modificateur de longueur. Voir snprintf(3) pour une description détaillée de ces spécificateurs de conversion.

L'implémentation est conforme à la norme C99 concernant la conversion des valeurs NaN et infinies :

Si fp est un NaN, +NaN ou -NaN, et que f (ou a, e, g) est le spécificateur de conversion, la conversion est en "nan", "nan", ou "-nan", respectivement. Si F (ou A, E, G) est le spécificateur de conversion, la conversion est en "NAN" ou "-NAN".

De même, si fp est infini, il est converti en [-]inf ou [-]INF.

Une chaîne de format mal formée entraîne un comportement indéfini.

VALEUR DE RETOUR

Les fonctions strfromd(), strfromf() et strfroml() renvoient le nombre de caractères qui auraient été écrits dans str si n avait été suffisamment grand, sans compter l'octet nul de terminaison. Ainsi, une valeur de retour de n ou plus signifie que la sortie a été tronquée.

NOTES

Ces fonctions tiennent compte de la catégorie LC_NUMERIC de la locale courante.

EXEMPLES

Pour convertir la valeur 12.1 en type float en une chaîne en utilisant la notation décimale, ce qui donne "12.100000" :


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%f", 12.1);

Pour convertir la valeur 12.3456 en type float en une chaîne en utilisant la notation décimale avec deux chiffres de précision, ce qui donne "12.35" :


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%.2f", 12.3456);

Pour convertir la valeur 12.345e19 en type double en une chaîne en utilisant la notation scientifique avec zéro chiffre de précision, ce qui donne "1E+20" :


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromd(s, ssize, "%.E", 12.345e19);

VOIR AUSSI
