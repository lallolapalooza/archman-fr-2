class std::basic_ios< _CharT, _Traits >"Classe modèle basic_ios, classe de base virtuelle pour toutes les classes de flux.

Paramètres du Modèle

_CharT Type du flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

template<typename _CharT, typename _Traits> basic_ios< _CharT, _Traits > & std::basic_ios< _CharT, _Traits >::copyfmt (const basic_ios< _CharT, _Traits > & __rhs)

Copie les champs de `__rhs` dans cet objet.

Paramètres

__rhs Les valeurs sources pour les copies.

Retourne

Une référence à cet objet.

Tous les champs de `__rhs` sont copiés dans cet objet, à l'exception de `rdbuf()` et `rdstate()` qui restent inchangés. Toutes les valeurs des tableaux `pword` et `iword` sont copiées. Avant la copie, chaque rappel est appelé avec `erase_event`. Après la copie, chaque (nouveau) rappel est appelé avec `copyfmt_event`. La dernière étape consiste à copier `exceptions()`.

Références basic_ios(), std::__addressof(), exceptions(), fill(), std::ios_base::flags(), std::ios_base::getloc(), std::ios_base::precision(), tie(), std::tie(), et std::ios_base::width().

template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline]

Lancer des exceptions en cas d'erreur.

Paramètres

__except Le nouveau masque d'exceptions.

Par défaut, les indicateurs d'erreur sont définis silencieusement. Vous pouvez définir un masque d'exceptions pour chaque flux ; si un bit dans le masque devient défini dans les indicateurs d'erreur, alors une exception de type `std::ios_base::failure` est lancée.

Si l'indicateur d'erreur est déjà défini lorsque le masque d'exceptions est ajouté, l'exception est immédiatement lancée. Essayez d'exécuter le code suivant sous GCC 3.1 ou une version ultérieure :

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

int std::ios_base::xalloc () [static], [hérité]

Accès aux indices uniques.

Retourne

Un entier différent de tous les appels précédents.

Cette fonction retourne un entier unique à chaque appel. Il peut être utilisé à n'importe quelle fin, mais est principalement destiné à être un indice unique pour les fonctions iword et pword. L'attente est qu'une application appelle xalloc afin d'obtenir un indice dans les tableaux iword et pword qui peut être utilisé sans crainte de conflit.

L'implémentation maintient une variable statique qui est incrémentée et retournée à chaque invocation. xalloc est garanti de retourner un indice sûr à utiliser dans les tableaux iword et pword.
