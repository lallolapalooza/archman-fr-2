Description détaillée

template<typename _Iterator>

class std::move_iterator< _Iterator >"Un adaptateur d'itérateur qui renvoie une référence rvalue.

La classe modèle move_iterator est un adaptateur d'itérateur avec le même comportement que l'itérateur sous-jacent, sauf que son opérateur de déréférencement convertit implicitement la valeur renvoyée par l'opérateur de déréférencement de l'itérateur sous-jacent en une référence rvalue. Certains algorithmes génériques peuvent être appelés avec des itérateurs de déplacement pour remplacer la copie par le déplacement.
