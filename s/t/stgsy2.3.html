sous-routine stgsy2 (caractère trans, entier ijob, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( ldd, * ) d, entier ldd, réel, dimension( lde, * ) e, entier lde, réel, dimension( ldf, * ) f, entier ldf, réel scale, réel rdsum, réel rdscal, entier, dimension( * ) iwork, entier pq, entier info)

STGSY2 résout l'équation de Sylvester généralisée (algorithme non-bloqué).

Objectif :

!>
!> STGSY2 résout l'équation de Sylvester généralisée :
!>
!>             A * R - L * B = scale * C                (1)
!>             D * R - L * E = scale * F,
!>
!> en utilisant les BLAS de niveau 1 et 2. Où R et L sont des matrices inconnues M par N,
!> (A, D), (B, E) et (C, F) sont des paires de matrices données de taille M par M,
!> N par N et M par N, respectivement, avec des entrées réelles. (A, D) et (B, E)
!> doivent être sous forme canonique quasi-généralisée de Schur, c'est-à-dire A, B sont quasi-triangulaires supérieures
!> et D, E sont triangulaires supérieures. La solution (R, L)
!> écrase (C, F). 0 <= SCALE <= 1 est un facteur de mise à l'échelle de sortie
!> choisi pour éviter le débordement.
!>
!> En notation matricielle, la résolution de l'équation (1) correspond à résoudre
!> Z*x = scale*b, où Z est définie comme
!>
!>        Z = [ kron(In, A)  -kron(B**T, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**T, Im) ],
!>
!> Ik est la matrice identité de taille k et X**T est la transposée de X.
!> kron(X, Y) est le produit de Kronecker entre les matrices X et Y.
!> Dans le processus de résolution de (1), nous résolvons un certain nombre de systèmes de ce type
!> où Dim(In), Dim(In) = 1 ou 2.
!>
!> Si TRANS = 'T', résoudre le système transposé Z**T*y = scale*b pour y,
!> ce qui équivaut à résoudre pour R et L dans
!>
!>             A**T * R  + D**T * L   = scale * C           (3)
!>             R  * B**T + L  * E**T  = scale * -F
!>
!> Ce cas est utilisé pour calculer une estimation de Dif[(A, D), (B, E)] =
!> sigma_min(Z) en utilisant la communication inverse avec SLACON.
!>
!> STGSY2 contribue également (IJOB >= 1) au calcul dans STGSYL
!> d'une borne supérieure de la séparation entre deux paires de matrices. Alors
!> les entrées (A, D), (B, E) sont des sous-pénins de la paire de matrices dans
!> STGSYL. Voir STGSYL pour les détails.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : résout l'équation de Sylvester généralisée (1).
!>          = 'T' : résout le système 'transposé' (3).
!>

IJOB

!>          IJOB est INTEGER
!>          Spécifie quel type de fonctionnalité doit être exécuté.
!>          = 0 : résout (1) seulement.
!>          = 1 : une contribution de ce sous-système à une estimation de la norme de Frobenius
!>               de la séparation entre deux paires de matrices
!>               est calculée. (la stratégie de prévisualisation est utilisée).
!>          = 2 : une contribution de ce sous-système à une estimation de la norme de Frobenius
!>               de la séparation entre deux paires de matrices
!>               est calculée. (SGECON sur les sous-systèmes est utilisé.)
!>          Non référencé si TRANS = 'T'.
!>

M

!>          M est INTEGER
!>          En entrée, M spécifie l'ordre de A et D, et la dimension en ligne
!>          de C, F, R et L.
!>

N

!>          N est INTEGER
!>          En entrée, N spécifie l'ordre de B et E, et la dimension en colonne
!>          de C, F, R et L.
!>

A

!>          A est un tableau de réels, dimension (LDA, M)
!>          En entrée, A contient une matrice quasi-triangulaire supérieure.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de la matrice A. LDA >= max(1, M).
!>

B

!>          B est un tableau de réels, dimension (LDB, N)
!>          En entrée, B contient une matrice quasi-triangulaire supérieure.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de la matrice B. LDB >= max(1, N).
!>

C

!>          C est un tableau de réels, dimension (LDC, N)
!>          En entrée, C contient le membre de droite de la première matrice
!>          de l'équation dans (1).
!>          En sortie, si IJOB = 0, C a été écrasé par la solution R.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale de la matrice C. LDC >= max(1, M).
!>

D

!>          D est un tableau de réels, dimension (LDD, M)
!>          En entrée, D contient une matrice triangulaire supérieure.
!>

LDD

!>          LDD est INTEGER
!>          La dimension principale de la matrice D. LDD >= max(1, M).
!>

E

!>          E est un tableau de réels, dimension (LDE, N)
!>          En entrée, E contient une matrice triangulaire supérieure.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale de la matrice E. LDE >= max(1, N).
!>

F

!>          F est un tableau de réels, dimension (LDF, N)
!>          En entrée, F contient le membre de droite de la deuxième matrice
!>          de l'équation dans (1).
!>          En sortie, si IJOB = 0, F a été écrasé par la solution L.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale de la matrice F. LDF >= max(1, M).
!>

SCALE

!>          SCALE est REAL
!>          En sortie, 0 <= SCALE <= 1. Si 0 < SCALE < 1, les solutions
!>          R et L (C et F en entrée) contiendront les solutions d'un
!>          système légèrement perturbé mais les matrices d'entrée A, B, D et
!>          E n'ont pas été modifiées. Si SCALE = 0, R et L contiendront les
!>          solutions du système homogène avec C = F = 0. Normalement,
!>          SCALE = 1.
!>

RDSUM

!>          RDSUM est REAL
!>          En entrée, la somme des carrés des contributions calculées à
!>          l'estimation de Dif en cours de calcul par STGSYL, où le
!>          facteur de mise à l'échelle RDSCAL (voir ci-dessous) a été extrait.
!>          En sortie, la somme des carrés correspondante mise à jour avec les
!>          contributions du sous-système actuel.
!>          Si TRANS = 'T', RDSUM n'est pas modifié.
!>          NOTE : RDSUM n'a de sens que lorsque STGSY2 est appelé par STGSYL.
!>

RDSCAL

!>          RDSCAL est REAL
!>          En entrée, le facteur de mise à l'échelle utilisé pour éviter le débordement dans RDSUM.
!>          En sortie, RDSCAL est mis à jour par rapport aux contributions actuelles
!>          dans RDSUM.
!>          Si TRANS = 'T', RDSCAL n'est pas modifié.
!>          NOTE : RDSCAL n'a de sens que lorsque STGSY2 est appelé par
!>                STGSYL.
!>

IWORK

!>          IWORK est un tableau d'entiers, dimension (M+N+2)
!>

PQ

!>          PQ est INTEGER
!>          En sortie, le nombre de sous-systèmes (de taille 2x2, 4x4 et
!>          8x8) résolus par cette routine.
!>

INFO

!>          INFO est INTEGER
!>          En sortie, si INFO est défini à
!>            =0 : Sortie réussie
!>            <0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>            >0 : Les paires de matrices (A, D) et (B, E) ont des valeurs propres communes ou très
!>                proches.
!>

NAME

stgsy2 — solve the generalized Sylvester equation

Function/Subroutine Documentation

Purpose:

STGSY2 solves the generalized Sylvester equation: 

        A X B - D X E = C

where A, B, D, E are upper quasi-triangular matrices and X, C are unknown matrices. With the option 3 TRANSR, the equation is 

        A^T X B^T - D^T X E^T = C

and with the option 4 TRANSR, the equation is 

        A^T X B - D^T X E = C

and with the option 1 TRANSR, the equation is 

        A X B^T - D X E^T = C

This is a numerically stable variant of the original algorithm of Björck and Hammarling, and it is a translation of the LAPACK routine ZTGSY2. It is assumed that.

Parameters:

IB
IB is INTEGER.

If IB = 1, the first row of C is ignored. If IB = 2, the first column of C is ignored. This option is used in the Schur decomposition based algorithm for solving the generalized eigenvalue problem.

CMAT
CMAT is REAL array, dimension (LDC, N).

The right hand side matrix C.

LDC
LDC is INTEGER.

The leading dimension of the array CMAT.

A
A is REAL array, dimension (LDA, N).

The N-by-N matrix A.

LDA
LDA is INTEGER.

The leading dimension of the array A.

B
B is REAL array, dimension (LDB, N).
LDB
LDB is INTEGER.

The leading dimension of the array B.

D
D is REAL array, dimension (LDD, N).

The N-by-N matrix D.

LDD
LDD is INTEGER.

The leading dimension of the array D.

E
E is REAL array, dimension (LDE, N).
LDE
LDE is INTEGER.

The leading dimension of the array E.

F
F is REAL array, dimension (LDF, N).

The N-by-N matrix F.

LDF
LDF is INTEGER.

The leading dimension of the array F.

X
X is REAL array, dimension (LDX, N).

The N-by-N solution matrix X.

LDX
LDX is INTEGER.

The leading dimension of the array X.

TRANSR
TRANSR is CHARACTER*1.

TRANSR = 'N': 

                A X B - D X E = C

TRANSR = 'T': 

                A^T X B^T - D^T X E^T = C

TRANSR = 'S': 

                A^T X B - D^T X E = C

TRANSR = 'L': 

                A X B^T - D X E^T = C

TRANSR = 'G': 

                A X B - D X E = C
SCALE
SCALE is REAL.

On exit, SCALE contains the scaling factor if scaling was needed to avoid overflow or underflow. Only the elements of CMAT corresponding to the first row or column of X are used. On exit, SCALE is set to 1.0.

INFO
INFO is INTEGER.

INFO = 0: successful exit INFO < 0: if INFO = -i, the i-th argument had an illegal value. INFO > 0: if INFO = i, the i-th diagonal block of A and D has zero frequency, and the problem is unsolvable. The algorithm will stop.
