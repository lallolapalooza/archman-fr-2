Description détaillée

template<class _Tp>

class std::valarray< _Tp >"Tableau intelligent conçu pour prendre en charge le traitement numérique.

Un valarray est un tableau qui fournit des contraintes destinées à permettre une optimisation efficace du traitement de tableaux numériques en réduisant le masquage qui peut résulter des représentations par pointeur. Il représente un tableau unidimensionnel à partir duquel différents sous-ensembles multidimensionnels peuvent être accédés et modifiés.

Paramètres du template

_Tp Type d'objet dans le tableau.
