FBB::String(3bobcat) Opérations sur les objets std::string FBB::String(3bobcat)

NOM

FBB::String - Plusieurs opérations sur les objets std::string

SYNOPSIS

#include <bobcat/string>
Option de liaison : -lbobcat

DESCRIPTION

Cette classe offre des facilités pour les transformations souvent utilisées sur les objets std::string, qui ne sont pas prises en charge par la classe std::string elle-même. Tous les membres de FBB::String sont statiques.

Initialement, cette classe était dérivée de std::string. Cependant, dériver de std::string est considéré comme une mauvaise conception car std::string n'a pas été conçu comme une classe de base.

FBB::String offre une série de fonctions membres statiques fournissant les facilités initialement implémentées en tant que membres non statiques. L'un de ces membres est le membre split (surchargé), qui divise une chaîne en éléments séparés par un ou plusieurs caractères configurables. Ces éléments peuvent contenir ou consister en des chaînes (sous-)chaînes délimitées par des guillemets doubles ou simples et des caractères d'échappement. Les caractères d'échappement sont convertis en leurs valeurs d'octet implicites (par exemple, \n est converti en la valeur d'octet 10) sauf s'ils sont intégrés dans des chaînes (sous-)chaînes délimitées par des apostrophes. Les guillemets entourant les chaînes (sous-)chaînes délimitées par des guillemets doubles et simples sont supprimés des éléments retournés par les membres split.

ENUMERATIONS

o
Type :
Cette énumération indique la nature du contenu d'un élément dans le tableau retourné par les membres split surchargés (voir ci-dessous).
DQUOTE, un sous-ensemble des caractères de l'élément string correspondant a été délimité par des guillemets doubles dans la chaîne analysée par les membres split.
DQUOTE_UNTERMINATED, le contenu de la chaîne analysée par les membres split a commencé à un moment donné par un guillemet double, mais le guillemet double de fin correspondant était manquant.
ESCAPED_END, le contenu de la chaîne analysée par les membres split se terminait par une simple barre oblique inverse.
NORMAL, une chaîne normale ;
SEPARATOR, un séparateur ;
SQUOTE, un sous-ensemble des caractères de l'élément string correspondant a été délimité par des apostrophes dans la chaîne analysée par les membres split.
SQUOTE_UNTERMINATED, le contenu de la chaîne analysée par les membres split a commencé à un moment donné par une apostrophe, mais l'apostrophe de fin correspondante était manquante.
o
SplitType :
Cette énumération est utilisée pour spécifier comment les membres split doivent diviser les informations dans les objets chaîne qui leur sont passés :
TOK : le membre split agit comme la fonction C standard strtok(3). L'essence ici est qu'aucun élément vide n'est retourné. Par exemple, une chaîne contenant "a,," qui est traitée en mode TOK retourne un élément NORMAL contenant "a".
TOKSEP : le membre split agit comme la fonction C standard strtok(3), retournant également des informations sur les séparateurs rencontrés. Comme strtok ne retourne pas d'éléments vides, TOKSEP utilise des éléments vides pour indiquer l'occurrence de séparateurs. Par exemple, une chaîne contenant "a,," qui est traitée en mode TOKSEP retourne un élément NORMAL contenant "a", suivi de deux éléments SEPARATOR vides.
STR : le membre split agit comme la fonction C standard strstr(3). L'essence ici est que des éléments vides sont également retournés. Par exemple, une chaîne contenant "a,," qui est traitée en mode STR retourne un élément contenant "a", suivi de deux éléments NORMAL vides.
STRSEP : le membre split agit comme la fonction C standard strstr(3), retournant également des informations sur les séparateurs rencontrés. Par exemple, une chaîne contenant "a,," qui est traitée en mode STRSEP retourne un élément NORMAL contenant "a", suivi d'un élément SEPARATOR contenant ",", suivi d'un élément NORMAL vide, suivi d'un élément SEPARATOR contenant ",", et enfin suivi d'un élément NORMAL vide,

TYPE IMBRIQUÉ

La structure SplitPair définit un std::pair<std::string, String::Type> et est utilisée par certains membres split surchargés (voir ci-dessous).

std::string unescape(std::string const &str):
Retourne une copie de str dans laquelle les caractères échappés (c'est-à-dire précédés d'un antislash) ont été interprétés. Tous les caractères d'échappement standard (\a, \b, \f, \n, \r, \t, \v) sont reconnus. Si un caractère d'échappement est suivi de x, au plus les deux caractères suivants sont interprétés comme un nombre hexadécimal. Si un caractère d'échappement est suivi d'un chiffre octal, alors au plus les trois caractères suivants l'antislash sont interprétés comme un nombre octal. Dans tous les autres cas, l'antislash est supprimé et le caractère qui le suit est conservé.
o
std::string urlDecode(std::string const &str):
Les spécifications URL utilisent le codage %xx pour encoder les caractères, à l'exception des caractères alphanumériques et des caractères - _ . et ~, qui sont conservés tels quels. Les autres caractères sont codés par un caractère %, suivi de deux caractères hexadécimaux représentant la valeur de l'octet de ces caractères. Par exemple, un espace est codé sous forme de %20, un caractère plus est codé sous forme de %2B. Le membre urlDecode retourne une std::string contenant les caractères décodés de la chaîne encodée en URL qui est passée en argument à ce membre.
o
std::string urlEncode(std::string const &str):
Voir le membre urlDecode : urlEncode retourne une std::string contenant les caractères encodés en URL des caractères de la chaîne passée en argument à ce membre.

EXEMPLE

#include <iostream>
#include <vector>
#include <bobcat/string>
using namespace std;
using namespace FBB;
static char const *type[] =
{
    "DQUOTE_UNTERMINATED",
    "SQUOTE_UNTERMINATED",
    "ESCAPED_END",
    "SEPARATOR",
    "NORMAL",
    "DQUOTE",
    "SQUOTE",
};
int main(int argc, char **argv)
{
    cout << "Nom du programme en majuscules : " << String::uc(argv[0]) << "\n\n";
    vector<String::SplitPair> splitpair;
    string text{ "one, two, ’thr\\x65\\145’" };
    string encoded{ String::urlEncode(text) };
    cout << "La cha\xee\x6e\x65 `" << text << "’\n"
            "   en cha\xee\x6e\x65 encod\x65\x65 en URL : `" << encoded << "’\n"
            "   et la cha\xee\x6e\x65 pr\x65c\x65d\x65nte d\x65cod\x65\x65e en URL : " <<
                                    String::urlDecode(encoded) << "\n"
            "\n"
            "Divisant `" << text << "’ en " <<
                    String::split(&splitpair, text, String::STRSEP, ", ") <<
                " champs\n";
    for (auto it = splitpair.begin(); it != splitpair.end(); ++it)
        cout << (it - splitpair.begin() + 1) << ": " <<
                type[it->second] << ": `" << it->first <<
                "’, non \x65chapp\x65 : `" << String::unescape(it->first) <<
                "’\n";
    cout << ’\n’ <<
        text << ":\n"
        "   majuscules : " << String::uc(text) << ",\n"
        "   minuscules : " << String::lc(text) << ’\n’;
}
/*
    Appel du programme comme
        driver’
    produit la sortie suivante :
        Nom du programme en majuscules : DRIVER
        Divisant `one, two, ’thr\x65\145’’ en 9 champs
        1: NORMAL: `one’, non échappé : `one’
        2: SEPARATOR: `,’, non échappé : `,’
        3: NORMAL: `’, non échappé : `’
        4: SEPARATOR: ` ’, non échappé : ` ’
        5: NORMAL: `two’, non échappé : `two’
        6: SEPARATOR: `,’, non échappé : `,’
        7: NORMAL: `’, non échappé : `’
        8: SEPARATOR: ` ’, non échappé : ` ’
        9: SQUOTE: `thr\x65\145’, non échappé : `three’
        one, two, ’thr\x65\145’:
           majuscules : ONE, TWO, ’THR\X65\145’,
           minuscules : one, two, ’thr\x65\145’
*/
