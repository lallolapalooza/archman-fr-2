NOM

start - Exemple de script de démarrage OTP pour Unix

DESCRIPTION

Le script start est un exemple de script pour démarrer le système Erlang en mode embarqué sous Unix.

Pour plus d'informations sur son utilisation, consultez le guide de l'utilisateur des systèmes embarqués dans la Documentation système.

start [ fichier_de_donnees ]

Argument :

fichier_de_donnees

Facultatif. Spécifie quel fichier start_erl.data utiliser.

La variable d'environnement RELDIR peut être définie avant d'appeler cet exemple, ce qui définit le répertoire où trouver les fichiers de release.

Voir aussi

run_erl(1), start_erl(1)
