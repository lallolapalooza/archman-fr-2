stream(1) Manuel des commandes générales stream(1)

NOM

stream - un outil léger pour diffuser un ou plusieurs composants pixel de l'image ou une partie de l'image dans le format de stockage de votre choix.

SYNOPHIS

magick stream [options] fichier-entrée fichier-sortie

APERÇU

Stream est un outil léger pour diffuser un ou plusieurs composants pixel de l'image ou une partie de l'image dans le format de stockage de votre choix. Il écrit les composants pixel au fur et à mesure de leur lecture depuis l'image d'entrée, ligne par ligne, rendant stream souhaitable lors du travail avec de grandes images ou lorsque vous avez besoin de composants pixel bruts.

Pour plus d'informations sur la commande stream, ouvrez votre navigateur à l'adresse file:///usr/share/doc/ImageMagick-7/www/stream.html ou https://imagemagick.org/script/stream.php.

DESCRIPTION

Paramètres de l'image :
-authenticate valeur déchiffre l'image avec ce mot de passe
-colorspace type espace colorimétrique alternatif de l'image
-compress type type de compression pixel lors de l'écriture de l'image
-define format:option
définit une ou plusieurs options de format d'image
-density géométrie densité horizontale et verticale de l'image
-depth valeur profondeur de l'image
-extract géométrie extrait une zone de l'image
-identify identifie le format et les caractéristiques de l'image
-interlace type type de schéma d'entrelacement de l'image
-interpolate méthode méthode d'interpolation des couleurs pixel
-limit type valeur limite de ressources du cache pixel
-map composants un ou plusieurs composants pixel
-monitor surveille la progression
-quantize colorspace réduit les couleurs dans cet espace colorimétrique
-quiet supprime tous les messages d'avertissement
-regard-warnings prête attention aux messages d'avertissement
-respect-parentheses les paramètres restent actifs jusqu'à la frontière de la parenthèse
-sampling-factor géométrie
facteur d'échantillonnage horizontal et vertical
-seed valeur initialise une nouvelle séquence de nombres pseudo-aléatoires
-set attribut valeur définit un attribut d'image
-size géométrie largeur et hauteur de l'image
-storage-type type type de stockage pixel
-synchronize synchronise l'image avec le périphérique de stockage
-taint déclare l'image comme modifiée
-transparent-color couleur
couleur transparente
-verbose imprime des informations détaillées sur l'image
-virtual-pixel méthode
méthode d'accès aux pixels virtuels

Options diverses :
-channel masque définit le masque de canal de l'image
-debug events affiche des informations de débogage abondantes
-help imprime les options du programme
-log format format des informations de débogage
-list type imprime une liste des arguments d'option pris en charge
-version imprime les informations de version

Par défaut, le format de l'image `fichier' est déterminé par son numéro magique. Pour spécifier un format d'image particulier, faites précéder le nom de fichier d'un nom de format d'image et d'un deux-points (c'est-à-dire ps:image) ou spécifiez le type d'image comme suffixe du nom de fichier (c'est-à-dire image.ps). Spécifiez `fichier' comme '-' pour l'entrée ou la sortie standard.
