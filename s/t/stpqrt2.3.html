Documentation de la fonction/sous-programme

sous-programme stpqrt2 (integer m, integer n, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldt, * ) t, integer ldt, integer info)

STPQRT2 calcule une factorisation QR d'une matrice réelle ou complexe ``triangulaire-pentagonale'', qui est composée d'un bloc triangulaire et d'un bloc pentagonal, en utilisant la représentation WY compacte pour Q.

Objectif :

!>
!> STPQRT2 calcule une factorisation QR d'une matrice réelle 
!> C, composée d'un bloc triangulaire A et d'un bloc pentagonal B,
!> en utilisant la représentation WY compacte pour Q.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre total de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice B, et l'ordre de
!>          la matrice triangulaire A.
!>          N >= 0.
!>

L

!>          L est INTEGER
!>          Le nombre de lignes de la partie trapézoïdale supérieure de B.
!>          MIN(M,N) >= L >= 0.  Voir Détails supplémentaires.
!>

A

!>          A est tableau REAL, dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire supérieure N par N, A.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice triangulaire supérieure R.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est tableau REAL, dimension (LDB,N)
!>          À l'entrée, la matrice pentagonale M par N, B. Les M-L premières lignes
!>          sont rectangulaires, et les L dernières lignes sont trapézoïdales supérieures.
!>          À la sortie, B contient la matrice pentagonale V.  Voir Détails supplémentaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

T

!>          T est tableau REAL, dimension (LDT,N)
!>          Le facteur triangulaire supérieur N par N, T, du réflecteur de bloc.
!>          Voir Détails supplémentaires.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= max(1,N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> La matrice d'entrée C est une matrice (N+M)-par-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!> où A est une matrice triangulaire supérieure N par N, et B est une matrice
!> pentagonale M par N composée d'une matrice rectangulaire (M-L)-par-N, B1, au-dessus
!> d'une matrice trapézoïdale supérieure L par N, B2 :
!>
!>               B = [ B1 ]  <- (M-L)-par-N rectangulaire
!>                   [ B2 ]  <-     L-par-N trapézoïdale supérieure.
!>
!> La matrice trapézoïdale supérieure B2 est composée des L premières lignes d'une
!> matrice triangulaire supérieure N par N, où 0 <= L <= MIN(M,N). Si L=0,
!> B est rectangulaire M par N ; si M=L=N, B est triangulaire supérieure.
!>
!> La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!> en dessous de la diagonale (de A) dans la matrice d'entrée C de taille (N+M)-par-N
!>
!>               C = [ A ]  <- triangulaire supérieure N par N
!>                   [ B ]  <- pentagonale M par N
!>
!> de sorte que W peut être représentée comme
!>
!>               W = [ I ]  <- identité, N par N
!>                   [ V ]  <- M par N, même forme que B.
!>
!> Ainsi, toutes les informations nécessaires pour W sont contenues en sortie dans B,
!> que nous appelons V ci-dessus. Notez que V a la même forme que B ; c'est-à-dire,
!>
!>               V = [ V1 ] <- (M-L)-par-N rectangulaire
!>                   [ V2 ] <-     L-par-N trapézoïdale supérieure.
!>
!> Les colonnes de V représentent les vecteurs qui définissent les H(i).
!> Le réflecteur de bloc H de taille (M+N)-par-(M+N) est alors donné par
!>
!>               H = I - W * T * W^H
!>
!> où W^H est la transposée conjuguée de W et T est le facteur triangulaire supérieur
!> du réflecteur de bloc.
!>
