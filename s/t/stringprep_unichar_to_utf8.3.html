NOM

stringprep_unichar_to_utf8 - fonction API

SYNTAXE

#include <stringprep.h>

int stringprep_unichar_to_utf8(uint32_t c, char * outbuf);

ARGUMENTS

uint32_t c
un code de caractère ISO10646
char * outbuf
tampon de sortie, doit disposer d'au moins 6 octets d'espace. Si NULL, la longueur sera calculée et retournée et rien ne sera écrit dans outbuf.

DESCRIPTION

Convertit un seul caractère en UTF-8.

Valeur de retour : nombre d'octets écrits.
