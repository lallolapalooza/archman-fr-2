Description détaillée

Classe de base pour les fonctionnalités de localisation.

La classe facet est la classe de base pour une fonctionnalité de localisation, telle que l'impression de monnaies, d'heures et de nombres. Elle fournit un support commun pour les facets et la gestion des références.

Les facets ne peuvent être ni copiés ni assignés.
