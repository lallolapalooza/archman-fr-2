Detailed Description

Classe de base abstraite pour les façades de catégorie de caractères.

La classe std::ctype est une façade de catégorie de caractères. Elle fournit des méthodes pour classifier les caractères et pour les convertir en majuscules/minuscules.

Cette classe de base abstraite __ctype_abstract_base est utilisée en interne par la bibliothèque C++ standard pour définir l'interface commune des différentes implémentations de std::ctype.

Member Typedef Documentation

Aucune typedef documentée pour cette classe.

Member Function Documentation

Les méthodes spécifiques à std::ctype sont définies dans les classes dérivées et ne sont pas directement documentées ici.

Exemples de méthodes courantes (héritées ou à implémenter) :

  • classic() : Retourne un pointeur vers l'objet ctype classique.
  • do_is(mask, c) : Teste si le caractère c appartient à la catégorie mask.
  • do_scan_is(mask, first, last) : Trouve le premier caractère dans la plage [first, last) qui appartient à la catégorie mask.
  • do_scan_not(mask, first, last) : Trouve le premier caractère dans la plage [first, last) qui n'appartient pas à la catégorie mask.

  • do_tolower(c) : Convertit le caractère c en minuscule.

  • do_w_tolower(c) : Convertit le caractère large c en minuscule.
