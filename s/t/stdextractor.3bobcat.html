FBB::StdExtractor(3bobcat) Exécution de processus enfants FBB::StdExtractor(3bobcat)

NOM

FBB::StdExtractor - Lance des programmes externes écrivant sur la sortie d'erreur standard

SYNTAXE

#include <bobcat/cerrextractor>
Option de liaison : -lbobcat

DESCRIPTION

La classe FBB::StdExtractor offre une interface basique pour appeler des programmes externes (appelés processus enfants) écrivant sur leurs flux de sortie standard et de sortie d'erreur. Le flux d'entrée standard des processus enfants n'est par défaut pas géré par les objets StdExtractor. Les flux de sortie standard et de sortie d'erreur de l'enfant sont lus via l'objet StdExtractor : les informations écrites par le processus enfant sur ces flux sont extraites ou lues depuis l'objet StdExtractor. La variable d'environnement PATH n'est pas utilisée lors de l'appel des processus enfants : les programmes des processus enfants doivent être spécifiés en utilisant des chemins.

Les objets StdExtractor peuvent être utilisés de manière répétée pour exécuter les mêmes processus enfants ou différents.

Les arguments passés aux processus enfants peuvent être entourés de guillemets doubles ou simples. Les arguments entourés de guillemets doubles ont leurs guillemets retirés, tout en interprétant les séquences d'échappement qui auraient pu être utilisées à l'intérieur. Les arguments entourés de guillemets simples ont leurs guillemets retirés, tout en acceptant leur contenu tel quel. De plus, des séquences d'échappement non entourées peuvent être spécifiées : ces séquences d'échappement sont évaluées et remplacées par leurs caractères prévus (par exemple, \100 est converti en @).

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HÉRITE DE

FBB::Exec (privé), FBB::IFdBuf (privé), std::istream

CONSTRUCTEUR

o
StdExtractor(size_t bufSize = 100):
Un argument bufSize peut être spécifié : il définit la taille du tampon interne utilisé par le streambuf de StdExtractor. Par défaut, le flux d'entrée standard n'est pas géré.
o
CoutExtractor(Mode mode, size_t bufSize = 100):
L'argument mode doit être StdExtractor::CLOSE_STD. Il indique que le flux d'entrée standard est redirigé vers /dev/null : les processus enfants ne peuvent pas lire leur flux d'entrée standard. Un argument bufSize peut être spécifié : il définit la taille du tampon interne utilisé par le streambuf de CinInserter.

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

MEMBRES

o
void execute(std::string const &cmd):
L'argument spécifie la commande à exécuter : la commande elle-même doit être spécifiée comme un chemin (la variable d'environnement PATH n'est pas utilisée). Ce membre retourne immédiatement, après quoi les informations écrites par le processus enfant sur ses flux de sortie standard et de sortie d'erreur peuvent être extraites de l'objet StdExtractor.
Une fois que execute est retourné, il peut être appelé à nouveau, soit en utilisant la même commande, soit une autre.
Les arguments passés au programme à exécuter en tant que processus enfant peuvent éventuellement être spécifiés en utilisant des guillemets simples ou doubles, comme décrit dans la section DESCRIPTION de cette page de manuel.
o
int ret() const:
Une fois que execute est retourné, ce membre fournit le code de sortie réel du processus enfant. Sa valeur est égale à -1 avant le premier appel à execute.

MEMBRE PROTÉGÉ

o
Pipe &childOutPipe():
Si les classes dérivées ont besoin de substituer les membres de redirection, elles auront probablement besoin d'accéder au tube écrit par le processus enfant. Ce membre fournit une référence à ce tube. Par défaut, le processus parent lit les informations depuis le tube, tandis que le processus enfant insère sa sortie d'erreur standard dans le tube.

EXEMPLE

#include <iostream>
#include <bobcat/cerrextractor>
using namespace std;
using namespace FBB;
int main()
{
    CerrExtractor extractor;
    extractor.execute("/bin/cat driver.cc");
    cout << extractor.rdbuf();
    cerr << "Returning: " << extractor.ret() << "\n"
            "again:\n";
    extractor.execute("/bin/cat driver.cc");
    cout << extractor.rdbuf();
    cerr << "Returning: " << extractor.ret() << ’\n’;
}

# Créer un objet StdExtractor pour exécuter la commande "ls -l"
