NOM

stringprep_4i - Fonction d'API

SYNTAXE

#include <stringprep.h>

int stringprep_4i(uint32_t * ucs4, size_t * len, size_t maxucs4len, Stringprep_profile_flags flags, const Stringprep_profile * profile);

ARGUMENTS

uint32_t * ucs4
tableau d'entrée/sortie avec la chaîne à préparer.
size_t * len
en entrée, longueur du tableau d'entrée avec les points de code Unicode, en sortie, longueur du tableau de sortie avec les points de code Unicode.
size_t maxucs4len
longueur maximale du tableau d'entrée/sortie.
Stringprep_profile_flags flags
une valeur de Stringprep_profile_flags, ou 0.
const Stringprep_profile * profile
pointeur vers le Stringprep_profile à utiliser.

DESCRIPTION

Prépare la chaîne UCS-4 d'entrée selon le profil stringprep, et écrit le résultat dans la chaîne d'entrée.

L'entrée n'est pas obligatoirement terminée par un zéro ( ucs4 [ len ] = 0). La sortie ne sera pas terminée par un zéro sauf si ucs4 [ len ] = 0. Voir plutôt stringprep_4zi() si votre entrée est terminée par un zéro ou si vous voulez que la sortie le soit.

Comme l'opération stringprep peut agrandir la chaîne, maxucs4len indique la taille du tampon contenant la chaîne. Cette fonction ne lira ni n'écrira dans des points de code en dehors de cette taille.

Les flags sont l'une des valeurs de Stringprep_profile_flags, ou 0.

Le profile contient les instructions Stringprep_profile à effectuer. Votre application peut définir de nouveaux profils, en réutilisant éventuellement les tables stringprep génériques qui feront toujours partie de la bibliothèque, ou utiliser l'un des profils actuellement pris en charge.

Valeur de retour : Retourne STRINGPREP_OK si succès, ou un code d'erreur Stringprep_rc.
