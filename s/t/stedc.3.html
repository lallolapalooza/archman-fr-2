CSTEDC

Objectif :

!>
!> CSTEDC calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique en utilisant la méthode diviser pour régner.
!> Les vecteurs propres d'une matrice hermitienne complète ou bande peuvent également
!> être trouvés si CHETRD ou CHPTRD ou CHBTRD a été utilisé pour réduire cette
!> matrice sous forme tridiagonale.
!>
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres.
!>          = 'I' : Calculer également les vecteurs propres de la matrice tridiagonale.
!>          = 'V' : Calculer également les vecteurs propres de la matrice hermitienne originale.
!>                  À l'entrée, Z contient la matrice unitaire utilisée pour réduire
!>                  la matrice originale sous forme tridiagonale.
!>

N

!>          N est INTEGER
!>          La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>          À l'entrée, les éléments sous-diagonaux de la matrice tridiagonale.
!>          À la sortie, E est détruit.
!>

Z

!>          Z est un tableau COMPLEX, dimension (LDZ,N)
!>          À l'entrée, si COMPZ = 'V', alors Z contient la matrice unitaire
!>          utilisée dans la réduction à la forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormés de la matrice hermitienne originale,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormés
!>          de la matrice tridiagonale symétrique.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si des vecteurs propres sont désirés, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si COMPZ = 'N' ou 'I', ou N <= 1, LWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LWORK doit être au moins N*N.
!>          Notez que pour COMPZ = 'V', si N est inférieur ou égal à
!>          la taille minimale de division, généralement 25, alors LWORK
!>          a seulement besoin d'être 1.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (MAX(1,LRWORK))
!>          À la sortie, si INFO = 0, RWORK(1) contient le LRWORK optimal.
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.
!>          Si COMPZ = 'N' ou N <= 1, LRWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LRWORK doit être au moins
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         où lg( N ) = plus petit entier k tel que
!>                         2**k >= N.
!>          Si COMPZ = 'I' et N > 1, LRWORK doit être au moins
!>                         1 + 4*N + 2*N**2 .
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou égal
!>          à la taille minimale de division, généralement 25, alors LRWORK
!>          a seulement besoin d'être max(1,2*(N-1)).
!>
!>          Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si COMPZ = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si COMPZ = 'V' ou N > 1,  LIWORK doit être au moins
!>                                    6 + 6*N + 5*N*lg N.
!>          Si COMPZ = 'I' ou N > 1,  LIWORK doit être au moins
!>                                    3 + 5*N .
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou égal
!>          à la taille minimale de division, généralement 25, alors LIWORK
!>          a seulement besoin d'être 1.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les tailles optimales des tableaux WORK, RWORK et
!>          IWORK, renvoie ces valeurs comme premières entrées
!>          des tableaux WORK, RWORK et IWORK, et aucun message d'erreur
!>          lié à LWORK ou LRWORK ou LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : L'algorithme n'a pas réussi à calculer une valeur propre lors
!>                de l'opération sur la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) jusqu'à mod(INFO,N+1).
!>

DSTEDC

Objectif :

!>
!> DSTEDC calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique en utilisant la méthode diviser pour régner.
!> Les vecteurs propres d'une matrice hermitienne complète ou bande peuvent également
!> être trouvés si DHERTRD ou DHETRD ou DHBTRD a été utilisé pour réduire cette
!> matrice sous forme tridiagonale.
!>
!>

Calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une matrice symétrique tridiagonale à l'aide de la méthode diviser pour régner. Les vecteurs propres d'une matrice symétrique réelle pleine ou bande peuvent également être trouvés si DSYTRD ou DSPTRD ou DSBTRD a été utilisé pour réduire cette matrice à la forme tridiagonale.

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N': Calculer uniquement les valeurs propres.
!>          = 'I': Calculer également les vecteurs propres de la matrice tridiagonale.
!>          = 'V': Calculer également les vecteurs propres de la matrice symétrique d'origine.
!>                 À l'entrée, Z contient la matrice orthogonale utilisée pour réduire la matrice d'origine à la forme tridiagonale.
!>

N

!>          N est INTEGER
!>          La dimension de la matrice symétrique tridiagonale. N >= 0.
!>

D

!>          D est un tableau de DOUBLE PRECISION, de dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres par ordre croissant.
!>

E

!>          E est un tableau de DOUBLE PRECISION, de dimension (N-1)
!>          À l'entrée, les éléments sous-diagonaux de la matrice tridiagonale.
!>          À la sortie, E a été détruit.
!>

Z

!>          Z est un tableau de DOUBLE PRECISION, de dimension (LDZ,N)
!>          À l'entrée, si COMPZ = 'V', Z contient la matrice orthogonale utilisée dans la réduction à la forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les vecteurs propres orthonormés de la matrice symétrique d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormés de la matrice symétrique tridiagonale.
!>          Si COMPZ = 'N', Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si les vecteurs propres sont désirés, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si COMPZ = 'N' ou N <= 1, LWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LWORK doit être au moins
!>                         ( 1 + 3*N + 2*N*lg N + 4*N**2 ),
!>                         où lg( N ) = le plus petit entier k tel que
!>                         2**k >= N.
!>          Si COMPZ = 'I' et N > 1, LWORK doit être au moins
!>                         ( 1 + 4*N + N**2 ).
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou égal à la taille minimale de division, généralement 25, alors LWORK n'a besoin d'être que max(1,2*(N-1)).
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) contient le LIWORK optimal.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK.
!>          Si COMPZ = 'N' ou N <= 1, LIWORK doit être au moins 1.
!>          Si COMPZ = 'V' et N > 1, LIWORK doit être au moins
!>                         ( 6 + 6*N + 5*N*lg N ).
!>          Si COMPZ = 'I' et N > 1, LIWORK doit être au moins
!>                         ( 3 + 5*N ).
!>          Notez que pour COMPZ = 'I' ou 'V', si N est inférieur ou égal à la taille minimale de division, généralement 25, alors LIWORK
!>          n'a besoin d'être que 1.
!>
!>          Si LIWORK = -1, une requête d'espace de travail est supposée ; la
!>          routine calcule seulement la taille optimale du tableau IWORK,
!>          renvoie cette valeur comme première entrée du tableau IWORK, et
!>          aucun message d'erreur relatif à LIWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme n'a pas réussi à calculer une valeur propre pendant
!>                le travail sur la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) à mod(INFO,N+1).
!>

sous-routine zstedc (character compz, integer n, double precision, dimension( * ) d, double

zstedc(3)`

NAME

zstedc — Computes all eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

SYNOPSIS


SUBROUTINE ZSTEDC( COMPZ, N, D, E, Z, LDZ, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK, INFO )

    CHARACTER(KIND=1)         COMPZ
    INTEGER                   N
    DOUBLE PRECISION, DIMENSION( * ) D
    DOUBLE PRECISION, DIMENSION( * ) E
    COMPLEX(KIND=16)          Z( LDZ, * )
    INTEGER                   LDZ
    COMPLEX(KIND=16), DIMENSION( * ) WORK
    INTEGER                   LWORK
    DOUBLE PRECISION, DIMENSION( * ) RWORK
    INTEGER                   LRWORK
    INTEGER, DIMENSION( * )   IWORK
    INTEGER                   LIWORK
    INTEGER                   INFO

    INTEGER N
    DOUBLE PRECISION D( * )
    DOUBLE PRECISION E( * )
    COMPLEX*16 Z( LDZ, * )
    INTEGER LDZ
    COMPLEX*16 WORK( * )
    INTEGER LWORK
    DOUBLE PRECISION RWORK( * )
    INTEGER LRWORK
    INTEGER IWORK( * )
    INTEGER LIWORK
    INTEGER INFO

Detailed Description

The routine computes all eigenvalues and, optionally, eigenvectors of a symmetric tridiagonal matrix using the divide and conquer method. The eigenvectors of a full or band complex Hermitian matrix can also be found if ZHETRD or ZHPTRD or ZHBTRD has been used to reduce this matrix to tridiagonal form.

subroutine zstedc (character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZSTEDC

Purpose:

!>
!> ZSTEDC computes all eigenvalues and, optionally, eigenvectors of a
!> symmetric tridiagonal matrix using the divide and conquer method.
!> The eigenvectors of a full or band complex Hermitian matrix can also
!> be found if ZHETRD or ZHPTRD or ZHBTRD has been used to reduce this
!> matrix to tridiagonal form.
!>
!>

Parameters

COMPZ 
!>          COMPZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only.
!>          = 'I':  Compute eigenvectors of tridiagonal matrix also.
!>          = 'V':  Compute eigenvectors of original Hermitian matrix
!>                  also.  On entry, Z contains the unitary matrix used
!>                  to reduce the original matrix to tridiagonal form.
!>

N

!>          N is INTEGER
!>          The dimension of the symmetric tridiagonal matrix.  N >= 0.
!>

D

!>          D is DOUBLE PRECISION array, dimension (N)
!>          On entry, the diagonal elements of the tridiagonal matrix.
!>          On exit, if INFO = 0, the eigenvalues in ascending order.
!>

E

!>          E is DOUBLE PRECISION array, dimension (N-1)
!>          On entry, the subdiagonal elements of the tridiagonal matrix.
!>          On exit, E has been destroyed.
!>

Z

!>          Z is COMPLEX*16 array, dimension (LDZ,N)
!>          On entry, if COMPZ = 'V', then Z contains the unitary
!>          matrix used in the reduction to tridiagonal form.
!>          On exit, if INFO = 0, then if COMPZ = 'V', Z contains the
!>          orthonormal eigenvectors of the original Hermitian matrix,
!>          and if COMPZ = 'I', Z contains the orthonormal eigenvectors
!>          of the symmetric tridiagonal matrix.
!>          If  COMPZ = 'N', then Z is not referenced.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1.
!>          If eigenvectors are desired, then LDZ >= max(1,N).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If COMPZ = 'N' or 'I', or N <= 1, LWORK must be at least 1.
!>          If COMPZ = 'V' and N > 1, LWORK must be at least N*N.
!>          Note that for COMPZ = 'V', then if N is less than or
!>          equal to the minimum divide size, usually 25, then LWORK need
!>          only be 1.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal sizes of the WORK, RWORK and
!>          IWORK arrays, returns these values as the first entries of
!>          the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (MAX(1,LRWORK))
!>          On exit, if INFO = 0, RWORK(1) returns the optimal LRWORK.
!>

LRWORK

!>          LRWORK is INTEGER
!>          The dimension of the array RWORK.
!>          If COMPZ = 'N' or N <= 1, LRWORK must be at least 1.
!>          If COMPZ = 'V' and N > 1, LRWORK must be at least
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         where lg( N ) = smallest integer k such
!>                         that 2**k >= N.
!>          If COMPZ = 'I' and N > 1, LRWORK must be at least
!>                         1 + 4*N + 2*N**2 .
!>          Note that for COMPZ = 'I' or 'V', then if N is less than or
!>          equal to the minimum divide size, usually 25, then LRWORK
!>          need only be max(1,2*(N-1)).
!>
!>          If LRWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal sizes of the WORK, RWORK
!>          and IWORK arrays, returns these values as the first entries
!>          of the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          If COMPZ = 'N' or N <= 1, LIWORK must be at least 1.
