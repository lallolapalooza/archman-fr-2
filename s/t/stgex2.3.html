STGEX2 échange des blocs diagonaux adjacents dans une paire de matrices supérieure (quasi) triangulaire par une transformation d'équivalence orthogonale.

Documentation de la fonction/sous-programme

sous-programme stgex2 (logical wantq, logical wantz, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldz, * ) z, integer ldz, integer j1, integer n1, integer n2, real, dimension( * ) work, integer lwork, integer info)

STGEX2 échange des blocs diagonaux adjacents dans une paire de matrices supérieure (quasi) triangulaire par une transformation d'équivalence orthogonale.

But :

!>
!> STGEX2 échange les blocs diagonaux adjacents (A11, B11) et (A22, B22)
!> de taille 1x1 ou 2x2 dans une paire de matrices supérieure (quasi)
!> triangulaire (A, B) par une transformation d'équivalence orthogonale.
!>
!> (A, B) doit être dans une forme canonique généralisée de Schur réelle
!> (telle que retournée par SGGES), c'est-à-dire A est bloc supérieur
!> triangulaire avec des blocs diagonaux de 1x1 et 2x2. B est supérieur
!> triangulaire.
!>
!> Optionnellement, les matrices Q et Z de vecteurs de Schur généralisés sont
!> mises à jour.
!>
!>        Q(in) * A(in) * Z(in)**T = Q(out) * A(out) * Z(out)**T
!>        Q(in) * B(in) * Z(in)**T = Q(out) * B(out) * Z(out)**T
!>
!>

Paramètres

WANTQ 
!>          WANTQ est LOGICAL
!>          .VRAI. : met à jour la matrice de transformation gauche Q;
!>          .FAUX. : ne met pas à jour Q.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          .VRAI. : met à jour la matrice de transformation droite Z;
!>          .FAUX. : ne met pas à jour Z.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          À l'entrée, la matrice A dans la paire (A, B).
!>          À la sortie, la matrice A mise à jour.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau REAL, dimension (LDB,N)
!>          À l'entrée, la matrice B dans la paire (A, B).
!>          À la sortie, la matrice B mise à jour.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

Q

!>          Q est un tableau REAL, dimension (LDQ,N)
!>          À l'entrée, si WANTQ = .VRAI., la matrice orthogonale Q.
!>          À la sortie, la matrice Q mise à jour.
!>          Non référencé si WANTQ = .FAUX..
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1.
!>          Si WANTQ = .VRAI., LDQ >= N.
!>

Z

!>          Z est un tableau REAL, dimension (LDZ,N)
!>          À l'entrée, si WANTZ = .VRAI., la matrice orthogonale Z.
!>          À la sortie, la matrice Z mise à jour.
!>          Non référencé si WANTZ = .FAUX..
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si WANTZ = .VRAI., LDZ >= N.
!>

J1

!>          J1 est INTEGER
!>          L'indice du premier bloc (A11, B11). 1 <= J1 <= N.
!>

N1

!>          N1 est INTEGER
!>          L'ordre du premier bloc (A11, B11). N1 = 0, 1 ou 2.
!>

N2

!>          N2 est INTEGER
!>          L'ordre du second bloc (A22, B22). N2 = 0, 1 ou 2.
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK)).
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >=  MAX( N*(N2+N1), (N2+N1)*(N2+N1)*2 )
!>

INFO

!>          INFO est INTEGER
!>            =0: Sortie réussie
!>            >0: Si INFO = 1, la matrice transformée (A, B) serait trop éloignée
!>                de la forme de Schur généralisée ; les blocs ne sont pas
!>                échangés et (A, B) ainsi que (Q, Z) restent inchangés.
!>                Le problème d'échange est trop mal conditionné.
!>            <0: Si INFO = -16 : LWORK est trop petit. La valeur appropriée
!>                pour LWORK est retournée dans WORK(1).
!>

Détails supplémentaires :
