template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lancer des exceptions en cas d'erreurs.

Paramètres

__except Le nouveau masque des exceptions.

Par défaut, les indicateurs d'erreur sont définis silencieusement. Vous pouvez définir un masque d'exceptions pour chaque flux ; si un bit du masque est défini dans les indicateurs d'erreur, une exception de type std::ios_base::failure est lancée.

Si l'indicateur d'erreur est déjà défini lorsque le masque des exceptions est ajouté, l'exception est immédiatement lancée. Essayez d'exécuter le code suivant sous GCC 3.1 ou une version ultérieure :

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");

int std::ios_base::xalloc () [static], [inherited]

Accès aux indices uniques.

Retourne

Un entier différent de tous les appels précédents.

Cette fonction retourne un entier unique à chaque appel. Il peut être utilisé à n'importe quelle fin, mais est principalement destiné à être un indice unique pour les fonctions `iword` et `pword`. L'attente est qu'une application appelle `xalloc` afin d'obtenir un indice dans les tableaux `iword` et `pword` qui peut être utilisé sans crainte de conflit.

L'implémentation maintient une variable statique qui est incrémentée et retournée à chaque invocation. `xalloc` est garanti de retourner un indice qui est sûr à utiliser dans les tableaux `iword` et `pword`.

Description détaillée

La classe std::basic_ostream est la classe de base des flux de sortie de caractères. Elle fournit les opérations communes pour écrire des caractères, des chaînes et des types numériques formatés dans un flux.

Les flux de sortie sont généralement associés à des tampons de flux (classes dérivant de std::basic_streambuf) qui gèrent le stockage et les opérations d'E/S réelles. La classe std::basic_ostream utilise le modèle de flux d'insertion (opérateur <<) pour écrire des données dans le tampon de flux associé.

Les classes std::ostream et std::wostream sont des types spécialisés pour les flux de caractères étroits (char) et larges (wchar_t) respectivement.

Documentation des types imbriqués

char_type
Le type de caractère utilisé par le flux. Il s'agit de CharT pour std::basic_ostream, char pour std::ostream, et wchar_t pour std::wostream.
int_type
Le type entier utilisé pour représenter les caractères individuels dans les opérations du tampon de flux. Il s'agit généralement de int.
streamoff
Type utilisé pour représenter les décalages dans un flux. Il s'agit de std::streamoff.
streampos
Type utilisé pour représenter les positions dans un flux. Il s'agit de std::streampos.
traits_type
Le type de traits utilisé pour gérer les opérations sur les caractères. Il s'agit de std::char_traits<CharT> par défaut.
