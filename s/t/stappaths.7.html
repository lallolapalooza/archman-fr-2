NOM

stappaths - chemins de fichiers configurables de systemtap

DESCRIPTION

Cette page de manuel a été générée pour systemtap 5.4. La section suivante listera les chemins principaux de systemtap qui sont importants à connaître et qui peuvent nécessiter une référence.

/usr/share/systemtap/tapset/
Le répertoire pour la bibliothèque de tapset d'alias de sonde / fonction standard, sauf s'il est remplacé par la variable d'environnement SYSTEMTAP_TAPSET ou la variable d'environnement XDG_DATA_DIRS. Ceux-ci sont décrits dans les pages de manuel stapprobes(3stap), probe::*(3stap) et function::*(3stap).
/usr/share/systemtap/runtime/
Les sources d'exécution, sauf s'il est remplacé par la variable d'environnement SYSTEMTAP_RUNTIME.
/usr/bin/staprun
Le programme auxiliaire supervisant le chargement, l'interaction et le déchargement des modules.
/etc/stap-exporter
Le répertoire par défaut pour rechercher les fichiers *.stp, pour l'exportation vers HTTP.
/usr/lib/systemtap/systemtap/stapio
Le programme auxiliaire pour la gestion de l'entrée et de la sortie des modules.
/usr/include/sys/sdt.h
Emplacement des en-têtes <sys/sdt.h>.
Chemin des informations de débogage du noyau : /usr/lib/debug/lib/modules/$(uname -r)/
L'emplacement des informations de débogage du noyau lorsqu'elles sont packagées dans le RPM kernel-debuginfo, sauf s'il est remplacé par la variable d'environnement SYSTEMTAP_DEBUGINFO_PATH. La valeur par défaut pour cette variable est +:.debug:/usr/lib/debug:build. elfutils recherche vmlinux dans ce chemin et interprète le chemin comme un répertoire de base dans lequel divers sous-répertoires seront recherchés pour trouver les informations de débogage pour le noyau, les modules du noyau et les binaires de l'espace utilisateur. Par défaut, systemtap recherchera également vmlinux dans ces emplacements : 
/boot/vmlinux-`uname -r` 
/lib/modules/`uname -r`/vmlinux
/lib/modules/`uname -r`/vmlinux.debug
/lib/modules/`uname -r`/build/vmlinux
/lib/modules/`uname -r`/.debug/vmlinux.debug
/usr/lib/debug/lib/modules/`uname -r`/vmlinux.debug
/var/cache/abrt-di/usr/debug/lib/modules/`uname -r`/
/var/cache/abrt-di/usr/lib/debug/lib/modules/`uname -r`/vmlinux.debug

Les fichiers sources correspondants sont généralement situés sous /usr/src/debug/. Des informations de fichiers supplémentaires sur les applications en espace utilisateur peuvent être déterminées au cas par cas en utilisant rpm -ql <paquet>-debuginfo. Pour les informations des applications en espace utilisateur prises en charge, veuillez consulter le wiki systemtap.

Avec elfutils version >0.178, systemtap peut télécharger automatiquement les informations de débogage depuis les serveurs debuginfod. Vous pouvez l'essayer en définissant une ou deux variables d'environnement : 

export DEBUGINFOD_URLS=https://debuginfod.elfutils.org/
export DEBUGINFOD_PROGRESS=1
$HOME/.systemtap
Répertoire de données Systemtap pour les fichiers systemtap mis en cache, sauf s'il est remplacé par la variable d'environnement SYSTEMTAP_DIR.
/tmp/stapXXXXXX
Répertoire temporaire pour les fichiers systemtap, y compris le code C traduit et l'objet noyau.
/lib/modules/VERSION/build
L'emplacement de l'infrastructure de construction de modules du noyau.
/usr/share/doc/systemtap*/examples
Des exemples plus détaillés peuvent être trouvés ici. Chaque exemple est accompagné d'un fichier .txt ou .meta expliquant ce que fait l'exemple, l'échantillon ou la démo et comment il est normalement exécuté. Voir aussi en ligne à : https://sourceware.org/systemtap/examples/
$SYSTEMTAP_DIR/ssl/server
Base de données des certificats SSL côté serveur de l'utilisateur. Si SYSTEMTAP_DIR n'est pas défini, la valeur par défaut est $HOME/.systemtap.
$SYSTEMTAP_DIR/ssl/client
Base de données des certificats SSL privés côté client de l'utilisateur. Si SYSTEMTAP_DIR n'est pas défini, la valeur par défaut est $HOME/.systemtap.
/etc/systemtap/ssl/client
Base de données globale des certificats SSL côté client.
/etc/systemtap/staprun/
Base de données des certificats de signataires de confiance de staprun.
/etc/sysconfig/stap-server
Fichier de configuration globale du service stap-server.
/etc/sysconfig/stap-exporter
Fichier de configuration globale du service stap-exporter.
/var/run/stap-server/
Emplacement par défaut des fichiers d'état pour les serveurs en cours d'exécution du service stap-server.
/var/log/stap-server/log
Fichier journal par défaut du service stap-server.
