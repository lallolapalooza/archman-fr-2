class std::experimental::basic_string_view< _CharT, _Traits >"Une référence non possédante à une chaîne.

Paramètres du modèle

_CharT Type de caractère
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

Un basic_string_view ressemble à ceci :

_CharT*    _M_str
size_t     _M_len
