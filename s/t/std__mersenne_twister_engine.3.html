class std::mersenne_twister_engine< _UIntType, __w, __n, __m, __r, __a, __u, __d, __s, __b, __t, __c, __l, __f >"Un générateur de nombres aléatoires à registre à décalage à rétroaction généralisé.

Cet algorithme évite la multiplication et la division et est conçu pour être compatible avec une architecture pipelinée. Si les paramètres sont choisis correctement, ce générateur produira des nombres avec une période très longue et une entropie apparente assez bonne, bien que toujours pas cryptographiquement forte.

La meilleure façon d'utiliser ce générateur est avec la classe pré-définie mt19937.

Cet algorithme a été initialement inventé par Makoto Matsumoto et Takuji Nishimura.

Paramètres du modèle

__w Taille du mot, le nombre de bits dans chaque élément du vecteur d'état.
__n Le degré de récursion.
__m Le paramètre de période.
__r L'indice du bit du point de séparation.
__a La dernière ligne de la matrice de torsion.
__u Le premier paramètre de la matrice de trempe par décalage à droite.
__d Le masque du premier paramètre de la matrice de trempe par décalage à droite.
__s Le premier paramètre de la matrice de trempe par décalage à gauche.
__b Le masque du premier paramètre de la matrice de trempe par décalage à gauche.
__t Le second paramètre de la matrice de trempe par décalage à gauche.
__c Le masque du second paramètre de la matrice de trempe par décalage à gauche.
__l Le second paramètre de la matrice de trempe par décalage à droite.
__f Multiplicateur d'initialisation.

Description détaillée

Ce moteur génère des séquences de nombres pseudo-aléatoires selon l'algorithme Mersenne Twister.

Les paramètres du template définissent les caractéristiques spécifiques de l'implémentation du Mersenne Twister :

_UIntType
Type entier non signé utilisé pour représenter les nombres générés.
__w
Nombre de bits dans un mot.
__n
La longueur du "tampon" de l'état interne.
__m
Un paramètre utilisé dans la génération.
__r
Un paramètre utilisé dans la génération.
__a
Une valeur de masque utilisée dans la génération.
__u
Un décalage utilisé dans la génération.
__d
Un masque utilisé dans la génération.
__s
Un décalage utilisé dans la génération.
__b
Un masque utilisé dans la génération.
__t
Un décalage utilisé dans la génération.
__c
Un masque utilisé dans la génération.
__l
Un décalage utilisé dans la génération.
__f
Une valeur de masque utilisée dans la génération.

Les valeurs typiques pour ces paramètres sont celles définies dans la norme C++ pour les générateurs courants, tels que std::mt19937 et std::mt19937_64.
