PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails sur le comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

stdbool.h — type et valeurs booléens

SYNTAXE

#include <stdbool.h>

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

L'en-tête <stdbool.h> définit les macros suivantes :

bool
S'étend à _Bool.
true
S'étend à la constante entière 1.
false
S'étend à la constante entière 0.
__bool_true_false_are_defined

S'étend à la constante entière 1.

Une application peut annuler la définition puis potentiellement redéfinir les macros bool, true et false.

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

Aucune.

RATIONNEL

Aucun.

DIRECTIONS FUTURES

La possibilité d'annuler la définition et de redéfinir les macros bool, true et false est une fonctionnalité obsolète et pourrait être supprimée dans une future version.
