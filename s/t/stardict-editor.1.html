NOM

stardict-editor - programme pour éditer, compiler et décompiler les dictionnaires stardict

SYNOPSIS

stardict-editor

DESCRIPTION

Cette page de manuel documente brièvement la commande stardict-editor.

stardict-editor est un programme qui vous permet d'éditer, de compiler et de décompiler des dictionnaires stardict à partir d'une interface Gtk simple.

OPTIONS

Ce programme n'accepte aucune option.

AUTEUR
