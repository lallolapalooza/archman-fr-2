Documentation de la fonction/sous-routine

sous-routine strt01 (caractère uplo, caractère diag, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldainv, * ) ainv, entier ldainv, réel rcond, réel, dimension( * ) work, réel resid)

STRT01

Objectif:

!>
!> STRT01 calcule le résidu pour une matrice triangulaire A multipliée par son
!> inverse :
!>    RESID = norm( A*AINV - I ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Non-unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire de dimension n par n de la matrice A contient la
!>          matrice triangulaire supérieure, et la partie strictement inférieure
!>          de A n'est pas référencée.  Si UPLO = 'L', la partie inférieure
!>          triangulaire de dimension n par n de la matrice A contient la
!>          matrice triangulaire inférieure, et la partie strictement supérieure
!>          de A n'est pas référencée.  Si DIAG = 'U', les éléments diagonaux
!>          de A ne sont pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AINV

!>          AINV est un tableau REAL, dimension (LDAINV,N)
!>          En entrée, l'inverse (triangulaire) de la matrice A, dans le
!>          même format de stockage que A.
!>          En sortie, le contenu de AINV est détruit.
!>

LDAINV

!>          LDAINV est INTEGER
!>          La dimension principale du tableau AINV.  LDAINV >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          Le nombre de conditionnement réciproque de A, calculé comme
!>          1/(norm(A) * norm(AINV)).
!>

WORK

!>          WORK est un tableau REAL, dimension (N)
!>

RESID

!>          RESID est REAL
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
