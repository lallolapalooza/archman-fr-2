Description

This is a generator engine for pseudorandom number generation. It is a template that takes four parameters: _UIntType, __w, __s, and __r.

  • _UIntType: The unsigned integer type used for the internal state.
  • __w: The number of bits in each word of the state.
  • __s: The number of words in the state's delay line.
  • __r: The distance back in the delay line from which the value is taken.

The generator produces a sequence of unsigned integers of type result_type.

Seeds the initial state $x_0$ of the random number generator. N1688[4.19] modifies this as follows. If __value == 0, sets value to 19780503. In any case, with a linear congruential generator lcg(i) having parameters $ m_{lcg} = 2147483563, a_{lcg} = 40014, c_{lcg} = 0, and lcg(0) = value $, sets $ x_{-r} \dots x_{-1} $ to $ lcg(1) \dots lcg(r) $ respectively. If $ x_{-1} = 0 $ set carry to 1, otherwise sets carry to 0.
