Description détaillée

template<typename _CharT>

class std::numpunct< _CharT >"Modèle de classe principal numpunct.

Cette facette stocke plusieurs informations relatives à l'impression et à l'analyse des nombres, telles que le caractère du point décimal. Elle prend un paramètre de modèle spécifiant le type de caractère. La facette numpunct est utilisée par les flux pour de nombreuses opérations d'E/S impliquant des nombres.

Le modèle numpunct utilise des fonctions virtuelles protégées pour fournir les résultats réels. Les accesseurs publics transmettent l'appel aux fonctions virtuelles. Ces fonctions virtuelles sont des points d'accroche pour les développeurs afin d'implémenter le comportement requis d'une facette numpunct.

#include <locale>

Description détaillée

La classe std::numpunct est une facette de locale qui spécifie les règles pour la mise en forme des nombres. Elle fournit des méthodes pour obtenir les caractères et les chaînes de caractères utilisés pour la séparation des groupes de chiffres, les séparateurs décimaux, ainsi que les représentations textuelles des valeurs booléennes vraies et fausses.

Les classes dérivées peuvent remplacer les méthodes virtuelles protégées pour personnaliser le comportement de mise en forme des nombres pour une locale spécifique.

template<typename _CharT>
string std::numpunct<_CharT>::grouping () const [inline]

Spécification de groupement des chiffres. Cette fonction retourne une chaîne représentant les groupements pour la partie entière d'un nombre. Les groupements indiquent où les séparateurs de milliers doivent être insérés dans la partie entière d'un nombre.

Chaque char de la chaîne de retour est interprété comme un entier plutôt que comme un caractère. Ces nombres représentent le nombre de chiffres dans un groupe. Le premier char de la chaîne représente le nombre de chiffres dans le groupe le moins significatif. Si un char est négatif, il indique un nombre illimité de chiffres pour le groupe. Si des char supplémentaires de la chaîne sont nécessaires pour grouper un nombre, le dernier char est utilisé de manière répétée.

Par exemple, si grouping() retourne "\003\002" et est appliqué au nombre 123456789, cela correspond à 12,34,56,789. Notez que si la chaîne était "32", cela placerait plus de 50 chiffres dans le groupe le moins significatif si le jeu de caractères est ASCII.

La chaîne est retournée en appelant numpunct<char_type>::do_grouping().

Retours

Chaîne représentant la spécification de groupement.

Références do_grouping().
