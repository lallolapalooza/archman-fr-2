Description détaillée

template<typename _BiIter>

class std::sub_match< _BiIter >"Une séquence de caractères correspondants à une sous-expression marquée particulière.

Un objet de cette classe est essentiellement une paire d'itérateurs marquant une sous-expression correspondante dans une correspondance de motif d'expression régulière. Ces objets peuvent être convertis et comparés à des objets std::basic_string du même type de caractère que le motif correspondant par l'expression régulière.

Un sub_match<Iter> a une classe de base publique de type pair<Iter, Iter>, donc hérite des membres de données de pair nommés first et second. Les itérateurs qui composent la paire sont l'intervalle semi-ouvert habituel faisant référence au motif original réel correspondant.

Detailed Description

The class template std::sub_match represents a sub-match, which is a part of the sequence matched by a regular expression. It is defined by two iterators, one pointing to the beginning and one pointing to the end of the matched sequence. Note that the iterators may point to a sequence that does not match the regular expression at all. In that case, the matched() member function returns false.

The std::sub_match class template is used by the std::match_results class template to store the results of a regular expression match. Specifically, each element of the std::match_results object is a std::sub_match object representing one of the sub-matches found.

When a sub-match does not correspond to any part of the input sequence, for example, if a subexpression did not participate in the match, the first and second members are equal. The matched() member function will return false in this case.

The operator basic_string<value_type>() converts the sub-match to a string. This operator is not declared in the header, but it is declared for some specializations of std::sub_match. This can be quite confusing because the conversion is not obvious and it might pop up in unexpected places and cause a great deal of confusion and cursing from the unwary.
