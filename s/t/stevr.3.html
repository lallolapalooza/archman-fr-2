sous-routine dstevr (character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DSTEVR calcule les valeurs propres et, éventuellement, les vecteurs propres gauche et/ou droite pour d'AUTRES matrices

Objectif :

!>
!> DSTEVR calcule certaines valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique T. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit une plage de valeurs,
!> soit une plage d'indices pour les valeurs propres désirées.
!>
!> Dans la mesure du possible, DSTEVR appelle DSTEMR pour calculer le
!> spectre propre en utilisant des Représentations Relativement Robustes. DSTEMR
!> calcule les valeurs propres par l'algorithme dqds, tandis que les vecteurs propres
!> orthogonaux sont calculés à partir de diverses représentations L D L^T
!> (également connues sous le nom de Représentations Relativement Robustes). L'orthogonalisation
!> de Gram-Schmidt est évitée autant que possible. Plus précisément,
!> les différentes étapes de l'algorithme sont les suivantes. Pour le i-ème
!> bloc non réduit de T,
!>    (a) Calculer T - sigma_i = L_i D_i L_i^T, tel que L_i D_i L_i^T
!>         est une représentation relativement robuste,
!>    (b) Calculer les valeurs propres, lambda_j, de L_i D_i L_i^T avec une haute
!>        précision relative par l'algorithme dqds,
!>    (c) S'il existe un groupe de valeurs propres proches, sigma_i
!>        proche du groupe, et revenir à l'étape (a),
!>    (d) Étant donné la valeur propre approchée lambda_j de L_i D_i L_i^T,
!>        calculer le vecteur propre correspondant en formant une
!>        factorisation tordue révélatrice de rang.
!> La précision souhaitée des résultats peut être spécifiée par le paramètre d'entrée
!> ABSTOL.
!>
!> Pour plus de détails, voir , par Inderjit Dhillon,
!> Rapport technique de la division informatique n° UCB//CSD-97-971,
!> UC Berkeley, mai 1997.
!>
!>
!> Note 1 : DSTEVR appelle DSTEMR lorsque le spectre complet est demandé
!> sur les machines qui respectent la norme de virgule flottante ieee-754.
!> DSTEVR appelle DSTEBZ et DSTEIN sur les machines non-ieee et
!> lorsque des demandes de spectre partiel sont faites.
!>
!> L'exécution normale de DSTEMR peut créer des NaNs et des infinis et
!> peut donc échouer en raison d'une exception de virgule flottante dans les environnements
!> qui ne gèrent pas les NaNs et les infinis selon la manière par défaut de la norme ieee.
!>

Paramètres

JOBZ 
!>          JOBZ est de type CHARACTER*1
!>          = 'N' : calcul des valeurs propres uniquement ;
!>          = 'V' : calcul des valeurs propres et des vecteurs propres.
!>

RANGE

!>          RANGE est de type CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de l'indice IL à l'indice IU seront trouvées.
!>          Pour RANGE = 'V' ou 'I' et IU - IL < N - 1, DSTEBZ et
!>          DSTEIN sont appelés
!>

N

!>          N est un INTEGER
!>          L'ordre de la matrice. N >= 0.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.
!>          À la sortie, D peut être multiplié par un facteur constant choisi
!>          pour éviter le dépassement de capacité/sous-dépassement de capacité dans le calcul des valeurs propres.
!>

E

!>          E est un tableau de type DOUBLE PRECISION, de dimension (max(1,N-1))
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A dans les éléments 1 à N-1 de E.
!>          À la sortie, E peut être multiplié par un facteur constant choisi
!>          pour éviter le dépassement de capacité/sous-dépassement de capacité dans le calcul des valeurs propres.
!>

VL

!>          VL est de type DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est de type DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est de type INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est de type INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est de type DOUBLE PRECISION
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergée
!>          lorsqu'elle est déterminée se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision de la machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si une haute précision relative est importante, définissez ABSTOL à
!>          DLAMCH( 'Safe minimum' ). Cela garantira que
!>          les valeurs propres sont calculées avec une haute précision relative lorsque
!>          possible dans les futures versions. Le code actuel ne fait
!>          aucune garantie concernant la haute précision relative, mais
!>          les futures versions le feront. Voir J. Barlow et J. Demmel,
!>          , LAPACK Working Note #7, pour une discussion
!>          sur les matrices qui définissent leurs valeurs propres avec une haute précision relative.
!>

M

!>          M est de type INTEGER
!>          Le nombre total de valeurs propres trouvées. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau de type DOUBLE PRECISION, de dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées par ordre
!>          croissant.
!>

Z

!>          Z est un tableau de type DOUBLE PRECISION, de dimension (LDZ, max(1,M) )
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, avec la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Note : l'utilisateur

DSTEVR

subroutine dstevr (character jobz, character range, integer n, real, dimension( * ) d, real, dimension( * ) e, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DSTEVR computes the eigenvalues and, optionally, the left and/or right eigenvectors for OTHER matrices

Purpose:

!>
!> DSTEVR computes selected eigenvalues and, optionally, eigenvectors
!> of a real symmetric tridiagonal matrix T.  Eigenvalues and
!> eigenvectors can be selected by specifying either a range of values
!> or a range of indices for the desired eigenvalues.
!>
!> Whenever possible, DSTEVR calls DSTEMR to compute the
!> eigenspectrum using Relatively Robust Representations.  DSTEMR
!> computes eigenvalues by the dqds algorithm, while orthogonal
!> eigenvectors are computed from various  L D L^T representations
!> (also known as Relatively Robust Representations). Gram-Schmidt
!> orthogonalization is avoided as far as possible. More specifically,
!> the various steps of the algorithm are as follows. For the i-th
!> unreduced block of T,
!>    (a) Compute T - sigma_i = L_i D_i L_i^T, such that L_i D_i L_i^T
!>         is a relatively robust representation,
!>    (b) Compute the eigenvalues, lambda_j, of L_i D_i L_i^T to high
!>        relative accuracy by the dqds algorithm,
!>    (c) If there is a cluster of close eigenvalues,  sigma_i
!>        close to the cluster, and go to step (a),
!>    (d) Given the approximate eigenvalue lambda_j of L_i D_i L_i^T,
!>        compute the corresponding eigenvector by forming a
!>        rank-revealing twisted factorization.
!> The desired accuracy of the output can be specified by the input
!> parameter ABSTOL.
!>
!> For more details, see , by Inderjit Dhillon,
!> Computer Science Division Technical Report No. UCB//CSD-97-971,
!> UC Berkeley, May 1997.
!>
!>
!> Note 1 : DSTEVR calls DSTEMR when the full spectrum is requested
!> on machines which conform to the ieee-754 floating point standard.
!> DSTEVR calls DSTEBZ and DSTEIN on non-ieee machines and
!> when partial spectrum requests are made.
!>
!> Normal execution of DSTEMR may create NaNs and infinities and
!> hence may abort due to a floating point exception in environments
!> which do not handle NaNs and infinities in the ieee standard default
!> manner.
!>

Parameters

JOBZ 
!>          JOBZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only;
!>          = 'V':  Compute eigenvalues and eigenvectors.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': all eigenvalues will be found.
!>          = 'V': all eigenvalues in the half-open interval (VL,VU]
!>                 will be found.
!>          = 'I': the IL-th through IU-th eigenvalues will be found.
!>          For RANGE = 'V' or 'I' and IU - IL < N - 1, DSTEBZ and
!>          DSTEIN are called
!>

N

!>          N is INTEGER
!>          The order of the matrix.  N >= 0.
!>

D

!>          D is REAL array, dimension (N)
!>          On entry, the n diagonal elements of the tridiagonal matrix
!>          A.
!>          On exit, D may be multiplied by a constant factor chosen
!>          to avoid over/underflow in computing the eigenvalues.
!>

E

!>          E is REAL array, dimension (max(1,N-1))
!>          On entry, the (n-1) subdiagonal elements of the tridiagonal
!>          matrix A in elements 1 to N-1 of E.
!>          On exit, E may be multiplied by a constant factor chosen
!>          to avoid over/underflow in computing the eigenvalues.
!>

VL

!>          VL is REAL
!>          If RANGE='V', the lower bound of the interval to
!>          be searched for eigenvalues. VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

VU

!>          VU is REAL
!>          If RANGE='V', the upper bound of the interval to
!>          be searched for eigenvalues. VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

IL

!>          IL is INTEGER
!>          If RANGE='I', the index of the
!>          smallest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

IU

!>          IU is INTEGER
!>          If RANGE='I', the index of the
!>          largest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

ABSTOL

!>          ABSTOL is REAL
!>          The absolute error tolerance for the eigenvalues.
!>          An approximate eigenvalue is accepted as converged
!>          when it is determined to lie in an interval [a,b]
!>          of width less than or equal to
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          where EPS is the machine precision.  If ABSTOL is less than
!>          or equal to zero, then  EPS*|T|  will be used in its place,
!>          where |T| is the 1-norm of the tridiagonal matrix obtained
!>          by reducing A to tridiagonal form.
!>
!>          See  by Demmel and
!>          Kahan, LAPACK Working Note #3.
!>
!>          If high relative accuracy is important, set ABSTOL to
!>          DLAMCH( 'Safe minimum' ).  Doing so will guarantee that
!>          eigenvalues are computed to high relative accuracy when
!>          possible in future releases.  The current code does not
!>          make any guarantees about high relative accuracy, but
!>          future releases will. See J. Barlow and J. Demmel,
!>          , LAPACK Working Note #7, for a discussion
!>          of which matrices define their eigenvalues to high relative
!>          accuracy.
!>

M

!>          M is INTEGER
!>          The total number of eigenvalues found.  0 <= M <= N.
!>          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>

W

!>          W is REAL array, dimension (N)
!>          The first M elements contain the selected eigenvalues in
!>          ascending order.
!>

Z

!>          Z is REAL array, dimension (LDZ, max(1,M) )
!>          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
!>          contain the orthonormal eigenvectors of the matrix A
!>          corresponding to the selected eigenvalues, with the i-th
!>          column of Z holding the eigenvector associated with W(i).
!>          Note: the user must ensure that at least max(1,M) columns are
!>          supplied in the array Z; if RANGE = 'V', the exact value of M
!>          is not known in advance and an upper bound must be used.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1, and if
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ).
!>          Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal (and
!>          minimal) LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.  LWORK >= max(1,20*N).
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal sizes of the WORK and IWORK
!>          arrays, returns these values as the first entries of the WORK
!>          and IWORK arrays, and no error message related to LWORK or
!>          LIWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal (and
!>          minimal) LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.  LIWORK >= max(1,10*N).
!>
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal sizes of the WORK and
!>          IWORK arrays, returns these values as the first entries of
!>          the WORK and IWORK arrays, and no error message related to
!>          LWORK or LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  Internal error
!>

NAME

stevr — The eigenvectors and possibly eigenvalues and differences of eigenvalues of a symmetric tridiagonal matrix.

SYNOPSIS

  SUBROUTINE STEVR( JOBZ, RANGE, N, D, E, VL, VU, IL, IU, ABSTOL, M,
                    W, Z, LDZ, ISUPPZ, WORK, LWORK, IWORK, LIWORK, INFO )
    CHARACTER JOBZ, RANGE
    INTEGER IL, IU, INFO, LWORK, LIWORK, M, N
    REAL ABSTOL, D( * ), E( * ), VL, VU, W( * ), WORK( * )
    INTEGER ISUPPZ( * )
    REAL Z( * )
    INTEGER IWORK( * )

Detailed Description

This routine computes the eigenvectors and possibly eigenvalues and differences of eigenvalues of a real symmetric tridiagonal matrix T. Every subroutine in LAPACK is based on pieces of code developed at the Courant Institute of Mathematical Sciences by Prof. Peter Ullman and colleagues. Some routines are based on code developed at the University of Tennessee by Prof. van Loan and colleagues. Some routines are based on code developed at the University of California, Berkeley by Prof. Demmel and colleagues.

Arguments

JOBZ

CHARACTER*1.

Specifies whether to compute the eigenvectors.

= 'N': Compute only the eigenvalues and differences of eigenvalues.

= 'V': Compute the eigenvalues and eigenvectors.

If RANGE = 'I', then the eigenvalues are sorted in ascending order. Otherwise, the sorting is not guaranteed.

Suggested value: 'V'.

Unchanged on exit.

RANGE

CHARACTER*1.

Specifies whether to compute all eigenvalues, or only a subrange of eigenvalues.

= 'A': all eigenvalues will be found.

= 'V': all eigenvalues will be found in the range (VL, VU).

= 'I': find IL-th through IU-th eigenvalue.

Unchanged on exit.

N

INTEGER.

The order of the matrix T. 0 <= N.

Unchanged on exit.

D

REAL array, dimension (N).

On entry, the N diagonal elements of the tridiagonal matrix T.

On exit, the eigenvalues may be sorted.

E

REAL array, dimension (N-1).

On entry, the (N-1) subdiagonal elements of the tridiagonal matrix T.

On exit, E may be overwritten.

VL

REAL.

If RANGE = 'V', the lower bound of the eigenvalue range.

If RANGE = 'I' or 'A', VL is not used.

VU

REAL.

If RANGE = 'V', the upper bound of the eigenvalue range.

If RANGE = 'I' or 'A', VU is not used.

IL

INTEGER.

If RANGE = 'I', the index of the smallest eigenvalue to be sorted.

If RANGE = 'A' or 'V', IL is not used.

1 <= IL <= IU.

IU

INTEGER.

If RANGE = 'I', the index of the largest eigenvalue to be sorted.

If RANGE = 'A' or 'V', IU is not used.

IL <= IU <= N.

ABSTOL

REAL.

The absolute tolerance for convergence. If ABSTOL is negative, ABSTOL = EPSILON*MAX(|D|,|E|), where EPSILON is the machine epsilon for the data type and MAX(|D|,|E|) is the maximum absolute value of the diagonal and off-diagonal elements.

M

INTEGER.

The total number of eigenvalues found.

On exit: If RANGE = 'E' or 'I', M = IU-IL+1. If RANGE = 'A', M = N.

W

REAL array, dimension (N).

The computed eigenvalues, sorted in ascending order if JOBZ = 'V' and RANGE = 'I' or 'A'. If RANGE = 'V', the resulting eigenvalues satisfy VL <= W(I) <= VU.

Z

REAL array, dimension (LDZ,N).

The computed eigenvectors. The condition number of the eigenvector matrix Z may be k.

If JOBZ = 'V', then the columns Z(I) are the corresponding eigenvectors that satisfy the given range.

If JOBZ = 'N', then Z is not used.

The orthonormal eigenvectors are normalized so that ISUPPZ(I,J)=K, where K is the number of non-zero entries in the jth column of Z. If Z(I,J) is the k-th non-zero entry, then norm(Z(I,J)) = 1.

LDZ

INTEGER.

The leading dimension of the array Z. LDZ >= MAX(1,N).

ISUPPZ

INTEGER array, dimension (2,N).

The indices and size of the nonzero elements of the corresponding columns in Z. Specifically, for the j-th column Z(j), ISUPPZ(1,j) is the index of the first non-zero element and ISUPPZ(2,j) is the number of non-zero elements.

This is only implemented for RANGE = 'A' or 'I' and IU - IL = N - 1.

WORK

WORK is REAL array, dimension (MAX(1,LWORK))

On exit, if INFO = 0, WORK(1) returns the optimal (and minimal) LWORK.

LWORK

LWORK is INTEGER.

The dimension of the array WORK. LWORK >= 20*N.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK and IWORK arrays, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

IWORK

IWORK is INTEGER array, dimension (MAX(1,LIWORK))

On exit, if INFO = 0, IWORK(1) returns the optimal (and minimal) LIWORK.

LIWORK

LIWORK is INTEGER.

The dimension of the array IWORK. LIWORK >= 10*N.

If LIWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK and IWORK arrays, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

INFO

INTEGER.

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: Internal error
