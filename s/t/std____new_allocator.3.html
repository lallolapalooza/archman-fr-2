Description détaillée

template<typename _Tp>

class std::__new_allocator< _Tp >"Un allocateur qui utilise global new, conformément à C++03 [20.4.1].

C'est précisément l'allocateur défini dans la norme C++.

  • tous les appels d'allocation utilisent operator new
  • tous les appels de désallocation utilisent operator delete

C'est l'implémentation par défaut de la classe de base de std::allocator, et c'est aussi la classe de base de l'extension __gnu_cxx::new_allocator. Vous devriez utiliser std::allocator ou __gnu_cxx::new_allocator au lieu d'utiliser ceci directement.

Paramètres de modèle

_Tp Type de l'objet alloué.
