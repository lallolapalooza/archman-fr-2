Description détaillée

template<typename _Value, typename _Hash = hash<_Value>, typename _Pred = equal_to<_Value>, typename _Alloc = allocator<_Value>>

class std::unordered_multiset< _Value, _Hash, _Pred, _Alloc >"Un conteneur standard composé de clés équivalentes (pouvant contenir plusieurs occurrences de chaque valeur de clé) dans lequel les clés des éléments sont les éléments eux-mêmes.

Depuis

C++11

Paramètres de modèle

_Value Type des objets clé.
_Hash Type de l'objet fonction de hachage, par défaut hash<_Value>.
_Pred Type de l'objet fonction prédicat, par défaut equal_to<_Value>.
_Alloc Type de l'allocateur, par défaut allocator<_Key>.

Satisfait les exigences d'un conteneur, et d'un conteneur associatif non ordonné.

La base est _Hashtable, distribuée au moment de la compilation via l'alias de modèle __umset_hashtable.
