Description détaillée

template<typename _Tp>

class std::slice_array< _Tp > « Référence à un sous-ensemble unidimensionnel d'un tableau.

Un slice_array est une référence aux éléments réels d'un tableau spécifiés par une tranche (slice). La manière d'obtenir un slice_array est d'appeler operator[](slice) sur un valarray. Le slice_array retourné permet alors de réaliser des opérations sur le sous-ensemble d'éléments référencé dans le valarray d'origine. Par exemple, operator+=(valarray) ajoutera des valeurs au sous-ensemble d'éléments du valarray sous-jacent auquel ce slice_array fait référence.

Tp Type de l'élément.
