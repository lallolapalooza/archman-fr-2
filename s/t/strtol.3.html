strtol(3) Manuel des fonctions de bibliothèque strtol(3)

NOM

strtol, strtoll, strtoq - convertir une chaîne en entier long

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
long strtol(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
long long strtoll(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

strtoll() :

    _ISOC99_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

La fonction strtol() convertit la partie initiale de la chaîne dans nptr en une valeur entière longue selon la base donnée, qui doit être comprise entre 2 et 36 inclus, ou être la valeur spéciale 0.

La chaîne peut commencer par une quantité arbitraire d'espaces blancs (tels que déterminés par isspace(3)) suivie d'un signe facultatif '+' ou '-'. Si base est zéro ou 16, la chaîne peut alors inclure un préfixe "0x" ou "0X", et le nombre sera lu en base 16 ; si base est zéro ou 2, la chaîne peut alors inclure un préfixe "0b" ou "0B", et le nombre sera lu en base 2 ; sinon, une base zéro est prise comme 10 (décimal) à moins que le caractère suivant ne soit '0', auquel cas elle est prise comme 8 (octal).

Le reste de la chaîne est converti en une valeur long de la manière évidente, s'arrêtant au premier caractère qui n'est pas un chiffre valide dans la base donnée. (Dans les bases supérieures à 10, la lettre 'A' en majuscule ou minuscule représente 10, 'B' représente 11, et ainsi de suite, 'Z' représentant 35.)

Si endptr n'est pas NULL, et si la base est prise en charge, strtol() stocke l'adresse du premier caractère invalide dans *endptr. S'il n'y avait aucun chiffre, strtol() stocke la valeur originale de nptr dans *endptr (et renvoie 0). En particulier, si *nptr n'est pas '\0' mais que **endptr est '\0' au retour, la chaîne entière est valide.

La fonction strtoll() fonctionne exactement comme la fonction strtol() mais renvoie une valeur entière long long.

VALEUR DE RETOUR

La fonction strtol() renvoie le résultat de la conversion, sauf si la valeur provoque un sous-dépassement ou un dépassement. Si un sous-dépassement se produit, strtol() renvoie LONG_MIN. Si un dépassement se produit, strtol() renvoie LONG_MAX. Dans les deux cas, errno est défini à ERANGE. Exactement la même chose vaut pour strtoll() (avec LLONG_MIN et LLONG_MAX au lieu de LONG_MIN et LONG_MAX).

ERREURS

Cette fonction ne modifie pas errno en cas de succès.

EINVAL
(pas dans C99) La base donnée contient une valeur non prise en charge.
ERANGE
La valeur résultante était hors limites.

L'implémentation peut également définir errno à EINVAL dans le cas où aucune conversion n'a été effectuée (aucun chiffre trouvé, et 0 renvoyé).

VERSIONS

Selon POSIX.1, dans les locales autres que "C" et "POSIX", ces fonctions peuvent accepter d'autres chaînes numériques, dépendantes de l'implémentation.

BSD a également


quad_t strtoq(const char *nptr, char **endptr, int base);

avec une définition complètement analogue. Selon la taille du mot de l'architecture actuelle, cela peut être équivalent à strtoll() ou à strtol().

ATTENTION

Vérifications de plage

Étant donné que strtol() peut légitimement renvoyer 0, LONG_MAX ou LONG_MIN (LLONG_MAX ou LLONG_MIN pour strtoll()) en cas de succès comme d'échec, le programme appelant devrait définir errno à 0 avant l'appel, puis déterminer si une erreur s'est produite en vérifiant si errno == ERANGE après l'appel.


errno = 0;
n = strtol(s, &end, base);
if (end == s)
	goto no_number;
if ((errno == ERANGE && n == LONG_MIN) || n < min)
	goto too_low;
if ((errno == ERANGE && n == LONG_MAX) || n > max)
	goto too_high;

base

Si la base doit être testée, elle doit être testée lors d'un appel où la chaîne est connue pour réussir. Sinon, il est impossible de différencier les erreurs de manière portable.


errno = 0;
strtol("0", NULL, base);
if (errno == EINVAL)
    goto unsupported_base;

BOGUES

Espaces blancs

Ces fonctions acceptent silencieusement les espaces blancs en tête. Pour rejeter les espaces blancs, appelez isspace(3) avant strtol().

$ ./a.out 4000000000
