Description détaillée

Données d'ordre de formatage monétaire.

Cette classe contient un tableau ordonné de 4 champs pour représenter le modèle de formatage d'un montant monétaire. Chaque champ peut contenir une entrée de l'énumération part. symbol, sign, et value doivent être présents et le champ restant doit contenir soit none soit space.

Voir aussi

moneypunct::pos_format() et moneypunct::neg_format() pour des détails sur l'interprétation de ces champs.
