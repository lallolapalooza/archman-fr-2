NOM

streqvcmp - comparer deux chaînes avec un mappage d'équivalence

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

int streqvcmp(char const * str1, char const * str2);

DESCRIPTION

En utilisant un mappage de caractères, deux chaînes sont comparées pour l'"équivalence". Chaque caractère d'entrée est mappé à un caractère de comparaison et les caractères mappés sont comparés pour les deux chaînes d'entrée terminées par NUL. Le nom de cette fonction est mappé à option_streqvcmp afin de ne pas entrer en conflit avec l'espace de noms POSIX.

str1
première chaîne
str2
deuxième chaîne

VALEUR DE RETOUR

la différence entre deux caractères différents

ERREURS

aucune vérification. L'appelant est responsable des fautes de segmentation.
