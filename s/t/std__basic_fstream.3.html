Extracteurs
Toutes les fonctions operator>> (également appelées fonctions d'entrée formatée) ont un comportement commun. Chacune commence par la construction d'un objet temporaire de type std::basic_istream::sentry avec le second argument (noskipws) défini à false. Cela a plusieurs effets, se terminant par la définition d'un indicateur de statut ; voir la documentation de sentry pour plus de détails.

Si le statut de sentry est bon, la fonction essaie d'extraire les données appropriées au type de l'argument.

Si une exception est levée pendant l'extraction, ios_base::badbit sera activé dans l'état d'erreur du flux (sans provoquer la levée d'une ios_base::failure) et l'exception d'origine sera relancée si badbit est défini dans le masque des exceptions.

template<typename _CharT, typename _Traits>

class std::basic_fstream< _CharT, _Traits >"Contrôle de l'entrée et de la sortie pour les fichiers.

Paramètres de template

_CharT Type du flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

Cette classe prend en charge la lecture et l'écriture de fichiers nommés, en utilisant les fonctions héritées de std::basic_iostream. Pour contrôler la séquence associée, une instance de std::basic_filebuf est utilisée, à laquelle cette page fait référence en tant que sb.

typedef _Ios_Iostate std::ios_base::iostate [hérité]

Ceci est un type de masque de bits. _Ios_Iostate est défini par l'implémentation, mais il est valide d'effectuer des opérations binaires sur ces valeurs et de s'attendre à ce que les bonnes choses se produisent. Les objets définis de type iostate sont :

  • badbit
  • eofbit
  • failbit
  • goodbit

typedef _Ios_Openmode std::ios_base::openmode [hérité]

Ceci est un type de masque de bits. _Ios_Openmode est défini par l'implémentation, mais il est valide d'effectuer des opérations binaires sur ces valeurs et de s'attendre à ce que les bonnes choses se produisent. Les objets définis de type openmode sont :

  • app
  • ate
  • binary
  • in
  • out
  • trunc

typedef _Ios_Seekdir std::ios_base::seekdir [hérité]

Ceci est un type énuméré. _Ios_Seekdir est défini par l'implémentation. Les valeurs définies de type seekdir sont :

  • beg
  • cur, équivalent à SEEK_CUR dans la bibliothèque standard C.
  • end, équivalent à SEEK_END dans la bibliothèque standard C.
