Description détaillée

template<typename _CharT, typename _Traits>

La classe basic_streambuf est la classe de base pour les tampons de flux dans la bibliothèque C++ standard. Elle agit comme une interface abstraite pour les flux d'entrée et de sortie. Les opérations de flux réelles sont gérées par des classes dérivées qui implémentent des mécanismes de mise en mémoire tampon spécifiques.

Paramètres de modèle

_CharT Type du flux de caractères.
_Traits Traits pour le type de caractère, par défaut char_traits<_CharT>.

Ceci est une classe de base. Les tampons de flux dérivés contrôlent chacun une paire de séquences de caractères : une pour l'entrée et une pour la sortie.

La section [27.5.1] de la norme décrit les exigences et le comportement des classes de tampons de flux. Cette section (trois paragraphes) est reproduite ici, pour plus de simplicité et d'exactitude.

1.
Les tampons de flux peuvent imposer diverses contraintes sur les séquences qu'ils contrôlent. Certaines contraintes sont :
•
La séquence d'entrée contrôlée peut ne pas être lisible.
•
La séquence de sortie contrôlée peut ne pas être accessible en écriture.
•
Les séquences contrôlées peuvent être associées au contenu d'autres représentations de séquences de caractères, telles que des fichiers externes.
•
Les séquences contrôlées peuvent prendre en charge des opérations *directement* vers ou depuis des séquences associées.
•
Les séquences contrôlées peuvent imposer des limitations sur la façon dont le programme peut lire des caractères d'une séquence, écrire des caractères dans une séquence, remettre des caractères dans une séquence d'entrée ou modifier la position du flux.
2.
Chaque séquence est caractérisée par trois pointeurs qui, s'ils ne sont pas nuls, pointent tous vers le même objet tableau charT. Le tableau objet représente, à tout moment, une (sous-)séquence de caractères de la séquence. Les opérations effectuées sur une séquence modifient les valeurs stockées dans ces pointeurs, effectuent des lectures et des écritures directement vers ou depuis des séquences associées, et modifient *la position du flux* et l'état de conversion si nécessaire pour maintenir cette relation de sous-séquence. Les trois pointeurs sont :
•
le *pointeur de début*, ou l'adresse du premier élément du tableau (appelé *xbeg* ici) ;
•
le *pointeur suivant*, ou l'adresse du prochain élément qui est un candidat actuel pour la lecture ou l'écriture (appelé *xnext* ici) ;
•
le *pointeur de fin*, ou l'adresse du premier élément après la fin du tableau (appelé *xend* ici).
3.
Les contraintes sémantiques suivantes doivent toujours s'appliquer pour tout ensemble de trois pointeurs pour une séquence, en utilisant les noms de pointeurs donnés immédiatement ci-dessus :
•
Si *xnext* n'est pas un pointeur nul, alors *xbeg* et *xend* doivent également être des pointeurs non nuls dans le même tableau charT, comme décrit ci-dessus ; sinon, *xbeg* et *xend* doivent également être nuls.
•
Si *xnext* n'est pas un pointeur nul et *xnext* < *xend* pour une séquence de sortie, alors une *position d'écriture* est disponible. Dans ce cas, *xnext* doit être assignable comme prochain élément à écrire (pour mettre, ou stocker une valeur de caractère, dans la séquence).
•
Si *xnext* n'est pas un pointeur nul et *xbeg* < *xnext* pour une séquence d'entrée, alors une *position de remise en arrière* est disponible. Dans ce cas, xnext[-1] doit avoir une valeur définie et est le prochain élément (précédent) où stocker un caractère qui est remis dans la séquence d'entrée.
•
Si *xnext* n'est pas un pointeur nul et *xnext*< *xend* pour une séquence d'entrée, alors une *position de lecture* est disponible. Dans ce cas, *xnext* doit avoir une valeur définie et est le prochain élément à lire (pour obtenir, ou obtenir une valeur de caractère, de la séquence).

    template<typename _CharT, typename _Traits> virtual int_type std::basic_streambuf< _CharT, _Traits >::overflow (int_type __c = traits_type::eof()) [inline], [protected], [virtual]

    Consomme des données du tampon ; écrit dans la séquence contrôlée.

    Paramètres

    __c Un caractère supplémentaire à consommer.

    Retourne

    eof() pour indiquer un échec, autre chose (généralement __c, ou not_eof())

    Informellement, cette fonction est appelée lorsque le tampon de sortie est plein (ou n'existe pas, car la mise en tampon n'est pas obligatoire). Si un tampon existe, il est *consommé*, avec *un certain effet* sur la séquence contrôlée. (Typiquement, le tampon est écrit dans la séquence telle quel.) Dans les deux cas, le caractère *c* est également écrit, si *__c* n'est pas eof().

    Pour une définition formelle de cette fonction, consultez un bon ouvrage tel que Langer & Kreft, ou [27.5.2.4.5]/3-7.

    Un streambuf de sortie fonctionnel peut être créé en ne redéfinissant que cette fonction (aucune zone tampon ne sera utilisée).

    Note

    La version de la classe de base ne fait rien, renvoie eof().

    Detailed Description

    Le modèle de classe std::basic_streambuf est le tampon de base pour les flux de caractères de la bibliothèque standard C++. Il gère la gestion des tampons d'entrée et de sortie, et fournit une interface virtuelle pour interagir avec les caractères.

    Les classes dérivées, telles que std::basic_filebuf, std::basic_stringbuf, et std::basic_stringstream, implémentent des stratégies de gestion de tampon spécifiques.

    Les méthodes virtuelles principales qui sont destinées à être redéfinies par les classes dérivées sont :

    underflow()
    Lit le caractère suivant disponible dans le tampon d'entrée.
    overflow(char_type __c = traits_type::eof())
    Écrit un caractère dans le tampon de sortie.
    seekoff(off_type __offset, std::ios_base::seekdir __way, std::ios_base::openmode __mode = std::ios_base::in | std::ios_base::out)
