sous-programme stbt06 (real rcond, real rcondc, character uplo, character diag, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) work, real rat)

STBT06

But :

!>
!> STBT06 calcule un ratio de test comparant RCOND (l'inverse du
!> conditionnement d'une matrice triangulaire A) et RCONDC, l'estimation
!> calculée par STBCON. Les informations sur la matrice triangulaire A
!> sont utilisées si une estimation est nulle et l'autre non nulle pour
!> décider si le sous-dépassement de l'estimation est justifié.
!>

Paramètres

RCOND 
!>          RCOND est REAL
!>          L'estimation du conditionnement inverse obtenue en formant
!>          l'inverse explicite de la matrice A et en calculant
!>          RCOND = 1/( norm(A) * norm(inv(A)) ).
!>

RCONDC

!>          RCONDC est REAL
!>          L'estimation du conditionnement inverse calculée par
!>          STBCON.
!>

UPLO

!>          UPLO est CHARACTER
!>          Spécifie si la matrice A est triangulaire supérieure ou
!>          inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est CHARACTER
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales ou de sous-diagonales de la
!>          matrice bande triangulaire A.  KD >= 0.
!>

AB

!>          AB est un tableau REAL, dimension (LDAB,N)
!>          La matrice bande triangulaire supérieure ou inférieure A,
!>          stockée dans les kd+1 premières lignes du tableau. La j-ème
!>          colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

WORK

!>          WORK est un tableau REAL, dimension (N)
!>

RAT

!>          RAT est REAL
!>          Le ratio de test.  Si RCOND et RCONDC sont tous deux non nuls,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, les deux estimations sont exactement identiques.
!>
