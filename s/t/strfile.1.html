strfile(1)

Paquet: fortune-mod

Licences: BSD-4-Clause-UC

STRFILE(1) 4e distribution Berkeley STRFILE(1)

NOM

strfile - crée un fichier à accès aléatoire pour stocker des chaînes
unstr - déverse des chaînes dans l'ordre des pointeurs

SYNTAXE


strfile [-iorsx]
[-c caractère]
fichier source
[fichier sortie]


unstr [-c caractère]
fichier données.[ext]
[fichier sortie]

DESCRIPTION

strfile lit un fichier contenant des groupes de lignes séparés par une ligne contenant un seul signe pour cent `%` (ou un autre caractère délimiteur spécifié) et crée un fichier de données contenant une structure d'en-tête et une table des décalages de fichier pour chaque groupe de lignes. Cela permet un accès aléatoire aux chaînes.

Le fichier de sortie, s'il n'est pas spécifié sur la ligne de commande, est nommé fichier source.dat.

Le but de unstr est d'annuler le travail de strfile. Il imprime les chaînes contenues dans le fichier source, qui est fichier données.ext sans son extension, ou fichier données si aucune extension n'est spécifiée (dans ce cas, l'extension .dat est ajoutée au nom du fichier de données) dans l'ordre où elles sont listées dans le fichier d'en-tête fichier données. Si aucun fichier sortie n'est spécifié, il imprime sur la sortie standard ; sinon, il imprime sur le fichier spécifié. unstr peut également changer universellement le caractère délimiteur dans un fichier de chaînes. Il est possible de créer des versions triées des fichiers d'entrée en utilisant strfile -o puis en utilisant unstr pour les déverser dans l'ordre de la table.

Options

Les options sont les suivantes :

-c caractère

Change le caractère délimiteur du signe pour cent à caractère. Cette option est disponible pour strfile et unstr.

-i

Ignore la casse lors du tri des chaînes.

-o

Trie les chaînes par ordre alphabétique. La table des décalages sera triée par ordre alphabétique des groupes de lignes référencés. Tous les caractères non alphanumériques initiaux sont ignorés. Cette option provoque le réglage du bit STR_ORDERED dans le champ str_flags de l'en-tête. (Elle trie réellement maintenant ! Ce n'était pas le cas avant).

-r

Randomise l'accès aux chaînes. Les entrées de la table des décalages seront ordonnées aléatoirement. Cette option provoque le réglage du bit STR_RANDOM dans le champ str_flags de l'en-tête. (Et randomise réellement)

-s

Fonctionne silencieusement ; ne donne pas de message récapitulatif une fois terminé.

-x

Notez que chaque caractère alphabétique des groupes de lignes est décalé de 13 positions dans un simple chiffrement de César. Cette option provoque le réglage du bit STR_ROTATED dans le champ str_flags de l'en-tête. Notez qu'elle ne déchiffre pas les chaînes ; cette opération doit être effectuée séparément.

En-tête

Le format de l'en-tête est :

#define VERSION 1 unsigned long str_version; /* numéro de version */ unsigned long str_numstr; /* # de chaînes dans le fichier */ unsigned long str_longlen; /* longueur de la plus longue chaîne */ unsigned long str_shortlen; /* longueur de la chaîne la plus courte */ #define STR_RANDOM 0x1 /* pointeurs randomisés */ #define STR_ORDERED 0x2 /* pointeurs ordonnés */ #define STR_ROTATED 0x4 /* texte rot-13'd */ unsigned long str_flags; /* champ de bits pour les drapeaux */ char str_delim; /* caractère délimiteur */

Tous les champs sont écrits en ordre d'octets réseau.

BOGUES

Moins maintenant, on l'espère. Cependant, les fortunes (chaînes de texte) commençant par une ligne vide semblent être triées entre des lettres aléatoires. Cela inclut l'art ASCII qui ne contient pas de lettres, et les premières lignes qui sont uniquement des caractères non alphanumériques, apparemment. Je n'ai aucune idée de pourquoi cela devrait être le cas.

AUTRES UTILISATIONS

Que pouvez-vous faire avec ceci, à part imprimer des messages sarcastiques et obscènes sur les écrans des utilisateurs à la connexion ou à la déconnexion ?

Il y a d'autres possibilités. Le code source d'un programme d'exemple, randstr, est inclus dans cette distribution : randstr fait la différence entre unstr et fortune. Il lit un seul fichier spécifié et sélectionne aléatoirement une seule chaîne de texte.

1

Incluez strfile.h dans un programme de lecture/publication de nouvelles, pour générer des signatures aléatoires. Tin(1) fait quelque chose de similaire, de manière beaucoup plus complexe.

2

Incluez-le dans un jeu. Bien que strfile ne supporte pas les 'champs' ou les 'enregistrements', il n'y a aucune raison pour que les chaînes de texte ne soient pas cohérentes : première ligne, un jet de dé ; deuxième ligne, un score ; troisième ligne et suivantes, un message texte.

3

Utilisez-le pour stocker votre carnet d'adresses. Diantre, certains des gars que je connais feraient aussi bien de l'utiliser pour décider qui appeler le vendredi soir (et pour certains, peu importe s'il y avait des numéros de téléphone dedans ou non).

4

Utilisez-le dans des situations de 'loterie'. Si vous êtes un fournisseur d'accès à Internet, écrivez un script pour stocker des noms de connexion et des GECOS de /etc/passwd au format strfile, écrivez-en un autre pour envoyer 'félicitations, vous avez gagné' au login chanceux sélectionné. Le prix pourrait être un mois de service gratuit, ou si vous êtes AOL, un mois gratuit sur un vrai fournisseur de services.

VOIR AUSSI

HISTORIQUE

L'utilitaire strfile est apparu pour la première fois dans 4.4BSD. Cette version a été considérablement modifiée, en grande partie de manière spécifique à Linux. Des travaux ont depuis été effectués pour rendre le code plus générique, et il a été testé avec succès sur SunOS 4.x. D'autres plateformes devraient être supportées au fur et à mesure des travaux.
