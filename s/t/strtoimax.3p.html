STRTOIMAX(3P) Manuel du programmeur POSIX STRTOIMAX(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

strtoimax, strtoumax — convertir une chaîne en type entier

SYNTAXE

#include <inttypes.h>
intmax_t strtoimax(const char *restrict nptr, char **restrict endptr,
    int base);
uintmax_t strtoumax(const char *restrict nptr, char **restrict endptr,
    int base);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions doivent être équivalentes aux fonctions strtol(), strtoll(), strtoul() et strtoull(), à l'exception près que la partie initiale de la chaîne doit être convertie en représentation intmax_t et uintmax_t, respectivement.

VALEUR DE RETOUR

Ces fonctions doivent retourner la valeur convertie, le cas échéant.

Si aucune conversion n'a pu être effectuée, zéro doit être retourné et errno peut être défini à [EINVAL].

Si la valeur de base n'est pas prise en charge, 0 doit être retourné et errno doit être défini à [EINVAL].

Si la valeur correcte est en dehors de la plage des valeurs représentables, {INTMAX_MAX}, {INTMAX_MIN} ou {UINTMAX_MAX} doit être retourné (selon le type de retour et le signe de la valeur, le cas échéant), et errno doit être défini à [ERANGE].

ERREURS

Ces fonctions échoueront si :

EINVAL
La valeur de base n'est pas prise en charge.
ERANGE
La valeur à retourner n'est pas représentable.

Ces fonctions peuvent échouer si :

EINVAL
Aucune conversion n'a pu être effectuée.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

Étant donné que la valeur de *endptr n'est pas spécifiée si la valeur de base n'est pas prise en charge, les applications doivent soit s'assurer que base a une valeur prise en charge (0 ou comprise entre 2 et 36) avant l'appel, soit vérifier une erreur [EINVAL] avant d'examiner *endptr.
