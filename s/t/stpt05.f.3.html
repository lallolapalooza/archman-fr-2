Documentation de la fonction/sous-routine

sous-routine stpt05 (caractère uplo, caractère trans, caractère diag, entier n, entier nrhs, réel, dimension( * ) ap, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldxact, * ) xact, entier ldxact, réel, dimension( * ) ferr, réel, dimension( * ) berr, réel, dimension( * ) reslts)

STPT05

Objectif :

!>
!> STPT05 teste les bornes d'erreur issues du raffinement itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une matrice
!> triangulaire en stockage compacté.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce ratio n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la sous-routine de raffinement itératif
!>           = le maximum de BERR / ( (n+1)*EPS + (*) ), où
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B  (Pas de transposée)
!>          = 'T':  A'* X = B  (Transposée)
!>          = 'C':  A'* X = B  (Transposée conjuguée = Transposée)
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

N

!>          N est ENTIER
!>          Le nombre de lignes des matrices X, B et XACT, et l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de colonnes des matrices X, B et XACT.
!>          NRHS >= 0.
!>

AP

!>          AP est tableau REEL, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, stockée en colonne
!>          dans un tableau linéaire.  La j-ième colonne de A est stockée dans
!>          le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés être 1.
!>

B

!>          B est tableau REEL, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension de tête du tableau B.  LDB >= max(1,N).
!>

X

!>          X est tableau REEL, dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés. Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est ENTIER
!>          La dimension de tête du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est tableau REEL, dimension (LDX,NRHS)
!>          Les vecteurs solutions exacts. Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est ENTIER
!>          La dimension de tête du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est tableau REEL, dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur solution
!>          X.  Si XTRUE est la vraie solution, FERR borne la magnitude de
!>          la plus grande entrée de (X - XTRUE) divisée par la magnitude de
!>          la plus grande entrée de X.
!>

BERR

!>          BERR est tableau REEL, dimension (NRHS)
!>          L'erreur relative composante par composante de chaque vecteur solution
!>          (c'est-à-dire, le plus petit changement relatif dans une entrée de A
!>          ou B qui rend X une solution exacte).
!>

RESLTS

!>          RESLTS est tableau REEL, dimension (2)
!>          Le maximum sur les vecteurs solutions NRHS des ratios :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
