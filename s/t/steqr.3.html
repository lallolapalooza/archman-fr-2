sous-routine csteqr (character compz, integer n, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer info)

CSTEQR

Objectif :

!>
!> CSTEQR calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice triangulaire symétrique en utilisant la méthode QR ou QL implicite.
!> Les vecteurs propres d'une matrice hermitienne complexe pleine ou bande peuvent également être trouvés
!> si CHETRD, CHPTRD ou CHBTRD ont été utilisés pour réduire cette matrice à la forme triangulaire.
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres.
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres de la
!>                  matrice hermitienne d'origine. En entrée, Z doit contenir la
!>                  matrice unitaire utilisée pour réduire la matrice d'origine
!>                  à la forme triangulaire.
!>          = 'I':  Calculer les valeurs propres et les vecteurs propres de la
!>                  matrice triangulaire. Z est initialisée à la matrice identité.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N >= 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          En entrée, les éléments diagonaux de la matrice triangulaire.
!>          En sortie, si INFO = 0, les valeurs propres dans l'ordre croissant.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>          En entrée, les éléments sous-diagonaux (n-1) de la matrice triangulaire.
!>          En sortie, E est détruit.
!>

Z

!>          Z est un tableau COMPLEX, dimension (LDZ, N)
!>          En entrée, si COMPZ = 'V', alors Z contient la matrice unitaire
!>          utilisée dans la réduction à la forme triangulaire.
!>          En sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormés de la matrice hermitienne d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormés
!>          de la matrice triangulaire symétrique.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          des vecteurs propres sont souhaités, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (max(1,2*N-2))
!>          Si COMPZ = 'N', alors WORK n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  l'algorithme n'a pas réussi à trouver toutes les valeurs propres en
!>                un total de 30*N itérations ; si INFO = i, alors i
!>                éléments de E n'ont pas convergé vers zéro ; en sortie, D
!>                et E contiennent les éléments d'une matrice triangulaire symétrique
!>                qui est unitairement similaire à la matrice d'origine.
!>

steqr(3) - LAPACK - Arch Linux

NAME

steqr - computes all eigenvalues and, optionally, eigenvectors of a symmetric tridiagonal matrix

SYNOPSIS

subroutine   ssteqr (character compz, integer n, real, dimension( * ) d, real, dimension( *   ) e, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work,   integer info)
subroutine   zsteqr (character compz, integer n, double precision, dimension( * ) d, double   precision, dimension( * ) e, complex*16, dimension( ldz, * ) z, integer ldz,   double precision, dimension( * ) work, integer info)

Detailed Description

SSTEQR

Purpose:

!>
!> SSTEQR calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice tridiagonale symétrique à l'aide de la méthode implicite QL ou QR.
!> Les vecteurs propres d'une matrice symétrique pleine ou bande peuvent également être trouvés
!> si SSYTRD ou SSPTRD ou SSBTRD a été utilisé pour réduire cette matrice
!> à la forme tridiagonale.
!>

Parameters

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N' : Calculer uniquement les valeurs propres.
!>          = 'V' : Calculer les valeurs propres et les vecteurs propres de la matrice
!>                  symétrique d'origine. À l'entrée, Z doit contenir la
!>                  matrice orthogonale utilisée pour réduire la matrice d'origine
!>                  à la forme tridiagonale.
!>          = 'I' : Calculer les valeurs propres et les vecteurs propres de la
!>                  matrice tridiagonale. Z est initialisée à la matrice identité.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N >= 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          À l'entrée, les éléments diagonaux de la matrice tridiagonale.
!>          À la sortie, si INFO = 0, les valeurs propres par ordre croissant.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>          À l'entrée, les (N-1) éléments sous-diagonaux de la matrice
!>          tridiagonale.
!>          À la sortie, E a été détruit.
!>

Z

!>          Z est un tableau REAL, dimension (LDZ, N)
!>          À l'entrée, si COMPZ = 'V', alors Z contient la matrice orthogonale
!>          utilisée dans la réduction à la forme tridiagonale.
!>          À la sortie, si INFO = 0, alors si COMPZ = 'V', Z contient les
!>          vecteurs propres orthonormés de la matrice symétrique d'origine,
!>          et si COMPZ = 'I', Z contient les vecteurs propres orthonormés
!>          de la matrice tridiagonale symétrique.
!>          Si COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          des vecteurs propres sont désirés, alors LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (max(1,2*N-2))
!>          Si COMPZ = 'N', alors WORK n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : l'algorithme a échoué à trouver toutes les valeurs propres en
!>                un total de 30*N itérations ; si INFO = i, alors i
!>                éléments de E n'ont pas convergé vers zéro ; à la sortie, D
!>                et E contiennent les éléments d'une matrice tridiagonale symétrique
!>                qui est orthogonalement similaire à la matrice d'origine.
!>
