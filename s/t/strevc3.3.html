Documentation de la fonction/sous-programme

subroutine strevc3 (character side, character howmny, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, real, dimension( * ) work, integer lwork, integer info)

STREVC3

Purpose:

!>
!> STREVC3 calcule certains ou tous les vecteurs propres à droite et/ou à gauche
!> d'une matrice T quasi-triangulaire réelle.
!> Les matrices de ce type sont produites par la factorisation de Schur d'une
!> matrice générale réelle :  A = Q*T*Q**T, telle que calculée par SHSEQR.
!>
!> Les vecteurs propres à droite x et à gauche y de T correspondant à une valeur
!> propre w sont définis par :
!>
!>    T*x = w*x,     (y**T)*T = w*(y**T)
!>
!> où y**T dénote la transposée du vecteur y.
!> Les valeurs propres ne sont pas entrées dans cette routine, mais sont lues
!> directement sur les blocs diagonaux de T.
!>
!> Cette routine retourne les matrices X et/ou Y des vecteurs propres à droite et
!> à gauche de T, ou les produits Q*X et/ou Q*Y, où Q est une matrice entrée.
!> Si Q est le facteur orthogonal qui réduit une matrice A à la forme de Schur T,
!> alors Q*X et Q*Y sont les matrices des vecteurs propres à droite et à gauche de A.
!>
!> Ceci utilise une version BLAS de niveau 3 de la rétro-transformation.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R':  calculer uniquement les vecteurs propres à droite ;
!>          = 'L':  calculer uniquement les vecteurs propres à gauche ;
!>          = 'B':  calculer les vecteurs propres à droite et à gauche.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A':  calculer tous les vecteurs propres à droite et/ou à gauche ;
!>          = 'B':  calculer tous les vecteurs propres à droite et/ou à gauche,
!>                  rétro-transformés par les matrices dans VR et/ou VL ;
!>          = 'S':  calculer les vecteurs propres à droite et/ou à gauche sélectionnés,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Si w(j) est une valeur propre réelle, le vecteur propre réel correspondant
!>          est calculé si SELECT(j) est .VRAI..
!>          Si w(j) et w(j+1) sont les parties réelle et imaginaire d'une valeur
!>          propre complexe, le vecteur propre complexe correspondant est calculé si
!>          soit SELECT(j) soit SELECT(j+1) est .VRAI., et à la sortie SELECT(j) est mis
!>          à .VRAI. et SELECT(j+1) est mis à .FAUX..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau REEL, de dimension (LDT,N)
!>          La matrice quasi-triangulaire supérieure T en forme canonique de Schur.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau REEL, de dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit contenir une
!>          matrice Q de taille N*N (généralement la matrice orthogonale Q des
!>          vecteurs de Schur retournée par SHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres à gauche de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres à gauche de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VL, dans le même ordre que leurs valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle, et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL.
!>          LDVL >= 1, et si SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau REEL, de dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit contenir une
!>          matrice Q de taille N*N (généralement la matrice orthogonale Q des
!>          vecteurs de Schur retournée par SHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres à droite de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres à droite de T spécifiés par
!>                           SELECT, stockés consécutivement dans les colonnes
!>                           de VR, dans le même ordre que leurs valeurs propres.
!>          Un vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR.
!>          LDVR >= 1, et si SIDE = 'R' ou 'B', LDVR >= N.
!>

MM

!>          MM est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR réellement
!>          utilisées pour stocker les vecteurs propres.
!>          Si HOWMNY = 'A' ou 'B', M est mis à N.
!>          Chaque vecteur propre réel sélectionné occupe une colonne et chaque
!>          vecteur propre complexe sélectionné occupe deux colonnes.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,3*N).
!>          Pour des performances optimales, LWORK >= N + 2*N*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne cette
!>          valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!>
!>  L'algorithme utilisé dans ce programme est essentiellement une substitution
!>  arrière (avant), avec mise à l'échelle pour rendre le code robuste contre
!>  d'éventuels débordements.
!>
!>  Chaque vecteur propre est normalisé de sorte que l'élément de plus grande
!>  magnitude ait une magnitude de 1 ; ici, la magnitude d'un nombre complexe
!>  (x,y) est prise comme |x| + |y|.
!>
