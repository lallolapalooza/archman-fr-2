Description détaillée

template<typename _Bi_iter, typename _Alloc = allocator<sub_match<_Bi_iter> >>

class std::match_results< _Bi_iter, _Alloc >"Les résultats d'une opération de correspondance ou de recherche.

Une collection de séquences de caractères représentant le résultat d'une correspondance d'expression régulière. Le stockage de la collection est alloué et libéré au besoin par les fonctions membres de la classe template match_results.

Cette classe satisfait les exigences de la Séquence, à l'exception du fait que seules les opérations définies pour une Séquence qualifiée de const sont supportées.

L'objet sub_match stocké à l'index 0 représente la sous-expression 0, c'est-à-dire la correspondance entière. Dans ce cas, le membre matched de sub_match est toujours vrai. L'objet sub_match stocké à l'index n désigne ce qui correspond à la sous-expression marquée n dans l'expression correspondante. Si la sous-expression n a participé à une correspondance d'expression régulière, alors le membre matched de sub_match est vrai, et les membres first et second désignent la plage de caractères [first, second) qui a formé cette correspondance.
