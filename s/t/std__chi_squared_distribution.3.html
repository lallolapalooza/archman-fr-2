Detailed Description

The distribution is the continuous distribution of the sum of the squares of n independent standard normal random variables, where n is the number of degrees of freedom.

The probability density function (PDF) is:

  f(x; n) = (x^(n/2 - 1) * exp(-x/2)) / (2^(n/2) * Gamma(n/2))

for x > 0, where n is the number of degrees of freedom.

The cumulative distribution function (CDF) is:

  F(x; n) = Gamma(n/2, x/2) / Gamma(n/2)

where Gamma(a, x) is the incomplete gamma function.
