Description détaillée

Espace de noms ISO C++ 2014 pour les suffixes des littéraux de durée.

Ces suffixes peuvent être utilisés pour créer des valeurs chrono::duration avec des périodes d'horloge d'heures, de minutes, de secondes, de millisecondes, de microsecondes ou de nanosecondes. Par exemple, std::chrono::seconds(5) peut être écrit comme 5s après avoir rendu le suffixe visible dans la portée actuelle. Les suffixes peuvent être rendus visibles par une directive using ou une déclaration using telles que :

  • using namespace std::chrono_literals;
  • using namespace std::literals;
  • using namespace std::chrono;
  • using namespace std;
  • using std::chrono_literals::operator""s;

Le résultat de ces suffixes sur un littéral entier est l'un des typedefs standard tels que std::chrono::hours. Le résultat sur un littéral à virgule flottante est un type de durée avec la période d'horloge spécifiée et une représentation à virgule flottante non spécifiée, par exemple 1.5e2ms pourrait être équivalent à chrono::duration<long double, chrono::milli>(1.5e2).
