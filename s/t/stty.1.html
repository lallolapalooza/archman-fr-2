STTY(1) Commandes utilisateur STTY(1)

NOM

stty - changer et afficher les paramètres de ligne du terminal

SYNTAXE

stty [-F PÉRIPHÉRIQUE | --fichier=PÉRIPHÉRIQUE] [PARAMÈTRE]...
stty [-F PÉRIPHÉRIQUE | --fichier=PÉRIPHÉRIQUE] [-a|--tous]
stty [-F PÉRIPHÉRIQUE | --fichier=PÉRIPHÉRIQUE] [-g|--sauvegarder]

DESCRIPTION

Affiche ou modifie les caractéristiques du terminal.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-a, --tous
affiche tous les paramètres actuels sous une forme lisible par l'homme
-g, --sauvegarder
affiche tous les paramètres actuels sous une forme lisible par stty
-F, --fichier=PÉRIPHÉRIQUE
ouvre et utilise PÉRIPHÉRIQUE à la place de l'entrée standard
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Un - optionnel avant PARAMÈTRE indique une négation. Un * marque les paramètres non-POSIX. Le système sous-jacent définit quels paramètres sont disponibles.

Caractères spéciaux:

* annuler_envoi CHAR
CHAR activera l'annulation de l'envoi de la sortie
eof CHAR
CHAR enverra une fin de fichier (terminera l'entrée)
eol CHAR
CHAR terminera la ligne
* eol2 CHAR
CHAR alternatif pour terminer la ligne
effacer CHAR
CHAR effacera le dernier caractère tapé
intr CHAR
CHAR enverra un signal d'interruption
tuer CHAR
CHAR effacera la ligne actuelle
* lnext CHAR
CHAR entrera dans le prochain caractère cité
quitter CHAR
CHAR enverra un signal de quitter
* rprnt CHAR
CHAR redessinera la ligne actuelle
démarrer CHAR
CHAR redémarrera la sortie après l'avoir arrêtée
arrêter CHAR
CHAR arrêtera la sortie
susp CHAR
CHAR enverra un signal d'arrêt de terminal
* swtch CHAR
CHAR passera à une couche de shell différente
* werase CHAR
CHAR effacera le dernier mot tapé

Paramètres spéciaux:

N
définit les vitesses d'entrée et de sortie à N bauds
cols N
indique au noyau que le terminal a N colonnes
* colonnes N
identique à cols N
* [-]vider
attend la transmission avant d'appliquer les paramètres (activé par défaut)
vitesse_entrée N
définit la vitesse d'entrée à N
* ligne N
utilise la discipline de ligne N
min N
avec -icanon, définit N caractères minimum pour une lecture terminée
vitesse_sortie N
définit la vitesse de sortie à N
lignes N
indique au noyau que le terminal a N lignes
taille
affiche le nombre de lignes et de colonnes selon le noyau
vitesse
affiche la vitesse du terminal
temps N
avec -icanon, définit le délai de lecture à N dixièmes de seconde

Paramètres de contrôle:

[-]clocal
désactive les signaux de contrôle du modem
[-]cread
autorise la réception des entrées
* [-]crtscts
active la négociation RTS/CTS
csN
définit la taille des caractères à N bits, N dans [5..8]
[-]cstopb
utilise deux bits d'arrêt par caractère (un avec '-')
[-]hup
envoie un signal de déconnexion lorsque le dernier processus ferme le tty
[-]hupcl
identique à [-]hup
[-]parenb
génère un bit de parité en sortie et attend un bit de parité en entrée
[-]parodd
définit la parité impaire (ou paire avec '-')
* [-]cmspar
utilise la parité "mark"/"space"

Paramètres d'entrée:

[-]brkint
les interruptions provoquent un signal d'interruption
[-]icrnl
traduit le retour chariot en nouvelle ligne
[-]ignbrk
ignore les caractères d'interruption
[-]igncr
ignore le retour chariot
[-]ignpar
ignore les caractères avec erreurs de parité
* [-]imaxbel
émet un bip et ne vide pas un tampon d'entrée plein lors d'un caractère
[-]inlcr
traduit la nouvelle ligne en retour chariot
[-]inpck
active la vérification de parité en entrée
[-]istrip
efface le 8ème bit (le plus significatif) des caractères d'entrée
* [-]iutf8
suppose que les caractères d'entrée sont codés en UTF-8
* [-]iuclc
traduit les caractères majuscules en minuscules
* [-]ixany
laisse n'importe quel caractère redémarrer la sortie, pas seulement le caractère de démarrage
[-]ixoff
active l'envoi de caractères de démarrage/arrêt
[-]ixon
active le contrôle de flux XON/XOFF
[-]parmrk
marque les erreurs de parité (avec une séquence de caractères 255-0-)
[-]tandem
identique à [-]ixoff

Paramètres de sortie:

* bsN
style de délai de retour arrière, N dans [0..1]
* crN
style de délai de retour chariot, N dans [0..3]
* ffN
style de délai de saut de page, N dans [0..1]
* nlN
style de délai de nouvelle ligne, N dans [0..1]
* [-]ocrnl
traduit le retour chariot en nouvelle ligne
* [-]ofdel
utilise des caractères effacer pour le remplissage au lieu des caractères NUL
* [-]ofill
utilise des caractères de remplissage (remplissage) au lieu de temporisation pour les délais
* [-]olcuc
traduit les caractères minuscules en majuscules
* [-]onlcr
traduit la nouvelle ligne en retour chariot-nouvelle ligne
* [-]onlret
la nouvelle ligne effectue un retour chariot
* [-]onocr
n'affiche pas de retours chariot dans la première colonne
[-]opost
post-traite la sortie
* tabN
style de délai de tabulation horizontale, N dans [0..3]
* tabs
identique à tab0
* -tabs
identique à tab3
* vtN
style de délai de tabulation verticale, N dans [0..1]

Paramètres locaux:

[-]crterase
affiche les caractères d'effacement sous forme de retour arrière-espace-retour arrière
* crtkill
tue toute la ligne en respectant les paramètres echoprt et echoe
* -crtkill
tue toute la ligne en respectant les paramètres echoctl et echok
* [-]ctlecho
affiche les caractères de contrôle

sane
identique à cread -ignbrk brkint -inlcr -igncr icrnl icanon iexten echo echoe echok -echonl -noflsh -ixoff -iutf8 -iuclc -ixany imaxbel -xcase -olcuc -ocrnl opost -ofill onlcr -onocr -onlret nl0 cr0 tab0 bs0 vt0 ff0 isig -tostop -ofdel -echoprt echoctl echoke -extproc -flusho, tous les caractères spéciaux à leurs valeurs par défaut

Gère la ligne tty connectée à l'entrée standard. Sans arguments, affiche le débit en bauds, la discipline de ligne et les écarts par rapport à stty sane. Dans les paramètres, CHAR est pris littéralement, ou codé comme dans ^c, 0x37, 0177 ou 127 ; les valeurs spéciales ^- ou undef sont utilisées pour désactiver les caractères spéciaux.
