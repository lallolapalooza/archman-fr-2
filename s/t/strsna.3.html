!>
!> STRSNA estime les nombres de condition réciproques pour des
!> valeurs propres et/ou des vecteurs propres droits spécifiés d'une matrice
!> réelle quasi-triangulaire T (ou de toute matrice Q*T*Q**T avec Q
!> orthogonale).
!>
!> T doit être sous forme canonique de Schur (comme retournée par SHSEQR), c'est-à-dire
!> triangulaire supérieure par blocs avec des blocs diagonaux de 1x1 et 2x2 ; chaque
!> bloc diagonal de 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonaux de signes opposés.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (SEP) :
!>          = 'E' : pour les valeurs propres uniquement (S) ;
!>          = 'V' : pour les vecteurs propres uniquement (SEP) ;
!>          = 'B' : pour les valeurs propres et les vecteurs propres (S et SEP).
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calcule les nombres de condition pour toutes les paires propres ;
!>          = 'S' : calcule les nombres de condition pour les paires propres sélectionnées
!>                 spécifiées par le tableau SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour lesquelles
!>          les nombres de condition sont requis. Pour sélectionner les nombres de condition
!>          correspondant à une valeur propre réelle w(j),
!>          SELECT(j) doit être mis à .VRAI.. Pour sélectionner les nombres de condition
!>          correspondant à une paire de valeurs propres conjuguées w(j)
!>          et w(j+1), SELECT(j) ou SELECT(j+1) ou les deux doivent
!>          être mis à .VRAI..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est un entier
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau REEL, de dimension (LDT,N)
!>          La matrice quasi-triangulaire supérieure T, sous forme canonique de Schur.
!>

LDT

!>          LDT est un entier
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau REEL, de dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres gauches de T
!>          (ou de toute Q*T*Q**T avec Q orthogonale), correspondant aux
!>          paires propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VL, comme retournés par
!>          SHSEIN ou STREVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un entier
!>          La dimension principale du tableau VL.
!>          LDVL >= 1 ; et si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau REEL, de dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres droits de T
!>          (ou de toute Q*T*Q**T avec Q orthogonale), correspondant aux
!>          paires propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VR, comme retournés par
!>          SHSEIN ou STREVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un entier
!>          La dimension principale du tableau VR.
!>          LDVR >= 1 ; et si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau REEL, de dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments consécutifs du
!>          tableau. Pour une paire de valeurs propres conjuguées, deux
!>          éléments consécutifs de S sont mis à la même valeur. Ainsi
!>          S(j), SEP(j), et les j-èmes colonnes de VL et VR correspondent tous
!>          à la même paire propre (mais pas nécessairement à la j-ème paire propre,
!>          sauf si toutes les paires propres sont sélectionnées).
!>          Si JOB = 'V', S n'est pas référencé.
!>

SEP

!>          SEP est un tableau REEL, de dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés des
!>          vecteurs propres sélectionnés, stockés dans des éléments consécutifs du
!>          tableau. Pour un vecteur propre complexe, deux
!>          éléments consécutifs de SEP sont mis à la même valeur. Si
!>          les valeurs propres ne peuvent pas être réordonnées pour calculer SEP(j), SEP(j)
!>          est mis à 0 ; cela ne peut arriver que lorsque la valeur réelle serait
!>          très petite de toute façon.
!>          Si JOB = 'E', SEP n'est pas référencé.
!>

MM

!>          MM est un entier
!>          Le nombre d'éléments dans les tableaux S (si JOB = 'E' ou 'B')
!>           et/ou SEP (si JOB = 'V' ou 'B'). MM >= M.
!>

M

!>          M est un entier
!>          Le nombre d'éléments des tableaux S et/ou SEP réellement
!>          utilisés pour stocker les nombres de condition estimés.
!>          Si HOWMNY = 'A', M est mis à N.
!>

WORK

!>          WORK est un tableau REEL, de dimension (LDWORK,N+6)
!>          Si JOB = 'E', WORK n'est pas référencé.
!>

LDWORK

!>          LDWORK est un entier
!>          La dimension principale du tableau WORK.
!>          LDWORK >= 1 ; et si JOB = 'V' ou 'B', LDWORK >= N.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (2*(N-1))
!>          Si JOB = 'E', IWORK n'est pas référencé.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  L'inverse du nombre de condition d'une valeur propre lambda est
!>  défini comme
!>
!>          S(lambda) = |v**T*u| / (norm(u)*norm(v))
!>
!>  où u et v sont les vecteurs propres droit et gauche de T correspondant
!>  à lambda ; v**T dénote la transposée de v, et norm(u)
!>  dénote la norme euclidienne. Ces nombres de condition réciproques se situent toujours
!>  entre zéro (très mal conditionné) et un (très bien
!>  conditionné). Si n = 1, S(lambda) est défini comme 1.
!>
!>  Une borne d'erreur approximative pour une valeur propre calculée W(i) est donnée par
!>
!>                      EPS * norm(T) / S(i)
!>
!>  où EPS est la précision machine.
!>
!>  L'inverse du nombre de condition du vecteur propre droit u
!>  correspondant à lambda est défini comme suit. Supposons
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!>  Alors le nombre de condition réciproque est
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!>  où sigma-min dénote la plus petite valeur singulière. Nous approximons
!>  la plus petite valeur singulière par l'inverse d'une estimation de
!>  la norme un de l'inverse de T22 - lambda*I. Si n = 1, SEP(1) est
!>  défini comme abs(T(1,1)).
!>
!>  Une app

      SUBROUTINE STRSNA( JOB, HOWMNY, SELECT, N, A, LDA, VL,
     $                   LDVL, VR, LDVR, SCOMP, SEP, WORK, INFO )

      CHARACTER          JOB
      CHARACTER          HOWMNY
      LOGICAL            SELECT( * )
      INTEGER            N, LDA, LDVL, LDVR, INFO
      REAL               A( LDA, * ), VL( LDVL, * ), VR( LDVR, * )
      REAL               SCOMP( * ), SEP( * ), WORK( * )

Function/Subroutine Documentation

strsna computes the reciprocal condition numbers for selected eigenvalues and their corresponding right eigenvectors.

An eigenvector v corresponding to the eigenvalue lambda is a condition number sep which is the reciprocal of the norm of the left eigenvector u corresponding to the same eigenvalue.

It is the condition number of the eigenvector, so that the forward error dv is bounded by:

    ||dv|| / ||v|| <= sep * ||da||

where da is the forward error in the matrix A.

The approximate error bound for a computed right eigenvector VR(i) is given by

                      EPS * norm(T) / SEP(i)
