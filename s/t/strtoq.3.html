strtol(3) Manuel des fonctions de bibliothèque strtol(3)

NOM

strtol, strtoll, strtoq - convertir une chaîne en un entier long

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
long strtol(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
long long strtoll(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

strtoll():

    _ISOC99_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

La fonction strtol() convertit la partie initiale de la chaîne nptr en une valeur entière longue selon la base donnée, qui doit être comprise entre 2 et 36 inclusivement, ou être la valeur spéciale 0.

La chaîne peut commencer par une quantité arbitraire d'espaces blancs (tels que déterminés par isspace(3)) suivie d'un signe '+' ou '-' optionnel. Si la base est zéro ou 16, la chaîne peut ensuite inclure le préfixe "0x" ou "0X", et le nombre sera lu en base 16 ; si la base est zéro ou 2, la chaîne peut ensuite inclure le préfixe "0b" ou "0B", et le nombre sera lu en base 2 ; sinon, une base nulle est prise comme 10 (décimal) sauf si le caractère suivant est '0', auquel cas elle est prise comme 8 (octal).

Le reste de la chaîne est converti en une valeur long de la manière évidente, s'arrêtant au premier caractère qui n'est pas un chiffre valide dans la base donnée. (Dans les bases supérieures à 10, la lettre 'A', en majuscule ou minuscule, représente 10, 'B' représente 11, et ainsi de suite, jusqu'à 'Z' représentant 35.)

Si endptr n'est pas NULL, et que la base est supportée, strtol() stocke l'adresse du premier caractère invalide dans *endptr. S'il n'y avait aucun chiffre du tout, strtol() stocke la valeur originale de nptr dans *endptr (et retourne 0). En particulier, si *nptr n'est pas '\0' mais **endptr est '\0' au retour, la chaîne entière est valide.

La fonction strtoll() fonctionne exactement comme la fonction strtol() mais retourne une valeur entière long long.

VALEUR DE RETOUR

La fonction strtol() retourne le résultat de la conversion, à moins que la valeur ne provoque un dépassement inférieur ou supérieur. Si un dépassement inférieur se produit, strtol() retourne LONG_MIN. Si un dépassement supérieur se produit, strtol() retourne LONG_MAX. Dans les deux cas, errno est défini à ERANGE. Exactement la même chose s'applique à strtoll() (avec LLONG_MIN et LLONG_MAX au lieu de LONG_MIN et LONG_MAX).

ERREURS

Cette fonction ne modifie pas errno en cas de succès.

EINVAL
(pas dans C99) La base donnée contient une valeur non supportée.
ERANGE
La valeur résultante était hors limites.

L'implémentation peut également définir errno à EINVAL si aucune conversion n'a été effectuée (aucun chiffre trouvé, et 0 retourné).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strtol (), strtoll (), strtoq () Sécurité des threads MT-Safe locale

VERSIONS

Selon POSIX.1, dans les locales autres que "C" et "POSIX", ces fonctions peuvent accepter d'autres chaînes numériques définies par l'implémentation.

BSD a également


quad_t strtoq(const char *nptr, char **endptr, int base);

avec une définition complètement analogue. Selon la taille du mot de l'architecture actuelle, cela peut être équivalent à strtoll() ou à strtol().

NORMES

C23, POSIX.1-2024.

HISTORIQUE

strtol()
POSIX.1-2001, C89, SVr4, 4.3BSD.
strtoll()
POSIX.1-2001, C99.
"0b", "0B"
C23. glibc 2.38. (Pas dans POSIX.)

AVERTISSEMENTS

Vérifications de plage

Puisque strtol() peut légitimement retourner 0, LONG_MAX, ou LONG_MIN (LLONG_MAX ou LLONG_MIN pour strtoll()) en cas de succès comme d'échec, le programme appelant doit définir errno à 0 avant l'appel, puis déterminer si une erreur s'est produite en vérifiant si errno == ERANGE après l'appel.


errno = 0;
n = strtol(s, &end, base);
if (end == s)
	goto no_number;
if ((errno == ERANGE && n == LONG_MIN) || n < min)
	goto too_low;
if ((errno == ERANGE && n == LONG_MAX) || n > max)
	goto too_high;

base

Si la base doit être testée, elle doit l'être dans un appel où la chaîne est connue pour réussir. Sinon, il est impossible de différencier les erreurs de manière portable.


errno = 0;
strtol("0", NULL, base);
if (errno == EINVAL)
    goto unsupported_base;

BOGUES

Espaces blancs

Ces fonctions acceptent silencieusement les espaces blancs en tête. Pour rejeter les espaces blancs, appelez isspace(3) avant strtol().

EXEMPLES

Le programme présenté ci-dessous démontre l'utilisation de strtol(). Le premier argument de la ligne de commande spécifie une chaîne à partir de laquelle strtol() doit analyser un nombre. Le second argument (optionnel) spécifie la base à utiliser pour la conversion. (Cet argument est converti en forme numérique en utilisant atoi(3), une fonction qui n'effectue aucune vérification d'erreur et a une interface plus simple que strtol().) Quelques exemples des résultats produits par ce programme sont les suivants:


$ ./a.out 123
strtol() a retourné 123
$ ./a.out '    123'
strtol() a retourné 123
$ ./a.out 123abc
strtol() a retourné 123
Caractères supplémentaires après le nombre : "abc"
$ ./a.out 123abc 55
strtol : Argument invalide
$ ./a.out ''
Aucun chiffre n'a été trouvé
$ ./a.out 4000000000
strtol : Résultat numérique hors limites

Source du programme

#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    int base;
    char *endptr, *str;
    long val;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s str [base]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    str = argv[1];
    base = (argc > 2) ? atoi(argv[2]) : 0;
    errno = 0;    /* Pour différencier succès/échec après l'appel */
    strtol("0", NULL, base);
    if (errno == EINVAL) {
        perror("strtol");
        exit(EXIT_FAILURE);
    }
    errno = 0;    /* Pour différencier succès/échec après l'appel */
    val = strtol(str, &endptr, base);
    /* Vérifier diverses erreurs possibles.  */
    if (errno == ERANGE) {
        perror("strtol");
        exit(EXIT_FAILURE);
    }
    if (endptr == str) {
        fprintf(stderr, "Aucun chiffre n'a été trouvé\n");
        exit(EXIT_FAILURE);
    }
    if (*endptr != '\0')
        printf("Caractères supplémentaires après le nombre : \"%s\"\n", endptr);
    if (base == 0) {
        printf("strtol() a interprété la base comme décimale\n");
    }
    else if (base == 2) {
        printf("strtol() a interprété la base comme binaire\n");
    }
    else if (base == 8) {
        printf("strtol() a interprété la base comme octale\n");
    }
    else if (base == 16) {
        printf("strtol() a interprété la base comme hexadécimale\n");
    }
    printf("strtol() a retourné %ld\n", val);
    exit(EXIT_SUCCESS);
}

strtoq(3) - man pages

NAME

strtoq, strtoq_l - convert string to quad-precision number

LIBRARY

Math library (libmath, -lm)

SYNOPSIS

#include <stdlib.h>

long long strtoq(const char *nptr,
                         char **endptr, int base);

#include <locale.h>

long long strtoq_l(const char *nptr,
                         char **endptr, int base);

DESCRIPTION

strtoq() function converts the initial part of the string pointed to by nptr to a long long integer representation. It is equivalent to calling strtoll(3).

strtoq_l() is the same as strtoq() except that it uses the specified locale, locale.

The string is interpreted in the number base specified by base. This argument must be an integer between 2 and 36, or be the special value 0.

If base is 0, the base is inferred from the string itself. If the string begins with ‘0‘, base 8 (octal) is assumed. If the string begins with ‘0x‘ or ‘0X‘, base 16 (hexadecimal) is assumed. Otherwise, base 10 (decimal) is assumed.

If base is 16, the string may begin with optional ‘0x‘ or ‘0X‘.

The string may consist of:

  • Optional white space characters (as determined by the current locale).
  • An optional plus (‘+‘) or minus (‘-‘) sign.
  • A sequence of digits. This sequence must contain at least one digit, and if a sign is present, the sequence must contain at least one digit. Digits are taken from ‘0‘ through ‘9‘. If base is greater than 10, letters from ‘a‘ (or ‘A‘) through the letter corresponding to the value of base are used.

If endptr is not NULL, strtoq() stores the address of the first character after the number in the location pointed to by endptr. If no number could be converted, nptr is stored in the location pointed to by endptr.

If the value of the number is out of range for a long long, the overflow result is returned (see RETURN VALUE). If no value can be converted, 0 is returned, and unless endptr is NULL, endptr is set to point to nptr.

RETURN VALUE

strtoq() returns the converted value. If the value is out of range, it returns LLONG_MAX or LLONG_MIN (see limits.h(3)). If no conversion could be performed, it returns 0.

ERRORS

No errors are set by this function.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

VERSIONS

strtoq() and strtoq_l() are available since glibc 2.1.

STANDARDS

strtoq() and strtoq_l() are POSIX.1-2001 and POSIX.1-2008. The behavior for base being 0 or 16 is specified in POSIX. The behavior for other bases is specified in C99.

HISTORY

strtoq() and strtoq_l() are historical functions that have been superseded by strtoll(3).

CAVEATS

The function strtoq() is not standard C. It is superseded by strtoll(3).

BUGS

None known.

EXAMPLES

The following example program demonstrates the use of strtoq():

#include <stdio.h>
#include <stdlib.h>

int
main(void)
{
    const char *str;
    char *endptr;
    long long val;

    str = " 12345678901234567890abc";
    val = strtoq(str, &endptr, 10);

    if (*endptr != '\0' && *endptr != '\n') {
        fprintf(stderr, "No strtoq() could convert string\n");
        exit(EXIT_FAILURE);
    }

    // If we got here, strtoq() successfully parsed a number.  
    printf("strtoq() returned %lld\n", val);
    if (*endptr != '\0')        // Not necessarily an error.  
        printf("Further characters after number: \"%s\"\n", endptr);

    exit(EXIT_SUCCESS);
}
