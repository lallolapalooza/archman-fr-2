sous-routine stpttr (uplo, n, ap, a, lda, info)
STPTTR copie une matrice triangulaire du format compact standard (TP) au format plein standard (TR).

Documentation de la fonction/sous-routine

sous-routine stpttr (caractère uplo, entier n, réel, dimension( * ) ap, réel, dimension( lda, * ) a, entier lda, entier info)

STPTTR copie une matrice triangulaire du format compact standard (TP) au format plein standard (TR).

Objectif :

!>
!> STPTTR copie une matrice triangulaire A du format compact standard (TP)
!> au format plein standard (TR).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure.
!>          = 'L' :  A est triangulaire inférieure.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

AP

!>          AP est un tableau de type REAL, dimension ( N*(N+1)/2 ),
!>          À l'entrée, la matrice triangulaire A (supérieure ou inférieure)
!>          compactée par colonnes dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

A

!>          A est un tableau de type REAL, dimension ( LDA, N )
!>          À la sortie, la matrice triangulaire A. Si UPLO = 'U', la partie
!>          supérieure N-par-N principale de A contient la partie triangulaire
!>          supérieure de la matrice A, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure N-par-N principale de A contient la partie triangulaire
!>          inférieure de la matrice A, et la partie strictement triangulaire
!>          supérieure de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
