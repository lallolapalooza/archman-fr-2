strsep(3) Manuel des fonctions de bibliothèque strsep(3)

NOM

strsep - extraire un jeton d'une chaîne

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
char *strsep(char **restrict stringp, const char *restrict delim);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

strsep() :

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et antérieur :
        _BSD_SOURCE

DESCRIPTION

Si *stringp est NULL, la fonction strsep() renvoie NULL et ne fait rien d'autre. Sinon, cette fonction trouve le premier jeton dans la chaîne *stringp qui est délimitée par l'un des octets de la chaîne delim. Ce jeton est terminé en écrasant le délimiteur par un octet nul ('\0'), et *stringp est mis à jour pour pointer après le jeton. Si aucun délimiteur n'est trouvé, le jeton est considéré comme étant la chaîne entière *stringp, et *stringp est rendu NULL.

VALEUR DE RETOUR

La fonction strsep() renvoie un pointeur vers le jeton, c'est-à-dire qu'elle renvoie la valeur originale de *stringp.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
strsep () Sécurité des threads MT-Safe

NORMES

BSD.

HISTORIQUE

4.4BSD.

La fonction strsep() a été introduite comme remplacement de strtok(3), car cette dernière ne peut pas gérer les champs vides.

MISE EN GARDE

Soyez prudent lorsque vous utilisez cette fonction. Si vous l'utilisez, notez que :

•
Cette fonction modifie son premier argument.
•
Cette fonction ne peut pas être utilisée sur des chaînes constantes.
•
L'identité du caractère délimitant est perdue.

EXEMPLES

Le programme ci-dessous est un portage de celui trouvé dans strtok(3), qui, cependant, ne jette pas les délimiteurs multiples ou les jetons vides :


$ ./a.out 'a/bbb///cc;xxx:yyy:' ':;' '/'
1: a/bbb///cc
         --> a
         --> bbb
         -->
         -->
         --> cc
2: xxx
         --> xxx
3: yyy
         --> yyy
4:
         -->

Source du programme

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(int argc, char *argv[])
{
    char *token, *subtoken;
    if (argc != 4) {
        fprintf(stderr, "Usage: %s string delim subdelim\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    for (unsigned int j = 1; (token = strsep(&argv[1], argv[2])); j++) {
        printf("%u: %s\n", j, token);
        while ((subtoken = strsep(&token, argv[3])))
            printf("\t --> %s\n", subtoken);
    }
    exit(EXIT_SUCCESS);
}
