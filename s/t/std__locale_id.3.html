DESCRIPTION Détaillée

Classe d'identifiant de facette.

La classe ID fournit aux facettes un index utilisé pour les identifier. Chaque classe de facette doit définir un membre statique public locale::id, ou être dérivée d'une facette qui fournit ce membre, sinon la facette ne peut pas être utilisée dans une locale. locale::id garantit que chaque type de classe obtient un identifiant unique.

template<typename _Facet> bool has_facet (const locale & __loc) [ami]

Teste la présence d'une facette. has_facet teste la locale argument pour la présence du type de facette fourni comme paramètre de template. Les facettes dérivées du paramètre de facette retourneront également true.

Paramètres de template

Retourne

template<typename _Facet> const _Facet & use_facet (const locale & __loc) [ami]

Retourne une facette. use_facet recherche et retourne une référence à une facette de type Facet où Facet est le paramètre de template. Si has_facet(locale) est true, il y a une facette appropriée à retourner. Elle lance std::bad_cast si la locale ne contient pas de facette de type Facet.

Paramètres de template

_Facet Le type de facette à accéder.

Paramètres

__loc La locale à utiliser.

Retourne

Référence à une facette de type Facet.

Exceptions

std::bad_cast si __loc ne contient pas de facette de type _Facet.
