sous-programme strtri (caractère uplo, caractère diag, entier n, réel, dimension( lda, * ) a, entier lda, entier info)

STRTRI

Objectif :

!>
!> STRTRI calcule l'inverse d'une matrice triangulaire réelle supérieure ou
!> inférieure A.
!>
!> Ceci est la version de l'algorithme de niveau 3 BLAS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure ;
!>          = 'L' :  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N' :  A est triangulaire non unitaire ;
!>          = 'U' :  A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire A. Si UPLO = 'U', la
!>          partie triangulaire supérieure N par N en tête du tableau A contient
!>          la matrice triangulaire supérieure, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée. Si UPLO = 'L', la
!>          partie triangulaire inférieure N par N en tête du tableau A contient
!>          la matrice triangulaire inférieure, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée. Si DIAG = 'U', les
!>          éléments diagonaux de A ne sont pas référencés et sont
!>          supposés être égaux à 1.
!>          À la sortie, l'inverse (triangulaire) de la matrice originale, dans
!>          le même format de stockage.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, A(i,i) est exactement zéro. La matrice
!>               triangulaire est singulière et son inverse ne peut pas être calculé.
!>
