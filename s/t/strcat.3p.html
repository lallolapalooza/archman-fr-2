STRCAT(3P) Manuel du programmeur POSIX STRCAT(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

strcat — concaténer deux chaînes

SYNTAXE

#include <string.h>
char *strcat(char *restrict s1, const char *restrict s2);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction strcat() copie la chaîne pointée par s2 (y compris le caractère NUL terminant) à la fin de la chaîne pointée par s1. L'octet initial de s2 écrase le caractère NUL à la fin de s1. Si une copie a lieu entre des objets qui se chevauchent, le comportement est indéfini.

VALEUR DE RETOUR

La fonction strcat() retourne s1; aucune valeur de retour n'est réservée pour indiquer une erreur.

ERREURS

Aucune erreur n'est définie.
