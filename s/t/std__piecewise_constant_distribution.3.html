Description détaillée

template<typename _RealType = double>

class std::piecewise_constant_distribution< _RealType >"Une distribution de nombres aléatoires piecewise_constant_distribution.

Cette distribution produit des nombres aléatoires $ x, b_0 d sur chaque sous-intervalle $ [b_i, b_{i+1}) $ selon la fonction de masse de probabilité p(x | b_0, ..., b_n, ho_0, ..., ho_{n-1})
= ho_i dot ac{b_{i+1} - x}{b_{i+1} - b_i}
+ ho_{i+1} dot ac{ x - b_i}{b_{i+1} - b_i} ] pour $ b_i
