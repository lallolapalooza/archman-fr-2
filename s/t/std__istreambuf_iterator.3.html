NAME

std::istreambuf_iterator — Interface to stream buffer iterators.

SYNOPSIS

#include <iterator>

std::istreambuf_iterator< _CharT, _Traits >

Detailed Description

The stream buffer iterators provide an interface to the C++ stream buffer iterators. For more information see the C++ standard library documentation.
