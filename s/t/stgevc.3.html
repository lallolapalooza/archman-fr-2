Objectif:

!>
!> STGEVC calcule tout ou partie des vecteurs propres droits et/ou gauches
!> d'une paire de matrices réelles (S,P), où S est une matrice quasi-triangulaire
!> et P est triangulaire supérieure. Les paires de matrices de ce type sont produites par
!> la factorisation de Schur généralisée d'une paire de matrices (A,B):
!>
!>    A = Q*S*Z**T,  B = Q*P*Z**T
!>
!> telles que calculées par SGGHRD + SHGEQZ.
!>
!> Les vecteurs propres droits x et gauches y de (S,P) correspondant à une valeur propre w sont définis par:
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> où y**H désigne la transposée conjuguée de y.
!> Les valeurs propres ne sont pas fournies en entrée de cette routine, mais sont calculées
!> directement à partir des blocs diagonaux de S et P.
!>
!> Cette routine renvoie les matrices X et/ou Y des vecteurs propres droits et gauches
!> de (S,P), ou les produits Z*X et/ou Q*Y,
!> où Q et Z sont des matrices d'entrée.
!> Si Q et Z sont les facteurs orthogonaux de la factorisation de Schur
!> généralisée d'une paire de matrices (A,B), alors Z*X et Q*Y
!> sont les matrices des vecteurs propres droits et gauches de (A,B).
!>
!>

NAME

stgevc - computes the generalised eigenvectors of a real generalised eigenvalue problem A*v = w*B*v.

Function/Subroutine Documentation

Subroutine

stgevc

computes the generalised eigenvectors of a real generalised eigenvalue problem A*v = w*B*v.

Right eigenvectors are computed by the QR algorithm. Left eigenvectors are computed by the QR algorithm.

The method used is backward substitution.

The equation to be solved for the i-th right eigenvector v(i) is: (A - w B) v(i) = 0

If the i-th eigenvalue w(i) is computed from the upper triangular matrices A and B, then the i-th right eigenvector v(i) is computed from the equation: (A - w(i) B) v(i) = 0 This requires solving a system of linear equations of the form C v(i) = 0, where C = A - w(i) B. This is equivalent to finding the null space of C.

The method used is based on the observation that if v is an eigenvector, then the components v(i+1:n) are zero. The equations become: n sum C(j,k) v(k) = 0 for j=i,...,1 k=j The last equation (j=i) is C(i,i) v(i) = 0. If C(i,i) is not zero, then v(i) must be zero. However, if w(i) is an eigenvalue, C(i,i) must be zero. Then the i-th equation is satisfied, and we can set v(i) = 1. The remaining equations can be solved for v(i-1), v(i-2), ..., v(1) by backward substitution.

Right Eigenvectors

The problem is to compute the right eigenvectors of A, B:

A V = B V W

where W is the diagonal matrix of eigenvalues, and V is the matrix of corresponding right eigenvectors.

The eigenvalues w(i) are computed by the QR algorithm. The eigenvectors are computed by backward substitution using the upper triangular matrices A and B.

The equation to be solved for the i-th right eigenvector v(i) is:

(A - w(i) B) v(i) = 0

Let C = A - w(i) B. The i-th column of C is given by:

C(j,i) = A(j,i) - w(i) B(j,i) for j=1,...,n

The equation for the i-th eigenvector v(i) is:

n sum C(j,k) v(k) = 0 for j=1,...,n k=1

Since A and B are upper triangular, C is also upper triangular. This means that C(j,k) = 0 for j > k.

The equation for the i-th eigenvector v(i) becomes:

i sum C(j,k) v(k) = 0 for j=i,...,1 k=j

This can be solved by backward substitution:

1. Set v(i) = 1.

2. For j = i-1 down to 1:

v(j) = - ( sum C(j,k) v(k) ) / C(j,j) k=j+1

This requires that C(j,j) is not zero. Since w(i) is an eigenvalue, the matrix C is singular, meaning that at least one diagonal element C(k,k) must be zero. The algorithm proceeds by setting the eigenvector component corresponding to the zero diagonal element to 1, and then solving for the remaining components.

**Left Eigenvectors**

The problem is to compute the left eigenvectors of A, B:

Y**H A = W Y**H B

where W is the diagonal matrix of eigenvalues, and Y is the matrix of corresponding left eigenvectors.

This is equivalent to finding the right eigenvectors of B**T, A**T:

A**T Y = W B**T Y

The algorithm is the same as for the right eigenvectors, but applied to the transpose of the matrices A and B.

**The `select` array**

If `howsm` = 'S', the logical array `select` is used to specify which eigenvectors are to be computed. For each i, if select(i) is true, then the i-th eigenvector is computed.

**Algorithm for computing eigenvectors**

The following is a simplified description of the algorithm for computing the i-th right eigenvector v, assuming all eigenvalues are real:

The equation is (A - w B) v = 0.

Let C = A - w B.

The i-th row of the equation is:

n sum C(i,k) v(k) = 0 k=1

Since A and B are upper triangular, C is upper triangular. The equation becomes:

i sum C(i,k) v(k) = 0 k=i

If C(i,i) is non-zero, then v(i) must be zero. If w is an eigenvalue, then C is singular, and there must be at least one diagonal element C(i,i) which is zero (or close to zero).

We can solve the system by backward substitution. Suppose we want to compute the i-th right eigenvector (assume all eigenvalues are real). The equation to be solved is:

n 0 = sum C(j,k) v(k) = sum C(j,k) v(k) for j = i,...,1 k=j k=j

where C = (A - w B). The components v(i+1:n) are 0.

The method is:

(1) v(i) := 1

for j = i-1,...,1:

(2) compute s = - sum C(j,k) v(k) and k=j+1

(3) v(j) := s / C(j,j)

Step 2 is sometimes called the dot product, since it is an inner product between the j-th row and the portion of the eigenvector that has been computed so far.

The dot product method consists basically in doing the sums for all the rows in parallel. As each v(j) is computed, the contribution of v(j) times the j-th column of C is added to the partial sums. Since FORTRAN arrays are stored columnwise, this has the advantage that at each step, the elements of C that are accessed are adjacent to one another, whereas with the rowwise method, the elements accessed at a step are spaced LDS (and LDP) words apart.

When finding left eigenvectors, the matrix in question is the transpose of the one in storage, so the rowwise method then actually accesses columns of A and B at each step, and so is the preferred method.
