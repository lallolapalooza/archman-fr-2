strdup(3) Manuel des fonctions de bibliothèque strdup(3)

NOM

strdup, strndup, strdupa, strndupa - dupliquer une chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
char *strdup(const char *s);
char *strndup(const char *s, size_t n);
char *strdupa(const char *s);
char *strndupa(const char *s, size_t n);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

strdup() :

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.12 : */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

strndup() :

    Depuis glibc 2.10 :
        _POSIX_C_SOURCE >= 200809L
    Avant glibc 2.10 :
        _GNU_SOURCE

strdupa(), strndupa() :

    _GNU_SOURCE

DESCRIPTION

La fonction strdup() retourne un pointeur vers une nouvelle chaîne qui est une duplication de la chaîne s. La mémoire pour la nouvelle chaîne est obtenue avec malloc(3), et peut être libérée avec free(3).

La fonction strndup() est similaire, mais copie au maximum n octets. Si s est plus longue que n, seuls n octets sont copiés, et un octet nul de terminaison ('\0') est ajouté.

strdupa() et strndupa() sont similaires, mais utilisent alloca(3) pour allouer le tampon.

VALEUR DE RETOUR

En cas de succès, la fonction strdup() retourne un pointeur vers la chaîne dupliquée. Elle retourne NULL si une mémoire insuffisante était disponible, avec errno défini pour indiquer l'erreur.

ERREURS

ENOMEM
Mémoire insuffisante disponible pour allouer la chaîne dupliquée.
