template<typename _CharT, bool _Intl> string std::moneypunct< _CharT, _Intl >::grouping () const [inline]

Retourne la spécification de groupement. Cette fonction retourne une chaîne représentant les groupements pour la partie entière d'un montant. Les groupements indiquent où insérer les séparateurs de milliers.

Chaque caractère de la chaîne retournée est interprété comme un entier plutôt qu'un caractère. Ces nombres représentent le nombre de chiffres dans un groupe. Le premier caractère de la chaîne représente le nombre de chiffres dans le groupe le moins significatif. Si un caractère est négatif, il indique un nombre illimité de chiffres pour ce groupe. Si des caractères supplémentaires de la chaîne sont nécessaires pour grouper un nombre, le dernier caractère est utilisé de manière répétée.

Par exemple, si grouping() retourne \003\002 et est appliqué au nombre 123456789, cela correspond à 12,34,56,789. Notez que si la chaîne était 32, cela placerait plus de 50 chiffres dans le groupe le moins significatif si le jeu de caractères est ASCII.

La chaîne est retournée en appelant moneypunct<char_type>::do_grouping().

Retourne

Une chaîne représentant la spécification de groupement.

Références do_grouping().

template<typename _CharT, bool _Intl> pattern std::moneypunct< _CharT, _Intl >::neg_format () const [inline]

Retourne le modèle de formatage des montants monétaires. Cette fonction retourne un modèle décrivant le formatage d'un montant monétaire de valeur positive ou négative. Elle le fait en retournant moneypunct<char_type>::do_pos_format() ou moneypunct<char_type>::do_neg_format().

Le modèle comporte 4 champs décrivant l'ordre du symbole, du signe, de la valeur, et de l'absence ou de l'espace. Il doit y avoir un de chaque dans le modèle. Les énumérations none et space ne peuvent pas apparaître dans le premier champ et space ne peut pas apparaître dans le dernier champ.

Les parties d'une chaîne monétaire doivent apparaître dans l'ordre indiqué par les champs du modèle. Le champ symbol indique que la valeur de curr_symbol() peut être présente. Le champ sign indique que la valeur de positive_sign() ou negative_sign() doit être présente. Le champ value indique que la valeur absolue du montant monétaire est présente. none indique zéro ou plusieurs caractères d'espacement, sauf à la fin, où il ne permet aucun espacement. space indique qu'un ou plusieurs caractères d'espacement doivent être présents.

Par exemple, pour la locale US et le modèle {symbol,sign,value,none} de pos_format(), curr_symbol() vaut '$', positive_sign() vaut '+', la valeur est 10.01, et les options sont réglées pour forcer le symbole, la chaîne correspondante est $+10.01.

Retourne

Un modèle pour le formatage des montants monétaires.

Références do_neg_format().
