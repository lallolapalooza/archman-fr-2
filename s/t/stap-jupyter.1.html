STAP-JUPYTER-*(1) Manuel des commandes générales STAP-JUPYTER-*(1)

NOM

stap-jupyter-install - installe isystemtap localement

stap-jupyter-container - gère une image de conteneur isystemtap

SYNOPIS

stap-jupyter-install [--remove] [--container-install PREFIX]

stap-jupyter-container [--repo REPOSITORY] [--image IMAGE] [--tag TAG] [--keyname KEYNAME] --{run, pull, build, publish, remove}

DESCRIPTION

ISystemtap est une interface jupyter interactive pour l'écriture et l'exécution incrémentielles de scripts Systemtap.

Le programme stap-jupyter-install peut être utilisé pour installer localement le noyau jupyter ISystemtap, le serveur de langage et l'extension jupyter-lab dans ~/.systemtap/jupyter. Une fois installé, le noyau peut être utilisé avec jupyter-lab.

Alternativement, le programme stap-jupyter-container peut être utilisé pour exécuter ISystemtap dans un conteneur, évitant ainsi le besoin d'installer un noyau jupyter local.

OPTIONS D'INSTALLATION

Les options suivantes sont prises en charge par stap-jupyter-install. Toute autre option affiche un bref message d'aide.

--remove
Désinstalle les fichiers ISystemtap locaux.
--container-install PREFIX
[Destiné aux mainteneurs uniquement] Ceci est utilisé pour spécifier le PREFIX du répertoire d'installation de stap. Il est appelé dans le processus de construction du conteneur et ne doit pas être utilisé autrement.

OPTIONS DU CONTENEUR

Les options suivantes sont prises en charge par stap-jupyter-container. Toute autre option affiche un bref message d'aide.

--repo REPOSITORY
Spécifie quel dépôt utiliser, par défaut "quay.io".
--image IMAGE
Spécifie le nom de l'image. Par défaut "systemtap/isystemtap"
--tag TAG
Spécifie le tag de l'image. Par défaut "latest"
--keyname KEYNAME
Pour que le conteneur puisse exécuter stap, il doit se connecter en ssh à l'hôte. Il nécessite une paire de clés ssh, et est spécifié par KEYNAME, qui est par défaut "id_rsa".

COMMANDES DU CONTENEUR

Les commandes suivantes sont reconnues par stap-jupyter-container. L'une des commandes suivantes est requise.

--run

Exécute l'image. Télécharge si ce n'est pas déjà fait.
--pull

Télécharge l'image.
--build

Construit une copie locale de l'image. Le dépôt sera "localhost". Voir les images podman.
--remove

Supprime l'image.
--publish

[Destiné aux mainteneurs uniquement] Ceci est utilisé pour publier l'image construite. Il nécessite des permissions d'écriture sur https://quay.io/systemtap/isystemtap.
