NAME

std::independent_bits_engine — Générateur de nombres aléatoires avec un nombre spécifié de bits indépendants

SYNOPSIS

Detailed Description

This class template produces random numbers with a specified number of independent bits, using an underlying random number engine.

The class template `independent_bits_engine` is a Uniform Random Bit Generator. It uses an underlying engine of type `_RandomNumberEngine` to produce a sequence of unsigned integer values of type `_UIntType`. It then combines these values to produce a sequence of random numbers, each having exactly `__w` independent bits.

The template parameters are:

_RandomNumberEngine
The type of the underlying random number engine. It must meet the requirements of a Uniform Random Bit Generator.
__w
The number of random bits to be produced by each generated value.
_UIntType
The unsigned integer type used to represent the generated random numbers.
