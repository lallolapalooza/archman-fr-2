STARTLXQT(1) Gestion de session LXQt STARTLXQT(1)

NOM

startlxqt - script pour initialiser et lancer les sessions LXQt

SYNTAXE

startlxqt

DESCRIPTION

startlxqt est un script shell destiné à initialiser et à lancer les sessions LXQt. Il est ainsi similaire aux scripts counterparts d'autres environnements de bureau tels que startlxde dans LXDE ou startxfce dans XFCE.

Ses tâches principales consistent à exporter des variables d'environnement, parfois après avoir effectué les vérifications correspondantes, et à lancer lxqt-session, le gestionnaire de session LXQt.

Il n'est pas destiné à être exécuté par les utilisateurs. Plutôt, il est appelé en tant que backend, par exemple par le script startx sur les terminaux virtuels ou par les gestionnaires d'affichage comme SDDM ou LightDM, voir la section EXEMPLE.

FICHIERS

$XDG_DATA_DIRS/xsessions/lxqt.desktop

Fichier d'entrée de bureau indiquant startlxqt comme binaire nécessaire pour démarrer les sessions LXQt. Sourcé par exemple par les gestionnaires d'affichage.

BOGUES

Aucun au moment de la rédaction. Les bogues peuvent être signalés sur https://github.com/lxqt/lxqt-session/issues.

EXEMPLE

Pour démarrer une session LXQt depuis un terminal virtuel (console virtuelle) ajoutez une ligne

exec startlxqt

au fichier ~/.xinitrc. Une session LXQt sera alors lancée en exécutant startx.

Les gestionnaires d'affichage utilisent des scripts comme startlxqt automatiquement. Les informations sur les environnements de bureau disponibles sont fournies par les fichiers $XDG_DATA_DIRS/xsessions/*.desktop, typiquement /usr/share/xessions/*.desktop.
Le fichier lxqt.desktop fourni par LXQt indique startlxqt dans la clé Exec tout en s'assurant que le gestionnaire de session lxqt-session existe en l'indiquant dans la clé TryExec.
