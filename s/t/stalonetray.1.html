STALONETRAY(1) Commandes utilisateur STALONETRAY(1)

NOM

stalonetray - Implémentation de barre système (zone de notification) autonome. Ce document couvre la version 1.0.1 de stalonetray.

SYNTAXE


.HP 288u


stalonetray
[option...]

DESCRIPTION


.PP Stalonetray est une barre système (zone de notification) autonome pour le système X Window/X11 (par exemple XOrg ou XFree86). Il a des dépendances minimales de compilation et d'exécution : une bibliothèque X11 seulement. Le support complet de XEMBED est en cours de développement. Stalonetray fonctionne avec pratiquement n'importe quel gestionnaire de fenêtres compatible EWMH.


.PP Le comportement et l'apparence de stalonetray peuvent être configurés soit via des options en ligne de commande, soit via un fichier de configuration. Comme d'habitude, les options en ligne de commande ont la priorité sur les options spécifiées dans le fichier de configuration.


.PP Les noms des paramètres en ligne de commande peuvent avoir deux variantes : courte (-o) et longue (--option). Écrivez -ovaleur ou -o valeur pour passer une valeur en utilisant le nom court d'un paramètre ; pour passer une valeur en utilisant un nom long, écrivez --option valeur ou --option=valeur. Tous les paramètres de type drapeau ont une valeur booléenne optionnelle qui, si omis, est supposée être "vrai". Écrivez "vrai", "oui", "1" pour les valeurs booléennes positives, et "faux", "non", "0" pour les valeurs négatives.


.PP Le fichier de configuration par défaut est $HOME/.stalonetrayrc. S'il n'est pas trouvé, alors $XDG_CONFIG_HOME/stalonetrayrc est vérifié. Un fichier de configuration contient des paires mot-clé-argument insensibles à la casse, une par ligne. Les lignes commençant par '#' et les lignes vides sont ignorées. Alternativement, le fichier de configuration peut être spécifié via les options de ligne de commande -c ou --config.


.PP Stalonetray peut être configuré pour écrire des messages de journalisation diagnostique dans le flux d'erreur standard.


.PP Ci-dessous se trouve la liste des options possibles en ligne de commande/fichier de configuration. Les options commençant par des tirets sont des paramètres en ligne de commande, les autres sont des mots-clés de fichier de configuration. Les options nouvelles dans la version 1.0.1 sont marquées avec "NOUVEAU dans 1.0.1".

OPTIONS


.PP -bg couleur, --background couleur, background couleur


Utilise couleur pour l'arrière-plan de la barre. couleur peut être spécifiée comme un triplet hexadécimal HTML ou comme un nom de rgb.txt (notez que '#' doit être mis entre guillemets). Valeur par défaut : #777777.


.RE


.PP -c nom_fichier, --config nom_fichier


Lit la configuration à partir de nom_fichier au lieu du défaut $HOME/.stalonetrayrc.


.RE


.PP -d spec_decor, --decorations spec_decor, decorations spec_decor


Spécifie les décorations visibles de la fenêtre de la barre. Les valeurs possibles pour spec_decor sont : all, title, border, none (par défaut).


.RE


.PP -display ecran, display ecran


Utilise l'écran X ecran.


.RE


.PP --dockapp-mode [mode], dockapp_mode [mode]


Définit le mode dockapp, qui peut être soit simple pour par ex. OpenBox, wmaker pour WindowMaker, soit none (par défaut).


.RE


.PP -f [niveau], --fuzzy-edges [niveau], fuzzy_edges [niveau]


Active les bords flous de la fenêtre de la barre et définit le niveau de flou qui peut aller de 0 (désactivé, par défaut) à 3. Si omis, la valeur de niveau est par défaut 2.


.RE


.PP --geometry spec_geometrie, geometry spec_geometrie


Définit la géométrie initiale de la barre à spec_geometrie, spécifiée en notation X standard : largeurxhauteur[+x[+y]], où largeur et hauteur sont spécifiées en multiples d'emplacements d'icône. Valeur par défaut : 1x1+0-0.


.RE


.PP --grow-gravity gravite, grow_gravity gravite


Spécifie la gravité de positionnement des icônes (soit N, S, W, E, NW, NE, SW, SE). La gravité de croissance spécifie les directions dans lesquelles la fenêtre de la barre peut grandir. Par exemple, si vous spécifiez NW, la fenêtre de la barre grandira vers le bas verticalement et vers la droite horizontalement (ce sont les côtés opposés au coin supérieur gauche ou Nord-Ouest de la fenêtre) ; avec W, la fenêtre de la barre grandira horizontalement uniquement vers la gauche, et elle grandira verticalement vers le haut et vers le bas en maintenant la position de son centre. Veuillez noter que ce dernier comportement est nouveau dans la version 0.8. Valeur par défaut : NW.


.RE


.PP --icon-gravity gravite, icon_gravity gravite


Spécifie la gravité de positionnement des icônes (soit NW, NE, SW, SE). Si vous spécifiez, par exemple SW, alors les icônes apparaîtront en partant du coin inférieur gauche de la fenêtre de la barre. Valeur par défaut : NW.


.RE


.PP -i n, --icon-size n, icon_size n


Définit la taille d'icône par défaut à n. Valeur par défaut : 24. Minimum : 16.


.RE


.PP -h, --help


Affiche le message d'aide.


.RE


.PP ignore_classes classes


Définit les noms de classe de fenêtre X11 à ignorer par stalonetray. Les noms de classe sont des arguments séparés : classe1 classe2 ....


.RE


.PP --log-level niveau, log_level niveau


Définit la quantité d'informations à afficher par stalonetray sur la sortie standard. Les valeurs possibles pour niveau sont : err (par défaut), info, et trace. Pour que l'option trace soit disponible, stalonetray doit être configuré avec --enable-debug lors de la compilation.


.RE


.PP --kludges bidouille [,bidouille...]


Active des bidouilles spécifiques pour contourner les WM non conformes et/ou les bogues de stalonetray. L'argument est une liste séparée par des virgules de :

•fix_window_pos — corrige la position de la fenêtre de la barre lors de déplacements erronés par le WM
•force_icons_size — ignore les événements de redimensionnement sur toutes les icônes ; force leur taille à être égale à icon_size
•use_icons_hints — utilise les indices de fenêtre d'icône pour déterminer la taille de l'icône
.sp


.RE


.PP --max-geometry spec_geometrie, max_geometry spec_geometrie


Définit la géométrie maximale de la barre à spec_geometrie. Valeur par défaut : 0x0, aucune limite.


.RE


.PP -m n, --monitor n, monitor n


Définit le moniteur cible à n. Valeur par défaut : 0.


.RE


.PP --no-shrink, no_shrink [bool]


Ne réduit pas la fenêtre de la barre après la suppression d'une icône. Utile lorsque la barre est engloutie par une autre fenêtre comme FvwmButtons. Valeur par défaut : false.


.RE


.PP -p, --parent-bg, parent_bg [bool]


Utilise la fenêtre parente comme arrière-plan de la fenêtre de la barre. Valeur par défaut : false.


.RE


.PP --pixmap-bg chemin_vers_xpm, pixmap_bg chemin_vers_xpm


Utilise le pixmap

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

map depuis un fichier XPM spécifié par path_to_xpm pour l'arrière-plan de la fenêtre du tray (le pixmap sera carrelé pour remplir toute la fenêtre).


.RE


.PP -r name, --remote-click-icon name


Contrôle/clic à distance. Lorsque cette option est spécifiée, stalonetray envoie un clic factice à l'icône dont la fenêtre est nommée name et se termine. L'icône est recherchée dans le tray actuellement actif pour l'écran courant. Par défaut, stalonetray envoie un clic simple avec le 1er bouton de la souris au centre de l'icône. Voir les options ci-dessous pour plus d'informations sur la façon de modifier les valeurs par défaut.


.RE


.PP --remote-click-button n


Définit le numéro du bouton du clic à distance à n (dans l'ordre de numérotation X11).


.RE


.PP --remote-click-position xxy


Définit la position du clic à distance.


.RE


.PP --remote-click-type type


Définit le type de clic à distance. Valeurs possibles : single et double.


.RE


.PP -s n, --slot-size w[xw], slot_size w[xw]


Définit la largeur de la cellule de la grille à w et la hauteur à b, toutes deux ne pouvant être inférieures à icon_size. Par défaut, la taille de la cellule est la même que la taille de l'icône. Si omis, la hauteur est réglée sur la même valeur que la largeur.


.RE


.PP --scrollbars mode, scrollbars mode


Définit le mode des barres de défilement. Valeurs possibles : vertical, horizontal, all, ou none (par défaut). Les barres de défilement apparaissent comme un espace supplémentaire aux bords du tray qui peuvent être cliqués pour faire défiler la zone des icônes. La molette de la souris fonctionne également.


.RE


.PP --scrollbars-highlight mode, scrollbars_highlight mode


Définit le mode de mise en évidence des barres de défilement. Valeurs possibles : une spécification de couleur, ou disable.


.RE


.PP --scrollbars-size n, scrollbars_size n


Définit la taille des barres de défilement à n pixels. Par défaut, la taille est 1/4 de la slot_size.


.RE


.PP --scrollbars-step n, scrollbars_step n


Définit le pas de défilement à n pixels. Par défaut, c'est 1/2 de la slot_size.


.RE


.PP --scroll-everywhere, scroll_everywhere [bool]


Active le défilement en dehors des barres de défilement également. Valeur par défaut : false.


.RE


.PP --skip-taskbar, skip_taskbar [bool]


Masque la fenêtre du tray de la barre des tâches. Valeur par défaut : false.


.RE


.PP --sticky, sticky [bool]


Rend la fenêtre du tray collante sur plusieurs bureaux/pages. Valeur par défaut : false.


.RE


.PP --tint-color, tint_color [bool]


Définit la couleur de teinte. Valeur par défaut : white.


.RE


.PP --tint-level, tint_level [level]


Définit le niveau de teinte. Valeur par défaut : 0 (teinte désactivée).


.RE


.PP -t, --transparent, transparent [bool]


Active la transparence racine. Valeur par défaut : false.


.RE


.PP -v, --vertical, vertical [bool]


Utilise une disposition verticale des icônes (horizontale est utilisée par défaut).


.RE


.PP --window-layer layer, window_layer layer


Définit la couche de la fenêtre du tray conforme à la norme EWMH. Valeurs possibles pour layer : bottom, normal, top. Valeur par défaut : normal.


.RE


.PP --window-strut mode, window_strut mode


Active les contraintes de fenêtre pour la fenêtre du tray (pour éviter la couverture de la fenêtre du tray par les fenêtres maximisées). Le mode définit sur quel bord de l'écran la fenêtre du tray sera attachée. Il peut être top, bottom, left, right, none, ou auto (par défaut).


.RE


.PP --window-type type, window_type type


Définit le type de la fenêtre du tray conforme à la norme EWMH. Valeurs possibles pour type : desktop, dock, normal, toolbar, utility. Valeur par défaut : dock.


.RE


.PP --xsync, xsync [bool]


Opère sur le serveur X de manière synchrone (LENT, désactivé par défaut).


.RE

DÉPRÉCIATIONS


.PP À partir de stalonetray 0.8, les paramètres de ligne de commande et de fichier de configuration suivants sont obsolètes :


.PP --dbg-level, dbg_level


Utilisez --log-level à la place.


.RE


.PP --max-tray-width, --max-tray-height, max_tray_width, max_tray_height


Utilisez --max-geometry à la place.


.RE


.PP -w, --withdrawn, withdrawn


Utilisez --dockapp-mode à la place.


.RE


.PP --respect-icon-hints, respect_icon_hints


Utilisez --kludges avec le paramètre use_icon_hints à la place.


.RE

FICHIERS

$HOME/.stalonetrayrc — fichier de configuration par défaut.

BOGUES

Il y en a quelques-uns, certainement.

Si vous avez besoin d'aide, la meilleure façon de l'obtenir est d'ouvrir un problème sur la page github[1] de stalonetray ou de m'envoyer un e-mail directement à <busa_ru@users.sourceforge.net>.

Si vous avez trouvé un bogage, veuillez essayer de le reproduire avec le niveau de journalisation défini sur trace et redirigez le flux d'erreur standard vers un fichier. Attachez ensuite le fichier à un problème github ou à un e-mail. Si le problème est intermittent, joignez deux fichiers journaux - un avec le bon comportement et un avec le mauvais. Si vous avez installé stalonetray à partir d'un dépôt de paquets, vous pouvez également déposer un rapport de bogage dans le système de suivi des bogues respectif.
