s390_runtime_instr(2) Manuel des appels système s390_runtime_instr(2)

NOM

s390_runtime_instr - activer/désactiver l'instrumentation d'exécution du processeur s390

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <asm/runtime_instr.h> /* Définition des constantes S390_* */
#include <sys/syscall.h>       /* Définition des constantes SYS_* */
#include <unistd.h>
int syscall(SYS_s390_runtime_instr, int command, int signum);

Note : glibc ne fournit pas de fonction d'encapsulation pour s390_runtime_instr(), nécessitant l'utilisation de syscall(2).

DESCRIPTION

L'appel système s390_runtime_instr() démarre ou arrête l'instrumentation d'exécution du processeur pour le thread appelant.

L'argument command contrôle si l'instrumentation d'exécution est démarrée (S390_RUNTIME_INSTR_START, 1) ou arrêtée (S390_RUNTIME_INSTR_STOP, 2) pour le thread appelant.

L'argument signum spécifie le numéro d'un signal temps réel. Cet argument était utilisé pour spécifier un numéro de signal qui devait être envoyé au thread si le tampon d'instrumentation d'exécution était plein ou si l'interruption d'arrêt de l'instrumentation d'exécution s'était produite. Cette fonctionnalité n'a jamais été utilisée, et dans le noyau Linux 4.4, la prise en charge de cette fonctionnalité a été supprimée ; par conséquent, dans les noyaux actuels, cet argument est ignoré.

VALEUR DE RETOUR

En cas de succès, s390_runtime_instr() retourne 0 et active le thread pour l'instrumentation d'exécution en lui attribuant un bloc de contrôle d'instrumentation d'exécution par défaut. L'appelant peut alors lire et modifier le bloc de contrôle et démarrer l'instrumentation d'exécution. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
La valeur spécifiée dans command n'est pas une commande valide.
EINVAL
La valeur spécifiée dans signum n'est pas un numéro de signal temps réel. À partir de Linux 4.4, l'argument signum n'a aucun effet, donc un numéro de signal invalide n'entraînera pas d'erreur.
ENOMEM
L'allocation de mémoire pour le bloc de contrôle d'instrumentation d'exécution a échoué.
EOPNOTSUPP
La fonctionnalité d'instrumentation d'exécution n'est pas disponible.

NORMES

Linux sur s390.

HISTORIQUE

Linux 3.7. System z EC12.

NOTES

Le fichier d'en-tête asm/runtime_instr.h est disponible depuis Linux 4.16.

À partir de Linux 4.4, la prise en charge de la signalisation a été supprimée, tout comme la vérification si signum est un signal temps réel valide. Pour des raisons de compatibilité ascendante avec les anciens noyaux, il est recommandé de passer un numéro de signal temps réel valide dans signum et d'installer un gestionnaire pour ce signal.

VOIR AUSSI

syscall(2), signal(7)
