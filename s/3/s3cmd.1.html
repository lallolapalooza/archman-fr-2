NOM

s3cmd - outil de gestion de l'espace de stockage Amazon S3 et du réseau de diffusion de contenu Amazon CloudFront

SYNOPSIS

s3cmd [OPTIONS] COMMANDE [PARAMÈTRES]

DESCRIPTION

s3cmd est un client en ligne de commande pour copier des fichiers vers/depuis Amazon S3 (Simple Storage Service) et effectuer d'autres tâches associées, par exemple créer et supprimer des buckets, lister des objets, etc.

COMMANDES

s3cmd peut effectuer plusieurs actions spécifiées par les commandes suivantes.

s3cmd mb s3://BUCKET
Créer un bucket
s3cmd rb s3://BUCKET
Supprimer un bucket
s3cmd ls [s3://BUCKET[/PREFIX]]
Lister des objets ou des buckets
s3cmd la
Lister tous les objets dans tous les buckets
s3cmd put FICHIER [FICHIER...] s3://BUCKET[/PREFIX]
Placer un fichier dans un bucket
s3cmd get s3://BUCKET/OBJET FICHIER_LOCAL
Obtenir un fichier depuis un bucket
s3cmd del s3://BUCKET/OBJET
Supprimer un fichier d'un bucket
s3cmd rm s3://BUCKET/OBJET
Supprimer un fichier d'un bucket (alias pour del)
s3cmd restore s3://BUCKET/OBJET
Restaurer un fichier depuis le stockage Glacier
s3cmd sync RÉPERTOIRE_LOCAL s3://BUCKET[/PREFIX] ou s3://BUCKET[/PREFIX] RÉPERTOIRE_LOCAL ou s3://BUCKET[/PREFIX] s3://BUCKET[/PREFIX]
Synchroniser un arbre de répertoires vers S3 (vérifie la fraîcheur des fichiers en utilisant la taille et la somme de contrôle md5, sauf si remplacé par des options, voir ci-dessous)
s3cmd du [s3://BUCKET[/PREFIX]]
Utilisation du disque par buckets
s3cmd info s3://BUCKET[/OBJET]
Obtenir diverses informations sur les buckets ou les fichiers
s3cmd cp s3://BUCKET1/OBJET1 s3://BUCKET2[/OBJET2]
Copier un objet
s3cmd modify s3://BUCKET1/OBJET
Modifier les métadonnées d'un objet
s3cmd mv s3://BUCKET1/OBJET1 s3://BUCKET2[/OBJET2]
Déplacer un objet
s3cmd setacl s3://BUCKET[/OBJET]
Modifier la liste de contrôle d'accès pour un bucket ou des fichiers
s3cmd setversioning s3://BUCKET activer|désactiver
Modifier le versionnement d'un bucket
s3cmd setownership s3://BUCKET BucketOwnerPreferred|BucketOwnerEnforced|ObjectWriter
Modifier la propriété des objets d'un bucket
s3cmd setblockpublicaccess s3://BUCKET BlockPublicAcls,IgnorePublicAcls,BlockPublicPolicy,RestrictPublicBuckets
Modifier les règles de blocage d'accès public
s3cmd setobjectlegalhold STATUT s3://BUCKET/OBJET
Modifier la rétention légale d'un objet
s3cmd setobjectretention MODE DATE_DE_RETENTION_JUSQU_À s3://BUCKET/OBJET
Modifier la rétention d'un objet
s3cmd setpolicy FICHIER s3://BUCKET
Modifier la politique du bucket
s3cmd delpolicy s3://BUCKET
Supprimer la politique du bucket
s3cmd setcors FICHIER s3://BUCKET
Modifier le CORS du bucket
s3cmd delcors s3://BUCKET
Supprimer le CORS du bucket
s3cmd payer s3://BUCKET
Modifier la politique Requester Pays du bucket
s3cmd multipart s3://BUCKET [Id]
Afficher les téléchargements multipartites
s3cmd abortmp s3://BUCKET/OBJET Id
Interrompre un téléchargement multipartite
s3cmd listmp s3://BUCKET/OBJET Id
Lister les parties d'un téléchargement multipartite
s3cmd accesslog s3://BUCKET
Activer/désactiver la journalisation d'accès du bucket
s3cmd sign CHAÎNE-À-SIGNER
Signer une chaîne arbitraire en utilisant la clé secrète
s3cmd signurl s3://BUCKET/OBJET <date_expiration_epoch|+décalage_expiration>
Signer une URL S3 pour fournir un accès public limité avec expiration
s3cmd fixbucket s3://BUCKET[/PREFIX]
Corriger les noms de fichiers invalides dans un bucket
s3cmd settagging s3://BUCKET[/OBJET] "CLE=VALEUR[&CLE=VALEUR ...]"
Modifier le marquage pour un bucket ou des fichiers
s3cmd gettagging s3://BUCKET[/OBJET]
Obtenir le marquage pour un bucket ou des fichiers
s3cmd deltagging s3://BUCKET[/OBJET]
Supprimer le marquage pour un bucket ou des fichiers
s3cmd expire s3://BUCKET
Définir ou supprimer une règle d'expiration pour le bucket
s3cmd setlifecycle FICHIER s3://BUCKET
Télécharger une politique de cycle de vie pour le bucket
s3cmd getlifecycle s3://BUCKET
Obtenir une politique de cycle de vie pour le bucket
s3cmd dellifecycle s3://BUCKET
Supprimer une politique de cycle de vie pour le bucket
s3cmd setnotification FICHIER s3://BUCKET
Télécharger une politique de notification pour le bucket
s3cmd getnotification s3://BUCKET
Obtenir une politique de notification pour le bucket
s3cmd delnotification s3://BUCKET
Supprimer une politique de notification pour le bucket

Commandes pour la configuration de sites Web statiques

s3cmd ws-create s3://BUCKET
Créer un site Web à partir d'un bucket
s3cmd ws-delete s3://BUCKET
Supprimer un site Web
s3cmd ws-info s3://BUCKET
Informations sur le site Web

Commandes pour la gestion de CloudFront

s3cmd cfinvalinfo cf://ID_DIST[/ID_INVAL]
Afficher le statut de(s) demande(s) d'invalidation CloudFront

EXEMPLES

Une des commandes les plus puissantes d's3cmd est s3cmd sync utilisée pour synchroniser des arborescences de répertoires complètes vers ou depuis le stockage S3 distant. Dans une certaine mesure, s3cmd put et s3cmd get se comportent de manière similaire à sync.

L'utilisation de base courante dans les scénarios de sauvegarde est aussi simple que :

s3cmd sync /chemin/local/ s3://mon-bucket-test/sauvegarde/

Cette commande trouvera tous les fichiers sous le répertoire /chemin/local/ et les copiera vers les chemins correspondants sous s3://mon-bucket-test/sauvegarde du côté distant. Par exemple :

/chemin/local/fichier1.ext         ->  s3://mon-bucket/sauvegarde/fichier1.ext
/chemin/local/dir123/fichier2.bin  ->  s3://mon-bucket/sauvegarde/dir123/fichier2.bin

Cependant, si le chemin local ne se termine pas par une barre oblique, le nom du dernier répertoire est également utilisé du côté distant. Comparez ceci avec l'exemple précédent :

s3cmd sync /chemin/local s3://mon-bucket-test/sauvegarde/
synchronisera : 
/chemin/local/fichier1.ext         ->  s3://mon-bucket/sauvegarde/local/fichier1.ext
/chemin/local/dir123/fichier2.bin  ->  s3://mon-bucket/sauvegarde/local/dir123/fichier2.bin

Pour récupérer les fichiers depuis S3, utilisez la syntaxe inversée :

s3cmd sync s3://mon-bucket-test/sauvegarde/ ~/restauration/
ce qui téléchargera les fichiers : 
s3://mon-bucket/sauvegarde/fichier1.ext         ->  ~/restauration/fichier1.ext
s3://mon-bucket/sauvegarde/dir123/fichier2.bin  ->  ~/restauration/dir123/fichier2.bin

Sans la barre oblique finale sur la source, le comportement est similaire à ce qui a été démontré lors du téléversement :

s3cmd sync s3://mon-bucket-test/sauvegarde ~/restauration/
téléchargera les fichiers comme suit : 
s3://mon-bucket/sauvegarde/fichier1.ext         ->  ~/restauration/sauvegarde/fichier1.ext
s3://mon-bucket/sauvegarde/dir123/fichier2.bin  ->  ~/restauration/sauvegarde/dir123/fichier2.bin

Tous les noms de fichiers source, les noms en gras ci-dessus, sont comparés aux règles exclude, puis ils sont re-vérifiés contre les règles include pour voir s'ils doivent être exclus ou conservés dans la liste source.

Pour la mise en correspondance de --exclude et --include, seuls les noms de fichiers en gras ci-dessus sont utilisés. Par exemple, seul chemin/fichier1.ext est testé contre les motifs, pas /local/chemin/fichier1.ext

Les deux options --exclude et --include fonctionnent avec les jokers de style shell (aussi appelés GLOB). Pour plus de flexibilité, s3cmd fournit des versions d'expressions régulières des

s3cmd(1) - s3cmd

NOM

s3cmd - interface en ligne de commande pour Amazon S3

SYNTAXE

s3cmd [OPTIONS] COMMANDE [ARGS]

DESCRIPTION

s3cmd est un client en ligne de commande pour Amazon S3 (Simple Storage Service). Il permet de gérer vos buckets et objets S3, ainsi que de transférer des fichiers entre votre machine locale et S3.

Les règles d'inclusion et d'exclusion peuvent être spécifiées à l'aide des options --exclude, --include, --rexclude et --rinclude.

Les options avec le suffixe -from (par exemple --rinclude-from) attendent un nom de fichier comme argument. Chaque ligne d'un tel fichier est traitée comme un motif.

Il n'y a qu'un seul ensemble de motifs construit à partir de toutes les options --(r)exclude(-from) et de manière similaire pour la variante include. Tout fichier exclu avec, par exemple, --exclude peut être réintégré avec un motif trouvé dans la liste --rinclude-from.

Exécutez s3cmd avec --dry-run pour vérifier que vos règles fonctionnent comme prévu. Utilisez-le conjointement avec --debug pour obtenir des informations détaillées sur la correspondance des noms de fichiers avec les règles d'exclusion et d'inclusion.

Par exemple, pour exclure tous les fichiers avec l'extension « .jpg » sauf ceux commençant par un chiffre, utilisez :

--exclude '*.jpg' --rinclude '[0-9].*.jpg'

Pour exclure tous les fichiers sauf ceux avec l'extension « *.jpg », utilisez :

--exclude '*' --include '*.jpg'

Pour exclure le répertoire local 'somedir', assurez-vous d'utiliser une barre oblique inverse finale, comme ceci :

--exclude 'somedir/'

COMMANDES

Les commandes courantes incluent :

s3cmd sync
Synchronise un répertoire local avec un bucket S3 ou vice-versa.
s3cmd put
Téléverse un ou plusieurs fichiers vers S3.
s3cmd get
Télécharge un ou plusieurs fichiers depuis S3.
s3cmd ls
Liste les buckets ou les objets dans un bucket.
s3cmd mb
Crée un nouveau bucket.
s3cmd rb
Supprime un bucket.
s3cmd rm
Supprime un ou plusieurs objets.

OPTIONS

Les options courantes incluent :

--exclude PATTERN
Exclut les fichiers correspondant au motif.
--include PATTERN
Inclut les fichiers correspondant au motif (peut annuler une exclusion).
--exclude-from FILE
Lit les motifs d'exclusion depuis FILE.
--include-from FILE
Lit les motifs d'inclusion depuis FILE.
--rexclude PATTERN
Exclut les fichiers correspondant au motif (récursif).
--rinclude PATTERN
Inclut les fichiers correspondant au motif (récursif).
--rexclude-from FILE
Lit les motifs d'exclusion récursifs depuis FILE.
--rinclude-from FILE
Lit les motifs d'inclusion récursifs depuis FILE.
--dry-run
Simule l'opération sans effectuer de modifications réelles.
--debug
Active la sortie de débogage détaillée.
-h, --help
Affiche l'aide et quitte.
--version
Affiche les informations de version et quitte.

Voir la page de manuel ou l'aide de s3cmd --help pour la liste complète des options.

EXEMPLES

Pour exclure tous les fichiers .log et les répertoires .git :

s3cmd sync --exclude '*.log' --exclude '.git/' . s3://mon-bucket

Pour ne synchroniser que les fichiers .jpg et .png :

s3cmd sync --exclude '*' --include '*.jpg' --include '*.png' . s3://mon-bucket

Pour exclure tous les fichiers sauf ceux se trouvant dans le répertoire 'data' :

s3cmd sync --exclude '*' --include 'data/*' . s3://mon-bucket

Utilisation de fichiers pour les motifs :

echo "*.tmp" > exclude-list.txt

echo "*.bak" >> exclude-list.txt

s3cmd sync --exclude-from exclude-list.txt . s3://mon-bucket
