s390_pci_mmio_write(2) Manuel des appels système s390_pci_mmio_write(2)

NOM

s390_pci_mmio_write, s390_pci_mmio_read - transférer des données vers/depuis une page mémoire PCI MMIO

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
int syscall(size_t length;
            SYS_s390_pci_mmio_write, unsigned long mmio_addr,
            const void user_buffer[length], size_t length);
int syscall(size_t length;
            SYS_s390_pci_mmio_read, unsigned long mmio_addr,
            void user_buffer[length], size_t length);

Note : glibc ne fournit pas de fonctions d'enrobage pour ces appels système, ce qui nécessite l'utilisation de syscall(2).

DESCRIPTION

L'appel système s390_pci_mmio_write() écrit length octets de données depuis le tampon de l'espace utilisateur user_buffer vers l'emplacement mémoire PCI MMIO spécifié par mmio_addr. L'appel système s390_pci_mmio_read() lit length octets de données depuis l'emplacement mémoire PCI MMIO spécifié par mmio_addr vers le tampon de l'espace utilisateur user_buffer.

Ces appels système doivent être utilisés à la place des opérations d'assignation ou de transfert de données simples utilisées pour accéder aux zones mémoire PCI MMIO mappées dans l'espace utilisateur sur la plateforme Linux System z. L'adresse spécifiée par mmio_addr doit appartenir à un mappage de page mémoire PCI MMIO dans l'espace d'adressage de l'appelant, et les données écrites ou lues ne doivent pas franchir une limite de page. La valeur length ne peut pas être supérieure à la taille de page du système.

VALEUR DE RETOUR

En cas de succès, s390_pci_mmio_write() et s390_pci_mmio_read() retournent 0. En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
L'adresse dans mmio_addr est invalide.
EFAULT
user_buffer ne pointe pas vers un emplacement valide dans l'espace d'adressage de l'appelant.
EINVAL
Argument length invalide.
ENODEV
Le support PCI n'est pas activé.
ENOMEM
Mémoire insuffisante.

NORMES

Linux sur s390.

HISTORIQUE

Linux 3.19. System z EC12.

VOIR AUSSI

syscall(2)
