SWITCHEROOCTL(1) Commandes utilisateur SWITCHEROOCTL(1)

NOM

switcherooctl - Lancer une commande sur un GPU spécifique

SYNTAXE

switcherooctl help [COMMANDE]

switcherooctl version

switcherooctl list

switcherooctl launch [OPTION] COMMANDE...

DESCRIPTION

switcherooctl est un utilitaire pour lancer une commande spécifique sur un GPU spécifique.

COMMANDES

help [COMMANDE]

Affiche un bref synopsis des commandes disponibles ou fournit une aide détaillée sur une commande spécifique.

version

Affiche la version de switcheroo-control à laquelle switcherooctl appartient.

list

Liste les GPU connus. Le numéro de périphérique peut être utilisé pour spécifier le GPU sur lequel lancer la commande. C'est la commande par défaut si aucune commande n'est passée à switcherooctl.

launch [OPTION] COMMANDE...

Lance COMMANDE sur un GPU spécifique. Si aucun GPU n'est spécifié, le premier GPU discret (non-par défaut) est utilisé, ou le GPU par défaut s'il n'y a pas de GPU discret.

Options

-g --gpu=GPU

Le GPU sur lequel lancer. L'identifiant du GPU peut être obtenu en utilisant la commande list.

ETAT DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.
