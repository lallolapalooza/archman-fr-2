NOM

swtpm_cert - Outil pour créer des certificats EK et de plateforme pour swtpm (1.2 & 2.0)

SYNTAXE

swtpm_cert [OPTIONS]

DESCRIPTION

swtpm_cert est un outil de CA local pour créer des certificats X.509v3 pour la clé d'attestation (Endorsement Key) du TPM. La raison d'être de cet outil spécifique est qu'il fonctionne sans accès à la clé privée de la clé d'attestation. Généralement, les outils nécessitent soit une demande de certificat auto-signée, soit l'accès à la clé privée pour émettre un certificat. Cet outil fonctionne uniquement avec la partie clé publique.

Les options suivantes sont supportées :

--type {ek|platform}
Le type de certificat à créer ; par défaut, un certificat EK est créé.
--pubkey <nom-fichier>
La clé publique (EK) au format PEM.
--modulus <chiffres hexadécimaux>
Le module de la clé publique sous forme d'une chaîne de chiffres hexadécimaux. Cette option peut être utilisée à la place de l'option --pubkey.
--ecc-x <chiffres hexadécimaux>
Le paramètre x de la courbe elliptique sous forme d'une chaîne de chiffres hexadécimaux.
--ecc-y <chiffres hexadécimaux>
Le paramètre y de la courbe elliptique sous forme d'une chaîne de chiffres hexadécimaux.
--ecc-curveid <id-courbe>
L'identifiant de la courbe elliptique. secp256r1, secp384r1 et secp521r1 sont supportés. Si cette option n'est pas fournie, secp256r1 est supposé.
--exponent <exposant>
L'exposant de la clé publique. Par défaut, 0x10001 est supposé.
--signkey <nom-fichier>
La clé utilisée pour signer le certificat. Le fichier doit être au format PEM.
--signkey-password <mot-de-passe>
Mot de passe optionnel pour la clé de signature.
--signkey-pwd <mdp>
Ceci est une option alternative pour fournir le mot de passe de la clé de signature. Les formats suivants sont supportés pour mdp : 
- <mot-de-passe>         : mot de passe direct
- pass:<mot-de-passe>        : mot de passe direct
- file:<nom-fichier>         : mot de passe dans un fichier
- fd:<descripteur de fichier> : lire le mot de passe depuis un descripteur de fichier
- env:<variable d'environnement> : lire le mot de passe depuis une variable d'environnement

Tous les mots de passe lus à partir de fichiers et de descripteurs de fichiers doivent avoir une longueur maximale de 255 octets (plus un octet pour le caractère NUL de terminaison).

--parentkey-password <mot-de-passe>
Mot de passe optionnel pour une clé parente. Si une clé TPM est utilisée pour la signature, ce serait le mot de passe de la clé racine de stockage (SRK) du TPM.
--parentkey-pwd <mdp>
Ceci est une option alternative pour fournir le mot de passe de la clé parente. Voir la description ci-dessus pour les formats mdp supportés.
--issuercert <nom-fichier>
Le certificat X.509 du signataire qui assume le rôle d'une CA locale.
--out-cert <nom-fichier>
Le nom du fichier dans lequel écrire le certificat X.509v3. La sortie sera au format PEM.
--serial <numéro-de-série>
Numéro de série 32 bits optionnel pour le certificat.
--days <nombre>
Le nombre de jours pendant lesquels le certificat est valide ; par défaut, il est valide pendant 365 jours.
--pem
Écrire le certificat résultant au format PEM ; le format DER est le défaut.
--tpm-manufacturer <nom>
Le nom du fabricant du TPM.
--tpm-model <modèle>
Le modèle du TPM (numéro de pièce).
--tpm-version <version>
La version du firmware du TPM.
--platform-manufacturer <nom>
Le nom du fabricant de la plateforme.
--platform-model <modèle>
Le modèle de la plateforme.
--platform-version <version>
La version de la plateforme.
--subject <sujet>
Sujet à fournir, par exemple, l'emplacement du TPM, au format C=<pays>,ST=<état>,L=<lieu>. Notez que le lieu ne doit contenir aucun espace.
--tpm2
Émettre des certificats conformes à TPM 2.
--allow-signing
Créer une EK qui peut également être utilisée pour la signature. Sans cette option, l'EK ne peut être utilisée que pour le chiffrement de clés. Cette option nécessite --tpm2.
--decryption
Si --allow-signing est passé et que l'EK doit également être utilisable pour le chiffrement de clés, cette option doit être passée. Sinon, le chiffrement de clés est le comportement par défaut. Cette option nécessite --tpm2.
--print-capabilities (depuis v0.3)
Affiche les capacités qui ont été ajoutées à swtpm_cert après la version 0.2. La sortie peut contenir les éléments suivants : 
{
  "type": "swtpm_cert",
  "features": [
    "cmdarg-signkey-pwd",
    "cmdarg-parentkey-pwd"
  ],
  "version": "0.7.0"
}

Le champ version est disponible depuis la version 0.7.

La signification des verbes de fonctionnalités est la suivante :

cmdarg-signkey-pwd
L'option --signkey-pwd est supportée.
cmdarg-parentkey-pwd
L'option --parentkey-pwd est supportée.
--help, -h
Affiche l'écran d'aide
