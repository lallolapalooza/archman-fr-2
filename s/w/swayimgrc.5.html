SWAYIMGRC(5) Configuration de Swayimg SWAYIMGRC(5)

NOM

swayimgrc - fichier de configuration pour le visualiseur Swayimg

SYNOPIS

Le fichier de configuration de Swayimg est un fichier texte au format INI utilisé pour remplacer les paramètres par défaut.

EMPLACEMENT

Swayimg recherche un fichier de configuration aux emplacements suivants, dans cet ordre :

  • $XDG_CONFIG_HOME/swayimg/config
  • $HOME/.config/swayimg/config
  • $XDG_CONFIG_DIRS/swayimg/config
  • /etc/xdg/swayimg/config

DESCRIPTION

La structure du fichier INI se compose de paires clé-valeur pour les propriétés et de sections qui organisent ces propriétés.

Le signe dièse (#) au début d'une ligne indique un commentaire. Les lignes vides et les commentaires sont ignorés.

L'élément de base contenu dans le fichier INI est la clé ou la propriété. Chaque clé a un nom et une valeur, délimités par un signe égal (=). Le nom apparaît à gauche du signe égal. La valeur peut contenir n'importe quel caractère.

Les clés sont regroupées en sections nommées. Le nom de la section apparaît sur une ligne seule, entre crochets. Toutes les clés après la déclaration de section lui sont associées.

La directive spéciale include permet de charger un autre fichier de configuration. La directive doit contenir le chemin d'accès ou le nom du fichier à charger pour la configuration.

Toute option peut être remplacée en utilisant l'argument --config sur la ligne de commande, par exemple : swayimg --config="general.mode=gallery".

SECTIONS

Général

Configuration générale pour l'ensemble de l'application : [general].

mode = viewer|slideshow|gallery

Mode utilisé au démarrage, viewer par défaut.

size = fullscreen|image|L,H

Taille initiale de la fenêtre :
  • fullscreen : utiliser le mode plein écran ;
  • image : définir la taille à partir de la première image de la première image ;
  • L,H : taille absolue de la fenêtre en pixels, par défaut 1280,720.

position = auto|X,Y

Sway et Hyprland uniquement : position initiale de la fenêtre :
  • auto : laisser le gestionnaire de fenêtres contrôler la position de la fenêtre (par défaut) ;
  • X,Y : coordonnées absolues du coin supérieur gauche, par exemple 100,200.

overlay = yes|no

Sway et Hyprland uniquement : crée une fenêtre flottante avec les mêmes coordonnées et la même taille que la fenêtre actuellement active. Cette option remplace les paramètres position et size. La valeur par défaut est no.

decoration = yes|no

Utiliser la décoration de fenêtre (bordures et titre), no par défaut.

sigusr1 = ACTION

Action à effectuer lorsque le signal SIGUSR1 est déclenché, reload par défaut.

sigusr2 = ACTION

Action à effectuer lorsque le signal SIGUSR2 est déclenché, next_file par défaut.

app_id = NOM

Identifiant de l'application utilisé comme nom de classe de fenêtre, swayimg par défaut.

Paramètres du mode DRM

Configuration utilisée pour initialiser le mode DRM : [drm].

path = auto|CHEMIN

Chemin d'accès au périphérique DRM, par exemple /dev/dri/card1, auto par défaut (utilise le premier disponible).

connector = auto|NOM

Nom du connecteur, par exemple DP-1, auto par défaut (utilise le premier disponible).

mode = auto|MODE

Résolution et fréquence d'affichage, par exemple 1920x1080@60, auto par défaut (utilise la résolution préférée ou la première disponible).

Visualiseur

Configuration spécifique au mode visualiseur : [viewer].

window = auto|extend|mirror|#COULEUR

Arrière-plan de la fenêtre :
  • auto : remplir l'arrière-plan de la fenêtre en mode extend ou mirror selon le rapport d'aspect de l'image ;
  • extend : remplir la fenêtre avec l'image actuelle et la flouter ;
  • mirror : remplir la fenêtre avec l'image actuelle en miroir et la flouter ;
  • #COULEUR : couleur unie en RVB ou RGBA, #00000000 par défaut ;

transparency = grid|#COULEUR

Arrière-plan pour les images transparentes :
  • grid : dessiner un damier (par défaut) ;
  • #COULEUR : couleur unie en RVB ou RGBA, par exemple #10ff4280.

scale = MODE

Échelle initiale de l'image :
  • optimal : 100 % ou moins pour s'adapter à la fenêtre (par défaut) ;
  • width : adapter la largeur de l'image à la largeur de la fenêtre ;
  • height : adapter la hauteur de l'image à la hauteur de la fenêtre ;
  • fit : s'adapter à la fenêtre ;
  • fill : rogner l'image pour remplir la fenêtre ;
  • real : taille réelle (100 %) ;
  • keep : conserver la même échelle que pour l'image vue précédemment.

position = POSITION

Position initiale de l'image dans la fenêtre :
  • center : centre de la fenêtre (par défaut) ;
  • top : en haut et centré horizontalement ;
  • bottom : en bas et centré horizontalement ;
  • left : à gauche et centré verticalement ;
  • right : à droite et centré verticalement ;
  • top_left : coin supérieur gauche de la fenêtre ;
  • top_right : coin supérieur droit de la fenêtre ;
  • bottom_left : coin inférieur gauche de la fenêtre ;
  • bottom_right : coin inférieur droit de la fenêtre ;
  • free : comme center, mais déplaçable librement (non fixe).

antialiasing = METHODE

Méthode d'anti-crénelage lors de la mise à l'échelle des images. En général, les méthodes s'améliorent en qualité et diminuent en performance de haut en bas :
  • none : voisin le plus proche, ou pas d'anti-crénelage ;
  • box : voisin le plus proche en agrandissement, moyenne dans une boîte en réduction ;
  • bilinear : bilinéaire ;
  • bicubic : bicubique avec la spline de Catmull-Rom ;
  • mks13 : Magic Kernel avec l'approximation Sharp de 2013 (par défaut).

loop = yes|no

Boucler la liste des images : sauter à la première image lorsque la fin de la liste est atteinte, yes par défaut.

history = TAILLE

Nombre d'images précédemment vues à stocker dans le cache, 1 par défaut.

preload = TAILLE

Nombre d'images à précharger dans un thread séparé, 1 par défaut.

Diapositive

Configuration spécifique au mode diaporama : [slideshow].

time = SECONDES

Durée de chaque image du diaporama en secondes, 3 par défaut.

window

Même format que pour viewer.window.

transparency

Même format que pour viewer.transparency.

scale

Même format que pour viewer.scale.

position

Même format que pour viewer.position.

antialiasing

Même format que pour viewer.antialiasing.

Galerie

Configuration spécifique au mode galerie : [gallery].

size = PIXELS

Hauteur et largeur de chaque miniature en pixels, 200 par défaut.

cache = TAILLE

Nombre maximum de miniatures invisibles stockées dans le cache mémoire, 100 par défaut.

preload = yes|no

Charger non seulement les miniatures visibles, mais aussi les miniatures adjacentes, no par défaut. Le paramètre cache limite le nombre de miniatures préchargées.

pstore = yes|no

Activer/désactiver le stockage des miniatures dans le p

NAME

swayimgrc - configuration file for swayimg

SYNOPSIS

~/.config/swayimg/config, ~/.config/swayimg/config.rc, /etc/swayimg/config, /etc/swayimg/config.rc

LOCATION

Configuration file is looked for in the following locations in order:

1. ~/.config/swayimg/config
2. ~/.config/swayimg/config.rc
3. /etc/swayimg/config
4. /etc/swayimg/config.rc

If none of them exist, default values are used.

DESCRIPTION

The configuration file is split into sections denoted by square brackets, e.g. [section]. Sections can contain comments denoted by hash character #.

GENERAL

Default settings:

cache_size
Set size of the cache in MB. Default: 1024.
font
Font specification. Default: monospace.
font_size
Font size in points. Default: 10.
colors COLOR...
Set colors for various UI elements. Scheme is specified as name=color. See wiki for supported color names.
max_connections N
Maximum number of client connections. Default: 16.
sorting MODE
Set sorting mode for gallery. MODE is: asc, desc, random.
default_view MODE
Set default view mode. MODE is: viewer, gallery. Default: viewer.
slideshow_delay SECONDS
Set delay between images in slideshow mode in seconds. Default: 5.
slideshow_loop
Loop slideshow indefinitely.
slideshow_random
Play images in random order in slideshow.
bg_image FILE
Set background image. Applies to viewer and gallery modes.
bg_color COLOR
Set background color. Applies to viewer and gallery modes.

KEYS

Set key bindings. Syntax is: KEYBINDING = ACTION. KEYBINDING can be composed of modifiers (Ctrl, Alt, Shift, Super) and key name, e.g.: Ctrl+Shift+o. See xkb keycodes for names.

escape
Hide window.
enter
Enter/exit fullscreen.
space
Next image.
backspace
Previous image.
home
First image.
end
Last image.
pgup
Previous image.
pgdn
Next image.
left
Previous image.
right
Next image.
up
Previous image.
down
Next image.
delete
Delete current image.
c
Copy current image to clipboard.
i
Show image info.
z
Zoom to fit.
x
Zoom to original size.
r
Rotate image.
f
Flip image.
a
Toggle anti-aliasing.
n
Switch to next image in gallery.
p
Switch to previous image in gallery.
g
Switch to gallery view.
v
Switch to viewer view.
s
Start/stop slideshow.
q
Quit.
o
Open file.
e
Execute external command.
t
Toggle thumbnail size.
ANY_KEY
Any other key can be bound to any action.

ACTIONS

List of available actions:

prev

Viewer/Gallery modes. Previous image.

next

Viewer/Gallery modes. Next image.

first

Viewer/Gallery modes. First image.

last

Viewer/Gallery modes. Last image.

zoom FACTOR

Viewer mode only. Zoom image by FACTOR. FACTOR is float value, e.g. 1.1.

zoom_to MODE

Viewer mode only. Zoom image to MODE. MODE is: fit, orig.

rotate_left

Viewer mode only. Rotate image anticlockwise.

rotate_right

Viewer mode only. Rotate image clockwise.

flip_vertical

Viewer mode only. Flip image vertically.

flip_horizontal

Viewer mode only. Flip image horizontally.

thumb SIZE

Gallery mode only. Resize thumbnails, SIZE is:
  • delta in pixels with + or - sign (e.g. +10);
  • absolute size in pixels, e.g. 200.

reload

Viewer/Gallery modes only. Reset cache and reload current image.

antialiasing [MODE]

Viewer/Gallery modes only. Set anti-aliasing mode or switch if on/off, MODE is:
  • one of the viewer.antialiasing modes (none/mks13/etc);
  • empty value to toggle AA on/off.

info [MODE]

Set text info mode or cycle through them, MODE is one of the configured schemes: off/viewer/gallery or empty value to switch to the next mode.

exec COMMAND

Execute an external command, use % to substitute the full path to the current image, %% to escape %. Swayimg waits for child processes to complete, to "detach" the child process from Swayimg, call any another launcher, for example:
  • Sway: `swaymsg exec ...`;
  • Hyprland: `hyprctl dispatch exec ...`;
  • Niri: `niri msg action spawn ...`.

drag

Mouse buttons in viewer mode only. Set the button for drag operation.

export FILE

Viewer mode only. Export currently displayed image to PNG file.

pause

Slideshow mode only. Pause/continue slideshow.

status TEXT

Display text in status field.

exit

Exit the application.

EXAMPLES

Sample file is available on the project repository: https://github.com/artemsen/swayimg/blob/master/extra/swayimgrc or locally after installation: /usr/share/swayimg/swayimgrc.

[list]
order = random
[font]
size = 16
[keys]
