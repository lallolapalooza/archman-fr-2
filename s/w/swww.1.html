swww(1) Manuel des commandes générales swww(1)

NOM

swww - Une solution à vos problèmes de fond d'écran Wayland

SYNTAXE

swww <COMMANDE>

COMMANDES

clear

Remplit les sorties spécifiées avec la couleur donnée

restore

Restaure la dernière image affichée sur les sorties spécifiées

clear-cache

Supprime le répertoire cache de `swww`

img

Envoie une image (ou un gif animé) pour que le démon l'affiche

kill

Arrête le démon

query

Demande au démon d'afficher les informations de sortie (noms et dimensions)

help [COMMANDE]

Affiche l'aide ou l'aide de la commande donnée

OPTIONS

-h, --help

Affiche l'aide (voir un résumé avec '-h')

-V, --version

Affiche la version

DESCRIPTION

swww est un gestionnaire de fonds d'écran qui vous permet de changer ce que vos moniteurs affichent en arrière-plan en contrôlant le swww-daemon à l'exécution.

Il prend en charge les gifs animés et l'affichage de contenus différents sur différents moniteurs. J'ai également fait de mon mieux pour qu'il soit aussi efficace que possible en termes de ressources.

Pour commencer, exécutez swww-daemon. Cela configurera le swww-daemon. Ensuite, vous pouvez envoyer des images à afficher avec swww img. Pour arrêter le démon, utilisez swww kill.

Notez que swww ne fonctionne qu'avec un compositeur qui implémente le protocole layer-shell. Typiquement, les compositeurs basés sur wlr-roots.

FICHIERS

swww créera les fichiers suivants sur votre système :

•
Un socket dans ${XDG_RUNTIME_DIR}/${WAYLAND_DISPLAY}-swww-daemon.<namespace>.socket, ou
/tmp/swww/${WAYLAND_DISPLAY}-swww-daemon.<namespace>.socket, si $XDG_RUNTIME_DIR n'est pas défini.
•
Des fichiers cache dans $XDG_CACHE_HOME/swww ou $HOME/.cache/swww si $XDG_CACHE_HOME n'existe pas. Ceux-ci sont utilisés pour définir le fond d'écran à l'image précédente lorsqu'un moniteur est (re)connecté ou allumé.
