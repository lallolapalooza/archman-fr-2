swaynag(5) Formats de fichier swaynag(5)

NOM

swaynag - fichier de configuration de swaynag

SYNTAXE

$HOME/.swaynag/config, $XDG_CONFIG_HOME/swaynag/config, SYSCONFDIR/swaynag/config

FICHIER DE CONFIGURATION

Au début du fichier de configuration, les options de swaynag peuvent être définies en utilisant le format long-option=valeur. Celles-ci seront utilisées comme valeurs par défaut si swaynag n'est pas lancé avec ces options. Cela peut être utile pour définir une police, une sortie et un bord préférés.

Sous les options, des types personnalisés peuvent être définis. Pour définir un type, utilisez le format suivant :

[nom-du-type]
option=valeur

Toutes les couleurs peuvent être données sous la forme RRGGBB ou RRGGBBAA. Les couleurs suivantes peuvent être définies :

background=<couleur>

La couleur d'arrière-plan pour swaynag.

border=<couleur>

La couleur à utiliser pour les bordures des boutons.

border-bottom=<couleur>

La couleur de la ligne de bordure en bas de swaynag.

button-background=<couleur>

La couleur d'arrière-plan des boutons.

text=<couleur>

La couleur du texte.

button-text=<couleur>

La couleur du texte des boutons.

Les options de dimensionnement suivantes peuvent également être définies :

border-bottom-size=<taille>

Définit l'épaisseur de la bordure inférieure.

message-padding=<remplissage>

Définit le remplissage du message.

details-background=<couleur>

La couleur d'arrière-plan des détails.

details-border-size=<taille>

Définit l'épaisseur de la bordure des détails.

button-border-size=<taille>

Définit l'épaisseur de la bordure des boutons.

button-gap=<espace>

Définit la taille de l'espace entre les boutons.

button-dismiss-gap=<espace>

Définit la taille de l'espace entre le bouton de rejet et un autre bouton.

button-margin-right=<marge>

Définit la marge entre le bouton de rejet et le bord.

button-padding=<remplissage>

Définit le remplissage du texte du bouton.

De plus, les options suivantes peuvent se voir attribuer une valeur par défaut par type :

edge=top|bottom

Définit le bord à utiliser.

layer=overlay|top|bottom|background

Définit la couche à utiliser.

font=<police>

Définit la police à utiliser.

output=<sortie>

Définit la sortie à utiliser. Ce doit être le nom d'une xdg_output.

EXEMPLE

font=Monospace 12
edge=bottom
[green]
edge=top
background=00AA00
border=006600
border-bottom=004400
text=FFFFFF
button-background=00CC00
message-padding=10
