NOM

swaybg - Fond d'écran pour Wayland

SYNOPSIS

swaybg [options...]

Affiche une image de fond sur toutes les sorties de votre session Wayland.

Sans sortie spécifiée, les options d'apparence s'appliquent à toutes les sorties. Les options d'apparence par sortie peuvent être définies en passant -o, --output suivi de ces options.

OPTIONS

-c, --color <[#]rrggbb>

Définit la couleur de fond.

-h, --help

Affiche le message d'aide et quitte.

-i, --image <chemin>

Définit l'image de fond.

-m, --mode <mode>

Mode de mise à l'échelle pour les images : stretch, fill, fit, center, ou tile. Utilisez le mode supplémentaire solid_color pour afficher uniquement la couleur de fond, même si une image de fond est spécifiée.

-o, --output <nom>

Sélectionne une sortie à configurer. Les options d'apparence ultérieures ne s'appliqueront qu'à cette sortie. La valeur spéciale * sélectionne toutes les sorties.

-v, --version

Affiche le numéro de version et quitte.
