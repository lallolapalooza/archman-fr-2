NOM

swirl - dessine des motifs tourbillonnants cyclant en couleur

SYNTAXE

swirl [--display hôte:écran.serveur] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id nombre][--mono] [--install] [--visual visual] [--ncolors nombre] [--delay microsecondes] [--count nombre]

[--fps]

DESCRIPTION

Le programme swirl dessine des motifs tourbillonnants cyclant en couleur.

OPTIONS

swirl accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id nombre
Dessiner sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, faire comme si on était sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visual
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--ncolors nombre
Combien de couleurs utiliser (si possible). Par défaut 200.
--count nombre
--fps
Afficher le taux d'images par seconde et la charge CPU actuels.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1), xlock(1)
