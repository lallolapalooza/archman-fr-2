NOM

swtpm_bios - Outil de simulation du BIOS pour swtpm

SYNTAXE

swtpm_bios [OPTIONS]

DESCRIPTION

swtpm_bios est un outil qui peut envoyer des commandes au TPM (programme swtpm) qui sont typiquement utilisées par le BIOS pour initialiser le TPM. L'utilisateur peut choisir parmi plusieurs options en ligne de commande pour définir l'état dans lequel le TPM doit être configuré.

Cette commande nécessite que la variable d'environnement TCSD_USE_TCP_DEVICE soit définie pour la communication via TCP. Sinon, elle utilisera le périphérique défini dans la variable d'environnement TPM_DEVICE ou se rabattra sur l'utilisation de /dev/tpm0 pour envoyer les commandes. En mode TCP, la variable d'environnement TCSD_TCP_DEVICE_HOSTNAME est utilisée pour indiquer l'hôte auquel envoyer les commandes. Par défaut, localhost est supposé. Le port TCP par défaut est 6545 à moins que la variable d'environnement TCSD_TCP_DEVICE_PORT n'indique un autre port.

En cas de succès, 0 sera retourné. En cas d'erreur TPM rencontrée, le code de retour sera 128. En cas d'échec de communication, 255 sera retourné. Si le TPM doit être réinitialisé pour devenir actif, 129 sera retourné.

Cette commande enverra la séquence de commandes suivante au TPM.

TPM_Startup(mode choisi) -- démarre le TPM
TSC_PhysicalPresence(0x20) -- PhysicalPresenceCMDEnable
TSC_PhysicalPresence(0x08) -- active la présence physique
TPM_GetCapability -- obtient les indicateurs permanents
TPM_PhysicalEnable -- active le TPM
TPM_PhysicalSetDeactivated(0x0) -- active le TPM
TPM_ContinueSelfTest -- continue l'auto-test
TSC_PhysicalPresence(0x20) -- PhysicalPresenceCMDEnable
TSC_PhysicalPresence(0x14) -- désactive la présence physique & la verrouille

Les options suivantes sont prises en charge :

--tpm-device <périphérique>
Utilise le périphérique donné plutôt que /dev/tpm0 par défaut. Cette option remplace la variable d'environnement TPM_DEVICE.
--tcp <serveur>:<port>
Se connecte au serveur et port donnés ; si aucun serveur n'est donné, 127.0.0.1 est utilisé ; si le port n'est pas donné, le port par défaut 6545 est utilisé.
--unix <chemin>
Se connecte au chemin UnixIO donné.
-tpm2
Le périphérique est un TPM 2.
-c
Envoie TPM_Startup(ST_CLEAR) (par défaut). Ceci demande au TPM de démarrer avec un état effacé.
-s
Envoie TPM_Startup(ST_STATE). Ceci demande au TPM de démarrer en restaurant l'état précédemment sauvegardé.
-d
Envoie TPM_Startup(ST_DEACTIVATED). Ceci demande au TPM de démarrer en mode désactivé. Cette option n'a aucun effet sur un TPM 2.
-n
N'envoie pas de commande TPM_Startup.
-o
Envoie uniquement la commande de démarrage et rien d'autre.
-ea
S'assure que le TPM est activé ; si le TPM nécessite une réinitialisation, le programme se terminera et retournera un code de retour de 129.
-cs
Envoie une commande TPM_ContinueSelfTest à un TPM 1.2 et une commande TPM2_IncrementalSelfTest à un TPM 2.
-u
Abandonne la présence physique sur un TPM 1.2. Dans le cas d'un TPM 2, définit la hiérarchie de la plateforme avec un mot de passe aléatoire.
-v
Affiche la version et quitte.
-h
Affiche l'écran d'aide et quitte.
