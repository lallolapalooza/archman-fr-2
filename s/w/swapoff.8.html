SWAPON(8) Administration système SWAPON(8)

NOM

swapon, swapoff - activer/désactiver les périphériques et fichiers pour la pagination et le swap

SYNTAXE

swapon [options] [fichier-spécial...]

swapoff [-va] [fichier-spécial...]

DESCRIPTION

swapon est utilisé pour spécifier les périphériques sur lesquels la pagination et le swap doivent avoir lieu.

Le périphérique ou fichier utilisé est donné par le paramètre fichier-spécial. Il peut être de la forme -L label ou -U uuid pour indiquer un périphérique par son label ou son uuid.

Les appels à swapon se font normalement dans les scripts de démarrage du système, rendant disponibles tous les périphériques de swap, afin que l'activité de pagination et de swap soit entrelacée sur plusieurs périphériques et fichiers.

swapoff désactive le swap sur les périphériques et fichiers spécifiés. Lorsque l'option -a est donnée, le swap est désactivé sur tous les périphériques et fichiers de swap connus (tels que trouvés dans /proc/swaps ou /etc/fstab).

OPTIONS

-a, --all

Tous les périphériques marqués comme "swap" dans /etc/fstab sont rendus disponibles, à l'exception de ceux ayant l'option "noauto". Les périphériques déjà utilisés comme swap sont silencieusement ignorés.

-T, --fstab chemin

Spécifie un fichier fstab alternatif pour la compatibilité avec mount(8). Si chemin est un répertoire, alors les fichiers du répertoire sont triés par strverscmp(3) ; les fichiers commençant par "." ou sans extension .fstab sont ignorés. L'option peut être spécifiée plusieurs fois. Cette option est principalement conçue pour les scripts initramfs ou chroot où une configuration supplémentaire est spécifiée au-delà de la configuration système standard.

-d, --discard[=politique]

Active les suppressions de swap, si le périphérique de support de swap prend en charge l'opération de suppression (discard) ou de découpage (trim). Cela peut améliorer les performances sur certains périphériques à état solide, mais souvent ce n'est pas le cas. L'option permet de choisir entre deux politiques de suppression de swap disponibles :

--discard=once

pour effectuer une opération de suppression unique pour toute la zone de swap lors de l'appel à swapon ; ou

--discard=pages

pour supprimer de manière asynchrone les pages de swap libérées avant qu'elles ne soient réutilisables.

Si aucune politique n'est sélectionnée, le comportement par défaut est d'activer les deux types de suppression. Les options de montage /etc/fstab discard, discard=once, ou discard=pages peuvent également être utilisées pour activer les indicateurs de suppression.

-e, --ifexists

Ignore silencieusement les périphériques qui n'existent pas. L'option de montage /etc/fstab nofail peut également être utilisée pour ignorer les périphériques non existants.

-f, --fixpgsz

Réinitialise (exécute mkswap) l'espace de swap si sa taille de page ne correspond pas à celle du noyau en cours d'exécution. mkswap(8) initialise le périphérique entier et ne vérifie pas les blocs défectueux.

-L label

Utilise la partition qui a le label spécifié. (Pour cela, l'accès à /proc/partitions est nécessaire.)

-o, --options opts

Spécifie les options de swap par une chaîne séparée par des virgules compatible avec fstab. Par exemple :

swapon -o pri=1,discard=pages,nofail /dev/sda2

La chaîne opts est évaluée en dernier et remplace toutes les autres options de la ligne de commande.

-p, --priority priorité

Spécifie la priorité du périphérique de swap. priorité est une valeur comprise entre 0 et 32767. Des nombres plus élevés indiquent une priorité plus élevée. Voir swapon(2) pour une description complète des priorités de swap. Ajoutez pri=valeur au champ d'options de /etc/fstab pour une utilisation avec swapon -a. Lorsqu'aucune priorité n'est définie, le noyau Linux utilise par défaut des nombres négatifs.

-s, --summary

Affiche un résumé de l'utilisation du swap par périphérique. Équivalent à cat /proc/swaps. Ce format de sortie est DÉPRÉCIÉ au profit de --show qui offre un meilleur contrôle sur les données de sortie.

--show[=colonne...]

Affiche un tableau définissable de zones de swap. Voir la sortie de --help pour une liste des colonnes disponibles.

--output-all

Affiche toutes les colonnes disponibles.

--noheadings

N'affiche pas d'en-têtes lors de l'affichage de la sortie de --show.

--raw

Affiche la sortie de --show sans aligner les colonnes du tableau.

--bytes

Affiche la taille du swap en octets dans la sortie de --show au lieu d'unités faciles à lire.

-U uuid

Utilise la partition qui a le uuid spécifié.

-v, --verbose

Être verbeux.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

STATUT DE SORTIE

swapoff a les valeurs de statut de sortie suivantes depuis v2.36 :

0

succès

2

le système a une mémoire insuffisante pour arrêter le swap (OOM)

4

l'appel système swapoff(2) a échoué pour une autre raison

8

erreur système non liée à l'appel swapoff(2) (manque de mémoire, ...)

16

erreur d'utilisation ou de syntaxe

32

tous les swapoff ont échoué avec --all

64

certains swapoff ont réussi avec --all

La commande swapoff --all retourne 0 (tous réussis), 32 (tous échoués), ou 64 (certains échoués, certains réussis).

+ Les anciennes versions avant v2.36 n'avaient pas de statut de sortie documenté, 0 signifie succès dans toutes les versions.

NOTES

Fichiers avec trous

L'implémentation du fichier de swap dans le noyau s'attend à pouvoir écrire directement dans le fichier, sans l'aide du système de fichiers. Ceci pose problème pour les fichiers avec des trous ou sur des fichiers copy-on-write sur des systèmes de fichiers comme Btrfs.

Les commandes comme cp(1) ou truncate(1) créent des fichiers avec des trous. Ces fichiers seront rejetés par swapon.

Les fichiers préalloués créés par fallocate(1) peuvent également être interprétés comme des fichiers avec trous en fonction du système de fichiers. Les fichiers de swap préalloués sont pris en charge sur XFS depuis Linux 4.18.

La solution la plus portable pour créer un fichier de swap est d'utiliser dd(1) et /dev/zero.

Btrfs

Les fichiers de swap sur Btrfs sont pris en charge depuis Linux 5.0 sur les fichiers avec l'attribut nocow. Voir la page de manuel btrfs(5) pour plus de détails.

Depuis la version 2.41, la commande mkswap --file peut créer un nouveau fichier de swap avec l'attribut nocow.

NFS

Le swap sur NFS peut ne pas fonctionner.

Suspendre

swapon détecte et réécrit automatiquement une signature d'espace d'échange avec d'anciennes données de suspension logicielle (par exemple, S1SUSPEND, S2SUSPEND, ...). Le problème est que si nous ne le faisons pas, nous obtenons une corruption de données lors de la prochaine tentative de désuspension.

HISTORIQUE

La commande swapon est apparue dans 4.0BSD.
