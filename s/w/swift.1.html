NOM

swift - Outil client OpenStack Swift

SYNTAXE

swift [options] <commande> [args]

DESCRIPTION

L'outil swift est une utilitaire en ligne de commande pour communiquer avec un environnement OpenStack Object Storage (Swift). Il permet d'effectuer plusieurs types d'opérations.

COMMANDES

stat [options-de-commande] [conteneur] [objet]

Affiche les informations pour le compte, le conteneur ou l'objet en fonction des arguments fournis (s'il y en a). En mode verbeux, l'URL de stockage et le jeton d'authentification sont également affichés. L'option --lh signale les tailles dans un format lisible par l'homme, similaire à ls -lh.

list [options-de-commande] [conteneur]

Liste les conteneurs du compte ou les objets d'un conteneur. L'option -p <préfixe> ou --prefix <préfixe> permet de ne lister que les éléments commençant par ce préfixe. L'option -d <dél> ou --delimiter <dél> (pour les listages de conteneurs uniquement) permet de regrouper les éléments avec le délimiteur donné (voir la documentation générale d'OpenStack Swift pour ce que cela signifie).

Les options -l ou --long et --lh fournissent plus de détails, similaires à ls -l et ls -lh, cette dernière fournissant les tailles dans un format lisible par l'homme (par ex. 3K, 12M, etc.). Ces deux dernières options entraînent une consommation de ressources plus importante pour obtenir ces détails, ce qui est directement proportionnel au nombre de conteneurs ou d'objets listés. Avec l'option -t ou --total, elles ne signalent que les totaux.

upload [options-de-commande] conteneur fichier_ou_répertoire [fichier_ou_répertoire] [...]

Télécharge dans le conteneur donné les fichiers et répertoires spécifiés par les arguments restants. L'option -c ou --changed permet de ne télécharger que les fichiers qui ont changé depuis le dernier téléchargement. L'option --object-name <nom-objet> permet de télécharger un fichier et de nommer l'objet <nom-objet> ou de télécharger un répertoire et d'utiliser <nom-objet> comme préfixe d'objet. Si le nom du fichier est "-", le contenu est lu depuis l'entrée standard. Dans ce cas, --object-name est obligatoire et aucun autre fichier ne peut être fourni. Les options -S <taille> ou --segment-size <taille> et --leave-segments, ainsi que d'autres, sont également disponibles (voir swift upload --help pour plus de détails).

post [options-de-commande] [conteneur] [objet]

Met à jour les méta-informations pour le compte, le conteneur ou l'objet en fonction des arguments fournis. Si le conteneur n'est pas trouvé, il sera créé automatiquement ; mais ce n'est pas le cas pour les comptes et les objets. Les conteneurs autorisent également les options -r (ou --read-acl) et -w (ou --write-acl). L'option -m ou --meta est autorisée sur tous et est utilisée pour définir les éléments de méta-données utilisateur à définir sous la forme Nom:Valeur. Cette option peut être répétée. Pour plus de détails et d'options, voir swift post --help. Exemple : post -m Color:Blue -m Size:Large

copy [options-de-commande] conteneur objet

Copie un objet vers une nouvelle destination ou ajoute des méta-données utilisateur à l'objet (les méta-données utilisateur actuelles seront préservées, contrairement à la commande post) en fonction des arguments fournis. L'option --destination définit la destination sous la forme /conteneur/objet. Si elle n'est pas définie, l'objet sera copié sur lui-même, ce qui est utile pour ajouter des méta-données. L'option -M ou --fresh-metadata copie l'objet sans les méta-données utilisateur existantes. L'option -m ou --meta est toujours autorisée et est utilisée pour définir les éléments de méta-données utilisateur à définir sous la forme Nom:Valeur (cette option peut être répétée). Pour plus de détails et d'options, voir swift copy --help.

download [options-de-commande] [conteneur] [objet] [objet] [...]

Télécharge tout le contenu du compte (avec --all), ou tout le contenu d'un conteneur, ou une liste d'objets en fonction des arguments fournis. Pour le téléchargement d'un seul objet, vous pouvez utiliser l'option -o [--output] <nom-fichier> pour rediriger la sortie vers un fichier spécifique ou, si c'est "-", pour la rediriger simplement vers la sortie standard ou, avec --no-download, pour ne rien écrire sur le disque. L'option --ignore-checksum permet de désactiver la validation de la somme de contrôle. Vous pouvez spécifier des en-têtes optionnels avec l'option répétable de type cURL -H [--header]. Pour plus de détails et d'options, voir swift download --help. L'option --ignore-mtime ignore l'entrée de métadonnées x-object-meta-mtime sur l'objet (si présente) et crée plutôt les fichiers téléchargés avec de nouvelles valeurs atime et mtime.

delete [options-de-commande] [conteneur] [objet] [objet] [...]

Supprime tout le contenu du compte (avec --all), ou tout le contenu d'un conteneur, ou tous les objets d'un conteneur qui commencent par une chaîne donnée (fournie par --prefix), ou une liste d'objets en fonction des arguments fournis. Les segments des objets manifestes seront également supprimés, sauf si vous spécifiez l'option --leave-segments. Pour plus de détails et d'options, voir swift delete --help.

capabilities [options-de-commande] [url-proxy]

Affiche les capacités du cluster. Si l'option proxy-url n'est pas fournie, l'URL de stockage récupérée après authentification est utilisée comme proxy-url.

Par défaut, la sortie inclut la liste des middlewares Swift activés ainsi que les options pertinentes pour chacun d'eux. De plus, la commande affiche les options pertinentes pour le noyau Swift.

L'option --json affichera une représentation JSON des capacités du cluster. Ceci est généralement plus adapté à la consommation par d'autres programmes, tels que jq.

Exemple : capabilities https://swift.example.com
capabilities --json

tempurl [option-de-commande] méthode temps chemin clé

Génère une URL temporaire permettant un accès non authentifié à l'objet Swift au chemin donné, en utilisant la méthode HTTP donnée, pendant la durée donnée, en utilisant la clé TempURL donnée.

Le temps peut être spécifié soit comme un entier représentant le nombre de secondes pendant lesquelles l'URL temporaire est valide, soit comme un horodatage ISO 8601 dans l'un des formats suivants : date complète : AAAA-MM-JJ (par ex. 1997-07-16), date complète plus heures, minutes et secondes : AAAA-MM-JJThh:mm:ss (par ex. 1997-07-16T19:20:30) ou date complète plus heures, minutes et secondes avec le descripteur UTC : AAAA-MM-JJThh:mm:ssZ (par ex. 1997-07-16T19:20:30Z). Attention, si vous n'utilisez pas ce dernier format, l'horodatage est généré en utilisant le fuseau horaire de votre locale. Si le premier format est utilisé, la partie heure sera égale à 00:00:00.

Avec l'option --prefix-based, une URL basée sur un préfixe est générée.

L'option --iso8601 fournit des horodatages UTC ISO 8601 au lieu des horodatages Unix dans l'URL générée.

Si l'argument optionnel --absolute est fourni et que l'argument temps est spécifié en secondes, les secondes sont interprétées comme un horodatage Unix auquel l'URL expirera.

Exemple : tempurl GET $(date -d "1 Jan 2016" +%s) /v1/AUTH_foo/bar_container/quux.md ma_cle_tempurl_secrete --absolute

auth

Affiche les variables d'authentification liées à l'authentification dans un format convivial pour le shell. Pour des exemples, voir swift auth --help.

OPTIONS

--version Affiche la version du programme et quitte
-h, --help Affiche ce message d'aide (ou celui d'une sous-commande si placé après une commande) et quitte
-s, --snet Utilise le réseau interne SERVICENET
-v, --verbose Affiche plus d'informations
-q, --quiet Supprime la sortie de statut
-A AUTH, --auth=AUTH URL pour obtenir un jeton d'authentification
-U USER, --user=USER Nom d'utilisateur pour obtenir un jeton d'authentification
-V 1|2, --auth-version=VERSION Version du protocole d'authentification
-K KEY, --key=KEY Clé pour obtenir un jeton d'authentification
--os-storage-url=URL Utilise ceci à la place de l'URL retournée par l'authentification
--os-help Affiche toutes les options d'authentification OpenStack
Pour plus d'options, voir swift --help et swift --os-help.

EXEMPLE

swift -A https://127.0.0.1:443/auth/v1.0 -U swiftops:swiftops -K swiftops stat
