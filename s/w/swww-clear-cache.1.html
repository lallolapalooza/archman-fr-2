swww-clear-cache(1) Manuel des commandes générales swww-clear-cache(1)

NOM

swww-clear-cache

SYNTAXE

swww clear-cache

OPTIONS

-h, --help

Affiche l'aide (voir un résumé avec '-h')

DESCRIPTION

Supprime le répertoire de cache de `swww`.

Le cache se trouve dans $XDG_CACHE_HOME/swww ou $HOME/.cache/swww si $XDG_CACHE_HOME n'existe pas. Pour chaque moniteur, il y aura un fichier à ces emplacements correspondant à l'image/animation actuelle affichée.

De plus, le cache conservera des versions prétraitées des `gif`. Ainsi, si vous chargez un `gif` volumineux, vous devrez payer le prix de son traitement la première fois.

Notez que `swww` supprimera automatiquement toute animation prétraitée créée avec une version précédente de `swww` du cache.
