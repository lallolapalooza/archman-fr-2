swaylock(1) Manuel des commandes générales swaylock(1)

NOM

swaylock - Verrouilleur d'écran pour Wayland

SYNTAXE

swaylock [options...]

Verrouille votre session Wayland.

OPTIONS

-C, --config <chemin>

Le fichier de configuration à utiliser. Par défaut, les chemins suivants sont vérifiés : $HOME/.swaylock/config, $XDG_CONFIG_HOME/swaylock/config, et SYSCONFDIR/swaylock/config. Tous les indicateurs, à l'exception de celui-ci, sont des options valides dans le fichier de configuration en utilisant le format long-option=valeur. Pour des options telles que ignore-empty-password, fournissez simplement le long-option. Tous les tirets initiaux doivent être omis et le signe égal est requis pour les indicateurs qui prennent un argument.

-d, --debug

Activer la sortie de débogage.

-e, --ignore-empty-password

Lorsqu'un mot de passe vide est fourni, ne pas le valider.

-F, --show-failed-attempts

Afficher le nombre actuel de tentatives d'authentification échouées.

-f, --daemonize

Se détacher du terminal de contrôle après le verrouillage.

Note : c'est le comportement par défaut d'i3lock.

-R, --ready-fd <fd>

Descripteur de fichier vers lequel envoyer les notifications de prêt.

Lorsque la session a été verrouillée, une seule nouvelle ligne est écrite dans le FD. À ce moment-là, le compositeur garantit qu'aucun contenu sensible à la sécurité n'est visible à l'écran.

-h, --help

Afficher le message d'aide et quitter.

-v, --version

Afficher le numéro de version et quitter.

APPARENCE

-u, --no-unlock-indicator

Désactiver l'indicateur de déverrouillage.

-i, --image [[<sortie>]:]<chemin>

Afficher l'image donnée, éventuellement uniquement sur la sortie donnée. Utilisez -c pour définir une couleur d'arrière-plan. Si le chemin peut potentiellement contenir un ':', préfixez-le avec un autre ':' pour éviter d'interpréter une partie de celui-ci comme <sortie>.

-k, --show-keyboard-layout

Afficher la disposition actuelle du clavier xkb pendant la frappe.

-K, --hide-keyboard-layout

Masquer de force la disposition actuelle du clavier xkb pendant la frappe, même si plusieurs dispositions sont configurées ou si l'option show-keyboard-layout est définie.

-L, --disable-caps-lock-text

Désactiver le texte de verrouillage des majuscules.

-l, --indicator-caps-lock

Afficher l'état actuel de verrouillage des majuscules également sur l'indicateur.

-s, --scaling

Mode de mise à l'échelle de l'image : stretch, fill, fit, center, tile, solid_color. Utilisez solid_color pour afficher uniquement la couleur d'arrière-plan, même si une image d'arrière-plan est spécifiée.

-t, --tiling

Identique à --scaling=tile.

-c, --color <rrggbb[aa]>

Transformer l'écran en la couleur donnée au lieu du gris clair. Si -i est utilisé, cela définit l'arrière-plan de l'image à la couleur donnée. Par défaut, gris clair (A3A3A3).

--bs-hl-color <rrggbb[aa]>

Définit la couleur des segments de mise en surbrillance de retour arrière.

--caps-lock-bs-hl-color <rrggbb[aa]>

Définit la couleur des segments de mise en surbrillance de retour arrière lorsque le verrouillage des majuscules est actif.

--caps-lock-key-hl-color <rrggbb[aa]>

Définit la couleur des segments de mise en surbrillance de la pression des touches lorsque le verrouillage des majuscules est actif.

--font <police>

Définit la police du texte.

--font-size <taille>

Définit une taille de police fixe pour le texte de l'indicateur.

--indicator-idle-visible

Définit l'indicateur à afficher même lorsqu'il est inactif.

--indicator-radius <rayon>

Définit le rayon de l'indicateur. La valeur par défaut est 50.

--indicator-thickness <épaisseur>

Définit l'épaisseur de l'indicateur. La valeur par défaut est 10.

--indicator-x-position <x>

Définit la position horizontale de l'indicateur.

--indicator-y-position <y>

Définit la position verticale de l'indicateur.

--inside-color <rrggbb[aa]>

Définit la couleur de l'intérieur de l'indicateur.

--inside-clear-color <rrggbb[aa]>

Définit la couleur de l'intérieur de l'indicateur lorsqu'il est effacé.

--inside-caps-lock-color <rrggbb[aa]>

Définit la couleur de l'intérieur de l'indicateur lorsque le verrouillage des majuscules est actif.

--inside-ver-color <rrggbb[aa]>

Définit la couleur de l'intérieur de l'indicateur lors de la vérification.

--inside-wrong-color <rrggbb[aa]>

Définit la couleur de l'intérieur de l'indicateur lorsqu'il est invalide.

--key-hl-color <rrggbb[aa]>

Définit la couleur des segments de mise en surbrillance de la pression des touches.

--layout-bg-color <rrggbb[aa]>

Définit la couleur d'arrière-plan de la boîte contenant le texte de disposition.

--layout-border-color <rrggbb[aa]>

Définit la couleur de la bordure de la boîte contenant le texte de disposition.

--layout-text-color <rrggbb[aa]>

Définit la couleur du texte de disposition.

--line-color <rrggbb[aa]>

Définit la couleur de la ligne entre l'intérieur et l'anneau.

--line-clear-color <rrggbb[aa]>

Définit la couleur de la ligne entre l'intérieur et l'anneau lorsqu'elle est effacée.

--line-caps-lock-color <rrggbb[aa]>

Définit la couleur de la ligne entre l'intérieur et l'anneau lorsque le verrouillage des majuscules est actif.

--line-ver-color <rrggbb[aa]>

Définit la couleur de la ligne entre l'intérieur et l'anneau lors de la vérification.

--line-wrong-color <rrggbb[aa]>

Définit la couleur de la ligne entre l'intérieur et l'anneau lorsqu'elle est invalide.

-n, --line-uses-inside

Utilise la couleur intérieure pour la ligne entre l'intérieur et l'anneau.

-r, --line-uses-ring

Utilise la couleur de l'anneau pour la ligne entre l'intérieur et l'anneau.

--ring-color <rrggbb[aa]>

Définit la couleur de l'anneau de l'indicateur lors de la frappe ou de l'inactivité.

--ring-clear-color <rrggbb[aa]>

Définit la couleur de l'anneau de l'indicateur lorsqu'il est effacé.

--ring-caps-lock-color <rrggbb[aa]>

Définit la couleur de l'anneau de l'indicateur lorsque le verrouillage des majuscules est actif.

--ring-ver-color <rrggbb[aa]>

Définit la couleur de l'anneau de l'indicateur lors de la vérification.

--ring-wrong-color <rrggbb[aa]>

Définit la couleur de l'anneau de l'indicateur lorsqu'il est invalide.

--separator-color <rrggbb[aa]>

Définit la couleur des lignes qui séparent les segments de mise en surbrillance.

--text-color <rrggbb[aa]>

Définit la couleur du texte.

--text-clear-color <rrggbb[aa]>

Définit la couleur du texte lorsqu'il est effacé.

--text-caps-lock-color <rrggbb[aa]>

Définit la couleur du texte lorsque le verrouillage des majuscules est actif.

--text-ver-color <rrggbb[aa]>

Définit la couleur du texte lors de la vérification.

--text-wrong-color <rrggbb[aa]>

Définit la couleur du texte lorsqu'il est invalide.

SIGNaux

SIGUSR1

Déverrouille l'écran et quitte.

lock your screen

NAME

swaylock - lock your screen

SYNOPSIS

swaylock [-C config] [-d] [-f] [-i image] [-k] [-l] [-p] [-r] [-s] [-u] [-v]

OPTIONS

-C config

Use the specified configuration file.

-d

Debug mode. Prints additional information.

-f

Force unlock. When the user presses Esc, swaylock will exit without checking the password.

-i image

Display the specified image on the lock screen. See also the --image option in the configuration file.

-k

Keep screens active. Prevent screens from going blank.

-l

Images are relative to the user’s home directory.

-p

Show the prompt. Display the password input prompt.

-r

Restore the last saved state. This is useful for restoring the screen contents after unlocking.

-s

Show the screen. Display the screen contents behind the lock screen.

-u

Unlock. Exit immediately without checking the password.

-v

Print version information and exit.

APPEARANCE

The appearance of the lock screen can be configured using the configuration file. The following options are available:

--image path

Display the specified image on the lock screen. The path can be absolute or relative to the user’s home directory.

--color color

Set the background color. The color can be specified in hexadecimal format (e.g., #RRGGBB).

--indicator

Show a password indicator.

--line-width width

Set the width of the indicator line.

--inside-color color

Set the color of the input box’s inside.

--ring-color color

Set the color of the indicator’s ring.

--key-hl-color color

Set the color of the highlighted key.

--separator-color color

Set the color of the separator between the ring and the inside input.

--text-color color

Set the color of the text.

--text-clear-color color

Set the color of the text when the input is cleared.

--text-ver-color color

Set the color of the text when the input is verified.

--text-wrong-color color

Set the color of the text when the input is wrong.

SIGNALS

SIGUSR1

Refresh the screen.

SIGINT, SIGTERM

Exit.
