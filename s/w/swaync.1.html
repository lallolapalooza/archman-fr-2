swaync(1) Manuel des commandes générales swaync(1)

NOM

swaync - Un démon de notification simple avec une interface GTK pour les notifications et le centre de contrôle

UTILISATION

swaync [option]

OPTIONS

-h, --help

Affiche les options d'aide

-v, --version

Imprime la version

-s, --style <fichier CSS>

Utilise un fichier de feuille de style personnalisé

--skip-system-css

Évite de tenter d'analyser le fichier de feuille de style empaqueté. Utile pour le débogage CSS

-c, --config <fichier de configuration>

Utilise un fichier de configuration personnalisé

RACC';COURTS DU CENTRE DE CONTR'LE

Haut/Bas: Navigue entre les notifications

Début: Navigue vers la notification la plus récente

Fin: Navigue vers la notification la plus ancienne

Échap/Verr. Maj.: Ferme le panneau de notification

Entrée: Exécute l'action par défaut ou ferme la notification si aucune

Suppr/Retour Arrière: Ferme la notification

Maj+C: Ferme toutes les notifications

Maj+D: Active/désactive le mode Ne pas déranger

Touches 1 à 9: Exécute des actions alternatives

Clic gauche sur un bouton / une action: Active l'action de la notification

Clic milieu/droit sur une notification: Ferme la notification

CONFIGURATION

Le fichier de configuration principal se trouve dans /etc/xdg/swaync/config.json. Copiez-le dans votre dossier ~/.config/swaync/ pour le personnaliser sans avoir besoin des droits root.

Pour recharger la configuration, vous devrez exécuter swaync-client --reload-config

Pour plus d'informations sur le format du fichier de configuration, voir swaync(5)

Scripting

Règles et logique de scripting :

1.
Un seul script peut être déclenché par notification
2.
Chaque script nécessite `exec` et au moins une des autres propriétés
3.
Toutes les propriétés listées doivent correspondre à la notification pour que le script soit exécuté
4.
Si l'une des propriétés ne correspond pas, le script sera ignoré
5.
Si une notification n'inclut pas l'une des propriétés, cette propriété sera ignorée

Les informations de notification peuvent être imprimées dans un terminal en exécutant G_MESSAGES_DEBUG=all swaync (lorsqu'une notification apparaît).

Propriétés de configuration :

{
	"scripts": {
		"exemple-script": {
			"exec": "Votre commande shell ou script ici...",
			"app-name": "Regex du nom de l'application de notification",
			"summary": "Regex du résumé de la notification",
			"body": "Regex du corps de la notification",
			"urgency": "Low ou Normal ou Critical",
			"category": "Regex de la catégorie de notification"
		}
	}
	autres propriétés non liées au scripting...
}

Exemple config.json :

{
	"scripts": {
		// Ce script ne s'exécutera que lorsque Spotify enverra une notification contenant
		// ce résumé et ce corps exacts
		"exemple-script": {
			"exec": "~/.config/swaync/myRickRollScript.sh",
			"app-name": "Spotify"
			"summary": "Never Gonna Give You Up",
			"body": "Rick Astley - Whenever You Need Somebody"
		}
	}
	autres propriétés non liées au scripting...
}

Désactiver le scripting

Pour désactiver complètement le scripting, le projet doit être compilé comme suit :

meson build -Dscripting=false
ninja -C build
meson install -C build

Exemple Waybar

Cet exemple nécessite la NotoSansMono Nerd Font pour que les icônes s'affichent correctement

Configuration Waybar

"custom/notification": {
	"tooltip": false,
	"format": "{icon}",
	"format-icons": {
		"notification": "<span foreground='red'><sup></sup></span>",
		"none": "",
		"dnd-notification": "<span foreground='red'><sup></sup></span>",
		"dnd-none": "",
		"inhibited-notification": "<span foreground='red'><sup></sup></span>",
		"inhibited-none": "",
		"dnd-inhibited-notification": "<span foreground='red'><sup></sup></span>",
		"dnd-inhibited-none": ""
	},
	"return-type": "json",
	"exec-if": "which swaync-client",
	"exec": "swaync-client -swb",
	"on-click": "swaync-client -t -sw",
	"on-click-right": "swaync-client -d -sw",
	"escape": true
},

Fichier CSS Waybar

#custom-notification {
	font-family: "NotoSansMono Nerd Font";
}
