swww-restore(1) Manuel des commandes générales swww-restore(1)

NOM

swww-restore

SYNTAXE

swww restore

OPTIONS

-a,--all

Envoyer cette commande à tous les espaces de noms `swww-daemon` actifs.

-n,--namespace <espace de noms>

Quel espace de noms Wayland recevoir cette commande.

Vous pouvez spécifier cette option plusieurs fois pour envoyer des commandes à plusieurs espaces de noms en même temps : `swww restore -n <espace de noms1> -n <espace de noms 2>`.

Cela affecte le nom du socket `swww-daemon` que nous utiliserons pour communiquer. Plus précisément, le nom de notre socket est ${WAYLAND_DISPLAY}-swww-daemon.<espace de noms spécifié>.socket.

Certains compositeurs peuvent avoir plusieurs fonds d'écran par sortie. Cela vous permet de les différencier. La plupart des utilisateurs n'auront probablement pas besoin de configurer quoi que ce soit dans cette option.

-o, --outputs

Liste des sorties séparées par des virgules à restaurer. Utilisez swww query pour connaître les sorties actuellement utilisées.

Si elle n'est pas définie, toutes les sorties seront restaurées.

-h, --help

Afficher l'aide (voir un résumé avec '-h')

DESCRIPTION

Restaure la dernière image affichée sur les sorties spécifiées.

Ceci peut être utilisé pour diviser l'initialisation (avec `swww init --no-daemon`) et le chargement du cache en différentes étapes, afin d'éviter les erreurs de concurrence.

Vous pouvez également utiliser cette commande pour restaurer la dernière image affichée lors de la reconnexion d'un moniteur.

VOIR AUSSI
