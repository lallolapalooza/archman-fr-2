NOM

swayimg - visionneuse d'images pour les serveurs d'affichage Wayland

SYNTAXE

swayimg [OPTIONS]... [FICHIER]...

DESCRIPTION

Si aucun fichier ou répertoire d'entrée n'est spécifié, la visionneuse essaiera de lire tous les fichiers du répertoire courant.

Utilisez '-' comme FICHIER pour lire les données de l'image depuis l'entrée standard.

Utilisez le préfixe exec:// pour obtenir les données de l'image depuis la sortie standard imprimée par une commande externe.

OPTIONS

-h, --help

Affiche le message d'aide et quitte.

-v, --version

Affiche les informations de version et la liste des formats d'image pris en charge.

-g, --gallery

Démarre en mode galerie.

-l, --slideshow

Exécute un diaporama au démarrage.

-F, --from-file

Interprète FICHIER comme une liste textuelle de fichiers image. Utilisez '-' pour lire la liste des fichiers depuis l'entrée standard.

-r, --recursive

Lit les répertoires de manière récursive.

-o, --order=ORDRE

Définit l'ordre de la liste d'images :
  • none : non trié ;
  • alpha : trié par ordre alphabétique ;
  • numeric : trié numériquement ;
  • mtime : trié par date de modification du fichier ;
  • size : trié par taille de fichier ;
  • random : mélange la liste.

-s, --scale=MODE

Définit l'échelle de l'image :
  • optimal : 100 % ou moins pour s'adapter à la fenêtre (par défaut) ;
  • width : adapte la largeur de l'image à la largeur de la fenêtre ;
  • height : adapte la hauteur de l'image à la hauteur de la fenêtre ;
  • fit : adapte à la fenêtre ;
  • fill : rogne l'image pour remplir la fenêtre ;
  • real : taille réelle (100 %) ;
  • keep : conserve la même échelle que pour l'image vue précédemment.

-f, --fullscreen

Démarre en mode plein écran.

-p, --position=auto|X,Y

Définit la position de la fenêtre, cette option n'est valide que dans le gestionnaire de fenêtres Sway :
  • auto : laisse le gestionnaire de fenêtres contrôler la position de la fenêtre (par défaut) ;
  • X,Y : coordonnées absolues du coin supérieur gauche, par ex. 100,200.

-w, --size=fullscreen|image|L,H

Définit la taille de la fenêtre :
  • fullscreen : utilise le mode plein écran ;
  • image : définit la taille à partir de la première image de la première image ;
  • L,H : taille absolue de la fenêtre en pixels, la valeur par défaut est 1280,720.

-a, --class=NOM

Définit la classe/app_id de la fenêtre.

-i, --ipc=FICHIER

Démarre un serveur IPC basé sur des sockets UNIX. FICHIER doit pointer vers le fichier de socket UNIX à créer. Le protocole IPC est un protocole unidirectionnel simple basé sur du texte qui permet aux clients de soumettre des actions pour exécution. Pour une liste des actions et de leurs paramètres, voir swayimgrc(5).

-c, --config=SECTION.CLÉ=VALEUR

Remplace un paramètre de configuration, voir swayimgrc(5) pour une liste des sections et de leurs paramètres.

-C, --config-file=FICHIER

Charge la configuration depuis le FICHIER spécifié.

INTÉGRATION SWAY/HYPRLAND

Le mode d'intégration Sway/Hyprland est automatiquement activé si l'IPC pour ces compositeurs est présent dans le système. Ce mode fournit certaines fonctionnalités telles que la définition de la position de la fenêtre et l'obtention de la disposition de l'espace de travail. Par défaut, l'application crée une « superposition » au-dessus de la fenêtre active, ce qui donne l'illusion que l'image est ouverte directement dans la fenêtre du terminal.

ENVIRONNEMENT

SWAYSOCK

Chemin du fichier socket utilisé pour l'IPC Sway.

HYPRLAND_INSTANCE_SIGNATURE, XDG_RUNTIME_DIR

Chemin du fichier socket utilisé pour l'IPC Hyprland.

XDG_CONFIG_HOME, XDG_CONFIG_DIRS, HOME

Préfixe du chemin du fichier de configuration de l'application, voir swayimgrc(5) pour les détails.

XDG_CACHE_HOME, HOME

Préfixe du chemin utilisé comme stockage persistant pour les miniatures.

SHELL

Shell pour exécuter une commande externe et charger une image depuis la sortie standard.

SIGNaux

SIGUSR1, SIGUSR2

Exécute les actions spécifiées dans le fichier de configuration.

STATUT DE SORTIE

Le statut de sortie est de 0 si le programme s'est terminé avec succès et de 1 si une erreur s'est produite.

EXEMPLES

Afficher plusieurs fichiers :

swayimg photo.jpg logo.png

Démarrer un diaporama pour tous les fichiers (récursivement) du répertoire courant dans un ordre aléatoire :

swayimg --slideshow --recursive --order=random

Afficher en utilisant des pipes :

wget -qO- https://www.kernel.org/theme/images/logos/tux.png | swayimg -

Charger la sortie standard de commandes externes :

swayimg "exec://wget -qO- https://www.kernel.org/theme/images/logos/tux.png" \
        "exec://curl -so- https://www.kernel.org/theme/images/logos/tux.png"

Afficher toutes les images du répertoire courant en mode galerie :

swayimg --gallery
