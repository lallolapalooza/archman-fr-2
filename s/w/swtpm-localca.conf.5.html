NOM

swtpm-localca.conf - Fichier de configuration pour swtpm_localca

DESCRIPTION

Le fichier /etc/swtpm-localca.conf contient les variables de configuration pour le programme swtpm_localca.

Les entrées peuvent contenir des variables d'environnement qui seront résolues. Toutes les variables d'environnement doivent être formatées comme suit : '${nom_var}'.

Les utilisateurs peuvent écrire leur propre configuration dans ${XDG_CONFIG_HOME}/swtpm-localca.conf ou, si XDG_CONFIG_HOME n'est pas défini, dans ${HOME}/.config/swtpm-localca.conf.

Les variables de configuration suivantes sont prises en charge :

statedir
Le nom d'un répertoire où stocker les données. Un verrou sera créé dans ce répertoire.
signinkey
Le fichier contenant la clé utilisée pour signer les certificats. Fournir une clé au format PEM ou une URI pkcs11.
signingkey_password
Le mot de passe à utiliser pour la clé de signature.
issuercert
Le fichier contenant le certificat pour cette CA. Fournir un certificat au format PEM.
certserial
Le nom du fichier contenant le numéro de série du prochain certificat.

Le numéro de série doit être un nombre décimal et doit être représentable avec 20 octets ou moins. Une fois 21 octets utilisés, un nouveau numéro de série aléatoire de 20 chiffres décimaux sera créé.

TSS_TCSD_HOSTNAME
Cette variable peut être définie sur l'hôte où tcsd s'exécute au cas où la clé de signature serait une clé GnuTLS TPM 1.2. Par défaut, localhost sera utilisé.
TSS_TCSD_PORT
Cette variable peut être définie sur le port sur lequel tcsd écoute les connexions. Par défaut, le port 30003 sera utilisé.
env:<nom_variable_environnement=<valeur>>
Les variables d'environnement, qui sont nécessaires aux modules pkcs11, peuvent être définies en utilisant ce format. Un exemple d'une telle variable d'environnement pourrait ressembler à ceci : 
env:MY_MODULE_PKCS11_CONFIG = /tmp/mymodule-pkcs11.conf

La ligne ne doit pas contenir d'espaces de fin.

EXEMPLE

Un fichier swtpm-localca.conf exemple pourrait ressembler à ceci :

statedir = /var/lib/swtpm_localca
signingkey = /var/lib/swtpm_localca/signkey.pem
issuercert = /var/lib/swtpm_localca/issuercert.pem
certserial = /var/lib/swtpm_localca/certserial

Avec une URI PKCS11, cela pourrait ressembler à ceci :

statedir = /var/lib/swtpm-localca
signingkey = pkcs11:model=SoftHSM%20v2;manufacturer=SoftHSM%20project;serial=891b99c169e41301;token=mylabel;id=%00;object=mykey;type=public
issuercert = /var/lib/swtpm-localca/swtpm-localca-tpmca-cert.pem
certserial = /var/lib/swtpm-localca/certserial
SWTPM_PKCS11_PIN = 1234
