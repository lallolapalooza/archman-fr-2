NOM

swtpm_localca - CA locale pour créer des certificats EK et de plateforme pour swtpm

SYNTAXE

swtpm_localca [OPTIONS]

DESCRIPTION

swtpm_localca est un outil pour créer des certificats d'Endorsement Key (EK) et de plateforme sur l'hôte. Il utilise le programme swtpm_cert pour créer les certificats.

Le programme sera généralement invoqué par le programme swtpm_setup qui utilise le fichier de configuration /etc/swtpm_setup.conf où une variable doit être définie pour pointer vers ce programme. Il implémente des options de ligne de commande que le programme swtpm_setup utilise pour lui fournir les paramètres nécessaires.

swtpm_localca tentera automatiquement de créer la clé et le certificat de signature si la configuration pointe vers une clé de signature manquante. Comme ce certificat doit être signé par une CA, une autorité de certification racine sera également créée et signera ce certificat. La clé privée et le certificat de la CA racine seront situés dans le même répertoire que la clé de signature et porteront les noms swtpm-localca-rootca-privkey.pem et swtpm-localca-rootca-cert.pem respectivement. La variable d'environnement SWTPM_ROOTCA_PASSWORD peut être définie pour le mot de passe de la clé privée de la CA racine.

Note : En raison des limitations de 'certtool', les mots de passe possibles utilisés pour sécuriser la clé privée de la CA racine et la clé privée de la CA intermédiaire doivent être passés en ligne de commande et seront donc visibles par d'autres sur le système. Si cela vous préoccupe, vous devriez créer les CA ailleurs et les copier sur le système cible.

Les options suivantes sont prises en charge :

--type type
Ce paramètre indique le type de certificat à créer. Le paramètre type peut être l'un des suivants : ek, ou platform
--dir dir
Ce paramètre indique le répertoire dans lequel le certificat doit être stocké. Le certificat EK est stocké dans ce répertoire sous le nom ek.cert et le certificat de plateforme sous le nom platform.cert.
--ek ek ou --key key
Ce paramètre indique le module de la clé publique de l'Endorsement Key (EK). La clé publique est fournie sous forme d'une séquence de chiffres hexadécimaux ASCII.

L'option --key est un alias pour --ek et doit être utilisée si des paramètres de clé pour une clé autre qu'une Endorsement Key sont passés.

Si des clés ECC (cryptographie à courbe elliptique) sont utilisées, le paramètre doit avoir le format --ek x=<chiffres hex>,y=<chiffres hex>,id=<id de courbe>. La partie id=<id de courbe> est facultative et nécessaire uniquement pour les courbes ECC autres que secp256r1.

--vmid ID
Ce paramètre indique l'ID de la VM pour laquelle créer le certificat.
--logfile <logfile>
Le fichier journal dans lequel écrire la sortie ; par défaut, la journalisation va vers stdout et stderr sur la console.
--configfile <fichier de configuration>
Le fichier de configuration à utiliser. Si omis, le fichier de configuration par défaut /etc/swtpm-localca.conf sera utilisé.
--optsfile <fichier d'options>
Le fichier d'options à utiliser. Si omis, le fichier d'options par défaut /etc/swtpm-localca.options sera utilisé.
--tpm-spec-family, --tpm-spec-revision, --tpm-spec-level
Paramètres de spécification TPM qui décrivent la spécification qui a été suivie pour l'implémentation du TPM. Les paramètres seront transmis à swtpm_cert pour la création du certificat EK.
--tpm2
Créer des certificats conformes à TPM 2.
--allow-signing
Créer une EK qui peut également être utilisée pour la signature. Sans cette option, l'EK ne peut être utilisée que pour le chiffrement de clé. Cette option nécessite --tpm2.
--decryption
Si --allow-signing est passé et que l'EK doit également être utilisable pour le chiffrement de clé, cette option doit être passée. Sinon, le chiffrement de clé est le comportement par défaut. Cette option nécessite --tpm2.
