NOM

swapin.bt - Compte les swapins par processus. Utilise bpftrace/eBPF.

SYNOPIS

swapin

DESCRIPTION

Cet outil compte les swapins par processus, pour montrer quel processus est affecté par le swapping (si des périphériques de swap sont utilisés). Cela peut expliquer une source significative de latence applicative, s'il a commencé à swapper en raison d'une pression mémoire sur le système.

Cela fonctionne en suivant la fonction noyau swap_readpage() à l'aide de l'instrumentation dynamique. Cet outil peut nécessiter une maintenance pour continuer à fonctionner si cette fonction change dans les noyaux ultérieurs.

Puisque cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Compte les swapins par processus, affichant des résumés par seconde.
# swapin.bt

CHAMPOS

1er
Le nom du processus.
2ème
L'ID du processus.
3ème
Le nombre de swapins pendant cet intervalle.

SURCHARGE

Le taux de swapins devrait être faible (limité par les IOPS du périphérique de swap), de telle sorte que la surcharge de cet outil est attendue comme étant négligeable.

SOURCE

Cet outil provient du livre "BPF Performance Tools", publié par Addison Wesley (2019) :

http://www.brendangregg.com/bpf-performance-tools-book.html

Voir le livre pour plus de documentation sur cet outil.

Cette version est dans le dépôt bpftrace :

https://github.com/bpftrace/bpftrace

Recherchez également dans la distribution bpftrace un fichier _examples.txt compagnon contenant des exemples d'utilisation, des sorties et des commentaires pour cet outil.
