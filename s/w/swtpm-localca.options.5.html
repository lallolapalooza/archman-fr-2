NOM

swtpm-localca.options - Fichier d'options pour swtpm_localca

DESCRIPTION

Le fichier /etc/swtpm-localca.options contient les options de ligne de commande à passer au programme swtpm_cert et doit contenir les options qui s'appliquent à la création de tous les certificats de clé d'endossement (EK) et de plateforme.

Les utilisateurs peuvent écrire leurs propres options dans ${XDG_CONFIG_HOME}/swtpm-localca.options ou si XDG_CONFIG_HOME n'est pas défini, dans ${HOME}/.config/swtpm-localca.options.

EXEMPLE

Un fichier swtpm-localca.options d'exemple peut ressembler à ceci :

--platform-manufacturer Fedora
--platform-version 2.1
--platform-model QEMU
