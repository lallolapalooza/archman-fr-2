NOM

swtpm_setup.conf - Fichier de configuration pour swtpm_setup

DESCRIPTION

Le fichier /etc/swtpm_setup.conf contient des informations de configuration pour swtpm_setup. Il ne doit contenir qu'un seul mot-clé de configuration par ligne, suivi d'un signe égal (=), puis des informations de configuration appropriées. Un commentaire en fin de ligne peut être introduit par un signe dièse (#).

Les utilisateurs peuvent écrire leur propre configuration dans ${XDG_CONFIG_HOME}/swtpm_setup.conf ou, si XDG_CONFIG_HOME n'est pas défini, elle peut se trouver dans ${HOME}/.config/swtpm_setup.conf.

Les mots-clés suivants sont reconnus :

create_certs_tool
Ce mot-clé doit être suivi du nom d'un exécutable ou d'un script exécutable utilisé pour créer divers certificats TPM. L'outil sera appelé avec les options suivantes :
--type type
Ce paramètre indique le type de certificat à créer. Le paramètre type peut être l'un des suivants : ek, ou platform.
--dir dir
Ce paramètre indique le répertoire dans lequel le certificat doit être stocké. On s'attend à ce que le certificat EK soit stocké dans ce répertoire sous le nom ek.cert et le certificat de plateforme sous le nom platform.cert.
--ek ek
Ce paramètre indique le module de la clé publique de la clé d'endossement (EK). La clé publique est fournie sous forme d'une séquence de chiffres hexadécimaux ASCII.
--vmid ID
Ce paramètre indique l'identifiant de la VM pour laquelle créer le certificat.
--logfile <logfile>
Le fichier journal pour écrire la sortie ; par défaut, la journalisation se fait sur stdout et stderr sur la console.
--configfile <fichier de configuration>
Le fichier de configuration à utiliser. Ce fichier contient généralement des informations de configuration pour le programme appelé. S'il est omis, le programme doit utiliser son fichier de configuration par défaut.
--optsfile <fichier d'options>
Le fichier d'options à utiliser. Ce fichier contient généralement des options que le programme appelé utilise. S'il est omis, le programme doit utiliser son fichier d'options par défaut.
--tpm-spec-family <famille>, --tpm-spec-level <niveau>, --tpm-spec-revision <révision>
Ces 3 options décrivent la spécification TPM qui a été suivie pour l'implémentation du TPM et feront partie du certificat EK.
--tpm2
Cette option est passée au cas où un certificat conforme à TPM 2 doit être créé.
create_certs_tool_config
Ce mot-clé doit être suivi du nom d'un fichier de configuration qui sera passé au programme appelé à l'aide de l'option --configfile décrite ci-dessus. S'il est omis, le programme appelé utilisera le fichier de configuration par défaut.
create_certs_tool_options
Ce mot-clé doit être suivi du nom d'un fichier d'options qui sera passé au programme appelé à l'aide de l'option --optsfile décrite ci-dessus. S'il est omis, le programme appelé utilisera le fichier d'options par défaut.
active_pcr_banks (depuis v0.7)
Ce mot-clé doit être suivi d'une liste de noms de banques PCR séparés par des virgules. La liste ne doit pas contenir d'espaces. Les noms de banques PCR valides sont sha1, sha256, sha384 et sha512.
rsa_keysize (depuis v0.10)
Ce mot-clé permet de spécifier la taille de clé RSA par défaut à utiliser si elle n'est pas fournie avec une option en ligne de commande à swtpm_setup. Toute valeur pouvant être passée à swtpm_setup est également valide ici, telle que 2048, ou 'max'. Les tailles de clés supportées dépendent de la version de libtpms.
profile (depuis v0.10)
Ce mot-clé permet de spécifier soit le nom d'un profil, soit une carte JSON décrivant le profil, telle que 'profile = {"Name": "default-v1"}'. Veuillez également vous référer à la description de l'option --profile pour swtpm_setup.
profile_file (depuis v0.10)
Ce mot-clé permet de spécifier un fichier de profil par défaut.
local_profiles_dir (depuis v0.10)
Ce mot-clé permet de définir un répertoire de profils contenant des profils écrits par les utilisateurs du système.
