NOM

swaybar-protocol - Protocole de ligne de statut JSON pour swaybar

RÉSUMÉ

swaybar définit le protocole JSON suivant pour spécifier les informations affichées dans la ligne de statut sur le côté droit de swaybar. Le protocole comprend un en-tête, qui est un objet JSON, suivi d'un retour à la ligne (0x0A), suivi d'un tableau JSON infini qui représente les informations à afficher. Toute la communication se fait en écrivant la ligne de statut sur la sortie standard et en lisant les événements depuis l'entrée standard.

EN-TÊTE

L'en-tête est un objet JSON prenant en charge les propriétés suivantes (seule la propriété version est requise) :

PROPRIÉTÉ TYPE DE DONNÉES DÉFAUT DESCRIPTION
version entier - La version du protocole à utiliser. Actuellement, elle doit être 1
click_events booléen faux Indique si les informations d'événements de clic doivent être reçues sur l'entrée standard
cont_signal entier SIGCONT Le signal que swaybar doit envoyer pour continuer le traitement
stop_signal entier SIGSTOP Le signal que swaybar doit envoyer pour arrêter le traitement

EN-TÊTE MINIMAL

{
	"version": 1
}

EN-TÊTE COMPLET

{
	"version": 1,
	"click_events": true,
	"cont_signal": 18,
	"stop_signal": 19
}

CORPS

Le corps est un tableau infini, où chaque élément du tableau est une représentation de la ligne de statut au moment où l'élément a été écrit. Chaque élément du tableau est lui-même un tableau d'objets JSON, où chaque objet représente un bloc dans la ligne de statut. Chaque bloc peut avoir les propriétés suivantes (seule full_text est requise) :

PROPRIÉTÉ TYPE DE DONNÉES DESCRIPTION
full_text chaîne Le texte qui sera affiché. S'il est manquant, le bloc sera ignoré.
short_text chaîne S'il est fourni et que le texte doit être raccourci en raison de l'espace, c'est ce qui sera affiché à la place de full_text
color chaîne La couleur du texte à utiliser au format #RRGGBBAA ou #RRGGBB
background chaîne La couleur de fond du bloc au format #RRGGBBAA ou #RRGGBB
border chaîne La couleur de la bordure du bloc au format #RRGGBBAA ou #RRGGBB
border_top entier La hauteur en pixels de la bordure supérieure. La valeur par défaut est 1
border_bottom entier La hauteur en pixels de la bordure inférieure. La valeur par défaut est 1
border_left entier La largeur en pixels de la bordure gauche. La valeur par défaut est 1
border_right entier La largeur en pixels de la bordure droite. La valeur par défaut est 1
min_width entier ou chaîne La largeur minimale à utiliser pour le bloc. Cela peut être donné en pixels ou une chaîne peut être fournie pour permettre un calcul basé sur la largeur de la chaîne.
align chaîne Si le texte ne remplit pas toute la largeur du bloc, cela spécifie comment le texte doit être aligné à l'intérieur du bloc. Cela peut être left (par défaut), right, ou center.
name chaîne Un nom pour le bloc. Ceci est uniquement utilisé pour identifier le bloc pour les événements de clic. S'il est défini, chaque bloc doit avoir une paire name et instance unique.
instance chaîne L'instance du name pour le bloc. Ceci est uniquement utilisé pour identifier le bloc pour les événements de clic. S'il est défini, chaque bloc doit avoir une paire name et instance unique.
urgent booléen Indique si le bloc doit être affiché comme urgent. Actuellement, swaybar utilise les couleurs définies dans la configuration de sway pour les boutons d'espace de travail urgents. Voir sway-bar(5) pour plus d'informations sur la configuration des couleurs de la barre.
separator booléen Indique si le séparateur de la barre doit être dessiné après le bloc. Voir sway-bar(5) pour plus d'informations sur la façon de définir le texte du séparateur.
separator_block_width entier La quantité d'espace en pixels à laisser après le bloc. Le texte du séparateur sera centré dans cet espace. La valeur par défaut est 9 pixels.
markup chaîne Le type de balisage à utiliser lors de l'analyse du texte pour le bloc. Cela peut être pango ou none (par défaut).

D'autres propriétés peuvent être fournies et swaybar ignorera toute propriété qu'il ne connaît pas. Il est recommandé de préfixer toute propriété personnalisée avec un trait de soulignement pour la distinguer plus facilement des propriétés du protocole.

EXEMPLE DE CORPS

[
	[
		{
			"full_text": "25%",
			"min_width": "100%",
			"urgent": false
		},
		{
			"full_text": "Jeu 30 Mai 2019 02:15:15"
		}
	],
	[
		{
			"full_text": "20%",
			"min_width": "100%",
			"urgent": false
		},
		{
			"full_text": "Jeu 30 Mai 2019 02:20:52"
		}
	],
	[
		{
			"full_text": "15%",
			"min_width": "100%",
			"urgent": true
		},
		{
			"full_text": "Jeu 30 Mai 2019 02:25:41"
		}
	],
	...

ÉVÉNEMENTS DE CLIC

Si demandé dans l'en-tête, swaybar enverra des informations sur les événements de clic à l'entrée standard. Chaque événement de clic est un tableau JSON contenant les informations suivantes :

{ "name": "nom du bloc, si défini", "instance": "instance du bloc, si définie", "x": "coordonnée x où le clic s'est produit", "y": "coordonnée y où le clic s'est produit", "button": "bouton x11 pour le clic. Sera 0 si le bouton n'a pas de mappage x11.", "event": "code événement correspondant au bouton pour le clic", "relative_x": "coordonnée x du clic par rapport au coin supérieur gauche du bloc", "relative_y": "coordonnée y du clic par rapport au coin supérieur gauche du bloc", "width": "largeur du bloc en pixels", "height": "hauteur du bloc en pixels" }
