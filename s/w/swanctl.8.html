NOM

swanctl - Interface en ligne de commande pour la configuration, le contrôle et la surveillance de strongSwan.

SYNTAXE

swanctl commande [option ...]
swanctl -h | --help

DESCRIPTION

swanctl est un utilitaire en ligne de commande multiplateforme permettant de configurer, contrôler et surveiller le démon IKE strongSwan. Il remplace les anciens outils starter, ipsec et stroke.

swanctl utilise un fichier de configuration appelé swanctl.conf(5) pour analyser les configurations et les identifiants. Les clés privées, les certificats et autres identifiants liés à l'infrastructure à clé publique (ICP) sont lus à partir de répertoires spécifiques.

Pour communiquer avec le démon IKE, swanctl utilise le protocole VICI, le Versatile IKE Configuration Interface. Cette interface stable peut être utilisée par d'autres outils et est souvent préférable à la mise en script de swanctl et à l'analyse de sa sortie.

COMMANDES

-i, --initiate
initier une connexion
-t, --terminate
terminer une connexion
-R, --rekey
renégocier une SA
-d, --redirect
rediriger une IKE_SA
-p, --install
installer une politique de trap ou de shunt
-u, --uninstall
désinstaller une politique de trap ou de shunt
-l, --list-sas
lister les IKE_SA actives
-P, --list-pols
lister les politiques installées
-b, --load-authorities
charger (ou recharger) les informations des autorités de certification
-L, --list-conns
lister les configurations chargées
-B, --list-authorities
lister les informations chargées des autorités de certification
-x, --list-certs
lister les certificats stockés
-A, --list-pools
lister les configurations de pools chargées
-g, --list-algs
lister les algorithmes chargés et leur implémentation
-q, --load-all
charger (ou recharger) les identifiants, les pools, les autorités et les connexions
-c, --load-conns
charger (ou recharger) la configuration des connexions
-s, --load-creds
charger (ou recharger) les identifiants
-a, --load-pools
charger (ou recharger) la configuration des pools
-T, --log
tracer la sortie du journal (niveaux 0 et 1 uniquement)
-S, --stats
afficher les informations et statistiques du démon
-f, --flush-certs
vider le cache des certificats
-r, --reload-settings
recharger la configuration de strongswan.conf(5)
-v, --version
afficher les informations de version du démon
-h, --help
afficher les informations d'utilisation
