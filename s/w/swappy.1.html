swappy(1) Manuel des commandes générales swappy(1)

NOM

swappy - Capturer et éditer à la volée des instantanés d'un compositeur Wayland

SYNTAXE

swappy [options...]

DESCRIPTION

swappy est un utilitaire en ligne de commande pour prendre et éditer des captures d'écran de bureaux Wayland. Fonctionne parfaitement avec grim, slurp et sway. Mais peut facilement fonctionner avec d'autres outils de capture d'écran capables de sortir une image finale sur stdout.

swappy sauvegardera les images annotées dans le répertoire de configuration save_dir, voir ci-dessous.

Si absent, alors il essaiera de prendre par défaut un dossier Desktop suivant ce modèle : $XDG_DESKTOP_DIR. Si cette variable n'est pas définie, il reviendra à : $XDG_CONFIG_HOME/Desktop. Si $XDG_CONFIG_HOME n'est pas défini, il reviendra à : $HOME/Desktop.

OPTIONS

-h, --help

Afficher le message d'aide et quitter.

-v, --version

Afficher la version et quitter.

-f, --file <fichier>

Un fichier image à charger pour l'édition.

S'il est défini sur -, lire le fichier depuis l'entrée standard à la place. Ceci est compatible avec grim.

-o, --output-file <fichier>

Afficher la surface finale dans <fichier> à la sortie de l'application.

S'il est défini sur -, afficher la surface finale sur stdout.

Notez que le bouton Save sauvegardera l'image dans le paramètre de configuration save_dir, comme décrit dans la section DESCRIPTION.

FICHIER DE CONFIGURATION

Le fichier de configuration se trouve à $XDG_CONFIG_HOME/swappy/config ou à $HOME/.config/swappy/config. Le fichier suit le format conf de GLib.

[Section]
clef=valeur

Les lignes suivantes peuvent être utilisées comme valeurs par défaut de swappy :

[Default]
save_dir=$HOME/Desktop
save_filename_format=swappy-%Y%m%d-%H%M%S.png
show_panel=false
line_size=5
text_size=20
text_font=sans-serif
paint_mode=brush
early_exit=false
fill_shape=false
auto_save=false
custom_color=rgba(192,125,17,1)
transparent=false
transparency=50
  • save_dir est l'endroit où les captures seront sauvegardées, peut contenir des variables d'environnement. Lorsque ce répertoire n'existe pas, swappy tente de le créer, mais n'interrompt pas le processus si la création échoue.
  • save_filename_format est le modèle de nom de fichier. S'il contient un format de date, celui-ci sera analysé pour créer un horodatage. Le format est détaillé dans strftime(3). Si ce format de date est manquant, le nom du fichier n'aura pas d'horodatage.
  • show_panel est utilisé pour activer ou désactiver le panneau de dessin au démarrage.
  • line_size est la taille de ligne par défaut (doit être comprise entre 1 et 50).
  • text_size est la taille de texte par défaut (doit être comprise entre 10 et 50).
  • text_font est la police utilisée pour le rendu du texte, son format est compatible avec Pango.
  • paint_mode est le mode activé au démarrage de l'application (doit être l'un des suivants : brush|text|rectangle|ellipse|arrow|blur, la correspondance n'est pas sensible à la casse).
  • early_exit est utilisé pour faire quitter l'application après avoir sauvegardé l'image ou l'avoir copiée dans le presse-papiers.
  • fill_shape est utilisé pour activer ou désactiver le remplissage des formes (pour les outils rectangle et ellipse) au démarrage.
  • auto_save est utilisé pour activer ou désactiver la sauvegarde automatique du tampon final dans save_dir à la sortie.
  • custom_color est utilisé pour définir une valeur par défaut pour la couleur personnalisée. Les formats acceptés sont : nom standard (l'un des : https://github.com/rgb-x/system/blob/master/root/etc/X11/rgb.txt), #rgb, #rrggbb, #rrrgggbbb, #rrrrggggbbbb, rgb(r,b,g), rgba(r,g,b,a).
  • transparency est utilisé pour définir la transparence de tout ce qui est dessiné au démarrage.
  • transparent est utilisé pour activer ou désactiver la transparence au démarrage.

RACCOURCIS CLAVIER

MISE EN PAGE

•
Ctrl+b : Afficher/masquer le panneau de dessin

MODE DE PEINTURE

  • b : Passer au pinceau
  • `e` `t` : Passer au texte (Éditeur)
  • `r` `s` : Passer au rectangle (Carré)
  • `c` `o` : Passer à l'ellipse (Cercle)
  • a : Passer à la flèche
  • d : Passer au flou (d pour droplet)
  • R : Utiliser la couleur rouge
  • G : Utiliser la couleur verte
  • B : Utiliser la couleur bleue
  • C : Utiliser la couleur personnalisée
  • Moins : Réduire la taille du trait
  • Plus : Augmenter la taille du trait
  • Égal : Réinitialiser la taille du trait
  • f : Activer/désactiver le remplissage des formes
  • T : Activer/désactiver la transparence
  • `x` `k` : Effacer les dessins (irréversible)

MODIFICATEURS

•
Ctrl : Centrer la forme (Rectangle & Ellipse) par rapport au point de départ du dessin

BARRE D'EN TÊTE

  • Ctrl+z : Annuler
  • Ctrl+Shift+z ou Ctrl+y : Rétablir
  • Ctrl+s : Sauvegarder dans un fichier (voir la page de manuel)
  • Ctrl+c : Copier dans le presse-papiers
  • Échap ou q ou Ctrl+w : Quitter swappy
