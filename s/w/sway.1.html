sway(1) Manuel des commandes générales sway(1)

NOM

sway - Un compositeur Wayland compatible avec i3

SYNTAXE

sway [options...] [commande]

OPTIONS

-h, --help

Affiche le message d'aide et quitte.

-c, --config <config>

Spécifie un fichier de configuration.

-C, --validate

Vérifie la validité du fichier de configuration, puis quitte.

-d, --debug

Active la journalisation complète, y compris les informations de débogage.

-v, --version

Affiche le numéro de version et quitte.

-V, --verbose

Active une journalisation plus détaillée.

--get-socketpath

Récupère le chemin du socket IPC et l'affiche, puis quitte.

DESCRIPTION

sway a été créé pour répondre au besoin d'un gestionnaire de fenêtres de type i3 pour Wayland. Les développeurs principaux d'i3 n'ont aucune intention de porter i3 sur Wayland, et les projets proposés par d'autres se sont avérés être du vaporware. Un grand merci aux équipes d'i3 pour avoir fourni un logiciel aussi génial, tellement bon que leurs utilisateurs préfèrent réécrire entièrement un nouveau gestionnaire de fenêtres à partir de zéro qui se comporterait *exactement* comme i3 plutôt que de passer à autre chose.

Vous pouvez exécuter sway directement depuis un tty, ou via un gestionnaire de connexion compatible Wayland.

CONFIGURATION

sway recherche un fichier de configuration aux emplacements suivants, dans cet ordre :

1.
~/.sway/config
2.
$XDG_CONFIG_HOME/sway/config (emplacement suggéré)
3.
~/.i3/config
4.
$XDG_CONFIG_HOME/i3/config
5.
/etc/sway/config
6.
/etc/i3/config

Si non défini, $XDG_CONFIG_HOME vaut par défaut ~/.config.

Une erreur est générée lorsqu'aucun fichier de configuration n'est trouvé. La configuration par défaut recommandée est généralement installée dans /etc/sway/config ; vous êtes encouragé à la copier dans ~/.config/sway/config et à l'éditer à partir de là.

Pour plus d'informations sur le format du fichier de configuration, voir sway(5).

COMMANDES IPC

Bien que swaymsg(1) soit généralement préféré, vous pouvez exécuter sway commande pour envoyer commande à l'instance en cours d'exécution de sway. Vous pouvez également émettre des commandes avec i3-msg(1) ou même avec i3(1).

ENVIRONNEMENT

Les variables d'environnement suivantes ont un effet sur sway :

SWAYSOCK

Spécifie le chemin vers le socket IPC de sway.

XKB_DEFAULT_RULES, XKB_DEFAULT_MODEL, XKB_DEFAULT_LAYOUT, XKB_DEFAULT_VARIANT, XKB_DEFAULT_OPTIONS

Configure les paramètres du clavier xkb. Voir xkeyboard-config(7). La méthode préférée pour configurer le clavier est via le fichier de configuration, voir sway-input(5).

Les variables d'environnement suivantes sont définies par sway :

DISPLAY

Si compilé avec le support Xwayland et que Xwayland n'est pas désactivé par la configuration, cela sera défini sur le nom de l'affichage X utilisé pour Xwayland.

I3SOCK

Pour la compatibilité avec i3, spécifie le chemin vers le socket IPC de sway.

SWAYSOCK

Spécifie le chemin vers le socket IPC de sway.

WAYLAND_DISPLAY

Spécifie le nom de l'affichage Wayland sur lequel sway est en cours d'exécution.

XCURSOR_SIZE

Spécifie la taille du curseur configurée.

XCURSOR_THEME

Spécifie le thème du curseur configuré.
