switch(n) Commandes intégrées Tcl switch(n)

NOM

switch - Évalue l'un des scripts suivants, en fonction d'une valeur donnée

SYNOPSIS

switch ?options? chaîne motif corps ?motif corps ...?

switch ?options? chaîne {motif corps ?motif corps ...?}

DESCRIPTION

La commande switch compare son argument chaîne avec chacun des arguments motif dans l'ordre. Dès qu'elle trouve un motif qui correspond à la chaîne, elle évalue l'argument corps suivant en le passant récursivement à l'interpréteur Tcl et retourne le résultat de cette évaluation. Si le dernier argument motif est default, il correspond à tout. Si aucun argument motif ne correspond à la chaîne et qu'aucun défaut n'est donné, la commande switch retourne une chaîne vide.

Si les arguments initiaux de switch commencent par -, ils sont traités comme des options, sauf s'il y a exactement deux arguments pour switch (auquel cas le premier doit être la chaîne et le second doit être la liste motif/corps). Les options suivantes sont actuellement prises en charge :

-exact
Utilise la comparaison exacte lors de la comparaison de la chaîne avec un motif. C'est le comportement par défaut.
-glob
Lors de la comparaison de la chaîne avec les motifs, utilise la correspondance de style glob (c'est-à-dire la même que celle implémentée par la commande string match).
-regexp
Lors de la comparaison de la chaîne avec les motifs, utilise la correspondance d'expressions régulières (comme décrit dans la page de référence re_syntax).
-nocase
Permet de gérer les comparaisons de manière insensible à la casse.
-matchvar nomVar
Cette option (légale uniquement lorsque -regexp est également spécifié) spécifie le nom d'une variable dans laquelle la liste des correspondances trouvées par le moteur d'expressions régulières sera écrite. Le premier élément de la liste écrite sera la sous-chaîne globale de la chaîne d'entrée (c'est-à-dire l'argument chaîne de switch) qui a correspondu, le deuxième élément de la liste sera la sous-chaîne correspondant à la première parenthèse capturante dans l'expression régulière qui a correspondu, et ainsi de suite. Lorsqu'une branche default est prise, la variable contiendra une liste vide. Cette option peut être spécifiée en même temps que l'option -indexvar.
-indexvar nomVar
Cette option (légale uniquement lorsque -regexp est également spécifié) spécifie le nom d'une variable dans laquelle la liste des indices faisant référence aux sous-chaînes correspondantes trouvées par le moteur d'expressions régulières sera écrite. Le premier élément de la liste écrite sera une liste à deux éléments spécifiant l'indice de début et l'indice du premier caractère après la fin de la sous-chaîne globale de la chaîne d'entrée (c'est-à-dire l'argument chaîne de switch) qui a correspondu, d'une manière similaire à l'option -indices de la commande regexp. De même, le deuxième élément de la liste fera référence à la première parenthèse capturante dans l'expression régulière qui a correspondu, et ainsi de suite. Lorsqu'une branche default est prise, la variable contiendra une liste vide. Cette option peut être spécifiée en même temps que l'option -matchvar.
--
Marque la fin des options. L'argument qui suit sera traité comme une chaîne même s'il commence par un -. Ceci n'est pas nécessaire lorsque les motifs et les corps de correspondance sont groupés ensemble dans un seul argument.

Deux syntaxes sont fournies pour les arguments motif et corps. La première utilise un argument séparé pour chacun des motifs et commandes ; cette forme est pratique si des substitutions sont souhaitées sur certains motifs ou commandes. La seconde forme regroupe tous les motifs et commandes en un seul argument ; l'argument doit avoir une structure de liste correcte, les éléments de la liste étant les motifs et les commandes. La seconde forme facilite la construction de commandes switch multilignes, car les accolades entourant toute la liste rendent inutile l'ajout d'une barre oblique inverse à la fin de chaque ligne. Étant donné que les arguments motif sont entre accolades dans la seconde forme, aucune substitution de commande ou de variable n'est effectuée sur eux ; cela rend le comportement de la seconde forme différent de la première forme dans certains cas.

Si un corps est spécifié comme “-”, cela signifie que le corps du motif suivant doit également être utilisé comme corps pour ce motif (si le motif suivant a également un corps de “-”, alors le corps après celui-ci est utilisé, et ainsi de suite). Cette fonctionnalité permet de partager un seul corps entre plusieurs motifs.

Faites attention à la manière dont vous placez les commentaires dans les commandes switch. Les commentaires ne doivent être placés qu'à l'intérieur du corps d'exécution de l'un des motifs, et non mélangés avec les motifs.

EXEMPLES

La commande switch peut correspondre à des variables et pas seulement à des littéraux, comme le montre cet exemple (le résultat est 2) :

set foo "abc"
switch abc a - b {expr {1}} $foo {expr {2}} default {expr {3}}

L'utilisation de la correspondance glob et du corps de chute est une alternative à l'écriture d'expressions régulières avec des alternatives, comme on peut le voir ici (cela renvoie 1) :

switch -glob aaab {
    a*b     -
    b       {expr {1}}
    a*      {expr {2}}
    default {expr {3}}
}

Lorsque rien ne correspond, la clause default (qui doit être la dernière) est prise. Cet exemple a un résultat de 3 :

switch xyz {
    a -
    b {
        # Placement correct du commentaire
        expr {1}
    }
    c {
        expr {2}
    }
    default {
        expr {3}
    }
}

Lors de la correspondance avec des expressions régulières, les informations sur ce qui a exactement correspondu sont facilement obtenues en utilisant l'option -matchvar :

switch -regexp -matchvar foo -- $bar {
    a(b*)c {
        puts "Trouvé [string length [lindex $foo 1]] 'b'"
    }
    d(e*)f(g*)h {
        puts "Trouvé [string length [lindex $foo 1]] 'e' et\
                [string length [lindex $foo 2]] 'g'"
    }
}
