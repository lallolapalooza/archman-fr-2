swaynag(1) Manuel des commandes générales swaynag(1)

NOM

swaynag - Afficher un message d'avertissement ou d'erreur avec des boutons

SYNTAXE

swaynag [options...]

OPTIONS

-b, --button <texte> <action>

Crée un bouton avec le texte texte qui exécute action lorsqu'il est pressé. Si la variable d'environnement TERMINAL est définie, action sera exécutée dans le terminal. Sinon, elle s'exécutera directement. Plusieurs boutons peuvent être définis en utilisant l'indicateur plusieurs fois.

-B, --button-no-terminal <texte> <action>

Crée un bouton avec le texte texte qui exécute action lorsqu'il est pressé. action sera exécutée directement au lieu d'être dans un terminal. Plusieurs boutons peuvent être définis en utilisant l'indicateur plusieurs fois.

-z, --button-dismiss <texte> <action>

Crée un bouton avec le texte texte qui exécute action lorsqu'il est pressé, et ferme swaynag. Si la variable d'environnement TERMINAL est définie, action sera exécutée dans le terminal. Sinon, elle s'exécutera directement. Plusieurs boutons peuvent être définis en utilisant l'indicateur plusieurs fois.

-Z, --button-dismiss-no-terminal <texte> <action>

Crée un bouton avec le texte texte qui exécute action lorsqu'il est pressé, et ferme swaynag. action sera exécutée directement au lieu d'être dans un terminal. Plusieurs boutons peuvent être définis en utilisant l'indicateur plusieurs fois.

-c, --config <chemin>

Le fichier de configuration à utiliser. Par défaut, les chemins suivants sont vérifiés : $HOME/.swaynag/config, $XDG_CONFIG_HOME/swaynag/config, et SYSCONFDIR/swaynag/config. Tous les indicateurs, à l'exception de celui-ci et de debug, sont des options valides dans le fichier de configuration au format option-longue=valeur. Tous les tirets initiaux doivent être omis et le signe égal est requis. Voir swaynag(5) pour plus d'informations.

-d, --debug

Active le débogage.

-e, --edge top|bottom

Définit le bord à utiliser.

-y, --layer overlay|top|bottom|background

Définit la couche à utiliser.

-f, --font <police>

Définit la police à utiliser.

-h, --help

Affiche le message d'aide et quitte.

-l, --detailed-message

Lit un message détaillé depuis l'entrée standard. Un bouton pour afficher/masquer les détails sera ajouté. Les détails sont affichés dans une zone de texte multi-lignes déroulante.

-L, --detailed-button <texte>

Définit le texte du bouton qui affiche/masque les détails. Cela n'a aucun effet s'il n'y a pas de message détaillé. Le texte par défaut est Afficher les détails.

-m, --message <msg>

Définit le texte du message.

-o, --output <sortie>

Définit la sortie à utiliser. Il doit s'agir du nom d'une xdg_output.

-s, --dismiss-button <texte>

Définit le texte du bouton de fermeture de la barre d'avertissement. Le texte par défaut est X.

-t, --type <type>

Définit le type de message. Deux types sont créés par défaut : error et warning. Des types personnalisés peuvent être définis dans le fichier de configuration. Voir --config et swaynag(5) pour les détails. Les deux types par défaut peuvent être remplacés dans le fichier de configuration.

-v, --version

Affiche le numéro de version et quitte.

OPTIONS D'APPARANCE

--background <RRGGBB[AA]>

Définit la couleur de l'arrière-plan.

--border <RRGGBB[AA]>

Définit la couleur de la bordure.

--border-bottom <RRGGBB[AA]>

Définit la couleur de la bordure inférieure.

--button-background <RRGGBB[AA]>

Définit la couleur de l'arrière-plan des boutons.

--text <RRGGBB[AA]>

Définit la couleur du texte.

--button-text <RRGGBB[AA]>

Définit la couleur du texte des boutons.

--border-bottom-size <taille>

Définit l'épaisseur de la bordure inférieure.

--message-padding <remplissage>

Définit le remplissage du message.

--details-background <RRGGBB[AA]>

Définit la couleur de l'arrière-plan des détails.

--details-border-size <taille>

Définit l'épaisseur de la bordure des détails.

--button-border-size <taille>

Définit l'épaisseur de la bordure des boutons.

--button-gap <espace>

Définit l'espace entre les boutons.

--button-dismiss-gap <espace>

Définit l'espace entre le bouton de fermeture et un autre bouton.

--button-margin-right <marge>

Définit la marge du bouton de fermeture vers le bord droit.

--button-padding <remplissage>

Définit le remplissage du texte du bouton.
