swaymsg(1) Manuel des commandes générales swaymsg(1)

NOM

swaymsg - Envoyer des messages à une instance en cours d'exécution de sway via le socket IPC.

SYNOPSIS

swaymsg [options...] [message]

OPTIONS

-h, --help

Afficher le message d'aide et quitter.

-m, --monitor

Surveiller les réponses jusqu'à ce que le processus soit arrêté au lieu de quitter après la première réponse. Ceci ne peut être utilisé qu'avec le type de message IPC subscribe. S'il y a une réponse malformée ou si un type d'événement invalide a été demandé, swaymsg arrêtera la surveillance et quittera.

-p, --pretty

Utiliser une sortie formatée même lorsque vous n'utilisez pas un tty. Non disponible pour tous les types de messages.

-q, --quiet

Envoie le message IPC mais n'imprime pas la réponse de sway.

-r, --raw

Utiliser une sortie JSON brute même en utilisant un tty.

-s, --socket <chemin>

Utiliser le chemin du socket spécifié. Sinon, swaymsg demandera à sway où se trouve le socket (qui est la valeur de $SWAYSOCK, puis de $I3SOCK).

-t, --type <type>

Spécifier le type de message IPC. Voir ci-dessous.

-v, --version

Afficher la version (de swaymsg) et quitter.

TYPES DE MESSAGES IPC

<commande>

Le message est une commande sway (les mêmes commandes que vous pouvez lier à des raccourcis clavier dans votre fichier de configuration sway). Elle sera exécutée immédiatement.

Voir sway(5) pour une liste des commandes.

swaymsg peut retourner une sortie formatée joliment (standalone-default) ou formatée en JSON (--raw). Pour une documentation détaillée sur les données JSON retournées pour chaque type de message listé ci-dessous, référez-vous à sway-ipc(7). Le format JSON peut contenir plus d'informations que le formatage joli.

Conseils :

  • L'expansion des commandes est effectuée deux fois : une fois par swaymsg, et à nouveau par sway. Si vous avez cité des chaînes de caractères composées de plusieurs mots dans votre commande, entourez la commande entière de guillemets simples. Par exemple, utilisez swaymsg 'output "Foobar Display" enable' au lieu de swaymsg output "Foobar Display" enable. De plus, notez que les options séparées par des virgules sont également considérées comme des chaînes de plusieurs mots, car les virgules peuvent être utilisées pour exécuter des commandes sur la même ligne.
  • Si vous fournissez une commande qui commence par un tiret (-), insérez deux tirets (--) avant la commande pour signaler à swaymsg de ne rien analyser au-delà de ce point comme une option. Par exemple, utilisez swaymsg -- mark --add test au lieu de swaymsg mark --add test.

get_workspaces

Récupère une liste des espaces de travail et leur statut.

get_inputs

Récupère une liste des entrées actuelles.

get_outputs

Récupère une liste des sorties actuelles.

get_tree

Récupère une arborescence de mise en page encodée en JSON de toutes les fenêtres ouvertes, conteneurs, sorties, espaces de travail, etc.

get_seats

Récupère une liste de tous les sièges, leurs propriétés et tous les périphériques assignés.

get_marks

Récupère une liste des marques encodée en JSON.

get_bar_config

Récupère la configuration encodée en JSON pour swaybar.

get_version

Récupère les informations de version pour l'instance en cours d'exécution de sway.

get_binding_modes

Récupère une liste des modes de liaison actuellement configurés, encodée en JSON.

get_binding_state

Récupère des informations sur l'état actuel des liaisons, encodées en JSON.

get_config

Récupère une copie de la configuration actuelle. N'étend pas les inclusions.

send_tick

Envoie un événement tick à tous les clients abonnés.

subscribe

S'abonne à une liste de types d'événements. L'argument pour ce type doit être fourni sous la forme d'un tableau JSON valide. Si l'un des types est invalide ou si un tableau JSON valide n'est pas fourni, cela entraînera un échec. Pour une liste des types d'événements valides et des données renvoyées avec eux, référez-vous à sway-ipc(7).

CODES DE RETOUR

0

Succès

1

Erreurs de swaymsg telles que syntaxe invalide, incapacité à se connecter au socket ipc ou incapacité à analyser la réponse de sway

2

Sway a renvoyé une erreur lors du traitement de la commande (par exemple, commande invalide, commande échouée et demande d'abonnement invalide)
