NOM

sane-kodakaio - Backend SANE pour imprimantes / scanners Kodak multifonctions

DESCRIPTION

La bibliothèque sane-kodakaio implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux imprimantes/scanners Kodak multifonctions, comme les séries ESP et Hero.

Ce document décrit la version 2.4 du backend, qui est la première candidate à être incorporée dans sane-backends.

MATÉRIEL SUPPORTÉ

Cette version devrait supporter les modèles des séries Kodak ESP et Hero, et potentiellement certains scanners Advent AiO. Les ESP 5250 et Hero 9.1 ont été utilisés pour développer le backend, mais d'autres modèles pourraient fonctionner. Veuillez consulter la liste des appareils supportés sur http://www.sane-project.org/sane-backends.html#S-KODAKAIO.

Si vous avez un modèle qui ne figure pas sur cette liste, ou marqué comme 'non testé' : le meilleur moyen de déterminer le niveau de support est de tester le scanner directement.

FICHIER DE CONFIGURATION

Le fichier de configuration kodakaio.conf est utilisé pour indiquer au backend comment rechercher les scanners et fournir des options contrôlant le fonctionnement du backend. Ce fichier est lu à chaque fois que le frontend demande au backend une liste de scanners, généralement uniquement au démarrage du frontend.

ENVIRONNEMENT

SANE_DEBUG_KODAKAIO
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

PROBLÈMES CONNUS

La plupart des options matérielles ne sont soit pas supportées, soit pas exposées pour le contrôle par l'utilisateur, y compris : la détection de multi-alimentations, la compression d'image, etc.
