sane-p5(5) SANE Scanner Access Now Easy sane-p5(5)

NOM

sane-p5 - Backend SANE pour le Primax PagePartner

DESCRIPTION

La bibliothèque sane-p5 implémente un backend SANE (Scanner Access Now Easy) qui donne accès au scanner à alimentation papier par port parallèle Primax PagePartner.

Ce backend gère les résolutions de scan de 100, 150, 200, 300 et 600 dpi, en modes couleur et niveaux de gris. Le 600 dpi est en réalité 300x600 avec des lignes agrandies pour correspondre à la résolution verticale.

MODES EPP/ECP UNIQUEMENT La version actuelle du backend n'utilise que le mode EPP ou ECP pour communiquer avec le scanner. Il est recommandé de configurer votre port parallèle en EPP dans le BIOS avec la version actuelle de ce backend. ECPEPP ne fonctionnera que si vous utilisez un noyau 2.4 ou 2.6 avec le support du périphérique caractère ppdev.

NOMS DE PÉRISPHÉRIQUES

Ce backend attend des noms de périphériques de la forme :

port valeur

Où valeur est :

auto
détecte automatiquement tous les ports parallèles et les sonde pour trouver le scanner
/dev/parport0
utilise le périphérique ppdev de Linux, en fonction du nombre de ports parallèles disponibles, vous devrez utiliser /dev/parport1, /dev/parport2, ...

Vous pouvez renommer n'importe quel périphérique en utilisant l'option


option nom mon_nom

Cette option s'applique à la dernière option de port.

CONFIGURATION

Assurez-vous d'éditer dll.conf avant d'utiliser le backend, car ce backend n'est pas activé par défaut.

FICHIERS

/etc/sane.d/p5.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-p5.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-p5.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes \*NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (`.`) puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour résultat la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_P5
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 255 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité. 
niveau  sortie de débogage
------- ------------------------------
 0       erreurs critiques
 1       erreurs
 2       avertissements & erreurs mineures
 4       messages d'information
 8       début/fin de fonctions
 16      messages de traçage
 32      fonctions d'E/S
 64      fonctions d'E/S avec traçages
 128     données numérisées/calibrées

SIGNALEMENT DE BOGUES

Si quelque chose ne fonctionne pas, envoyez un e-mail à sane-devel@alioth-lists.debian.net ou soumettez un ticket via https://gitlab.com/sane-project/backends/issues/new avec le label backend/p5. Veuillez fournir autant d'informations que possible.

Version SANE
exécutez "scanimage -V" pour la déterminer
la version du backend et le matériel de votre scanner
exécutez SANE_DEBUG_P5=255 scanimage -L 2>log en tant que root. Si vous n'obtenez aucune sortie du backend p5, assurez-vous qu'une ligne "p5" est incluse dans votre /etc/sane.d/dll.conf. Si votre scanner n'est pas détecté, assurez-vous d'avoir défini la bonne adresse de port, ou le bon périphérique dans votre fichier p5.conf.
le nom de votre scanner/fabricant
une information également utile. Veuillez également inclure la résolution optique et le type de lampe de votre scanner, que l'on trouve tous deux dans le manuel de votre scanner.
tous commentaires supplémentaires
si vous avez des commentaires sur la documentation (ce qui pourrait être amélioré), ou si vous pensez que je devrais savoir quelque chose, veuillez l'inclure.
