NOM

sane-gphoto2 - Module SANE pour les appareils photo supportés par gphoto2

DESCRIPTION

La bibliothèque sane-gphoto2 implémente un module SANE (Scanner Access Now Easy) qui permet d'accéder aux appareils photo numériques supportés par gphoto2. Ce module n'a été testé qu'avec une poignée d'appareils jusqu'à présent. Les correctifs pour supporter d'autres modèles sont les bienvenus.

En raison du nombre limité de tests effectués pour ce module, il est commenté par défaut dans /etc/sane.d/dll.conf. Soit le caractère de commentaire doit être supprimé, soit le module doit être appelé explicitement. Par exemple, scanimage -d gphoto2 ou xscanimage gphoto2.

NOMS DE PÉRIPHÉRIQUE

La version actuelle du module ne permet qu'un seul appareil connecté. Le nom du périphérique est toujours "0".

CONFIGURATION

Le contenu de gphoto2.conf spécifie les caractéristiques de l'appareil photo à utiliser. Les résolutions (haute résolution, basse résolution et taille de vignette) sont nécessaires car elles sont requises par les interfaces SANE, mais elles ne peuvent pas être obtenues via l'interface gphoto2. Les ports et appareils valides peuvent être obtenus par gphoto2 --list-cameras et gphoto2 --list-ports.

La ligne dumpinquiry provoque l'affichage de certaines informations sur l'appareil photo.

Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous:

La ligne topfolder spécifie la partie "fixe" du chemin du fichier. Par exemple, sur le Kodak DC-240, les fichiers sont stockés dans le répertoire /DCIM/100DC240. Le /DCIM est constant, mais 100DC240 changera et devra être lu à partir de l'appareil photo. Dans ce cas, la ligne serait "topfolder=/DCIM"

Certains appareils n'implémentent pas de structure de fichiers et stockent toutes les images dans le répertoire /. Ceci est indiqué en définissant "subdirs=0" avec "topfolder=/"

port=usb:
camera=Kodak DC240
# ceci est un commentaire
high_resolution=1280x960
low_resolution=640x480
thumb_resolution=160x120
dumpinquiry

FICHIERS

/etc/sane.d/gphoto2.conf
Le fichier de configuration du module (voir également la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-gphoto2.a
La bibliothèque statique implémentant ce module.
/usr/lib/sane/libsane-gphoto2.so
La bibliothèque partagée implémentant ce module (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:') , sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (.) puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_GPHOTO2
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce module. Une valeur de 128 demande une sortie de débogage maximale ; des niveaux plus bas réduisent la verbosité.
GP_DEBUG
Défini à 1, 2 ou 3, pour activer différents niveaux de débogage dans les bibliothèques gphoto2.
