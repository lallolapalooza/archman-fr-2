sane-ibm(5) SANE Scanner Access Now Easy sane-ibm(5)

NOM

sane-ibm - Backend SANE pour scanners à plat SCSI IBM et Ricoh

DESCRIPTION

La bibliothèque sane-ibm implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat SCSI IBM 2456 et Ricoh IS-410, IS-420 et IS-430. Le support pour les IS-410 et IS-430 n'est pas testé. Veuillez contacter le mainteneur ou la liste de diffusion sane-devel si vous possédez un tel scanner.

Ce backend est de qualité alpha. Il peut contenir des bugs et certains scanners n'ont pas été testés du tout. Soyez prudent et tirez la prise si le scanner provoque un bruit inhabituel.

NOMS DE PÉRIPHÉRIQUE

Ce backend attend des noms de périphérique de la forme :

spécial

Où spécial est le chemin d'accès au périphérique spécial qui correspond à un scanner SCSI. Le programme sane-find-scanner(1) aide à trouver le bon périphérique. Sous Linux, un tel nom de périphérique pourrait être /dev/sg0 ou /dev/sga, par exemple. Voir sane-scsi(5) pour plus de détails.

CONFIGURATION

Le contenu du fichier ibm.conf est une liste de noms de périphérique qui correspondent à des scanners SCSI. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Voir sane-scsi(5) pour les détails sur ce qui constitue un nom de périphérique valide.

FICHIERS

/etc/sane.d/ibm.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-ibm.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-ibm.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:`), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour résultat de rechercher dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_IBM
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.
