NOM

sane-sceptre - Backend SANE pour scanners SCEPTRE

DESCRIPTION

La bibliothèque sane-sceptre implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat Sceptre. Ce backend doit être considéré comme un logiciel de qualité bêta ! Veuillez signaler tout comportement étrange au mainteneur du backend ou à la liste de diffusion SANE.

Actuellement, un seul scanner est connu pour fonctionner avec ce backend :

Modèle                       Type de connexion
---------------------------  -------------------
Sceptre VividScan S1200      SCSI

La marque de ce scanner est KINPO, donc d'autres scanners de ce fabricant peuvent également fonctionner (par exemple, le S600).

OPTIONS

Les options supportées par le backend peuvent être sélectionnées via les options de ligne de commande de programmes comme scanimage(1) ou via des éléments d'interface graphique dans xscanimage(1) ou xsane(1).

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant

scanimage --help -d sceptre
Mode de numérisation
--mode Lineart|Halftone|Gray|Color
Sélectionne le mode de fonctionnement de base du scanner. Les modes Lineart et Halftone sont uniquement en noir et blanc (1 bit). Gray produira 256 niveaux de gris (8 bits). Color produira une image couleur de 24 bits. Le scanner supporte 30 bits en interne mais n'en exporte que 24.
--resolution 50..1200
Sélectionne la résolution pour une numérisation. Le scanner peut effectuer plusieurs résolutions entre 50 et 1200.
--halftone-pattern 1|2|3|4
Sélectionne le mode de motif utilisé en mode Halftone.
--gamma-correction Default|User Defined|High Density Printing|Low density printing|High contrast printing
contrôle la correction gamma interne du scanner.
--custom-gamma
Permet à l'utilisateur de spécifier une table gamma (voir les 3 paramètres suivants). Mode Color uniquement.
--red-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal rouge. La table doit être longue de 256 octets. Mode Color uniquement.
--green-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal vert. La table doit être longue de 256 octets. Mode Color uniquement.
--blue-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal bleu. La table doit être longue de 256 octets. Mode Color uniquement.
--threshold 0..255
Définit le seuil pour les pixels noirs et blancs en mode Lineart. Les valeurs possibles vont de 0 (plus sombre) à 255 (plus clair).
--preview
Demande une numérisation d'aperçu. La résolution utilisée pour cette numérisation est de 30 dpi et la zone de numérisation est le maximum autorisé. Le mode de numérisation est sélectionné par l'utilisateur. La valeur par défaut est "non".
Les options de géométrie
-l -t -x -y
contrôlent la zone de numérisation : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de numérisation. Tous les paramètres sont spécifiés en millimètres par défaut.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/sceptre.conf ne supporte qu'un seul élément : le nom du périphérique à utiliser (par exemple /dev/scanner).

FICHIERS

/usr/lib/sane/libsane-sceptre.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-sceptre.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_SCEPTRE
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité.

LIMITATIONS

Résolutions
Le pilote TWAIN de Windows peut être réglé à n'importe quelle résolution entre 50 et 1200 (interpolation logicielle exclue). Ce backend ne peut pas. Seule une poignée de résolutions sont disponibles, bien qu'elles devraient être suffisantes en nombre.

BOGUES

Aucun connu.
