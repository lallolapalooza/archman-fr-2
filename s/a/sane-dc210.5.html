NOM

sane-dc210 - Backend SANE pour appareil photo numérique Kodak DC210

DESCRIPTION

La bibliothèque sane-dc210 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à l'appareil photo Kodak DC210. Ceci est du code EXTRÊMEMENT ALPHA ! UTILISEZ À VOS RISQUES ET PÉRILS !!

NOMS DE PÉRIPHÉRIQUE

La version actuelle du backend ne permet de connecter qu'un seul appareil photo. Le nom du périphérique est toujours "0".

CONFIGURATION

Le contenu de dc210.conf spécifie le port série et le débit en bauds à utiliser. Le débit en baud spécifie le débit maximum à utiliser lors du téléchargement des images. (L'appareil photo est toujours initialisé en utilisant 9600 bauds, puis passe au débit supérieur). Sur mon Pentium de 90MHz, je n'ai généralement aucun problème à télécharger à 115200 bauds tant que le système n'est pas excessivement occupé et que le "flag de démasquage d'interruption" est activé dans le pilote IDE (hdparm -u1). Les débits en bauds pris en charge sont : 9600, 19200, 38400, 57600 et 115200.

La ligne dumpinquiry provoque l'affichage de certaines informations sur l'appareil photo.

cmdrespause spécifie le nombre d'usec (1 millionièmes de seconde) à attendre entre l'écriture de la commande et la lecture du résultat. 125000 semble être le minimum que j'ai pu descendre de manière fiable.

breakpause spécifie le nombre d'usec (1 millionièmes de seconde) entre l'envoi de la rupture "retour au défaut" et l'envoi des commandes.

Les lignes vides et les lignes commençant par un signe dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous :

port=/dev/ttyS0
# ceci est un commentaire
baud=115200
dumpinquiry
cmdrespause=125000
breakpause=1000000

FICHIERS

/etc/sane.d/dc210.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-dc210.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-dc210.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux points (`:'), sous OS/2, ils sont séparés par un point virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires spécifiés explicitement. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche des répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_DC210
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Une valeur de 128 demande une sortie de débogage maximale ; des niveaux plus petits réduisent la verbosité.
