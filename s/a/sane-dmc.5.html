sane-dmc(5) SANE Scanner Access Now Easy sane-dmc(5)

NOM

sane-dmc - Backend SANE pour le Polaroid Digital Microscope Camera

DESCRIPTION

La bibliothèque sane-dmc implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès au Polaroid Digital Microscope Camera.

NOMS DE PÉRIphérique

Ce backend s'attend à des noms de périphérique de la forme :

spécial

Où spécial est le nom de chemin UNIX pour le périphérique spécial qui correspond au scanner. Le nom de périphérique spécial doit être un périphérique SCSI générique ou un lien symbolique vers un tel périphérique. Sous Linux, un tel nom de périphérique pourrait être /dev/sga ou /dev/sge, par exemple.

MODES D'IMAGERIE

Le Polaroid DMC prend en charge un certain nombre de modes d'imagerie. Ce pilote prend en charge cinq des modes d'imagerie :

Full Frame
Ce mode correspond à l'image couleur pleine résolution de 801 par 600 pixels.
Viewfinder
Ce mode correspond à l'image de viseur en niveaux de gris de 270 par 201 pixels. Cette image est acquise très rapidement.
Raw
Ce mode correspond à l'image "brute" de 1599 par 600 pixels du CCD. Elle est en niveaux de gris, avec des pixels alternant horizontalement entre des bandes rouges, vertes et bleues. Les pixels sont deux fois plus hauts que larges, donc l'image est déformée.
Thumbnail
Ce mode correspond à l'image miniature couleur de 80 par 60 pixels.
Super Resolution
Cette image est une image couleur de 1599 par 1200 pixels construite en filtrant et en interpolant l'image "brute". Le filtrage et l'interpolation sont effectués par logiciel, donc ce mode est très lent. De plus, ce mode impose des restrictions sur la façon dont l'image est lue, ce qui signifie que le mode "aperçu" de xscanimage(1) ne fonctionne pas en mode Super Resolution. (xcam(1) et les modes sans aperçu de scanimage(1) et xscanimage(1) fonctionnent correctement, cependant.)

AUTRES PARAMÈTRES

Paramètre ASA
Ce paramètre ajuste la sensibilité de la caméra. Vous pouvez choisir parmi 25, 50 ou 100 ASA "équivalents".
Vitesse d'obturation
Vous pouvez sélectionner une vitesse d'obturation de 8 à 1000 millisecondes. La vitesse d'obturation est quantifiée par unités de 32 microsecondes.
Balance des blancs
Vous pouvez choisir parmi les balances des blancs "Lumière du jour", "Incandescent" ou "Fluorescent". Ce paramètre correspond plus ou moins aux réglages de "Température de couleur" des logiciels Windows et Mac de Polaroid.

CONFIGURATION

Le contenu du fichier dmc.conf est une liste de noms de périphériques qui correspondent aux scanners DMC. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous :

/dev/scanner
# ceci est un commentaire
/dev/sge

FICHIERS

/etc/sane.d/dmc.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-dmc.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-dmc.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") et ensuite dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_DMC
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande à afficher toutes les sorties de débogage. Des niveaux plus petits réduisent la verbosité.

BOGUES

Dans les modes "Full Frame" et "Raw", les images doivent être lues par unités de lignes complètes. Le pilote n'effectue aucun buffering dans ces modes ; si vous demandez à sane_read de lire un nombre non entier de lignes, il peut lire moins que ce que vous avez demandé. Si vous demandez à sane_read de lire moins qu'une ligne entière, il renvoie SANE_STATUS_INVAL.

En mode "Super Resolution", les images doivent être lues par unités de deux lignes (3198 pixels ou 9594 octets). Si vous essayez de lire moins de deux lignes, vous obtenez SANE_STATUS_INVAL. Le mode Super Resolution est très lent.

En modes "Viewfinder" et "Thumbnail", l'image entière doit être lue en un seul transfert SCSI. Dans ce cas, le pilote effectue un buffering et vous pouvez lire l'image par incréments aussi petits que vous le souhaitez.
