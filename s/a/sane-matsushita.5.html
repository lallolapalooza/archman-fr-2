NOM

sane-matsushita - Backend SANE pour les scanners haute vitesse Panasonic KV-SS

DESCRIPTION

La bibliothèque sane-matsushita implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à certains scanners haute vitesse Panasonic KV-SS. Ce backend est stable.

Actuellement, les scanners suivants sont connus pour fonctionner avec ce backend :

  Identifiant produit
--------------
   KV-SS25
   KV-SS25D
   KV-SS55EX (*)
   KV-S2025C (*)
   KV-S2045C (*)
   KV-S2065L (*)

(*) ATTENTION : Aucune des options avancées de ces scanners n'est disponible (c.-à-d. pas de couleur, pas de haute résolution, pas de recadrage automatique). Fondamentalement, le pilote ne fait pas plus que pour le KV-SS25. Je n'ai pas accès à de tels scanners et ne peux donc pas ajouter ces options.

D'autres scanners haute vitesse Panasonic peuvent ou non fonctionner avec ce backend.

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant :

scanimage --help -d matsushita

Mode de balayage
--mode
sélectionne le mode de fonctionnement de base du scanner.
--resolution
sélectionne la résolution pour un balayage. Chaque modèle prend en charge tout ou partie de ces résolutions : 100, 150, 200, 240, 300, 360, 400.
--duplex
indique s'il faut numériser les deux côtés de la feuille.
--feeder-mode
sélectionne le nombre de pages à numériser (une ou jusqu'à ce que le bac soit vide).
Géométrie
--paper-size A4|...|Legal|Letter [A4]
sélectionne la zone à numériser. Il ajuste les options -l -t -x -y en conséquence. Il n'a pas besoin d'être la taille réelle du papier.
-l -t -x -y
contrôle la zone de numérisation : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de numérisation. Tous les paramètres sont spécifiés en millimètres. Il est possible d'utiliser l'option --paper-size à la place.
Amélioration
--brightness
contrôle la luminosité de l'image acquise. La valeur varie de 1 à 255, ou moins, selon le modèle du scanner.
--contrast
contrôle le contraste de l'image acquise. Certains modèles ne prennent pas en charge cette option.
--automatic-threshold
définit automatiquement la luminosité, le contraste, le niveau de blanc, la gamma, la réduction du bruit et l'accentuation de l'image. Ces options ne sont pas disponibles lorsque l'option automatic-threshold est utilisée.
--halftone-pattern
définit la gradation des tons pour le mode demi-teintes. Le téléchargement de motifs n'est pas implémenté par le backend.
--autoseparation
fournit une séparation automatique du texte et des images.
--white-level
indique la source de la base blanche.
--noise-reduction
réduit le bruit des points isolés. Cette option n'est pas prise en charge par tous les scanners.
--image-emphasis
définit l'accentuation de l'image. Certaines sélections ne sont pas disponibles sur tous les scanners.
--gamma
définit la courbe gamma. Elle n'est valide que pour les modes Gris et n'est pas disponible sur tous les scanners. Le téléchargement de la courbe gamma n'est pas implémenté par le backend.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/matsushita.conf prend en charge le nom de périphérique à utiliser (par exemple, /dev/scanner) et l'option SCSI pour détecter automatiquement les scanners pris en charge.

FICHIERS

/usr/lib/sane/libsane-matsushita.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-matsushita.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_MATSUSHITA
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande que toutes les sorties de débogage soient imprimées. Des niveaux plus bas réduisent la verbosité.

LIMITATIONS

Mémoire dans le KV-SS 25
Le KV-SS 25 n'a pas assez de mémoire interne pour numériser une page A4 entière en mode duplex à haute résolution. Le frontend renverra une erreur de mémoire dans ce cas. Apparemment, le KV-SS 25D n'a pas ce problème.
Téléchargement de motifs et de courbes gamma
Le scanner, avec le firmware approprié, peut télécharger un motif de demi-teintes et une table gamma. Ceci n'est pas implémenté.
Sous-zones
Le scanner peut supporter jusqu'à 3 sous-zones de chaque côté pour définir des options d'amélioration plus précises. Ceci n'est pas implémenté.
Mode duplex
Le backend ne prend pas en charge la définition d'options différentes pour chaque côté. Le balayage s'effectuera avec les mêmes options (motif de demi-teintes, luminosité, accentuation de l'image) pour les deux côtés.

EXEMPLE DE NUMÉRISATION

À ce jour, le seul frontend capable d'utiliser ce scanner à pleine vitesse est scanadf(1).

Une ligne de commande scanadf(1) ressemblerait à ceci :

scanadf -d matsushita --output-file scan%04d.pbm --start-count 0 --duplex --resolution 300 --feeder-mode="Toutes les pages" --paper-size="A4"

BOGUES

Aucun connu.
