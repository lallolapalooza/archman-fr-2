sane-ricoh(5) SANE Scanner Access Now Easy sane-ricoh(5)

NOM

sane-ricoh - backend SANE pour les scanners plats Ricoh

DESCRIPTION

La bibliothèque sane-ricoh implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners plats Ricoh suivants :

IS50
IS60

NOMS DE PÉRIPHÉRIQUE

Ce backend attend des noms de périphérique de la forme :

special

Où special est le chemin d'accès du périphérique spécial correspondant à un scanner SCSI. Le nom du périphérique spécial doit être un périphérique SCSI générique ou un lien symbolique vers un tel périphérique. Le programme sane-find-scanner(1) aide à trouver le bon périphérique. Sous Linux, un tel nom de périphérique pourrait être /dev/sga ou /dev/sge, par exemple. Voir sane-scsi(5) pour plus de détails.

FICHIERS

/etc/sane.d/ricoh.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-ricoh.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-ricoh.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_DEBUG_RICOH
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_RICOH=4

VOIR AUSSI

sane(7), sane-scsi(5), sane-find-scanner(1)
