sane-sm3600(5) SANE Scanner Access Now Easy sane-sm3600(5)

NOM

sane-sm3600 - Backend SANE pour les scanners Microtek avec puce USB M011

DESCRIPTION

La bibliothèque sane-sm3600 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à certains scanners Microtek avec la puce USB personnalisée Toshiba M011. Ce backend doit être considéré comme alpha.

Il existe également des backends pour les scanners Microtek avec un jeu de commandes SCSI. Reportez-vous à sane-microtek(5) et sane-microtek2(5) pour plus de détails.

Actuellement, les scanners suivants sont connus pour fonctionner avec ce backend :

Vendeur     Identifiant produit:     Remarque :
--------   --------------  -----------
Microtek   ScanMaker 3600  tous modes ok
Microtek   ScanMaker 3700  signalé comme fonctionnant
Microtek   ScanMaker 3750  signalé comme fonctionnant

Si vous possédez un scanner Microtek avec la puce M011 autre que ceux listés ci-dessus, il peut fonctionner ou non avec SANE !

OPTIONS FRONTEND

Ce backend active dynamiquement les options pour le frontend, qui sont prises en charge par le scanner en fonction du mode de numérisation et d'autres options. Les options non prises en charge sont désactivées.

Les options suivantes sont prises en charge par le backend sane-sm3600 : numérisations couleur, niveaux de gris, tramage et dessin. Également correction du contraste, de la luminosité et du gamma.

NOMS D'APPAREIL

Ce backend ne prend pas en charge les noms d'appareils sous une forme standardisée.

CONFIGURATION

Ce backend ne prend pas en charge de fichier de configuration pour l'instant.

FICHIERS

/usr/lib/sane/libsane-sm3600.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-sm3600.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_SM3600
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande que toutes les sorties de débogage soient imprimées. Des niveaux inférieurs réduisent la verbosité. Pour voir les messages d'erreur sur la sortie d'erreur standard, définissez SANE_DEBUG_SM3600 sur 1.

Par exemple, dites simplement :
export SANE_DEBUG_SM3600=5
