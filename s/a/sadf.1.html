NOM

sadf - Afficher les données collectées par sar dans plusieurs formats.

SYNTAXE

sadf [ -C ] [ -c | -d | -g | -j | -l | -p | -r | -x ] [ -H ] [ -h ] [ -T | -t | -U ] [ -V ] [ -O opts [,...] ] [ -P { liste_cpu | ALL } ] [ -s [ heure_debut ] ] ] [ -e [ heure_fin ] ] ] [ --dev=liste_peripheriques ] [ --fs=liste_fs ] [ --iface=liste_interfaces] [ --int=liste_interruptions ] [ -- options_sar ] [ intervalle [ nombre ] ] [ fichier_donnees | -[0-9]+ ]

DESCRIPTION

La commande sadf sert à afficher le contenu des fichiers de données créés par la commande sar(1). Mais contrairement à sar, sadf peut écrire ses données dans de nombreux formats différents (CSV, XML, etc.). Le format par défaut est celui qui peut être facilement traité par des commandes de traitement de motifs comme awk (voir l'option -p). La commande sadf peut également être utilisée pour dessiner des graphiques des différentes activités collectées par sar et les afficher sous forme de graphiques SVG (Scalable Vector Graphics) dans votre navigateur web (voir l'option -g).

La commande sadf extrait et écrit sur la sortie standard les enregistrements sauvegardés dans le fichier fichier_donnees. Ce fichier doit avoir été créé par une version de sar compatible avec celle de sadf. Si fichier_donnees est omis, sadf utilise le fichier de données quotidien d'activité système standard. Il est également possible d'entrer -1, -2, etc. comme argument pour sadf afin d'afficher les données d'il y a autant de jours. Par exemple, -1 pointera vers le fichier d'activité système standard d'hier.

Le fichier de données quotidien d'activité système standard s'appelle saDD ou saYYYYMMDD, où YYYY représente l'année en cours, MM le mois en cours et DD le jour en cours. sadf recherchera le plus récent des fichiers saDD et saYYYYMMDD et l'utilisera. Par défaut, il se trouve dans le répertoire /var/log/sa. Il est cependant possible de spécifier un emplacement alternatif : si fichier_donnees est un répertoire (au lieu d'un fichier ordinaire), il sera considéré comme le répertoire où se trouve le fichier de données quotidien d'activité système standard.

Les paramètres intervalle et nombre sont utilisés pour indiquer à sadf de sélectionner nombre enregistrements espacés de intervalle secondes. Si le paramètre nombre n'est pas spécifié, tous les enregistrements sauvegardés dans le fichier de données seront affichés.

Tous les indicateurs d'activité de sar peuvent être saisis sur la ligne de commande pour indiquer quelles activités doivent être rapportées. Avant de les spécifier, placez une paire de tirets (--) sur la ligne de commande afin de ne pas confondre ces indicateurs avec ceux de sadf. Si aucun indicateur n'est spécifié, seule l'activité CPU est sélectionnée.

OPTIONS

-C
Indique à sadf d'afficher les commentaires présents dans le fichier.
-c
Convertit un ancien fichier binaire d'activité système (version 9.1.6 et ultérieures) au format actuel mis à jour. Utiliser la syntaxe suivante :

sadf -c ancien_fichier_donnees > nouveau_fichier_donnees

La conversion peut être contrôlée à l'aide de l'option -O (voir ci-dessous).

-d
Affiche le contenu du fichier de données dans un format qui peut facilement être ingéré par un système de gestion de base de données relationnelle. La sortie se compose de champs séparés par un point-virgule. Chaque enregistrement contient le nom d'hôte de la machine où le fichier a été créé, la valeur de l'intervalle (ou -1 si non applicable), l'horodatage dans un format facilement acceptable par la plupart des bases de données, et des champs de données supplémentaires séparés par des points-virgules tels que spécifiés par les options de ligne de commande options_sar. Notez que la sortie de l'horodatage peut être contrôlée par les options -T, -t et -U.
--dev=liste_peripheriques
Spécifie les périphériques de bloc pour lesquels les statistiques doivent être affichées par sadf. liste_peripheriques est une liste de noms de périphériques séparés par des virgules. Utile avec l'option -d de sar.

-e [ hh:mm[:ss] ]
-e [ secondes_depuis_l_epoch ]

Définit l'heure de fin du rapport. L'heure de fin par défaut est 18:00:00. Les heures doivent être données au format 24 heures, ou comme le nombre de secondes depuis l'epoch (donné sous forme d'un nombre à 10 chiffres).
--fs=liste_fs
Spécifie les systèmes de fichiers pour lesquels les statistiques doivent être affichées par sadf. liste_fs est une liste de noms de systèmes de fichiers ou de points de montage séparés par des virgules. Utile avec l'option -F de sar.
-g
Affiche le contenu du fichier de données au format SVG (Scalable Vector Graphics). Cette option vous permet d'afficher de jolis graphiques dans votre navigateur web. Utilisez la syntaxe suivante :

sadf -g votre_fichier_donnees [ -- options_sar ] > output.svg

et ouvrez le fichier SVG résultant dans votre navigateur web préféré. La sortie peut être contrôlée à l'aide de l'option -O (voir ci-dessous).

-H
Affiche uniquement l'en-tête du rapport (lorsque cela est applicable). Si aucun format n'a été spécifié, alors les données d'en-tête (métadonnées) du fichier de données sont affichées.
-h
Lorsqu'il est utilisé conjointement avec l'option -d, toutes les activités seront affichées horizontalement sur une seule ligne.
--iface=liste_interfaces
Spécifie les interfaces réseau pour lesquelles les statistiques doivent être affichées par sadf. liste_interfaces est une liste de noms d'interfaces séparés par des virgules. Utile avec les options -n DEV et -n EDEV de sar.
--int=liste_interruptions
Spécifie les noms des interruptions pour lesquelles les statistiques doivent être affichées par sadf. liste_interruptions est une liste de valeurs ou de plages de valeurs séparées par des virgules (par exemple, 0-16,35,40-). Utile avec l'option -I de sar.
-j
Affiche le contenu du fichier de données au format JSON (JavaScript Object Notation). Les horodatages peuvent être contrôlés par les options -T et -t.
-l
Exporte le contenu du fichier de données vers une archive PCP (Performance Co-Pilot). Le nom de l'archive peut être spécifié à l'aide du mot-clé pcparchive= avec l'option -O.
-O opts[,...]
Utilise les options spécifiées pour contrôler la sortie de sadf. Les options suivantes sont utilisées pour contrôler la sortie SVG affichée par sadf -g :
autoscale
Dessine tous les graphiques d'une vue donnée aussi grands que possible en fonction de l'échelle de la vue actuelle. Pour ce faire, un facteur (10, 100, 1000...) est utilisé pour agrandir le dessin du graphique. Cette option peut être intéressante lorsque plusieurs graphiques sont dessinés sur la même vue, certains avec seulement de très petites valeurs, et d'autres avec des valeurs élevées, ces dernières rendant les premières difficilement visibles.
bwcol
Utilise une palette de couleurs noir et blanc pour dessiner les graphiques.
customcol
Utilise une palette de couleurs personnalisable au lieu de celle par défaut pour dessiner les graphiques. Voir la variable d'environnement S_COLORS_PALETTE ci-dessous pour savoir comment personnaliser cette palette.
debug
Ajoute des commentaires utiles dans le fichier de sortie SVG.
height=valeur
Définit la hauteur de la zone de dessin SVG à valeur.
oneday
Affiche les données des graphiques sur une période de 24 heures. Notez que les heures sont toujours imprimées en UTC par défaut : vous devriez utiliser l'option -T pour les imprimer en heure locale et obtenir une fenêtre temporelle commençant à minuit.
packed
Regroupe toutes les vues de la même activité (et pour le même périphérique) sur la même ligne.
showidle
Affiche également l'état %idle dans les graphiques pour

NOM

sadf - Collecteur et rapporteur d'activité système

SYNTAXE

sadf [ -C ] [ -c ] [ -d ] [ -F ] [ -g ] [ -h ] [ -H ] [ -i ] [ -j ] [ -l ] [ -m ] [ -o ] [ -r ] [ -s ] [ -T ] [ -t ] [ -U ] [ -V ] [ -x ] [ -X ] [ -P cpu_list | ALL ] [ -p ] [ -O keyword[=value] ... ] [ interval [ count ] ]

DESCRIPTION

La commande sadf est utilisée pour collecter, reporter et analyser les statistiques d'activité de votre système. Elle peut générer des rapports dans plusieurs formats, y compris le format texte brut, le format XML et le format SVG (Scalable Vector Graphics).

La commande sadf peut lire les données à partir des fichiers binaires d'activité système par défaut (qui sont créés par la commande sadc) ou à partir d'un fichier binaire d'activité système spécifié.

Par défaut, sadf sélectionne les données de la journée en cours. La commande peut extraire des données des fichiers journaux d'activité système, dont les noms sont du type saDD où DD est le jour du mois.

Les options suivantes peuvent être utilisées pour contrôler le comportement de sadf et le format de sortie :

-C
Affiche les statistiques de la mémoire cache.
-c
Affiche les statistiques de l'utilisation de la mémoire et de l'espace d'échange.
-d
Affiche les statistiques des E/S par appareil.
-F
Affiche les statistiques des E/S du système de fichiers.
-g
Génère un graphique SVG des statistiques d'activité du système. Ce format de sortie peut être utilisé pour afficher les données sous forme de graphiques dans un navigateur Web.
-h
Affiche les statistiques d'utilisation des disques.
-H
Affiche les statistiques d'utilisation du noyau.
-i
Affiche les statistiques d'interruption par appareil.
-j
Affiche les statistiques de la file d'attente des E/S.
-l
Affiche les statistiques de la mémoire paginée.
-m
Affiche les statistiques de la mémoire.
-O keyword[=value]
Les mots-clés suivants peuvent être utilisés pour affiner la sortie SVG (voir également l'option -g) :
color
Utiliser un schéma de couleurs personnalisé. La palette de couleurs par défaut peut être remplacée en utilisant la variable d'environnement S_COLORS_PALETTE.
customcol
Utiliser un schéma de couleurs personnalisé pour le graphique SVG. Les couleurs peuvent être spécifiées via la variable d'environnement S_COLORS_PALETTE.
daysort
Trier les données par jour. Cela n'est applicable que lorsque plusieurs fichiers d'activité système sont lus.
disable-fixed-legend
Désactiver la légende fixe dans le graphique SVG.
fixed-legend
Afficher une légende fixe dans le graphique SVG.
global
Produire un graphique global des statistiques d'activité système.
line-width=value
Définir la largeur des lignes des graphiques SVG.
paws=value
Définir le nombre de secondes d'inactivité avant que le graphique ne soit interrompu.
skipempty
Ne pas afficher les vues où tous les graphiques n'ont que des valeurs zéro.
showinfo
Afficher des informations supplémentaires (telles que la date et le nom d'hôte) sur chaque vue.
showtoc
Ajouter une table des matières au début de la sortie SVG, composée de liens pointant vers le premier graphique de chaque activité.
-o
Affiche les statistiques d'utilisation de la mémoire du processus.
-r
Affiche le contenu brut du fichier de données. Avec ce format, les valeurs de tous les compteurs sont affichées telles qu'elles sont lues depuis le noyau, ce qui signifie par exemple qu'aucune valeur moyenne n'est calculée sur l'intervalle de temps écoulé. La sortie peut être contrôlée à l'aide de l'option -O (voir ci-dessus).

L'option suivante peut être utilisée lors de la conversion d'un ancien fichier de données binaire d'activité système au format actuel à jour :

hz=valeur
Spécifie le nombre d'intermittences par seconde pour la machine où le fichier de données a été créé.
L'option suivante peut être utilisée lors de l'exportation de données vers une archive PCP :
pcparchive=nom
Spécifie le nom de l'archive PCP à créer.
L'option suivante est utilisée pour contrôler la sortie brute affichée par sadf -r :
debug
Affiche des informations supplémentaires, principalement utiles à des fins de débogage.
-P { liste_cpu | TOUT }
Indique à sadf que les statistiques dépendantes du processeur doivent être rapportées uniquement pour le ou les processeurs spécifiés. liste_cpu est une liste de valeurs séparées par des virgules ou des plages de valeurs (par exemple, 0,2,4-7,12-). Notez que le processeur 0 est le premier processeur, et le processeur TOUT est la moyenne globale entre tous les processeurs. Spécifier le mot-clé TOUT rapporte les statistiques pour chaque processeur individuel, et globalement pour tous les processeurs.
-p
Affiche le contenu du fichier de données dans un format qui peut être facilement traité par des commandes de traitement de motifs comme awk. La sortie se compose de champs séparés par une tabulation. Chaque enregistrement contient le nom d'hôte de la machine où le fichier a été créé, la valeur de l'intervalle (ou -1 si non applicable), l'horodatage, le nom de l'appareil (ou - si non applicable), le nom du champ et sa valeur. Notez que la sortie de l'horodatage peut être contrôlée par les options -T, -t et -U.
-s [ hh:mm[:ss] ]
-s [ secondes_depuis_epoch ]
Définit l'heure de début des données, amenant la commande sadf à extraire les enregistrements horodatés à l'heure spécifiée ou après. L'heure de début par défaut est 08:00:00. Les heures doivent être données au format 24 heures, ou comme le nombre de secondes depuis l'époque (donné sous forme d'un nombre à 10 chiffres).

-T
-t
-U
-V
-x

-T
Affiche l'horodatage en heure locale au lieu de UTC (Temps Universel Coordonné).
-t
Affiche l'horodatage en heure locale d'origine du créateur du fichier de données au lieu de UTC (Temps Universel Coordonné).
-U
Affiche l'horodatage (UTC - Temps Universel Coordonné) en secondes depuis l'époque.
-V
Affiche le numéro de version puis quitte.
-x
Affiche le contenu du fichier de données au format XML. Les horodatages peuvent être contrôlés par les options -T et -t. La DTD (Définition de Type de Document) correspondante et le schéma XML sont inclus dans le package source de sysstat. Ils sont également disponibles à l'adresse https://sysstat.github.io/.

ENVIRONNEMENT

La commande sadf prend en compte les variables d'environnement suivantes :

S_COLORS_PALETTE
Spécifie les couleurs utilisées par sadf -g pour rendre la sortie SVG. Cette variable d'environnement n'est prise en compte que lorsque la palette de couleurs personnalisée a été sélectionnée avec l'option customcol (voir l'option -O). Sa valeur est une liste de capacités séparées par des deux-points associées à des nombres hexadécimaux de six chiffres et trois octets (triplets hex) représentant les couleurs qui, par défaut, sont

0=000000:1=1a1aff:2=1affb2:3=b21aff:
4=1ab2ff:5=ff1a1a:6=ffb31a:7=b2ff1a:
8=efefef:9=000000:A=1a1aff:B=1affb2:
C=b21aff:D=1ab2ff:E=ff1a1a:F=ffb31a:
G=bebebe:H=000000:I=000000:K=ffffff:
L=000000:T=000000:W=000000:X=000000

Les capacités composées d'un chiffre hexadécimal (0 à F) sont utilisées pour spécifier les seize premières couleurs de la palette (ces couleurs sont utilisées pour dessiner les graphiques), par exemple, 3=ffffff indiquerait que la troisième couleur de la palette est blanche (0xffffff).
Les autres capacités sont :

G=
Spécifie la couleur utilisée pour dessiner les lignes de grille.
H=
Spécifie la couleur utilisée pour afficher l'en-tête du rapport.
I=
Spécifie la couleur utilisée pour afficher des informations supplémentaires (par exemple, date, nom d'hôte...).
K=
Spécifie la couleur utilisée pour l'arrière-plan des graphiques.
L=
Spécifie la couleur par défaut (qui est par exemple utilisée pour afficher la table des matières).
T=
Spécifie la couleur utilisée pour afficher le titre des graphiques.
W=
Spécifie la couleur utilisée pour afficher les messages d'avertissement et d'erreur.
X=
Spécifie la couleur utilisée pour dessiner les axes et afficher les graduations.
S_TIME_DEF_TIME
Si cette variable existe et que sa valeur est UTC, alors sadf utilisera l'heure UTC au lieu de l'heure locale pour déterminer le fichier de données quotidien actuel situé dans le répertoire /var/log/sa.

EXEMPLES

sadf -d /var/log/sa/sa21 -- -r -n DEV
Extraire les statistiques de mémoire et de réseau du fichier d'activité système sa21, et les afficher dans un format qui peut être ingéré par une base de données.
sadf -p -P 1
Extraire les statistiques du processeur pour le processeur 1 (le deuxième processeur) du fichier de données quotidien actuel, et les afficher dans un format qui peut être facilement traité par une commande de traitement de motifs.

BOGUES

La sortie SVG (telle que créée par l'option -g) est entièrement conforme à la norme SVG 1.1. Les graphiques ont été affichés avec succès dans divers navigateurs Web, y compris Firefox, Chrome et Opera. Cependant, le rendu SVG est défectueux sur les navigateurs Microsoft (testé sur Internet Explorer 11 et Edge 13.1) : veuillez donc ne pas les utiliser.

FICHIERS

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD

Les fichiers de données quotidiens standard d'activité système et leur emplacement par défaut. YYYY représente l'année en cours, MM le mois en cours et DD le jour en cours.
