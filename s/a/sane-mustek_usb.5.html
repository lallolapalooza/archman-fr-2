sane-mustek_usb(5) SANE Scanner Access Now Easy sane-mustek_usb(5)

NOM

sane-mustek_usb - Backend SANE pour scanners à plat USB Mustek

DESCRIPTION

La bibliothèque sane-mustek_usb implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat USB Mustek (y compris un clone de Trust). Actuellement, les scanners suivants sont connus pour fonctionner plus ou moins avec ce backend :

Mustek 600 CU
Mustek 1200 UB
Mustek 1200 CU
Mustek 1200 CU Plus
Trust Compact Scan USB 19200

Plus de détails peuvent être trouvés sur la page d'accueil du backend Mustek USB http://www.meier-geinitz.de/sane/mustek_usb-backend/.

Les scanners Mustek BearPaw 1200 et 2400 sont pris en charge par le backend plustek. Voir sane-plustek(5) pour les détails. Le Mustek BearPaw 1200F est pris en charge par le backend MA-1509. Voir sane-ma1509(5) pour les détails. Les autres scanners USB Mustek sont pris en charge par le backend gt68xx, voir sane-gt68xx(5).

Ce backend ne peut fonctionner qu'avec les scanners déjà détectés par le système d'exploitation. Voir sane-usb(5) pour les détails.

Si vous possédez un scanner Mustek (ou Trust) autre que ceux listés ci-dessus qui fonctionne avec ce backend, veuillez me le faire savoir en m'envoyant le nom exact du modèle du scanner et les identifiants vendeur et produit USB (par exemple, à partir de /proc/bus/usb/devices ou du syslog).

NOMS DES PÉRIPHÉRIQUES

Ce backend attend des noms de périphériques de la forme :

special

Où special est le chemin d'accès au périphérique spécial qui correspond à un scanner USB. Sous Linux, un tel nom de périphérique pourrait être /dev/usb/scanner0 ou /dev/usbscanner1, par exemple.

Pour FreeBSD, utilisez /dev/uscanner0.

CONFIGURATION

Le contenu du fichier mustek_usb.conf est une liste d'options et de noms de périphériques qui correspondent aux scanners USB Mustek. Les lignes vides et les lignes commençant par un signe dièse (#) sont ignorées. Si un nom de périphérique est placé dans mustek_usb.conf, il doit être suivi d'une ligne contenant le mot-clé option et une option spécifiant le type de scanner. Les options suivantes peuvent être utilisées : 600cu, 1200cu, 1200cu_plus, 1200ub. Pour le Trust Compact Scan USB 19200, utilisez `option 1200ub'.

Au lieu d'utiliser le nom du périphérique, le scanner peut être autodétecté par les instructions usb vendor_id product_id qui sont déjà incluses dans mustek_usb.conf. Ceci n'est pris en charge qu'avec Linux 2.4.8 et supérieur et tous les systèmes qui prennent en charge libusb. "vendor_id" et "product_id" sont des nombres hexadécimaux qui identifient le scanner. Si cela ne fonctionne pas, un nom de périphérique et l'option spécifiant le type de scanner doivent être placés dans mustek_usb.conf comme décrit ci-dessus.

L'option globale max_block_size peut être utilisée pour limiter la quantité de données acquise en un seul tour du système USB. Cela peut valoir la peine d'essayer en cas d'erreurs USB.

Un exemple de fichier de configuration est montré ci-dessous :

# Commentaire
option max_block_size 1024
usb 0x055f 0x0001
/dev/usb/scanner0
option 600cu

La première ligne est ignorée. La deuxième ligne définit la taille du tampon à un maximum de 1024 octets. La troisième ligne tente de détecter automatiquement un scanner avec l'identifiant vendeur 0x055f et l'identifiant produit 0x0001 (Mustek 1200 CU). La quatrième ligne indique au backend de se connecter à /dev/usb/scanner0 et la cinquième ligne spécifie que /dev/usb/scanner0 est un Mustek 600 CU.

FICHIERS

/etc/sane.d/mustek_usb.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-mustek_usb.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-mustek_usb.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux points (`:`), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_MUSTEK_USB
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie. 
Valeur  Description
0      aucune sortie
1      affichez les erreurs fatales
2      affichez les messages importants
3      affichez les erreurs non fatales et les messages moins importants
4      affichez tous les messages sauf ceux de débogage
5      affichez les messages de débogage de haut niveau
6      affichez les messages de débogage de niveau moyen
7      affichez les messages de débogage de bas niveau

Exemple : export SANE_DEBUG_MUSTEK_USB=4

BOGUES

Ces périphériques ont un défaut matériel : une fois que des données leur sont écrites, ils ne peuvent pas être réinitialisés (toggle = DATA0). Cela signifie que toute opération qui tente de réinitialiser le périphérique entraînera des temps morts.

Dans les versions antérieures, ce backend échouait lorsqu'il était chargé pour la deuxième fois dans certaines configurations. La seule option était de rebrancher le scanner dans ce cas. Le backend utilise maintenant une solution de contournement pour ce bogue, mais il n'est testé que sous Linux. Les rapports pour d'autres systèmes d'exploitation sont appréciés.

Des informations plus détaillées sur les bogues sont disponibles sur la page d'accueil du backend Mustek http://www.meier-geinitz.de/sane/mustek_usb-backend/.
