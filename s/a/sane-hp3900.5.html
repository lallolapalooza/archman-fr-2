sane-hp3900(5) SANE Scanner Access Now Easy sane-hp3900(5)

NOM

sane-hp3900 - Backend SANE pour scanners basés sur le chipset RTS8822

DESCRIPTION

La bibliothèque sane-hp3900 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès au moins aux scanners à plat USB suivants :

Modèle :                     Chipset :
------                     --------
HP ScanJet 3800            RTS8822BL-03A
HP ScanJet 3970            RTS8822L-01H
HP ScanJet 4070 Photosmart RTS8822L-01H
HP ScanJet 4370            RTS8822L-02A
HP ScanJet G2710           RTS8822BL-03A
HP ScanJet G3010           RTS8822L-02A
HP ScanJet G3110           RTS8822L-02A
UMAX Astra 4900/4950       RTS8822L-01H *
BenQ 5550                  RTS8823L-01E *

Plus de détails peuvent être trouvés sur la page d'accueil du backend sane-hp3900(5) : http://sourceforge.net/projects/hp3900-series/.

Ceci est un logiciel ALPHA. Gardez votre main sur la prise du scanner et débranchez-la si le scanner ne démarre pas le scan. Voir aussi la section BUGS.

Si vous possédez un scanner autre que ceux listés ci-dessus qui fonctionne avec ce backend, merci de nous en informer en envoyant le nom exact du modèle du scanner et les identifiants USB du vendeur et du produit (par exemple, depuis /proc/bus/usb/devices, sane-find-scanner(1) ou le syslog) . Même si le nom du scanner est seulement légèrement différent des modèles mentionnés ci-dessus, merci de nous en informer.

CONFIGURATION

Le contenu du fichier hp3900.conf est une liste de lignes usb contenant les identifiants du vendeur et du produit qui correspondent aux scanners USB. Le fichier peut également contenir les noms des fichiers périphériques qui correspondent à un scanner HP 39XX. Les lignes vides et celles commençant par un croisillon (#) sont ignorées. Les scanners sont autodétectés par les instructions usb vendor_id product_id qui sont déjà incluses dans hp3900.conf. "vendor_id" et "product_id" sont des nombres hexadécimaux qui identifient le scanner. Si l'autodétection ne fonctionne pas, ajoutez le nom du périphérique de votre scanner au fichier de configuration.

FICHIERS

/etc/sane.d/hp3900.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-hp3900.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-hp3900.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (` ;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (.) puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour résultat la recherche des répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_HP3900
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_HP3900=4

BOGUES

Le scan n'est testé qu'avec Linux/ix86/gcc. Soyez prudent lors des tests sur d'autres systèmes d'exploitation et en particulier sur les plateformes big-endian. Le scanner peut recevoir des données incorrectes.
