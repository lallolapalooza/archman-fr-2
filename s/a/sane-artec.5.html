NOM

sane-artec - Module d'extension SANE pour scanners à plat Artec

DESCRIPTION

La bibliothèque sane-artec implémente un module d'extension SANE (Scanner Access Now Easy) qui fournit l'accès aux scanners à plat SCSI Artec/Ultima. Actuellement, les scanners suivants sont connus pour fonctionner au moins partiellement avec ce module d'extension :

* Artec A6000C
* Artec A6000C PLUS
* Artec ViewStation AT3
* BlackWidow BW4800SP (rebadgé Artec AT3)
* Artec ViewStation AT6
* Artec ViewStation AT12
* Artec AM12S
* Plustek 19200S (rebadgé Artec AM12S)

Bien que cette page de manuel soit généralement mise à jour à chaque version, des informations à jour sur les nouvelles versions et des astuces supplémentaires utiles sont disponibles sur la page d'accueil du module d'extension : http://www4.infi.net/~cpinkham/sane.

CONFIGURATION

Le contenu du fichier artec.conf est une liste de noms de périphériques correspondant aux scanners Artec. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Voir sane-scsi(5) pour plus de détails sur ce qui constitue un nom de périphérique valide.

Exemple de fichier : 

# artec.conf
#
# ceci est un commentaire.
#
# cette ligne indique de rechercher tous les périphériques SCSI qui sont des scanners et ont
#     une chaîne de fournisseur ('vendor') de 'ULTIMA'
scsi ULTIMA
#
# la ligne suivante force le module d'extension à supposer que le prochain scanner trouvé a
#     la chaîne de fournisseur spécifiée (utile pour tester les modèles rebadgés).
vendor ULTIMA
#
# la ligne suivante force le module d'extension à supposer que le prochain scanner trouvé a
#     la chaîne de modèle spécifiée (utile pour tester les modèles rebadgés).
model AT3
#
# maintenant une ligne qui spécifie réellement un périphérique. Le module d'extension va
#     supposer qu'il s'agit d'un Artec/Ultima AT3 car nous avons forcé le fournisseur et le
#     modèle ci-dessus.
/dev/scanner
#
# une fois que nous atteignons une ligne de périphérique scanner, la chaîne de fournisseur et de modèle forcée est
#     'oubliée', donc le fournisseur et le modèle pour ce prochain périphérique seront
#     déterminés à partir du résultat d'une interrogation SCSI.
/dev/sge
#

CONSEILS ADAPTATEUR SCSI

Certains scanners Artec sont livrés avec un adaptateur SCSI inclus. Si votre scanner est livré avec des cartes SCSI ISA DTC, vous pouvez probablement les utiliser avec des noyaux récents (>= 2.2.0) en utilisant le support générique NCR5380. Vous devez passer l'argument de démarrage suivant au noyau : "dtc3181e=0x2c0,0"
Je n'ai aucune information sur l'adaptateur SCSI PCI inclus avec certains scanners Artec plus récents.

FICHIERS

/etc/sane.d/artec.conf
Le fichier de configuration du module d'extension (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-artec.a
La bibliothèque statique implémentant ce module d'extension.
/usr/lib/sane/libsane-artec.so
La bibliothèque partagée implémentant ce module d'extension (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires spécifiés explicitement. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_ARTEC
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce module d'extension. Par exemple, une valeur de 128 demande à ce que toutes les sorties de débogage soient imprimées. Des niveaux inférieurs réduisent la verbosité : SANE_DEBUG_ARTEC valeurs : 
Nombre  Remarque
 0       imprime les erreurs importantes
 1       imprime les erreurs
 2       imprime les sens (sense)
 3       imprime les avertissements
 4       imprime l'interrogation du scanner
 5       imprime les informations
 6       imprime les informations moins importantes
 7       imprime les procédures principales appelées
 8       imprime toutes les procédures appelées
 9       imprime les messages d'information/données de procédure
 10      imprime les routines d'initialisation sane appelées
 11      imprime les procédures sane appelées
 12      imprime les informations sane
 13      imprime les messages de contrôle des options sane
 50      imprime les messages de données/débogage verbaux
 == 100  imprime les données de calibration RGB logicielles
 == 101  imprime les données brutes du scanner dans le fichier artec.data.raw
 == 128  imprime tous les messages

Exemple : export SANE_DEBUG_ARTEC=13

BOGUES

Bogues connus dans cette version : les utilisateurs de A6000C+ avec le firmware v1.92 ou antérieur ont des problèmes avec le module d'extension, la cause n'a pas été déterminée. Parfois, le module d'extension n'est pas particulièrement robuste, vous pouvez potentiellement bloquer le bus SCSI (et/ou la machine) en manquant de patience lors de la numérisation. La correction gamma à 3 canaux n'est pas implémentée et la correction gamma à canal unique ne fonctionne pas totalement sur les modèles autres que l'AT3.
