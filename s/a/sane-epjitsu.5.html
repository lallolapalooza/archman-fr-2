NOM

sane-epjitsu - Backend SANE pour les scanners Fujitsu USB basés sur Epson

DESCRIPTION

La bibliothèque sane-epjitsu implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès basique aux scanners Fujitsu fi-60F/fi-65F et ScanSnap S300/S1300(i)/S1100(i).

PRISE EN CHARGE DU MATÉRIEL

Ces scanners sont assez limités, ne supportant que quelques modes et résolutions, et scannant toujours en pleine largeur. Le backend prend en charge les modes manquants (binaire, niveaux de gris) et les résolutions intermédiaires par logiciel, mais ne fournit que des contrôles d'aire de scan minimaux. Voir PROBLÈMES CONNUS.

Ce backend peut prendre en charge d'autres scanners. Si une inspection physique révèle un chipset Epson, veuillez contacter l'auteur pour obtenir des instructions sur la collecte d'une trace USB sous Windows pour vérification.

OPTIONS

Un effort limité a été fait pour exposer les options standard à l'API. Cela permet à un frontend de définir la résolution, le mode couleur et de choisir le paramètre ADF. Le backend sane-epjitsu prend en charge les options de base suivantes pour la plupart des scanners :

source s

Sélectionne la source du scan. Les options peuvent inclure "Flatbed", "ADF Front", "ADF Back", "ADF Duplex".

mode m

Sélectionne le mode du scan. Les options peuvent inclure "Lineart", "Gray", "Color".

resolution, y-resolution

Contrôle la résolution du scan. La définition de --resolution définit également --y-resolution, bien que ce comportement soit remplacé par certains frontends.

D'autres options seront disponibles en fonction des capacités du scanner. Utilisez 'scanimage --help' pour obtenir une liste. Sachez que certaines options peuvent n'apparaître que lorsqu'une autre option a été définie, et que les options avancées peuvent être masquées par le frontend.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/epjitsu.conf est utilisé pour indiquer au backend comment rechercher des scanners et fournir des options contrôlant le fonctionnement du backend. Ce fichier est lu chaque fois que le frontend demande au backend une liste de scanners, généralement uniquement au démarrage du frontend. Si le fichier de configuration est manquant, le backend ne fonctionnera pas.

Les scanners peuvent être spécifiés dans le fichier de configuration de deux manières :

"usb 0x04c5 0x10c7" (ou d'autres identifiants fournisseur/produit)

Demande au backend de rechercher dans tous les bus USB du système un appareil utilisant cet identifiant fournisseur et produit. L'appareil sera ensuite interrogé pour déterminer s'il s'agit d'un scanner pris en charge.

"usb /dev/usb/scanner0" (ou autre fichier périphérique)

Certains systèmes utilisent un pilote noyau pour accéder aux scanners USB. Cette méthode n'est pas testée.

La seule option de configuration prise en charge est "firmware /CHEMIN/VERS/FICHIER", vous permettant de définir l'emplacement du fichier de firmware que vous avez extrait du pilote Windows.

Note : Ce firmware est une œuvre protégée par le droit d'auteur de Fujitsu, il ne peut donc pas être fourni par le backend ou l'auteur. Veuillez ne pas demander.

Note : Ces scanners NÉCESSITENT un fichier de firmware pour fonctionner. Voir le fichier de configuration fourni pour plus de détails.

Note : Cette option peut apparaître plusieurs fois dans le fichier de configuration. Elle ne s'applique qu'aux scanners découverts par les lignes 'usb' qui suivent cette option.

ENVIRONNEMENT

Le backend utilise une seule variable d'environnement, SANE_DEBUG_EPJITSU, qui active la sortie de débogage sur stderr. Les valeurs valides sont :

5 Erreurs
10 Trace des fonctions
15 Détail des fonctions
20 Commandes d'options
25 Trace USB
30 Détail USB
35 Bruit inutile

PROBLÈMES CONNUS

Seules des options limitées pour la zone de scan sont exposées.
Le mode niveaux de gris matériel des fi-60F et fi-65F n'est pas utilisé, car le code d'étalonnage n'est pas terminé.

CRÉDITS

Support fi-60F financé par TrueCheck, Inc.
