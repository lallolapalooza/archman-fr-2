sous-routine saxpy (integer n, real sa, real, dimension(*) sx, integer incx, real, dimension(*) sy, integer incy)

SAXPY

Objectif :

!>
!>    SAXPY une constante fois un vecteur plus un vecteur.
!>    utilise des boucles déroulées pour des incréments égaux à un.
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

SA

!>          SA est un REEL
!>           À l'entrée, SA spécifie le scalaire alpha.
!>

SX

!>          SX est un tableau REEL, de dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un ENTIER
!>         espacement de stockage entre les éléments de SX
!>

SY

!>          SY est un tableau REEL, de dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est un ENTIER
!>         espacement de stockage entre les éléments de SY
!>
