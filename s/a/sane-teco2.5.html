sane-teco2(5) SANE Scanner Access Now Easy sane-teco2(5)

NOM

sane-teco2 - Backend SANE pour scanners TECO / RELISYS

DESCRIPTION

La bibliothèque sane-teco2 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à certains scanners à plat SCSI TECO. Ce backend doit être considéré comme un logiciel de qualité bêta ! Les scanners TECO sont vendus sous diverses marques comme Mustek, Relisys, Piotech, Primax, TRUST. Ce backend peut ou non supporter le vôtre.

Les scanners qui devraient fonctionner avec ce backend sont :

   Vendeur   Modèle                 Modèle TECO    statut
--------------------------- --------------  -----------
  Mustek ScanMagic 4830S      VM3575         non testé
  Primax Jewel 4800           VM356A         bon
  Primax Profi 9600           VM6575         basique
  Primax Profi 19200          VM6586         bon
  Relisys APOLLO Express 3    VM356A         basique
  Relisys APOLLO Express 6    VM6565         bon
  Relisys APOLLO Express 12   ?              non testé
  Relisys AVEC II S3          VM3564         bon
  Relisys AVEC Super 3        VM3575         basique
  Relisys SCORPIO Pro         VM6575         bon
  Relisys SCORPIO Pro-S       VM6586         non testé
  Relisys SCORPIO Super 3     VM3575         bon

Pour tous ces scanners, les modes ligne art et niveaux de gris fonctionnent bien. Cependant, la plupart d'entre eux ne supportent qu'un petit nombre de résolutions en mode couleur. Voir la page d'accueil du backend (sous AUTEUR) pour le statut exact de chaque scanner.

Notez que les scanners non testés ne seront pas directement pris en charge. Vous devriez contacter l'auteur pour cela.

Le numéro TECO VM se trouve généralement au dos du scanner. Il fait également partie de l'identifiant FCC.

Les options que le backend prend en charge peuvent être sélectionnées soit via des options en ligne de commande pour des programmes comme scanimage(1), soit via des éléments d'interface graphique dans xscanimage(1), xsane(1), quiteinsane(1) ou kooka(1).

Si vous avez du succès avec un scanner non listé ici, ou si vous remarquez un comportement étrange, veuillez le signaler au mainteneur du backend ou à la liste de diffusion SANE.

OPTIONS

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant :

scanimage --help -d teco2
Mode de balayage
--mode Lineart|Gray|Color
sélectionne le mode de fonctionnement de base du scanner. Le mode Lineart est uniquement noir et blanc (1 bit). Le mode Gray produira 256 niveaux de gris (8 bits). Le mode Color produira une image couleur 24 bits.
--resolution 1..600
Sélectionne la résolution pour un balayage. Le scanner peut gérer toutes les résolutions entre 1 et 600, par incréments de 1, pour Lineart et Gray. Pour Color, un ensemble limité de résolutions est disponible.

Note : Toutes les valeurs avec une résolution verticale en dpi > 300 (300 x 600) ou 600 (600 x 1200) entraînent une mauvaise proportion pour le balayage. La proportion peut être ajustée avec la commande convert(1) suivante d'imagemagick :
convert -geometry (dpi/max_xdpi * 100%)x100%
max_xdpi est pour la constante VM3575 avec 300 dpi, par exemple, 600dpi ajustez avec : convert -geometry 200%x100%

--preview
demande un balayage de prévisualisation. La résolution utilisée pour ce balayage est de 50 dpi (pour VM356A et VM6575, 75 dpi) et la zone de balayage est la zone maximale autorisée. Le mode de balayage est sélectionné par l'utilisateur. La valeur par défaut est « non ».
Options de géométrie
-l, -t, -x, -y
Contrôle la zone de balayage : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de balayage. Tous les paramètres sont spécifiés en millimètres par défaut.
Options d'amélioration
--custom-gamma (pas d'option gamma personnalisée pour VM3564 et VM356A)
(mode couleur uniquement) permet à l'utilisateur de spécifier une table gamma (voir les 3 paramètres suivants).

OPTIONS POUR LE MODE COULEUR

Ces options sont valides uniquement pour le mode de balayage Color.

--red-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal rouge. La table doit faire 256 octets de long.
--green-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal vert. La table doit faire 256 octets de long.
--blue-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal bleu. La table doit faire 256 octets de long.

OPTIONS UNIQUEMENT POUR VM3564, VM356A, VM3575 et VM6575

Ces options ne sont disponibles que pour les modèles VM3564, VM356A, VM3575 et VM6575.

--white-level-r 0..64
Sélectionne quel niveau de radiance rouge doit être considéré comme « blanc », lors du balayage de certaines feuilles en changeant la valeur de calibrage chargée dans le scanner. Échelle 0..64 par pas de 1.
--white-level-g 0..64
Sélectionne quel niveau de radiance vert doit être considéré comme « blanc », lors du balayage de certaines feuilles en changeant la valeur de calibrage chargée dans le scanner. Échelle 0..64 par pas de 1.
--white-level-b 0..64
Sélectionne quel niveau de radiance bleu doit être considéré comme « blanc », lors du balayage de certaines feuilles en changeant la valeur de calibrage chargée dans le scanner. Échelle 0..64 par pas de 1.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/teco2.conf ne prend en charge qu'un seul élément : le nom du périphérique à utiliser (par ex. /dev/scanner).

FICHIERS

/usr/lib/sane/libsane-teco2.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-teco2.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_TECO2
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux inférieurs réduisent la verbosité.
SANE_TECO2_CAL_ALGO
Soit 0, soit 1. Sélectionne l'algorithme pour le calibrage. Une valeur de 1 semble donner de meilleurs numérisations sur les VM356A, VM3575. Les retours à ce sujet sont les bienvenus. Pour VM3564, VM356A, VM3575, VM6575, la valeur par défaut est 1. Pour les autres types pris en charge, la valeur par défaut est 0.

LIMITATIONS

Le pilote TWAIN pour Windows dispose de nombreuses options supplémentaires par rapport à ce backend SANE. Cependant, ce ne sont que des ajustements logiciels. Ce backend n'implémente que ce que le scanner peut supporter.

BOGUES

Beaucoup. Certaines parties de ce backend sont encore en cours de développement.
