SAMBA-LOG-PARSER(1) Commandes utilisateur SAMBA-LOG-PARSER(1)

NOM

samba-log-parser - Analyseur de traces Samba (winbind).

options :
-h, --help afficher ce message d'aide et quitter
--traceid ID spécifier l'ID de trace des enregistrements de trace
--pid PID spécifier le PID du client winbind
--breakdown décomposer les traces en fichiers par ID de trace
--merge-by-timestamp fusionner les journaux par horodatage
--flow afficher les traces du flux de requêtes/sous-requêtes
--flow-compact afficher les traces du flux de requêtes/sous-requêtes sans détails dcerpc

SYNTAXE

samba-log-parser {chemin} [--pid=PID] [--traceid=ID] [--breakdown] [--merge-by-timestamp] [--flow] [--flow-compact] [-h|--help]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

Le programme samba-log-parser analyse les journaux samba winbind.

OPTIONS

Les options suivantes sont disponibles pour le programme samba-log-parser.

--pid=PID

Affiche les traces pour le client winbind avec le PID correspondant.

--traceid=ID

Affiche les traces avec le champ d'en-tête de débogage de l'ID de trace correspondant.

--breakdown

Décompose toutes les traces en fichiers séparés dans le répertoire de travail actuel. Pour chaque ID de trace, trois fichiers sont créés : traceid.full traceid.flow traceid.flowcompact

--merge-by-timestamp

Trie les lignes de trace en fonction de l'horodatage. Fonctionne également avec les fichiers journaux sans en-tête d'ID de trace.

--flow

Affiche le flux de requêtes/sous-requêtes.

--flow-compact

Affiche le flux de requêtes/sous-requêtes sans les détails des appels dcerpc.

EXEMPLES

Afficher les traces de flux pour l'ID de trace 1234 du fichier journal log.winbind :

# samba-log-parser --traceid 1234 --flow /var/log/samba/log.winbind

Afficher toutes les traces pour le client winbind avec le PID 999999 triées par horodatage pour les fichiers journaux trouvés dans le répertoire de journaux samba :

# samba-log-parser --pid 999999 --merge-by-timestamp /var/log/samba

Décomposer les traces en fichiers séparés selon l'ID de trace, triées par horodatage pour les fichiers journaux trouvés dans le répertoire de journaux samba :

# samba-log-parser --breakdown --merge-by-timestamp /var/log/samba

Trier les traces en utilisant l'horodatage pour les fichiers journaux trouvés dans le répertoire de journaux samba. Les traces n'ont pas besoin de contenir le champ d'en-tête de l'ID de trace.

# samba-log-parser --merge-by-timestamp /var/log/samba
