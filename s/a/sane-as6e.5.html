sane-as6e(5) SANE Scanner Access Now Easy sane-as6e(5)

NOM

sane-as6e - Backend SANE pour l'utilisation du scanner Artec AS6E à port parallèle.

DESCRIPTION

La bibliothèque sane-as6e implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès au scanner à plat Artec AS6E. Elle nécessite le programme as6edriver pour fonctionner. Le programme as6edriver n'est pas inclus dans le paquet SANE. Il peut être trouvé à http://as6edriver.sourceforge.net. Voir la documentation d'as6edriver pour des informations techniques.

Le programme as6edriver doit être dans le chemin des exécutables ($PATH). Particulièrement si vous lancez saned(8) (le démon de numérisation réseau SANE), prenez soin de configurer correctement le chemin pour inetd(8) ou xinetd(8) ou placez le programme dans un répertoire qui fait partie du chemin.

FICHIERS

as6edriver - programme pilote qui contrôle le scanner.

VOIR AUSSI

sane(7), as6edriver(5), saned(8), inetd(8), xinetd(8)
http://as6edriver.sourceforge.net
