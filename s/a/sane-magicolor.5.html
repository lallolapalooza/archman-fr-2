NOM

sane-magicolor - Backend SANE pour les scanners KONICA MINOLTA magicolor et Toshiba TEC e-STUDIO

DESCRIPTION

Le backend sane-magicolor prend en charge les scanners KONICA MINOLTA magicolor et Toshiba TEC e-STUDIO connectés via USB ou LAN.

PÉRIPHÉRIQUES SUPPORTÉS

Les scanners suivants devraient fonctionner avec ce backend :

Détails du périphérique
-----------------------------
Vendeur : KONICA MINOLTA
Modèle : magicolor 1690MF
Vendeur : Toshiba TEC
Modèle : e-STUDIO2323AM

CONFIGURATION

Cette section décrit les entrées du fichier de configuration du backend. Le fichier est situé à :

/etc/sane.d/magicolor.conf

Pour une configuration correcte, au moins une des entrées suivantes est nécessaire :

net autodiscovery
net [ADRESSE IP] [ID_PÉRIPHÉRIQUE]
usb
usb [ID_VENDEUR] [ID_PÉRIPHÉRIQUE]

FICHIERS

/etc/sane.d/magicolor.conf
Le fichier de configuration du backend
/usr/lib/sane/libsane-magicolor.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-magicolor.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires spécifiés explicitement. Par exemple, définir SANE_CONFIG_DIR sur "/tmp/config:" aurait pour conséquence la recherche dans les répertoires /tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_DEBUG_MAGICOLOR
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_MAGICOLOR=127

Pour obtenir des messages de débogage du backend, définissez cette variable d'environnement avant d'appeler votre frontend préféré (par exemple, xscanimage(1)).

Exemple : SANE_DEBUG_MAGICOLOR=65 xscanimage

BOGUES CONNUS ET RESTRICTIONS

Les numérisations couleur volumineuses peuvent parfois expirer pour des raisons inconnues (le scanner cesse simplement de renvoyer des données).

L'annulation de numérisations volumineuses peut bloquer le scanner.
