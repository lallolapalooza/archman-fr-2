sane-teco3(5) SANE Scanner Access Now Easy sane-teco3(5)

NOM

sane-teco3 - Backend SANE pour scanners TECO / RELISYS

DESCRIPTION

La bibliothèque sane-teco3 implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès à certains scanners à plat SCSI TECO. Ce backend doit être considéré comme un logiciel de qualité alpha ! Les scanners TECO sont vendus sous diverses marques comme RELYSIS, PIOTECH, TRUST. Ce backend peut ou peut ne pas supporter le vôtre.

Les scanners qui devraient fonctionner avec ce backend sont :

  Fabricant Modèle           Modèle TECO   statut
  ---------------------------  ----------  ----------
  Relisys Scorpio                VM3552     testé
  Plustek OpticPro 2400SP        VM3552     non testé
  PIOTECH Splendeur 3024         VM3552     testé
  Trust Imagery 2400 SP          VM3552     testé
  Trust Imagery 4800 SP+         VM3552     testé
  Trust Imagery 9600 SP          VM3552     non testé

Le numéro VM de TECO se trouve généralement à l'arrière du scanner. Il fait également partie de l'identifiant FCC.

Les options prises en charge par le backend peuvent être sélectionnées soit via les options de ligne de commande des programmes comme scanimage(1), soit via les éléments de l'interface graphique dans xscanimage(1) ou xsane(1).

Si vous avez du succès avec un scanner non listé ici, ou si vous remarquez un comportement étrange, veuillez en informer le mainteneur du backend ou la liste de diffusion SANE.

OPTIONS

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant :

scanimage --help -d teco3
Mode de numérisation
--mode Noir & Blanc|Niveaux de gris|Couleur
Sélectionne le mode de fonctionnement de base du scanner. Le mode Noir & Blanc est uniquement en noir et blanc (1 bit). Niveaux de gris produira 256 niveaux de gris (8 bits). Couleur produira une image couleur de 24 bits.
--resolution 1..1200
Sélectionne la résolution pour une numérisation. Le scanner peut gérer toutes les résolutions comprises entre 1 et 1200, par incréments de 1.
--preview
Demande une numérisation d'aperçu. La résolution utilisée pour cette numérisation est de 22 dpi et la zone de numérisation est le maximum autorisé. Le mode de numérisation est sélectionné par l'utilisateur. La valeur par défaut est « non ».
Options de géométrie
-l -t -x -y
Contrôle la zone de numérisation : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de numérisation. Tous les paramètres sont spécifiés en millimètres par défaut.

OPTIONS POUR LE MODE COULEUR SEULEMENT

--custom-gamma
Permet à l'utilisateur de spécifier une table gamma (voir les 3 paramètres suivants).
--red-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal rouge. La table doit avoir une longueur de 1024 octets.
--green-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal vert. La table doit avoir une longueur de 1024 octets.
--blue-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal bleu. La table doit avoir une longueur de 1024 octets.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/teco3.conf ne prend en charge qu'un seul élément : le nom du périphérique à utiliser (par exemple /dev/scanner).

FICHIERS

/usr/lib/sane/libsane-teco3.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-teco3.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_TECO3
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux inférieurs réduisent la verbosité.

LIMITATIONS

Le pilote TWAIN pour Windows possède de nombreuses options supplémentaires par rapport à ce backend SANE. Cependant, ce ne sont que des ajustements logiciels. Ce backend n'implémente que ce que le scanner peut supporter.

BOGUES

Pas grand-chose.
