NAME

sane-hp3500 - Backend SANE pour les scanners Hewlett-Packard série ScanJet 3500

DESCRIPTION

La bibliothèque sane-hp3500 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat USB Hewlett-Packard suivants :

ScanJet 3500C
ScanJet 3530C
ScanJet 3570C

Si vous possédez un scanner autre que ceux listés ci-dessus qui fonctionne avec ce backend, veuillez nous en informer en nous envoyant le nom de modèle exact du scanner ainsi que les identifiants vendeur et produit USB (par exemple, depuis /proc/bus/usb/devices, sane-find-scanner(1) ou le syslog). Même si le nom du scanner est légèrement différent des modèles mentionnés ci-dessus, veuillez nous en informer.

CONFIGURATION

Aucune requise.

FICHIERS

/usr/lib/sane/libsane-hp3500.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-hp3500.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_HP3500 Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verborosité de la sortie.

Exemple : export SANE_DEBUG_HP3500=4

VOIR AUSSI

sane(7), sane-usb(5),
http://projects.troy.rollo.name/rt-scanners/
