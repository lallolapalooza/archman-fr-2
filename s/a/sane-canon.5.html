sane-canon(5) SANE Scanner Access Now Easy sane-canon(5)

NOM

sane-canon - Backend SANE pour scanners SCSI Canon

DESCRIPTION

La bibliothèque sane-canon implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès aux scanners à plat et scanners de films Canon suivants :

CanoScan 300
CanoScan 600
CanoScan FB620S
CanoScan FB1200S
CanoScan FS2700F
CanoScan FS2710S

Les scanners à port parallèle et USB ne sont pas supportés par ce backend ; voir les pages man de sane-canon_pp(5) et sane-canon630u(5) pour plus d'informations.

IMPORTANT : Ceci est du code bêta. Nous avons testé le code sur les scanners listés ci-dessus, en utilisant les ordinateurs et les systèmes d'exploitation à notre disposition, mais nous ne pouvons garantir que le backend fonctionnera sans problème avec les futurs systèmes d'exploitation, adaptateurs SCSI, programmes frontaux SANE, ou scanners Canon non contenus dans la liste ci-dessus. Dans certains cas, votre ordinateur pourrait même planter. Il ne peut être exclu (bien que nous le considérions comme extrêmement improbable) que votre scanner soit endommagé.

Cela dit, LES TESTEURS SONT BIENVENUS. Envoyez vos rapports de bug et vos commentaires à Manuel Panea <mpd@rzg.mpg.de> ; pour les questions concernant les FB620 et FB1200S contactez Mitsuru Okaniwa <m-okaniwa@bea.hi-ho.ne.jp>, pour le FS2710S Ulrich Deiters <ukd@xenon.pc.uni-koeln.de>.

CONSEILS (FS2700F)

Pour la numérisation de diapositives ou de négatifs, des corrections de gamma plutôt importantes d'environ 2,2 à 2,4 (même valeur pour le rouge, le vert et le bleu) ont été trouvées nécessaires. Il est recommandé d'utiliser les contrôles d'exposition automatique du frontal xsane(1) pour de meilleurs résultats.

La fonction "Mise au point automatique" déclenche un passage spécial pour déterminer la valeur de mise au point. Ensuite, le passage de numérisation réel a lieu.

Même avec la "Mise au point automatique" activée, l'image numérisée est souvent un peu trop floue. L'utilisation de gimp(1) pour effectuer un "Filtre->Améliorer->Netteté" à environ 40 à 60 améliore considérablement l'image.

CONSEILS (FS2710S)

Les corrections de gamma sont effectuées non pas par le scanner, mais par le backend. Le scanner est toujours exécuté en mode 12 bits. En mode "couleur", les données de l'image sont corrigées en gamma, point d'ombre, etc., puis tronquées à des intensités de 8 bits ; la valeur de gamma par défaut est de 2,0. En mode "brut", les données de l'image sont exportées sans corrections sous forme d'intensités de 16 bits ; ce mode peut être recommandé si des ajustements importants doivent être apportés à une image (et si le frontal peut gérer des intensités de 16 bits).

Les négatifs sont gérés par une simple inversion des couleurs et nécessiteront une suppression manuelle de la dominante bleutée.

FICHIERS

/usr/lib/sane/libsane-canon.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-canon.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_CANON
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_CANON=4
