sane-canon_lide70(5) SANE Scanner Access Now Easy sane-canon_lide70(5)

NOM

sane-canon_lide70 - Backend SANE pour les scanners USB à plat Canon LiDE 70 et 600(F)

DESCRIPTION

La bibliothèque canon_lide70 met en œuvre un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat USB de Canon Inc. CanoScan LiDE 70 et 600(F). L'unité de film du LiDE 600F n'est pas prise en charge.

En raison du refus de Canon de fournir la documentation du scanner, ce logiciel a été développé en analysant le trafic USB du pilote Windows XP. Le sens précis des commandes individuelles envoyées au scanner n'est connu que dans une très mesure limitée. Une certaine sophistication présente dans le pilote Windows XP a été omise. Il n'y a, par exemple, aucune calibration active.

Les testeurs et les critiques sont les bienvenus. Envoyez vos rapports de bugs et commentaires à la liste de diffusion sane-devel <sane-devel@alioth-lists.debian.net>.

CONFIGURATION

Le fichier /etc/sane.d/canon_lide70.conf identifie le LiDE 70 par son code vendeur 0x04a9 et son code produit 0x2225. Pour le LiDE 600(f), le code produit est 0x2224.

OPTIONS SPÉCIFIQUES AU BACKEND

Mode de numérisation :

--resolution 75|150|300|600|1200 [par défaut 600]
Définit la résolution de l'image numérisée en points par pouce. La numérisation à 1200 dpi n'est pas disponible sur le LiDE 600(F) et elle est très lente sur le LiDE 70.
--mode Couleur|Niveaux de gris|Image monochrome [par défaut : Couleur]
Sélectionne le mode de numérisation. L'image monochrome signifie uniquement des pixels entièrement noirs et entièrement blancs.
--seuil 0..100 (par pas de 1) [par défaut 75]
Sélectionne le pourcentage minimum de luminosité pour obtenir un point blanc, pertinent uniquement pour l'image monochrome.
--non-bloquant[=(oui|non)] [inactif]
Cette option n'a pas encore été implémentée. Les numérisations sont capturées dans un fichier temporaire d'une taille typique de 100 Mo.

Géométrie :

-l 0..216.069 [par défaut 0]
Position X du coin supérieur gauche de la zone de numérisation en millimètres.
-t 0..297 [par défaut 0]
Position Y du coin supérieur gauche de la zone de numérisation en millimètres.
-x 0..216.069 [par défaut 80]
Largeur de la zone de numérisation en millimètres.
-y 0..297 [par défaut 100]
Hauteur de la zone de numérisation en millimètres.

FICHIERS

/etc/sane.d/canon_lide70.conf
Le fichier de configuration du backend.
/usr/lib/sane/libsane-canon_lide70.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-canon_lide70.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_CANON_LIDE70
Si la bibliothèque a été compilée avec la prise en charge du débogage activée, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verborité de la sortie.

Exemple :
SANE_DEBUG_CANON_LIDE70=128 scanimage > /dev/null

PROBLÈMES CONNUS

À basse résolution (75 et 150 dpi, impliquant des vitesses de glissière élevées), le LiDE 70 manque le millimètre supérieur de la zone de numérisation. Cela peut être remédié en décalant le document d'un millimètre vers le bas, dans les cas où une telle précision est importante. Notez que xsane(1) utilise le mode 75 dpi pour les prescans. Le problème est plus grave sur le LiDE 600(F), où le décalage est de cinq millimètres.
