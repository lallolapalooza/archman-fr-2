saquery(8) Diagnostics Open IB saquery(8)

Nom

saquery - interroger les attributs d'administration de sous-réseau InfiniBand

Syntaxe

saquery [options] [<nom> | <lid> | <guid>]

Description

saquery émet la requête SA sélectionnée. Les enregistrements de nœuds sont interrogés par défaut.

Options

-p
obtenir des informations sur PathRecord
-N
obtenir des informations sur NodeRecord
-D, --list
obtenir uniquement les descriptions de nœuds des CA
-S
obtenir des informations sur ServiceRecord
-I
obtenir des informations sur InformInfoRecord (abonnement)
-L
retourner les LIDs du nom spécifié
-l
retourner le LID unique du nom spécifié
-G
retourner les GUIDs du nom spécifié
-O
retourner le nom pour le LID spécifié
-U
retourner le nom pour le GUID spécifié
-c
obtenir des informations sur le port de classe du SA
-s
retourner les PortInfoRecords avec le masque de capacité isSM ou isSMdisabled activé
-g
obtenir des informations sur les groupes multicast
-m
obtenir des informations sur les membres multicast. Si un groupe est spécifié, limitez la sortie au groupe spécifié et affichez une seule ligne contenant uniquement le GUID et la description du nœud pour chaque entrée. Exemple : saquery -m 0xc000
-x
obtenir des informations sur LinkRecord
--src-to-dst <src:dst>
obtenir un PathRecord pour <src:dst> où src et dst sont des noms de nœuds ou des LIDs
--sgid-to-dgid <sgid:dgid>
obtenir un PathRecord de sgid à dgid où les deux GIDs sont au format IPv6 acceptable par inet_pton (3)
--smkey <val>
utiliser la valeur SM_Key pour la requête. Sera utilisée uniquement avec les requêtes « de confiance ». Si une valeur non numérique (comme 'x') est spécifiée, saquery demandera une valeur. La valeur par défaut (lorsqu'elle n'est pas spécifiée ici ou dans /etc/infiniband-diags/ibdiag.conf) est d'utiliser SM_Key == 0 (ou « non fiable »)
-K, --show_keys
afficher les clés de sécurité (mkey, smkey, etc.) associées à la demande.

--slid <lid> LID source (PathRecord)

--dlid <lid> LID destination (PathRecord)

--mlid <lid> LID multicast (MCMemberRecord)

--sgid <gid> GID source (format IPv6) (PathRecord)

--dgid <gid> GID destination (format IPv6) (PathRecord)

--gid <gid> GID de port (MCMemberRecord)

--mgid <gid> GID multicast (MCMemberRecord)

--reversible Chemin réversible (PathRecord)

--numb_path Nombre de chemins (PathRecord)

--pkey P_Key (PathRecord, MCMemberRecord). Si une valeur non numérique (comme 'x')
est spécifiée, saquery demandera une valeur

--qos_class Classe QoS (PathRecord)

--sl Niveau de service (PathRecord, MCMemberRecord)

--mtu MTU et sélecteur (PathRecord, MCMemberRecord)

--rate Débit et sélecteur (PathRecord, MCMemberRecord)

--pkt_lifetime Durée de vie du paquet et sélecteur (PathRecord, MCMemberRecord)

--qkey Q_Key (MCMemberRecord). Si une valeur non numérique (comme 'x') est spécifiée
saquery demandera une valeur

--tclass Classe de trafic (PathRecord, MCMemberRecord)

--flow_label Label de flux (PathRecord, MCMemberRecord)

--hop_limit Limite de sauts (PathRecord, MCMemberRecord)

--scope Portée (MCMemberRecord)

--join_state État de jointure (MCMemberRecord)

--proxy_join Jointure proxy (MCMemberRecord)

--service_id ServiceID (PathRecord)

Noms de requêtes pris en charge (et alias) :

ClassPortInfo (CPI)
NodeRecord (NR) [lid]
PortInfoRecord (PIR) [[lid]/[port]/[options]]
SL2VLTableRecord (SL2VL) [[lid]/[in_port]/[out_port]]
PKeyTableRecord (PKTR) [[lid]/[port]/[block]]
VLArbitrationTableRecord (VLAR) [[lid]/[port]/[block]]
InformInfoRecord (IIR)
LinkRecord (LR) [[from_lid]/[from_port]] [[to_lid]/[to_port]]
ServiceRecord (SR)
PathRecord (PR)
MCMemberRecord (MCMR)
LFTRecord (LFTR) [[lid]/[block]]
MFTRecord (MFTR) [[mlid]/[position]/[block]]
GUIDInfoRecord (GIR) [[lid]/[block]]
SwitchInfoRecord (SWIR) [lid]
SMInfoRecord (SMIR) [lid]

Flags de sélection de port

-C, --Ca <ca_name> utiliser le ca_name spécifié.

-P, --Port <ca_port> utiliser le ca_port spécifié.

Sélection du port local

Support multi-port/multi-CA : lorsqu'aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port ACTIF.
2.
si non trouvé, le premier port ACTIF (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de répondre à la demande de l'utilisateur et échouera si cela n'est pas possible.

Par exemple :

ibaddr                 # utiliser le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port uniquement parmi « mthca1 ».
ibaddr -P 2            # utiliser le deuxième port (actif/haut) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser uniquement le port spécifié.

Flags de débogage

-d
augmenter le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
afficher les erreurs d'envoi et de réception (timeouts et autres)

-h, --help afficher le message d'aide

-v, --verbose
augmenter le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version afficher les informations de version.

Flags de configuration

-t, --timeout <timeout_ms> remplacer le timeout par défaut pour les mads sollicités.

--outstanding_smps, -o <val>
spécifier le nombre de SMPs en attente qui doivent être émis pendant le balayage

Défaut : 2

--node-name-map <node-name-map> spécifier une carte de noms de nœuds.

Ce fichier mappe les GUIDs à des noms plus conviviaux. Voir la section FICHIERS.

--config, -z <config_file> spécifier un fichier de configuration alternatif.

Défaut : /etc/infiniband-diags/ibdiag.conf

FICHIERS COMMUNS

FICHIER DE CONFIGURATION

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines des options courantes pour tous les outils. Voir le fichier de configuration fourni pour plus de détails.

FORMAT DU FICHIER DE CARTE DES NOMS DE NOEUDS

La carte des noms de nœuds est utilisée pour spécifier des noms conviviaux pour les nœuds dans la sortie. Les GUID sont utilisés pour effectuer la recherche.

Cette fonctionnalité est fournie par le package opensm-libs. Voir opensm(8) pour l'emplacement du fichier dans votre installation.

Génériquement :

# commentaire
<guid> "<nom>"

Exemple :

# IB1
# Cartes de ligne
0x0008f104003f125c "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f125d "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d2 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d3 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10bf "IB1 (Rack 11 slot 12  ) ISR9288/ISR9096 Voltaire sLB-24D"
# Épines
0x0008f10400400e2d "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2f "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e31 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e32 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
# GUID   Nom du nœud
0x0008f10400411a08 "SW1  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a28 "SW2  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a34 "SW3  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f104004119d0 "SW4  (Rack  3) ISR9024 Voltaire 9024D"
