SAMPLV1(1) Manuel des commandes générales SAMPLV1(1)

NOM

samplv1 - synthétiseur échantillonneur polyphonique à l'ancienne

SYNTAXE

samplv1_jack [options] [fichier-preset]

DESCRIPTION

Cette page de manuel documente brièvement la commande samplv1_jack.

samplv1 est un synthétiseur échantillonneur polyphonique à l'ancienne avec effets stéréo.

fonctionnalités :

un client JACK autonome pur avec prise en charge de JACK-session, NSM et des entrées MIDI JACK et ALSA ;
un plugin d'instrument LV2. URI : http://samplv1.sourceforge.net/lv2

OPTIONS

-g, --no-gui

Désactive l'interface graphique (GUI)

-n, --client-name=[étiquette]

Définit le nom du client JACK (par défaut : samplv1)

-h, --help

Affiche l'aide sur les options de ligne de commande

-v, --version

Affiche les informations de version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/samplv1.conf
