NOM

sane-qcam - Backend SANE pour les caméras Connectix QuickCam

DESCRIPTION

La bibliothèque sane-qcam implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux caméras Connectix QuickCam.

NOMS DE PÉRIPHÉRIQUE

Ce backend attend des noms de périphérique de la forme :

port

où port est l'adresse du port d'entrée/sortie où se trouve le périphérique. Cette adresse est normalement spécifiée en hexadécimal en syntaxe C (par exemple, 0x37b) et peut être préfixée par la lettre « u » (par exemple, u0x37b) pour forcer le backend à accéder à la caméra en mode unidirectionnel.

CONFIGURATION

Le contenu du fichier qcam.conf est une liste d'adresses de port qui peuvent être connectées à une Connectix QuickCam. Les lignes vides et tout ce qui commence par un dièse (#) jusqu'à la fin de la ligne sont ignorés. Un exemple de fichier de configuration est montré ci-dessous :

0x37b # /dev/lp0
0x378 # /dev/lp1
u0x278 # /dev/lp2 forcé en mode unidirectionnel
0x3bc # /dev/lp0 (adresse alternative)

En général, il est plus sûr de ne lister que les adresses de port qui correspondent réellement à une QuickCam. Par exemple, si l'une des adresses listées se connecte effectivement à une imprimante, le démarrage de ce backend provoquera un réinitialisation du périphérique de l'imprimante (ce qui est généralement indésirable).

FICHIERS

/etc/sane.d/qcam.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-qcam.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-qcam.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:`), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (« . ») puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à « /tmp/config: » entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_QCAM
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux plus petits réduisent la verbosité.

AUTEUR

David Mosberger

BOGUES

Le support est actuellement limité à la version couleur de la QuickCam. La caméra noir et blanc commence également à fonctionner, mais je ne pense pas qu'elle fonctionne dans tous les cas pour le moment. Il a été rapporté que l'acquisition d'images de certaines tailles fonctionne bien, mais d'autres résultent en des images décalées (cela ressemble à un problème dû au remplissage d'octets).

Le programme nécessite des privilèges root car il doit pouvoir accéder aux ports d'E/S de la caméra.
