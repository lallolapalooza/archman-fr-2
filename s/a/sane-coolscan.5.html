NOM

sane-coolscan - Backend SANE pour les scanners de film Nikon

À PROPOS DE CE FICHIER

Ce fichier est une courte description du backend coolscan pour SANE.

DESCRIPTION

La bibliothèque sane-coolscan implémente un backend SANE qui fournit l'interface aux scanners de film Nikon Coolscan suivants : Nikon LS20, LS30, LS1000, LS2000.

Bien que le backend ait fonctionné pour un certain nombre de personnes, il subsiste encore quelques problèmes, notamment en combinaison avec certaines cartes/pilotes SCSI (AHA-1505/aha152x.o) et la commande d'autofocus. Vous devriez considérer ce backend comme 'alpha' et être prudent lors de sa première utilisation.

CONFIGURATION

Le fichier de configuration pour ce backend se trouve dans /etc/sane.d/coolscan.conf.

Son contenu est une liste de noms de périphériques qui correspondent aux scanners Nikon Coolscan. Les lignes vides et les lignes commençant par un signe dièse (#) sont ignorées. Un exemple de fichier de configuration est présenté ci-dessous :

 #scsi Vendor Model Type
 scsi Nikon * Scanner
 /dev/scanner

Le nom de périphérique spécial doit être un périphérique SCSI générique ou un lien symbolique vers un tel périphérique. Pour savoir à quel périphérique votre scanner est assigné et comment vous pouvez définir les autorisations de ce périphérique, consultez sane-scsi(5).

ASTUCES POUR ADAPTATEUR SCSI

Certains adaptateurs SCSI et pilotes SCSI de bas niveau ne fonctionnent pas correctement avec ce backend et les scanners Coolscan. Ces systèmes se bloquent lorsque la commande d'autofocus est envoyée au scanner. Pour voir une liste des combinaisons carte/pilote qui fonctionnent ou pas, consultez : http://andreas.rick.free.fr/sane/autofocus.html.

FICHIERS

Le fichier de configuration du backend :
/etc/sane.d/coolscan.conf
La bibliothèque statique implémentant ce backend :
/usr/lib/sane/libsane-coolscan.a
La bibliothèque partagée implémentant ce backend :
/usr/lib/sane/libsane-coolscan.so (présente sur les systèmes qui supportent le chargement dynamique)

ENVIRONNEMENT

SANE_DEBUG_COOLSCAN
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande que toutes les sorties de débogage soient imprimées. Des niveaux inférieurs réduisent la verbosité.

Exemples :

Sur bash :
export SANE_DEBUG_COOLSCAN=8

Sur csh :
setenv SANE_DEBUG_COOLSCAN 8

BOGUES

La commande d'autofocus ne fonctionne pas avec certaines combinaisons carte/pilote SCSI.

La table gamma n'est pas encore implémentée pour le LS1000.

La suppression de poussière ne fonctionne pas encore.
