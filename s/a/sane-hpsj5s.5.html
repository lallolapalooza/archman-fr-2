sane-hpsj5s(5) SANE Scanner Access Now Easy sane-hpsj5s(5)

NOM

sane-hpsj5s - Backend SANE pour le scanner à alimentation feuille HP ScanJet 5S

DESCRIPTION

La bibliothèque sane-hpsj5s implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès au scanner à alimentation feuille Hewlett-Packard ScanJet 5S par port parallèle.

IMPORTANT : ceci est du code alpha. Ne vous attendez pas à ce que cela fonctionne correctement. De nombreuses fonctions sont manquantes, d'autres contiennent des erreurs. Dans certains cas, votre ordinateur pourrait même se bloquer. Il ne peut être exclu (bien que je considère cela extrêmement improbable) que votre scanner soit endommagé.

LIMITATIONS : Pour l'instant, ce backend ne fonctionne que sous Linux. Cette limitation est due à la dépendance à la bibliothèque libieee1284(3). Si votre système prend également en charge libieee1284(3), ce backend devrait fonctionner. Si vous avez porté libieee1284(3) pour votre plateforme, veuillez m'en informer. Votre système doit prendre en charge le mode EPP (ou EPP+ECP) pour faire fonctionner ce scanner. Les versions futures prendront également en charge les modes ECP et SPP (Nibble et Byte). Il est prévu de prendre en charge les scanners non seulement à la position de chaîne (daisy-chain) 0, mais n'importe où. Le support de plusieurs scanners pourrait également être implémenté.

La version actuelle implémente uniquement la numérisation en niveaux de gris. Les modes Couleur Vraie et N/B ne sont pas pris en charge pour l'instant.

Cela dit, les TESTEURS SONT LES BIENVENUS. Envoyez vos rapports de bugs et commentaires à Max Vorobiev <pcwizard@yandex.ru>.

NOMS DE PÉRIPHÉRIQUE

Ce backend attend des noms de périphérique de la forme :

spécial

Où spécial est le nom du port parallèle dans la forme attendue par libieee1284(3). Cela semble dépendre du système. Sous Linux, il s'agit de parport0, parport1, etc.

CONFIGURATION

Le contenu du fichier hpsj5s.conf est une liste de noms de ports parallèles qui correspondent aux scanners HP ScanJet 5S. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Un seul nom de périphérique peut être listé dans hpsj5s.conf pour le moment. Les futures versions prendront en charge la sélection de chaîne en série.

CONSEILS

Il semble que le scanner HP ScanJet 5S utilise une correction logicielle du bruit. Cette fonctionnalité, ainsi que la correction gamma et la calibration, ne sont pas implémentées pour l'instant. Elles seront gérées dans les futures versions. La résolution native de ce scanner est de 300 DPI. D'autres modes peuvent présenter des artefacts d'aliasing.

FICHIERS

/etc/sane.d/hpsj5s.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-hpsj5s.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-hpsj5s.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes prenant en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (` ;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_DEBUG_HPSJ5S
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.
