sane-kodak(5) SANE Scanner Access Now Easy sane-kodak(5)

NOM

sane-kodak - Backend SANE pour les scanners à plat et ADF Kodak volumineux

DESCRIPTION

La bibliothèque sane-kodak implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat et ADF Kodak volumineux.

Ce document décrit la version 7 du backend, livrée avec SANE 1.0.21.

MATÉRIEL SUPPORTÉ

Cette version devrait supporter les modèles qui parlent les protocoles SCSI et Firewire de Kodak. Le i1860 a été utilisé pour développer le backend, mais d'autres modèles pourraient fonctionner avec des modifications minimales. Veuillez consulter la liste sur http://www.sane-project.org/sane-supported-devices.html pour une liste mise à jour.

Si vous possédez une machine qui ne figure pas sur cette liste, ou signalée comme 'non testée' : le meilleur moyen de déterminer le niveau de support est de tester le scanner directement, ou de collecter une trace du pilote Windows en action. Veuillez contacter l'auteur pour obtenir de l'aide ou partager vos résultats de test.

MATÉRIEL NON SUPPORTÉ

La plupart des machines Kodak récentes de niveau consommateur ou de groupe de travail sont basées sur d'autres chipsets et ne sont pas supportées par ce backend. Certains de ces scanners peuvent être supportés par un autre backend.

OPTIONS

Des efforts ont été faits pour exposer les options matérielles de base, notamment :

--source s

Sélectionne la source pour la numérisation. Les options peuvent inclure "Flatbed", "ADF Front", "ADF Back", "ADF Duplex".

--mode m

Sélectionne le mode de numérisation. Les options peuvent inclure "Lineart", "Halftone", "Gray", et "Color".

--resolution

Contrôle la résolution de la numérisation. Les choix disponibles peuvent être limités par le mode.

--tl-x, --tl-y, --br-x, --br-y

Définit les coordonnées du coin supérieur gauche et du coin inférieur droit de la zone de numérisation. Celles-ci sont renommées -t, -l, -x, -y par certains frontends.

--page-width, --page-height

Définit la taille du papier. Utilisé par le scanner pour déterminer le centrage des coordonnées de numérisation lors de l'utilisation de l'ADF (alimentateur automatique de documents) et pour détecter les erreurs de double alimentation.

D'autres options seront disponibles en fonction des capacités du scanner. Utilisez scanimage --help pour obtenir une liste, mais soyez conscient que certaines options ne peuvent être définies que lorsqu'une autre option a été définie, et que les options avancées peuvent être masquées par certains programmes frontends.

FICHIER DE CONFIGURATION

Le fichier de configuration kodak.conf est utilisé pour indiquer au backend comment rechercher les scanners, et fournir des options contrôlant le fonctionnement du backend. Ce fichier est lu chaque fois que le frontend demande au backend une liste de scanners, généralement uniquement au démarrage du frontend. Si le fichier de configuration est absent, le backend utilisera un ensemble de valeurs par défaut compilées, qui sont identiques au fichier de configuration par défaut fourni avec SANE.

Les scanners peuvent être spécifiés dans le fichier de configuration de 2 manières :

"scsi KODAK"

Demande au backend de rechercher sur tous les bus scsi du système un périphérique qui se déclare comme un scanner fabriqué par 'KODAK'.

"scsi /dev/sg0" (ou autre fichier de périphérique scsi)

Demande au backend d'ouvrir le périphérique scsi nommé. Utile uniquement si vous avez plusieurs scanners compatibles connectés à votre système, et que vous avez besoin d'en spécifier un. Probablement à ne pas utiliser avec l'autre ligne "scsi" ci-dessus.

La seule option de configuration supportée est "buffer-size=xxx", vous permettant de définir le nombre d'octets dans le tampon de données à une valeur autre que celle compilée par défaut, 32768 (32 Ko). Certains utilisateurs rapportent que leur scanner "se bloque" en milieu de page, ou ne parvient pas à transmettre l'image si le tampon n'est pas assez grand.

Remarque : Cette option peut apparaître plusieurs fois dans le fichier de configuration. Elle s'applique uniquement aux scanners découverts par les lignes 'scsi/usb' qui suivent cette option.

Remarque : Le backend ne place pas de limite supérieure à cette valeur, car certains utilisateurs ont nécessité qu'elle soit assez grande. Les valeurs supérieures à la valeur par défaut ne sont pas recommandées et peuvent bloquer votre système d'exploitation ou votre pilote de carte scsi. Vous avez été averti.

ENVIRONNEMENT

Le backend utilise une seule variable d'environnement, SANE_DEBUG_KODAK, qui active la sortie de débogage sur stderr. Les valeurs valides sont :

5 Erreurs
10 Trace de fonctions
15 Détail des fonctions
20 Commandes d'options
25 Trace SCSI
30 Détail SCSI
35 Bruit inutile

PROBLÈMES CONNUS

La plupart des options matérielles ne sont soit pas supportées, soit pas exposées pour le contrôle par l'utilisateur, notamment : détection de multi-alimentation, compression d'image, recadrage automatique, endosseur, seuillage, multi-flux, etc.

CRÉDITS

Les différents auteurs du backend sane-fujitsu(5) ont fourni du code utile.
Kodak a fourni un accès au matériel, à la documentation et au personnel.
