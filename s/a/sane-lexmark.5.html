sane-lexmark(5) SANE Scanner Access Now Easy sane-lexmark(5)

NOM

sane-lexmark - Backend SANE pour les scanners Lexmark séries X1100/X1200

DESCRIPTION

La bibliothèque sane-lexmark implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès à la partie scanner des imprimantes multifonctions Lexmark X1100/X1200. Ce backend doit être considéré comme un logiciel de qualité bêta !

Les scanners qui devraient fonctionner avec ce backend sont :

   Vendeur   Modèle      statut
----------------------  -----------
  Lexmark X74             bon
  Lexmark X1110           non testé
  Lexmark X1140           non testé
  Lexmark X1150           bon
  Lexmark X1170           bon
  Lexmark X1180           bon
  Lexmark X1185           complet
  Lexmark X12xx           bon en USB1.1,
                          pas entièrement testé en USB2.0
  Dell    A920            bon

Les options supportées par le backend peuvent être sélectionnées soit via des options en ligne de commande pour des programmes comme scanimage(1), soit via des éléments d'interface graphique dans xscanimage(1) ou xsane(1).

Si vous remarquez un comportement étrange, veuillez le signaler au mainteneur du backend ou à la liste de diffusion SANE.

Les options valides en ligne de commande et leur syntaxe peuvent être listées en utilisant

scanimage --help -d lexmark:usb:<port usb>

Options de mode de numérisation
--mode
sélectionne le mode de fonctionnement de base du scanner. Les choix valides sont Couleur, Niveaux de gris et Ligne. Le mode par défaut est Couleur. Le mode Ligne est uniquement en noir et blanc (1 bit). Le mode Niveaux de gris produira 256 niveaux de gris (8 bits). Le mode Couleur permet plus de 16 millions de couleurs différentes produites à partir de 24 bits d'informations couleur.
--resolution
sélectionne la résolution pour une numérisation. Les résolutions horizontale et verticale sont définies par la valeur de cette option. Le scanner est capable des résolutions suivantes pour la valeur de l'option spécifiée :
  Valeur  Résolution Hor.  Résolution Vert.
  -----   ---------------  -------------------
  75      75dpi            75dpi
  150     150dpi           150dpi
  300     300dpi           300dpi
  600     600dpi           600dpi
  1200    600dpi           1200dpi  (uniquement pour les modèles X11xx avec capteur 'B2')
--preview
demande une numérisation de prévisualisation. La résolution utilisée pour cette numérisation est de 75 dpi et la zone de numérisation ainsi que le mode de numérisation sont ceux spécifiés via leurs options, ou les valeurs par défaut si elles ne sont pas spécifiées. La valeur par défaut pour le mode de prévisualisation est "non".
--threshold
sélectionne la luminosité minimale pour obtenir un point blanc. Le seuil n'est utilisé qu'avec les numérisations en mode Ligne. Il est spécifié en pourcentage dans la plage 0..100 % (par pas de 1). La valeur par défaut de l'option de seuil est 50.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/lexmark.conf contient uniquement l'identifiant de l'appareil USB (par exemple, usb 0x043d 0x007c).

FICHIERS

/usr/lib/sane/libsane-lexmark.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-lexmark.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_LEXMARK
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 255 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité.
SANE_DEBUG_LEXMARK_LOW
Fournit des sorties de débogage pour les fonctions Lexmark de bas niveau.

LIMITATIONS

Le pilote TWAIN de Windows possède beaucoup plus d'options que ce backend SANE. Cependant, il ne s'agit que d'ajustements logiciels. Ce backend n'implémente que ce que le scanner peut supporter. Par exemple, la correction d'ombrage (rayures verticales dues aux variations du capteur sur sa largeur) est effectuée par logiciel. La position de stationnement de la tête est également détectée par logiciel. La compression des données n'est pas supportée pour la série X1200 en USB 1.1, ce qui entraîne des numérisations lentes.

BOGUES

Aucun bogue connu actuellement.
