NOM

sane-xerox_mfp - Backend SANE pour les appareils Xerox Phaser 3200MFP et autres.

DESCRIPTION

La bibliothèque sane-xerox_mfp implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à plusieurs scanners Samsung, Xerox et Dell basés sur Samsung. Voir la liste complète des appareils pris en charge sur http://www.sane-project.org/sane-supported-devices.html.

CONFIGURATION

/etc/sane.d/xerox_mfp.conf
Les scanners USB ne nécessitent aucune configuration.

Pour le SCX-4500W en mode réseau, vous devez spécifier

tcp adresse_hote [port]

L'adresse_hote est transmise au résolveur, elle peut donc être un quad-dot ou un nom provenant de /etc/hosts ou résolvable via DNS.

FICHIERS

/etc/sane.d/xerox_mfp.conf
Le fichier de configuration du backend. Par défaut, tous les types/modèles de scanners sont activés, vous pourriez vouloir commenter les entrées non désirées.
/usr/lib/sane/libsane-xerox_mfp.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-xerox_mfp.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_XEROX_MFP
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_XEROX_MFP=4

LIMITATIONS

La configuration automatique multicast pour les scanners LAN n'est pas encore implémentée. L'adressage IPv6 n'a jamais été testé.

BOGUES ET SUPPORT

Si vous avez trouvé un bogue ou si vous avez besoin de support, veuillez suivre la voie open-source pour obtenir du support via les listes de diffusion http://www.sane-project.org/mailing-lists.html ou le traqueur de bogues SANE http://www.sane-project.org/bugs.html.
