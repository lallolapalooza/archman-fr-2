sane-dc240(5) SANE Scanner Access Now Easy sane-dc240(5)

NOM

sane-dc240 - Backend SANE pour l'appareil photo numérique Kodak DC240

DESCRIPTION

La bibliothèque sane-dc240 implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès à l'appareil photo Kodak DC240. Ceci est du code EXTRÊMEMENT ALPHA ! UTILISEZ À VOS RISQUES ET PÉRILS !!

NOMS DE PÉRIPHÉRIQUE

La version actuelle du backend ne permet qu'un seul appareil photo connecté. Le nom du périphérique est toujours "0".

CONFIGURATION

Le contenu du fichier dc240.conf spécifie le port série et le débit en bauds à utiliser. Le débit en bauds spécifie le taux maximum à utiliser lors du téléchargement des images. (L'appareil photo est toujours initialisé en utilisant 9600 bauds, puis passe au taux plus élevé). Sur un Pentium de 450 MHz, je n'ai généralement pas de problèmes à télécharger à 115200 bauds, bien que l'appareil photo doive parfois renvoyer des paquets en raison de caractères perdus. Les résultats sont meilleurs lorsque le "drapeau de démasquage d'interruption" est défini dans le pilote IDE (hdparm -u1). Les débits en bauds pris en charge sont : 9600, 19200, 38400, 57600 et 115200.

La ligne dumpinquiry provoque l'affichage d'informations sur l'appareil photo.

cmdrespause spécifie combien de microsecondes (1 000 000èmes de seconde) attendre entre l'écriture de la commande et la lecture du résultat. 125000 semble être le minimum que j'aie pu utiliser de manière fiable.

breakpause spécifie combien de microsecondes (1 000 000èmes de seconde) attendre entre l'envoi de la rupture "retour aux valeurs par défaut" et l'envoi des commandes.

Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous :

port=/dev/ttyS0
# ceci est un commentaire
baud=115200
dumpinquiry
cmdrespause=125000
breakpause=1000000

FICHIERS

/etc/sane.d/dc240.conf
Le fichier de configuration du backend (voir également la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-dc240.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-dc240.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:`), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour effet de rechercher les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_DC240
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Une valeur de 128 demande une sortie de débogage maximale ; des niveaux plus bas réduisent la verbosité.

BOGUES

La principale limitation que je connaisse est que le backend suppose que le répertoire de l'appareil photo est 100dc240. Une fois que l'appareil photo a pris plus de 9999 photos, le répertoire passera à 101dc240. Non seulement nous devrions vérifier le répertoire supplémentaire, mais les photos pourraient en fait se trouver dans plusieurs répertoires.

Les commentaires plus généraux, suggestions et questions sur les interfaces utilisateur ou SANE doivent être envoyés à la liste de diffusion des développeurs SANE (voir http://www.sane-project.org/mailing-lists.html pour plus de détails). Vous devez être abonné à la liste, sinon votre courrier ne sera pas envoyé aux abonnés.
