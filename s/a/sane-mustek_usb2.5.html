NOM

sane-mustek_usb2 - Backend SANE pour les scanners à plat USB basés sur SQ113

DESCRIPTION

La bibliothèque sane-mustek_usb2 implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès aux scanners à plat USB basés sur le chipset Service & Quality SQ113. Pour le moment, seul le Mustek BearPaw 2448 TA Pro est supporté. Il est prévu d'ajouter le support pour d'autres scanners basés sur le SQ113 et potentiellement le SQ11. Pour plus de détails, consultez la page d'accueil du backend sane-mustek_usb2 : http://www.meier-geinitz.de/sane/mustek_usb2-backend/.

Ceci est un logiciel BETA. En particulier si vous testez des scanners nouveaux ou non testés, gardez la main sur la prise de courant du scanner et débranchez-le si la tête heurte la fin de la zone de scan.

Si vous possédez un scanner autre que ceux listés sur la page d'accueil de mustek_usb2 qui fonctionne avec ce backend, veuillez m'en informer en envoyant le nom exact du modèle du scanner et les identifiants du vendeur et du périphérique USB (par exemple, depuis sane-find-scanner(1) ou le syslog) à mon attention. Même si le nom du scanner est légèrement différent des modèles déjà listés comme supportés, veuillez m'en informer.

PROBLÈMES LIBUSB

Veuillez utiliser libusb-0.1.8 ou une version ultérieure. Sans libusb ou avec des versions plus anciennes de libusb, toutes sortes de problèmes peuvent être attendus. Le scanner devrait être trouvé par sane-find-scanner(1) sans actions supplémentaires. Pour la gestion des permissions et les informations USB générales, consultez sane-usb(5).

FICHIERS

/usr/lib/sane/libsane-mustek_usb2.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-mustek_usb2.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_MUSTEK_USB2
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_MUSTEK_USB2=4
