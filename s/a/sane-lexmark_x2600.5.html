sane-lexmark_x2600(5) SANE Scanner Access Now Easy sane-lexmark_x2600(5)

NOM

sane-lexmark_x2600 - backend SANE pour les scanners Lexmark série X2600

DESCRIPTION

La bibliothèque sane-lexmark implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à la partie scanner des imprimantes multifonctions Lexmark X2600.

Les scanners qui devraient fonctionner avec ce backend sont :

   Fabricant Modèle           statut
----------------------  -----------
  Lexmark X2670           bon

Les options que le backend supporte peuvent être sélectionnées soit via des options de ligne de commande pour des programmes comme scanimage(1), soit via des éléments d'interface graphique dans xscanimage(1), xsane(1) ou simple-scan(1).
Si vous remarquez un comportement étrange, veuillez le signaler au mainteneur du backend ou à la liste de diffusion SANE.

FICHIERS

/usr/lib/sane/libsane-lexmark_x2600.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-lexmark_x2600.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_LEXMARK_X2600
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 255 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité.
