NOM

sa-check_spamd - script de surveillance de spamd à utiliser avec Nagios, etc.

SYNTAXE

sa-check_spamd [options]

Options :

-c secs, --critical=secs          Seuil critique de réponse ping
-h, -?, --help                    Afficher le message d'utilisation
-H hostname, --hostname=hostname  Nom d'hôte du service spamd à pinger
-p port, --port=port              Port du service spamd à pinger
--socketpath=path                 Se connecter au socket de domaine UNIX donné
-t secs, --timeout=secs           Temps maximum d'attente pour une réponse ping
-v, --verbose                     Sortie de débogage détaillée
-V, --version                     Afficher les informations de version
-w secs, --warning=secs           Seuil d'avertissement de réponse ping

DESCRIPTION

L'objectif de ce programme est de fournir un outil pour surveiller l'état des processus serveur "spamd". spamd est la version démonisée de l'exécutable spamassassin, tous deux fournis dans la distribution SpamAssassin.

Ce programme est conçu pour être utilisé, en tant que plugin, avec le logiciel de surveillance de services Nagios disponible sur http://nagios.org. Il peut être compatible avec d'autres packages de surveillance de services. Il est également utile comme utilitaire en ligne de commande ou comme composant d'un script shell personnalisé.

OPTIONS

Les options de forme longue peuvent être raccourcies tant qu'elles restent sans ambiguïté (par exemple, --host peut être utilisé à la place de --hostname).

-c secs, --critical=secs
Seuil critique de réponse ping en secondes. Si une réponse ping de spamd prend plus de temps que la valeur spécifiée (en secondes), le programme se terminera avec la valeur 2 pour indiquer l'état critique.

Cette valeur doit être au moins aussi longue que la valeur spécifiée pour warning et inférieure à la valeur spécifiée pour timeout.

-h, -?, --help
Affiche ce message d'utilisation et quitte.
-H hostname, --hostname=hostname
Le nom d'hôte, ou l'adresse IP, du service spamd à pinger. Par défaut, le nom d'hôte localhost est utilisé. Si --socketpath est défini, cette valeur sera ignorée.
-p port, --port=port
Le port du service spamd à pinger. Par défaut, le port 783 (le numéro de port par défaut de spamd) est utilisé. Si --socketpath est défini, cette valeur sera ignorée.
--socketpath=path
Se connecter au socket de domaine UNIX donné. À utiliser à la place d'un nom d'hôte et d'un port TCP. Lorsque défini, tout nom d'hôte et port TCP spécifiés seront ignorés.
-t secs, --timeout=secs
Le temps maximum à attendre pour une réponse ping. Une fois dépassé, le programme se terminera avec la valeur 2 pour indiquer l'état critique. La valeur de délai d'attente par défaut est de 45 secondes. Le délai d'attente ne doit pas être inférieur à 1 seconde.

Cette valeur doit être supérieure aux valeurs spécifiées pour critical et warning.

-v, --verbose
Afficher la sortie de débogage détaillée sur STDOUT.
-V, --version
Afficher les informations de version sur STDOUT.
-w secs, --warning=secs
Seuil d'avertissement de réponse ping en secondes. Si une réponse ping de spamd prend plus de temps que la valeur spécifiée (en secondes), et ne dépasse pas la valeur du seuil critical, le programme se terminera avec la valeur 1 pour indiquer l'état d'avertissement.

Cette valeur ne doit pas être plus longue que la valeur spécifiée pour critical et inférieure à la valeur spécifiée pour timeout.

CODES DE SORTIE

Le programme indiquera l'état du processus spamd surveillé en se terminant avec l'une des valeurs suivantes :

0
OK : Une réponse ping de spamd a été reçue dans les temps impartis pour tous les seuils.
1
AVERTISSEMENT : Une réponse ping de spamd a dépassé le seuil d'avertissement mais pas le seuil critique.
2
CRITIQUE : Une réponse ping de spamd a dépassé soit le seuil critique, soit la valeur de délai d'attente.
3
INCONNU : Une erreur, probablement causée par une dépendance manquante ou un paramètre de configuration invalide, s'est produite dans le programme sa-check_spamd.
