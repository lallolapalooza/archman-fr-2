sane-leo(5) Accès Facile aux Scanners SANE sane-leo(5)

NOM

sane-leo - Backend SANE pour les scanners LEO Technologies

DESCRIPTION

La bibliothèque sane-leo implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à certains scanners LEO SCSI à plat. Ce backend doit être considéré comme un logiciel de qualité bêta ! Les scanners LEO étaient également vendus sous la marque Across Technologies.

Les scanners qui devraient fonctionner avec ce backend sont :

   Fabricant Modèle        statut
----------------------  -----------
  Across FS-1130          testé
  LEO S3                  testé

Les options que le backend supporte peuvent être sélectionnées via des options de ligne de commande pour des programmes comme scanimage(1) ou via des éléments d'interface graphique dans xscanimage(1) ou xsane(1).

Si vous rencontrez un comportement étrange, veuillez le signaler au mainteneur du backend ou à la liste de diffusion SANE.

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant

scanimage --help -d leo
Mode de balayage
--mode
sélectionne le mode de fonctionnement de base du scanner. Les choix valides sont Noir & Blanc, Niveaux de gris et Couleur. Le mode Noir & Blanc est uniquement en noir et blanc (1 bit). Le mode Niveaux de gris produira 256 niveaux de gris (8 bits). Le mode Couleur produira une image couleur de 24 bits.
--resolution
sélectionne la résolution pour un balayage. Le scanner peut faire toutes les résolutions entre 1 et 300, par incréments de 1.
Options de géométrie
-l -t -x -y
contrôlent la zone de balayage : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de balayage. Tous les paramètres sont spécifiés en millimètres par défaut.
Options d'amélioration
--custom-gamma
(mode niveaux de gris et couleur uniquement) permet à l'utilisateur de spécifier une table gamma (voir les 3 paramètres suivants).
--red-gamma-table
(mode couleur uniquement) peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal rouge. La table doit faire 256 octets de long.
--green-gamma-table
(mode couleur uniquement) peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal vert. La table doit faire 256 octets de long.
--blue-gamma-table
(mode couleur uniquement) peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal bleu. La table doit faire 256 octets de long.
--halftone
(Noir & Blanc uniquement) sélectionne le masque de demi-teintes à utiliser. Les valeurs possibles sont Diamant, Trame grossière 8x8, Trame fine 8x8, Bayer 8x8 et Ligne verticale 8x8.
--preview
demande un balayage d'aperçu. La résolution utilisée pour ce balayage est de 28 dpi et la zone de balayage est le maximum autorisé. Le mode de balayage est sélectionné par l'utilisateur. La valeur par défaut est "non".

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/leo.conf ne supporte qu'une seule information : le nom de l'appareil à utiliser (par ex. /dev/scanner).

FICHIERS

/usr/lib/sane/libsane-leo.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-leo.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_LEO
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux inférieurs réduisent la verbosité.

LIMITATIONS

Le pilote TWAIN pour Windows a beaucoup plus d'options que ce backend SANE. Cependant, ce ne sont que des ajustements logiciels. Ce backend n'implémente que ce que le scanner peut supporter.

BOGUES

Aucun connu.
