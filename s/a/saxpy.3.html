SAXPY

Objectif x2f;but x2f;finalité :

!>
!>    SAXPY une constante fois un vecteur plus un vecteur.
!>    utilise des boucles déroulées pour des inckements égaux à un.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         nombre d’éléments dans le(s) vecteur(s) d’entrée
!>

SA

!>          SA est un réel (REAL)
!>           A l’entrée, SA spécifie le scalaire alpha.
!>

SX

!>          SX est un tableau de réels (REAL array), de dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un entier (INTEGER)
!>         pas de stockage entre les éléments de SX
!>

SY

!>          SY est un tableau de réels (REAL array), de dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est un entier (INTEGER)
!>         pas de stockage entre les éléments de SY
