sane-canon630u(5) SANE Scanner Access Now Easy sane-canon630u(5)

NOM

sane-canon630u - Backend SANE pour le scanner plat Canon 630u USB

DESCRIPTION

La bibliothèque sane-canon630u implémente un backend SANE (Scanner Access Now Easy) qui donne accès aux scanners plats Canon suivants :

CanoScan 630u
CanoScan 636u

La numérisation en couleur est prise en charge à 75, 150, 300 et 600 dpi, et le gamma et le gain analogique sont réglables.

LES TESTEURS SONT LES BIENVENUS. Envoyez vos rapports de bugs et commentaires à Nathan Rutman <nthn1@yahoo.com>.

CONFIGURATION

Le contenu du fichier canon630u.conf est une liste de noms de périphériques correspondant aux scanners USB Canon. Les lignes vides et celles commençant par un dièse (#) sont ignorées. Un seul nom de périphérique peut être listé dans canon630u.conf. Le programme sane-find-scanner(1) aide à trouver le bon périphérique. Sous Linux, un tel nom de périphérique pourrait être, par exemple, /dev/usb/scanner0. Voir sane-usb(5) pour les détails.

Ce pilote de scanner spécifique au produit utilise le pilote USB du noyau de bas niveau "scanner". Vérifiez "Driver=usbscanner" sous /proc/bus/usb/devices. Si "Driver=(none)", essayez de le forcer avec insmod scanner vendor=0x04a9 product=0x2204

NOTES

En raison du manque de volonté de Canon à fournir la documentation des scanners, ce logiciel a été développé en analysant le trafic USB du pilote Windows 2000. Ainsi, des choses comme la procédure de calibration sont un peu improvisées ; cela semble fonctionner pour mon scanner. Si vous avez des plaintes, faites-le moi savoir.

Ce pilote nécessite la capacité d'envoyer des messages de contrôle USB, disponible dans le noyau 2.4.12 ou une version ultérieure.

Certains utilisateurs ont signalé que ce pilote ne fonctionne pas du tout. Cela semble être un problème spécifique au matériel, bien que je ne sache pas exactement quel est le problème. Si vous rencontrez des problèmes, veuillez m'envoyer les informations contenues dans /proc/bus/usb/devices, /proc/pci, la version du pilote scanner.c du noyau à partir de /var/log/messages, et la sortie de SANE_DEBUG_CANON630U=12 scanimage > /dev/null

FICHIERS

/etc/sane.d/canon630u.conf
Le fichier de configuration du backend (voir également la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-canon630u.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-canon630u.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).
/tmp/canon.cal
Le fichier de calibration utilisé pour normaliser la luminosité des pixels. Celui-ci est calculé à chaque utilisation du scanner après qu'il ait perdu l'alimentation. La suppression de ce fichier forcera la recalibration.

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux points (`:'), sous OS/2, ils sont séparés par un point virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_CANON630U
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple :
SANE_DEBUG_CANON630U=12 scanimage > /dev/null
