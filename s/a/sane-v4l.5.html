sane-v4l(5) SANE Scanner Access Now Easy sane-v4l(5)

NOM

sane-v4l - Interface SANE pour l'API Video for Linux

DESCRIPTION

La bibliothèque sane-v4l implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès générique aux caméras vidéo et équipements similaires utilisant l'API V4L (Video for Linux).

Ceci est un logiciel ALPHA. Vraiment ! Des fonctionnalités importantes manquent et il y a beaucoup de bugs. Le code n'est actuellement testé que sur un système Linux 2.4 avec une carte vidéo Hauppauge WinTV.

NOMS DES APPAREILS

Ce backend attend des noms d'appareils de la forme :

spécial

Où spécial est le nom de chemin UNIX pour l'appareil spécial qui correspond à l'appareil v4l. Le nom de l'appareil spécial doit être un appareil v4l ou un lien symbolique vers un tel appareil. Par exemple, un tel nom d'appareil pourrait être /dev/video0 ou /dev/bttv0.

CONFIGURATION

Le contenu du fichier v4l.conf est une liste de noms d'appareils qui correspondent aux appareils v4l. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous :

/dev/bttv0
# ceci est un commentaire
/dev/video3

FICHIERS

/etc/sane.d/v4l.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-v4l.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-v4l.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_V4L
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux plus petits réduisent la verbosité.

AUTEUR

Juergen G. Schimmer, Henning Meier-Geinitz

BOGUES :

Si plus d'une carte vidéo est présente, un crash peut survenir. La sélection de la fréquence et de la géométrie est manquante.
Envoyez les rapports de bugs à la liste de diffusion SANE : sane-devel@alioth-lists.debian.net. Vous devez être abonné à la liste pour envoyer des e-mails. Voir http://www.sane-project.org/mailing-lists.html pour plus de détails.
