NOM

sane-config - obtenir des informations sur la version installée de libsane

SYNTAXE

sane-config [--prefix] [--exec-prefix] [--libs] [--cflags] [--ldflags] [--version] [--help [OPTION]]

DESCRIPTION

sane-config est un outil utilisé pour déterminer les indicateurs du compilateur et de l'éditeur de liens qui doivent être utilisés pour compiler et lier les interfaces SANE à une bibliothèque de backends SANE (libsane).

OPTIONS

sane-config accepte les options suivantes (vous ne pouvez pas utiliser plus d'une option à la fois) :

--version
Affiche la version actuellement installée de libsane sur la sortie standard.
--help OPTION
Affiche un court message d'utilisation. Si OPTION est spécifiée, l'aide pour cette option (par exemple, --libs) est affichée (si disponible).
--libs
Affiche les bibliothèques supplémentaires nécessaires pour lier une interface SANE à libsane.
--ldflags
Affiche les indicateurs de l'éditeur de liens nécessaires pour lier une interface SANE à libsane.
--cflags
Affiche les indicateurs du compilateur nécessaires pour compiler une interface SANE.
--prefix
Affiche le préfixe utilisé lors de la compilation de libsane.
--exec-prefix
Affiche l'exec-prefix utilisé lors de la compilation de libsane.
