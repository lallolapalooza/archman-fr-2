NOM

sa-awl - examiner et manipuler la base de données auto-liste blanche de SpamAssassin

SYNTAXE

sa-awl [--clean] [--dry-run] [--min n] [fichier_db]

DESCRIPTION

Vérifie ou nettoie un fichier de base de données de liste blanche automatique (AWL) de SpamAssassin.

Le nom du fichier est spécifié après les options, comme "fichier_db". Le nom par défaut est "$HOME/.spamassassin/auto-welcomelist".

OPTIONS

--clean
Nettoie les entrées AWL utilisées de manière peu fréquente. Le commutateur "--min" peut être utilisé pour sélectionner le seuil auquel les entrées sont conservées ou supprimées.
--dry-run
Lorsqu'il est spécifié avec l'option "--clean", il affiche les entrées AWL utilisées de manière peu fréquente qui seront supprimées. Le commutateur "--min" peut être utilisé pour sélectionner le seuil auquel les entrées sont conservées ou supprimées.
--min n
Sélectionne le seuil auquel les entrées sont conservées ou supprimées lorsque "--clean" est utilisé. La valeur par défaut est 2, donc les entrées qui n'ont été vues qu'une seule fois sont supprimées.

SORTIE

La sortie ressemble à ceci :

MOYENNE  (SCORE TOTAL/NOMBRE)  --  EMAIL|ip=IPBASE

Par exemple :

 0.0         (0.0/7)  --  dawson@example.com|ip=208.192
21.8        (43.7/2)  --  mcdaniel_2s2000@example.com|ip=200.106

"MOYENNE" est le score moyen ; "SCORE TOTAL" est le score total de tous les courriels vus jusqu'à présent ; "NOMBRE" est le nombre de messages vus de cet expéditeur ; "EMAIL" est l'adresse e-mail de l'expéditeur, et "IPBASE" est l'adresse IP de base AWL.

L'adresse IP de base AWL est un moyen d'identifier l'adresse IP de l'expéditeur à partir de laquelle il envoie fréquemment, de manière approximative, tout en restant difficile à usurper pour les spammeurs. L'algorithme est le suivant :

- prendre le dernier en-tête Received qui contient une adresse IP publique -- à savoir
  une qui n'est pas dans un espace IP privé non routable.
- supprimer les deux derniers octets, en supposant que l'utilisateur se trouve
  peut-être dans le pool d'adresses dynamiques d'un FAI.
