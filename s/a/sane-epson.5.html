NOM

sane-epson - backend SANE pour les scanners EPSON

DESCRIPTION

La bibliothèque sane-epson implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat EPSON. Certaines fonctions de ce backend doivent être considérées comme des logiciels de qualité bêta ! La plupart des fonctions sont stables depuis longtemps, mais bien sûr, le développement de nouvelles fonctionnalités ne peut pas fonctionner correctement dès le premier jour, et souvent ne fonctionne pas. Veuillez signaler tout comportement étrange au mainteneur du backend.

Actuellement, les scanners suivants sont connus pour fonctionner avec ce backend :

Pour les autres scanners, le logiciel peut fonctionner ou non. Veuillez envoyer un e-mail à l'auteur du backend (khk@khk.net) pour signaler les succès avec les scanners non listés ou les problèmes avec les scanners listés.

OPTIONS

Les options prises en charge par le backend peuvent être sélectionnées soit via des options de ligne de commande pour des programmes comme scanimage(1), soit via des éléments d'interface graphique dans des programmes comme xscanimage(1) ou xsane(1).

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant :

scanimage --help -d epson

Tous les appareils ne prennent pas en charge toutes les options.

Mode de numérisation
Le commutateur --mode sélectionne le mode de fonctionnement de base du scanner. Les choix valides sont Binaire, Niveaux de gris et Couleur. Le mode Binaire est uniquement noir et blanc, Niveaux de gris produira 256 niveaux de gris ou plus selon le scanner, et Couleur signifie 24 bits en mode couleur ou plus selon le scanner. Certains scanners utiliseront en interne 36 bits de couleur, mais leur interface externe peut ne supporter que 24 bits.

L'option --depth sélectionne la profondeur de bits que le scanner utilise. Cette option n'est disponible que pour les scanners qui prennent en charge plus d'une profondeur de bits. Les anciens scanners transféreront toujours l'image en mode 8 bits. Les scanners plus récents permettent de sélectionner soit 8 bits, 12 ou 14 bits par canal de couleur. Pour une numérisation couleur, cela signifie une profondeur de couleur effective de 36 ou 42 bits sur les trois canaux. Les choix valides dépendent du modèle de scanner.

Le commutateur --halftoning sélectionne le mode utilisé en mode Binaire. Les options valides sont "None", "Halftone A (Hard Tone)", "Halftone B (Soft Tone)", "Halftone C (Net Screen)", "Dither A (4x4 Bayer)", "Dither B (4x4 Spiral)", "Dither C (4x4 Net Screen)", "Dither D (8x4 Net Screen)", "Text Enhanced Technology", "Download pattern A" et "Download pattern B".

Le commutateur --dropout sélectionne la couleur dite de rejet. Les options valides sont None, Rouge, Vert et Bleu. La valeur par défaut est None. La couleur de rejet est utilisée pour la numérisation monochrome et sélectionne la couleur qui n'est pas numérisée. Cela peut être utilisé pour, par exemple, numériser un original avec un fond coloré.

Le commutateur --brightness contrôle la luminosité de la numérisation. Les options valides sont des valeurs entières de -3 à 3. La valeur par défaut est 0. Plus la valeur de luminosité est élevée, plus l'image devient lumineuse. Si une table définie par l'utilisateur pour la correction gamma est sélectionnée, le paramètre de luminosité n'est pas disponible.

Le commutateur --sharpness règle la netteté des données d'image. Les options valides sont des valeurs entières de -2 à 2, avec -2 signifiant "Flou", -1 "Légèrement flou", 0 "Normal", 1 "Légèrement net" et 2 "Net".

Le commutateur --gamma-correction contrôle la fonction de correction gamma interne du scanner. Les options valides sont "Default", "User defined", "High density printing" "Low density printing" et "High contrast printing".

Le commutateur --color-correction contrôle la fonction de correction des couleurs interne du scanner. Les options valides sont "No Correction", "Impact-dot printers", "Thermal printers", "Ink-jet printers" et "CRT monitors". La valeur par défaut est "CRT monitors".

Le commutateur --resolution sélectionne la résolution pour une numérisation. Certains scanners EPSON numériseront à n'importe quelle résolution comprise entre la valeur la plus basse et la plus haute possible. La liste rapportée par le scanner peut être affichée en utilisant les paramètres "--help -d epson" pour scanimage(1).

L'option --mirror contrôle la manière dont l'image est numérisée. En lisant les données de l'image de droite à gauche, l'image est inversée. Les options valides sont "yes" et "no". La valeur par défaut est "no".

L'option --speed peut améliorer la vitesse de numérisation en mode monochrome. Les options valides sont "yes" ou "no", l'option "yes" accélérera la numérisation si cette option est prise en charge.

Le commutateur --auto-area-segmentation active la segmentation automatique des zones pour les numérisations monochromes. Le scanner essaiera de déterminer quelles zones contiennent du texte et lesquelles contiennent des images. Les zones d'image seront tramées, et le texte sera amélioré. Les options valides sont "yes" et "no". La valeur par défaut est "yes".

Le paramètre --gamma-table peut être utilisé pour télécharger une table gamma définie par l'utilisateur. L'option prend 256 valeurs dans la plage 0-255. En mode couleur, cette option affecte également les canaux rouge, vert et bleu.

Le paramètre --red-gamma-table peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal rouge. Les options valides sont les mêmes que pour --gamma-table.

Le paramètre --green-gamma-table peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal vert. Les options valides sont les mêmes que pour --gamma-table.

Le paramètre --blue-gamma-table peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal bleu. Les options valides sont les mêmes que pour --gamma-table.

Les coefficients de correction des couleurs --cct-1 --cct-2 ... --cct-9 installeront des coefficients de correction des couleurs pour la correction des couleurs définie par l'utilisateur. Les valeurs sont spécifiées sous forme d'entiers dans la plage -127..127.

L'option --preview demande une numérisation de prévisualisation. Le logiciel frontal sélectionne automatiquement une résolution basse. Les options valides sont "yes" et "no". La valeur par défaut est "no".

L'option --preview-speed augmentera la vitesse de numérisation si cela est pris en charge par le scanner. Les options valides sont "yes" et "no", la valeur par défaut est "no".

Les options de géométrie -l -t -x -y contrôlent la zone de numérisation : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de numérisation. Tous les paramètres sont spécifiés en millimètres.

L'option --quick-format permet à l'utilisateur de sélectionner une zone de numérisation avec des tailles prédéfinies. Les paramètres valides sont "CD", "A5 portrait", "A5 landscape", "Letter", "A4" et "max". La valeur par défaut est "max", qui sélectionne la plus grande zone possible.

L'option --source sélectionne la source de numérisation. Les options valides dépendent des options installées. La valeur par défaut est "Flatbed"

Les types de connexion possibles sont :</p> <dl class="Bl-tag"> <dt id="SCSI_1"><a class="permalink" href="#SCSI_1"><i>SCSI</i></a></dt> <dd>C'est la valeur par défaut, et si rien d'autre n'est spécifié, le logiciel backend ouvrira un chemin donné en tant que périphérique SCSI. Plus d'informations sur la syntaxe valide pour les périphériques SCSI peuvent être trouvées dans <a href='/man/sane-scsi.5.en'>sane-scsi(5)</a>. <br/> Habituellement, les scanners SCSI sont configurés avec une ligne "scsi EPSON" dans ce fichier. Dans certains cas, il peut être nécessaire d'utiliser uniquement la chaîne "scsi" (par exemple, pour le GT-6500).</dd> <dt id="PIO_1"><a class="permalink" href="#PIO_1"><i>PIO - Interface Parallèle</i></a></dt> <dd>L'interface parallèle peut être configurée de deux manières : Une valeur entière commençant au début d'une ligne sera interprétée comme l'adresse d'entrée/sortie du port parallèle. Pour rendre plus clair qu'une adresse d'entrée/sortie configurée est un port parallèle, l'adresse du port peut être précédée de la chaîne "PIO". La connexion PIO n'utilise pas de fichier périphérique spécial dans le répertoire <i>/dev</i>. L'adresse d'entrée/sortie peut être spécifiée en mode hexadécimal (précédé de "0x").</dd> <dt id="USB_1"><a class="permalink" href="#USB_1"><i>USB</i></a></dt> <dd>Un fichier périphérique précédé de la chaîne "USB" est traité comme un scanner connecté via le bus série universel. Le fichier périphérique spécial correct doit être créé avant de pouvoir l'utiliser avec Sane. Voir la documentation USB pour plus d'informations sur la configuration du sous-système USB et des fichiers périphériques requis.</dd> </dl> </section> <section class="Sh"> <h1 class="Sh" id='FICHIERS_1'>FICHIERS <dl class="Bl-tag"> <dt><i>/usr/lib/sane/libsane-epson.a</i></dt> <dd>La bibliothèque statique implémentant ce backend.</dd> <dt><i>/usr/lib/sane/libsane-epson.so</i></dt> <dd>La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).</dd> </dl> </section> <section class="Sh"> <h1 class="Sh" id='ENVIRONNEMENT_1'>ENVIRONNEMENT <dl class="Bl-tag"> <dt id="SANE_DEBUG_EPSON_1"><a class="permalink" href="#SANE_DEBUG_EPSON_1"><b>SANE_DEBUG_EPSON</b></a></dt> <dd>Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Si le backend ne reconnaît pas le niveau de fonction rapporté par le scanner, il utilisera par défaut le niveau de fonction B3. Les niveaux de fonction valides sont A1, A2, B1, B2, B3, B4, B5, B6, B7, B8, D1 et F5.
