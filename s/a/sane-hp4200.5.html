sane-hp4200(5) SANE Scanner Access Now Easy sane-hp4200(5)

NOM

sane-hp4200 - Backend SANE pour les scanners Hewlett-Packard 4200

DESCRIPTION

La librairie sane-hp4200 implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès aux scanners à plat USB Hewlett-Packard suivants :

ScanJet 4200 C
ScanJet 4200 Cxi
ScanJet 4200 Cse

Plus de détails peuvent être trouvés sur la page d'accueil du backend hp4200 : http://hp4200-backend.sourceforge.net/.

Ceci est un logiciel BÊTA. Gardez la main sur le cordon d'alimentation du scanner et débranchez-le si la tête heurte le bord de la zone de balayage.

Si vous possédez un scanner autre que ceux listés ci-dessus qui fonctionne avec ce backend, merci de nous le faire savoir en envoyant le nom exact du modèle du scanner et les identifiants USB du vendeur et du produit (par exemple, depuis /proc/bus/usb/devices, sane-find-scanner(1) ou le syslog) à notre attention. Même si le nom du scanner est légèrement différent des modèles mentionnés ci-dessus, merci de nous en informer.

CONFIGURATION

Le contenu du fichier hp4200.conf est une liste de lignes `usb` contenant les identifiants de vendeur et de produit correspondant aux scanners USB. Le fichier peut également contenir les noms des fichiers de périphériques qui correspondent à un scanner HP 4200. Les lignes vides et les lignes commençant par un signe dièse (#) sont ignorées. Les scanners sont auto-détectés par des instructions usb vendor_id product_id qui sont déjà incluses dans hp4200.conf. « vendor_id » et « product_id » sont des nombres hexadécimaux qui identifient le scanner. Si la détection automatique ne fonctionne pas, ajoutez le nom du périphérique de votre scanner au fichier de configuration, par exemple /dev/usb/scanner0.

FICHIERS

/etc/sane.d/hp4200.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-hp4200.a
La librairie statique implémentant ce backend.
/usr/lib/sane/libsane-hp4200.so
La librairie partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (.) et ensuite dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" résulterait en la recherche des répertoires tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_DEBUG_HP4200
Si la librairie a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_HP4200=4

Testé uniquement sous Linux.

La numérisation est lente en raison du retour arrière.

Envoyez les rapports de bogues à la liste de diffusion sane-devel : sane-devel@alioth-lists.debian.net.
