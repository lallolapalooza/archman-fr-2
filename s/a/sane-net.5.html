sane-net(5) SANE Scanner Access Now Easy sane-net(5)

NOM

sane-net - Backend réseau SANE

DESCRIPTION

La bibliothèque sane-net implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux périphériques d'acquisition d'images via une connexion réseau. Cela permet de contrôler des périphériques connectés à un hôte distant et offre également un moyen d'accorder aux utilisateurs l'accès à des ressources protégées.

NOMS DE PÉRIPHÉRIQUE

Ce backend attend des noms de périphérique du format :

hôte:périphérique

Où hôte est le nom (ou l'adresse IP) de l'hôte (distant) et périphérique est le nom du périphérique sur cet hôte qui doit être adressé. Si le nom du périphérique ne contient pas de deux-points (:), alors toute la chaîne est traitée comme la chaîne périphérique pour l'hôte par défaut. L'hôte par défaut est le dernier hôte listé dans le fichier de configuration (voir ci-dessous).

Une adresse IPv6 peut être spécifiée entre crochets :

[::1]:périphérique

CONFIGURATION

Le fichier net.conf contient à la fois des options du backend et une liste de noms d'hôtes (ou d'adresses IP) qui doivent être contactés pour les requêtes de numérisation. Tout ce qui n'est pas l'une des options listées ci-dessous sera traité comme un nom d'hôte.

connect_timeout = nsecs
Délai d'attente (en secondes) pour la connexion initiale au serveur saned(8). Cela empêchera le backend de bloquer pendant plusieurs minutes en essayant de se connecter à un hôte saned(8) qui ne répond pas (panne réseau, hôte indisponible, ...). La variable d'environnement SANE_NET_TIMEOUT peut également être utilisée pour spécifier le délai d'attente à l'exécution.

Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Notez que les adresses IPv6 dans ce fichier n'ont pas besoin d'être entourées de crochets. Un exemple de fichier de configuration est montré ci-dessous :

scan-server.somedomain.firm
192.168.0.1
# ceci est un commentaire
localhost
::1

La liste d'hôtes ci-dessus peut être étendue à l'exécution en utilisant la variable d'environnement SANE_NET_HOSTS. Cette variable d'environnement est une liste d'hôtes ou d'adresses IP séparés par des deux-points qui doivent être contactés en plus des hôtes mentionnés dans le fichier de configuration. Par exemple, un utilisateur pourrait définir la variable d'environnement avec la chaîne :

new.scanner.com:[::1]:192.168.0.2:scanner.univ.edu

Pour demander que les hôtes new.scanner.com, [::1], 192.168.0.2 et scanner.univ.edu soient contactés en plus des hôtes listés ci-dessus.

Pour que ce backend fonctionne correctement, il est également nécessaire de définir le service sane-port dans /etc/services en utilisant une ligne de la forme suivante :

sane-port 6566/tcp # SANE network scanner daemon

FICHIERS

/etc/sane.d/net.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-net.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-net.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") et ensuite dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_NET_HOSTS
Une liste d'hôtes ou d'adresses IP séparés par des deux-points à contacter par ce backend.
SANE_NET_TIMEOUT
Nombre de secondes d'attente d'une réponse du serveur saned(8) pour la requête de connexion initiale.
SANE_DEBUG_NET
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité.

BOGUES

Si saned(8) a expiré, le backend net peut boucler avec des demandes d'autorisation.
