sackd(8) Démon du Kiosque d'Authentification et de Crédentials Slurm sackd(8)

NOM

sackd - Démon du Kiosque d'Authentification et de Crédentials Slurm.

SYNOPSIS

sackd [OPTIONS...]

DESCRIPTION

sackd est le Démon du Kiosque d'Authentification et de Crédentials Slurm. Il peut être utilisé sur les nœuds de connexion qui n'exécutent pas de démons slurmd pour permettre l'authentification au cluster. Le programme s'exécutera en tant que SlurmdUser. Lors de l'exécution en mode "sans configuration" de Slurm, auquel cas les fichiers de configuration sont récupérés et écrits dans le répertoire /run/slurm/conf (sauf si RUNTIME_DIRECTORY est défini).

OPTIONS

--ca-cert-file <fichier>
Chemin absolu du certificat d'autorité de certification (CA) utilisé pour récupérer la configuration lors de l'exécution sans configuration dans un cluster activé pour TLS.
--conf-server hôte[:port]
Récupère les configurations depuis slurmctld s'exécutant sur hôte[:port]. Nécessite un support de slurmctld fourni en définissant enable_configless dans SlurmctldParameters.
-D
Exécute sackd en avant-plan avec la journalisation copiée sur stderr.
--disable-reconfig
Récupère les configurations en mode sans configuration une seule fois, mais ne s'enregistre pas auprès de slurmctld pour les mises à jour de reconfiguration ultérieures.
-f fichier
Lit la configuration à partir du fichier spécifié.
-h
Aide ; affiche un bref résumé des options de commande.
--jwks-file <fichier>
Lit les informations d'authentification/JWKS de Slurm à partir du fichier spécifié. La valeur par défaut est slurm.jwks situé dans le même répertoire que slurm.conf.
--key-file <fichier>
Lit la clé d'authentification/d'authentification Slurm à partir du fichier spécifié. La valeur par défaut est slurm.key situé dans le même répertoire que slurm.conf.
--port nombre
Numéro de port de la socket pour écouter les mises à jour de reconfiguration. Ceci peut être utile lorsque plusieurs sackd coexistent sur le même nœud de connexion. La valeur par défaut est SlurmdPort.
--systemd
À utiliser lorsqu'il est démarré à partir d'un fichier d'unité systemd.
-v
Mode verbeux. Plusieurs -v augmentent la verbosité.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour remplacer les paramètres compilés dans sackd.

ABORT_ON_FATAL
Lorsqu'une erreur fatale est détectée, utilise abort() au lieu de exit() pour terminer le processus. Cela permet de capturer les traces de pile sans recompiler Slurm.
RUNTIME_DIRECTORY
Chemin absolu régissant l'emplacement du cache de configuration que sackd maintient, et du socket Unix sack.socket utilisé pour fournir les services d'authentification.

Si plusieurs sackd doivent être démarrés sur le même nœud de connexion, l'option d'unité systemd RuntimeDirectory doit être définie sur slurm-<nom_du_cluster>. Systemd v240+ définit automatiquement RUNTIME_DIRECTORY sur /run/$RuntimeDirectory pour chaque service sackd, sinon elle nécessite une définition manuelle (c'est-à-dire via l'option d'unité EnvironmentFile).

Si elle n'est pas définie, la valeur par défaut est /run/slurm/.

SACKD_DEBUG
Définit explicitement le niveau de débogage pour syslog et stderr. Les valeurs valides sont 0-9, ou les mêmes valeurs textuelles que les options de débogage telles que SlurmctldDebug dans slurm.conf(5).
SACKD_DISABLE_RECONFIG
Identique à --disable-reconfig.
SACKD_PORT
Identique à --port.
SACKD_STDERR_DEBUG
Définit explicitement le niveau de débogage pour stderr. Les valeurs valides sont 0-9, ou les mêmes valeurs textuelles que les options de débogage telles que SlurmctldDebug dans slurm.conf(5).
SACKD_SYSLOG_DEBUG
Définit explicitement le niveau de débogage pour syslog. Les valeurs valides sont 0-9, ou les mêmes valeurs textuelles que les options de débogage telles que SlurmctldDebug dans slurm.conf(5).
SLURM_CONF
L'emplacement du fichier de configuration Slurm.
SLURM_DEBUG_FLAGS
Spécifie les indicateurs de débogage à utiliser par sackd. Voir DebugFlags dans la page de manuel slurm.conf(5) pour une liste complète des indicateurs. La variable d'environnement a priorité sur le paramètre de slurm.conf.

SIGNALS

SIGINT
sackd s'arrêtera proprement.
SIGHUP
sackd se reconfigurera.
SIGUSR2 SIGPIPE
Ce signal est explicitement ignoré.
