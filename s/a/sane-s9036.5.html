sane-s9036(5) SANE Scanner Access Now Easy sane-s9036(5)

NOM

sane-s9036 - Backend SANE pour les scanners à plat Siemens 9036

DESCRIPTION

La bibliothèque sane-s9036 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat Siemens 9036.

NOMS DE PÉRIPHÉRIQUE

Ce backend s'attend à des noms de périphérique de la forme :

spécial

Où spécial est le nom de chemin du périphérique spécial qui correspond à un scanner SCSI. Le nom du périphérique spécial doit être un périphérique SCSI générique ou un lien symbolique vers un tel périphérique. Le programme sane-find-scanner(1) aide à trouver le périphérique correct. Sous Linux, un tel nom de périphérique pourrait être /dev/sga ou /dev/sge, par exemple. Voir sane-scsi(5) pour plus de détails.

FICHIERS

/etc/sane.d/s9036.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-s9036.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-s9036.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:`), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires spécifiés explicitement. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour résultat la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_S9036
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_S9036=4

VOIR AUSSI

sane(7), sane-scsi(5)
