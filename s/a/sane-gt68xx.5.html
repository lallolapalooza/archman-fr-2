sane-gt68xx(5) SANE Scanner Access Now Easy sane-gt68xx(5)

NOM

sane-gt68xx - Backend SANE pour scanners à plat USB basés sur GT-68XX

DESCRIPTION

La bibliothèque sane-gt68xx implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat USB basés sur les puces Grandtech GT-6801 et GT-6816. Une liste des scanners pris en charge peut être trouvée sur la page d'accueil du backend gt68xx : http://www.meier-geinitz.de/sane/gt68xx-backend/.

Ceci est un logiciel BÊTA. Particulièrement si vous testez des scanners nouveaux ou non testés, gardez la main sur la prise du scanner et débranchez-la si la tête heurte la fin de la zone de balayage.

Si vous possédez un scanner autre que ceux listés sur la page d'accueil gt68xx qui fonctionne avec ce backend, veuillez me le faire savoir en m'envoyant le nom exact du modèle du scanner et les identifiants USB du fabricant et du produit (par exemple, depuis sane-find-scanner(1) ou syslog). Même si le nom du scanner est seulement légèrement différent des modèles déjà listés comme pris en charge, veuillez me le faire savoir.

Si vous possédez un scanner qui n'est pas détecté par le backend gt68xx mais qui possède un chipset GT-6801 ou GT-6816, vous pouvez essayer de l'ajouter au backend. Jetez un œil à la page web suivante : http://www.meier-geinitz.de/sane/gt68xx-backend/adding.html

PROBLEMES LIBUSB

Veuillez utiliser libusb-0.1.8 ou une version ultérieure. Sans libusb ou avec des versions plus anciennes de libusb, toutes sortes de problèmes peuvent être attendus. Le scanner devrait être trouvé par sane-find-scanner(1) sans actions supplémentaires. Pour la définition des permissions et des informations USB générales, regardez sane-usb(5).

FICHIER FIRMWARE

Vous avez besoin d'un fichier firmware pour votre scanner. C'est un petit fichier contenant un logiciel qui sera téléchargé dans la mémoire du scanner. Il est généralement nommé *.usb, par exemple PS1fw.usb. Il provient du CD d'installation fourni par le fabricant, mais il peut être empaqueté avec le programme d'installation dans un fichier .exe. Pour les scanners Mustek, le fichier peut être téléchargé depuis la page d'accueil du backend gt68xx. Pour d'autres scanners, vérifiez le CD pour les fichiers .usb. Si vous ne trouvez que des fichiers *.cab, essayez cabextract(1) pour décompresser. Si tout le reste échoue, vous devez installer le pilote Windows et obtenir le firmware à partir de là (généralement dans les répertoires windows/system ou system32). Placez ce fichier firmware dans /usr/share/sane/gt68xx/. Assurez-vous qu'il est lisible par tout le monde.

CONFIGURATION

Le contenu du fichier gt68xx.conf est une liste de lignes usb contenant des identifiants de fabricant et de produit qui correspondent aux scanners USB. Le fichier peut également contenir des lignes d'options. Les lignes vides et les lignes commençant par un croisillon (#) sont ignorées. Les scanners sont auto-détectés par les instructions usb vendor_id product_id qui sont déjà incluses dans gt68xx.conf. "vendor_id" et "product_id" sont des nombres hexadécimaux qui identifient le scanner.

Les options override, firmware, vendor, model et afe doivent être placées après la ligne usb à laquelle elles se réfèrent.

L'option override est utilisée pour remplacer les paramètres du modèle par défaut. C'est nécessaire pour certains scanners qui utilisent les mêmes identifiants de fabricant/produit mais qui sont différents. Pour ces scanners, il existe déjà des lignes de remplacement commentées dans le fichier de configuration. override mustek-scanexpress-1200-ub-plus est nécessaire pour le Mustek Scanexpress 1200 UB Plus, le Medion/Lifetec/Tevion LT 9452 et le Trust Compact Scan USB 19200. override artec-ultima-2000 est utilisé pour l'Artec Ultima 2000, le Boeder SmartScan Slim Edition, le Medion/Lifetec/Tevion/Cytron MD/LT 9385, le Medion/Lifetec/Tevion MD 9458 et le Trust Flat Scan USB 19200. override mustek-bearpaw-2400-cu est nécessaire pour le Mustek BearPaw 2400 CU et le Fujitsu 1200CUS. L'option override doit être la première après la ligne usb.

L'option firmware sélectionne le nom et le chemin du fichier firmware. Elle n'est nécessaire que si le défaut (ou le remplacement) ne fonctionne pas. Le répertoire firmware par défaut est /usr/share/sane/gt68xx/. Vous devrez peut-être créer ce répertoire. Si vous souhaitez placer les fichiers firmware à un chemin différent, utilisez une ligne firmware.

Les options vendor et model ne sont pas absolument nécessaires mais par souci de commodité. Pas mal de scanners de différents fabricants partagent les mêmes identifiants fabricant/produit, vous pouvez donc définir le "bon" nom ici.

L'option afe permet de définir des valeurs personnalisées de décalage (offset) et de gain pour le Front End Analogique (Analog Front End) du scanner. Cette option peut être utilisée soit pour sélectionner les valeurs AFE si la calibration grossière automatique est désactivée, soit pour accélérer la calibration grossière automatique. Pour cette dernière utilisation, activez le niveau de débogage 3 (voir ci-dessous), scannez une image et recherchez la ligne de débogage contenant "afe". Copiez cette ligne dans gt68xx.conf. L'option a six paramètres : décalage rouge, gain rouge, décalage vert, gain vert, décalage bleu et gain bleu.

Un exemple de fichier de configuration est montré ci-dessous :

usb 0x05d8 0x4002
override "mustek-scanexpress-1200-ub-plus"
firmware "/opt/gt68xx/SBfw.usb"
vendor "Trust"
model "Compact Scan USB 19200"
afe 0x20 0x02 0x22 0x03 0x1f 0x04

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour résultat de rechercher les répertoires tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_DEBUG_GT68XX
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie. Si le niveau de débogage est défini à 1 ou plus, certaines options de débogage deviennent disponibles et sont normalement cachées. Manipulez-les avec précaution.

Exemple : export SANE_DEBUG_GT68XX=4

BUGS

The first few lines of the image are garbage for the 2400 TA Plus.

Interpolation should be used instead of just copying data, when the X- and Y-resolution differ.

Support for buttons is missing.

More detailed bug information is available at the gt68xx backend homepage http://www.meier-geinitz.de/sane/gt68xx-backend/.
Please contact us if you find a bug or missing feature: <sane-devel@alioth-lists.debian.net>.
Please send a debug log if your scanner isn't detected correctly (see SANE_DEBUG_GT68XX above).
