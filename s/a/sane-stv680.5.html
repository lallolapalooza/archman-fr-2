NOM

sane-stv680 - Backend SANE pour les caméras STV680

DESCRIPTION

La librairie sane-stv680 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à certaines caméras STV680. Ce backend doit être considéré comme un logiciel de qualité bêta ! Les caméras STV680 sont vendues sous diverses marques comme Aiptek. Ce backend peut ou non supporter la vôtre.

Les caméras qui devraient fonctionner avec ce backend sont :

Vendeur Modèle           ID vendeur USB  ID produit USB  statut
------------------------  -------------  --------------  --------
AIPTEK stv680                0x0553         0x0202       basique
Konica e-mini                0x04c8         0x0722       non testé
DigitalDream l'espion XS     0x1183         0x0001       non testé
Creative WebCam Go mini      0x041e         0x4007       non testé

Pour toutes ces caméras, consultez la page d'accueil du backend (sous AUTEUR) pour connaître le statut exact de chaque caméra.

Pour démarrer ce backend, vérifiez que le module noyau stv680, s'il est présent, est supprimé ou désactivé.
De plus, avant utilisation, activez le backend en éditant le fichier /etc/sane.d/dll.conf, remplacez #stv680 par stv680.

Pour les problèmes avec les caméras non testées, vous devriez contacter l'auteur.

Les options que le backend supporte peuvent être sélectionnées soit via les options de ligne de commande des programmes comme scanimage(1), soit via les éléments graphiques dans xcam(1). Pour les deux programmes, utilisez l'option -B nécessaire pour la taille du buffer.

Quelques exemples de frontends :

xcam(1)

xcam -B

scanimage(1) : pour écrire en mode batch dans un fichier ou dans un nouveau fichier à chaque fois :

scanimage -B -d stv680:libusb:001:002 --batch=out.ppm --batch-count 5 --mode "Color RGB"
scanimage -B -d stv680:libusb:001:002 --batch=out%d.ppm --batch-count 5 --mode "Color RGB"

Si vous obtenez des résultats avec une caméra non listée ici, ou si vous observez un comportement étrange, veuillez le signaler au mainteneur du backend ou à la liste de diffusion SANE.

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant :

scanimage --help -d stv680
Mode de Scan
--mode
sélectionne le mode de fonctionnement de base de la webcam parmi les choix valides.

Le mode de résolution lu est de 8 bits, la résolution de sortie est de 24 bits. Sélectionne la résolution pour un scan. La caméra ne peut faire que les résolutions listées.

--Raw
Dans ce mode, les données brutes sont affichées
--Color
Dans ce mode, le désentrelacement Bayer est effectué mais aucune correction de couleur
--Color_RGB
Désentrelacement Bayer, correction de couleur
--Color_RGB_TXT
Désentrelacement Bayer, correction de couleur, ligne de texte avec date et heure ajoutée
Options d'amélioration
--white-level-r -32..+32
Sélectionne quel niveau de radiance rouge doit être considéré comme "blanc", lors du scan de certaines feuilles en modifiant la valeur de calibration chargée dans le scanner. Échelle -32 .. 0 .. +32 par pas de 1.
--white-level-g -32..+32
Sélectionne quel niveau de radiance verte doit être considéré comme "blanc", lors du scan de certaines feuilles en modifiant la valeur de calibration chargée dans le scanner. Échelle -32 .. 0 .. +32 par pas de 1.
--white-level-b -32..+32
Sélectionne quel niveau de radiance bleue doit être considéré comme "blanc", lors du scan de certaines feuilles en modifiant la valeur de calibration chargée dans le scanner. Échelle -32 .. 0 .. +32 par pas de 1.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/stv680.conf ne supporte qu'un seul élément : le nom du périphérique à utiliser (par ex. usb 0x.... 0x....).

FICHIERS

/usr/lib/sane/libsane-stv680.a
La librairie statique implémentant ce backend.
/usr/lib/sane/libsane-stv680.so
La librairie partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_STV680
Si la librairie a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'impression de toutes les sorties de débogage. Des niveaux plus petits réduisent la verbosité.

LIMITATIONS

Le pilote TWAIN pour Windows a beaucoup plus d'options que ce backend SANE. Cependant, ce sont seulement des ajustements logiciels. Ce backend implémente uniquement ce que la webcam peut supporter.

BOGUES

Beaucoup. Certaines parties de ce backend sont encore en développement.
1. Certaines caméras non testées.
2. Streaming vidéo lent et s'arrête parfois (scanimage).
3. Parfois 1/3 de l'image est KO (xcam).
