sane-nec(5) SANE Scanner Access Now Easy sane-nec(5)

NOM

sane-nec - Backend SANE pour scanners NEC

DESCRIPTION

La bibliothèque sane-nec implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès aux scanners SCSI NEC. Ce backend doit être considéré comme un logiciel de qualité alpha ! Dans son état actuel, il est connu pour fonctionner avec les scanners PC-IN500/4C. Les autres scanners de la série MultiReader ne sont pas supportés. Les scanners PC-IN 500/4C et MultiReader ne sont vendus qu'au Japon (sauf le Multi Reader PetiScan).

Pour les autres scanners, cela peut fonctionner ou non.

Le backend présente les problèmes connus suivants :

- Le mode Couleur/Lineart n'est pas supporté.
- Le nom de l'appareil est fixé à /dev/scanner

Actuellement, les scanners suivants sont connus pour fonctionner avec ce backend.

Vendeur Produit id
------ -----------
NEC    PC-IN500/4C

FICHIERS

/etc/sane.d/nec.conf
Le fichier de configuration du backend.
/usr/lib/sane/libsane-nec.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-nec.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_NEC
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux plus petits réduisent la verbosité.

VOIR AUSSI

sane(7), sane-scsi(5)
