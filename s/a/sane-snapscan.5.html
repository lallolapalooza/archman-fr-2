sane-snapscan(5) Accès facile aux scanners SANE sane-snapscan(5)

NOM

sane-snapscan - Backend SANE pour scanners à plat AGFA SnapScan

DESCRIPTION

La bibliothèque sane-snapscan implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat AGFA SnapScan. Actuellement, les scanners suivants sont pris en charge par ce backend : AGFA SnapScan 300, 310, 600 et 1236s, 1236u, 1212u, e20, e25, e40, e50, e60, Vuego 310s, Acer 300f, 310s, 610s, 610plus, Prisa 620s, Prisa 620u, Prisa 620ut, Prisa 640u, Prisa 640bu, Prisa 1240, Prisa 3300, Prisa 4300, Prisa 5300 et Guillemot Maxi Scan A4 Deluxe (SCSI) (avec succès variable).

NOMS DE PÉRIPHÉRIQUE

Ce backend attend des noms de périphérique de la forme :

spécial

Où spécial est le chemin d'accès au périphérique spécial correspondant à un scanner SCSI. Pour les scanners SCSI, le nom du périphérique spécial doit être un périphérique SCSI générique ou un lien symbolique vers un tel périphérique. Sous Linux, un tel nom de périphérique pourrait être par exemple /dev/sga ou /dev/sge. Voir sane-scsi(5) pour plus de détails.

Pour les scanners USB, le nom du périphérique doit contenir le mot-clé "usb", comme dans /dev/usbscanner ou /dev/usb/scanner0. Pour les scanners qui nécessitent un téléchargement de firmware avant la numérisation, ajoutez une ligne commençant par "firmware" suivie du chemin complet de votre fichier de firmware, par exemple :

firmware /usr/share/sane/snapscan/firmware.bin

Pour plus de détails, lisez http://snapscan.sourceforge.net.

CONFIGURATION

Le contenu du fichier snapscan.conf est une liste de noms de périphériques correspondant aux scanners SnapScan. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Voir sane-scsi(5) pour les détails sur ce qui constitue un nom de périphérique valide.

FICHIERS

/etc/sane.d/snapscan.conf
Le fichier de configuration du backend (voir également la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-snapscan.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-snapscan.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_DEBUG_SNAPSCAN
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 255 demande l'impression de toutes les sorties de débogage. Des niveaux inférieurs réduisent la verbosité.
