NOM

sakura - Un émulateur de terminal simple mais puissant basé sur libvte.

SYNTAXE

sakura [options...]

DESCRIPTION

sakura est un émulateur de terminal basé sur GTK+ et VTE. C'est un émulateur de terminal avec peu de dépendances, vous n'avez donc pas besoin d'un bureau GNOME complet installé pour avoir un émulateur de terminal décent.

OPTIONS D'AIDE

-?, --help
Afficher les options d'aide.
--help-all
Afficher toutes les options d'aide.
--help-gtk
Afficher les options GTK+.

OPTIONS DE L'APPLICATION

-v, --version
Afficher le numéro de version.
-f, --font
Sélectionner la police de caractères initiale du terminal.
-n, --ntabs
Sélectionner le nombre initial d'onglets.
-x, --execute
Exécuter une commande.
-e, --xterm-execute
Exécuter une commande (compatible avec l'option -e de xterm).
-l, --login
Shell de connexion.
-c, --columns
Définir le nombre de colonnes.
-r, --rows
Définir le nombre de lignes.
-h, --hold
Maintenir la fenêtre après l'exécution de la commande.
-d, --working-directory
Définir le répertoire de travail.
-m, --maximize
Maximiser la fenêtre.
-s, --fullscreen
Mode plein écran.
--display=DISPLAY
Affichage X à utiliser.
--config-file=FILENAME
Utiliser un fichier de configuration alternatif. Le chemin est relatif au répertoire de configuration de sakura. (Exemple : ~/.config/sakura/FILENAME).

OPTIONS GTK+

--class=CLASS
Classe du programme telle qu'utilisée par le gestionnaire de fenêtres.
--name=NAME
Nom du programme tel qu'utilisé par le gestionnaire de fenêtres.
--screen=SCREEN
Écran X à utiliser.
--sync
Rendre les appels X synchrones.
--gtk-module=MODULES
Charger des modules GTK+ supplémentaires.
--g-fatal-warnings
Rendre tous les avertissements fatals.

CONFIGURATION

show_tab_bar=[always | multiple | never]
Cette liste d'options est actuellement incomplète.

SUPPORT DES RACCOURCIS CLAVIER

sakura prend en charge les raccourcis clavier. Ils sont configurables en définissant les propriétés suivantes dans votre fichier de configuration sakura (~/.config/sakura/sakura.conf).

ACCÉLÉRATEURS

Les accélérateurs peuvent être définis sur n'importe quelle valeur de masque de GdkModifierType dans gdktypes.h ; voir :

http://gtk.php.net/manual/en/html/gdk/gdk.enum.modifiertype.html

Les valeurs de masque peuvent être combinées en utilisant l'opérateur OU.

Par exemple, pour définir l'accélérateur de suppression d'onglet sur Ctrl + Maj :

del_tab_accelerator=5

car GDK_SHIFT_MASK a une valeur de 1 (1 << 0), et GDK_CONTROL_MASK a une valeur de 4 (1 << 2) ; en les combinant avec OU, vous obtenez 5.

Je réalise que cette configuration n'est pas très conviviale pour les non-programmeurs, mais c'est un début. :)

TOUCHES

Par exemple, pour définir la touche d'ajout d'onglet sur « T » :

add_tab_key=T

Auparavant, sakura utilisait des codes de touches au lieu de chaînes de caractères. Ils sont toujours valides.

PAR DÉFAUT

Ctrl + Maj + T                 -> Nouvel onglet
Ctrl + Maj + W                 -> Fermer l'onglet actuel
Ctrl + Maj + C                 -> Copier le texte sélectionné
Ctrl + Maj + V                 -> Coller le texte sélectionné
Ctrl + Flèche gauche           -> Onglet précédent
Ctrl + Flèche droite           -> Onglet suivant
Ctrl + [1-9]                   -> Basculer vers l'onglet N (1-9)
Ctrl + Maj + S                 -> Basculer la barre de défilement
Ctrl + Bouton gauche de la souris Maj  -> Ouvrir un lien
F11                            -> Plein écran
Maj + Page précédente         -> Monter dans la zone de défilement par page
Maj + Page suivante           -> Descendre dans la zone de défilement par page
Ctrl + Maj + Haut              -> Monter dans la zone de défilement par ligne
Ctrl + Maj + Bas               -> Descendre dans la zone de défilement par ligne

Vous pouvez également augmenter et diminuer la taille de la police de la manière standard GTK+ (non configurable) :

Ctrl + '+'                     -> Augmenter la taille de la police
Ctrl + '-'                     -> Diminuer la taille de la police

BOGUES

sakura est hébergé sur Launchpad. Les bogues peuvent être signalés à :

https://bugs.launchpad.net/sakura
