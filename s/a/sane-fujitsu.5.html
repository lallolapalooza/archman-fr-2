sane-fujitsu(5) SANE Scanner Access Now Easy sane-fujitsu(5)

NOM

sane-fujitsu - backend SANE pour les scanners Fujitsu et Ricoh de la série fi

DESCRIPTION

La bibliothèque sane-fujitsu implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à la plupart des scanners à plat et ADF Fujitsu, ainsi qu'aux modèles Ricoh ultérieurs.

Ce document décrit la version 140 du backend.

MATÉRIEL SUPPORTÉ

Cette version prend en charge tous les modèles connus qui communiquent via les protocoles SCSI et SCSI-sur-USB de Fujitsu. Spécifiquement, les scanners des séries SCSI M309x et M409x, les scanners SCSI série fi, et la plupart des scanners USB des séries fi, ScanSnap et iX sont pris en charge. Veuillez consulter la liste à l'adresse http://www.sane-project.org/sane-supported-devices.html pour plus de détails.

Ce backend peut prendre en charge d'autres scanners Fujitsu ou des scanners Ricoh plus récents. Le meilleur moyen de déterminer le niveau de prise en charge est de tester directement le scanner, ou de collecter une trace du pilote Windows en action. Veuillez contacter l'auteur pour obtenir de l'aide ou pour partager des résultats de test.

MATÉRIEL NON SUPPORTÉ

Les scanners suivants sont connus pour NE PAS fonctionner avec ce backend, soit parce qu'ils ont un chipset non pris en charge, soit un type d'interface non pris en charge. Certains de ces scanners peuvent être pris en charge par un autre backend.

OPTIONS

Des efforts ont été faits pour exposer toutes les options matérielles, y compris :

source s

Sélectionne la source pour le scan. Les options peuvent inclure « Flatbed », « ADF Front », « ADF Back », « ADF Duplex », « Card Front », « Card Back », « Card Duplex ».

mode m

Sélectionne le mode pour le scan. Les options peuvent inclure « Lineart », « Halftone », « Gray » et « Color ».

resolution, y-resolution

Contrôle la résolution du scan. La définition de --resolution définit également --y-resolution, bien que ce comportement soit remplacé par certains frontends.

tl-x, tl-y, br-x, br-y

Définit les coordonnées du coin supérieur gauche et inférieur droit de la zone de scan. Celles-ci sont renommées t, l, x, y par certains frontends.

page-width, page-height

Définit la taille du papier. Utilisé par le scanner pour déterminer le centrage des coordonnées de scan lors de l'utilisation de l'ADF (Alimentateur Automatique de Documents) et pour détecter les erreurs de double alimentation.

D'autres options seront disponibles en fonction des capacités du scanner : les machines dotées d'IPC ou de DTC auront des options d'amélioration supplémentaires, celles dotées de CMP auront des options de compression, celles dotées d'une imprimante auront un groupe d'options d'endosseur.

De plus, plusieurs options « logicielles » sont exposées par le backend. Il s'agit de réimplémentations de fonctionnalités fournies nativement par de plus grands scanners, mais exécutées sur l'ordinateur hôte. Cela permet aux machines plus petites d'avoir des capacités similaires. Veuillez noter que ces fonctionnalités sont quelque peu simplistes et peuvent ne pas être aussi performantes que les implémentations natives. Notez également que toutes ces fonctionnalités nécessitent que le pilote mette en cache l'image entière en mémoire. Cela entraînera presque certainement une réduction de la vitesse de numérisation.

swcrop

Demande au pilote de détecter les extrémités du papier dans l'image plus grande et de recadrer les bords vides.

swdeskew

Demande au pilote de détecter la rotation du papier dans l'image plus grande et de contrer la rotation.

swdespeck X

Demande au pilote de trouver et de supprimer les points d'un diamètre X ou inférieur de l'image, et de remplir l'espace avec la couleur environnante moyenne.

Utilisez 'scanimage --help' pour obtenir une liste, mais sachez que certaines options peuvent n'être configurables que lorsqu'une autre option a été définie, et que les options avancées peuvent être masquées par certains programmes frontends.

FICHIER DE CONFIGURATION

Le fichier de configuration fujitsu.conf est utilisé pour indiquer au backend comment rechercher les scanners, et fournir des options contrôlant le fonctionnement du backend. Ce fichier est lu à chaque fois que le frontend demande au backend une liste de scanners, généralement uniquement lorsque le frontend démarre. Si le fichier de configuration est manquant, le backend ne pourra trouver aucun scanner.

Les scanners peuvent être spécifiés dans le fichier de configuration de 4 manières :

"scsi FUJITSU"

Demande au backend de rechercher sur tous les bus SCSI du système un appareil qui s'identifie comme un scanner fabriqué par 'FUJITSU'.

"scsi /dev/sg0" (ou autre fichier de périphérique SCSI)

Demande au backend d'ouvrir le périphérique SCSI nommé. Utile uniquement si vous avez plusieurs scanners compatibles connectés à votre système et que vous devez en spécifier un. Ne devrait probablement pas être utilisé avec l'autre ligne « scsi » ci-dessus.

"usb 0x04c5 0x1042" (ou autres identifiants vendeur/produit)

Demande au backend de rechercher sur tous les bus USB du système un appareil utilisant cet identifiant vendeur et produit. L'appareil sera ensuite interrogé pour déterminer s'il s'agit d'un scanner pris en charge.

"usb /dev/usb/scanner0" (ou autre fichier de périphérique)

Certains systèmes utilisent un pilote noyau pour accéder aux scanners USB. Cette méthode n'est pas testée.

La seule option de configuration prise en charge est "buffer-size=xxx", vous permettant de définir le nombre d'octets dans le tampon de données sur autre chose que la valeur par défaut compilée, 65536 (64 Ko). Certains utilisateurs signalent que leur scanner se « bloque » à mi-page, ou ne parvient pas à transmettre l'image si le tampon n'est pas assez grand.

Note : Cette option peut apparaître plusieurs fois dans le fichier de configuration. Elle ne s'applique qu'aux scanners découverts par les lignes 'scsi/usb' qui suivent cette option.

Note : Le backend ne place pas de limite supérieure à cette valeur, car certains utilisateurs ont nécessité qu'elle soit assez grande. Les valeurs supérieures à la valeur par défaut ne sont pas recommandées et peuvent planter votre système d'exploitation ou bloquer votre pilote de carte SCSI. Vous êtes averti.

ENVIRONNEMENT

Le backend utilise une seule variable d'environnement, SANE_DEBUG_FUJITSU, qui active la sortie de débogage sur stderr. Les valeurs valides sont :

5 Erreurs
10 Trace des fonctions
15 Détails des fonctions
20 Commandes d'options
25 Trace SCSI/USB
30 Écritures SCSI/USB
31 Lectures SCSI/USB
35 Bruit inutile

PROBLÈMES CONNUS

Les unités à plat peuvent ne pas scanner à la zone maximale, particulièrement à haute résolution.

Tout modèle qui ne prend pas en charge le VPD lors de l'interrogation ne fonctionnera pas tant qu'une dérogation ne sera pas ajoutée au backend.

La compression de fax CCITT utilisée par les scanners plus anciens n'est pas prise en charge.

La sortie JPEG est prise en charge par le backend, mais pas par le protocole SANE, elle est donc désactivée dans cette version. Elle peut être activée si vous recompilez à partir des sources.

Les interfaces réseau ne sont prises en charge sur aucun modèle de scanner.

sane-fujitsu.5.en — Arch manual pages

NAME

sane-fujitsu

Fujitsu backend for SANE

DESCRIPTION

The sane-fujitsu is a backend for the SANE (Scanner Access Now Easy) API that supports various Fujitsu scanners.

This backend supports scanners connected via USB and SCSI. A full list of supported scanners is available in the documentation.

SUPPORTED HARDWARE

The following Fujitsu scanners are known to work with this backend:

USB scanners:

ScanPartner 600C, ScanSnap S1500, ScanSnap S1500M, ScanSnap S300M, ScanSnap S300, fi-5015C, fi-60F, fi-6110, fi-6140, fi-6240, fi-5530C2, fi-6000CS, fi-4340C, fi-5900C, fi-6800, fi-6400, fi-5750C, fi-5650C, fi-6770, fi-6770A, fi-6750S, fi-6750W, fi-6400, fi-65F, fi-4110C, fi-4120C, fi-4120CU, fi-4220C, fi-4220CU, fi-6010N, fi-5015C, fi-5110C, fi-5120C, fi-5120CU, fi-5220C, fi-5220CU, fi-6125C, fi-6130, fi-6130Z, fi-6225C, fi-6230, fi-6230Z, fi-4010C, fi-4110CU, fi-4120CU, fi-4220CU, fi-4010C, fi-5110C, fi-5120C, fi-5120CU, fi-5220C, fi-5220CU, fi-4110C, fi-4120C, fi-4120CU, fi-4220C, fi-4220CU, fi-4110CU, fi-4120CU, fi-4220CU.

SCSI scanners:

fi-4120C, fi-4120CU, fi-4220C, fi-4220CU, fi-5110C, fi-5120C, fi-5120CU, fi-5220C, fi-5220CU, fi-5530C, fi-5530C2, fi-5650C, fi-5750C, fi-5900C.

For a complete list of tested scanners, please refer to the sane-fujitsu documentation.

UNSUPPORTED HARDWARE

The following scanners are not supported by this backend:

ScanAce 1200, ScanAce 300, ScanExpress SC-420C, ScanExpress SC-600C.

The configuration file for this backend is located at ~/.config/sane/fujitsu.conf. It allows you to specify default options for your scanner.
