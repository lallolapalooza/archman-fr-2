NOM

sasldblistusers2 - lister les utilisateurs dans sasldb

SYNOPSIS

sasldblistusers2 [-f fichier] [-v]

DESCRIPTION

sasldblistusers2 est utilisé pour lister les utilisateurs dans la base de données des mots de passe SASL (généralement /etc/sasldb2). Cela ne listera PAS tous les utilisateurs de /etc/passwd, shadow, PAM, etc., seulement ceux créés par SASL (via saslpasswd2).

OPTIONS

-f fichier
utiliser fichier pour sasldb
-v
Afficher le numéro de version de libsasl2 et quitter.

VOIR AUSSI

saslpasswd2(8)

7 mars 2005 CMU SASL
