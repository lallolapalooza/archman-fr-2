NOM

sane-epson2 - Backend SANE pour scanners EPSON

DESCRIPTION

La bibliothèque sane-epson2 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat Epson. Cette bibliothèque prend en charge un ensemble d'appareils similaire au pilote sane-epson, mais a été développée pour prendre en charge un éventail plus large de connexions au scanner, y compris l'accès réseau.

Étant donné que les pilotes sane-epson et sane-epson2 prennent en charge bon nombre des mêmes appareils, si un pilote vous pose des problèmes, vous pouvez essayer de le désactiver pour essayer l'autre. Cela peut être fait en supprimant le nom du pilote de dll.conf ou peut-être en commentant les options dans epson.conf ou epson2.conf.

OPTIONS

Les options prises en charge par le backend peuvent être sélectionnées soit via les options de ligne de commande des programmes comme scanimage(1), soit via les éléments de l'interface graphique des programmes comme xscanimage(1) ou xsane(1).

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant

scanimage --help -d epson2

Tous les appareils ne prennent pas en charge toutes les options.

Mode de balayage
Le commutateur --mode sélectionne le mode de fonctionnement de base du scanner. Les choix valides sont Binaire, Niveaux de gris et Couleur. Le mode binaire n'est que noir et blanc, le mode niveaux de gris produira 256 niveaux de gris ou plus selon le scanner et Couleur signifie 24 bits en mode couleur ou plus selon le scanner. Certains scanners utiliseront en interne 36 bits en couleur, mais leur interface externe peut ne prendre en charge que 24 bits.

L'option --depth sélectionne la profondeur de bits utilisée par le scanner. Cette option n'est disponible que pour les scanners qui prennent en charge plus d'une profondeur de bits. Les anciens scanners transféreront toujours l'image en mode 8 bits. Les scanners plus récents permettent de sélectionner soit 8 bits, 12 ou 14 bits par canal de couleur. Pour un balayage en couleur, cela signifie une profondeur de couleur effective de 36 ou 42 bits sur les trois canaux. Les choix valides dépendent du modèle de scanner.

Le commutateur --halftoning sélectionne le mode utilisé en mode binaire. Les options valides sont "None", "Halftone A (Hard Tone)", "Halftone B (Soft Tone)", "Halftone C (Net Screen)", "Dither A (4x4 Bayer)", "Dither B (4x4 Spiral)", "Dither C (4x4 Net Screen)", "Dither D (8x4 Net Screen)", "Text Enhanced Technology", "Download pattern A" et "Download pattern B".

Le commutateur --dropout sélectionne la couleur dite de renvoi. Les options valides sont Aucun, Rouge, Vert et Bleu. La valeur par défaut est Aucun. La couleur de renvoi est utilisée pour la numérisation monochrome et sélectionne la couleur qui n'est pas numérisée. Cela peut être utilisé pour, par exemple, numériser un original avec un arrière-plan coloré.

Le commutateur --brightness contrôle la luminosité du balayage. Les options valides sont des valeurs entières allant de -3 à 3. La valeur par défaut est 0. Plus la valeur de luminosité est élevée, plus l'image devient lumineuse. Si une table définie par l'utilisateur pour la correction gamma est sélectionnée, le paramètre de luminosité n'est pas disponible.

Le commutateur --sharpness définit la netteté des données d'image. Les options valides sont des valeurs entières allant de -2 à 2, -2 signifiant "Défocalisé", -1 "Légèrement défocalisé", 0 "Normal", 1 "Légèrement net" et 2 "Net".

Le commutateur --gamma-correction contrôle la correction gamma interne du scanner. Les options valides sont "Default", "User defined", "High density printing", "Low density printing" et "High contrast printing".

Le commutateur --color-correction contrôle la fonction de correction des couleurs interne du scanner. Les options valides sont "No Correction", "Impact-dot printers", "Thermal printers", "Ink-jet printers" et "CRT monitors". La valeur par défaut est "CRT monitors".

Le commutateur --resolution sélectionne la résolution pour un balayage. Certains scanners EPSON numériseront à n'importe quelle résolution entre la valeur la plus basse et la plus haute possible. La liste signalée par le scanner peut être affichée en utilisant les paramètres "--help -d epson" de scanimage(1).

Le commutateur --threshold sélectionne la luminosité minimale pour obtenir un point blanc.

L'option --mirror contrôle la façon dont l'image est balayée. En lisant les données de l'image de droite à gauche, l'image est renversée. Les options valides sont "yes" et "no". La valeur par défaut est "no".

Le commutateur --auto-area-segmentation active la segmentation automatique de la zone pour les balayages monochromes. Le scanner essaiera de déterminer quelles zones sont du texte et quelles contiennent des images. Les zones d'image seront tramées et le texte sera amélioré. Les options valides sont "yes" et "no". La valeur par défaut est "yes".

Le paramètre --red-gamma-table peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal rouge. Les options valides sont les mêmes que pour --gamma-table.

Le paramètre --green-gamma-table peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal vert. Les options valides sont les mêmes que pour --gamma-table.

Le paramètre --blue-gamma-table peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal bleu. Les options valides sont les mêmes que pour --gamma-table.

Le paramètre --wait-for-button peut être utilisé pour attendre que le bouton du scanner soit pressé pour réellement commencer le processus de balayage.

Les coefficients de correction des couleurs --cct-1 --cct-2 --cct-3 ... --cct-9 installeront des coefficients de correction des couleurs pour la correction des couleurs définie par l'utilisateur. Les valeurs sont spécifiées comme des entiers dans la plage -127..127.

DESCRIPTION

The library libsane-epson2 is a backend for SANE (Scanner Access Now Easy) that supports a number of Epson scanners. The scanners are connected via USB, SCSI, Parallel Port, or Network. The actual list of supported scanners can be found in the file /usr/share/doc/sane/epson2.doc.

The configuration file /etc/sane.d/epson2.conf specifies the device(s) that the backend will use. This file is also used to configure the frontend software.

OPTIONS

This backend supports the SANE standard options and some specific options. The options can be specified in the configuration file and on the command line.

The backend supports the following options:

preview
Perform a preview scan. This option is intended for the frontend software. The backend uses this option to determine the resolution of the preview scan.
resolution
Sets the resolution for the scan. The default is 75 dpi.
format
Sets the image format. Valid options are "png", "jpeg", "tiff", "pnm".
mode
Sets the scan mode. Valid options are "Color", "Gray", "Lineart".
brightness
Controls the brightness of the scan. Valid options range from -100 to 100.
contrast
Controls the contrast of the scan. Valid options range from -100 to 100.
halftoning
Controls the halftoning algorithm used. Valid options depend on the scanner. The default is "Normal".
color-mode
Controls the color mode. Valid options are "sRGB" and "AdobeRGB".
gamma
Controls the gamma correction. Valid options range from 0.5 to 3.0.
auto-threshold
Automatically determines the threshold for lineart scans. Valid options are "yes" and "no".
auto-brightness
Automatically adjusts the brightness for scans. Valid options are "yes" and "no".
auto-contrast
Automatically adjusts the contrast for scans. Valid options are "yes" and "no".
auto-scale
Automatically scales the image to fit the scan area. Valid options are "yes" and "no".
auto-fill
Automatically fills the background of the image. Valid options are "yes" and "no".
low-resolution
If set to "yes", the frontend software automatically selects a low resolution. Valid options are "yes" and "no". The default is "no".

The geometry options -l -t -x -y control the scan area: -l sets the top left x coordinate, -t the top left y coordinate, -x selects the width and -y the height of the scan area. All parameters are specified in millimeters.

--source
The --source option selects the scan source. Valid options depend on the installed options. The default is "Flatbed".
--auto-eject
The --auto-eject option will eject a page after scanning from the document feeder.
--film-type
The --film-type option will select the film type for scans with the transparency unit. This option is only activated if the TPU is selected as scan source. Valid options are "Negative Film" and "Positive Film".
--focus-position
The --focus-position option selects the focus position for all scans. Valid options are "Focus 2.5mm above glass" and "Focus on glass". The focus on the 2.5mm point above the glass is necessary for scans with the transparency unit, so that the scanner can focus on the film if one of the film holders is used. This option is only functional for selected scanners, all other scanners will ignore this option.
--bay
The --bay option selects which bay to scan.
--eject
The --eject option ejects the sheet in the ADF.
--adf-mode
The --adf-mode option select the ADF mode (simplex/duplex).

CONFIGURATION FILE

The configuration file /etc/sane.d/epson2.conf specifies the device(s) that the backend will use. Possible connection types are:

SCSI
This is the default, and if nothing else is specified the backend software will open a given path as SCSI device. More information about valid syntax for SCSI devices can be found in sane-scsi(5).
Usually SCSI scanners are configured with a line "scsi EPSON" in this file. In some cases it may be necessary to only use the string "scsi" (e.g. for the GT-6500).
PIO - Parallel Interface
The parallel interface can be configured in two ways: An integer value starting at the beginning of a line will be interpreted as the IO address of the parallel port. To make it clearer that a configured IO address is a parallel port the port address can be preceded by the string "PIO". The PIO connection does not use a special device file in the /dev directory. The IO address can be specified in hex mode (prefixed with "0x").
USB
For USB scanners not automatically detect, their VENDOR and PRODUCT ID can be specified manually in the config file. More information about valid syntax for USB devices can be found in sane-usb(5).
Network
Network scanners can be auto-discovered if autodiscovery is specified after net keyword. An IP address to connect to can also be used.

FILES

/usr/lib/sane/libsane-epson2.a
The static library implementing this backend.
/usr/lib/sane/libsane-epson2.so
The shared library implementing this backend (present on systems that support dynamic loading).

ENVIRONMENT

SANE_DEBUG_EPSON2
If the library was compiled with debug support enabled, this environment variable controls the debug level for this backend. E.g., a value of 128 requests all debug output to be printed. Smaller levels reduce verbosity.
SANE_DEBUG_EPSON2_SCSI
If the library was compiled with debug support enabled, this environment variable controls the SCSI related debug level for this backend. Only a value of 2 is supported.
SANE_DEBUG_EPSON2_NET
If the library was compiled with debug support enabled, this environment variable controls the network related debug level for this backend. E.g., a value of 128 requests all debug output to be printed. Smaller levels reduce verbosity.
SANE_EPSON2_CMD_LVL
This allows one to override the function or command level that the backend uses to communicate with the scanner. The function level a scanner supports is determined during the initialization of the device. If the backend does not recognize the function level reported by the scanner it will default to function level B3. Valid function levels are A1, A2, B1, B2, B3, B4, B5, B6, B7, B8, D1 and F5. Use this feature only if you know what you are doing!

BUGS

None :-) At least none are currently known.

UNSUPPORTED DEVICES

The backend may be used with Epson scanners that are not yet listed under the list of supported devices. A scanner that is not recognized may default to the function level B3, which means that not all functions that the scanner may be capable of are accessible.

If the scanner is not even recognized as an Epson scanner this is probably because the device name reported by the scanner is not in the correct format. Please send this information to the backend maintainer (email address is in the AUTHOR section of this man page or in the AUTHORS file of the SANE distribution).
