SASLPASSWD2(8) Manuel du gestionnaire système SASLPASSWD2(8)

NOM

saslpasswd2 - définit le mot de passe sasl d'un utilisateur

SYNTAXE

saslpasswd2 [-p] [-d] [-c] [-n] [-f fichier] [-u domaine] [-a nomapp] [-v] idutilisateur

DESCRIPTION

saslpasswd2 est utilisé par un administrateur système pour définir le mot de passe sasl d'un utilisateur pour les programmes serveur et les mécanismes SASL qui utilisent la base de données standard libsasl des secrets d'utilisateurs.

OPTIONS

-p
Mode pipe - saslpasswd2 ne demandera pas le mot de passe et ne vérifiera pas qu'il a été correctement saisi. C'est le comportement par défaut lorsque l'entrée standard n'est pas un terminal.
-c
Crée une entrée pour l'utilisateur si celui-ci n'existe pas déjà. Ceci est mutuellement exclusif avec le drapeau -d (supprimer l'utilisateur).
-d
Supprime l'entrée de l'utilisateur. Ceci est mutuellement exclusif avec le drapeau -c (créer l'utilisateur).
-n
Ne définit pas la propriété userPassword en texte clair pour l'utilisateur. Seuls les secrets spécifiques au mécanisme seront définis (par exemple, OTP, SCRAM, SRP).
-u domaine
utilise domaine pour le domaine utilisateur (realm).
-f fichier
utilise fichier pour sasldb
-a nomapp
utilise nomapp comme nom d'application.
-v
Affiche le numéro de version de libsasl2 et quitte.
