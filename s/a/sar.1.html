NOM

sar - Collecter, rapporter ou sauvegarder les informations d'activité du système.

SYNTAXE

sar [ -A ] [ -B ] [ -b ] [ -C ] [ -D ] [ -d ] [ -F [ MOUNT ] ] [ -H ] [ -h ] [ -p ] [ -r [ ALL ] ] [ -S ] [ -t ] [ -u [ ALL ] ] [ -V ] [ -v ] [ -W ] [ -w ] [ -x ] [ -y ] [ -z ] [ --dec={ 0 | 1 | 2 } ] [ --dev=liste_périphériques ] [ --fs=liste_fs ] [ --help ] [ --human ] [ --iface=liste_interfaces ] [ --int=liste_interruptions ] [ --pretty ] [ --sadc ] [ -I [ SUM | ALL ] ] [ -P { liste_cpus | ALL } ] [ -m { mot-clé[,...] | ALL } ] [ -n { mot-clé[,...] | ALL } ] [ -q [ mot-clé[,...] | ALL ] ] [ -j {SID | ID | LABEL | PATH | UUID | ... } ] [ -f [ nom_fichier ] | -o [ nom_fichier ] | -[0-9]+ ] [ -i intervalle ] [ -s [ heure_début ] ] [ -e [ heure_fin ] ] ] [ intervalle [ compteur ] ]

DESCRIPTION

La commande sar écrit sur la sortie standard le contenu des compteurs d'activité cumulatifs sélectionnés dans le système d'exploitation. Le système de comptabilité, basé sur les valeurs des paramètres compteur et intervalle, écrit les informations le nombre spécifié de fois, espacées par les intervalles spécifiés en secondes. Si le paramètre intervalle est réglé à zéro, la commande sar affiche les statistiques moyennes depuis le démarrage du système. Si le paramètre intervalle est spécifié sans le paramètre compteur, des rapports sont générés en continu. Les données collectées peuvent également être sauvegardées dans le fichier spécifié par le drapeau -o nom_fichier, en plus d'être affichées à l'écran. Si nom_fichier est omis, sar utilise le fichier de données quotidien d'activité système standard (voir ci-dessous). Par défaut, toutes les données disponibles à partir du noyau sont sauvegardées dans le fichier de données.

La commande sar extrait et écrit sur la sortie standard les enregistrements précédemment sauvegardés dans un fichier. Ce fichier peut être celui spécifié par le drapeau -f ou, par défaut, le fichier de données quotidien d'activité système standard. Il est également possible d'entrer -1, -2, etc. comme argument à sar pour afficher les données de ces jours précédents. Par exemple, -1 pointera vers le fichier d'activité système standard d'hier.

Les fichiers de données quotidiens d'activité système standard sont nommés saDD ou saYYYYMMDD, où YYYY représente l'année en cours, MM le mois en cours et DD le jour en cours. Ce sont les fichiers par défaut utilisés par sar uniquement lorsqu'aucun nom de fichier n'a été explicitement spécifié. Lorsqu'elle est utilisée pour écrire des données dans des fichiers (avec son option -o), sar utilisera saYYYYMMDD si l'option -D a également été spécifiée, sinon elle utilisera saDD. Lorsqu'elle est utilisée pour afficher les enregistrements précédemment sauvegardés dans un fichier, sar recherchera le plus récent des fichiers saDD et saYYYYMMDD et l'utilisera.

Les fichiers de données quotidiens d'activité système standard sont situés dans le répertoire /var/log/sa par défaut. Il est cependant possible de spécifier un emplacement alternatif pour ceux-ci : Si un répertoire (au lieu d'un fichier simple) est utilisé avec les options -f ou -o, il sera considéré comme le répertoire contenant les fichiers de données.

Sans l'option -P, la commande sar rapporte les statistiques globales du système (globales sur tous les processeurs), qui sont calculées comme des moyennes pour les valeurs exprimées en pourcentages, et comme des sommes sinon. Si l'option -P est donnée, la commande sar rapporte l'activité qui concerne le ou les processeurs spécifiés. Si -P ALL est donné, la commande sar rapporte les statistiques pour chaque processeur individuel et les statistiques globales sur tous les processeurs. Les processeurs hors ligne ne sont pas affichés.

Vous pouvez sélectionner des informations sur des activités système spécifiques à l'aide des options. Ne pas spécifier d'option sélectionne uniquement l'activité CPU. Spécifier l'option -A sélectionne toutes les activités possibles.

La version par défaut de la commande sar (rapport d'utilisation CPU) peut être l'une des premières facilités que l'utilisateur exécute pour commencer l'investigation de l'activité système, car elle surveille les ressources système majeures. Si l'utilisation CPU est proche de 100 % (user + nice + system), la charge échantillonnée est limitée par le CPU.

Si plusieurs échantillons et plusieurs rapports sont souhaités, il est pratique de spécifier un fichier de sortie pour la commande sar. Exécutez la commande sar en tant que processus d'arrière-plan. La syntaxe pour cela est :

sar -o fichier_donnees intervalle compteur >/dev/null 2>&1 &

Toutes les données sont capturées en format binaire et sauvegardées dans un fichier (fichier_donnees). Les données peuvent ensuite être affichées sélectivement avec la commande sar en utilisant l'option -f. Réglez les paramètres intervalle et compteur pour sélectionner compteur enregistrements à des intervalles de intervalle secondes. Si le paramètre compteur n'est pas réglé, tous les enregistrements sauvegardés dans le fichier seront sélectionnés. La collecte de données de cette manière est utile pour caractériser l'utilisation du système sur une période donnée et déterminer les heures d'utilisation maximales.

Note : La commande sar ne fait que rapporter les activités locales.

OPTIONS

-A
Ceci est équivalent à spécifier -bBdFHISvwWy -m ALL -n ALL -q ALL -r ALL -u ALL. Cette option implique également de spécifier -I ALL -P ALL à moins que ces options ne soient explicitement définies sur la ligne de commande.
-B
Rapport des statistiques de pagination. Les valeurs suivantes sont affichées :
pgpgin/s
Nombre total de kibibytes que le système a pagine depuis le disque par seconde.
pgpgout/s
Nombre total de kibibytes que le système a pagine vers le disque par seconde.
fault/s
Nombre de défauts de page (majeurs + mineurs) effectués par le système par seconde. Ceci n'est pas un décompte des défauts de page qui génèrent des E/S, car certains défauts de page peuvent être résolus sans E/S.
majflt/s
Nombre de défauts majeurs que le système a effectués par seconde, ceux qui ont nécessité le chargement d'une page mémoire depuis le disque.
pgfree/s
Nombre de pages placées sur la liste libre par le système par seconde.
pgscank/s
Nombre de pages balayées par le démon kswapd par seconde.
pgscand/s
Nombre de pages balayées directement par seconde.
pgsteal/s
Nombre de pages que le système a récupérées du cache (pagecache et swapcache) par seconde pour satisfaire ses demandes mémoire.
pgprom/s
Nombre de pages promues (c'est-à-dire migrées de types de mémoire lents vers rapides) par le système par seconde.
pgdem/s
Nombre de pages dégradées (c'est-à-dire migrées de types de mémoire rapides vers lents) par le système par seconde.
-b
Rapport des statistiques de taux d'E/S et de transfert. Les valeurs suivantes sont affichées :
tps
Nombre total de transferts par seconde qui ont été émis vers les périphériques physiques. Un transfert est une requête d'E/S vers un périphérique physique. Plusieurs requêtes logiques peuvent être combinées en une seule requête d'E/S vers le périphérique. Un transfert est de taille indéterminée.
rtps
Nombre total de requêtes de lecture par seconde émises vers les périphériques physiques.
wtps
Nombre total de requêtes d'écriture par seconde émises vers les périphériques physiques.
dtps
Nombre total de requêtes d'abandon par seconde émises vers les périphériques physiques.
bread/s
Quantité totale de données lues depuis les périphériques en blocs par seconde. Les blocs sont équivalents aux secteurs et ont donc une taille de 512 octets.
bwrtn/s
Quantité totale de données écrites sur les périphériques en blocs par seconde.
bdscd/s
Quantité totale de données abandonnées pour les périphériques en blocs par seconde.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

-C
Lors de la lecture de données à partir d'un fichier, indiquez à sar d'afficher les commentaires insérés par sadc.
-D
Utilisez saYYYYMMDD au lieu de saDD comme nom de fichier standard pour les données quotidiennes d'activité système. Cette option ne fonctionne que lorsqu'elle est utilisée conjointement avec l'option -o pour enregistrer les données dans un fichier.
-d
Rapport sur l'activité de chaque périphérique bloc. Lorsque les données sont affichées, le nom du périphérique est affiché tel qu'il (devrait) apparaître dans /dev. sar utilise les données de /sys pour déterminer le nom du périphérique en fonction de ses numéros majeur et mineur. Si cette résolution de nom échoue, sar utilisera le mappage de noms contrôlé par le fichier /etc/conf.d/sysstat.ioconf . Les noms de périphériques persistants peuvent également être imprimés si l'option -j est utilisée (voir ci-dessous). Les statistiques pour tous les périphériques sont affichées sauf si une liste restreinte est spécifiée à l'aide de l'option --dev= (voir l'entrée d'option correspondante). Notez que l'activité disque dépend des options -S DISK et -S XDISK de sadc pour être collectée. Les valeurs suivantes sont affichées :
tps
Nombre total de transferts par seconde émis vers les périphériques physiques. Un transfert est une requête d'E/S vers un périphérique physique. Plusieurs requêtes logiques peuvent être combinées en une seule requête d'E/S vers le périphérique. Un transfert est de taille indéterminée.
rkB/s
Nombre de kibibytes lus depuis le périphérique par seconde.
wkB/s
Nombre de kibibytes écrits sur le périphérique par seconde.
dkB/s
Nombre de kibibytes ignorés pour le périphérique par seconde.
areq-sz
La taille moyenne (en kibibytes) des requêtes d'E/S émises vers le périphérique.
Note : Dans les versions précédentes, ce champ était connu sous le nom d'avgrq-sz et était exprimé en secteurs.
aqu-sz
La longueur moyenne de la file d'attente des requêtes émises vers le périphérique.
Note : Dans les versions précédentes, ce champ était connu sous le nom d'avgqu-sz.
await
Le temps moyen (en millisecondes) nécessaire pour que les requêtes d'E/S émises vers le périphérique soient traitées. Cela inclut le temps passé par les requêtes dans la file d'attente et le temps passé à les traiter.
%util
Pourcentage du temps écoulé pendant lequel des requêtes d'E/S ont été émises vers le périphérique (utilisation de la bande passante pour le périphérique). La saturation du périphérique se produit lorsque cette valeur est proche de 100% pour les périphériques qui traitent les requêtes séquentiellement. Mais pour les périphériques qui traitent les requêtes en parallèle, tels que les réseaux RAID et les SSD modernes, ce nombre ne reflète pas leurs limites de performance.
--dec={ 0 | 1 | 2 }
Spécifiez le nombre de décimales à utiliser (0 à 2, la valeur par défaut est 2).
--dev=liste_périph
Spécifiez les périphériques blocs pour lesquels des statistiques doivent être affichées par sar. liste_périph est une liste de noms de périphériques séparés par des virgules.

-e [ hh:mm[:ss] ]
-e [ secondes_depuis_l_epoch ]

Définissez l'heure de fin du rapport. L'heure de fin par défaut est 18:00:00. Les heures doivent être données au format 24 heures, ou comme le nombre de secondes depuis l'époque (donné sous forme d'un nombre à 10 chiffres). Cette option peut être utilisée lorsque les données sont lues ou écrites dans un fichier (options -f ou -o).
-F [ MONTAGE ]
Afficher les statistiques pour les systèmes de fichiers actuellement montés. Les pseudo-systèmes de fichiers sont ignorés. À la fin du rapport, sar affichera un résumé de tous ces systèmes de fichiers. L'utilisation du mot-clé paramètre MONTAGE indique que le point de montage sera rapporté au lieu du périphérique du système de fichiers. Les statistiques pour tous les systèmes de fichiers sont affichées sauf si une liste restreinte est spécifiée à l'aide de l'option --fs= (voir l'entrée d'option correspondante). Notez que les statistiques des systèmes de fichiers dépendent de l'option -S XDISK de sadc pour être collectées.

Les valeurs suivantes sont affichées :

MBfsfree
Quantité totale d'espace libre en mebibytes (y compris l'espace disponible uniquement pour l'utilisateur privilégié).
MBfsused
Quantité totale d'espace utilisé en mebibytes.
%fsused
Pourcentage d'espace de système de fichiers utilisé, tel que vu par un utilisateur privilégié.
%ufsused
Pourcentage d'espace de système de fichiers utilisé, tel que vu par un utilisateur non privilégié.
Ifree
Nombre total de nœuds de fichiers libres dans le système de fichiers.
Iused
Nombre total de nœuds de fichiers utilisés dans le système de fichiers.
%Iused
Pourcentage de nœuds de fichiers utilisés dans le système de fichiers.
-f [ nom_fichier ]
Extraire les enregistrements de nom_fichier (créé par le drapeau -o nom_fichier). La valeur par défaut du paramètre nom_fichier est le fichier de données quotidien d'activité système standard actuel. Si nom_fichier est un répertoire au lieu d'un fichier ordinaire, il est alors considéré comme le répertoire où se trouvent les fichiers de données quotidiens d'activité système standard. L'option -f est exclusive de l'option -o.
--fs=liste_fs
Spécifiez les systèmes de fichiers pour lesquels des statistiques doivent être affichées par sar. liste_fs est une liste de noms de systèmes de fichiers ou de points de montage séparés par des virgules.
-H
Rapporter les statistiques d'utilisation des hugepages. Les valeurs suivantes sont affichées :
kbhugfree
Quantité de mémoire hugepages en kibibytes qui n'a pas encore été allouée.
kbhugused
Quantité de mémoire hugepages en kibibytes qui a été allouée.
%hugused
Pourcentage de la mémoire totale des hugepages qui a été allouée.
kbhugrsvd
Quantité de mémoire hugepages réservée en kibibytes.
kbhugsurp
Quantité de mémoire hugepages excédentaire en kibibytes.
-h
Cette option est équivalente à la spécification --pretty --human.
--help
Affiche un court message d'aide puis quitte.
--human
Affiche les tailles dans un format lisible par l'homme (par exemple 1.0k, 1.2M, etc.). Les unités affichées avec cette option supplantent toutes les autres unités par défaut (par exemple, kibibytes, secteurs...) associées aux métriques.
-I [ SOMME | TOUT ]
Rapporter les statistiques des interruptions. Les valeurs affichées sont le nombre d'interruptions par seconde pour le processeur donné ou parmi tous les processeurs. Une liste d'interruptions peut être spécifiée à l'aide de --int= (voir cette option). Le mot-clé SOMME indique que le nombre total d'interruptions reçues par seconde doit être affiché. Le mot-clé TOUT indique que les statistiques de toutes les interruptions doivent être rapportées (c'est la valeur par défaut). Notez que les statistiques des interruptions dépendent de l'option -S INT de sadc pour être collectées.
-i intervalle
Sélectionner les enregistrements de données à des secondes aussi proches que possible du nombre spécifié par le paramètre intervalle.
--iface=liste_iface
Spécifiez les interfaces réseau pour lesquelles des statistiques doivent être affichées par sar. liste_iface est une liste de noms d'interface séparés par des virgules.
--int=liste_int
Spécifiez les noms d'interruptions pour lesquels des statistiques doivent être affichées par sar. liste_int est une liste de valeurs ou de plages de valeurs séparées par des virgules (par exemple, 0-16,35,40-).
-j { SID | ID | LABEL | PATH | UUID | ... }
Afficher les noms de périphériques persistants. Utilisez cette option en conjonction avec l'option -d. Les mots-clés ID, LABEL, etc. spécifient le type du nom persistant. Ces mots-clés ne sont pas limités, la seule condition préalable est que le répertoire contenant les noms persistants requis soit présent dans /dev/disk. Le mot-clé SID tente d'obtenir un identifiant stable à utiliser comme nom de périphérique. Un identifiant stable ne changera pas entre les redémarrages pour le même périphérique physique. S'il existe, cet identifiant est normalement le WWN (World Wide Name) du périphérique, tel que lu dans le répertoire /dev/disk/by-id .
-m { mot-clé[,...] | TOUT }
Rapporter les statistiques de gestion de l'alimentation. Notez que ces statistiques dépendent de l'option -S POWER de sadc pour être collectées.

Les mots-clés possibles sont BAT, CPU, FAN, FREQ, IN, TEMP et USB.

Avec le mot-clé BAT, des statistiques sur la capacité des batteries sont rapportées. Les valeurs suivantes sont affichées :

%cap
Capacité de la batterie.
cap/min
Capacité perdue ou gagnée par minute par la batterie.
status
État de charge de la batterie : ↑ (pleine), ↗ (en charge), → (pas en charge), ↘ (décharge), ? (inconnu).
Avec le mot-clé CPU, des statistiques sur le CPU sont rapportées. La valeur suivante est affichée :
MHz
Fréquence d'horloge instantanée du CPU en MHz.
Avec le mot-clé FAN, des statistiques sur la vitesse des ventilateurs sont rapportées. Les valeurs suivantes sont affichées :
rpm
Vitesse du ventilateur exprimée en tours par minute.
drpm
Ce champ est calculé comme la différence entre la vitesse actuelle du ventilateur (tr/min) et sa limite basse (fan_min).
DEVICE
Nom du périphérique du capteur.
Avec le mot-clé FREQ, des statistiques sur la fréquence d'horloge du processeur sont rapportées. La valeur suivante est affichée :
wghMHz
Fréquence d'horloge moyenne pondérée du processeur en MHz. Notez que le pilote cpufreq-stats doit être compilé dans le noyau pour que cette option fonctionne.
Avec le mot-clé IN, des statistiques sur les entrées de tension sont rapportées. Les valeurs suivantes sont affichées :
inV
Entrée de tension exprimée en Volts.
%in
Valeur d'entrée relative. Une valeur de 100 % signifie que l'entrée de tension a atteint sa limite haute (in_max) tandis qu'une valeur de 0 % signifie qu'elle a atteint sa limite basse (in_min).
DEVICE
Nom du périphérique du capteur.
Avec le mot-clé TEMP, des statistiques sur la température des périphériques sont rapportées. Les valeurs suivantes sont affichées :
degC
Température du périphérique exprimée en degrés Celsius.
%temp
Température relative du périphérique. Une valeur de 100 % signifie que la température a atteint sa limite haute (temp_max).
DEVICE
Nom du périphérique du capteur.
Avec le mot-clé USB, la commande sar prend un instantané de tous les périphériques USB actuellement connectés au système. À la fin du rapport, sar affichera un résumé de tous ces périphériques USB. Les valeurs suivantes sont affichées :
BUS
Numéro du hub racine du périphérique USB.
idvendor
Numéro d'identifiant du vendeur (attribué par l'organisation USB).
idprod
Numéro d'identifiant du produit (attribué par le fabricant).
maxpower
Consommation électrique maximale du périphérique (exprimée en mA).
manufact
Nom du fabricant.
product
Nom du produit.
Le mot-clé ALL équivaut à spécifier tous les mots-clés ci-dessus et par conséquent toutes les statistiques de gestion de l'énergie sont rapportées.
-n { mot-clé[,...] | ALL }
Rapport des statistiques réseau.

Les mots-clés possibles sont DEV, EDEV, FC, ICMP, EICMP, ICMP6, EICMP6, IP, EIP, IP6, EIP6, NFS, NFSD, SOCK, SOCK6, SOFT, TCP, ETCP, UDP et UDP6.

Avec le mot-clé DEV, des statistiques des périphériques réseau sont rapportées. Les statistiques pour toutes les interfaces réseau sont affichées sauf si une liste restreinte est spécifiée à l'aide de l'option --iface= (voir l'entrée de l'option correspondante). Les valeurs suivantes sont affichées :

IFACE
Nom de l'interface réseau pour laquelle les statistiques sont rapportées.
rxpck/s
Nombre total de paquets reçus par seconde.
txpck/s
Nombre total de paquets transmis par seconde.
rxkB/s
Nombre total de kibibytes reçus par seconde.
txkB/s
Nombre total de kibibytes transmis par seconde.
rxcmp/s
Nombre de paquets compressés reçus par seconde (pour cslip etc.).
txcmp/s
Nombre de paquets compressés transmis par seconde.
rxmcst/s
Nombre de paquets multicast reçus par seconde.
%ifutil
Pourcentage d'utilisation de l'interface réseau. Pour les interfaces half-duplex, l'utilisation est calculée en utilisant la somme de rxkB/s et txkB/s comme pourcentage de la vitesse de l'interface. Pour le full-duplex, il s'agit du plus grand des deux : rxkB/S ou txkB/s.
Avec le mot-clé EDEV, des statistiques sur les échecs (erreurs) des périphériques réseau sont rapportées. Les statistiques pour toutes les interfaces réseau sont affichées sauf si une liste restreinte est spécifiée à l'aide de l'option --iface= (voir l'entrée de l'option correspondante). Les valeurs suivantes sont affichées :
IFACE
Nom de l'interface réseau pour laquelle les statistiques sont rapportées.
rxerr/s
Nombre total de paquets erronés reçus par seconde.
txerr/s
Nombre total d'erreurs survenues par seconde lors de la transmission de paquets.
coll/s
Nombre de collisions survenues par seconde lors de la transmission de paquets.
rxdrop/s
Nombre de paquets reçus abandonnés par seconde en raison d'un manque d'espace dans les tampons Linux.
txdrop/s
Nombre de paquets transmis abandonnés par seconde en raison d'un manque d'espace dans les tampons Linux.
txcarr/s
Nombre d'erreurs de porteuse survenues par seconde lors de la transmission de paquets.
rxfram/s
Nombre d'erreurs d'alignement de trame survenues par seconde sur les paquets reçus.
rxfifo/s
Nombre d'erreurs de dépassement FIFO survenues par seconde sur les paquets reçus.
txfifo/s
Nombre d'erreurs de dépassement FIFO survenues par seconde sur les paquets transmis.
Avec le mot-clé FC, des statistiques sur le trafic fibre channel sont rapportées. Notez que les statistiques fibre channel dépendent de l'option -S DISK de sadc pour être collectées. Les valeurs suivantes sont affichées :
FCHOST
Nom de l'interface du bus adaptateur fibre channel (HBA) pour laquelle les statistiques sont rapportées.
fch_rxf/s
Le nombre total de trames reçues par seconde.
fch_txf/s
Le nombre total de trames transmises par seconde.
fch_rxw/s
Le nombre total de mots de transmission reçus par seconde.
fch_txw/s
Le nombre total de mots de transmission transmis par seconde.
Avec le mot-clé ICMP, des statistiques sur le trafic réseau ICMPv4 sont rapportées. Notez que les statistiques ICMPv4 dépendent de l'option -S SNMP de sadc pour être collectées. Les valeurs suivantes sont affichées (noms SNMP formels entre crochets) :
imsg/s
Le nombre total de messages ICMP que l'entité a reçus par seconde [icmpInMsgs]. Notez que ce compteur inclut tous ceux comptés par ierr/s.
omsg/s
Le nombre total de messages ICMP que cette entité a tenté d'envoyer par seconde [icmpOutMsgs]. Notez que ce compteur inclut tous ceux comptés par oerr/s.
iech/s
Le nombre de messages ICMP Echo (requête) reçus par seconde [icmpInEchos].
iechr/s
Le nombre de messages ICMP Echo Reply reçus par seconde [icmpInEchoReps].
oech/s
Le nombre de messages ICMP Echo (requête) envoyés par seconde [icmpOutEchos].
oechr/s
Le nombre de messages ICMP Echo Reply envoyés par seconde [icmpOutEchoReps].
itm/s
Le nombre de messages ICMP Timestamp (requête) reçus par seconde [icmpInTimestamps].
itmr/s
Le nombre de messages ICMP Timestamp Reply reçus par seconde [icmpInTimestampReps].
otm/s
Le nombre de messages ICMP Timestamp (requête) envoyés par seconde [icmpOutTimestamps].

ENVIRONNEMENT

La commande sar prend en compte les variables d'environnement suivantes :

S_COLORS
Par défaut, les statistiques sont affichées en couleur lorsque la sortie est connectée à un terminal. Utilisez cette variable pour modifier les paramètres. Les valeurs possibles pour cette variable sont never, always ou auto (cette dernière équivaut aux paramètres par défaut).
Veuillez noter que la couleur (rouge, jaune ou une autre couleur) utilisée pour afficher une valeur n'indique aucun problème, simplement à cause de la couleur. Elle indique seulement différentes plages de valeurs.
S_COLORS_SGR
Spécifie les couleurs et autres attributs utilisés pour afficher les statistiques sur le terminal. Sa valeur est une liste de capacités séparées par des deux-points, qui par défaut est C=33;22:I=32;22:N=34;1:R=31;22:W=35;1:X=31;1:Z=34;22. Les capacités prises en charge sont :
C=
Sous-chaîne SGR (Select Graphic Rendition) pour les commentaires insérés dans les fichiers de données binaires quotidiens.
I=
Sous-chaîne SGR pour les noms ou valeurs d'éléments (par exemple, interfaces réseau, numéro de CPU...)
N=
Sous-chaîne SGR pour les statistiques dont les valeurs sont non nulles.
R=
Sous-chaîne SGR pour les messages de redémarrage.
W= (ou M=)
Sous-chaîne SGR pour les pourcentages compris entre 75% et 90% (ou entre 10% et 25% selon la signification de la métrique). Elle est également utilisée pour les valeurs négatives comprises entre -10 et -5.
X= (ou H=)
Sous-chaîne SGR pour les pourcentages supérieurs ou égaux à 90% (ou inférieurs ou égaux à 10% selon la signification de la métrique). Elle est également utilisée pour les valeurs négatives inférieures ou égales à -10.
Z=
Sous-chaîne SGR pour les valeurs nulles.
S_REPEAT_HEADER
Cette variable contient le nombre maximum de lignes après lesquelles un en-tête doit être affiché par sar lorsque la sortie n'est pas un terminal.
S_TIME_DEF_TIME
Si cette variable existe et que sa valeur est UTC, alors sar enregistrera ses données en temps UTC (les données seront toujours affichées en heure locale). sar utilisera également l'heure UTC au lieu de l'heure locale pour déterminer le fichier de données quotidien actuel situé dans le répertoire /var/log/sa. Cette variable peut être utile pour les serveurs ayant des utilisateurs situés dans plusieurs fuseaux horaires.
S_TIME_FORMAT
Si cette variable existe et que sa valeur est ISO, alors la locale actuelle sera ignorée lors de l'impression de la date dans l'en-tête du rapport. La commande sar utilisera alors le format ISO 8601 (AAAA-MM-JJ). L'horodatage sera également conforme au format ISO 8601.

EXEMPLES

sar -u 2 5
Rapporte l'utilisation du CPU toutes les 2 secondes. 5 lignes sont affichées.
sar -I --int=14 -o int14.file 2 10
Rapporte les statistiques sur l'IRQ 14 toutes les 2 secondes. 10 lignes sont affichées. Les données sont stockées dans un fichier nommé int14.file.
sar -r -n DEV -f /var/log/sa/sa16
Affiche les statistiques mémoire et réseau sauvegardées dans le fichier de données quotidien sa16.
sar -A
Affiche toutes les statistiques sauvegardées dans le fichier de données quotidien actuel.

BOGUES

Le système de fichiers /proc doit être monté pour que la commande sar fonctionne.

Toutes les statistiques ne sont pas nécessairement disponibles, en fonction de la version du noyau utilisée. sar suppose que vous utilisez au moins un noyau 2.6.

Bien que sar affiche des unités correspondant à des kilo-octets (kB), méga-octets (MB)..., il utilise en réalité des kibioctets (kiB), mébioctets (MiB)... Un kibioctet est égal à 1024 octets, et un mébioctet est égal à 1024 kibioctets.

FICHIERS

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD

Les fichiers de données quotidiens standard d'activité système et leur emplacement par défaut. YYYY représente l'année en cours, MM le mois en cours et DD le jour en cours.

/proc et /sys contiennent divers fichiers avec des statistiques système.

DESCRIPTION

Le programme sar (System Activity Reporter) est utilisé pour collecter, enregistrer et signaler les informations sur l'activité du système. Les informations collectées peuvent inclure : l'activité du processeur, l'activité de la mémoire, l'activité du disque, l'activité réseau, l'activité des processus, etc.

Par défaut, sar collecte des informations toutes les 10 minutes et les enregistre dans le fichier /var/log/sa/saXX, où XX est le numéro du jour du mois. Ce fichier est créé au démarrage du système.

OPTIONS

-A
Toutes les options de reporting sont activées.
-u [all]
Rapporte l'utilisation du processeur. Si l'argument all est fourni, rapporte également l'utilisation de chaque processeur.
-d
Rapporte l'activité du disque (par appareil).
-b
Rapporte les statistiques d'entrée/sortie et de débit.
-r [all]
Rapporte l'utilisation de la mémoire. Si l'argument all est fourni, rapporte également l'utilisation de la mémoire swap.
-n [DEV|ED|TCP|UDP|ICMP|IP|ALL]
Rapporte les statistiques réseau.
-q [all]
Rapporte la longueur de la file d'attente du système et la charge moyenne. Si l'argument all est fourni, rapporte également la longueur de la file d'attente des processus en attente.
-p
Rapporte l'activité des périphériques de bloc en utilisant des noms de périphériques lisibles par l'homme.
-t [-o FILE] | -f FILE
Lit les statistiques depuis un fichier d'archive binaire créé par sar. L'option -t est nécessaire pour lire les données d'un fichier d'archive binaire.
-i N
Spécifie l'intervalle (en secondes) entre les collectes de données.
-l INTERVAL
Spécifie la période (en minutes) pour les statistiques d'utilisation du disque.
-m [KB|MO||KMG ]
Rapporte les statistiques sur la mémoire (en Ko, Mo ou Ko/Mo/Go).
-P [cpu,...] | ALL
Rapporte l'activité de chaque processeur spécifié ou de tous les processeurs (ALL).
-o FILE
Enregistre les statistiques dans un fichier d'archive binaire.
-f FILE
Lit les statistiques depuis un fichier d'archive binaire.
-j
Utilise des noms de périphériques de bloc standard au lieu de noms de périphériques dérivés.
-s [HH:MM:SS]
Spécifie l'heure de début de la collecte des données.
-e [HH:MM:SS]
Spécifie l'heure de fin de la collecte des données.
-T
Indique à sar d'essayer de détecter le type de terminal et d'adapter la sortie en conséquence.
-V
Affiche les informations de version et quitte.
--dec={BYTES|SI|I8042|BLOCK}
Spécifie le mode de décimalisation pour les valeurs binaires. Les valeurs possibles sont BYTES (octets), SI (kilo, méga, giga...), I8042 (contrôleur de clavier 8042) et BLOCK (secteurs de disque).
--pretty
Produit une sortie formatée de manière lisible par l'homme.
--human
Produit une sortie formatée de manière lisible par l'homme, en utilisant des suffixes d'unités (K, M, G, etc.).
--output-version VERSION
Spécifie la version du format de sortie.
--output-separator STRING
Spécifie la chaîne de caractères à utiliser comme séparateur de sortie.
--output-field-separator STRING
Spécifie la chaîne de caractères à utiliser comme séparateur de champs.
--output-header
Affiche un en-tête pour chaque section de sortie.
--output-reset
Réinitialise les compteurs de statistiques.
--output-terse
Produit une sortie compacte.
--output-skip-empty-lines
Ignore les lignes vides dans la sortie.
--output-line-separator STRING
Spécifie la chaîne de caractères à utiliser comme séparateur de ligne.
--output-no-header
Ne pas afficher l'en-tête.
--output-terse-over-lines
Produit une sortie compacte sur plusieurs lignes.
--output-no-output-terse-over-lines
Désactive la sortie compacte sur plusieurs lignes.
--output-end-line
Termine la sortie après la dernière ligne.
--output-end-time TIME
Arrête la collecte des données à l'heure spécifiée.
--output-end-date DATE
Arrête la collecte des données à la date spécifiée.
--output-end-sample N
Arrête la collecte des données après N échantillons.
--output-end-period N
Arrête la collecte des données après une période de N secondes.
--output-end-date-time DATETIME
Arrête la collecte des données à la date et à l'heure spécifiées.
--output-line-count N
Limité la sortie à N lignes.
--output-time-zone ZONE
Spécifie le fuseau horaire à utiliser pour l'affichage de l'heure.
--output-time-format FORMAT
Spécifie le format d'affichage de l'heure.
--output-time-only
Affiche uniquement l'heure.
--output-date-only
Affiche uniquement la date.
--output-date-time
Affiche la date et l'heure.
--output-duration
Affiche la durée.
-h, --help
Affiche un message d'aide et quitte.
-?
Affiche un message d'aide et quitte.
--version
Affiche les informations de version et quitte.

EXEMPLES

sar -u 1 5 : Affiche l'utilisation du processeur toutes les secondes pendant 5 secondes.

sar -d -f /var/log/sa/sa01 : Affiche l'activité du disque à partir du fichier d'archive du 1er jour du mois.

sar -n DEV 2 10 : Affiche les statistiques réseau pour tous les périphériques toutes les 2 secondes pendant 10 secondes.

ENVIRONNEMENT

Aucune variable d'environnement n'affecte le fonctionnement de sar.

FICHIERS

/var/log/sa/saXX
Fichier d'archive des données de performance système. XX est le numéro du jour du mois.

STATUT DE SORTIE

0 en cas de succès, 1 en cas d'échec.
