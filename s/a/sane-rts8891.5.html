sane-rts8891(5) SANE Scanner Access Now Easy sane-rts8891(5)

NOM

sane-rts8891 - Backend SANE pour scanners basés sur rts8891

DESCRIPTION

La bibliothèque sane-rts8891 implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès aux scanners basés sur le ASIC rts8891.

Les scanners qui fonctionnent avec ce backend sont :

   Vendeur Modèle           statut
----------------------  -----------
  Umax Astra 4400       non testé
  Umax Astra 4450       non testé
  HP scanjet 4000c      bon
  HP scanjet 4470c      bon

Les options que le backend prend en charge peuvent être sélectionnées soit via des options en ligne de commande pour des programmes comme scanimage(1), soit via des éléments d'interface graphique dans xscanimage(1) ou xsane(1).

Si vous remarquez un comportement étrange, veuillez le signaler au mainteneur du backend ou à la liste de diffusion SANE.

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant

scanimage --help -d rts8891
Options du Mode de numérisation
--mode
sélectionne le mode de fonctionnement de base du scanner. Les choix valides sont Couleur, Niveaux de gris et Noir et blanc. Le mode par défaut est Couleur. Le mode Noir et blanc est uniquement pour le noir et blanc (1 bit). Niveaux de gris produira 256 niveaux de gris (8 bits). Le mode Couleur permet plus de 16 millions de couleurs différentes produites à partir de 24 bits d'informations de couleur.
--resolution
sélectionne la résolution pour une numérisation. Les résolutions horizontale et verticale sont définies par la valeur de cette option. Le scanner est capable des résolutions suivantes pour la valeur d'option spécifiée :
  Valeur   Résolution Hor.  Résolution Vert.
  -----   ---------------  -------------------
  75      75dpi            75dpi
  150     150dpi           150dpi
  300     300dpi           300dpi
  600     600dpi           600dpi
  1200    1200dpi          1200dpi
--preview
demande une numérisation d'aperçu. La résolution utilisée pour cette numérisation est de 75 dpi et la zone de numérisation et le mode de numérisation sont tels que spécifiés par leurs options, ou par défaut s'ils ne sont pas spécifiés. La valeur par défaut pour le mode aperçu est "non".
--threshold
sélectionne la luminosité minimale pour obtenir un point blanc. Le seuil n'est utilisé qu'avec les numérisations en mode Noir et blanc. Il est spécifié en pourcentage dans la plage 0..100% (par pas de 1). La valeur par défaut de l'option de seuil est 50.

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/rts8891.conf contient les identifiants de périphérique USB des scanners pris en charge (par ex. usb 0x043d 0x007c) et les options de configuration du scanner. Les lignes vides et les lignes commençant par une marque dièse (#) sont ignorées.

Les options prises en charge sont allowsharing, modelnumber

Option

allowsharing
active ou non le partage du scanner entre plusieurs frontends simultanément.
modelnumber
est utilisé pour forcer le modèle rapporté par le backend et n'est utile que dans le cas d'un scanner dont la NVRAM a été effacée. 
0 pour rapporter un HP4470c.
1 pour rapporter un HP4400c.
2 pour rapporter un Astra 4400.

FICHIERS

/usr/lib/sane/libsane-rts8891.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-rts8891.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_RTS8891 SANE_DEBUG_RTS8891_LOW SANE_DEBUG_RTS88XX_LIB
Si la bibliothèque a été compilée avec le support de débogage activé, ces variables d'environnement contrôlent le niveau de débogage pour ce backend. Par exemple, une valeur de 255 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité.

LIMITATIONS

Il existe des scanners du même modèle avec des capteurs différents, en raison du manque de données (c'est-à-dire les journaux USB), certains capteurs sont mieux pris en charge que d'autres. Au moins le mode 75 dpi fonctionne pour n'importe quel modèle. Le partage du scanner entre plusieurs frontends en même temps (option allowsharing) peut ne pas fonctionner sur certains contrôleurs USB.

XPA n'est pas (encore) pris en charge.

BOGUES

Aucun bug connu actuellement.
