NOM

sane-dc25 - Backend SANE pour appareils photo numériques Kodak DC20/DC25

DESCRIPTION

La bibliothèque sane-dc25 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux appareils photo Kodak DC20 et DC25. Actuellement, seul le DC25 a été testé, mais comme le code est basé sur un programme d'interface DC20, il est probable qu'il fonctionne également pour ce modèle.

NOMS_DE_PÉRIPHÉRIQUE

La version actuelle du backend ne permet qu'un seul appareil photo connecté. Le nom du périphérique est toujours "0".

CONFIGURATION

Le contenu de dc25.conf spécifie le port série et le débit en bauds à utiliser. Le débit en bauds spécifie le débit maximum à utiliser lors du téléchargement des images. (L'appareil photo est toujours initialisé en utilisant 9600 bauds, puis passe au débit supérieur). Sur mon Pentium 90 MHz, je n'ai généralement aucun problème à télécharger à 115200 bauds tant que le système n'est pas excessivement occupé et que le "drapeau de démasquage d'interruption" est activé dans le pilote IDE (hdparm -u1). Les débits en bauds pris en charge sont : 9600, 19200, 38400, 57600 et 115200.

La ligne dumpinquiry provoque l'affichage d'informations sur l'appareil photo sur stderr au démarrage. Remarque : Ceci n'est pas compatible avec saned, assurez-vous donc de ne pas avoir de lignes dumpinquiry si vous utilisez saned (c'est-à-dire en numérisant sur une machine distante via un réseau).

Les lignes vides et les lignes commençant par un signe dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous :

port=/dev/ttyS0
# ceci est un commentaire
baud=115200
dumpinquiry

FICHIERS

/etc/sane.d/dc25.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-dc25.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-dc25.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") puis dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, . et /etc/sane.d (dans cet ordre).
SANE_DEBUG_DC25
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Une valeur de 128 demande une sortie de débogage maximale ; des niveaux plus bas réduisent la verbosité.

BOGUES

Les bogues/limitations connus sont :

Je n'ai pas compris comment déclencher un rechargement des options suite à un "scan." Cela pose des problèmes lorsqu'une nouvelle image est capturée, par exemple, le curseur utilisé pour sélectionner l'image de l'appareil photo peut ne pas être mis à jour immédiatement.

Des commentaires plus généraux, des suggestions et des demandes concernant les interfaces graphiques ou SANE doivent être envoyés à la liste de diffusion des développeurs SANE (voir http://www.sane-project.org/mailing-lists.html pour plus de détails). Vous devez être abonné à la liste, sinon votre courrier ne sera pas envoyé aux abonnés.
