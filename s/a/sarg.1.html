NOM

sarg - Générateur de rapports d'analyse pour Squid

SYNOPSIS

sarg [options] [fichier_journal...]

DESCRIPTION

sarg est un analyseur et un générateur de rapports de journaux pour le Squid Web Proxy Cache[1]. Il permet de visualiser où vos utilisateurs vont sur Internet.

sarg génère des rapports en HTML avec des champs tels que : utilisateurs, adresses IP, octets, sites et heures. Ces fichiers HTML peuvent apparaître dans le répertoire de votre serveur web pour être consultés par les utilisateurs ou les administrateurs. Vous pouvez également faire en sorte que sarg envoie les rapports par e-mail à l'administrateur du cache Squid.

sarg peut lire les journaux d'accès de Squid ou de Microsoft ISA. Optionnellement, il peut compléter les rapports avec le journal d'un filtre/redirectionneur Squid tel que squidGuard[2].

OPTIONS

Un résumé des options est inclus ci-dessous.

-h --help

Affiche le résumé des options.

-a nom_hote|adresse_ip

Limite le rapport aux enregistrements contenant le nom d'hôte/adresse IP spécifié.

-b nom_fichier

Active le journal UserAgent et l'écrit dans nom_fichier.

-c nom_fichier

Lit nom_fichier pour obtenir une liste des hôtes web à exclure du rapport. Voir la section « FICHIER D'EXCLUSION D'HÔTES ».

--convert

Convertit le champ date/heure du fichier journal squid en un format lisible par l'homme. Tous les fichiers journaux sont lus et leur contenu est affiché sous forme de texte sur la sortie standard.

--css

Affiche, sur la sortie standard, le CSS interne que sarg intègre dans les rapports. Vous pouvez rediriger la sortie vers un fichier de votre choix et le modifier. Ensuite, vous pouvez remplacer le CSS interne par external_css_file dans sarg.conf.

L'utilisation d'un CSS externe peut réduire la taille du fichier de rapport. Si vous manquez d'espace disque, vous pouvez envisager d'exporter le CSS comme expliqué ci-dessus.

-d date

Utilise date pour restreindre le rapport à une période donnée lors du traitement des fichiers journaux. Le format de date est jj/mm/aaaa-jj/mm/aaaa ou une date unique jj/mm/aaaa. Les plages de dates peuvent également être spécifiées comme jour-n, semaine-n, ou mois-n où n est le nombre de jours, semaines ou mois à reculer. Notez qu'il n'y a pas d'espaces autour du trait d'union.

-e e-mail

Envoie le rapport à e-mail (stdout pour la console).

-f nom_fichier

Lit la configuration à partir de nom_fichier.

-g e|u

Définit le format de date dans les rapports générés.
e = Europe -> jj/mm/aa
u = USA -> mm/jj/aa

-i

Génère des rapports par utilisateur et par adresse IP.

Note
Ceci nécessite que l'option report_type dans le fichier de configuration contienne « users_sites ».

--keeplogs

Ne supprime aucun ancien rapport. C'est équivalent à définir --lastlog 0 mais est fourni pour plus de commodité.

-l nom_fichier

Utilise nom_fichier comme journal d'entrée. Cette option peut être répétée jusqu'à 255 fois pour lire plusieurs fichiers. Si les fichiers se terminent par l'extension .gz, .bz2 ou .Z, ils sont décompressés. Si le nom de fichier est simplement -, le fichier journal est lu depuis l'entrée standard. Dans ce cas, il ne peut pas être compressé.

Cette option est conservée pour la compatibilité avec les anciennes versions de sarg mais, à partir de sarg 2.3, les fichiers journaux peuvent être nommés sur la ligne de commande sans l'option -l. Cela permet l'utilisation de caractères génériques sur la ligne de commande. Assurez-vous de ne pas dépasser la limite de 255 fichiers.

--lastlog n

Limite le nombre de journaux conservés dans le répertoire de sortie à n. Tout rapport excédentaire est supprimé en commençant par le rapport le plus ancien. La valeur de n doit être positive ou nulle. Une valeur de zéro signifie qu'aucun rapport ne doit être supprimé.

-L nom_fichier

Lit un fichier journal de redirection de proxy tel que ceux créés par squidGuard ou Rejik. Si vous utilisez cette option, vous voudrez peut-être configurer redirector_log_format dans sarg.conf pour qu'il corresponde au format de sortie de votre programme de filtrage de contenu web. Cette option peut être répétée jusqu'à 64 fois pour lire plusieurs fichiers.

-n

Active la résolution d'adresses IP.

-o répertoire

Écrit le rapport dans répertoire.

-p

Génère des rapports en utilisant l'adresse IP au lieu de l'identifiant utilisateur.

-P préfixe --splitprefix préfixe

Cette option doit être utilisée avec --split. Si elle est fournie, le journal d'entrée est divisé en plusieurs fichiers contenant chacun une journée. Le nom des fichiers de sortie est constitué du préfixe et de la date formatée en -AAAA-MM-JJ.

Les fichiers de sortie sont écrits dans le répertoire de sortie spécifié avec -o ou dans le répertoire courant.

-r

Affiche le rapport en temps réel sur la sortie standard et quitte.

-s chaîne

Limite le rapport au site spécifié par chaîne [par ex. www.debian.org].

--split

Divise le fichier journal squid et l'affiche sous forme de texte sur la sortie standard, en omettant les dates en dehors de la plage spécifiée par le paramètre -d. S'il est combiné avec --convert, les dates sont également converties en format lisible par l'homme.

Combiné avec -P, le journal est écrit dans plusieurs fichiers contenant chacun une journée du journal d'origine.

--statistics

Écrit des statistiques sur le temps d'exécution. Les statistiques incluent le temps d'exécution total ; le nombre d'enregistrements lus dans les fichiers journaux d'entrée et le temps nécessaire pour les lire ; le nombre d'enregistrements et d'utilisateurs traités et le temps nécessaire pour les traiter.

-t chaîne

Limite les enregistrements inclus dans le rapport en fonction de l'heure de la journée. Le format de chaîne est HH:MM ou HH:MM-HH:MM. Le premier ne rapporte que l'heure demandée. Le second rapporte toute entrée tombant dans la plage demandée. Cette limite complète celle imposée par l'option -d.

-u utilisateur

Limite les rapports aux activités de utilisateur.

-v

Affiche la version de sarg et quitte.

-w répertoire

Stocke les fichiers temporaires dans répertoire. En fait, sarg stocke ses fichiers temporaires dans le sous-répertoire sarg de répertoire. Assurez-vous de définir le répertoire de sortie HTML dans un endroit situé en dehors du répertoire temporaire, sinon sarg pourrait échouer ou supprimer le rapport une fois sa tâche terminée.

-x

Affiche les messages de débogage sur stdout.

-z

Affiche les messages de processus sur stdout.

FICHIER EXCLUSION HÔTE

Sarg peut être configuré pour exclure les hôtes visités du rapport en lui fournissant un fichier contenant un hôte à exclure par ligne. L'"hôte" peut être l'un des éléments suivants :

• un nom d'hôte complet,
• un nom d'hôte commençant par un caractère générique (*) pour correspondre à n'importe quel préfixe,
• une adresse IP unique,
• un sous-réseau noté a.b.c.d/e.

Exemple 1. Exemple de fichier d'exclusion d'hôtes

*.google.com
10.0.0.0/8

Sarg ne peut pas exclure les adresses IPv6 pour le moment.
