NOM

samba-gpupdate - appliquer la stratégie de groupe

SYNTAXE

samba-gpupdate

samba-gpupdate [options]

DESCRIPTION

Cet outil fait partie de la suite samba(1).

samba-gpupdate est un script pour appliquer et annuler l'application de la Stratégie de Groupe. Cela applique les stratégies de mot de passe (âge minimum/maximum du mot de passe, longueur minimum du mot de passe, complexité du mot de passe), les stratégies kerberos (durée de vie du ticket utilisateur/service et durée de vie du renouvellement), les stratégies smb.conf, les scripts cron horaires/quotidiens/hebdomadaires/mensuels, les privilèges Sudo, les messages du Jour et messages d'invite de connexion, etc.

OPTIONS

-h, --help afficher ce message d'aide et quitter

-H URL, --url=URL URL pour le samdb

-X, --unapply Annuler l'application de la Stratégie de Groupe

--target {Computer | User}

--force Réappliquer tous les paramètres de stratégie

--rsop Afficher l'Ensemble Résultant de Stratégie

Options communes Samba :

-s FICHIER, --configfile=FICHIER Fichier de configuration

-d NIVEAU_DEBOGAGE, --debuglevel=NIVEAU_DEBOGAGE Niveau de débogage

--option=OPTION définir l'option smb.conf depuis la ligne de commande

--realm=REALM définir le nom du realm

Options de version :

-V, --version Afficher le numéro de version

Options d'identification :

--simple-bind-dn=DN DN à utiliser pour un bind simple

--password=MOTDEPASSE Mot de passe

-U NOM_UTILISATEUR, --username=NOM_UTILISATEUR Nom d'utilisateur

-W GROUPE_DE_TRAVAIL, --workgroup=GROUPE_DE_TRAVAIL Groupe de travail

-N, --no-pass Ne pas demander de mot de passe

-k KERBEROS, --kerberos=KERBEROS Utiliser Kerberos

--ipaddress=ADRESSE_IP Adresse IP du serveur

-P, --machine-pass Utiliser le mot de passe de compte machine stocké
