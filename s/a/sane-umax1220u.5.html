sane-umax1220u(5) SANE Scanner Access Now Easy sane-umax1220u(5)

NOM

sane-umax1220u - Backend SANE pour le scanner UMAX Astra 1220U et similaires

DESCRIPTION

La bibliothèque sane-umax1220 implémente un backend SANE (Scanner Access Now Easy) pour le scanner UMAX Astra 1220U et similaires.

Pour plus d'informations sur ce backend, veuillez visiter http://umax1220u-sane.sourceforge.net/.

SUPPORT UMAX ASTRA 1600U/2000U/2100U

Ce backend est également capable de piloter les UMAX Astra 1600U/2000U/2100U. Le 2100U est confirmé comme fonctionnel. Pour les autres scanners, aucun rapport n'a encore été reçu. Veuillez nous contacter pour nous indiquer si votre scanner fonctionne (sane-devel@alioth-lists.debian.net).

CONFIGURATION

Normalement, aucune configuration manuelle n'est nécessaire. Le fichier de configuration pour ce backend se trouve dans /etc/sane.d/umax1220u.conf.

Son contenu est une liste de noms de périphériques correspondant aux scanners UMAX Astra. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous:

 #usb vendor product
 usb 0x1606 0x0010
 # Liste des périphériques pour les systèmes non-linux
 /dev/scanner
 /dev/usb/scanner0

Voir sane-usb(5) pour des informations sur la manière de définir les permissions d'accès sur les fichiers de périphériques usb.

FICHIERS

Le fichier de configuration du backend :
/etc/sane.d/umax1220u.conf
La bibliothèque statique implémentant ce backend :
/usr/lib/sane/libsane-umax1220u.a
La bibliothèque partagée implémentant ce backend :
/usr/lib/sane/libsane-umax1220u.so (présente sur les systèmes qui supportent le chargement dynamique)

ENVIRONNEMENT

SANE_DEBUG_UMAX1220U
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité :

Valeurs de SANE_DEBUG_UMAX1220U :

Nombre  Remarque
 1       affiche les erreurs
 2       affiche les informations
 3       affiche les appels de fonctions de haut niveau
 4       affiche les points de contrôle des fonctions de haut niveau
 9       affiche les appels de fonctions de niveau intermédiaire
 10      affiche les points de contrôle des fonctions de niveau intermédiaire
 80      affiche l'entrée des fonctions au niveau protocole
 90      affiche la sortie des fonctions au niveau protocole
Exemple :
export SANE_DEBUG_UMAX1220U=10

BUGS CONNUS

La numérisation à 600 dpi peut échouer pour de grandes tailles d'image.

Si vous continuez à recevoir des erreurs d'E/S, essayez de redémarrer votre scanner pour le réinitialiser.

Il n'y a aucun moyen d'annuler une numérisation, car le pilote ignore sane_cancel().

Si vous essayez de numériser une image trop petite, vous obtiendrez des erreurs d'E/S. Assurez-vous d'ajuster la zone de numérisation avant de procéder à une numérisation, car par défaut, la zone de numérisation est nulle.

SIGNALEMENT DE BUGS

Ce backend n'est pas activement maintenu. Néanmoins, les rapports de bugs et commentaires doivent être envoyés à la liste de diffusion sane-devel. Lors du signalement de bugs, veuillez exécuter le backend avec SANE_DEBUG_UMAX1220U défini sur 10 et joindre une copie des messages du journal.
