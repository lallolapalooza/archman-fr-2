sane-hp5590(5) SANE Scanner Access Now Easy sane-hp5590(5)

NOM

sane-hp5590 - Backend SANE pour les scanners Hewlett-Packard 4500C/4570C/5500C/5550C/5590/7650 Workgroup/Document

DESCRIPTION

La bibliothèque sane-hp5590 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners Hewlett-Packard Workgroup/Document suivants :

•
ScanJet 4500C
•
ScanJet 4570C
•
ScanJet 5500C
•
ScanJet 5550C
•
ScanJet 5590
•
ScanJet 7650

Si vous possédez un scanner autre que ceux listés ci-dessus qui fonctionne avec ce backend, veuillez nous le faire savoir en envoyant le nom exact du modèle du scanner et les identifiants du vendeur et de l'appareil USB (par exemple, depuis /sys/bus/usb/devices, sane-find-scanner(1) ou le journal système) nous. Même si le nom du scanner n'est que légèrement différent des modèles mentionnés ci-dessus, veuillez nous en informer.

OPTIONS

Les options prises en charge par le backend peuvent être sélectionnées soit via des options en ligne de commande pour des programmes comme scanimage(1), soit via des éléments d'interface graphique dans xscanimage(1) ou xsane(1). Les options valides en ligne de commande et leur syntaxe peuvent être listées en utilisant :

scanimage --help -d hp5590:interface:device

où interface et device spécifient le périphérique en question, comme dans le fichier de configuration. Ajoutez --all-options pour lister également les options de lecture du matériel. Le paramètre -d et son argument peuvent être omis pour obtenir des informations sur le premier scanner identifié.

Utilisez la commande :

scanimage -L

pour lister tous les périphériques reconnus par votre installation SANE.

OPTIONS SPÉCIFIQUES AU PÉRIPHÉRIQUE

-l n
Position X du coin supérieur gauche de la zone de numérisation en mm. Plage autorisée : 0 .. 215,889.
-t n
Position Y du coin supérieur gauche de la zone de numérisation en mm. Plage autorisée : 0 .. 297,699.
-x n
Largeur X de la zone de numérisation en mm. Plage autorisée : 0 .. 215,889.
-y n
Hauteur Y de la zone de numérisation en mm. Plage autorisée : 0 .. 297,699.

Par défaut, la taille maximale sera numérisée.

--mode mode
Sélectionne le mode couleur. mode doit être l'un des éléments suivants : « Couleur », « Couleur (48 bits) », « Gris », « Ligne d'art ».
•
« Couleur » - La numérisation est effectuée avec 3 * 8 bits de valeurs couleur RVB par pixel.
•
« Couleur (48 bits) » - La numérisation est effectuée avec 3 * 16 bits de valeurs couleur RVB par pixel.
•
« Gris » - La numérisation est effectuée avec 1 valeur grise de 8 bits par pixel.
•
« Ligne d'art » - La numérisation est effectuée avec 1 bit de valeur noire et blanche par pixel.
--source source
Sélectionne la source pour la numérisation. source doit être l'un des éléments suivants : « Chargeur », « ADF », « ADF Recto-Verso », « Diapositives TMA », « Négatifs TMA ».
•
« Chargeur » - Numérise le document sur la vitre du chargeur.
•
« ADF » - Numérise les faces avant des documents avec le chargeur automatique de documents.
•
« ADF Recto-Verso » - Numérise les faces avant et arrière des documents avec le chargeur automatique de documents. Notez que les images du verso doivent être pivotées dans une étape de post-traitement séparée.
•
« Diapositives TMA » - Numérisation de diapositives avec adaptateur pour supports transparents. (Non entièrement pris en charge par le backend hp5590).
•
« Négatifs TMA » - Numérisation de films négatifs avec adaptateur pour supports transparents. (Non entièrement pris en charge par le backend hp5590).
--resolution res
Définit la résolution de l'image numérisée en dpi. res doit être l'un des éléments suivants : 100, 200, 300, 600, 1200, 2400.

Paramètres par défaut : Ligne d'art, Chargeur, 100 dpi.

--extend-lamp-timeout[=oui|non]
Prolonge la période de délai de la lampe. non = 15 minutes, oui = 1 heure. (Par défaut : non)
--wait-for-button[=oui|non]
Attend la pression d'un bouton avant le début de la numérisation. (Par défaut : non)
--preview[=oui|non]
Demande une numérisation de qualité aperçu. (Par défaut : non)
--hide-eop-pixel[=oui|non]
Masque les pixels indicateurs de fin de page et les remplace par la couleur des pixels voisins. (Par défaut : oui)
Le scanner utilise le dernier pixel de chaque ligne de numérisation pour stocker l'état de fin de page. Ceci est nécessaire pour détecter la fin de la feuille du document lorsque le chargeur automatique de documents (ADF) est utilisé. Malheureusement, les pixels de fin de page sont également générés lors des numérisations sur chargeur. Il est recommandé de masquer ces pixels.
--trailing-lines-mode mode
Mode de remplissage des lignes de fin après la fin de page lors de l'utilisation du chargeur automatique de documents (ADF). mode doit être l'un des éléments suivants : « last », « raw », « raster », « white », « black », « color ». (Par défaut : « last »)
•
« last » = répéter la dernière ligne de numérisation (recommandé),
•
« raw » = lire les données brutes de numérisation (non recommandé),
•
« raster » = générer un motif de pixels noir et blanc,
•
« white » = pixels blancs,
•
« black » = pixels noirs,
•
« color » = pixels couleur RVB ou gris (voir option suivante).
--trailing-lines-color n
Définit la valeur de couleur pour remplir les lignes de numérisation de fin en mode « color » (voir option précédente). (Couleur par défaut : violet)
La valeur de couleur RVB doit être spécifiée et calculée comme 65536 * r + 256 * g + b, avec r, g, b étant des valeurs comprises entre 0 et 255.

OPTIONS DE LECTURE

Les options suivantes permettent de lire l'état des boutons, la valeur du compteur, le réglage de la couleur et l'état du document dans l'ADF. Ceci peut être utilisé pour contrôler par programme des options de scanner correspondantes comme le passage du mode chargeur à ADF, ou le déclenchement de tâches de post-traitement après la numérisation.

--button-pressed
Obtient l'identifiant du dernier bouton pressé. L'identifiant est l'un des éléments suivants : « none », « power », « scan », « collect », « file », « email », « copy », « up », « down », « mode », « cancel ».
Le scanner stocke l'identifiant du dernier bouton pressé jusqu'à ce qu'il soit lu. Après lecture, l'état est réinitialisé et les lectures suivantes renverront « none ».
--color-led
Obtient l'état des indicateurs LED de couleur. L'état est soit « color », soit « black_white ».
--counter-value
Obtenir la valeur du compteur telle qu'affichée sur l'écran LCD. La valeur est comprise entre 1 et 99.
--doc-in-adf
Obtenir l'état de l'indicateur de présence de document du chargeur automatique de documents (CAD). L'état est soit « oui », soit « non ».

CONSEILS POUR LES UTILISATEURS DE SCANBD

scanbd(8) est un démon de boutons de scanner, qui peut lire les boutons du scanner et déclencher des actions de numérisation.

N'utilisez pas l'ancienne interface scanbuttond(8) avec hp5590. Elle est obsolète et ne doit plus être utilisée. L'interface régulière de scanbd(8) est entièrement prise en charge par la version actuelle du backend hp5590.

Cet exemple montre un fichier de configuration minimum et le fichier de script correspondant pour scanbd(8) à inclure dans scanbd.conf.

•
hp5590.conf
device hp5590 {
    # Correspondance de l'appareil
    filter = "^hp5590.*"
    desc = "Famille de scanners HP5590"
    # Lire la valeur du compteur et la stocker dans une variable d'environnement.
    function function_lcd_counter {
        filter = "^counter-value.*"
        desc   = "hp5590: Compteur LCD"
        env    = "SCANBD_FUNCTION_LCD_COUNTER"
    }
    # Exécuter le script de numérisation lorsque le bouton est enfoncé.
    action do-scan {
        filter = "^button-pressed.*"
        desc   = "hp5590: Bouton de numérisation enfoncé"
        script = "scan_action.script"
        string-trigger {
            from-value  = "none"
            to-value    = "scan"
        }
    }
}
•
scan_action.script
#!/bin/bash
echo device = $SCANBD_DEVICE
echo action = $SCANBD_ACTION
echo counter = $SCANBD_FUNCTION_LCD_COUNTER
scanfile="$HOME/tmp/scans/scan-$(date +%s).pnm"
case $SCANBD_ACTION in
do-scan)
    scanimage -d "$SCANBD_DEVICE" > "$scanfile"
    ;;
*)
    echo Warning: Action scanbd inconnue: "$SCANBD_ACTION"
    ;;
esac

ENVIRONNEMENT

Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend.

SANE_DEBUG_HP5590

Des niveaux de débogage plus élevés augmentent le caractère verbeux de la sortie :

10 - traitement générique
20 - messages de backend verbeux
40 - commandes HP5590 de haut niveau
50 - commandes HP5590 de bas niveau (USB dans USB)
Exemple:
export SANE_DEBUG_HP5590=50
