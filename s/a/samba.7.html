NOM

samba - Serveur de fichiers SMB/CIFS et AD Windows pour UNIX

SYNTAXE

samba

DESCRIPTION

La suite logicielle Samba est une collection de programmes qui implémente le protocole Server Message Block (couramment abrégé SMB) pour les systèmes UNIX et fournit des services Active Directory. La première version du protocole SMB est parfois également appelée Common Internet File System (CIFS). Pour une description plus complète, voir http://www.ubiqx.org/cifs/. Samba implémente également le protocole NetBIOS dans nmbd(8).

samba(8)

Le démon samba fournit les services Active Directory ainsi que les services de fichiers et d'impression aux clients SMB. Le fichier de configuration de ce démon est décrit dans smb.conf(5).

smbd(8)

Le démon smbd fournit les services de fichiers et d'impression aux clients SMB. Le fichier de configuration de ce démon est décrit dans smb.conf(5).

nmbd(8)

Le démon nmbd fournit le service de noms NetBIOS et la prise en charge de la navigation. Le fichier de configuration de ce démon est décrit dans smb.conf(5).

winbindd(8)

winbindd est un démon utilisé pour intégrer l'authentification et la base de données des utilisateurs à UNIX.

smbclient(1)

Le programme smbclient implémente un client simple de type ftp. Ceci est utile pour accéder aux partages SMB sur d'autres serveurs SMB compatibles, et peut également être utilisé pour permettre à une machine UNIX d'imprimer sur une imprimante connectée à n'importe quel serveur SMB.

samba-tool(8)

samba-tool est l'outil principal d'administration de Samba concernant les services Active Directory.

testparm(1)

L'utilitaire testparm est un simple vérificateur de syntaxe pour le fichier de configuration smb.conf(5) de Samba. En mode serveur AD, il convient cependant d'utiliser samba-tool testparm.

smbstatus(1)

L'outil smbstatus donne accès aux informations sur les connexions actuelles à smbd.

nmblookup(1)

L'outil nmblookup permet d'effectuer des requêtes de noms NetBIOS.

smbpasswd(8)

La commande smbpasswd est un outil pour définir les mots de passe sur Samba local, mais aussi sur les serveurs SMB distants.

smbcacls(1)

La commande smbcacls est un outil pour définir les ACL sur les serveurs SMB distants.

smbtree(1)

La commande smbtree est un outil de voisinage réseau basé sur du texte.

smbtar(1)

smbtar peut effectuer des sauvegardes de données directement depuis des serveurs SMB.

smbspool(8)

smbspool est un utilitaire auxiliaire pour l'impression sur des imprimantes connectées à des serveurs SMB.

smbcontrol(1)

smbcontrol est un utilitaire qui peut modifier le comportement des démons samba, smbd, nmbd et winbindd en cours d'exécution.

rpcclient(1)

rpcclient est un utilitaire qui peut être utilisé pour exécuter des commandes RPC sur des serveurs SMB distants.

pdbedit(8)

La commande pdbedit peut être utilisée pour maintenir la base de données des utilisateurs locaux sur un serveur Samba.

net(8)

La commande net est l'outil d'administration principal pour les serveurs membres et autonomes Samba.

wbinfo(1)

wbinfo est un utilitaire qui récupère et stocke des informations relatives à winbind.

profiles(1)

profiles est un utilitaire en ligne de commande qui peut être utilisé pour remplacer toutes les occurrences d'un certain SID par un autre SID.

log2pcap(1)

log2pcap est un utilitaire pour générer des fichiers de trace pcap à partir des fichiers journaux de Samba.

vfstest(1)

vfstest est un utilitaire qui peut être utilisé pour tester les modules vfs.

ntlm_auth(1)

ntlm_auth est un utilitaire auxiliaire pour les programmes externes souhaitant effectuer l'authentification NTLM.

smbcquotas(1)

smbcquotas est un outil pour gérer les quotas sur les serveurs SMB distants.

COMPOSANTS

La suite Samba est composée de plusieurs composants. Chaque composant est décrit dans une page de manuel séparée. Il est fortement recommandé de lire la documentation fournie avec Samba et les pages de manuel des composants que vous utilisez. Si les pages de manuel et les documents ne sont pas assez clairs, veuillez visiter https://devel.samba.org pour savoir comment signaler un bug ou soumettre un correctif.

Si vous avez besoin d'aide, visitez la page web de Samba à l'adresse https://www.samba.org/ et explorez les nombreuses options qui s'offrent à vous.

DISPONIBILITÉ

La suite logicielle Samba est sous licence GNU Public License (GPL). Une copie de cette licence devrait avoir été fournie avec le paquet dans le fichier COPYING. Vous êtes encouragé à distribuer des copies de la suite Samba, mais veuillez respecter les termes de cette licence.

La dernière version de la suite Samba peut être obtenue sur https://download.samba.org/pub/samba/.

Le wiki Samba à https://wiki.samba.org contient également beaucoup d'informations utiles. Sur la liste de diffusion Samba à https://lists.samba.org, vous pouvez trouver beaucoup d'informations dans les archives et vous pouvez vous abonner à la liste samba pour demander de l'aide ou discuter de sujets.

CONTRIBUTIONS

Si vous souhaitez contribuer au projet Samba, je vous suggère de rejoindre la liste de diffusion Samba à https://lists.samba.org.

Si vous avez des correctifs à soumettre, visitez https://devel.samba.org/ pour obtenir des informations sur la manière de le faire correctement. Nous préférons les correctifs au format git format-patch.

CONTRIBUTEURS

Les contributeurs au projet sont maintenant trop nombreux pour être mentionnés ici, mais tous méritent les remerciements de tous les utilisateurs de Samba. Pour voir une liste complète, consultez le journal des modifications dans le paquet source pour les changements pré-CVS et sur https://git.samba.org/ pour les contributeurs à Samba après GIT. GIT est le système de contrôle de code source Open Source utilisé par l'équipe Samba pour développer Samba. Le projet aurait été ingérable sans lui.

AUTEUR
