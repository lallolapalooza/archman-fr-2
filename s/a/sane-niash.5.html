sane-niash(5) SANE Scanner Access Now Easy sane-niash(5)

NOM

sane-niash - Backend SANE pour les scanners basés sur le chipset NIASH

DESCRIPTION

Le programme sane-niash implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners basés sur le chipset NIASH. Ce backend essaiera de supporter les modèles suivants :

FABRICANT:       MODÈLE:         IDENTIFIANT USB:
---------------  ----------------  ---------
Agfa             Snapscan Touch    06BD-0100 (1)(a)
Trust            Office Scan 19200 047B-1000 (1)(a)
Hewlett-Packard  Scanjet 3300c     03F0-0205 (1)(a)(b)
Hewlett-Packard  Scanjet 3400c     03F0-0405 (2)(b)
Hewlett-Packard  Scanjet 4300c     03F0-0305 (2)(a)
Silitek          ScanJet 4300c     047B-1002 (2)(b)

ASIC : (1) - NIASH00012/00013/00014 / (2) - NIASH00019
FRONT-END ANALOGIQUE : (a) - ESIC ES8100QA / (b) - WM8143-12

CONFIGURATION

Le fichier niash.conf est destiné aux futures options de configuration. Les lignes vides et les lignes commençant par un dièse (#) sont ignorées. Actuellement, aucune option de configuration n'existe.

FICHIERS

/usr/lib/sane/libsane-niash.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-niash.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

LIMITATIONS

Si vous utilisez un
Hewlett-Packard Scanjet 3400c ou
Hewlett-Packard Scanjet 4300c
avec le noyau Linux 2.6, une version du noyau 2.6.8 ou plus récente est nécessaire.

ENVIRONNEMENT

SANE_DEBUG_NIASH
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_NIASH=255
