NOM

sas_disk_blink - faire clignoter la LED d'un disque SAS

SYNTAXE

sas_disk_blink [--help] [--set NUM] [--verbose] PÉRIPHÉRIE

DESCRIPTION

Ce script shell bash tente de faire clignoter la LED du disque SAS désigné par PÉRIPHÉRIE. Par défaut, la LED clignotera pendant 30 secondes. Ceci est destiné à aider à identifier quel disque correspond à une PÉRIPHÉRIE donnée.

Le script utilise l'utilitaire sdparm et manipule le champ "Ready LED Meaning" (RLM) dans la page de mode spécifique au protocole afin de faire clignoter la LED.

OPTIONS

Les arguments pour les options longues sont obligatoires pour les options courtes également.

-h, --help
affiche le message d'utilisation puis quitte.
-s, --set NUM
quand NUM est 0, le champ RLM est effacé. Quand NUM est 1, le champ RLM est défini. Quand NUM > 1, la LED du disque SAS est mise en mode clignotant pendant NUM secondes. Si cette option n'est pas fournie, la LED du disque SAS est mise en mode clignotant pendant 30 secondes.
-v, --verbose
augmente le niveau de verbosité.

STATUT DE SORTIE

Le statut de sortie de ce script est 0 lorsqu'il réussit. Sinon, le statut de sortie est celui du dernier utilitaire sdparm appelé. Voir la page de manuel sdparm(8).
