NOM

sane-epsonds - Backend SANE pour les scanners EPSON ESC/I-2

DESCRIPTION

La bibliothèque sane-epsonds implémente un backend SANE (Scanner Access Now Easy) qui permet d'accéder aux scanners Epson ESC/I-2.

Les options de ligne de commande valides et leur syntaxe peuvent être listées en utilisant

scanimage --help -d epsonds

Tous les périphériques ne supportent pas toutes les options.

Mode de numérisation
Le commutateur --mode sélectionne le mode de fonctionnement de base du scanner. Les choix valides sont Lineart, Gray et Color. Le mode Lineart est uniquement en noir et blanc, Gray produira 256 niveaux de gris ou plus selon le scanner et Color signifie un mode couleur 24 bits ou plus selon le scanner. Certains scanners utiliseront en interne 36 bits de couleur, leur interface externe peut cependant ne supporter que 24 bits.

L'option --depth sélectionne la profondeur de bits utilisée par le scanner. Cette option n'est disponible que pour les scanners qui prennent en charge plus d'un niveau de profondeur de bits. Les anciens scanners transféreront toujours l'image en mode 8 bits. Les nouveaux scanners permettent de sélectionner soit 8 bits, 12 ou 14 bits par canal de couleur. Pour une numérisation couleur, cela signifie une profondeur de couleur effective de 36 ou 42 bits sur les trois canaux. Les choix valides dépendent du modèle de scanner.

Le commutateur --resolution sélectionne la résolution pour une numérisation. Certains scanners EPSON numériseront à n'importe quelle résolution comprise entre la valeur la plus basse et la plus haute possible. La liste rapportée par le scanner peut être affichée en utilisant les paramètres "--help -d epson" de scanimage(1).

Les options de géométrie -l -t -x -y contrôlent la zone de numérisation : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de numérisation. Tous les paramètres sont spécifiés en millimètres.

L'option --source sélectionne la source de numérisation. Les options valides dépendent des options installées. La valeur par défaut est "Flatbed".

L'option --eject éjecte la feuille dans l'ADF.

L'option --adf-mode sélectionne le mode ADF (simplex/duplex).

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/epsonds.conf spécifie le ou les périphériques que le backend utilisera. Les types de connexion possibles sont :

USB
Pour les scanners USB non détectés automatiquement, leur ID VENDEUR et PRODUCTEUR peuvent être spécifiés manuellement dans le fichier de configuration. Plus d'informations sur la syntaxe valide pour les périphériques USB peuvent être trouvées dans sane-usb(5).
Réseau (pas encore pris en charge)
Les scanners réseau peuvent être auto-détectés si autodiscovery est spécifié après le mot-clé net. Une adresse IP pour se connecter peut également être utilisée.

FICHIERS

/usr/lib/sane/libsane-epsonds.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-epsonds.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui supportent le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_EPSONDS
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux inférieurs réduisent la verbosité. Les valeurs autour de 11-16 suffiront généralement pour un rapport de bug.

VOIR AUSSI

sane-usb(5), scanimage(1), xscanimage(1), xsane(1)
