NOM

sane-escl - Backend SANE pour scanners eSCL

DESCRIPTION

La bibliothèque sane-escl implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners utilisant le protocole eSCL.

Actuellement, les modèles suivants fonctionnent avec ce backend (Cette liste n'est pas exhaustive) :

BROTHER DCP-J772DW, DCP-L2530DW
BROTHER HL-L2590DW
BROTHER MFC-J4540DW, MFC-J985DW, MFC-J1300DW
CANON IR C3520
CANON PIXMA MG5765
CANON PIXMA G4511, G7050
CANON PIXMA TR4520, TR4540, TR4550, TR4551, TR7500, TR8500
CANON PIXMA TR8520
CANON PIXMA TS3100, TS3150, TS3151, TS3152, TS3300, TS3350
CANON PIXMA TS3351, TS3352, TS3450, TS3451, TS3452, TS5350
CANON PIXMA TS5351, TS5150, TS6150, TS8050, TS8350, TS9100
EPSON ET-2750, ET-3750, ET-4750
EPSON EcoTank L3160
EPSON XP-4200, XP-6100
HP DESKJET 2710, DESKJET 2723, DESKJET 3760
HP LASERJET ENTREPRISE FLOW MFP M578,
HP LASERJET MFP M28W, LASERJET MFP M630
HP OFFICEJET 4630, OFFICEJET PRO 8610
RICOH SP3710S
XEROX VERSALINK C7220

Le backend sane-escl pour SANE prend en charge les périphériques AirScan/eSCL qui s'annoncent via mDNS sous le nom _uscan._utcp ou _uscans._utcp. Si le périphérique est disponible, le backend sane-escl en récupère les capacités. L'utilisateur configure et lance la numérisation. Une liste des périphériques utilisant le protocole eSCL peut être trouvée à l'adresse https://support.apple.com/en-us/HT201311. Bien que ces périphériques soient censés fonctionner, votre expérience peut varier.

FICHIERS

/etc/sane.d/escl.conf
Le fichier de configuration du backend.
/usr/lib/sane/libsane-escl.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-escl.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_ESCL
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les informations de débogage. Des niveaux inférieurs réduisent la verbosité.
