NOM

sane-microtek - Backend SANE pour scanners Microtek

DESCRIPTION

La bibliothèque sane-microtek implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès aux scanners Microtek de la "seconde génération". À l'heure actuelle, le matériel suivant est connu pour fonctionner avec ce backend :

Microtek ScanMaker E2, E3, E6
Microtek ScanMaker II, IIG, IIHR, IISP, III
Microtek ScanMaker 35t, 35t+, 45t
Microtek ScanMaker 600GS, 600ZS (voir les notes sur les bugs)
Agfa StudioScan
Agfa StudioScan II, StudioScan IIsi
Agfa Arcus II (mais pas l'"Arcus")
Agfa DuoScan (préliminaire)
Vobis "Highscreen Realscan"
Microtek Color PageWiz (préliminaire)

Adaptateur de médias transparents
Chargeur automatique de documents

Le pilote prend en charge les numérisations en trait de dessin, halftone, niveaux de gris 8bpp et couleur 24bpp à des résolutions normales et "étendues" (c'est-à-dire 1200x1200 sur un E6), des numérisations rapides pour les aperçus couleur et des tables gamma téléchargeables.

Les scanners pris en charge sont tous des scanners SCSI. Cependant, certains modèles à port parallèle peuvent fonctionner (sous Linux), s'ils utilisent une puce parport->scsi, et si vous pouvez trouver un pilote scsi->parport. Ceci est connu pour être le cas du Color PageWiz.

Le pilote ne prend pas en charge les scanners Microtek les plus récents, tels que les V330 et V660, qui utilisent un jeu de commandes SCSI-II nouveau et très différent. Pour ceux-ci, essayez le backend alternatif microtek2(5). La plupart des scanners non-SCSI utiliseraient le nouveau jeu de commandes. La plupart des scanners plus récents que le Scanmaker E6 utiliseraient le nouveau jeu de commandes.

Si vous possédez un scanner Microtek autre que ceux listés ci-dessus, dites-nous ce qui se passe --- voir la section BUGS à la fin de ce document.

Bien que cette page de manuel soit généralement mise à jour à chaque version, des informations à jour sur les nouvelles versions et des astuces utiles supplémentaires sont disponibles sur la page d'accueil du backend :

http://www.mir.com/mtek/

NOMS DE PÉRIPHÉRIQUE

Ce backend attend des noms de périphérique de la forme :

spécial

Où spécial est le nom de chemin UNIX du périphérique spécial qui correspond au scanner. Le nom du périphérique spécial doit être un périphérique SCSI générique ou un lien symbolique vers un tel périphérique. Sous Linux, un tel nom de périphérique pourrait être /dev/sga ou /dev/sge, par exemple.

CONFIGURATION

Le contenu du fichier microtek.conf est une liste de noms de périphérique qui correspondent aux scanners Microtek. Les lignes vides et les lignes commençant par un symbole dièse (#) sont ignorées. Un exemple de fichier de configuration est montré ci-dessous :

/dev/scanner
# ceci est un commentaire
/dev/sge

Le fichier de configuration peut également contenir les jetons spéciaux norealcal ou noprecal. norealcal désactivera l'utilisation de commandes de calibration de scanner magiques et non documentées qui fonctionnent sur l'E6, mais peuvent ne pas fonctionner avec d'autres modèles. noprecal désactivera la logique qui tente d'éviter la pré-calibration du scanner. Cette logique n'aurait été activée que si le code de calibration magique était désactivé.

FICHIERS

/etc/sane.d/microtek.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-microtek.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-microtek.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") et ensuite dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" entraînerait la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_MICROTEK
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Une valeur de 128 demande une sortie de débogage maximale ; des niveaux plus bas réduisent la verbosité.

BUGS

Bugs/limitations connus :

Luminosité et contraste défectueux.
Le 600GS est uniquement en niveaux de gris et se bloquera si vous sélectionnez la couleur. (Malheureusement, le 600GS et le 600ZS sont indiscernables par logiciel.)

c'est-à-dire ne vous plaignez pas de ceux-ci --- mais si la luminosité et/ou le contraste fonctionnent pour vous, s'il vous plaît, dites-le moi.

Si votre scanner se bloque, essayez de régler l'option norealcal ou noprecal dans le fichier de configuration (d'abord l'une, puis les deux), et voyez si cela aide. (Si c'est le cas, signalez-le.)

Envoyez des rapports de bugs détaillés et des informations sur de nouveaux scanners à mtek-bugs@mir.com. Tous les rapports de bugs et les demandes d'informations sur de nouveaux scanners doivent inclure un fichier journal d'erreurs. Vous pouvez générer une sortie stderr abondante en définissant la variable d'environnement SANE_DEBUG_MICROTEK décrite ci-dessus. Par exemple :

setenv SANE_DEBUG_MICROTEK 128

Les commentaires plus généraux, suggestions et questions sur les interfaces graphiques ou SANE doivent être envoyés à sane-devel@alioth-lists.debian.net, la liste de diffusion des développeurs SANE. Jetez un œil à http://www.sane-project.org/mailing-lists.html concernant l'abonnement à sane-devel.

sane-microtek - Pilote pour scanners Microtek.

Description

Le pilote sane-microtek est un backend pour SANE (Scanner Access Now Easy) qui supporte un certain nombre de scanners Microtek.

Pour une liste des appareils supportés, voir la liste des appareils supportés par SANE.

Options

Ce pilote n'a pas d'options spécifiques. Les options génériques de SANE sont disponibles.

Configuration

Ce pilote peut être configuré dans le fichier /etc/sane.d/microtek.conf. Le fichier de configuration ne contient généralement que le nom du périphérique (par exemple, /dev/usb/scanner0 ou /dev/scanner).

Il est également possible de spécifier l'adresse du périphérique USB, soit par numéro de vendeur/produit, soit par le chemin du bus/périphérique.

# Pour les scanners connectés via SCSI
scsi SCANNER

# Pour les scanners connectés via USB
usb 0x050f 0x0101

# Ou spécifier le chemin du périphérique USB
# usb /dev/bus/usb/001/002

Les options de ligne de commande peuvent être utilisées pour passer des paramètres spécifiques au pilote, par exemple, pour activer le mode de débogage:

$ scanimage -d microtek:/dev/usb/scanner0 --debug 1 > debug.txt

Voir également

sane(7), sane-scsi(5)
