save_d(3) Manuel des fonctions de bibliothèque save_d(3)

NOM

save_d - Pilote AA-lib utilisé pour enregistrer une image en art ASCII dans un fichier dans le format spécifié.

SYNTAXE

#include <aalib.h>

extern const struct aa_driver save_d;

DESCRIPTION

Initialisez ce pilote en utilisant la fonction aa_init et spécifiez les paramètres dépendants du pilote dans la structure aa_savedata pour enregistrer l'image dans un fichier. Voir la documentation texinfo pour les détails.
