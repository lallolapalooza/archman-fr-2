NOM

samba_downgrade_db - Outil Samba pour la rétrogradation des bases de données AD

SYNTAXE

samba_downgrade_db [-H] [-s]

DESCRIPTION

Cet outil fait partie de la suite samba(8).

Le format de la base de données Samba Active Directory (AD) a changé dans les versions 4.8 et 4.11. Lors de la rétrogradation d'un contrôleur de domaine Samba AD (DC) vers une version antérieure à l'une de ces versions (par exemple, de 4.11 à 4.10), la base de données AD doit être manuellement rétrogradée *avant* que les paquets Samba puissent être rétrogradés en toute sécurité.

Cet outil rétrograde une base de données sam.ldb de Samba du format utilisé dans la version 4.23.3 vers celui de la version 4.7. Le format de base de données v4.7 peut être lu en toute sécurité par n'importe quelle version de Samba. Si nécessaire, les versions ultérieures de Samba réorganiseront et reconfigureront une base de données au format v4.7 lors du premier démarrage de l'exécutable samba.

Notez que tous les services Samba doivent être arrêtés sur le DC avant d'exécuter cet outil. Une fois l'outil exécuté, ne redémarrez pas samba et ne modifiez pas la base de données avant que le paquet logiciel Samba n'ait été rétrogradé.

OPTIONS

-H [fichier sam.ldb]

Lien direct vers un fichier sam.ldb au lieu d'utiliser le chemin dans le smb.conf système

-s [fichier smb.conf]

Lien direct vers le fichier smb.conf au lieu du défaut système (généralement dans /usr/local/samba/etc/smb.conf)

Cette page de manuel est complète pour la version 4.23.3 de la suite Samba.
