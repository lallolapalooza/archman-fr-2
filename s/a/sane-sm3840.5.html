NOM

sane-sm3840 - Backend SANE pour les scanners Microtek avec puce USB SCAN08

DESCRIPTION

La bibliothèque sane-sm3840 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès à certains scanners Microtek dotés de la puce USB SCAN08.

Il existe des backends pour les scanners Microtek utilisant l'ensemble de commandes SCSI. Voir sane-microtek(5) et sane-microtek2(5) pour plus de détails.

Il existe également un pilote pour la série Microtek 3600, voir sane-sm3600(5) pour plus de détails.

À l'heure actuelle, les scanners suivants fonctionnent positivement avec ce backend :

Vendeur     Identifiant Produit:     Remarque :
--------   --------------  -----------
Microtek   ScanMaker 3840  Tous les modes OK
Microtek   ScanMaker 4800  Tous les modes OK

Si vous possédez un scanner Microtek avec la puce SCAN08 autre que ceux listés ci-dessus, il peut fonctionner ou non avec SANE. N'hésitez pas à contacter l'auteur du backend (earle@ziplabel.com) pour signaler les résultats obtenus avec les scanners ne figurant pas sur la liste.

OPTIONS D'INTERFACE

Les options suivantes sont prises en charge par le pilote sane-sm3840 :

--mode couleur|niveaux de gris|noir et blanc|tramage
Mode couleur ou niveaux de gris.
--resolution 150|300|600|1200
Pixels par pouce pour les numérisations.
--depth 8|16
Notez que les bits les moins significatifs du mode 16 bits par pixel peuvent être du bruit.
--brightness 1..4096
Des nombres plus élevés augmentent la luminosité de l'image retournée.
--contrast 0.1..9.9
Des nombres plus élevés diminuent le contraste de l'image retournée.
--lamp-timeout 1..15
Temps en minutes avant que la lampe ne s'éteigne après une numérisation.

CONFIGURATION

Ce backend ne prend pas en charge de fichier de configuration pour le moment.

FICHIERS

/usr/lib/sane/libsane-sm3840.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-sm3840.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_SM3840
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande l'affichage de toutes les sorties de débogage. Des niveaux plus bas réduisent la verbosité. Pour voir les messages d'erreur sur la sortie standard d'erreur, définissez SANE_DEBUG_SM3840 à 1.
