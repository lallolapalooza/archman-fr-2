SAMBA-DCERPCD(8) Outils d'administration système SAMBA-DCERPCD(8)

NOM

samba-dcerpcd - C'est l'un des processus serveur DCERPC de Samba qui peut écouter sur des sockets où des services RPC sont offerts et est le processus parent des services DCERPC qu'il invoque. Sauf s'il est invoqué séparément, il est démarré à la demande depuis smbd ou winbind et sert DCERPC uniquement via des tubes nommés (np) en tant que processus d'aide. Ce sera la configuration standard pour la plupart des installations (serveur autonome/membre/serveur AD) sauf s'ils modifient leurs scripts de démarrage. Notez que lorsque Samba est configuré en tant que contrôleur de domaine Active Directory, le processus samba qui invoque smbd fournira toujours ses services DCERPC normaux, pas samba-dcerpcd. Lorsqu'il est invoqué séparément par des scripts de démarrage système ou un démon, l'option globale smb.conf rpc start on demand helpers = false DOIT être définie pour permettre à samba-dcerpcd de démarrer de manière autonome.

SYNTAXE

samba-dcerpcd [-D|--daemon] [-i|--interactive] [-F|--foreground] [--no-process-group] [-d <niveau de débogage>] [--debug-stdout] [--configfile=<fichier de configuration>] [--option=<nom>=<valeur>] [--leak-report] [--leak-report-full] [-V|--version] [--libexec-rpcds] [--np-helper] [--ready-signal-fd=<fd>] [<SERVICE_1>] [<SERVICE_2>] [<...>]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

samba-dcerpcd peut être utilisé de deux manières. Dans le cas normal sans modification du script de démarrage et avec l'option globale smb.conf rpc start on demand helpers = true définie (paramètre par défaut), il est invoqué à la demande par smbd ou winbind avec une ligne de commande contenant --np-helper pour servir DCERPC via des tubes nommés (np). Il peut également être utilisé en mode autonome où il est démarré séparément de smbd ou winbind via les scripts de démarrage système. S'il est invoqué en tant que démon autonome ou démarré à partir des scripts de démarrage système, l'option globale smb.conf rpc start on demand helpers = false DOIT être définie sur false. Si l'option globale smb.conf rpc start on demand helpers = true est définie sur true ou laissée par défaut, samba-dcerpcd échouera au démarrage et enregistrera un message d'erreur.

Notez que lorsque Samba est exécuté en mode contrôleur de domaine Active Directory, le code AD de Samba fournira toujours ses services DCERPC normaux tout en permettant à samba-dcerpcd de fournir des services comme SRVSVC de la même manière que smbd le faisait dans cette configuration.

Le mode autonome peut également être utile en dehors du cadre de Samba, par exemple, pour une utilisation avec le serveur SMB2 du noyau Linux ksmbd ou potentiellement d'autres implémentations de serveur SMB2. Dans ce mode, il se comporte comme inetd et écoute sur des sockets pour le compte des implémentations de serveurs RPC.

Lorsqu'un client se connecte, samba-dcerpcd démarrera le binaire de service RPC pertinent à la demande et lui transmettra la connexion. Lorsqu'un service RPC est resté inactif pendant un certain temps, samba-dcerpcd lui demandera de s'arrêter à nouveau.

OPTIONS

-D|--daemon

Si spécifié, ce paramètre fait fonctionner le serveur comme un démon. C'est-à-dire qu'il se détache et s'exécute en arrière-plan, traitant les requêtes sur le port approprié. Faire fonctionner le serveur comme un démon est utile pour exécuter samba-dcerpcd en dehors du cadre de Samba. Cependant, il peut également être utilisé de cette manière dans Samba pour les serveurs membres s'il est configuré pour démarrer via les scripts de démarrage système. Ce commutateur est supposé si samba-dcerpcd est exécuté sur la ligne de commande d'un shell.

-i|--interactive

Si ce paramètre est spécifié, il fait fonctionner le serveur en mode "interactif", pas en tant que démon, même si le serveur est exécuté sur la ligne de commande d'un shell. La définition de ce paramètre annule le mode démon implicite lorsqu'il est exécuté à partir de la ligne de commande. samba-dcerpcd n'acceptera qu'une seule connexion et se terminera. Il écrira également sur la sortie standard, comme si le paramètre -S avait été donné.

-F|--foreground

Si spécifié, ce paramètre empêche le processus principal samba-dcerpcd de devenir un démon, c'est-à-dire de doubler la fork et de se dissocier du terminal. Des processus enfants sont toujours créés normalement pour traiter chaque demande de connexion, mais le processus principal ne se termine pas. Ce mode de fonctionnement convient pour exécuter samba-dcerpcd sous des superviseurs de processus tels que supervise et svscan du package daemontools de Daniel J. Bernstein, ou le moniteur de processus AIX.

--no-process-group

Ne crée pas de nouveau groupe de processus pour samba-dcerpcd.

--libexec-rpcds

Offre des services RPC pour tous les démons du répertoire LIBEXECDIR de Samba, tous les programmes commençant par "rpcd_" sont supposés offrir des services RPC. Si vous n'utilisez pas l'option --libexec-rpcds, vous pouvez lister explicitement tous les assistants de service RPC sur la ligne de commande.

--np-helper

Exécute samba-dcerpcd à la demande en ouvrant des sockets de tubes nommés comme assistants pour smbd ou winbind. Pour fonctionner dans ce mode, l'option globale smb.conf rpc start on demand helpers = true doit être définie sur true (c'est le paramètre par défaut).

--ready-signal-fd=<fd>

Signale la disponibilité du service via ce descripteur de fichier (fd) à smbd ou winbind. Pour usage interne uniquement.
