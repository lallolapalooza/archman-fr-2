sane-kvs1025(5) SANE Scanner Access Now Easy sane-kvs1025(5)

NOM

sane-kvs1025 - Backend SANE pour les scanners USB ADF Panasonic KV-S102xC.

DESCRIPTION

La bibliothèque sane-kvs1025 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners Panasonic KV-S1020C/1025C et KV-S1045C.

PROBLÈMES CONNUS

Ce document a été écrit par le projet SANE, qui n'a aucune information concernant les capacités ou la fiabilité du backend. Toutes les informations contenues ici sont suspectes.

CRÉDITS

Le backend a été écrit par Tao Zhang / Panasonic Russia Ltd.

Le backend a été porté vers sane-backends 1.0.21 et mis à jour pour utiliser sanei_usb au lieu de libusb par m. allan noah.

Le backend a été testé sur KV-S1025C et 1045C par Tiago Zaniquelli.

VOIR AUSSI

sane(7), sane-usb(5)
