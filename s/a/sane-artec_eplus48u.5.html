NOM

sane-artec_eplus48u - Backend SANE pour le scanner Artec E+ 48U et modèles rebadgés

DESCRIPTION

La bibliothèque sane-artec_eplus48u implémente un backend SANE (Scanner Access Now Easy) qui donne accès à plusieurs scanners plats USB utilisant le chipset GT6816, comme l'Artec E+ 48U. Ces scanners sont équipés d'un capteur d'image contact (CIS).

Une liste complète des appareils supportés peut être trouvée sur http://www.sane-project.org/sane-supported-devices.html.

Ceci est un logiciel ALPHA. Particulièrement si vous testez des scanners nouveaux ou non testés, gardez votre main sur la prise du scanner et débranchez-la si la tête heurte le bout de la zone de scan.

Si vous possédez un scanner autre que ceux mentionnés dans la liste qui fonctionne avec ce backend, veuillez nous en informer en envoyant le nom exact du modèle du scanner et les identifiants USB du vendeur et du produit (par exemple, depuis /proc/bus/usb/devices, sane-find-scanner(1) ou le syslog) à mon attention. Même si le nom du scanner est seulement légèrement différent des modèles mentionnés ci-dessus, veuillez m'en informer.

PROBLÈMES_DU_NOYAU

Si libusb-0.1.6 ou une version ultérieure est installée, cette section peut être ignorée. Le scanner devrait être trouvé par sane-find-scanner(1) sans actions supplémentaires. Pour le réglage des permissions et des informations USB générales, consultez sane-usb(5).

Lorsque vous utilisez le module scanner, un noyau Linux 2.4.12 ou plus récent est requis.

FICHIER_FIRMWARE

Vous avez besoin d'un fichier firmware pour votre scanner. C'est un petit fichier contenant un logiciel qui sera téléchargé dans la mémoire du scanner. Pour les scanners mentionnés ci-dessus, il est généralement nommé Artec48.usb ou 1200.usb. Vous pouvez le trouver sur le CD d'installation fourni par le fabricant, normalement dans le répertoire Win98, WinMe ou similaire. Si le pilote Windows est installé sur votre ordinateur, vous pouvez également trouver le fichier firmware sous c:288vers.

CONFIGURATION

Le contenu du fichier artec_eplus48u.conf est une liste de lignes usb contenant les identifiants du vendeur et du produit qui correspondent aux scanners USB. Le fichier peut également contenir des lignes d'options. Les lignes vides et celles commençant par une dièse (#) sont ignorées. Les scanners sont auto-détectés par les instructions usb vendor_id product_id qui sont déjà incluses dans artec_eplus48u.conf. "vendor_id" et "product_id" sont des nombres hexadécimaux qui identifient le scanner.

Chaque section usb peut avoir des options supplémentaires.

artecFirmwareFile /usr/share/sane/artec_eplus48u/Artec48.usb
Le chemin vers le fichier firmware. Cette option est obligatoire.
redGamma 1.0
greenGamma 1.0
blueGamma 1.0
masterGamma 1.9
Ce sont les valeurs gamma par défaut. Si vous réglez l'option "Défauts" avec une interface graphique, les options gamma seront réinitialisées aux valeurs spécifiées ici.
redOffset 0x28
greenOffset 0x2f
blueOffset 0x2f
redExposure 0xa7
greenExposure 0x116
blueExposure 0xdc
Ce sont les valeurs par défaut pour le décalage et le temps d'exposition. Vous pouvez les modifier (par exemple, pour accélérer la calibration) si vous ne souhaitez pas enregistrer les données de calibration de manière permanente.
vendorString Artec
modelString E+ 48U
Par défaut, le scanner est rapporté comme "Artec E+ 48U". Si cela ne vous convient pas, par exemple parce que vous possédez un Tevion MD 9693, modifiez les options en conséquence.

FICHIERS

/usr/local/etc/sane.d/artec_eplus48u.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/local/lib/sane/libsane-artec_eplus48u.a
La bibliothèque statique implémentant ce backend.
/usr/local/lib/sane/libsane-artec_eplus48u.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes supportant le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par un deux-points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail courant (".") et ensuite dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour résultat la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_ARTEC_EPLUS48U
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_ARTEC_EPLUS48U=3

BUGS

Ce backend a été testé uniquement sous Linux. Si vous l'utilisez sur une plateforme différente, veuillez nous contacter.

L'interpolation à 1200 dpi est faible.

Le support des boutons manque en raison du manque de support dans SANE.

Veuillez nous contacter si vous trouvez un bug : http://www.sane-project.org/bugs.html.
