sane-hp5400(5) SANE Scanner Access Now Easy sane-hp5400(5)

NOM

sane-hp5400 - Backend SANE pour les scanners Hewlett-Packard 54XX

DESCRIPTION

La bibliothèque sane-hp5400 implémente un backend SANE (Scanner Access Now Easy) qui fournit un accès aux scanners à plat USB Hewlett-Packard suivants :

ScanJet 5400C
ScanJet 5470C
ScanJet 5490C

Plus de détails peuvent être trouvés sur la page d'accueil du backend hp5400 : http://hp5400backend.sourceforge.net/.

Ceci est un logiciel ALPHA. Gardez votre main sur la prise du scanner et débranchez-la si la tête de numérisation heurte l'extrémité de la zone de balayage. Voir aussi la section BUGS.

Si vous possédez un scanner autre que ceux listés ci-dessus qui fonctionne avec ce backend, veuillez nous en informer en envoyant le nom exact du modèle du scanner et les identifiants vendeur et produit USB (par exemple, de /proc/bus/usb/devices, sane-find-scanner(1) ou syslog) . Même si le nom du scanner est légèrement différent des modèles mentionnés ci-dessus, veuillez nous en informer.

CONFIGURATION

Le contenu du fichier hp5400.conf est une liste de lignes usb contenant les identifiants de vendeur et de produit qui correspondent aux scanners USB. Le fichier peut également contenir les noms des fichiers de périphériques qui correspondent à un scanner HP 54XX. Les lignes vides et les lignes commençant par un signe dièse (#) sont ignorées. Les scanners sont autodétectés par les instructions usb vendor_id product_id qui sont déjà incluses dans hp5400.conf. "vendor_id" et "product_id" sont des nombres hexadécimaux qui identifient le scanner. Si l'autodétection ne fonctionne pas, ajoutez le nom du périphérique de votre scanner au fichier de configuration, par exemple /dev/usb/scanner0.

FICHIERS

/etc/sane.d/hp5400.conf
Le fichier de configuration du backend (voir aussi la description de SANE_CONFIG_DIR ci-dessous).
/usr/lib/sane/libsane-hp5400.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-hp5400.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_CONFIG_DIR
Cette variable d'environnement spécifie la liste des répertoires qui peuvent contenir le fichier de configuration. Sur les systèmes *NIX, les répertoires sont séparés par deux points (`:'), sous OS/2, ils sont séparés par un point-virgule (`;'). Si cette variable n'est pas définie, le fichier de configuration est recherché dans deux répertoires par défaut : d'abord, le répertoire de travail actuel (.) et ensuite dans /etc/sane.d. Si la valeur de la variable d'environnement se termine par le caractère séparateur de répertoire, alors les répertoires par défaut sont recherchés après les répertoires explicitement spécifiés. Par exemple, définir SANE_CONFIG_DIR à "/tmp/config:" aurait pour résultat la recherche dans les répertoires tmp/config, ., et /etc/sane.d (dans cet ordre).
SANE_DEBUG_HP5400
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Des niveaux de débogage plus élevés augmentent la verbosité de la sortie.

Exemple : export SANE_DEBUG_HP5400=4

BOGUES

La numérisation n'est testée qu'avec Linux/ix86/gcc. Soyez prudent lors de tests sur d'autres systèmes d'exploitation et en particulier sur les plateformes à architecture big-endian. Le scanner pourrait recevoir des données incorrectes.
