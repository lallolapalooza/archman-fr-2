sane-teco1(5) Accès Facile aux Scanners SANE sane-teco1(5)

NOM

sane-teco1 - backend SANE pour scanners TECO / RELISYS

DESCRIPTION

La bibliothèque sane-teco1 implémente un backend SANE (Scanner Access Now Easy) qui fournit l'accès à certains scanners à plat SCSI TECO. Ce backend doit être considéré comme un logiciel de qualité beta ! Les scanners TECO sont vendus sous diverses marques comme RELISYS, PIOTECH, TRUST. Ce backend peut ou peut ne pas supporter le vôtre.

Les scanners qui devraient fonctionner avec ce backend sont :

   Vendeur Modèle         Modèle TECO     statut
----------------------  --------------  -----------
  Relisys AVEC 2400        VM3520        testé
  Relisys AVEC 2412        VM3520+       testé
  Relisys AVEC 4800        VM4530        non testé
  Relisys AVEC 4816        VM4530+       non testé
  Relisys RELI 2400        VM3530        non testé
  Relisys RELI 2412        VM3530+       testé
  Relisys RELI 2412        VM3530+       non testé
  Relisys RELI 4816        VM4540        testé
  Relisys RELI 4830        VM4542        testé
  Relisys RELI 9600        VM6530        non testé
  Relisys RELI 9612        VM6530*       non testé
  Relisys RELI 9624        VM6530+       non testé
  Relisys RELI 9630        VM6540        non testé
  Relisys RELI DS15        VM3440        non testé
  Relisys RELI DS6         VM3420        non testé
  Dextra  DF-600P          VM3510        testé
  Dextra  DF-4830T         VM4542        non testé
  Dextra  DF-1200T+        VM3530+       non testé
  Dextra  DF-9624          VM6530+       non testé

Notez que les scanners non testés ne seront pas directement pris en charge. Vous devriez contacter l'auteur pour cela.

Le numéro VM de TECO se trouve généralement à l'arrière du scanner. Il fait également partie de l'identifiant FCC. sane-find-scanner -v affichera également l'interrogation SCSI, et s'il s'agit d'un scanner TECO, le nom sera également présent.

Les options que le backend prend en charge peuvent être sélectionnées soit via des options en ligne de commande pour des programmes comme scanimage(1), soit via des éléments d'interface graphique dans xscanimage(1) ou xsane(1).

Si vous avez un succès avec un scanner non répertorié ici, ou si vous remarquez un comportement étrange, veuillez le signaler au mainteneur du backend ou à la liste de diffusion SANE.

Les options valides en ligne de commande et leur syntaxe peuvent être listées en utilisant :

scanimage --help -d teco1
Mode de Scan
--mode Noir & Blanc|Niveaux de gris|Couleur
Sélectionne le mode de fonctionnement de base du scanner. Les choix valides sont Noir & Blanc, Niveaux de gris et Couleur.

Le mode Noir & Blanc est pour le noir et blanc uniquement (1 bit). Niveaux de gris produira 256 niveaux de gris (8 bits). Couleur produira une image couleur 24 bits.

--resolution 1..600
Sélectionne la résolution pour un scan. Le scanner peut gérer toutes les résolutions comprises entre 1 et 600, par incréments de 1.
Options de géométrie
-l -t -x -y
Contrôle la zone de scan : -l définit la coordonnée x du coin supérieur gauche, -t la coordonnée y du coin supérieur gauche, -x sélectionne la largeur et -y la hauteur de la zone de scan. Tous les paramètres sont spécifiés en millimètres par défaut.
Options d'amélioration
--custom-gamma
(mode couleur uniquement) permet à l'utilisateur de spécifier une table gamma (voir les 3 paramètres suivants).
--red-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal rouge. La table doit faire 256 octets de long. Mode couleur uniquement.
--green-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal vert. La table doit faire 256 octets de long. Mode couleur uniquement.
--blue-gamma-table
Peut être utilisé pour télécharger une table gamma définie par l'utilisateur pour le canal bleu. La table doit faire 256 octets de long. Mode couleur uniquement.
--dither Line art|2x2|3x3|4x4 bayer|4x4 smooth|8x8 bayer|8x8 smooth|8x8 horizontal|8x8 vertical
Sélectionne le masque de tramage à utiliser. Noir & Blanc uniquement.
--preview
Demande un scan de prévisualisation. La résolution utilisée est de 22 dpi et la zone de scan est le maximum autorisé. Le mode de scan est sélectionné par l'utilisateur. La valeur par défaut est « non ».

FICHIER DE CONFIGURATION

Le fichier de configuration /etc/sane.d/teco1.conf ne prend en charge qu'un seul élément : le nom du périphérique à utiliser (par ex. /dev/scanner).

FICHIERS

/usr/lib/sane/libsane-teco1.a
La bibliothèque statique implémentant ce backend.
/usr/lib/sane/libsane-teco1.so
La bibliothèque partagée implémentant ce backend (présente sur les systèmes qui prennent en charge le chargement dynamique).

ENVIRONNEMENT

SANE_DEBUG_TECO1
Si la bibliothèque a été compilée avec le support de débogage activé, cette variable d'environnement contrôle le niveau de débogage pour ce backend. Par exemple, une valeur de 128 demande que toutes les sorties de débogage soient imprimées. Des niveaux plus bas réduisent la verbosité.

LIMITATIONS

Le pilote TWAIN pour Windows a beaucoup plus d'options que ce backend SANE. Cependant, ce ne sont que des ajustements logiciels. Ce backend n'implémente que ce que le scanner peut supporter.

BOGUES

Aucun connu.
