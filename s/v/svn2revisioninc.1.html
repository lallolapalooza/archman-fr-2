svn2revisioninc(1) Utilité pour créer le fichier revision.inc à partir du dépôt SVN svn2revisioninc(1)

NOM

svn2revisioninc - L'utilitaire Lazarus pour créer le fichier revision.inc à partir du dépôt SVN.

SYNTAXE

svn2revisioninc
svn2revisioninc [Options] <chemin du dépôt> <fichier de sortie>
svn2revisioninc <chemin du dépôt> [Options] <fichier de sortie>

DESCRIPTION

svn2revisioninc est utilisé par le système de construction de Lazarus pour créer le fichier revision.inc à partir du dépôt SVN.

NOTES

1er paramètre sans commutateur = <chemin du dépôt> (par défaut, le répertoire courant)
2ème paramètre sans commutateur = <fichier de sortie> (par défaut, revision.inc par défaut)

OPTIONS

-h
Affiche un court message d'aide.
--o
Fichier de sortie. Ceci remplace <fichier de sortie>
--c=<nom>
Nom de la constante (par défaut RevisionStr).
--s
écrire la révision sur la sortie standard, ne pas créer de fichier inc
--v
Être verbeux
