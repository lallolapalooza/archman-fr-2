svipc(7) Manuel d'informations diverses svipc(7)

NOM

sysvipc - Mécanismes de communication interprocessus System V

DESCRIPTION

La communication interprocessus (IPC) System V est le nom donné à trois mécanismes de communication interprocessus largement disponibles sur les systèmes UNIX : les files de messages, les sémaphores et la mémoire partagée.

Files de messages

Les files de messages System V permettent l'échange de données sous forme d'unités appelées messages. Chaque message peut avoir une priorité associée. Les files de messages POSIX fournissent une API alternative pour obtenir le même résultat ; voir mq_overview(7).

L'API des files de messages System V se compose des appels système suivants :

msgget(2)
Crée une nouvelle file de messages ou obtient l'identifiant d'une file de messages existante. Cet appel renvoie un identifiant qui est utilisé dans les API restantes.
msgsnd(2)
Ajoute un message à une file.
msgrcv(2)
Retire un message d'une file.
msgctl(2)
Effectue diverses opérations de contrôle sur une file, y compris sa suppression.

Ensembles de sémaphores

Les sémaphores System V permettent aux processus de synchroniser leurs actions. Les sémaphores System V sont alloués par groupes appelés ensembles ; chaque sémaphore d'un ensemble est un sémaphore compteur. Les sémaphores POSIX fournissent une API alternative pour obtenir le même résultat ; voir sem_overview(7).

L'API des sémaphores System V se compose des appels système suivants :

semget(2)
Crée un nouvel ensemble ou obtient l'identifiant d'un ensemble existant. Cet appel renvoie un identifiant qui est utilisé dans les API restantes.
semop(2)
Effectue des opérations sur les sémaphores d'un ensemble.
semctl(2)
Effectue diverses opérations de contrôle sur un ensemble, y compris sa suppression.

Segments de mémoire partagée

La mémoire partagée System V permet aux processus de partager une région de mémoire (un « segment »). La mémoire partagée POSIX est une API alternative pour obtenir le même résultat ; voir shm_overview(7).

L'API de mémoire partagée System V se compose des appels système suivants :

shmget(2)
Crée un nouveau segment ou obtient l'identifiant d'un segment existant. Cet appel renvoie un identifiant qui est utilisé dans les API restantes.
shmat(2)
Attache un objet de mémoire partagée existant dans l'espace d'adressage du processus appelant.
shmdt(2)
Détache un segment de l'espace d'adressage du processus appelant.
shmctl(2)
Effectue diverses opérations de contrôle sur un segment, y compris sa suppression.

Espaces de noms IPC

Pour une discussion sur l'interaction des objets IPC System V et des espaces de noms IPC, voir ipc_namespaces(7).
