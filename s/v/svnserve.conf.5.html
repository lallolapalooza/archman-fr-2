svnserve.conf(5) Manuel des formats de fichiers svnserve.conf(5)

NOM

svnserve.conf - Fichier de configuration du dépôt pour svnserve

SYNTAXE

chemin_dépôt/conf/svnserve.conf

DESCRIPTION

svnserve.conf contrôle le comportement du démon svnserve sur une base par dépôt. Il est situé dans le sous-répertoire conf du dépôt.

La structure globale du fichier est identique à celle des fichiers de configuration utilisateur de Subversion. Au niveau supérieur se trouvent des sections, spécifiées par des mots entre crochets ; à l'intérieur de chaque section se trouvent des définitions de variables de la forme "variable = valeur". Les lignes commençant par '#' sont ignorées. svnserve.conf n'utilise actuellement qu'une seule section nommée "general" et prend en charge les variables suivantes :

anon-access = none|read|write
Détermine le niveau d'accès pour les utilisateurs non authentifiés. L'accès en write autorise toutes les opérations du dépôt. L'accès en read autorise toutes les opérations sauf l'engagement et la modification des propriétés de révision. L'accès none n'autorise aucun accès. Le niveau par défaut est read.
auth-access = none|read|write
Détermine le niveau d'accès pour les utilisateurs authentifiés, en utilisant les mêmes niveaux d'accès que ci-dessus. Le niveau par défaut est write.
password-db = nom_fichier
Définit l'emplacement de la base de données des mots de passe. nom_fichier peut être relatif au répertoire de configuration du dépôt. Il n'y a pas de valeur par défaut. La base de données des mots de passe a le même format général que ce fichier. Elle utilise une seule section "users" ; chaque variable dans la section est un nom d'utilisateur, et chaque valeur est un mot de passe.
authz-db = chemin
L'option authz-db contrôle l'emplacement des règles d'autorisation pour le contrôle d'accès basé sur les chemins. chemin peut être relatif au répertoire de configuration du dépôt. chemin peut être une URL relative au dépôt (^/) ou une URL absolue de type file:// vers un fichier texte dans un dépôt Subversion. Il n'y a pas de valeur par défaut. Si vous ne spécifiez pas d'authz-db, aucun contrôle d'accès basé sur les chemins n'est effectué.
realm = nom_domaine
Définit le domaine d'authentification du dépôt. Si deux dépôts ont la même base de données de mots de passe, ils devraient avoir le même domaine, et vice versa ; cette association permet aux clients d'utiliser un seul mot de passe mis en cache pour plusieurs dépôts. La valeur par défaut du domaine est l'uuid du dépôt.

EXEMPLE

L'exemple de svnserve.conf suivant autorise l'accès en lecture pour les utilisateurs authentifiés, aucun accès pour les utilisateurs anonymes, pointe vers une base de données de mots de passe dans le même répertoire et définit un nom de domaine.

 [general]
 anon-access = none
 auth-access = read
 password-db = passwd
 realm = Mon Premier Dépôt

Le fichier "passwd" ressemblerait à ceci :

 [users]
 joeuser = joepassword
 jayrandom = randomjay
