NOM

svnlook - Outil d'examen de dépôt Subversion

SYNTAXE

svnlook commande /chemin/vers/dépôt [options] [arguments]

APERÇU

Subversion est un système de contrôle de version, qui vous permet de conserver les anciennes versions de fichiers et répertoires (généralement le code source), de garder une trace de qui, quand et pourquoi les changements se sont produits, etc., comme CVS, RCS ou SCCS. Subversion conserve une copie maîtresse unique des sources. Cette copie s'appelle le « dépôt » source ; elle contient toutes les informations nécessaires pour extraire les versions précédentes de ces fichiers à tout moment.

Pour plus d'informations sur le projet Subversion, visitez http://subversion.apache.org.

La documentation pour Subversion et ses outils, y compris des explications détaillées sur l'utilisation des programmes svn, svnadmin, svnserve et svnlook, son historique, ses approches philosophiques et ses raisons, etc., peut être trouvée à l'adresse http://svnbook.red-bean.com/.

Exécutez `svnlook help' pour accéder à la documentation intégrée de l'outil.
