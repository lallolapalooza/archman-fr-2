NOM

svnsync - Outil de synchronisation de dépôts Subversion

SYNTAXE

svnsync commande url-destination [options] [arguments]

VUE D'ENSEMBLE

Subversion est un système de contrôle de version, qui vous permet de conserver les anciennes versions de fichiers et de répertoires (généralement du code source), de garder un journal de qui, quand et pourquoi les changements ont été effectués, etc., comme CVS, RCS ou SCCS. Subversion conserve une copie unique des sources maîtres. Cette copie s'appelle le « dépôt » source ; elle contient toutes les informations nécessaires pour extraire les versions précédentes de ces fichiers à tout moment.

Pour plus d'informations sur le projet Subversion, visitez http://subversion.apache.org.

La documentation pour Subversion et ses outils, y compris des explications détaillées sur l'utilisation des programmes svn, svnadmin, svnserve et svnlook, des informations historiques, des approches philosophiques et des justifications, etc., se trouve sur http://svnbook.red-bean.com/.

Exécutez `svnsync help` pour accéder à la documentation intégrée de l'outil.
