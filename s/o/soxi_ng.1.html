SoXI_ng(1) eXchange de Son_ng SoXI_ng(1)

NOM

SoXI_ng - Information eXchange de Son_ng, affiche les métadonnées du fichier audio

SYNTAXE

soxi_ng [-V[niveau]] [-T] [-t|-r|-c|-s|-d|-D|-b|-B|-p|-e|-a] fichier1 ...

DESCRIPTION

Affiche des informations de l'en-tête d'un ou plusieurs fichiers audio donnés. Les types de fichiers audio pris en charge sont répertoriés et décrits dans soxformat_ng(7). Notez cependant que soxi_ng est destiné à être utilisé uniquement avec des fichiers audio dotés d'un en-tête auto-descriptif.

Par défaut, autant d'informations que disponibles sont affichées. Une option peut être donnée pour sélectionner une seule information (peut-être pour utilisation dans un script ou un fichier batch).

OPTIONS

-V
Définit la verbosité. Voir sox_ng(1) pour les détails.
-T
Utilisé avec plusieurs fichiers ; change le comportement de -s, -d et -D pour afficher le total sur tous les fichiers donnés. Notez que lorsqu'il est utilisé avec -s avec des fichiers ayant des taux d'échantillonnage différents, sa valeur est discutable.
-t
Affiche le type de fichier détecté.
-r
Affiche le taux d'échantillonnage.
-c
Affiche le nombre de canaux.
-s
Affiche le nombre d'échantillons (0 si indisponible).
-d
Affiche la durée en heures, minutes et secondes (0 si indisponible). Équivalent au nombre d'échantillons divisé par le taux d'échantillonnage.
-D
Affiche la durée en secondes (0 si indisponible).
-b
Affiche le nombre de bits par échantillon (0 si non applicable).
-B
Affiche le débit binaire moyen sur l'ensemble du fichier (0 si indisponible).
-p
Affiche la précision estimée de l'échantillon en bits.
-e
Affiche le nom de l'encodage audio.
-a
Affiche les commentaires (annotations) du fichier si disponibles.
