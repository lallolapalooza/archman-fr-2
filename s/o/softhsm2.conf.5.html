softhsm2.conf(5) Manuel des formats de fichiers softhsm2.conf(5)

NOM

softhsm2.conf - Fichier de configuration de SoftHSM

SYNTAXE

softhsm2.conf

DESCRIPTION

Ceci est le fichier de configuration de SoftHSM. Il peut se trouver à un emplacement par défaut, mais peut également être déplacé en utilisant la variable d'environnement. Toute configuration doit être effectuée conformément au format de fichier décrit dans ce document.

FORMAT DE FICHIER

Chaque option de configuration est une paire nom et valeur séparée par un signe égal. L'option de configuration doit être située sur une seule ligne.

<nom> = <valeur>

Il est également possible d'ajouter des commentaires dans le fichier en utilisant le signe dièse. Tout ce qui suit le signe dièse sera ignoré.

# Un commentaire
Toutes les lignes vides ou les lignes qui n'ont pas le format correct seront ignorées.

DIRECTORIES.TOKENDIR

L'emplacement où SoftHSM peut stocker les tokens.

directories.tokendir = /var/lib/softhsm/tokens/

OBJECTSTORE.BACKEND

Le backend à utiliser par SoftHSM pour stocker les objets de token. "file" ou "db" est pris en charge. Pour utiliser le backend "db", la construction de SoftHSM doit être configurée avec "configure --with-objectstore-backend-db"

objectstore.backend = file

LOG.LEVEL

Le niveau de journalisation qui peut être défini sur ERROR, WARNING, INFO ou DEBUG.

log.level = INFO

SLOTS.REMOVABLE

S'il est défini sur true, CKF_REMOVABLE_DEVICE est défini dans les indicateurs renvoyés par C_GetSlotInfo. La valeur par défaut est false.

slots.removable = true

TOKEN.MECHANISMS

Permet d'activer et de désactiver tous les mécanismes PKCS#11 signalés dans C_GetMechanismList(). L'option accepte un argument de chaîne contenant la liste séparée par des virgules de tous les algorithmes qui doivent être activés (n'oubliez pas les mécanismes de génération de clés). La liste peut être précédée d'un signe moins "-" pour ne lister que les mécanismes désactivés. De plus, le mot-clé spécial ALL peut être utilisé pour activer tous les mécanismes connus (par défaut). Les mécanismes inconnus sont ignorés. Cette option a une priorité plus élevée que l'attribut CKA_ALLOWED_MECHANISMS sur les objets de clé.

slots.mechanisms = ALL

LIBRARY.RESET_ON_FORK

S'il est défini sur true, la bibliothèque réinitialisera l'état lors du fork. La valeur par défaut est false.

library.reset_on_fork = true

ENVIRONNEMENT

SOFTHSM2_CONF
Lorsqu'elle est définie, la valeur sera utilisée comme chemin vers le fichier de configuration.

FICHIERS

~/.config/softhsm2/softhsm2.conf
emplacement par défaut spécifique à l'utilisateur du fichier de configuration SoftHSM ; s'il existe, il remplacera la configuration système.
/etc/softhsm2.conf
emplacement système par défaut du fichier de configuration SoftHSM.
/etc/softhsm2.conf.sample
un exemple de fichier de configuration SoftHSM.
