SORD_VALIDATE(1) Manuel des commandes générales SORD_VALIDATE(1)

NOM

sord_validate — valide des données RDF

SYNTAXE

sord_validate [-hlv] entrée ...

DESCRIPTION

sord_validate est un validateur simple qui vérifie que toutes les propriétés utilisées sont effectivement définies, et que le domaine et la plage des propriétés sont explicitement corrects. Notez qu'une "erreur" de validation ici ne signifie pas nécessairement que les données sont invalides, car il n'est pas, par exemple, obligatoire de lister explicitement les types dans RDF. Ce validateur implémente un ensemble de règles plus strictes et explicites, basé sur les besoins réalistes des implémentations simples du monde réel. Par exemple, le manque d'informations de type explicites peut être signalé, même si même un simple moteur d'inférence serait capable de le déduire.

sord_validate ne récupère jamais de données sur le web ou dans des endroits spéciaux du système de fichiers, il ne traite que les fichiers passés directement sur la ligne de commande. Cela signifie que vous devez passer tous les vocabulaires utilisés pour obtenir un résultat utile.

Si un schéma approprié est disponible, les littéraux sont vérifiés par rapport aux définitions de types de données (à la fois le type de données explicite du littéral lui-même, ainsi que tout type implicite par la propriété correspondante). Trois contraintes de types de données XML Schema (XSD) sont actuellement prises en charge : les expressions régulières (xsd:pattern), et les intervalles inclusifs (xsd:minimumInclusive et xsd:maximumInclusive). Étant donné un schéma approprié, cela suffit pour valider la plupart des types de données XSD standard.

Les options sont les suivantes :

-h
Affiche les options de la ligne de commande.
-l
Affiche les erreurs sur une seule ligne.
-v
Affiche les informations de version et quitte.

STATUT DE SORTIE

sord_validate se termine avec un statut de 0 si les données d'entrée sont valides, ou non-zéro s'il y a des problèmes avec les données ou si une erreur s'est produite.
