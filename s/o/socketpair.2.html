socketpair(2) Manuel des appels système socketpair(2)

NOM

socketpair - crée une paire de sockets connectés

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/socket.h>
int socketpair(int domain, int type, int protocol, int sv[2]);

DESCRIPTION

L'appel socketpair() crée une paire sans nom de sockets connectés dans le domaine spécifié, du type spécifié et en utilisant le protocole optionnellement spécifié. Pour plus de détails sur ces arguments, voir socket(2).

Les descripteurs de fichiers utilisés pour référencer les nouveaux sockets sont retournés dans sv[0] et sv[1]. Les deux sockets sont indiscernables.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, errno est défini pour indiquer l'erreur, et sv reste inchangé.

Sur Linux (et d'autres systèmes), socketpair() ne modifie pas sv en cas d'échec. Une exigence standardisant ce comportement a été ajoutée dans POSIX.1-2008 TC2.

ERREURS

EAFNOSUPPORT
La famille d'adresses spécifiée n'est pas supportée sur cette machine.
EFAULT
L'adresse sv ne spécifie pas une partie valide de l'espace d'adressage du processus.
EMFILE
La limite par processus du nombre de descripteurs de fichiers ouverts a été atteinte.
ENFILE
La limite du système sur le nombre total de fichiers ouverts a été atteinte.
EOPNOTSUPP
Le protocole spécifié ne supporte pas la création de paires de sockets.
EPROTONOSUPPORT
Le protocole spécifié n'est pas supporté sur cette machine.

VERSIONS

Sous Linux, les seuls domaines supportés pour cet appel sont AF_UNIX (ou de manière synonyme, AF_LOCAL) et AF_TIPC (depuis Linux 4.12).

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, 4.2BSD.

Il est généralement portable vers/depuis les systèmes non-BSD supportant des clones de la couche de sockets BSD (y compris les variantes System V).

SOCK_CLOEXEC
SOCK_NONBLOCK
POSIX.1-2024 ; Linux 2.6.27. (Voir socket(2).)

VOIR AUSSI

pipe(2), read(2), socket(2), write(2), socket(7), unix(7)
