source::encoding(3perl) Guide de référence des programmeurs Perl source::encoding(3perl)

NOM

source::encoding -- Déclarer l'encodage du code source Perl

SYNOPSIS

use source::encoding 'ascii';
use source::encoding 'utf8';
no source::encoding;

DESCRIPTION

De nos jours, le code Perl contient généralement soit uniquement des caractères ASCII avec des échappements comme "\x{}" pour représenter des caractères non-ASCII, soit "use utf8" est utilisé pour indiquer que le code source lui-même contient des caractères encodés en UTF-8.

Cela signifie qu'un caractère dans le code source ne répondant pas à ces critères est souvent une erreur typographique. Ce pragma est utilisé pour dire à Perl de générer une erreur lorsque cela se produit.

"use source::encoding 'utf8'" est un synonyme de "use utf8". Ils peuvent être utilisés de manière interchangeable.

"use source::encoding 'ascii'" désactive toute attente concernant UTF-8 et génère une erreur fatale si un caractère dans sa portée du code source d'entrée n'est pas ASCII (ou équivalent ASCII sur les systèmes EBCDIC).

"no source::encoding" désactive toute attente concernant UTF-8/ASCII pour le reste de sa portée. La signification des caractères non-ASCII est alors indéfinie.

"use source::encoding 'ascii'" est automatiquement activé dans la portée lexicale d'un "use v5.41.0" ou supérieur.
