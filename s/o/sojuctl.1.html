NOM

sojuctl - Gérer une instance en cours d'exécution du bouncer IRC soju

SYNOPIS

sojuctl [options...] <commande...>

DESCRIPTION

sojuctl envoie une commande BouncerServ à une instance soju en cours d'exécution. Voir la section SERVICE IRC de soju(1) pour plus d'informations.

sojuctl nécessite une directive listen unix+admin:// dans le fichier de configuration de soju. sojuctl doit être exécuté avec des permissions d'écriture sur le socket d'administration de soju.

OPTIONS

-h, -help

Affiche le message d'aide et quitte.

-config <chemin>

Chemin vers le fichier de configuration. S'il n'est pas défini, le chemin par défaut du fichier de configuration est utilisé, le cas échéant.
