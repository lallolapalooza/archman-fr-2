Documentation de la fonction/sous-routine

sous-routine sorg2r (integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer info)

SORG2R génère tout ou partie de la matrice orthogonale Q à partir d'une factorisation QR déterminée par sgeqrf (algorithme non-bloqué).

Objectif :

!>
!> SORG2R génère une matrice réelle m par n avec des colonnes orthonormées,
!> qui est définie comme les n premières colonnes d'un produit de k
!> réflecteurs élémentaires d'ordre m
!>
!>       Q  =  H(1) H(2) . . . H(k)
!>
!> telle que retournée par SGEQRF.
!>

Paramètres

M 
!>          M est un entier
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un entier
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau de réels, dimension (LDA,N)
!>          À l'entrée, la i-ème colonne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel
!>          que retourné par SGEQRF dans les n premières colonnes de son
!>          tableau argument A.
!>          À la sortie, la matrice m par n Q.
!>

LDA

!>          LDA est un entier
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de réels, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par SGEQRF.
!>

WORK

!>          WORK est un tableau de réels, dimension (N)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
