sous-routine sorgql (m, n, k, a, lda, tau, work, lwork, info)

Documentation de la fonction/sous-routine

sous-routine sorgql (integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SORGQL

But :

!>
!> SORGQL génère une matrice réelle Q de dimensions M x N avec des colonnes
!> orthonormées, qui est définie comme les N dernières colonnes d'un produit de K
!> réflecteurs élémentaires d'ordre M
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tel que retourné par SGEQLF.
!>

Paramètres

M 
!>          M est un INTEGER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau REAL, de dimension (LDA,N)
!>          En entrée, la (n-k+i)-ème colonne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel
!>          que retourné par SGEQLF dans les k dernières colonnes de son
!>          argument de tableau A.
!>          En sortie, la matrice Q de dimensions M x N.
!>

LDA

!>          LDA est un INTEGER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau REAL, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par SGEQLF.
!>

WORK

!>          WORK est un tableau REAL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la dimension optimale de
!>          LWORK.
!>

LWORK

!>          LWORK est un INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Pour des performances optimales, LWORK >= N*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur dans la première entrée du tableau WORK, et aucun message
!>          d'erreur relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
