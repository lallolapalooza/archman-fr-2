Documentation de la fonction/sous-programme

sous-programme sort01 (caractère rowcol, entier m, entier n, réel, dimension( ldu, * ) u, entier ldu, réel, dimension( * ) work, entier lwork, réel resid)

SORT01

Objectif :

!>
!> SORT01 vérifie que la matrice U est orthogonale en calculant le ratio
!>
!>    RESID = norm( I - U*U' ) / ( n * EPS ), si ROWCOL = 'R',
!> ou
!>    RESID = norm( I - U'*U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
!> Alternativement, s'il n'y a pas suffisamment d'espace de travail pour former
!> I - U*U' ou I - U'*U, le ratio est calculé comme
!>
!>    RESID = abs( I - U*U' ) / ( n * EPS ), si ROWCOL = 'R',
!> ou
!>    RESID = abs( I - U'*U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
!> où EPS est la précision machine. ROWCOL n'est utilisé que si m = n ;
!> si m > n, ROWCOL est supposé être 'C', et si m < n, ROWCOL est
!> supposé être 'R'.
!>

Paramètres

ROWCOL 
!>          ROWCOL est CARACTERE
!>          Spécifie si les lignes ou les colonnes de U doivent être vérifiées
!>          pour l'orthogonalité. Utilisé uniquement si M = N.
!>          = 'R':  Vérifier l'orthogonalité des lignes de U
!>          = 'C':  Vérifier l'orthogonalité des colonnes de U
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice U.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice U.
!>

U

!>          U est un tableau REEL, dimension (LDU,N)
!>          La matrice orthogonale U. U est vérifiée pour l'orthogonalité des colonnes
!>          si m > n ou si m = n et ROWCOL = 'C'. U est vérifiée pour
!>          l'orthogonalité des lignes si m < n ou si m = n et ROWCOL = 'R'.
!>

LDU

!>          LDU est ENTIER
!>          La dimension principale du tableau U. LDU >= max(1,M).
!>

WORK

!>          WORK est un tableau REEL, dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur du tableau WORK. Pour une meilleure performance, LWORK
!>          devrait être au moins N*(N+1) si ROWCOL = 'C' ou M*(M+1) si
!>          ROWCOL = 'R', mais le test sera effectué même si LWORK est 0.
!>

RESID

!>          RESID est REEL
!>          RESID = norm( I - U * U' ) / ( n * EPS ), si ROWCOL = 'R', ou
!>          RESID = norm( I - U' * U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
