SORCSD2BY1

But:

!>
!> SORCSD2BY1 calcule la décomposition CS d'une matrice X de taille M par Q
!> avec des colonnes orthonormales qui a été partitionnée en une structure de
!> blocs 2x1 :
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 est de taille P par Q. Les matrices orthogonales U1, U2 et V1 sont
!> respectivement de taille P par P, (M-P) par (M-P), et Q par Q. C et S sont
!> des matrices diagonales non négatives de taille R par R satisfaisant
!> C^2 + S^2 = I, où R = MIN(P,M-P,Q,M-Q). I1 est une matrice identité de
!> taille K1 par K1 et I2 est une matrice identité de taille K2 par K2, où
!> K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>

Paramètres

JOBU1 
!>          JOBU1 est CARACTERE
!>          = 'Y':      U1 est calculée ;
!>          sinon:      U1 n'est pas calculée.
!>

JOBU2

!>          JOBU2 est CARACTERE
!>          = 'Y':      U2 est calculée ;
!>          sinon:      U2 n'est pas calculée.
!>

JOBV1T

!>          JOBV1T est CARACTERE
!>          = 'Y':      V1T est calculée ;
!>          sinon:      V1T n'est pas calculée.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de X.
!>

P

!>          P est ENTIER
!>          Le nombre de lignes de X11. 0 <= P <= M.
!>

Q

!>          Q est ENTIER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est tableau REEL, dimension (LDX11,Q)
!>          En entrée, partie de la matrice orthogonale dont la décomposition CS
!>          est désirée.
!>

LDX11

!>          LDX11 est ENTIER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 est tableau REEL, dimension (LDX21,Q)
!>          En entrée, partie de la matrice orthogonale dont la décomposition CS
!>          est désirée.
!>

LDX21

!>          LDX21 est ENTIER
!>           La dimension principale de X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA est tableau REEL, dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est tableau REEL, dimension (P)
!>          Si JOBU1 = 'Y', U1 contient la matrice orthogonale U1 de taille P par P.
!>

LDU1

!>          LDU1 est ENTIER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est tableau REEL, dimension (M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice orthogonale U2 de taille
!>          (M-P) par (M-P).
!>

LDU2

!>          LDU2 est ENTIER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est tableau REEL, dimension (Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice orthogonale V1**T de taille
!>          Q par Q.
!>

LDV1T

!>          LDV1T est ENTIER
!>          La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK est tableau REEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie la taille optimale LWORK.
!>          Si INFO > 0 en sortie, WORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, avec THETA(1), ..., THETA(R), définissent la
!>          matrice sous forme bidiagonale par blocs intermédiaire en cas de
!>          non-convergence. INFO spécifie le nombre de PHI non nuls.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>
!>          Si LWORK = -1, alors une requête de dimension de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau work, et aucun
!>          message d'erreur relatif à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est tableau ENTIER, dimension (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO est ENTIER
!>          = 0:  fin réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  SBBCSD n'a pas convergé. Voir la description de WORK
!>                ci-dessus pour les détails.
!>

sorcsd2by1(8)

SOCKS Daemon for v1.2.x and v1.3.x

sorcsd2by1 [-d] [-f config_file] [-i host] [-l log_file] [-p port] [-v] [-4 | -6]

DESCRIPTION

sorcsd2by1 is a SOCKS daemon that supports SOCKS v1.2.x and v1.3.x. It allows clients to make TCP connections through the server to any destination host and port.

OPTIONS

-d
Run in debug mode.
-f config_file
Specify a configuration file to use.
-i host
Bind to a specific IP address.
-l log_file
Log messages to the specified file.
-p port
Listen on the specified port.
-v
Verbose output.
-4
Use IPv4 only.
-6
Use IPv6 only.

CONFIGURATION FILE

The configuration file allows you to specify various options, such as allowed clients, destination hosts, and ports. The format of the configuration file is as follows: 

# This is a comment
allow client_ip from_host to_host to_port
deny client_ip from_host to_host to_port

Where:

  • client_ip: The IP address of the client. Can be a single IP, a network in CIDR notation, or '*' to match any IP.
  • from_host: The IP address or hostname of the source. Can be a single IP, a network in CIDR notation, or '*' to match any IP.
  • to_host: The IP address or hostname of the destination. Can be a single IP, a network in CIDR notation, or '*' to match any IP.
  • to_port: The destination port. Can be a single port, a range (e.g., 1-1024), or '*' to match any port.

The allow directive permits connections, while the deny directive forbids them. Rules are processed in order, and the first matching rule determines whether a connection is allowed or denied.

EXAMPLES

To start sorcsd2by1 with default settings (listening on port 1080, all interfaces): 

sorcsd2by1

To start sorcsd2by1 listening on port 1081 on interface 192.168.1.1: 

sorcsd2by1 -i 192.168.1.1 -p 1081

To start sorcsd2by1 with a custom configuration file and log file: 

sorcsd2by1 -f /etc/sorcsd2by1.conf -l /var/log/sorcsd2by1.log
