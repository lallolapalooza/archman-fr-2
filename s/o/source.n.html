source(n) Commandes intégrées Tcl source(n)

NOM

source - Évaluer un fichier ou une ressource comme un script Tcl

SYNOPIS

source nomFichier

source -encoding nomEncodage nomFichier

DESCRIPTION

Cette commande prend le contenu du fichier ou de la ressource spécifiée et le transmet à l'interpréteur Tcl sous forme de script texte. La valeur de retour de source est la valeur de retour de la dernière commande exécutée dans le script. Si une erreur survient lors de l'évaluation du contenu du script, la commande source retournera cette erreur. Si une commande return est invoquée depuis le script, le reste du fichier sera ignoré et la commande source retournera normalement avec le résultat de la commande return.

Le caractère de fin de fichier pour les fichiers est “\32” (^Z) pour toutes les plateformes. La commande source lira les fichiers jusqu'à ce caractère. Cette restriction n'existe pas pour les commandes read ou gets, permettant des fichiers contenant du code et des segments de données (documents scriptés). Si vous avez besoin d'un “^Z” dans le code pour une comparaison de chaînes, vous pouvez utiliser “\032” ou “\u001a”, qui seront sûrement substitués par l'interpréteur Tcl en “^Z”.

Un BOM (Byte order mark) initial contenu dans le fichier est ignoré pour les encodages unicode (utf-8, unicode).

L'option -encoding est utilisée pour spécifier l'encodage des données stockées dans nomFichier. Lorsque l'option -encoding est omise, l'encodage système est supposé.

EXEMPLE

Exécuter le script dans le fichier foo.tcl, puis le script dans le fichier bar.tcl :

source foo.tcl
source bar.tcl

Alternativement :

foreach scriptFile {foo.tcl bar.tcl} {
    source $scriptFile
}
