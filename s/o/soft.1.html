SOFT(1) Un serveur Git auto-hébergeable pour la ligne de commande SOFT(1)

NOM

soft - Un serveur Git auto-hébergeable pour la ligne de commande

SYNTAXE

soft [options...] [argument...]

DESCRIPTION

Soft Serve est un serveur Git auto-hébergeable pour la ligne de commande.

COMMANDES

admin
Administrer le serveur
COMMANDES
migrate
Migrer la base de données vers la dernière version
rollback
Annuler la migration de la base de données vers la version précédente
sync-hooks
Mettre à jour les hooks des dépôts
browse CHEMIN
Parcourir un dépôt
help [commande]
Aide sur une commande quelconque
serve
Démarrer le serveur
OPTIONS
--sync-hooks synchroniser les hooks pour tous les dépôts avant de lancer le serveur
