Documentation de la fonction/sous-routine

sous-routine sopgtr (caractère uplo, entier n, réel, dimension( * ) ap, réel, dimension( * ) tau, réel, dimension( ldq, * ) q, entier ldq, réel, dimension( * ) work, entier info)

SOPGTR

Objectif :

!>
!> SOPGTR génère une matrice orthogonale réelle Q qui est définie comme le
!> produit de n-1 réflecteurs élémentaires H(i) d'ordre n, tels que retournés par
!> SSPTRD en utilisant un stockage compacté :
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': Stockage compacté de la partie triangulaire supérieure utilisé dans l'appel précédent
!>                 à SSPTRD ;
!>          = 'L': Stockage compacté de la partie triangulaire inférieure utilisé dans l'appel précédent
!>                 à SSPTRD.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice Q. N >= 0.
!>

AP

!>          AP est un tableau REAL, dimension (N*(N+1)/2)
!>          Les vecteurs qui définissent les réflecteurs élémentaires, tels que retournés par SSPTRD.
!>

TAU

!>          TAU est un tableau REAL, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par SSPTRD.
!>

Q

!>          Q est un tableau REAL, dimension (LDQ,N)
!>          La matrice orthogonale de taille N x N, Q.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (N-1)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie
!>          < 0:  Si INFO = -i, alors le i-ème argument était invalide
!>
