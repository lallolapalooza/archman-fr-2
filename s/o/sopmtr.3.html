Documentation de la fonction/sous-programme

sous-programme sopmtr (caractere side, caractere uplo, caractere trans, entier m, entier n, reel, dimension( * ) ap, reel, dimension( * ) tau, reel, dimension( ldc, * ) c, entier ldc, reel, dimension( * ) work, entier info)

SOPMTR

Objectif :

!>
!> SOPMTR remplace la matrice generale réelle M-par-N C par
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> où Q est une matrice orthogonale réelle d'ordre nq, avec nq = m si
!> SIDE = 'L' et nq = n si SIDE = 'R'. Q est définie comme le produit de
!> nq-1 réflexions élémentaires, tel que retourné par SSPTRD en utilisant le stockage compacté :
!>
!> si UPLO = 'U', Q = H(nq-1) . . . H(2) H(1);
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(nq-1).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T depuis la gauche ;
!>          = 'R': appliquer Q ou Q**T depuis la droite.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U': stockage compacté triangulaire supérieur utilisé dans l'appel précédent
!>                 à SSPTRD ;
!>          = 'L': stockage compacté triangulaire inférieur utilisé dans l'appel précédent
!>                 à SSPTRD.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'T':  Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

AP

!>          AP est un tableau REAL, de dimension
!>                               (M*(M+1)/2) si SIDE = 'L'
!>                               (N*(N+1)/2) si SIDE = 'R'
!>          Les vecteurs qui définissent les réflexions élémentaires, tels que
!>          retournés par SSPTRD. AP est modifié par la routine mais
!>          restauré à la sortie.
!>

TAU

!>          TAU est un tableau REAL, de dimension (M-1) si SIDE = 'L'
!>                                     ou (N-1) si SIDE = 'R'
!>          TAU(i) doit contenir le facteur scalaire de la réflexion
!>          élémentaire H(i), tel que retourné par SSPTRD.
!>

C

!>          C est un tableau REAL, de dimension (LDC,N)
!>          À l'entrée, la matrice M-par-N C.
!>          À la sortie, C est remplacé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau REAL, de dimension
!>                                   (N) si SIDE = 'L'
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
