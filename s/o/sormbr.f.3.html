Documentation de la fonction/sous-routine

subroutine sormbr (character vect, character side, character trans, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

SORMBR

Purpose:

!>
!> Si VECT = 'Q', SORMBR écrase la matrice réelle générale M-par-N C avec
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> Si VECT = 'P', SORMBR écrase la matrice réelle générale M-par-N C avec
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      P * C          C * P
!> TRANS = 'T':      P**T * C       C * P**T
!>
!> Ici Q et P**T sont les matrices orthogonales déterminées par SGEBRD lors de
!> la réduction d'une matrice réelle A en forme bidiagonale : A = Q * B * P**T. Q et
!> P**T sont définis comme des produits de réflecteurs élémentaires H(i) et G(i)
!> respectivement.
!>
!> Soit nq = m si SIDE = 'L' et nq = n si SIDE = 'R'. Ainsi nq est l'ordre
!> de la matrice orthogonale Q ou P**T qui est appliquée.
!>
!> Si VECT = 'Q', A est supposée avoir été une matrice NQ-par-K :
!> si nq >= k, Q = H(1) H(2) . . . H(k);
!> si nq < k, Q = H(1) H(2) . . . H(nq-1).
!>
!> Si VECT = 'P', A est supposée avoir été une matrice K-par-NQ :
!> si k < nq, P = G(1) G(2) . . . G(k);
!> si k >= nq, P = G(1) G(2) . . . G(nq-1).
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'Q': appliquer Q ou Q**T;
!>          = 'P': appliquer P ou P**T.
!>

SIDE

!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q, Q**T, P ou P**T par la Gauche ;
!>          = 'R': appliquer Q, Q**T, P ou P**T par la Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q  ou P ;
!>          = 'T':  Transposée, appliquer Q**T ou P**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Si VECT = 'Q', le nombre de colonnes de la matrice originale
!>          réduite par SGEBRD.
!>          Si VECT = 'P', le nombre de lignes de la matrice originale
!>          réduite par SGEBRD.
!>          K >= 0.
!>

A

!>          A est tableau de REAL, dimension
!>                                (LDA,min(nq,K)) si VECT = 'Q'
!>                                (LDA,nq)        si VECT = 'P'
!>          Les vecteurs qui définissent les réflecteurs élémentaires H(i) et
!>          G(i), dont les produits déterminent les matrices Q et P, tels que
!>          retournés par SGEBRD.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si VECT = 'Q', LDA >= max(1,nq);
!>          si VECT = 'P', LDA >= max(1,min(nq,K)).
!>

TAU

!>          TAU est tableau de REAL, dimension (min(nq,K))
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i) ou G(i) qui détermine Q ou P, tel que retourné
!>          par SGEBRD dans le paramètre de tableau TAUQ ou TAUP.
!>

C

!>          C est tableau de REAL, dimension (LDC,N)
!>          En entrée, la matrice C de taille M-par-N.
!>          En sortie, C est écrasée par Q*C ou Q**T*C ou C*Q**T ou C*Q
!>          ou P*C ou P**T*C ou C*P ou C*P**T.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau de REAL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour une performance optimale LWORK >= N*NB si SIDE = 'L', et
!>          LWORK >= M*NB si SIDE = 'R', où NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
