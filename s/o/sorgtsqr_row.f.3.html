Documentation de la fonction/sous-routine

sous-routine sorgtsqr_row (integer m, integer n, integer mb, integer nb, real, dimension( lda, * ) a, integer lda, real, dimension( ldt, * ) t, integer ldt, real, dimension( * ) work, integer lwork, integer info)

SORGTSQR_ROW

Objectif:

!>
!> SORGTSQR_ROW génère une matrice réelle M par N, Q_out, avec des colonnes
!> orthonormales à partir de la sortie de SLATSQR. Ces N colonnes orthonormales
!> sont les N premières colonnes d'un produit de matrices unitaires complexes
!> Q(k)_in d'ordre M, qui sont retournées par SLATSQR dans un format spécial.
!>
!>      Q_out = premières_N_colonnes_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Les matrices d'entrée Q(k)_in sont stockées en blocs de lignes et de colonnes dans A.
!> Voir la documentation de SLATSQR pour plus de détails sur le format de
!> Q(k)_in, où chaque Q(k)_in est représenté par des transformations de Householder
!> par blocs. Cette routine appelle une routine auxiliaire SLARFB_GETT, où le calcul
!> est effectué sur chaque bloc individuel. L'algorithme balaie d'abord des blocs
!> de colonnes de taille NB de droite à gauche en commençant dans le bloc de ligne
!> inférieur et continue jusqu'au bloc de ligne supérieur (d'où _ROW dans le nom
!> de la routine). Ce balayage est dans l'ordre inverse de l'ordre dans lequel
!> SLATSQR génère les blocs de sortie.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un ENTIER
!>          La taille du bloc de lignes utilisé par SLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
!>

NB

!>          NB est un ENTIER
!>          La taille du bloc de colonnes utilisé par SLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes).
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>
!>          En entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas utilisés
!>             comme entrée. Les éléments sous la diagonale représentent la matrice
!>             trapézoïdale inférieure unitaire par blocs V calculée par SLATSQR
!>             qui définit les matrices d'entrée Q_in(k) (les uns sur la diagonale
!>             ne sont pas stockés). Voir SLATSQR pour plus de détails.
!>
!>          En sortie :
!>
!>             Le tableau A contient une matrice orthonormée Q_out de taille M par N,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau REEL,
!>          de dimension (LDT, N * NIRB)
!>          où NIRB = Nombre_de_blocs_de_lignes_d'entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre_de_blocs_de_colonnes_d'entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les réflecteurs de blocs
!>          sont stockés sous forme compacte dans NIRB séquences de réflecteurs de blocs.
!>          Chacune des NIRB séquences de réflecteurs de blocs est stockée dans un
!>          bloc de colonnes de T de taille NB par N et consiste en NICB blocs
!>          colonnaires plus petits de taille NB par NB, triangulaires supérieurs.
!>          Voir SLATSQR pour plus de détails sur le format de T.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB,N)).
!>

WORK

!>          (espace de travail) Tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          LWORK >= NBLOCAL * MAX(NBLOCAL,(N-NBLOCAL)),
!>          où NBLOCAL=MIN(NB,N).
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur dans la première entrée du tableau WORK, et
!>          aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
