NOM

sound-juicer - Graveur et lecteur de CD pour l'environnement GNOME utilisant GStreamer

SYNTAXE

sound-juicer [option...]

DESCRIPTION

sound-juicer est un graveur et lecteur de CD pour GNOME qui vise une interface simple, claire et facile à utiliser. sound-juicer prend en charge l'encodage dans plusieurs formats audio populaires tels que Ogg Vorbis et FLAC ; des formats supplémentaires peuvent être ajoutés via des plugins GStreamer.

Pour une documentation supplémentaire sur l'utilisation interactive de sound-juicer, sélectionnez l'option de menu Aide. Les menus donnent accès à des fonctionnalités non disponibles via les options de ligne de commande.

OPTIONS

-a, --auto-start
Commencer l'extraction immédiatement
-p, --play
Commencer la lecture immédiatement
-d, --device=APPAREIL
Quel appareil CD lire
--display=DISPLAY
Affichage X à utiliser
-?, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gst
Afficher les options GStreamer
--help-gtk
Afficher les options GTK+
--help-bonobo-activation
Afficher les options d'activation Bonobo
--help-gnome
Afficher les options GNOME
--help-gnome-session
Afficher les options de gestion de session GNOME
--help-gnome-ui
Afficher les options de l'interface graphique GNOME
