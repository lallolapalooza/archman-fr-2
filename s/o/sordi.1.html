SORDI(1) Manuel des commandes générales SORDI(1)

NOM

sordi — charger et réécrire des données RDF

SYNTAXE

sordi [-hv] [-i syntaxe] [-o syntaxe] [-s chaîne] entrée [uri_base]

DESCRIPTION

sordi est un utilitaire en ligne de commande pour charger des données RDF dans un modèle, et les réécrire ensuite.

sordi est principalement utile pour des choses comme supprimer les déclarations dupliquées, fusionner des fichiers de données, ou un formatage agressif avec réorganisation des déclarations.

Les options sont les suivantes :

-h, --help
Afficher les options de la ligne de commande.
-i syntaxe
Lire l'entrée comme syntaxe. La casse est ignorée, les valeurs valides sont : « NQuads », « NTriples », « TriG », « Turtle ».
-o syntaxe
Écrire la sortie comme syntaxe. La casse est ignorée, les valeurs valides sont : « NQuads », « NTriples », « TriG », « Turtle ».
-s chaîne
Analyser l'entrée chaîne au lieu d'un fichier (termine les options).
-v
Afficher les informations de version et quitter.

CODE DE SORTIE

sordi quitte avec un statut de 0, ou non-zéro si une erreur s'est produite.
