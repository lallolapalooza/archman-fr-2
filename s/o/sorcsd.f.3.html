Documentation de la fonction/sous-programme

sous-programme récursif sorcsd (caractère jobu1, caractère jobu2, caractère jobv1t, caractère jobv2t, caractère trans, caractère signs, entier m, entier p, entier q, réel, dimension( ldx11, * ) x11, entier ldx11, réel, dimension( ldx12, * ) x12, entier ldx12, réel, dimension( ldx21, * ) x21, entier ldx21, réel, dimension( ldx22, * ) x22, entier ldx22, réel, dimension( * ) theta, réel, dimension( ldu1, * ) u1, entier ldu1, réel, dimension( ldu2, * ) u2, entier ldu2, réel, dimension( ldv1t, * ) v1t, entier ldv1t, réel, dimension( ldv2t, * ) v2t, entier ldv2t, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier info)

Objectif:

!>
!> SORCSD calcule la décomposition CS d'une matrice orthogonale M-par-M partitionnée
!> X:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**T
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 est P-par-Q. Les matrices orthogonales U1, U2, V1 et V2 sont P-par-P,
!> (M-P)-par-(M-P), Q-par-Q et (M-Q)-par-(M-Q), respectivement. C et S sont
!> des matrices diagonales non négatives R-par-R satisfaisant C^2 + S^2 = I,
!> où R = MIN(P,M-P,Q,M-Q).
!>

Paramètres

JOBU1 
!>          JOBU1 est CARACTÈRE
!>          = 'Y':      U1 est calculé;
!>          sinon:  U1 n'est pas calculé.
!>

JOBU2

!>          JOBU2 est CARACTÈRE
!>          = 'Y':      U2 est calculé;
!>          sinon:  U2 n'est pas calculé.
!>

JOBV1T

!>          JOBV1T est CARACTÈRE
!>          = 'Y':      V1T est calculé;
!>          sinon:  V1T n'est pas calculé.
!>

JOBV2T

!>          JOBV2T est CARACTÈRE
!>          = 'Y':      V2T est calculé;
!>          sinon:  V2T n'est pas calculé.
!>

TRANS

!>          TRANS est CARACTÈRE
!>          = 'T':      X, U1, U2, V1T et V2T sont stockés en ordre row-major;
!>          sinon:  X, U1, U2, V1T et V2T sont stockés en ordre column-
!>                  major.
!>

SIGNS

!>          SIGNS est CARACTÈRE
!>          = 'O':      Le bloc inférieur gauche est rendu non positif (la
!>                       convention);
!>          sinon:  Le bloc supérieur droit est rendu non positif (la
!>                       convention).
!>

M

!>          M est ENTIER
!>          Le nombre de lignes et de colonnes de X.
!>

P

!>          P est ENTIER
!>          Le nombre de lignes de X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est ENTIER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau RÉEL, de dimension (LDX11,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est souhaitée.
!>

LDX11

!>          LDX11 est ENTIER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X12

!>          X12 est un tableau RÉEL, de dimension (LDX12,M-Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est souhaitée.
!>

LDX12

!>          LDX12 est ENTIER
!>          La dimension principale de X12. LDX12 >= MAX(1,P).
!>

X21

!>          X21 est un tableau RÉEL, de dimension (LDX21,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est souhaitée.
!>

LDX21

!>          LDX21 est ENTIER
!>          La dimension principale de X11. LDX21 >= MAX(1,M-P).
!>

X22

!>          X22 est un tableau RÉEL, de dimension (LDX22,M-Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est souhaitée.
!>

LDX22

!>          LDX22 est ENTIER
!>          La dimension principale de X11. LDX22 >= MAX(1,M-P).
!>

THETA

!>          THETA est un tableau RÉEL, de dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est un tableau RÉEL, de dimension (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contient la matrice orthogonale P-par-P U1.
!>

LDU1

!>          LDU1 est ENTIER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est un tableau RÉEL, de dimension (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice orthogonale (M-P)-par-(M-P)
!>          U2.
!>

LDU2

!>          LDU2 est ENTIER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est un tableau RÉEL, de dimension (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice orthogonale Q-par-Q
!>          V1**T.
!>

LDV1T

!> LDV1T est ENTIER !> La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >= !> MAX(1,Q). !>

V2T

!>          V2T est un tableau RÉEL, de dimension (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contient la matrice orthogonale (M-Q)-par-(M-Q)
!>          V2**T.
!>

LDV2T

!>          LDV2T est ENTIER
!>          La dimension principale de V2T. Si JOBV2T = 'Y', LDV2T >=
!>          MAX(1,M-Q).
!>

WORK

!>          WORK est un tableau RÉEL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>          Si INFO > 0 à la sortie, WORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, avec THETA(1), ..., THETA(R),
!>          définissent la matrice restante sous forme de bloc bidiagonal
!>          en cas de non-convergence. INFO spécifie le nombre
!>          de PHI non nuls.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau work, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (M-MIN(P, M-P, Q, M-Q))
!>

INFO

!>

NAME

sorcsd - routines to compute the CS decomposition of an N-by-N upper triangular matrix.

SYNOPSIS

Subroutine sorcsd( JOBU, JOBV, M, P, N, X, LDX, Q, LDQ, Y, LDY, R, LDR,
                        TAUQ, TAUP, WORK, LWORK, INFO )

  REAL (Kind=8)             :: X( LDX, * )
  REAL (Kind=8)             :: Q( LDQ, * )
  REAL (Kind=8)             :: Y( LDY, * )
  REAL (Kind=8)             :: R( LDR, * )
  REAL (Kind=8)             :: TAUQ( * )
  REAL (Kind=8)             :: TAUP( * )
  REAL (Kind=8)             :: WORK( * )
  INTEGER                   :: M, P, N, LDX, LDQ, LDY, LDR, LWORK, INFO
  CHARACTER (LEN=1)         :: JOBU, JOBV

Function/Subroutine Documentation

This routine computes the CS decomposition of an N-by-N upper triangular matrix X.

The CS decomposition is defined as X = Q * R * Y', where Q and Y are orthogonal matrices and R is an upper triangular matrix.

JOBU
CHARACTER*1.

Specifies whether to compute the orthogonal matrix U. Possible values for JOBU are:

  • ‘V’: U is computed and returned.
  • ‘N’: U is not computed.
JOBV
CHARACTER*1.

Specifies whether to compute the orthogonal matrix V. Possible values for JOBV are:

  • ‘V’: V is computed and returned.
  • ‘N’: V is not computed.
M
INTEGER.

The number of rows of the matrix X.

P
INTEGER.

The number of columns of the matrix X.

N
INTEGER.

The number of columns of the matrix X.

X
REAL (Kind=8) array, dimension (LDX,P).

On entry, the N-by-P upper triangular matrix X.

On exit, the elements of X contain information about the CS decomposition. The exact details depend on the values of JOBU and JOBV.

LDX
INTEGER.

Leading dimension of the array X. LDX must be at least max(1,M).

Q
REAL (Kind=8) array, dimension (LDQ,M).

On exit, if JOBU = ‘V’, Q contains the orthogonal matrix U. If JOBU = ‘N’, the array Q is not used.

LDQ
INTEGER.

Leading dimension of the array Q. LDQ must be at least max(1,M).

Y
REAL (Kind=8) array, dimension (LDY,P).

On exit, if JOBV = ‘V’, Y contains the orthogonal matrix V. If JOBV = ‘N’, the array Y is not used.

LDY
INTEGER.

Leading dimension of the array Y. LDY must be at least max(1,P).

R
REAL (Kind=8) array, dimension (LDR,P).

On exit, R contains the upper triangular matrix R.

LDR
INTEGER.

Leading dimension of the array R. LDR must be at least max(1,M).

TAUQ
REAL (Kind=8) array, dimension (min(M,N)).

On exit, the scalar factors of the elementary transformations which form the matrix U.

TAUP
REAL (Kind=8) array, dimension (min(N,P)).

On exit, the scalar factors of the elementary transformations which form the matrix V.

WORK
REAL (Kind=8) array, dimension (LWORK).

Workspace array.

On exit, WORK(1) contains the optimal value of LWORK.

LWORK
INTEGER.

The dimension of the array WORK. LWORK must be at least max(1, 2*min(M,P) + max(M,P)).

For optimal performance, LWORK must be at least max(1, 2*min(M,P) + max(M,P))

If LWORK = -1, then LWORK is set to the optimal value and no computation is performed.

INFO
INTEGER.

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: SBBCSD did not converge. See the description of WORK above for details.

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
