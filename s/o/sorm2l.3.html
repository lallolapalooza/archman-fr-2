SORM2L multiplie une matrice générale par la matrice orthogonale d'une factorisation QL déterminée par sgeqlf (algorithme non bloqué).

Documentation de la fonction/sous-programme

sous-programme sorm2l (caractère side, caractère trans, entier m, entier n, entier k, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) tau, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) work, entier info)

SORM2L multiplie une matrice générale par la matrice orthogonale provenant d'une factorisation QL déterminée par sgeqlf (algorithme non bloqué).

Objectif :

!>
!> SORM2L remplace la matrice réelle m par n de C par
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**T * C  si SIDE = 'L' et TRANS = 'T', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**T si SIDE = 'R' et TRANS = 'T',
!>
!> où Q est une matrice orthogonale réelle définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> telle que retournée par SGEQLF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T à Gauche
!>          = 'R': appliquer Q ou Q**T à Droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer Q  (Pas de transposée)
!>          = 'T': appliquer Q**T (Transposée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau REAL de dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          SGEQLF dans les k dernières colonnes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau REAL de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par SGEQLF.
!>

C

!>          C est un tableau REAL de dimension (LDC,N)
!>          À l'entrée, la matrice C de taille m par n.
!>          À la sortie, C est remplacé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau REAL de dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
