NOM

softhsm2-migrate - Outil de migration des bases de données SoftHSM v1

SYNTAXE

softhsm2-migrate --db chemin --token étiquette [--pin PIN --no-public-key]

DESCRIPTION

softhsm2-migrate est un outil qui peut migrer les bases de données SoftHSM v1 vers PKCS#11. Le HSM par défaut est SoftHSM v2, mais il peut être utilisé avec d'autres bibliothèques PKCS#11 en utilisant l'option --module

OPTIONS

--db chemin
La base de données SoftHSM v1 qui va être migrée. L'emplacement de la base de données du token se trouve dans le fichier de configuration de SoftHSM v1.
--help, -h
Afficher les informations d'aide.
--module chemin
Utiliser une autre bibliothèque PKCS#11 que SoftHSM.
--no-public-key
Ne pas migrer la clé publique.
--pin PIN
Le PIN pour l'utilisateur normal.
--serial numéro
Utilisera le token avec un numéro de série correspondant.
--slot numéro
La base de données sera migrée vers ce slot.
--token étiquette
Utilisera le token avec une étiquette de token correspondante.
--version, -v
Afficher les informations de version.

EXEMPLE

Une base de données de token peut être migrée avec la commande suivante:

softhsm2-migrate --db /home/user/token.db --token mytoken
