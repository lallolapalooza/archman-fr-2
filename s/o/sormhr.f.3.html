Documentation de la fonction/sous-routine

sous-routine sormhr (character side, character trans, integer m, integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

SORMHR

Objectif :

!>
!> SORMHR écrase la matrice réelle M par N, C, avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> où Q est une matrice orthogonale réelle d'ordre nq, avec nq = m si
!> SIDE = 'L' et nq = n si SIDE = 'R'. Q est définie comme le produit de
!> IHI-ILO réflecteurs élémentaires, comme renvoyé par SGEHRD :
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T depuis la gauche ;
!>          = 'R': appliquer Q ou Q**T depuis la droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposée, appliquer Q ;
!>          = 'T': Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>
!>          ILO et IHI doivent avoir les mêmes valeurs que dans l'appel
!>          précédent de SGEHRD. Q est égale à la matrice unité sauf dans la
!>          sous-matrice Q(ilo+1:ihi,ilo+1:ihi).
!>          Si SIDE = 'L', alors 1 <= ILO <= IHI <= M, si M > 0, et
!>          ILO = 1 et IHI = 0, si M = 0 ;
!>          si SIDE = 'R', alors 1 <= ILO <= IHI <= N, si N > 0, et
!>          ILO = 1 et IHI = 0, si N = 0.
!>

A

!>          A est un tableau REAL, dimension
!>                               (LDA,M) si SIDE = 'L'
!>                               (LDA,N) si SIDE = 'R'
!>          Les vecteurs qui définissent les réflecteurs élémentaires, comme
!>          renvoyé par SGEHRD.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          LDA >= max(1,M) si SIDE = 'L' ; LDA >= max(1,N) si SIDE = 'R'.
!>

TAU

!>          TAU est un tableau REAL, dimension
!>                               (M-1) si SIDE = 'L'
!>                               (N-1) si SIDE = 'R'
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), comme renvoyé par SGEHRD.
!>

C

!>          C est un tableau REAL, dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour des performances optimales, LWORK >= N*NB si SIDE = 'L', et
!>          LWORK >= M*NB si SIDE = 'R', où NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Succès de l'exécution
!>          < 0:  Si INFO = -i, le i-ème argument avait une valeur illégale
!>
