soelim(1) Manuel des commandes générales soelim(1)

Nom

soelim - interpole récursivement les requêtes source dans les fichiers roff ou autres fichiers texte

Synopsis

soelim [-Crt] [-I dir] [fichier-entrée ...]
soelim --help
soelim -v
soelim --version

Description

soelim de GNU est un préprocesseur pour le système de mise en page de documents groff(7). soelim agit comme un filtre pour éliminer les requêtes source dans les fichiers d'entrée roff(7) ; il remplace les lignes de la forme “.so fichier-inclus” dans chaque fichier texte fichier-entrée par le contenu de fichier-inclus, récursivement. Par défaut, il écrit également des requêtes lf pour enregistrer le nom et le numéro de ligne de chaque fichier-entrée et fichier-inclus, afin que les diagnostics produits par le traitement ultérieur puissent être tracés avec précision vers l'entrée d'origine. Les options permettent de supprimer ces informations (-r) ou de les fournir sous forme de commentaires TeX (-t). En l'absence d'arguments fichier-entrée, soelim lit le flux d'entrée standard. La sortie est écrite dans le flux de sortie standard.

Si le nom d'un fichier-macro contient une barre oblique inverse, utilisez \\ ou \e pour l'intégrer. Pour intégrer un espace, écrivez “\ ” (barre oblique inverse suivie d'un espace). Toute autre séquence d'échappement dans fichier-macro, y compris “\[rs]”, empêche soelim de remplacer la requête source.

Le point doit être au début d'une ligne et doit être suivi de “so” sans espaces ou tabulations intermédiaires pour que soelim le traite. Cette convention permet de “protéger” les requêtes source du traitement par soelim, par exemple dans le cadre de définitions de macros ou de requêtes “if”.

Il doit également y avoir au moins un espace entre “so” et son argument fichier-macro. L'option -C annule cette exigence.

Ce qui précède est la limite de la compréhension du langage roff par soelim ; il ne remplace pas, par exemple, la ligne d'entrée

.if 1 .so otherfile
par le contenu de otherfile. Avec son option -r, par conséquent, soelim peut être utilisé pour traiter des fichiers texte en général, pour aplatir un arbre de documents d'entrée.

soelim a été conçu pour gérer les situations où la cible d'une requête source roff nécessite un préprocesseur tel que eqn(1), pic(1), refer(1), ou tbl(1). La séquence de traitement habituelle de groff(1) est la suivante.

          entrée        source
          fichier       fichier
            ⎪             ⎪
            ↓             ↓
        préprocesseur ⎯→ troff ⎯→ postprocesseur
                                      ⎪
                                      ↓
                                   sortie
                                    fichier

C'est-à-dire que les fichiers sourcés avec “so” sont normalement lus *uniquement* par le formateur, troff. soelim n'est *pas* nécessaire pour que troff source des fichiers.

Si un fichier à sourcer doit également être prétraité, il doit déjà être lu *avant* que le fichier d'entrée ne passe par le préprocesseur. soelim, normalement appelé via l'option -s de groff, gère cela.

          entrée
          fichier
            ⎪
            ↓
          soelim ⎯→ préprocesseur ⎯→ troff ⎯→ postprocesseur
            ↑                                     ⎪
            ⎪                                     ↓
         sourcé                                sortie
          fichier                                fichier

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent les informations de version ; tous se terminent ensuite.

-C
Reconnaît une ligne d'entrée commençant par .so même si un caractère autre qu'un espace ou un saut de ligne suit.
-I dir
Recherche dans le répertoire dir les fichiers-entrée et fichiers-inclus. -I peut être spécifié plus d'une fois ; chaque dir est recherché dans l'ordre donné. Pour rechercher le répertoire de travail actuel avant les autres, ajoutez “-I .” à l'endroit souhaité ; il est sinon recherché en dernier.
-r
Écrit les fichiers “bruts” ; n'ajoute pas de requêtes lf.
-t
Émet des lignes de commentaires TeX commençant par “%” indiquant le fichier actuel et le numéro de ligne, plutôt que des requêtes lf dans le même but.

Si -r et -t sont tous deux donnés, le dernier spécifié contrôle.
