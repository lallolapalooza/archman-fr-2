NOM

sozip - Générer un fichier SOZip (Seek-Optimized ZIP).

Ajouté dans la version 3.7.

SYNTAXE

sozip [--help] [--help-general]
      [--quiet|--verbose]
      [[-g|--grow] | [--overwrite]]
      [-r|--recurse-paths]
      [-j|--junk-paths]
      [-l|--list]
      [--optimize-from=<input.zip>]
      [--validate]
      [--enable-sozip={auto|yes|no}]
      [--sozip-chunk-size=<valeur>]
      [--sozip-min-file-size=<valeur>]
      [--content-type=<valeur>]
      <nom_fichier_zip> [<nom_fichier>]...

DESCRIPTION

L'utilitaire sozip peut être utilisé pour :

  • créer un fichier SOZip (Seek-Optimized ZIP)
  • ajouter des fichiers à un fichier ZIP/SOZip existant
  • lister le contenu d'un fichier ZIP/SOZip
  • valider un fichier SOZip
  • convertir un fichier Zip existant en un fichier optimisé SOZip
--help
Afficher ce message d'aide et quitter
--help-general
Donne un bref message d'utilisation pour les options de ligne de commande GDAL génériques et quitte.
--quiet
Mode silencieux. Aucun message de progression n'est émis sur la sortie standard.
--verbose
Mode verbeux.
-g
--grow
Agrandir un fichier zip existant avec le contenu des fichiers spécifiés. C'est le mode par défaut de l'utilitaire. Ce commutateur est là pour la compatibilité avec l'utilitaire zip d'Info-ZIP.
--overwrite
Écraser le fichier zip cible s'il existe déjà.
-l
--list
Lister les fichiers contenus dans le fichier zip dans une sortie similaire à l'utilitaire unzip d'Info-ZIP, mais avec l'ajout d'une colonne indiquant si chaque fichier est optimisé pour la recherche.
--validate
Valide un fichier SOZip. La validation de base du format ZIP est effectuée de manière légère, limitée à pouvoir parcourir les enregistrements ZIP avec le lecteur ZIP basé sur InfoZIP utilisé par GDAL. Mais la validation des aspects spécifiques à SOZip est effectuée de manière plus approfondie.
-r
--recurse-paths
Parcourt la structure du répertoire du ou des répertoires spécifiés de manière récursive.
-j
--junk-paths
Stocker uniquement le nom d'un fichier sauvegardé (ignorer le chemin), et ne pas stocker les noms de répertoires. Par défaut, sozip stockera le chemin complet (relatif au répertoire courant).
--optimize-from=<input.zip>
Reprocesser {input.zip} pour générer un .zip optimisé SOZip. Les options --enable-sozip, --sozip-chunk-size et --sozip-min-file-size peuvent être utilisées dans ce mode.
--enable-sozip={auto|yes|no}
En mode auto, un fichier est optimisé pour la recherche uniquement si sa taille est supérieure à la valeur de --sozip-min-file-size. En mode yes, tous les fichiers d'entrée seront optimisés pour la recherche. En mode no, aucun fichier d'entrée ne sera optimisé pour la recherche.
--sozip-chunk-size=<valeur>
Taille des blocs pour un fichier optimisé pour la recherche. Par défaut, 32768 octets. La valeur est spécifiée en octets, ou les suffixes K et M peuvent être respectivement utilisés pour spécifier une valeur en kilo-octets ou méga-octets.
--sozip-min-file-size=<valeur>
Taille minimale du fichier pour décider si un fichier doit être optimisé pour la recherche, en mode --enable-sozip=auto. Par défaut, 1 Mo. La valeur est spécifiée en octets, ou les suffixes K, M ou G peuvent être respectivement utilisés pour spécifier une valeur en kilo-octets, méga-octets ou giga-octets.
--content-type=<valeur>
Stocke le Content-Type du fichier ajouté en tant que paire clé-valeur dans le champ d'extension 'KV' (0x564b) dédié au stockage des métadonnées de paires clé-valeur.
<nom_fichier_zip>
Nom du fichier zip à créer/ajouter/lister.
<nom_fichier>
Nom du fichier à ajouter.

MULTITHREADING

L'option de configuration GDAL_NUM_THREADS peut être définie sur ALL_CPUS ou une valeur entière pour spécifier le nombre de threads à utiliser pour les fichiers compressés SOZip. Par défaut, ALL_CPUS.

API C

La fonctionnalité de cet utilitaire peut être réalisée en C avec CPLAddFileInZip() ou VSICopyFile().

EXEMPLES

Créer un fichier ZIP, potentiellement optimisé pour la recherche, avec le contenu de my.gpkg :

sozip my.gpkg.zip my.gpkg

Créer un fichier ZIP, potentiellement optimisé pour la recherche, à partir du contenu d'un répertoire source :

sozip -r my.gpkg.zip source_dir/

Créer un fichier ZIP, potentiellement optimisé pour la recherche, à partir d'un fichier ZIP existant.

sozip --convert-from=in.zip out.zip

Lister le contenu d'un fichier ZIP et afficher quels fichiers sont optimisés pour la recherche :

sozip -l my.gpkg.zip

Valide un fichier SOZip :

sozip --validate my.gpkg.zip
