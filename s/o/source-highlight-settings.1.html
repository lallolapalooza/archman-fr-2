SOURCE-HIGHLIGHT-SETTINGS(1) Commandes utilisateur SOURCE-HIGHLIGHT-SETTINGS(1)

NOM

Source-highlight-settings - utilitaire pouvant être utilisé pour écrire un fichier de configuration pour GNU Source-highlight (et sa bibliothèque)

SYNTAXE

source-highlight-settings

DESCRIPTION

Depuis la version 3.0, GNU Source-highlight inclut également l'utilitaire source-highlight-settings, qui peut être utilisé pour vérifier si source-highlight sera en mesure de trouver ses fichiers de définition de langage, et d'autres fichiers de configuration, et dans ce cas, pour enregistrer les paramètres corrects dans un fichier de configuration, dans le répertoire personnel de l'utilisateur.

En particulier, le fichier de configuration enregistré s'appellera source-highlight.conf et sera stocké dans $HOME/.source-highlight/.

Pour le moment, ce fichier ne stocke que la valeur par défaut pour l'option --data-dir.
