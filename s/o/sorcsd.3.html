sous-programme récursif sorcsd (caractère jobu1, caractère jobu2, caractère jobv1t, caractère jobv2t, caractère trans, caractère signs, entier m, entier p, entier q, réel, dimension( ldx11, * ) x11, entier ldx11, réel, dimension( ldx12, * ) x12, entier ldx12, réel, dimension( ldx21, * ) x21, entier ldx21, réel, dimension( ldx22, * ) x22, entier ldx22, réel, dimension( * ) theta, réel, dimension( ldu1, * ) u1, entier ldu1, réel, dimension( ldu2, * ) u2, entier ldu2, réel, dimension( ldv1t, * ) v1t, entier ldv1t, réel, dimension( ldv2t, * ) v2t, entier ldv2t, réel, dimension( * ) work, entier lwork, entier, dimension( * ) iwork, entier info)

But :

!>
!> SORCSD calcule la décomposition CS d'une matrice orthogonale M-par-M
!> partitionnée X :
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**T
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 est de taille PxQ. Les matrices orthogonales U1, U2, V1 et V2 sont
!> respectivement PxP, (M-P)x(M-P), QxQ et (M-Q)x(M-Q). C et S sont des
!> matrices diagonales non négatives RxR telles que C^2 + S^2 = I, où
!> R = MIN(P,M-P,Q,M-Q).
!>

Paramètres

JOBU1 
!>          JOBU1 est CARACTÈRE
!>          = 'Y' : U1 est calculée ;
!>          sinon : U1 n'est pas calculée.
!>

JOBU2

!>          JOBU2 est CARACTÈRE
!>          = 'Y' : U2 est calculée ;
!>          sinon : U2 n'est pas calculée.
!>

JOBV1T

!>          JOBV1T est CARACTÈRE
!>          = 'Y' : V1T est calculée ;
!>          sinon : V1T n'est pas calculée.
!>

JOBV2T

!>          JOBV2T est CARACTÈRE
!>          = 'Y' : V2T est calculée ;
!>          sinon : V2T n'est pas calculée.
!>

TRANS

!>          TRANS est CARACTÈRE
!>          = 'T' : X, U1, U2, V1T et V2T sont stockés en ordre ligne-majeur ;
!>          sinon : X, U1, U2, V1T et V2T sont stockés en ordre colonne-majeur.
!>

SIGNS

!>          SIGNS est CARACTÈRE
!>          = 'O' : Le bloc inférieur gauche est rendu non positif
!>                  (la convention) ;
!>          sinon : Le bloc supérieur droit est rendu non positif
!>                  (la convention).
!>

M

!>          M est ENTIER
!>          Le nombre de lignes et de colonnes de X.
!>

P

!>          P est ENTIER
!>          Le nombre de lignes de X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est ENTIER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est tableau RÉEL, dimension (LDX11,Q)
!>          À l'entrée, fait partie de la matrice orthogonale dont la CSD
!>          est recherchée.
!>

LDX11

!>          LDX11 est ENTIER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X12

!>          X12 est tableau RÉEL, dimension (LDX12,M-Q)
!>          À l'entrée, fait partie de la matrice orthogonale dont la CSD
!>          est recherchée.
!>

LDX12

!>          LDX12 est ENTIER
!>          La dimension principale de X12. LDX12 >= MAX(1,P).
!>

X21

!>          X21 est tableau RÉEL, dimension (LDX21,Q)
!>          À l'entrée, fait partie de la matrice orthogonale dont la CSD
!>          est recherchée.
!>

LDX21

!>          LDX21 est ENTIER
!>          La dimension principale de X11. LDX21 >= MAX(1,M-P).
!>

X22

!>          X22 est tableau RÉEL, dimension (LDX22,M-Q)
!>          À l'entrée, fait partie de la matrice orthogonale dont la CSD
!>          est recherchée.
!>

LDX22

!>          LDX22 est ENTIER
!>          La dimension principale de X11. LDX22 >= MAX(1,M-P).
!>

THETA

!>          THETA est tableau RÉEL, dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est tableau RÉEL, dimension (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contient la matrice orthogonale PxP, U1.
!>

LDU1

!>          LDU1 est ENTIER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est tableau RÉEL, dimension (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice orthogonale (M-P)x(M-P),
!>          U2.
!>

LDU2

!>          LDU2 est ENTIER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est tableau RÉEL, dimension (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice orthogonale QxQ,
!>          V1**T.
!>

LDV1T

!>          LDV1T est ENTIER
!>          La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

V2T

!>          V2T est tableau RÉEL, dimension (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contient la matrice orthogonale (M-Q)x(M-Q),
!>          V2**T.
!>

LDV2T

!>          LDV2T est ENTIER
!>          La dimension principale de V2T. Si JOBV2T = 'Y', LDV2T >=
!>          MAX(1,M-Q).
!>

WORK

!>          WORK est tableau RÉEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille LWORK
!>          optimale.
!>          Si INFO > 0 à la sortie, WORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, avec THETA(1), ..., THETA(R), définissent
!>          la matrice dans la forme bidiagonale par blocs intermédiaire
!>          restante après non-convergence. INFO spécifie le nombre
!>          de PHI non nuls.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          la retourne comme première entrée du tableau work, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est tableau ENTIER, dimension (M-MIN(P, M-P, Q, M-Q))
!>

INFO

!>          IN
