sous-programme sopgtr (caractère uplo, entier n, réel, dimension( * ) ap, réel, dimension( * ) tau, réel, dimension( ldq, * ) q, entier ldq, réel, dimension( * ) work, entier info)

SOPGTR

But :

!>
!> SOPGTR génère une matrice orthogonale réelle Q qui est définie comme le
!> produit de n-1 réflecteurs élémentaires H(i) d'ordre n, tels que retournés par
!> SSPTRD en utilisant le stockage compact :
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': stockage compact triangulaire supérieur utilisé dans l'appel précédent
!>                 à SSPTRD ;
!>          = 'L': stockage compact triangulaire inférieur utilisé dans l'appel précédent
!>                 à SSPTRD.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice Q. N >= 0.
!>

AP

!>          AP est un tableau REEL, de dimension (N*(N+1)/2)
!>          Les vecteurs qui définissent les réflecteurs élémentaires, tels que
!>          retournés par SSPTRD.
!>

TAU

!>          TAU est un tableau REEL, de dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par SSPTRD.
!>

Q

!>          Q est un tableau REEL, de dimension (LDQ,N)
!>          La matrice orthogonale N-par-N, Q.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, de dimension (N-1)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
