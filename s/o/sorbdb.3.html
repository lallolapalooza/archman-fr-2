sous-programme sorbdb (character trans, character signs, integer m, integer p, integer q, real, dimension( ldx11, * ) x11, integer ldx11, real, dimension( ldx12, * ) x12, integer ldx12, real, dimension( ldx21, * ) x21, integer ldx21, real, dimension( ldx22, * ) x22, integer ldx22, real, dimension( * ) theta, real, dimension( * ) phi, real, dimension( * ) taup1, real, dimension( * ) taup2, real, dimension( * ) tauq1, real, dimension( * ) tauq2, real, dimension( * ) work, integer lwork, integer info)

SORBDB

But :

!>
!> SORBDB bidiagonalise simultanément les blocs d'une matrice orthogonale M-par-M
!> partitionnée X :
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 est P-par-Q. Q ne doit pas être plus grand que P, M-P, ou M-Q. (Si ce n'est
!> pas le cas, alors X doit être translatée et/ou permutée. Ceci peut être fait
!> en temps constant en utilisant les options TRANS et SIGNS. Voir SORCSD pour
!> les détails.)
!>
!> Les matrices orthogonales P1, P2, Q1, et Q2 sont respectivement P-par-P,
!> (M-P)-par-(M-P), Q-par-Q, et (M-Q)-par-(M-Q). Elles sont représentées
!> implicitement par des vecteurs de Householder.
!>
!> B11, B12, B21, et B22 sont des matrices bidiagonales Q-par-Q représentées
!> implicitement par les angles THETA, PHI.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER
!>          = 'T':      X, U1, U2, V1T, et V2T sont stockés en ordre ligne par ligne ;
!>          sinon :     X, U1, U2, V1T, et V2T sont stockés en ordre colonne par colonne.
!>

SIGNS

!>          SIGNS est CHARACTER
!>          = 'O':      Le bloc inférieur gauche est rendu non positif (la convention) ;
!>          sinon :     Le bloc supérieur droit est rendu non positif (la convention).
!>

M

!>          M est INTEGER
!>          Le nombre de lignes et de colonnes dans X.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes dans X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est INTEGER
!>          Le nombre de colonnes dans X11 et X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 est tableau REAL, dimension (LDX11,Q)
!>          À l'entrée, le bloc supérieur gauche de la matrice orthogonale à réduire.
!>          À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X11) spécifient les réflecteurs pour P1,
!>             les lignes de triu(X11,1) spécifient les réflecteurs pour Q1 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X11) spécifient les réflecteurs pour P1,
!>             les colonnes de tril(X11,-1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est INTEGER
!>          La dimension principale de X11. Si TRANS = 'N', alors LDX11 >=
!>          P ; sinon LDX11 >= Q.
!>

X12

!>          X12 est tableau REAL, dimension (LDX12,M-Q)
!>          À l'entrée, le bloc supérieur droit de la matrice orthogonale à réduire.
!>          À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X12) spécifient les premiers P réflecteurs pour
!>             Q2 ;
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X12) spécifient les premiers P réflecteurs
!>             pour Q2.
!>

LDX12

!>          LDX12 est INTEGER
!>          La dimension principale de X12. Si TRANS = 'N', alors LDX12 >=
!>          P ; sinon LDX11 >= M-Q.
!>

X21

!>          X21 est tableau REAL, dimension (LDX21,Q)
!>          À l'entrée, le bloc inférieur gauche de la matrice orthogonale à réduire.
!>          À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X21) spécifient les réflecteurs pour P2 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est INTEGER
!>          La dimension principale de X21. Si TRANS = 'N', alors LDX21 >=
!>          M-P ; sinon LDX21 >= Q.
!>

X22

!>          X22 est tableau REAL, dimension (LDX22,M-Q)
!>          À l'entrée, le bloc inférieur droit de la matrice orthogonale à réduire.
!>          À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X22(Q+1:M-P,P+1:M-Q)) spécifient les derniers
!>             M-P-Q réflecteurs pour Q2,
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X22(P+1:M-Q,Q+1:M-P)) spécifient les derniers
!>             M-P-Q réflecteurs pour P2.
!>

LDX22

!>          LDX22 est INTEGER
!>          La dimension principale de X22. Si TRANS = 'N', alors LDX22 >=
!>          M-P ; sinon LDX22 >= M-Q.
!>

THETA

!>          THETA est tableau REAL, dimension (Q)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent être
!>          calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est tableau REAL, dimension (Q-1)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent être
!>          calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est tableau REAL, dimension (P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P1.
!>

TAUP2

!>          TAUP2 est tableau REAL, dimension (M-P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P2.
!>

TAUQ1

!>          TAUQ1 est tableau REAL, dimension (Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q1.
!>

TAUQ2

!>          TAUQ2 est tableau REAL, dimension (M-Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q2.
!>

WORK

!>          WORK est tableau REAL, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

!> approximates the singular value decomposition of a bidiagonal matrix.
!>
!> approximates the singular value decomposition of a bidiagonal matrix
!>
!> \param U CHARACTER*1.
!>          Specifies whether to compute U.
!>          = 'N': The upper triangular factor U is not computed.
!>          = 'Q': The upper triangular factor U is returned.
!>
!> \param VT CHARACTER*1.
!>          Specifies whether to compute VT.
!>          = 'N': The lower triangular factor V^T is not computed.
!>          = 'Q': The lower triangular factor V^T is returned.
!>
!> \param S REAL (KIND=WP) array, dimension ( MIN(N,M) ).
!>          On exit, S contains the singular values of A.
!>
!> \param A REAL (KIND=WP) array, dimension (LDA, K), where K = min(N, M).
!>          On entry, A contains the upper bidiagonal matrix.
!>          On exit, A is overwritten by the diagonal elements of the
!>          decomposition.
!>
!> \param B REAL (KIND=WP) array, dimension (LDB, K), where K = min(N, M).
!>          On entry, B contains the off-diagonal elements of the
!>          bidiagonal matrix.
!>          On exit, B is overwritten by the off-diagonal elements of the
!>          decomposition.
!>
!> \param EPS REAL (KIND=WP).
!>          The threshold for determining the singular values.
!>
!> \param SFMIN REAL (KIND=WP).
!>          The smallest representable floating point number.
!>
!> \param TOLER REAL (KIND=WP).
!>          Tolerance for determining the rank of the matrix.
!>
!> \param N INTEGER.
!>          The number of rows of A.
!>
!> \param M INTEGER.
!>          The number of columns of A.
!>
!> \param NZ INTEGER.
!>          The number of non-zero singular values.
!>
!> \param WORK REAL (KIND=WP) array, dimension (LWORK).
!>          Work space for the subroutine.
!>
!> \param INFO INTEGER.
!>          Error flag.
!>          = 0: successful exit.
!>          < 0: if INFO = -i, the i-th argument had an illegal value.
!>
!> \details The matrix is represented as a product of
!>  Q_k ... Q_1 * diag(A) * P_1 ... P_l where Q_i and P_i are Householder
!>  reflector transformations.
!>
!>  The bidiagonal matrix is represented as follows:
!>
!>  diag(A) has diagonal entries A(1,1), A(2,2), ..., A(K,K) where K = min(N,M).
!>  off-diagonal entries B(I,I) for I = 1, ..., K-1.
!>
!>  The diagonal blocks B11, B12, B21, and B22 are represented implicitly
!>  by angles THETA(1), ..., THETA(Q) and PHI(1), ..., PHI(Q-1). B11 and
!>  B21 are upper bidiagonal, while B21 and B22 are lower bidiagonal.
!>  Every entry in each bidiagonal band is a product of a sine or cosine
!>  of a THETA with a sine or cosine of a PHI. See [1] or SORCSD for
!>  details.
!>
!>  P1, P2, Q1, and Q2 are represented as products of elementary
!>  reflectors. See SORCSD for details on generating P1, P2, Q1, and Q2
!>  using SORGQR and SORGLQ.
!>

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
