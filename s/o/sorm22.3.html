Documentation de la fonction/sous-programme

sous-programme sorm22 (caractère side, caractère trans, entier m, entier n, entier n1, entier n2, réel, dimension( ldq, * ) q, entier ldq, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) work, entier lwork, entier info)

SORM22 multiplie une matrice générale par une matrice orthogonale bande.

Objectif

!>
!>
!>  SORM22 écrase la matrice C générale réelle M par N avec
!>
!>                  SIDE = 'L'     SIDE = 'R'
!>  TRANS = 'N':      Q * C          C * Q
!>  TRANS = 'T':      Q**T * C       C * Q**T
!>
!>  où Q est une matrice orthogonale réelle d'ordre NQ, avec NQ = M si
!>  SIDE = 'L' et NQ = N si SIDE = 'R'.
!>  La matrice orthogonale Q traite une structure de blocs 2x2
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  où Q12 est une matrice triangulaire inférieure N1xN1 et Q21 est une
!>  matrice triangulaire supérieure N2xN2.
!>

Paramètres

SIDE 
!>          SIDE est CARACTERE*1
!>          = 'L': applique Q ou Q**T à Gauche ;
!>          = 'R': applique Q ou Q**T à Droite.
!>

TRANS

!>          TRANS est CARACTERE*1
!>          = 'N':  applique Q (Pas de transposée) ;
!>          = 'C':  applique Q**T (Transposée conjuguée).
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

N1
N2

!>          N1 est ENTIER
!>          N2 est ENTIER
!>          La dimension de Q12 et Q21, respectivement. N1, N2 >= 0.
!>          La condition suivante doit être satisfaite :
!>          N1 + N2 = M si SIDE = 'L' et N1 + N2 = N si SIDE = 'R'.
!>

Q

!>          Q est tableau REEL, dimension
!>                              (LDQ,M) si SIDE = 'L'
!>                              (LDQ,N) si SIDE = 'R'
!>

LDQ

!>          LDQ est ENTIER
!>          La dimension principale du tableau Q.
!>          LDQ >= max(1,M) si SIDE = 'L' ; LDQ >= max(1,N) si SIDE = 'R'.
!>

C

!>          C est tableau REEL, dimension (LDC,N)
!>          À l'entrée, la matrice M par N C.
!>          À la sortie, C est écrasée par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est ENTIER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour des performances optimales LWORK >= M*N.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
