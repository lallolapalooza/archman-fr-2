NOM

socklist - affiche la liste des sockets ouverts

SYNTAXE

socklist

DESCRIPTION

socklist est un script Perl qui vous donne une liste de tous les sockets ouverts, énumérant les types, le port, l'inode, l'uid, le pid, le fd et le programme auquel il appartient.

OPTIONS

Aucune.

FICHIERS

/proc/*/fd/*
Descripteurs de fichiers.
/proc/net/tcp
Liste des sockets TCP.
/proc/net/udp
Liste des sockets UDP.
/proc/net/raw
Liste des sockets brutes.

BOGUES

Aucun pour le moment.

VOIR AUSSI

procinfo(8), netstat(8).
