Documentation de la fonction/sous-routine

sous-routine sorhr_col (entier m, entier n, entier nb, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldt, * ) t, entier ldt, réel, dimension( * ) d, entier info)

SORHR_COL

But:

!>
!>  SORHR_COL prend en entrée une matrice réelle M par N, Q_in, avec des colonnes
!>  orthonormales, stockée dans A, et effectue une Reconstruction de Householder (HR),
!>  c'est-à-dire qu'elle reconstruit des vecteurs de Householder V(i) représentant
!>  implicitement une autre matrice M par N, Q_out, telle que Q_in = Q_out*S,
!>  où S est une matrice diagonale N par N avec des entrées diagonales
!>  égales à +1 ou -1. Les vecteurs de Householder (colonnes V(i) de V) sont
!>  stockés dans A en sortie, et les entrées diagonales de S sont stockées dans D.
!>  Les réflecteurs par blocs sont également retournés dans T
!>  (même format de sortie que SGEQRT).
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

NB

!>          NB est un ENTIER
!>          La taille du bloc de colonnes à utiliser pour la reconstruction
!>          des blocs de vecteurs de colonnes de Householder dans le tableau A
!>          et des réflecteurs de bloc correspondants dans le tableau T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes.)
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>
!>          En entrée :
!>
!>             Le tableau A contient une matrice orthonormale M par N, Q_in,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>
!>          En sortie :
!>
!>             Les éléments sous la diagonale de A représentent la matrice
!>             inférieure trapézoïdale unitaire V des vecteurs de colonnes de Householder
!>             V(i). Les entrées diagonales unitaires de V ne sont pas stockées
!>             (même format que la sortie sous la diagonale de A par
!>             SGEQRT). La matrice T et la matrice V stockées en sortie
!>             dans A définissent implicitement Q_out.
!>
!>             Les éléments au-dessus de la diagonale contiennent le facteur U
!>             de la décomposition LU :
!>                Q_in - ( S ) = V * U
!>                       ( 0 )
!>             où 0 est une matrice nulle de taille (M-N)-par-(M-N).
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau REEL,
!>          dimension (LDT, N)
!>
!>          Soit NOCB = Nombre_de_blocs_de_colonnes_en_sortie
!>                   = CEIL(N/NB)
!>
!>          En sortie, T(1:NB, 1:N) contient NOCB réflecteurs de bloc supérieurs
!>          utilisés pour définir Q_out stockés sous forme compacte en tant que
!>          séquence de blocs de colonnes NBxNB triangulaires supérieurs
!>          (même format que la sortie T dans SGEQRT).
!>          La matrice T et la matrice V stockées en sortie dans A
!>          définissent implicitement Q_out. NOTE : Les triangles inférieurs
!>          sous les blocs triangulaires supérieurs seront remplis de
!>          zéros. Voir Détails supplémentaires.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB,N)).
!>

D

!>          D est un tableau REEL, dimension min(M,N).
!>          Les éléments ne peuvent être que plus ou moins un.
!>
!>          D(i) est construit comme D(i) = -SIGN(Q_in_i(i,i)), où
!>          1 <= i <= min(M,N), et Q_in_i est Q_in après avoir effectué
!>          i-1 étapes d'élimination Gaussienne "modifiée".
!>          Voir Détails supplémentaires.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Le facteur orthogonal M par M calculé Q_out est défini implicitement comme
!> un produit de matrices orthogonales Q_out(i). Chaque Q_out(i) est stocké dans
!> le format de représentation WY compact dans les blocs correspondants des
!> matrices V (stockées dans A) et T.
!>
!> La matrice inférieure trapézoïdale unitaire M par N, V, stockée dans la
!> matrice M par N A, contient les vecteurs colonnes V(i) en blocs de colonnes
!> de taille NB, VB(j). Par exemple, VB(1) contient les colonnes
!> V(1), V(2), ... V(NB). NOTE : Les entrées unitaires sur
!> la diagonale de V ne sont pas stockées dans A.
!>
!> Le nombre de blocs de colonnes est
!>
!>     NOCB = Nombre_de_blocs_de_colonnes_en_sortie = CEIL(N/NB)
!>
!> où chaque bloc est d'ordre NB sauf le dernier bloc, qui
!> est d'ordre LAST_NB = N - (NOCB-1)*NB.
!>
!> Par exemple, si M=6, N=5 et NB=2, la matrice V est
!>
!>
!>     V = (    VB(1),   VB(2), VB(3) ) =
!>
!>       = (    1                      )
!>         ( v21    1                 )
!>         ( v31  v32    1            )
!>         ( v41  v42  v43   1        )
!>         ( v51  v52  v53  v54    1  )
!>         ( v61  v62  v63  v54   v65 )
!>
!>
!> Pour chacun des blocs de colonnes VB(i), un réflecteur de bloc triangulaire
!> supérieur TB(i) est calculé. Ces blocs sont stockés sous forme de
!> séquence de blocs de colonnes triangulaires supérieurs dans la matrice T, NB par N.
!> La taille de chaque bloc TB(i) est NB par NB, sauf
!> pour le dernier bloc, dont la taille est LAST_NB par LAST_NB.
!>
!> Par exemple, si M=6, N=5 et NB=2, la matrice T est
!>
!>     T  = (    TB(1),    TB(2), TB(3) ) =
!>
!>        = ( t11  t12  t13  t14   t15  )
!>          (      t22       t24        )
!>
!>
!> Le facteur M par M, Q_out, est donné comme un produit de NOCB
!> matrices orthogonales M par M, Q_out(i).
!>
!>     Q_out = Q_out(1) * Q_out(2) * ... * Q_out(NOCB),
!>
!> où chaque matrice Q_out(i) est donnée par la représentation WY
!> en utilisant les blocs correspondants des matrices V et T :
!>
!>     Q_out(i) = I - VB(i) * TB(i) * (VB(i))**T,
!>
!> où I est la matrice identité. Voici la formule avec les dimensions matricielles :
!>
!>  Q(i){M-par-M} = I{M-par-M} -
!>    VB(i){M-par-INB} * TB(i){INB-par-INB} * (VB(i))**T {INB-par-M},
!>
!> où INB = NB, sauf pour le dernier bloc NOCB
!> pour lequel INB=LAST_NB.
!>
!> =====
!> NOTE :
!> =====
!>
!> Si Q_in est le résultat d'une factorisation QR
!> B = Q_in * R_in, alors :
!>
!> B = (Q_out*S) * R_in = Q_out * (S * R_in) = Q_out * R_out.
!>
!> Donc, si l'on veut interpréter Q_out comme le résultat
!> de la factorisation QR de B, alors le R_out correspondant
!> doit être égal à R_out = S * R_in, c'est-à-dire que certaines lignes de R_in
!> doivent être multipliées par -1.
!>
!> Pour les détails de l'algorithme, voir [1].
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>
