SOURCE-HIGHLIGHT(1) Commandes utilisateur SOURCE-HIGHLIGHT(1)

NOM

Source-highlight - convertir le code source en document avec coloration syntaxique

SYNTAXE

source-highlight [OPTIONS]... < FICHIER_ENTREE FICHIER_SORTIE

DESCRIPTION

GNU GNU source-highlight 3.1.9

Colore la syntaxe d'un fichier source (par ex. Java) dans un format spécifique (par ex. HTML)

source-highlight [OPTIONS]... -i FICHIER_ENTREE -oFICHIER_SORTIE source-highlight [OPTIONS]... [FICHIERS]...
-h, --help
Affiche l'aide et quitte
--detailed-help
Affiche l'aide, y compris tous les détails et les options cachées, et quitte
-V, --version
Affiche la version et quitte
-i, --input=NOMFICHIER
Fichier d'entrée (par défaut=stdin)
-o, --output=NOMFICHIER
Fichier de sortie (par défaut=stdout, lorsque la troisième forme d'invocation est utilisée). Si 'STDOUT' est spécifié, la sortie est dirigée vers la sortie standard.

Vous pouvez simplement spécifier certains fichiers sur la ligne de commande et utiliser également des expressions régulières (par exemple *.java). Dans ce cas, le nom des fichiers de sortie sera formé en utilisant le nom du fichier source avec une extension .EXT ajoutée, où EXT est l'extension choisie selon le format de sortie spécifié (par exemple .html).

-s, --src-lang=CHAINE
langue source (utilisez --lang-list pour obtenir la liste complète). Si non spécifié, la langue source sera devinée à partir de l'extension du fichier.
--lang-list
liste toutes les langues supportées et le fichier de définition de langue associé.
--outlang-list
liste toutes les langues de sortie supportées et le fichier de définition de langue associé.
-f, --out-format=CHAINE
format de sortie (utilisez --outlang-list pour obtenir la liste complète) (par défaut=`html')
-d, --doc
crée un fichier de sortie qui peut être utilisé comme document autonome (par exemple, ne pas être inclus dans un autre).
--no-doc
annule l'option --doc même si elle est implicite (par exemple, lorsqu'un css est donné).
-c, --css=NOMFICHIER
le nom du fichier de feuille de style externe. Implique --doc
-T, --title=CHAINE
donne un titre au document de sortie. Implique --doc
-t, --tab=INT
spécifie la longueur de tabulation. (par défaut=`8')
-H, --header=NOMFICHIER
fichier à insérer comme en-tête
-F, --footer=NOMFICHIER
fichier à insérer comme pied de page
--style-file=NOMFICHIER
spécifie le fichier contenant les options de format (par défaut=`default.style')
--style-css-file=NOMFICHIER spécifie le fichier contenant les options de format (en
syntaxe css)
--style-defaults=NOMFICHIER spécifie le fichier contenant les valeurs par défaut pour les options de format
(par défaut=`style.defaults')
--outlang-def=NOMFICHIER
fichier de définition de langue de sortie
--outlang-map=NOMFICHIER
fichier de mappage de langue de sortie (par défaut=`outlang.map')
--data-dir=CHEMIN
répertoire où rechercher les fichiers de définition de langue et les mappages de langue. S'il n'est pas spécifié, ces fichiers sont recherchés dans le répertoire courant et dans le répertoire d'installation des données.
--output-dir=CHEMIN
répertoire de sortie
--lang-def=NOMFICHIER
fichier de définition de langue
--lang-map=NOMFICHIER
fichier de mappage de langue (par défaut=`lang.map')
--show-lang-elements=NOMFICHIER
affiche les éléments de langue qui sont définis.
dans le fichier de définition de langue.
--infer-lang
force l'inférence du langage du script source (en remplaçant la spécification de langue donnée).

Lignes :

-n, --line-number[=REMPlISSAGE]
numérote toutes les lignes de sortie, en utilisant le caractère de remplissage spécifié (par défaut=`0').
--line-number-ref[=PREFIXE]
numérote toutes les lignes de sortie et génère une ancre,
faite du préfixe spécifié + le numéro de ligne
(par défaut=`line').

Filtrage de la sortie :

Mode : linerange
spécification de plages de lignes.
--line-range=CHAINE
génère uniquement les lignes dans les plages spécifiées.
--range-separator=CHAINE
le séparateur optionnel à imprimer entre les plages (par exemple, "...").
--range-context=INT
nombre de lignes (de contexte) générées même si elles ne sont pas dans la plage.
Mode : regexrange
spécification de plages délimitées par des expressions régulières.
--regex-range=CHAINE
génère uniquement les lignes comprises dans les expressions régulières spécifiées.

Génération de références :

--gen-references=CHAINE
génère des références (valeurs possibles = "inline", "postline", "postdoc" par défaut = `inline').
--ctags-file=NOMFICHIER
spécifie le fichier généré par ctags qui sera utilisé pour générer des références (par défaut=`tags').
--ctags=CMD
comment exécuter la commande ctags. Si cette option n'est pas spécifiée, ctags sera exécuté avec la valeur par défaut. S'il est spécifié avec une chaîne vide, ctags ne sera pas exécuté du tout (par défaut = `ctags --excmd=n --tag-relative=yes').

Tests :

-v, --verbose
mode verbeux activé.
-q, --quiet
n'affiche aucune information de progression.
--binary-output
écrit les fichiers de sortie en mode binaire.
--statistics
affiche quelques statistiques (par exemple, temps écoulé).
--gen-version
inclut la version de source-highlight dans le fichier généré (par défaut=activé).
--check-lang=NOMFICHIER
vérifie uniquement la correction d'un fichier de définition de langue.
--check-outlang=NOMFICHIER
vérifie uniquement la correction d'un fichier de définition de langue de sortie.
--failsafe

t>
si aucune définition de langage n'est trouvée pour l'entrée, elle est simplement copiée en sortie
-g, --debug-langdef[=TYPE]
déboguer une définition de langage. En mode dump, il affiche simplement toutes les étapes ; en mode interactif, à chaque étape, il attend une entrée (appuyez sur ENTRÉE pour avancer) (valeurs possibles="interactive", "dump" par défaut=`dump')
--show-regex=FILENAME
afficher l'automate d'expression régulière correspondant à un fichier de définition de langage
