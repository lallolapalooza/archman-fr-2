Documentation de la fonction/sous-programme

sous-programme sorgl2 (entier m, entier n, entier k, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) tau, reel, dimension( * ) work, entier info)

SORGL2

But :

!>
!> SORGL2 génère une matrice réelle m par n, Q, dont les lignes sont orthonormées,
!> qui est définie comme les m premières lignes d'un produit de k réflecteurs
!> élémentaires d'ordre n
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tel que retourné par SGELQF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          À l'entrée, la i-ème ligne doit contenir le vecteur qui définit
!>          le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné
!>          par SGELQF dans les k premières lignes de son tableau argument A.
!>          À la sortie, la matrice m x n, Q.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau REEL, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par SGELQF.
!>

WORK

!>          WORK est un tableau REEL, de dimension (M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
