SOFTHSM2-KEYCONV(1) Manuel des commandes générales SOFTHSM2-KEYCONV(1)

NOM

softhsm2-keyconv - conversion du format de fichier clé BIND vers PKCS#8

SYNTAXE

softhsm2-keyconv --in chemin --out chemin [--pin PIN]

DESCRIPTION

softhsm2-keyconv peut convertir des fichiers .private-key BIND au format de fichier PKCS#8. Ceci vous permet d'importer le fichier PKCS#8 dans libsofthsm en utilisant la commande softhsm2-util. Si vous avez un autre format de fichier, alors openssl peut probablement vous aider à le convertir au format de fichier PKCS#8.

OPTIONS

--help, -h Affiche l'écran d'aide.

--in chemin
Le chemin vers le fichier d'entrée.
--out chemin
Le chemin vers le fichier de sortie.
--pin PIN
Le PIN sera utilisé pour chiffrer le fichier PKCS#8. S'il n'est pas fourni, le fichier PKCS#8 ne sera pas chiffré.
--version, -v
Affiche les informations de version.

EXEMPLES

La commande suivante peut être utilisée pour convertir un fichier .private-key BIND en un fichier PKCS#8 :

softhsm2-keyconv --in Kexample.com.+007+05474.private \
--out rsa.pem
