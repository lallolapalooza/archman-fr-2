NOM

sogrep - Trouver les liens de bibliothèques partagées dans un dépôt Arch Linux

SYNTAXE

sogrep [options] dépôt nom_lib

DESCRIPTION

Vérifie la base de données des liens soname pour les dépôts Arch Linux contenant des paquets liés à une bibliothèque partagée donnée. Si le dépôt spécifié est "all", tous les dépôts seront recherchés, sinon seul le dépôt nommé sera recherché.

Si la base de données des liens n'existe pas, elle sera téléchargée en premier.

OPTIONS

-v, --verbose

Fournit une sortie détaillée contenant les liens correspondants pour chaque paquet, le dépôt d'où il provient (dans le cas où tous les dépôts sont recherchés), et, en combinaison avec -r, une barre de progression pour le téléchargement de la base de données des liens.

-r, --refresh

Actualise les bases de données de liens.

-h, --help

Affiche un texte d'aide.

VARIABLES ENVIRONNEMENT

SOLINKS_MIRROR="https://mirror.foo.com" Miroir alternatif à utiliser pour télécharger la base de données des liens soname.

SOCACHE_DIR="/chemin/vers/le/répertoire"

Répertoire où la base de données des liens soname est stockée, remplace le répertoire par défaut défini par la variable d'environnement XDG_CACHE_HOME ou la variable d'environnement HOME si XDG_CACHE_HOME n'est pas définie.
