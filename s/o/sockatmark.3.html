sockatmark(3) Manuel des fonctions de bibliothèque sockatmark(3)

NOM

sockatmark - déterminer si une socket est à la marque de données hors bande

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/socket.h>
int sockatmark(int sockfd);
Conditions de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

sockatmark() :

    _POSIX_C_SOURCE >= 200112L

DESCRIPTION

sockatmark() renvoie une valeur indiquant si la socket référencée par le descripteur de fichier sockfd se trouve ou non à la marque de données hors bande. Si la socket est à la marque, 1 est renvoyé ; si la socket n'est pas à la marque, 0 est renvoyé. Cette fonction ne supprime pas la marque de données hors bande.

VALEUR DE RETOUR

Un appel réussi à sockatmark() renvoie 1 si la socket est à la marque de données hors bande, ou 0 si elle ne l'est pas. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
sockfd n'est pas un descripteur de fichier valide.
EINVAL
sockfd n'est pas un descripteur de fichier auquel sockatmark() peut être appliquée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sockatmark () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.2.4. POSIX.1-2001.

NOTES

Si sockatmark() renvoie 1, les données hors bande peuvent être lues en utilisant le drapeau MSG_OOB de recv(2).

Les données hors bande ne sont prises en charge que sur certains protocoles de socket de flux.

sockatmark() peut être appelée en toute sécurité depuis un gestionnaire du signal SIGURG.

sockatmark() est implémentée en utilisant l'opération ioctl(2) SIOCATMARK.

BOGUES

Avant glibc 2.4, sockatmark() ne fonctionnait pas.

EXEMPLES

Le code suivant peut être utilisé après la réception d'un signal SIGURG pour lire (et ignorer) toutes les données jusqu'à la marque, puis lire l'octet de données à la marque :

    char buf[BUF_LEN];
    char oobdata;
    int atmark, s;
    for (;;) {
        atmark = sockatmark(sockfd);
        if (atmark == -1) {
            perror("sockatmark");
            break;
        }
        if (atmark)
            break;
        s = read(sockfd, buf, BUF_LEN);
        if (s == -1)
            perror("read");
        if (s <= 0)
            break;
    }
    if (atmark == 1) {
        if (recv(sockfd, &oobdata, 1, MSG_OOB) == -1) {
            perror("recv");
            ...
        }
    }

VOIR AUSSI

fcntl(2), recv(2), send(2), tcp(7)
