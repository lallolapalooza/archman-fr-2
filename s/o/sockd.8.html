SOCKD(8) Manuel du gestionnaire système SOCKD(8)

NOM

sockd - serveur proxy réseau

SYNTAXE

sockd [-DLVdhnv] [-N nombre] [-f fichier] [-p fichier]

DESCRIPTION

Dante implémente le standard SOCKS et peut fonctionner comme pare-feu entre réseaux.

Dante relaie les connexions TCP et UDP, aussi bien depuis l'extérieur du réseau que vers l'intérieur, et depuis l'intérieur vers l'extérieur.

Les options sont les suivantes :

-D
Dante se détache du terminal de contrôle et s'exécute en arrière-plan en tant que démon système.
-L
Affiche la licence sous laquelle Dante est distribué.
-Nnombre
Au démarrage, Dante lancera nombre "serveurs principaux". Ceci peut être utilisé pour des serveurs extrêmement sollicités, ou pour mettre en place une redondance très rudimentaire, car Dante essaiera de rendre ces "serveurs principaux" aussi indépendants que possible les uns des autres. Il est peu probable qu'un nombre supérieur au nombre de CPU améliore les performances.
-V
Vérifie le fichier de configuration et quitte.
-dnombre
Définit le niveau de débogage, zéro pour désactiver.
-ffichier
Dante lira sa configuration dans le fichier fichier.
-h
Affiche les options actuellement valides.
-n
Désactive les messages de maintien de connexion TCP (keep-alive). Normalement, Dante active ces messages afin que les connexions avec des machines en panne ou inaccessibles pour d'autres raisons expirent. Notez que cela peut prendre plusieurs heures. Voir aussi l'option "timeout" dans sockd.conf(5).
-pfichier
Dante écrira le PID du processus principal dans ce fichier. fichier.
-v
Affiche la version de Dante.

SIGNALS

SIGHUP
Recharge le fichier de configuration. Rouvre également les fichiers journaux.
SIGINFO/SIGUSR1
Affiche des informations sur l'état actuel des serveurs et des clients.

ENVIRONNEMENT

TMPDIR
Utilise TMPDIR pour les fichiers temporaires. Dante utilisera ce répertoire pour les fichiers de verrouillage et les fichiers mappés en mémoire. Il est recommandé que TMPDIR soit défini sur un système de fichiers (local) à faible latence. Le répertoire doit avoir les permissions de lecture/écriture/exécution pour l'utilisateur privilégié et non privilégié (tel que spécifié dans /etc/sockd.conf), mais pour aucun autre utilisateur non privilégié.

FICHIERS

/etc/sockd.conf
Fichier de configuration du serveur Dante.
