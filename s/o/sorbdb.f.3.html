Documentation de la fonction/sous-routine

sous-routine sorbdb (character trans, character signs, integer m, integer p, integer q, real, dimension( ldx11, * ) x11, integer ldx11, real, dimension( ldx12, * ) x12, integer ldx12, real, dimension( ldx21, * ) x21, integer ldx21, real, dimension( ldx22, * ) x22, integer ldx22, real, dimension( * ) theta, real, dimension( * ) phi, real, dimension( * ) taup1, real, dimension( * ) taup2, real, dimension( * ) tauq1, real, dimension( * ) tauq2, real, dimension( * ) work, integer lwork, integer info)

Objectif :

!>
!> SORBDB bidiagonalise simultanément les blocs d'une matrice orthogonale M-par-M
!> partitionnée X :
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 est de taille P par Q. Q ne doit pas être plus grand que P, M-P ou M-Q. (Si ce
!> n'est pas le cas, alors X doit être transposée et/ou permutée. Cela peut être
!> fait en temps constant en utilisant les options TRANS et SIGNS. Voir SORCSD
!> pour les détails.)
!>
!> Les matrices orthogonales P1, P2, Q1 et Q2 sont de taille P-par-P, (M-P)-par-
!> (M-P), Q-par-Q et (M-Q)-par-(M-Q) respectivement. Elles sont
!> représentées implicitement par des vecteurs de Householder.
!>
!> B11, B12, B21 et B22 sont des matrices bidiagonales Q-par-Q représentées
!> implicitement par les angles THETA, PHI.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER
!>          = 'T':      X, U1, U2, V1T et V2T sont stockés en ordre ligne par ligne ;
!>          autrement : X, U1, U2, V1T et V2T sont stockés en ordre colonne par colonne.
!>

SIGNS

!>          SIGNS est CHARACTER
!>          = 'O':      Le bloc inférieur gauche est rendu non positif (la
!>                       convention) ;
!>          autrement : Le bloc supérieur droit est rendu non positif (la
!>                       convention).
!>

M

!>          M est INTEGER
!>          Le nombre de lignes et de colonnes dans X.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes dans X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est INTEGER
!>          Le nombre de colonnes dans X11 et X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 est un tableau de REAL, dimension (LDX11,Q)
!>          En entrée, le bloc supérieur gauche de la matrice orthogonale à réduire.
!>          En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X11) spécifient les réflecteurs pour P1,
!>             les lignes de triu(X11,1) spécifient les réflecteurs pour Q1 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X11) spécifient les réflecteurs pour P1,
!>             les colonnes de tril(X11,-1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est INTEGER
!>          La dimension principale de X11. Si TRANS = 'N', alors LDX11 >=
!>          P ; sinon LDX11 >= Q.
!>

X12

!>          X12 est un tableau de REAL, dimension (LDX12,M-Q)
!>          En entrée, le bloc supérieur droit de la matrice orthogonale à réduire.
!>          En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X12) spécifient les P premiers réflecteurs pour
!>             Q2 ;
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X12) spécifient les P premiers réflecteurs
!>             pour Q2.
!>

LDX12

!>          LDX12 est INTEGER
!>          La dimension principale de X12. Si TRANS = 'N', alors LDX12 >=
!>          P ; sinon LDX11 >= M-Q.
!>

X21

!>          X21 est un tableau de REAL, dimension (LDX21,Q)
!>          En entrée, le bloc inférieur gauche de la matrice orthogonale à réduire.
!>          En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X21) spécifient les réflecteurs pour P2 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est INTEGER
!>          La dimension principale de X21. Si TRANS = 'N', alors LDX21 >=
!>          M-P ; sinon LDX21 >= Q.
!>

X22

!>          X22 est un tableau de REAL, dimension (LDX22,M-Q)
!>          En entrée, le bloc inférieur droit de la matrice orthogonale à réduire.
!>          En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X22(Q+1:M-P,P+1:M-Q)) spécifient les derniers
!>             M-P-Q réflecteurs pour Q2,
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X22(P+1:M-Q,Q+1:M-P)) spécifient les derniers
!>             M-P-Q réflecteurs pour P2.
!>

LDX22

!>          LDX22 est INTEGER
!>          La dimension principale de X22. Si TRANS = 'N', alors LDX22 >=
!>          M-P ; sinon LDX22 >= M-Q.
!>

THETA

!>          THETA est un tableau de REAL, dimension (Q)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est un tableau de REAL, dimension (Q-1)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est un tableau de REAL, dimension (P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P1.
!>

TAUP2

!>          TAUP2 est un tableau de REAL, dimension (M-P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P2.
!>

TAUQ1

!>          TAUQ1 est un tableau de REAL, dimension (Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q1.
!>

TAUQ2

!>          TAUQ2 est un tableau de REAL, dimension (M-Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q2.
!>

WORK

!>          WORK est un tableau de REAL, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, alors une requête de mémoire est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
