NOM

solv - exemple de gestionnaire de paquets basé sur libsolv

SYNTAXE

solv install [OPTIONS] PKG...

solv erase [OPTIONS] PKG...

solv list [OPTIONS] PKG...

solv info [OPTIONS] PKG...

solv search [OPTIONS] STRING...

solv verify [OPTIONS] PKG...

solv update [OPTIONS] PKG...

solv dist-upgrade [OPTIONS] PKG...

solv repolist [OPTIONS]

DESCRIPTION

L'outil solv démontre certaines fonctionnalités de la bibliothèque libsolv. Il n'est pas destiné à remplacer un véritable gestionnaire de paquets, par exemple, il ne met pas en cache les paquets téléchargés.

--root ROOTDIR

Installe les paquets en utilisant ROOTDIR comme racine du système de fichiers. Cela signifie également que la base de données des paquets de ROOTDIR sera utilisée.

--clean

Supprime également les paquets qui ne sont plus nécessaires lors de la désinstallation, comme les bibliothèques qui étaient utilisées par les paquets désinstallés.

--best

Force l'utilisation du meilleur paquet (normalement celui avec la version la plus élevée) pour les opérations d'installation et de mise à jour.

--testcase

Écrit un cas de test après la résolution des dépendances.

Les options suivantes peuvent être utilisées pour filtrer les paquets. Si la même option est utilisée plusieurs fois, le résultat est combiné avec un OU logique.

-i

Limite les paquets aux paquets installés.

-r REPO

Limite les paquets au dépôt spécifié.

--arch ARCHITECTURE

Limite les paquets à l'architecture de paquet spécifiée.

--type TYPE

Limite les paquets au type de paquet spécifié.
