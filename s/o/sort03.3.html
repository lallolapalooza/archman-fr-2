Documentation de la fonction/sous-routine

sous-routine sort03 (character*( * ) rc, integer mu, integer mv, integer n, integer k, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( * ) work, integer lwork, real result, integer info)

SORT03

But:

!>
!> SORT03 compare deux matrices orthogonales U et V pour déterminer si leurs
!> lignes ou colonnes correspondantes couvrent les mêmes espaces. Les lignes
!> sont vérifiées si RC = 'R', et les colonnes sont vérifiées si RC = 'C'.
!>
!> RESULT est le maximum de
!>
!>    | V*V' - I | / ( MV ulp ), si RC = 'R', ou
!>
!>    | V'*V - I | / ( MV ulp ), si RC = 'C',
!>
!> et le maximum sur les lignes (ou colonnes) 1 à K de
!>
!>    | U(i) - S*V(i) |/ ( N ulp )
!>
!> où S est +-1 (choisi pour minimiser l'expression), U(i) est la i-ème
!> ligne (colonne) de U, et V(i) est la i-ème ligne (colonne) de V.
!>

Paramètres

RC 
!>          RC est CHARACTER*1
!>          Si RC = 'R', les lignes de U et V sont comparées.
!>          Si RC = 'C', les colonnes de U et V sont comparées.
!>

MU

!>          MU est INTEGER
!>          Le nombre de lignes de U si RC = 'R', et le nombre de
!>          colonnes si RC = 'C'. Si MU = 0, SORT03 ne fait rien.
!>          MU doit être supérieur ou égal à zéro.
!>

MV

!>          MV est INTEGER
!>          Le nombre de lignes de V si RC = 'R', et le nombre de
!>          colonnes si RC = 'C'. Si MV = 0, SORT03 ne fait rien.
!>          MV doit être supérieur ou égal à zéro.
!>

N

!>          N est INTEGER
!>          Si RC = 'R', le nombre de colonnes des matrices U et V,
!>          et si RC = 'C', le nombre de lignes de U et V. Si N = 0,
!>          SORT03 ne fait rien. N doit être supérieur ou égal à zéro.
!>

K

!>          K est INTEGER
!>          Le nombre de lignes ou colonnes de U et V à comparer.
!>          0 <= K <= max(MU,MV).
!>

U

!>          U est un tableau REAL, dimension (LDU,N)
!>          La première matrice à comparer. Si RC = 'R', U est MU par N, et
!>          si RC = 'C', U est N par MU.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale de U. Si RC = 'R', LDU >= max(1,MU),
!>          et si RC = 'C', LDU >= max(1,N).
!>

V

!>          V est un tableau REAL, dimension (LDV,N)
!>          La deuxième matrice à comparer. Si RC = 'R', V est MV par N, et
!>          si RC = 'C', V est N par MV.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale de V. Si RC = 'R', LDV >= max(1,MV),
!>          et si RC = 'C', LDV >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. Pour de meilleures performances, LWORK
!>          devrait être au moins N*N si RC = 'C' ou M*M si RC = 'R', mais
!>          les tests seront effectués même si LWORK est 0.
!>

RESULT

!>          RESULT est REAL
!>          La valeur calculée par le test décrit ci-dessus. RESULT est
!>          limité à 1/ulp pour éviter le débordement.
!>

INFO

!>          INFO est INTEGER
!>          0 indique une sortie réussie
!>          -k indique que le k-ième paramètre avait une valeur illégale
!>
