Documentation de fonction/sous-routine

sous-routine sormql (character side, character trans, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

SORMQL

But :

!>
!> SORMQL écrase la matrice réelle générale M par N de C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> où Q est une matrice orthogonale réelle définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> tels que renvoyés par SGEQLF. Q est de dimension M si SIDE = 'L' et de dimension N
!> si SIDE = 'R'.
!>

Paramètres :

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T à gauche ;
!>          = 'R': appliquer Q ou Q**T à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'T':  Transposée, appliquer Q**T.
!>

M

!>          M est un entier
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est un entier
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau de REEL, dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que renvoyé par
!>          SGEQLF dans les k dernières colonnes de son argument tableau A.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau de REEL, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que renvoyé par SGEQLF.
!>

C

!>          C est un tableau de REEL, dimension (LDC,N)
!>          À l'entrée, la matrice C de M par N.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est un entier
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la taille optimale LWORK.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
