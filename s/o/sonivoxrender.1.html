SONIVOXRENDER(1) Rendu de fichier MIDI Sonivox SONIVOXRENDER(1)

NOM

sonivoxrender — Rendu de fichiers MIDI standard en audio PCM brut

SYNTAXE

sonivoxrender [-h|--help] [-v|--version] [-d|--dls fichier.dls] [-r|--reverb 0..4] [-w|--wet 0..32767] [-n|--dry 0..32767] [-c|--chorus 0..4] [-l|--level 0..32767] [-g|--gain 0..100] [-V|--Verbosity 0..5] fichier_midi

DESCRIPTION

Ce programme est un rendu de fichier MIDI basé sur la bibliothèque de synthèse sonivox. Il lit le format de fichier .MID (Standard MIDI Files) et écrit un flux audio sur la sortie standard sous forme d'échantillons PCM stéréo bruts de 16 bits.

Options

-h, --help
Affiche des informations d'utilisation brèves.
-v, --version
Affiche les numéros de version.
-d, --dls fichier.dls
Nom de fichier optionnel pour le soundfont DLS. S'il n'est pas fourni, il utilise un soundfont interne embarqué.
-r, --reverb preset_reverb
Préréglage de réverbération entre 0 et 4 : 0=aucun, 1=grande salle, 2=salle, 3=chambre, 4=pièce.
-w, --wet wet_reverb
Niveau wet de la réverbération entre 0 et 32767.
-n, --dry dry_reverb
Niveau dry de la réverbération entre 0 et 32767.
-c, --chorus preset_chorus
Préréglage de chorus entre 0 et 4 : 0=aucun, 1..4=préréglages.
-l, --level niveau_chorus
Niveau de chorus entre 0 et 32767.
-g, --gain gain_maitre
Gain maître entre 0 et 100, par défaut 90 (10 dB en dessous du maximum).
-V, --Verbosity verbeux
Niveau de verbosité entre 0 et 5, où 0=aucun, 1..5=niveaux de gravité.

Arguments

fichier_midi
Nom du fichier MID d'entrée.

EXEMPLES

Les exemples suivants supposent l'option par défaut USE_44KHZ=ON, ce qui signifie un taux d'échantillonnage de sortie = 44100 Hz.

Exemple 1 : Rendre un fichier MIDI et enregistrer l'audio rendu sous forme de fichier audio brut :

$ sonivoxrender ants.mid > ants.pcm

Exemple 2 : rediriger l'audio rendu via l'utilitaire ALSA aplay de Linux :

$ sonivoxrender ants.mid | aplay -c 2 -f S16_LE -r 44100

est équivalent à :

$ sonivoxrender ants.mid | aplay -f cd

Exemple 3 : rediriger l'audio rendu via l'utilitaire lame pour créer un fichier MP3 :

$ sonivoxrender ants.mid | lame -r -s 44100 - ants.mp3

Exemple 4 : rediriger l'audio rendu via l'utilitaire sox pour créer un fichier WAV :

$ sonivoxrender ants.mid | sox -t s16 -c 2 -r 44100 - ants.wav

Exemple 5 : rediriger l'audio rendu via l'utilitaire pacat de PulseAudio :

$ sonivoxrender ants.mid | pacat
