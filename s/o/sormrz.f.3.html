SORMRZ

Documentation de fonction/sous-programme

sous-routine sormrz (caractere side, caractere trans, entier m, entier n, entier k, entier l, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) tau, reel, dimension( ldc, * ) c, entier ldc, reel, dimension( * ) work, entier lwork, entier info)

SORMRZ

Objectif:

!>
!> SORMRZ écrase la matrice réelle M par N, C, avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> où Q est une matrice orthogonale réelle définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tels que retournés par STZRZF. Q est d'ordre M si SIDE = 'L' et d'ordre N
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T depuis la Gauche ;
!>          = 'R': appliquer Q ou Q**T depuis la Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'T':  Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

L

!>          L est INTEGER
!>          Le nombre de colonnes de la matrice A contenant
!>          la partie significative des réflecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

A

!>          A est tableau REAL, dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          STZRZF dans les k dernières lignes de son argument de tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est tableau REAL, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par STZRZF.
!>

C

!>          C est tableau REAL, dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau REAL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la taille optimale LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
