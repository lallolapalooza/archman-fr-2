SOFTHSM2-DUMP-FILE(1) Manuel des commandes générales SOFTHSM2-DUMP-FILE(1)

NOM

softhsm2-dump-file - Vidage du fichier d'objets SoftHSM

SYNTAXE

softhsm2-dump-file chemin

DESCRIPTION

softhsm2-dump-file est un outil qui permet de vider un fichier d'objets SoftHSM v2 à des fins de débogage.

OPTIONS

chemin
Le fichier d'objets SoftHSM v2 qui doit être vidé.
--help, -h
Afficher les informations d'aide.
