Documentation de fonction/sous-routine

sous-routine sorcsd2by1 (character jobu1, character jobu2, character jobv1t, integer m, integer p, integer q, real, dimension(ldx11,*) x11, integer ldx11, real, dimension(ldx21,*) x21, integer ldx21, real, dimension(*) theta, real, dimension(ldu1,*) u1, integer ldu1, real, dimension(ldu2,*) u2, integer ldu2, real, dimension(ldv1t,*) v1t, integer ldv1t, real, dimension(*) work, integer lwork, integer, dimension(*) iwork, integer info)

SORCSD2BY1

Objectif :

!>
!> SORCSD2BY1 calcule la décomposition CS d'une matrice M par Q, X, avec
!> des colonnes orthogonales, qui a été partitionnée en une structure de 2 blocs par 1 :
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 est P par Q. Les matrices orthogonales U1, U2 et V1 sont respectivement
!> P par P, (M-P) par (M-P), et Q par Q. C et S sont des matrices diagonales
!> non négatives R par R satisfaisant C^2 + S^2 = I, où
!> R = MIN(P,M-P,Q,M-Q). I1 est une matrice identité K1 par K1 et I2 est une
!> matrice identité K2 par K2, où K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>

Paramètres

JOBU1 
!>          JOBU1 est CHARACTER
!>          = 'Y':      U1 est calculé ;
!>          sinon :     U1 n'est pas calculé.
!>

JOBU2

!>          JOBU2 est CHARACTER
!>          = 'Y':      U2 est calculé ;
!>          sinon :     U2 n'est pas calculé.
!>

JOBV1T

!>          JOBV1T est CHARACTER
!>          = 'Y':      V1T est calculé ;
!>          sinon :     V1T n'est pas calculé.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes dans X.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes dans X11. 0 <= P <= M.
!>

Q

!>          Q est INTEGER
!>          Le nombre de colonnes dans X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau REAL, dimension (LDX11,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est désirée.
!>

LDX11

!>          LDX11 est INTEGER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 est un tableau REAL, dimension (LDX21,Q)
!>          À l'entrée, partie de la matrice orthogonale dont la CSD est désirée.
!>

LDX21

!>          LDX21 est INTEGER
!>           La dimension principale de X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA est un tableau REAL, dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est un tableau REAL, dimension (P)
!>          Si JOBU1 = 'Y', U1 contient la matrice orthogonale P par P, U1.
!>

LDU1

!>          LDU1 est INTEGER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est un tableau REAL, dimension (M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice orthogonale (M-P) par (M-P), U2.
!>

LDU2

!>          LDU2 est INTEGER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est un tableau REAL, dimension (Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice orthogonale Q par Q, V1**T.
!>

LDV1T

!>          LDV1T est INTEGER
!>          La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille LWORK optimale.
!>          Si INFO > 0 à la sortie, WORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, avec THETA(1), ..., THETA(R),
!>          définissent la matrice sous forme bidiagonale par blocs
!>          intermédiaire restante après non-convergence. INFO spécifie le nombre
!>          de PHI non nuls.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  SBBCSD n'a pas convergé. Voir la description de WORK
!>                ci-dessus pour les détails.
!>

Références :

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
