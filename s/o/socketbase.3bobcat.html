FBB::SocketBase(3bobcat) Classe de base pour les sockets FBB::SocketBase(3bobcat)

NOM

FBB::SocketBase - Classe de base pour les classes construisant des sockets

SYNTAXE

#include <bobcat/socketbase>
Option de liaison : -lbobcat

DESCRIPTION

Cette classe est une classe de base pour les classes FBB::ServerSocket et FBB::ClientSocket. Comme elle est conçue comme une classe de base, tous ses constructeurs sont protégés.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

FBB::InetAddress

CONSTRUCTEURS PROTEGES

o
SocketBase(size_t port):
Ce constructeur crée une SocketBase à utiliser avec des objets ServerSocket, en écoute sur le port port.
o
SocketBase(std::string const &host, uint16_t port):
Ce constructeur crée une FBB::SocketBase à utiliser avec un objet ClientSocket, se connectant à l'hôte host, au port `port’.

Ces constructeurs lèvent une std::exception s'ils ne peuvent pas s'achever correctement.

Le constructeur de copie et l'opérateur d'affectation par copie sont disponibles. Les deux offrent des droits d'accès protégés.

MEMBRE PROTEGE

o
SocketBase makeBase(int socket, sockaddr_in const &address):
Ce membre retourne un objet FBB::SocketBase initialisant son socket et son FBB::InetAddress à partir des arguments fournis.

FONCTIONS MEMBRES

Tous les membres de FBB::InetAddress sont disponibles, car FBB::SocketBase hérite de cette classe.

o
bool debug() const:
Cet accesseur retourne true si l'option de socket debug (SO_DEBUG) du socket est active. Il lève une exception FBB::Exception si le statut de l'option debug ne peut être déterminé ;
o
bool reuse() const:
Cet accesseur retourne true si l'option de socket reuse (SO_REUSEADDR) du socket est active. Il lève une exception FBB::Exception si le statut de l'option reuse ne peut être déterminé ;
o
void setDebug(bool trueIsOn) const:
Ce membre peut être utilisé pour modifier l'option de socket debug (SO_DEBUG) du socket. Il lève une exception FBB::Exception si l'option debug du socket ne peut être modifiée ;
o
void setReuse(bool trueIsOn) const:
Ce membre peut être utilisé pour modifier l'option de socket reuse (SO_REUSEADDR) du socket. Il lève une exception FBB::Exception si l'option reuse du socket ne peut être modifiée ;
o
int socket() const:
Cet accesseur retourne la valeur du socket de FBB::SocketBase.

EXEMPLE

Les classes FBB::ClientSocket et FBB::ServerSocket sont dérivées de SocketBase. Par exemple :

#ifndef INCLUDED_BOBCAT_CLIENTSOCKET_
#define INCLUDED_BOBCAT_CLIENT SOCKET_
#include <string>
#include <bobcat/socketbase>
#include <bobcat/exception>
namespace FBB
{
class ClientSocket: public SocketBase
{
    public:
                                // host peut être une adresse ou un nom
        ClientSocket(std::string const &host, uint16_t port);
        int connect();          // retourne le descripteur de fichier (socket) pour parler au serveur
};
} // FBB
#endif

Voir la page de manuel clientsocket(3bobcat) pour un exemple montrant comment utiliser FBB::ClientSocket.
