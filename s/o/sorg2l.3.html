Documentation de la fonction/sous-programme

sous-programme sorg2l (entier m, entier n, entier k, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) tau, réel, dimension( * ) work, entier info)

SORG2L génère tout ou partie de la matrice orthogonale Q à partir d'une factorisation QL déterminée par sgeqlf (algorithme non bloqué).

Objectif :

!>
!> SORG2L génère une matrice réelle m par n, Q, dont les colonnes sont orthonormales,
!> qui est définie comme les n dernières colonnes d'un produit de k réflecteurs élémentaires
!> d'ordre m
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tels que retournés par SGEQLF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          À l'entrée, la colonne (n-k+i) doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que
!>          retourné par SGEQLF dans les k dernières colonnes de son argument
!>          de tableau A.
!>          À la sortie, la matrice m par n, Q.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau REEL, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par SGEQLF.
!>

WORK

!>          WORK est un tableau REEL, de dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
