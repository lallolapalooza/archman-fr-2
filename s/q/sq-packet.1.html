sq-packet(1)

Paquet: sequoia-sq

Licences: LGPL-2.0-or-later

SQ(1) Commandes utilisateur SQ(1)

NOM

sq-packet - Manipulation de paquets de bas niveau

SYNTAXE

sq packet armor [OPTIONS] FICHIER
sq packet dearmor [OPTIONS] FICHIER
sq packet dump [OPTIONS] FICHIER
sq packet decrypt [OPTIONS] FICHIER
sq packet split [OPTIONS] FICHIER
sq packet join [OPTIONS] FICHIER

DESCRIPTION

Manipulation de paquets de bas niveau.

Un flux de données OpenPGP est composé de paquets. Ces outils permettent de travailler avec des flux de paquets. Ils intéressent principalement les développeurs, mais `sq packet dump` peut être utile à un public plus large, à la fois pour fournir des informations précieuses dans les rapports de bogues aux logiciels liés à OpenPGP, et comme outil d'apprentissage.

SOUS-COMMANDES

sq packet armor

Convertir du binaire en ASCII.

Pour faciliter la manipulation et le transport des données chiffrées, les données OpenPGP peuvent être transformées en une représentation ASCII appelée ASCII Armor. `sq` émet des données blindées par défaut, mais cette sous-commande peut être utilisée pour convertir des données OpenPGP existantes en leur représentation encodée en ASCII.

L'opération inverse est `sq packet dearmor`.

sq packet dearmor

Convertir de l'ASCII en binaire.

Pour faciliter la manipulation et le transport des données chiffrées, les données OpenPGP peuvent être transformées en une représentation ASCII appelée ASCII Armor. `sq` gère de manière transparente les données blindées, mais cette sous-commande peut être utilisée pour convertir explicitement des données OpenPGP existantes encodées en ASCII en leur représentation binaire.

L'opération inverse est `sq packet armor`.

sq packet dump

Lister les paquets.

Crée une description lisible par l'homme de la séquence de paquets. De plus, il peut afficher des artefacts cryptographiques et afficher le flux d'octets brut, similaire à hexdump(1), en annotant spécifiquement quels octets sont analysés en valeurs OpenPGP.

Si le flux de paquets inclut un conteneur de chiffrement, `sq` tentera de le déchiffrer.

sq packet decrypt

Déballer un conteneur de chiffrement.

Déchiffre un message, en affichant le contenu du conteneur de chiffrement sans traitement supplémentaire. Le résultat est un message OpenPGP valide qui peut, entre autres, être inspecté à l'aide de `sq packet dump`.

sq packet split

Diviser un message en paquets.

Diviser une séquence de paquets en paquets individuels, puis les recombiner librement avec `sq packet join` est un excellent moyen d'expérimenter avec les données OpenPGP.

Par défaut, les paquets sont écrits sur la sortie standard sous forme de blocs ASCII blindés. Il est possible de modifier ce fichier directement (par exemple, déplacer, ajouter ou supprimer des paquets), puis d'utiliser `sq packet join` pour assembler le flux.

Alternativement, si un `--output-prefix` est donné, les paquets sont écrits dans des fichiers individuels commençant par ce préfixe, et peuvent être réassemblés avec `sq packet join`.

L'opération inverse est `sq packet join`.

sq packet join

Joindre des paquets séparés dans des fichiers.

Diviser une séquence de paquets en paquets individuels, puis les recombiner librement avec `sq packet join` est un excellent moyen d'expérimenter avec les données OpenPGP.

L'opération inverse est `sq packet split`.

EXEMPLES

sq packet armor

Convertir un message OpenPGP binaire en un message OpenPGP binaire ASCII blindé.

sq packet armor message.bin

Convertir un message OpenPGP binaire en un message OpenPGP binaire ASCII blindé en choisissant explicitement l'étiquette de blindage.

sq packet armor --label=message message.bin

sq packet dearmor

Convertir un message OpenPGP binaire ASCII blindé en un message OpenPGP binaire.

sq packet dearmor --output=message.bin message.pgp

sq packet dump

Afficher les paquets d'un certificat.

sq packet dump juliet.pgp

Afficher les paquets, y compris les artefacts cryptographiques, d'un certificat.

sq packet dump --mpis juliet.pgp

Afficher les paquets, y compris une représentation hexadécimale de chaque octet d'un certificat.

sq packet dump --hex juliet.pgp

Affiche les paquets d'un message chiffré, en le déchiffrant à l'aide d'un fichier de clé secrète.

sq packet dump --recipient-file bob-secret.pgp message.pgp

sq packet decrypt

Déballer le chiffrement pour révéler le message signé.

sq packet decrypt --recipient-file bob-secret.pgp message.pgp

sq packet split

Diviser un certificat en paquets individuels affichés sur la sortie standard.

sq packet split --output=- juliet.pgp

Diviser un message signé en ligne en paquets individuels écrits dans des fichiers distincts avec le préfixe 'packet'.

sq packet split --output-prefix packet document.pgp

Puis réassembler le message, en le transformant en un message signé ancien style avec une signature préfixée.

sq packet join --output prefix-signature.pgp --label message \
packet-2-Signature-Packet packet-1-Literal-Data-Packet

sq packet join

Diviser un message signé en ligne en paquets individuels écrits dans des fichiers distincts avec le préfixe 'packet'.

sq packet split --output-prefix packet document.pgp

Puis réassembler le message, en le transformant en un message signé ancien style avec une signature préfixée.

sq packet join --output prefix-signature.pgp --label message \
packet-2-Signature-Packet packet-1-Literal-Data-Packet
