NOM

sql2csv - Documentation de sql2csv

DESCRIPTION

Exécute des commandes arbitraires contre une base de données SQL et affiche les résultats sous forme de CSV :

usage: sql2csv [-h] [-v] [-l] [-V] [--db CONNECTION_STRING] [--query QUERY]
               [-e ENCODING] [-H]
               [FICHIER]
Exécute une requête SQL sur une base de données et affiche le résultat dans un fichier CSV.
arguments positionnels :
  FICHIER               Le fichier à utiliser comme requête SQL. Si FICHIER et --query
                        sont omis, la requête est acheminée via STDIN.
arguments optionnels :
  -h, --help            affiche ce message d'aide et quitte
  --db CONNECTION_STRING
                        Une chaîne de connexion SQLAlchemy pour se connecter à une
                        base de données.
  --engine-option ENGINE_OPTION ENGINE_OPTION
                        Un argument mot-clé pour create_engine() de SQLAlchemy, sous forme de paire
                        séparée par des espaces. Cette option peut être spécifiée plusieurs fois. Par exemple :
                        thick_mode True
  --execution-option EXECUTION_OPTION EXECUTION_OPTION
                        Un argument mot-clé pour execution_options() de SQLAlchemy, sous forme de paire
                        séparée par des espaces. Cette option peut être spécifiée plusieurs fois. Par exemple :
                        stream_results True
  --query QUERY         La requête SQL à exécuter. Remplace FICHIER et STDIN.
  -e ENCODING, --encoding ENCODING
                        Spécifie l'encodage du fichier de requête d'entrée.
  -H, --no-header-row   Ne pas afficher les noms de colonnes.

EXEMPLES

Chargez des exemples de données dans une table à l'aide de csvsql, puis interrogez-la à l'aide de sql2csv :

csvsql --db "sqlite:///dummy.db" --tables "test" --insert examples/dummy.csv
sql2csv --db "sqlite:///dummy.db" --query "select * from test"

Chargez des données sur les bénéficiaires de l'aide financière dans PostgreSQL. Trouvez ensuite les trois États ayant reçu le plus, tout en filtrant les lignes vides :

createdb recipients
csvsql --db "postgresql:///recipients" --tables "fy09" --insert examples/realdata/FY09_EDU_Recipients_by_State.csv
sql2csv --db "postgresql:///recipients" --query "select * from fy09 where \"State Name\" != '' order by fy09.\"TOTAL\" limit 3"

Vous pouvez même l'utiliser comme une simple calculatrice SQL (dans cet exemple, une base de données SQLite en mémoire est utilisée par défaut) :

sql2csv --query "select 300 * 47 % 14 * 27 + 7000"

La chaîne de connexion accepte des paramètres. Par exemple, pour définir l'encodage d'une base de données MySQL :

sql2csv --db 'mysql://user:pass@host/database?charset=utf8' --query "SELECT myfield FROM mytable"
