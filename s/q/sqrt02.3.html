Documentation de la fonction/sous-routine

sous-routine sqrt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) r, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SQRT02

Objectif :

!>
!> SQRT02 teste SORGQR, qui génère une matrice Q de dimensions m x n avec
!> des colonnes orthonormées, définie comme le produit de k facteurs élémentaires.
!>
!> Étant donné la factorisation QR d'une matrice A de dimensions m x n, SQRT02 génère
!> la matrice orthogonale Q définie par la factorisation des k premières colonnes
!> de A ; elle compare R(1:n,1:k) avec Q(1:m,1:n)'*A(1:m,1:k),
!> et vérifie que les colonnes de Q sont orthonormées.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice Q à générer. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice Q à générer.
!>          M >= N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de facteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau de réels (REAL), dimension (LDA,N)
!>          La matrice A de dimensions m x n factorisée par SQRT01.
!>

AF

!>          AF est un tableau de réels (REAL), dimension (LDA,N)
!>          Détails de la factorisation QR de A, tels que retournés par SGEQRF.
!>          Voir SGEQRF pour plus de détails.
!>

Q

!>          Q est un tableau de réels (REAL), dimension (LDA,N)
!>

R

!>          R est un tableau de réels (REAL), dimension (LDA,N)
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale des tableaux A, AF, Q et R. LDA >= M.
!>

TAU

!>          TAU est un tableau de réels (REAL), dimension (N)
!>          Les facteurs scalaires des facteurs élémentaires correspondant
!>          à la factorisation QR dans AF.
!>

WORK

!>          WORK est un tableau de réels (REAL), dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau de réels (REAL), dimension (M)
!>

RESULT

!>          RESULT est un tableau de réels (REAL), dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
