NOM

squiral - économiseur d'écran à spirales carrées

SYNTAXE

squiral [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--noinstall] [--visual visuel] [--fill pourcentage] [--count numéro] [--scale numéro] [--delay usec] [--disorder fraction] [--handedness fraction] [--cycle] [--fps]

DESCRIPTION

Le programme squiral affiche des automates interactifs produisant des spirales.

OPTIONS

squiral accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, faire comme si on était sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--fill pourcentage
Spécifier le pourcentage (0-100) de l'écran qui doit être rempli avant que l'écran ne soit effacé. 60-80% sont de bonnes valeurs.
--count numéro
Le nombre de spirales. Par défaut, la largeur de l'écran divisée par 32.
--scale numéro
Épaisseur des lignes.
--delay usec
Le délai entre les étapes. La valeur par défaut est 1000.
--disorder fraction
La fraction du temps pendant laquelle une spirale choisira une nouvelle direction. La valeur par défaut est 0.005.
--handedness fraction
La fraction du temps pendant laquelle une spirale choisira d'entrer en mode gaucher. 0.0 signifie un comportement exclusivement droitier, 0.5 (la valeur par défaut) est un équilibre entre les deux, et 1.0 est un comportement exclusivement gaucher.
--fps
Afficher le taux de rafraîchissement actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

BOGUES

Aucun connu
