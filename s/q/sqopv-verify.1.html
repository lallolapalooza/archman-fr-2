sqopv-verify(1) Manuel des commandes générales sqopv-verify(1)

NOM

sqopv-verify - Vérifie les signatures détachées

SYNTAXE

sqopv verify [--debug] [--not-before] [--not-after] [-h|--help] <SIGNATURES> [CERTS]

DESCRIPTION

Vérifie les signatures détachées

OPTIONS

--debug
Émettre une sortie détaillée pour le débogage
--not-before <NOT_BEFORE>
Considérer les signatures antérieures à cette date comme invalides
--not-after <NOT_AFTER>
Considérer les signatures postérieures à cette date comme invalides
-h, --help
Afficher l'aide
<SIGNATURES>
Signatures à vérifier
[CERTS]
Certificats pour la vérification
février 2025 sqopv 0.37.3
