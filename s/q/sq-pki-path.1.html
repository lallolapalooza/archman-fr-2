SQ(1) Commandes utilisateur SQ(1)

NOM

sq-pki-path - Vérifie le chemin spécifié

SYNTAXE

sq pki path [OPTIONS] EMPREINTE|IDCLEF

DESCRIPTION

Vérifie le chemin spécifié.

Un chemin est une séquence de certificats commençant à la racine, et un Identifiant Utilisateur. Cette fonction vérifie que chaque segment du chemin a une certification valide, qui satisfait également toutes les contraintes (montant de confiance, profondeur de confiance, expressions régulières).

Si un chemin valide n'est pas trouvé, alors cette sous-commande analyse également le chemin. En particulier, elle signale si des certifications sont insuffisantes, par exemple, pas assez de profondeur de confiance, ou invalides, par exemple, parce qu'elles utilisent SHA-1, mais que l'utilisation de SHA-1 a été désactivée.

OPTIONS

Options de sous-commande

--amount=MONTANT
Le montant de confiance requis
120 indique une authentification complète ; les valeurs inférieures à 120 indiquent une authentification partielle. Lorsque `--certification-network` est passé, la valeur par défaut est 1200, c'est-à-dire que cette commande essaie de trouver 10 chemins.
--certification-network
Traite le réseau comme un réseau de certification
Normalement, le mécanisme d'authentification traite le réseau Web de Confiance comme un réseau d'authentification où une certification signifie seulement que la liaison est correcte, pas que la cible doit être traitée comme un introducteur de confiance. Dans un réseau de certification, les cibles des certifications sont traitées comme des introducteurs de confiance avec une profondeur infinie, et toutes les expressions régulières sont ignorées. Note : Le montant de confiance reste inchangé. C'est ainsi que fonctionnent la plupart des algorithmes dits de recherche de chemin PGP.
--email=EMAIL
Authentifie l'adresse e-mail spécifiée
Ceci vérifie s'il est possible d'authentifier l'identifiant utilisateur composé uniquement de l'adresse e-mail spécifiée. L'identifiant utilisateur n'a pas besoin d'être auto-signé.
--userid=USERID
Authentifie l'identifiant utilisateur spécifié
L'identifiant utilisateur spécifié n'a pas besoin d'être auto-signé.
--userid-by-email=EMAIL
Authentifie l'identifiant utilisateur auto-signé avec l'adresse e-mail spécifiée
Ceci vérifie s'il est possible d'authentifier l'identifiant utilisateur auto-signé avec l'adresse e-mail spécifiée.
Si le certificat est invalide ou s'il n'y a pas d'identifiant utilisateur auto-signé avec l'adresse e-mail spécifiée, utilise un identifiant utilisateur contenant uniquement l'adresse e-mail.

EMPREINTE|IDCLEF
Le chemin à authentifier
Un chemin est composé d'un ou plusieurs certificats. Le premier certificat est la racine, et le dernier certificat est celui qui est authentifié pour l'identifiant utilisateur spécifié.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Vérifie qu'Alice a certifié un Identifiant Utilisateur particulier pour le certificat de Bob.

sq pki path EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
511257EBBF077B7AEDAE5D093F68CB84CE537C9A --userid \
"Bob <bob@example.org>"
