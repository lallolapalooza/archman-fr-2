SQFSCAT(1) Commandes utilisateur SQFSCAT(1)

NOM

sqfscat - outil pour afficher le contenu de fichiers d'un système de fichiers squashfs vers la sortie standard

SYNOPSIS

sqfscat [OPTIONS] FILESYSTEM [liste des fichiers à afficher sur la sortie standard]

DESCRIPTION

Squashfs est un système de fichiers en lecture seule hautement compressé pour Linux. Il utilise la compression gzip/xz/lzo/lz4/zstd pour compresser à la fois les fichiers, les inodes et les répertoires. Les inodes du système sont très petits et tous les blocs sont regroupés pour minimiser la surcharge de données. Les tailles de bloc supérieures à 4 Ko sont prises en charge jusqu'à un maximum de 1 Mo (taille de bloc par défaut 128 Ko).

Squashfs est destiné à une utilisation générale en lecture seule, à l'archivage (c'est-à-dire dans les cas où un fichier .tar.gz pourrait être utilisé) et aux systèmes contraints en périphériques de bloc/mémoire (par exemple, systèmes embarqués) où une faible surcharge est nécessaire.

OPTIONS

Options d'exécution :

-v, -version
affiche la version, la licence et les informations de copyright.
-p NOMBRE, -processors NOMBRE
utilise NOMBRE processeurs. Par défaut, utilise le nombre de processeurs disponibles.
-mem TAILLE
utilise TAILLE de mémoire physique pour les caches. Utilisez K, M ou G pour spécifier des Kilo-octets, Méga-octets ou Giga-octets respectivement. Par défaut 512 Méga-octets.
-mem-percent POURCENTAGE
utilise POURCENTAGE de mémoire physique pour les caches.
-o OCTETS, -offset OCTETS
saute OCTETS au début de FILESYSTEM. Optionnellement, un suffixe K, M ou G peut être donné pour spécifier des Kilo-octets, Méga-octets ou Giga-octets respectivement (par défaut 0 octet).
-ig, -ignore-errors
traite les erreurs d'écriture de fichiers sur la sortie standard comme non fatales.
-st, -strict-errors
traite toutes les erreurs comme fatales.
-no-exit, -no-exit-code
ne définit pas le code de sortie (à une valeur non nulle) en cas d'erreurs non fatales.

Options de filtrage :

-no-wild, -no-wildcards
n'utilise pas la correspondance de caractères génériques dans les noms de fichiers.
-r, -regex
traite les noms de fichiers comme des expressions régulières POSIX plutôt que d'utiliser l'expansion de caractères génériques du shell (globbing) par défaut.

Options d'aide :

-h, -help
affiche un résumé de l'aide dans le pager (ou dans la sortie standard si ce n'est pas un terminal).
-help-option REGEX
affiche les informations d'aide pour les options correspondant à REGEX dans le pager (ou dans la sortie standard si ce n'est pas un terminal).
-help-section SECTION
affiche les informations d'aide pour la section SECTION dans le pager (ou dans la sortie standard si ce n'est pas un terminal). Si SECTION ne correspond pas exactement à un nom de section, elle est traitée comme une expression régulière, et tous les noms de sections correspondants sont affichés. Utilisez "list" comme nom de section pour obtenir une liste des sections et de leurs noms.
-help-all
affiche les informations d'aide pour toutes les options et sections de Sqfscat dans le pager (ou dans la sortie standard si ce n'est pas un terminal).
-ho REGEX
alternative abrégée à -help-option.
-hs SECTION
alternative abrégée à -help-section.
-ha
alternative abrégée à -help-all.
-no-pager
n'utilise pas de pager pour afficher les informations d'aide.
-cols LARGEUR
utilise LARGEUR colonnes pour afficher les informations d'aide. Utile si la sortie n'est pas dirigée vers un terminal.

STATUT DE SORTIE

0
Le ou les fichiers ont été affichés sur la sortie standard avec succès.
1
Des erreurs FATALES se sont produites, par exemple corruption du système de fichiers, erreurs d'E/S. Sqfscat n'a pas continué et s'est arrêté.
2
Des erreurs NON FATALES se sont produites, par exemple fichier non régulier, ou échec de résolution du chemin. Sqfscat a continué et ne s'est pas arrêté.

Voir les options -ignore-errors, -strict-errors et -no-exit-code pour voir comment elles affectent le statut de sortie.

DÉCOMPRESSEURS DISPONIBLES

gzip, lzo, lz4, xz, zstd, lzma

ENVIRONNEMENT

SQFS_CMDLINE
S'il est défini, ceci est utilisé comme répertoire pour écrire le fichier sqfs_cmdline qui contient les arguments de la ligne de commande donnés à Sqfscat. Chaque argument de ligne de commande est entouré de guillemets pour garantir qu'il n'y ait aucune ambiguïté lorsque les arguments contiennent des espaces. Si le fichier existe déjà, alors la ligne de commande est ajoutée au fichier.
PAGER
S'il est défini, ceci est utilisé comme nom du programme utilisé pour afficher le texte d'aide. La valeur peut être une commande simple ou un chemin d'accès. La valeur par défaut est /usr/bin/pager.

EXEMPLES

sqfscat IMAGE.SQFS hello
Affiche le contenu de "hello" sur la sortie standard.
sqfscat IMAGE.SQFS hello world
Affiche le contenu de "hello" puis de "world" sur la sortie standard.
sqfscat IMAGE.SQFS "*.[ch]"
Affiche le contenu de tous les fichiers du répertoire racine qui correspondent au caractère générique *.[ch], sur la sortie standard, par exemple hello.c, hello.h, world.c, world.h.

Remarque : lors du passage de noms avec caractères génériques à Sqfscat, ceux-ci doivent être mis entre guillemets (comme dans les exemples ci-dessus), pour garantir qu'ils ne soient pas traités par le shell.
