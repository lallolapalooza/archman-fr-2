sqopv(1) Manuel des commandes générales sqopv(1)

NOM

sqopv - Une implémentation du sous-ensemble de vérification seule de l'interface en ligne de commande Stateless OpenPGP utilisant sqopv 0.37.3

SYNTAXE

sqopv [--debug] [-h|--help] <sous-commandes>

DESCRIPTION

Une implémentation du sous-ensemble de vérification seule de l'interface en ligne de commande Stateless OpenPGP utilisant sqopv 0.37.3

OPTIONS

--debug
Émet une sortie détaillée pour le débogage
-h, --help
Affiche l'aide

SOUS-COMMANDES

sqopv-version(1)
Affiche les informations de version
sqopv-verify(1)
Vérifie les signatures détachées
sqopv-inline-verify(1)
Vérifie les messages signés en ligne

VERSION

v0.37.3

AUTEURS

Sequoia PGP

février 2025 sqopv 0.37.3
