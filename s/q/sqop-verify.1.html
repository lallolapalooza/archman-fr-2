sqop-verify(1) Manuel des commandes générales sqop-verify(1)

NOM

sqop-verify - Vérifie les signatures détachées

SYNTAXE

sqop verify [--debug] [--not-before] [--not-after] [-h|--help] <SIGNATURES> [CERTS]

DESCRIPTION

Vérifie les signatures détachées

OPTIONS

--debug
Émettre une sortie verbeuse pour le débogage
--not-before <PAS_AVANT>
Considérer les signatures antérieures à cette date comme invalides
--not-after <PAS_APRES>
Considérer les signatures postérieures à cette date comme invalides
-h, --help
Afficher l'aide
<SIGNATURES>
Signatures à vérifier
[CERTS]
Certificats pour la vérification
