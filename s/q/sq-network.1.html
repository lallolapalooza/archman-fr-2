SQ(1) Commandes utilisateur SQ(1)

NOM

sq-network - Récupérer et publier des certificats sur le réseau

SYNTAXE

sq network search [OPTIONS] REQUÊTE
sq network keyserver [OPTIONS] SOUS-COMMANDE
sq network wkd [OPTIONS] SOUS-COMMANDE
sq network dane [OPTIONS] SOUS-COMMANDE

DESCRIPTION

Récupérer et publier des certificats sur le réseau.

Les certificats OpenPGP peuvent être découverts et mis à jour depuis, et publiés sur des services accessibles sur le réseau. Ceci est une collection de commandes pour interagir avec ces services.

SOUS-COMMANDES

sq network search

Récupérer des certificats en utilisant tous les services réseau supportés.

Cette commande tentera de localiser les certificats pertinents étant donnée une requête, qui peut être une empreinte, un ID de clé, une adresse e-mail ou une URL https. Elle peut également découvrir et importer des certificats associés à celui qui a été interrogé, tels que des certificats alternatifs, des certificats expirés ou des certificats révoqués.

La découverte de certificats associés est utile : les certificats alternatifs supportent les rotations de clés, les certificats expirés permettent la vérification des signatures faites dans le passé, et la découverte de certificats révoqués est importante pour obtenir les informations de révocation. Le mécanisme PKI aidera à sélectionner le bon certificat, voir `sq pki`.

Par défaut, tous les certificats retournés sont stockés dans le dépôt de certificats local. Ceci peut être outrepassé en utilisant l'option `--output`.

Lorsqu'un certificat est récupéré depuis un serveur de clés vérifiant (actuellement, ceci est limité à une liste de serveurs connus : `hkps://keys.openpgp.org`, `hkps://keys.mailvelope.com`, et `hkps://mail-api.proton.me`), WKD, DANE, ou via https, et importé dans le dépôt de certificats local, les User IDs sont également certifiés avec une clé locale spécifique au serveur. Cette clé proxy est à son tour certifiée comme une CA d'une confiance minimale (montant de confiance : 1 sur 120) par la racine de confiance locale. Le niveau de confiance d'une CA de serveur de clés proxy peut être ajusté en utilisant `sq pki link add` ou `sq pki link retract` de la manière habituelle.

sq network keyserver

Récupérer et publier des certificats via des serveurs de clés.

Le protocole OpenPGP HTTP Keyserver Protocol (HKP) est une méthode pour publier et récupérer des certificats depuis des serveurs de clés.

sq network wkd

Récupérer et publier des certificats via des répertoires de clés web.

Le répertoire de clés web (WKD) est une méthode pour publier et récupérer des certificats depuis des serveurs web.

sq network dane

Récupérer et publier des certificats via DANE.

L'authentification des entités nommées basée sur DNS (DANE) est une méthode pour publier et récupérer des certificats dans le DNS tel que spécifié dans la RFC 7929.

EXEMPLES

Rechercher le certificat de signature maître de Qubes.

sq network search 427F11FD0FAA4B080123F01CDDFA1A3E36879494

Rechercher des certificats associés à une adresse e-mail.

sq network search alice@example.org
