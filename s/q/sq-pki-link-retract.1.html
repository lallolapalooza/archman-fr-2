SQ(1) Commandes utilisateur SQ(1)

NOM

sq-pki-link-retract - Rétracter des liens

SYNTAXE

sq pki link retract [OPTIONS]

DESCRIPTION

Rétracte des liens.

Cette commande rétracte les liens qui ont été créés précédemment à l'aide de `sq pki link add` ou `sq pki link authorize`. Voir la documentation de cette sous-commande pour plus de détails. Remarque : ceci est appelé `retract` et non `remove`, car les certifications ne sont pas supprimées. Au lieu de cela, une nouvelle certification est ajoutée, indiquant que la liaison n'a pas été authentifiée.

`sq pki link retract` respecte l'heure de référence définie par l'argument de niveau supérieur `--time`. Cela provoque la rétractation d'un lien à partir d'une heure particulière au lieu de l'heure actuelle.

OPTIONS

Options de sous-commande

--all
Utiliser tous les identifiants utilisateur auto-signés
--cert=EMPREINTE|IDCLEF
Utiliser les certificats avec l'empreinte ou l'ID de clé spécifié
--cert-special=SPÉCIAL
Utiliser les certificats identifiés par le nom spécial
[valeurs possibles : public-directories, keys.openpgp.org, keys.mailvelope.com, proton.me, wkd, dane, autocrypt, web]
--email=EMAIL
Utiliser un identifiant utilisateur avec l'adresse e-mail spécifiée
L'identifiant utilisateur se compose uniquement de l'adresse e-mail. L'adresse e-mail n'a pas besoin d'apparaître dans un identifiant utilisateur auto-signé.
--recreate
Recréer la signature même si les paramètres n'ont pas changé
Si les paramètres du lien n'ont pas changé, et donc que la création d'une signature ne devrait pas être nécessaire, nous omettons l'opération. Ce drapeau peut être donné pour forcer la recréation de la signature de toute façon.
--signature-notation NOM VALEUR
Ajouter une notation à la signature
Le nom d'une notation définie par l'utilisateur doit être de la forme `name@a.domain.you.control.org`. Si le nom de la notation commence par `!`, alors la notation est marquée comme critique. Si un consommateur d'une signature ne comprend pas une notation critique, alors il ignorera la signature. La notation est marquée comme lisible par l'homme.
--userid=USERID
Utiliser l'identifiant utilisateur spécifié
L'identifiant utilisateur spécifié n'a pas besoin d'être auto-signé.
Étant donné que l'utilisation d'un identifiant utilisateur qui n'est pas auto-signé est souvent une erreur, vous devez utiliser cette option pour y consentir explicitement.
--userid-by-email=EMAIL
Utiliser l'identifiant utilisateur auto-signé avec l'adresse e-mail spécifiée

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Lier le certificat EB28F26E2739A4870ECC47726F0073F60FD0CBF0 avec l'adresse e-mail alice@example.org.

sq pki link add \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--add-email=alice@example.org

Rétracter l'acceptation du certificat EB28F26E2739A4870ECC47726F0073F60FD0CBF0 et de l'adresse e-mail alice@example.org.

sq pki link retract \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--email=alice@example.org

Rétracter l'acceptation du certificat EB28F26E2739A4870ECC47726F0073F60FD0CBF0 et de tous les identifiants utilisateur associés. Ceci invalidera effectivement tous les liens.

sq pki link retract \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 --all
