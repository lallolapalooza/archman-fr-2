SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key-approvals-list - Liste les certifications tierces et leur statut d'approbation

SYNOPSIS

sq key approvals list [OPTIONS]

DESCRIPTION

Liste les certifications tierces et leur statut d'approbation.

Pour empêcher les attaques par déferlement de certificats, les serveurs de clés modernes empêchent la distribution non contrôlée de certifications tierces sur les certificats. Pour permettre au détenteur de clé de contrôler quelles informations sont distribuées avec son certificat, ces serveurs de clés ne distribuent que les certifications tierces que le détenteur de clé a explicitement approuvées.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Liste les approbations sur le certificat avec l'empreinte ou l'ID de clé spécifié(e)
--cert-email=EMAIL
Liste les approbations sur le certificat où un ID utilisateur inclut l'adresse e-mail spécifiée
--cert-file=CHEMIN
Liste les approbations sur le certificat lu à partir du CHEMIN
--cert-userid=IDUTILISATEUR
Liste les approbations sur le certificat avec l'ID utilisateur spécifié
--email=EMAIL
Utilise l'ID utilisateur auto-signé avec l'adresse e-mail spécifiée
--pending
Liste les certifications non approuvées
--userid=IDUTILISATEUR
Utilise l'ID utilisateur auto-signé spécifié
L'ID utilisateur spécifié doit être auto-signé.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Liste les certifications approuvées sur tous les ID utilisateur.

sq key approvals list \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Liste les certifications non approuvées sur tous les ID utilisateur.

sq key approvals list --pending \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Liste toutes les certifications non approuvées sur un ID utilisateur donné.

sq key approvals list --pending --email=alice@example.org \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

VOIR AUSSI

sq(1), sq-key(1), sq-key-approvals(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
