sqop-decrypt(1) Manuel des commandes générales sqop-decrypt(1)

NOM

sqop-decrypt - Décrypte un message

SYNTAXE

sqop decrypt [--debug] [--session-key-out] [--with-session-key] [--with-password] [--verifications-out] [--verify-with] [--verify-not-before] [--verify-not-after] [--with-key-password] [-h|--help] [CLÉS]

DESCRIPTION

Décrypte un message

OPTIONS

--debug
Émettre une sortie verbeuse pour le débogage
--session-key-out <SESSION_KEY_OUT>
Écrire la clé de session ici
--with-session-key <WITH_SESSION_KEY>
Essayer de décrypter avec cette clé de session
--with-password <WITH_PASSWORD>
Essayer de décrypter avec ce mot de passe
--verifications-out <VERIFICATIONS_OUT>
Écrire le résultat de la vérification ici
--verify-with <VERIFY_WITH>
Certificats pour la vérification
--verify-not-before <VERIFY_NOT_BEFORE>
Considérer les signatures antérieures à cette date comme invalides
--verify-not-after <VERIFY_NOT_AFTER>
Considérer les signatures postérieures à cette date comme invalides
--with-key-password <WITH_KEY_PASSWORD>
Essayer de décrypter les CLÉS de chiffrement avec ces mots de passe
-h, --help
Afficher l'aide
[CLÉS]
Essayer de décrypter avec ces clés
février 2025 sqop 0.37.3
