NOM

sq-packet-decrypt - Déballer un conteneur de chiffrement

SYNTAXE

sq packet decrypt [OPTIONS] FICHIER

DESCRIPTION

Déballe un conteneur de chiffrement.

Déchiffre un message, en exportant le contenu du conteneur de chiffrement sans traitement supplémentaire. Le résultat est un message OpenPGP valide qui peut, entre autres, être inspecté avec `sq packet dump`.

OPTIONS

Options de sous-commande

--binary
Émet des données binaires
--dump-session-key
Affiche la clé de session sur stderr
--output=FICHIER
Écrit dans FICHIER ou stdout si omis
[par défaut : -]
--recipient-file=FICHIER_CLE
Déchiffre le message en utilisant la clé dans FICHIER_CLE
--session-key=CLE-SESSION
Déchiffre un message chiffré en utilisant CLE-SESSION

FICHIER
Lit depuis FICHIER ou stdin si FICHIER est '-'
[par défaut : -]

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Déballe le chiffrement pour révéler le message signé.

sq packet decrypt --recipient-file bob-secret.pgp message.pgp

VOIR AUSSI

sq(1), sq-packet(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
