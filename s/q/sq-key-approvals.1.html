SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key-approvals - Gère les approbations de certification

SYNTAXE

sq key approvals list [OPTIONS]
sq key approvals update [OPTIONS]

DESCRIPTION

Gère les approbations de certification.

Les détenteurs de clés peuvent approuver les certifications tierces associées à leur certificat. Cette sous-commande gère les approbations.

Pour prévenir les attaques par déni de service par saturation de certificats, les serveurs de clés modernes empêchent la distribution non contrôlée de certifications tierces sur les certificats. Pour permettre au détenteur de la clé de contrôler quelles informations sont distribuées avec son certificat, ces serveurs de clés ne distribuent que les certifications tierces que le détenteur de la clé a explicitement approuvées.

SOUS-COMMANDES

sq key approvals list

Liste les certifications tierces et leur statut d'approbation.

Pour prévenir les attaques par déni de service par saturation de certificats, les serveurs de clés modernes empêchent la distribution non contrôlée de certifications tierces sur les certificats. Pour permettre au détenteur de la clé de contrôler quelles informations sont distribuées avec son certificat, ces serveurs de clés ne distribuent que les certifications tierces que le détenteur de la clé a explicitement approuvées.

sq key approvals update

Approuve les certifications tierces, permettant leur distribution.

Pour prévenir les attaques par déni de service par saturation de certificats, les serveurs de clés modernes empêchent la distribution non contrôlée de certifications tierces sur les certificats. Pour permettre au détenteur de la clé de contrôler quelles informations sont distribuées avec son certificat, ces serveurs de clés ne distribuent que les certifications tierces que le détenteur de la clé a explicitement approuvées.

Par défaut, tous les identifiants utilisateur sont pris en compte, mais si au moins un argument `--name`, `--email` ou `--userid` est donné, seuls les identifiants utilisateur correspondants sont pris en compte.

Après que les approbations aient été modifiées, le certificat doit être distribué, par exemple en le téléchargeant sur un serveur de clés.

EXEMPLES

sq key approvals list

Liste les certifications approuvées sur tous les identifiants utilisateur.

sq key approvals list \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Liste les certifications non approuvées sur tous les identifiants utilisateur.

sq key approvals list --pending \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Liste toutes les certifications non approuvées sur un identifiant utilisateur donné.

sq key approvals list --pending --email=alice@example.org \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key approvals update

Approuve toutes les certifications sur tous les identifiants utilisateur d'Alice.

sq key approvals update --add-all \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Approuve toutes les certifications sur tous les identifiants utilisateur d'Alice faites par Bob, en supprimant d'abord toutes les approbations précédentes.

sq key approvals update --remove-all \
--add-by=511257EBBF077B7AEDAE5D093F68CB84CE537C9A \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Approuve toutes les certifications sur un identifiant utilisateur spécifique par des certificateurs authentifiables, en supprimant d'abord toutes les approbations précédentes.

sq key approvals update --remove-all --add-authenticated \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--userid="Alice <alice@example.org>"

Supprime l'approbation de la certification de Bob sur tous les identifiants utilisateur d'Alice.

sq key approvals update \
--remove-by=511257EBBF077B7AEDAE5D093F68CB84CE537C9A \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0
