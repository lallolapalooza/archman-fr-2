NOM

sqop-change-key-password - Met à jour le mot de passe d'une clé

SYNTAXE

sqop change-key-password [--debug] [--no-armor] [--new-key-password] [--old-key-password] [-h|--help]

DESCRIPTION

Met à jour le mot de passe d'une clé.

La sortie sera le même ensemble de Clés Secrètes Transférables OpenPGP que l'entrée, mais avec tout le matériel de clé secrète verrouillé selon le mot de passe indiqué par l'option `--new-key-password` (ou, sans mot de passe du tout, si `--new-key-password` est absent). Notez que `--old-key-password` peut être fourni plusieurs fois, et chaque mot de passe fourni sera essayé comme moyen de déverrouiller tout matériel de clé verrouillé rencontré. Il normalisera une Clé Secrète Transférable pour utiliser un seul mot de passe, même si elle avait initialement des mots de passe distincts verrouillant chacune des sous-clés.

Si un paquet de clé secrète est verrouillé mais ne peut pas être déverrouillé avec l'un des arguments `--old-key-password` fournis, cette sous-commande doit échouer avec `KEY_IS_PROTECTED`.

OPTIONS

--debug
Émettre une sortie détaillée pour le débogage
--no-armor
Ne pas utiliser l'encapsulation ASCII pour la sortie
--new-key-password <NouveauMotDePasseClé>
Le nouveau mot de passe pour verrouiller la clé, ou simplement déverrouiller la clé si l'option est absente
--old-key-password <AncienMotDePasseClé>
Déverrouiller les clés avec ces mots de passe
-h, --help
Afficher l'aide (voir un résumé avec '-h')
