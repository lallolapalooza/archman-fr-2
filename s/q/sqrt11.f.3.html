Documentation de la fonction/du sous-programme

real function sqrt11 (integer m, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork)

SQRT11

Objectif :

!>
!> SQRT11 calcule le rapport de test
!>
!>       || Q'*Q - I || / (eps * m)
!>
!> où la matrice orthogonale Q est représentée comme un produit de
!> transformations élémentaires. Chaque transformation a la forme
!>
!>    H(k) = I - tau(k) v(k) v(k)'
!>
!> où tau(k) est stocké dans TAU(k) et v(k) est un m-vecteur de la forme
!> [ 0 ... 0 1 x(k) ]', où x(k) est un vecteur de longueur m-k stocké
!> dans A(k+1:m,k).
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de colonnes de A dont les entrées sous-diagonales
!>          contiennent des informations sur les transformations orthogonales.
!>

A

!>          A est un tableau REEL (REAL), dimension (LDA,K)
!>          La sortie (éventuellement partielle) d'une routine de réduction QR.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.
!>

TAU

!>          TAU est un tableau REEL (REAL), dimension (K)
!>          Les facteurs d'échelle tau pour les transformations élémentaires calculés
!>          par la routine de factorisation QR.
!>

WORK

!>          WORK est un tableau REEL (REAL), dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La longueur du tableau WORK.  LWORK >= M*M + M.
!>
