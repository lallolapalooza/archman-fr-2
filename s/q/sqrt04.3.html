Documentation de la fonction/sous-programme

sous-programme sqrt04 (entier m, entier n, entier nb, réel, dimension(6) result)

SQRT04

Objectif :

!>
!> SQRT04 teste SGEQRT et SGEMQRT.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Nombre de lignes dans la matrice de test.
!>

N

!>          N est un ENTIER
!>          Nombre de colonnes dans la matrice de test.
!>

NB

!>          NB est un ENTIER
!>          Taille du bloc de la matrice de test.  NB <= Min(M,N).
!>

RESULTAT

!>          RESULTAT est un tableau RÉEL, dimension (6)
!>          Résultats de chacun des six tests ci-dessous.
!>
!>          RESULTAT(1) = | A - Q R |
!>          RESULTAT(2) = | I - Q^H Q |
!>          RESULTAT(3) = | Q C - Q C |
!>          RESULTAT(4) = | Q^H C - Q^H C |
!>          RESULTAT(5) = | C Q - C Q |
!>          RESULTAT(6) = | C Q^H - C Q^H |
!>
