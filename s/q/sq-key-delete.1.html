NOM

sq-key-delete - Supprimer le matériel de clé secrète d'un certificat

SYNOPIS

sq key delete [OPTIONS]

DESCRIPTION

Supprime le matériel de clé secrète d'un certificat.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Supprime le matériel de clé secrète de la clé avec l'empreinte ou l'ID de clé spécifié(e)
--cert-email=EMAIL
Supprime le matériel de clé secrète de la clé où un ID utilisateur inclut l'adresse e-mail spécifiée
--cert-file=CHEMIN
Supprime le matériel de clé secrète de la clé lue depuis CHEMIN
--cert-userid=IDUTILISATEUR
Supprime le matériel de clé secrète de la clé avec l'ID utilisateur spécifié
--output=FICHIER
Écrit le certificat dépouillé dans le fichier spécifié

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Supprimer toute clé secrète associée au certificat d'Alice.

sq key delete --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Supprimer toute clé secrète associée au certificat d'Alice sélectionnée par ID utilisateur.

sq key delete --cert-email=alice@example.org

VOIR AUSSI

sq(1), sq-key(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
