NOM

sqop-generate-key - Génère une clé secrète

SYNTAXE

sqop generate-key [--debug] [--no-armor] [--profile] [--signing-only] [--with-key-password] [-h|--help] [USERIDS]

DESCRIPTION

Génère une clé secrète

OPTIONS

--debug
Émet une sortie verbeuse pour le débogage
--no-armor
Ne pas appliquer le codage ASCII-Armor à la sortie
--profile <PROFIL>
Sélectionne le profil à utiliser pour la génération de clé
--signing-only
Crée une clé uniquement pour la signature
--with-key-password <MOTDEPASSECLE>
Protège la clé nouvellement générée avec le mot de passe donné
-h, --help
Affiche l'aide
[USERIDS]
UserIDs pour la clé générée
