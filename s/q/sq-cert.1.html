NOM

sq-cert - Gérer les certificats

SYNOPSIS

sq cert import [OPTIONS] FICHIER
sq cert export [OPTIONS]
sq cert list [OPTIONS] EMPREINTE|IDCLEF|MOTIF
sq cert lint [OPTIONS]

DESCRIPTION

Gérer les certificats.

Nous utilisons le terme « certificat » (ou « cert » en abrégé) pour désigner les clés OpenPGP qui ne contiennent pas de secrets. Cette sous-commande fournit des primitives pour générer et manipuler des certificats.

Inversement, nous utilisons le terme « clé » pour désigner les clés OpenPGP qui contiennent des secrets. Voir `sq key` pour les opérations sur les clés.

SOUS-COMMANDES

sq cert import

Importer des certificats dans le magasin de certificats local.

sq cert export

Exporter des certificats depuis le magasin de certificats local.

Si plusieurs prédicats sont spécifiés, un certificat est renvoyé si au moins un d'entre eux correspond.

Cela ne vérifie en aucun cas l'authenticité des certificats. Avant d'utiliser les certificats, assurez-vous de les valider et de les authentifier.

Lors de la correspondance sur des sous-clés ou des identifiants utilisateur, le composant doit avoir une auto-signature valide selon la politique.

Échoue si des critères de recherche sont spécifiés et qu'aucun d'entre eux ne correspond à des certificats. Remarque : cela signifie que si le magasin de certificats est vide et qu'aucun critère de recherche n'est spécifié, la commande réussira.

sq cert list

Lister les certificats et les identifiants utilisateur.

Liste les certificats et les identifiants utilisateur qui correspondent à une requête, sont utilisables et peuvent être authentifiés. Par défaut, les liaisons (paires certificat et identifiant utilisateur) doivent être entièrement authentifiées. Si aucun certificat ou liaison ne correspond à une requête, la commande renvoie un code de sortie non nul.

Si aucune requête n'est fournie, toutes les liaisons utilisables et pouvant être authentifiées sont listées. S'il n'y a pas de telles liaisons, la commande réussit néanmoins.

Par défaut, les certificats inutilisables, c'est-à-dire ceux qui ne sont pas valides selon la politique, qui sont révoqués ou qui ne sont pas actifs, sont ignorés. De même, les auto-signatures d'identifiant utilisateur et les certifications qui ne sont pas valides selon la politique, ainsi que les identifiants utilisateur révoqués, sont ignorés.

sq cert lint

Vérifier les certificats pour des problèmes.

`sq cert lint` vérifie les certificats fournis pour les problèmes suivants liés à SHA-1 :


- Si une révocation de certificat utilise SHA-1.


- Si l'auto-signature actuelle pour un identifiant utilisateur non révoqué utilise SHA-1.


- Si la signature de liaison de sous-clé actuelle pour une sous-clé non révoquée et active utilise SHA-1.


- Si une signature de liaison de clé primaire (« backsig ») pour une sous-clé non révoquée et active utilise SHA-1.

Les diagnostics sont imprimés sur stderr. À la fin, quelques statistiques sont affichées. Ceci est utile lors de l'examen d'une keyring. Si `--fix` est spécifié et qu'au moins un problème a pu être corrigé, les certificats corrigés sont imprimés sur stdout.

Cet outil ne prend pas en charge les cartes à puce pour le moment. Mais, si seules les sous-clés sont sur une carte à puce, cet outil peut toujours réparer partiellement le certificat. En particulier, il pourra corriger les problèmes d'auto-signatures d'identifiant utilisateur et de signatures de liaison de sous-clés pour les sous-clés capables de chiffrement, mais il ne pourra pas générer de nouvelles signatures de liaison de clé primaire pour les sous-clés capables de signature.

EXEMPLES

sq cert import

Importer un certificat.

sq cert import juliet.pgp

sq cert export

Exporter les certificats avec un identifiant utilisateur contenant l'adresse e-mail.

sq cert export --cert-email=alice@example.org

Exporter les certificats qui contiennent un identifiant utilisateur avec *l'une ou l'autre* (pas les deux !) adresse e-mail.

sq cert export --cert-email=alice@example.org \
--cert-email=bob@example.org

Exporter tous les certificats.

sq cert export --all

sq cert list

Lister toutes les liaisons pour les identifiants utilisateur contenant une adresse e-mail de example.org, et qui peuvent être authentifiées.

sq cert list @example.org

Lister toutes les liaisons authentifiées pour les identifiants utilisateur contenant une adresse e-mail spécifique.

sq cert list --cert-email=alice@example.org

Lister tous les chemins vers les certificats contenant une adresse e-mail spécifique.

sq cert list --gossip --show-paths \
--cert-email=alice@example.org

sq cert lint


Collecter des statistiques sur les certificats d'une keyring.

sq cert lint --cert-file certs.pgp

Corriger une clé avec des problèmes connus.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
| sq cert lint --fix --cert-file=- \
| sq cert import
