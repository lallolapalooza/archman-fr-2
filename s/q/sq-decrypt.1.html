SQ(1) Commandes utilisateur SQ(1)

NOM

sq-decrypt - Décrypte un message

SYNTAXE

sq decrypt [OPTIONS] FICHIER

DESCRIPTION

Décrypte un message.

Décrypte un message en utilisant soit les clés fournies, soit en demandant un mot de passe. Si une falsification du message est détectée, une erreur est renvoyée. Voir ci-dessous pour plus de détails.

Si des certificats sont fournis à l'aide de l'option `--signer-file`, les signatures trouvées sont vérifiées à l'aide de ces certificats. La vérification n'est réussie que s'il n'y a pas de mauvaise signature, et que le nombre de signatures vérifiées avec succès atteint le seuil configuré avec le paramètre `--signatures`.

Si la vérification de la signature échoue, ou si une falsification du message est détectée, le programme se termine avec un statut de sortie indiquant l'échec, et le fichier de sortie est supprimé. Si la sortie a été envoyée à stdout, les 25 derniers MiB du message sont retenus (par conséquent, si le message est inférieur à 25 MiB, aucune sortie n'est produite).

L'opération converse est `sq encrypt`.

OPTIONS

Options de sous-commande

--dump-session-key
Affiche la clé de session sur stderr
--output=FICHIER
Écrit dans FICHIER ou stdout si omis
[défaut : -]
--recipient-file=FICHIER_CLE
Décrypte le message en utilisant la clé dans FICHIER_CLE
--session-key=CLE-SESSION
Décrypte un message chiffré en utilisant CLE-SESSION
--signatures=N
Définit le seuil des signatures valides à N
Le message ne sera considéré comme vérifié que si ce seuil est atteint. [défaut : 1 si au moins un fichier de certificat signataire est donné, 0 sinon]
--signer=EMPREINTE|IDCLE
Exige une signature d'un certificat avec l'empreinte ou l'ID de clé spécifié
--signer-domain=DOMAINE
Exige une signature d'un certificat où un ID utilisateur inclut une adresse e-mail pour le domaine spécifié
--signer-email=EMAIL
Exige une signature d'un certificat où un ID utilisateur inclut l'adresse e-mail spécifiée
--signer-file=CHEMIN
Exige une signature d'un certificat lu depuis CHEMIN
--signer-userid=IDUTILISATEUR
Exige une signature d'un certificat avec l'ID utilisateur spécifié

FICHIER
Lit depuis FICHIER ou stdin si FICHIER est '-'
[défaut : -]

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Décrypter un fichier à l'aide d'une clé secrète

sq decrypt --recipient-file juliet-secret.pgp ciphertext.pgp

Décrypter un fichier en vérifiant les signatures

sq decrypt --recipient-file juliet-secret.pgp --signer-file \
romeo.pgp ciphertext.pgp

décrypter un fichier en utilisant le magasin de clés

sq decrypt ciphertext.pgp
