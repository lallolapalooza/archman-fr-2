sqop(1) Manuel des commandes générales sqop(1)

NOM

sqop - Une implémentation de l'interface en ligne de commande Stateless OpenPGP utilisant sqop 0.37.3

SYNTAXE

sqop [--debug] [-h|--help] <sous-commandes>

DESCRIPTION

Une implémentation de l'interface en ligne de commande Stateless OpenPGP utilisant sqop 0.37.3

OPTIONS

--debug
Émettre une sortie détaillée pour le débogage
-h, --help
Afficher l'aide

SOUS-COMMANDES

sqop-version(1)
Affiche les informations de version
sqop-list-profiles(1)
Émet une liste de profils pris en charge par la sous-commande identifiée
sqop-generate-key(1)
Génère une clé secrète
sqop-change-key-password(1)
Met à jour le mot de passe d'une clé
sqop-revoke-key(1)
Crée un certificat de révocation
sqop-extract-cert(1)
Extrait un certificat d'une clé secrète
sqop-update-key(1)
Maintient une clé secrète à jour
sqop-merge-certs(1)
Fusionne des certificats OpenPGP
sqop-certify-userid(1)
Certifie les identifiants utilisateur de certificat OpenPGP
sqop-validate-userid(1)
Valide un identifiant utilisateur dans un certificat OpenPGP
sqop-sign(1)
Crée des signatures détachées
sqop-verify(1)
Vérifie les signatures détachées
sqop-encrypt(1)
Chiffre un message
sqop-decrypt(1)
Déchiffre un message
sqop-inline-detach(1)
Sépare les signatures d'un message signé en ligne
sqop-inline-verify(1)
Vérifie les messages signés en ligne
sqop-inline-sign(1)
Crée des messages signés en ligne
sqop-armor(1)
Convertit les données binaires OpenPGP en ASCII
sqop-dearmor(1)
Convertit les données ASCII OpenPGP en binaire

v0.37.3
