real function sqrt12 (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real, dimension( lwork ) work, integer lwork)

SQRT12

But :

!>
!> SQRT12 calcule les valeurs singulières `svlues' du trapèze supérieur
!> de A(1:M,1:N) et renvoie le rapport
!>
!>      || svlues - s ||/(||s||*eps*max(M,N))
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A.
!>

A

!>          A est un tableau de réels (REAL), dimension (LDA,N)
!>          La matrice A de taille M par N. Seul le trapèze supérieur est référencé.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.
!>

S

!>          S est un tableau de réels (REAL), dimension (min(M,N))
!>          Les valeurs singulières de la matrice A.
!>

WORK

!>          WORK est un tableau de réels (REAL), dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La longueur du tableau WORK. LWORK >= max(M*N + 4*min(M,N) +
!>          max(M,N), M*N+2*MIN( M, N )+4*N).
!>
