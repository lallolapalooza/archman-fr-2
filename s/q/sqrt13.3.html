sous-programme sqrt13 (entier scale, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel norma, entier, dimension( 4 ) iseed)

SQRT13

Objectif :

!>
!> SQRT13 génère une matrice de rang complet qui peut être mise à l'échelle pour avoir une norme grande ou petite.
!>

Paramètres

SCALE 
!>          SCALE est ENTIER
!>          SCALE = 1 : matrice normalement mise à l'échelle
!>          SCALE = 2 : matrice agrandie
!>          SCALE = 3 : matrice réduite
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de A.
!>

A

!>          A est un tableau RÉEL, dimension (LDA,N)
!>          La matrice A de taille M par N.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.
!>

NORMA

!>          NORMA est RÉEL
!>          La norme unitaire de A.
!>

ISEED

!>          ISEED est un tableau entier, dimension (4)
!>          Graine pour le générateur de nombres aléatoires
!>
