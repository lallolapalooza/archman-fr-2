NOM

sq-keyring-list - Lister les clés d'un porte-clés

SYNTAXE

sq keyring list [OPTIONS] FICHIER

DESCRIPTION

Lister les clés d'un porte-clés.

Affiche l'empreinte ainsi que l'identifiant utilisateur principal pour chaque certificat rencontré dans le porte-clés.

OPTIONS

Options de sous-commande

--all-userids
Lister tous les identifiants utilisateur
Inclure les identifiants utilisateur qui sont expirés, révoqués, ou qui ne sont pas valides selon la politique standard.

FICHIER
Lire depuis FICHIER ou depuis l'entrée standard si FICHIER est '-'
[défaut : -]

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Lister tous les certificats.

sq keyring list certs.pgp

Lister tous les certificats avec un identifiant utilisateur sur example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp \
| sq keyring list

VOIR AUSSI

sq(1), sq-keyring(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
