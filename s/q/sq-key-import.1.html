SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key-import - Importer des clés dans le magasin de clés

SYNTAXE

sq key import [OPTIONS] FICHIER_CLE

DESCRIPTION

Importer des clés dans le magasin de clés.

OPTIONS

Options de sous-commande


FICHIER_CLE
Lire depuis FICHIER_CLE ou depuis l'entrée standard si omis

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Importer les clés dans le magasin de clés.

sq key import alice-secret.pgp

VOIR AUSSI

sq(1), sq-key(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
