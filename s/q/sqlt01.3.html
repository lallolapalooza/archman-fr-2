Documentation de la fonction/sous-programme

sous-programme sqlt01 (entier m, entier n, reel, dimension( lda, * ) a, reel, dimension( lda, * ) af, reel, dimension( lda, * ) q, reel, dimension( lda, * ) l, entier lda, reel, dimension( * ) tau, reel, dimension( lwork ) work, entier lwork, reel, dimension( * ) rwork, reel, dimension( * ) result)

SQLT01

Objectif :

!>
!> SQLT01 teste SGEQLF, qui calcule la factorisation QL d'une matrice m-par-n
!> A, et teste partiellement SORGQL qui forme la matrice orthogonale m-par-m
!> Q.
!>
!> SQLT01 compare L avec Q'*A, et vérifie que Q est orthogonale.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          La matrice m-par-n A.
!>

AF

!>          AF est un tableau REEL, de dimension (LDA,N)
!>          Détails de la factorisation QL de A, tels que retournés par SGEQLF.
!>          Voir SGEQLF pour plus de détails.
!>

Q

!>          Q est un tableau REEL, de dimension (LDA,M)
!>          La matrice orthogonale m-par-m Q.
!>

L

!>          L est un tableau REEL, de dimension (LDA,max(M,N))
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU est un tableau REEL, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que
!>          retournés par SGEQLF.
!>

WORK

!>          WORK est un tableau REEL, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, de dimension (2)
!>          Les ratios de test :
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
