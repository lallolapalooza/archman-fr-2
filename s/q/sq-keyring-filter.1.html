SQ(1) Commandes utilisateur SQ(1)

NOM

sq-keyring-filter - Joindre des clés dans un trousseau en appliquant un filtre

SYNTAXE

sq keyring filter [OPTIONS] FICHIER

DESCRIPTION

Joindre des clés dans un trousseau en appliquant un filtre.

Ceci peut être utilisé pour filtrer des clés en fonction de prédicats donnés, par exemple si elles ont un identifiant utilisateur contenant une adresse e-mail avec un domaine spécifique. De plus, les clés peuvent être élaguées pour n'inclure que les composants correspondant aux prédicats.

Si aucun filtre n'est fourni, tout correspond.

Si plusieurs prédicats sont donnés, ils sont combinés avec un OU logique, c'est-à-dire qu'une clé correspond si l'un des prédicats correspond. Pour exiger que tous les prédicats correspondent, chaînez plusieurs invocations de cette commande. Voir EXEMPLES pour l'inspiration.

Note : cette commande est considérée comme expérimentale et peut changer dans les futures versions. Pour en tenir compte, vous devez fournir l'option `--experimental` lors de l'invocation de cette commande.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Correspondance sur les empreintes de certificat et les ID de clé
Correspondance sur les clés primaires, y compris les certificats qui correspondent à l'empreinte ou à l'ID de clé donné.
--domain=FQDN
Correspondance sur le domaine de messagerie FQDN
Analyse les identifiants utilisateur en nom et adresse e-mail et correspond de manière sensible à la casse sur le domaine de l'adresse e-mail, exigeant une correspondance exacte.
--email=ADRESSE
Correspondance sur l'ADRESSE e-mail
Analyse les identifiants utilisateur en nom et adresse e-mail et correspond de manière sensible à la casse sur l'adresse e-mail, exigeant une correspondance exacte.
--experimental
Accepte l'utilisation d'une fonctionnalité expérimentale
Cette commande est considérée comme expérimentale et peut changer dans les futures versions. Pour en tenir compte, vous devez fournir l'option `--experimental` lors de l'invocation de cette commande.
À l'avenir, nous pourrions stabiliser cette commande. Lorsque cela se produira, `--experimental` ne sera plus requis, mais sera ignoré silencieusement.
--key=EMPREINTE|IDCLEF
Correspondance sur les empreintes de (sous-)clé et les ID de clé
Correspondance sur les clés primaires et les sous-clés, y compris les certificats qui correspondent à l'empreinte ou à l'ID de clé donné.
--name=NOM
Correspondance sur le NOM
Analyse les identifiants utilisateur en nom et e-mail et correspond de manière sensible à la casse sur le nom, exigeant une correspondance exacte.
--output=FICHIER
Écrire dans FICHIER ou dans la sortie standard si omis
[défaut : -]
--prune-certs
Supprimer les composants de certificat ne correspondant pas au filtre
--to-cert
Convertir les clés dans l'entrée en certificats
Convertir une clé en certificat supprime le matériel de clé sec de la clé, la transformant ainsi en un certificat.
--userid=USERID
Correspondance sur USERID
Correspond de manière sensible à la casse sur l'identifiant utilisateur, exigeant une correspondance exacte.

FICHIER
Lire depuis FICHIER ou depuis l'entrée standard si omis

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Convertir toutes les clés en certificats (c'est-à-dire supprimer tout matériel de clé sec).

sq keyring filter --experimental --to-cert certs.pgp

Obtenir tous les certificats avec un identifiant utilisateur sur example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp

Obtenir tous les certificats avec un identifiant utilisateur sur example.org ou example.net.

sq keyring filter --experimental --domain=example.org \
--domain=example.net certs.pgp

Obtenir tous les certificats avec un nom d'identifiant utilisateur correspondant à Romeo.

sq keyring filter --experimental --name=Romeo certs.pgp

Obtenir tous les certificats avec un nom d'identifiant utilisateur correspondant à Romeo sur example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp \
| sq keyring filter --experimental --name=Romeo

Obtenir tous les certificats avec un identifiant utilisateur sur example.org, en élaguant les autres identifiants utilisateur.

sq keyring filter --experimental --domain=example.org \
--prune-certs certs.pgp
