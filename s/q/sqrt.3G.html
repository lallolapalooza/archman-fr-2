NOM

sqrt - renvoie la racine carrée du paramètre

DÉCLARATION

genType sqrt(genType x);

genDType sqrt(genDType x);

PARAMÈTRES

x

Spécifie la valeur dont on doit prendre la racine carrée.

DESCRIPTION

sqrt renvoie la racine carrée de $x$, c'est-à-dire la valeur $\sqrt { x }$. Le résultat est indéfini si $x < 0$.
