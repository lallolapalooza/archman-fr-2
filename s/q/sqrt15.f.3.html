SQRT15

Documentation de la fonction/sous-programme

sous-programme sqrt15 (integer scale, integer rksel, integer m, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) s, integer rank, real norma, real normb, integer, dimension( 4 ) iseed, real, dimension( lwork ) work, integer lwork)

SQRT15

Objectif :

!>
!> SQRT15 génère une matrice de rang plein ou déficient et de normes variées.
!>

Paramètres

SCALE 
!>          SCALE est un ENTIER
!>          SCALE = 1 : matrice normalement mise à l'échelle
!>          SCALE = 2 : matrice mise à l'échelle vers le haut
!>          SCALE = 3 : matrice mise à l'échelle vers le bas
!>

RKSEL

!>          RKSEL est un ENTIER
!>          RKSEL = 1 : matrice de rang plein
!>          RKSEL = 2 : matrice de rang déficient
!>

M

!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de A.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de colonnes de B.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          La matrice A de dimensions M x N.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.
!>

B

!>          B est un tableau REEL, de dimension (LDB, NRHS)
!>          Une matrice qui est dans l'espace image de la matrice A.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.
!>

S

!>          S est un tableau REEL, de dimension MIN(M,N)
!>          Les valeurs singulières de A.
!>

RANK

!>          RANK est un ENTIER
!>          nombre de valeurs singulières non nulles de A.
!>

NORMA

!>          NORMA est un REEL
!>          la norme en colonne 1 de A.
!>

NORMB

!>          NORMB est un REEL
!>          la norme en colonne 1 de B.
!>

ISEED

!>          ISEED est un tableau entier, de dimension (4)
!>          graine pour le générateur de nombres aléatoires.
!>

WORK

!>          WORK est un tableau REEL, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          taille de l'espace de travail requis.
!>          LWORK >= MAX(M+MIN(M,N),NRHS*MIN(M,N),2*N+M)
!>
