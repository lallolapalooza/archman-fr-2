NOM

sq-network-dane - Récupère et publie des certificats via DANE

SYNOPIS

sq network dane search [OPTIONS] ADRESSE
sq network dane generate [OPTIONS]

DESCRIPTION

Récupère et publie des certificats via DANE.

DANE (DNS-Based Authentication of Named Entities) est une méthode de publication et de récupération de certificats dans le DNS, telle que spécifiée dans la RFC 7929.

SOUS-COMMANDES

sq network dane search

Récupère des certificats en utilisant DANE.

Par défaut, tous les certificats renvoyés sont stockés dans le magasin de certificats local. Ceci peut être remplacé en utilisant l'option `--output`.

Lorsqu'un certificat est récupéré via DANE et importé dans le magasin de certificats local, tous les User IDs avec l'adresse e-mail qui a été recherchée sont certifiés avec une clé locale spécifique à DANE. Ce certificat proxy est à son tour certifié comme une CA minimale de confiance (montant de confiance : 1 sur 120) par la racine de confiance locale. Le degré de confiance de la CA proxy DANE peut être ajusté en utilisant `sq pki link add` ou `sq pki link retract` de la manière habituelle.

sq network dane generate

Génère des enregistrements DANE pour le domaine et les certificats donnés.

Les certificats sont minimisés, et un enregistrement par adresse e-mail est émis. Si plusieurs User IDs correspondent à une adresse e-mail, tous les User IDs correspondants sont inclus dans les certificats émis.

Par défaut, des enregistrements de ressource OPENPGPKEY sont émis. Si votre serveur DNS ne les comprend pas, utilisez `--type generic` pour émettre des enregistrements génériques à la place.

EXEMPLES

sq network dane search

Récupérer le certificat d'Alice via DANE.

sq network dane search alice@example.org

Récupérer les mises à jour pour tous les certificats connus via DANE.

sq network dane search --all

sq network dane generate

Générer des enregistrements DANE à partir de juliet.pgp pour example.org.

sq network dane generate --domain=example.org \
--cert-file=juliet.pgp

Générer des enregistrements DANE pour tous les certificats avec un User ID authentifié dans example.org.

sq network dane generate --domain=example.org --all
