NOM

sq-key-approvals-update - Approuve les certifications tierces pour permettre leur distribution

SYNTAXE

sq key approvals update [OPTIONS]

DESCRIPTION

Approuve les certifications tierces pour permettre leur distribution.

Pour éviter les attaques par inondation de certificats, les serveurs de clés modernes empêchent la distribution incontrôlée de certifications tierces sur les certificats. Pour permettre au détenteur de clé de contrôler quelles informations sont distribuées avec son certificat, ces serveurs de clés ne distribuent que les certifications tierces que le détenteur de clé a explicitement approuvées.

Par défaut, tous les identifiants utilisateur sont pris en compte, mais si au moins un argument de type `--name`, `--email`, ou `--userid` est donné, seuls les identifiants utilisateur correspondants sont pris en compte.

Après que les approbations aient été modifiées, le certificat doit être distribué, par exemple en le téléchargeant sur un serveur de clés.

OPTIONS

Options de sous-commande

--add-all
Approuver toutes les certifications en attente
--add-authenticated
Approuver toutes les certifications par des certificateurs authentifiés
Pour toutes les approbations en attente, essayer d'authentifier tout identifiant utilisateur sur le certificateur, et si l'un d'eux peut être authentifié, approuver la certification.
--add-by=EMPREINTE|IDCLEF
Approuver toutes les certifications par ce certificateur
--cert=EMPREINTE|IDCLEF
Lister les approbations sur le certificat avec l'empreinte ou l'ID de clé spécifié
--cert-email=EMAIL
Lister les approbations sur le certificat où un identifiant utilisateur inclut l'adresse e-mail spécifiée
--cert-file=CHEMIN
Lister les approbations sur le certificat lu depuis CHEMIN
--cert-userid=IDUTIL
Lister les approbations sur le certificat avec l'identifiant utilisateur spécifié
--email=EMAIL
Utiliser l'identifiant utilisateur auto-signé avec l'adresse e-mail spécifiée
--output=FICHIER
Écrire dans le FICHIER spécifié
Si non spécifié, et que le certificat a été lu depuis le magasin de certificats, importe le certificat modifié dans le magasin de certificats. Si non spécifié, et que le certificat a été lu depuis un fichier, écrit le certificat modifié sur la sortie standard.
--remove-all
Supprimer toutes les approbations antérieures
Par défaut, cette commande s'ajoute à l'ensemble des certifications déjà approuvées. Si ce drapeau est donné, les approbations existantes sont ignorées, et seules les certifications nouvellement sélectionnées sont approuvées, s'il y en a.
--remove-by=EMPREINTE|IDCLEF
Supprimer toutes les approbations antérieures de certifications par ce certificateur
--userid=IDUTIL
Utiliser l'identifiant utilisateur auto-signé spécifié
L'identifiant utilisateur spécifié doit être auto-signé.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Approuver toutes les certifications sur tous les identifiants utilisateur d'Alice.

sq key approvals update --add-all \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Approuver toutes les certifications sur tous les identifiants utilisateur d'Alice faites par Bob, en supprimant d'abord toutes les approbations précédentes.

sq key approvals update --remove-all \
--add-by=511257EBBF077B7AEDAE5D093F68CB84CE537C9A \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Approuver toutes les certifications sur un identifiant utilisateur spécifique par des certificateurs qui peuvent être authentifiés, en supprimant d'abord toutes les approbations précédentes.

sq key approvals update --remove-all --add-authenticated \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--userid="Alice <alice@example.org>"

Supprimer l'approbation de la certification de Bob sur tous les identifiants utilisateur d'Alice.

sq key approvals update \
--remove-by=511257EBBF077B7AEDAE5D093F68CB84CE537C9A \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0
