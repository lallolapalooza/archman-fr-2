SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key-userid - Gérer les identifiants utilisateur

SYNTAXE

sq key userid add [OPTIONS]
sq key userid revoke [OPTIONS]

DESCRIPTION

Gérer les identifiants utilisateur.

Ajouter des identifiants utilisateur à une clé, ou les révoquer.

SOUS-COMMANDES

sq key userid add

Ajouter un identifiant utilisateur.

Un identifiant utilisateur peut contenir un nom, comme « Juliet », ou une adresse e-mail, comme « <juliet@example.org> ». Historiquement, un nom et une adresse e-mail étaient généralement combinés en un seul identifiant utilisateur, comme « Juliet <juliet@example.org> ». Cependant, les identifiants utilisateur qui incluent des informations différentes telles que le nom et l'adresse e-mail sont plus difficiles à interpréter, donc l'utilisation d'identifiants utilisateur distincts pour le nom et l'adresse e-mail est préférable de nos jours.

`sq key userid add` respecte l'heure de référence définie par l'argument de niveau supérieur `--time`. Il définit l'heure de création de la signature de liaison de l'identifiant utilisateur à l'heure spécifiée.

sq key userid revoke

Révoquer un identifiant utilisateur.

Crée un certificat de révocation pour un identifiant utilisateur.

Si `--revoker` ou `--revoker-file` est fourni, alors cette clé est utilisée pour créer le certificat de révocation. Si cette clé est différente de celle qui est révoquée, cela entraîne une révocation par un tiers. Ceci n'est normalement utile que si le propriétaire du certificat a désigné la clé comme révocateur désigné.

Pour révoquer un identifiant utilisateur, le certificat doit être valide selon la politique actuelle. Si le certificat n'est pas valide selon la politique actuelle, envisagez de révoquer le certificat entier, ou de le corriger en utilisant `sq cert lint` après avoir vérifié l'intégrité du certificat. Si le certificat est valide selon la politique actuelle, mais que l'identifiant utilisateur que vous souhaitez révoquer ne l'est pas, vous pouvez toujours révoquer l'identifiant utilisateur en utilisant `--add-userid`.

`sq key userid revoke` respecte l'heure de référence définie par l'argument de niveau supérieur `--time`. Lorsqu'elle est définie, elle utilise l'heure spécifiée au lieu de l'heure actuelle pour déterminer quelles clés sont valides, et elle définit l'heure de création du certificat de révocation à l'heure de référence au lieu de l'heure actuelle.

EXEMPLES

sq key userid add

# Ajouter un nouvel identifiant utilisateur à la clé d'Alice.

sq key userid add --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0 --name Alice \
--email alice@work.example.com

sq key userid revoke

Retirer un identifiant utilisateur de la clé d'Alice.

sq key userid revoke --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0 --userid \
"Alice <alice@example.org>" --reason retired --message \
"Ne travaille plus chez example.org."
