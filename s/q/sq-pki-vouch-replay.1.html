NOM

sq-pki-vouch-replay - Rejoue les validations

SYNTAXE

sq pki vouch replay [OPTIONS]

DESCRIPTION

Rejoue les validations.

Cette commande rejoue les validations effectuées par un certificat en utilisant un autre certificat. Ceci est principalement utile lorsque vous remplacez un certificat, et que vous souhaitez que le nouveau certificat ait effectué les mêmes validations que vous aviez effectuées avec l'ancien certificat.

Étant donné que les validations sont associées au certificat validé, et non au certificat du valideur, cela peut ne pas rejouer toutes les validations que la source a jamais effectuées.

Cette commande copie uniquement la validation active pour un identifiant d'utilisateur et un certificat donnés. Cela inclut les validations exportables (valides) ainsi que les validations non exportables (liens). Elle exclut les validations expirées. Elle ne rejoue pas non plus les validations effectuées sur des certificats invalides, expirés ou révoqués, ou sur des identifiants d'utilisateur révoqués.

Cette commande rejoue tous les paramètres de validation, y compris toute heure d'expiration, mais l'heure de création est définie sur l'heure actuelle.

Stable depuis 1.2.0.

OPTIONS

Options de sous-commande

--allow-dissimilar-userids
Ne vérifie pas que les identifiants d'utilisateur source et cible sont identiques.
Normalement, cette commande vérifie que les certificats source et cible ont un identifiant d'utilisateur en commun. Ce drapeau saute cette vérification.
--output=FICHIER
Écrit dans FICHIER ou sur la sortie standard si omis.
--source=EMPREINTE|IDCLEF
Utilise les certificats avec l'empreinte ou l'ID de clé spécifié.
--source-email=EMAIL
Utilise les certificats dont un identifiant d'utilisateur inclut l'adresse e-mail spécifiée.
--source-file=CHEMIN
Lit les certificats depuis CHEMIN.
--source-userid=IDENTIFIANTUTILISATEUR
Utilise les certificats avec l'identifiant d'utilisateur spécifié.
--target=EMPREINTE|IDCLEF
Utilise les certificats avec l'empreinte ou l'ID de clé spécifié.
--target-email=EMAIL
Utilise les certificats dont un identifiant d'utilisateur inclut l'adresse e-mail spécifiée.
--target-file=CHEMIN
Lit les certificats depuis CHEMIN.
--target-userid=IDENTIFIANTUTILISATEUR
Utilise les certificats avec l'identifiant d'utilisateur spécifié.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Alice génère un nouveau certificat et rejoue les validations qu'elle a faites avec l'ancien certificat en utilisant le nouveau.

sq pki vouch replay \
--source=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--target=C5999E8191BF7B503653BE958B1F7910D01F86E5
