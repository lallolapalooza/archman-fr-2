sq-pki-link-list(1)

Paquet: sequoia-sq

Licences: LGPL-2.0-or-later

SQ(1) Commandes utilisateur SQ(1)

NOM

sq-pki-link-list - Lister les liens

SYNTAXE

sq pki link list [OPTIONS] MOTIF

DESCRIPTION

Lister les liens.

Cette commande liste toutes les liaisons qui sont liées ou dont le lien a été rétracté.

Retourne un code de sortie non nul si un certificat explicitement désigné n'a jamais été lié.

OPTIONS

Options de sous-commande

--ca
Ne liste que les liaisons liées en tant qu'AC (Autorités de Certification)
C'est-à-dire, ne liste un lien que si sa profondeur de confiance est supérieure à 0.
--cert=EMPREINTE|IDCLEF
Utilise les certificats avec l'empreinte ou l'ID de clé spécifié
--cert-domain=DOMAINE
Utilise les certificats où un identifiant utilisateur inclut une adresse email pour le domaine spécifié
--cert-email=EMAIL
Utilise les certificats où un identifiant utilisateur inclut l'adresse email spécifiée
--cert-grep=MOTIF
Utilise les certificats avec un identifiant utilisateur qui correspond au motif, insensible à la casse
--cert-userid=IDENTIFIANTUTILISATEUR
Utilise les certificats avec l'identifiant utilisateur spécifié

MOTIF
Un motif pour sélectionner les liaisons à authentifier
Le motif est traité comme une chaîne encodée en UTF-8 et une recherche de sous-chaîne insensible à la casse (utilisant la locale courante) est effectuée sur chaque identifiant utilisateur. Si un identifiant utilisateur n'est pas un UTF-8 valide, la liaison est ignorée.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Lier le certificat EB28F26E2739A4870ECC47726F0073F60FD0CBF0 avec l'adresse email alice@example.org.

sq pki link add \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--email=alice@example.org

Lister tous les liens.

sq pki link list

Lister les liens vers des certificats avec un identifiant utilisateur authentifié qui contient une adresse email dans le domaine spécifié.

sq pki link list --cert-domain=example.org

VOIR AUSSI

sq(1), sq-pki(1), sq-pki-link(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
