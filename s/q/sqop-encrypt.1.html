sqop-encrypt(1) Manuel des commandes générales sqop-encrypt(1)

NOM

sqop-encrypt - Chiffre un message

SYNTAXE

sqop encrypt [--debug] [--no-armor] [--profile] [--as] [--with-password] [--sign-with] [--with-key-password] [--session-key-out] [-h|--help] [CERTS]

DESCRIPTION

Chiffre un message

OPTIONS

--debug
Émettre une sortie détaillée pour le débogage
--no-armor
Ne pas utiliser le format ASCII blindé pour la sortie
--profile <PROFIL>
Sélectionne le profil à utiliser pour le chiffrement
--as <AS> [défaut : binaire]
Chiffre des données binaires ou du texte UTF-8
--with-password <MOT_DE_PASSE>
Chiffre avec des mots de passe
--sign-with <SIGN_WITH>
Clés pour la signature
--with-key-password <MOT_DE_PASSE_CLE>
Essaye de déchiffrer les CLÉS de signature avec ces mots de passe
--session-key-out <SESSION_KEY_OUT>
Écrit la clé de session ici
-h, --help
Affiche l'aide
[CERTS]
Chiffre pour ces certificats
