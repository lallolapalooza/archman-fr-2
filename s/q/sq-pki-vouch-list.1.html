SQ(1) Commandes utilisateur SQ(1)

NOM

sq-pki-vouch-list - Lister les certifications

SYNTAXE

sq pki vouch list [OPTIONS]

DESCRIPTION

Lister les certifications.

Si l'argument certifieur est fourni, alors les certifications faites par le certificat spécifié sont montrées. Si l'argument certificat est fourni, alors les certifications du certificat spécifié sont montrées. Si les deux sont fournis, alors les certifications du certificat spécifié faites par le certifieur spécifié sont montrées.

Cette commande liste toutes les certifications, pas seulement la certification active.

Comme les certifications sont associées au certificat certifié et non au certificat du certifieur, cette liste est probablement incomplète.

Stable depuis 1.2.0.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Utiliser les certificats avec l'empreinte ou l'ID de clef spécifié
--cert-email=EMAIL
Utiliser les certificats où un ID utilisateur inclut l'adresse email spécifiée
--cert-file=CHEMIN
Lire les certificats depuis CHEMIN
--cert-userid=IDUTILISATEUR
Utiliser les certificats avec l'ID utilisateur spécifié
--certifier=EMPREINTE|IDCLEF
Utiliser les certificats avec l'empreinte ou l'ID de clef spécifié
--certifier-email=EMAIL
Utiliser les certificats où un ID utilisateur inclut l'adresse email spécifiée
--certifier-file=CHEMIN
Lire les certificats depuis CHEMIN
--certifier-self
Créer la certification en utilisant votre clef de certification par défaut
Ceci utilise les certificats définis dans le fichier de configuration sous `pki.vouch.certifier-self` comme clef de certification.
Actuellement, il n'y a pas de clef de certification par défaut.
--certifier-special=SPECIAL
Utiliser les certificats identifiés par le nom spécial
[valeurs possibles : public-directories, keys.openpgp.org, keys.mailvelope.com, proton.me, wkd, dane, autocrypt, web]
--certifier-userid=IDUTILISATEUR
Utiliser les certificats avec l'ID utilisateur spécifié

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Lister les certifications faites par Alice.

sq pki vouch list \
--certifier=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Lister les certifications faites par Alice pour le certificat de Bob.

sq pki vouch list \
--certifier=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--cert=511257EBBF077B7AEDAE5D093F68CB84CE537C9A

VOIR AUSSI

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
