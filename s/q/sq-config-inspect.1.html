SQ(1) Commandes utilisateur SQ(1)

NOM

sq-config-inspect - Examiner les détails de configuration effectifs

SYNTAXE

sq config inspect paths [OPTIONS]
sq config inspect network [OPTIONS]
sq config inspect policy [OPTIONS]

DESCRIPTION

Examiner les détails de configuration effectifs.

Cette sous-commande peut être utilisée pour examiner divers aspects de la configuration effective, tels que divers chemins pertinents, la politique cryptographique, la configuration réseau, etc.

SOUS-COMMANDES

sq config inspect paths

Examiner les chemins pertinents.

Affiche les chemins utilisés par sq, tels que l'emplacement du répertoire personnel, le fichier de configuration, le magasin de certificats, le magasin de clés, etc.

sq config inspect network

Examiner la configuration réseau.

Affiche la configuration réseau. Cela peut être utilisé pour évaluer la fuite de métadonnées résultant des opérations réseau.

sq config inspect policy

Examiner la politique cryptographique.

Explique la politique cryptographique que Sequoia utilise pour accepter ou rejeter les algorithmes et les paquets directement, ou à un moment configuré.

EXEMPLES

sq config inspect paths

Examiner les chemins pertinents.

sq config inspect paths

sq config inspect network

Examiner la configuration réseau.

sq config inspect network

sq config inspect policy

Examiner la politique cryptographique.

sq config inspect policy
