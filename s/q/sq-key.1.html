SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key - Gérer les clés

SYNTAXE

sq key list [OPTIONS] EMPREINTE|ID_CLE|MOTIF
sq key generate [OPTIONS]
sq key rotate [OPTIONS]
sq key import [OPTIONS] FICHIER_CLE
sq key export [OPTIONS]
sq key delete [OPTIONS]
sq key password [OPTIONS]
sq key expire [OPTIONS]
sq key revoke [OPTIONS]
sq key userid [OPTIONS] SOUS-COMMANDE
sq key subkey [OPTIONS] SOUS-COMMANDE
sq key approvals [OPTIONS] SOUS-COMMANDE

DESCRIPTION

Gérer les clés.

Nous utilisons le terme « clé » pour désigner les clés OpenPGP qui contiennent des secrets. Cette sous-commande fournit des primitives pour générer et manipuler les clés.

Inversement, nous utilisons le terme « certificat » (ou « cert » en abrégé) pour désigner les clés OpenPGP qui ne contiennent pas de secrets. Voir `sq cert` pour les opérations sur les certificats.

SOUS-COMMANDES

sq key list

Lister les clés gérées par le magasin de clés.

sq key generate

Générer une nouvelle clé.

La génération d'une clé est un prérequis pour recevoir des messages chiffrés et créer des signatures. Il y a quelques paramètres à ce processus, mais nous fournissons des valeurs par défaut raisonnables pour la plupart des utilisateurs.

Lors de la génération d'une clé, nous générons également un certificat de révocation d'urgence. Celui-ci peut être utilisé en cas de perte ou de compromission de la clé. Il est enregistré aux côtés de la clé. Cela peut être modifié à l'aide de l'argument `--rev-cert`.

Par défaut, une clé expire après 3 ans. Cela peut être modifié à l'aide de l'argument `--expiration`.

`sq key generate` respecte l'heure de référence définie par l'argument de niveau supérieur `--time`. Il définit l'heure de création de la clé principale, de toutes les sous-clés et des signatures de liaison à l'heure de référence.

sq key rotate

Faire pivoter un certificat.

Génère un nouveau certificat pour remplacer un certificat existant.

Le nouveau certificat aura les mêmes capacités que l'ancien certificat. Cela peut être outrepassé à l'aide des arguments `--can-sign`, `--cannot-sign`, etc. Note : le nouveau certificat peut avoir une forme différente de l'ancien certificat. Par exemple, si la clé principale de l'ancien certificat est marquée comme capable de certification et de signature, la clé principale du nouveau certificat sera capable de certification, et elle aura une sous-clé de signature.

Par défaut, le certificat expire après 3 ans. Cela peut être modifié à l'aide de l'argument `--expiration`.

Le nouveau certificat aura les mêmes identifiants utilisateur auto-signés que l'ancien certificat. Les identifiants utilisateur révoqués sont ignorés.

Le nouveau certificat et l'ancien certificat se certifieront mutuellement comme introduits de confiance sans restriction.

Le nouveau certificat sera lié de la même manière que l'ancien certificat. Cela peut être outrepassé à l'aide des arguments `--own-key` ou `--shared-key`.

Le nouveau certificat certifiera les mêmes certificats que l'ancien certificat. C'est-à-dire que les certifications de l'ancien certificat seront rejouées. Voir `sq pki vouch replay` pour plus d'informations.

Un certificat de révocation indiquant que l'ancien certificat est retiré et que le nouveau certificat doit être utilisé à la place sera émis. Par défaut, il prendra effet dans 182 jours. Cela peut être modifié ou supprimé à l'aide de l'argument `--retire-in`.

Lors de l'utilisation de `--output`, le nouveau certificat ainsi que tous les autres certificats mis à jour sont écrits dans le fichier spécifié.

Stable depuis 1.2.0.

sq key import

Importer des clés dans le magasin de clés.

sq key export

Exporter des clés depuis le magasin de clés.

Export les données de clé secrète associées à un certificat. Notez que même si des données de clé secrète sont disponibles, elles peuvent ne pas être exportables. Par exemple, les données de clé secrète stockées sur un module matériel de sécurité ne peuvent généralement pas être exportées de l'appareil.

Itère sur tous les certificats spécifiés et exporte toutes les clés (clé principale et sous-clés) avec des données de clé secrète. Une erreur est renvoyée si un certificat spécifié ne contient aucune donnée de clé secrète.

Si vous ne souhaitez exporter qu'une clé particulière et non toutes les clés associées à un certificat, utilisez `sq key subkey export`.

sq key delete

Supprimer les données de clé secrète d'un certificat.

sq key password

Changer le mot de passe protégeant les données de clé secrète.

Les données de clé secrète peuvent être protégées par un mot de passe. Cette sous-commande modifie ou efface le mot de passe.

Pour supprimer le mot de passe, utilisez `--clear` ou fournissez un mot de passe de longueur nulle lorsque vous êtes invité à entrer le nouveau mot de passe.

Si une clé est protégée par un mot de passe et que le mot de passe correct n'a pas été fourni à l'aide de l'argument `--password-file`, l'utilisateur est invité à saisir le mot de passe. De même, si le nouveau mot de passe n'est pas fourni, l'utilisateur est invité.

sq key expire

Changer la date d'expiration d'un certificat.

Cette sous-commande change la date d'expiration d'un certificat. Pour modifier la date d'expiration d'une sous-clé individuelle, utilisez la sous-commande `sq key subkey expire`.

sq key revoke

Révocquer un certificat.

Crée un certificat de révocation pour un certificat.

Si `--revoker` ou `--revoker-file` est fourni, alors cette clé est utilisée pour créer le certificat de révocation. Si cette clé est différente du certificat qui est révoqué, cela entraîne une révocation par un tiers. Ceci est normalement utile uniquement si le propriétaire du certificat a désigné la clé comme un révocateur désigné.

`sq key revoke` respecte l'heure de référence définie par l'argument de niveau supérieur `--time`. Lorsqu'il est défini, il utilise l'heure spécifiée au lieu de l'heure actuelle pour déterminer quelles clés sont valides, et il définit l'heure de création du certificat de révocation à l'heure de référence au lieu de l'heure actuelle.

sq key userid

Gérer les identifiants utilisateur.

Ajouter des identifiants utilisateur à une clé, ou les révoquer.

sq key subkey

Gérer les sous-clés.

Ajouter de nouvelles sous-clés à un certificat existant, modifier leur date d'expiration et les révoquer.

sq key approvals

Gère les approbations de certification.

Les détenteurs de clés peuvent approuver les certifications tierces associées à leur certificat. Cette sous-commande gère les approbations.

Pour prévenir les attaques par déferlement de certificats, les serveurs de clés modernes empêchent la distribution incontrôlée des certifications tierces sur les certificats. Pour permettre au détenteur de la clé de contrôler quelles informations sont distribuées avec son certificat, ces serveurs de clés ne distribuent que les certifications tierces que le détenteur de la clé a explicitement approuvées.

EXEMPLES

sq key list

Lister les clés gérées par le serveur de magasin de clés.

sq key list

Lister les clés gérées par le serveur de magasin de clés avec un identifiant utilisateur dans example.org.

sq key list --cert-domain=example.org

sq key generate

Générer une clé et l'enregistrer dans le magasin de clés.

sq key generate --own-key --name Alice --email \
alice@example.org

Générer une clé et l'enregistrer dans un fichier au lieu du magasin de clés.

sq key generate --own-key --name Alice --email \
alice@example.org --output alice-priv.pgp --rev-cert \
alice-priv.rev

sq key rotate

Faire pivoter la clé principale d'Alice.

sq key rotate --own-key --cert-email alice@example.org

Faire pivoter la clé principale d'Alice, et l'enregistrer dans un fichier.

sq key rotate --own-key --cert-email alice@example.org --output \
alice-rotated.pgp --rev-cert alice-rotated.rev

Retirer la clé principale d'Alice et la remplacer par une nouvelle clé qui prendra effet dans 182 jours.

sq key rotate --own-key --cert-email alice@example.org --retire-in \
182d

sq key import

Importer des clés depuis un fichier.

sq key import bob.pgp

sq key export

Exporter les clés d'Alice.

sq key export --cert-email alice@example.org

Exporter toutes les clés du magasin de clés.

sq key export

sq key delete

Supprimer la clé d'Alice.

sq key delete --cert-email alice@example.org

sq key password

Changer le mot de passe de la clé d'Alice.

sq key password --cert-email alice@example.org

Supprimer le mot de passe de la clé d'Alice.

sq key password --cert-email alice@example.org --clear

sq key expire

Changer la date d'expiration de la clé d'Alice.

sq key expire --cert-email alice@example.org --expire-in 1y

sq key revoke

Révocquer la clé d'Alice.

sq key revoke --cert-email alice@example.org

Révocquer la clé d'Alice à l'aide d'une clé tierce.

sq key revoke --cert-email alice@example.org --revoker \
--cert-email revoker@example.org

sq key userid

Ajouter un identifiant utilisateur à la clé d'Alice.

sq key userid --cert-email alice@example.org add --name Bob \
--email bob@example.org

Supprimer un identifiant utilisateur de la clé d'Alice.

sq key userid --cert-email alice@example.org delete \
--email bob@example.org

Révocquer un identifiant utilisateur de la clé d'Alice.

sq key userid --cert-email alice@example.org revoke \
--email bob@example.org

sq key subkey

Ajouter une sous-clé à la clé d'Alice.

sq key subkey --cert-email alice@example.org add

Changer la date d'expiration de la sous-clé d'Alice.

sq key subkey --cert-email alice@example.org expire --subkey-id \
0x1234567890ABCDEF --expire-in 1y

Révocquer la sous-clé d'Alice.

sq key subkey --cert-email alice@example.org revoke --subkey-id \
0x1234567890ABCDEF

sq key approvals

Approuver une certification tierce pour la clé d'Alice.

sq key approvals --cert-email alice@example.org add \
--cert-sig-key bob@example.org --cert-sig-id 0xDEADBEEF

Supprimer une approbation de certification de la clé d'Alice.

sq key approvals --cert-email alice@example.org delete \
--cert-sig-key bob@example.org --cert-sig-id 0xDEADBEEF

p class="Pp">Fait pivoter le certificat d'Alice.

sq key rotate --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key import

Importe les clés dans le magasin de clés.

sq key import alice-secret.pgp

sq key export

Exporte le certificat d'Alice avec tout le matériel de clé secrète disponible.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Exporte le certificat d'Alice avec tout le matériel de clé secrète disponible identifié par adresse e-mail.

sq key export --cert-email alice@example.org

sq key delete

Supprime toute clé secrète associée au certificat d'Alice.

sq key delete --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Supprime toute clé secrète associée au certificat d'Alice sélectionné par ID utilisateur.

sq key delete --cert-email=alice@example.org

sq key password

Modifie le mot de passe de toutes les clés d'Alice pour le mot de passe du fichier spécifié.

sq key password --new-password-file password-file.txt --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Efface la protection par mot de passe de toutes les clés d'Alice.

sq key password --password-file password-file.txt \
--clear-password --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key expire

Modifie la date d'expiration du certificat d'Alice à un an.

sq key expire --expiration 1y --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Modifie la date d'expiration du certificat d'Alice à jamais.

sq key expire --expiration never --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key revoke

Révoque la clé d'Alice, indiquant qu'il y a un nouveau certificat.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason superseded --message \
"Mon nouveau certificat est C5999E8191BF7B503653BE958B1F7910D01F86E5"

Révoque la clé, indiquant que le matériel de la clé secrète a été compromis.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason compromised --message \
"Ordinateur attaqué, matériel de clé secrète compromis"
