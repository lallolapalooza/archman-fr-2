SQ(1) Commandes utilisateur SQ(1)

NOM

sq-config-get - Obtenir les options de configuration

SYNTAXE

sq config get [OPTIONS] NOM

DESCRIPTION

Obtenir les options de configuration.

Récupère la configuration avec la clé donnée. Utilisez `sq config get` pour voir toutes les options disponibles et leurs valeurs.

OPTIONS

Options de sous-commande


NOM
Obtenir la valeur de la configuration NOM

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Lister toutes les options de configuration.

sq config get

Obtenir le chiffrement par défaut pour la génération de clés.

sq config get key.generate.cipher-suite

VOIR AUSSI

sq(1), sq-config(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
