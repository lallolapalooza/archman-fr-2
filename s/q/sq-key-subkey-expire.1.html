SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key-subkey-expire - Modifier l'heure d'expiration d'une sous-clé

SYNTAXE

sq key subkey expire [OPTIONS]

DESCRIPTION

Modifie l'heure d'expiration d'une sous-clé.

Cette sous-commande modifie l'heure d'expiration d'une clé. Pour modifier l'heure d'expiration du certificat, utilisez la sous-commande `sq key expire`.

La modification de l'heure d'expiration de la clé primaire équivaut à la modification de l'heure d'expiration du certificat. L'heure d'expiration d'une sous-clé est limitée par l'expiration du certificat.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Modifie l'expiration des sous-clés spécifiées sur la clé avec l'empreinte ou l'ID de clé spécifié(e)
--cert-email=EMAIL
Modifie l'expiration des sous-clés spécifiées sur la clé où un ID utilisateur inclut l'adresse e-mail spécifiée
--cert-file=CHEMIN
Modifie l'expiration des sous-clés spécifiées sur la clé lue depuis CHEMIN
--cert-userid=IDUTILISATEUR
Modifie l'expiration des sous-clés spécifiées sur la clé avec l'ID utilisateur spécifié
--expiration=EXPIRATION
Définit l'heure d'expiration
EXPIRATION est soit une date formatée ISO 8601 avec une heure optionnelle, soit une durée personnalisée. Une durée prend la forme `N[amjsh]`, où les lettres signifient années, mois, semaines, jours et secondes respectivement. Alternativement, le mot-clé `jamais` ne définit pas d'heure d'expiration.
[par défaut : jamais]
--key=EMPREINTE|IDCLEF
Utilise la clé avec l'empreinte ou l'ID de clé spécifié(e)
--output=FICHIER
Écrit dans le FICHIER spécifié
Si non spécifié, et que le certificat a été lu depuis le magasin de certificats, importe le certificat modifié dans le magasin de certificats. Si non spécifié, et que le certificat a été lu depuis un fichier, écrit le certificat modifié sur la sortie standard.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Modifier la sous-clé d'authentification d'Alice pour qu'elle expire dans 6 mois.

sq key subkey expire --expiration 6m \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1

VOIR AUSSI

sq(1), sq-key(1), sq-key-subkey(1).

Pour la documentation complète, consultez https://book.sequoia-pgp.org/.
