SQLT02

Documentation de la fonction/sous-routine

sous-routine sqlt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) l, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SQLT02

Objectif:

!>
!> SQLT02 teste SORGQL, qui génère une matrice m-par-n, Q, avec des
!> colonnes orthogonales définies comme le produit de k réflecteurs
!> élémentaires.
!>
!> Étant donnée la factorisation QL d'une matrice m-par-n, A, SQLT02 génère
!> la matrice orthogonale Q définie par la factorisation des k dernières
!> colonnes de A ; elle compare L(m-n+1:m,n-k+1:n) avec
!> Q(1:m,m-n+1:m)'*A(1:m,n-k+1:n), et vérifie que les colonnes de Q sont
!> orthogonales.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice Q à générer. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice Q à générer.
!>          M >= N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau réel (REAL), dimension (LDA,N)
!>          La matrice m-par-n A qui a été factorisée par SQLT01.
!>

AF

!>          AF est un tableau réel (REAL), dimension (LDA,N)
!>          Détails de la factorisation QL de A, tels que retournés par SGEQLF.
!>          Voir SGEQLF pour plus de détails.
!>

Q

!>          Q est un tableau réel (REAL), dimension (LDA,N)
!>

L

!>          L est un tableau réel (REAL), dimension (LDA,N)
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= M.
!>

TAU

!>          TAU est un tableau réel (REAL), dimension (N)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation QL dans AF.
!>

WORK

!>          WORK est un tableau réel (REAL), dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau réel (REAL), dimension (M)
!>

RESULT

!>          RESULT est un tableau réel (REAL), dimension (2)
!>          Les rapports de test:
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
