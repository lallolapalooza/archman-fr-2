SQ(1) Commandes utilisateur SQ(1)

NOM

sq-inspect - Inspecter des données, comme file(1)

SYNTAXE

sq inspect [OPTIONS] FICHIER

DESCRIPTION

Inspecter des données, comme file(1).

Il est souvent difficile de dire, à partir d'une inspection rapide avec cat(1) ou file(1), quel type d'OpenPGP on regarde. Cette sous-commande inspecte les données et fournit une description significative et lisible par l'homme.

sq inspect respecte l'heure de référence définie par l'argument `--time` de niveau supérieur. Il utilise l'heure de référence pour déterminer quelles signatures de liaison sont actives.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Inspecter les certificats avec l'empreinte ou l'ID de clé spécifié(e)
--cert-domain=DOMAINE
Inspecter les certificats où un ID utilisateur inclut une adresse e-mail pour le domaine spécifié (note : les ID utilisateur ne sont pas authentifiés)
--cert-email=EMAIL
Inspecter les certificats où un ID utilisateur inclut l'adresse e-mail spécifiée (note : les ID utilisateur ne sont pas authentifiés)
--cert-file=CHEMIN
Lire les certificats depuis CHEMIN
--cert-grep=MOTIF
Inspecter les certificats avec un ID utilisateur qui correspond au motif, sans distinction de casse (note : les ID utilisateur ne sont pas authentifiés)
--cert-userid=IDUTILISATEUR
Inspecter les certificats avec l'ID utilisateur spécifié (note : les ID utilisateur ne sont pas authentifiés)
--certifications
Afficher les certifications tierces
--dump-bad-signatures
Afficher les signatures qui sont définitivement mauvaises

FICHIER
Lire depuis FICHIER ou stdin si FICHIER est '-'
[par défaut : -]

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Inspecter un certificat.

sq inspect juliet.pgp

Montrer à quoi ressemblait le certificat le 21 juillet 2013.

sq inspect --time 20130721 juliet.pgp

Inspecter un message chiffré.

sq inspect message.pgp

Inspecter une signature détachée.

sq inspect document.sig

VOIR AUSSI

sq(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
