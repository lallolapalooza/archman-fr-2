NOM

sq-cert-lint - Vérifier les certificats pour des problèmes

SYNTAXE

sq cert lint [OPTIONS]

DESCRIPTION

Vérifier les certificats pour des problèmes.

`sq cert lint` vérifie les certificats fournis pour les problèmes liés à SHA-1 suivants :


- Si une révocation de certificat utilise SHA-1.


- Si la signature personnelle actuelle pour un ID utilisateur non révoqué utilise SHA-1.


- Si la signature de liaison de sous-clé actuelle pour une sous-clé active non révoquée utilise SHA-1.


- Si une signature de liaison de clé primaire (« backsig ») pour une sous-clé active non révoquée utilise SHA-1.

Les diagnostics sont imprimés sur stderr. À la fin, quelques statistiques sont affichées. Ceci est utile lors de l'examen d'un keyring. Si `--fix` est spécifié et qu'au moins un problème a pu être corrigé, les certificats corrigés sont imprimés sur stdout.

Cet outil ne prend pas en charge les cartes à puce pour le moment. Mais, si seulement les sous-clés sont sur une carte à puce, cet outil peut encore être capable de réparer partiellement le certificat. En particulier, il sera capable de corriger les problèmes avec les signatures personnelles d'ID utilisateur et les signatures de liaison de sous-clé pour les sous-clés capables de chiffrement, mais il ne sera pas capable de générer de nouvelles signatures de liaison de clé primaire pour les sous-clés capables de signature.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Utiliser les certificats avec l'empreinte ou l'ID de clé spécifié
--cert-domain=DOMAINE
Utiliser les certificats où un ID utilisateur inclut une adresse e-mail pour le domaine spécifié
--cert-email=EMAIL
Utiliser les certificats où un ID utilisateur inclut l'adresse e-mail spécifiée
--cert-file=CHEMIN
Lire les certificats depuis CHEMIN
--cert-grep=MOTIF
Utiliser les certificats avec un ID utilisateur qui correspond au motif, sans tenir compte de la casse
--cert-userid=IDUTILISATEUR
Utiliser les certificats avec l'ID utilisateur spécifié
--fix
Tente de corriger les certificats, lorsque c'est possible
--output=FICHIER
Écrire dans le FICHIER spécifié
Si non spécifié, et que le certificat a été lu depuis le magasin de certificats, importe le certificat modifié dans le magasin de certificats. Si non spécifié, et que le certificat a été lu depuis un fichier, écrit le certificat modifié sur stdout.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES


Collecter des statistiques sur les certificats dans un keyring.

sq cert lint --cert-file certs.pgp

Corriger une clé avec des problèmes connus.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
| sq cert lint --fix --cert-file=- \
| sq cert import

VOIR AUSSI

sq(1), sq-cert(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
