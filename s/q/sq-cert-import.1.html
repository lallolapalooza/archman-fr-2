SQ(1) Commandes utilisateur SQ(1)

NOM

sq-cert-import - Importer des certificats dans le magasin de certificats local

SYNOPSIS

sq cert import [OPTIONS] FICHIER

DESCRIPTION

Importer des certificats dans le magasin de certificats local.

OPTIONS

Options de sous-commande


FICHIER
Lire depuis FICHIER ou l'entrée standard si omis

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Importer un certificat.

sq cert import juliet.pgp

VOIR AUSSI

sq(1), sq-cert(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
