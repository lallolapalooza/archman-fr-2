NOM

sql - exécute une commande sur une base de données déterminée par une dburl

SYNTAXE

sql [options] dburl [commandes]

sql [options] dburl < fichier_commande

#!/usr/bin/sql --shebang [options] dburl

DESCRIPTION

GNU sql vise à fournir une interface simple et unifiée pour accéder aux bases de données via tous les différents clients en ligne de commande des bases de données. Jusqu'à présent, l'accent a été mis sur la fourniture d'un moyen commun de spécifier les informations de connexion (protocole, nom d'utilisateur, mot de passe, nom d'hôte et numéro de port), la taille (taille de la base de données et des tables) et l'exécution des requêtes.

La base de données est adressée en utilisant une DBURL. Si les commandes sont omises, vous obtiendrez le shell interactif de cette base de données.

GNU sql est souvent utilisé en combinaison avec GNU parallel.

dburl
Une DBURL a la syntaxe suivante : [sql:]vendor:// [[user][:password]@][host][:port]/[database][?sqlquery]

Voir la section DBURL ci-dessous.

commandes
Les commandes SQL à exécuter. Chaque argument sera suivi d'un retour à la ligne.

Exemple : "SELECT * FROM foo;" "SELECT * FROM bar;"

Si les arguments contiennent '\n' ou '\x0a', ils seront remplacés par un retour à la ligne :

Exemple : "SELECT * FROM foo;\n SELECT * FROM bar;"

Si aucune commande n'est donnée, SQL est lu depuis le clavier ou STDIN.

Exemple : echo 'SELECT * FROM foo;' | sql mysql:///

--csv
Sortie CSV.
--db-size
--dbsize
Taille de la base de données. Affiche la taille de la base de données sur disque. Pour Oracle, cela nécessite un accès en lecture à la table dba_data_files - l'utilisateur system possède cet accès.
--help
-h
Affiche un résumé des options de GNU sql et quitte.
--html
Sortie HTML. Active la sortie tabulaire HTML.
--json
--pretty
Sortie JSON formatée.
--list-databases
--listdbs
--show-databases
--showdbs
Liste les bases de données (espaces de table) dans la base de données.
--listproc
--proclist
--show-processlist
Affiche la liste des requêtes en cours d'exécution.
--list-tables
--show-tables
--table-list
Liste les tables de la base de données.
--noheaders
--no-headers
-n
Supprime les en-têtes et les pieds de page et n'affiche que les tuples. Bug dans Oracle : il affiche toujours le nombre de lignes trouvées.
-p pass-through
La chaîne suivant -p sera passée en arguments au programme de connexion à la base de données. Plusieurs -p seront joints par un espace. Exemple : passer '-U' et le nom d'utilisateur au programme :

-p "-U scott" peut aussi s'écrire -p -U -p scott.

--precision <rfc3339|h|m|s|ms|u|ns>
Précision des horodatages.

Spécifie le format des horodatages de sortie : rfc3339, h, m, s, ms, u ou ns.

-r
Essayer 3 fois. Version courte de --retries 3.
--retries ntimes
Essayer ntimes fois. Si le programme client retourne une erreur, réessayer la commande. La valeur par défaut est --retries 1.
--sep string
-s string
Séparateur de champs. Utilise string comme séparateur entre les colonnes.
--skip-first-line
Ne pas utiliser la première ligne d'entrée (utilisé par GNU sql lui-même lorsqu'il est appelé avec --shebang).
--table-size
--tablesize
Taille des tables. Affiche la taille des tables dans la base de données.
--verbose
-v
Affiche la commande envoyée.
--version
-V
Affiche la version de GNU sql et quitte.
--shebang
-Y
GNU sql peut être appelé comme commande shebang (#!) en tant que première ligne d'un script. Comme ceci : 
#!/usr/bin/sql -Y mysql:///
SELECT * FROM foo;

Pour que cela fonctionne, --shebang ou -Y doit être défini comme première option.

DBURL

Une DBURL a la syntaxe suivante : [sql:]vendor:// [[user][:password]@][host][:port]/[database][?sqlquery]

Pour citer des caractères spéciaux, utilisez l'encodage % spécifié dans http://tools.ietf.org/html/rfc3986#section-2.1 (Par exemple, un mot de passe contenant '/' contiendrait '%2F').

csv:///%2Ftmp%2Fparallel-bug-56096/mytable csv:////tmp/parallel-bug-56096/mytable mysql://me@/me/ mysql:////

sqlite3:///%2Frun%2Fshm%2Fparallel.db sqlite3:///%2Frun%2Fshm%2Fparallel.db/table sqlite:///%2Ftmp%2Ffile.sqlite?SELECT csv:///%2Ftmp%2Fparallel-CSV/OK csv:///%2Fmust%2Ffail/fail sqlite3:///%2Frun%2Fshm%2Fparallel.db

Exemples :

mysql://scott:tiger@my.example.com/mydb
influxdb://scott:tiger@influxdb.example.com/foo
sql:oracle://scott:tiger@ora.example.com/xe
postgresql://scott:tiger@pg.example.com/pgdb
pg:///
postgresqlssl://scott@pg.example.com:3333/pgdb
sql:sqlite2:////tmp/db.sqlite?SELECT * FROM foo;
sqlite3:///../db.sqlite3?SELECT%20*%20FROM%20foo;

Fournisseurs actuellement supportés :

  • MySQL (mysql) avec SSL (mysqls, mysqlssl)
  • Oracle (oracle, ora)
  • PostgreSQL (postgresql, pg, pgsql, postgres) avec SSL (postgresqlssl, pgs, pgsqlssl, postgresssl, pgssl, postgresqls, pgsqls, postgress)
  • SQLite2 (sqlite, sqlite2)
  • SQLite3 (sqlite3)
  • InfluxDB 1.x (influx, influxdb) avec SSL (influxdbssl, influxdbs, influxs, influxssl)

Les alias doivent commencer par ':' et sont lus à partir de /etc/sql/aliases et ~/.sql/aliases. Les alias ~/.sql/aliases de l'utilisateur ne doivent être lisibles que par l'utilisateur.

Exemple d'alias :

:myalias1 pg://scott:tiger@pg.example.com/pgdb
:myalias2 ora://scott:tiger@ora.example.com/xe
# Forme courte de mysql://`whoami`:nopassword@localhost:3306/`whoami`
:myalias3 mysql:///
# Forme courte de mysql://`whoami`:nopassword@localhost:33333/mydb
:myalias4 mysql://:33333/mydb
# Alias pour un alias
:m      :myalias4
# L'alias le plus court possible
:       sqlite2:////tmp/db.sqlite
# Incluant une requête SQL
:query  sqlite:////tmp/db.sqlite?SELECT * FROM foo;

EXEMPLES

Obtenir une invite interactive

L'utilisation la plus basique de GNU sql est d'obtenir

et une invite interactive :

sql sql:oracle://scott:tiger@ora.example.com/xe

Si vous avez configuré un alias, vous pouvez faire :

sql :myora

Exécuter une requête

Pour exécuter une requête directement depuis la ligne de commande :

sql :myalias "SELECT * FROM foo;"

Oracle nécessite des sauts de ligne après chaque instruction. Ceci peut être fait comme suit :

sql :myora "SELECT * FROM foo;" "SELECT * FROM bar;"

Ou ceci :

sql :myora "SELECT * FROM foo;\nSELECT * FROM bar;"

Copier une base de données PostgreSQL

Pour copier une base de données PostgreSQL, utilisez pg_dump pour générer le dump et GNU sql pour l'importer :

pg_dump pg_database | sql pg://scott:tiger@pg.example.com/pgdb

Vider toutes les tables d'une base de données MySQL

En utilisant GNU parallel, il est facile de vider toutes les tables sans les supprimer :

sql -n mysql:/// 'show tables' | parallel sql mysql:/// DELETE FROM {};

Supprimer toutes les tables d'une base de données PostgreSQL

Pour supprimer toutes les tables d'une base de données PostgreSQL, faites :

sql -n pg:/// '\dt' | parallel --colsep '\|' -r sql pg:/// DROP TABLE {2};

Exécuter comme un script

Au lieu de faire :

sql mysql:/// < sqlfile

vous pouvez combiner le fichier sql avec le DBURL pour créer un script UNIX. Créez un script appelé demosql :

#!/usr/bin/sql -Y mysql:///

SELECT * FROM foo;

Ensuite, faites :

chmod +x demosql; ./demosql

Utiliser --colsep pour traiter plusieurs colonnes

Utilisez --colsep de GNU parallel pour séparer les colonnes :

sql -s '\t' :myalias 'SELECT * FROM foo;' | parallel --colsep '\t' do_stuff {4} {1}

Réessayer si la connexion échoue

Si l'accès à la base de données échoue occasionnellement, --retries peut aider à garantir le succès de la requête :

sql --retries 5 :myalias 'SELECT * FROM really_big_foo;'

Obtenir des informations sur le système de base de données en cours d'exécution

Afficher la taille de la base de données :

sql --db-size :myalias

Lister les tables :

sql --list-tables :myalias

Lister la taille des tables :

sql --table-size :myalias

Lister les processus en cours :

sql --show-processlist :myalias

SIGNALEMENT DE BOGUES

GNU sql fait partie de GNU parallel. Signalez les bogues à <bug-parallel@gnu.org>.

DÉPENDANCES

GNU sql utilise Perl. Si mysql est installé, les dburls MySQL fonctionneront. Si psql est installé, les dburls PostgreSQL fonctionneront. Si sqlite est installé, les dburls SQLite2 fonctionneront. Si sqlite3 est installé, les dburls SQLite3 fonctionneront. Si sqlplus est installé, les dburls Oracle fonctionneront. Si rlwrap est installé, GNU sql aura un historique de commandes pour Oracle.

/etc/sql/aliases - alias communs avec DBURLs
