NOM

sq-key-subkey-revoke - Révoquer une sous-clé

SYNOPHIS

sq key subkey revoke [OPTIONS]

DESCRIPTION

Révoque une sous-clé.

Crée un certificat de révocation pour une sous-clé.

Si `--revoker` ou `--revoker-file` est fourni, alors cette clé est utilisée pour créer le certificat de révocation. Si cette clé est différente de la clé qui est révoquée, cela résulte en une révocation par un tiers. Ceci est normalement utile uniquement si le propriétaire du certificat a désigné la clé comme révocateur désigné.

`sq key subkey revoke` respecte l'heure de référence définie par l'argument de niveau supérieur `--time`. Lorsqu'elle est définie, elle utilise l'heure spécifiée au lieu de l'heure actuelle pour déterminer quelles clés sont valides, et elle définit l'heure de création du certificat de révocation à l'heure de référence au lieu de l'heure actuelle.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Révoque les sous-clés spécifiées sur la clé avec l'empreinte ou l'ID de clé spécifié
--cert-email=EMAIL
Révoque les sous-clés spécifiées sur la clé où un ID utilisateur inclut l'adresse e-mail spécifiée
--cert-file=CHEMIN
Révoque les sous-clés spécifiées sur la clé lue à partir du CHEMIN
--cert-userid=IDUTILISATEUR
Révoque les sous-clés spécifiées sur la clé avec l'ID utilisateur spécifié
--key=EMPREINTE|IDCLEF
Révoque la sous-clé spécifiée
--message=MESSAGE
Un texte court et explicatif
Le texte est montré à un spectateur du certificat de révocation, et explique pourquoi la sous-clé a été révoquée. Par exemple, si Alice a créé une nouvelle clé, elle générerait un certificat de révocation `superseded` pour son ancienne clé, et pourrait inclure le message « J'ai créé une nouvelle sous-clé, veuillez rafraîchir le certificat. »
--output=FICHIER
Écrit dans le FICHIER spécifié
Si non spécifié, et que le certificat a été lu à partir du magasin de certificats, importe le certificat modifié dans le magasin de certificats. Si non spécifié, et que le certificat a été lu à partir d'un fichier, écrit le certificat modifié sur la sortie standard.
--reason=RAISON
La raison de la révocation
Si la raison s'est produite dans le passé, vous devriez le spécifier en utilisant l'argument `--time`. Cela permet aux implémentations OpenPGP de raisonner plus précisément sur les artefacts dont la validité dépend de la validité de l'ID utilisateur.
[valeurs possibles : compromised, superseded, retired, unspecified]
--revoker=EMPREINTE|IDCLEF
Utilise la clé avec l'empreinte ou l'ID de clé spécifié pour créer le certificat de révocation
Signe le certificat de révocation en utilisant la clé spécifiée. Par défaut, le certificat révoqué est utilisé. En utilisant cette option, il est possible de créer une révocation par un tiers.
--revoker-email=EMAIL
Utilise la clé où un ID utilisateur inclut l'adresse e-mail spécifiée pour créer le certificat de révocation
Signe le certificat de révocation en utilisant la clé spécifiée. Par défaut, le certificat révoqué est utilisé. En utilisant cette option, il est possible de créer une révocation par un tiers.
--revoker-file=CHEMIN
Lit la clé à partir du CHEMIN pour créer le certificat de révocation
Signe le certificat de révocation en utilisant la clé spécifiée. Par défaut, le certificat révoqué est utilisé. En utilisant cette option, il est possible de créer une révocation par un tiers.
--revoker-userid=IDUTILISATEUR
Utilise la clé avec l'ID utilisateur spécifié pour créer le certificat de révocation
Signe le certificat de révocation en utilisant la clé spécifiée. Par défaut, le certificat révoqué est utilisé. En utilisant cette option, il est possible de créer une révocation par un tiers.
--signature-notation NOM VALEUR
Ajoute une notation à la signature
Le nom d'une notation définie par l'utilisateur doit être de la forme `nom@un.domaine.que.vous.contrôlez.org`. Si le nom de la notation commence par un `!`, alors la notation est marquée comme étant critique. Si un consommateur d'une signature ne comprend pas une notation critique, alors il ignorera la signature. La notation est marquée comme étant lisible par l'homme.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Révoque la sous-clé de signature d'Alice.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 --reason \
retired --message "Rotation de sous-clé."

Révoque les sous-clés de signature et de chiffrement d'Alice.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728 --reason \
retired --message "Rotation de sous-clé."
