NOM

sqlite3 - une interface pour le moteur de base de données SQLite3

SYNTAXE

sqlite3 nom_commande ?fichier_nom?

DESCRIPTION

SQLite3 est un moteur de base de données SQL autonome, sans configuration, transactionnel. Cette extension fournit une interface facile à utiliser pour accéder aux fichiers de base de données SQLite à partir de Tcl.

Pour une documentation complète, consultez https://sqlite.org/ et en particulier https://sqlite.org/tclsqlite.html.
