SQ(1) Commandes utilisateur SQ(1)

NOM

sq-config-inspect-paths - Inspecte les chemins pertinents

SYNTAXE

sq config inspect paths [OPTIONS]

DESCRIPTION

Inspecte les chemins pertinents.

Affiche les chemins utilisés par sq, tels que l'emplacement du répertoire personnel, du fichier de configuration, du magasin de certificats, du magasin de clés, etc.

OPTIONS

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Inspecte les chemins pertinents.

sq config inspect paths

VOIR AUSSI

sq(1), sq-config(1), sq-config-inspect(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
