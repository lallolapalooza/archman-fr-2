subroutine sqrt02 (m, n, k, a, af, q, r, lda, tau, work, lwork, rwork, result)
SQRT02

Documentation de la fonction/sous-programme

sous-programme sqrt02 (entier m, entier n, entier k, reel, dimension( lda, * ) a, reel, dimension( lda, * ) af, reel, dimension( lda, * ) q, reel, dimension( lda, * ) r, entier lda, reel, dimension( * ) tau, reel, dimension( lwork ) work, entier lwork, reel, dimension( * ) rwork, reel, dimension( * ) result)

SQRT02

Objectif :

!>
!> SQRT02 teste SORGQR, qui génère une matrice m par n, Q, avec des colonnes
!> orthonormales, définie comme le produit de k réflecteurs élémentaires.
!>
!> Étant donné la factorisation QR d'une matrice m par n, A, SQRT02 génère
!> la matrice orthogonale Q définie par la factorisation des k premières colonnes
!> de A ; elle compare R(1:n,1:k) avec Q(1:m,1:n)'*A(1:m,1:k),
!> et vérifie que les colonnes de Q sont orthonormales.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q à générer. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q à générer.
!>          M >= N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice m par n, A, qui a été factorisée par SQRT01.
!>

AF

!>          AF est un tableau REEL, dimension (LDA,N)
!>          Détails de la factorisation QR de A, tels que retournés par SGEQRF.
!>          Voir SGEQRF pour plus de détails.
!>

Q

!>          Q est un tableau REEL, dimension (LDA,N)
!>

R

!>          R est un tableau REEL, dimension (LDA,N)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et R. LDA >= M.
!>

TAU

!>          TAU est un tableau REEL, dimension (N)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation QR dans AF.
!>

WORK

!>          WORK est un tableau REEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
