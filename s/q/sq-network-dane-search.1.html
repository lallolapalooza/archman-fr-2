NOM

sq-network-dane-search - Récupérer des certificats en utilisant DANE

SYNTAXE

sq network dane search [OPTIONS] ADRESSE

DESCRIPTION

Récupère des certificats en utilisant DANE.

Par défaut, tous les certificats retournés sont stockés dans le magasin de certificats local. Ceci peut être remplacé en utilisant l'option `--output`.

Lorsqu'un certificat est récupéré via DANE et importé dans le magasin de certificats local, tous les User IDs ayant l'adresse e-mail recherchée sont certifiés avec une clé locale spécifique à DANE. Ce certificat proxy est à son tour certifié comme une CA minimalement fiable (montant de confiance : 1 sur 120) par la racine de confiance locale. Le niveau de confiance de la CA proxy DANE peut être ajusté en utilisant `sq pki link add` ou `sq pki link retract` de la manière habituelle.

OPTIONS

Options de sous-commande

--all
Récupère les mises à jour pour tous les certificats connus
--output=FICHIER
Écrit dans FICHIER (ou stdout si omis) au lieu d'importer dans le magasin de certificats

ADRESSE
Récupère le(s) certificat(s) pour ADRESSE

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Récupérer le certificat d'Alice via DANE.

sq network dane search alice@example.org

Récupérer les mises à jour pour tous les certificats connus via DANE.

sq network dane search --all

VOIR AUSSI

sq(1), sq-network(1), sq-network-dane(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
