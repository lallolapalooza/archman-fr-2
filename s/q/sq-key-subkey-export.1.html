SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key-subkey-export - Exporter le matériel de clé secrète depuis le magasin de clés secrètes

SYNTAXE

sq key subkey export [OPTIONS]

DESCRIPTION

Exporte le matériel de clé secrète depuis le magasin de clés secrètes.

Exporte le matériel de clé secrète. Notez que même si le matériel de clé secrète est disponible, il peut ne pas être exportable. Par exemple, le matériel de clé secrète stocké sur un module matériel de sécurité ne peut généralement pas être exporté de l'appareil.

L'intégralité du certificat est exportée, mais seul le matériel de clé secrète de la clé spécifiée est exporté. Une erreur est renvoyée si le matériel de clé secrète pour la clé spécifiée n'est pas disponible.

Si vous souhaitez exporter tout le matériel de clé secrète associé à un certificat, utilisez `sq key export`.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Utiliser les certificats avec l'empreinte ou l'ID de clé spécifié(e)
--cert-email=EMAIL
Utiliser les certificats où un ID utilisateur inclut l'adresse e-mail spécifiée
--cert-userid=IDUTILISATEUR
Utiliser les certificats avec l'ID utilisateur spécifié
--key=EMPREINTE|IDCLEF
Exporter le matériel de clé secrète pour la clé primaire ou la sous-clé spécifiée
--output=FICHIER
Écrire dans FICHIER ou stdout si omis
[par défaut : -]

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Exporter les sous-clés de signature et de chiffrement d'Alice, mais pas sa clé primaire ni sa sous-clé d'authentification.

sq key subkey export \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728

VOIR AUSSI

sq(1), sq-key(1), sq-key-subkey(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
