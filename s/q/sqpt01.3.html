real function sqpt01 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, integer lda, real, dimension( * ) tau, integer, dimension( * ) jpvt, real, dimension( lwork ) work, integer lwork)

SQPT01

But :

!>
!> SQPT01 teste la factorisation QR avec pivotement d'une matrice A. Le
!> tableau AF contient la factorisation QR (éventuellement partielle) de A, où
!> le triangle supérieur de AF(1:k,1:k) est un facteur triangulaire partiel,
!> les entrées sous la diagonale dans les k premières colonnes sont les
!> vecteurs de Householder, et le reste de AF contient une matrice partiellement mise à jour.
!>
!> Cette fonction renvoie ||A*P - Q*R|| / ( ||norme(A)||*eps*max(M,N) )
!> où || . || est la norme matricielle unitaire.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes des matrices A et AF.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et AF.
!>

K

!>          K est un ENTIER
!>          Le nombre de colonnes de AF qui ont été réduites
!>          en forme triangulaire supérieure.
!>

A

!>          A est un tableau REEL, de dimension (LDA, N)
!>          La matrice originale A.
!>

AF

!>          AF est un tableau REEL, de dimension (LDA,N)
!>          La sortie (éventuellement partielle) de SGEQPF. Le triangle supérieur
!>          de AF(1:k,1:k) est un facteur triangulaire partiel, les entrées
!>          sous la diagonale dans les k premières colonnes sont les vecteurs de
!>          Householder, et le reste de AF contient une matrice partiellement mise à jour.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A et AF.
!>

TAU

!>          TAU est un tableau REEL, de dimension (K)
!>          Détails des transformations de Householder tels que retournés par
!>          SGEQPF.
!>

JPVT

!>          JPVT est un tableau ENTIER, de dimension (N)
!>          Informations de pivot telles que retournées par SGEQPF.
!>

WORK

!>          WORK est un tableau REEL, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK. LWORK >= M*N+N.
!>
