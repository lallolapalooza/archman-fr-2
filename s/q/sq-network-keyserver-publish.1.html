SQ(1) Commandes utilisateur SQ(1)

NOM

sq-network-keyserver-publish - Publier des certificats sur les serveurs de clés

SYNOPIS

sq network keyserver publish [OPTIONS]

DESCRIPTION

Publie des certificats sur les serveurs de clés.

Envoie des certificats aux serveurs de clés configurés pour publication. Par défaut, les certificats sont envoyés à `hkps://keys.openpgp.org`, `hkps://mail-api.proton.me`, `hkps://keys.mailvelope.com`, `hkps://keyserver.ubuntu.com` et `hkps://sks.pod01.fleetstreetops.com`. Ceci peut être modifié en utilisant `--servers`.

OPTIONS

Options de sous-commande

--cert=EMPREINTE|IDCLEF
Utiliser les certificats avec l'empreinte ou l'ID de clé spécifié(e)
--cert-domain=DOMAINE
Utiliser les certificats où un ID utilisateur inclut une adresse e-mail pour le domaine spécifié
--cert-email=EMAIL
Utiliser les certificats où un ID utilisateur inclut l'adresse e-mail spécifiée
--cert-file=CHEMIN
Lire les certificats depuis CHEMIN
--cert-userid=IDUTILISATEUR
Utiliser les certificats avec l'ID utilisateur spécifié
--server=URI
Définir un serveur de clés à utiliser (peut être donné plusieurs fois)
La valeur par défaut peut être modifiée dans le fichier de configuration en utilisant le réglage `network.keyserver.servers`.
[défaut : hkps://keys.openpgp.org, hkps://mail-api.proton.me, hkps://keys.mailvelope.com, hkps://keyserver.ubuntu.com, hkps://sks.pod01.fleetstreetops.com]

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Publier le certificat d'Alice sur les serveurs de clés par défaut.

sq network keyserver publish --cert-email=alice@example.org

VOIR AUSSI

sq(1), sq-network(1), sq-network-keyserver(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
