SQ(1) Commandes utilisateur SQ(1)

NOM

sq-key-subkey - Gérer les sous-clés

SYNTAXE

sq key subkey add [OPTIONS]
sq key subkey export [OPTIONS]
sq key subkey delete [OPTIONS]
sq key subkey password [OPTIONS]
sq key subkey expire [OPTIONS]
sq key subkey revoke [OPTIONS]
sq key subkey bind [OPTIONS]

DESCRIPTION

Gérer les sous-clés.

Ajouter de nouvelles sous-clés à un certificat existant, modifier leur expiration, et les révoquer.

SOUS-COMMANDES

sq key subkey add

Ajouter une nouvelle sous-clé à un certificat.

Une sous-clé a une ou plusieurs capacités.

`--can-sign` définit la capacité de signature, et signifie que la clé peut être utilisée pour signer. `--can-authenticate` définit la capacité d'authentification, et signifie que la clé peut être utilisée pour l'authentification (par exemple, en tant que clé SSH). `--can-certify` définit la capacité de certification, et signifie que la clé peut être utilisée pour faire des certifications tierces. Ces capacités peuvent être combinées.

`--can-encrypt=storage` définit la capacité de chiffrement de stockage, et signifie que la clé peut être utilisée pour le chiffrement de stockage. `--can-encrypt=transport` définit la capacité de chiffrement de transport, et signifie que la clé peut être utilisée pour le chiffrement de transport. `--can-encrypt=universal` définit les deux capacités de chiffrement de stockage et de transport, et signifie que la clé peut être utilisée pour le chiffrement de stockage et de transport. Les capacités de chiffrement ne doivent pas être combinées avec les capacités de signature ou d'authentification.

Normalement, `sq` demande à l'utilisateur un mot de passe pour chiffrer le matériel de la clé secrète. Le mot de passe de la nouvelle sous-clé peut être différent des autres clés. En utilisant `--without-password`, `sq` ne demande pas de mot de passe et ne protège pas la sous-clé par mot de passe.

Par défaut, une nouvelle sous-clé n'expire pas d'elle-même. Cependant, sa période de validité est limitée par celle du certificat. L'utilisation de l'argument `--expiration` permet de définir une autre date d'expiration.

`sq key subkey add` respecte l'heure de référence définie par l'argument `--time` de niveau supérieur. Elle définit l'heure de création de la sous-clé à l'heure spécifiée.

sq key subkey export

Exporter le matériel de clé secrète depuis le magasin de clés secrètes.

Exporte le matériel de clé secrète. Notez que même si le matériel de clé secrète est disponible, il peut ne pas être exportable. Par exemple, le matériel de clé secrète stocké sur un module de sécurité matériel ne peut généralement pas être exporté de l'appareil.

Le certificat entier est exporté, mais seul le matériel de clé secrète de la clé spécifiée est exporté. Une erreur est renvoyée si le matériel de clé secrète pour la clé spécifiée n'est pas disponible.

Si vous souhaitez exporter tout le matériel de clé secrète associé à un certificat, utilisez `sq key export`.

sq key subkey delete

Supprimer le matériel de clé secrète d'un certificat.

Contrairement à `sq key delete`, qui supprime tout le matériel de clé secrète, cette commande ne supprime que le matériel de clé secrète spécifié.

Si le matériel de clé secrète est géré par plusieurs appareils, il est supprimé de tous.

Bien que le matériel de clé secrète soit supprimé, les clés publiques sont conservées. Si vous ne souhaitez plus que les clés soient utilisées, vous devez révoquer les clés en utilisant `sq key subkey revoke`.

sq key subkey password

Changer le mot de passe protégeant le matériel de clé secrète.

Le matériel de clé secrète peut être protégé par un mot de passe. Cette sous-commande change ou efface le mot de passe d'une ou plusieurs clés.

Pour supprimer le mot de passe, utilisez `--clear` ou fournissez un mot de passe de longueur nulle lorsqu'il est demandé pour le nouveau mot de passe.

Si une clé est protégée par un mot de passe et que le mot de passe correct n'a pas été fourni via l'argument `--password-file`, l'utilisateur est invité à entrer le mot de passe. De même, si le nouveau mot de passe n'est pas fourni, l'utilisateur est invité.

sq key subkey expire

Changer la date d'expiration d'une sous-clé.

Cette sous-commande modifie la date d'expiration d'une clé. Pour modifier la date d'expiration du certificat, utilisez la sous-commande `sq key expire`.

Changer la date d'expiration de la clé principale équivaut à changer la date d'expiration du certificat. La date d'expiration d'une sous-clé est limitée par celle du certificat.

sq key subkey revoke

Révoquer une sous-clé.

Crée un certificat de révocation pour une sous-clé.

Si `--revoker` ou `--revoker-file` est fourni, alors cette clé est utilisée pour créer le certificat de révocation. Si cette clé est différente du certificat qui est révoqué, cela entraîne une révocation par un tiers. Ceci est normalement utile uniquement si le propriétaire du certificat a désigné la clé comme un révocateur désigné.

`sq key subkey revoke` respecte l'heure de référence définie par l'argument `--time` de niveau supérieur. Lorsqu'il est défini, il utilise l'heure spécifiée au lieu de l'heure actuelle pour déterminer quelles clés sont valides, et il définit l'heure de création du certificat de révocation à l'heure de référence au lieu de l'heure actuelle.

sq key subkey bind

Lier des clés d'un certificat à un autre.

Cette commande permet à l'utilisateur d'attacher une clé primaire ou une sous-clé attachée à un certificat à un autre certificat. Supposons que vous souhaitiez transitionner vers un nouveau certificat, mais que vous ayez une sous-clé d'authentification sur votre certificat actuel que vous souhaitez conserver car elle permet d'accéder à un serveur et que la mise à jour de sa configuration n'est pas réalisable. Cette commande permet de facilement attacher la sous-clé au nouveau certificat.

Après l'opération, la clé est liée à la fois à l'ancien certificat et au nouveau. Pour supprimer le matériel de clé secrète de l'ancien certificat, utilisez `sq key subkey delete` ou `sq key delete`, selon le cas. Pour révoquer l'ancienne sous-clé ou clé, utilisez `sq key subkey revoke` ou `sq key revoke`, respectivement.

EXEMPLES

sq key subkey add

Ajouter une nouvelle sous-clé capable de signature à la clé d'Alice.

sq key subkey add --can-sign \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key subkey export

Exporter les sous-clés d'Alice capables de signature et de chiffrement, mais pas sa clé primaire ni sa sous-clé capable d'authentification.

sq key subkey export \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728

sq key subkey delete

Supprimer la sous-clé de signature d'Alice.

sq key subkey delete \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8

sq key subkey password

Changer le mot de passe de la clé de signature d'Alice pour le mot de passe du fichier spécifié.

sq key subkey password --new-password-file=fichier-mot-de-passe.txt \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8

Supprimer la protection par mot de passe de la clé de signature d'Alice.

sq key subkey password --password-file=fichier-mot-de-passe.txt \
--clear-password \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8

sq key subkey expire

Changer la sous-clé d'authentification d'Alice

sq-key-subkey(1) — Sequoia PGP

NAME

sq-key-subkey — manage subkeys of a Sequoia PGP certificate

SYNOPSIS

sq key subkey SUBCOMMAND

DESCRIPTION

This page documents the sq key subkey subcommand and its subcommands.

SUBCOMMANDS

The following subcommands are available:

  • sq key subkey add
  • sq key subkey delete
  • sq key subkey export
  • sq key subkey expire
  • sq key subkey revoke
  • sq key subkey bind
  • sq key subkey password

EXAMPLES

sq key subkey add

Add a new signing subkey to Alice's certificate.

sq key subkey add \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1 \
--sign-for=Alice \
--usage=sign

Add a new authentication subkey to Alice's certificate.

sq key subkey add \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1 \
--sign-for=Alice \
--usage=auth

sq key subkey delete

Delete Alice's authentication subkey.

sq key subkey delete \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1

sq key subkey export

Export Alice's signing subkey.

sq key subkey export \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--output=alice-sign.key

Export Alice's signing and encryption subkeys.

sq key subkey export \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728 \
--output=alice-keys.key

sq key subkey expire

Make Alice's signing subkey expire in 6 months.

sq key subkey expire \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--expiration 6m

Make Alice's encryption subkey expire in 6 months.

sq key subkey expire \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1 \
--expiration 6m

sq key subkey revoke

Revoke Alice's signing subkey.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--reason retired \
--message "Subkey rotation."

Revoke Alice's signing subkey and encryption subkeys.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728 \
--reason retired \
--message "Subkey rotation."

sq key subkey bind

Bind Alice's old authentication subkey to Alice's new certificate.

sq key subkey bind \
--cert=C5999E8191BF7B503653BE958B1F7910D01F86E5 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1

Bind a bare key to Alice's certificate. A bare key is a public key without any components or signatures. This simplifies working with raw keys, e.g., keys generated on an OpenPGP card, a TPM device, etc.

sq key subkey bind --keyring=bare.pgp \
--cert=C5999E8191BF7B503653BE958B1F7910D01F86E5 \
--key=B321BA8F650CB16443E06826DBFA98A78CF6562F \
--can-encrypt=universal
