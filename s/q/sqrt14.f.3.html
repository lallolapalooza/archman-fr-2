real function sqrt14 (character trans, integer m, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldx, * ) x, integer ldx, real, dimension( lwork ) work, integer lwork)

SQRT14

But :

!>
!> SQRT14 vérifie si X appartient à l'espace des lignes de A ou de A'. Il le fait
!> en mettant à l'échelle X et A de manière à ce que leurs normes soient dans l'intervalle
!> [sqrt(eps), 1/sqrt(eps)], puis en calculant une factorisation QR de [A,X]
!> (si TRANS = 'T') ou une factorisation LQ de [A',X]' (si TRANS = 'N'),
!> et en retournant la norme du triangle de fin, mise à l'échelle par
!> MAX(M,N,NRHS)*eps.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, vérifie si X appartient à l'espace des lignes de A
!>          = 'T':  Transposée, vérifie si X appartient à l'espace des lignes de A'.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de X.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice A de taille M par N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Si TRANS = 'N', la matrice X de taille N par NRHS.
!>          Si TRANS = 'T', la matrice X de taille M par NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.
!>

WORK

!>          WORK est un tableau REAL de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          longueur du tableau de travail requis
!>          Si TRANS = 'N', LWORK >= (M+NRHS)*(N+2);
!>          si TRANS = 'T', LWORK >= (N+NRHS)*(M+2).
!>
