SQ(1) Commandes utilisateur SQ(1)

NOM

sq-network-keyserver - Récupère et publie des certificats via des serveurs de clés

SYNTAXE

sq network keyserver search [OPTIONS] RECHERCHE
sq network keyserver publish [OPTIONS]

DESCRIPTION

Récupère et publie des certificats via des serveurs de clés.

Le protocole OpenPGP HTTP Keyserver Protocol (HKP) est une méthode pour publier et récupérer des certificats depuis des serveurs de clés.

SOUS-COMMANDES

sq network keyserver search

Récupère des certificats depuis des serveurs de clés.

Par défaut, tous les certificats retournés sont stockés dans le dépôt local de certificats. Ceci peut être outrepassé en utilisant l'option `--output`.

Lorsqu'un certificat est récupéré d'un serveur de clés vérifiant (actuellement, ceci est limité à une liste de serveurs connus : `hkps://keys.openpgp.org`, `hkps://keys.mailvelope.com`, et `hkps://mail-api.proton.me`), et importé dans le dépôt local de certificats, les User IDs sont également certifiés avec une clé locale spécifique au serveur. Ce certificat proxy est à son tour certifié comme une CA minimalement de confiance (montant de confiance : 1 sur 120) par la racine de confiance locale. Le degré de confiance accordé à une CA de serveur de clés proxy peut être ajusté en utilisant `sq pki link add` ou `sq pki link retract` de la manière habituelle.

sq network keyserver publish

Publie des certificats sur des serveurs de clés.

Envoie des certificats aux serveurs de clés configurés pour publication. Par défaut, les certificats sont envoyés à `hkps://keys.openpgp.org`, `hkps://mail-api.proton.me`, `hkps://keys.mailvelope.com`, `hkps://keyserver.ubuntu.com`, et `hkps://sks.pod01.fleetstreetops.com`. Ceci peut être modifié en utilisant `--servers`.

EXEMPLES

sq network keyserver search

Récupère le certificat d'Alice depuis les serveurs de clés par défaut.

sq network keyserver search alice@example.org

Récupère le certificat d'Alice adressé par empreinte depuis les serveurs de clés par défaut.

sq network keyserver search \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Récupère le certificat d'Alice depuis un serveur de clés non défaut.

sq network keyserver search --server=hkps://keys.example.org \
alice@example.org

Récupère les mises à jour pour tous les certificats connus depuis les serveurs de clés par défaut.

sq network keyserver search --all

sq network keyserver publish

Publie le certificat d'Alice sur les serveurs de clés par défaut.

sq network keyserver publish --cert-email=alice@example.org
