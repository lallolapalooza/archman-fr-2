NOM

sq-config - Interroger, inspecter et créer le fichier de configuration

SYNTAXE

sq config get [OPTIONS] NOM
sq config inspect [OPTIONS] SOUS-COMMANDE
sq config template [OPTIONS]

DESCRIPTION

Interroge, inspecte et crée le fichier de configuration.

Cette sous-commande peut être utilisée pour interroger et inspecter le fichier de configuration (emplacement par défaut : $HOME/.config/sequoia/sq/config.toml), et pour créer un modèle qui peut être modifié selon vos préférences.

Fichier de configuration : $HOME/.config/sequoia/sq/config.toml

SOUS-COMMANDES

sq config get

Obtenir les options de configuration.

Récupère la configuration avec la clé donnée. Utilisez `sq config get` pour voir toutes les options disponibles et leurs valeurs.

sq config inspect

Inspecter les détails de configuration effectifs.

Cette sous-commande peut être utilisée pour inspecter divers aspects de la configuration effective, tels que les différents chemins pertinents, la politique cryptographique, la configuration réseau, etc.

sq config template

Écrire un fichier de configuration modèle.

Écrit un modèle contenant les valeurs par défaut dans le fichier donné ou dans la sortie standard. Ceci peut être utilisé comme point de départ pour ajuster la configuration.

EXEMPLES

sq config get

Lister toutes les options de configuration.

sq config get

Obtenir la suite de chiffrement par défaut pour la génération de clés.

sq config get key.generate.cipher-suite

sq config template

Écrire un modèle de configuration.

sq config template

VOIR AUSSI

sq(1), sq-config-get(1), sq-config-inspect(1), sq-config-template(1).

Pour la documentation complète, voir https://book.sequoia-pgp.org/.
