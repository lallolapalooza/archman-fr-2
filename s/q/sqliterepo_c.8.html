NOM

sqliterepo_c - Génère des fichiers de base de données sqlite pour un dépôt au format rpm-md

SYNOPIS

sqliterepo_c [options] <répertoire_dépôt>

OPTIONS

-V --version

Affiche le numéro de version du programme et quitte.

-q --quiet

Exécute silencieusement.

-v --verbose

Exécute en mode verbeux.

-f --force

Écrase les BDD existantes.

--keep-old

Ne supprime pas les anciennes BDD. À utiliser uniquement en combinaison avec --force.

--xz

Utilise xz pour la compression des données du dépôt.

--compress-type <type_compression>

Quel type de compression utiliser.

--checksum <type_somme_controle>

Quel type de somme de contrôle utiliser dans repomd.xml pour les BDD sqlite.

--local-sqlite

Génère les BDD sqlite localement (dans un répertoire de fichiers temporaires). Parfois, sqlite a du mal à générer des BDD sur un montage NFS, utilisez cette option dans de tels cas. Cette option peut entraîner une consommation de mémoire plus élevée si TMPDIR est défini sur /tmp ou non défini du tout, car /tmp est alors utilisé et /tmp est souvent un disque en RAM.
