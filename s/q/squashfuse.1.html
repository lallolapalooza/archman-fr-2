NOM

squashfuse — monter une archive SquashFS avec FUSE

SYNOPSIS

squashfuse [-o options] archive point_de_montage

DESCRIPTION

squashfuse monte le système de fichiers SquashFS archive sur le répertoire point_de_montage. Le système de fichiers peut être démonté en utilisant umount(8) ou fusermount(8). L'implémentation de squashfuse est mono-thread.

Les options supportées par la bibliothèque fuse(8) sont supportées. De plus, les options suivantes sont supportées :

-o offset=N
défale N octets dans l'archive pour le montage
-o subdir=CHEMIN
monter le sous-répertoire CHEMIN comme racine du système de fichiers
-o notify_pipe=CHEMIN
tube nommé qui recevra 's' (succès) ou 'f' (échec) lorsque le point de montage sera prêt

Voici une sélection d'options généralement utiles de la bibliothèque FUSE :

-h, --help
afficher l'aide
-V, --version
afficher la version de FUSE
-d, -o debug
activer la sortie de débogage (implique -f)
-f
opération en premier plan
-o allow_other
autoriser l'accès par d'autres utilisateurs
-o allow_root
autoriser l'accès par le superutilisateur

VOIR AUSSI

fuse(8), fusermount(8), mount(8), umount(8)
