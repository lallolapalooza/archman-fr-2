Paquet: sequoia-sq

SQ(1) Commandes utilisateur SQ(1)

NOM

sq-keyring - Gérer des collections de clés ou de certificats

SYNTAXE

sq keyring list [OPTIONS] FICHIER
sq keyring split [OPTIONS] FICHIER
sq keyring merge [OPTIONS] FICHIER
sq keyring filter [OPTIONS] FICHIER

DESCRIPTION

Gérer des collections de clés ou de certificats.

Les collections de clés ou de certificats (également appelées "keyrings" lorsqu'elles contiennent des clés secrètes, et "certrings" lorsqu'elles n'en contiennent pas) sont un nombre quelconque de certificats concaténés. Cette sous-commande fournit des outils pour lister, diviser, fusionner et filtrer les keyrings.

Note : Dans la documentation de cette sous-commande, nous utilisons parfois les termes clés et certificats de manière interchangeable.

SOUS-COMMANDES

sq keyring list

Lister les clés dans un keyring.

Affiche l'empreinte ainsi que l'identifiant utilisateur principal pour chaque certificat rencontré dans le keyring.

sq keyring split

Diviser un keyring en clés individuelles.

La division d'un keyring en clés individuelles facilite la curation d'un keyring.

L'opération inverse est `sq keyring merge`.

sq keyring merge

Fusionner des clés ou des keyrings en un seul keyring.

Plusieurs versions du même certificat sont fusionnées ensemble. Lorsque des données sont remplacées (par exemple, des clés secrètes), les données du certificat le plus récent sont privilégiées.

sq keyring filter

Joindre des clés dans un keyring en appliquant un filtre.

Cela peut être utilisé pour filtrer des clés en fonction de prédicats donnés, par exemple, s'ils ont un identifiant utilisateur contenant une adresse e-mail avec un domaine spécifique. De plus, les clés peuvent être élaguées pour ne inclure que les composants correspondant aux prédicats.

Si aucun filtre n'est fourni, tout correspond.

Si plusieurs prédicats sont donnés, ils sont combinés par un OU logique, c'est-à-dire qu'une clé correspond si l'un des prédicats correspond. Pour exiger que tous les prédicats correspondent, chaînez plusieurs invocations de cette commande. Voir EXEMPLES pour des inspirations.

Note : cette commande est considérée comme expérimentale et peut changer dans les futures versions. Pour l'indiquer, vous devez fournir le drapeau `--experimental` lors de l'invocation de cette commande.

EXEMPLES

sq keyring list

Lister tous les certificats.

sq keyring list certs.pgp

Lister tous les certificats avec un identifiant utilisateur sur example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp \
| sq keyring list

sq keyring split

Diviser tous les certificats.

sq keyring split certs.pgp

Diviser tous les certificats, en les fusionnant d'abord pour éviter les doublons.

sq keyring merge certs.pgp \
| sq keyring split

sq keyring merge

Fusionner les mises à jour de certificats.

sq keyring merge bob.pgp bob-updates.pgp

sq keyring filter

Convertir toutes les clés en certificats (c'est-à-dire supprimer toute matière de clé secrète).

sq keyring filter --experimental --to-cert certs.pgp

Obtenir tous les certificats avec un identifiant utilisateur sur example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp

Obtenir tous les certificats avec un identifiant utilisateur sur example.org ou example.net.

sq keyring filter --experimental --domain=example.org \
--domain=example.net certs.pgp

Obtenir tous les certificats avec un identifiant utilisateur de nom correspondant à Romeo.

sq keyring filter --experimental --name=Romeo certs.pgp

Obtenir tous les certificats avec un identifiant utilisateur de nom correspondant à Romeo sur example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp \
| sq keyring filter --experimental --name=Romeo

Obtenir tous les certificats avec un identifiant utilisateur sur example.org, en élaguant les autres identifiants utilisateur.

sq keyring filter --experimental --domain=example.org \
--prune-certs certs.pgp
