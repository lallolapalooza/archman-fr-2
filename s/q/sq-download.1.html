SQ(1) Commandes utilisateur SQ(1)

NOM

sq-download - Télécharger et authentifier les données

SYNTAXE

sq download [OPTIONS]

DESCRIPTION

Télécharge et authentifie les données.

Cette commande télécharge les données depuis l'URL spécifiée, vérifie la signature, puis authentifie le signataire. Si le signataire ne peut être authentifié, les données sont supprimées, si possible.

OPTIONS

Options de sous-commande

--cleartext
Vérifie un message signé en clair.
--message
Vérifie un message signé en ligne.
--output=FICHIER
Écrit dans FICHIER ou dans la sortie standard si FICHIER est '-'.
--signature-url=URL
URL de la signature.
Utilisez ceci lorsque la signature est détachée des données.
Si aucune signature n'est spécifiée, la signature est supposée être en ligne.
--signatures=N
Définit le seuil de signatures valides à N.
Si ce seuil n'est pas atteint, le message ne sera pas considéré comme vérifié.
[défaut: 1]
--signer=EMPREINTE|IDCLE
Exige une signature d'un certificat avec l'empreinte ou l'ID de clé spécifié.
--signer-domain=DOMAINE
Exige une signature d'un certificat où un ID utilisateur inclut une adresse e-mail pour le domaine spécifié.
--signer-email=EMAIL
Exige une signature d'un certificat où un ID utilisateur inclut l'adresse e-mail spécifiée.
--signer-file=CHEMIN
Exige une signature d'un certificat lu depuis CHEMIN.
--signer-userid=USERID
Exige une signature d'un certificat avec l'ID utilisateur spécifié.
--url=URL
Les données à télécharger.

Options globales

Voir sq(1) pour une description des options globales.

EXEMPLES

Télécharger et vérifier le fichier de sommes de contrôle Debian 12.

sq download --url=file://debian/SHA512SUMS \
--signature-url=file://debian/SHA512SUMS.sign \
--signer=DF9B9C49EAA9298432589D76DA87E80D6294BE9B \
--output=SHA512SUMS
