NOM

squirtorus - comment les arcs-en-ciel sont fabriqués.

SYNOPIS

squirtorus [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--delay numéro] [--speed numéro] [--count numéro] [--fps]

DESCRIPTION

Un paysage défilant laisse échapper des arcs-en-ciel toroïdaux dans le ciel. Au-dessus, les étoiles s'éteignent lentement.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine sur une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--delay numéro
Délai par image, en microsecondes. Par défaut : 30000 (0,03 seconde).
--speed numéro
Vitesse de défilement. 2.0 signifie deux fois plus vite, 0.5 signifie deux fois moins vite.
--count numéro
Nombre. 1 - 50. Par défaut : 12.
--fps | --no-fps
Indique s'il faut afficher le nombre d'images par seconde en bas de l'écran.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.
