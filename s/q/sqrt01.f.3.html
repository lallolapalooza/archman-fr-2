sous-programme sqrt01 (entier m, entier n, réel, dimension( lda, * ) a, réel, dimension( lda, * ) af, réel, dimension( lda, * ) q, réel, dimension( lda, * ) r, entier lda, réel, dimension( * ) tau, réel, dimension( lwork ) work, entier lwork, réel, dimension( * ) rwork, réel, dimension( * ) result)

SQRT01

But :

!>
!> SQRT01 teste SGEQRF, qui calcule la factorisation QR d'une matrice A de taille m x n,
!> et teste partiellement SORGQR qui forme la matrice orthogonale Q de taille m x m.
!>
!> SQRT01 compare R avec Q'*A, et vérifie que Q est orthogonale.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          La matrice A de taille m x n.
!>

AF

!>          AF est un tableau REEL, de dimension (LDA,N)
!>          Détails de la factorisation QR de A, tels que retournés par SGEQRF.
!>          Voir SGEQRF pour plus de détails.
!>

Q

!>          Q est un tableau REEL, de dimension (LDA,M)
!>          La matrice orthogonale Q de taille m x m.
!>

R

!>          R est un tableau REEL, de dimension (LDA,max(M,N))
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU est un tableau REEL, de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGEQRF.
!>

WORK

!>          WORK est un tableau REEL, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, de dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
