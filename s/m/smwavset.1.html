NOM

smwavset - Programme pour gérer les fichiers multi-onde spectmorph

SYNTAXE

smwavset <commande> [OPTIONS] [ <arguments spécifiques à la commande>... ]

DESCRIPTION

smwavset est un outil en ligne de commande pour gérer les fichiers multi-onde pour SpectMorph. Habituellement, un fichier multi-onde est d'abord initialisé (en utilisant la commande init), puis différents fichiers d'onde sont ajoutés en utilisant la commande add. Après cela, l'encodage de toutes les ondes peut être fait en une seule commande, tout comme le décodage de toutes les ondes.

OPTIONS

smwavset suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux traits d'union ('-').

-h, --help
Affiche un bref message d'aide.
-v, --version
Affiche la version de smwavset.
--args <arguments>
Spécifie des arguments supplémentaires à passer à smenc/smplay. Cela pourrait être --args "-O1" pour l'encodage, ou --args "--no-sines" pour le décodage.
-d, --data-dir
Pour l'encodage/décodage, ceci définit un répertoire de données où les fichiers .wav ou une liste de fichiers .wav (ou .sm), il est important que des ensembles d'ondes différents stockent leurs fichiers dans des répertoires différents (sinon ils écraseront les fichiers wav appartenant à un autre ensemble d'ondes). Spécifier un répertoire de données approprié qui est différent pour chaque ensemble d'ondes est donc généralement nécessaire. La valeur par défaut est /tmp, ce qui convient uniquement pour les tests ; vous devez vous assurer que les scripts configurent une valeur différente.
--format <champ1>,<champ2>,<champ3>,...,<champN>
Définit le format de sortie pour la commande list.
-j <travaux>
Utilise <travaux> travaux parallèles pour l'encodage (pour les systèmes avec plus d'un processeur).

COMMANDES

init [ <options> ] <ensemble_ondes>...
Initialise un nouvel ensemble d'ondes ; peut également initialiser plus d'un ensemble d'ondes spécifié en ligne de commande.
add [ <options> ] <ensemble_ondes> <note_midi> <chemin>
Ajoute un fichier onde à l'ensemble d'ondes, où note_midi est la note midi pour laquelle le fichier onde a été enregistré.
list [ <options> ] <ensemble_ondes>
Liste les fichiers onde contenus dans l'ensemble d'ondes. Le format de sortie pour la commande list peut être spécifié en utilisant l'option format (champs séparés par des virgules). Voir la section CHAMPS pour une liste des champs valides
encode [ <options> ] <nom_fichier_ensemble_ondes> <nom_fichier_ensemble_sm>
Encode un ensemble d'ondes en utilisant smenc.
decode [ <options> ] <nom_fichier_ensemble_sm> <nom_fichier_ensemble_ondes>
Décode un ensemble d'ondes en utilisant smplay.
delta [ <options> ] <nom_fichier_ensemble_ondes1>...<nom_fichier_ensemble_ondesN>
Calcule la différence entre plusieurs ensembles d'ondes. La différence entre le premier et le deuxième ensemble d'ondes est la référence, qui est de 100%. Les autres ensembles d'ondes sont mesurés par rapport à cette référence.
link <ensemble_sm>
Cette commande inclut tous les fichiers .sm auxquels l'ensemble_sm fait référence dans un seul grand fichier. Ceci est utile comme étape finale lors de la construction d'instruments.

CHAMPS

Pour la commande list, les champs valides sont :

note-midi
Note midi de l'entrée audio (0-127)
canal
Canal pour l'entrée audio (0 est le premier canal)
nom-fichier
Nom du fichier de l'entrée audio
velocite-min
Vélocité minimale de l'entrée audio (0-127)
velocite-max
Vélocité maximale de l'entrée audio (0-127)
