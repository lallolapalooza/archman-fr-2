SMBTREE(1) Commandes Utilisateur SMBTREE(1)

NOM

smbtree - Un explorateur réseau smb en mode texte

SYNTAXE

smbtree [-D|--domains] [-S|--servers] [-?|--help] [--usage] [-d|--debuglevel=DEBUGLEVEL] [--debug-stdout] [--configfile=FICHIER_CONFIG] [--option=nom=valeur] [-l|--log-basename=FICHIER_LOG] [--leak-report] [--leak-report-full] [-U|--user=[DOMAINE/]NOM_UTILISATEUR[%MOT_DE_PASSE]] [-N|--no-pass] [--password=CHAINE] [--pw-nt-hash] [-A|--authentication-file=FICHIER] [-P|--machine-pass] [--simple-bind-dn=DN] [--use-kerberos=desired|required|off] [--use-krb5-ccache=CCACHE] [--use-winbind-ccache] [--client-protection=sign|encrypt|off] [-V|--version]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

smbtree est un programme de navigation smb en mode texte. Il est similaire au "Network Neighborhood" trouvé sur les ordinateurs Windows. Il affiche un arbre avec tous les domaines connus, les serveurs dans ces domaines et les partages sur les serveurs.

OPTIONS

-D|--domains

N'affiche qu'une liste de tous les domaines connus par diffusion ou par le navigateur maître.

-S|--servers

N'affiche qu'une liste de tous les domaines et serveurs répondant à la diffusion ou connus par le navigateur maître.

-?|--help

Affiche un résumé des options de ligne de commande.

--usage

Affiche un bref message d'utilisation.

-d|--debuglevel=niveau

niveau est un entier de 0 à 10. La valeur par défaut si ce paramètre n'est pas spécifié est 1 pour les applications client.

Plus cette valeur est élevée, plus les journaux contiendront de détails sur les activités du serveur. Au niveau 0, seuls les erreurs critiques et les avertissements sérieux seront enregistrés. Le niveau 1 est un niveau raisonnable pour une utilisation quotidienne - il génère une petite quantité d'informations sur les opérations effectuées.

Les niveaux supérieurs à 1 généreront une quantité considérable de données de journalisation et ne doivent être utilisés que lors de la recherche d'un problème. Les niveaux supérieurs à 3 sont conçus pour être utilisés uniquement par les développeurs et génèrent d'énormes quantités de données de journalisation, dont la plupart sont extrêmement cryptiques.

Notez que la spécification de ce paramètre ici remplacera le paramètre log level du fichier /etc/samba/smb.conf.

--debug-stdout

Redirigera la sortie de débogage vers STDOUT. Par défaut, tous les clients enregistrent sur STDERR.

--configfile=<fichier de configuration>

Le fichier spécifié contient les détails de configuration requis par le client. Les informations de ce fichier peuvent être générales pour le client et le serveur ou fournir uniquement des options spécifiques au client comme client smb encrypt. Voir /etc/samba/smb.conf pour plus d'informations. Le nom du fichier de configuration par défaut est déterminé lors de la compilation.

--option=<nom>=<valeur>

Définit l'option smb.conf(5) "<nom>" à la valeur "<valeur>" depuis la ligne de commande. Ceci remplace les valeurs par défaut compilées et les options lues depuis le fichier de configuration. Si un nom ou une valeur inclut un espace, entourez tout --option=nom=valeur de guillemets.

-l|--log-basename=répertoire_journal

Nom de base du répertoire pour les fichiers de journalisation/débogage. L'extension ".progname" sera ajoutée (par exemple, log.smbclient, log.smbd, etc.). Le fichier journal n'est jamais supprimé par le client.

--leak-report

Active le rapport de fuite talloc à la sortie.

--leak-report-full

Active le rapport complet de fuite talloc à la sortie.

-V|--version

Affiche le numéro de version du programme.

-U|--user=[DOMAINE\]NOM_UTILISATEUR[%MOT_DE_PASSE]

Définit le nom d'utilisateur SMB ou le nom d'utilisateur et le mot de passe.

Si %MOT_DE_PASSE n'est pas spécifié, l'utilisateur sera invité. Le client vérifiera d'abord la variable d'environnement USER (qui est également autorisée à contenir le mot de passe séparé par un %), puis la variable LOGNAME (qui n'est pas autorisée à contenir de mot de passe) et si l'un ou l'autre existe, la valeur est utilisée. Si ces variables d'environnement ne sont pas trouvées, le nom d'utilisateur trouvé dans un cache d'identification Kerberos peut être utilisé.

Une troisième option consiste à utiliser un fichier d'identification qui contient le texte en clair du nom d'utilisateur et du mot de passe. Cette option est principalement destinée aux scripts où l'administrateur ne souhaite pas passer les informations d'identification en ligne de commande ou via des variables d'environnement. Si cette méthode est utilisée, assurez-vous que les autorisations du fichier restreignent l'accès aux utilisateurs non désirés. Voir le paramètre -A pour plus de détails.

Soyez prudent quant à l'inclusion de mots de passe dans les scripts ou à la transmission de valeurs fournies par l'utilisateur en ligne de commande. Par sécurité, il est préférable de laisser l'outil client Samba demander le mot de passe si nécessaire, ou d'obtenir le mot de passe une fois avec kinit.

Bien que Samba tente de supprimer le mot de passe du titre de processus (tel que vu dans ps), cela se produit après le démarrage et est donc sujet à une course.

-N|--no-pass

Si spécifié, ce paramètre supprime la demande normale de mot de passe du client à l'utilisateur. Ceci est utile lors de l'accès à un service qui ne nécessite pas de mot de passe.

À moins qu'un mot de passe ne soit spécifié en ligne de commande ou que ce paramètre ne soit spécifié, le client demandera un mot de passe.

Si un mot de passe est spécifié en ligne de commande et que cette option est également définie, le mot de passe sur la ligne de commande sera ignoré en silence et aucun mot de passe ne sera utilisé.

--password

Spécifie le mot de passe en ligne de commande.

Soyez prudent quant à l'inclusion de mots de passe dans les scripts ou à la transmission de valeurs fournies par l'utilisateur en ligne de commande. Par sécurité, il est préférable de laisser l'outil client Samba demander le mot de passe si nécessaire, ou d'obtenir le mot de passe une fois avec kinit.

Si --password n'est pas spécifié, l'outil vérifiera la variable d'environnement PASSWD, suivie de PASSWD_FD qui devrait contenir un numéro de descripteur de fichier (FD) ouvert.

Enfin, il vérifiera PASSWD_FILE (contenant un chemin de fichier à ouvrir). Le fichier ne doit contenir que le mot de passe. Assurez-vous que les autorisations du fichier restreignent l'accès aux utilisateurs non désirés !

Bien que Samba tente de supprimer le mot de passe du titre de processus (tel que vu dans ps), cela se produit après le démarrage et est donc sujet à une course.

--pw-nt-hash

Le mot de passe fourni est le hachage NT.

-A|--authentication-file=nom_fichier

Cette option vous permet de spécifier un fichier à partir duquel lire le nom d'utilisateur et le mot de passe utilisés dans la connexion. Le format du fichier est le suivant : 
username = <valeur>
password = <valeur>
domain   = <valeur>

Assurez-vous que les autorisations du fichier restreignent l'accès aux utilisateurs non désirés !

-P|--machine-pass

Utilise le mot de passe de compte machine stocké.

--simple-bind-dn=DN

DN à utiliser pour une liaison simple.

--use-kerberos=desired|required|off

Ce paramètre détermine si les outils client Samba tenteront de s'authentifier à l'aide de Kerberos. Pour l'authentification Kerberos, vous devez utiliser des noms DNS au lieu d'adresses IP lors de la connexion à un service. Par défaut, les outils client Samba tenteront d'utiliser le cache d'identification Kerberos (ccache) par défaut. Dans le cas où le ccache n'existe pas ou si l'option -U|--user a été spécifiée, les clients demanderont de saisir un mot de passe et obtiendront un ticket Kerberos (kinit) pour vous. Si vous souhaitez utiliser un cache d'identification Kerberos alternatif, utilisez l'option --use-krb5-ccache.

Notez que la spécification de ce paramètre ici remplacera le paramètre client use kerberos du fichier /etc/samba/smb.conf.

--use-krb5-ccache=CCACHE

Spécifie l'emplacement du cache d'identification pour l'authentification Kerberos.

Ceci forcera --use-kerberos=required.

--use-winbind-ccache

Tenter d'utiliser le cache d'identification de winbind.

--client-protection=sign|encrypt|off

Définit la protection de connexion que l'outil client doit utiliser.

Notez que la spécification de ce paramètre ici remplacera le paramètre client protection du fichier /etc/samba/smb.conf.

Si vous avez besoin d'un contrôle plus fin, vous pouvez utiliser : --option=clientsmbencrypt=OPTION, --option=clientipcsigning=OPTION, --option=clientsigning=OPTION.

smbtree(1) — man pages

NAME

smbtree list shares in a directory or domain

SYNOPSIS

smbtree [options]

DESCRIPTION

The smbtree command is a small utility that lists the available network shares on a given server or domain. It displays the information in a tree-like format, showing the relationship between servers and their shares.

OPTIONS

This utility has no command line options.

VERSION

The smbtree man page is part of version 4.23.3 of the Samba suite.

AUTHOR

The original Samba software and related utilities were created by Andrew Tridgell. Samba is now developed by the Samba Team as an Open Source project similar to the way the Linux kernel is developed.

The smbtree man page was written by Jelmer Vernooij.
