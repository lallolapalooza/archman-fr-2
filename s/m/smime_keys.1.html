NOM

smime_keys - Utilitaire pour ajouter un certificat S/MIME à la base de données interne utilisée par mutt

SYNTAXE

smime_keys <opération> [fichier(s) | IDclé [fichier(s)]]

DESCRIPTION

Le but de cet outil est de manipuler la base de données interne des certificats S/MIME utilisés par mutt pour signer les messages électroniques qui seront envoyés ou pour vérifier les messages électroniques reçus et signés avec S/MIME.

OPTIONS

init
aucun fichier nécessaire, initialise la structure du répertoire.
refresh
aucun fichier nécessaire. met à jour les fichiers d'index, y compris le drapeau de confiance / expiration.
list
liste les certificats stockés dans la base de données.
label
IDclé requis. change / supprime / ajoute une étiquette.
remove
IDclé requis.
verify
1=IDclé et optionnellement 2=CRL. Vérifie la chaîne de certificats, et optionnellement si ce certificat est inclus dans la CRL fournie (format PEM). Note : pour vérifier tous les certificats en même temps, remplacez IDclé par "all".
add_cert
certificat requis.
add_chain
trois fichiers requis : 1=Clé, 2=certificat plus 3=certificat(s) intermédiaire(s).
add_p12
un fichier requis. Ajoute une paire clé au magasin. le fichier est PKCS12 (par exemple, exportation depuis netscape).
add_pem
un fichier requis. Ajoute une paire clé au magasin. (fichier converti depuis, par exemple, PKCS12).
add_root
un fichier requis. Ajoute un certificat racine PEM à l'emplacement spécifié dans muttrc (commande smime_verify_*).
