NOM

smbios-type-11 - Chaînes de caractères SMBIOS Type 11

SYNTAXE

/sys/firmware/dmi/entries/11-*/raw

DESCRIPTION

Plusieurs composants du système d'exploitation traitent les chaînes de caractères du vendeur SMBIOS Type 11 qu'un gestionnaire de machine virtuelle (VMM) peut définir et qu'une machine virtuelle (VM) reçoit. Les chaînes de caractères du vendeur SMBIOS Type 11 peuvent jouer un rôle similaire à celui des paramètres de kernel-command-line(7), mais sont généralement sous le contrôle du VMM plutôt que du chargeur de démarrage ou de l'UKI.

Pour plus de détails sur SMBIOS Type 11, consultez les spécifications du System Management BIOS[1].

CHAÎNES DE CARACTÈRES

Les chaînes de caractères suivantes sont prises en charge :

io.systemd.credential:CREDENTIAL=VALUE, io.systemd.credential.binary:CREDENTIAL=VALUE

Ceci permet de passer des informations d'identification système supplémentaires sous forme textuelle ou binaire (Base64) dans le système. Voir systemd.exec(5) et System and Service Credentials[2] pour plus de détails.

Ajouté dans la version 252.

io.systemd.stub.kernel-cmdline-extra=CMDLINE

Ceci permet de configurer des options de ligne de commande du noyau supplémentaires, et est lu par le stub UEFI du noyau. Pour plus de détails, voir systemd-stub(7).

Ajouté dans la version 254.

io.systemd.boot.kernel-cmdline-extra=CMDLINE

Ceci permet de configurer des options de ligne de commande du noyau supplémentaires pour les entrées du Type 1 de la spécification du chargeur de démarrage, et est lu par systemd-boot. Pour plus de détails, voir systemd-boot(7).

Ajouté dans la version 256.

io.systemd.boot-entries.extra:ID=DEFINITION

Ceci permet d'insérer des entrées supplémentaires dans le menu de systemd-boot. Pour plus de détails, voir systemd-boot(7).

Ajouté dans la version 258.
