smpdump(8) Diagnostics Open IB smpdump(8)

Nom

smpdump - vidange les attributs de gestion de sous-réseau InfiniBand

Syntaxe

smpdump [options] <dlid|dr_path> <attribut> [modificateur_attribut]

Description

smpdump est un utilitaire SMP généraliste qui récupère les attributs SM d'un SMA spécifié. Le résultat est vidangé en hexadécimal par défaut.

Options

dlid|drpath
LID ou chemin DR vers le SMA
attribut
ID d'attribut IBA pour l'attribut SM
modificateur_attribut
Modificateur IBA pour l'attribut SM
-s, --string
Affiche les chaînes dans le paquet si possible

Indicateurs d'adressage

-D, --Direct L'adresse spécifiée est une route dirigée

Exemples :
   [options] -D [options] "0"          # port de soi-même
   [options] -D [options] "0,1,2,1,4"  # sortie via le port 1, puis 2, ...
   (Notez que le deuxième nombre dans le chemin spécifié doit correspondre au port
   utilisé. Ceci peut être spécifié en utilisant l'indicateur de sélection de port
   '-P' ou le port trouvé par le processus de sélection automatique.)

-L, --Lid L'adresse spécifiée est un LID

Indicateurs de sélection de port

-C, --Ca <nom_ca> utiliser le nom_ca spécifié.

-P, --Port <port_ca> utiliser le port_ca spécifié.

Sélection du port local

Prise en charge de plusieurs ports/plusieurs CA : lorsqu'aucun périphérique IB ou port n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port ACTIF.
2.
si non trouvé, le premier port ACTIF (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de satisfaire la demande de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utiliser le premier port (critère #1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utiliser le deuxième port (actif/en ligne) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser le port spécifié uniquement.

Indicateurs de débogage

-d
augmente le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
affiche les erreurs d'envoi et de réception (timeouts et autres)

-h, --help affiche le message d'utilisation

-v, --verbose
augmente le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version affiche les informations de version.

Indicateurs de configuration

-t, --timeout <timeout_ms> remplace le délai d'attente par défaut pour les mads sollicités.

--config, -z <fichier_config> spécifie un fichier de configuration alternatif.

Par défaut : /etc/infiniband-diags/ibdiag.conf

Fichiers

Fichier de configuration

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines des options courantes pour tous les outils. Voir le fichier de configuration fourni pour les détails.

Exemples

Exemples de routage dirigé

smpdump -D 0,1,2,3,5 16 # NODE DESC
smpdump -D 0,1,2 0x15 2 # PORT INFO, port 2

Exemples de routage par LID

smpdump 3 0x15 2        # PORT INFO, lid 3 port 2
smpdump 0xa0 0x11       # NODE INFO, lid 0xa0
