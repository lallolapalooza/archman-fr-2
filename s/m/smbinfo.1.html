SMBINFO(1) Manuel des commandes générales SMBINFO(1)

NOM

smbinfo - Programme utilitaire en espace utilisateur pour afficher des informations de fichier spécifiques à SMB pour le système de fichiers client SMB (CIFS) de Linux

SYNTAXE

smbinfo [-v] [-h] [-V] {commande} {objet du système de fichiers}

DESCRIPTION

Cet outil fait partie de la suite cifs-utils.

smbinfo est un programme utilitaire en espace utilisateur pour le système de fichiers client SMB (CIFS) de Linux. Il est destiné à afficher des informations de fichier spécifiques à SMB telles que les descripteurs de sécurité et les quotas.

Cet outil fonctionne en effectuant un appel IOCTL CIFS_QUERY_INFO au client SMB de Linux, qui à son tour émet une requête SMB Query Info et renvoie le résultat. Ceci est différent de getcifsacl qui utilise des attributs de fichier étendus.

OPTIONS

-v
Imprime le numéro de version et quitte.
-V
Sortie verbeuse.
-h
Imprime l'aide expliquant les options de la ligne de commande.

COMMANDE

fileaccessinfo : Imprime la classe FileAccessInformation

filealigninfo : Imprime la classe FileAlignmentInformation

fileallinfo : Imprime la classe FileAllInformation

filebasicinfo : Imprime la classe FileBasicInformation

fileeainfo : Imprime la classe FileEaInformation

filefsfullsizeinfo : Imprime la classe FileFsFullSizeInformation

fileinternalinfo : Imprime la classe FileInternalInformation

filemodeinfo : Imprime la classe FileModeInformation

filepositioninfo : Imprime la classe FilePositionInformation

filestandardinfo : Imprime la classe FileStandardInformation

filestreaminfo : Imprime la classe FileStreamInformation

fsctl-getobjid : Imprime l'ObjectID

getcompression : Imprime le paramètre de compression du fichier.

setcompression -c <no|default|lznt1> : Définit le paramètre de compression pour le fichier.

list-snapshots : Liste les versions précédentes du volume qui supporte ce fichier

quota : Imprime le quota du volume sous la forme - SID Longueur - Heure de modification - Quota utilisé - Seuil de quota - Limite de quota - SID

secdesc : Imprime le descripteur de sécurité sous la forme - Révision - Contrôle - SID Propriétaire - SID Groupe - ACL - Types de fichier - Indicateurs de fichier

keys : Vide l'ID de session, les clés de chiffrement et les clés de déchiffrement afin que le trafic SMB3 de ce montage puisse être déchiffré, par exemple via Wireshark (nécessite root).

gettconinfo : Imprime à la fois l'ID TCON et l'ID de session pour un fichier cifs.

NOTES

La prise en charge par le noyau des utilitaires smbinfo nécessite l'IOCTL CIFS_QUERY_INFO, introduit initialement dans le noyau 4.20 et implémenté uniquement pour les points de montage utilisant SMB2 ou supérieur (voir l'option vers de mount.cifs(8)).

VOIR AUSSI

mount.cifs(8), getcifsacl(1)
