sminfo(8) Diagnostics InfiniBand sminfo(8)

Nom

sminfo - interroger l'attribut SMInfo d'InfiniBand

Syntaxe

sminfo [options] sm_lid | sm_dr_path [modificateur]

Description

Optionnellement, définir et afficher le résultat d'une requête sminfo dans un format lisible par l'homme. Le SM cible est celui listé dans les informations du port local, ou le SM spécifié par le lid SM optionnel ou par le chemin routé directement du SM.

Note : Utiliser sminfo à d'autres fins que des requêtes simples peut être très dangereux et entraîner un dysfonctionnement du SM cible.

Options

-s, --state <état> définir l'état du SM
0 inactif

1 découverte en cours

2 veille

3 maître

-p, --priority <priorité> définir la priorité (0-15)

-a, --activity <val> définir le compteur d'activité

Drapeaux d'adressage

-D, --Direct L'adresse spécifiée est une route dirigée

Exemples :
   [options] -D [options] "0"          # port propre
   [options] -D [options] "0,1,2,1,4"  # sortie via le port 1, puis 2, ...
   (Notez que le deuxième nombre dans le chemin spécifié doit correspondre au port
   utilisé. Ceci peut être spécifié en utilisant le drapeau de sélection de port
   '-P' ou le port trouvé via le processus de sélection automatique.)

-G, --Guid L'adresse spécifiée est un GUID de port

-L, --Lid L'adresse spécifiée est un LID

Drapeaux de sélection de port

-C, --Ca <nom_ca> utiliser le nom_ca spécifié.

-P, --Port <ca_port> utiliser le ca_port spécifié.

Sélection du port local

Support multi-ports/multi-CA : lorsque aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port ACTIF.
2.
si non trouvé, le premier port CONNECTÉ (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de satisfaire la demande de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utiliser le premier port (critère #1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utiliser le deuxième port (actif/connecté) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser le port spécifié uniquement.

Drapeaux de débogage

-d
augmenter le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
afficher les erreurs d'envoi et de réception (timeouts et autres)

-h, --help afficher le message d'aide

-v, --verbose
augmenter le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version afficher les informations de version.

Drapeaux de configuration

-t, --timeout <timeout_ms> remplacer le timeout par défaut pour les MADs sollicitées.

-y, --m_key <clé>
utiliser la M_key spécifiée pour les requêtes. Si une valeur non numérique (comme 'x') est spécifiée, une valeur sera demandée.

--config, -z <fichier_config> spécifier un fichier de configuration alternatif.

Par défaut : /etc/infiniband-diags/ibdiag.conf

Fichiers

FICHIER DE CONFIG

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines options communes à tous les outils. Voir le fichier de configuration fourni pour plus de détails.

Exemples

sminfo                  # sminfo du port local
sminfo 32               # afficher le sminfo du lid 32
sminfo  -G 0x8f1040023  # idem mais en utilisant l'adresse guid
