NOM

smtool - outil pour afficher/modifier les données SpectMorph depuis les fichiers .sm/.smset

SYNTAXE

smtool <fichier_sm>|<fichier_smset> <commande> [ <arguments_spécifiques_commande> ]

DESCRIPTION

smtool est un programme généraliste qui peut effectuer des opérations sur les fichiers .sm/.smset. Certaines opérations extraient des données (comme size), d'autres modifient des données (comme auto-tune). Si un fichier .smset est donné en argument, l'opération est effectuée sur les fichiers .sm individuels contenus dans le fichier .smset.

OPTIONS

Les options de smtool dépendent de la commande utilisée, les arguments spécifiques à la commande sont listés ci-dessous.

COMMANDES

volume <pourcentage>
Calcule l'énergie moyenne des données audio autour de <pourcentage>.
fundamental-freq
Affiche la fréquence fondamentale des données audio.
mix-freq
Affiche la fréquence de mélange (taux d'échantillonnage) des données audio.
zero-values-at-start
Affiche la propriété zero-values-at-start des données audio.
attack
Affiche les paramètres d'attaque des données audio.
size
Affiche un aperçu de la taille en octets des différentes parties des données audio.
loop-params
Affiche les paramètres de boucle des données audio.
noise-params <num_trame>
Affiche le composant de bruit d'une trame des données audio.
frame <num_trame>
Affiche les échantillons originaux et les échantillons reconstruits pour une trame des données audio.
frame-params <num_trame>
Affiche les fréquences/amplitudes d'une trame des données audio.
total-noise
Additionne tous les paramètres de bruit de toutes les trames des données audio.
nan-test
Vérifie si tous les contenus des données de trame sont des NaN.
original-samples
Affiche les échantillons originaux des données audio.
freq <freq_min> <freq_max>
Affiche toutes les entrées de fréquence des données audio dans la plage spécifiée.
spectrum <num_trame>
Compare le spectre original et reconstruit pour une trame donnée.
auto-loop <pourcentage>
Définit une boucle d'une trame qui commence et se termine au même point (donné par <pourcentage>).
tail-loop
Boucle les données audio à la fin en utilisant une boucle d'une trame.
auto-tune
Accordez l'instrument en utilisant les données (40%..60%) pour extraire la fréquence réelle.
tune-all-frames
Accordez chaque trame de l'instrument. Cela supprimera les changements minimaux de fréquence qui sont normaux pour la plupart des instruments, donc cela pourrait sembler artificiel.
auto-volume <pourcentage>
Normalise le volume audio, en utilisant le volume autour de <pourcentage> comme référence.
auto-volume-from-loop
Normalise le volume audio, en utilisant le volume de la partie en boucle comme référence.
