NOM

smproxy - Proxy de gestionnaire de session

SYNTAXE

smproxy [-clientId id] [-restore saveFile] [-version]

OPTIONS

-clientId id
Spécifie l'identifiant de session utilisé par smproxy lors de la session précédente.
-restore saveFile
Spécifie le fichier utilisé par smproxy pour sauvegarder l'état lors de la session précédente.
-version
Affiche la version du programme et quitte.

DESCRIPTION

smproxy permet aux applications X qui ne supportent pas la gestion de session X11R6 de participer à une session X11R6.

Pour que smproxy agisse comme proxy pour une application X, l'une des conditions suivantes doit être remplie :

–
L'application mappe une fenêtre de niveau supérieur contenant la propriété WM_CLIENT_LEADER. Cette propriété fournit un pointeur vers la fenêtre leader du client qui contient les propriétés WM_CLASS, WM_NAME, WM_COMMAND et WM_CLIENT_MACHINE.

ou

–
L'application mappe une fenêtre de niveau supérieur qui ne contient pas la propriété WM_CLIENT_LEADER. Cependant, cette fenêtre de niveau supérieur contient les propriétés WM_CLASS, WM_NAME, WM_COMMAND et WM_CLIENT_MACHINE.

Une application qui supporte le protocole WM_SAVE_YOURSELF recevra un message client WM_SAVE_YOURSELF chaque fois que le gestionnaire de session émettra un point de contrôle ou une fermeture. Cela permet à l'application de sauvegarder son état. Si une application ne supporte pas le protocole WM_SAVE_YOURSELF, le proxy fournira suffisamment d'informations au gestionnaire de session pour redémarrer l'application (en utilisant WM_COMMAND), mais aucun état ne sera restauré.
