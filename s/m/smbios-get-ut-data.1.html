SYNTAXE

smbios-get-ut-data [options]

DESCRIPTION

--help, -h
Affiche ces informations
--cmos_file, -c <args>
Débogage : fichier de vidage CMOS à utiliser au lieu du CMOS physique
--memory_file, -m <args>
Débogage : fichier de vidage mémoire à utiliser au lieu de la mémoire physique
--version, -v
Affiche les informations de version de libsmbios

VOIR AUSSI

La documentation complète de smbios-get-ut-data est maintenue sous forme de manuel Texinfo. Si les programmes info et smbios-get-ut-data sont correctement installés sur votre système, la commande

info smbios-get-ut-data

devrait vous donner accès au manuel complet.
