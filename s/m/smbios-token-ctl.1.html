smbios-token-ctl(1)

Paquet: libsmbios

Licences: GPL, custom

SMBIOS-TOKEN-CTL(1) Commandes utilisateur SMBIOS-TOKEN-CTL(1)

NOM

smbios-token-ctl - ../src/bin/smbios-token-ctl

SYNTAXE

smbios-token-ctl

OPTIONS

--version
affiche la version du programme et quitte
-h, --help
affiche ce message d'aide et quitte
-d, --dump-tokens
Action : déverser la table des jetons
--dump-tokens-csv
Action : déverser la table des jetons au format CSV
--import-token-settings-csv
Action : restaurer les paramètres des jetons à partir d'un déversement CSV de la table
--is-string
Action : renvoyer vrai si le jeton spécifié est une chaîne.
--is-bool
Action : renvoyer vrai si le jeton spécifié est booléen.
--is-active
Action : renvoyer vrai si le jeton booléen spécifié est actif.
--get-string
Action : obtenir la valeur du jeton chaîne.
--activate
Action : activer le jeton booléen spécifié.
--set-string
Action : définir la valeur du jeton chaîne.
-i ID_JETON, --token-id=ID_JETON, --token=ID_JETON
Filtrer uniquement les jetons avec l'ID.
-n NOM_JETON, --token-name=NOM_JETON
Filtrer uniquement les jetons avec le nom.
-s PARAMETRE_JETON, --token-setting=PARAMETRE_JETON
Filtrer uniquement les jetons avec le paramètre.
--token-csv=JETON_CSV
chemin vers le fichier token.csv.
--token-blacklist-csv=JETON_LISTE_NOIRE_CSV
Chemin vers le fichier de liste noire de jetons.
-v, --verbose
Afficher une sortie plus détaillée.
-q, --quiet
Minimiser la sortie du programme. Seules les erreurs et les avertissements sont affichés.
--trace
Activer le traçage détaillé des fonctions.
--logconfig=CONFIG_LOG
Spécifier une configuration de journalisation alternative.
--password=MOT_DE_PASSE
Mot de passe de configuration du BIOS pour les opérations de définition/activation.
-r, --rawpassword
Ne pas convertir automatiquement le mot de passe en codes de balayage.
--memory-dat=FICHIER_MEMOIRE_DAT
Chemin vers un fichier de vidage mémoire à utiliser à la place de la RAM réelle
--cmos-dat=FICHIER_CMOS_DAT
Chemin vers un fichier de vidage CMOS à utiliser à la place du CMOS réel

VOIR AUSSI

La documentation complète de smbios-token-ctl est maintenue sous forme de manuel Texinfo. Si les programmes info et smbios-token-ctl sont correctement installés sur votre site, la commande

info smbios-token-ctl

devrait vous donner accès au manuel complet.
