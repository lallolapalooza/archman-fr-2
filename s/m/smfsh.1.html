NOM

smfsh - Shell SMF

SYNTAXE

smfsh [ -V ] [ fichier ]

OPTIONS

-V
Imprimer la version de libsmf et quitter.
fichier
Charger le fichier.

DESCRIPTION

smfsh, un « shell SMF », est une interface interactive pilotée par commandes pour libsmf, utile pour modifier manuellement les fichiers MIDI. Il a été conçu à l'origine comme aide au débogage pour libsmf.

Il existe quatre groupes de commandes : niveau SMF, niveau piste, niveau événement et autres.

COMMANDES DE NIVEAU SMF

Les commandes de niveau SMF affichent ou modifient les propriétés du smf (c'est-à-dire le fichier MIDI) dans son ensemble.

save fichier
Sauvegarder un fichier. Si le nom de fichier n'est pas donné, le dernier nom de fichier est utilisé.

Notez que cela ne demandera pas de confirmation.

load fichier
Charger un fichier. Si le nom de fichier n'est pas donné, le dernier nom de fichier est utilisé.

Au lieu d'utiliser « load », vous pouvez passer le nom du fichier sur la ligne de commande.

ppqn nouveau-ppqn
Afficher (si utilisé sans paramètre) ou modifier le PPQN (Pouls Par Quiartier de Note, aussi appelé Division).
format nouveau-format
Afficher (si utilisé sans paramètre) ou modifier le format.
tempo
Afficher la carte de tempo. La carte de tempo est calculée automatiquement à partir du contenu du SMF - pour modifier un tempo, ajoutez simplement un événement de changement de tempo en utilisant la commande « add ».
length
Afficher la longueur totale de la chanson. Tout comme la carte de tempo, la longueur du fichier est calculée à partir du contenu du SMF.

COMMANDES DE NIVEAU DE PISTE

Les commandes de niveau de piste affichent ou modifient les propriétés des pistes. Un SMF peut contenir une ou plusieurs pistes.

tracks
Afficher la liste des pistes dans le SMF.
track numéro-de-piste
Afficher les détails d'une piste (si appelé sans paramètre), ou sélectionner la piste avec un numéro donné - par exemple pour afficher les événements qu'elle contient (« events »).
trackadd
Créer une nouvelle piste.
trackrm numéro-de-piste
Supprimer la piste. Si le numéro de piste n'est pas donné, cela supprimera la piste actuellement sélectionnée.

COMMANDES DE NIVEAU D'ÉVÉNEMENT

Les commandes de niveau d'événement affichent ou modifient les propriétés des événements. Les événements sont regroupés en pistes. Une piste peut contenir un nombre quelconque d'événements, y compris zéro.

events
Afficher la liste des événements dans la piste actuelle.
event numéro-d'événement
Afficher des informations sur un événement actuel (si utilisé sans paramètre) ou sélectionner l'événement.
add temps-en-secondes message-midi-en-hex
Ajouter un nouvel événement à la piste actuellement sélectionnée.
rm numéro-d'événement
Supprimer l'événement. Si le numéro d'événement n'est pas donné, cela supprimera l'événement actuellement sélectionné.

AUTRES COMMANDES

Il y a trois commandes dans la catégorie « autres » : « help », « version » et « exit ». Leur signification devrait être évidente.
