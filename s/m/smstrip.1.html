NOM

smstrip - programme pour supprimer les données supplémentaires des fichiers de modèle SpectMorph

SYNTAXE

smstrip FichierSM...

DESCRIPTION

smstrip est un outil qui supprime toutes les données de débogage d'un modèle SpectMorph. Par défaut, smenc inclut plus de données que ce qui est nécessaire pour la lecture dans le FichierSM. Ces données supplémentaires peuvent être supprimées, ce qui réduit considérablement la taille du fichier. Notez que les modèles dépouillés peuvent être créés directement par l'encodeur en utilisant smenc -s.

OPTIONS

smstrip suit la syntaxe habituelle de la ligne de commande GNU, avec les options longues commençant par deux traits d'union ('-').

-h, --help
Affiche un bref message d'aide.
-v, --version
Affiche la version de smstrip.
--keep-samples
Supprime les informations de débogage, mais conserve les données d'échantillon d'origine (utile pour les comparaisons de qualité). Cela réduit bien sûr moins la taille du fichier qu'un dépouillement complet.
