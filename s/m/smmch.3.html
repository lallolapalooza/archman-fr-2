SBLAT3

Objectif :

!>
!> Programme de test pour le niveau 3 BLAS RÉEL.
!>
!> Le programme doit être piloté par un court fichier de données. Les 14 premières
!> lignes du fichier sont lues en utilisant l'entrée dirigée par la liste,
!> les 7 dernières lignes sont lues en utilisant le format ( A7, L2 ). Un exemple
!> annoté de fichier de données peut être obtenu en supprimant les 3 premiers
!> caractères des 20 lignes suivantes :
!> 'sblat3.out'      NOM DU FICHIER DE RÉSUMÉ DE SORTIE
!> 6                 NUMÉRO D'UNITÉ DU FICHIER DE RÉSUMÉ
!> 'SBLAT3.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REBOBINER LE FICHIER INSTANTANÉ APRÈS CHAQUE LIGNE.
!> F        INDICATEUR LOGIQUE, T POUR S'ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 3                 NOMBRE DE VALEURS D'ALPHA
!> 0.0 1.0 0.7       VALEURS D'ALPHA
!> 3                 NOMBRE DE VALEURS DE BÊTA
!> 0.0 1.0 1.3       VALEURS DE BÊTA
!> SGEMM  T METTRE F Pour PAS DE TEST. MÊMES COLONNES.
!> SSYMM  T METTRE F Pour PAS DE TEST. MÊMES COLONNES.
!> STRMM  T METTRE F Pour PAS DE TEST. MÊMES COLONNES.
!> STRSM  T METTRE F Pour PAS DE TEST. MÊMES COLONNES.
!> SSYRK  T METTRE F Pour PAS DE TEST. MÊMES COLONNES.
!> SSYR2K T METTRE F Pour PAS DE TEST. MÊMES COLONNES.
!> SGEMMTR T METTRE F Pour PAS DE TEST. MÊMES COLONNES.
!>
