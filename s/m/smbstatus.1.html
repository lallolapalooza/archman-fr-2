SMBSTATUS(1) Commandes utilisateur SMBSTATUS(1)

NOM

smbstatus - signaler les connexions Samba actuelles

SYNTAXE

smbstatus [-p|--processes] [-v|--verbose] [-L|--locks] [-S|--shares] [-N|--notify] [-u|--user=CHAÎNE] [-b|--brief] [-P|--profile] [-R|--profile-rates] [-B|--byterange] [-n|--numeric] [-f|--fast] [-j|--json] [--resolve-uids] [-?|--help] [--usage] [-d|--debuglevel=NIVEAU_DEBOGAGE] [--debug-stdout] [--configfile=FICHIER_CONFIG] [--option=nom=valeur] [-l|--log-basename=BASENOM_FICHIER_JOURNAL] [--leak-report] [--leak-report-full]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

smbstatus est un programme très simple pour lister les connexions Samba actuelles.

OPTIONS

-P|--profile

Si samba a été compilé avec l'option de profilage, affiche uniquement le contenu de la zone mémoire partagée de profilage.

-R|--profile-rates

Si samba a été compilé avec l'option de profilage, affiche le contenu de la zone mémoire partagée de profilage et les taux d'appels.

-b|--brief

produit une sortie courte.

-v|--verbose

produit une sortie détaillée.

-L|--locks

demande à smbstatus de ne lister que les verrous.

-B|--byterange

demande à smbstatus d'inclure les verrous de plage d'octets.

-p|--processes

affiche une liste des processus smbd(8) et quitte. Utile pour l'écriture de scripts.

-S|--shares

demande à smbstatus de ne lister que les partages.

-N|--notify

demande à smbstatus d'afficher les notifications de fichier enregistrées.

-f|--fast

demande à smbstatus de ne pas vérifier la validité des données d'état en vérifiant si les processus auxquels les données d'état font référence existent toujours. Cela accélère l'exécution sur les systèmes occupés et les clusters, mais peut afficher des données obsolètes pour les processus qui se sont terminés sans nettoyage approprié.

-u|--user=<nom_utilisateur>

sélectionne uniquement les informations relatives à nom_utilisateur.

-n|--numeric

demande à smbstatus d'afficher les UID et GID numériques au lieu de les résoudre en noms.

-?|--aide

Affiche un résumé des options de la ligne de commande.

--utilisation

Affiche un bref message d'utilisation.

-d|--niveau-debug=niveau

niveau est un entier de 0 à 10. La valeur par défaut si ce paramètre n'est pas spécifié est 1 pour les applications clientes.

Plus cette valeur est élevée, plus les détails seront enregistrés dans les fichiers journaux sur les activités du serveur. Au niveau 0, seuls les erreurs critiques et les avertissements graves seront enregistrés. Le niveau 1 est un niveau raisonnable pour une utilisation quotidienne - il génère une petite quantité d'informations sur les opérations effectuées.

Les niveaux supérieurs à 1 généreront une quantité considérable de données de journal, et ne devraient être utilisés que lors de l'investigation d'un problème. Les niveaux supérieurs à 3 sont conçus pour être utilisés uniquement par les développeurs et génèrent d'énormes quantités de données de journal, dont la plupart sont extrêmement cryptiques.

Notez que la spécification de ce paramètre remplacera le paramètre niveau de journalisation du fichier /etc/samba/smb.conf.

--debug-stdout

Cela redirigera la sortie de débogage vers STDOUT. Par défaut, tous les clients enregistrent dans STDERR.

--fichier-config=<fichier de configuration>

Le fichier spécifié contient les détails de configuration requis par le client. Les informations de ce fichier peuvent être générales pour le client et le serveur ou fournir uniquement des options spécifiques au client telles que client smb encrypt. Voir /etc/samba/smb.conf pour plus d'informations. Le nom du fichier de configuration par défaut est déterminé lors de la compilation.

--option=<nom>=<valeur>

Définit l'option smb.conf(5) "<nom>" à la valeur "<valeur>" depuis la ligne de commande. Cela remplace les valeurs par défaut compilées et les options lues depuis le fichier de configuration. Si un nom ou une valeur contient un espace, entourez tout --option=nom=valeur de guillemets.

-l|--basename-log=repertoire-journal

Nom du répertoire de base pour les fichiers journaux/de débogage. L'extension ".nomprog" sera ajoutée (par exemple, log.smbclient, log.smbd, etc...). Le fichier journal n'est jamais supprimé par le client.

--rapport-fuite

Active le rapport de fuite talloc à la sortie.

--rapport-fuite-complet

Active le rapport complet de fuite talloc à la sortie.

-V|--version

Affiche le numéro de version du programme.
