SMFREC(1) Manuel des commandes générales SMFREC(1)

NOM

smfrec — enregistrer un fichier MIDI standard

SYNOPIS

smfrec [-amxy] [-g mesure] [-d nomdev] [-i nomdev] fichier_midi

DESCRIPTION

L'utilitaire smfrec enregistre un fichier MIDI. Il peut ajouter des événements enregistrés par-dessus un fichier MIDI existant. Pour arrêter la performance, envoyez un signal d'interruption à smfrec (par exemple, en appuyant sur Ctrl+C dans le terminal). Les options sont les suivantes :

-a
Mode d'ajout. Joue le fichier MIDI donné et y ajoute une nouvelle piste contenant les événements enregistrés.
-m
Utiliser le métronome.
-x
Synchroniser avec le périphérique midi(4) par défaut au lieu d'utiliser une source d'horloge interne.
-y
Envoyer des informations de synchronisation MIDI au périphérique par défaut. Utile s'il s'agit d'un séquenceur MIDI esclave.
-g mesure
Commencer la lecture et l'enregistrement à partir du numéro de mesure donné.
-d nomfichier
Périphérique midi(4) par défaut à partir duquel enregistrer et sur lequel envoyer les événements MIDI. Si non spécifié, le contenu de la variable d'environnement MIDIDEV sera utilisé à la place.
-i nomfichier
Périphérique midi(4) d'entrée alternatif. Les événements vocaux (notes, contrôleurs, etc.) reçus sur le périphérique d'entrée seront enregistrés et envoyés tels quels au périphérique par défaut. Sans ce drapeau, le périphérique par défaut sera utilisé pour l'entrée.

L'utilitaire smfrec est une interface pour midish(1). Si des fonctionnalités plus spécifiques sont nécessaires, l'utilisateur peut envisager d'utiliser midish(1).

EXEMPLES

Ce qui suit jouera mysong.mid et y ajoutera les événements enregistrés depuis le périphérique /dev/rmidi4 ; le métronome sera utilisé.

$ smfrec -a -m -d /dev/rmidi4 mysong.mid
