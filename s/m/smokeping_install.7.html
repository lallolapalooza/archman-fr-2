NOM

smokeping_install - Comment installer SmokePing

APERÇU

Ce document explique comment configurer SmokePing sur votre site.

DESCRIPTION

Prérequis

SmokePing ne fonctionne pas seul. Il dépend de divers autres outils et services. Outre un système d'exploitation Unix et une installation Perl fonctionnelle, vous avez besoin des composants suivants :

RRDtool 1.2.x ou plus récent
Smokeping utilise RRDtool pour la journalisation et la création de graphiques. Si votre distribution Linux fournit un paquet rrdtool avec support Perl, utilisez-le. Si vous voulez obtenir la dernière version, compilez la vôtre : http://oss.oetiker.ch/rrdtool/

Ubuntu :

sudo apt install rrdtool librrds-perl libssl-dev

RedHat :

sudo yum install rrdtool perl-rrdtool openssl-devel
FPing (optionnel)
Aller sur http://www.fping.org/ pour en télécharger une copie.

Notez que fping doit être installé avec le bit setuid root. Il semble que des versions plus anciennes de fping rapportent les temps d'aller-retour en 0,1 millisecondes au lieu de 1 milliseconde comme annoncé... SmokePing essaie de le détecter. Il vous le dit quand il démarre... faites-moi savoir si il se trompe.

EchoPing (Optionnel)
https://github.com/bortzmeyer/echoping/

Vous en avez besoin pour exécuter les sondes EchoPing

Curl (Optionnel)
http://curl.haxx.se/

Vous en avez besoin pour la sonde Curl.

dig (Optionnel)
http://www.isc.org/sw/bind/

Vous en avez besoin pour la sonde DNS.

SSH (Optionnel)
http://www.openssh.org/

Vous en avez besoin pour la sonde SSH.

Serveur Web
http://httpd.apache.org/

Je ne vais pas trop m'étendre là-dessus. L'important est d'avoir un serveur web qui vous permette d'exécuter des scripts CGI et de préférence FastCGI. Si vous utilisez Apache, je recommande fortement d'utiliser le système suexec pour exécuter les scripts CGI en tant qu'utilisateur spécifique.

Voir http://httpd.apache.org/mod_fcgid/mod/mod_fcgid.html et http://httpd.apache.org/docs/2.2/mod/mod_suexec.html pour plus d'informations à ce sujet.

Perl 5.10.1 ou plus récent.
Si vous avez toujours une version plus ancienne, jetez un œil à perlbrew.

Ubuntu :

sudo apt install perl

RedHat :

sudo yum install perl-core

Installation

Une fois les outils listés ci-dessus installés, vous pouvez commencer à configurer SmokePing lui-même. Décompressez l'archive tar et exécutez le script de configuration inclus :

./configure --prefix=/opt/smokeping

Configure vérifiera que tous les modules Perl requis sont disponibles. Si certains sont manquants, il vous dira d'exécuter le script de construction du module. Suivez simplement les instructions à l'écran, puis réexécutez configure. Une fois qu'il est terminé, vous pouvez exécuter

make install

pour terminer votre installation.

Configuration

Utilisez le fichier etc/config.dist comme modèle pour créer votre propre fichier de configuration smokeping. Voir smokeping_config pour les détails.

Installation de l'interface Web
Copiez le contenu du répertoire PREFIX/htdocs à l'endroit où votre serveur web attend ses données. Peut-être vers /var/www/smokeping.

Modifiez le script smokeping.fcgi pour qu'il pointe vers votre script smokeping_cgi.

Si vous n'avez pas de support FastCGI dans votre serveur web, vous voudrez peut-être utiliser le script smokeping.cgi.

etc/basepage.html
Modifiez le modèle HTML selon vos préférences. Veuillez ne pas supprimer le lien vers le compteur SmokePing et mon nom du modèle. Le contenu du modèle sera rendu par smokeping.cgi. Cela signifie que tous les liens intégrés doivent être relatifs à smokeping.cgi. Si vous utilisez l'authentification HTTP, alors la variable de modèle "authuser" sera remplie à partir de la variable d'environnement $ENV{REMOTE_USER}.
etc/smokemail
Si vous comptez utiliser la prise en charge des adresses IP DYNAMIQUES, personnalisez le contenu de ce fichier.

Démarrage du démon SmokePing

Une fois toute l'infrastructure en place, vous pouvez maintenant lancer le démon smokeping et le laisser collecter des données pour vous. D'abord, vous voudrez peut-être l'exécuter en mode débogage pour voir ce qu'il fait

./bin/smokeping --config=/opt/smokeping/etc/config --debug

une fois que tout va bien, lancez-le en tant que démon. Je vous recommande d'activer l'option de fichier journal afin que vous puissiez voir s'il rencontre des problèmes.

./bin/smokeping --config=/opt/smokeping/etc/config --logfile=smoke.log

Une fois que le système fonctionne, vous voudrez peut-être placer un script de démarrage SmokePing dans votre répertoire /etc/init.d. Consultez smokeping pour plus d'informations.

Vous pouvez maintenant ouvrir la page web smokeping.cgi pour consulter vos données.

Voir la documentation smokeping_cgi sur la façon de configurer l'interface web smokeping.
