SMTP-SOURCE(1) Manuel des commandes générales SMTP-SOURCE(1)

NOM

smtp-source - Générateur de tests SMTP/LMTP parallélisé

SYNTAXE

smtp-source [options] [inet:]hôte[:port]

smtp-source [options] unix:chemin

DESCRIPTION


smtp-source se connecte à l’hôte et au port TCP nommés (par défaut : port 25) et lui envoie un ou plusieurs messages, séquentiellement ou en parallèle. Le programme parle soit SMTP (par défaut), soit LMTP. Les connexions peuvent être établies vers des serveurs de domaine UNIX et des serveurs IPv4 ou IPv6. IPv4 et IPv6 sont les valeurs par défaut.

Note : il s'agit d'un programme de test non supporté. Aucun effort n'est fait pour maintenir la compatibilité entre les versions successives.

Arguments :

-4
Se connecter au serveur avec IPv4. Cette option n'a aucun effet lorsque Postfix est compilé sans prise en charge IPv6.
-6
Se connecter au serveur avec IPv6. Cette option n'est pas disponible lorsque Postfix est compilé sans prise en charge IPv6.
-A
Ne pas abandonner lorsque le serveur envoie autre chose que le code de réponse positive attendu.
-c
Afficher un compteur en cours d'exécution qui est incrémenté chaque fois qu'une commande SMTP DATA est terminée.
-C compteur
Lorsque qu'un hôte envoie un RESET au lieu d'un SYN|ACK, essayer compteur fois avant d'abandonner. Le compteur par défaut est 1. Spécifiez un compteur plus grand pour contourner un problème avec les piles TCP/IP qui envoient un RESET lorsque la file d'attente d'écoute est pleine.
-d
Ne pas se déconnecter après l'envoi d'un message ; envoyer le message suivant sur la même connexion.
-f de
Utiliser l'adresse de l'expéditeur spécifiée (par défaut : <foo@my-hostname>).
-F fichier
Envoyer l'en-tête et le corps du message pré-formatés dans le fichier spécifié, tout en ajoutant un '.' avant les lignes qui commencent par '.', et en ajoutant CRLF après chaque ligne.
-l longueur
Envoyer longueur octets comme charge utile du message. La longueur n'inclut pas les en-têtes de message.
-L
Parler LMTP plutôt que SMTP.
-m nombre_messages
Envoyer le nombre spécifié de messages (par défaut : 1).
-M mon-nom-hote
Utiliser le nom d'hôte ou [l'adresse] spécifié dans la commande HELO et dans les adresses par défaut de l'expéditeur et du destinataire, à la place du nom d'hôte de la machine.
-N
Générer chaque adresse de destinataire en ajoutant un numéro (un compteur de destinataires par processus) à la partie locale de l'adresse du destinataire spécifiée avec l'option -t.

Note : pour utiliser le numéro comme extension d'adresse, spécifiez un délimiteur d'adresse explicite à la fin de la partie locale du destinataire, comme "-t localpart+@domain" ou "-t localpart+", où "+" est un délimiteur d'adresse de destinataire Postfix.

Avantages :

  • Une adresse de destinataire non constante évite un taux de succès de cache irréaliste de 100 % dans les clients du service de réécriture triviale de Postfix, se rapprochant mieux des performances dans des charges de travail réelles.
  • Une partie locale d'adresse de destinataire fixe avec une extension d'adresse non constante évite la nécessité de configurer un grand nombre d'adresses de destinataires valides dans le serveur Postfix récepteur.
-o
Mode ancien : ne pas envoyer HELO, et ne pas envoyer les en-têtes de message.
-r nombre_destinataires
Envoyer le nombre spécifié de destinataires par transaction (par défaut : 1), et générer les adresses de destinataires comme décrit sous l'option -N.
-R intervalle
Attendre un temps aléatoire (0 <= n <= intervalle) entre les messages. La suspension d'un thread n'affecte pas les autres threads de livraison.
-s nombre_sessions
Exécuter le nombre spécifié de sessions SMTP en parallèle (par défaut : 1).
-S sujet
Envoyer le courrier avec la ligne de sujet nommée (par défaut : aucune).
-t à
Utiliser l'adresse du destinataire spécifiée (par défaut : <foo@mon-nom-hote>).
-T taille_fenetre
Remplacer la taille de fenêtre TCP par défaut. Pour contourner les implémentations défectueuses de mise à l'échelle de fenêtre TCP, spécifiez une valeur > 0 et < 65536.
-v
Rendre le programme plus verbeux, à des fins de débogage.
-w intervalle
Attendre un temps fixe entre les messages. La suspension d'un thread n'affecte pas les autres threads de livraison.
[inet:]hôte[:port]
Se connecter via TCP à l'hôte hôte, port port. Le port par défaut est smtp.
unix:chemin
Se connecter au socket de domaine UNIX au chemin.

BOGUES


Aucune prise en charge du pipelining des commandes SMTP.
