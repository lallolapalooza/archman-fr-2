SMBTAR(1) Commandes utilisateur SMBTAR(1)

NOM

smbtar - script shell pour sauvegarder des partages SMB/CIFS directement sur bandes UNIX

SYNTAXE

smbtar [-r] [-i] [-a] [-v] {-s serveur} [-p motdepasse] [-x services] [-X] [-N nomfichier] [-b taillebloc] [-d repertoire] [-l niveaujournal] [-u utilisateur] [-t bande] {nomsfichiers}

DESCRIPTION

Cet outil fait partie de la suite samba(7).

smbtar est un très petit script shell basé sur smbclient(1) qui sauvegarde des partages SMB directement sur bande.

OPTIONS

-s serveur

Le serveur SMB/CIFS sur lequel réside le partage.

-x service

Le nom du partage sur le serveur auquel se connecter. La valeur par défaut est "backup".

-X

Mode exclusion. Exclure les noms de fichiers... de la création ou de la restauration tar.

-d repertoire

Changer pour le répertoire initial avant de restaurer / sauvegarder des fichiers.

-v

Mode verbeux.

-p motdepasse

Le mot de passe à utiliser pour accéder à un partage. Défaut : aucun

-u utilisateur

L'identifiant utilisateur avec lequel se connecter. Défaut : nom de connexion UNIX.

-a

Réinitialiser le mode bit d'archivage DOS pour indiquer que le fichier a été archivé.

-t bande

Périphérique de bande. Peut être un fichier régulier ou un périphérique de bande. Défaut : variable d'environnement $TAPE ; sinon, un fichier nommé tar.out.

-b taillebloc

Facteur de blocage. Défaut 20. Voir tar(1) pour une explication plus complète.

-N nomfichier

Sauvegarder uniquement les fichiers plus récents que nomfichier. Peut être utilisé (par exemple) sur un fichier journal pour implémenter des sauvegardes incrémentielles.

-i

Mode incrémentiel ; les fichiers tar ne sont sauvegardés que s'ils ont le bit d'archivage défini. Le bit d'archivage est réinitialisé après la lecture de chaque fichier.

-r

Restaurer. Les fichiers sont restaurés sur le partage à partir du fichier tar.

-l niveaujournal

Niveau de journalisation (débogage). Correspond à l'option -d de smbclient(1).

VARIABLES ENVIRONNEMENT

La variable $TAPE spécifie le périphérique de bande par défaut sur lequel écrire. Peut être remplacée par l'option -t.

BOGUES

Le script smbtar a des options différentes de celles de tar ordinaire et de la commande tar de smbclient.

AVERTISSEMENTS

Les sites qui sont plus prudents en matière de sécurité pourraient ne pas aimer la façon dont le script gère les mots de passe PC. La sauvegarde et la restauration fonctionnent sur des partages entiers ; cela devrait fonctionner sur des listes de fichiers. smbtar fonctionne mieux avec GNU tar et peut ne pas bien fonctionner avec d'autres versions.

DIAGNOSTICS

Voir la section DIAGNOSTICS de la commande smbclient(1).
