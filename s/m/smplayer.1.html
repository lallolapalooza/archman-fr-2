NOM

SMPlayer - Le meilleur frontend graphique pour MPlayer

SYNTAXE

smplayer [-minigui] [-mpcgui] [-defaultgui] [-config-path <répertoire>] [-send-action <nom_action>] [-actions <liste_actions>] [[-no]-close-at-end] [[-no]-fullscreen] [-sub <fichier_sous-titre>] [-pos <x> <y>] [-size <largeur> <hauteur>] [-add-to-playlist] [-disable-server] [-help|--help|-h|-?] [<média1>] [<média2>]...

DESCRIPTION

SMPlayer est un lecteur multimédia graphique basé sur Qt, utilisant mplayer(1) comme backend.

OPTIONS

-minigui
Ouvre l'interface graphique miniature au lieu de celle par défaut.
-mpcgui
Ouvre l'interface graphique mpc au lieu de celle par défaut.
-defaultgui
Ouvre l'interface graphique par défaut.
-config-path <répertoire>
Spécifie le répertoire pour les fichiers de configuration (smplayer.ini, smplayer_files.ini...).
-send-action <nom_action>
Tente d'établir une connexion avec une autre instance en cours d'exécution et lui envoie l'action spécifiée.
Exemple : smplayer -send-action pause
Le reste des options (s'il y en a) sera ignoré et l'application se terminera. Elle retournera 0 en cas de succès ou -1 en cas d'échec.
-actions <liste_actions>
<liste_actions> est une liste d'actions séparées par des espaces. Les actions seront exécutées juste après le chargement du fichier (s'il y en a) dans le même ordre qu'elles sont entrées. Pour les actions commutables, vous pouvez passer vrai ou faux comme paramètre.
Exemple : smplayer -actions.br "fullscreen compact true"
Les guillemets sont nécessaires si vous passez plus d'une action.
-close-at-end
Ferme la fenêtre principale lorsque le fichier/playlist est terminé.
-no-close-at-end
Ne ferme pas la fenêtre principale lorsque le fichier/playlist est terminé.
-fullscreen
Lit la vidéo en mode plein écran.
-no-fullscreen
Lit la vidéo en mode fenêtré.
-sub
Spécifie le fichier de sous-titres à charger (pour la première vidéo uniquement).
-pos <x> <y>
Spécifie les coordonnées où la fenêtre principale sera affichée.
-size <largeur> <hauteur>
Spécifie la taille de la fenêtre principale.
-h, -help, --help, -?
Affiche le message d'aide puis se termine.
-add-to-playlist
S'il y a une autre instance en cours d'exécution, le média sera ajouté à la playlist de cette instance. S'il n'y a pas d'autre instance, cette option sera ignorée et les fichiers seront ouverts dans une nouvelle instance.
-disable-server
Désactive le serveur utilisé pour communiquer avec d'autres instances. Cela désactive également la possibilité d'utiliser une seule instance.
<média1> <média2> ...
Tout type de fichier que SMPlayer peut ouvrir. Il peut s'agir d'un fichier local, d'un DVD (par ex. dvd://1), d'un flux Internet (par ex. mms://....) ou d'une playlist locale aux formats m3u ou pls.
