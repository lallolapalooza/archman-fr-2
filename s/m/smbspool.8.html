SMBSPOOL(8) Outils d'administration système SMBSPOOL(8)

NOM

smbspool - envoyer un fichier d'impression à une imprimante SMB

SYNTAXE

smbspool {travail} {utilisateur} {titre} {copies} {options} [fichier]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

smbspool est un petit programme de mise en file d'attente d'impression qui envoie un fichier d'impression à une imprimante SMB. Les arguments de la ligne de commande sont dépendants de leur position pour assurer la compatibilité avec le Common UNIX Printing System (CUPS), mais vous pouvez utiliser smbspool avec n'importe quel système d'impression ou depuis un programme ou un script.

URI_DE_PERIPHERIQUE

smbspool spécifie la destination à l'aide d'un identifiant uniforme de ressource (« URI ») avec la méthode « smb ». Cette chaîne peut prendre plusieurs formes :

•smb://serveur[:port]/imprimante
•smb://groupe_de_travail/serveur[:port]/imprimante
•smb://utilisateur:mot_de_passe@serveur[:port]/imprimante
•smb://utilisateur:mot_de_passe@groupe_de_travail/serveur[:port]/imprimante

smbspool essaie d'obtenir l'URI à partir de la variable d'environnement DEVICE_URI. Si DEVICE_URI n'est pas présente, smbspool utilisera argv[0] si celui-ci commence par « smb:// » ou argv[1] si ce n'est pas le cas.

Les programmes utilisant les fonctions exec(2) peuvent passer l'URI dans argv[0], tandis que les scripts shell doivent définir la variable d'environnement DEVICE_URI avant d'exécuter smbspool.

OPTIONS

•L'argument travail (argv[1]) contient le numéro d'identification du travail et n'est actuellement pas utilisé par smbspool.
•L'argument utilisateur (argv[2]) contient le nom de l'utilisateur d'impression et n'est actuellement pas utilisé par smbspool, sauf dans les environnements Kerberos pour accéder au cache de tickets de l'utilisateur.
•L'argument titre (argv[3]) contient la chaîne de titre du travail et est passé comme nom de fichier distant lors de l'envoi du travail d'impression.
•L'argument copies (argv[4]) contient le nombre de copies à imprimer du fichier nommé. Si aucun nom de fichier n'est fourni, cet argument n'est pas utilisé par smbspool.
•L'argument options (argv[5]) contient les options d'impression dans une seule chaîne et n'est actuellement pas utilisé par smbspool.
•L'argument fichier (argv[6]) contient le nom du fichier à imprimer. Si cet argument n'est pas spécifié, le fichier d'impression est lu depuis l'entrée standard.
