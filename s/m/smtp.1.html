SMTP(1) Manuel des commandes générales SMTP(1)

NOM

smtp — Client du protocole Simple Mail Transfer Protocol

SYNTAXE

smtp [-Chnv] [-a fichier_auth] [-F expediteur] [-H helo] [-s serveur] [-T params] [destinataire ...]

DESCRIPTION

L'utilitaire smtp est un client du protocole Simple Mail Transfer Protocol (SMTP) qui peut être utilisé pour effectuer une transaction SMTP contre un serveur SMTP.

Par défaut, smtp lit le contenu du courrier depuis l'entrée standard, établit une session SMTP et effectue une transaction SMTP pour tous les destinataires spécifiés. Le contenu est envoyé tel quel comme données de courrier.

Les options sont les suivantes :

-a fichier_auth
Effectue une connexion avant d'envoyer le message. Le nom d'utilisateur et le mot de passe sont lus depuis fichier_auth et doivent se trouver respectivement sur la première et la deuxième ligne. Cette option nécessite un serveur serveur TLS ou STARTTLS.
-C
N'exige pas que le certificat du serveur soit valide. Cet indicateur est déprécié. Utilisez “-T noverify” à la place.
-F expediteur
Définit le chemin de retour (MAIL FROM) pour la transaction SMTP. Par défaut, l'utilisateur actuel.
-H helo
Définit le nom d'hôte à annoncer (HELO) lors de l'établissement de la session SMTP.
-h
Affiche l'aide.
-n
N'exécute pas réellement une transaction, essaie simplement d'établir une session SMTP et de quitter. Lorsque cette option est fournie, aucun message n'est lu depuis l'entrée standard.
-s serveur
Spécifie le serveur auquel se connecter et les paramètres de connexion. Le format est [proto://[utilisateur:motdepasse@]]hote[:port]. Les protocoles suivants sont disponibles :
smtp
Session SMTP normale avec STARTTLS opportuniste.
smtp+tls
Session SMTP normale avec STARTTLS obligatoire.
smtp+notls
Session SMTP en texte clair sans TLS.
lmtp
Session LMTP avec STARTTLS opportuniste.
lmtp+tls
Session LMTP avec STARTTLS obligatoire.
lmtp+notls
Session LMTP en texte clair sans TLS.
smtps
Session SMTP avec TLS forcé à la connexion.

Par défaut : “smtp://localhost:25”.

-T params
Définit des paramètres spécifiques pour les sessions TLS. La chaîne params est une liste d'options séparées par des virgules ou des espaces. Les options disponibles sont :
cafile=nom_fichier
Utilise nom_fichier comme fichier de certificats racine au lieu de la valeur par défaut du système.
ciphers=valeur
Spécifie les chiffrements autorisés. Se référer à tls_config_set_ciphers(3) pour la valeur.
nosni
Désactive l'indication du nom du serveur (SNI).
noverify
N'exige pas que le certificat du serveur soit valide.
protocols=valeur
Spécifie les protocoles à utiliser. Se référer à tls_config_parse_protocols(3) pour la valeur.
servername=valeur
Utilise valeur pour l'indication du nom du serveur (SNI). Par défaut, le nom d'hôte du serveur spécifié.
-v
Être plus verbeux. Cette option peut être spécifiée plusieurs fois.
