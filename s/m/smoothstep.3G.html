NOM

smoothstep - effectue une interpolation de Hermite entre deux valeurs

DÉCLARATION

genType smoothstep(genType edge0, genType edge1, genType x);

genType smoothstep(float edge0, float edge1, genType x);

genDType smoothstep(genDType edge0, genDType edge1, genDType x);

genDType smoothstep(double edge0, double edge1, genDType x);

PARAMÈTRES

edge0

Spécifie la valeur du bord inférieur de la fonction de Hermite.

edge1

Spécifie la valeur du bord supérieur de la fonction de Hermite.

x

Spécifie la valeur source pour l'interpolation.

DESCRIPTION

smoothstep effectue une interpolation de Hermite lisse entre 0 et 1 lorsque edge0 < x < edge1. Ceci est utile dans les cas où une fonction de seuil avec une transition douce est souhaitée. smoothstep est équivalent à :

    genType t;  /* Ou genDType t; */
    t = clamp((x - edge0) / (edge1 - edge0), 0.0, 1.0);
    return t * t * (3.0 - 2.0 * t);

Les résultats ne sont pas définis si edge0 ≥ edge1.
