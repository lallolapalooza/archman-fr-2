SMFPLAY(1) Manuel des commandes générales SMFPLAY(1)

NOM

smfplay — jouer un fichier MIDI standard

SYNTAXE

smfplay [-mxy] [-g mesure] [-d nomdev] [-i nomdev] fichier_midi

DESCRIPTION

L'utilitaire smfplay joue un fichier MIDI. Pendant la lecture, il peut rediriger des événements d'un périphérique midi(4) vers un autre. Pour arrêter la performance, envoyez un signal d'interruption à smfplay (par exemple, en appuyant sur contrôle ^C dans le terminal). Les options sont les suivantes :

-m
Utiliser le métronome. Le métronome suivra les changements de tempo et de signature rythmique dans le fichier midi.
-x
Synchroniser avec un périphérique midi(4) externe. Si l'indicateur -i est utilisé, la lecture sera synchronisée avec le périphérique d'entrée, sinon elle sera synchronisée avec le périphérique par défaut.
-y
Envoyer des informations de synchronisation MIDI au périphérique par défaut. Utile si le périphérique de sortie est un séquenceur MIDI esclave.
-g mesure
Commencer la lecture à la mesure donnée.
-d nomfichier
Périphérique midi(4) par défaut sur lequel jouer le fichier midi. S'il n'est pas spécifié, le contenu de la variable d'environnement MIDIDEV sera utilisé à la place.
-i nomfichier
Périphérique midi(4) d'entrée alternatif. Les événements de voix (notes, contrôleurs, etc.) reçus sur le périphérique d'entrée seront envoyés tels quels au périphérique par défaut. Sans cet indicateur, le périphérique par défaut sera utilisé pour l'entrée.

L'utilitaire smfplay est une interface vers midish(1). Si des fonctionnalités plus spécifiques sont nécessaires, l'utilisateur peut envisager d'utiliser midish(1).

EXEMPLES

Ce qui suit jouera mysong.mid sur le périphérique /dev/rmidi4 et utilisera le métronome.

$ smfplay -m -d /dev/rmidi4 mysong.mid
