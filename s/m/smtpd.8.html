NOM

smtpd — Démon du protocole SMTP (Simple Mail Transfer Protocol)

SYNTAXE

smtpd [-dFhnv] [-D macro=valeur] [-f fichier] [-P système] [-T trace]

DESCRIPTION

smtpd est un démon du protocole SMTP (Simple Mail Transfer Protocol) qui peut être utilisé comme système de messagerie principal d'une machine. smtpd peut écouter sur une interface réseau et gérer les transactions SMTP ; il peut également recevoir des messages via l'interface sendmail(8) standard. Il peut relayer des messages via des agents de transfert de courrier distants ou les stocker localement en utilisant le format mbox ou maildir. Cette implémentation prend en charge le protocole SMTP tel que défini par la RFC 5321 ainsi que plusieurs extensions. Un smtpd en cours d'exécution peut être contrôlé via smtpctl(8).

Les options sont les suivantes :

-D macro=valeur
Définit la macro à valeur sur la ligne de commande. Remplace la définition de macro dans le fichier de configuration.
-d
Ne pas démoniser. Si cette option est spécifiée, smtpd s'exécutera en premier plan et enregistrera sur stderr.
-F
Ne pas démoniser. Si cette option est spécifiée, smtpd s'exécutera en premier plan et enregistrera dans syslogd(8).
-f fichier
Spécifie un fichier de configuration alternatif.
-h
Affiche la version et l'utilisation.
-n
Mode test de configuration. Vérifie uniquement la validité du fichier de configuration.
-P système
Met en pause un sous-système spécifique au démarrage. L'opération normale peut être reprise en utilisant smtpctl(8). Cette option peut être utilisée plusieurs fois. Les valeurs acceptées sont :
mda
Ne pas planifier les livraisons locales.
mta
Ne pas planifier les transferts distants.
smtp
Ne pas écouter sur les sockets SMTP.
-T trace
Active le traçage en temps réel au démarrage. L'opération normale peut être reprise en utilisant smtpctl(8). Cette option peut être utilisée plusieurs fois. Les valeurs acceptées sont :
  • imsg
  • io
  • smtp (sessions entrantes)
  • filters
  • transfer (sessions sortantes)
  • bounce
  • scheduler
  • expand (expansion alias/virtuel/forward)
  • lookup (recherches utilisateur/identifiants)
  • stat
  • rules (correspondant aux sessions entrantes)
  • mproc
  • all
-v
Produire une sortie plus détaillée.

FICHIERS

/etc/smtpd/mailname
Nom alternatif du serveur à utiliser.
/etc/smtpd/smtpd.conf
Fichier de configuration smtpd par défaut.
/run/smtpd.sock
Socket de domaine UNIX utilisé pour la communication avec smtpctl(8).
/var/spool/smtpd/
Répertoires de spool pour le courrier pendant le traitement.
~/.forward
Informations de transfert d'e-mail de l'utilisateur.

VOIR AUSSI

forward(5), smtpd.conf(5), mailwrapper(8), smtpctl(8)

NORMES

J. Klensin, Simple Mail Transfer Protocol, RFC 5321, Octobre 2008.
