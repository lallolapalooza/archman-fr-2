NOM

smokeping_cgi - Interface web de SmokePing

APERÇU

Ce script sert de 'site web' pour votre opération de surveillance SmokePing. Il présente les cibles que vous regardez dans une structure arborescente et dessine des graphiques au besoin des personnes consultant les pages.

DESCRIPTION

Pour faire fonctionner smokeping_cgi, vous avez besoin d'un serveur web qui vous permet d'exécuter des scripts CGI ou, de préférence, FastCGI. Le système doit être configuré de manière à ce que le processus cgi soit autorisé à écrire dans la zone de cache d'images définie dans le fichier de configuration.

Ce script fonctionne bien en tant que CGI normal, MAIS il semblera très lent, car il effectue de nombreuses opérations au démarrage. Donc, si le script doit être démarré à chaque clic, c'est à la fois lent et difficile pour votre serveur web. Je recommande donc fortement l'utilisation de FastCGI.

Veuillez vous référer au document d'installation pour des instructions détaillées de configuration.

MISE EN PLACE

Il y a un répertoire exemple htdocs dans la racine de votre installation smokeping. Copiez son contenu à l'endroit où votre serveur web attend ses fichiers. Le script fcgi montre la méthode préférée pour exécuter smokeping. Vous pouvez également exécuter smokeping en tant que cgi. Mais assurez-vous d'utiliser le wrapper, car l'exposition d'ARGV au serveur web représente une vulnérabilité de sécurité que vous préférerez peut-être ne pas gérer.

Ajustez les chemins dans le script et vous devriez être prêt à partir.
