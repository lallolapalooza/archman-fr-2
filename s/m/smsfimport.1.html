NOM

smsfimport - programme pour créer des modèles SpectMorph à partir de préréglages SoundFont

SYNTAXE

smsfimport <commande> <FichierSoundFont> [OPTIONS] [arguments spécifiques à la commande...]

DESCRIPTION

smsfimport peut être utilisé pour convertir des préréglages SoundFont (.sf2 format) en instruments SpectMorph (.smset format). Comme il n'implémente pas toutes les fonctionnalités fournies par SoundFonts, les fichiers résultants peuvent sonner différemment des SoundFonts d'origine, et dans certains cas, l'importation échouera complètement.

OPTIONS

smsfimport suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets ('-').

-h, --help
Affiche un bref message d'aide.
-v, --version
Affiche la version de smsfimport.

COMMANDES

lister <FichierSoundFont>
Affiche tous les préréglages contenus dans le FichierSoundFont.
lancer <FichierSoundFont> [ <NomPréréglage> ]
Affiche une vue détaillée des paramètres spécifiés pour un préréglage (ou pour tous les préréglages).
importer <FichierSoundFont> <NomPréréglage>
Importe un préréglage, créant un fichier *.smset. Pour le préréglage "Grand Piano", le résultat serait "grand_piano.smset".
