NOM

smokeinfo - interroger le site smokeping pour obtenir des informations numériques

SYNTAXE

smokeinfo chemin/vers/config.cfg [options]

--start x                     heure de début du graphique rrd. (défaut maintenant-24h)

--end y                       heure de fin du graphique rrd. (défaut maintenant)
--filter pattern              motif de recherche pour la sélection des nœuds
--mode plain (défaut)        comment utiliser le motif
                              - plain
                              - recursive
                              - regexp
--separator ; (défaut)
--format %le (défaut)
--no-head                      ne pas afficher d'en-tête
--man                          afficher la page man et quitter
-h, --help                     afficher cette aide et quitter
--version                      afficher les informations de version et quitter

DESCRIPTION

SmokeInfo est un simple frontal pour le module Smokeping::Info. Il fournit un accès aux données numériques stockées dans les fichiers rrd.

Notez que --start et --end sont passés directement à rrd graph. Cela signifie qu'ils fonctionnent sur la même syntaxe.

Exemples

Obtenir toutes les données de tous les nœuds

smokeinfo etc/config

Afficher uniquement les nœuds directement sous /Customers

smokeinfo --filter=/Customers/ etc/config

Afficher tous les nœuds sous /Customers

smokeinfo --mode=recursive --filter=/Customers/ etc/config

Afficher tous les nœuds avec '_wlan_' dans leur nom

smokeinfo --mode=regexp --filter=_wlan_ etc/config
