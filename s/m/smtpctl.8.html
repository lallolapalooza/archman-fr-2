smtpctl(8)

Paquet: opensmtpd

Licences: custom

SMTPCTL(8) Manuel du gestionnaire système SMTPCTL(8)

NOM

smtpctl, mailq — contrôler le démon SMTP

SYNTAXE

smtpctl commande [argument ...]

mailq

DESCRIPTION

Le programme smtpctl contrôle smtpd(8). Les commandes peuvent être abrégées au préfixe non ambigu minimum; par exemple, sh ro pour show routes.

La commande mailq est fournie pour la compatibilité avec d'autres MTA et est simplement un raccourci pour show queue.

Les commandes suivantes sont disponibles :

discover id-enveloppe | id-message
Planifier une seule enveloppe, ou toutes les enveloppes avec le même ID de message qui ont été déplacées manuellement dans la file d'attente.
encrypt [chaîne]
Chiffrer le mot de passe chaîne en une représentation adaptée aux identifiants utilisateur et l'afficher sur la sortie standard. Si chaîne n'est pas fournie, les mots de passe en clair sont lus depuis l'entrée standard.

Il est conseillé d'éviter de fournir le mot de passe en paramètre car il sera visible depuis la sortie de top(1) et ps(1).

log brief
Désactiver la journalisation de débogage détaillée.
log verbose
Activer la journalisation de débogage détaillée.
monitor
Afficher les mises à jour de certains compteurs internes de smtpd(8) à intervalles d'une seconde. Chaque ligne rapporte l'incrément de tous les compteurs depuis la dernière mise à jour, à l'exception de certains compteurs qui sont toujours des valeurs absolues. La première ligne rapporte la valeur actuelle de chaque compteur. Les champs sont :
  • Nombre actuel de clients SMTP actifs (valeur absolue).
  • Nouveaux clients SMTP.
  • Clients déconnectés.
  • Nombre actuel d'enveloppes dans la file d'attente (valeur absolue).
  • Enveloppes nouvellement mises en file d'attente.
  • Enveloppes retirées de la file d'attente.
  • Livraisons réussies.
  • Échecs temporaires.
  • Échecs permanents.
  • Boucles de messages.
  • Enveloppes expirées.
  • Enveloppes supprimées par l'administrateur.
  • Rejets générés.
pause envelope id-enveloppe | id-message | all
Suspendre temporairement la planification pour l'enveloppe avec l'ID donné, les enveloppes avec l'ID de message donné, ou toutes les enveloppes.
pause mda
Arrêter temporairement les livraisons aux utilisateurs locaux.
pause mta
Arrêter temporairement le relais et les livraisons aux utilisateurs distants.
pause smtp
Arrêter temporairement l'acceptation des sessions entrantes.
profile sous-système
Active le profilage en temps réel du sous-système. Les sous-systèmes supportés sont :
  • queue, pour profiler le coût des I/O de la file d'attente
  • imsg, pour profiler le coût des gestionnaires d'événements
remove id-enveloppe | id-message | all
Supprimer une seule enveloppe, les enveloppes avec l'ID de message donné, ou toutes les enveloppes.
resume envelope id-enveloppe | id-message | all
Reprendre la planification pour l'enveloppe avec l'ID donné, les enveloppes avec l'ID de message donné, ou toutes les enveloppes.
resume mda
Reprendre les livraisons aux utilisateurs locaux.
resume mta
Reprendre le relais et les livraisons aux utilisateurs distants.
resume route id-route
Reprendre le routage sur la route désactivée id-route.
resume smtp
Reprendre l'acceptation des sessions entrantes.
schedule id-enveloppe | id-message | all
Marquer comme prêtes pour livraison immédiate une seule enveloppe, les enveloppes avec l'ID de message donné, ou toutes les enveloppes.
show envelope id-enveloppe
Afficher le contenu de l'enveloppe pour l'ID donné.
show hosts
Afficher la liste des hôtes MX distants connus. Pour chacun d'eux, il affiche l'adresse IP, le nom d'hôte canonique, un compteur de référence, le nombre de connexions actives vers cet hôte et le temps écoulé depuis la dernière connexion.
show hoststats
Afficher le statut de la dernière livraison pour les domaines qui ont été actifs au cours des 4 dernières heures. Il se compose des champs suivants, séparés par un caractère "|" :
  • Domaine.
  • Horodatage UNIX de la dernière livraison.
  • Statut de la dernière livraison.
show message id-enveloppe
Afficher le contenu du message pour l'ID donné.
show queue
Afficher les informations concernant les enveloppes actuellement dans la file d'attente. Chaque ligne de sortie décrit une seule enveloppe. Elle se compose des champs suivants, séparés par un "|" :
  • ID de l'enveloppe.
  • Famille d'adresses du client qui a mis le courrier en file d'attente.
  • Type de livraison : l'un de "mta", "mda" ou "bounce".
  • Divers drapeaux sur l'enveloppe.
  • Adresse de l'expéditeur (chemin de retour).
  • L'adresse du destinataire d'origine.
  • L'adresse de destination.
  • Heure de création.
  • Heure d'expiration.
  • Heure de la dernière tentative de livraison ou de relais.
  • Nombre de tentatives de livraison ou de relais.
  • État actuel : soit "pending" (en attente) soit "inflight" si smtpd(8) est en cours d'exécution, soit "offline" sinon.
  • Délai en secondes avant la prochaine tentative si en attente, ou temps écoulé si en cours d'exécution. Ce champ est vide si smtpd(8) n'est pas en cours d'exécution.
  • Chaîne d'erreur pour la dernière livraison échouée ou tentative de relais.
show relays
Afficher la liste des relais actifs et des connecteurs associés. Pour chaque relais, il affiche un certain nombre de compteurs et des informations sur son état interne sur une seule ligne. Ensuite vient la liste des connecteurs (adresses source à partir desquelles se connecter pour ce relais).
show routes
Afficher le statut des routes actuellement connues par smtpd(8).

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

Chaque ligne se compose d'un numéro de route, d'une adresse source, d'une adresse de destination, d'un ensemble d'indicateurs, du nombre de connexions sur cette route, du niveau de pénalité actuel qui détermine la durée pendant laquelle la route est désactivée en cas d'erreur, et du délai avant sa réactivation. Les indicateurs suivants sont définis :
D
La route est actuellement désactivée.
N
La route est nouvelle. Aucune session SMTP n'a encore été établie.
Q
Un délai d'attente est enregistré pour la route afin de réduire son niveau de pénalité et éventuellement la réactiver ou la supprimer.
show stats
Affiche les statistiques d'exécution concernant smtpd(8).
show status
Indique si les systèmes MTA, MDA et SMTP sont actuellement en cours d'exécution ou en pause.
spf walk
Recherche récursivement les enregistrements SPF pour les domaines lus depuis l'entrée standard. Par exemple : 
$ smtpctl spf walk < domains.txt

Les enregistrements SPF peuvent contenir des macros qui ne peuvent pas être incluses dans une liste statique et doivent être résolues dynamiquement au moment de la connexion. spf walk ne peut pas fournir de résultats complets dans ces cas.

trace sous-système
Active le traçage en temps réel du sous-système. Les sous-systèmes pris en charge sont :
  • imsg
  • io
  • smtp (sessions entrantes)
  • filters
  • mta (sessions sortantes)
  • bounce
  • scheduler
  • expand (expansion des alias/virtuels/redirections)
  • lookup (recherches d'utilisateurs/identifiants)
  • stat
  • rules (correspondance par les sessions entrantes)
  • mproc
  • all
unprofile sous-système
Désactive le profilage en temps réel du sous-système.
untrace sous-système
Désactive le traçage en temps réel du sous-système.
update table nom
Met à jour le contenu de la table nom, pour les tables utilisant le backend « file ».

Lorsqu'il reçoit un message, smtpd génère un message-id pour le message, et un envelope-id par destinataire. Le message-id est un identifiant aléatoire de 32 bits garanti d'être unique sur le système hôte. Le envelope-id est un identifiant unique de 64 bits qui encode le message-id dans les 32 bits supérieurs et un identifiant d'enveloppe aléatoire dans les 32 bits inférieurs.

Une commande spécifiant un message-id s'applique à tous les destinataires d'un message ; une commande spécifiant un envelope-id s'applique à un destinataire spécifique d'un message.

FICHIERS

/run/smtpd.sock
socket de domaine UNIX utilisé pour la communication avec smtpd(8).
