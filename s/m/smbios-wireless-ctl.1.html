smbios-wireless-ctl(1)

Paquet: libsmbios

Licences: GPL, custom

SMBIOS-WIRELESS-CTL(1) Commandes utilisateur SMBIOS-WIRELESS-CTL(1)

NOM

smbios-wireless-ctl - ../src/bin/smbios-wireless-ctl

SYNTAXE

smbios-wireless-ctl

OPTIONS

--version
afficher la version du programme et quitter
-h, --help
afficher ce message d'aide et quitter
--info
Afficher la configuration sans fil (par défaut)
--boot
Définir le paramètre de démarrage du BIOS.
--no-boot
Ne pas définir le paramètre de démarrage du BIOS.
--runtime
Définir le paramètre d'exécution du BIOS (par défaut).
--no-runtime, --boot-only, --boot_only
Ne pas définir le paramètre d'exécution du BIOS.
--wlan=WLAN
Définir l'état du signal radio d'exécution pour le réseau local sans fil
--bt=BT
Définir l'état du signal radio d'exécution pour Bluetooth
--wwan=WWAN
Définir l'état du signal radio d'exécution pour le cellulaire (WAN sans fil)
--uwb=UWB
Définir l'état du signal radio d'exécution pour UWB
--wigig=WIGIG
Définir l'état du signal radio d'exécution pour WiGig
--sw_wlan=SW_WLAN
Définir le commutateur matériel de manière à ce qu'il contrôle le signal radio pour le réseau local sans fil
--sw_bt=SW_BT
Définir le commutateur matériel de manière à ce qu'il contrôle le signal radio pour Bluetooth
--sw_wwan=SW_WWAN
Définir le commutateur matériel de manière à ce qu'il contrôle le signal radio pour le cellulaire (WAN sans fil)
--sw_uwb=SW_UWB
Définir le commutateur matériel de manière à ce qu'il contrôle le signal radio pour UWB
--sw_wigig=SW_WIGIG
Définir le commutateur matériel de manière à ce qu'il contrôle le signal radio pour WiGig
--sw_locator=SW_LOCATOR
Activer ou désactiver le commutateur de localisation WIFI
--st_wlan
Obtenir l'état du réseau local sans fil. 0 = activé. 1 = désactivé. 2 = non présent. 3 = non supporté. 4 = inconnu.
--st_bt
Obtenir l'état de Bluetooth. 0 = activé. 1 = désactivé. 2 = non présent. 3 = non supporté. 4 = inconnu.
--st_wwan
Obtenir l'état du cellulaire (WAN sans fil). 0 = activé. 1 = désactivé. 2 = non présent. 3 = non supporté. 4 = inconnu.
--st_uwb
Obtenir l'état de UWB. 0 = activé. 1 = désactivé. 2 = non présent. 3 = non supporté. 4 = inconnu.
--st_wigig
Obtenir l'état de WiGig. 0 = activé. 1 = désactivé. 2 = non présent. 3 = non supporté. 4 = inconnu.
--st_locator=ST_LOCATOR
Obtenir l'état du commutateur de localisation
-v, --verbose
Afficher une sortie plus détaillée.
-q, --quiet
Minimiser la sortie du programme. Seules les erreurs et les avertissements sont affichés.
--trace
Activer le traçage de fonction détaillé.
--logconfig=LOGCONFIG
Spécifier un journal de configuration alternatif.
--security-key=SECURITY_KEY
Clé de sécurité pré-calculée du BIOS.
--password=PASSWORD
Mot de passe de configuration du BIOS pour les opérations de définition/activation.
-r, --rawpassword
Ne pas convertir automatiquement le mot de passe en codes de balayage.
--memory-dat=MEMORY_DAT
Chemin vers un fichier de vidage mémoire à utiliser à la place de la RAM réelle
--cmos-dat=CMOS_DAT
Chemin vers un fichier de vidage CMOS à utiliser à la place du CMOS réel

VOIR AUSSI

La documentation complète de smbios-wireless-ctl est maintenue sous forme de manuel Texinfo. Si les programmes info et smbios-wireless-ctl sont correctement installés sur votre site, la commande

info smbios-wireless-ctl

devrait vous donner accès au manuel complet.
