Licences: GPL, custom

SMBIOS-UPFLAG-CTL(1) Commandes Utilisateur SMBIOS-UPFLAG-CTL(1)

NOM

smbios-upflag-ctl - out/smbios-upflag-ctl

SYNOPSIS

smbios-upflag-ctl [options]

DESCRIPTION

--help, -h
Affiche ces informations
--memory_file, -m <args>
Debug : Fichier de vidage mémoire à utiliser à la place de la mémoire physique
--cmos_file, -c <args>
Debug : Fichier de vidage CMOS à utiliser à la place du CMOS physique
--set, -s
Définit le drapeau "Boot To UP" à vrai
--clear, -c
Définit le drapeau "Boot To UP" à faux
--get, -g
Définit le drapeau "Boot To UP" à vrai
--version, -v
Affiche les informations de version de libsmbios

VOIR AUSSI

La documentation complète de smbios-upflag-ctl est maintenue sous forme de manuel Texinfo. Si les programmes info et smbios-upflag-ctl sont correctement installés sur votre site, la commande

info smbios-upflag-ctl

devrait vous donner accès au manuel complet.
