SMBIOS-WAKEUP-CTL(1) Commandes utilisateur SMBIOS-WAKEUP-CTL(1)

NOM

smbios-wakeup-ctl - ../src/bin/smbios-wakeup-ctl

SYNTAXE

smbios-wakeup-ctl

OPTIONS

--version
afficher le numéro de version du programme et quitter
-h, --help
afficher ce message d'aide et quitter
--hour=HEURE
Définir l'heure de réveil. Doit être 0-23
--minute=MINUTE
Définir la minute de réveil. Doit être 0-59
--everyday
Définir le réveil pour tous les jours
--weekday
Définir le réveil uniquement pour les jours ouvrables
--disable
Désactiver les réveils
-v, --verbose
Afficher une sortie plus détaillée.
-q, --quiet
Minimiser la sortie du programme. Seules les erreurs et les avertissements sont affichés.
--trace
Activer le traçage de fonction détaillé.
--logconfig=LOGCONFIG
Spécifier un fichier journal de configuration alternatif.
--password=MOT_DE_PASSE
Mot de passe de configuration du BIOS pour les opérations de définition/activation.
-r, --rawpassword
Ne pas convertir automatiquement le mot de passe en codes de balayage.
--memory-dat=FICHIER_DAT_MEMOIRE
Chemin vers un fichier de vidage mémoire à utiliser à la place de la RAM réelle
--cmos-dat=FICHIER_DAT_CMOS
Chemin vers un fichier de vidage CMOS à utiliser à la place du CMOS réel

VOIR AUSSI

La documentation complète de smbios-wakeup-ctl est maintenue sous forme de manuel Texinfo. Si les programmes info et smbios-wakeup-ctl sont correctement installés sur votre site, la commande

info smbios-wakeup-ctl

devrait vous donner accès au manuel complet.
