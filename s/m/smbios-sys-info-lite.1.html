SMBIOS-SYS-INFO-LITE(1) Commandes utilisateur SMBIOS-SYS-INFO-LITE(1)

NOM

smbios-sys-info-lite - out/smbios-sys-info-lite

SYNTAXE

smbios-sys-info-lite [options]

DESCRIPTION

--help, -h
Affiche cette aide
--memory_file, -m <args>
Débogage : fichier de vidage mémoire à utiliser à la place de la mémoire physique
--version, -v
Affiche les informations de version de libsmbios

VOIR AUSSI

La documentation complète de smbios-sys-info-lite est maintenue sous forme de manuel Texinfo. Si les programmes info et smbios-sys-info-lite sont correctement installés sur votre site, la commande

info smbios-sys-info-lite

devrait vous donner accès au manuel complet.
