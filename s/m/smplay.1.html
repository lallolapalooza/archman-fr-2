NOM

smplay - Programme pour lire un modèle SpectMorph

SYNTAXE

smplay [OPTIONS] FichierSM|FichierSMSet

DESCRIPTION

smplay est un lecteur en ligne de commande pour les modèles SpectMorph (qui peuvent être créés à l'aide de smenc). La lecture peut utiliser la carte son, de sorte que le modèle soit entendu directement, ou créer un fichier wav à la place si l'option --export est utilisée.

Comme le modèle SpectMorph est constitué d'ondes sinusoïdales et de bruit, des options pour désactiver l'un de ces composants existent.

OPTIONS

smplay suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets ('-').

-h, --help
Affiche un bref message d'aide.
-v, --version
Affiche la version de smplay.
--rate <fréquence d'échantillonnage>
Définit manuellement la fréquence de relecture ; utile également pour spécifier la fréquence désirée du fichier wav, si --export est utilisé.
--no-noise
Désactive le décodeur de bruit, de sorte que seule la partie onde sinusoïdale du signal soit décodée.
--no-sines
Désactive le décodeur de sinusoïdes, de sorte que seule la partie bruit du signal soit décodée.
--det-random
Utilise un générateur aléatoire déterministe ; cela produira des composants de bruit identiques si le même fichier est décodé deux fois, rendant la sortie audio exactement la même.
--export <nom de fichier wav>
Au lieu de lire le fichier, écrit la sortie dans un fichier wav.
-m, --midi-note <note>
Sélectionne la note MIDI à jouer, dans le cas où un FichierSMSet a été spécifié comme fichier d'entrée.
