NOM

smokeping - Outil en ligne de commande pour SmokePing

SYNTAXE

smokeping [ --email | --makepod | --version | --restart ]

Options:
--man[=x]    Afficher la page de manuel du programme (ou de la sonde x, si spécifiée)
--help       Aide :-)
--email      Envoyer les agents SmokePing à toutes les cibles marquées DYNAMIC
--config=x   Utiliser un fichier de configuration différent de celui par défaut
--check      Vérifier uniquement la syntaxe du fichier de configuration, ne pas démarrer le démon
--makepod[=x] Créer la documentation POD sur le fichier de configuration (ou pour la sonde x, si spécifiée)
--version    Afficher la version de SmokePing
--debug      Exécuter une seule fois et ne pas forker
--debug-daemon Démarrer le démon avec le débogage activé
--restart    Redémarrer SmokePing
--reload     Recharger la configuration dans le processus en cours sans interrompre
             aucune sonde
--nodaemon    Ne pas démoniser le processus (pas de fork)
--filter=x   Mesurer uniquement les entrées qui satisfont le filtre x
--logfile=x    Ajouter les avertissements au fichier journal x.
--static[=x] Génère un site web statique dans le répertoire x. Si x est omis,
             pagedir de la configuration est utilisé.
--nosleep    Pour le débogage, vous pouvez vouloir exécuter SmokePing sans intervalle de sommeil
--gen-examples Générer le document smokeping_examples et les fichiers de configuration d'exemple
               (à utiliser lors de la construction à l'intérieur de la distribution smokeping)
               Avec --check : vérifier la syntaxe des exemples générés.
--master-url=s Exécuter smokeping en mode esclave. Se connecter au maître pour la configuration.
--slave-name=s Par défaut, l'esclave utilisera ce qu'il pense être son nom
               lorsqu'il communique avec son maître. Dans certains cas, vous voudrez peut-être
               remplacer cela.
--shared-secret=s Fichier contenant le secret partagé pour la communication avec le serveur.
--cache-dir=s Répertoire pour le stockage temporaire des données lors de l'exécution en mode esclave.
--pid-dir=s Répertoire pour le fichier PID lors de l'exécution en mode esclave.
            (optionnel, par défaut --cache-dir)

DESCRIPTION

L'outil smokeping est la partie en ligne de commande du système SmokePing. Sa fonction principale est de s'exécuter comme un démon et d'envoyer des pings à toutes les cibles que vous avez spécifiées dans le fichier de configuration. Lorsque vous appelez smokeping sans arguments, il démarre comme un démon et fait son travail.

S'il est appelé avec un argument, d'autres fonctions peuvent être activées, comme vu dans la Synopsis ci-dessus. La fonction --email est expliquée dans la documentation du fichier de configuration.

L'option --filter vous permet d'exécuter le démon sur un gros fichier de configuration, mais de filtrer le fichier de configuration et de ne mesurer que les entrées qui satisfont le filtre. Ceci est utile pour la mesure à distance. Exécutez Smokeping avec deux filtres exclusifs à deux emplacements et synchronisez les rrd en retour vers l'hôte du serveur web où vous exécutez le cgi. Les filtres agissent sur les noms de section dans le fichier de configuration. Plusieurs noms de section sont concaténés avec des chemins comme / :

*** targets ***
+ A
....
+ B
...
++ C

Ceci donne

/A

et

/B, /B/C

Si je veux surveiller /A, mon filtre ressemblerait à ceci :

--filter=/A

Les filtres suivent la syntaxe des expressions régulières. Ils sont toujours ancrés à l'extrémité de la chaîne. En ajoutant un ! au début de la chaîne de filtre, vous la n'égativez. Les entrées correspondantes seront exclues de la surveillance. Plusieurs arguments --filter peuvent être utilisés pour assembler des filtres complexes :

--filter=/A --filter=/B

inclurait toutes les cibles

--filter=/A --filter=/B --filter=!/B/C

exclurait tout sauf /B/C.

La fonction --makepod est utilisée en interne pour produire la documentation du fichier de configuration SmokePing.

Veuillez vous référer au document d'installation pour des instructions de configuration détaillées.

CONFIGURATION

Lors de l'installation de SmokePing, ce fichier doit être ajusté pour correspondre à votre système local. Trois chemins doivent être entrés.

Un pointant vers votre installation rrdtool

use lib qw(/usr/pack/rrdtool-1.0.33-to/lib/perl);

Un pointant vers l'endroit où vous avez installé les bibliothèques SmokePing

use lib qw(/home/oetiker/public_html/smokeping/lib);

Le troisième chemin est l'argument de la commande Smokeping::main. Il pointe vers le fichier de configuration SmokePing.

use Smokeping;
Smokeping::main("/home/oetiker/.smokeping/config");
