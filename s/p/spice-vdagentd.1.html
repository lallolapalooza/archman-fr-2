spice-vdagentd(1) Manuel des commandes générales spice-vdagentd(1)

NOM

spice-vdagentd - Daemon de l'agent invité Spice

SYNTAXE

spice-vdagent [OPTIONS]

DESCRIPTION

L'agent invité Spice pour Linux se compose de 2 parties, un daemon système spice-vdagentd et un agent de session X11 spice-vdagent dont il existe un par session X11.
spice-vdagentd est lancé via un script d'initialisation Sys-V ou une unité systemd.

FONCTIONNALITÉS

L'agent invité Spice ajoute les fonctionnalités suivantes aux invités Spice sous Linux :

Mode souris client (pas besoin de saisir la souris par le client, pas de décalage de la souris)

Ajustement automatique du nombre de moniteurs virtuels de la session X11, et de leur résolution, au nombre de fenêtres client et à leur résolution

Support du copier-coller (texte et images) entre la session X11 active et le client, cela supporte à la fois la sélection primaire et le presse-papiers

Support du transfert de fichiers du client vers l'agent

OPTIONS

-h
Affiche une courte description de toutes les options de ligne de commande
-d
Enregistre les messages de débogage (utilisez deux fois pour plus d'informations)
-f
Traite le périphérique uinput comme un faux ; pas d'ioctls. Ceci est utile en combinaison avec Xspice.
-o
Le daemon se terminera après avoir traité une seule session.
-s port
Définit le port série virtio port (par défaut : /dev/virtio-ports/com.redhat.spice.0)
-u périphérique
Définit le périphérique uinput device (par défaut : /dev/uinput)
-x
Ne pas daemoniser
-X
Désactive l'utilisation des informations de session, spice-vdagentd a besoin de savoir quel spice-vdagent se trouve dans la session X11 actuellement active. spice-vdagentd utilise le console kit ou systemd-logind (option de compilation) pour cela ; l'option -X désactive cela, si aucune information de session n'est disponible, un seul spice-vdagent est autorisé

FICHIERS

Le script d'initialisation Sys-V ou l'unité systemd analyse les fichiers suivants :

/etc/conf.d/spice-vdagentd
Les options de ligne de commande par défaut peuvent être passées à spice-vdagentd en les définissant dans la variable SPICE_VDAGENTD_EXTRA_ARGS dans ce fichier
