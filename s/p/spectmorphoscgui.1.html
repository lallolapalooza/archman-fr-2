NOM

spectmorphoscgui - application auxiliaire pour le plugin BEAST SpectMorph

SYNTAXE

spectmorphoscgui <titre>

DESCRIPTION

spectmorphoscgui est une application auxiliaire utilisée par le plugin BEAST SpectMorph pour afficher une interface graphique. Elle n'est utile que lorsqu'elle est appelée par le plugin BEAST.

OPTIONS

Le titre de la fenêtre est défini par l'argument <titre>.
