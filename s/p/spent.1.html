NOM

ospent - Concatène les entités d'un document SGML/XML

SYNOPSIS

ospent [-ChnrRv] [-bbctf] [-csysid] [-ffichier] [-Drépertoire] [sysid...]

DESCRIPTION

ospent (OpenSP print entity) imprime la concaténation des entités avec des identificateurs système

sur la sortie standard.

Les options suivantes sont disponibles :

-bbctf, --bctf=bctf

Utilise le BCTF nommé bctf pour la sortie.

-csysid, --catalog=sysid

Mappe les identificateurs publics et les noms d'entité vers des identificateurs système en utilisant le fichier d'entrée de catalogue dont l'identificateur système est sysid.

-C, --catalogs

Ceci a le même effet que dans onsgmls(1).

-Drépertoire, --directory=répertoire

Recherche dans le répertoire les fichiers spécifiés dans les identificateurs système. Ceci a le même effet que dans onsgmls(1).

-ffichier, --error-file=fichier

Redirige les messages d'erreur vers fichier.

-h, --help

Affiche un texte d'aide et quitte.

-n, --non-sgml

L'entité est une entité de données non-SGML. Cette option force les octets des objets de stockage composant l'entité à être copiés exactement sans aucune des conversions effectuées pour les entités texte. Implique -r.

-r, --raw

Sortie brute. N'effectue aucune conversion sur les RS et RE lors de l'impression de l'entité. L'entité aurait typiquement l'attribut du gestionnaire de stockage records=asis.

-R, --restricted

Ceci a le même effet que dans onsgmls(1).

-v, --version

Affiche le numéro de version.
