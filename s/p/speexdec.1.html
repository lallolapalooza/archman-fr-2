SPEEXDEC(1) Commandes utilisateur SPEEXDEC(1)

NOM

speexdec - Implémentation de référence du décodeur Speex.

SYNTAXE

speexdec [options] fichier_entree.spx [fichier_sortie]

DESCRIPTION

Décode un fichier Speex et produit un fichier WAV ou un fichier brut

fichier_entree peut être :

nomfichier.spx
fichier Speex ordinaire
-
stdin

fichier_sortie peut être :

nomfichier.wav
fichier Wav
nomfichier.*
fichier PCM brut (toute extension autre que .wav)
-
stdout
(rien)
Sera joué sur la carte son

OPTIONS

--enh
Active l'amélioration perceptive (par défaut)
--no-enh
Désactive l'amélioration perceptive
--force-nb
Force le décodage en bande étroite
--force-wb
Force le décodage en bande large
--force-uwb
Force le décodage en ultra-bande large
--mono
Force le décodage en mono
--stereo
Force le décodage en stéréo
--rate n
Force le décodage à la fréquence d'échantillonnage n Hz
--packet-loss n
Simule n % de perte de paquets aléatoire
-V
Mode verbeux (affiche le débit binaire)
-h, --help
Cette aide
-v, --version
Informations sur la version
--pf
Obsolète, utilisez --enh à la place
--no-pf
Obsolète, utilisez --no-enh à la place

Plus d'informations sont disponibles sur le site de Speex : http://www.speex.org

Veuillez signaler les bugs à la liste de diffusion `speex-dev@xiph.org'.
