splice(2) Manuel des appels système splice(2)

NOM

splice - relier des données vers/depuis un tube

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#define _FILE_OFFSET_BITS 64
#include <fcntl.h>
ssize_t splice(int fd_in, off_t *_Nullable off_in,
               int fd_out, off_t *_Nullable off_out,
               size_t size, unsigned int flags);

DESCRIPTION

splice() déplace des données entre deux descripteurs de fichier sans copie entre l'espace d'adressage du noyau et l'espace d'adressage utilisateur. Il transfère jusqu'à size octets de données du descripteur de fichier fd_in vers le descripteur de fichier fd_out, où l'un des descripteurs de fichier doit faire référence à un tube.

Les sémantiques suivantes s'appliquent à fd_in et off_in :

•
Si fd_in fait référence à un tube, alors off_in doit être NULL.
•
Si fd_in ne fait pas référence à un tube et off_in est NULL, alors les octets sont lus depuis fd_in en commençant par l'offset du fichier, et l'offset du fichier est ajusté en conséquence.
•
Si fd_in ne fait pas référence à un tube et off_in n'est pas NULL, alors off_in doit pointer vers un tampon qui spécifie l'offset de départ à partir duquel les octets seront lus depuis fd_in ; dans ce cas, l'offset du fichier de fd_in n'est pas modifié, et l'offset pointé par off_in est ajusté en conséquence à la place.

Des déclarations analogues s'appliquent à fd_out et off_out.

L'argument flags est un masque de bits composé en combinant par OU zéro ou plusieurs des valeurs suivantes :

SPLICE_F_MOVE
Tenter de déplacer des pages au lieu de les copier. Ceci n'est qu'un indice pour le noyau : les pages peuvent encore être copiées si le noyau ne peut pas déplacer les pages du tube, ou si les tampons du tube ne font pas référence à des pages complètes. L'implémentation initiale de ce drapeau était boguée : par conséquent, à partir de Linux 2.6.21, c'est un no-op (mais il est toujours autorisé dans un appel splice()) ; à l'avenir, une implémentation correcte pourra être restaurée.
SPLICE_F_NONBLOCK
Ne pas bloquer sur les E/S. Cela rend les opérations de tube splice non bloquantes, mais splice() peut néanmoins bloquer car les descripteurs de fichier qui sont reliés vers/depuis peuvent bloquer (sauf s'ils ont le drapeau O_NONBLOCK défini).
SPLICE_F_MORE
D'autres données arriveront lors d'un prochain splice. Ceci est un indice utile lorsque fd_out fait référence à une socket (voir aussi la description de MSG_MORE dans send(2), et la description de TCP_CORK dans tcp(7)).
SPLICE_F_GIFT
Non utilisé pour splice() ; voir vmsplice(2).

VALEUR DE RETOUR

En cas de succès, splice() retourne le nombre d'octets reliés vers ou depuis le tube.

Une valeur de retour de 0 signifie fin de l'entrée. Si fd_in fait référence à un tube, cela signifie qu'il n'y avait pas de données à transférer, et il ne serait pas logique de bloquer car il n'y a pas d'écrivains connectés à l'extrémité d'écriture du tube.

En cas d'erreur, splice() retourne -1 et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
SPLICE_F_NONBLOCK a été spécifié dans flags ou l'un des descripteurs de fichier avait été marqué comme non bloquant (O_NONBLOCK), et l'opération aurait bloqué.
EBADF
Un ou les deux descripteurs de fichier ne sont pas valides, ou n'ont pas le mode lecture-écriture approprié.
EINVAL
Le système de fichiers cible ne prend pas en charge le splicing.
EINVAL
Le fichier cible est ouvert en mode ajout.
EINVAL
Ni l'un ni l'autre des descripteurs de fichier ne fait référence à un tube.
EINVAL
Un offset a été donné pour un périphérique non-recherchable (par exemple, un tube).
EINVAL
fd_in et fd_out font référence au même tube.
ENOMEM
Pas assez de mémoire.
ESPIPE
Soit off_in, soit off_out n'était pas NULL, mais le descripteur de fichier correspondant fait référence à un tube.

NORMES

Linux.

HISTORIQUE

Linux 2.6.17, glibc 2.5.

Dans Linux 2.6.30 et versions antérieures, exactement un des descripteurs fd_in et fd_out devait être un tube. Depuis Linux 2.6.31, les deux arguments peuvent faire référence à des tubes.

NOTES

Les trois appels système splice(), vmsplice(2), et tee(2), fournissent aux programmes en espace utilisateur un contrôle complet sur un tampon arbitraire du noyau, implémenté au sein du noyau en utilisant le même type de tampon que celui utilisé pour un tube. En bref, ces appels système effectuent les tâches suivantes :

splice()
déplace des données du tampon vers un descripteur de fichier arbitraire, ou inversement, ou d'un tampon à un autre.
tee(2)
« copie » les données d'un tampon à un autre.
vmsplice(2)
« copie » des données de l'espace utilisateur vers le tampon.

Bien que nous parlions de copie, les copies réelles sont généralement évitées. Le noyau réalise cela en implémentant un tampon de tube comme un ensemble de pointeurs à comptage de références vers des pages de mémoire du noyau. Le noyau crée des « copies » de pages dans un tampon en créant de nouveaux pointeurs (pour le tampon de sortie) faisant référence aux pages, et en augmentant les comptages de références pour les pages : seuls les pointeurs sont copiés, pas les pages du tampon.

_FILE_OFFSET_BITS doit être défini à 64 dans le code qui utilise off_in ou off_out non NULL ou qui prend l'adresse de splice, si le code est destiné à être portable vers les plateformes x86 et ARM 32 bits traditionnelles où la largeur de off_t est par défaut de 32 bits.

EXEMPLES

Voir tee(2) pour un autre exemple.

#define _GNU_SOURCE
#define _FILE_OFFSET_BITS 64
#include <err.h>
#include <fcntl.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
int
main(void)
{
        int         fd;
        int         pfd[2];
        off_t       off;
        [[gnu::nonstring]]
	const char  s[12] = "Hello, world";
        fd = open("out", O_WRONLY | O_CREAT | O_EXCL, 0666);
        if (fd == -1)
                err(EXIT_FAILURE, "open");
        if (pipe(pfd) == -1)
                err(EXIT_FAILURE, "pipe");
        if (write(pfd[1], s, sizeof(s)) != sizeof(s))
                err(EXIT_FAILURE, "write");
        if (close(pfd[1]) == -1)
                err(EXIT_FAILURE, "close");
        off = 10;
        if (splice(pfd[0], NULL, fd, &off, sizeof(s), 0) != sizeof(s))
                err(EXIT_FAILURE, "splice");
        if (close(pfd[0]) == -1)
err(EXIT_FAILURE, "close"); printf("Le nouvel décalage est %jd\n", (intmax_t) off); if (close(fd) == -1) err(EXIT_FAILURE, "close"); exit(EXIT_SUCCESS); }
