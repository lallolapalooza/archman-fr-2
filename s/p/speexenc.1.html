SPEEXENC(1) Commandes utilisateur SPEEXENC(1)

NOM

speexenc - L'implémentation de référence de l'encodeur Speex.

SYNTAXE

speexenc [options] fichier_entrée fichier_sortie

DESCRIPTION

Encode le fichier d'entrée en utilisant Speex. Il peut lire des fichiers WAV ou bruts.

fichier_entrée peut être :

nomdefichier.wav
Fichier wav
nomdefichier.*
Fichier PCM brut (toute extension autre que .wav)
-
stdin

fichier_sortie peut être :

nomdefichier.spx
Fichier Speex
-
stdout

OPTIONS

-n, --narrowband
Fichier d'entrée bande étroite (8 kHz)
-w, --wideband
Fichier d'entrée bande large (16 kHz)

-u, --ultra-wideband "Bande ultra-large" (Fichier d'entrée 32 kHz)

--quality n
Qualité d'encodage (0-10), par défaut 8
--bitrate n
Débit d'encodage (utiliser un débit n ou inférieur)
--vbr
Activer le débit variable (VBR)
--abr débit
Activer le débit moyen (ABR) à un débit en bps
--vad
Activer la détection d'activité vocale (VAD)
--dtx
Activer la transmission discontinue basée sur fichier (DTX)
--comp n
Définir la complexité d'encodage (0-10), par défaut 3
--nframes n
Nombre de trames par paquet Ogg (1-10), par défaut 1
--comment
Ajouter la chaîne donnée comme commentaire supplémentaire. Ceci peut être utilisé plusieurs fois
--author
Auteur de cette piste
--title
Titre pour cette piste
-h, --help
Cette aide
-v, --version
Informations sur la version
-V
Mode verbeux (afficher le débit)

Options d'entrée brute :

--rate n
Taux d'échantillonnage pour l'entrée brute
--stereo
Considérer l'entrée brute comme stéréo
--le
L'entrée brute est en little-endian
--be
L'entrée brute est en big-endian
--8bit
L'entrée brute est en 8 bits non signé
--16bit
L'entrée brute est en 16 bits signé

L'entrée PCM brute par défaut est en 16 bits, little-endian, mono

Plus d'informations sont disponibles sur le site de Speex : http://www.speex.org

Veuillez signaler les bugs à la liste de diffusion `speex-dev@xiph.org'.
