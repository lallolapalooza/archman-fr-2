Documentation de la fonction/sous-programme

sous-programme sptt01 (entier n, reel, dimension( * ) d, reel, dimension( * ) e, reel, dimension( * ) df, reel, dimension( * ) ef, reel, dimension( * ) work, reel resid)

SPTT01

But :

!>
!> SPTT01 reconstruit une matrice tridiagonale A à partir de sa factorisation L*D*L'
!> et calcule le résidu
!>    norme(L*D*L' - A) / ( n * norme(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau REEL, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau REEL, dimension (N)
!>          Les n éléments diagonaux du facteur L de la factorisation L*D*L'
!>          de A.
!>

EF

!>          EF est un tableau REEL, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux du facteur L de la
!>          factorisation L*D*L' de A.
!>

WORK

!>          WORK est un tableau REEL, dimension (2*N)
!>

RESID

!>          RESID est REEL
!>          norme(L*D*L' - A) / (n * norme(A) * EPS)
!>
