Documentation de la fonction/sous-programme

sous-programme spoequ (integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, integer info)

SPOEQU

But :

!>
!> SPOEQU calcule des mises à l'échelle des lignes et des colonnes destinées à équilibrer une
!> matrice symétrique définie positive A et à réduire son conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de sorte que la matrice mise à l'échelle B avec
!> les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S met le conditionnement de B à une distance d'un facteur N du
!> plus petit conditionnement possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

N 
!>          N est un entier
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice symétrique définie positive N x N dont les facteurs
!>          d'échelle doivent être calculés. Seuls les éléments diagonaux de A
!>          sont référencés.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

S

!>          S est un tableau REEL, dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est REEL
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est REEL
!>          Valeur absolue du plus grand élément de la matrice. Si AMAX est très
!>          proche du débordement ou très proche de la sous-dépassement, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est un entier
!>          = 0 : réussite de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le i-ème élément diagonal n'est pas positif.
!>
