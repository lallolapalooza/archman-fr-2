sous-routine sppt03 (caractère uplo, entier n, réel, dimension( * ) a, réel, dimension( * ) ainv, réel, dimension( ldwork, * ) work, entier ldwork, réel, dimension( * ) rwork, réel rcond, réel resid)

SPPT03

Objectif :

!>
!> SPPT03 calcule le résidu pour une matrice symétrique "packed" multipliée
!> par son inverse :
!>    norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> où EPS est le epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de
!>          la matrice symétrique A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL de dimension (N*(N+1)/2)
!>          La matrice symétrique originale A, stockée sous forme de
!>          matrice triangulaire "packed".
!>

AINV

!>          AINV est un tableau REAL de dimension (N*(N+1)/2)
!>          L'inverse (symétrique) de la matrice A, stockée sous forme de
!>          matrice triangulaire "packed".
!>

WORK

!>          WORK est un tableau REAL de dimension (LDWORK,N)
!>

LDWORK

!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REAL de dimension (N)
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de condition de A, calculé comme
!>          ( 1/norm(A) ) / norm(AINV).
!>

RESID

!>          RESID est REAL
!>          norm(I - A*AINV) / ( N * norm(A) * norm(AINV) * EPS )
!>
