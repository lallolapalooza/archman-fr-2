sous-programme sppsvx (caractere fact, caractere uplo, entier n, entier nrhs, reel, dimension( * ) ap, reel, dimension( * ) afp, caractere equed, reel, dimension( * ) s, reel, dimension( ldb, * ) b, entier ldb, reel, dimension( ldx, * ) x, entier ldx, reel rcond, reel, dimension( * ) ferr, reel, dimension( * ) berr, reel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SPPSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> SPPSVX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T pour
!> calculer la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique définie positive de taille N x N stockée
!> au format compacté et X et B sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition
!> sont également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    L'équilibrage du système dépendra ou non de la mise à l'échelle de
!>    la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasé par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = U**T* U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!>    inférieure.
!>
!> 3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    la routine renvoie INFO = i. Sinon, la forme factorisée de A est
!>    utilisée pour estimer le nombre de condition de la matrice
!>    A. Si l'inverse du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est renvoyé comme un avertissement, mais la routine continue
!>    à résoudre X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. L'amélioration itérative est appliquée pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les erreurs résiduelles pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie
!>          en entrée, et sinon, si la matrice A doit être équilibrée
!>          avant d'être factorisée.
!>          = 'F' : En entrée, AFP contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec les facteurs d'échelle donnés par S. AP et AFP ne
!>                  seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFP et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFP et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

AP

!>          AP est tableau REAL, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, compacté par colonne dans un tableau linéaire, sauf si FACT = 'F'
!>          et EQUED = 'Y', alors A doit contenir la matrice équilibrée
!>          diag(S)*A*diag(S). La j-ème colonne de A est stockée dans le
!>          tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails. A n'est pas modifié si
!>          FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED = 'N' à la sortie.
!>
!>          À la sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>          diag(S)*A*diag(S).
!>

AFP

!>          AFP est tableau REAL, dimension (N*(N+1)/2)
!>          Si FACT = 'F', alors AFP est un argument d'entrée et contient à l'entrée
!>          la factorisation triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T, dans le même format de stockage que A.
!>          Si EQUED .ne. 'N', alors AFP est la forme factorisée de la matrice
!>          équilibrée A.
!>
!>          Si FACT = 'N', alors AFP est un argument de sortie et renvoie à la sortie
!>          la factorisation triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T * U ou A = L * L**T de la matrice originale A.
!>
!>          Si FACT = 'E', alors AFP est un argument de sortie et renvoie à la sortie
!>          la factorisation triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T * U ou A = L * L**T de la matrice équilibrée A (voir la
!>          description de AP pour la forme de la matrice équilibrée).
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Aucun équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y' : L'équilibrage a été effectué, c'est-à-dire que A a été remplacé par
!>                  diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est tableau REAL, dimension (N)
!>          Les facteurs d'échelle pour A ; non consultés si EQUED = 'N'. S est
!>          un argument d'entrée si FACT = 'F' ; sinon, S est un argument
!>          de sortie. Si FACT = 'F' et EQUED = 'Y', chaque élément de S
!>          doit être positif.
!>

B

!>          B est tableau REAL, dimension (LDB,NRHS)
!>          En entrée, la matrice membre de droite B de taille N x NRHS.
!>          À la sortie, si EQUED = 'N', B n'est pas modifié ; si EQUED = 'Y',
!>          B est écrasé par diag(S) * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est tableau REAL, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS
!>          du système original d'équations. Notez que si EQUED = 'Y',
!>          A et B sont modifiés à la sortie, et la solution du
!>          système équilibré est inv(diag(S))*X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          L'estimation de l'inverse du nombre de condition de la matrice
!>          A après équilibrage (si effectué). Si RCOND est inférieur à la
!>          précision machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition est
!>          indiquée par un code de retour de INFO > 0.
!>

FERR

/i>

!>          FERR est un tableau REAL, de dimension (NRHS)
!>          La borne d'erreur directe estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation de RCOND, et est presque toujours une légère
!>          surentimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau REAL, de dimension (NRHS)
!>          L'erreur résiduelle relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau REAL, de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que ne le suggérerait
!>                       la valeur de RCOND.
!>
