NOM

spuunmux - démultiplexe les sous-titres d'un flux de programme mpeg2 existant

SYNTAXE

spuunmux [ fichier d'entrée ] [ fichier d'entrée ... ]

DESCRIPTION

spuunmux démultiplexe les sous-titres d'un flux de programme mpeg2 existant

OPTIONS

-o nom
nom de base pour le script et les images. Par défaut sub.
-v niveau
niveau de verbosité. *sub*. Par défaut 0.
-f
redimensionne les images à taille réelle, qui est 720x480 pour NTSC, 720x576 pour PAL.
-F PAL|NTSC
spécifie le format vidéo, utilisé pour calculer les dimensions de la taille réelle pour -f.
-s flux
numéro du sous-flux à extraire. Par défaut 0.
-p fichier
nom du fichier contenant la palette dvd. Si le fichier de palette se termine par .rgb, il est traité comme un RGB, sinon comme une couleur YCbCr.
-h
affiche cette aide
-V
affiche le numéro de version

UTILISATION

spuunmux fichier_entree1 fichier_entree2

démultiplexe les sous-titres d'un flux de programme mpeg2 existant. Pour utiliser stdin pour le démultiplexage, utilisez - pour le fichier d'entrée :

play_cell GoldFinger.iso 1 1 6 | spuunmux -

AVERTISSEMENTS

Aucun.

BOGUES

Aucun.
