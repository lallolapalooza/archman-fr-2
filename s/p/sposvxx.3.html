Documentation de la fonction/sous-programme

sous-programme sposvxx (character fact, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPOSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!>    SPOSVXX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T
!>    pour calculer la solution d'un système d'équations linéaires réelles
!>    A * X = B, où A est une matrice symétrique définie positive de taille N x N
!>    et X et B sont des matrices de taille N x NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur par composante maximale
!>    sont retournées. SPOSVXX retournera une solution avec une petite erreur garantie
!>    (O(eps) où eps est la précision de la machine de travail) à moins que la matrice ne soit très mal conditionnée,
!>    auquel cas un avertissement est retourné. Les nombres de condition pertinents sont également
!>    calculés et retournés.
!>
!>    SPOSVXX accepte des factorisations et des facteurs d'équilibration fournis par l'utilisateur ;
!>    voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation d'un appel précédent à SPOSVXX produiront également une solution avec des erreurs O(eps) ou des avertissements, mais nous ne pouvons pas affirmer cela pour des factorisations et des facteurs d'équilibration fournis par l'utilisateur si elles diffèrent de ce que SPOSVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la matrice A,
!>    mais si l'équilibration est utilisée, A est écrasé par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibration si FACT = 'E') comme suit :
!>       A = U**T* U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure.
!>
!>    3. Si le mineur principal de tête d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée pour estimer
!>    le nombre de condition de la matrice A (voir l'argument RCOND). Si l'inverse du nombre de condition
!>    est inférieur à la précision de la machine, la routine continue à résoudre pour X et à calculer
!>    les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est défini à zéro),
!>    la routine utilisera le raffinement itératif pour essayer d'obtenir une petite
!>    erreur et de petites bornes d'erreur. Le raffinement calcule le résidu à
!>    au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibration a été utilisée, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système d'origine avant
!>    l'équilibration.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent la façon dont le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est
!>     fournie à l'entrée, et sinon, si la matrice A doit être
!>     équilibrée avant d'être factorisée.
!>       = 'F':  À l'entrée, AF contient la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec des facteurs d'échelle donnés par S.
!>               A et AF ne sont pas modifiés.
!>       = 'N':  La matrice A sera copiée dans AF et factorisée.
!>       = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  La partie triangulaire supérieure de A est stockée ;
!>       = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau REAL, de dimension (LDA,N)
!>     À l'entrée, la matrice symétrique A, sauf si FACT = 'F' et EQUED =
!>     'Y', alors A doit contenir la matrice équilibrée
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la partie triangulaire supérieure
!>     N x N de A contient la partie triangulaire supérieure de
!>     la matrice A, et la partie strictement triangulaire inférieure de A n'est pas
!>     référencée. Si UPLO = 'L', la partie triangulaire inférieure
!>     N x N de A contient la partie triangulaire inférieure de la matrice A, et
!>     la partie strictement triangulaire supérieure de A n'est pas
!>     référencée. A n'est pas modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED =
!>     'N' à la sortie.
!>
!>     À la sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau REAL, de dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et à l'entrée
!>     contient le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, dans le même format de stockage
!>     que A. Si EQUED .ne. 'N', alors AF est la forme factorisée
!>     de la matrice équilibrée diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et à la sortie
!>     retourne le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T de la matrice d'origine
!>     A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et à la sortie
!>     retourne le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T de la matrice équilibrée
!>     A (voir la description de A pour la forme de la
!>     matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée.
!>       = 'N':  Aucune équilibration (toujours vrai si FACT = 'N').
!>       = 'Y':  Équilibrage des lignes et des colonnes
mn equilibration, c'est-à-dire que A a été !> remplacé par diag(S) * A * diag(S). !> EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un !> argument de sortie. !>

S

!>           S est un tableau de REAL, de dimension (N)
!>     Les facteurs d'échelle de ligne pour A. Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S). S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie. Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif. Si S est en sortie, chaque
!>     élément de S est une puissance de la base de numération. Si S est en entrée, chaque
!>     élément de S doit être une puissance de la base de numération afin d'assurer une solution fiable
!>     et des estimations d'erreur. La mise à l'échelle par des puissances de la base de numération n'entraîne pas
!>     d'erreurs d'arrondi, sauf si le résultat déborde (sous-dépassement ou dépassement). Les
!>     erreurs d'arrondi lors de la mise à l'échelle conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>           B est un tableau de REAL, de dimension (LDB,NRHS)
!>     À l'entrée, la matrice B du second membre de taille N x NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié ;
!>     si EQUED = 'Y', B est écrasé par diag(S)*B ;
!>

LDB

!>           LDB est un INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>           X est un tableau de REAL, de dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de taille N x NRHS du système d'équations
!>     original. Notez que A et B sont modifiés en sortie si
!>     EQUED != 'N', et la solution du système équilibré est
!>     inv(diag(S))*X.
!>

LDX

!>           LDX est un INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>           RCOND est un REAL
!>     Conditionnement réciproque mis à l'échelle. C'est une estimation du
!>     nombre de conditionnement de Skeel réciproque de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision de la machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être faible même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

RPVGRW

!>           RPVGRW est un REAL
!>     Croissance réciproque des pivots. À la sortie, ceci contient le facteur de
!>     croissance réciproque des pivots norm(A)/norm(U). La
!>     norme est utilisée. Si ceci est beaucoup inférieur à 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être médiocre.
!>     Cela signifie également que la solution X, les nombres de conditionnement estimés
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0 < INFO <= N, alors ceci contient le facteur de croissance réciproque des pivots
!>     pour les INFO premières colonnes de A.
!>

BERR

!>           BERR est un tableau de REAL, de dimension (NRHS)
!>     Erreur relative par composante à rebours. C'est l'
!>     erreur relative par composante à rebours de chaque vecteur solution X(j)
!>     (c'est-à-dire, le plus petit changement relatif dans un élément quelconque de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>           N_ERR_BNDS est un INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (par norme ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>           ERR_BNDS_NORM est un tableau de REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de conditionnement correspondant à l'
!>     erreur relative par norme, qui est définie comme suit :
!>
!>     Erreur relative par norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'informations d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit être
!>              fait confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de conditionnement réciproque : Estimé par norme
!>              nombre de conditionnement réciproque. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces nombres de conditionnement réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z appropriée.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance de la
!>              base de numération de sorte que toutes les sommes de lignes absolues de Z
!>              soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des mises en garde supplémentaires.
!>

ERR_BNDS_COMP

!>           ERR_BNDS_COMP est un tableau de REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de conditionnement correspondant à l'
!>     erreur relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le i-ème second membre (sur lequel l'
!>     erreur relative par composante dépend), et le type d'informations d'erreur

!>     retournées pour chaque second membre. Si
!>     une précision par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.

!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre de conditionnement réciproque est inférieur au seuil

!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit être
!>              fait confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de conditionnement réciproque : Estimé par composante

!>              de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des mises en garde supplémentaires.
!>

NAME


sposvxx — Hierarchical matrices support for some LAPACK routines






SYNOPSIS


SUBROUTINE sposvxx(uplo, n, nrhs, a, lda, b, ldb, x, ldx, rcond, flag, work, iwork, info)




CHARACTER


uplo


INTEGER


n, nrhs, lda, ldb, ldx, info


REAL


a(lda,*), b(ldb,*), x(ldx,*), rcond, work(*)


INTEGER


iwork(*)








Function/Subroutine Documentation


sposvxx is a LAPACK routine that supports hierarchical
    matrices for some LAPACK routines. The purpose of this routine is to
    provide error estimates for the solution of a linear system of equations
    $A \mathbf{x} = \mathbf{b}$, where $A$ is a symmetric positive definite
    matrix.


Arguments




uplo


(CHARACTER*1) On entry, specifies whether the matrix $A$
    is upper or lower triangular.


'U': $A$ is upper triangular.


'L': $A$ is lower triangular.


n


(INTEGER) The order of the matrix $A$. The dimensions of
    $A$ are $N \times N$, and the dimensions of $B$ and $X$ are $N \times Nrhs$.


nrhs


(INTEGER) The number of right-hand sides, i.e., the number of
    columns of the matrices $B$ and $X$. NRHS >= 0.


a


(REAL(N,N)) The coefficient matrix $A$ of the linear
    system.


lda


(INTEGER) The leading dimension of the array A.
    LDA >= max(1,N).


b


(REAL(N,NRHS)) On entry, the right-hand side matrix
    $B$. On exit, the matrix $B$ is overwritten by the solution matrix $X$.


ldb


(INTEGER) The leading dimension of the array B.
    LDB >= max(1,N).


x


(REAL(N,NRHS)) On exit, the solution matrix $X$ to the
    system of equations $A \mathbf{x} = \mathbf{b}$.


ldx


(INTEGER) The leading dimension of the array X.
    LDX >= max(1,N).


rcond


(REAL) On exit, an estimate of the reciprocal condition number
    of $A$. The magnitude of RCOND is used to assess the
    accuracy of the solution.


flag


(INTEGER) On exit, a flag indicating the result of the
    computation.


flag = 0: The solution is well-conditioned.


flag = 1: The solution is moderately ill-conditioned.


flag = 2: The solution is badly ill-conditioned.


flag = 3: The matrix $A$ is not positive definite.


work


(REAL) Workspace array.


iwork


(INTEGER) Workspace array.


info


(INTEGER) INFO = 0: Successful exit.


INFO < 0: If INFO = -i, the i-th argument had an
    illegal value.




Description


The routine computes the solution $X$ to the system of linear
    equations $A \mathbf{x} = \mathbf{b}$, where $A$ is an $N \times N$
    symmetric positive definite matrix. It also computes an estimate of the
    reciprocal condition number of $A$, and sets a flag to indicate the
    quality of the solution. The estimate is computed using the norm of the
    matrix $A$ and the norm of its inverse.


The routine assumes that the matrix $A$ has been factorized using
    a routine such as SPOTRF. The factorization is not performed
    within this routine.


The following example shows how to use sposvxx to solve
    a system of equations and check the solution quality:


  CALL SPOTRF(UPLO, N, A, LDA, INFO)
  IF (INFO.EQ.0) THEN
     CALL SPOSVXX(UPLO, N, NRHS, A, LDA, B, LDB, X, LDX, RCOND, FLAG, WORK, IWORK, INFO)
     IF (INFO.EQ.0) THEN
        IF (FLAG.EQ.0) THEN
           PRINT *, 'Solution is well-conditioned.'
        ELSE IF (FLAG.EQ.1) THEN
           PRINT *, 'Solution is moderately ill-conditioned.'
        ELSE IF (FLAG.EQ.2) THEN
           PRINT *, 'Solution is badly ill-conditioned.'
        END IF
     ELSE IF (FLAG.EQ.3) THEN
        PRINT *, 'Matrix A is not positive definite.'
     END IF
  END IF



The quality of the solution can be assessed by checking the value
    of RCOND and the value of FLAG. If RCOND
    is close to zero or FLAG is 2 or 3, the solution may not be
    reliable. In such cases, it is advisable to use a higher precision
    arithmetic or to reformulate the problem.


The arrays ERR_BNDS_NORM(:,1) and
    ERR_BNDS_COMP(:,1) are used internally by the routine to store
    error bounds for the solution. The value ERR_BNDS_COMP(J,1) = 0.0
    indicates that the computed solution for the J-th right-hand side is
    accurate within the machine precision. See the definition of
    ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get
    information about all of the right-hand sides check ERR_BNDS_NORM or
    ERR_BNDS_COMP.
