Documentation de la fonction/sous-routine

sous-routine sposvx (character fact, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPOSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> SPOSVX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T pour
!> calculer la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique définie positive de taille N x N et X et B
!> sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de conditionnement sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    L'équilibrage du système dépendra de l'échelle de la matrice A, mais si
!>    l'équilibrage est utilisé, A est écrasée par diag(S)*A*diag(S) et B par
!>    diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = U**T* U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice
!>    triangulaire inférieure.
!>
!> 3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    la routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de conditionnement de la matrice
!>    A. Si le réciproque du nombre de conditionnement est inférieur à la
!>    précision machine, INFO = N+1 est retourné à titre d'avertissement,
!>    mais la routine continue pour résoudre X et calculer les bornes d'erreur
!>    comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en
!>          entrée, et sinon, si la matrice A doit être équilibrée avant
!>          d'être factorisée.
!>          = 'F' : En entrée, AF contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec des facteurs d'échelle donnés par S.
!>                  A et AF ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AF et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau de type REAL, de dimensions (LDA,N)
!>          En entrée, la matrice symétrique A, sauf si FACT = 'F' et
!>          EQUED = 'Y', auquel cas A doit contenir la matrice équilibrée
!>          diag(S)*A*diag(S). Si UPLO = 'U', la partie supérieure
!>          N x N de A contient la partie triangulaire supérieure de la
!>          matrice A, et la partie strictement triangulaire inférieure de A
!>          n'est pas référencée. Si UPLO = 'L', la partie inférieure
!>          N x N de A contient la partie triangulaire inférieure de la
!>          matrice A, et la partie strictement triangulaire supérieure de A
!>          n'est pas référencée. A n'est pas modifié si
!>          FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED = 'N' en sortie.
!>
!>          En sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>          diag(S)*A*diag(S).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau de type REAL, de dimensions (LDAF,N)
!>          Si FACT = 'F', alors AF est un argument d'entrée et contient en
!>          entrée le facteur triangulaire U ou L de la factorisation de
!>          Cholesky A = U**T*U ou A = L*L**T, dans le même format de
!>          stockage que A. Si EQUED .ne. 'N', alors AF est la forme factorisée
!>          de la matrice équilibrée diag(S)*A*diag(S).
!>
!>          Si FACT = 'N', alors AF est un argument de sortie et contient en
!>          sortie le facteur triangulaire U ou L de la factorisation de
!>          Cholesky A = U**T*U ou A = L*L**T de la matrice originale
!>          A.
!>
!>          Si FACT = 'E', alors AF est un argument de sortie et contient en
!>          sortie le facteur triangulaire U ou L de la factorisation de
!>          Cholesky A = U**T*U ou A = L*L**T de la matrice équilibrée
!>          A (voir la description de A pour la forme de la matrice
!>          équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>          La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Pas d'équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y' : L'équilibrage a été effectué, c'est-à-dire que A a été
!>                  remplacée par diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est un tableau de type REAL, de dimensions (N)
!>          Les facteurs d'échelle pour A ; non accédé si EQUED = 'N'. S est
!>          un argument d'entrée si FACT = 'F' ; sinon, S est un argument de
!>          sortie. Si FACT = 'F' et EQUED = 'Y', chaque élément de S
!>          doit être positif.
!>

B

!>          B est un tableau de type REAL, de dimensions (LDB,NRHS)
!>          En entrée, la matrice des membres de droite B de taille N x NRHS.
!>          En sortie, si EQUED = 'N', B n'est pas modifié ; si EQUED = 'Y',
!>          B est écrasé par diag(S) * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau de type REAL, de dimensions (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS
!>          du système original d'équations. Notez que si EQUED = 'Y',
!>          A et B sont modifiés en sortie, et la solution du système
!>          équilibré est inv(diag(S))*X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          Le réciproque de l'estimation du nombre de conditionnement de la
!>          matrice A. Les valeurs petites indiquent que la matrice est proche
!>          d'être singulière.
!>

FERR

!>          FERR est REAL array, dimension (NRHS)
!>          Les bornes d'erreur avant, FERR(J), pour chaque colonne J de la
!>          solution X(J). Les valeurs sont des estimations relatives des erreurs
!>          avant, calculées par la routine comme
!>             max(| A*X(J) - B(J) | / (| A |*| X(J) |+ | B(J) |)
!>          où |.| signifie la valeur absolue des éléments.
!>

BERR

!>          BERR est REAL array, dimension (NRHS)
!>          Les bornes d'erreur arrière, BERR(J), pour chaque colonne J de la
!>          solution X(J). Les valeurs sont des estimations relatives des erreurs
!>          arrière, calculées par la routine comme
!>             max(| A*X(J) - B(J) | / (| A |*| X(J) |)
!>          où |.| signifie la valeur absolue des éléments.
!>

WORK

!>          WORK est REAL array, dimension (max(1, 3*N, 2*N+N*NB))
!>          où NB est le bloc de taille optimum utilisé dans la décomposition
!>          LU. Ce paramètre est utilisé pour le stockage temporaire.
!>

IWORK

!>          IWORK est INTEGER array, dimension (max(1,N))
!>          Ce paramètre est utilisé pour le stockage temporaire.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : Exécution réussie.
!>          > 0 : Si INFO = i, et 1 <= i <= N, alors la factorisation Cholesky
!>                a échoué et le i-ème mineur principal est non positif.
!>                La factorisation a été arrêtée et INFO est défini à i.
!>          = N+1 : La matrice est très mal conditionnée. L'inverse de son nombre
!>                  de conditionnement est inférieur à la précision machine.
!>                  La solution X et les bornes d'erreur ont été calculées mais
!>                  ne sont pas fiables.
!>

>

RCOND

!>          RCOND est REAL
!>          L'estimation du nombre de condition réciproque de la matrice
!>          A après équilibration (si elle est effectuée). Si RCOND est inférieur à la
!>          précision machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition est
!>          indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau de REAL, de dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément dans (X(j) - XTRUE) divisé par la magnitude du plus grand
!>          élément dans X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          majoration de l'erreur réelle.
!>

BERR

!>          BERR est un tableau de REAL, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire la plus petite modification relative dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau de REAL, de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau de INTEGER, de dimension (N)
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la précision machine,
!>                       ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe plusieurs situations où la
!>                       solution calculée peut être plus précise que
!>                       ce que la valeur de RCOND suggérerait.
!>
