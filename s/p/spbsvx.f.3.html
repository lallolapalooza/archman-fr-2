sous-programme spbsvx (caractère fact, caractère uplo, entier n, entier kd, entier nrhs, réel, dimension( ldab, * ) ab, entier ldab, réel, dimension( ldafb, * ) afb, entier ldafb, caractère equed, réel, dimension( * ) s, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldx, * ) x, entier ldx, réel rcond, réel, dimension( * ) ferr, réel, dimension( * ) berr, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SPBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> SPBSVX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T pour
!> calculer la solution d'un système linéaire réel
!>    A * X = B,
!> où A est une matrice bande symétrique définie positive de taille N x N et X
!> et B sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la
!>    matrice A, mais si l'équilibrage est utilisé, A est écrasé par
!>    diag(S)*A*diag(S) et B par diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme
!>       A = U**T * U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice bande triangulaire supérieure, et L est une matrice
!>    bande triangulaire inférieure.
!>
!> 3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice
!>    A. Si l'inverse du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer des bornes d'erreur et des estimations d'erreur arrière
!>    pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en
!>          entrée, et sinon, si la matrice A doit être équilibrée avant d'être
!>          factorisée.
!>          = 'F' : En entrée, AFB contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec les facteurs d'échelle donnés par S. AB et AFB ne seront
!>                  pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFB et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau REAL de dimension (LDAB,N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          symétrique A, stocké dans les KD+1 premières lignes du tableau, sauf
!>          si FACT = 'F' et EQUED = 'Y', alors A doit contenir la
!>          matrice équilibrée diag(S)*A*diag(S). La j-ième colonne de A
!>          est stockée dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) pour max(1,j-KD) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(N,j+KD).
!>          Voir ci-dessous pour plus de détails.
!>
!>          En sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau A.  LDAB >= KD+1.
!>

AFB

!>          AFB est un tableau REAL de dimension (LDAFB,N)
!>          Si FACT = 'F', alors AFB est un argument d'entrée et contient en
!>          entrée le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T de la matrice bande
!>          A, dans le même format de stockage que A (voir AB). Si EQUED = 'Y',
!>          alors AFB est la forme factorisée de la matrice A équilibrée.
!>
!>          Si FACT = 'N', alors AFB est un argument de sortie et retourne en
!>          sortie le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T.
!>
!>          Si FACT = 'E', alors AFB est un argument de sortie et retourne en
!>          sortie le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T de la matrice équilibrée A (voir la description de A
!>          pour la forme de la matrice équilibrée).
!>

LDAFB

!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Aucun équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y' : Un équilibrage a été effectué, c'est-à-dire que A a été remplacé par
!>                  diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est un tableau REAL de dimension (N)
!>          Les facteurs d'échelle pour A ; non accédé si EQUED = 'N'. S est
!>          un argument d'entrée si FACT = 'F' ; sinon, S est un argument de
!>          sortie. Si FACT = 'F' et EQUED = 'Y', chaque élément de S
!>          doit être positif.
!>

B

!>          B est un tableau REAL de dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B de taille N x NRHS.
!>          En sortie, si EQUED = 'N', B n'est pas modifié ; si EQUED = 'Y',
!>          B est écrasé par diag(S) * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL de dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS
!>          du système d'équations original. Notez que si EQUED = 'Y',
!>          A et B sont modifiés en sortie, et la solution du
!>          système équilibré est inv(diag(S))*X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          Sur la sortie, une estimation du nombre de condition réciproque de la
!>          matrice A, c'est-à-dire la valeur de min(i) `|A(i,i)| / (norm(A) * norm(A) * eps)`,
!>          où eps est la précision machine. La matrice est considérée comme
!>          mal conditionnée si RCOND est inférieure à la précision machine.
!>

FERR

!>          FERR est un tableau REAL de dimension (NRHS)
!>          Sur la sortie, le vecteur des bornes d'erreur avant pour les colonnes
!>          de B.  Si `EQUED = 'N'`, FERR(j) est une borne d'erreur avant estimée
!>          pour la colonne j de X, qui est une borne supérieure de la
!>          norme `||X_true(j) - X(j)|| / ||X(j)||`.  Si `EQUED = 'Y'`,
!>          alors FERR(j) est une borne d'erreur avant estimée pour la colonne j
!>          de la solution du système équilibré.
!>

BERR

!>          BERR est un tableau REAL de dimension (NRHS)
!>          Sur la sortie, le vecteur des erreurs arrières pour les colonnes
!>          de B. BERR(j) contient l'erreur arrière calculée pour la solution
!>          de la j-ième colonne de X, `|| B - A*X(:,j) || / (norm(A) * ||X(:,j)||)`.
!>

WORK

!>          WORK est un tableau REAL de dimension (max(max(2*N,KD+1), N+2*KD),
!>          max(NRHS,2)).
!>          Ceci est un espace de travail. Les lignes et colonnes sont utilisées
!>          conformément à la structure des tableaux AB et AFB.
!>

IWORK

!>          IWORK est un tableau INTEGER de dimension (N).
!>          C'est un espace de travail pour les entiers.
!>

INFO

!>          INFO est INTEGER
!>          Sur la sortie, INFO est un entier.
!>          Si INFO = 0 : exécution réussie.
!>          Si INFO < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>                     Sinon, si INFO = -10, le nombre de super-/sous-diagonales
!>                     était illégal.
!>          Si INFO > 0 et INFO <= N : si INFO = i, la factorisation de Cholesky
!>                     a échoué et le facteur UL de rang i-1 a été calculé.
!>                     La matrice A n'est donc pas symétrique définie positive.
!>          Si INFO = N+1 : l'inversion de la matrice a échoué car la matrice
!>                     était mal conditionnée. RCOND <= machine epsilon.
!>

spbsvx

SUBROUTINE SPBSVX( FACT, UPLO, N, NRHS, AB, LDAB, B, LDB, X, LDX, RCOND, FERR, BERR, WORK, IWORK, INFO )

SPBSVX solves a system of linear equations A*X = B with a complex single-precision symmetric positive definite band matrix A, or computes an L*U factorization of a complex single-precision symmetric positive definite band matrix A, using the bounded Bunch-Kaufman algorithm.

SPBSVX is the code that calls the LAPACK driver routine SPBTRF and then the LAPACK solution routine SPBTRS. It uses pre-allocated workspace arrays.

This routine uses the bounded Bunch-Kaufman algorithm to factor ize the matrix A as A = P*U*D*U**T*Q, where P and Q are permutation matrices. If Fact = 'N', SPBSVX computes the factorization and uses it to solve the system of equations.

If Fact = 'F', SPBSVX computes the factorization and uses it to solve the system of equations.

This routine is in the general category of solving systems of linear equations with a band matrix.

Arguments

CHARACTER*1 FACT

CHARACTER*1 UPLO

INTEGER N

INTEGER NRHS

REAL, DIMENSION (LDAB,*) AB

INTEGER LDAB

REAL, DIMENSION (LDB,*) B

INTEGER LDB

REAL, DIMENSION (LDX,*) X

INTEGER LDX

REAL RCOND

REAL, DIMENSION (NRHS) FERR

REAL, DIMENSION (NRHS) BERR

REAL, DIMENSION (3*N) WORK

INTEGER, DIMENSION (N) IWORK

INTEGER INFO

FACT

!>          FACT is CHARACTER*1
!>          = 'F':  On entry with FACT = 'F', the routine SPBSVX will
!>                  immediately compute the factorization of A.
!>          = 'N':  On entry with FACT = 'N', the routine SPBSVX will use
!>                  a previously computed factorization. The factors of A
!>                  are stored in the array AB.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored.
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  To compute the
!>          factorization, N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the arrays B, X, and FERR, and BERR. NRHS >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,*)
!>          On entry, the upper or lower triangular band matrix A.
!>          On exit, if FACT = 'F', AB is overwritten by values generated
!>          during the execution of the bounded Bunch-Kaufman factorization.
!>          If FACT = 'N', AB must contain the factors U and D from the
!>          factorization P*A = U*D*U**T*Q.
!>          The Bunch-Kaufman factorization is done using the bounded
!>          Bunch-Kaufman algorithm, which uses limited lookahead and
!>          limited rook pivoting.
!>
!>          The width of the band is determined by the number of
!>          subdiagonals (or superdiagonals) KD.
!>          If UPLO = 'U', the elements a(i,j) with j > i + KD are not
!>          stored.
!>          If UPLO = 'L', the elements a(i,j) with j < i - KD are not
!>          stored.
!>          We use the standard LAPACK band storage format.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= max(1,N).
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the right hand side vectors for the systems of
!>          equations:
!>          if applicable, B = A**(-T)*B or B = A**(-1)*B.
!>          On exit, B is overwritten by the solution vectors X for the
!>          systems of equations.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!>

X

!>          X is REAL array, dimension (LDX,NRHS)
!>          On exit, if FACT = 'F', the solution vectors X to the systems
!>          A*X = B.
!>          On exit, if FACT = 'N', the solution vectors X to the systems
!>          A*X = B.
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND is REAL
!>          The estimate of the reciprocal condition number of the matrix
!>          A after equilibration (if done).  If RCOND is less than the
!>          machine precision (in particular, if RCOND = 0), the matrix
!>          is singular to working precision.  This condition is
!>          indicated by a return code of INFO > 0.
!>

FERR

!>          FERR is REAL array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>

WORK

!>          WORK is REAL array, dimension (3*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, and i is
!>                <= N:  the leading principal minor of order i of A
!>                       is not positive, so the factorization could not
!>                       be completed, and the solution has not been
!>                       computed. RCOND = 0 is returned.
!>                = N+1: U is nonsingular, but RCOND is less than machine
!>                       precision, meaning that the matrix is singular
!>                       to working precision.  Nevertheless, the
!>                       solution and error bounds are computed because
!>                       there are a number of situations where the
!>                       computed solution can be more accurate than the
!>                       value of RCOND would suggest.
!>

!>                         a55  a56

!>  Similarly, if UPLO = 'L' the format of A is as follows:
!>
!>     a11  a22  a33  a44  a55  a66

!>     a31  a42  a53  a64   *    *
!>
!>  Array elements marked * are not used by the routine.
!>
