sous-programme spptrf (caractère uplo, entier n, réel, dimension( * ) ap, entier info)

SPPTRF

But:

!>
!> SPPTRF calcule la factorisation de Cholesky d'une matrice symétrique
!> réelle positive définie A stockée en format compacté.
!>
!> La factorisation a la forme
!>    A = U**T * U,  si UPLO = 'U', ou
!>    A = L  * L**T,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau REAL, dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, compacté colonne par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, si INFO = 0, le facteur triangulaire U ou L de la
!>          factorisation de Cholesky A = U**T*U ou A = L*L**T, dans le même
!>          format de stockage que A.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas positif, et la factorisation n'a pas pu être
!>                achevée.
!>

Détails supplémentaires :

!>
!>  Le schéma de stockage compacté est illustré par l'exemple suivant
!>  lorsque N = 4, UPLO = 'U' :
!>
!>  Stockage bidimensionnel de la matrice symétrique A :
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = aji)
!>                 a44
!>
!>  Stockage compacté du triangle supérieur de A :
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
