Documentation de la fonction/sous-programme

sous-programme sptrfs (integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) df, real, dimension( * ) ef, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer info)

SPTRFS

Objectif :

!>
!> SPTRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice des coefficients est symétrique définie positive
!> et tridiagonale, et fournit des bornes d'erreur ainsi que des estimations
!> d'erreur arrière pour la solution.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau REEL, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau REEL, dimension (N)
!>          Les n éléments diagonaux de la matrice diagonale D issue de la
!>          factorisation calculée par SPTTRF.
!>

EF

!>          EF est un tableau REEL, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux du facteur bidiagonal unitaire
!>          L issu de la factorisation calculée par SPTTRF.
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          La matrice des côtés droits B.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REEL, dimension (LDX,NRHS)
!>          En entrée, la matrice solution X, telle que calculée par SPTTRS.
!>          En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau REEL, dimension (NRHS)
!>          La borne d'erreur avant pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude de l'élément
!>          le plus grand dans (X(j) - XTRUE) divisée par la magnitude de
!>          l'élément le plus grand dans X(j).
!>

BERR

!>          BERR est un tableau REEL, dimension (NRHS)
!>          L'erreur relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire la plus petite modification relative dans
!>          n'importe quel élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau REEL, dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
