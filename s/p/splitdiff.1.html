NOM

splitdiff - séparer les correctifs incrémentiels

SYNTAXE

splitdiff [-a] [-d] [-D rép] [-p n] [-E] [fichier]

splitdiff {[--aide] | [--version]}

DESCRIPTION

Si vous avez un fichier de correctifs composé de plusieurs correctifs incrémentiels, vous pouvez utiliser splitdiff pour les séparer. Vous pourriez vouloir le faire en préparation pour les recombiner avec combinediff(1).

L'effet de l'exécution de splitdiff est de séparer son entrée en un ensemble de fichiers de sortie, aucun fichier de sortie ne modifiant le même fichier plus d'une fois.

OPTIONS

-a

Séparer chaque correctif au niveau du fichier.

-d

Créer des noms de fichiers tels que a_b.c.patch pour un correctif qui modifie a/b.c.

-D rép

Écrire les fichiers de sortie dans le sous-répertoire rép. Implique -d.

-p n

Supprimer les n premiers composants du chemin pour faciliter les comparaisons.

-E

Ne pas utiliser l'extension de nom de fichier .patch lors de l'écriture des fichiers de sortie.

--aide

Afficher un court message d'utilisation.

--version

Afficher le numéro de version de splitdiff.

VOIR AUSSI

combinediff(1), lsdiff(1)
