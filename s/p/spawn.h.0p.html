spawn.h(0P) Manuel du programmeur POSIX spawn.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

spawn.h — spawn (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <spawn.h>

DESCRIPTION

L'en-tête <spawn.h> définira les types posix_spawnattr_t et posix_spawn_file_actions_t utilisés lors des opérations de spawn.

L'en-tête <spawn.h> définira les types mode_t et pid_t tels que décrits dans <sys/types.h>.

L'en-tête <spawn.h> définira le type sigset_t tel que décrit dans <signal.h>.

L'étiquette sched_param sera déclarée comme nommant un type de structure incomplet, dont le contenu est décrit dans l'en-tête <sched.h>.

L'en-tête <spawn.h> définira les constantes symboliques suivantes à utiliser comme indicateurs qui peuvent être définis dans un objet posix_spawnattr_t à l'aide de la fonction posix_spawnattr_setflags():

POSIX_SPAWN_RESETIDS
POSIX_SPAWN_SETPGROUP
POSIX_SPAWN_SETSCHEDPARAM
POSIX_SPAWN_SETSCHEDULER
POSIX_SPAWN_SETSIGDEF
POSIX_SPAWN_SETSIGMASK

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Des prototypes de fonctions seront fournis.
