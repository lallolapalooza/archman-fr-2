sous-programme spot05 (caractere uplo, entier n, entier nrhs, reel, dimension( lda, * ) a, entier lda, reel, dimension( ldb, * ) b, entier ldb, reel, dimension( ldx, * ) x, entier ldx, reel, dimension( ldxact, * ) xact, entier ldxact, reel, dimension( * ) ferr, reel, dimension( * ) berr, reel, dimension( * ) reslts)

SPOT05

But:

!>
!> SPOT05 teste les bornes d'erreur de l'affinage itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une
!> matrice symétrique n par n.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce rapport n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la routine d'affinage itératif
!>           = le maximum de BERR / ( (n+1)*EPS + (*) ), où
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes des matrices X, B et XACT, et l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X, B et XACT.
!>          NRHS >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice symétrique A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure n par n de A contient la partie triangulaire
!>          supérieure de la matrice A, et la partie strictement inférieure
!>          de A n'est pas référencée.  Si UPLO = 'L', la partie triangulaire
!>          inférieure n par n de A contient la partie triangulaire
!>          inférieure de la matrice A, et la partie strictement supérieure
!>          de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          Les vecteurs du second membre pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés.  Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau REAL, dimension (LDXACT,NRHS)
!>          Les vecteurs solution exacts.  Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est un tableau REAL, dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur solution
!>          X.  Si XTRUE est la vraie solution, FERR borne la magnitude de
!>          la plus grande entrée dans (X - XTRUE) divisée par la magnitude
!>          de la plus grande entrée dans X.
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>          L'erreur relative par composante de la solution (c'est-à-dire,
!>          la plus petite variation relative de toute entrée de A ou B qui
!>          fait de X une solution exacte).
!>

RESLTS

!>          RESLTS est un tableau REAL, dimension (2)
!>          Le maximum sur les NRHS vecteurs solutions des rapports :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
