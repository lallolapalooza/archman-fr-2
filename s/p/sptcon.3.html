Documentation de fonction/sous-programme

sous-programme sptcon (integer n, real, dimension( * ) d, real, dimension( * ) e, real anorm, real rcond, real, dimension( * ) work, integer info)

SPTCON

Objectif :

!>
!> SPTCON calcule l'inverse du nombre de conditionnement (en norme 1)
!> d'une matrice tridiagonale symétrique réelle définie positive
!> utilisant la factorisation A = L*D*L**T ou A = U**T*D*U calculée par
!> SPTTRF.
!>
!> Norm(inv(A)) est calculée par une méthode directe, et l'inverse du
!> nombre de conditionnement est calculé comme
!>              RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

N 
!>          N est un INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

D

!>          D est un tableau REAL de dimension (N)
!>          Les n éléments diagonaux de la matrice diagonale D issue de la
!>          factorisation de A, calculée par SPTTRF.
!>

E

!>          E est un tableau REAL de dimension (N-1)
!>          Les (n-1) éléments hors-diagonaux du facteur bidiagonal unitaire
!>          U ou L issu de la factorisation de A, calculée par SPTTRF.
!>

ANORM

!>          ANORM est un REAL
!>          La norme 1 de la matrice originale A.
!>

RCOND

!>          RCOND est un REAL
!>          L'inverse du nombre de conditionnement de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est la
!>          norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau REAL de dimension (N)
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : exécution réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
