NOM

spa-inspect - Utilitaire d'information sur les plugins SPA de PipeWire

SYNOPSIS

spa-inspect FICHIER

DESCRIPTION

Affiche des informations sur un plugin SPA.

Liste les usines SPA qu'il contient et tente de les instancier.

EXEMPLES

spa-inspect /usr/lib/spa-0.2/bluez5/libspa-codec-bluez5-sbc.so

Affiche des informations sur un plugin.

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire est disponible sur https://pipewire.org
