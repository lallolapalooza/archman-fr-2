Documentation Fonction/Sous-routine

sous-routine spbt02 (caractère uplo, entier n, entier kd, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) rwork, réel resid)

SPBT02

Objectif:

!>
!> SPBT02 calcule le résidu pour une solution d'un système d'équations
!>   bande symétrique A*x = b:
!>    RESID = norm( B - A*X ) / ( norm(A) * norm(X) * EPS)
!> où EPS est la précision machine.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée:
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

KD

!>          KD est ENTIER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite. NRHS >= 0.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          La matrice bande symétrique originale A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure de A est stockée sous forme de
!>          matrice bande; si UPLO = 'L', la partie triangulaire inférieure
!>          de A est stockée.  Les colonnes du triangle approprié sont
!>          stockées dans les colonnes de A et les diagonales du triangle
!>          sont stockées dans les lignes de A.  Voir SPBTRF pour plus de
!>          détails.
!>

LDA

!>          LDA est ENTIER.
!>          La dimension principale du tableau A.  LDA >= max(1,KD+1).
!>

X

!>          X est tableau REEL, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.   LDX >= max(1,N).
!>

B

!>          B est tableau REEL, dimension (LDB,NRHS)
!>          En entrée, les vecteurs du membre de droite pour le système d'équations
!>          linéaires.
!>          En sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est tableau REEL, dimension (N)
!>

RESID

!>          RESID est REEL
!>          Le maximum sur le nombre de membres de droite de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
