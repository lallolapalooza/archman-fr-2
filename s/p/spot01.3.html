sous-programme spot01 (caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldafac, * ) afac, entier ldafac, réel, dimension( * ) rwork, réel resid)

SPOT01

But:

!>
!> SPOT01 reconstruit une matrice définie positive symétrique A à partir de
!> sa factorisation L*L' ou U'*U et calcule le résidu
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> où EPS est la machine epsilon.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de REELS, dimension (LDA,N)
!>          La matrice symétrique d'origine A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau de REELS, dimension (LDAFAC,N)
!>          À l'entrée, le facteur L ou U de la factorisation L * L**T ou U**T * U
!>          de A.
!>          Est écrasé par la matrice reconstruite, puis par
!>          la différence L * L**T - A (ou U**T * U - A).
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC.  LDAFAC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau de REELS, dimension (N)
!>

RESID

!>          RESID est un REEL
!>          Si UPLO = 'L', norm(L * L**T - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U**T * U - A) / ( N * norm(A) * EPS )
!>
