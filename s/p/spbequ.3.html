sous-programme spbequ (character uplo, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) s, real scond, real amax, integer info)

SPBEQU

But :

!>
!> SPBEQU calcule les échelles de lignes et de colonnes destinées à équilibrer une
!> matrice bande symétrique définie positive A et à réduire son nombre de conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de sorte que la matrice mise à l'échelle B avec
!> les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S met le nombre de conditionnement de B à un facteur N du
!> plus petit nombre de conditionnement possible sur toutes les échelles diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': la partie triangulaire supérieure de A est stockée ;
!>          = 'L': la partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A. N >= 0.
!>

KD

!>          KD est INTEGER
!>          Nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB est un tableau REAL de dimension (LDAB,N)
!>          La partie triangulaire supérieure ou inférieure de la matrice bande symétrique A,
!>          stockée dans les KD+1 premières lignes du tableau. La j-ème colonne
!>          de A est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          Dimension principale du tableau A. LDAB >= KD+1.
!>

S

!>          S est un tableau REAL de dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est REAL
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle par S.
!>

AMAX

!>          AMAX est REAL
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du débordement ou très proche du sous-dépassement, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide.
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
