spa-json-dump(1) Manuel des commandes générales spa-json-dump(1)

NOM

spa-json-dump - Convertisseur SPA JSON vers JSON

SYNTAXE

spa-json [FICHIER]

DESCRIPTION

Lit un fichier SPA JSON ou l'entrée standard, et le sort en JSON standard.

EXEMPLES

spa-json-dump /usr/share/pipewire/pipewire.conf

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire est disponible sur https://pipewire.org
