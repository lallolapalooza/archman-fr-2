SPORFSX

Objectif:

!>
!>    SPORFSX améliore la solution calculée d'un système d'équations linéaires
!>    lorsque la matrice des coefficients est symétrique définie positive,
!>    et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur normwise, le code
!>    fournit une borne d'erreur composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires original peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED et S
!>    ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     réglages déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U': le triangle supérieur de A est stocké ;
!>       = 'L': le triangle inférieur de A est stocké.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N': Aucun équilibrage
!>       = 'Y': Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>               Le côté droit B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>     La matrice symétrique A. Si UPLO = 'U', la partie triangulaire
!>     supérieure N par N de A contient la partie triangulaire
!>     supérieure de la matrice A, et la partie strictement triangulaire
!>     inférieure de A n'est pas référencée. Si UPLO = 'L', la partie
!>     triangulaire inférieure N par N de A contient la partie
!>     triangulaire inférieure de la matrice A, et la partie strictement
!>     triangulaire supérieure de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau REAL, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par SPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

S

!>          S est un tableau REAL, dimension (N)
!>     Les facteurs d'échelle pour A. Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S). S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie. Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif. Si S est en sortie, chaque
!>     élément de S est une puissance du radix. Si S est en entrée, chaque
!>     élément de S devrait être une puissance du radix pour assurer une solution fiable
!>     et des estimations d'erreur. La mise à l'échelle par des puissances du radix ne cause pas
!>     d'erreurs d'arrondi sauf si le résultat sousflue ou déborde.
!>     Les erreurs d'arrondi pendant la mise à l'échelle entraînent un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>     La matrice du côté droit B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par SGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>     Conditionnement inversé mis à l'échelle. Ceci est une estimation du
!>     conditionnement inverse de Skeel de la matrice A après
!>     équilibrage (si effectué). S'il est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>     Erreur arrière relative par composante. Ceci est l'
!>     erreur arrière relative par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque côté droit
!>     et chaque type (normwise ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque côté droit, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'
!>     erreur relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     côté droit.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              conditionnement inversé est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur vraie
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Thi

NOM

SPORFSX - SPORFSX calcule les estimations d'erreurs normwise et composante par composante pour la solution d'un système linéaire de matrices triangulaires.

SYNOPSIS

SUBROUTINE SPORFSX(
 UPLO, TRANS, DIAG, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX,
 XTRUE, EQUED, RCOND, ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS, PARAMS,
 WORK, IWORK, INFO )

 INTEGER N, NRHS, LDA, LDAF, LDB, LDX
 REAL A( LDA, * ), AF( LDAF, * ), B( LDB, * ), X( LDX, * ),
 XTRUE( LDX, * ), RCOND( * ), ERR_BNDS_NORM( NRHS, * ),
 ERR_BNDS_COMP( NRHS, * ), PARAMS( * ), WORK( * )
 INTEGER IPIV( * ), IWORK( * ), INFO

 CHARACTER UPLO, TRANS, DIAG, EQUED

Fonction/Documentation de sous-routine

UPLO

 CHARACTER*1 UPLO
 Specifies whether the matrix A is upper or lower triangular.
    UPLO = 'U': Upper triangular
    UPLO = 'L': Lower triangular

TRANS

 CHARACTER*1 TRANS
 Specifies the form of the system of equations:
    TRANS = 'N': AX = B (No transpose)
    TRANS = 'T': A**T X = B (Transpose)
    TRANS = 'C': A**H X = B (Conjugate transpose)

DIAG

 CHARACTER*1 DIAG
 Specifies whether or not the matrix D is assumed to be unit triangular:
    DIAG = 'N': D is not assumed unit triangular
    DIAG = 'U': D is assumed unit triangular

N

 INTEGER N
 The order of the matrix A. N >= 0.

NRHS

 INTEGER NRHS
 The number of right-hand sides, i.e., the number of columns of the
 matrices B, X, and XTRUE. NRHS >= 0.

A

 REAL A( LDA, * )
 The original upper or lower triangular matrix A, of dimension (LDA,N).

LDA

 INTEGER LDA
 The leading dimension of the array A. LDA >= max(1,N).

AF

 REAL AF( LDAF, * )
 The factorized form of the matrix A.
 This must be the same factorized form that was returned by SPOTRF.
 For UPLO = 'U', AF is upper triangular. For UPLO = 'L', AF is lower
 triangular.

LDAF

 INTEGER LDAF
 The leading dimension of the array AF. LDAF >= max(1,N).

IPIV

 INTEGER IPIV( * )
 The pivot indices from the factorization.
 This must be the same pivot index array that was returned by SPOTRF,
 and which must be of dimension (N).

B

 REAL B( LDB, * )
 The right-hand side matrix B, of dimension (LDB,NRHS).

LDB

 INTEGER LDB
 The leading dimension of the array B. LDB >= max(1,N).

X

 REAL X( LDX, * )
 The solution matrix X, of dimension (LDX,NRHS). This subroutine
 overwrites the input matrix B with the solution matrix X.

LDX

 INTEGER LDX
 The leading dimension of the array X. LDX >= max(1,N).

XTRUE

 REAL XTRUE( LDX, * )
 The true solution matrix XTRUE, of dimension (LDX,NRHS).



EQUED


 CHARACTER*1 EQUED
 Specifies the form of equilibration whose information is
 returned in EQUED. This must be the same character string that
 was returned by SPBEqu.
    EQUED = 'N': No equilibration was performed, and no row and
                  scaling were done.
    EQUED = 'R': Row equilibration was performed, and B was replaced by
                  diag(R)*B, where R is the row scaling vector.
    EQUED = 'C': Column equilibration was performed, and B was replaced by
                  diag(C)*B, where C is the column scaling vector.
    EQUED = 'B': Both row and column equilibration were performed, and B was
                  replaced by diag(R)*B*diag(C).



RCOND


 REAL RCOND( * )
 Real array, dimension (NRHS). Contains the reciprocal condition
 numbers of the matrices A for the row/column sensible norm.



ERR_BNDS_NORM


 REAL ERR_BNDS_NORM( NRHS, * )
 For each right hand side, this array contains information about
 various error bounds and condition numbers corresponding to the
 normwise error, which is defined as follows:
    Normwise relative error in the ith solution vector:
        || XTRUE(i) - X(i) ||_inf / || X(i) ||_inf
 The array is indexed by the right hand side i (on which the normwise
 relative error depends), and the type of error information as
 described below. There currently are up to three pieces of
 information returned for each right hand side. If componentwise
 accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_NORM
 is not accessed. If N_ERR_BNDS < 3, then at most the first
 (:,N_ERR_BNDS) entries are returned.
 The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right
 hand side.
 The second index in ERR_BNDS_NORM(:,err) contains the following
 three fields:
    err = 1  Boolean. Trust the answer if the reciprocal condition
              number is less than the threshold sqrt(n) *
              slamch('Epsilon').
    err = 2  Error bound. The estimated forward error, almost certainly
              within a factor of 10 of the true error so long as the
              next entry is greater than the threshold sqrt(n) *
              slamch('Epsilon'). This error bound should only be
              trusted if the previous boolean is true.
    err = 3  Reciprocal condition number. Estimated normwise
              reciprocal condition number. Compared with the threshold
              sqrt(n) * slamch('Epsilon') to determine if the error
              estimate is . These reciprocal condition
              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
              appropriately scaled matrix Z.
              Let Z = S*A, where S scales each row by a power of the
              radix so all absolute row sums of Z are approximately 1.
    See Lapack Working Note 165 for further details and extra
    cautions.



ERR_BNDS_COMP


 REAL ERR_BNDS_COMP( NRHS, * )
 For each right hand side, this array contains information about
 various error bounds and condition numbers corresponding to the
 componentwise relative error, which is defined as follows:
    Componentwise relative error in the ith solution vector:
                    abs(XTRUE(j,i) - X(j,i))
             max_j ----------------------
                         abs(X(j,i))
 The array is indexed by the right hand side i (on which the
 componentwise relative error depends), and the type of error
 information as described below. There currently are up to three
 pieces of information returned for each right hand side. If
 componentwise accuracy is not requested (PARAMS(3) = 0.0), then
 ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most
 the first (:,N_ERR_BNDS) entries are returned.
 The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
 right hand side.
 The second index in ERR_BNDS_COMP(:,err) contains the following
 three fields:
    err = 1  Boolean. Trust the answer if the
              reciprocal condition number is less than the threshold
              sqrt(n) * slamch('Epsilon').
    err = 2  Error bound. The estimated forward error,
              almost certainly within a factor of 10 of the true error
              so long as the next entry is greater than the threshold
              sqrt(n) * slamch('Epsilon'). This error bound should only
              be trusted if the previous boolean is true.
    err = 3  Reciprocal condition number. Estimated componentwise
              reciprocal condition number. Compared with the threshold
              sqrt(n) * slamch('Epsilon') to determine if the error
              estimate is . These reciprocal condition
              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
              appropriately scaled matrix Z.
              Let Z = S*(A*diag(x)), where x is the solution for the
              current right hand side and S scales each row of
              A*diag(x) by a power of the radix so all absolute row
              sums of Z are approximately 1.
    See Lapack Working Note 165 for further details and extra
    cautions.



NPARAMS


 INTEGER NPARAMS
 Specifies the number of parameters set in PARAMS. If <= 0, the
 PARAMS array is never referenced and default values are used.



PARAMS


 REAL PARAMS( * )
 Specifies algorithm parameters. If an entry is < 0.0, then
 that entry will be filled with default value used for that
 parameter. Only positions up to NPARAMS are accessed; defaults
 are used for higher-numbered parameters.
       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
            refinement or not.
         Default: 1.0
            = 0.0:  No refinement is performed, and no error bounds are
                    computed.
            = 1.0:  Use the double-precision refinement algorithm,
                    possibly with doubled-single computations if the
                    compilation environment does not support DOUBLE
                    PRECISION.
              (other values are reserved for future use)
       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
            computations allowed for refinement.
         Default: 10
         Aggressive: Set to 100 to permit convergence using approximate
                     factorizations or factorizations other than LU. If
                     the factorization uses a technique other than
                     Gaussian elimination, the guarantees in
                     err_bnds_norm and err_bnds_comp may no longer be
                     trustworthy.
       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
            will attempt to find a solution with small componentwise
            relative error in the double-precision algorithm.  Positive
            is true, 0.0 is false.
         Default: 1.0 (attempt componentwise convergence)



WORK


 REAL WORK( * )
 Workspace array, dimension (4*N).



IWORK


 INTEGER IWORK( * )
 Integer workspace array, dimension (N).



INFO


 INTEGER INFO
        = 0:  Successful exit. The solution to every right-hand side is
          guaranteed.
        < 0:  If INFO = -i, the i-th argument had an illegal value
        > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
          has been completed, but the factor U is exactly singular, so
          the solution and error bounds could not be computed. RCOND = 0
          is returned.
        = N+J: The solution corresponding to the Jth right-hand side is
          not guaranteed. The solutions corresponding to other right-
          hand sides K with K > J may not be guaranteed as well, but
          only the first such right-hand side is reported. If a small
          componentwise error is not requested (PARAMS(3) = 0.0) then
          the Jth right-hand side is the first with a normwise error
          bound that is not guaranteed (the smallest J such
          that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
          the Jth right-hand side is the first with either a normwise or
          componentwise error bound that is not guaranteed (the smallest
          J such that either ERR_BNDS_NORM(J,1) = 0.0 or
          ERR_BNDS_COMP(J,1) = 0.0). See the definition of
          ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
          about all of the right-hand sides check ERR_BNDS_NORM or
          ERR_BNDS_COMP.
