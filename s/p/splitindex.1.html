NOM

splitindex - page de manuel pour splitindex 0.2a

SYNTAXE

splitindex.pl [OPTION] ... FICHIER-INDEX-INTERMEDIAIRE [OPTION-MAKEINDEX] ...

splitindex [OPTION] ... FICHIER-INDEX-INTERMEDIAIRE [OPTION-MAKEINDEX] ...

java splitindex [OPTION] ... FICHIER-INDEX-INTERMEDIAIRE [OPTION-MAKEINDEX] ...

tex splitindex

DESCRIPTION

splitindex 0.2a Copyright (c) 2002 Markus Kohm <kohm@gmx.de>

Divise un seul fichier d'index intermédiaire en plusieurs fichiers d'index bruts.

Exemple : splitindex.pl foo.idx.

OPTIONS

-h, --help
afficher cette aide et quitter
-m, --makeindex NOMPROG
appeler NOMPROG au lieu de `makeindex' par défaut.
-i, --identify EXPRESSION
utiliser l'EXPRESSION régulière pour faire correspondre les entrées (voir aussi les options --resultis et --suffixis). La valeur par défaut est `^(\\indexentry)\[([^]]*)\](.*)$'.
-r, --resultis MODELE
créer une ligne à écrire à partir du MODÈLE après avoir fait correspondre les lignes (voir aussi l'option --identify). La valeur par défaut est `$1$3'.
-s, --suffixis MODELE
créer un suffixe à utiliser à partir du MODÈLE après avoir fait correspondre les lignes (voir aussi l'option --identify). La valeur par défaut est `-$2'.
-v, --verbose
être plus verbeux (peut être utilisé plusieurs fois pour augmenter la verbosité)
--version
afficher la version et quitter

DROITS D'AUTEUR

VOIR AUSSI

La documentation complète de splitindex est maintenue sous forme de manuel LaTeX. Si les programmes texdoc et splitindex sont correctement installés sur votre système, la commande

texdoc splitidx

devrait vous donner accès au manuel complet.
