NOM

spotlight - déplacer un projecteur sur le bureau

SYNTAXE

spotlight [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visual] [--delay µs] [--duration s] [--radius pixels] [--fps]

DESCRIPTION

Le programme spotlight prend une image et expose de petites sections de celle-ci comme à travers le faisceau d'un projecteur errant.

L'image qu'il manipule sera capturée depuis la portion de l'écran située sous la fenêtre, ou depuis l'entrée vidéo du système, ou depuis un fichier aléatoire sur disque, comme indiqué par les options grabDesktopImages, grabVideoFrames, et chooseRandomImages dans le fichier ~/.xscreensaver ; voir xscreensaver-settings(1) pour plus de détails.

OPTIONS

spotlight accepte les options suivantes :

--window
Dessiner sur une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, faire comme si nous étions sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--delay microsecondes
Ralentir le mouvement.
--duration secondes
Durée d'affichage avant de charger une nouvelle image. Par défaut 120 secondes.
--radius pixels
Rayon du projecteur en pixels.
--fps
Afficher le taux d'images par seconde et la charge CPU actuelle.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

VOIR AUSSI
