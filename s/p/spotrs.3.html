sous-routine spotrs (caractère uplo, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, entier info)

SPOTRS

But :

!>
!> SPOTRS résout un système d'équations linéaires A*X = B avec une matrice
!> symétrique définie positive A en utilisant la factorisation de Cholesky
!> A = U**T*U ou A = L*L**T calculée par SPOTRF.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T, tel que calculé par SPOTRF.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          En entrée, la matrice des membres de droite B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
