sous-programme spotrf (caractère uplo, entier n, réel, dimension( lda, * ) a, entier lda, entier info)

SPOTRF

But:

!>
!> SPOTRF calcule la factorisation de Cholesky d'une matrice symétrique réelle
!> définie positive A.
!>
!> La factorisation est de la forme
!>    A = U**T * U,  si UPLO = 'U', ou
!>    A = L  * L**T,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure.
!>
!> C'est la version par blocs de l'algorithme, appelant BLAS de niveau 3.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est un entier
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de réels, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N de A contient la partie supérieure
!>          triangulaire de la matrice A, et la partie strictement inférieure
!>          triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire N x N de A contient la partie inférieure
!>          triangulaire de la matrice A, et la partie strictement supérieure
!>          triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de premier ordre i
!>                n'est pas positif, et la factorisation n'a pas pu être
!>                terminée.
!>
