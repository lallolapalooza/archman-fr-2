sous-programme sppt05 (caractère uplo, entier n, entier nrhs, réel, dimension( * ) ap, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldxact, * ) xact, entier ldxact, réel, dimension( * ) ferr, réel, dimension( * ) berr, réel, dimension( * ) reslts)

SPPT05

Objectif :

!>
!> SPPT05 teste les bornes d'erreur de l'affinement itératif pour la
!> solution calculée d'un système d'équations A*X = B, où A est une
!> matrice symétrique en format de stockage condensé.
!>
!> RESLTS(1) = test de la borne d'erreur
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Une grande valeur est retournée si ce rapport n'est pas inférieur à un.
!>
!> RESLTS(2) = résidu de la routine d'affinement itératif
!>           = le maximum de BERR / ( (n+1)*EPS + (*) ), où
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes des matrices X, B et XACT, et l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes des matrices X, B et XACT.
!>          NRHS >= 0.
!>

AP

!>          AP est un tableau REAL, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice symétrique A,
!>          condensé colonne par colonne dans un tableau linéaire. La j-ème
!>          colonne de A est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          Les vecteurs du membre de droite pour le système d'équations
!>          linéaires.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés. Chaque vecteur est stocké comme
!>          une colonne de la matrice X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

XACT

!>          XACT est un tableau REAL, dimension (LDXACT,NRHS)
!>          Les vecteurs solution exacts. Chaque vecteur est stocké comme
!>          une colonne de la matrice XACT.
!>

LDXACT

!>          LDXACT est INTEGER
!>          La dimension principale du tableau XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR est un tableau REAL, dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur solution
!>          X.  Si XTRUE est la vraie solution, FERR borne la magnitude de
!>          la plus grande entrée dans (X - XTRUE) divisée par la magnitude
!>          de la plus grande entrée dans X.
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>          L'erreur relative par composante de la solution vecteur (c'est-à-dire
!>          le plus petit changement relatif dans une entrée de A ou B qui
!>          rend X une solution exacte).
!>

RESLTS

!>          RESLTS est un tableau REAL, dimension (2)
!>          Le maximum sur les vecteurs solution NRHS des rapports :
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
