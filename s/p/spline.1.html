SPLINE(1) Utilitaires de tracé GNU SPLINE(1)

NOM

spline - interpole des jeux de données en utilisant des splines sous tension

SYNTAXE

spline [ options ] [ fichiers ]

DESCRIPTION

spline lit des jeux de données depuis l'entrée standard ou depuis un ou plusieurs fichiers, et ajuste une courbe lisse (une « spline ») à travers chaque jeu de données. Une version interpolée de chaque jeu de données, composée de points de la courbe lisse, est écrite sur la sortie standard.

À moins que les options -a ou -A ne soient utilisées (voir ci-dessous), chaque jeu de données doit être une séquence de valeurs pour une fonction vectorielle d'une seule variable scalaire. C'est-à-dire que chaque jeu de données doit être une séquence de points de données, donnés comme des valeurs alternées de t et y. t est une variable indépendante scalaire, et y est une variable dépendante à valeurs vectorielles. La dimensionnalité de y est spécifiée avec l'option -d (la dimensionnalité par défaut est 1). Entre chaque point de données et le suivant, t doit augmenter.

Un fichier d'entrée peut contenir plus d'un jeu de données. Si un fichier d'entrée est au format ASCII (par défaut), ses jeux de données doivent être séparés par des lignes vides. Les valeurs t et y des points de données dans chaque jeu de données peuvent être arrangées arbitrairement, tant qu'elles sont séparées par des espaces blancs. Outre les jeux de données, un fichier d'entrée peut contenir un nombre quelconque de lignes de commentaires, qui doivent commencer par le caractère de commentaire `#'. Les lignes de commentaires sont ignorées. Elles ne sont pas traitées comme vides, c'est-à-dire qu'elles n'interrompent pas un jeu de données en cours.

Les options et les noms de fichiers peuvent être mélangés sur la ligne de commande, mais les options sont traitées avant la lecture des noms de fichiers. Si -- est rencontré, il est interprété comme la fin des options. Si aucun nom de fichier n'est spécifié, ou si le nom de fichier - est rencontré, l'entrée standard est lue.

Le type d'interpolation et le format des fichiers d'entrée et de sortie peuvent être sélectionnés par des options en ligne de commande.

OPTIONS

Options relatives à l'interpolation

-f

--filter
Utilise un algorithme d'interpolation locale (l'algorithme de Bessel cubique), de sorte que spline puisse être utilisé comme filtre en temps réel. La pente de la courbe interpolante à chaque point d'un jeu de données sera choisie en ajustant une fonction quadratique passant par ce point et les deux points adjacents du jeu de données. Si -f est spécifié, alors l'option -t, autrement optionnelle, doit également être utilisée. De plus, si -f est spécifié, alors les options -k, -p et -T ne peuvent pas être utilisées.
Si -f n'est pas spécifié, alors l'algorithme d'interpolation par défaut (global) sera utilisé.
-k k

--boundary-condition k
Définit le paramètre de condition aux limites pour chaque spline construite à k. (La valeur par défaut est 1.0.) Dans chacune de ses composantes, la spline satisfera les deux conditions aux limites y"[0]=ky"[1] et y"[n]=ky"[n-1]. Ici y[0] et y[1] signifient les valeurs d'une composante spécifiée de la variable dépendante vectorielle y aux deux premiers points d'un jeu de données, et y[n-1] et y[n] les valeurs aux deux derniers points. Poser k à zéro produira une spline « naturelle », c'est-à-dire une spline qui a une courbure nulle aux deux extrémités du jeu de données. L'option -k ne peut pas être utilisée si -f ou -p est spécifié.
-n n

--number-of-intervals n
Divise l'intervalle sur lequel l'interpolation se produit en n sous-intervalles. Le nombre de points de données calculés et écrits en sortie sera n+1. La valeur par défaut pour n est 100.
-p

--periodic
Construit une spline périodique. Si cette option est spécifiée, les valeurs y pour le premier et le dernier point de chaque jeu de données doivent être égales. Les options -f et -k ne peuvent pas être utilisées si -p est spécifié.
-T tension

--tension tension
Chaque courbe interpolante sera une spline sous tension. Cette option définit la valeur de la tension (la valeur par défaut est 0.0).
Si tension est égale à zéro, la courbe sera une spline cubique par morceaux. Augmenter la tension au-dessus de zéro rend la courbe plus « serrée » et réduit la probabilité de points d'inflexion parasites. En effet, entre chaque paire de points successifs d'un jeu de données, la courbe satisfera l'équation différentielle d'ordre quatre y""=sgn(tension)*(tension^2)y" dans chacune de ses composantes. Lorsque tension augmente vers l'infini positif, elle convergera vers une ligne polygonale. L'option -T ne peut pas être utilisée si -f est spécifié.
-t tmin tmax [tpas]

--t-spacing tmin tmax [tpas]
Pour chaque jeu de données, définit l'intervalle sur lequel l'interpolation se produit comme étant l'intervalle entre tmin et tmax. Si tpas n'est pas spécifié, l'intervalle sera divisé dans le nombre de sous-intervalles spécifié par l'option -n.
Si l'option -t n'est pas utilisée, l'intervalle sur lequel l'interpolation se produit sera toute la plage de la variable indépendante dans le jeu de données. L'option -t doit toujours être utilisée si l'option -f est utilisée pour demander un comportement de type filtre (voir ci-dessus).

Options relatives au format

-d dimension

--y-dimension dimension
Définit la dimensionnalité de la variable dépendante y dans les fichiers d'entrée et de sortie à dimension. La dimension par défaut est 1.
-I format-donnees

--input-format format-donnees
Définit le format des données pour le(s) fichier(s) d'entrée à format-donnees, qui peut être l'un des suivants.
a
ASCII format (par défaut). Chaque fichier est une séquence de nombres à virgule flottante, interprétés comme les coordonnées t et y des points de données successifs d'un jeu de données. Si y est de dimension d, il y aura d+1 nombres pour chaque point. Les coordonnées t et y d'un point n'ont pas besoin d'apparaître sur la même ligne, et les points n'ont pas besoin d'apparaître sur des lignes différentes. Mais si une ligne vide se produit (c'est-à-dire que deux sauts de ligne consécutifs sont vus), elle est interprétée comme la fin d'un jeu de données et le début du suivant.
f
Format binaire en simple précision. Chaque fichier est une séquence de nombres à virgule flottante, interprétés comme les coordonnées t et y des points de données successifs d'un jeu de données. Si y est de dimension d, il y aura d+1 nombres pour chaque point. Les jeux de données successifs sont séparés par une seule occurrence de la quantité FLT_MAX, qui est le plus grand nombre à virgule flottante en simple précision possible. Sur la plupart des machines, cela est approximativement 3.4x10^38.
d
Format binaire en double précision. Chaque fichier est une séquence de nombres à virgule flottante en double précision, interprétés comme les coordonnées t et y des points de données successifs d'un jeu de données. Si y est de dimension d, il y aura d+1 nombres pour chaque point. Les jeux de données successifs sont séparés par une seule occurrence de la quantité DBL_MAX, qui est le plus grand nombre à virgule flottante en double précision possible. Sur la plupart des machines, cela est approximativement 1.8x10^308.
-O data-format

--output-format data-format
Définit le format des données pour le fichier de sortie à data-format, qui peut être l'un des suivants.
a
ASCII format (le défaut). Les points interpolés sont écrits sur la sortie standard, un par ligne. Chaque ligne commence par la coordonnée t, suivie des d composantes de la coordonnée y. Toutes les valeurs sont séparées par des espaces.
f
Format binaire en simple précision. Les points interpolés sont écrits sur la sortie standard. Le format est identique à celui de l'entrée binaire en simple précision.
d
Format binaire en double précision. Les points interpolés sont écrits sur la sortie standard. Le format est identique à celui de l'entrée binaire en double précision.
-A

--all
Écrit l'ensemble des points interpolés, que l'option -n soit utilisée ou non. Normalement, seul le dernier point est écrit.
-q

--quiet
Supprime les messages d'avertissement sur la présence de points de données dans un ordre incorrect ou dans un ordre qui viole la condition t croissant.

EXEMPLES

Pour interpoler une courbe à travers le fichier de données data.txt et écrire 100 points dans le fichier plot.txt:

spline -n 100 data.txt > plot.txt

Pour créer une spline sous tension à travers data.txt, avec une tension de 2, et écrire 200 points dans plot.txt:

spline -n 200 -T 2 data.txt > plot.txt

Pour interpoler une courbe à travers une série de jeux de données binaires en double précision dans data.bin et écrire les résultats en binaire en double précision dans plot.bin:

spline -I d -O d data.bin > plot.bin

Pour interpoler des données à deux dimensions (x, y) dans data.txt et écrire les résultats en ASCII dans plot.txt:

spline -d 2 data.txt > plot.txt

Pour interpoler une courbe à travers le fichier data.txt sur l'intervalle t de 0 à 10, avec 50 sous-intervalles, et écrire les résultats dans plot.txt:

spline -t 0 10 -n 50 data.txt > plot.txt

spline(1) — Utilitaires de traçage

NOM

spline - interpoler des ensembles de données avec des splines

SYNOPSIS

spline [-a [taille_pas [limite_inférieure]]] [-A] [-d dimensions] [-f format_données] [-I format_données] [-O format_données] [-P chiffres_significatifs] [-s] [--help] [--version]

DESCRIPTION

La commande spline construit une nouvelle définition d'ensemble de données par interpolation à partir d'un ensemble de données d'entrée. L'ensemble de données d'entrée est composé de points (t, y), où t est la variable indépendante (l'abscisse) et y est la variable dépendante (l'ordonnée). L'ensemble de données de sortie est une interpolation polynomiale par morceaux de l'ensemble de données d'entrée.

La commande spline lit les données d'entrée à partir de l'entrée standard et écrit l'ensemble de données interpolé à la sortie standard. Les ensembles de données d'entrée peuvent être dans une variété de formats.

-d dimensions
Détermine le nombre de coordonnées dans la variable dépendante y. La valeur par défaut est 1. Cette option est requise si les ensembles de données d'entrée contiennent des variables dépendantes multidimensionnelles.
-f format_données
Détermine le format dans lequel les ensembles de données d'entrée sont écrits. Les formats disponibles sont :
a
Format texte ASCII. Chaque fichier est une séquence de nombres en virgule flottante, interprétés comme les coordonnées t et y des points de données successifs dans un ensemble de données. Si y est d-dimensionnel, il y aura d+1 nombres pour chaque point. Les ensembles de données successifs sont séparés par une seule occurrence de la quantité DBL_MAX, qui est le plus grand nombre possible en virgule flottante double précision. Sur la plupart des machines, cela correspond à environ 1.8x10^308.
i
Format entier binaire. Chaque fichier est une séquence d'entiers, interprétés comme les coordonnées t et y des points de données successifs dans un ensemble de données. Si y est d-dimensionnel, il y aura d+1 nombres pour chaque point. Les ensembles de données successifs sont séparés par une seule occurrence de la quantité INT_MAX, qui est le plus grand entier possible. Sur la plupart des machines, cela correspond à 2^31-1.
-a [taille_pas [limite_inférieure]]

--auto-abscissa [taille_pas [limite_inférieure]]
Générer automatiquement des valeurs pour t, la variable indépendante (les valeurs par défaut de taille_pas et limite_inférieure sont respectivement 1.0 et 0.0).
Indépendamment du format des données (`a', `f', `d', ou `i'), cette option spécifie que les valeurs de t sont manquantes dans le fichier d'entrée : les ensembles de données à lire ne contiennent que les valeurs de y, la variable dépendante. Ainsi, si y est d-dimensionnel, il n'y aura que d nombres pour chaque point. L'incroment de chaque valeur t à la suivante sera taille_pas, et la première valeur t sera limite_inférieure. Cette option est utile, par exemple, lors de l'interpolation de courbes plutôt que de fonctions.
-A

--auto-dist-abscissa
Générer automatiquement des valeurs pour t, la variable indépendante. C'est une forme variante de l'option -a. L'incroment de chaque valeur t à la suivante sera la distance dans l'espace d-dimensionnel entre les valeurs y correspondantes, et la première valeur t sera 0.0. C'est-à-dire, t sera la "longueur d'arc polygonale". Cette option est utile lorsque l'on interpole des courbes plutôt que des fonctions.
-O format_données

--output-format format_données
Définir le format des données pour le fichier de sortie à format_données. L'interprétation de format_données est la même que pour l'option -I. La valeur par défaut est `a', c'est-à-dire le format ASCII.
-P chiffres_significatifs

--precision chiffres_significatifs
Définir la précision numérique des valeurs t et y dans le fichier de sortie à chiffres_significatifs. Ceci n'a d'effet que si le fichier de sortie est écrit au format `a', c'est-à-dire en ASCII. chiffres_significatifs doit être un entier positif (la valeur par défaut est 6).
-s

--suppress-abscissa
Omettre la variable indépendante t du fichier de sortie ; pour chaque point, ne fournir que la variable dépendante y. Si y est d-dimensionnel, il n'y aura que d nombres pour chaque point, et non d+1. Cette option est utile lorsque l'on interpole des courbes plutôt que des fonctions.

OPTIONS INFORMATIONELLES

--help
Afficher une liste des options en ligne de commande, puis quitter.
--version
Afficher le numéro de version de spline et du paquet d'utilitaires de traçage, puis quitter.

EXEMPLES

Taper

echo 0 0 1 1 2 0 | spline

produira sur la sortie standard un ensemble de données interpolé composé de 101 points de données. Si représenté graphiquement, cet ensemble de données interpolé produira une parabole.

Il est parfois utile d'interpoler entre une séquence de points arbitrairement placés dans un espace d-dimensionnel, c'est-à-dire de "spliner une courbe" plutôt qu'une fonction. Les options -a et -s sont utilisées pour cela. Par exemple,

echo 0 0 1 0 1 1 0 1 | spline -d 2 -a -s

produira sur la sortie standard un ensemble de données de 101 points qui interpole entre les quatre points (0,0), (1,0), (1,1) et (0,1). L'option -d 2 spécifie que la variable dépendante y est bidimensionnelle. L'option -a spécifie que les valeurs t sont manquantes dans l'entrée et doivent être générées automatiquement. L'option -s spécifie que les valeurs t doivent être supprimées de la sortie.

AUTEURS
