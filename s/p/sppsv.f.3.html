sous-programme sppsv (caractère uplo, entier n, entier nrhs, réel, dimension( * ) ap, réel, dimension( ldb, * ) b, entier ldb, entier info)

SPPSV calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> SPPSV calcule la solution d'un système linéaire réel
!>    A * X = B,
!> où A est une matrice symétrique définie positive N par N stockée en
!> format compacté et X et B sont des matrices N par NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A en
!>    A = U**T* U,  si UPLO = 'U', ou
!>    A = L * L**T,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure.
!> La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau de type REAL, de dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice symétrique
!>          A, compacté par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          En sortie, si INFO = 0, le facteur U ou L de la décomposition de Cholesky
!>          A = U**T*U ou A = L*L**T, dans le même format de stockage que A.
!>

B

!>          B est un tableau de type REAL, de dimension (LDB,NRHS)
!>          En entrée, la matrice B du côté droit de N par NRHS.
!>          En sortie, si INFO = 0, la matrice solution X de N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension de tête du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être complétée et la solution n'a pas été calculée.
!>

Détails supplémentaires :

!>
!>  Le schéma de stockage compacté est illustré par l'exemple suivant
!>  lorsque N = 4, UPLO = 'U' :
!>
!>  Stockage bidimensionnel de la matrice symétrique A :
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Stockage compacté du triangle supérieur de A :
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
