spice-vdagent(1) Manuel des commandes générales spice-vdagent(1)

NOM

spice-vdagent - Agent de session X11 de l'agent invité Spice

SYNTAXE

spice-vdagent [OPTIONS]

DESCRIPTION

L'agent invité Spice pour Linux se compose de 2 parties, un démon système spice-vdagentd et un agent de session X11 spice-vdagent dont il y a un par session X11.
spice-vdagent est automatiquement démarré dans les environnements de bureau qui respectent /etc/xdg/autostart, et sous gdm.

FONCTIONNALITÉS

L'agent invité Spice ajoute les fonctionnalités suivantes aux invités Spice sous Linux :

Mode souris client (pas besoin de capturer la souris par le client, pas de latence de la souris)

Ajustement automatique du nombre de moniteurs virtuels de la session X11, et de leur résolution, au nombre de fenêtres clientes et à leur résolution

Support du copier-coller (texte et images) entre la session X11 active et le client, ceci supporte à la fois la sélection primaire et le presse-papiers

Support pour le transfert de fichiers du client vers l'agent

OPTIONS

-h
Affiche une courte description de toutes les options de ligne de commande
-d
Journalise les messages de débogage
-s port
Définit le port série virtio port (par défaut : /dev/virtio-ports/com.redhat.spice.0)
-x
Ne pas daemoniser
-f répertoire|xdg-bureau|xdg-téléchargement
Définit le répertoire où sauvegarder les fichiers envoyés par le client, cela peut être un répertoire arbitraire ou l'une des valeurs spéciales xdg-bureau ou xdg-téléchargement pour sélectionner le répertoire par défaut xdg Bureau ou xdg Téléchargement. Si aucune valeur n'est spécifiée, la valeur par défaut est xdg-bureau lorsqu'on s'exécute dans un environnement de bureau qui a des icônes sur le bureau et xdg-téléchargement sous d'autres environnements de bureau.
-o 0|1
Désactive/active l'ouverture du répertoire de sauvegarde de fichiers avec xdg-open (affichant le répertoire dans le gestionnaire de fichiers) lorsqu'un transfert de fichier du client est terminé. Si aucune valeur n'est spécifiée, la valeur par défaut est 0 lorsqu'on s'exécute dans un environnement de bureau qui a des icônes sur le bureau et 1 sous d'autres environnements de bureau.
