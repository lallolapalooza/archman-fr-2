DOCUMENTATION DE FONCTION/SOUS-PROGRAMME

sous-programme spteqr (caractère compz, entier n, réel, dimension( * ) d, réel, dimension( * ) e, réel, dimension( ldz, * ) z, entier ldz, réel, dimension( * ) work, entier info)

SPTEQR

But:

!>
!> SPTEQR calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une
!> matrice tridiagonale symétrique définie positive en factorisant d'abord la
!> matrice à l'aide de SPTTRF, puis en appelant SBDSQR pour calculer les valeurs singulières
!> du facteur bidiagonal.
!>
!> Cette routine calcule les valeurs propres de la matrice tridiagonale définie
!> positive avec une grande précision relative. Cela signifie que si les
!> valeurs propres varient sur plusieurs ordres de grandeur, les
!> petites valeurs propres et leurs vecteurs propres correspondants seront calculés
!> plus précisément que, par exemple, avec la méthode QR standard.
!>
!> Les vecteurs propres d'une matrice symétrique définie positive complète ou bande
!> peuvent également être trouvés si SSYTRD, SSPTRD, ou SSBTRD a été utilisé pour
!> réduire cette matrice à la forme tridiagonale. (La réduction à la forme tridiagonale,
!> cependant, peut exclure la possibilité d'obtenir une grande
!> précision relative dans les petites valeurs propres de la matrice d'origine, si
!> ces valeurs propres varient sur plusieurs ordres de grandeur.)
!>

Paramètres

COMPZ 
!>          COMPZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres.
!>          = 'V':  Calculer également les vecteurs propres de la matrice
!>                  symétrique d'origine. Le tableau Z contient la matrice orthogonale
!>                  utilisée pour réduire la matrice d'origine à la forme tridiagonale.
!>          = 'I':  Calculer également les vecteurs propres de la matrice tridiagonale.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice.  N >= 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale.
!>          À la sortie normale, D contient les valeurs propres, dans l'ordre décroissant.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice tridiagonale.
!>          À la sortie, E a été détruit.
!>

Z

!>          Z est un tableau REAL, dimension (LDZ, N)
!>          À l'entrée, si COMPZ = 'V', la matrice orthogonale utilisée dans la
!>          réduction à la forme tridiagonale.
!>          À la sortie, si COMPZ = 'V', les vecteurs propres orthonormés de la
!>          matrice symétrique d'origine ;
!>          si COMPZ = 'I', les vecteurs propres orthonormés de la
!>          matrice tridiagonale.
!>          Si INFO > 0 à la sortie, Z contient les vecteurs propres associés
!>          uniquement aux valeurs propres stockées.
!>          Si  COMPZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          COMPZ = 'V' ou 'I', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (4*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = i, et i est :
!>                <= N  la factorisation de Cholesky de la matrice n'a pas
!>                      pu être effectuée car le mineur principal principal d'ordre i n'était pas positif.
!>                > N   l'algorithme SVD n'a pas convergé ;
!>                      si INFO = N+i, i éléments hors diagonale du
!>                      facteur bidiagonal n'ont pas convergé vers zéro.
!>
