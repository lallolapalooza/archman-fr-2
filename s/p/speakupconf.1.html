NOM

speakupconf - script pour charger/sauvegarder toutes les variables de speakup

SYNTAXE

speakupconf save|load

DESCRIPTION

Speakupconf est un script qui sauvegarde et restaure les variables personnalisables de speakup.

S'il est exécuté en tant que root, il sauvegarde dans /etc/speakup, ou, s'il est exécuté en tant qu'utilisateur, il sauvegarde dans $HOME/.speakup. Cela signifie que chaque utilisateur peut avoir des paramètres speakup uniques.
