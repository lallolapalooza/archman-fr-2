sous-programme spbsvx (character fact, character uplo, integer n, integer kd, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices OTHER

Objectif :

!>
!> SPBSVX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T pour
!> calculer la solution d'un système réel d'équations linéaires
!>    A * X = B,
!> où A est une matrice bande symétrique définie positive de taille N x N et X
!> et B sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    L'équilibrage du système dépend de la mise à l'échelle de la matrice A,
!>    mais si l'équilibrage est utilisé, A est écrasée par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme suit :
!>       A = U**T * U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice bande triangulaire supérieure et L est une matrice bande triangulaire inférieure.
!>
!> 3. Si le mineur principal d'ordre i n'est pas positif,
!>    la routine retourne avec INFO = i. Sinon, la forme factorisée de A est utilisée pour estimer le numéro de condition de la matrice
!>    A. Si l'inverse du numéro de condition est inférieur à la précision machine, INFO = N+1 est retourné comme avertissement, mais la routine continue à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie en entrée,
!>          et si ce n'est pas le cas, si la matrice A doit être équilibrée avant d'être factorisée.
!>          = 'F':  En entrée, AFB contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec les facteurs d'échelle donnés par S.  AB et AFB ne seront pas
!>                  modifiés.
!>          = 'N':  La matrice A sera copiée dans AFB et factorisée.
!>          = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau REAL, dimension (LDAB,N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande symétrique
!>          A, stocké dans les KD+1 premières lignes du tableau, sauf
!>          si FACT = 'F' et EQUED = 'Y', alors A doit contenir la
!>          matrice équilibrée diag(S)*A*diag(S). La j-ème colonne de A
!>          est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) pour max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(N,j+KD).
!>          Voir ci-dessous pour plus de détails.
!>
!>          En sortie, si FACT = 'E' et EQUED = 'Y', A est écrasée par
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau A.  LDAB >= KD+1.
!>

AFB

!>          AFB est un tableau REAL, dimension (LDAFB,N)
!>          Si FACT = 'F', alors AFB est un argument d'entrée et contient en entrée
!>          le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T de la matrice bande
!>          A, dans le même format de stockage que A (voir AB). Si EQUED = 'Y',
!>          alors AFB est la forme factorisée de la matrice A équilibrée.
!>
!>          Si FACT = 'N', alors AFB est un argument de sortie et contient en sortie
!>          le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T.
!>
!>          Si FACT = 'E', alors AFB est un argument de sortie et contient en sortie
!>          le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T de la matrice équilibrée A (voir la description de A pour la forme de la
!>          matrice équilibrée).
!>

LDAFB

!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N':  Aucun équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y':  L'équilibrage a été effectué, c'est-à-dire que A a été remplacé par
!>                  diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F'; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est un tableau REAL, dimension (N)
!>          Les facteurs d'échelle pour A ; non accédé si EQUED = 'N'. S est
!>          un argument d'entrée si FACT = 'F'; sinon, S est un argument de
!>          sortie.  Si FACT = 'F' et EQUED = 'Y', chaque élément de S
!>          doit être positif.
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B de taille N x NRHS.
!>          En sortie, si EQUED = 'N', B n'est pas modifié ; si EQUED = 'Y',
!>          B est écrasée par diag(S) * B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS
!>          du système original d'équations. Notez que si EQUED = 'Y',
!>          A et B sont modifiés en sortie, et la solution du
!>          système équilibré est inv(diag(S))*X.
!>

;

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REEL
!>          L'estimation du nombre de conditionnement réciproque de la matrice
!>          A après équilibration (si effectuée). Si RCOND est inférieur à la
!>          précision machine (en particulier, si RCOND = 0), la matrice
!>          est singulière à la précision de travail. Cette condition
!>          est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau REEL, de dimension (NRHS)
!>          La borne d'erreur directe estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisé par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          sur-estimation de l'erreur vraie.
!>

BERR

!>          BERR est un tableau REEL, de dimension (NRHS)
!>          L'erreur résiduelle relative par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          tout élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau REEL, de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ième argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est
!>                       singulière à la précision de travail. Néanmoins,
!>                       la solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
