speedtest-cli(1) Manuel des commandes générales speedtest-cli(1)

NOM

speedtest-cli - Interface en ligne de commande pour tester la bande passante Internet en utilisant speedtest.net

SYNOPIS

speedtest-cli [OPTION...]

DESCRIPTION

Speedtest.net est un service Web permettant de tester votre connexion haut débit en téléchargeant un fichier depuis un serveur speedtest.net proche sur le Web. Cet outil vous permet d'accéder au service depuis la ligne de commande.

Speedtest mini est une version du serveur Speedtest.net que vous pouvez héberger localement.

OPTIONS

Usage : speedtest-cli [OPTION...]

Options d'aide

-h, --help

Affiche l'aide d'utilisation de l'outil.

Options

--no-download

Ne pas effectuer le test de téléchargement

--no-upload

Ne pas effectuer le test d'envoi

--single

Utiliser une seule connexion au lieu de plusieurs. Ceci simule un transfert de fichier typique.

--bytes

Afficher les valeurs en octets au lieu de bits. N'affecte pas l'image générée par --share, ni la sortie de --json ou --csv

--share

Générer et fournir une URL vers l'image des résultats speedtest.net, non affichée avec --csv

--simple

Supprimer la sortie verbeuse, n'afficher que les informations de base

--csv

Supprimer la sortie verbeuse, n'afficher que les informations de base au format CSV. Les débits sont indiqués en bit/s et ne sont pas affectés par --bytes

--csv-delimiter CSV_DELIMITER

Délimiteur à un caractère à utiliser dans la sortie CSV. Par défaut ","

--csv-header

Afficher les en-têtes CSV

--json

Supprimer la sortie verbeuse, n'afficher que les informations de base au format JSON. Les débits sont indiqués en bit/s et ne sont pas affectés par --bytes

--list

Afficher une liste de serveurs speedtest.net triés par distance

--server SERVER

Spécifier un identifiant de serveur pour le test. Peut être fourni plusieurs fois

--exclude EXCLUDE

Exclure un serveur de la sélection. Peut être fourni plusieurs fois

--mini MINI

URL du serveur Speedtest Mini

--source SOURCE

Adresse IP source à lier

--timeout TIMEOUT

Délai d'attente HTTP en secondes. Par défaut 10

--secure

Utiliser HTTPS au lieu de HTTP lors de la communication avec les serveurs gérés par speedtest.net

--no-pre-allocate

Ne pas pré-allouer les données d'envoi. La pré-allocation est activée par défaut pour améliorer les performances d'envoi. Pour prendre en charge les systèmes avec une mémoire insuffisante, utilisez cette option pour éviter une MemoryError

--version

Afficher le numéro de version et quitter

EXEMPLES

Trouver automatiquement le serveur le plus proche et démarrer le test

speedtest-cli

Spécifier le test contre le serveur 1491

speedtest-cli --server 1491

Tester contre Speedtest Mini

speedtest-cli --mini 172.18.66.1
