DESCRIPTION

La commande spinbox crée une nouvelle fenêtre (donnée par l'argument nomChemin) et en fait un widget spinbox. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer certains aspects du sélecteur, tels que ses couleurs, sa police et son relief. La commande spinbox renvoie l'argument nomChemin. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée nomChemin, mais le parent de nomChemin doit exister.

Un spinbox est un widget entry étendu qui permet à l'utilisateur de se déplacer, ou de faire tourner, à travers un ensemble fixe de valeurs ascendantes ou descendantes telles que des heures ou des dates.

Si un spinbox exporte sa sélection (voir l'option -exportselection), il respectera les protocoles standards pour la gestion de la sélection ; les sélections des spinboxes sont disponibles sous le type STRING. Les spinboxes respectent également les règles standards de Tk pour la gestion du focus d'entrée. Lorsqu'un spinbox a le focus d'entrée, il affiche un curseur d'insertion pour indiquer où les nouveaux caractères seront insérés.

Les spinboxes sont capables d'afficher des chaînes trop longues pour tenir entièrement dans la fenêtre du widget. Dans ce cas, seule une partie de la chaîne sera affichée ; les commandes décrites ci-dessous peuvent être utilisées pour modifier la vue dans la fenêtre. Les spinboxes utilisent le mécanisme standard -xscrollcommand pour interagir avec les barres de défilement (voir la description de l'option -xscrollcommand pour plus de détails). Ils prennent également en charge le balayage, comme décrit ci-dessous.

VALIDATION

La validation fonctionne en définissant l'option -validatecommand sur un script qui sera évalué selon l'option -validate comme suit :

none
Par défaut. Cela signifie qu'aucune validation n'aura lieu.
focus
Le -validatecommand sera appelé lorsque le spinbox recevra ou perdra le focus.
focusin
Le -validatecommand sera appelé lorsque le spinbox recevra le focus.
focusout
Le -validatecommand sera appelé lorsque le spinbox perdra le focus.
key
Le -validatecommand sera appelé lorsque le spinbox sera édité.
all
Le -validatecommand sera appelé pour toutes les conditions ci-dessus.

Il est possible d'effectuer des substitutions de pourcentage sur les scripts -validatecommand et -invalidcommand, comme vous le feriez dans un script bind. Les substitutions suivantes sont reconnues :

%d
Type d'action : 1 pour insert, 0 pour delete, ou -1 pour validation par focus, forcée ou textvariable.
%i
Index du caractère à insérer/supprimer, le cas échéant, sinon -1.
%P
La valeur que le spinbox devrait avoir après l'édition. Si vous configurez le widget spinbox pour qu'il ait un nouveau textvariable, ce sera la valeur de ce textvariable.
%s
La valeur actuelle du spinbox avant l'édition.
%S
La chaîne de texte en cours d'insertion/suppression, le cas échéant. Sinon, c'est une chaîne vide.
%v
Le type de validation actuellement défini.
%V
Le type de validation qui a déclenché le rappel (key, focusin, focusout, forced).
%W
Le nom du widget spinbox.

En général, le mélange de -textvariable et de -validatecommand peut être dangereux. Tous les problèmes ont été résolus de manière à ce que l'utilisation de -validatecommand n'interfère pas avec le comportement traditionnel du widget spinbox. L'utilisation de -textvariable à des fins de lecture seule ne causera jamais de problèmes. Le danger survient lorsque vous essayez de définir -textvariable à quelque chose que -validatecommand n'accepterait pas, ce qui fait que -validate devient none (le -invalidcommand ne sera pas déclenché). Il en va de même lorsqu'une erreur survient lors de l'évaluation de -validatecommand.

Principalement, une erreur se produira lorsque -validatecommand ou -invalidcommand rencontre une erreur dans son script lors de l'évaluation, ou lorsque -validatecommand ne renvoie pas une valeur booléenne Tcl valide. L'option -validate se réglera également sur none lorsque vous éditez le widget spinbox à partir du -validatecommand ou du -invalidcommand. Ces éditions remplaceront celle en cours de validation. Si vous souhaitez éditer la valeur du widget pendant la validation et que l'option -validate reste activée, vous devriez inclure la commande

     %W config -validate %v
dans le -validatecommand ou le -invalidcommand (depuis lequel vous éditiez le widget spinbox). Il est également recommandé de ne pas définir un -textvariable associé pendant la validation, car cela pourrait désynchroniser le widget spinbox avec le -textvariable.

De plus, l'option -validate se réglera sur none lorsque la valeur du spinbox sera modifiée en raison de l'ajustement de -from ou -to et que le -validatecommand renvoie faux. Par exemple :

     spinbox pathName -from 1 -to 10 -validate all -vcmd {return 0}
définira en fait l'option -validate sur none car la valeur par défaut du spinbox est modifiée (en raison des options -from et -to) à une valeur non acceptée par le script de validation.

De plus, une validation forcée est effectuée lors de l'invocation de n'importe quel bouton du spinbox. Si le script de validation renvoie faux dans cette situation, l'option -validate sera automatiquement définie sur none.

COMMANDE DU WIDGET

La commande spinbox crée une nouvelle commande Tcl dont le nom est pathName. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

pathName option ?arg arg ...?
La option et les args déterminent le comportement exact de la commande.

INDICES

Beaucoup des commandes de widget pour les spinboxes prennent un ou plusieurs indices comme arguments. Un indice spécifie un caractère particulier dans la chaîne du spinbox, de l'une des manières suivantes :

nombre
Spécifie le caractère sous forme d'indice numérique, où 0 correspond au premier caractère de la chaîne.
anchor
Indique le point d'ancrage de la sélection, qui est défini avec les commandes de widget select from et select adjust.
end
Indique le caractère juste après le dernier caractère de la chaîne du spinbox. Ceci équivaut à spécifier un indice numérique égal à la longueur de la chaîne du spinbox.
insert
Indique le caractère adjacent et immédiatement suivant le curseur d'insertion.
sel.first
Indique le premier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre du spinbox.
sel.last
Indique le caractère juste après le dernier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre du spinbox.
@nombre
Dans cette forme, nombre est traité comme une coordonnée x dans la fenêtre du spinbox ; le caractère qui couvre cette coordonnée x est utilisé. Par exemple, “@0” indique le caractère le plus à gauche de la fenêtre.

Des abréviations peuvent être utilisées pour l'une des formes ci-dessus, par exemple “e” ou “sel.f”. En général, les indices hors limites sont automatiquement arrondis à la valeur légale la plus proche.

SOUS-COMMANDES

Les commandes suivantes sont possibles pour les widgets spinbox :

pathName bbox index
Retourne une liste de quatre nombres décrivant la boîte englobante du caractère donné par index. Les deux premiers éléments de la liste donnent les coordonnées x et y du coin supérieur gauche de la zone d'écran couverte par le caractère (en pixels par rapport au widget) et les deux derniers éléments donnent la largeur et la hauteur du caractère, en pixels. La boîte englobante peut faire référence à une zone située en dehors de la zone visible de la fenêtre.
pathName cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande spinbox.
pathName configure ?option? ?value option value ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour pathName (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans value, la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie les options du widget données pour leur attribuer les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande spinbox.
pathName delete first ?last?
Supprime un ou plusieurs éléments du spinbox. First est l'indice du premier caractère à supprimer, et last est l'indice du caractère juste après le dernier à supprimer. Si last n'est pas spécifié, il prend par défaut la valeur first+1, c'est-à-dire qu'un seul caractère est supprimé. Cette commande retourne une chaîne vide.
pathName get
Retourne la chaîne du spinbox.
pathName icursor index
Arrange l'affichage du curseur d'insertion juste avant le caractère donné par index. Retourne une chaîne vide.
pathName identify x y
Retourne le nom de l'élément de fenêtre correspondant aux coordonnées x et y dans le spinbox. La valeur de retour est l'un des éléments suivants : none, buttondown, buttonup, entry.

pathName

See “pathName” in Tk commands for a list of commands that operate on the various Tk controls.

The pathName commands described below are specific to spinboxes.

pathName activate
Activates the spinbox widget. This is used to make the spinbox visible on the screen, and to place the insertion cursor within it. If a validation command is associated with the widget, it is evaluated when the spinbox is activated. If the validation command returns false, then the activation fails and an error is returned.
pathName cget option
Returns the current value of the specified configuration option; see “STANDARD OPTIONS” section below.
pathName index index
Returns the numerical index corresponding to index.
pathName insert index string
Insert the characters of string just before the character indicated by index. Returns an empty string.
pathName invoke element
Causes the specified element, either buttondown or buttonup, to be invoked, triggering the action associated with it.
pathName scan option args
This command is used to implement scanning on spinboxes. It has two forms, depending on option:
pathName scan mark x
Records x and the current view in the spinbox window; used in conjunction with later scan dragto commands. Typically this command is associated with a mouse button press in the widget. It returns an empty string.
pathName scan dragto x
This command computes the difference between its x argument and the x argument to the last scan mark command for the widget. It then adjusts the view left or right by 10 times the difference in x-coordinates. This command is typically associated with mouse motion events in the widget, to produce the effect of dragging the spinbox at high speed through the window. The return value is an empty string.
pathName selection option arg
This command is used to adjust the selection within a spinbox. It has several forms, depending on option:
pathName selection adjust index
Locate the end of the selection nearest to the character given by index, and adjust that end of the selection to be at index (i.e. including but not going beyond index). The other end of the selection is made the anchor point for future select to commands. If the selection is not currently in the spinbox, then a new selection is created to include the characters between index and the most recent selection anchor point, inclusive. Returns an empty string.
pathName selection clear
Clear the selection if it is currently in this widget. If the selection is not in this widget then the command has no effect. Returns an empty string.
pathName selection element ?element?
Sets or gets the currently selected element. If a spinbutton element is specified, it will be displayed depressed.
pathName selection from index
Set the selection anchor point to just before the character given by index. Does not change the selection. Returns an empty string.
pathName selection present
Returns 1 if there is are characters selected in the spinbox, 0 if nothing is selected.
pathName selection range start end
Sets the selection to include the characters starting with the one indexed by start and ending with the one just before end. If end refers to the same character as start or an earlier one, then the spinbox's selection is cleared.
pathName selection to index
If index is before the anchor point, set the selection to the characters from index up to but not including the anchor point. If index is the same as the anchor point, do nothing. If index is after the anchor point, set the selection to the characters from the anchor point up to but not including index. The anchor point is determined by the most recent select from or select adjust command in this widget. If the selection is not in this widget then a new selection is created using the most recent anchor point specified for the widget. Returns an empty string.
pathName set ?string?
If string is specified, the spinbox will try and set it to this value, otherwise it just returns the spinbox's string. If validation is on, it will occur when setting the string.
pathName validate
This command is used to force an evaluation of the -validatecommand independent of the conditions specified by the -validate option. This is done by temporarily setting the -validate option to all. It returns 0 or 1.
pathName xview args
This command is used to query and change the horizontal position of the text in the widget's window. It can take any of the following forms:
pathName xview
Returns a list containing two elements. Each element is a real fraction between 0 and 1; together they describe the horizontal span that is visible in the window. For example, if the first element is .2 and the second element is .6, 20% of the spinbox's text is off-screen to the left, the middle 40% is visible in the window, and 40% of the text is off-screen to the right. These are the same values passed to scrollbars via the -xscrollcommand option.
pathName xview index
Adjusts the view in the window so that the character given by index is displayed at the left edge of the window.
pathName xview moveto fraction
Adjusts the view in the window so that the character fraction of the way through the text appears at the left edge of the window. Fraction must be a fraction between 0 and 1.
pathName xview scroll number what
This command shifts the view in the window left or right according to number and what. Number must be an integer. What must be either units or pages or an abbreviation of one of these. If what is units, the view adjusts left or right by number average-width characters on the display; if it is pages then the view adjusts by number screenfuls. If number is negative then characters farther to the left become visible; if it is positive then characters farther to the right become visible.

LIAISONS PAR DÉFAUT

Tk crée automatiquement des liaisons de classe pour les boîtes de sélection qui leur confèrent le comportement par défaut suivant. Dans les descriptions ci-dessous, un « mot » fait référence à un groupe contigu de lettres, de chiffres ou de caractères « _ », ou à tout caractère unique autre que ceux-ci.

[1]
Cliquer sur le bouton 1 de la souris positionne le curseur d'insertion juste avant le caractère situé sous le curseur de la souris, attribue le focus d'entrée à ce widget et efface toute sélection dans le widget. Faire glisser avec le bouton 1 de la souris sélectionne la plage de texte entre le curseur d'insertion et le caractère sous la souris.
[2]
Double-cliquer avec le bouton 1 de la souris sélectionne le mot sous la souris et positionne le curseur d'insertion au début du mot. Faire glisser après un double-clic sélectionnera la plage de texte constituée de mots entiers.
[3]
Triple-cliquer avec le bouton 1 de la souris sélectionne tout le texte de la boîte de sélection et positionne le curseur d'insertion avant le premier caractère.
[4]
Les extrémités de la sélection peuvent être ajustées en faisant glisser avec le bouton 1 de la souris tout en maintenant la touche Maj enfoncée ; cela ajustera l'extrémité de la sélection qui était la plus proche du curseur de la souris lorsque le bouton 1 a été enfoncé. Si le bouton est double-cliqué avant de faire glisser, la sélection sera ajustée par unités de mots entiers.
[5]
Cliquer sur le bouton 1 de la souris avec la touche Ctrl enfoncée positionnera le curseur d'insertion dans la boîte de sélection sans affecter la sélection.
[6]
Si des caractères d'impression normaux sont tapés dans une boîte de sélection, ils sont insérés à la position du curseur d'insertion.
[7]
La vue dans la boîte de sélection peut être ajustée en faisant glisser avec le bouton du milieu de la souris (bouton 2, ou bouton 3 dans TkAqua). Si le bouton du milieu de la souris est cliqué sans déplacer la souris, la sélection est copiée dans la boîte de sélection à la position du curseur de la souris.
[8]
Si la souris est déplacée hors de la boîte de sélection par la gauche ou par la droite pendant que le bouton 1 est enfoncé, la boîte de sélection défilera automatiquement pour rendre plus de texte visible (s'il y a plus de texte hors écran du côté où la souris a quitté la fenêtre).
[9]
Les touches Gauche et Droite déplacent le curseur d'insertion d'un caractère vers la gauche ou vers la droite ; elles effacent également toute sélection dans la boîte de sélection et définissent l'ancre de sélection. Si Gauche ou Droite est tapé avec la touche Maj enfoncée, le curseur d'insertion se déplace et la sélection est étendue pour inclure le nouveau caractère. Ctrl-Gauche et Ctrl-Droite déplacent le curseur d'insertion par mots, et Ctrl-Maj-Gauche et Ctrl-Maj-Droite déplacent le curseur d'insertion par mots et étendent également la sélection. Ctrl-b et Ctrl-f se comportent de la même manière que Gauche et Droite, respectivement. Meta-b et Meta-f se comportent de la même manière que Ctrl-Gauche et Ctrl-Droite, respectivement.
[10]
La touche Début, ou Ctrl-a, déplacera le curseur d'insertion au début de la boîte de sélection et effacera toute sélection dans la boîte de sélection. Maj-Début déplace le curseur d'insertion au début de la boîte de sélection et étend également la sélection jusqu'à ce point.
[11]
La touche Fin, ou Ctrl-e, déplacera le curseur d'insertion à la fin de la boîte de sélection et effacera toute sélection dans la boîte de sélection. Maj-Fin déplace le curseur à la fin et étend la sélection jusqu'à ce point.
[12]
dd>La touche Select et Control-Espace définissent l'ancre de sélection à la position du curseur d'insertion. Elles n'affectent pas la sélection actuelle. Shift-Select et Control-Shift-Espace ajustent la sélection à la position actuelle du curseur d'insertion, sélectionnant de l'ancre au curseur d'insertion s'il n'y avait pas de sélection auparavant.
[13]
Control-/ sélectionne tout le texte dans la boîte déroulante.
[14]
Control-\ efface toute sélection dans la boîte déroulante.
[15]
La touche F16 (marquée Copy sur de nombreux postes de travail Sun) ou Meta-w copie la sélection dans le widget vers le presse-papiers, s'il y a une sélection.
[16]
La touche F20 (marquée Cut sur de nombreux postes de travail Sun) ou Control-w copie la sélection dans le widget vers le presse-papiers et supprime la sélection. S'il n'y a pas de sélection dans le widget, ces touches n'ont aucun effet.
[17]
La touche F18 (marquée Paste sur de nombreux postes de travail Sun) ou Control-y insère le contenu du presse-papiers à la position du curseur d'insertion.
[18]
La touche Suppr supprime la sélection, s'il y en a une dans la boîte déroulante. S'il n'y a pas de sélection, elle supprime le caractère à droite du curseur d'insertion.
[19]
La touche Retour arrière et Control-h suppriment la sélection, s'il y en a une dans la boîte déroulante. S'il n'y a pas de sélection, elle supprime le caractère à gauche du curseur d'insertion.
[20]
Control-d supprime le caractère à droite du curseur d'insertion.
[21]
Meta-d supprime le mot à droite du curseur d'insertion.
[22]
Control-k supprime tous les caractères à droite du curseur d'insertion.
[23]
Control-t inverse l'ordre des deux caractères à droite du curseur d'insertion.

Si la boîte déroulante est désactivée à l'aide de l'option -state, la vue de la boîte déroulante peut toujours être ajustée et le texte dans la boîte déroulante peut toujours être sélectionné, mais aucun curseur d'insertion ne sera affiché et aucune modification de texte n'aura lieu.

Le comportement des boîtes déroulantes peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.
