WABT(1) Manuel des commandes générales WABT(1)

NOM

spectest-interp — lire un fichier JSON Spectest et exécuter ses tests dans l'interpréteur

SYNTAXE

spectest-interp [options] fichier

DESCRIPTION

spectest-interp lit un fichier JSON Spectest et exécute ses tests dans l'interpréteur.

Les options sont les suivantes :

--help
Afficher un message d'aide
--version
Afficher les informations sur la version
-v, --verbose
Utiliser plusieurs fois pour plus d'informations
--enable-exceptions
Activer la gestion expérimentale des exceptions
--disable-mutable-globals
Désactiver les importations/exportations de globales mutables
--disable-saturating-float-to-int
Désactiver les opérateurs de conversion saturante de flottants vers entiers
--disable-sign-extension
Désactiver les opérateurs d'extension de signe
--disable-simd
Désactiver le support SIMD
--enable-threads
Activer le support des threads
--enable-function-references
Activer les références de fonctions typées
--disable-multi-value
Désactiver les multi-valeurs
--enable-tail-call
Activer le support des appels finaux
--disable-bulk-memory
Désactiver les opérations de mémoire en bloc
--disable-reference-types
Désactiver les types de références (externref)
--enable-annotations
Activer la syntaxe personnalisée d'annotations
--enable-code-metadata
Activer les métadonnées de code
--enable-gc
Activer le garbage collection
--enable-memory64
Activer la mémoire 64 bits
--enable-multi-memory
Activer la multi-mémoire
--enable-extended-const
Activer les expressions constantes étendues
--enable-all
Activer toutes les fonctionnalités
-V, --value-stack-size=TAILLE
Taille de la pile de valeurs en éléments
-C, --call-stack-size=TAILLE
Taille de la pile d'appels en éléments
-t, --trace
Tracer l'exécution

EXEMPLES

Analyser test.json et exécuter les tests de spécification

$ spectest-interp test.json
