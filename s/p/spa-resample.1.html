NOM

spa-resample - L'utilitaire de débogage du rééchantillonneur PipeWire

SYNTAXE

spa-resample [OPTIONS] FICHIER_ENTREE FICHIER_SORTIE

DESCRIPTION

Utilise le rééchantillonneur PipeWire pour rééchantillonner le fichier d'entrée vers le fichier de sortie, en suivant les options données.

Ceci est utile uniquement pour tester le rééchantillonneur.

OPTIONS

-r TAUX | --rate=TAUX

Taux d'échantillonnage de sortie.

-f FORMAT | --format=FORMAT

Format d'échantillon de sortie (s8 | s16 | s32 | f32 | f64).

-q QUALITE | --quality=QUALITE

Qualité de sortie du rééchantillonneur (0-14).

-c FLAGS | --cpuflags=FLAGS

Voir spa/support/cpu.h.

-h

Afficher l'aide.

-v

Fonctionnement verbeux.

EXEMPLES

spa-resample -r 48000 -f s32 in.wav out.wav

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues ; PipeWire est disponible à l'adresse https://pipewire.org
