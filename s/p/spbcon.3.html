Documentation de la fonction/sous-routine

sous-routine spbcon (character uplo, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real anorm, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPBCON

But:

!>
!> SPBCON estime la réciproque du nombre de conditionnement (en norme 1)
!> d'une matrice bande symétrique définie positive réelle, calculée par SPBTRF
!> à l'aide de la factorisation de Cholesky A = U**T*U ou A = L*L**T.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du nombre
!> de conditionnement est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  Facteur triangulaire supérieur stocké dans AB ;
!>          = 'L':  Facteur triangulaire inférieur stocké dans AB.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau REAL de dimension (LDAB,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T de la matrice bande A, stocké dans les
!>          KD+1 premières lignes du tableau. La j-ème colonne de U ou L est
!>          stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          Dimension principale du tableau AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM est REAL
!>          La norme 1 (ou norme infinie) de la matrice bande symétrique A.
!>

RCOND

!>          RCOND est REAL
!>          La réciproque du nombre de conditionnement de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau REAL de dimension (3*N)
!>

IWORK

!>          IWORK est un tableau INTEGER de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  succès de l'exécution
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>
