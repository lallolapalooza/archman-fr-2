cc_t(3type) cc_t(3type)

NOM

cc_t, speed_t, tcflag_t — caractères spéciaux du terminal, débits en bauds, modes

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <termios.h>
typedef /* ... */ cc_t;
typedef /* ... */ speed_t;
typedef /* ... */ tcflag_t;

DESCRIPTION

cc_t est utilisé pour les caractères spéciaux du terminal, speed_t pour les débits en bauds, et tcflag_t pour les modes.

Ce sont tous des types entiers non signés.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

VOIR AUSSI

termios(3)
