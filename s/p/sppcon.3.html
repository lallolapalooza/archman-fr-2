SPPCON

Documentation de la fonction/sous-programme

sous-programme sppcon (caractère uplo, entier n, réel, dimension( * ) ap, réel anorm, réel rcond, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SPPCON

But :

!>
!> SPPCON estime l'inverse du nombre de condition (en norme 1) d'une matrice
!> symétrique définie positive réelle, utilisant la factorisation de Cholesky
!> A = U**T*U ou A = L*L**T calculée par SPPTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et l'inverse du nombre de
!> condition est calculé comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

AP

!>          AP est un tableau de REAL, dimension (N*(N+1)/2)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T, condensé par colonne dans un tableau linéaire.
!>          La j-ème colonne de U ou L est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) pour j<=i<=n.
!>

ANORM

!>          ANORM est REAL
!>          La norme 1 (ou norme infinie) de la matrice symétrique A.
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau de REAL, dimension (3*N)
!>

IWORK

!>          IWORK est un tableau de INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
