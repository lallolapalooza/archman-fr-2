SPRINGGRAPH(1) Manuel des commandes générales SPRINGGRAPH(1)

NOM

springgraph - dessine un graphe à partir d'un fichier .dot

SYNTAXE

springgraph [OPTIONS] < fichier-entree.dot > fichier-sortie.png

DESCRIPTION

Springgraph lit un fichier .dot décrivant un graphe, qui, pour chaque nœud, spécifie son nom et les autres nœuds auxquels il est connecté, puis dessine un graphe. La sortie est un fichier PNG. Chaque nœud est dessiné comme une ellipse, et chaque connexion est dessinée comme une flèche. Le placement des nœuds résulte de tous les nœuds s'éloignant les uns des autres, tandis que tous les nœuds connectés se rapprochent les uns des autres. Ce mouvement est répété jusqu'à stabilisation.

Springgraph a été écrit comme une alternative à neato, qui fait partie de graphviz. Il tente de lire les mêmes fichiers .dot utilisés par graphviz, mais prend actuellement en charge un nombre limité d'attributs de nœuds (label et fillcolor) et ne peut gérer que deux nœuds par définition d'arête ("nœud1 -> nœud2", pas "nœud1 -> nœud2 -> nœud3").

OPTIONS

springgraph accepte les options suivantes :

-p
Crée un fichier qui peut être rendu avec POV-Ray
-v
Crée un fichier VRML
-s
Cette option spécifie l'échelle. Tous les emplacements des nœuds sont multipliés par cette valeur. Augmentez l'échelle pour éliminer les chevauchements de nœuds. Diminuez l'échelle pour rendre le graphe plus petit.
-t
Rend l'arrière-plan de l'image résultante transparent.
-b
Définit la couleur d'arrière-plan de l'image, spécifiez-la sous forme de RRGGBB, en chiffres hexadécimaux, par exemple FFFFFF est blanc, 000000 est noir, FF0000 est rouge, ...
-l
Définit la couleur de la ligne, même format que la couleur d'arrière-plan
-h
Affiche le synopsis d'utilisation

EXEMPLE


digraph {
"rene" -> "myon";
"mvo" -> "rene";
}
