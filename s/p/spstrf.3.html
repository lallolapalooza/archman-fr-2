Documentation de la fonction/sous-programme

sous-programme spstrf (caractere uplo, entier n, reels, dimension( lda, * ) a, entier lda, entier, dimension( n ) piv, entier rank, reel tol, reels, dimension( 2*n ) work, entier info)

SPSTRF calcule la factorisation de Cholesky avec pivotement complet d'une matrice réelle symétrique semi-définie positive.

Objectif :

!>
!> SPSTRF calcule la factorisation de Cholesky avec pivotement
!> complet d'une matrice réelle symétrique semi-définie positive A.
!>
!> La factorisation a la forme
!>    P**T * A * P = U**T * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**T,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est triangulaire inférieure, et
!> P est stocké sous forme de vecteur PIV.
!>
!> Cet algorithme ne tente pas de vérifier que A est semi-définie positive.
!> Cette version de l'algorithme utilise le BLAS de niveau 3.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de REELS, dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de dimension n par n d'A contient la
!>          partie triangulaire supérieure de la matrice A, et la partie
!>          strictement triangulaire inférieure d'A n'est pas référencée. Si
!>          UPLO = 'L', la partie inférieure triangulaire de dimension n par n
!>          d'A contient la partie triangulaire inférieure de la matrice A, et
!>          la partie strictement triangulaire supérieure d'A n'est pas
!>          référencée.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la factorisation de
!>          Cholesky comme ci-dessus.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

PIV

!>          PIV est un tableau de INTEGER, dimension (N)
!>          PIV est tel que les entrées non nulles sont P( PIV(K), K ) = 1.
!>

RANK

!>          RANK est INTEGER
!>          Le rang de A donné par le nombre d'étapes que l'algorithme a
!>          réalisées.
!>

TOL

!>          TOL est REAL
!>          Tolérance définie par l'utilisateur. Si TOL < 0, alors
!>          N*U*MAX( A(K,K) ) sera utilisé. L'algorithme se termine à la
!>          (K-1)-ième étape si le pivot <= TOL.
!>

WORK

!>          WORK est un tableau de REAL, dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est INTEGER
!>          < 0 : Si INFO = -K, le K-ième argument avait une valeur illégale,
!>          = 0 : l'algorithme s'est terminé avec succès, et
!>          > 0 : la matrice A est soit de rang déficient avec un rang calculé
!>               tel que retourné dans RANK, soit n'est pas semi-définie positive.
!>               Voir la section 7 du LAPACK Working Note #161 pour plus
!>               d'informations.
!>
