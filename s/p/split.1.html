SPLIT(1) Commandes utilisateur SPLIT(1)

NOM

split - diviser un fichier en morceaux

SYNTAXE

split [OPTION]... [FICHIER [PREFIXE]]

DESCRIPTION

Écrit des morceaux du FICHIER dans PREFIXaa, PREFIXab, ... ; la taille par défaut est de 1000 lignes, et le PREFIXE par défaut est 'x'.

Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-a, --longueur-suffixe=N
génère des suffixes de longueur N (2 par défaut)
--suffixe-supplementaire=SUFFIXE
ajoute un SUFFIXE supplémentaire aux noms de fichier
-b, --octets=TAILLE
met TAILLE octets par fichier de sortie
-C, --octets-par-ligne=TAILLE
met au plus TAILLE octets d'enregistrements par fichier de sortie
-d
utilise des suffixes numériques commençant à 0, pas alphabétiques
--suffixes-numeriques[=DEPUIS]
identique à -d, mais permet de définir la valeur de départ
-x
utilise des suffixes hexadécimaux commençant à 0, pas alphabétiques
--suffixes-hexadecimal[=DEPUIS]
identique à -x, mais permet de définir la valeur de départ
-e, --ignorer-fichiers-vides
ne génère pas de fichiers de sortie vides avec '-n'
--filtre=COMMANDE
écrit dans la coquille COMMANDE ; le nom de fichier est $FICHIER
-l, --lignes=NOMBRE
met NOMBRE lignes/enregistrements par fichier de sortie
-n, --nombre=MORCEAUX
génère MORCEAUX fichiers de sortie ; voir l'explication ci-dessous
-t, --separateur=SEP
utilise SEP au lieu d'un saut de ligne comme séparateur d'enregistrement ; '\0' (zéro) spécifie le caractère NUL
-u, --non-bufferisé
copie immédiatement l'entrée vers la sortie avec '-n r/...'
--verbeux
affiche un diagnostic juste avant l'ouverture de chaque fichier de sortie
--aide
affiche cette aide et quitte
--version
affiche les informations de version et quitte

L'argument TAILLE est un entier et une unité facultative (exemple : 10K fait 10*1024). Les unités sont K,M,G,T,P,E,Z,Y,R,Q (puissances de 1024) ou KB,MB,... (puissances de 1000). Les préfixes binaires peuvent aussi être utilisés : KiB=K, MiB=M, et ainsi de suite.

LES MORCEAUX peuvent être :

N
diviser en N fichiers basés sur la taille de l'entrée
K/N
écrire le K-ième de N dans la sortie standard
l/N
diviser en N fichiers sans diviser les lignes/enregistrements
l/K/N
écrire le K-ième de N dans la sortie standard sans diviser les lignes/enregistrements
r/N
similaire à 'l' mais utilise une distribution aléatoire
r/K/N
similairement mais n'écrit que le K-ième de N dans la sortie standard
