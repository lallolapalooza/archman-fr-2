sous-programme sptsvx (caractère fact, entier n, entier nrhs, réel, dimension( * ) d, réel, dimension( * ) e, réel, dimension( * ) df, réel, dimension( * ) ef, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( ldx, * ) x, entier ldx, réel rcond, réel, dimension( * ) ferr, réel, dimension( * ) berr, réel, dimension( * ) work, entier info)

SPTSVX calcule la solution du système d'équations linéaires A * X = B pour matrices PT

Objectif :

!>
!> SPTSVX utilise la factorisation A = L*D*L**T pour calculer la solution
!> d'un système d'équations linéaires réelles A*X = B, où A est une matrice
!> tridiagonale symétrique définie positive de taille N x N et X et B sont
!> des matrices N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de la condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la matrice A est factorisée sous la forme A = L*D*L**T, où L
!>    est une matrice bidiagonale inférieure unitaire et D est diagonale. La
!>    factorisation peut également être considérée comme ayant la forme
!>    A = U**T*D*U.
!>
!> 2. Si le mineur principal de tête d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée
!>    de A est utilisée pour estimer le nombre de conditionnement de la matrice
!>    A. Si l'inverse du nombre de conditionnement est inférieur à la précision de la machine,
!>    INFO = N+1 est retourné comme avertissement, mais la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la matrice solution calculée
!>    et calculer les bornes d'erreur et les estimations d'erreur arrière pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie ou non à l'entrée.
!>          = 'F' : À l'entrée, DF et EF contiennent la forme factorisée de A.
!>                  D, E, DF et EF ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans DF et EF et
!>                  factorisée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau REAL, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient à l'entrée
!>          les n éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**T de A.
!>          Si FACT = 'N', alors DF est un argument de sortie et contient à la sortie
!>          les n éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**T de A.
!>

EF

!>          EF est un tableau REAL, dimension (N-1)
!>          Si FACT = 'F', alors EF est un argument d'entrée et contient à l'entrée
!>          les (n-1) éléments sous-diagonaux du facteur bidiagonal unitaire L
!>          de la factorisation L*D*L**T de A.
!>          Si FACT = 'N', alors EF est un argument de sortie et contient à la sortie
!>          les (n-1) éléments sous-diagonaux du facteur bidiagonal unitaire L
!>          de la factorisation L*D*L**T de A.
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          La matrice côté droit B de taille N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N x NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de conditionnement de la matrice A. Si RCOND
!>          est inférieur à la précision de la machine (en particulier, si
!>          RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau REAL, dimension (NRHS)
!>          La borne d'erreur avant pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans n'importe quel
!>          élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau REAL, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal de tête d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la précision de la machine,
!>                       ce qui signifie que la matrice est singulière
!>                       à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>
