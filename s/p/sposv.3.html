Documentation de la fonction/sous-programme

sous-programme sposv (caractère uplo, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, entier info)

SPOSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> SPOSV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique définie positive de taille N et X et B
!> sont des matrices de taille N x NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A comme
!>    A = U**T* U,  si UPLO = 'U', ou
!>    A = L * L**T,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!> inférieure. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations
!> A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  La partie triangulaire supérieure de A est stockée ;
!>          = 'L' :  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est un ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire N x N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, la factorisation U ou L de la décomposition de
!>          Cholesky A = U**T*U ou A = L*L**T.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau de type REAL, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B du membre de droite N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être terminée, et la solution n'a pas été calculée.
!>
