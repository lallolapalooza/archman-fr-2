SPIX(1) Manuel des commandes générales SPIX(1)

NOM

spix - Compiler un fichier .tex, exécutant les commandes définies dans le fichier lui-même.

SYNTAXE

spix [--version] [-h] [-n] fichier

DESCRIPTION

spix analyse un fichier .tex pour trouver les lignes commençant par %$ (avant le préambule). Ces lignes sont des commandes shell qui sont exécutées par spix.

Les commandes sont exécutées telles quelles, sauf que :

- les commandes sont exécutées depuis le répertoire du fichier donné en argument ;

- les variables shell $texname et $basename sont définies avec le nom du fichier tex (respectivement avec et sans l'extension .tex).

OPTIONS

-n, --dry-run
Affiche les commandes qui seraient exécutées, mais ne les exécute pas.
-h, --help
Affiche l'aide et quitte.
--version
Affiche la version et quitte.

EXEMPLES

Soit foo.tex le fichier suivant.

% Compilez ce fichier deux fois avec lualatex.
%$ lualatex foo.tex
%$ lualatex foo.tex
\documentclass{article}
\begin{document}
Bonjour, monde !
\end{document}

En exécutant spix sur ce fichier, il est compilé deux fois en utilisant lualatex(1) (comme écrit aux lignes 2 et 3 du fichier).
