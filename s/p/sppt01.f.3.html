sous-routine sppt01 (caractère uplo, entier n, réel, dimension( * ) a, réel, dimension( * ) afac, réel, dimension( * ) rwork, réel resid)

SPPT01

But:

!>
!> SPPT01 reconstruit une matrice symétrique définie positive compactée A
!> à partir de sa factorisation L*L' ou U'*U et calcule le résidu
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée:
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est ENTIER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau RÉEL, dimension (N*(N+1)/2)
!>          La matrice symétrique originale A, stockée comme une matrice
!>          triangulaire compactée.
!>

AFAC

!>          AFAC est un tableau RÉEL, dimension (N*(N+1)/2)
!>          À l'entrée, le facteur L ou U de la factorisation L*L' ou U'*U
!>          de A, stocké comme une matrice triangulaire compactée.
!>          Est écrasé par la matrice reconstruite, puis par la différence
!>          L*L' - A (ou U'*U - A).
!>

RWORK

!>          RWORK est un tableau RÉEL, dimension (N)
!>

RESID

!>          RESID est RÉEL
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>
