NOM

split - Divise une chaîne en une liste Tcl appropriée

SYNOPIS

split chaîne ?caractèresDeDivision?

DESCRIPTION

Retourne une liste créée en divisant chaîne à chaque caractère présent dans l'argument caractèresDeDivision. Chaque élément de la liste résultante sera constitué des caractères de chaîne qui se trouvent entre les instances des caractères de caractèresDeDivision. Des éléments de liste vides seront générés si chaîne contient des caractères adjacents dans caractèresDeDivision, ou si le premier ou le dernier caractère de chaîne est dans caractèresDeDivision. Si caractèresDeDivision est une chaîne vide, alors chaque caractère de chaîne devient un élément distinct de la liste résultante. CaractèresDeDivision correspond par défaut aux caractères d'espacement standard.

EXEMPLES

Diviser un nom de groupe USENET en ses composants hiérarchiques :

split "comp.lang.tcl" .
      → comp lang tcl

Voir comment la commande split divise sur chaque caractère de caractèresDeDivision, ce qui peut entraîner une perte d'informations si vous ne faites pas attention :

split "alpha beta gamma" "temp"
      → al {ha b} {} {a ga} {} a

Extraire les mots d'une liste à partir d'une chaîne qui n'est pas une liste bien formée :

split "Exemple avec {accolade de bloc non équilibrée"
      → Exemple avec \{accolade de bloc non équilibrée

Diviser une chaîne en ses caractères constitutifs

split "Bonjour le monde" {}
      → B o n j o u r { } l e m o n d e

ANALYSE DE FICHIERS ORIENTÉS ENREGISTREMENT

Analyser un fichier Unix /etc/passwd, qui se compose d'une entrée par ligne, chaque ligne étant une liste de champs séparés par des deux-points :

## Lire le fichier
set fid [open /etc/passwd]
set content [read $fid]
close $fid
## Diviser en enregistrements sur les sauts de ligne
set records [split $content "\n"]
## Itérer sur les enregistrements
foreach rec $records {
    ## Diviser en champs sur les deux-points
    set fields [split $rec ":"]
    ## Assigner les champs aux variables et afficher certains...
    lassign $fields \
            nomUtilisateur motDePasse uid groupe nomComplet repertoirePersonnel shell
    puts "$nomComplet utilise [file tail $shell] comme shell de connexion"
}
