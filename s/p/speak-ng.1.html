SPEAK-NG(1) Manuel des commandes générales SPEAK-NG(1)

NOM

speak-ng - Synthétiseur vocal logiciel multilingue.

SYNTAXE

speak-ng [options] [<mots>]

DESCRIPTION

speak-ng est un synthétiseur vocal logiciel pour l'anglais et quelques autres langues.

OPTIONS

-h, --help
Affiche un résumé des options.
--version
Affiche la version de la bibliothèque espeak et l'emplacement des données vocales espeak.
-f <fichier texte>
Fichier texte à vocaliser.
--stdin
Lit l'entrée texte depuis stdin au lieu d'un fichier.

Si ni -f ni --stdin ne sont fournis, <mots> sont vocalysés, ou si aucun mot n'est fourni, le texte est lu depuis stdin ligne par ligne.

-q
Silencieux, ne produit aucune parole (peut être utile avec -x).
-a <entier>
Amplitude, de 0 à 200, défaut 100.
-g <entier>
Espace entre mots. Pause entre les mots, en unités de 10 ms à la vitesse par défaut.
-k <entier>
Indique les lettres majuscules par : 1=son, 2=le mot "capitale", des valeurs plus élevées = une augmentation de hauteur (essayer -k20).
-l <entier>
Longueur de ligne. Si différent de zéro (qui est la valeur par défaut), considérer les lignes plus courtes que cette longueur comme une fin de clause.
-p <entier>
Ajustement de hauteur, de 0 à 99, défaut 50.
-s <entier>
Vitesse en mots par minute, défaut 175.
-v <nom de voix>
Utilise le fichier vocal de ce nom provenant de espeak-ng-data/voices. Un variante peut être spécifiée en utilisant voix+variante, comme af+m3.
-w <nom de fichier WAV>
Écrit la sortie dans ce fichier WAV, plutôt que de la vocaliser directement.
--split=<minutes>
Utilisé avec -w pour diviser la sortie audio en <minutes> morceaux enregistrés.
-b
Encodage du texte d'entrée, 1=UTF8, 2=8 bits, 4=16 bits.
-m
Indique que le texte contient des balises SSML (Speech Synthesis Markup Language) ou d'autres balises XML. Les balises SSML qui sont supportées sont interprétées. Les autres balises, y compris HTML, sont ignorées, sauf que certaines balises HTML comme
-x
Écrit les mnémoniques de phonèmes sur stdout.
-X
Écrit les mnémoniques de phonèmes et la trace de traduction sur stdout. Si les fichiers de règles ont été compilés avec --compile=debug, les numéros de ligne seront également affichés.
-z
Pas de pause finale de phrase à la fin du texte.
--stdout
Écrit la sortie vocale sur stdout.
--compile=voicename
Compile les règles de prononciation et le dictionnaire dans le répertoire courant. =<nom de voix< est optionnel et spécifie quelle langue est compilée.
--compile-debug=voicename
Compile les règles de prononciation et le dictionnaire dans le répertoire courant comme ci-dessus, mais inclut les numéros de ligne, qui sont affichés lorsque -X est utilisé.
--ipa
Écrit les phonèmes sur stdout en utilisant l'Alphabet Phonétique International. --ipa=1 Utilise les ligatures, --ipa=2 Utilise ZWJ, --ipa=3 Sépare avec _.
--tie=<caractère>
Le caractère à utiliser pour joindre les phonèmes de plusieurs lettres dans la sortie -x et --ipa.
--path=<chemin>
Spécifie le répertoire contenant le répertoire espeak-ng-data.
--pho
Écrit les données phonétiques mbrola (.pho) sur stdout ou dans le fichier spécifié par --phonout.
--phonout=<nom de fichier>
Écrit la sortie des commandes -x -X et les données phonétiques mbrola dans ce fichier.
--punct="<caractères>"
Prononce les noms des caractères de ponctuation pendant la vocalisation. Si =<caractères> est omis, toute la ponctuation est prononcée.
--sep=<caractère>
Le caractère à utiliser pour séparer les phonèmes de la sortie -x et --ipa.
--voices[=<code langue>]
Liste les voix disponibles. Si =<code langue> est présent, seules les voix appropriées pour cette langue sont listées.
--voices=<répertoire>
Liste les voix dans le sous-répertoire spécifié.

EXEMPLES

speak-ng "Ceci est un test"
Vocalise la phrase "Ceci est un test" en utilisant la voix anglaise par défaut.
speak-ng -f hello.txt
Vocalise le contenu de hello.txt en utilisant la voix anglaise par défaut.
cat hello.txt | speak-ng
Vocalise le contenu de hello.txt en utilisant la voix anglaise par défaut.
speak-ng -x hello
Vocalise le mot "hello" en utilisant la voix anglaise par défaut, et affiche les phonèmes qui ont été prononcés.
speak-ng -ven-us "[[h@'loU]]"
Vocalise les phonèmes "h@'loU" en utilisant la voix anglaise américaine.
speak-ng --voices
Liste toutes les voix supportées par eSpeak.
speak-ng --voices=en
Liste toutes les voix qui parlent anglais (en).
speak-ng --voices=mb
Liste toutes les voix utilisant le synthétiseur vocal MBROLA.

    speak-ng(1)

    SPEAK-NG — un logiciel de synthèse vocale simple

    DESCRIPTION

    speak-ng est un logiciel simple pour faire parler votre ordinateur. Il prend le texte de l'entrée standard et le transmet à un moteur de synthèse vocale.

    OPTIONS

    Aucune option n'est prise en charge par cette version.

    EXEMPLES

    Pour faire dire "Bonjour le monde" à votre ordinateur :

    echo "Bonjour le monde" | speak-ng
