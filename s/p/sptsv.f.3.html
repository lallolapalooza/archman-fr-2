sous-routine sptsv (integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldb, * ) b, integer ldb, integer info)

SPTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

Objectif :

!>
!> SPTSV calcule la solution d'un système d'équations linéaires réelles
!> A*X = B, où A est une matrice tridiagonale symétrique définie positive de taille N
!> et X et B sont des matrices de taille N par NRHS.
!>
!> A est factorisée comme A = L*D*L**T, et la forme factorisée de A est ensuite
!> utilisée pour résoudre le système d'équations.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

D

!>          D est un tableau REEL, de dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A.  À la sortie, les n éléments diagonaux de la matrice diagonale
!>          D de la factorisation A = L*D*L**T.
!>

E

!>          E est un tableau REEL, de dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice tridiagonale
!>          A.  À la sortie, les (n-1) éléments sous-diagonaux du facteur
!>          bidiagonal unitaire L de la factorisation L*D*L**T de
!>          A.  (E peut également être considéré comme la surdiagonale du facteur
!>          bidiagonal unitaire U de la factorisation U**T*D*U de A.)
!>

B

!>          B est un tableau REEL, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des membres de droite de taille N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N par NRHS.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas positif, et la solution n'a pas été
!>                calculée.  La factorisation n'est pas terminée
!>                sauf si i = N.
!>
