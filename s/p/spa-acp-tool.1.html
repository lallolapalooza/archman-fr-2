NOM

spa-acp-tool - L'utilitaire de débogage de profils ALSA de PipeWire

SYNTAXE

spa-acp-tool [OPTIONS] [COMMANDE]

DESCRIPTION

Outil de débogage pour tester le code d'interrogation des profils de carte ALSA, sans exécuter PipeWire.

Peut être utilisé pour déboguer des problèmes où PipeWire a des profils de carte ALSA fonctionnant de manière incorrecte.

OPTIONS

-h | --help

Afficher l'aide

-v | --verbose

Augmenter le niveau de verbosité d'un cran

-c NOMBRE | --card NOMBRE

Sélectionner la carte à interroger

-p | --properties

Propriétés supplémentaires à passer à ACP, par exemple clé=valeur ....

COMMANDES

help | h

Afficher les commandes disponibles

quit | q

Quitter

card ID | c ID

Interroger la carte

info | i

Lister les informations de la carte

list | l

Lister tous les objets

list-verbose | lv

Lister toutes les données

list-profiles [ID] | lpr [ID]

Lister les profils

set-profile ID | spr ID

Activer un profil

list-ports [ID] | lp [ID]

Lister les ports

set-port ID | sp ID

Activer un port

list-devices [ID] | ld [ID]

Lister les périphériques disponibles

get-volume ID | gv ID

Obtenir le volume d'un périphérique

set-volume ID VOL | v ID VOL

Définir le volume sur un périphérique

inc-volume ID | v+ ID

Augmenter le volume sur un périphérique

dec-volume ID | v- ID

Diminuer le volume sur un périphérique

get-mute ID | gm ID

Obtenir l'état muet d'un périphérique

set-mute ID VAL | sm ID VAL

Définir le mode muet sur un périphérique

toggle-mute ID | m ID

Basculer le mode muet sur un périphérique
