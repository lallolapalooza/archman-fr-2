NOM

sphinx-quickstart - Générateur de modèles de documentation Sphinx

SYNTAXE

sphinx-quickstart

DESCRIPTION

sphinx-quickstart est un outil interactif qui pose quelques questions sur votre projet, puis génère un répertoire de documentation complet et un fichier Makefile d'exemple à utiliser avec sphinx-build(1).

OPTIONS

-q, --quiet
Mode silencieux qui ignore l'assistant interactif pour spécifier les options. Cette option nécessite les options -p, -a et -v.
-h, --help, --version
Affiche le résumé d'utilisation ou la version de Sphinx.

Options de structure

--sep
Si spécifié, sépare les répertoires source et de build.
--no-sep
Si spécifié, crée le répertoire de build sous le répertoire source.
--dot=DOT
Dans le répertoire racine, deux répertoires supplémentaires seront créés ; "_templates" pour les modèles HTML personnalisés et "_static" pour les feuilles de style personnalisées et autres fichiers statiques. Vous pouvez entrer un autre préfixe (tel que ".") pour remplacer le soulignement.

Options de base du projet

-p PROJET, --project=PROJET
Le nom du projet sera défini. (voir project).
-a AUTEUR, --author=AUTEUR
Noms des auteurs. (voir copyright).
-v VERSION
Version du projet. (voir version).
-r RELEASE, --release=RELEASE
Release du projet. (voir release).
-l LANGUE, --language=LANGUE
Langue du document. (voir language).
--suffix=SUFFIXE
Suffixe du fichier source. (voir source_suffix).
--master=MASTER
Nom du document maître. (voir root_doc).

Options d'extension

--ext-autodoc
Active l'extension sphinx.ext.autodoc.
--ext-doctest
Active l'extension sphinx.ext.doctest.
--ext-intersphinx
Active l'extension sphinx.ext.intersphinx.
--ext-todo
Active l'extension sphinx.ext.todo.
--ext-coverage
Active l'extension sphinx.ext.coverage.
--ext-imgmath
Active l'extension sphinx.ext.imgmath.
--ext-mathjax
Active l'extension sphinx.ext.mathjax.
--ext-ifconfig
Active l'extension sphinx.ext.ifconfig.
--ext-viewcode
Active l'extension sphinx.ext.viewcode.
--ext-githubpages
Active l'extension sphinx.ext.githubpages.
--extensions=EXTENSIONS
Active des extensions arbitraires.

Options de création de Makefile et Batchfile

--use-make-mode (-m), --no-use-make-mode (-M)
Makefile/make.bat utilise (ou n'utilise pas) make-mode. Par défaut, il est utilisé, ce qui génère un Makefile/make.bat plus concis.

Modifié dans la version 1.5 : make-mode est par défaut.

Modifié dans la version 7.3 : La prise en charge de la désactivation de make-mode sera supprimée dans Sphinx 8.

Supprimé dans la version 8.0 : L'option --no-use-make-mode. L'option --use-make-mode n'a plus d'effet.

--makefile, --no-makefile
Crée (ou ne crée pas) le makefile.
--batchfile, --no-batchfile
Crée (ou ne crée pas) le fichier batch

Modèles de projet

Ajouté dans la version 1.5 : Options de modèles de projet pour sphinx-quickstart

-t, --templatedir=REPERTOIRE_MODELES
Répertoire de modèles pour les fichiers de modèle. Vous pouvez modifier les modèles des fichiers de projet Sphinx générés par quickstart. Les fichiers de modèle Jinja2 suivants sont autorisés :
  • root_doc.rst.jinja
  • conf.py.jinja
  • Makefile.jinja
  • Makefile.new.jinja
  • make.bat.jinja
  • make.bat.new.jinja

Pour plus de détails, veuillez consulter les fichiers de modèles du système fournis par Sphinx. (sphinx/templates/quickstart)

-d NOM=VALEUR
Définit une variable de modèle

sphinx-quickstart(1) — Arch Linux man pages

SYNOPSIS

sphinx-quickstart [options] [sourcedir]

DESCRIPTION

sphinx-quickstart automates the creation of a Sphinx documentation directory and configuration file. It can also create a basic project structure with subdirectories for source files and build files.

It asks a series of questions to configure the project, such as the project name, author, version, and language. It then creates the necessary files and directories, including a conf.py file, a Makefile, and a make.bat file.

OPTIONS

The following options can be passed to sphinx-quickstart:

--help
Show a help message and exit.
-q, --quiet
Do not ask any questions and use default values.
-p project
Set the project name.
-a author
Set the author name.
-v version
Set the project version.
-l language
Set the project language.
-s
Separate source and build directories.
-r
Separate reStructuredText files from LaTeX files.
-d dot
Enable the autodoc extension.
-e epydoc
Enable the epydoc extension.
-m modindex
Enable the modindex extension.
-b batchfile
Set the batch file name.

EXIT STATUS

Returns 0 on success, and non-zero on failure.
