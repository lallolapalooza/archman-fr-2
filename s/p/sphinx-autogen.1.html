SPHINX-AUTOGEN(1) Sphinx SPHINX-AUTOGEN(1)

NOM

sphinx-autogen - Génère des pages de stub autodoc

SYNTAXE

sphinx-autogen [options] <fichier_source> ...

DESCRIPTION

sphinx-autogen est un outil pour la génération automatique de sources Sphinx qui, en utilisant l'extension autodoc, documentent les éléments inclus dans une ou plusieurs listes autosummary.

OPTIONS

-o <repertoire_sortie>
Répertoire où placer le fichier de sortie. S'il n'existe pas, il est créé. Par défaut, utilise la valeur passée à l'option :toctree:.
-s <suffixe>, --suffix <suffixe>
Suffixe par défaut à utiliser pour les fichiers générés. Par défaut, rst.
-t <modeles>, --templates <modeles>
Répertoire de modèles personnalisé. Par défaut, None.
-i, --imported-members
Documenter les membres importés.
-a, --respect-module-all
Documenter exactement les membres dans l'attribut __all__ d'un module.
--remove-old
Supprimer les fichiers existants dans le répertoire de sortie qui ne sont plus générés.

EXEMPLE

Étant donné la structure de répertoire suivante :

docs
├── index.rst
└── ...
foobar
├── foo
│   └── __init__.py
└── bar
    ├── __init__.py
    └── baz
        └── __init__.py

et en supposant que docs/index.rst contenait ceci :

Modules
=======
.. autosummary::
   :toctree: modules
   foobar.foo
   foobar.bar
   foobar.bar.baz

Si vous exécutez ceci :

$ PYTHONPATH=. sphinx-autogen docs/index.rst

alors les fichiers de stub suivants seront créés dans docs :

docs
├── index.rst
└── modules
    ├── foobar.bar.rst
    ├── foobar.bar.baz.rst
    └── foobar.foo.rst

et chacun de ces fichiers contiendra une directive autodoc et d'autres informations.
