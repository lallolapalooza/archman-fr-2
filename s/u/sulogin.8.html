SULOGIN(8) Administration système SULOGIN(8)

NOM

sulogin - connexion en mode mono-utilisateur

SYNTAXE

sulogin [options] [tty]

DESCRIPTION

sulogin est appelé par init lorsque le système passe en mode mono-utilisateur.

L'utilisateur est invité à saisir le mot de passe suivant :

Donner le mot de passe root pour la maintenance du système (ou taper Control-D pour un démarrage normal) :

Si le compte root est verrouillé et que --force est spécifié, aucun mot de passe n'est requis.

sulogin sera connecté au terminal courant, ou au périphérique tty optionnel qui peut être spécifié sur la ligne de commande (typiquement /dev/console).

Lorsque l'utilisateur quitte le shell mono-utilisateur, ou appuie sur contrôle-D à l'invite, le système continuera le démarrage.

OPTIONS

-e, --force

Si la méthode par défaut pour obtenir le mot de passe root du système via getpwnam(3) échoue, alors examinez /etc/passwd et /etc/shadow pour obtenir le mot de passe. Si ces fichiers sont endommagés ou inexistants, ou lorsque le compte root est verrouillé par '!' ou '*' au début du mot de passe, alors sulogin démarrera un shell root sans demander de mot de passe.

N'utilisez l'option -e que si vous êtes sûr que la console est physiquement protégée contre tout accès non autorisé.

-p, --login-shell

La spécification de cette option fait que sulogin démarre le processus du shell comme un shell de connexion.

-t, --timeout secondes

Spécifiez le temps maximum d'attente pour la saisie utilisateur. Par défaut, sulogin attendra indéfiniment.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

ENVIRONNEMENT

sulogin recherche la variable d'environnement SUSHELL ou sushell pour déterminer quel shell démarrer. Si la variable d'environnement n'est pas définie, il essaiera d'exécuter le shell de root depuis /etc/passwd. Si cela échoue, il se rabattra sur /bin/sh.

AUTEURS

sulogin a été écrit par Miquel van Smoorenburg pour sysvinit et plus tard porté sur util-linux par Dave Reisner et Karel Zak.
