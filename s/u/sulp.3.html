Detailed Description

Constants for the LAPACK library.

This module defines a number of constants used within the LAPACK library.

The constants are defined for both single precision (sp) and double precision (dp).

dp is defined as:

integer, parameter :: dp = kind(0.0d0)

sp is defined as:

integer, parameter :: sp = kind(0.0)

The following constants are defined:

dbig
Largest representable number, approximately 1/dsafmin.
dbignum
Largest representable number, approximately dsafmax * dulp.
dhalf
1/2 in double precision.
dmax
dsbig
Largest representable number. This is used in the LAPACK routines to set thresholds for determining whether numbers are "too big" and should be treated as infinity.
dmin
dtsml
Smallest representable number. This is used in the LAPACK routines to set thresholds for determining whether numbers are "too small" and should be treated as zero.
dsafmax
Largest positive representable number, without underflow.
dsafmin
Smallest positive representable number, without underflow.
dsmlnum
Smallest representable number, approximately dsafmin / dulp.
dssml
Smallest positive normalized number.
dtbig
Largest positive normalized number.
dten
10.0 in double precision.
dthree
3.0 in double precision.
dtwo
2.0 in double precision.
dulp
The distance between 1.0 and the next representable double-precision number. This is equivalent to machine epsilon for double precision.
dzero
0.0 in double precision.
sbignum
Largest representable number, approximately ssafmax * sulp.
seight
8.0 in single precision.
seps
Half of the machine epsilon for single precision. Used in some LAPACK routines for tolerance calculations.
sfour
4.0 in single precision.
shalf
1/2 in single precision.
sone
1.0 in single precision.
sprefix
The character 'S', used to identify single-precision routines.
srtmax
The square root of sbignum. Used in some LAPACK routines to check for potential overflow during calculations.
srtmin
The square root of ssmlnum. Used in some LAPACK routines to check for potential underflow during calculations.
ssafmax
Largest positive representable number, without underflow.
ssafmin
Smallest positive representable number, without underflow.
ssbig
Largest representable number. This is used in the LAPACK routines to set thresholds for determining whether numbers are "too big" and should be treated as infinity.
ssmlnum
Smallest representable number, approximately ssafmin / sulp.
sssml
Smallest positive normalized number.
stbig
Largest positive normalized number.
sten
10.0 in single precision.
sthree
3.0 in single precision.
stsml
Smallest positive normalized number.
stwo
2.0 in single precision.
sulp
The distance between 1.0 and the next representable single-precision number. This is equivalent to machine epsilon for single precision.
szero
0.0 in single precision.
zhalf
The complex number (0.5, 0.0) in double precision.
zone
The complex number (1.0, 0.0) in double precision.
zprefix
The character 'Z', used to identify double-precision complex routines.
zzero
The complex number (0.0, 0.0) in double precision.
