SURFRAW(1) Manuel des commandes générales SURFRAW(1)

NOM

surfraw - une interface en ligne de commande Unix rapide pour les services du WWW

SYNTAXE

surfraw nom_elvi [options] mots de recherche ...
sr nom_elvi [options] mots de recherche ...
sr -elvi
sr [options] signet [mots de recherche]

DESCRIPTION

Surfraw fournit une interface en ligne de commande Unix rapide pour une variété de moteurs de recherche WWW populaires et d'autres artefacts de puissance. Il récupère google, altavista, dejanews, freshmeat, research index, slashdot et bien d'autres des terres païennes de formulaires html, infestées de faux prophètes et de maladies, plaçant ces merveilles là où elles appartiennent, au cœur de l'univers Unix, comme des extensions aimantes de Dieu pour le shell.

Surfraw se compose d'une collection d'elvi, chacun sachant comment rechercher sur un site Web spécifique. Pour voir la liste des elvi, tapez :


surfraw -elvi

Notez que sr est un alias pour surfraw, donc cela pourrait aussi être


sr -elvi

Pour rechercher en utilisant un elvi, utilisez :


sr nom_elvi [options] termes de recherche..

Par exemple, pour rechercher sur Google des informations sur les ports Debian, en utilisant l'option "Je me sens chanceux" :


sr google -l debian ports

Ajouter les elvi à votre chemin

Si vous utilisez régulièrement surfraw, vous vous lasserez probablement de taper sr ou surfraw à chaque fois. Vous pouvez retrouver le comportement précédent d'exécution directe des elvi en ajoutant le répertoire elvi (/usr/lib/surfraw) à votre chemin, soit manuellement, soit en utilisant surfraw-update-path(1).

Signets

Surfraw prend en charge les signets. Pour ajouter un signet, ajoutez-le à /etc/xdg/surfraw/bookmarks ou $HOME/.config/surfraw/bookmarks

Le format du fichier de signets est simple, chaque signet est sur une ligne séparée, le signet et l'URL étant séparés par un espace blanc, par exemple :


ntk http://www.ntk.net/

Si l'URL contient la chaîne %s, vous pouvez spécifier un argument optionnel pour le signet. Sans argument, seul le domaine sera retourné. Avec des arguments, %s sera remplacé par les arguments. Cela évite de créer des elvi pour des sites avec des options de recherche très simples.

Pour invoquer un signet, utilisez "surfraw bookmark" ou "sr bookmark", et si un elvi de ce nom n'existe pas, il recherchera un signet de ce nom à la place.

Il y a quelques exemples de signets dans /etc/xdg/surfraw/bookmarks

OPTIONS

Utilisez sr nom_elvi -aide-locale pour les options spécifiques aux elvi.

Les options suivantes fonctionnent avec tous les elvi.

-aide
Afficher un résumé des options (y compris les options spécifiques aux elvi).
-aide-locale
Afficher les options spécifiques aux elvi.
-version
Afficher la version du programme.
-navigateur=EXECUTABLE
Définir le navigateur (par défaut : sensible-browser).
-elvi
Afficher une liste d'autres mécanismes Surfraw pour conquérir le mal.
-echapper-url-args=oui|non
Appliquer l'échappement d'URL aux arguments (par défaut : oui)
-q|-citation
Encadrer tous les arguments avec des guillemets ("") (par défaut : non). Notez que mettre des guillemets autour des arguments fonctionne maintenant, vous pouvez donc faire, par exemple :


sr google foo "bar baz" bam

et les guillemets sont transmis au moteur de recherche

EXEMPLES


$ sr ask pourquoi jeeves est-il gay ?
$ surfraw google -resultats=100 RMS, GNU, qui est le pécheur, qui est le péché ?
$ sr austlii -methode=phrase chien aime
$ /usr/lib/surfraw/rhyme -methode=parfaite Julien

CONFIGURATION

Surfraw utilise la spécification XDG basedir (http://standards.freedesktop.org/basedir-spec/basedir-spec-0.6.html) pour localiser les fichiers de configuration. Les emplacements par défaut sont indiqués ci-dessous, mais peuvent être modifiés en définissant les variables d'environnement $XDG_CONFIG_HOME et $XDG_CONFIG_DIRS. Voir la spécification pour plus de détails.

Surfraw obtient sa configuration de trois sources, dans l'ordre :

1.
Variables d'environnement
2.
/etc/xdg/surfraw/conf
3.
$HOME/.config/surfraw/conf

/etc/xdg/surfraw.conf et $HOME/.config/surfraw/conf sont tous deux des fragments de script shell style bourne.

/etc/xdg/surfraw.conf doit utiliser def et defyn pour définir des variables. Ces fonctions définissent des variables sauf si elles sont déjà définies par l'environnement. defyn est utilisé pour les variables de configuration booléennes, def pour toutes les autres. Par exemple :


def SURFRAW_text_browser /usr/bin/lynx
defyn SURFRAW_graphical non

$HOME/.config/surfraw/conf doit utiliser des entrées style sh, par exemple :


SURFRAW_text_browser=/usr/bin/lynx
SURFRAW_graphical=non

C'est parce que vous voulez qu'elles remplacent les variables d'environnement sans condition.

VARIABLES DE CONFIGURATION

SURFRAW_global_conf
Emplacement du fichier de configuration global.

Défaut :


def SURFRAW_global_conf /etc/xdg/surfraw/conf

SURFRAW_conf
Emplacement du fichier de configuration par utilisateur.

Défaut :


def SURFRAW_conf $HOME/.config/surfraw/conf

SURFRAW_graphical
Indique s'il faut utiliser un navigateur graphique.

Défaut :

defyn SURFRAW_graphical non

SURFRAW_text_browser
Nom/chemin de l'exécutable du navigateur texte. par ex. links, lynx, w3m

Défaut :

def SURFRAW_text_browser sensible-browser

SURFRAW_graphical_browser
Nom/chemin de l'exécutable du navigateur graphique. par ex. mozilla, netscape etc.

Défaut :


def SURFRAW_graphical_browser sensible-browser

SURFRAW_text_browser_args
Arguments du navigateur texte, ou "none".

Défaut :


def SURFRAW_text_browser_args none

SURFRAW_graphical_browser_args
Arguments du navigateur graphique, ou "none".

Défaut :


def SURFRAW_graphical_browser_args none

SURFRAW_graphical_remote
Indique s'il faut utiliser "-remote openURL" pour le navigateur graphique.

Défaut :


defyn SURFRAW_graphical_remote oui

SURFRAW_new_window
Lors de l'utilisation de SURFRAW_graphical_remote, ouvrir une nouvelle fenêtre ?

Défaut :


defyn SURFRAW_new_window non

SURFRAW_screen
Optionnel : spécifie le nom d'écran X à utiliser si SURFRAW_graphical_remote est défini sur oui.

Défaut :


def SURFRAW_screen $DISPLAY

surfraw(1) - Pages de manuel Arch Linux

NOM

surfraw – interface en ligne de commande pour les moteurs de recherche

SYNOPSIS

surfraw [OPTIONS] ELV QUERY...

surfraw -h | --help

surfraw -v | --version

surfraw -l | --list

DESCRIPTION

Surfraw est une interface en ligne de commande pour les moteurs de recherche (elvi). Elle permet de rechercher des termes sur un grand nombre de sites Web.

OPTIONS

-a
surfraw tentera de choisir le meilleur elvis pour vous et de lancer ce que vous avez sur la ligne de commande. L'option -a (ou --all) ne devrait jamais être utilisée car elle n'a aucune utilité pour ce programme.
-d
Mode de débogage. Il imprima tout ce qui se passe dans le script.
-e
Cette option vous permet de fournir une liste d'elvis séparés par des virgules. Si la liste se termine par un virgule, alors tous les elvis sont utilisés.
-f
Définir le fichier de configuration.
-h, --help
Afficher un message d'aide et quitter.
-l, --list
Lister tous les elvis disponibles et quitter.
-n
Ne pas lancer le navigateur. Ceci est utile si vous voulez juste obtenir les URLs des résultats de recherche.
-p
Définir le navigateur utilisé pour ouvrir les URLs.
-q
Mode silencieux. Ne pas afficher les messages sur la sortie standard.
-s
Définir le nombre de résultats à afficher.
-t
Définir le délai d'attente en secondes avant d'abandonner une requête.
-u
Rechercher dans l'ordre inverse. Utile si vous voulez obtenir les meilleurs résultats en premier.
-v, --version
Afficher les informations de version et quitter.

EXEMPLES

Lancer une recherche sur Google pour "arch linux":

surfraw google arch linux

Lancer une recherche sur DuckDuckGo et Wikipedia pour "nix":

surfraw duckduckgo,wikipedia nix

Lancer une recherche sur tous les elvis disponibles pour "surfraw":

surfraw -e, google arch linux

Obtenir les URLs pour une recherche sur Google sans lancer le navigateur:

surfraw -n google arch linux

CONFIGURATION

Surfraw peut être configuré en utilisant des variables d'environnement ou des fichiers de configuration.

Fichiers de configuration :
  • /etc/xdg/surfraw/conf : fichier de configuration système global.
  • $HOME/.config/surfraw/conf : fichier de configuration utilisateur.

VARIABLES DE CONFIGURATION

SURFRAW_browser

Navigateur à utiliser pour ouvrir les URLs.

Défaut :


def BROWSER=firefox

SURFRAW_screen

Nom de la commande screen à exécuter.

Défaut :


def SURFRAW_screen screen

SURFRAW_new_screen

Si surfraw s'exécute sous screen(1), lancer une nouvelle session screen pour chaque invocation du navigateur textuel ?

Défaut :


defyn SURFRAW_new_screen no

SURFRAW_screen_args

Arguments à passer à la commande SURFRAW_screen.

Défaut :


def SURFRAW_screen_args ""

SURFRAW_quote_args

Mettre des guillemets autour de tous les arguments.

Défaut :


defyn SURFRAW_quote_args no

SURFRAW_quote_ifs

Remettre des guillemets aux arguments s'ils contiennent des espaces, afin que :

sr google foo "bar baz" bam

fonctionne comme prévu.

Défaut :

defyn SURFRAW_quote_ifs yes

SURFRAW_results

Nombre par défaut de résultats à retourner (non supporté par tous les elvis).

Défaut :


def SURFRAW_results 30

SURFRAW_escape_url_args

Mettre des caractères d'échappement [% "$%&+,/:;<=>?@[{|}~'] dans les arguments de la ligne de commande utilisés ensuite pour construire une URL.

Défaut :


defyn SURFRAW_escape_url_args yes
