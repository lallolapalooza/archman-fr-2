time_t(3type) time_t(3type)

NOM

time_t, suseconds_t, useconds_t - entiers de temps

BIBLIOTHQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <time.h>
typedef /* ... */  time_t;
#include <sys/types.h>
typedef /* ... */  suseconds_t;
typedef /* ... */  useconds_t;

DESCRIPTION

time_t
Utilisé pour le temps en secondes. Conformément à POSIX, c'est un type entier d'au moins 64 bits.
suseconds_t
Utilisé pour le temps en microsecondes. C'est un type entier signé capable de stocker des valeurs au moins dans la plage [-1, 1000000].
useconds_t
Utilisé pour le temps en microsecondes. C'est un type entier non signé capable de stocker des valeurs au moins dans la plage [0, 1000000].

NORMES

time_t
C11, POSIX.1-2024.
suseconds_t
POSIX.1-2024.
useconds_t
Aucune.

HISTORIQUE

time_t
C89, POSIX.1-2001.
suseconds_t
POSIX.1-2001.
useconds_t
POSIX.1-2001. Supprimé dans POSIX.1-2008.

Fichiers d'en-tête

<sched.h> définit time_t depuis POSIX.1-2008.

time_t

Dans POSIX.1-2001, time_t était spécifié comme étant soit un type entier, soit un type réel à virgule flottante. Cependant, les implémentations existantes utilisaient un type entier, et POSIX.1-2008 a resserré la spécification pour refléter cela.

POSIX.1-2024 a exigé que la largeur de time_t soit d'au moins 64 bits.

NOTES

Sur certaines architectures, la largeur de time_t peut être contrôlée avec la macro de test de fonctionnalité _TIME_BITS. Voir feature_test_macros(7).

Les en-têtes suivants fournissent également time_t : <sched.h>, <sys/msg.h>, <sys/select.h>, <sys/sem.h>, <sys/shm.h>, <sys/stat.h>, <sys/time.h>, <sys/types.h>, et <utime.h>.

Les en-têtes suivants fournissent également suseconds_t : <sys/select.h> et <sys/time.h>.

Les en-têtes suivants fournissaient également useconds_t : <unistd.h>.

VOIR AUSSI

stime(2), time(2), ctime(3), difftime(3), usleep(3), timeval(3type)
