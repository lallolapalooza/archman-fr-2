subs(3perl) Guide de référence du programmeur Perl subs(3perl)

NOM

subs - Pragma Perl pour prédéclarer les noms de sous-routines

SYNTAXE

use subs qw(frob);
frob 3..10;

DESCRIPTION

Cela prédéclarera toutes les sous-routines dont les noms sont dans la liste, vous permettant de les utiliser sans parenthèses (en tant qu'opérateurs de liste) même avant qu'elles ne soient déclarées.

Contrairement aux pragmas qui affectent la variable d'indices $^H, les déclarations "use vars" et "use subs" ne sont pas limitées lexicalement au bloc dans lequel elles apparaissent : elles affectent l'intégralité du paquet dans lequel elles apparaissent. Il n'est pas possible de révoquer ces déclarations avec "no vars" ou "no subs".

Voir "Pragmatic Modules" dans perlmodlib et "strict subs" dans strict.
