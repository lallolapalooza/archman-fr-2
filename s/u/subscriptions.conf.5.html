NOM

subscriptions.conf - fichier de configuration des abonnements pour cups

DESCRIPTION

Le fichier subscriptions.conf définit les abonnements locaux aux notifications d'événements qui sont actifs. Il est normalement situé dans le répertoire /etc/cups et est géré par le programme cupsd(8). Ce fichier n'est pas destiné à être édité ou géré manuellement.

NOTES

Le nom, l'emplacement et le format de ce fichier sont un détail d'implémentation qui changera dans les futures versions de CUPS.
