surfaces(6) Manuel XScreenSaver surfaces(6)

NOM

surfaces - Dessine des surfaces paramétriques 3D intéressantes.

SYNTAXE

surfaces [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--speed numéro] [--rand] [--spin] [--wander] [--fps] [--surface nom-surface] [--random-surface] [--dini] [--enneper] [--kuen] [--moebius] [--seashell] [--swallowtail] [--bohemian] [--whitney] [--pluecker] [--henneberg] [--catalan] [--corkscrew] [--mode mode-affichage] [--random-mode] [--points] [--lines] [--line-loops]

DESCRIPTION

Ceci dessine l'une des plusieurs surfaces paramétriques tridimensionnelles.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--delay numéro
Délai par image, en microsecondes. Défaut : 20000 (0.02 secondes).
--speed numéro
Nombre d'images avant de changer de forme. Défaut : 1000.
--surface random (Raccourci : --random-surface)
Affiche une surface aléatoire. C'est le comportement par défaut.
--surface dini (Raccourci : --dini)
Affiche la surface de Dini.
--surface enneper (Raccourci : --enneper)
Affiche la surface minimale d'Enneper.
--surface kuen (Raccourci : --kuen)
Affiche la surface de Kuen.
--surface moebius (Raccourci : --moebius)
Affiche la bande de Möbius.
--surface seashell (Raccourci : --seashell)
Affiche la surface coquillage.
--surface swallowtail (Raccourci : --swallowtail)
Affiche la catastrophe en queue d'aronde.
--surface bohemian (Raccourci : --bohemian)
Affiche le dôme bohémien.
--surface whitney (Raccourci : --whitney)
Affiche le parapluie de Whitney.
--surface pluecker (Raccourci : --pluecker)
Affiche le conoïde de Plücker.
--surface henneberg (Raccourci : --henneberg)
Affiche la surface minimale de Henneberg.
--surface catalan (Raccourci : --catalan)
Affiche la surface minimale de Catalan.
--surface corkscrew (Raccourci : --corkscrew)
Affiche la surface tire-bouchon.
--mode random (Raccourci : --random-mode)
Utilise des primitives OpenGL aléatoires pour afficher la surface. C'est le défaut.
--mode points (Raccourci : --points)
Utilise des points OpenGL pour afficher la surface.
--mode lines (Raccourci : --lines)
Utilise des lignes OpenGL pour afficher la surface.
--mode line-loops (Raccourci : --line-loops)
Utilise des boucles de lignes OpenGL pour afficher la surface.
--wander | --no-wander
Indique s'il faut se déplacer aléatoirement sur l'écran.
--spin | --no-spin
Indique s'il faut tourner autour du centre de la figure.
--fps
Affiche le taux de rafraîchissement actuel, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
