subst(n) Commandes intégrées Tcl subst(n)

NOM

subst - Effectue des substitutions de backslash, de commande et de variable

SYNOPSIS

subst ?-nobackslashes? ?-nocommands? ?-novariables? string

DESCRIPTION

Cette commande effectue des substitutions de variables, des substitutions de commandes et des substitutions de backslash sur son argument string et retourne le résultat entièrement substitué. Les substitutions sont effectuées exactement de la même manière que pour les commandes Tcl. Par conséquent, l'argument string est en fait substitué deux fois, une fois par l'analyseur Tcl de la manière habituelle pour les commandes Tcl, et une fois par la commande subst.

Si l'une des options -nobackslashes, -nocommands ou -novariables est spécifiée, alors les substitutions correspondantes ne sont pas effectuées. Par exemple, si -nocommands est spécifié, la substitution de commande n'est pas effectuée : les crochets ouverts et fermés sont traités comme des caractères ordinaires sans interprétation spéciale.

Notez que la substitution d'un type peut inclure la substitution d'autres types. Par exemple, même lorsque l'option -novariables est spécifiée, la substitution de commande est effectuée sans restriction. Cela signifie que toute substitution de variable nécessaire pour compléter la substitution de commande aura toujours lieu. De même, toute substitution de commande nécessaire pour compléter une substitution de variable aura lieu, même lorsque -nocommands est spécifié. Voir les EXEMPLES ci-dessous.

Si une erreur se produit pendant la substitution, subst retournera cette erreur. Si une exception de break se produit pendant une substitution de commande ou de variable, le résultat de la substitution entière sera la chaîne (telle que substituée) jusqu'au début de la substitution qui a déclenché l'exception. Si une exception de continue se produit pendant l'évaluation d'une substitution de commande ou de variable, une chaîne vide sera substituée pour cette substitution de commande ou de variable entière (tant qu'elle est correctement formée en Tcl). Si une exception de return se produit, ou si tout autre code de retour est retourné pendant une substitution de commande ou de variable, alors la valeur retournée est substituée pour cette substitution. Voir les EXEMPLES ci-dessous. De cette manière, tous les codes de retour exceptionnels sont « capturés » par subst. La commande subst elle-même retournera soit une erreur, soit s'achèvera avec succès.

EXEMPLES

Lorsqu'elle effectue ses substitutions, subst n'accorde aucun traitement spécial aux guillemets doubles ou aux accolades (sauf dans les substitutions de commandes), donc le script

set a 44
subst {xyz {$a}}

retourne « xyz {44} », pas « xyz {$a} » et le script

set a "p\} q \{r"
subst {xyz {$a}}

retourne « xyz {p} q {r} », pas « xyz {p\} q \{r} ».

Lorsque la substitution de commande est effectuée, elle inclut toute substitution de variable nécessaire pour évaluer le script.

set a 44
subst -novariables {$a [format $a]}

retourne « $a 44 », pas « $a $a ». De même, lorsque la substitution de variable est effectuée, elle inclut toute substitution de commande nécessaire pour récupérer la valeur de la variable.

proc b {} {return c}
array set a {c c [b] tricky}
subst -nocommands {[b] $a([b])}

retourne « [b] c », pas « [b] tricky ».

Les exceptions continue et break permettent aux substitutions de commandes d'empêcher la substitution du reste de la substitution de commande et du reste de string respectivement, donnant plus d'options aux auteurs de scripts lors du traitement de texte à l'aide de subst. Par exemple, le script

subst {abc,[break],def}

retourne « abc, », pas « abc,,def » et le script

subst {abc,[continue;expr {1+2}],def}

retourne « abc,,def », pas « abc,3,def ».

D'autres codes de retour exceptionnels substituent la valeur retournée

subst {abc,[return foo;expr {1+2}],def}

retourne « abc,foo,def », pas « abc,3,def » et

subst {abc,[return -code 10 foo;expr {1+2}],def}

retourne également « abc,foo,def », pas « abc,3,def ».
