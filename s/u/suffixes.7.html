NOM

suffixes - liste des suffixes de fichiers

DESCRIPTION

Il est d'usage d'indiquer le contenu d'un fichier par son suffixe, qui (typiquement) consiste en un point, suivi d'une ou plusieurs lettres. De nombreux utilitaires standards, tels que les compilateurs, utilisent cela pour reconnaître le type de fichier avec lequel ils traitent. L'utilitaire make(1) est piloté par des règles basées sur le suffixe des fichiers.

Voici une liste des suffixes susceptibles d'être trouvés sur un système Linux.

Suffixe Type de fichier
,v fichiers pour RCS (Revision Control System)
