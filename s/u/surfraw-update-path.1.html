NOM

surfraw-update-path - met à jour PATH dans les fichiers de configuration du shell

SYNTAXE

surfraw-update-path [-add] [-remove] [-check] [-sys] [-all] [-help] [-shell=SHELL]

DESCRIPTION

surfraw-update-path ajoute le répertoire des elvis de surfraw (/usr/lib/surfraw) à votre PATH dans le fichier de configuration de votre shell.

Il prend actuellement en charge bash, sh, csh, tcsh, ash, dash, ksh, pdksh, zsh, rc et es

N'oubliez pas de vous reconnecter ou de sourcer vos fichiers de connexion pour que cela prenne effet.

OPTIONS

-check
Vérifie si le code de configuration surfraw est présent. C'est la valeur par défaut.
-add
Ajoute le code de configuration surfraw.
-remove
Supprime le code de configuration surfraw
-sys
Met à jour la configuration du shell à l'échelle du système au lieu de celle de l'utilisateur. Doit être exécuté en tant que root.
-shell=SHELL
Sélectionne le shell à configurer. Par défaut, il prend la valeur de la variable d'environnement $SHELL.

Les shells actuellement pris en charge sont :

sh, ash, bash, dash, csh, tcsh, ksh, pdksh, zsh, rc et es.

-all
Tente de configurer les fichiers de démarrage pour tous les shells connus.
-help
Affiche un message d'utilisation.

VALEUR DE RETOUR

-check renvoie 0 si le code surfraw est présent dans le fichier, 1 s'il n'est pas trouvé, ou 2 en cas d'erreur.

Toutes les autres options renvoient 0 en cas de succès, ou 2 en cas d'erreur.

ENVIRONNEMENT

SHELL
Utilisé pour déterminer quel shell configurer, si -shell n'est pas donné.
HOME
Utilisé pour trouver les fichiers de configuration de l'utilisateur.
ENV
Utilisé par les shells conformes à POSIX pour spécifier un fichier rc de démarrage.
ZDOTDIR
Utilisé pour trouver les fichiers de configuration utilisateur pour zsh. S'il n'est pas défini, il prend la valeur de HOME par défaut.
