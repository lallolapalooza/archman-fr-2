NOM

sxhkd - Démon de raccourcis clavier X simple

SYNTAXE

sxhkd [OPTIONS] [EXTRA_CONFIG ...]

DESCRIPTION

sxhkd est un démon de raccourcis clavier X simple avec une syntaxe de configuration puissante et compacte.

OPTIONS

-h

Affiche la syntaxe sur la sortie standard et quitte.

-v

Affiche les informations de version sur la sortie standard et quitte.

-m COUNT

Traiter les COUNT premiers événements de notification de mappage.

-t TIMEOUT

Délai d'attente en secondes pour l'enregistrement des chaînes d'accords.

-c FICHIER_CONFIG

Lire la configuration principale depuis le fichier spécifié.

-r FICHIER_REDIR

Rediriger la sortie des commandes vers le fichier spécifié.

-s FIFO_STATUT

Envoyer les informations de statut vers le FIFO spécifié.

-a CLEFSYM_ANNULER

Nom du keysym utilisé pour annuler les chaînes d'accords.

COMPORTEMENT

sxhkd est un démon qui écoute les événements clavier et exécute des commandes.

Il lit son fichier de configuration par défaut à l'adresse $XDG_CONFIG_HOME/sxhkd/sxhkdrc, ou à partir du fichier spécifié si l'option -c est utilisée.

Des fichiers de configuration supplémentaires peuvent être passés en arguments.

Si sxhkd reçoit un signal SIGUSR1 (resp. SIGUSR2), il rechargera son fichier de configuration (resp. basculera l'état de saisie de toutes ses liaisons).

Si sxhkd reçoit un signal SIGALRM, il interrompra la chaîne en cours s'il y en a une.

Les commandes sont exécutées via SHELL -c COMMANDE (vous pouvez donc utiliser les variables d'environnement).

SHELL sera le contenu de la première variable d'environnement définie dans la liste suivante : SXHKD_SHELL, SHELL.

SXHKD_PID sera automatiquement défini sur le pid de sxhkd dans les processus lancés par sxhkd, ce qui peut être utilisé par le processus enfant pour envoyer facilement des signaux tels que SIGALRM à la bonne instance de sxhkd.

Si vous avez un clavier non QWERTY ou une configuration de disposition non standard, vous devriez fournir un COUNT de 1 à l'option -m ou -1 (interprété comme l'infini) si vous passez constamment d'une disposition à l'autre (sxhkd ignore tous les événements de notification de mappage par défaut car la majorité de ces événements sont inutiles).

CONFIGURATION

Chaque ligne du fichier de configuration est interprétée comme suit :

•Si elle est vide ou commence par #, elle est ignorée.
•Si elle commence par un espace, elle est lue comme une commande.
•Sinon, elle est lue comme un raccourci clavier.

Syntaxe générale :

HOTKEY
    [;]COMMANDE
HOTKEY      := ACCORD_1 ; ACCORD_2 ; ... ; ACCORD_n
ACCORD_i    := [MODIFICATEURS_i +] [~][@]KEYSYM_i
MODIFICATEURS_i := MODIFICATEUR_i1 + MODIFICATEUR_i2 + ... + MODIFICATEUR_ik

Les noms de modificateurs valides sont : super, hyper, meta, alt, control, ctrl, shift, mode_switch, lock, mod1, mod2, mod3, mod4, mod5 et any.

Les noms de keysym sont donnés par la sortie de xev -event keyboard.

Les raccourcis clavier et les commandes peuvent être répartis sur plusieurs lignes en terminant chaque ligne partielle par un caractère backslash.

Lorsque plusieurs accords sont séparés par des points-virgules, le raccourci clavier est une chaîne d'accords : la commande ne sera exécutée qu'après avoir reçu chaque accord de la chaîne dans l'ordre consécutif.

Le caractère deux-points peut être utilisé à la place du point-virgule pour indiquer que la chaîne d'accords ne doit pas être interrompue lorsque la fin de la chaîne est atteinte.

Si une commande commence par un point-virgule, elle sera exécutée synchrone, sinon asynchrone.

La touche Échap peut être utilisée pour annuler une chaîne d'accords.

Si @ est ajouté au début du keysym, la commande sera exécutée lors des événements de relâchement de touche, sinon lors des événements d'appui de touche.

Si ~ est ajouté au début du keysym, l'événement capturé sera rejoué pour les autres clients.

Les raccourcis clavier du pointeur peuvent être définis en utilisant l'un des noms de keysym spéciaux suivants : button1, button2, button3, ..., button24.

Le raccourci clavier et la commande peuvent contenir des séquences de la forme {CHAINE_1,...,CHAINE_N}. Les accolades peuvent être échappées avec \.

De plus, les séquences peuvent contenir des plages de la forme A-Z où A et Z sont des caractères alphanumériques.

Le caractère underscore représente un élément de séquence vide.
