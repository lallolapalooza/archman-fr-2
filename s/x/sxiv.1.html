NOM

sxiv - Visionneuse d'images simple pour X

SYNOPIS

sxiv [-abcfhiopqrtvZ] [-A TAUX_IMPRESSIONS] [-e WID] [-G GAMMA] [-g GEOMETRIE] [-N NOM] [-n NUM] [-S DELAI] [-s MODE] [-z ZOOM] FICHIER...

DESCRIPTION

sxiv est une visionneuse d'images simple pour X.

Elle fonctionne selon deux modes : le mode image et le mode miniature. Le mode par défaut est le mode image, dans lequel seule l'image actuelle est affichée. En mode miniature, une grille de petites prévisualisations est affichée, facilitant le choix d'une image à ouvrir.

Veuillez noter que le mode plein écran nécessite un gestionnaire de fenêtres compatible EWMH/NetWM.

OPTIONS

-A TAUX_IMPRESSIONS
Lit les animations avec un taux d'impressions constant défini à TAUX_IMPRESSIONS.
-a
Lit les animations des images multi-images.
-b
N'affiche pas la barre d'informations en bas de la fenêtre.
-c
Supprime tous les fichiers de cache orphelins du répertoire de cache des miniatures et quitte.
-e WID
Intègre la fenêtre de sxiv dans la fenêtre dont l'ID est WID.
-f
Démarre en mode plein écran.
-G GAMMA
Définit le gamma de l'image à GAMMA (-32..32).
-g GEOMETRIE
Définit la position et la taille de la fenêtre. Voir la section SPÉCIFICATIONS DE GÉOMÉTRIE de X(7) pour plus d'informations sur l'argument GEOMETRIE.
-N NOM
Définit le nom de ressource de la fenêtre X de sxiv à NOM.
-n NUM
Commence à l'image numéro NUM.
-h
Affiche un bref résumé d'utilisation sur la sortie standard et quitte.
-i
Lit les noms des fichiers à ouvrir depuis l'entrée standard. C'est aussi fait si FICHIER est `-'.
-o
Écrit la liste de tous les fichiers marqués sur la sortie standard à la sortie. En combinaison avec -i, sxiv peut être utilisé comme un filtre/tube visuel.
-p
Active le mode privé, dans lequel sxiv n'écrit aucun fichier cache ou temporaire.
-q
Sois silencieux, désactive les avertissements sur le flux d'erreur standard.
-r
Recherche récursivement dans les répertoires donnés les images à visualiser.
-S DELAI
Démarre en mode diaporama. Définit le délai entre les images à DELAI secondes. DELAI peut être un nombre à virgule flottante.
-s MODE
Définit le mode de mise à l'échelle selon le caractère MODE. Les modes supportés sont : [d]own (vers le bas), [f]it (adapter), [w]idth (largeur), [h]eight (hauteur).
-t
Démarre en mode miniature.
-v
Affiche les informations de version sur la sortie standard et quitte.
-Z
Identique à `-z 100'.
-z ZOOM
Définit le niveau de zoom à ZOOM pour cent.

BARRE D'ÉTAT

Les informations affichées sur le côté gauche de la barre d'état peuvent être remplacées par la sortie d'un script défini par l'utilisateur, qui est appelé par sxiv chaque fois qu'une image est chargée. Le chemin de ce script est $XDG_CONFIG_HOME/sxiv/exec/image-info et les arguments qui lui sont passés sont : 1) le chemin du fichier image, 2) la largeur de l'image, 3) la hauteur de l'image.

Il existe également un script d'exemple installé avec sxiv sous le nom /usr/share/sxiv/exec/image-info.

GESTIONNAIRE CLAVIER EXTERNE

Des commandes clavier externes supplémentaires peuvent être définies à l'aide d'un programme de gestion situé dans $XDG_CONFIG_HOME/sxiv/exec/key-handler. Le gestionnaire est appelé en appuyant sur Ctrl-x. La combinaison de touches suivante lui est passée comme premier argument. Les images sur lesquelles agir sont passées via stdin, une ligne par chemin : toutes les images marquées, si en mode vignette et au moins une image a été marquée, sinon l'image actuelle. sxiv(1) sera bloqué jusqu'à ce que le gestionnaire se termine. Il vérifie ensuite quelles images ont été modifiées et les recharge.

L'argument de combinaison de touches a la forme suivante : "[C-][M-][S-]KEY", où C/M/S indiquent les états du modificateur Ctrl/Meta(Alt)/Shift et KEY est le keysym X tel que listé dans /usr/include/X11/keysymdef.h sans le préfixe "XK_".

Il existe également un script d'exemple installé avec sxiv sous le nom /usr/share/sxiv/exec/key-handler.

MISE EN CACHE DES VIGNETTES

sxiv stocke toutes les vignettes sous $XDG_CACHE_HOME/sxiv/.

Utilisez l'option de ligne de commande -c pour supprimer tous les fichiers de cache orphelins. De plus, exécutez la commande suivante ensuite dans le répertoire de cache pour supprimer les sous-répertoires vides :

find . -depth -type d -empty ! -name '.' -exec rmdir {} \;
