SXPM(1) Manuel des commandes générales SXPM(1)

NOM

sxpm - Afficher un fichier XPM (X PixMap) et/ou convertir des fichiers XPM 1 ou 2 en XPM 3.

SYNTAXE

sxpm [-d nom_affichage] [-g géométrie] [-hints] [-icon nom_fichier] [-plaid | nom_fichier | -] [-o nom_fichier | -o -] [-pcmap] [-closecolors] [-nod] [-nom] [-mono | -grey4 | -grey | -color] [-sc symbole couleur] [-sp symbole pixel] [-cp couleur pixel] [-rgb nom_fichier] [-v]

DESCRIPTION

Le programme sxpm peut être utilisé pour afficher n'importe quel fichier XPM (version 1, 2 ou 3) et/ou pour convertir un fichier XPM1 ou XPM2 en version 3. Si sxpm est exécuté avec une option bidon, l'utilisation est affichée. Si aucune géométrie n'est spécifiée, la fenêtre d'affichage aura la taille du pixmap lu. Appuyer sur la touche Q dans la fenêtre quittera le programme.

OPTIONS

-d nom_affichage
Spécifie l'affichage auquel se connecter.
-g géométrie
Géométrie de la fenêtre (par défaut, taille du pixmap).
-hints
Définit ResizeInc pour la fenêtre.
-icon nom_fichier
Définit l'icône avec le pixmap créé à partir du fichier nom_fichier.
-plaid
Affiche le pixmap en damier qui est stocké comme donnée.
nom_fichier
Lire depuis le fichier nom_fichier et depuis l'entrée standard si nom_fichier est '-'. Si aucune entrée n'est spécifiée, sxpm lit depuis l'entrée standard.
-o nom_fichier
Écrire dans le fichier nom_fichier (écraser s'il existe déjà) et vers la sortie standard si nom_fichier est '-'.
-mono
Utiliser les couleurs spécifiées pour un affichage monochrome.
-grey4
Utiliser les couleurs spécifiées pour un affichage en niveaux de gris 4 couleurs.
-grey
Utiliser les couleurs spécifiées pour un affichage en niveaux de gris.
-color
Utiliser les couleurs spécifiées pour un affichage en couleurs.
-pcmap
Utiliser une palette de couleurs privée.
-closecolors
Essayer d'utiliser des "couleurs proches" avant de se rabattre sur d'autres affichages.
-nod
Ne pas afficher le pixmap dans une fenêtre. (Utile lorsqu'utilisé comme convertisseur)
-nom
Ne pas utiliser le masque de découpe s'il y en a un.
-sc symbole nom_couleur
Remplacer la couleur par défaut du symbole par nom_couleur.
-sp symbole valeur_pixel
Remplacer la couleur par défaut du symbole par valeur_pixel.
-cp nom_couleur valeur_pixel
Remplacer la couleur par défaut du nom_couleur par valeur_pixel.
-rgb nom_fichier
Rechercher les noms de couleurs dans le fichier nom_fichier et les écrire à la place des valeurs rgb.
-v
Verbeux - pour afficher les extensions (sur stderr).

BOGUES CONNUS

Certains gestionnaires de fenêtres peuvent ne pas accepter un pixmap qui n'est pas un bitmap comme icône car cela ne respecte pas ICCCM, cependant beaucoup des gestionnaires bien connus l'accepteront.
