Paquet: net-snmp

SNMP-BRIDGE-MIB(1) Net-SNMP SNMP-BRIDGE-MIB(1)

NOM

snmp-bridge-mib - fournir des informations sur les ponts Linux via SNMP

SYNTAXE

snmp-bridge-mib {bridge}

ARGUMENTS

Les arguments suivants sont requis :

bridge

Le nom du pont Linux pour lequel vous souhaitez fournir des informations via SNMP, par exemple br0.

DESCRIPTION

Le snmp-bridge-mib est une extension de net-snmp. Il collecte des informations sur un pont dans un système Linux et les exporte pour les interroger à partir d'autres systèmes (à distance) à des fins de gestion.

CONFIGURATION :

La méthode préférée de snmp-bridge-mib pour se connecter à net-snmp est agentx. Pour que cela fonctionne, vous devrez ajouter la ligne suivante à /etc/snmp/snmpd.conf,

    master agentx

redémarrez snmpd et lancez snmp-bridge-mib. snmp-bridge-mib se connectera alors au démon snmpd en cours d'exécution.

Une autre façon d'attacher snmp-bridge-mib est de le lancer en tant que module Perl embarqué. Vous devez ajouter

    perl do "chemin vers l'emplacement de snmp-bridge-mib"

et redémarrer snmpd.

EXEMPLE :

Suivez les instructions de cette page de manuel et tapez

    perl /usr/bin/snmp-bridge-mib br0

Vous obtiendrez la sortie suivante :

     registering at .1.3.6.1.2.1.17
     running as a subagent.
     dot1qbridge agent started.
     NET-SNMP version 5.4.2.1 AgentX subagent connected

Il est maintenant temps d'un premier test :

    $ export MIBS=+BRIDGE-MIB
    $ snmpwalk localhost .1.3.6.1.2.1.17

BOGUES

1. snmp-bridge-mib ne prend actuellement en charge qu'un seul pont, qui doit être spécifié sur la ligne de commande.
2. Tous les éléments du RFC 4188 ne sont pas présents car ils ne sont soit pas disponibles dans sysfs, soit difficiles à extraire des données existantes.
