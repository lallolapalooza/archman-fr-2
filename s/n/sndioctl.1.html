SNDIOCTL(1) Manuel des commandes générales SNDIOCTL(1)

NOM

sndioctl — manipuler les contrôles des périphériques audio

SYNTAXE

sndioctl [-dimnqv] [-f périphérique] [commande ...]

DESCRIPTION

L'utilitaire sndioctl peut afficher ou manipuler les contrôles des périphériques audio sndio(7), comme le niveau de sortie. Les options sont les suivantes :

-d
Exporter la liste brute des contrôles disponibles et quitter. Utile comme outil de débogage.
-f périphérique
Utiliser ce périphérique audio sndio(7).
-i
Afficher les caractéristiques des contrôles demandés au lieu de leurs valeurs.
-m
Surveiller et afficher les changements des contrôles audio.
-n
Supprimer l'impression du nom de la variable.
-q
Supprimer toute impression lors de la définition d'une variable.
-v
Activer le mode verbeux, alias mode multicanal. Par défaut, les contrôles affectant différents canaux du même flux sont déguisés en un seul contrôle mono pour masquer les détails qui ne sont pas essentiels.

Si aucune commande n'est spécifiée, tous les contrôles valides sont affichés sur la sortie standard (stdout). Sauf si -d, -m, -n, ou -i sont utilisés, les lignes affichées sont des commandes valides. L'ensemble des contrôles disponibles dépend du périphérique audio.

Les commandes utilisent les deux formats suivants pour afficher et modifier respectivement les contrôles :

[groupe/]flux[canal].fonction
[groupe/]flux[canal].fonction=valeur

Sur le côté gauche sont spécifiés le groupe de contrôle (le cas échéant), le nom du flux affecté, et le numéro de canal optionnel. Exemples de termes de côté gauche :

output.level
output[0].level

Si le numéro de canal (y compris les crochets) est omis, la commande est appliquée à tous les canaux.

Les valeurs sont des nombres compris entre 0 et 1. Les contrôles à deux états (interrupteurs) prennent 0 ou 1 comme valeur, correspondant généralement aux états désactivé et activé respectivement.

Si un décimal est précédé du signe plus (moins), alors la valeur donnée est ajoutée à (soustraite de) la valeur actuelle du contrôle. Si "!" est utilisé à la place d'un nombre, alors l'interrupteur est basculé.

EXEMPLES

Augmenter le contrôle level affectant tous les canaux de output de 10% du maximum :

$ sndioctl output.level=+0.1

Couper le son de tous les canaux de output :

$ sndioctl output.mute=1

Basculer le contrôle mute ci-dessus :

$ sndioctl output.mute=!

Autoriser l'enregistrement audio et régler tous les canaux d'input à 50% :

# sysctl kern.audio.record=1
$ sndioctl input.mute=0 input.level=0.5
