NOM

snmpconf - crée et modifie les fichiers de configuration SNMP

SYNTAXE

snmpconf [OPTIONS] [fichierÀCréer]

Démarrer avec :
snmpconf -g basic_setup
Ou même juste :
snmpconf

DESCRIPTION

snmpconf est un script Perl simple qui vous guide étape par étape dans la configuration d'un fichier de configuration. Son utilisation devrait être assez simple. Il suffit de le lancer et de répondre à ses questions.

Dans son mode de fonctionnement par défaut, il interroge l'utilisateur avec des menus montrant les sections des différents fichiers de configuration qu'il connaît. Lorsque l'utilisateur sélectionne une section, un sous-menu est affiché, répertoriant les descriptions des jetons qui peuvent être créés dans cette section. Lorsqu'une description est sélectionnée, l'utilisateur est invité à répondre à des questions qui construisent la ligne de configuration en question.

Enfin, lorsque l'utilisateur quitte le programme, tous les fichiers de configuration qui ont été modifiés par l'utilisateur sont enregistrés dans le répertoire local, entièrement commentés.

Une option particulièrement utile est le commutateur -g, qui guide l'utilisateur à travers un ensemble spécifique de questions de configuration. Exécutez :

snmpconf -g basic_setup

pour un exemple.

OPTIONS

-f
Force l'écrasement des fichiers existants dans le répertoire courant sans demander à l'utilisateur si c'est une action souhaitée.
-i
Une fois terminé, installe les fichiers à l'emplacement où les commandes système globales s'attendent à les trouver.
-p
Une fois terminé, installe les fichiers dans le sous-répertoire .snmp du répertoire personnel de l'utilisateur (où les applications chercheront également les fichiers de configuration).
-I RÉPERTOIRE
Une fois terminé, installe les fichiers dans le répertoire RÉPERTOIRE.
-a
Ne pose aucune question. Lit simplement les différents fichiers de configuration connus et les réécrit. Cela a pour effet de "commenter automatiquement" les fichiers de configuration pour vous. Voir la section ASTUCES GÉNIALES ci-dessous.
-rtout|aucun
Lit tous les fichiers de configuration trouvés ou aucun. Normalement, snmpconf vous demande quels fichiers vous souhaitez lire. La lecture de ces fichiers de configuration fusionnera ces fichiers avec les résultats des questions qu'il vous pose.
-R FICHIER,...
Lit une liste spécifique de fichiers de configuration.
-g NOMGROUPE
Des groupes d'entrées de configuration peuvent être créés pour guider l'utilisateur à travers une série de questions afin de créer un fichier de configuration initial. Il n'y a pas de menus à naviguer, juste une liste de questions. Exécutez :

snmpconf -g basic_setup

pour un bon exemple.

-G
Liste tous les groupes connus.
-c RÉPERTOIRECONFIG
snmpconf utilise un répertoire d'informations de configuration pour apprendre les fichiers et les questions qu'il doit poser. Cette option indique à snmpconf d'utiliser un emplacement différent pour se configurer.
-q
Exécution légèrement plus silencieuse. Comme il s'agit d'un programme interactif, je ne recommande pas cette option car elle ne fait que supprimer des informations de la sortie qui sont conçues pour vous aider.
-d
Active beaucoup de sortie de débogage.
-D
Ajoute encore plus de sortie de débogage sous forme de dumps de variables Perl.

ASTUCES GÉNIALES

snmpconf -g basic_setup
Ai-je mentionné cette commande suffisamment ? Elle est conçue pour guider quelqu'un à travers une configuration initiale du démon snmpd(8). Vraiment, vous devriez l'essayer.
snmpconf -R /usr/local/snmp/snmpd.conf -a -f snmpd.conf
Lit automatiquement un fichier snmpd.conf (par exemple) et y ajoute des commentaires décrivant la fonction de chaque jeton. Essayez-le. C'est cool.

NOTES

snmpconf est en réalité un utilitaire très générique qui pourrait être facilement configuré pour aider à construire à peu près n'importe quel type de fichier de configuration. Son ensemble de fichiers de configuration par défaut est basé sur SNMP.
