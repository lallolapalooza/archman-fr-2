NOM

snmpdf - afficher l'utilisation de l'espace disque sur une entité réseau via SNMP

SYNTAXE

snmpdf [OPTIONS COMMUNES] [-Cu] [-Ch] AGENT

DESCRIPTION

snmpdf est simplement une version réseau de la commande df typique. Elle vérifie l'espace disque sur la machine distante en examinant la table hrStorageTable de HOST-RESOURCES-MIB ou la table dskTable de UCD-SNMP-MIB. Par défaut, hrStorageTable est préférée car elle contient généralement plus d'informations. Cependant, l'argument -Cu peut être passé à snmpdf pour forcer l'utilisation de dskTable.

AGENT identifie un agent SNMP cible, qui est instrumenté pour surveiller les objets donnés. Dans sa forme la plus simple, la spécification AGENT consistera en un nom d'hôte ou une adresse IPv4. Dans ce cas, la commande tentera une communication avec l'agent, en utilisant UDP/IPv4 vers le port 161 de l'hôte cible donné. Voir la page de manuel snmpcmd(1) pour une liste complète des formats possibles pour AGENT.

Voir la page de manuel snmpd.conf(5) sur la configuration de dskTable en utilisant la directive disk dans le fichier snmpd.conf.

OPTIONS

OPTIONS COMMUNES
Veuillez consulter snmpcmd(1) pour une liste des valeurs possibles pour OPTIONS COMMUNES ainsi que leurs descriptions.
-Cu
Force la commande à utiliser dskTable dans le MIB UCD-SNMP-MIB au lieu du MIB par défaut pour déterminer les informations de stockage. Généralement, l'utilisation par défaut de hrStorageTable dans le MIB HOST-RESOURCES-MIB est préférée car elle contient généralement plus d'informations.
-Ch
Affiche les tailles dans un format lisible par l'homme (c'est-à-dire MiB, GiB, TiB)
-CH
Affiche les tailles dans un format SI lisible par l'homme (c'est-à-dire Mo, Go, To)

% snmpdf -v 2c -c public localhost
