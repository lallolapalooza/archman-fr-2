SNMPSTATUS(1) Net-SNMP SNMPSTATUS(1)

NOM

snmpstatus - récupère un ensemble fixe d'informations de gestion à partir d'une entité réseau

SYNTAXE

snmpstatus [OPTIONS COMMUNES] [-Cf] AGENT

DESCRIPTION

snmpstatus est une application SNMP qui récupère plusieurs statistiques importantes d'une entité réseau.

AGENT identifie un agent SNMP cible, instrumenté pour surveiller les objets donnés. Dans sa forme la plus simple, la spécification AGENT consistera en un nom d'hôte ou une adresse IPv4. Dans ce cas, la commande tentera une communication avec l'agent, en utilisant UDP/IPv4 vers le port 161 de l'hôte cible donné.

Voir la page de manuel snmpcmd(1) pour une liste complète des formats possibles pour AGENT.

Les informations retournées sont :

L'adresse IP de l'entité.
Une description textuelle de l'entité (sysDescr.0)
Le temps de fonctionnement de l'agent SNMP de l'entité (sysUpTime.0)
La somme des paquets reçus sur toutes les interfaces (ifInUCastPkts.* + ifInNUCastPkts.*)
La somme des paquets transmis sur toutes les interfaces (ifOutUCastPkts.* + ifOutNUCastPkts.*)
Le nombre de paquets IP entrants (ipInReceives.0)
Le nombre de paquets IP sortants (ipOutRequests.0)

Par exemple :

snmpstatus -c public -v 1 netdev-kbox.cc.cmu.edu

produira une sortie similaire à ce qui suit :

[128.2.56.220]=>[Kinetics FastPath2] Actif depuis : 1 jour, 4:43:31
Interfaces : 1, Paquets reçus/transmis : 262874/39867 | IP : 31603/15805

snmpstatus vérifie également l'état opérationnel de toutes les interfaces (ifOperStatus.*), et s'il en trouve qui ne fonctionnent pas, il le signalera d'une manière similaire à celle-ci :

2 interfaces sont inactives !

Si l'entité réseau a une erreur lors du traitement du paquet de requête, un paquet d'erreur sera renvoyé et un message sera affiché, aidant à identifier la manière dont la requête était malformée. snmpstatus tentera de reformuler sa requête pour éliminer la variable malformée (sauf si l'option -Cf est donnée, voir ci-dessous), mais cette variable sera alors manquante dans les données affichées.

OPTIONS

OPTIONS COMMUNES
Veuillez consulter la page de manuel snmpcmd(1) pour une liste des valeurs possibles pour OPTIONS COMMUNES ainsi que leurs descriptions.
-Cf
Par défaut, snmpstatus essaiera de corriger les erreurs renvoyées par l'agent et de réessayer une requête. Dans ce cas, la commande affichera les données qu'elle peut obtenir. Si l'option -Cf est spécifiée, alors snmpstatus n'essaiera pas de corriger les erreurs, et l'erreur entraînera la fin de la commande.

VOIR AUSSI
