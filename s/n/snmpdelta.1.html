Paquet: net-snmp

SNMPDELTA(1) Net-SNMP SNMPDELTA(1)

NOM

snmpdelta - Surveiller les différences delta des valeurs de compteur SNMP

SYNTAXE

snmpdelta [ OPTIONS COMMUNES ] [-Cf] [ -Ct ] [ -Cs ] [ -CS ] [ -Cm ] [ -CF fichier_config ] [ -Cl ] [ -Cp période ] [ -CP pics ] [ -Ck ] [ -CT ] AGENT OID [ OID ... ]

DESCRIPTION

snmpdelta surveillera les OID spécifiés à valeur entière et rapportera les changements au fil du temps.

AGENT identifie un agent SNMP cible, instrumenté pour surveiller les objets donnés. Au plus simple, la spécification AGENT consistera en un nom d'hôte ou une adresse IPv4. Dans ce cas, la commande tentera une communication avec l'agent, en utilisant UDP/IPv4 vers le port 161 de l'hôte cible donné. Voir snmpcmd(1) pour une liste complète des formats possibles pour AGENT.

OID est un identifiant d'objet qui identifie de manière unique le type d'objet dans une MIB. Plusieurs OID peuvent être spécifiés sur une seule commande snmpdelta.

OPTIONS

OPTIONS COMMUNES
Veuillez consulter snmpcmd(1) pour une liste des valeurs possibles pour les OPTIONS COMMUNES ainsi que leurs descriptions.
-Cf
Ne pas corriger les erreurs et réessayer la requête. Sans cette option, si plusieurs oids ont été spécifiés pour une seule requête et si la requête pour un ou plusieurs oids échoue, snmpdelta réessaiera la requête afin que les données pour les oids autres que ceux qui ont échoué soient quand même renvoyées. Spécifier -Cf indique à snmpdelta de ne pas réessayer une requête, même s'il y a plusieurs oids spécifiés.
-Ct
Ce drapeau déterminera l'intervalle de temps de l'entité surveillée.
-Cs
Ce drapeau affichera un horodatage.
-CS
Génère un « total cumulé » en plus des comptes individuels des instances. Le « total cumulé » est la somme de tous les deltas individuels pour chaque période de temps.
-Cm
Affiche la valeur maximale jamais atteinte.
-CF fichier_config
Indique à snmpdelta de lire sa configuration depuis le fichier spécifié. Cette option permet de configurer l'entrée à l'avance plutôt que de devoir la spécifier en ligne de commande.
-Cl
Indique à snmpdelta d'écrire sa configuration dans des fichiers dont les noms correspondent aux instances MIB surveillées. Par exemple, snmpdelta -Cl localhost ifInOctets.1 créera un fichier « localhost-ifInOctets.1 ».
-Cp
Spécifie le nombre de secondes entre les périodes d'interrogation. L'interrogation consiste à envoyer une requête à l'agent. La période d'interrogation par défaut est d'une seconde.
-CP pics
Spécifie la période de rapport en nombre de périodes d'interrogation. Si cette option est spécifiée, snmpdelta interroge l'agent pics fois avant de rapporter les résultats. Le résultat rapporté inclut la valeur moyenne sur la période de rapport. De plus, la valeur la plus élevée interrogée pendant la période de rapport est affichée.
-Ck
Lorsque la période d'interrogation (-Cp) est un multiple de 60 secondes et que l'horodatage est affiché dans la sortie (-Cs), alors l'affichage par défaut montre l'horodatage au format hh:mm mm/jj. Cette option provoque un format d'horodatage hh:mm:ss mm/jj.
-CT
Fait en sorte que snmpdelta affiche sa sortie sous forme tabulaire.
-Cv vars/paquet
Spécifie le nombre maximum d'oids autorisés à être empaquetés dans une seule PDU. Plusieurs PDU peuvent être créées dans une seule requête. La valeur par défaut des variables par paquet est de 60. Cette option est utile si une réponse de requête entraîne une erreur car le paquet est trop gros.

Notez que snmpdelta REQUIERT un argument spécifiant l'agent à interroger et au moins un argument OID, comme décrit dans la page de manuel snmpcmd(1).

L'exemple suivant utilise un certain nombre d'options. Comme l'option Cl est spécifiée, la sortie est envoyée à un fichier et non à l'écran.

$ snmpdelta -c public -v 1 -Ct -Cs -CS -Cm -Cl -Cp 60 -CP 60
  interlink.sw.net.cmu.edu .1.3.6.1.2.1.2.2.1.16.3 .1.3.6.1.2.1.2.2.1.16.4
