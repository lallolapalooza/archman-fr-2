SNMPBULKGET(1) Net-SNMP SNMPBULKGET(1)

NOM

snmpbulkget - communique avec une entité réseau en utilisant des requêtes SNMP GETBULK.

SYNTAXE

snmpbulkget [OPTIONS COMMUNES] [-Cn <num>] [-Cr <NUM>] AGENT OID [OID]...

DESCRIPTION

snmpbulkget est une application SNMP qui utilise la requête SNMP GETBULK pour interroger efficacement une entité réseau pour obtenir des informations. Un ou plusieurs identifiants d'objet (OID) peuvent être fournis comme arguments sur la ligne de commande. Chaque nom de variable est donné dans le format spécifié dans variables(5).

Si l'entité réseau rencontre une erreur lors du traitement du paquet de requête, un paquet d'erreur sera renvoyé et un message sera affiché, aidant à identifier pourquoi la requête était malformée.

OPTIONS

-Cn<NUM>
Définit le champ non-repeaters dans le PDU GETBULK. Ceci spécifie le nombre de variables fournies qui ne doivent pas être itérées. La valeur par défaut est 0.
-Cr<NUM>
Définit le champ max-repetitions dans le PDU GETBULK. Ceci spécifie le nombre maximum d'itérations sur les variables répétitives. La valeur par défaut est 10.

En plus de ces options, snmpbulkget accepte les options communes décrites dans la page de manuel snmpcmd(1). Notez que snmpbulkget REQUIERT un argument spécifiant l'agent à interroger et au moins un argument OID, comme décrit là.

EXEMPLE

La commande :

snmpbulkget -v2c -Cn1 -Cr5 -Os -c public zeus system ifTable

récupérera la variable system.sysDescr.0 (qui est l'objet lexicographiquement suivant de system) et les 5 premiers objets de ifTable :

sysDescr.0 = STRING: "SunOS zeus.net.cmu.edu 4.1.3_U1 1 sun4m"
ifIndex.1 = INTEGER: 1
ifIndex.2 = INTEGER: 2
ifDescr.1 = STRING: "lo0"
etc.

NOTE

Comme son nom l'indique, snmpbulkget utilise le message SNMP GETBULK, qui n'est pas disponible dans SNMPv1.

VOIR AUSSI

snmpcmd(1), variables(5), RFC 1905.
