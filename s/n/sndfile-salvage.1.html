NOM

sndfile-salvage — récupérer des données audio à partir de fichiers WAV plus longs que 4G

SYNTAXE

sndfile-salvage toolong.wav fixed64.wav

DESCRIPTION

Les fichiers audio utilisant le conteneur de fichiers WAV sont intrinsèquement limités par les champs de taille de données de 4G dans l'en-tête WAV, stockés sous forme d'entiers non signés de 32 bits. De nombreuses applications ont des problèmes avec ces fichiers WAV dont la taille dépasse 4G. sndfile-salvage réécrit le fichier WAV dans un fichier W64 avec le même contenu audio. Ce fichier est écrasé s'il existe déjà.

CODE DE SORTIE

L'utilitaire sndfile-salvage se termine 0 en cas de succès, et >0 si une erreur survient.
