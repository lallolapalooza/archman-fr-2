snmpps(1)

Paquet: net-snmp

Licences: BSD

SNMPPS(1) Net-SNMP SNMPPS(1)

NOM

snmpps - affiche la table des processus sur une entité réseau via SNMP

SYNTAXE

snmpps [OPTIONS COMMUNES] [-Cp] [-Ca] [-C n | m | t ] AGENT

snmptop [OPTIONS COMMUNES] [-Cp] [-Ca] [-C n | m | t ] AGENT

DESCRIPTION

snmpps est une version réseau d'une simple commande ps. Il vérifie les processus sur la machine distante en examinant la hrSWRunTable et la hrSWRunPerfTable du HOST-RESOURCES-MIB.

AGENT identifie un agent SNMP cible, instrumenté pour surveiller les objets donnés. Dans sa forme la plus simple, la spécification AGENT consistera en un nom d'hôte ou une adresse IPv4. Dans ce cas, la commande tentera une communication avec l'agent, en utilisant UDP/IPv4 sur le port 161 de l'hôte cible donné. Voir la page de manuel snmpcmd(1) pour une liste complète des formats possibles pour AGENT.

snmptop émule la commande top en utilisant SNMP. Pendant l'exécution, les entrées du clavier 'c', 'n', 'm', 't' basculent le tri entre le CPU, le PID, la mémoire ou le temps d'exécution total. Taper 'i' active/désactive le masquage des processus inactifs, tandis que 'o' active/désactive le masquage des processus Os. Taper 'a' active/désactive l'affichage des hrSWRunParameters, 'p' active/désactive l'affichage des hrSWRunPath.

OPTIONS

OPTIONS COMMUNES
Veuillez consulter snmpcmd(1) pour une liste des valeurs possibles pour OPTIONS COMMUNES ainsi que leurs descriptions.
-Cp
Affiche hrSWRunPath en plus de hrSWRunName
-Ca
Affiche hrSWRunParameters en plus de hrSWRunName
-Ct
Trie l'affichage par utilisation totale du CPU
-Cm
Trie l'affichage par utilisation de la mémoire
-Cn
Trie l'affichage numériquement par PID

EXEMPLES

% snmpps -v 2c -c public localhost

Index Type Status     Memory         CPU Command
    1 Appl   Wait     1.00MB        1.29 init 
  554 Appl   Wait   364.00kB        0.03 udevd 
 1813 Appl    Run     6.73MB        0.41 snmpd 
 1833 Appl   Wait     1.27MB        3.49 rsyslogd 
 1871 Appl   Wait   496.00kB       47.92 irqbalance

 2121 Appl   Wait     1.89MB        0.00 bash 
 2150 Appl   Wait     3.49MB        0.16 vim 
 2185 Appl   Wait   556.00kB        0.00 sleep
