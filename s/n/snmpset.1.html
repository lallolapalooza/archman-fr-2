SNMPSET(1) Net-SNMP SNMPSET(1)

NOM

snmpset - communique avec une entité réseau en utilisant des requêtes SNMP SET

SYNTAXE

snmpset [OPTIONS COMMUNES] AGENT OID TYPE VALEUR [OID TYPE VALEUR]...

DESCRIPTION

snmpset est une application SNMP qui utilise la requête SNMP SET pour définir des informations sur une entité réseau. Un ou plusieurs identificateurs d'objet (OID) doivent être fournis en arguments sur la ligne de commande. Un type et une valeur à définir doivent accompagner chaque identificateur d'objet. Chaque nom de variable est donné dans le format spécifié dans variables(5).

Le TYPE est un seul caractère, parmi:

i
ENTIER
u
NON SIGNÉ
s
CHAÎNE
x
CHAÎNE HEXADÉCIMALE
d
CHAÎNE DÉCIMALE
n
NULLOBJ
o
OBJID
t
TIMETICKS
a
IPADDRESS
b
BITS
La plupart d'entre eux utiliseront le type ASN.1 correspondant évident. 's', 'x', 'd' et 'b' sont différentes façons de spécifier une valeur de type OCTET STRING, et le type non signé 'u' est également utilisé pour gérer les valeurs Gauge32.

Si vous avez le fichier MIB approprié chargé, vous pouvez, dans la plupart des cas, remplacer le type par un signe '='. Pour un objet de type OCTET STRING, cela supposera une chaîne comme la notation de type 's'. Pour d'autres types, cela fera "la bonne chose".

Par exemple:

snmpset -c private -v 1 test-hub system.sysContact.0 s dpz@noc.rutgers.edu ip.ipforwarding.0 = 2

définira les variables sysContact.0 et ipForwarding.0:

system.sysContact.0 = STRING: "dpz@noc.rutgers.edu"
ip.ipForwarding.0 = ENTIER: not-forwarding(2)

Si l'entité réseau a une erreur lors du traitement du paquet de requête, un paquet d'erreur sera renvoyé et un message sera affiché, aidant à identifier la manière dont la requête a été mal formée.

OPTIONS

snmpset prend les options communes décrites dans la page de manuel snmpcmd(1). Notez que snmpset REQUIERT un argument spécifiant l'agent à interroger et au moins un jeu d'arguments OID/type/valeur, comme décrit dans celle-ci.

VOIR AUSSI

snmpcmd(1), variables(5).
