NOM

snmpwalk - récupère un sous-arbre de valeurs de gestion en utilisant des requêtes GETNEXT SNMP

SYNTAXE

snmpwalk [OPTIONS APPLICATION] [OPTIONS COMMUNES] AGENT [OID]

DESCRIPTION

snmpwalk est une application SNMP qui utilise des requêtes SNMP GETNEXT pour interroger une entité réseau pour un arbre d'informations.

Un identifiant d'objet (OID) peut être donné sur la ligne de commande. Cet OID spécifie quelle partie de l'espace des identifiants d'objets sera recherchée à l'aide des requêtes GETNEXT. Toutes les variables du sous-arbre sous l'OID donné sont interrogées et leurs valeurs sont présentées à l'utilisateur. Chaque nom de variable est donné dans le format spécifié dans variables(5).

Si aucun argument OID n'est présent, snmpwalk recherchera le sous-arbre enraciné à SNMPv2-SMI::mib-2 (y compris les valeurs d'objets MIB provenant d'autres modules MIB, qui sont définis comme se situant dans ce sous-arbre). Si l'entité réseau rencontre une erreur lors du traitement du paquet de requête, un paquet d'erreur sera renvoyé et un message sera affiché, aidant à identifier pourquoi la requête était malformée.

Si la recherche de l'arbre entraîne des tentatives de recherche au-delà de la fin du MIB, le message « End of MIB » sera affiché.

OPTIONS

-Cc
Ne pas vérifier si les OID renvoyés sont croissants. Certains agents (les LaserJet en sont un exemple) renvoient les OID dans le désordre, mais peuvent quand même terminer la recherche. D'autres agents renvoient des OID désordonnés et peuvent provoquer une boucle infinie de snmpwalk. Par défaut, snmpwalk tente de détecter ce comportement et vous avertit lorsqu'il rencontre un agent agissant illégalement. Utilisez -Cc pour désactiver cette vérification.
-CE {OID}
Terminer la recherche à l'OID spécifié, plutôt qu'à un simple sous-arbre. Ceci peut être utilisé pour parcourir un sous-arbre partiel, des colonnes sélectionnées d'une table, ou même deux tables ou plus au sein d'une seule commande.
-Ci
Inclure l'OID donné dans la plage de recherche. Normalement, snmpwalk utilise des requêtes GETNEXT à partir de l'OID que vous avez spécifié et renvoie tous les résultats dans le sous-arbre MIB enraciné à cet OID. Parfois, vous souhaiterez peut-être inclure l'OID spécifié sur la ligne de commande dans les résultats imprimés s'il s'agit d'un OID valide dans l'arbre lui-même. Cette option vous permet de le faire explicitement.
-CI
En fait, l'OID donné sera récupéré automatiquement si la recherche du sous-arbre principal ne renvoie aucune valeur utilisable. Cela permet à la recherche d'une seule instance de se comporter comme attendu en général et de renvoyer la valeur de l'instance spécifiée. Cette option désactive cette dernière requête GET, de sorte qu'une recherche d'une seule instance ne renverra rien.
-Cp
À la fin de la recherche, affichez le nombre de variables trouvées.
-Ct
À la fin de la recherche, affichez le temps total d'horloge écoulé qu'il a fallu pour collecter les données (en secondes). Notez que le chronomètre est démarré juste avant le début de la série de requêtes de données et arrêté juste après sa fin. Le plus important, cela signifie qu'il n'inclut pas l'initialisation de la bibliothèque snmp, l'arrêt, le traitement des arguments, ni aucune autre surcharge.

En plus de ces options, snmpwalk prend les options communes décrites dans la page de manuel snmpcmd(1).

EXEMPLES

Notez que snmpwalk REQUIERT un argument spécifiant l'agent à interroger et au plus un argument OID, comme décrit là-bas. La commande :

snmpwalk -Os -c public -v 1 zeus system

récupérera toutes les variables sous system :

sysDescr.0 = STRING: "SunOS zeus.net.cmu.edu 4.1.3_U1 1 sun4m"
sysObjectID.0 = OID: enterprises.hp.nm.hpsystem.10.1.1
sysUpTime.0 = Timeticks: (155274552) 17 days, 23:19:05
sysContact.0 = STRING: ""
sysName.0 = STRING: "zeus.net.cmu.edu"
sysLocation.0 = STRING: ""
sysServices.0 = INTEGER: 72
(plus le contenu de sysORTable).

La commande :

snmpwalk -Os -c public -v 1 -CE sysORTable zeus system

récupérera les valeurs scalaires, mais omettra sysORTable.

VOIR AUSSI

snmpcmd(1), snmpbulkwalk(1), variables(5).
