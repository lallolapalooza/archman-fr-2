SNDFILE-METADATA-GET(1) Manuel des commandes générales SNDFILE-METADATA-GET(1)

NOM

sndfile-metadata-get, sndfile-metadata-set — obtenir ou définir des métadonnées dans un fichier son

SYNOPIS

sndfile-metadata-get [options] fichier

sndfile-metadata-set [options] fichier

sndfile-metadata-set [options] entrée sortie

DESCRIPTION

sndfile-metadata-get affiche les métadonnées bext et de chaîne stockées dans un fichier audio. Les options suivantes spécifient ce qu'il faut imprimer.

--all
toutes les métadonnées
--bext-description
description
--bext-originator
informations d'origine
--bext-orig-ref
référence de l'origine
--bext-umid
Identifiant Unique de Matériel
--bext-orig-date
date d'origine
--bext-orig-time
heure d'origine
--bext-coding-hist
historique de codage
--str-title
titre
--str-copyright
droits d'auteur
--str-artist
artiste
--str-comment
commentaire
--str-date
date de création
--str-album
album
--str-license
licence

sndfile-metadata-set définit les métadonnées bext et de chaîne dans un fichier audio si le format le supporte. Si le fichier ne contient pas de bloc BEXT à modifier, la deuxième synopsis doit être utilisée, où un autre fichier de sortie capable de stocker les métadonnées est créé. Ce fichier est écrasé s'il existe déjà. Les options suivantes prennent un argument spécifiant les métadonnées :

--bext-description
description
--bext-originator
origine
--bext-orig-ref
référence de l'origine
--bext-umid
Identifiant Unique de Matériel
--bext-orig-date
date d'origine
--bext-orig-time
heure d'origine
--bext-coding-hist
historique de codage
--bext-time-raf
référence temporelle
--str-comment
commentaire
--str-title
titre
--str-copyright
droits d'auteur
--str-artist
artiste
--str-date
date
--str-album
album
--str-license
licence

Les options suivantes ne prennent pas d'argument :

--bext-auto-time-date
Définit l'heure et la date BEXT à l'heure actuelle.
--bext-auto-time
Définit l'heure BEXT à l'heure actuelle.
--bext-auto-date
Définit la date BEXT à l'heure actuelle.
--str-auto-date
Définit la date de chaîne à l'heure actuelle.

ETAT DE SORTIE

L'utilitaire sndfile-metadata-get se termine avec un statut de 0 en cas de succès, et >0 si une erreur se produit.
