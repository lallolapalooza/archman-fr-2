Documentation de fonction/sous-programme

real(wp) fonction snrm2 (entier n, réel(wp), dimension(*) x, entier incx)

SNRM2

Objectif :

!>
!> SNRM2 retourne la norme euclidienne d'un vecteur via le nom de la fonction,
!> de telle sorte que
!>
!>    SNRM2 := sqrt( x'*x ).
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

X

!>          X est un tableau REEL, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un ENTIER, espacement de stockage entre les éléments de X
!>          Si INCX > 0, X(1+(i-1)*INCX) = x(i) pour 1 <= i <= n
!>          Si INCX < 0, X(1-(n-i)*INCX) = x(i) pour 1 <= i <= n
!>          Si INCX = 0, x n'est pas un vecteur donc il n'y a pas besoin d'appeler
!>          ce sous-programme. Si vous l'appelez quand même, il comptera x(1)
!>          dans la norme du vecteur N fois.
!>
