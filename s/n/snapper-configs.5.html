SNAPPER-CONFIGS(5) Gestion des instantanés de système de fichiers SNAPPER-CONFIGS(5)

NOM

snapper-configs - Fichiers de configuration pour les configurations de snapper

DESCRIPTION

Chaque fichier /etc/snapper/configs/* décrit une configuration de snapper.

VARIABLES

Voici une liste des variables pouvant être présentes dans le fichier de configuration. Les valeurs booléennes doivent être "yes" ou "no".

SUBVOLUME=chemin

Chemin du sous-volume ou du point de montage.

Il n'y a pas de valeur par défaut. La valeur doit toujours être spécifiée.

FSTYPE=valeur

Type de système de fichiers pour le sous-volume.

La valeur par défaut est "btrfs" mais il est recommandé de toujours spécifier le type de système de fichiers.

QGROUP=qgroup

Le groupe de quotas btrfs utilisé pour les algorithmes de nettoyage tenant compte de l'espace.

Uniquement supporté pour btrfs.

SPACE_LIMIT=flottant ou taille

Seuil pour l'espace maximal que les instantanés devraient utiliser sur le système de fichiers. Lorsque les instantanés dépassent cette limite (soit en fraction du système de fichiers entier, soit en valeur absolue), snapper supprimera les instantanés plus anciens lors des opérations de nettoyage. Une valeur absolue doit utiliser la locale C.

Uniquement supporté pour btrfs.

La valeur par défaut est "0.5" (50% du système de fichiers).

Nouveau dans la version 0.3.0, valeur absolue nouvelle dans la version 0.9.0.

FREE_LIMIT=flottant ou taille

Seuil pour l'espace libre minimum qui devrait rester sur le système de fichiers. Lorsque l'espace libre tombe en dessous de cette limite (soit en fraction du système de fichiers entier, soit en valeur absolue), snapper supprimera les instantanés plus anciens lors des opérations de nettoyage pour récupérer de l'espace. Une valeur absolue doit utiliser la locale C.

Uniquement supporté pour btrfs.

La valeur par défaut est "0.2" (20% du système de fichiers).

Nouveau dans la version 0.8.0, valeur absolue nouvelle dans la version 0.9.0.

ALLOW_USERS=utilisateurs

Liste des utilisateurs autorisés à opérer avec la configuration. Les noms d'utilisateur doivent être séparés par des espaces. Les espaces dans les noms d'utilisateur peuvent être échappés avec un "\".

Voir aussi la section PERMISSIONS dans snapper(8).

Il faut éviter d'utiliser des utilisateurs réseau car cela peut casser la plupart des commandes, y compris le rollback, lorsque le réseau ne fonctionne pas.

La valeur par défaut est "" mais "root" est toujours implicitement inclus.

ALLOW_GROUPS=groupes

Liste des groupes autorisés à opérer avec la configuration. Les noms de groupe doivent être séparés par des espaces. Les espaces dans les noms de groupe peuvent être échappés avec un "\".

Voir aussi la section PERMISSIONS dans snapper(8).

Il faut éviter d'utiliser des groupes réseau car cela peut casser la plupart des commandes, y compris le rollback, lorsque le réseau ne fonctionne pas.

La valeur par défaut est "".

SYNC_ACL=booléen

Définit si snapper synchronisera les utilisateurs et groupes de ALLOW_USERS et ALLOW_GROUPS avec l'ACL du répertoire .snapshots.

Voir aussi la section PERMISSIONS dans snapper(8).

La valeur par défaut est "no".

Nouveau dans la version 0.2.0.

BACKGROUND_COMPARISON=booléen

Définit si les instantanés avant et après doivent être comparés en arrière-plan après leur création.

La valeur par défaut est "yes".

COMPRESSION=algorithme

Définit l'algorithme de compression utilisé pour enregistrer la liste des fichiers. Les valeurs autorisées sont "none" et "gzip". Selon les bibliothèques installées, certains algorithmes de compression pourraient ne pas être disponibles.

La valeur par défaut est "gzip".

Nouveau dans la version 0.10.1.

NUMBER_CLEANUP=booléen

Définit si l'algorithme de nettoyage par numéro doit être exécuté pour la configuration.

La valeur par défaut est "no".

NUMBER_MIN_AGE=secondes

Âge minimum des instantanés pour être supprimés par l'algorithme de nettoyage par numéro.

La valeur par défaut est "3600".

NUMBER_LIMIT=nombre ou plage

Définit combien d'instantanés l'algorithme de nettoyage par numéro doit conserver. Les instantanés les plus récents seront conservés.

La valeur par défaut est "50".

NUMBER_LIMIT_IMPORTANT=nombre ou plage

Définit combien d'instantanés importants l'algorithme de nettoyage par numéro doit conserver. Les instantanés importants ont la valeur important=yes dans leurs données utilisateur. Les instantanés importants les plus récents seront conservés.

Le nombre d'instantanés normaux et importants sont comptés indépendamment.

La valeur par défaut est "10".

Nouveau dans la version 0.1.8.

TIMELINE_CREATE=booléen

Définit si des instantanés horaires doivent être créés.

Avec l'algorithme de nettoyage de chronologie, cela créera une collection d'instantanés avec plus d'instantanés dans le passé récent et moins d'instantanés dans le passé lointain.

La valeur par défaut est "no".

TIMELINE_CLEANUP=booléen

Définit si l'algorithme de nettoyage de chronologie doit être exécuté pour la configuration.

La valeur par défaut est "no".

TIMELINE_MIN_AGE=secondes

Âge minimum des instantanés pour être supprimés par l'algorithme de nettoyage de chronologie.

La valeur par défaut est "3600".

TIMELINE_LIMIT_HOURLY=nombre ou plage

Définit combien d'instantanés horaires l'algorithme de nettoyage de chronologie doit conserver. Un instantané horaire est le premier instantané d'une heure. Les instantanés horaires les plus récents seront conservés.

La valeur par défaut est "10".

TIMELINE_LIMIT_DAILY=nombre ou plage

Définit combien d'instantanés quotidiens l'algorithme de nettoyage de chronologie doit conserver. Un instantané quotidien est le premier instantané d'un jour. Les instantanés quotidiens les plus récents seront conservés.

La valeur par défaut est "10".

TIMELINE_LIMIT_WEEKLY=nombre ou plage

Définit combien d'instantanés hebdomadaires l'algorithme de nettoyage de chronologie doit conserver. Un instantané hebdomadaire est le premier instantané d'une semaine. Les instantanés hebdomadaires les plus récents seront conservés. Conformément à l'ISO 8601, les semaines commencent le lundi.

La valeur par défaut est "0".

TIMELINE_LIMIT_MONTHLY=nombre ou plage

Définit combien d'instantanés mensuels l'algorithme de nettoyage de chronologie doit conserver. Un instantané mensuel est le premier instantané d'un mois. Les instantanés mensuels les plus récents seront conservés.

La valeur par défaut est "10".

TIMELINE_LIMIT_QUARTERLY=nombre ou plage

Définit combien d'instantanés trimestriels l'algorithme de nettoyage de chronologie doit conserver. Un instantané trimestriel est le premier instantané d'un trimestre. Les instantanés trimestriels les plus récents seront conservés.

La valeur par défaut est "0".

TIMELINE_LIMIT_YEARLY=nombre ou plage

Définit combien d'instantanés annuels l'algorithme de nettoyage de chronologie doit conserver. Un instantané annuel est le premier instantané d'une année. Les instantanés annuels les plus récents seront conservés.

La valeur par défaut est "10".

EMPTY_PRE_POST_CLEANUP=booléen

Définit si l'algorithme de nettoyage empty-pre-post doit être exécuté pour la configuration.

La valeur par défaut est "no".

EMPTY_PRE_POST_MIN_AGE=secondes

Âge minimum des instantanés pour être supprimés par l'algorithme de nettoyage empty-pre-post.

La valeur par défaut est "3600".

TYPES

Certains des types utilisés pour les variables méritent une explication.

plage

Une plage de nombres donnée sous la forme valeur-min-valeur-max, par exemple "10-20".

qgroup

Un groupe de quotas btrfs

snapper-configs(5) — Arch manual pages

NAME

snapper-configs(5) ― configuration files for snapper

DESCRIPTION

The configuration files for snapper are located in the /etc/snapper/configs/ directory. Each file in this directory describes a snapshot configuration.

The configuration file is a plain text file, which is parsed by snapper. It supports comments starting with #.

The configuration file has the following sections:

  • SUBVOLUME
  • DESCRIPTION
  • ALLOW_USERS
  • ALLOW_GROUPS
  • SYNC_ACL
  • EARLY_TRIM_HOLDS
  • TRIM_LIMIT
  • TRIM_SUGGESTED_BUSINESS_DAYS
  • TRIM_AMOUNT
  • TRIM_FREESPACE
  • NUMBER_MIN_INTEGER_SIZE
  • NUMBER_MAX_INTEGER_SIZE
  • NUMBER_CLEANUP_ALGORITHM
  • NUMBER_CLEANUP_HOLDS
  • NUMBER_CLEANUP_MAX_AGE
  • NUMBER_CLEANUP_MIN_AGE
  • NUMBER_CLEANUP_REMOTE
  • NUMBER_CLEANUP_ALL
  • NUMBER_CLEANUP_TOO_OLD
  • NUMBER_CLEANUP_MAX_snapshots
  • NUMBER_CLEANUP_MIN_snapshots
  • NUMBER_CLEANUP_MAX_snapshots_since_hourly
  • NUMBER_CLEANUP_MAX_snapshots_since_daily
  • NUMBER_CLEANUP_MAX_SNAPSHOTS_since_weekly
  • NUMBER_CLEANUP_MAX_SNAPSHOTS_since_monthly
  • NUMBER_CLEANUP_MAX_SNAPSHOTS_since_yearly
  • NUMBER_CLEANUP_EMPTY_DIR
  • NUMBER_CLEANUP_REMOTE_PREFIX
  • NUMBER_CLEANUP_REMOTE_GROUP
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_AGE
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MIN_AGE
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_TOO_OLD
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MIN_SNAPSHOTS
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_hourly
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_daily
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_weekly
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_monthly
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_yearly
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_EMPTY_DIR
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_REMOTE_PREFIX
  • NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_REMOTE_GROUP
  • QGROUP

VARIABLES

The configuration file uses the following variables:

SUBVOLUME
The subvolume that is watched by snapper. This is the only required parameter.
DESCRIPTION
An optional description for the configuration.
ALLOW_USERS
A list of users that are allowed to use snapper with this configuration. If empty, all users are allowed.
ALLOW_GROUPS
A list of groups that are allowed to use snapper with this configuration. If empty, all groups are allowed.
SYNC_ACL
If set to yes, the access control lists (ACLs) of the snapshots will be synchronized with the subvolume. Default is no.
EARLY_TRIM_HOLDS
If set to yes, the TRIM algorithm will be run before the cleanup algorithm. Default is no.
TRIM_LIMIT
A percentage of the total free space on the filesystem. The TRIM algorithm will not remove snapshots if the free space is below this limit. Default is 50.
TRIM_SUGGESTED_BUSINESS_DAYS
The TRIM algorithm will suggest a number of days to keep snapshots based on the amount of free space. Default is 7.
TRIM_AMOUNT
A percentage of the total free space on the filesystem. The TRIM algorithm will try to free up this amount of space. Default is 50.
TRIM_FREESPACE
A minimum amount of free space in percent of the total filesystem size. The TRIM algorithm will try to ensure that at least this amount of free space is available. Default is 10.
NUMBER_MIN_INTEGER_SIZE
The minimum size of the integer used for snapshot numbering. Default is 10.
NUMBER_MAX_INTEGER_SIZE
The maximum size of the integer used for snapshot numbering. Default is 10.
NUMBER_CLEANUP_ALGORITHM
The cleanup algorithm to use. Can be number, empty_dir, or used_space. Default is number.
NUMBER_CLEANUP_HOLDS
A list of integer snapshot numbers that will not be removed by the cleanup algorithm. Default is empty.
NUMBER_CLEANUP_MAX_AGE
Maximum age of snapshots to be removed by the cleanup algorithm. Can be specified in seconds, minutes, hours, days, weeks, months, or years. Default is 0 (no limit).
NUMBER_CLEANUP_MIN_AGE
Minimum age of snapshots to be removed by the cleanup algorithm. Can be specified in seconds, minutes, hours, days, weeks, months, or years. Default is 0 (no limit).
NUMBER_CLEANUP_REMOTE
If set to yes, snapshots on remote repositories will also be cleaned up. Default is no.
NUMBER_CLEANUP_ALL
If set to yes, all snapshots will be considered for cleanup. Default is no.
NUMBER_CLEANUP_TOO_OLD
If set to yes, snapshots older than NUMBER_CLEANUP_MAX_AGE will be removed. Default is no.
NUMBER_CLEANUP_MAX_SNAPSHOTS
Maximum number of snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_MIN_SNAPSHOTS
Minimum number of snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_hourly
Maximum number of hourly snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_daily
Maximum number of daily snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_weekly
Maximum number of weekly snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_monthly
Maximum number of monthly snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_yearly
Maximum number of yearly snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_EMPTY_DIR
If set to yes, empty directories will be removed. Default is no.
NUMBER_CLEANUP_REMOTE_PREFIX
Prefix for remote snapshots. Default is .
NUMBER_CLEANUP_REMOTE_GROUP
A list of groups that are allowed to create remote snapshots. Default is empty.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT
Maximum number of remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_AGE
Maximum age of remote snapshots to be removed. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MIN_AGE
Minimum age of remote snapshots to be removed. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_TOO_OLD
If set to yes, remote snapshots older than NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_AGE will be removed. Default is no.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS
Maximum number of remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MIN_SNAPSHOTS
Minimum number of remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_hourly
Maximum number of hourly remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_daily
Maximum number of daily remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_weekly
Maximum number of weekly remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_monthly
Maximum number of monthly remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_yearly
Maximum number of yearly remote snapshots to keep. Default is 0 (no limit).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_EMPTY_DIR
If set to yes, empty remote directories will be removed. Default is no.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_REMOTE_PREFIX
Prefix for remote snapshots. Default is .
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_REMOTE_GROUP
A list of groups that are allowed to create remote snapshots. Default is empty.
QGROUP
The qgroup limit for snapshots. The format is level-id, e.g. 1/0.

TYPES

The configuration file uses the following types:

SUBVOLUME
A path to a subvolume.
DESCRIPTION
A string.
ALLOW_USERS
A comma-separated list of user names.
ALLOW_GROUPS
A comma-separated list of group names.
SYNC_ACL
A boolean value (yes or no).
EARLY_TRIM_HOLDS
A boolean value (yes or no).
TRIM_LIMIT
An integer percentage.
TRIM_SUGGESTED_BUSINESS_DAYS
An integer number of days.
TRIM_AMOUNT
An integer percentage.
TRIM_FREESPACE
An integer percentage.
NUMBER_MIN_INTEGER_SIZE
An integer number.
NUMBER_MAX_INTEGER_SIZE
An integer number.
NUMBER_CLEANUP_ALGORITHM
A string (number, empty_dir, or used_space).
NUMBER_CLEANUP_HOLDS
A comma-separated list of integer snapshot numbers.
NUMBER_CLEANUP_MAX_AGE
A time value (e.g., 1d, 2w, 3m, 4y).
NUMBER_CLEANUP_MIN_AGE
A time value (e.g., 1d, 2w, 3m, 4y).
NUMBER_CLEANUP_REMOTE
A boolean value (yes or no).
NUMBER_CLEANUP_ALL
A boolean value (yes or no).
NUMBER_CLEANUP_TOO_OLD
A boolean value (yes or no).
NUMBER_CLEANUP_MAX_SNAPSHOTS
An integer number.
NUMBER_CLEANUP_MIN_SNAPSHOTS
An integer number.
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_hourly
An integer number.
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_daily
An integer number.
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_weekly
An integer number.
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_monthly
An integer number.
NUMBER_CLEANUP_MAX_SNAPSHOTS_since_yearly
An integer number.
NUMBER_CLEANUP_EMPTY_DIR
A boolean value (yes or no).
NUMBER_CLEANUP_REMOTE_PREFIX
A string.
NUMBER_CLEANUP_REMOTE_GROUP
A comma-separated list of group names.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_AGE
A time value (e.g., 1d, 2w, 3m, 4y).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MIN_AGE
A time value (e.g., 1d, 2w, 3m, 4y).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_TOO_OLD
A boolean value (yes or no).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MIN_SNAPSHOTS
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_hourly
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_daily
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_weekly
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_monthly
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_MAX_SNAPSHOTS_since_yearly
An integer number.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_EMPTY_DIR
A boolean value (yes or no).
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_REMOTE_PREFIX
A string.
NUMBER_CLEANUP_PRESERVE_REMOTE_AMOUNT_REMOTE_GROUP
A comma-separated list of group names.
QGROUP
The qgroup limit for snapshots in the standard form level-id, e.g. 1/0.

NOTES

The default values stated here are the values snapper uses when the entry is missing in the configuration file. Some are not identical to the values from the configuration file template.
