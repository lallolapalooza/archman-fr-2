snmptranslate(1)

Paquet: net-snmp

Licences: BSD

SNMPTRANSLATE(1) Net-SNMP SNMPTRANSLATE(1)

NOM

snmptranslate - traduire les noms d'OID MIB entre les formes numérique et textuelle

SYNOPIS

snmptranslate [OPTIONS] OID [OID]...
snmptranslate [OPTIONS] -

DESCRIPTION

snmptranslate est une application qui traduit une ou plusieurs valeurs d'identificateur d'objet SNMP de leurs formes symboliques (textuelles) vers leurs formes numériques (ou vice versa).

OID est soit un identificateur d'objet numérique, soit textuel.

L'argument spécial - est utilisé pour traduire plusieurs OID en une seule exécution. L'entrée est prise depuis stdin, et la sortie est écrite vers stdout. Le format d'entrée peut être un seul OID par ligne, ou peut être la sortie de snmpwalk ou snmpget.

OPTIONS

-D[TOKEN[,...]]
Activer la sortie de débogage pour le(s) TOKEN spécifié(s). Essayez ALL pour une sortie extrêmement détaillée.
-h
Afficher un bref message d'utilisation puis quitter.
-m MIBLIST
Spécifie une liste de modules MIB séparés par des deux-points à charger pour cette application. Ceci remplace la variable d'environnement MIBS.
Le mot-clé spécial ALL est utilisé pour spécifier tous les modules dans tous les répertoires lors de la recherche de fichiers MIB. Chaque fichier dont le nom ne commence pas par "." sera analysé comme s'il s'agissait d'un fichier MIB.
-M DIRLIST
Spécifie une liste de répertoires séparés par des deux-points pour rechercher les MIB. Ceci remplace la variable d'environnement MIBDIRS.
-T TRANSOPTS
Permet de contrôler la traduction des valeurs d'OID. Les TRANSOPTS suivants sont disponibles :
-TB
Afficher tous les objets correspondants pour une recherche par regex.
-Td
Afficher les détails complets de l'OID spécifié.
-Tp
Afficher un arbre graphique, enraciné à l'OID spécifié.
-Ta
Exporter la MIB chargée sous une forme triviale.
-Tl
Exporter une forme étiquetée de tous les objets.
-To
Exporter une forme numérique de tous les objets.
-Ts
Exporter une forme symbolique de tous les objets.
-Tt
Exporter une forme arborescente des MIB chargées (principalement utile pour le débogage).
-Tz
Exporter une forme numérique et étiquetée de tous les objets (compatible avec le format MIB2SCHEMA).
-V
Afficher les informations de version de l'application puis quitter.
-w WIDTH
Spécifie la largeur de la sortie de -Tp et -Td. La valeur par défaut est très grande.

En plus des options ci-dessus, snmptranslate prend les options d'entrée d'OID (-I), d'analyse de MIB (-M) et de sortie d'OID (-O) décrites dans les sections OPTIONS D'ENTRÉE, OPTIONS D'ANALYSE DE MIB et OPTIONS DE SORTIE de la page de manuel snmpcmd(1).

EXEMPLES

•
snmptranslate -On -IR sysDescr
traduira "sysDescr" dans une forme plus qualifiée :
system.sysDescr
•
snmptranslate -Onf -IR sysDescr
traduira "sysDescr" en :
.iso.org.dod.internet.mgmt.mib-2.system.sysDescr
•
snmptranslate -Td -OS system.sysDescr
traduira "sysDescr" en :
SNMPv2-MIB::sysDescr
sysDescr OBJECT-TYPE
  -- FROM SNMPv2-MIB
  -- TEXTUAL CONVENTION DisplayString
  SYNTAX OCTET STRING (0..255)
  DISPLAY-HINT "255a"
  MAX-ACCESS read-only
  STATUS current
  DESCRIPTION "A textual description of the entity. This
               value should include the full name and
               version identification of the system's
               hardware type, software operating-system,
               and networking software."
::= { iso(1) org(3) dod(6) internet(1) mgmt(2) mib-2(1) system(1) 1 }
•
snmptranslate -Tp -OS system
affichera l'arbre suivant :
