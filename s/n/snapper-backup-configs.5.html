SNAPPER-BACKUP-CON(5) Gestion des snapshots de système de fichiers SNAPPER-BACKUP-CON(5)

NOM

snapper-backup-configs - Fichiers de configuration pour les configurations de sauvegarde snapper

DESCRIPTION

Chaque fichier /etc/snapper/backup-configs/*.json décrit une configuration de sauvegarde snapper.

Le fichier utilise la syntaxe JSON contenant un seul objet avec des paires clé-valeur.

PAIRS CLÉ VALEUR

Ce qui suit est une liste de clés pouvant être présentes dans le fichier de configuration.

config

Nom de la configuration snapper.

target-mode

Soit local, soit ssh-push.

source-path

Chemin du sous-volume source. Ceci doit correspondre au sous-volume de la configuration snapper correspondante.

target-path

Chemin du sous-volume cible ou du point de montage.

automatic

Booléen pour activer le transfert et la suppression automatiques pour la configuration de sauvegarde à l'aide d'un service de timer systemd.

ssh-host

Nom de l'hôte cible. Requis pour le mode target ssh-push.

ssh-port

Port de l'hôte cible. Optionnel pour le mode target ssh-push.

ssh-user

Utilisateur sur l'hôte cible. Optionnel pour le mode target ssh-push.

ssh-identity

Une identité ssh pour accéder à l'hôte sans nécessiter de mot de passe ou de phrase secrète. Optionnel pour le mode target ssh-push.

target-btrfs-bin

Emplacement du binaire btrfs sur la cible. Peut également être utilisé pour installer des scripts wrapper. Optionnel.

target-findmnt-bin

Emplacement du binaire findmnt sur la cible. Peut également être utilisé pour installer des scripts wrapper. Optionnel.

target-mkdir-bin

Emplacement du binaire mkdir sur la cible. Peut également être utilisé pour installer des scripts wrapper. Optionnel.

target-realpath-bin

Emplacement du binaire realpath sur la cible. Peut également être utilisé pour installer des scripts wrapper. Optionnel.

target-rm-bin

Emplacement du binaire rm sur la cible. Peut également être utilisé pour installer des scripts wrapper. Optionnel.

target-rmdir-bin

Emplacement du binaire rmdir sur la cible. Peut également être utilisé pour installer des scripts wrapper. Optionnel.

EXEMPLES

Un exemple de configuration de sauvegarde pour les sauvegardes locales :

{
    "config": "root",
    "target-mode": "local",
    "automatic": true,
    "source-path": "/",
    "target-path": "/backups/root"
}

Un exemple de configuration de sauvegarde pour les sauvegardes distantes via ssh-push :

{
    "config": "root",
    "target-mode": "ssh-push",
    "automatic": false,
    "source-path": "/",
    "target-path": "/backups/eberich/root",
    "ssh-host": "backups.example.com",
    "ssh-identity": "/etc/snapper/certs/id_ecdsa"
}
