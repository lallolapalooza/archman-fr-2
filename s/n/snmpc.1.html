snmpc(1) Commandes utilisateur snmpc(1)

NOM

snmpc - Frontend du compilateur MIB SNMP

SYNTAXE

snmpc [options] fichier.mib | fichier.bin

DESCRIPTION

Le programme snmpc fournit un moyen d'exécuter le compilateur MIB SNMP du système Erlang.

snmpc compile un fichier MIB SNMP. Voir compile/1,2 pour plus d'informations.

Il peut également être utilisé pour générer un fichier d'en-tête (.hrl) avec les définitions des constantes Erlang pour les objets de la MIB. Voir mib_to_hrl/1.

Options du compilateur

Les options suivantes sont prises en charge (notez que la plupart d'entre elles concernent la compilation du fichier MIB) :

--help

Affiche l'aide.

--version

Affiche la version de l'application et du format mib.

--verbosity verbosite

Affiche les informations de débogage.

verbosite = trace | debug | log | info | silence

Par défaut, silence.

--warnings | --W

Affiche les messages d'avertissement.

--wae | --Werror

Les avertissements sont traités comme des erreurs. Indique que les avertissements doivent être traités comme des erreurs.

--o répertoire

Le répertoire où le compilateur doit placer les fichiers de sortie. S'il n'est pas spécifié, les fichiers de sortie seront placés dans le répertoire de travail actuel.

--i Répertoire

Spécifie le chemin à rechercher pour les fichiers MIB importés (compilés). Par défaut, le répertoire de travail actuel est toujours inclus.

Cette option peut être présente plusieurs fois, spécifiant à chaque fois *un* chemin.

--il Répertoire

Cette option (include_lib), spécifie une liste de répertoires à rechercher pour les MIB importées. Elle suppose que le premier élément du nom du répertoire correspond à une application OTP. Le compilateur trouvera la version actuellement installée. Par exemple, la valeur ["snmp/mibs/"] sera remplacée par ["snmp-3.1.1/mibs/"] (ou quelle que soit la version actuelle dans le système). Le répertoire actuel et le répertoire "snmp-home"/priv/mibs/ sont toujours listés en dernier dans le chemin d'inclusion.

--sgc

Cette option (skip group check), si elle est présente, désactive la vérification de groupe du compilateur mib. C'est-à-dire, si les macros OBJECT-GROUP et NOTIFICATION-GROUP doivent être vérifiées pour leur exactitude ou non.

--dep

Conserve les définitions obsolètes. Si non spécifié, le compilateur ignorera les définitions obsolètes.

--desc

Le champ DESCRIPTION sera inclus.

--ref

Le champ REFERENCE sera inclus.

--imp

Le champ IMPORTS sera inclus.

--mi

Le champ MODULE-IDENTITY sera inclus.

--mc

Le champ MODULE-COMPLIANCE sera inclus.

--ac

Le champ AGENT-CAPABILITIES sera inclus.

--mod module

Le module qui implémente toutes les fonctions d'instrumentation.

Le nom de toutes les fonctions d'instrumentation doit être le même que celui de l'objet géré correspondant qu'il implémente.

--nd

Les fonctions d'instrumentation par défaut ne seront *pas* utilisées si un objet géré n'a pas de fonction d'instrumentation. Ceci sera plutôt signalé comme une erreur et la compilation sera interrompue.

--rrnac

Cette option, si elle est présente, spécifie que la vérification de l'affectation du nom de ligne ne doit pas être effectuée strictement selon la SMI (qui n'autorise que la valeur 1).

Avec cette option, toutes les valeurs supérieures à zéro sont autorisées (>= 1). Cela signifie que l'erreur sera convertie en avertissement.

Par défaut, elle n'est pas incluse, mais si cette option est présente, elle le sera.
