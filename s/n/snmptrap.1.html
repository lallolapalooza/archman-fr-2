snmptrap(1)

Paquet: net-snmp

SNMPTRAP(1) Net-SNMP SNMPTRAP(1)

NOM

snmptrap, snmpinform - envoie une notification SNMP à un gestionnaire

SYNTAXE

snmptrap -v 1 [OPTIONS COMMUNES] AGENT enterprise-oid agent generic-trap specific-trap uptime [OID TYPE VALEUR]...

snmptrap -v [2c|3] [OPTIONS COMMUNES] [-Ci] AGENT uptime trap-oid [OID TYPE VALEUR]...

snmpinform -v [2c|3] [OPTIONS COMMUNES] AGENT uptime trap-oid [OID TYPE VALEUR]...

DESCRIPTION

snmptrap est une application SNMP qui utilise l'opération SNMP TRAP pour envoyer des informations à un gestionnaire de réseau. Un ou plusieurs identificateurs d'objets (OID) peuvent être donnés comme arguments sur la ligne de commande. Un type et une valeur doivent accompagner chaque identificateur d'objet. Chaque nom de variable est donné dans le format spécifié dans variables(5).

Lorsqu'il est appelé en tant que snmpinform, ou lorsque -Ci est ajouté aux options de ligne de commande de snmptrap, il envoie un INFORM-PDU, attendant une réponse du récepteur de trap, et retransmettant si nécessaire. Sinon, il envoie un TRAP-PDU ou un TRAP2-PDU.

Si l'un des paramètres requis de la version 1, enterprise-oid, agent, et uptime est spécifié comme vide, il prendra par défaut 1.3.6.1.4.1.3.1.1 (enterprises.cmu.1.1), hostname, et host-uptime respectivement.

Le TYPE est un seul caractère, parmi :

u
NON SIGNÉ
c

s
CHAÎNE

a

qui sont traités de la même manière que la commande snmpset.

L'argument AGENT est uniquement intégré dans les TRAP-PDU SNMP mais pas dans les INFORM-PDU SNMP. Si AGENT n'est pas une chaîne vide, il doit être une adresse IPv4. Cette limitation provient du RFC 1157, dans lequel le champ d'adresse de l'agent est défini comme suit :

agent-addr NetworkAddress, -- adresse de l'objet générant le trap

D'après le RFC 1155 :

NetworkAddress ::=
CHOICE {
internet IpAddress
}
[ ... ]
IpAddress ::=
[APPLICATION 0] -- en ordre d'octets réseau
IMPLICIT OCTET STRING (SIZE (4))

Un exemple d'utilisation de snmptrap :

snmptrap -v 1 -c public manager enterprises.spider test-hub 3 0 '' interfaces.iftable.ifentry.ifindex.1 i 1

enverra un trap générique linkUp au gestionnaire, pour l'interface 1.

OPTIONS

snmptrap prend les options communes décrites dans la page de manuel snmpcmd(1) en plus de l'option -Ci décrite ci-dessus. Notez que snmptrap REQUIERT un argument spécifiant l'agent à interroger comme décrit là-bas.

VOIR AUSSI

snmpcmd(1), snmpset(1), variables(5).
