NOM

snmptable - récupérer un tableau SNMP et l'afficher sous forme tabulaire

SYNOPSIS

snmptable [OPTIONS COMMUNES] [-Cb] [-CB] [-Ch] [-CH] [-Ci] [-Cf CHAINE] [-Cw LARGEUR] AGENT OID-TABLEAU

DESCRIPTION

snmptable est une application SNMP qui utilise de manière répétée les requêtes SNMP GETNEXT ou GETBULK pour interroger des informations sur une entité réseau. Le paramètre OID-TABLEAU doit spécifier un tableau SNMP.

AGENT identifie un agent SNMP cible, instrumenté pour surveiller les objets donnés. Dans sa forme la plus simple, la spécification AGENT consistera en un nom d'hôte ou une adresse IPv4. Dans ce cas, la commande tentera de communiquer avec l'agent, en utilisant UDP/IPv4 sur le port 161 de l'hôte cible donné. Voir snmpcmd(1) pour une liste complète des formats possibles pour AGENT.

OPTIONS

OPTIONS COMMUNES
Veuillez consulter snmpcmd(1) pour une liste des valeurs possibles pour les OPTIONS COMMUNES ainsi que leur description.
-Cb
Afficher uniquement un en-tête bref. Tout préfixe commun des noms de champs du tableau sera supprimé.
-CB
Ne pas utiliser les requêtes GETBULK pour récupérer les données, seulement GETNEXT.
-Cc CARACTERES
Afficher le tableau en colonnes d'une largeur de CARACTERES.
-Cf CHAINE
La chaîne CHAINE est utilisée pour séparer les colonnes du tableau. Avec cette option, chaque entrée du tableau sera affichée sous forme compacte, juste avec la chaîne donnée pour séparer les colonnes (utile si vous voulez l'importer dans une base de données). Sinon, elle est affichée dans des colonnes bien alignées.
-Ch
Afficher *uniquement* les en-têtes de colonne.
-CH
Ne pas afficher les en-têtes de colonne.
-Ci
Cette option préfixe l'indice de l'entrée à toutes les lignes affichées.
-Cl
Aligner à gauche les données dans chaque colonne.
-Cr REPETITIONS
Pour les requêtes GETBULK, REPETITIONS spécifie la valeur max-repeaters à utiliser. Pour les requêtes GETNEXT, REPETITIONS spécifie le nombre d'entrées à récupérer à la fois.
-Cw LARGEUR
Spécifie la largeur des lignes lors de l'affichage du tableau. Si les lignes sont plus longues, le tableau sera affiché en sections de LARGEUR caractères au maximum. Si LARGEUR est inférieure à la longueur du contenu d'une seule colonne, alors cette colonne unique sera quand même affichée.

Notez que snmptable REQUIERT un argument spécifiant l'agent à interroger et exactement un argument OID, comme décrit dans la page de manuel snmpcmd(1). Cet OID *doit* être celui d'un objet de tableau MIB.

EXEMPLES

$ snmptable -v 2c -c public localhost at.atTable

SNMP table: at.atTable RFC1213-MIB::atTable

atIfIndex atPhysAddress atNetAddress
1 8:0:20:20:0:ab 130.225.243.33

$ snmptable -v 2c -c public -Cf + localhost at.atTable

SNMP table: at.atTable

atIfIndex+atPhysAddress+atNetAddress 1+8:0:20:20:0:ab+130.225.243.33

BOGUES

Le test pour savoir si OID-TABLEAU spécifie réellement un tableau est assez heuristique. Notez également que le test nécessite que le fichier MIB définissant soit chargé.
