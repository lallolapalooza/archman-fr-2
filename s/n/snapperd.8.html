SNAPPERD(8) Gestion des instantanés de système de fichiers SNAPPERD(8)

NOM

snapperd - démon DBus pour snapper

SYNTAXE

snapperd

DESCRIPTION

Snapperd est un démon DBus pour snapper et n'est pas destiné à une utilisation directe par l'utilisateur.

OPTIONS

--logger-type type

Définit le type de journalisation. Les valeurs possibles sont none, stdout, logfile et syslog.

--debug

Active le mode de débogage.
