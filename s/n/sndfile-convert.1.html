NOM

sndfile-convert — convertir des fichiers sonores d'un format à un autre

SYNOPSIS

sndfile-convert [-override-sample-rate=taux] [-endian=little | big | cpu] [-normalize] [encodage] entrée sortie

DESCRIPTION

sndfile-convert convertit des fichiers sonores d'un format audio à un autre. Le fichier de sortie est écrasé s'il existe déjà.

Options

Les options suivantes sont reconnues :

-override-sample-rate=taux
Fait en sorte que l'entrée utilise le taux d'échantillonnage de taux Hz.
-endian=little
Fait en sorte que le fichier de sortie utilise des données little-endian.
-endian=big
Fait en sorte que le fichier de sortie utilise des données big-endian.
-endian=cpu
Fait en sorte que le fichier de sortie utilise l'endianness du CPU.
-normalize
Normalise les données audio dans le fichier de sortie.

Encodages

Le paramètre optionnel encodage permet de définir l'encodage des données pour le fichier de sortie. Les encodages suivants sont actuellement supportés :

-pcms8
pcm signé 8 bits
-pcmu8
pcm non signé 8 bits
-pcm16
pcm 16 bits
-pcm24
pcm 24 bits
-pcm32
pcm 32 bits
-float32
point flottant 32 bits
-ulaw
ULAW
-alaw
ALAW
-ima-adpcm
IMA ADPCM (WAV uniquement)
-ms-adpcm
MS ADPCM (WAV uniquement)
-gsm610
GSM6.10 (WAV uniquement)
-dwvw12
DWVW 12 bits (AIFF uniquement)
-dwvw16
DWVW 16 bits (AIFF uniquement)
-dwvw24
DWVW 24 bits (AIFF uniquement)
-vorbis
Vorbis (OGG uniquement)

Si aucun encodage n'est spécifié pour le fichier de sortie, sndfile-convert essaiera d'utiliser l'encodage du fichier d'entrée. Cela ne fonctionnera pas toujours car la plupart des formats conteneurs (par exemple, WAV, AIFF, etc.) ne prennent en charge qu'un petit sous-ensemble d'encodages (par exemple, PCM 16 bits, a-law, Vorbis, etc.).

CODE DE SORTIE

L'utilitaire sndfile-convert se termine avec un statut 0 en cas de succès, et >0 si une erreur se produit.
