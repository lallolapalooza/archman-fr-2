SNAKE(6) Manuel des Jeux SNAKE(6)

NOM

snake — jeu de poursuite sur écran

SYNTAXE

snake [largeur hauteur] [-s]

DESCRIPTION

snake est un jeu basé sur l'écran qui doit être joué sur un terminal CRT. Le but du jeu est de gagner le plus d'argent possible sans se faire manger par le serpent. Deux arguments optionnels permettent de spécifier la taille du terrain de jeu. Par défaut, tout l'écran est utilisé. Si l'argument -s est passé, snake affichera les scores et quittera.

Vous êtes représenté à l'écran par un @. Le serpent est représenté par des s avec un S à sa tête. L'argent est $, et une sortie est #. Votre score est affiché dans le coin supérieur gauche.

Vous pouvez vous déplacer en utilisant les mêmes conventions que vi(1), les touches h, j, k et l fonctionnent, tout comme les touches fléchées.
Ceci vous permet de quitter le jeu à tout moment.
Warp spatial pour sortir des situations difficiles, à un prix.

Pour gagner de l'argent, déplacez-vous sur la même case que l'argent. Un nouveau $ apparaîtra lorsque vous gagnerez le courant. Plus vous devenez riche, plus le serpent a faim. Pour quitter le jeu, déplacez-vous vers la sortie (#).

Un enregistrement est conservé du meilleur score personnel de chaque joueur. Les scores ne sont comptabilisés que si vous quittez par la sortie, se faire manger par le serpent ne vaut rien.

Comme au flipper, faire correspondre le dernier chiffre de votre score au numéro qui apparaît après le jeu vaut un bonus.

FICHIERS

base de données des meilleurs scores personnels

BOGUES

Lorsque vous jouez sur un petit écran, il est difficile de savoir quand vous touchez le bord de l'écran.

La fonction de notation prend en compte la taille de l'écran. Une fonction parfaite pour le faire équitablement n'a pas encore été conçue.
