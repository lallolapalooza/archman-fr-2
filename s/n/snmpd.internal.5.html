NOM

snmpd.internal - configuration interne de l'agent Net-SNMP

DESCRIPTION

La page de manuel snmpd.conf(5) définit la syntaxe et le comportement des directives de configuration principales qui peuvent être utilisées pour contrôler le fonctionnement de l'agent Net-SNMP et les informations de gestion qu'il fournit.

Cependant, plusieurs autres directives de configuration (dont beaucoup, mais pas toutes, commencent par un trait de soulignement) sont reconnues par l'agent. Celles-ci sont généralement utilisées pour conserver la configuration lors des redémarrages de l'agent et ne sont pas destinées à un accès direct par l'utilisateur. Cette page de manuel liste ces directives, en indiquant brièvement où elles sont utilisées. Pour plus de détails, consultez les fichiers sources pertinents. Si vous ne parvenez pas à suivre cette source, vous ne devriez probablement pas toucher à ces directives !

COMPORTEMENT DE LAGENT

quit

CONTROLE DACCES

Configuration VACM

vacmView / vacmGroup / vacmAccess
Ces directives sont utilisées pour conserver les paramètres de contrôle d'accès configurés dynamiquement.

INFORMATIONS SYSTEME

Groupe Système

setSerialNo
Cette directive est utilisée pour implémenter l'objet de verrouillage consultatif snmpSetSerialNo.
psyslocation / psyscontact / psysname
Ces directives sont utilisées pour conserver les paramètres système configurés dynamiquement. Ils seront remplacés par les directives sysLocation, sysContact et sysName correspondantes.

SURVEILLANCE ACTIVE

Gestion des notifications

pauthtrapenable
Cette directive est utilisée pour conserver le réglage configuré dynamiquement de savoir si l'agent doit générer des pièges d'authentification échouée. Il sera remplacé par la directive authtrapenable correspondante.
snmpNotify*Table
targetAddr / targetParams
Ces directives sont utilisées pour conserver les paramètres de destination des notifications configurés dynamiquement.

MIB Événement DisMan

_mteE*Table, _mteOTable, _mteT*Table
Ces directives sont utilisées pour conserver les paramètres d'événements, d'objets et de déclencheurs de surveillance configurés dynamiquement.
mteObjectsTable / mteTriggerTable
Ces directives sont pour la compatibilité avec l'implémentation précédente de disman/event-mib.

MIB Planification DisMan

_schedTable
Cette directive est utilisée pour conserver les événements planifiés configurés dynamiquement.

EXTENSION DES FONCTIONNALITES DE LAGENT

Commandes d'extension arbitraires

extend-sh
exec2 / sh2 / execFix2
Ces directives ont été définies par analogie avec les directives équivalentes de l'implémentation précédente ucd-snmp/extensible. Elles sont dépréciées et ne devraient pas être utilisées.

FICHIERS

/etc/snmp/snmpd.conf

VOIR AUSSI
