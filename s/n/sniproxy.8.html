NOM

SNIProxy - proxy TLS et HTTP transparent basé sur les sessions

SYNTAXE

sniproxy [ -c config ] [ -f ] [ -n limite-descripteurs-fichier ] [ -V ]

DESCRIPTION

Proxy les connexions HTTP et TLS entrantes en fonction du nom d'hôte contenu dans la requête initiale de la session TCP. Ceci permet l'hébergement virtuel basé sur le nom pour HTTPS afin de séparer les serveurs backend sans installer la clé privée sur la machine proxy.

OPTIONS

-c config
Spécifie le fichier de configuration à utiliser. Le défaut est /etc/sniproxy.conf.
-f
Ne pas devenir un démon, et s'exécuter au premier plan.
-n limite-descripteurs-fichier
Spécifie la limite de ressource maximale de descripteurs de fichier. SNIProxy tentera de définir la limite maximale de descripteurs de fichier à la valeur spécifiée.
-V
Affiche la version de SNIProxy et quitte.
