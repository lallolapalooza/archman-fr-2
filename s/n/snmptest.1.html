Paquet: net-snmp

SNMPTEST(1) Net-SNMP SNMPTEST(1)

NOM

snmptest - communique avec une entité réseau en utilisant des requêtes SNMP

SYNTAXE

snmptest [OPTIONS COMMUNES] AGENT

DESCRIPTION

snmptest est une application SNMP flexible qui peut surveiller et gérer des informations sur une entité réseau.

Après avoir lancé le programme, un interpréteur en ligne de commande accepte les commandes. Cet interpréteur permet à l'utilisateur d'envoyer différents types de requêtes SNMP aux agents cibles.

AGENT identifie un agent SNMP cible, qui est instrumenté pour surveiller les objets donnés. Dans sa forme la plus simple, la spécification AGENT consistera en un nom d'hôte ou une adresse IPv4. Dans ce cas, la commande tentera de communiquer avec l'agent, en utilisant UDP/IPv4 sur le port 161 de l'hôte cible donné. Voir snmpcmd(1) pour une liste complète des formats possibles pour AGENT.

Une fois snmptest lancé, l'interpréteur en ligne de commande affichera l'invite :

Variable:

À ce stade, vous pouvez entrer un ou plusieurs noms de variables, un par ligne. Une ligne vide termine la saisie des paramètres et envoie la requête (variables entrées) dans un seul paquet, à l'entité distante. Chaque nom de variable est donné dans le format spécifié dans variables(5). Par exemple :

snmptest -c public -v 1 zeus
Variable: system.sysDescr.0
Variable:

renverra des informations sur les paquets de requête et de réponse, ainsi que les informations :

requestid 0x5992478A errstat 0x0 errindex 0x0
system.sysDescr.0 = STRING: "Unix 4.3BSD"

La valeur errstatus indique le code d'état d'erreur pour l'appel. Les valeurs possibles pour errstat se trouvent dans le fichier d'en-tête snmp.h. La valeur errindex identifie la variable qui présente l'erreur donnée. Les valeurs d'index sont attribuées à toutes les variables entrées à l'invite "Variable". La première valeur reçoit un index de 1.

Au démarrage, le programme envoie par défaut un paquet de requête GET. Le type de requête peut être modifié en tapant l'une des commandes suivantes à l'invite "Variable:" :

$G - envoyer une requête GET
$N - envoyer une requête GETNEXT
$S - envoyer une requête SET
$B - envoyer une requête GETBULK
     Note : GETBULK n'est pas disponible en SNMPv1
$I - envoyer une requête Inform
$T - envoyer une requête Trap SNMPv2

D'autres valeurs peuvent être entrées à l'invite "Variable:" :

$D - basculer le déchargement de chaque paquet envoyé et reçu
$QP - basculer une forme de sortie plus rapide et moins verbeuse
$Q - Quitter le programme

Types de requêtes :

Requête GET :

En mode "Requête GET" ($G ou par défaut), l'utilisateur peut entrer un OID à l'invite "Variable:". L'utilisateur peut entrer plusieurs OID, un par invite. L'utilisateur entre une ligne vide pour envoyer la requête GET.

Requête GETNEXT :

Le mode "Requête GETNEXT" ($N) est similaire au mode "Requête GET", décrit ci-dessus.

Requête SET :

En mode "Requête SET" ($S), plus d'informations sont demandées par l'invite pour chaque variable. L'invite :

Type [i|u|s|x|d|n|o|t|a]:
demande le type de la variable à entrer. Selon le type de valeur que vous souhaitez définir, vous pouvez taper l'un des éléments suivants : 
i - entier
u - entier non signé
s - chaîne d'octets en ASCII
x - chaîne d'octets en octets hexadécimaux, séparés par des espaces
d - chaîne d'octets en octets décimaux, séparés par des espaces
a - adresse IP en notation IP pointée
o - identifiant d'objet
n - nul
t - timeticks
À ce stade, une valeur sera demandée :

Valeur :

S'il s'agit d'une valeur entière, tapez simplement l'entier (en décimal). S'il s'agit d'une chaîne décimale, tapez des nombres décimaux séparés par des espaces, un par octet de la chaîne. Tapez à nouveau une ligne vide à l'invite pour le nom de la variable afin d'envoyer le paquet.

Requête GETBULK :

Le mode "Requête GETBULK" ($B) est similaire au mode "Requête SET". Cependant, GETBULK n'est pas disponible en SNMPv1.

Requête Inform :

Le mode "Requête Inform" ($I) est similaire au mode "Requête SET". Cependant, ce type de requête n'est pas disponible en SNMPv1. De plus, l'_agent_ spécifié dans la commande snmptest doit correspondre à l'agent snmptrapd cible.

Requête Trap SNMPv2 :

Le mode "Requête Trap SNMPv2" ($T) est similaire au mode "Requête SET". Cependant, ce type de requête n'est pas disponible en SNMPv1. De plus, l'_agent_ spécifié dans la commande snmptest doit correspondre à l'agent snmptrapd cible.

OPTIONS

snmptest prend les options communes décrites dans la page de manuel snmpcmd(1).

EXEMPLES

L'exemple suivant montre l'envoi d'une requête GET pour deux OID :

% snmptest -v 2c -c public testhost:9999

Variable: system.sysDescr.0
Variable: system.sysContact.0
Variable:
Réponse GET reçue de 128.2.56.220
requestid 0x7D9FCD63 errstat 0x0 errindex 0x0
SNMPv2-MIB::sysDescr.0 = STRING: SunOS testhost 5.9 Generic_112233-02 sun4u
SNMPv2-MIB::sysContact.0 = STRING: x1111

L'exemple suivant montre l'envoi d'une requête GETNEXT :

Variable: SNMPv2-MIB::sysORUpTime
Variable:
Réponse GET reçue de 128.2.56.220
requestid 0x7D9FCD64 errstat 0x0 errindex 0x0
SNMPv2-MIB::sysORUpTime.1 = Timeticks: (6) 0:00:00.06
Variable:

L'exemple suivant montre l'envoi d'une requête SET :

Variable: $S
Le type de requête est Requête SET
Variable: system.sysLocation.0
Type [i|u|s|x|d|n|o|t|a]: s
Valeur: building 17
Variable:
Réponse GET reçue de 128.2.56.220
requestid 0x7D9FCD65 errstat 0x0 errindex 0x0
SNMPv2-MIB::sysLocation.0 = STRING: building A
Variable:

L'exemple suivant montre l'envoi d'une requête GETBULK :

Variable: $B
Le type de requête est Requête BULK
Entrez une ligne vide pour terminer la liste des non-répétiteurs
et pour commencer les variables répétitives
Variable:
Maintenant, saisissez les variables répétitives
Variable: system.sysContact.0
Variable: system.sysLocation.0
Variable:
Quel compte de répétition ? 2
Réponse GET reçue de 128.2.56.220
requestid 0x2EA7942A errstat 0x0 errindex 0x0
SNMPv2-MIB::sysName.0 = STRING: testhost
SNMPv2-MIB::sysORLastChange.0 = Timeticks: (58) 0:00:00.58
SNMPv2-MIB::sysLocation.0 = STRING: bldg A
SNMPv2-MIB::sysORID.1 = OID: IF-MIB::ifMIB
Variable:

L'exemple suivant montre l'envoi d'une requête Inform :

snmptest -v 2c -c public snmptrapd_host
Variable: $I
Le type de requête est Requête Inform
(Envoyez-vous au bon port ?)
Variable: system.sysContact.0
Type [i|u|sIx|d|n|o|t|a]: s
Valeur: x12345
Variable:
Inform Accusé de réception
Variable:

Le snmptrapd_host affichera :

snmptrapd_host [<adresse ip>]: Trap SNMPv2-MIB::sysContact.0 = STRING: x12345

L'exemple suivant montre l'envoi d'une requête Trap SNMPv2 :

snmptest -v 2c -c public snmptrapd_host
Variable: $T
Le type de requête est Requête Trap SNMPv2
(Envoyez-vous au bon port ?)
Variable: system.sysLocation.0
Type [i|u|s|x|d|n|o|t|a]: s
Valeur: building a
Variable:

Le snmptrapd_host affichera :

snmptrapd_host [<adresse ip>]: Trap SNMPv2-MIB::sys.0 = STRING:
building a
