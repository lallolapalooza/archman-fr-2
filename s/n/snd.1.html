SND(1) Manuel des commandes générales SND(1)

NOM

snd - un éditeur de son

SYNTAXE

snd [-l FICHIER] [-p RÉPERTOIRE] [-v] [-h] [-notebook] [-separate] [-noglob] [-noinit] [--help] [--version]

DESCRIPTION

Snd est un éditeur de son.

Snd est un logiciel libre. Il est disponible sur ftp://ccrma-ftp.stanford.edu/pub/Lisp/.

UTILISATION

snd oboe.snd charge oboe.snd dans Snd.

OPTIONS

-l fichier
Charge le code du langage d'extension dans le fichier.
-p répertoire
Préchage des fichiers son trouvés dans le répertoire répertoire.
-noinit
Ne charge aucun fichier d'initialisation (~/.snd et al).
--help
Donne de l'aide.
--version
Décrit le Snd actuel.

FICHIERS

~/.snd un fichier qui peut contenir du code de personnalisation local.

AUTEURS
