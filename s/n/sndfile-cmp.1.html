NAME

sndfile-cmp — compare deux fichiers audio

SYNOPSIS

sndfile-cmp fichier1 fichier2

DESCRIPTION

sndfile-cmp compare les données audio de deux fichiers son. Pour que deux fichiers soient considérés comme identiques, leur nombre de canaux, leur fréquence d'échantillonnage, la longueur de leurs données audio et les données audio elles-mêmes doivent correspondre. Les autres différences telles que les métadonnées textuelles comme le titre de la chanson, l'artiste, etc., ainsi que leur présence ou absence, sont ignorées.

EXIT STATUS

0
Les données audio sont identiques.
1
Les données audio diffèrent.
