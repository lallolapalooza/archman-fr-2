SNIFFIT(5) Manuel des formats de fichiers SNIFFIT(5)

NOM

sniffit - fichier de configuration pour sniffit (nom arbitraire)

DESCRIPTION

Cette page décrit le format du fichier de configuration pour sniffit (voir sniffit(8)). Ce fichier vous permet de spécifier en grand détail quels paquets doivent être traités par sniffit. Ce fichier contrôle également (ou contrôlera) certaines fonctions de journalisation continue (option '-L').

Un fichier de configuration sniffit pourrait ressembler à ceci (Assurez-vous qu'il se termine par une ligne VIDE) :

# Fichier de configuration d'exemple Sniffit -- Brecht Claerhout
logfile /var/log/sniffit.today.log
# Sélectionner d'abord tous les paquets !
select both mhosts 1
select both mhosts 2
# Désélectionner maintenant tous les paquets de/vers ces maudits 'surfeurs'
deselect both port 80
deselect both port 8001

Ce fichier indiquera à sniffit de traiter tous les paquets sur le sous-réseau, à l'exception de ceux VENANT/ALLANT des ports 80 et 8001 (nous ne voulons donc pas de journaux de ces connexions WWW massives qui rendent nos journaux illisibles).

FORMAT GLOBAL

Le fichier est composé de lignes, les lignes sont formées de champs, les champs sont séparés par des ESPACES (PAS de TABULATIONS). Les lignes de commentaires Unix (commençant par '#') sont autorisées. Donc, cela nous donne :

<champ1> <champ2> <champ3> <champ4> <champ5>

FORMAT DES CHAMPS

<champ1>
select - Sniffit recherchera les paquets qui correspondent à la description suivante (autres champs)
deselect - Sniffit ignorera les paquets qui correspondent à la description
logfile - change le nom du fichier journal en <champ2> au lieu du 'sniffit.log' par défaut.
<champ2>
from - Les paquets VENANT de l'hôte correspondant à la description suivante sont considérés.
to - similaire, les paquets ALLANT de....
both - similaire, les paquets VENANT ou ALLANT de....
un nom de fichier - comme argument de 'logfile' dans <champ1>
<champ3>
host - Le critère de (dé)sélection concerne un nom d'hôte.
port - similaire, ... un numéro de port
mhosts - Le critère de (dé)sélection concerne plusieurs hôtes, comme avec les jokers en 0.3.0, mais sans le 'x'
<champ4>
Soit un nom d'hôte, un numéro de port, un nom de service ou une notation partielle nombre-point indiquant plusieurs hôtes selon <champ3> (les noms de services comme 'ftp' sont résolus comme les services disponibles sur l'hôte qui exécute Sniffit, et traduits en numéro de port)
<champ5>
Un numéro de port, si <champ3> était 'host' ou 'mhosts' (facultatif, si non rempli, tous les ports seront (dé)sélectionnés)

INTERPRÉTATION DU FICHIER

Le fichier de configuration est interprété SÉQUENTIELLEMENT, alors faites attention, ne mélangez pas les lignes dans un fichier. Exemple :

      select both mhosts 100.100.12.
      deselect both port 80
      select both host 100.100.12.2
Ce fichier vous donnera les paquets :
      a) Envoyés par les hôtes '100.100.12.*'
      b) SAUF les paquets WWW
      c) MAIS affichant les paquets WWW concernant
         100.100.12.2
      select both mhosts 100.100.12.
      select both host 100.100.12.2
      deselect both port 80
Donnera les paquets (résultat probablement indésirable) :
      a) Envoyés par les hôtes '100.100.12.*'
      b) Envoyés depuis/vers 100.100.12.2 (ligne inutile)
      c) désélectionnant tous les paquets WWW sur le sous-réseau
