SNDFILE-INTERLEAVE(1) Manuel des commandes générales SNDFILE-INTERLEAVE(1)

NOM

sndfile-interleave, sndfile-deinterleave — convertir des fichiers mono en un fichier multicanal et vice versa

SYNTAXE

sndfile-interleave entrée1 entrée2 ... -o sortie

sndfile-deinterleave fichier

DESCRIPTION

sndfile-interleave crée un fichier multicanal en prenant les données audio de deux fichiers mono ou plus comme canaux individuels. Le format du fichier de sortie est déterminé par son extension de nom de fichier. Les paramètres audio du fichier de sortie seront ajustés pour pouvoir accueillir chacune des entrées mono ; par exemple, le taux d'échantillonnage sera le taux d'échantillonnage maximal parmi les entrées. Le fichier de sortie sera écrasé s'il existe déjà.

sndfile-deinterleave crée deux fichiers mono ou plus à partir d'un fichier audio multicanal, contenant les données des canaux individuels. Les noms des fichiers mono résultants sont de la forme “nom_XY.suf” où nom et suf sont le nom de base et le suffixe du fichier d'origine. Si un fichier portant un tel nom existe déjà, il sera écrasé. Outre le nombre de canaux, le format audio des fichiers mono résultants est le même que celui du fichier original.

STATUT DE SORTIE

L'utilitaire sndfile-interleave se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.

EXEMPLES

Fusionner un fichier OGG mono et un fichier FLAC mono en un fichier WAV stéréo :

$ sndfile-interleave gauche.ogg droite.flac -o stereo.wav

Séparer un fichier multicanal en fichiers mono individuels :

$ sndfile-deinterleave multi.wav
Fichier d'entrée : multi
Fichiers de sortie :
    multi_00.wav
    multi_01.wav
    multi_02.wav
    multi_03.wav
