SNDFILE-CONCAT(1) Manuel des commandes générales SNDFILE-CONCAT(1)

NOM

sndfile-concat — concatène des données audio à partir d'un ou plusieurs fichiers audio

SYNTAXE

sndfile-concat fichier_entree1 fichier_entree2 ... fichier_sortie

DESCRIPTION

sndfile-concat génère un nouveau fichier de sortie en concaténant les données audio de deux ou plusieurs fichiers d'entrée. L'encodage du fichier de sortie est l'encodage utilisé dans fichier_entree1. Les données audio des fichiers suivants sont converties vers cet encodage. La seule restriction est que les fichiers doivent avoir le même nombre de canaux. Le fichier de sortie est écrasé s'il existe déjà.

STATUT DE SORTIE

L'utilitaire sndfile-concat se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.
