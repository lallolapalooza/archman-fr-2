SNBK(8) Gestion des instantanés de fichiers SNBK(8)

NOM

snbk - Programme en ligne de commande pour sauvegarder les instantanés de snapper

SYNTAXE

snbk [options-globales] commande [arguments-commande]

snbk {--help}

DESCRIPTION

Snbk est un programme en ligne de commande pour sauvegarder les instantanés de snapper. Il peut transférer et supprimer les instantanés de sauvegarde sur des systèmes de fichiers btrfs locaux et distants.

CONCEPTS

Configurations de sauvegarde

Pour chaque configuration snapper, il peut y avoir plusieurs configurations de sauvegarde. Chaque configuration de sauvegarde définit les sauvegardes des instantanés snapper à un emplacement, local ou distant, voir snapper-backup-configs(5) pour les paramètres possibles.

Statuts des instantanés

Chaque instantané a un statut sur la source et sur la cible. Les valeurs possibles pour la source sont :

(vide)

L'instantané est manquant et est donc considéré comme obsolète sur la cible. Il sera supprimé sur la cible par la prochaine commande de suppression.

read-only

L'instantané est en lecture seule.

read-write

L'instantané est en lecture-écriture et ne peut donc pas être sauvegardé.

Les valeurs possibles pour la cible sont :

(vide)

L'instantané est manquant. Si l'instantané source est en lecture seule, il sera transféré vers la cible par la prochaine commande de transfert.

valid

L'instantané est valide. Cela implique qu'il est en lecture seule.

invalid

L'instantané est invalide. Soit l'UUID reçu est incorrect, soit il est en lecture-écriture. Cela peut se produire si le transfert a été interrompu. La prochaine commande de transfert tentera de transférer à nouveau l'instantané.

OPTIONS GLOBALES

-q, --quiet

Supprimer la sortie normale. Les messages d'erreur seront toujours affichés, cependant.

-v, --verbose

Augmenter la verbosité.

--debug

Activer le débogage.

--utc

Afficher les dates et heures en UTC. Par défaut, l'heure locale est utilisée.

--iso

Afficher les dates et heures au format ISO. Le format ISO est toujours utilisé pour les sorties lisibles par machine.

-t, --table-style style

Spécifie le style de tableau. Le style de tableau est identifié par un nombre entier.

--machine-readable format

Spécifie un format de sortie lisible par machine. Les options possibles sont csv et json.

--csvout

Définit le format de sortie CSV. Pour certaines commandes, la sortie CSV contient plus d'informations que la sortie de tableau par défaut. Voir RFC 4180[1] pour les détails, sauf que les lignes se terminent par un LF, pas par un CR+LF.

--jsonout

Définit le format de sortie JSON. Pour certaines commandes, la sortie JSON contient plus d'informations que la sortie de tableau par défaut.

--separator caractère

Spécifie le caractère séparateur pour le format de sortie CSV.

--no-headers

Supprime les en-têtes pour le format de sortie CSV.

-b, --backup-config nom

Utilise la configuration spécifiée au lieu de toutes les configurations.

--no-dbus

Fonctionne sans connexion DBus.

Utiliser avec prudence.

--target-mode nom

Ne fonctionne que sur les configurations de sauvegarde avec le mode cible spécifié.

--automatic

Ne fonctionne que sur les configurations de sauvegarde qui ont le drapeau automatique défini.

--version

Affiche la version et quitte.

COMMANDES

Snbk fournit un certain nombre de commandes. Chaque commande accepte les options listées dans la section OPTIONS GLOBALES. Ces options doivent être spécifiées avant le nom de la commande. De plus, de nombreuses commandes ont des arguments spécifiques, qui sont listés dans cette section. Ces arguments spécifiques à la commande doivent être spécifiés après le nom de la commande.

help

Affiche un court texte d'aide.

list-configs

Liste les configurations disponibles.

list (ls)

Liste les instantanés.

transfer [nombre]

Transfère tous les instantanés manquants ou l'instantané spécifié vers la cible.

delete (remove|rm) [nombre]

Supprime tous les instantanés obsolètes ou l'instantané spécifié de la cible.

transfer-and-delete

Combine le transfert et la suppression.

RESTITUER

Jusqu'à présent, une restauration doit être effectuée manuellement. Il existe plusieurs méthodes pour effectuer une restauration, par exemple, la sauvegarde peut être montée puis copiée, ou rsync peut être utilisé. Nous fournissons ici un exemple sur la façon d'utiliser btrfs send et receive pour restaurer un instantané sur le système source. En général, l'utilisation de btrfs send et receive est un peu délicate.

Lors de l'utilisation de target-mode local :

# mkdir /.snapshots/42
# cp /backups/root/42/info.xml /.snapshots/42/
# btrfs send /backups/root/42/snapshot | btrfs receive /.snapshots/42

Lors de l'utilisation de target-mode ssh-push :

# mkdir /.snapshots/42
# scp backups.example.com:/backups/eberich/root/42/info.xml /.snapshots/42
# ssh backups.example.com btrfs send /backups/eberich/root/42/snapshot | btrfs receive /.snapshots/42

Si le système a été réinstallé, il n'est malheureusement généralement pas possible d'utiliser simplement l'instantané restauré comme instantané par défaut, car certains fichiers, par exemple /etc/fstab, nécessitent probablement des modifications. De plus, malheureusement, pour des sous-volumes autres que root, un rollback n'est pas pris en charge.

S'il y a des instantanés sur la source pour accélérer l'opération, vous pouvez également utiliser l'option -p pour btrfs send.

NOTES

Le contenu des instantanés transférés ne doit pas être modifié sur le système source. Normalement, cela est assuré puisque les instantanés sont en lecture seule. Mais il est possible de changer les instantanés en lecture-écriture. Cela peut causer des erreurs lors des transferts futurs.

PERMISSIONS

Comme le mode cible ssh-push nécessite des permissions root sur la cible, il est recommandé d'utiliser une machine ou un conteneur dédié comme cible.

FICHIERS

/etc/snapper/backup-configs

Répertoire contenant les fichiers de configuration.

STATUT DE SORTIE

Normalement, le statut de sortie est 0. Si une erreur s'est produite, le statut de sortie est 1.
