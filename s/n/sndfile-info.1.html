SNDFILE-INFO(1) Manuel des commandes générales SNDFILE-INFO(1)

NOM

sndfile-info — affiche des informations sur les fichiers audio

SYNTAXE

sndfile-info [--broadcast] [--cart] [--channel-map] [--instrument] fichier ...

DESCRIPTION

sndfile-info affiche des informations de base sur les fichiers audio tels que le format, le nombre de canaux, le taux d'échantillonnage et la durée. Les options suivantes sont reconnues :

--broadcast
Affiche les informations de diffusion (BWF).
--cart
Affiche le bloc cart d'un fichier WAV (ou similaire).
--channel-map
Affiche la carte des canaux.
--instrument
Affiche les informations sur l'instrument : note de base, gain, vélocité, clé et points de boucle.
