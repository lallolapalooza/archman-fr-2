Paquet: net-snmp

SNMPNETSTAT(1) Net-SNMP SNMPNETSTAT(1)

NOM

snmpnetstat - afficher l'état et la configuration réseau d'une entité réseau via SNMP

SYNTAXE

snmpnetstat [OPTIONS COMMUNES] [-Ca] [-Cn] [-Cv] [-Cf famille_adresse] AGENT
snmpnetstat [OPTIONS COMMUNES] [-Cr] [-Cn] [-Cv] [-Cf famille_adresse] AGENT
snmpnetstat [OPTIONS COMMUNES] [-Ci] [-C o | b | d] [-Cn] [-Cv] [-CI interface] [-Cw intervalle] AGENT
snmpnetstat [OPTIONS COMMUNES] [-Cs[s]] [-Cp protocole] AGENT

DESCRIPTION

La commande snmpnetstat affiche symboliquement les valeurs de diverses informations relatives au réseau récupérées à partir d'un système distant à l'aide du protocole SNMP. Il existe plusieurs formats de sortie, en fonction des options pour les informations présentées. La première forme de la commande affiche une liste des sockets actifs. La seconde forme présente les valeurs d'autres informations relatives au réseau selon l'option sélectionnée. En utilisant la troisième forme, avec un intervalle spécifié, snmpnetstat affichera en continu les informations relatives au trafic de paquets sur les interfaces réseau configurées. La quatrième forme affiche les statistiques relatives au protocole nommé.

snmpnetstat émettra des requêtes GETBULK pour interroger les informations si au moins la version de protocole v2 est utilisée.

AGENT identifie un agent SNMP cible, instrumenté pour surveiller les objets donnés. Dans sa forme la plus simple, la spécification AGENT consistera en un nom d'hôte ou une adresse IPv4. Dans cette situation, la commande tentera de communiquer avec l'agent, en utilisant UDP/IPv4 vers le port 161 de l'hôte cible donné. Voir snmpcmd(1) pour une liste complète des formats possibles pour AGENT.

OPTIONS

Les options ont la signification suivante :

OPTIONS COMMUNES
Veuillez consulter snmpcmd(1) pour une liste des valeurs possibles pour les options communes ainsi que leurs descriptions.

-CL utilise les anciens éléments MIB SNMP, et non les tables modernes indépendantes de la version IP. snmpnetstat se rabattra automatiquement sur les tables héritées si les tables modernes ne sont pas disponibles.

-Ca Avec l'affichage par défaut, affiche l'état de tous les sockets ; normalement, les sockets utilisés par les processus serveur ne sont pas affichés.

-Cf famille_adresse Affiche uniquement les entrées pour la famille d'adresses sélectionnée (inet, inet6)

-Ci Affiche l'état de toutes les interfaces réseau. L'affichage de l'interface fournit un tableau de statistiques cumulatives relatives aux paquets transférés, aux erreurs et aux collisions. Les adresses réseau de l'interface et l'unité de transmission maximale (``mtu'') sont également affichées.

-Cd Ajoute les paquets abandonnés à l'affichage de l'interface.

-Cb Affiche un état d'interface étendu, donnant des octets en plus des paquets.

-Co Affiche un état d'interface abrégé, donnant des octets à la place des paquets. Ceci est utile lors de la requête d'interfaces virtuelles (telles que les circuits Frame-Relay) sur un routeur.

-CI interface Affiche uniquement les informations sur cette interface ; utilisé avec un intervalle tel que décrit ci-dessous.

-Cn Affiche les adresses réseau sous forme numérique (normalement, snmpnetstat interprète les adresses et tente de les afficher symboliquement). Cette option peut être utilisée avec l'un des formats d'affichage.

-Cv Permet aux noms longs d'hôtes ou de services de casser la sortie des colonnes. Cette option peut être utilisée avec n'importe lequel des formats d'affichage.

-Cp protocole Affiche les statistiques relatives à protocole, qui est soit un nom bien connu pour un protocole, soit un alias pour celui-ci. Certains noms de protocoles et alias sont listés dans le fichier /etc/protocols. Une réponse nulle signifie généralement qu'il n'y a pas de nombres intéressants à rapporter. Le programme se plaindra si protocole est inconnu ou s'il n'y a pas de routine de statistiques pour celui-ci.

-Cs Affiche les statistiques par protocole. Si cela est dupliqué (-Css), les entrées de statistiques qui sont nulles seront supprimées.

-Cr Affiche les tables de routage.

-CR répéteurs Pour les requêtes GETBULK, répéteurs spécifie la valeur max-repeaters à utiliser.

Lorsque snmpnetstat est appelé avec un argument d'intervalle, il affiche un décompte continu des statistiques relatives aux interfaces réseau. intervalle est le nombre de secondes entre la notification des statistiques.

L'affichage des sockets actifs (par défaut)

L'affichage par défaut, pour les sockets actifs, montre les adresses locales et distantes, le protocole et l'état interne du protocole. Les formats d'adresse sont de la forme ``hôte.port'' ou ``réseau.port'' si l'adresse d'un socket spécifie un réseau mais pas une adresse d'hôte spécifique. Lorsque cela est connu, les adresses d'hôte et de réseau sont affichées symboliquement selon les bases de données /etc/hosts et /etc/networks, respectivement. Si un nom symbolique pour une adresse est inconnu, ou si l'option -Cn est spécifiée, l'adresse est imprimée numériquement, selon la famille d'adresses. Pour plus d'informations sur le ``format point'' d'Internet, référez-vous à inet(3N). Les adresses et ports non spécifiés, ou ``wildcard'', apparaissent comme ``*''.

L'affichage de l'interface

L'affichage de l'interface fournit un tableau de statistiques cumulatives relatives aux paquets transférés, aux erreurs et aux collisions. Les adresses réseau de l'interface et l'unité de transmission maximale (``mtu'') sont également affichées.

L'affichage de la table de routage

L'affichage de la table de routage indique les routes disponibles et leur état. Chaque route se compose d'une destination d'hôte ou de réseau et d'une passerelle à utiliser pour transférer les paquets. Le champ des drapeaux indique l'état de la route (``U'' si ``up''), si la route mène à une passerelle (``G''), si la route a été créée dynamiquement par un redirect (``D''), et si la route a été modifiée par un redirect (``M''). Les routes directes sont créées pour chaque interface attachée à l'hôte local ; le champ passerelle pour de telles entrées montre l'adresse de l'interface sortante. L'entrée d'interface indique l'interface réseau utilisée pour la route.

L'affichage de l'interface avec un intervalle

Lorsque snmpnetstat est appelé avec un argument intervalle, il affiche un décompte continu des statistiques relatives aux interfaces réseau. Cet affichage se compose d'une colonne pour l'interface primaire et d'une colonne résumant les informations pour toutes les interfaces. L'interface primaire peut être remplacée par une autre interface avec l'option -CI. La première ligne de chaque écran d'information contient un résumé depuis le dernier redémarrage du système. Les lignes de sortie ultérieures montrent les valeurs accumulées sur l'intervalle précédent.

L'affichage des sockets actifs pour un unique protocole

Lorsqu'un protocole est spécifié avec l'option -Cp, les informations affichées sont similaires à celles de l'affichage par défaut pour les sockets actifs, sauf que l'affichage est limité au protocole donné.

EXEMPLES

Exemple d'utilisation de snmpnetstat pour afficher les sockets actifs (par défaut) :

% snmpnetstat -v 2c -c public -Ca testhost

Active Internet (tcp) Connections (including servers)
Proto Local Address                Foreign Address                 (state)
tcp   *.echo                        *.*                            LISTEN
tcp   *.discard                     *.*                            LISTEN
tcp   *.daytime                     *.*                            LISTEN
tcp   *.chargen                     *.*                            LISTEN
tcp   *.ftp                         *.*                            LISTEN
tcp   *.telnet                      *.*                            LISTEN
tcp   *.smtp                        *.*                            LISTEN
...
Active Internet (udp) Connections
Proto Local Address
udp    *.echo
udp    *.discard
udp    *.daytime
udp    *.chargen
udp    *.time
...

% snmpnetstat -v 2c -c public -Ci testhost

Name     Mtu Network    Address          Ipkts   Ierrs    Opkts Oerrs Queue
eri0    1500 10.6.9/24  testhost     170548881  245601   687976     0    0
lo0     8232 127        localhost      7530982       0  7530982     0    0

Exemple d'utilisation de snmpnetstat pour afficher les statistiques sur un protocole spécifique :

% snmpnetstat -v 2c -c public -Cp tcp testhost
Active Internet (tcp) Connections
Proto Local Address                Foreign Address                 (state)
tcp   *.echo                        *.*                            LISTEN
tcp   *.discard                     *.*                            LISTEN
tcp   *.daytime                     *.*                            LISTEN
tcp   *.chargen                     *.*
