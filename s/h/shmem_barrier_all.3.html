shmem_barrier_all(3)

SHMEM_BARRIER_ALL(3) Open MPI SHMEM_BARRIER_ALL(3)

shmem_barrier_all - Interrompt l'exécution du PE appelant jusqu'à ce que tous les autres PEs aient émis un appel à cette instruction shmem_barrier_all() particulière.

SYNTAXE

C ou C++:

#include <mpp/shmem.h>
void shmem_barrier_all(void)

Fortran:

include 'mpp/shmem.h'
CALL SHMEM_BARRIER_ALL

DESCRIPTION

La routine shmem_barrier_all ne retourne pas tant que tous les autres PEs n'ont pas atteint ce point du chemin d'exécution.

Avant de se synchroniser avec les autres PEs, shmem_barrier_all assure l'achèvement de tous les magasins mémoire locaux précédemment émis et des mises à jour mémoire distantes émises via les fonctions SHMEM telles que shmem_put32(3).

EXEMPLES

setup_data()
{
  if (shmem_my_pe() == 0) {
    setup();
  }
  /* Tous les PEs attendent que le PE 0 termine setup(). */
  shmem_barrier_all();
}
