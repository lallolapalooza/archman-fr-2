shmem_malloc(3)

SHMEM_MALLOC(3) Open MPI SHMEM_MALLOC(3)

shmem_malloc(3), shmem_free(3), shmem_align(3), shmem_realloc(3) shmalloc(3), shfree(3), shmemalign(3), shrealloc(3) - Fonctions de gestion de la mémoire de tas symétrique.

SYNOPSIS

En C ou C++ :

#include <mpp/shmem.h>
void *shmem_malloc(size_t size)
void *shmalloc(size_t size)
void shmem_free(void *ptr)
void shfree(void *ptr)
void *shmem_realloc(void *ptr, size_t size)
void *shrealloc(void *ptr, size_t size)
void *shmem_align(size_t alignment, size_t size)
void *shmemalign(size_t alignment, size_t size)
extern long malloc_error

DESCRIPTION

La fonction shmem_malloc renvoie un pointeur vers un bloc d'au moins size octets, correctement aligné pour toute utilisation. Cet espace est alloué à partir du tas symétrique (par opposition à malloc(3), qui alloue à partir du tas privé).

La fonction shmem_align alloue un bloc dans le tas symétrique qui a un alignement d'octets spécifié par l'argument alignment.

La fonction shmem_free libère le bloc auquel pointe ptr, le rendant disponible pour de futures allocations. Si ptr est un pointeur nul, aucune action n'est effectuée ; sinon, si l'argument ne correspond pas à un pointeur retourné précédemment par une fonction du tas symétrique, ou si l'espace a déjà été libéré, malloc_error est défini pour indiquer l'erreur, et shfree se termine.

La fonction shmem_realloc change la taille du bloc auquel pointe ptr, pour la taille (en octets) spécifiée par size.

Le contenu du bloc est inchangé jusqu'à la plus petite des deux tailles, nouvelle et ancienne. Si la nouvelle taille est plus grande, la valeur de la portion nouvellement allouée du bloc est indéterminée. Si ptr est un pointeur nul, la fonction shrealloc se comporte comme la fonction shmalloc pour la taille spécifiée. Si size est 0 et ptr n'est pas un pointeur nul, le bloc auquel il pointe est libéré. Sinon, si ptr ne correspond pas à un pointeur retourné précédemment par une fonction du tas symétrique, ou si l'espace a déjà été libéré, la variable malloc_error est définie pour indiquer l'erreur, et shrealloc renvoie un pointeur nul. Si l'espace ne peut pas être alloué, le bloc auquel pointe ptr reste inchangé.

Les fonctions shmem_malloc, shmem_free et shmem_realloc sont fournies afin que plusieurs PEs (Processing Elements) dans une application puissent allouer des blocs de mémoire symétriques et accessibles à distance. Ces blocs de mémoire peuvent ensuite être utilisés avec les routines de communication (shmem). Chacune de ces fonctions appelle la fonction shmem_barrier_all(3) avant de retourner ; cela garantit que tous les PEs participent à l'allocation de mémoire, et que la mémoire sur les autres PEs peut être utilisée dès le retour du PE local.

L'utilisateur est responsable de l'appel de ces fonctions avec des arguments identiques sur tous les PEs ; si des arguments de taille différents sont utilisés, les appels ultérieurs pourraient ne pas renvoyer la même adresse de tas symétrique sur tous les PEs.

NOTES

La taille totale du tas symétrique est déterminée au démarrage du job. On peut ajuster la taille du tas en utilisant la variable d'environnement SHMEM_SYMMETRIC_HEAP_SIZE. Voir la page de manuel intro_shmem(3) pour plus de détails. Les fonctions shmem_malloc, shmem_free et shmem_realloc diffèrent des fonctions d'allocation de tas privé en ce sens que tous les PEs d'une application doivent les appeler (une barrière est utilisée pour garantir cela).

VALEURS DE RETOUR

La fonction shmem_malloc renvoie un pointeur vers l'espace alloué (qui devrait être identique sur tous les PEs) ; sinon, elle renvoie un pointeur nul (avec malloc_error défini). La fonction shmem_free ne renvoie aucune valeur. La fonction shmem_realloc renvoie un pointeur vers l'espace alloué (qui pourrait avoir été déplacé) ; sinon, elle renvoie un pointeur nul (avec malloc_error défini).
