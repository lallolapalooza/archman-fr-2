SHOWQ(8) Manuel du gestionnaire système SHOWQ(8)

NOM

showq - lister la file d'attente de courrier Postfix

SYNOPSIS

showq [options générales de démon Postfix]

DESCRIPTION


Le démon showq(8) rapporte l'état de la file d'attente de courrier Postfix. La sortie est destinée à être formatée par la commande postqueue(1), car elle émule la commande `mailq' de Sendmail.

Le démon showq(8) peut également être exécuté en mode autonome par le superutilisateur. Ce mode de fonctionnement est utilisé pour émuler la commande `mailq' lorsque le système de messagerie Postfix est arrêté.

SÉCURITÉ

Le démon showq(8) peut s'exécuter dans un chroot jail avec des privilèges bas fixes, et ne prend aucune entrée du client. Son port de service est accessible aux utilisateurs locaux non fiables, de sorte que le service peut être vulnérable aux attaques par déni de service.

NORMES

Aucune. Le démon showq(8) n'interagit pas avec le monde extérieur.

DIAGNOSTICS


Les problèmes et les transactions sont enregistrés dans syslogd(8) ou postlogd(8).

PARAMÈTRES DE CONFIGURATION

Les changements apportés à main.cf sont capturés automatiquement car les processus showq(8) s'exécutent pendant une durée limitée. Utilisez la commande "postfix reload" pour accélérer un changement.

Le texte ci-dessous ne fournit qu'un résumé des paramètres. Voir postconf(5) pour plus de détails, y compris des exemples.

config_directory (voir la sortie de 'postconf -d')
L'emplacement par défaut des fichiers de configuration main.cf et master.cf de Postfix.
daemon_timeout (18000s)
Le temps qu'un processus démon Postfix peut prendre pour traiter une requête avant d'être terminé par une minuterie de surveillance intégrée.
duplicate_filter_limit (1000)
Le nombre maximal d'adresses mémorisées par le filtre de doublons d'adresses pour l'expansion d'alias aliases(5) ou virtual(5), ou pour les affichages de file d'attente showq(8).
empty_address_recipient (MAILER-DAEMON)
Le destinataire du courrier adressé à l'adresse nulle.
ipc_timeout (3600s)
La limite de temps pour envoyer ou recevoir des informations sur un canal de communication interne.
max_idle (100s)
La durée maximale pendant laquelle un processus démon Postfix inactif attend une connexion entrante avant de se terminer volontairement.
max_use (100)
Le nombre maximal de connexions entrantes que desservira un processus démon Postfix avant de se terminer volontairement.
process_id (lecture seule)
L'ID du processus d'une commande ou d'un processus démon Postfix.
process_name (lecture seule)
Le nom du processus d'une commande ou d'un processus démon Postfix.
queue_directory (voir la sortie de 'postconf -d')
L'emplacement du répertoire de files d'attente principal de Postfix.
syslog_facility (mail)
La facilité syslog de la journalisation Postfix.
syslog_name (voir la sortie de 'postconf -d')
Un préfixe qui est ajouté au nom du processus dans les enregistrements syslog, de sorte que, par exemple, "smtpd" devient "prefix/smtpd".

Disponible dans Postfix version 2.9 et ultérieures :

enable_long_queue_ids (non)
Activer les IDs de file d'attente longs et non répétitifs (noms de fichiers de file d'attente).

Disponible dans Postfix 3.3 et ultérieures :

service_name (lecture seule)
Le nom du service master.cf d'un processus démon Postfix.
