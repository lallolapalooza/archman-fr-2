NAME

shapeclustering - entraînement de regroupement de formes pour Tesseract

SYNOPSIS

shapeclustering -D répertoire_sortie -U unicharset -O mfunicharset -F propriétés_police -X hauteurs_x FICHIER...

DESCRIPTION

shapeclustering(1) prend des fichiers .tr de caractéristiques extraites (générés par tesseract(1) exécuté dans un mode spécial à partir de fichiers box) et produit un fichier shapetable et un unicharset amélioré. Ce programme est encore expérimental et n'est pas requis (encore) pour l'entraînement de Tesseract.

OPTIONS

-U FICHIER

L'unicharset généré par unicharset_extractor(1).

-D répertoire

Répertoire où écrire les fichiers de sortie.

-F fichier_propriétés_police

(Entrée) Fichier de propriétés de police, où chaque ligne est de la forme suivante, chaque champ autre que le nom de la police étant 0 ou 1 : 
'nom_police' 'italique' 'gras' 'police_à_pas_fixe' 'avec_empattement' 'fraktur'

-X fichier_hauteurs_x

(Entrée) Fichier des hauteurs x, chaque ligne est de la forme suivante, où la hauteur x est calculée comme la hauteur x en pixels d'un caractère dessiné à 32pt sur 300 dpi. [ C'est-à-dire, si hauteur de base x + ascendants + descendants = 133, quelle est la hauteur x ? ] 
'nom_police' 'hauteur_x'

-O FICHIER

L'unicharset de sortie qui sera donné à combine_tessdata(1).
