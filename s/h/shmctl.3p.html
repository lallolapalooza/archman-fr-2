SHMCTL(3P) Manuel du programmeur POSIX SHMCTL(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

shmctl — opérations de contrôle de mémoire partagée XSI

SYNTAXE

#include <sys/shm.h>
int shmctl(int shmid, int cmd, struct shmid_ds *buf);

DESCRIPTION

La fonction shmctl() opère sur la mémoire partagée XSI (voir le volume des Définitions de base de POSIX.1‐2017, Section 3.346, Objet de mémoire partagée). Il n'est pas spécifié si cette fonction interagit avec les installations de communication interprocessus temps réel définies dans la Section 2.8, Temps réel.

La fonction shmctl() fournit une variété d'opérations de contrôle de mémoire partagée comme spécifié par cmd. Les valeurs suivantes pour cmd sont disponibles :

IPC_STAT
Place la valeur actuelle de chaque membre de la structure de données shmid_ds associée à shmid dans la structure pointée par buf. Le contenu de la structure est défini dans <sys/shm.h>.
IPC_SET
Définit la valeur des membres suivants de la structure de données shmid_ds associée à shmid à la valeur correspondante trouvée dans la structure pointée par buf :
shm_perm.uid
shm_perm.gid
shm_perm.mode    Neuf bits de poids faible.

De plus, l'horodatage shm_ctime sera défini à l'heure actuelle, comme décrit dans la Section 2.7.1, Description générale IPC.

IPC_SET ne peut être exécuté que par un processus dont l'ID d'utilisateur effectif est égal soit à celui d'un processus disposant des privilèges appropriés, soit à la valeur de shm_perm.cuid ou shm_perm.uid dans la structure de données shmid_ds associée à shmid.

IPC_RMID
Supprime l'identifiant de mémoire partagée spécifié par shmid du système et détruit le segment de mémoire partagée et la structure de données shmid_ds qui lui sont associés. IPC_RMID ne peut être exécuté que par un processus dont l'ID d'utilisateur effectif est égal soit à celui d'un processus disposant des privilèges appropriés, soit à la valeur de shm_perm.cuid ou shm_perm.uid dans la structure de données shmid_ds associée à shmid.

VALEUR RENVOYÉE

En cas de succès, shmctl() renvoie 0 ; sinon, elle renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction shmctl() échouera si :

EACCES
L'argument cmd est égal à IPC_STAT et le processus appelant n'a pas l'autorisation de lecture ; voir la Section 2.7, Communication Interprocessus XSI.
EINVAL
La valeur de shmid n'est pas un identifiant de mémoire partagée valide, ou la valeur de cmd n'est pas une commande valide.
EPERM
L'argument cmd est égal à IPC_RMID ou IPC_SET et l'ID d'utilisateur effectif du processus appelant n'est pas égal à celui d'un processus disposant des privilèges appropriés et il n'est pas égal à la valeur de shm_perm.cuid ou shm_perm.uid dans la structure de données associée à shmid.

La fonction shmctl() peut échouer si :

EOVERFLOW
L'argument cmd est IPC_STAT et la valeur gid ou uid est trop grande pour être stockée dans la structure pointée par l'argument buf.

NOM

shmctl — Contrôle des segments de mémoire partagée (interface POSIX)

SYNTAXE

#include <sys/ipc.h>
#include <sys/shm.h>

int shmctl(int shmid, int cmd, struct shmid_ds *buf);

DESCRIPTION

La fonction shmctl effectue diverses opérations de contrôle sur un segment de mémoire partagée identifié par shmid. L'opération spécifique à effectuer est spécifiée par l'argument cmd. Le troisième argument, buf, est un pointeur vers une structure shmid_ds qui est utilisée pour stocker ou récupérer des informations sur le segment de mémoire partagée. Les valeurs possibles pour cmd sont :
  • IPC_STAT : Copie les informations sur le segment de mémoire associé à shmid dans la structure shmid_ds pointée par buf.
  • IPC_SET : Écrit les valeurs des membres shm_perm.uid, shm_perm.gid et shm_perm.mode de la structure shmid_ds pointée par buf dans le segment de mémoire associé à shmid. Seul le superutilisateur ou un processus possédant les privilèges appropriés peut modifier ces valeurs. La modification des permissions de base est autorisée pour un processus ayant les privilèges appropriés ou pour le propriétaire du segment de mémoire partagée, à condition que le processus ait les droits d'accès en écriture sur le segment.
  • IPC_RMID : Marque le segment de mémoire associé à shmid pour suppression. Le segment sera effectivement supprimé lorsque le dernier processus s'y rattachant s'en détachera. Les informations sur le segment seront libérées. Cet argument ne peut être utilisé que par le superutilisateur ou par un processus possédant les privilèges appropriés, ou par un processus qui a créé le segment de mémoire partagée.
  • IPC_INFO : (Non standard POSIX) Copie les informations générales sur le système concernant les segments de mémoire partagée dans la structure shmid_ds pointée par buf. Les membres significatifs sont shm_perm.uid, shm_perm.gid, shm_perm.mode et la structure shm_segsz. La valeur de shmid doit être 0 pour cette commande.
  • SHM_INFO : (Non standard POSIX) Identique à IPC_INFO, mais ne retourne que les informations relatives aux segments de mémoire partagée.
  • SHM_STAT : (Non standard POSIX) Identique à IPC_STAT, mais ne nécessite pas de valeur de shmid valide. La commande parcourt les segments existants et copie les informations du premier segment trouvé dans buf.
La structure shmid_ds est définie comme suit : 
struct shmid_ds {
    struct ipc_perm shm_perm; /* Permissions de l'objet IPC */
    size_t shm_segsz;         /* Taille du segment en octets */
    time_t shm_atime;         /* Heure du dernier rattachement */
    time_t shm_dtime;         /* Heure du dernier détachement */
    time_t shm_ctime;         /* Heure de la dernière modification des informations */
    pid_t shm_cpid;           /* PID du processus qui a créé le segment */
    pid_t shm_lpid;           /* PID du dernier processus qui a modifié le segment */
    shmatt_t shm_nattch;      /* Nombre de processus actuellement rattachés */
    // ... autres membres spécifiques à l'implémentation
};

struct ipc_perm {
    key_t key;
    uid_t uid;
    gid_t gid;
    uid_t cuid;
    gid_t cgid;
    mode_t mode;
    unsigned int seq;
};

VALEUR RENVOYÉE

En cas de succès, shmctl renvoie 0. En cas d'erreur, elle renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

  • EACCES : Le processus n'a pas les permissions requises pour la commande demandée.
  • EINVAL : shmid est invalide, ou cmd est invalide.
  • ENOMEM : La commande IPC_SET demande plus de mémoire que ce qui est disponible.
  • ENOTTY : shmid fait référence à un objet qui n'est pas un segment de mémoire partagée.
  • EPERM : Le processus n'est pas autorisé à effectuer la commande demandée (par exemple, IPC_RMID sans les privilèges appropriés).

CONFORMITÉ

POSIX.1-2001, POSIX.1-2008. Les commandes IPC_INFO, SHM_INFO et SHM_STAT ne font pas partie de la norme POSIX.

NOTES

Les implémentations peuvent fournir des valeurs supplémentaires pour cmd. Il est généralement déconseillé d'utiliser des constantes non standard.

EXEMPLE

#include <stdio.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <errno.h>

int main() {
    int shmid;
    struct shmid_ds buf;

    // Obtenir un identifiant de segment de mémoire partagée (remplacez par un shmid réel)
    shmid = /* ... obtenir un shmid ... */;

    if (shmid == -1) {
        perror("Erreur lors de l'obtention du shmid");
        return 1;
    }

    // Obtenir les informations sur le segment de mémoire partagée
    if (shmctl(shmid, IPC_STAT, &buf) == -1) {
        perror("Erreur shmctl(IPC_STAT)");
        return 1;
    }

    printf("Taille du segment: %zu octets\n", buf.shm_segsz);
    printf("Nombre d'attachements: %ld\n", (long)buf.shm_nattch);
    printf("Dernière modification: %s", ctime(&buf.shm_ctime));

    // Exemple de modification (requiert les privilèges appropriés)
    // buf.shm_perm.mode = 0666; // Définir les permissions (exemple)
    // if (shmctl(shmid, IPC_SET, &buf) == -1) {
    //     perror("Erreur shmctl(IPC_SET)");
    //     // Ignorer l'erreur si elle est due à un manque de privilèges
    // }

    // Marquer le segment pour suppression (requiert les privilèges appropriés ou la propriété)
    // if (shmctl(shmid, IPC_RMID, NULL) == -1) {
    //     perror("Erreur shmctl(IPC_RMID)");
    // }

    return 0;
}
