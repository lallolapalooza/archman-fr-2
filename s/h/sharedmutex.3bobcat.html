FBB::SharedMutex(3bobcat) Mutex partagé FBB::SharedMutex(3bobcat)

NOM

FBB::SharedMutex - Mutex pour mémoire partagée

SYNTAXE

#include <bobcat/sharedmutex>
Option de liaison : -lpthread, -lbobcat

DESCRIPTION

La mémoire partagée peut être utilisée par plusieurs processus. Pour synchroniser l'accès à la mémoire partagée, un FBB::SharedMutex peut être défini à l'intérieur d'un segment de mémoire partagée. Les objets SharedMutex permettent aux clients de verrouiller un segment de mémoire partagée avant de lire ou d'écrire son contenu. Par exemple, la classe Bobcat FBB::SharedSegment définit un SharedMutex dans son segment de mémoire partagée.

La classe SharedMutex utilise les facilités offertes par la bibliothèque PThread pour implémenter le verrouillage de mémoire partagée (non récursif). Pour forcer le déverrouillage d'un segment de mémoire partagée (potentiellement) verrouillé, son destructeur peut être appelé.

Les mutex SharedMutex ne sont pas récursifs, ce qui entraîne des blocages si leur méthode lock est appelée deux fois depuis le même fil d'exécution sans appel intermédiaire à unlock du mutex. Si cela pose problème, une variable peut être définie indiquant si le verrou a déjà été obtenu.

CONSTRUCTEURS, DESTRUCTEUR

o
SharedMutex():
Le constructeur par défaut initialise un objet FBB::SharedMutex en tant que mutex de mémoire partagée (utilisant l'attribut PTHREAD_PROCESS_SHARED). Comme un objet FBB::SharedMutex sera normalement défini à l'intérieur d'un segment de mémoire partagée, la mémoire de l'objet est déjà disponible. Dans ce cas, l'opérateur new placé (placement new) doit être utilisé pour appeler le constructeur. Par exemple, si un segment de mémoire partagée est attaché au processus courant à l'adresse d_shared, et qu'un FBB::SharedMutex doit être défini à l'adresse de d_shared, alors l'objet FBB::SharedMutex peut être initialisé comme suit : 
    new (d_shared) FBB::SharedMutex;
Attention : lors de l'utilisation de placement new pour initialiser un SharedMutex, assurez-vous que le SharedMutex rentre dans un bloc (c'est-à-dire shared.blockOffset() + sizeof(SharedMemory) < shared.dataSegmentSize()). Sinon, utilisez seek pour passer à un décalage où cette égalité est vraie, ou utilisez simplement SharedMemory::create comme suit : 
    FBB::SharedMemory::create<FBB::SharedMutex>();
o
~SharedMutex():
Le destructeur de la classe libère tous les verrous imbriqués du segment de mémoire partagée du processus courant. Pour détruire un objet FBB::SharedMutex qui a été construit en utilisant l'opérateur new placé, utilisez 
d_sharedMutex->~SharedMutex();
(en supposant que SharedMutex *d_sharedMutex pointe vers l'emplacement où placement new a précédemment initialisé l'objet FBB::SharedMutex.)
Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

FONCTIONS MEMBRES

o
void lock() const:
Lorsque cette fonction membre retourne, le processus courant a verrouillé le segment de mémoire partagée. Notez que les objets SharedMutex ne sont pas récursifs.
o
void unlock() const:
Le verrou du segment de mémoire partagée de l'objet est libéré. Cette fonction membre peut également être appelée si le verrou du SharedMutex n'a pas été obtenu.

FONCTION MEMBRE PROTÉGÉE

o
pthread_mutex_t *mutexPtr():
Un pointeur est retourné vers l'objet pthread_mutex_t utilisé par l'objet SharedMutex ;

EXEMPLE

#include <sys/types.h>
#include <signal.h>
#include <iostream>
#include <string>
#include <chrono>
#include <bobcat/fork>
#include <bobcat/semaphore>
#include <bobcat/sharedsegment>
#include <bobcat/sharedmutex>
using namespace std;
using namespace FBB;
class Wait: public Fork
{
    SharedSegment *d_shared;
    int d_id;
    SharedMutex *d_mutex;
    public:
        Wait();
        ~Wait();
        void childProcess() override;
        void parentProcess() override;
};
Wait::Wait()
:
    d_shared(SharedSegment::create(&d_id, 1, 100, 0700)),
    d_mutex(new (d_shared) SharedMutex)
{
    cout << "shared memory ID = " << d_id << ’\n’;
}
Wait::~Wait()
{
    d_mutex->~SharedMutex();
    SharedSegment::deleteSegment(d_id);
    cout << "deleted the shared memory\n";
}
void Wait::childProcess()
{
    Semaphore waiter{0};
    while (true)
    {
        waiter.wait_for(chrono::seconds(2));
        d_mutex->lock();
        cout << "child hello\n";
        d_mutex->unlock();
    }
}
void Wait::parentProcess()
{
    string line;
    do
    {
        cout << "press enter to allow the parent to locck\n";
        cin.ignore(100, ’\n’);
        d_mutex->lock();
        cout << "parent has the lock, press enter to continue "
                "(to end: some input)\n";
        getline(cin, line);
        d_mutex->unlock();
    }
    while (line.empty());
    kill(pid(), SIGTERM);
}
int main()
{
    Wait waiter;
    waiter.fork();
}
