SHMALLOC(3) Open MPI SHMALLOC(3)

shmalloc(3), shfree(3), shmemalign(3), shrealloc(3) - Fonctions de gestion de la mémoire du tas symétrique.

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
void *shmalloc(size_t size)
void shfree(void *ptr)
void *shrealloc(void *ptr, size_t size)
void *shmemalign(size_t alignment, size_t size)
extern long malloc_error

DESCRIPTION

La fonction shmalloc renvoie un pointeur vers un bloc d'au moins size octets, correctement aligné pour toute utilisation. Cet espace est alloué à partir du tas symétrique (par opposition à malloc(3), qui alloue à partir du tas privé).

La fonction shmemalign alloue un bloc dans le tas symétrique qui a un alignement en octets spécifié par l'argument alignment.

La fonction shfree entraîne la désallocation du bloc pointé par ptr, c'est-à-dire sa mise à disposition pour une allocation ultérieure. Si ptr est un pointeur nul, aucune action n'est effectuée ; sinon, si l'argument ne correspond pas à un pointeur renvoyé précédemment par une fonction du tas symétrique, ou si l'espace a déjà été désalloué, malloc_error est défini pour indiquer l'erreur, et shfree revient.

La fonction shrealloc modifie la taille du bloc pointé par ptr à la taille (en octets) spécifiée par size.

Le contenu du bloc reste inchangé jusqu'au moindre des nouvelles et anciennes tailles. Si la nouvelle taille est plus grande, la valeur de la partie nouvellement allouée du bloc est indéterminée. Si ptr est un pointeur nul, la fonction shrealloc se comporte comme la fonction shmalloc pour la taille spécifiée. Si size est 0 et ptr n'est pas un pointeur nul, le bloc pointé est libéré. Sinon, si ptr ne correspond pas à un pointeur renvoyé précédemment par une fonction du tas symétrique, ou si l'espace a déjà été désalloué, la variable malloc_error est définie pour indiquer l'erreur, et shrealloc renvoie un pointeur nul. Si l'espace ne peut pas être alloué, le bloc pointé par ptr reste inchangé.

Les fonctions shmalloc, shfree et shrealloc sont fournies pour que plusieurs PE (Process Elements) d'une application puissent allouer des blocs de mémoire symétriques et accessibles à distance. Ces blocs de mémoire peuvent ensuite être utilisés avec les routines de communication (shmem). Chacune de ces fonctions appelle la fonction shmem_barrier_all(3) avant de revenir ; cela garantit que tous les PE participent à l'allocation de mémoire, et que la mémoire sur les autres PE peut être utilisée dès que le PE local revient.

L'utilisateur est responsable de l'appel de ces fonctions avec des arguments identiques sur tous les PE ; si des arguments de taille différents sont utilisés, les appels ultérieurs peuvent ne pas renvoyer la même adresse de tas symétrique sur tous les PE.

NOTES

La taille totale du tas symétrique est déterminée au démarrage du job. On peut ajuster la taille du tas en utilisant la variable d'environnement SHMEM_SYMMETRIC_HEAP_SIZE. Voir la page de manuel intro_shmem(3) pour plus de détails. Les fonctions shmalloc, shfree et shrealloc diffèrent des fonctions d'allocation du tas privé en ce que tous les PE d'une application doivent les appeler (une barrière est utilisée pour assurer cela).

VALEURS DE RETOUR

La fonction shmalloc renvoie un pointeur vers l'espace alloué (qui doit être identique sur tous les PE) ; sinon, elle renvoie un pointeur nul (avec malloc_error défini). La fonction shfree ne renvoie aucune valeur. La fonction shrealloc renvoie un pointeur vers l'espace alloué (qui peut avoir bougé) ; sinon, elle renvoie un pointeur nul (avec malloc_error défini).
