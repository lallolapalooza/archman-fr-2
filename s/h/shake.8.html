SHAKE(8) Utilitaires d'administration système SHAKE(8)

NOM

Shake - Réécrit les fichiers fragmentés, améliorant potentiellement les performances.

SYNTAXE

shake [OPTION]... [FICHIER|RÉPERTOIRE]...

DESCRIPTION

Réécrit les fichiers fragmentés ou mal placés, améliorant potentiellement les performances. Lit la liste des fichiers depuis l'entrée standard s'il n'y a pas de fichiers dans les arguments. Vous devez monter votre partition avec l'option user_xattr.

-c, --max-crumbc
nombre maximum de miettes (crumbs)
-C, --max-fragc
nombre maximum de fragments
-d, --max-deviance
distance maximale entre le début du fichier et sa position idéale
-h, --help
vous regardez là !
-L, --no-locks
ne pas placer de verrou sur les fichiers écrits
-m, --many-fs
secouer les sous-répertoires qui sont sur des systèmes de fichiers différents
-n, --new
âge des fichiers "nouveaux", qui seront secoués (shak()ed)
-o, --old
âge des fichiers "anciens", qui ne seront pas secoués (shak()ed)
-p, --pretend
ne pas modifier les fichiers
-r, --crumbratio
ratio du fichier en dessous duquel un fragment est une miette
-s, --smallsize
taille en dessous de laquelle un fichier est considéré petit
-S, --bigsize
taille en dessous de laquelle un fichier est considéré grand

-t, --small-tolerance multiplier le crumbratio et diviser le nombre maximal de petits fichiers

-T, --big-tolerance
multiplier le crumbratio et diviser le nombre maximal de grands fichiers
-v, --verbose
augmenter le niveau de verbosité
-V, --version
afficher le numéro de version et le copyright
-X, --no-xattr
désactiver l'utilisation des xattr

UTILISATION

S'il n'y a pas de FICHIERS, shake lit depuis l'entrée standard.

Veuillez consulter http://vleu.net/shake/ pour des instructions détaillées.

EXEMPLES

Voir la fragmentation d'un fichier :
shake --pretend --verbose --verbose FICHIER
Secouer tous les fichiers d'un répertoire, récursivement :
shake --old=0 REP
Secouer tous les mp3 d'un sous-répertoire, en regroupant ceux qui sont proches par ordre alphabétique :
find -iname '*.mp3' | sort | shake
