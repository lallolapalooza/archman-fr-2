shmem_clear_cache_inv(3)

Paquet: openmpi

SHMEM_CLEAR_CACHE_INV(3) Open MPI SHMEM_CLEAR_CACHE_INV(3)

shmem_clear_cache_inv(3), shmem_set_cache_inv(3), shmem_set_cache_line_inv(3), shmem_udcflush(3), shmem_udcflush_line(3) - Contrôle les utilitaires de cache de données

SYNTAXE

C ou C++:

#include <mpp/shmem.h>
void shmem_clear_cache_inv(void)
void shmem_clear_cache_line_inv(void *target)
void shmem_set_cache_inv(void)
void shmem_set_cache_line_inv(void *target)
void shmem_udcflush(void)
void shmem_udcflush_line(void *target)

Fortran:

INCLUDE "mpp/shmem.fh"
CALL SHMEM_CLEAR_CACHE_INV
CALL SHMEM_CLEAR_CACHE_LINE_INV(target)
CALL SHMEM_SET_CACHE_INV
CALL SHMEM_SET_CACHE_LINE_INV(target)
CALL SHMEM_UDCFLUSH
CALL SHMEM_UDCFLUSH_LINE(target)

DESCRIPTION

L'argument suivant est passé aux routines de contrôle de ligne de cache :

cible
Un objet de données local à l'élément de traitement (PE). cible peut être de n'importe quel type non caractère. Si vous utilisez Fortran, il peut être de n'importe quel type.

shmem_clear_cache_inv désactive le mode de cohérence automatique du cache précédemment activé par shmem_set_cache_inv ou shmem_set_cache_line_inv.

shmem_clear_cache_line_inv désactive le mode de cohérence automatique du cache uniquement pour la ligne de cache associée à l'adresse de cible.

shmem_set_cache_inv permet à l'API OpenSHMEM de décider automatiquement de la meilleure stratégie pour la cohérence du cache.

shmem_set_cache_line_inv active uniquement le mode de cohérence automatique du cache pour la ligne de cache associée à l'adresse de cible.

shmem_clear_cache_inv désactive le mode de cohérence automatique du cache précédemment activé par shmem_set_cache_inv ou shmem_set_cache_line_inv.

shmem_udcflush rend l'intégralité du cache de données utilisateur cohérent.

shmem_udcflush_line rend cohérente la ligne de cache qui correspond à l'adresse spécifiée par cible.

NOTES

Ces routines ont été conservées pour une meilleure compatibilité ascendante avec les architectures héritées.
