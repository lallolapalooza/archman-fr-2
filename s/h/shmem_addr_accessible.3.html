shmem_addr_accessible - Indique si une adresse est accessible via les opérations OpenSHMEM depuis le PE distant spécifié.

SYNOPSIS

C ou C++ :

#include <mpp/shmem.h>
int shmem_addr_accessible(const void *addr, int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
LOGICAL LOG, SHMEM_ADDR_ACCESSIBLE
INTEGER pe
LOG = SHMEM_ADDR_ACCESSIBLE(addr, pe)

DESCRIPTION

shmem_addr_accessible est une fonction de requête qui indique si une adresse locale est accessible via les opérations SHMEM depuis le PE distant spécifié.

Cette fonction vérifie que le PE distant est accessible via les fonctions de transfert de données SHMEM depuis le PE local, et que l'adresse spécifiée se trouve dans un segment de données symétrique par rapport au PE distant.

VALEURS DE RETOUR

C : La valeur de retour est 1 si addr est un objet de données symétrique et accessible via les opérations SHMEM depuis le PE distant spécifié ; sinon, elle est 0.

Fortran : La valeur de retour est .TRUE. si addr est un objet de données symétrique et accessible via les opérations SHMEM depuis le PE distant spécifié ; sinon, elle est .FALSE..
