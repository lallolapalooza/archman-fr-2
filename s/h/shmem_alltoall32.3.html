SHMEM_ALLTOALL32(3) Open MPI SHMEM_ALLTOALL32(3)

shmem_alltoall32(3), shmem_alltoall64(3), shmem_alltoalls32(3), shmem_alltoalls64(3) - routine collective où chaque PE échange une quantité fixe de données avec tous les autres PE de l'ensemble Actif

SYNOPSIS

C ou C++ :

#include <mpp/shmem.h>
void shmem_alltoall32(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoall64(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls32(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls64(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER dst, sst, nelems, PE_root, PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_ALLTOALL_SYNC_SIZE)
CALL SHMEM_ALLTOALL32(target, source, nelems,
& PE_start, logPE_stride, PE_size, fIpSync)
CALL SHMEM_ALLTOALL64(target, source, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS32(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS64(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)

DESCRIPTION

Les routines shmem_alltoalls sont des routines collectives. Chaque PE de l'ensemble Actif échange nelems éléments de données avec un pas de 32 bits (pour shmem_alltoalls32) ou 64 bits (pour shmem_alltoalls64) avec tous les autres PE de l'ensemble. Les deux pas, dst et sst, doivent être supérieurs ou égaux à 1. Le j-ième bloc de taille sst envoyé par le PE i au PE j est placé dans le i-ième bloc de taille dst de l'objet de données de destination sur le PE j. Comme pour toutes les routines collectives OpenSHMEM, ces routines supposent que seuls les PE de l'ensemble Actif appellent la routine. Si un PE n'appartenant pas à l'ensemble Actif appelle une routine collective OpenSHMEM, cela entraîne un comportement indéfini. Les valeurs des arguments dst, sst, nelems, PE_start, logPE_stride et PE_size doivent être égales sur tous les PE de l'ensemble Actif. Les mêmes objets de données de destination et source, ainsi que le même tableau de travail pSync, doivent être passés à tous les PE de l'ensemble Actif. Avant tout appel de routine shmem_alltoalls par un PE, les conditions suivantes doivent exister (une synchronisation via une barrière ou une autre méthode est souvent nécessaire pour s'en assurer) : Le tableau pSync sur tous les PE de l'ensemble Actif n'est plus utilisé suite à un appel antérieur à une routine shmem_alltoalls. L'objet de données de destination sur tous les PE de l'ensemble Actif est prêt à recevoir les données de shmem_alltoalls. Au retour d'une routine shmem_alltoalls, ce qui suit est vrai pour le PE local : Son objet de données symétrique de destination est complètement mis à jour et les données ont été copiées hors de l'objet de données source. Les valeurs dans le tableau pSync sont restaurées à leurs valeurs d'origine.

Les arguments sont les suivants :

Un objet de données symétrique avec l'un des types de données suivants :

shmem_alltoall32: Tout type non caractère qui
a une taille d'élément de 32 bits. Aucun type dérivé Fortran ou structure C/C++ n'est autorisé.
shmem_alltoall64: Tout type non caractère ayant une taille
d'élément de 64 bits. Aucun type dérivé Fortran ou structure C/C++ n'est autorisé.

target Un objet de données symétrique suffisamment grand pour recevoir le total combiné de nelems éléments de chaque PE de l'ensemble Actif.

source
Un objet de données symétrique contenant nelems éléments de données pour chaque PE de l'ensemble Actif, ordonnés selon le PE de destination.
dst
Le pas entre les éléments consécutifs de l'objet de données de destination. Le pas est mis à l'échelle par la taille de l'élément. Une valeur de 1 indique des données contiguës. dst doit être de type ptrdiff_t. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
sst
Le pas entre les éléments consécutifs de l'objet de données source. Le pas est mis à l'échelle par la taille de l'élément. Une valeur de 1 indique des données contiguës. sst doit être de type ptrdiff_t. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
nelems
Le nombre d'éléments à échanger pour chaque PE. nelems doit être de type size_t pour C/C++. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
PE_start
Le plus petit numéro de PE virtuel de l'ensemble actif de PE. PE_start doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
logPE_stride
Le logarithme (base 2) du pas entre les numéros de PE virtuels consécutifs dans l'ensemble actif. log_PE_stride doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
PE_size
Le nombre de PE dans l'ensemble actif. PE_size doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
pSync
Un tableau de travail symétrique. En C/C++, pSync doit être de type long et de taille _SHMEM_ALLTOALL_SYNC_SIZE. En Fortran, pSync doit être de type entier et de taille SHMEM_ALLTOALL_SYNC_SIZE. Chaque élément de ce tableau doit être initialisé avec la valeur _SHMEM_SYNC_VALUE (en C/C++) ou SHMEM_SYNC_VALUE (en Fortran) avant que l'un des PE de l'ensemble actif n'entre dans shmem_barrier().

Au retour d'une routine shmem_alltoalls, ce qui suit est vrai pour le PE local : Son objet de données symétrique de destination est complètement mis à jour et les données ont été copiées hors de l'objet de données source. Les valeurs dans le tableau pSync sont restaurées à leurs valeurs d'origine.

Les valeurs des arguments PE_root, PE_start, logPE_stride et PE_size doivent être égales sur tous les PE de l'ensemble actif. Les mêmes objets de données de destination et source, ainsi que le même tableau de travail pSync, doivent être passés à tous les PE de l'ensemble actif.

Avant que tout PE n'appelle une routine alltoall, vous devez vous assurer que les conditions suivantes existent (une synchronisation via une barrière ou une autre méthode est souvent nécessaire pour s'en assurer) : Le tableau pSync sur tous les PE de l'ensemble actif n'est plus utilisé suite à un appel antérieur à une routine alltoall. Le tableau de destination sur tous les PE de l'ensemble actif est prêt à accepter les données alltoall.

NOTES

Les termes collectif et symétrique sont définis dans intro_shmem(3).

Toutes les routines SHMEM alltoall restaurent pSync à son contenu d'origine. Des appels multiples à des routines SHMEM qui utilisent le même tableau pSync ne nécessitent pas que pSync soit réinitialisé après le premier appel.

Vous devez vous assurer que le tableau pSync n'est pas mis à jour par un PE de l'ensemble actif pendant que l'un des PE participe au traitement d'une routine de diffusion SHMEM. Faites attention à éviter ces situations : Si le tableau pSync est initialisé à l'exécution, un certain type de synchronisation est nécessaire pour s'assurer que tous les PE de l'ensemble de travail ont initialisé pSync avant que l'un d'eux n'entre dans une routine SHMEM appelée avec le tableau de synchronisation pSync. Un tableau pSync peut être réutilisé sur une routine de diffusion SHMEM ultérieure uniquement si aucun des PE de l'ensemble actif n'est encore en train de traiter un appel de routine SHMEM alltoall antérieur qui utilisait le même tableau pSync. En général, cela ne peut être garanti qu'en effectuant une sorte de synchronisation. Cependant, dans le cas spécial des routines SHMEM appelées avec le même ensemble actif, vous pouvez allouer deux tableaux pSync et alterner entre eux lors d'appels successifs.

shmem_alltoall32(3)

shmem_alltoall32, shmem_alltoall64 — déplace des données entre tous les PEs

30 octobre 2025

SYNOPSIS

#include <memory.h>

void shmem_alltoall32(void *dest, const void *source, int nlong, int PE_start, int PE_stride, int PE_count, long *pSync);

void shmem_alltoall64(void *dest, const void *source, int nlong, int PE_start, int PE_stride, int PE_count, long *pSync);

DESCRIPTION

La routine de communication collective shmem_alltoall32 et shmem_alltoall64 déplace des données entre tous les PEs dans un groupe de PEs. Spécifiquement, chaque PE envoie les mêmes données à tous les autres PEs. Les données envoyées par le PE `p' sont reçues par tous les autres PEs.

Les paramètres sont les suivants :

dest
Pointeur vers la mémoire où les données reçues seront stockées.
source
Pointeur vers la mémoire qui contient les données à envoyer.
nlong
Le nombre de 32 bits (pour shmem_alltoall32) ou 64 bits (pour shmem_alltoall64) qui seront envoyés.
PE_start
Le premier PE dans le groupe de PEs qui participera à l'opération.
PE_stride
L'intervalle entre les PEs dans le groupe de PEs. Pour inclure tous les PEs, la valeur devrait être 1.
PE_count
Le nombre de PEs qui participeront à l'opération.
pSync
Un tableau de synchronisation qui doit être initialisé avec la valeur SHMEM_SYNC_VALUE. Ce tableau doit avoir une taille d'au moins SHMEM_ALLTOALLS_SYNC_SIZE.

Dans une opération shmem_alltoall32, chaque PE envoie nlong entiers de 32 bits depuis son tableau source à tous les PEs spécifiés dans la plage de PEs. Le PE `p' envoie les données à partir de l'index `p * nlong' dans son tableau source. Les données reçues par un PE `p' sont stockées à l'index `p * nlong' dans son tableau dest.

Dans une opération shmem_alltoall64, chaque PE envoie nlong entiers de 64 bits depuis son tableau source à tous les PEs spécifiés dans la plage de PEs. Le PE `p' envoie les données à partir de l'index `p * nlong' dans son tableau source. Les données reçues par un PE `p' sont stockées à l'index `p * nlong' dans son tableau dest.

NOTES

Les routines shmem_alltoall32 et shmem_alltoall64 sont des fonctions de blocage. L'appel ne retourne pas tant que toutes les données n'ont pas été envoyées et reçues.

Les tableaux source et dest doivent être correctement alignés pour le type de données qui sera transféré. La valeur de nlong ne peut pas dépasser 1 dans shmem_alltoall32 et shmem_alltoall64.

L'utilisation de shmem_alltoall32 et shmem_alltoall64 est similaire à celle de shmem_broadcast32 et shmem_broadcast64, sauf que les données sont envoyées à tous les PEs, et non pas uniquement à un seul PE.

EXAMPLES

#include <mpp/shmem.h>
#include <stdio.h>

#define COUNT 10

int main(void) {
    long *source, *dest;
    long pSync[SHMEM_ALLTOALLS_SYNC_SIZE];
    int i, pe;

    /* Initialiser les tableaux */
    source = (long *) shmem_malloc(COUNT * sizeof(long));
    dest = (long *) shmem_malloc(COUNT * sizeof(long));

    /* Initialiser le tableau source */
    for (i=0; i<COUNT; i++) {
        source[i] = shmem_my_pe() * COUNT + i;
    }

    /* Initialiser le tableau de synchronisation */
    for (i=0; i<SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* Attendre que tous les PEs initialisent pSync */
    shmem_barrier_all();

    /* alltoalls sur tous les PEs */
    shmem_alltoall64(dest, source, COUNT, 0, 1, shmem_n_pes(), pSync);

    /* Vérifier les résultats */
    for (pe=0; pe<shmem_n_pes(); pe++) {
        for (i=0; i<COUNT; i++){
            if (dest[i] != pe * COUNT + i) {
                printf("[%d] ERREUR: dest[%d]=%ld, devrait être %ld\n",
                       shmem_my_pe(), i, dest[i], pe * COUNT + i);
            }
        }
    }

    shmem_barrier_all();
    shmem_free(dest);
    shmem_free(source);
    shmem_finalize();
    return 0;
}

L'exemple ci-dessus montre comment utiliser shmem_alltoall64 pour échanger des données entre tous les PEs. Chaque PE envoie un tableau de COUNT entiers à tous les autres PEs. Chaque PE reçoit les données de tous les autres PEs dans son tableau dest. Les données reçues sont ensuite vérifiées pour s'assurer qu'elles sont correctes.

Voici un autre exemple utilisant shmem_alltoall32 avec des valeurs différentes pour PE_start, PE_stride et PE_count.

#include <mpp/shmem.h>
#include <stdio.h>

#define COUNT 10

int main(void) {
    short *source, *dest;
    long pSync[SHMEM_ALLTOALLS_SYNC_SIZE];
    int i, pe;

    /* Initialiser les tableaux */
    source = (short *) shmem_malloc(COUNT * sizeof(short));
    dest = (short *) shmem_malloc(COUNT * sizeof(short));

    /* Initialiser le tableau source */
    for (i=0; i<COUNT; i++){
        source[(shmem_my_pe()*COUNT)+i] = shmem_my_pe() + pe;
    }

    /* Initialiser le tableau de synchronisation */
    for (i=0; i< SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }
    /* attendre que tous les PEs initialisent pSync */
    shmem_barrier_all();
    /* alltoalls sur tous les PES */
    shmem_alltoalls32(dest, source, 1, 0, 1, shmem_n_pes(), pSync);
    /* vérifier les résultats */
    for (pe=0; pe<shmem_n_pes(); pe++) {
        for (i=0; i<count; i++){
            if (dest[(pe*count)+i] != shmem_my_pe() + pe) {
                printf("[%d] ERREUR: dest[%d]=%d, devrait être %d\n",
                       shmem_my_pe(),(pe*count)+i,dest[(pe*count)+i],
                       shmem_n_pes() + pe);
            }
        }
    }
    shmem_barrier_all();
    shmem_free(dest);
    shmem_free(source);
    shmem_finalize();
    return 0;
}
