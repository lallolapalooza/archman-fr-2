SHMIDCAT(1) Mémoire partagée Trampoline SHMIDCAT(1)

NOM

shmidcat - Copie stdin/fichier dans un bloc de mémoire partagée pour gtkwave(1)

SYNTAXE

shmidcat [FICHIERVCD]

DESCRIPTION

Copie soit le fichier spécifié en ligne de commande, soit l'entrée standard (si aucun fichier n'est spécifié) ligne par ligne dans un bloc de mémoire partagée. La sortie standard contiendra un identifiant de mémoire partagée qui devra être passé à gtkwave(1).

EXEMPLES

Pour exécuter ce programme de manière standard, tapez :

cat whatever.vcd | shmidcat
L'identifiant de mémoire partagée est émis vers la sortie standard.
shmidcat whatever.vcd | gtkwave -v -I whatever.sav
GTKWave récupère directement l'identifiant depuis l'entrée standard.

LIMITATIONS

Ce programme est principalement destiné à des fins illustratives et de test. Son utilisation principale est pour ceux qui souhaitent écrire des dumpers VCD interactifs pour gtkwave(1), car son code source peut être examiné, en particulier la fonction emit_string(). Il peut également être utilisé pour tester si un fichier VCD existant se charge correctement en mode interactif. Notez qu'il peut aussi être utilisé pour rediriger des fichiers VCD écrits dans un tube vers gtkwave(1) de manière non bloquante.
