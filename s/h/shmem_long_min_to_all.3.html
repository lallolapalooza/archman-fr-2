shmem_double_min_to_all(3), shmem_float_min_to_all(3), shmem_int_min_to_all(3), shmem_int4_min_to_all(3), shmem_int8_min_to_all(3), shmem_long_min_to_all(3), shmem_longdouble_min_to_all(3), shmem_longlong_min_to_all(3), shmem_real4_min_to_all(3), shmem_real8_min_to_all(3), shmem_real16_min_to_all(3), shmem_short_min_to_all(3) - Effectue une réduction de fonction minimum à travers un ensemble d'éléments de traitement (PE)

SYNOPIS

C ou C++ :

#include <mpp/shmem.h>
void shmem_double_min_to_all(double *target, const double *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  double *pWrk, long *pSync)
void shmem_float_min_to_all(float *target, const float *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  float *pWrk, long *pSync)
void shmem_int_min_to_all(int *target, const int *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  int *pWrk, long *pSync)
void shmem_long_min_to_all(long *target, const long *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  long *pWrk, long *pSync)
void shmem_longdouble_min_to_all(long double *target,
  const long double *source, int nreduce, int PE_start,
  int logPE_stride, int PE_size, long double *pWrk,
  long *pSync)
void shmem_longlong_min_to_all(long long *target,
  const long long *source, int nreduce, int PE_start, int logPE_stride,
  int PE_size, long long *pWrk, long *pSync)
void shmem_short_min_to_all(short *target, const short *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  short *pWrk, long *pSync)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER pSync(SHMEM_REDUCE_SYNC_SIZE)
INTEGER nreduce, PE_start, logPE_stride, PE_size
CALL SHMEM_INT4_MIN_TO_ALL(target, source, nreduce, PE_start,
& logPE_stride, PE_size, pWrk, pSync)
CALL SHMEM_INT8_MIN_TO_ALL(target, source, nreduce, PE_start,
& logPE_stride, PE_size, pWrk, pSync)

& logPE_stride, PE_size, pWrk, pSync)
CALL SHMEM_REAL8_MIN_TO_ALL(target, source, nreduce, PE_start,
& logPE_stride, PE_size, pWrk, pSync)
CALL SHMEM_REAL16_MIN_TO_ALL(target, source, nreduce, PE_start,
& logPE_stride, PE_size, pWrk, pSync)

DESCRIPTION

Les routines de réduction de la mémoire partagée (SHMEM) calculent une ou plusieurs réductions sur des tableaux symétriques sur plusieurs PE virtuels. Une réduction effectue une opération binaire associative sur un ensemble de valeurs. Pour une liste d'autres routines de réduction SHMEM, voir intro_shmem(3).

Comme avec toutes les routines collectives SHMEM, chacune de ces routines suppose que seuls les PE de l'ensemble actif appellent la routine. Si un PE n'appartenant pas à l'ensemble actif appelle une routine collective SHMEM, un comportement indéfini en résulte.

L'argument nreduce détermine le nombre de réductions distinctes à effectuer. Le tableau source sur tous les PE de l'ensemble actif fournit un élément pour chaque réduction. Les résultats des réductions sont placés dans le tableau cible sur tous les PE de l'ensemble actif. L'ensemble actif est défini par le triplet PE_start, logPE_stride, PE_size.

Les tableaux source et cible peuvent être le même tableau, mais ils ne peuvent pas être des tableaux qui se chevauchent.

Les arguments sont les suivants :

cible
Un tableau symétrique de nreduce éléments qui recevra les résultats des opérations de réduction. Le type de données de la cible varie selon la version de la routine de réduction appelée. Lors de l'appel depuis C/C++, reportez-vous à la section SYNOPIS pour les informations sur les types de données. Lors de l'appel depuis Fortran, les types de données cibles sont les suivants :

shmem_int4_min_to_all : Entier, avec une taille d'élément de 4 octets

shmem_int8_min_to_all : Entier, avec une taille d'élément de 8 octets

shmem_real4_min_to_all : Réel, avec une taille d'élément de 4 octets

shmem_real8_min_to_all : Réel, avec une taille d'élément de 8 octets

shmem_real16_min_to_all : Réel, avec une taille d'élément de 16 octets

source Un tableau symétrique : de nreduce éléments, qui contient un
élément pour chaque opération de réduction distincte. L'argument source doit avoir le même type de données que la cible.
nreduce
Le nombre d'éléments dans les tableaux cible et source. nreduce doit être de type entier. Si vous utilisez Fortran, ce doit être une valeur entière par défaut.
PE_start
Le plus petit numéro de PE virtuel de l'ensemble actif de PE. PE_start doit être de type entier. Si vous utilisez Fortran, ce doit être une valeur entière par défaut.
logPE_stride
Le log (base 2) du pas entre les numéros de PE virtuels consécutifs dans l'ensemble actif. logPE_stride doit être de type entier. Si vous utilisez Fortran, ce doit être une valeur entière par défaut.
PE_size
Le nombre de PE dans l'ensemble actif. PE_size doit être de type entier. Si vous utilisez Fortran, ce doit être une valeur entière par défaut.
pWrk
Un tableau de travail symétrique. L'argument pWrk doit avoir le même type de données que la cible. En C/C++, il contient max(nreduce/2 + 1, _SHMEM_REDUCE_MIN_WRKDATA_SIZE) éléments. En Fortran, il contient max(nreduce/2 + 1, SHMEM_REDUCE_MIN_WRKDATA_SIZE) éléments.
pSync
Un tableau de travail symétrique. En C/C++, pSync est de type long et de taille _SHMEM_REDUCE_SYNC_SIZE. En Fortran, pSync est de type entier et de taille SHMEM_REDUCE_SYNC_SIZE. Si vous utilisez Fortran, ce doit être une valeur entière par défaut. Chaque élément de ce tableau doit être initialisé avec la valeur _SHMEM_SYNC_VALUE (en C/C++) ou SHMEM_SYNC_VALUE (en Fortran) avant que l'un des PE de l'ensemble actif n'entre dans la routine de réduction.

Les valeurs des arguments nreduce, PE_start, logPE_stride et PE_size doivent être égales sur tous les PE de l'ensemble actif. Les mêmes tableaux cible et source, ainsi que les mêmes tableaux de travail pWrk et pSync, doivent être passés à tous les PE de l'ensemble actif.

Avant que tout PE n'appelle une routine de réduction, vous devez vous assurer que les conditions suivantes existent (une synchronisation via une barrière ou une autre méthode est souvent nécessaire pour garantir cela) : Les tableaux pWrk et pSync sur tous les PE de l'ensemble actif ne sont plus utilisés d'un appel précédent à une routine collective SHMEM. Le tableau cible sur tous les PE de l'ensemble actif est prêt à recevoir les résultats de la réduction.

Au retour d'une routine de réduction, les conditions suivantes sont vraies pour le PE local : La cible est mise à jour. Les valeurs dans le tableau pSync sont restaurées à leurs valeurs d'origine.

NOTES

Les termes collectif, symétrique et aligné en cache sont définis dans intro_shmem(3). Toutes les routines de réduction SHMEM réinitialisent les valeurs de pSync avant de retourner, de sorte qu'un tampon pSync particulier n'a besoin d'être initialisé que la première fois qu'il est utilisé.

Vous devez vous assurer que le tableau pSync n'est pas mis à jour sur aucun PE de l'ensemble actif pendant que l'un des PE participe au traitement d'une routine de réduction SHMEM. Faites attention aux situations suivantes : Si le tableau pSync est initialisé à l'exécution, un type de synchronisation est nécessaire pour s'assurer que tous les PE de l'ensemble de travail ont initialisé pSync avant que l'un d'entre eux n'entre dans une routine SHMEM appelée avec le tableau de synchronisation pSync. Un tableau pSync ou pWrk peut être réutilisé dans un appel de routine de réduction ultérieur uniquement si aucun des PE de l'ensemble actif ne traite encore un appel de routine de réduction précédent utilisant les mêmes tableaux pSync ou pWrk. En général, cela ne peut être assuré qu'en effectuant une forme de synchronisation. Cependant, dans le cas particulier des routines de réduction appelées avec le même ensemble actif, vous pouvez allouer deux tableaux pSync et pWrk et alterner entre eux lors des appels successifs.

shmem_real8_min_to_all(3) — Open MPI 5.0.9-2

NAME

shmem_real8_min_to_all - Computes the minimum value of a real variable across all PEs.

SYNOPSIS

C:

#include <mpp/shmem.h>
void shmem_real8_min_to_all(double *target, double *source, int nlong, int PE_mask, int PE_stride, int logPE_stride, double *pWrk, double *pSync);

Fortran:

INCLUDE "mpp/shmem.fh"
CALL SHMEM_REAL8_MIN_TO_ALL(target, source, nlong, PE_mask, PE_stride, logPE_stride, pWrk, pSync)

DESCRIPTION

The symmetric shared memory (SHMEM) routines provide a way to perform operations on remote processing elements (PEs). The shmem_real8_min_to_all routines are collective routines that compute the minimum value of a real variable across all PEs. Each PE can provide a value on its source argument. The minimum value is then distributed to the target argument on all participating PEs.

The arguments are:

target
Pointer to the destination array on the local PE. This array should be of size nlong.
source
Pointer to the source array on the local PE. This array should be of size nlong.
nlong
The number of elements to be reduced. This parameter must be consistent across all PEs.
PE_mask
A bitmask used to select PEs for the operation. If PE_mask is set to SHMEM_ALL_PE, then all PEs participate in the operation.
PE_stride
The stride between PEs to be included in the operation. This parameter is only relevant if PE_mask is not SHMEM_ALL_PE.
logPE_stride
The base-2 logarithm of the stride between PEs. This parameter is only relevant if PE_mask is not SHMEM_ALL_PE.
pWrk
A pointer to a working array. The size of this array depends on the number of elements being reduced and the specific SHMEM implementation. For shmem_real8_min_to_all, the minimum required size is nlong + SHMEM_REDUCE_MIN_WRKDATA_SIZE.
pSync
A pointer to a synchronization array. This array must be of size SHMEM_REDUCE_SYNC_SIZE. It is used to ensure synchronization between PEs during the reduction operation. The array must be initialized with the value SHMEM_SYNC_VALUE.

NOTES

The shmem_real8_min_to_all routine is a specialized version of the generic shmem_reduce_min_to_all routine, optimized for double-precision real numbers.

The PE_mask, PE_stride, and logPE_stride arguments provide flexibility in selecting the PEs that participate in the reduction. When PE_mask is set to SHMEM_ALL_PE, all PEs in the system participate in the reduction.

The pWrk array is used for intermediate storage during the reduction. Its size must be sufficient to accommodate the data being processed.

The pSync array is crucial for ensuring that all PEs involved in the reduction operation complete their tasks before proceeding. It must be initialized correctly before the call to shmem_real8_min_to_all.

EXAMPLES

Example 1: Fortran code snippet:

INCLUDE "mpp/shmem.fh"
INTEGER PSYNC(SHMEM_REDUCE_SYNC_SIZE)
DATA PSYNC /SHMEM_REDUCE_SYNC_SIZE*SHMEM_SYNC_VALUE/
PARAMETER (NR=1)
REAL FOO, FOOMIN, PWRK(MAX(NR/2+1,SHMEM_REDUCE_MIN_WRKDATA_SIZE))
COMMON /COM/ FOO, FOOMIN, PWRK
INTRINSIC MY_PE
IF ( MOD(MY_PE(),2) .EQ. 0) THEN
  CALL SHMEM_REAL8_MIN_TO_ALL(FOOMIN, FOO, NR, 0, 1, N$PES/2,
  & PWRK, PSYNC)
  PRINT *, 'Result on PE ', MY_PE(), ' is ', FOOMIN
ENDIF

This example calculates the minimum value of the real variable FOO across all even PEs.

Example 2: Consider the following C/C++ call:

shmem_int_min_to_all( target, source, 3, 0, 0, 8, pwrk, psync );

The preceding call is more efficient, but semantically equivalent to, the combination of the following calls:

shmem_int_min_to_all(&(target[0]), &(source[0]), 1, 0, 0, 8,
  pwrk1, psync1);
shmem_int_min_to_all(&(target[1]), &(source[1]), 1, 0, 0, 8,
  pwrk2, psync2);
shmem_int_min_to_all(&(target[2]), &(source[2]), 1, 0, 0, 8,
  pwrk1, psync1);

Note that two sets of pWrk and pSync arrays are used alternately because no synchronization is done between calls.
