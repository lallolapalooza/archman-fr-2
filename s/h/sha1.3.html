SHA1(3) Manuel des fonctions de bibliothèque SHA1(3)

NOM

SHA1Init, SHA1Update, SHA1Pad, SHA1Final, SHA1Transform, SHA1End, SHA1File, SHA1FileChunk, SHA1Data — calculer l'algorithme de hachage sécurisé du NIST

BIBLIOTHÈQUE

Bibliothèque de prise en charge des fonctions de résumé de message (MD4, MD5, etc.) (libmd, -lmd)

SYNTAXE

#include <sys/types.h>
#include <sha1.h>

void
SHA1Init(SHA1_CTX *contexte);

void
SHA1Update(SHA1_CTX *contexte, const uint8_t *données, size_t longueur);

void
SHA1Pad(SHA1_CTX *contexte);

void
SHA1Final(uint8_t résumé[SHA1_DIGEST_LENGTH], SHA1_CTX *contexte);

void
SHA1Transform(uint32_t état[5], const uint8_t tampon[SHA1_BLOCK_LENGTH]);

char *
SHA1End(SHA1_CTX *contexte, char *tampon);

char *
SHA1File(const char *nom_fichier, char *tampon);

char *
SHA1FileChunk(const char *nom_fichier, char *tampon, off_t décalage, off_t longueur);

char *
SHA1Data(const uint8_t *données, size_t longueur, char *tampon);

DESCRIPTION

Les fonctions SHA1 implémentent le NIST Secure Hash Algorithm (SHA-1), FIPS PUB 180-1. SHA-1 est utilisé pour générer une représentation condensée d'un message appelée résumé de message. L'algorithme prend en entrée un message de moins de 2^64 bits et produit un résumé de 160 bits adapté à une utilisation comme signature numérique.

Bien que les fonctions SHA1 soient considérées comme plus sûres que les fonctions md4(3) et md5(3) avec lesquelles elles partagent une interface similaire, elles sont considérées comme non sécurisées depuis 2005, et depuis 2020, les attaques par préfixe choisi sont devenues pratiques, elles ne doivent donc pas être utilisées dans des contextes cryptographiques.

La fonction SHA1Init() initialise un SHA1_CTX contexte à utiliser avec SHA1Update() et SHA1Final(). La fonction SHA1Update() ajoute les données de longueur longueur au SHA1_CTX spécifié par contexte. SHA1Final() est appelée lorsque toutes les données ont été ajoutées via SHA1Update() et stocke un résumé de message dans le paramètre résumé.

La fonction SHA1Pad() peut être utilisée pour appliquer un remplissage au résumé de message comme dans SHA1Final(), mais le contexte actuel peut toujours être utilisé avec SHA1Update().

La fonction SHA1Transform() est utilisée par SHA1Update() pour hacher des blocs de 512 bits et constitue le cœur de l'algorithme. La plupart des programmes devraient utiliser l'interface fournie par SHA1Init(), SHA1Update() et SHA1Final() au lieu d'appeler SHA1Transform() directement.

La fonction SHA1End() est une interface pour SHA1Final() qui convertit le résumé en une représentation ASCII du résumé de 160 bits en hexadécimal.

La fonction SHA1File() calcule le résumé d'un fichier et retourne le résultat via SHA1End(). Si SHA1File() ne peut pas ouvrir le fichier, un pointeur NULL est retourné.

SHA1FileChunk() se comporte comme SHA1File() mais calcule le résumé uniquement pour cette portion du fichier commençant à décalage et continuant sur longueur octets ou jusqu'à la fin du fichier, selon ce qui arrive en premier. Une longueur nulle peut être spécifiée pour lire jusqu'à la fin du fichier. Une longueur ou un décalage négatif sera ignoré.

La fonction SHA1Data() calcule le résumé d'une chaîne arbitraire et retourne le résultat via SHA1End().

Pour chacune des fonctions SHA1End(), SHA1File() et SHA1Data() le paramètre tampon doit soit être une chaîne d'au moins 41 caractères, soit un pointeur NULL. Dans ce dernier cas, de l'espace sera dynamiquement alloué via malloc(3) et devra être libéré en utilisant free(3) lorsqu'il ne sera plus nécessaire.

EXEMPLES

Le fragment de code suivant calculera le résumé de la chaîne "abc" qui est ``0xa9993e364706816aba3e25717850c26c9cd0d89d''.

SHA1_CTX sha;
uint8_t résultats[SHA1_DIGEST_LENGTH];
char *tampon;
int n;

tampon = "abc";
n = strlen(tampon);
SHA1Init(&sha);
SHA1Update(&sha, (uint8_t *)tampon, n);
SHA1Final(résultats, &sha);

/* Afficher le résumé sous forme d'une seule longue valeur hexadécimale */
printf("0x");
for (n = 0; n < SHA1_DIGEST_LENGTH; n++)
	printf("%02x", résultats[n]);
putchar('\n');

Alternativement, les fonctions auxiliaires pourraient être utilisées de la manière suivante :

uint8_t sortie[SHA1_DIGEST_STRING_LENGTH];
char *tampon = "abc";

printf("0x%s\n", SHA1Data(tampon, strlen(tampon), sortie));

AUTEURS

Cette implémentation de SHA-1 a été écrite par Steve Reid.

Les fonctions d'aide SHA1End(), SHA1File(), SHA1FileChunk(), et SHA1Data() sont dérivées de code écrit par Poul-Henning Kamp.

ATTENTION

Cette implémentation de SHA-1 n'a pas été validée par le NIST et n'est donc pas officiellement conforme à la norme.

Si un résumé de message doit être copié dans un type multi-octets (c'est-à-dire un tableau de cinq entiers de 32 bits), il sera nécessaire d'effectuer un échange d'octets sur les machines little-endian telles que les i386, alpha et vax.
