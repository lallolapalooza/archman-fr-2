shmem_long_set(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONG_SET(3) Open MPI SHMEM_LONG_SET(3)

shmem_double_set(3), shmem_float_set(3), shmem_int_set(3), shmem_long_set(3), shmem_longlong_set(3) shmem_int4_set(3), shmem_int8_set(3), shmem_real4_set(3), shmem_real8_set(3), - Définit atomiquement la valeur d'un objet de données distant

SYNOPSIS

C ou C++ :

#include <mpp/shmem.h>
void shmem_double_set(double *target, double value, int pe)
void shmem_float_set(float *target, float value, int pe)
void shmem_int_set(int *target, int value, int pe)
void shmem_long_set(long *target, long value, int pe)
void shmem_longlong_set(long long *target, long long value, int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER pe
CALL SHMEM_INT4_SET(target, value, pe)
CALL SHMEM_INT8_SET(target, value, pe)
CALL SHMEM_REAL4_SET(target, value, pe)
CALL SHMEM_REAL8_SET(target, value, pe)

DESCRIPTION

Les routines de définition écrivent la value dans l'adresse target sur le pe en tant qu'opération atomique.

Les arguments sont les suivants :

target
L'objet de données accessible à distance à définir sur le PE distant.
value
La valeur à écrire atomiquement sur le PE distant.
pe
Un entier qui indique le numéro du PE sur lequel target doit être mis à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
