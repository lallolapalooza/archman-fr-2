RANLIB(1) Outils de développement GNU RANLIB(1)

NOM

ranlib - générer un index pour une archive

SYNTAXE

ranlib [--plugin nom] [-DhHvVt] archive

DESCRIPTION

ranlib génère un index du contenu d'une archive et le stocke dans l'archive. L'index liste chaque symbole défini par un membre d'une archive qui est un fichier objet redistribuable.

Vous pouvez utiliser nm -s ou nm --print-armap pour lister cet index.

Une archive avec un tel index accélère la liaison à la bibliothèque et permet aux routines de la bibliothèque de s'appeler mutuellement sans tenir compte de leur placement dans l'archive.

Le programme GNU ranlib est une autre forme de GNU ar ; l'exécution de ranlib est complètement équivalente à l'exécution de ar -s.

OPTIONS

-h
-H
--help
Afficher les informations d'utilisation pour ranlib.
-v
-V
--version
Afficher le numéro de version de ranlib.
-D
Fonctionner en mode déterministe. L'en-tête du membre d'archive de la carte des symboles affichera zéro pour l'UID, le GID et l'horodatage. Lorsque cette option est utilisée, plusieurs exécutions produiront des fichiers de sortie identiques.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, décrite ci-dessous.

-t
Mettre à jour l'horodatage de la carte des symboles d'une archive.
-U
Ne pas fonctionner en mode déterministe. C'est l'inverse de l'option -D, ci-dessus : l'index de l'archive obtiendra les valeurs réelles d'UID, de GID, d'horodatage et de mode de fichier.

Si binutils a été configuré sans --enable-deterministic-archives, alors ce mode est activé par défaut.

@fichier
Lire les options de la ligne de commande à partir de fichier. Les options lues sont insérées à la place de l'option @fichier originale. Si fichier n'existe pas ou ne peut pas être lu, alors l'option sera traitée littéralement et ne sera pas supprimée.

Les options dans fichier sont séparées par des espaces. Un caractère d'espacement peut être inclus dans une option en entourant l'option entière entre guillemets simples ou doubles. Tout caractère (y compris une barre oblique inverse) peut être inclus en faisant précéder le caractère à inclure d'une barre oblique inverse. Le fichier peut lui-même contenir des options @fichier supplémentaires ; toutes ces options seront traitées récursivement.
