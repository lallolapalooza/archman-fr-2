NOM

shlock - Créer des fichiers de verrouillage pour utilisation dans des scripts shell

SYNTAXE

shlock [-b|-c|-u] -f nom -p pid

DESCRIPTION

shlock tente de créer un fichier de verrouillage nommé nom et d'y écrire l'identifiant de processus pid. Si le fichier existe déjà, shlock lira l'identifiant de processus à partir du fichier et vérifiera si le processus est actuellement en cours d'exécution. Si le processus existe, alors le fichier ne sera pas créé. shlock se termine avec un statut zéro s'il a pu créer le fichier de verrouillage, ou non nul si le fichier fait référence à un processus actuellement actif.

Un wrapper Perl pour shlock peut être utilisé via le module "INN::Utils::Shlock".

OPTIONS

-b
Les identifiants de processus sont normalement lus et écrits en ASCII. Si l'option -b est utilisée, alors ils seront écrits comme un entier binaire.
-c
Si l'option -c est utilisée, alors shlock ne créera pas de fichier de verrouillage, mais utilisera plutôt le fichier pour vérifier si le verrouillage est détenu par un autre programme. Si le verrouillage est valide, le programme se terminera avec un statut non nul ; si le verrouillage n'est pas valide (c'est-à-dire que l'invocation de shlock sans l'option aurait réussi), alors le programme se terminera avec un statut zéro.
-f nom
nom est le nom du fichier de verrouillage que shlock tente de créer. Si le fichier existe déjà, il lira l'identifiant de processus à partir du fichier et se terminera avec un statut non nul si ce processus est actuellement actif.
-p pid
pid est l'identifiant de processus à écrire dans le fichier nom.
-u
Pour la compatibilité avec d'autres systèmes, l'option -u est acceptée comme un synonyme de -b étant donné que les verrous binaires sont utilisés par de nombreux paquets UUCP.

EXEMPLES

L'exemple suivant montre comment shlock serait utilisé dans un script shell :

LOCK=<chemin d'exécution dans inn.conf>/LOCK.send
trap 'rm -f ${LOCK} ; exit 1' 1 2 3 15
if shlock -p $$ -f ${LOCK} ; then
    # Effectuer le travail approprié.
else
    echo "Verrouillé par `cat ${LOCK}`"
fi
