NOM

sharesec - Définir ou obtenir les ACL de partage

SYNTAXE

sharesec {nom_partage} [-r, --remove=ACL] [-m, --modify=ACL] [-a, --add=ACL] [-R, --replace=ACLs] [-D, --delete] [-v, --view] [--view-all] [-M, --machine-sid] [-F, --force] [-d, --debuglevel=NIVEAU_DEBOGAGE] [-s, --configfile=FICHIER_CONFIG] [-l, --log-basename=FICHIER_JOURNAL] [-S, --setsddl=CHAINE] [--viewsddl] [-?|--help] [--usage] [-d|--debuglevel=NIVEAU_DEBOGAGE] [--debug-stdout] [--configfile=FICHIER_CONFIG] [--option=nom=valeur] [-l|--log-basename=FICHIER_JOURNAL] [--leak-report] [--leak-report-full]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

Le programme sharesec manipule les permissions des partages sur les partages de fichiers SMB.

OPTIONS

Les options suivantes sont disponibles pour le programme sharesec. Le format des ACL est décrit dans la section FORMAT DES ACL

-a|--add=ACL

Ajoute les ACE spécifiés à la liste des ACL.

-D|--delete

Supprime le descripteur de sécurité entier.

-F|--force

Force le stockage de l'ACL.

-m|--modify=ACL

Modifie les ACE existants.

-M|--machine-sid

Initialise le SID de la machine.

-r|--remove=ACL

Supprime les ACE.

-R|--replace=ACLS

Remplace une ACL de permission de partage existante.

-v|--view

Liste une ACL de partage

--view-all

Liste toutes les ACL de partage

-S|--setsddl=CHAINE

Définit le descripteur de sécurité en fournissant l'ACL au format SDDL.

--viewsddl

Liste une ACL de partage au format SDDL.

-?|--help

Affiche un résumé des options de ligne de commande.

--usage

Affiche un bref message d'utilisation.

-d|--debuglevel=niveau

niveau est un entier compris entre 0 et 10. La valeur par défaut si ce paramètre n'est pas spécifié est 1 pour les applications client.

Plus cette valeur est élevée, plus les détails seront enregistrés dans les fichiers journaux sur les activités du serveur. Au niveau 0, seuls les erreurs critiques et les avertissements sérieux seront enregistrés. Le niveau 1 est un niveau raisonnable pour une utilisation quotidienne - il génère une petite quantité d'informations sur les opérations effectuées.

Les niveaux supérieurs à 1 généreront une quantité considérable de données de journalisation et ne devraient être utilisés que lors de l'investigation d'un problème. Les niveaux supérieurs à 3 sont conçus pour être utilisés uniquement par les développeurs et génèrent d'énormes quantités de données de journalisation, dont la plupart sont extrêmement cryptiques.

Notez que la spécification de ce paramètre remplacera le paramètre log level du fichier /etc/samba/smb.conf.

--debug-stdout

Redirige la sortie de débogage vers STDOUT. Par défaut, tous les clients écrivent sur STDERR.

--configfile=<fichier de configuration>

Le fichier spécifié contient les détails de configuration requis par le client. Les informations de ce fichier peuvent être générales pour le client et le serveur ou uniquement fournir des options spécifiques au client telles que client smb encrypt. Voir /etc/samba/smb.conf pour plus d'informations. Le nom du fichier de configuration par défaut est déterminé au moment de la compilation.

--option=<nom>=<valeur>

Définit l'option smb.conf(5) "<nom>" à la valeur "<valeur>" depuis la ligne de commande. Ceci remplace les valeurs par défaut compilées et les options lues dans le fichier de configuration. Si un nom ou une valeur contient un espace, entourez l'ensemble --option=nom=valeur de guillemets.

-l|--log-basename=repertoire_journal

Nom de base du répertoire pour les fichiers journaux/de débogage. L'extension ".progname" sera ajoutée (par exemple, log.smbclient, log.smbd, etc...). Le fichier journal n'est jamais supprimé par le client.

--leak-report

Active le rapport de fuite talloc à la sortie.

--leak-report-full

Active le rapport complet de fuite talloc à la sortie.

-V|--version

Affiche le numéro de version du programme.

FORMAT DES ACL

Le format d'une ACL est une ou plusieurs entrées d'ACL séparées par des virgules ou des nouvelles lignes. Une entrée d'ACL est l'une des suivantes :

REVISION:<numéro de révision>
PROPRIETAIRE:<sid ou nom>
GROUPE:<sid ou nom>
ACL:<sid ou nom>:<type>/<indicateurs>/<masque>

La révision de l'ACL spécifie la révision interne de l'ACL Windows NT pour le descripteur de sécurité. Si elle n'est pas spécifiée, elle vaut 1 par défaut. L'utilisation de valeurs autres que 1 peut entraîner un comportement inhabituel.

Le propriétaire et le groupe spécifient les SIDs du propriétaire et du groupe pour l'objet. Les ACL de partage ne spécifient pas de propriétaire ni de groupe, donc ces champs sont vides.

Les ACL spécifient les permissions accordées au SID. Ce SID peut être spécifié au format S-1-x-y-z ou sous forme de nom, auquel cas il est résolu par rapport au serveur sur lequel le fichier ou le répertoire réside. Les valeurs de type, d'indicateurs et de masque déterminent le type d'accès accordé au SID.

Le type peut être ALLOWED ou DENIED pour autoriser/refuser l'accès au SID. Les valeurs des indicateurs sont généralement nulles pour les ACL de partage.

Le masque est une valeur qui exprime le droit d'accès accordé au SID. Il peut être donné sous forme de valeur décimale ou hexadécimale, ou en utilisant l'une des chaînes de caractères suivantes qui correspondent aux permissions de fichiers NT du même nom.

•R - Autoriser l'accès en lecture
•W - Autoriser l'accès en écriture
•X - Autorisation d'exécution sur l'objet
•D - Supprimer l'objet
•P - Modifier les permissions
•O - Prendre possession

Les permissions combinées suivantes peuvent être spécifiées :

•READ - Équivalent aux permissions 'RX'
•CHANGE - Équivalent aux permissions 'RXWD'
•FULL - Équivalent aux permissions 'RWXDPO'

STATUT DE SORTIE

Le programme sharesec définit le statut de sortie en fonction du succès ou de l'échec des opérations effectuées. Le statut de sortie peut être l'une des valeurs suivantes.

Si l'opération a réussi, sharesec retourne un statut de sortie de 0. Si sharesec n'a pas pu se connecter au serveur spécifié, ou s'il y a eu une erreur lors de l'obtention ou de la définition des ACL, un statut de sortie de 1 est retourné. S'il y a eu une erreur lors de l'analyse des arguments de la ligne de commande, un statut de sortie de 2 est retourné.

EXEMPLES

Ajouter un accès complet pour le SID S-1-5-21-1866488690-1365729215-3963860297-17724 sur share :

host:~ # sharesec share -a S-1-5-21-1866488690-1365729215-3963860297-17724:ALLOWED/0/FULL

Lister toutes les ACE pour share :

host:~ # sharesec share -v
REVISION:1
CONTROL:SR|DP
OWNER:
GROUP:
ACL:S-1-1-0:ALLOWED/0x0/FULL
ACL:S-1-5-21-1866488690-1365729215-3963860297-17724:ALLOWED/0x0/FULL
