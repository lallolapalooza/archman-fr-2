shmem_long_add(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONG_ADD(3) Open MPI SHMEM_LONG_ADD(3)

shmem_int_add(3), shmem_int4_add(3), shmem_int8_add(3), shmem_long_add(3), shmem_longlong_add(3) - Effectue une opération d'addition atomique.

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
void shmem_int_add(int *cible, int valeur, int pe)
void shmem_long_add(long *cible, long valeur, int pe)
void shmem_longlong_add(long long *cible, long long valeur,
  int pe)

Fortran :

include 'mpp/shmem.h'
INTEGER pe
CALL SHMEM_INT4_ADD(cible, valeur, pe)
CALL SHMEM_INT8_ADD(cible, valeur, pe)

DESCRIPTION

Les routines d'addition atomique ajoutent valeur aux données à l'adresse cible sur le PE pe. L'opération s'achève sans possibilité qu'un autre processus mette à jour cible entre le moment de la lecture et la mise à jour.

Les arguments sont les suivants :

cible
L'objet de données entier accessible à distance à mettre à jour sur le PE distant. Si vous utilisez C/C++, le type de cible doit correspondre à celui implicite dans la section SYNTAXE. Si vous utilisez le compilateur Fortran, il doit être de type entier avec une taille d'élément de 4 octets pour SHMEM_INT4_ADD et de 8 octets pour SHMEM_INT8_ADD.
valeur
La valeur à ajouter atomiquement à cible. Si vous utilisez C/C++, le type de valeur doit correspondre à celui implicite dans la section SYNTAXE. Si vous utilisez Fortran, il doit être de type entier avec une taille d'élément de cible.
pe
Un entier qui indique le numéro du PE sur lequel cible doit être mis à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

NOTES

Le terme "accessible à distance" est défini dans intro_shmem(3).
