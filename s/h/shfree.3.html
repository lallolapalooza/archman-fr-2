shmem_malloc(3), shmem_free(3), shmem_align(3), shmem_realloc(3) shmalloc(3), shfree(3), shmemalign(3), shrealloc(3) - Fonctions de gestion de la mémoire du tas symétrique.

SYNTAXE

En C ou C++ :

#include <mpp/shmem.h>
void *shmem_malloc(size_t size)
void *shmalloc(size_t size)
void shmem_free(void *ptr)
void shfree(void *ptr)
void *shmem_realloc(void *ptr, size_t size)
void *shrealloc(void *ptr, size_t size)
void *shmem_align(size_t alignment, size_t size)
void *shmemalign(size_t alignment, size_t size)
extern long malloc_error

DESCRIPTION

La fonction shmem_malloc renvoie un pointeur vers un bloc d'au moins taille octets, correctement aligné pour tout usage. Cet espace est alloué depuis le tas symétrique (contrairement à malloc(3), qui alloue depuis le tas privé).

La fonction shmem_align alloue un bloc dans le tas symétrique qui a un alignement en octets spécifié par l'argument alignment.

La fonction shmem_free libère le bloc pointé par ptr, c'est-à-dire le rend disponible pour des allocations ultérieures. Si ptr est un pointeur nul, aucune action n'est effectuée ; sinon, si l'argument ne correspond pas à un pointeur précédemment retourné par une fonction du tas symétrique, ou si l'espace a déjà été libéré, malloc_error est défini pour indiquer l'erreur, et shfree retourne.

La fonction shmem_realloc modifie la taille du bloc pointé par ptr à la taille (en octets) spécifiée par size.

Le contenu du bloc reste inchangé jusqu'au minimum entre la nouvelle et l'ancienne taille. Si la nouvelle taille est plus grande, la valeur de la portion nouvellement allouée du bloc est indéterminée. Si ptr est un pointeur nul, la fonction shrealloc se comporte comme la fonction shmalloc pour la taille spécifiée. Si size est 0 et ptr n'est pas un pointeur nul, le bloc pointé est libéré. Sinon, si ptr ne correspond pas à un pointeur précédemment retourné par une fonction du tas symétrique, ou si l'espace a déjà été libéré, la variable malloc_error est définie pour indiquer l'erreur, et shrealloc retourne un pointeur nul. Si l'espace ne peut pas être alloué, le bloc pointé par ptr reste inchangé.

Les fonctions shmem_malloc, shmem_free et shmem_realloc sont fournies afin que plusieurs PEs dans une application puissent allouer des blocs de mémoire symétriques et accessibles à distance. Ces blocs de mémoire peuvent ensuite être utilisés avec les routines de communication (shmem). Chacune de ces fonctions appelle la fonction shmem_barrier_all(3) avant de retourner ; cela garantit que tous les PEs participent à l'allocation mémoire, et que la mémoire des autres PEs peut être utilisée dès que le PE local retourne.

L'utilisateur est responsable de l'appel de ces fonctions avec des arguments identiques sur tous les PEs ; si des arguments de taille différents sont utilisés, les appels ultérieurs peuvent ne pas retourner la même adresse de tas symétrique sur tous les PEs.

NOTES

La taille totale du tas symétrique est déterminée au démarrage du job. Il est possible d'ajuster la taille du tas en utilisant la variable d'environnement SHMEM_SYMMETRIC_HEAP_SIZE. Voir la page de manuel intro_shmem(3) pour plus de détails. Les fonctions shmem_malloc, shmem_free et shmem_realloc diffèrent des fonctions d'allocation de tas privé en ce sens que tous les PEs d'une application doivent les appeler (une barrière est utilisée pour s'en assurer).

VALEURS DE RETOUR

La fonction shmem_malloc retourne un pointeur vers l'espace alloué (qui devrait être identique sur tous les PEs) ; sinon, elle retourne un pointeur nul (avec malloc_error défini). La fonction shmem_free ne retourne aucune valeur. La fonction shmem_realloc retourne un pointeur vers l'espace alloué (qui peut avoir changé de place) ; sinon, elle retourne un pointeur nul (avec malloc_error défini).
