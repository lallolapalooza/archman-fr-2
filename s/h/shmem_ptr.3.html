shmem_ptr(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_PTR(3) Open MPI SHMEM_PTR(3)

Retourne un pointeur vers un objet de données sur un élément de traitement (PE) spécifié.

SYNTOPSIS

C ou C++ :

#include <mpp/shmem.h>
void *shmem_ptr(const void *target, int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
POINTER (PTR, POINTEE)
INTEGER pe
PTR = SHMEM_PTR(target, pe)

DESCRIPTION

La routine shmem_ptr retourne une adresse qui peut être utilisée pour référencer directement target sur le PE distant pe. Avec cette adresse, nous pouvons effectuer des lectures et écritures ordinaires sur l'adresse distante.

Lorsqu'une séquence de lectures (gets) et écritures (puts) vers un objet de données sur un PE distant ne correspond pas au schéma d'accès fourni dans une routine de transfert de données SHMEM telle que shmem_put32(3) ou shmem_real_iget(3), la fonction shmem_ptr peut fournir un moyen efficace d'accomplir la communication.

Les arguments sont les suivants :

target
L'objet de données symétrique à référencer.
pe
Un entier qui indique le numéro du PE sur lequel target doit être accédé. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

EXEMPLES

Ce programme Fortran appelle shmem_ptr, puis le PE 0 écrit dans le tableau BIGD sur le PE 1 :

PROGRAM REMOTEWRITE
  INCLUDE 'mpp/shmem.fh'
  INTEGER BIGD(100)
  SAVE BIGD
  INTEGER POINTEE(*)
  POINTER (PTR,POINTEE)
  CALL START_PES(0)
  IF (MY_PE() .EQ. 0) THEN
                             ! initialiser le tableau BIGD du PE 1
    PTR = SHMEM_PTR(BIGD, 1) ! obtenir l'adresse du tableau BIGD du PE 1
                             !
    DO I=1,100
      POINTEE(I) = I
    ENDDO
  ENDIF
  CALL SHMEM_BARRIER_ALL
  IF (MY_PE() .EQ. 1) THEN
    PRINT *, 'BIGD sur le PE 1 est : '
    PRINT *, BIGD
  ENDIF
END

Ceci est le programme équivalent écrit en C :

#include <mpp/shmem.h>
main()
{
  static int bigd[100];
  int *ptr;
  int i;
  shmem_init();
  if (shmem_my_pe() == 0) {
  /* initialiser le tableau bigd du PE 1 */
    ptr = shmem_ptr(bigd, 1);
    for (i=0; i<100; i++)
      *ptr++ = i+1;
  }
  shmem_barrier_all();
  if (shmem_my_pe() == 1) {
    printf("bigd sur le PE 1 est :\n");
    for (i=0; i<100; i++)
      printf(" %d\n",bigd[i]);
    printf("\n");
  }
}

NOTES

La fonction shmem_ptr n'est disponible que sur les systèmes où les lectures et écritures de mémoire ordinaires sont utilisées pour implémenter les opérations put et get SHMEM.

VALEURS DE RETOUR

shmem_ptr retourne un pointeur vers l'objet de données sur le PE distant spécifié. Si target n'est pas accessible à distance, un pointeur NULL est retourné.
