shmem_info_get_version - Renvoie la version majeure et mineure de l'implémentation de la bibliothèque.

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
void shmem_info_get_version(int *major, int *minor)

Fortran :

include 'mpp/shmem.fh'
SHMEM_INFO_GET_VERSION(MAJOR, MINOR)
INTEGER MAJOR, MINOR

DESCRIPTION

shmem_info_get_version() Cette routine renvoie la version majeure et mineure de la norme OpenSHMEM utilisée. Pour une implémentation de bibliothèque donnée, la version majeure et mineure renvoyée par ces appels est cohérente avec les constantes de compilation, SHMEM_MAJOR_VERSION et SHMEM_MINOR_VERSION, définies dans son shmem.h. La valeur valide pour la version majeure est 1, et la valeur valide pour la version mineure est 2.
