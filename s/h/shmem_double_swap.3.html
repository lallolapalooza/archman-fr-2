shmem_double_swap(3)

SHMEM_DOUBLE_SWAP(3) Open MPI SHMEM_DOUBLE_SWAP(3)

shmem_double_swap(3), shmem_float_swap(3), shmem_int_swap(3), shmem_long_swap(3), shmem_swap(3), shmem_int4_swap(3), shmem_int8_swap(3), shmem_real4_swap(3), shmem_real8_swap(3), shmem_longlong_swap(3) - Effectue un échange atomique vers un objet de données distant

SYNTAXIS

C ou C++ :

#include <mpp/shmem.h>
double shmem_double_swap(double *target, double value,
  int pe)
float shmem_float_swap(float *target, float value, int pe)
int shmem_int_swap(int *target, int value, int pe)
long shmem_long_swap(long *target, long value, int pe)
long long shmem_longlong_swap(long long *target,
  long long value, int pe)
long shmem_swap(long *target, long value, int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER SHMEM_SWAP
ires = SHMEM_SWAP(target, value, pe)
INTEGER(KIND=4) SHMEM_INT4_SWAP
ires = SHMEM_INT4_SWAP(target, value, pe)
INTEGER(KIND=8) SHMEM_INT8_SWAP
ires = SHMEM_INT8_SWAP(target, value, pe)
REAL(KIND=4) SHMEM_REAL4_SWAP
res = SHMEM_REAL4_SWAP(target, value, pe)
REAL(KIND=8) SHMEM_REAL8_SWAP
res = SHMEM_REAL8_SWAP(target, value, pe)

DESCRIPTION

Les routines d'échange atomique écrivent value à l'adresse target sur la PE pe, et retournent le contenu précédent de target en une seule opération atomique.

Les arguments sont les suivants :

target
L'objet de données entier accessible à distance à mettre à jour sur la PE distante. Si vous utilisez C/C++, le type de target doit correspondre à celui impliqué dans la section SYNTAXIS. Si vous utilisez Fortran, il doit être du type suivant :

SHMEM_SWAP : Entier de type par défaut

SHMEM_INT4_SWAP : Entier de 4 octets

SHMEM_INT8_SWAP : Entier de 8 octets

SHMEM_REAL4_SWAP : Réel de 4 octets

SHMEM_REAL8_SWAP : Réel de 8 octets

value
Valeur à écrire atomiquement sur la PE distante. value est du même type que target.
pe
Un entier qui indique le numéro de la PE sur laquelle target doit être mise à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

NOTES

Le terme « accessible à distance » est défini dans intro_shmem(3).

VALEURS DE RETOUR

Le contenu qui se trouvait à l'adresse cible sur la PE distante avant l'échange est retourné.
