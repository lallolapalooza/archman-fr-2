Documentation de la fonction/sous-programme

sous-programme shst01 (entier n, entier ilo, entier ihi, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldh, * ) h, entier ldh, réel, dimension( ldq, * ) q, entier ldq, réel, dimension( lwork ) work, entier lwork, réel, dimension( 2 ) result)

SHST01

Objectif:

!>
!> SHST01 teste la réduction d'une matrice générale A à la forme
!> d'Hessenberg supérieure : A = Q*H*Q'. Deux rapports de test sont calculés ;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> La matrice Q est supposée être donnée explicitement comme elle le serait
!> après SGEHRD + SORGHR.
!>
!> Dans cette version, ILO et IHI ne sont pas utilisés et sont supposés être 1 et
!> N, respectivement.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>
!>          A est supposée être triangulaire supérieure dans les lignes et colonnes
!>          1:ILO-1 et IHI+1:N, donc Q diffère de l'identité uniquement dans
!>          les lignes et colonnes ILO+1:IHI.
!>

A

!>          A est un tableau RÉEL, dimension (LDA,N)
!>          La matrice originale A de taille n par n.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

H

!>          H est un tableau RÉEL, dimension (LDH,N)
!>          La matrice d'Hessenberg supérieure H issue de la réduction A = Q*H*Q'
!>          telle que calculée par SGEHRD. H est supposée être nulle en dessous
!>          de la première sous-diagonale.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

Q

!>          Q est un tableau RÉEL, dimension (LDQ,N)
!>          La matrice orthogonale Q issue de la réduction A = Q*H*Q' telle que
!>          calculée par SGEHRD + SORGHR.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau RÉEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.  LWORK >= 2*N*N.
!>

RESULT

!>          RESULT est un tableau RÉEL, dimension (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
