NOM

shy - lanceur ssh minimaliste

SYNOPIS

shy [OPTIONS]

DESCRIPTION

shy est une petite interface utilisateur en console pour se connecter rapidement à un serveur ssh. Il analyse votre fichier `~/.ssh/config` et affiche tous vos modèles "Host", vous permettant d'en sélectionner rapidement un à l'aide d'une invite de commande de type readline.

Habituellement, shy est lancé sans option :

shy

Pour vous connecter plus rapidement à un hôte, vous pourriez vouloir lancer en mode recherche :

shy -s

Si vous souhaitez utiliser un fichier de configuration autre que `~/.ssh/config`, vous pouvez passer un chemin en utilisant les options `-c` ou `--config`.

OPTIONS

-c, --config FICHIER

Utiliser FICHIER à la place de ~/.ssh/config

-h, --help

Afficher un résumé de l'aide et quitter.

-v, --version

Afficher les informations de version et quitter.

NOTES

Si aucun fichier de configuration n'est trouvé, shy échouera au démarrage.

NAVIGATION

shy possède deux modes : le mode Navigation et le mode Recherche. Par défaut, le programme est en mode Navigation - une simple vue de liste qui vous permet de déplacer votre hôte sélectionné vers le haut ou vers le bas.

En appuyant sur `i`, `s`, `f`, ou `/`, le programme entre en mode Recherche, vous permettant de sauter rapidement vers un hôte en tapant le début de son nom.

RACCOURCIS CLAVIER MODE NAV

q, Esc, Ctrl-c

Quitter shy.

Flèche haut, Ctrl-p, k

Sélectionner l'hôte précédent dans la liste.
Flèche bas, Ctrl-n, j
Sélectionner l'hôte suivant dans la liste.
Page Down, Barre d'espace
Sauter de cinq entrées vers le bas.
Page Up, -
Sauter de cinq entrées vers le haut.

Entrée

Se connecter à l'hôte sélectionné.

i, s, /, f

Entrer en mode recherche.
r, F5
Actualiser la vue.

RACCOURCIS CLAVIER MODE RECHERCHE

Esc, Ctrl-c

Effacer l'entrée, puis quitter le mode Recherche.

Flèche haut, Ctrl-p, k

Sélectionner l'hôte correspondant précédent.
Flèche bas, Ctrl-n, j
Sélectionner l'hôte correspondant suivant.

Entrée

Se connecter à l'hôte sélectionné.
