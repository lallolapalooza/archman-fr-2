NOM

readelf - affiche les informations sur les fichiers ELF

SYNTAXE

DESCRIPTION

readelf affiche des informations sur un ou plusieurs fichiers objets au format ELF. Les options contrôlent quelles informations spécifiques afficher.

fichier_elf... sont les fichiers objets à examiner. Les fichiers ELF 32 bits et 64 bits sont supportés, ainsi que les archives contenant des fichiers ELF.

Ce programme remplit une fonction similaire à objdump mais il va plus en détail et il est indépendant de la bibliothèque BFD, donc s'il y a un bug dans BFD, readelf ne sera pas affecté.

OPTIONS

Les formes longues et courtes des options, présentées ici comme des alternatives, sont équivalentes. Au moins une option autre que -v ou -H doit être donnée.

-a
--all
Équivaut à spécifier --file-header, --program-headers, --sections, --symbols, --relocs, --dynamic, --notes, --version-info, --arch-specific, --unwind, --section-groups et --histogram.

Notez que cette option n'active pas --use-dynamic elle-même, donc si cette option n'est pas présente sur la ligne de commande, les symboles dynamiques et les relocalisations dynamiques ne seront pas affichés.

-h
--file-header
Affiche les informations contenues dans l'en-tête ELF au début du fichier.
-l
--program-headers
--segments
Affiche les informations contenues dans les en-têtes de segment du fichier, s'il en a.
--quiet
Supprime le message diagnostique "pas de symboles".
-S
--sections
--section-headers
Affiche les informations contenues dans les en-têtes de section du fichier, s'il en a.
-g
--section-groups
Affiche les informations contenues dans les groupes de sections du fichier, s'il en a.
-t
--section-details
Affiche les informations détaillées sur les sections. Implique -S.
-s
--symbols
--syms
Affiche les entrées dans la table des symboles du fichier, s'il en a une. Si un symbole a des informations de version associées, elles sont également affichées. La chaîne de version est affichée en suffixe du nom du symbole, précédée d'un caractère @. Par exemple, foo@VER_1. Si la version est la version par défaut utilisée lors de la résolution des références non versionnées au symbole, elle est affichée en suffixe précédée de deux caractères @. Par exemple, foo@@VER_2.
--dyn-syms
Affiche les entrées dans la table des symboles dynamiques du fichier, s'il en a une. Le format de sortie est le même que celui utilisé par l'option --syms.
--lto-syms
Affiche le contenu des tables de symboles LTO dans le fichier.
--sym-base=[0|8|10|16]
Force le champ de taille de la table des symboles à utiliser la base donnée. Toute option non reconnue sera traitée comme 0. --sym-base=0 représente le comportement par défaut et hérité. Il affichera les tailles en décimal pour les nombres inférieurs à 100000. Pour les tailles égales ou supérieures à 100000, la notation hexadécimale sera utilisée avec un préfixe 0x. --sym-base=8 affichera les tailles des symboles en octal. --sym-base=10 affichera toujours les tailles des symboles en décimal. --sym-base=16 affichera toujours les tailles des symboles en hexadécimal avec un préfixe 0x.
-C
--demangle[=style]
Décoder (demangle) les noms de symboles de bas niveau en noms de haut niveau. Cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de mangling. L'argument optionnel de style de décodage peut être utilisé pour choisir un style de décodage approprié pour votre compilateur.
--no-demangle
Ne pas décoder les noms de symboles de bas niveau. C'est le comportement par défaut.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite sur la quantité de récursion effectuée lors du décodage des chaînes. Comme les formats de mangling de noms permettent un niveau de récursion infini, il est possible de créer des chaînes dont le décodage épuisera l'espace de pile disponible sur la machine hôte, provoquant une erreur mémoire. La limite tente d'empêcher cela en restreignant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais sa désactivation peut être nécessaire pour décoder des noms vraiment compliqués. Notez cependant que si la limite de récursion est désactivée, l'épuisement de la pile est possible et tout rapport de bug concernant un tel événement sera rejeté.

-U méthode
--unicode=méthode
Utilise la méthode spécifiée pour encoder les chaînes Unicode lors de l'affichage des informations. Les méthodes possibles sont none, locale, utf8, utf16, utf32. La méthode par défaut est locale.
-X
--extra-sym-info
--no-extra-sym-info
Affiche des informations supplémentaires sur les symboles, telles que les types de symboles et les informations sur les variables globales. Par défaut, ces informations ne sont pas affichées.
-n
--notes
Affiche les sections de notes du fichier ELF. Les notes sont des blocs de données spécifiques au système qui peuvent contenir des informations utiles pour le débogage ou la configuration.
-r
--relocs
Affiche les informations de relocalisation du fichier ELF. Les relocalisations indiquent comment les symboles référencés par le fichier doivent être liés à leur adresse réelle lors de l'exécution.
-u
--unwind
Affiche les informations de "unwinding" (déroulement de pile) du fichier ELF. Ces informations sont utilisées pour reconstruire la pile d'appels lors d'une exception ou d'un crash.
-d
--dynamic
Affiche les informations de la section dynamique du fichier ELF. Cette section contient des informations utilisées par le lieur dynamique lors de l'exécution.
-V
--version-info
Affiche les informations de version du fichier ELF. Cela inclut les versions requises et fournies par le fichier.
-A
--arch-specific
Affiche les informations spécifiques à l'architecture du fichier ELF. Cela peut inclure des drapeaux ou des extensions propres à l'architecture.
-D
--use-dynamic
Lors de l'affichage des symboles, utilise la table des symboles dynamiques au lieu de la table des symboles standard. Ceci est utile pour examiner les fichiers qui ne contiennent pas de table des symboles standard, comme les binaires finaux.
-L
--lint
--enable-checks
Effectue des vérifications de conformité sur le fichier ELF et signale toutes les erreurs ou avertissements détectés.
-x <nombre ou nom>
--hex-dump=<nombre ou nom>
Affiche le contenu hexadécimal d'une section spécifiée par son numéro ou son nom. Si la section est spécifiée par son nom, elle doit être précédée de '.'. Par exemple, -x .text.
-p <nombre ou nom>
--string-dump=<nombre ou nom>
Affiche les chaînes de caractères contenues dans une section spécifiée par son numéro ou son nom. Utile pour extraire les chaînes de débogage ou les chaînes de ressources.
-R <nombre ou nom>
--relocated-dump=<nombre ou nom>
Affiche les informations de relocalisation d'une section spécifiée par son numéro ou son nom. Utile pour comprendre comment les symboles sont liés dans une section spécifique.
-z
--decompress
Tente de décompresser les sections compressées du fichier ELF. Ceci est utile pour examiner le contenu des sections qui ont été compressées pour réduire la taille du fichier.
-c
--archive-index
Affiche l'index d'archive du fichier. Ceci est pertinent pour les fichiers d'archive (comme les bibliothèques statiques) qui contiennent un index pour accéder rapidement aux membres.
-w[lLiaprmfFsoORtUuTgAck]
--debug-dump[=rawline,=decodedline,=info,=abbrev,=pubnames,=aranges,=macro,=frames,=frames-interp,=str,=str-offsets,=loc,=Ranges,=pubtypes,=trace_info,=trace_abbrev,=trace_aranges,=gdb_index,=addr,=cu_index,=links]
Affiche les informations de débogage contenues dans le fichier ELF. Les différentes lettres ou noms spécifient quels types d'informations de débogage afficher (par exemple, lignes de code source, informations DWARF, table des chaînes, etc.).
-wK
--debug-dump=follow-links
Lors de l'affichage des informations de débogage, suit les liens symboliques (par exemple, entre les unités de compilation).
-wN
--debug-dump=no-follow-links
Lors de l'affichage des informations de débogage, ne suit pas les liens symboliques. C'est le comportement par défaut.
-wD
--debug-dump=use-debuginfod
Utilise le service `debuginfod` pour récupérer les informations de débogage manquantes.
-wE
--debug-dump=do-not-use-debuginfod
Ne pas utiliser le service `debuginfod` pour récupérer les informations de débogage. C'est le comportement par défaut.
-P
--process-links
Traite les liens symboliques dans les informations de débogage (par exemple, pour les tables de liens DWARF).
--dwarf-depth=n
Définit la profondeur maximale de récursion pour l'analyse des informations DWARF.
--dwarf-start=n
Définit l'unité de compilation DWARF à partir de laquelle commencer l'analyse.
--ctf=section
Spécifie la section contenant les données CTF (Common Type Format) à analyser.
--ctf-parent=section
Spécifie la section parente pour les données CTF.
--ctf-symbols=section
Spécifie la section contenant les symboles CTF.
--ctf-strings=section
Spécifie la section contenant les chaînes CTF.
--sframe=section
Spécifie la section contenant les informations `sframe` (Common Frame Information).
-I
--histogram
Affiche un histogramme de la distribution des tailles des sections. Ceci peut être utile pour identifier les sections volumineuses ou anormales.
-v
--version
Affiche la version de l'outil et quitte.
-W
--wide
Affiche les informations dans un format plus large, utile pour les écrans avec une largeur plus importante.
-T
--silent-truncation
Supprime les messages indiquant que des chaînes ont été tronquées lors de l'affichage.
-H
--help
Affiche un message d'aide et quitte.
-U [d|i|l|e|x|h]
--unicode=[default|invalid|locale|escape|hex|highlight]
Contrôle l'affichage des caractères non-ASCII dans les noms d'identifiants. Par défaut (--unicode=locale ou --unicode=default), ils sont traités comme des caractères multi-octets et affichés dans la locale courante. Toutes les autres variantes de cette option traitent les octets comme des valeurs encodées en UTF-8 et tentent de les interpréter. S'ils ne peuvent pas être interprétés ou si l'option --unicode=invalid est utilisée, ils sont alors affichés sous forme d'une séquence d'octets hexadécimaux, entourés d'accolades.

L'utilisation de l'option --unicode=escape affichera les caractères sous forme de séquences d'échappement unicode (\uxxxx). L'utilisation de l'option --unicode=hex affichera les caractères sous forme de séquences d'octets hexadécimaux entourées d'angles.

L'utilisation de l'option --unicode=highlight affichera les caractères sous forme de séquences d'échappement unicode, mais les mettra également en surbrillance en rouge, en supposant que la coloration est prise en charge par le périphérique de sortie. La coloration vise à attirer l'attention sur la présence de séquences unicode lorsqu'elles ne sont pas attendues.

-X
--extra-sym-info
Lors de l'affichage des détails des symboles, inclure des informations supplémentaires normalement non présentées. Actuellement, cela ajoute simplement le nom de la section référencée par le champ d'index du symbole, s'il y en a un. À l'avenir, plus d'informations pourront être affichées lorsque cette option sera activée.

L'activation de cette option active effectivement également l'option --wide, du moins lors de l'affichage des informations de symboles.

--no-extra-sym-info
Désactive l'effet de l'option --extra-sym-info. C'est le comportement par défaut.
-e
--headers
Affiche tous les en-têtes du fichier. Équivalent à -h -l -S.
-n
--notes
Affiche le contenu des segments et/ou sections NOTE, s'il y en a.
-r
--relocs
Affiche le contenu de la section de relocalisation du fichier, s'il en possède une.
-u
--unwind
Affiche le contenu de la section de déroulement (unwind) du fichier, s'il en possède une. Seules les sections de déroulement pour les fichiers ELF IA64, ainsi que les tables de déroulement ARM (".ARM.exidx" / ".ARM.extab") sont actuellement prises en charge. Si la prise en charge n'est pas encore implémentée pour votre architecture, vous pouvez essayer de déverser le contenu de la section .eh_frames en utilisant les options --debug-dump=frames ou --debug-dump=frames-interp.
-d
--dynamic
Affiche le contenu de la section dynamique du fichier, s'il en possède une.
-V
--version-info
Affiche le contenu des sections de version du fichier, s'elles existent.
-A
--arch-specific
Affiche les informations spécifiques à l'architecture dans le fichier, s'il y en a.
-D
--use-dynamic
Lors de l'affichage des symboles, cette option fait utiliser par readelf les tables de hachage de symboles dans la section dynamique du fichier, plutôt que les sections de table de symboles.

Lors de l'affichage des relocalisations, cette option fait afficher par readelf les relocalisations dynamiques plutôt que les relocalisations statiques.

-L
--lint
--enable-checks
Affiche des messages d'avertissement concernant d'éventuels problèmes avec les fichiers examinés. S'il est utilisé seul, tout le contenu des fichiers sera examiné. S'il est utilisé avec l'une des options de déchargement, les messages d'avertissement ne seront produits que pour les éléments affichés.
-x <nombre ou nom>
--hex-dump=<nombre ou nom>
Affiche le contenu de la section indiquée sous forme d'octets hexadécimaux. Un nombre identifie une section particulière par son index dans la table des sections ; toute autre chaîne identifie toutes les sections portant ce nom dans le fichier objet.
-R <nombre ou nom>
--relocated-dump=<nombre ou nom>
Affiche le contenu de la section indiquée sous forme d'octets hexadécimaux. Un nombre identifie une section particulière par son index dans la table des sections ; toute autre chaîne identifie toutes les sections portant ce nom dans le fichier objet. Le contenu de la section sera relocalisé avant d'être affiché.
-p <nombre ou nom>
--string-dump=<nombre ou nom>
Affiche le contenu de la section indiquée sous forme de chaînes imprimables. Un nombre identifie une section particulière par son index dans la table des sections ; toute autre chaîne identifie toutes les sections portant ce nom dans le fichier objet.
-z
--decompress
Demande la décompression des sections à déverser par les options x, R ou p avant leur affichage. Si les sections ne sont pas compressées, elles sont affichées telles quelles.
-c
--archive-index
Affiche les informations de l'index de symboles du fichier contenues dans la partie en-tête des archives binaires. Exécute la même fonction que la commande t de ar, mais sans utiliser la bibliothèque BFD.
-w[lLiaprmfFsOoRtUuTgAckK]
--debug-dump[=rawline,=decodedline,=info,=abbrev,=pubnames,=aranges,=macro,=frames,=frames-interp,=str,=str-offsets,=loc,=Ranges,=pubtypes,=trace_info,=trace_abbrev,=trace_aranges,=gdb_index,=addr,=cu_index,=links,=follow-links]
Affiche le contenu des sections de débogage DWARF dans le fichier, s'il y en a. Les sections de débogage compressées sont automatiquement décompressées (temporairement) avant d'être affichées. Si une ou plusieurs des lettres ou mots optionnels suivent le commutateur, seuls ces types de données seront déversés. Les lettres et les mots font référence aux informations suivantes :
"a"
"=abbrev"
Affiche le contenu de la section .debug_abbrev.
"A"
"=addr"
Affiche le contenu de la section .debug_addr.
"c"
"=cu_index"
Affiche le contenu des sections .debug_cu_index et/ou .debug_tu_index.
"f"
"=frames"
Affiche le contenu brut d'une section .debug_frame.
"F"
"=frames-interp"
Affiche le contenu interprété d'une section .debug_frame.
"g"
"=gdb_index"
Affiche le contenu des sections .gdb_index et/ou .debug_names.
"i"
"=info"
Affiche le contenu de la section .debug_info. Remarque : la sortie de cette option peut également être limitée par l'utilisation des options --dwarf-depth et --dwarf-start.
"k"
"=links"
Affiche le contenu des sections .gnu_debuglink, .gnu_debugaltlink et .debug_sup, si l'une d'entre elles est présente. Affiche également tout lien vers des fichiers objets de débogage séparés (dwo), s'ils sont spécifiés par les attributs DW_AT_GNU_dwo_name ou DW_AT_dwo_name dans la section .debug_info.
"K"
"=follow-links"
Affiche le contenu de toute section de débogage sélectionnée qui se trouve dans des fichiers d'informations de débogage séparés et liés. Cela peut entraîner l'affichage de plusieurs versions de la même section de débogage si elle existe dans plus d'un fichier.

De plus, lors de l'affichage des attributs DWARF, si une forme est trouvée qui fait référence au fichier d'informations de débogage séparé, le contenu référencé sera également affiché.

Remarque : dans certaines distributions, cette option est activée par défaut. Elle peut être désactivée via l'option de débogage N. Le comportement par défaut peut être choisi lors de la configuration des binutils via les options --enable-follow-debug-links=yes ou --enable-follow-debug-links=no. Si celles-ci ne sont pas utilisées, le comportement par défaut est d'activer le suivi des liens de débogage.

Remarque : si la prise en charge du protocole debuginfod a été activée lors de la construction des binutils, cette option inclura également une tentative de contact des serveurs debuginfod mentionnés dans la variable d'environnement DEBUGINFOD_URLS. Cela peut prendre du temps à résoudre. Ce comportement peut être désactivé via l'option de débogage =do-not-use-debuginfod.

"N"
"=no-follow-links"
Désactive le suivi des liens vers les fichiers d'informations de débogage séparés.
"D"
"=use-debuginfod"
Active le contact avec les serveurs debuginfod s'il est nécessaire de suivre les liens de débogage. C'est le comportement par défaut.
"E"
"=do-not-use-debuginfod"
Désactive le contact avec les serveurs debuginfod lorsqu'il est nécessaire de suivre les liens de débogage.
"l"

DESCRIPTION

Read and display information about the contents of an ELF file. This program is part of the GNU Binutils.

The options are:

-a
--all
Print all information that this utility can know about the file. This is equivalent to specifying all of the other debugging options.
-h
--file-header
Print the detailed informations from the ELF header.
-l
--sections-details
Print the section header table. This provides detailed information on all the sections in the file.
-S
--section-header
Print the section header table. This gives a summary of each section in the file.
-g
--group
Print the ELF section group information.
-t
--segment-header
Print the program's segment header table. This provides information on which segments are needed when the program is run.
-d
--dynamic
Print the dynamic linking information contained in the file.
-c
--relocations
Print the relocation bits contained in the file.
--debug-dump=type
Dump the specified debug sections. A list of the possible debug section types can be found below. If no type is specified, then all debug sections that are found will be dumped.
=rawline
Displays the contents of the .debug_line section in a raw format.
L
=decodedline
Displays the interpreted contents of the .debug_line section.
m
=macro
Displays the contents of the .debug_macro and/or .debug_macinfo sections.
o
=loc
Displays the contents of the .debug_loc and/or .debug_loclists sections.
O
=str-offsets
Displays the contents of the .debug_str_offsets section.
p
=pubnames
Displays the contents of the .debug_pubnames and/or .debug_gnu_pubnames sections.
r
=aranges
Displays the contents of the .debug_aranges section.
R
=Ranges
Displays the contents of the .debug_ranges and/or .debug_rnglists sections.
s
=str
Displays the contents of the .debug_str, .debug_line_str and/or .debug_str_offsets sections.
t
=pubtype
Displays the contents of the .debug_pubtypes and/or .debug_gnu_pubtypes sections.
T
=trace_aranges
Displays the contents of the .trace_aranges section.
u
=trace_abbrev
Displays the contents of the .trace_abbrev section.
U
=trace_info
Displays the contents of the .trace_info section.
Note: displaying the contents of .debug_static_funcs, .debug_static_vars and debug_weaknames sections is not currently supported.

--dwarf-depth=n
Limit the dump of the ".debug_info" section to n children. This is only useful with --debug-dump=info. The default is to print all DIEs; the special value 0 for n will also have this effect.

With a non-zero value for n, DIEs at or deeper than n levels will not be printed. The range for n is zero-based.

--dwarf-start=n
Print only DIEs beginning with the DIE numbered n. This is only useful with --debug-dump=info.

If specified, this option will suppress printing of any header information and all DIEs before the DIE numbered n. Only siblings and children of the specified DIE will be printed.

This can be used in conjunction with --dwarf-depth.

-P
--process-links
Display the contents of non-debug sections found in separate debuginfo files that are linked to the main file. This option automatically implies the -wK option, and only sections requested by other command line options will be displayed.
--ctf[=section]
Display the contents of the specified CTF section. CTF sections themselves contain many subsections, all of which are displayed in order.

By default, display the name of the section named .ctf, which is the name emitted by ld.

--ctf-parent=member
If the CTF section contains ambiguously-defined types, it will consist of an archive of many CTF dictionaries, all inheriting from one dictionary containing unambiguous types. This member is by default named .ctf, like the section containing it, but it is possible to change this name using the "ctf_link_set_memb_name_changer" function at link time. When looking at CTF archives that have been created by a linker that uses the name changer to rename the parent archive member, --ctf-parent can be used to specify the name used for the parent.
--ctf-symbols=section
--ctf-strings=section
Specify the name of another section from which the CTF file can inherit strings and symbols. By default, the ".symtab" and its linked string table are used.

If either of --ctf-symbols or --ctf-strings is specified, the other must be specified as well.

-I
--histogram
Display a histogram of bucket list lengths when displaying the contents of the symbol tables.
-v
--version
Display the version number of readelf.
-W
--wide
Don't break output lines to fit into 80 columns. By default readelf breaks section header and segment listing lines for 64-bit ELF files, so that they fit into 80 columns. This option causes readelf to print each section header resp. each segment one a single line, which is far more readable on terminals wider than 80 columns.
-T
--silent-truncation
Normally when readelf is displaying a symbol name, and it has to truncate the name to fit into an 80 column display, it will add a suffix of "[...]" to the name. This command line option disables this behaviour, allowing 5 more characters of the name to be displayed and restoring the old behaviour of readelf (prior to release 2.35).
-H
--help
Display the command-line options understood by readelf.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
