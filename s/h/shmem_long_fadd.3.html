shmem_long_fadd(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONG_FADD(3) Open MPI SHMEM_LONG_FADD(3)

shmem_int4_fadd(3), shmem_int8_fadd(3), shmem_int_fadd(3), shmem_long_fadd(3), shmem_longlong_fadd(3) - Effectue une opération atomique de type "fetch-and-add" sur un objet de données distant

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
int shmem_int_fadd(int *target, int value, int pe)
long shmem_long_fadd(long *target, long value, int pe)
long long shmem_longlong_fadd(long long *target, longlong value,
  int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_FADD, ires, target, value
ires = SHMEM_INT4_FADD(target, value, pe)
INTEGER(KIND=8) SHMEM_INT8_FADD, ires, target, value
ires = SHMEM_INT8_FADD(target, value, pe)

DESCRIPTION

Les fonctions shmem_fadd effectuent une opération atomique de type "fetch-and-add". Une opération atomique "fetch-and-add" récupère la valeur actuelle de la cible et ajoute la valeur à la cible, sans possibilité qu'un autre processus mette à jour la cible entre le moment de la récupération et celui de la mise à jour. Ces routines ajoutent la valeur à la cible sur l'élément de traitement (PE) `pe` et renvoient le contenu précédent de la cible en tant qu'opération atomique.

Les arguments sont les suivants :

target
L'objet de données entier accessible à distance à mettre à jour sur le PE distant. Le type de `target` doit correspondre à celui implicite dans la section SYNTAXE.
value
La valeur à ajouter atomiquement à `target`. Le type de `value` doit correspondre à celui implicite dans la section SYNTAXE.
pe
Un entier indiquant le numéro du PE sur lequel `target` doit être mis à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

NOTES

Le terme "accessible à distance" est défini dans intro_shmem(3).

VALEURS DE RETOUR

Le contenu qui se trouvait à l'adresse cible sur le PE distant avant l'opération d'addition atomique.
