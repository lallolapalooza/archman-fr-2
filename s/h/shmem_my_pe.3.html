shmem_my_pe, my_pe, _my_pe - Retourne le numéro de PE virtuel du PE appelant.

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
int shmem_my_pe (void)
int my_pe (void)

Fortran :

include 'mpp/shmem.fh'
I = SHMEM_MY_PE ()
I = MY_PE ()

DESCRIPTION

my_pe() ou shmem_my_pe() retourne le numéro de l'élément de traitement (PE) du PE appelant. Elle n'accepte aucun argument. Le résultat est un entier compris entre 0 et npes - 1, où npes est le nombre total de PE exécutant le programme courant.
