FBB::SharedBuf(3bobcat) Flux de mémoire partagée FBB::SharedBuf(3bobcat)

NOM

FBB::SharedBuf - flux s'interfaçant à la mémoire partagée

SYNOPIS

#include <bobcat/sharedbuf>
Option de liaison : -lpthread -lbobcat

DESCRIPTION

Cette classe implémente une spécialisation de la classe std::streambuf, permettant aux classes de flux (std::istream, std::ostream, FBB::ISharedStream, FBB::OSharedStream et FBB::SharedStream) d'effectuer des opérations d'E/S sur la mémoire partagée. Les objets FBB::SharedBuf s'interfacent avec des objets FBB::SharedMemory.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HÉRITE DE

std::streambuf, FBB::SharedEnum__ (cf. sharedmemory(3bobcat) pour une description de cette dernière classe).

ÉNUMÉRATION SIZEUNIT

L'énumération enum SizeUnit définit les constantes symboliques suivantes :

o
kB, représentant 1024 (2**10) octets de mémoire ;
o
MB, représentant 1048576 (2**20) octets de mémoire ;
o
GB, représentant 1073741824 (2**30) octets de mémoire

CONSTRUCTEURS

o
SharedBuf() :
Le constructeur par défaut définit un objet SharedBuf factice qui ne peut pas être utilisé immédiatement pour accéder à la mémoire partagée. Avant qu'il puisse être utilisé par des classes de flux partagées comme FBB::SharedStream, son membre setMemory doit d'abord avoir été appelé.
o
SharedBuf(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in | std::ios::out, size_t access = 0600) :
Ce constructeur crée un segment de mémoire partagée ayant une capacité d'au moins maxSize * sizeUnit octets.
Par défaut, le segment de mémoire partagée est ouvert en lecture et écriture. Différent des modes d'ouverture utilisés pour les flux de fichiers, créer un flux de mémoire partagée avec les modes d'ouverture ios::in | ios::out est correct. Dans ce cas, le segment de mémoire partagée est créé et une fois que des informations ont été écrites dans la mémoire partagée, elles peuvent également être relues.
Les droits d'accès de la mémoire partagée sont définis par le paramètre access, interprété comme une valeur octale, en utilisant la manière bien connue (chmod(1)) de définir les droits d'accès pour le propriétaire, le groupe et les autres.
Si la construction échoue, une FBB::Exception est levée.
o
SharedBuf(int id, std::ios::openmode openMode = std::ios::in | std::ios::out) :
Ce constructeur se connecte à un segment de mémoire partagée ayant l'ID id.
La spécification du drapeau ios::trunc efface immédiatement le contenu de la mémoire partagée.
Une FBB::Exception est levée si la construction échoue (par exemple, aucun segment de mémoire partagée ayant l'ID id n'existe),

Les constructeurs et opérateurs d'affectation par copie et déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::streambuf et les valeurs de l'énumération kB, MB, et GB, définies par FBB::SharedEnum__ sont disponibles.

o
void clear() :
La mémoire partagée est d'abord verrouillée. Ensuite, tous les segments de données partagées sont retournés au système d'exploitation, après quoi le segment de mémoire partagée est déverrouillé. Après le retour de clear, la mémoire partagée, l'objet FBB::SharedMemory est effectivement réinitialisé, avec offset et nReadable retournant 0.
o
int id() const :
L'ID du segment de mémoire partagée est retourné.
o
void kill() :
Sans verrouiller la mémoire partagée, la mémoire partagée de FBB::SharedBuf est supprimée. L'objet FBB::SharedBuf devient inutilisable après le retour de kill.
o
void memInfo(std::ostream &out) :
Les informations concernant l'objet SharedMemory sont insérées dans l'objet ostream fourni. Les ID des segments partagés, leurs tailles, le nombre maximum de segments de mémoire partagée, le nombre d'octets pouvant être lus de la mémoire partagée, et sa capacité de stockage réelle, etc., sont affichés. Les informations insérées ne sont pas terminées par un caractère de nouvelle ligne final.
o
void remove() :
La mémoire partagée est verrouillée, et la mémoire partagée de FBB::SharedBuf est supprimée. L'objet FBB::SharedBuf devient inutilisable après le retour de remove.
o
void setMemory(SharedMemory &&tmp) :
L'objet SharedMemory temporaire anonyme passé à setMemory définit le nouveau segment de mémoire partagée auquel l'objet FBB::SharedBuf s'interface. Il peut également être appelé pour réutiliser un objet FBB::SharedBuf après avoir appelé kill ou remove.
o
FBB::SharedMemory &sharedMemory() :
Une référence à l'objet FBB::SharedMemory auquel l'objet FBB::SharedBuf s'interface est retournée.

FONCTIONS MEMBRES PROTÉGÉES

o
FBB::SharedCondition attachSharedCondition(std::ios::off_type offset, std::ios::seekdir origin) :
Retourne un objet FBB::SharedCondition(3), s'interfaçant à une variable de condition partagée située à l'offset offset (relatif à origin) dans l'objet SharedMemory auquel l'objet SharedStreamBuf s'interface.
Une FBB::Exception est levée si l'objet FBB::SharedCondition n'a pas pu être construit.
o
FBB::SharedCondition createSharedCondition() :
Retourne un objet FBB::SharedCondition(3), s'interfaçant à une nouvelle variable de condition partagée qui est créée à l'offset actuel de l'objet SharedMemory auquel l'objet SharedStream s'interface (ou au premier offset du prochain bloc de données de mémoire partagée, cf. sharedcondition(3bobcat)).
Une FBB::Exception est levée si l'objet FBB::SharedCondition n'a pas pu être construit.
o
void setOpenMode(std::ios::openmode flag) :
L'openmode du flux est modifié pour correspondre aux paramètres définis par flag. Ce membre est utilisé, par exemple, par SharedStream::open, pour adapter l'openmode de FBB::SharedBuf aux drapeaux passés à open.
o
FBB::SharedMemory &sharedMemory() :
Retourne une référence à l'objet FBB::SharedMemory auquel l'objet SharedBuf s'interface.

BOGUES

Notez que par défaut, les exceptions lancées depuis un objet std::stream sont interceptées par l'objet stream, qui définit son indicateur ios::failbit. Pour permettre aux exceptions de quitter un objet stream, sa méthode exceptions peut être appelée, par exemple, en utilisant :

    myStream.exceptions(ios::failbit | ios::badbit | ios::eofbit);
