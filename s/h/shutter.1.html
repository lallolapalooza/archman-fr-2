NOM

Shutter - Outil de capture d'écran riche en fonctionnalités

SYNTAXE

shutter [options]

DROITS D'ACTIVITÉ

Shutter est protégé par copyright (C) par Mario Kemper et l'équipe Shutter

DESCRIPTION

Shutter est un programme de capture d'écran riche en fonctionnalités. Vous pouvez capturer une zone spécifique de l'écran, une fenêtre, votre écran entier, ou même une page web - appliquer différents effets, dessiner dessus pour mettre en évidence des points, puis téléverser vers un site d'hébergement d'images, le tout dans une seule fenêtre.

OPTIONS

Exemple 1
shutter -a -p=monprofil --min_au_démarrage
Exemple 2
shutter -s=100,100,300,300 -e
Exemple 3
shutter --fenêtre=.*firefox.*
Exemple 4
shutter --web=http://shutter-project.org/ -e

OPTIONS DE MODE DE CAPTURE

-s, --selectionner=[X,Y,LARGEUR,HAUTEUR]
Capture une zone de l'écran. Spécifier X,Y,LARGEUR,HAUTEUR est facultatif.
-f, --plein
Capture l'écran entier.
-w, --fenêtre=[MOTIF_NOM]
Sélectionne une fenêtre à capturer. Spécifier un MOTIF_NOM (regex style Perl) est facultatif.
-a, --actif
Capture la fenêtre active actuelle.
-m, --menu
Capture un menu.
-t, --infobulle
Capture une infobulle.
--web=[URL]
Capture une page web. Spécifier une URL est facultatif.
-r, --refaire
Refait la dernière capture d'écran.

OPTIONS DE CONFIGURATION

-p, --profil=NOM
Charge un profil spécifique au démarrage.
-o, --sortie=NOM_FICHIER
Spécifie un nom de fichier pour enregistrer la capture d'écran (écrase tout paramètre lié au profil).

Formats d'image supportés : Vous pouvez enregistrer dans n'importe quel format d'image populaire (par ex. jpeg, png, gif, bmp). De plus, il est possible d'enregistrer en pdf, ps ou svg.

Remarque : Il existe plusieurs jokers disponibles, tels que

%Y = année
%m = mois
%d = jour
%T = heure
$w = largeur
$h = hauteur
$nom = polyvalent (par ex. titre de fenêtre)
$nb_nom = comme $nom mais sans espaces dans les chaînes résultantes
$profil = nom du profil actuel
$R = caractère aléatoire (par ex. $RRRR = ag4r)
%NN = compteur

La chaîne est interprétée par strftime. Voir "man strftime" pour plus d'exemples.

Par exemple : shutter -f -e -o './%y-%m-%d_$w_$h.png' créerait un fichier nommé '11-10-28_1280_800.png' dans le répertoire courant.

-d, --delai=SECONDES
Attend n secondes avant de prendre une capture d'écran.
-c, --inclure_curseur
Inclut le curseur lors de la prise de capture d'écran.
-C, --supprimer_curseur
Supprime le curseur lors de la prise de capture d'écran.

OPTIONS APPLICATIVES

-h, --aide
Affiche un bref message d'aide et quitte.
-v, --version
Affiche les informations de version.
--debug
Affiche beaucoup d'informations de débogage sur STDOUT.
--clear_cache
Nettoie le cache, par ex. les plugins installés, au démarrage.
--min_au_démarrage
Démarre Shutter minimisé dans la barre d'état système.
--disable_systray
Désactive l'icône de la barre d'état système.
-e, --quitter_apres_capture
Quitte après la première capture effectuée. Ceci est utile lors de l'utilisation de Shutter dans des scripts.
-n, --pas_session
N'ajoute pas la capture d'écran à la session. Ceci est utile lors de l'utilisation de Shutter dans des scripts.

SIGNALEMENTS DE BOGUES

Si vous trouvez un bogue dans Shutter, vous devriez le signaler. Mais avant, assurez-vous qu'il s'agit bien d'un bogue, et qu'il apparaît dans la dernière version de Shutter.

La dernière version est toujours disponible à l'adresse : https://github.com/shutter-project/shutter/releases

Une fois que vous avez déterminé qu'un bogue existe réellement, veuillez le signaler sur github : https://github.com/shutter-project/shutter/issues/new
