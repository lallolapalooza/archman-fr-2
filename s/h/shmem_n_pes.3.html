SHMEM_N_PES(3) Open MPI SHMEM_N_PES(3)

_num_pes, _num_pes shmem_n_pes - Renvoie le nombre d'éléments de traitement (PE) utilisés pour exécuter l'application.

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
int _num_pes (void)
int shmem_n_pes (void)

Fortran :

include 'mpp/shmem.fh'
I = NUM_PES ()
I = SHMEM_N_PES ()

DESCRIPTION

num_pes() ou shmem_n_pes() renvoient le nombre total de PE exécutant une application.

VOIR AUSSI :

intro_shmem(3) shmem_my_pe(3) shmem_init(3)
