SHA512SUM(1) Commandes utilisateur SHA512SUM(1)

NOM

sha512sum - calculer et vérifier les sommes de contrôle SHA512

SYNOPSIS

sha512sum [OPTION]... [FICHIER]...

DESCRIPTION

Afficher ou vérifier les sommes de contrôle SHA512 (512 bits).

Sans FICHIER, ou lorsque FICHIER est -, lire depuis l'entrée standard.

-b, --binary
lire en mode binaire
-c, --check
lire les sommes de contrôle depuis les FICHIERs et les vérifier
--tag
créer une somme de contrôle de style BSD
-t, --text
lire en mode texte (par défaut)
-z, --zero
terminer chaque ligne de sortie avec NUL, pas un saut de ligne, et désactiver l'échappement des noms de fichiers

Les cinq options suivantes sont utiles uniquement lors de la vérification des sommes de contrôle :

--ignore-missing
ne pas échouer ou signaler le statut pour les fichiers manquants
--quiet
ne pas afficher OK pour chaque fichier vérifié avec succès
--status
ne rien afficher, le code d'état indique le succès
--strict
sortir avec un code non nul pour les lignes de somme de contrôle mal formatées
-w, --warn
avertir des lignes de somme de contrôle mal formatées
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Les sommes sont calculées comme décrit dans FIPS-180-2. Lors de la vérification, l'entrée doit être une sortie précédente de ce programme. Le mode par défaut est d'afficher une ligne avec : somme de contrôle, un espace, un caractère indiquant le mode d'entrée ('*' pour binaire, ' ' pour texte ou lorsque le binaire est insignifiant), et le nom pour chaque FICHIER.

Il n'y a pas de différence entre le mode binaire et le mode texte sur les systèmes GNU.
