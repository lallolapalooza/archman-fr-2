NOM

showfigfonts - affiche une liste des polices figlet disponibles

SYNTAXE

showfigfonts [ -d répertoire ] [ mot ]

DESCRIPTION

Affiche une liste des polices figlet disponibles, ainsi qu'un exemple de chaque police. Si un répertoire est indiqué, liste les polices de ce répertoire ; sinon, utilise le répertoire de polices par défaut. Si un mot est indiqué, affiche ce mot dans chaque police ; sinon, affiche le nom de la police.

EXEMPLES

Pour utiliser showfigfonts avec ses paramètres par défaut, tapez simplement

exemple% showfigfonts

Pour afficher toutes les polices dans /usr/share/fonts/figlet

exemple% showfigfonts -d /usr/share/fonts/figlet

Pour afficher le mot foo en utilisant toutes les polices disponibles

exemple% showfigfonts foo
