SHIFT(1P) Manuel du programmeur POSIX SHIFT(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

shift — décale les paramètres positionnels

SYNOPSIS

shift [n]

DESCRIPTION

Les paramètres positionnels seront décalés. Le paramètre positionnel 1 recevra la valeur du paramètre (1+n), le paramètre 2 recevra la valeur du paramètre (2+n), et ainsi de suite. Les paramètres représentés par les nombres "$#" jusqu'à "$#-n+1" seront désaffectés, et le paramètre '#' sera mis à jour pour refléter le nouveau nombre de paramètres positionnels.

La valeur n sera un entier décimal non signé inférieur ou égal à la valeur du paramètre spécial '#'. Si n n'est pas donné, il sera supposé valoir 1. Si n vaut 0, les paramètres positionnels et spéciaux ne seront pas modifiés.

STATUT DE SORTIE

Si l'opérande n est invalide ou supérieur à "$#", cela peut être considéré comme une erreur de syntaxe et un shell non interactif peut se terminer ; si le shell ne se termine pas dans ce cas, un statut de sortie non nul sera retourné. Sinon, zéro sera retourné.
