shmem_quiet(3) - Attend la complétion de toutes les écritures distantes en cours émises par un élément de traitement (PE).

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
void shmem_quiet(void)

Fortran :

CALL SHMEM_QUIET

DESCRIPTION

shmem_quiet assure l'ordonnancement des opérations de type put (écriture distante). Toutes les opérations put émises vers n'importe quel élément de traitement (PE) avant l'appel à shmem_quiet sont garanties d'être visibles par tous les autres PE au plus tard à l'heure de toute opération de chargement ou de stockage, put ou get distant, ou opération de synchronisation qui suit l'appel à shmem_quiet.

NOTES

shmem_quiet est particulièrement utile pour garantir l'ordonnancement de la livraison
plusieurs opérations put. Par exemple, vous pourriez utiliser shmem_quiet
pour attendre la livraison d'un bloc de données avant d'émettre un autre put, qui
définit un drapeau de complétion sur un autre PE.
shmem_quiet n'est généralement pas nécessaire si shmem_barrier_all(3) ou
shmem_barrier(3) sont appelés. Les routines de barrière attendent toutes la
complétion des écritures distantes (puts) en cours.

EXEMPLES

PROGRAM COMPFLAG
  INCLUDE "mpp/shmem.fh"
  INTEGER FLAG_VAR, ARRAY(100), RECEIVER, SENDER
  COMMON/FLAG/FLAG_VAR
  COMMON/DATA/ARRAY
  INTRINSIC MY_PE
  FLAG_VAR = 0
  CALL SHMEM_BARRIER_ALL ! attendre que FLAG_VAR soit initialisé
  SENDER = 0                        ! PE 0 envoie les données
  RECEIVER = 1                      ! PE 1 reçoit les données
  IF (MY_PE() .EQ. 0) THEN
    ARRAY = 33
    CALL SHMEM_PUT(ARRAY, ARRAY, 100, RECEIVER) ! commencer l'envoi des données
    CALL SHMEM_QUIET                ! attendre la livraison
    CALL SHMEM_PUT(FLAG_VAR, 1, 1, RECEIVER) ! envoyer le drapeau de complétion
  ELSE IF (MY_PE() .EQ. RECEIVER) THEN
    CALL SHMEM_UDCFLUSH
    CALL SHMEM_WAIT(FLAG_VAR, 0)
    PRINT *,ARRAY                       ! ARRAY a été livré
  ENDIF
END
