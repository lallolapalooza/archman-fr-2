shmem_int_inc(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_INT_INC(3) Open MPI SHMEM_INT_INC(3)

shmem_int4_inc(3), shmem_int8_inc(3), shmem_int_inc(3), shmem_long_inc(3), shmem_longlong_inc(3) - Ces routines effectuent une opération d'incrémentation atomique sur un objet de données distant.

SYNOPSIS

C ou C++:

#include <mpp/shmem.h>
int shmem_int_inc(int *target, int pe)
long shmem_long_inc(long *target, int pe)
long long shmem_longlong_inc(long long *target, int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_INC, target4
INTEGER(KIND=8) SHMEM_INT8_INC, target8
ires4 = SHMEM_INT4_INC(target4, pe)
ires8 = SHMEM_INT8_INC(target8, pe)

DESCRIPTION

Les routines d'incrémentation atomique remplacent la valeur de target par sa valeur incrémentée de un. L'opération doit être achevée sans possibilité qu'un autre processus mette à jour target entre le moment où la valeur est lue et la mise à jour.

Les arguments sont les suivants :

target
L'objet de données entier accessible à distance à mettre à jour sur le PE distant. Le type de target doit correspondre à celui implicite dans la section SYNOPSIS.
pe
Un entier qui indique le numéro du PE sur lequel target doit être mis à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

NOTES

Le terme « accessible à distance » est défini dans intro_shmem(3).

VALEURS DE RETOUR

Aucune.
