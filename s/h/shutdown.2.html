shutdown(2) Manuel des appels système shutdown(2)

NOM

shutdown - arrêter une partie d'une connexion full-duplex

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/socket.h>
int shutdown(int sockfd, int how);

DESCRIPTION

L'appel shutdown() provoque l'arrêt de tout ou partie d'une connexion full-duplex sur le socket associé à sockfd. Si how est SHUT_RD, les réceptions ultérieures seront interdites. Si how est SHUT_WR, les transmissions ultérieures seront interdites. Si how est SHUT_RDWR, les réceptions et transmissions ultérieures seront interdites.

VALEUR RENVOYÉE

En cas de succès, zéro est renvoyé. En cas d'erreur, -1 est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
sockfd n'est pas un descripteur de fichier valide.
EINVAL
Une valeur invalide a été spécifiée dans how (mais voir BUGS).
ENOTCONN
Le socket spécifié n'est pas connecté.
ENOTSOCK
Le descripteur de fichier sockfd ne fait pas référence à un socket.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, 4.4BSD (est apparu pour la première fois dans 4.2BSD).

NOTES

Les constantes SHUT_RD, SHUT_WR, SHUT_RDWR ont les valeurs 0, 1, 2, respectivement, et sont définies dans <sys/socket.h> depuis glibc-2.1.91.

BOGUES

Les vérifications de la validité de how sont effectuées dans le code spécifique au domaine, et avant Linux 3.7, tous les domaines ne effectuaient pas ces vérifications. Notamment, les sockets de domaine UNIX ignoraient simplement les valeurs invalides. Ce problème a été corrigé pour les sockets de domaine UNIX dans Linux 3.7.

VOIR AUSSI

close(2), connect(2), socket(2), socket(7)
