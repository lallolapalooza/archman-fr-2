SHMEM_GETMEM(3) Open MPI SHMEM_GETMEM(3)

shmem_character_get(3), shmem_complex_get(3), shmem_double_get(3), shmem_float_get(3), shmem_get4(3), shmem_get8(3), shmem_get32(3), shmem_get64(3), shmem_get128(3), shmem_getmem(3), shmem_int_get(3), shmem_integer_get(3), shmem_logical_get(3), shmem_long_get(3), shmem_longdouble_get(3), shmem_longlong_get(3), shmem_real_get(3), shmem_short_get(3) - Transfère des données à partir d'un traitement élémentaire (PE) spécifié.

  size_t len, int pe)

  size_t len, int pe)

  size_t len, int pe)

  size_t len, int pe)
void shmem_double_get(double *target, const double *source,
  size_t len, int pe)
void shmem_float_get(float *target, const float *source,
  size_t len, int pe)
void shmem_long_get(long *target, const long *source,
  size_t len, int pe)
void shmem_longdouble_get(long double *target,
  const long double *source, size_t len, int pe)
void shmem_longlong_get(long long *target,
  const long long *source, size_t len, int pe)

  const short *source, size_t len, int pe)

DESCRIPTION

Les routines shmem_get transfèrent nelems éléments de l'objet de données à l'adresse source sur le PE distant pe, vers l'objet de données à l'adresse target sur le PE local. Ces routines retournent une fois que les données ont été copiées à l'adresse target sur le PE local.

Les arguments sont les suivants :

target
Objet de données local à mettre à jour.
source
Objet de données sur le PE identifié par pe qui contient les données à copier. Cet objet de données doit être accessible à distance.
len
Nombre d'éléments dans les tableaux cibles et sources. len doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une constante, d'une variable ou d'un élément de tableau de type entier par défaut.
pe
Numéro du PE distant. pe doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une constante, d'une variable ou d'un élément de tableau de type entier par défaut.

Les objets de données cibles et sources doivent respecter les contraintes de typage, qui sont les suivantes :

shmem_getmem: Fortran : tout type non caractère. C : tout type de données. len est
calculé en octets.
shmem_get4, shmem_get32 : tout type non caractère ayant une taille de stockage
égale à 32 bits.
{shmem_get8, shmem_get64} : tout type non caractère ayant une taille de stockage égale à
64 bits.
shmem_get128: tout type non caractère ayant une taille de stockage égale à 128
bits.

shmem_short_get : éléments de type short.

shmem_int_get : éléments de type int.

shmem_long_get : éléments de type long.

shmem_longlong_get : éléments de type long long.

shmem_float_get : éléments de type float.

shmem_double_get : éléments de type double.

shmem_longdouble_get : éléments de type long double.

SHMEM_CHARACTER_GET: éléments de type caractère. len est le nombre de
caractères à transférer. Les longueurs de caractères réelles des variables source et cible sont ignorées.

SHMEM_COMPLEX_GET : éléments de type complexe de taille par défaut.

SHMEM_DOUBLE_GET : (Fortran) éléments de type double précision.

SHMEM_INTEGER_GET : éléments de type entier.

SHMEM_LOGICAL_GET : éléments de type logique.

SHMEM_REAL_GET : éléments de type réel.

Si vous utilisez Fortran, les types de données doivent être de taille par défaut. Par exemple, une variable réelle doit être déclarée comme REAL, REAL*4 ou REAL(KIND=4).

NOTES

Voir intro_shmem(3) pour une définition du terme accessible à distance.

EXEMPLES

Considérez ce simple exemple pour Fortran.

PROGRAM REDUCTION
  REAL VALUES, SUM
  COMMON /C/ VALUES
  REAL WORK
  CALL START_PES(0) ! AUTORISER N'IMPORTE QUEL NOMBRE DE PE
  VALUES = MY_PE() ! INITIALISER À QUELQUE CHOSE
  CALL SHMEM_BARRIER_ALL
  SUM = 0.0
  DO I = 0,NUM_PES()-1
    CALL SHMEM_REAL_GET(WORK, VALUES, 1, I)
    SUM = SUM + WORK
  ENDDO
  PRINT *, 'PE ', MY_PE(), ' SOMME CALCULÉE=', SUM
  CALL SHMEM_BARRIER_ALL
END
