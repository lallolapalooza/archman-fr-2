shmem_longdouble_p(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONGDOUBLE_P(3) Open MPI SHMEM_LONGDOUBLE_P(3)

shmem_char_p(3), shmem_float_p(3), shmem_int_p(3), shmem_long_p(3), shmem_short_p(3), shmem_longlong_p(3), shmem_longdouble_p(3) - Ces routines fournissent un mécanisme à faible latence pour écrire des types de base (char, short, int, float, double, long, long long, long double) dans des objets de données symétriques sur des PE distants.

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
void shmem_char_p(char *addr, char value, int pe)
void shmem_short_p(short *addr, short value, int pe)
void shmem_int_p(int *addr, int value, int pe)
void shmem_long_p(long *addr, long value, int pe)
void shmem_longlong_p(long long *addr, long long value, int pe)
void shmem_float_p(float *addr, float value, int pe)
void shmem_double_p(double *addr, double value, int pe)
void shmem_longdouble_p(long double *addr, long double value, int pe)

DESCRIPTION

Ces routines fournissent une capacité d'écriture (put) à très faible latence pour des éléments uniques de la plupart des types de base.

Les arguments sont les suivants :

addr
L'élément de tableau accessible à distance ou l'objet de données scalaire qui recevra les données sur le PE distant.
value
La valeur à transférer vers addr sur le PE distant.
pe
Le numéro du PE distant.

Comme avec shmem_put(3), ces fonctions démarrent le transfert distant et peuvent retourner avant que les données ne soient livrées au PE distant. Utilisez shmem_quiet(3) pour forcer l'achèvement de tous les transferts PUT distants.

VOIR AUSSI :

intro_shmem(3) shmem_put(3)
