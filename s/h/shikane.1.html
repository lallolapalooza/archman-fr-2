shikane(1) Manuel des commandes générales shikane(1)

NOM

shikane - configuration dynamique de sortie déterministe

SYNTAXE

shikane

shikane [-hV] [-o] [-c fichier]

shikane [--oneshot] [--config fichier]

DESCRIPTION

shikane (/ʃiˈkaːnə/), est un outil de configuration dynamique de sortie axé sur la précision et le déterminisme.

Il détecte et configure automatiquement les affichages connectés en fonction d'un ensemble de profils. Chaque profil spécifie un ensemble de sorties avec des paramètres supplémentaires (par exemple, mode, position, échelle). Un profil sera appliqué automatiquement si toutes les sorties et modes spécifiés peuvent être parfaitement mis en correspondance avec les affichages actuellement connectés et leurs capacités. (Voir shikane(5) pour plus de détails.)

C'est un équivalent Wayland pour des outils comme autorandr. Il vise à remplacer complètement kanshi, à surpasser ses inexactitudes et à ajouter de nouvelles fonctionnalités. shikane fonctionne avec les compositeurs Wayland supportant les versions >=3 du protocole wlr-output-management (par exemple, les compositeurs utilisant wlroots v0.16).

OPTIONS

-h, --help
Affiche les informations d'aide
-c, --config fichier
Chemin vers un fichier de configuration fichier
-o, --oneshot
Active le mode oneshot

Se termine après qu'un profil a été appliqué ou si aucun profil n'a été trouvé

-s, --socket chemin
Remplace le chemin par défaut du socket IPC
-T, --timeout délai
Attend délai millisecondes avant de traiter les changements [défaut: 0]
-V, --version
Affiche les informations de version

ENVIRONNEMENT

SHIKANE_LOG
Contrôle le niveau de journalisation auquel shikane et ses modules impriment des messages sur stderr. Les niveaux de journalisation disponibles sont error, warn, info, debug et trace ; triés de la priorité la plus haute à la plus basse. Un niveau de journalisation inférieur inclut les messages des niveaux supérieurs. Définir SHIKANE_LOG sur trace vous permettra de tout voir. Le définir sur off désactive toute journalisation.

Cette variable permet de filtrer par modules et accepte une liste séparée par des virgules : SHIKANE_LOG=shikane=warn,shikane::matching=debug n'affichera que les warnings et les errors de shikane, à l'exception du module de correspondance où les messages de journalisation de niveau debug et supérieur seront affichés.

Remarque : la sortie et le filtrage de la journalisation ne sont pas une interface stable et peuvent changer à tout moment.

SHIKANE_LOG_STYLE
Contrôle si les couleurs et les styles avec des caractères ANSI sont utilisés pour la sortie de journalisation. Les valeurs possibles sont auto, always et never. La valeur par défaut est auto.
SHIKANE_LOG_TIME
Active la journalisation des horodatages préfixés si défini sur 1.

FICHIERS

shikane lit sa configuration à partir de $XDG_CONFIG_HOME/shikane/config.toml par défaut. Le programme se termine avec une erreur si aucun fichier de configuration fichier n'est trouvé. Le format du fichier de configuration est documenté dans shikane(5).

BOGUES

Espérons-en moins de 4.
