shmem_int_fetch(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_INT_FETCH(3) Open MPI SHMEM_INT_FETCH(3)

shmem_int4_fetch(3), shmem_int8_fetch(3), shmem_int_fetch(3), shmem_long_fetch(3), shmem_longlong_fetch(3) shmem_double_fetch(3) shmem_float_fetch(3) - Récupère atomiquement la valeur d'un objet de données distant

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
int shmem_int_fetch(int *target, int pe)
long shmem_long_fetch(long *target, int pe)
long long shmem_longlong_fetch(long long *target, int pe)
double shmem_double_fetch(long long *target, int pe)
float  shmem_float_fetch(float *target, int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_FETCH, ires, target
ires = SHMEM_INT4_FETCH(target, pe)
INTEGER(KIND=8) SHMEM_INT8_FETCH, ires, target
ires = SHMEM_INT8_FETCH(target, pe)
REAL(KIND=4) SHMEM_INT4_FETCH, ires, target
ires = SHMEM_REAL4_FETCH(target, pe)
REAL(KIND=8) SHMEM_INT8_FETCH, ires, target
ires = SHMEM_REAL8_FETCH(target, pe)

DESCRIPTION

Les fonctions shmem_fetch effectuent une opération de récupération atomique. Elles retournent le contenu de la cible comme une opération atomique.

Les arguments sont les suivants :

cible
L'objet de données accessible à distance à récupérer à partir du PE distant.
pe
Un entier qui indique le numéro du PE à partir duquel la cible doit être récupérée. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

VALEURS DE RETOUR

Le contenu à l'adresse de la cible sur le PE distant. Le type de données de la valeur de retour est le même que le type de l'objet de données distant.
