FBB::SharedBlock(3bobcat) Bloc de mémoire partagée FBB::SharedBlock(3bobcat)

NOM

FBB::SharedBlock - Informations sur les blocs de données de mémoire partagée

SYNTAXE

#include <bobcat/sharedblock>
Option de liaison : -lpthread, -lbobcat

DESCRIPTION

Les objets FBB::SharedBlock sont utilisés par FBB::SharedSegment pour accéder aux identifiants et aux verrous de mémoire partagée des segments de données en mémoire partagée.

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HERITE DE

-

CONSTRUCTEURS

Seul le constructeur par défaut est disponible. Les opérateurs d'affectation par copie et par déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

o
size_t id() const:
La valeur de l'identifiant stocké dans l'objet est retournée.
o
void lock() const:
Lorsque ce membre retourne, le processus courant a obtenu le verrou mutex de mémoire partagée du FBB::SharedBlock.
o
void setID(size_t id):
La valeur de l'identifiant stocké dans l'objet est définie à id.
o
void unlock() const:
Le verrou mutex du segment de mémoire partagée est libéré.
