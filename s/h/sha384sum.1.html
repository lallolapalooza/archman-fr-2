SHA384SUM(1) Commandes utilisateur SHA384SUM(1)

NOM

sha384sum - calculer et vérifier les sommes de contrôle de messages SHA384

SYNOPSIS

sha384sum [OPTION]... [FICHIER]...

DESCRIPTION

Affiche ou vérifie les sommes de contrôle SHA384 (384 bits).

Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

-b, --binary
lire en mode binaire
-c, --check
lire les sommes de contrôle depuis les FICHIERs et les vérifier
--tag
créer une somme de contrôle de style BSD
-t, --text
lire en mode texte (par défaut)
-z, --zero
terminer chaque ligne de sortie avec NUL, et non une nouvelle ligne, et désactiver l'échappement des noms de fichiers

Les cinq options suivantes sont utiles uniquement lors de la vérification des sommes de contrôle :

--ignore-missing
ne pas échouer ni signaler le statut pour les fichiers manquants
--quiet
ne pas afficher OK pour chaque fichier vérifié avec succès
--status
ne rien afficher, le code de statut indique le succès
--strict
quitter avec un code non nul pour les lignes de somme de contrôle mal formatées
-w, --warn
avertir des lignes de somme de contrôle mal formatées
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Les sommes sont calculées comme décrit dans FIPS-180-2. Lors de la vérification, l'entrée doit être une sortie antérieure de ce programme. Le mode par défaut est d'afficher une ligne avec : somme de contrôle, un espace, un caractère indiquant le mode d'entrée ('*' pour binaire, ' ' pour texte ou lorsque le binaire est insignifiant), et le nom pour chaque FICHIER.

Il n'y a pas de différence entre le mode binaire et le mode texte sur les systèmes GNU.
