SHASUM(1perl) Guide de référence du programmeur Perl SHASUM(1perl)

NOM

shasum - Affiche ou vérifie les sommes de contrôle SHA

SYNTAXE

Utilisation : shasum [OPTION]... [FICHIER]...
Affiche ou vérifie les sommes de contrôle SHA.
Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.
  -a, --algorithm   1 (défaut), 224, 256, 384, 512, 512224, 512256
  -b, --binary      lit en mode binaire
  -c, --check       lit les sommes SHA des FICHIERS et les vérifie
      --tag         crée une somme de contrôle de style BSD
  -t, --text        lit en mode texte (défaut)
  -U, --UNIVERSAL   lit en mode Universel de sauts de ligne
                        produit le même digest sous Windows/Unix/Mac
  -0, --01          lit en mode BITS
                        '0' ASCII interprété comme 0-bit,
                        '1' ASCII interprété comme 1-bit,
                        tous les autres caractères ignorés
Les cinq options suivantes ne sont utiles que lors de la vérification des sommes de contrôle :
      --ignore-missing  ne pas échouer ou signaler l'état pour les fichiers manquants
  -q, --quiet           ne pas afficher OK pour chaque fichier vérifié avec succès
  -s, --status          ne rien afficher, le code de statut indique le succès
      --strict          sortir avec une valeur non nulle pour les lignes de somme de contrôle mal formatées
  -w, --warn            avertir des lignes de somme de contrôle mal formatées
  -h, --help        afficher cette aide et quitter
  -v, --version     afficher les informations de version et quitter
Lors de la vérification des sommes de contrôle SHA-512/224 ou SHA-512/256, indiquez
l'algorithme explicitement en utilisant l'option -a, par exemple
  shasum -a 512224 -c fichier_somme_controle
Les sommes sont calculées comme décrit dans FIPS PUB 180-4. Lors de la vérification,
l'entrée doit être une sortie précédente de ce programme. Le mode par défaut
est d'afficher une ligne avec la somme de contrôle, un caractère indiquant le type
(`*' pour binaire, ` ' pour texte, `U' pour UNIVERSAL, `^' pour BITS),
et le nom pour chaque FICHIER. La ligne commence par un caractère `\' si le
nom du FICHIER contient des sauts de ligne ou des barres obliques inverses, qui sont
ensuite remplacés par les séquences de deux caractères `\n' et `\\' respectivement.
Signaler les bugs de shasum à mshelor@cpan.org

DESCRIPTION

L'exécution de shasum est souvent le moyen le plus rapide de calculer les digests de message SHA. L'utilisateur alimente simplement les données au script via des fichiers ou l'entrée standard, puis collecte les résultats à partir de la sortie standard.

La commande suivante montre comment calculer les digests pour des entrées typiques comme le vecteur de test NIST "abc" :

perl -e "print qq(abc)" | shasum

Ou, si vous voulez utiliser SHA-256 au lieu du SHA-1 par défaut, dites simplement :

perl -e "print qq(abc)" | shasum -a 256

Puisque shasum imite le comportement des programmes combinés GNU sha1sum, sha224sum, sha256sum, sha384sum et sha512sum, vous pouvez installer ce script comme remplacement pratique immédiat.

Contrairement aux programmes GNU, shasum englobe la norme SHA complète en autorisant les entrées d'octets partiels. Ceci est réalisé grâce à l'option BITS (-0). L'exemple suivant calcule le digest SHA-224 du message de 7 bits 0001100 :

perl -e "print qq(0001100)" | shasum -0 -a 224
