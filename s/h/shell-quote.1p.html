NOM

shell-quote - échappe les arguments pour une utilisation sécurisée, non modifiée dans une commande shell

SYNTAXE

shell-quote [option]... arg...

DESCRIPTION

shell-quote vous permet de passer des chaînes arbitraires à travers le shell de manière à ce qu'elles ne soient pas modifiées par le shell. Cela vous permet de traiter des commandes ou des fichiers contenant des espaces ou des caractères de globbing du shell en toute sécurité. Voici quelques exemples.

EXEMPLES

ssh préservant les arguments
Lors de l'exécution d'une commande à distance avec ssh, ssh ne préserve pas les arguments distincts qu'il reçoit. Il les joint simplement avec des espaces et les passe à "$SHELL -c". Cela ne fonctionne pas comme prévu : 
ssh hôte touch 'bonjour tout le monde'           # échoue

Cela crée 2 fichiers, bonjour et tout. Faites plutôt ceci :

cmd=`shell-quote touch 'bonjour tout le monde'`
ssh hôte "$cmd"

Cela vous donne 1 seul fichier, bonjour tout le monde.

traiter la sortie de find
Il n'est normalement pas possible de traiter une liste arbitraire de fichiers issue de find avec un script shell. Tout ce que vous mettriez dans $IFS pour diviser la sortie pourrait légitimement se trouver dans le nom d'un fichier. Voici comment vous pouvez le faire en utilisant shell-quote : 
eval set -- `find -type f -print0 | xargs -0 shell-quote --`
scripts shell de débogage
shell-quote est meilleur que echo pour déboguer des scripts shell. 
debug() {
    [ -z "$debug" ] || shell-quote "debug:" "$@"
}

Avec echo, vous ne pouvez pas faire la différence entre "debug 'foo bar'" et "debug foo bar", mais avec shell-quote, vous le pouvez.

sauvegarder une commande pour plus tard
shell-quote peut être utilisé pour construire une commande shell à exécuter plus tard. Disons que vous voulez que l'utilisateur puisse vous donner des commutateurs pour une commande que vous allez exécuter. Si vous ne voulez pas que les commutateurs soient réévalués par le shell (ce qui est généralement une bonne idée, sinon il y a des choses que l'utilisateur ne peut pas passer), vous pouvez faire quelque chose comme ceci : 
switches_utilisateur=
while [ $# != 0 ]
do
    case x$1 in
        x--pass-through)
            [ $# -gt 1 ] || die "nécessite un argument pour $1"
            switches_utilisateur="$switches_utilisateur "`shell-quote -- "$2"`
            shift;;
        # traiter d'autres commutateurs
    esac
    shift
done
# plus tard
eval "shell-quote commande-quelconque $switches_utilisateur mes arguments"

OPTIONS

--debug
Active le débogage.
--help
Affiche le message d'utilisation et quitte.
--version
Affiche le numéro de version et quitte.
