shmem_pe_accessible - Détermine si un élément de traitement (PE) est accessible via les opérations de transfert de données SHMEM.

SYNOPSIS

C:

#include <mpp/shmem.h>
int shmem_pe_accessible(int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
LOGICAL LOG, SHMEM_PE_ACCESSIBLE
INTEGER pe
LOG = SHMEM_PE_ACCESSIBLE(pe)

DESCRIPTION

shmem_pe_accessible retourne une valeur qui indique si le PE appelant est capable d'effectuer des opérations de communication OpenSHMEM avec le PE distant.

VALEURS DE RETOUR

C/C++
La valeur de retour est 1 si le PE spécifié est un PE distant valide pour les fonctions SHMEM ; sinon, elle est 0.
Fortran
La valeur de retour est .TRUE. si le PE spécifié est un PE distant valide pour les fonctions SHMEM ; sinon, elle est .FALSE..
