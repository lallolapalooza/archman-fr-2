SHMEM_LONG_G(3) Open MPI SHMEM_LONG_G(3)

shmem_char_g(3), shmem_float_g(3), shmem_int_g(3), shmem_long_g(3), shmem_short_g(3), shmem_longlong_g(3), shmem_longdouble_g(3) - Ces routines fournissent un mécanisme à faible latence pour lire des types de base (char, short, int, float, double, long, long long, long double) à partir d'objets de données symétriques sur des PEs distants.

SYNTAXE

C ou C++:

#include <mpp/shmem.h>
char shmem_char_g(const char *addr, int pe)
short shmem_short_g(const short *addr, int pe)
int shmem_int_g(const int *addr, int pe)
long shmem_long_g(const long *addr, int pe)
long shmem_longlong_g(const long long *addr, int pe)
float shmem_float_g(const float *addr, int pe)
double shmem_double_g(const double *addr, int pe)
long shmem_longdouble_g(const long double *addr, int pe)

DESCRIPTION

Ces routines fournissent une capacité de récupération ('get') à très faible latence pour des éléments uniques de la plupart des types de base.

Les arguments sont les suivants:

addr
L'élément de tableau accessible à distance ou l'objet de données scalaire qui recevra les données sur le PE distant.
pe
Le numéro du PE distant.
