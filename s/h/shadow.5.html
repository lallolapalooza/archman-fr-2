SHADOW(5) Formats de fichiers et configuration SHADOW(5)

NOM

shadow - fichier des mots de passe protégés

DESCRIPTION

shadow est un fichier qui contient les informations de mot de passe des comptes du système et des informations facultatives sur l'expiration.

Ce fichier ne doit pas être lisible par les utilisateurs ordinaires si la sécurité des mots de passe doit être maintenue.

Chaque ligne de ce fichier contient 9 champs, séparés par des deux-points (« : »), dans l'ordre suivant :

nom d'utilisateur

Il doit s'agir d'un nom de compte valide, qui existe sur le système.

mot de passe chiffré

Si le champ mot de passe est vide, l'utilisateur peut se connecter sans mot de passe. Cependant, certaines applications qui lisent le fichier /etc/shadow peuvent bloquer l'accès si le champ mot de passe est vide.

Si le champ mot de passe commence par un point d'exclamation !, le mot de passe est verrouillé. Les caractères restants sur la ligne représentent le champ mot de passe avant que le mot de passe ne soit verrouillé.

Consultez crypt(3) pour les détails sur l'interprétation de cette chaîne.

Si le champ mot de passe contient une chaîne qui n'est pas un résultat valide de crypt(3), par exemple ! ou *, l'utilisateur ne peut pas utiliser un mot de passe UNIX pour se connecter. Cependant, l'utilisateur peut se connecter au système par d'autres moyens.

date du dernier changement de mot de passe

La date du dernier changement de mot de passe, exprimée en nombre de jours depuis le 1970-01-01 00:00:00 UTC.

La valeur 0 indique que l'utilisateur doit changer son mot de passe la prochaine fois qu'il se connectera au système.

Un champ vide signifie que les fonctionnalités d'expiration des mots de passe sont désactivées.

âge minimum du mot de passe

L'âge minimum du mot de passe est le nombre de jours que l'utilisateur doit attendre avant de pouvoir changer à nouveau son mot de passe.

Un champ vide et une valeur 0 signifient qu'il n'y a pas d'âge minimum pour le mot de passe.

âge maximum du mot de passe

L'âge maximum du mot de passe est le nombre de jours après lesquels l'utilisateur doit changer son mot de passe.

Une fois ce nombre de jours écoulé, le mot de passe peut toujours être valide. L'utilisateur est invité à changer son mot de passe lors de la prochaine connexion.

Un champ vide signifie qu'il n'y a pas d'âge maximum pour le mot de passe, pas de période d'avertissement pour le mot de passe, et pas de période d'inactivité du mot de passe (voir ci-dessous).

Si l'âge maximum du mot de passe est inférieur à l'âge minimum du mot de passe, l'utilisateur ne peut pas changer son mot de passe.

période d'avertissement du mot de passe

Le nombre de jours avant l'expiration d'un mot de passe (voir l'âge maximum du mot de passe ci-dessus) pendant lesquels l'utilisateur est averti.

Un champ vide et une valeur 0 signifient qu'il n'y a pas de période d'avertissement du mot de passe.

période d'inactivité du mot de passe

Le nombre de jours après l'expiration d'un mot de passe (voir l'âge maximum du mot de passe ci-dessus) pendant lesquels le mot de passe est toujours accepté, et l'utilisateur doit mettre à jour son mot de passe lors de la prochaine connexion.

Une fois que le mot de passe a expiré et que la période d'inactivité du mot de passe est écoulée, l'utilisateur ne peut pas se connecter et doit contacter son administrateur.

Une chaîne vide signifie qu'aucune période d'inactivité n'est appliquée.

date d'expiration du compte

La date à laquelle le compte expire, exprimée en nombre de jours depuis le 1970-01-01.

Notez que l'expiration du compte est différente de l'expiration du mot de passe. L'expiration du compte empêche l'utilisateur de se connecter, tandis que l'expiration du mot de passe empêche seulement les utilisateurs de se connecter avec leur mot de passe.

Un champ vide signifie que le compte n'expire jamais.

La valeur 0 ne doit pas être utilisée, car elle est interprétée soit comme un compte sans expiration, soit comme une date d'expiration du 1970-01-01.

champ réservé

Ce champ est réservé pour une utilisation future.

FICHIERS

/etc/passwd

Informations sur les comptes utilisateur.

/etc/shadow

Informations sécurisées sur les comptes utilisateur.

/etc/shadow-

Fichier de sauvegarde pour /etc/shadow.

Notez que ce fichier est utilisé par les outils de la suite d'outils shadow, mais pas par tous les outils de gestion d'utilisateurs et de mots de passe.
