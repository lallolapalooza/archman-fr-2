NOM

strip - supprime les symboles et autres données des fichiers objets

SYNTAXE

strip [-F nombfd |--target=nombfd]
[-I nombfd |--input-target=nombfd]
[-O nombfd |--output-target=nombfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nomsymbole|--keep-symbol=nomsymbole]
[-M|--merge-notes][--no-merge-notes]
[-N nomsymbole |--strip-symbol=nomsymbole]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nomsection |--remove-section=nomsection]
[--keep-section=motifsection]
[--remove-relocations=motifsection]
[--strip-section-headers]
[-o fichier] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
fichierobjet...

DESCRIPTION

GNU strip supprime tous les symboles des fichiers objets fichierobjet. La liste des fichiers objets peut inclure des archives. Au moins un fichier objet doit être fourni.

strip modifie les fichiers nommés dans ses arguments, plutôt que d'écrire des copies modifiées sous des noms différents.

OPTIONS

-F nombfd
--target=nombfd
Traiter le fichierobjet original comme un fichier avec le format de code objet nombfd, et le réécrire dans le même format.
--help
Afficher un résumé des options de strip et quitter.
--info
Afficher une liste montrant tous les formats d'architecture et d'objet disponibles.
-I nombfd
--input-target=nombfd
Traiter le fichierobjet original comme un fichier avec le format de code objet nombfd.
-O nombfd
--output-target=nombfd
Remplacer fichierobjet par un fichier au format de sortie nombfd.
-R nomsection
--remove-section=nomsection
Supprimer toute section nommée nomsection du fichier de sortie, en plus de toutes les sections qui seraient autrement supprimées. Cette option peut être donnée plusieurs fois. Notez qu'utiliser cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Le caractère joker * peut être donné à la fin de nomsection. Si c'est le cas, toute section commençant par nomsection sera supprimée.

Si le premier caractère de motifsection est le point d'exclamation (!) alors les sections correspondantes ne seront pas supprimées même si une utilisation antérieure de --remove-section sur la même ligne de commande les supprimerait autrement. Par exemple :

--remove-section=.text.* --remove-section=!.text.foo

supprimera toutes les sections correspondant au motif '.text.*', mais ne supprimera pas la section '.text.foo'.

--keep-section=motifsection
Lors de la suppression de sections du fichier de sortie, conserver les sections qui correspondent à motifsection.
--remove-relocations=motifsection
Supprimer les relocations du fichier de sortie pour toute section correspondant à motifsection. Cette option peut être donnée plusieurs fois. Notez qu'utiliser cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Les caractères joker sont acceptés dans motifsection. Par exemple : 
--remove-relocations=.text.*

supprimera les relocations de toutes les sections correspondant au motif '.text.*'.

Si le premier caractère de motifsection est le point d'exclamation (!) alors les sections correspondantes n'auront pas leurs relocations supprimées même si une utilisation antérieure de --remove-relocations sur la même ligne de commande causerait autrement la suppression des relocations. Par exemple :

--remove-relocations=.text.* --remove-relocations=!.text.foo

supprimera toutes les relocations pour les sections correspondant au motif '.text.*', mais ne supprimera pas les relocations pour la section '.text.foo'.

--strip-section-headers
Supprimer les en-têtes de section. Cette option est spécifique aux fichiers ELF. Implique --strip-all et --merge-notes.
-s
--strip-all
Supprimer tous les symboles.
-g
-S
-d
--strip-debug
Supprimer uniquement les symboles de débogage.
--strip-dwo
Supprimer le contenu de toutes les sections DWARF .dwo, en laissant les sections de débogage restantes et tous les symboles intacts. Voir la description de cette option dans la section objcopy pour plus d'informations.
--strip-unneeded
Supprimer tous les symboles qui ne sont pas nécessaires au traitement des relocations en plus des symboles et sections de débogage supprimés par --strip-debug.
-K nomsymbole
--keep-symbol=nomsymbole
Lors de la suppression de symboles, conserver le symbole nomsymbole même s'il serait normalement supprimé. Cette option peut être donnée plusieurs fois.
-M
--merge-notes
--no-merge-notes
Pour les fichiers ELF, tenter (ou ne pas tenter) de réduire la taille des sections de type SHT_NOTE en supprimant les notes dupliquées. Par défaut, cette réduction est tentée, sauf lors de la suppression des informations de débogage ou DWO.
-N nomsymbole
--strip-symbol=nomsymbole
Supprimer le symbole nomsymbole du fichier source. Cette option peut être donnée plusieurs fois, et peut être combinée avec des options de strip autres que -K.
-o fichier
Placer la sortie dépouillée dans fichier, plutôt que de remplacer le fichier existant. Lorsque cet argument est utilisé, un seul argument fichierobjet peut être spécifié.
-p
--preserve-dates
Conserver les dates d'accès et de modification du fichier.
-D
--enable-deterministic-archives
Opérer en mode déterministe. Lors de la copie des membres d'archive et de l'écriture de l'index de l'archive, utiliser zéro pour les UID, GID, timestamps, et utiliser des modes de fichier cohérents pour tous les fichiers.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, ci-dessous.

-U
--disable-deterministic-archives
Ne pas opérer en mode déterministe. C'est t

Content from the Arch Linux man pages is licensed under the CC BY-SA 4.0 International license.

Le contraire de l'option -D, ci-dessus : lors de la copie des membres de l'archive et de l'écriture de l'index de l'archive, utilisez leurs valeurs réelles d'UID, GID, horodatage et mode de fichier.

C'est le comportement par défaut, sauf si binutils a été configuré avec --enable-deterministic-archives.

-w
--wildcard
Permet les expressions régulières dans les nom_symboles utilisés dans d'autres options de ligne de commande. Les opérateurs point d'interrogation (?), astérisque (*), antislash (\) et crochets ([]) peuvent être utilisés n'importe où dans le nom du symbole. Si le premier caractère du nom du symbole est le point d'exclamation (!), alors le sens de l'interrupteur est inversé pour ce symbole. Par exemple : 
-w -K !foo -K fo*

ferait que strip ne conserve que les symboles commençant par les lettres « fo », mais élimine le symbole « foo ».

-x
--discard-all
Supprime les symboles non globaux.
-X
--discard-locals
Supprime les symboles locaux générés par le compilateur. (Ceux-ci commencent généralement par L ou ..)
--keep-section-symbols
Lors du dépouillement d'un fichier, peut-être avec --strip-debug ou --strip-unneeded, conserve tous les symboles spécifiant les noms de section, qui seraient autrement dépouillés.
--keep-file-symbols
Lors du dépouillement d'un fichier, peut-être avec --strip-debug ou --strip-unneeded, conserve tous les symboles spécifiant les noms de fichiers source, qui seraient autrement dépouillés.
--only-keep-debug
Dépouille un fichier, vidant le contenu de toutes les sections qui ne seraient pas dépouillées par --strip-debug et laissant les sections de débogage intactes. Dans les fichiers ELF, cela préserve également toutes les sections de note dans la sortie.

Note : les en-têtes de section des sections dépouillées sont préservés, y compris leurs tailles, mais le contenu de la section est supprimé. Les en-têtes de section sont préservés afin que d'autres outils puissent faire correspondre le fichier d'informations de débogage avec l'exécutable réel, même si cet exécutable a été relocalisé dans un espace d'adressage différent.

L'intention est que cette option soit utilisée conjointement avec --add-gnu-debuglink pour créer un exécutable en deux parties. L'une est un binaire dépouillé qui occupera moins d'espace en RAM et dans une distribution, et la seconde est un fichier d'informations de débogage qui n'est nécessaire que si des capacités de débogage sont requises. La procédure suggérée pour créer ces fichiers est la suivante :

1.<Liez l'exécutable normalement. En supposant qu'il s'appelle>
"foo" alors...
1.<Exécutez "objcopy --only-keep-debug foo foo.dbg" pour>
créer un fichier contenant les informations de débogage.
1.<Exécutez "objcopy --strip-debug foo" pour créer un>
exécutable dépouillé.
1.<Exécutez "objcopy --add-gnu-debuglink=foo.dbg foo">
pour ajouter un lien vers les informations de débogage dans l'exécutable dépouillé.

Note : le choix de l'extension ".dbg" pour le fichier d'informations de débogage est arbitraire. De plus, l'étape "--only-keep-debug" est facultative. Vous pouvez plutôt faire ceci :

1.<Liez l'exécutable normalement.>
1.<Copiez "foo" dans "foo.full">
1.<Exécutez "strip --strip-debug foo">
1.<Exécutez "objcopy --add-gnu-debuglink=foo.full foo">

c'est-à-dire que le fichier pointé par --add-gnu-debuglink peut être l'exécutable complet. Il n'a pas à être un fichier créé par l'interrupteur --only-keep-debug.

Note : cet interrupteur est uniquement destiné à être utilisé sur des fichiers entièrement liés. Il n'est pas logique de l'utiliser sur des fichiers objets où les informations de débogage peuvent être incomplètes. De plus, la fonctionnalité gnu_debuglink ne prend actuellement en charge que la présence d'un seul nom de fichier contenant des informations de débogage, et non plusieurs noms de fichier sur une base un par fichier objet.

-V
--version
Affiche le numéro de version de strip.
-v
--verbose
Sortie détaillée : liste tous les fichiers objets modifiés. Dans le cas des archives, strip -v liste tous les membres de l'archive.
@fichier
Lit les options de ligne de commande à partir de fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas ou ne peut pas être lu, l'option sera traitée littéralement et ne sera pas supprimée.

Les options dans fichier sont séparées par des espaces. Un caractère d'espacement peut être inclus dans une option en entourant toute l'option entre guillemets simples ou doubles. N'importe quel caractère (y compris une barre oblique inverse) peut être inclus en faisant précéder le caractère à inclure par une barre oblique inverse. Le fichier peut lui-même contenir d'autres options @fichier ; toutes ces options seront traitées récursivement.
