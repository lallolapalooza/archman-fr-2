NAME

shout — client source Icecast

SYNOPSIS

shout [OPTIONS]

DESCRIPTION

shout lit des données depuis l'entrée standard et les diffuse vers Icecast.

OPTIONS

--format format
Définit le format du flux. Peut être "ogg", "mp3" ou "webm". La valeur par défaut est "ogg".
-H host
Voir --host
-h
Voir --help
--help
Affiche l'aide.
--host host
Définit l'hôte de destination. La valeur par défaut est "localhost".
--mount string
Définit le point de montage. La valeur par défaut est "/example.ogg".
-P port
Voir --port
--pass string
Définit le mot de passe source. La valeur par défaut est "hackme".
--port port
Définit le port de destination. Les noms symboliques sont pris en charge. La valeur par défaut est 8000.
--proto protocol
Définit le protocole. La valeur par défaut est "http".
--station-description string
Définit la description du flux.
--station-genre string
Définit le genre du flux.
--station-meta key=value
Définit les informations méta. Les deux, key et value, sont des chaînes arbitraires.
--station-name string
Définit le nom du flux.
--station-url string
Définit l'URL du flux.
--tls-mode tls-mode
Définit le mode TLS. Peut être "disabled", "auto", "auto_no_plain", "rfc2818" ou "rfc2817". La valeur par défaut est "auto".

Lorsque libshout est compilé sans support TLS, seuls "disabled" et "auto" sont pris en charge.

--usage usage{,usage}
Définit les usages du flux. Peut être :
"audio"
pour les sous-flux audio
"visual"
pour les sous-flux d'images/vidéo (le plus souvent combiné avec "audio")
"text"
pour les sous-flux texte qui ne sont pas des sous-titres
"subtitle"
pour les sous-flux de sous-titres
"light"
pour les sous-flux de contrôle de la lumière
"ui"
pour les données d'interface utilisateur, tels que les menus DVD ou les boutons
"metadata"
pour les sous-flux qui incluent des métadonnées pour le flux
"application"
pour les sous-flux de données spécifiques à l'application
"control"
pour les sous-flux qui contrôlent l'infrastructure
"complex"
pour les sous-flux qui sont eux-mêmes un mélange d'autres types
"other"
pour les sous-flux de types non listés ici
"unknown"
pour les flux qui peuvent contenir des sous-flux supplémentaires de nature inconnue
"3d"
pour les flux contenant des informations pour la lecture 3D
"4d"
pour les flux contenant des informations pour la lecture 4D/XD
--user string
Définit l'utilisateur source. La valeur par défaut est "source".

NOTES

Si ce binaire est lié symboliquement ou en dur au nom "oggfwd", il fournit une compatibilité directe avec oggfwd(1).
