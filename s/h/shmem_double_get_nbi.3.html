DESCRIPTION

Les routines get fournissent une méthode pour copier un objet de données symétrique contigu d'un PE différent vers un objet de données contigu sur le PE local. Les routines retournent après avoir posté l'opération. L'opération est considérée comme terminée après un appel ultérieur à shmem_quiet. À la fin de shmem_quiet, les données ont été livrées au tableau dest sur le PE local.

Les arguments sont les suivants :

dest
Objet de données local à mettre à jour.
source
Objet de données sur le PE identifié par pe qui contient les données à copier. Cet objet de données doit être accessible à distance.
nelems
Nombre d'éléments dans les tableaux de destination et source. len doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une constante, d'une variable ou d'un élément de tableau de type entier par défaut.
pe
Numéro du PE distant. pe doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une constante, d'une variable ou d'un élément de tableau de type entier par défaut.

Si vous utilisez Fortran, les types de données doivent être de taille par défaut. Par exemple, une variable réelle doit être déclarée comme REAL, REAL*4 ou REAL(KIND=4).

NOTES

Voir intro_shmem(3) pour une définition du terme accessible à distance.

EXEMPLES

Considérez cet exemple simple pour Fortran.

PROGRAM REDUCTION
  REAL VALUES, SUM
  COMMON /C/ VALUES
  REAL WORK
  CALL START_PES(0) ! PERMETTRE N'IMPORTE QUEL NOMBRE DE PEs
  VALUES = MY_PE() ! INITIALISER À QUELQUE CHOSE
  CALL SHMEM_BARRIER_ALL
  SUM = 0.0
  DO I = 0,NUM_PES()-1
    CALL SHMEM_REAL_GET_NBI(WORK, VALUES, 1, I)
    CALL SHMEM_QUIET                ! attendre la livraison
    SUM = SUM + WORK
  ENDDO
  PRINT *, 'PE ', MY_PE(), ' SOMME CALCULÉE=', SUM
  CALL SHMEM_BARRIER_ALL
END
