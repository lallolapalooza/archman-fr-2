SHSEIN

But:

!>
!> SHSEIN utilise l'itération inverse pour trouver les vecteurs propres droits et/ou
!> gauches spécifiés d'une matrice réelle de Hessenberg supérieure H.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de la matrice H
!> correspondant à une valeur propre w sont définis par :
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> où y**h dénote la transposée conjuguée du vecteur y.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R': calcul des vecteurs propres droits seulement ;
!>          = 'L': calcul des vecteurs propres gauches seulement ;
!>          = 'B': calcul des deux vecteurs propres droits et gauches.
!>

EIGSRC

!>          EIGSRC est CHARACTER*1
!>          Spécifie la source des valeurs propres fournies dans (WR,WI) :
!>          = 'Q': les valeurs propres ont été trouvées en utilisant SHSEQR ; ainsi, si
!>                 H a des éléments sous-diagonaux nuls, et est donc
!>                 triangulaire par blocs, alors la j-ième valeur propre peut
!>                 être considérée comme une valeur propre du bloc contenant
!>                 la j-ième ligne/colonne. Cette propriété permet à SHSEIN
!>                 d'effectuer une itération inverse sur un seul bloc diagonal.
!>          = 'N': aucune hypothèse n'est faite sur la correspondance
!>                 entre les valeurs propres et les blocs diagonaux. Dans ce
!>                 cas, SHSEIN doit toujours effectuer une itération inverse
!>                 en utilisant la matrice H entière.
!>

INITV

!>          INITV est CHARACTER*1
!>          = 'N': aucun vecteur initial n'est fourni ;
!>          = 'U': des vecteurs initiaux fournis par l'utilisateur sont stockés
!>                 dans les tableaux VL et/ou VR.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Spécifie les vecteurs propres à calculer. Pour sélectionner le
!>          vecteur propre réel correspondant à une valeur propre réelle WR(j),
!>          SELECT(j) doit être mis à .VRAI.. Pour sélectionner le vecteur
!>          propre complexe correspondant à une valeur propre complexe
!>          (WR(j),WI(j)), avec son conjugué complexe (WR(j+1),WI(j+1)),
!>          soit SELECT(j), soit SELECT(j+1), soit les deux, doivent être mis à
!>          .VRAI. ; ensuite, à la sortie, SELECT(j) est .VRAI. et SELECT(j+1)
!>          est .FAUX..
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice H. N >= 0.
!>

H

!>          H est un tableau RÉEL, de dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>          Si un NaN est détecté dans H, la routine retournera avec INFO=-6.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H. LDH >= max(1,N).
!>

WR

!>          WR est un tableau RÉEL, de dimension (N)
!>

WI

!>          WI est un tableau RÉEL, de dimension (N)
!>
!>          À l'entrée, les parties réelles et imaginaires des valeurs propres de
!>          H ; une paire de valeurs propres complexes conjuguées doit être stockée
!>          dans des éléments consécutifs de WR et WI.
!>          À la sortie, WR peut avoir été modifié car les valeurs propres proches
!>          sont légèrement perturbées lors de la recherche de vecteurs propres
!>          indépendants.
!>

VL

!>          VL est un tableau RÉEL, de dimension (LDVL,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'L' ou 'B', VL doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres gauches ; le vecteur de départ pour chaque vecteur
!>          propre doit être dans les mêmes colonnes où le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'L' ou 'B', les vecteurs propres gauches
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VL, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Si SIDE = 'R', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL.
!>          LDVL >= max(1,N) si SIDE = 'L' ou 'B' ; LDVL >= 1 sinon.
!>

VR

!>          VR est un tableau RÉEL, de dimension (LDVR,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'R' ou 'B', VR doit
!>          contenir les vecteurs de départ pour l'itération inverse des
!>          vecteurs propres droits ; le vecteur de départ pour chaque vecteur
!>          propre doit être dans les mêmes colonnes où le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'R' ou 'B', les vecteurs propres droits
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VR, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe
!>          est stocké dans deux colonnes consécutives, la première contenant la
!>          partie réelle et la seconde la partie imaginaire.
!>          Si SIDE = 'L', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR.
!>          LDVR >= max(1,N) si SIDE = 'R' ou 'B' ; LDVR >= 1 sinon.
!>

MM

!>          MM est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR requis pour
!>          stocker les vecteurs propres ; chaque vecteur propre réel sélectionné
!>          occupe une colonne et chaque vecteur propre complexe sélectionné
!>          occupe deux colonnes.
!>

WORK

!>          WORK est un tableau RÉEL, de dimension ((N+2)*N)
!>

IFAILL

!>          IFAILL est un tableau ENTIER, de dimension (MM)
!>          Si SIDE = 'L' ou 'B', IFAILL(i) = j > 0 si le vecteur propre gauche
!>          dans la i-ème colonne de VL (correspondant à la valeur propre
!>          w(j)) n'a pas convergé ; IFAILL(i) = 0 si le vecteur propre
!>          a convergé de manière satisfaisante. Si les i-ème et (i+1)-ème
!>          colonnes de VL contiennent un vecteur propre complexe, alors IFAILL(i)
!>          et IFAILL(i+1) sont mis à la même valeur.
!>          Si SIDE = 'R', IFAILL n'est pas référencé.
!>

IFAILR

!>          IFAILR est un tableau ENTIER, de dimension (MM)
!>          Si SIDE = 'R' ou 'B', IFAILR(i) = j > 0 si le vecteur propre droit
!>          dans la i-ème colonne de VR (correspondant à la valeur propre
!>          w(j)) n'a pas convergé ; IFAILR(i) = 0 si le vecteur propre
!>          a convergé de manière satisfaisante. Si les i-ème et (i+1)-ème
!>          colonnes de VR contiennent un vecteur propre complexe, alors IFAILR(i)
!>          et IFAILR(i+1) sont mis à la même valeur.
!>          Si SIDE = 'L', IFAILR n'est pas référencé.
!>

INFO

!>          = 0: sortie réussie

shsein.f(3) - LAPACK manual

NAME

shsein.f - approximate eigenvalues and eigenvectors of a real general matrix.

SYNOPSIS

Uses the following LAPACK routines:

CALL SHSEIN( JOB, N, K, RR, CI, SELECT, NMAX, SMAX, VR, LDVR, VI, LDVI,
             M, INFO )

Function/Subroutine Documentation

SHSEIN is a subroutine in the LAPACK library that computes the eigenvalues and eigenvectors of a real general matrix. It is typically used after the matrix has been reduced to upper Hessenberg form.

Purpose
SHSEIN uses inverse iteration to find selected eigenvalues and eigenvectors of a real upper Hessenberg matrix.
Arguments
JOB: Character string. Specifies whether to compute eigenvalues and/or eigenvectors.
  • 'E': Compute eigenvalues only.
  • 'V': Compute eigenvalues and eigenvectors.
N: Integer. The order of the matrix.
K: Integer. The subdiagonal index for which eigenvalues are to be computed. This is typically 1 for a standard upper Hessenberg matrix.
RR: Real array of dimension (N). Contains the real parts of the eigenvalues.
CI: Real array of dimension (N). Contains the imaginary parts of the eigenvalues.
SELECT: Logical array of dimension (N). Specifies which eigenvalues are to be selected. SELECT(j) is true if the eigenvalue j is to be selected.
NMAX: Integer. The maximum number of eigenvalues that can be stored in VR and VI.
SMAX: Real. Used as a threshold for accepting eigenvectors. A larger value leads to more aggressive deflation.
VR: Real array of dimension (LDVR, M). The eigenvectors if JOB = 'V'. Stores the right eigenvectors corresponding to the selected eigenvalues.
LDVR: Integer. The leading dimension of the array VR.
VI: Real array of dimension (LDVI, M). Stores the imaginary parts of the right eigenvectors corresponding to the selected eigenvalues.
LDVI: Integer. The leading dimension of the array VI.
M: Integer. The number of eigenvalues selected. On input, M is the number of eigenvalues available for selection. On output, M is the number of eigenvalues actually selected.
INFO: Integer.
  • 0: Successful exit.
  • > 0: If INFO is the same as the value of IFAILL or IFAILR (returned from the subroutine LAHQR or SLAG2), then INFO is the number of eigenvalues which failed to converge.
  • -1: The JOB argument was illegal.
  • -2: The value of N was illegal.
  • -3: The value of K was illegal.
  • -4: The value of NMAX was less than the number of eigenvalues selected.
  • -5: An illegal value was detected in SELECT.
  • -6: An illegal value was detected in SMAX.
  • -7: An illegal value was detected in VR.
  • -8: An illegal value was detected in LDVR.
  • -9: An illegal value was detected in VI.
  • -10: An illegal value was detected in LDVI.
  • -11: An illegal value was detected in M.
!>          > 0:  if INFO = i, i is the number of eigenvectors which
!>                failed to converge; see IFAILL and IFAILR for further
!>                details.
!>
