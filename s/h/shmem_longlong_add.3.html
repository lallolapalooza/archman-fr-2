SHMEM_LONGLONG_ADD(3) Open MPI SHMEM_LONGLONG_ADD(3)

shmem_int_add(3), shmem_int4_add(3), shmem_int8_add(3), shmem_long_add(3), shmem_longlong_add(3) - Effectue une opération d'addition atomique.

SYNOPSIS

C ou C++ :

#include <mpp/shmem.h>
void shmem_int_add(int *target, int value, int pe)
void shmem_long_add(long *target, long value, int pe)
void shmem_longlong_add(long long *target, long long value,
  int pe)

Fortran :

include 'mpp/shmem.h'
INTEGER pe
CALL SHMEM_INT4_ADD(target, value, pe)
CALL SHMEM_INT8_ADD(target, value, pe)

DESCRIPTION

Les routines d'addition atomique ajoutent la valeur aux données à l'adresse target sur le PE pe. L'opération s'achève sans possibilité qu'un autre processus mette à jour target entre le moment de la récupération et celui de la mise à jour.

Les arguments sont les suivants :

target
L'objet de données entier accessible à distance à mettre à jour sur le PE distant. Si vous utilisez C/C++, le type de target doit correspondre à celui implicite dans la section SYNOPSIS. Si vous utilisez le compilateur Fortran, il doit être de type entier avec une taille d'élément de 4 octets pour SHMEM_INT4_ADD et de 8 octets pour SHMEM_INT8_ADD.
value
La valeur à ajouter atomiquement à target. Si vous utilisez C/C++, le type de value doit correspondre à celui implicite dans la section SYNOPSIS. Si vous utilisez Fortran, il doit être de type entier avec une taille d'élément égale à celle de target.
pe
Un entier qui indique le numéro du PE sur lequel target doit être mis à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

NOTES

Le terme accessible à distance est défini dans intro_shmem(3).
