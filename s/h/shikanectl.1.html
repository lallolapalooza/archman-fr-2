shikanectl(1) Manuel des commandes générales shikanectl(1)

NOM

shikanectl - contrôler le démon shikane

SYNTAXE

shikanectl [options] <commande>

OPTIONS

-h, --help
Afficher les informations d'aide
-s, --socket socket
Se connecter au socket spécifié
-V, --version
Afficher les informations de version

COMMANDES

reload [fichier]
Recharger le fichier de configuration du démon, éventuellement en fournissant un fichier différent.
switch nom
Utiliser le profil donné temporairement.
export [options] nom
Exporter la configuration d'affichage actuelle en tant que configuration shikane. Inclure le vendeur, le modèle et le numéro de série dans les recherches par défaut. Il est recommandé d'utiliser un nom significatif et unique pour le nouveau profil.

OPTIONS EXPORT

-d, --description
Inclure la description dans les recherches
-n, --name
Inclure le nom dans les recherches
-m, --model
Inclure le modèle dans les recherches
-s, --serial
Inclure le numéro de série dans les recherches
-v, --vendor
Inclure le vendeur dans les recherches

EXEMPLES

Utilisation de shikanectl export pour ajouter la configuration d'affichage actuelle en tant que nouveau profil à votre configuration existante. Remplacez simplement le nom du profil par quelque chose de significatif et d'unique.

shikanectl export "NOM_DU_NOUVEAU_PROFIL" >> $XDG_CONFIG_HOME/shikane/config.toml

BOGUES

Espérons moins de 4.
