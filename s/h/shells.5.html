shells(5) Manual des formats de fichiers shells(5)

NOM

shells - chemins d'accès aux shells de connexion valides

DESCRIPTION

/etc/shells est un fichier texte contenant les chemins d'accès complets des shells de connexion valides. Ce fichier est consulté par chsh(1) et peut être interrogé par d'autres programmes.

Soyez conscient qu'il existe des programmes qui consultent ce fichier pour déterminer si un utilisateur est un utilisateur normal ; par exemple, les démons FTP interdisent traditionnellement l'accès aux utilisateurs dont le shell n'est pas inclus dans ce fichier.

FICHIERS

/etc/shells

EXEMPLES

/etc/shells peut contenir les chemins suivants :


/bin/sh
/bin/bash
/bin/csh

VOIR AUSSI

chsh(1), getusershell(3), pam_shells(8)
