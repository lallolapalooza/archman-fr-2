FBB::SharedStream(3bobcat) I/O sur mémoire partagée FBB::SharedStream(3bobcat)

NOM

FBB::SharedStream - Opérations d'E/S sur mémoire partagée

SYNTAXE

#include <bobcat/sharedstream>
Option de liaison : -lpthread -lbobcat

DESCRIPTION

Cette classe combine les fonctionnalités des classes std::istream et std::ostream, opérant sur la mémoire partagée. Comme avec les objets std::fstream, un appel à la fonction membre seekp ou seekg est requis pour passer de l'écriture à la lecture ou vice versa.

Comme avec les objets std::fstream, les objets FBB::SharedStream ne maintiennent pas de décalages séparés pour la lecture et l'écriture : les membres seek font toujours référence au décalage (unique) maintenu par l'objet FBB::SharedMemory auquel l'objet SharedStream est connecté.

Ainsi, bien que tellg et tellp retournent des valeurs identiques, tellg ne doit pas être appelé après avoir écrit dans un objet SharedStream, et tellp ne doit pas être appelé après avoir lu à partir d'un objet SharedStream, car l'appel de membres liés à la lecture (tellg) après l'écriture et vice versa met le flux en état d'échec.

ESPACE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::istream,
std::ostream,
FBB::SharedEnum__ (cf. sharedmemory(3bobcat) pour une description de cette classe de base).

ENUMERATION SIZEUNIT

L'énumération SizeUnit définit les constantes symboliques suivantes :

o
kB, représentant 1024 (2**10) octets de mémoire ;
o
MB, représentant 1048576 (2**20) octets de mémoire ;
o
GB, représentant 1073741824 (2**30) octets de mémoire )

CONSTRUCTEURS

o
SharedStream():
Le constructeur par défaut définit un objet stub SharedStream qui ne peut pas être utilisé immédiatement pour accéder à la mémoire partagée. Pour l'utiliser, son membre open doit d'abord être appelé.
o
SharedStream(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in | std::ios::out, size_t access = 0600):
Ce constructeur crée un flux héritant des facilités d'une std::istream et std::ostream qui est connecté à un segment de mémoire partagée ayant une capacité d'au moins maxSize * sizeUnit octets.
Par défaut, le segment de mémoire partagée est ouvert en lecture et écriture. Différent des modes d'ouverture utilisés pour les flux de fichiers, créer un flux de mémoire partagée avec les modes d'ouverture ios::in | ios::out est acceptable. Dans ce cas, le segment de mémoire partagée est créé et une fois que les informations ont été écrites dans la mémoire partagée, elles peuvent également être relues.
Les droits d'accès de la mémoire partagée sont définis par le paramètre access, interprété comme une valeur octale, en utilisant la manière bien connue (chmod(1)) de définir les droits d'accès pour le propriétaire, le groupe et les autres.
Si la construction échoue, une FBB::Exception est levée.
o
SharedStream(int id, std::ios::openmode openMode = std::ios::in | std::ios::out):
Ce constructeur crée un flux héritant des facilités d'une std::istream et std::ostream qui se connecte à un segment de mémoire partagée ayant l'ID id.
Spécifier le drapeau ios::trunc efface immédiatement le contenu de la mémoire partagée.
Une FBB::Exception est levée si la construction échoue (par exemple, aucun segment de mémoire partagée ayant l'ID id n'existe).
Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

FONCTIONS MEMBRE

Tous les membres de std::istream et std::ostream ainsi que les valeurs d'enum kB, MB, et GB, définies par FBB::SharedEnum__ sont disponibles.
o
FBB::SharedCondition attachSharedCondition(std::ios::off_type offset, std::ios::seekdir origin):
Retourne un objet FBB::SharedCondition(3), connectant une variable de condition partagée située à l'offset offset (relatif à origin) dans l'objet SharedMemory auquel l'objet SharedStream est connecté. Ce membre ne modifie pas la valeur retournée par les membres tellg et tellp du flux.
Une FBB::Exception est levée si l'objet FBB::SharedCondition n'a pas pu être construit.
o
FBB::SharedCondition createSharedCondition():
Retourne un objet FBB::SharedCondition(3), connectant une variable de condition partagée nouvellement créée qui est créée à l'offset actuel de l'objet SharedMemory auquel l'objet SharedStream est connecté (ou au premier offset du prochain bloc de données de mémoire partagée physique, cf. sharedcondition(3bobcat)). La création d'un objet SharedCondition ne modifie pas la valeur retournée par les membres tellg et tellp du flux.
Une FBB::Exception est levée si l'objet FBB::SharedCondition n'a pas pu être construit.
o
int id() const:
L'ID du segment de mémoire partagée est retourné.
o
void kill():
Sans verrouiller la mémoire partagée au préalable, toute la mémoire partagée est rendue au système d'exploitation. L'objet FBB::SharedStream devient inutilisable après le retour de kill. D'autres processus qui utilisaient la mémoire partagée peuvent continuer à le faire.
o
void memInfo(std::ostream &out, char const *end = "\n"):
Les informations concernant l'objet SharedMemory sont insérées dans l'objet ostream fourni. Les IDs des segments partagés, leurs tailles, le nombre maximum de segments de mémoire partagée, le nombre d'octets pouvant être lus à partir de la mémoire partagée, et sa capacité de stockage réelle, etc., sont affichés. Après les informations sur la mémoire partagée, end est inséré dans out.
o
void open(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in | std::ios::out, size_t access = 0600):
Ce membre crée un segment de mémoire partagée ayant une capacité d'au moins maxSize * sizeUnit octets, et connecte le segment de mémoire partagée au FBB::SharedStream. Un membre close correspondant n'existe pas et n'est pas requis.
Par défaut, le segment de mémoire partagée est ouvert en lecture et écriture. Différent des modes d'ouverture utilisés pour les flux de fichiers, créer un flux de mémoire partagée avec les modes d'ouverture ios::in | ios::out est acceptable. Dans ce cas, le segment de mémoire partagée est créé et une fois que les informations ont été écrites dans la mémoire partagée, elles peuvent également être relues.
Les droits d'accès de la mémoire partagée sont définis par le paramètre access, interprété comme une valeur octale, en utilisant la manière bien connue (chmod(1)) de définir les droits d'accès pour le propriétaire, le groupe et les autres.
Si l'ouverture échoue, une FBB::Exception est levée.
o
void open(int id, std::ios::openmode openMode = std::ios::in | std::ios::out):
Ce membre connecte l'objet FBB::SharedStream à un segment de mémoire partagée ayant l'ID id
i>. Un membre close correspondant n'existe pas et n'est pas requis. Si l'ouverture réussit, la mémoire partagée est prête à être utilisée.
La spécification du drapeau ios::trunc efface immédiatement le contenu de la mémoire partagée.
Une FBB::Exception est levée si l'ouverture échoue (par exemple, aucun segment de mémoire partagée ayant l'ID id n'existe).
o
void remove() :
La mémoire partagée est d'abord verrouillée. Ensuite, toute la mémoire partagée est retournée au système d'exploitation. L'objet FBB::SharedStream est inutilisable après le retour de remove. Les autres processus qui utilisaient la mémoire partagée peuvent continuer à le faire.
o
bool truncate(std::streamsize offset) :
Si offset ne dépasse pas la valeur retournée par seekg(0, std::ios::end), alors cette dernière valeur est changée en offset et true est retourné. Sinon, false est retourné et la valeur retournée par seekg n'est pas modifiée. Si la valeur retournée par tellg dépassait offset, la valeur de retour de tellg est également réduite à offset. Les opérations de lecture ultérieures sur la mémoire partagée ne peuvent réussir tant que la valeur de retour de tellg n'a pas atteint la valeur offset.

EXEMPLE

#include <iostream>
#include <string>
#include <ostream>
#include <istream>
#include <bobcat/exception>
#include <bobcat/sharedstream>
#include <bobcat/sharedcondition>
using namespace std;
using namespace FBB;
int main()
{
    SharedStream sharedStream;
    int id = -1;
    while (true)
    {
        cout <<
                "\n"
                " K             tuer (sans verrou) le segment partagé existant\n"
                " S             afficher les statistiques du segment partagé actuel\n"
                " L <id>        charger le segment <id>\n"
                " C             installer une SharedCondition à l'offset 0\n"
                " c            créer une nouvelle mémoire partagée (définit l'id)\n"
//                " l            verrouiller le segment id jusqu'à ce qu'une touche soit pressée\n"
//                " p <x> c      placer le caractère c à l'offset x\n"
                " q            quitter\n"
//                " r <x> <n>    lire n caractères depuis l'offset x\n"
//                " w <x> args   écrire tous les arguments à l'offset x\n"
                  " i            insérer des lignes (jusqu'à vide) à l'offset actuel "
                                                                "\n"
                  " x            extraire des lignes (jusqu'à EOF) depuis l'offset actuel "
                                                                "\n"
                  " X            extraire la prochaine ligne depuis l'offset actuel "
                                                                "\n"
                  "              lorsqu'elle est modifiée via ’N’\n"
                  " N            notifier un X en attente\n"
                  " s <x>        positionner (absolu) à l'offset x\n"
                "? ";
        char ch;
        cin >> ch;
        ios::off_type offset;
        cout << "Demandé : " << ch << ’\n’;
        sharedStream.clear();
        switch (ch)
        {
            case ’c’:
            {
                sharedStream.open(1, SharedStream::kB);
                id = sharedStream.id();
                cout << "id = " << id << ’\n’;
                sharedStream.memInfo(cout);
                cout << ’\n’;
            }
            break;
            case ’C’:
            {
                sharedStream.seekp(0);
                SharedCondition cond(sharedStream.createSharedCondition());
                sharedStream.seekg(cond.width());
                break;
            }
            case ’K’:         // supprimer le segment
            {
                if (id == -1)
                {
                    cout << "Aucun segment chargé\n";
                    continue;
                }
                cout << "Suppression du segment id = " << id << ’\n’;
                if (ch == ’R’)
                    sharedStream.remove();
                else
                    sharedStream.kill();
                id = -1;
            }
            break;
            case ’L’:
                cin >> id;
                cout << "Chargement du segment " << id << ’\n’;
                sharedStream.open(id);
                sharedStream.memInfo(cout);
                cout << ’\n’;
            break;
            case ’S’:
                if (id == -1)
                {
                    cout << "Aucun segment chargé\n";
                    continue;
                }
                sharedStream.memInfo(cout);
                cout << ’\n’;
            break;
            case ’s’:
            {
                size_t offset;
                if (id == -1)
                {
                    cout << "Aucun segment chargé\n";
                    continue;
                }
                cin >> offset;
                sharedStream.seekg(offset);
                sharedStream.seekp(offset);
                cout << "tellg : " << sharedStream.tellg() << ", "
                        "tellp : " << sharedStream.tellp() << ’\n’;
            }
            break;
            case ’i’:
            {
                string line;
                getline(cin, line);
                sharedStream.seekp(0, ios::cur);
                while (true)
                {
                    cout << "? ";
                    if (not getline(cin, line) || line.empty())
                        break;
                    sharedStream << line << endl;
                    cout <<
                            "   tellp : " << sharedStream.tellp() << ’\n’;
                }
                    cout << // "   tellg : " << sharedStream.tellg() << ", "
                            "   tellp : " << sharedStream.tellp() << ’\n’;
            }
            break;
            case ’x’:
            {
                string line;
                sharedStream.seekg(0, ios::cur);
                while (true)
                {
                    cout << ": ";
                    if (not getline(sharedStream, line))
                        break;
                    cout << line << "\n"
                            "   tellg : " << sharedStream.tellg() << ", "
                            "   tellp : " << sharedStream.tellp() << ’\n’;
                }
            }
            break;
            case ’X’:
            {
                SharedCondition cond(sharedStream.attachSharedCondition(0));
                string line;
                sharedStream.seekg(cond.width());
                cond.lock();
                while (true)
                {
                    cond.wait();
                    cout << ": ";
                    if (not getline(sharedStream, line))
                        break;
                    cout << line << "\n"
                            "   tellg : " << sharedStream.tellg() << ", "
                            "   tellp : " << sharedStream.tellp() << ’\n’;
                }
                cout << "Terminé\n";
                cond.unlock();
            }
            break;
            case ’N’:
            {
                string line;
                getline(cin, line);
                SharedCondition cond(sharedStream.attachSharedCondition(0));
                while (true)
                {
                    cout << "’entrée’ ou ’q’ ? ";
                    getline(cin, line);
                    if (line == "q")
                        break;
                    cond.lock();
                    cond.notify();
                    cond.unlock();
                }
            }
            break;
            case ’p’:           // placer un caractère après le dernier écrit
            {
                if (id == -1)
                {
                    cout << "Aucun segment chargé\n";
                    continue;
                }
                cin >> offset >> ch;
                if (!cin)
                    throw Exception() << "erreur de spécification de commande";
                sharedStream.seekp(offset);
                cout << "Segment id = " << id << " à l'offset d'écriture " <<
                                                    sharedStream.tellp() << ’\n’;
                sharedStream.put(ch);
            }
            break;
            case ’r’:           // placer un caractère après le dernier écrit
            {
                if (id == -1)
                {
                    cout << "Aucun segment chargé\n";
                    continue;
                }
                int n;
                cin >> offset >> n;
                if (!cin)
                    throw Exception() << "erreur de spécification de commande";
                char buf[n];
                sharedStream.seekg(offset);
                cout << "Segment id = " << id << " à l'offset " <<
                         sharedStream.tellg() << ", à lire " << n << " octets\n";
                n = sharedStream.read(buf, n).gcount();
                if (n < 0)
                    cout << "Pas de données à " << offset << ’\n’;
                else
                {
                    cout << "Récupérés " << n << " octets, contenant `";
                    cout.write(buf, n);
                    cout << "’\n";
                    for (auto ch: buf)
                        cout << static_cast<int>(ch) << ’ ’;
                    cout << ’\n’;
                }
            }
            break;
            case ’w’:           // écrire des caractères à l'offset
            {
                if (id == -1)
                {
                    cout << "Aucun segment chargé\n";
                    continue;
                }
                string line;
                cin >> offset;
                getline(cin, line);
                if (!cin)
                    throw Exception() << "erreur de spécification de commande";
                streampos pos = sharedStream.seekp(offset).tellp();
                cout << "Segment id = " << id << " à l'offset " <<
                         pos << ", à écrire ";
quot; << line.length() << " octets\n";
                sharedStream.write(line.data(), line.length());
                if (!sharedStream)
                    cout << "Plus de place pour écrire des octets\n";
                else
                    cout << "Écrit " << (sharedStream.tellp() - pos) << " octets\n";
            }
            break;
            case ’q’:
            return 0;
            default:
                cout << "Requête non implémentée : " << ch << ’\n’;
            break;
        }
    }
}

BOGUES

Notez que par défaut, les exceptions levées à l'intérieur d'un objet std::stream sont interceptées par l'objet stream, qui met son drapeau ios::failbit. Pour permettre aux exceptions de quitter un objet stream, son membre exceptions peut être appelé, par exemple en utilisant :

    myStream.exceptions(ios::failbit | ios::badbit | ios::eofbit);
