SHADOW(3) Appels système SHADOW(3)

NOM

shadow, getspnam - routines pour le fichier de mots de passe chiffrés

SYNTAXE

#include <shadow.h>

struct spwd *getspent();

struct spwd *getspnam(char *name);

void setspent();

void endspent();

struct spwd *fgetspent(FILE *fp);

struct spwd *sgetspent(char *cp);

int putspent(struct spwd *p, FILE *fp);

int lckpwdf();

int ulckpwdf();

DESCRIPTION

shadow manipule le contenu du fichier de mots de passe shadow, /etc/shadow. La structure dans le fichier #include est :

struct spwd {
      char		*sp_namp; /* nom de connexion de l'utilisateur */
      char		*sp_pwdp; /* mot de passe chiffré */
      long int		sp_lstchg; /* dernier changement de mot de passe */
      long int		sp_min; /* jours avant lesquels le changement est autorisé. */
      long int		sp_max; /* jours avant lesquels le changement est requis */
      long int		sp_warn; /* jours d'avertissement avant expiration */
      long int		sp_inact; /* jours avant que le compte soit inactif */
      long int		sp_expire; /* date d'expiration du compte */
      unsigned long int	sp_flag; /* réservé pour un usage futur */
}

La signification de chaque champ est :

•sp_namp - pointeur vers le nom d'utilisateur terminé par null
•sp_pwdp - pointeur vers le mot de passe chiffré terminé par null
•sp_lstchg - nombre de jours depuis le 1er janvier 1970 où le mot de passe a été changé pour la dernière fois
•sp_min - nombre de jours avant lesquels le mot de passe ne peut pas être changé
•sp_max - nombre de jours après lesquels le mot de passe doit être changé
•sp_warn - nombre de jours avant l'expiration du mot de passe pendant lesquels l'utilisateur est averti de l'expiration imminente
•sp_inact - nombre de jours après l'expiration du mot de passe pendant lesquels le compte est considéré comme inactif et désactivé
•sp_expire - nombre de jours depuis le 1er janvier 1970 où le compte sera désactivé
•sp_flag - réservé pour un usage futur

DESCRIPTION

getspent, getspname, fgetspent et sgetspent retournent chacune un pointeur vers une structure spwd. getspent retourne l'entrée suivante du fichier, et fgetspent retourne l'entrée suivante du flux donné, qui est supposé être un fichier au format approprié. sgetspent retourne un pointeur vers une structure spwd en utilisant la chaîne fournie comme entrée. getspnam recherche à partir de la position actuelle dans le fichier une entrée correspondant à name.

setspent et endspent peuvent être utilisés pour commencer et terminer, respectivement, l'accès au fichier de mots de passe shadow.

Les routines lckpwdf et ulckpwdf doivent être utilisées pour garantir un accès exclusif au fichier /etc/shadow. lckpwdf tente d'acquérir un verrou en utilisant pw_lock pendant 15 secondes au maximum. Il continue en essayant d'acquérir un second verrou en utilisant spw_lock pour le reste des 15 secondes initiales. Si l'une des tentatives échoue après un total de 15 secondes, lckpwdf retourne -1. Lorsque les deux verrous sont acquis, 0 est retourné.

DIAGNOSTICS

Les routines retournent NULL s'il n'y a plus d'entrées disponibles ou si une erreur se produit pendant le traitement. Les routines qui ont int comme valeur de retour retournent 0 en cas de succès et -1 en cas d'échec.

CAVEATS

Ces routines ne peuvent être utilisées que par le superutilisateur, car l'accès au fichier de mots de passe shadow est restreint.
