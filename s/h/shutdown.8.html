NOM

shutdown - Arrêter, éteindre ou redémarrer la machine

SYNTAXE

shutdown [OPTIONS...] [TEMPS] [MESSAGE...]

DESCRIPTION

shutdown peut être utilisé pour arrêter, éteindre ou redémarrer la machine.

Le premier argument peut être une chaîne de temps (généralement "now"). Optionnellement, cela peut être suivi d'un message de type "wall" à envoyer à tous les utilisateurs connectés avant l'arrêt.

La chaîne de temps peut être au format "hh:mm" pour l'heure/les minutes spécifiant le moment où l'arrêt doit avoir lieu, en utilisant l'horloge de 24 heures. Alternativement, elle peut être de la forme "+m" faisant référence au nombre spécifié de minutes m à partir de maintenant. "now" est un alias pour "+0", c'est-à-dire pour déclencher un arrêt immédiat. Si aucun argument de temps n'est spécifié, "+1" est implicite.

Notez que pour spécifier un message "wall", vous devez également spécifier un argument de temps.

Si l'argument de temps est utilisé, 5 minutes avant que le système ne s'arrête, le fichier /run/nologin est créé pour s'assurer que de nouvelles connexions ne seront pas autorisées.

OPTIONS

Les options suivantes sont comprises :

--help

Affiche un court message d'aide et quitte.

-H, --halt

Arrête la machine.

-P, --poweroff

Éteint la machine (par défaut).

-r, --reboot

Redémarre la machine.

-h

Identique à --poweroff, mais ne remplace pas l'action à effectuer si elle est "halt". Par exemple, shutdown --reboot -h signifie "poweroff", mais shutdown --halt -h signifie "halt".

-k

N'arrête, n'éteint ou ne redémarre pas, mais écrit simplement le message "wall".

--no-wall

N'envoie pas de message "wall" avant l'arrêt, l'extinction ou le redémarrage.

-c

Annule un arrêt en attente. Ceci peut être utilisé pour annuler l'effet d'une invocation de shutdown avec un argument de temps qui n'est pas "+0" ou "now".

--show

Affiche une action d'arrêt en attente et son heure, s'il y en a une.

Ajouté dans la version 250.

STATUT DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.

COMPATIBILITÉ

La commande shutdown des systèmes d'init précédents (y compris sysvinit) arrêtait la machine en mode mono-utilisateur par défaut au lieu de l'éteindre. Pour passer en mode mono-utilisateur, utilisez plutôt systemctl rescue.
