Documentation de la fonction/sous-programme

sous-routine shst01 (integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( ldh, * ) h, integer ldh, real, dimension( ldq, * ) q, integer ldq, real, dimension( lwork ) work, integer lwork, real, dimension( 2 ) result)

SHST01

Objectif:

!>
!> SHST01 teste la réduction d'une matrice générale A en forme de Hessenberg supérieure : A = Q*H*Q'. Deux rapports de test sont calculés ;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> La matrice Q est supposée être donnée explicitement telle qu'elle le serait
!> après SGEHRD + SORGHR.
!>
!> Dans cette version, ILO et IHI ne sont pas utilisés et sont supposés être 1 et
!> N, respectivement.
!>

Paramètres

N 
!>          N est un entier
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est un entier
!>

IHI

!>          IHI est un entier
!>
!>          On suppose que A est triangulaire supérieure dans les lignes et colonnes
!>          1:ILO-1 et IHI+1:N, donc Q ne diffère de l'identité que dans les
!>          lignes et colonnes ILO+1:IHI.
!>

A

!>          A est un tableau de réels, dimension (LDA,N)
!>          La matrice originale A de taille n x n.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

H

!>          H est un tableau de réels, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H issue de la réduction A = Q*H*Q'
!>          telle que calculée par SGEHRD.  On suppose que H est nulle en dessous de la
!>          première sous-diagonale.
!>

LDH

!>          LDH est un entier
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

Q

!>          Q est un tableau de réels, dimension (LDQ,N)
!>          La matrice orthogonale Q issue de la réduction A = Q*H*Q' telle que
!>          calculée par SGEHRD + SORGHR.
!>

LDQ

!>          LDQ est un entier
!>          La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau de réels, dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La longueur du tableau WORK.  LWORK >= 2*N*N.
!>

RESULT

!>          RESULT est un tableau de réels, dimension (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
