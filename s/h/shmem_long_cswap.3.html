shmem_long_cswap(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONG_CSWAP(3) Open MPI SHMEM_LONG_CSWAP(3)

shmem_int_cswap(3), shmem_int4_cswap(3), shmem_int8_cswap(3), shmem_long_cswap(3), shmem_longlong_cswap(3) - Effectue un échange conditionnel atomique sur un objet de données distant

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
int shmem_int_cswap(int *target, int cond, int value, int pe)
long shmem_long_cswap(long *target, long cond, long value,
  int pe)
long long shmem_longlong_cswap(longlong *target,
  longlong cond, longlong value, int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_CSWAP
ires = SHMEM_INT4_CSWAP(target, cond, value, pe)
INTEGER(KIND=8) SHMEM_INT8_CSWAP
ires = SHMEM_INT8_CSWAP(target, cond, value, pe)

DESCRIPTION

Les routines d'échange conditionnel mettent à jour conditionnellement un objet de données cible sur un élément de traitement (PE) arbitraire et retournent le contenu précédent de l'objet de données en une seule opération atomique.

Les arguments sont les suivants :

cible
L'objet de données entier accessible à distance à mettre à jour sur le PE distant. Si vous utilisez C/C++, le type de cible doit correspondre à celui implicite dans la section SYNTAXE. Si vous utilisez le compilateur Fortran, il doit être de type entier avec une taille d'élément de 4 octets pour SHMEM_INT4_ADD et de 8 octets pour SHMEM_INT8_ADD.
valeur
La valeur à ajouter atomiquement à cible. Si vous utilisez C/C++, le type de valeur doit correspondre à celui implicite dans la section SYNTAXE. Si vous utilisez Fortran, il doit être de type entier avec une taille d'élément égale à celle de cible.
pe
Un entier qui indique le numéro du PE sur lequel cible doit être mis à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
cible
L'objet de données entier accessible à distance à mettre à jour sur le PE distant. Si vous utilisez C/C++, le type de données de cible doit correspondre à celui implicite dans la section SYNTAXE. Si vous utilisez Fortran, il doit être du type suivant :

SHMEM_INT4_CSWAP : entier de 4 octets

SHMEM_INT8_CSWAP : entier de 8 octets

cond
cond est comparé à la valeur cible distante. Si cond et la cible distante sont égaux, alors valeur est échangée avec la cible distante. Sinon, la cible distante reste inchangée. Dans les deux cas, l'ancienne valeur de la cible distante est retournée comme valeur de retour de la fonction. cond doit être du même type de données que cible.
valeur
La valeur à écrire atomiquement sur le PE distant. valeur doit être du même type de données que cible.
pe
Un entier qui indique le numéro du PE sur lequel cible doit être mis à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

NOTES

Le terme accessible à distance est défini dans intro_shmem(3).

VALEURS DE RETOUR

Le contenu qui se trouvait dans l'objet de données cible sur le PE distant avant l'échange conditionnel.

EXEMPLES

L'appel suivant garantit que le premier PE à exécuter l'échange conditionnel écrira avec succès son numéro de PE dans race_winner sur le PE 0.

main()
{
  static int race_winner = -1;
  int oldval;
  shmem_init();
  oldval = shmem_int_cswap(&race_winner, -1, shmem_my_pe(), 0);
  if (oldval == -1)
    printf("pe %d etait le premier\n",shmem_my_pe());
}
