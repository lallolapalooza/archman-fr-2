shmem_barrier - Effectue une opération de barrière sur un sous-ensemble d'éléments de traitement (PE).

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
void shmem_barrier(int PE_start, int logPE_stride, int PE_size,
  long *pSync)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_BARRIER_SYNC_SIZE)
CALL SHMEM_BARRIER(PE_start, logPE_stride, PE_size, pSync)

DESCRIPTION

La routine shmem_barrier ne retourne que lorsque le sous-ensemble des PE spécifiés par PE_start, logPE_stride et PE_size est entré dans cette routine au même point du chemin d'exécution.

Comme pour toutes les routines collectives SHMEM, chacune de ces routines suppose que seuls les PE de l'ensemble actif appellent la routine. Si un PE qui n'appartient pas à l'ensemble actif appelle une routine collective SHMEM, un comportement indéfini en résulte.

Les arguments sont les suivants :

PE_start
Le plus petit numéro virtuel de PE de l'ensemble actif de PE. PE_start doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
logPE_stride
Le logarithme (base 2) du pas entre les numéros virtuels de PE consécutifs dans l'ensemble actif. logPE_stride doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
PE_size
Le nombre de PE dans l'ensemble actif. PE_size doit être de type entier. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.
pSync
Un tableau de travail symétrique. En C/C++, pSync doit être de type int et de taille _SHMEM_BARRIER_SYNC_SIZE. En Fortran, pSync doit être de type entier et de taille SHMEM_BARRIER_SYNC_SIZE. Si vous utilisez Fortran, il doit s'agir d'un type entier par défaut. Chaque élément de ce tableau doit être initialisé à 0 avant que l'un des PE de l'ensemble actif n'appelle shmem_barrier pour la première fois.

Les valeurs des arguments PE_start, logPE_stride et PE_size doivent être égales sur tous les PE de l'ensemble actif. Le même tableau de travail doit être passé dans pSync à tous les PE de l'ensemble actif.

shmem_barrier garantit que toutes les écritures locales précédemment émises et toutes les mises à jour de mémoire distante précédemment émises par l'un des PE de l'ensemble actif (en utilisant des appels SHMEM, par exemple shmem_put(3)) sont terminées avant de retourner.

Le même tableau pSync peut être réutilisé lors d'appels consécutifs à shmem_barrier si le même ensemble de PE actifs est utilisé.

NOTES

Le terme symétrique est défini dans intro_shmem(3).

Si le tableau pSync est initialisé au moment de l'exécution, assurez-vous d'utiliser une forme de synchronisation, par exemple un appel à shmem_barrier_all(3), avant d'appeler shmem_barrier pour la première fois.

Si l'ensemble actif ne change pas, shmem_barrier peut être appelé à plusieurs reprises avec le même tableau pSync. Aucune synchronisation supplémentaire au-delà de celle implicite par shmem_barrier lui-même n'est nécessaire dans ce cas.

EXEMPLES

Exemple C/C++ :

shmem_barrier(PE_start, logPE_stride, size, pSync);

Exemple Fortran :

INTEGER PSYNC(SHMEM_BARRIER_SYNC_SIZE)
INTEGER PE_START, LOGPE_STRIDE, PE_SIZE, PSYNC
DATA PSYNC /SHMEM_BARRIER_SYNC_SIZE*0/
CALL SHMEM_BARRIER(PE_START, LOGPE_STRIDE, PE_SIZE, PSYNC)
