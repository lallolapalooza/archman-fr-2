NOM

sh5util - Outil pour fusionner les fichiers HDF5 du plugin acct_gather_profile qui collecte des données détaillées pour les tâches exécutées sous Slurm

SYNTAXE

sh5util

DESCRIPTION

sh5util fusionne les fichiers HDF5 produits sur chaque nœud pour chaque étape d'une tâche en un seul fichier HDF5 pour la tâche. Le fichier résultant peut être visualisé et manipulé par des outils HDF5 courants tels que HDF5View, h5dump, h5edit ou h5ls.

sh5util possède également deux modes d'extraction. Le premier, écrit un ensemble limité de données pour des nœuds, étapes et séries de données spécifiques sous forme de "valeurs séparées par des virgules" dans un fichier qui peut être importé dans d'autres outils d'analyse tels que les tableurs.

Le second, (Extraction d'élément) extrait un élément de données d'une série de données pour tous les échantillons sur tous les nœuds du profil HDF5 d'une tâche.

- Trouve l'échantillon avec la valeur maximale de l'élément.

- Écrit un fichier CSV avec les totaux minimum, moyen, maximum et globaux pour chaque nœud pour chaque échantillon

OPTIONS

-E, --extract

Extraire des séries de données d'un fichier de tâche fusionné.

Options du mode d'extraction
-i, --input=chemin
fichier fusionné à partir duquel extraire (par défaut ./job_$jobid.h5)
-N, --node=nom_du_noeud
Nom du nœud à extraire (par défaut, tous)
-l, --level=[Node:Totals | Node:TimeSeries]
Niveau auquel la série est attachée. (par défaut Node:Totals)
-s, --series=[Energy | Filesystem | Network | Task | Task_#]
Task correspond à toutes les tâches, Task_# (# est un identifiant de tâche) (par défaut, tout)
-h, --help
Afficher cette description d'utilisation.
-I, --item-extract

Extraire un élément de données de tous les échantillons d'une série de données de tous les nœuds d'un fichier de tâche fusionné.

Options du mode Extraction d'élément
-s, --series=[Energy | Filesystem | Network | Task]
-d, --data
Nom de l'élément de données dans la série (voir note ci-dessous).
-j, --jobs=<tâche[.étape]>
Format : <tâche[.étape]>. Fusionner cette tâche/étape (ou une liste de tâches séparées par des virgules). Cette option est obligatoire. Ne pas spécifier d'étape entraînera le traitement de toutes les étapes trouvées.
-L, --list

Afficher les éléments d'une série contenus dans un fichier de tâche.

Options du mode Liste
-i, --input=chemin
Fichier fusionné à partir duquel extraire (par défaut ./job_$jobid.h5)
-s, --series=[Energy | Filesystem | Network | Task]
-o, --output=<chemin>
Chemin vers un fichier dans lequel écrire. Par défaut pour la fusion, ./job_$jobid.h5. Par défaut pour l'extraction, ./extract_$jobid.csv.
-p, --profiledir=<répertoire>
Emplacement du répertoire où se trouvent les fichiers de nœuds-étapes, par défaut défini dans acct_gather.conf.
-S, --savefiles
Au lieu de supprimer les fichiers de nœuds-étapes après les avoir fusionnés dans le fichier de tâche, les conserver.
--usage
Afficher un bref message d'utilisation.
--user=<utilisateur>
Utilisateur qui a profilé la tâche. (Utile pour l'utilisateur root, par défaut l'utilisateur exécutant cette commande.)

PERFORMANCE

L'exécution de sh5util envoie un appel de procédure distante à slurmctld. Si un nombre suffisant d'appels de sh5util ou d'autres commandes clientes Slurm qui envoient des appels de procédure distante au démon slurmctld arrivent simultanément, cela peut entraîner une dégradation des performances du démon slurmctld, potentiellement un déni de service.

N'exécutez pas sh5util ou d'autres commandes clientes Slurm qui envoient des appels de procédure distante à slurmctld à partir de boucles dans des scripts shell ou d'autres programmes. Assurez-vous que les programmes limitent les appels à sh5util au minimum nécessaire pour les informations que vous essayez de collecter.

EXEMPLES

Fusionner les fichiers de nœuds-étapes (dans le cadre d'un script sbatch) :
$ sbatch -n1 -d$SLURM_JOB_ID --wrap="sh5util --savefiles -j $SLURM_JOB_ID"
Extraire toutes les données de tâche d'un nœud :
$ sh5util -j 42 -N snowflake01 --level=Node:TimeSeries --series=Tasks
Extraire toutes les données d'énergie :
$ sh5util -j 42 --series=Energy --data=power
