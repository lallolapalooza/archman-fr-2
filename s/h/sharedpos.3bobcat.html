FBB::Sharedpos(3bobcat) Décalages de mémoire partagée FBB::Sharedpos(3bobcat)

NOM

FBB::Sharedpos - Contrôleur de décalage de mémoire partagée

SYNTAXE

#include <bobcat/sharedpos>
Option de liaison : -lbobcat

DESCRIPTION

La classe SharedPos est une classe de support pour les classes de gestion de mémoire partagée de Bobcat. Elle contrôle le décalage de lecture/écriture de la mémoire partagée et garantit que les opérations sur la mémoire partagée ne dépassent jamais le décalage maximal de la mémoire partagée.

La classe SharedPos a plusieurs membres publics, mais ils sont principalement utiles pour les autres classes Shared* proposées par Bobcat. Il y a probablement peu d'utilité pour un objet SharedPos autonome.

Dans les descriptions des fonctions membres de la classe, offset fait référence au décalage de lecture/écriture au sein d'un objet FBB::SharedSegment(3bobcat) pour lequel SharedPos effectue l'administration des décalages.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HÉRITE DE

-

TYPEDEFS ET ENUMS

CONSTRUCTEURS

Les constructeurs par défaut, de copie et de déplacement, ainsi que les opérateurs d'affectation par copie et par déplacement sont disponibles. Le constructeur par défaut ne surveille pas encore le décalage d'un objet FBB::SharedSegment. Le membre reset est utilisé pour commencer la surveillance des décalages.

OPÉRATEURS SURCHARGÉS

o
void operator++():
Le décalage est incrémenté. Si ce membre est appelé lorsque le décalage est égal au décalage maximal de la mémoire partagée, une FBB::Exception est levée.
o
void operator+=(size_t len):
Le décalage est incrémenté de len. Si offset + len dépasse le décalage maximal de la mémoire partagée, le décalage est défini sur le décalage maximal et une FBB::Exception est levée.
o
std::ostream &operator<<(std::ostream &out, SharedPos const &pos):
Insère des informations sur l'objet SharedPos dans out.

FONCTIONS MEMBRES

Note : le comportement des fonctions membres retournant des valeurs qui font référence à des informations d'un FBB::SharedSegment est indéfini jusqu'à ce que le membre reset ait été appelé.

o
bool atMaxOffset() const:
Retourne true si le décalage est égal au décalage maximal utilisable pour l'objet FBB::SharedSegment configuré.
o
size_t blockIdx() const:
L'indice du bloc de données du segment partagé de l'objet FBB::SharedSegment configuré auquel le décalage fait référence est retourné.
o
size_t blockOffset() const:
Le décalage au sein du bloc de données du segment partagé correspondant à la valeur de retour du membre offset est retourné.
o
bool eof() const:
Retourne true si le décalage dépasse le décalage maximal de tout caractère jamais écrit dans la mémoire partagée à laquelle l'objet SharedPos interface. Si eof retourne true, des informations peuvent toujours être écrites dans la mémoire partagée : l'écriture est possible jusqu'à ce que le décalage maximal du segment de mémoire partagée soit atteint.
o
std::streamsize eos() const:
Le décalage juste après le décalage maximal pour le bloc de données de segment partagé actuel est retourné. Par exemple, si blockIdx retourne 5, et que la taille des blocs de données de segment partagé est de 2000, alors eos retourne 12000 (le premier décalage du segment 6).
o
std::streamsize maxOffset() const:
Le décalage maximal possible pour le FBB::SharedSegment actuellement surveillé est retourné.
o
std::streamsize offset() const:
Le décalage au sein du segment de mémoire partagée actuellement surveillé est retourné.
o
void reset(SharedSegment *sharedData):
L'objet SharedPos est réinitialisé pour surveiller le décalage de l'objet FBB::SharedSegment dont l'adresse est passée en argument à reset. L'adresse doit pointer vers un objet sharedsegment(3bobcat) qui doit exister jusqu'à la fin de la durée de vie de l'objet SharedPos ou jusqu'à son prochain appel à reset. Immédiatement après l'appel à reset, le décalage est réinitialisé à 0.
o
std::streamsize showmanyc() const:
Le nombre de caractères pouvant être lus à partir du bloc de données de segment partagé actuel est retourné. Ce membre interroge le nombre de caractères lisibles dans le segment de mémoire partagée. Ce nombre peut changer pendant l'exécution de ce membre. Afin de recevoir une valeur de retour stable, les fonctions appelantes devraient avoir obtenu un verrou sur les données de FBB::SharedSegment avant d'appeler ce membre. Voir également la page de manuel sharedsegment(3bobcat).
o
std::ios::pos_type seek(std::ios::off_type offset, std::ios::seekdir origin = std::ios::beg):
Le décalage surveillé est modifié à l'argument offset de ce membre, par rapport à origin. Se déplacer au-delà de eof est OK. Cependant, -1 est retourné lors d'un déplacement au-delà de maxOffset ou avant le décalage 0 du segment partagé.

sharedpos(3bobcat) — libbobcat

NAME

sharedpos - shared position

SYNOPSIS

#include <bobcat/sharedpos>

namespace bobcat {

class sharedpos;

} // namespace bobcat

DESCRIPTION

This class is a value-object that represents a position. It is used as a generalisation for position information.

The sharedpos class is used to store position information. It is a value-object, which means that it is copied when it is assigned or passed as a parameter.

The position is represented by two integers, _col and _lin.

The class is used in combination with the sharedfile class.

NAMESPACE

bobcat

INHERITS FROM

None

TYPEDEFS AND ENUMS

None

CONSTRUCTORS

A default constructor is provided. The position is initialised to (0, 0).

sharedpos();

A constructor is provided to define the position.

sharedpos(int col, int lin);

OVERLOADED OPERATORS

The assignment operator is provided.

sharedpos &operator=(const sharedpos &rhs);

The equality and inequality operators are provided.

bool operator==(const sharedpos &rhs) const;
bool operator!=(const sharedpos &rhs) const;

The less-than operator is provided, to allow storing sharedpos objects in ordered containers.

bool operator<(const sharedpos &rhs) const;

MEMBER FUNCTIONS

The following member functions are provided:

int col() const;
int lin() const;

Return the column and line number.

void col(int col);
void lin(int lin);

Set the column and line number.

void clear();

Clear the position information.

std::ostream &operator<<(std::ostream &stream, const sharedpos &pos);

The position information is printed to the given output stream.

std::istream &operator>>(std::istream &stream, sharedpos &pos);

The position information is read from the given input stream.

EXAMPLE

A code example:

#include <bobcat/sharedpos>

int main()
{
    bobcat::sharedpos pos;
    pos.col(10);
    pos.lin(5);

    std::cout << "Column: " << pos.col() << std::endl;
    std::cout << "Line: " << pos.lin() << std::endl;

    return 0;
}
