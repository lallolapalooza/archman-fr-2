SHMEM_SET_LOCK(3) Open MPI SHMEM_SET_LOCK(3)

shmem_set_lock(3), shmem_clear_lock(3), shmem_test_lock(3) - Libère, verrouille et teste un verrou de mémoire à exclusion mutuelle.

SYNTAXE

C ou C++ :

#include <mpp/shmem.h>
void shmem_clear_lock(volatile long *lock)
void shmem_set_lock(volatile long *lock)
int shmem_test_lock(volatile long *lock)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER lock, SHMEM_TEST_LOCK
CALL SHMEM_CLEAR_LOCK(lock)
CALL SHMEM_SET_LOCK(lock)
I = SHMEM_TEST_LOCK(lock)

DESCRIPTION

La routine shmem_set_lock positionne un verrou à exclusion mutuelle après avoir attendu que le verrou soit libéré par tout autre PE qui le détient actuellement. Les PEs en attente sont assurés d'obtenir le verrou selon le principe du premier arrivé, premier servi.

La routine shmem_clear_lock libère un verrou précédemment positionné par shmem_set_lock après s'être assuré que tous les stockages locaux et distants initiés dans la région critique sont terminés.

La fonction shmem_test_lock positionne un verrou à exclusion mutuelle uniquement s'il est actuellement dégagé. En utilisant cette fonction, un PE peut éviter de bloquer sur un verrou défini. Si le verrou est actuellement positionné, la fonction renvoie sans attendre. Ces routines sont appropriées pour protéger une région critique contre une mise à jour simultanée par plusieurs PEs. Elles acceptent les arguments suivants :

lock
Un objet de données symétrique qui est une variable scalaire ou un tableau de longueur 1. Cet objet de données doit être initialisé à 0 sur tous les éléments de traitement (PE) avant la première utilisation. lock doit être de type entier. Si vous utilisez Fortran, il doit être de la sorte par défaut.

NOTES

Le terme objet de données symétrique est défini dans intro_shmem(3).

VALEURS DE RETOUR

La fonction shmem_test_lock renvoie 0 si le verrou était initialement dégagé et que cet appel a pu le positionner. Une valeur de 1 est renvoyée si le verrou avait été positionné et que l'appel est revenu sans attendre pour positionner le verrou.
