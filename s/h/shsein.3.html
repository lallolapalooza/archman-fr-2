sous-programme shsein (caractère side, caractère eigsrc, caractère initv, logique, dimension( * ) select, entier n, réel, dimension( ldh, * ) h, entier ldh, réel, dimension( * ) wr, réel, dimension( * ) wi, réel, dimension( ldvl, * ) vl, entier ldvl, réel, dimension( ldvr, * ) vr, entier ldvr, entier mm, entier m, réel, dimension( * ) work, entier, dimension( * ) ifaill, entier, dimension( * ) ifailr, entier info)

SHSEIN

Objectif :

!>
!> SHSEIN utilise l'itération inverse pour trouver les vecteurs propres droits et/ou gauches
!> spécifiés d'une matrice réelle de Hessenberg supérieure H.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de la matrice H
!> correspondant à une valeur propre w sont définis par :
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> où y**h dénote la transposée conjuguée du vecteur y.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : ne calculer que les vecteurs propres droits ;
!>          = 'L' : ne calculer que les vecteurs propres gauches ;
!>          = 'B' : calculer les deux vecteurs propres droits et gauches.
!>

EIGSRC

!>          EIGSRC est CHARACTER*1
!>          Spécifie la source des valeurs propres fournies dans (WR,WI) :
!>          = 'Q' : les valeurs propres ont été trouvées en utilisant SHSEQR ; ainsi, si
!>                 H a des éléments sous-diagonaux nuls, et est donc
!>                 triangulaire par blocs, alors la j-ème valeur propre peut
!>                 être supposée être une valeur propre du bloc contenant
!>                 la j-ème ligne/colonne. Cette propriété permet à SHSEIN
!>                 d'effectuer l'itération inverse sur un seul bloc diagonal.
!>          = 'N' : aucune supposition n'est faite quant à la correspondance
!>                 entre les valeurs propres et les blocs diagonaux. Dans ce
!>                 cas, SHSEIN doit toujours effectuer l'itération inverse
!>                 en utilisant toute la matrice H.
!>

INITV

!>          INITV est CHARACTER*1
!>          = 'N' : aucun vecteur initial n'est fourni ;
!>          = 'U' : les vecteurs initiaux fournis par l'utilisateur sont stockés dans les tableaux
!>                 VL et/ou VR.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          Spécifie les vecteurs propres à calculer. Pour sélectionner le
!>          vecteur propre réel correspondant à une valeur propre réelle WR(j),
!>          SELECT(j) doit être mis à .TRUE.. Pour sélectionner le
!>          vecteur propre complexe correspondant à une valeur propre complexe
!>          (WR(j),WI(j)), avec son conjugué complexe (WR(j+1),WI(j+1)),
!>          soit SELECT(j) soit SELECT(j+1) soit les deux doivent être mis à
!>          .TRUE. ; alors à la sortie SELECT(j) vaut .TRUE. et SELECT(j+1)
!>          vaut .FALSE..
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau RÉEL, de dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>          Si une valeur NaN est détectée dans H, la routine retournera avec INFO=-6.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

WR

!>          WR est un tableau RÉEL, de dimension (N)
!>

WI

!>          WI est un tableau RÉEL, de dimension (N)
!>
!>          À l'entrée, les parties réelles et imaginaires des valeurs propres de
!>          H ; une paire de valeurs propres complexes conjuguées doit être stockée dans
!>          des éléments consécutifs de WR et WI.
!>          À la sortie, WR peut avoir été modifié car les valeurs propres proches
!>          sont légèrement perturbées lors de la recherche de vecteurs propres indépendants.
!>

VL

!>          VL est un tableau RÉEL, de dimension (LDVL,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'L' ou 'B', VL doit
!>          contenir les vecteurs de départ pour l'itération inverse pour les
!>          vecteurs propres gauches ; le vecteur de départ pour chaque vecteur propre
!>          doit se trouver dans les mêmes colonnes dans lesquelles le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'L' ou 'B', les vecteurs propres gauches
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VL, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe est
!>          stocké dans deux colonnes consécutives, la première contenant la partie réelle
!>          et la seconde la partie imaginaire.
!>          Si SIDE = 'R', VL n'est pas référencé.
!>

LDVL

!>          LDVL est un ENTIER
!>          La dimension principale du tableau VL.
!>          LDVL >= max(1,N) si SIDE = 'L' ou 'B' ; LDVL >= 1 sinon.
!>

VR

!>          VR est un tableau RÉEL, de dimension (LDVR,MM)
!>          À l'entrée, si INITV = 'U' et SIDE = 'R' ou 'B', VR doit
!>          contenir les vecteurs de départ pour l'itération inverse pour les
!>          vecteurs propres droits ; le vecteur de départ pour chaque vecteur propre
!>          doit se trouver dans les mêmes colonnes dans lesquelles le vecteur propre sera
!>          stocké.
!>          À la sortie, si SIDE = 'R' ou 'B', les vecteurs propres droits
!>          spécifiés par SELECT seront stockés consécutivement dans les
!>          colonnes de VR, dans le même ordre que leurs valeurs propres. Un
!>          vecteur propre complexe correspondant à une valeur propre complexe est
!>          stocké dans deux colonnes consécutives, la première contenant la partie réelle
!>          et la seconde la partie imaginaire.
!>          Si SIDE = 'L', VR n'est pas référencé.
!>

LDVR

!>          LDVR est un ENTIER
!>          La dimension principale du tableau VR.
!>          LDVR >= max(1,N) si SIDE = 'R' ou 'B' ; LDVR >= 1 sinon.
!>

MM

!>          MM est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR requis pour
!>          stocker les vecteurs propres ; chaque vecteur propre réel sélectionné
!>          occupe une colonne et chaque vecteur propre complexe sélectionné
!>          occupe deux colonnes.
!>

WORK

!>          WORK est un tableau RÉEL, de dimension ((N+2)*N)
!>

IFAILL

!>          IFAILL est un tableau ENTIER, de dimension (MM)
!>          Si SIDE = 'L' ou 'B', IFAILL(i) = j > 0 si le vecteur propre gauche
!>          dans la i-ème colonne de VL (correspondant à la
!>          valeur propre w(j)) n'a pas convergé ; IFAILL(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante. Si les i-ème et (i+1)-ème
!>          colonnes de VL contiennent un vecteur propre complexe, alors IFAILL(i) et
!>          IFAILL(i+1) sont mis à la même valeur.
!>          Si SIDE = 'R', IFAILL n'est pas référencé.
!>

IFAILR

!>          IFAILR est un tableau ENTIER, de dimension (MM)
!>          Si SIDE = 'R' ou 'B', IFAILR(i) = j > 0 si le vecteur propre droit
!>          dans la i-ème colonne de VR (correspondant à la
!>          valeur propre w(j)) n'a pas convergé ; IFAILR(i) = 0 si le
!>          vecteur propre a convergé de manière satisfaisante. Si les i-ème et (i+1)-ème
!>          colonnes de VR contiennent un vecteur propre complexe, alors IFAILR(i) et
!>          IFAILR(i+1) sont mis à la même valeur.
!>          Si SIDE = 'L', IFAILR n'est pas référencé.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur incorrecte
!>          > 0 : si INFO = i, l'itération inverse n'a pas convergé pour le i-ème vecteur propre.
!>
