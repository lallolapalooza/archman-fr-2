SHOTCUT(1) Commandes utilisateur SHOTCUT(1)

NOM

shotcut - éditeur vidéo

SYNTAXE

shotcut [options] [FICHIER]...

OPTIONS

-h, --help
Affiche cette aide.
-v, --version
Affiche les informations sur la version.
--fullscreen
Remplir l'écran avec la fenêtre Shotcut.
--noupgrade
Masquer l'invite de mise à niveau et l'élément de menu.
--glaxnimate
Exécuter Glaxnimate à la place de Shotcut.
--gpu
Utiliser le traitement GPU.
--clear-recent
Effacer les fichiers récents à la sortie.
--appdata <répertoire>
Le répertoire pour la configuration et les données de l'application.
--QT_SCALE_FACTOR <nombre>
Le facteur d'échelle pour un écran haute résolution
--QT_SCREEN_SCALE_FACTORS <liste>
Une liste séparée par des points-virgules de facteurs d'échelle pour chaque écran.
--QT_SCALE_FACTOR_ROUNDING_POLICY <chaîne>
Comment gérer une échelle d'affichage fractionnaire : Round, Ceil, Floor, RoundPreferFloor, PassThrough
--SDL_AUDIODRIVER <chaîne>
Quelle API audio du système d'exploitation utiliser : alsa, arts, dsp, esd, jack, pipewire, pulseaudio

Arguments :

[FICHIER]...
Zéro ou plusieurs fichiers ou dossiers à ouvrir.

INTERNET

Il est préférable de commencer à https://shotcut.org/tutorials/
