shmem_int_fadd(3)

Paquet: openmpi

Licences: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_INT_FADD(3) Open MPI SHMEM_INT_FADD(3)

shmem_int4_fadd(3), shmem_int8_fadd(3), shmem_int_fadd(3), shmem_long_fadd(3), shmem_longlong_fadd(3) - Effectue une opération atomique de lecture-et-addition sur un objet de données distant

SYNOPSIS

C ou C++ :

#include <mpp/shmem.h>
int shmem_int_fadd(int *target, int value, int pe)
long shmem_long_fadd(long *target, long value, int pe)
long long shmem_longlong_fadd(long long *target, longlong value,
  int pe)

Fortran :

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_FADD, ires, target, value
ires = SHMEM_INT4_FADD(target, value, pe)
INTEGER(KIND=8) SHMEM_INT8_FADD, ires, target, value
ires = SHMEM_INT8_FADD(target, value, pe)

DESCRIPTION

Les fonctions shmem_fadd effectuent une opération atomique de lecture-et-addition. Une opération atomique de lecture-et-addition lit la cible actuelle et ajoute la valeur à la cible sans possibilité qu'un autre processus mette à jour la cible entre le moment de la lecture et la mise à jour. Ces routines ajoutent la valeur à la cible sur l'élément de traitement (PE) pe et retournent le contenu précédent de la cible comme une opération atomique.

Les arguments sont les suivants :

cible
L'objet de données entier accessible à distance à mettre à jour sur le PE distant. Le type de la cible doit correspondre à celui implicite dans la section SYNOPSIS.
valeur
La valeur à ajouter atomiquement à la cible. Le type de la valeur doit correspondre à celui implicite dans la section SYNOPSIS.
pe
Un entier qui indique le numéro du PE sur lequel la cible doit être mise à jour. Si vous utilisez Fortran, il doit s'agir d'une valeur entière par défaut.

NOTES

Le terme « accessible à distance » est défini dans intro_shmem(3).

VALEURS DE RETOUR

Le contenu qui se trouvait à l'adresse cible sur le PE distant avant l'opération d'addition atomique.
