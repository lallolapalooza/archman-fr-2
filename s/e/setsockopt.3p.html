SETSOCKOPT(3P) Manuel du programmeur POSIX SETSOCKOPT(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

setsockopt — définir les options de socket

SYNTAXE

#include <sys/socket.h>
int setsockopt(int socket, int level, int option_name,
    const void *option_value, socklen_t option_len);

DESCRIPTION

La fonction setsockopt() définit l'option spécifiée par l'argument option_name, au niveau de protocole spécifié par l'argument level, à la valeur pointée par l'argument option_value pour le socket associé au descripteur de fichier spécifié par l'argument socket.

L'argument level spécifie le niveau de protocole auquel l'option réside. Pour définir des options au niveau du socket, spécifiez l'argument level comme SOL_SOCKET. Pour définir des options à d'autres niveaux, fournissez l'identifiant level approprié pour le protocole contrôlant l'option. Par exemple, pour indiquer qu'une option est interprétée par TCP (Transport Control Protocol), définissez level à IPPROTO_TCP tel que défini dans l'en-tête <netinet/in.h>.

L'argument option_name spécifie une seule option à définir. Il peut s'agir de l'une des options de niveau socket définies dans <sys_socket.h> et décrites dans la Section 2.10.16, Utilisation des options. Si option_name est égal à SO_RCVTIMEO ou SO_SNDTIMEO et que l'implémentation prend en charge la définition de l'option, il n'est pas spécifié si la struct timeval pointée par option_value est stockée telle que fournie par cette fonction ou si elle est arrondie pour s'aligner sur la résolution de l'horloge utilisée. Si setsockopt() est appelée avec option_name égal à SO_ACCEPTCONN, SO_ERROR, ou SO_TYPE, le comportement n'est pas spécifié.

VALEUR RETOURNÉE

En cas de succès, setsockopt() renvoie 0. Sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction setsockopt() échoue si :

EBADF
L'argument socket n'est pas un descripteur de fichier valide.
EDOM
Les valeurs de délai d'attente d'envoi et de réception sont trop grandes pour tenir dans les champs de délai d'attente de la structure de socket.
EINVAL
L'option spécifiée est invalide au niveau de socket spécifié ou le socket a été arrêté.
EISCONN
Le socket est déjà connecté, et une option spécifiée ne peut pas être définie pendant que le socket est connecté.
ENOPROTOOPT

L'option n'est pas prise en charge par le protocole.
ENOTSOCK
L'argument socket ne fait pas référence à un socket.

La fonction setsockopt() peut échouer si :

ENOMEM
La mémoire disponible était insuffisante pour que l'opération s'achève.
ENOBUFS
Ressources suffisantes indisponibles dans le système pour compléter l'appel.

UTILISATION PAR L'APPLICATION

La fonction setsockopt() offre à un programme applicatif la possibilité de contrôler le comportement du socket. Un programme applicatif peut utiliser setsockopt() pour allouer de l'espace tampon, contrôler les délais d'attente ou autoriser la diffusion de données de socket. L'en-tête <sys/socket.h> définit les options de niveau socket disponibles pour setsockopt().

Des options peuvent exister à plusieurs niveaux de protocole. Les options SO_ sont toujours présentes au niveau le plus élevé du socket.
