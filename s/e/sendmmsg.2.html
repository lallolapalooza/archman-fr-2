sendmmsg(2) Manuel des appels système sendmmsg(2)

NOM

sendmmsg - envoyer plusieurs messages sur un socket

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <sys/socket.h>
int sendmmsg(unsigned int n;
             int sockfd, struct mmsghdr msgvec[n], unsigned int n,
             int flags);

DESCRIPTION

L'appel système sendmmsg() est une extension de sendmsg(2) qui permet à l'appelant de transmettre plusieurs messages sur un socket en un seul appel système. (Ceci présente des avantages de performance pour certaines applications.)

L'argument sockfd est le descripteur de fichier du socket sur lequel les données doivent être transmises.

L'argument msgvec est un pointeur vers un tableau de structures mmsghdr. La taille de ce tableau est spécifiée dans n.

La structure mmsghdr est définie dans <sys/socket.h> comme suit :


struct mmsghdr {
    struct msghdr msg_hdr;  /* En-tête du message */
    unsigned int  msg_len;  /* Nombre d'octets transmis */
};

Le champ msg_hdr est une structure msghdr, comme décrit dans sendmsg(2). Le champ msg_len est utilisé pour retourner le nombre d'octets envoyés à partir du message dans msg_hdr (c'est-à-dire le même que la valeur de retour d'un seul appel à sendmsg(2)).

L'argument flags contient des drapeaux combinés par OU. Les drapeaux sont les mêmes que pour sendmsg(2).

Un appel bloquant à sendmmsg() se bloque jusqu'à ce que n messages aient été envoyés. Un appel non bloquant envoie autant de messages que possible (jusqu'à la limite spécifiée par n) et retourne immédiatement.

Au retour de sendmmsg(), les champs msg_len des éléments successifs de msgvec sont mis à jour pour contenir le nombre d'octets transmis à partir de msg_hdr correspondant. La valeur de retour de l'appel indique le nombre d'éléments de msgvec qui ont été mis à jour.

VALEUR DE RETOUR

En cas de succès, sendmmsg() retourne le nombre de messages envoyés depuis msgvec ; si ce nombre est inférieur à n, l'appelant peut réessayer avec un autre appel sendmmsg() pour envoyer les messages restants.

En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Les erreurs sont les mêmes que pour sendmsg(2). Une erreur n'est retournée que si aucun datagramme n'a pu être envoyé. Voir aussi BUGS.

NORMES

Linux.

HISTORIQUE

Linux 3.0, glibc 2.14.

NOTES

La valeur spécifiée dans n est plafonnée à UIO_MAXIOV (1024).

BUGS

Si une erreur se produit après qu'au moins un message ait été envoyé, l'appel réussit et retourne le nombre de messages envoyés. Le code d'erreur est perdu. L'appelant peut réessayer la transmission, en commençant par le premier message échoué, mais il n'y a aucune garantie que, si une erreur est retournée, ce sera la même que celle qui a été perdue lors de l'appel précédent.

EXEMPLES

L'exemple ci-dessous utilise sendmmsg() pour envoyer onetwo et three dans deux datagrammes UDP distincts en un seul appel système. Le contenu du premier datagramme provient d'une paire de tampons.

#define _GNU_SOURCE
#include <arpa/inet.h>
#include <netinet/in.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/types.h>
int
main(void)
{
    int                 retval;
    int                 sockfd;
    struct iovec        msg1[2], msg2;
    struct mmsghdr      msg[2];
    struct sockaddr_in  addr;
    sockfd = socket(AF_INET, SOCK_DGRAM, 0);
    if (sockfd == -1) {
        perror("socket()");
        exit(EXIT_FAILURE);
    }
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
    addr.sin_port = htons(1234);
    if (connect(sockfd, (struct sockaddr *) &addr, sizeof(addr)) == -1) {
        perror("connect()");
        exit(EXIT_FAILURE);
    }
    memset(msg1, 0, sizeof(msg1));
    msg1[0].iov_base = "one";
    msg1[0].iov_len = 3;
    msg1[1].iov_base = "two";
    msg1[1].iov_len = 3;
    memset(&msg2, 0, sizeof(msg2));
    msg2.iov_base = "three";
    msg2.iov_len = 5;
    memset(msg, 0, sizeof(msg));
    msg[0].msg_hdr.msg_iov = msg1;
    msg[0].msg_hdr.msg_iovlen = 2;
    msg[1].msg_hdr.msg_iov = &msg2;
    msg[1].msg_hdr.msg_iovlen = 1;
    retval = sendmmsg(sockfd, msg, 2, 0);
    if (retval == -1)
        perror("sendmmsg()");
    else
        printf("%d messages sent\n", retval);
    exit(0);
}
