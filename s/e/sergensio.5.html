NOM

sergensio - Comment utiliser un gensio série

DESCRIPTION

NOTE : sergensio est obsolète, les fonctionnalités pour cela ne sont plus gérées par les fonctions acontrol() et control() dans le type gensio principal.

Un objet sergensio est un type de gensio qui fournit des fonctions de port série. Il ne peut pas être créé directement, vous créez plutôt un gensio qui possède des capacités de port série et vous le casttez en utilisant la fonction gensio_to_sergensio().

Un objet sergensio peut être un client, ce qui signifie que vous pouvez définir des paramètres de port série pour ce gensio. C'est ce à quoi vous vous attendriez normalement, et cela fonctionne pour tous les types de ports série.

Un objet sergensio peut également être un serveur, ce qui signifie qu'il peut recevoir des requêtes de l'extrémité distante pour définir des paramètres de port série. Actuellement, seul le gensio telnet a la capacité serveur, donc une extrémité distante peut demander que des paramètres de port série soient définis.
