semind(1) Manuel des commandes générales semind(1)

NOM

semind - Indexeur sémantique pour C

SYNTAXE

semind [options]
semind [options] add [options de commande] [--] [options du compilateur] [fichiers...]
semind [options] rm [options de commande] modèle
semind [options] search [options de commande] [modèle]
semind [options] search [options de commande] (-e|-l) nom_fichier:num_ligne:colonne

DESCRIPTION

semind est l'outil de type cscope simple à utiliser basé sur sparse/dissect. Contrairement à cscope, il s'exécute après le préprocesseur et ne peut donc pas indexer le code filtré par les directives ifdef, mais il comprend comment le symbole est utilisé et peut suivre l'utilisation des membres de structures.

SOUS-COMMANDES

add
génère ou met à jour le fichier d'index sémantique.
rm
supprime des fichiers de l'index par modèle. Le modèle est un modèle de caractères génériques glob(7).
search
interroge des informations sur un symbole par modèle. Le modèle est un modèle de caractères génériques glob(7).

OPTIONS COMMUNES

-D, --database=FICHIER
spécifie le fichier de base de données (par défaut : ./semind.sqlite).
-v, --verbose
affiche des informations sur ce qui est en cours.
-h, --help
affiche ce texte et quitte.

OPTIONS ADD

--include-local-syms
inclut les symboles locaux dans l'index.

OPTIONS SEARCH

-f, --format=CHAINE
spécifie un format de sortie. Par défaut : '(%m) %f\t%l\t%c\t%C\t%s' (voir FORMAT ci-dessous).
-p, --path=MODÈLE
recherche les symboles uniquement dans les répertoires spécifiés.
-m, --mode=MODE
recherche uniquement le type d'accès spécifié (voir MODE ci-dessous).
-k, --kind=TYPE
spécifie un type de symbole (voir TYPE ci-dessous).
-e, --explain
montre ce qui se passe à la position spécifiée du fichier ;
-l, --location
montre l'utilisation des symboles à partir d'une position spécifique du fichier ;
-v, --verbose
affiche des informations sur ce qui est en cours ;
-h, --help
affiche ce texte et quitte.

FORMAT

%m
mode d'accès sous forme lisible (voir MODE ci-dessous).
%f
nom du fichier.
%l
numéro de ligne.
%c
numéro de colonne.
%C
le nom de la fonction dans laquelle le symbole apparaît.
%n
nom du symbole.
%s
ligne de code source. L'indexeur ne sauvegarde pas les lignes de code source. Elles sont lues à partir du fichier pendant la recherche.

TYPE

f
fonction
s
structure
m
membre de structure

MODE

Le MODE est représenté par une chaîne de 3 lettres. La première lettre indique la partie d'adresse, la 2ème - l'accès en lecture, la 3ème - l'accès par pointeur. Une valeur spéciale 'def' signifie une définition de symbole.

r
lecture
w
écriture
m
lecture et écriture
