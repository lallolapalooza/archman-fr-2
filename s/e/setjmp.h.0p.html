setjmp.h(0P) Manuel du programmeur POSIX setjmp.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

setjmp.h — déclarations d'environnement de pile

SYNOPIS

#include <setjmp.h>

DESCRIPTION

Certaines des fonctionnalités décrites sur cette page de référence étendent la norme ISO C. Les applications doivent définir la macro de test de fonctionnalité appropriée (voir le volume Interfaces système de POSIX.1‐2017, Section 2.2, L'environnement de compilation) pour activer la visibilité de ces symboles dans cet en-tête.

L'en-tête <setjmp.h> doit définir les types de tableaux jmp_buf et sigjmp_buf.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme macros. Des prototypes de fonctions doivent être fournis.

void   _longjmp(jmp_buf, int);
void   longjmp(jmp_buf, int);
void   siglongjmp(sigjmp_buf, int);

Les éléments suivants peuvent être déclarés comme fonctions, ou définis comme macros, ou les deux. Si des fonctions sont déclarées, des prototypes de fonctions doivent être fournis.

int    _setjmp(jmp_buf);
int    setjmp(jmp_buf);
int    sigsetjmp(sigjmp_buf, int);
