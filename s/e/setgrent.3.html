getgrent(3) Manuel des fonctions de bibliothèque getgrent(3)

NOM

getgrent, setgrent, endgrent — obtenir une entrée du fichier de groupes

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/types.h>
#include <grp.h>
struct group *getgrent(void);
void setgrent(void);
void endgrent(void);
Exigences de Macro de Test de Fonctionnalité pour glibc (voir feature_test_macros(7)):

setgrent():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

getgrent(), endgrent():

    Depuis glibc 2.22 :
        _XOPEN_SOURCE >= 500 || _DEFAULT_SOURCE
    glibc 2.21 et antérieures
        _XOPEN_SOURCE >= 500
            || /* Depuis glibc 2.12 : */ _POSIX_C_SOURCE >= 200809L
            || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction getgrent() renvoie un pointeur vers une structure contenant les champs décomposés d'un enregistrement dans la base de données des groupes (par exemple, le fichier de groupes local /etc/group, NIS et LDAP). La première fois que getgrent() est appelée, elle renvoie la première entrée ; par la suite, elle renvoie les entrées successives.

La fonction setgrent() rembobine au début de la base de données des groupes, pour permettre des analyses répétées.

La fonction endgrent() est utilisée pour fermer la base de données des groupes après l'exécution de tout traitement.

La structure group est définie dans <grp.h> comme suit :


struct group {
    char   *gr_name;        /* nom du groupe */
    char   *gr_passwd;      /* mot de passe du groupe */
    gid_t   gr_gid;         /* identifiant du groupe */
    char  **gr_mem;         /* tableau terminé par NULL de pointeurs
                               vers les noms des membres du groupe */
};

Pour plus d'informations sur les champs de cette structure, voir group(5).

VALEUR DE RETOUR

La fonction getgrent() renvoie un pointeur vers une structure group, ou NULL s'il n'y a plus d'entrées ou si une erreur se produit.

En cas d'erreur, errno peut être défini. Si l'on souhaite vérifier errno après l'appel, il doit être mis à zéro avant l'appel.

La valeur de retour peut pointer vers une zone statique et peut être écrasée par des appels ultérieurs à getgrent(), getgrgid(3), ou getgrnam(3). (Ne pas passer le pointeur renvoyé à free(3).)

ERREURS

EAGAIN
Le service était temporairement indisponible ; réessayez plus tard. Pour les backends NSS dans glibc, cela indique une erreur temporaire lors de la communication avec le backend. L'erreur peut se corriger d'elle-même ; il est suggéré de réessayer plus tard.
EINTR
Un signal a été intercepté ; voir signal(7).
EIO
Erreur d'E/S.
EMFILE
La limite par processus sur le nombre de descripteurs de fichiers ouverts a été atteinte.
ENFILE
La limite du système sur le nombre total de fichiers ouverts a été atteinte.
ENOENT
Un fichier d'entrée nécessaire ne peut pas être trouvé. Pour les backends NSS dans glibc, cela indique que le backend n'est pas correctement configuré.
ENOMEM
Mémoire insuffisante pour allouer la structure group.
ERANGE
Espace tampon insuffisant fourni.

FICHIERS

/etc/group
fichier de base de données des groupes locaux

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getgrent () Sécurité des threads MT-Unsafe race:grent race:grentbuf locale
setgrent (), endgrent () Sécurité des threads MT-Unsafe race:grent locale

Dans le tableau ci-dessus, grent dans race:grent signifie que si l'une des fonctions setgrent(), getgrent(), ou endgrent() est utilisée en parallèle dans différents threads d'un programme, des courses de données pourraient survenir.

HISTORIQUE
