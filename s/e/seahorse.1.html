SEAHORSE(1) Commandes utilisateur SEAHORSE(1)

NOM

seahorse - Mots de passe et clés

SYNTAXE

seahorse [OPTIONS...] [FICHIERS...]

DESCRIPTION

Seahorse est une interface graphique pour la gestion et l'utilisation de clés de chiffrement, de mots de passe et de certificats. Actuellement, il prend en charge les clés PGP (via GPG/GPGME) et les clés SSH. Son objectif est de fournir un outil de gestion de clés facile à utiliser, ainsi qu'une interface facile à utiliser pour les opérations de chiffrement.

OPTIONS

-?, --help

Affiche un court message d'aide et quitte.

--help-all

Affiche toutes les options d'aide

--help-gtk

Affiche toutes les options GTK

OPTIONS DE L'APPLICATION

-v, --version

Version de cette application

--display=AFFICHAGE

Écran X à utiliser

BOGUES

Si vous trouvez un bogue, veuillez le signaler à https://gitlab.gnome.org/GNOME/seahorse/issues/.
