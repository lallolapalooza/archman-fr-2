NOM

setup-plt - outil de configuration Racket de compatibilité

SYNOPSIS

setup-plt [ option ... ] [ argument ... ]

DESCRIPTION

setup-plt fournit une ancienne interface à certains outils Racket qui sont maintenant normalement fournis via raco.

Exécutez


setup-plt --help

pour une liste des options en ligne de commande.

PLUS D'INFORMATIONS

Pour plus d'informations, exécutez


raco help

pour ouvrir la documentation installée dans votre navigateur web.

Alternativement, consultez la documentation en ligne et d'autres informations disponibles sur


http://racket-lang.org/
