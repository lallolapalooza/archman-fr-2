NOM

sensors-conf-convert - conversion de configuration des capteurs

SYNTAXE

sensors-conf-convert < /etc/sensors.conf > /etc/sensors3.conf

DESCRIPTION

Le but de l'outil sensors-conf-convert est de convertir sensors.conf du format de la version 2 de lm_sensors au format de la version 3 de lm_sensors.

Le fichier de configuration ancien est lu depuis l'entrée standard et le nouveau est écrit sur la sortie standard.

VOIR AUSSI

sensors(1), libsensors(3)
