NOM

sensors - afficher les informations des capteurs

SYNTAXE

sensors [ options ] [ puces ]
sensors -s [ puces ]
sensors --bus-list

DESCRIPTION

sensors est utilisé pour afficher les lectures actuelles de toutes les puces de capteurs.
sensors -s est utilisé pour définir toutes les limites comme spécifié dans le fichier de configuration.
sensors --bus-list est utilisé pour générer des instructions bus appropriées pour le fichier de configuration.

OPTIONS

-c, --config-file fichier-config
Spécifiez un fichier de configuration. Si aucun fichier n'est spécifié, le fichier de configuration par défaut de libsensors est utilisé. Utilisez `-c /dev/null' pour désactiver temporairement ce fichier de configuration par défaut.
-h, --help
Affiche un texte d'aide et quitte.
-s, --set
Évalue toutes les instructions `set' du fichier de configuration et quitte. Vous devez être `root' pour ce faire. Si ce paramètre n'est pas spécifié, aucune instruction `set' n'est évaluée.
-A, --no-adapter
N'affiche pas l'adaptateur pour chaque puce.
-u
Sortie brute. Ce mode convient au débogage et au post-traitement de la sortie par des scripts. Il est également utile lors de l'écriture d'un fichier de configuration car il montre les noms d'entrée bruts qui doivent être référencés dans le fichier de configuration.
-j
Sortie Json.
-J
Nouvelle sortie json. Ce mode convient au post-traitement de la sortie par des scripts.
-v, --version
Affiche la version du programme et quitte.
-f, --fahrenheit
Affiche les températures en degrés Fahrenheit au lieu de Celsius.
--bus-list
Génère des instructions bus appropriées pour une utilisation dans sensors.conf. De telles instructions bus ne sont nécessaires que si plusieurs puces partagent la même adresse sur différents bus du même type. Comme les numéros de bus ne sont généralement pas garantis d'être stables après les redémarrages, ces instructions vous permettent de faire référence à chaque bus par son nom plutôt que par des numéros.
-n, --allow-no-sensors
Ne pas échouer si aucun capteur n'est trouvé. Le message d'erreur sera imprimé dans le journal.

FICHIERS

/etc/sensors3.conf
/etc/sensors.conf

Le fichier de configuration système. Voir sensors.conf(5) pour plus de détails.

VOIR AUSSI

sensors.conf(5), sensors-detect(8).
