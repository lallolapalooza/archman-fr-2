NOM

seccomp_release - Libérer l'état du filtre seccomp

SYNOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

void seccomp_release(scmp_filter_ctx ctx);

Lier avec -lseccomp.

DESCRIPTION

Libère le filtre seccomp dans ctx qui a été initialisé par seccomp_init(3) ou seccomp_reset(3) et libère toute mémoire associée au contexte de filtre seccomp donné. Les filtres seccomp chargés dans le noyau ne sont pas affectés.

VALEUR DE RETOUR

Ne retourne aucune valeur.

EXEMPLES

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		return 1;
	/* ... */
	seccomp_release(ctx);
	return 0;
}

NOTES

Bien que le filtre seccomp puisse être généré indépendamment du noyau, le support du noyau est nécessaire pour charger et appliquer le filtre seccomp généré par libseccomp.

Le site du projet libseccomp, avec plus d'informations et le dépôt de code source, se trouve à l'adresse https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, est actuellement en cours de développement. Veuillez signaler tout bogue sur le site du projet ou directement à l'auteur.
