sem_open(3) Manuel des fonctions de bibliothèque sem_open(3)

NOM

sem_open - initialiser et ouvrir un sémaphore nommé

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <fcntl.h>           /* Pour les constantes O_* */
#include <sys/stat.h>        /* Pour les constantes de mode */
#include <semaphore.h>
sem_t *sem_open(const char *name, int oflag, ...
                /* mode_t mode, unsigned int value */ );

DESCRIPTION

sem_open() crée un nouveau sémaphore POSIX ou ouvre un sémaphore existant. Le sémaphore est identifié par name. Pour les détails de la construction de name, voir sem_overview(7).

L'argument oflag spécifie les drapeaux qui contrôlent le fonctionnement de l'appel. (Les définitions des valeurs des drapeaux peuvent être obtenues en incluant <fcntl.h>.) Si O_CREAT est spécifié dans oflag, alors le sémaphore est créé s'il n'existe pas déjà. Le propriétaire (ID utilisateur) du sémaphore est défini à l'ID utilisateur effectif du processus appelant. Le groupe propriétaire (ID groupe) est défini à l'ID groupe effectif du processus appelant. Si O_CREAT et O_EXCL sont tous deux spécifiés dans oflag, alors une erreur est retournée si un sémaphore avec le nom donné existe déjà.

Si O_CREAT est spécifié dans oflag, alors deux arguments supplémentaires doivent être fournis. L'argument mode spécifie les permissions à appliquer au nouveau sémaphore, comme pour open(2). (Les définitions symboliques des bits de permissions peuvent être obtenues en incluant <sys/stat.h>.) Les paramètres de permissions sont masqués par le umask du processus. Des permissions de lecture et d'écriture doivent être accordées à chaque classe d'utilisateur qui accédera au sémaphore. L'argument value spécifie la valeur initiale pour le nouveau sémaphore. Si O_CREAT est spécifié, et qu'un sémaphore avec le nom donné existe déjà, alors mode et value sont ignorés.

VALEUR DE RETOUR

En cas de succès, sem_open() retourne l'adresse du nouveau sémaphore ; cette adresse est utilisée lors de l'appel d'autres fonctions liées aux sémaphores. En cas d'erreur, sem_open() retourne SEM_FAILED, avec errno défini pour indiquer l'erreur.

ERREURS

EACCES
Le sémaphore existe, mais l'appelant n'a pas la permission de l'ouvrir.
EEXIST
O_CREAT et O_EXCL étaient tous deux spécifiés dans oflag, mais un sémaphore avec ce nom existe déjà.
EINVAL
value était supérieur à SEM_VALUE_MAX.
EINVAL
name consiste uniquement en "/", suivi d'aucun autre caractère.
EMFILE
La limite par processus sur le nombre de descripteurs de fichiers ouverts a été atteinte.
ENAMETOOLONG
name était trop long.
ENFILE
La limite globale du système sur le nombre total de fichiers ouverts a été atteinte.
ENOENT
L'indicateur O_CREAT n'a pas été spécifié dans oflag et aucun sémaphore avec ce nom n'existe ; ou, O_CREAT a été spécifié, mais name n'était pas bien formé.
ENOMEM
Mémoire insuffisante.
