senpai(5) Manuel des formats de fichiers senpai(5)

NOM

senpai - Format de fichier de configuration et paramètres

DESCRIPTION

Un fichier de configuration senpai est un fichier scfg. Voir https://git.sr.ht/~emersion/scfg.

Certains paramètres sont requis, les autres sont facultatifs.

PARAMÈTRES

address (requis)

L'adresse (hôte[:port]) du serveur IRC. senpai utilise des connexions TLS par défaut, sauf si vous spécifiez l'option tls à false. Les connexions TLS utilisent le port 6697 par défaut, le texte brut utilise le port 6667.

Un schéma facultatif peut être spécifié (schéma://hôte[:port]) :

  • irc:// est le défaut implicite, TLS est activé ou désactivé selon la valeur de configuration tls.
  • ircs:// active TLS.
  • irc+insecure:// désactive TLS (IRC en texte brut).
  • ircs+insecure:// active TLS mais ignore la vérification du certificat TLS. Ceci protège contre les attaques MITM passives mais pas contre les attaques MITM actives.

nickname (requis)

Votre pseudo, envoyé avec un message IRC NICK. Il ne doit pas contenir d'espaces ou de deux-points (:).

realname

Votre nom réel, ou en fait juste un champ qui sera disponible pour les autres et qui peut contenir des espaces et des deux-points. Envoyé avec le message IRC USER. Par défaut, la valeur de nick est utilisée.

username

Votre nom d'utilisateur, envoyé avec le message IRC USER et également utilisé pour l'authentification SASL. Par défaut, la valeur de nick est utilisée.

password

Votre mot de passe, utilisé pour l'authentification SASL. Voir aussi password-cmd.

password-cmd commande [arguments...]

Au lieu de fournir votre mot de passe d'authentification SASL directement en clair, vous pouvez spécifier une commande à exécuter pour récupérer le mot de passe à l'exécution. Ceci est utile si vous stockez vos mots de passe dans un fichier séparé (probablement chiffré) en utilisant `gpg` ou un gestionnaire de mots de passe en ligne de commande tel que pass ou gopass. Si une commande password-cmd est fournie, la valeur de password sera ignorée et la première ligne de la sortie de password-cmd sera utilisée pour la connexion.

La commande et les arguments sont déjà mis entre guillemets par scfg, il n'est donc pas nécessaire de mettre en guillemets supplémentaires toute la chaîne de commande. Par exemple :

password-cmd pass "Messaging/irc"

channel

Une liste séparée par des espaces de noms de canaux auxquels senpai se joindra automatiquement au démarrage et lors de la reconnexion au serveur. Cette directive peut être spécifiée plusieurs fois.

Cette directive ne doit pas être utilisée avec un bouncer, car le bouncer se souvient déjà et rejoint automatiquement senpai à ses canaux sauvegardés.

highlight

Une liste séparée par des espaces de mots-clés qui déclencheront une notification et un indicateur d'affichage lorsqu'ils seront prononcés par d'autres. Cette directive peut être spécifiée plusieurs fois.

Par défaut, senpai utilisera votre pseudo actuel.

on-highlight-beep

Active l'envoi du caractère de sonnerie (BEL) lorsque vous êtes mis en évidence. Désactivé par défaut.

pane-widths { ... }

Configure la largeur de divers panneaux d'interface utilisateur.

Les largeurs de panneaux sont définies comme des sous-directives de la directive principale pane-widths :

pane-widths {
    nicknames 16
}
Cette directive supporte les sous-directives suivantes :

nicknames

Le nombre de cellules occupées par la colonne des pseudos dans la chronologie. Par défaut, 14.

channels

Le nombre de cellules occupées par la colonne des canaux à l'écran. Par défaut, 16. Utilisez la valeur spéciale 0 pour rendre la liste des canaux horizontale. Si la valeur est négative, la liste des canaux sera horizontale par défaut et prendra la valeur de largeur positive (opposée) lorsqu'elle sera basculée avec F7.

members

Le nombre de cellules occupées par la colonne de la liste des membres du canal à l'écran. Par défaut, 16. Utilisez la valeur spéciale 0 pour désactiver. Si la valeur est négative, la liste des membres sera désactivée par défaut et prendra la valeur de largeur positive (opposée) lorsqu'elle sera basculée avec F8.

text

La largeur maximale de ligne de texte des messages, en nombre de cellules. Par défaut, la valeur est zéro, ce qui signifie qu'il n'y a pas de maximum. Utile pour conserver une largeur de ligne lisible sur de grands écrans.

tls

Active le chiffrement TLS. Par défaut, vrai.

typings

Envoie des notifications de frappe qui indiquent aux autres quand vous tapez un message. Par défaut, vrai.

mouse

Active ou désactive la prise en charge de la souris. Par défaut, vrai.

colors { ... }

Paramètres pour les couleurs des différents éléments de l'interface utilisateur.

Les couleurs peuvent être définies soit par leur nom ("red"), soit par leur numéro (de 0 à 255, pour les 256 couleurs de terminal par défaut ; -1 signifie par défaut), soit par leur couleur hexadécimale RVB vraie (#rrggbb).

Les couleurs sont définies comme des sous-directives de la directive principale colors :

colors {
    prompt green
}
Sous-directive Description
prompt <couleur> couleur pour l'invite ">" qui apparaît en mode commande
unread <couleur> couleur du premier plan pour les noms de tampons non lus dans les listes de tampons
status [...] couleur du premier plan pour les lignes d'événements de statut (par exemple, join, part, changement de pseudo) dans les tampons, voir le tableau ci-dessous
nicks [...] schéma de couleurs pour les pseudos des utilisateurs, voir le tableau ci-dessous
Sous-directive status Description
status <couleur> affiche les événements de statut avec la couleur spécifiée
status disabled masque les événements de statut
Sous-directive nicks Description
nicks base affiche les pseudos avec 16 couleurs différentes (par défaut)
nicks extended affiche les pseudos avec 256 couleurs différentes
nicks fixed [<autres>] affiche les pseudos avec une couleur fixe, spécifiant éventuellement les couleurs pour les autres pseudos
nicks self <self> affiche le pseudo de soi-même avec une couleur fixe spécifiée (peut être ajouté avec d'autres directives)

debug

Avancé. Déverse toutes les données envoyées et reçues dans le tampon d'accueil, utile pour le débogage. Par défaut, faux.

-transient

Avancé. Exécute une instance éphémère sans lecture/écriture sur disque (à l'exception de la configuration initiale). Peut être utile pour les instances publiques. Par défaut, faux.

-local-integrations

Avancé. Active les intégrations avec le système local (par exemple, les notifications via DBus). Peut être utile de désactiver sur les systèmes prévus pour être utilisés via SSH. Par défaut, vrai.

on-highlight-path

Avancé. senpai vous notifiera par défaut sans avoir besoin d'un script de mise en évidence personnalisé. Chemin alternatif vers un script shell à exécuter lorsque vous êtes mis en évidence. Par défaut, senpai recherche un script shell de mise en évidence à l'emplacement $XDG_CONFIG_HOME/senpai/highlight. Si aucun fichier n'est trouvé à cet endroit et qu'un chemin alternatif n'est pas fourni, l'exécution de la commande de mise en évidence est désactivée.

Si non défini, $XDG_CONFIG_HOME est défini par défaut à ~/.config/.

Avant que le script de mise en évidence ne soit exécuté, les variables d'environnement suivantes sont renseignées :

Les scripts shell DOIVENT S'ASSURER QUE LES VARIABLES sont bien entre guillemets dans le fichier script, OU VOUS SEREZ EXPOSÉ À DES VULNÉRABILITÉS D'INJECTION DE COMMANDE. Les scripts shell doivent également s'assurer que des caractères tels que '*' et '?' ne sont pas développés.

Variable d'environnement Description
BUFFER tampon où le message est apparu
HERE égal à 1 si BUFFER est le tampon actuel, 0 sinon
MESSAGE contenu du message
SENDER Nom d'utilisateur de l'expéditeur
Note: lors de la transmission de ceux-ci à notify-send(1), certains démons de notification utilisent \ pour les séquences d'échappement dans le corps, ce qui fait disparaître \ du message ou déclenche des effets secondaires involontaires (comme de nouvelles lignes).

Pour contourner cela, vous pouvez doubler le backslash avec le fragment de code suivant :

#!/bin/sh
escape() {
	printf "%s" "$1" | sed 's#\#\\#g'
}
notify-send "[$BUFFER] $SENDER" "$(escape "$MESSAGE")"

EXEMPLES

Un fichier de configuration minimal pour se connecter à Libera.Chat en tant que "Guest123456" :

address irc.libera.chat
nickname Guest123456

Un fichier de configuration plus avancé qui récupère un mot de passe d'un programme externe, modifie la largeur de certains panneaux et active plus de couleurs pour les pseudos des utilisateurs :

address irc.libera.chat
nickname Guest123456
username senpai
realname "Guest von Lenon"
password-cmd gopass show irc/guest # utilisez votre solution de mot de passe CLI préférée ici
channel "#rahxephon"
pane-widths {
	nicknames 10
	channels 16
	members 16
}
colors {
	nicks extended
}
