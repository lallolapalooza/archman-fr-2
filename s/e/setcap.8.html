NOM

setcap - définir les capacités de fichier

SYNTAXE

setcap [-q] [-n <uid_root>] [-v] {capacités|-|*--r*filename [ ... capacitésN fichierN ]

DESCRIPTION

En l'absence de l'option -v (vérifier), setcap définit les capacités de chaque filename spécifié aux capacités spécifiées. L'argument optionnel -n <uid_root> peut être utilisé pour définir la capacité de fichier à utiliser uniquement dans un espace de noms utilisateur avec cet ID utilisateur racine propriétaire. L'option -v est utilisée pour vérifier que les capacités spécifiées sont actuellement associées au fichier. Si -v et -n sont fournis, l'argument -n <uid_root> est également vérifié.

Les ensembles de capacités sont spécifiés sous la forme décrite dans cap_text_formats(7).

La chaîne de capacités spéciale, '-', peut être utilisée pour indiquer que les capacités sont lues depuis l'entrée standard. Dans de tels cas, l'ensemble de capacités est terminé par une ligne vide.

La chaîne de capacités spéciale, '-r', est utilisée pour supprimer un ensemble de capacités d'un fichier. Notez que définir un ensemble de capacités vide n'est **pas la même chose** que de le supprimer. Un ensemble vide peut être utilisé pour garantir qu'un fichier ne sera pas exécuté avec des privilèges malgré le fait que les ensembles ambiant+héritable prédominants conféreraient des capacités aux binaires exécutés.

L'option '-f' est utilisée pour forcer l'achèvement même lorsque l'opération est d'une manière ou d'une autre considérée comme invalide. Cela peut affecter '-r' et la définition des capacités de fichiers que le noyau ne pourra pas interpréter correctement.

L'option -q est utilisée pour rendre le programme moins prolixe dans sa sortie.

CODE DE SORTIE

Le programme setcap se terminera avec un code de sortie de 0 en cas de succès. En cas d'échec, le code de sortie est 1.
