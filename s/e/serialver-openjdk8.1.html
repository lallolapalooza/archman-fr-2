serialver(1) Outils d'invocation de méthode distante (RMI) serialver(1)

NOM

serialver - Renvoie l'UID de version de série pour les classes spécifiées.

SYNTAXE

serialver [ options ] [ noms_de_classes ]
options
Les options en ligne de commande. Voir Options.
noms_de_classes
Les classes pour lesquelles le serialVersionUID doit être renvoyé.

DESCRIPTION

La commande serialver renvoie le serialVersionUID pour une ou plusieurs classes dans un format approprié pour être copié dans une classe évolutive. Lorsqu'elle est appelée sans arguments, la commande serialver affiche une ligne d'utilisation.

OPTIONS

-classpath fichiers_chemin

Définit le chemin de recherche des classes et des ressources de l'application. Séparez les classes et les ressources par un deux-points (:).
-show

Affiche une interface utilisateur simple. Entrez le nom complet de la classe et appuyez sur la touche Entrée ou sur le bouton Afficher pour afficher le serialVersionUID.
-Joption

Passe option à la machine virtuelle Java, où option est l'une des options décrites sur la page de référence du lanceur d'applications Java. Par exemple, -J-Xms48m définit la mémoire de démarrage à 48 Mo. Voir java(1).

NOTES

La commande serialver charge et initialise les classes spécifiées dans sa machine virtuelle, et par défaut, elle ne définit pas de gestionnaire de sécurité. Si la commande serialver doit être exécutée avec des classes non fiables, alors un gestionnaire de sécurité peut être défini avec l'option suivante :

-J-Djava.security.manager

Si nécessaire, une politique de sécurité peut être spécifiée avec l'option suivante :

-J-Djava.security.policy=<fichier_politique>
