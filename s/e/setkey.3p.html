SETKEY(3P) Manuel du programmeur POSIX SETKEY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

setkey — définir la clé d'encodage (CRYPT)

SYNTAXE

#include <stdlib.h>
void setkey(const char *key);

DESCRIPTION

La fonction setkey() donne accès à un algorithme d'encodage défini par l'implémentation. L'argument de setkey() est un tableau de 64 octets ne contenant que les octets avec une valeur numérique de 0 et 1. Si cette chaîne est divisée en groupes de 8, le bit de poids faible de chaque groupe est ignoré ; cela donne une clé de 56 bits qui est utilisée par l'algorithme. C'est la clé qui sera utilisée avec l'algorithme pour encoder une chaîne block passée à encrypt().

La fonction setkey() ne modifiera pas le réglage de errno en cas de succès. Une application souhaitant vérifier les situations d'erreur doit définir errno à 0 avant d'appeler setkey(). Si errno est différent de zéro au retour, une erreur s'est produite.

La fonction setkey() n'a pas besoin d'être thread-safe.

VALEUR DE RETOUR

Aucune valeur n'est retournée.

UTILISATION APPLICATIVE

Le décodage n'est pas nécessairement implémenté dans tous les environnements. Ceci est lié aux restrictions gouvernementales dans certains pays sur les routines de chiffrement et de déchiffrement. Historiquement, on expédiait une version différente de la bibliothèque de chiffrement sans la fonctionnalité de décodage dans les routines fournies. Ainsi, la version exportée de encrypt() effectue l'encodage mais pas le décodage.
