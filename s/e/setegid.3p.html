SETEGID(3P) Manuel du programmeur POSIX SETEGID(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NAME

setegid — définir l'ID de groupe effectif

SYNOPSIS

#include <unistd.h>
int setegid(gid_t gid);

DESCRIPTION

Si gid est égal à l'ID de groupe réel ou à l'ID de groupe défini par le set-group-ID sauvegardé, ou si le processus possède les privilèges appropriés, setegid() définit l'ID de groupe effectif du processus appelant à gid ; l'ID de groupe réel, l'ID de groupe défini par le set-group-ID sauvegardé et les IDs de groupe supplémentaires restent inchangés.

La fonction setegid() n'affecte en aucun cas la liste des groupes supplémentaires.

VALEUR EN RETOUR

En cas de succès, 0 est retourné ; sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction setegid() échoue si :

EINVAL
La valeur de l'argument gid est invalide et n'est pas supportée par l'implémentation.
EPERM
Le processus n'a pas les privilèges appropriés et gid ne correspond pas à l'ID de groupe réel ou à l'ID de groupe défini par le set-group-ID sauvegardé.
