SETSID(1) Commandes utilisateur SETSID(1)

NOM

setsid - exécute un programme dans une nouvelle session

SYNOPSIS

setsid [options] programme [arguments]

DESCRIPTION

setsid exécute un programme dans une nouvelle session. La commande appelle fork(2) si le processus est déjà un chef de groupe. Sinon, il exécute le programme dans le processus courant. Ce comportement par défaut peut être outrepassé par l'option --fork.

OPTIONS

-c, --ctty

Définit le terminal de contrôle au terminal courant.

-f, --fork

Crée toujours un nouveau processus.

-w, --wait

Attend la fin de l'exécution du programme et retourne son code de sortie en tant que code de sortie de setsid.

-V, --version

Affiche les informations de version et quitte.

-h, --help

Affiche le texte d'aide et quitte.
