NOM

seccomp_api_get, seccomp_api_set - Gérer le niveau d'API libseccomp

SYNOPSIS

#include <seccomp.h>

const unsigned int seccomp_api_get(void);
int seccomp_api_set(unsigned int level);

Lier avec -lseccomp.

DESCRIPTION

La fonction seccomp_api_get() renvoie un entier représentant la fonctionnalité ("niveau d'API") fournie par le noyau en cours d'exécution. Il est important de noter que bien que seccomp_api_get() puisse être appelée plusieurs fois, le noyau n'est interrogé que la première fois pour voir quelle fonctionnalité est supportée ; tous les appels suivants à seccomp_api_get() renvoient une valeur mise en cache.

La fonction seccomp_api_set() permet aux appelants de forcer le niveau d'API à la valeur fournie ; cependant, c'est presque toujours une mauvaise idée et l'utilisation de cette fonction est fortement déconseillée.

Les différents niveaux d'API sont décrits ci-dessous :

0
Valeur réservée, actuellement non utilisée.
1
Support de base.
2
L'attribut de filtre SCMP_FLTATR_CTL_TSYNC est supporté et libseccomp utilise l'appel système seccomp(2) pour charger le filtre seccomp dans le noyau.
3
L'attribut de filtre SCMP_FLTATR_CTL_LOG et l'action SCMP_ACT_LOG sont supportés.
4
L'attribut de filtre SCMP_FLTATR_CTL_SSB est supporté.
5
L'action SCMP_ACT_NOTIFY et les API de notification sont supportées.
6
L'utilisation simultanée de SCMP_FLTATR_CTL_TSYNC et des API de notification est supportée.

VALEUR DE RETOUR

La fonction seccomp_api_get() renvoie un entier représentant le niveau d'API supporté. La fonction seccomp_api_set() renvoie zéro en cas de succès, des valeurs négatives en cas d'échec.

EXEMPLES

#include <seccomp.h>
int main(int argc, char *argv[])
{
	unsigned int api;
	api = seccomp_api_get();
	switch (api) {
	case 2:
		/* ... */
	default:
		/* ... */
	}
	return 0;
err:
	return 1;
}

NOTES

Bien que le filtre seccomp puisse être généré indépendamment du noyau, le support du noyau est requis pour charger et appliquer le filtre seccomp généré par libseccomp.

Le site du projet libseccomp, avec plus d'informations et le dépôt de code source, peut être trouvé sur https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, est actuellement en cours de développement. Veuillez signaler tout bogue sur le site du projet ou directement à l'auteur.
