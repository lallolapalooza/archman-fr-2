SETMETAMODE(1) Manuel des commandes générales SETMETAMODE(1)

NOM

setmetamode - définir la gestion de la touche méta du clavier

SYNTAXE

setmetamode [ options ] [ argument ]

DESCRIPTION

Sans argument, setmetamode affiche le mode actuel de la touche Méta. Avec un argument, il définit le mode de la touche Méta comme indiqué. Le réglage avant et après la modification est rapporté.

Le mode de la touche Méta est spécifique à chaque VT (et le VT correspondant à l'entrée standard est utilisé). On pourrait utiliser setmetamode dans /etc/rc pour définir l'état initial du mode de la touche Méta, par exemple par


INITTY=/dev/tty[1-8]
for tty in $INITTY; do

setmetamode escprefix < $tty

done

ARGUMENTS

esc, prefix, escprefix
La touche Méta envoie un préfixe Échappement.
meta, bit, metabit
La touche Méta définit le bit de poids fort du caractère.

OPTIONS

-C, --console=DEV
le périphérique console à utiliser.
-V, --version
affiche le numéro de version.
-h, --help
affiche ce message d'utilisation.
