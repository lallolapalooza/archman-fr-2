NOM

secfixes-check - Un analyseur statique pour les déclarations de secfixes d'Alpine Linux dans les APKBUILDs

SYNTAXE

secfixes-check <apkbuild...>

DESCRIPTION

secfixes-check est un analyseur statique pour les déclarations secfixes à l'intérieur des APKBUILDs. Il lit le fichier donné dans chaque argument de la ligne de commande et recherche les violations de politique pour les secfixes, et valide également le yaml en essayant de le charger avec le module 'lyaml' de lua. Voir alint(5) dans la section secfixes-check pour une explication de chaque violation que secfixes-checks détecte.

secfixes-check affichera les violations de politique et se terminera avec le code correspondant au nombre de violations trouvées. Si aucune violation n'est trouvée, rien n'est affiché et secfixes-check se terminera avec le code 0.

SORTIE

secfixes-check affichera sur la sortie standard chaque fois qu'une violation de politique est trouvée, dans le format suivant :

SEVERITECERTITUDE:[TAG]:CHEMIN::MESSAGE
  • SEVERITE fait référence à la gravité d'une violation, allant de S à M.
  • CERTITUDE fait référence à la probabilité qu'il ne s'agisse pas d'un faux positif, allant de C à P
  • TAG fait référence à l'étiquette de la violation, voir alint(5) pour plus de détails.
  • CHEMIN fait référence au chemin donné pour que apkbuild-lint vérifie.
  • MESSAGE est un court message destiné aux humains pour connaître la violation.
