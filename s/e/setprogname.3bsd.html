setprogname(3bsd)

Paquet: libbsd

Licences: custom

getprogname(3bsd) 3bsd getprogname(3bsd)

NOM

getprogname, setprogname — obtenir et définir le nom du programme

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <stdlib.h> (Voir libbsd(7) pour l'utilisation de l'include.)
const char *
getprogname(void);

void
setprogname(const char *progname);

DESCRIPTION

La fonction getprogname() renvoie une chaîne de caractères avec le nom actuel du programme, excluant tout composant de répertoire. La fonction renverra NULL si elle n'a pas pu obtenir le nom du programme à partir d'une source connue.

La fonction setprogname() définit le nom actuel du programme, en supprimant tout préfixe de composant de répertoire. La fonction conservera une référence au pointeur de chaîne passé, il ne doit donc pas être libéré ou modifié pendant que ces fonctions peuvent être appelées.

Les implémentations sur la plupart des BSD essaieront d'initialiser le nom du programme au démarrage de celui-ci, et libbsd essaiera de le déduire de diverses sources connues en fonction du système cible. Mais il n'est pas portable de supposer que le nom du programme sera défini sans appeler setprogname(), les programmes portables devraient donc toujours l'appeler après le démarrage.

VOIR AUSSI

setproctitle(3bsd).

HISTORIQUE

Les fonctions setprogname() et getprogname() sont apparues pour la première fois dans NetBSD 1.6, FreeBSD 4.4, DragonFly 2.1 et OpenBSD 5.4.
