NOM

seccomp_syscall_priority - Prioriser les appels système dans le filtre seccomp

SYNOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int SCMP_SYS(nom_syscall);

int seccomp_syscall_priority(scmp_filter_ctx ctx,
                             int syscall, uint8_t priorite);

Lier avec -lseccomp.

DESCRIPTION

La fonction seccomp_syscall_priority() fournit un indice de priorité au générateur de filtre seccomp dans libseccomp, de sorte que les appels système de priorité plus élevée soient placés plus tôt dans le code du filtre seccomp, engendrant ainsi moins de surcharge au détriment des appels système de priorité plus faible. La priorité d'un appel système peut être définie, indépendamment de l'existence de règles pour cet appel système ; la bibliothèque mémorisera la priorité et elle sera attribuée à l'appel système si et quand une règle pour cet appel système sera créée.

Bien qu'il soit possible de spécifier directement la valeur syscall en utilisant les valeurs standard __NR_syscall, afin d'assurer un fonctionnement correct sur plusieurs architectures, il est fortement recommandé d'utiliser plutôt la macro SCMP_SYS(). Voir la section EXAMPLES ci-dessous.

Le paramètre priorite prend une valeur de 8 bits allant de 0 à 255 ; une valeur plus élevée représente une priorité plus élevée.

Le contexte de filtre ctx est la valeur retournée par l'appel à seccomp_init().

VALEUR DE RETOUR

La macro SCMP_SYS() retourne une valeur appropriée pour être utilisée comme valeur syscall dans seccomp_syscall_priority().

La fonction seccomp_syscall_priority() retourne zéro en cas de succès ou l'un des codes d'erreur suivants en cas d'échec :

-EDOM
Échec spécifique à l'architecture.
-EFAULT
Échec interne de libseccomp.
-EINVAL
Entrée invalide, soit le contexte, soit le jeton d'architecture est invalide.
-ENOMEM
La bibliothèque n'a pas pu allouer suffisamment de mémoire.

EXEMPLES

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	rc = seccomp_syscall_priority(ctx, SCMP_SYS(read), 200);
	if (rc < 0)
		goto out;
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTES

Bien que le filtre seccomp puisse être généré indépendamment du noyau, un support du noyau est requis pour charger et appliquer le filtre seccomp généré par libseccomp.

Le site du projet libseccomp, avec plus d'informations et le dépôt du code source, se trouve sur https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, sont actuellement en développement, veuillez signaler tout bug sur le site du projet ou directement à l'auteur.
