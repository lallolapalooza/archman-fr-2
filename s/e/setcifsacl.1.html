SETCIFSACL(1) Manuel des commandes générales SETCIFSACL(1)

NOM

setcifsacl - Utilititaire utilisateur pour modifier les composants d'un descripteur de sécurité pour Common Internet File System (CIFS)

SYNTAXE

setcifsacl [-v|-U|-a|-A|-D|-M|-S|-o|-g] "{une ou plusieurs ACE ou un SID}" {objet du système de fichiers}

DESCRIPTION

Cet outil fait partie de la suite cifs-utils.

setcifsacl est un programme utilitaire utilisateur pour le système de fichiers client CIFS sous Linux. Il est destiné à modifier une ACL ou à définir le SID du propriétaire/groupe d'un descripteur de sécurité pour un objet du système de fichiers. L'application ou non d'un descripteur de sécurité est déterminée par le serveur CIFS/SMB.

Ce programme utilise un plugin pour gérer le mappage des noms d'utilisateurs et de groupes aux SIDs. /etc/cifs-utils/idmap-plugin devrait être un lien symbolique pointant vers le bon plugin à utiliser.

OPTIONS

-h
Affiche le message d'utilisation et quitte.
-v
Affiche le numéro de version et quitte.
-U
Applique les actions de modification d'ACE (-a, -D, -M, -S) à la SACL (ACL d'audit). Les actions sont appliquées à la DACL si -U n'est pas spécifié.
-a
Ajoute une ou plusieurs ACE à une ACL d'un descripteur de sécurité. Une ACE est ajoutée même si la même ACE existe déjà dans l'ACL.
-A
Ajoute une ou plusieurs ACE à l'ACL d'un descripteur de sécurité, tout en maintenant l'ordre préféré des ACE. L'ordre préféré des ACE est décrit dans la documentation suivante :
https://docs.microsoft.com/en-us/windows/win32/secauthz/order-of-aces-in-a-dacl
-D
Supprime une ou plusieurs ACE d'une ACL d'un descripteur de sécurité. L'ACE complète doit correspondre à une ACE existante dans l'ACL pour que les ACE listées soient supprimées.
-M
Modifie une ou plusieurs ACE d'une ACL d'un descripteur de sécurité. Le SID et le type sont utilisés pour faire correspondre les ACE existantes à modifier avec la liste des ACE spécifiées.
-S
Définit une ACL de descripteur de sécurité avec la liste des ACE. L'ACL existante est entièrement remplacée par les ACE spécifiées.
-o
Définit le SID du propriétaire à celui spécifié comme argument de ligne de commande.
-g
Définit le SID du groupe à celui spécifié comme argument de ligne de commande.

Le SID du propriétaire/groupe peut être spécifié sous forme de nom ou de valeur SID brute. Chaque entrée ACE commence par "ACL:". Une ou plusieurs ACE sont spécifiées entre guillemets doubles. Plusieurs ACE sont séparées par une virgule.

Les champs suivants d'une ACE DACL peuvent être modifiés avec les valeurs possibles :

  • SID - Soit un nom, soit une valeur SID brute.
  • type - ALLOWED (0x0), DENIED (0x1), OBJECT_ALLOWED (0x5), OBJECT_DENIED (0x6)
  • flags - OBJECT_INHERIT_FLAG (OI ou 0x1), CONTAINER_INHERIT_FLAG (CI ou 0x2), NO_PROPAGATE_INHERIT_FLAG (NI ou 0x4), INHERIT_ONLY_FLAG (IO ou 0x8), INHERITED_ACE_FLAG (IA ou 0x10) ou une combinaison/OU de ces valeurs.
  • mask - Soit FULL, CHANGE, READ, une combinaison de R W X D P O, soit une valeur hexadécimale.

Les champs suivants d'une ACE SACL peuvent être modifiés avec les valeurs possibles :

  • SID - Soit un nom, soit une valeur SID brute.
  • type - AUDIT (0x2), AUDIT_OBJECT (0x7), AUDIT_CALLBACK (0xD), AUDIT_CALLBACK_OBJECT (0xF), MANDATORY_LABEL (0x11), RESOURCE_ATTRIBUTE (0x12), SCOPED_POLICY_ID (0x13)
  • flags - SUCCESSFULL_ACCESS (SA ou 0x40), FAILED_ACCESS (FA ou 0x80)
  • mask - Soit FULL, CHANGE, READ, une combinaison de R W X D P O, soit une valeur hexadécimale.

EXEMPLES

Ajouter une ACE

setcifsacl -a "ACL:CIFSTESTDOM\user2:DENIED/0x1/D" <nom_fichier>

setcifsacl -a "ACL:CIFSTESTDOM\user1:ALLOWED/OI|CI|NI/D" <nom_fichier>

setcifsacl -U -a "ACL:CIFSTESTDOM\user1:AUDIT/SA/D" <nom_fichier>

Ajouter une ACE et réorganiser l'ACL

setcifsacl -A "ACL:CIFSTESTDOMuser3:ALLOWED/OI/FULL" <nom_fichier> setcifsacl -A "ACL:CIFSTESTDOMuser2:DENIED/0x1/D" <nom_fichier> setcifsacl -A "ACL:CIFSTESTDOMuser1:ALLOWED/OI|CI|NI/D" <nom_fichier>

Après avoir défini les ACE mentionnées ci-dessus, voici la sortie de getcifsacl : ACL:CIFSTESTDOMuser2:DENIED/0x1/D ACL:CIFSTESTDOMuser3:ALLOWED/OI/FULL ACL:CIFSTESTDOMuser1:ALLOWED/OI|CI|NI/D

Supprimer une ACE

setcifsacl -D "ACL:S-1-1-0:0x1/OI/0x1201ff" <nom_fichier>

setcifsacl -U -D "ACL:S-1-1-0:0x2/FA/0xf01ff" <nom_fichier>

Modifier une ACE

setcifsacl -M "ACL:CIFSTESTDOM\user1:ALLOWED/0x1f/CHANGE" <nom_fichier>

setcifsacl -U -M "ACL:CIFSTESTDOM\user1:AUDIT_OBJECT/SA/CHANGE" <nom_fichier>

Définir une ACL

setcifsacl -S "ACL:CIFSTESTDOM\Administrator:0x0/0x0/FULL,ACL:CIFSTESTDOM\user2:0x0/0x0/FULL" <nom_fichier>

setcifsacl -U -S "ACL:CIFSTESTDOM\Administrator:AUDIT/SA/FULL,ACL:CIFSTESTDOM\user2:0x7/0x80/FULL" <nom_fichier>

Définir le SID du propriétaire

setcifsacl -o "S-1-5-21-3338130290-3403600371-1423429424-2102" <nom_fichier>

Définir le SID du groupe

setcifsacl -g " <Administrators@BUILTIN> " <nom_fichier>

NOTES

Le support du noyau pour les utilitaires getcifsacl/setcifsacl a été introduit initialement dans le noyau 2.6.37.
