But :

!>
!> SERRST teste les sorties d'erreur pour SSYTRD, SSYTD2, SORGTR, SORMTR, SSPTRD,
!> SOPGTR, SOPMTR, SSTEQR, SSTERF, SSTEBZ, SSTEIN, SPTEQR, SSBTRD,
!> SSYEV, SSYEVX, SSYEVD, SSBEV, SSBEVX, SSBEVD,
!> SSPEV, SSPEVX, SSPEVD, SSTEV, SSTEVX, SSTEVD, et SSTEDC.
!> SSYEVD_2STAGE, SSYEVR_2STAGE, SSYEVX_2STAGE,
!> SSYEV_2STAGE, SSBEV_2STAGE, SSBEVD_2STAGE,
!> SSBEVX_2STAGE, SSYTRD_2STAGE, SSYTRD_SY2SB,
!> SSYTRD_SB2ST
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le nom du chemin LAPACK pour les routines à tester.
!>

NUNIT

!>          NUNIT est INTEGER
!>          Le numéro d'unité pour la sortie.
!>
