getservent(3) Manuel des fonctions de bibliothèque getservent(3)

NOM

getservent, getservbyname, getservbyport, setservent, endservent - obtenir une entrée de service

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <netdb.h>
struct servent *getservent(void);
struct servent *getservbyname(const char *nom, const char *proto);
struct servent *getservbyport(int port, const char *proto);
void setservent(int stayopen);
void endservent(void);

DESCRIPTION

La fonction getservent() lit la prochaine entrée de la base de données des services (voir services(5)) et renvoie une structure servent contenant les champs décomposés de l'entrée. Une connexion à la base de données est ouverte si nécessaire.

La fonction getservbyname() renvoie une structure servent pour l'entrée de la base de données qui correspond au nom de service nom en utilisant le protocole proto. Si proto est NULL, n'importe quel protocole sera trouvé. Une connexion à la base de données est ouverte si nécessaire.

La fonction getservbyport() renvoie une structure servent pour l'entrée de la base de données qui correspond au port port (donné en octets de poids fort) en utilisant le protocole proto. Si proto est NULL, n'importe quel protocole sera trouvé. Une connexion à la base de données est ouverte si nécessaire.

La fonction setservent() ouvre une connexion à la base de données et définit la prochaine entrée à la première entrée. Si stayopen est non nul, la connexion à la base de données ne sera pas fermée entre les appels à l'une des fonctions getserv*().

La fonction endservent() ferme la connexion à la base de données.

La structure servent est définie dans <netdb.h> comme suit :


struct servent {
    char  *s_name;       /* nom officiel du service */
    char **s_aliases;    /* liste des alias */
    int    s_port;       /* numéro de port */
    char  *s_proto;      /* protocole à utiliser */
}

Les membres de la structure servent sont :

s_name
Le nom officiel du service.
s_aliases
Une liste terminée par NULL des noms alternatifs pour le service.
s_port
Le numéro de port pour le service donné en octets de poids fort.
s_proto
Le nom du protocole à utiliser avec ce service.

VALEUR RENVOYÉE

Les fonctions getservent(), getservbyname() et getservbyport() renvoient un pointeur vers une structure servent statiquement allouée, ou NULL si une erreur se produit ou si la fin du fichier est atteinte.

FICHIERS

/etc/services
fichier de base de données des services

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getservent () Sécurité des threads MT-Unsafe race:servent race:serventbuf locale
getservbyname () Sécurité des threads MT-Unsafe race:servbyname locale
getservbyport () Sécurité des threads MT-Unsafe race:servbyport locale
setservent (), endservent () Sécurité des threads MT-Unsafe race:servent locale

Dans le tableau ci-dessus, servent dans race:servent signifie que si l'une des fonctions setservent(), getservent() ou endservent() est utilisée en parallèle dans différents threads d'un programme, des courses de données peuvent se produire.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, 4.3BSD.
