encrypt(3) Manuel des fonctions de bibliothèque encrypt(3)

NOM

encrypt, setkey, encrypt_r, setkey_r - chiffrer des messages de 64 bits

BIBLIOTHÈQUE

Bibliothèque de hachage de mots de passe (libcrypt, -lcrypt)

SYNTAXE

#define _XOPEN_SOURCE       /* Voir feature_test_macros(7) */
#include <unistd.h>
[[deprecated]] void encrypt(char block[64], int edflag);
#define _XOPEN_SOURCE       /* Voir feature_test_macros(7) */
#include <stdlib.h>
[[deprecated]] void setkey(const char *key);
#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <crypt.h>
[[deprecated]] void setkey_r(const char *key, struct crypt_data *data);
[[deprecated]] void encrypt_r(char *block, int edflag,
                              struct crypt_data *data);

DESCRIPTION

Ces fonctions chiffrent et déchiffrent des messages de 64 bits. La fonction setkey() définit la clé utilisée par encrypt(). L'argument key utilisé ici est un tableau de 64 octets, dont chaque valeur numérique est 1 ou 0. Les octets key[n] où n=8*i-1 sont ignorés, de sorte que la longueur effective de la clé est de 56 bits.

La fonction encrypt() modifie le tampon passé, en le chiffrant si edflag vaut 0, et en le déchiffrant si 1 est passé. Comme l'argument key, block est également une représentation en vecteur de bits de la valeur réelle qui est chiffrée. Le résultat est retourné dans ce même vecteur.

Ces deux fonctions ne sont pas réentrantes, c'est-à-dire que les données de la clé sont conservées dans un stockage statique. Les fonctions setkey_r() et encrypt_r() sont les versions réentrantes. Elles utilisent la structure suivante pour conserver les données de la clé :


struct crypt_data {
    char keysched[16 * 8];
    char sb0[32768];
    char sb1[32768];
    char sb2[32768];
    char sb3[32768];
    char crypt_3_buf[14];
    char current_salt[2];
    long current_saltbits;
    int  direction;
    int  initialized;
};

Avant d'appeler setkey_r(), initialisez data->initialized à zéro.

VALEUR DE RETOUR

Ces fonctions ne retournent aucune valeur.

ERREURS

Mettez errno à zéro avant d'appeler les fonctions ci-dessus. En cas de succès, errno reste inchangé.

ENOSYS
La fonction n'est pas fournie. (Par exemple, en raison d'anciennes restrictions d'exportation américaines.)

HISTORIQUE

Supprimé dans glibc 2.28.

Comme elles utilisent l'algorithme de chiffrement par bloc DES, qui n'est plus considéré comme sécurisé, ces fonctions ont été supprimées de glibc. Les applications devraient passer à une bibliothèque de cryptographie moderne, telle que libgcrypt.

encrypt()
setkey()
POSIX.1-2001, SUS, SVr4.

Disponibilité dans glibc

Voir crypt(3).

Fonctionnalités dans glibc

Dans glibc 2.2, ces fonctions utilisent l'algorithme DES.

EXEMPLES

#define _XOPEN_SOURCE
#include <crypt.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(void)
{
    char key[64];
    char orig[9] = "eggplant";
    char buf[64];
    char txt[9];
    for (size_t i = 0; i < 64; i++) {
        key[i] = rand() & 1;
    }
    for (size_t i = 0; i < 8; i++) {
        for (size_t j = 0; j < 8; j++) {
            buf[i * 8 + j] = orig[i] >> j & 1;
        }
        setkey(key);
    }
    printf("Avant le chiffrement : %s\n", orig);
    encrypt(buf, 0);
    for (size_t i = 0; i < 8; i++) {
        for (size_t j = 0, txt[i] = '\0'; j < 8; j++) {
            txt[i] |= buf[i * 8 + j] << j;
        }
        txt[8] = '\0';
    }
    printf("Après le chiffrement :  %s\n", txt);
    encrypt(buf, 1);
    for (size_t i = 0; i < 8; i++) {
        for (size_t j = 0, txt[i] = '\0'; j < 8; j++) {
            txt[i] |= buf[i * 8 + j] << j;
        }
        txt[8] = '\0';
    }
    printf("Après le déchiffrement :  %s\n", txt);
    exit(EXIT_SUCCESS);
}
