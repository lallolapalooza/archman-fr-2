SETVTRGB(8) Manuel du gestionnaire système SETVTRGB(8)

NOM

setvtrgb - définir les couleurs RVB du terminal virtuel

SYNTAXE

setvtrgb [options] vga|FICHIER|-

DESCRIPTION

La commande setvtrgb prend un seul argument, soit la chaîne vga, soit le chemin vers un fichier contenant les couleurs à utiliser par les terminaux virtuels Linux.

Vous pouvez choisir d'écrire les couleurs en format décimal ou hexadécimal, cela sera détecté à l'exécution.

Le format décimal du FICHIER doit être exactement 3 lignes de 16 valeurs décimales séparées par des virgules pour le ROUGE, le VERT et le BLEU.

Pour générer un FICHIER valide :

cat /sys/module/vt/parameters/default_{red,grn,blu} > FICHIER

Et ensuite éditez les valeurs dans FICHIER.

Le format hexadécimal du FICHIER doit être exactement 16 lignes de triplets hexadécimaux pour le ROUGE, le VERT et le BLEU, préfixés par un signe dièse (#). Par exemple :

#000000
#AA0000
#00AA00
#AA5500
#0000AA
#AA00AA
#00AAAA
#AAAAAA
#555555
#FF5555
#55FF55
#FFFF55
#5555FF
#FF55FF
#55FFFF
#FFFFFF

OPTIONS

-C, --console=DEV
le périphérique console à utiliser.
-h, --help
Affiche le message d'utilisation et quitte.
-V, --version
Affiche le numéro de version et quitte.
