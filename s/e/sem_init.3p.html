SEM_INIT(3P) Manuel du programmeur POSIX SEM_INIT(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sem_init — initialiser un sémaphore non nommé

SYNOPIS

#include <semaphore.h>
int sem_init(sem_t *sem, int pshared, unsigned value);

DESCRIPTION

La fonction sem_init() initialise le sémaphore non nommé référencé par sem. La valeur du sémaphore initialisé sera value. Après un appel réussi à sem_init(), le sémaphore peut être utilisé dans des appels ultérieurs à sem_wait(), sem_timedwait(), sem_trywait(), sem_post() et sem_destroy(). Ce sémaphore restera utilisable jusqu'à ce qu'il soit détruit.

Si l'argument pshared a une valeur non nulle, alors le sémaphore est partagé entre les processus ; dans ce cas, tout processus qui peut accéder au sémaphore sem peut utiliser sem pour effectuer les opérations sem_wait(), sem_timedwait(), sem_trywait(), sem_post() et sem_destroy().

Si l'argument pshared est zéro, alors le sémaphore est partagé entre les threads du processus ; tout thread de ce processus peut utiliser sem pour effectuer les opérations sem_wait(), sem_timedwait(), sem_trywait(), sem_post() et sem_destroy().

Voir la Section 2.9.9, Copies d'objets de synchronisation et mappings alternatifs pour des exigences supplémentaires.

Tenter d'initialiser un sémaphore déjà initialisé entraîne un comportement indéfini.

VALEUR DE RETOUR

En cas de succès, la fonction sem_init() initialise le sémaphore dans sem et retourne 0. Sinon, elle retourne -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction sem_init() échouera si :

EINVAL
La valeur de l'argument value dépasse {SEM_VALUE_MAX}.
ENOSPC
Une ressource requise pour initialiser le sémaphore a été épuisée, ou la limite des sémaphores ({SEM_NSEMS_MAX}) a été atteinte.
EPERM
Le processus ne possède pas les privilèges appropriés pour initialiser le sémaphore.
