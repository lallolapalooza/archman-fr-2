NOM

secutil - Extraire les certificats X.509 et les strongnames des assemblies.

SYNTAXE

secutil [options] nom_fichier

DESCRIPTION

Extrait les certificats X.509 et les strongnames des assemblies dans un format facilement réutilisable dans le code source (syntaxe C# ou VB.NET).

OPTIONS

-s assembly , -strongname assembly
Affiche les informations de strongname concernant l'assembly.
-x assembly , -x509certificate assembly
Affiche le certificat d'authentification X509 (Authenticode) pour l'assembly.
-a , -array
Affiche les données dans un tableau décimal (par défaut).
-v , -vbmode
Affiche les données dans un format compatible avec VisualBasic.
-c , -cmode
Affiche les données dans un format compatible C/C++/C# (par défaut).
-help , -h , -?
Affiche l'aide relative à cet outil.
