NOM

sergensio_event - Gestionnaire d'événements pour les événements provenant d'un sergensio

SYNTAXE

#include <gensio/sergensio.h>

DESCRIPTION

Lorsqu'un événement se produit sur un sergensio qui est signalé à l'utilisateur, la bibliothèque gensio appelle le gestionnaire de type gensio_event qui a été enregistré auprès du gensio, comme tout autre événement sur un gensio. Voir gensio_event(3) pour plus de détails sur la façon dont cela se produit.

Ce document détaille les événements spécifiques aux sergensio. Ceux-ci rapportent une valeur entière non signée, sauf indication contraire dans la description, le paramètre buf du gestionnaire gensio_event est un pointeur vers la valeur entière non signée.

CONTROLES DE PORT SÉRIE

Ce sont des contrôles pour les paramètres du port série. Ceux-ci sont reçus côté serveur uniquement. Il doit répondre en définissant la valeur (si possible et si la valeur n'est pas zéro) et en répondant avec la valeur actuelle avec sergensio_xxx().

GENSIO_EVENT_SER_BAUD
GENSIO_EVENT_SER_DATASIZE
GENSIO_EVENT_SER_PARITY
GENSIO_EVENT_SER_STOPBITS
GENSIO_EVENT_SER_FLOWCONTROL
GENSIO_EVENT_SER_IFLOWCONTROL
GENSIO_EVENT_SER_SBREAK
GENSIO_EVENT_SER_DTR
GENSIO_EVENT_SER_RTS

SIGNATURE

GENSIO_EVENT_SER_SIGNATURE est reçu côté serveur uniquement et constitue une demande de signature. Le serveur doit répondre en envoyant la signature avec sergensio_signature(). Aucune valeur n'est passée dans ce cas.

FONCTIONS D'ÉTAT

GENSIO_EVENT_SER_MODEMSTATE_MASK
GENSIO_EVENT_SER_LINESTATE_MASK
Ceux-ci sont reçus côté serveur pour demander la mise à jour du masque des valeurs rapportées. Le serveur doit répondre en renvoyant le masque actuel avec les fonctions sergensio_modemstate ou sergensio_linestate. Le serveur n'a pas besoin de gérer tous les bits demandés par l'utilisateur.

GENSIO_EVENT_SER_MODEMSTATE
GENSIO_EVENT_SER_LINESTATE

Côté client, ceux-ci rapportent les changements d'état du modem et de la ligne en tant qu'entier non signé. Voir sergensio_modemstate(3) et sergensio_linestate(3) pour la signification des bits dans l'entier.

AUTRES CONTROLES DE PORT SÉRIE

Ceux-ci sont uniquement côté serveur, ils sont reçus pour demander les diverses opérations. Le serveur doit les effectuer, mais aucune réponse n'est requise. Vous remarquerez que le break n'est pas ici, le break est géré via l'événement GENSIO_EVENT_SEND_BREAK.

GENSIO_EVENT_SER_FLOW_STATE
GENSIO_EVENT_SER_FLUSH

SYNC

GENSIO_EVENT_SER_SYNC est une opération spéciale qui arrive lorsqu'un événement TCP sync est reçu. Il peut être reçu des deux côtés. Un serveur doit envoyer un break. Le client peut faire ce qu'il veut avec l'information, ce qui n'est pas défini par la spécification RFC2217.

VALEURS DE RETOUR

Les valeurs de retour sont actuellement ignorées pour tous ces événements, mais vous devriez retourner 0 en cas de succès, GE_NOTSUP si la fonction n'est pas supportée, ou d'autres erreurs gensio si nécessaire.

VOIR AUSSI

sergensio(5), gensio_event(3), gensio_err(3)
