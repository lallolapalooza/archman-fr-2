NOM

setuids.bt - Trace les appels système de la famille setuid. Utilise bpftrace/eBPF.

SYNTAXE

setuids.bt

DESCRIPTION

Cet outil trace l'escalade de privilèges via les appels système setuid et peut être utilisé pour le débogage, la création de listes blanches et la détection d'intrusions.

Il fonctionne en traçant les appels système setuid(2), setfsuid(2) et retresuid(2) en utilisant les points de trace des appels système.

Comme ceci utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Tracer les appels système setuid :
# setuids.bt

CHAMPS

PID
L'ID du processus appelant.
COMM
Le nom du processus (thread) appelant.
UID
L'UID de l'appelant.
SYSCALL
Le nom de l'appel système.
ARGS
Les arguments de l'appel système
(RET)
La valeur de retour de l'appel système : 0 == succès, d'autres nombres indiquent un code d'erreur.

SURCHARGE

La fréquence des appels setuid est censée être faible (<< 100/s), donc la surcharge de cet outil est supposée être négligeable.

SOURCE

Cet outil est originaire du livre "BPF Performance Tools", publié par Addison Wesley (2019) :

http://www.brendangregg.com/bpf-performance-tools-book.html

Consultez le livre pour plus de documentation sur cet outil.

Cette version se trouve dans le dépôt bpftrace :

https://github.com/bpftrace/bpftrace

Regardez également dans la distribution bpftrace un fichier _examples.txt compagnon contenant des exemples d'utilisation, de sorties et des commentaires pour cet outil.
