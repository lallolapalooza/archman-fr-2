SEM_TIMEDWAIT(3P) Manuel du programmeur POSIX SEM_TIMEDWAIT(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sem_timedwait — verrouiller un sémaphore

SYNTAXE

#include <semaphore.h>
#include <time.h>
int sem_timedwait(sem_t *restrict sem,
    const struct timespec *restrict abstime);

DESCRIPTION

La fonction sem_timedwait() verrouille le sémaphore référencé par sem comme la fonction sem_wait(). Cependant, si le sémaphore ne peut pas être verrouillé sans attendre qu'un autre processus ou thread déverrouille le sémaphore en effectuant une fonction sem_post(), cette attente sera terminée lorsque le délai d'attente spécifié expirera.

Le délai d'attente expirera lorsque l'heure absolue spécifiée par abstime sera dépassée, telle que mesurée par l'horloge sur laquelle sont basés les délais d'attente (c'est-à-dire lorsque la valeur de cette horloge est égale ou supérieure à abstime), ou si l'heure absolue spécifiée par abstime a déjà été dépassée au moment de l'appel.

Le délai d'attente sera basé sur l'horloge CLOCK_REALTIME. La résolution du délai d'attente sera la résolution de l'horloge sur laquelle il est basé. Le type de données timespec est défini comme une structure dans l'en-tête <time.h>.

En aucun cas la fonction ne doit échouer avec un délai d'attente si le sémaphore peut être verrouillé immédiatement. La validité de abstime n'a pas besoin d'être vérifiée si le sémaphore peut être verrouillé immédiatement.

VALEUR DE RETOUR

La fonction sem_timedwait() renvoie zéro si le processus appelant a effectué avec succès l'opération de verrouillage du sémaphore sur le sémaphore désigné par sem. Si l'appel a échoué, l'état du sémaphore reste inchangé, et la fonction renvoie une valeur de -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction sem_timedwait() échoue si :

EINVAL
Le processus ou le thread aurait dû bloquer, et le paramètre abstime spécifiait une valeur pour le champ nanosecondes inférieure à zéro ou supérieure ou égale à 1000 millions.
ETIMEDOUT
Le sémaphore n'a pas pu être verrouillé avant l'expiration du délai d'attente spécifié.

La fonction sem_timedwait() peut échouer si :

EDEADLK
Une condition d'interblocage a été détectée.
EINTR
Un signal a interrompu cette fonction.
EINVAL
L'argument sem ne fait pas référence à un sémaphore valide.

EXEMPLES

Le programme présenté ci-dessous opère sur un sémaphore non nommé. Le programme attend deux arguments de ligne de commande. Le premier argument spécifie une valeur en secondes qui est utilisée pour régler un minuteur d'alarme afin de générer un signal SIGALRM. Ce gestionnaire effectue un sem_post(3) pour incrémenter le sémaphore sur lequel on attend dans main() en utilisant sem_timedwait(). Le deuxième argument de ligne de commande spécifie la durée du délai d'attente, en secondes, pour sem_timedwait().

#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>
#include <semaphore.h>
#include <time.h>
#include <assert.h>
#include <errno.h>
#include <signal.h>
sem_t sem;
static void
handler(int sig)
{
    int sav_errno = errno;
    static const char info_msg[] = "sem_post() depuis le gestionnaire\n";
    write(STDOUT_FILENO, info_msg, sizeof info_msg - 1);
    if (sem_post(&sem) == -1) {
        static const char err_msg[] = "sem_post() a échoué\n";
        write(STDERR_FILENO, err_msg, sizeof err_msg - 1);
        _exit(EXIT_FAILURE);
    }
    errno = sav_errno;
}
int
main(int argc, char *argv[])
{
    struct sigaction sa;
    struct timespec ts;
    int s;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <alarme-sec> <attente-sec>\n",
            argv[0]);
        exit(EXIT_FAILURE);
    }
    if (sem_init(&sem, 0, 0) == -1) {
        perror("sem_init");
        exit(EXIT_FAILURE);
    }
    /* Établir le gestionnaire SIGALRM; régler le minuteur d'alarme en utilisant argv[1] */
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;
    if (sigaction(SIGALRM, &sa, NULL) == -1) {
        perror("sigaction");
        exit(EXIT_FAILURE);
    }
    alarm(atoi(argv[1]));
    /* Calculer l'intervalle relatif comme l'heure actuelle plus
       le nombre de secondes donné par argv[2] */
    if (clock_gettime(CLOCK_REALTIME, &ts) == -1) {
        perror("clock_gettime");
        exit(EXIT_FAILURE);
    }
    ts.tv_sec += atoi(argv[2]);
    printf("main() sur le point d'appeler sem_timedwait()\n");
    while ((s = sem_timedwait(&sem, &ts)) == -1 && errno == EINTR)
        continue;       /* Redémarrer si interrompu par le gestionnaire */
    /* Vérifier ce qui s'est passé */
    if (s == -1) {
        if (errno == ETIMEDOUT)
            printf("sem_timedwait() a expiré\n");
        else
            perror("sem_timedwait");
    } else
        printf("sem_timedwait() a réussi\n");
    exit((s == 0) ? EXIT_SUCCESS : EXIT_FAILURE);
}
