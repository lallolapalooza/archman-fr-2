FBB::ServerSocket(3bobcat) Socket serveur FBB::ServerSocket(3bobcat)

NOM

FBB::ServerSocket - Socket serveur acceptant les requêtes de connexion Internet

SYNOPIS

#include <bobcat/serversocket>
Option de liaison : -lbobcat

DESCRIPTION

Un FBB::ServerSocket peut être construit pour écouter les requêtes de connexion provenant d'Internet ou de l'hôte local. Les requêtes de connexion peuvent être acceptées en mode bloquant ou non-bloquant. Lorsqu'une connexion est acceptée, un socket est retourné, qui peut être utilisé pour lire des informations du client qui a demandé la connexion ou écrire des informations vers celui-ci. Le socket rendu disponible est un descripteur de fichier qui peut être utilisé pour initialiser un std::istream et/ou std::ostream. Le std::istream est utilisé pour lire des informations du processus client ; le std::ostream est utilisé pour envoyer des informations au processus client. Puisqu'un socket peut être considéré comme un descripteur de fichier, les classes FBB::IFdStream, FBB::IFdStreamBuf, FBB::OFdStream et FBB::OFdStreamBuf disponibles peuvent être utilisées avantageusement ici. Notez que la disponibilité d'un socket ne signifie pas que cela définit le protocole de communication. Il incombe (toujours) au programmeur de se conformer à un protocole existant ou d'implémenter un protocole sur mesure. Cette dernière situation implique que la séquence des opérations d'entrée et de sortie est définie par le programmeur.

Un socket serveur de domaine Unix peut être défini en utilisant FBB::LocalServerSocket.

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page man sont définis dans l'espace de nommage FBB.

HERITE DE

FBB::SocketBase

CONSTRUCTEUR

o
ServerSocket(size_t port):
Ce constructeur initialise un objet FBB::ServerSocket, qui écoutera les connexions sur le port spécifié. La construction du socket ne signifie pas que l'objet FBB::ServerSocket écoute effectivement les connexions. Pour commencer à écouter, le membre listen() doit être utilisé.

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de FBB::SocketBase (et donc de FBB::InetAddress) sont disponibles, car FBB::ServerSocket hérite de FBB::SocketBase.

o
void listen(size_t backlog = 5, bool blocking = true):
Le membre listen() définit la manière dont le FBB::ServerSocket écoutera les clients demandant une connexion. Il ne peut être utilisé qu'une seule fois avec un FBB::ServerSocket. Un objet FBB::Exception est levé si l'écoute échoue, si le constructeur n'a pas pu créer de socket, ou si la classe de base SocketBase n'a pas pu être construite correctement.
Le paramètre backlog du membre listen() définit la taille de la file d'attente interne du FBB::ServerSocket dans laquelle les requêtes de connexion peuvent être stockées en attendant leur tour pour être traitées. Lorsque backlog requêtes sont en attente et qu'une autre requête arrive, cette requête est perdue.
Le second paramètre du membre, blocking, est utilisé pour contrôler le mode bloquant. Par défaut, le mode bloquant est utilisé, et listen() attendra jusqu'à ce qu'une connexion soit établie. Ceci est acceptable dans les situations où les clients se connectent peu fréquemment et pour des intervalles de temps relativement courts. Sinon, dans des programmes plus complexes, un objet FBB::Selector peut être utilisé pour détecter les entrées sur le socket serveur et/ou sur divers sockets clients.
o
SocketBase accept():
Le membre accept() retourne un objet FBB::SocketBase contenant des informations sur le client dont la requête de connexion a été acceptée. Le descripteur de socket de l'objet FBB::SocketBase peut être utilisé pour initialiser des flux qui peuvent être utilisés pour communiquer avec le client. Dans des programmes plus complexes, le FBB::SocketBase pourrait être passé à une classe dérivée de FBB::Fork, gérant la communication avec l'enfant comme un processus séparé (enfant).

EXEMPLE

Voir également l'exemple clientsocket(3bobcat).

    #include <iostream>
    #include <string>
    #include <bobcat/serversocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Fournir le numéro de port du serveur\n";
            return 1;
        }
        size_t portnr = stoul(argv[1]);
        ServerSocket server(portnr);
        cerr << "le serveur écoute sur le port " << argv[1] << endl;
        cerr << "serversocket renvoie :\n" <<
            "adresse = " << server.dottedDecimalAddress() << "\n"
            "port    = " << server.port() << endl;
        int fd = server.socket();       // ouvrir le descripteur du socket
        cout << "Le descripteur de fichier du socket est " << fd << "\n"
            "Le serveur se termine lorsqu'il reçoit un "
                                        "unique `q’ sur une ligne\n"
            "Une connexion est terminée lorsqu'aucune entrée "
                                        "n'est reçue pendant un certain temps.\n"
            "Alors une autre connexion est possible" << endl;
        server.listen();                // écouter en mode bloquant
        while (true)
        {
            SocketBase fdb = server.accept();
            int fd = fdb.socket();
            cerr << "FD client = " << fd << ", " << endl <<
                    "adresse = " << fdb.dottedDecimalAddress() << ", " <<
                    endl <<
                    "communication via le port " << fdb.port() << endl;
            IFdStream in(fd);           // flux pour lire depuis le client
            OFdStream out(fd);          // flux pour écrire vers le client
            string cmd;
            while (getline(in, cmd))
            {
                cout << "Reçu : " << cmd << endl;
                out << "Reçu : " << cmd << "\r" << endl;
                if (cmd[0] == ’q’)
                    return 0;
            }
            cout << "Prêt pour une autre connexion\n";
        }
    }
    catch (Exception const &err)
    {
        cerr <<
            err.what() << endl <<
            "Le socket serveur sur le port " << argv[1] <<
            " ne peut pas être ouvert" << endl;
        return -1;
    }
