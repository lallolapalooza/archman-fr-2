NOM

setconf - change les paramètres dans les fichiers texte de configuration

SYNTAXE

setconf nom_fichier clé valeur [chaîne de fin pour une valeur multiligne]

DESCRIPTION

S'il existe un fichier texte avec des champs comme ceux-ci :

CC=gcc

lights := on

compileToday: true

anumber = 42

cabal ==1.2.3

Setconf peut changer les valeurs par autre chose. La valeur associée à la première clé trouvée sera changée à la valeur donnée.

Par exemple, CC est une clé et gcc est une valeur.

EXEMPLES

setconf
Sort avec le code d'erreur 1

setconf Makefile.defaults NETSURF_USE_HARU_PDF NO
Dans Makefile.defaults, définit NETSURF_USE_HARU_PDF à NO

setconf Makefile CC gcc
Définit CC=gcc dans Makefile

setconf PKGBUILD sha256sums "('123abc' 'abc123')" ')'
Dans le fichier PKGBUILD, définit la valeur pour la clé sha256sums à
('123abc' 'abc123') quelle que soit la longueur de la valeur précédente
en lignes, puisque la chaîne de fin ')' est donnée.

setconf app.py NUMS "[1, 2, 3]" ']'
Remplacement multiligne, remplaçant le texte de la valeur appartenant
à la clé NUMS jusqu'à la chaîne de fin ] par la valeur [1, 2, 3],
quelle que soit la longueur de la valeur précédente en lignes.

setconf my.conf x=1
Définit x à 1 dans my.conf, même si my.conf utilise une autre assignation,
comme x := 42, x : 42, x == 42, x :: 42 ou x => 42.

setconf -a server.ini 'Z => 99'
Ajoute Z => 99 à server.ini

setconf --add rolling.conf N 1000
Ajoute N=1000. Crée le fichier si nécessaire.

setconf test.file y-=0.1
Diminue y de 0.1.

setconf values.conf x+=2
Augmente x de 2.

setconf -d linux/printk.h CONSOLE_LOGLEVEL_DEFAULT=4
Change #define CONSOLE_LOGLEVEL_DEFAULT à 4

setconf -u kernel_config CONFIG_ULTRIX_PARTITION=y
Décommente et définit CONFIG_ULTRIX_PARTITION=y, même si la valeur originale
est suffixée par "is not set". Prévu pour être utilisé avec la configuration
du noyau Linux.

OPTIONS

-v ou --version
affiche le numéro de version actuel
-h ou --help
affiche des informations d'utilisation brèves
-t ou --test
effectue des auto-tests internes
-a ou --add
ajoute une option, si elle n'est pas déjà présente. Doit être suivi d'un nom de fichier et d'une paire clé/valeur.
-d ou --define
change une valeur #define sur une seule ligne
-u ou --uncomment
décommente une clé avant de changer la valeur

POURQUOI

Vise à résoudre un petit problème correctement au lieu de mille problèmes à moitié, dans le véritable esprit UNIX.

Crée une ligne très facile à lire, contrairement à l'utilisation de sed pour la même tâche.

La syntaxe doit clairement indiquer ce qui est fait.

Un seul petit exécutable, pas un gros paquet.

VOIR AUSSI

sed(1) make(1)

BOGUES

Seuls des bogues inconnus jusqu'à présent. Les bogues peuvent être rapportés à https://github.com/xyproto/setconf/issues.
