PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sem_destroy — détruire un sémaphore anonyme

SYNTAXE

#include <semaphore.h>
int sem_destroy(sem_t *sem);

DESCRIPTION

La fonction sem_destroy() détruit le sémaphore anonyme indiqué par sem. Seul un sémaphore qui a été créé en utilisant sem_init() peut être détruit en utilisant sem_destroy() ; l'effet d'un appel à sem_destroy() avec un sémaphore nommé est indéfini. L'effet d'une utilisation ultérieure du sémaphore sem est indéfini jusqu'à ce que sem soit réinitialisé par un autre appel à sem_init().

Il est sûr de détruire un sémaphore initialisé sur lequel aucun thread n'est actuellement bloqué. L'effet de la destruction d'un sémaphore sur lequel d'autres threads sont actuellement bloqués est indéfini.

VALEUR DE RETOUR

En cas de succès, une valeur de zéro est retournée. Sinon, une valeur de -1 est retournée et errno est définie pour indiquer l'erreur.

ERREURS

La fonction sem_destroy() peut échouer si :

EINVAL
L'argument sem n'est pas un sémaphore valide.
EBUSY
Il y a actuellement des processus bloqués sur le sémaphore.
