NOM

seccomp_merge - Fusionner deux filtres seccomp

SYNOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int seccomp_merge(scmp_filter_ctx dst, scmp_filter_ctx src);

Lier avec -lseccomp.

DESCRIPTION

La fonction seccomp_merge() fusionne le filtre seccomp dans src avec le filtre dans dst et stocke le résultat dans le filtre dst. En cas de succès, le filtre seccomp src est libéré et toute la mémoire interne associée au filtre est libérée ; il n'est pas nécessaire d'appeler seccomp_release(3) sur src et l'appelant doit ignorer toute référence au filtre.

Pour fusionner deux filtres seccomp, les deux filtres doivent avoir les mêmes valeurs d'attributs et aucune architecture qui se chevauche.

VALEUR DE RETOUR

Retourne zéro en cas de succès ou l'un des codes d'erreur suivants en cas d'échec :

-EDOM
Impossible de fusionner les filtres en raison de problèmes d'architecture, par exemple, des incompatibilités d'endianness.
-EEXIST
L'architecture existe déjà dans le filtre.
-EINVAL
L'un des filtres est invalide.
-ENOMEM
La bibliothèque n'a pas pu allouer suffisamment de mémoire.

EXEMPLES

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx_32, ctx_64;
	ctx_32 = seccomp_init(SCMP_ACT_KILL);
	if (ctx_32 == NULL)
		goto out_all;
	ctx_64 = seccomp_init(SCMP_ACT_KILL);
	if (ctx_64 == NULL)
		goto out_all;
	if (seccomp_arch_exist(ctx_32, SCMP_ARCH_X86) == -EEXIST) {
		rc = seccomp_arch_add(ctx_32, SCMP_ARCH_X86);
		if (rc != 0)
			goto out_all;
		rc = seccomp_arch_remove(ctx_32, SCMP_ARCH_NATIVE);
		if (rc != 0)
			goto out_all;
	}
	if (seccomp_arch_exist(ctx_64, SCMP_ARCH_X86_64) == -EEXIST) {
		rc = seccomp_arch_add(ctx_64, SCMP_ARCH_X86_64);
		if (rc != 0)
			goto out_all;
		rc = seccomp_arch_remove(ctx_64, SCMP_ARCH_NATIVE);
		if (rc != 0)
			goto out_all;
	}
	/* ... */
	rc = seccomp_merge(ctx_64, ctx_32);
	if (rc != 0)
		goto out_all;
	/* NOTE: le filtre 'ctx_32' n'est plus valide à ce stade */
	/* ... */
out:
	seccomp_release(ctx_64);
	return -rc;
out_all:
	seccomp_release(ctx_32);
	goto out;
}

NOTES

Bien que le filtre seccomp puisse être généré indépendamment du noyau, un support du noyau est nécessaire pour charger et appliquer le filtre seccomp généré par libseccomp.

Le site du projet libseccomp, avec plus d'informations et le dépôt de code source, se trouve à l'adresse https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, sont actuellement en développement, veuillez signaler tout bug sur le site du projet ou directement à l'auteur.
