DESCRIPTION

Ce sont des équivalents des fonctions non bloquantes (sans le suffixe _b), mais elles attendent bloquées pour les résultats. Comme toute entrée/sortie synchrone, cela peut introduire des risques d'interblocage, il faut donc les utiliser avec prudence.

Pour les utiliser, vous devez d'abord allouer une structure de données bloquante sergensio en utilisant sergensio_b_alloc pour l'utiliser dans les autres fonctions. La valeur allouée ne peut être utilisée que pour une seule opération à la fois. Lorsque vous avez terminé, vous devez la libérer avec sergensio_b_free.

Avec ces fonctions, vous passez un pointeur vers la valeur que vous souhaitez définir. Si la valeur pointée est nulle, la valeur n'est pas définie, elle est simplement récupérée. Si la fonction retourne sans erreur, la valeur actuelle est retournée dans la destination du pointeur passé.

Notez que ces fonctions ne nécessitent pas gensio_set_sync pour fonctionner et peuvent être mélangées avec des opérations non bloquantes.

Consultez les différentes fonctions non bloquantes pour plus de détails sur les valeurs et leur signification.

VALEURS DE RETOUR

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.
