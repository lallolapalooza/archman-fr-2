getpwent(3) Manuel des fonctions de bibliothèque getpwent(3)

NOM

getpwent, setpwent, endpwent - obtenir une entrée du fichier de mots de passe

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/types.h>
#include <pwd.h>
struct passwd *getpwent(void);
void setpwent(void);
void endpwent(void);
Exigences pour les macros de test de fonctionnalités de glibc (voir feature_test_macros(7)):

getpwent(), setpwent(), endpwent():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction getpwent() renvoie un pointeur vers une structure contenant les champs décomposés d'un enregistrement de la base de données des mots de passe (par exemple, le fichier local de mots de passe /etc/passwd, NIS et LDAP). La première fois que getpwent() est appelée, elle renvoie la première entrée ; par la suite, elle renvoie les entrées successives.

La fonction setpwent() rembobine le début de la base de données des mots de passe.

La fonction endpwent() est utilisée pour fermer la base de données des mots de passe après que tout traitement a été effectué.

La structure passwd est définie dans <pwd.h> comme suit :


struct passwd {
    char   *pw_name;       /* nom d'utilisateur */
    char   *pw_passwd;     /* mot de passe utilisateur */
    uid_t   pw_uid;        /* identifiant utilisateur */
    gid_t   pw_gid;        /* identifiant de groupe */
    char   *pw_gecos;      /* informations utilisateur */
    char   *pw_dir;        /* répertoire personnel */
    char   *pw_shell;      /* programme de shell */
};

Pour plus d'informations sur les champs de cette structure, voir passwd(5).

VALEUR DE RETOUR

La fonction getpwent() renvoie un pointeur vers une structure passwd, ou NULL s'il n'y a plus d'entrées ou si une erreur s'est produite. Si une erreur se produit, errno est définie pour indiquer l'erreur. Si l'on souhaite vérifier errno après l'appel, il doit être mis à zéro avant l'appel.

La valeur de retour peut pointer vers une zone statique et peut être écrasée par des appels ultérieurs à getpwent(), getpwnam(3), ou getpwuid(3). (Ne pas passer le pointeur renvoyé à free(3).)

ERREURS

EINTR
Un signal a été intercepté ; voir signal(7).
EIO
Erreur d'entrée/sortie.
EMFILE
La limite par processus sur le nombre de descripteurs de fichiers ouverts a été atteinte.
ENFILE
La limite système sur le nombre total de fichiers ouverts a été atteinte.
ENOMEM
Mémoire insuffisante pour allouer la structure passwd.
ERANGE
Espace tampon insuffisant fourni.

FICHIERS

/etc/passwd
fichier de la base de données locale des mots de passe

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getpwent () Thread safety MT-Unsafe race:pwent race:pwentbuf locale
setpwent (), endpwent () Thread safety MT-Unsafe race:pwent locale

Dans le tableau ci-dessus, pwent dans race:pwent signifie que si l'une des fonctions setpwent(), getpwent(), ou endpwent() est utilisée en parallèle dans différents threads d'un programme, des conditions de concurrence de données (data races) peuvent se produire.

VERSIONS

Le champ pw_gecos n'est pas spécifié dans POSIX, mais est présent sur la plupart des implémentations.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, SVr4, 4.3BSD.

VOIR AUSSI

fgetpwent(3), getpw(3), getpwent_r(3), getpwnam(3), getpwuid(3), putpwent(3), passwd(5)
