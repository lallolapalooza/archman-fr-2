PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

setvbuf — attribuer une mise en mémoire tampon à un flux

SYNOPSIS

#include <stdio.h>
int setvbuf(FILE *restrict stream, char *restrict buf, int type,
    size_t size);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction setvbuf() peut être utilisée après que le flux pointé par stream est associé à un fichier ouvert mais avant que toute autre opération (autre qu'un appel infructueux à setvbuf()) ne soit effectuée sur le flux. L'argument type détermine comment stream sera mis en mémoire tampon, comme suit :

*
{_IOFBF} doit provoquer une mise en mémoire tampon complète des entrées/sorties.
*
{_IOLBF} doit provoquer une mise en mémoire tampon par ligne des entrées/sorties.
*
{_IONBF} doit provoquer une mise en mémoire tampon nulle des entrées/sorties.

Si buf n'est pas un pointeur nul, le tableau qu'il pointe peut être utilisé à la place d'une mémoire tampon allouée par setvbuf() et l'argument size spécifie la taille du tableau ; sinon, size peut déterminer la taille d'une mémoire tampon allouée par la fonction setvbuf(). Le contenu du tableau à tout moment n'est pas spécifié.

Pour plus d'informations sur les flux, voir Section 2.5, Flux d'E/S Standard.

VALEUR DE RETOUR

En cas de succès, setvbuf() doit retourner 0. Sinon, elle doit retourner une valeur non nulle si une valeur invalide est donnée pour type ou si la requête ne peut pas être satisfaite, et peut définir errno pour indiquer l'erreur.

ERREURS

La fonction setvbuf() peut échouer si :

EBADF
Le descripteur de fichier sous-jacent à stream n'est pas valide.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATIVE

Une source d'erreur courante est l'allocation d'espace de mémoire tampon comme variable « automatique » dans un bloc de code, puis l'échec de fermeture du flux dans le même bloc.

Avec setvbuf(), l'allocation d'une mémoire tampon de size octets n'implique pas nécessairement que tous les octets de size sont utilisés pour la zone de mémoire tampon.

Les applications doivent noter que de nombreuses implémentations ne fournissent une mise en mémoire tampon par ligne que pour les entrées provenant de terminaux.
