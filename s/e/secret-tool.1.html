SECRET-TOOL(1) Commandes utilisateur SECRET-TOOL(1)

NOM

secret-tool - Stocker et récupérer des mots de passe

SYNTAXE

secret-tool store --label='Étiquette' {attribut} {valeur} ...

secret-tool lookup {attribut} {valeur} ...

secret-tool clear {attribut} {valeur} ...

secret-tool search [--all]{attribut} {valeur} ...

DESCRIPTION

secret-tool est un outil en ligne de commande qui peut être utilisé pour stocker et récupérer des mots de passe.

Chaque mot de passe est stocké dans un élément. Les éléments sont identifiés de manière unique par un ensemble de clés et de valeurs d'attributs. Lorsque vous stockez un mot de passe, vous devez spécifier des paires uniques de noms et de valeurs d'attributs, et lorsque vous recherchez un mot de passe, vous fournissez les mêmes paires de noms et de valeurs d'attributs.

STORE

Pour stocker un mot de passe, exécutez secret-tool avec l'argument store. Vous devez également spécifier une étiquette pour le mot de passe avec l'argument --label. Cette étiquette sera affichée dans le gestionnaire de mots de passe.

Assurez-vous de fournir un ensemble unique de noms et de valeurs d'attributs lors du stockage d'un mot de passe. Si les attributs correspondent à un élément déjà existant, il sera mis à jour au lieu de créer un nouvel élément.

Si l'outil est invoqué depuis un terminal ou un tty, le mot de passe à stocker sera demandé et seule une ligne sera acceptée.

Un mot de passe à stocker peut également être transmis via stdin. Le mot de passe sera le contenu de stdin jusqu'à EOF. Si vous fournissez un saut de ligne via stdin, il sera stocké dans le mot de passe.

LOOKUP

Pour rechercher un mot de passe, exécutez secret-tool avec l'argument lookup. Spécifiez les mêmes noms et valeurs d'attributs que ceux que vous avez fournis lors du stockage du mot de passe.

Si plusieurs éléments correspondent à l'attribut fourni, le premier mot de passe déjà déverrouillé sera retourné. Si nécessaire, un élément sera déverrouillé.

Lors de l'affichage du mot de passe dans un terminal ou un tty, un saut de ligne supplémentaire sera ajouté après le mot de passe.

CLEAR

Pour supprimer un mot de passe, exécutez secret-tool avec l'argument clear. Spécifiez les mêmes noms et valeurs d'attributs que ceux que vous avez fournis lors du stockage du mot de passe.

Tous les éléments déverrouillés correspondant aux attributs seront supprimés.

SEARCH

Cette commande recherche et affiche les détails sur les éléments correspondants dans le service secret. Spécifiez les mêmes attributs et valeurs que ceux que vous avez fournis lors du stockage du mot de passe. Vous pouvez utiliser les options suivantes :

--all

Retourne tous les résultats correspondants, plutôt qu'un seul des correspondants. Sans cette option, le premier correspondant déverrouillé renvoyé par le service sera affiché.

--unlock

Déverrouille les éléments verrouillés puis affiche leurs détails. Sans cette option, les éléments verrouillés sont ignorés.

ÉTAT DE SORTIE

En cas de succès, 0 est retourné, sinon un code d'échec non nul.

EXEMPLES

Exemple 1. Stockage, récupération et suppression d'un mot de passe

$ secret-tool store --label='Mon mot de passe' cle1 valeur1 cle2 valeur2
Mot de passe : hunter2
$ secret-tool lookup cle1 valeur1 cle2 valeur2
hunter2
$ secret-tool clear cle1 valeur1 cle2 valeur2

BOGUES

Le suivi des bogues est accessible en visitant le site web https://gitlab.gnome.org/GNOME/libsecret/issues. Avant d'envoyer un rapport de bogue, veuillez vérifier que vous disposez de la dernière version de secret-tool. De nombreux bogues (majeurs et mineurs) sont corrigés à chaque version, et si vous utilisez une version obsolète, le problème pourrait déjà être résolu.
