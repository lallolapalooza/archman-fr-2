SERIALVIEW(1) Manuel des commandes générales SERIALVIEW(1)

NOM

serialview - Émulateur de terminal pour uCsim

SYNTAXE

serialview -i <nom_fichier> -o <nom_fichier> -L n -a <motif> -A <réponse> -IOh

DESCRIPTION

serialview est un émulateur de terminal simple qui peut être utilisé avec uCsim.

OPTIONS

-i nom_fichier
nom_fichier est le tube d'entrée série du contrôleur. Les caractères tapés dans le panneau d'entrée seront écrits dans ce fichier.
-o nom_fichier
nom_fichier est le tube de sortie série du contrôleur. Le contenu de ce fichier est présenté dans le panneau de sortie.
-I
Utilise un filtre hexadécimal sur l'entrée. Seuls les caractères hexadécimaux sont acceptés dans le panneau d'entrée. Deux caractères sont combinés en un code hexadécimal et la valeur est écrite dans le tube d'entrée.
-O
Utilise un filtre hexadécimal sur la sortie. Le contenu du tube de sortie est présenté sous forme de dump hexadécimal. L'option -L peut être utilisée pour définir le nombre d'octets imprimés par ligne.
-a motif
motif est une chaîne de caractères reconnue dans le flux de sortie et à laquelle on répond automatiquement en envoyant une chaîne de réponse (voir l'option -A). La chaîne peut être formatée comme une chaîne C, les caractères non ASCII peuvent être échappés en style C.
-A réponse
réponse est une chaîne de caractères qui est envoyée lorsqu'un motif (voir l'option -a) est détecté dans la sortie du simulateur. Cette chaîne de réponse est écrite dans le tube d'entrée mais n'est pas affichée dans le panneau d'entrée.
-L n
Définit la longueur de ligne du dump hexadécimal dans le panneau de sortie (défaut=8).
-h
Affiche un résumé des options.

Lorsque aucune option n'est fournie, les tubes d'entrée et de sortie sont créés dans /tmp et nommés respectivement in et out.

VOIR AUSSI

sdcc(1), ucsim(1).
