SETXKBMAP(1) Manuel des commandes générales SETXKBMAP(1)

NOM

setxkbmap - configurer le clavier à l'aide de l'extension X Keyboard

SYNTAXE

setxkbmap [ arguments ] [ disposition [ variante [ option ... ] ] ]

DESCRIPTION

La commande setxkbmap configure le clavier pour utiliser la disposition déterminée par les options spécifiées sur la ligne de commande.

Une carte de clavier XKB est construite à partir d'un certain nombre de composants qui ne sont compilés qu'au besoin. La source de tous les composants se trouve dans /usr/share/X11/xkb.

OPTIONS

-compat nom
Spécifie le nom du composant de la carte de compatibilité utilisé pour construire une disposition de clavier.
-config fichier
Spécifie le nom d'un fichier de configuration XKB qui décrit le clavier à utiliser.
-device périphérique
Spécifie l'identifiant numérique du périphérique d'entrée à mettre à jour avec la nouvelle disposition de clavier. S'il n'est pas spécifié, le périphérique clavier principal du serveur X est mis à jour.
-display affichage
Spécifie l'affichage à mettre à jour avec la nouvelle disposition de clavier.
-geometry nom
Spécifie le nom du composant de géométrie utilisé pour construire une disposition de clavier.
-help
Affiche un message décrivant les entrées valides pour setxkbmap.
-I répertoire
Ajoute un répertoire à la liste des répertoires à utiliser pour rechercher les fichiers de disposition ou de règles spécifiés.
-keycodes nom
Spécifie le nom du composant des codes de touches utilisé pour construire une disposition de clavier.
-keymap nom
Spécifie le nom de la description de la carte de touches utilisée pour construire une disposition de clavier.
-layout nom
Spécifie le nom de la disposition utilisée pour déterminer les composants qui composent la description du clavier. L'option -layout ne peut être utilisée qu'une seule fois. Plusieurs dispositions peuvent être spécifiées sous forme de liste séparée par des virgules.
-model nom
Spécifie le nom du modèle de clavier utilisé pour déterminer les composants qui composent la description du clavier. Un seul modèle peut être spécifié sur la ligne de commande.
-option nom
Spécifie le nom d'une option pour déterminer les composants qui composent la description du clavier ; plusieurs options peuvent être spécifiées, une par flag -option. Notez que setxkbmap ajoute les options spécifiées sur la ligne de commande aux options qui étaient définies précédemment (telles qu'enregistrées dans les propriétés de la fenêtre racine). Si vous souhaitez remplacer toutes les options précédemment spécifiées, utilisez le flag -option avec un argument vide en premier.
-print
Avec cette option, setxkbmap affiche simplement les noms des composants dans un format acceptable par xkbcomp (un compilateur de cartes de touches XKB) et quitte. L'option peut être utilisée pour des tests au lieu d'une option verbeuse et dans les cas où l'on a besoin d'exécuter à la fois setxkbmap et xkbcomp en chaîne (voir ci-dessous).
-query
Avec cette option, setxkbmap affiche simplement les règles, le modèle, la disposition, la variante et les options actuels, puis quitte.
-rules fichier
Spécifie le nom du fichier de règles utilisé pour résoudre la disposition et le modèle demandés en un ensemble de noms de composants.
-symbols nom
Spécifie le nom du composant des symboles utilisé pour construire une disposition de clavier.
-synch
Force la synchronisation pour les requêtes X.
-types nom
Spécifie le nom du composant des types utilisé pour construire une disposition de clavier.
-variant nom
Spécifie quelle variante de la disposition du clavier doit être utilisée pour déterminer les composants qui composent la description du clavier. L'option -variant ne peut être utilisée qu'une seule fois. Plusieurs variantes peuvent être spécifiées sous forme de liste séparée par des virgules et seront correspondantes aux dispositions spécifiées avec -layout.
-verbose|-v [niveau]
Spécifie le niveau de verbosité dans les messages de sortie. Les niveaux valides vont de 0 (moins verbeux) à 10 (le plus verbeux). Le niveau de verbosité par défaut est de 5. Si aucun niveau n'est spécifié, chaque flag -v ou -verbose augmente le niveau de 1.
-version
Affiche le numéro de version du programme.

UTILISATION AVEC xkbcomp

Si vous avez un serveur X et un shell client s'exécutant sur des ordinateurs différents et que certains fichiers de configuration XKB sur ces machines sont différents, vous pouvez rencontrer des problèmes lors de la spécification d'une carte de clavier par nom de modèle, de disposition et d'options. En effet, setxkbmap convertit ses arguments en noms de fichiers de configuration XKB selon les fichiers présents sur la machine côté client, puis envoie ces noms de fichiers au serveur où xkbcomp doit composer une carte de clavier complète en utilisant les fichiers que le serveur possède. Ainsi, si les ensembles de fichiers diffèrent d'une manière ou d'une autre, les noms générés par setxkbmap peuvent être inacceptables côté serveur. Vous pouvez résoudre ce problème en exécutant également xkbcomp côté client. Avec l'option -print, setxkbmap affiche simplement les noms de fichiers dans un format approprié sur sa sortie standard et cette sortie peut être directement redirigée vers l'entrée de xkbcomp. Par exemple, la commande

setxkbmap us -print | xkbcomp - $DISPLAY

effectue les deux étapes sur la même machine (client) et charge une carte de clavier dans le serveur.

XWAYLAND

Xwayland est un serveur X qui utilise un compositeur Wayland comme backend. Xwayland agit comme une couche de traduction entre le protocole X et le protocole Wayland mais ne gère pas les cartes de touches - celles-ci sont gérées par le compositeur Wayland.

La modification de la carte de touches avec setxkbmap n'est pas prise en charge par Xwayland. Dans la plupart des cas, l'utilisation de setxkbmap sur Xwayland est indicative d'un bug dans un script shell et setxkbmap affichera un avertissement. Utilisez plutôt les méthodes de configuration XKB natives du compositeur Wayland.
