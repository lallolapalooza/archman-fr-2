NOM

send_osc - Envoie un message OSC unique

SYNTAXE

send_osc port chemin [,types] [args...]

DESCRIPTION

send_osc envoie un message OSC au port spécifié (numéro de port UDP, ou toute autre chaîne d'adresse supportée par liblo). Le message est livré au chemin. Si le premier argument suivant le chemin commence par une virgule, il est interprété comme une chaîne de types, spécifiant les types de données OSC à utiliser pour l'envoi des arguments du message. Sinon, send_osc essaie automatiquement d'utiliser les types de données appropriés. Les valeurs entières et flottantes valides sont envoyées telles quelles, tout le reste est envoyé sous forme de chaîne.
