NOM

set - Lire et écrire des variables

SYNOPSIS

set varName ?valeur?

DESCRIPTION

Renvoie la valeur de la variable varName. Si valeur est spécifiée, alors définit la valeur de varName à valeur, créant une nouvelle variable si elle n'existe pas déjà, et renvoie sa valeur. Si varName contient une parenthèse ouvrante et se termine par une parenthèse fermante, alors il fait référence à un élément de tableau : les caractères avant la première parenthèse ouvrante sont le nom du tableau, et les caractères entre les parenthèses sont l'index dans le tableau. Sinon, varName fait référence à une variable scalaire.

Si varName inclut des qualificateurs d'espace de noms (dans le nom du tableau s'il fait référence à un élément de tableau), ou si varName n'est pas qualifié (ne contient pas les noms des espaces de noms conteneurs) mais qu'aucune procédure n'est active, varName fait référence à une variable d'espace de noms résolue selon les règles décrites sous RÉSOLUTION DE NOM dans la page de manuel namespace.

Si une procédure est active et que varName n'est pas qualifié, alors varName fait référence à un paramètre ou à une variable locale de la procédure, à moins que varName n'ait été déclaré pour résoudre différemment via l'une des commandes global, variable ou upvar.

EXEMPLES

Stocke un nombre aléatoire dans la variable r :

set r [expr {rand()}]

Stocke un court message dans un élément de tableau :

set anAry(msg) "Bonjour, le Monde !"

Stocke un court message dans un élément de tableau spécifié par une variable :

set elemName "msg"
set anAry($elemName) "Bonjour, le Monde !"

Copie une valeur dans la variable out depuis une variable dont le nom est stocké dans vbl (notez qu'il est souvent plus facile d'utiliser des tableaux en pratique que de faire une double déréférence) :

set in0 "petit aléatoire"
set in1 "grand aléatoire"
set vbl in[expr {rand() >= 0.5}]
set out [set $vbl]

MOTS CLÉS

lire, écrire, variable
