SHADOW(3) Appels de bibliothèque SHADOW(3)

NOM

shadow, getspnam - routines de fichier de mots de passe chiffrés

SYNTAXE

#include <shadow.h>

struct spwd *getspent();

struct spwd *getspnam(char *name);

void setspent();

void endspent();

struct spwd *fgetspent(FILE *fp);

struct spwd *sgetspent(char *cp);

int putspent(struct spwd *p, FILE *fp);

int lckpwdf();

int ulckpwdf();

DESCRIPTION

shadow manipule le contenu du fichier de mots de passe shadow, /etc/shadow. La structure dans le fichier #include est :

struct spwd {
      char		*sp_namp; /* nom d'utilisateur */
      char		*sp_pwdp; /* mot de passe chiffré */
      long int		sp_lstchg; /* dernier changement de mot de passe */
      long int		sp_min; /* jours avant changement autorisé. */
      long int		sp_max; /* jours avant changement requis */
      long int		sp_warn; /* jours d'avertissement avant expiration */
      long int		sp_inact; /* jours avant inactivité du compte */
      long int		sp_expire; /* date d'expiration du compte */
      unsigned long int	sp_flag; /* réservé pour usage futur */
}

Les significations de chaque champ sont :

•sp_namp - pointeur vers le nom d'utilisateur terminé par un caractère nul
•sp_pwdp - pointeur vers le mot de passe terminé par un caractère nul
•sp_lstchg - jours depuis le 1er janvier 1970 où le mot de passe a été modifié pour la dernière fois
•sp_min - jours avant lesquels le mot de passe ne peut être modifié
•sp_max - jours après lesquels le mot de passe doit être modifié
•sp_warn - jours avant l'expiration du mot de passe pendant lesquels l'utilisateur est averti de l'expiration imminente
•sp_inact - jours après l'expiration du mot de passe pendant lesquels le compte est considéré inactif et désactivé
•sp_expire - jours depuis le 1er janvier 1970 à partir desquels le compte sera désactivé
•sp_flag - réservé pour usage futur

DESCRIPTION

getspent, getspname, fgetspent et sgetspent renvoient chacun un pointeur vers une struct spwd. getspent renvoie la prochaine entrée du fichier, et fgetspent renvoie la prochaine entrée du flux donné, qui est supposé être un fichier au format approprié. sgetspent renvoie un pointeur vers une struct spwd en utilisant la chaîne fournie comme entrée. getspnam recherche à partir de la position actuelle dans le fichier une entrée correspondant à name.

setspent et endspent peuvent être utilisés pour commencer et terminer, respectivement, l'accès au fichier de mots de passe shadow.

Les routines lckpwdf et ulckpwdf doivent être utilisées pour garantir un accès exclusif au fichier /etc/shadow. lckpwdf tente d'acquérir un verrou en utilisant pw_lock pendant jusqu'à 15 secondes. Il continue en tentant d'acquérir un second verrou en utilisant spw_lock pour le reste des 15 secondes initiales. Si l'une ou l'autre tentative échoue après un total de 15 secondes, lckpwdf renvoie -1. Lorsque les deux verrous sont acquis, 0 est renvoyé.

DIAGNOSTICS

Les routines renvoient NULL s'il n'y a plus d'entrées disponibles ou si une erreur se produit pendant le traitement. Les routines qui renvoient un entier renvoient 0 en cas de succès et -1 en cas d'échec.

CAVEATS

Ces routines ne peuvent être utilisées que par le superutilisateur car l'accès au fichier de mots de passe shadow est restreint.
