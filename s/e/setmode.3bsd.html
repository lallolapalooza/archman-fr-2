setmode(3bsd)

Paquet: libbsd

Licences: custom

setmode(3bsd) 3bsd setmode(3bsd)

NOM

getmode, setmode — modifier les bits de mode

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <unistd.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
void *
setmode(const char *mode_str);

mode_t
getmode(const void *set, mode_t mode);

DESCRIPTION

La fonction setmode() accepte une représentation textuelle d'un changement de mode de fichier, la compile sous forme binaire, et retourne une représentation abstraite qui peut être passée à getmode(). La chaîne peut être numérique (octale) ou symbolique, de la forme acceptée par chmod(1), et peut représenter soit un mode exact à définir, soit un changement à apporter au mode existant.

La fonction getmode() ajuste les bits de permissions du fichier donnés par mode selon la représentation de changement compilée set, et retourne le mode ajusté. Bien que seuls les bits de permissions soient modifiés, d'autres parties du mode de fichier, notamment le type, peuvent être examinées.

Parce que certaines des valeurs symboliques possibles sont définies par rapport au masque de création de fichier, setmode() peut appeler umask(2), en changeant temporairement le masque. Si cela se produit, le masque de création de fichier sera restauré avant le retour de setmode(). Si le programme appelant modifie la valeur de son masque de création de fichier après avoir appelé setmode(), setmode() doit être rappelé pour recompiler la chaîne de mode si getmode() doit modifier correctement les futurs modes de fichiers.

Si le mode passé à setmode() est invalide, setmode() retourne NULL.

La valeur retournée par setmode() est obtenue à partir de malloc() et devrait être retournée au système avec free() lorsque le programme n'en a plus besoin, généralement après un appel à getmode().

EXEMPLES

Les effets de la commande shell ‘chmod a+x myscript.sh’ peuvent être reproduits comme suit :

const char *file = "myscript.sh";
struct stat st;
mode_t newmode;

stat(file, &st);
newmode = getmode(setmode("a+x"), st.st_mode);
chmod(file, newmode);

ERREURS

La fonction setmode() peut échouer et définir errno pour l'une des erreurs spécifiées pour les routines de bibliothèque malloc(3) ou strtol(3). De plus, setmode() échouera et définira errno à :

[EINVAL]
L'argument mode ne représente pas un mode valide.

VOIR AUSSI

chmod(1), stat(2), umask(2), malloc(3)

HISTORIQUE

Les fonctions getmode() et setmode() sont apparues pour la première fois dans 4.4BSD.

BOGUES

Le type de set devrait en réalité être un certain type de structure opaque utilisé uniquement par ces fonctions plutôt que void *.
