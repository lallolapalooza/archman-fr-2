SETLOCALE(3P) Manuel du programmeur POSIX SETLOCALE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

setlocale — définir la locale du programme

SYNTAXE

#include <locale.h>
char *setlocale(int category, const char *locale);

DESCRIPTION

Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction setlocale() sélectionne la partie appropriée de la locale globale, telle que spécifiée par les arguments category et locale, et peut être utilisée pour modifier ou interroger la locale globale entière ou des parties de celle-ci. La valeur LC_ALL pour category nomme la locale globale entière ; d'autres valeurs pour category nomment seulement une partie de la locale globale :

LC_COLLATE
Affecte le comportement des expressions régulières et des fonctions de collation.
LC_CTYPE
Affecte le comportement des expressions régulières, de la classification des caractères, des fonctions de conversion de caractères et des fonctions de caractères larges.
LC_MESSAGES
Affecte les expressions de réponse affirmative et négative retournées par nl_langinfo() et la manière dont les catalogues de messages sont localisés. Elle peut également affecter le comportement des fonctions qui retournent ou écrivent des chaînes de messages.
LC_MONETARY
Affecte le comportement des fonctions qui traitent les valeurs monétaires.
LC_NUMERIC
Affecte le comportement des fonctions qui traitent les valeurs numériques.
LC_TIME
Affecte le comportement des fonctions de conversion de date et d'heure.

L'argument locale est un pointeur vers une chaîne de caractères contenant le paramètre requis pour category. Le contenu de cette chaîne est dépendant de l'implémentation. De plus, les valeurs prédéfinies suivantes de locale sont définies pour tous les paramètres de category :

"POSIX"
Spécifie l'environnement minimal pour la traduction en langage C, appelé locale POSIX. La locale POSIX est la locale globale par défaut à l'entrée de main().
"C"
Équivalent à "POSIX".
""
Spécifie un environnement natif dépendant de l'implémentation. La détermination du nom de la nouvelle locale pour la catégorie spécifiée dépend de la valeur des variables d'environnement associées, LC_* et LANG ; voir le volume des Définitions de base de POSIX.1‐2017, Chapitre 7, Locale et Chapitre 8, Variables d'environnement.
Un pointeur nul
Demande à setlocale() d'interroger le paramètre actuel de la locale globale et de retourner le nom de la locale si category n'est pas LC_ALL, ou une chaîne qui encode le(s) nom(s) de locale pour toutes les catégories individuelles si category est LC_ALL.

La définition de toutes les catégories de la locale globale est similaire à la définition successive de chaque catégorie individuelle de la locale globale, à la différence que toutes les vérifications d'erreur sont effectuées avant que toute action ne soit entreprise. Pour définir toutes les catégories de la locale globale, setlocale() peut être appelée comme suit :

setlocale(LC_ALL, "");

Dans ce cas, setlocale() vérifiera d'abord que les valeurs de toutes les variables d'environnement dont elle a besoin selon les règles de priorité (décrites dans le volume des Définitions de base de POSIX.1‐2017, Chapitre 8, Variables d'environnement) indiquent des locales supportées. Si la valeur de l'une de ces recherches de variables d'environnement donne une locale qui n'est pas supportée (et non nulle), setlocale() retournera un pointeur nul et la locale globale ne sera pas modifiée. Si toutes les variables d'environnement nomment des locales supportées, setlocale() procédera comme si elle avait été appelée pour chaque catégorie, en utilisant la valeur appropriée de la variable d'environnement associée ou de la valeur par défaut dépendant de l'implémentation s'il n'y a pas une telle valeur.

La locale globale établie à l'aide de setlocale() ne sera utilisée que dans les threads pour lesquels aucune locale actuelle n'a été définie à l'aide de uselocale() ou dont la locale actuelle a été définie sur la locale globale à l'aide de uselocale(LC_GLOBAL_LOCALE).

L'implémentation se comportera comme si aucune fonction définie dans ce volume de POSIX.1‐2017 n'appelait setlocale().

La fonction setlocale() n'est pas nécessairement thread-safe.

VALEUR DE RETOUR

En cas de succès, setlocale() retournera la chaîne associée à la catégorie spécifiée pour la nouvelle locale. Sinon, setlocale() retournera un pointeur nul et la locale globale ne sera pas modifiée.

Un pointeur nul pour locale entraînera le retour par setlocale() d'un pointeur vers la chaîne associée à la category spécifiée pour la locale globale actuelle. La locale globale ne sera pas modifiée.

La chaîne retournée par setlocale() est telle qu'un appel ultérieur avec cette chaîne et sa category associée restaurera cette partie de la locale globale. L'application ne doit pas modifier la chaîne retournée. Le pointeur vers la chaîne retournée peut être invalidé ou le contenu de la chaîne peut être écrasé par un appel ultérieur à setlocale(). Le pointeur retourné peut également être invalidé si le thread appelant est terminé.

ERREURS

Aucune erreur n'est définie.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Le code suivant illustre comment un programme peut initialiser l'environnement international pour une langue, tout en modifiant sélectivement la locale globale de sorte que les expressions régulières et les opérations sur les chaînes puissent être appliquées à du texte enregistré dans une langue différente :

setlocale(LC_ALL, "De");
setlocale(LC_COLLATE, "Fr@dict");

Les programmes internationalisés peuvent initier les opérations linguistiques conformément aux paramètres des variables d'environnement (voir le volume des Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation) en appelant setlocale() comme suit :

setlocale(LC_ALL, "");

La modification du paramètre de LC_MESSAGES n'affecte pas les catalogues déjà ouverts par des appels à catopen().

Afin d'utiliser différents paramètres de locale lorsque plusieurs threads s'exécutent, les applications doivent préférer uselocale() à setlocale().

setlocale(3) — Arch manual pages

NAME

setlocale — query and change the locale

SYNOPSIS

#include <locale.h>

char *setlocale(int category, const char * locale);

DESCRIPTION

The setlocale() function is used to query and modify the program's current locale. The locale is a collection of internationalization attributes that depend on the language, country, and character set.

The category argument determines which part of the program's internationalization attributes are to be set or queried. The following constants are defined in <locale.h> and are used to specify the category:

LC_ALL

LC_COLLATE

LC_CTYPE

LC_MESSAGES

LC_MONETARY

LC_NUMERIC

LC_TIME

The LC_ALL category affects all the other categories listed above. The functionality mentioned above.

The syntax for setlocale() is as follows:

char *setlocale(int category, const char *locale);

where category is the name of one of following categories, namely:

LC_COLLATE LC_CTYPE LC_MESSAGES LC_MONETARY LC_NUMERIC LC_TIME

In addition, a special value called LC_ALL directs setlocale() to set all categories.

There are two primary uses of setlocale():

1.
Querying the international environment to find out what it is set to
2.
Setting the international environment, or locale, to a specific value

The behavior of setlocale() in these two areas is described below. Since it is difficult to describe the behavior in words, examples are used to illustrate the behavior of specific uses.

To query the international environment, setlocale() is invoked with a specific category and the null pointer as the locale. The null pointer is a special directive to setlocale() that tells it to query rather than set the international environment. The following syntax is used to query the name of the international environment:

setlocale({LC_ALL, LC_COLLATE, LC_CTYPE, LC_MESSAGES, LC_MONETARY, \
    LC_NUMERIC, LC_TIME},(char *) NULL);

RETURN VALUE

The setlocale() function shall return the string corresponding to the current international environment. This value may be used by a subsequent call to setlocale() to reset the international environment to this value. However, it should be noted that the return value from setlocale() may be a pointer to a static area within the function and is not guaranteed to remain unchanged (that is, it may be modified by a subsequent call to setlocale()). Therefore, if the purpose of calling setlocale() is to save the value of the current international environment so it can be changed and reset later, the return value should be copied to an array of char in the calling program.

ERRORS

The setlocale() function may fail if the locale specified by the locale argument is not supported by the system. In this case, it returns a null pointer and the locale is not changed.

EXAMPLES

There are three ways to set the international environment with setlocale():

setlocale(category, string)

This usage sets a specific category in the international environment to a specific value corresponding to the value of the string. A specific example is provided below:
setlocale(LC_ALL, "fr_FR.ISO-8859-1");

In this example, all categories of the international environment are set to the locale corresponding to the string "fr_FR.ISO-8859-1", or to the French language as spoken in France using the ISO/IEC 8859‐1:1998 standard codeset.

If the string does not correspond to a valid locale, setlocale() shall return a null pointer and the international environment is not changed. Otherwise, setlocale() shall return the name of the locale just set.

setlocale(category, "C")

The ISO C standard states that one locale must exist on all conforming implementations. The name of the locale is C and corresponds to a minimal international environment needed to support the C programming language.
setlocale(category, "")

This sets a specific category to an implementation-defined default. This corresponds to the value of the environment variables.

APPLICATION USAGE

Applications should call setlocale() at the beginning of their execution to set the desired locale. If the return value is saved, it can be used to restore the locale later.

RATIONALE

The setlocale() function provides a standard way to control the behavior of locale-dependent functions. It allows programs to adapt to different cultural conventions, such as date and time formats, currency symbols, and character classification rules.

The use of categories allows for fine-grained control over the locale settings. For example, an application might want to use the default locale for numeric formatting but a specific locale for monetary formatting.

The special value "" for the locale argument allows applications to use the locale settings defined by the environment variables (e.g., LANG, LC_ALL). This provides a convenient way to set the locale according to the user's preferences.

The C locale is guaranteed to be available on all POSIX-compliant systems. It provides a minimal, portable environment suitable for basic C programming tasks.

The return value of setlocale() is a pointer to a static buffer. This means that subsequent calls to setlocale() may overwrite the previous return value. Therefore, it is important to copy the return value to a separate buffer if it needs to be preserved.
