getttyent(3) Manuel des fonctions de bibliothèque getttyent(3)

NOM

getttyent, getttynam, setttyent, endttyent - obtenir une entrée du fichier ttys

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <ttyent.h>
struct ttyent *getttyent(void);
struct ttyent *getttynam(const char *name);
int setttyent(void);
int endttyent(void);

DESCRIPTION

Ces fonctions fournissent une interface au fichier _PATH_TTYS (par exemple, /etc/ttys).

La fonction setttyent() ouvre le fichier ou le rembobine s'il est déjà ouvert.

La fonction endttyent() ferme le fichier.

La fonction getttynam() recherche un nom de terminal donné dans le fichier. Elle renvoie un pointeur vers une structure ttyent (description ci-dessous).

La fonction getttyent() ouvre le fichier _PATH_TTYS (si nécessaire) et renvoie la première entrée. Si le fichier est déjà ouvert, elle renvoie l'entrée suivante. La structure ttyent a la forme suivante :


struct ttyent {
    char *ty_name;     /* nom du périphérique de terminal */
    char *ty_getty;    /* commande à exécuter, généralement getty */
    char *ty_type;     /* type de terminal pour termcap */
    int   ty_status;   /* indicateurs d'état */
    char *ty_window;   /* commande pour démarrer le gestionnaire de fenêtres */
    char *ty_comment;  /* champ commentaire */
};

ty_status peut être :


#define TTY_ON     0x01  /* activer les connexions (démarrer le programme ty_getty) */
#define TTY_SECURE 0x02  /* autoriser la connexion de l'UID 0 */

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getttyent (), setttyent (), endttyent (), getttynam () Thread safety MT-Unsafe race:ttyent

NORMES

BSD.

NOTES

Sous Linux, le fichier /etc/ttys et les fonctions décrites ci-dessus ne sont pas utilisés.

VOIR AUSSI
