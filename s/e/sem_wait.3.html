sem_wait(3) Manuel des fonctions de bibliothèque sem_wait(3)

NOM

sem_wait, sem_timedwait, sem_trywait - verrouiller un sémaphore

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <semaphore.h>
int sem_wait(sem_t *sem);
int sem_trywait(sem_t *sem);
int sem_timedwait(sem_t *restrict sem,
                  const struct timespec *restrict abs_timeout);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

sem_timedwait():

    _POSIX_C_SOURCE >= 200112L

DESCRIPTION

sem_wait() décrémente (verrouille) le sémaphore pointé par sem. Si la valeur du sémaphore est supérieure à zéro, la décrémentation s'effectue et la fonction retourne immédiatement. Si le sémaphore a actuellement la valeur zéro, l'appel est bloqué jusqu'à ce qu'il soit possible de réaliser la décrémentation (c'est-à-dire que la valeur du sémaphore passe au-dessus de zéro), ou qu'un gestionnaire de signaux interrompe l'appel.

sem_trywait() est identique à sem_wait(), sauf que si la décrémentation ne peut pas être effectuée immédiatement, l'appel retourne une erreur (errno défini à EAGAIN) au lieu de se bloquer.

sem_timedwait() est identique à sem_wait(), sauf que abs_timeout spécifie une limite de temps pendant laquelle l'appel doit être bloqué si la décrémentation ne peut pas être effectuée immédiatement. L'argument abs_timeout pointe vers une structure timespec(3) qui spécifie un délai d'expiration absolu en secondes et nanosecondes depuis l'Epoch, le 1er janvier 1970 à 00:00:00 UTC.

Si le délai d'expiration a déjà expiré au moment de l'appel, et que le sémaphore n'a pas pu être verrouillé immédiatement, alors sem_timedwait() échoue avec une erreur de délai d'expiration (errno défini à ETIMEDOUT).

Si l'opération peut être effectuée immédiatement, alors sem_timedwait() n'échoue jamais avec une erreur de délai d'expiration, indépendamment de la valeur de abs_timeout. De plus, la validité de abs_timeout n'est pas vérifiée dans ce cas.

VALEUR DE RETOUR

Toutes ces fonctions retournent 0 en cas de succès ; en cas d'erreur, la valeur du sémaphore reste inchangée, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
(sem_trywait()) L'opération n'a pas pu être effectuée sans blocage (c'est-à-dire que le sémaphore a actuellement la valeur zéro).
EINTR
L'appel a été interrompu par un gestionnaire de signaux ; voir signal(7).
EINVAL
sem n'est pas un sémaphore valide.
EINVAL
(sem_timedwait()) La valeur de abs_timeout.tv_nsecs est inférieure à 0, ou supérieure ou égale à 1000 millions.
ETIMEDOUT
(sem_timedwait()) L'appel a expiré avant que le sémaphore ne puisse être verrouillé.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sem_wait (), sem_trywait (), sem_timedwait () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

EXEMPLES

Le programme ci-dessous (assez trivial) opère sur un sémaphore sans nom. Le programme attend deux arguments en ligne de commande. Le premier argument spécifie une valeur en secondes utilisée pour régler un minuteur d'alarme afin de générer un signal SIGALRM. Ce gestionnaire effectue un sem_post(3) pour incrémenter le sémaphore sur lequel sem_timedwait() attend dans main(). Le second argument de ligne de commande spécifie la durée du délai d'attente, en secondes, pour sem_timedwait(). Ce qui suit montre ce qui se passe lors de deux exécutions différentes du programme :


$ ./a.out 2 3
About to call sem_timedwait()
sem_post() from handler
sem_timedwait() succeeded
$ ./a.out 2 1
About to call sem_timedwait()
sem_timedwait() timed out

Source du programme

#include <err.h>
#include <errno.h>
#include <semaphore.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
#include <assert.h>
sem_t sem;
static void
handler(int sig)
{
    write(STDOUT_FILENO, "sem_post() from handler\n", 24);
    if (sem_post(&sem) == -1) {
        write(STDERR_FILENO, "sem_post() failed\n", 18);
        _exit(EXIT_FAILURE);
    }
}
int
main(int argc, char *argv[])
{
    struct sigaction sa;
    struct timespec ts;
    int s;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <alarm-secs> <wait-secs>\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    if (sem_init(&sem, 0, 0) == -1)
        err(EXIT_FAILURE, "sem_init");
    /* Establish SIGALRM handler; set alarm timer using argv[1].  */
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;
    if (sigaction(SIGALRM, &sa, NULL) == -1)
        err(EXIT_FAILURE, "sigaction");
    alarm(atoi(argv[1]));
    /* Calculate relative interval as current time plus
       number of seconds given argv[2].  */
    if (clock_gettime(CLOCK_REALTIME, &ts) == -1)
        err(EXIT_FAILURE, "clock_gettime");
    ts.tv_sec += atoi(argv[2]);
    printf("%s() about to call sem_timedwait()\n", __func__);
    while ((s = sem_timedwait(&sem, &ts)) == -1 && errno == EINTR)
        continue;       /* Restart if interrupted by handler.  */
    /* Check what happened.  */
    if (s == -1) {
        if (errno == ETIMEDOUT)
            printf("sem_timedwait() timed out\n");
        else
            perror("sem_timedwait");
    } else
        printf("sem_timedwait() succeeded\n");
    exit((s == 0) ? EXIT_SUCCESS : EXIT_FAILURE);
}

NOM

sem_wait - attendre pour un sémaphore

BIBLIOTHÈQUE

Bibliothèque de threads -lpt (pour les sémaphores non nommés), Bibliothèque en temps réel -lrt (pour les sémaphores nommés)

SYNTAXE

#include <semaphore.h>

int sem_wait(sem_t *sem);
int sem_timedwait(sem_t *restrict sem, const struct timespec *restrict abs_timeout);
int sem_trywait(sem_t *sem);

DESCRIPTION

La fonction sem_wait décrémente (verrouille) le sémaphore pointé par sem. Si la valeur du sémaphore est supérieure à zéro, la décrémentation se produit et la fonction renvoie immédiatement. Si la valeur du sémaphore est égale à zéro, la fonction se bloque jusqu'à ce que la valeur devienne supérieure à zéro en raison d'une opération sem_post effectuée par un autre thread ou processus. Dans ce cas, sem_wait décrémente la valeur du sémaphore et renvoie.

La fonction sem_timedwait est identique à sem_wait, sauf que si le sémaphore ne peut pas être décrémenté immédiatement (parce que sa valeur est zéro), elle attend au plus la durée spécifiée par abs_timeout. abs_timeout pointe vers une structure timespec qui spécifie une heure absolue à laquelle le délai d'attente doit expirer. Voir clock_gettime(3) pour la structure timespec.

La fonction sem_trywait est identique à sem_wait, mais si le sémaphore ne peut pas être décrémenté immédiatement (parce que sa valeur est zéro), elle renvoie immédiatement sans se bloquer.

La valeur du sémaphore est traitée comme un entier non signé. Les opérations sur les sémaphores sont atomiques.

Ces fonctions sont utilisées pour coordonner des threads ou des processus. Les sémaphores peuvent être partagés entre des processus s'ils sont initialisés à l'aide de sem_init avec une valeur pshared non nulle, ou s'ils sont créés à l'aide de sem_open(3).

Les sémaphores nommés créés avec sem_open(3) peuvent être utilisés par sem_wait, sem_timedwait et sem_trywait.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient zéro.

En cas d'échec, elles renvoient -1 et errno est définie pour indiquer l'erreur.

Pour sem_timedwait, si une erreur se produit ou si le délai d'attente expire, sem_wait renvoie -1 et errno est défini à ETIMEDOUT.

ERREURS

EINVAL
La valeur spécifiée pour sem n'est pas valide.
EINTR
L'appel a été interrompu par un signal avant que le sémaphore n'ait pu être décrémenté.
ETIMEDOUT
Le délai d'attente spécifié dans abs_timeout a expiré. (Seulement pour sem_timedwait).

Les fonctions sem_wait et sem_trywait peuvent également échouer avec les erreurs suivantes :

EDEADLK
Un blocage de ressources mortel a été détecté. Cela peut se produire si tous les threads qui pourraient potentiellement débloquer le sémaphore sont bloqués en attendant d'acquérir d'autres ressources qui sont détenues par le thread qui attend actuellement le sémaphore.

ATTRIBUTS

Pour obtenir des informations sur la syntaxe et les attributs de ces fonctions, consulter attributes(7).

| sem_timedwait(), sem_trywait()  |     asynchronous-cancel |

NORMES

sem_wait, sem_timedwait et sem_trywait sont conformes à POSIX.1-2008.

HISTORIQUE

La fonction sem_timedwait a été introduite dans POSIX.1-2001.

EXEMPLES

Le programme suivant montre comment utiliser sem_wait pour créer et utiliser un sémaphore non nommé.

#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <semaphore.h>
#include <unistd.h>

#define THREAD_NUM 5

sem_t sem_full; // Sémaphore pour les éléments pleins
sem_t sem_empty; // Sémaphore pour les éléments vides
sem_t sem_mutex; // Sémaphore mutex pour l'accès à la liste partagée

// Structure pour représenter un élément dans le tampon circulaire
typedef struct {
    int value;
} buffer_item;

// Tampon circulaire
#define BUFFER_SIZE 5
buffer_item buffer[BUFFER_SIZE];
int head = 0;
int tail = 0;

void *producer(void *arg) {
    int item_value = 0;
    while (1) {
        // Attendre qu'un espace vide soit disponible
        sem_wait(&sem_empty);
        // Acquérir le mutex pour accéder au tampon
        sem_wait(&sem_mutex);

        // Produire un nouvel élément
        buffer[tail].value = item_value++;
        printf("Producteur a produit : %d\n", buffer[tail].value);
        tail = (tail + 1) % BUFFER_SIZE;

        // Libérer le mutex
        sem_post(&sem_mutex);
        // Signaler qu'un élément plein est disponible
        sem_post(&sem_full);

        sleep(rand() % 2); // Simulation du temps de production
    }
    return NULL;
}

void *consumer(void *arg) {
    while (1) {
        // Attendre qu'un élément plein soit disponible
        sem_wait(&sem_full);
        // Acquérir le mutex pour accéder au tampon
        sem_wait(&sem_mutex);

        // Consommer un élément
        int consumed_item = buffer[head].value;
        printf("Consommateur a consommé : %d\n", consumed_item);
        head = (head + 1) % BUFFER_SIZE;

        // Libérer le mutex
        sem_post(&sem_mutex);
        // Signaler qu'un espace vide est disponible
        sem_post(&sem_empty);

        sleep(rand() % 3); // Simulation du temps de consommation
    }
    return NULL;
}

int main() {
    pthread_t producer_tid, consumer_tid;

    // Initialiser les sémaphores
    // sem_init(sem_t *sem, int pshared, unsigned int value);
    // pshared=0 : le sémaphore est partagé entre les threads du processus
    // pshared!=0 : le sémaphore est partagé entre les processus
    sem_init(&sem_full, 0, 0); // Initialement aucun élément plein
    sem_init(&sem_empty, 0, BUFFER_SIZE); // Initialement tous les emplacements sont vides
    sem_init(&sem_mutex, 0, 1); // Initialement le mutex est débloqué

    // Créer le thread producteur
    if (pthread_create(&producer_tid, NULL, producer, NULL) != 0) {
        perror("Erreur de création du thread producteur");
        exit(EXIT_FAILURE);
    }

    // Créer le thread consommateur
    if (pthread_create(&consumer_tid, NULL, consumer, NULL) != 0) {
        perror("Erreur de création du thread consommateur");
        exit(EXIT_FAILURE);
    }

    // Attendre la fin des threads (ne se terminera jamais dans ce cas)
    pthread_join(producer_tid, NULL);
    pthread_join(consumer_tid, NULL);

    // Détruire les sémaphores (ne sera jamais atteint)
    sem_destroy(&sem_full);
    sem_destroy(&sem_empty);
    sem_destroy(&sem_mutex);

    return 0;
}
