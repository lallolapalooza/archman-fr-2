SETQUOTA(8) Manuel de l'administrateur système SETQUOTA(8)

NOM

setquota - définir les quotas disque

SYNTAXE

setquota [ -rm ] [ -u | -g | -P ] [ -F format_quota ] nom limite-douce-blocs limite-stricte-blocs limite-douce-inodes limite-stricte-inodes -a | système_de_fichiers...

setquota [ -rm ] [ -u | -g | -P ] [ -F format_quota ] [ -p nom_prototype ] nom -a | système_de_fichiers...

setquota -b [ -rm ] [ -u | -g | -P ] [ -F format_quota ] -a | système_de_fichiers...

setquota -t [ -u | -g | -P ] [ -F format_quota ] délai-blocs délai-inodes -a | système_de_fichiers...

setquota -T [ -u | -g | -P ] [ -F format_quota ] nom délai-blocs délai-inodes -a | système_de_fichiers...

DESCRIPTION

setquota est un éditeur de quotas en ligne de commande. Le système de fichiers, le nom d'utilisateur/groupe/projet et les nouveaux quotas pour ce système de fichiers peuvent être spécifiés sur la ligne de commande. Notez que si un nombre est donné à la place d'un nom d'utilisateur/groupe/projet, il est traité comme un UID/GID/ID de projet.

-r, --remote
Modifier également les quotas distants en utilisant rpc.rquotad sur le serveur distant pour définir le quota. Cette option n'est disponible que si les outils de quota ont été compilés avec le support de la définition des quotas via RPC activé.
-m, --no-mixed-pathnames
Actuellement, les noms de chemins des points de montage NFSv4 sont envoyés sans la barre oblique initiale dans le chemin. rpc.rquotad utilise cela pour reconnaître les montages NFSv4 et ajouter correctement le pseudo-racine du système de fichiers NFS au chemin. Si vous spécifiez cette option, setquota enverra toujours les chemins avec une barre oblique initiale. Cela peut être utile pour des raisons de compatibilité ascendante, mais sachez que le quota sur RPC cessera de fonctionner si vous utilisez un nouveau rpc.rquotad.
-F, --format=format_quota
Effectuer la définition pour le format spécifié (c.-à-d. ne pas effectuer l'autodétection du format). Les noms de formats possibles sont : vfsold Ancien format de quota avec UID / GID 16 bits, vfsv0 Format de quota avec UID / GID 32 bits, utilisation de l'espace 64 bits, limites d'utilisation et d'inodes 32 bits, vfsv1 Format de quota avec limites et utilisations de quota 64 bits, rpc (quota sur NFS), xfs (quota sur système de fichiers XFS)
-u, --user
Définir les quotas utilisateur pour l'utilisateur nommé. C'est le comportement par défaut.
-g, --group
Définir les quotas groupe pour le groupe nommé.
-P, --project
Définir les quotas projet pour le projet nommé.
-p, --prototype=nom_prototype
Utiliser les paramètres de quota de l'utilisateur, du groupe ou du projet nom_prototype pour définir le quota de l'utilisateur, du groupe ou du projet nommé.
--always-resolve
Toujours essayer de traduire le nom d'utilisateur / groupe / projet en uid / gid / ID de projet, même si le nom n'est composé que de chiffres.
-b, --batch
Lire les informations à définir depuis l'entrée standard (format d'entrée : nom limite-douce-blocs limite-stricte-blocs limite-douce-inodes limite-stricte-inodes ). Les lignes vides et les lignes commençant par # sont ignorées.
-c, --continue-batch
Si l'analyse d'une ligne d'entrée en mode batch échoue, continuer avec le traitement de la ligne suivante.
-t, --edit-period
Définir les délais de grâce pour les utilisateurs/groupes/projets. Les temps délai-blocs et délai-inodes sont spécifiés en secondes.
-T, --edit-times
Modifier les temps pour un utilisateur/groupe/projet individuel lorsque la limite douce est appliquée. Les temps délai-blocs et délai-inodes sont spécifiés en secondes ou peuvent être la chaîne 'unset'.
-a, --all
Parcourir tous les systèmes de fichiers avec quota dans /etc/mtab et effectuer la définition.

limite-douce-blocs et limite-stricte-blocs sont interprétés comme des multiples de blocs de kibioctets (1024 octets) par défaut. Les symboles K, M, G et T peuvent être ajoutés à une valeur numérique pour exprimer des kibioctets, mébioctets, gibioctets et tébioctets.

limite-douce-inodes et limite-stricte-inodes sont interprétés littéralement. Les symboles k, m, g et t peuvent être ajoutés à une valeur numérique pour exprimer des multiples de 10^3, 10^6, 10^9 et 10^12 inodes.

Pour désactiver un quota, définir le paramètre correspondant à 0. Pour modifier les quotas pour plusieurs systèmes de fichiers, invoquer une fois pour chaque système de fichiers.

Seul le super-utilisateur peut modifier les quotas.

FICHIERS

aquota.user ou aquota.group
fichier de quota à la racine du système de fichiers (quota version 2, systèmes de fichiers non-XFS)
quota.user ou quota.group
fichier de quota à la racine du système de fichiers (quota version 1, systèmes de fichiers non-XFS)
/etc/mtab
table des systèmes de fichiers montés
