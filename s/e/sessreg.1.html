NOM

sessreg - gérer les entrées utmpx/wtmpx pour les clients non-init

SYNTAXE

sessreg [-w fichier-wtmpx] [-u fichier-utmpx] [-L fichier-lastlog]
    [-l nom-ligne] [-h nom-hote] [-s numero-slot]
    [-x fichier-Xservers] [-t fichier-ttys] [-V] [-a] [-d] nom-utilisateur

DESCRIPTION

Sessreg est un programme simple pour gérer les entrées utmpx/wtmpx et lastlog pour les sessions xdm.

Cette version de sessreg est construite à l'aide des interfaces POSIX modernes pututxline(3c), qui ne nécessitent plus de numéros de slot, ni de mappings de fichiers ttys ou Xservers. Pour des raisons de compatibilité avec les versions plus anciennes et d'autres systèmes d'exploitation, les options -s, -t et -x sont acceptées, mais ignorées.

UTILISATION

Dans Xstartup, placez un appel comme :

       sessreg -a -l $DISPLAY -x /etc/X11/xdm/Xservers $USER

et dans Xreset :

       sessreg -d -l $DISPLAY -x /etc/X11/xdm/Xservers $USER

OPTIONS

-w fichier-wtmpx
Ceci spécifie un fichier wtmpx alternatif, au lieu de /var/log/wtmp. Le nom spécial "none" désactive l'écriture d'enregistrements dans le fichier wtmpx.
-u fichier-utmpx
Ceci spécifie un fichier utmpx alternatif, au lieu de /var/run/utmp. Le nom spécial "none" désactive l'écriture d'enregistrements dans le fichier utmpx.
-L fichier-lastlog
Ceci spécifie un fichier lastlog alternatif, au lieu de /var/log/lastlog, si la plateforme supporte les fichiers lastlog. Le nom spécial "none" désactive l'écriture d'enregistrements dans le fichier lastlog.
-l nom-ligne
Ceci décrit le nom de "ligne" de l'entrée. Pour les sessions terminales, c'est le segment de chemin final du nom de fichier du périphérique terminal (par exemple ttyd0). Pour les sessions X, ce devrait probablement être le nom d'affichage local donné à la session de l'utilisateur (par exemple :0). Si aucun n'est spécifié, le nom du terminal sera déterminé avec ttyname(3) et ses composants de début seront supprimés.
-h nom-hote
Ceci est défini pour indiquer que la session a été initiée depuis un hôte distant. Dans une utilisation xdm typique, cette option n'est pas utilisée.
-s numero-slot
Cette option est acceptée pour la compatibilité, mais ne fait rien dans cette version de sessreg.
-x fichier-Xservers
Cette option est acceptée pour la compatibilité, mais ne fait rien dans cette version de sessreg.
-t fichier-ttys
Cette option est acceptée pour la compatibilité, mais ne fait rien dans cette version de sessreg.
-V, --version
Cette option provoque l'affichage de la version de la commande et sa sortie.
-a
Cette session doit être ajoutée à utmpx/wtmpx.
-d
Cette session doit être supprimée d'utmpx/wtmpx. Une des options -a/-d doit être spécifiée.

VOIR AUSSI

xdm(1), utmpx(5), wtmpx(5)
