NOM

seccomp_export_bpf, seccomp_export_pfc - Exporter le filtre seccomp

SYNOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int seccomp_export_bpf(const scmp_filter_ctx ctx, int fd);
int seccomp_export_pfc(const scmp_filter_ctx ctx, int fd);

Lier avec -lseccomp.

DESCRIPTION

Les fonctions seccomp_export_bpf() et seccomp_export_pfc() génèrent et sortent le filtre seccomp actuel soit en format BPF (Berkeley Packet Filter) soit en format PFC (Pseudo Filter Code). La sortie de seccomp_export_bpf() est adaptée pour être chargée dans le noyau, tandis que la sortie de seccomp_export_pfc() est lisible par l'homme et est principalement destinée à un usage de débogage pour les développeurs utilisant libseccomp. Les deux fonctions écrivent le filtre dans le descripteur de fichier fd.

Le contexte de filtre ctx est la valeur retournée par l'appel à seccomp_init(3).

Bien que les deux formats de sortie soient garantis d'être fonctionnellement équivalents pour la configuration du filtre seccomp donné, les instructions du filtre, et leur ordre, ne sont pas garantis d'être les mêmes dans les deux formats BPF et PFC.

VALEUR DE RETOUR

Retourne zéro en cas de succès ou l'un des codes d'erreur suivants en cas d'échec :

-ECANCELED
Il y a eu un échec système échappant au contrôle de la bibliothèque.
-EFAULT
Échec interne de libseccomp.
-EINVAL
Entrée invalide, le contexte ou le jeton d'architecture est invalide.
-ENOMEM
La bibliothèque n'a pas pu allouer suffisamment de mémoire.

Si l'attribut de filtre SCMP_FLTATR_API_SYSRAWRC est non nul, des codes d'erreur supplémentaires peuvent être retournés à l'appelant ; ces codes d'erreur supplémentaires sont les valeurs négatives de errno retournées par le système. Malheureusement, libseccomp ne peut faire aucune garantie concernant ces valeurs de retour.

EXEMPLES

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	int filter_fd;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	filter_fd = open("/tmp/seccomp_filter.bpf", O_WRONLY);
	if (filter_fd == -1) {
		rc = -errno;
		goto out;
	}
	rc = seccomp_export_bpf(ctx, filter_fd);
	if (rc < 0) {
		close(filter_fd);
		goto out;
	}
	close(filter_fd);
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTES

Bien que le filtre seccomp puisse être généré indépendamment du noyau, le support du noyau est requis pour charger et appliquer le filtre seccomp généré par libseccomp.

Le site du projet libseccomp, avec plus d'informations et le dépôt de code source, se trouve à l'adresse https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, sont actuellement en développement, veuillez signaler tout bug sur le site du projet ou directement à l'auteur.
