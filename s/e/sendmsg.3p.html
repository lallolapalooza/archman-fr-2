SENDMSG(3P) Manuel du programmeur POSIX SENDMSG(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

sendmsg — envoie un message sur un socket en utilisant une structure de message

SYNOPSIS

#include <sys/socket.h>
ssize_t sendmsg(int socket, const struct msghdr *message, int flags);

DESCRIPTION

La fonction sendmsg() envoie un message via un socket en mode connexion ou en mode sans connexion. Si le socket est en mode sans connexion, le message est envoyé à l'adresse spécifiée par msghdr si aucune adresse de pair pré-spécifiée n'a été définie. Si une adresse de pair a été pré-spécifiée, soit le message est envoyé à l'adresse spécifiée dans msghdr (en remplaçant l'adresse de pair pré-spécifiée), soit la fonction retourne -1 et définit errno à [EISCONN]. Si le socket est en mode connexion, l'adresse de destination dans msghdr est ignorée.

La fonction sendmsg() prend les arguments suivants :

socket
Spécifie le descripteur de fichier du socket.
message
Pointe vers une structure msghdr, contenant à la fois l'adresse de destination et les buffers pour le message sortant. La longueur et le format de l'adresse dépendent de la famille d'adresses du socket. Le membre msg_flags est ignoré.
flags
Spécifie le type de transmission du message. L'application peut spécifier 0 ou le drapeau suivant :
MSG_EOR
Termine un enregistrement (si supporté par le protocole).
MSG_OOB
Envoie des données hors bande sur les sockets qui supportent les données hors bande. La signification et la sémantique des données hors bande sont spécifiques au protocole.
MSG_NOSIGNAL
Demande de ne pas envoyer le signal SIGPIPE si une tentative d'envoi est effectuée sur un socket orienté flux qui n'est plus connecté. L'erreur [EPIPE] sera toujours retournée.

Les champs msg_iov et msg_iovlen de message spécifient zéro ou plusieurs buffers contenant les données à envoyer. msg_iov pointe vers un tableau de structures iovec ; msg_iovlen doit être défini à la dimension de ce tableau. Dans chaque structure iovec, le champ iov_base spécifie une zone de stockage et le champ iov_len donne sa taille en octets. Certaines de ces tailles peuvent être nulles. Les données de chaque zone de stockage indiquée par msg_iov sont envoyées successivement.

L'achèvement réussi d'un appel à sendmsg() ne garantit pas la livraison du message. Une valeur de retour de -1 indique uniquement des erreurs détectées localement.

Si l'espace n'est pas disponible au socket d'envoi pour contenir le message à transmettre et que le descripteur de fichier du socket n'a pas O_NONBLOCK défini, la fonction sendmsg() bloquera jusqu'à ce que l'espace soit disponible. Si l'espace n'est pas disponible au socket d'envoi pour contenir le message à transmettre et que le descripteur de fichier du socket a O_NONBLOCK défini, la fonction sendmsg() échouera.

Si le protocole du socket supporte la diffusion (broadcast) et que l'adresse spécifiée est une adresse de diffusion pour le protocole du socket, sendmsg() échouera si l'option SO_BROADCAST n'est pas définie pour le socket.

Le socket utilisé peut nécessiter que le processus ait les privilèges appropriés pour utiliser la fonction sendmsg().

VALEUR DE RETOUR

En cas de succès, sendmsg() retourne le nombre d'octets envoyés. Sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction sendmsg() échouera si :

EAGAIN ou EWOULDBLOCK

Le descripteur de fichier du socket est marqué O_NONBLOCK et l'opération demandée bloquerait.
EAFNOSUPPORT

Les adresses de la famille d'adresses spécifiée ne peuvent pas être utilisées avec ce socket.
EBADF
L'argument socket n'est pas un descripteur de fichier valide.
ECONNRESET
Une connexion a été rompue de force par un pair.
EINTR
Un signal a interrompu sendmsg() avant que des données ne soient transmises.
EINVAL
La somme des valeurs de iov_len dépasse un ssize_t.
EMSGSIZE
Le message est trop volumineux pour être envoyé en une seule fois (comme l'exige le socket), ou le membre msg_iovlen de la structure msghdr pointée par message est inférieur ou égal à 0 ou est supérieur à {IOV_MAX}.
ENOTCONN
Le socket est en mode connexion mais n'est pas connecté.
ENOTSOCK
L'argument socket ne fait pas référence à un socket.
EOPNOTSUPP
L'argument socket est associé à un socket qui ne supporte pas une ou plusieurs des valeurs définies dans flags.
EPIPE
Le socket est fermé en écriture, ou le socket est en mode connexion et n'est plus connecté. Dans ce dernier cas, et si le socket est de type SOCK_STREAM ou SOCK_SEQPACKET et que le drapeau MSG_NOSIGNAL n'est pas défini, le signal SIGPIPE est généré vers le thread appelant.

Si la famille d'adresses du socket est AF_UNIX, alors sendmsg() échouera si :

EIO
Une erreur d'E/S s'est produite lors de la lecture ou de l'écriture dans le système de fichiers.
ELOOP
Une boucle existe dans les liens symboliques rencontrés lors de la résolution du chemin dans l'adresse du socket.
ENAMETOOLONG

La longueur d'un composant d'un chemin est supérieure à {NAME_MAX}.
ENOENT
Un composant du chemin ne nomme pas un fichier existant ou le chemin est une chaîne vide.
ENOTDIR
Un composant du chemin d'accès préfixe du nom de fichier dans l'adresse du socket nomme un fichier existant qui n'est ni un répertoire ni un lien symbolique vers un répertoire, ou le nom de fichier dans l'adresse du socket contient au moins un caractère non-<slash> et se termine par un ou plusieurs <slash> finaux et le dernier composant du nom de fichier nomme un fichier existant qui n'est ni un répertoire ni un lien symbolique vers un répertoire.

La fonction sendmsg() peut échouer si :

EACCES
Les permissions de recherche sont refusées pour un composant du chemin d'accès préfixe ; ou l'accès en écriture au socket nommé est refusé.
EDESTADDRREQ

Le socket n'est pas en mode connexion et son adresse de pair n'est pas définie, et aucune adresse de destination n'a été spécifiée.
EHOSTUNREACH

L'hôte de destination ne peut pas être atteint (probablement parce que l'hôte est en panne ou qu'un routeur distant ne peut pas l'atteindre).
EIO
Une erreur d'E/S s'est produite lors de la lecture ou de l'écriture dans le système de fichiers.
EISCONN
Une adresse de destination a été spécifiée et le socket est déjà connecté.
ENETDOWN
L'interface réseau locale utilisée pour atteindre la destination est désactivée.
ENETUNREACH

Aucune route vers le réseau n'est présente.
ENOBUFS
Les ressources système disponibles étaient insuffisantes pour effectuer l'opération.
ENOMEM
La mémoire disponible était insuffisante pour satisfaire la demande.

Si la famille d'adresses du socket est AF_UNIX, alors sendmsg() peut échouer si :

ELOOP
Plus de {SYMLOOP_MAX} liens symboliques ont été rencontrés lors de la résolution du nom de chemin dans l'adresse du socket.
ENAMETOOLONG

La longueur d'un nom de chemin dépasse {PATH_MAX}, ou la résolution du nom de chemin d'un lien symbolique a produit un résultat intermédiaire dont la longueur dépasse {PATH_MAX}.
