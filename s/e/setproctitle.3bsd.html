Paquet: libbsd

Licences: custom

setproctitle(3bsd) 3bsd setproctitle(3bsd)

NOM

setproctitle — définir le titre du processus

BIBLIOTHÈQUE

bibliothèque “libbsd”

SYNTAXE

#include <unistd.h> (Voir libbsd(7) pour l'usage des includes.)
void
setproctitle_init(int argc, char *argv[], char *envp[]);

void
setproctitle(const char *fmt, ...);

DESCRIPTION

La routine de bibliothèque setproctitle() définit le titre du processus qui apparaît sur la commande ps(1).

La routine de bibliothèque setproctitle_init() doit seulement être appelée (avant tout appel à setproctitle() et avec les arguments de main()), si le support de constructeur automatique n'a pas été lié par le fichier pkgconf libbsd-ctor.

Le titre est défini à partir du nom de l'exécutable, suivi du résultat d'une expansion de style printf(3) des arguments spécifiés par l'argument fmt. Si l'argument fmt commence par un caractère “-”, le nom de l'exécutable est ignoré.

Si fmt est NULL, le titre du processus est restauré.

EXEMPLES

Pour définir le titre d'un démon afin d'indiquer son activité :

setproctitle("talking to %s", inet_ntoa(addr));

VOIR AUSSI

ps(1), w(1), kvm(3), kvm_getargv(3), printf(3)

NORMES

La fonction setproctitle() est implicitement non standard. D'autres méthodes pour modifier la ligne de commande de ps(1), y compris la copie de la chaîne argv[0], sont également implicitement non portables. Il est préférable d'utiliser une fonction setproctitle() fournie par le système d'exploitation, si elle est présente.

Malheureusement, il est possible qu'il existe d'autres conventions d'appel pour d'autres versions de setproctitle(), bien qu'aucune n'ait été trouvée par l'auteur jusqu'à présent. Ceci est considéré comme la convention prédominante.

On pense que l'implémentation est compatible avec d'autres systèmes, notamment NetBSD et BSD/OS.

HISTORIQUE

La fonction setproctitle() est apparue pour la première fois dans NetBSD 1.0 et FreeBSD 2.2. D'autres systèmes d'exploitation ont des fonctions similaires.

La fonction setproctitle_init() est une extension libbsd non présente sur les BSD ; évitez de l'utiliser dans du code portable.

AUTEURS

Peter Wemm ⟨peter@FreeBSD.org⟩ a volé l'idée au code source de Sendmail 8.7.3 par Eric Allman ⟨eric@sendmail.org⟩.

BOGUES

Ne transmettez jamais une chaîne contenant des données fournies par l'utilisateur comme format sans utiliser ‘%s’. Un attaquant peut insérer des spécificateurs de format dans la chaîne pour altérer votre pile, conduisant à une possible faille de sécurité. Ceci est vrai même si la chaîne a été construite à l'aide d'une fonction comme snprintf(), car la chaîne résultante peut encore contenir des spécificateurs de conversion fournis par l'utilisateur pour une interpolation ultérieure par setproctitle().

Utilisez toujours l'idiome sécurisé approprié :

setproctitle("%s", string);
