SERIALVER(1) Commandes JDK SERIALVER(1)

NOM

serialver - retourne le serialVersionUID pour une ou plusieurs classes sous une forme appropriée pour être copiée dans une classe évolutive

SYNTAXE

serialver [options] [nomdeclasses]

options
Représente les options de ligne de commande pour la commande serialver. Voir Options pour serialver.
nomdeclasses
Les classes pour lesquelles le serialVersionUID doit être retourné.

DESCRIPTION

La commande serialver retourne le serialVersionUID pour une ou plusieurs classes sous une forme appropriée pour être copiée dans une classe évolutive. Lorsqu'elle est appelée sans arguments, la commande serialver affiche une ligne d'utilisation.

OPTIONS POUR SERIALVER

-classpath chemin-fichiers
Définit le chemin de recherche des classes et ressources de l'application. Séparez les classes et les ressources par un deux-points (:).
-Joption
Transmet l'option spécifiée à la machine virtuelle Java, où option est l'une des options décrites sur la page de référence du lanceur d'application Java. Par exemple, -J-Xms48m définit la mémoire de démarrage à 48 Mo.

AVERTISSEMENT

La commande serialver charge et initialise les classes spécifiées afin de déterminer leurs valeurs de serialVersionUID. NE PAS EXECUTER serialver sur des classes non fiables.
