getenv(3) Manuel des fonctions de bibliothèque getenv(3)

NOM

getenv, secure_getenv - obtenir une variable d'environnement

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
char *getenv(const char *name);
char *secure_getenv(const char *name);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

secure_getenv():

    _GNU_SOURCE

DESCRIPTION

La fonction getenv() recherche dans la liste d'environnement la variable d'environnement name, et renvoie un pointeur vers la chaîne de value correspondante.

La fonction secure_getenv() est identique à getenv() sauf qu'elle renvoie NULL dans les cas où une "exécution sécurisée" est requise. L'exécution sécurisée est requise si l'une des conditions suivantes était vraie lorsque le programme exécuté par le processus appelant a été chargé:

•
l'ID utilisateur effectif du processus ne correspondait pas à son ID utilisateur réel ou l'ID de groupe effectif du processus ne correspondait pas à son ID de groupe réel (typiquement, c'est le résultat de l'exécution d'un programme set-user-ID ou set-group-ID) ;
•
le bit de capacité effectif était défini sur le fichier exécutable ; ou
•
le processus a un ensemble de capacités autorisées non vide.

L'exécution sécurisée peut également être requise si elle est déclenchée par certains modules de sécurité Linux.

La fonction secure_getenv() est destinée à être utilisée dans les bibliothèques à usage général pour éviter les vulnérabilités qui pourraient survenir si les programmes set-user-ID ou set-group-ID faisaient accidentellement confiance à l'environnement.

VALEUR DE RETOUR

La fonction getenv() renvoie un pointeur vers la valeur dans l'environnement, ou NULL s'il n'y a pas de correspondance.

NOTES

Les chaînes dans la liste d'environnement sont de la forme name=value.

Tel qu'implémenté généralement, getenv() renvoie un pointeur vers une chaîne dans la liste d'environnement. L'appelant doit veiller à ne pas modifier cette chaîne, car cela modifierait l'environnement du processus.

L'implémentation de getenv() n'est pas requise pour être réentrante. La chaîne pointée par la valeur de retour de getenv() peut être allouée statiquement, et peut être modifiée par un appel ultérieur à getenv(), putenv(3), setenv(3), ou unsetenv(3).

Le mode "exécution sécurisée" de secure_getenv() est contrôlé par le drapeau AT_SECURE contenu dans le vecteur auxiliaire passé du noyau à l'espace utilisateur.

VOIR AUSSI
