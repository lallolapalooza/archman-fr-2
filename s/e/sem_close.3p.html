SEM_CLOSE(3P) Manuel du programmeur POSIX SEM_CLOSE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sem_close — fermer un sémaphore nommé

SYNOPIS

#include <semaphore.h>
int sem_close(sem_t *sem);

DESCRIPTION

La fonction sem_close() indique que le processus appelant a fini d'utiliser le sémaphore nommé indiqué par sem. Les effets de l'appel à sem_close() pour un sémaphore anonyme (créé par sem_init()) sont indéfinis. La fonction sem_close() désalloue (c'est-à-dire rend disponible pour une réutilisation par un appel ultérieur à sem_open() par ce processus) toutes les ressources système allouées par le système pour l'utilisation de ce sémaphore par ce processus. L'effet d'une utilisation ultérieure du sémaphore indiqué par sem par ce processus est indéfini. Si des threads du processus appelant sont actuellement bloqués sur le sémaphore, le comportement est indéfini. Si le sémaphore n'a pas été supprimé par un appel réussi à sem_unlink(), alors sem_close() n'a aucun effet sur l'état du sémaphore. Si la fonction sem_unlink() a été invoquée avec succès pour name après le dernier appel à sem_open() avec O_CREAT pour ce sémaphore, alors lorsque tous les processus qui ont ouvert le sémaphore le ferment, le sémaphore n'est plus accessible.

VALEUR RENVOYÉE

En cas de succès, une valeur de zéro est renvoyée. Sinon, une valeur de -1 est renvoyée et errno est définie pour indiquer l'erreur.

ERREURS

La fonction sem_close() peut échouer si :

EINVAL
L'argument sem n'est pas un descripteur de sémaphore valide.
