SERIALVER(1) Commandes JDK SERIALVER(1)

NOM

serialver - renvoie le serialVersionUID pour une ou plusieurs classes sous une forme appropriée pour la copie dans une classe évolutive

SYNTAXE

serialver [options] [noms_de_classes]

options
Ceci représente les options de ligne de commande pour la commande serialver. Voir Options pour serialver.
noms_de_classes
Les classes pour lesquelles le serialVersionUID doit être renvoyé.

DESCRIPTION

La commande serialver renvoie le serialVersionUID pour une ou plusieurs classes sous une forme appropriée pour la copie dans une classe évolutive. Lorsqu'elle est appelée sans arguments, la commande serialver affiche une ligne d'utilisation.

OPTIONS POUR SERIALVER

-classpath fichiers_chemin
Définit le chemin de recherche pour les classes et ressources de l'application. Séparez les classes et les ressources par un deux-points (:).
-Joption
Passe l' option spécifiée à la Machine Virtuelle Java, où option est l'une des options décrites sur la page de référence du lanceur d'application Java. Par exemple, -J-Xms48m définit la mémoire de démarrage à 48 Mo.

NOTES

La commande serialver charge et initialise les classes spécifiées dans sa machine virtuelle, et par défaut, elle ne définit pas de gestionnaire de sécurité. Si la commande serialver doit être exécutée avec des classes non fiables, un gestionnaire de sécurité peut être défini avec l'option suivante :

-J-Djava.security.manager

Lorsque nécessaire, une politique de sécurité peut être spécifiée avec l'option suivante :

-J-Djava.security.policy=fichier_politique
