SETBUF(3P) Manuel du programmeur POSIX SETBUF(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

setbuf — attribuer la mise en mémoire tampon à un flux

SYNTAXE

#include <stdio.h>
void setbuf(FILE *restrict stream, char *restrict buf);

DESCRIPTION

La fonctionnalité décrite dans cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Sauf qu'elle ne retourne aucune valeur, l'appel de fonction :

setbuf(stream, buf)

doit être équivalent à :

setvbuf(stream, buf, _IOFBF, BUFSIZ)

si buf n'est pas un pointeur nul, ou à :

setvbuf(stream, buf, _IONBF, BUFSIZ)

si buf est un pointeur nul.

VALEUR DE RETOUR

La fonction setbuf() ne retourne aucune valeur.

ERREURS

Bien que l'interface setvbuf() puisse définir errno de manière définie, la valeur de errno après un appel à setbuf() n'est pas spécifiée.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATIVE

Une source courante d'erreur est l'allocation d'espace tampon en tant que variable « automatique » dans un bloc de code, puis l'échec de la fermeture du flux dans le même bloc.

Avec setbuf(), l'allocation d'un tampon de BUFSIZ octets n'implique pas nécessairement que tous les octets de BUFSIZ sont utilisés pour la zone tampon.

Comme errno n'est pas requis pour rester inchangé en cas de succès, afin de détecter et éventuellement de récupérer correctement des erreurs, les applications doivent utiliser setvbuf() au lieu de setbuf().
