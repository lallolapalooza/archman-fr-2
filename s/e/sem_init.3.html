sem_init(3) Manuel des fonctions de bibliothèque sem_init(3)

NOM

sem_init - initialiser un sémaphore non nommé

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <semaphore.h>
int sem_init(sem_t *sem, int pshared, unsigned int value);

DESCRIPTION

sem_init() initialise le sémaphore non nommé à l'adresse pointée par sem. L'argument value spécifie la valeur initiale du sémaphore.

L'argument pshared indique si ce sémaphore doit être partagé entre les threads d'un processus, ou entre des processus.

Si pshared a la valeur 0, le sémaphore est partagé entre les threads d'un processus, et doit être situé à une adresse visible par tous les threads (par exemple, une variable globale ou une variable allouée dynamiquement sur le tas).

Si pshared est non nul, le sémaphore est partagé entre les processus, et doit être situé dans une région de mémoire partagée (voir shm_open(3), mmap(2), et shmget(2)). (Comme un enfant créé par fork(2) hérite des mappages mémoire de son parent, il peut également accéder au sémaphore.) Tout processus pouvant accéder à la région de mémoire partagée peut manipuler le sémaphore en utilisant sem_post(3), sem_wait(3), etc.

L'initialisation d'un sémaphore déjà initialisé entraîne un comportement indéfini.

VALEUR DE RETOUR

sem_init() retourne 0 en cas de succès ; en cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
value dépasse SEM_VALUE_MAX.
ENOSYS
pshared est non nul, mais le système ne prend pas en charge les sémaphores partagés entre processus (voir sem_overview(7)).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sem_init () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

Bizarrement, POSIX.1-2001 ne spécifie pas la valeur qui doit être retournée par un appel réussi à sem_init(). POSIX.1-2008 corrige cela, en spécifiant le retour zéro en cas de succès.

EXEMPLES

Voir shm_open(3) et sem_wait(3).

VOIR AUSSI

sem_destroy(3), sem_post(3), sem_wait(3), sem_overview(7)
