SET_UNICHARSET_PROPE(1)   SET_UNICHARSET_PROPE(1)

NOM

set_unicharset_properties - définit les propriétés relatives aux unichars

SYNTAXE

set_unicharset_properties --U fichier_unicharset_entrée --script_dir /chemin/vers/langdata --O fichier_unicharset_sortie

DESCRIPTION

set_unicharset_properties(1) lit un fichier unicharset, place le résultat dans un objet UNICHARSET, le remplit avec les propriétés des unichars qu'il contient et réécrit le résultat dans un autre fichier unicharset.

OPTIONS

--script_dir /chemin/vers/langdata

(Entrée) Spécifie l'emplacement du répertoire pour les unichars de script universels et les hauteurs x des polices (type: chaîne de caractères défaut:)

--U fichier_unicharset

(Entrée) Spécifie l'emplacement du fichier unicharset à charger en entrée.

--O fichier_unicharset

(Sortie) Spécifie l'emplacement du fichier unicharset à écrire avec les propriétés mises à jour.

HISTORIQUE

set_unicharset_properties(1) a été disponible pour la première fois pour la version 3.03 de tesseract.
