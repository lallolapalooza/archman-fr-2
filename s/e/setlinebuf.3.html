setbuf(3) Manuel des fonctions de bibliothèque setbuf(3)

NOM

setbuf, setbuffer, setlinebuf, setvbuf - opérations de mise en tampon des flux

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
int setvbuf(size_t size;
            FILE *restrict stream, char buf[restrict size],
            int mode, size_t size);
void setbuf(FILE *restrict stream, char *restrict buf);
void setbuffer(size_t size;
            FILE *restrict stream, char buf[restrict size],
            size_t size);
void setlinebuf(FILE *stream);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

setbuffer(), setlinebuf():

    Depuis glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures:
        _BSD_SOURCE

DESCRIPTION

Les trois types de mise en tampon disponibles sont : sans tampon, avec tampon de bloc et avec tampon de ligne. Lorsqu'un flux de sortie n'est pas mis en tampon, les informations apparaissent sur le fichier de destination ou le terminal dès qu'elles sont écrites ; lorsqu'il est mis en tampon par bloc, de nombreux caractères sont mis de côté et écrits sous forme de bloc ; lorsqu'il est mis en tampon par ligne, les caractères sont mis de côté jusqu'à ce qu'un saut de ligne soit émis ou que des entrées soient lues à partir de n'importe quel flux attaché à un périphérique terminal (typiquement stdin). La fonction fflush(3) peut être utilisée pour forcer l'envoi du bloc plus tôt. (Voir fclose(3).)

Normalement, tous les fichiers sont mis en tampon par bloc. Si un flux fait référence à un terminal (comme le fait normalement stdout), il est mis en tampon par ligne. Le flux d'erreurs standard stderr n'est toujours pas mis en tampon par défaut.

La fonction setvbuf() peut être utilisée sur n'importe quel flux ouvert pour changer son tampon. L'argument mode doit être l'une des trois macros suivantes :

_IONBF
sans tampon
_IOLBF
tampon de ligne
_IOFBF
tampon complet

À l'exception des fichiers sans tampon, l'argument buf doit pointer vers un tampon d'au moins size octets ; ce tampon sera utilisé à la place du tampon actuel. Si l'argument buf est NULL, seul le mode est affecté ; un nouveau tampon sera alloué lors de la prochaine opération de lecture ou d'écriture. La fonction setvbuf() ne peut être utilisée qu'après l'ouverture d'un flux et avant que toute autre opération n'ait été effectuée sur celui-ci.

Les trois autres appels sont, en fait, simplement des alias pour des appels à setvbuf(). La fonction setbuf() est exactement équivalente à l'appel


setvbuf(stream, buf, buf ? _IOFBF : _IONBF, BUFSIZ);

La fonction setbuffer() est identique, sauf que la taille du tampon est laissée au choix de l'appelant, plutôt que d'être déterminée par la valeur par défaut de BUFSIZ. La fonction setlinebuf() est exactement équivalente à l'appel :


setvbuf(stream, NULL, _IOLBF, 0);

VALEUR DE RETOUR

La fonction setvbuf() retourne 0 en cas de succès. Elle retourne une valeur non nulle en cas d'échec (mode invalide ou la demande ne peut pas être satisfaite). Elle peut définir errno en cas d'échec.

Les autres fonctions ne retournent pas de valeur.

AVERTISSEMENTS

POSIX note que la valeur de errno n'est pas spécifiée après un appel à setbuf() et ajoute que, comme la valeur de errno n'est pas tenue d'être inchangée après un appel réussi à setbuf(), les applications devraient plutôt utiliser setvbuf() afin de détecter les erreurs.

BOGUES

Vous devez vous assurer que l'espace auquel buf pointe existe toujours au moment où stream est fermé, ce qui se produit également lors de la terminaison du programme. Par exemple, ce qui suit est invalide :

#include <stdio.h>
int
main(void)
{
    char buf[BUFSIZ];
    setbuf(stdout, buf);
    printf("Hello, world!\n");
    return 0;
}
