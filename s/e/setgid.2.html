setgid(2) Manuel des appels système setgid(2)

NOM

setgid - définir l'identité de groupe

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int setgid(gid_t gid);

DESCRIPTION

setgid() définit l'identifiant de groupe effectif du processus appelant. Si le processus appelant est privilégié (plus précisément : possède la capacité CAP_SETGID dans son espace de noms utilisateur), l'identifiant de groupe réel et l'identifiant de groupe effectif sauvegardé sont également définis.

Sous Linux, setgid() est implémenté comme la version POSIX avec la fonctionnalité _POSIX_SAVED_IDS. Cela permet à un programme set-group-ID qui n'est pas set-user-ID-root de se défaire de tous ses privilèges de groupe, d'effectuer des travaux non privilégiés, puis de réactiver l'identifiant de groupe effectif d'origine de manière sécurisée.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
L'identifiant de groupe spécifié par gid n'est pas valide dans cet espace de noms utilisateur.
EPERM
Le processus appelant n'est pas privilégié (ne possède pas la capacité CAP_SETGID dans son espace de noms utilisateur), et gid ne correspond pas à l'identifiant de groupe réel ou à l'identifiant de groupe effectif sauvegardé du processus appelant.

VERSIONS

Différences bibliothèque C/noyau

Au niveau du noyau, les identifiants utilisateur et de groupe sont un attribut par thread. Cependant, POSIX exige que tous les threads d'un processus partagent les mêmes identifiants. L'implémentation de threads NPTL gère les exigences POSIX en fournissant des fonctions d'encapsulation pour les divers appels système qui modifient les identifiants UIDs et GIDs des processus. Ces fonctions d'encapsulation (y compris celle pour setgid()) utilisent une technique basée sur les signaux pour garantir que lorsqu'un thread modifie les identifiants, tous les autres threads du processus modifient également leurs identifiants. Pour plus de détails, voir nptl(7).

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, SVr4.

L'appel système setgid() original de Linux ne prenait en charge que les identifiants de groupe 16 bits. Par la suite, Linux 2.4 a ajouté setgid32() prenant en charge les identifiants 32 bits. La fonction d'encapsulation setgid() de glibc gère de manière transparente les variations entre les versions du noyau.

VOIR AUSSI

getgid(2), setegid(2), setregid(2), capabilities(7), credentials(7), user_namespaces(7)
