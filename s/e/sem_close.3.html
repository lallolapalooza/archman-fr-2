sem_close(3) Manuel des fonctions de bibliothèque sem_close(3)

NOM

sem_close - fermer un sémaphore nommé

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <semaphore.h>
int sem_close(sem_t *sem);

DESCRIPTION

sem_close() ferme le sémaphore nommé référencé par sem, permettant ainsi de libérer les ressources que le système a allouées à ce sémaphore pour le processus appelant.

VALEUR DE RETOUR

En cas de succès, sem_close() retourne 0 ; en cas d'erreur, -1 est retourné, avec errno défini pour indiquer l'erreur.

ERREURS

EINVAL
sem n'est pas un sémaphore valide.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sem_close () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Tous les sémaphores nommés ouverts sont automatiquement fermés lors de la terminaison du processus, ou lors d'un appel à execve(2).

VOIR AUSSI

sem_getvalue(3), sem_open(3), sem_post(3), sem_unlink(3), sem_wait(3), sem_overview(7)
