NOM

seccomp_version - interroger les informations de version de libseccomp

SYNTAXE

#include <seccomp.h>

struct scmp_version {
	unsigned int major;
	unsigned int minor;
	unsigned int micro;
}

const struct scmp_version *seccomp_version(void);

Lier avec -lseccomp.

DESCRIPTION

Les fonctions seccomp_version() et seccomp_reset() renvoient un pointeur vers une structure scmp_version qui contient les informations de version de la bibliothèque libseccomp actuellement chargée. Cette fonction peut être utilisée par les applications qui ont besoin de vérifier qu'elles sont liées à une version spécifique de libseccomp à l'exécution.

L'appelant ne doit pas tenter de libérer la structure scmp_version retournée une fois terminée.

VALEUR DE RETOUR

La fonction seccomp_version() renvoie un pointeur vers une structure scmp_version en cas de succès, NULL en cas d'échec. L'appelant ne doit pas tenter de libérer la structure retournée.

EXEMPLES

#include <seccomp.h>
int main(int argc, char *argv[])
{
	const struct scmp_version *ver;
	ver = seccomp_version();
	if (ver == NULL)
		goto err;
	/* ... */
	return 0;
err:
	return 1;
}

NOTES

Bien que le filtre seccomp puisse être généré indépendamment du noyau, un support du noyau est requis pour charger et appliquer le filtre seccomp généré par libseccomp.

Le site du projet libseccomp, avec plus d'informations et le dépôt du code source, se trouve à l'adresse https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, est actuellement en développement, veuillez signaler tout bogue sur le site du projet ou directement à l'auteur.
