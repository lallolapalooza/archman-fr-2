NOM

sendmail — un metteur en file d'attente de courrier pour smtpd(8)

SYNTAXE

sendmail [-tv] [-F nom] [-f de] à ...

DESCRIPTION

L'utilitaire sendmail est un metteur en file d'attente local pour le démon smtpd(8), compatible avec mailwrapper(8). Le message est lu sur l'entrée standard (stdin) jusqu'à ce que sendmail rencontre une fin de fichier. Le metteur en file d'attente sendmail n'est pas destiné à être utilisé directement pour envoyer du courrier, mais plutôt via une interface utilisateur appelée agent utilisateur de courrier.

À moins que l'option facultative -t ne soit spécifiée, un ou plusieurs destinataires doivent être spécifiés sur la ligne de commande.

Les options sont les suivantes :

-F nom
Définit le nom complet de l'expéditeur.
-f de
Définit l'adresse de l'expéditeur.
-t
Lit les champs To:, Cc:, et Bcc: du message pour les destinataires. Le champ Bcc: sera supprimé avant l'envoi.
-v
Active la sortie détaillée.

Pour maintenir la compatibilité avec l'implémentation de sendmail de Sendmail, Inc., diverses autres options sont acceptées, mais n'ont aucun effet.

STATUT DE SORTIE

L'utilitaire sendmail se termine avec le code  0 en cas de succès, et avec un code  >0 si une erreur se produit.

VOIR AUSSI

smtpctl(8), smtpd(8)
