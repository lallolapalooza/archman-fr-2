NOM

seccomp_load - Charge le filtre seccomp actuel dans le noyau

SYNOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int seccomp_load(scmp_filter_ctx ctx);

Lier avec -lseccomp.

DESCRIPTION

Charge le filtre seccomp fourni par ctx dans le noyau ; si la fonction réussit, le nouveau filtre seccomp sera actif au retour de la fonction.

Comme il est possible d'avoir plusieurs filtres seccomp empilés pour une tâche donnée (définie comme un processus ou un thread), il est important de se rappeler que chacun des filtres chargés pour une tâche donnée est exécuté lorsqu'un appel système est effectué et que la règle la "plus stricte" est celle qui est appliquée. Dans le cas de seccomp, "plus stricte" est défini comme l'action ayant la valeur la plus basse (par exemple, SCMP_ACT_KILL est "plus strict" que SCMP_ACT_ALLOW).

VALEUR DE RETOUR

Retourne zéro en cas de succès ou l'un des codes d'erreur suivants en cas d'échec :

-ECANCELED
Il y a eu un échec système au-delà du contrôle de la bibliothèque.
-EFAULT
Échec interne de libseccomp.
-EINVAL
Entrée invalide, le contexte ou le jeton d'architecture est invalide.
-ENOMEM
La bibliothèque n'a pas pu allouer suffisamment de mémoire.
-ESRCH
Impossible de charger le filtre en raison de problèmes de thread.

Si l'attribut de filtre SCMP_FLTATR_API_SYSRAWRC est non nul, des codes d'erreur supplémentaires peuvent être retournés à l'appelant ; ces codes d'erreur supplémentaires sont les valeurs négatives de errno retournées par le système. Malheureusement, libseccomp ne peut faire aucune garantie quant à ces valeurs de retour.

EXEMPLES

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	rc = seccomp_load(ctx);
	if (rc < 0)
		goto out;
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTES

Bien que le filtre seccomp puisse être généré indépendamment du noyau, un support du noyau est requis pour charger et appliquer le filtre seccomp généré par libseccomp.

Le site du projet libseccomp, avec plus d'informations et le dépôt de code source, peut être trouvé à https://github.com/seccomp/libseccomp. Cet outil, ainsi que la bibliothèque libseccomp, est actuellement en cours de développement, veuillez signaler tout bogue sur le site du projet ou directement à l'auteur.
