FBB::Selector(3bobcat) Délais chronométrés, E/S sur fichiers multiples FBB::Selector(3bobcat)

NOM

FBB::Selector - Délais chronométrés, Alarmes et E/S sur fichiers multiples.

SYNOPIS

#include <bobcat/selector>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::Selector sont des wrappers autour des appels système select(2) et permettent des délais chronométrés, des fonctionnalités d'alarme et/ou des E/S sur fichiers multiples. Ils nécessitent l'utilisation de descripteurs de fichiers, qui ne font pas partie officiellement de C++. Cependant, la plupart des systèmes d'exploitation offrent des descripteurs de fichiers. Les sockets sont des descripteurs de fichiers bien connus.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

FONCTIONS MEMBRE

o
void addExceptFd(int fd):
Ajoute un descripteur de fichier à l'ensemble des descripteurs de fichiers surveillés pour les exceptions (notez qu'il ne s'agit pas d'exceptions C++. Voir man 2 select pour plus de détails).
o
void addReadFd(int fd):
Ajoute un descripteur de fichier à l'ensemble des descripteurs de fichiers surveillés pour la lecture.
o
void addWriteFd(int fd):
Ajoute un descripteur de fichier à l'ensemble des descripteurs de fichiers surveillés pour l'écriture.
o
int exceptFd():
Retourne -1 si plus aucun descripteur de fichier n'est disponible dans la catégorie exception. Sinon, le prochain descripteur de fichier disponible dans la catégorie exception est retourné. En retournant de wait, cette fonction peut être appelée à plusieurs reprises jusqu'à ce que -1 soit retourné, traitant chaque descripteur de fichier disponible tour à tour.
o
void noAlarm():
Ce membre empêche toute alarme de délai d'expiration de se déclencher.
o
int nReady():
Retourne le nombre de descripteurs de fichiers disponibles. 0 est retourné en cas de délai d'expiration, -1 est retourné lorsque select(2) a échoué.
o
int readFd():
Retourne -1 si plus aucun descripteur de fichier n'est disponible pour la lecture. Sinon, le prochain descripteur de fichier disponible pour la lecture est retourné. En retournant de wait, cette fonction peut être appelée à plusieurs reprises jusqu'à ce que -1 soit retourné, traitant chaque descripteur de fichier disponible tour à tour. Notez que le fichier dont le descripteur de fichier est retourné par readFd peut également être à sa position de fin de fichier. Le fichier est « prêt pour la lecture », mais aucun caractère ne sera retourné lors de la tentative de lecture en raison de son statut de fin de fichier. Dans ce cas, il est probablement préférable de supprimer le descripteur de fichier de l'ensemble des descripteurs de fichiers actifs.
o
void rmExceptFd(int fd):
Supprime un descripteur de fichier de l'ensemble des descripteurs de fichiers surveillés pour les exceptions (notez qu'il ne s'agit pas d'exceptions C++. Voir man 2 select pour plus de détails).
o
void rmReadFd(int fd):
Supprime un descripteur de fichier de l'ensemble des descripteurs de fichiers surveillés pour la lecture.
o
void rmWriteFd(int fd):
Supprime un descripteur de fichier de l'ensemble des descripteurs de fichiers surveillés pour l'écriture.
o
void setAlarm(int sec, int usec = 0):
Ce membre configure l'alarme aux secondes et microsecondes indiquées. Si aucune action ne s'est produite sur l'un des descripteurs de fichiers surveillés après la durée indiquée, wait retournera avec nReady retournant 0. Le temps d'alarme demandé (sec + usec / 1e+6) ne peut pas être négatif et ne peut pas dépasser std::numeric_limits<int>::max(), sinon une exception FBB::Exception sera levée. Une spécification de temps d'alarme de 0 entraîne le retour immédiat de wait. Pour désactiver le temps d'alarme, utilisez noAlarm.
o
int wait():
Ce membre doit être appelé pour attendre des activités sur les descripteurs de fichiers installés ou la période de délai d'attente. Les membres exceptFd, nReady, readFd et writeFd n'affichent leurs comportements définis qu'après le retour de wait.
Il lève une exception FBB::Exception lorsque select(2) échoue, ce qui pourrait très bien indiquer la fin de toute entrée disponible. Une exception est également levée si le programme a reçu un signal.
Si wait retourne normalement, sa valeur de retour représente le nombre de descripteurs de fichiers disponibles. Notez que wait peut également retourner avec un descripteur de fichier d'entrée retourné par readFd d'un fichier à sa position de fin de fichier. Le fichier est « prêt pour la lecture », mais aucun caractère ne sera retourné lors de la tentative de lecture en raison de son statut de fin de fichier.
o
int writeFd():
Retourne -1 si plus aucun descripteur de fichier n'est disponible pour l'écriture. Sinon, le prochain descripteur de fichier disponible pour l'écriture est retourné. En retournant de wait, cette fonction peut être appelée à plusieurs reprises jusqu'à ce que -1 soit retourné, traitant chaque descripteur de fichier disponible tour à tour.

EXEMPLE

#include <string>
#include <iostream>
#include <bobcat/selector>
#include <bobcat/exception>
using namespace std;
using namespace FBB;
int main(int argc, char **argv, char **envp)
try
{
    Selector selector;
    selector.setAlarm(5);               // toutes les 5 secondes : l'alarme se déclenche
    selector.addReadFd(STDIN_FILENO);   // regarder aussi dans cin
    while (true)
    {
        if (!selector.wait())           // 0 : l'alarme se déclenche
            cout << "Êtes-vous toujours là ?" << endl;
        else
        {
            string s;
            if (!getline(cin, s) || !s.length())
                return 0;
            cout << "Merci pour : " << s << endl;
        }
    }
}
catch (Exception const &e)
{
    cout << e.what() << ’\n’;
    return 1;
}
