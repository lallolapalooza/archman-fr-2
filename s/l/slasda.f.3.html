SLASDA calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle supérieurement bi-diagonale avec les diagonales d et e. Utilisé par sbdsdc.

But :

!>
!> En utilisant une approche de diviser pour régner, SLASDA calcule la décomposition
!> en valeurs singulières (SVD) d'une matrice réelle supérieurement bi-diagonale
!> N-par-M, B, avec diagonale D et hors-diagonale E, où M = N + SQRE.
!> L'algorithme calcule les valeurs singulières dans la SVD B = U * S * VT.
!> Les matrices orthogonales U et VT sont calculées de manière optionnelle
!> sous forme compacte.
!>
!> Une sous-routine associée, SLASD0, calcule les valeurs singulières et
!> les vecteurs singuliers sous forme explicite.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un ENTIER
!>         Spécifie si les vecteurs singuliers doivent être calculés
!>         sous forme compacte, comme suit :
!>         = 0 : Calculer uniquement les valeurs singulières.
!>         = 1 : Calculer les vecteurs singuliers de la matrice
!>              supérieurement bi-diagonale sous forme compacte.
!>

SMLSIZ

!>          SMLSIZ est un ENTIER
!>         La taille maximale des sous-problèmes au bas de l'arbre de
!>         calcul.
!>

N

!>          N est un ENTIER
!>         La dimension de ligne de la matrice supérieurement bi-diagonale. C'est
!>         aussi la dimension du tableau de diagonale principale D.
!>

SQRE

!>          SQRE est un ENTIER
!>         Spécifie la dimension de colonne de la matrice bi-diagonale.
!>         = 0 : La matrice bi-diagonale a une dimension de colonne M = N ;
!>         = 1 : La matrice bi-diagonale a une dimension de colonne M = N + 1.
!>

D

!>          D est un tableau REEL, dimension ( N )
!>         À l'entrée, D contient la diagonale principale de la matrice
!>         bi-diagonale. À la sortie, D, si INFO = 0, contient ses valeurs singulières.
!>

E

!>          E est un tableau REEL, dimension ( M-1 )
!>         Contient les entrées sous-diagonales de la matrice bi-diagonale.
!>         À la sortie, E a été détruit.
!>

U

!>          U est un tableau REEL,
!>         dimension ( LDU, SMLSIZ ) si ICOMPQ = 1, et non référencé
!>         si ICOMPQ = 0. Si ICOMPQ = 1, à la sortie, U contient les matrices
!>         de vecteurs singuliers gauches de tous les sous-problèmes au niveau inférieur.
!>

LDU

!>          LDU est un ENTIER, LDU = > N.
!>         La dimension principale des tableaux U, VT, DIFL, DIFR, POLES,
!>         GIVNUM et Z.
!>

VT

!>          VT est un tableau REEL,
!>         dimension ( LDU, SMLSIZ+1 ) si ICOMPQ = 1, et non référencé
!>         si ICOMPQ = 0. Si ICOMPQ = 1, à la sortie, VT**T contient les matrices
!>         de vecteurs singuliers droits de tous les sous-problèmes au niveau inférieur.
!>

K

!>          K est un tableau ENTIER, dimension ( N )
!>         si ICOMPQ = 1 et dimension 1 si ICOMPQ = 0.
!>         Si ICOMPQ = 1, à la sortie, K(I) est la dimension de la I-ème
!>         équation séculaire sur l'arbre de calcul.
!>

DIFL

!>          DIFL est un tableau REEL, dimension ( LDU, NLVL ),
!>         où NLVL = floor(log_2 (N/SMLSIZ))).
!>

DIFR

!>          DIFR est un tableau REEL,
!>                  dimension ( LDU, 2 * NLVL ) si ICOMPQ = 1 et
!>                  dimension ( N ) si ICOMPQ = 0.
!>         Si ICOMPQ = 1, à la sortie, DIFL(1:N, I) et DIFR(1:N, 2 * I - 1)
!>         enregistrent les distances entre les valeurs singulières au I-ème
!>         niveau et les valeurs singulières au (I -1)-ème niveau, et
!>         DIFR(1:N, 2 * I ) contient les facteurs de normalisation pour
!>         la matrice des vecteurs singuliers droits. Voir SLASD8 pour les détails.
!>

Z

!>          Z est un tableau REEL,
!>                  dimension ( LDU, NLVL ) si ICOMPQ = 1 et
!>                  dimension ( N ) si ICOMPQ = 0.
!>         Les K premiers éléments de Z(1, I) contiennent les composantes
!>         du vecteur ligne de mise à jour ajusté par déflation pour les sous-problèmes
!>         au I-ème niveau.
!>

POLES

!>          POLES est un tableau REEL,
!>         dimension ( LDU, 2 * NLVL ) si ICOMPQ = 1, et non référencé
!>         si ICOMPQ = 0. Si ICOMPQ = 1, à la sortie, POLES(1, 2*I - 1) et
!>         POLES(1, 2*I) contiennent les valeurs singulières nouvelles et anciennes
!>         impliquées dans les équations séculaires au I-ème niveau.
!>

GIVPTR

!>          GIVPTR est un tableau ENTIER,
!>         dimension ( N ) si ICOMPQ = 1, et non référencé si
!>         ICOMPQ = 0. Si ICOMPQ = 1, à la sortie, GIVPTR( I ) enregistre
!>         le nombre de rotations de Givens effectuées sur le I-ème
!>         problème sur l'arbre de calcul.
!>

GIVCOL

!>          GIVCOL est un tableau ENTIER,
!>         dimension ( LDGCOL, 2 * NLVL ) si ICOMPQ = 1, et non
!>         référencé si ICOMPQ = 0. Si ICOMPQ = 1, à la sortie, pour chaque I,
!>         GIVCOL(1, 2 *I - 1) et GIVCOL(1, 2 *I) enregistrent les emplacements
!>         des rotations de Givens effectuées au I-ème niveau sur
!>         l'arbre de calcul.
!>

LDGCOL

!>          LDGCOL est un ENTIER, LDGCOL = > N.
!>         La dimension principale des tableaux GIVCOL et PERM.
!>

PERM

!>          PERM est un tableau ENTIER, dimension ( LDGCOL, NLVL )
!>         si ICOMPQ = 1, et non référencé
!>         si ICOMPQ = 0. Si ICOMPQ = 1, à la sortie, PERM(1, I) enregistre
!>         les permutations effectuées au I-ème niveau de l'arbre de calcul.
!>

GIVNUM

!>          GIVNUM est un tableau REEL,
!>         dimension ( LDU,  2 * NLVL ) si ICOMPQ = 1, et non
!>         référencé si ICOMPQ = 0. Si ICOMPQ = 1, à la sortie, pour chaque I,
!>         GIVNUM(1, 2 *I - 1) et GIVNUM(1, 2 *I) enregistrent les valeurs C et S
!>         des rotations de Givens effectuées au I-ème niveau sur
!>         l'arbre de calcul.
!>

C

!>          C est un tableau REEL,
!>         dimension ( N ) si ICOMPQ = 1, et dimension 1 si ICOMPQ = 0.
!>         Si ICOMPQ = 1 et le I-ème sous-problème n'est pas carré, à la sortie,
!>         C( I ) contient la valeur C d'une rotation de Givens liée
!>         au noyau droit du I-ème sous-problème.
!>

S

!>          S est un tableau REEL, dimension ( N ) si
!>
ICOMPQ = 1, et la dimension 1 si ICOMPQ = 0. Si ICOMPQ = 1 !> et que le sous-problème I-ème n'est pas carré, à la sortie, S( I ) !> contient la valeur S d'une rotation de Givens liée à !> l'espace nul droit du sous-problème I-ème. !>

WORK

!>          WORK est un tableau RÉEL, de dimension
!>         (6 * N + (SMLSIZ + 1)*(SMLSIZ + 1)).
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (7*N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé.
!>
