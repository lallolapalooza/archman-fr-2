NOM

Slurm - Présentation du gestionnaire de charge de travail Slurm.

DESCRIPTION

Le gestionnaire de charge de travail Slurm est un système de gestion de cluster et de planification de travaux open source, tolérant aux pannes et hautement évolutif, pour les clusters Linux petits et grands. Slurm ne nécessite aucune modification du noyau pour fonctionner et est relativement autonome. En tant que gestionnaire de ressources de cluster, Slurm a trois fonctions clés. Premièrement, il alloue l'accès exclusif et/ou non exclusif aux ressources (nœuds de calcul) aux utilisateurs pendant une certaine durée afin qu'ils puissent effectuer des travaux. Deuxièmement, il fournit un cadre pour démarrer, exécuter et surveiller des travaux (normalement un travail parallèle) sur l'ensemble des nœuds alloués. Enfin, il arbitre la concurrence pour les ressources en gérant une file d'attente des travaux en attente. Des plugins optionnels peuvent être utilisés pour la comptabilité, la réservation avancée, la planification gang (partage de temps pour les travaux parallèles), la planification de backfill, les limites de ressources par utilisateur ou compte, et les algorithmes sophistiqués de priorisation des travaux multi-facteurs.

Slurm dispose d'un gestionnaire centralisé, slurmctld, pour surveiller les ressources et les travaux. Il peut également y avoir un gestionnaire de secours pour assumer ces responsabilités en cas de défaillance. Chaque serveur de calcul (nœud) dispose d'un démon slurmd, qui peut être comparé à une coque distante : il attend les travaux, exécute ces travaux, renvoie l'état et attend d'autres travaux. Un slurmdbd (Slurm DataBase Daemon) optionnel peut être utilisé à des fins de comptabilité et pour maintenir les informations sur les limites de ressources.

Les outils utilisateur de base incluent srun pour initier des travaux, scancel pour terminer les travaux en file d'attente ou en cours d'exécution, sinfo pour signaler l'état du système, et squeue pour signaler l'état des travaux. Il existe également un outil administratif scontrol disponible pour surveiller et/ou modifier la configuration et les informations d'état. Des API sont disponibles pour toutes les fonctions.

La configuration de Slurm est maintenue dans le fichier slurm.conf.

Des pages de manuel sont disponibles pour toutes les commandes Slurm, les démons, les API, ainsi que le fichier slurm.conf. Une documentation complète est également disponible sur Internet à l'adresse https://slurm.schedmd.com/.
