sous-programme slasy2 (logical ltranl, logical ltranr, integer isgn, integer n1, integer n2, real, dimension( ldtl, * ) tl, integer ldtl, real, dimension( ldtr, * ) tr, integer ldtr, real, dimension( ldb, * ) b, integer ldb, real scale, real, dimension( ldx, * ) x, integer ldx, real xnorm, integer info)

SLASY2 résout l'équation matricielle de Sylvester où les matrices sont d'ordre 1 ou 2.

Objectif :

!>
!> SLASY2 résout pour la matrice X de taille N1 par N2, 1 <= N1,N2 <= 2, dans
!>
!>        op(TL)*X + ISGN*X*op(TR) = SCALE*B,
!>
!> où TL est de taille N1 par N1, TR est de taille N2 par N2, B est de taille N1 par N2, et ISGN = 1 ou
!> -1.  op(T) = T ou T**T, où T**T désigne la transposée de T.
!>

Paramètres

LTRANL 
!>          LTRANL est LOGICAL
!>          En entrée, LTRANL spécifie op(TL):
!>             = .FALSE., op(TL) = TL,
!>             = .TRUE., op(TL) = TL**T.
!>

LTRANR

!>          LTRANR est LOGICAL
!>          En entrée, LTRANR spécifie op(TR):
!>            = .FALSE., op(TR) = TR,
!>            = .TRUE., op(TR) = TR**T.
!>

ISGN

!>          ISGN est INTEGER
!>          En entrée, ISGN spécifie le signe de l'équation
!>          tel que décrit précédemment. ISGN ne peut être que 1 ou -1.
!>

N1

!>          N1 est INTEGER
!>          En entrée, N1 spécifie l'ordre de la matrice TL.
!>          N1 ne peut être que 0, 1 ou 2.
!>

N2

!>          N2 est INTEGER
!>          En entrée, N2 spécifie l'ordre de la matrice TR.
!>          N2 ne peut être que 0, 1 ou 2.
!>

TL

!>          TL est un tableau REAL, de dimension (LDTL,2)
!>          En entrée, TL contient une matrice de taille N1 par N1.
!>

LDTL

!>          LDTL est INTEGER
!>          La dimension principale de la matrice TL. LDTL >= max(1,N1).
!>

TR

!>          TR est un tableau REAL, de dimension (LDTR,2)
!>          En entrée, TR contient une matrice de taille N2 par N2.
!>

LDTR

!>          LDTR est INTEGER
!>          La dimension principale de la matrice TR. LDTR >= max(1,N2).
!>

B

!>          B est un tableau REAL, de dimension (LDB,2)
!>          En entrée, la matrice B de taille N1 par N2 contient le membre de droite
!>          de l'équation.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de la matrice B. LDB >= max(1,N1).
!>

SCALE

!>          SCALE est REAL
!>          En sortie, SCALE contient le facteur d'échelle. SCALE est choisi
!>          inférieur ou égal à 1 pour éviter le débordement de la solution.
!>

X

!>          X est un tableau REAL, de dimension (LDX,2)
!>          En sortie, X contient la solution de taille N1 par N2.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale de la matrice X. LDX >= max(1,N1).
!>

XNORM

!>          XNORM est REAL
!>          En sortie, XNORM est la norme infinie de la solution.
!>

INFO

!>          INFO est INTEGER
!>          En sortie, INFO est défini comme suit :
!>             0: sortie réussie.
!>             1: TL et TR ont des valeurs propres trop proches, donc TL ou
!>                TR est perturbée pour obtenir une équation non singulière.
!>          NOTE : Dans un souci de rapidité, cette routine ne
!>                vérifie pas les entrées pour les erreurs.
!>
