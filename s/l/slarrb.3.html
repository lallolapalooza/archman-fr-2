Documentation de fonction/sous-programme

sous-programme slarrb (entier n, reel, dimension( * ) d, reel, dimension( * ) lld, entier ifirst, entier ilast, reel rtol1, reel rtol2, entier offset, reel, dimension( * ) w, reel, dimension( * ) wgap, reel, dimension( * ) werr, reel, dimension( * ) work, entier, dimension( * ) iwork, reel pivmin, reel spdiam, entier twist, entier info)

SLARRB effectue une dichotomie limitée pour localiser les valeurs propres avec plus de précision.

Objectif :

!>
!> Étant donné la représentation relativement robuste (RRR) L D L^T, SLARRB
!> effectue une dichotomie pour affiner les valeurs propres de L D L^T,
!> W( IFIRST-OFFSET ) à W( ILAST-OFFSET ), avec plus de précision. Les estimations initiales
!> de ces valeurs propres sont fournies en entrée dans W, les estimations correspondantes
!> de l'erreur dans ces estimations et leurs écarts sont fournies en entrée dans WERR
!> et WGAP, respectivement. Pendant la dichotomie, les intervalles
!> [gauche, droite] sont maintenus en stockant leurs milieux et
!> leurs demi-largeurs dans les tableaux W et WERR respectivement.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

LLD

!>          LLD est un tableau REEL, dimension (N-1)
!>          Les (N-1) éléments L(i)*L(i)*D(i).
!>

IFIRST

!>          IFIRST est un ENTIER
!>          L'indice de la première valeur propre à calculer.
!>

ILAST

!>          ILAST est un ENTIER
!>          L'indice de la dernière valeur propre à calculer.
!>

RTOL1

!>          RTOL1 est un REEL
!>

RTOL2

!>          RTOL2 est un REEL
!>          Tolérance pour la convergence des intervalles de dichotomie.
!>          Un intervalle [GAUCHE,DROITE] a convergé si
!>          DROITE-GAUCHE < MAX( RTOL1*ECART, RTOL2*MAX(|GAUCHE|,|DROITE|) )
!>          où ECART est la distance (estimée) à la valeur propre
!>          la plus proche.
!>

OFFSET

!>          OFFSET est un ENTIER
!>          Décalage pour les tableaux W, WGAP et WERR, c'est-à-dire que les éléments IFIRST-OFFSET
!>          à ILAST-OFFSET de ces tableaux sont utilisés.
!>

W

!>          W est un tableau REEL, dimension (N)
!>          En entrée, W( IFIRST-OFFSET ) à W( ILAST-OFFSET ) sont
!>          des estimations des valeurs propres de L D L^T indexées IFIRST à
!>          ILAST.
!>          En sortie, ces estimations sont affinées.
!>

WGAP

!>          WGAP est un tableau REEL, dimension (N-1)
!>          En entrée, les écarts (estimés) entre les valeurs propres consécutives
!>          de L D L^T, c'est-à-dire WGAP(I-OFFSET) est l'écart entre
!>          les valeurs propres I et I+1. Notez que si IFIRST = ILAST
!>          alors WGAP(IFIRST-OFFSET) doit être mis à ZÉRO.
!>          En sortie, ces écarts sont affinés.
!>

WERR

!>          WERR est un tableau REEL, dimension (N)
!>          En entrée, WERR( IFIRST-OFFSET ) à WERR( ILAST-OFFSET ) sont
!>          les erreurs dans les estimations des éléments correspondants de W.
!>          En sortie, ces erreurs sont affinées.
!>

WORK

!>          WORK est un tableau REEL, dimension (2*N)
!>          Espace de travail.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (2*N)
!>          Espace de travail.
!>

PIVMIN

!>          PIVMIN est un REEL
!>          Le pivot minimum dans la séquence de Sturm.
!>

SPDIAM

!>          SPDIAM est un REEL
!>          Le diamètre spectral de la matrice.
!>

TWIST

!>          TWIST est un ENTIER
!>          L'indice de torsion pour la factorisation tordue utilisée
!>          pour le comptage négatif.
!>          TWIST = N : Calcule le comptage négatif à partir de L D L^T - LAMBDA I = L+ D+ L+^T
!>          TWIST = 1 : Calcule le comptage négatif à partir de L D L^T - LAMBDA I = U- D- U-^T
!>          TWIST = R : Calcule le comptage négatif à partir de L D L^T - LAMBDA I = N(r) D(r) N(r)
!>

INFO

!>          INFO est un ENTIER
!>          Indicateur d'erreur.
!>
