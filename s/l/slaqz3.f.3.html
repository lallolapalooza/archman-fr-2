Purpose:

!>
!> SLAQZ3 effectue AED
!>

Paramètres

ILSCHUR 
!>          ILSCHUR est LOGIQUE
!>              Détermine si la forme de Schur complète doit être mise à jour ou non
!>

ILQ

!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, Q et Z.  N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>          ILO et IHI marquent les lignes et colonnes de (A,B) qui
!>          doivent être normalisées
!>

NW

!>          NW est ENTIER
!>          La taille souhaitée de la fenêtre de déflation.
!>

A

!>          A est un tableau REEL, dimension (LDA, N)
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max( 1, N ).
!>

B

!>          B est un tableau REEL, dimension (LDB, N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau REEL, dimension (LDQ, N)
!>

LDQ

!>          LDQ est ENTIER
!>

Z

!>          Z est un tableau REEL, dimension (LDZ, N)
!>

LDZ

!>          LDZ est ENTIER
!>

NS

!>          NS est ENTIER
!>          Le nombre de valeurs propres non convergées disponibles pour
!>          être utilisées comme décalages.
!>

ND

!>          ND est ENTIER
!>          Le nombre de valeurs propres convergées trouvées.
!>

ALPHAR

!>          ALPHAR est un tableau REEL, dimension (N)
!>          Les parties réelles de chaque scalaire alpha définissant une valeur propre
!>          de GNEP.
!>

ALPHAI

!>          ALPHAI est un tableau REEL, dimension (N)
!>          Les parties imaginaires de chaque scalaire alpha définissant une
!>          valeur propre de GNEP.
!>          Si ALPHAI(j) est zéro, alors la j-ème valeur propre est réelle ; si
!>          positive, alors la j-ème et la (j+1)-ème valeurs propres sont une
!>          paire conjuguée complexe, avec ALPHAI(j+1) = -ALPHAI(j).
!>

BETA

!>          BETA est un tableau REEL, dimension (N)
!>          Les scalaires bêta qui définissent les valeurs propres de GNEP.
!>          Ensemble, les quantités alpha = (ALPHAR(j),ALPHAI(j)) et
!>          beta = BETA(j) représentent la j-ème valeur propre de la paire
!>          de matrices (A,B), sous l'une des formes lambda = alpha/beta ou
!>          mu = beta/alpha. Puisque lambda ou mu peut déborder,
!>          ils ne devraient, en général, pas être calculés.
!>

QC

!>          QC est un tableau REEL, dimension (LDQC, NW)
!>

LDQC

!>          LDQC est ENTIER
!>

ZC

!>          ZC est un tableau REEL, dimension (LDZC, NW)
!>

LDZC

!>          LDZ est ENTIER
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO >= 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur relatif à LWORK n'est émis par XERBLA.
!>

REC

!>          REC est ENTIER
!>             REC indique le niveau de récursion actuel. Devrait être mis
!>             à 0 lors du premier appel.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>

slaqz3.f(3)

Nom

slaqz3

Description

slaqz3 est une fonction FORTRAN qui calcule les valeurs propres et les vecteurs propres de la matrice généralisée A-λB.

Syntaxe

CALL slaqz3( A, LDA, B, LDB, ALPHA, BETA, Q, LDQ, Z, LDZ, WORK, INFO )

Paramètres

A
Matrice carrée de taille LDAxN.
LDA
Ordre de la première dimension de A.
B
Matrice carrée de taille LDBxN.
LDB
Ordre de la première dimension de B.
ALPHA
Vecteur de taille N contenant les numérateurs des valeurs propres.
BETA
Vecteur de taille N contenant les dénominateurs des valeurs propres.
Q
Matrice unitaire de taille LDQxN contenant les vecteurs propres à gauche.
LDQ
Ordre de la première dimension de Q.
Z
Matrice unitaire de taille LDZxN contenant les vecteurs propres à droite.
LDZ
Ordre de la première dimension de Z.
WORK
Vecteur de travail de taille LWORK.
LWORK
Taille du vecteur de travail.
INFO
Entier indiquant le statut de sortie.

Voir la documentation de LAPACK pour des exemples d'utilisation.
