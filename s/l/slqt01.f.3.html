sous-programme slqt01 (entier m, entier n, réel, dimension( lda, * ) a, réel, dimension( lda, * ) af, réel, dimension( lda, * ) q, réel, dimension( lda, * ) l, entier lda, réel, dimension( * ) tau, réel, dimension( lwork ) work, entier lwork, réel, dimension( * ) rwork, réel, dimension( * ) result)

SLQT01

But :

!>
!> SLQT01 teste SGELQF, qui calcule la factorisation LQ d'une matrice m-par-n
!> A, et teste partiellement SORGLQ qui forme la matrice orthogonale n-par-n
!> Q.
!>
!> SLQT01 compare L avec A*Q', et vérifie que Q est orthogonale.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau RÉEL, dimension (LDA,N)
!>          La matrice m-par-n A.
!>

AF

!>          AF est un tableau RÉEL, dimension (LDA,N)
!>          Détails de la factorisation LQ de A, tels que retournés par SGELQF.
!>          Voir SGELQF pour plus de détails.
!>

Q

!>          Q est un tableau RÉEL, dimension (LDA,N)
!>          La matrice orthogonale n-par-n Q.
!>

L

!>          L est un tableau RÉEL, dimension (LDA,max(M,N))
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et L.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU est un tableau RÉEL, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGELQF.
!>

WORK

!>          WORK est un tableau RÉEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau RÉEL, dimension (max(M,N))
!>

RESULT

!>          RESULT est un tableau RÉEL, dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
