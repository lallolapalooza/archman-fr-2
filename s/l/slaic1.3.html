Documentation de la fonction/sous-programme

sous-programme slaic1 (integer job, integer j, real, dimension( j ) x, real sest, real, dimension( j ) w, real gamma, real sestpr, real s, real c)

SLAIC1 applique une étape d'estimation incrémentielle de la condition.

Objectif :

!>
!> SLAIC1 applique une étape d'estimation incrémentielle de la condition
!> dans sa version la plus simple :
!>
!> Soit x, twonorm(x) = 1, un vecteur singulier approximatif d'une matrice
!> triangulaire inférieure j-par-j L, tel que
!>          twonorm(L*x) = sest
!> Alors SLAIC1 calcule sestpr, s, c tels que
!> le vecteur
!>                 [ s*x ]
!>          xhat = [  c  ]
!> est un vecteur singulier approximatif de
!>                 [ L      0  ]
!>          Lhat = [ w**T gamma ]
!> au sens où
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> Selon JOB, une estimation de la plus grande ou de la plus petite valeur
!> singulière est calculée.
!>
!> Notez que [s c]**T et sestpr**2 est une paire propre du système
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ alpha ]
!>                                           [ gamma ]
!>
!> où  alpha =  x**T*w.
!>

Paramètres

JOB 
!>          JOB est un entier
!>          = 1 : une estimation de la plus grande valeur singulière est calculée.
!>          = 2 : une estimation de la plus petite valeur singulière est calculée.
!>

J

!>          J est un entier
!>          Longueur de X et W
!>

X

!>          X est un tableau réel, de dimension (J)
!>          Le vecteur j x.
!>

SEST

!>          SEST est réel
!>          Valeur singulière estimée de la matrice L de taille j par j
!>

W

!>          W est un tableau réel, de dimension (J)
!>          Le vecteur j w.
!>

GAMMA

!>          GAMMA est réel
!>          L'élément diagonal gamma.
!>

SESTPR

!>          SESTPR est réel
!>          Valeur singulière estimée de la matrice Lhat de taille (j+1) par (j+1).
!>

S

!>          S est réel
!>          Sinus nécessaire pour former xhat.
!>

C

!>          C est réel
!>          Cosinus nécessaire pour former xhat.
!>
