sous-routine slarfy (character uplo, integer n, real, dimension( * ) v, integer incv, real tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work)

SLARFY

But:

!>
!> SLARFY applique un réflecteur élémentaire, ou matrice de Householder, H,
!> à une matrice symétrique n x n, C, à gauche et à droite.
!>
!> H est représentée sous la forme
!>
!>    H = I - tau * v * v'
!>
!> où tau est un scalaire et v est un vecteur.
!>
!> Si tau est zéro, alors H est prise comme étant la matrice identité.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de
!>          la matrice symétrique C est stockée.
!>          = 'U':  Triangle supérieur
!>          = 'L':  Triangle inférieur
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice C. N >= 0.
!>

V

!>          V est un tableau REAL, dimension
!>                  (1 + (N-1)*abs(INCV))
!>          Le vecteur v tel que décrit ci-dessus.
!>

INCV

!>          INCV est INTEGER
!>          L'incrément entre les éléments successifs de v. INCV ne doit
!>          pas être zéro.
!>

TAU

!>          TAU est REAL
!>          La valeur tau telle que décrite ci-dessus.
!>

C

!>          C est un tableau REAL, dimension (LDC, N)
!>          En entrée, la matrice C.
!>          En sortie, C est écrasé par H * C * H'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max( 1, N ).
!>

WORK

!>          WORK est un tableau REAL, dimension (N)
!>
