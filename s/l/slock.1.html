NOM

slock — verrouilleur d'écran X simple

SYNTAXE

slock [-v] [cmd [arg ...]]

DESCRIPTION

slock est un verrouilleur d'écran X simple. Si fourni, cmd est exécuté après que l'écran a été verrouillé.

Les options sont les suivantes :

-v
Affiche les informations de version sur la sortie standard et quitte.

STATUT DE SORTIE

L'utilitaire slock se termine avec le code 0 en cas de succès et un code supérieur à 0 si une erreur se produit.

EXEMPLES

$ slock /usr/sbin/s2ram

CONSIDÉRATIONS DE SÉCURITÉ

Pour s'assurer qu'un écran verrouillé ne peut pas être contourné en changeant de VT ou en tuant le serveur X avec Ctrl+Alt+Backspace, il est recommandé de désactiver les deux dans xorg.conf(5) pour une sécurité maximale :

Section "ServerFlags"
	Option "DontVTSwitch" "True"
	Option "DontZap"      "True"
EndSection

PERSONNALISATION

slock peut être personnalisé en créant un config.h personnalisé à partir de config.def.h et en (re)compilant le code source. Cela le maintient rapide, sécurisé et simple.
