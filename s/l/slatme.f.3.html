Documentation de la fonction/sous-programme

sous-programme slatme (entier n, caractère dist, entier, dimension( 4 ) iseed, réel, dimension( * ) d, entier mode, réel cond, réel dmax, caractère, dimension( * ) ei, caractère rsign, caractère upper, caractère sim, réel, dimension( * ) ds, entier modes, réel conds, entier kl, entier ku, réel anorm, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) work, entier info)

SLATME

Objectif :

!>
!>    SLATME génère des matrices carrées aléatoires non symétriques avec
!>    des valeurs propres spécifiées pour tester les programmes LAPACK.
!>
!>    SLATME fonctionne en appliquant la séquence d'opérations suivante :
!>
!>    1. La diagonale est définie à D, où D peut être entrée ou
!>         calculée selon MODE, COND, DMAX et RSIGN tels que décrits ci-dessous.
!>
!>    2. Si des paires de conjugués complexes sont souhaitées (MODE=0 et EI(1)='R',
!>         ou MODE=5), certaines paires d'éléments adjacents de D sont
!>         interprétées comme les parties réelle et imaginaire d'une paire
!>         conjuguée complexe ; A devient alors bloc-diagonale, avec des blocs 1x1
!>         et 2x2.
!>
!>    3. Si UPPER='T', le triangle supérieur de A est rempli de valeurs aléatoires
!>         issues de la distribution DIST.
!>
!>    4. Si SIM='T', A est multipliée à gauche par une matrice aléatoire
!>         X, dont les valeurs singulières sont spécifiées par DS, MODES, et
!>         CONDS, et à droite par X inverse.
!>
!>    5. Si KL < N-1, la bande inférieure est réduite à KL à l'aide de
!>         transformations de Householder. Si KU < N-1, la bande supérieure
!>         est réduite à KU.
!>
!>    6. Si ANORM est non négatif, la matrice est mise à l'échelle pour avoir
!>         une norme d'élément maximum ANORM.
!>
!>    (Note : comme la matrice ne peut pas être réduite au-delà de la forme de Hessenberg,
!>     aucune option de "packing" n'est disponible.)
!>

Paramètres

N 
!>          N est un ENTIER
!>           Le nombre de colonnes (ou de lignes) de A. Non modifié.
!>

DIST

!>          DIST est de type CARACTÈRE*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires, et pour
!>           le triangle supérieur (voir UPPER).
!>           'U' => UNIFORME( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMALE( 0, 1 )   ( 'N' pour normale )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres aléatoires.
!>           Les valeurs doivent être comprises entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une séquence congruente linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires indépendants
!>           de la machine. Les valeurs de ISEED sont modifiées à la sortie,
!>           et peuvent être utilisées lors du prochain appel à SLATME
!>           pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau de type RÉEL, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de A. Si
!>           MODE=0, alors D est supposé contenir les valeurs propres (mais
!>           voir la description de EI), sinon elles seront
!>           calculées selon MODE, COND, DMAX et RSIGN et
!>           placées dans D.
!>           Modifié si MODE est non nul.
!>

MODE

!>          MODE est un ENTIER
!>           À l'entrée, ceci décrit comment les valeurs propres doivent
!>           être spécifiées :
!>           MODE = 0 signifie utiliser D (avec EI) en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    sont uniformément distribués. Chaque paire impaire-paire
!>                    sera soit utilisée comme deux valeurs propres réelles,
!>                    soit comme la partie réelle et imaginaire d'une paire
!>                    conjuguée complexe ; le choix est aléatoire, avec
!>                    une probabilité de 50-50 pour chaque paire.
!>           MODE = 6 définit D à des nombres aléatoires issus de la même
!>                    distribution que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est compris entre 1 et 4, D a des entrées allant
!>              de 1 à 1/COND, si entre -1 et -4, D a des entrées
!>              allant de 1/COND à 1.
!>           Non modifié.
!>

COND

!>          COND est un type RÉEL
!>           À l'entrée, il est utilisé comme décrit dans MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est un type RÉEL
!>           Si MODE n'est ni -6, ni 0, ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))). Notez que DMAX n'a pas besoin
!>           d'être positif : si DMAX est négatif (ou zéro), D sera
!>           mis à l'échelle par un nombre négatif (ou zéro).
!>           Non modifié.
!>

EI

!>          EI est un tableau de type CARACTÈRE*1, dimension ( N )
!>           Si MODE est 0, et que EI(1) n'est pas ' ' (espace),
!>           ce tableau spécifie quels éléments de D (en entrée) sont
!>           des valeurs propres réelles et quels sont les parties réelle et imaginaire
!>           d'une paire de valeurs propres conjuguées complexes. Les éléments
!>           de EI ne peuvent alors avoir que les valeurs 'R' et 'I'. Si
!>           EI(j)='R' et EI(j+1)='I', alors la j-ème valeur propre est
!>           CMPLX( D(j) , D(j+1) ), et la (j+1)-ème est son conjugué complexe.
!>           Si EI(j)=EI(j+1)='R', alors la j-ème valeur propre est D(j) (c'est-à-dire réelle).
!>           EI(1) ne peut pas être 'I', ni deux éléments adjacents de EI avoir la valeur 'I'.
!>           Si MODE n'est pas 0, alors EI est ignoré. Si MODE est 0 et
!>           EI(1)=' ', alors les valeurs propres seront toutes réelles.
!>           Non modifié.
!>

RSIGN

!>          RSIGN est de type CARACTÈRE*1
!>           Si MODE n'est pas 0, 6, ou -6, et que RSIGN='T', alors les
!>           éléments de D, tels que calculés selon MODE et COND, seront
!>           multipliés par un signe aléatoire (+1 ou -1). Si RSIGN='F',
!>           ils ne le seront pas. RSIGN ne peut avoir que les valeurs 'T' ou
!>           'F'.
!>           Non modifié.
!>

UPPER

!>          UPPER est de type CARACTÈRE*1
!>           Si UPPER='T', alors les éléments de A au-dessus de la diagonale
!>           (et au-dessus des blocs diagonaux 2x2, si A a des valeurs propres
!>           complexes) seront remplis de nombres aléatoires issus de DIST.
!>           Si UPPER='F', ils ne le seront pas. UPPER ne peut avoir que les
!>           valeurs 'T' ou 'F'.
!>           Non modifié.
!>

SIM

!>          SIM est de type CARACTÈRE*1
!>           Si SIM='T', alors A sera opérée, c'est-à-dire multipliée à gauche par une matrice X et
!>           à droite par X inverse. X = U S V, où U et V sont
!>           des matrices unitaires aléatoires et S est une matrice (diagonale) de
!>           valeurs singulières spécifiées par DS, MODES, et CONDS. Si
!>           SIM='F', alors A ne sera pas

Function/Subroutine Documentation

SLATME génère des matrices de test de LAPACK.

Paramètres

DIST

CHARACTER*1. Spécifie la distribution des valeurs des entrées de la matrice de test.

Possibilités:

'N'
Entrées normales aléatoires distribuées.
'S'
Entrées uniformes aléatoires distribuées.
'L'
Entrées exponentielles aléatoires distribuées.
'C'
Entrées complexes aléatoires distribuées (valeur absolue).
'Z'
Entrées aléatoires distribuées comme si elles provenaient de la matrice unitée des nombres aléatoires.
'K'
Matrice de Markov avec un nombre de condition spécifié.
'D'
Matrice diagonale.
'B'
Matrice bidiagonale.
'U'
Matrice unitaire supérieure.
'L'
Matrice unitaire inférieure.
'I'
Matrice d'identité.
'Q'
Matrice orthogonale.
'R'
Matrice aléatoire.
'T'
Matrice triangulaire supérieure.
'L'
Matrice triangulaire inférieure.

Non modifié.

N

INTEGER. La dimension de la matrice.

Non modifié.

MODE

INTEGER. Spécifie la façon dont la matrice de test est construite.

Possibilités:

0
La matrice A est construite de telle sorte que ses valeurs propres (valeurs singulières) soient contenues dans le vecteur D.
-1
La matrice A est construite de telle sorte que ses valeurs propres (valeurs singulières) soient contenues dans le vecteur D, où D est égal à (1, ..., N).
-2
La matrice A est construite de telle sorte que ses valeurs propres (valeurs singulières) soient contenues dans le vecteur D, où D est égal à (1, ..., N), et A est supérieurement Hessenberg.
-3
La matrice A est construite de telle sorte que ses valeurs propres (valeurs singulières) soient contenues dans le vecteur D, où D est égal à (1, ..., N), et A est inférieurement Hessenberg.
-4
La matrice A est construite de telle sorte que ses valeurs propres (valeurs singulières) soient contenues dans le vecteur D, où D est égal à (1, ..., N), et A est symétrique ou hermitienne.
-5
La matrice A est construite de telle sorte que ses valeurs propres (valeurs singulières) soient contenues dans le vecteur D, où D est égal à (1, ..., N), et A est symétrique ou hermitienne, et supérieurement Hessenberg.
-6
La matrice A est construite de telle sorte que ses valeurs propres (valeurs singulières) soient contenues dans le vecteur D, où D est égal à (1, ..., N), et A est symétrique ou hermitienne, et inférieurement Hessenberg.
1
La matrice A est construite pour avoir une forme Hessenberg supérieure.
2
La matrice A est construite pour avoir une forme Hessenberg inférieure.
3
La matrice A est construite pour être symétrique ou hermitienne.
4
La matrice A est construite pour être symétrique ou hermitienne et supérieurement Hessenberg.
5
La matrice A est construite pour être symétrique ou hermitienne et inférieurement Hessenberg.
6
La matrice A est construite pour être une matrice de Markov avec un nombre de condition spécifié par CNDNUM.

Modifié si MODE est non nul.

CNDNUM

REAL. Le nombre de condition de la matrice A. Si MODE=6, A est construit de sorte que son nombre de condition soit CNDNUM.

Non modifié.

RSIGN

REAL. Spécifie le signe des valeurs propres de A (si MODE=0 ou MODE<0). Si RSIGN = 1.0, les valeurs propres sont positives. Si RSIGN = -1.0, les valeurs propres sont négatives.

Non modifié.

UPPER

LOGICAL. Si .TRUE., la matrice A générée est triangulaire supérieure. Si .FALSE., elle est triangulaire inférieure.

Non modifié.

SIM

LOGICAL. Si .TRUE., la matrice A est générée comme la matrice A = U * S * V**H, où U et V sont des matrices unitaires aléatoires et S est une matrice diagonale.

Non modifié.

A

REAL array, dimension ( LDA, N ). Sur sortie, A est la matrice de test souhaitée.

Modifié.

LDA

INTEGER. LDA spécifie la première dimension de A telle que déclarée dans le programme appelant. LDA doit être au moins N.

Non modifié.

D

REAL array, dimension ( N ). Sur sortie, D contient les valeurs propres de A.

Modifié si MODE est non nul.

E

REAL array, dimension ( N-1 ). Sur sortie, E contient les sous-diagonales de A.

Modifié si MODE est non nul.

V

REAL array, dimension ( LDV, N ). Si SIM = .TRUE., V contient la matrice unitaire droite.

Modifié.

LDV

INTEGER. LDV spécifie la première dimension de V telle que déclarée dans le programme appelant.

Non modifié.

TRSVLS

REAL array, dimension ( N ). Si MODE = 0, TRSVLS contient les valeurs singulières souhaitées de X.

Modifié si MODE est non nul.

WORK

REAL array, dimension ( LWORK ). Espace de travail.

Modifié.

LWORK

INTEGER. La longueur de WORK.

Non modifié.

INFO

INTEGER. Code d'erreur. Sur sortie, INFO sera défini à l'une des valeurs suivantes:

0
=> retour normal
-1
=> N est négatif.
-2
=> DIST est une chaîne illégale.
-5
=> MODE n'est pas compris entre -6 et 6.
-6
=> CNDNUM est inférieur à 1.0, et MODE n'est ni -6, 0 ni 6.
-8
=> EI(1) n'est pas ' ' ou 'R', EI(j) n'est pas 'R' ou 'I', ou deux éléments adjacents de EI sont 'I'.
-9
=> RSIGN n'est pas 'T' ou 'F'
-10
=> UPPER n'est pas 'T' ou 'F'
-11
=> SIM n'est pas 'T' ou 'F'
-12
=> MODES=0 et DS a une valeur singulière nulle.
-13
=> MODES n'est pas compris entre -5 et 5.
-14
=> MODES est non nul et CONDS est inférieur à 1.
-15
=> KL est inférieur à 1.
-16
=> KU est inférieur à 1, ou KL et KU sont tous deux inférieurs à N-1.
-19
=> LDA est inférieur à N.
1
=> Retour d'erreur de SLATM1 (calcul de D)
2
=> Impossible de mettre à l'échelle DMAX (la valeur propre maximale est 0)
3
=> Retour d'erreur de SLATM1 (calcul de DS)
4
=> Retour d'erreur de SLARGE
5
=> Valeur singulière nulle de SLATM1.
