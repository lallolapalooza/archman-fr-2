sous-programme slaord (job caractère, entier n, réel, dimension( * ) x, entier incx)

SLAORD

But:

!>
!> SLAORD trie les éléments d'un vecteur x par ordre croissant ou décroissant.
!>

Paramètres

JOB 
!>          JOB est CARACTÈRE
!>          = 'I':  Trier par ordre croissant
!>          = 'D':  Trier par ordre décroissant
!>

N

!>          N est ENTIER
!>          La longueur du vecteur X.
!>

X

!>          X est un tableau RÉEL, dimension
!>                         (1+(N-1)*INCX)
!>          À l'entrée, le vecteur de longueur n à trier.
!>          À la sortie, le vecteur x est trié dans l'ordre prescrit.
!>

INCX

!>          INCX est ENTIER
!>          L'espacement entre les éléments successifs de X.  INCX >= 0.
!>
