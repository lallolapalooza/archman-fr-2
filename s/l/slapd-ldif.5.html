NOM

slapd-ldif - Backend LDIF pour slapd

SYNOPSIS

/etc/openldap/slapd.conf

DESCRIPTION

Le backend LDIF de slapd(8) est un backend de stockage basique qui stocke les entrées dans des fichiers texte au format LDIF, et exploite le système de fichiers pour créer la structure arborescente de la base de données. Il est destiné à être un backend économique, facile à utiliser et peu performant, et il est exploité par des structures internes de plus haut niveau pour fournir un stockage permanent.

CONFIGURATION

Ces options slapd.conf s'appliquent à la base de données backend LDIF. C'est-à-dire qu'elles doivent suivre une ligne « database ldif » et venir avant toute ligne « backend » ou « database » ultérieure. Les autres options de base de données sont décrites dans le manuel slapd.conf(5).

directory <dir>
Spécifie le répertoire où commence l'arbre de la base de données. Le répertoire doit exister et accorder les permissions appropriées (rwx) à l'identité avec laquelle slapd est exécuté.

CONTRÔLE D'ACCÈS

Le backend LDIF ne respecte aucune des sémantiques de contrôle d'accès décrites dans slapd.access(5). Seul l'accès lecture (=r) à l'attribut pseudo-attribut entry et aux autres valeurs d'attributs des entrées retournées par l'opération search est respecté, ce qui est effectué par le frontend.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd

VOIR AUSSI

slapd.conf(5), slapd-config(5), slapd(8), ldif(5).
