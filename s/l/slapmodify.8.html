SLAPMODIFY(8C) SLAPMODIFY(8C)

NOM

slapmodify - Modifier les entrées dans une base de données SLAPD

SYNTAXE

/usr/bin/slapmodify [-b suffixe] [-c] [-d niveau-débogage] [-f slapd.conf] [-F confdir] [-g] [-j numéro-ligne] [-l fichier-ldif] [-n dbnum] [-o option[=valeur]] [-q] [-s] [-S SID] [-u] [-v] [-w]

DESCRIPTION

Slapmodify est utilisé pour appliquer des modifications spécifiées au format LDIF (LDAP Directory Interchange Format) à une base de données slapd(8). Il ouvre la base de données spécifiée, déterminée par le numéro de base de données ou le suffixe, et effectue les modifications correspondant à l'LDIF fourni dans la base de données. Les bases de données configurées comme subordonnées à celle-ci sont également mises à jour, sauf si l'option -g est spécifiée. L'entrée LDIF est lue depuis l'entrée standard ou le fichier spécifié.

Tous les fichiers créés éventuellement par slapmodify appartiendront à l'identité sous laquelle slapmodify est exécuté. Assurez-vous donc soit d'exécuter slapmodify avec la même identité que celle sous laquelle slapd(8) sera exécuté (voir l'option -u dans slapd(8)), soit de changer la propriété des fichiers avant d'exécuter slapd(8).

Remarque : slapmodify effectuera également l'indexation pertinente tout en modifiant la base de données si une indexation est configurée. Pour des détails spécifiques, veuillez consulter slapindex(8).

OPTIONS

-b suffixe
Utiliser le suffixe spécifié pour déterminer à quelle base de données ajouter les entrées. L'option -b ne peut pas être utilisée en conjonction avec l'option -n.
-c
Activer le mode de continuation (ignorer les erreurs).
-d niveau-débogage
Activer les messages de débogage tels que définis par le niveau-débogage spécifié ; voir slapd(8) pour les détails.
-f slapd.conf
Spécifier un fichier slapd.conf(5) alternatif.
-F confdir
Spécifier un répertoire de configuration. Si -f et -F sont tous deux spécifiés, le fichier de configuration sera lu et converti au format de répertoire de configuration, puis écrit dans le répertoire spécifié. Si aucune de ces options n'est spécifiée, une tentative de lecture du répertoire de configuration par défaut sera faite avant d'essayer d'utiliser le fichier de configuration par défaut. Si un répertoire de configuration valide existe, le fichier de configuration par défaut est ignoré. Si le mode simulation est également spécifié, aucune conversion n'aura lieu.
-g
Désactiver le collage subordonné. Seule la base de données spécifiée sera traitée, et non ses subordonnés collés (s'il y en a).
-j numéro-ligne
Sauter à la ligne spécifiée dans le fichier LDIF avant de traiter toute entrée. Cela permet de reprendre une modification qui a été interrompue en raison d'erreurs dans l'LDIF d'entrée après correction des erreurs.
-l fichier-ldif
Lire l'LDIF à partir du fichier spécifié au lieu de l'entrée standard.
-n dbnum
Effectuer les modifications sur la dbnum-ième base de données listée dans le fichier de configuration. L'option -n ne peut pas être utilisée en conjonction avec l'option -b. Pour manipuler la base de données de configuration slapd-config(5), utilisez -n 0 car c'est toujours la première base de données. Elle doit cependant exister physiquement sur le système de fichiers au préalable.
-o option[=valeur]
Spécifier une option avec une valeur (optionnelle). Les options/valeurs génériques possibles sont :
              syslog=<sous-systèmes> (voir `-s' dans slapd(8))
              syslog-level=<niveau>  (voir `-S' dans slapd(8))
              syslog-user=<utilisateur> (voir `-l' dans slapd(8))
              schema-check={oui|non}
              value-check={oui|non}
L'option schema-check active/désactive la vérification du schéma (activée par défaut) ;
l'option value-check active/désactive la vérification des valeurs (désactivée par défaut).
Cette dernière est incompatible avec -q.
-q
Activer le mode rapide (moins de vérifications d'intégrité). Effectue moins
de vérifications de cohérence sur les données d'entrée, et aucune vérification
de cohérence lors de l'écriture de la base de données. Améliore le temps
d'exécution, mais si des erreurs ou des interruptions se produisent, la base de
données résultante sera inutilisable.
-s
Désactiver la vérification du schéma. Cette option est destinée à être
utilisée lors de la manipulation de bases de données contenant des objets
spéciaux, tels que des objets fractionnaires sur une réplique partielle. La
création d'objets normaux qui ne respectent pas le schéma peut entraîner un
comportement inattendu et incorrect.
-S SID
ID du serveur à utiliser dans entryCSN généré. Également utilisé pour
contextCSN si -w est également défini. Valeur par défaut : 0.
-u
Activer le mode simulation (ne pas écrire dans le backend).
-v
Activer le mode verbeux.
-w
Écrire les informations de contexte syncrepl.
Après l'ajout de toutes les entrées, contextCSN sera mis à jour avec le CSN le
plus grand de la base de données.

LIMITATIONS

Votre slapd(8) ne doit pas être en cours d'exécution lorsque vous faites cela pour garantir la cohérence de la base de données.

Tous les backends ne prennent pas en charge tous les types de modifications, le type de modification modrdn en particulier n'est implémenté pour aucun des backends actuels.

slapmodify peut ne pas fournir de vérifications de nommage ou de schéma. Il est conseillé d'utiliser ldapmodify(1) lorsque cela est possible.

EXEMPLES

Pour apporter les modifications spécifiées dans le fichier ldif à votre base de données slapd(8), donnez la commande :

/usr/bin/slapmodify -l ldif

ldap(3), ldif(5), slapcat(8), slapadd(8), slapindex(8), ldapmodify(1), slapd(8)

slapmodify(8)

slapmodify - Modifier des entrées dans une base de données LDAP

SYNTHESE

slapmodify [OPTIONS] [FICHIER]

DESCRIPTION

La commande slapmodify est utilisée pour modifier des entrées dans une base de données LDAP. Elle peut être utilisée pour ajouter, supprimer ou modifier des entrées existantes.

OPTIONS

  • -b, --binddn <binddn> : Spécifie le DN de liaison.
  • -H, --uri <ldapuri> : Spécifie l'URI LDAP.
  • -f, --configfile <file> : Spécifie le fichier de configuration.
  • -a, --add : Ajoute une nouvelle entrée.
  • -d, --delete : Supprime une entrée.
  • -m, --modify : Modifie une entrée existante.
  • -r, --replace : Remplace une entrée existante.
  • -s, --search : Recherche une entrée.
  • -p, --port <port> : Spécifie le port LDAP.
  • -D, --binddn <binddn> : Spécifie le DN de liaison.
  • -w, --bindpw <bindpw> : Spécifie le mot de passe de liaison.
  • -W, --bindpwfile <file> : Spécifie le fichier contenant le mot de passe de liaison.
  • -S, --ssl (<allow|try|demand|disallow>) : Spécifie le niveau de sécurité SSL/TLS.
  • -X, --tls_requirecert <level> : Spécifie le niveau d'exigence de certificat TLS.
  • -c, --continue : Continue même en cas d'erreur.
  • -n, --dbname <db_name> : Spécifie le nom de la base de données.
  • -v, --verbose : Active la sortie verbeuse.
  • -V, --version : Affiche les informations de version.
  • -?, --help : Affiche l'aide.

LIMITATIONS

Cette commande ne peut pas être utilisée pour modifier la structure du schéma LDAP.

EXEMPLES

Pour ajouter une nouvelle entrée à partir d'un fichier LDIF :

slapmodify -a -f entry.ldif

Pour supprimer une entrée :

slapmodify -d cn=test,dc=example,dc=com

Pour modifier une entrée :

slapmodify -m -f modify.ldif

VOIR AUSSI

ldapsearch(1), ldapadd(8), ldapdelete(8), slapd.conf(5)
