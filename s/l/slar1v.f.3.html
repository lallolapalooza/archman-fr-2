sous programme slar1v (integer n, integer b1, integer bn, real lambda, real, dimension( * ) d, real, dimension( * ) l, real, dimension( * ) ld, real, dimension( * ) lld, real pivmin, real gaptol, real, dimension( * ) z, logical wantnc, integer negcnt, real ztz, real mingma, integer r, integer, dimension( * ) isuppz, real nrminv, real resid, real rqcorr, real, dimension( * ) work)

SLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de la sous-matrice comprise entre les lignes b1 et bn de la matrice tridiagonale LDLT - λI.

Objectif :

!>
!> SLAR1V calcule la colonne r (mise à l'échelle) de l'inverse de
!> la sous-matrice comprise entre les lignes B1 et BN de la matrice
!> tridiagonale L D L**T - sigma I. Lorsque sigma est proche d'une valeur propre,
!> le vecteur calculé est un vecteur propre précis. Généralement, r correspond
!> à l'indice où le vecteur propre est de magnitude maximale.
!> Les étapes suivantes accomplissent ce calcul :
!> (a) Transformation qd stationnaire,  L D L**T - sigma I = L(+) D(+) L(+)**T,
!> (b) Transformation qd progressive, L D L**T - sigma I = U(-) D(-) U(-)**T,
!> (c) Calcul des éléments diagonaux de l'inverse de
!>     L D L**T - sigma I en combinant les transformations ci-dessus, et en choisissant
!>     r comme l'indice où la diagonale de l'inverse est (l'un des)
!>     plus grands en magnitude.
!> (d) Calcul de la colonne r (mise à l'échelle) de l'inverse en utilisant la
!>     factorisation torsadée obtenue en combinant la partie supérieure de la
!>     transformation stationnaire et la partie inférieure de la transformation progressive.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>           L'ordre de la matrice L D L**T.
!>

B1

!>          B1 est un entier (INTEGER)
!>           Premier indice de la sous-matrice de L D L**T.
!>

BN

!>          BN est un entier (INTEGER)
!>           Dernier indice de la sous-matrice de L D L**T.
!>

LAMBDA

!>          LAMBDA est un réel (REAL)
!>           Le décalage. Afin de calculer un vecteur propre précis,
!>           LAMBDA doit être une bonne approximation d'une valeur propre
!>           de L D L**T.
!>

L

!>          L est un tableau de réels (REAL array), dimension (N-1)
!>           Les (N-1) éléments sous-diagonaux de la matrice unitaire bidiagonale
!>           L, dans les éléments 1 à N-1.
!>

D

!>          D est un tableau de réels (REAL array), dimension (N)
!>           Les N éléments diagonaux de la matrice diagonale D.
!>

LD

!>          LD est un tableau de réels (REAL array), dimension (N-1)
!>           Les N-1 éléments L(i)*D(i).
!>

LLD

!>          LLD est un tableau de réels (REAL array), dimension (N-1)
!>           Les N-1 éléments L(i)*L(i)*D(i).
!>

PIVMIN

!>          PIVMIN est un réel (REAL)
!>           Le pivot minimum dans la séquence de Sturm.
!>

GAPTOL

!>          GAPTOL est un réel (REAL)
!>           Tolérance indiquant quand les entrées du vecteur propre sont négligeables
!>           par rapport à leur contribution au résidu.
!>

Z

!>          Z est un tableau de réels (REAL array), dimension (N)
!>           En entrée, toutes les entrées de Z doivent être initialisées à 0.
!>           En sortie, Z contient la colonne r (mise à l'échelle) de l'inverse.
!>           La mise à l'échelle est telle que Z(R) est égal à 1.
!>

WANTNC

!>          WANTNC est un booléen (LOGICAL)
!>           Spécifie si NEGCNT doit être calculé.
!>

NEGCNT

!>          NEGCNT est un entier (INTEGER)
!>           Si WANTNC est .VRAI. alors NEGCNT = le nombre de pivots < pivmin
!>           dans la factorisation L D L**T, et NEGCNT = -1 sinon.
!>

ZTZ

!>          ZTZ est un réel (REAL)
!>           Le carré de la norme 2 de Z.
!>

MINGMA

!>          MINGMA est un réel (REAL)
!>           L'inverse du plus grand (en magnitude) élément diagonal
!>           de l'inverse de L D L**T - sigma I.
!>

R

!>          R est un entier (INTEGER)
!>           L'indice de torsion pour la factorisation torsadée utilisée pour
!>           calculer Z.
!>           En entrée, 0 <= R <= N. Si R est entré comme 0, R est mis à
!>           l'indice où (L D L**T - sigma I)^{-1} est de magnitude maximale.
!>           Si 1 <= R <= N, R n'est pas modifié.
!>           En sortie, R contient l'indice de torsion utilisé pour calculer Z.
!>           Idéalement, R désigne la position de l'entrée maximale dans le
!>           vecteur propre.
!>

ISUPPZ

!>          ISUPPZ est un tableau d'entiers (INTEGER array), dimension (2)
!>           Le support du vecteur dans Z, c'est-à-dire que le vecteur Z est
!>           non nul seulement dans les éléments ISUPPZ(1) à ISUPPZ( 2 ).
!>

NRMINV

!>          NRMINV est un réel (REAL)
!>           NRMINV = 1/SQRT( ZTZ )
!>

RESID

!>          RESID est un réel (REAL)
!>           Le résidu du vecteur FP.
!>           RESID = ABS( MINGMA )/SQRT( ZTZ )
!>

RQCORR

!>          RQCORR est un réel (REAL)
!>           La correction du quotient de Rayleigh à LAMBDA.
!>           RQCORR = MINGMA*TMP
!>

WORK

!>          WORK est un tableau de réels (REAL array), dimension (4*N)
!>
