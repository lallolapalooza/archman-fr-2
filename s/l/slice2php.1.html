slice2php(1) Manuel des commandes générales slice2php(1)

NOM

slice2php - Le compilateur Slice vers PHP.

SYNTAXE

slice2php [options] [fichiers]

DESCRIPTION

slice2php compile les fichiers Slice en PHP. La macro __SLICE2PHP__ est définie pendant cette compilation.

La documentation complète de slice2php est disponible en ligne à :
https://doc.zeroc.com/ice/3.7/language-mappings/php-mapping/client-side-slice-to-php-mapping/slice2php-command-line-options

OPTIONS

-h, --help

Affiche un message d'aide.
-v, --version
Affiche la version du compilateur.
-DNAME

Définit le symbole préprocesseur NAME.
-DNAME=DEF

Définit le symbole préprocesseur NAME avec la valeur DEF.
-UNAME

Annule la définition du symbole préprocesseur NAME.
-IDIR

Ajoute le répertoire DIR au chemin de recherche pour les directives #include.
-E

Affiche la sortie du préprocesseur sur stdout.
--output-dir DIR

Place les fichiers générés dans le répertoire DIR.
-d, --debug

Affiche des informations de débogage montrant le fonctionnement de l'analyseur Slice.
--depend

Affiche les informations de dépendance sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-xml

Affiche les informations de dépendance au format XML sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-file FILE

Dirige les informations de dépendance vers le fichier spécifié. Le format de sortie dépend si --depend ou --depend-xml sont également spécifiés.
--validate

Vérifie la correction des options de ligne de commande fournies, et ne génère aucun code.
--all

Génère le code pour toutes les définitions Slice, y compris celles des fichiers inclus.
--no-namespace

Génère le code sans prise en charge des namespaces PHP (obsolète).
--checksum CLASS

Génère des sommes de contrôle pour les définitions Slice.
--php5 CLASS

Génère du code compatible PHP5.
