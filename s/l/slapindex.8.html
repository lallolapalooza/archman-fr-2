SLAPINDEX(8C) SLAPINDEX(8C)

NOM

slapindex - Régénérer les index d'une base de données SLAPD

SYNTAXE

/usr/bin/slapindex [-b suffixe] [-c] [-d niveau-debug] [-f slapd.conf] [-F répertoire-config] [-g] [-n num-bd] [-o option[=valeur]] [-q] [-t] [-v] [attribut[...]]

DESCRIPTION

Slapindex est utilisé pour régénérer les index de slapd(8) basés sur le contenu actuel d'une base de données. Il ouvre la base de données spécifiée, déterminée par le numéro de base de données ou le suffixe, et met à jour les index pour toutes les valeurs de tous les attributs de toutes les entrées. Si une liste d'attributs spécifiques est fournie sur la ligne de commande, seuls les index pour ces attributs seront régénérés. Les bases de données configurées comme subordonnées à celle-ci sont également ré-indexées, sauf si -g est spécifié.

Tous les fichiers éventuellement créés par slapindex appartiendront à l'utilisateur sous lequel slapindex est exécuté. Assurez-vous donc soit d'exécuter slapindex avec la même identité que celle sous laquelle slapd(8) sera exécuté (voir l'option -u dans slapd(8)), soit de changer la propriété des fichiers avant d'exécuter slapd(8).

OPTIONS

-b suffixe
Utilise le suffixe spécifié pour déterminer quelle base de données doit recevoir la sortie. Par défaut, la première base de données qui supporte l'opération demandée est utilisée. Le -b ne peut pas être utilisé conjointement avec l'option -n.
-c
Active le mode continu (ignore les erreurs).
-d niveau-debug
Active les messages de débogage tels que définis par le niveau-debug spécifié ; voir slapd(8) pour les détails.
-f slapd.conf
Spécifie un fichier slapd.conf(5) alternatif.
-F répertoire-config
Spécifie un répertoire de configuration. Si -f et -F sont tous deux spécifiés, le fichier de configuration sera lu et converti au format de répertoire de configuration, puis écrit dans le répertoire spécifié. Si aucune des deux options n'est spécifiée, une tentative de lecture du répertoire de configuration par défaut sera effectuée avant d'essayer d'utiliser le fichier de configuration par défaut. Si un répertoire de configuration valide existe, le fichier de configuration par défaut est ignoré.
-g
Désactive le collage des subordonnés. Seule la base de données spécifiée sera traitée, et non ses subordonnés collés (s'il y en a).
-n num-bd
Génère la sortie pour la num-bd-ième base de données listée dans le fichier de configuration. La base de données de configuration slapd-config(5) est toujours la première base de données, utilisez donc -n 0.

L'option -n ne peut pas être utilisée conjointement avec l'option -b.

-o option[=valeur]
Spécifie une option avec une valeur (optionnelle). Options/valeurs génériques possibles :
              syslog=<sous-systèmes>  (voir `-s' dans slapd(8))
              syslog-level=<niveau> (voir `-S' dans slapd(8))
              syslog-user=<utilisateur>   (voir `-l' dans slapd(8))
-q
Active le mode rapide (moins de vérifications d'intégrité). N'effectue aucune vérification de cohérence lors de l'écriture de la base de données. Améliore le temps d'indexation, cependant la base de données sera très probablement inutilisable en cas d'erreurs ou d'interruptions.
-t
Active le mode troncation. Tronque (vide) une base de données d'index avant d'indexer des entrées. Peut seulement être utilisé avec back-mdb.
-v
Active le mode verbeux.

LIMITATIONS

Votre slapd(8) ne doit pas être en cours d'exécution (du moins, pas en mode lecture-écriture) lorsque vous faites cela pour assurer la cohérence de la base de données.

Cette commande offre amplement l'occasion à l'utilisateur d'obtenir et de boire sa boisson préférée.

EXEMPLES

Pour réindexer votre base de données SLAPD, tapez la commande :

/usr/bin/slapindex
Pour régénérer l'index d'un attribut spécifique, par exemple « uid », tapez la commande : 
/usr/bin/slapindex uid
