NOM

slapdn - Vérifie une liste de DN LDAP représentés par des chaînes, en fonction de la syntaxe du schéma

SYNTAXE

/usr/bin/slapdn [-d niveau-débogage] [-f slapd.conf] [-F confdir] [-N|-P] [-o option[=valeur]] [-v] DN [...]

DESCRIPTION

Slapdn est utilisé pour vérifier la conformité d'un DN par rapport au schéma défini dans slapd(8) et à celui chargé via slapd.conf(5). Il ouvre le fichier de configuration slapd.conf(5) ou le backend slapd-config (5), lit les définitions de schéma, puis analyse la liste des DN fournie sur la ligne de commande.

OPTIONS

-d niveau-débogage
active les messages de débogage tels que définis par le niveau-débogage spécifié ; voir slapd(8) pour les détails.
-f slapd.conf
spécifie un fichier slapd.conf(5) alternatif.
-F confdir
spécifie un répertoire de configuration. Si -f et -F sont tous deux spécifiés, le fichier de configuration sera lu et converti au format de répertoire de configuration, puis écrit dans le répertoire spécifié. Si aucune de ces options n'est spécifiée, une tentative de lecture du répertoire de configuration par défaut sera effectuée avant d'essayer d'utiliser le fichier de configuration par défaut. Si un répertoire de configuration valide existe, le fichier de configuration par défaut est ignoré.
-N
n'affiche qu'une forme normalisée du DN, adaptée à l'utilisation dans un outil de normalisation ; incompatible avec -P.
-o option[=valeur]
spécifie une option avec une valeur (facultative). Les options/valeurs génériques possibles sont :
              syslog=<sous-systèmes> (voir `-s' dans slapd(8))
              syslog-level=<niveau> (voir `-S' dans slapd(8))
              syslog-user=<utilisateur> (voir `-l' dans slapd(8))
-P
n'affiche qu'une forme "prettifiée" (lisible) du DN, adaptée à l'utilisation dans un outil de vérification et d'embellissement ; incompatible avec -N.
-v
active le mode verbeux.

EXEMPLES

Pour vérifier un DN, tapez la commande :

/usr/bin/slapdn -f //etc/openldap/slapd.conf -v DN
