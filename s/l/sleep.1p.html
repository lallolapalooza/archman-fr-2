SLEEP(1P) Manuel du programmeur POSIX SLEEP(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sleep — suspendre l'exécution pendant un intervalle

SYNTAXE

sleep temps

DESCRIPTION

L'utilitaire sleep suspendra l'exécution pendant au moins le nombre entier de secondes spécifié par l'opérande temps.

OPTIONS

Aucune.

OPÉRANDES

Le opérande suivant est pris en charge :

temps
Un entier décimal non négatif spécifiant le nombre de secondes pendant lesquelles suspendre l'exécution.

ENTRÉE STANDARD

Non utilisé.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution de sleep :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume des Définitions de Base de POSIX.1-2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de localisation.)
LC_ALL
Si définie à une chaîne non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la localisation pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Détermine la localisation qui devrait être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Si l'utilitaire sleep reçoit un signal SIGALRM, l'une des actions suivantes est effectuée :

1.
Terminer normalement avec un statut de sortie zéro.
2.
Ignorer effectivement le signal.
3.
Fournir le comportement par défaut pour les signaux décrits dans la section ÉVÉNEMENTS ASYNCHRONES de Section 1.4, Comportements par défaut des utilitaires. Cela peut inclure la terminaison avec un statut de sortie non nul.

L'utilitaire sleep prend l'action standard pour tous les autres signaux.

SORTIE STANDARD

Non utilisé.

SORTIE D'ERREUR STANDARD

La sortie d'erreur standard est utilisée uniquement pour les messages de diagnostic.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes sont renvoyées :

 0
L'exécution a été suspendue avec succès pendant au moins temps secondes, ou un signal SIGALRM a été reçu. Voir la section ÉVÉNEMENTS ASYNCHRONES.
>0
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

Par défaut.

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

Aucune.

EXEMPLES

L'utilitaire sleep peut être utilisé pour exécuter une commande après une certaine durée, comme dans :

(sleep 105; commande) &

ou pour exécuter une commande périodiquement, comme dans :

while true
do
    commande
    sleep 37
done

JUSTIFICATION

Le statut de sortie est autorisé à être zéro lorsque sleep est interrompu par le signal SIGALRM car la plupart des implémentations de cet utilitaire s'appuient sur l'arrivée de ce signal pour les notifier que le temps de fin demandé a été atteint avec succès. Ces implémentations ne distinguent donc pas cette situation du cas d'achèvement réussi. D'autres implémentations sont autorisées à intercepter le signal et à reprendre la veille jusqu'à l'expiration du temps demandé ou à fournir les procédures de terminaison de signal normales.

Comme avec tous les autres utilitaires qui acceptent des opérandes entiers et ne spécifient pas de sous-intervalles de valeurs autorisées, sleep est requis par ce volume de POSIX.1-2017 pour gérer les demandes de temps allant jusqu'à 2147483647 secondes. Cela peut signifier que certaines implémentations doivent effectuer plusieurs appels au mécanisme de délai du système d'exploitation sous-jacent si sa plage d'arguments est inférieure à cela.
