sous-routine slasrt (caractère id, entier n, réel, dimension( * ) d, entier info)

SLASRT trie des nombres par ordre croissant ou décroissant.

Objectif :

!>
!> Trie les nombres dans D par ordre croissant (si ID = 'I') ou
!> par ordre décroissant (si ID = 'D' ).
!>
!> Utilise le tri rapide, basculant vers le tri par insertion pour les tableaux de
!> taille <= 20. La dimension de STACK limite N à environ 2**32.
!>

Paramètres

ID 
!>          ID est CARACTERE*1
!>          = 'I' : trie D par ordre croissant ;
!>          = 'D' : trie D par ordre décroissant.
!>

N

!>          N est ENTIER
!>          La longueur du tableau D.
!>

D

!>          D est un tableau REEL, dimension (N)
!>          À l'entrée, le tableau à trier.
!>          À la sortie, D est trié par ordre croissant
!>          (D(1) <= ... <= D(N) ) ou par ordre décroissant
!>          (D(1) >= ... >= D(N) ), selon ID.
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>
