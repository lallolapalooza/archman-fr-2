subroutine slags2 (logical upper, real a1, real a2, real a3, real b1, real b2, real b3, real csu, real snu, real csv, real snv, real csq, real snq)

SLAGS2 calcule les matrices orthogonales 2x2 U, V et Q, et les applique aux matrices A et B de telle sorte que les lignes des matrices transformées A et B soient parallèles.

Objectif :

!>
!> SLAGS2 calcule les matrices orthogonales 2x2 U, V et Q, de telle sorte que si ( UPPER ) alors
!>
!>           U**T *A*Q = U**T *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> et
!>           V**T*B*Q = V**T *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> ou si ( .NOT.UPPER ) alors
!>
!>           U**T *A*Q = U**T *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> et
!>           V**T*B*Q = V**T*( B1 0  )*Q = ( x  x  )
!>                           ( B2 B3 )     ( 0  x  )
!>
!> Les lignes des matrices A et B transformées sont parallèles, où
!>
!>   U = (  CSU  SNU ), V = (  CSV SNV ), Q = (  CSQ   SNQ )
!>       ( -SNU  CSU )      ( -SNV CSV )      ( -SNQ   CSQ )
!>
!> Z**T dénote la transposée de Z.
!>
!>

Paramètres

UPPER 
!>          UPPER est LOGICAL
!>          = .TRUE. : les matrices d'entrée A et B sont triangulaires supérieures.
!>          = .FALSE. : les matrices d'entrée A et B sont triangulaires inférieures.
!>

A1

!>          A1 est REAL
!>

A2

!>          A2 est REAL
!>

A3

!>          A3 est REAL
!>          À l'entrée, A1, A2 et A3 sont des éléments de la matrice 2x2
!>          triangulaire supérieure (inférieure) d'entrée A.
!>

B1

!>          B1 est REAL
!>

B2

!>          B2 est REAL
!>

B3

!>          B3 est REAL
!>          À l'entrée, B1, B2 et B3 sont des éléments de la matrice 2x2
!>          triangulaire supérieure (inférieure) d'entrée B.
!>

CSU

!>          CSU est REAL
!>

SNU

!>          SNU est REAL
!>          La matrice orthogonale désirée U.
!>

CSV

!>          CSV est REAL
!>

SNV

!>          SNV est REAL
!>          La matrice orthogonale désirée V.
!>

CSQ

!>          CSQ est REAL
!>

SNQ

!>          SNQ est REAL
!>          La matrice orthogonale désirée Q.
!>
