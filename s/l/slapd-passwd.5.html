SLAPD-PASSWD(5) Manuel des formats de fichiers SLAPD-PASSWD(5)

NOM

slapd-passwd - backend pour /etc/passwd dans slapd

SYNTAXE

/etc/openldap/slapd.conf

DESCRIPTION

Le backend PASSWD de slapd(8) sert les informations de compte utilisateur listées dans le fichier système passwd(5). Ce backend est fourni à des fins de démonstration uniquement. Le DN de chaque entrée est "uid=<nom d'utilisateur>,<suffixe>". Notez que les recherches non-base parcourent l'intégralité du fichier passwd, et conviennent mieux aux hôtes avec de petits fichiers passwd.

CONFIGURATION

Cette option de slapd.conf s'applique à la base de données du backend PASSWD. C'est-à-dire qu'elle doit suivre une ligne "database passwd" et précéder toute ligne "backend" ou "database" subséquente. Les autres options de base de données sont décrites dans le manuel slapd.conf(5).

fichier <nom de fichier>
Spécifie un fichier passwd alternatif à utiliser. Le défaut est /etc/passwd.

CONTRÔLE D'ACCÈS

Le backend passwd ne tient compte d'aucune des sémantiques de contrôle d'accès décrites dans slapd.access(5). Seul l'accès en lecture (=r) à l'attribut pseudo- entry et aux autres valeurs d'attribut des entrées retournées par l'opération search est pris en compte, ce qui est effectué par le frontend.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd
/etc/passwd
informations de compte utilisateur

VOIR AUSSI

slapd.conf(5), slapd(8), passwd(5).
