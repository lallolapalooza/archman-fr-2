NOM

slapd-pw-sha2 - Module de mot de passe SHA-2 pour slapd

SYNTAXE

ETCDIR/slapd.conf

moduleload pw-sha2

DESCRIPTION

Le module pw-sha2 pour slapd(8) fournit la prise en charge de l'utilisation de SSHA-512, SSHA-384, SSHA-256, SHA-512, SHA-384 et SHA-256 de la famille de fonctions de hachage SHA-2 (FIPS 180-2) dans les mots de passe hachés dans OpenLDAP.

Il le fait en fournissant les schémas de mots de passe supplémentaires suivants pour une utilisation dans slapd :

{SSHA256}
SHA-256 avec sel, produisant des valeurs de hachage d'une longueur de 256 bits
{SHA256}
SHA-256 simple, produisant des valeurs de hachage d'une longueur de 256 bits
{SSHA384}
SHA-384 avec sel, produisant des valeurs de hachage d'une longueur de 384 bits
{SHA384}
SHA-384 simple, produisant des valeurs de hachage d'une longueur de 384 bits
{SSHA512}
SHA-512 avec sel, produisant des valeurs de hachage d'une longueur de 512 bits
{SHA512}
SHA-512 simple, produisant des valeurs de hachage d'une longueur de 512 bits

CONFIGURATION

Le module pw-sha2 ne nécessite aucune configuration.

Après le chargement du module, les schémas de mots de passe {SSHA256}, {SSHA384}, {SSHA512}, {SSHA256}, {SHA384} et {SHA512} seront reconnus dans les valeurs de l'attribut userPassword.

Vous pouvez alors indiquer à OpenLDAP d'utiliser ces schémas lors du traitement des opérations étendues de modification de mot de passe LDAPv3 (RFC 3062) en utilisant l'option password-hash dans slapd.conf(5).

NOTES

Si vous souhaitez utiliser les schémas décrits ici avec slappasswd(8), n'oubliez pas de charger le module en utilisant ses options en ligne de commande. L'option/valeur pertinente est :

-o module-load=pw-sha2

Selon l'emplacement de pw-sha2, vous pourriez également avoir besoin de :

-o module-path=spécification_chemin

EXEMPLES

Tous les attributs LDAP userPassword ci-dessous codent le mot de passe 'secret'.

userPassword: {SHA512}vSsar3708Jvp9Szi2NWZZ02Bqp1qRCFpbcTZPdBhnWgs5WtNZKnvCXdhztmeD2cmW192CF5bDufKRpayrW/isg==
userPassword: {SHA384}WKd1ukESvjAFrkQHznV9iP2nHUBJe7gCbsrFTU4//HIyzo3jq1rLMK45dg/ufFPt
userPassword: {SHA256}K7gNU3sdo+OL0wNhqoVWhr3g6s1xYv72ol/pe/Unols=

Pour faire de {SSHA512} le hachage de mot de passe utilisé dans les opérations étendues de modification de mot de passe, définissez simplement cette ligne dans slapd.conf(5) :

password-hash   {SSHA512}
