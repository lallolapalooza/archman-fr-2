real function slatm2 (integer m, integer n, integer i, integer j, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer igrade, real, dimension( * ) dl, real, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, real sparse)

SLATM2

But:

!>
!>    SLATM2 renvoie l'élément (I,J) d'une matrice aléatoire de dimension
!>    (M, N) décrite par les autres paramètres. Elle est appelée par la
!>    routine SLATMR afin de construire des matrices de test aléatoires. Aucune vérification d'erreur
!>    sur les paramètres n'est effectuée, car cette routine est appelée dans une
!>    boucle serrée par SLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de SLATM2 diffère de SLATM3 par l'ordre dans lequel le générateur
!>    de nombres aléatoires est appelé pour remplir les entrées de la matrice aléatoire.
!>    Avec SLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    colonne par colonne. Avec SLATM3, le générateur est appelé pour remplir la
!>    matrice colonne par colonne, après quoi elle est pivotée. Ainsi, SLATM3 peut
!>    être utilisé pour construire des matrices aléatoires qui ne diffèrent que par leur
!>    ordre de lignes et/ou de colonnes. SLATM2 est utilisé pour construire des matrices bande
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour les
!>    entrées situées en dehors de la bande (et donc de générer des nombres aléatoires
!>
!>    La matrice dont l'élément (I,J) est renvoyé est construite comme suit
!>    (cette routine ne calcule qu'une seule entrée) :
!>
!>      Si I est en dehors de (1..M) ou J est en dehors de (1..N), renvoyer zéro
!>         (ceci est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Graduer la matrice, si désiré, par la gauche (avec DL) et/ou
!>         par la droite (avec DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Transformer en bande la matrice pour avoir une bande inférieure KL et une bande supérieure
!>         KU.
!>
!>      Définir les entrées aléatoires à zéro comme spécifié par SPARSE.
!>

Paramètres

M 
!>          M est un entier
!>           Nombre de lignes de la matrice. Non modifié.
!>

N

!>          N est un entier
!>           Nombre de colonnes de la matrice. Non modifié.
!>

I

!>          I est un entier
!>           Ligne de l'entrée à renvoyer. Non modifié.
!>

J

!>          J est un entier
!>           Colonne de l'entrée à renvoyer. Non modifié.
!>

KL

!>          KL est un entier
!>           Bande inférieure. Non modifié.
!>

KU

!>          KU est un entier
!>           Bande supérieure. Non modifié.
!>

IDIST

!>          IDIST est un entier
!>           À l'entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMALE( 0, 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau d'entiers de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau REEL de dimension ( MIN( I , J ) )
!>           Entrées diagonales de la matrice. Non modifié.
!>

IGRADE

!>          IGRADE est un entier
!>           Spécifie la graduation de la matrice comme suit :
!>           0  => pas de graduation
!>           1  => matrice prémultipliée par diag( DL )
!>           2  => matrice postmultipliée par diag( DR )
!>           3  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DR )
!>           4  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par inv( diag( DL ) )
!>           5  => matrice prémultipliée par diag( DL ) et
!>                         postmultipliée par diag( DL )
!>           Non modifié.
!>

DL

!>          DL est un tableau REEL ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour la graduation de la matrice. Non modifié.
!>

DR

!>          DR est un tableau REEL ( I ou J, selon le cas )
!>           Facteurs d'échelle droit pour la graduation de la matrice. Non modifié.
!>

IPVTNG

!>          IPVTNG est un entier
!>           À l'entrée, spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement de ligne.
!>           2 => pivotement de colonne.
!>           3 => pivotement complet, c'est-à-dire des deux côtés.
!>           Non modifié.
!>

IWORK

!>          IWORK est un tableau d'entiers ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) à la position K était initialement à la
!>           position IWORK( K ).
!>           Ceci diffère de IWORK pour SLATM3. Non modifié.
!>

SPARSE

!>          SPARSE est REEL entre 0. et 1.
!>           À l'entrée, spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire uniforme ( 0, 1 ) x est généré et
!>           comparé à SPARSE ; si x est supérieur, l'entrée de la matrice
!>           n'est pas modifiée et si x est inférieur, l'entrée est mise
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>
