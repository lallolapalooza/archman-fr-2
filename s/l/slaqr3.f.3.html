sous-routine slaqr3 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, real, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, real, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, real, dimension( * ) sr, real, dimension( * ) si, real, dimension( ldv, * ) v, integer ldv, integer nh, real, dimension( ldt, * ) t, integer ldt, integer nv, real, dimension( ldwv, * ) wv, integer ldwv, real, dimension( * ) work, integer lwork)

SLAQR3 effectue la transformation de similarité orthogonale d'une matrice de Hessenberg pour détecter et déflater les valeurs propres entièrement convergentes d'une sous-matrice principale suffixe (déflation précoce agressive).

Objectif :

!>
!>    Déflation précoce agressive :
!>
!>    SLAQR3 accepte en entrée une matrice de Hessenberg
!>    H et effectue une transformation de similarité orthogonale
!>    conçue pour détecter et déflater les valeurs propres entièrement convergentes d'une
!>    sous-matrice principale suffixe. En sortie, H a été écrasée par une nouvelle matrice de Hessenberg qui est une perturbation d'une transformation de similarité orthogonale de H. Il faut espérer que la version finale de H ait de nombreuses entrées sous-diagonales nulles.
!>

Paramètres

WANTT 
!>          WANTT est LOGIQUE
!>          Si .VRAI., alors la matrice de Hessenberg H est entièrement mise à jour
!>          afin que le facteur de Schur quasi-triangulaire puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FAUX., seule une partie suffisante de H est mise à jour pour préserver
!>          les valeurs propres.
!>

WANTZ

!>          WANTZ est LOGIQUE
!>          Si .VRAI., alors la matrice orthogonale Z est mise à jour
!>          afin que le facteur de Schur orthogonal puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FAUX., alors Z n'est pas référencée.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice H et (si WANTZ est .VRAI.) l'ordre
!>          de la matrice orthogonale Z.
!>

KTOP

!>          KTOP est ENTIER
!>          On suppose que soit KTOP = 1, soit H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP ensemble déterminent un bloc isolé
!>          le long de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est ENTIER
!>          On suppose sans vérification que soit
!>          KBOT = N, soit H(KBOT+1,KBOT)=0. KBOT et KTOP ensemble
!>          déterminent un bloc isolé le long de la diagonale de la
!>          matrice de Hessenberg.
!>

NW

!>          NW est ENTIER
!>          Taille de la fenêtre de déflation.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est un tableau REAL, dimension (LDH,N)
!>          En entrée, la section initiale N x N de H contient la
!>          matrice de Hessenberg soumise à une déflation précoce agressive.
!>          En sortie, H a été transformée par une transformation de similarité
!>          orthogonale, perturbée, et ramenée
!>          à la forme de Hessenberg qui (il faut l'espérer) a quelques
!>          entrées sous-diagonales nulles.
!>

LDH

!>          LDH est ENTIER
!>          Dimension principale de H telle que déclarée dans la sous-routine
!>          appelante.  N <= LDH
!>

ILOZ

!>          ILOZ est ENTIER
!>

IHIZ

!>          IHIZ est ENTIER
!>          Spécifient les lignes de Z auxquelles les transformations doivent être
!>          appliquées si WANTZ est .VRAI.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est un tableau REAL, dimension (LDZ,N)
!>          Si WANTZ est .VRAI., alors en sortie, la transformation
!>          de similarité orthogonale mentionnée ci-dessus a été
!>          accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ) par la droite.
!>          Si WANTZ est .FAUX., alors Z n'est pas référencée.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale de Z telle que déclarée dans la
!>          sous-routine appelante.  1 <= LDZ.
!>

NS

!>          NS est ENTIER
!>          Le nombre de valeurs propres non convergentes (c'est-à-dire approximatives)
!>          renvoyées dans SR et SI qui peuvent être utilisées comme décalages par
!>          la sous-routine appelante.
!>

ND

!>          ND est ENTIER
!>          Le nombre de valeurs propres convergentes découvertes par cette
!>          sous-routine.
!>

SR

!>          SR est un tableau REAL, dimension (KBOT)
!>

SI

!>          SI est un tableau REAL, dimension (KBOT)
!>          En sortie, les parties réelles et imaginaires des valeurs propres
!>          approximatives qui peuvent être utilisées pour les décalages sont stockées
!>          dans SR(KBOT-ND-NS+1) à SR(KBOT-ND) et
!>          SI(KBOT-ND-NS+1) à SI(KBOT-ND), respectivement.
!>          Les parties réelles et imaginaires des valeurs propres convergentes
!>          sont stockées dans SR(KBOT-ND+1) à SR(KBOT) et
!>          SI(KBOT-ND+1) à SI(KBOT), respectivement.
!>

V

!>          V est un tableau REAL, dimension (LDV,NW)
!>          Un tableau de travail NW x NW.
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale de V telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDV
!>

NH

!>          NH est ENTIER
!>          Le nombre de colonnes de T.  NH >= NW.
!>

T

!>          T est un tableau REAL, dimension (LDT,NW)
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale de T telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDT
!>

NV

!>          NV est ENTIER
!>          Le nombre de lignes du tableau de travail WV disponibles pour
!>          l'espace de travail.  NV >= NW.
!>

WV

!>          WV est un tableau REAL, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est ENTIER
!>          La dimension principale de W telle que déclarée dans la
!>          sous-routine appelante.  NW <= LDV
!>

WORK

!>          WORK est un tableau REAL, dimension (LWORK)
!>          En sortie, WORK(1) est défini comme une estimation de la valeur optimale
!>          de LWORK pour les valeurs données de N, NW, KTOP et KBOT.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau de travail WORK.  LWORK = 2*NW
!>          suffit, mais une plus grande efficacité peut résulter de valeurs
!>          plus grandes de LWORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; SLAQR3
!>          estime seulement la taille optimale de l'espace de travail pour les
!>          valeurs données de N, NW, KTOP et KBOT.  L'estimation est renvoyée
!>          dans WORK(1). Aucun message d'erreur relatif à LWORK n'est émis
!>          par XERBLA. Ni H ni Z ne sont accédés.
!>

Function/Subroutine Documentation

@brief@ subroutine slaqr3(n, knt, b, ldb, wr, wi, ssf, sse, q, ldq, iq, ski, sl, sm, sr, se, tol, ns, nw, nc)

slaqr3 computes the eigenvalues of a upper Hessenberg matrix B using an implicitly shifted QR algorithm.

Arguments

n -- Integer. Order of the matrix B. n >= 0.

knt -- Integer. The number of columns of B the subroutine is asked to deflate. knt <= n.

b -- Real array of dimension (ldb, n). Input, upper Hessenberg matrix.

ldb -- Integer. Leading dimension of the array B. ldb >= n.

wr -- Real array of dimension (n). Output, real part of the eigenvalues.

wi -- Real array of dimension (n). Output, imaginary part of the eigenvalues.

ssf -- Real. Input, the shift P in the middle of the range of eigenvalues.

sse -- Real. Input, the shift P in the middle of the range of eigenvalues.

q -- Real array of dimension (ldq, n). Output, the orthogonal matrix Q such that B = Q*R.

ldq -- Integer. Leading dimension of the array Q. ldq >= n.

iq -- Integer array of dimension (n).

ski -- Integer array of dimension (n).

sl -- Real array of dimension (n).

sm -- Real array of dimension (n).

sr -- Real array of dimension (n).

se -- Real array of dimension (n).

tol -- Real. Input, the tolerance used to treat eigenvalues as converged.

ns -- Integer. Output, the number of eigenvalues selected.

nw -- Integer. Output, the number of eigenvalues computed.

nc -- Integer. Output, the number of eigenvalues converged.
