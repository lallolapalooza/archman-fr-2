Documentation de la fonction/sous-programme

sous-programme slasyf_rk (caractère uplo, entier n, entier nb, entier kb, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) e, entier, dimension( * ) ipiv, réel, dimension( ldw, * ) w, entier ldw, entier info)

SLASYF_RK calcule une factorisation partielle d'une matrice réelle symétrique indéfinie en utilisant la méthode de pivotement diagonal bornée de Bunch-Kaufman (rook).

Objectif:

!> SLASYF_RK calcule une factorisation partielle d'une matrice réelle symétrique
!> A en utilisant la méthode de pivotement diagonal bornée de Bunch-Kaufman (rook).
!> La factorisation partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> où l'ordre de D est au maximum NB. L'ordre réel est retourné dans
!> l'argument KB, et est soit NB, soit NB-1, soit N si N <= NB.
!>
!> SLASYF_RK est une routine auxiliaire appelée par SSYTRF_RK. Elle utilise
!> du code bloqué (appelant BLAS de niveau 3) pour mettre à jour la sous-matrice
!> A11 (si UPLO = 'U') ou A22 (si UPLO = 'L').
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure
!>          de la matrice symétrique A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NB

!>          NB est INTEGER
!>          Le nombre maximum de colonnes de la matrice A qui doivent être
!>          factorisées.  NB doit être au moins 2 pour permettre des blocs
!>          de pivot de 2x2.
!>

KB

!>          KB est INTEGER
!>          Le nombre de colonnes de A qui ont été effectivement factorisées.
!>          KB est soit NB-1, soit NB, soit N si N <= NB.
!>

A

!>          A est tableau de REAL, dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.
!>            Si UPLO = 'U': la partie supérieure N x N principale
!>            de A contient la partie triangulaire supérieure de la matrice A,
!>            et la partie strictement triangulaire inférieure de A n'est pas
!>            référencée.
!>
!>            Si UPLO = 'L': la partie inférieure N x N principale
!>            de A contient la partie triangulaire inférieure de la matrice A,
!>            et la partie strictement triangulaire supérieure de A n'est pas
!>            référencée.
!>
!>          À la sortie, contient :
!>            a) SEULEMENT les éléments diagonaux de la matrice symétrique
!>               par blocs de la diagonale D sur la diagonale de A, c'est-à-dire
!>               D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou subdiagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U': facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L': facteur L dans la partie subdiagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est tableau de REAL, dimension (N)
!>          À la sortie, contient les éléments superdiagonaux (ou subdiagonaux)
!>          de la matrice symétrique par blocs de la diagonale D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est tableau de INTEGER, dimension (N)
!>          IPIV décrit la matrice de permutation P dans la factorisation
!>          de la matrice A comme suit. La valeur absolue de IPIV(k)
!>          représente l'indice de la ligne et de la colonne qui ont été
!>          échangées avec la k-ième ligne et colonne. La valeur de UPLO
!>          décrit l'ordre dans lequel les échanges ont été appliqués.
!>          De plus, le signe de IPIV représente la structure par blocs
!>          de la matrice symétrique par blocs de la diagonale D avec des
!>          blocs diagonaux de 1x1 ou 2x2 qui correspondent à 1 ou 2 échanges
!>          à chaque étape de factorisation.
!>
!>          Si UPLO = 'U',
!>          ( dans l'ordre de factorisation, k décroît de N à 1 ) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,N-KB+1:N) ;
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k-1) < 0 signifie :
!>               D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k-1) != k-1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la sous-matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), on a toujours ABS( IPIV(k) ) <= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>
!>          Si UPLO = 'L',
!>          ( dans l'ordre de factorisation, k augmente de 1 à N ) :
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,1:KB).
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k+1) < 0 signifie :
!>               D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent UNIQUEMENT par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k+1) != k+1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), on a toujours ABS( IPIV(k) ) >= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>

W

!>          W est tableau de REAL, dimension (LDW,NB)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau W.  LDW >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès
!>
!>          < 0: Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0: Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient que des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient que des zéros.
!>
!>               Par conséquent D(k,k) est exactement zéro, et les éléments
!>               superdiagonaux de la colonne k de U (ou éléments subdiagonaux de
!>               la colonne k de L ) sont tous des zéros. La factorisation est
!>               complète.

Function/Subroutine Documentation

slasyf_rk computes the factorization of a real general band matrix.

This subroutine is deprecated. Use slasyf instead.

Description:

This subroutine is deprecated and will be removed in a future release. It is used for the real general band matrix factorization routine slasyf.

In the current implementation, slasyf_rk is identical to slasyf.

slasyf_rk computes the factorization of a real general band matrix A of order N, which is partitioned into a block structure.

It is assumed that the block structure is such that the matrices A11 and A22 are square. The routine uses block-Householder transformations (implemented as block reflections) to factor A.

The factorization is computed in the form

A = P * U * T * U**T * P**T

where P is a permutation matrix, U is a sequence of block-reflections, and T is a block upper triangular matrix.

T is block upper triangular of the form:

T = [ T11 T12 ... T1k ]

[ 0 T22 ... T2k ]

[ . . . ]

[ 0 0 ... Tkk ]

where each Tij is a square matrix, and Tii is block tridiagonal.

The block diagonal matrix D is exactly singular, and division by zero will occur if it is used to solve a system of equations.

NOTE: INFO only stores the first occurrence of a singularity, any subsequent occurrence of singularity is not stored in INFO even though the factorization always completes.

Parameters:

UPLO
CHARACTER*1.
Specifies whether the matrix A is upper or lower triangular.
UPLO = 'U': Upper triangular.
UPLO = 'L': Lower triangular.
N
INTEGER.
The order of the matrix A. N >= 0.
NB
INTEGER.
The block size of the factorization. NB >= 1.
A
REAL array, dimension (LDA, k), where k is the number of blocks.
On entry, the band matrix A. On exit, the factors U and T are stored in A.
LDA
INTEGER.
The leading dimension of the array A. LDA >= max(1, N).
IPVT
INTEGER array, dimension (N).
Details of the block interchanges.
Q
REAL array, dimension (LDQ, k), where k is the number of blocks.
On exit, the block matrix Q which is the product of block reflections.
LDQ
INTEGER.
The leading dimension of the array Q. LDQ >= max(1, N).
WORK
REAL array, dimension (max(N, 2*NB)).
Workspace.
INFO
INTEGER.

= 0: successful exit

< 0: if INFO = -i, the i-th parameter had an illegal value.

> 0: if INFO = i, D(i,i) is singular.

The block diagonal matrix D is exactly singular, and division by zero will occur if it is used to solve a system of equations.

NOTE: INFO only stores the first occurrence of a singularity, any subsequent occurrence of singularity is not stored in INFO even though the factorization always completes.

Dans l'implémentation actuelle, slasyf_rk est identique à slasyf.

slasyf_rk calcule la factorisation d'une matrice bande générale réelle A d'ordre N, qui est partitionnée en une structure par blocs.
