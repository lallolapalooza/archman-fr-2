NOM

slapd-wt - Backend WiredTiger pour slapd

SYNOPIS

/etc/openldap/slapd.conf

DESCRIPTION

Le backend wt de slapd(8) utilise la bibliothèque de base de données WiredTiger pour stocker les données.

Le backend wt est un module expérimental qui offre des performances d'écriture potentiellement élevées et des performances de concurrence élevées. Ce backend ne dispose pas encore de certaines fonctionnalités de base. Veuillez sauvegarder vos données à l'aide de slapcat avant de mettre à jour le module.

CONFIGURATION

Ces options slapd.conf s'appliquent à la base de données backend wt. Cela signifie qu'elles doivent suivre une ligne « database wt » et précéder toute ligne « backend » ou « database » ultérieure. Les autres options de base de données sont décrites dans la page de manuel slapd.conf(5).

directory <répertoire>
Spécifie le répertoire d'accueil de WiredTiger où résident cette base de données et les index associés. Un répertoire séparé doit être spécifié pour chaque base de données. La valeur par défaut est /var/lib/openldap/openldap-data.
idlcache <booléen>
Utilise l'idlcache en mémoire. La valeur par défaut est vrai.
index {<liste_attributs>|default} [pres,eq,approx,sub,<spécial>]
Spécifie les index à maintenir pour l'attribut donné (ou la liste d'attributs). Certains attributs ne prennent en charge qu'un sous-ensemble d'index. Si seul un <attribut> est donné, les index spécifiés pour default sont maintenus. Notez que la définition d'une valeur par défaut n'implique pas que tous les attributs seront indexés. De plus, pour de meilleures performances, un index eq doit toujours être configuré pour l'attribut objectClass.
mode <entier>
back-wt ne prend pas en charge l'option mode. Utilisez umask à la place.
wtconfig {create,cache_size=512M,async=(enabled)}
Spécifie la configuration pour wiredtiger. Ce paramètre est passé à wiredtiger_open(3).
create
crée la base de données si elle n'existe pas.
cache_size
taille maximale de la mémoire du tas à allouer pour le cache.
async
options de configuration des opérations asynchrones. désactivé par défaut.

CONTROLE D'ACCES

Le backend wt respecte les sémantiques de contrôle d'accès telles qu'indiquées dans slapd.access(5).

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration slapd par défaut
