NOM

slogkey --- Gère les clés cryptographiques pour l'utilisation de l'environnement de journalisation sécurisée de {{ site.product.short_name }}.

SYNTAXE

slogkey [options] [arguments]

DESCRIPTION

L'utilitaire slogkey est utilisé pour gérer les clés cryptographiques pour l'utilisation du module de journalisation sécurisée de syslog-ng OSE. Utilisez cet utilitaire pour créer une clé maîtresse, dériver une clé d'hôte à utiliser par une configuration de journalisation sécurisée et pour afficher le compteur de séquence actuel d'une clé. Les options déterminent le mode de fonctionnement et sont mutuellement exclusives.

ARGUMENTS

Les arguments dépendent du mode de fonctionnement.

•
Génération de clé maîtresse

Séquence d'appel : slogkey --master-key <nom de fichier>

<nom de fichier> : Le nom du fichier dans lequel la clé maîtresse est écrite.

•
Dérivation de clé d'hôte

Séquence d'appel : slogkey --derive-key <fichier de clé maîtresse> <adresse MAC de l'hôte> <numéro de série de l'hôte> <fichier de clé de l'hôte>

  • <fichier de clé maîtresse> : La clé maîtresse à partir de laquelle la clé d'hôte est dérivée.
  • <adresse MAC de l'hôte> : L'adresse MAC de l'hôte sur lequel la clé est utilisée. Au lieu de l'adresse MAC, toute autre chaîne identifiant de manière unique un hôte peut être fournie, par exemple le numéro d'inventaire de l'entreprise.
  • <numéro de série de l'hôte> : Le numéro de série de l'hôte sur lequel la clé est utilisée. Au lieu du numéro de série, toute autre chaîne identifiant de manière unique un hôte peut être fournie, par exemple, le numéro d'inventaire de l'entreprise.
  • <fichier de clé de l'hôte> : Le nom du fichier dans lequel la clé d'hôte est écrite.
NOTE : La clé d'hôte nouvellement créée a son compteur défini sur 0, indiquant qu'elle représente la clé d'hôte initiale k0). Cette clé d'hôte doit être gardée secrète et ne pas être divulguée à des tiers. Elle est requise pour déchiffrer et vérifier avec succès les archives de logs traitées par l'environnement de journalisation sécurisée. Comme chaque entrée de log est chiffrée avec sa propre clé, une nouvelle clé d'hôte est créée après le traitement réussi d'une entrée de log et remplace la clé précédente. Par conséquent, la clé d'hôte initiale doit être stockée dans un endroit sûr avant de démarrer l'environnement de journalisation sécurisée, car elle est supprimée de l'hôte de log après le traitement de la première entrée de log.
•
Affichage du compteur de séquence

OPTIONS

•
--master-key ou -m

Génère une nouvelle clé maîtresse. <nom de fichier> est le nom du fichier stockant la clé maîtresse nouvellement générée.

•
--derive-key ou -d

Dérive une clé d'hôte à l'aide d'une clé maîtresse générée précédemment.

•
--counter ou -c

Affiche le compteur de séquence de log actuel d'une clé.

•
--help ou -h

Affiche un message d'aide.

FICHIERS

/usr/bin/slogkey

/etc/syslog-ng.conf
