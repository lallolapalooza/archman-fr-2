Documentation de la fonction/sous-routine

integer function slaneg (integer n, real, dimension( * ) d, real, dimension( * ) lld, real sigma, real pivmin, integer r)

SLANEG calcule le compte de Sturm.

Objectif:

!>
!> SLANEG calcule le compte de Sturm, le nombre de pivots négatifs
!> rencontrés lors de la factorisation de la matrice tridiagonale T - sigma I = L D L^T.
!> Cette implémentation travaille directement sur les facteurs sans former
!> la matrice tridiagonale T. Le compte de Sturm est aussi le nombre
!> de valeurs propres de T inférieures à sigma.
!>
!> Cette routine est appelée par SLARRB.
!>
!> La routine actuelle n'utilise pas le paramètre PIVMIN mais plutôt
!> requiert la propagation IEEE-754 des Infinities et des NaNs. Cette
!> routine n'a pas non plus de restrictions sur la plage d'entrée mais nécessite
!> une gestion des exceptions par défaut telle que x/0 produise Inf lorsque x est
!> non nul, et Inf/Inf produise NaN. Pour plus d'informations, voir:
!>
!>   Marques, Riedy, et Voemel, SIAM Journal on
!>   Scientific Computing, v28, n5, 2006. DOI 10.1137/050641624
!>   (Version rapport technique dans LAWN 172 avec le même titre.)
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau réel (REAL array), dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

LLD

!>          LLD est un tableau réel (REAL array), dimension (N-1)
!>          Les (N-1) éléments L(i)*L(i)*D(i).
!>

SIGMA

!>          SIGMA est un réel (REAL)
!>          Montant du décalage dans T - sigma I = L D L^T.
!>

PIVMIN

!>          PIVMIN est un réel (REAL)
!>          Le pivot minimum dans la séquence de Sturm. Peut être utilisé
!>          lorsque des pivots nuls sont rencontrés sur des architectures non-IEEE-754.
!>

R

!>          R est un entier (INTEGER)
!>          L'indice de rotation pour la factorisation tournée utilisée
!>          pour le calcul du nombre de pivots négatifs.
!>
