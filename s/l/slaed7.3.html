subroutine slaed7 (integer icompq, integer n, integer qsiz, integer tlvls, integer curlvl, integer curpbm, real, dimension( * ) d, real, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, real rho, integer cutpnt, real, dimension( * ) qstore, integer, dimension( * ) qptr, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, real, dimension( 2, * ) givnum, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLAED7 utilisée par SSTEDC. Calcule le système propre mis à jour d'une matrice diagonale après modification par une matrice symétrique de rang un. Utilisée lorsque la matrice d'origine est dense.

Objectif :

!>
!> SLAED7 calcule le système propre mis à jour d'une matrice diagonale
!> après modification par une matrice symétrique de rang un. Cette
!> sous-routine est utilisée uniquement pour le problème propre qui exige toutes
!> les valeurs propres et éventuellement les vecteurs propres d'une matrice symétrique dense
!> qui a été réduite à une forme tridiagonale. SLAED1 gère
!> le cas où toutes les valeurs propres et vecteurs propres d'une matrice
!> tridiagonale symétrique sont souhaités.
!>
!>   T = Q(entree) ( D(entree) + RHO * Z*Z**T ) Q**T(entree) = Q(sortie) * D(sortie) * Q**T(sortie)
!>
!>    où Z = Q**Tu, u est un vecteur de longueur N avec des uns dans les
!>    éléments CUTPNT et CUTPNT + 1 et des zéros ailleurs.
!>
!>    Les vecteurs propres de la matrice d'origine sont stockés dans Q, et les
!>    valeurs propres sont dans D. L'algorithme se compose de trois étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a des valeurs propres multiples ou s'il y a un zéro dans
!>       le vecteur Z. Pour chaque occurrence de ce type, la dimension du
!>       problème d'équation séculaire est réduite de un. Cette étape
!>       est effectuée par la sous-routine SLAED8.
!>
!>       La deuxième étape consiste à calculer les valeurs propres mises à jour.
!>       Ceci est fait en trouvant les racines de l'équation séculaire
!>       via la sous-routine SLAED4 (appelée par SLAED9).
!>       Cette sous-routine calcule également les vecteurs propres du
!>       problème courant.
!>
!>       La dernière étape consiste à calculer directement les vecteurs propres mis à jour
!>       en utilisant les valeurs propres mises à jour. Les vecteurs propres
!>       du problème courant sont multipliés par les vecteurs propres du
!>       problème global.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est INTEGER
!>          = 0 : Calculer uniquement les valeurs propres.
!>          = 1 : Calculer également les vecteurs propres de la matrice symétrique dense d'origine.
!>                À l'entrée, Q contient la matrice orthogonale utilisée
!>                pour réduire la matrice d'origine à une forme tridiagonale.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

QSIZ

!>          QSIZ est INTEGER
!>         La dimension de la matrice orthogonale utilisée pour réduire
!>         la matrice complète à une forme tridiagonale. QSIZ >= N si ICOMPQ = 1.
!>

TLVLS

!>          TLVLS est INTEGER
!>         Le nombre total de niveaux de fusion dans l'arbre de division et de conquête global.
!>

CURLVL

!>          CURLVL est INTEGER
!>         Le niveau actuel dans la routine de fusion globale,
!>         0 <= CURLVL <= TLVLS.
!>

CURPBM

!>          CURPBM est INTEGER
!>         Le problème actuel au niveau actuel dans la routine de fusion globale
!>         (en comptant de gauche à droite et de bas en haut).
!>

D

!>          D est un tableau REAL, dimension (N)
!>         À l'entrée, les valeurs propres de la matrice perturbée par rang 1.
!>         À la sortie, les valeurs propres de la matrice réparée.
!>

Q

!>          Q est un tableau REAL, dimension (LDQ, N)
!>         À l'entrée, les vecteurs propres de la matrice perturbée par rang 1.
!>         À la sortie, les vecteurs propres de la matrice tridiagonale réparée.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau INTEGER, dimension (N)
!>         La permutation qui réintégrera le sous-problème qui vient
!>         d'être résolu dans l'ordre trié, c'est-à-dire D( INDXQ( I = 1, N ) )
!>         sera dans l'ordre croissant.
!>

RHO

!>          RHO est REAL
!>         L'élément sous-diagonal utilisé pour créer la modification de rang 1.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         Contient l'emplacement de la dernière valeur propre dans la
!>         matrice symétrique principale. min(1,N) <= CUTPNT <= N.
!>

QSTORE

!>          QSTORE est un tableau REAL, dimension (N**2+1)
!>         Stocke les vecteurs propres des sous-matrices rencontrées lors
!>         de la division et de la conquête, regroupés. QPTR pointe vers
!>         le début des sous-matrices.
!>

QPTR

!>          QPTR est un tableau INTEGER, dimension (N+2)
!>         Liste des pointeurs vers le début des sous-matrices stockées
!>         dans QSTORE. Les sous-matrices sont numérotées en commençant par
!>         le bas à gauche de l'arbre de division et de conquête, de gauche
!>         à droite et de bas en haut.
!>

PRMPTR

!>          PRMPTR est un tableau INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans PERM la
!>         permutation d'un niveau est stockée. PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et également la taille du
!>         problème complet non déflaté.
!>

PERM

!>          PERM est un tableau INTEGER, dimension (N lg N)
!>         Contient les permutations (provenant de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est un tableau INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans GIVCOL les
!>         rotations de Givens d'un niveau sont stockées. GIVPTR(i+1) - GIVPTR(i)
!>         indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est un tableau INTEGER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau REAL, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!>

WORK

!>          WORK est un tableau REAL, dimension (3*N+2*QSIZ*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (4*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé.
!>
