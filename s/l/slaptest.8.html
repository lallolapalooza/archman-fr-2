NOM

slaptest - Vérifie la pertinence de la configuration slapd d'OpenLDAP

SYNOPSIS

/usr/bin/slaptest [-d niveau-debug] [-f slapd.conf] [-F repoconf] [-nnuméro-bd] [-o option[=valeur]] [-Q] [-u] [-v]

DESCRIPTION

Slaptest est utilisé pour vérifier la conformité de la configuration slapd(8). Il ouvre le fichier de configuration slapd.conf(5) ou le backend slapd-config(5), et l'analyse conformément aux règles générales et spécifiques au backend, en vérifiant sa cohérence.

OPTIONS

-d niveau-debug
active les messages de débogage tels que définis par le niveau-debug spécifié ; voir slapd(8) pour les détails.
-f slapd.conf
spécifie un fichier slapd.conf(5) alternatif.
-F repoconf
spécifie un répertoire de configuration. Si -f et -F sont tous deux spécifiés, le fichier de configuration sera lu et converti au format de répertoire de configuration, puis écrit dans le répertoire spécifié. Si aucune de ces options n'est spécifiée, slaptest tentera de lire le répertoire de configuration par défaut avant d'essayer d'utiliser le fichier de configuration par défaut. Si un répertoire de configuration valide existe, le fichier de configuration par défaut est ignoré. Si le mode simulation est également spécifié, aucune conversion n'aura lieu.
-n numéro-bd
Ouvre et teste uniquement la numéro-bd-ième base de données listée dans le fichier de configuration. Pour tester uniquement la base de données de configuration slapd-config(5), utilisez -n 0 car c'est toujours la première base de données.
-o option[=valeur]
Spécifie une option avec une valeur (optionnelle). Les options/valeurs génériques possibles sont :
              syslog=<sous-systèmes>  (voir `-s' dans slapd(8))
              syslog-level=<niveau> (voir `-S' dans slapd(8))
              syslog-user=<utilisateur>   (voir `-l' dans slapd(8))
-Q
Être extrêmement silencieux : seul le code de sortie indique le succès (0) ou non (toute autre valeur).
-u
active le mode simulation (c'est-à-dire ne pas échouer si les bases de données ne peuvent pas être ouvertes, mais si la configuration est correcte).
-v
active le mode verbeux.

EXEMPLES

Pour vérifier un slapd.conf(5), tapez la commande :

/usr/bin/slaptest -f //etc/openldap/slapd.conf -v
