sous-programme slasd5 (entier i, relatif, dimension( 2 ) d, relatif, dimension( 2 ) z, relatif, dimension( 2 ) delta, relatif rho, relatif dsigma, relatif, dimension( 2 ) work)

SLASD5 calcule la racine carrée de la i-ième valeur propre d'une modification symétrique de rang un d'une matrice diagonale 2x2. Utilisé par sbdsdc.

Objectif :

!>
!> Ce sous-programme calcule la racine carrée de la I-ième valeur propre
!> d'une modification symétrique de rang un d'une matrice diagonale 2x2
!>
!>            diag( D ) * diag( D ) +  RHO * Z * transpose(Z) .
!>
!> Les entrées diagonales dans le tableau D sont supposées satisfaire
!>
!>            0 <= D(i) < D(j)  pour  i < j .
!>
!> Nous supposons également que RHO > 0 et que la norme euclidienne du vecteur
!> Z est un.
!>

Paramètres

I 
!>          I est ENTIER
!>         L'indice de la valeur propre à calculer.  I = 1 ou I = 2.
!>

D

!>          D est un tableau RELATIF, dimension (2)
!>         Les valeurs propres originales.  Nous supposons 0 <= D(1) < D(2).
!>

Z

!>          Z est un tableau RELATIF, dimension (2)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau RELATIF, dimension (2)
!>         Contient (D(j) - sigma_I) dans sa j-ième composante.
!>         Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres.
!>

RHO

!>          RHO est RELATIF
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DSIGMA

!>          DSIGMA est RELATIF
!>         Le sigma_I calculé, la I-ième valeur propre mise à jour.
!>

WORK

!>          WORK est un tableau RELATIF, dimension (2)
!>         WORK contient (D(j) + sigma_I) dans sa j-ième composante.
!>
