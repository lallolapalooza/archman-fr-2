Documentation de la fonction/sous-programme

sous-programme slahilb (entier n, entier nrhs, reel, dimension(lda, n) a, entier lda, reel, dimension(ldx, nrhs) x, entier ldx, reel, dimension(ldb, nrhs) b, entier ldb, reel, dimension(n) work, entier info)

SLAHILB

But :

!>
!> SLAHILB génère une matrice de Hilbert mise à l'échelle N par N dans A ainsi que
!> NRHS membres de droite dans B et solutions dans X tels que A*X=B.
!>
!> La matrice de Hilbert est mise à l'échelle par M = PPCM(1, 2, ..., 2*N-1) de sorte que toutes
!> les entrées soient des entiers. Les membres de droite sont les NRHS premières
!> colonnes de M * la matrice identité, et les solutions sont les
!> premières NRHS colonnes de la matrice de Hilbert inverse.
!>
!> Le nombre de condition de la matrice de Hilbert croît exponentiellement avec
!> sa taille, approximativement comme O(e ** (3.5*N)). De plus, les matrices de Hilbert inverses
!> au-delà d'une dimension relativement petite ne peuvent pas être
!> générées exactement sans précision supplémentaire. La précision est épuisée
!> lorsque la plus grande entrée de la matrice de Hilbert inverse est supérieure à
!> 2 élevé à la puissance du nombre de bits de la fraction du type de données
!> utilisé plus un, soit 24 pour la précision simple.
!>
!> En précision simple, la solution générée est exacte pour N <= 6 et présente
!> une petite erreur composante pour 7 <= N <= 11.
!>

Paramètres

N 
!>          N est ENTIER
!>          La dimension de la matrice A.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre demandé de membres de droite.
!>

A

!>          A est tableau REEL, dimension (LDA, N)
!>          La matrice de Hilbert mise à l'échelle générée.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= N.
!>

X

!>          X est tableau REEL, dimension (LDX, NRHS)
!>          Les solutions exactes générées. Actuellement, les NRHS premières
!>          colonnes de la matrice de Hilbert inverse.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X. LDX >= N.
!>

B

!>          B est tableau REEL, dimension (LDB, NRHS)
!>          Les membres de droite générés. Actuellement, les NRHS premières
!>          colonnes de PPCM(1, 2, ..., 2*N-1) * la matrice identité.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= N.
!>

WORK

!>          WORK est tableau REEL, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès de l'exécution
!>          = 1 : N est trop grand ; les données sont toujours générées mais peuvent ne pas
!>               être exactes.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
