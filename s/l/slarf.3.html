SYNOPSIS

Fonctions/Sous-routines


sous-routine slarf (side, m, n, v, incv, tau, c, ldc, work)
SLARF applique un réflecteur élémentaire à une matrice rectangulaire générale.

Documentation de la fonction/sous-routine

sous-routine slarf (caractère side, entier m, entier n, réel, dimension( * ) v, entier incv, réel tau, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) work)

SLARF applique un réflecteur élémentaire réel H à une matrice réelle m par n C, soit par la gauche, soit par la droite. H est représenté sous la forme 

       H = I - tau * v * v**T

où tau est un scalaire réel et v est un vecteur réel.

Si tau = 0, alors H est considérée comme la matrice unité.

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': former  H * C
!>          = 'R': former  C * H

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.

V

!>          V est un tableau REAL, dimension
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  ou (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H. V n'est pas utilisé si
!>          TAU = 0.

INCV

!>          INCV est INTEGER
!>          L'incrément entre les éléments de v. INCV <> 0.

TAU

!>          TAU est REAL
!>          La valeur tau dans la représentation de H.

C

!>          C est un tableau REAL, dimension (LDC,N)
!>          À l'entrée, la matrice C de taille m par n.
!>          À la sortie, C est écrasé par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).

WORK

!>          WORK est un tableau REAL, dimension
!>                         (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
