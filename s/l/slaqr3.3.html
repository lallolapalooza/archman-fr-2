sous-routine slaqr3 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, real, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, real, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, real, dimension( * ) sr, real, dimension( * ) si, real, dimension( ldv, * ) v, integer ldv, integer nh, real, dimension( ldt, * ) t, integer ldt, integer nv, real, dimension( ldwv, * ) wv, integer ldwv, real, dimension( * ) work, integer lwork)

SLAQR3 effectue la transformation de similarité orthogonale d'une matrice de Hessenberg pour détecter et déflater les valeurs propres entièrement convergentes d'une sous-matrice principale de droite (déflation précoce agressive).

But :

!>
!>    Déflation précoce agressive :
!>
!>    SLAQR3 accepte en entrée une matrice de Hessenberg
!>    H et effectue une transformation de similarité orthogonale
!>    visant à détecter et déflater les valeurs propres entièrement convergentes de
!>    une sous-matrice principale. En sortie, H a été écrasée par une nouvelle matrice de Hessenberg qui est une perturbation de
!>    une transformation de similarité orthogonale de H. On espère que la version finale de H aura de nombreuses entrées sous-diagonales nulles.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          Si .VRAI., alors la matrice de Hessenberg H est entièrement mise à jour
!>          afin que le facteur de Schur quasi-triangulaire puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FAUX., seule une partie suffisante de H est mise à jour pour préserver
!>          les valeurs propres.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          Si .VRAI., alors la matrice orthogonale Z est mise à jour afin
!>          que le facteur de Schur orthogonal puisse être calculé
!>          (en coopération avec la sous-routine appelante).
!>          Si .FAUX., alors Z n'est pas référencé.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H et (si WANTZ est .VRAI.) l'ordre de la matrice orthogonale Z.
!>

KTOP

!>          KTOP est INTEGER
!>          On suppose que KTOP = 1 ou que H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP ensemble déterminent un bloc isolé
!>          le long de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est INTEGER
!>          On suppose sans vérification que soit
!>          KBOT = N, soit H(KBOT+1,KBOT)=0. KBOT et KTOP ensemble
!>          déterminent un bloc isolé le long de la diagonale de la
!>          matrice de Hessenberg.
!>

NW

!>          NW est INTEGER
!>          Taille de la fenêtre de déflation. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est tableau REAL, dimension (LDH,N)
!>          En entrée, la section N x N initiale de H stocke la
!>          matrice de Hessenberg subissant une déflation précoce agressive.
!>          En sortie, H a été transformée par une transformation de similarité orthogonale,
!>          perturbée, et retournée
!>          à la forme de Hessenberg qui (on l'espère) a quelques
!>          entrées sous-diagonales nulles.
!>

LDH

!>          LDH est INTEGER
!>          Dimension de tête de H, telle que déclarée dans la sous-routine appelante.
!>          N <= LDH
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>          Spécifient les lignes de Z auxquelles les transformations doivent
!>          être appliquées si WANTZ est .VRAI.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est tableau REAL, dimension (LDZ,N)
!>          SI WANTZ est .VRAI., alors en sortie, la transformation de similarité orthogonale
!>          mentionnée ci-dessus a été
!>          accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ) par la droite.
!>          Si WANTZ est .FAUX., alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension de tête de Z, telle que déclarée dans la
!>          sous-routine appelante. 1 <= LDZ.
!>

NS

!>          NS est INTEGER
!>          Le nombre de valeurs propres non convergentes (c'est-à-dire approximatives)
!>          retournées dans SR et SI qui peuvent être utilisées comme pivots par
!>          la sous-routine appelante.
!>

ND

!>          ND est INTEGER
!>          Le nombre de valeurs propres convergentes découvertes par cette
!>          sous-routine.
!>

SR

!>          SR est tableau REAL, dimension (KBOT)
!>

SI

!>          SI est tableau REAL, dimension (KBOT)
!>          En sortie, les parties réelles et imaginaires des valeurs propres approximatives
!>          qui peuvent être utilisées comme pivots sont stockées dans
!>          SR(KBOT-ND-NS+1) à SR(KBOT-ND) et
!>          SI(KBOT-ND-NS+1) à SI(KBOT-ND), respectivement.
!>          Les parties réelles et imaginaires des valeurs propres convergentes
!>          sont stockées dans SR(KBOT-ND+1) à SR(KBOT) et
!>          SI(KBOT-ND+1) à SI(KBOT), respectivement.
!>

V

!>          V est tableau REAL, dimension (LDV,NW)
!>          Un tableau de travail NW x NW.
!>

LDV

!>          LDV est INTEGER
!>          La dimension de tête de V, telle que déclarée dans la
!>          sous-routine appelante. NW <= LDV
!>

NH

!>          NH est INTEGER
!>          Le nombre de colonnes de T. NH >= NW.
!>

T

!>          T est tableau REAL, dimension (LDT,NW)
!>

LDT

!>          LDT est INTEGER
!>          La dimension de tête de T, telle que déclarée dans la
!>          sous-routine appelante. NW <= LDT
!>

NV

!>          NV est INTEGER
!>          Le nombre de lignes du tableau de travail WV disponibles pour
!>          l'espace de travail. NV >= NW.
!>

WV

!>          WV est tableau REAL, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est INTEGER
!>          La dimension de tête de W, telle que déclarée dans la
!>          sous-routine appelante. NW <= LDV
!>

WORK

!>          WORK est tableau REAL, dimension (LWORK)
!>          À la sortie, WORK(1) est défini à une estimation de la valeur optimale
!>          de LWORK pour les valeurs données de N, NW, KTOP et KBOT.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau de travail WORK. LWORK = 2*NW
!>          suffit, mais une efficacité accrue peut résulter de valeurs plus grandes
!>          de LWORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; SLAQR3
!>          estime seulement la taille optimale de l'espace de travail pour les
!>          valeurs données de N, NW, KTOP et KBOT. L'estimation est retournée
!>          dans WORK(1). Aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA. Ni H ni Z ne sont accédés.
!>

NAME

slaqr3 - routines to compute the Schur decomposition of a general matrix.

SYNOPSIS

  subroutine slaqr3(n, knt, nropt, nl, nr, il, ir,
                     ilo, ihi, lwork, info, t,
                     s, vr, ldvr, work, iwork)

Parameters:

`n`

INTEGER. Order of the matrix T.

`knt`

INTEGER. (Input) Number of iterations in the QR iteration.

`nropt`

INTEGER. (Input) Number of shifts performed.

`nl`

INTEGER. (Input) Number of deflation shifts from the left.

`nr`

INTEGER. (Input) Number of deflation shifts from the right.

`il`

INTEGER. (Input) The start of the range of columns of T to be reduced.

`ir`

INTEGER. (Input) The end of the range of columns of T to be reduced.

`ilo`

INTEGER. (Input) The start of the range of rows of T to be reduced.

`ihi`

INTEGER. (Input) The end of the range of rows of T to be reduced.

`lwork`

INTEGER. (Input) The dimension of the array WORK.

`info`

INTEGER. (Output) Error flag. 0 for successful exit, and non-zero for abnormal exit.

`t`

REAL array, dimension (LD T, N). (Input/Output) Upper Hessenberg matrix whose Schur decomposition is desired.

`s`

REAL array, dimension (N). (Output) The eigenvalues of T.

`vr`

REAL array, dimension (LD VR, N). (Output) The unitary matrix Q that performs the similarity transformation T=Q*T*Q**H.

`ldvr`

INTEGER. (Input) The number of rows of the array VR.

`work`

REAL array, dimension (LWORK). (Workspace) Workspace array.

`iwork`

INTEGER array, dimension (N). (Workspace) Workspace array.

Function/Subroutine Documentation

slaqr3

Purpose:

This subroutine computes the Schur decomposition of a condensed matrix T.

Description:

This subroutine is called by the hybrid QR algorithm routine SLAHQR. It is used to compute the Schur decomposition of a tridiagonal matrix T.

The input matrix T is assumed to be in upper Hessenberg form and its Schur decomposition is desired.

The subroutine computes the eigenvalues of T and the corresponding Schur vectors.

The routine returns the eigenvalues in the array S and the Schur vectors in the array VR.

The array VR is updated to accumulate the transformations applied to T.

The subroutine takes the following parameters:

n: The order of the matrix T.

knt: The number of iterations in the QR iteration.

nropt: The number of shifts performed.

nl: The number of deflation shifts from the left.

nr: The number of deflation shifts from the right.

il: The start of the range of columns of T to be reduced.

ir: The end of the range of columns of T to be reduced.

ilo: The start of the range of rows of T to be reduced.

ihi: The end of the range of rows of T to be reduced.

lwork: The dimension of the array WORK.

info: Error flag. 0 for successful exit, and non-zero for abnormal exit.

t: The upper Hessenberg matrix whose Schur decomposition is desired.

s: The eigenvalues of T.

vr: The unitary matrix Q that performs the similarity transformation T=Q*T*Q**H.

ldvr: The number of rows of the array VR.

work: Workspace array.

iwork: Workspace array.
