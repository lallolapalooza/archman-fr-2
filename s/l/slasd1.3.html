sous-programme slasd1 (entier nl, entier nr, entier sqre, reel, dimension( * ) d, reel alpha, reel beta, reel, dimension( ldu, * ) u, entier ldu, reel, dimension( ldvt, * ) vt, entier ldvt, entier, dimension( * ) idxq, entier, dimension( * ) iwork, reel, dimension( * ) work, entier info)

SLASD1 calcule la SVD d'une matrice B bidiagonale supérieure de taille spécifiée. Utilisé par sbdsdc.

Objectif :

!>
!> SLASD1 calcule la SVD d'une matrice B bidiagonale N-par-M supérieure,
!> où N = NL + NR + 1 et M = N + SQRE. SLASD1 est appelée depuis SLASD0.
!>
!> Une sous-routine connexe, SLASD7, gère le cas où les valeurs singulières
!> (et les vecteurs singuliers sous forme factorisée) sont désirées.
!>
!> SLASD1 calcule la SVD comme suit :
!>
!>               ( D1(ent)    0    0       0 )
!>   B = U(ent) * (   Z1**T   a   Z2**T    b ) * VT(ent)
!>               (   0       0   D2(ent)   0 )
!>
!>     = U(sor) * ( D(sor) 0) * VT(sor)
!>
!> où Z**T = (Z1**T a Z2**T b) = u**T VT**T, et u est un vecteur de dimension M
!> avec ALPHA et BETA dans les entrées NL+1 et NL+2 et des zéros
!> ailleurs ; et l'entrée b est vide si SQRE = 0.
!>
!> Les vecteurs singuliers gauches de la matrice originale sont stockés dans U, et
!> la transposée des vecteurs singuliers droits est stockée dans VT, et les
!> valeurs singulières sont dans D. L'algorithme se compose de trois étapes :
!>
!>    La première étape consiste à déflater la taille du problème
!>    lorsqu'il y a plusieurs valeurs singulières ou lorsqu'il y a des zéros
!>    dans le vecteur Z. Pour chaque occurrence, la dimension du
!>    problème de l'équation séculaire est réduite d'une unité. Cette étape
!>    est effectuée par la routine SLASD2.
!>
!>    La deuxième étape consiste à calculer les valeurs singulières mises à jour.
!>    Ceci est fait en trouvant les racines carrées des racines de
!>    l'équation séculaire via la routine SLASD4 (appelée par SLASD3).
!>    Cette routine calcule également les vecteurs singuliers du
!>    problème actuel.
!>
!>    La dernière étape consiste à calculer directement les vecteurs singuliers mis à jour
!>    en utilisant les valeurs singulières mises à jour. Les vecteurs singuliers
!>    du problème actuel sont multipliés par les vecteurs singuliers
!>    du problème global.
!>

Paramètres

NL 
!>          NL est ENTIER
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est ENTIER
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est ENTIER
!>         = 0 : le bloc inférieur est une matrice carrée NR-par-NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR-par-(NR+1).
!>
!>         La matrice bidiagonale a une dimension de ligne N = NL + NR + 1,
!>         et une dimension de colonne M = N + SQRE.
!>

D

!>          D est tableau REEL, dimension (NL+NR+1).
!>         N = NL+NR+1
!>         À l'entrée, D(1:NL,1:NL) contient les valeurs singulières du
!>         bloc supérieur ; et D(NL+2:N) contient les valeurs singulières du
!>         bloc inférieur. À la sortie, D(1:N) contient les valeurs singulières
!>         de la matrice modifiée.
!>

ALPHA

!>          ALPHA est REEL
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est REEL
!>         Contient l'élément hors-diagonale associé à la ligne ajoutée.
!>

U

!>          U est tableau REEL, dimension (LDU,N)
!>         À l'entrée, U(1:NL, 1:NL) contient les vecteurs singuliers gauches du
!>         bloc supérieur ; U(NL+2:N, NL+2:N) contient les vecteurs singuliers
!>         gauches du bloc inférieur. À la sortie, U contient les vecteurs singuliers
!>         gauches de la matrice bidiagonale.
!>

LDU

!>          LDU est ENTIER
!>         La dimension de tête du tableau U. LDU >= max( 1, N ).
!>

VT

!>          VT est tableau REEL, dimension (LDVT,M)
!>         où M = N + SQRE.
!>         À l'entrée, VT(1:NL+1, 1:NL+1)**T contient les vecteurs singuliers
!>         droits du bloc supérieur ; VT(NL+2:M, NL+2:M)**T contient
!>         les vecteurs singuliers droits du bloc inférieur. À la sortie,
!>         VT**T contient les vecteurs singuliers droits de la
!>         matrice bidiagonale.
!>

LDVT

!>          LDVT est ENTIER
!>         La dimension de tête du tableau VT. LDVT >= max( 1, M ).
!>

IDXQ

!>          IDXQ est tableau ENTIER, dimension (N)
!>         Il contient la permutation qui réintégrera le sous-problème
!>         qui vient d'être résolu dans l'ordre trié, c'est-à-dire
!>         D( IDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

IWORK

!>          IWORK est tableau ENTIER, dimension (4*N)
!>

WORK

!>          WORK est tableau REEL, dimension (3*M**2+2*M)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>
