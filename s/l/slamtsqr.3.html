Documentation de la fonction/sous-programme

sous-routine slamtsqr (caractere side, caractere trans, entier m, entier n, entier k, entier mb, entier nb, reel, dimension( lda, * ) a, entier lda, reel, dimension( ldt, * ) t, entier ldt, reel, dimension( ldc, * ) c, entier ldc, reel, dimension( * ) work, entier lwork, entier info)

SLAMTSQR

Objectif:

!>
!>      SLAMTSQR écrase la matrice réelle M par N, C, avec
!>
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>      où Q est une matrice réelle orthogonale définie comme le produit
!>      de réflecteurs élémentaires bloqués calculés par la factorisation QR
!>      "tall skinny" (SLATSQR)
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**T depuis la gauche ;
!>          = 'R' : appliquer Q ou Q**T depuis la droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'T' : Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q. M >= K >= 0 ;
!>
!>

MB

!>          MB est INTEGER
!>          La taille de bloc à utiliser dans la QR bloquée.
!>          MB > N. (doit être la même que SLATSQR)
!>

NB

!>          NB est INTEGER
!>          La taille de bloc de colonne à utiliser dans la QR bloquée.
!>          N >= NB >= 1.
!>

A

!>          A est un tableau REAL, dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire bloqué H(i), pour i = 1,2,...,k, tel que
!>          retourné par SLATSQR dans les k premières colonnes de
!>          son tableau argument A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est un tableau REAL, dimension
!>          ( N * Nombre de blocs(CEIL(M-K/MB-K)),
!>          Les réflecteurs de bloc triangulaires supérieurs bloqués stockés sous forme compacte
!>          en séquence de blocs triangulaires supérieurs. Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= NB.
!>

C

!>          C est un tableau REAL, dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) tableau REAL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK minimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,N*NB).
!>          Si SIDE = 'R', LWORK >= max(1,MB*NB).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille minimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires:

!> QR "Tall-Skinny" (TSQR) effectue la QR par une séquence de transformations orthogonales,
!> représentant Q comme un produit d'autres matrices orthogonales
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> où chaque Q(i) annule les entrées sous-diagonales d'un bloc de MB lignes de A :
!>   Q(1) annule les entrées sous-diagonales des lignes 1:MB de A
!>   Q(2) annule les lignes MB-N inférieures des lignes [1:N,MB+1:2*MB-N] de A
!>   Q(3) annule les lignes MB-N inférieures des lignes [1:N,2*MB-N+1:3*MB-2*N] de A
!>   . . .
!>
!> Q(1) est calculé par GEQRT, qui représente Q(1) par des vecteurs de Householder
!> stockés sous la diagonale des lignes 1:MB de A, et par des réflecteurs de bloc
!> triangulaires supérieurs, stockés dans le tableau T(1:LDT,1:N).
!> Pour plus d'informations, voir les Détails supplémentaires de GEQRT.
!>
!> Q(i) pour i>1 est calculé par TPQRT, qui représente Q(i) par des vecteurs de Householder
!> stockés dans les lignes [(i-1)*(MB-N)+N+1:i*(MB-N)+N] de A, et par des réflecteurs de bloc
!> triangulaires supérieurs, stockés dans le tableau T(1:LDT,(i-1)*N+1:i*N).
!> Le dernier Q(k) peut utiliser moins de lignes.
!> Pour plus d'informations, voir les Détails supplémentaires de TPQRT.
!>
!> Pour plus de détails sur l'algorithme global, voir la description de
!> TSQR séquentiel à la section 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>
