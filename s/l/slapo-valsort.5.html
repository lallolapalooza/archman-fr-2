NOM

slapo-valsort - Superposition de tri de valeurs pour slapd

SYNOPSIS

/etc/openldap/slapd.conf

DESCRIPTION

La superposition de tri de valeurs (Value Sorting overlay) peut être utilisée avec une base de données backend pour trier les valeurs d'attributs multi-valués spécifiques au sein d'un sous-arbre. Le tri s'effectue chaque fois que les attributs sont retournés dans une réponse de recherche.

Le tri peut être spécifié par ordre croissant ou décroissant, en utilisant des méthodes de tri alphanumériques ou numériques. De plus, un tri "pondéré" peut être spécifié, qui utilise un poids numérique préfixé aux valeurs des attributs. Le tri pondéré est toujours effectué par ordre croissant, mais peut être combiné avec les autres méthodes pour les valeurs qui ont toutes des poids égaux. Le poids est spécifié en préfixant un poids entier {<poids>} devant chaque valeur de l'attribut pour lequel un tri pondéré est souhaité. Ce facteur de pondération est supprimé et n'est pas retourné dans les résultats de recherche, sauf si le contrôle valsort est spécifié (1.3.6.1.4.1.4203.666.5.14).

Le contrôle valsort nécessite une valeur constituée d'une Séquence qui contient un indicateur booléen. Le facteur de pondération n'est retourné que si la valeur booléenne est VRAIE. En format lber-encode(3), la valeur requise doit conformer à la syntaxe "{b}".

CONFIGURATION

Ces options slapd.conf s'appliquent à la superposition de tri de valeurs. Elles doivent apparaître après la directive overlay.

valsort-attr <attribut> <baseDN> (<methode-tri> | pondere [<methode-tri>])
Configure une méthode de tri pour l'attribut spécifié attribut dans le sous-arbre dont la racine est baseDN. La methode-tri peut être l'une des suivantes : alpha-ascend, alpha-descend, numeric-ascend, ou numeric-descend. Si la méthode spéciale pondere est spécifiée, une methode-tri secondaire peut également être spécifiée. Il est erroné de spécifier une methode-tri alphanumérique pour un attribut ayant une syntaxe Integer ou NumericString, et il est erroné de spécifier une methode-tri numérique pour un attribut ayant une syntaxe autre que Integer ou NumericString.

EXEMPLES

database mdb
suffix dc=example,dc=com
...
overlay valsort
valsort-attr member ou=groups,dc=example,dc=com alpha-ascend

Pour invoquer ldapsearch(1) avec le contrôle valsort, la valeur du contrôle doit être correctement définie. Les octets suivants représentent l'encodage "{b}" désiré :

0x30 0x03 0x01 0x01 0xff

Le contrôle peut être envoyé depuis la ligne de commande en utilisant l'encodage base64 de la valeur :

ldapsearch -E 1.3.6.1.4.1.4203.666.5.14=::MAMBAf8=

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd

VOIR AUSSI

slapd.conf(5), slapd-config(5).
