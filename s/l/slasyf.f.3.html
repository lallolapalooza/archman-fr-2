SLASYF calcule une factorisation partielle d'une matrice réelle symétrique en utilisant la méthode de pivotement diagonal de Bunch-Kaufman.

Documentation de la fonction/sous-programme

sous-programme slasyf (caractere uplo, entier n, entier nb, entier kb, reelle, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, reelle, dimension( ldw, * ) w, entier ldw, entier info)

SLASYF calcule une factorisation partielle d'une matrice réelle symétrique en utilisant la méthode de pivotement diagonal de Bunch-Kaufman.

Objectif :

!>
!> SLASYF calcule une factorisation partielle d'une matrice réelle symétrique A
!> en utilisant la méthode de pivotement diagonal de Bunch-Kaufman. La factorisation
!> partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L'
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> où l'ordre de D est au plus NB. L'ordre réel est retourné dans
!> l'argument KB, et est soit NB, soit NB-1, soit N si N <= NB.
!>
!> SLASYF est une routine auxiliaire appelée par SSYTRF. Elle utilise du code
!> bloqué (appelant les BLAS de niveau 3) pour mettre à jour la sous-matrice A11 (si UPLO = 'U') ou
!> A22 (si UPLO = 'L').
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure
!>          de la matrice symétrique A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NB

!>          NB est INTEGER
!>          Le nombre maximal de colonnes de la matrice A qui doivent être
!>          factorisées.  NB doit être au moins 2 pour permettre des blocs de pivotement 2x2.
!>

KB

!>          KB est INTEGER
!>          Le nombre de colonnes de A qui ont été effectivement factorisées.
!>          KB est soit NB-1, soit NB, soit N si N <= NB.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire principale n x n de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire principale n x n de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>          En sortie, A contient les détails de la factorisation partielle.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure de bloc de D.
!>
!>          Si UPLO = 'U' :
!>             Seuls les derniers KB éléments de IPIV sont définis.
!>
!>             Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>             échangées et D(k,k) est un bloc diagonal 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, alors les lignes et colonnes
!>             k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k)
!>             est un bloc diagonal 2x2.
!>
!>          Si UPLO = 'L' :
!>             Seuls les premiers KB éléments de IPIV sont définis.
!>
!>             Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>             échangées et D(k,k) est un bloc diagonal 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes
!>             k+1 et -IPIV(k) ont été échangées et D(k:k+1,k:k+1)
!>             est un bloc diagonal 2x2.
!>

W

!>          W est tableau REEL, dimension (LDW,NB)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau W.  LDW >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          > 0 : si INFO = k, D(k,k) est exactement zéro.  La factorisation
!>               a été complétée, mais la matrice bloc diagonale D est
!>               exactement singulière.
!>
