sous-routine slarfx (side, m, n, v, tau, c, ldc, work)
SLARFX applique un réflecteur élémentaire à une matrice rectangulaire générale, avec déroulement de boucle lorsque le réflecteur a un ordre ≤ 10.

Documentation de fonction/sous-routine

sous-routine slarfx (character side, integer m, integer n, real, dimension( * ) v, real tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work)

SLARFX applique un réflecteur élémentaire réel H à une matrice réelle m par n C, par la gauche ou par la droite. H est représenté sous la forme

       H = I - tau * v * v**T

où tau est un scalaire réel et v est un vecteur réel.

Si tau = 0, alors H est considérée comme la matrice unité.

Cette version utilise du code en ligne si H a un ordre < 11.

Objectif :

!>
!> SLARFX applique un réflecteur élémentaire réel H à une matrice réelle m par n
!> C, par la gauche ou par la droite. H est représenté sous la
!> forme
!>
!>       H = I - tau * v * v**T
!>
!> où tau est un scalaire réel et v est un vecteur réel.
!>
!> Si tau = 0, alors H est considérée comme la matrice unité
!>
!> Cette version utilise du code en ligne si H a un ordre < 11.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau REAL, de dimension (M) si SIDE = 'L'
!>                                     ou (N) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H.
!>

TAU

!>          TAU est REAL
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau REAL, de dimension (LDC,N)
!>          En entrée, la matrice C de dimensions m par n.
!>          En sortie, C est écrasée par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= (1,M).
!>

WORK

!>          WORK est un tableau REAL, de dimension
!>                      (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
!>          WORK n'est pas référencé si H a un ordre < 11.
!>
