fonction réelle slamch (caractère cmach)

SLAMCH

Objectif :

!>
!> SLAMCH détermine les paramètres de la machine en simple précision.
!>

Paramètres

CMACH 
!>          CMACH est CHARACTER*1
!>          Spécifie la valeur à retourner par SLAMCH :
!>          = 'E' ou 'e',   SLAMCH := eps
!>          = 'S' ou 's',   SLAMCH := sfmin
!>          = 'B' ou 'b',   SLAMCH := base
!>          = 'P' ou 'p',   SLAMCH := eps*base
!>          = 'N' ou 'n',   SLAMCH := t
!>          = 'R' ou 'r',   SLAMCH := rnd
!>          = 'M' ou 'm',   SLAMCH := emin
!>          = 'U' ou 'u',   SLAMCH := rmin
!>          = 'L' ou 'l',   SLAMCH := emax
!>          = 'O' ou 'o',   SLAMCH := rmax
!>          où
!>          eps   = précision relative de la machine
!>          sfmin = minimum sûr, tel que 1/sfmin ne déborde pas
!>          base  = base de la machine
!>          prec  = eps*base
!>          t     = nombre de chiffres (de base) dans le mantisse
!>          rnd   = 1.0 lorsque l'arrondi se produit à l'addition, 0.0 sinon
!>          emin  = exposant minimum avant le débordement (graduel)
!>          rmin  = seuil de débordement - base**(emin-1)
!>          emax  = plus grand exposant avant le débordement
!>          rmax  = seuil de débordement  - (base**emax)*(1-eps)
!>

Auteur

Univ. du Tennessee

Univ. de Californie à Berkeley

NAG Ltd.
