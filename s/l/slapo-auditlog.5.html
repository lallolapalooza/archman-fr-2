NOM

slapo-auditlog - Superposition d'enregistrement d'audit pour slapd

SYNTAXE

/etc/openldap/slapd.conf

/etc/openldap/slapd.d

DESCRIPTION

La superposition d'enregistrement d'audit (Audit Logging overlay) peut être utilisée pour enregistrer toutes les modifications sur une base de données backend donnée dans un fichier journal spécifié. Les modifications sont enregistrées au format LDIF standard, avec un en-tête de commentaire supplémentaire fournissant six champs d'informations sur la modification. Un deuxième en-tête de commentaire est ajouté à la fin de l'opération pour signaler la fin de la modification.

Pour les opérations d'ajout (Add) et de modification (Modify), l'identité provient de modifiersName associé à l'opération. C'est généralement la même que l'identité du demandeur, mais peut être définie par d'autres superpositions pour refléter d'autres valeurs.

CONFIGURATION

Cette option slapd.conf s'applique à la superposition d'enregistrement d'audit. Elle doit apparaître après la directive overlay.

auditlog <nom_fichier>
Spécifiez le chemin complet du fichier journal.
olcAuditlogFile <nom_fichier>
À utiliser avec cn=config

INFORMATIONS SUR LES CHAMPS DE COMMENTAIRES

Le premier champ est le type d'opération.
Le deuxième champ est l'horodatage de l'opération en secondes depuis l'époque.
Le troisième champ est le suffixe de la base de données.
Le quatrième champ est le modifiersName enregistré.
Le cinquième champ est l'adresse IP d'origine et le port.
Le sixième champ est le numéro de connexion. Un numéro de connexion de -1 indique une opération interne de slapd.

EXEMPLE

Le LDIF suivant pourrait être utilisé pour ajouter cette superposition à cn=config (ajuster selon vos besoins)

dn: olcOverlay=auditlog,olcDatabase={1}mdb,cn=config
changetype: add
objectClass: olcOverlayConfig
objectClass: olcAuditLogConfig
olcOverlay: auditlog
olcAuditlogFile: /tmp/auditlog.ldif

EXEMPLE JOURNAL DES CHANGEMENTS

# modifier 1614223245 dc=example,dc=com cn=admin,dc=example,dc=com IP=[::1]:47270 conn=1002
dn: uid=joepublic,ou=people,dc=example,dc=com
changetype: modify
replace: displayName
displayName: Joe Public
-
replace: entryCSN
entryCSN: 20210225032045.045229Z#000000#001#000000
-
replace: modifiersName
modifiersName: cn=admin,dc=example,dc=com
-
replace: modifyTimestamp
modifyTimestamp: 20210225032045Z
-
# fin modifier 1614223245

répertoire de configuration slapd par défaut
