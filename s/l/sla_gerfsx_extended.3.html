subroutine sla_gerfsx_extended (integer prec_type, integer trans_type, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldy, * ) y, integer ldy, real, dimension( * ) berr_out, integer n_norms, real, dimension( nrhs, * ) errs_n, real, dimension( nrhs, * ) errs_c, real, dimension( * ) res, real, dimension( * ) ayb, real, dimension( * ) dy, real, dimension( * ) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

SLA_GERFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour des matrices générales en effectuant un raffinement itératif avec une précision supplémentaire et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Objectif :

!>
!> SLA_GERFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif avec une précision supplémentaire
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!> Cette sous-routine est appelée par SGERFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur
!> composante par composante maximale si possible. Voir les commentaires pour ERRS_N
!> et ERRS_C pour les détails des bornes d'erreur. Notez que cette
!> sous-routine est uniquement responsable de la définition des seconds champs de
!> ERRS_N et ERRS_C.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est une chaîne de caractères et P
!>          = 'S' : Simple précision
!>          = 'D' : Double précision
!>          = 'I' : Indigène
!>          = 'X' ou 'E' : Extra
!>

TRANS_TYPE

!>          TRANS_TYPE est INTEGER
!>     Spécifie l'opération de transposition sur A.
!>     La valeur est définie par ILATRANS(T) où T est une chaîne de caractères et T
!>          = 'N' : Pas de transposition
!>          = 'T' : Transposée
!>          = 'C' : Transposée conjuguée
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau REAL, de dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau REAL, de dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U tels que calculés par SGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     tels que calculés par SGETRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .TRUE. alors l'équilibrage des colonnes a été effectué sur A avant d'appeler
!>     cette sous-routine. Ceci est nécessaire pour calculer correctement la solution et
!>     les bornes d'erreur.
!>

C

!>          C est un tableau REAL, de dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FALSE., C
!>     n'est pas accédé. Si C est en entrée, chaque élément de C doit être une puissance
!>     de la base pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne provoque pas d'erreurs
!>     d'arrondi, sauf si le résultat sous-flotte ou surflotte. Les erreurs d'arrondi
!>     pendant la mise à l'échelle conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau REAL, de dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

Y

!>          Y est un tableau REAL, de dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par SGETRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y. LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau REAL, de dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur arrière relative composante par
!>     composante pour le j-ème membre de droite, selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par SLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERRS_N
!>     et ERRS_C).
!>     Si N_NORMS >= 1, retourne les bornes d'erreur normwise.
!>     Si N_NORMS >= 2, retourne les bornes d'erreur composante par composante.
!>

ERRS_N

!>          ERRS_N est un tableau REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à l'erreur
!>     relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice dans ERRS_N(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second indice dans ERRS_N(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Numéro de condition réciproque

SYNOPSIS

SUBROUTINE SLA_GERFSX_EXTENDED(
     MATRIX_TRANSPOSE,
     MATRIX_TRANSPOSE_EQUATION,
     N, NRHS, A, LDA, AFAC, LDAFAC, IPIV, B, LDB, X, LDX,
     FERR, BERR, Z, DZ, ERRS_N, ERRS_C, RES, AYB, DY, Y_TAIL,
     RCOND, ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO)

    LOGICAL                      MATRIX_TRANSPOSE, MATRIX_TRANSPOSE_EQUATION, IGNORE_CWISE
    INTEGER                      N, NRHS, LDA, LDAFAC, LDB, LDX, ITHRESH, INFO
    INTEGER                      IPIV( * )
    REAL                         A( LDA, * ), AFAC( LDAFAC, * ), B( LDB, * ),
                                 X( LDX, * ), FERR( * ), BERR( * ), Z( * ),
                                 DZ( * ), ERRS_N( * ), ERRS_C( * ), RES( * ),
                                 AYB( * ), DY( * ), Y_TAIL( * ), RCOND,
                                 RTHRESH, DZ_UB

Function/Subroutine Documentation

SLA_GERFSX_EXTENDED provides detailed error bounds for the solution of a system of linear equations AX=B.

This routine is called by SGETRSX, which computes the solution to a linear system of equations.

Parameters

MATRIX_TRANSPOSE

LOGICAL

      = .TRUE. :   The subroutine computes the scaled and possibly
                   equilibrated error bounds for A'X=B.
      = .FALSE. : The subroutine computes the scaled and possibly
                   equilibrated error bounds for AX=B.
MATRIX_TRANSPOSE_EQUATION

LOGICAL

      = .TRUE. :   The subroutine computes the scaled and possibly
                   equilibrated error bounds for A'X=B.
      = .FALSE. : The subroutine computes the scaled and possibly
                   equilibrated error bounds for AX=B.

These two parameters are only present to allow lazy evaluation of the arguments that are passed through to SGETRF.

N

INTEGER

      The number of linear equations, or the order of the matrix A.
      N >= 0.
NRHS

INTEGER

      The number of right hand sides, i.e. the number of columns of the
      matrices B, X, FERR, and BERR. NRHS >= 0.
A

REAL array, dimension (LDA,N)

      The original coefficient matrix A.
LDA

INTEGER

      The leading dimension of the array A. LDA >= max(1,N).
AFAC

REAL array, dimension (LDAFAC,N)

      The factors L and U from the factorization of A, as computed by SGETRF.
      If MATRIX_TRANSPOSE is .TRUE., then AFAC contains the factors L and U
      from the factorization of A'.
LDAFAC

INTEGER

      The leading dimension of the array AFAC.
      LDAFAC >= max(1,N).
IPIV

INTEGER array, dimension (N)

      The pivot indices from the factorization.
      IPIV[i] = k indicates that the previous matrix was rotated by k
      rows, and that the row k of the original matrix was swapped with
      the row i of the rotated matrix.
B

REAL array, dimension (LDB,NRHS)

      The original right hand side matrix.
LDB

INTEGER

      The leading dimension of the array B. LDB >= max(1,N).
X

REAL array, dimension (LDX,NRHS)

      The solution matrix X to the system of equations AX = B.
      Computed by SGETRS.
LDX

INTEGER

      The leading dimension of the array X. LDX >= max(1,N).
FERR

REAL array, dimension (NRHS)

      The estimated forward error bounds for each right-hand side in the
      solution matrix X. If AX = B, then FERR(i) is an estimate of the
      relative error in the ith column of X, and is given by
      max(abs(X(j,i) - XTRUE(j,i)) / abs(X(j,i))).
      The error estimate is computed without scaling and pivoting.
BERR

REAL array, dimension (NRHS)

      The estimated backward error bounds for each right-hand side in the
      solution matrix X. If AX = B, then BERR(i) is an estimate of the
      relative error in the ith column of X, and is given by
      max(abs(X(j,i) - XTRUE(j,i)) / abs(X(j,i))).
      The error estimate is computed without scaling and pivoting.
Z

REAL array, dimension (N)

      Workspace for the scaled vector.
DZ

REAL array, dimension (N)

      Workspace for the scaled vector.
ERRS_N

REAL array, dimension (NRHS, N_ERR_BNDS)

      For each right hand side, this array contains information about
      various error bounds and condition numbers corresponding to the
      normwise relative error, which is defined as follows:
      Normwise relative error:
                     norm(XTRUE - X, inf)
              ---------------------------
                     norm(X, inf)
      The array is indexed by the right hand side i (on which the
      normwise relative error depends), and the type of error
      information as described below. There currently are up to three
      pieces of information returned for each right hand side. If
      normwise accuracy is not requested (PARAMS(3) = 0.0), then
      ERRS_N is not accessed. If N_ERR_BNDS < 3, then at most
      the first (:,N_ERR_BNDS) entries are returned.
      The first index in ERRS_N(i,:) corresponds to the ith
      right-hand side.
      The second index in ERRS_N(:,err) contains the following
      three fields:
      err = 1  boolean. Trust the answer if the
               reciprocal condition number is less than the threshold
               sqrt(n) * slamch('Epsilon').
      err = 2  error bound: The estimated forward error,
               almost certainly within a factor of 10 of the true error
               so long as the next entry is greater than the threshold
               sqrt(n) * slamch('Epsilon'). This error bound should only
               be trusted if the previous boolean is true.
      err = 3  Reciprocal condition number: Estimated normwise
               reciprocal condition number. Compared with the threshold
               sqrt(n) * slamch('Epsilon') to determine if the error
               estimate is . These reciprocal condition
               numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
               appropriately scaled matrix Z.
               Let Z = S*A, where S scales each row by a power of the
               radix so all absolute row sums of Z are approximately 1.
      This subroutine is only responsible for setting the second field
      above.
      See Lapack Working Note 165 for further details and extra
      cautions.
ERRS_C

REAL array, dimension (NRHS, N_ERR_BNDS)

      For each right-hand side, this array contains information about
      various error bounds and condition numbers corresponding to the
      componentwise relative error, which is defined as follows:
      Componentwise relative error in the ith solution vector:
                     abs(XTRUE(j,i) - X(j,i))
              max_j ----------------------
                         abs(X(j,i))
      The array is indexed by the right-hand side i (on which the
      componentwise relative error depends), and the type of error
      information as described below. There currently are up to three
      pieces of information returned for each right-hand side. If
      componentwise accuracy is not requested (PARAMS(3) = 0.0), then
      ERRS_C is not accessed. If N_ERR_BNDS < 3, then at most
      the first (:,N_ERR_BNDS) entries are returned.
      The first index in ERRS_C(i,:) corresponds to the ith
      right-hand side.
      The second index in ERRS_C(:,err) contains the following
      three fields:
      err = 1  boolean. Trust the answer if the
               reciprocal condition number is less than the threshold
               sqrt(n) * slamch('Epsilon').
      err = 2  error bound: The estimated forward error,
               almost certainly within a factor of 10 of the true error
               so long as the next entry is greater than the threshold
               sqrt(n) * slamch('Epsilon'). This error bound should only
               be trusted if the previous boolean is true.
      err = 3  Reciprocal condition number: Estimated componentwise
               reciprocal condition number. Compared with the threshold
               sqrt(n) * slamch('Epsilon') to determine if the error
               estimate is . These reciprocal condition
               numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
               appropriately scaled matrix Z.
               Let Z = S*(A*diag(x)), where x is the solution for the
               current right-hand side and S scales each row of
               A*diag(x) by a power of the radix so all absolute row
               sums of Z are approximately 1.
      This subroutine is only responsible for setting the second field
      above.
      See Lapack Working Note 165 for further details and extra
      cautions.
RES

REAL array, dimension (N)

      Workspace to hold the intermediate residual.
AYB

REAL array, dimension (N)

      Workspace. This can be the same workspace passed for Y_TAIL.
DY

REAL array, dimension (N)

      Workspace to hold the intermediate solution.
Y_TAIL

REAL array, dimension (N)

      Workspace to hold the trailing bits of the intermediate solution.
RCOND

REAL

      Reciprocal scaled condition number. This is an estimate of the
      reciprocal Skeel condition number of the matrix A after
      equilibration (if done). If this is less than the machine
      precision (in particular, if it is zero), the matrix is singular
      to working precision. Note that the error may still be small even
      if this number is very small and the matrix appears ill-
      conditioned.
ITHRESH

INTEGER

      The maximum number of residual computations allowed for
      refinement. The default is 10. For 'aggressive' set to 100 to
      permit convergence using approximate factorizations or
      factorizations other than LU. If the factorization uses a
      technique other than Gaussian elimination, the guarantees in
      ERRS_N and ERRS_C may no longer be trustworthy.
RTHRESH

REAL

      Determines when to stop refinement if the error estimate stops
      decreasing. Refinement will stop when the next solution no longer
      satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
      the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
      default value is 0.5. For 'aggressive' set to 0.9 to permit
      convergence on extremely ill-conditioned matrices. See LAWN 165
      for more details.
DZ_UB

REAL

      Determines when to start considering componentwise convergence.
      Componentwise convergence is only considered after each component
      of the solution Y is stable, which we define as the relative
      change in each component being less than DZ_UB. The default value
      is 0.25, requiring the first bit to be stable. See LAWN 165 for
      more details.
IGNORE_CWISE

LOGICAL

      If .TRUE. then ignore componentwise convergence. Default value
      is .FALSE..
INFO

INTEGER

      = 0:  Successful exit.
      < 0:  if INFO = -i, the ith argument to SGETRS had an illegal
            value
