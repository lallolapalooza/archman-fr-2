Documentation de la fonction/sous-routine

sous-routine slamrg (entier n1, entier n2, réel, dimension( * ) a, entier strd1, entier strd2, entier, dimension( * ) index)

SLAMRG crée une liste de permutation pour fusionner les entrées de deux ensembles triés indépendamment en un seul ensemble trié par ordre croissant.

Objectif :

!>
!> SLAMRG créera une liste de permutation qui fusionnera les éléments
!> de A (qui est composé de deux ensembles triés indépendamment) en un
!> ensemble unique qui est trié par ordre croissant.
!>

Paramètres

N1 
!>          N1 est un ENTIER
!>

N2

!>          N2 est un ENTIER
!>         Ces arguments contiennent les longueurs respectives des deux
!>         listes triées à fusionner.
!>

A

!>          A est un tableau REEL, dimension (N1+N2)
!>         Les N1 premiers éléments de A contiennent une liste de nombres
!>         qui sont triés par ordre croissant ou décroissant. Il en va de
!>         même pour les N2 derniers éléments.
!>

STRD1

!>          STRD1 est un ENTIER
!>

STRD2

!>          STRD2 est un ENTIER
!>         Ce sont les pas à suivre dans le tableau A.
!>         Les pas autorisés sont 1 et -1. Ils indiquent si un sous-ensemble
!>         de A est trié par ordre croissant (STRDx = 1) ou décroissant
!>         (STRDx = -1).
!>

INDEX

!>          INDEX est un tableau ENTIER, dimension (N1+N2)
!>         À la sortie, ce tableau contiendra une permutation telle que
!>         si B( I ) = A( INDEX( I ) ) pour I=1,N1+N2, alors B sera
!>         trié par ordre croissant.
!>
