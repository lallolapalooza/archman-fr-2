SLAPD-PERL(5) Manuel des formats de fichiers SLAPD-PERL(5)

NOM

slapd-perl - Backend Perl pour slapd

SYNTAXE

/etc/openldap/slapd.conf

DESCRIPTION

Le backend Perl de slapd(8) fonctionne en intégrant un interpréteur perl(1) dans slapd(8). Toute section de base de données perl du fichier de configuration slapd.conf(5) doit alors spécifier quel module Perl utiliser. Slapd crée ensuite un nouvel objet Perl qui gère toutes les requêtes pour cette instance particulière du backend.

Vous devrez créer une méthode pour chacune des actions suivantes :

  * new        # crée un nouvel objet,
  * search     # effectue la recherche ldap,
  * compare    # effectue une comparaison,
  * modify     # modifie une entrée,
  * add        # ajoute une entrée au backend,
  * modrdn     # modifie le rdn d'une entrée,
  * delete     # supprime une entrée ldap,
  * config     # directives de configuration spécifiques au module,
  * init       # appelé après l'initialisation du backend.

Sauf indication contraire, les méthodes retournent le code de résultat qui sera renvoyé au client. Les actions non implémentées peuvent simplement retourner unwillingToPerform (53).

new
Cette méthode est appelée lorsque le fichier de configuration rencontre une ligne perlmod. Le module de cette ligne est ensuite effectivemment `use'd dans l'interpréteur perl, puis la méthode new est appelée pour créer un nouvel objet. Notez que plusieurs instances de cet objet peuvent être instanciées, comme pour tout objet perl. La méthode new reçoit le nom de la classe comme argument.
search
Cette méthode est appelée lorsqu'une requête de recherche provient d'un client. Ses arguments sont les suivants : 
  * référence d'objet
  * DN de base
  * portée
  * politique de déférencement des alias
  * limite de taille
  * limite de temps
  * chaîne de filtre
  * indicateur d'attributs uniquement (1 si oui)
  * liste d'attributs à retourner (peut être vide)

Valeur de retour : (codé_résultat, entrée_ldif, entrée_ldif, ...)

compare
Cette méthode est appelée lorsqu'une requête de comparaison provient d'un client. Ses arguments sont les suivants. 
  * référence d'objet
  * dn
  * chaîne d'assertion d'attribut
modify
Cette méthode est appelée lorsqu'une requête de modification provient d'un client. Ses arguments sont les suivants. 
  * référence d'objet
  * dn
  * une liste formatée comme suit
    ({ "ADD" | "DELETE" | "REPLACE" },
     type_attribut, valeur...)...
add
Cette méthode est appelée lorsqu'une requête d'ajout provient d'un client. Ses arguments sont les suivants. 
  * référence d'objet
  * entrée au format chaîne
modrdn
Cette méthode est appelée lorsqu'une requête modrdn provient d'un client. Ses arguments sont les suivants. 
  * référence d'objet
  * dn
  * nouveau rdn
  * indicateur de suppression de l'ancien dn (1 signifie oui)
delete
Cette méthode est appelée lorsqu'une requête de suppression provient d'un client. Ses arguments sont les suivants. 
  * référence d'objet
  * dn
config
Cette méthode est appelée une fois pour chaque ligne perlModuleConfig dans le fichier de configuration slapd.conf(5). Ses arguments sont les suivants. 
  * référence d'objet
  * tableau d'arguments sur la ligne

Valeur de retour : non nul si ce n'est pas une option valide.

init
Cette méthode est appelée après l'initialisation du backend. Son argument est le suivant. 
  * référence d'objet

Valeur de retour : non nul si l'initialisation a échoué.

CONFIGURATION

Ces options de slapd.conf s'appliquent à la base de données du backend PERL. C'est-à-dire qu'elles doivent suivre une ligne "database perl" et précéder toute ligne "backend" ou "database" ultérieure. Les autres options de base de données sont décrites dans la page de manuel slapd.conf(5).

perlModulePath /chemin/vers/libs
Ajoute le chemin à la variable @INC.
perlModule NomMod
`Utilise' le nom du module NomMod à partir de NomMod.pm
filterSearchResults
Les résultats de recherche sont des candidats qui doivent être filtrés (avec le filtre de la requête de recherche), plutôt que des résultats de recherche à retourner directement au client.
perlModuleConfig <arguments>
Appelle la méthode config du module avec les arguments donnés.

EXEMPLE

Il existe un exemple de module Perl `SampleLDAP' dans le répertoire slapd/back-perl/ de l'arborescence source OpenLDAP.

CONTRÔLE ACCÈS

Le backend perl n'honore aucune des sémantiques de contrôle d'accès décrites dans slapd.access(5) ; tout le contrôle d'accès est délégué au script PERL sous-jacent. Seul l'accès en lecture (=r) à l'attribut pseudo-entry et aux autres valeurs d'attribut des entrées retournées par l'opération search est honoré, ce qui est effectué par le frontend.

AVERTISSEMENT

L'interface de ce backend avec le module perl PEUT changer. Toute suggestion serait grandement appréciée.

Note : dans les versions précédentes, toutes les lignes non reconnues dans le fichier slapd.conf étaient passées à la méthode config du module perl. Ce comportement est déprécié (mais toujours autorisé pour des raisons de compatibilité ascendante), et la directive perlModuleConfig doit plutôt être utilisée pour appeler la méthode config du module. Cette fonctionnalité de compatibilité sera supprimée à une date ultérieure.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration slapd par défaut

VOIR AUSSI

slapd.conf(5), slapd(8), perl(1).
