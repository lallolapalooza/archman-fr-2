NOM

slapo-sssvlv - Superposition côté serveur pour le tri et la vue de liste virtuelle de slapd

SYNTAXE

/etc/openldap/slapd.conf

DESCRIPTION

Cette superposition implémente le contrôle LDAP Server Side Sorting (RFC2891) ainsi que le contrôle Virtual List View. Elle remplace également l'implémentation par défaut du contrôle LDAP PagedResults (RFC2696) pour garantir qu'il fonctionne avec le tri. La superposition peut être utilisée avec n'importe quel backend ou globalement pour tous les backends.

Étant donné qu'un ensemble complet de résultats doit être généré en mémoire avant que le tri puisse être effectué, le traitement des requêtes de tri peut avoir un impact important sur l'utilisation de la mémoire du serveur. Par conséquent, chaque connexion est limitée à un nombre limité de requêtes de tri actives à la fois. Des limites supplémentaires peuvent être configurées comme décrit ci-dessous.

CONFIGURATION

Ces options slapd.conf s'appliquent à la superposition SSSVLV. Elles doivent apparaître après la directive overlay.

sssvlv-max <nombre>
Définit le nombre maximum de requêtes de tri simultanées autorisées sur toutes les connexions. La valeur par défaut est la moitié du nombre de threads du serveur.
sssvlv-maxkeys <nombre>
Définit le nombre maximum de clés autorisées dans une requête de tri. La valeur par défaut est 5.
sssvlv-maxperconn <nombre>
Définit le nombre maximum de requêtes de recherche paginées simultanées par connexion. La valeur par défaut est 5. Le nombre de requêtes simultanées reste limité par sssvlv-max.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd
/etc/openldap/slapd.d
répertoire de configuration par défaut de slapd
