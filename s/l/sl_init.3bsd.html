stringlist(3bsd) 3bsd stringlist(3bsd)

NOM

stringlist, sl_init, sl_add, sl_free, sl_find, sl_delete — fonctions de manipulation de listes de chaînes

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <stringlist.h> (Voir libbsd(7) pour l'utilisation de l'include.)
StringList *
sl_init(void);

int
sl_add(StringList *sl, char *item);

void
sl_free(StringList *sl, int freeall);

char *
sl_find(StringList *sl, const char *item);

int
sl_delete(StringList *sl, const char *item, int freeit);

DESCRIPTION

Les fonctions stringlist manipulent des listes de chaînes, qui sont des listes de chaînes qui s'étendent automatiquement si nécessaire.

La structure StringList a la définition suivante :

typedef struct _stringlist {
	char	**sl_str;
	size_t	  sl_max;
	size_t	  sl_cur;
} StringList;

où :

sl_str
est un pointeur vers la base du tableau contenant la liste,
sl_max
est la taille de sl_str, et
sl_cur
est le décalage dans sl_str de l'élément courant.

Les fonctions de manipulation de listes de chaînes suivantes sont disponibles :

sl_init()
Crée une liste de chaînes. Retourne un pointeur vers une StringList, ou NULL en cas d'échec.
sl_free()
Libère la mémoire occupée par sl et le tableau sl->sl_str. Si freeall est non nul, alors chaque élément de sl->sl_str est également libéré.
sl_add()
Ajoute item à sl->sl_str à sl->sl_cur, en étendant la taille de sl->sl_str. Retourne zéro en cas de succès, -1 en cas d'échec.
sl_find()
Recherche item dans sl, en retournant NULL s'il n'est pas trouvé.
sl_delete()
Supprime item de la liste. Si freeit est non nul, la chaîne est libérée. Retourne 0 si le nom est trouvé et -1 si le nom n'est pas trouvé.

VOIR AUSSI

free(3), malloc(3)

HISTORIQUE

Les fonctions stringlist sont apparues dans FreeBSD 2.2.6 et NetBSD 1.3.
