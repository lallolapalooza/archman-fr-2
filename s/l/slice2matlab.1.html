NOM

slice2matlab - Le compilateur Slice vers MATLAB.

SYNTAXE

slice2matlab [options] [fichiers]

DESCRIPTION

slice2matlab compile les fichiers Slice vers MATLAB. La macro __SLICE2MATLAB__ est définie pendant cette compilation.

La documentation complète de slice2matlab est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/language-mappings/matlab-mapping/client-side-slice-to-matlab-mapping/slice2matlab-command-line-options

OPTIONS

-h, --help

Affiche un message d'aide.
-v, --version
Affiche la version du compilateur.
-DNAME

Définit le symbole de préprocesseur NAME.
-DNAME=DEF

Définit le symbole de préprocesseur NAME avec la valeur DEF.
-UNAME

Annule la définition du symbole de préprocesseur NAME.
-IDIR

Ajoute le répertoire DIR au chemin de recherche des directives #include.
-E

Affiche la sortie du préprocesseur sur stdout.
--output-dir DIR

Place les fichiers générés dans le répertoire DIR.
-d, --debug

Affiche des informations de débogage montrant le fonctionnement de l'analyseur Slice.
--depend

Affiche les informations de dépendance sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-xml

Affiche les informations de dépendance au format XML sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-file FILE

Dirige les informations de dépendance vers le fichier spécifié. Le format de sortie dépend si --depend ou --depend-xml est également spécifié.
--validate

Vérifie la correction des options de ligne de commande fournies et ne génère aucun code.
--all

Génère du code pour toutes les définitions Slice, y compris celles des fichiers inclus.
--list-generated

Émet une liste des fichiers générés au format XML.
