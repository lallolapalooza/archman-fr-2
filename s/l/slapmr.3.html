sous-programme slapmr (logical forwrd, integer m, integer n, real, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

SLAPMR réorganise les lignes d'une matrice selon un vecteur de permutation.

Objectif :

!>
!> SLAPMR réorganise les lignes de la matrice M par N, X, selon la
!> permutation K(1),K(2),...,K(M) des entiers 1,...,M.
!> Si FORWRD = .VRAI., permutation avant :
!>
!>      X(K(I),*) est déplacé vers X(I,*) pour I = 1,2,...,M.
!>
!> Si FORWRD = .FAUX., permutation arrière :
!>
!>      X(I,*) est déplacé vers X(K(I),*) pour I = 1,2,...,M.
!>

Paramètres

FORWRD 
!>          FORWRD est LOGICAL
!>          = .VRAI., permutation avant
!>          = .FAUX., permutation arrière
!>

M

!>          M est un ENTIER
!>          Le nombre de lignes de la matrice X. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice X. N >= 0.
!>

X

!>          X est un tableau de REEL, dimension (LDX,N)
!>          À l'entrée, la matrice M par N, X.
!>          À la sortie, X contient la matrice permutée X.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X, LDX >= MAX(1,M).
!>

K

!>          K est un tableau d'ENTIERS, dimension (M)
!>          À l'entrée, K contient le vecteur de permutation. K est utilisé
!>          comme espace de travail interne, mais est remis à sa valeur
!>          originale à la sortie.
!>
