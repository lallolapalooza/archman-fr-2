subroutine slacon (integer n, real, dimension( * ) v, real, dimension( * ) x, integer, dimension( * ) isgn, real est, integer kase)

SLACON estime la 1-norme d'une matrice carrée réelle, en utilisant la communication inverse pour évaluer les produits matrice-vecteur.

Objectif :

!>
!> SLACON estime la 1-norme d'une matrice carrée réelle A.
!> La communication inverse est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est un ENTIER
!>         L'ordre de la matrice.  N >= 1.
!>

V

!>          V est un tableau REEL, dimension (N)
!>         Lors du retour final, V = A*W,  où  EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau REEL, dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**T * X,  si KASE=2,
!>         et SLACON doit être rappelé avec tous les autres paramètres
!>         inchangés.
!>

ISGN

!>          ISGN est un tableau ENTIER, dimension (N)
!>

EST

!>          EST est un REEL
!>         À l'entrée avec KASE = 1 ou 2 et JUMP = 3, EST doit être
!>         inchangé depuis l'appel précédent à SLACON.
!>         À la sortie, EST est une estimation (une borne inférieure) pour norm(A).
!>

KASE

!>          KASE est un ENTIER
!>         Lors de l'appel initial à SLACON, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**T * X.
!>         Lors du retour final de SLACON, KASE sera à nouveau 0.
!>
