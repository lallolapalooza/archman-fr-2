sous-routine slasd6 (integer icompq, integer nl, integer nr, integer sqre, real, dimension( * ) d, real, dimension( * ) vf, real, dimension( * ) vl, real alpha, real beta, integer, dimension( * ) idxq, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, real, dimension( ldgnum, * ) givnum, integer ldgnum, real, dimension( ldgnum, * ) poles, real, dimension( * ) difl, real, dimension( * ) difr, real, dimension( * ) z, integer k, real c, real s, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLASD6 calcule la SVD d'une matrice bidimensionnelle supérieure mise à jour obtenue en fusionnant deux matrices plus petites par l'ajout d'une ligne. Utilisé par sbdsdc.

Objectif :

!>
!> SLASD6 calcule la SVD d'une matrice bidimensionnelle supérieure mise à jour B
!> obtenue en fusionnant deux matrices plus petites par l'ajout d'une ligne. Cette
!> sous-routine est utilisée uniquement pour le problème qui exige toutes les valeurs singulières
!> et éventuellement des matrices de vecteurs singuliers sous forme factorisée.
!> B est une matrice N x M avec N = NL + NR + 1 et M = N + SQRE.
!> Une sous-routine connexe, SLASD1, gère le cas où toutes les valeurs singulières
!> et tous les vecteurs singuliers de la matrice bidimensionnelle sont désirés.
!>
!> SLASD6 calcule la SVD comme suit :
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> où Z**T = (Z1**T a Z2**T b) = u**T VT**T, et u est un vecteur de dimension M
!> avec ALPHA et BETA dans les entrées NL+1 et NL+2 et des zéros
!> ailleurs ; et l'entrée b est vide si SQRE = 0.
!>
!> Les valeurs singulières de B peuvent être calculées en utilisant D1, D2, les premières
!> composantes de tous les vecteurs singuliers droits du bloc inférieur, et
!> les dernières composantes de tous les vecteurs singuliers droits du bloc supérieur.
!> Ces composantes sont stockées et mises à jour dans VF et VL,
!> respectivement, dans SLASD6. Par conséquent, U et VT ne sont pas explicitement
!> référencés.
!>
!> Les valeurs singulières sont stockées dans D. L'algorithme consiste en deux
!> étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a plusieurs valeurs singulières ou s'il y a un zéro
!>       dans le vecteur Z. Pour chaque occurrence, la dimension de
!>       l'équation séculaire est réduite de un. Cette étape est
!>       réalisée par la routine SLASD7.
!>
!>       La deuxième étape consiste à calculer les valeurs singulières
!>       mises à jour. Ceci est fait en trouvant les racines de
!>       l'équation séculaire via la routine SLASD4 (appelée par SLASD8).
!>       Cette routine met également à jour VF et VL et calcule les distances
!>       entre les valeurs singulières mises à jour et les anciennes valeurs
!>       singulières.
!>
!> SLASD6 est appelée depuis SLASDA.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un entier
!>         Spécifie si les vecteurs singuliers doivent être calculés sous
!>         forme factorisée :
!>         = 0 : Calculer uniquement les valeurs singulières.
!>         = 1 : Calculer également les vecteurs singuliers sous forme factorisée.
!>

NL

!>          NL est un entier
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est un entier
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est un entier
!>         = 0 : le bloc inférieur est une matrice carrée NR x NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR x (NR+1).
!>
!>         La matrice bidimensionnelle a une dimension de ligne N = NL + NR + 1,
!>         et une dimension de colonne M = N + SQRE.
!>

D

!>          D est un tableau de réels, de dimension (NL+NR+1).
!>         À l'entrée, D(1:NL,1:NL) contient les valeurs singulières du
!>         bloc supérieur, et D(NL+2:N) contient les valeurs singulières
!>         du bloc inférieur. À la sortie, D(1:N) contient les valeurs singulières
!>         de la matrice modifiée.
!>

VF

!>          VF est un tableau de réels, de dimension (M)
!>         À l'entrée, VF(1:NL+1) contient les premières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VF(NL+2:M)
!>         contient les premières composantes de tous les vecteurs singuliers droits
!>         du bloc inférieur. À la sortie, VF contient les premières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidimensionnelle.
!>

VL

!>          VL est un tableau de réels, de dimension (M)
!>         À l'entrée, VL(1:NL+1) contient les dernières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VL(NL+2:M)
!>         contient les dernières composantes de tous les vecteurs singuliers droits
!>         du bloc inférieur. À la sortie, VL contient les dernières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidimensionnelle.
!>

ALPHA

!>          ALPHA est un réel
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est un réel
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

IDXQ

!>          IDXQ est un tableau d'entiers, de dimension (N)
!>         Contient la permutation qui réintégrera le sous-problème qui vient
!>         d'être résolu dans l'ordre trié, c'est-à-dire
!>         D( IDXQ( I = 1, N ) ) sera en ordre croissant.
!>

PERM

!>          PERM est un tableau d'entiers, de dimension ( N )
!>         Les permutations (provenant de la déflation et du tri) à appliquer
!>         à chaque bloc. Non utilisé si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR est un entier
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème. Non utilisé si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL est un tableau d'entiers, de dimension ( LDGCOL, 2 )
!>         Chaque paire de nombres indique une paire de colonnes pour participer
!>         à une rotation de Givens. Non utilisé si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL est un entier
!>         Dimension de tête de GIVCOL, doit être au moins N.
!>

GIVNUM

!>          GIVNUM est un tableau de réels, de dimension ( LDGNUM, 2 )
!>         Chaque nombre indique la valeur C ou S à utiliser dans la
!>         rotation de Givens correspondante. Non utilisé si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM est un entier
!>         La dimension de tête de GIVNUM et POLES, doit être au moins N.
!>

POLES

!>          POLES est un tableau de réels, de dimension ( LDGNUM, 2 )
!>         À la sortie, POLES(1,*) est un tableau contenant les nouvelles valeurs
!>         singulières obtenues en résolvant l'équation séculaire, et
!>         POLES(2,*) est un tableau contenant les pôles dans l'équation
!>         séculaire. Non utilisé si ICOMPQ = 0.
!>

DIFL

!>          DIFL est un tableau de réels, de dimension ( N )
!>         À la sortie, DIFL(I) est la distance entre la I-ème mise à jour
!>

Fonction/Documentation de sous-routine

SLASD6 compute the solution to the 1-dimensional secular equation
(D - SIGMA)**(-1) * B + Z = 0

where the D array is diagonal, and B and Z are vectors.

All the singularities are permanent. No deflation is applied at the level of this routine.

Returns:

  • If ICOMPQ = 0, the subarray D(1:K) contains the singular values.
  • If ICOMPQ = 1, D(1:K) contains the singular values and Q(1:M,1:K) contains the right singular vectors.

Arguments:

IWORK

IWORK is INTEGER array, dimension ( 3 * N )

Local workspace for IWORK.

ALPHA

ALPHA is REAL

It is the slant-top of the secular equation.

B

B is REAL

It is the value of the second row of the matrix.

C

C is REAL

It contains garbage if SQRE =0 and the C-value of a Givens rotation related to the right null space if SQRE = 1.

D

D is REAL array, dimension ( N ). On entry, D contains the off-diagonal entries of the matrix. On exit, D contains the singular values, sorted in ascending order.

E

E is REAL array, dimension ( N ). On entry, E contains the diagonal entries of the matrix. On exit, E contains the off-diagonal entries of the updated matrix.

Q

Q is REAL array, dimension ( LDDQ, K ). On exit, Q contains the desired right singular vectors. If ICOMPQ = 0, Q is not used.

WORK

WORK is REAL array, dimension ( 4 * M )

Z

Z is REAL array, dimension ( M ). The first elements of this array contain the components of the deflation-adjusted updating row vector.

INFO

INFO is INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = 1, a singular value did not converge
