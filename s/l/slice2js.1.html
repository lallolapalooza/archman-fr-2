slice2js(1) Manuel des commandes générales slice2js(1)

NOM

slice2js - Le compilateur Slice vers JavaScript.

SYNTAXE

slice2js [options] [fichiers]

DESCRIPTION

slice2js compile les fichiers Slice en JavaScript. La macro __SLICE2JS__ est définie pendant cette compilation.

La documentation complète de slice2js est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/language-mappings/javascript-mapping/client-side-slice-to-javascript-mapping/slice2js-command-line-options

OPTIONS

-h, --help

Affiche le message d'aide.
-v, --version
Affiche la version du compilateur.
-DNAME

Définit le symbole du préprocesseur NAME.
-DNAME=DEF

Définit le symbole du préprocesseur NAME avec la valeur DEF.
-UNAME

Annule la définition du symbole du préprocesseur NAME.
-IDIR

Ajoute le répertoire DIR au chemin de recherche pour les directives #include.
-E

Affiche la sortie du préprocesseur sur stdout.
--output-dir DIR

Place les fichiers générés dans le répertoire DIR.
-d, --debug

Affiche des informations de débogage montrant le fonctionnement de l'analyseur Slice.
--depend

Affiche les informations de dépendance sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-xml

Affiche les informations de dépendance au format XML sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-file FILE

Dirige les informations de dépendance vers le fichier spécifié. Le format de sortie dépend de la spécification de --depend ou --depend-xml.
--depend-json

Affiche les informations de dépendance au format JSON sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--validate

Vérifie la correction des options de ligne de commande fournies, et ne génère aucun code.
--stdout

Affiche le code généré sur la sortie standard.
--typescript

Génère des fichiers de déclaration TypeScript.
