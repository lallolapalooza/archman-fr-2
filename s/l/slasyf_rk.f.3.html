subroutine slasyf_rk (uplo, n, nb, kb, a, lda, e, ipiv, w, ldw, info)
SLASYF_RK calcule une factorisation partielle d'une matrice réelle symétrique indéfinie en utilisant la méthode de pivotement diagonal bornée de Bunch-Kaufman (rook).

Documentation de la fonction/sous-programme

sous-programme slasyf_rk (caractère uplo, entier n, entier nb, entier kb, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) e, entier, dimension( * ) ipiv, réel, dimension( ldw, * ) w, entier ldw, entier info)

SLASYF_RK calcule une factorisation partielle d'une matrice réelle symétrique indéfinie en utilisant la méthode de pivotement diagonal bornée de Bunch-Kaufman (rook).

Objectif :

!> SLASYF_RK calcule une factorisation partielle d'une matrice réelle
!> symétrique A en utilisant la méthode de pivotement diagonal bornée de Bunch-Kaufman (rook).
!> La factorisation partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L',
!>       ( L21  I ) (  0   A22 ) (  0       I    )
!>
!> où l'ordre de D est au plus NB. L'ordre réel est retourné dans
!> l'argument KB, et est soit NB, soit NB-1, soit N si N <= NB.
!>
!> SLASYF_RK est une routine auxiliaire appelée par SSYTRF_RK. Elle utilise
!> du code bloc (appelant le BLAS de niveau 3) pour mettre à jour la sous-matrice
!> A11 (si UPLO = 'U') ou A22 (si UPLO = 'L').
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

NB

!>          NB est INTEGER
!>          Nombre maximum de colonnes de la matrice A qui doivent être
!>          factorisées.  NB doit être au moins 2 pour permettre des blocs de pivot
!>          de taille 2x2.
!>

KB

!>          KB est INTEGER
!>          Nombre de colonnes de A qui ont été effectivement factorisées.
!>          KB est soit NB-1, soit NB, soit N si N <= NB.
!>

A

!>          A est un tableau REEL de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.
!>            Si UPLO = 'U' : la partie triangulaire supérieure N x N principale
!>            de A contient la partie triangulaire supérieure de la matrice A,
!>            et la partie strictement triangulaire inférieure de A n'est pas
!>            référencée.
!>
!>            Si UPLO = 'L' : la partie triangulaire inférieure N x N principale
!>            de A contient la partie triangulaire inférieure de la matrice A,
!>            et la partie strictement triangulaire supérieure de A n'est pas
!>            référencée.
!>
!>          À la sortie, contient :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice bloc diagonale symétrique
!>               D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments superdiagonaux (ou sous-diagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : facteur L dans la partie sous-diagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau REEL de dimension (N)
!>          À la sortie, contient les éléments superdiagonaux (ou sous-diagonaux)
!>          de la matrice bloc diagonale symétrique D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal de 1x1, D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux
!>          cas UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau INTEGER de dimension (N)
!>          IPIV décrit la matrice de permutation P dans la factorisation
!>          de la matrice A comme suit. La valeur absolue de IPIV(k)
!>          représente l'indice de la ligne et de la colonne qui ont été
!>          échangées avec la k-ième ligne et colonne. La valeur de UPLO
!>          décrit l'ordre dans lequel les échanges ont été appliqués.
!>          De plus, le signe de IPIV représente la structure de bloc
!>          de la matrice bloc diagonale symétrique D avec des blocs diagonaux
!>          de 1x1 ou 2x2 qui correspondent à 1 ou 2 échanges
!>          à chaque étape de factorisation.
!>
!>          Si UPLO = 'U',
!>          (dans l'ordre de factorisation, k décroît de N à 1) :
!>            a) Une entrée positive unique IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k-1) < 0 signifie :
!>               D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent QUE par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k-1) != k-1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la sous-matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), on a toujours ABS( IPIV(k) ) <= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>
!>          Si UPLO = 'L',
!>          (dans l'ordre de factorisation, k augmente de 1 à N) :
!>            a) Une entrée positive unique IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,1:KB).
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k+1) < 0 signifie :
!>               D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent QUE par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k+1) != k+1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), on a toujours ABS( IPIV(k) ) >= k.
!>
!>            d) NOTE : Toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>

W

!>          W est un tableau REEL de dimension (LDW,NB)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau W.  LDW >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>
!>          < 0 : Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient tous des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient tous des zéros.
!>
!>               Par conséquent, D(k,k) est exactement zéro, et les éléments
!>               superdiagonaux de la colonne k de U (ou sous-diagonaux de
!>               la colonne k de L) sont tous des zéros. La factorisation a
!>               été complé

SUBROUTINE SLASYF_RK(
     UPLO, N, NB, A, LDA, KB, SEGOPT, INFO )

  CHARACTER(LEN=1) :: UPLO
  INTEGER :: N, NB, KB, INFO
  REAL    :: A( LDA, * )
  LOGICAL :: SEGOPT( * )

Function/Subroutine Documentation

!>
!> @brief
!> SLASYF_RK computes the factorization of a real general
!> rectangular matrix $A$ in the form
!>
!>    $A = P \cdot R \cdot Q^T$
!>
!> where $U$ is upper triangular, and $P$ and $Q$ are orthogonal matrices.
!>
!> @param[in] UPLO
!>          CHARACTER*1. Specifies whether the matrix $A$ is upper or lower
!>          triangular.
!>          = 'U': Upper triangular;
!>          = 'L': Lower triangular.
!>
!> @param[in] N
!>          INTEGER. The order of the matrix $A$. $N \ge 0$.
!>
!> @param[in] NB
!>          INTEGER. The blocking size for the factorization.
!>
!> @param[in,out] A
!>          REAL array, dimension (LDA, N). On entry, the matrix $A$.
!>          On exit, the upper or lower triangular part of $A$ is
!>          replaced by the factors $U$ and the information needed to
!>          the orthogonal transformations $P$ and $Q$ represented by
!>          segregated segments of $A$.
!>
!> @param[in] LDA
!>          INTEGER. The leading dimension of the array $A$. $LDA \ge \max(1, N)$.
!>
!> @param[out] KB
!>          INTEGER. The number of segments in the segregation block.
!>
!> @param[out] SEGOPT
!>          LOGICAL array, dimension (N).
!>
!> @param[out] INFO
!>          INTEGER.
!>          = 0: successful exit.
!>          > 0: if INFO = i, the block diagonal matrix D of the block
!>               triangular factorization is exactly singular. The
!>               singular index is i.
!>
!>
!> @author Univ. of Tennessee, Univ. of California Berkeley, Univ. of
!> Colorado Denver, NAG Ltd.
!>
!> @date December 2016, Igor Kozachenko, Computer Science Division, University of
!> California, Berkeley. September 2007, Sven Hammarling, Nicholas J. Higham,
!> Craig Lucas, School of Mathematics, University of Manchester.
!>
!> @note The output INFO is the first occurrence of a singularity, any
!> subsequent occurrence of singularity is not stored in INFO even though the
!> factorization always completes.
!>
!> If INFO > 0, then the block diagonal matrix D is
!> exactly singular, and division by zero will occur if
!> it is used to solve a system of equations.
!>
!> NOTE: INFO only stores the first occurrence of
!> a singularity, any subsequent occurrence of singularity
!> is not stored in INFO even though the factorization
!> always completes.
!>
