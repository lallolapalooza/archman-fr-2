Documentation de la fonction/sous-routine

fonction réelle sla_syrpvgrw (character*1 uplo, integer n, integer info, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, real, dimension( * ) work)

SLA_SYRPVGRW calcule le facteur de croissance réciproque des pivots norm(A)/norm(U) pour une matrice indéfinie symétrique.

Objectif :

!>
!>
!> SLA_SYRPVGRW calcule le facteur de croissance réciproque des pivots
!> norm(A)/norm(U). La norme est utilisée. Si celle-ci est
!> beaucoup plus petite que 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être médiocre. Cela signifie également que
!> la solution X, les nombres de condition estimés et les bornes d'erreur pourraient être
!> peu fiables.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : La partie triangulaire supérieure de A est stockée ;
!>       = 'L' : La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A. N >= 0.
!>

INFO

!>          INFO est INTEGER
!>     La valeur de INFO retournée par SSYTRF, c'est-à-dire que le pivot dans
!>     la colonne INFO est exactement 0.
!>

A

!>          A est tableau de REAL, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est tableau de REAL, dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par SSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV est tableau de INTEGER, dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par SSYTRF.
!>

WORK

!>          WORK est tableau de REAL, dimension (2*N)
!>
