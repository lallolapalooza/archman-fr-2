real function slatm3 (integer m, integer n, integer i, integer j, integer isub, integer jsub, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer igrade, real, dimension( * ) dl, real, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, real sparse)

SLATM3

Objectif :

!>
!>    SLATM3 renvoie l'entrée (ISUB,JSUB) d'une matrice aléatoire de
!>    dimension (M, N) décrite par les autres paramètres. (ISUB,JSUB)
!>    est la position finale de l'entrée (I,J) après pivotement
!>    selon IPVTNG et IWORK. SLATM3 est appelée par la
!>    routine SLATMR afin de construire des matrices de test aléatoires. Aucune vérification
!>    d'erreur sur les paramètres n'est effectuée, car cette routine est appelée dans une
!>    boucle serrée par SLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de SLATM3 diffère de SLATM2 par l'ordre dans lequel le générateur
!>    de nombres aléatoires est appelé pour remplir les entrées de la matrice aléatoire.
!>    Avec SLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    par colonne. Avec SLATM3, le générateur est appelé pour remplir la
!>    matrice par colonne, après quoi elle est pivotée. Ainsi, SLATM3 peut
!>    être utilisée pour construire des matrices aléatoires qui ne diffèrent que par leur
!>    ordre de lignes et/ou de colonnes. SLATM2 est utilisée pour construire des matrices bande
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour les entrées
!>    en dehors de la bande (et donc de générer des nombres aléatoires dans des ordres différents pour des ordres de pivotement différents).
!>
!>    La matrice dont l'entrée (ISUB,JSUB) est renvoyée est construite comme
!>    suit (cette routine ne calcule qu'une entrée) :
!>
!>      Si ISUB est en dehors de (1..M) ou JSUB est en dehors de (1..N), renvoyer zéro
!>         (ceci est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Classer la matrice, si désiré, à gauche (par DL) et/ou
!>         à droite (par DR ou DL) comme spécifié par IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou colonnes comme spécifié par
!>         IPVTNG et IWORK.
!>
!>      Mettre la matrice en bande pour avoir une bande inférieure KL et une bande supérieure
!>         KU.
!>
!>      Définir les entrées aléatoires à zéro comme spécifié par SPARSE.
!>

Paramètres

M 
!>          M est INTEGER
!>           Nombre de lignes de la matrice. Non modifié.
!>

N

!>          N est INTEGER
!>           Nombre de colonnes de la matrice. Non modifié.
!>

I

!>          I est INTEGER
!>           Ligne de l'entrée non pivotée à renvoyer. Non modifié.
!>

J

!>          J est INTEGER
!>           Colonne de l'entrée non pivotée à renvoyer. Non modifié.
!>

ISUB

!>          ISUB est INTEGER
!>           Ligne de l'entrée pivotée à renvoyer. Modifié à la sortie.
!>

JSUB

!>          JSUB est INTEGER
!>           Colonne de l'entrée pivotée à renvoyer. Modifié à la sortie.
!>

KL

!>          KL est INTEGER
!>           Bande inférieure. Non modifié.
!>

KU

!>          KU est INTEGER
!>           Bande supérieure. Non modifié.
!>

IDIST

!>          IDIST est INTEGER
!>           À l'entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMALE( 0, 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau INTEGER de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau REAL de dimension ( MIN( I , J ) )
!>           Entrées diagonales de la matrice. Non modifié.
!>

IGRADE

!>          IGRADE est INTEGER
!>           Spécifie le classement de la matrice comme suit :
!>           0  => pas de classement
!>           1  => matrice pré-multipliée par diag( DL )
!>           2  => matrice post-multipliée par diag( DR )
!>           3  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DR )
!>           4  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par inv( diag( DL ) )
!>           5  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DL )
!>           Non modifié.
!>

DL

!>          DL est un tableau REAL ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour classer la matrice. Non modifié.
!>

DR

!>          DR est un tableau REAL ( I ou J, selon le cas )
!>           Facteurs d'échelle droite pour classer la matrice. Non modifié.
!>

IPVTNG

!>          IPVTNG est INTEGER
!>           À l'entrée spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement de ligne.
!>           2 => pivotement de colonne.
!>           3 => pivotement complet, c'est-à-dire des deux côtés.
!>           Non modifié.
!>

IWORK

!>          IWORK est un tableau INTEGER ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) initialement en position K est en
!>           position IWORK( K ) après pivotement.
!>           Ceci diffère de IWORK pour SLATM2. Non modifié.
!>

SPARSE

!>          SPARSE est REAL entre 0. et 1.
!>           À l'entrée spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire uniforme ( 0, 1 ), x, est généré et
!>           comparé à SPARSE ; si x est supérieur, l'entrée de la matrice
!>           n'est pas modifiée et si x est inférieur, l'entrée est mise
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>

slatm3.3 (fr)

NOM

slatm3 - Une bibliothèque pour les transformateurs de structure atomique locale.

SYNOPSIS

int slatm3_build(slatm3_object *self,
                 const char *filename,
                 const char *model_name);

int slatm3_free(slatm3_object *self);

int slatm3_load_model(slatm3_object *self,
                      const char *model_name);

int slatm3_predict(slatm3_object *self,
                   const float *positions,
                   const int *atomic_numbers,
                   const int num_atoms,
                   float *energies,
                   float *forces,
                   float *stresses);

Documentation des fonctions/sous-routines

slatm3_build

Construit et initialise un objet slatm3_object à partir d'un fichier modèle.

  • self: Pointeur vers le slatm3_object à initialiser.
  • filename: Nom du fichier contenant le modèle.
  • model_name: Nom du modèle à charger depuis le fichier.
  • Retourne 0 en cas de succès, une valeur négative en cas d'erreur.

slatm3_free

Libère la mémoire allouée pour un objet slatm3_object.

  • self: Pointeur vers le slatm3_object à libérer.
  • Retourne 0 en cas de succès, une valeur négative en cas d'erreur.

slatm3_load_model

Charge un modèle spécifique dans un slatm3_object existant.

  • self: Pointeur vers le slatm3_object.
  • model_name: Nom du modèle à charger.
  • Retourne 0 en cas de succès, une valeur négative en cas d'erreur.

slatm3_predict

Prédit les énergies, forces et contraintes pour une configuration atomique donnée.

  • self: Pointeur vers le slatm3_object.
  • positions: Tableau des positions atomiques (x, y, z pour chaque atome).
  • atomic_numbers: Tableau des numéros atomiques.
  • num_atoms: Nombre d'atomes dans la configuration.
  • energies: Pointeur pour stocker l'énergie totale prédite.
  • forces: Pointeur pour stocker les vecteurs forces prédits (3 par atome).
  • stresses: Pointeur pour stocker les tenseurs de contraintes prédits.
  • Retourne 0 en cas de succès, une valeur négative en cas d'erreur.
