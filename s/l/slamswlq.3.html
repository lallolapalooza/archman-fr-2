Documentation de la fonction/sous-routine

subroutine slamswlq (caractère side, caractère trans, entier m, entier n, entier k, entier mb, entier nb, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldt, * ) t, entier ldt, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) work, entier lwork, entier info)

SLAMSWLQ

Objectif :

!>
!>    SLAMSWLQ écrase la matrice réelle M par N, C, avec
!>
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**T * C       C * Q**T
!>    où Q est une matrice orthogonale réelle définie comme le produit de
!>    réflecteurs élémentaires bloqués calculés par la factorisation LQ courte
!>    et large (SLASWLQ).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**T par la Gauche ;
!>          = 'R' : appliquer Q ou Q**T par la Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposition, appliquer Q ;
!>          = 'T' : Transposition, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.  M >=0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          M >= K >= 0 ;
!>
!>

MB

!>          MB est INTEGER
!>          La taille de bloc de ligne à utiliser dans la LQ bloquée.
!>          M >= MB >= 1
!>

NB

!>          NB est INTEGER
!>          La taille de bloc de colonne à utiliser dans la LQ bloquée.
!>          NB > M.
!>

A

!>          A est un tableau de type REAL, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le réflecteur
!>          bloqué élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          SLASWLQ dans les k premières lignes de son argument de tableau A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

T

!>          T est un tableau de type REAL, de dimension
!>          ( M * Nombre de blocs(CEIL(N-K/NB-K)),
!>          Les réflecteurs de blocs triangulaires supérieurs bloqués stockés sous forme compacte
!>          comme une séquence de blocs triangulaires supérieurs. Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= MB.
!>

C

!>          C est un tableau de type REAL, de dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) Tableau de type REAL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK minimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,NB*MB).
!>          Si SIDE = 'R', LWORK >= max(1,M*MB).
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille minimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>

Détails supplémentaires :

!> La factorisation LQ courte et large (SWLQ) effectue la factorisation LQ par une séquence de transformations orthogonales,
!> représentant Q comme un produit d'autres matrices orthogonales
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> où chaque Q(i) annule les entrées diagonales supérieures d'un bloc de NB lignes de A :
!>   Q(1) annule les entrées diagonales supérieures des lignes 1:NB de A
!>   Q(2) annule les lignes MB-N inférieures des lignes [1:M,NB+1:2*NB-M] de A
!>   Q(3) annule les lignes MB-N inférieures des lignes [1:M,2*NB-M+1:3*NB-2*M] de A
!>   . . .
!>
!> Q(1) est calculé par GELQT, qui représente Q(1) par des vecteurs de Householder
!> stockés sous la diagonale des lignes 1:MB de A, et par des réflecteurs de blocs triangulaires supérieurs,
!> stockés dans le tableau T(1:LDT,1:N).
!> Pour plus d'informations, voir les Détails supplémentaires dans GELQT.
!>
!> Q(i) pour i>1 est calculé par TPLQT, qui représente Q(i) par des vecteurs de Householder
!> stockés dans les colonnes [(i-1)*(NB-M)+M+1:i*(NB-M)+M] de A, et par des réflecteurs de blocs triangulaires supérieurs,
!> stockés dans le tableau T(1:LDT,(i-1)*M+1:i*M).
!> Le dernier Q(k) peut utiliser moins de lignes.
!> Pour plus d'informations, voir les Détails supplémentaires dans TPLQT.
!>
!> Pour plus de détails sur l'algorithme global, voir la description de
!> QR séquentiel optimisé en communication dans la section 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>
