sous-routine slarfg (integer n, real alpha, real, dimension( * ) x, integer incx, real tau)

SLARFG génère un réflecteur élémentaire réel H d'ordre n, tel que

Objectif :

!>
!> SLARFG génère un réflecteur élémentaire réel H d'ordre n, tel
!> que
!>
!>       H * ( alpha ) = ( beta ),   H**T * H = I.
!>           (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, et x est un vecteur réel de
!> (n-1) éléments. H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**T ) ,
!>                     ( v )
!>
!> où tau est un scalaire réel et v est un vecteur réel de (n-1)
!> éléments.
!>
!> Si les éléments de x sont tous nuls, alors tau = 0 et H est prise comme
!> la matrice identité.
!>
!> Sinon, 1 <= tau <= 2.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est un REEL
!>          En entrée, la valeur alpha.
!>          En sortie, elle est écrasée par la valeur beta.
!>

X

!>          X est un tableau REEL, de dimension
!>                         (1+(N-2)*abs(INCX))
!>          En entrée, le vecteur x.
!>          En sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est un REEL
!>          La valeur tau.
!>
