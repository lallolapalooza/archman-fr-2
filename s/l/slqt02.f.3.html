sous-routine slqt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) l, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SLQT02

But :

!>
!> SLQT02 teste SORGLQ, qui génère une matrice m-par-n Q avec
!> des lignes orthonormées qui est définie comme le produit de k
!> réflexions élémentaires.
!>
!> Étant donné la factorisation LQ d'une matrice m-par-n A, SLQT02 génère
!> la matrice orthogonale Q définie par la factorisation des k premières
!> lignes de A ; elle compare L(1:k,1:m) à A(1:k,1:n)*Q(1:m,1:n)', et
!> vérifie que les lignes de Q sont orthonormées.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q à générer.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q à générer.
!>          N >= M >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflexions élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice m-par-n A qui a été factorisée par SLQT01.
!>

AF

!>          AF est un tableau REEL, dimension (LDA,N)
!>          Détails de la factorisation LQ de A, tel que retourné par SGELQF.
!>          Voir SGELQF pour plus de détails.
!>

Q

!>          Q est un tableau REEL, dimension (LDA,N)
!>

L

!>          L est un tableau REEL, dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= N.
!>

TAU

!>          TAU est un tableau REEL, dimension (M)
!>          Les facteurs scalaires des réflexions élémentaires correspondant
!>          à la factorisation LQ dans AF.
!>

WORK

!>          WORK est un tableau REEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
