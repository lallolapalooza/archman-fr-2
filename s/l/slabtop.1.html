SLABTOP(1) Manuel des commandes générales SLABTOP(1)

NOM

slabtop - affiche les informations sur les caches slab du noyau en temps réel

SYNTAXE

slabtop [option ...]

DESCRIPTION

slabtop affiche des informations détaillées sur les caches slab du noyau en temps réel. Il affiche une liste des principaux caches triés selon l'un des critères de tri listés. Il affiche également un en-tête de statistiques rempli d'informations sur la couche slab.

OPTIONS

L'invocation normale de slabtop ne nécessite aucune option. Le comportement peut cependant être affiné en spécifiant un ou plusieurs des indicateurs suivants :

-d, --delay=N
Actualise l'affichage toutes les n secondes. Par défaut, slabtop actualise l'affichage toutes les trois secondes. Pour quitter le programme, appuyez sur q. Ceci ne peut pas être combiné avec l'option -o.
-s, --sort=S
Trie selon S, où S est l'un des critères de tri.
-o, --once
Affiche la sortie une fois, puis quitte.
--human
Affiche automatiquement les tailles de slab mises à l'échelle à l'unité la plus courte à trois chiffres et affiche les unités de sortie. Les unités suivantes sont utilisées : 
  B = octets
  Ki = kibioctet
  Mi = mebioctet
  Gi = gibioctet
  Ti = tebioctet
  Pi = pebioctet
Si cet indicateur n'est pas utilisé, les tailles de slab seront affichées en KiB.
-V, --version
Affiche les informations de version et quitte.
-h, --help
Affiche les informations d'utilisation et quitte.

CRITÈRES DE TRI

Les critères de tri valides suivants sont utilisés pour trier les caches slab individuels et ainsi déterminer quels sont les caches slab "principaux" à afficher. Le critère de tri par défaut est de trier par le nombre d'objets ("o").

Les critères de tri peuvent également être modifiés pendant que slabtop est en cours d'exécution en appuyant sur le caractère associé.

caractère description en-tête
a nombre d'objets actifs ACTIVE
b objets par slab OBJ/SLAB
c taille du cache CACHE SIZE
l nombre de slabs SLABS
v nombre de slabs actifs N/A
n nom NAME
o nombre d'objets OBJS
p pages par slab N/A
s taille de l'objet OBJ SIZE
u utilisation du cache USE

COMMANDES

slabtop accepte des commandes clavier de l'utilisateur pendant son utilisation. Les commandes suivantes sont prises en charge. Dans le cas des lettres, les deux casse sont acceptés.

Chacun des caractères de tri valides est également accepté pour modifier la routine de tri. Voir la section CRITÈRES DE TRI.

<ESPACE>
Actualise l'écran.
Q
Quitte le programme.

FICHIERS

/proc/slabinfo
informations sur les slabs

VOIR AUSSI

free(1), ps(1), top(1), vmstat(8)

NOTES

Actuellement, slabtop nécessite un noyau 2.4 ou ultérieur (spécifiquement, une version 1.1 ou ultérieure de /proc/slabinfo). Le noyau 2.2 devrait être pris en charge à l'avenir.

L'en-tête de statistiques slabtop suit le nombre d'octets de slabs utilisés et ne constitue pas une mesure de la mémoire physique. Le champ 'Slab' dans le fichier /proc/meminfo suit les informations sur la mémoire physique des slabs utilisés.

La colonne CACHE SIZE n'est pas précise, c'est la limite supérieure de la mémoire utilisée par un slab spécifique. Lorsque le système utilise slub (cas le plus courant) sous forte pression mémoire, il y a des retours en arrière d'ordre de slab, ce qui signifie que le nombre de "pages par slab" n'est pas constant et peut diminuer.
