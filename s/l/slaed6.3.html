sous-routine slaed6 (integer kniter, logical orgati, real rho, real, dimension( 3 ) d, real, dimension( 3 ) z, real finit, real tau, integer info)

SLAED6 utilisée par SSTEDC. Calcule une étape de Newton pour la résolution de l'équation séculaire.

Objectif :

!>
!> SLAED6 calcule la racine positive ou négative (la plus proche de l'origine) de
!>                  z(1)        z(2)        z(3)
!> f(x) =   rho + --------- + ---------- + ---------
!>                 d(1)-x      d(2)-x      d(3)-x
!>
!> On suppose que
!>
!>       si ORGATI = .true. la racine est entre d(2) et d(3);
!>       sinon elle est entre d(1) et d(2)
!>
!> Cette routine sera appelée par SLAED4 lorsque nécessaire. Dans la plupart des cas,
!> la racine recherchée est la plus petite en magnitude, bien que ce ne soit pas
!> toujours le cas dans des situations extrêmement rares.
!>

Paramètres

KNITER 
!>          KNITER est INTEGER
!>               Se référer à SLAED4 pour sa signification.
!>

ORGATI

!>          ORGATI est LOGICAL
!>               Si ORGATI est vrai, la racine nécessaire est entre d(2) et
!>               d(3); sinon elle est entre d(1) et d(2). Voir
!>               SLAED4 pour plus de détails.
!>

RHO

!>          RHO est REAL
!>               Se référer à l'équation f(x) ci-dessus.
!>

D

!>          D est un tableau de REAL, dimension (3)
!>               D satisfait d(1) < d(2) < d(3).
!>

Z

!>          Z est un tableau de REAL, dimension (3)
!>               Chacun des éléments de z doit être positif.
!>

FINIT

!>          FINIT est REAL
!>               La valeur de f en 0. Elle est plus précise que celle
!>               évaluée à l'intérieur de cette routine (si quelqu'un veut
!>               le faire).
!>

TAU

!>          TAU est REAL
!>               La racine de l'équation f(x).
!>

INFO

!>          INFO est INTEGER
!>               = 0 : sortie réussie
!>               > 0 : si INFO = 1, échec de convergence
!>
