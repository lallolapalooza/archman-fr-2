subroutine slaqtr (ltran, lreal, n, t, ldt, b, w, scale, x, work, info)
SLAQTR résout un système d'équations quasi-triangulaire réel, ou un système quasi-triangulaire complexe de forme spéciale, en arithmétique réelle.

Documentation de la fonction/sous-routine

sous-routine slaqtr (logical ltran, logical lreal, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( * ) b, real w, real scale, real, dimension( * ) x, real, dimension( * ) work, integer info)

SLAQTR résout un système d'équations quasi-triangulaire réel, ou un système quasi-triangulaire complexe de forme spéciale, en arithmétique réelle.

But:

!>
!> SLAQTR résout le système quasi-triangulaire réel
!>
!>              op(T)*p = scale*c,               si LREAL = .TRUE.
!>
!> ou les systèmes quasi-triangulaires complexes
!>
!>            op(T + iB)*(p+iq) = scale*(c+id),  si LREAL = .FALSE.
!>
!> en arithmétique réelle, où T est quasi-triangulaire supérieure.
!> Si LREAL = .FALSE., alors le premier bloc diagonal de T doit être
!> 1 par 1, B est la matrice de structure spéciale
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A ou A**T, A**T dénote la transposée de
!> la matrice A.
!>
!> En entrée, X = [ c ].  En sortie, X = [ p ].
!>               [ d ]                  [ q ]
!>
!> Cette sous-routine est conçue pour l'estimation du nombre de conditionnement
!> dans la routine STRSNA.
!>

Paramètres

LTRAN 
!>          LTRAN est LOGICAL
!>          En entrée, LTRAN spécifie l'option de transposer conjuguée:
!>             = .FALSE.,    op(T+i*B) = T+i*B,
!>             = .TRUE.,     op(T+i*B) = (T+i*B)**T.
!>

LREAL

!>          LREAL est LOGICAL
!>          En entrée, LREAL spécifie la structure de la matrice d'entrée:
!>             = .FALSE.,    l'entrée est complexe
!>             = .TRUE.,     l'entrée est réelle
!>

N

!>          N est INTEGER
!>          En entrée, N spécifie l'ordre de T+i*B. N >= 0.
!>

T

!>          T est tableau de REAL, dimension (LDT,N)
!>          En entrée, T contient une matrice en forme canonique de Schur.
!>          Si LREAL = .FALSE., alors le premier bloc diagonal de T doit
!>          être de taille 1 par 1.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale de la matrice T. LDT >= max(1,N).
!>

B

!>          B est tableau de REAL, dimension (N)
!>          En entrée, B contient les éléments pour former la matrice
!>          B comme décrit ci-dessus.
!>          Si LREAL = .TRUE., B n'est pas référencé.
!>

W

!>          W est REAL
!>          En entrée, W est l'élément diagonal de la matrice B.
!>          Si LREAL = .TRUE., W n'est pas référencé.
!>

SCALE

!>          SCALE est REAL
!>          En sortie, SCALE est le facteur d'échelle.
!>

X

!>          X est tableau de REAL, dimension (2*N)
!>          En entrée, X contient le côté droit du système.
!>          En sortie, X est écrasé par la solution.
!>

WORK

!>          WORK est tableau de REAL, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          En sortie, INFO est défini à
!>             0: sortie réussie.
!>               1: un bloc diagonal 1 par 1 a été perturbé par
!>                  un petit nombre SMIN pour maintenir la non-singularité.
!>               2: un bloc diagonal 2 par 2 a été perturbé par
!>                  un petit nombre dans SLALN2 pour maintenir la non-singularité.
!>          NOTE: Dans un souci de rapidité, cette routine ne vérifie pas
!>                les entrées pour les erreurs.
!>
