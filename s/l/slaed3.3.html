sous-programme slaed3 (integer k, integer n, integer n1, real, dimension( * ) d, real, dimension( ldq, * ) q, integer ldq, real rho, real, dimension( * ) dlambda, real, dimension( * ) q2, integer, dimension( * ) indx, integer, dimension( * ) ctot, real, dimension( * ) w, real, dimension( * ) s, integer info)

SLAED3 utilisé par SSTEDC. Trouve les racines de l'équation séculaire et met à jour les vecteurs propres. Utilisé lorsque la matrice d'origine est tridiagonale.

Objectif :

!>
!> SLAED3 trouve les racines de l'équation séculaire, telles que définies par
!> les valeurs D, W et RHO, entre 1 et K. Il effectue les appels appropriés
!> à SLAED4 et met ensuite à jour les vecteurs propres en multipliant
!> la matrice des vecteurs propres des systèmes propres de paires à combiner
!> par la matrice des vecteurs propres du système K par K qui est résolu ici.
!>
!>

Paramètres

K 
!>          K est de type INTEGER
!>          Le nombre de termes dans la fonction rationnelle à résoudre par
!>          SLAED4. K >= 0.
!>

N

!>          N est de type INTEGER
!>          Le nombre de lignes et de colonnes de la matrice Q.
!>          N >= K (la déflation peut entraîner N>K).
!>

N1

!>          N1 est de type INTEGER
!>          La position de la dernière valeur propre dans la sous-matrice principale.
!>          min(1,N) <= N1 <= N/2.
!>

D

!>          D est un tableau de type REAL, dimension (N)
!>          D(I) contient les valeurs propres mises à jour pour
!>          1 <= I <= K.
!>

Q

!>          Q est un tableau de type REAL, dimension (LDQ,N)
!>          Initialement, les K premières colonnes sont utilisées comme espace
!>          de travail.
!>          En sortie, les colonnes 1 à K contiennent les vecteurs propres
!>          mis à jour.
!>

LDQ

!>          LDQ est de type INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

RHO

!>          RHO est de type REAL
!>          La valeur du paramètre dans l'équation de mise à jour de rang un.
!>          RHO >= 0 requis.
!>

DLAMBDA

!>          DLAMBDA est un tableau de type REAL, dimension (K)
!>          Les K premiers éléments de ce tableau contiennent les anciennes racines
!>          du problème de mise à jour déflaté. Ce sont les pôles de l'équation
!>          séculaire.
!>

Q2

!>          Q2 est un tableau de type REAL, dimension (LDQ2*N)
!>          Les K premières colonnes de cette matrice contiennent les vecteurs propres
!>          non déflatés pour le problème divisé.
!>

INDX

!>          INDX est un tableau de type INTEGER, dimension (N)
!>          La permutation utilisée pour organiser les colonnes de la matrice Q
!>          déflatée en trois groupes (voir SLAED2).
!>          Les lignes des vecteurs propres trouvés par SLAED4 doivent être
!>          permises de la même manière avant que la multiplication matricielle
!>          ne puisse avoir lieu.
!>

CTOT

!>          CTOT est un tableau de type INTEGER, dimension (4)
!>          Un décompte total des différents types de colonnes dans Q, tels que décrits
!>          dans INDX. Le quatrième type de colonne est toute colonne qui a été déflatée.
!>

W

!>          W est un tableau de type REAL, dimension (K)
!>          Les K premiers éléments de ce tableau contiennent les composantes
!>          du vecteur de mise à jour ajusté par déflation. Détruit en sortie.
!>

S

!>          S est un tableau de type REAL, dimension (N1 + 1)*K
!>          Contiendra les vecteurs propres de la matrice réparée qui
!>          seront multipliés par les vecteurs propres accumulés précédemment
!>          pour mettre à jour le système.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0: sortie réussie.
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0: si INFO = 1, une valeur propre n'a pas convergé
!>
