sous-programme sla_syrfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldy, * ) y, integer ldy, real, dimension( * ) berr_out, integer n_norms, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, real, dimension( * ) res, real, dimension( * ) ayb, real, dimension( * ) dy, real, dimension( * ) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

SLA_SYRFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour des matrices symétriques indéfinies en effectuant un raffinage itératif de précision étendue et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Objectif :

!>
!>
!> SLA_SYRFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif de précision étendue
!> et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.
!> Ce sous-programme est appelé par SSYRFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur
!> composante par composante maximale si possible. Voir les commentaires pour ERR_BNDS_NORM
!> et ERR_BNDS_COMP pour les détails des bornes d'erreur. Notez que ce
!> sous-programme est uniquement responsable de la définition des seconds champs de
!> ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser pour le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CHARACTER et P
!>          = 'S': Simple précision
!>          = 'D': Double précision
!>          = 'I': Précision indigène
!>          = 'X' ou 'E': Précision étendue
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U': Le triangle supérieur de A est stocké ;
!>       = 'L': Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau de type REAL, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau de type REAL, dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par SSYTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau de type INTEGER, dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par SSYTRF.
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .TRUE. alors l'équilibration des colonnes a été effectuée sur A avant d'appeler
!>     ce sous-programme. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau de type REAL, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FALSE., C
!>     n'est pas accédé. Si C est entré, chaque élément de C devrait être une puissance
!>     de la base pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base ne cause pas d'erreurs d'arrondi, sauf si
!>     le résultat sous-flue ou surflue. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui pourraient ne pas être
!>     fiables.
!>

B

!>          B est un tableau de type REAL, dimension (LDB,NRHS)
!>     La matrice des membres de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

Y

!>          Y est un tableau de type REAL, dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par SSYTRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau de type REAL, dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur relative arrière composante par composante
!>     pour le j-ème membre de droite, selon la formule :
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par SLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 retourner les bornes d'erreur normwise.
!>     Si N_NORMS >= 2 retourner les bornes d'erreur composante par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau de type REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à l'erreur
!>     relative normwise, définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier index dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second index dans ERR_BNDS_NORM(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur vraie
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Numéro de condition réciproque : Normwise estimé
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau de type REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et numéros de condition correspondant à l'erreur
!>     relative composante par composante, définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>             max_i (abs(XTRUE(i,j) - X(i,j)))
!>            ------------------------------
!>                  max_i abs(X(i,j))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier index dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     membre de droite.
!>
!>     Le second index dans ERR_BNDS_COMP(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              numéro de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur vraie
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Numéro de condition réciproque : Composante par composante estimé
!>

RES

!>          RES est un tableau de type REAL, dimension (N)
!>     Le résidu A*Y - B.
!>

AYB

!>          AYB est un tableau de type REAL, dimension (N)
!>     Pour le calcul de l'erreur composante par composante.
!>

DY

!>          DY est un tableau de type REAL, dimension (N)
!>     Pour le calcul de l'erreur composante par composante.
!>

Y_TAIL

!>          Y_TAIL est un tableau de type REAL, dimension (N)
!>     Pour le calcul de l'erreur composante par composante.
!>

RCOND

!>          RCOND est REAL
!>     Le numéro de condition réciproque estimé de A.
!>

ITHRESH

!>          ITHRESH est INTEGER
!>     Seuil pour le test booléen concernant le numéro de condition.
!>

RTHRESH

!>          RTHRESH est REAL
!>     Seuil pour le test d'erreur concernant le numéro de condition.
!>

DZ_UB

!>          DZ_UB est REAL
!>     Borne supérieure pour l'erreur composante par composante.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGICAL
!>     Si .TRUE. alors l'erreur composante par composante n'est pas calculée.
!>

INFO

!>          INFO est INTEGER
!>     = 0:  Succès de l'exécution.
!>     < 0:  Si INFO = -i, le i-ème argument était d'un type incorrect.
!>     > 0:  Erreur lors du calcul de la borne d'erreur.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     divers bornes d'erreur et nombres de condition correspondant à l'erreur
!>     relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'erreur
!>     relative par composante) et le type d'information d'erreur tel que décrit ci-dessous.
!>     Il y a actuellement jusqu'à trois morceaux d'informations retournés pour chaque second membre.
!>     Si la précision par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : La marge d'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition réciproque
!>              par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'erreur
!>              estimée est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z appropriément mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre actuel et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance du radix de sorte que toutes les sommes de lignes
!>              absolues de Z soient approximativement 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du second champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions supplémentaires.
!>

RES

!>          RES est un tableau REAL, de dimension (N)
!>     Espace de travail pour contenir le résidu intermédiaire.
!>

AYB

!>          AYB est un tableau REAL, de dimension (N)
!>     Espace de travail. Il peut s'agir du même espace de travail que celui passé pour Y_TAIL.
!>

DY

!>          DY est un tableau REAL, de dimension (N)
!>     Espace de travail pour contenir la solution intermédiaire.
!>

Y_TAIL

!>          Y_TAIL est un tableau REAL, de dimension (N)
!>     Espace de travail pour contenir les bits restants de la solution intermédiaire.
!>

RCOND

!>          RCOND est REAL
!>     Nombre de condition réciproque mis à l'échelle. C'est une estimation du
!>     nombre de condition de Skeel réciproque de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision de la machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être faible même
!>     si ce nombre est très faible et que la matrice semble mal conditionnée.
!>

ITHRESH

!>          ITHRESH est INTEGER
!>     Le nombre maximum de calculs de résidu autorisés pour
!>     le raffinement. La valeur par défaut est 10. Pour 'agressif', mettez à 100 pour
!>     permettre la convergence en utilisant des factorisations approximatives ou
!>     des factorisations autres que LU. Si la factorisation utilise une
!>     technique autre que l'élimination gaussienne, les garanties dans
!>     ERR_BNDS_NORM et ERR_BNDS_COMP peuvent ne plus être fiables.
!>

RTHRESH

!>          RTHRESH est REAL
!>     Détermine quand arrêter le raffinement si l'estimation d'erreur cesse
!>     de diminuer. Le raffinement s'arrêtera lorsque la solution suivante ne satisfera plus
!>     norm(dx_{i+1}) < RTHRESH * norm(dx_i) où norm(Z) est
!>     la norme infinie de Z. RTHRESH satisfait 0 < RTHRESH <= 1. La
!>     valeur par défaut est 0.5. Pour 'agressif', mettez à 0.9 pour permettre
!>     la convergence sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!>

DZ_UB

!>          DZ_UB est REAL
!>     Détermine quand commencer à considérer la convergence par composante.
!>     La convergence par composante n'est envisagée qu'après que chaque composante
!>     de la solution Y soit stable, ce que nous définissons comme le changement relatif
!>     de chaque composante étant inférieur à DZ_UB. La valeur par défaut
!>     est 0.25, exigeant que le premier bit soit stable. Voir LAWN 165 pour
!>     plus de détails.
!>

IGNORE_CWISE

!>          IGNORE_CWISE est LOGICAL
!>     Si .VRAI. alors ignorer la convergence par composante. Valeur par défaut
!>     est .FAUX..
!>

INFO

!>          INFO est INTEGER
!>       = 0 : Sortie réussie.
!>       < 0 : si INFO = -i, le i-ème argument de SLA_SYRFSX_EXTENDED avait une valeur illégale.
!>
