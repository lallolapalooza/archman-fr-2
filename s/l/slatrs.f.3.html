Documentation de la fonction/sous-programme

sous-programme slatrs (caractere uplo, caractere trans, caractere diag, caractere normin, entier n, reelle, dimension( lda, * ) a, entier lda, reelle, dimension( * ) x, reelle scale, reelle, dimension( * ) cnorm, entier info)

SLATRS résout un système d'équations triangulaire avec le facteur d'échelle défini pour éviter le dépassement de capacité.

Objectif :

!>
!> SLATRS résout l'un des systèmes triangulaires
!>
!>    A *x = s*b  ou  A**T*x = s*b
!>
!> avec une mise à l'échelle pour éviter le dépassement de capacité. Ici A est une matrice triangulaire supérieure ou inférieure, A**T dénote la transposée de A, x et b sont des vecteurs de n éléments, et s est un facteur d'échelle, généralement inférieur ou égal à 1, choisi de sorte que les composantes de x soient inférieures au seuil de dépassement de capacité. Si le problème non mis à l'échelle ne provoque pas de dépassement de capacité, la routine BLAS de niveau 2 STRSV est appelée. Si la matrice A est singulière (A(j,j) = 0 pour un certain j), alors s est mis à 0 et une solution non triviale à A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b  (Pas de transposée)
!>          = 'T':  Résoudre A**T* x = s*b  (Transposée)
!>          = 'C':  Résoudre A**T* x = s*b  (Conjuguée transposée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

NORMIN

!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes de colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. À la sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure gauche
!>          de dimension n par n du tableau A contient la matrice triangulaire
!>          supérieure, et la partie strictement triangulaire inférieure de
!>          A n'est pas référencée. Si UPLO = 'L', la partie inférieure gauche
!>          de dimension n par n du tableau A contient la matrice triangulaire
!>          inférieure, et la partie strictement triangulaire supérieure de
!>          A n'est pas référencée. Si DIAG = 'U', les éléments diagonaux de A
!>          ne sont pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max (1,N).
!>

X

!>          X est un tableau REEL, dimension (N)
!>          À l'entrée, le membre de droite b du système triangulaire.
!>          À la sortie, X est écrasé par le vecteur solution x.
!>

SCALE

!>          SCALE est REEL
!>          Le facteur d'échelle s pour le système triangulaire
!>             A * x = s*b  ou  A**T* x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle, et
!>          le vecteur x est une solution exacte ou approximative à A*x = 0.
!>

CNORM

!>          CNORM est un tableau REEL, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie non diagonale de la j-ième colonne
!>          de A. Si TRANS = 'N', CNORM(j) doit être supérieur ou égal à
!>          la norme infinie, et si TRANS = 'T' ou 'C', CNORM(j)
!>          doit être supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie non diagonale de la j-ième colonne
!>          de A.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -k, le k-ième argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Une estimation grossière de x est calculée ; si elle est inférieure au dépassement de capacité, STRSV est appelée, sinon, un code spécifique est utilisé qui vérifie les éventuels dépassements de capacité ou divisions par zéro à chaque opération.
!>
!> Un schéma colonne par colonne est utilisé pour résoudre A*x = b. L'algorithme de base
!> si A est triangulaire inférieure est
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Définissons les bornes des composantes de x après j itérations de la boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!> Initialement, posons M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!> Puis pour l'itération j+1, nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> où CNORM(j+1) est supérieur ou égal à la norme infinie de la
!> colonne j+1 de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Puisque |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 STRSV si le
!> inverse du plus grand M(j), j=1,..,n, est supérieur à
!> max(sous-dépassement, 1/dépassement).
!>
!> La borne sur x(j) est également utilisée pour déterminer quand une étape dans la
!> méthode colonne par colonne peut être effectuée sans craindre de dépassement de capacité. Si
!> la borne calculée est supérieure à une grande constante, x est mis à l'échelle pour
!> éviter le dépassement de capacité, mais si la borne dépasse, x est mis à 0, x(j) à
!> 1, et scale à 0, et une solution non triviale à A*x = 0 est trouvée.
!>
!> De même, un schéma ligne par ligne est utilisé pour résoudre A**T*x = b. L'algorithme de base
!> pour A triangulaire supérieure est
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!> Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!> ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!> Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> et nous pouvons appeler STRSV en toute sécurité si 1/M(n) et 1/G(n) sont tous deux supérieurs
!> à max(sous-dépassement, 1/dépassement).
!>
