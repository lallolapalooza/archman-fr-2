Documentation de fonction/sous-programme

sous-programme slatm7 (entier mode, reel cond, entier irsign, entier idist, entier, dimension( 4 ) iseed, reel, dimension( * ) d, entier n, entier rank, entier info)

SLATM7

Objectif :

!>
!>    SLATM7 calcule les entrées de D comme spécifié par MODE
!>    COND et IRSIGN. IDIST et ISEED déterminent la génération
!>    de nombres aléatoires. SLATM7 est appelé par SLATMT pour générer
!>    des matrices de test aléatoires.
!> 
!>  MODE   - ENTIER
!>           À l'entrée décrit comment D doit être calculé :
!>           MODE = 0 signifie ne pas modifier D.
!>
!>           MODE = 1 définit D(1)=1 et D(2:RANK)=1.0/COND
!>           MODE = 2 définit D(1:RANK-1)=1 et D(RANK)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(RANK-1)) I=1:RANK
!>
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi si MODE est positif, D a des entrées allant de
!>              1 à 1/COND, si négatif, de 1/COND à 1,
!>           Non modifié.
!>
!>  COND   - REEL
!>           À l'entrée, utilisé comme décrit sous MODE ci-dessus.
!>           Si utilisé, il doit être >= 1. Non modifié.
!>
!>  IRSIGN - ENTIER
!>           À l'entrée, si MODE n'est ni -6, 0 ni 6, détermine le signe des
!>           entrées de D
!>           0 => laisse les entrées de D inchangées
!>           1 => multiplie chaque entrée de D par 1 ou -1 avec une probabilité de 0,5
!>
!>  IDIST  - CARACTERE*1
!>           À l'entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMALE( 0, 1 )
!>           Non modifié.
!>
!>  ISEED  - Tableau ENTIER, dimension ( 4 )
!>           À l'entrée ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Le générateur de nombres aléatoires utilise une
!>           séquence congruente linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires
!>           indépendants de la machine. Les valeurs de ISEED sont modifiées
!>           à la sortie, et peuvent être utilisées dans le prochain appel à SLATM7
!>           pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>
!>  D      - Tableau REEL, dimension ( MIN( M , N ) )
!>           Tableau à calculer selon MODE, COND et IRSIGN.
!>           Peut être modifié à la sortie si MODE est différent de zéro.
!>
!>  N      - ENTIER
!>           Nombre d'entrées de D. Non modifié.
!>
!>  RANK   - ENTIER
!>           Le rang de la matrice à générer pour les modes 1,2,3 seulement.
!>           D( RANK+1:N ) = 0.
!>           Non modifié.
!>
!>  INFO   - ENTIER
!>            0  => terminaison normale
!>           -1  => si MODE n'est pas dans l'intervalle -6 à 6
!>           -2  => si MODE n'est ni -6, 0 ni 6, et
!>                  IRSIGN n'est ni 0 ni 1
!>           -3  => si MODE n'est ni -6, 0 ni 6 et COND inférieur à 1
!>           -4  => si MODE est égal à 6 ou -6 et IDIST n'est pas dans l'intervalle 1 à 3
!>           -7  => si N est négatif
!>
