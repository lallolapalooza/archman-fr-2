SLAPO-AUTOGROUP(5) Manuel des formats de fichiers SLAPO-AUTOGROUP(5)

NOM

slapo-autogroup - mises à jour automatiques des appartenances de groupe qui répondent aux exigences de tout filtre contenu dans la définition du groupe.

SYNOPHIS

Dans slapd.conf :
...
include ETCDIR/schema/dyngroup.schema
...
moduleload autogroup.so
...
database ...
...
overlay autogroup
autogroup-attrset groupOfURLs memberURL member

DESCRIPTION

La superposition autogroup pour slapd(8) permet des mises à jour automatisées des appartenances de groupe qui répondent aux exigences de tout filtre contenu dans la définition du groupe. Les filtres sont construits à partir d'attributs de valeur d'URI LDAP. Chaque fois qu'un objet est ajouté/supprimé/mis à jour, il est testé pour sa conformité aux filtres, et son appartenance est mise à jour en conséquence. Pour les recherches et les comparaisons, il se comporte comme un groupe statique. Si la partie attribut de l'URI est remplie, l'entrée du groupe est peuplée par les valeurs de cet attribut dans les entrées résultant de la recherche.

Notez que les filtres qui utilisent des attributs qui sont eux-mêmes calculés dynamiquement peuvent ne pas fonctionner de manière cohérente et doivent être évités.

CONFIGURATION

Soit slapd.conf(5), soit la méthodologie cn=config de slapd-config(5) peut être utilisée pour configurer autogroup. Les deux syntaxes sont fournies ici pour plus de commodité :

autogroup-attrset <group-oc> <URL-ad> <member-ad>
olcAutoGroupAttrSet: <group-oc> <URL-ad> <member-ad>
Ceci définit les mappages d'objetClass-attribut-URI qui définissent les groupes gérés automatiquement, et peut apparaître plusieurs fois.

La valeur <group-oc> est le nom de l'objetClass qui représente le groupe.

La valeur <URL-ad> est le nom de la description d'attribut qui contient l'URI convertie en filtres. S'il n'y a pas d'URI, ce groupe n'aura pas de membres. Elle doit être un sous-type de labeledURI.

La valeur <member-ad> est le nom de la description d'attribut qui spécifie l'attribut membre. La modification de cet attribut par l'utilisateur est désactivée pour des raisons de cohérence.

autogroup-memberof-ad <memberof-ad>
olcAutoGroupMemberOfAd <memberof-ad>
Ceci définit l'attribut utilisé par la superposition memberOf pour stocker les noms des groupes dont une entrée est membre ; il doit être valorisé en DN. Il doit être défini à la même valeur que memberof-memberof-ad. Par défaut, il s'agit de 'memberOf'.

EXEMPLES

Comme ci-dessus dans la SYNOPHIS, ou avec memberof :


...
include ETCDIR/schema/dyngroup.schema
include ETCDIR/schema/memberof.schema
...
moduleload autogroup.so
moduleload memberof.so
...
database ...
...
overlay memberof
memberof-memberof-ad foo
...
overlay autogroup
autogroup-attrset groupOfURLs memberURL member
autogroup-memberof-ad foo

AVERTISSEMENTS

Comme pour les groupes statiques, les opérations de mise à jour sur des groupes comportant un grand nombre de membres peuvent être lentes. Si la partie attribut de l'URI est spécifiée, les opérations de modification et de suppression sont plus difficiles à gérer. Dans ces cas, la superposition essaiera de détecter si les groupes ont été modifiés et les actualisera simplement. Cela peut entraîner des ralentissements si la recherche spécifiée par l'URI concerne un nombre important d'entrées.

COMPATIBILITE ASCENDANTE

La superposition autogroup a été retravaillée avec la version 2.5 pour utiliser un espace de noms cohérent, comme pour les autres superpositions. Par effet secondaire, les paramètres cn=config suivants sont obsolètes et seront supprimés dans une future version :

•
olcAGattrSet est remplacé par olcAutoGroupAttrSet
•
olcAGmemberOfAd est remplacé par olcAutoGroupMemberOfAd
•
olcAutomaticGroups est remplacé par olcAutoGroupConfig
