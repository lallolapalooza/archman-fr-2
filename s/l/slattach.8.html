NOM

slattach - attacher une interface réseau à une ligne série

SYNTAXE

slattach [-dehlLmnqv] [-c commande] [-p proto] [-s vitesse] [tty]

DESCRIPTION

Slattach est un petit programme qui peut être utilisé pour mettre une ligne de terminal normale ("série") dans l'un de plusieurs modes "réseau", permettant ainsi de l'utiliser pour des liaisons point à point vers d'autres ordinateurs.

OPTIONS

tty
Chemin d'accès à un périphérique série comme /dev/ttyS*, /dev/cua* ou /dev/ptmx pour lancer un nouveau pseudo tty.
[-c commande]
Exécute commande lorsque la ligne est raccrochée. Ceci peut être utilisé pour lancer des scripts ou rétablir des connexions lorsque un lien tombe.
[-d]
Active la sortie de débogage. Utile pour déterminer pourquoi une configuration donnée ne fonctionne pas.
[-h]
Sort lorsque le porteur est perdu. Ceci fonctionne sur les périphériques /dev/tty et /dev/cua en surveillant directement l'état du porteur toutes les 15 secondes.
[-v]
Active la sortie détaillée. Utile dans les scripts shell.
[-q]
Fonctionne en mode silencieux - aucun message du tout.
[-l]
Crée un fichier de verrouillage de style UUCP pour le périphérique dans /var/lock.
[-n]
Équivalent à la commande "mesg n".
[-m]
N'initialise pas la ligne en mode brut 8 bits.
[-e]
Sort immédiatement après l'initialisation du périphérique, au lieu d'attendre que la ligne soit raccrochée.
[-L]
Active l'opération 3 fils. Le terminal est déplacé en mode CLOCAL, la surveillance du porteur est désactivée.
[-p proto]
Définit un type de protocole spécifique à utiliser sur la ligne. Le défaut est réglé sur cslip, c'est-à-dire SLIP compressé. D'autres valeurs possibles sont slip (SLIP normal), adaptive (CSLIP/SLIP adaptatif), ppp (Protocole Point-à-Point) et kiss (un protocole utilisé pour communiquer avec les contrôleurs de terminaux de radiocommunication AX.25). L'argument spécial tty peut être utilisé pour remettre le périphérique en opération série normale. Utiliser le mode 'ppp' n'est normalement pas utile car ppp nécessite un démon ppp supplémentaire pppd pour être actif sur la ligne. Pour les connexions kiss, le programme kissattach devrait être utilisé.
[-s vitesse]
Définit une vitesse de ligne spécifique, autre que celle par défaut.

Si aucun argument n'est donné, la ligne de terminal actuelle (généralement: le périphérique de connexion) est utilisée. Sinon, une tentative est faite pour réclamer le port de terminal indiqué, le verrouiller et l'ouvrir.

FICHIERS

/dev/cua* /var/lock/LCK.* /dev/ttyS* /dev/ptmx

BOGUES

Aucun connu.
