sous-routine slarrb (integer n, real, dimension( * ) d, real, dimension( * ) lld, integer ifirst, integer ilast, real rtol1, real rtol2, integer offset, real, dimension( * ) w, real, dimension( * ) wgap, real, dimension( * ) werr, real, dimension( * ) work, integer, dimension( * ) iwork, real pivmin, real spdiam, integer twist, integer info)

SLARRB fournit une bissection limitée pour localiser des valeurs propres avec plus de précision.

Objectif :

!>
!> Étant donné la représentation relativement robuste (RRR) L D L^T, SLARRB
!> effectue une bissection pour affiner les valeurs propres de L D L^T,
!> W( IFIRST-OFFSET ) à W( ILAST-OFFSET ), avec plus de précision. Les estimations
!> initiales de ces valeurs propres sont fournies en entrée dans W, les estimations
!> correspondantes de l'erreur dans ces estimations et leurs écarts sont fournies
!> en entrée dans WERR et WGAP, respectivement. Pendant la bissection, les intervalles
!> [gauche, droite] sont maintenus en stockant leurs points médians et
!> demi-largueurs dans les tableaux W et WERR respectivement.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau réel (REAL array), dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

LLD

!>          LLD est un tableau réel (REAL array), dimension (N-1)
!>          Les (N-1) éléments L(i)*L(i)*D(i).
!>

IFIRST

!>          IFIRST est un entier (INTEGER)
!>          L'indice de la première valeur propre à calculer.
!>

ILAST

!>          ILAST est un entier (INTEGER)
!>          L'indice de la dernière valeur propre à calculer.
!>

RTOL1

!>          RTOL1 est un réel (REAL)
!>

RTOL2

!>          RTOL2 est un réel (REAL)
!>          Tolérances pour la convergence des intervalles de bissection.
!>          Un intervalle [GAUCHE,DROITE] a convergé si
!>          DROITE-GAUCHE < MAX( RTOL1*ECART, RTOL2*MAX(|GAUCHE|,|DROITE|) )
!>          où ECART est la distance (estimée) à la valeur propre
!>          la plus proche.
!>

OFFSET

!>          OFFSET est un entier (INTEGER)
!>          Décalage pour les tableaux W, WGAP et WERR, c'est-à-dire que les éléments
!>          IFIRST-OFFSET à ILAST-OFFSET de ces tableaux sont à utiliser.
!>

W

!>          W est un tableau réel (REAL array), dimension (N)
!>          En entrée, W( IFIRST-OFFSET ) à W( ILAST-OFFSET ) sont
!>          des estimations des valeurs propres de L D L^T indexées de IFIRST à
!>          ILAST.
!>          En sortie, ces estimations sont raffinées.
!>

WGAP

!>          WGAP est un tableau réel (REAL array), dimension (N-1)
!>          En entrée, les écarts (estimés) entre les valeurs propres consécutives
!>          de L D L^T, c'est-à-dire que WGAP(I-OFFSET) est l'écart entre
!>          les valeurs propres I et I+1. Notez que si IFIRST = ILAST
!>          alors WGAP(IFIRST-OFFSET) doit être mis à ZÉRO.
!>          En sortie, ces écarts sont raffinés.
!>

WERR

!>          WERR est un tableau réel (REAL array), dimension (N)
!>          En entrée, WERR( IFIRST-OFFSET ) à WERR( ILAST-OFFSET ) sont
!>          les erreurs dans les estimations des éléments correspondants dans W.
!>          En sortie, ces erreurs sont raffinées.
!>

WORK

!>          WORK est un tableau réel (REAL array), dimension (2*N)
!>          Espace de travail.
!>

IWORK

!>          IWORK est un tableau entier (INTEGER array), dimension (2*N)
!>          Espace de travail.
!>

PIVMIN

!>          PIVMIN est un réel (REAL)
!>          Le pivot minimum dans la séquence de Sturm.
!>

SPDIAM

!>          SPDIAM est un réel (REAL)
!>          Le diamètre spectral de la matrice.
!>

TWIST

!>          TWIST est un entier (INTEGER)
!>          L'indice de torsion pour la factorisation tordue qui est utilisée
!>          pour le comptage négatif.
!>          TWIST = N : Calculer le comptage négatif à partir de L D L^T - LAMBDA I = L+ D+ L+^T
!>          TWIST = 1 : Calculer le comptage négatif à partir de L D L^T - LAMBDA I = U- D- U-^T
!>          TWIST = R : Calculer le comptage négatif à partir de L D L^T - LAMBDA I = N(r) D(r) N(r)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          Indicateur d'erreur.
!>
