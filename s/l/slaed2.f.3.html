sous-programme slaed2 (integer k, integer n, integer n1, real, dimension( * ) d, real, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, real rho, real, dimension( * ) z, real, dimension( * ) dlambda, real, dimension( * ) w, real, dimension( * ) q2, integer, dimension( * ) indx, integer, dimension( * ) indxc, integer, dimension( * ) indxp, integer, dimension( * ) coltyp, integer info)

SLAED2 utilisé par SSTEDC. Fusionne les valeurs propres et déflate l'équation séculaire. Utilisé lorsque la matrice originale est tridiagonale.

Objectif :

!>
!> SLAED2 fusionne les deux ensembles de valeurs propres en un seul
!> ensemble trié. Ensuite, il essaie de déflater la taille du problème.
!> Il existe deux façons dont la déflation peut se produire : lorsque deux ou plusieurs
!> valeurs propres sont proches les unes des autres ou s'il y a une entrée minuscule dans
!> le vecteur Z. Pour chaque occurrence, l'ordre du problème de l'équation séculaire
!> associé est réduit de un.
!>

Paramètres

K 
!>          K est un entier (INTEGER)
!>         Le nombre de valeurs propres non déflatées, et l'ordre de
!>         l'équation séculaire associée. 0 <= K <= N.
!>

N

!>          N est un entier (INTEGER)
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

N1

!>          N1 est un entier (INTEGER)
!>         La position de la dernière valeur propre dans la sous-matrice principale.
!>         min(1,N) <= N1 <= N/2.
!>

D

!>          D est un tableau réel (REAL array), dimension (N)
!>         À l'entrée, D contient les valeurs propres des deux sous-matrices à
!>         combiner.
!>         À la sortie, D contient les (N-K) dernières valeurs propres mises à jour
!>         (celles qui ont été déflatées) triées par ordre croissant.
!>

Q

!>          Q est un tableau réel (REAL array), dimension (LDQ, N)
!>         À l'entrée, Q contient les vecteurs propres de deux sous-matrices dans
!>         les deux blocs carrés d'angles en (1,1), (N1,N1)
!>         et (N1+1, N1+1), (N,N).
!>         À la sortie, Q contient les (N-K) derniers vecteurs propres mis à jour
!>         (ceux qui ont été déflatés) dans ses N-K dernières colonnes.
!>

LDQ

!>          LDQ est un entier (INTEGER)
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau entier (INTEGER array), dimension (N)
!>         La permutation qui trie séparément les deux sous-problèmes
!>         dans D par ordre croissant. Notez que les éléments de la deuxième
!>         moitié de cette permutation doivent d'abord avoir N1 ajouté à leurs
!>         valeurs. Détruit à la sortie.
!>

RHO

!>          RHO est un réel (REAL)
!>         À l'entrée, l'élément hors diagonale associé à la coupe de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         recombinées.
!>         À la sortie, RHO a été modifié pour la valeur requise par
!>         SLAED3.
!>

Z

!>          Z est un tableau réel (REAL array), dimension (N)
!>         À l'entrée, Z contient le vecteur de mise à jour (la dernière
!>         ligne de la première matrice de sous-vecteurs propres et la première ligne de
!>         la deuxième matrice de sous-vecteurs propres).
!>         À la sortie, le contenu de Z a été détruit par le processus de
!>         mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau réel (REAL array), dimension (N)
!>         Une copie des K premières valeurs propres qui seront utilisées par
!>         SLAED3 pour former l'équation séculaire.
!>

W

!>          W est un tableau réel (REAL array), dimension (N)
!>         Les k premières valeurs du vecteur z modifié par déflation finale
!>         qui sera passé à SLAED3.
!>

Q2

!>          Q2 est un tableau réel (REAL array), dimension (N1**2+(N-N1)**2)
!>         Une copie des K premiers vecteurs propres qui seront utilisés par
!>         SLAED3 dans une multiplication matricielle (SGEMM) pour résoudre les nouveaux
!>         vecteurs propres.
!>

INDX

!>          INDX est un tableau entier (INTEGER array), dimension (N)
!>         La permutation utilisée pour trier le contenu de DLAMBDA par
!>         ordre croissant.
!>

INDXC

!>          INDXC est un tableau entier (INTEGER array), dimension (N)
!>         La permutation utilisée pour organiser les colonnes de la matrice Q
!>         déflatée en trois groupes : le premier groupe contient des éléments non nuls
!>         uniquement en haut et au-dessus de N1, le deuxième contient
!>         des éléments non nuls uniquement en dessous de N1, et le troisième est dense.
!>

INDXP

!>          INDXP est un tableau entier (INTEGER array), dimension (N)
!>         La permutation utilisée pour placer les valeurs déflatées de D à la fin
!>         du tableau. INDXP(1:K) pointe vers les valeurs D non déflatées
!>         et INDXP(K+1:N) pointe vers les valeurs propres déflatées.
!>

COLTYP

!>          COLTYP est un tableau entier (INTEGER array), dimension (N)
!>         Pendant l'exécution, une étiquette qui indiquera lequel des
!>         types suivants une colonne dans la matrice Q2 est :
!>         1 : non nul seulement dans la moitié supérieure ;
!>         2 : dense ;
!>         3 : non nul seulement dans la moitié inférieure ;
!>         4 : déflaté.
!>         À la sortie, COLTYP(i) est le nombre de colonnes de type i,
!>         pour i=1 à 4 seulement.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0: sortie réussie.
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale.
!>
