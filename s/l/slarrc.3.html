SLARRC calcule le nombre de valeurs propres de la matrice tridiagonale symétrique.

Documentation de la fonction/sous-programme

sous-programme slarrc (caractère jobt, entier n, réel vl, réel vu, réel, dimension( * ) d, réel, dimension( * ) e, réel pivmin, entier eigcnt, entier lcnt, entier rcnt, entier info)

SLARRC calcule le nombre de valeurs propres de la matrice tridiagonale symétrique.

Objectif :

!>
!> Trouve le nombre de valeurs propres de la matrice tridiagonale symétrique T
!> qui se trouvent dans l'intervalle (VL,VU] si JOBT = 'T', et de L D L^T
!> si JOBT = 'L'.
!>

Paramètres

JOBT 
!>          JOBT est CHARACTER*1
!>          = 'T':  Calcule le compte de Sturm pour la matrice T.
!>          = 'L':  Calcule le compte de Sturm pour la matrice L D L^T.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N > 0.
!>

VL

!>          VL est REAL
!>          La borne inférieure pour les valeurs propres.
!>

VU

!>          VU est REAL
!>          La borne supérieure pour les valeurs propres.
!>

D

!>          D est un tableau de type REAL, dimension (N)
!>          JOBT = 'T': Les N éléments diagonaux de la matrice tridiagonale T.
!>          JOBT = 'L': Les N éléments diagonaux de la matrice diagonale D.
!>

E

!>          E est un tableau de type REAL, dimension (N)
!>          JOBT = 'T': Les N-1 éléments hors diagonaux de la matrice T.
!>          JOBT = 'L': Les N-1 éléments hors diagonaux de la matrice L.
!>

PIVMIN

!>          PIVMIN est REAL
!>          Le pivot minimum dans la séquence de Sturm pour T.
!>

EIGCNT

!>          EIGCNT est INTEGER
!>          Le nombre de valeurs propres de la matrice tridiagonale symétrique T
!>          qui se trouvent dans l'intervalle (VL,VU]
!>

LCNT

!>          LCNT est INTEGER
!>

RCNT

!>          RCNT est INTEGER
!>          Les comptes négatifs gauche et droit de l'intervalle.
!>

INFO

!>          INFO est INTEGER
!>
