Documentation de la fonction/sous-routine

sous-routine slaptm (integer n, integer nrhs, real alpha, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldx, * ) x, integer ldx, real beta, real, dimension( ldb, * ) b, integer ldb)

SLAPTM

Objectif :

!>
!> SLAPTM multiplie une matrice N par NRHS X par une matrice tridiagonale
!> symétrique A et stocke le résultat dans une matrice B. L'opération a la forme
!>
!>    B := alpha * A * X + beta * B
!>
!> où alpha peut être 1. ou -1. et beta peut être 0., 1. ou -1.
!>

Paramètres

N 
!>          N est un entier
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.
!>

ALPHA

!>          ALPHA est un réel
!>          Le scalaire alpha. ALPHA doit être 1. ou -1. ; sinon,
!>          il est supposé être 0.
!>

D

!>          D est un tableau réel, de dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau réel, de dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux ou super-diagonaux de A.
!>

X

!>          X est un tableau réel, de dimension (LDX,NRHS)
!>          La matrice X de N par NRHS.
!>

LDX

!>          LDX est un entier
!>          La dimension principale du tableau X. LDX >= max(N,1).
!>

BETA

!>          BETA est un réel
!>          Le scalaire beta. BETA doit être 0., 1. ou -1. ; sinon,
!>          il est supposé être 1.
!>

B

!>          B est un tableau réel, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de N par NRHS.
!>          À la sortie, B est écrasé par l'expression matricielle
!>          B := alpha * A * X + beta * B.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= max(N,1).
!>
