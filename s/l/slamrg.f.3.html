sous-programme slamrg (n1, n2, a, strd1, strd2, index)
SLAMRG crée une liste de permutation pour fusionner les entrées de deux ensembles triés indépendamment en un seul ensemble trié par ordre croissant.

Documentation de la fonction/sous-programme

sous-programme slamrg (integer n1, integer n2, real, dimension( * ) a, integer strd1, integer strd2, integer, dimension( * ) index)

SLAMRG crée une liste de permutation qui fusionnera les éléments de A (qui est composé de deux ensembles triés indépendamment) en un ensemble unique trié par ordre croissant.

Objectif :

!>
!> SLAMRG créera une liste de permutation qui fusionnera les éléments
!> de A (qui est composé de deux ensembles triés indépendamment) en un
!> ensemble unique trié par ordre croissant.
!>

Paramètres

N1 
!>          N1 est un entier
!>

N2

!>          N2 est un entier
!>         Ces arguments contiennent les longueurs respectives des deux
!>         listes triées à fusionner.
!>

A

!>          A est un tableau de réels, de dimension (N1+N2)
!>         Les N1 premiers éléments de A contiennent une liste de nombres
!>         qui sont triés par ordre croissant ou décroissant. De même
!>         pour les N2 derniers éléments.
!>

STRD1

!>          STRD1 est un entier
!>

STRD2

!>          STRD2 est un entier
!>         Ce sont les pas à effectuer dans le tableau A.
!>         Les pas autorisés sont 1 et -1. Ils indiquent si un
!>         sous-ensemble de A est trié par ordre croissant (STRDx = 1)
!>         ou décroissant (STRDx = -1).
!>

INDEX

!>          INDEX est un tableau d'entiers, de dimension (N1+N2)
!>         À la sortie, ce tableau contiendra une permutation telle que
!>         si B( I ) = A( INDEX( I ) ) pour I=1,N1+N2, alors B sera
!>         trié par ordre croissant.
!>
