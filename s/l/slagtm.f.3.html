sous-programme slagtm (trans, n, nrhs, alpha, dl, d, du, x, ldx, beta, b, ldb)
SLAGTM effectue un produit matrice-matrice de la forme C = αAB+βC, où A est une matrice tridiagonale, B et C sont des matrices rectangulaires, et α et β sont des scalaires, pouvant être 0, 1, ou -1.

sous-programme slagtm (caractere trans, entier n, entier nrhs, reel alpha, reel, dimension( * ) dl, reel, dimension( * ) d, reel, dimension( * ) du, reel, dimension( ldx, * ) x, entier ldx, reel beta, reel, dimension( ldb, * ) b, entier ldb)

SLAGTM effectue un produit matrice-matrice de la forme C = αAB+βC, où A est une matrice tridiagonale, B et C sont des matrices rectangulaires, et α et β sont des scalaires, pouvant être 0, 1, ou -1.

Objectif :

!>
!> SLAGTM effectue un produit matrice-matrice de la forme
!>
!>    B := alpha * A * X + beta * B
!>
!> où A est une matrice tridiagonale d'ordre N, B et X sont des matrices N par NRHS
!> et alpha et beta sont des scalaires réels, chacun pouvant être
!> 0., 1., ou -1.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N' : Pas de transposée, B := alpha * A * X + beta * B
!>          = 'T' : Transposée,    B := alpha * A'* X + beta * B
!>          = 'C' : Transposée conjuguée = Transposée
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices X et B.
!>

ALPHA

!>          ALPHA est un REEL
!>          Le scalaire alpha.  ALPHA doit être 0., 1., ou -1. ; sinon,
!>          il est supposé être 0.
!>

DL

!>          DL est un tableau de REEL, dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de T.
!>

D

!>          D est un tableau de REEL, dimension (N)
!>          Les éléments diagonaux de T.
!>

DU

!>          DU est un tableau de REEL, dimension (N-1)
!>          Les éléments super-diagonaux (n-1) de T.
!>

X

!>          X est un tableau de REEL, dimension (LDX,NRHS)
!>          La matrice X de taille N par NRHS.
!>

LDX

!>          LDX est un ENTIER
!>          La dimension principale du tableau X.  LDX >= max(N,1).
!>

BETA

!>          BETA est un REEL
!>          Le scalaire beta.  BETA doit être 0., 1., ou -1. ; sinon,
!>          il est supposé être 1.
!>

B

!>          B est un tableau de REEL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice B de taille N par NRHS.
!>          À la sortie, B est écrasé par l'expression matricielle
!>          B := alpha * A * X + beta * B.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(N,1).
!>
