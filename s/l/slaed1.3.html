Documentation de la fonction/sous-routine

sous-routine slaed1 (integer n, real, dimension( * ) d, real, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, real rho, integer cutpnt, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLAED1 utilisé par SSTEDC. Calcule le système propre mis à jour d'une matrice diagonale après modification par une matrice symétrique de rang un. Utilisé lorsque la matrice originale est tridiagonale.

Objectif :

!>
!> SLAED1 calcule le système propre mis à jour d'une
!> matrice diagonale après modification par une matrice symétrique de rang un.  Cette
!> sous-routine est uniquement utilisée pour le problème propre qui nécessite toutes
!> les valeurs propres et vecteurs propres d'une matrice tridiagonale.  SLAED7 gère
!> le cas où seules les valeurs propres ou les valeurs propres et les vecteurs propres
!> d'une matrice symétrique complète (qui a été réduite à une forme tridiagonale)
!> sont souhaités.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**T ) Q**T(in) = Q(out) * D(out) * Q**T(out)
!>
!>    où Z = Q**T*u, u est un vecteur de longueur N avec des uns dans les
!>    éléments CUTPNT et CUTPNT + 1 et des zéros ailleurs.
!>
!>    Les vecteurs propres de la matrice originale sont stockés dans Q, et les
!>    valeurs propres sont dans D.  L'algorithme se compose de trois étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a des valeurs propres multiples ou s'il y a un zéro dans
!>       le vecteur Z.  Pour chaque occurrence de ce type, la dimension de
!>       l'équation séculaire est réduite de un.  Cette étape est
!>       effectuée par la sous-routine SLAED2.
!>
!>       La deuxième étape consiste à calculer les valeurs propres mises à jour.
!>       Ceci est fait en trouvant les racines de l'équation séculaire
!>       via la sous-routine SLAED4 (appelée par SLAED3).
!>       Cette sous-routine calcule également les vecteurs propres du problème
!>       actuel.
!>
!>       La dernière étape consiste à calculer les vecteurs propres mis à jour
!>       directement en utilisant les valeurs propres mises à jour.  Les vecteurs
!>       propres du problème actuel sont multipliés par les vecteurs propres du
!>       problème global.
!>

Paramètres

N 
!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

D

!>          D est tableau REAL, dimension (N)
!>         À l'entrée, les valeurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les valeurs propres de la matrice réparée.
!>

Q

!>          Q est tableau REAL, dimension (LDQ,N)
!>         À l'entrée, les vecteurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les vecteurs propres de la matrice tridiagonale réparée.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est tableau INTEGER, dimension (N)
!>         À l'entrée, la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant.
!>         À la sortie, la permutation qui réintégrera les
!>         sous-problèmes dans l'ordre trié,
!>         c'est-à-dire que D( INDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

RHO

!>          RHO est REAL
!>         L'entrée sous-diagonale utilisée pour créer la modification de rang 1.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         L'emplacement de la dernière valeur propre dans la sous-matrice principale.
!>         min(1,N) <= CUTPNT <= N/2.
!>

WORK

!>          WORK est tableau REAL, dimension (4*N + N**2)
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (4*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument était illégal.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé.
!>
