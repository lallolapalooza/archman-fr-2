subroutine slasr (character side, character pivot, character direct, integer m, integer n, real, dimension( * ) c, real, dimension( * ) s, real, dimension( lda, * ) a, integer lda)

SLASR applique une séquence de rotations planes à une matrice réelle A, par la gauche ou par la droite.

Objectif :

!>
!> SLASR applique une séquence de rotations planes à une matrice réelle A,
!> par la gauche ou par la droite.
!>
!> Lorsque SIDE = 'L', la transformation prend la forme
!>
!>    A := P*A
!>
!> et lorsque SIDE = 'R', la transformation prend la forme
!>
!>    A := A*P**T
!>
!> où P est une matrice orthogonale composée d'une séquence de z rotations
!> planes, avec z = M si SIDE = 'L' et z = N si SIDE = 'R',
!> et P**T est la transposée de P.
!>
!> Lorsque DIRECT = 'F' (séquence avant), alors
!>
!>    P = P(z-1) * ... * P(2) * P(1)
!>
!> et lorsque DIRECT = 'B' (séquence arrière), alors
!>
!>    P = P(1) * P(2) * ... * P(z-1)
!>
!> où P(k) est une matrice de rotation plane définie par la rotation 2x2
!>
!>    R(k) = (  c(k)  s(k) )
!>         = ( -s(k)  c(k) ).
!>
!> Lorsque PIVOT = 'V' (pivot variable), la rotation est effectuée
!> pour le plan (k,k+1), c'est-à-dire que P(k) a la forme
!>
!>    P(k) = (  1                                            )
!>           (       ...                                     )
!>           (              1                                )
!>           (                   c(k)  s(k)                  )
!>           (                  -s(k)  c(k)                  )
!>           (                                1              )
!>           (                                     ...       )
!>           (                                            1  )
!>
!> où R(k) apparaît comme une modification de rang 2 à la matrice identité
!> dans les lignes et colonnes k et k+1.
!>
!> Lorsque PIVOT = 'T' (pivot supérieur), la rotation est effectuée
!> pour le plan (1,k+1), donc P(k) a la forme
!>
!>    P(k) = (  c(k)                    s(k)                 )
!>           (         1                                     )
!>           (              ...                              )
!>           (                     1                         )
!>           ( -s(k)                    c(k)                 )
!>           (                                 1             )
!>           (                                      ...      )
!>           (                                             1 )
!>
!> où R(k) apparaît dans les lignes et colonnes 1 et k+1.
!> Similairement, lorsque PIVOT = 'B' (pivot inférieur), la rotation est
!> effectuée pour le plan (k,z), donnant à P(k) la forme
!>
!>    P(k) = ( 1                                             )
!>           (      ...                                      )
!>           (             1                                 )
!>           (                  c(k)                    s(k) )
!>           (                         1                     )
!>           (                              ...              )
!>           (                                     1         )
!>           (                 -s(k)                    c(k) )
!>
!> où R(k) apparaît dans les lignes et colonnes k et z. Les rotations sont
!> effectuées sans jamais former P(k) explicitement.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          Spécifie si la matrice de rotation plane P est appliquée à
!>          A par la gauche ou par la droite.
!>          = 'L':  Gauche, calculer A := P*A
!>          = 'R':  Droite, calculer A:= A*P**T
!>

PIVOT

!>          PIVOT est CHARACTER*1
!>          Spécifie le plan pour lequel P(k) est une matrice de rotation
!>          plane.
!>          = 'V':  Pivot variable, le plan (k,k+1)
!>          = 'T':  Pivot supérieur, le plan (1,k+1)
!>          = 'B':  Pivot inférieur, le plan (k,z)
!>

DIRECT

!>          DIRECT est CHARACTER*1
!>          Spécifie si P est une séquence avant ou arrière de rotations
!>          planes.
!>          = 'F':  Avant, P = P(z-1)*...*P(2)*P(1)
!>          = 'B':  Arrière, P = P(1)*P(2)*...*P(z-1)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. Si m <= 1, un retour
!>          immédiat est effectué.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. Si n <= 1, un retour
!>          immédiat est effectué.
!>

C

!>          C est un tableau de type REAL, de dimensions
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Les cosinus c(k) des rotations planes.
!>

S

!>          S est un tableau de type REAL, de dimensions
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Les sinus s(k) des rotations planes. La partie de rotation plane
!>          2x2 de la matrice P(k), R(k), a la forme
!>          R(k) = (  c(k)  s(k) )
!>                 ( -s(k)  c(k) ).
!>

A

!>          A est un tableau de type REAL, de dimensions (LDA,N)
!>          La matrice A de taille M par N. En sortie, A est écrasée par
!>          P*A si SIDE = 'R' ou par A*P**T si SIDE = 'L'.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

Installer le paquet ng sur Arch Linux

Le paquet `ng` est un outil utile pour de nombreux développeurs et administrateurs système. Voici comment l'installer sur une distribution Arch Linux.

Prérequis

Assurez-vous que votre système Arch Linux est à jour. Ouvrez un terminal et exécutez : 

sudo pacman -Syu

Installation

Le paquet `ng` est généralement disponible dans les dépôts officiels d'Arch Linux. Utilisez `pacman` pour l'installer : 

sudo pacman -S ng

Si le paquet n'est pas trouvé dans les dépôts officiels, il se peut qu'il soit disponible dans l'AUR (Arch User Repository). Dans ce cas, vous devrez utiliser un helper AUR comme `yay` ou `paru`. Si vous avez `yay` installé, vous pouvez exécuter : 

yay -S ng

Suivez les instructions à l'écran pour terminer l'installation.

Vérification

Une fois l'installation terminée, vous pouvez vérifier que `ng` est correctement installé en exécutant : 

ng --version

Cela devrait afficher la version du paquet `ng` installé sur votre système.
