NOM

slim - Simple LogIn Manager

SYNTAXE

slim [options] [<arguments>]

DESCRIPTION

SLiM est un gestionnaire de connexion léger pour X11, permettant l'initialisation d'une session graphique en entrant nom d'utilisateur et mot de passe dans un écran de connexion. Il est indépendant du bureau et devrait fonctionner (correctement configuré) avec tout style de session.

OPTIONS

-c /chemin/vers/config
sélectionner un fichier de configuration non standard au lieu de /etc/slim.conf
-d
exécuter en mode démon
-n
ne PAS exécuter en mode démon
-s
être compatible systemd en désactivant le support de consolekit. Cette option ne fait rien si le support de consolekit n'a pas été intégré lors de la compilation.
-p /chemin/vers/theme
afficher un aperçu du thème. Une session X11 déjà en cours est requise pour l'aperçu du thème.
-w <largeur>x<hauteur>
définir la taille de la fenêtre utilisée pour l'aperçu du thème. Cette option n'est valide qu'après une option -p
-h
afficher un bref message d'aide
-v
afficher les informations de version

EXEMPLES

slim -d
exécuter slim en mode démon
slim -p /usr/share/slim/themes/default -w 800x600
aperçu du thème par défaut à basse résolution

DÉMARRAGE DE SLIM AU DÉMARRAGE

Veuillez vous référer à la documentation de votre système d'exploitation pour faire démarrer slim automatiquement après le démarrage du système. En particulier, la méthode est très différente entre les processus d'initialisation SysV, OpenRC, runit et systemd.

CONFIGURATION

La configuration globale est stockée dans le fichier /etc/slim.conf. Consultez les commentaires à l'intérieur du fichier pour une explication détaillée des options.

UTILISATION ET NOMS D'UTILISATEUR SPÉCIAUX

Au démarrage, slim affichera un panneau de connexion ; entrez le nom d'utilisateur et le mot de passe de l'utilisateur sous lequel vous souhaitez vous connecter.

Noms d'utilisateur spéciaux :

console
ouvre une console de connexion xterm. Pas de mot de passe nécessaire
exit
quitte slim. Pas de mot de passe nécessaire. Voir la note dans BUGS.
halt
arrête la machine
reboot
redémarre la machine
suspend
met la machine en veille prolongée

Consultez le fichier de configuration pour personnaliser les commandes ci-dessus. Les commandes 'halt' et 'reboot' nécessitent le mot de passe root, et peuvent donc ne pas fonctionner sur les systèmes où la connexion root est désactivée.

Raccourcis :

F11
exécute une commande personnalisée (par défaut, prend une capture d'écran)
F1
choisit le type de session parmi la liste des sessions.

BOGUES

Lorsqu'il est exécuté en mode démon depuis OpenRC (et potentiellement d'autres systèmes d'init), faire quitter SLiM peut parfois entraîner un écran noir et un ordinateur non réactif. Cela inclut l'utilisation du nom d'utilisateur spécial "exit".

Probablement encore quelques-uns, mais je travaille dessus.
