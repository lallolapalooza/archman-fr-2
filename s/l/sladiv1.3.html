sous-programme sladiv (real a, real b, real c, real d, real p, real q)

SLADIV effectue une division complexe en arithmétique réelle, évitant les dépassements de capacité inutiles.

Objectif :

!>
!> SLADIV effectue une division complexe en arithmétique réelle
!>
!>                       a + i*b
!>            p + i*q = ---------
!>                       c + i*d
!>
!> L'algorithme est dû à Michael Baudin et Robert L. Smith
!> et peut être trouvé dans l'article
!> 
!>

!>

!>          B est REEL
!>

!>          C est REEL
!>

!>          D est REEL
!>          Les scalaires a, b, c et d dans l'expression ci-dessus.
!>

!>

!>          Q est REEL
!>          Les scalaires p et q dans l'expression ci-dessus.
