sous-programme slattp (entier imat, caractère uplo, caractère trans, caractère diag, entier, dimension( 4 ) iseed, entier n, réel, dimension( * ) a, réel, dimension( * ) b, réel, dimension( * ) work, entier info)

SLATTP

But :

!>
!> SLATTP génère une matrice triangulaire de test en stockage compacté.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau AP.
!>

Paramètres

IMAT 
!>          IMAT est un ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce chemin.
!>

UPLO

!>          UPLO est un CARACTÈRE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est un CARACTÈRE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée (= Transposée)
!>

DIAG

!>          DIAG est un CARACTÈRE*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau d'ENTIERS, de dimension (4)
!>          Le vecteur graine pour le générateur de nombres aléatoires (utilisé dans
!>          SLATMS). Modifié à la sortie.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice à générer.
!>

A

!>          A est un tableau de RÉELS, de dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, compactée par colonne dans
!>          un tableau linéaire. La j-ième colonne de A est stockée dans le tableau
!>          AP comme suit :
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau de RÉELS, de dimension (N)
!>          Le vecteur membre de droite, si IMAT > 10.
!>

WORK

!>          WORK est un tableau de RÉELS, de dimension (3*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -k, le k-ième argument avait une valeur illégale
!>
