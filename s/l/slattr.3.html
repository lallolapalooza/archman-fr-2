SLATTR

But:

!>
!> SLATTR génère une matrice de test triangulaire.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice de test,
!> qui est retournée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce chemin.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Transposée conjuguée (= Transposée)
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)
!>          Le vecteur de germe pour le générateur de nombres aléatoires (utilisé dans
!>          SLATMS). Modifié à la sortie.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice à générer.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice triangulaire A. Si UPLO = 'U', la partie supérieure triangulaire
!>          principale de n par n du tableau A contient la matrice triangulaire
!>          supérieure, et la partie strictement triangulaire inférieure de A n'est
!>          pas référencée. Si UPLO = 'L', la partie inférieure triangulaire
!>          principale de n par n du tableau A contient la matrice triangulaire
!>          inférieure, et la partie strictement supérieure triangulaire de A n'est
!>          pas référencée. Si DIAG = 'U', les éléments diagonaux de A sont
!>          définis de telle sorte que A(k,k) = k pour 1 <= k <= n.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau REEL, dimension (N)
!>          Le vecteur de membre de droite, si IMAT > 10.
!>

WORK

!>          WORK est un tableau REEL, dimension (3*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  Sortie réussie
!>          < 0: si INFO = -k, le k-ième argument avait une valeur illégale
!>
