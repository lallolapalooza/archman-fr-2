SLARZB applique un réflecteur de bloc ou sa transposée à une matrice générale.

Documentation de la fonction/sous-routine

sous-routine slarzb (caractère side, caractère trans, caractère direct, caractère storev, entier m, entier n, entier k, entier l, réel, dimension( ldv, * ) v, entier ldv, réel, dimension( ldt, * ) t, entier ldt, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( ldwork, * ) work, entier ldwork)

SLARZB applique un réflecteur de bloc réel H ou sa transposée H**T à une matrice C générale réelle distribuée M-par-N, à gauche ou à droite.

Objectif :

!>
!> SLARZB applique un réflecteur de bloc réel H ou sa transposée H**T à
!> une matrice C générale réelle distribuée M-par-N depuis la gauche ou la droite.
!>
!> Actuellement, seuls STOREV = 'R' et DIRECT = 'B' sont supportés.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer H ou H**T depuis la gauche
!>          = 'R' : appliquer H ou H**T depuis la droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : appliquer H (pas de transposée)
!>          = 'C' : appliquer H**T (Transposée)
!>

DIRECT

!>          DIRECT est CHARACTER*1
!>          Indique comment H est formé à partir d'un produit de réflecteurs
!>          élémentaires
!>          = 'F' : H = H(1) H(2) . . . H(k) (Avant, non supporté pour l'instant)
!>          = 'B' : H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est CHARACTER*1
!>          Indique comment les vecteurs définissant les réflecteurs élémentaires
!>          sont stockés :
!>          = 'C' : Par colonne (non supporté pour l'instant)
!>          = 'R' : Par ligne
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est INTEGER
!>          L'ordre de la matrice T (= le nombre de réflecteurs élémentaires
!>          dont le produit définit le réflecteur de bloc).
!>

L

!>          L est INTEGER
!>          Le nombre de colonnes de la matrice V contenant la
!>          partie significative des réflecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V est tableau REEL, dimension (LDV,NV).
!>          Si STOREV = 'C', NV = K ; si STOREV = 'R', NV = L.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C', LDV >= L ; si STOREV = 'R', LDV >= K.
!>

T

!>          T est tableau REEL, dimension (LDT,K)
!>          La matrice triangulaire K-par-K T dans la représentation du
!>          réflecteur de bloc.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est tableau REEL, dimension (LDC,N)
!>          À l'entrée, la matrice C M-par-N.
!>          À la sortie, C est écrasé par H*C ou H**T*C ou C*H ou C*H**T.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est tableau REEL, dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N) ;
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>
