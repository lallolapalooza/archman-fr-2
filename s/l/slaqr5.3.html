sous-routine slaqr5 (logique wantt, logique wantz, entier kacc22, entier n, entier ktop, entier kbot, entier nshfts, reel, dimension( * ) sr, reel, dimension( * ) si, reel, dimension( ldh, * ) h, entier ldh, entier iloz, entier ihiz, reel, dimension( ldz, * ) z, entier ldz, reel, dimension( ldv, * ) v, entier ldv, reel, dimension( ldu, * ) u, entier ldu, entier nv, reel, dimension( ldwv, * ) wv, entier ldwv, entier nh, reel, dimension( ldwh, * ) wh, entier ldwh)

SLAQR5 effectue un balayage QR multi-leviers avec un petit bombardement.

Objectif:

!>
!>    SLAQR5, appelé par SLAQR0, effectue un
!>    balayage QR multi-leviers avec un petit bombardement.
!>

Paramètres

WANTT 
!>          WANTT est LOGIQUE
!>             WANTT = .vrai. si le facteur de Schur quasi-triangulaire
!>             est en cours de calcul.  WANTT est mis à .faux. sinon.
!>

WANTZ

!>          WANTZ est LOGIQUE
!>             WANTZ = .vrai. si le facteur de Schur orthogonal est en cours de
!>             calcul.  WANTZ est mis à .faux. sinon.
!>

KACC22

!>          KACC22 est ENTIER avec la valeur 0, 1, ou 2.
!>             Spécifie le mode de calcul des mises à jour orthogonales
!>             loignées de la diagonale.
!>        = 0: SLAQR5 n'accumule pas les réflexions et n'utilise pas
!>             la multiplication matrice-matrice pour mettre à jour les
!>             entrées de matrice éloignées de la diagonale.
!>        = 1: SLAQR5 accumule les réflexions et utilise la multiplication
!>             matrice-matrice pour mettre à jour les entrées de matrice
!>             éloignées de la diagonale.
!>        = 2: Identique à KACC22 = 1. Cette option était utilisée pour
!>             exploiter la structure 2x2 lors des multiplications de matrices,
!>             mais ce n'est plus supporté.
!>

N

!>          N est ENTIER
!>             N est l'ordre de la matrice de Hessenberg H sur laquelle
!>             cette sous-routine opère.
!>

KTOP

!>          KTOP est ENTIER
!>

KBOT

!>          KBOT est ENTIER
!>             Ce sont les première et dernière lignes et colonnes d'un
!>             bloc diagonal isolé sur lequel le balayage QR doit être
!>             appliqué. On suppose sans vérification que
!>                       soit KTOP = 1  soit   H(KTOP,KTOP-1) = 0
!>             et
!>                       soit KBOT = N  soit   H(KBOT+1,KBOT) = 0.
!>

NSHFTS

!>          NSHFTS est ENTIER
!>             NSHFTS donne le nombre de leviers simultanés. NSHFTS
!>             doit être positif et pair.
!>

SR

!>          SR est un tableau REEL, dimension (NSHFTS)
!>

SI

!>          SI est un tableau REEL, dimension (NSHFTS)
!>             SR contient les parties réelles et SI contient les parties
!>             imaginaires des NSHFTS leviers d'origine qui définissent le
!>             balayage QR multi-leviers. En sortie SR et SI peuvent être
!>             réordonnés.
!>

H

!>          H est un tableau REEL, dimension (LDH,N)
!>             En entrée H contient une matrice de Hessenberg. En sortie un
!>             balayage QR multi-leviers avec les leviers SR(J)+i*SI(J) est
!>             appliqué au bloc diagonal isolé des lignes et colonnes KTOP
!>             à KBOT.
!>

LDH

!>          LDH est ENTIER
!>             LDH est la dimension principale de H telle que déclarée dans la
!>             procédure appelante. LDH >= MAX(1,N).
!>

ILOZ

!>          ILOZ est ENTIER
!>

IHIZ

!>          IHIZ est ENTIER
!>             Spécifier les lignes de Z auxquelles les transformations doivent
!>             être appliquées si WANTZ est .vrai.. 1 <= ILOZ <= IHIZ <= N
!>

Z

!>          Z est un tableau REEL, dimension (LDZ,IHIZ)
!>             Si WANTZ = .vrai., alors la transformation de similarité orthogonale
!>             du balayage QR est accumulée dans
!>             Z(ILOZ:IHIZ,ILOZ:IHIZ) par la droite.
!>             Si WANTZ = .faux., alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est ENTIER
!>             LDA est la dimension principale de Z telle que déclarée dans la
!>             procédure appelante. LDZ >= N.
!>

V

!>          V est un tableau REEL, dimension (LDV,NSHFTS/2)
!>

LDV

!>          LDV est ENTIER
!>             LDV est la dimension principale de V telle que déclarée dans la
!>             procédure appelante. LDV >= 3.
!>

U

!>          U est un tableau REEL, dimension (LDU,2*NSHFTS)
!>

LDU

!>          LDU est ENTIER
!>             LDU est la dimension principale de U telle que déclarée dans la
!>             procédure appelante. LDU >= 2*NSHFTS.
!>

NV

!>          NV est ENTIER
!>             NV est le nombre de lignes disponibles dans WV pour l'espace de
!>             travail. NV >= 1.
!>

WV

!>          WV est un tableau REEL, dimension (LDWV,2*NSHFTS)
!>

LDWV

!>          LDWV est ENTIER
!>             LDWV est la dimension principale de WV telle que déclarée dans la
!>             procédure appelante. LDWV >= NV.
!>

NH

!>          NH est ENTIER
!>             NH est le nombre de colonnes disponibles dans le tableau WH pour
!>             l'espace de travail. NH >= 1.
!>

WH

!>          WH est un tableau REEL, dimension (LDWH,NH)
!>

LDWH

!>          LDWH est ENTIER
!>             Dimension principale de WH telle que déclarée dans la
!>             procédure appelante. LDWH >= 2*NSHFTS.
!>
