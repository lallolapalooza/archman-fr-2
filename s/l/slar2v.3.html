Documentation de la fonction/sous-programme

sous-programme slar2v (integer n, real, dimension( * ) x, real, dimension( * ) y, real, dimension( * ) z, integer incx, real, dimension( * ) c, real, dimension( * ) s, integer incc)

SLAR2V applique un vecteur de rotations planes avec cosinus réels et sinus réels des deux côtés à une séquence de matrices symétriques/hermitiennes de taille 2x2.

Objectif :

!>
!> SLAR2V applique un vecteur de rotations planes réelles des deux côtés à
!> une séquence de matrices réelles symétriques de taille 2x2, définies par les éléments
!> des vecteurs x, y et z. Pour i = 1,2,...,n
!>
!>    ( x(i)  z(i) ) := (  c(i)  s(i) ) ( x(i)  z(i) ) ( c(i) -s(i) )
!>    ( z(i)  y(i) )    ( -s(i)  c(i) ) ( z(i)  y(i) ) ( s(i)  c(i) )
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de rotations planes à appliquer.
!>

X

!>          X est un tableau REEL,
!>                         de dimension (1+(N-1)*INCX)
!>          Le vecteur x.
!>

Y

!>          Y est un tableau REEL,
!>                         de dimension (1+(N-1)*INCX)
!>          Le vecteur y.
!>

Z

!>          Z est un tableau REEL,
!>                         de dimension (1+(N-1)*INCX)
!>          Le vecteur z.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les éléments de X, Y et Z. INCX > 0.
!>

C

!>          C est un tableau REEL, de dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

S

!>          S est un tableau REEL, de dimension (1+(N-1)*INCC)
!>          Les sinus des rotations planes.
!>

INCC

!>          INCC est un ENTIER
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>
