subroutine slahr2 (n, k, nb, a, lda, tau, t, ldt, y, ldy)
SLAHR2 réduit le nombre spécifié de premières colonnes d'une matrice rectangulaire générale A de sorte que les éléments en dessous de la sous-diagonale spécifiée soient nuls, et renvoie des matrices auxiliaires nécessaires pour appliquer la transformation à la partie non réduite de A.

Documentation de la fonction/sous-programme

sous-programme slahr2 (integer n, integer k, integer nb, real, dimension( lda, * ) a, integer lda, real, dimension( nb ) tau, real, dimension( ldt, nb ) t, integer ldt, real, dimension( ldy, nb ) y, integer ldy)

SLAHR2 réduit le nombre spécifié de premières colonnes d'une matrice rectangulaire générale A de sorte que les éléments en dessous de la sous-diagonale spécifiée soient nuls, et renvoie des matrices auxiliaires nécessaires pour appliquer la transformation à la partie non réduite de A.

Objectif :

!>
!> SLAHR2 réduit les NB premières colonnes d'une matrice générale A de taille n x (n-k+1)
!> de sorte que les éléments sous la k-ième sous-diagonale soient nuls. La
!> réduction est effectuée par une transformation de similarité orthogonale
!> Q**T * A * Q. La sous-routine renvoie les matrices V et T qui déterminent
!> Q comme un bloc réflecteur I - V*T*V**T, ainsi que la matrice Y = A * V * T.
!>
!> Ceci est une sous-routine auxiliaire appelée par SGEHRD.
!>

Paramètres

N 
!>          N est de type INTEGER
!>          Ordre de la matrice A.
!>

K

!>          K est de type INTEGER
!>          Décalage pour la réduction. Les éléments sous la k-ième
!>          sous-diagonale dans les NB premières colonnes sont réduits à zéro.
!>          K < N.
!>

NB

!>          NB est de type INTEGER
!>          Nombre de colonnes à réduire.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N-K+1)
!>          À l'entrée, la matrice générale A de taille n x (n-k+1).
!>          À la sortie, les éléments sur et au-dessus de la k-ième sous-diagonale dans
!>          les NB premières colonnes sont écrasés par les éléments correspondants
!>          de la matrice réduite ; les éléments sous la k-ième
!>          sous-diagonale, avec le tableau TAU, représentent la matrice Q sous forme de
!>          produit de réflecteurs élémentaires. Les autres colonnes de A sont
!>          inchangées. Voir Détails supplémentaires.
!>

LDA

!>          LDA est de type INTEGER
!>          Dimension principale du tableau A. LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau de type REAL, de dimension (NB)
!>          Les facteurs scalaires des réflecteurs élémentaires. Voir Détails
!>          supplémentaires.
!>

T

!>          T est un tableau de type REAL, de dimension (LDT,NB)
!>          La matrice triangulaire supérieure T.
!>

LDT

!>          LDT est de type INTEGER
!>          Dimension principale du tableau T. LDT >= NB.
!>

Y

!>          Y est un tableau de type REAL, de dimension (LDY,NB)
!>          La matrice Y de taille n x nb.
!>

LDY

!>          LDY est de type INTEGER
!>          Dimension principale du tableau Y. LDY >= N.
!>

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de nb réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(nb).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**T
!>
!>  où tau est un scalaire réel, et v est un vecteur réel avec
!>  v(1:i+k-1) = 0, v(i+k) = 1 ; v(i+k+1:n) est stocké à la sortie dans
!>  A(i+k+1:n,i), et tau dans TAU(i).
!>
!>  Les éléments des vecteurs v forment la matrice V de taille (n-k+1)-by-nb
!>  qui est nécessaire, avec T et Y, pour appliquer la transformation à la
!>  partie non réduite de la matrice, en utilisant une mise à jour de la forme :
!>  A := (I - V*T*V**T) * (A - Y*V**T).
!>
!>  Le contenu de A à la sortie est illustré par l'exemple suivant
!>  avec n = 7, k = 3 et nb = 2 :
!>
!>     ( a   a   a   a   a )
!>     ( a   a   a   a   a )
!>     ( a   a   a   a   a )
!>     ( h   h   a   a   a )
!>     ( v1  h   a   a   a )
!>     ( v1  v2  a   a   a )
!>     ( v1  v2  a   a   a )
!>
!>  où a désigne un élément de la matrice originale A, h un élément modifié
!>  de la matrice de Hessenberg supérieure H, et vi un élément du vecteur
!>  définissant H(i).
!>
!>  Cette sous-routine est une légère modification de SLAHRD de LAPACK-3.0
!>  intégrant des améliorations proposées par Quintana-Orti et Van de
!>  Geijn. Notez que les entrées de A(1:K,2:NB) diffèrent de celles
!>  renvoyées par la routine SLAHRD originale de LAPACK-3.0. (Cette
!>  sous-routine n'est pas rétrocompatible avec SLAHRD de LAPACK-3.0.)
!>

Références :

Gregorio Quintana-Orti et Robert van de Geijn, "Improving the performance of reduction to Hessenberg form," ACM Transactions on Mathematical Software, 32(2):180-194, juin 2006.
