NOM

slapo-pbind - superposition proxy bind pour slapd

SYNTAXE

/etc/openldap/slapd.conf

DESCRIPTION

La superposition pbind pour slapd(8) redirige les Binds Simples sur une base de données locale vers un serveur LDAP distant au lieu de les traiter localement. La connexion distante est gérée à l'aide d'une instance du backend ldap.

La superposition pbind utilise un sous-ensemble des directives de configuration du backend ldap. Elles sont décrites plus en détail dans slapd-ldap(5).

Note : cette superposition est intégrée au backend ldap ; ce n'est pas un module séparé.

overlay pbind
Cette directive ajoute la superposition proxy bind au backend courant. La superposition proxy bind peut être utilisée avec n'importe quel backend, mais elle est principalement destinée à être utilisée avec des backends de stockage locaux.
uri <ldapurl>
Serveur LDAP à utiliser.
tls <paramètres TLS>
Spécifie l'utilisation de TLS.
network-timeout <temps>
Définit le délai d'attente réseau.
quarantine <paramètres de quarantaine>
Active la mise en quarantaine des URIs qui ont retourné LDAP_UNAVAILABLE.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd

VOIR AUSSI

slapd.conf(5), slapd-config(5), slapd-ldap(5), slapd(8).
