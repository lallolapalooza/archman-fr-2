Documentation de la fonction/du sous-programme

sous-programme slarhs (character*3 path, character xtype, character uplo, character trans, entier m, entier n, entier kl, entier ku, entier nrhs, reel, dimension( lda, * ) a, entier lda, reel, dimension( ldx, * ) x, entier ldx, reel, dimension( ldb, * ) b, entier ldb, entier, dimension( 4 ) iseed, entier info)

SLARHS

Objectif :

!>
!> SLARHS choisit un ensemble de NRHS vecteurs solution aléatoires et configure
!> les seconds membres pour le système linéaire
!>    op(A) * X = B,
!> où op(A) = A ou A**T, selon TRANS.
!>

Paramètres

PATH 
!>          PATH est CHARACTER*3
!>          Le type de la matrice réelle A. PATH peut être donné dans n'importe
!>          quelle combinaison de majuscules et minuscules. Les types valides
!>          incluent
!>             xGE : Matrice générale m x n
!>             xGB : Matrice bande générale
!>             xPO : Définie positive symétrique, stockage 2D
!>             xPP : Définie positive symétrique, conditionnée
!>             xPB : Définie positive symétrique, bande
!>             xSY : Symétrique indéfinie, stockage 2D
!>             xSP : Symétrique indéfinie, conditionnée
!>             xSB : Symétrique indéfinie, bande
!>             xTR : Triangulaire
!>             xTP : Triangulaire, conditionnée
!>             xTB : Triangulaire, bande
!>             xQR : Matrice générale m x n
!>             xLQ : Matrice générale m x n
!>             xQL : Matrice générale m x n
!>             xRQ : Matrice générale m x n
!>          où le premier caractère indique la précision.
!>

XTYPE

!>          XTYPE est CHARACTER*1
!>          Spécifie comment la solution exacte X sera déterminée :
!>          = 'N' : Nouvelle solution ; générer une solution aléatoire X.
!>          = 'C' : Calculée ; utiliser la valeur de X à l'entrée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice A est stockée, si A est symétrique.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Utilisé seulement si A est non symétrique ; spécifie l'opération
!>          appliquée à la matrice A.
!>          = 'N' : B := A    * X  (Pas de transposée)
!>          = 'T' : B := A**T * X  (Transposée)
!>          = 'C' : B := A**H * X  (Conjuguée transposée = Transposée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Utilisé seulement si A est une matrice bande ; spécifie le nombre
!>          de sous-diagonales de A si A est une matrice bande générale ou si A est
!>          symétrique ou triangulaire et UPLO = 'L' ; spécifie le nombre
!>          de super-diagonales de A si A est symétrique ou triangulaire et
!>          UPLO = 'U'.  0 <= KL <= M-1.
!>

KU

!>          KU est INTEGER
!>          Utilisé seulement si A est une matrice bande générale ou si A est
!>          triangulaire.
!>
!>          Si PATH = xGB, spécifie le nombre de super-diagonales de A,
!>          et 0 <= KU <= N-1.
!>
!>          Si PATH = xTR, xTP, ou xTB, spécifie si la matrice a une diagonale unitaire ou non :
!>          = 1 : matrice avec diagonale non unitaire (par défaut)
!>          = 2 : matrice avec diagonale unitaire
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de vecteurs du second membre dans le système A*X = B.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice de test dont le type est donné par PATH.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si PATH = xGB, LDA >= KL+KU+1.
!>          Si PATH = xPB, xSB, xHB, ou xTB, LDA >= KL+1.
!>          Sinon, LDA >= max(1,M).
!>

X

!>          X est un tableau REAL (entrée ou sortie), dimension(LDX,NRHS)
!>          À l'entrée, si XTYPE = 'C' (pour 'Calculée'), alors X contient
!>          la solution exacte du système d'équations linéaires.
!>          En sortie, si XTYPE = 'N' (pour 'Nouvelle'), alors X est initialisé
!>          avec des valeurs aléatoires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. Si TRANS = 'N',
!>          LDX >= max(1,N) ; si TRANS = 'T', LDX >= max(1,M).
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          Le(s) vecteur(s) du second membre pour le système d'équations,
!>          calculé(s) à partir de B = op(A) * X, où op(A) est déterminé par
!>          TRANS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. Si TRANS = 'N',
!>          LDB >= max(1,M) ; si TRANS = 'T', LDB >= max(1,N).
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension (4)
!>          La graine pour le générateur de nombres aléatoires (utilisé dans
!>          SLATMS). Modifié en sortie.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
