Documentation de la fonction/sous-routine

sous-routine slarre (character range, integer n, real vl, real vu, integer il, integer iu, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real rtol1, real rtol2, real spltol, integer nsplit, integer, dimension( * ) isplit, integer m, real, dimension( * ) w, real, dimension( * ) werr, real, dimension( * ) wgap, integer, dimension( * ) iblock, integer, dimension( * ) indexw, real, dimension( * ) gers, real pivmin, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLARRE étant donné la matrice tridiagonale T, met à zéro les petits éléments hors diagonale et pour chaque bloc non réduit Ti, trouve les représentations de base et les valeurs propres.

But :

!>
!> Pour trouver les valeurs propres désirées d'une matrice tridiagonale symétrique réelle donnée T,
!> SLARRE met à zéro tous les éléments hors diagonale, et pour chaque bloc non réduit T_i, il trouve
!> (a) un décalage approprié à une extrémité du spectre du bloc,
!> (b) la représentation de base, T_i - sigma_i I = L_i D_i L_i^T, et
!> (c) les valeurs propres de chaque L_i D_i L_i^T.
!> Les représentations et valeurs propres trouvées sont ensuite utilisées par
!> SSTEMR pour calculer les vecteurs propres de T.
!> La précision varie selon que la méthode par bissection est utilisée pour
!> trouver quelques valeurs propres ou l'algorithme dqds (sous-routine SLASQ2) pour
!> calculer toutes les valeurs propres puis en rejeter celles qui ne sont pas désirées.
!> Comme bénéfice supplémentaire, SLARRE produit également les n
!> intervalles de Gerschgorin pour les matrices L_i D_i L_i^T.
!>

Paramètres

RANGE 
!>          RANGE est CHARACTER*1
!>          = 'A': ()   toutes les valeurs propres seront trouvées.
!>          = 'V': () toutes les valeurs propres dans l'intervalle semi-ouvert
!>                           (VL, VU] seront trouvées.
!>          = 'I': () les IL-èmes à IU-èmes valeurs propres (de la
!>                           matrice entière) seront trouvées.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N > 0.
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure pour les valeurs propres.
!>          Les valeurs propres inférieures ou égales à VL, ou supérieures à VU,
!>          ne seront pas retournées.  VL < VU.
!>          Si RANGE='I' ou ='A', SLARRE calcule les bornes sur la partie
!>          désirée du spectre.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure pour les valeurs propres.
!>          Les valeurs propres inférieures ou égales à VL, ou supérieures à VU,
!>          ne seront pas retournées.  VL < VU.
!>          Si RANGE='I' ou ='A', SLARRE calcule les bornes sur la partie
!>          désirée du spectre.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N.
!>

D

!>          D est tableau REAL, dimension (N)
!>          À l'entrée, les N éléments diagonaux de la matrice tridiagonale
!>          T.
!>          À la sortie, les N éléments diagonaux des matrices diagonales
!>          D_i.
!>

E

!>          E est tableau REAL, dimension (N)
!>          À l'entrée, les (N-1) premiers éléments contiennent les éléments
!>          sous-diagonaux de la matrice tridiagonale T ; E(N) n'a pas besoin
!>          d'être défini.
!>          À la sortie, E contient les éléments sous-diagonaux des matrices
!>          unitaires bidiagonales L_i. Les entrées E( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, contiennent les points de base sigma_i en sortie.
!>

E2

!>          E2 est tableau REAL, dimension (N)
!>          À l'entrée, les (N-1) premiers éléments contiennent les CARRÉS des
!>          éléments sous-diagonaux de la matrice tridiagonale T ;
!>          E2(N) n'a pas besoin d'être défini.
!>          À la sortie, les entrées E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, ont été mises à zéro.
!>

RTOL1

!>          RTOL1 est REAL
!>

RTOL2

!>          RTOL2 est REAL
!>           Paramètres pour la bissection.
!>           Un intervalle [LEFT,RIGHT] a convergé si
!>           RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>

SPLTOL

!>          SPLTOL est REAL
!>          Le seuil pour la séparation.
!>

NSPLIT

!>          NSPLIT est INTEGER
!>          Le nombre de blocs dans lesquels T se divise. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT est tableau INTEGER, dimension (N)
!>          Les points de séparation, où T se divise en blocs.
!>          Le premier bloc comprend les lignes/colonnes 1 à ISPLIT(1),
!>          le second les lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et le NSPLIT-ième comprend les lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres (de tous les L_i D_i L_i^T)
!>          trouvées.
!>

W

!>          W est tableau REAL, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres. Les
!>          valeurs propres de chacun des blocs, L_i D_i L_i^T, sont
!>          triées par ordre croissant ( SLARRE peut utiliser les
!>          N-M éléments restants comme espace de travail).
!>

WERR

!>          WERR est tableau REAL, dimension (N)
!>          La borne d'erreur sur la valeur propre correspondante dans W.
!>

WGAP

!>          WGAP est tableau REAL, dimension (N)
!>          La séparation avec la valeur propre voisine de droite dans W.
!>          L'écart n'est qu'envers les valeurs propres du même bloc,
!>          car chaque bloc a son propre arbre de représentation.
!>          Exception : à l'extrémité droite d'un bloc, nous stockons l'écart gauche.
!>

IBLOCK

!>          IBLOCK est tableau INTEGER, dimension (N)
!>          Les indices des blocs (sous-matrices) associés aux
!>          valeurs propres correspondantes dans W ; IBLOCK(i)=1 si la valeur propre
!>          W(i) appartient au premier bloc par le haut, =2 si W(i)
!>          appartient au deuxième bloc, etc.
!>

INDEXW

!>          INDEXW est tableau INTEGER, dimension (N)
!>          Les indices des valeurs propres au sein de chaque bloc (sous-matrice) ;
!>          par exemple, INDEXW(i)= 10 et IBLOCK(i)=2 impliquent que la
!>          i-ème valeur propre W(i) est la 10-ème valeur propre du bloc 2.
!>

GERS

!>          GERS est tableau REAL, dimension (2*N)
!>          Les N intervalles de Gerschgorin (le i-ème intervalle de
!>          Gerschgorin est (GERS(2*i-1), GERS(2*i)).
!>

PIVMIN

!>          PIVMIN est REAL
!>          Le pivot minimum dans la séquence de Sturm pour T.
!>

WORK

!>          WORK est tableau REAL, dimension (6*N)
!>          Espace de travail.
!>

IWORK

!>

NAME

slarre — computes the right singular vectors of a real upper bidiagonal matrix.

SYNOPSIS

 SUBROUTINE SLARRE(N, D, E, VF, VL, DIFL, DIFR, Z, WORK, INFO)
 INTEGER N
 REAL    D(N), E(N-1)
 REAL    VF(N), VL(N)
 REAL    DIFL(N), DIFR(N)
 REAL    Z(N, N)
 REAL    WORK(5*N)
 INTEGER INFO

Function/Subroutine Documentation

SLARRE computes the right singular vectors of a real upper bidiagonal matrix A.

The singular values of A are computed by SLARRE and the singular vectors are computed by SLASQ2.

This subroutine is called by SLASQ1, SLASQ3, and SLASQ4.

The algorithm used is described in:

B.
Parlett, “The Symmetric Eigenvalue Problem”, Prentice-Hall, 1980.
C.
Voemel, “Fast and Robust computation of Singular Vectors of Bidiagonal Matrices”, ACM Trans. Math. Softw. 35, 4, Article 29, 2009.

Arguments:

N
(input) The dimension of the matrix A. N >= 0.
D
(input) The vector D contains the diagonal entries of the bidiagonal matrix A.
E
(input) The vector E contains the entries of the super-diagonal of the bidiagonal matrix A.
VF
(output) The vector VF.
VL
(output) The vector VL.
DIFL
(output) The vector DIFL.
DIFR
(output) The vector DIFR.
Z
(output) The matrix Z.
IWORK
(workspace) INTEGER array, dimension (5*N).

INFO

 INFO is INTEGER
 = 0:  successful exit
 > 0:  A problem occurred in SLARRE.
 < 0:  One of the called subroutines signaled an internal problem.
       Needs inspection of the corresponding parameter IINFO
       for further information.

 =-1:  Problem in SLARRD.
 = 2:  No base representation could be found in MAXTRY iterations.
       Increasing MAXTRY and recompilation might be a remedy.
 =-3:  Problem in SLARRB when computing the refined root
       representation for SLASQ2.
 =-4:  Problem in SLARRB when preforming bisection on the
       desired part of the spectrum.
 =-5:  Problem in SLASQ2.
 =-6:  Problem in SLASQ2.

Further Details:

 The base representations are required to suffer very little
 element growth and consequently define all their eigenvalues to
 high relative accuracy.
