NOM

slurmdbd - Démon de base de données Slurm.

SYNTAXE

slurmdbd [OPTIONS...]

DESCRIPTION

slurmdbd fournit une interface sécurisée à l'échelle de l'entreprise vers une base de données pour Slurm. Ceci est particulièrement utile pour l'archivage des enregistrements de comptabilité.

OPTIONS

-D
Exécute slurmdbd au premier plan avec la journalisation copiée vers stdout.
-h
Aide ; imprime un bref résumé des options de commande.
-n <valeur>
Définit la valeur de nice du démon à la valeur spécifiée, généralement un nombre négatif.
-s
Change le répertoire de travail de slurmdbd vers le chemin LogFile si possible, ou vers /var/tmp sinon.
-u
Affiche uniquement la version de la base de données Slurm et si une conversion est nécessaire, puis quitte sans prendre le contrôle. Si aucune conversion n'est nécessaire, 0 est renvoyé ; si une conversion est nécessaire, 1 est renvoyé.
-v
Fonctionnement détaillé. Plusieurs v peuvent être spécifiés, chaque 'v' après le premier augmentant le niveau de détail, jusqu'à 6 fois (c'est-à-dire -vvvvvv).
-V
Imprime les informations de version et quitte.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour remplacer les paramètres compilés dans slurmdbd.

ABORT_ON_FATAL
Lorsqu'une erreur fatale est détectée, utilise abort() au lieu de exit() pour terminer le processus. Cela permet de capturer des traces de pile sans recompiler Slurm.

EMPLACEMENT DU FICHIER CORE

Si slurmdbd est démarré avec l'option -D, le fichier core sera écrit dans le répertoire de travail courant. Sinon, si LogFile dans "slurmdbd.conf" est un nom de chemin complet (commençant par un slash), le fichier core sera écrit dans le même répertoire que le fichier journal, à condition que SlurmUser ait les permissions d'écriture sur ce répertoire. Sinon, le fichier core sera écrit dans "/var/tmp/" en dernier recours. Si aucun des répertoires ci-dessus n'a les permissions d'écriture pour SlurmUser, aucun fichier core ne sera produit.

SIGNAUX

SIGTERM SIGINT SIGQUIT
slurmdbd s'arrêtera proprement, attendant que les consolidations en cours se terminent.
SIGABRT
slurmdbd effectuera une vidange mémoire (core dump), puis s'arrêtera. Les opérations en cours seront tuées.
SIGHUP
Recharge les fichiers de configuration de Slurm, similaire à 'scontrol reconfigure'.
SIGTSTP
Arrête le processus depuis un terminal.
SIGUSR2
Relit le niveau de journalisation à partir des configurations, puis rouvre le fichier journal. Ceci devrait être utilisé lors de la configuration de logrotate(8).
SIGCHLD SIGUSR1 SIGXCPU SIGPIPE SIGALRM
Ces signaux sont explicitement ignorés.

NOTES

Il peut être utile d'expérimenter avec différents paramètres de configuration spécifiques à slurmctld en utilisant un fichier de configuration distinct (par exemple, les délais d'attente). Cependant, ce fichier de configuration spécial ne sera pas utilisé par le démon slurmd ni par les programmes Slurm, à moins que vous ne leur indiquiez spécifiquement de l'utiliser. Si vous souhaitez modifier les ports de communication, l'emplacement du système de fichiers temporaire, ou d'autres paramètres utilisés par d'autres composants Slurm, modifiez le fichier de configuration commun, slurm.conf.
