SLAEDA utilisé par SSTEDC. Calcule le vecteur Z déterminant la modification de rang un de la matrice diagonale. Utilisé lorsque la matrice d'origine est dense.

sous-routine slaeda (integer n, integer tlvls, integer curlvl, integer curpbm, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, real, dimension( 2, * ) givnum, real, dimension( * ) q, integer, dimension( * ) qptr, real, dimension( * ) z, real, dimension( * ) ztemp, integer info)

SLAEDA utilisé par SSTEDC. Calcule le vecteur Z déterminant la modification de rang un de la matrice diagonale. Utilisé lorsque la matrice d'origine est dense.

But :

!>
!> SLAEDA calcule le vecteur Z correspondant à l'étape de fusion dans la
!> CURLVLème étape du processus de fusion avec TLVLS étapes pour le CURPBMème
!> problème.
!>

Paramètres

N 
!>          N est un ENTIER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

TLVLS

!>          TLVLS est un ENTIER
!>         Le nombre total de niveaux de fusion dans l'arbre diviser pour
!>         régner global.
!>

CURLVL

!>          CURLVL est un ENTIER
!>         Le niveau actuel dans la routine de fusion globale,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM est un ENTIER
!>         Le problème actuel au niveau actuel dans la routine de fusion
!>         globale (compté de la gauche vers la droite en bas).
!>

PRMPTR

!>          PRMPTR est un tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans PERM la
!>         permutation d'un niveau est stockée.  PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et incidemment la
!>         taille du problème complet, non déflaté.
!>

PERM

!>          PERM est un tableau ENTIER, dimension (N lg N)
!>         Contient les permutations (issues de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est un tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans GIVCOL les
!>         rotations de Givens d'un niveau sont stockées.  GIVPTR(i+1) - GIVPTR(i)
!>         indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est un tableau ENTIER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes pour la
!>         rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau REEL, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la rotation de
!>         Givens correspondante.
!>

Q

!>          Q est un tableau REEL, dimension (N**2)
!>         Contient les blocs propres carrés des niveaux précédents, les
!>         positions de départ des blocs sont données par QPTR.
!>

QPTR

!>          QPTR est un tableau ENTIER, dimension (N+2)
!>         Contient une liste de pointeurs qui indiquent où dans Q un
!>         bloc propre est stocké.  SQRT( QPTR(i+1) - QPTR(i) ) indique
!>         la taille du bloc.
!>

Z

!>          Z est un tableau REEL, dimension (N)
!>         En sortie, ce vecteur contient le vecteur de mise à jour (la
!>         dernière ligne de la première matrice propre-sous et la première
!>         ligne de la deuxième matrice propre-sous).
!>

ZTEMP

!>          ZTEMP est un tableau REEL, dimension (N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
