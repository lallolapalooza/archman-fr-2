Documentation de la fonction/sous-programme

sous-programme slaed5 (entier i, reel, dimension( 2 ) d, reel, dimension( 2 ) z, reel, dimension( 2 ) delta, reel rho, reel dlam)

SLAED5 utilisé par SSTEDC. Résout l'équation séculaire 2x2.

But:

!>
!> Ce sous-programme calcule la I-ème valeur propre d'une modification
!> symétrique de rang un d'une matrice diagonale 2x2
!>
!>            diag( D )  +  RHO * Z * transpose(Z) .
!>
!> Les éléments diagonaux dans le tableau D sont supposés satisfaire
!>
!>            D(i) < D(j)  pour  i < j .
!>
!> Nous supposons également RHO > 0 et que la norme euclidienne du vecteur
!> Z est un.
!>

Paramètres

I 
!>          I est ENTIER
!>         L'indice de la valeur propre à calculer. I = 1 ou I = 2.
!>

D

!>          D est un tableau REEL, de dimension (2)
!>         Les valeurs propres originales. Nous supposons D(1) < D(2).
!>

Z

!>          Z est un tableau REEL, de dimension (2)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau REEL, de dimension (2)
!>         Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres.
!>

RHO

!>          RHO est REEL
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DLAM

!>          DLAM est REEL
!>         Le lambda_I calculé, la I-ème valeur propre mise à jour.
!>
