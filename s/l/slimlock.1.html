slimlock(1) Manuel des commandes générales slimlock(1)

NOM

slimlock - Verrouilleur d'écran impie

SYNTAXE

slimlock [-v]

DESCRIPTION

Le monstre de Frankenstein des verrouilleurs d'écran. Greffer SLiM et slock ensemble conduit au sang, aux larmes et aux écrans verrouillés.

OPTIONS

-v
affiche les informations de version

CONFIGURATION

Slimlock lit les mêmes fichiers de configuration que ceux utilisés pour SLiM. Il recherche dans CFGDIR/slim.conf et CFGDIR/slimlock.conf, où CFGDIR est défini lors de la compilation - généralement /etc. Les options lues dans slim.conf sont hidecursor, current_theme, background_color et background_style, screenshot_cmd, et welcome_msg. Voir la documentation SLiM pour plus d'informations.

slimlock.conf contient les paramètres suivants :

dpms_standby_timeout
nombre de secondes d'inactivité avant que l'écran ne s'éteigne. Défaut : 60
dpms_off_timeout
nombre de secondes d'inactivité avant que l'écran ne s'éteigne complètement. Défaut : 600
wrong_passwd_timeout
délai en secondes après la saisie d'un mot de passe incorrect. Défaut : 2
passwd_feedback_msg
message à afficher après une tentative d'authentification échouée. Défaut : Authentication failed
passwd_feedback_capslock
message à afficher après une tentative d'authentification échouée si le verrouillage majuscule est activé. Défaut : Authentication failed (CapsLock is on)
show_username
1 pour afficher le nom d'utilisateur sur les thèmes avec un seul champ de saisie ; 0 pour désactiver. Défaut : 1
show_welcome_msg
1 pour afficher le message de bienvenue de SLiM ; 0 pour désactiver. Défaut : 0
tty_lock
1 pour interdire le changement de terminaux virtuels ; 0 pour autoriser. Défaut : 1
bell
1 pour activer la sonnerie en cas d'échec d'authentification ; 0 pour désactiver. Défaut : 1

BOGUES

Lorsque le thème définit un message de bienvenue ou une invite de mot de passe, slimlock les affiche au mauvais endroit.

L'utilisation du même thème que slim suppose que le thème est approprié. La plupart des thèmes existants (y compris nos thèmes par défaut) affichent le mot "Login" sur le panneau, ce qui n'est pas tout à fait correct pour un verrouillage d'écran.

Pour résoudre ces deux problèmes, vous pouvez spécifier un thème différent dans CFGDIR/slimlock.conf, qui remplacera le paramètre dans CFGDIR/slim.conf, mais vous devrez toujours trouver (ou créer) un thème de verrouillage approprié.
