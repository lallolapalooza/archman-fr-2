Documentation de la fonction/sous-routine

sous-routine slahd2 (integer iounit, character*3 path)

SLAHD2

Objectif :

!>
!> SLAHD2 imprime les informations d'en-tête pour les différents chemins de test.
!>

Paramètres

IOUNIT 
!>          IOUNIT est un entier.
!>          À l'entrée, IOUNIT spécifie le numéro d'unité vers lequel les
!>          informations d'en-tête doivent être imprimées.
!>

PATH

!>          PATH est un caractère*3.
!>          À l'entrée, PATH contient le nom du chemin pour lequel les
!>          informations d'en-tête doivent être imprimées. Les chemins actuels sont :
!>
!>             SHS, CHS : Problème de valeurs propres non symétrique.
!>             SST, CST : Problème de valeurs propres symétrique.
!>             SSG, CSG : Problème généralisé de valeurs propres symétrique.
!>             SBD, CBD : Décomposition en valeurs singulières (SVD)
!>             SBB, CBB : Réduction générale d'une bande à une forme bidiagonale
!>
!>          Ces chemins sont également fournis en double précision (remplacer
!>          le S de tête par D et le C de tête par Z dans les noms de chemin).
!>
