sous-routine slarra (integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real spltol, real tnrm, integer nsplit, integer, dimension( * ) isplit, integer info)

SLARRA calcule les points de division avec le seuil spécifié.

Objectif :

!>
!> Calcule les points de division avec le seuil SPLTOL.
!> SLARRA met à zéro les éléments hors diagonale.
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice. N > 0.
!>

D

!>          D est un tableau REAL, dimension (N)
!>          En entrée, les N éléments diagonaux de la matrice tridiagonale
!>          T.
!>

E

!>          E est un tableau REAL, dimension (N)
!>          En entrée, les (N-1) premières entrées contiennent les éléments
!>          sous-diagonaux de la matrice tridiagonale T; E(N) n'a pas besoin
!>          d'être défini.
!>          En sortie, les entrées E( ISPLIT( I ) ), 1 <= I <= NSPLIT,
!>          sont mises à zéro, les autres entrées de E ne sont pas modifiées.
!>

E2

!>          E2 est un tableau REAL, dimension (N)
!>          En entrée, les (N-1) premières entrées contiennent les CARRÉS des
!>          éléments sous-diagonaux de la matrice tridiagonale T;
!>          E2(N) n'a pas besoin d'être défini.
!>          En sortie, les entrées E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, ont été mises à zéro.
!>

SPLTOL

!>          SPLTOL est REAL
!>          Le seuil pour la division. Deux critères peuvent être utilisés :
!>          SPLTOL<0 : critère basé sur la valeur absolue de l'élément hors
!>                      diagonale.
!>          SPLTOL>0 : critère qui préserve la précision relative.
!>

TNRM

!>          TNRM est REAL
!>          La norme de la matrice.
!>

NSPLIT

!>          NSPLIT est INTEGER
!>          Le nombre de blocs dans lesquels T se divise. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT est un tableau INTEGER, dimension (N)
!>          Les points de division, où T se divise en blocs.
!>          Le premier bloc comprend les lignes/colonnes 1 à ISPLIT(1),
!>          le second les lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et le NSPLIT-ième comprend les lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>
