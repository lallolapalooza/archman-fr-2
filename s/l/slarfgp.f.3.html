sous-programme slarfgp (entier n, reel alpha, reel, dimension( * ) x, entier incx, reel tau)

SLARFGP génère un réflecteur élémentaire réel H d'ordre n, tel que

Objectif :

!>
!> SLARFGP génère un réflecteur élémentaire réel H d'ordre n, tel que
!>
!>       H * ( alpha ) = ( beta ),   H**T * H = I.
!>           (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, beta est non négatif, et x est
!> un vecteur réel de (n-1) éléments.  H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**T ) ,
!>                     ( v )
!>
!> où tau est un scalaire réel et v est un vecteur réel de (n-1) éléments.
!>
!> Si les éléments de x sont tous nuls, alors tau = 0 et H est considéré comme
!> la matrice unité.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est REEL
!>          À l'entrée, la valeur alpha.
!>          À la sortie, elle est écrasée par la valeur beta.
!>

X

!>          X est tableau REEL, dimension
!>                         (1+(N-2)*abs(INCX))
!>          À l'entrée, le vecteur x.
!>          À la sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est REEL
!>          La valeur tau.
!>
