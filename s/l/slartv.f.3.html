sous-routine slartv (n, x, incx, y, incy, c, s, incc)
SLARTV applique un vecteur de rotations planes avec des cosinus réels et des sinus réels aux éléments d'une paire de vecteurs.

Documentation de la fonction/sous-routine

sous-routine slartv (integer n, real, dimension( * ) x, integer incx, real, dimension( * ) y, integer incy, real, dimension( * ) c, real, dimension( * ) s, integer incc)

SLARTV applique un vecteur de rotations planes avec des cosinus réels et des sinus réels aux éléments des vecteurs réels x et y.

Objectif:

!>
!> SLARTV applique un vecteur de rotations planes réelles aux éléments des
!> vecteurs réels x et y. Pour i = 1,2,...,n
!>
!>    ( x(i) ) := (  c(i)  s(i) ) ( x(i) )
!>    ( y(i) )    ( -s(i)  c(i) ) ( y(i) )
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de rotations planes à appliquer.
!>

X

!>          X est un tableau REEL,
!>                         dimension (1+(N-1)*INCX)
!>          Le vecteur x.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

Y

!>          Y est un tableau REEL,
!>                         dimension (1+(N-1)*INCY)
!>          Le vecteur y.
!>

INCY

!>          INCY est un ENTIER
!>          L'incrément entre les éléments de Y. INCY > 0.
!>

C

!>          C est un tableau REEL, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

S

!>          S est un tableau REEL, dimension (1+(N-1)*INCC)
!>          Les sinus des rotations planes.
!>

INCC

!>          INCC est un ENTIER
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>
