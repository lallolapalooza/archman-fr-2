SLAQZ4

Objectif :

!>
!> SLAQZ4 exécute un balayage QZ multishift unique
!>

Paramètres

ILSCHUR 
!>          ILSCHUR est LOGIQUE
!>              Détermine si la forme complète de Schur doit être mise à jour ou non
!>

ILQ

!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, Q et Z. N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>

NSHIFTS

!>          NSHIFTS est ENTIER
!>          Le nombre souhaité de décalages à utiliser
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED est ENTIER
!>          La taille souhaitée des fenêtres de calcul
!>

SR

!>          SR est un tableau REEL. SR contient
!>          les parties réelles des décalages à utiliser.
!>

SI

!>          SI est un tableau REEL. SI contient
!>          les parties imaginaires des décalages à utiliser.
!>

SS

!>          SS est un tableau REEL. SS contient
!>          l'échelle des décalages à utiliser.
!>

A

!>          A est un tableau REEL, de dimensions (LDA, N)
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max( 1, N ).
!>

B

!>          B est un tableau REEL, de dimensions (LDB, N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau REEL, de dimensions (LDQ, N)
!>

LDQ

!>          LDQ est ENTIER
!>

Z

!>          Z est un tableau REEL, de dimensions (LDZ, N)
!>

LDZ

!>          LDZ est ENTIER
!>

QC

!>          QC est un tableau REEL, de dimensions (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC est ENTIER
!>

ZC

!>          ZC est un tableau REEL, de dimensions (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ est ENTIER
!>

WORK

!>          WORK est un tableau REEL, de dimensions (MAX(1,LWORK))
!>          En sortie, si INFO >= 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
