Documentation de la fonction/sous-routine

sous-routine slaein (logical rightv, logical noinit, integer n, real, dimension( ldh, * ) h, integer ldh, real wr, real wi, real, dimension( * ) vr, real, dimension( * ) vi, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, real eps3, real smlnum, real bignum, integer info)

SLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

Objectif :

!>
!> SLAEIN utilise l'itération inverse pour trouver un vecteur propre droit ou
!> gauche correspondant à la valeur propre (WR,WI) d'une matrice de Hessenberg
!> supérieure réelle H.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGICAL
!>          = .TRUE. : calcule le vecteur propre droit ;
!>          = .FALSE.: calcule le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGICAL
!>          = .TRUE. : aucun vecteur initial fourni dans (VR,VI).
!>          = .FALSE.: vecteur initial fourni dans (VR,VI).
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau de REAL, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

WR

!>          WR est REAL
!>

WI

!>          WI est REAL
!>          Les parties réelle et imaginaire de la valeur propre de H dont
!>          le vecteur propre droit ou gauche correspondant doit être calculé.
!>

VR

!>          VR est un tableau de REAL, dimension (N)
!>

VI

!>          VI est un tableau de REAL, dimension (N)
!>          À l'entrée, si NOINIT = .FALSE. et WI = 0.0, VR doit contenir
!>          un vecteur de départ réel pour l'itération inverse utilisant la
!>          valeur propre réelle WR ; si NOINIT = .FALSE. et WI.ne.0.0, VR et VI
!>          doivent contenir les parties réelle et imaginaire d'un vecteur
!>          de départ complexe pour l'itération inverse utilisant la valeur
!>          propre complexe (WR,WI) ; sinon VR et VI n'ont pas besoin d'être
!>          définis.
!>          À la sortie, si WI = 0.0 (valeur propre réelle), VR contient le
!>          vecteur propre réel calculé ; si WI.ne.0.0 (valeur propre complexe),
!>          VR et VI contiennent les parties réelle et imaginaire du vecteur
!>          propre complexe calculé. Le vecteur propre est normalisé de sorte
!>          que la composante de magnitude la plus grande ait une magnitude
!>          de 1 ; ici, la magnitude d'un nombre complexe (x,y) est prise
!>          comme |x| + |y|.
!>          VI n'est pas référencé si WI = 0.0.
!>

B

!>          B est un tableau de REAL, dimension (LDB,N)
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= N+1.
!>

WORK

!>          WORK est un tableau de REAL, dimension (N)
!>

EPS3

!>          EPS3 est REAL
!>          Une petite valeur dépendant de la machine utilisée pour perturber
!>          les valeurs propres proches, et pour remplacer les pivots nuls.
!>

SMLNUM

!>          SMLNUM est REAL
!>          Une valeur dépendant de la machine, proche du seuil de
!>          sous-dépassement.
!>

BIGNUM

!>          BIGNUM est REAL
!>          Une valeur dépendant de la machine, proche du seuil de
!>          dépassement.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          = 1 :  l'itération inverse n'a pas convergé ; VR est défini sur la
!>                dernière itération, tout comme VI si WI.ne.0.0.
!>
