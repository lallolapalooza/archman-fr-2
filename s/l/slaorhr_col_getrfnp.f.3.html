sous-programme slaorhr_col_getrfnp (entier m, entier n, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) d, entier info)

SLAORHR_COL_GETRFNP

But :

!>
!> SLAORHR_COL_GETRFNP calcule la factorisation LU modifiée sans
!> pivot d'une matrice réelle générale M par N, A. La factorisation a
!> la forme :
!>
!>     A - S = L * U,
!>
!> où :
!>    S est une matrice signe diagonale M par N avec la diagonale D, de sorte que
!>    D(i) = S(i,i), 1 <= i <= min(M,N). La diagonale D est construite
!>    comme D(i)=-SIGN(A(i,i)), où A(i,i) est la valeur après avoir effectué
!>    i-1 étapes d'élimination gaussienne. Cela signifie que l'élément diagonal
!>    à chaque étape de l'élimination gaussienne est
!>    d'au moins un en valeur absolue (de sorte que la division par zéro n'est pas
!>    possible lors de la division par l'élément diagonal) ;
!>
!>    L est une matrice triangulaire inférieure M par N avec des éléments diagonaux unitaires
!>    (trapézoïdale inférieure si M > N) ;
!>
!>    et U est une matrice triangulaire supérieure M par N
!>    (trapézoïdale supérieure si M < N).
!>
!> Ce sous-programme est un sous-programme auxiliaire utilisé dans le sous-programme
!> de reconstruction de Householder SORHR_COL. Dans SORHR_COL, ce sous-programme est
!> appliqué à une matrice A M par N avec des colonnes orthonormées, où chaque
!> élément est borné par un en valeur absolue. Avec le choix de
!> la matrice S ci-dessus, on peut montrer que l'élément diagonal à chaque
!> étape de l'élimination gaussienne est le plus grand (en valeur absolue) dans
!> la colonne sur ou sous la diagonale, de sorte qu'aucun pivot n'est requis
!> pour la stabilité numérique [1].
!>
!> Pour plus de détails sur l'algorithme de reconstruction de Householder,
!> y compris la factorisation LU modifiée, voir [1].
!>
!> Ceci est la version bloquée "right-looking" de l'algorithme,
!> appelant BLAS de niveau 3 pour mettre à jour la sous-matrice. Pour factoriser un bloc,
!> ce sous-programme appelle le sous-programme récursif SLAORHR_COL_GETRFNP2.
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          À l'entrée, la matrice M par N à factoriser.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A-S=L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est tableau REEL, dimension min(M,N)
!>          Les éléments diagonaux de la matrice signe diagonale M par N, S,
!>          D(i) = S(i,i), où 1 <= i <= min(M,N). Les éléments peuvent
!>          être seulement plus ou moins un.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
