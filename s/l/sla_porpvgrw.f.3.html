fonction réelle sla_porpvgrw (caractère*1 uplo, entier ncols, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldaf, * ) af, entier ldaf, réel, dimension( * ) work)

SLA_PORPVGRW calcule le facteur de croissance du pivot réciproque norm(A)/norm(U) pour une matrice symétrique ou hermitienne définie positive.

Objectif :

!>
!>
!> SLA_PORPVGRW calcule le facteur de croissance du pivot
!> réciproque norm(A)/norm(U). La norme est utilisée. Si ceci est
!> beaucoup plus petit que 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être faible. Cela signifie également que
!> la solution X, les conditionnements estimés et les bornes d'erreur pourraient
!> être peu fiables.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!>

NCOLS

!>          NCOLS est ENTIER
!>     Le nombre de colonnes de la matrice A. NCOLS >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>     En entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est ENTIER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau REEL, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par SPOTRF.
!>

LDAF

!>          LDAF est ENTIER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

WORK

!>          WORK est un tableau REEL, dimension (2*N)
!>
