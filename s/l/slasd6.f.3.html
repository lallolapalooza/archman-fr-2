sous-programme slasd6 (entier icompq, entier nl, entier nr, entier sqre, réel, dimension( * ) d, réel, dimension( * ) vf, réel, dimension( * ) vl, réel alpha, réel bêta, entier, dimension( * ) idxq, entier, dimension( * ) perm, entier givptr, entier, dimension( ldgcol, * ) givcol, entier ldgcol, réel, dimension( ldgnum, * ) givnum, entier ldgnum, réel, dimension( ldgnum, * ) poles, réel, dimension( * ) difl, réel, dimension( * ) difr, réel, dimension( * ) z, entier k, réel c, réel s, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SLASD6 calcule la SVD d'une matrice résultante triangulaire supérieure bidimensionnelle obtenue en fusionnant deux matrices plus petites en ajoutant une ligne. Utilisé par sbdsdc.

Objectif :

!>
!> SLASD6 calcule la SVD d'une matrice bidimensionnelle supérieure mise à jour B
!> obtenue en fusionnant deux matrices plus petites en ajoutant une ligne. Cette
!> routine n'est utilisée que pour le problème qui nécessite toutes les valeurs singulières
!> et éventuellement les matrices de vecteurs singuliers sous forme factorisée.
!> B est une matrice N-par-M avec N = NL + NR + 1 et M = N + SQRE.
!> Une routine associée, SLASD1, gère le cas où toutes les valeurs singulières
!> et les vecteurs singuliers de la matrice bidimensionnelle sont souhaités.
!>
!> SLASD6 calcule la SVD comme suit :
!>
!>               ( D1(entré)    0    0       0 )
!>   B = U(entré) * (   Z1**T   a   Z2**T    b ) * VT(entré)
!>               (   0       0   D2(entré)   0 )
!>
!>     = U(sorti) * ( D(sorti) 0) * VT(sorti)
!>
!> où Z**T = (Z1**T a Z2**T b) = u**T VT**T, et u est un vecteur de dimension M
!> avec ALPHA et BETA dans les entrées NL+1 et NL+2 et des zéros
!> ailleurs ; et l'entrée b est vide si SQRE = 0.
!>
!> Les valeurs singulières de B peuvent être calculées à l'aide de D1, D2, les premières
!> composantes de tous les vecteurs singuliers droits du bloc inférieur, et
!> les dernières composantes de tous les vecteurs singuliers droits du bloc supérieur.
!> Ces composantes sont stockées et mises à jour dans VF et VL,
!> respectivement, dans SLASD6. Par conséquent, U et VT ne sont pas explicitement
!> référencés.
!>
!> Les valeurs singulières sont stockées dans D. L'algorithme comprend deux
!> étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a plusieurs valeurs singulières ou s'il y a un zéro
!>       dans le vecteur Z. Pour chaque occurrence, la dimension de
!>       l'équation séculaire est réduite de un. Cette étape est
!>       effectuée par la routine SLASD7.
!>
!>       La deuxième étape consiste à calculer les valeurs singulières
!>       mises à jour. Ceci est fait en trouvant les racines de
!>       l'équation séculaire via la routine SLASD4 (appelée par SLASD8).
!>       Cette routine met également à jour VF et VL et calcule les distances
!>       entre les valeurs singulières mises à jour et les anciennes valeurs
!>       singulières.
!>
!> SLASD6 est appelée depuis SLASDA.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est ENTIER
!>         Spécifie si les vecteurs singuliers doivent être calculés sous
!>         forme factorisée :
!>         = 0 : Calculer uniquement les valeurs singulières.
!>         = 1 : Calculer également les vecteurs singuliers sous forme factorisée.
!>

NL

!>          NL est ENTIER
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est ENTIER
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est ENTIER
!>         = 0 : le bloc inférieur est une matrice carrée NR-par-NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR-par-(NR+1).
!>
!>         La matrice bidimensionnelle a une dimension de ligne N = NL + NR + 1,
!>         et une dimension de colonne M = N + SQRE.
!>

D

!>          D est tableau REEL, dimension (NL+NR+1).
!>         À l'entrée, D(1:NL,1:NL) contient les valeurs singulières du
!>         bloc supérieur, et D(NL+2:N) contient les valeurs singulières
!>         du bloc inférieur. À la sortie, D(1:N) contient les valeurs
!>         singulières de la matrice modifiée.
!>

VF

!>          VF est tableau REEL, dimension (M)
!>         À l'entrée, VF(1:NL+1) contient les premières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VF(NL+2:M)
!>         contient les premières composantes de tous les vecteurs singuliers
!>         droits du bloc inférieur. À la sortie, VF contient les premières
!>         composantes de tous les vecteurs singuliers droits de la matrice
!>         bidimensionnelle.
!>

VL

!>          VL est tableau REEL, dimension (M)
!>         À l'entrée, VL(1:NL+1) contient les dernières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VL(NL+2:M)
!>         contient les dernières composantes de tous les vecteurs singuliers
!>         droits du bloc inférieur. À la sortie, VL contient les dernières
!>         composantes de tous les vecteurs singuliers droits de la matrice
!>         bidimensionnelle.
!>

ALPHA

!>          ALPHA est REEL
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est REEL
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

IDXQ

!>          IDXQ est tableau ENTIER, dimension (N)
!>         Il contient la permutation qui réintégrera le sous-problème
!>         qui vient d'être résolu dans l'ordre trié, c'est-à-dire
!>         D( IDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

PERM

!>          PERM est tableau ENTIER, dimension ( N )
!>         Les permutations (issues de la déflation et du tri) à appliquer
!>         à chaque bloc. Non référencé si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR est ENTIER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème. Non référencé si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL est tableau ENTIER, dimension ( LDGCOL, 2 )
!>         Chaque paire de nombres indique une paire de colonnes pour une
!>         rotation de Givens. Non référencé si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL est ENTIER
!>         Dimension principale de GIVCOL, doit être au moins N.
!>

GIVNUM

!>          GIVNUM est tableau REEL, dimension ( LDGNUM, 2 )
!>         Chaque nombre indique la valeur C ou S à utiliser dans la
!>         rotation de Givens correspondante. Non référencé si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM est ENTIER
!>         La dimension principale de GIVNUM et POLES, doit être au moins N.
!>

POLES

!>          POLES est tableau REEL, dimension ( LDGNUM, 2 )
!>         À la sortie, POLES(1,*) est un tableau contenant les nouvelles valeurs
!>         singulières obtenues en résolvant l'équation séculaire, et
!>         POLES(2,*) est un tableau contenant les pôles de l'équation
!>         séculaire. Non référencé si ICOMPQ = 0.
!>

DIFL

!>          DIFL est tableau REEL, dimension ( N )
!>         À la sortie, DIFL(I) est la distance entre la I-ème valeur

DIFR

!>          DIFR est un tableau REEL,
!>                   de dimension ( LDDIFR, 2 ) si ICOMPQ = 1 et
!>                   de dimension ( K ) si ICOMPQ = 0.
!>          En sortie, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) n'est pas
!>          défini et ne sera pas référencé.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) est un tableau contenant les
!>          facteurs de normalisation pour la matrice des vecteurs singuliers droits.
!>
!>         Voir SLASD8 pour plus de détails sur DIFL et DIFR.
!>

Z

!>          Z est un tableau REEL, de dimension ( M )
!>         Les premiers éléments de ce tableau contiennent les composantes
!>         du vecteur ligne de mise à jour ajusté par dégonflement.
!>

K

!>          K est un ENTIER
!>         Contient la dimension de la matrice non dégonflée,
!>         Ceci est l'ordre de l'équation séculaire associée. 1 <= K <=N.
!>

C

!>          C est un REEL
!>         C contient des déchets si SQRE =0 et la valeur C d'une rotation de Givens
!>         liée à l'espace nul droit si SQRE = 1.
!>

S

!>          S est un REEL
!>         S contient des déchets si SQRE =0 et la valeur S d'une rotation de Givens
!>         liée à l'espace nul droit si SQRE = 1.
!>

WORK

!>          WORK est un tableau REEL, de dimension ( 4 * M )
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension ( 3 * N )
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = 1, une valeur singulière n'a pas convergé
