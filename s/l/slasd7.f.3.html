SLASD7 fusionne les deux ensembles de valeurs singulières en un seul ensemble trié. Il tente ensuite de dégonfler la taille du problème. Utilisé par sbdsdc.

Objectif :

!>
!> SLASD7 fusionne les deux ensembles de valeurs singulières en un seul
!> ensemble trié. Il tente ensuite de dégonfler la taille du problème. Il y
!> a deux manières dont le dégonflement peut se produire : lorsque deux valeurs
!> singulières ou plus sont proches l'une de l'autre, ou s'il y a une entrée
!> minuscule dans le vecteur Z. Pour chaque occurrence, l'ordre du problème
!> de l'équation séculaire lié est réduit d'un.
!>
!> SLASD7 est appelé depuis SLASD6.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un entier
!>          Spécifie si les vecteurs singuliers doivent être calculés
!>          sous forme compacte, comme suit :
!>          = 0 : Calculer uniquement les valeurs singulières.
!>          = 1 : Calculer les vecteurs singuliers de la matrice
!>               bidiagonale supérieure sous forme compacte.
!>

NL

!>          NL est un entier
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est un entier
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est un entier
!>         = 0 : le bloc inférieur est une matrice carrée NR-par-NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR-par-(NR+1).
!>
!>         La matrice bidiagonale a
!>         N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!>

K

!>          K est un entier
!>         Contient la dimension de la matrice non dégonflée, c'est
!>         l'ordre de l'équation séculaire liée. 1 <= K <=N.
!>

D

!>          D est un tableau REEL, dimension ( N )
!>         À l'entrée, D contient les valeurs singulières des deux sous-matrices
!>         à combiner. À la sortie, D contient les valeurs singulières mises à jour
!>         des suffixes (N-K) (celles qui ont été dégonflées) triées
!>         par ordre croissant.
!>

Z

!>          Z est un tableau REEL, dimension ( M )
!>         À la sortie, Z contient le vecteur ligne de mise à jour dans l'équation
!>         séculaire.
!>

ZW

!>          ZW est un tableau REEL, dimension ( M )
!>         Espace de travail pour Z.
!>

VF

!>          VF est un tableau REEL, dimension ( M )
!>         À l'entrée, VF(1:NL+1) contient les premières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VF(NL+2:M)
!>         contient les premières composantes de tous les vecteurs singuliers droits
!>         du bloc inférieur. À la sortie, VF contient les premières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

VFW

!>          VFW est un tableau REEL, dimension ( M )
!>         Espace de travail pour VF.
!>

VL

!>          VL est un tableau REEL, dimension ( M )
!>         À l'entrée, VL(1:NL+1) contient les dernières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VL(NL+2:M)
!>         contient les dernières composantes de tous les vecteurs singuliers droits
!>         du bloc inférieur. À la sortie, VL contient les dernières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

VLW

!>          VLW est un tableau REEL, dimension ( M )
!>         Espace de travail pour VL.
!>

ALPHA

!>          ALPHA est un REEL
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est un REEL
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

DSIGMA

!>          DSIGMA est un tableau REEL, dimension ( N )
!>         Contient une copie des éléments diagonaux (K-1 valeurs singulières
!>         et un zéro) dans l'équation séculaire.
!>

IDX

!>          IDX est un tableau ENTIER, dimension ( N )
!>         Ceci contiendra la permutation utilisée pour trier le contenu de
!>         D par ordre croissant.
!>

IDXP

!>          IDXP est un tableau ENTIER, dimension ( N )
!>         Ceci contiendra la permutation utilisée pour placer les valeurs
!>         dégonflées de D à la fin du tableau. En sortie, IDXP(2:K)
!>         pointe vers les valeurs D non dégonflées et IDXP(K+1:N)
!>         pointe vers les valeurs singulières dégonflées.
!>

IDXQ

!>          IDXQ est un tableau ENTIER, dimension ( N )
!>         Ceci contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant. Notez que les entrées
!>         de la première moitié de cette permutation doivent d'abord être déplacées
!>         d'une position vers l'arrière ; et les entrées de la seconde moitié
!>         doivent d'abord avoir NL+1 ajouté à leurs valeurs.
!>

PERM

!>          PERM est un tableau ENTIER, dimension ( N )
!>         Les permutations (issues du dégonflement et du tri) à appliquer
!>         à chaque bloc singulier. Non référencé si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR est un ENTIER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème. Non référencé si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL est un tableau ENTIER, dimension ( LDGCOL, 2 )
!>         Chaque paire de nombres indique une paire de colonnes à faire
!>         participer à une rotation de Givens. Non référencé si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL est un ENTIER
!>         La dimension principale de GIVCOL, doit être au moins N.
!>

GIVNUM

!>          GIVNUM est un tableau REEL, dimension ( LDGNUM, 2 )
!>         Chaque nombre indique la valeur C ou S à utiliser dans la
!>         rotation de Givens correspondante. Non référencé si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM est un ENTIER
!>         La dimension principale de GIVNUM, doit être au moins N.
!>

C

!>          C est un REEL
!>         C contient des données indéfinies si SQRE = 0 et la valeur C d'une rotation
!>         de Givens liée à l'espace nul droit si SQRE = 1.
!>

S

!>          S est un REEL
!>         S contient des données indéfinies si SQRE = 0 et la valeur S d'une rotation
!>         de Givens liée à l'espace nul droit si SQRE = 1.
!>

INFO

!>          INFO est un ENTIER
!>         = 0 : succès.
!>         < 0 : si INFO = -i, alors le i-ème argument avait une valeur
!>               illégale.
!>
