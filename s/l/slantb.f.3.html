Documentation de fonction/sous-routine

real function slantb (character norm, character uplo, character diag, integer n, integer k, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) work)

SLANTB retourne la valeur de la norme 1, de la norme de Frobenius, de la norme infinie, ou de l'élément de plus grande valeur absolue d'une matrice triangulaire bande.

But :

!>
!> SLANTB  retourne la valeur de la norme 1,  de la norme de Frobenius,  de
!> la norme infinie,  ou de l'élément de plus grande valeur absolue d'une
!> matrice triangulaire bande A de taille n par n,  avec ( k + 1 )
!> diagonales.
!>

Retourne

SLANTB 
!>
!>    SLANTB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> où norm1  dénote la norme 1 d'une matrice (somme maximale des colonnes),
!> normI  dénote la norme infinie  d'une matrice (somme maximale des lignes) et
!> normF  dénote la norme de Frobenius  d'une matrice (racine carrée de la somme des
!> carrés).  Notez que  max(abs(A(i,j)))  n'est pas une norme matricielle cohérente.
!>

Paramètres

NORM 
!>          NORM est de type CHARACTER*1
!>          Spécifie la valeur à retourner dans SLANTB comme décrit
!>          ci-dessus.
!>

UPLO

!>          UPLO est de type CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou
!>          inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

DIAG

!>          DIAG est de type CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

N

!>          N est de type INTEGER
!>          L'ordre de la matrice A.  N >= 0.  Quand N = 0, SLANTB est
!>          mis à zéro.
!>

K

!>          K est de type INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales de la matrice A si UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB est un tableau de type REAL, de dimension (LDAB,N)
!>          La matrice triangulaire bande supérieure ou inférieure A, stockée
!>          dans les k+1 premières lignes de AB.  La j-ème colonne de A est
!>          stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) pour max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) pour j<=i<=min(n,j+k).
!>          Notez que lorsque DIAG = 'U', les éléments du tableau AB
!>          correspondant aux éléments diagonaux de la matrice A ne sont
!>          pas référencés, mais sont supposés valoir un.
!>

LDAB

!>          LDAB est de type INTEGER
!>          La dimension principale du tableau AB.  LDAB >= K+1.
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (MAX(1,LWORK)),
!>          où LWORK >= N lorsque NORM = 'I'; sinon, WORK n'est pas
!>          référencé.
!>
