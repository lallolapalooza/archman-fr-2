NOM

sliceprint - découpe les documents avec des lignes longues.

SYNTAXE

sliceprint [-ofichier] [options_enscript] [fichiers]

DESCRIPTION

Sliceprint est un script enveloppant l'option --slice de enscript(1). Les découpes de sortie sont écrites dans fichier.1, fichier.2 et ainsi de suite.
