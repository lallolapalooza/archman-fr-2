SLIDETOOL(1) Commandes utilisateur SLIDETOOL(1)

NOM

slidetool - Récupérer des données à partir d'images de lames entières

SYNTAXE

slidetool [--help] [--version]
slidetool assoc icc read nom_fichier [fichier_sortie]
slidetool assoc list fichier...
slidetool assoc read nom_fichier [fichier_sortie]
slidetool prop get propriété fichier...
slidetool prop list [--names] fichier...
slidetool region icc read fichier [fichier_sortie]
slidetool region read fichier x y niveau largeur hauteur [fichier_sortie]
slidetool slide open fichier...
slidetool slide quickhash1 fichier...
slidetool slide vendor fichier...

DESCRIPTION

slidetool utilise OpenSlide pour récupérer des données à partir d'images de lames entières, également connues sous le nom de fichiers d'images virtuelles.

slidetool assoc icc read

Écrit le profil de couleur ICC de l'image associée dans fichier_sortie si spécifié, et sinon dans la sortie standard. Si aucun profil de couleur ICC n'est disponible, l'opération échoue.

slidetool assoc list

Liste les images associées pour une ou plusieurs lames. Les images associées sont de petites images non pyramidales contenant des informations supplémentaires sur la lame, telles que son étiquette.

slidetool assoc read

Écrit l'image associée avec le nom spécifié dans un fichier image PNG. Si fichier_sortie n'est pas spécifié, l'image sera écrite dans la sortie standard.

slidetool prop get

Affiche la valeur d'une seule propriété OpenSlide pour une ou plusieurs lames. Les propriétés sont des morceaux individuels de métadonnées textuelles sur la lame. Les propriétés préfixées par openslide. sont définies par OpenSlide ; les autres sont définies par le format de la lame individuelle.

slidetool prop list

Affiche toutes les propriétés OpenSlide pour une ou plusieurs lames.

slidetool region icc read

Écrit le profil de couleur ICC de la lame dans fichier_sortie si spécifié, et sinon dans la sortie standard. Si aucun profil de couleur ICC n'est disponible, l'opération échoue.

slidetool region read

Écrit une région du niveau spécifié d'une lame dans une image PNG. x et y sont des coordonnées en pixels au niveau 0, le niveau de lame de plus haute résolution. largeur et hauteur sont des dimensions en pixels au niveau spécifié. Si fichier_sortie n'est pas spécifié, l'image sera écrite dans la sortie standard.

Les dimensions de chaque niveau d'une lame peuvent être obtenues avec slidetool prop list.

slidetool slide open

Vérifie si OpenSlide peut ouvrir un ou plusieurs fichiers de lames.

slidetool slide quickhash1

Affiche les sommes de contrôle quickhash-1 d'OpenSlide pour une ou plusieurs lames, dans un format similaire à sha256sum(1).

quickhash-1 est un hachage non cryptographique de 256 bits d'un sous-ensemble des données d'une lame. Il identifie de manière unique une lame particulière, mais ne peut pas être utilisé pour détecter la corruption ou la modification du fichier de lame.

quickhash-1 n'est pas défini pour tous les fichiers de lames pris en charge par OpenSlide. Si une lame n'a pas de quickhash-1, « Aucun quickhash-1 disponible » sera affiché.

slidetool slide vendor

Rapporte le nom du vendeur OpenSlide détecté pour un ou plusieurs fichiers de lames.

OPTIONS

--help
Afficher le résumé d'utilisation.
--names
Pour slidetool prop list, omettre les valeurs des propriétés.
--version
Afficher les informations de version et de copyright.

STATUT DE SORTIE

slidetool retourne 0 en cas de succès, 1 si un fichier de lame n'a pas pu être lu, ou 2 si les arguments sont invalides.
