Documentation de la fonction/sous-programme

sous-programme slargv (integer n, real, dimension( * ) x, integer incx, real, dimension( * ) y, integer incy, real, dimension( * ) c, integer incc)

SLARGV génère un vecteur de rotations planes réelles avec des cosinus réels et des sinus réels.

Objectif :

!>
!> SLARGV génère un vecteur de rotations planes réelles, déterminé par
!> les éléments des vecteurs réels x et y. Pour i = 1,2,...,n
!>
!>    (  c(i)  s(i) ) ( x(i) ) = ( a(i) )
!>    ( -s(i)  c(i) ) ( y(i) ) = (   0  )
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          Le nombre de rotations planes à générer.
!>

X

!>          X est un tableau réel (REAL array),
!>                         dimension (1+(N-1)*INCX)
!>          À l'entrée, le vecteur x.
!>          À la sortie, x(i) est écrasé par a(i), pour i = 1,...,n.
!>

INCX

!>          INCX est un entier (INTEGER)
!>          L'incrément entre les éléments de X. INCX > 0.
!>

Y

!>          Y est un tableau réel (REAL array),
!>                         dimension (1+(N-1)*INCY)
!>          À l'entrée, le vecteur y.
!>          À la sortie, les sinus des rotations planes.
!>

INCY

!>          INCY est un entier (INTEGER)
!>          L'incrément entre les éléments de Y. INCY > 0.
!>

C

!>          C est un tableau réel (REAL array), dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

INCC

!>          INCC est un entier (INTEGER)
!>          L'incrément entre les éléments de C. INCC > 0.
!>
