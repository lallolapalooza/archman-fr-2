Documentation de la fonction/sous-routine

sous-routine slafts (character*3 type, integer m, integer n, integer imat, integer ntests, real, dimension( * ) result, integer, dimension( 4 ) iseed, real thresh, integer iounit, integer ie)

SLAFTS

Objectif :

!>
!>    SLAFTS teste le vecteur résultat par rapport à la valeur seuil pour
!>    déterminer quels tests pour ce type de matrice n'ont pas dépassé le seuil.
!>    La sortie se fait sur le fichier donné par l'unité IOUNIT.
!> 
!>  TYPE   - CHARACTER*3
!>           À l'entrée, TYPE spécifie le type de matrice à utiliser dans les
!>           messages imprimés.
!>           Non modifié.
!>
!>  N      - INTEGER
!>           À l'entrée, N spécifie l'ordre de la matrice de test.
!>           Non modifié.
!>
!>  IMAT   - INTEGER
!>           À l'entrée, IMAT spécifie le type de la matrice de test.
!>           Une liste des différents types est imprimée par SLAHD2
!>           dans le fichier de sortie si un test ne dépasse pas le seuil.
!>           Non modifié.
!>
!>  NTESTS - INTEGER
!>           À l'entrée, NTESTS est le nombre de tests effectués sur les
!>           sous-routines du chemin donné par TYPE.
!>           Non modifié.
!>
!>  RESULT - REAL               tableau de dimension( NTESTS )
!>           À l'entrée, RESULT contient les rapports de test des tests
!>           effectués dans le programme appelant.
!>           Non modifié.
!>
!>  ISEED  - INTEGER            tableau de dimension( 4 )
!>           Contient la graine aléatoire qui a généré la matrice utilisée
!>           pour les tests dont les rapports sont dans RESULT.
!>           Non modifié.
!>
!>  THRESH - REAL
!>           À l'entrée, THRESH spécifie le seuil acceptable des rapports de test.
!>           Si RESULT( K ) > THRESH, alors le K-ième test
!>           n'a pas dépassé le seuil et un message sera imprimé.
!>           Non modifié.
!>
!>  IOUNIT - INTEGER
!>           À l'entrée, IOUNIT spécifie le numéro d'unité du fichier
!>           auquel les messages sont imprimés.
!>           Non modifié.
!>
!>  IE     - INTEGER
!>           À l'entrée, IE contient le nombre de tests qui ont
!>           échoué à dépasser le seuil jusqu'à présent.
!>           Mis à jour à la sortie si certains des rapports dans RESULT échouent également.
!>
