Documentation de la fonction/sous-routine

sous-routine slaqz2 (logique, intent(in) ilq, logique, intent(in) ilz, entier, intent(in) k, entier, intent(in) istartm, entier, intent(in) istopm, entier, intent(in) ihi, reel, dimension( lda, * ) a, entier, intent(in) lda, reel, dimension( ldb, * ) b, entier, intent(in) ldb, entier, intent(in) nq, entier, intent(in) qstart, reel, dimension( ldq, * ) q, entier, intent(in) ldq, entier, intent(in) nz, entier, intent(in) zstart, reel, dimension( ldz, * ) z, entier, intent(in) ldz)

SLAQZ2

Objectif:

!>
!>      SLAQZ2 chasse une protubérance de décalage 2x2 vers le bas dans un crayon de matrice
!>      d'une seule position.
!>

Paramètres

ILQ 
!>          ILQ est LOGIQUE
!>              Détermine s'il faut mettre à jour ou non la matrice Q
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine s'il faut mettre à jour ou non la matrice Z
!>

K

!>          K est ENTIER
!>              Indice indiquant la position de la protubérance.
!>              À l'entrée, la protubérance est située dans
!>              (A(k+1:k+2,k:k+1),B(k+1:k+2,k:k+1)).
!>              À la sortie, la protubérance est située dans
!>              (A(k+2:k+3,k+1:k+2),B(k+2:k+3,k+1:k+2)).
!>

ISTARTM

!>          ISTARTM est ENTIER
!>

ISTOPM

!>          ISTOPM est ENTIER
!>              Les mises à jour de (A,B) sont limitées à
!>              (istartm:k+3,k:istopm). Il est supposé
!>              sans vérification que istartm <= k+1 et
!>              k+2 <= istopm.
!>

IHI

!>          IHI est ENTIER
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>

LDA

!>          LDA est ENTIER
!>              La dimension principale de A telle que déclarée dans
!>              la procédure appelante.
!>

B

!>          B est un tableau REEL, dimension (LDB,N)
!>

LDB

!>          LDB est ENTIER
!>              La dimension principale de B telle que déclarée dans
!>              la procédure appelante.
!>

NQ

!>          NQ est ENTIER
!>              L'ordre de la matrice Q
!>

QSTART

!>          QSTART est ENTIER
!>              Indice de départ de la matrice Q. Les rotations sont appliquées
!>              aux colonnes k+2-qStart:k+4-qStart de Q.
!>

Q

!>          Q est un tableau REEL, dimension (LDQ,NQ)
!>

LDQ

!>          LDQ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>

NZ

!>          NZ est ENTIER
!>              L'ordre de la matrice Z
!>

ZSTART

!>          ZSTART est ENTIER
!>              Indice de départ de la matrice Z. Les rotations sont appliquées
!>              aux colonnes k+1-qStart:k+3-qStart de Z.
!>

Z

!>          Z est un tableau REEL, dimension (LDZ,NZ)
!>

LDZ

!>          LDZ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>
