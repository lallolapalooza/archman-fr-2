fonction réelle sla_syrpvgrw (caractère*1 uplo, entier n, entier info, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldaf, * ) af, entier ldaf, entier, dimension( * ) ipiv, réel, dimension( * ) work)

SLA_SYRPVGRW calcule le facteur de croissance du pivot réciproque norm(A)/norm(U) pour une matrice indéfinie symétrique.

Objectif :

!>
!>
!> SLA_SYRPVGRW calcule le facteur de croissance du pivot réciproque
!> norm(A)/norm(U). La norme est utilisée. Si cela est
!> beaucoup inférieur à 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être médiocre. Cela signifie également que
!> la solution X, les estimations des nombres de condition, et les bornes d'erreur pourraient
!> être peu fiables.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : le triangle supérieur de A est stocké ;
!>       = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A. N >= 0.
!>

INFO

!>          INFO est ENTIER
!>     La valeur de INFO retournée par SSYTRF, c'est-à-dire le pivot de la
!>     colonne INFO est exactement 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est ENTIER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau REEL, dimension (LDAF,N)
!>     La matrice diagonale par blocs D et les multiplicateurs utilisés pour
!>     obtenir le facteur U ou L tels que calculés par SSYTRF.
!>

LDAF

!>          LDAF est ENTIER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>     Détails des échanges et de la structure par blocs de D
!>     tels que déterminés par SSYTRF.
!>

WORK

!>          WORK est un tableau REEL, dimension (2*N)
!>
