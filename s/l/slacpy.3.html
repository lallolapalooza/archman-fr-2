Documentation de la fonction/sous-programme

sous-programme slacpy (caractère uplo, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb)

SLACPY copie tout ou partie d'une matrice bidimensionnelle A dans une autre.

Objectif :

!>
!> SLACPY copie tout ou partie d'une matrice bidimensionnelle A dans une
!> autre matrice B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la partie de la matrice A à copier dans B.
!>          = 'U' :      Partie triangulaire supérieure
!>          = 'L' :      Partie triangulaire inférieure
!>          Sinon :    Toute la matrice A
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type REAL, dimension (LDA,N)
!>          La matrice A de dimensions m x n.  Si UPLO = 'U', seule la partie
!>          triangulaire ou trapézoïdale supérieure est accédée ; si UPLO = 'L',
!>          seule la partie triangulaire ou trapézoïdale inférieure est accédée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau de type REAL, dimension (LDB,N)
!>          En sortie, B = A dans les emplacements spécifiés par UPLO.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>
