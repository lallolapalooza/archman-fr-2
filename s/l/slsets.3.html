sous-routine slsets (entier m, entier p, entier n, reel, dimension( lda, * ) a, reel, dimension( lda, * ) af, entier lda, reel, dimension( ldb, * ) b, reel, dimension( ldb, * ) bf, entier ldb, reel, dimension( * ) c, reel, dimension( * ) cf, reel, dimension( * ) d, reel, dimension( * ) df, reel, dimension( * ) x, reel, dimension( lwork ) work, entier lwork, reel, dimension( * ) rwork, reel, dimension( 2 ) result)

SLSETS

But:

!>
!> SLSETS teste SGGLSE - une sous-routine pour résoudre le problème des moindres carrés linéaires avec égalité de contraintes (LSE).
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de lignes de la matrice B. P >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et B. N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice M-par-N A.
!>

AF

!>          AF est un tableau REEL, dimension (LDA,N)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et R.
!>          LDA >= max(M,N).
!>

B

!>          B est un tableau REEL, dimension (LDB,N)
!>          La matrice P-par-N A.
!>

BF

!>          BF est un tableau REEL, dimension (LDB,N)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF, V et S.
!>          LDB >= max(P,N).
!>

C

!>          C est un tableau REEL, dimension( M )
!>          le vecteur C dans le problème LSE.
!>

CF

!>          CF est un tableau REEL, dimension( M )
!>

D

!>          D est un tableau REEL, dimension( P )
!>          le vecteur D dans le problème LSE.
!>

DF

!>          DF est un tableau REEL, dimension( P )
!>

X

!>          X est un tableau REEL, dimension( N )
!>          le vecteur solution X dans le problème LSE.
!>

WORK

!>          WORK est un tableau REEL, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (2)
!>          Les rapports de test :
!>            RESULT(1) = norm( A*x - c )/ norm(A)*norm(X)*EPS
!>            RESULT(2) = norm( B*x - d )/ norm(B)*norm(X)*EPS
!>
