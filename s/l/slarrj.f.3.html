Documentation de la fonction/sous-programme

sous-programme slarrj (integer n, real, dimension( * ) d, real, dimension( * ) e2, integer ifirst, integer ilast, real rtol, integer offset, real, dimension( * ) w, real, dimension( * ) werr, real, dimension( * ) work, integer, dimension( * ) iwork, real pivmin, real spdiam, integer info)

SLARRJ effectue le raffinement des estimations initiales des valeurs propres de la matrice T.

Objectif :

!>
!> Compte tenu des approximations initiales des valeurs propres de T, SLARRJ
!> effectue une dichotomie pour raffiner les valeurs propres de T,
!> W( IFIRST-OFFSET ) à W( ILAST-OFFSET ), à une plus grande précision. Les
!> estimations initiales pour ces valeurs propres sont entrées dans W, les
!> estimations correspondantes de l'erreur dans ces estimations sont dans WERR.
!> Pendant la dichotomie, les intervalles [gauche, droite] sont maintenus en
!> stockant leurs points médians et leurs demi-largeurs dans les tableaux W
!> et WERR respectivement.
!>

Paramètres

N 
!>          N est un entier (INTEGER).
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau réel (REAL array), dimension (N).
!>          Les N éléments diagonaux de T.
!>

E2

!>          E2 est un tableau réel (REAL array), dimension (N-1).
!>          Les carrés des (N-1) éléments sous-diagonaux de T.
!>

IFIRST

!>          IFIRST est un entier (INTEGER).
!>          L'indice de la première valeur propre à calculer.
!>

ILAST

!>          ILAST est un entier (INTEGER).
!>          L'indice de la dernière valeur propre à calculer.
!>

RTOL

!>          RTOL est un réel (REAL).
!>          Tolérance pour la convergence des intervalles de dichotomie.
!>          Un intervalle [GAUCHE,DROITE] a convergé si
!>          DROITE-GAUCHE < RTOL*MAX(|GAUCHE|,|DROITE|).
!>

OFFSET

!>          OFFSET est un entier (INTEGER).
!>          Décalage pour les tableaux W et WERR, c'est-à-dire que les éléments
!>          IFIRST-OFFSET à ILAST-OFFSET de ces tableaux doivent être utilisés.
!>

W

!>          W est un tableau réel (REAL array), dimension (N).
!>          En entrée, W( IFIRST-OFFSET ) à W( ILAST-OFFSET ) sont des
!>          estimations des valeurs propres de L D L^T indexées de IFIRST à
!>          ILAST.
!>          En sortie, ces estimations sont raffinées.
!>

WERR

!>          WERR est un tableau réel (REAL array), dimension (N).
!>          En entrée, WERR( IFIRST-OFFSET ) à WERR( ILAST-OFFSET ) sont
!>          les erreurs dans les estimations des éléments correspondants dans W.
!>          En sortie, ces erreurs sont raffinées.
!>

WORK

!>          WORK est un tableau réel (REAL array), dimension (2*N).
!>          Espace de travail.
!>

IWORK

!>          IWORK est un tableau entier (INTEGER array), dimension (2*N).
!>          Espace de travail.
!>

PIVMIN

!>          PIVMIN est un réel (REAL).
!>          Le pivot minimum dans la séquence de Sturm pour T.
!>

SPDIAM

!>          SPDIAM est un réel (REAL).
!>          Le diamètre spectral de T.
!>

INFO

!>          INFO est un entier (INTEGER).
!>          Indicateur d'erreur.
!>
