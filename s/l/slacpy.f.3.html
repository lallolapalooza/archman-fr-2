sous-routine slacpy (uplo, m, n, a, lda, b, ldb)
SLACPY copie tout ou partie d'un tableau bidimensionnel dans un autre.

Documentation de la fonction/sous-routine

sous-routine slacpy (caractère uplo, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb)

SLACPY copie tout ou partie d'une matrice bidimensionnelle A dans une autre.

But :

!>
!> SLACPY copie tout ou partie d'une matrice bidimensionnelle A dans une autre
!> matrice B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la partie de la matrice A à copier dans B.
!>          = 'U' :      Partie triangulaire supérieure
!>          = 'L' :      Partie triangulaire inférieure
!>          Autrement : Tout de la matrice A
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          La matrice A de taille m par n.  Si UPLO = 'U', seul le triangle
!>          ou trapèze supérieur est accédé ; si UPLO = 'L', seul le triangle
!>          ou trapèze inférieur est accédé.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau REEL, dimension (LDB,N)
!>          À la sortie, B = A dans les emplacements spécifiés par UPLO.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>
