sous-programme slartgs (real x, real y, real sigma, real cs, real sn)

SLARTGS génère une rotation plane conçue pour introduire un renflement dans l'itération QR implicite de style Golub-Reinsch pour le problème SVD bidiagonal.

Objectif :

!>
!> SLARTGS génère une rotation plane conçue pour introduire un renflement dans
!> l'itération QR implicite de style Golub-Reinsch pour le problème SVD
!> bidiagonal. X et Y sont les entrées de la première ligne, et SIGMA est le décalage.
!> Les CS et SN calculés définissent une rotation plane satisfaisant
!>
!>    [  CS  SN  ]  .  [ X^2 - SIGMA ]  =  [ R ],
!>    [ -SN  CS  ]     [    X * Y    ]     [ 0 ]
!>
!> avec R non négatif.  Si X^2 - SIGMA et X * Y sont 0, alors la
!> rotation est de PI/2.
!>

Paramètres

X 
!>          X est REEL
!>          L'entrée (1,1) d'une matrice bidiagonale supérieure.
!>

Y

!>          Y est REEL
!>          L'entrée (1,2) d'une matrice bidiagonale supérieure.
!>

SIGMA

!>          SIGMA est REEL
!>          Le décalage.
!>

CS

!>          CS est REEL
!>          Le cosinus de la rotation.
!>

SN

!>          SN est REEL
!>          Le sinus de la rotation.
!>
