NOM

slapo-deref - Superposition (overlay) de contrôle de déréférencement pour slapd

SYNOPIS

/etc/openldap/slapd.conf

/etc/openldap/slapd.d

DESCRIPTION

Cette superposition (overlay) implémente le contrôle de déréférencement (draft Dereference control). Elle peut être utilisée avec n'importe quel backend ou globalement pour tous les backends.

EXEMPLES

  database mdb
  ...
  overlay deref

Étant donné les entrées suivantes :

  dn: cn=Howard Chu,ou=people,dc=example,dc=org
  objectClass: inetOrgPerson
  cn: Howard Chu
  sn: Chu
  uid: hyc
  dn: cn=Pierangelo Masarati,ou=people,dc=example,dc=org
  objectClass: inetOrgPerson
  cn: Pierangelo Masarati
  sn: Masarati
  uid: ando
  dn: cn=Test Group,ou=groups,dc=example,dc=org
  objectClass: groupOfNames
  cn: Test Group
  member: cn=Howard Chu,ou=people,dc=example,dc=org
  member: cn=Pierangelo Masarati,ou=people,dc=example,dc=org

Une recherche peut être effectuée avec un contrôle de requête de déréférencement spécifié comme :

  { member, uid }

C'est-à-dire :

  ldapsearch -x -b dc=example,dc=org -E 'deref=member:uid'

Et l'entrée "cn=Test Group" serait retournée avec la valeur de contrôle de réponse :

  { { member, cn=Howard Chu,ou=people,dc=example,dc=org,
      { { uid, [hyc] } } },
    { member, cn=Pierangelo Masarati,ou=people,dc=example,dc=org,
      { { uid, [ando] } } } }

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd
/etc/openldap/slapd.d
répertoire de configuration par défaut de slapd

VOIR AUSSI

slapd.conf(5), slapd-config(5).

"Guide de l'administrateur OpenLDAP" (http://www.OpenLDAP.org/doc/admin/)

Proposition de contrôle de déréférencement LDAP de l'IETF par P. Masarati, H. Chu, dans le document IETF "draft-masarati-ldap-deref-00.txt".
