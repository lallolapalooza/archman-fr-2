real function sla_gbrcond (character trans, integer n, integer kl, integer ku, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, integer cmode, real, dimension( * ) c, integer info, real, dimension( * ) work, integer, dimension( * ) iwork)

SLA_GBRCOND estime le nombre de condition de Skeel pour une matrice bande générale.

Objectif :

!>
!>    SLA_GBRCOND Estime le nombre de condition de Skeel de  op(A) * op2(C)
!>    où op2 est déterminé par CMODE comme suit
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    Le nombre de condition de Skeel  cond(A) = norminf( |inv(A)||A| )
!>    est calculé en calculant des facteurs de mise à l'échelle R tels que
!>    diag(R)*A*op2(C) est équilibré par lignes et en calculant le nombre
!>    de condition standard en norme infinie.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée Transposée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est tableau REAL, dimension (LDAB,N)
!>     À l'entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est INTEGER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau REAL, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, comme
!>     calculé par SGBTRF.  U est stocké comme une matrice bande triangulaire
!>     supérieure avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés pendant la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est INTEGER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est tableau INTEGER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     comme calculé par SGBTRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

CMODE

!>          CMODE est INTEGER
!>     Détermine op2(C) dans la formule op(A) * op2(C) comme suit :
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C est tableau REAL, dimension (N)
!>     Le vecteur C dans la formule op(A) * op2(C).
!>

INFO

!>          INFO est INTEGER
!>       = 0:  Sortie réussie.
!>     i > 0:  Le i-ème argument est invalide.
!>

WORK

!>          WORK est tableau REAL, dimension (5*N).
!>     Espace de travail.
!>

IWORK

!>          IWORK est tableau INTEGER, dimension (N).
!>     Espace de travail.
!>
