Documentation de la fonction/sous-routine

sous-routine slacn2 (integer n, real, dimension( * ) v, real, dimension( * ) x, integer, dimension( * ) isgn, real est, integer kase, integer, dimension( 3 ) isave)

SLACN2 estime la norme 1 d'une matrice carrée réelle, en utilisant la communication inverse pour évaluer les produits matrice-vecteur.

But :

!>
!> SLACN2 estime la norme 1 d'une matrice carrée réelle A.
!> La communication inverse est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         L'ordre de la matrice.  N >= 1.
!>

V

!>          V est un tableau de réels (REAL array), dimension (N)
!>         Lors du retour final, V = A*W,  où  EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau de réels (REAL array), dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**T * X,  si KASE=2,
!>         et SLACN2 doit être re-appelée avec tous les autres paramètres
!>         inchangés.
!>

ISGN

!>          ISGN est un tableau d'entiers (INTEGER array), dimension (N)
!>

EST

!>          EST est un réel (REAL)
!>         À l'entrée avec KASE = 1 ou 2 et ISAVE(1) = 3, EST doit être
!>         inchangé par rapport à l'appel précédent à SLACN2.
!>         À la sortie, EST est une estimation (une borne inférieure) pour norm(A).
!>

KASE

!>          KASE est un entier (INTEGER)
!>         Lors de l'appel initial à SLACN2, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**T * X.
!>         Lors du retour final de SLACN2, KASE sera à nouveau 0.
!>

ISAVE

!>          ISAVE est un tableau d'entiers (INTEGER array), dimension (3)
!>         ISAVE est utilisé pour sauvegarder des variables entre les appels
!>         à SLACN2.
!>
