sous-routine slatzm (side, m, n, v, incv, tau, c1, c2, ldc, work)
SLATZM

Documentation de la fonction/sous-routine

sous-routine slatzm (caractère side, entier m, entier n, réel, dimension( * ) v, entier incv, réel tau, réel, dimension( ldc, * ) c1, réel, dimension( ldc, * ) c2, entier ldc, réel, dimension( * ) work)

SLATZM

But :

!>
!> Cette routine est obsolète et a été remplacée par la routine SORMRZ.
!>
!> SLATZM applique une matrice de Householder générée par STZRQF à une matrice.
!>
!> Soit P = I - tau*u*u**T,   u = ( 1 ),
!>                               ( v )
!> où v est un vecteur (m-1) si SIDE = 'L', ou un vecteur (n-1) si
!> SIDE = 'R'.
!>
!> Si SIDE est égal à 'L', soit
!>        C = [ C1 ] 1
!>            [ C2 ] m-1
!>              n
!> Alors C est écrasé par P*C.
!>
!> Si SIDE est égal à 'R', soit
!>        C = [ C1, C2 ] m
!>               1  n-1
!> Alors C est écrasé par C*P.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : forme P * C
!>          = 'R' : forme C * P
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau REEL, dimension
!>                  (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          Le vecteur v dans la représentation de P. V n'est pas utilisé
!>          si TAU = 0.
!>

INCV

!>          INCV est ENTIER
!>          L'incrément entre les éléments de v. INCV <> 0
!>

TAU

!>          TAU est REEL
!>          La valeur tau dans la représentation de P.
!>

C1

!>          C1 est un tableau REEL, dimension
!>                         (LDC,N) si SIDE = 'L'
!>                         (M,1)   si SIDE = 'R'
!>          À l'entrée, le vecteur C1 de taille n si SIDE = 'L', ou le vecteur C1
!>          de taille m si SIDE = 'R'.
!>
!>          À la sortie, la première ligne de P*C si SIDE = 'L', ou la première
!>          colonne de C*P si SIDE = 'R'.
!>

C2

!>          C2 est un tableau REEL, dimension
!>                         (LDC, N)   si SIDE = 'L'
!>                         (LDC, N-1) si SIDE = 'R'
!>          À l'entrée, la matrice C2 de taille (m - 1) x n si SIDE = 'L', ou la
!>          matrice C2 de taille m x (n - 1) si SIDE = 'R'.
!>
!>          À la sortie, les lignes 2:m de P*C si SIDE = 'L', ou les colonnes 2:m de C*P
!>          si SIDE = 'R'.
!>

LDC

!>          LDC est ENTIER
!>          La dimension principale des tableaux C1 et C2. LDC >= (1,M).
!>

WORK

!>          WORK est un tableau REEL, dimension
!>                      (N) si SIDE = 'L'
!>                      (M) si SIDE = 'R'
!>
