subroutine slarrk (integer n, integer iw, real gl, real gu, real, dimension( * ) d, real, dimension( * ) e2, real pivmin, real reltol, real w, real werr, integer info)

SLARRK calcule une valeur propre d'une matrice tridiagonale symétrique à une précision adéquate.

Objectif:

!>
!> SLARRK calcule une valeur propre d'une matrice tridiagonale
!> symétrique T à une précision adéquate. Ceci est un code auxiliaire à appeler depuis SSTEMR.
!>
!> Pour éviter le dépassement de capacité, la matrice doit être mise à l'échelle de sorte que son
!> plus grand élément en valeur absolue ne dépasse pas overflow**(1/2) * underflow**(1/4), et pour une précision maximale,
!> elle ne doit pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan, Rapport CS41, Département d'Informatique, Stanford
!> University, 21 juillet 1966.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice tridiagonale T. N >= 0.
!>

IW

!>          IW est un ENTIER
!>          L'indice de la valeur propre à retourner.
!>

GL

!>          GL est un RÉEL
!>

GU

!>          GU est un RÉEL
!>          Une borne supérieure et une borne inférieure sur la valeur propre.
!>

D

!>          D est un tableau RÉEL, de dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale T.
!>

E2

!>          E2 est un tableau RÉEL, de dimension (N-1)
!>          Les (n-1) éléments hors diagonale au carré de la matrice tridiagonale T.
!>

PIVMIN

!>          PIVMIN est un RÉEL
!>          Le pivot minimum autorisé dans la séquence de Sturm pour T.
!>

RELTOL

!>          RELTOL est un RÉEL
!>          La largeur relative minimale d'un intervalle. Lorsque un intervalle
!>          est plus étroit que RELTOL fois le plus grand des points d'extrémité (en
!>          valeur absolue), il est considéré comme suffisamment petit, c'est-à-dire
!>          convergé. Note : cela devrait toujours être au moins le radical * l'epsilon machine.
!>

W

!>          W est un RÉEL
!>

WERR

!>          WERR est un RÉEL
!>          La borne d'erreur sur l'approximation correspondante de la valeur propre
!>          dans W.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:       La valeur propre a convergé
!>          = -1:      La valeur propre N'a PAS convergé
!>

Paramètres internes:

!>  FUDGE   REAL            , par défaut = 2
!>          Pour élargir les intervalles de Gershgorin.
!>
