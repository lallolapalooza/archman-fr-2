SLA_GERCOND estime le nombre de conditionnement de Skeel pour une matrice générale.

Objectif :

!>
!>    SLA_GERCOND estime le nombre de conditionnement de Skeel de op(A) * op2(C)
!>    où op2 est déterminé par CMODE comme suit
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    Le nombre de conditionnement de Skeel cond(A) = norminf( |inv(A)||A| )
!>    est calculé en calculant des facteurs de mise à l'échelle R tels que
!>    diag(R)*A*op2(C) est équilibré par lignes et en calculant le nombre de
!>    conditionnement standard en norme infinie.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Conjuguée Transposée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau REAL, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U calculée par SGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     calculée par SGETRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

CMODE

!>          CMODE est INTEGER
!>     Détermine op2(C) dans la formule op(A) * op2(C) comme suit :
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C est un tableau REAL, dimension (N)
!>     Le vecteur C dans la formule op(A) * op2(C).
!>

INFO

!>          INFO est INTEGER
!>       = 0:  Sortie réussie.
!>     i > 0:  Le i-ème argument est invalide.
!>

WORK

!>          WORK est un tableau REAL, dimension (3*N).
!>     Espace de travail.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N).
!>     Espace de travail.2
!>
