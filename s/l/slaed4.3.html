sous-routine slaed4 (integer n, integer i, real, dimension( * ) d, real, dimension( * ) z, real, dimension( * ) delta, real rho, real dlam, integer info)

SLAED4 utilisé par SSTEDC. Trouve une racine unique de l'équation séculaire.

Objectif :

!>
!> Cette sous-routine calcule la I-ième valeur propre mise à jour d'une modification
!> de rang un d'une matrice diagonale dont les éléments sont donnés dans le tableau d, et cela
!>
!>            D(i) < D(j)  pour  i < j
!>
!> et RHO > 0. Ceci est arrangé par la routine appelante, et ne constitue aucune perte
!> de généralité. Le système modifié de rang un est donc
!>
!>            diag( D )  +  RHO * Z * Z_transpose.
!>
!> où nous supposons que la norme euclidienne de Z est 1.
!>
!> La méthode consiste à approximer les fonctions rationnelles de l'équation séculaire
!> par des fonctions rationnelles interpolantes plus simples.
!>

Paramètres

N 
!>          N est INTEGER
!>         La longueur de tous les tableaux.
!>

I

!>          I est INTEGER
!>         L'indice de la valeur propre à calculer.  1 <= I <= N.
!>

D

!>          D est un tableau REAL, dimension (N)
!>         Les valeurs propres originales. On suppose qu'elles sont en
!>         ordre, D(I) < D(J)  pour I < J.
!>

Z

!>          Z est un tableau REAL, dimension (N)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau REAL, dimension (N)
!>         Si N > 2, DELTA contient (D(j) - lambda_I) dans sa j-ième
!>         composante.  Si N = 1, alors DELTA(1) = 1. Si N = 2, voir SLAED5
!>         pour les détails. Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres par SLAED3 et SLAED9.
!>

RHO

!>          RHO est REAL
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DLAM

!>          DLAM est REAL
!>         Le lambda_I calculé, la I-ième valeur propre mise à jour.
!>

INFO

!>          INFO est INTEGER
!>         = 0 : sortie réussie
!>         > 0 : si INFO = 1, le processus de mise à jour a échoué.
!>

Paramètres internes :

!>  Variable logique ORGATI (origin-at-i?) est utilisée pour distinguer
!>  si D(i) ou D(i+1) est traité comme l'origine.
!>
!>            ORGATI = .true.    origine à i
!>            ORGATI = .false.   origine à i+1
!>
!>   Variable logique SWTCH3 (switch-for-3-poles?) sert à noter
!>   si nous travaillons avec TROIS pôles !
!>
!>   MAXIT est le nombre maximum d'itérations autorisé pour chaque
!>   valeur propre.
!>
