SLAQZ4

Objectif :

!>
!> SLAQZ4 exécute un balayage QZ multishift unique
!>

Paramètres

ILSCHUR 
!>          ILSCHUR est LOGIQUE
!>              Détermine s'il faut mettre à jour ou non la forme de Schur complète
!>

ILQ

!>          ILQ est LOGIQUE
!>              Détermine s'il faut mettre à jour ou non la matrice Q
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine s'il faut mettre à jour ou non la matrice Z
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, Q et Z.  N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>

NSHIFTS

!>          NSHIFTS est ENTIER
!>          Le nombre souhaité de décalages à utiliser
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED est ENTIER
!>          La taille souhaitée des fenêtres de calcul
!>

SR

!>          SR est un tableau RÉEL. SR contient
!>          les parties réelles des décalages à utiliser.
!>

SI

!>          SI est un tableau RÉEL. SI contient
!>          les parties imaginaires des décalages à utiliser.
!>

SS

!>          SS est un tableau RÉEL. SS contient
!>          l'échelle des décalages à utiliser.
!>

A

!>          A est un tableau RÉEL, dimension (LDA, N)
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max( 1, N ).
!>

B

!>          B est un tableau RÉEL, dimension (LDB, N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau RÉEL, dimension (LDQ, N)
!>

LDQ

!>          LDQ est ENTIER
!>

Z

!>          Z est un tableau RÉEL, dimension (LDZ, N)
!>

LDZ

!>          LDZ est ENTIER
!>

QC

!>          QC est un tableau RÉEL, dimension (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC est ENTIER
!>

ZC

!>          ZC est un tableau RÉEL, dimension (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ est ENTIER
!>

WORK

!>          WORK est un tableau RÉEL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO >= 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
