sous-programme slasq5 (i0, n0, z, pp, tau, sigma, dmin, dmin1, dmin2, dn, dnm1, dnm2, ieee, eps)
SLASQ5 calcule une transformation dqds en forme ping-pong. Utilisé par sbdsqr et sstegr.

Documentation de la Fonction/Sous-programme

sous-programme slasq5 (integer i0, integer n0, real, dimension( * ) z, integer pp, real tau, real sigma, real dmin, real dmin1, real dmin2, real dn, real dnm1, real dnm2, logical ieee, real eps)

SLASQ5 calcule une transformation dqds en forme ping-pong, une version pour machines IEEE et une autre pour machines non IEEE.

Objectif :

!>
!> SLASQ5 calcule une transformation dqds en forme ping-pong, une
!> version pour machines IEEE et une autre pour machines non IEEE.
!>

Paramètres

I0 
!>          I0 est de type INTEGER
!>        Premier indice.
!>

N0

!>          N0 est de type INTEGER
!>        Dernier indice.
!>

Z

!>          Z est un tableau de type REAL, dimension ( 4*N )
!>        Z contient le tableau qd. EMIN est stocké dans Z(4*N0) pour éviter
!>        un argument supplémentaire.
!>

PP

!>          PP est de type INTEGER
!>        PP=0 pour ping, PP=1 pour pong.
!>

TAU

!>          TAU est de type REAL
!>        Ceci est le décalage.
!>

SIGMA

!>          SIGMA est de type REAL
!>        Ceci est le décalage accumulé jusqu'à cette étape.
!>

DMIN

!>          DMIN est de type REAL
!>        Valeur minimale de d.
!>

DMIN1

!>          DMIN1 est de type REAL
!>        Valeur minimale de d, excluant D( N0 ).
!>

DMIN2

!>          DMIN2 est de type REAL
!>        Valeur minimale de d, excluant D( N0 ) et D( N0-1 ).
!>

DN

!>          DN est de type REAL
!>        d(N0), la dernière valeur de d.
!>

DNM1

!>          DNM1 est de type REAL
!>        d(N0-1).
!>

DNM2

!>          DNM2 est de type REAL
!>        d(N0-2).
!>

IEEE

!>          IEEE est de type LOGICAL
!>        Indicateur pour l'arithmétique IEEE ou non IEEE.
!>

EPS

!>         EPS est de type REAL
!>        Ceci est la valeur d'epsilon utilisée.
!>
