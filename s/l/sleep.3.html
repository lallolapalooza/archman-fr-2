sleep(3) Manuel des fonctions de bibliothèque sleep(3)

NOM

sleep - suspendre l'exécution pendant un nombre spécifié de secondes

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
unsigned int sleep(unsigned int secondes);

DESCRIPTION

La fonction sleep() suspend le thread appelant soit jusqu'à ce que le nombre de secondes spécifié en temps réel dans secondes se soit écoulé, soit jusqu'à ce qu'un signal arrive et ne soit pas ignoré.

VALEUR DE RETOUR

Zéro si le temps demandé s'est écoulé, ou le nombre de secondes restantes à dormir, si l'appel a été interrompu par un gestionnaire de signal.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sleep () Sécurité des threads Non sûr pour les threads sig:SIGCHLD/linux

VERSIONS

Sur Linux, sleep() est implémenté via nanosleep(2). Voir la page de manuel nanosleep(2) pour une discussion sur l'horloge utilisée.

Sur certains systèmes, sleep() peut être implémenté en utilisant alarm(2) et SIGALRM (POSIX.1 le permet) ; mélanger les appels à alarm(2) et sleep() est une mauvaise idée.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

MISE EN GARDE

Utiliser longjmp(3) depuis un gestionnaire de signal ou modifier la gestion de SIGALRM pendant le sommeil entraînera des résultats indéfinis.

VOIR AUSSI

sleep(1), alarm(2), nanosleep(2), signal(2), signal(7)
