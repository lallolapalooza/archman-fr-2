sous-programme slaed0 (integer icompq, integer qsiz, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldqs, * ) qstore, integer ldqs, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLAED0 utilisé par SSTEDC. Calcule toutes les valeurs propres et les vecteurs propres correspondants d'une matrice tridiagonale symétrique non réduite par la méthode de diviser pour régner.

Objectif :

!>
!> SLAED0 calcule toutes les valeurs propres et les vecteurs propres correspondants d'une
!> matrice tridiagonale symétrique en utilisant la méthode de diviser pour régner.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un entier
!>          = 0 : Calcul des valeurs propres seulement.
!>          = 1 : Calcul aussi des vecteurs propres de la matrice symétrique dense originale.
!>                À l'entrée, Q contient la matrice orthogonale utilisée pour réduire la matrice originale en forme tridiagonale.
!>          = 2 : Calcul des valeurs propres et des vecteurs propres de la matrice tridiagonale.
!>

QSIZ

!>          QSIZ est un entier
!>         La dimension de la matrice orthogonale utilisée pour réduire
!>         la matrice complète en forme tridiagonale. QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N est un entier
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

D

!>          D est un tableau de réels, dimension (N)
!>         À l'entrée, la diagonale principale de la matrice tridiagonale.
!>         À la sortie, ses valeurs propres.
!>

E

!>          E est un tableau de réels, dimension (N-1)
!>         Les éléments hors diagonale de la matrice tridiagonale.
!>         À la sortie, E est détruit.
!>

Q

!>          Q est un tableau de réels, dimension (LDQ, N)
!>         À l'entrée, Q doit contenir une matrice orthogonale N x N.
!>         Si ICOMPQ = 0, Q n'est pas référencé.
!>         Si ICOMPQ = 1, à l'entrée, Q est un sous-ensemble des colonnes de la
!>                          matrice orthogonale utilisée pour réduire la
!>                          matrice complète en forme tridiagonale correspondant
!>                          au sous-ensemble de la matrice complète qui est
!>                          décomposée à ce moment.
!>         Si ICOMPQ = 2, à l'entrée, Q sera la matrice identité.
!>                          À la sortie, Q contient les vecteurs propres de la
!>                          matrice tridiagonale.
!>

LDQ

!>          LDQ est un entier
!>         La dimension principale du tableau Q. Si des vecteurs propres sont
!>         désirés, alors LDQ >= max(1,N). Dans tous les cas, LDQ >= 1.
!>

QSTORE

!>          QSTORE est un tableau de réels, dimension (LDQS, N)
!>         Référencé seulement lorsque ICOMPQ = 1. Utilisé pour stocker des parties
!>         de la matrice des vecteurs propres lorsque les multiplications matricielles
!>         prennent place.
!>

LDQS

!>          LDQS est un entier
!>         La dimension principale du tableau QSTORE. Si ICOMPQ = 1,
!>         alors LDQS >= max(1,N). Dans tous les cas, LDQS >= 1.
!>

WORK

!>          WORK est un tableau de réels,
!>         Si ICOMPQ = 0 ou 1, la dimension de WORK doit être au moins
!>                     1 + 3*N + 2*N*lg N + 3*N**2
!>                     ( lg( N ) = plus petit entier k
!>                                 tel que 2^k >= N )
!>         Si ICOMPQ = 2, la dimension de WORK doit être au moins
!>                     4*N + N**2.
!>

IWORK

!>          IWORK est un tableau d'entiers,
!>         Si ICOMPQ = 0 ou 1, la dimension de IWORK doit être au moins
!>                        6 + 6*N + 5*N*lg N.
!>                        ( lg( N ) = plus petit entier k
!>                                    tel que 2^k >= N )
!>         Si ICOMPQ = 2, la dimension de IWORK doit être au moins
!>                        3 + 5*N.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : l'algorithme n'a pas réussi à calculer une valeur propre lors de
!>                l'opération sur la sous-matrice située dans les lignes et colonnes
!>                INFO/(N+1) à mod(INFO,N+1).
!>
