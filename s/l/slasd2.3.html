subroutine slasd2 (integer nl, integer nr, integer sqre, integer k, real, dimension( * ) d, real, dimension( * ) z, real alpha, real beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( * ) dsigma, real, dimension( ldu2, * ) u2, integer ldu2, real, dimension( ldvt2, * ) vt2, integer ldvt2, integer, dimension( * ) idxp, integer, dimension( * ) idx, integer, dimension( * ) idxc, integer, dimension( * ) idxq, integer, dimension( * ) coltyp, integer info)

SLASD2 fusionne les deux ensembles de valeurs singulières en un seul ensemble trié. Utilisé par sbdsdc.

Objectif :

!>
!> SLASD2 fusionne les deux ensembles de valeurs singulières en un seul
!> ensemble trié. Ensuite, il tente de déflater la taille du problème.
!> Il existe deux façons pour que la déflation se produise : lorsque deux ou plusieurs
!> valeurs singulières sont proches l'une de l'autre ou s'il y a une entrée minuscule dans
!> le vecteur Z. Pour chaque occurrence de ce type, l'ordre du problème d'équation séculaire
!> associé est réduit d'une unité.
!>
!> SLASD2 est appelé depuis SLASD1.
!>

Paramètres

NL 
!>          NL est un entier
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est un entier
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est un entier
!>         = 0: le bloc inférieur est une matrice carrée NR-par-NR.
!>         = 1: le bloc inférieur est une matrice rectangulaire NR-par-(NR+1).
!>
!>         La matrice bidiagonale a N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!>

K

!>          K est un entier
!>         Contient la dimension de la matrice non déflatée,
!>         c'est l'ordre de l'équation séculaire associée. 1 <= K <=N.
!>

D

!>          D est un tableau de réels, dimension (N)
!>         À l'entrée, D contient les valeurs singulières des deux sous-matrices
!>         à combiner. À la sortie, D contient les valeurs singulières mises à jour
!>         des trailing (N-K) (celles qui ont été déflatées) triées par ordre croissant.
!>

Z

!>          Z est un tableau de réels, dimension (N)
!>         À la sortie, Z contient le vecteur ligne de mise à jour dans l'équation séculaire.
!>

ALPHA

!>          ALPHA est un réel
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est un réel
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

U

!>          U est un tableau de réels, dimension (LDU,N)
!>         À l'entrée, U contient les vecteurs singuliers gauches de deux
!>         sous-matrices dans les deux blocs carrés avec coins à (1,1),
!>         (NL, NL), et (NL+2, NL+2), (N,N).
!>         À la sortie, U contient les vecteurs singuliers gauches mis à jour
!>         des trailing (N-K) (ceux qui ont été déflatés) dans ses dernières N-K colonnes.
!>

LDU

!>          LDU est un entier
!>         La dimension principale du tableau U. LDU >= N.
!>

VT

!>          VT est un tableau de réels, dimension (LDVT,M)
!>         À l'entrée, VT**T contient les vecteurs singuliers droits de deux
!>         sous-matrices dans les deux blocs carrés avec coins à (1,1),
!>         (NL+1, NL+1), et (NL+2, NL+2), (M,M).
!>         À la sortie, VT**T contient les vecteurs singuliers droits mis à jour
!>         des trailing (N-K) (ceux qui ont été déflatés) dans ses dernières N-K colonnes.
!>         Dans le cas où SQRE =1, la dernière ligne de VT couvre l'espace nul droit.
!>

LDVT

!>          LDVT est un entier
!>         La dimension principale du tableau VT. LDVT >= M.
!>

DSIGMA

!>          DSIGMA est un tableau de réels, dimension (N)
!>         Contient une copie des éléments diagonaux (K-1 valeurs singulières
!>         et un zéro) dans l'équation séculaire.
!>

U2

!>          U2 est un tableau de réels, dimension (LDU2,N)
!>         Contient une copie des K-1 premiers vecteurs singuliers gauches qui
!>         seront utilisés par SLASD3 dans une multiplication matricielle (SGEMM) pour résoudre
!>         pour les nouveaux vecteurs singuliers gauches. U2 est organisé en quatre
!>         blocs. Le premier bloc contient une colonne avec 1 à NL+1 et
!>         zéro partout ailleurs ; le second bloc contient des entrées non nulles uniquement à NL et au-dessus ; le troisième contient des entrées non nulles uniquement en dessous de NL+1 ; et le quatrième est dense.
!>

LDU2

!>          LDU2 est un entier
!>         La dimension principale du tableau U2. LDU2 >= N.
!>

VT2

!>          VT2 est un tableau de réels, dimension (LDVT2,N)
!>         VT2**T contient une copie des K premiers vecteurs singuliers droits
!>         qui seront utilisés par SLASD3 dans une multiplication matricielle (SGEMM) pour
!>         résoudre pour les nouveaux vecteurs singuliers droits. VT2 est organisé en
!>         trois blocs. Le premier bloc contient une ligne qui correspond
!>         à l'élément diagonal spécial 0 dans SIGMA ; le second bloc
!>         contient des non-zéros uniquement à NL+1 et avant ; le troisième bloc
!>         contient des non-zéros uniquement à NL+2 et après.
!>

LDVT2

!>          LDVT2 est un entier
!>         La dimension principale du tableau VT2. LDVT2 >= M.
!>

IDXP

!>          IDXP est un tableau d'entiers, dimension (N)
!>         Il contiendra la permutation utilisée pour placer les valeurs
!>         déflatées de D à la fin du tableau. En sortie, IDXP(2:K)
!>         pointe vers les valeurs D non déflatées et IDXP(K+1:N)
!>         pointe vers les valeurs singulières déflatées.
!>

IDX

!>          IDX est un tableau d'entiers, dimension (N)
!>         Il contiendra la permutation utilisée pour trier le contenu de
!>         D par ordre croissant.
!>

IDXC

!>          IDXC est un tableau d'entiers, dimension (N)
!>         Il contiendra la permutation utilisée pour organiser les colonnes
!>         de la matrice U déflatée en trois groupes : le premier groupe
!>         contient des entrées non nulles uniquement à NL et au-dessus, le second
!>         contient des entrées non nulles uniquement en dessous de NL+2, et le troisième
!>         est dense.
!>

IDXQ

!>          IDXQ est un tableau d'entiers, dimension (N)
!>         Il contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant. Notez que les entrées de la première
!>         moitié de cette permutation doivent d'abord être déplacées d'une position
!>         vers l'arrière ; et les entrées de la seconde moitié
!>         doivent d'abord avoir NL+1 ajouté à leurs valeurs.
!>

COLTYP

!>          COLTYP est un tableau d'entiers, dimension (N)
!>         Comme espace de travail, il contiendra une étiquette qui indiquera
!>         le type d'une colonne dans la matrice U2 ou d'une ligne dans la matrice VT2 :
!>         1 : non nul dans la moitié supérieure seulement
!>         2 : non nul dans la moitié inférieure seulement
!>         3 : dense
!>         4 : déflaté
!>
!>         À la sortie, il s'agit d'un tableau de dimension 4, avec COLTYP(

Function/Subroutine Documentation

slasd2 requires a substantial amount of descriptive text. The following is a summary of the routine's purpose and parameters.

This subroutine computes the singular values and the corresponding singular vectors of a bidiagonal matrix.

It is used for solving the singular value decomposition (SVD) of a general matrix by the divide and conquer method.

Input

NL, NR, SQRE, KORELA, MAXCH, NLCH, NRCH, X, LX, Y, LY, IWORK, WORK, LWORK

Output

X, LX, Y, LY, IWORK, WORK, INFO

Description

The routine first computes the singular values of the matrix represented by the arrays X and Y. These singular values are then used to compute the corresponding singular vectors.

The parameters NL, NR, SQRE, KORELA, MAXCH, NLCH, and NRCH are used to define the structure of the problem and to control the computation. The arrays X and Y store the input singular values and vectors, and the arrays IWORK and WORK are used for temporary storage during the computation.

The parameter INFO indicates the success or failure of the computation. A value of 0 indicates success, while a negative value indicates an error, with the absolute value of INFO specifying the argument that caused the error.
