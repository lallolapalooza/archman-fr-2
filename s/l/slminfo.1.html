NOM

slminfo - obtenir des informations sur un modèle de langage à reculons

SYNTAXE

slminfo [option]... fichier_slm

DESCRIPTION

slminfo donne des informations sur le modèle de langage à reculons 'fichier_slm'. Il peut également imprimer le modèle au format ARPA. Lorsque aucune option n'est donnée, slminfo imprimera seulement le nombre d'éléments dans chaque niveau du modèle de langage.

OPTIONS

-v,--verbose
Activer le mode verbeux, affichant le format arpa.
-p,--pr
Préférer la probabilité normale à -log(Pr) qui est par défaut. Valide sous l'option -v.
-l,--lexicon fichier_dict
Spécifier le lexique. Valide sous l'option -v. Substitue l'ID du mot par le texte du mot dans la sortie.
