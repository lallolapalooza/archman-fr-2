SLAPAUTH(8C) SLAPAUTH(8C)

NOM

slapauth - Vérifie une liste d'identifiants représentés par des chaînes pour l'authentification/autorisation LDAP

SYNTAXE

/usr/bin/slapauth [-d niveau-débogage] [-f slapd.conf] [-F confdir] [-M mécanisme] [-o option[=valeur]] [-R domaine] [-U authcID] [-v] [-X authzID] ID [...]

DESCRIPTION

Slapauth est utilisé pour vérifier le comportement de slapd lors du mappage des identités à des fins d'authentification et d'autorisation, tel que spécifié dans slapd.conf(5). Il ouvre le fichier de configuration slapd.conf(5) ou le backend slapd-config(5), lit les directives authz-policy/olcAuthzPolicy et authz-regexp/olcAuthzRegexp, puis analyse la liste d'ID fournie sur la ligne de commande.

OPTIONS

-d niveau-débogage
active les messages de débogage tels que définis par le niveau-débogage spécifié ; voir slapd(8) pour les détails.
-f slapd.conf
spécifie un fichier slapd.conf(5) alternatif.
-F confdir
spécifie un répertoire de configuration. Si -f et -F sont spécifiés, le fichier de configuration sera lu et converti au format de répertoire de configuration, puis écrit dans le répertoire spécifié. Si aucune de ces options n'est spécifiée, une tentative de lecture du répertoire de configuration par défaut sera effectuée avant d'essayer d'utiliser le fichier de configuration par défaut. Si un répertoire de configuration valide existe, le fichier de configuration par défaut est ignoré.
-M mécanisme
spécifie un mécanisme.
-o option[=valeur]
spécifie une option avec une valeur (optionnelle). Les options/valeurs génériques possibles sont :
              syslog=<sous-systèmes>  (voir `-s' dans slapd(8))
              syslog-level=<niveau> (voir `-S' dans slapd(8))
              syslog-user=<utilisateur>   (voir `-l' dans slapd(8))
-R domaine
spécifie un domaine.
-U authcID
spécifie un ID à utiliser comme authcID pendant la session de test. S'il est présent, et si aucun authzID n'est fourni, les ID de la liste d'ID sont traités comme des authzID.
-X authzID
spécifie un ID à utiliser comme authzID pendant la session de test. S'il est présent, et si aucun authcID n'est fourni, les ID de la liste d'ID sont traités comme des authcID. Si des authcID et des authzID sont tous deux fournis via un commutateur de ligne de commande, la liste d'ID ne peut pas être présente.
-v
active le mode verbeux.

EXEMPLES

La commande

	/usr/bin/slapauth -f //etc/openldap/slapd.conf -v \
            -U bjorn -X u:bjensen
teste si l'utilisateur bjorn peut assumer l'identité de l'utilisateur bjensen, à condition que les directives 
authz-policy from
authz-regexp "^uid=([^,]+).*,cn=auth$"
	"ldap:///dc=example,dc=net??sub?uid=$1"
soient définies dans slapd.conf(5).
