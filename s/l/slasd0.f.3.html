sous-programme slasd0 (n, sqre, d, e, u, ldu, vt, ldvt, smlsiz, iwork, work, info)
SLASD0 calcule les valeurs singulières d'une matrice n par m réelle, bidiagonale supérieure B avec diagonale d et hors diagonale e. Utilisé par sbdsdc.

Documentation de la fonction/sous-programme

sous-programme slasd0 (integer n, integer sqre, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, integer smlsiz, integer, dimension( * ) iwork, real, dimension( * ) work, integer info)

SLASD0 calcule les valeurs singulières d'une matrice B réelle, bidiagonale supérieure de taille N par M, avec diagonale D et hors diagonale E. Utilisé par sbdsdc.

Objectif :

!>
!> En utilisant une approche diviser pour régner, SLASD0 calcule la
!> décomposition en valeurs singulières (SVD) d'une matrice B réelle,
!> bidiagonale supérieure N-par-M avec diagonale D et hors diagonale E, où M = N + SQRE.
!> L'algorithme calcule les matrices orthogonales U et VT telles que
!> B = U * S * VT. Les valeurs singulières S sont écrasées sur D.
!>
!> Un sous-programme apparenté, SLASDA, calcule uniquement les valeurs singulières,
!> et optionnellement, les vecteurs singuliers sous forme compacte.
!>

Paramètres

N 
!>          N est un ENTIER
!>         En entrée, la dimension des lignes de la matrice bidiagonale.
!>         C'est aussi la dimension du tableau de diagonale principale D.
!>

SQRE

!>          SQRE est un ENTIER
!>         Spécifie la dimension des colonnes de la matrice bidiagonale.
!>         = 0 : La matrice bidiagonale a une dimension de colonne M = N ;
!>         = 1 : La matrice bidiagonale a une dimension de colonne M = N+1 ;
!>

D

!>          D est un tableau REEL, dimension (N)
!>         En entrée, D contient la diagonale principale de la matrice
!>         bidiagonale.
!>         En sortie, si INFO = 0, D contient les valeurs singulières.
!>

E

!>          E est un tableau REEL, dimension (M-1)
!>         Contient les entrées sous-diagonales de la matrice bidiagonale.
!>         En sortie, E a été détruit.
!>

U

!>          U est un tableau REEL, dimension (LDU, N)
!>         En sortie, U contient les vecteurs singuliers gauches,
!>          si U est passé en tant qu'identité (N, N).
!>

LDU

!>          LDU est un ENTIER
!>         En entrée, dimension principale de U.
!>

VT

!>          VT est un tableau REEL, dimension (LDVT, M)
!>         En sortie, VT**T contient les vecteurs singuliers droits,
!>          si VT est passé en tant qu'identité (M, M).
!>

LDVT

!>          LDVT est un ENTIER
!>         En entrée, dimension principale de VT.
!>

SMLSIZ

!>          SMLSIZ est un ENTIER
!>         En entrée, taille maximale des sous-problèmes à la
!>         base de l'arbre de calcul.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (8*N)
!>

WORK

!>          WORK est un tableau REEL, dimension (3*M**2+2*M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument était invalide.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>
