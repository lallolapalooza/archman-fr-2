NOM

slogencrypt --- Chiffre les fichiers journaux texte existants en utilisant l'environnement de journalisation sécurisé de {{ site.product.short_name }}.

SYNOPIS

slogencrypt [options] [arguments]

DESCRIPTION

L'utilitaire slogencrypt chiffre les fichiers journaux texte en utilisant un environnement de journalisation sécurisé existant. En utilisant cet utilitaire, les fichiers journaux obtenus d'une installation précédente de syslog-ng OSE ou d'un autre système de journalisation peuvent être transférés vers un environnement de journalisation sécurisé. L'ordre des entrées de journal est préservé. Le chiffrement des fichiers journaux texte à l'aide d'un environnement de journalisation sécurisé existant nécessite la fourniture de la clé de chiffrement actuelle afin de préserver la cohérence.

Exemple : une séquence d'appel générale

slogencrypt -k <fichier clé> -m <fichier MAC> <nouveau fichier clé> <nouveau fichier MAC> <journal texte brut> <fichier de sortie> [compteur]

Arguments

•
<nouveau fichier clé>

Le fichier contenant la nouvelle clé de chiffrement après chiffrement réussi.

•
<nouveau fichier MAC>

Le fichier recevant le nouveau code d'authentification de message (MAC) de la destination sécurisée chiffrée après le chiffrement. Si un fichier existant est fourni, les nouvelles entrées sont ajoutées.

•
<fichier journal d'entrée>

Le fichier journal texte brut qui est chiffré à l'aide de l'environnement de journalisation sécurisé.

•
<fichier journal de sortie>

Le fichier contenant les entrées de journal chiffrées du fichier journal texte brut fourni après le chiffrement.

•
compteur

Le compteur d'entrées de journal actuel de la destination sécurisée chiffrée après le chiffrement. Ceci est requis si les entrées de journal à chiffrer sont ajoutées à une destination sécurisée chiffrée existante.

Options

•
--key-file ou -k

La clé d'hôte actuelle du système où le chiffrement est effectué.

•
--mac-file ou -m

Le fichier MAC actuel du système où le chiffrement est effectué.

•
--help ou -h

Affiche un message d'aide.

Fichiers

/usr/bin/slogencrypt

/etc/syslog-ng.conf
