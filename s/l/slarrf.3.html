sous-routine slarrf (integer n, real, dimension( * ) d, real, dimension( * ) l, real, dimension( * ) ld, integer clstrt, integer clend, real, dimension( * ) w, real, dimension( * ) wgap, real, dimension( * ) werr, real spdiam, real clgapl, real clgapr, real pivmin, real sigma, real, dimension( * ) dplus, real, dimension( * ) lplus, real, dimension( * ) work, integer info)

SLARRF trouve une nouvelle représentation relativement robuste telle qu'au moins une des valeurs propres soit relativement isolée.

Objectif :

!>
!> Étant donnée la représentation initiale L D L^T et son cluster de valeurs
!> propres proches (en mesure relative), W( CLSTRT ), W( CLSTRT+1 ), ...
!> W( CLEND ), SLARRF trouve une nouvelle représentation relativement robuste
!> L D L^T - SIGMA I = L(+) D(+) L(+)^T telle qu'au moins une des
!> valeurs propres de L(+) D(+) L(+)^T soit relativement isolée.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice (sous-bloc, si la matrice est divisée).
!>

D

!>          D est un tableau REEL (REAL), dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

L

!>          L est un tableau REEL (REAL), dimension (N-1)
!>          Les N-1 éléments sous-diagonaux de la matrice bidiagonale
!>          unitaire L.
!>

LD

!>          LD est un tableau REEL (REAL), dimension (N-1)
!>          Les N-1 éléments L(i)*D(i).
!>

CLSTRT

!>          CLSTRT est un entier (INTEGER)
!>          L'indice de la première valeur propre dans le cluster.
!>

CLEND

!>          CLEND est un entier (INTEGER)
!>          L'indice de la dernière valeur propre dans le cluster.
!>

W

!>          W est un tableau REEL (REAL), dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          Les APPROXIMATIONS des valeurs propres de L D L^T par ordre
!>          croissant.
!>          W( CLSTRT ) à W( CLEND ) forment le cluster de valeurs propres
!>          relativement proches.
!>

WGAP

!>          WGAP est un tableau REEL (REAL), dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          La séparation de la valeur propre voisine droite dans W.
!>

WERR

!>          WERR est un tableau REEL (REAL), dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          WERR contient la demi-largeur de l'intervalle d'incertitude
!>          de l'approximation de valeur propre correspondante dans W.
!>

SPDIAM

!>          SPDIAM est un REEL (REAL)
!>          Estimation du diamètre spectral obtenu à partir des
!>          intervalles de Gerschgorin.
!>

CLGAPL

!>          CLGAPL est un REEL (REAL)
!>

CLGAPR

!>          CLGAPR est un REEL (REAL)
!>          Écart absolu à chaque extrémité du cluster.
!>          Défini par la routine appelante pour éviter des décalages trop proches
!>          des valeurs propres extérieures au cluster.
!>

PIVMIN

!>          PIVMIN est un REEL (REAL)
!>          Le pivot minimum autorisé dans la séquence de Sturm.
!>

SIGMA

!>          SIGMA est un REEL (REAL)
!>          Le décalage utilisé pour former L(+) D(+) L(+)^T.
!>

DPLUS

!>          DPLUS est un tableau REEL (REAL), dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D(+).
!>

LPLUS

!>          LPLUS est un tableau REEL (REAL), dimension (N-1)
!>          Les N-1 premiers éléments de LPLUS contiennent les éléments
!>          sous-diagonaux de la matrice bidiagonale unitaire L(+).
!>

WORK

!>          WORK est un tableau REEL (REAL), dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          Indique si le traitement s'est bien déroulé (=0) ou a échoué (=1)
!>
