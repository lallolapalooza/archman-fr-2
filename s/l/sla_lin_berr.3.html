sous-programme sla_lin_berr (integer n, integer nz, integer nrhs, real, dimension( n, nrhs ) res, real, dimension( n, nrhs ) ayb, real, dimension( nrhs ) berr)

SLA_LIN_BERR calcule une erreur résiduelle relative composante par composante.

Objectif :

!>
!>    SLA_LIN_BERR calcule l'erreur résiduelle relative composante par composante
!>    à partir de la formule
!>        max(i) ( abs(R(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>    où abs(Z) est la valeur absolue composante par composante de la matrice
!>    ou du vecteur Z.
!>

Paramètres

N 
!>          N est un ENTIER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

NZ

!>          NZ est un ENTIER
!>     Nous ajoutons (NZ+1)*SLAMCH( 'Safe minimum' ) à R(i) au numérateur pour
!>     éviter les résidus faussement nuls. La valeur par défaut est N.
!>

NRHS

!>          NRHS est un ENTIER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices AYB, RES et BERR.  NRHS >= 0.
!>

RES

!>          RES est un tableau REEL, dimension (N,NRHS)
!>     La matrice résiduelle, c'est-à-dire la matrice R dans la formule
!>     de l'erreur résiduelle relative ci-dessus.
!>

AYB

!>          AYB est un tableau REEL, dimension (N, NRHS)
!>     Le dénominateur dans la formule de l'erreur résiduelle relative ci-dessus,
!>     c'est-à-dire la matrice abs(op(A_s))*abs(Y) + abs(B_s). Les matrices A, Y et B
!>     proviennent du raffinement itératif (voir sla_gerfsx_extended.f).
!>

BERR

!>          BERR est un tableau REEL, dimension (NRHS)
!>     L'erreur résiduelle relative composante par composante de la formule
!>     ci-dessus.
!>
