sous-routine slaed8 (integer icompq, integer k, integer n, integer qsiz, real, dimension( * ) d, real, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, real rho, integer cutpnt, real, dimension( * ) z, real, dimension( * ) dlambda, real, dimension( ldq2, * ) q2, integer ldq2, real, dimension( * ) w, integer, dimension( * ) perm, integer givptr, integer, dimension( 2, * ) givcol, real, dimension( 2, * ) givnum, integer, dimension( * ) indxp, integer, dimension( * ) indx, integer info)

SLAED8 utilisé par SSTEDC. Fusionne les valeurs propres et déflate l'équation séculaire. Utilisé lorsque la matrice d'origine est dense.

Objectif :

!>
!> SLAED8 fusionne les deux ensembles de valeurs propres en un seul
!> ensemble trié. Ensuite, il tente de déflater la taille du problème.
!> Il existe deux façons dont la déflation peut se produire : lorsque deux valeurs propres ou plus sont proches l'une de l'autre, ou s'il y a un élément minuscule dans le
!> vecteur Z. Pour chaque occurrence de ce type, l'ordre du problème d'équation séculaire associé est réduit de un.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est INTEGER
!>          = 0 : Calcule uniquement les valeurs propres.
!>          = 1 : Calcule également les vecteurs propres de la matrice symétrique dense d'origine
!>                également. En entrée, Q contient la matrice orthogonale utilisée
!>                pour réduire la matrice d'origine à la forme tridiagonale.
!>

K

!>          K est INTEGER
!>         Le nombre de valeurs propres non déflatées, et l'ordre de
!>         l'équation séculaire associée.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

QSIZ

!>          QSIZ est INTEGER
!>         La dimension de la matrice orthogonale utilisée pour réduire
!>         la matrice complète à la forme tridiagonale.  QSIZ >= N si ICOMPQ = 1.
!>

D

!>          D est un tableau REAL, de dimension (N)
!>         En entrée, les valeurs propres des deux sous-matrices à
!>         combiner. En sortie, les valeurs propres mises à jour finales (N-K)
!>         (celles qui ont été déflatées) triées par ordre croissant.
!>

Q

!>          Q est un tableau REAL, de dimension (LDQ,N)
!>         Si ICOMPQ = 0, Q n'est pas référencé. Sinon,
!>         en entrée, Q contient les vecteurs propres du système partiellement résolu
!>         qui a été précédemment mis à jour dans des multiplications matricielles
!>         avec d'autres systèmes propres partiellement résolus.
!>         En sortie, Q contient les vecteurs propres mis à jour finaux (N-K)
!>         (ceux qui ont été déflatés) dans ses N-K dernières colonnes.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau INTEGER, de dimension (N)
!>         La permutation qui trie séparément les deux sous-problèmes
!>         en D par ordre croissant. Notez que les éléments de la seconde
!>         moitié de cette permutation doivent d'abord avoir CUTPNT ajouté à
!>         leurs valeurs pour être précis.
!>

RHO

!>          RHO est REAL
!>         En entrée, l'élément hors diagonale associé à la coupure de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         en cours de recombinaison.
!>         En sortie, RHO a été modifié pour la valeur requise par
!>         SLAED3.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         L'emplacement de la dernière valeur propre dans la sous-matrice
!>         principale.  min(1,N) <= CUTPNT <= N.
!>

Z

!>          Z est un tableau REAL, de dimension (N)
!>         En entrée, Z contient le vecteur de mise à jour (la dernière ligne de
!>         la première matrice de vecteurs propres et la première ligne de
!>         la seconde matrice de vecteurs propres).
!>         En sortie, le contenu de Z est détruit par le processus de mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau REAL, de dimension (N)
!>         Une copie des K premières valeurs propres qui seront utilisées par
!>         SLAED3 pour former l'équation séculaire.
!>

Q2

!>          Q2 est un tableau REAL, de dimension (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 n'est pas référencé. Sinon,
!>         une copie des K premiers vecteurs propres qui seront utilisés par
!>         SLAED7 dans une multiplication matricielle (SGEMM) pour mettre à jour les nouveaux
!>         vecteurs propres.
!>

LDQ2

!>          LDQ2 est INTEGER
!>         La dimension principale du tableau Q2.  LDQ2 >= max(1,N).
!>

W

!>          W est un tableau REAL, de dimension (N)
!>         Les K premières valeurs du vecteur z final modifié par déflation
!>         et seront passées à SLAED3.
!>

PERM

!>          PERM est un tableau INTEGER, de dimension (N)
!>         Les permutations (issues de la déflation et du tri) à appliquer
!>         à chaque bloc de valeurs propres.
!>

GIVPTR

!>          GIVPTR est INTEGER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème.
!>

GIVCOL

!>          GIVCOL est un tableau INTEGER, de dimension (2, N)
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau REAL, de dimension (2, N)
!>         Chaque nombre indique la valeur S à utiliser dans la rotation de Givens
!>         correspondante.
!>

INDXP

!>          INDXP est un tableau INTEGER, de dimension (N)
!>         La permutation utilisée pour placer les valeurs déflatées de D à la fin
!>         du tableau.  INDXP(1:K) pointe vers les valeurs D non déflatées
!>         et INDXP(K+1:N) pointe vers les valeurs propres déflatées.
!>

INDX

!>          INDX est un tableau INTEGER, de dimension (N)
!>         La permutation utilisée pour trier le contenu de D par ordre
!>         croissant.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
