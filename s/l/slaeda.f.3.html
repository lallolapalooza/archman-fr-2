sous-programme slaeda (entier n, entier tlvls, entier curlvl, entier curpbm, entier, dimension( * ) prmptr, entier, dimension( * ) perm, entier, dimension( * ) givptr, entier, dimension( 2, * ) givcol, reel, dimension( 2, * ) givnum, reel, dimension( * ) q, entier, dimension( * ) qptr, reel, dimension( * ) z, reel, dimension( * ) ztemp, entier info)

SLAEDA utilisé par SSTEDC. Calcule le vecteur Z déterminant la modification de rang un de la matrice diagonale. Utilisé lorsque la matrice originale est dense.

Objectif :

!>
!> SLAEDA calcule le vecteur Z correspondant à l'étape de fusion dans la
!> Curlvl-ième étape du processus de fusion avec TLVLS étapes pour le CURPBM-ième
!> problème.
!>

Paramètres

N 
!>          N est ENTIER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

TLVLS

!>          TLVLS est ENTIER
!>         Le nombre total de niveaux de fusion dans l'arbre de diviser pour
!>         régner.
!>

CURLVL

!>          CURLVL est ENTIER
!>         Le niveau actuel dans la routine de fusion globale,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM est ENTIER
!>         Le problème actuel au niveau actuel dans la routine de fusion
!>         globale (en comptant de la gauche vers la droite).
!>

PRMPTR

!>          PRMPTR est tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans PERM la
!>         permutation d'un niveau est stockée.  PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et incidemment la
!>         taille du problème complet, non déflaté.
!>

PERM

!>          PERM est tableau ENTIER, dimension (N lg N)
!>         Contient les permutations (issues de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans GIVCOL les
!>         rotations de Givens d'un niveau sont stockées.  GIVPTR(i+1) - GIVPTR(i)
!>         indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est tableau ENTIER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes pour prendre
!>         part à une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est tableau REEL, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la rotation de
!>         Givens correspondante.
!>

Q

!>          Q est tableau REEL, dimension (N**2)
!>         Contient les blocs propres carrés des niveaux précédents, les
!>         positions de départ des blocs sont données par QPTR.
!>

QPTR

!>          QPTR est tableau ENTIER, dimension (N+2)
!>         Contient une liste de pointeurs qui indiquent où dans Q un
!>         bloc propre est stocké.  SQRT( QPTR(i+1) - QPTR(i) ) indique
!>         la taille du bloc.
!>

Z

!>          Z est tableau REEL, dimension (N)
!>         En sortie, ce vecteur contient le vecteur de mise à jour (la dernière
!>         ligne de la première matrice sous-vecteur propre et la première ligne
!>         de la seconde matrice sous-vecteur propre).
!>

ZTEMP

!>          ZTEMP est tableau REEL, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
