sous-routine slaev2 (real a, real b, real c, real rt1, real rt2, real cs1, real sn1)

SLAEV2 calcule les valeurs propres et les vecteurs propres d'une matrice symétrique/Hermitienne 2x2.

Objectif :

!>
!> SLAEV2 calcule la décomposition en valeurs propres d'une matrice symétrique 2x2
!>    [  A   B  ]
!>    [  B   C  ].
!> Au retour, RT1 est la valeur propre de plus grande valeur absolue, RT2 est la
!> valeur propre de plus petite valeur absolue, et (CS1,SN1) est le vecteur propre
!> droit unitaire pour RT1, donnant la décomposition
!>
!>    [ CS1  SN1 ] [  A   B  ] [ CS1 -SN1 ]  =  [ RT1  0  ]
!>    [-SN1  CS1 ] [  B   C  ] [ SN1  CS1 ]     [  0  RT2 ].
!>

Paramètres

A 
!>          A est REAL
!>          L'élément (1,1) de la matrice 2x2.
!>

B

!>          B est REAL
!>          L'élément (1,2) et le conjugué de l'élément (2,1) de
!>          la matrice 2x2.
!>

C

!>          C est REAL
!>          L'élément (2,2) de la matrice 2x2.
!>

RT1

!>          RT1 est REAL
!>          La valeur propre de plus grande valeur absolue.
!>

RT2

!>          RT2 est REAL
!>          La valeur propre de plus petite valeur absolue.
!>

CS1

!>          CS1 est REAL
!>

SN1

!>          SN1 est REAL
!>          Le vecteur (CS1, SN1) est un vecteur propre droit unitaire pour RT1.
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  RT1 est précis à quelques ULP près, à l'exception des dépassements
!>  de capacité (overflow/underflow).
!>
!>  RT2 peut être imprécis s'il y a une annulation massive dans le
!>  déterminant A*C-B*B ; une arithmétique de plus haute précision,
!>  arrondie ou tronquée correctement, serait nécessaire pour calculer RT2
!>  précisément dans tous les cas.
!>
!>  CS1 et SN1 sont précis à quelques ULP près, à l'exception des dépassements
!>  de capacité.
!>
!>  Le dépassement de capacité (overflow) n'est possible que si RT1 est à un facteur
!>  de 5 de la limite supérieure.
!>  Le dépassement de capacité vers le bas (underflow) est sans danger si les données
!>  d'entrée sont nulles ou dépassent le seuil
!>  underflow_threshold / macheps.
!>
