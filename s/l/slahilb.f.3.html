sous-routine slahilb (integer n, integer nrhs, real, dimension(lda, n) a, integer lda, real, dimension(ldx, nrhs) x, integer ldx, real, dimension(ldb, nrhs) b, integer ldb, real, dimension(n) work, integer info)

SLAHILB

But:

!>
!> SLAHILB génère une matrice de Hilbert N par N mise à l'échelle dans A ainsi que
!> NRHS membres de droite dans B et solutions dans X tels que A*X=B.
!>
!> La matrice de Hilbert est mise à l'échelle par M = PPCM(1, 2, ..., 2*N-1) de sorte que toutes
!> les entrées soient des entiers. Les membres de droite sont les NRHS premières
!> colonnes de la matrice identité multipliée par M, et les solutions sont les
!> NRHS premières colonnes de la matrice de Hilbert inverse.
!>
!> Le conditionnement de la matrice de Hilbert croît exponentiellement avec
!> sa taille, approximativement comme O(e ** (3.5*N)). De plus, les matrices de Hilbert
!> inverses au-delà d'une dimension relativement petite ne peuvent pas
!> être générées exactement sans précision supplémentaire. La précision est épuisée
!> lorsque la plus grande entrée dans la matrice de Hilbert inverse est supérieure à
!> 2 puissance du nombre de bits dans la fraction du type de données
!> utilisé plus un, soit 24 pour la simple précision.
!>
!> En simple précision, la solution générée est exacte pour N <= 6 et a
!> une petite erreur composante pour 7 <= N <= 11.
!>

Paramètres

N 
!>          N est un entier
!>          La dimension de la matrice A.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de membres de droite demandés.
!>

A

!>          A est un tableau REEL, dimension (LDA, N)
!>          La matrice de Hilbert mise à l'échelle générée.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= N.
!>

X

!>          X est un tableau REEL, dimension (LDX, NRHS)
!>          Les solutions exactes générées. Actuellement, les NRHS premières
!>          colonnes de la matrice de Hilbert inverse.
!>

LDX

!>          LDX est un entier
!>          La dimension principale du tableau X. LDX >= N.
!>

B

!>          B est un tableau REEL, dimension (LDB, NRHS)
!>          Les membres de droite générés. Actuellement, les NRHS premières
!>          colonnes de PPCM(1, 2, ..., 2*N-1) multiplié par la matrice identité.
!>

LDB

!>          LDB est un entier
!>          La dimension principale du tableau B. LDB >= N.
!>

WORK

!>          WORK est un tableau REEL, dimension (N)
!>

INFO

!>          INFO est un entier
!>          = 0: succès
!>          = 1: N est trop grand ; les données sont toujours générées mais peuvent ne pas
!>               être exactes.
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
