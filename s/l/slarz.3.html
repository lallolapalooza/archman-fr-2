subroutine slarz (side, m, n, l, v, incv, tau, c, ldc, work)
SLARZ applique un réflecteur élémentaire (tel que retourné par stzrzf) à une matrice générale.

Documentation de la fonction/sous-routine

subroutine slarz (caractère side, entier m, entier n, entier l, réel, dimension( * ) v, entier incv, réel tau, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) work)

SLARZ applique un réflecteur élémentaire réel (tel que retourné par stzrzf) à une matrice générale.

Objectif :

!>
!> SLARZ applique un réflecteur élémentaire réel H à une matrice C réelle
!> de taille M par N, soit à gauche, soit à droite. H est représenté sous la
!> forme
!>
!>       H = I - tau * v * v**T
!>
!> où tau est un scalaire réel et v est un vecteur réel.
!>
!> Si tau = 0, alors H est considérée comme la matrice identité.
!>
!>
!> H est un produit de k réflecteurs élémentaires tels que retournés par STZRZF.
!>

Paramètres

SIDE 
!>          SIDE est de type CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est un INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

L

!>          L est un INTEGER
!>          Le nombre d'entrées du vecteur V contenant
!>          la partie significative des vecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V est un tableau de type REAL, de dimension (1+(L-1)*abs(INCV))
!>          Le vecteur v dans la représentation de H tel que retourné par
!>          STZRZF. V n'est pas utilisé si TAU = 0.
!>

INCV

!>          INCV est un INTEGER
!>          Le pas entre les éléments de v. INCV <> 0.
!>

TAU

!>          TAU est un REAL
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau de type REAL, de dimension (LDC,N)
!>          À l'entrée, la matrice C de taille M par N.
!>          À la sortie, C est écrasée par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est un INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de type REAL, de dimension
!>                         (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
!>
