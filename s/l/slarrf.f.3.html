sous-routine slarrf (entier n, reel, dimension( * ) d, reel, dimension( * ) l, reel, dimension( * ) ld, entier clstrt, entier clend, reel, dimension( * ) w, reel, dimension( * ) wgap, reel, dimension( * ) werr, reel spdiam, reel clgapl, reel clgapr, reel pivmin, reel sigma, reel, dimension( * ) dplus, reel, dimension( * ) lplus, reel, dimension( * ) work, entier info)

SLARRF trouve une nouvelle représentation relativement robuste telle qu'au moins une des valeurs propres soit relativement isolée.

Objectif :

!>
!> Étant donné la représentation initiale L D L^T et son cluster de valeurs propres
!> proches (dans une mesure relative), W( CLSTRT ), W( CLSTRT+1 ), ...
!> W( CLEND ), SLARRF trouve une nouvelle représentation relativement robuste
!> L D L^T - SIGMA I = L(+) D(+) L(+)^T telle qu'au moins une des
!> valeurs propres de L(+) D(+) L(+)^T soit relativement isolée.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice (sous-bloc si la matrice est divisée).
!>

D

!>          D est tableau REEL, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

L

!>          L est tableau REEL, dimension (N-1)
!>          Les (N-1) éléments sous-diagonaux de la matrice bidiagonale unitaire
!>          L.
!>

LD

!>          LD est tableau REEL, dimension (N-1)
!>          Les (N-1) éléments L(i)*D(i).
!>

CLSTRT

!>          CLSTRT est ENTIER
!>          L'indice de la première valeur propre dans le cluster.
!>

CLEND

!>          CLEND est ENTIER
!>          L'indice de la dernière valeur propre dans le cluster.
!>

W

!>          W est tableau REEL, dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          Les APPROXIMATIONS des valeurs propres de L D L^T en ordre croissant.
!>          W( CLSTRT ) à W( CLEND ) forment le cluster de valeurs propres relativement
!>          proches.
!>

WGAP

!>          WGAP est tableau REEL, dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          La séparation de la valeur propre voisine droite dans W.
!>

WERR

!>          WERR est tableau REEL, dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          WERR contient la demi-largeur de l'intervalle d'incertitude
!>          de l'APPROXIMATION de valeur propre correspondante dans W
!>

SPDIAM

!>          SPDIAM est REEL
!>          estimation du diamètre spectral obtenu à partir des
!>          intervalles de Gerschgorin
!>

CLGAPL

!>          CLGAPL est REEL
!>

CLGAPR

!>          CLGAPR est REEL
!>          l'écart absolu à chaque extrémité du cluster.
!>          Défini par la routine appelante pour éviter des décalages trop proches
!>          des valeurs propres en dehors du cluster.
!>

PIVMIN

!>          PIVMIN est REEL
!>          Le pivot minimum autorisé dans la séquence de Sturm.
!>

SIGMA

!>          SIGMA est REEL
!>          Le décalage utilisé pour former L(+) D(+) L(+)^T.
!>

DPLUS

!>          DPLUS est tableau REEL, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D(+).
!>

LPLUS

!>          LPLUS est tableau REEL, dimension (N-1)
!>          Les premiers (N-1) éléments de LPLUS contiennent les éléments sous-diagonaux
!>          de la matrice bidiagonale unitaire L(+).
!>

WORK

!>          WORK est tableau REEL, dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est ENTIER
!>          Indique que le traitement s'est bien déroulé (=0) ou a échoué (=1)
!>
