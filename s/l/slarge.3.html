Documentation de la fonction/sous-programme

sous-programme slarge (entier n, réel, dimension( lda, * ) a, entier lda, entier, dimension( 4 ) iseed, réel, dimension( * ) work, entier info)

SLARGE

But :

!>
!> SLARGE pré- et post-multiplie une matrice réelle générale A de taille n x n
!> par une matrice orthogonale aléatoire: A = U*D*U'.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau RÉEL, de dimension (LDA,N)
!>          À l'entrée, la matrice originale A de taille n x n.
!>          À la sortie, A est écrasée par U*A*U' pour une matrice
!>          orthogonale aléatoire U.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= N.
!>

ISEED

!>          ISEED est un tableau ENTIER, de dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires ; les éléments
!>          du tableau doivent être compris entre 0 et 4095, et ISEED(4) doit
!>          être impair.
!>          À la sortie, la graine est mise à jour.
!>

WORK

!>          WORK est un tableau RÉEL, de dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
