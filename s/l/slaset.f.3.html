subroutine slaset (uplo, m, n, alpha, beta, a, lda)
SLASET initialise les éléments hors diagonale et les éléments diagonaux d'une matrice à des valeurs données.

Documentation de la fonction/sous-programme

sous-programme slaset (caractère uplo, entier m, entier n, réel alpha, réel beta, réel, dimension( lda, * ) a, entier lda)

SLASET initialise les éléments hors diagonale et les éléments diagonaux d'une matrice à des valeurs données.

Objectif :

!>
!> SLASET initialise une matrice A de taille m x n à BETA sur la diagonale et
!> ALPHA sur les éléments hors diagonale.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la partie de la matrice A à définir.
!>          = 'U' :      La partie triangulaire supérieure est définie ; la partie
!>                      strictement triangulaire inférieure de A n'est pas modifiée.
!>          = 'L' :      La partie triangulaire inférieure est définie ; la partie
!>                      strictement triangulaire supérieure de A n'est pas modifiée.
!>          Sinon :    Toute la matrice A est définie.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

ALPHA

!>          ALPHA est REAL
!>          La constante à laquelle les éléments hors diagonale doivent être définis.
!>

BETA

!>          BETA est REAL
!>          La constante à laquelle les éléments diagonaux doivent être définis.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          En sortie, la sous-matrice principale m x n de A est définie comme suit :
!>
!>          si UPLO = 'U', A(i,j) = ALPHA, 1<=i<=j-1, 1<=j<=n,
!>          si UPLO = 'L', A(i,j) = ALPHA, j+1<=i<=m, 1<=j<=n,
!>          sinon,     A(i,j) = ALPHA, 1<=i<=m, 1<=j<=n, i.ne.j,
!>
!>          et, pour tout UPLO, A(i,i) = BETA, 1<=i<=min(m,n).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>
