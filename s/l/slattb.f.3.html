sous-programme slattb (entier imat, caractère uplo, caractère trans, caractère diag, entier, dimension( 4 ) iseed, entier n, entier kd, réel, dimension( ldab, * ) ab, entier ldab, réel, dimension( * ) b, réel, dimension( * ) work, entier info)

SLATTB

Objectif :

!>
!> SLATTB génère une matrice test triangulaire en stockage 2D.
!> IMAT et UPLO spécifient de manière unique les propriétés de la matrice test,
!> qui est retournée dans le tableau A.
!>

Paramètres

IMAT 
!>          IMAT est ENTIER
!>          Une clé entière décrivant quelle matrice générer pour ce
!>          chemin.
!>

UPLO

!>          UPLO est CARACTÈRE*1
!>          Spécifie si la matrice A sera triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTÈRE*1
!>          Spécifie si la matrice ou sa transposée sera utilisée.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Conjuguée transposée (= transposée)
!>

DIAG

!>          DIAG est CARACTÈRE*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

ISEED

!>          ISEED est tableau de ENTIER, dimension (4)
!>          Le vecteur de départ pour le générateur de nombres aléatoires (utilisé dans
!>          SLATMS).  Modifié à la sortie.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice à générer.
!>

KD

!>          KD est ENTIER
!>          Le nombre de superdiagonales ou sous-diagonales de la matrice
!>          triangulaire bande A.  KD >= 0.
!>

AB

!>          AB est tableau de RÉEL, dimension (LDAB,N)
!>          La matrice triangulaire bande supérieure ou inférieure A, stockée dans les
!>          KD+1 premières lignes de AB.  Soit j une colonne de A, 1<=j<=n.
!>          Si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j.
!>          Si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

B

!>          B est tableau de RÉEL, dimension (N)
!>

WORK

!>          WORK est tableau de RÉEL, dimension (2*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  Sortie réussie
!>          < 0: si INFO = -k, le k-ème argument avait une valeur illégale
!>
