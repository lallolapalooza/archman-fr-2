sous-programme slartgs (real x, real y, real sigma, real cs, real sn)

SLARTGS génère une rotation de plan conçue pour introduire une bosse dans l'itération QR implicite de style Golub-Reinsch pour le problème SVD bidiagonal.

Objectif :

!>
!> SLARTGS génère une rotation de plan conçue pour introduire une bosse dans
!> l'itération QR implicite de style Golub-Reinsch pour le problème SVD
!> bidiagonal. X et Y sont les entrées de la ligne supérieure, et SIGMA est le
!> décalage. La rotation calculée CS et SN satisfait
!>
!>    [  CS  SN  ]  .  [ X^2 - SIGMA ]  =  [ R ],
!>    [ -SN  CS  ]     [    X * Y    ]     [ 0 ]
!>
!> avec R non négatif. Si X^2 - SIGMA et X * Y sont 0, alors la rotation est de PI/2.
!>

Paramètres

X 
!>          X est REAL
!>          L'entrée (1,1) d'une matrice bidiagonale supérieure.
!>

Y

!>          Y est REAL
!>          L'entrée (1,2) d'une matrice bidiagonale supérieure.
!>

SIGMA

!>          SIGMA est REAL
!>          Le décalage.
!>

CS

!>          CS est REAL
!>          Le cosinus de la rotation.
!>

SN

!>          SN est REAL
!>          Le sinus de la rotation.
!>
