subroutine slasd7 (integer icompq, integer nl, integer nr, integer sqre, integer k, real, dimension( * ) d, real, dimension( * ) z, real, dimension( * ) zw, real, dimension( * ) vf, real, dimension( * ) vfw, real, dimension( * ) vl, real, dimension( * ) vlw, real alpha, real beta, real, dimension( * ) dsigma, integer, dimension( * ) idx, integer, dimension( * ) idxp, integer, dimension( * ) idxq, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, real, dimension( ldgnum, * ) givnum, integer ldgnum, real c, real s, integer info)

SLASD7 fusionne les deux ensembles de valeurs singulières en un seul ensemble trié. Ensuite, il tente de déflater la taille du problème. Il existe deux manières dont la déflation peut se produire : lorsque deux valeurs singulières ou plus sont proches les unes des autres ou s'il y a une entrée minuscule dans le vecteur Z. Pour chaque occurrence de ce type, l'ordre du problème d'équation séculaire associé est réduit de un.

SLASD7 est appelé depuis SLASD6.

Objectif :

!>
!> SLASD7 fusionne les deux ensembles de valeurs singulières en un seul
!> ensemble trié. Ensuite, il tente de déflater la taille du problème. Il
!> existe deux façons dont la déflation peut se produire : lorsque deux ou plusieurs valeurs singulières
!> sont proches les unes des autres ou s'il y a une entrée minuscule dans le
!> vecteur Z. Pour chaque occurrence de ce type, l'ordre du problème
!> d'équation séculaire associé est réduit de un.
!>
!> SLASD7 est appelé depuis SLASD6.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est INTEGER
!>          Spécifie si les vecteurs singuliers doivent être calculés
!>          sous forme compacte, comme suit :
!>          = 0 : Calculer uniquement les valeurs singulières.
!>          = 1 : Calculer les vecteurs singuliers de la matrice
!>               bidiagonale supérieure sous forme compacte.
!>

NL

!>          NL est INTEGER
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est INTEGER
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR-par-NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR-par-(NR+1).
!>
!>         La matrice bidiagonale a
!>         N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!>

K

!>          K est INTEGER
!>         Contient la dimension de la matrice non déflatée, c'est
!>         l'ordre de l'équation séculaire associée. 1 <= K <=N.
!>

D

!>          D est tableau REAL, dimension ( N )
!>         À l'entrée, D contient les valeurs singulières des deux sous-matrices
!>         à combiner. À la sortie, D contient les (N-K) dernières valeurs singulières
!>         mises à jour (celles qui ont été déflatées) triées par ordre croissant.
!>

Z

!>          Z est tableau REAL, dimension ( M )
!>         À la sortie, Z contient le vecteur ligne de mise à jour dans l'équation
!>         séculaire.
!>

ZW

!>          ZW est tableau REAL, dimension ( M )
!>         Espace de travail pour Z.
!>

VF

!>          VF est tableau REAL, dimension ( M )
!>         À l'entrée, VF(1:NL+1) contient les premières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VF(NL+2:M)
!>         contient les premières composantes de tous les vecteurs singuliers
!>         droits du bloc inférieur. À la sortie, VF contient les premières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

VFW

!>          VFW est tableau REAL, dimension ( M )
!>         Espace de travail pour VF.
!>

VL

!>          VL est tableau REAL, dimension ( M )
!>         À l'entrée, VL(1:NL+1) contient les dernières composantes de tous
!>         les vecteurs singuliers droits du bloc supérieur ; et VL(NL+2:M)
!>         contient les dernières composantes de tous les vecteurs singuliers
!>         droits du bloc inférieur. À la sortie, VL contient les dernières composantes
!>         de tous les vecteurs singuliers droits de la matrice bidiagonale.
!>

VLW

!>          VLW est tableau REAL, dimension ( M )
!>         Espace de travail pour VL.
!>

ALPHA

!>          ALPHA est REAL
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est REAL
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

DSIGMA

!>          DSIGMA est tableau REAL, dimension ( N )
!>         Contient une copie des éléments diagonaux (K-1 valeurs singulières
!>         et un zéro) dans l'équation séculaire.
!>

IDX

!>          IDX est tableau INTEGER, dimension ( N )
!>         Ceci contiendra la permutation utilisée pour trier le contenu de
!>         D par ordre croissant.
!>

IDXP

!>          IDXP est tableau INTEGER, dimension ( N )
!>         Ceci contiendra la permutation utilisée pour placer les valeurs
!>         déflatées de D à la fin du tableau. En sortie, IDXP(2:K)
!>         pointe vers les valeurs D non déflatées et IDXP(K+1:N)
!>         pointe vers les valeurs singulières déflatées.
!>

IDXQ

!>          IDXQ est tableau INTEGER, dimension ( N )
!>         Ceci contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant. Notez que les entrées
!>         de la première moitié de cette permutation doivent d'abord être déplacées d'une
!>         position vers l'arrière ; et les entrées de la seconde moitié
!>         doivent d'abord avoir NL+1 ajouté à leurs valeurs.
!>

PERM

!>          PERM est tableau INTEGER, dimension ( N )
!>         Les permutations (issues de la déflation et du tri) à appliquer
!>         à chaque bloc singulier. Non référencé si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR est INTEGER
!>         Le nombre de rotations de Givens qui ont eu lieu dans ce
!>         sous-problème. Non référencé si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL est tableau INTEGER, dimension ( LDGCOL, 2 )
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens. Non référencé si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL est INTEGER
!>         La dimension principale de GIVCOL, doit être au moins N.
!>

GIVNUM

!>          GIVNUM est tableau REAL, dimension ( LDGNUM, 2 )
!>         Chaque nombre indique la valeur C ou S à utiliser dans la
!>         rotation de Givens correspondante. Non référencé si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM est INTEGER
!>         La dimension principale de GIVNUM, doit être au moins N.
!>

C

!>          C est REAL
!>         C contient des données incohérentes si SQRE = 0 et la valeur C d'une rotation
!>         de Givens liée à l'espace nul droit si SQRE = 1.
!>
