sous-programme récursif slarft (direct, storev, n, k, v, ldv, tau, t, ldt)
SLARFT forme le facteur triangulaire T d'un réflecteur de bloc H = I - vtvH

Documentation de la fonction/sous-programme

sous-programme récursif slarft (caractère direct, caractère storev, entier n, entier k, réel, dimension( ldv, * ) v, entier ldv, réel, dimension( * ) tau, réel, dimension( ldt, * ) t, entier ldt)

SLARFT forme le facteur triangulaire T d'un réflecteur de bloc H.

Objectif :

!>
!> SLARFT forme le facteur triangulaire T d'un réflecteur de bloc réel H
!> d'ordre n, qui est défini comme un produit de k réflecteurs élémentaires.
!>
!> Si DIRECT = 'F', H = H(1) H(2) . . . H(k) et T est triangulaire supérieure ;
!>
!> Si DIRECT = 'B', H = H(k) . . . H(2) H(1) et T est triangulaire inférieure.
!>
!> Si STOREV = 'C', le vecteur qui définit le réflecteur élémentaire
!> H(i) est stocké dans la i-ème colonne du tableau V, et
!>
!>    H  =  I - V * T * V**T
!>
!> Si STOREV = 'R', le vecteur qui définit le réflecteur élémentaire
!> H(i) est stocké dans la i-ème ligne du tableau V, et
!>
!>    H  =  I - V**T * T * V
!>

Paramètres

DIRECT 
!>          DIRECT est CHARACTER*1
!>          Spécifie l'ordre dans lequel les réflecteurs élémentaires sont
!>          multipliés pour former le réflecteur de bloc :
!>          = 'F' : H = H(1) H(2) . . . H(k) (Avant)
!>          = 'B' : H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est CHARACTER*1
!>          Spécifie comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés (voir aussi Détails supplémentaires) :
!>          = 'C' : par colonne
!>          = 'R' : par ligne
!>

N

!>          N est INTEGER
!>          L'ordre du réflecteur de bloc H. N >= 0.
!>

K

!>          K est INTEGER
!>          L'ordre du facteur triangulaire T (= le nombre de
!>          réflecteurs élémentaires). K >= 1.
!>

V

!>          V est un tableau de type REAL, de dimension
!>                               (LDV,K) si STOREV = 'C'
!>                               (LDV,N) si STOREV = 'R'
!>          La matrice V. Voir détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C', LDV >= max(1,N) ; si STOREV = 'R', LDV >= K.
!>

TAU

!>          TAU est un tableau de type REAL, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i).
!>

T

!>          T est un tableau de type REAL, de dimension (LDT,K)
!>          Le facteur triangulaire T, de taille k par k, du réflecteur de bloc.
!>          Si DIRECT = 'F', T est triangulaire supérieure ; si DIRECT = 'B', T est
!>          triangulaire inférieure. Le reste du tableau n'est pas utilisé.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

Détails supplémentaires :

!>
!>  La forme de la matrice V et le stockage des vecteurs qui définissent
!>  les H(i) sont mieux illustrés par l'exemple suivant avec n = 5 et
!>  k = 3. Les éléments égaux à 1 ne sont pas stockés.
!>
!>  DIRECT = 'F' et STOREV = 'C' :         DIRECT = 'F' et STOREV = 'R' :
!>
!>               V = (  1       )                 V = (  1 v1 v1 v1 v1 )
!>                   ( v1  1    )                     (     1 v2 v2 v2 )
!>                   ( v1 v2  1 )                     (        1 v3 v3 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  DIRECT = 'B' et STOREV = 'C' :         DIRECT = 'B' et STOREV = 'R' :
!>
!>               V = ( v1 v2 v3 )                 V = ( v1 v1  1       )
!>                   ( v1 v2 v3 )                     ( v2 v2 v2  1    )
!>                   (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
!>                   (     1 v3 )
!>                   (        1 )
!>
