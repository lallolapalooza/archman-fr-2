Documentation de fonction/sous-routine

sous-routine slaqps (integer m, integer n, integer offset, integer nb, integer kb, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, real, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, real, dimension( * ) auxv, real, dimension( ldf, * ) f, integer ldf)

SLAQPS calcule une étape de la factorisation QR avec pivotement de colonnes d'une matrice réelle m x n A en utilisant BLAS niveau 3.

Objectif:

!>
!> SLAQPS calcule une étape de la factorisation QR avec pivotement de colonnes
!> d'une matrice réelle M x N A en utilisant BLAS niveau 3. Il essaie de factoriser
!> NB colonnes de A à partir de la ligne OFFSET+1, et met à jour toute
!> la matrice avec xGEMM de niveau Blas-3.
!>
!> Dans certains cas, en raison d'annulations catastrophiques, il ne peut pas
!> factoriser NB colonnes. Ainsi, le nombre réel de colonnes factorisées
!> est retourné dans KB.
!>
!> Le bloc A(1:OFFSET,1:N) est correctement pivoté, mais pas factorisé.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0
!>

OFFSET

!>          OFFSET est INTEGER
!>          Le nombre de lignes de A qui ont été factorisées dans
!>          les étapes précédentes.
!>

NB

!>          NB est INTEGER
!>          Le nombre de colonnes à factoriser.
!>

KB

!>          KB est INTEGER
!>          Le nombre de colonnes réellement factorisées.
!>

A

!>          A est tableau REAL, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions M x N.
!>          À la sortie, le bloc A(OFFSET+1:M,1:KB) est le facteur
!>          triangulaire obtenu et le bloc A(1:OFFSET,1:N) a été
!>          correctement pivoté, mais non factorisé.
!>          Le reste de la matrice, le bloc A(OFFSET+1:M,KB+1:N) a
!>          été mis à jour.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est tableau INTEGER, dimension (N)
!>          JPVT(I) = K <==> La colonne K de la matrice A complète a été
!>          permuteée à la position I dans AP.
!>

TAU

!>          TAU est tableau REAL, dimension (KB)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

VN1

!>          VN1 est tableau REAL, dimension (N)
!>          Le vecteur avec les normes partielles des colonnes.
!>

VN2

!>          VN2 est tableau REAL, dimension (N)
!>          Le vecteur avec les normes exactes des colonnes.
!>

AUXV

!>          AUXV est tableau REAL, dimension (NB)
!>          Vecteur auxiliaire.
!>

F

!>          F est tableau REAL, dimension (LDF,NB)
!>          Matrice F**T = L*Y**T*A.
!>

LDF

!>          LDF est INTEGER
!>          La dimension principale du tableau F. LDF >= max(1,N).
!>
