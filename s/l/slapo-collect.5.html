NOM

slapo-collect - Superposition d'attributs collectifs pour slapd

SYNTAXE

/etc/openldap/slapd.conf

DESCRIPTION

La superposition collect est utilisée pour fournir une implémentation relativement basique des attributs collectifs RFC 3671. Dans X.500, un attribut collectif est « un attribut utilisateur dont les valeurs sont identiques pour chaque membre d'une collection d'entrées ».

Les attributs collectifs sont ajoutés aux entrées renvoyées par une opération de recherche lorsque l'entrée se trouve dans la portée de l'ancêtre associé. Les attributs collectifs ne peuvent être modifiés que lorsque la modification affecte l'ancêtre associé.

CONFIGURATION

Cette option slapd.conf s'applique à la superposition collect. Elle doit apparaître après la directive overlay.

collectinfo <DN> <attrlist>
Spécifie le DN de l'entrée ancêtre et l'ensemble des attributs collectifs associés, où attrlist est une liste d'attributs séparés par des virgules. Le DN doit se trouver dans le contexte de nommage de la base de données.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd

VOIR AUSSI

slapd.conf(5), slapd-config(5), La superposition slapo-collect(5) prend en charge la configuration dynamique via back-config.
