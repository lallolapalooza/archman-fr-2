sous-routine slaebz (integer ijob, integer nitmax, integer n, integer mmax, integer minp, integer nbmin, real abstol, real reltol, real pivmin, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, integer, dimension( * ) nval, real, dimension( mmax, * ) ab, real, dimension( * ) c, integer mout, integer, dimension( mmax, * ) nab, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLAEBZ calcule le nombre de valeurs propres d'une matrice réelle symétrique tridiagonale qui sont inférieures ou égales à une valeur donnée, et effectue d'autres tâches requises par la sous-routine sstebz.

Objectif :

!>
!> SLAEBZ contient les boucles d'itération qui calculent et utilisent
!> la fonction N(w), qui est le nombre de valeurs propres d'une matrice
!> tridiagonale symétrique T inférieur ou égal à son argument w.  Elle
!> effectue un choix entre deux types de boucles :
!>
!> IJOB=1, suivi de
!> IJOB=2 : Elle prend comme entrée une liste d'intervalles et retourne
!>         une liste d'intervalles suffisamment petits dont l'union
!>         contient les mêmes valeurs propres que l'union des intervalles
!>         originaux.
!>         Les intervalles d'entrée sont (AB(j,1),AB(j,2)], j=1,...,MINP.
!>         L'intervalle de sortie (AB(j,1),AB(j,2)] contiendra
!>         les valeurs propres NAB(j,1)+1,...,NAB(j,2), où 1 <= j <= MOUT.
!>
!> IJOB=3 : Elle effectue une recherche dichotomique dans chaque intervalle
!>         d'entrée (AB(j,1),AB(j,2)] pour un point w(j) tel que
!>         N(w(j))=NVAL(j), et utilise C(j) comme point de départ de
!>         la recherche.  Si un tel w(j) est trouvé, alors en sortie
!>         AB(j,1)=AB(j,2)=w.  Si aucun tel w(j) n'est trouvé, alors en sortie
!>         (AB(j,1),AB(j,2)] sera un petit intervalle contenant le
!>         point où N(w) saute à travers NVAL(j), à moins que ce point
!>         ne se trouve en dehors de l'intervalle initial.
!>
!> Notez que les intervalles sont dans tous les cas des intervalles semi-ouverts,
!> c'est-à-dire de la forme (a,b], qui inclut b mais pas a.
!>
!> Pour éviter le débordement (underflow), la matrice doit être mise à
!> l'échelle de sorte que son plus grand élément n'excède pas
!> overflow**(1/2) * underflow**(1/4)
!> en valeur absolue. Pour assurer le calcul le plus précis
!> des petites valeurs propres, la matrice doit être mise à l'échelle pour ne
!> pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan, Rapport CS41, Département d'Informatique, Université de
!> Stanford, 21 juillet 1966
!>
!> Note : les arguments ne sont généralement PAS vérifiés pour des valeurs
!> déraisonnables.
!>

Paramètres

IJOB 
!>          IJOB est un INTEGER
!>          Spécifie ce qui doit être fait :
!>          = 1 : Calculer NAB pour les intervalles initiaux.
!>          = 2 : Effectuer une itération de dichotomie pour trouver les valeurs
!>                propres de T.
!>          = 3 : Effectuer une itération de dichotomie pour inverser N(w),
!>                c'est-à-dire trouver un point qui a un nombre spécifié de
!>                valeurs propres de T à sa gauche.
!>          D'autres valeurs entraîneront le retour de SLAEBZ avec INFO=-1.
!>

NITMAX

!>          NITMAX est un INTEGER
!>          Le nombre maximum d'itérations de dichotomie à effectuer, c'est-à-dire
!>          qu'un intervalle de largeur W ne sera pas rendu plus petit que
!>          2^(-NITMAX) * W. Si tous les intervalles n'ont pas convergé
!>          après NITMAX itérations, alors INFO est défini au nombre
!>          d'intervalles non convergés.
!>

N

!>          N est un INTEGER
!>          La dimension n de la matrice tridiagonale T. Elle doit être au
!>          moins de 1.
!>

MMAX

!>          MMAX est un INTEGER
!>          Le nombre maximum d'intervalles. Si plus de MMAX intervalles
!>          sont générés, alors SLAEBZ s'arrêtera avec INFO=MMAX+1.
!>

MINP

!>          MINP est un INTEGER
!>          Le nombre initial d'intervalles. Il ne peut pas être supérieur à
!>          MMAX.
!>

NBMIN

!>          NBMIN est un INTEGER
!>          Le plus petit nombre d'intervalles qui doivent être traités
!>          en utilisant une boucle vectorielle. Si zéro, alors seule la
!>          boucle scalaire sera utilisée.
!>

ABSTOL

!>          ABSTOL est un REAL
!>          La largeur minimale (absolue) d'un intervalle. Quand un
!>          intervalle est plus étroit que ABSTOL, ou que RELTOL fois le
!>          plus grand (en magnitude) des points extrêmes, alors il est
!>          considéré comme suffisamment petit, c'est-à-dire convergé.
!>          Doit être supérieur ou égal à zéro.
!>

RELTOL

!>          RELTOL est un REAL
!>          La largeur relative minimale d'un intervalle. Quand un
!>          intervalle est plus étroit que ABSTOL, ou que RELTOL fois le
!>          plus grand (en magnitude) des points extrêmes, alors il est
!>          considéré comme suffisamment petit, c'est-à-dire convergé.
!>          Note : cela devrait toujours être au moins epsilon_machine * radix.
!>

PIVMIN

!>          PIVMIN est un REAL
!>          La valeur absolue minimale d'un pivot dans la boucle de
!>          séquence de Sturm.
!>          Doit être au moins max |e(j)**2|*safe_min et au moins
!>          safe_min, où safe_min est au moins le plus petit nombre qui
!>          peut diviser un sans débordement.
!>

D

!>          D est un tableau de REAL, dimension (N)
!>          Les éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau de REAL, dimension (N)
!>          Les éléments hors diagonale de la matrice tridiagonale T dans
!>          les positions 1 à N-1. E(N) est arbitraire.
!>

E2

!>          E2 est un tableau de REAL, dimension (N)
!>          Les carrés des éléments hors diagonale de la matrice
!>          tridiagonale T. E2(N) est ignoré.
!>

NVAL

!>          NVAL est un tableau de INTEGER, dimension (MINP)
!>          Si IJOB=1 ou 2, non référencé.
!>          Si IJOB=3, les valeurs souhaitées de N(w). Les éléments de NVAL
!>          seront réordonnés pour correspondre aux intervalles dans AB.
!>          Ainsi, NVAL(j) en sortie sera différent de NVAL(j) en entrée,
!>          mais correspondra à l'intervalle (AB(j,1),AB(j,2)] en sortie.
!>

AB

!>          AB est un tableau de REAL, dimension (MMAX,2)
!>          Les points extrêmes des intervalles. AB(j,1) est a(j), le point
!>          extrême gauche du j-ième intervalle, et AB(j,2) est b(j), le
!>          point extrême droit du j-ième intervalle. Les intervalles d'entrée
!>          seront, en général, modifiés, divisés et réordonnés par le
!>          calcul.
!>

C

!>          C est un tableau de REAL, dimension (MMAX)
!>          Si IJOB=1, ignoré.
!>          Si IJOB=2, espace de travail.
!>          Si IJOB=3, alors en entrée C(j) doit être initialisé au
!>          premier point de recherche dans la recherche dichotomique.
!>

MOUT

!>          MOUT est un INTEGER
!>          Si IJOB=1, le nombre de valeurs propres dans les intervalles.
!>          Si IJOB=2 ou 3, le nombre d'intervalles en sortie.
!>          Si IJOB=3, MOUT sera égal à MINP.
!>

NAME

SLAEBZ - compute NEIG eigenvalues of a symmetric tridiagonal matrix

SYNOPSIS

SUBROUTINE SLAEBZ(
     IJOB,     NMAX,     NTOTAL,   NLVL,     NDIV,     THRESH,
     A,        LDA,      B,        LDB,      C,        LDC,
     F,        LDF,      G,        LDG,      NASM,     NBM,
     NAB,      WORK,     IWORK,    INFO )
CHARACTER     *     IJOB
INTEGER     NMAX,     NTOTAL,   NLVL,     NDIV,     LDA,
     LDB,      LDC,      LDF,      LDG,      NASM( * ), NBM( * ),
     NAB( *, * ),  IWORK( * ), INFO
REAL    THRESH, A( * ), B( * ), C( * ), F( * ), G( * )

Function/Subroutine Documentation

IJOB

!>  IJOB is CHARACTER*1
!>  IJOB = 'B':  Compute NEIG eigenvalues in each interval (A(I,1), A(I,2))
!>             of the matrix A.
!>  IJOB = 'E':  Compute eigenvalues of matrix A.
!>  IJOB = 'S':  Compute NEIG eigenvalues of matrix A.
!>  IJOB = 'N':  Compute NEIG eigenvalues of matrix A.
!>  IJOB = 'C':  Compute NEIG eigenvalues of matrix A.

NMAX

!>  NMAX is INTEGER
!>  The maximum number of eigenvalues which may be generated in any
!>  interval.

NTOTAL

!>  NTOTAL is INTEGER
!>  The total number of eigenvalues requested.

NLVL

!>  NLVL is INTEGER
!>  The number of levels of subdivision of the initial interval.

NDIV

!>  NDIV is INTEGER
!>  The number of divisions of the initial interval.

THRESH

!>  THRESH is REAL
!>  Threshold of matrix norm used to estimate eigenvalues.

A

!>  A is REAL array, dimension (LDA, NLVL)
!>  On entry, A(I,J) contains the approximate L-th eigenvalue of the
!>  subproblem of order K.
!>  On exit, A(I,J) contains the approximate L-th eigenvalue of the
!>  subproblem of order K.

LDA

!>  LDA is INTEGER
!>  The leading dimension of the array A. LDA >= max(1, NLVL).

B

!>  B is REAL array, dimension (LDB, NLVL)
!>  On entry, B(I,J) contains the approximate U-th eigenvalue of the
!>  subproblem of order K.
!>  On exit, B(I,J) contains the approximate U-th eigenvalue of the
!>  subproblem of order K.

LDB

!>  LDB is INTEGER
!>  The leading dimension of the array B. LDB >= max(1, NLVL).

C

!>  C is REAL array, dimension (LDC, NLVL)
!>  On entry, C(I,J) contains the approximate L-th eigenvalue of the
!>  subproblem of order K.
!>  On exit, C(I,J) contains the approximate L-th eigenvalue of the
!>  subproblem of order K.

LDC

!>  LDC is INTEGER
!>  The leading dimension of the array C. LDC >= max(1, NLVL).

F

!>  F is REAL array, dimension (LDF, NLVL)
!>  On entry, F(I,J) contains the approximate U-th eigenvalue of the
!>  subproblem of order K.
!>  On exit, F(I,J) contains the approximate U-th eigenvalue of the
!>  subproblem of order K.

LDF

!>  LDF is INTEGER
!>  The leading dimension of the array F. LDF >= max(1, NLVL).

G

!>  G is REAL array, dimension (LDG, NLVL)
!>  On entry, G(I,J) contains the approximate U-th eigenvalue of the
!>  subproblem of order K.
!>  On exit, G(I,J) contains the approximate U-th eigenvalue of the
!>  subproblem of order K.

LDG

!>  LDG is INTEGER
!>  The leading dimension of the array G. LDG >= max(1, NLVL).

NASM

!>  NASM is INTEGER array, dimension (NLVL)
!>  On entry, NASM(I) contains the number of eigenvalues in the interval
!>  (A(I,1), A(I,2)) of the matrix A.
!>  On exit, NASM(I) contains the number of eigenvalues in the interval
!>  (A(I,1), A(I,2)) of the matrix A.

NBM

!>  NBM is INTEGER array, dimension (NLVL)
!>  On entry, NBM(I) contains the number of eigenvalues in the interval
!>  (B(I,1), B(I,2)) of the matrix B.
!>  On exit, NBM(I) contains the number of eigenvalues in the interval
!>  (B(I,1), B(I,2)) of the matrix B.

NAB

!>  NAB is INTEGER array, dimension (NMAX, NMAX)
!>  On entry, NAB(I,J) is the number of eigenvalues in the interval
!>  (A(I,J), B(I,J)) of the matrix A.
!>  On output, NAB(I,J) will contain max(na(k),min(nb(k),N(AB(i,j)))),
!>  where k is the index of the input interval that the output interval
!>  (AB(j,1),AB(j,2)] came from, and na(k) and nb(k) are the
!>  the input values of NAB(k,1) and NAB(k,2).
!>  If IJOB=3, then on output, NAB(i,j) contains N(AB(i,j)),
!>  unless N(w) > NVAL(i) for all search points  w , in which
!>  case NAB(i,1) will not be modified, i.e., the output
!>  value will be the same as the input value (modulo
!>  reorderings -- see NVAL and AB), or unless N(w) < NVAL(i)
!>  for all search points  w , in which case NAB(i,2) will
!>  not be modified.  Normally, NAB should be set to some
!>  distinctive value(s) before SLAEBZ is called.

WORK

!>  WORK is REAL array, dimension (MMAX)
!>  Workspace.

IWORK

!>  IWORK is INTEGER array, dimension (MMAX)
!>  Workspace.

INFO

!>  INFO is INTEGER
!>  = 0:       All intervals converged.
!>  = 1--MMAX: The last INFO intervals did not converge.
!>  = MMAX+1:  More than MMAX intervals were generated.

Further Details:

!>
!>      This routine is intended to be called only by other LAPACK
!>  routines, thus the interface is less user-friendly.  It is intended
!>  for two purposes:
!>
!>  (a) finding eigenvalues.  In this case, SLAEBZ should have one or
!>      more initial intervals set up in AB, and SLAEBZ should be called
!>      with IJOB=1.  This sets up NAB, and also counts the eigenvalues.
!>      Intervals with no eigenvalues would usually be thrown out at
!>      this point.  Also, if not all the eigenvalues in an interval i
!>      are desired, NAB(i,1) can be increased or NAB(i,2) decreased.
!>      For example, set NAB(i,1)=NAB(i,2)-1 to get the largest
!>      eigenvalue.  SLAEBZ is then called with IJOB=2 and MMAX
!>      no smaller than the value of MOUT returned by the call with
!>      IJOB=1.  After this (IJOB=2) call, eigenvalues NAB(i,1)+1
!>      through NAB(i,2) are approximately AB(i,1) (or AB(i,2)) to the
!>      tolerance specified by ABSTOL and RELTOL.
!>
!>  (b) finding an interval (a',b'] containing eigenvalues w(f),...,w(l).
!>      In this case, start with a Gershgorin interval  (a,b).  Set up
!>      AB to contain 2 search intervals, both initially (a,b).  One
!>      NVAL element should contain  f-1  and the other should contain  l
!>      , while C should contain a and b, resp.  NAB(i,1) should be -1
!>      and NAB(i,2) should be N+1, to flag an error if the desired
!>      interval does not lie in (a,b).  SLAEBZ is then called with
!>      IJOB=3.  On exit, if w(f-1) < w(f), then one of the intervals --
!>      j -- will have AB(j,1)=AB(j,2) and NAB(j,1)=NAB(j,2)=f-1, while
!!>      if, to the specified tolerance, w(f-k)=...=w(f+r), k > 0 and r
!>      >= 0, then the interval will have  N(AB(j,1))=NAB(j,1)=f-k and
!>      N(AB(j,2))=NAB(j,2)=f+r.  The cases w(l) < w(l+1) and
!>      w(l-r)=...=w(l+k) are handled similarly.
!>
