subroutine slasd5 (integer i, real, dimension( 2 ) d, real, dimension( 2 ) z, real, dimension( 2 ) delta, real rho, real dsigma, real, dimension( 2 ) work)

SLASD5 calcule la racine carrée de la i-ème valeur propre d'une matrice diagonale de taille 2x2 modifiée par rang un, symétrique et positive. Utilisé par sbdsdc.

Objectif:

!>
!> Cette sous-routine calcule la racine carrée de la I-ème valeur propre
!> d'une modification symétrique de rang un d'une matrice diagonale 2x2
!>
!>            diag( D ) * diag( D ) +  RHO * Z * transpose(Z) .
!>
!> On suppose que les entrées diagonales dans le tableau D satisfont
!>
!>            0 <= D(i) < D(j)  pour  i < j .
!>
!> On suppose également que RHO > 0 et que la norme euclidienne du vecteur
!> Z est un.
!>

Paramètres

I 
!>          I est INTEGER
!>         L'indice de la valeur propre à calculer. I = 1 ou I = 2.
!>

D

!>          D est un tableau REAL, dimension (2)
!>         Les valeurs propres originales. On suppose 0 <= D(1) < D(2).
!>

Z

!>          Z est un tableau REAL, dimension (2)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau REAL, dimension (2)
!>         Contient (D(j) - sigma_I) dans sa j-ème composante.
!>         Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres.
!>

RHO

!>          RHO est REAL
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DSIGMA

!>          DSIGMA est REAL
!>         Le sigma_I calculé, la I-ème valeur propre mise à jour.
!>

WORK

!>          WORK est un tableau REAL, dimension (2)
!>         WORK contient (D(j) + sigma_I) dans sa j-ème composante.
!>
