SLASD8 trouve les racines carrées des racines de l'équation séculaire, et stocke, pour chaque élément de D, la distance à ses deux pôles les plus proches. Utilisé par sbdsdc.

Objectif :

!>
!> SLASD8 trouve les racines carrées des racines de l'équation séculaire,
!> telles que définies par les valeurs dans DSIGMA et Z. Il effectue les
!> appels appropriés à SLASD4, et stocke, pour chaque élément de D, la distance
!> à ses deux pôles les plus proches (éléments de DSIGMA). Il met également
!> à jour les tableaux VF et VL, les premières et dernières composantes de tous les
!> vecteurs singuliers droits de la matrice bidiagonale originale.
!>
!> SLASD8 est appelé depuis SLASD6.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est ENTIER
!>          Spécifie si les vecteurs singuliers doivent être calculés sous
!>          forme factorisée dans la routine appelante :
!>          = 0 : Calculer uniquement les valeurs singulières.
!>          = 1 : Calculer également les vecteurs singuliers sous forme factorisée.
!>

K

!>          K est ENTIER
!>          Le nombre de termes dans la fonction rationnelle à résoudre
!>          par SLASD4. K >= 1.
!>

D

!>          D est un tableau REEL, dimension ( K )
!>          En sortie, D contient les valeurs singulières mises à jour.
!>

Z

!>          Z est un tableau REEL, dimension ( K )
!>          En entrée, les K premiers éléments de ce tableau contiennent les
!>          composantes du vecteur ligne de mise à jour ajusté par déflation.
!>          En sortie, Z est mis à jour.
!>

VF

!>          VF est un tableau REEL, dimension ( K )
!>          En entrée, VF contient des informations transmises par DBEDE8.
!>          En sortie, VF contient les K premières composantes des
!>          premières composantes de tous les vecteurs singuliers droits de la
!>          matrice bidiagonale.
!>

VL

!>          VL est un tableau REEL, dimension ( K )
!>          En entrée, VL contient des informations transmises par DBEDE8.
!>          En sortie, VL contient les K premières composantes des
!>          dernières composantes de tous les vecteurs singuliers droits de la
!>          matrice bidiagonale.
!>

DIFL

!>          DIFL est un tableau REEL, dimension ( K )
!>          En sortie, DIFL(I) = D(I) - DSIGMA(I).
!>

DIFR

!>          DIFR est un tableau REEL,
!>                   dimension ( LDDIFR, 2 ) si ICOMPQ = 1 et
!>                   dimension ( K ) si ICOMPQ = 0.
!>          En sortie, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) n'est pas
!>          défini et ne sera pas référencé.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) est un tableau contenant les
!>          facteurs de normalisation pour la matrice des vecteurs singuliers droits.
!>

LDDIFR

!>          LDDIFR est ENTIER
!>          La dimension principale de DIFR, doit être au moins K.
!>

DSIGMA

!>          DSIGMA est un tableau REEL, dimension ( K )
!>          En entrée, les K premiers éléments de ce tableau contiennent les anciennes
!>          racines du problème de mise à jour déflationné. Ce sont les pôles
!>          de l'équation séculaire.
!>

WORK

!>          WORK est un tableau REEL, dimension (3*K)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé.
!>
