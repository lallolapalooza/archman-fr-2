Documentation de la fonction/sous-routine

sous-routine slarrk (integer n, integer iw, real gl, real gu, real, dimension( * ) d, real, dimension( * ) e2, real pivmin, real reltol, real w, real werr, integer info)

SLARRK calcule une valeur propre d'une matrice tridiagonale symétrique avec une précision appropriée.

Objectif :

!>
!> SLARRK calcule une valeur propre d'une matrice tridiagonale
!> symétrique avec une précision appropriée. C'est un code auxiliaire
!> à appeler depuis SSTEMR.
!>
!> Pour éviter le débordement, la matrice doit être mise à l'échelle
!> de telle sorte que son élément le plus grand ne dépasse pas
!> overflow**(1/2) * underflow**(1/4) en valeur absolue, et pour une
!> précision maximale, elle ne doit pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan, Rapport CS41, Département des sciences informatiques,
!> Université de Stanford, 21 juillet 1966.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice tridiagonale T. N >= 0.
!>

IW

!>          IW est un ENTIER
!>          L'indice de la valeur propre à retourner.
!>

GL

!>          GL est un RÉEL
!>

GU

!>          GU est un RÉEL
!>          Une borne supérieure et une borne inférieure sur la valeur
!>          propre.
!>

D

!>          D est un tableau de RÉEL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale T.
!>

E2

!>          E2 est un tableau de RÉEL, dimension (N-1)
!>          Les (n-1) éléments carrés hors diagonale de la matrice
!>          tridiagonale T.
!>

PIVMIN

!>          PIVMIN est un RÉEL
!>          Le pivot minimum autorisé dans la séquence de Sturm pour T.
!>

RELTOL

!>          RELTOL est un RÉEL
!>          La largeur relative minimale d'un intervalle. Quand un intervalle
!>          est plus étroit que RELTOL fois le plus grand (en
!>          valeur absolue) des points d'extrémité, alors il est considéré
!>          comme suffisamment petit, c'est-à-dire convergent.
!>          Note : cela devrait toujours être au moins radix * epsilon machine.
!>

W

!>          W est un RÉEL
!>

WERR

!>          WERR est un RÉEL
!>          La borne d'erreur sur l'approximation de la valeur propre
!>          correspondante dans W.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :       La valeur propre a convergé
!>          = -1 :      La valeur propre N'a PAS convergé
!>

Paramètres internes :

!>  FUDGE   REAL            , par défaut = 2
!>          Une valeur pour élargir les intervalles de Gershgorin.
!>
