SLICK-GREETER(8) Commandes de gestion système SLICK-GREETER(8)

NOM

slick-greeter - Greeter LightDM indépendant de la distribution

SYNTAXE

slick-greeter [ OPTIONS ]

DESCRIPTION

Slick Greeter est un greeter LightDM pour tous les environnements de bureau. Il est exécuté par le démon LightDM s'il est configuré dans lightdm.conf. Il n'est normalement pas exécuté par un utilisateur, mais peut être exécuté en mode test avec l'option --test-mode. Cela permet de tester l'interface sans installer une version mise à jour.

OPTIONS

-v, --version
Affiche la version de la publication.
--test-mode
Exécute le greeter en mode test dans la session X actuelle.
-?, --help
Affiche les options d'aide.

FICHIER DE CONFIGURATION-FORMAT

/etc/lightdm/slick-greeter.conf
Les options de configuration disponibles sont listées ci-dessous.
fond=
Fichier d'arrière-plan à utiliser, soit un chemin d'image, soit une couleur (par exemple, #772953)
couleur-fond=
Couleur d'arrière-plan (par exemple, #772953), définie avant que le fond d'écran ne soit visible
dessiner-fonds-utilisateurs=
Indique s'il faut dessiner les fonds d'écran des utilisateurs (vrai ou faux)
dessiner-grille=
Indique s'il faut dessiner une grille de superposition (vrai ou faux)
afficher-nom-hote=
Indique s'il faut afficher le nom d'hôte dans la barre de menu (vrai ou faux)
afficher-clavier=
Indique s'il faut afficher l'indicateur de clavier dans la barre de menu (vrai ou faux)
afficher-a11y=
Indique s'il faut afficher les options d'accessibilité dans la barre de menu (vrai ou faux)
afficher-alimentation=
Indique s'il faut afficher l'indicateur d'alimentation dans la barre de menu (vrai ou faux)
afficher-horloge=
Indique s'il faut afficher l'horloge dans la barre de menu (vrai ou faux)
afficher-quitter=
Indique s'il faut afficher le menu de déconnexion dans la barre de menu (vrai ou faux)
logo=
Fichier logo à utiliser
logo-autres-moniteurs=
Fichier logo à utiliser pour les autres moniteurs
nom-theme=
Thème GTK+ à utiliser
nom-theme-icone=
Thème d'icônes à utiliser
nom-police=
Police à utiliser
xft-antialiasing=
Indique s'il faut utiliser l'anti-aliasing pour les polices Xft (vrai ou faux)
xft-dpi=
Résolution pour Xft en points par pouce
xft-hintstyle=
Degré de rendu de la police à utiliser (hintnone/hintslight/hintmedium/hintfull)
xft-rgba=
Type d'anti-aliasing des sous-pixels (none/rgb/bgr/vrgb/vbgr)
clavier-ecran=
Indique s'il faut activer le clavier virtuel (vrai ou faux)
contraste-eleve=
Indique s'il faut utiliser un thème à contraste élevé (vrai ou faux)
lecteur-ecran=
Indique s'il faut activer le lecteur d'écran (vrai ou faux)
jouer-son-pret=
Un fichier audio à jouer lorsque le greeter est prêt
utilisateurs-caches=
Liste des noms d'utilisateurs qui sont masqués jusqu'à ce qu'une combinaison de touches spéciale soit activée
filtre-groupe=
Liste des groupes auxquels les utilisateurs doivent appartenir pour être affichés (une liste vide affiche tous les utilisateurs)
activer-hidpi=
Indique s'il faut activer la prise en charge HiDPI (on/off/auto)
uniquement-sur-moniteur=
Définit le moniteur sur lequel afficher la fenêtre de connexion, -1 signifie "suivre la souris"
