subroutine slartv (n, x, incx, y, incy, c, s, incc)
SLARTV applique un vecteur de rotations planes avec des cosinus réels et des sinus réels aux éléments d'une paire de vecteurs.

Documentation de la fonction/sous-programme

sous-routine slartv (entier n, reel, dimension( * ) x, entier incx, reel, dimension( * ) y, entier incy, reel, dimension( * ) c, reel, dimension( * ) s, entier incc)

SLARTV applique un vecteur de rotations planes avec des cosinus réels et des sinus réels aux éléments d'une paire de vecteurs.

But :

!>
!> SLARTV applique un vecteur de rotations planes réelles aux éléments
!> des vecteurs réels x et y. Pour i = 1,2,...,n
!>
!>    ( x(i) ) := (  c(i)  s(i) ) ( x(i) )
!>    ( y(i) )    ( -s(i)  c(i) ) ( y(i) )
!>

Paramètres

N 
!>          N est ENTIER
!>          Le nombre de rotations planes à appliquer.
!>

X

!>          X est un tableau REEL,
!>                         dimension (1+(N-1)*INCX)
!>          Le vecteur x.
!>

INCX

!>          INCX est ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

Y

!>          Y est un tableau REEL,
!>                         dimension (1+(N-1)*INCY)
!>          Le vecteur y.
!>

INCY

!>          INCY est ENTIER
!>          L'incrément entre les éléments de Y. INCY > 0.
!>

C

!>          C est un tableau REEL, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

S

!>          S est un tableau REEL, dimension (1+(N-1)*INCC)
!>          Les sinus des rotations planes.
!>

INCC

!>          INCC est ENTIER
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>
