NOM

slimevolley - Simulation de volleyball 2D irréaliste

SYNTAXE

slimevolley

DESCRIPTION

Slime Volley est une simulation de volleyball 2D orientée arcade, dans l'esprit de certains jeux Java portant le même nom.

Deux équipes, de 1 à 3 joueurs chacune, essaient d'être les premières à atteindre 10 points. Cela se produit lorsque la balle touche le sol du côté adverse du filet.
Il peut y avoir de 1 à 8 balles en jeu. Une fois qu'une balle touche le sol, le set se termine et toutes les balles sont remises en jeu.
Chaque joueur utilise 4 touches : 2 pour les directions, une pour sauter et une pour changer de skin.
Vous ne pouvez pas bouger lorsque vous n'êtes pas en contact avec le sol.
