NOM

slmbuild - génère un modèle de langage à partir d'un fichier idngram

SYNTAXE

slmbuild [option]... fichier_idngram...

DESCRIPTION

slmbuild génère un modèle de langage avec lissage par retour à partir d'un fichier idngram donné. Généralement, le fichier_idngram est créé par ids2ngram.

OPTIONS Toutes les options suivantes sont obligatoires.

-n,--NMax N
1 pour unigramme, 2 pour bigramme, 3 pour trigramme. Tout nombre hors de la plage 1..3 n'est pas valide.
-o, --out fichier-sortie
Spécifie le nom du fichier de sortie xfilei.
-l, --log
Utilise -log(pr), utilise pr directement par défaut.
-w, --wordcount N
Taille du lexique, nombre de mots différents.
-b, --brk id...
Définit les id qui doivent être traités comme des séparateurs.
-e, --e id...
Définit les id qui ne doivent pas être mis dans le LM.
-c, --cut c...
Les k-grammes dont la fréquence est <= c[k] sont supprimés.
-d, --discount méthode, param...
Le k-ième paramètre -d spécifie la méthode de remise de la probabilité

Pour les k-grammes, les valeurs possibles pour méthode/param sont :

B<GT>,I<R>,I<dis>  : Remise B<GT> pour r E<lt>= I<R>, r est la fréquence d'un ngram.
            Remise linéaire pour ceux r E<gt> I<R>, c'est-à-dire r'=r*dis
            0 E<lt>E<lt> dis E<lt> 1.0, par exemple 0.999
B<ABS>,[I<dis>] : Remise absolue r'=r-I<dis>. Et I<dis> est facultatif
            0 E<lt>E<lt> I<dis> E<lt> cut[k]+1.0, normalement I<dis> E<lt> 1.0.
LIN,[I<dis>] : Remise linéaire r'=r*dis. Et dis est facultatif
            0 E<lt> dis E<lt> 1.0

NOTE

-n doit être spécifié avant -c et -b. Et -c doit fournir le bon nombre de seuils, de même -d doit apparaître exactement N fois, spécifiant les remises pour les 1-grammes, 2-grammes..., respectivement.

Les ID DE SÉPARATEUR peuvent être des Jetons de Phrase ou des Jetons de Paragraphe. Conceptuellement, ces id n'ont aucune signification lorsqu'ils apparaissent au milieu d'un n-gramme.

Les ID À EXCLURE peuvent être des id ambigus. Conceptuellement, les n-grammes qui contiennent ces id sont dénués de sens.

Nous ne pouvons pas supprimer les n-grammes en fonction des ID DE SÉPARATEUR et des ID À EXCLURE directement à partir du fichier IDNGRAM, car certaines informations de bas niveau y restent utiles.

EXEMPLE

L'exemple suivant lit 'all.id3gram' et écrit le modèle trigramme 'all.slm'.

Au niveau 1-gramme, utiliser la remise Good-Turing avec un seuil de 0, i<R>=8, dis=0.9995. Au niveau 2-gramme, utiliser la remise Absolue avec un seuil de 3, dis calculé automatiquement. Au niveau 3-gramme, utiliser la remise Absolue avec un seuil de 2, dis calculé automatiquement. L'id de mot 10,11,12 sont des séparateurs (séparateur de phrase/paragraphe/document, etc.). L'ID à exclure est 9. Le lexique contient 200000 mots. Le modèle de langage résultant utilise -log(pr).

slmbuild -l -n 3 -o all.slm -w 200000 -c 0,3,2 -d GT,8,0.9995 -d ABS -d ABS -b 10,11,12 -e 9 all.id3gram
