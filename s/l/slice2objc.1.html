NOM

slice2objc - Le compilateur Slice vers Objective-C.

SYNTAXE

slice2objc [options] [fichiers]

DESCRIPTION

slice2objc compile les fichiers Slice en Objective-C. La macro __SLICE2OBJC__ est définie pendant cette compilation.

La documentation complète de slice2objc est disponible en ligne sur :
https://doc.zeroc.com/ice/latest/language-mappings/objective-c-mapping/client-side-slice-to-objective-c-mapping/slice2objc-command-line-options

OPTIONS

-h, --help

Affiche le message d'aide.
-v, --version
Affiche la version du compilateur.
-DNAME

Définit le symbole préprocesseur NAME.
-DNAME=DEF

Définit le symbole préprocesseur NAME avec la valeur DEF.
-UNAME

Annule la définition du symbole préprocesseur NAME.
-IDIR

Ajoute le répertoire DIR au chemin de recherche pour les directives #include.
-E

Imprime la sortie du préprocesseur sur stdout.
--output-dir DIR

Place les fichiers générés dans le répertoire DIR.
-d, --debug

Imprime des informations de débogage montrant le fonctionnement de l'analyseur Slice.
--depend

Imprime les informations de dépendance sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-xml

Imprime les informations de dépendance au format XML sur la sortie standard par défaut, ou sur le fichier spécifié par l'option --depend-file. Aucun code n'est généré lorsque cette option est spécifiée.
--depend-file FILE

Dirige les informations de dépendance vers le fichier spécifié. Le format de sortie dépend de la présence ou non des options --depend ou --depend-xml.
--validate

Vérifie la correction des options de ligne de commande fournies et ne génère aucun code.
--include-dir DIR

Modifie les directives #include dans les fichiers source pour ajouter le chemin d'accès de chaque fichier d'en-tête préfixé par le répertoire DIR.
