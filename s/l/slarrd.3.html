SLARRD calcule les valeurs propres d'une matrice tridiagonale symétrique avec une précision appropriée.

Documentation de la fonction/sous-routine

sous-routine slarrd (character range, character order, integer n, real vl, real vu, integer il, integer iu, real, dimension( * ) gers, real reltol, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real pivmin, integer nsplit, integer, dimension( * ) isplit, integer m, real, dimension( * ) w, real, dimension( * ) werr, real wl, real wu, integer, dimension( * ) iblock, integer, dimension( * ) indexw, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLARRD calcule les valeurs propres d'une matrice tridiagonale symétrique avec une précision appropriée.

Objectif :

!>
!> SLARRD calcule les valeurs propres d'une matrice tridiagonale symétrique
!> T avec une précision appropriée. C'est un code auxiliaire à appeler
!> depuis SSTEMR.
!> L'utilisateur peut demander toutes les valeurs propres, toutes les valeurs propres
!> dans l'intervalle semi-ouvert (VL, VU], ou les valeurs propres de l'IL-ème à l'IU-ème
!> (de la matrice entière).
!>
!> Pour éviter le dépassement de capacité, la matrice doit être mise à l'échelle de sorte que
!> son élément le plus grand ne dépasse pas overflow**(1/2) * underflow**(1/4) en valeur absolue, et pour
!> une meilleure précision, elle ne doit pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan , Rapport CS41, Département des Sciences Informatiques, Université de Stanford
!> (Stanford University), 21 juillet 1966.
!>

Paramètres

RANGE 
!>          RANGE est CHARACTER*1
!>          = 'A': ()   toutes les valeurs propres seront trouvées.
!>          = 'V': () toutes les valeurs propres dans l'intervalle
!>                           semi-ouvert (VL, VU] seront trouvées.
!>          = 'I': () les valeurs propres de l'IL-ème à l'IU-ème
!>                           (de la matrice entière) seront trouvées.
!>

ORDER

!>          ORDER est CHARACTER*1
!>          = 'B': () les valeurs propres seront regroupées par
!>                              bloc de séparation (voir IBLOCK, ISPLIT) et
!>                              ordonnées de la plus petite à la plus grande à l'intérieur
!>                              du bloc.
!>          = 'E': ()
!>                              les valeurs propres de la matrice entière
!>                              seront ordonnées de la plus petite à la plus grande.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice tridiagonale T. N >= 0.
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle dans lequel
!>          rechercher les valeurs propres. Les valeurs propres inférieures ou égales
!>          à VL, ou supérieures à VU, ne seront pas retournées. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle dans lequel
!>          rechercher les valeurs propres. Les valeurs propres inférieures ou égales
!>          à VL, ou supérieures à VU, ne seront pas retournées. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

GERS

!>          GERS est un tableau de REAL, dimension (2*N)
!>          Les N intervalles de Gerschgorin (le i-ème intervalle de
!>          Gerschgorin est (GERS(2*i-1), GERS(2*i))).
!>

RELTOL

!>          RELTOL est REAL
!>          La largeur relative minimale d'un intervalle. Quand un intervalle
!>          est plus étroit que RELTOL multiplié par le plus grand (en
!>          valeur absolue) des points d'extrémité, alors il est considéré
!>          comme suffisamment petit, c'est-à-dire convergent. Note : ceci doit
!>          toujours être au moins radix*machine epsilon.
!>

D

!>          D est un tableau de REAL, dimension (N)
!>          Les N éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau de REAL, dimension (N-1)
!>          Les N-1 éléments hors diagonale de la matrice tridiagonale T.
!>

E2

!>          E2 est un tableau de REAL, dimension (N-1)
!>          Les N-1 éléments hors diagonale mis au carré de la matrice tridiagonale T.
!>

PIVMIN

!>          PIVMIN est REAL
!>          Le pivot minimal autorisé dans la séquence de Sturm pour T.
!>

NSPLIT

!>          NSPLIT est INTEGER
!>          Le nombre de blocs diagonaux dans la matrice T.
!>          1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT est un tableau de INTEGER, dimension (N)
!>          Les points de division, où T se décompose en sous-matrices.
!>          La première sous-matrice comprend les lignes/colonnes 1 à ISPLIT(1),
!>          la seconde les lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et la NSPLIT-ème comprend les lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>          (Seuls les NSPLIT premiers éléments seront effectivement utilisés, mais
!>          comme l'utilisateur ne peut pas savoir a priori quelle valeur NSPLIT aura,
!>          N mots doivent être réservés pour ISPLIT.)
!>

M

!>          M est INTEGER
!>          Le nombre réel de valeurs propres trouvées. 0 <= M <= N.
!>          (Voir aussi la description de INFO=2,3.)
!>

W

!>          W est un tableau de REAL, dimension (N)
!>          En sortie, les M premiers éléments de W contiendront les
!>          approximations des valeurs propres. SLARRD calcule un intervalle
!>          I_j = (a_j, b_j] qui inclut la valeur propre j. L'approximation de la valeur propre
!>          est donnée par le point médian de l'intervalle
!>          W(j)= ( a_j + b_j)/2. L'erreur correspondante est bornée par
!>          WERR(j) = abs( a_j - b_j)/2
!>

WERR

!>          WERR est un tableau de REAL, dimension (N)
!>          La borne d'erreur sur l'approximation de la valeur propre correspondante
!>          dans W.
!>

WL

!>          WL est REAL
!>

WU

!>          WU est REAL
!>          L'intervalle (WL, WU] contient toutes les valeurs propres recherchées.
!>          Si RANGE='V', alors WL=VL et WU=VU.
!>          Si RANGE='A', alors WL et WU sont les bornes de Gerschgorin globales
!>                        sur le spectre.
!>          Si RANGE='I', alors WL et WU sont calculés par SLAEBZ à partir de
!>                        l'intervalle d'indices spécifié.
!>

IBLOCK

!>          IBLOCK est un tableau de INTEGER, dimension (N)
!>          À chaque ligne/colonne j où E(j) est nul ou petit, la
!>          matrice T est considérée comme se décomposant en une matrice diagonale par blocs.
!>          En sortie, si INFO = 0, IBLOCK(i) spécifie à quel
!>          bloc (de 1 au nombre de blocs) appartient la valeur propre W(i).
!>          (SLARRD peut utiliser les N-M éléments restants comme
!>          espace de travail.)

NAME

slarrd — subroutine to find eigenvalues of a symmetric tridiagonal matrix

SYNOPSIS

 SUBROUTINE SLARRD( N,VL,VU,IL,IU,ABSTOL,W,IZ,M,Z,LDZ,WORK,IWORK,INFO )

Parameters
INTEGER N
REAL VL, VU
INTEGER IL, IU
REAL ABSTOL
REAL W( N )
INTEGER IZ( N )
INTEGER M
REAL Z( LDZ, N )
INTEGER LDZ
REAL WORK( 4*N )
INTEGER IWORK( 3*N )
INTEGER INFO

Function/Subroutine Documentation

SLARRD is a subroutine of the LAPACK library.

This routine computes the eigenvalues of a symmetric tridiagonal matrix T.

It is intended as a simple replacement of the LAPACK routines DSTEGR/DSTEDC that compute the eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

If needed, the routine can be further optimized.

The eigenvectors are computed by the routine `smarz`.

The eigenvalues are computed using bisection.

The routine returns the eigenvalues in ascending order.

The algorithm is based on the routine `SSTEGR` which computes the eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

The routine is based on the algorithm described in the paper:

B. N. Parlett and H. R. Wiegelmann, "The QR algorithm for symmetric tridiagonal
matrices", Linear Algebra and its Applications, 1990.

The algorithm computes the eigenvalues by bisection. The eigenvectors are computed by the routine `smarz`.

The routine returns the eigenvalues in ascending order.

The routine is intended as a simple replacement of the LAPACK routines DSTEGR/DSTEDC that compute the eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

Parameters:

N

 INTEGER
          The order of the matrix T. N >= 0.

VL, VU

 REAL
          The lower and upper bounds of the interval in which the eigenvalues
          are to be computed.

IL, IU

 INTEGER
          The indices of the eigenvalues to be computed.
          If RANGE = 'A' or RANGE = 'S' or RANGE = 'I':
          IL and IU specify the range of the eigenvalues to be computed.
          1 <= IL <= IU <= N.

ABSTOL

 REAL
          Absolute tolerance for convergence of bisection.

W

 REAL array, dimension (N)
          On exit, W contains the computed eigenvalues in ascending order.

IZ

 INTEGER array, dimension (N)
          On exit, IZ contains the indices of the eigenvalues within each block
          (submatrix); for example, INDEXW(i)= j and IBLOCK(i)=k imply that the
          i-th eigenvalue W(i) is the j-th eigenvalue in block k.

M

 INTEGER
          The number of eigenvalues computed.

Z

 REAL array, dimension (LDZ, N)
          On exit, Z contains the computed eigenvectors. The i-th column of Z
          is the eigenvector corresponding to the i-th eigenvalue in W.

LDZ

 INTEGER
          The leading dimension of the array Z. LDZ >= max(1,N).

WORK

 REAL array, dimension (4*N)

IWORK

 INTEGER array, dimension (3*N)

INFO

 INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  some or all of the eigenvalues failed to converge or
                were not computed:
                =1 or 3: Bisection failed to converge for some
                        eigenvalues; these eigenvalues are flagged by a
                        negative block number.  The effect is that the
                        eigenvalues may not be as accurate as the
                        absolute and relative tolerances.  This is
                        generally caused by unexpectedly inaccurate
                        arithmetic.
                =2 or 3: RANGE='I' only: Not all of the eigenvalues
                        IL:IU were found.
                        Effect: M < IU+1-IL
                        Cause:  non-monotonic arithmetic, causing the
                                Sturm sequence to be non-monotonic.
                        Cure:   recalculate, using RANGE='A', and pick
                                out eigenvalues IL:IU.  In some cases,
                                increasing the PARAMETER may
                                make things work.
                = 4:    RANGE='I', and the Gershgorin interval
                        initially used was too small.  No eigenvalues
                        were computed.
                        Probable cause: your machine has sloppy
                                        floating-point arithmetic.
                        Cure: Increase the PARAMETER ,
                              recompile, and try again.

Internal Parameters

  FUDGE   REAL, default = 2
          A  to widen the Gershgorin intervals.  Ideally,
          a value of 1 should work, but on machines with sloppy
          arithmetic, this needs to be larger.  The default for
          publicly released versions should be large enough to handle
          the worst machine around.  Note that this has no effect
          on accuracy of the solution.

Documentation de fonction/sous-routine

SLARRD est une sous-routine de la bibliothèque LAPACK.

Cette sous-routine calcule les valeurs propres d'une matrice tridiagonale symétrique T.

Elle est conçue comme un remplacement simple des sous-routines LAPACK DSTEGR/DSTEDC qui calculent les valeurs propres et les vecteurs propres d'une matrice tridiagonale symétrique.

Si nécessaire, la sous-routine peut être optimisée davantage.

Les vecteurs propres sont calculés par la sous-routine `smarz`.

Les valeurs propres sont calculées par dichotomie.

La sous-routine renvoie les valeurs propres dans l'ordre croissant.

La sous-routine est basée sur l'algorithme décrit dans l'article :

B. N. Parlett et H. R. Wiegelmann, "The QR algorithm for symmetric tridiagonal
matrices", Linear Algebra and its Applications, 1990.

L'algorithme calcule les valeurs propres par dichotomie. Les vecteurs propres sont calculés par la sous-routine `smarz`.

La sous-routine renvoie les valeurs propres dans l'ordre croissant.

La sous-routine est conçue comme un remplacement simple des sous-routines LAPACK DSTEGR/DSTEDC qui calculent les valeurs propres et les vecteurs propres d'une matrice tridiagonale symétrique.
