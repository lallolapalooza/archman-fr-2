Documentation de la fonction/sous-programme

sous-programme slasd4 (entier n, entier i, reel, dimension( * ) d, reel, dimension( * ) z, reel, dimension( * ) delta, reel rho, reel sigma, reel, dimension( * ) work, entier info)

SLASD4 calcule la racine carrée de la i-ème valeur propre mise à jour d'une matrice diagonale positive modifiée par rang-un symétrique à une matrice diagonale positive. Utilisé par sbdsdc.

Objectif :

!>
!> Ce sous-programme calcule la racine carrée de la I-ème valeur propre mise à jour
!> d'une modification symétrique de rang un à une matrice diagonale positive dont
!> les entrées sont données comme les carrés des entrées correspondantes dans le tableau d, et qui
!>
!>        0 <= D(i) < D(j)  pour  i < j
!>
!> et RHO > 0. Ceci est organisé par la routine appelante, et n'est
!> aucune perte de généralité. Le système modifié par rang un est donc
!>
!>        diag( D ) * diag( D ) +  RHO * Z * Z_transpose.
!>
!> où nous supposons que la norme euclidienne de Z est 1.
!>
!> La méthode consiste à approximer les fonctions rationnelles dans l'équation séculaire
!> par des fonctions rationnelles interpolatrices plus simples.
!>

Paramètres

N 
!>          N est ENTIER
!>         La longueur de tous les tableaux.
!>

I

!>          I est ENTIER
!>         L'indice de la valeur propre à calculer.  1 <= I <= N.
!>

D

!>          D est un tableau REEL, dimension ( N )
!>         Les valeurs propres originales. On suppose qu'elles sont en
!>         ordre, 0 <= D(I) < D(J)  pour I < J.
!>

Z

!>          Z est un tableau REEL, dimension ( N )
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau REEL, dimension ( N )
!>         Si N .ne. 1, DELTA contient (D(j) - sigma_I) dans sa j-ème
!>         composante.  Si N = 1, alors DELTA(1) = 1.  Le vecteur DELTA
!>         contient les informations nécessaires pour construire les
!>         vecteurs propres (singuliers).
!>

RHO

!>          RHO est REEL
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

SIGMA

!>          SIGMA est REEL
!>         Le sigma_I calculé, la I-ème valeur propre mise à jour.
!>

WORK

!>          WORK est un tableau REEL, dimension ( N )
!>         Si N .ne. 1, WORK contient (D(j) + sigma_I) dans sa j-ème
!>         composante.  Si N = 1, alors WORK( 1 ) = 1.
!>

INFO

!>          INFO est ENTIER
!>         = 0 : sortie réussie
!>         > 0 : si INFO = 1, le processus de mise à jour a échoué.
!>

Paramètres internes :

!>  La variable logique ORGATI (origine à i ?) est utilisée pour distinguer
!>  si D(i) ou D(i+1) est traité comme l'origine.
!>
!>            ORGATI = .vrai.    origine à i
!>            ORGATI = .faux.   origine à i+1
!>
!>  La variable logique SWTCH3 (switch pour 3 pôles ?) sert à indiquer
!>  si nous travaillons avec TROIS pôles !
!>
!>  MAXIT est le nombre maximum d'itérations autorisées pour chaque
!>  valeur propre.
!>
