real function slatm3 (integer m, integer n, integer i, integer j, integer isub, integer jsub, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer igrade, real, dimension( * ) dl, real, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, real sparse)

SLATM3

But :

!>
!>    SLATM3 renvoie l'entrée (ISUB,JSUB) d'une matrice aléatoire de
!>    dimension (M, N) décrite par les autres paramètres. (ISUB,JSUB)
!>    est la position finale de l'entrée (I,J) après pivotement
!>    selon IPVTNG et IWORK. SLATM3 est appelée par la
!>    routine SLATMR afin de construire des matrices de test aléatoires. Aucune vérification des erreurs sur les paramètres n'est effectuée, car cette routine est appelée dans une boucle serrée par SLATMR qui a déjà vérifié les paramètres.
!>
!>    L'utilisation de SLATM3 diffère de SLATM2 dans l'ordre dans lequel le générateur de nombres aléatoires est appelé pour remplir les entrées de la matrice aléatoire.
!>    Avec SLATM2, le générateur est appelé pour remplir la matrice pivotée
!>    colonne par colonne. Avec SLATM3, le générateur est appelé pour remplir la
!>    matrice colonne par colonne, après quoi elle est pivotée. Ainsi, SLATM3 peut
!>    être utilisé pour construire des matrices aléatoires qui ne diffèrent que par leur
!>    ordre de lignes et/ou de colonnes. SLATM2 est utilisé pour construire des matrices bandes
!>    tout en évitant d'appeler le générateur de nombres aléatoires pour
!>    les entrées hors de la bande (et donc en générant des nombres aléatoires
!>    dans des ordres différents pour différents ordres de pivotement).
!>
!>    La matrice dont l'entrée (ISUB,JSUB) est retournée est construite comme suit
!>    (cette routine ne calcule qu'une seule entrée) :
!>
!>      Si ISUB est hors de (1..M) ou JSUB est hors de (1..N), renvoyer zéro
!>         (ceci est pratique pour générer des matrices au format bande).
!>
!>      Générer une matrice A avec des entrées aléatoires de distribution IDIST.
!>
!>      Définir la diagonale à D.
!>
!>      Graduer la matrice, si désiré, à gauche (par DL) et/ou
!>         à droite (par DR ou DL) selon IGRADE.
!>
!>      Permuter, si désiré, les lignes et/ou colonnes selon
!>         IPVTNG et IWORK.
!>
!>      Mettre la matrice en bande pour avoir une bande inférieure KL et une bande supérieure
!>         bande KU.
!>
!>      Définir les entrées aléatoires à zéro selon SPARSE.
!>

Paramètres

M 
!>          M est de type INTEGER
!>           Nombre de lignes de la matrice. Non modifié.
!>

N

!>          N est de type INTEGER
!>           Nombre de colonnes de la matrice. Non modifié.
!>

I

!>          I est de type INTEGER
!>           Ligne de l'entrée non pivotée à retourner. Non modifié.
!>

J

!>          J est de type INTEGER
!>           Colonne de l'entrée non pivotée à retourner. Non modifié.
!>

ISUB

!>          ISUB est de type INTEGER
!>           Ligne de l'entrée pivotée à retourner. Modifié en sortie.
!>

JSUB

!>          JSUB est de type INTEGER
!>           Colonne de l'entrée pivotée à retourner. Modifié en sortie.
!>

KL

!>          KL est de type INTEGER
!>           Bande inférieure. Non modifié.
!>

KU

!>          KU est de type INTEGER
!>           Bande supérieure. Non modifié.
!>

IDIST

!>          IDIST est de type INTEGER
!>           En entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMALE( 0, 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau de type INTEGER de dimension ( 4 )
!>           Graine pour le générateur de nombres aléatoires.
!>           Modifié en sortie.
!>

D

!>          D est un tableau de type REAL de dimension ( MIN( I , J ) )
!>           Entrées diagonales de la matrice. Non modifié.
!>

IGRADE

!>          IGRADE est de type INTEGER
!>           Spécifie la graduation de la matrice comme suit :
!>           0  => pas de graduation
!>           1  => matrice pré-multipliée par diag( DL )
!>           2  => matrice post-multipliée par diag( DR )
!>           3  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DR )
!>           4  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par inv( diag( DL ) )
!>           5  => matrice pré-multipliée par diag( DL ) et
!>                         post-multipliée par diag( DL )
!>           Non modifié.
!>

DL

!>          DL est un tableau de type REAL ( I ou J, selon le cas )
!>           Facteurs d'échelle gauche pour la graduation de la matrice. Non modifié.
!>

DR

!>          DR est un tableau de type REAL ( I ou J, selon le cas )
!>           Facteurs d'échelle droite pour la graduation de la matrice. Non modifié.
!>

IPVTNG

!>          IPVTNG est de type INTEGER
!>           En entrée spécifie les permutations de pivotement comme suit :
!>           0 => aucune.
!>           1 => pivotement de ligne.
!>           2 => pivotement de colonne.
!>           3 => pivotement complet, c'est-à-dire des deux côtés.
!>           Non modifié.
!>

IWORK

!>          IWORK est un tableau de type INTEGER ( I ou J, selon le cas )
!>           Ce tableau spécifie la permutation utilisée. La
!>           ligne (ou colonne) initialement en position K est en
!>           position IWORK( K ) après pivotement.
!>           Ceci diffère de IWORK pour SLATM2. Non modifié.
!>

SPARSE

!>          SPARSE est de type REAL entre 0. et 1.
!>           En entrée spécifie la sparsité de la matrice
!>           si une matrice creuse doit être générée.
!>           SPARSE doit être compris entre 0 et 1.
!>           Un nombre aléatoire uniforme ( 0, 1 ) x est généré et
!>           comparé à SPARSE ; si x est plus grand, l'entrée de la matrice
!>           n'est pas modifiée et si x est plus petit, l'entrée est mise
!>           à zéro. Ainsi, en moyenne, une fraction SPARSE des
!>           entrées sera mise à zéro.
!>           Non modifié.
!>
