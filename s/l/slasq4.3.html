Documentation de fonction/sous-programme

sous-programme slasq4 (integer i0, integer n0, real, dimension( * ) z, integer pp, integer n0in, real dmin, real dmin1, real dmin2, real dn, real dn1, real dn2, real tau, integer ttype, real g)

SLASQ4 calcule une approximation TAU de la plus petite valeur propre en utilisant les valeurs de d de la transformation précédente. Utilisé par sbdsqr.

Objectif :

!>
!> SLASQ4 calcule une approximation TAU de la plus petite valeur propre
!> en utilisant les valeurs de d de la transformation précédente.
!>

Paramètres

I0 
!>          I0 est un ENTIER
!>        Premier indice.
!>

N0

!>          N0 est un ENTIER
!>        Dernier indice.
!>

Z

!>          Z est un tableau REEL, dimension ( 4*N0 )
!>        Z contient le tableau qd.
!>

PP

!>          PP est un ENTIER
!>        PP=0 pour ping, PP=1 pour pong.
!>

N0IN

!>          N0IN est un ENTIER
!>        La valeur de N0 au début de EIGTEST.
!>

DMIN

!>          DMIN est un REEL
!>        Valeur minimale de d.
!>

DMIN1

!>          DMIN1 est un REEL
!>        Valeur minimale de d, excluant D( N0 ).
!>

DMIN2

!>          DMIN2 est un REEL
!>        Valeur minimale de d, excluant D( N0 ) et D( N0-1 ).
!>

DN

!>          DN est un REEL
!>        d(N)
!>

DN1

!>          DN1 est un REEL
!>        d(N-1)
!>

DN2

!>          DN2 est un REEL
!>        d(N-2)
!>

TAU

!>          TAU est un REEL
!>        C'est le décalage.
!>

TTYPE

!>          TTYPE est un ENTIER
!>        Type de décalage.
!>

G

!>          G est un REEL
!>        G est passé en argument afin de sauvegarder sa valeur entre
!>        les appels à SLASQ4.
!>
