Documentation de la fonction/sous-routine

sous-routine slasd0 (integer n, integer sqre, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, integer smlsiz, integer, dimension( * ) iwork, real, dimension( * ) work, integer info)

SLASD0 calcule les valeurs singulières d'une matrice réelle bidiagonale supérieure n-par-m B avec diagonale D et hors-diagonale E. Utilisé par sbdsdc.

Objectif :

!>
!> En utilisant une approche de diviser pour régner, SLASD0 calcule la
!> décomposition en valeurs singulières (SVD) d'une matrice B réelle, bidiagonale
!> supérieure de taille N-par-M avec diagonale D et hors-diagonale E, où M = N + SQRE.
!> L'algorithme calcule des matrices orthogonales U et VT telles que
!> B = U * S * VT. Les valeurs singulières S sont écrasées sur D.
!>
!> Une sous-routine apparentée, SLASDA, calcule uniquement les valeurs singulières,
!> et optionnellement, les vecteurs singuliers sous forme compacte.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         En entrée, la dimension de ligne de la matrice bidiagonale.
!>         C'est aussi la dimension du tableau de diagonale principale D.
!>

SQRE

!>          SQRE est un entier (INTEGER)
!>         Spécifie la dimension de colonne de la matrice bidiagonale.
!>         = 0 : La matrice bidiagonale a une dimension de colonne M = N ;
!>         = 1 : La matrice bidiagonale a une dimension de colonne M = N+1 ;
!>

D

!>          D est un tableau réel (REAL array), dimension (N)
!>         En entrée, D contient la diagonale principale de la matrice bidiagonale.
!>         En sortie, si INFO = 0, D contient ses valeurs singulières.
!>

E

!>          E est un tableau réel (REAL array), dimension (M-1)
!>         Contient les éléments sous-diagonaux de la matrice bidiagonale.
!>         En sortie, E est détruit.
!>

U

!>          U est un tableau réel (REAL array), dimension (LDU, N)
!>         En sortie, U contient les vecteurs singuliers gauches,
!>          si U est passé en tant qu'identité (N, N).
!>

LDU

!>          LDU est un entier (INTEGER)
!>         En entrée, la dimension principale de U.
!>

VT

!>          VT est un tableau réel (REAL array), dimension (LDVT, M)
!>         En sortie, VT**T contient les vecteurs singuliers droits,
!>          si VT est passé en tant qu'identité (M, M).
!>

LDVT

!>          LDVT est un entier (INTEGER)
!>         En entrée, la dimension principale de VT.
!>

SMLSIZ

!>          SMLSIZ est un entier (INTEGER)
!>         En entrée, la taille maximale des sous-problèmes au
!>         bas de l'arbre de calcul.
!>

IWORK

!>          IWORK est un tableau entier (INTEGER array), dimension (8*N)
!>

WORK

!>          WORK est un tableau réel (REAL array), dimension (3*M**2+2*M)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>
