Documentation de fonction/sous-programme

sous-programme slatme (integer n, character dist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer mode, real cond, real dmax, character, dimension( * ) ei, character rsign, character upper, character sim, real, dimension( * ) ds, integer modes, real conds, integer kl, integer ku, real anorm, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work, integer info)

SLATME

Objectif :

!>
!>    SLATME génère des matrices carrées aléatoires non symétriques avec
!>    des valeurs propres spécifiées pour tester les programmes LAPACK.
!>
!>    SLATME opère en appliquant la séquence d'opérations suivante :
!>
!>    1. Définit la diagonale à D, où D peut être entrée ou
!>         calculée selon MODE, COND, DMAX et RSIGN
!>         comme décrit ci-dessous.
!>
!>    2. Si des paires de conjugués complexes sont désirées (MODE=0 et EI(1)='R',
!>         ou MODE=5), certaines paires d'éléments adjacents de D sont
!>         interprétées comme les parties réelles et complexes d'une paire
!>         conjuguée complexe ; A devient ainsi bloc diagonal, avec des blocs 1x1
!>         et 2x2.
!>
!>    3. Si UPPER='T', le triangle supérieur de A est rempli de valeurs aléatoires
!>         selon la distribution DIST.
!>
!>    4. Si SIM='T', A est multipliée à gauche par une matrice aléatoire
!>         X, dont les valeurs singulières sont spécifiées par DS, MODES et
!>         CONDS, et à droite par X inverse.
!>
!>    5. Si KL < N-1, la bande inférieure est réduite à KL en utilisant
!>         des transformations de Householder. Si KU < N-1, la bande supérieure
!>         est réduite à KU.
!>
!>    6. Si ANORM n'est pas négatif, la matrice est mise à l'échelle pour avoir
!>         une norme d'élément maximum ANORM.
!>
!>    (Note : comme la matrice ne peut pas être réduite au-delà de la forme de Hessenberg,
!>     aucune option de paquetage n'est disponible.)
!>

Paramètres

N 
!>          N est INTEGER
!>           Le nombre de colonnes (ou de lignes) de A. Non modifié.
!>

DIST

!>          DIST est CHARACTER*1
!>           En entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires, et pour
!>           le triangle supérieur (voir UPPER).
!>           'U' => UNIFORME( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMALE( 0, 1 )   ( 'N' pour normale )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension ( 4 )
!>           En entrée, ISEED spécifie la graine du générateur de nombres aléatoires.
!>           Ils doivent être compris entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une séquence linéaire congruente limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires indépendants de la machine.
!>           Les valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées
!>           dans le prochain appel à SLATME pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau REAL, dimension ( N )
!>           Ce tableau est utilisé pour spécifier les valeurs propres de A. Si
!>           MODE=0, alors D est supposé contenir les valeurs propres (mais
!>           voir la description de EI), sinon elles seront calculées selon
!>           MODE, COND, DMAX et RSIGN et placées dans D.
!>           Modifié si MODE est non nul.
!>

MODE

!>          MODE est INTEGER
!>           En entrée, cela décrit comment les valeurs propres doivent
!>           être spécifiées :
!>           MODE = 0 signifie utiliser D (avec EI) en entrée
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    sont uniformément distribués. Chaque paire impair-pair
!>                    sera soit utilisée comme deux valeurs propres réelles, soit comme
!>                    la partie réelle et imaginaire d'une paire conjuguée complexe ;
!>                    le choix de laquelle est fait est aléatoire, avec
!>                    une probabilité de 50-50, pour chaque paire.
!>           MODE = 6 définit D à des nombres aléatoires de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est compris entre 1 et 4, D a des entrées allant
!>              de 1 à 1/COND, s'il est compris entre -1 et -4, D a des entrées
!>              allant de 1/COND à 1,
!>           Non modifié.
!>

COND

!>          COND est REAL
!>           En entrée, il est utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est REAL
!>           Si MODE n'est ni -6, ni 0, ni 6, les contenus de D, tels que calculés
!>           selon MODE et COND, seront mis à l'échelle par DMAX / max(abs(D(i))).
!>           Notez que DMAX n'a pas besoin d'être positif : si DMAX est négatif (ou zéro),
!>           D sera mis à l'échelle par un nombre négatif (ou zéro).
!>           Non modifié.
!>

EI

!>          EI est un tableau CHARACTER*1, dimension ( N )
!>           Si MODE est 0, et EI(1) n'est pas ' ' (espace),
!>           ce tableau spécifie quels éléments de D (en entrée) sont
!>           des valeurs propres réelles et quels sont les parties réelles et imaginaires
!>           d'une paire de valeurs propres conjuguées complexes. Les éléments
!>           de EI peuvent alors uniquement avoir les valeurs 'R' et 'I'. Si
!>           EI(j)='R' et EI(j+1)='I', alors la j-ème valeur propre est
!>           CMPLX( D(j) , D(j+1) ), et la (j+1)-ème est son conjugué complexe.
!>           Si EI(j)=EI(j+1)='R', alors la j-ème valeur propre est D(j) (c'est-à-dire réelle).
!>           EI(1) ne peut pas être 'I', ni deux éléments adjacents de EI avoir la valeur 'I'.
!>           Si MODE n'est pas 0, alors EI est ignoré. Si MODE est 0 et
!>           EI(1)=' ', alors les valeurs propres seront toutes réelles.
!>           Non modifié.
!>

RSIGN

!>          RSIGN est CHARACTER*1
!>           Si MODE n'est ni 0, ni 6, ni -6, et RSIGN='T', alors les
!>           éléments de D, calculés selon MODE et COND, seront
!>           multipliés par un signe aléatoire (+1 ou -1). Si RSIGN='F',
!>           ils ne le seront pas. RSIGN ne peut avoir que les valeurs 'T' ou
!>           'F'.
!>           Non modifié.
!>

UPPER

!>          UPPER est CHARACTER*1
!>           Si UPPER='T', alors les éléments de A au-dessus de la diagonale
!>           (et au-dessus des blocs diagonaux 2x2, si A a des valeurs propres
!>           complexes) seront remplis de nombres aléatoires selon DIST.
!>           Si UPPER='F', ils ne le seront pas. UPPER ne peut avoir que les
!>           valeurs 'T' ou 'F'.
!>           Non modifié.
!>

SIM

!>          SIM est CHARACTER*1
!>           Si SIM='T', alors A sera opéré par , c'est-à-dire multiplié à gauche par une matrice X et
!>           à droite par X inverse. X = U S V, où U et V sont
!>           des matrices unitaires aléatoires et S est une matrice (diagonale) de
!>           valeurs singulières spécifiées par DS, MODES et CONDS. Si
!>           SIM='F', alors A ne sera pas t

SYNOPSIS


SUBROUTINE SLATME(
     DIST, N, MODE, VL, VU, IL, IU, KEY, PIVOT, SUB,
     N1, N2, NB, SIGMA, RESL, RESR, A, LDA, D, E,
     U, LDU, V, LDV, X, Y, IWORK, WORK, INFO )



    

  • 

    DIST
    

         CHARACTER*1   DIST
     On entry, DIST specifies the type of distribution from which the
     matrix A is chosen.

    

    • 

  • 

    N
    

         INTEGER       N
     The order of the matrix A.

    

    • 

  • 

    MODE
    

         INTEGER       MODE
     If MODE = 0, the eigenvalues are chosen from the interval [VL, VU].
     If MODE = 1, the eigenvalues are chosen from the interval [VL, VU]
     and sorted.
     If MODE = 2, the eigenvalues are chosen from the interval [VL, VU]
     and are randomly permuted.
     If MODE = 3, the eigenvalues are chosen from the interval [VL, VU]
     and are symmetrically permuted.
     If MODE = 4, the eigenvalues are chosen from the interval [VL, VU]
     and the singular values are randomly permuted.
     If MODE = 5, the eigenvalues are chosen from the interval [VL, VU]
     and the singular values are symmetrically permuted.
     If MODE = 6, the eigenvalues are chosen from the interval [VL, VU]
     and the singular values are randomly permuted.
     Modified if MODE is nonzero.

    

    • 

  • 

    VL
    

         REAL          VL
     The lower bound of the interval for the eigenvalues.

    

    • 

  • 

    VU
    

         REAL          VU
     The upper bound of the interval for the eigenvalues.

    

    • 

  • 

    IL
    

         INTEGER
     The row index of the first eigenvalue to be modified.

    

    • 

  • 

    IU
    

         INTEGER
     The row index of the last eigenvalue to be modified.

    

    • 

  • 

    KEY
    

         CHARACTER*1   KEY
     Specifies the form of the matrix A.

    

    • 

  • 

    PIVOT
    

         CHARACTER*1   PIVOT
     Specifies the pivot for the matrix A.

    

    • 

  • 

    SUB
    

         CHARACTER*1   SUB
     Specifies the subdiagonal for the matrix A.

    

    • 

  • 

    N1
    

         INTEGER
     Specifies the number of eigenvalues to be modified in the first block.

    

    • 

  • 

    N2
    

         INTEGER
     Specifies the number of eigenvalues to be modified in the second block.

    

    • 

  • 

    NB
    

         INTEGER
     Specifies the number of eigenvalues to be modified in the third block.

    

    • 

  • 

    SIGMA
    

         REAL          SIGMA
     Specifies the value of sigma.

    

    • 

  • 

    RESL
    

         REAL          RESL
     Specifies the lower bound for the real part of the eigenvalues.

    

    • 

  • 

    RESR
    

         REAL          RESR
     Specifies the upper bound for the real part of the eigenvalues.

    

    • 

  • 

    A
    

         REAL array, dimension ( LDA, N )
     On entry, A is a matrix of dimension (N,N).
     On exit, A is the desired test matrix.
     Modified.

    

    • 

  • 

    LDA
    

         INTEGER
     LDA specifies the first dimension of A as declared in the
     calling program. LDA must be at least N.
     Not modified.

    

    • 

  • 

    D
    

         REAL array, dimension ( N )
     On entry, D contains the desired eigenvalues.
     On exit, D contains the desired eigenvalues, possibly modified.
     Modified if MODE is nonzero.

    

    • 

  • 

    E
    

         REAL array, dimension ( N )
     On entry, E contains the desired subdiagonal elements.
     On exit, E contains the desired subdiagonal elements, possibly modified.
     Modified if MODE is nonzero.

    

    • 

  • 

    U
    

         REAL array, dimension ( LDU, N )
     On entry, U is an orthogonal matrix.
     On exit, U is an orthogonal matrix which is used to transform A.
     Modified.

    

    • 

  • 

    LDU
    

         INTEGER
     LDU specifies the first dimension of U as declared in the
     calling program. LDU must be at least N.
     Not modified.

    

    • 

  • 

    V
    

         REAL array, dimension ( LDV, N )
     On entry, V is an orthogonal matrix.
     On exit, V is an orthogonal matrix which is used to transform A.
     Modified.

    

    • 

  • 

    LDV
    

         INTEGER
     LDV specifies the first dimension of V as declared in the
     calling program. LDV must be at least N.
     Not modified.

    

    • 

  • 

    X
    

         REAL array, dimension ( N )
     Used for transformations.
     Modified.

    

    • 

  • 

    Y
    

         REAL array, dimension ( N )
     Used for transformations.
     Modified.

    

    • 

  • 

    IWORK
    

         INTEGER array, dimension ( N )
     Workspace for sorting eigenvalues.
     Modified.

    

    • 

  • 

    WORK
    

         REAL array, dimension ( N )
     Workspace.
     Modified.

    

    • 

  • 

    INFO
    

         INTEGER
     Error code. On exit, INFO will be set to one of the following values:
       0 => normal return
      -1 => N negative
      -2 => DIST illegal string
      -5 => MODE not in range -6 to 6
      -6 => COND less than 1.0, and MODE neither -6, 0 nor 6
      -8 => EI(1) is not ' ' or 'R', EI(j) is not 'R' or 'I', or
            two adjacent elements of EI are 'I'.
      -9 => RSIGN is not 'T' or 'F'
     -10 => UPPER is not 'T' or 'F'
     -11 => SIM   is not 'T' or 'F'
     -12 => MODES=0 and DS has a zero singular value.
     -13 => MODES is not in the range -5 to 5.
     -14 => MODES is nonzero and CONDS is less than 1.
     -15 => KL is less than 1.
     -16 => KU is less than 1, or KL and KU are both less than
            N-1.
     -19 => LDA is less than N.
       1 => Error return from SLATM1 (computing D)
       2 => Cannot scale to DMAX (max. eigenvalue is 0)
       3 => Error return from SLATM1 (computing DS)
       4 => Error return from SLARGE
       5 => Zero singular value from SLATM1.
