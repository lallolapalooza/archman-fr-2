NOM

slapd-dnssrv - Backend de référencement DNS SRV pour slapd

SYNOPIS

/etc/openldap/slapd.conf

DESCRIPTION

Le backend DNSSRV de slapd(8) sert des références basées sur les enregistrements de ressources SRV contenus dans le système DNS.

Ce backend est expérimental.

CONFIGURATION

Le backend DNSSRV n'a pas d'options spécifiques au backend ni à la base de données. Il est configuré simplement par "database dnssrv" suivi d'une directive suffixe, par exemple suffixe "".

CONTRÔLE D'ACCÈS

Le backend dnssrv ne respecte pas toutes les sémantiques ACL telles que décrites dans slapd.access(5). En fait, ce backend n'implémente que l'opération search lorsque le contrôle manageDSAit (RFC 3296) est utilisé, sinon pour chaque opération une référence, lorsque c'est approprié, ou une erreur est retournée. Actuellement, il n'y a aucun moyen de conditionner le retour de la référence par des ACL ; aucun contrôle d'accès n'est implémenté, à l'exception de l'accès read (=r) aux entrées retournées, qui est en fait fourni par le frontend. Notez cependant que les informations retournées par ce backend sont collectées via le DNS, elles sont donc publiques par définition.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd
