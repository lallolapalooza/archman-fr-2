sous-routine slaed7 (integer icompq, integer n, integer qsiz, integer tlvls, integer curlvl, integer curpbm, real, dimension( * ) d, real, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, real rho, integer cutpnt, real, dimension( * ) qstore, integer, dimension( * ) qptr, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, real, dimension( 2, * ) givnum, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLAED7 utilisée par SSTEDC. Calcule le système d'équations propres mis à jour d'une matrice diagonale après modification par une matrice symétrique de rang un. Utilisée lorsque la matrice originale est dense.

Objectif :

!>
!> SLAED7 calcule le système d'équations propres mis à jour d'une matrice diagonale
!> après modification par une matrice symétrique de rang un. Cette
!> sous-routine est utilisée uniquement pour le problème propre nécessitant toutes
!> les valeurs propres et éventuellement les vecteurs propres d'une matrice symétrique dense
!> qui a été réduite à une forme tridiagonale. SLAED1 gère
!> le cas où toutes les valeurs propres et tous les vecteurs propres d'une matrice
!> tridiagonale symétrique sont souhaités.
!>
!>   T = Q(entree) ( D(entree) + RHO * Z*Z**T ) Q**T(entree) = Q(sortie) * D(sortie) * Q**T(sortie)
!>
!>    où Z = Q**Tu, u est un vecteur de longueur N avec des uns dans les
!>    éléments CUTPNT et CUTPNT + 1 et des zéros ailleurs.
!>
!>    Les vecteurs propres de la matrice originale sont stockés dans Q, et les
!>    valeurs propres sont dans D. L'algorithme se compose de trois étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a des valeurs propres multiples ou s'il y a un zéro dans
!>       le vecteur Z. Pour chaque occurrence, la dimension du
!>       problème de l'équation séculaire est réduite de un. Cette étape
!>       est effectuée par la sous-routine SLAED8.
!>
!>       La deuxième étape consiste à calculer les valeurs propres mises à jour.
!>       Ceci est fait en trouvant les racines de l'équation séculaire
!>       via la sous-routine SLAED4 (appelée par SLAED9).
!>       Cette sous-routine calcule également les vecteurs propres du
!>       problème actuel.
!>
!>       La dernière étape consiste à calculer directement les vecteurs propres mis à jour
!>       en utilisant les valeurs propres mises à jour. Les vecteurs propres du
!>       problème actuel sont multipliés par les vecteurs propres du
!>       problème global.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un INTEGER
!>          = 0 : Calcul des valeurs propres uniquement.
!>          = 1 : Calcul également des vecteurs propres de la matrice symétrique dense originale.
!>                À l'entrée, Q contient la matrice orthogonale utilisée
!>                pour réduire la matrice originale à une forme tridiagonale.
!>

N

!>          N est un INTEGER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

QSIZ

!>          QSIZ est un INTEGER
!>         La dimension de la matrice orthogonale utilisée pour réduire
!>         la matrice complète à une forme tridiagonale. QSIZ >= N si ICOMPQ = 1.
!>

TLVLS

!>          TLVLS est un INTEGER
!>         Le nombre total de niveaux de fusion dans l'arbre diviser-pour-régner global.
!>

CURLVL

!>          CURLVL est un INTEGER
!>         Le niveau courant dans la routine de fusion globale,
!>         0 <= CURLVL <= TLVLS.
!>

CURPBM

!>          CURPBM est un INTEGER
!>         Le problème courant au niveau courant dans la routine de fusion globale
!>         (en comptant de la gauche vers la droite, du haut vers le bas).
!>

D

!>          D est un tableau de type REAL, dimension (N)
!>         À l'entrée, les valeurs propres de la matrice perturbée par rang 1.
!>         À la sortie, les valeurs propres de la matrice réparée.
!>

Q

!>          Q est un tableau de type REAL, dimension (LDQ, N)
!>         À l'entrée, les vecteurs propres de la matrice perturbée par rang 1.
!>         À la sortie, les vecteurs propres de la matrice tridiagonale réparée.
!>

LDQ

!>          LDQ est un INTEGER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau de type INTEGER, dimension (N)
!>         La permutation qui réintégrera le sous-problème nouvellement résolu dans l'ordre trié,
!>         c'est-à-dire que D( INDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

RHO

!>          RHO est un REAL
!>         L'élément sous-diagonal utilisé pour créer la modification de rang 1.
!>

CUTPNT

!>          CUTPNT est un INTEGER
!>         Contient l'emplacement de la dernière valeur propre dans la matrice
!>         principale de sous-blocage. min(1,N) <= CUTPNT <= N.
!>

QSTORE

!>          QSTORE est un tableau de type REAL, dimension (N**2+1)
!>         Stocke les vecteurs propres des sous-matrices rencontrées pendant
!>         le processus diviser-pour-régner, regroupés. QPTR pointe vers
!>         le début des sous-matrices.
!>

QPTR

!>          QPTR est un tableau de type INTEGER, dimension (N+2)
!>         Liste des indices pointant vers le début des sous-matrices stockées
!>         dans QSTORE. Les sous-matrices sont numérotées à partir du
!>         coin inférieur gauche de l'arbre diviser-pour-régner, de gauche
!>         à droite et de bas en haut.
!>

PRMPTR

!>          PRMPTR est un tableau de type INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans PERM la
!>         permutation d'un niveau est stockée. PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et aussi la taille du
!>         problème complet, non déflaté.
!>

PERM

!>          PERM est un tableau de type INTEGER, dimension (N lg N)
!>         Contient les permutations (de la déflation et du tri) à
!>         appliquer à chaque bloc propre.
!>

GIVPTR

!>          GIVPTR est un tableau de type INTEGER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans GIVCOL les
!>         rotations de Givens d'un niveau sont stockées. GIVPTR(i+1) - GIVPTR(i)
!>         indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est un tableau de type INTEGER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau de type REAL, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la rotation de Givens
!>         correspondante.
!>

WORK

!>          WORK est un tableau de type REAL, dimension (3*N+2*QSIZ*N)
!>

IWORK

!>          IWORK est un tableau de type INTEGER, dimension (4*N)
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé.
!>
