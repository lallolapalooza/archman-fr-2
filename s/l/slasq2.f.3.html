sous-routine slasq2 (integer n, real, dimension( * ) z, integer info)

SLASQ2 calcule toutes les valeurs propres de la matrice tridiagonale symétrique définie positive associée au tableau qd Z, avec une haute précision relative. Utilisé par sbdsqr et sstegr.

Objectif :

!>
!> SLASQ2 calcule toutes les valeurs propres de la matrice tridiagonale
!> symétrique définie positive associée au tableau qd Z, avec une haute
!> précision relative, en l'absence de dénormalisation, de débordement
!> inférieur et supérieur.
!>
!> Pour voir la relation entre Z et la matrice tridiagonale, soit L une
!> matrice bidiagonale inférieure unitaire avec des sous-diagonales
!> Z(2,4,6,,..) et soit U une matrice bidiagonale supérieure avec des 1
!> au-dessus et des diagonales Z(1,3,5,,..). La tridiagonale est L*U ou,
!> si vous préférez, la symétrique tridiagonale à laquelle elle est
!> similaire.
!>
!> Note : SLASQ2 définit une variable logique, IEEE, qui est vraie
!> sur les machines qui suivent la norme flottante ieee-754 dans leur
!> gestion des infinis et des NaN, et fausse sinon. Cette variable
!> est passée à SLASQ3.
!>

Paramètres

N 
!>          N est un ENTIER
!>        Le nombre de lignes et de colonnes de la matrice. N >= 0.
!>

Z

!>          Z est un tableau REEL, de dimension ( 4*N )
!>        À l'entrée, Z contient le tableau qd. À la sortie, les entrées
!>        de 1 à N contiennent les valeurs propres par ordre décroissant,
!>        Z( 2*N+1 ) contient la trace, et Z( 2*N+2 ) contient la somme
!>        des valeurs propres. Si N > 2, alors Z( 2*N+3 ) contient le
!>        compteur d'itérations, Z( 2*N+4 ) contient NDIVS/NIN^2, et
!>        Z( 2*N+5 ) contient le pourcentage de changements qui ont échoué.
!>

INFO

!>          INFO est un ENTIER
!>        = 0 : sortie réussie
!>        < 0 : si le i-ème argument est un scalaire et avait une valeur
!>             illégale, alors INFO = -i, si le i-ème argument est un
!>             tableau et que l'entrée j avait une valeur illégale, alors
!>             INFO = -(i*100+j)
!>        > 0 : l'algorithme a échoué
!>              = 1, un découpage a été marqué par une valeur positive dans E
!>              = 2, le bloc courant de Z n'a pas été diagonalisé après 100*N
!>                   itérations (dans la boucle while interne). À la sortie Z
!>                   contient un tableau qd avec les mêmes valeurs propres que le
!>                   Z donné.
!>              = 3, le critère d'arrêt de la boucle while externe n'a pas été
!>                   atteint (le programme a créé plus de N blocs non réduits)
!>

Détails supplémentaires :

!>
!>  Variables locales : I0:N0 définit un segment courant non réduit de Z.
!>  Les changements sont accumulés dans SIGMA. Le compteur d'itérations est
!>  dans ITER. Le ping-pong est contrôlé par PP (alterne entre 0 et 1).
!>
