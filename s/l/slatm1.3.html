subroutine slatm1 (integer mode, real cond, integer irsign, integer idist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer n, integer info)

SLATM1

Objectif :

!>
!>    SLATM1 calcule les entrées de D(1..N) comme spécifié par
!>    MODE, COND et IRSIGN. IDIST et ISEED déterminent la génération
!>    de nombres aléatoires. SLATM1 est appelé par SLATMR pour générer
!>    des matrices de test aléatoires pour les programmes LAPACK.
!>

Paramètres

MODE 
!>          MODE est un entier
!>           À l'entrée, décrit comment D doit être calculé :
!>           MODE = 0 signifie ne pas modifier D.
!>           MODE = 1 définit D(1)=1 et D(2:N)=1.0/COND
!>           MODE = 2 définit D(1:N-1)=1 et D(N)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    sont uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires issus de la même
!>                    distribution que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est positif, D a des entrées allant de
!>              1 à 1/COND, si négatif, de 1/COND à 1,
!>           Non modifié.
!>

COND

!>          COND est un réel
!>           À l'entrée, utilisé comme décrit sous MODE ci-dessus.
!>           S'il est utilisé, il doit être >= 1. Non modifié.
!>

IRSIGN

!>          IRSIGN est un entier
!>           À l'entrée, si MODE n'est ni -6, ni 0, ni 6, détermine le signe des
!>           entrées de D
!>           0 => laisse les entrées de D inchangées
!>           1 => multiplie chaque entrée de D par 1 ou -1 avec une probabilité de 0.5
!>

IDIST

!>          IDIST est un entier
!>           À l'entrée, IDIST spécifie le type de distribution à utiliser
!>           pour générer une matrice aléatoire.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMALE( 0, 1 )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Le générateur de nombres aléatoires utilise une
!>           séquence congruente linéaire limitée à de petits entiers,
!>           et devrait produire des nombres aléatoires indépendants de la machine.
!>           Les valeurs de ISEED sont modifiées à la sortie et peuvent être
!>           utilisées dans le prochain appel à SLATM1 pour continuer la même
!>           séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

D

!>          D est un tableau réel, dimension ( N )
!>           Tableau à calculer selon MODE, COND et IRSIGN.
!>           Peut être modifié à la sortie si MODE est non nul.
!>

N

!>          N est un entier
!>           Nombre d'entrées de D. Non modifié.
!>

INFO

!>          INFO est un entier
!>            0  => fin normale
!>           -1  => si MODE n'est pas dans l'intervalle -6 à 6
!>           -2  => si MODE n'est ni -6, ni 0, ni 6, et
!>                  IRSIGN n'est ni 0 ni 1
!>           -3  => si MODE n'est ni -6, ni 0, ni 6 et COND est inférieur à 1
!>           -4  => si MODE est égal à 6 ou -6 et IDIST n'est pas dans l'intervalle 1 à 3
!>           -7  => si N est négatif
!>
