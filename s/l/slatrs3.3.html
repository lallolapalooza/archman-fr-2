sous-programme slatrs3 (caractère uplo, caractère trans, caractère diag, caractère normin, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( * ) scale, réel, dimension( * ) cnorm, réel, dimension( * ) work, entier lwork, entier info)

SLATRS3 résout un système d'équations triangulaires avec les facteurs d'échelle définis pour éviter le dépassement de capacité.

Objectif :

!>
!> SLATRS3 résout l'un des systèmes triangulaires
!>
!>    A * X = B * diag(scale)  ou  A**T * X = B * diag(scale)
!>
!> avec mise à l'échelle pour éviter le dépassement de capacité. Ici, A est une
!> matrice triangulaire supérieure ou inférieure, A**T dénote la transposée de A. X et B sont
!> des matrices n par nrhs et scale est un vecteur de nrhs éléments de facteurs
!> d'échelle. Un facteur d'échelle scale(j) est généralement inférieur ou égal
!> à 1, choisi de telle sorte que X(:,j) soit inférieur au seuil de dépassement.
!> Si la matrice A est singulière (A(j,j) = 0 pour un certain j), alors
!> une solution non triviale à A*X = 0 est renvoyée. Si le système est
!> si mal mis à l'échelle que la solution ne peut pas être représentée comme
!> (1/scale(k))*X(:,k), alors x(:,k) = 0 et scale(k) est renvoyé.
!>
!> Ceci est une version BLAS-3 de LATRS pour résoudre plusieurs côtés droits
!> simultanément.
!>
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b  (Pas de transposée)
!>          = 'T':  Résoudre A**T* x = s*b  (Transposée)
!>          = 'C':  Résoudre A**T* x = s*b  (Transposée conjuguée = Transposée)
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

NORMIN

!>          NORMIN est CARACTERE*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. En sortie, les normes seront
!>                  calculées et stockées dans CNORM.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de colonnes de X.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure supérieure n x n du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          triangulaire inférieure n x n du tableau A contient la matrice
!>          triangulaire inférieure, et la partie strictement triangulaire
!>          supérieure de A n'est pas référencée.  Si DIAG = 'U', les éléments
!>          diagonaux de A ne sont pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max (1,N).
!>

X

!>          X est un tableau REEL, de dimension (LDX,NRHS)
!>          À l'entrée, le côté droit B du système triangulaire.
!>          En sortie, X est écrasé par la matrice solution X.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max (1,N).
!>

SCALE

!>          SCALE est un tableau REEL, de dimension (NRHS)
!>          Le facteur d'échelle s(k) est pour le système triangulaire
!>          A * x(:,k) = s(k)*b(:,k)  ou  A**T* x(:,k) = s(k)*b(:,k).
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle.
!>          Si A(j,j) = 0 est rencontré, un vecteur non trivial x(:,k)
!>          qui est une solution exacte ou approximative à A*x(:,k) = 0
!>          est renvoyé. Si le système est si mal mis à l'échelle que la solution
!>          ne peut pas être présentée comme x(:,k) * 1/s(k), alors x(:,k) = 0
!>          est renvoyé.
!>

CNORM

!>          CNORM est un tableau REEL, de dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie non diagonale de la j-ème colonne
!>          de A.  Si TRANS = 'N', CNORM(j) doit être supérieur ou égal
!>          à la norme infinie, et si TRANS = 'T' ou 'C', CNORM(j)
!>          doit être supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          renvoie la norme 1 de la partie non diagonale de la j-ème colonne
!>          de A.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>
!>          Si MIN(N,NRHS) = 0, LWORK >= 1, sinon
!>          LWORK >= MAX(1, 2*NBA * MAX(NBA, MIN(NRHS, 32)), où
!>          NBA = (N + NB - 1)/NB et NB est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement les dimensions optimales du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -k, le k-ème argument avait une valeur illégale
!>
