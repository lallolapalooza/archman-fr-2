NOM

slurmstepd - Le gestionnaire de pas de tâche pour Slurm.

SYNTAXE

slurmstepd

DESCRIPTION

slurmstepd est un gestionnaire de pas de tâche pour Slurm. Il est lancé par le démon slurmd lors du lancement d'un pas de tâche et se termine lorsque le pas de tâche se termine. Il est responsable de la gestion des entrées et sorties (stdin, stdout et stderr) pour le pas de tâche, ainsi que de sa comptabilité et de son traitement des signaux. slurmstepd ne doit pas être initié par les utilisateurs ou les administrateurs système.

VARIABLES D'ENVIRONNEMENT :

Les variables d'environnement suivantes peuvent être utilisées pour remplacer les paramètres compilés dans slurmstepd.

SLURM_DEBUG_FLAGS
Spécifie les indicateurs de débogage à utiliser par slurmstepd. Voir DebugFlags dans la page de manuel de slurm.conf(5) pour une liste complète des indicateurs. La variable d'environnement a la priorité sur le paramètre dans slurm.conf.

SIGNALS

SIGINT SIGTERM SIGQUIT
slurmstepd s'arrêtera proprement.
SIGPROF
Enregistre l'état du gestionnaire de connexion lorsque le niveau de débogage est au moins info.
SIGTSTP SIGPIPE SIGUSR1 SIGUSR2 SIGALRM SIGHUP
Ces signaux sont explicitement ignorés.
