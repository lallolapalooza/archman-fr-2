NOM

slapcat - Utilitaire de base de données SLAPD vers le format LDIF

SYNTAXE

/usr/bin/slapcat [-afiltre] [-bsuffixe] [-c] [-dniveau-débogage] [-fslapd.conf] [-Frépertoire-conf] [-g] [-HURI] [-lfichier-ldif] [-nnuméro-db] [-ooption[=valeur]] [-sdn-sous-arbre] [-v]

DESCRIPTION

Slapcat est utilisé pour générer une sortie au format LDIF (LDAP Directory Interchange Format) basée sur le contenu d'une base de données slapd(8). Il ouvre la base de données spécifiée, déterminée par son numéro ou son suffixe, et écrit la sortie LDIF correspondante sur la sortie standard ou dans le fichier spécifié. Les bases de données configurées comme subordonnées à celle-ci sont également incluses dans la sortie, sauf si -g est spécifié.

Les enregistrements des entrées sont présentés par ordre de base de données, et non par ordre hiérarchique croissant. Les enregistrements des entrées incluront tous les attributs (utilisateurs et opérationnels) stockés dans la base de données. Les enregistrements des entrées n'incluront pas les attributs générés dynamiquement (comme subschemaSubentry).

La sortie de slapcat est destinée à être utilisée comme entrée pour slapadd(8). La sortie de slapcat ne peut généralement pas être utilisée comme entrée pour ldapadd(1) ou d'autres clients LDAP sans édition préalable de la sortie. Cette édition impliquerait normalement de réorganiser les enregistrements par ordre hiérarchique croissant et de supprimer les attributs opérationnels non modifiables par l'utilisateur.

OPTIONS

-a filtre
Ne sortir que les entrées correspondant au filtre spécifié. Par exemple

slapcat -a \
"(!(entryDN:dnSubtreeMatch:=ou=People,dc=example,dc=com))"

sortira tout sauf le sous-arbre "ou=People,dc=example,dc=com" de la base de données "dc=example,dc=com". Obsolète ; utiliser -H ldap:///???(filtre) à la place.

-b suffixe
Utiliser le suffixe spécifié pour déterminer quelle base de données doit générer la sortie. Par défaut, la première base de données qui supporte l'opération demandée est utilisée. L'option -b ne peut pas être utilisée en conjonction avec l'option -n.
-c
Activer le mode de poursuite (ignorer les erreurs). Des occurrences multiples de -c font que slapcat(8) essaie plus fort.
-d niveau-débogage
Activer les messages de débogage tels que définis par le niveau-débogage spécifié ; voir slapd(8) pour les détails.
-f slapd.conf
Spécifier un fichier slapd.conf(5) alternatif.
-F répertoire-conf
spécifier un répertoire de configuration. Si -f et -F sont spécifiés, le fichier de configuration sera lu et converti au format de répertoire de configuration et écrit dans le répertoire spécifié. Si aucune de ces options n'est spécifiée, une tentative de lecture du répertoire de configuration par défaut sera faite avant d'essayer d'utiliser le fichier de configuration par défaut. Si un répertoire de configuration valide existe, le fichier de configuration par défaut est ignoré.
-g
Désactiver le collage des subordonnés. Seule la base de données spécifiée sera traitée, et non ses subordonnés collés (s'il y en a).
-H  URI
Utiliser le dn, la portée et le filtre de l'URI pour ne traiter que les entrées correspondantes.
-l fichier-ldif
Écrire la sortie LDIF dans le fichier spécifié au lieu de la sortie standard.
-n numéro-db
Générer la sortie pour la numéro-db-ième base de données listée dans le fichier de configuration. La base de données de configuration slapd-config(5) est toujours la première base de données, donc utiliser -n 0 pour la sélectionner.

L'option -n ne peut pas être utilisée en conjonction avec l'option -b.

-o option[=valeur]
Spécifier une option avec une valeur (optionnelle). Les options/valeurs génériques possibles sont :
              syslog=<sous-systèmes>  (voir `-s' dans slapd(8))
              syslog-level=<niveau> (voir `-S' dans slapd(8))
              syslog-user=<utilisateur>   (voir `-l' dans slapd(8))
              ldif_wrap={non|<n>}
n est le nombre de colonnes autorisées pour la sortie LDIF
(n égal à 0 utilise la valeur par défaut, correspondant à 78).
Le minimum est 2, laissant de la place pour un caractère et un
caractère de continuation.
Utiliser non pour ne pas faire de retour à la ligne.
-s dn-sous-arbre
Ne sortir que les entrées dans le sous-arbre spécifié par ce DN.
Implique -b dn-sous-arbre si aucune
option -b
ou
-n
n'est donnée.
Obsolète ; utiliser -H ldap:///dn-sous-arbre à la place.
-v
Activer le mode verbeux.

LIMITATIONS

Pour certains types de backends, votre slapd(8) ne doit pas être en cours d'exécution (du moins, pas en mode lecture-écriture) lorsque vous effectuez cette opération pour garantir la cohérence de la base de données. Il est toujours sûr d'exécuter slapcat avec les backends slapd-mdb(5) et slapd-null(5).

EXEMPLES

Pour faire une sauvegarde texte de votre base de données SLAPD et la placer dans un fichier nommé ldif, tapez la commande :

/usr/bin/slapcat -l ldif
