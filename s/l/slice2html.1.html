slice2html(1) Manuel des commandes générales slice2html(1)

NOM

slice2html - L'outil de documentation Slice vers HTML.

SYNTAXE

slice2html [options] [fichiers]

DESCRIPTION

slice2html génère la documentation HTML à partir des fichiers Slice. La macro __SLICE2HTML__ est définie lors de cette compilation.

La documentation complète pour slice2html est disponible en ligne à l'adresse :
https://doc.zeroc.com/ice/3.7/the-slice-language/generating-slice-documentation

slice2html est obsolète, Doxygen est maintenant la méthode préférée pour générer la référence d'API Slice, voir :
https://doc.zeroc.com/api/ice/3.7/slice/

OPTIONS

-h, --help

Affiche le message d'aide.
-v, --version
Affiche la version du compilateur.
-DNAME

Définit le symbole du préprocesseur NAME.
-DNAME=DEF

Définit le symbole du préprocesseur NAME avec la valeur DEF.
-UNAME

Annule la définition du symbole du préprocesseur NAME.
-IDIR

Ajoute le répertoire DIR au chemin de recherche pour les directives #include.
-E

Affiche la sortie du préprocesseur sur la sortie standard.
--output-dir DIR

Place les fichiers générés dans le répertoire DIR.
-d, --debug

Affiche des informations de débogage montrant le fonctionnement de l'analyseur Slice.
--hdr FICHIER

Prépende FICHIER à chaque fichier HTML généré (sauf _sindex.html). Ceci vous permet de remplacer l'en-tête HTML et d'autres informations de préambule par une version personnalisée, afin de pouvoir connecter des feuilles de style aux pages générées. Le fichier spécifié doit inclure la balise <body> (mais il n'est pas nécessaire qu'il se termine par une balise </body>). FICHIER est censé contenir la chaîne TITLE sur une ligne séparée, commençant dans la première colonne. slice2html remplace la chaîne TITLE par le nom complètement qualifié du symbole Slice qui est documenté sur la page correspondante.
--ftr FICHIER

Ajoute FICHIER à la fin de chaque fichier HTML généré (sauf _sindex.html). Ceci vous permet d'ajouter, par exemple, un pied de page personnalisé à chaque page générée. FICHIER doit se terminer par une balise </body>.
--indexhdr FICHIER

slice2html génère un fichier _sindex.html qui contient une table des matières de tous les symboles Slice qui hyperliens vers la page correspondante. Cette option vous permet de remplacer l'en-tête standard par un en-tête personnalisé, par exemple, pour attacher un JavaScript. Le fichier spécifié doit inclure la balise <body> (mais il n'est pas nécessaire qu'il se termine par une balise </body>). La valeur par défaut est le paramètre de --hdr (le cas échéant).
--indexftr FICHIER

Ajoute FICHIER à la fin de la page sindex.html générée. Ceci vous permet d'ajouter, par exemple, un pied de page personnalisé à la table des matières, ou d'invoquer un JavaScript. FICHIER doit se terminer par une balise </body>. La valeur par défaut est le paramètre de --ftr (le cas échéant).
--image-dir DIR

Avec cette option, slice2html recherche dans le répertoire spécifié des images à utiliser pour les hyperliens de navigation générés. (Sans cette option, des liens textuels sont utilisés à la place.) Veuillez consulter le HTML généré pour connaître les noms des différents fichiers image. (Ils peuvent facilement être trouvés en recherchant les éléments img.)
--logo-url URL

Utilise l'URL spécifiée comme hyperlien pour le logo de l'entreprise ajouté à chaque page (si --image-dir est spécifié). Le logo de l'entreprise est censé être dans <image_dir>/logo.gif.
--search ACTION

Si cette option est spécifiée, les pages générées contiennent une boîte de recherche qui vous permet de connecter les pages générées à un moteur de recherche. En appuyant sur le bouton "Search", l'ACTION spécifiée est exécutée.
--index NUM

slice2html génère des sous-index pour divers symboles Slice. Cette option contrôle combien d'entrées doivent être présentes avant qu'un sous-index ne soit généré. Par exemple, si NUM est défini à 3, un sous-index ne sera généré que s'il y a trois symboles ou plus qui apparaissent dans cet index. La valeur par défaut est 1, ce qui signifie qu'un sous-index est toujours généré. Pour désactiver complètement les sous-index, définissez NUM sur 0.
--summary NUM

Si cette option est définie, les phrases récapitulatives dépassant NUM caractères génèrent un avertissement.
