NOM

slmthread - met en file d'attente le modèle de langue

SYNTAXE

slmthread slm_primitive slm_en_file_attente

DESCRIPTION

slmthread ajoute un état de réduction pour chaque nœud slm dans le slm_primitive. Il compresse également les nombres flottants 32 bits en représentation 16 bits. Ces traitements accélèrent la recherche.

Le slm_primitive est toujours généré par slmprune. Et le slm_en_file_attente peut être utilisé pour alimenter slmseg comme référence pour segmenter le texte chinois.
