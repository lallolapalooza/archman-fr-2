Documentation de fonction/sous-routine

sous-routine slatmt (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, real, dimension( * ) d, integer mode, real cond, real dmax, integer rank, integer kl, integer ku, character pack, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work, integer info)

SLATMT

Objectif :

!>
!>    SLATMT génère des matrices aléatoires avec des valeurs singulières spécifiées
!>    (ou symétriques/hermitiennes avec des valeurs propres spécifiées)
!>    pour tester les programmes LAPACK.
!>
!>    SLATMT opère en appliquant la séquence suivante d'
!>    opérations :
!>
!>      Définit la diagonale à D, où D peut être entré ou
!>         calculé selon MODE, COND, DMAX, et SYM
!>         comme décrit ci-dessous.
!>
!>      Génère une matrice avec la structure de bande appropriée, par une
!>         des deux méthodes :
!>
!>      Méthode A :
!>          Génère une matrice dense M x N en multipliant D à gauche
!>              et à droite par des matrices unitaires aléatoires, puis :
!>
!>          Réduit la bande selon KL et KU, en utilisant
!>          des transformations de Householder.
!>
!>      Méthode B :
!>          Convertit la matrice de bande 0 (c'est-à-dire diagonale) en une
!>              matrice de bande 1 en utilisant des rotations de Givens, 
!>              les éléments hors bande reviennent, un peu comme dans QR ; puis
!>              convertit la bande 1 en une bande 2, etc.
!>              Notez que pour des bandes raisonnablement petites (par rapport à
!>              M et N) cela nécessite moins de stockage, car une matrice dense
!>              n'est pas générée. De plus, pour les matrices symétriques, seul
!>              un triangle est généré.
!>
!>      La méthode A est choisie si la bande est une grande fraction de l'
!>          ordre de la matrice, et si LDA est au moins égal à M (donc une matrice
!>          dense peut être stockée.) La méthode B est choisie si la bande
!>          est petite (< 1/2 N pour symétrique, < .3 N+M pour
!>          non-symétrique), ou si LDA est inférieur à M et non inférieur à la
!>          bande.
!>
!>      Empaquette la matrice si désiré. Les options spécifiées par PACK sont :
!>         pas d'empaquetage
!>         remplir de zéros la moitié supérieure (si symétrique)
!>         remplir de zéros la moitié inférieure (si symétrique)
!>         stocker la moitié supérieure colonne par colonne (si symétrique ou
!>               triangulaire supérieure)
!>         stocker la moitié inférieure colonne par colonne (si symétrique ou
!>               triangulaire inférieure)
!>         stocker le triangle inférieur au format bande (si symétrique ou
!>               triangulaire inférieure)
!>         stocker le triangle supérieur au format bande (si symétrique ou
!>               triangulaire supérieure)
!>         stocker toute la matrice au format bande
!>      Si la méthode B est choisie, et si le format bande est spécifié, alors la
!>         matrice sera générée au format bande, donc aucun ré-empaquetage
!>         ne sera nécessaire.
!>

Paramètres

M 
!>          M est INTEGER
!>           Le nombre de lignes de A. Non modifié.
!>

N

!>          N est INTEGER
!>           Le nombre de colonnes de A. Non modifié.
!>

DIST

!>          DIST est CHARACTER*1
!>           À l'entrée, DIST spécifie le type de distribution à utiliser
!>           pour générer les valeurs propres/singulières aléatoires.
!>           'U' => UNIFORME( 0, 1 )  ( 'U' pour uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' pour symétrique )
!>           'N' => NORMALE( 0, 1 )   ( 'N' pour normale )
!>           Non modifié.
!>

ISEED

!>          ISEED est un tableau INTEGER, dimension ( 4 )
!>           À l'entrée, ISEED spécifie la graine du générateur de nombres
!>           aléatoires. Les valeurs doivent être comprises entre 0 et 4095 inclus,
!>           et ISEED(4) doit être impair. Le générateur de nombres aléatoires
!>           utilise une séquence congruente linéaire limitée à de petits
!>           entiers, et devrait donc produire des nombres aléatoires indépendants
!>           de la machine. Les valeurs de ISEED sont modifiées à la sortie,
!>           et peuvent être utilisées dans le prochain appel à SLATMT
!>           pour continuer la même séquence de nombres aléatoires.
!>           Modifié à la sortie.
!>

SYM

!>          SYM est CHARACTER*1
!>           Si SYM='S' ou 'H', la matrice générée est symétrique, avec
!>             des valeurs propres spécifiées par D, COND, MODE, et DMAX ; elles
!>             peuvent être positives, négatives ou nulles.
!>           Si SYM='P', la matrice générée est symétrique, avec
!>             des valeurs propres (= valeurs singulières) spécifiées par D, COND,
!>             MODE, et DMAX ; elles ne seront pas négatives.
!>           Si SYM='N', la matrice générée est non symétrique, avec
!>             des valeurs singulières spécifiées par D, COND, MODE, et DMAX ;
!>             elles ne seront pas négatives.
!>           Non modifié.
!>

D

!>          D est un tableau REAL, dimension ( MIN( M , N ) )
!>           Ce tableau est utilisé pour spécifier les valeurs singulières ou
!>           les valeurs propres de A (voir SYM, ci-dessus.) Si MODE=0, alors D est
!>           supposé contenir les valeurs propres/singulières, sinon
!>           elles seront calculées selon MODE, COND, et DMAX,
!>           et placées dans D.
!>           Modifié si MODE est non nul.
!>

MODE

!>          MODE est INTEGER
!>           À l'entrée, cela décrit comment les valeurs propres/singulières sont
!>           spécifiées :
!>           MODE = 0 signifie utiliser D en entrée
!>
!>           MODE = 1 définit D(1)=1 et D(2:RANK)=1.0/COND
!>           MODE = 2 définit D(1:RANK-1)=1 et D(RANK)=1.0/COND
!>           MODE = 3 définit D(I)=COND**(-(I-1)/(RANK-1))
!>
!>           MODE = 4 définit D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 définit D à des nombres aléatoires dans l'intervalle
!>                    ( 1/COND , 1 ) tels que leurs logarithmes
!>                    soient uniformément distribués.
!>           MODE = 6 définit D à des nombres aléatoires provenant de la même distribution
!>                    que le reste de la matrice.
!>           MODE < 0 a la même signification que ABS(MODE), sauf que
!>              l'ordre des éléments de D est inversé.
!>           Ainsi, si MODE est positif, D a des entrées allant de
!>              1 à 1/COND, si négatif, de 1/COND à 1,
!!>           Si SYM='S' ou 'H', et que MODE n'est ni 0, ni 6, ni -6, alors
!>              les éléments de D seront également multipliés par un signe aléatoire
!>              (c'est-à-dire +1 ou -1.)
!>           Non modifié.
!>

COND

!>          COND est REAL
!>           À l'entrée, ceci est utilisé comme décrit sous MODE ci-dessus.
!>           Si utilisé, il doit être >= 1. Non modifié.
!>

DMAX

!>          DMAX est REAL
!>           Si MODE n'est ni -6, ni 0, ni 6, le contenu de D, tel que
!>           calculé selon MODE et COND, sera mis à l'échelle par
!>           DMAX / max(abs(D(i))) ; ainsi, la valeur propre ou singulière
!>           absolue maximale (qui est la norme) sera abs(DMAX).
!>           Notez que DMAX n'a pas besoin d'être positif : si DMAX est négatif
!>           (ou nul), D sera mis à l'échelle par un nombre négatif (ou nul).
!>           Non modifié.
!>

RANK

!>          RANK est INTEGER
!>           Le rang de la matrice à générer pour les modes 1, 2, 3 uniquement.
!>           D( RANK+1:N ) = 0.
!>           Non modifié.
!>

KL

!>          KL est INTEGER
!>           Ceci spécifie la bande inférieure de la matrice. Par
!>           exemple, KL=0 implique triangulaire supérieure, KL=1 implique
!>           Hessenberg supérieure, et KL étant au moins égal à M-1 signifie que la matrice
!>           a une bande inférieure complète. KL doit être égal à KU si la matrice
!>           est symétrique.
!>           Non modifié.
!>

KU

!>          KU

Function/Subroutine Documentation

SLATMT

  REAL FUNCTION SLATMT( N, DIST, MODE, D, V, LDFLAGS, DIAG,
     & U, LDQU, KU, KL, PACK, A, LDA, WORK, INFO )
  CHARACTER*1 DIST, MODE, DIAG, PACK
  INTEGER N, LDFLAGS, LDQU, KU, KL, LDA, INFO
  REAL D( * ), V( * ), U( * ), A( * ), WORK( * )

Purpose

SLATMT generates test matrices for use in (high-level) sparse matrix routines. It is particularly useful for testing the routines which solve Ax = B when A is symmetric or has a known bandwidth.

Matrices generated by SLATMT are formed as follows:

  A = U * diag(D) * V**T
      where U and V are orthogonal matrices, and D is a diagonal matrix
      with diagonal entries D.

If DIAG = 'N', the diagonal entries D are constructed so that the row sums of absolute values are equal.

If DIAG = 'Y', the diagonal entries D are constructed so that the 1-norm of the matrix is equal to COND.

If DIAG = 'N', the matrices U and V are constructed by orthogonal transformations, so that the resulting matrix A has a specified bandwidth (KU, KL) and storage format (PACK).

If DIAG = 'Y', U and V are not necessarily orthogonal. They are generated in packed or banded format, and packed into the first M elements of the first N columns of A. The diagonal elements D are generated to satisfy the 1-norm condition.

The subroutines SLATMS and SLATMTS are called by SLATMT to generate the orthogonal matrices U and V.

Arguments

N INTEGER

  The number of columns of the matrix A.  N >= 0.

DIST CHARACTER*1

  Specifies the form of the matrix A and the distribution of its
  eigenvalues.
  'U' => U and V are randomly chosen orthogonal matrices.
  'R' => U and V are random matrices.
  'S' => U and V are randomly chosen orthogonal matrices.
  'N' => U = I and V = I.
  'P' => U and V are random matrices, and the matrix A is perturbed
         by multiplying it by a random diagonal matrix.
  'Z' => U and V are random matrices.
  Not modified.

MODE INTEGER

  Specifies the form of the diagonal matrix D.
  MODE = -1 => D is randomly chosen from [0, 1].
  MODE = 0 => D is randomly chosen from [-1, 1].
  MODE = 1 => D is randomly chosen from [1, 10].
  MODE = 2 => D is randomly chosen from [10, 100].
  MODE = 3 => D is randomly chosen from [100, 1000].
  MODE = 4 => D is constant, D(i) = 1 for all i.
  MODE = 5 => D is constant, D(i) = i for all i.
  MODE = 6 => D is constant, D(i) = 1/i for all i.
  MODE = -2 => D is randomly chosen from [0, 1], and A = U*diag(D)*V**T.
                The matrix A is constructed so that its singular values
                are randomly distributed in [0,1].
  MODE = -3 => D is randomly chosen from [1,10], and A = U*diag(D)*V**T.
                The matrix A is constructed so that its singular values
                are randomly distributed in [1,10].
  MODE = -4 => D is randomly chosen from [10,100], and A = U*diag(D)*V**T.
                The matrix A is constructed so that its singular values
                are randomly distributed in [10,100].
  MODE = -5 => D is randomly chosen from [100,1000], and A = U*diag(D)*V**T.
                The matrix A is constructed so that its singular values
                are randomly distributed in [100,1000].
  MODE = -6 => D is randomly chosen from [0,1], and A = U*diag(D)*V**T.
                The matrix A is constructed so that its singular values
                are randomly distributed in [0,1]. The subroutines SLATMS
                and SLATMTS are called to generate U and V, and the
                singular values are used as eigenvalues of the symmetric
                part of the matrix.
  Not modified.

D CHARACTER*1

  Specifies how the diagonal elements of the matrix A are computed.
  'N' => The diagonal elements are computed so that the row sums of
         absolute values of A are all equal.
  'Y' => The diagonal elements are computed so that the 1-norm of A is
         equal to COND.
  Not modified.

V CHARACTER*1

  Specifies the properties of the orthogonal factor V.
  'N' => V is not used.
  'U' => V is a random orthogonal matrix.
  'S' => V is a random orthogonal matrix.
  'Z' => V is a random orthogonal matrix.
  Not modified.

LDFLAGS INTEGER

  The leading dimensions of the arrays D and V. LDFLAGS must be at
  least max(1,N) and LDQU respectively.
  Not modified.

U CHARACTER*1

  Specifies the properties of the orthogonal factor U.
  'N' => U is not used.
  'U' => U is a random orthogonal matrix.
  'S' => U is a random orthogonal matrix.
  'Z' => U is a random orthogonal matrix.
  Not modified.

LDQU INTEGER

  The leading dimensions of the arrays U and V. LDQU must be at least
  max(1,N) and LDFLAGS respectively.
  Not modified.

KU INTEGER

  This specifies the upper bandwidth of the matrix. For
  example, KU=0 implies lower triangular, KU=1 implies lower
  Hessenberg, and KU being at least N-1 means that the matrix
  has full upper bandwidth.  KL must equal KU if the matrix
  is symmetric.
  Not modified.

KL INTEGER

  This specifies the lower bandwidth of the matrix. KL must equal KU
  if the matrix is symmetric.
  Not modified.

PACK CHARACTER*1

  This specifies packing of matrix as follows:
  'N' => no packing
  'U' => zero out all subdiagonal entries (if symmetric)
  'L' => zero out all superdiagonal entries (if symmetric)
  'C' => store the upper triangle columnwise
         (only if the matrix is symmetric or upper triangular)
  'R' => store the lower triangle columnwise
         (only if the matrix is symmetric or lower triangular)
  'B' => store the lower triangle in band storage scheme
         (only if matrix symmetric or lower triangular)
  'Q' => store the upper triangle in band storage scheme
         (only if matrix symmetric or upper triangular)
  'Z' => store the entire matrix in band storage scheme
         (pivoting can be provided for by using this
         option to store A in the trailing rows of
         the allocated storage)
  Using these options, the various LAPACK packed and banded
  storage schemes can be obtained:
  GB               - use 'Z'
  PB, SB or TB     - use 'B' or 'Q'
  PP, SP or TP     - use 'C' or 'R'
  If two calls to SLATMT differ only in the PACK parameter,
  they will generate mathematically equivalent matrices.
  Not modified.

A REAL array, dimension ( LDA, N )

  On exit A is the desired test matrix.  A is first generated
  in full (unpacked) form, and then packed, if so specified
  by PACK.  Thus, the first M elements of the first N
  columns will always be modified.  If PACK specifies a
  packed or banded storage scheme, all LDA elements of the
  first N columns will be modified; the elements of the
  array which do not correspond to elements of the generated
  matrix are set to zero.
  Modified.

LDA INTEGER

  LDA specifies the first dimension of A as declared in the
  calling program.  If PACK='N', 'U', 'L', 'C', or 'R', then
  LDA must be at least M.  If PACK='B' or 'Q', then LDA must
  be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
  If PACK='Z', LDA must be large enough to hold the packed
  array: MIN( KU, N-1) + MIN( KL, M-1) + 1.
  Not modified.

WORK REAL array, dimension ( 3*MAX( N , M ) )

  Workspace.
  Modified.

INFO INTEGER

  Error code.  On exit, INFO will be set to one of the
  following values:
    0 => normal return
   -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
   -2 => N negative
   -3 => DIST illegal string
   -5 => SYM illegal string
   -7 => MODE not in range -6 to 6
   -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
  -10 => KL negative
  -11 => KU negative, or SYM='S' or 'H' and KU not equal to KL
  -12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
         or PACK='C' or 'Q' and SYM='N' and KL is not zero;
         or PACK='R' or 'B' and SYM='N' and KU is not zero;
         or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
         N.
  -14 => LDA is less than M, or PACK='Z' and LDA is less than
         MIN(KU,N-1) + MIN(KL,M-1) + 1.
    1  => Error return from SLATM7
    2  => Cannot scale to DMAX (max. sing. value is 0)
    3  => Error return from SLAGGE or SLAGSY
