sous-routine slarfb (side, trans, direct, storev, m, n, k, v, ldv, t, ldt, c, ldc, work, ldwork)
SLARFB applique un bloc réflecteur ou sa transposée à une matrice rectangulaire générale.

Documentation de la fonction/sous-routine

sous-routine slarfb (character side, character trans, character direct, character storev, integer m, integer n, integer k, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldwork, * ) work, integer ldwork)

SLARFB applique un bloc réflecteur réel H ou sa transposée H**T à une matrice rectangulaire réelle m par n C, par la gauche ou par la droite.

Objectif :

!>
!> SLARFB applique un bloc réflecteur réel H ou sa transposée H**T à une
!> matrice réelle m par n C, depuis la gauche ou la droite.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer H ou H**T par la gauche
!>          = 'R': appliquer H ou H**T par la droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer H (pas de transposée)
!>          = 'T': appliquer H**T (Transposée)
!>

DIRECT

!>          DIRECT est CHARACTER*1
!>          Indique comment H est formée à partir d'un produit de réflecteurs
!>          élémentaires.
!>          = 'F': H = H(1) H(2) . . . H(k) (Forward)
!>          = 'B': H = H(k) . . . H(2) H(1) (Backward)
!>

STOREV

!>          STOREV est CHARACTER*1
!>          Indique comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés :
!>          = 'C': par colonne
!>          = 'R': par ligne
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est INTEGER
!>          L'ordre de la matrice T (= le nombre de réflecteurs élémentaires
!>          dont le produit définit le bloc réflecteur).
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V est un tableau REAL, de dimension
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' et SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' et SIDE = 'R'
!>          La matrice V. Voir Détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C' et SIDE = 'L', LDV >= max(1,M);
!>          Si STOREV = 'C' et SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T est un tableau REAL, de dimension (LDT,K)
!>          La matrice triangulaire k par k T dans la représentation du
!>          bloc réflecteur.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est un tableau REAL, de dimension (LDC,N)
!>          À l'entrée, la matrice C de m lignes et n colonnes.
!>          À la sortie, C est écrasé par H*C ou H**T*C ou C*H ou C*H**T.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau REAL, de dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          Si SIDE = 'R', LDWORK >= max(1,M).
!>

Détails supplémentaires :

!>
!>  La forme de la matrice V et le stockage des vecteurs qui définissent
!>  les H(i) sont mieux illustrés par l'exemple suivant avec n = 5 et
!>  k = 3. La partie triangulaire de V (y compris sa diagonale) n'est pas
!>  référencée.
!>
!>  DIRECT = 'F' et STOREV = 'C':         DIRECT = 'F' et STOREV = 'R':
!>
!>               V = (  1       )                 V = (  1 v1 v1 v1 v1 )
!>                   ( v1  1    )                     (     1 v2 v2 v2 )
!>                   ( v1 v2  1 )                     (        1 v3 v3 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  DIRECT = 'B' et STOREV = 'C':         DIRECT = 'B' et STOREV = 'R':
!>
!>               V = ( v1 v2 v3 )                 V = ( v1 v1  1       )
!>                   ( v1 v2 v3 )                     ( v2 v2 v2  1    )
!>                   (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
!>                   (     1 v3 )
!>                   (        1 )
!>
