NOM

sload.f2fs - charge les répertoires et les fichiers dans le périphérique directement

SYNTAXE

sload.f2fs [ -f chemin-du-répertoire-source ] [ -t point-de-montage ] [ -d niveau-de-débogage ] [ -P ] [ -c [ -L log-des-blocs-par-cluster ] [ -a algorithme-de-compression ] [ -x extension-de-fichier-à-exclure-de-la-compression | -i extension-de-fichier-à-inclure-pour-la-compression ] [ -m blocs-compressés-minimum-par-cluster ] [ -r ] ] périphérique

DESCRIPTION

sload.f2fs est utilisé pour charger des répertoires et des fichiers dans une partition de disque, ou une image F2FS (fichier). périphérique peut être un fichier spécial correspondant au périphérique (par exemple, /dev/sdXX), ou un fichier image F2FS.

Le code de sortie renvoyé par sload.f2fs est 0 en cas de succès et -1 en cas d'échec.

OPTIONS

-f chemin-du-répertoire-source
Spécifie le chemin du répertoire source à charger.
-t chemin-du-point-de-montage
Spécifie le chemin du point de montage dans la partition à charger.
-d niveau-de-débogage
Spécifie le niveau des options de débogage. Le nombre par défaut est 0, ce qui affiche les messages de débogage de base.
-P
Préserve le propriétaire : utilisateur et groupe. L'utilisateur et le groupe des fichiers sources seront pris en compte.
-c
Active la compression de fichiers basée sur les clusters. Le fichier sera coupé en clusters, et chaque cluster sera compressé indépendamment.
-L log-des-blocs-par-cluster
Spécifie la taille du cluster en puissance de deux blocs. La valeur minimale est 2 (4 blocs, par défaut). La valeur maximale est 8 (256 blocs). Notez qu'un bloc contient 4096 octets. Cette option doit être utilisée avec l'option -c.
-a algorithme-de-compression
Choisit l'algorithme de compression. Les options disponibles sont : lzo, lz4 (par défaut). Cette option doit être utilisée avec l'option -c.
-i extension-de-fichier-à-inclure-pour-la-compression
Spécifie une extension de fichier à inclure pour la compression. Pour spécifier plusieurs extensions de fichier, utilisez plusieurs options -i. Les fichiers ayant l'une des extensions listées seront compressés. Cette option doit être utilisée avec l'option -c.
-x extension-de-fichier-à-exclure-de-la-compression
Spécifie une extension de fichier à exclure de la compression. Pour spécifier plusieurs extensions de fichier, utilisez plusieurs options -x. Les fichiers ayant l'une des extensions listées ne seront pas compressés. Cette option doit être utilisée avec l'option -c.
-m blocs-compressés-minimum-par-cluster
Spécifie un nombre minimum de blocs économisés (par compression) par cluster. La valeur minimale est 1 (par défaut). La valeur maximale est la taille du cluster en blocs moins 1. Si la compression d'un cluster échoue à économiser au moins le nombre minimum de blocs compressés donné par l'option, le cluster ne sera pas compressé. Cette option doit être utilisée avec l'option -c.
-r
Spécifie l'indicateur lecture seule pour les fichiers compressés. Cela permet au système de fichiers de libérer l'espace compressé pour les utilisateurs, car, sans cette option, le système de fichiers devrait conserver l'espace pour les mises à jour futures des fichiers. Cette option doit être utilisée avec l'option -c.

NOTES

Si ni -i ni -x n'est utilisé, tous les fichiers seront compressés. Clairement, les options -i et -x ne peuvent pas être utilisées ensemble.
