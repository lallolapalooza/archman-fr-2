sous-routine slag2 (real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real safmin, real scale1, real scale2, real wr1, real wr2, real wi)

SLAG2 calcule les valeurs propres d'un problème de valeurs propres généralisé 2x2, avec mise à l'échelle si nécessaire pour éviter les dépassements/sous-dépassements.

Objectif :

!>
!> SLAG2 calcule les valeurs propres d'un problème de valeurs propres généralisé 2 x 2
!>  A - w B, avec mise à l'échelle si nécessaire pour éviter les dépassements/sous-dépassements.
!>
!> Le facteur de mise à l'échelle  entraîne une équation de valeurs propres modifiée
!>
!>     s A - w B
!>
!> où  s  est un facteur de mise à l'échelle non négatif choisi de sorte que  w,  w B,
!> et  s A  ne dépassent pas, et, si possible, ne sous-dépasse pas non plus.
!>

Paramètres

A 
!>          A est un tableau REAL, de dimension (LDA, 2)
!>          À l'entrée, la matrice 2x2 A. On suppose que sa norme 1
!>          est inférieure à 1/SAFMIN. Les entrées inférieures à
!>          sqrt(SAFMIN)*norm(A) sont susceptibles d'être traitées comme nulles.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= 2.
!>

B

!>          B est un tableau REAL, de dimension (LDB, 2)
!>          À l'entrée, la matrice triangulaire supérieure 2x2 B. Elle est
!>          supposée avoir une norme 1 inférieure à 1/SAFMIN. Les
!>          diagonales doivent être au moins sqrt(SAFMIN) fois le plus grand
!>          élément de B (en valeur absolue) ; si une diagonale est plus petite
!>          que cela, alors +/- sqrt(SAFMIN) sera utilisé à la place de
!>          cette diagonale.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B. LDB >= 2.
!>

SAFMIN

!>          SAFMIN est REAL
!>          Le plus petit nombre positif s tel que 1/SAFMIN ne dépasse pas.
!>          (Cela devrait toujours être SLAMCH('S') -- c'est un
!>          argument afin d'éviter d'appeler SLAMCH fréquemment.)
!>

SCALE1

!>          SCALE1 est REAL
!>          Un facteur de mise à l'échelle utilisé pour éviter les dépassements/sous-dépassements dans l'équation de valeur propre
!>          qui définit la première valeur propre. Si
!>          les valeurs propres sont complexes, alors les valeurs propres sont
!>          ( WR1 +/- WI i ) / SCALE1 (qui peuvent se trouver en dehors de
!>          la plage d'exposants de la machine), SCALE1=SCALE2, et SCALE1
!>          sera toujours positif. Si les valeurs propres sont réelles, alors
!>          la première valeur propre (réelle) est WR1 / SCALE1, mais cela peut
!>          dépasser ou sous-dépasser, et en fait, SCALE1 peut être nul ou
!>          inférieur au seuil de sous-dépassement si la valeur propre exacte
!>          est suffisamment grande.
!>

SCALE2

!>          SCALE2 est REAL
!>          Un facteur de mise à l'échelle utilisé pour éviter les dépassements/sous-dépassements dans l'équation de valeur propre
!>          qui définit la deuxième valeur propre. Si
!>          les valeurs propres sont complexes, alors SCALE2=SCALE1. Si les
!>          valeurs propres sont réelles, alors la deuxième valeur propre (réelle)
!>          est WR2 / SCALE2, mais cela peut dépasser ou sous-dépasser, et en
!>          fait, SCALE2 peut être nul ou inférieur au seuil de sous-dépassement
!>          si la valeur propre exacte est suffisamment grande.
!>

WR1

!>          WR1 est REAL
!>          Si la valeur propre est réelle, alors WR1 est SCALE1 fois la
!>          valeur propre la plus proche de l'élément (2,2) de A B**(-1). Si la
!>          valeur propre est complexe, alors WR1=WR2 est SCALE1 fois la partie
!>          réelle des valeurs propres.
!>

WR2

!>          WR2 est REAL
!>          Si la valeur propre est réelle, alors WR2 est SCALE2 fois l'autre
!>          valeur propre. Si la valeur propre est complexe, alors
!>          WR1=WR2 est SCALE1 fois la partie réelle des valeurs propres.
!>

WI

!>          WI est REAL
!>          Si la valeur propre est réelle, alors WI est zéro. Si la
!>          valeur propre est complexe, alors WI est SCALE1 fois la partie imaginaire
!>          des valeurs propres. WI sera toujours non négatif.
!>
