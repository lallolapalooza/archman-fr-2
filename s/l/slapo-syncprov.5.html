NOM

slapo-syncprov - Superposition fournisseur de synchronisation pour slapd

SYNTAXE

/etc/openldap/slapd.conf

DESCRIPTION

La superposition Sync Provider implémente le support côté fournisseur pour la synchronisation de contenu LDAP (RFC4533) ainsi que le support de réplication syncrepl. La superposition peut être utilisée avec n'importe quel backend qui maintient les attributs entryCSN et entryUUID pour ses entrées. Elle crée également un attribut contextCSN dans l'entrée racine de la base de données.

Le contextCSN est mis à jour pour chaque opération d'écriture effectuée sur la base de données. Pour réduire la contention sur la base de données, le contextCSN est uniquement mis à jour en mémoire. La valeur est écrite dans la base de données lors de l'arrêt du serveur et lue en mémoire au démarrage, puis maintenue en mémoire par la suite. Des points de contrôle peuvent être configurés pour écrire le contextCSN dans la base de données sous-jacente afin de minimiser le temps de récupération après un arrêt inattendu.

Sur les bases de données qui supportent l'indexation par inégalité, il est fortement recommandé de définir un index eq sur l'attribut entryCSN lors de l'utilisation de cette superposition.

CONFIGURATION

Ces options de slapd.conf s'appliquent à la superposition Sync Provider. Elles doivent apparaître après la directive overlay.

syncprov-checkpoint <ops> <minutes>
Après qu'une opération d'écriture a réussi, écrit le contextCSN dans la base de données sous-jacente si <ops> opérations d'écriture ou plus de <minutes> temps se sont écoulés depuis le dernier point de contrôle. La création de points de contrôle est désactivée par défaut.
syncprov-sessionlog <ops>
Configure un journal de session en mémoire pour enregistrer les informations sur les opérations d'écriture effectuées sur la base de données. <ops> spécifie le nombre d'opérations enregistrées dans le journal. Toutes les opérations d'écriture (sauf les Ajouts) sont enregistrées dans le journal. Lors de l'utilisation du journal de session, il est utile de définir un index eq sur l'attribut entryUUID dans la base de données sous-jacente.
syncprov-sessionlog-source <dn>
Ne doit pas être défini lorsque syncprov-sessionlog est défini et vice versa.

Lorsque accesslog pour cette base de données est configuré et enregistre à ce suffixe, il peut être utilisé comme source du journal de session au lieu du journal de session en mémoire mentionné ci-dessus. Ce journal a l'avantage de ne pas redémarrer à chaque redémarrage du serveur.

syncprov-nopresent TRUE | FALSE
Spécifie que la phase de Présentation du rafraîchissement doit être ignorée. Cette valeur ne doit être définie sur TRUE que pour une instance syncprov au-dessus d'une base de données de journal (telle que celle gérée par la superposition accesslog). La valeur par défaut est FALSE.
syncprov-reloadhint TRUE | FALSE
Spécifie que la superposition doit respecter le drapeau reloadHint dans le contrôle Sync. Il doit être défini sur TRUE lors de l'utilisation de la superposition accesslog pour le support de réplication syncrepl basé sur les delta. La valeur par défaut est FALSE.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd
