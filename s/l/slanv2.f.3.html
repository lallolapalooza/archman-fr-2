subroutine slanv2 (real a, real b, real c, real d, real rt1r, real rt1i, real rt2r, real rt2i, real cs, real sn)

SLANV2 calcule la factorisation de Schur d'une matrice réelle 2x2 non symétrique sous forme standard.

Objectif :

!>
!> SLANV2 calcule la factorisation de Schur d'une matrice réelle 2x2 non
!> symétrique sous forme standard :
!>
!>      [ A  B ] = [ CS -SN ] [ AA  BB ] [ CS  SN ]
!>      [ C  D ]   [ SN  CS ] [ CC  DD ] [-SN  CS ]
!>
!> où soit
!> 1) CC = 0 donc AA et DD sont des valeurs propres réelles de la matrice, soit
!> 2) AA = DD et BB*CC < 0, donc AA + ou - sqrt(BB*CC) sont des valeurs propres
!>    complexes conjuguées.
!>

Paramètres

A 
!>          A est REAL
!>

B

!>          B est REAL
!>

C

!>          C est REAL
!>

D

!>          D est REAL
!>          À l'entrée, les éléments de la matrice d'entrée.
!>          À la sortie, ils sont écrasés par les éléments de la
!>          forme de Schur standardisée.
!>

RT1R

!>          RT1R est REAL
!>

RT1I

!>          RT1I est REAL
!>

RT2R

!>          RT2R est REAL
!>

RT2I

!>          RT2I est REAL
!>          Les parties réelles et imaginaires des valeurs propres. Si les
!>          valeurs propres sont une paire complexe conjuguée, RT1I > 0.
!>

CS

!>          CS est REAL
!>

SN

!>          SN est REAL
!>          Paramètres de la matrice de rotation.
!>

!>  lors du calcul de valeurs propres réelles, et pour garantir, si possible, que
!>  abs(RT1R) >= abs(RT2R).
!>
