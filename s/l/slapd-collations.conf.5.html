SLAPD-COLLATIONS.CONF(5) Manuel des formats de fichiers SLAPD-COLLATIONS.CONF(5)

NOM

/etc/dirsrv/config/slapd-collations.conf - Contient les balises linguistiques et les OID utilisés dans le serveur d'annuaire 389.

SYNOPIS

/etc/dirsrv/config/slapd-collations.conf

DESCRIPTION

slapd-collations.conf

Ce fichier contient toutes les règles de collation (balises et OID) utilisées par le serveur d'annuaire.

SYNTAXE

collation
Ce paramètre est structuré comme suit : langue, pays, variante, force, décomposition, oid, oid ...

EXEMPLE

collation "" "" "" 1 3 2.16.840.1.113730.3.3.2.0.1 default
collation ar "" "" 1 3 2.16.840.1.113730.3.3.2.1.1 ar
collation be "" "" 1 3 2.16.840.1.113730.3.3.2.2.1 be be-BY
...
...
