sous-routine slalsd (character uplo, integer smlsiz, integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldb, * ) b, integer ldb, real rcond, integer rank, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLALSD utilise la décomposition en valeurs singulières de A pour résoudre le problème des moindres carrés.

Objectif :

!>
!> SLALSD utilise la décomposition en valeurs singulières de A pour résoudre
!> le problème des moindres carrés consistant à trouver X qui minimise la norme
!> euclidienne de chaque colonne de A*X-B, où A est une matrice bidiagonale
!> supérieure N x N, et X et B sont N x NRHS. La solution X écrase B.
!>
!> Les valeurs singulières de A inférieures à RCOND fois la plus grande
!> valeur singulière sont considérées comme nulles lors de la résolution du
!> problème des moindres carrés ; dans ce cas, une solution de norme minimale
!> est retournée. Les valeurs singulières réelles sont retournées dans D par
!> ordre croissant.
!>
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>         = 'U' : D et E définissent une matrice bidiagonale supérieure.
!>         = 'L' : D et E définissent une matrice bidiagonale inférieure.
!>

SMLSIZ

!>          SMLSIZ est INTEGER
!>         La taille maximale des sous-problèmes au bas de l'arbre de
!>         calcul.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice bidiagonale. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>         Le nombre de colonnes de B. NRHS doit être au moins 1.
!>

D

!>          D est un tableau REAL, dimension (N)
!>         À l'entrée, D contient la diagonale principale de la matrice
!>         bidiagonale. À la sortie, si INFO = 0, D contient ses valeurs
!>         singulières.
!>

E

!>          E est un tableau REAL, dimension (N-1)
!>         Contient les entrées super-diagonales de la matrice bidiagonale.
!>         À la sortie, E a été détruit.
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>         À l'entrée, B contient les seconds membres du problème des
!>         moindres carrés. À la sortie, B contient la solution X.
!>

LDB

!>          LDB est INTEGER
!>         La dimension principale de B dans le sous-programme appelant.
!>         LDB doit être au moins max(1,N).
!>

RCOND

!>          RCOND est REAL
!>         Les valeurs singulières de A inférieures ou égales à RCOND fois
!>         la plus grande valeur singulière sont traitées comme nulles lors
!>         de la résolution du problème des moindres carrés. Si RCOND est négatif,
!>         la précision machine est utilisée à la place.
!>         Par exemple, si diag(S)*X=B était le problème des moindres carrés,
!>         où diag(S) est une matrice diagonale de valeurs singulières, la
!>         solution serait X(i) = B(i) / S(i) si S(i) est supérieure à
!>         RCOND*max(S), et X(i) = 0 si S(i) est inférieure ou égale à
!>         RCOND*max(S).
!>

RANK

!>          RANK est INTEGER
!>         Le nombre de valeurs singulières de A supérieures à RCOND fois
!>         la plus grande valeur singulière.
!>

WORK

!>          WORK est un tableau REAL, dimension au moins
!>         (9*N + 2*N*SMLSIZ + 8*N*NLVL + N*NRHS + (SMLSIZ+1)**2),
!>         où NLVL = max(0, INT(log_2 (N/(SMLSIZ+1))) + 1).
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension au moins
!>         (3*N*NLVL + 11*N)
!>

INFO

!>          INFO est INTEGER
!>         = 0 : succès.
!>         < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>         > 0 : l'algorithme n'a pas réussi à calculer une valeur singulière
!>               lors du travail sur la sous-matrice située dans les lignes
!>               et colonnes INFO/(N+1) à MOD(INFO,N+1).
!>
