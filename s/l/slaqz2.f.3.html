sous-programme slaqz2 (logical, intent(in) ilq, logical, intent(in) ilz, integer, intent(in) k, integer, intent(in) istartm, integer, intent(in) istopm, integer, intent(in) ihi, real, dimension( lda, * ) a, integer, intent(in) lda, real, dimension( ldb, * ) b, integer, intent(in) ldb, integer, intent(in) nq, integer, intent(in) qstart, real, dimension( ldq, * ) q, integer, intent(in) ldq, integer, intent(in) nz, integer, intent(in) zstart, real, dimension( ldz, * ) z, integer, intent(in) ldz)

SLAQZ2

But:

!>
!>      SLAQZ2 poursuit une bosse de décalage 2x2 dans un pinceau de matrices vers le bas
!>      d'une seule position
!>

Paramètres

ILQ 
!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

K

!>          K est ENTIER
!>              Indice indiquant la position de la bosse.
!>              À l'entrée, la bosse est située dans
!>              (A(k+1:k+2,k:k+1),B(k+1:k+2,k:k+1)).
!>              À la sortie, la bosse est située dans
!>              (A(k+2:k+3,k+1:k+2),B(k+2:k+3,k+1:k+2)).
!>

ISTARTM

!>          ISTARTM est ENTIER
!>

ISTOPM

!>          ISTOPM est ENTIER
!>              Les mises à jour de (A,B) sont limitées à
!>              (istartm:k+3,k:istopm). Il est supposé
!>              sans vérification que istartm <= k+1 et
!>              k+2 <= istopm
!>

IHI

!>          IHI est ENTIER
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>

LDA

!>          LDA est ENTIER
!>              La dimension principale de A telle que déclarée dans
!>              la procédure appelante.
!>

B

!>          B est un tableau REEL, dimension (LDB,N)
!>

LDB

!>          LDB est ENTIER
!>              La dimension principale de B telle que déclarée dans
!>              la procédure appelante.
!>

NQ

!>          NQ est ENTIER
!>              L'ordre de la matrice Q
!>

QSTART

!>          QSTART est ENTIER
!>              Indice de début de la matrice Q. Les rotations sont appliquées
!>              aux colonnes k+2-qStart:k+4-qStart de Q.
!>

Q

!>          Q est un tableau REEL, dimension (LDQ,NQ)
!>

LDQ

!>          LDQ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>

NZ

!>          NZ est ENTIER
!>              L'ordre de la matrice Z
!>

ZSTART

!>          ZSTART est ENTIER
!>              Indice de début de la matrice Z. Les rotations sont appliquées
!>              aux colonnes k+1-qStart:k+3-qStart de Z.
!>

Z

!>          Z est un tableau REEL, dimension (LDZ,NZ)
!>

LDZ

!>          LDZ est ENTIER
!>              La dimension principale de Q telle que déclarée dans
!>              la procédure appelante.
!>
