NOM

slapo-nestgroup - Superposition pour les groupes imbriqués sur slapd

SYNOPSIS

/etc/openldap/slapd.conf

DESCRIPTION

La superposition nestgroup pour slapd(8) supporte l'évaluation des groupes imbriqués dans les opérations de recherche. Le support comprend quatre fonctionnalités possibles : l'inclusion des groupes parents lors de la recherche avec des filtres (member=), l'inclusion des groupes enfants lors de la recherche avec des filtres (memberOf=), l'expansion des groupes enfants lors du retour des attributs de membre, et l'expansion des groupes parents lors du retour des attributs memberOf. Chacune de ces fonctionnalités peut être activée indépendamment. Par défaut, aucune fonctionnalité n'est activée, donc cette superposition ne fait rien à moins d'être explicitement activée.

CONFIGURATION

Les directives de configuration spécifiques à la superposition nestgroup doivent être préfixées par nestgroup-, afin d'éviter des conflits potentiels avec les directives spécifiques à la base de données sous-jacente ou à d'autres superpositions empilées.

overlay nestgroup
Cette directive ajoute la superposition nestgroup à la base de données actuelle ; voir slapd.conf(5) pour les détails.

Les options de configuration slapd.conf suivantes sont définies pour la superposition nestgroup.

nestgroup-member <membre-ad>
La valeur <membre-ad> est le nom de l'attribut qui contient les noms des membres dans les objets groupe ; il doit être valorisé par DN. Il vaut par défaut member.
nestgroup-memberof <memberof-ad>
La valeur <memberof-ad> est le nom de l'attribut qui contient les noms des groupes dont une entrée est membre ; il doit être valorisé par DN. Il vaut par défaut memberOf.
nestgroup-base <dn>
La valeur <dn> spécifie un sous-arbre contenant les entrées de groupe dans le DIT. Il peut être spécifié plusieurs fois pour plusieurs sous-arbres distincts. Il n'a pas de valeur par défaut et la superposition ne traite rien tant qu'elle n'est pas explicitement configurée.
nestgroup-flags {filtre-membre, filtre-memberof, valeurs-membre, valeurs-memberof}
Cette option spécifie quelles fonctionnalités activer dans la superposition. Par défaut, rien n'est activé et la superposition est un no-op.

La superposition nestgroup peut être utilisée avec n'importe quel backend qui fournit une fonctionnalité de recherche standard.

FICHIERS

/etc/openldap/slapd.conf
fichier de configuration par défaut de slapd

VOIR AUSSI

slapo-dynlist(5), slapo-memberof(5), slapd.conf(5), slapd-config(5), slapd(8). La superposition slapo-nestgroup(5) supporte la configuration dynamique via back-config.
