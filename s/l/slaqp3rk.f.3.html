sous-routine slaqp3rk (integer m, integer n, integer nrhs, integer ioffset, integer nb, real abstol, real reltol, integer kp1, real maxc2nrm, real, dimension( lda, * ) a, integer lda, logical done, integer kb, real maxc2nrmk, real relmaxc2nrmk, integer, dimension( * ) jpiv, real, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, real, dimension( * ) auxv, real, dimension( ldf, * ) f, integer ldf, integer, dimension( * ) iwork, integer info)

SLAQP3RK calcule une étape de factorisation QR tronquée avec pivotement de colonne d'une matrice réelle m par n A en utilisant le niveau 3 BLAS et écrase une matrice réelle m par nrhs B avec Q**T * B.

Objectif :

!>
!> SLAQP3RK calcule une étape de factorisation QR tronquée avec pivotement de colonne
!> de la matrice réelle M par N, A, bloc A(IOFFSET+1:M,1:N)
!> en utilisant le niveau 3 BLAS comme suit :
!>
!>   A * P(KB) = Q(KB) * R(KB).
!>
!> La sous-routine tente de factoriser NB colonnes de A à partir de
!> la ligne IOFFSET+1 et met à jour la matrice résiduelle avec BLAS 3
!> xGEMM. Le nombre de colonnes réellement factorisées est retourné
!> comme étant inférieur à NB.
!>
!> Le bloc A(1:IOFFSET,1:N) est pivoté en conséquence, mais pas factorisé.
!>
!> La sous-routine écrase également la matrice des seconds membres B stockée
!> dans A(IOFFSET+1:M,1:N+1:N+NRHS) avec Q(KB)**T * B.
!>
!> Cas où le nombre de colonnes factorisées KB < NB :
!>
!> (1) Dans certains cas, en raison d'annulations catastrophiques, elle ne peut pas
!> factoriser toutes les NB colonnes et doit mettre à jour la matrice résiduelle.
!> Par conséquent, le nombre réel de colonnes factorisées dans le bloc retourné
!> en KB est inférieur à NB. La variable logique DONE est retournée comme FAUX.
!> La factorisation de la matrice originale complète A_orig doit se poursuivre
!> avec le bloc suivant.
!>
!> (2) Chaque fois que le critère d'arrêt ABSTOL ou RELTOL est satisfait,
!> la factorisation de la matrice originale complète A_orig est arrêtée,
!> la variable logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées
!> qui est inférieur à NB est retourné dans KB.
!>
!> (3) Si les deux critères d'arrêt ABSTOL ou RELTOL ne sont pas utilisés,
!> et lorsque la matrice résiduelle est une matrice nulle dans une étape de factorisation
!> KB, la factorisation de la matrice originale complète A_orig est arrêtée,
!> la variable logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées
!> qui est inférieur à NB est retourné dans KB.
!>
!> (4) Chaque fois qu'une valeur NaN est détectée dans la matrice A ou dans le tableau TAU,
!> la factorisation de la matrice originale complète A_orig est arrêtée,
!> la variable logique DONE est retournée comme VRAI. Le nombre de colonnes factorisées
!> qui est inférieur à NB est retourné dans KB. Le paramètre INFO est défini à l'indice de colonne
!> de la première occurrence de NaN.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes de la matrice B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET est INTEGER
!>          Le nombre de lignes de la matrice A qui doivent être pivotées
!>          mais non factorisées. IOFFSET >= 0.
!>
!>          IOFFSET représente également le nombre de colonnes de la matrice
!>          originale complète A_orig qui ont été factorisées
!>          dans les étapes précédentes.
!>

NB

!>          NB est INTEGER
!>          Taille du bloc de factorisation, c'est-à-dire le nombre de colonnes
!>          à factoriser dans la matrice A. 0 <= NB
!>
!>          Si NB = 0, la sous-routine se termine immédiatement.
!>             Cela signifie que la factorisation n'est pas effectuée,
!>             les matrices A et B et les tableaux TAU, IPIV
!>             ne sont pas modifiés.
!>

ABSTOL

!>          ABSTOL est REAL, ne peut pas être NaN.
!>
!>          La tolérance absolue (seuil d'arrêt) pour
!>          la norme 2 maximale des colonnes de la matrice résiduelle.
!>          L'algorithme converge (arrête la factorisation) lorsque
!>          la norme 2 maximale des colonnes de la matrice résiduelle
!>          est inférieure ou égale à ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la sous-routine factorise les colonnes en fonction
!>                de NB et RELTOL.
!>                Ceci inclut le cas ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL, alors la valeur d'entrée
!>                de ABSTOL est utilisée.
!>

RELTOL

!>          RELTOL est REAL, ne peut pas être NaN.
!>
!>          La tolérance (seuil d'arrêt) pour le rapport de la
!>          norme 2 maximale des colonnes de la matrice résiduelle à la
!>          norme 2 maximale des colonnes de la matrice originale A_orig.
!>          L'algorithme converge (arrête la factorisation), lorsque ce rapport est
!>          inférieur ou égal à RELTOL.
!>
!>          a) Si RELTOL < 0.0, alors ce critère d'arrêt n'est pas
!>                utilisé, la sous-routine factorise les colonnes en fonction
!>                de NB et ABSTOL.
!>                Ceci inclut le cas RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL, alors la valeur d'entrée de RELTOL
!>                est utilisée.
!>

KP1

!>          KP1 est INTEGER
!>          L'indice de la colonne avec la norme 2 maximale dans
!>          la matrice originale complète A_orig déterminé dans
!>          la sous-routine principale SGEQP3RK. 1 <= KP1 <= N_orig.
!>

MAXC2NRM

!>          MAXC2NRM est REAL
!>          La norme 2 maximale des colonnes de la matrice originale
!>          complète A_orig calculée dans la sous-routine principale SGEQP3RK.
!>          MAXC2NRM >= 0.
!>

A

!>          A est un tableau de REAL, dimension (LDA,N+NRHS)
!>          À l'entrée :
!>              la matrice A de taille M par N et la matrice B de taille M par NRHS, comme dans
!>
!>                                  N     NRHS
!>              tableau_A   =   M  [ mat_A, mat_B ]
!>
!>          À la sortie :
!>          1. Les éléments du bloc A(IOFFSET+1:M,1:KB) sous
!>             la diagonale représentent, avec le tableau TAU,
!>             la matrice orthogonale Q(KB) comme un produit de réflexions élémentaires.
!>          2. Le bloc triangulaire supérieur de la matrice A stocké
!>             dans A(IOFFSET+1:M,1:KB) est le facteur triangulaire obtenu.
!>          3. Le bloc de la matrice A stocké dans A(1:IOFFSET,1:N)
!>             a été pivoté en conséquence, mais pas factorisé.
!>          4. Le reste du tableau A, bloc A(IOFFSET+1:M,KB+1:N+NRHS).
!>             La partie gauche A(IOFFSET+1:M,KB+1:N) de ce bloc
!>             contient le résidu de la matrice A, et,
!>             si NRHS > 0, la partie droite du bloc
!>             A(IOFFSET+1:M,N+1:N+NRHS) contient le bloc de
!>             la matrice des seconds membres B. Ces deux blocs ont été
!>             mis à jour par multiplication par la gauche par Q(KB)**T.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

DONE

!>          DONE

NAME

The slaqp3rk subroutine advances the partial Schur decomposition of a real matrix A.

SYNOPSIS

SUBROUTINE SLAQP3RK(
     UPLO, N, NB, NRHS, A, LDA, AF, LDAF, Q, LDQ, R, LDR, JPVT,
     VN1, VN2, AUXV, F, LDF, TAU, WORK, LWORK, SWORK, LSWORK,
     KB, RCOND, INFO )

CHARACTER * 1 UPLO

INTEGER N, NB, NRHS, LDA, LDAF, LDQ, LDR, LDF, LWORK, LSWORK, KB, INFO

REAL A( LDA, * ), AF( LDAF, * ), Q( LDQ, * ), R( LDR, * ), VN1( * ), VN2( * ), AUXV( * ), F( LDF, * ), TAU( * ), WORK( * ), RCOND

INTEGER JPVT( * )

CHARACTER * 1 SWORK( * )

Function/Subroutine Documentation

UPLO

    UPLO is CHARACTER*1
    = 'U': Upper triangle of A is stored;
    = 'L': Lower triangle of A is stored.

N

    N is INTEGER
    The number of columns of the matrix A. N >= 0.

NB

    NB is INTEGER
    The block size to be used in the outermost block
    cyclic decomposition. NB >= 1.

NRHS

    NRHS is INTEGER
    The number of right hand sides, i.e., the number of columns of
    the matrix B if we are solving A*X = B.  NRHS >= 0.

A

    A is REAL array, dimension (LDA,N)
    On entry, the M-by-N matrix A.
    On exit:
    If UPLO = 'U', A contains the upper triangular matrix R.
    If UPLO = 'L', A contains the lower triangular matrix R.

LDA

    LDA is INTEGER
    The leading dimension of the array A. LDA >= max(1,N).

AF

    AF is REAL array, dimension (LDAF,N)
    On entry, the elements of AF must contain the elements of A.
    On exit, AF is overwritten with the results of the factorization.

LDAF

    LDAF is INTEGER
    The leading dimension of the array AF. LDAF >= max(1,N).

Q

    Q is REAL array, dimension (LDQ,N)
    On exit, Q contains the orthogonal matrix Q, such that A = Q*R.

LDQ

    LDQ is INTEGER
    The leading dimension of the array Q. LDQ >= max(1,N).

R

    R is REAL array, dimension (LDR,N)
    On exit, R contains the upper triangular factor of A.

LDR

    LDR is INTEGER
    The leading dimension of the array R. LDR >= max(1,N).

JPVT

    JPVT is INTEGER array, dimension (N)
    On entry, JPVT contains the pivot indices in the previous stage
    of the factorization.
    On exit, JPVT contains the pivot indices of the current
    factorization.

VN1

    VN1 is REAL array, dimension (N)
    On exit, VN1 contains the partial column norms.

VN2

    VN2 is REAL array, dimension (N)
    On exit, VN2 contains the exact column norms.

AUXV

    AUXV is REAL array, dimension (NB)
    Auxiliary vector.

F

    F is REAL array, dimension (LDF,NB)
    Matrix F**T = L*(Y**T)*A.

LDF

    LDF is INTEGER
    The leading dimension of the array F. LDF >= max(1,N+NRHS).

TAU

    TAU is REAL array, dimension (min(M,N))
    On exit, TAU contains the scalar factors of the elementary
    reflectors.

WORK

    WORK is REAL array, dimension (LWORK)
    On exit, WORK(1) contains the optimal LWORK.

LWORK

    LWORK is INTEGER
    The dimension of the array WORK. LWORK >= 1.
    For optimum performance, LWORK must be at least max(2*N, N + NB).

SWORK

    SWORK is CHARACTER*1 array, dimension (LSWORK)
    Auxiliary character array.

LSWORK

    LSWORK is INTEGER
    The dimension of the array SWORK. LSWORK >= N.

KB

    KB is INTEGER
    The number of columns of A that have been factorized.

RCOND

    RCOND is REAL
    On exit, RCOND is a lower bound on the reciprocal of the
    condition number of the matrix A. This is an upper bound on
    1/cond(A).

INFO

    INFO is INTEGER
    = 0: successful exit.
    < 0: If INFO = -i, the i-th argument had an illegal value.
    > 0: If INFO = i, the algorithm cannot achieve high precision.
         The factorization has been completed, but the computed
         rank may be different from the actual rank. KB is the
         effective rank.
