sous-routine slarrr (integer n, real, dimension( * ) d, real, dimension( * ) e, integer info)

SLARRR effectue des tests pour décider si la matrice tridiagonale symétrique T justifie des calculs coûteux qui garantissent une grande précision relative dans les valeurs propres.

Objectif :

!>
!> Effectuer des tests pour décider si la matrice tridiagonale symétrique
!> T justifie des calculs coûteux qui garantissent une grande précision relative
!> dans les valeurs propres.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice. N > 0.
!>

D

!>          D est un tableau REEL, de dimension (N)
!>          Les N éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau REEL, de dimension (N)
!>          À l'entrée, les (N-1) premières entrées contiennent les éléments
!>          sous-diagonaux de la matrice tridiagonale T ; E(N) est mis à ZÉRO.
!>

INFO

!>          INFO est un ENTIER
!>          INFO = 0 (par défaut) : la matrice justifie des calculs préservant
!>                                  la précision relative.
!>          INFO = 1           : la matrice justifie des calculs ne garantissant
!>                                  que la précision absolue.
!>
