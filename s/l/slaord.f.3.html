sous-routine slaord (character job, integer n, real, dimension( * ) x, integer incx)

SLAORD

Objectif:

!>
!> SLAORD trie les éléments d'un vecteur x dans l'ordre croissant ou décroissant.
!>

Paramètres

JOB 
!>          JOB est CHARACTER
!>          = 'I':  Trier dans l'ordre croissant
!>          = 'D':  Trier dans l'ordre décroissant
!>

N

!>          N est INTEGER
!>          La longueur du vecteur X.
!>

X

!>          X est un tableau REAL, dimension
!>                         (1+(N-1)*INCX)
!>          À l'entrée, le vecteur de longueur n à trier.
!>          À la sortie, le vecteur x est trié dans l'ordre prescrit.
!>

INCX

!>          INCX est INTEGER
!>          L'espacement entre les éléments successifs de X. INCX >= 0.
!>
