Documentation de la fonction/sous-routine

sous-routine slaein (logical rightv, logical noinit, integer n, real, dimension( ldh, * ) h, integer ldh, real wr, real wi, real, dimension( * ) vr, real, dimension( * ) vi, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, real eps3, real smlnum, real bignum, integer info)

SLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

Objectif :

!>
!> SLAEIN utilise l'itération inverse pour trouver un vecteur propre droit ou gauche
!> correspondant à la valeur propre (WR,WI) d'une matrice H de Hessenberg supérieure
!> réelle.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGIQUE
!>          = .TRUE. : calculer le vecteur propre droit ;
!>          = .FALSE.: calculer le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGIQUE
!>          = .TRUE. : aucun vecteur initial fourni dans (VR,VI).
!>          = .FALSE.: vecteur initial fourni dans (VR,VI).
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau REEL, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

WR

!>          WR est un REEL
!>

WI

!>          WI est un REEL
!>          Les parties réelle et imaginaire de la valeur propre de H dont
!>          le vecteur propre droit ou gauche correspondant doit être calculé.
!>

VR

!>          VR est un tableau REEL, dimension (N)
!>

VI

!>          VI est un tableau REEL, dimension (N)
!>          À l'entrée, si NOINIT = .FALSE. et WI = 0.0, VR doit contenir
!>          un vecteur de départ réel pour l'itération inverse utilisant la valeur propre
!>          réelle WR ; si NOINIT = .FALSE. et WI.ne.0.0, VR et VI doivent contenir
!>          les parties réelle et imaginaire d'un vecteur de départ complexe
!>          pour l'itération inverse utilisant la valeur propre complexe (WR,WI) ;
!>          sinon, VR et VI n'ont pas besoin d'être définis.
!>          À la sortie, si WI = 0.0 (valeur propre réelle), VR contient le
!>          vecteur propre réel calculé ; si WI.ne.0.0 (valeur propre complexe),
!>          VR et VI contiennent les parties réelle et imaginaire du vecteur
!>          propre complexe calculé. Le vecteur propre est normalisé de telle sorte
!>          que le composant de magnitude la plus grande ait une magnitude de 1 ;
!>          ici, la magnitude d'un nombre complexe (x,y) est considérée comme
!>          |x| + |y|.
!>          VI n'est pas référencé si WI = 0.0.
!>

B

!>          B est un tableau REEL, dimension (LDB,N)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= N+1.
!>

WORK

!>          WORK est un tableau REEL, dimension (N)
!>

EPS3

!>          EPS3 est un REEL
!>          Une petite valeur dépendant de la machine qui est utilisée pour perturber
!>          les valeurs propres proches, et pour remplacer les pivots nuls.
!>

SMLNUM

!>          SMLNUM est un REEL
!>          Une valeur dépendant de la machine proche du seuil de sous-dépassement.
!>

BIGNUM

!>          BIGNUM est un REEL
!>          Une valeur dépendant de la machine proche du seuil de dépassement de capacité.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          = 1 : l'itération inverse n'a pas convergé ; VR est défini sur la
!>                dernière itération, et VI aussi si WI.ne.0.0.
!>
