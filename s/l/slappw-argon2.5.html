NOM

slappw-argon2 - Module de mot de passe Argon2 pour slapd

SYNOPSIS

/etc/openldap/slapd.conf

moduleload argon2 [<paramètres>]

DESCRIPTION

Le module argon2 pour slapd(8) fournit la prise en charge de la fonction de dérivation de clé Argon2, qui a été sélectionnée comme lauréate du concours de hachage de mots de passe en juillet 2015, dans les mots de passe hachés dans OpenLDAP.

Il le fait en fournissant le schéma de mot de passe supplémentaire {ARGON2} à utiliser dans slapd.

CONFIGURATION

Le module argon2 ne nécessite aucune configuration, mais il peut être configuré en donnant les paramètres suivants :

m=<mémoire>
Définit l'utilisation de la mémoire à <mémoire> KiB.
p=<parallélisme>
Définit le parallélisme à <parallélisme> threads. Actuellement pris en charge uniquement lorsqu'il est lié avec libargon2.
t=<itérations>
Définit le nombre d'itérations à <itérations>.

Ceux-ci remplacent les valeurs par défaut lors de la préparation des hachages pour les nouveaux mots de passe lorsque cela est possible.

Après avoir chargé le module, le schéma de mot de passe {ARGON2} sera reconnu dans les valeurs de l'attribut userPassword.

Vous pouvez ensuite indiquer à OpenLDAP d'utiliser ce schéma lors du traitement des opérations étendues de modification de mot de passe LDAPv3 (RFC 3062) en utilisant l'option password-hash dans slapd.conf(5) :

password-hash {ARGON2}

NOTES

Si vous souhaitez utiliser le schéma décrit ici avec slappasswd(8), n'oubliez pas de charger le module en utilisant ses options de ligne de commande. L'option/valeur pertinente est :

-o module-load=argon2

Ou si des paramètres non par défaut sont requis :

-o module-load="argon2 [<param>...]"

Selon l'emplacement d'argon2, vous pourriez également avoir besoin de :

-o module-path=spécification_chemin

EXEMPLES

Les deux attributs userPassword LDAP ci-dessous encodent le mot de passe 'secret' en utilisant différents sels :

userPassword: {ARGON2}$argon2i$v=19$m=4096,t=3,p=1$c2FsdHNhbHQ$DKlexoEJUoZTmkAAC3SaMWk30El9/RvVhlqGo6afIng
userPassword: {ARGON2}$argon2i$v=19$m=4096,t=3,p=1$c2FsdHNhbHRzYWx0$qOCkx9nMeFlaGOO4DUmPDgrlUbgMMuO9T1+vQCFuyzw
