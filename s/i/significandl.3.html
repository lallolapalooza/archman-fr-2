significand(3) Manuel des fonctions de bibliothèque significand(3)

NOM

significand, significandf, significandl - obtenir la mantisse d'un nombre à virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double significand(double x);
float significandf(float x);
long double significandl(long double x);
Conditions requises pour les macros de test de fonctionnalité sur glibc (voir feature_test_macros(7)) :

significand(), significandf(), significandl() :

    /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent la mantisse de x mise à l'échelle dans l'intervalle [1, FLT_RADIX). Elles sont équivalentes à


scalb(x, (double) -ilogb(x))

Cette fonction existe principalement pour être utilisée dans certains tests standardisés de conformité IEEE 754.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
significand (), significandf (), significandl () Sécurité des threads MT-Safe

NORMES

Aucune.
