NOM

sieve-dump - Outil de vidage binaire Sieve de Pigeonhole

SYNOPIS

sieve-dump [options] fichier-binaire-sieve [fichier-sortie]

DESCRIPTION


La commande fait partie de Pigeonhole (pigeonhole(7)), qui ajoute la prise en charge de Sieve (RFC 5228) et ManageSieve (RFC 5804) à Dovecot (dovecot(1)).


La commande, les fichiers binaires Sieve, qui sont produits par exemple par sievec(1), peuvent être transformés en une représentation textuelle lisible par l'homme. Cela peut fournir un aperçu précieux de la manière dont le script Sieve est exécuté. Ceci est également particulièrement utile pour visualiser des fichiers binaires corrompus qui peuvent résulter de bogues dans l'implémentation Sieve. Cet outil est principalement destiné à des fins de développement, donc normalement les administrateurs système et les utilisateurs n'auront pas besoin d'utiliser cet outil.

Le format de la sortie n'est pas expliqué ici en détail, mais il devrait être relativement facile à comprendre. Les fichiers binaires Sieve comprennent un ensemble de blocs de données, chacun pouvant contenir des données arbitraires. Pour l'implémentation du langage de base, deux blocs sont utilisés : le premier contenant une spécification de toutes les extensions de langage requises et le second contenant le programme Sieve principal. Les programmes Sieve compilés sont représentés sous forme de code machine plat, et donc le vidage du programme principal est une liste de désassemblage des opérations de l'interpréteur. Les extensions peuvent définir de nouvelles opérations et utiliser des blocs supplémentaires. Par conséquent, la sortie de sieve-dump dépend fortement des extensions de langage utilisées lors de la compilation du fichier binaire.

OPTIONS

-c fichier-config

Chemin alternatif du fichier de configuration Dovecot.

-D

Activer le débogage Sieve.

-h

Produire une sortie hexdump par bloc de l'ensemble du fichier binaire au lieu de la sortie lisible normale.

-o parametre=valeur

Remplace le parametre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les jokers '*' et '?' (par exemple -u *@example.org).

-x infos-authentification

infos-authentification spécifie des conditions supplémentaires pour la commande user. La chaîne d'option infos-authentification doit être donnée sous la forme d'une paire nom = valeur. Pour plusieurs conditions, l'option -x peut être fournie plusieurs fois.

Les noms possibles pour infos-authentification sont :

service

Le service pour lequel la recherche userdb doit être testée. La valeur peut être le nom d'un service, couramment utilisé avec Dovecot. Par exemple : imap, pop3 ou smtp.

session

Identifiant de session.

lip

L'adresse IP locale (serveur) pour le test.

rip

L'adresse IP distante (client) pour le test.

lport

Le port local, par exemple 143

rport

Le port distant, par exemple 24567

real_lip

L'adresse IP locale à laquelle le client s'est connecté sur cet hôte.

real_rip

L'adresse IP distante d'où le client s'est connecté à cet hôte.

real_lport

Le port local auquel le client s'est connecté à cet hôte.

real_rport

Le port distant d'où le client s'est connecté à cet hôte.

forward_<champ>

Champ à transférer comme %{forward:champ} au processus d'authentification.

ARGUMENTS

fichier-binaire-sieve

Spécifie le fichier binaire Sieve qui doit être vidangé.

fichier-sortie

Spécifie où la sortie doit être écrite. Cet argument est facultatif. S'il est omis, la sortie est écrite sur stdout.

STATUT DE SORTIE

sieve-dump se terminera avec l'une des valeurs suivantes :

0

Le vidage a réussi. (EX_OK, EXIT_SUCCESS)

1

L'opération a échoué. Ceci est renvoyé pour presque tous les échecs. (EXIT_FAILURE)

64

Paramètre invalide fourni. (EX_USAGE)

FICHIERS

/etc/dovecot/dovecot.conf

Fichier de configuration principal de Dovecot.

/etc/dovecot/conf.d/90-sieve.conf

Paramètres de l'interpréteur Sieve (inclus depuis le fichier de configuration principal de Dovecot).

SIGNALEMENT DE BOGUES

Signalez les bogues, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement de bogues sont disponibles sur : https://dovecot.org/bugreport.html
