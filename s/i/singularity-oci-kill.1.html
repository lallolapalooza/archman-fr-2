NOM

apptainer-oci-kill - Tuer un conteneur (uniquement pour l'utilisateur root)

SYNTAXE

apptainer oci kill [options de kill...]

DESCRIPTION

Tuer invoque l'opération de mise à mort pour tuer les processus en cours d'exécution dans le conteneur
identifié par l'ID du conteneur.

OPTIONS

-f, --force[=false] tuer le processus du conteneur avec SIGKILL

-h, --help[=false] aide pour kill

-s, --signal="SIGTERM" signal envoyé au conteneur

-t, --timeout=0 délai en secondes avant de tuer le conteneur

EXEMPLE

  $ apptainer oci kill mycontainer INT
  $ apptainer oci kill mycontainer -s INT
