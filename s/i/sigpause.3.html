sigpause(3) Manuel des fonctions de bibliothèque sigpause(3)

NOM

sigpause - libérer atomiquement les signaux bloqués et attendre une interruption

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <signal.h>
[[deprecated]] int sigpause(int sigmask);  /* BSD (mais voir VERSIONS) */
[[deprecated]] int sigpause(int sig);      /* POSIX.1 / SysV / UNIX 95 */

DESCRIPTION

N'utilisez pas cette fonction. Utilisez sigsuspend(2) à la place.

La fonction sigpause() est conçue pour attendre un signal. Elle modifie le masque de signaux du processus (ensemble des signaux bloqués), puis attend l'arrivée d'un signal. Lors de l'arrivée d'un signal, le masque de signaux d'origine est restauré.

VALEUR DE RETOUR

Si sigpause() retourne, elle a été interrompue par un signal et la valeur de retour est -1 avec errno défini à EINTR.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sigpause () Thread safety MT-Safe

VERSIONS

Sur Linux, cette routine n'est un appel système que sur l'architecture Sparc (sparc64).

glibc utilise la version BSD si le macro de test de fonctionnalités _BSD_SOURCE est défini et qu'aucun des macros _POSIX_SOURCE, _POSIX_C_SOURCE, _XOPEN_SOURCE, _GNU_SOURCE, ou _SVID_SOURCE n'est défini. Sinon, la version System V est utilisée, et les macros de test de fonctionnalités doivent être définis comme suit pour obtenir la déclaration :

•
Depuis glibc 2.26 : _XOPEN_SOURCE >= 500
•
glibc 2.25 et antérieures : _XOPEN_SOURCE

Depuis glibc 2.19, seule la version System V est exposée par <signal.h> ; les applications qui utilisaient auparavant la version BSD de sigpause() devraient être modifiées pour utiliser sigsuspend(2).

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001. Obsolète dans POSIX.1-2008.

La version classique de BSD de cette fonction est apparue dans 4.2BSD. Elle définit le masque de signaux du processus à sigmask. UNIX 95 a standardisé la version incompatible de System V de cette fonction, qui retire seulement le signal spécifié sig du masque de signaux du processus. La situation malheureuse avec deux fonctions incompatibles portant le même nom a été résolue par la fonction sigsuspend(2), qui prend un argument sigset_t * (au lieu d'un int).

VOIR AUSSI

kill(2), sigaction(2), sigprocmask(2), sigsuspend(2), sigblock(3), sigvec(3), feature_test_macros(7)
