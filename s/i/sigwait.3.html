sigwait(3) Manuel des fonctions de bibliothèque sigwait(3)

NOM

sigwait - attendre un signal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <signal.h>
int sigwait(const sigset_t *restrict set, int *restrict sig);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

sigwait() :

    Depuis glibc 2.26 :
        _POSIX_C_SOURCE >= 199506L
    glibc 2.25 et versions antérieures :
        _POSIX_C_SOURCE

DESCRIPTION

La fonction sigwait() suspend l'exécution du thread appelant jusqu'à ce que l'un des signaux spécifiés dans l'ensemble de signaux set devienne en attente. Pour qu'un signal devienne en attente, il doit d'abord être bloqué avec sigprocmask(2). La fonction accepte le signal (le retire de la liste des signaux en attente) et renvoie le numéro du signal dans sig.

Le fonctionnement de sigwait() est identique à celui de sigwaitinfo(2), sauf que :

•
sigwait() ne renvoie que le numéro du signal, plutôt qu'une structure siginfo_t décrivant le signal.
•
Les valeurs de retour des deux fonctions sont différentes.

VALEUR DE RETOUR

En cas de succès, sigwait() renvoie 0. En cas d'erreur, elle renvoie un numéro d'erreur positif (listé dans ERREURS).

ERREURS

EINVAL
set contient un numéro de signal invalide.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sigwait () Sécurité des threads MT-Safe

VERSIONS

sigwait() est implémentée en utilisant sigtimedwait(2) ; consultez sa section NOTES.

L'implémentation glibc de sigwait() ignore silencieusement les tentatives d'attente des deux signaux temps réel utilisés en interne par l'implémentation de threads NPTL. Voir nptl(7) pour plus de détails.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

EXEMPLES

Voir pthread_sigmask(3).

VOIR AUSSI

sigaction(2), signalfd(2), sigpending(2), sigsuspend(2), sigwaitinfo(2), sigsetops(3), signal(7)
