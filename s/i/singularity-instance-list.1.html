NOM

apptainer-instance-list - Lister toutes les instances Apptainer en cours d'exécution et nommées

SYNTAXE

apptainer instance list [options de liste...] []

DESCRIPTION

La commande `instance list` vous permet de visualiser les conteneurs Apptainer
instances qui sont actuellement en cours d'exécution en arrière-plan.

OPTIONS

-a, --all[=false] afficher toutes les instances (inclure les instances --sharens)

-h, --help[=false] aide pour la liste

-j, --json[=false] afficher un JSON structuré au lieu d'une liste

-l, --logs[=false] afficher l'emplacement des fichiers journaux stdout et stderr pour les instances

-u, --user="" si exécuté en tant que root, lister les instances de ""

EXEMPLE

  $ apptainer instance list
  NOM DE L'INSTANCE      PID       IMAGE
  test               11963     /home/mibauer/apptainer/sinstance/test.sif
  test2              11964     /home/mibauer/apptainer/sinstance/test.sif
  lolcow             11965     /home/mibauer/apptainer/sinstance/lolcow.sif
  $ apptainer instance list 'test*'
  NOM DE L'INSTANCE      PID       IMAGE
  test               11963     /home/mibauer/apptainer/sinstance/test.sif
  test2              11964     /home/mibauer/apptainer/sinstance/test.sif
  $ sudo apptainer instance list -u mibauer
  NOM DE L'INSTANCE      PID       IMAGE
  test               11963     /home/mibauer/apptainer/sinstance/test.sif
  test2              16219     /home/mibauer/apptainer/sinstance/test.sif
