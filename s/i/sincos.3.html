sincos(3) Manuel des fonctions de bibliothèque sincos(3)

NOM

sincos, sincosf, sincosl — calculer le sinus et le cosinus simultanément

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNOPSIS

#define _GNU_SOURCE         /* voir feature_test_macros(7) */
#include <math.h>
void sincos(double x, double *sin, double *cos);
void sincosf(float x, float *sin, float *cos);
void sincosl(long double x, long double *sin, long double *cos);

DESCRIPTION

Plusieurs applications ont besoin du sinus et du cosinus du même angle x. Ces fonctions calculent les deux en même temps et stockent les résultats dans *sin et *cos. L'utilisation de cette fonction peut être plus efficace que deux appels séparés à sin(3) et cos(3).

Si x est un NaN, un NaN est retourné dans *sin et *cos.

Si x est l'infini positif ou l'infini négatif, une erreur de domaine se produit et un NaN est retourné dans *sin et *cos.

VALEUR DE RETOUR

Ces fonctions retournent void.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est un infini
errno est défini à EDOM (mais voir BUGS). Une exception flottante invalide (FE_INVALID) est levée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sincos (), sincosf (), sincosl () Sécurité des threads MT-Safe

NORMES

GNU.

HISTORIQUE

glibc 2.1.

NOTES

Pour constater l'avantage en performance de sincos(), il peut être nécessaire de désactiver les optimisations intégrées de gcc(1), en utilisant des indicateurs tels que :


cc -O -lm -fno-builtin prog.c

BUGS

Avant glibc 2.22, l'implémentation glibc ne définissait pas errno à EDOM lorsqu'une erreur de domaine se produisait.

VOIR AUSSI

cos(3), sin(3), tan(3)
