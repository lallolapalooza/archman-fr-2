sigsuspend(2) Manuel des appels système sigsuspend(2)

NOM

sigsuspend, rt_sigsuspend - attendre un signal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <signal.h>
int sigsuspend(const sigset_t *mask);
Exigences de macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

sigsuspend():

    _POSIX_C_SOURCE

DESCRIPTION

sigsuspend() remplace temporairement le masque de signaux du fil d'exécution appelant par le masque donné par mask, puis suspend le fil d'exécution jusqu'à la livraison d'un signal dont l'action est d'invoquer un gestionnaire de signaux ou de terminer un processus.

Si le signal termine le processus, alors sigsuspend() ne revient pas. Si le signal est intercepté, alors sigsuspend() revient après le retour du gestionnaire de signaux, et le masque de signaux est restauré à l'état d'avant l'appel à sigsuspend().

Il n'est pas possible de bloquer SIGKILL ou SIGSTOP ; spécifier ces signaux dans mask n'a aucun effet sur le masque de signaux du fil d'exécution.

VALEUR DE RETOUR

sigsuspend() retourne toujours -1, avec errno défini pour indiquer l'erreur (normalement, EINTR).

ERREURS

EFAULT
mask pointe vers une mémoire qui ne fait pas partie de l'espace d'adressage valide du processus.
EINTR
L'appel a été interrompu par un signal ; signal(7).

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

DIFFÉRENCES BIBLIOTHÈQUE C/NOYAU

L'appel système Linux original s'appelait sigsuspend(). Cependant, avec l'ajout des signaux temps réel dans Linux 2.2, le type sigset_t de taille fixe, 32 bits, supporté par cet appel système n'était plus adapté. Par conséquent, un nouvel appel système, rt_sigsuspend(), a été ajouté pour supporter un type sigset_t agrandi. Le nouvel appel système prend un deuxième argument, size_t sigsetsize, qui spécifie la taille en octets de l'ensemble de signaux dans mask. Cet argument doit actuellement avoir la valeur sizeof(sigset_t) (sinon l'erreur EINVAL résulte). La fonction wrapper sigsuspend() de glibc nous cache ces détails, appelant transparenment rt_sigsuspend() lorsque le noyau le fournit.

NOTES

Normalement, sigsuspend() est utilisé en conjonction avec sigprocmask(2) afin d'empêcher la livraison d'un signal pendant l'exécution d'une section de code critique. L'appelant bloque d'abord les signaux avec sigprocmask(2). Lorsque le code critique est terminé, l'appelant attend alors les signaux en appelant sigsuspend() avec le masque de signaux qui a été retourné par sigprocmask(2) (dans l'argument oldset).

Voir sigsetops(3) pour les détails sur la manipulation des ensembles de signaux.

VOIR AUSSI

kill(2), pause(2), sigaction(2), signal(2), sigprocmask(2), sigwaitinfo(2), sigsetops(3), sigwait(3), signal(7)
