NOM

simple-scan - Utilitaire de numérisation

SYNTAXE

simple-scan [PÉRIPHÉRIQUE]

DESCRIPTION

Cette page de manuel documente brièvement la commande simple-scan.

Scanner de documents est une application facile à utiliser, conçue pour permettre aux utilisateurs de connecter leur scanner et d'obtenir rapidement l'image/le document dans un format approprié.

Scanner de documents a été écrit avec les bibliothèques GTK+, et après avoir installé l'application, vous pouvez la lancer depuis le menu Applications.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous. Pour une description complète, consultez les fichiers Info.

-d, --debug
Affiche les messages de débogage.
-v, --version
Affiche la version de publication.
-?, --help
Affiche les options d'aide.
--help-all
Affiche toutes les options d'aide.
-d, --help-gtk
Affiche les options GTK+.
