NOM

apptainer-checkpoint-create - Crée un stockage de points de contrôle vide (expérimental)

SYNTAXE

apptainer checkpoint create

DESCRIPTION

La commande checkpoint create initialise un emplacement pour stocker les données de point de contrôle une fois qu'un conteneur est utilisé.

OPTIONS

-h, --help[=false] aide pour create

EXEMPLE

  Pour créer un point de contrôle initialement vide :
  $ apptainer checkpoint create example-checkpoint
