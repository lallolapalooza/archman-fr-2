NOM

sigtool - outil de gestion des signatures et des bases de données

SYNTAXE

sigtool [options]

DESCRIPTION

sigtool peut être utilisé pour générer des sommes de contrôle MD5, convertir des données au format hexadécimal, lister les signatures de virus et construire/décompresser/tester/vérifier des bases de données CVD et des scripts de mise à jour.

OPTIONS COMMUNES

-h, --help
Afficher les informations d'aide et quitter.
-V, --version
Afficher le numéro de version et quitter.
--quiet
Être silencieux, n'afficher que les messages d'erreur.
--debug
Activer les messages de débogage.
--stdout
Écrire tous les messages sur stdout.
--tempdir=DIRECTORY
Créer des fichiers temporaires dans DIRECTORY. Le répertoire doit être accessible en écriture par l'utilisateur exécutant sigtool.
--leave-temps
Ne pas supprimer les fichiers temporaires.
--datadir=DIR
Utiliser DIR comme répertoire de base de données par défaut pour toutes les opérations.

COMMANDES POUR TRAVAILLER AVEC LES SIGNATURES

-l[FILE], --list-sigs[=FILE]
Lister tous les noms de signatures de la base de données locale (par défaut) ou de FILE.
-fREGEX, --find-sigs=REGEX
Trouver et afficher les signatures de la base de données locale qui correspondent à REGEX. Le corps entier de la signature (nom, chaîne hexadécimale, etc.) est vérifié.
--decode-sigs=REGEX
Décoder les signatures lues depuis l'entrée standard (par exemple, via un pipe depuis --find-sigs)
--test-sigs=DATABASE TARGET_FILE
Tester toutes les signatures de DATABASE contre TARGET_FILE. Cette option ne donnera des résultats valides que si le fichier cible est le fichier final (après décompression, normalisation, etc.) pour lequel les signatures ont été créées.

COMMANDES POUR GENERER DES SIGNATURES

--md5 [FILES]
Générer une somme de contrôle MD5 depuis stdin ou des signatures MD5 pour FILES.
--sha1 [FILES]
Générer une somme de contrôle SHA1 depuis stdin ou des signatures SHA1 pour FILES.
--sha2-256 [FILES]
Générer une somme de contrôle SHA2-256 depuis stdin ou des signatures SHA2-256 pour FILES. L'option précédente --sha256 est obsolète et pourra être supprimée dans une future version.
--mdb [FILES]
Générer des signatures .mdb (hash de section PE) pour FILES.
--imp [FILES]
Générer des signatures .imp (hash d'adresse d'importation PE) pour FILES.
--fuzzy-img [FILES]
Générer un hash flou d'image pour chaque fichier.

COMMANDES POUR NORMALISER LES FICHIERS

--html-normalise=FILE
Créer les fichiers comment.html, nocomment.html et script.html normalisés dans le répertoire de travail courant.
--ascii-normalise=FILE
Créer un fichier texte normalisé à partir d'une source ASCII.
--utf16-decode=FILE
Décoder les données encodées en UTF16.

COMMANDES POUR L'ANALYSE DE FICHIERS

--vba=FILE
Extraire les macros VBA/Word6 du document MS Office donné.
--vba-hex=FILE
Extraire les macros Word6 du document MS Office donné et afficher les valeurs hexadécimales correspondantes.
--print-certs=FILE
Afficher les détails Authenticode d'un fichier PE.
--hex-dump
Lire les données depuis stdin et écrire la chaîne hexadécimale sur stdout.

COMMANDES POUR TRAVAILLER AVEC LES CVD

-i, --info
Afficher les informations d'un CVD et vérifier sa signature MD5 et numérique.
--build=FILE, -b FILE
Construire un fichier CVD. -s, --server est requis pour les bases de données de virus signées (.cvd), ou --unsigned pour les non signées (.cud).
--max-bad-sigs=NUMBER
Nombre maximum de signatures non concordantes lors de la construction d'un CVD. Par défaut : 3000.
--flevel
Spécifier un flevel personnalisé. Par défaut : 77.
--cvd-version
Spécifier le numéro de version à utiliser pour la construction. Par défaut, la valeur+1 de la CVD actuelle dans --datadir est utilisée. Si aucun fichier de données n'est trouvé, le comportement par défaut est de demander un numéro de version, ce commutateur empêchera la demande. NOTE : Si une CVD est trouvée dans le --datadir, sa valeur+1 est utilisée et cette valeur est ignorée.
--no-cdiff
Ne pas créer de fichier .cdiff lors de la construction d'un nouveau fichier de base de données.
--hybrid
Créer un fichier de base de données hybride (standard et bytecode).
--unsigned
Créer un fichier de base de données sans signature numérique (.cud).
--server=ADDR
Adresse du service de signature ClamAV (réservé aux mainteneurs de la base de données de virus).
--unpack=FILE, -u FILE
Décompresser FILE (CVD) dans le répertoire courant.
--unpack-current
Décompresser une CVD locale (principale ou quotidienne) dans le répertoire courant.
--fips-limits
Appliquer des limites de type FIPS à l'utilisation des algorithmes de hachage à des fins cryptographiques. Désactivera les signatures FP MD5 et SHA1 et exigera des fichiers '.sign' pour vérifier l'authenticité des CVD.

COMMANDES POUR TRAVAILLER AVEC LES FICHIERS DE PATCH CDIFF

--diff=OLD NEW, -d OLD NEW
Créer un fichier de différences pour les CVD/INCDIRs OLD et NEW.
--compare=OLD NEW, -c OLD NEW
Cette commande comparera deux fichiers texte et affichera les différences au format cdiff.
--run-cdiff=FILE, -r FILE
Exécuter le script de mise à jour FILE dans le répertoire courant.
--verify-cdiff=FILE, -r FILE
Vérifier DIFF par rapport à CVD/INCDIR.

COMMANDES POUR CREER ET VERIFIER DES SIGNATURES NUMERIQUES DETACHEES

--sign
Signer un fichier. Le nom du fichier .sign résultant sera de la forme : dbname-version.cvd.sign ou FILE.sign pour les cibles autres que CVD. I

sigtool(1) — Arch Linux man pages

NAME

sigtool — Sigtool, a utility for managing ClamAV signatures

SYNOPSIS

sigtool [options]

DESCRIPTION

Sigtool is a utility for managing ClamAV signatures. It can be used to create, verify, and manipulate signature files and databases.

COMMON OPTIONS

--help
Show help message.
--version
Show version information.

COMMANDS FOR WORKING WITH SIGNATURES

--hex-dump
Dumps the hexadecimal representation of the input data.
--decode-hex
Decodes hexadecimal data from the input.
--create-hex
Create signature from hex string.
--dump-signatures
Dump signatures from a database.
--update-signatures
Update signatures in a database.

COMMANDS TO GENERATE SIGNATURES

--gen-coldfusion-sig
Generate a signature for a ColdFusion exploit.
--gen-html-sig
Generate a signature for an HTML exploit.
--gen-olev1-sig
Generate a signature for an OLEv1 exploit.
--gen-ole-sig
Generate a signature for an OLE exploit.
--gen-pe-sig
Generate a signature for a PE exploit.
--gen-pdf-sig
Generate a signature for a PDF exploit.
--gen-xml-sig
Generate a signature for an XML exploit.

COMMANDS TO NORMALIZE FILES

--normalize
Normalize a file for signature generation.
--normalize-unicode
Normalize a file containing unicode characters.

COMMANDS FOR FILE ANALYSIS

--scan
Scan a file for malware.
--list-bad-files
List known bad files.

COMMANDS FOR WORKING WITH CVDS

--build-cvd
Build a CVD database.
--sign-cvd
Sign a CVD database.
--verify-cvd
Verify a CVD database.

COMMANDS FOR WORKING WITH CDIFF PATCH FILES

--make-cdiff
Create a cdiff patch file.
--apply-cdiff
Apply a cdiff patch file.

COMMANDS FOR CREATING AND VERIFYING DETACHED DIGITAL SIGNATURES

--sign=FILE
Create a detached digital signature for the given file. The signature file will be created next to the target file. If a .sign file already exists, then the new signature will be appended to file.
--key=FILE
Specify a signing key.
--cert=FILE
Specify a signing cert. May be used more than once to add intermediate and root certificates.
--append
Use to add a signature line to an existing .sign file. Otherwise an existing .sign file will be overwritten.
--verify
Find and verify a detached digital signature for the given file. The digital signature file name must be in the form: dbname-version.cvd.sign or FILE.sign for non-CVD targets. It must be found next to the target file.
--cvdcertsdir=DIR
Specify a directory containing the root CA cert needed to verify the signature. If not provided, then sigtool will look in the default certs directory.

ENVIRONMENT VARIABLES

Sigtool uses the following environment variables:

SIGNDUSER
The username to authenticate with the signing server when building a signed CVD database.
SIGNDPASS
The password to authenticate with the signing server when building a signed CVD database.
CVD_CERTS_DIR
Specify a directory containing the root CA cert needed to verify detached CVD digital signatures. If not provided, then sigtool will look in the default directory.

EXAMPLES

Generate hex string from testfile and save it to testfile.hex:

cat testfile | sigtool --hex-dump > testfile.hex
