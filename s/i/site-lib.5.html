DESCRIPTION

Chaque installation de "findlib" possède un emplacement par défaut pour les répertoires de paquets, qui est normalement un répertoire appelé "site-lib". L'emplacement peut être défini par les variables de configuration path (utilisée pour rechercher les paquets) et destdir (utilisée pour installer de nouveaux paquets) ; voir findlib.conf.

Le nom d'un paquet est le nom du répertoire du paquet. Par exemple, si destdir=/usr/local/lib/ocaml/site-lib, le paquet p sera installé dans le sous-répertoire /usr/local/lib/ocaml/site-lib/p. Ce sous-répertoire doit contenir le fichier META et tous les autres fichiers appartenant au paquet. Les noms de paquets ne doivent pas contenir le caractère '.'.

La variable destdir spécifie le répertoire pour les nouveaux paquets. Vous ne pouvez avoir qu'un seul répertoire de ce type à la fois ; mais bien sûr, vous pouvez changer ce répertoire dans findlib.conf. La commande ocamlfind install place les nouveaux paquets dans ce répertoire ; il est recommandé d'utiliser cette commande pour l'installation car elle assure que la structure du répertoire est correcte.

Pour la recherche de paquets, findlib utilise (uniquement) la variable path qui peut nommer plusieurs emplacements à examiner.

Pour les systèmes avec prise en charge des DLL, un autre répertoire peut exister : stublibs. S'il est présent, findlib installera les DLL dans ce répertoire qui est partagé par tous les paquets au même emplacement site-lib. Findlib se souvient de quelle DLL appartient à quel paquet grâce à des fichiers spéciaux avec le suffixe ".owner" ; par exemple, pour la DLL "dllpcre.so", il existe un autre fichier "dllpcre.so.owner" contenant la chaîne "pcre", donc findlib sait que le paquet "pcre" possède cette DLL. Il n'est pas possible qu'une DLL soit possédée par plusieurs paquets.

Si le répertoire stublibs n'existe pas, les DLL sont installées régulièrement dans les répertoires de paquets comme n'importe quel autre fichier.

Pour des besoins spéciaux, un script postinstall et/ou un script postremove peuvent être installés dans le répertoire site-lib. Ces scripts sont appelés après l'installation ou la suppression d'un paquet, respectivement.

Ceci est une disposition de répertoire alternative collectant tous les fichiers META dans un seul répertoire. Vous pouvez configurer cette disposition en définissant path sur l'emplacement absolu de metaregistry. Findlib reconnaît qu'il y a des fichiers META dans ce répertoire et les utilise ; il n'est pas nécessaire d'inclure site-lib dans le path.

Pour fonctionner, les fichiers META doivent contenir une directive directory pointant vers le répertoire du paquet correspondant qui réside sous site-lib.

La commande ocamlfind install gère également cette disposition. La variable destdir doit contenir l'emplacement absolu de site-lib, et la variable metadir doit contenir l'emplacement absolu de metaregistry. Notez que ocamlfind install ajoute automatiquement une directive directory au fichier META, vous n'avez donc pas besoin de le faire manuellement.
