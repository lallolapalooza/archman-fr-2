SIGPENDING(3P) Manuel du programmeur POSIX SIGPENDING(3P)

PREAMBULE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sigpending — examiner les signaux en attente

SYNTAXE

#include <signal.h>
int sigpending(sigset_t *set);

DESCRIPTION

La fonction sigpending() doit stocker, à l'emplacement référencé par l'argument set, l'ensemble des signaux qui sont bloqués de la livraison au thread appelant et qui sont en attente sur le processus ou sur le thread appelant.

VALEUR DE RETOUR

En cas de succès, sigpending() retourne 0 ; sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Aucune erreur n'est définie.
