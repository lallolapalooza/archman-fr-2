NOM

signaltest - logiciel de test de boucle de signaux

SYNTAXE

signaltest [ -a|--affinity NUM] [ -b|--backtrace USEC ] [-D|--duration TIME] [-h|--help] [--json FILENAME] [-l|--loops LOOPS ] [-p|--prio PRIO] [-q|--quiet] [-S|--smp] [-t|--threads NUM] [-m|--mlockall ] [-v|--verbose ]

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets ('--').

-a, --affinity[=PROC-SET]
Exécute les threads sur l'ensemble des processeurs donné par PROC-SET. Si PROC-SET n'est pas spécifié, tous les processeurs seront utilisés. Les threads seront assignés aux processeurs de l'ensemble dans un ordre numérique, de manière cyclique (round-robin).
L'ensemble des processeurs peut être spécifié comme A,B,C, ou A-C, ou A-B,D-F, et ainsi de suite*. Le caractère ! peut être utilisé pour nier un ensemble. Par exemple, !B-D signifie utiliser tous les CPUs disponibles sauf B à D. Les numéros de CPU sont les mêmes que ceux affichés dans le champ processor de /proc/cpuinfo. Voir numa(3) pour plus d'informations sur la spécification des ensembles de CPU. * La prise en charge des ensembles de CPU nécessite la version >= 2 de libnuma. Pour libnuma v1, PROC-SET, s'il est spécifié, doit être un seul numéro de CPU.
-b, --backtrace=USEC
Envoie une commande de trace de coupure lorsque la latence > USEC
-D, --duration=TIME
Spécifie une durée pour l'exécution du test.
Ajoutez 'm', 'h', ou 'd' pour spécifier des minutes, heures ou jours.
--help

affiche les informations d'utilisation
--json=FILENAME
Écrit les résultats finaux dans FILENAME, au format JSON.
-l, --loops=LOOPS
Nombre de boucles : par défaut=0 (sans fin)
-p, --priority=PRIO
Priorité du thread le plus prioritaire
-q, --quiet
n'affiche qu'un résumé à la sortie
-S, --smp
Définit les options pour les tests standards sur les systèmes SMP. Équivalent à l'utilisation des options : "-t -a" tout en conservant la priorité spécifiée égale pour tous les threads
-t, --threads=NUM
nombre de threads : par défaut=2
-m, --mlockall
verrouille la mémoire actuelle et future allouée
-v, --verbose
affiche les valeurs sur stdout pour les statistiques
format : n:c:v n=numéro de tâche c=compteur v=valeur en µs
