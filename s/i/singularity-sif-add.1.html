NOM

apptainer-sif-add - Ajouter un objet de données

SYNOPIS

apptainer sif add [options]

DESCRIPTION

Ajoute un objet de données à une image SIF.

OPTIONS

--alignment=0 définit l'alignement [défaut : 4096 avec --datatype 4-Partition, 0 sinon]

--datatype=0 le type de données à ajouter [NÉCESSAIRE, pas de défaut] :
1-Deffile, 2-EnvVar, 3-Labels,
4-Partition, 5-Signature, 6-GenericJSON,
7-Generic, 8-CryptoMessage, 9-SBOM,
10-OCI.RootIndex, 11-OCI.Blob

--filename="" définit le nom de fichier logique/le handle [défaut : nom du fichier d'entrée]

--groupid=0 définit l'identifiant du groupe [défaut : 0]

-h, --help[=false] aide pour add

--link=0 définit le pointeur de lien [défaut : 0]

--partarch=0 l'architecture principale utilisée (avec --datatype 4-Partition) [NÉCESSAIRE, pas de défaut] :
1-386, 2-amd64, 3-arm,
4-arm64, 5-ppc64, 6-ppc64le,
7-mips, 8-mipsle, 9-mips64,
10-mips64le, 11-s390x, 12-riscv64

--partfs=0 le système de fichiers utilisé (avec --datatype 4-Partition) [NÉCESSAIRE, pas de défaut] :
1-Squash, 2-Ext3, 3-ImmuObj,
4-Raw

--parttype=0 le type de partition (avec --datatype 4-Partition) [NÉCESSAIRE, pas de défaut] :
1-System, 2-PrimSys, 3-Data,
4-Overlay

--sbomformat="" le format SBOM (avec --datatype 9-sbom) :
cyclonedx-json, cyclonedx-xml, github-json,
spdx-json, spdx-rdf, spdx-tag-value,
spdx-yaml, syft-json

--signentity="" l'entité qui signe (avec --datatype 5-Signature) [NÉCESSAIRE, pas de défaut] :
exemple : 433FE984155206BD962725E20E8713472A879943

--signhash=0 le hachage de signature utilisé (avec --datatype 5-Signature) [NÉCESSAIRE, pas de défaut] :
1-SHA256, 2-SHA384, 3-SHA512,
4-BLAKE2s_256, 5-BLAKE2b_256

EXEMPLE

sif add image.sif recipe.def --datatype 1
sif add image.sif rootfs.squashfs --datatype 4 --parttype 1 --partfs 1 --partarch 2
sif add image.sif signature.bin --datatype 5 --signentity 433FE984155206BD962725E20E8713472A879943 --signhash 1
