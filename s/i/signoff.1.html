NOM

signoff - Approuver ou révoquer des paquets Arch Linux Testing

SYNTAXE

signoff [options] [paquet]

DESCRIPTION

Les paquets des dépôts testing d'Arch Linux peuvent être signés comme étant entièrement fonctionnels par l'équipe de test d'Arch Linux, puis promus dans les dépôts normaux après un certain nombre d'approbations. L'outil signoff est créé pour l'équipe de test d'Arch Linux afin de faciliter l'approbation des paquets de manière interactive.

OPTIONS

-s, --signoff paquet

Approuve le paquet spécifié.

-r, --revoke paquet

Révogue le paquet spécifié.

-l, --list

Liste des paquets pouvant être approuvés.

-i, --interactive

Approuve les paquets de manière interactive.

-u, --uninstalled

Inclut les paquets non installés lors de la liste.

-a, --signed-off

Inclut les paquets approuvés lors de la liste.

-q, --quiet

Moins verbeux lors de la liste des paquets.

-b, --db-path <chemin_db>

Chemin de la base de données pacman

--username nom_utilisateur

Nom d'utilisateur ArchWeb.

--password mot_de_passe

Mot de passe ArchWeb.

--noconfirm

Ne pas demander de confirmation.

--nocolor

Ne pas utiliser de couleur dans la sortie.

-h, --help

Affiche ce message et quitte.

ENVIRONNEMENT

ARCHWEB_USERNAME

Le nom d'utilisateur archweb à utiliser pour se connecter à archweb.

ARCHWEB_PASSWORD

Le mot de passe archweb à utiliser pour se connecter à archweb.
