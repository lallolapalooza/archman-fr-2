NOM

apptainer-pull - Télécharger une image depuis une URI

SYNTAXE

apptainer pull [options de téléchargement...] [fichier de sortie]

DESCRIPTION

La commande 'pull' vous permet de télécharger ou de construire un conteneur à partir d'une
URI donnée. Les URIs prises en charge incluent :

library: Télécharger une image depuis la bibliothèque actuellement configurée
library://user/collection/container[:tag]

docker: Télécharger une image Docker/OCI depuis Docker Hub, ou un autre registre OCI.
docker://user/image:tag

shub: Télécharger une image depuis Singularity Hub
shub://user/image:tag

oras: Télécharger une image SIF depuis un registre OCI prenant en charge ORAS.
oras://registry/namespace/image:tag

http, https: Télécharger une image en utilisant le protocole http(s?)
https://example.com/alpine.sif

OPTIONS

--arch="amd64" architecture depuis laquelle télécharger depuis la bibliothèque

--arch-variant="" variante d'architecture à télécharger depuis la bibliothèque

--authfile="" fichier d'authentification de type Docker à utiliser pour écrire/lire les identifiants du registre OCI

--dir="" télécharger les images dans le répertoire spécifique

--disable-cache[=false] ne pas utiliser ou créer d'images/blobs en cache

--docker-host="" spécifier un hôte de démon Docker personnalisé

--docker-login[=false] se connecter à un dépôt Docker interactivement

-F, --force[=false] écraser un fichier image s'il existe

-h, --help[=false] aide pour pull

--library="" télécharger les images depuis la bibliothèque fournie

--no-cleanup[=false] NE PAS nettoyer le bundle après un échec de construction, peut être utile pour le débogage

--no-https[=false] utiliser http au lieu de https pour les URIs docker://, oras:// et library:///...

--sandbox[=false] télécharger l'image au format sandbox (structure de répertoire chroot)

EXEMPLE

  Depuis une bibliothèque
  $ apptainer pull alpine.sif library://alpine:latest
  Depuis Docker
  $ apptainer pull tensorflow.sif docker://tensorflow/tensorflow:latest
  $ apptainer pull --arch arm --arch-variant 6 alpine.sif docker://alpine:latest
  Depuis Shub
  $ apptainer pull apptainer-images.sif shub://vsoch/apptainer-images
  Depuis un registre OCI compatible (par ex. Azure Container Registry)
  $ apptainer pull image.sif oras://<username>.azurecr.io/namespace/image:tag
