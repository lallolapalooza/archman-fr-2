NOM

apptainer - Plateforme de conteneurisation Linux optimisée pour le calcul haute performance (HPC) et le calcul haute performance d'entreprise (EPC)

SYNTAXE

apptainer [options globales...]

DESCRIPTION

Les conteneurs Apptainer fournissent une couche de virtualisation d'applications permettant
la mobilité du calcul via la portabilité des applications et de l'environnement. Avec
Apptainer, il est possible de construire un système de fichiers racine qui s'exécute sur tout
autre système Linux où Apptainer est installé.

OPTIONS

--build-config[=false] utiliser la configuration nécessaire pour construire des conteneurs

-c, --config="/etc/apptainer/apptainer.conf" spécifier un fichier de configuration (pour installation root ou non privilégiée uniquement)

-d, --debug[=false] afficher les informations de débogage (verbeux maximum)

-h, --help[=false] aide pour apptainer

--nocolor[=false] afficher sans sortie couleur (par défaut Faux)

-q, --quiet[=false] supprimer la sortie normale

-s, --silent[=false] afficher uniquement les erreurs

-v, --verbose[=false] afficher des informations supplémentaires

EXEMPLE

  $ apptainer help <commande> [<sous-commande>]
  $ apptainer help build
  $ apptainer help instance start
