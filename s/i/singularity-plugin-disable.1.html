NOM

apptainer-plugin-disable - désactive un plugin Apptainer installé

SYNTAXE

apptainer plugin disable

DESCRIPTION

La commande 'plugin disable' permet à un utilisateur de désactiver un plugin déjà installé dans le système et qui avait été précédemment activé.

OPTIONS

-h, --help[=false] aide pour disable

EXEMPLE

  $ apptainer plugin disable example.org/plugin
