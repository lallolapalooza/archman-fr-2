NOM

signstar-configure-build - Interface en ligne de commande pour la configuration de la construction d'images Signstar

SYNOPIS

signstar-configure-build [-c|--config] [-v|--version] [-h|--help]

DESCRIPTION

Interface en ligne de commande pour la configuration de la construction d'images Signstar.

NOTE : Cette commande doit être exécutée en tant que root !

Cet exécutable est destiné à être utilisé pour configurer les utilisateurs système pertinents d'un système Signstar pendant la construction.

Il crée les utilisateurs système et leur intégration sur la base d'un fichier de configuration central.

Par défaut, l'un des fichiers de configuration suivants est utilisé s'il existe, dans l'ordre suivant :

- "/usr/local/share/signstar/config.toml"

- "/run/signstar/config.toml"

- "/etc/signstar/config.toml"

Si aucun des fichiers ci-dessus n'est trouvé, l'emplacement par défaut "/usr/share/signstar/config.toml" est utilisé. Alternativement, un emplacement de fichier de configuration personnalisé peut être spécifié en utilisant l'option "--config"/"-c".

Les utilisateurs système, s'ils n'existent pas déjà, sont créés avec l'aide de `useradd`. Les utilisateurs sont créés sans mot de passe et configurés avec un répertoire personnel sous "/var/lib/signstar/home/". Cependant, leur répertoire personnel n'est pas créé automatiquement. Les comptes utilisateurs système sont ensuite déverrouillés avec l'aide de `usermod`. Pour chaque utilisateur système, une intégration tmpfiles.d est fournie sous "/usr/lib/tmpfiles.d", pour permettre la création automatique de leur répertoire personnel.

Si le fichier de configuration utilisé associe l'utilisateur système à des clés publiques SSH, un fichier dédié "authorized_keys" contenant les clés publiques SSH pour l'utilisateur est créé sous "/etc/ssh/". De plus, une configuration de remplacement "sshd_config" est créée sous "/etc/ssh/sshd_config.d/". Cette configuration de remplacement "sshd_config" impose l'utilisation du fichier "authorized_keys" de l'utilisateur et l'utilisation d'une commande spécifique (c'est-à-dire l'une des :["signstar-download-backup", "signstar-download-key-certificate", "signstar-download-metrics", "signstar-download-secret-share", "signstar-download-wireguard", "signstar-sign", "signstar-upload-backup", "signstar-upload-secret-share", "signstar-upload-update"]) en fonction du rôle de l'utilisateur.

OPTIONS

-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé.

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement du fichier de configuration par défaut.

S'il n'est pas spécifié, l'un des fichiers de configuration suivants est utilisé s'il existe, dans l'ordre suivant :

- "/usr/local/share/signstar/config.toml"

- "/run/signstar/config.toml"

- "/etc/signstar/config.toml"

Si aucun des fichiers ci-dessus n'est trouvé, l'emplacement par défaut "/usr/share/signstar/config.toml" est utilisé.

Peut également être spécifié avec la variable d'environnement SIGNSTAR_CONFIG.
-v, --version
Retourne le nom et la version de l'application.
-h, --help
Affiche l'aide (voir un résumé avec '-h').
