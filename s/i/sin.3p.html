SIN(3P) Manuel du programmeur POSIX SIN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sin, sinf, sinl — fonction sinus

SYNTAXE

#include <math.h>
double sin(double x);
float sinf(float x);
long double sinl(long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent le sinus de leur argument x, mesuré en radians.

Une application souhaitant vérifier les situations d'erreur doit initialiser errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est différent de zéro ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est différent de zéro, une erreur s'est produite.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent le sinus de x.

Si x est NaN, un NaN est retourné.

Si x est ±0, x est retourné.

Si x est sous-normal, une erreur de plage peut se produire
et x doit être retourné.

Si x n'est pas retourné, sin(), sinf(), et sinl() retournent une valeur indéfinie par l'implémentation, de magnitude ne dépassant pas respectivement DBL_MIN, FLT_MIN et LDBL_MIN.

Si x est ±Inf, une erreur de domaine se produit et un NaN est retourné.

ERREURS

Ces fonctions échouent si :

Erreur de Domaine
L'argument x est ±Inf.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception virgule flottante invalide est levée.

Ces fonctions peuvent échouer si :

Erreur de Plage
La valeur de x est sous-normale

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception virgule flottante de sous-dépassement est levée.

Les sections suivantes sont informatives.

EXEMPLES

Calculer le sinus d'un angle de 45 degrés

#include <math.h>
...
double radians = 45.0 * M_PI / 180;
double resultat;
...
resultat = sin(radians);

USAGE APPLICATIF

Ces fonctions peuvent perdre de la précision lorsque leur argument est proche d'un multiple de π ou est éloigné de 0.0.

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins une d'entre elles doit être non nulle.

RATIONALE

Aucun.

DIRECTIONS FUTURES

Aucun.
