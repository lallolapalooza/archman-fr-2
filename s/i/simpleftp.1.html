NOM

simpleftp - Client FTP et HTTP(S) rudimentaire

SYNTAXE

simpleftp url [...]

DESCRIPTION

simpleftp est un script Perl qui fournit un support de base pour la récupération de fichiers de manière orientée batch. Il prend une ou plusieurs URL FTP ou HTTP(S) en ligne de commande. Les fichiers seront récupérés depuis les serveurs FTP ou web distants et placés dans le répertoire courant avec le même nom de base qu'à distance ; par exemple, https://downloads.isc.org/pub/usenet/CONFIG/active.gz est stocké sous le nom active.gz dans le répertoire courant.

Le script comprend correctement les noms d'utilisateur, mots de passe et ports spécifiés comme suit :

ftp://utilisateur:motdepasse@hôte:port/chemin/fichier

simpleftp a un délai d'attente codé en dur de 30 secondes. Il utilise le mode binaire et le mode passif pour les transferts de données FTP.

Il se termine avec le statut 0 en cas de succès. Sinon, le statut de sortie est le nombre de transferts échoués.

INN utilise seulement simpleftp lors de l'exécution de actsyncd. Si wget (ou aussi ncftpget ou ncftp dans la seule portée FTP) est trouvé lors de la configuration, alors il sera utilisé à la place de ce script.

BOGUES

simpleftp est un substitut extrêmement médiocre pour des programmes plus complets comme l'utilitaire wget librement disponible, que nous vous encourageons à utiliser à la place. Il a été écrit uniquement pour fournir un support élémentaire dans INN pour la récupération non interactive des fichiers dans https://downloads.isc.org/pub/pgpcontrol/ ou https://downloads.isc.org/pub/usenet/CONFIG/ sans obliger les administrateurs à installer un autre paquet. Ses lacunes en tant que programme à usage général sont trop nombreuses pour être mentionnées, mais l'une qui ressort est que les fichiers téléchargés par simpleftp remplacent les fichiers existants portant le même nom dans le répertoire local.

Le support HTTP nécessite le module Perl "HTTP::Tiny", uniquement installé dans Perl 5.14.0 et supérieur comme module de base de Perl. De plus, les modules Perl "IO::Socket::SSL" et "Net::SSLeay" sont requis pour le support HTTPS. Au cas où ils ne seraient pas installés, simpleftp ne peut pas gérer ces protocoles.
