NOM

apptainer-push - Télécharger une image vers l'URI fournie

SYNTAXE

apptainer push [options de push...]

DESCRIPTION

La commande 'push' vous permet de télécharger un conteneur SIF vers un
URI donné. Les URI pris en charge incluent :

library:
library://utilisateur/collection/conteneur[:tag]

oras:
oras://registre/espace-de-noms/image:tag

REMARQUE : Il est toujours recommandé de signer vos conteneurs avant
de les pousser dans la bibliothèque. Un jeton d'authentification est requis pour pousser dans la bibliothèque,
vous devrez donc peut-être d'abord le configurer avec 'apptainer remote'.

OPTIONS

-U, --allow-unsigned[=false] ne pas exiger une image de conteneur signée

--authfile="" fichier d'authentification de style Docker à utiliser pour lire/écrire les identifiants du registre OCI

-D, --description="" description de l'image du conteneur (library:// seulement)

--docker-host="" spécifier un hôte de démon Docker personnalisé

-h, --help[=false] aide pour push

--library="" la bibliothèque vers laquelle pousser

--no-https[=false] utiliser http au lieu de https pour les URI docker://, oras:// et library:///...

EXEMPLE

  Vers la bibliothèque
  $ apptainer push /home/utilisateur/mon.sif library://utilisateur/collection/mon.sif:latest
  Vers un registre OCI pris en charge
  $ apptainer push /home/utilisateur/mon.sif oras://registre/espace-de-noms/image:tag
