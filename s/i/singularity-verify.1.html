NOM

apptainer-verify - Vérifier une ou plusieurs signatures numériques dans une image

SYNOPIS

apptainer verify [options de vérification...]

DESCRIPTION

La commande verify permet à un utilisateur de vérifier une ou plusieurs signatures numériques
dans une image SIF.

Le matériel de clé peut être fourni via un fichier encodé PEM, ou via le porte-clés PGP. Pour
gérer le porte-clés PGP, voir 'apptainer help key'.

OPTIONS

-a, --all[=false] vérifier tous les objets

--certificate="" chemin vers le certificat

--certificate-intermediates="" chemin vers le pool de certificats intermédiaires

--certificate-roots="" chemin vers le pool de certificats racines

-g, --group-id=0 vérifier les objets avec l'ID de groupe spécifié

-h, --help[=false] aide pour verify

-j, --json[=false] sortie json

--key="" chemin vers le fichier de clé publique

--legacy-insecure[=false] activer la vérification des signatures héritées (non sécurisées)

-l, --local[=false] vérifier uniquement avec les clés locales du porte-clés

--ocsp-verify[=false] activer la vérification de révocation en ligne pour les certificats

-i, --sif-id=0 vérifier l'objet avec l'ID spécifié

-u, --url="" spécifier une URL pour un serveur de clés

EXEMPLE

  Vérifier avec une clé publique :
  $ apptainer verify --key public.pem container.sif
  Vérifier avec PGP :
  $ apptainer verify container.sif
