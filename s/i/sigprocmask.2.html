sigprocmask(2) Manuel des appels système sigprocmask(2)

NOM

sigprocmask, rt_sigprocmask - examiner et modifier les signaux bloqués

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <signal.h>

/* Prototype de la fonction d'enveloppement de glibc */
int sigprocmask(int how, const sigset_t *_Nullable restrict set,
                           sigset_t *_Nullable restrict oldset);
#include <signal.h>           /* Définition des constantes SIG_* */
#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
/* Prototype de l'appel système sous-jacent */
int syscall(SYS_rt_sigprocmask, int how,
                           const kernel_sigset_t *_Nullable set,
                           kernel_sigset_t *_Nullable oldset,
                           size_t sigsetsize);
/* Prototype de l'appel système hérité */
[[deprecated]] int syscall(SYS_sigprocmask, int how,
                           const old_kernel_sigset_t *_Nullable set,
                           old_kernel_sigset_t *_Nullable oldset);
Exigences pour les macros de test de fonctionnalité dans glibc (voir feature_test_macros(7)):

sigprocmask():

    _POSIX_C_SOURCE

DESCRIPTION

sigprocmask() est utilisé pour récupérer et/ou modifier le masque de signaux du thread appelant. Le masque de signaux est l'ensemble des signaux dont la livraison est actuellement bloquée pour l'appelant (voir aussi signal(7) pour plus de détails).

Le comportement de l'appel dépend de la valeur de how, comme suit.

SIG_BLOCK
L'ensemble des signaux bloqués est l'union de l'ensemble actuel et de l'argument set.
SIG_UNBLOCK
Les signaux présents dans set sont retirés de l'ensemble actuel de signaux bloqués. Il est permis de tenter de débloquer un signal qui n'est pas bloqué.
SIG_SETMASK
L'ensemble des signaux bloqués est défini à l'argument set.

Si oldset n'est pas NULL, la valeur précédente du masque de signaux est stockée dans oldset.

Si set est NULL, alors le masque de signaux n'est pas modifié (c'est-à-dire que how est ignoré), mais la valeur actuelle du masque de signaux est néanmoins renvoyée dans oldset (si celui-ci n'est pas NULL).

Un ensemble de fonctions pour modifier et inspecter les variables de type sigset_t ("ensembles de signaux") est décrit dans sigsetops(3).

L'utilisation de sigprocmask() n'est pas spécifiée dans un processus multithreadé ; voir pthread_sigmask(3).

VALEUR DE RETOUR

sigprocmask() renvoie 0 en cas de succès. En cas d'échec, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
L'argument set ou oldset pointe en dehors de l'espace d'adressage alloué du processus.
EINVAL
Soit la valeur spécifiée dans how était invalide, soit le noyau ne prend pas en charge la taille passée dans sigsetsize.

VERSIONS

Différences bibliothèque C/noyau

La définition du noyau pour sigset_t diffère en taille de celle utilisée par la bibliothèque C. Dans cette page man, la première est désignée sous le nom de kernel_sigset_t (elle est néanmoins nommée sigset_t dans les sources du noyau).

La fonction d'enveloppement glibc pour sigprocmask() ignore silencieusement les tentatives de blocage des deux signaux temps réel utilisés en interne par l'implémentation du threading NPTL. Voir nptl(7) pour les détails.

L'appel système Linux d'origine était nommé sigprocmask(). Cependant, avec l'ajout des signaux temps réel dans Linux 2.2, le type sigset_t de taille fixe et 32 bits (désigné comme old_kernel_sigset_t dans cette page man) supporté par cet appel système n'était plus adapté. Par conséquent, un nouvel appel système, rt_sigprocmask(), a été ajouté pour supporter un type sigset_t agrandi (désigné comme kernel_sigset_t dans cette page man). Le nouvel appel système prend un quatrième argument, size_t sigsetsize, qui spécifie la taille en octets des ensembles de signaux dans set et oldset. Cet argument doit actuellement avoir une valeur fixe spécifique à l'architecture (égale à sizeof(kernel_sigset_t)).

La fonction d'enveloppement glibc sigprocmask() nous cache ces détails, appelant de manière transparente rt_sigprocmask() lorsque le noyau le fournit.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

NOTES

Il n'est pas possible de bloquer SIGKILL ou SIGSTOP. Les tentatives de le faire sont silencieusement ignorées.

Chacun des threads d'un processus a son propre masque de signaux.

Un enfant créé via fork(2) hérite d'une copie du masque de signaux de son parent ; le masque de signaux est préservé lors d'un execve(2).

Si SIGBUS, SIGFPE, SIGILL, ou SIGSEGV sont générés alors qu'ils sont bloqués, le résultat est indéfini, à moins que le signal n'ait été généré par kill(2), sigqueue(3), ou raise(3).

Voir sigsetops(3) pour les détails sur la manipulation des ensembles de signaux.

Notez qu'il est permis (bien que peu utile) de spécifier à la fois set et oldset comme NULL.

VOIR AUSSI

kill(2), pause(2), sigaction(2), signal(2), sigpending(2), sigsuspend(2), pthread_sigmask(3), sigqueue(3), sigsetops(3), signal(7)

sigprocmask(2)

NAME sigprocmask, pthread_sigmask - manipule le masque de signalisation des threads

LIBRARY libc — Standard C Library

SYNOPSIS 

#include <signal.h>

int sigprocmask(int how, const sigset_t *set, sigset_t *oldset);
int pthread_sigmask(int how, const sigset_t *set, sigset_t *oldset);

DESCRIPTION Les fonctions sigprocmask() et pthread_sigmask() sont utilisées pour examiner et modifier le masque de signalisation des signaux bloqués du processus appelant ou du thread appelant, respectivement.

Le masque de signalisation est un ensemble de signaux que le processus ou le thread ne recevra pas. Lorsqu'un signal est bloqué, il est mis en attente jusqu'à ce qu'il soit débloqué. Les signaux non bloqués sont livrés immédiatement.

Le masque de signalisation est représenté par une structure sigset_t. La manipulation de cette structure est effectuée à l'aide des macros suivantes, qui sont définies dans <signal.h> :

sigemptyset(sigset_t *set)
Initialise le masque set pour qu'il ne contienne aucun signal.
sigfillset(sigset_t *set)
Initialise le masque set pour qu'il contienne tous les signaux définis.
sigaddset(sigset_t *set, int signum)
Ajoute le signal signum au masque set.
sigdelset(sigset_t *set, int signum)
Supprime le signal signum du masque set.
sigismember(const sigset_t *set, int signum)
Vérifie si le signal signum est membre du masque set. Renvoie 1 si c'est le cas, 0 sinon, et -1 en cas d'erreur.

L'argument how spécifie comment le masque de signalisation doit être modifié :

SIG_BLOCK
Le nouveau masque de signalisation est l'union de l'ancien masque et de l'ensemble spécifié par set. Les signaux dans set sont ajoutés au masque de signalisation.
SIG_UNBLOCK
Le nouveau masque de signalisation est l'intersection de l'ancien masque et du complément de l'ensemble spécifié par set. Les signaux dans set sont supprimés du masque de signalisation.
SIG_SETMASK
Le nouveau masque de signalisation est directement l'ensemble spécifié par set.

Si l'argument oldset n'est pas NULL, l'ancien masque de signalisation est stocké dans la structure sigset_t pointée par oldset.

La différence entre sigprocmask() et pthread_sigmask() est que sigprocmask() affecte le masque de signalisation de tous les threads du processus, tandis que pthread_sigmask() affecte uniquement le masque de signalisation du thread appelant.

RETURN VALUE En cas de succès, sigprocmask() et pthread_sigmask() renvoient 0. En cas d'erreur, ils renvoient -1 et errno est définie pour indiquer l'erreur.

ERRORS Les erreurs suivantes peuvent être renvoyées :

EINVAL
La valeur de how n'est pas valide.

VERSIONS Les fonctions sigprocmask() et pthread_sigmask() sont disponibles depuis la glibc 2.1.

STANDARDS POSIX.1-2001, POSIX.1-2008.

HISTORY Les fonctions sigprocmask() et pthread_sigmask() ont été introduites dans POSIX.1-1990.

NOTES La fonction sigprocmask() peut être utilisée pour bloquer ou débloquer des signaux pour l'ensemble du processus. La fonction pthread_sigmask() est l'équivalent au niveau du thread.

Il est important de noter que le blocage de signaux ne les empêche pas de se produire ; ils sont simplement mis en attente jusqu'à ce que le blocage soit levé. Pour ignorer complètement un signal, vous devez utiliser signal() ou sigaction().
