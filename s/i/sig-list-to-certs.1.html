SIG-LIST-TO-CERTS(1) Commandes utilisateur SIG-LIST-TO-CERTS(1)

NOM

sig-list-to-certs - outil pour convertir les listes de signatures EFI en certificats openssl

SYNTAXE

sig-list-to-certs <fichier de liste de signatures efi> <nom de base du fichier de certificat>

DESCRIPTION

Prend le <fichier de liste de signatures efi> et le convertit en un ensemble de certificats openssl au format DER dans <nom de base du fichier de certificat>.n (où n va de 0 au nombre de certificats dans le fichier)

EXEMPLES

Pour voir quels certificats votre système UEFI possède actuellement, vous pouvez utiliser la commande dmpstore pour les imprimer dans un fichier

dmpstore PK > PK.uc16

Ce fichier n'est pas facilement lisible sur un système unix standard car il est au format UC-16, donc convertissez-le en texte ordinaire

iconv -f utf-16 PK.uc16 > PK.txt

Maintenant, supprimez l'en-tête qui dit quelque chose comme


Dump Variable pk
Variable NV+RT+BS 'Efi:PK' DataSize = 2DA

Laissant uniquement le dump hexadécimal. Ceci peut ensuite être converti en une liste de signatures EFI par xxd

xxd -r PK.txt > PK.esl

et vous pouvez maintenant extraire des certificats lisibles par openssl à partir de ceci

sig-list-to-certs PK.esl PK

Ce qui imprimera des informations telles que


X509 Header sls=730, header=0, sig=686
file PK.0: Guid 77fa9abd-0359-4d32-4d60-28f4e78f784b
Written 686 bytes

Et enfin, vous pouvez voir le certificat en format texte

openssl x509 -text -inform DER -in PK.0

En supposant qu'il s'agit d'un certificat X509
