SIG2DOT(1) Manuel des commandes générales SIG2DOT(1)

NOM

sig2dot - crée un fichier .dot à partir d'une liste de signatures GPG

SYNTAXE

sig2dot [OPTIONS] < fichier-entrée > fichier-sortie

DESCRIPTION

Cette page de manuel documente brièvement la commande sig2dot. Sig2dot analyse la sortie de "gpg --list-sigs" et produit un fichier .dot qui peut être utilisé comme entrée pour un programme de graphe.

OPTIONS

sig2dot accepte les options suivantes :

-b
Noir et blanc / ne pas coloriser.
-d <date>
Représenter le graphe tel qu'il apparaissait à la <date> (ignore les signatures plus récentes). La date doit être au format "AAAA-MM-JJ". Ignorera également les clés qui ont été révoquées depuis.
-s <nom-fichier-html>
Produit un fichier de statistiques HTML trié avec le nombre de signatures par nœud.
-a
Graphes de toutes les clés, même si elles n'ont pas de signature
-r <chaine-cle-revoquee>
Définit le texte pour la chaîne de clé révoquée utilisée par GnuPG. La valeur par défaut est celle utilisée dans la version anglaise. Ce paramètre peut être défini pour les versions de GnuPG localisées dans d'autres langues. Par défaut : "[revoked".
-t <titre>
Définit le titre du graphe généré. Par défaut : "Statistiques de l'anneau de clés".
-u <chaine-utilisateur-introuvable>
Définit le texte pour la chaîne d'utilisateur introuvable utilisée par GnuPG. La valeur par défaut est celle utilisée dans la version anglaise. Ce paramètre peut être défini pour les versions de GnuPG localisées dans d'autres langues. Par défaut : "[user id not found]".
-q
Soyez silencieux.
-h
Afficher l'aide et quitter.
-v
Afficher la version et quitter.

EXEMPLE

gpg --list-sigs | sig2dot > sigs.dot

springgraph < sigs.dot > sigs.png

VOIR AUSSI

springgraph(1) gnupg(1)
