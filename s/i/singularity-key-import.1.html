NOM

apptainer-key-import - Importer une clé locale dans le trousseau local ou global

SYNTAXE

apptainer key import [options d'importation...]

DESCRIPTION

La commande 'key import' vous permet d'ajouter une clé à votre trousseau local ou global depuis un fichier spécifique.

OPTIONS

-g, --global[=false] gérer les clés publiques globales (les importations/téléchargements/suppressions sont restreints à l'utilisateur root ou à l'installation sans privilèges uniquement)

-h, --help[=false] aide pour l'importation

-d, --keysdir="/build/.apptainer/keys" définir le chemin du répertoire du trousseau local, une autre façon est de définir la variable d'environnement 'APPTAINER_KEYSDIR'

--new-password[=false] définir un nouveau mot de passe pour la clé privée

EXEMPLE

  $ apptainer key import ./ma-cle.asc
  # Importer dans le trousseau global (utilisateur root uniquement)
  $ apptainer key import --global ./ma-cle.asc
