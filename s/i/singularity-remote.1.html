NOM

apptainer-remote - Gérer les points d'extrémité distants d'Apptainer

SYNTAXE

apptainer remote [options_distantes...]

DESCRIPTION

La commande 'remote' vous permet de gérer les points d'extrémité distants d'Apptainer via
ses sous-commandes.

Un 'point d'extrémité distant' est un groupe de services compatible avec l'API
de la bibliothèque de conteneurs. Le point d'extrémité distant est une adresse unique,
par exemple 'cloud.example.com', via laquelle les services de bibliothèque et/ou de chambre forte
seront automatiquement découverts.

Pour configurer un point d'extrémité distant, vous devez l'ajouter avec 'remote add'. Vous pouvez vous connecter avec 'remote login' si
vous allez effectuer des actions nécessitant une authentification. Basculez entre
les points d'extrémité distants configurés avec la commande 'remote use'. Le point d'extrémité distant actif
sera utilisé pour les opérations de clé, et les opérations de téléchargement et d'envoi
'library://'. Vous pouvez également vous déconnecter de 'remote logout' et supprimer un point d'extrémité
'remote remove' qui n'est plus requis.

La configuration distante est stockée par défaut dans $HOME/.apptainer/remotes.yaml.

OPTIONS

-c, --config="/build/.apptainer/remote.yaml" chemin vers le fichier contenant les configurations des points d'extrémité distants

-h, --help[=false] aide pour remote

EXEMPLE

  Toutes les commandes de groupe ont leur propre aide :
    $ apptainer help remote list
    $ apptainer remote list
