NOM

apptainer-cache-clean - Nettoyer le cache local d'Apptainer

SYNTAXE

apptainer cache clean [options de nettoyage...]

DESCRIPTION

Cela nettoiera votre cache local (stocké dans $HOME/.apptainer/cache si
APPTAINER_CACHEDIR n'est pas défini). Par défaut, tout le cache est nettoyé ; utilisez
les options --days et --type pour modifier ce comportement. Notez : si vous utilisez Apptainer
en tant que root, le cache sera stocké dans '/root/.apptainer/.cache'. Pour nettoyer ce
cache, vous devrez exécuter 'cache clean' en tant que root, ou avec 'sudo'.

OPTIONS

-D, --days=0 Supprime toutes les entrées du cache plus anciennes que le nombre de jours spécifié

-n, --dry-run[=false] Opère en mode simulation et ne nettoie pas réellement le cache

-f, --force[=false] Supprime toutes les invites et nettoie le cache

-h, --help[=false] Aide pour la commande clean

-T, --type=[all] Une liste des types de cache à nettoyer (valeurs possibles : library, oci, shub, blob, net, oras, all)

EXEMPLE

  Toutes les commandes de groupe ont leur propre aide :
  $ apptainer help cache clean --days 30
  $ apptainer help cache clean --type=library,oci
  $ apptainer cache clean --help
