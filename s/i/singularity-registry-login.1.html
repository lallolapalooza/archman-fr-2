NOM

apptainer-registry-login - Se connecter à un registre OCI/Docker

SYNTAXE

apptainer registry login [options de connexion...]

DESCRIPTION

La commande 'registry login' vous permet de vous connecter à un registre OCI/Docker spécifique.

OPTIONS

--authfile="" Fichier d'authentification style Docker à utiliser pour écrire/lire les identifiants du registre OCI

-h, --help[=false] aide pour login

-p, --password="" mot de passe / jeton pour s'authentifier

--password-stdin[=false] prendre le mot de passe depuis l'entrée standard

-u, --username="" nom d'utilisateur pour s'authentifier (requis pour la connexion au registre Docker/OCI)

EXEMPLE

  Pour vous connecter à un registre docker/OCI :
  $ apptainer registry login --username foo docker://docker.io
  $ apptainer registry login --username foo oras://myregistry.example.com
  Notez que de nombreux registres OCI cloud utilisent une authentification par jeton. Le jeton
  doit être spécifié comme mot de passe pour la connexion. Un nom d'utilisateur est toujours requis.
  Par exemple, lors de l'utilisation d'une identité et d'un jeton Azure standard pour se connecter à un registre ACR 
  , le nom d'utilisateur '00000000-0000-0000-0000-000000000000' est requis.
  Consultez la documentation de votre fournisseur pour les détails concernant leurs exigences de connexion spécifiques.
