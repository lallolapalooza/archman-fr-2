siginterrupt(3) Manuel des fonctions de bibliothèque siginterrupt(3)

NOM

siginterrupt - autoriser les signaux à interrompre les appels système

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <signal.h>
[[deprecated]] int siginterrupt(int sig, int flag);
Exigences des macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

siginterrupt():

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.12 : */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19 : */ _BSD_SOURCE

DESCRIPTION

La fonction siginterrupt() modifie le comportement de redémarrage lorsqu'un appel système est interrompu par le signal sig. Si l'argument flag est faux (0), les appels système seront redémarrés s'ils sont interrompus par le signal spécifié sig. C'est le comportement par défaut sous Linux.

Si l'argument flag est vrai (1) et qu'aucun donnée n'a été transférée, un appel système interrompu par le signal sig retournera -1 et errno sera défini à EINTR.

Si l'argument flag est vrai (1) et que le transfert de données a commencé, l'appel système sera interrompu et retournera la quantité réelle de données transférées.

VALEUR DE RETOUR

La fonction siginterrupt() retourne 0 en cas de succès. Elle retourne -1 si le numéro de signal sig est invalide, avec errno défini pour indiquer l'erreur.

ERREURS

EINVAL
Le numéro de signal spécifié est invalide.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
siginterrupt () Sécurité des threads MT-Unsafe const:sigintr

NORMES

POSIX.1-2008.

HISTORIQUE

4.3BSD, POSIX.1-2001. Obsolète dans POSIX.1-2008, qui recommande l'utilisation de sigaction(2) avec le drapeau SA_RESTART à la place.

VOIR AUSSI

signal(2)
