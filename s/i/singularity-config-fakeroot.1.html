NOM

apptainer-config-fakeroot - Gérer les entrées de mappage fakeroot d'utilisateur (utilisateur root uniquement)

SYNTAXE

apptainer config fakeroot

DESCRIPTION

La commande config fakeroot permet à un utilisateur root d'ajouter/supprimer/activer/désactiver les mappages d'utilisateurs fakeroot.

OPTIONS

-a, --add[=false] ajouter une entrée de mappage fakeroot pour un utilisateur lui permettant d'utiliser la fonctionnalité fakeroot

-d, --disable[=false] désactiver une entrée de mappage fakeroot d'un utilisateur l'empêchant d'utiliser la fonctionnalité fakeroot (le mappage de l'utilisateur doit être présent)

-e, --enable[=false] activer une entrée de mappage fakeroot d'un utilisateur lui permettant d'utiliser la fonctionnalité fakeroot (le mappage de l'utilisateur doit être présent)

-h, --help[=false] aide pour fakeroot

-r, --remove[=false] supprimer l'entrée de mappage fakeroot d'un utilisateur l'empêchant d'utiliser la fonctionnalité fakeroot

EXEMPLE

  Pour ajouter un mappage d'utilisateur fakeroot pour l'utilisateur vagrant :
  $ apptainer config fakeroot --add vagrant
  Pour supprimer un mappage d'utilisateur fakeroot pour l'utilisateur vagrant :
  $ apptainer config fakeroot --remove vagrant
  Pour désactiver un mappage d'utilisateur fakeroot pour l'utilisateur vagrant :
  $ apptainer config fakeroot --disable vagrant
  Pour activer un mappage d'utilisateur fakeroot pour l'utilisateur vagrant :
  $ apptainer config fakeroot --enable vagrant
