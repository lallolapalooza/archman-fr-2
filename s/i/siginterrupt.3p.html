SIGINTERRUPT(3P) Manuel du programmeur POSIX SIGINTERRUPT(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

siginterrupt — autoriser les signaux à interrompre les fonctions

SYNTAXE

#include <signal.h>
int siginterrupt(int sig, int flag);

DESCRIPTION

La fonction siginterrupt() modifie le comportement de redémarrage lorsqu'une fonction est interrompue par le signal spécifié. La fonction siginterrupt(sig, flag) a un effet comme si elle était implémentée comme suit :

int siginterrupt(int sig, int flag) {
    int ret;
    struct sigaction act;
    (void) sigaction(sig, NULL, &act);
    if (flag)
        act.sa_flags &= ~SA_RESTART;
    else
        act.sa_flags |= SA_RESTART;
    ret = sigaction(sig, &act, NULL);
    return ret;
}

VALEUR DE RETOUR

En cas de succès, siginterrupt() retourne 0 ; sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction siginterrupt() échoue si :

EINVAL
L'argument sig n'est pas un numéro de signal valide.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

La fonction siginterrupt() prend en charge les programmes écrits pour les interfaces système historiques. Les applications doivent utiliser sigaction() avec le drapeau SA_RESTART au lieu de la fonction obsolète siginterrupt().
