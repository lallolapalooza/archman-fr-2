NOM

apptainer-inspect - Afficher les métadonnées d'une image

SYNTAXE

apptainer inspect [options d'inspection...]

DESCRIPTION

Inspect vous montrera les étiquettes, variables d'environnement, applications et scripts associés
à l'image déterminée par les drapeaux que vous passez. Par défaut, ils seront affichés en
texte brut. Si vous souhaitez les lister au format json, vous devez utiliser l'option --json.

OPTIONS

--all[=false] afficher toutes les données disponibles (implique l'option --json)

--app="" inspecter une application spécifique

-d, --deffile[=false] afficher le fichier de définition Apptainer qui a été utilisé pour générer l'image

-e, --environment[=false] afficher les paramètres d'environnement pour l'image

-h, --help[=false] aide pour inspect

-H, --helpfile[=false] inspecter le fichier d'aide du script d'exécution, s'il existe

-j, --json[=false] afficher du json structuré au lieu de sections

-l, --labels[=false] afficher les étiquettes de l'image
(par défaut)

--list-apps[=false] lister toutes les applications dans un conteneur

-r, --runscript[=false] afficher le script d'exécution de l'image

-s, --startscript[=false] afficher le script de démarrage de l'image

-t, --test[=false] afficher le script de test de l'image

EXEMPLE

  $ apptainer inspect ubuntu.sif
  Si vous voulez lister les applications (apps) installées dans un conteneur (situé à
  /scif/apps), vous devez exécuter la commande inspect avec le drapeau --list-apps <image-conteneur>.
  ( Voir https://sci-f.github.io pour plus d'informations sur les applications SCIF)
  Les variables d'environnement suivantes vous sont disponibles lorsqu'elles sont appelées
  depuis le shell à l'intérieur du conteneur. Les variables supérieures sont pertinentes
  pour l'application active (--app <app>) et les variables inférieures sont disponibles pour toutes les applications
  indépendamment de l'application active. Les deux ensembles de variables sont également disponibles pendant le développement (au moment de la construction).
  ENVIRONNEMENT DE L'APPLICATION ACTIVE :
      SCIF_APPNAME       le nom de l'application active
      SCIF_APPROOT       le dossier d'installation de l'application créé à /scif/apps/<app>
      SCIF_APPMETA       le dossier des métadonnées de l'application
      SCIF_APPDATA       le dossier de données créé pour l'application à /scif/data/<app>
        SCIF_APPINPUT    dossier d'entrée attendu dans la base de données des dossiers
        SCIF_APPOUTPUT   le dossier de sortie des données dans la base de données des dossiers
      SCIF_APPENV        pointe vers le fichier environment.sh personnalisé de l'application dans son dossier de métadonnées
      SCIF_APPLABELS     est le fichier labels.json de l'application dans le dossier des métadonnées
      SCIF_APPBIN        est le dossier bin de l'application, qui est automatiquement ajouté au $PATH lorsque l'application est active
      SCIF_APPLIB        est le dossier des bibliothèques de l'application qui est ajouté au LD_LIBRARY_PATH
      SCIF_APPRUN        est le script d'exécution
      SCIF_APPSTART      est le script de démarrage
      SCIF_APPHELP       est le fichier d'aide pour le script d'exécution
      SCIF_APPTEST       est le script de test (test.sh) associé à l'application
      SCIF_APPNAME       le nom de l'application active
      SCIF_APPFILES      la section files associée à l'application qui est ajoutée à
  ENVIRONNEMENT GLOBAL DES APPLICATIONS :
      SCIF_DATA             base de données définie par scif pour toutes les applications (/scif/data)
      SCIF_APPS             bases d'installation définies par scif pour toutes les applications (/scif/apps)
      SCIF_APPROOT_<app>    racine pour l'application <app>
      SCIF_APPDATA_<app>    racine des données pour l'application <app>
  Pour lister toutes vos applications :
  $ apptainer inspect --list-apps ubuntu.sif
  Pour lister uniquement les étiquettes au format json d'une image :
  $ apptainer inspect --json --labels ubuntu.sif
  Pour vérifier que vous possédez une seule application sur votre image de conteneur, utilisez le drapeau --app <nom_application> :
  $ apptainer inspect --app <nom_application> ubuntu.sif
