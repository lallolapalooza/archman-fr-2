NOM

apptainer-instance-stop - Arrête une instance nommée d'une image de conteneur donnée

SYNOPIS

apptainer instance stop [options d'arrêt...] [instance]

DESCRIPTION

La commande apptainer instance stop vous permet d'arrêter et de nettoyer une instance nommée,
en cours d'exécution d'une image de conteneur donnée.

OPTIONS

-a, --all[=false] arrête toutes les instances de l'utilisateur

-F, --force[=false] force l'arrêt de l'instance

-h, --help[=false] aide pour l'arrêt

-s, --signal="" signal envoyé à l'instance

-t, --timeout=10 force l'arrêt des instances non arrêtées après X secondes

-u, --user="" si exécuté en tant que root, arrête les instances appartenant à l'utilisateur

EXEMPLE

  $ apptainer instance start my-sql.sif mysql1
  $ apptainer instance start my-sql.sif mysql2
  $ apptainer instance stop mysql*
  Arrêt de l'instance mysql1 de my-sql.sif (PID=23845)
  Arrêt de l'instance mysql2 de my-sql.sif (PID=23858)
  $ apptainer instance start my-sql.sif mysql1
  Force l'arrêt de l'instance
  $ apptainer instance stop -f mysql1 (peut corrompre les données)
  Envoi de SIGTERM à l'instance
  $ apptainer instance stop -s SIGTERM mysql1
  $ apptainer instance stop -s TERM mysql1
  $ apptainer instance stop -s 15 mysql1
