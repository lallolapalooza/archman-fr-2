sigtrap(3perl) Guide du programmeur Perl sigtrap(3perl)

NOM

sigtrap - Pragma Perl pour activer la gestion simple des signaux

SYNOPHIS

use sigtrap;
use sigtrap qw(stack-trace old-interface-signals);  # équivalent
use sigtrap qw(BUS SEGV PIPE ABRT);
use sigtrap qw(die INT QUIT);
use sigtrap qw(die normal-signals);
use sigtrap qw(die untrapped normal-signals);
use sigtrap qw(die untrapped normal-signals
                stack-trace any error-signals);
use sigtrap 'handler' => \&my_handler, 'normal-signals';
use sigtrap qw(handler my_handler normal-signals
                stack-trace error-signals);

DESCRIPTION

Le pragma sigtrap est une interface simple pour installer des gestionnaires de signaux. Vous pouvez lui demander d'installer l'un des deux gestionnaires fournis par sigtrap lui-même (l'un qui fournit une trace de pile Perl et l'autre qui se contente de faire die()), ou alternativement, vous pouvez fournir votre propre gestionnaire à installer. Il peut être configuré pour installer un gestionnaire uniquement pour les signaux qui ne sont pas déjà interceptés ou qui sont ignorés. Il dispose de trois listes de signaux à intercepter, et vous pouvez également fournir votre propre liste de signaux.

Les arguments passés à l'instruction "use" qui invoque sigtrap sont traités dans l'ordre. Lorsqu'un nom de signal ou le nom d'une des listes de signaux de sigtrap est rencontré, un gestionnaire est immédiatement installé ; lorsqu'une option est rencontrée, elle affecte les gestionnaires installés ultérieurement.

OPTIONS

GESTIONNAIRES DE SIGNAL

Ces options affectent le gestionnaire qui sera utilisé pour les signaux installés ultérieurement.

stack-trace
Le gestionnaire utilisé pour les signaux installés ultérieurement affiche une trace de pile Perl sur STDERR puis tente de générer un core dump. C'est le gestionnaire de signal par défaut.
die
Le gestionnaire utilisé pour les signaux installés ultérieurement appelle "die" (en fait "croak") avec un message indiquant quel signal a été capturé.
handler votre-gestionnaire
votre-gestionnaire sera utilisé comme gestionnaire pour les signaux installés ultérieurement. votre-gestionnaire peut être toute valeur valide pour une assignation à un élément de %SIG. Voir perlvar pour des exemples de fonctions gestionnaires.

LISTES DE SIGNAL

sigtrap dispose de quelques listes intégrées de signaux à intercepter. Ce sont :

normal-signals
Ce sont les signaux qu'un programme peut normalement s'attendre à rencontrer et qui provoquent par défaut son arrêt. Ce sont HUP, INT, PIPE et TERM.
error-signals
Ces signaux indiquent généralement un problème grave avec l'interpréteur Perl ou avec votre script. Ce sont ABRT, BUS, EMT, FPE, ILL, QUIT, SEGV, SYS et TRAP.
old-interface-signals
Ce sont les signaux qui étaient interceptés par défaut par l'ancienne interface sigtrap ; ce sont ABRT, BUS, EMT, FPE, ILL, PIPE, QUIT, SEGV, SYS, TERM, et TRAP. Si aucun signal ou aucune liste de signaux n'est transmis à sigtrap, cette liste est utilisée.

Pour chacune de ces trois listes, l'ensemble des signaux définis pour être interceptés est vérifié avant l'interception ; si votre architecture n'implémente pas un signal particulier, il ne sera pas intercepté mais sera silencieusement ignoré.

AUTRES

untrapped
Ce jeton indique à sigtrap d'installer des gestionnaires uniquement pour les signaux listés ultérieurement qui ne sont pas déjà interceptés ou ignorés.
any
Ce jeton indique à sigtrap d'installer des gestionnaires pour tous les signaux listés ultérieurement. C'est le comportement par défaut.
signal
Tout argument qui ressemble à un nom de signal (c'est-à-dire, "/^[A-Z][A-Z0-9]*$/") indique que sigtrap doit installer un gestionnaire pour ce nom.
nombre
Exige qu'au moins la version nombre de sigtrap soit utilisée.

EXEMPLES

Fournir une trace de pile pour les old-interface-signals :

use sigtrap;

Idem :

use sigtrap qw(stack-trace old-interface-signals);

Fournir une trace de pile uniquement sur les 4 signaux listés :

use sigtrap qw(BUS SEGV PIPE ABRT);

Faire die sur INT ou QUIT :

use sigtrap qw(die INT QUIT);

Faire die sur HUP, INT, PIPE ou TERM :

use sigtrap qw(die normal-signals);

Faire die sur HUP, INT, PIPE ou TERM, mais ne pas modifier le comportement pour les signaux déjà interceptés ou ignorés :

use sigtrap qw(die untrapped normal-signals);

Faire die à la réception de l'un des normal-signals qui est actuellement untrapped, fournir une trace de pile à la réception de l'un des error-signals :

use sigtrap qw(die untrapped normal-signals
                stack-trace any error-signals);

Installer my_handler() comme gestionnaire pour les normal-signals :

use sigtrap 'handler', \&my_handler, 'normal-signals';

Installer my_handler() comme gestionnaire pour les normal-signals, fournir une trace de pile Perl lors de la réception de l'un des error-signals :

use sigtrap qw(handler my_handler normal-signals
                stack-trace error-signals);
