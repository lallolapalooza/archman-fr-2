sinh(3) Manuel des fonctions de bibliothèque sinh(3)

NOM

sinh, sinhf, sinhl - fonction sinus hyperbolique

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double sinh(double x);
float sinhf(float x);
long double sinhl(long double x);
Exigences relatives aux macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

sinhf(), sinhl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions renvoient le sinus hyperbolique de x, qui est défini mathématiquement comme suit :

    sinh(x) = (exp(x) - exp(-x)) / 2

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient le sinus hyperbolique de x.

Si x est un NaN, un NaN est renvoyé.

Si x est +0 (-0), +0 (-0) est renvoyé.

Si x est l'infini positif (infini négatif), l'infini positif (infini négatif) est renvoyé.

Si le résultat déborde, une erreur de plage se produit et les fonctions renvoient HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement, avec le même signe que x.

ERREURS

Voir math_error(7) pour plus d'informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de plage : débordement du résultat
errno est défini à ERANGE. Une exception à virgule flottante de débordement (FE_OVERFLOW) est levée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
sinh (), sinhf (), sinhl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante renvoyant double est également conforme à SVr4, 4.3BSD, C89.

VOIR AUSSI

acosh(3), asinh(3), atanh(3), cosh(3), csinh(3), tanh(3)
