sile(1) Manuel des commandes générales sile(1)

NOM

sile - Le moteur de composition de Simon, amélioré

SYNTAXE

sile [options] [ENTRÉE]

DESCRIPTION

Le compositeur SILE lit les fichiers d'entrée et compose le contenu dans un format de document rendu, typiquement le PDF.

Par défaut, les fichiers d'entrée peuvent être en balisage SIL déclaratif, en XML structuré ou en Lua programmatique. Le format d'entrée est détecté automatiquement par les modules actifs. Par défaut, la sortie sera un fichier portant le même nom que le premier fichier d'entrée, avec l'extension changée en .pdf. Le nom du fichier de sortie peut être remplacé par l'argument --output. En utilisant --backend, on peut passer à un format de sortie différent (ou à un pilote différent pour le même format). Des formats d'entrée ou de sortie supplémentaires peuvent être gérés en chargeant un module tiers qui les prend en charge en ajoutant l'argument --use sur la ligne de commande (qui sera chargé avant de tenter de lire les documents d'entrée).

OPTIONS

-b, --backend=valeur
Spécifie le backend de sortie.
La valeur par défaut est libtexpdf et convient à la plupart des sorties PDF. Les alternatives prises en charge nativement incluent text, debug, dummy, cairo et podofo. D'autres générateurs peuvent être activés via --use.
-c, --class=valeur
Remplace la classe de document par défaut ou spécifiée.
La classe par défaut pour les documents qui n'en spécifient pas dans la balise racine est plain. Ceci peut être utilisé pour changer la classe par défaut ou pour remplacer la classe réellement spécifiée dans un document. Les autres classes groupées incluent base, bible, book, diglot, docbook, docbook, jbook, jplain, letter, pecha, tbook, tplain et triglot. D'autres seront chargés dynamiquement à partir du chemin des modules.
-d, --debug=valeur[,valeur]
Affiche des informations de débogage pour les aspects étiquetés de l'opération de SILE.
Plusieurs indicateurs de débogage peuvent être donnés sous forme de liste séparée par des virgules. Bien que les paquets puissent définir leurs propres indicateurs de débogage, les plus couramment utilisés sont typesetter, pagebuilder, vboxes, break, frames, profile et versions. Peut être spécifié plusieurs fois.
-e, --evaluate=valeur
Évalue une expression Lua avant de traiter l'entrée.
Peut être spécifié plusieurs fois.
-E, --evaluate-after=valeur
Évalue une expression Lua après le traitement de l'entrée.
Peut être spécifié plusieurs fois.
-f, --fontmanager=valeur
Spécifie quel gestionnaire de polices utiliser.
Le gestionnaire de polices est responsable de la découverte des emplacements des fichiers de polices sur le système à partir d'un nom de police. Le gestionnaire de polices par défaut est fontconfig sur les systèmes non-macOS et macfonts sur macOS.
-m, --makedepsfichier
Génère une liste de dépendances au format Makefile.
Ceci suit tous les fichiers (fichiers d'entrée, bibliothèques Lua, polices, images, etc.) utilisés pendant le processus de composition. Après achèvement, la liste est écrite dans FICHIER au format d'une liste de dépendances pour une cible dans un Makefile. Ceci peut être utilisé plus tard pour déterminer si un PDF doit être ré-rendu en fonction de si des entrées ont été modifiées.
-o, --output=fichier
Définit explicitement le nom du fichier de sortie.
Par défaut, le nom de base du premier fichier d'entrée sera utilisé comme nom de fichier de sortie. Une extension sera choisie en fonction du backend de sortie, généralement .pdf. Avec cette option, n'importe quel nom et chemin arbitraire peuvent être donnés. De plus, - peut être utilisé pour écrire la sortie sur STDOUT.
-O, --options=paramètre=valeur[,paramètre=valeur]
Définit ou remplace les options de la classe de document.
Peut être utilisé pour changer les options par défaut ou pour remplacer celles spécifiées dans un document. Par exemple, définir --options papersize=letter remplacerait à la fois l'option par défaut papersize de A4 et toute option spécifique définie dans les options du document. Peut être spécifié plusieurs fois.
-I, --include=nom_fichier
Obsolète, utiliser --use, --preamble, --postamble, ou plusieurs fichiers d'entrée.
-p, --preamble=nom_fichier
Inclut le contenu d'un fichier SIL, XML ou autre ressource avant le contenu du document d'entrée.
La valeur doit être un nom de fichier complet avec un chemin relatif au répertoire courant ou un chemin absolu. Peut être spécifié plusieurs fois.
-P, --postamble=nom_fichier
Inclut le contenu d'un fichier SIL, XML ou autre ressource après le contenu du document d'entrée.
La valeur doit être un nom de fichier complet avec un chemin relatif au répertoire courant ou un chemin absolu. Peut être spécifié plusieurs fois.
-u, --use=module[[paramètre=valeur[,paramètre=valeur]]]
Charge et initialise une classe, un module d'entrée, un module de mise en forme ou autre avant de traiter l'entrée principale.
La valeur doit être le nom d'un module chargeable (sans extension, utilisant '.' comme séparateur de chemin) et sera chargé en utilisant le chemin de recherche de modules de SILE. Des options peuvent être passées au module en entourant les paires clé=valeur entre crochets suivant le nom du module. Ceci est particulièrement utile lorsque le document d'entrée n'est pas SIL ou un schéma XML reconnu nativement et que SILE doit être instruit avant même de tenter de lire le fichier d'entrée. Si le module est une classe de document, il remplacera plain comme classe par défaut pour traiter les documents qui n'en spécifient pas explicitement une à utiliser. Comme cela s'exécute avant le chargement du document, cela peut même ajouter un analyseur d'entrée ou en modifier un existant pour prendre en charge de nouveaux formats de fichiers. Les modules de paquets seront ajoutés au préambule pour être chargés après l'initialisation de la classe. Peut être spécifié plusieurs fois.
-q, --quiet
Supprime les avertissements et les messages d'information pendant le traitement.
-t, --traceback
Affiche une trace de localisation détaillée en cas d'erreurs et d'avertissements.
[ENTRÉE]
Nom(s) du fichier du document d'entrée, par défaut au format SIL, XML ou Lua.
Un ou plusieurs fichiers d'entrée à partir desquels traiter le contenu. Le premier fichier listé est considéré comme le document maître, les autres sont traités en séquence. D'autres formats d'entrée peuvent être activés via --use. Utiliser - pour lire un flux de contenu depuis STDIN.
-h, --help
Affiche le message d'aide et quitte.
-v, --version
Affiche la version.
