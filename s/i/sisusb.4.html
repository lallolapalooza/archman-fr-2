NOM

sisusb - Pilote vidéo USB SiS

SYNTAXE

Section "Device"
  Identifier "nomdev"
  Driver "sisusb"
  ...
EndSection

DESCRIPTION

sisusb est un pilote Xorg pour les puces vidéo SiS (Silicon Integrated Systems) connectées via un dongle USB basé sur Net2280. Le pilote n'est pas accéléré, mais fournit une prise en charge des profondeurs de couleur de 8, 16 et 24 bpp, ainsi que de Render et d'autres extensions.

MATERIEL SUPPORTÉ

Le pilote sisusb prend en charge les cartes vidéo USB basées sur les chipsets suivants :

SiS315E/PRO

Le SiS315E/PRO dispose de deux contrôleurs CRT. Cependant, dans sa version USB, seule la première sortie, appelée "CRT1", est utilisée.

DÉTAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails de configuration généraux et à sis(4) pour plus d'informations. Cette page de manuel ne couvre qu'un sous-ensemble des options prises en charge.

Des informations détaillées sur toutes les options prises en charge sont disponibles sur http://www.winischhofer.at/linuxsisusbvga.shtml

Veuillez noter que ce pilote nécessite également un pilote de noyau Linux qui est inclus dans Linux 2.6.12 et versions ultérieures, ainsi que disponible sur le site Web susmentionné.

Les Options de pilote suivantes sont prises en charge :

Option "HWCursor" "booléen"
Active ou désactive le curseur matériel. Il n'est pas recommandé de désactiver le curseur matériel car cela augmentera la quantité de données transférées sur l'USB. Par défaut : HWCursor est activé.
Option "SWCursor" "booléen"
L'inverse de HWCursor. Cela active ou désactive le curseur logiciel. Ce type de curseur est plus lent car le pointeur doit être peint dans l'affichage graphique. Cela augmente considérablement la quantité de données transférées sur l'USB. Par défaut : SWCursor est désactivé.
Option "CRT1Gamma" "booléen"
Active ou désactive la correction gamma. Par défaut : la correction gamma est activée.
Option "DisconnectTimeout" "entier"
Cette option détermine la façon dont le pilote réagit à la déconnexion du périphérique USB. Si l'entier fourni est -1, le pilote interrompra le serveur X immédiatement après la déconnexion. Si la valeur donnée est 0, le pilote recherchera une reconnexion toutes les 2 secondes et, si le périphérique est détecté, rétablira l'affichage. Si la valeur est supérieure à 0, le pilote effectuera cette re-recherche dans le nombre de secondes donné et interrompra le serveur s'il ne détecte pas le périphérique dans ce délai d'attente. Par défaut : 0 (recherche la reconnexion du périphérique indéfiniment).
