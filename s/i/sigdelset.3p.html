SIGDELSET(3P) Manuel du programmeur POSIX SIGDELSET(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

sigdelset — supprimer un signal d'un ensemble de signaux

SYNTAXE

#include <signal.h>
int sigdelset(sigset_t *set, int signo);

DESCRIPTION

La fonction sigdelset() supprime le signal individuel spécifié par signo de l'ensemble de signaux pointé par set.

Les applications doivent appeler soit sigemptyset() soit sigfillset() au moins une fois pour chaque objet de type sigset_t avant toute autre utilisation de cet objet. Si un tel objet n'est pas initialisé de cette manière, mais qu'il est néanmoins fourni comme argument à l'une des fonctions pthread_sigmask(), sigaction(), sigaddset(), sigdelset(), sigismember(), sigpending(), sigprocmask(), sigsuspend(), sigtimedwait(), sigwait() ou sigwaitinfo(), les résultats sont indéfinis.

VALEUR DE RETOUR

En cas de succès, sigdelset() renvoie 0 ; sinon, elle renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction sigdelset() peut échouer si :

EINVAL
L'argument signo n'est pas un numéro de signal valide, ou est un numéro de signal non pris en charge.
