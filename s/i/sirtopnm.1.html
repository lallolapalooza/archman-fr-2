NOM

sirtopnm - convertir un fichier Solitaire en PNM

SYNTAXE

sirtopnm

[sirfile]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

sirtopnm lit un fichier Solitaire Image Recorder en entrée et produit une image PNM en sortie. Le type du fichier de sortie dépend du fichier d'entrée - s'il s'agit d'un fichier MGI TYPE 17, sirtopnm génère un fichier PGM. S'il s'agit d'un fichier MGI TYPE 11, sirtopnm génère un PPM. Le programme vous indique le type qu'il écrit.
