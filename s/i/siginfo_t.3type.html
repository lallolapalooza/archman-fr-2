NOM

system_data_types - aperçu des types de données système

DESCRIPTION

siginfo_t
Inclure : <signal.h>. Alternativement, <sys/wait.h>. 
typedef struct {
    int      si_signo;  /* Numéro du signal */
    int      si_code;   /* Code du signal */
    pid_t    si_pid;    /* Identifiant du processus émetteur */
    uid_t    si_uid;    /* Identifiant utilisateur réel du processus émetteur */
    void    *si_addr;   /* Emplacement mémoire qui a causé l'échec */
    int      si_status; /* Valeur de sortie ou signal */
    union sigval si_value;  /* Valeur du signal */
} siginfo_t;

Informations associées à un signal. Pour plus de détails sur cette structure (y compris des champs supplémentaires spécifiques à Linux), voir sigaction(2).

Conforme à : POSIX.1-2001 et versions ultérieures.

Voir aussi : pidfd_send_signal(2), rt_sigqueueinfo(2), sigaction(2), sigwaitinfo(2), psiginfo(3)

sigset_t
Inclure : <signal.h>. Alternativement, <spawn.h>, ou <sys/select.h>.

Ceci est un type qui représente un ensemble de signaux. Selon POSIX, ce doit être un type entier ou une structure.

Conforme à : POSIX.1-2001 et versions ultérieures.

Voir aussi : epoll_pwait(2), ppoll(2), pselect(2), sigaction(2), signalfd(2), sigpending(2), sigprocmask(2), sigsuspend(2), sigwaitinfo(2), signal(7)

NOTES

Les structures décrites dans cette page de manuel doivent contenir, au minimum, les membres indiqués dans leur définition, sans ordre particulier.

La plupart des types entiers décrits dans cette page n'ont pas de modificateur de longueur correspondant pour les fonctions des familles printf(3) et scanf(3). Pour imprimer une valeur d'un type entier qui n'a pas de modificateur de longueur, elle doit être convertie en intmax_t ou uintmax_t par un transtypage explicite. Pour lire dans une variable d'un type entier qui n'a pas de modificateur de longueur, une variable temporaire intermédiaire de type intmax_t ou uintmax_t doit être utilisée. Lors de la copie de la variable temporaire vers la variable de destination, la valeur pourrait déborder. Si le type a des limites supérieure et inférieure, l'utilisateur doit vérifier que la valeur se trouve dans ces limites avant de copier effectivement la valeur. L'exemple ci-dessous montre comment ces conversions doivent être effectuées.

Conventions utilisées sur cette page

Dans la section "Conforme à", nous nous concentrons uniquement sur C99 et versions ultérieures, ainsi que POSIX.1-2001 et versions ultérieures. Certains types peuvent être spécifiés dans des versions antérieures d'une de ces normes, mais dans un souci de simplicité, nous omettons les détails des normes antérieures.

Dans la section "Inclure", nous notons d'abord les en-têtes "primaires" qui définissent le type selon les normes C ou POSIX.1. Sous "Alternativement", nous notons les en-têtes supplémentaires que les normes spécifient comme devant définir le type.

EXEMPLES

Le programme ci-dessous lit un nombre à partir d'une chaîne et imprime une valeur stockée dans une variable d'un type entier qui n'a pas de modificateur de longueur. Les conversions appropriées depuis et vers intmax_t, ainsi que les vérifications de plage appropriées, sont utilisées comme expliqué dans la section des notes ci-dessus.

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
int
main (void)
{
    static const char *const str = "500000 us en une demi-seconde";
    suseconds_t us;
    intmax_t    tmp;
    /* Lire le nombre à partir de la chaîne dans la variable temporaire.  */
    sscanf(str, "%jd", &tmp);
    /* Vérifier que la valeur est dans la plage valide de suseconds_t.  */
    if (tmp < -1 || tmp > 1000000) {
        fprintf(stderr, "Valeur lue hors de la plage valide !\n");
        exit(EXIT_FAILURE);
    }
    /* Copier la valeur dans la variable suseconds_t 'us'.  */
    us = tmp;
    /* Bien que suseconds_t puisse contenir la valeur -1, ce n'est pas
       un nombre de microsecondes raisonnable.  */
    if (us < 0) {
        fprintf(stderr, "La valeur lue ne devrait pas être négative !\n");
        exit(EXIT_FAILURE);
    }
    /* Afficher la valeur.  */
    printf("Il y a %jd microsecondes dans une demi-seconde.\n",
            (intmax_t) us);
    exit(EXIT_SUCCESS);
}
