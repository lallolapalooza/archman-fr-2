SIEGE.CONFIG(1) Utilitaire siege.config SIEGE.CONFIG(1)

NOM

siege.config - crée un modèle de siege.conf dans le répertoire personnel de l'utilisateur.

INTRODUCTION

Les paramètres par défaut de siege sont stockés dans $HOME/.siege/siege.conf. Cet utilitaire créera un nouveau siege.conf s'il n'existe pas déjà. De manière générale, vous ne devriez pas avoir à exécuter cette commande avec les versions de siege égales ou ultérieures à 4.0.0.

Au démarrage, siege vérifie l'existence de $HOME/.siege/siege.conf. Si aucun fichier n'existe, siege exécutera cette commande pour en créer un nouveau, puis lira ce fichier pour se configurer.

INVOCATION

Le format pour invoquer siege.config est le suivant :

siege.config [aucun argument]
