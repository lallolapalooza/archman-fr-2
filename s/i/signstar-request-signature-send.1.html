NOM

signstar-request-signature-send - Envoyer une demande de signature via SSH

SYNTAXE

signstar-request-signature send <--host> [--port] <--user> <--agent-socket> <--user-public-key> <--known-hosts> [-v|--verbose]... [-q|--quiet]... [-h|--help] <ENTRÉE>

DESCRIPTION

Envoyer une demande de signature via SSH

OPTIONS

--host <HÔTE>
Hôte Signstar
--port <PORT> [défaut : 22]
Port Signstar
--user <UTILISATEUR>
Utilisateur Signstar
--agent-socket <AGENT_SOCKET>
Chemin vers le socket de l'agent utilisé pour l'authentification de l'utilisateur
--user-public-key <CLÉ_PUBLIQUE_UTILISATEUR>
Clé publique d'un utilisateur
--known-hosts <KNOWN_HOSTS>
Chemin d'un fichier known_hosts contenant les clés publiques du serveur
-v, --verbose
Augmenter la verbosité des logs
-q, --quiet
Diminuer la verbosité des logs
-h, --help
Afficher l'aide
<ENTRÉE>
Le chemin d'un fichier à signer
Peut également être spécifié avec la variable d'environnement SIGNSTAR_REQUEST_FILE.
