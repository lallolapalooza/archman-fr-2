signbit(3) Manuel des fonctions de bibliothèque signbit(3)

NOM

signbit - teste le signe d'un nombre réel à virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNOPSIS

#include <math.h>
int signbit(x);
Conditions de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

signbit():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

signbit() est une macro générique qui peut fonctionner sur tous les types réels à virgule flottante. Elle renvoie une valeur non nulle si la valeur de x a son bit de signe défini.

Ce n'est pas la même chose que x < 0.0, car la virgule flottante IEEE 754 autorise que zéro soit signé. La comparaison -0.0 < 0.0 est fausse, mais signbit(-0.0) renverra une valeur non nulle.

Les NaN et les infinis ont un bit de signe.

VALEUR DE RETOUR

La macro signbit() renvoie une valeur non nulle si le signe de x est négatif ; sinon, elle renvoie zéro.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
signbit () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

Cette fonction est définie dans IEC 559 (et l'annexe avec les fonctions recommandées dans IEEE 754/IEEE 854).
