NOM

sieve-dump - Outil de vidage binaire de script Sieve de Pigeonhole

SYNTAXE

sieve-dump [options] sieve-binaire [fichier-sortie]

DESCRIPTION


La commande est une partie de Pigeonhole (pigeonhole(7)), qui ajoute le support de Sieve (RFC 5228) et ManageSieve (RFC 5804) à Dovecot (dovecot(1)).


La commande, les binaires Sieve, qui sont produits par exemple par sievec(1), peuvent être transformés en une représentation textuelle lisible par l'homme. Cela peut fournir un aperçu précieux de la manière dont le script Sieve est exécuté. Ceci est également particulièrement utile pour visualiser des binaires corrompus qui peuvent résulter de bugs dans l'implémentation de Sieve. Cet outil est principalement destiné à des fins de développement, donc normalement les administrateurs système et les utilisateurs n'auront pas besoin de l'utiliser.

Le format de la sortie n'est pas expliqué ici en détail, mais il devrait être relativement facile à comprendre. Les binaires Sieve comprennent un ensemble de blocs de données, chacun pouvant contenir des données arbitraires. Pour l'implémentation de base du langage, deux blocs sont utilisés : le premier contenant une spécification de toutes les extensions de langage requises et le second contenant le programme Sieve principal. Les programmes Sieve compilés sont représentés sous forme de code machine plat et par conséquent, le vidage du programme principal est une liste de désassemblage des opérations de l'interpréteur. Les extensions peuvent définir de nouvelles opérations et utiliser des blocs supplémentaires. Par conséquent, la sortie de sieve-dump dépend fortement des extensions de langage utilisées lors de la compilation du binaire.

OPTIONS

-c fichier-config

Chemin alternatif du fichier de configuration Dovecot.

-D

Activer le débogage Sieve.

-h

Produire une sortie hexdump par bloc de tout le binaire au lieu de la sortie normale lisible par l'homme.

-o parametre=valeur

Remplace le parametre de configuration de /etc/dovecot/dovecot.conf et de l'userdb par la valeur donnée. Pour remplacer plusieurs paramètres, l'option -o peut être spécifiée plusieurs fois.

-u utilisateur/masque

Exécute la commande uniquement pour l'utilisateur donné. Il est également possible d'utiliser les caractères génériques '*' et '?' (par exemple -u *@example.org).

-x infos_auth

infos_auth spécifie des conditions supplémentaires pour la commande user. La chaîne d'option infos_auth doit être donnée sous la forme de paires nom = valeur. Pour plusieurs conditions, l'option -x peut être fournie plusieurs fois.

Noms possibles pour infos_auth :

service

Le service pour lequel la recherche userdb doit être testée. La valeur peut être le nom d'un service, couramment utilisé avec Dovecot. Par exemple : imap, pop3 ou smtp.

session

Identifiant de session.

lip

L'adresse IP locale (serveur) pour le test.

rip

L'adresse IP distante (client) pour le test.

lport

Le port local, par exemple 143

rport

Le port distant, par exemple 24567

real_lip

L'adresse IP locale à laquelle le client s'est connecté sur cet hôte.

real_rip

L'adresse IP distante d'où le client s'est connecté à cet hôte.

real_lport

Le port local auquel le client s'est connecté à cet hôte.

real_rport

Le port distant d'où le client s'est connecté à cet hôte.

forward_<field>

Champ à transmettre comme %{forward:champ} au processus d'authentification.

ARGUMENTS

sieve-binaire

Spécifie le fichier binaire Sieve qui doit être vidé.

fichier-sortie

Spécifie où la sortie doit être écrite. Cet argument est optionnel. S'il est omis, la sortie est écrite sur stdout.

STATUT DE SORTIE

sieve-dump se terminera avec l'une des valeurs suivantes :

0

Le vidage a réussi. (EX_OK, EXIT_SUCCESS)

1

L'opération a échoué. Ceci est retourné pour presque tous les échecs. (EXIT_FAILURE)

64

Paramètre invalide fourni. (EX_USAGE)

FICHIERS

/etc/dovecot/dovecot.conf

Fichier de configuration principal de Dovecot.

/etc/dovecot/conf.d/90-sieve.conf

Paramètres de l'interpréteur Sieve (inclus à partir du fichier

de configuration principal de Dovecot)

SIGNALEMENT DE BOGUES

Signalez les bugs, y compris la sortie de doveconf -n, à la liste de diffusion Dovecot ⟨dovecot@dovecot.org⟩. Les informations sur le signalement des bugs sont disponibles sur : https://dovecot.org/bugreport.html
