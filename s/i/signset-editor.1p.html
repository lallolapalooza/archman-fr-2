NOM

signset-editor - Éditeur graphique de jeux de signatures

SYNTAXE

signset-editor <fichier-keyrec>

DESCRIPTION

signset-editor offre la possibilité de gérer facilement des jeux de signatures dans une interface graphique. Un jeu de signatures contient zéro ou plusieurs noms de keyrecs de clés. Ces jeux sont utilisés par d'autres utilitaires DNSSEC-Tools pour la signature de zones. Les jeux de signatures trouvés dans le fichier keyrec donné sont affichés dans une nouvelle fenêtre. De nouveaux jeux de signatures peuvent être créés et les jeux de signatures existants peuvent être modifiés ou supprimés depuis signset-editor.

signset-editor dispose de deux modes d'affichage. Le mode d'affichage des jeux de signatures montre les noms de tous les keyrecs de clés du fichier keyrec donné. Le mode d'affichage des keyrecs montre les noms de tous les keyrecs de clés du fichier keyrec donné. signset-editor démarre en mode d'affichage des jeux de signatures, mais le mode peut être basculé autant que nécessaire.

Une bascule supplémentaire contrôle l'affichage de données supplémentaires. Si la bascule "Données étendues" est activée, alors le mode d'affichage des jeux de signatures montre les noms des keyrecs de clés dans chaque jeu de signatures et le mode d'affichage des keyrecs montre les noms de chaque jeu de signatures auquel chaque keyrec de clé appartient. Si la bascule "Données étendues" est désactivée, alors le mode d'affichage des jeux de signatures montre uniquement les noms des keyrecs de clés et le mode d'affichage des keyrecs montre uniquement les noms des keyrecs de clés.

signset-editor a un petit nombre de commandes. Ces commandes sont toutes disponibles via les menus, et la plupart ont un accélérateur clavier. Les commandes sont décrites dans la section suivante.

La gestion des jeux de signatures peut être effectuée à l'aide d'un éditeur de texte normal. Cependant, signset-editor fournit une belle interface graphique qui ne manipule que les jeux de signatures sans le potentiel désordre visuel du reste des entrées keyrec.

ANNULER LES MODIFICATIONS

signset-editor a la capacité d'annuler les modifications qu'il a apportées à un fichier keyrec. Cette restauration historique ne fonctionnera que pour les modifications apportées au cours d'une exécution particulière de signset-editor ; les modifications apportées lors d'une exécution précédente ne peuvent pas être annulées.

Lors de l'annulation des modifications, signset-editor ne restaure pas nécessairement l'ordre des noms dans le champ signing_set d'un keyrec. Cependant, les données du jeu de signatures sont conservées. Cela signifie qu'un fichier keyrec "annulé" peut ne pas être exactement le même, octet par octet, que le fichier d'origine, mais le sens propre des données est conservé.

Après une opération "Enregistrer", les données nécessaires à l'annulation des modifications sont supprimées. Ce n'est pas le cas pour l'opération "Enregistrer sous".

OPTIONS

signset-editor accepte les options suivantes :

-Version
Affiche les informations de version pour signset-editor et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.

COMMANDES

signset-editor fournit les commandes suivantes, organisées par menus :

Ouvrir (Menu Fichier)
Ouvre un nouveau fichier keyrec. Si le fichier spécifié n'existe pas, l'utilisateur sera invité à choisir une action. Si l'utilisateur choisit l'action "Continuer", alors signset-editor continuera d'éditer le fichier keyrec actuel. Si l'action "Quitter" est sélectionnée, alors signset-editor se terminera.
Sauvegarder (Menu Fichier)
Sauvegarde le fichier keyrec actuel. Les données pour la commande "Annuler les modifications" sont purgées, donc ce fichier apparaîtra comme non modifié.

Rien ne se passera si aucune modification n'a été effectuée.

Sauvegarder sous (Menu Fichier)
Sauvegarde le fichier keyrec actuel sous un nom choisi par l'utilisateur.
Quitter (Menu Fichier)
Termine signset-editor.
Annuler les modifications (Menu Édition)
Inverse les modifications apportées aux jeux de signatures et aux keyrecs. Ceci est uniquement pour la version en mémoire du fichier keyrec.
Nouveau jeu de signatures (Menu Commandes)
Crée un nouveau jeu de signatures. L'utilisateur a la possibilité d'ajouter des keyrecs de clés au nouveau jeu.

Cette commande est disponible depuis les deux modes d'affichage.

Supprimer jeu de signatures/clé (Menu Commandes)
Supprime le jeu de signatures ou la clé sélectionné(e).

Cette commande est disponible depuis les deux modes d'affichage. Si elle est utilisée depuis le mode d'affichage des jeux de signatures, alors toutes les clés du jeu de signatures sélectionné seront retirées de ce jeu. Si elle est utilisée depuis le mode d'affichage des keyrecs, alors la clé sélectionnée ne fera plus partie d'aucun jeu de signatures.

Modifier jeu de signatures/clé (Menu Commandes)
Modifie le jeu de signatures ou la clé sélectionné(e).

Cette commande est disponible depuis les deux modes d'affichage. Si elle est utilisée depuis le mode d'affichage des jeux de signatures, alors le jeu de signatures sélectionné peut être modifié en ajoutant des clés à ce jeu ou en les en supprimant. Si elle est utilisée depuis le mode d'affichage des keyrecs, alors la clé sélectionnée peut être ajoutée ou supprimée de n'importe lequel des jeux de signatures définis.

Afficher les jeux de signatures (Menu Affichage)
La fenêtre principale affichera les jeux de signatures du fichier keyrec. Si des données étendues doivent être affichées, alors chaque keyrec de clé du jeu de signatures sera également affiché. Si des données étendues ne doivent pas être affichées, alors seuls les noms des jeux de signatures seront affichés.

Cette commande est une bascule qui passe du mode Afficher les jeux de signatures au mode Afficher les keyrecs.

Afficher les keyrecs (Menu Affichage)
La fenêtre principale affichera les noms des keyrecs de clés du fichier keyrec. Si des données étendues doivent être affichées, alors le nom de chaque jeu de signatures du keyrec sera également affiché. Si des données étendues ne doivent pas être affichées, alors seuls les noms des keyrecs seront affichés.

Cette commande est une bascule qui passe du mode Afficher les keyrecs au mode Afficher les jeux de signatures.

Afficher les données étendues (Menu Affichage)
Des données supplémentaires seront affichées dans la fenêtre principale. Pour le mode d'affichage des jeux de signatures, les noms des jeux de signatures et leurs keyrecs de clés constitutifs seront affichés. Pour le mode d'affichage des keyrecs, les noms des keyrecs de clés et les jeux de signatures auxquels ils appartiennent seront affichés.

Cette commande est une bascule qui passe de l'affichage des données étendues à l'absence d'affichage de données étendues.

Ne pas afficher les données étendues (Menu Affichage)
Aucune donnée supplémentaire ne sera affichée dans la fenêtre principale. Pour le mode d'affichage des jeux de signatures, seuls les noms des jeux de signatures seront affichés. Pour le mode d'affichage des keyrecs, seuls les noms des keyrecs seront affichés.

Cette commande est une bascule qui passe de l'absence d'affichage de données étendues à l'affichage des données étendues.

Aide (Menu Aide)
Affiche une fenêtre d'aide.

ACCÉLÉRATEURS CLAVIER

Voici les accélérateurs clavier pour les commandes de signset-editor :

Ctrl-D  Supprimer jeu de signatures
Ctrl-E  Afficher données étendues / Ne pas afficher données étendues
Ctrl-H  Aide
Ctrl-M  Modifier jeu de signatures
Ctrl-N  Nouveau jeu de signatures
Ctrl-O  Ouvrir
Ctrl-Q  Quitter
Ctrl-S  Sauvegarder
Ctrl-U  Annuler modifications
Ctrl-V  Afficher jeux de signatures / Afficher keyrecs
Ctrl-W  Fermer fenêtre (Nouveau jeu de signatures, Modifier jeu de signatures, Aide)

Ces accélérateurs sont tous des lettres minuscules.

signset-editor(1p) — Arch Linux

NAME

signset-editor - A graphical tool for editing DNSSEC signset files.

SYNOPSIS

signset-editor [options]

DESCRIPTION

This manual page documents the signset-editor command.

The signset-editor is a graphical user interface (GUI) for editing DNSSEC signset files. It allows users to easily create, modify, and manage signset configurations for DNSSEC zone signing.

OPTIONS

The signset-editor command accepts the following options:

--help
Display a help message and exit.
--version
Display version information and exit.
--file <filename>
Open the specified signset file for editing.

COMMANDS

The signset-editor provides the following commands within its GUI interface:

New
Create a new signset file.
Open
Open an existing signset file.
Save
Save the current signset file.
Save As
Save the current signset file to a new location.
Add Key
Add a new cryptographic key to the signset.
Edit Key
Modify the properties of an existing key.
Delete Key
Remove a key from the signset.
Add Trust Anchor
Add a new trust anchor to the signset.
Edit Trust Anchor
Modify the properties of an existing trust anchor.
Delete Trust Anchor
Remove a trust anchor from the signset.
Validate
Validate the current signset file for correctness.
Close
Close the current signset file.
Exit
Exit the signset-editor application.

KEYBOARD ACCELERATORS

The following keyboard accelerators are available:

Ctrl+O
Open
Ctrl+S
Save
Ctrl+Q
Exit

REQUIREMENTS

The signset-editor requires Perl and the Tk toolkit to be installed on your system.
