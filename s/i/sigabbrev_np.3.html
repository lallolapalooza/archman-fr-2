strsignal(3) Manuel des fonctions de bibliothèque strsignal(3)

NOM

strsignal, sigabbrev_np, sigdescr_np, sys_siglist - retourner une chaîne décrivant un signal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <string.h>
char *strsignal(int sig);
const char *sigdescr_np(int sig);
const char *sigabbrev_np(int sig);
[[deprecated]] extern const char *const sys_siglist[];
Conditions pour les macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

sigabbrev_np(), sigdescr_np():

    _GNU_SOURCE

strsignal():

    De glibc 2.10 à glibc 2.31 :
        _POSIX_C_SOURCE >= 200809L
    Avant glibc 2.10 :
        _GNU_SOURCE

sys_siglist:

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _BSD_SOURCE

DESCRIPTION

La fonction strsignal() retourne une chaîne décrivant le numéro de signal passé en argument sig. La chaîne ne peut être utilisée qu'avant le prochain appel à strsignal(). La chaîne retournée par strsignal() est localisée selon la catégorie LC_MESSAGES de la locale actuelle.

La fonction sigdescr_np() retourne une chaîne décrivant le numéro de signal passé en argument sig. Contrairement à strsignal(), cette chaîne n'est pas influencée par la locale actuelle.

La fonction sigabbrev_np() retourne le nom abrégé du signal, sig. Par exemple, étant donné la valeur SIGINT, elle retourne la chaîne "INT".

Le tableau (obsolète) sys_siglist contient les chaînes de description des signaux indexées par numéro de signal. Il faut utiliser la fonction strsignal() ou sigdescr_np() à la place de ce tableau ; voir également VERSIONS.

VALEUR DE RETOUR

La fonction strsignal() retourne la chaîne de description appropriée, ou un message de signal inconnu si le numéro de signal est invalide. Sur certains systèmes (mais pas sous Linux), NULL peut être retourné à la place pour un numéro de signal invalide.

Les fonctions sigdescr_np() et sigabbrev_np() retournent la chaîne de description appropriée. La chaîne retournée est allouée statiquement et valide pendant toute la durée du programme. Ces fonctions retournent NULL pour un numéro de signal invalide.
