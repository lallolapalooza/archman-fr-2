NOM

apptainer-plugin-create - Crée un squelette de répertoire de plugin

SYNOPSIS

apptainer plugin create

DESCRIPTION

La commande 'plugin create' permet à un utilisateur de créer une structure de répertoire de squelette de plugin pour commencer le développement d'un nouveau plugin.

OPTIONS

-h, --help[=false] aide pour create

EXEMPLE

  $ apptainer plugin create ~/myplugin github.com/username/myplugin
  $ ls -1 ~/myplugin
  go.mod
  main.go
  apptainer_source
