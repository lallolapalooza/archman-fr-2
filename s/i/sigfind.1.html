NOM

sigfind - Trouver une signature binaire dans un fichier

SYNTAXE

sigfind [-b taille_bloc ] [-o décalage ] [-t modèle ] [-lV] [ signature_hex ] fichier

DESCRIPTION

sigfind parcourt un fichier et recherche la signature_hex à un décalage donné. Ceci peut être utilisé pour rechercher des secteurs de démarrage perdus, des superblocs et des tables de partition.

ARGUMENTS

-b taille_bloc
Spécifie la taille du bloc dans lequel rechercher. La valeur par défaut est 512 et la valeur doit être un multiple de 512.
-o décalage
Spécifie le décalage dans un bloc où la signature doit exister. La valeur par défaut est 0.
-t modèle
Spécifie un nom de modèle qui définit la valeur et le décalage de la signature. Exécutez sans options pour obtenir une liste des modèles supportés.
-l
La signature est stockée en ordre little-endian et doit donc être inversée.
-V
Affiche la version
[signature_hex]
La signature binaire que vous recherchez. Elle doit être fournie au format hexadécimal. Cet argument doit exister si -t n'est pas utilisé.
fichier
Toute donnée brute.

EXEMPLES

sigfind -o 510 -l AA55 disk.dd

sigfind -t fat disk.dd
