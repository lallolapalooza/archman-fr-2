SIGNIFY(1) Manuel des commandes générales SIGNIFY(1)

NOM

signify — signature et vérification cryptographiques de fichiers

SYNTAXE

signify -C [-q] [-p clé_publique] [-t type_clé] -x fichier_signature [fichier ...]

signify -G [-n] [-c commentaire] -p clé_publique -s clé_privée

signify -S [-enz] [-x fichier_signature] -s clé_privée -m message

signify -V [-eqz] [-p clé_publique] [-t type_clé] [-x fichier_signature] -m message

DESCRIPTION

L'utilitaire signify crée et vérifie des signatures cryptographiques. Une signature vérifie l'intégrité d'un message. Le mode de fonctionnement est sélectionné avec les options suivantes :

-C
Vérifie une liste de sommes de contrôle signée, puis vérifie la somme de contrôle pour chaque fichier. Si aucun fichier n'est spécifié, tous sont vérifiés. fichier_signature doit être la sortie signée de sha256(1).
-G
Génère une nouvelle paire de clés. Les noms de clés doivent suivre la convention de nom_clé.pub et nom_clé.sec pour les clés publiques et privées, respectivement.
-S
Signe le fichier message spécifié et crée une signature.
-V
Vérifie que le message et la signature correspondent.

Les autres options sont les suivantes :

-c commentaire
Spécifie le commentaire à ajouter lors de la génération de la clé.
-e
Lors de la signature, intègre le message après la signature. Lors de la vérification, extrait le message de la signature. (Cela nécessite que la signature ait été créée avec -e et crée un nouveau fichier message en sortie.)
-m message
Lors de la signature, le fichier contenant le message à signer. Lors de la vérification, le fichier contenant le message à vérifier. Lors de la vérification avec -e, le fichier à créer.
-n
Lors de la génération d'une paire de clés, ne demande pas de phrase secrète. Sinon, signify demandera à l'utilisateur une phrase secrète pour protéger la clé privée. Lors de la signature avec -z, enregistre un horodatage nul dans l'en-tête de gzip(1).
-p clé_publique
Clé publique produite par -G, et utilisée par -V pour vérifier une signature.
-q
Mode silencieux. Supprime les messages d'information.
-s clé_privée
Clé secrète (privée) produite par -G, et utilisée par -S pour signer un message.
-t type_clé
Lors de la déduction de la clé correcte pour vérifier une signature, s'assure que la clé réelle correspond à /etc/signify/*-type_clé.pub.
-x fichier_signature
Le fichier de signature à créer ou vérifier. Par défaut, c'est message.sig.
-z
Signe et vérifie des archives gzip(1), où les données de signature sont intégrées dans l'en-tête de gzip(1).

Les fichiers de clé et de signature créés par signify ont le même format. La première ligne du fichier est un commentaire textuel libre qui peut être modifié, tant qu'il ne dépasse pas une seule ligne. Les commentaires de signature seront générés en fonction du nom de la clé secrète utilisée pour signer. Ce commentaire peut alors être utilisé comme indice pour le nom de la clé publique lors de la vérification. La seconde ligne du fichier est la clé ou la signature réelle encodée en base64.

CODE DE RÉTABLISSEMENT

L'utilitaire signify se termine avec le code 0 en cas de succès, et un code >0 si une erreur se produit. Il peut échouer pour l'une des raisons suivantes :

  • Certains fichiers nécessaires n'existent pas.
  • La phrase secrète entrée est incorrecte.
  • Le fichier message a été corrompu et sa signature ne correspond pas.
  • Le fichier message est trop grand.

EXEMPLES

Créer une nouvelle paire de clés :

$ signify -G -p newkey.pub -s newkey.sec

Signer un fichier, en spécifiant un nom de signature :

$ signify -S -s key.sec -m message.txt -x msg.sig

Vérifier une signature, en utilisant le nom de signature par défaut :

$ signify -V -p key.pub -m generalsorders.txt

Vérifier un répertoire de publication contenant SHA256.sig et un ensemble complet de fichiers de publication :

$ signify -C -p /etc/signify/openbsd-76-base.pub -x SHA256.sig

Vérifier un bsd.rd avant une mise à niveau :

$ signify -C -p /etc/signify/openbsd-76-base.pub -x SHA256.sig bsd.rd

Signer une archive gzip :

$ signify -Sz -s key-arc.sec -m in.tgz -x out.tgz

Vérifier un pipeline gzip :

$ ftp url | signify -Vz -t arc | tar ztf -

VOIR AUSSI

gzip(1), pkg_add(1), sha256(1), fw_update(8), sysupgrade(8)

HISTORIQUE

La commande signify est apparue pour la première fois dans OpenBSD 5.5.
