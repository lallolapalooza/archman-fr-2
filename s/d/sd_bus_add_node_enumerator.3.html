NOM

sd_bus_add_node_enumerator - Ajouter un énumérateur de nœuds pour un préfixe de chemin d'objet D-Bus

SYNOPSIS

#include <systemd/sd-bus.h>

typedef int (*sd_bus_node_enumerator_t)(sd_bus *bus, const char *prefix, void *userdata, char ***ret_nodes, sd_bus_error *ret_error);

int sd_bus_add_node_enumerator(sd_bus *bus, sd_bus_slot **slot, const char *path, sd_bus_node_enumerator_t callback, void *userdata);

DESCRIPTION

sd_bus_add_node_enumerator() ajoute un énumérateur de nœuds D-Bus pour le préfixe de chemin donné. La fonction de rappel (callback) fournie est appelée pour énumérer tous les objets disponibles avec le préfixe de chemin donné lorsque cela est nécessaire (par exemple, lorsque org.freedesktop.DBus.Introspectable.Introspect ou org.freedesktop.DBus.ObjectManager.GetManagedObjects sont appelés sur un service D-Bus géré par sd-bus).

Le callback est appelé avec le chemin et le pointeur userdata enregistrés avec sd_bus_add_node_enumerator(). Lorsqu'il est appelé, il doit stocker tous les chemins d'objets enfants du préfixe de chemin donné dans ret_nodes avec un élément terminateur NULL. Le callback doit retourner une valeur non négative en cas de succès. Si une erreur se produit, il peut soit retourner un entier négatif, définir ret_error sur une erreur non vide, soit faire les deux. Toutes les erreurs retournées par le callback sont encodées sous forme d'erreurs D-Bus et envoyées à l'appelant. Les erreurs dans ret_error ont la priorité sur les valeurs de retour négatives.

Notez qu'un callback d'énumérateur de nœuds ne sera jamais appelé que pour un seul préfixe de chemin et donc, pour un fonctionnement normal, le prefix peut être ignoré. De plus, un énumérateur de nœuds est uniquement utilisé pour énumérer les objets enfants disponibles sous un préfixe donné. Pour installer un gestionnaire pour un ensemble d'objets enfants dynamiques, utilisez sd_bus_add_fallback_vtable(3).

Lorsque sd_bus_add_node_enumerator() réussit, un slot est créé en interne. Si le paramètre de sortie slot est NULL, un objet slot "flottant" est créé, voir sd_bus_slot_set_floating(3). Sinon, un pointeur vers l'objet slot est retourné. Dans ce cas, la référence à l'objet slot doit être abandonnée lorsque l'énumérateur de nœuds n'est plus nécessaire, voir sd_bus_slot_unref(3).

VALEUR RETOUR

En cas de succès, sd_bus_add_node_enumerator() retourne un entier non négatif. En cas d'échec, il retourne un code d'erreur négatif de style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Un des paramètres requis est NULL ou path n'est pas un chemin d'objet valide.

-ENOPKG

Le bus ne peut pas être résolu.

-ECHILD

Le bus a été créé dans un processus, une bibliothèque ou une instance de module différent.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour une utilisation multithread. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de ne faire des appels à setenv() que depuis une phase précoce du programme lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_node_enumerator_t() et sd_bus_add_node_enumerator() ont été ajoutés dans la version 221.
