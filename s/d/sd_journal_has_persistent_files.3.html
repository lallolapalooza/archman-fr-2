NOM

sd_journal_has_runtime_files, sd_journal_has_persistent_files - Interroger la disponibilité des fichiers de journal d'exécution ou persistants

SYNTAXE

#include <systemd/sd-journal.h>

int sd_journal_has_runtime_files(sd_journal *j);

int sd_journal_has_persistent_files(sd_journal *j);

DESCRIPTION

sd_journal_has_runtime_files() renvoie une valeur positive si des fichiers de journal d'exécution (présents dans /run/systemd/journal/) ont été trouvés. Sinon, renvoie 0.

sd_journal_has_persistent_files() renvoie une valeur positive si des fichiers de journal persistants (présents dans /var/log/journal/) ont été trouvés. Sinon, renvoie 0.

VALEUR DE RETOUR

Les fonctions sd_journal_has_runtime_files() et sd_journal_has_persistent_files() renvoient -EINVAL si leur argument est NULL.

NOTES

Toutes les fonctions listées ici sont indépendantes des threads et un seul thread peut opérer sur un objet donné à un instant donné. Différents threads peuvent accéder au même objet à différents moments. Plusieurs objets indépendants peuvent être utilisés à partir de différents threads en parallèle.

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

HISTORIQUE

Les fonctions sd_journal_has_runtime_files() et sd_journal_has_persistent_files() ont été ajoutées dans la version 229.
