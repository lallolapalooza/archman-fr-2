NOM

sdcv - version console du programme StarDict

SYNOPIS

sdcv [ options ] [liste de mots]

DESCRIPTION

sdcv est un utilitaire simple et multiplateforme basé sur du texte pour travailler avec des dictionnaires au format StarDict. Chaque mot de la "liste de mots" peut être une chaîne avec un '/' en préfixe pour utiliser un algorithme de recherche floue, avec un '|' en préfixe pour utiliser la recherche en texte intégral, et la chaîne peut contenir '?' et '*' pour la recherche d'expression régulière. Il fonctionne en mode interactif et non interactif. Pour quitter le mode interactif, appuyez sur Ctrl+D. En mode interactif, si sdcv a été compilé avec le support de la bibliothèque readline, vous pouvez utiliser les touches HAUT et BAS pour parcourir l'historique.

OPTIONS

-h --help
Afficher le message d'aide et quitter
-v --version
Afficher la version et quitter
-l --list-dicts
Afficher la liste des dictionnaires disponibles et quitter
-u --use-dict nom_de_fichier
Pour la recherche, utiliser uniquement le dictionnaire avec ce nom de livre
-n --non-interactive
Pour utilisation dans les scripts
-x --only-data-dir
Pour utilisation dans les scripts : utiliser uniquement les dictionnaires dans le répertoire de données, ne pas rechercher dans les répertoires utilisateur et système
-e --exact-search
Ne pas effectuer de recherche floue pour des mots similaires, ne retourner que les correspondances exactes
-j --json
Afficher les résultats de list-dicts et des recherches au format json, et non en texte brut. Pour une utilisation dans le traitement automatique des résultats d'une recherche de dictionnaire.
--utf8-output
Forcer sdcv à ne pas convertir vers le jeu de caractères local, sortie en utf8
--utf8-input
Forcer sdcv à ne pas convertir depuis le jeu de caractères local, supposer que l'entrée est en utf8
--data-dir chemin/vers/repertoire
Utiliser ce répertoire comme chemin vers le répertoire de données stardict. Cela signifie que sdcv recherche les dictionnaires dans data-dir/dic.
--color
Utiliser des codes d'échappement ANSI pour coloriser la sortie de sdcv (ne fonctionne pas avec la sortie json).

FICHIERS

/usr/share/stardict/dic
$(XDG_DATA_HOME)/stardict/dic

Emplacement où sdcv s'attend à trouver les dictionnaires. Au lieu de /usr/share/stardict/dic, vous pouvez utiliser n'importe quel répertoire de votre choix, il suffit de définir la variable d'environnement STARDICT_DATA_DIR. Par exemple, si vous avez des dictionnaires dans /mnt/data/stardict-dicts/dic, définissez STARDICT_DATA_DIR sur /mnt/data/stardict-dicts.

$(XDG_DATA_HOME)/sdcv_history

Ce fichier contient les derniers $(SDCV_HISTSIZE) mots que vous avez recherchés avec sdcv. SDCV n'utilise ce fichier que s'il a été compilé avec le support de la bibliothèque readline.

$(XDG_CONFIG_HOME)/sdcv_ordering

Il s'agit d'un fichier texte contenant un nom de livre de dictionnaire par ligne. Il spécifie dans quel ordre les résultats d'une recherche doivent être affichés.

ENVIRONNEMENT

Variables d'environnement utilisées par sdcv :

STARDICT_DATA_DIR
Si défini, sdcv utilise cette variable comme répertoire de données, ce qui signifie que sdcv recherche les dictionnaires dans $STARDICT_DATA_DIR/dic
SDCV_HISTSIZE
Si défini, sdcv écrit dans $(XDG_DATA_HOME)/sdcv_history (ou $(SDCV_HISTFILE)) les derniers $(SDCV_HISTSIZE) mots que vous recherchez avec sdcv. S'il n'est pas défini, alors les 2000 derniers mots sont enregistrés dans $(XDG_DATA_HOME)/sdcv_history.
SDCV_HISTFILE
Si défini, sdcv écrit son historique dans $(SDCV_HISTFILE). S'il n'est pas défini, alors le chemin par défaut $(XDG_DATA_HOME)/sdcv_history sera utilisé.
SDCV_PAGER
Si SDCV_PAGER est défini, sa valeur est utilisée comme nom du programme à utiliser pour afficher l'article du dictionnaire.

BOGUES

Envoyez les rapports de bogues par e-mail à dushistov at mail dot ru. Assurez-vous d'inclure le mot "sdcv" quelque part dans le champ "Sujet:".
