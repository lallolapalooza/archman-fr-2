NOM

sd-varlink - API pour Varlink IPC

SYNOPSIS

#include <systemd/sd-varlink.h>

pkg-config --cflags --libs libsystemd

DESCRIPTION

sd-varlink.h fait partie de libsystemd(3) et fournit des API pour l'implémentation de clients et de services Varlink IPC. Voir https://varlink.org/ pour plus d'informations sur Varlink IPC.

Varlink IPC utilise JSON[1] comme format de sérialisation. L'API sd-varlink repose sur l'API sd-json(3) pour la sérialisation, désérialisation et manipulation de JSON.

L'outil varlinkctl(1) rend les fonctionnalités implémentées par sd-varlink disponibles en ligne de commande.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr en multithreading. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'appeler setenv() que lors d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.
