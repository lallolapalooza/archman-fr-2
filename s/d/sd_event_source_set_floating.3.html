NOM

sd_event_source_set_floating, sd_event_source_get_floating - Définir ou récupérer l'état 'flottant' des sources d'événements

SYNTAXE

#include <systemd/sd-event.h>

int sd_event_source_set_floating(sd_event_source *source, int floating);

int sd_event_source_get_floating(sd_event_source *source);

DESCRIPTION

sd_event_source_set_floating() prend une valeur booléenne et définit l'état 'flottant' de l'objet source d'événement spécifié. Ceci est utilisé pour changer la direction des décomptes de références pour l'objet et la boucle d'événements à laquelle il est associé. En mode non flottant, l'objet source d'événement détient une référence à l'objet boucle d'événements, mais pas l'inverse. Le créateur de l'objet source d'événement doit en détenir une référence tant que la source doit exister. En mode flottant, la boucle d'événements détient une référence à l'objet source, et diminuera le décompte de références lors de sa libération. Cela signifie qu'une référence à la boucle d'événements doit être conservée pour empêcher la destruction des deux.

Divers appels qui allouent des objets sources d'événements (par exemple sd_event_add_io(3), sd_event_add_time(3) et similaires) définiront automatiquement un objet source d'événement en mode 'flottant' si l'appelant a passé NULL dans le paramètre utilisé pour retourner une référence à l'objet source d'événement. Néanmoins, il peut être nécessaire d'obtenir un accès temporaire à l'objet source, par exemple pour ajuster les propriétés de la source d'événement après l'allocation (par exemple, sa priorité ou sa chaîne de description). Dans ces cas, l'objet peut être créé en mode non flottant, la référence retournée utilisée pour ajuster les propriétés, puis l'objet marqué comme flottant, et la référence de l'appelant sera supprimée.

sd_event_source_get_floating() peut être utilisé pour interroger l'état 'flottant' actuel de l'objet source d'événement source. Il retourne zéro si le mode 'flottant' est désactivé, une valeur positive s'il est activé.

VALEUR DE RETOUR

En cas de succès, sd_event_source_set_floating() et sd_event_source_get_floating() retournent un entier non négatif. En cas d'échec, ils retournent un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

source n'est pas un pointeur valide vers un objet sd_event_source.

Ajouté dans la version 244.

-ECHILD

La boucle d'événements a été créée dans un processus, une bibliothèque ou une instance de module différente.

Ajouté dans la version 244.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à partir d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_event_source_set_floating() et sd_event_source_get_floating() ont été ajoutés dans la version 244.
