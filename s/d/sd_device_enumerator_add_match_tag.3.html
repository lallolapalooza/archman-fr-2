NOM

sd_device_enumerator_add_match_parent, sd_device_enumerator_add_match_property, sd_device_enumerator_add_match_property_required, sd_device_enumerator_add_match_subsystem, sd_device_enumerator_add_match_sysattr, sd_device_enumerator_add_match_sysname, sd_device_enumerator_add_nomatch_sysname, sd_device_enumerator_add_match_tag, sd_device_enumerator_allow_uninitialized, sd_device_enumerator_add_all_parents - Ajouter un filtre à l'énumérateur de périphériques

DESCRIPTION

La fonction sd_device_enumerator_add_match_parent() ajoute un filtre à l'enumerator afin que seuls les périphériques sous l'arborescence du périphérique parent spécifié soient énumérés. Si cette fonction est appelée plusieurs fois, le périphérique parent précédemment défini est effacé et seule le dernier appel prend effet.

La fonction sd_device_enumerator_add_match_property() ajoute un filtre à l'enumerator afin que seuls les périphériques dont la property spécifiée est égale à la value spécifiée soient énumérés. property et value peuvent être des motifs globaux. Lorsque cette fonction est appelée plusieurs fois, les périphériques qui ont au moins une des propriétés spécifiées avec des valeurs correspondantes sont énumérés. Autrement dit, les filtres sont ORés.

La fonction sd_device_enumerator_add_match_property_required() ajoute un filtre à l'enumerator afin que seuls les périphériques dont la property spécifiée est égale à la value spécifiée soient énumérés. Cette fonction est similaire à sd_device_enumerator_add_match_property(), mais lorsque celle-ci est appelée plusieurs fois, les périphériques qui ont toutes les propriétés spécifiées avec des valeurs correspondantes sont énumérés. Autrement dit, les filtres sont ETés.

La fonction sd_device_enumerator_add_match_subsystem() ajoute un filtre à l'enumerator afin que tous les périphériques du subsystem spécifié soient inclus, lorsque match est true. Lorsque match est false, alors tous les périphériques sauf ceux du subsystem spécifié sont énumérés. Lorsque appelée plusieurs fois, les filtres positifs sont ORés, et les filtres négatifs sont ETés.

La fonction sd_device_enumerator_add_match_sysattr() ajoute un filtre sur l'attribut sysfs sysattr correspondant à value. value peut être un motif global. Si value est NULL, les périphériques qui ont (si match est true) ou qui n'ont pas (si match est false) le sysattr spécifié sont inclus, quelle que soit sa valeur. Autrement dit, NULL est principalement équivalent à "*". Lorsque cette fonction est appelée plusieurs fois, seuls les périphériques qui correspondent à tous les filtres sysattr spécifiés sont énumérés. Autrement dit, ces filtres sont ETés.

La fonction sd_device_enumerator_add_match_sysname() ajoute un filtre afin que seuls les périphériques dont le nom système (sysname) est égal à sysname soient énumérés. sysname peut être un motif global. Lorsque appelée plusieurs fois, les filtres sont ORés.

La fonction sd_device_enumerator_add_nomatch_sysname() ajoute un filtre afin que les périphériques dont le nom système (sysname) est égal à sysname soient exclus de l'énumération. Ceci est utile pour exclure des périphériques spécifiques du processus d'énumération. Lorsque appelée plusieurs fois, les caractéristiques sont ETées.

La fonction sd_device_enumerator_add_match_tag() ajoute un filtre afin que seuls les périphériques tagués avec tag soient énumérés. Lorsque appelée plusieurs fois, les filtres sont ORés.

La fonction sd_device_enumerator_allow_uninitialized() permet aux périphériques qui n'ont pas encore été initialisés par udev d'être inclus dans l'énumération.

La fonction sd_device_enumerator_add_all_parents() énumère tous les périphériques parents des périphériques correspondants. Ceci est utile pour les cas où vous souhaitez inclure tous les périphériques parents dans l'énumération, par exemple lorsque vous vous intéressez à l'ensemble de l'arborescence des périphériques menant à un périphérique spécifique.

VALEUR DE RETOUR

Toutes les fonctions retournent 0 ou un entier positif en cas de succès, ou un code d'erreur négatif de style errno en cas d'échec.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ENOMEM

Allocation de mémoire échouée.

-EINVAL

L'un des arguments est invalide.

EXEMPLES

Exemple 1. Détecter les périphériques USB amovibles (Utilisation de Match et Exclude)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* Créer un nouvel énumérateur de périphériques */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Échec de la création de l'énumérateur de périphériques : %s\n", strerror(-r));
        return 1;
    }
    /* Inclure uniquement les périphériques du sous-système "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout du filtre par sous-système : %s\n", strerror(-r));
        return 1;
    }
    /*
     * Exclure les périphériques où l'attribut sysfs "removable" est "0"
     * Ce sont généralement des périphériques non amovibles comme les interfaces USB intégrées
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout du filtre par attribut sysfs : %s\n", strerror(-r));
        return 1;
    }
    /* Commencer l'énumération des périphériques correspondants */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* Obtenir le chemin sysfs du périphérique */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("Périphérique USB amovible trouvé : %s\n", syspath);
    }
    return 0;
}
