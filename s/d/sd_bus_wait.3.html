NOM

sd_bus_wait - Attendre une E/S sur une connexion de bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_wait(sd_bus *bus, uint64_t timeout_usec);

DESCRIPTION

sd_bus_wait() attend de manière synchrone une E/S sur l'objet de connexion de bus spécifié. Cette fonction est destinée à être appelée chaque fois que sd_bus_process(3) renvoie zéro, indiquant qu'aucun travail n'est en attente sur la connexion. En interne, cet appel utilise ppoll(2) pour attendre une E/S sur la connexion de bus. Si le paramètre timeout_usec est spécifié, l'appel bloquera au maximum pendant la durée spécifiée en μs. Passez UINT64_MAX pour permettre une mise en veille indéfinie.

Après chaque invocation de sd_bus_wait(), l'appel sd_bus_process() doit être effectué afin de traiter tout travail d'E/S désormais en attente.

Notez que sd_bus_wait() convient uniquement aux programmes simples car elle ne permet pas d'attendre d'autres événements d'E/S. Pour des programmes plus complexes, connectez l'objet de connexion de bus à une boucle d'événements externe à l'aide de sd_bus_get_fd(3) ou à une boucle d'événements sd-event(3) à l'aide de sd_bus_attach_event(3).

VALEUR DE RETOUR

Si une E/S a été détectée, une valeur positive est renvoyée, sinon zéro. Si une erreur se produit, un code d'erreur négatif de style errno est renvoyé.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants:

-EINVAL

Un objet de bus invalide a été passé.

-ECHILD

La connexion de bus a été allouée dans un processus parent et est réutilisée dans un processus enfant après fork().

-ENOTCONN

La connexion de bus a déjà été terminée.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'appeler setenv() que lors d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_wait() a été ajouté dans la version 240.
