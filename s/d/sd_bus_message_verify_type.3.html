NOM

sd_bus_message_verify_type - Vérifie si le message a le type spécifié à l'emplacement actuel

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_verify_type(sd_bus_message *m, char type, const char* contents);

DESCRIPTION

sd_bus_message_verify_type() vérifie si le type complet à l'emplacement actuel dans le message m correspond aux type et contents spécifiés. S'il est différent de zéro, le paramètre type doit être l'un des types spécifiés dans sd_bus_message_append(3). S'il n'est pas NULL, le paramètre contents doit être une séquence valide de types complets. Si type et contents sont spécifiés, type doit être un type conteneur.

Si type est spécifié, le type dans le message doit correspondre. Si contents est spécifié, le type dans le message doit être un type conteneur avec cette signature.

VALEUR DE RETOUR

En cas de succès, cet appel retourne vrai si le type correspond et zéro sinon (le message m contient des données différentes ou la fin du message a été atteinte). En cas d'échec, il retourne un code d'erreur négatif du style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

m ou les deux type et contents sont NULL.

Les arguments ne satisfont pas aux autres contraintes listées ci-dessus.

-EPERM

Le message m n'est pas scellé.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à partir d'une phase précoce du programme lorsque aucun autre thread n'a été démarré.
