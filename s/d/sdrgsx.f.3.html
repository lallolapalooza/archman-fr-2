SDRGSX

Objectif :

!>
!> SDRGSX vérifie le pilote expert de problème de valeurs propres généralisées non symétriques (forme de Schur)
!> SGGESX.
!>
!> SGGESX factorise A et B sous la forme Q S Z' et Q T Z', où ' signifie
!> transposée, T est triangulaire supérieure, S est sous forme de Schur généralisée
!> (triangulaire par blocs supérieure, avec des blocs 1x1 et 2x2 sur la diagonale,
!> les blocs 2x2 correspondant à des paires de valeurs propres généralisées complexes conjuguées),
!> et Q et Z sont orthogonales. Il calcule également les valeurs propres généralisées (alpha(1),beta(1)), ...,
!> (alpha(n),beta(n)). Ainsi, w(j) = alpha(j)/beta(j) est une racine de l'équation caractéristique
!>
!>     det( A - w(j) B ) = 0
!>
!> Optionnellement, il réordonne également les valeurs propres de manière à ce qu'un
!> cluster de valeurs propres sélectionnées apparaisse dans le bloc diagonal principal des
!> formes de Schur ; calcule un nombre de condition réciproque pour la moyenne
!> des valeurs propres sélectionnées ; et calcule un nombre de condition réciproque
!> pour les sous-espaces de déflation droite et gauche correspondant
!> aux valeurs propres sélectionnées.
!>
!> Lorsque SDRGSX est appelée avec NSIZE > 0, cinq (5) types de paires de matrices
!> intégrées sont utilisées pour tester la sous-routine SGGESX.
!>
!> Lorsque SDRGSX est appelée avec NSIZE = 0, elle lit les données de la matrice de test
!> pour tester SGGESX.
!>
!> Pour chaque paire de matrices, les tests suivants seront effectués et
!> comparés au seuil THRESH à l'exception des tests (7) et (9) :
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A est sous forme de Schur (c'est-à-dire forme quasi-triangulaire)
!>
!> (6)   maximum sur j de D(j)  où :
!>
!>       si alpha(j) est réel :
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) est complexe :
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>           et S et T sont ici les blocs diagonaux 2 x 2 de S et T
!>           correspondant aux j-ème et j+1-ème valeurs propres.
!>
!> (7)   si le tri a fonctionné et SDIM est le nombre de valeurs propres
!>       qui ont été sélectionnées.
!>
!> (8)   la valeur estimée DIF ne diffère pas des valeurs réelles de
!>       Difu et Difl plus d'un facteur 10*THRESH. Si l'estimation DIF
!>       est nulle, les valeurs réelles correspondantes de Difu et Difl
!>       devraient être inférieures à EPS*norm(A, B). Si la valeur réelle de Difu
!>       et Difl est nulle, l'estimation DIF devrait être inférieure à
!>       EPS*norm(A, B).
!>
!> (9)   Si INFO = N+3 est renvoyé par SGGESX, la réorganisation 
!>       et nous vérifions que DIF = PL = PR = 0 et que la valeur réelle de
!>       Difu et Difl est < EPS*norm(A, B). Nous comptons les événements lorsque
!>       INFO=N+3.
!>
!> Pour les matrices de test lues, les tests ci-dessus sont effectués, sauf que la
!> valeur exacte de DIF (et PL) sont des données d'entrée. De plus, un test supplémentaire
!> est effectué pour les matrices de test lues :
!>
!> (10)  la valeur estimée PL ne diffère pas de la valeur réelle de
!>       PLTRU plus d'un facteur THRESH. Si l'estimation PL est
!>       nulle, la valeur réelle correspondante de PLTRU devrait être inférieure à
!>       EPS*norm(A, B). Si la valeur réelle de PLTRU est nulle, l'
!>       estimation PL devrait être inférieure à EPS*norm(A, B).
!>
!> Notez que pour les tests intégrés, un total de 10*NSIZE*(NSIZE-1)
!> paires de matrices sont générées et testées. NSIZE doit être petit.
!>
!> SVD (routine SGESVD) est utilisé pour calculer la valeur réelle de DIF_u
!> et DIF_l lors du test des problèmes de test intégrés.
!>
!> Matrices de test intégrées
!> ======================
!>
!> Toutes les matrices de test intégrées sont des blocs 2 par 2 de matrices triangulaires
!>
!>          A = [ A11 A12 ]    et      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> où pour différents types de A11 et A22 sont donnés comme suit.
!> A12 et B12 sont choisis de sorte que l'équation de Sylvester généralisée
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> aient des solutions prescrites R et L.
!>
!> Type 1 :  A11 = J_m(1,-1) et A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          où J_k(a,b) est le bloc de Jordan k-par-k avec « a » sur la diagonale
!>          et « b » sur la superdiagonale.
!>
!> Type 2 :  A11 = (a_ij) = ( 2(.5-sin(i)) ) et
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) et
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=m+1,...,k, j=i,...,k
!>
!> Type 3 :  A11, A22 et B11, B22 sont choisis comme pour le Type 2, mais chaque
!>          deuxième bloc diagonal dans A_11 et chaque troisième bloc diagonal
!>          dans A_22 sont des blocs de 2 par 2.
!>
!> Type 4 :  A11 = ( 20(.5 - sin(ij)) ) et B22 = ( 2(.5 - sin(i+j)) )
!>             pour i=1,...,m,  j=1,...,m et
!>          A22 = ( 20(.5 - sin(i+j)) ) et B22 = ( 2(.5 - sin(ij)) )
!>             pour i=m+1,...,k,  j=m+1,...,k
!>
!> Type 5 :  (A,B) et ont des valeurs propres potentiellement proches ou communes et
!>          un très grand départ de la diagonale par blocs A_11 est choisi
!>          comme la sous-matrice principale m x m de A_1 :
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          et A_22 est choisi comme la sous-matrice principale k x k de A_2 :
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |                       -d  1+b    |
!>                  |                      -1+b  -d    |
!>                  |                              1-d |
!>          et la matrice B sont choisies comme des matrices identité (voir SLATM5).
!>
!>

Paramètres

NSIZE 
!>          NSIZE est un entier
!>          La taille maximale des matrices à utiliser. NSIZE >= 0.
!>          Si NSIZE = 0
, aucune matrice de test intégrée n'est utilisée, mais !> des matrices de test lues sont utilisées pour tester SGGESX. !>

NCMAX

!>          NCMAX est INTEGER
!>          NMAX maximal autorisé pour générer la matrice de Kronecker
!>          dans l'appel à SLAKF2
!>

THRESH

!>          THRESH est REAL
!>          Un test sera compté comme si le, calculé comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH doit être un multiple raisonnable
!>          de 1, par exemple, 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple ou double)
!>          ou de la taille de la matrice. THRESH >= 0.
!>

NIN

!>          NIN est INTEGER
!>          Le numéro d'unité FORTRAN pour lire le fichier de données des
!>          problèmes à résoudre.
!>

NOUT

!>          NOUT est INTEGER
!>          Le numéro d'unité FORTRAN pour imprimer les messages d'erreur
!>          (par exemple, si une routine retourne IINFO différent de 0.)
!>

A

!>          A est un tableau REAL, de dimension (LDA, NSIZE)
!>          Utilisé pour stocker la matrice dont les valeurs propres doivent être
!>          calculées. En sortie, A contient la dernière matrice effectivement utilisée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A, B, AI, BI, Z et Q,
!>          LDA >= max( 1, NSIZE ). Pour le test lu,
!>          LDA >= max( 1, N ), N est la taille des matrices de test.
!>

B

!>          B est un tableau REAL, de dimension (LDA, NSIZE)
!>          Utilisé pour stocker la matrice dont les valeurs propres doivent être
!>          calculées. En sortie, B contient la dernière matrice effectivement utilisée.
!>

AI

!>          AI est un tableau REAL, de dimension (LDA, NSIZE)
!>          Copie de A, modifiée par SGGESX.
!>

BI

!>          BI est un tableau REAL, de dimension (LDA, NSIZE)
!>          Copie de B, modifiée par SGGESX.
!>

Z

!>          Z est un tableau REAL, de dimension (LDA, NSIZE)
!>          Z contient les vecteurs de Schur gauches calculés par SGGESX.
!>

Q

!>          Q est un tableau REAL, de dimension (LDA, NSIZE)
!>          Q contient les vecteurs de Schur droits calculés par SGGESX.
!>

ALPHAR

!>          ALPHAR est un tableau REAL, de dimension (NSIZE)
!>

ALPHAI

!>          ALPHAI est un tableau REAL, de dimension (NSIZE)
!>

BETA

!>          BETA est un tableau REAL, de dimension (NSIZE)
!> \verbatim
!>          En sortie, (ALPHAR + ALPHAI*i)/BETA sont les valeurs propres.
!>

C

!>          C est un tableau REAL, de dimension (LDC, LDC)
!>          Stocke la matrice générée par la sous-routine SLAKF2, c'est la
!>          matrice formée par les produits de Kronecker utilisés pour estimer
!>          DIF.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale de C. LDC >= max(1, LDA*LDA/2 ).
!>

S

!>          S est un tableau REAL, de dimension (LDC)
!>          Valeurs singulières de C
!>

WORK

!>          WORK est un tableau REAL, de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX( 5*NSIZE*NSIZE/2 - 2, 10*(NSIZE+1) )
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (LIWORK)
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK. LIWORK >= NSIZE + 6.
!>

BWORK

!>          BWORK est un tableau LOGICAL, de dimension (LDA)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  Une routine a retourné un code d'erreur.
!>
