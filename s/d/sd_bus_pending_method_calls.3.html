NOM

sd_bus_pending_method_calls - Retourne le nombre d'appels de méthode en attente en cours

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_pending_method_calls(sd_bus *bus);

DESCRIPTION

sd_bus_pending_method_calls() retourne le nombre d'appels de méthode sortants en attente en cours, c'est-à-dire les appels de méthode mis en file d'attente avec sd_bus_call_async(3) pour lesquels aucune réponse n'a encore été reçue, et qui n'ont pas encore atteint leur délai d'expiration.

L'argument bus peut être NULL, auquel cas zéro est retourné.

VALEUR DE RETOUR

Cette fonction retourne 0 s'il n'y a pas d'appels de méthode en attente, ou si un objet bus NULL a été spécifié. En cas d'échec, un code d'erreur négatif de style errno est retourné.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() qu'à partir d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_pending_method_calls() a été ajouté dans la version 257.
