SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOM

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Ajouter, supprimer et récupérer des pairs de bus suivies dans un objet de suivi de pairs de bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPTION

sd_bus_track_add_name() ajoute une paire à suivre à un objet de suivi de paires de bus. Le premier argument doit faire référence à un objet de suivi de paires de bus créé avec sd_bus_track_new(3), le second nom doit faire référence à un nom de paire D-Bus à suivre, au format de service connu ou unique. Si le nom n'est pas encore suivi, il sera ajouté à la liste des noms à suivre. S'il est déjà suivi et que le mode non récursif est activé, aucune opération n'est exécutée par cet appel. Si le mode récursif est activé, un compteur par nom est incrémenté d'une unité à chaque invocation de cet appel, et sd_bus_track_remove_name() doit être appelé autant de fois que sd_bus_track_add_name() a été invoqué avant pour arrêter le suivi du nom. Utilisez sd_bus_track_set_recursive(3) pour passer du mode non récursif par défaut au mode récursif, ou inversement. Notez que le nom spécifié est suivi tel quel, les noms connus ne sont pas résolus en noms uniques par cet appel. Notez que plusieurs objets de suivi de paires de bus peuvent suivre le même nom.

sd_bus_track_remove_name() annule l'effet de sd_bus_track_add_name() et supprime un nom de paire de bus de la liste des paires à surveiller. Selon que le mode non récursif ou récursif est activé pour l'objet de suivi de paires de bus, cet appel soit supprimera le nom complètement de l'objet de suivi, soit décrémentera simplement le compteur par nom d'une unité, supprimant le nom uniquement lorsque le compteur atteint zéro (voir ci-dessus). Notez qu'une paire de bus se déconnectant du bus supprimera implicitement ses noms complètement de l'objet de suivi de paires de bus, indépendamment du compteur par nom actuel.

sd_bus_track_add_sender() et sd_bus_track_remove_sender() sont similaires à sd_bus_track_add_name() et sd_bus_track_remove_name() mais prennent un message de bus comme argument. L'expéditeur de ce message de bus est déterminé et ajouté/supprimé de l'objet de suivi de paires de bus. Comme les messages proviennent toujours de noms uniques, et jamais de noms connus, cela signifie que cet appel ajoutera effectivement uniquement des noms uniques à l'objet de suivi de paires de bus.

sd_bus_track_count() renvoie le nombre de noms actuellement suivis par l'objet de suivi de paires de bus spécifié. Notez que cette fonction renvoie toujours le nombre réel de noms suivis, et donc si sd_bus_track_add_name() a été invoqué plusieurs fois pour le même nom, il n'est compté qu'une seule fois, que le mode récursif soit utilisé ou non.

sd_bus_track_count_name() renvoie le compteur par nom actuel pour le nom spécifié. Si le mode non récursif est utilisé, il renvoie soit 1 soit 0, selon que le nom spécifié a déjà été ajouté à l'objet de suivi, ou non. Si le mode récursif a été activé, des valeurs supérieures à 1 peuvent également être renvoyées, si sd_bus_track_add_name() a été appelé plusieurs fois pour le même nom.

sd_bus_track_count_sender() est similaire à sd_bus_track_count_name(), mais prend un objet message de bus et renvoie le compteur par nom correspondant à l'expéditeur du message.

sd_bus_track_contains() peut être utilisé pour déterminer si le nom spécifié a été ajouté au moins une fois à l'objet de suivi de paires de bus spécifié.

sd_bus_track_first() et sd_bus_track_next() peuvent être utilisés pour énumérer tous les noms actuellement suivis par l'objet de suivi de paires de bus passé. sd_bus_track_first() renvoie la première entrée dans l'objet, et réinitialise un index de lecture interne. Chaque invocation subséquente de sd_bus_track_next() renvoie le nom suivant contenu dans l'objet de bus. Si la fin est atteinte, NULL est renvoyé. Si aucun nom n'a encore été ajouté à l'objet, sd_bus_track_first() renverra immédiatement NULL. L'ordre dans lequel les noms sont renvoyés n'est pas défini ; en particulier, le nom considéré comme le premier renvoyé n'est pas défini. Si le mode récursif est activé et que le même nom a été ajouté plusieurs fois à l'objet de suivi de paires de bus, il n'est renvoyé qu'une seule fois par cette énumération. Si de nouveaux noms sont ajoutés ou si des noms existants sont supprimés de l'objet de suivi de paires de bus pendant qu'il est en cours d'énumération, l'énumération se termine lors de la prochaine invocation de sd_bus_track_next() car NULL est renvoyé.

VALEUR RENVOYÉE

En cas de succès, sd_bus_track_add_name() et sd_bus_track_add_sender() renvoient 0 si le nom spécifié a déjà été ajouté auparavant à l'objet de suivi de paires de bus, et une valeur positive s'il ne l'a pas été. En cas d'échec, ils renvoient un code d'erreur négatif de type errno.

sd_bus_track_remove_name() et sd_bus_track_remove_sender() renvoient une valeur positive si le nom spécifié était précédemment suivi par l'objet de suivi de paires de bus et a maintenant été supprimé. En mode non récursif, 0 est renvoyé si le nom spécifié n'était pas encore suivi. En mode récursif, -EUNATCH est renvoyé dans ce cas. En cas d'échec, ils renvoient un code d'erreur négatif de type errno.

sd_bus_track_count() renvoie le nombre de noms actuellement suivis, ou 0 en cas d'échec.

sd_bus_track_count_name() et sd_bus_track_count_sender() renvoient le compteur par nom actuel pour le nom spécifié ou l'expéditeur du message spécifié. Zéro est renvoyé pour les noms qui ne sont pas encore suivis, une valeur positive pour les noms ajoutés au moins une fois. Des valeurs supérieures à 1 ne sont renvoyées qu'en mode récursif. En cas d'échec, un code d'erreur négatif de type errno est renvoyé.

sd_bus_track_contains() renvoie le nom passé s'il existe dans l'objet de suivi de paires de bus. En cas d'échec, et si le nom n'a pas encore été ajouté, NULL est renvoyé.

sd_bus_track_first() et sd_bus_track_next() renvoient le premier/prochain nom contenu dans l'objet de suivi de paires de bus, et NULL si la fin de l'énumération est atteinte et en cas d'erreur.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EUNATCH

sd_bus_track_remove_name() ou sd_bus_track_remove_sender() ont été invoqués pour un nom non ajouté auparavant à l'objet de paire de bus.

-EINVAL

Le paramètre spécifié est invalide.

-ENOMEM

Échec de l'allocation mémoire.

sd_bus_track_count(3) — systemd 258.2

NAME

sd_bus_track_count, sd_bus_track_count_name, sd_bus_track_count_sender — Compter les objets suivi par un bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_count(sd_bus_track *track);
int sd_bus_track_count_name(sd_bus_track *track, const char *name);
int sd_bus_track_count_sender(sd_bus_track *track, uint64_t sender);

DESCRIPTION

The function sd_bus_track_count() returns the total number of objects currently being tracked by the bus tracker track. The count represents all tracked objects, regardless of whether they were added via name or sender ID.

The function sd_bus_track_count_name() returns the number of objects currently being tracked by the bus tracker track that were added with the specified bus name name.

The function sd_bus_track_count_sender() returns the number of objects currently being tracked by the bus tracker track that were added with the specified sender ID sender.

A bus tracker object is created using sd_bus_track_new(). Objects are added to the tracker using sd_bus_track_add_name() and sd_bus_track_add_sender(). Objects are removed using sd_bus_track_remove_name() and sd_bus_track_remove_sender().

RETURN VALUE

On success, these functions return the number of tracked objects. On failure, they return a negative errno value.

NOTES

These functions are safe to call from any thread. They do not acquire any locks and may be used in the early phase of the program when no other threads have been started.

HISTORY

sd_bus_track_add_name(), sd_bus_track_add_sender(), sd_bus_track_remove_name(), sd_bus_track_remove_sender(), sd_bus_track_count(), sd_bus_track_count_name(), sd_bus_track_count_sender(), sd_bus_track_contains(), sd_bus_track_first(), and sd_bus_track_next() were added in version 232.
