!>
!> SDRVBD vérifie les pilotes de décomposition en valeurs singulières (SVD)
!> SGESVD, SGESDD, SGESVDQ, SGESVJ, SGEJSV et DGESVDX.
!>
!> SGESVD et SGESDD factorisent A = U diag(S) VT, où U et VT sont
!> orthogonales et diag(S) est diagonale avec les entrées du tableau S
!> sur sa diagonale. Les entrées de S sont les valeurs singulières,
!> non négatives et stockées par ordre décroissant. U et VT peuvent
!> éventuellement ne pas être calculées, être écrasées sur A, ou être calculées partiellement.
!>
!> A est de taille M par N. Soit MNMIN = min( M, N ). S a une dimension MNMIN.
!> U peut être de taille M par M ou M par MNMIN. VT peut être de taille N par N ou MNMIN par N.
!>
!> Lorsque SDRVBD est appelée, un nombre de tailles de matrices (M et N)
!> et un nombre de types de matrices sont spécifiés. Pour chaque taille (M,N)
!> et chaque type de matrice, et pour l'espace de travail minimal ainsi que
!> l'espace de travail suffisant pour permettre le blocage, une matrice M x N
!> sera générée et utilisée pour tester les routines SVD. Pour chaque matrice, A sera
!> factorisée en A = U diag(S) VT et les 12 tests suivants seront calculés :
!>
!> Test pour SGESVD :
!>
!> (1)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)    | I - U'U | / ( M ulp )
!>
!> (3)    | I - VT VT' | / ( N ulp )
!>
!> (4)    S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (5)    | U - Upartial | / ( M ulp ) où Upartial est un U calculé partiellement.
!>
!> (6)    | VT - VTpartial | / ( N ulp ) où VTpartial est un VT calculé partiellement.
!>
!> (7)    | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>        vecteur des valeurs singulières provenant de la SVD partielle.
!>
!> Test pour SGESDD :
!>
!> (8)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)    | I - U'U | / ( M ulp )
!>
!> (10)   | I - VT VT' | / ( N ulp )
!>
!> (11)   S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (12)   | U - Upartial | / ( M ulp ) où Upartial est un U calculé partiellement.
!>
!> (13)   | VT - VTpartial | / ( N ulp ) où VTpartial est un VT calculé partiellement.
!>
!> (14)   | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>        vecteur des valeurs singulières provenant de la SVD partielle.
!>
!> Test pour SGESVDQ :
!>
!> (36)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)   | I - U'U | / ( M ulp )
!>
!> (38)   | I - VT VT' | / ( N ulp )
!>
!> (39)   S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour SGESVJ :
!>
!> (15)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)   | I - U'U | / ( M ulp )
!>
!> (17)   | I - VT VT' | / ( N ulp )
!>
!> (18)   S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour SGEJSV :
!>
!> (19)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)   | I - U'U | / ( M ulp )
!>
!> (21)   | I - VT VT' | / ( N ulp )
!>
!> (22)   S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour SGESVDX( 'V', 'V', 'A' )/SGESVDX( 'N', 'N', 'A' )
!>
!> (23)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)   | I - U'U | / ( M ulp )
!>
!> (25)   | I - VT VT' | / ( N ulp )
!>
!> (26)   S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (27)   | U - Upartial | / ( M ulp ) où Upartial est un U calculé partiellement.
!>
!> (28)   | VT - VTpartial | / ( N ulp ) où VTpartial est un VT calculé partiellement.
!>
!> (29)   | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>        vecteur des valeurs singulières provenant de la SVD partielle.
!>
!> Test pour SGESVDX( 'V', 'V', 'I' )
!>
!> (30)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)   | I - U'U | / ( M ulp )
!>
!> (32)   | I - VT VT' | / ( N ulp )
!>
!> Test pour SGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Les tailles (M,N) sont spécifiées par les tableaux MM(1:NSIZES) et
!> NN(1:NSIZES) ; la valeur de chaque paire d'éléments (MM(j),NN(j))
!> spécifie une taille. Les types de matrices sont spécifiés par un tableau logique
!> DOTYPE( 1:NTYPES ) ; si DOTYPE(j) est .VRAI., alors la matrice de type
!> j sera générée.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!> (3)  Une matrice de la forme U D V, où U et V sont orthogonales et
!>      D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>      sur la diagonale.
!> (4)  Identique à (3), mais multipliée par le seuil de sous-dépassement / ULP.
!> (5)  Identique à (3), mais multipliée par le seuil de dépassement * ULP.
!>

Paramètres

NSIZES 
!>          NSIZES est un entier
!>          Le nombre de tailles de matrices (M,N) contenues dans les vecteurs
!>          MM et NN.
!>

MM

!>          MM est un tableau d'entiers, dimension (NSIZES)
!>          Les valeurs de la dimension ligne M de la matrice.
!>

NN

!>          NN est un tableau d'entiers, dimension (NSIZES)
!>          Les valeurs de la dimension colonne N de la matrice.
!>

NTYPES

!>          NTYPES est un entier
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, SDRVBD
!>          ne fait rien. Il doit être au moins zéro. S'il est MAXTYP+1
!>          et NSIZES est 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser les matrices présentes dans A et B.
!>          Ceci n'est utile que si DOTYPE(1:MAXTYP) est .FAUX. et
!>          DOTYPE(MAXTYP+1) est .VRAI. .
!>

DOTYPE

!>          DOTYPE est un tableau logique, dimension (NTYPES)
!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille (m,n), une matrice
!>          de type j sera générée. Si NTYPES est inférieur au
!>          nombre maximum de types définis (PARAMÈTRE MAXTYP), alors
!>          les types NTYPES+1 à MAXTYP ne seront pas générés. Si
!>          NTYPES est supérieur à MAXTYP, DOTYPE(MAXTYP+1) à
!>          DOTYPE(NTYPES) seront ignorés.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires. Les éléments
!>          du tableau doivent être compris entre 0 et 4095 ; sinon ils seront
!>          réduits modulo 4096. De plus, ISEED(4) doit être impair.
!>          À la sortie, ISEED est modifié et peut être utilisé dans l'appel suivant à
!>

THRESH

!>          THRESH est REAL
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Les rapports de test
!>          sont mis à l'échelle pour être O(1), donc THRESH devrait être un multiple
!>          faible de 1, par exemple, 10 ou 100. Pour que chaque rapport de test
!>          soit imprimé, utilisez THRESH = 0.
!>

A

!>          A est un tableau de REAL, de dimension (LDA,NMAX)
!>          où NMAX est la valeur maximale de N dans NN.
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,MMAX),
!>          où MMAX est la valeur maximale de M dans MM.
!>

U

!>          U est un tableau de REAL, de dimension (LDU,MMAX)
!>

LDU

!>          LDU est un INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,MMAX).
!>

VT

!>          VT est un tableau de REAL, de dimension (LDVT,NMAX)
!>

LDVT

!>          LDVT est un INTEGER
!>          La dimension principale du tableau VT. LDVT >= max(1,NMAX).
!>

ASAV

!>          ASAV est un tableau de REAL, de dimension (LDA,NMAX)
!>

USAV

!>          USAV est un tableau de REAL, de dimension (LDU,MMAX)
!>

VTSAV

!>          VTSAV est un tableau de REAL, de dimension (LDVT,NMAX)
!>

S

!>          S est un tableau de REAL, de dimension
!>                      (max(min(MM,NN)))
!>

SSAV

!>          SSAV est un tableau de REAL, de dimension
!>                      (max(min(MM,NN)))
!>

E

!>          E est un tableau de REAL, de dimension
!>                      (max(min(MM,NN)))
!>

WORK

!>          WORK est un tableau de REAL, de dimension (LWORK)
!>

LWORK

!>          LWORK est un INTEGER
!>          Le nombre d'entrées dans WORK. Il doit être au moins
!>          max(3*MN+MX,5*MN-4)+2*MN**2 pour toutes les paires
!>          paires  (MN,MX)=( min(MM(j),NN(j), max(MM(j),NN(j)) )
!>

IWORK

!>          IWORK est un tableau de INTEGER, de dimension au moins 8*min(M,N)
!>

NOUT

!>          NOUT est un INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie IINFO différent de 0).
!>

INFO

!>          INFO est un INTEGER
!>          Si 0, alors tout s'est bien passé.
!>           -1: NSIZES < 0
!>           -2: Certains MM(j) < 0
!>           -3: Certains NN(j) < 0
!>           -4: NTYPES < 0
!>           -7: THRESH < 0
!>          -10: LDA < 1 ou LDA < MMAX, où MMAX est max( MM(j) ).
!>          -12: LDU < 1 ou LDU < MMAX.
!>          -14: LDVT < 1 ou LDVT < NMAX, où NMAX est max( NN(j) ).
!>          -21: LWORK trop petit.
!>          Si SLATMS, ou SGESVD renvoie un code d'erreur, la
!>              valeur absolue de celui-ci est retournée.
!>
