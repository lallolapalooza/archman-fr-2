SD_BUS_SET_PROPERTY(3) sd_bus_set_property SD_BUS_SET_PROPERTY(3)

NOM

sd_bus_set_property, sd_bus_set_propertyv, sd_bus_get_property, sd_bus_get_property_trivial, sd_bus_get_property_string, sd_bus_get_property_strv - Définir ou interroger les propriétés d'un service D-Bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_set_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, ...);

int sd_bus_set_propertyv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, va_list ap);

int sd_bus_get_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, sd_bus_message **reply, const char *type);

int sd_bus_get_property_trivial(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char type, void *ret_ptr);

int sd_bus_get_property_string(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char **ret);

int sd_bus_get_property_strv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char ***ret);

DESCRIPTION

Ces fonctions définissent ou interrogent les propriétés D-Bus. Les propriétés D-Bus sont des champs de service exposés via l'interface org.freedesktop.DBus.Properties. Ces fonctions appellent en coulisses les méthodes de l'interface org.freedesktop.DBus.Properties et, par conséquent, leurs sémantiques sont similaires à celles de sd_bus_call_method(3).

sd_bus_set_property() définit une propriété D-Bus. Si la définition de la propriété échoue ou si une erreur interne se produit, une erreur est retournée et une description étendue de l'erreur est éventuellement stockée dans ret_error si celui-ci n'est pas NULL. type et les arguments qui le suivent décrivent la nouvelle valeur de la propriété et doivent suivre le format décrit dans sd_bus_message_append(3).

sd_bus_set_propertyv() est équivalent à sd_bus_set_property(), à l'exception qu'il est appelé avec une "va_list" au lieu d'un nombre variable d'arguments.

sd_bus_get_property() interroge une propriété D-Bus. Si la récupération de la propriété échoue ou si une erreur interne se produit, une erreur est retournée et une description étendue de l'erreur est éventuellement stockée dans ret_error si celui-ci n'est pas NULL. En cas de succès, la propriété est stockée dans reply. type décrit le type de la propriété et doit suivre le format décrit dans sd_bus_message_append(3).

sd_bus_get_property_trivial(), sd_bus_get_property_string() et sd_bus_get_property_strv() sont des raccourcis pour sd_bus_get_property() utilisés pour interroger respectivement les propriétés de base, de chaîne de caractères et de vecteur de chaînes de caractères. L'appelant est responsable de libérer les résultats de chaîne et de vecteur de chaînes stockés dans ret par sd_bus_get_property_string() et sd_bus_get_property_strv().

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent un entier non négatif. En cas d'échec, elles retournent un code d'erreur négatif de type errno.

Erreurs

Voir la page de manuel sd_bus_call_method(3) pour une liste des erreurs possibles.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme non thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que lors d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_set_property(), sd_bus_set_propertyv(), sd_bus_get_property(), sd_bus_get_property_trivial(), sd_bus_get_property_string() et sd_bus_get_property_strv() ont été ajoutées dans la version 246.
