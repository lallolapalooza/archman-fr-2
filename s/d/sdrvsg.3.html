!>      Lorsque SDRVSG est appelé, un certain nombre de tailles de matrices et un
!>      certain nombre de types de matrices sont spécifiés. Pour chaque taille et
!>      chaque type de matrice, une matrice A du type donné sera générée ; une
!>      matrice B bien conditionnée et aléatoire est également générée et la paire
!>      (A,B) est utilisée pour tester les pilotes.
!>
!>      Pour chaque paire (A,B), les tests suivants sont effectués :
!>
!>      (1) SSYGV avec ITYPE = 1 et UPLO ='U' :
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!>      (2) comme (1) mais en appelant SSPGV
!>      (3) comme (1) mais en appelant SSBGV
!>      (4) comme (1) mais avec UPLO = 'L'
!>      (5) comme (4) mais en appelant SSPGV
!>      (6) comme (4) mais en appelant SSBGV
!>
!>      (7) SSYGV avec ITYPE = 2 et UPLO ='U' :
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) comme (7) mais en appelant SSPGV
!>      (9) comme (7) mais avec UPLO = 'L'
!>      (10) comme (9) mais en appelant SSPGV
!>
!>      (11) SSYGV avec ITYPE = 3 et UPLO ='U' :
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) comme (11) mais en appelant SSPGV
!>      (13) comme (11) mais avec UPLO = 'L'
!>      (14) comme (13) mais en appelant SSPGV
!>
!>      SSYGVD, SSPGVD et SSBGVD ont effectué les 14 mêmes tests.
!>
!>      SSYGVX, SSPGVX et SSBGVX ont effectué les 14 tests ci-dessus avec
!>      les paramètres RANGE = 'A', 'N' et 'I', respectivement.
!>
!>      Les tailles de matrices sont spécifiées par un tableau NN(1:NSIZES) ; la valeur
!>      de chaque élément NN(j) spécifie une taille.
!>      Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!>      si DOTYPE(j) est .VRAI., alors le type de matrice j sera généré.
!>      Ce type est utilisé pour la matrice A qui a une demi-bande KA.
!>      B est générée comme une matrice définie positive bien conditionnée
!>      avec une demi-bande KB (<= KA).
!>      Actuellement, la liste des types possibles pour A est :
!>
!>      (1) La matrice nulle.
!>      (2) La matrice identité.
!>
!>      (3) Une matrice diagonale avec des entrées régulièrement espacées
!>           1, ..., ULP et des signes aléatoires.
!>           (ULP = (premier nombre supérieur à 1) - 1 )
!>      (4) Une matrice diagonale avec des entrées géométriquement espacées
!>           1, ..., ULP et des signes aléatoires.
!>      (5) Une matrice diagonale avec des entrées en progression géométrique
!>           1, ULP, ..., ULP et des signes aléatoires.
!>
!>      (6) Identique à (4), mais multipliée par SQRT( seuil de dépassement )
!>      (7) Identique à (4), mais multipliée par SQRT( seuil de sous-dépassement )
!>
!>      (8) Une matrice de la forme U* D U, où U est orthogonale et
!>           D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (9) Une matrice de la forme U* D U, où U est orthogonale et
!>           D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (10) Une matrice de la forme U* D U, où U est orthogonale et
!>           D a des entrées en progression géométrique 1, ULP,..., ULP avec des signes
!>           aléatoires sur la diagonale.
!>
!>      (11) Identique à (8), mais multipliée par SQRT( seuil de dépassement )
!>      (12) Identique à (8), mais multipliée par SQRT( seuil de sous-dépassement )
!>
!>      (13) Matrice symétrique avec des entrées aléatoires choisies parmi (-1,1).
!>      (14) Identique à (13), mais multipliée par SQRT( seuil de dépassement )
!>      (15) Identique à (13), mais multipliée par SQRT( seuil de sous-dépassement)

!>      (16) Identique à (8), mais avec KA = 1 et KB = 1
!>      (17) Identique à (8), mais avec KA = 2 et KB = 1
!>      (18) Identique à (8), mais avec KA = 2 et KB = 2
!>      (19) Identique à (8), mais avec KA = 3 et KB = 1
!>      (20) Identique à (8), mais avec KA = 3 et KB = 2

sdrvsg(3) - LAPACK manual

NAME

sdrvsg - generates the matrices A and B to be used in the nonsymmetric eigenvalue routines.

SYNOPSIS

CALL SDRVSG( NSIZES, NN, NTYPES, THRESH, NOUNIT, ISEED, A, LDA, B, LDB,
 D, Z, LDZ, AB, BB, AP, BP, WORK, NWORK, IWORK, LIWORK, RESULT, INFO )

Function/Subroutine Documentation

SUBROUTINE SDRVSG (NSIZES, NN, NTYPES, THRESH, NOUNIT, ISEED, A, LDA, B, LDB, D, Z, LDZ, AB, BB, AP, BP, WORK, NWORK, IWORK, LIWORK, RESULT, INFO)

!> Defines the arguments for the nonsymmetric eigenvalue problem driver routines.

!> Machine precision is the smallest number, eps, such that X+eps != X.

!>

!> NSIZES

INTEGER

!> The number of sizes of matrices to be generated.

!> NN

INTEGER array, dimension (NSIZES)

!> The sizes of the matrices to be generated. NN(j) is the dimension of the

!> square matrix for the j-th problem. NN(j) must be non-negative.

!>

!> NTYPES

INTEGER

!> The number of matrix types to be generated.

!> MAXTYP

INTEGER

!> The number of matrix types currently defined in the generators.

!> The types of matrices generated are:

!> 1 = matrix with random entries

!> 2 = matrix with random entries, diagonal

!> 3 = matrix with random entries, upper triangular

!> 4 = matrix with random entries, lower triangular

!> 5 = matrix with random entries, symmetric

!> 6 = matrix with random entries, skew-symmetric

!> 7 = matrix with random entries, Hermitian (if complex)

!> 8 = matrix with random entries, positive definite

!> 9 = matrix with random entries, indefinite

!> 10 = matrix with random entries, ill-conditioned

!>

!> Any types less than or equal to MAXTYP will be generated.

!> Any types greater than MAXTYP will be ignored.

!> Not modified.

!>

!> ISEED integer array, dimension (4)

!> On entry ISEED specifies the seed of the random number

!> generator. The array elements should be between 0 and 4095;

!> if not they will be reduced mod 4096. Also, ISEED(4) must

!> be odd. The random number generator uses a linear

!> congruential sequence limited to small integers, and so

!> should produce machine independent random numbers. The

!> values of ISEED are changed on exit, and can be used in the

!> next call to SDRVSG to continue the same random number

!> sequence.

!> Modified.

!>

!> THRESH REAL

!> A test will count as an error if the computed residual

!> (norm of A*Z - lambda*B*Z or A*Z - lambda*Z) exceeds THRESH.

!> Note that the error is scaled to be O(1), so THRESH should be a reasonably

!> small multiple of 1, e.g., 10 or 100. In particular,

!> it should not depend on the precision (single vs. double)

!> or the size of the matrix. It must be at least zero.

!> Not modified.

!>

!> NOUNIT INTEGER

!> The FORTRAN unit number for printing out error messages

!> (e.g., if a routine returns IINFO not equal to 0.)

!> Not modified.

!>

!> A REAL array, dimension (LDA , max(NN))

!> Used to hold the matrix whose eigenvalues are to be

!> computed. On exit, A contains the last matrix actually

!> used.

!> Modified.

!>

!> LDA INTEGER

!> The leading dimension of A and AB. It must be at

!> least 1 and at least max( NN ).

!> Not modified.

!>

!> B REAL array, dimension (LDB , max(NN))

!> Used to hold the symmetric positive definite matrix for

!> the generalized problem.

!> On exit, B contains the last matrix actually

!> used.

!> Modified.

!>

!> LDB INTEGER

!> The leading dimension of B and BB. It must be at

!> least 1 and at least max( NN ).

!> Not modified.

!>

!> D REAL array, dimension (max(NN))

!> The eigenvalues of A. On exit, the eigenvalues in D

!> correspond with the matrix in A.

!> Modified.

!>

!> Z REAL array, dimension (LDZ, max(NN))

!> The matrix of eigenvectors.

!> Modified.

!>

!> LDZ INTEGER

!> The leading dimension of Z. It must be at least 1 and

!> at least max( NN ).

!> Not modified.

!>

!> AB REAL array, dimension (LDA, max(NN))

!> Workspace.

!> Modified.

!>

!> BB REAL array, dimension (LDB, max(NN))

!> Workspace.

!> Modified.

!>

!> AP REAL array, dimension (max(NN)**2)

!> Workspace.

!> Modified.

!>

!> BP REAL array, dimension (max(NN)**2)

!> Workspace.

!> Modified.

!>

!> WORK REAL array, dimension (NWORK)

!> Workspace.

!> Modified.

!>

!> NWORK INTEGER

!> The number of entries in WORK. This must be at least

!> 1+5*N+2*N*lg(N)+3*N**2 where N = max( NN(j) ) and

!> lg( N ) = smallest integer k such that 2**k >= N.

!> Not modified.

!>

!> IWORK INTEGER array, dimension (LIWORK)

!> Workspace.

!> Modified.

!>

!> LIWORK INTEGER

!> The number of entries in WORK. This must be at least 6*N.

!> Not modified.

!>

!> RESULT REAL array, dimension (70)

!> The values computed by the 70 tests described above.

!> Modified.

!>

!> INFO INTEGER

!> If 0, then everything ran OK.

!> -1: NSIZES < 0

!> -2: Some NN(j) < 0

!> -3: NTYPES < 0

!> -5: THRESH < 0

!> -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).

!> -16: LDZ < 1 or LDZ < NMAX.

!> -21: NWORK too small.

!> -23: LIWORK too small.

!> If SLATMR, SLATMS, SSYGV, SSPGV, SSBGV, SSYGVD, SSPGVD,

!> SSBGVD, SSYGVX, SSPGVX or SSBGVX returns an error code,

!> the absolute value of it is returned.

!> Modified.

!>

!> ----------------------------------------------------------------------

!>

!> Some Local Variables and Parameters:

!> ---- ----- --------- --- ----------

!> ZERO, ONE Real 0 and 1.

!> MAXTYP The number of types defined.

!> NTEST The number of tests that have been run

!> on this matrix.

!> NTESTT The total number of tests for this call.

!> NMAX Largest value in NN.

!> NMATS The number of matrices generated so far.

!> NERRS The number of tests which have exceeded THRESH

!> so far (computed by SLAFTS).

!> COND, IMODE Values to be passed to the matrix generators.

!> ANORM Norm of A; passed to matrix generators.

!>

!> OVFL, UNFL Overflow and underflow thresholds.

!> ULP, ULPINV Finest relative precision and its inverse.

!> RTOVFL, RTUNFL Square roots of the previous 2 values.

!> The following four arrays decode JTYPE:

!> KTYPE(j) The general type (1-10) for type j.

!> KMODE(j) The MODE value to be passed to the matrix

!> generator for type j.

!> KMAGN(j) The order of magnitude ( O(1),

!> O(overflow^(1/2) ), O(underflow^(1/2) )
