SD_BUS_GET_NAME_CREDS(3) sd_bus_get_name_creds SD_BUS_GET_NAME_CREDS(3)

NOM

sd_bus_get_name_creds, sd_bus_get_owner_creds - Interroger les informations d'identification du client bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_get_name_creds(sd_bus *bus, const char *name, uint64_t mask, sd_bus_creds **creds);

int sd_bus_get_owner_creds(sd_bus *bus, uint64_t mask, sd_bus_creds **creds);

DESCRIPTION

sd_bus_get_name_creds() interroge les informations d'identification du client bus identifié par name. Le paramètre mask est une combinaison de drapeaux SD_BUS_CREDS_* indiquant quelles informations d'identification intéressent l'appelant. Voir sd_bus_creds_new_from_pid(3) pour une liste des drapeaux possibles. En cas de succès, creds contient une nouvelle instance sd_bus_creds avec les informations demandées. La propriété de cette instance appartient à l'appelant et elle doit être libérée une fois qu'elle n'est plus nécessaire en appelant sd_bus_creds_unref(3).

sd_bus_get_owner_creds() interroge les informations d'identification du créateur du bus donné. Les paramètres mask et creds se comportent de la même manière que dans sd_bus_get_name_creds().

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent un entier non négatif. En cas d'échec, elles retournent un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Un argument est invalide.

-ENOPKG

Le bus ne peut pas être résolu.

-EPERM

Le bus a déjà été démarré.

-ECHILD

Le bus a été créé dans un autre processus, bibliothèque ou instance de module.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_get_name_creds() et sd_bus_get_owner_creds() ont été ajoutées dans la version 221.
