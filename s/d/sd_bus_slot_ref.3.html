SD_BUS_SLOT_REF(3) sd_bus_slot_ref SD_BUS_SLOT_REF(3)

NOM

sd_bus_slot_ref, sd_bus_slot_unref, sd_bus_slot_unrefp - Créer et détruire des références à un objet slot de bus

SYNTAXE

#include <systemd/sd-bus.h>

sd_bus_slot *sd_bus_slot_ref(sd_bus_slot *slot);

sd_bus_slot *sd_bus_slot_unref(sd_bus_slot *slot);

void sd_bus_slot_unrefp(sd_bus_slot **slotp);

DESCRIPTION

sd_bus_slot_ref() augmente le compteur de références interne de slot d'une unité.

sd_bus_slot_unref() diminue le compteur de références interne de slot d'une unité. Une fois que le compteur de références est tombé à zéro, l'objet slot est détruit et ne peut plus être utilisé ; les appels ultérieurs à sd_bus_slot_ref() ou sd_bus_slot_unref() sont donc illégaux.

sd_bus_slot_unrefp() est similaire à sd_bus_slot_unref() mais prend un pointeur vers un pointeur vers un objet sd_bus_slot. Cet appel est utile en conjonction avec l'attribut de variable Clean-up[1] de GCC et LLVM. Voir sd_bus_new(3) pour un exemple d'utilisation de l'attribut cleanup.

sd_bus_slot_ref() et sd_bus_slot_unref() n'exécutent aucune opération si l'adresse de l'objet de bus passé est NULL. sd_bus_slot_unrefp() déréférencera d'abord son argument, qui ne doit pas être NULL, et n'exécutera aucune opération si *celui-ci* est NULL.

VALEUR RENVOYÉE

sd_bus_slot_ref() renvoie toujours l'argument.

sd_bus_slot_unref() renvoie toujours NULL.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que dès la phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_slot_ref(), sd_bus_slot_unref() et sd_bus_slot_unrefp() ont été ajoutés dans la version 240.
