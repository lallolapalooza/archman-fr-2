sous-routine sdrvst (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( * ) d1, real, dimension( * ) d2, real, dimension( * ) d3, real, dimension( * ) d4, real, dimension( * ) eveigs, real, dimension( * ) wa1, real, dimension( * ) wa2, real, dimension( * ) wa3, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldu, * ) v, real, dimension( * ) tau, real, dimension( ldu, * ) z, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, real, dimension( * ) result, integer info)

Objectif :

!>
!>      SDRVST  vérifie les drivers du problème de valeurs propres symétriques.
!>
!>              SSTEV calcule toutes les valeurs propres et, éventuellement, les
!>              vecteurs propres d'une matrice tridiagonale symétrique réelle.
!>
!>              SSTEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice tridiagonale symétrique réelle.
!>
!>              SSTEVR calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice tridiagonale symétrique réelle
!>              en utilisant la Représentation Relativement Robuste lorsque c'est possible.
!>
!>              SSYEV calcule toutes les valeurs propres et, éventuellement, les
!>              vecteurs propres d'une matrice symétrique réelle.
!>
!>              SSYEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle.
!>
!>              SSYEVR calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle
!>              en utilisant la Représentation Relativement Robuste lorsque c'est possible.
!>
!>              SSPEV calcule toutes les valeurs propres et, éventuellement, les
!>              vecteurs propres d'une matrice symétrique réelle en stockage
!>              compacté (packed).
!>
!>              SSPEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice symétrique réelle en stockage
!>              compacté (packed).
!>
!>              SSBEV calcule toutes les valeurs propres et, éventuellement, les
!>              vecteurs propres d'une matrice bande symétrique réelle.
!>
!>              SSBEVX calcule des valeurs propres sélectionnées et, éventuellement,
!>              les vecteurs propres d'une matrice bande symétrique réelle.
!>
!>              SSYEVD calcule toutes les valeurs propres et, éventuellement, les
!>              vecteurs propres d'une matrice symétrique réelle en utilisant
!>              un algorithme diviser pour régner.
!>
!>              SSPEVD calcule toutes les valeurs propres et, éventuellement, les
!>              vecteurs propres d'une matrice symétrique réelle en stockage
!>              compacté (packed), en utilisant un algorithme diviser pour régner.
!>
!>              SSBEVD calcule toutes les valeurs propres et, éventuellement, les
!>              vecteurs propres d'une matrice bande symétrique réelle,
!>              en utilisant un algorithme diviser pour régner.
!>
!>      Lorsque SDRVST est appelé, un certain nombre de tailles de matrices () et un
!>      certain nombre de types de matrices sont spécifiés. Pour chaque taille ()
!>      et chaque type de matrice, une matrice sera générée et utilisée
!>      pour tester les drivers appropriés. Pour chaque matrice et chaque
!>      routine de driver appelée, les tests suivants seront effectués :
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      où Z est la matrice des vecteurs propres retournée lorsque l'option de
!>      vecteurs propres est donnée et D1 et D2 sont les valeurs propres
!>      retournées avec et sans l'option de vecteurs propres.
!>
!>      Les tailles () sont spécifiées par un tableau NN(1:NSIZES) ; la valeur de
!>      chaque élément NN(j) spécifie une taille.
!>      Les types de matrices () sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!>      si DOTYPE(j) est .VRAI., alors le type de matrice j sera généré.
!>      Actuellement, la liste des types possibles est :
!>
!>      (1)  La matrice nulle.
!>      (2)  La matrice identité.
!>
!>      (3)  Une matrice diagonale avec des valeurs propres régulièrement espacées
!>           1, ..., ULP et des signes aléatoires.
!>           (ULP = (premier nombre supérieur à 1) - 1 )
!>      (4)  Une matrice diagonale avec des valeurs propres géométriquement espacées
!>           1, ..., ULP et des signes aléatoires.
!>      (5)  Une matrice diagonale avec des valeurs propres
!>           1, ULP, ..., ULP et des signes aléatoires.
!>
!>      (6)  Identique à (4), mais multipliée par SQRT( seuil de débordement )
!>      (7)  Identique à (4), mais multipliée par SQRT( seuil de sous-dépassement )
!>
!>      (8)  Une matrice de la forme  U' D U, où U est orthogonale et
!>           D a des entrées régulièrement espacées 1, ..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (9)  Une matrice de la forme  U' D U, où U est orthogonale et
!>           D a des entrées géométriquement espacées 1, ..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (10) Une matrice de la forme  U' D U, où U est orthogonale et
!>           D a des entrées 1, ULP,..., ULP avec des signes aléatoires
!>           sur la diagonale.
!>
!>      (11) Identique à (8), mais multipliée par SQRT( seuil de débordement )
!>      (12) Identique à (8), mais multipliée par SQRT( seuil de sous-dépassement )
!>
!>      (13) Matrice symétrique avec des entrées aléatoires choisies dans (-1,1).
!>      (14) Identique à (13), mais multipliée par SQRT( seuil de débordement )
!>      (15) Identique à (13), mais multipliée par SQRT( seuil de sous-dépassement )
!>      (16) Une matrice bande avec une demi-bande passante choisie aléatoirement entre
!>           0 et N-1, avec des valeurs propres régulièrement espacées 1, ..., ULP
!>           avec des signes aléatoires.
!>      (17) Identique à (16), mais multipliée par SQRT( seuil de débordement )
!>      (18) Identique à (16), mais multipliée par SQRT( seuil de sous-dépassement )
!> 
!>  NSIZES  INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est nul,
!>          SDRVST ne fait rien. Il doit être supérieur ou égal à zéro.
!>          Non modifié.
!>
!>  NN      INTEGER tableau, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.

!>          Si DOTYPE(j) est .VRAI., alors pour chaque taille dans NN, une

!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur

!>          Non modifié.

!>  ISEED   INTEGER tableau, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres

NAME

sdrvst - driver routines

SYNOPSIS

  SUBROUTINE sdrvst( A, LDA, B, LDB, C, LDC, D, LDDC, E, DUMMY,
 &                   WORK, LWORK, IWORK, LIWORK, INFO )

This subroutine is part of the LAPACK testing routines.

Function/Subroutine Documentation

!> \brief \
!>           The subroutine computes the difference between the result of
!>           a LAPACK eigenvalue routine and its reference routine.
!>
!> \details
!>           This subroutine computes the difference between the result of
!>           a LAPACK eigenvalue routine and its reference routine.
!>
!>           If the routine returns a traditional return value, the following
!>           values are defined:
!>
!>           = 0:  Success
!>           < 0:  -i indicates that the i-th argument is invalid.
!>
!>           To be added in 1999
!>
!>    75= |D(with Z) - D(w/o Z)| / (|D| ulp)    SSYEVR('L','N','I', ... )

!>    78= |D(with Z) - D(w/o Z)| / (|D| ulp)    SSYEVR('L','N','V', ... )
!>
!>    Tests 25 through 78 are repeated (as tests 79 through 132)
!>    with UPLO='U'

!>    To be added in 1999

!>    79= | A - U S U' | / ( |A| n ulp )        SSPEVR('L','V','A', ... )
