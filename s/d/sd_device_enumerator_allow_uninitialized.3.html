SD_DEVICE_ENUMERATOR_ADD_MATCH_PARENT(3) sd_device_enumerator_add_match_parent SD_DEVICE_ENUMERATOR_ADD_MATCH_PARENT(3)

NOM

sd_device_enumerator_add_match_parent, sd_device_enumerator_add_match_property, sd_device_enumerator_add_match_property_required, sd_device_enumerator_add_match_subsystem, sd_device_enumerator_add_match_sysattr, sd_device_enumerator_add_match_sysname, sd_device_enumerator_add_nomatch_sysname, sd_device_enumerator_add_match_tag, sd_device_enumerator_allow_uninitialized, sd_device_enumerator_add_all_parents - Ajouter un filtre à l'énumérateur de périphériques

SYNOPSIS

#include <systemd/sd-device.h>

int sd_device_enumerator_add_match_parent(sd_device_enumerator *enumerator, sd_device *parent);

int sd_device_enumerator_add_match_property(sd_device_enumerator *enumerator, const char *property, const char *value);

int sd_device_enumerator_add_match_property_required(sd_device_enumerator *enumerator, const char *property, const char *value);

int sd_device_enumerator_add_match_subsystem(sd_device_enumerator *enumerator, const char *subsystem, int match);

int sd_device_enumerator_add_match_sysattr(sd_device_enumerator *enumerator, const char *sysattr, const char *value, int match);

int sd_device_enumerator_add_match_sysname(sd_device_enumerator *enumerator, const char *sysname);

int sd_device_enumerator_add_nomatch_sysname(sd_device_enumerator *enumerator, const char *sysname);

int sd_device_enumerator_add_match_tag(sd_device_enumerator *enumerator, const char *tag);

int sd_device_enumerator_allow_uninitialized(sd_device_enumerator *enumerator);

int sd_device_enumerator_add_all_parents(sd_device_enumerator *enumerator);

DESCRIPTION

La fonction sd_device_enumerator_add_match_parent() ajoute un filtre à l'enumerator afin que seuls les périphériques sous l'arbre du parent spécifié soient énumérés. Si cette fonction est appelée plusieurs fois, le parent précédemment défini est effacé et seule le dernier appel prend effet.

La fonction sd_device_enumerator_add_match_property() ajoute un filtre à l'enumerator afin que seuls les périphériques dont la propriété spécifiée est égale à la valeur soient énumérés. La propriété et la valeur peuvent être des motifs glob. Lorsque cette fonction est appelée plusieurs fois, les périphériques qui ont au moins une des propriétés spécifiées avec des valeurs correspondantes sont énumérés. C'est-à-dire que les filtres sont combinés par un OU logique.

La fonction sd_device_enumerator_add_match_property_required() ajoute un filtre à l'enumerator afin que seuls les périphériques dont la propriété spécifiée est égale à la valeur soient énumérés. Cette fonction est similaire à sd_device_enumerator_add_match_property(), mais lorsque cette fonction est appelée plusieurs fois, les périphériques qui ont toutes les propriétés spécifiées avec des valeurs correspondantes sont énumérés. C'est-à-dire que les filtres sont combinés par un ET logique.

La fonction sd_device_enumerator_add_match_subsystem() ajoute un filtre à l'enumerator afin que tous les périphériques du sous-système spécifié soient inclus lorsque match est true. Lorsque match est false, tous les périphériques sauf ceux du sous-système spécifié sont énumérés. Lorsqu'elle est appelée plusieurs fois, les filtres positifs sont combinés par un OU logique, et les filtres négatifs par un ET logique.

La fonction sd_device_enumerator_add_match_sysattr() ajoute un filtre sur l'attribut sysfs sysattr correspondant à value. value peut être un motif glob. Si value est NULL, les périphériques qui ont (si match est true) ou n'ont pas (si match est false) le sysattr spécifié sont inclus, quelle que soit sa valeur. C'est-à-dire que NULL est principalement équivalent à "*". Lorsque cette fonction est appelée plusieurs fois, seuls les périphériques qui correspondent à tous les filtres sysattr spécifiés sont énumérés. C'est-à-dire que ces filtres sont combinés par un ET logique.

La fonction sd_device_enumerator_add_match_sysname() ajoute un filtre afin que seuls les périphériques dont le nom système (sysname) est égal à sysname soient énumérés. sysname peut être un motif glob. Lorsqu'elle est appelée plusieurs fois, les filtres sont combinés par un OU logique.

La fonction sd_device_enumerator_add_nomatch_sysname() ajoute un filtre afin que les périphériques dont le nom système (sysname) est égal à sysname soient exclus de l'énumération. Ceci est utile pour exclure des périphériques spécifiques du processus d'énumération. Lorsqu'elle est appelée plusieurs fois, les fonctionnalités sont combinées par un ET logique.

La fonction sd_device_enumerator_add_match_tag() ajoute un filtre afin que seuls les périphériques étiquetés avec tag soient énumérés. Lorsqu'elle est appelée plusieurs fois, les filtres sont combinés par un OU logique.

La fonction sd_device_enumerator_allow_uninitialized() permet d'inclure dans l'énumération les périphériques qui n'ont pas encore été initialisés par udev.

La fonction sd_device_enumerator_add_all_parents() énumère tous les périphériques parents des périphériques correspondants. Ceci est utile dans les cas où vous souhaitez inclure tous les périphériques parents dans l'énumération, par exemple lorsque vous vous intéressez à l'arbre de périphériques complet menant à un périphérique spécifique.

VALEUR RETOURNEE

Toutes les fonctions retournent 0 ou un entier positif en cas de succès, ou un code d'erreur négatif de style errno en cas d'échec.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ENOMEM

Échec de l'allocation mémoire.

-EINVAL

L'un des arguments est invalide.

EXEMPLES

Exemple 1. Détection des périphériques USB amovibles (Utilisation de Match et Exclude)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* Créer un nouvel énumérateur de périphériques */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Échec de la création de l'énumérateur de périphériques : %s\n", strerror(-r));
        return 1;
    }
    /* Inclure uniquement les périphériques du sous-système "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout du filtre de sous-système : %s\n", strerror(-r));
        return 1;
    }
    /*
     * Exclure les périphériques dont l'attribut sysfs "removable" est "0"
     * Ce sont généralement des périphériques non amovibles comme les interfaces USB intégrées
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout du filtre d'attribut sysfs : %s\n", strerror(-r));
        return 1;
    }
    /* Commencer à énumérer les périphériques correspondants */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* Obtenir le chemin système (syspath) du périphérique */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("Périphérique USB amovible trouvé : %s\n", syspath);
    }
    return 0;
}
