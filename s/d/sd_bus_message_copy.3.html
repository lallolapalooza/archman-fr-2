SD_BUS_MESSAGE_COPY(3) sd_bus_message_copy SD_BUS_MESSAGE_COPY(3)

NOM

sd_bus_message_copy - Copie le contenu d'un message à un autre

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_copy(sd_bus_message *m, sd_bus_message *source, int all);

DESCRIPTION

sd_bus_message_copy() copie le contenu du message source vers m. Si all est faux, un seul type complet est copié (basique ou conteneur). Si all est vrai, le contenu est copié jusqu'à la fin du conteneur actuellement ouvert ou jusqu'à la fin de source.

VALEUR DE RETOUR

En cas de succès, cet appel renvoie vrai si quelque chose a été copié, et faux s'il n'y avait rien à copier. En cas d'échec, il renvoie un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

source ou m sont NULL.

-EPERM

Le message m a été scellé ou source n'a pas été scellé.

-ESTALE

Le message de destination est dans un état invalide.

-ENXIO

Le message de destination ne peut pas être ajouté.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée à l'aide du fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme non sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() que dès le début du programme, lorsqu'aucun autre thread n'a été démarré.
