NOM

sd_bus_message_append_strv - Attacher un tableau de chaînes à un message

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_append_strv(sd_bus_message *m, char **l);

DESCRIPTION

La fonction sd_bus_message_append() peut être utilisée pour attacher un tableau de chaînes au message m. Le paramètre l doit pointer vers un tableau de pointeurs vers des chaînes terminées par NUL, se terminant lui-même par NULL. Chaque chaîne doit satisfaire les mêmes contraintes que celles décrites pour le type « s » dans sd_bus_message_append_basic(3).

La mémoire pointée par p et le contenu des chaînes elles-mêmes sont copiés dans la zone mémoire contenant le message et peuvent être modifiés après cet appel. Notez que la signature du paramètre l doit être traitée comme const char *const *, et le contenu ne sera pas modifié.

VALEUR DE RETOUR

En cas de succès, cet appel renvoie 0 ou un entier positif. En cas d'échec, un code d'erreur négatif de style errno est renvoyé.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre spécifié est invalide.

-EPERM

Le message a été scellé.

-ESTALE

Le message est dans un état invalide.

-ENXIO

Le message ne peut pas être ajouté.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() que dans une phase précoce du programme, lorsque aucun autre thread n'a été démarré.
