sd_bus_slot_get_current_message(3)

SD_BUS_SLOT_GET_BUS(3) sd_bus_slot_get_bus SD_BUS_SLOT_GET_BUS(3)

NOM

sd_bus_slot_get_bus, sd_bus_slot_get_current_handler, sd_bus_slot_get_current_message, sd_bus_slot_get_current_userdata - Interroger les informations attachées à un objet slot de bus

SYNTAXE

#include <systemd/sd-bus.h>

typedef int (*sd_bus_message_handler_t)(sd_bus_message *m, void *userdata, sd_bus_error *ret_error);

sd_bus *sd_bus_slot_get_bus(sd_bus_slot *slot);

sd_bus_message_handler_t sd_bus_slot_get_current_handler(sd_bus_slot *slot);

sd_bus_message *sd_bus_slot_get_current_message(sd_bus_slot *slot);

void *sd_bus_slot_get_current_userdata(sd_bus_slot *slot);

DESCRIPTION

sd_bus_slot_get_bus() renvoie l'objet bus auquel le message slot est attaché.

sd_bus_slot_get_current_handler(), sd_bus_slot_get_current_message() et sd_bus_slot_get_current_userdata() renvoient respectivement le gestionnaire, le message et les données utilisateur actuels du slot de bus auquel ils sont attachés, si nous exécutons actuellement le rappel associé à slot.

VALEUR RENVOYÉE

sd_bus_slot_get_bus() renvoie toujours l'objet bus.

En cas de succès, sd_bus_slot_get_current_handler(), sd_bus_slot_get_current_message() et sd_bus_slot_get_current_userdata() renvoient l'objet demandé. En cas d'échec, ils renvoient NULL.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer les appels à setenv() qu'à une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_slot_get_bus(), sd_bus_slot_get_current_handler(), sd_bus_slot_get_current_message(), et sd_bus_slot_get_current_userdata() ont été ajoutés dans la version 246.
