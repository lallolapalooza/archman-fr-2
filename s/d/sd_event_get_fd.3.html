SD_EVENT_GET_FD(3) sd_event_get_fd SD_EVENT_GET_FD(3)

NOM

sd_event_get_fd - Obtenir un descripteur de fichier pour interroger les événements de la boucle d'événements

SYNTAXE

#include <systemd/sd-event.h>

int sd_event_get_fd(sd_event *event);

DESCRIPTION

sd_event_get_fd() retourne le descripteur de fichier qu'un objet de boucle d'événements retourné par la fonction sd_event_new(3) utilise pour attendre les événements. Ce descripteur de fichier peut lui-même être interrogé pour les événements POLLIN/EPOLLIN. Cela permet d'intégrer une boucle d'événements sd-event(3) dans une autre boucle d'événements, potentiellement étrangère.

Le descripteur de fichier retourné fait référence à un objet epoll(7). Il est recommandé de ne pas le modifier en invoquant epoll_ctl(2) dessus, afin d'éviter d'interférer avec la logique interne et les hypothèses de la boucle d'événements.

VALEUR DE RETOUR

En cas de succès, sd_event_get_fd() retourne un descripteur de fichier non négatif. En cas d'échec, il retourne un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

event n'est pas un pointeur valide vers une structure sd_event.

-ECHILD

La boucle d'événements a été créée dans un autre processus, bibliothèque ou instance de module.

EXEMPLES

Exemple 1. Intégration dans la boucle d'événements GLib

/* SPDX-License-Identifier: MIT-0 */
#include <stdlib.h>
#include <glib.h>
#include <systemd/sd-event.h>
typedef struct SDEventSource {
  GSource source;
  GPollFD pollfd;
  sd_event *event;
} SDEventSource;
static gboolean event_prepare(GSource *source, gint *timeout_) {
  return sd_event_prepare(((SDEventSource *)source)->event) > 0;
}
static gboolean event_check(GSource *source) {
  return sd_event_wait(((SDEventSource *)source)->event, 0) > 0;
}
static gboolean event_dispatch(GSource *source, GSourceFunc callback, gpointer user_data) {
  return sd_event_dispatch(((SDEventSource *)source)->event) > 0;
}
static void event_finalize(GSource *source) {
  sd_event_unref(((SDEventSource *)source)->event);
}
static GSourceFuncs event_funcs = {
  .prepare = event_prepare,
  .check = event_check,
  .dispatch = event_dispatch,
  .finalize = event_finalize,
};
GSource *g_sd_event_create_source(sd_event *event) {
  SDEventSource *source;
  source = (SDEventSource *)g_source_new(&event_funcs, sizeof(SDEventSource));
  source->event = sd_event_ref(event);
  source->pollfd.fd = sd_event_get_fd(event);
  source->pollfd.events = G_IO_IN | G_IO_HUP | G_IO_ERR;
  g_source_add_poll((GSource *)source, &source->pollfd);
  return (GSource *)source;
}

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que dans une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.
