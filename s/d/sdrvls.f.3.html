sous-programme sdrvls (logique, dimension( * ) dotype, entier nm, entier, dimension( * ) mval, entier nn, entier, dimension( * ) nval, entier nns, entier, dimension( * ) nsval, entier nnb, entier, dimension( * ) nbval, entier, dimension( * ) nxval, reel thresh, logique tsterr, reel, dimension( * ) a, reel, dimension( * ) copya, reel, dimension( * ) b, reel, dimension( * ) copyb, reel, dimension( * ) c, reel, dimension( * ) s, reel, dimension( * ) copys, entier nout)

SDRVLS

Objectif :

!>
!> SDRVLS teste les routines de pilote de moindres carrés SGELS, SGELST,
!> SGETSLS, SGELSS, SGELSY et SGELSD.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>          La matrice de type j est générée comme suit :
!>          j=1 : A = U*D*V où U et V sont des matrices orthogonales aléatoires
!>               et D a des entrées aléatoires (> 0.1) prises dans une distribution
!>               uniforme (0,1). A est de rang plein.
!>          j=2 : Identique à 1, mais A est mise à l'échelle vers le haut.
!>          j=3 : Identique à 1, mais A est mise à l'échelle vers le bas.
!>          j=4 : A = U*D*V où U et V sont des matrices orthogonales aléatoires
!>               et D a 3*min(M,N)/4 entrées aléatoires (> 0.1) prises
!>               dans une distribution uniforme (0,1) et les entrées restantes
!>               sont mises à 0. A est de rang déficient.
!>          j=5 : Identique à 4, mais A est mise à l'échelle vers le haut.
!>          j=6 : Identique à 5, mais A est mise à l'échelle vers le bas.
!>

NM

!>          NM est un ENTIER
!>          Le nombre de valeurs de M contenues dans le vecteur MVAL.
!>

MVAL

!>          MVAL est un tableau ENTIER, de dimension (NM)
!>          Les valeurs de la dimension des lignes M de la matrice.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, de dimension (NN)
!>          Les valeurs de la dimension des colonnes N de la matrice.
!>

NNS

!>          NNS est un ENTIER
!>          Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau ENTIER, de dimension (NNS)
!>          Les valeurs du nombre de côtés droits NRHS.
!>

NNB

!>          NNB est un ENTIER
!>          Le nombre de valeurs de NB et NX contenus dans les
!>          tableaux NBVAL et NXVAL. Les paramètres de blocage sont utilisés
!>          par paires (NB,NX).
!>

NBVAL

!>          NBVAL est un tableau ENTIER, de dimension (NNB)
!>          Les valeurs de la taille de bloc NB.
!>

NXVAL

!>          NXVAL est un tableau ENTIER, de dimension (NNB)
!>          Les valeurs du point de croisement NX.
!>

THRESH

!>          THRESH est un REEL
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour imprimer
!>          chaque rapport de test, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui détermine si les sorties d'erreur doivent être testées.
!>

A

!>          A est un tableau REEL, de dimension (MMAX*NMAX)
!>          où MMAX est la valeur maximale de M dans MVAL et NMAX est la
!>          valeur maximale de N dans NVAL.
!>

COPYA

!>          COPYA est un tableau REEL, de dimension (MMAX*NMAX)
!>

B

!>          B est un tableau REEL, de dimension (MMAX*NSMAX)
!>          où MMAX est la valeur maximale de M dans MVAL et NSMAX est la
!>          valeur maximale de NRHS dans NSVAL.
!>

COPYB

!>          COPYB est un tableau REEL, de dimension (MMAX*NSMAX)
!>

C

!>          C est un tableau REEL, de dimension (MMAX*NSMAX)
!>

S

!>          S est un tableau REEL, de dimension
!>                      (min(MMAX,NMAX))
!>

COPYS

!>          COPYS est un tableau REEL, de dimension
!>                      (min(MMAX,NMAX))
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité de sortie.
!>
