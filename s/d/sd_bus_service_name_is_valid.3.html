sd_bus_service_name_is_valid(3)

SD_BUS_INTERFACE_NAME_IS_VALID(3) sd_bus_service_name_is_valid SD_BUS_INTERFACE_NAME_IS_VALID(3)

NOM

sd_bus_interface_name_is_valid, sd_bus_service_name_is_valid, sd_bus_member_name_is_valid, sd_bus_object_path_is_valid - Vérifier si une chaîne est un nom de bus valide ou un chemin d'objet

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_interface_name_is_valid(const char* p);

int sd_bus_service_name_is_valid(const char* p);

int sd_bus_member_name_is_valid(const char* p);

int sd_bus_object_path_is_valid(const char* p);

DESCRIPTION

sd_bus_interface_name_is_valid() vérifie si la chaîne donnée p est un nom d'interface de bus syntaxiquement valide. De même, sd_bus_service_name_is_valid() vérifie si l'argument est un nom de service de bus valide, sd_bus_member_name_is_valid() vérifie si l'argument est un nom de membre d'interface de bus valide, et sd_bus_object_path_is_valid() vérifie si l'argument est un chemin d'objet de bus valide. Ces fonctions vérifient généralement que seuls les caractères autorisés sont utilisés et que la longueur de la chaîne est dans les limites.

VALEUR DE RETOUR

Ces fonctions renvoient 1 si l'argument est un nom d'interface / service / membre ou un chemin d'objet valide, et 0 s'il ne l'est pas. Si l'argument est NULL, une erreur est renvoyée.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre p est NULL.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que depuis une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_interface_name_is_valid(), sd_bus_service_name_is_valid(), sd_bus_member_name_is_valid(), et sd_bus_object_path_is_valid() ont été ajoutés dans la version 246.
