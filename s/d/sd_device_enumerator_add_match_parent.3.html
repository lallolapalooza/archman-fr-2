SD_DEVICE_ENUMERATOR_ADD_MATCH_PARENT(3) sd_device_enumerator_add_match_parent SD_DEVICE_ENUMERATOR_ADD_MATCH_PARENT(3)

NOM

sd_device_enumerator_add_match_parent, sd_device_enumerator_add_match_property, sd_device_enumerator_add_match_property_required, sd_device_enumerator_add_match_subsystem, sd_device_enumerator_add_match_sysattr, sd_device_enumerator_add_match_sysname, sd_device_enumerator_add_nomatch_sysname, sd_device_enumerator_add_match_tag, sd_device_enumerator_allow_uninitialized, sd_device_enumerator_add_all_parents - Ajouter un filtre à l'énumérateur de périphériques

SYNTAXE

#include <systemd/sd-device.h>

int sd_device_enumerator_add_match_parent(sd_device_enumerator *enumerator, sd_device *parent);

int sd_device_enumerator_add_match_property(sd_device_enumerator *enumerator, const char *property, const char *value);

int sd_device_enumerator_add_match_property_required(sd_device_enumerator *enumerator, const char *property, const char *value);

int sd_device_enumerator_add_match_subsystem(sd_device_enumerator *enumerator, const char *subsystem, int match);

int sd_device_enumerator_add_match_sysattr(sd_device_enumerator *enumerator, const char *sysattr, const char *value, int match);

int sd_device_enumerator_add_match_sysname(sd_device_enumerator *enumerator, const char *sysname);

int sd_device_enumerator_add_nomatch_sysname(sd_device_enumerator *enumerator, const char *sysname);

int sd_device_enumerator_add_match_tag(sd_device_enumerator *enumerator, const char *tag);

int sd_device_enumerator_allow_uninitialized(sd_device_enumerator *enumerator);

int sd_device_enumerator_add_all_parents(sd_device_enumerator *enumerator);

DESCRIPTION

La fonction sd_device_enumerator_add_match_parent() ajoute un filtre à l'enumerator de sorte que seuls les périphériques sous l'arbre du périphérique parent spécifié soient énumérés. Si cette fonction est appelée plusieurs fois, le périphérique parent précédemment défini est effacé et seul le dernier appel prend effet.

La fonction sd_device_enumerator_add_match_property() ajoute un filtre à l'enumerator de sorte que seuls les périphériques dont la propriété spécifiée est égale à la valeur spécifiée soient énumérés. La propriété et la valeur peuvent être des motifs globaux. Lorsque cette fonction est appelée plusieurs fois, les périphériques qui ont au moins une des propriétés spécifiées avec des valeurs correspondantes sont énumérés. C'est-à-dire que les filtres sont combinés par OU.

La fonction sd_device_enumerator_add_match_property_required() ajoute un filtre à l'enumerator de sorte que seuls les périphériques dont la propriété spécifiée est égale à la valeur spécifiée soient énumérés. Cette fonction est similaire à sd_device_enumerator_add_match_property(), mais lorsqu'elle est appelée plusieurs fois, les périphériques qui ont toutes les propriétés spécifiées avec des valeurs correspondantes sont énumérés. C'est-à-dire que les filtres sont combinés par ET.

La fonction sd_device_enumerator_add_match_subsystem() ajoute un filtre à l'enumerator de sorte que tous les périphériques du sous-système spécifié soient inclus lorsque match est true. Lorsque match est false, tous les périphériques à l'exception de ceux du sous-système spécifié sont énumérés. Lorsque cette fonction est appelée plusieurs fois, les filtres positifs sont combinés par OU, et les filtres négatifs par ET.

La fonction sd_device_enumerator_add_match_sysattr() ajoute un filtre sur l'attribut sysfs sysattr correspondant à value. value peut être un motif glob. Si value est NULL, les périphériques qui possèdent (si match est true) ou ne possèdent pas (si match est false) le sysattr spécifié sont inclus, quelle que soit sa valeur. C'est-à-dire que NULL est essentiellement équivalent à "*". Lorsque cette fonction est appelée plusieurs fois, seuls les périphériques qui correspondent à tous les filtres sysattr spécifiés sont énumérés. C'est-à-dire que ces filtres sont combinés par ET.

La fonction sd_device_enumerator_add_match_sysname() ajoute un filtre de sorte que seuls les périphériques dont le nom système correspond à sysname soient énumérés. sysname peut être un motif glob. Lors d'appels multiples, les filtres sont combinés par OU.

La fonction sd_device_enumerator_add_nomatch_sysname() ajoute un filtre de sorte que les périphériques dont le nom système correspond à sysname soient exclus du processus d'énumération. Ceci est utile pour exclure des périphériques spécifiques de l'énumération. Lors d'appels multiples, les fonctions sont combinées par ET.

La fonction sd_device_enumerator_add_match_tag() ajoute un filtre de sorte que seuls les périphériques marqués avec tag soient énumérés. Lors d'appels multiples, les filtres sont combinés par OU.

La fonction sd_device_enumerator_allow_uninitialized() permet aux périphériques qui n'ont pas encore été initialisés par udev d'être inclus dans l'énumération.

La fonction sd_device_enumerator_add_all_parents() énumère tous les périphériques parents des périphériques correspondants. Ceci est utile dans les cas où vous souhaitez inclure tous les périphériques parents dans l'énumération, comme lorsque vous êtes intéressé par l'arbre entier des périphériques menant à un périphérique spécifique.

VALEUR DE RETOUR

Toutes les fonctions retournent 0 ou un entier positif en cas de succès, ou un code d'erreur négatif de style errno en cas d'échec.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ENOMEM

Échec de l'allocation de mémoire.

-EINVAL

Un des arguments est invalide.

EXEMPLES

Exemple 1. Détecter les périphériques USB amovibles (en utilisant la correspondance et l'exclusion)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* Créer un nouvel énumérateur de périphériques */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Échec de la création de l'énumérateur de périphériques : %s\n", strerror(-r));
        return 1;
    }
    /* Inclure uniquement les périphériques du sous-système "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout de la correspondance de sous-système : %s\n", strerror(-r));
        return 1;
    }
    /*
     * Exclure les périphériques où l'attribut système "removable" est "0"
     * Ce sont généralement des périphériques non amovibles comme les interfaces USB intégrées
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout de la correspondance sysattr : %s\n", strerror(-r));
        return 1;
    }
    /* Commencer à énumérer les périphériques correspondants */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* Obtenir le chemin système pour le périphérique */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("Périphérique USB amovible trouvé : %s\n", syspath);
    }
    return 0;
}

HISTORIQUE

Les fonctions sd_device_enumerator_add_match_parent(), sd_device_enumerator_add_match_property(), sd_device_enumerator_add_match_subsystem(), sd_device_enumerator_add_match_sysattr(), sd_device_enumerator_add_match_sysname(), sd_device_enumerator_add_match_tag() et sd_device_enumerator_allow_uninitialized() ont été ajoutées dans la version 240.

La fonction sd_device_enumerator_add_nomatch_sysname() a été ajoutée dans la version 251.

La fonction sd_device_enumerator_add_match_property_required() a été ajoutée dans la version 255.

sd_device_enumerator_add_all_parents(3) — systemd — Arch Linux

NAME

sd_device_enumerator_add_all_parents - Add all parents of a device to an enumerator

SYNOPSIS

#include <systemd/sd-device.h>

int sd_device_enumerator_add_all_parents(sd_device_enumerator *enumerator);

DESCRIPTION

The sd_device_enumerator_add_all_parents() function may be used to add all parent devices of the device specified in the enumerator to the enumerated set. This is useful when you want to match a device and all its ancestors. For example, if you want to match a partition, this will add the disk device and the controller device as well.

The enumerator parameter must point to a valid sd_device_enumerator object.

RETURN VALUE

On success, sd_device_enumerator_add_all_parents() returns a non-negative integer. On failure, it returns a negative errno value.

EXAMPLES

Add a device and all its parents to an enumerator:

#include <stdio.h>
#include <systemd/sd-device.h>

int main(int argc, char *argv[]) {
sd_device_enumerator *enumerator = NULL;
sd_device *device = NULL;
int r;

r = sd_device_enumerator_new(&enumerator);
if (r < 0) {
fprintf(stderr, "Failed to create device enumerator: %s\n", strerror(-r));
return 1;
}

r = sd_device_get_from_path(NULL, "/dev/sda1", &device);
if (r < 0) {
fprintf(stderr, "Failed to find device /dev/sda1: %s\n", strerror(-r));
sd_device_enumerator_unref(enumerator);
return 1;
}

r = sd_device_enumerator_add_device(enumerator, device);
if (r < 0) {
fprintf(stderr, "Failed to add device to enumerator: %s\n", strerror(-r));
sd_device_unref(device);
sd_device_enumerator_unref(enumerator);
return 1;
}
sd_device_unref(device);

r = sd_device_enumerator_add_all_parents(enumerator);
if (r < 0) {
fprintf(stderr, "Failed to add parents to enumerator: %s\n", strerror(-r));
sd_device_enumerator_unref(enumerator);
return 1;
}

/* Now you can iterate through the devices added to the enumerator */
sd_device_enumerator_unref(enumerator);
return 0;
}

HISTORY

sd_device_enumerator_add_all_parents() was added in version 258.
