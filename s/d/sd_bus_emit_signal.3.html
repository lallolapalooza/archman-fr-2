SD_BUS_EMIT_SIGNAL(3) sd_bus_emit_signal SD_BUS_EMIT_SIGNAL(3)

NOM

sd_bus_emit_signal, sd_bus_emit_signalv, sd_bus_emit_signal_to, sd_bus_emit_signal_tov, sd_bus_emit_interfaces_added, sd_bus_emit_interfaces_added_strv, sd_bus_emit_interfaces_removed, sd_bus_emit_interfaces_removed_strv, sd_bus_emit_properties_changed, sd_bus_emit_properties_changed_strv, sd_bus_emit_object_added, sd_bus_emit_object_removed - Fonctions pratiques pour émettre des signaux D-Bus (standard)

SYNOPSIS

#include <systemd/sd-bus-vtable.h>

int sd_bus_emit_signal(sd_bus *bus, const char *path, const char *interface, const char *member, const char *types, ...);

int sd_bus_emit_signalv(sd_bus *bus, const char *path, const char *interface, const char *member, const char *types, va_list ap);

int sd_bus_emit_signal_to(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, const char *types, ...);

int sd_bus_emit_signal_tov(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, const char *types, va_list ap);

int sd_bus_emit_interfaces_added(sd_bus *bus, const char *path, const char *interface, ...);

int sd_bus_emit_interfaces_added_strv(sd_bus *bus, const char *path, char **interfaces);

int sd_bus_emit_interfaces_removed(sd_bus *bus, const char *path, const char *interface, ...);

int sd_bus_emit_interfaces_removed_strv(sd_bus *bus, const char *path, char **interfaces);

int sd_bus_emit_properties_changed(sd_bus *bus, const char *path, const char *interface, const char *name, ...);

int sd_bus_emit_properties_changed_strv(sd_bus *bus, const char *path, const char *interface, char **names);

int sd_bus_emit_object_added(sd_bus *bus, const char *path);

int sd_bus_emit_object_removed(sd_bus *bus, const char *path);

DESCRIPTION

sd_bus_emit_signal() est une fonction pratique pour initialiser un objet message de bus et émettre le signal D-Bus correspondant. Elle combine les fonctions sd_bus_message_new_signal(3), sd_bus_message_append(3) et sd_bus_send(3) en un seul appel de fonction. sd_bus_emit_signalv() est équivalent à sd_bus_message_append(), à la différence qu'il est appelé avec une "va_list" au lieu d'un nombre variable d'arguments.

sd_bus_emit_signal_to() et sd_bus_emit_signal_tov() sont identiques à sd_bus_emit_signal() et sd_bus_emit_signalv(), à la différence qu'elles peuvent émettre le signal vers une destination unique. Donnez destination comme **NULL** pour diffuser le signal.

sd_bus_emit_interfaces_added() et sd_bus_emit_interfaces_removed() sont utilisés pour implémenter les signaux InterfacesAdded et InterfacesRemoved de l'interface org.freedesktop.DBus.ObjectManager. Ils prennent en argument un chemin d'objet dont les interfaces ont été modifiées et une liste variable d'interfaces qui ont été ajoutées ou supprimées, respectivement. Le dernier argument passé à sd_bus_emit_interfaces_added() et sd_bus_emit_interfaces_removed() *doit* être **NULL**. Cela permet aux deux fonctions de déterminer en toute sécurité le nombre d'arguments d'interface passés. sd_bus_emit_interfaces_added_strv() et sd_bus_emit_interfaces_removed_strv() sont identiques à leurs homologues respectifs mais prennent tous deux la liste des interfaces comme un seul argument au lieu d'un nombre variable d'arguments.

sd_bus_emit_properties_changed() est utilisé pour implémenter le signal PropertiesChanged de l'interface org.freedesktop.DBus.Properties. Il prend en arguments un chemin d'objet, une interface et une liste variable de noms de propriétés. Le dernier argument passé à sd_bus_emit_properties_changed() *doit* être **NULL**. Cela lui permet de déterminer en toute sécurité le nombre de noms de propriétés passés. sd_bus_emit_properties_changed_strv() est identique à sd_bus_emit_properties_changed() mais prend la liste des noms de propriétés comme un seul argument au lieu d'un nombre variable d'arguments.

sd_bus_emit_object_added() et sd_bus_emit_object_removed() sont des fonctions pratiques pour émettre les signaux InterfacesAdded ou InterfacesRemoved pour toutes les interfaces enregistrées sur un chemin d'objet spécifique, respectivement. Cela inclut toutes les vtables de repli parentes si elles ne sont pas remplacées par une vtable enfant plus applicable. Cela inclut également toutes les interfaces D-Bus standard implémentées par sd-bus lui-même sur n'importe quel objet enregistré.

Notez que sd_bus_emit_interfaces_added(), sd_bus_emit_interfaces_removed(), sd_bus_emit_object_added() et sd_bus_emit_object_removed() nécessitent qu'un gestionnaire d'objet soit enregistré sur le chemin d'objet donné ou l'un de ses chemins d'objet parents en utilisant sd_bus_add_object_manager(3).

VALEUR RETOURNÉE

En cas de succès, ces fonctions retournent un entier positif ou nul. En cas d'échec, elles retournent un code d'erreur négatif de style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

L'un des paramètres requis est **NULL** ou invalide. Une interface D-Bus réservée a été passée comme paramètre interface.

-ENOPKG

Le bus ne peut pas être résolu.

-ECHILD

Le bus a été créé dans un processus, une bibliothèque ou une instance de module différent.

-ENOMEM

Échec de l'allocation mémoire.

-ESRCH

L'une des fonctions sd_bus_emit_interfaces_added(), sd_bus_emit_interfaces_removed(), sd_bus_emit_object_added() ou sd_bus_emit_object_removed() a été appelée sur un objet sans gestionnaire d'objet enregistré sur son propre chemin d'objet ou l'un de ses chemins d'objet parents.

Voir les pages de manuel sd_bus_message_new_signal(3), sd_bus_message_append(3) et sd_bus_send(3) pour plus d'erreurs possibles.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que depuis une phase précoce du programme lorsque aucun autre thread n'a été démarré.

sd_bus_emit_signal_to() et sd_bus_emit_signal_tov() ont été ajoutés dans systemd v238.

sd_bus_emit_signal(3) — systemd — Arch Linux

NAME

sd_bus_emit_signal, sd_bus_emit_signal_strv, sd_bus_emit_object_added, sd_bus_emit_object_removed, sd_bus_emit_interfaces_added, sd_bus_emit_interfaces_removed, sd_bus_emit_properties_changed, sd_bus_emit_properties_changed_strv, sd_bus_emit_signalv, sd_bus_emit_signal_to, sd_bus_emit_signal_tov - Émettre des signaux et des événements du bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_emit_signal(sd_bus *bus, const char *path, const char *interface, const char *member, const char *signature, ...);

int sd_bus_emit_signal_strv(sd_bus *bus, const char *path, const char *interface, const char *member, const char *signature, char *const *argv);

int sd_bus_emit_object_added(sd_bus *bus, const char *path, sd_bus_error *error);

int sd_bus_emit_object_removed(sd_bus *bus, const char *path, sd_bus_error *error);

int sd_bus_emit_interfaces_added(sd_bus *bus, const char *path, sd_bus_error *error);

int sd_bus_emit_interfaces_removed(sd_bus *bus, const char *path, sd_bus_error *error);

int sd_bus_emit_properties_changed(sd_bus *bus, const char *path, const char *interface, sd_bus_error *error);

int sd_bus_emit_properties_changed_strv(sd_bus *bus, const char *path, const char *interface, char *const *argv, sd_bus_error *error);

int sd_bus_emit_signalv(sd_bus *bus, const char *path, const char *interface, const char *member, const char *signature, va_list ap);

int sd_bus_emit_signal_to(sd_bus *bus, sd_bus_message *reply, const char *path, const char *interface, const char *member, const char *signature, ...);

int sd_bus_emit_signal_tov(sd_bus *bus, sd_bus_message *reply, const char *path, const char *interface, const char *member, const char *signature, va_list ap);

DESCRIPTION

Ces fonctions permettent d'émettre des signaux sur le bus de messages.

sd_bus_emit_signal(), sd_bus_emit_signal_strv(), sd_bus_emit_signalv(), sd_bus_emit_signal_to() et sd_bus_emit_signal_tov() émettent un signal standard. Les arguments restants sont les paramètres du signal, qui doivent correspondre à la chaîne de signature.

sd_bus_emit_object_added() et sd_bus_emit_object_removed() émettent un signal "ObjectAdded" ou "ObjectRemoved" respectivement.

sd_bus_emit_interfaces_added() et sd_bus_emit_interfaces_removed() émettent un signal "InterfacesAdded" ou "InterfacesRemoved" respectivement.

sd_bus_emit_properties_changed() et sd_bus_emit_properties_changed_strv() émettent un signal "PropertiesChanged" pour un objet et une interface donnés.

sd_bus_emit_signal_to() et sd_bus_emit_signal_tov() émettent un signal dans le cadre d'une réponse à un appel de méthode.

RETURN VALUE

En cas de succès, ces fonctions retournent 0 ou un entier positif. En cas d'échec, elles retournent un entier négatif.

NOTES

Les objets, interfaces et membres sont représentés par des chaînes de caractères. La signature des paramètres est une chaîne de caractères décrivant les types des arguments du signal.

HISTORY
