SDIFF(1) Commandes utilisateur SDIFF(1)

NOM

sdiff - fusion latérale des différences de fichiers

SYNTAXE

sdiff [OPTION]... FICHIER1 FICHIER2

DESCRIPTION

Fusion latérale des différences entre FICHIER1 et FICHIER2.

Les arguments obligatoires pour les options longues le sont aussi pour les options courtes.

-o, --output=FICHIER
fonctionner interactivement, en envoyant la sortie vers FICHIER
-i, --ignore-case
considérer majuscules et minuscules comme identiques
-E, --ignore-tab-expansion
ignorer les changements dus à l'expansion des tabulations
-Z, --ignore-trailing-space
ignorer les espaces blancs en fin de ligne
-b, --ignore-space-change
ignorer les changements dans la quantité d'espaces blancs
-W, --ignore-all-space
ignorer tous les espaces blancs
-B, --ignore-blank-lines
ignorer les changements dont les lignes sont entièrement blanches
-I, --ignore-matching-lines=RE
ignorer les changements dont toutes les lignes correspondent à RE
--strip-trailing-cr
supprimer les retours chariot de fin d'entrée
-a, --text
traiter tous les fichiers comme du texte
-w, --width=NUM
sortir au maximum NUM (par défaut 130) colonnes d'impression
-l, --left-column
afficher uniquement la colonne de gauche des lignes communes
-s, --suppress-common-lines
ne pas afficher les lignes communes
-t, --expand-tabs
étendre les tabulations en espaces dans la sortie
--tabsize=NUM
les tabulations sont réglées toutes les NUM (par défaut 8) colonnes d'impression
-d, --minimal
essayer de trouver un ensemble plus petit de changements
-H, --speed-large-files
supposer des fichiers volumineux, avec de nombreux petits changements dispersés
--diff-program=PROGRAMME
utiliser PROGRAMME pour comparer les fichiers
--help
afficher cette aide et quitter
-v, --version
afficher les informations de version et quitter

Si un FICHIER est '-', lire l'entrée standard. Le code de sortie est 0 si les entrées sont identiques, 1 si elles sont différentes, 2 en cas de problème.
