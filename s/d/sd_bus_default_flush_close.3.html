SD_BUS_CLOSE(3) sd_bus_close SD_BUS_CLOSE(3)

NOM

sd_bus_close, sd_bus_flush, sd_bus_default_flush_close - Fermer et vider une connexion de bus

SYNOPSIS

#include <systemd/sd-bus.h>

void sd_bus_close(sd_bus *bus);

int sd_bus_flush(sd_bus *bus);

void sd_bus_default_flush_close(void);

DESCRIPTION

sd_bus_close() déconnecte la connexion de bus spécifiée. Lorsque cet appel est effectué et que l'objet bus spécifié fait référence à une connexion active, celle-ci est immédiatement terminée. Aucun autre message ne peut être envoyé ou reçu sur cette connexion. Les messages mis en file d'attente dans l'objet bus (entrants et sortants) sont libérés. Si la fonction est appelée avec un objet bus à NULL ou si la connexion de bus est déjà fermée, cette fonction n'effectue aucune opération. Cet appel ne libère ni ne déréférence pas l'objet bus lui-même. Utilisez sd_bus_unref(3) pour cela.

sd_bus_flush() écrit de manière synchrone tous les messages sortants mis en file d'attente sur une connexion de bus s'il y en a. Cet appel de fonction peut bloquer si le pair ne traite pas les messages du bus rapidement.

Avant qu'un programme ne se termine, il est généralement conseillé de vider tous les messages en attente avec sd_bus_flush(), puis de fermer les connexions avec sd_bus_close() pour s'assurer qu'aucun message non écrit n'est perdu, qu'aucun message supplémentaire ne peut être mis en file d'attente et que tous les messages entrants mais non traités sont libérés. Une fois ces deux opérations effectuées, il est judicieux de supprimer également toutes les références restantes à l'objet bus afin qu'il puisse être libéré. Étant donné que ces trois opérations sont fréquemment effectuées ensemble, une fonction d'aide sd_bus_flush_close_unref(3) est fournie qui combine ces opérations en une seule.

sd_bus_default_flush_close() est similaire à sd_bus_flush_close_unref(), mais ne prend pas d'argument de pointeur bus et itère plutôt sur les bus "par défaut" ouverts par sd_bus_default(3), sd_bus_default_user(3), sd_bus_default_system(3) et les appels similaires. sd_bus_default_flush_close() est particulièrement utile pour nettoyer tous les bus ouverts à l'aide de ces appels avant la sortie du programme.

VALEUR RENVOYÉE

En cas de succès, sd_bus_flush() renvoie un entier positif ou nul. En cas d'échec, elle renvoie un code d'erreur négatif de style errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion de bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'appeler setenv() qu'à partir d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_close() et sd_bus_flush() ont été ajoutés dans la version 221.

sd_bus_default_flush_close() a été ajouté dans la version 227.
