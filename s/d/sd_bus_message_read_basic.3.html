NOM

sd_bus_message_read_basic - Lire un type de base d'un message

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_read_basic(sd_bus_message *m, char type, void *p);

DESCRIPTION

sd_bus_message_read_basic() lit un type de base d'un message et avance la position de lecture dans le message. L'ensemble des types de base et de leurs codes ASCII passés dans type sont décrits dans la **Spécification D-Bus**[1].

Si p n'est pas NULL, il doit contenir un pointeur vers un objet approprié. Par exemple, si type est 'y', l'objet passé dans p doit être de type uint8_t *. Si type est 's', l'objet passé dans p doit être de type const char **. Notez que, si le type de base est un pointeur (par exemple, const char * dans le cas d'une chaîne), le pointeur n'est que prêté et le contenu doit être copié s'il doit être utilisé après la fin de la durée de vie du message. De même, pendant la durée de vie d'un tel pointeur, le message ne doit pas être modifié. Si type est 'h' (descripteur de fichier UNIX), le descripteur n'est pas dupliqué par cet appel et le descripteur retourné reste en possession de l'objet message, et doit être dupliqué par l'appelant afin de conserver une référence ouverte à celui-ci après que l'objet message ait été libéré (par exemple, en appelant "fcntl(fd, FD_DUPFD_CLOEXEC, 3)"). Voir le tableau ci-dessous pour une liste complète des types autorisés.

Tableau 1. Spécificateurs de type d'élément

Spécificateur Constante Description Type C attendu
"y" SD_BUS_TYPE_BYTE Entier non signé de 8 bits uint8_t *
"b" SD_BUS_TYPE_BOOLEAN booléen int * (NB: pas bool *)
"n" SD_BUS_TYPE_INT16 Entier signé de 16 bits int16_t *
"q" SD_BUS_TYPE_UINT16 Entier non signé de 16 bits uint16_t *
"i" SD_BUS_TYPE_INT32 Entier signé de 32 bits int32_t *
"u" SD_BUS_TYPE_UINT32 Entier non signé de 32 bits uint32_t *
"x" SD_BUS_TYPE_INT64 Entier signé de 64 bits int64_t *
"t" SD_BUS_TYPE_UINT64 Entier non signé de 64 bits uint64_t *
"d" SD_BUS_TYPE_DOUBLE Point flottant en double précision IEEE 754 double *
"s" SD_BUS_TYPE_STRING Chaîne UTF-8 const char **
"o" SD_BUS_TYPE_OBJECT_PATH Chaîne de chemin d'objet D-Bus const char **
"g" SD_BUS_TYPE_SIGNATURE Chaîne de signature D-Bus const char **
"h" SD_BUS_TYPE_UNIX_FD Descripteur de fichier UNIX int *

S'il n'y a pas d'objet du type spécifié à la position actuelle dans le message, une erreur est retournée.

VALEUR RENVOYÉE

En cas de succès, sd_bus_message_read_basic() renvoie un entier positif. Si la fin du tableau actuellement ouvert a été atteinte, il renvoie 0. En cas d'échec, il renvoie un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

La chaîne de type spécifiée est invalide ou le paramètre message est NULL.

-ENXIO

Le message ne contient pas le type spécifié à la position actuelle.

-EBADMSG

Le message ne peut pas être analysé.

HISTORIQUE

sd_bus_message_read_basic() a été ajouté dans la version 221.
