NOM

sd-path - APIs pour interroger les chemins du système de fichiers

SYNTAXE

#include <systemd/sd-path.h>

pkg-config --cflags --libs libsystemd

DESCRIPTION

sd-path.h fait partie de libsystemd(3) et fournit des API pour interroger les chemins du système de fichiers. Cette fonctionnalité est similaire à la fonctionnalité en ligne de commande fournie par systemd-path(1).

Voir sd_path_lookup(3) pour des informations sur les fonctions disponibles.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un fil d'exécution parallèle. Il est recommandé de n'appeler setenv() qu'à partir d'une phase précoce du programme lorsque aucun autre fil d'exécution n'a été démarré.
