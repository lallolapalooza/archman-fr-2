SDRVRFP

Objectif :

!>
!> SDRVRFP teste les routines LAPACK RFP :
!>     SPFTRF, SPFTRS, et SPFTRI.
!>
!> Cette routine de test suit les mêmes tests que DDRVPO (test pour le solveur
!> Symétrique Défini Positif en format complet).
!>
!> Les tests sont effectués en Format Complet, la conversion aller-retour
!> du format complet au format RFP est effectuée à l'aide des routines STRTTF et
!> STFTTR.
!>
!> Premièrement, une matrice spécifique A de taille N est créée. Il existe neuf
!> types de matrices différentes possibles.
!>  1. Diagonale                       6. Aléatoire, CNDNUM = sqrt(0.1/EPS)
!>  2. Aléatoire, CNDNUM = 2           7. Aléatoire, CNDNUM = 0.1/EPS
!> *3. Première ligne et colonne à zéro  8. Scalée proche du sous-dépassement
!> *4. Dernière ligne et colonne à zéro  9. Scalée proche du dépassement
!> *5. Ligne et colonne du milieu à zéro
!> (* - teste les sorties d'erreur de SPFTRF, aucun ratio de test n'est calculé)
!> Une solution XACT de taille N par NRHS est créée ainsi que le membre de droite
!> associé B. Ensuite SPFTRF est appelée pour calculer L (ou U), le
!> facteur de Cholesky de A. Ensuite L (ou U) est utilisé pour résoudre le système
!> linéaire d'équations AX = B. Cela donne X. Ensuite L (ou U) est utilisé pour calculer
!> l'inverse de A, AINV. Les quatre tests suivants sont alors effectués :
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> où EPS est la précision machine, RCOND le nombre de condition de A, et
!> norm( . ) la norme 1 pour (1,2,3) et la norme infini pour (4).
!> Des erreurs se produisent lorsque le paramètre INFO n'est pas celui attendu. Des
!> échecs se produisent lorsqu'un ratio de test est supérieur à THRES.
!>

!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>                Les valeurs de la dimension N de la matrice.
!>

NNS

!>          NNS est ENTIER
!>                Le nombre de valeurs de NRHS contenues dans le vecteur NSVAL.
!>

NSVAL

!>          NSVAL est un tableau ENTIER, dimension (NNS)
!>                Les valeurs du nombre de membres de droite NRHS.
!>

NNT

!>          NNT est ENTIER

!>

NTVAL

!>          NTVAL est un tableau ENTIER, dimension (NNT)
!>                Les valeurs du type de matrice (entre 0 et 9 pour les matrices PO/PP/PF).
