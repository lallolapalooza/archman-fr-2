SDRGSX

Objectif:

!>
!> SDRGSX vérifie le pilote expert SGGESX du problème de valeurs propres généralisé (forme de Schur) non symétrique.
!>
!> SGGESX factorise A et B en Q S Z' et Q T Z', où ' signifie transposée, T est triangulaire supérieure, S est sous forme de Schur généralisée (bloc triangulaire supérieure, avec des blocs 1x1 et 2x2 sur la diagonale, les blocs 2x2 correspondant à des paires de valeurs propres généralisées complexes conjuguées), et Q et Z sont orthogonales. Il calcule également les valeurs propres généralisées (alpha(1),beta(1)), ..., (alpha(n),beta(n)). Ainsi, w(j) = alpha(j)/beta(j) est une racine de l'équation caractéristique
!>
!>     det( A - w(j) B ) = 0
!>
!> Optionnellement, il réordonne également les valeurs propres de sorte qu'un cluster sélectionné de valeurs propres apparaisse dans le bloc diagonal principal des formes de Schur ; calcule un nombre de condition réciproque pour la moyenne des valeurs propres sélectionnées ; et calcule un nombre de condition réciproque pour les sous-espaces de déflation droit et gauche correspondant aux valeurs propres sélectionnées.
!>
!> Lorsque SDRGSX est appelé avec NSIZE > 0, cinq (5) types de paires de matrices intégrées sont utilisés pour tester la routine SGGESX.
!>
!> Lorsque SDRGSX est appelé avec NSIZE = 0, il lit les données de matrices de test pour tester SGGESX.
!>
!> Pour chaque paire de matrices, les tests suivants seront effectués et comparés au seuil THRESH, à l'exception des tests (7) et (9) :
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A est sous forme de Schur (c'est-à-dire forme quasi-triangulaire)
!>
!> (6)   maximum sur j de D(j)  où :
!>
!>       si alpha(j) est réel :
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) est complexe :
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>           et S et T sont ici les blocs diagonaux 2 x 2 de S et T
!>           correspondant aux j-ème et j+1-ème valeurs propres.
!>
!> (7)   si le tri a fonctionné et SDIM est le nombre de valeurs propres
!>       qui ont été sélectionnées.
!>
!> (8)   la valeur estimée DIF ne diffère pas des valeurs réelles de
!>       Difu et Difl plus que d'un facteur 10*THRESH. Si l'estimation DIF
!>       est nulle, les valeurs réelles correspondantes de Difu et Difl
!>       devraient être inférieures à EPS*norm(A, B). Si la valeur réelle de Difu
!>       et Difl est nulle, l'estimation DIF devrait être inférieure à
!>       EPS*norm(A, B).
!>
!> (9)   Si INFO = N+3 est retourné par SGGESX, le réordonnement
!>       et nous vérifions que DIF = PL = PR = 0 et que la valeur réelle de
!>       Difu et Difl est < EPS*norm(A, B). Nous comptons les événements où
!>       INFO=N+3.
!>
!> Pour les matrices de test lues, les tests ci-dessus sont effectués, à l'exception que la
!> valeur exacte de DIF (et PL) est une donnée d'entrée. De plus, un test supplémentaire
!> est effectué pour les matrices de test lues :
!>
!> (10)  la valeur estimée PL ne diffère pas de la valeur réelle de
!>       PLTRU plus que d'un facteur THRESH. Si l'estimation PL est
!>       nulle, la valeur réelle correspondante de PLTRU devrait être inférieure à
!>       EPS*norm(A, B). Si la valeur réelle de PLTRU est nulle,
!>       l'estimation PL devrait être inférieure à EPS*norm(A, B).
!>
!> Notez que pour les tests intégrés, un total de 10*NSIZE*(NSIZE-1)
!> paires de matrices sont générées et testées. NSIZE doit être maintenu petit.
!>
!> SVD (routine SGESVD) est utilisé pour calculer la valeur réelle de DIF_u
!> et DIF_l lors des tests des problèmes de test intégrés.
!>
!> Matrices de Test Intégrées
!> ======================
!>
!> Toutes les matrices de test intégrées sont le bloc 2 par 2 de matrices triangulaires
!>
!>          A = [ A11 A12 ]    et      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> où pour différents types de A11 et A22 sont donnés comme suit.
!> A12 et B12 sont choisis de sorte que l'équation de Sylvester généralisée
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> aient des solutions prescrites R et L.
!>
!> Type 1 :  A11 = J_m(1,-1) et A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          où J_k(a,b) est le bloc de Jordan k x k avec "a" sur la
!>          diagonale et "b" sur la superdiagonale.
!>
!> Type 2 :  A11 = (a_ij) = ( 2(.5-sin(i)) ) et
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) et
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=m+1,...,k, j=i,...,k
!>
!> Type 3 :  A11, A22 et B11, B22 sont choisis comme pour le Type 2, mais chaque
!>          deuxième bloc diagonal dans A_11 et chaque troisième bloc diagonal
!>          dans A_22 sont réalisés en blocs de 2 par 2.
!>
!> Type 4 :  A11 = ( 20(.5 - sin(ij)) ) et B22 = ( 2(.5 - sin(i+j)) )
!>             pour i=1,...,m,  j=1,...,m et
!>          A22 = ( 20(.5 - sin(i+j)) ) et B22 = ( 2(.5 - sin(ij)) )
!>             pour i=m+1,...,k,  j=m+1,...,k
!>
!> Type 5 :  (A,B) ont des valeurs propres potentiellement proches ou communes et
!>          un très grand écart par rapport à la diagonalité par blocs. A_11 est choisi
!>          comme la sous-matrice principale m x m de A_1 :
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          et A_22 est choisi comme la sous-matrice principale k x k de A_2 :
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |                       -d  1+b    |
!>                  |                      -1+b  -d    |
!>                  |                              1-d |
!>          et les matrices B sont choisies comme des matrices identité (voir SLATM5).
!>
!>

Paramètres

NSIZE 
!>          NSIZE est un ENTIER
!>          La taille maximale des matrices à utiliser. NSIZE >= 0.
!>          Si NSIZE = 0,
pas de matrices de test intégrées sont utilisées, mais !> des matrices de test lues sont utilisées pour tester SGGESX. !>

NCMAX

!>          NCMAX est un entier
!>          NMAX maximum autorisé pour la génération de matrices de Kronecker
!>          dans l'appel à SLAKF2
!>

THRESH

!>          THRESH est un réel
!>          Un test sera comptabilisé comme tel si la , calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être de O(1), donc THRESH devrait être un multiple raisonnable
!>          de 1, par exemple, 10 ou 100. En particulier,
!>          il ne doit pas dépendre de la précision (simple vs double)
!>          ou de la taille de la matrice. THRESH >= 0.
!>

NIN

!>          NIN est un entier
!>          Le numéro d'unité FORTRAN pour la lecture du fichier de données des
!>          problèmes à résoudre.
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (par exemple, si une routine renvoie IINFO différent de 0).
!>

A

!>          A est un tableau réel, de dimension (LDA, NSIZE)
!>          Utilisé pour stocker la matrice dont les valeurs propres doivent être
!>          calculées. En sortie, A contient la dernière matrice effectivement utilisée.
!>

LDA

!>          LDA est un entier
!>          La dimension principale de A, B, AI, BI, Z et Q,
!>          LDA >= max( 1, NSIZE ). Pour le test de lecture,
!>          LDA >= max( 1, N ), N est la taille des matrices de test.
!>

B

!>          B est un tableau réel, de dimension (LDA, NSIZE)
!>          Utilisé pour stocker la matrice dont les valeurs propres doivent être
!>          calculées. En sortie, B contient la dernière matrice effectivement utilisée.
!>

AI

!>          AI est un tableau réel, de dimension (LDA, NSIZE)
!>          Copie de A, modifiée par SGGESX.
!>

BI

!>          BI est un tableau réel, de dimension (LDA, NSIZE)
!>          Copie de B, modifiée par SGGESX.
!>

Z

!>          Z est un tableau réel, de dimension (LDA, NSIZE)
!>          Z contient les vecteurs de Schur gauches calculés par SGGESX.
!>

Q

!>          Q est un tableau réel, de dimension (LDA, NSIZE)
!>          Q contient les vecteurs de Schur droits calculés par SGGESX.
!>

ALPHAR

!>          ALPHAR est un tableau réel, de dimension (NSIZE)
!>

ALPHAI

!>          ALPHAI est un tableau réel, de dimension (NSIZE)
!>

BETA

!>          BETA est un tableau réel, de dimension (NSIZE)
!> \verbatim
!>          En sortie, (ALPHAR + ALPHAI*i)/BETA sont les valeurs propres.
!>

C

!>          C est un tableau réel, de dimension (LDC, LDC)
!>          Stocke la matrice générée par la sous-routine SLAKF2, c'est la
!>          matrice formée par les produits de Kronecker utilisés pour estimer
!>          DIF.
!>

LDC

!>          LDC est un entier
!>          La dimension principale de C. LDC >= max(1, LDA*LDA/2 ).
!>

S

!>          S est un tableau réel, de dimension (LDC)
!>          Valeurs singulières de C
!>

WORK

!>          WORK est un tableau réel, de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>          LWORK >= MAX( 5*NSIZE*NSIZE/2 - 2, 10*(NSIZE+1) )
!>

IWORK

!>          IWORK est un tableau d'entiers, de dimension (LIWORK)
!>

LIWORK

!>          LIWORK est un entier
!>          La dimension du tableau IWORK. LIWORK >= NSIZE + 6.
!>

BWORK

!>          BWORK est un tableau logique, de dimension (LDA)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : une routine a renvoyé un code d'erreur.
!>
