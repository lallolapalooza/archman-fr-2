But :

!>
!> SDRGEV vérifie la sous-routine pilote de problème de valeurs propres généralisées non symétriques SGGEV.
!>
!> SGGEV calcule pour une paire de matrices non symétriques de taille n x n (A,B) les
!> valeurs propres généralisées et, éventuellement, les vecteurs propres gauche et droit.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulier. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une interprétation raisonnable
!> pour beta=0, et même pour que les deux soient zéro.
!>
!> Un vecteur propre généralisé droit correspondant à une valeur propre généralisée
!> w pour une paire de matrices (A,B) est un vecteur r tel que
!> (A - wB) * r = 0. Un vecteur propre généralisé gauche est un vecteur l tel que
!> l**H * (A - wB) = 0, où l**H est la transposée conjuguée de l.
!>
!> Lorsque SDRGEV est appelée, un certain nombre de tailles de matrices et un
!> certain nombre de types de matrices sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les tests suivants
!> seront effectués et comparés au seuil THRESH.
!>
!> Résultats de SGGEV :
!>
!> (1) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,l) de
!>
!> | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!> où VL**H est la transposée conjuguée de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!> VL(i) désigne la i-ème colonne de VL.
!>
!> (3) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,r) de
!>
!> | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!> VR(i) désigne la i-ème colonne de VR.
!>
!> (5) W(full) = W(partial)
!> W(full) désigne les valeurs propres calculées lorsque l et r sont également calculés, et W(partial) désigne les valeurs propres
!> calculées lorsqu'uniquement W, seulement W et r, ou seulement W et l sont calculés.
!>
!> (6) VL(full) = VL(partial)
!> VL(full) désigne les vecteurs propres gauches calculés lorsque l et r sont calculés, et VL(partial) désigne le résultat
!> lorsqu'uniquement l est calculé.
!>
!> (7) VR(full) = VR(partial)
!> VR(full) désigne les vecteurs propres droits calculés lorsque l et r sont également calculés, et VR(partial) désigne le résultat
!> lorsqu'uniquement l est calculé.
!>
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .VRAI., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1) ( 0, 0 ) (une paire de matrices nulles)
!>
!> (2) ( I, 0 ) (une matrice identité et une matrice nulle)
!>
!> (3) ( 0, I ) (une matrice identité et une matrice nulle)
!>
!> (4) ( I, I ) (une paire de matrices identité)
!>
!> t   t
!> (5) ( J , J  ) (une paire de blocs de Jordan transposés)
!>
!>                                      t                ( I   0  )
!> (6) ( X, Y ) où  X = ( J   0  )  et Y = (      t )
!>                                   ( 0   I  )          ( 0   J  )
!>                       et I est une matrice identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7) ( D, I ) où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                       avec ces entrées diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) où big est proche du dépassement et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées aléatoires de O(1) au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!>

Paramètres

NSIZES 
!>          NSIZES est un ENTIER
!>          Le nombre de tailles de matrices à utiliser. Si NSIZES est zéro,
!>          SDRGES ne fait rien. NSIZES >= 0.
!>

NN

!>          NN est un TABLEAU D'ENTIERS, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. NN >= 0.
!>

NTYPES

!>          NTYPES est un ENTIER
!>          Le nombre d'éléments dans DOTYPE. Si NTYPES est zéro, SDRGES
!>          ne fait rien.
!>

DOTYPE

!>          DOTYPE est un TABLEAU LOGIQUE, de dimension (NTYPES)
!>          Si DOTYPE(j) est vrai, alors le type de matrice j sera généré.
!>

ISEED

!>          ISEED est un TABLEAU D'ENTIERS, de dimension (4)
!>          La graine du générateur de nombres aléatoires. Les quatre
!>          éléments de ISEED déterminent le point de départ du générateur.
!>          ISEED est mis à jour par SDRGEV.
!>

THRESH

!>          THRESH est un RÉEL
!>          Le seuil pour les tests d'erreurs. Les résultats calculés par
!>          SGGEV seront comparés à THRESH. Si le résultat est plus grand
!>          que THRESH, le test est considéré comme échoué.
!>

NOUNIT

!>          NOUNIT est un ENTIER
!>          L'option d'unité. Si NOUNIT=0, les matrices unitaires et
!>          les vecteurs propres sont calculés et testés. Si NOUNIT=1,
!>          les matrices unitaires et les vecteurs propres ne sont pas
!>          calculés ou testés.
!>

A

!>          A est un TABLEAU RÉEL, de dimension (LDA, N) où N est le
!>          nombre de colonnes de la matrice A. Sur l'entrée, A contient
!>          la matrice à tester. Sur la sortie, A contient le résultat
!>          de la sous-routine testée.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension de A, B, S, et T. LDA >= max(N).
!>

B

!>          B est un TABLEAU RÉEL, de dimension (LDA, N) où N est le
!>          nombre de colonnes de la matrice B. Sur l'entrée, B contient
!>          la matrice à tester. Sur la sortie, B contient le résultat
!>          de la sous-routine testée.
!>

S

!>          S est un TABLEAU RÉEL, de dimension (LDA, N) où N est le
!>          nombre de colonnes de la matrice S. Sur la sortie, S contient
!>          les valeurs propres généralisées (alphar(i)/beta(i)).
!>

T

!>          T est un TABLEAU RÉEL, de dimension (LDA, N) où N est le
!>          nombre de colonnes de la matrice T. Sur la sortie, T contient
!>          la matrice triangulaire supérieure de la décomposition de Schur.
!>

Q

!>          Q est un TABLEAU RÉEL, de dimension (LDQ, N) où N est la
!>          dimension de la matrice. Sur la sortie, Q contient les vecteurs
!>          propres gauches de la paire (A,B).
!>

LDQ

!>          LDQ est un ENTIER
!>          La première dimension de Q et Z. LDQ >= max(N).
!>

Z

!>          Z est un TABLEAU RÉEL, de dimension (LDQ, N) où N est la
!>          dimension de la matrice. Sur la sortie, Z contient les vecteurs
!>          propres droits de la paire (A,B).
!>

QE

!>          QE est un TABLEAU RÉEL, de dimension (LDQE, N) où N est la
!>          dimension de la matrice. Sur la sortie, QE contient les vecteurs
!>          propres gauches de la paire (A,B) calculés avec l'option
!>          de calcul des vecteurs propres droits désactivée.
!>

LDQE

!>          LDQE est un ENTIER
!>          La première dimension de QE. LDQE >= max(N).
!>

ALPHAR

!>          ALPHAR est un TABLEAU RÉEL, de dimension (N)
!>          Sur la sortie, ALPHAR contient la partie réelle des numérateurs
!>          des valeurs propres généralisées.
!>

ALPHAI

!>          ALPHAI est un TABLEAU RÉEL, de dimension (N)
!>          Sur la sortie, ALPHAI contient la partie imaginaire des numérateurs
!>          des valeurs propres généralisées.
!>

BETA

!>          BETA est un TABLEAU RÉEL, de dimension (N)
!>          Sur la sortie, BETA contient les dénominateurs des valeurs propres
!>          généralisées.
!>

ALPHR1

!>          ALPHR1 est un TABLEAU RÉEL, de dimension (N)
!>          Sur la sortie, ALPHR1 contient la partie réelle des numérateurs
!>          des valeurs propres généralisées calculées lorsque seuls les
!>          vecteurs propres gauches sont calculés.
!>

ALPHI1

!>          ALPHI1 est un TABLEAU RÉEL, de dimension (N)
!>          Sur la sortie, ALPHI1 contient la partie imaginaire des numérateurs
!>          des valeurs propres généralisées calculées lorsque seuls les
!>          vecteurs propres gauches sont calculés.
!>

BETA1

!>          BETA1 est un TABLEAU RÉEL, de dimension (N)
!>          Sur la sortie, BETA1 contient les dénominateurs des valeurs propres
!>          généralisées calculées lorsque seuls les vecteurs propres gauches
!>          sont calculés.
!>

WORK

!>          WORK est un TABLEAU RÉEL
!>          Un espace de travail pour la sous-routine. La taille requise
!>          est stockée dans WORK(1).
!>

LWORK

!>          LWORK est un ENTIER
!>          La taille du tableau WORK. LWORK >= 1.
!>

RESULT

!>          RESULT est un TABLEAU RÉEL, de dimension (22)
!>          Sur la sortie, RESULT contient les erreurs relatives pour chacun
!>          des 22 tests effectués.
!>

INFO

!>          INFO est un ENTIER
!>          Sur la sortie, INFO est un entier indiquant la situation de sortie.
!>          Si INFO = 0, un succès.
!>          Si INFO < 0, une erreur (par exemple, un paramètre d'entrée invalide).
!>          Si INFO > 0, un échec (par exemple, un problème lors de la
!>          décomposition de Schur).
!>

!>          À l'entrée, ISEED spécifie la graine du générateur de nombres aléatoires.
!>          Les éléments du tableau doivent être compris entre 0 et 4095 ;

!>          valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées dans
!>          le prochain appel à SDRGES pour continuer la même séquence de nombres aléatoires.
