SD_BUS_MESSAGE_APPEND_BASIC(3) sd_bus_message_append_basic SD_BUS_MESSAGE_APPEND_BASIC(3)

NOM

sd_bus_message_append_basic - Attacher un champ unique à un message

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_append_basic(sd_bus_message *m, char type, const void *p);

DESCRIPTION

sd_bus_message_append_basic() attache un champ unique au message m. Le paramètre type détermine comment le pointeur p est interprété. type doit être l'un des types de base tels que définis dans la section Types de base[1] de la spécification D-Bus, et listé dans le tableau ci-dessous.

Tableau 1. Spécificateurs de type d'élément

Spécificateur Constante Description Taille Type C attendu
"y" SD_BUS_TYPE_BYTE entier non signé 1 octet uint8_t
"b" SD_BUS_TYPE_BOOLEAN booléen 4 octets int
"n" SD_BUS_TYPE_INT16 entier signé 2 octets int16_t
"q" SD_BUS_TYPE_UINT16 entier non signé 2 octets uint16_t
"i" SD_BUS_TYPE_INT32 entier signé 4 octets int32_t
"u" SD_BUS_TYPE_UINT32 entier non signé 4 octets uint32_t
"x" SD_BUS_TYPE_INT64 entier signé 8 octets int64_t
"t" SD_BUS_TYPE_UINT64 entier non signé 8 octets uint64_t
"d" SD_BUS_TYPE_DOUBLE virgule flottante 8 octets double
"s" SD_BUS_TYPE_STRING chaîne Unicode variable char[]
"o" SD_BUS_TYPE_OBJECT_PATH chemin d'objet variable char[]
"g" SD_BUS_TYPE_SIGNATURE signature variable char[]
"h" SD_BUS_TYPE_UNIX_FD descripteur de fichier UNIX 4 octets int

La valeur du paramètre est copiée dans une zone mémoire détenue par l'objet message, reste en possession de l'appelant et peut donc être modifiée librement après cet appel sans affecter le message de bus auquel elle a été ajoutée. Si
type est "h" (descripteur de fichier UNIX), le descripteur est dupliqué par cet appel et le descripteur passé reste en possession de l'appelant.

Pour les types "s", "o" et "g", le paramètre p est interprété comme un pointeur vers une séquence de caractères terminée par un caractère NUL. À titre de cas spécial, un pointeur NULL est interprété comme une chaîne vide. La chaîne doit être une chaîne Unicode valide encodée en UTF-8. Dans le cas des deux derniers types, les exigences supplémentaires pour un chemin d'objet D-Bus ou une signature de type doivent être satisfaites. Ces exigences doivent être vérifiées par le destinataire du message.

VALEUR DE RETOUR

En cas de succès, cet appel renvoie 0 ou un entier positif. En cas d'échec, il renvoie un code d'erreur négatif de type errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre spécifié est invalide.

-EPERM

Le message a été scellé.

-ESTALE

Le message est dans un état invalide.

-ENXIO

Le message ne peut pas être ajouté.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée à l'aide du fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer les appels à setenv() que depuis une phase précoce du programme lorsque aucun autre thread n'a été démarré.
