SD_JOURNAL_GET_CATALOG(3) sd_journal_get_catalog SD_JOURNAL_GET_CATALOG(3)

NOM

sd_journal_get_catalog, sd_journal_get_catalog_for_message_id - Récupérer une entrée de catalogue de messages

SYNTAXE

#include <systemd/sd-journal.h>

int sd_journal_get_catalog(sd_journal *j, char **ret);

int sd_journal_get_catalog_for_message_id(sd_id128_t id, char **ret);

DESCRIPTION

sd_journal_get_catalog() récupère une entrée de catalogue de messages pour l'entrée de journal actuelle. Cela recherchera une entrée dans le catalogue de messages en utilisant le champ "MESSAGE_ID=" de l'entrée de journal actuelle. Avant de retourner l'entrée, tous les noms de champs du journal dans le texte de l'entrée du catalogue entourés de "@" seront remplacés par les valeurs des champs respectives de l'entrée actuelle. Si un nom de champ référencé dans l'entrée du catalogue de messages n'existe pas dans l'entrée de journal actuelle, le "@" sera supprimé, mais le nom du champ sera sinon laissé intact.

sd_journal_get_catalog_for_message_id() fonctionne de manière similaire à sd_journal_get_catalog(), mais l'entrée est recherchée par l'identifiant de message spécifié (aucun contexte de journal ouvert n'est nécessaire pour cela), et aucune substitution de champ n'est effectuée.

Pour plus d'informations sur le catalogue de messages du journal, veuillez vous référer à la page de documentation Catalogues de messages du journal[1].

VALEUR DE RETOUR

sd_journal_get_catalog() et sd_journal_get_catalog_for_message_id() retournent 0 en cas de succès ou un code d'erreur négatif de style errno. Si aucune entrée de catalogue de messages correspondante n'est trouvée, -ENOENT est retourné.

En cas de retour réussi, ret pointe vers une nouvelle chaîne qui doit être libérée avec free(3).

NOTES

La fonction sd_journal_get_catalog() est indépendante des threads et un seul thread peut opérer sur un objet donné à un moment donné. Plusieurs objets indépendants peuvent être utilisés à partir de threads différents en parallèle.

La fonction sd_journal_get_catalog_for_message_id() est thread-safe et peut être appelée à partir de plusieurs threads en parallèle.

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

HISTORIQUE

sd_journal_get_catalog() et sd_journal_get_catalog_for_message_id() ont été ajoutées dans la version 196.
