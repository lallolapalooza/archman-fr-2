NOM

sd_pidfd_get_inode_id - Acquérir l'ID d'inode 64 bits d'un descripteur de fichier PID (PIDFD)

SYNTAXE

#include <systemd/sd-daemon.h>

int sd_pidfd_get_inode_id(int pidfd, uint64_t *ret);

DESCRIPTION

sd_pidfd_get_inode_id() peut être appelée pour acquérir l'ID d'inode 64 bits d'un descripteur de fichier PID (PIDFD), qui peut être utilisé pour identifier de manière fiable un processus pour le démarrage actuel.

À titre d'exemple typique, le gestionnaire de services définit les variables d'environnement $MAINPIDFDID et $MANAGERPIDFDID aux IDs d'inode du processus principal du service et du gestionnaire de services lui-même, respectivement, si cette fonctionnalité est prise en charge par le noyau.

Sur les architectures 64 bits, l'ID d'inode peut être obtenu directement via un appel à fstat(2) sur un pidfd donné. Cependant, sur les architectures 32 bits, le champ .st_ino de struct stat est également en 32 bits, ce qui, tout comme les PID, est sujet à réutilisation. Par conséquent, un second mécanisme exploitant name_to_handle_at(2) a été ajouté au noyau à partir de la v6.14. Cette fonction d'aide est ajoutée pour simplifier la gestion en aval des internes des pidfd/pidfs.

VALEUR DE RETOUR

En cas de succès, la fonction renvoie 0 ou un entier positif. En cas d'échec, un code d'erreur négatif de style errno est renvoyé.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EOPNOTSUPP

L'ID d'inode PIDFD stable n'est pas pris en charge par le noyau en cours d'exécution, ou le système est 32 bits et name_to_handle_at() n'est pas disponible.

-EBADF

Le descripteur de fichier spécifié est invalide, ou n'est pas un PIDFD.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

HISTORIQUE

sd_pidfd_get_inode_id() a été ajoutée dans la version 258.
