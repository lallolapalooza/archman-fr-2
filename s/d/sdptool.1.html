sdptool(1) Administration système Linux sdptool(1)

Nom

sdptool - contrôler et interroger les serveurs SDP

SYNTAXE

sdptool [OPTIONS] [COMMANDE [PARAMÈTRES]]

DESCRIPTION

sdptool(1) fournit l'interface pour effectuer des requêtes SDP sur des appareils Bluetooth, et administrer une base de données SDP locale.

COMMANDES

Les commandes suivantes sont disponibles. Dans tous les cas, bdaddr spécifie l'appareil à rechercher ou à parcourir. Si local est utilisé pour bdaddr, alors la base de données SDP locale est recherchée.

Les services sont identifiés et manipulés avec un record_handle de 4 octets (PAS le nom du service). Pour trouver le record_handle d'un service, recherchez la ligne "Service RecHandle" dans les résultats de search ou browse.

search [--bdaddr bdaddr] [--tree] [--raw] [--xml] nom_service
Recherche des services.

Les noms de services connus sont DID, SP, DUN, LAN, FAX, OPUSH, FTP, HS, HF, HFAG, SAP, NAP, GN, PANU, HCRP, HID, CIP, A2SRC, A2SNK, AVRCT, AVRTG, UDIUE, UDITE et SYNCML.

browse [--tree] [--raw] [--xml] [bdaddr]
Parcourt tous les services disponibles sur l'appareil spécifié par une adresse Bluetooth comme paramètre.
records [--tree] [--raw] [--xml] bdaddr
Récupère tous les enregistrements de service possibles.
add [ --handle=N --channel=N ]
Ajoute un service à la base de données SDP locale.

Vous pouvez spécifier un handle pour cet enregistrement en utilisant l'option --handle.

Vous pouvez spécifier un canal sur lequel ajouter le service en utilisant l'option --channel.

NOTE : La configuration de l'adaptateur local ne sera pas mise à jour et cette commande ne doit être utilisée que pour tester SDP.

del record_handle
Supprime un service de la base de données SDP locale.

NOTE : La configuration de l'adaptateur local ne sera pas mise à jour et cette commande ne doit être utilisée que pour tester SDP.

get [--tree] [--raw] [--xml] [--bdaddr bdaddr] record_handle
Récupère un service de la base de données SDP locale.
setattr record_handle attrib_id attrib_value
Définit ou ajoute un attribut à un enregistrement SDP.
setseq record_handle attrib_id attrib_values
Définit ou ajoute une séquence d'attributs à un enregistrement SDP.

OPTIONS

--help
Affiche l'aide sur l'utilisation de sdptool.

EXEMPLES

$ sdptool browse 00:80:98:24:15:6D
$ sdptool browse local
$ sdptool add DUN
$ sdptool del 0x10000
