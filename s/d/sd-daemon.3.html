SD-DAEMON(3) sd-daemon SD-DAEMON(3)

NOM

sd-daemon, SD_EMERG, SD_ALERT, SD_CRIT, SD_ERR, SD_WARNING, SD_NOTICE, SD_INFO, SD_DEBUG - API pour les démons de nouveau style

SYNOPIS

#include <systemd/sd-daemon.h>

pkg-config --cflags --libs libsystemd

DESCRIPTION

sd-daemon.h fait partie de libsystemd(3) et fournit des API pour les démons de nouveau style, tels qu'implémentés par le gestionnaire de services systemd(1).

Voir sd_listen_fds(3), sd_notify(3), sd_booted(3), sd_is_fifo(3), sd_watchdog_enabled(3), et sd_pidfd_get_inode_id(3) pour plus d'informations sur les fonctions implémentées. En plus de ces fonctions, quelques préfixes de journalisation sont définis comme macros :

#define SD_EMERG   "<0>"  /* le système est inutilisable */
#define SD_ALERT   "<1>"  /* une action doit être effectuée immédiatement */
#define SD_CRIT    "<2>"  /* conditions critiques */
#define SD_ERR     "<3>"  /* conditions d'erreur */
#define SD_WARNING "<4>"  /* conditions d'avertissement */
#define SD_NOTICE  "<5>"  /* condition normale mais significative */
#define SD_INFO    "<6>"  /* informationnel */
#define SD_DEBUG   "<7>"  /* messages de niveau débogage */

Ces préfixes sont destinés à être utilisés conjointement avec la journalisation basée sur stderr (ou sur stdout) telle qu'implémentée par systemd. Si un fichier de définition de service systemd est configuré avec StandardError=journal ou StandardError=kmsg (et de même avec StandardOutput=), ces préfixes peuvent être utilisés pour encoder un niveau de journalisation dans les lignes imprimées. Ceci est similaire à la journalisation de style printk() du noyau. Voir klogctl(2) pour plus d'informations.

Les niveaux de journalisation sont identiques au système de niveaux de journalisation de syslog(3). Pour utiliser ces préfixes, il suffit de préfixer chaque ligne avec l'une de ces chaînes. Une ligne non préfixée sera journalisée au niveau de journalisation par défaut SD_INFO.

Exemple 1. Bonjour le monde

Un démon peut journaliser au niveau de journalisation NOTICE en effectuant cet appel :

fprintf(stderr, SD_NOTICE "Bonjour le monde !\n");

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'au début du programme, lorsqu'aucun autre thread n'a été démarré.
