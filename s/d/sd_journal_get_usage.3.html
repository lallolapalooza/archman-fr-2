NOM

sd_journal_get_usage - Utilisation du disque par le journal

SYNTAXE

#include <systemd/sd-journal.h>

int sd_journal_get_usage(sd_journal *j, uint64_t *bytes);

DESCRIPTION

sd_journal_get_usage() détermine l'espace disque total actuellement utilisé par les fichiers du journal (en octets). Si SD_JOURNAL_LOCAL_ONLY a été passé lors de l'ouverture du journal, cette valeur ne reflétera que la taille des fichiers journaux de l'hôte local, sinon celle de tous les hôtes.

VALEUR DE RETOUR

sd_journal_get_usage() retourne 0 en cas de succès ou un code d'erreur négatif de type errno.

NOTES

Toutes les fonctions listées ici sont indépendantes des threads et un seul thread peut opérer sur un objet donné à un moment donné. Différents threads peuvent accéder au même objet à différents moments. Plusieurs objets indépendants peuvent être utilisés à partir de différents threads en parallèle.

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

HISTORIQUE

sd_journal_get_usage() a été ajoutée dans la version 190.
