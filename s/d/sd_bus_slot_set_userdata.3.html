SD_BUS_SLOT_SET_USERDATA(3) sd_bus_slot_set_userdata SD_BUS_SLOT_SET_USERDATA(3)

NOM

sd_bus_slot_set_userdata, sd_bus_slot_get_userdata - Définir et interroger la valeur du champ « userdata »

SYNTAXE

#include <systemd/sd-bus.h>

void* sd_bus_slot_set_userdata(sd_bus_slot* slot, void* userdata);

void* sd_bus_slot_get_userdata(sd_bus_slot* slot);

DESCRIPTION

Le pointeur userdata permet de passer des données entre le point où un rappel est enregistré, par exemple lors de l'ajout d'un filtre avec sd_bus_add_filter(3) ou lors d'un appel de fonction asynchrone avec sd_bus_call_async(3), et le point où le rappel est appelé, sans avoir d'état global. Le pointeur est de type void* et n'est utilisé d'aucune manière par les fonctions sd-bus, sauf pour le passer à la fonction de rappel.

Généralement, le champ userdata est défini lors de l'enregistrement initial de l'objet slot. sd_bus_slot_set_userdata() peut être utilisé pour le changer plus tard pour l'objet slot de bus slot. La valeur précédente du champ est renvoyée. L'argument et la valeur renvoyée peuvent être NULL. Il sera passé comme argument userdata à la fonction de rappel attachée au slot.

sd_bus_slot_get_userdata() récupère la valeur du champ userdata dans l'objet slot de bus slot.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient la valeur du champ userdata avant l'appel de la fonction. Si l'objet slot est NULL, NULL sera renvoyé pour signaler une erreur, mais cela n'est pas distinguishable de la valeur du champ userdata qui est NULL.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr en multithreading. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de ne faire des appels à setenv() que dès les premières phases du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_slot_set_userdata() et sd_bus_slot_get_userdata() ont été ajoutés dans la version 240.
