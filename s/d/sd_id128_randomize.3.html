SD_ID128_RANDOMIZE(3) sd_id128_randomize SD_ID128_RANDOMIZE(3)

NOM

sd_id128_randomize - Générer des identifiants de 128 bits

SYNTAXE

#include <systemd/sd-id128.h>

int sd_id128_randomize(sd_id128_t *ret);

DESCRIPTION

sd_id128_randomize() génère un nouvel identifiant aléatoire de 128 bits et le retourne dans ret. Chaque appel retourne un nouvel identifiant généré aléatoirement. Ceci utilise le générateur de nombres aléatoires du noyau getrandom(2).

Notez que sd_id128_randomize() retourne toujours un identifiant compatible avec le UUID Variant 1 Version 4. Il est donc garanti que cette fonction ne retournera jamais l'identifiant composé de bits tous à zéro ou tous à un (SD_ID128_NULL, SD_ID128_ALLF).

Pour plus d'informations sur le type "sd_id128_t", voir sd-id128(3).

La commande new de systemd-id128(1) peut être utilisée comme interface en ligne de commande pour sd_id128_randomize().

VALEUR DE RETOUR

L'appel retourne 0 en cas de succès (auquel cas ret est rempli), ou un code d'erreur négatif de style errno.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les appels multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() qu'à partir d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_id128_randomize() a été ajouté dans la version 187.
