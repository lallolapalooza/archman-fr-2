NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Il est recommandé de n'effectuer les appels à setenv() que lors d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.
