NOM

sd_event_run, sd_event_loop - Exécuter une boucle d'événements

SYNTAXE

#include <systemd/sd-event.h>

int sd_event_run(sd_event *event, uint64_t usec);

int sd_event_loop(sd_event *event);

DESCRIPTION

sd_event_run() peut être utilisée pour exécuter une seule itération de la boucle d'événements spécifiée dans le paramètre event. La fonction attend qu'un événement à traiter soit disponible, et déclenche le gestionnaire enregistré pour celui-ci. Le paramètre usec spécifie le temps maximum (en microsecondes) à attendre pour un événement. Utilisez (uint64_t) -1 pour spécifier un délai d'attente infini.

sd_event_loop() invoque sd_event_run() dans une boucle, implémentant ainsi la boucle d'événements réelle. L'appel retourne dès que la sortie a été demandée en utilisant sd_event_exit(3).

L'objet boucle d'événements event est créé avec sd_event_new(3). Les sources d'événements à surveiller et leurs gestionnaires peuvent être enregistrés avec sd_event_add_io(3), sd_event_add_time(3), sd_event_add_signal(3), sd_event_add_child(3), sd_event_add_defer(3), sd_event_add_post(3) et sd_event_add_exit(3).

Pour un contrôle de bas niveau de l'exécution de la boucle d'événements, utilisez sd_event_prepare(3), sd_event_wait(3) et sd_event_dispatch(3) qui sont enveloppés par sd_event_run(). Avec sd_event_get_fd(3), ces fonctions permettent l'intégration d'une boucle d'événements sd-event(3) dans des implémentations de boucles d'événements étrangères.

VALEUR DE RETOUR

En cas d'échec, ces fonctions retournent un code d'erreur négatif de style errno. sd_event_run() retourne un entier positif non nul si une source d'événements a été déclenchée, et zéro lorsque le délai spécifié a été atteint avant qu'une source d'événements n'ait vu d'événement, et donc aucune source d'événements n'a été déclenchée. sd_event_loop() retourne le code de sortie spécifié lors de l'invocation de sd_event_exit().

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre event est invalide ou NULL.

-EBUSY

L'objet boucle d'événements n'est pas dans le bon état (voir sd_event_prepare(3) pour une explication des états possibles).

-ESTALE

La boucle d'événements est déjà terminée.

-ECHILD

La boucle d'événements a été créée dans un autre processus, bibliothèque ou instance de module.

D'autres erreurs sont également possibles.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que dès la phase initiale du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_event_run() et sd_event_loop() ont été ajoutées dans la version 220.
