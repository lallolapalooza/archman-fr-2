SDFFILTER(1) Commandes utilisateur SDFFILTER(1)

NOM

sdffilter - page de manuel pour sdffilter 25.11

SYNTAXE

sdffilter [OPTIONS] fichiersEntree...

DESCRIPTION

Fournit des informations dans une variété de formats (y compris de type usda) sur les couches Sdf ou sur des parties spécifiées (filtrées) d'une couche.

Positionnels :

fichiersEntree ...
Les fichiers d'entrée à traiter

OPTIONS

-h,--help
Imprimer ce message d'aide et quitter
-p,--path regex
Rapporter uniquement les chemins correspondant à cette expression régulière.
-f,--field regex
Rapporter uniquement les champs correspondant à cette expression régulière.
-t,--time n ou ff..lf
Rapporter uniquement ces temps (n) ou intervalles de temps (ff..lf) pour les champs 'timeSamples'
--timeTolerance tol
Rapporter les temps proches de ceux demandés avec cette tolérance relative. Défaut : 0.000125
--arraySizeLimit INT
Tronquer les tableaux comportant plus d'éléments que cette limite. Si -1, ne pas tronquer les tableaux. Défaut : 0 pour la sortie 'outline', 8 pour la sortie 'pseudoLayer', et -1 pour la sortie 'layer'.
--timeSamplesSizeLimit INT
Tronquer les timeSamples comportant plus de valeurs que cette limite. Si -1, ne pas tronquer les timeSamples. Défaut : 0 pour la sortie 'outline', 8 pour la sortie 'pseudoLayer', et -1 pour la sortie 'layer'. Le tronquage est effectué après le filtrage initial par les arguments --time.
-o,--out TEXT
Diriger la sortie vers ce fichier. Utiliser 'outputFormat' pour un contrôle plus fin du format sous-jacent pour les formats de sortie qui ne sont pas uniquement déterminés par l'extension du fichier.
--outputType validity|summary|outline|pseudoLayer|layer
Spécifier le format de sortie ; 'summary' rapporte des statistiques globales, 'outline' est un rapport texte plat des chemins et champs, 'pseudoLayer' est similaire au format de fichier usda mais avec des valeurs de tableau et des timeSamples tronqués pour une lisibilité humaine, et 'layer' est une vraie sortie de couche, dont le format est contrôlé par les arguments 'out' et 'outputFormat'. Défaut : outline
--outputFormat TEXT
Fournir ceci comme entrée 'format' de SdfFileFormatArguments pour la sortie 'layer' vers un fichier. Nécessite à la fois une sortie 'layer' et un fichier de sortie spécifié.
--sortBy path|field
Grouper la sortie 'outline' par chemin ou par champ. Ignoré pour les autres types de sortie. Défaut : path
--noValues
Ne pas rapporter les valeurs de champ.
