NOM

sd_bus_attach_event, sd_bus_detach_event, sd_bus_get_event - Attacher un objet de connexion de bus à une boucle d'événements

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_attach_event(sd_bus *bus, sd_event *e, int priority);

int sd_bus_detach_event(sd_bus *bus);

sd_event *sd_bus_get_event(sd_bus *bus);

DESCRIPTION

sd_bus_attach_event() attache l'objet de connexion de bus spécifié à un objet de boucle d'événements sd-event(3) avec la priorité spécifiée (voir sd_event_source_set_priority(3) pour les détails sur les priorités de boucle d'événements). Lorsqu'un objet de connexion de bus est attaché à une boucle d'événements, les messages entrants sont automatiquement lus et traités, et les messages sortants sont écrits, chaque fois que la boucle d'événements est exécutée. Lorsque la boucle d'événements est sur le point de se terminer, la connexion de bus est automatiquement vidée et fermée (voir sd_bus_set_close_on_exit(3) pour les détails à ce sujet). Par défaut, les objets de connexion de bus ne sont attachés à aucune boucle d'événements. Lorsqu'un objet de connexion de bus est attaché à une boucle, il n'est pas nécessaire d'invoquer sd_bus_wait(3) ou sd_bus_process(3) car cette fonctionnalité est gérée automatiquement par la boucle d'événements.

sd_bus_detach_event() détache un objet de bus de sa boucle d'événements.

La fonction sd_bus_get_event() renvoie l'objet de boucle d'événements auquel l'objet de bus spécifié est actuellement attaché, ou NULL s'il n'est actuellement attaché à aucune.

Notez que sd_bus_attach_event() n'est qu'une des trois méthodes prises en charge pour implémenter la gestion des événements d'E/S pour les connexions de bus. Alternativement, utilisez sd_bus_get_fd(3) pour connecter un objet de connexion de bus avec des boucles d'événements externes ou manuelles. Ou utilisez sd_bus_wait(3) comme un appel d'attente d'E/S bloquant synchrone simple.

VALEUR DE RETOUR

En cas de succès, sd_bus_attach_event() et sd_bus_detach_event() retournent 0 ou un entier positif. En cas d'échec, elles retournent un code d'erreur négatif de style errno.

sd_bus_get_event() retourne un objet de boucle d'événements ou NULL.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion de bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un fil d'exécution parallèle. Il est recommandé de n'effectuer des appels à setenv() qu'à partir d'une phase précoce du programme, lorsqu'aucun autre fil d'exécution n'a été démarré.

HISTORIQUE

sd_bus_attach_event(), sd_bus_detach_event(), et sd_bus_get_event() ont été ajoutées dans la version 221.
