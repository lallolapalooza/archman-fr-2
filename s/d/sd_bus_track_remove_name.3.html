SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOM

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Ajouter, supprimer et récupérer des pairs de bus suivis dans un objet de suivi de pairs de bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPTION

sd_bus_track_add_name() ajoute un pair à suivre à un objet de suivi de pairs de bus. Le premier argument doit faire référence à un objet de suivi de pairs de bus créé avec sd_bus_track_new(3), le nom second doit faire référence à un nom de pair D-Bus à suivre, au format unique ou de service connu. Si le nom n'est pas encore suivi, il sera ajouté à la liste des noms à suivre. S'il est déjà suivi et que le mode non récursif est activé, aucune opération n'est exécutée par cet appel. Si le mode récursif est activé, un compteur par nom est augmenté d'une unité à chaque fois que cet appel est invoqué, et sd_bus_track_remove_name() doit être appelé autant de fois que sd_bus_track_add_name() a été invoqué avant pour arrêter le suivi du nom. Utilisez sd_bus_track_set_recursive(3) pour passer du mode non récursif par défaut au mode récursif, ou inversement. Notez que le nom spécifié est suivi tel quel, les noms connus ne sont pas résolus en noms uniques par cet appel. Notez que plusieurs objets de suivi de pairs de bus peuvent suivre le même nom.

sd_bus_track_remove_name() annule l'effet de sd_bus_track_add_name() et supprime un nom de pair de bus de la liste des pairs à surveiller. Selon que le mode non récursif ou récursif est activé pour l'objet de suivi de pairs de bus, cet appel supprimera complètement le nom de l'objet de suivi, ou simplement décrémentera le compteur par nom d'une unité, supprimant le nom uniquement lorsque le compteur atteint zéro (voir ci-dessus). Notez qu'un pair de bus se déconnectant du bus supprimera implicitement ses noms complètement de l'objet de suivi de pairs de bus, quel que soit le compteur par nom actuel.

sd_bus_track_add_sender() et sd_bus_track_remove_sender() sont similaires à sd_bus_track_add_name() et sd_bus_track_remove_name() mais prennent un message de bus comme argument. L'expéditeur de ce message de bus est déterminé et ajouté/supprimé de l'objet de suivi de pairs de bus. Comme les messages proviennent toujours de noms uniques, et jamais de noms connus, cela signifie que cet appel ajoutera effectivement uniquement des noms uniques à l'objet de suivi de pairs de bus.

sd_bus_track_count() retourne le nombre de noms actuellement suivis par l'objet de suivi de pairs de bus spécifié. Notez que cette fonction retourne toujours le nombre réel de noms suivis, et donc si sd_bus_track_add_name() a été invoqué plusieurs fois pour le même nom, il n'est compté qu'une seule fois, que le mode récursif soit utilisé ou non.

sd_bus_track_count_name() retourne le compteur actuel par nom pour le nom spécifié. Si le mode non récursif est utilisé, cela retourne soit 1, soit 0, selon que le nom spécifié a été ajouté à l'objet de suivi avant, ou non. Si le mode récursif a été activé, des valeurs supérieures à 1 peuvent également être retournées, si sd_bus_track_add_name() a été appelé plusieurs fois pour le même nom.

sd_bus_track_count_sender() est similaire à sd_bus_track_count_name(), mais prend un objet de message de bus et retourne le compteur par nom correspondant à l'expéditeur du message.

sd_bus_track_contains() peut être utilisé pour déterminer si le nom spécifié a été ajouté au moins une fois à l'objet de suivi de pairs de bus spécifié.

sd_bus_track_first() et sd_bus_track_next() peuvent être utilisés pour énumérer tous les noms actuellement suivis par l'objet de suivi de pairs de bus passé. sd_bus_track_first() retourne la première entrée dans l'objet, et réinitialise un indice de lecture maintenu en interne. Chaque invocation subséquente de sd_bus_track_next() retourne le nom suivant contenu dans l'objet de bus. Si la fin est atteinte, NULL est retourné. Si aucun nom n'a encore été ajouté à l'objet, sd_bus_track_first() retournera NULL immédiatement. L'ordre dans lequel les noms sont retournés est indéfini ; en particulier, quel nom est considéré comme le premier retourné n'est pas défini. Si le mode récursif est activé et que le même nom a été ajouté plusieurs fois à l'objet de suivi de pairs de bus, il n'est retourné qu'une seule fois par cette énumération. Si de nouveaux noms sont ajoutés ou des noms existants supprimés de l'objet de suivi de pairs de bus pendant son énumération, l'énumération se termine lors de la prochaine invocation de sd_bus_track_next() car NULL est retourné.

VALEUR DE RETOUR

En cas de succès, sd_bus_track_add_name() et sd_bus_track_add_sender() retournent 0 si le nom spécifié a déjà été ajouté à l'objet de suivi de pairs de bus auparavant, et une valeur positive s'il ne l'a pas été. En cas d'échec, ils retournent un code d'erreur négatif de style errno.

sd_bus_track_remove_name() et sd_bus_track_remove_sender() retournent une valeur positive si le nom spécifié était précédemment suivi par l'objet de suivi de pairs de bus et a maintenant été supprimé. En mode non récursif, 0 est retourné si le nom spécifié n'était pas encore suivi. En mode récursif, -EUNATCH est retourné dans ce cas. En cas d'échec, ils retournent un code d'erreur négatif de style errno.

sd_bus_track_count() retourne le nombre de noms actuellement suivis, ou 0 en cas d'échec.

sd_bus_track_count_name() et sd_bus_track_count_sender() retournent le compteur actuel par nom pour le nom spécifié ou l'expéditeur du message spécifié. Zéro est retourné pour les noms qui ne sont pas encore suivis, une valeur positive pour les noms ajoutés au moins une fois. Des valeurs supérieures à 1 ne sont retournées qu'en mode récursif. En cas d'échec, un code d'erreur négatif de style errno est retourné.

sd_bus_track_contains() retourne le nom passé s'il existe dans l'objet de suivi de pairs de bus. En cas d'échec, et si le nom n'a pas encore été ajouté, NULL est retourné.

sd_bus_track_first() et sd_bus_track_next() retournent le premier/prochain nom contenu dans l'objet de suivi de pairs de bus, et NULL si la fin de l'énumération est atteinte et en cas d'erreur.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EUNATCH

sd_bus_track_remove_name() ou sd_bus_track_remove_sender() ont été invoqués pour un nom non ajouté auparavant à l'objet de pairs de bus.

-EINVAL

Le paramètre spécifié est invalide.

-ENOMEM

Échec de l'allocation mémoire.

NOM

sd_bus_track_remove_name, sd_bus_track_remove_sender - Retirer un nom de service ou un nom d'expéditeur d'un groupe de suivi de bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_remove_name(sd_bus_track *track, const char *name);
int sd_bus_track_remove_sender(sd_bus_track *track, const char *sender);

DESCRIPTION

La fonction sd_bus_track_remove_name() retire le nom de service name du groupe de suivi spécifié par track. Si le nom n'est pas présent dans le groupe de suivi, l'opération échoue avec l'erreur -ENOENT.

La fonction sd_bus_track_remove_sender() retire le nom d'expéditeur sender du groupe de suivi spécifié par track. Si le nom n'est pas présent dans le groupe de suivi, l'opération échoue avec l'erreur -ENOENT.

Ces fonctions sont utiles pour réduire un groupe de suivi existant, par exemple lorsque le programme n'a plus besoin de suivre des messages venant d'un nom de service spécifique ou envoyés par un expéditeur spécifique. Pour ajouter des noms de service ou des noms d'expéditeur à un groupe de suivi, voir sd_bus_track_add_name(3).

Le groupe de suivi track doit avoir été créé précédemment par un appel à sd_bus_track_new(3). Les appels aux fonctions de modification de groupe de suivi doivent être faits soit avant que le bus ne commence à traiter les messages du groupe, soit avant que le thread actuel n'ait été désactivé par sd_bus_process(3). Il est recommandé de modifier les groupes de suivi au plus tôt dans la vie du programme, lorsqu'aucun autre thread n'a encore été démarré.

VALEUR DE RETOUR

En cas de succès, sd_bus_track_remove_name() et sd_bus_track_remove_sender() renvoient 0. En cas d'échec, elles renvoient un code d'erreur négatif.

-ENOENT
Le nom spécifié n'a pas été trouvé dans le groupe de suivi.
-EINVAL
Le groupe de suivi track est invalide, ou le nom spécifié est invalide.

NOTES

Les fonctions sd_bus_track_remove_name() et sd_bus_track_remove_sender() sont des enveloppes pour des opérations internes de gestion des groupes de suivi. L'utilisation des groupes de suivi de bus est une fonctionnalité avancée qui doit être utilisée avec précaution pour éviter les fuites de mémoire ou les problèmes de performance.

Il est important de noter que ces fonctions ne modifient que le groupe de suivi. Le nom de service ou le nom d'expéditeur reste valide et peut être utilisé par d'autres parties du système ou d'autres groupes de suivi.
