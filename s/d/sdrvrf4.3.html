!>
!> SDRVRF4 teste les routines RFP de LAPACK :
!>     SSFRK
!>

Paramètres

NOUT 
!>          NOUT est ENTIER
!>                Le numéro d'unité pour la sortie.
!>

NN

!>          NN est ENTIER
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>                Les valeurs de la dimension de la matrice N.
!>

THRESH

!>          THRESH est REEL
!>                La valeur de seuil pour les rapports de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>                imprimer chaque rapport de test, utilisez THRESH = 0.
!>

C1

!>          C1 est un tableau REEL,
!>                dimension (LDC,NMAX)
!>

C2

!>          C2 est un tableau REEL,
!>                dimension (LDC,NMAX)
!>

LDC

!>          LDC est ENTIER
!>                La dimension principale du tableau A.
!>                LDA >= max(1,NMAX).
!>

CRF

!>          CRF est un tableau REEL,
!>                dimension ((NMAX*(NMAX+1))/2).
!>

A

!>          A est un tableau REEL,
!>                dimension (LDA,NMAX)
!>

LDA

!>          LDA est ENTIER
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

S_WORK_SLANGE

!>          S_WORK_SLANGE est un tableau REEL, dimension (NMAX)
!>
