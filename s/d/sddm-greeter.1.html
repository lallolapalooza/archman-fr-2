NOM

sddm-greeter - greeter du gestionnaire d'affichage sddm

SYNTHAXE

sddm-greeter [OPTIONS...]

DESCRIPTION

sddm est un gestionnaire d'affichage et de connexion basé sur les technologies Qt.

En utilisant QtQuick et QML, les concepteurs ont la possibilité de créer facilement des interfaces attrayantes et modernes pour sddm.

sddm-greeter est un processus auxiliaire qui affiche le greeter, une interface graphique pour effectuer l'authentification et sélectionner la session à lancer.

Il est lancé par le démon sddm, les utilisateurs finaux ne sont pas censés l'exécuter.

OPTIONS

--theme CHEMIN
Spécifie le chemin complet du thème.
--socket NOM
Spécifie le socket utilisé pour communiquer avec le démon sddm.
--test-mode
Lance le greeter en mode test.
--help, -h
Affiche le message d'aide et quitte.

FICHIERS

/usr/lib/sddm/sddm.conf.d
Répertoire de configuration système
/etc/sddm.conf.d
Répertoire de configuration locale
/etc/sddm.conf
Fichier de configuration locale pour la compatibilité
/usr/share/sddm/themes
Où sddm recherche les thèmes

VOIR AUSSI

sddm(1), sddm.conf(5)
