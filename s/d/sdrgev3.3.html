SDRGEV3

But :

!>
!> SDRGEV3 teste la procédure de pilotage de problème de valeurs propres généralisé non symétrique
!> SGGEV3.
!>
!> SGGEV3 calcule pour une paire de matrices carrées n x n non symétriques (A,B) les
!> valeurs propres généralisées et, optionnellement, les vecteurs propres gauches et droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulier. Elle est
!> généralement représentée par la paire (alpha,beta), car il y a une interprétation raisonnable
!> pour beta=0, et même pour les deux étant zéro.
!>
!> Un vecteur propre généralisé droit correspondant à une valeur propre généralisée
!> w pour une paire de matrices (A,B) est un vecteur r tel que
!> (A - wB) * r = 0. Un vecteur propre généralisé gauche est un vecteur l de telle sorte que
!> l**H * (A - wB) = 0, où l**H est la transposée conjuguée de l.
!>
!> Lorsque SDRGEV3 est appelée, un certain nombre de tailles de matrice (NN) et
!> un certain nombre de types de matrices (DOTYPE) sont spécifiés. Pour chaque taille (NN)
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les tests suivants
!> seront effectués et comparés au seuil THRESH.
!>
!> Résultats de SGGEV3 :
!>
!> (1) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,l) de
!>
!>     | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>     où VL**H est la transposée conjuguée de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!>     VL(i) dénote la i-ème colonne de VL.
!>
!> (3) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,r) de
!>
!>     | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!>     VR(i) dénote la i-ème colonne de VR.
!>
!> (5) W(complet) = W(partiel)
!>     W(complet) dénote les valeurs propres calculées lorsque l et r
!>     sont également calculés, et W(partiel) dénote les valeurs propres
!>     calculées lorsque seuls W, seulement W et r, ou seulement W et l sont
!>     calculés.
!>
!> (6) VL(complet) = VL(partiel)
!>     VL(complet) dénote les vecteurs propres gauches calculés lorsque l et
!>     r sont calculés, et VL(partiel) dénote le résultat
!>     lorsque seul l est calculé.
!>
!> (7) VR(complet) = VR(partiel)
!>     VR(complet) dénote les vecteurs propres droits calculés lorsque l et
!>     r sont également calculés, et VR(partiel) dénote le résultat
!>     lorsqu'il n'y a que l qui est calculé.
!>
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .TRUE., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1) ( 0, 0 ) (une paire de matrices nulles)
!>
!> (2) ( I, 0 ) (une matrice identité et une matrice nulle)
!>
!> (3) ( 0, I ) (une matrice nulle et une matrice identité)
!>
!> (4) ( I, I ) (une paire de matrices identité)
!>
!>         t   t
!> (5) ( J , J  ) (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y ) où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une matrice identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       ; k=(N-1)/2
!>
!> (7) ( D, I ) où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                       avec ces entrées diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) où  big est proche du dépassement de capacité et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées O(1) aléatoires au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!>

!>          NTYPES is INTEGER
!>          The number of types of matrices to be generated.
!>          NTYPES must be at least 0.
!>

NSIZES

!>          NSIZES is INTEGER
!>          The number of matrix sizes to be tested.
!>

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          The matrix sizes to be tested.
!>

MAXTYP

!>          MAXTYP is PARAMETER, INTEGER
!>          The maximum number of matrix types.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of B. It must be at least 1 and
!>          at least max(NN).
!>

LDZ 

!>          LDZ is INTEGER
!>          The leading dimension of Z. It must be at least 1 and
!>          at least max(NN).
!>

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated. If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096. Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to SDRGEV3 to continue the same random number
!>          sequence.
!>

THRESH

!>          THRESH is REAL
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error is
!>          scaled to be O(1), so THRESH should be a reasonably small
!>          multiple of 1, e.g., 10 or 100.  In particular, it should
!>          not depend on the precision (single vs. double) or the size
!>          of the matrix.  It must be at least zero.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IERR not equal to 0.)
!>

A

!>          A is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original A matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, S, and T.
!>          It must be at least 1 and at least max( NN ).
!>

B

!>          B is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original B matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S is REAL array,
!>                                 dimension (LDA, max(NN))
!>          The Schur form matrix computed from A by SGGEV3.  On exit, S
!>          contains the Schur form matrix corresponding to the matrix
!>          in A.
!>

T

!>          T is REAL array,
!>                                 dimension (LDA, max(NN))
!>          The upper triangular matrix computed from B by SGGEV3.
!>

Q

!>          Q is REAL array,
!>                                 dimension (LDQ, max(NN))
!>          The (left) eigenvectors matrix computed by SGGEV3.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q and Z. It must
!>          be at least 1 and at least max( NN ).
!>

Z

!>          Z is REAL array, dimension( LDQ, max(NN) )
!>          The (right) orthogonal matrix computed by SGGEV3.
!>

QE

!>          QE is REAL array, dimension( LDQ, max(NN) )
!>          QE holds the computed right or left eigenvectors.
!>

LDQE

!>          LDQE is INTEGER
!>          The leading dimension of QE. LDQE >= max(1,max(NN)).
!>

ALPHAR

!>          ALPHAR is REAL array, dimension (max(NN))
!>

ALPHAI

!>          ALPHAI is REAL array, dimension (max(NN))
!>

BETA

!>          BETA is REAL array, dimension (max(NN))
!> \verbatim
!>          The generalized eigenvalues of (A,B) computed by SGGEV3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th
!>          generalized eigenvalue of A and B.
!>

ALPHR1

!>          ALPHR1 is REAL array, dimension (max(NN))
!>

ALPHI1

!>          ALPHI1 is REAL array, dimension (max(NN))
!>

!>          BETA1 is REAL array, dimension (max(NN))
!>
!>          Like ALPHAR, ALPHAI, BETA, these arrays contain the
!>          eigenvalues of A and B, but those computed when SGGEV3 only
!>          computes a partial eigendecomposition, i.e. not the
!>          eigenvalues and left and right eigenvectors.
