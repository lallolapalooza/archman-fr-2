SD_EVENT_SOURCE_SET_USERDATA(3) sd_event_source_set_userdata SD_EVENT_SOURCE_SET_USERDATA(3)

NOM

sd_event_source_set_userdata, sd_event_source_get_userdata - Définir ou récupérer les données utilisateur des sources d'événements

SYNTAXE

#include <systemd/sd-event.h>

void* sd_event_source_set_userdata(sd_event_source *source, void *userdata);

void* sd_event_source_get_userdata(sd_event_source *source);

DESCRIPTION

sd_event_source_set_userdata() peut être utilisée pour définir un pointeur de données utilisateur arbitraire pour l'objet source d'événement spécifié par source. Le pointeur de données utilisateur est généralement spécifié lors de la création d'un objet source d'événement avec des appels tels que sd_event_add_io(3) ou sd_event_add_time(3), et peut être mis à jour avec cet appel. Les données utilisateur sont également transmises à toutes les fonctions de rappel de gestion associées à la source d'événement. Le paramètre userdata spécifie le nouveau pointeur de données utilisateur à définir, la fonction renvoie le pointeur de données utilisateur précédent. Notez que NULL est un pointeur de données utilisateur valide.

sd_event_source_get_userdata() peut être utilisée pour interroger le pointeur de données utilisateur actuel assigné à l'objet source d'événement source.

VALEUR DE RETOUR

En cas de succès, sd_event_source_set_userdata() et sd_event_source_get_userdata() retournent le pointeur de données utilisateur précédemment défini. En cas d'échec, elles retournent NULL.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() que lors d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_event_source_set_userdata() et sd_event_source_get_userdata() ont été ajoutées dans la version 229.
