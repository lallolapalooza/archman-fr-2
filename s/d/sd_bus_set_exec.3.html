SD_BUS_SET_ADDRESS(3) sd_bus_set_address SD_BUS_SET_ADDRESS(3)

NOM

sd_bus_set_address, sd_bus_get_address, sd_bus_set_exec - Définir ou interroger l'adresse de la connexion de bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_set_address(sd_bus *bus, const char *address);

int sd_bus_get_address(sd_bus *bus, const char **address);

int sd_bus_set_exec(sd_bus *bus, const char *path, char *const *argv);

DESCRIPTION

sd_bus_set_address() configure une liste d'adresses de courtiers de bus à essayer de connecter à partir d'un appel ultérieur à sd_bus_start(3). L'argument est une liste d'adresses séparées par des ";" à essayer. Chaque élément doit être l'un des éléments suivants :

•Une adresse de socket Unix spécifiée comme "unix:guid=guid,path=path" ou "unix:guid=guid,abstract=path". Exactement une des clés path= et abstract= doit être présente, tandis que guid= est facultative.
•Une adresse de socket TCP spécifiée comme "tcp:[guid=guid,][host=host][,port=port][,family=family]". Une ou deux des clés host= et port= doivent être présentes, tandis que le reste est facultatif. family peut être soit ipv4, soit ipv6.
•Un exécutable à lancer spécifié comme "unixexec:guid=guid,path=path,argv1=argument,argv2=argument,...". La clé path= doit être présente, tandis que guid= est facultative.
•Une machine (conteneur) à laquelle se connecter, spécifiée comme "x-machine-unix:guid=guid,machine=machine,pid=pid". Exactement une des clés machine= et pid= doit être présente, tandis que guid= est facultative. machine est le nom d'un conteneur local. Voir machinectl(1) pour plus d'informations sur le concept de "machine". "machine=.host" peut être utilisé pour spécifier la machine hôte. Une connexion au socket de bus système standard à l'intérieur de la machine spécifiée sera créée.

Dans tous les cas, le paramètre guid est un identifiant du pair distant, dans la syntaxe acceptée par sd_id128_from_string(3). S'il est spécifié, l'identifiant renvoyé par le pair après l'établissement de la connexion sera vérifié et la connexion sera rejetée en cas d'incohérence.

Notez que les adresses passées à sd_bus_set_address() pourraient ne pas être vérifiées immédiatement. Si elles sont invalides, une erreur peut être renvoyée, par exemple, à partir d'un appel ultérieur à sd_bus_start(3).

sd_bus_get_address() renvoie toutes les adresses précédemment définies. En plus d'être explicitement définies par sd_bus_set_address(), l'adresse sera également définie automatiquement par sd_bus_open(3) et les appels similaires, en fonction des variables d'environnement ou des valeurs par défaut intégrées.

sd_bus_set_exec() est une fonction abrégée pour définir une adresse "unixexec" qui lance l'exécutable donné avec les arguments donnés. Si argv est NULL, l'exécutable donné est lancé sans arguments supplémentaires.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient un entier non négatif. En cas d'échec, elles renvoient un code d'erreur négatif de type errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Les paramètres d'entrée bus ou address sont NULL.

Ajouté dans la version 246.

-ENOPKG

L'objet bus bus n'a pas pu être résolu.

Ajouté dans la version 246.

-EPERM

L'objet bus bus est dans un état incorrect (sd_bus_set_address() ne peut être appelé qu'une fois sur un objet bus nouvellement créé).

Ajouté dans la version 246.

-ECHILD

L'objet bus bus a été créé dans un processus différent.

Ajouté dans la version 246.

-ENODATA

L'objet bus bus n'a aucune adresse configurée.

Ajouté dans la version 246.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour l'utilisation dans des threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() qu'à partir d'une phase précoce du programme lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_set_address(), sd_bus_get_address() et sd_bus_set_exec() ont été ajoutés dans la version 246.
