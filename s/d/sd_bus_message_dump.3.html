SD_BUS_MESSAGE_DUMP(3) sd_bus_message_dump SD_BUS_MESSAGE_DUMP(3)

NOM

sd_bus_message_dump, sd_bus_message_dump_json - Produire une représentation textuelle d'un message à des fins de débogage

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_dump(sd_bus_message *m, FILE *f, uint64_t flags);

int sd_bus_message_dump_json(sd_bus_message *m, uint64_t flags, sd_json_variant **ret);

DESCRIPTION

La fonction sd_bus_message_dump() écrit une représentation textuelle du message m dans le flux f. Si f est NULL, la sortie standard (stdio) sera utilisée. Cette fonction est destinée à être utilisée à des fins de débogage, et la sortie n'est ni stable ni conçue pour être lisible par machine.

La fonction sd_bus_message_dump_json() convertit le message DBus m en un variant JSON et le stocke dans ret. L'appelant doit appeler sd_json_variant_unref() pour le variant JSON acquis après utilisation. Contrairement à sd_bus_message_dump(), la fonction elle-même n'affiche rien. Pour afficher le message DBus au format JSON, veuillez passer le variant JSON retourné à sd_json_variant_dump().

Le paramètre flags peut être utilisé pour modifier la sortie, et est une combinaison de zéro ou plusieurs des drapeaux suivants :

SD_BUS_MESSAGE_DUMP_WITH_HEADER

L'en-tête du message qui spécifie le type de message, les drapeaux et plusieurs métadonnées supplémentaires seront imprimés ou inclus dans l'objet JSON résultant.

SD_BUS_MESSAGE_DUMP_SUBTREE_ONLY

Seul le conteneur courant sera imprimé ou converti. Lorsque le drapeau n'est *pas* spécifié, le contenu du message entier sera imprimé ou converti.

Notez que ces fonctions déplacent le pointeur de lecture du message. Il peut être nécessaire de réinitialiser la position par la suite, par exemple avec sd_bus_message_rewind(3).

EXEMPLES

Sortie pour un message de signal (avec SD_BUS_MESSAGE_DUMP_WITH_HEADER) :

> Type=signal  Endian=l  Flags=1  Version=1  Cookie=22
  Path=/value/a  Interface=org.freedesktop.DBus.Properties  Member=PropertiesChanged
  MESSAGE "sa{sv}as" {
          STRING "org.freedesktop.systemd.ValueTest";
          ARRAY "{sv}" {
                  DICT_ENTRY "sv" {
                          STRING "Value";
                          VARIANT "s" {
                                  STRING "object 0x1e, path /value/a";
                          };
                  };
          };
          ARRAY "s" {
                  STRING "Value2";
                  STRING "AnExplicitProperty";
          };
  };

VALEUR DE RETOUR

En cas de succès, cette fonction retourne 0 ou un entier positif. En cas d'échec, elle retourne un code d'erreur négatif de type errno. Aucun code d'erreur n'est actuellement défini.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à partir d'une phase précoce du programme lorsque aucun autre thread n'a été démarré.
