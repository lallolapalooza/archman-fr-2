SD_JOURNAL_ENUMERATE_FIELDS(3) sd_journal_enumerate_fields SD_JOURNAL_ENUMERATE_FIELDS(3)

NOM

sd_journal_enumerate_fields, sd_journal_restart_fields, SD_JOURNAL_FOREACH_FIELD - Lire les noms de champs utilisés dans le journal

SYNTAXE

#include <systemd/sd-journal.h>

int sd_journal_enumerate_fields(sd_journal *j, const char **field);

void sd_journal_restart_fields(sd_journal *j);

SD_JOURNAL_FOREACH_FIELD(sd_journal *j, const char *field);

DESCRIPTION

sd_journal_enumerate_fields() peut être utilisé pour parcourir tous les noms de champs utilisés dans les fichiers du journal ouverts. À chaque appel, le nom du champ suivant est retourné. L'ordre des noms de champs retournés n'est pas défini. Il prend deux arguments : le contexte du journal, plus un pointeur vers un pointeur de chaîne constant où le nom du champ est stocké. Les données retournées se trouvent dans une carte mémoire en lecture seule et ne sont valides que jusqu'au prochain appel à sd_journal_enumerate_fields(). Notez que cet appel est soumis au seuil de taille des champs de données contrôlé par sd_journal_set_data_threshold().

sd_journal_restart_fields() réinitialise l'index de l'énumération des noms de champs au début de la liste. Le prochain appel à sd_journal_enumerate_fields() retournera à nouveau le premier nom de champ.

La macro SD_JOURNAL_FOREACH_FIELD() peut être utilisée comme un wrapper pratique autour de sd_journal_restart_fields() et sd_journal_enumerate_fields().

Ces fonctions ne sont actuellement pas influencées par les correspondances définies avec sd_journal_add_match(), mais cela pourrait changer dans une future version de ce logiciel.

Pour récupérer les valeurs possibles qu'un champ spécifique peut prendre, utilisez sd_journal_query_unique(3).

VALEUR DE RETOUR

sd_journal_enumerate_fields() retourne un entier positif si le nom du champ suivant a été lu, 0 lorsqu'il n'y a plus de noms de champs connus, ou un code d'erreur négatif de type errno. sd_journal_restart_fields() ne retourne rien.

NOTES

Toutes les fonctions listées ici sont indépendantes des threads et seul un seul thread peut opérer sur un objet donné à un moment donné. Différents threads peuvent accéder au même objet à des moments différents. Plusieurs objets indépendants peuvent être utilisés par différents threads en parallèle.

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

EXEMPLES

Utilisez la macro SD_JOURNAL_FOREACH_FIELD() pour parcourir tous les noms de champs utilisés dans le journal actuel.

/* SPDX-License-Identifier: MIT-0 */
#include <errno.h>
#include <stdio.h>
#include <systemd/sd-journal.h>
int main(int argc, char *argv[]) {
  sd_journal *j;
  const char *field;
  int r;
  r = sd_journal_open(&j, SD_JOURNAL_LOCAL_ONLY);
  if (r < 0) {
    fprintf(stderr, "Failed to open journal: %s\n", strerror(-r));
    return 1;
  }
  SD_JOURNAL_FOREACH_FIELD(j, field)
    printf("%s\n", field);
  sd_journal_close(j);
  return 0;
}

HISTORIQUE

sd_journal_enumerate_fields(), sd_journal_restart_fields(), et SD_JOURNAL_FOREACH_FIELD() ont été ajoutés dans la version 229.
