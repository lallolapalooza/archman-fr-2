SD_BUS_SET_FD(3) sd_bus_set_fd SD_BUS_SET_FD(3)

NOM

sd_bus_set_fd - Définit les descripteurs de fichiers à utiliser pour la communication sur le bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_set_fd(sd_bus *bus, int input_fd, int output_fd);

DESCRIPTION

sd_bus_set_fd() définit les descripteurs de fichiers utilisés pour communiquer par un objet de connexion de bus. Les deux input_fd et output_fd doivent être des descripteurs de fichiers valides, faisant référence à des objets de fichier basés sur des flux (par exemple, une socket de flux, une paire de pipes ou FIFOs, ou même un périphérique TTY). input_fd doit être lisible et output_fd doit être accessible en écriture. Le même descripteur de fichier peut être utilisé (et l'est typiquement) à la fois comme descripteur de fichier d'entrée et de sortie. Cette fonction doit être appelée avant que la connexion de bus ne soit démarrée via sd_bus_start(3).

L'objet de connexion de bus prendra possession des descripteurs de fichiers passés et les fermera automatiquement lorsqu'il sera libéré. Utilisez sd_bus_set_close_on_exit(3) pour désactiver ce comportement.

VALEUR DE RETOUR

En cas de succès, sd_bus_set_fd() renvoie un entier non négatif. En cas d'échec, elle renvoie un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Un objet de bus invalide a été passé.

Ajouté dans la version 248.

-ECHILD

La connexion de bus a été allouée dans un processus parent et est réutilisée dans un processus enfant après fork().

Ajouté dans la version 248.

-EBADF

Un descripteur de fichier invalide a été passé à sd_bus_set_fd().

Ajouté dans la version 248.

-ENOPKG

Le bus ne peut pas être résolu.

Ajouté dans la version 248.

-EPERM

La connexion de bus a déjà été démarrée.

Ajouté dans la version 248.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme non thread-safe. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() que dès le début du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_set_fd() a été ajoutée dans la version 248.
