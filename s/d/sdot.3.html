fonction réelle sdot (entier n, réel, dimension(*) sx, entier incx, réel, dimension(*) sy, entier incy)

SDOT

Objectif :

!>
!>    SDOT calcule le produit scalaire de deux vecteurs.
!>    utilise des boucles déroulées pour des incréments égaux à un.
!>

Paramètres

N 
!>          N est un ENTIER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

SX

!>          SX est un tableau RÉEL, de dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est un ENTIER
!>         espacement de stockage entre les éléments de SX
!>

SY

!>          SY est un tableau RÉEL, de dimension ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY est un ENTIER
!>         espacement de stockage entre les éléments de SY
!>
