SDRVSY_AA_2STAGE

Objectif :

!>
!> SDRVSY_AA_2STAGE teste la sous-routine pilote SSYSV_AA_2STAGE.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, de dimension (NN)
!>          Les valeurs de la dimension de la matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de droite générés pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un REEL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utiliser THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui signale si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau REEL, de dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau REEL, de dimension (NMAX*NMAX)
!>

AINV

!>          AINV est un tableau REEL, de dimension (NMAX*NMAX)
!>

B

!>          B est un tableau REEL, de dimension (NMAX*NRHS)
!>

X

!>          X est un tableau REEL, de dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau REEL, de dimension (NMAX*NRHS)
!>

WORK

!>          WORK est un tableau REEL, de dimension (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (NMAX+2*NRHS)
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité de sortie.
!>
