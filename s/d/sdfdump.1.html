SDFDUMP(1) Commandes utilisateur SDFDUMP(1)

NOM

sdfdump - page de manuel pour sdfdump 25.11

SYNTAXE

sdfdump [OPTIONS] fichiersEntree...

DESCRIPTION

Filtre et affiche les données brutes de couche

Positionnels :

fichiersEntree ...
Les fichiers d'entrée à exporter.

OPTIONS

-h,--aide
Imprimer ce message d'aide et quitter
-s,--resume
Rapporter un résumé de haut niveau.
--valider
Vérifier la validité en essayant de lire toutes les valeurs de données.
-p,--chemin regex
Rapporter uniquement les chemins correspondant à cette expression régulière.
-f,--champ regex
Rapporter uniquement les champs correspondant à cette expression régulière.
-t,--temps n ou ff..lf
Rapporter uniquement ces temps (n) ou ces plages de temps (ff..lf) pour les champs 'timeSamples'
--toleranceTemps tol
Rapporter les temps proches de ceux demandés dans cette tolérance relative. Par défaut : 0.000125
--trierPar chemin|champ
Regrouper la sortie par chemin ou par champ. Par défaut : chemin
--pasValeurs
Ne pas rapporter les valeurs des champs.
--tableauxComplets
Rapporter le contenu complet des tableaux plutôt que le nombre d'éléments
