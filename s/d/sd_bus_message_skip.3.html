SD_BUS_MESSAGE_SKIP(3) sd_bus_message_skip SD_BUS_MESSAGE_SKIP(3)

NOM

sd_bus_message_skip - Ignorer des éléments dans un message bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_skip(sd_bus_message *m, const char* types);

DESCRIPTION

sd_bus_message_skip() est en quelque sorte similaire à sd_bus_message_read(3), mais au lieu de lire le contenu du message, elle ne fait que déplacer le « pointeur de lecture ». Les opérations de lecture ultérieures liront les éléments qui se trouvent après les éléments qui ont été ignorés.

L'argument types a la même signification que dans sd_bus_message_read(). Il peut également être NULL, pour ignorer un seul élément de n'importe quel type.

VALEUR DE RETOUR

En cas de succès, sd_bus_message_skip() retourne 0 ou un entier positif. En cas d'échec, elle retourne un code d'erreur négatif de style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre m est NULL.

-EBADMSG

Le message ne peut pas être analysé.

-EPERM

Le message n'est pas scellé.

-ENXIO

La fin du message a été atteinte et les éléments demandés ne peuvent pas être lus.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() qu'à partir d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_message_skip() a été ajoutée dans la version 240.
