Documentation de la fonction/sous-programme

sous-programme sdrvsp (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, réel thresh, logique tsterr, entier nmax, réel, dimension( * ) a, réel, dimension( * ) afac, réel, dimension( * ) ainv, réel, dimension( * ) b, réel, dimension( * ) x, réel, dimension( * ) xact, réel, dimension( * ) work, réel, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

SDRVSP

Objectif :

!>
!> SDRVSP teste les routines de pilote SSPSV et -SVX.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI. ; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d' ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de la matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs du second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un RÉEL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULTAT >= SEUIL. Pour que
!>          chaque ratio de test soit imprimé, utiliser SEUIL = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur indiquant si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau de RÉELS, dimension
!>                      (NMAX*(NMAX+1)/2)
!>

AFAC

!>          AFAC est un tableau de RÉELS, dimension
!>                      (NMAX*(NMAX+1)/2)
!>

AINV

!>          AINV est un tableau de RÉELS, dimension
!>                      (NMAX*(NMAX+1)/2)
!>

B

!>          B est un tableau de RÉELS, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau de RÉELS, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau de RÉELS, dimension (NMAX*NRHS)
!>

WORK

!>          WORK est un tableau de RÉELS, dimension
!>                      (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK est un tableau de RÉELS, dimension (NMAX+2*NRHS)
!>

IWORK

!>          IWORK est un tableau d' ENTIERS, dimension (2*NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité pour la sortie.
!>
