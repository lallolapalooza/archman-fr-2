sd_bus_message_append_string_memfd(3)

SD_BUS_MESSAGE_APPEND_STRING_MEMFD(3) sd_bus_message_append_string_memfd SD_BUS_MESSAGE_APPEND_STRING_MEMFD(3)

NOM

sd_bus_message_append_string_memfd, sd_bus_message_append_string_iovec, sd_bus_message_append_string_space - Attacher une chaîne à un message

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_append_string_memfd(sd_bus_message *m, int memfd);

int sd_bus_message_append_string_iovec(sd_bus_message *m, const struct iovec *iov, unsigned n);

int sd_bus_message_append_string_space(sd_bus_message *m, size_t size, char **s);

DESCRIPTION

Les fonctions sd_bus_message_append_string_memfd() et sd_bus_message_append_string_iovec() peuvent être utilisées pour attacher une seule chaîne (élément de type « s ») au message m.

Dans le cas de sd_bus_message_append_string_memfd(), le contenu de memfd constitue la chaîne. Il doit satisfaire les mêmes contraintes que celles décrites pour le type « s » dans sd_bus_message_append_basic(3).

Dans le cas de sd_bus_message_append_string_iovec(), la charge utile de iov constitue la chaîne. Elle doit satisfaire les mêmes contraintes que celles décrites pour le type « s » dans sd_bus_message_append_basic(3).

L'argument iov doit pointer vers n structures iovec. Chaque structure peut avoir le champ iov_base défini, auquel cas la mémoire pointée sera copiée dans le message, ou non défini, auquel cas un bloc d'espaces (ASCII 32) de longueur iov_len sera inséré. La mémoire pointée par iov peut être modifiée après cet appel.

La fonction sd_bus_message_append_string_space() attache de l'espace pour une chaîne au message m. Elle se comporte de manière similaire à sd_bus_message_append_basic() avec le type « s », mais au lieu de copier une chaîne dans le message, elle renvoie un pointeur vers la zone de destination à l'appelant dans le pointeur p. De l'espace pour la chaîne de longueur size plus le caractère NUL de terminaison est alloué.

VALEUR DE RETOUR

En cas de succès, ces appels renvoient 0 ou un entier positif. En cas d'échec, ils renvoient un code d'erreur négatif de type errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre spécifié est invalide.

-EPERM

Le message a été scellé.

-ESTALE

Le message est dans un état invalide.

-ENXIO

Le message ne peut pas être attaché.

-ENOMEM

Échec de l'allocation de mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr en multithreading. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de ne faire des appels à setenv() que depuis une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.
