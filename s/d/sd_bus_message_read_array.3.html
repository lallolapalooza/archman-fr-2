NOM

sd_bus_message_read_array - Accéder à un tableau d'éléments dans un message

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_read_array(sd_bus_message *m, char type, const void **ptr, size_t *size);

DESCRIPTION

sd_bus_message_read_array() donne accès aux éléments d'un tableau dans le message de bus m. Le « pointeur de lecture » dans le message doit être positionné juste avant un tableau de type type. À titre de cas spécial, type peut être NUL, auquel cas tout type trivial est acceptable. Un pointeur vers les données du tableau est retourné dans le paramètre ptr et la taille des données du tableau (en octets) est retournée dans le paramètre size. Si le paramètre size retourné est 0, un pointeur valide non nul sera retourné comme ptr, mais il ne pourra pas être déréférencé. Les données sont alignées de manière appropriée pour le type de données. Les données font partie du message — elles ne peuvent pas être modifiées et ne sont valides que tant que le message est référencé. Après le retour de cette fonction, le « pointeur de lecture » pointe vers l'élément suivant le tableau.

Notez que cette fonction ne prend en charge que les tableaux de types triviaux, c'est-à-dire les tableaux de booléens, les différents types d'entiers, ainsi que les nombres à virgule flottante. En particulier, elle ne peut pas être utilisée pour les tableaux de chaînes de caractères, de structures ou similaires.

VALEUR DE RETOUR

En cas de succès et lorsqu'un tableau a été lu, sd_bus_message_read_array() retourne un entier supérieur à zéro. Si elle est appelée à l'intérieur d'un élément conteneur (tel qu'un tableau, par exemple lors de l'opération sur un tableau de tableaux) et que le dernier élément du conteneur externe a déjà été lu et que le pointeur de lecture est donc après le dernier élément du conteneur externe, cet appel retourne 0 (et le pointeur retourné sera NULL et la taille sera 0). En cas d'échec, il retourne un code d'erreur négatif de style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Le type spécifié est invalide ou n'est pas un type trivial (voir ci-dessus), ou le paramètre de message ou l'un des paramètres de sortie est NULL.

-EOPNOTSUPP

L'ordre des octets dans le message est différent de l'ordre natif des octets.

-EPERM

Le message n'est pas scellé.

-EBADMSG

Le message ne peut pas être analysé.

HISTORIQUE

sd_bus_message_read_array() a été ajouté dans la version 240.
