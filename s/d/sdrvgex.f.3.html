Documentation de la fonction/sous-routine

sous-routine sdrvge (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, reel thresh, logique tsterr, entier nmax, reel, dimension( * ) a, reel, dimension( * ) afac, reel, dimension( * ) asav, reel, dimension( * ) b, reel, dimension( * ) bsav, reel, dimension( * ) x, reel, dimension( * ) xact, reel, dimension( * ) s, reel, dimension( * ) work, reel, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

SDRVGEX

Objectif:

!>
!> SDRVGE teste les routines de pilotage SGESV, -SVX et -SVXX.
!>
!> Notez que ce fichier n'est utilisé que lorsque les XBLAS sont disponibles,
!> sinon sdrvge.f définit cette sous-routine.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .VRAI.; si DOTYPE(j) = .FAUX., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de colonne de la matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un REEL
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque ratio de test soit imprimé, utiliser THRESH = 0.
!>

TSTERR

!>          TSTERR est LOGIQUE
!>          Indicateur indiquant si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau REEL, dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau REEL, dimension (NMAX*NMAX)
!>

ASAV

!>          ASAV est un tableau REEL, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau REEL, dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV est un tableau REEL, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau REEL, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau REEL, dimension (NMAX*NRHS)
!>

S

!>          S est un tableau REEL, dimension (2*NMAX)
!>

WORK

!>          WORK est un tableau REEL, dimension
!>                      (NMAX*max(3,NRHS))
!>

RWORK

!>          RWORK est un tableau REEL, dimension (2*NRHS+NMAX)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (2*NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro d'unité pour la sortie.
!>
