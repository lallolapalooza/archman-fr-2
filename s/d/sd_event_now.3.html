NOM

sd_event_now - Récupérer l'horodatage de l'itération actuelle de la boucle d'événements

SYNTAXE

#include <systemd/sd-event.h>

int sd_event_now(sd_event *event, clockid_t clock, uint64_t *ret);

DESCRIPTION

sd_event_now() renvoie l'heure à laquelle la dernière itération de la boucle d'événements a commencé. Un horodatage est pris juste après le retour de la mise en veille de l'événement, et avant la distribution de toute source d'événement. Le paramètre event spécifie l'objet de la boucle d'événements dont il faut récupérer l'horodatage. Le paramètre clock spécifie l'horloge pour laquelle l'horodatage doit être récupéré, et il peut s'agir de CLOCK_REALTIME (ou équivalent CLOCK_REALTIME_ALARM), CLOCK_MONOTONIC, ou CLOCK_BOOTTIME (ou équivalent CLOCK_BOOTTIME_ALARM), voir clock_gettime(2) pour plus d'informations sur les différentes horloges. L'horodatage récupéré est stocké dans le paramètre ret, en μs depuis l'époque de l'horloge. Si cette fonction est appelée avant la première itération de la boucle d'événements, l'heure actuelle est renvoyée, telle que rapportée par clock_gettime(). Pour distinguer ce cas d'une invocation régulière, la valeur de retour sera positive, et nulle lorsque l'horodatage renvoyé fait référence à une itération réelle de la boucle d'événements.

VALEUR DE RETOUR

Si la première itération de la boucle d'événements n'a pas encore été exécutée, sd_event_now() écrit l'heure actuelle dans ret et renvoie une valeur positive. Sinon, elle écrira l'horodatage demandé dans ret et renverra 0. En cas d'échec, l'appel renvoie un code d'erreur négatif de type errno.

Erreurs

Les valeurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Un paramètre invalide a été passé.

-EOPNOTSUPP

Type d'horloge non supporté.

-ECHILD

L'objet de la boucle d'événements a été créé dans un processus, une bibliothèque ou une instance de module différente.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer les appels à setenv() que lors d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_event_now() a été ajoutée dans la version 229.
