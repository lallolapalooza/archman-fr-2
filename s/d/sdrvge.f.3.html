sous-routine sdrvge (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, reel thresh, logique tsterr, entier nmax, reel, dimension( * ) a, reel, dimension( * ) afac, reel, dimension( * ) asav, reel, dimension( * ) b, reel, dimension( * ) bsav, reel, dimension( * ) x, reel, dimension( * ) xact, reel, dimension( * ) s, reel, dimension( * ) work, reel, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

But :

!>
!> SDRVGE teste les routines de commande SGESV et -SVX.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un entier
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers de dimension (NN)
!>          Les valeurs de la dimension de colonne N de la matrice.
!>

NRHS

!>          NRHS est un entier
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un réel
!>          La valeur seuil pour les ratios de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>          avoir tous les ratios de test imprimés, utiliser THRESH = 0.
!>

TSTERR

!>          TSTERR est un logique
!>          Indicateur indiquant si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un entier
!>          La valeur maximale autorisée pour N, utilisée pour dimensionner les
!>          tableaux de travail.
!>

A

!>          A est un tableau de réels de dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau de réels de dimension (NMAX*NMAX)
!>

ASAV

!>          ASAV est un tableau de réels de dimension (NMAX*NMAX)
!>

B

!>          B est un tableau de réels de dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV est un tableau de réels de dimension (NMAX*NRHS)
!>

X

!>          X est un tableau de réels de dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau de réels de dimension (NMAX*NRHS)
!>

S

!>          S est un tableau de réels de dimension (2*NMAX)
!>

WORK

!>          WORK est un tableau de réels de dimension
!>                      (NMAX*max(3,NRHS))
!>

RWORK

!>          RWORK est un tableau de réels de dimension (2*NRHS+NMAX)
!>

IWORK

!>          IWORK est un tableau d'entiers de dimension (2*NMAX)
!>

NOUT

!>          NOUT est un entier
!>          Le numéro d'unité de sortie.
!>
