NOM

sd_bus_set_sender, sd_bus_get_sender - Configurer l'expéditeur par défaut pour les messages sortants

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_set_sender(sd_bus *bus, const char* name);

int sd_bus_get_sender(sd_bus *bus, const char** name);

DESCRIPTION

sd_bus_set_sender() configure le nom du service d'expéditeur par défaut à utiliser pour les messages sortants. Le nom du service spécifié dans le paramètre name est défini sur tous les messages sortants qui sont envoyés sur la connexion et pour lesquels aucun expéditeur n'est encore défini, par exemple via sd_bus_message_set_sender(3). Notez que cette fonction n'est prise en charge que sur les connexions directes, c'est-à-dire pas sur les connexions à un courtier de bus, car le courtier remplira automatiquement le nom du service d'expéditeur de toute façon. Par défaut, aucun nom d'expéditeur n'est configuré, et donc les messages sont envoyés sans champ d'expéditeur défini. Si le paramètre name est spécifié comme NULL, le nom du service d'expéditeur par défaut est effacé, revenant à l'état par défaut si un nom de service d'expéditeur par défaut avait été défini auparavant. S'il est passé comme non-NULL, le nom spécifié doit être un nom de service unique ou bien connu valide.

sd_bus_get_sender() peut être utilisé pour interroger le nom du service par défaut actuel pour les messages sortants.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient 0 ou un entier positif. En cas d'échec, elles renvoient un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion de bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

-EPERM

L'objet de connexion de bus spécifié n'est pas une connexion directe mais une connexion via un courtier.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée à l'aide du fichier pkg-config(1) libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les appels multi-threads. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_set_sender() et sd_bus_get_sender() ont été ajoutés dans la version 237.
