sd_journal_next_skip(3)

Paquet: systemd-libs

Licences: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_JOURNAL_NEXT(3) sd_journal_next SD_JOURNAL_NEXT(3)

NOM

sd_journal_next, sd_journal_previous, sd_journal_step_one, sd_journal_next_skip, sd_journal_previous_skip, SD_JOURNAL_FOREACH, SD_JOURNAL_FOREACH_BACKWARDS - Avancer ou reculer le pointeur de lecture dans le journal

SYNTAXE

#include <systemd/sd-journal.h>

int sd_journal_next(sd_journal *j);

int sd_journal_previous(sd_journal *j);

int sd_journal_step_one(sd_journal *j, int avancé);

int sd_journal_next_skip(sd_journal *j, uint64_t saut);

int sd_journal_previous_skip(sd_journal *j, uint64_t saut);

SD_JOURNAL_FOREACH(sd_journal *j);

SD_JOURNAL_FOREACH_BACKWARDS(sd_journal *j);

DESCRIPTION

sd_journal_next() fait avancer le pointeur de lecture dans le journal d'une entrée. Le seul argument pris est un objet de contexte de journal alloué via sd_journal_open(3). Après une invocation réussie, l'entrée peut être lue avec des fonctions telles que sd_journal_get_data(3).

De même, sd_journal_previous() recule le pointeur de lecture d'une entrée.

sd_journal_step_one() déplace également le pointeur de lecture. Si la position actuelle est la tête du journal, par exemple lors d'un appel suivant sd_journal_seek_head(), alors cela équivaut à sd_journal_next(), et l'argument avancé sera ignoré. De même, si la position actuelle est la queue du journal, par exemple lors d'un appel suivant sd_journal_seek_tail(), alors cela équivaut à sd_journal_previous(), et avancé sera ignoré. Sinon, cela équivaut à sd_journal_next() lorsque avancé est non nul, et sd_journal_previous() lorsque avancé est nul.

sd_journal_next_skip() et sd_journal_previous_skip() font avancer/reculer le pointeur de lecture de plusieurs entrées à la fois, comme spécifié dans le paramètre saut. Le paramètre saut doit être inférieur ou égal à 2147483647 (231-1).

Le journal est strictement ordonné par le temps de réception, et par conséquent, avancer à l'entrée suivante garantit que l'entrée sur laquelle le pointeur pointe est plus tardive que la précédente, ou a le même horodatage.

Notez que sd_journal_get_data(3) et les appels connexes échoueront à moins que sd_journal_next() n'ait été invoqué au moins une fois afin de positionner le pointeur de lecture sur une entrée du journal.

Notez que la macro SD_JOURNAL_FOREACH() peut être utilisée comme enveloppe autour de sd_journal_seek_head(3) et sd_journal_next() afin de faciliter l'itération à travers le journal. Voir ci-dessous pour un exemple. De même, SD_JOURNAL_FOREACH_BACKWARDS() peut être utilisée pour itérer le journal dans l'ordre inverse.

VALEUR DE RETOUR

Les quatre appels retournent le nombre d'entrées avancées/reculées en cas de succès ou un code d'erreur négatif de type errno. Lorsque la fin ou le début du journal est atteint, un nombre inférieur à celui demandé est retourné. Plus précisément, si sd_journal_next() ou sd_journal_previous() atteignent la fin/le début du journal, ils retourneront 0, au lieu de 1 en cas de succès. Ceci doit être considéré comme un marqueur de fin de fichier (EOF).

NOTES

Toutes les fonctions décrites ici sont indépendantes des threads et un seul thread peut opérer sur un objet donné à un moment donné. Différents threads peuvent accéder au même objet à différents moments. Plusieurs objets indépendants peuvent être utilisés par différents threads en parallèle.

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

EXEMPLES

Itération à travers le journal :

/* SPDX-License-Identifier: MIT-0 */
#include <errno.h>
#include <stdio.h>
#include <systemd/sd-journal.h>
int main(int argc, char *argv[]) {
  int r;
  sd_journal *j;
  r = sd_journal_open(&j, SD_JOURNAL_LOCAL_ONLY);
  if (r < 0) {
    fprintf(stderr, "Impossible d'ouvrir le journal : %s\n", strerror(-r));
    return 1;
  }
  SD_JOURNAL_FOREACH(j) {
    const char *d;
    size_t l;
    r = sd_journal_get_data(j, "MESSAGE", (const void **)&d, &l);
    if (r < 0) {
      fprintf(stderr, "Erreur lors de la lecture du champ MESSAGE : %s\n", strerror(-r));
      continue;
    }
    printf("%.*s\n", (int) l, d);
  }
  sd_journal_close(j);
  return 0;
}

HISTORIQUE

sd_journal_next(), sd_journal_previous(), sd_journal_next_skip(), sd_journal_previous_skip(), SD_JOURNAL_FOREACH(), et SD_JOURNAL_FOREACH_BACKWARDS() ont été ajoutés dans la version 187.

sd_journal_step_one() a été ajouté dans la version 254.
