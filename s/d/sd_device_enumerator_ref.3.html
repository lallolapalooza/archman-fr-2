SD_DEVICE_ENUMERATOR_NEW(3) sd_device_enumerator_new SD_DEVICE_ENUMERATOR_NEW(3)

NOM

sd_device_enumerator_new, sd_device_enumerator_ref, sd_device_enumerator_unref, sd_device_enumerator_unrefp - Créer, référencer et libérer un objet énumérateur de périphériques

SYNTAXE

#include <systemd/sd-device.h>

int sd_device_enumerator_new(sd_device_enumerator **ret);

sd_device_enumerator* sd_device_enumerator_ref(sd_device_enumerator *enumerator);

sd_device_enumerator* sd_device_enumerator_unref(sd_device_enumerator *enumerator);

void sd_device_enumerator_unrefp(sd_device_enumerator **enumerator);

DESCRIPTION

La famille de fonctions sd_device_enumerator fournit un moyen d'itérer sur les périphériques reconnus par systemd-udevd(8). L'énumérateur permet de filtrer et de faire correspondre des périphériques par sous-système, propriétés et autres attributs.

sd_device_enumerator_new() crée un nouvel objet énumérateur de périphériques et stocke le résultat dans le pointeur référencé par ret. Retourne 0 en cas de succès, ou un code d'erreur négatif de type errno en cas d'échec.

sd_device_enumerator_ref() augmente le compteur de références de l'enumerator spécifié d'une unité.

sd_device_enumerator_unref() diminue le compteur de références de l'enumerator d'une unité. Lorsque le compteur de références atteint zéro, l'objet énumérateur est détruit et ne peut plus être utilisé, donc les appels ultérieurs à sd_device_enumerator_unref() ou sd_device_enumerator_unrefp() sont illégaux.

sd_device_enumerator_unrefp() est similaire à sd_device_enumerator_unref() mais prend un pointeur vers un pointeur vers un objet sd_device_enumerator. Cet appel est utile en conjonction avec l'attribut de variable de nettoyage (Clean-up Variable Attribute) de GCC et LLVM[1]. Notez que cette fonction est définie comme une fonction inline. Utilisez une déclaration comme la suivante, afin d'allouer un objet sd_device_enumerator qui sera libéré automatiquement à la sortie du bloc de code :

{
  __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
  int r;
  ...
  r = sd_device_enumerator_new(&enumerator);
  if (r < 0)
    fprintf(stderr, "Échec de l'allocation de sd_device_enumerator : %s\n", strerror(-r));
  ...
}

sd_device_enumerator_ref() et sd_device_enumerator_unref() n'exécutent aucune opération si l'enumerator est NULL. sd_device_enumerator_unrefp() déréférencera d'abord son argument, qui ne doit pas être NULL, et n'exécutera aucune opération si *celui-ci* est NULL.

VALEUR DE RETOUR

sd_device_enumerator_new() retourne 0 en cas de succès ou un code d'erreur négatif de type errno en cas d'échec.

sd_device_enumerator_ref() retourne toujours le pointeur de l'énumérateur.

sd_device_enumerator_unref() retourne toujours NULL.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ENOMEM

Échec de l'allocation mémoire.

-EINVAL

L'argument est invalide.

EXEMPLE

Exemple 1. Utilisation de sd_device_enumerator_new()

/* SPDX-License-Identifier: MIT-0 */
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    sd_device_enumerator *enumerator;
    int r;
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Échec de la création de l'énumérateur : %s\n", strerror(-r));
        return 1;
    }
    sd_device_enumerator_ref(enumerator);
    sd_device_enumerator_unref(enumerator);
    sd_device_enumerator_unref(enumerator);
    return 0;
}
