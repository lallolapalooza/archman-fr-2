NOM

sddm - le gestionnaire de bureau simple

SYNTAXE

sddm [OPTIONS...]

DESCRIPTION

sddm est un gestionnaire d'affichage et de connexion basé sur les technologies Qt.

En utilisant QtQuick et QML, les concepteurs ont la possibilité de créer facilement des interfaces agréables et modernes pour sddm.

sddm exécute le greeter en tant qu'utilisateur système nommé sddm dont le répertoire personnel doit être défini sur /var/lib/sddm.

Si pam et systemd sont disponibles, le greeter passera par logind, ce qui lui donnera accès aux périphériques drm.

Les distributions sans pam et systemd devront ajouter l'utilisateur sddm au groupe video, sinon des erreurs concernant les périphériques GL et drm pourraient être rencontrées.

Pour les sessions X11, le cookie d'autorisation X est écrit dans un fichier temporaire /tmp/xauth_XXXXXX, appartenant et accessible uniquement par l'utilisateur.

OPTIONS

--test-mode
Démarre le démon en mode test.
--example-config
Affiche la configuration actuelle complète sur la sortie standard.
--help, -h
Affiche le message d'aide et quitte.

FICHIERS

/usr/lib/sddm/sddm.conf.d
Répertoire de configuration système
/etc/sddm.conf.d
Répertoire de configuration locale
/etc/sddm.conf
Fichier de configuration locale pour la compatibilité
/usr/share/sddm/themes
Où sddm recherche les thèmes
