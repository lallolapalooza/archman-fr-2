sd_bus_message_is_method_error(3)

Paquet: systemd-libs

SD_BUS_MESSAGE_GET_TYPE(3) sd_bus_message_get_type SD_BUS_MESSAGE_GET_TYPE(3)

NOM

sd_bus_message_get_type, sd_bus_message_get_error, sd_bus_message_get_errno, sd_bus_message_get_creds, sd_bus_message_is_signal, sd_bus_message_is_method_call, sd_bus_message_is_method_error - Interroger les métadonnées d'adressage/d'identification du message bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_get_type(sd_bus_message *m, uint8_t *type);

sd_bus_error* sd_bus_message_get_error(sd_bus_message *m);

int sd_bus_message_get_errno(sd_bus_message *m);

sd_bus_creds* sd_bus_message_get_creds(sd_bus_message *m);

int sd_bus_message_is_signal(sd_bus_message *m, const char *interface, const char *member);

int sd_bus_message_is_method_call(sd_bus_message *m, const char *interface, const char *member);

int sd_bus_message_is_method_error(sd_bus_message *m, const char *name);

DESCRIPTION

sd_bus_message_get_type() renvoie le type d'un message dans le paramètre de sortie type, l'un des types SD_BUS_MESSAGE_METHOD_CALL, SD_BUS_MESSAGE_METHOD_RETURN, SD_BUS_MESSAGE_METHOD_ERROR, SD_BUS_MESSAGE_SIGNAL. Ce type est soit spécifié comme paramètre lors de la création du message avec sd_bus_message_new(3), soit défini automatiquement lors de la création du message avec sd_bus_message_new_signal(3), sd_bus_message_new_method_call(3), sd_bus_message_new_method_error(3) et fonctions similaires.

sd_bus_message_get_error() renvoie l'erreur stockée dans le message m, s'il y en a une. Sinon, elle renvoie NULL. sd_bus_message_get_errno() renvoie l'erreur stockée dans le message m sous forme d'une valeur positive de type errno, s'il y en a une. Sinon, elle renvoie zéro. Les erreurs sont mappées aux valeurs errno selon les mappages par défaut et tout mappage supplémentaire enregistré. Voir sd-bus-errors(3) et sd_bus_error_add_map(3).

sd_bus_message_get_creds() renvoie les informations d'identification du message attachées au message m. Si aucune information d'identification n'est attachée au message, elle renvoie NULL. La propriété de l'instance d'informations d'identification n'est pas transférée à l'appelant et ne doit donc pas être libérée.

sd_bus_message_is_signal() vérifie si le message m est un message de signal. Si interface n'est pas nul, elle vérifie également si le message a la même interface définie. Si member n'est pas nul, elle vérifie également si le message a le même membre défini. Voir aussi sd_bus_message_new_signal(3). Elle renvoie vrai lorsque toutes les vérifications réussissent.

sd_bus_message_is_method_call() vérifie si le message m est un message d'appel de méthode. Si interface n'est pas nul, elle vérifie également si le message a la même interface définie. Si member n'est pas nul, elle vérifie également si le message a le même membre défini. Voir aussi sd_bus_message_new_method_call(3). Elle renvoie vrai lorsque toutes les vérifications réussissent.

sd_bus_message_is_method_error() vérifie si le message m est un message de réponse d'erreur. Si name n'est pas nul, elle vérifie également si le message a le même identifiant d'erreur défini. Voir aussi sd_bus_message_new_method_error(3). Elle renvoie vrai lorsque toutes les vérifications réussissent.

VALEUR RENVOYÉE

En cas de succès, ces fonctions (sauf sd_bus_message_get_error() et sd_bus_message_get_creds()) renvoient un entier non négatif. En cas d'échec, elles renvoient un code d'erreur négatif de type errno. sd_bus_message_get_errno() renvoie toujours un entier non négatif, même en cas d'échec.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre de message m ou un paramètre de sortie est NULL.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'appeler setenv() que lors d'une phase précoce du programme lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_message_get_type(), sd_bus_message_is_signal(), sd_bus_message_is_method_call(), et sd_bus_message_is_method_error() ont été ajoutées dans la version 240.

sd_bus_message_get_error(), sd_bus_message_get_errno(), et sd_bus_message_get_creds() ont été ajoutées dans la version 246.
