NOM

state.conf - configuration du gestionnaire d'affichage sddm

SYNOPSIS

~sddm/state.conf

DESCRIPTION

Ce fichier contient la configuration de l'état du gestionnaire d'affichage sddm sddm(1).

OPTIONS

Toutes les options sont configurées dans la section [Last] :

Session=
Nom du fichier de session de la dernière session sélectionnée. Cette session sera pré-sélectionnée lorsque l'écran de connexion s'affichera. La valeur par défaut est vide.
Utilisateur=
Nom de l'utilisateur qui s'est connecté en dernier. Ce nom d'utilisateur sera pré-sélectionné/affiché lorsque l'écran de connexion s'affichera. La valeur par défaut est vide.
