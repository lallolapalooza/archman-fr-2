Documentation de la fonction/sous-routine

sous-routine sdisna (character job, integer m, integer n, real, dimension( * ) d, real, dimension( * ) sep, integer info)

SDISNA

Objectif :

!>
!> SDISNA calcule les nombres de condition réciproques pour les vecteurs propres
!> d'une matrice réelle symétrique ou hermitienne complexe ou pour les vecteurs singuliers gauches ou
!> droits d'une matrice m x n générale. Le nombre de condition réciproque est "l'écart"
!> entre la valeur propre ou la valeur singulière correspondante et la plus proche autre.
!>
!> La borne de l'erreur, mesurée par l'angle en radians, dans le I-ème
!> vecteur calculé est donnée par
!>
!>        SLAMCH( 'E' ) * ( ANORM / SEP( I ) )
!>
!> où ANORM = norme 2(A) = max( abs( D(j) ) ). SEP(I) n'est pas autorisé
!> à être inférieur à SLAMCH( 'E' )*ANORM afin de limiter la taille de
!> la borne d'erreur.
!>
!> SDISNA peut également être utilisé pour calculer des bornes d'erreur pour les vecteurs propres de
!> le problème propre symétrique défini généralisé.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie pour quel problème les nombres de condition réciproques
!>          doivent être calculés :
!>          = 'E' : les vecteurs propres d'une matrice symétrique/hermitienne ;
!>          = 'L' : les vecteurs singuliers gauches d'une matrice générale ;
!>          = 'R' : les vecteurs singuliers droits d'une matrice générale.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice. M >= 0.
!>

N

!>          N est INTEGER
!>          Si JOB = 'L' ou 'R', le nombre de colonnes de la matrice,
!>          auquel cas N >= 0. Ignoré si JOB = 'E'.
!>

D

!>          D est un tableau REEL, de dimension (M) si JOB = 'E'
!>                               dimension (min(M,N)) si JOB = 'L' ou 'R'
!>          Les valeurs propres (si JOB = 'E') ou les valeurs singulières (si JOB =
!>          'L' ou 'R') de la matrice, dans l'ordre croissant ou décroissant.
!>          S'il s'agit de valeurs singulières, elles doivent être non négatives.
!>

SEP

!>          SEP est un tableau REEL, de dimension (M) si JOB = 'E'
!>                               dimension (min(M,N)) si JOB = 'L' ou 'R'
!>          Les nombres de condition réciproques des vecteurs.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
