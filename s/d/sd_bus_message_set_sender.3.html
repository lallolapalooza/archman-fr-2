sd_bus_message_set_sender(3)

Paquet: systemd-libs

Licences: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_SET_DESTINATION(3) sd_bus_message_set_destination SD_BUS_MESSAGE_SET_DESTINATION(3)

NOM

sd_bus_message_set_destination, sd_bus_message_get_destination, sd_bus_message_get_path, sd_bus_message_get_interface, sd_bus_message_get_member, sd_bus_message_set_sender, sd_bus_message_get_sender - Définir et interroger les informations d'adressage des messages du bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_message_set_destination(sd_bus_message *message, const char *destination);

const char* sd_bus_message_get_destination(sd_bus_message *message);

const char* sd_bus_message_get_path(sd_bus_message *message);

const char* sd_bus_message_get_interface(sd_bus_message *message);

const char* sd_bus_message_get_member(sd_bus_message *message);

int sd_bus_message_set_sender(sd_bus_message *message, const char *sender);

const char* sd_bus_message_get_sender(sd_bus_message *message);

DESCRIPTION

sd_bus_message_set_destination() définit le nom du service de destination pour l'objet de message de bus spécifié. Le nom spécifié doit être un nom de service unique ou bien connu valide.

sd_bus_message_get_destination(), sd_bus_message_get_path(), sd_bus_message_get_interface() et sd_bus_message_get_member() renvoient les champs de destination, chemin, interface et membre de l'en-tête de message. La valeur de retour sera NULL si message est NULL ou si le message est d'un type qui n'utilise pas ces champs ou si le message ne les a pas définis. Voir sd_bus_message_new_method_call(3) et sd_bus_message_set_destination(3) pour plus de détails sur ces valeurs.

sd_bus_message_set_sender() définit le nom du service d'expéditeur pour l'objet de message de bus spécifié. Le nom spécifié doit être un nom de service unique ou bien connu valide. Cette fonction n'est utile que pour les messages à envoyer sur des connexions directes, car pour les connexions aux courtiers de bus, le courtier remplira de toute façon le champ de destination, et le champ d'expéditeur défini par l'expéditeur d'origine est ignoré.

sd_bus_message_get_sender() renvoie le champ d'expéditeur de message.

Lorsqu'une chaîne de caractères est renvoyée, il s'agit d'un pointeur vers un stockage interne, et elle ne peut pas être modifiée ou libérée. Elle n'est valide que tant que message reste référencé et que ce champ n'a pas été modifié par un appel différent.

VALEUR DE RETOUR

En cas de succès, ces appels renvoient 0 ou un entier positif. En cas d'échec, ces appels renvoient un code d'erreur négatif de style errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre message ou le paramètre de sortie est NULL.

-EPERM

Pour sd_bus_message_set_destination() et sd_bus_message_set_sender(), le message est déjà scellé.

-EEXIST

Le message a déjà un champ de destination ou d'expéditeur défini.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que lors d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_message_set_destination() et sd_bus_message_set_sender() ont été ajoutées dans la version 237.

sd_bus_message_get_destination(), sd_bus_message_get_path(), sd_bus_message_get_interface(), sd_bus_message_get_member() et sd_bus_message_get_sender() ont été ajoutées dans la version 240.
