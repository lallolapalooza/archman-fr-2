NOM

sddm.conf - configuration du gestionnaire d'affichage sddm

SYNTAXE

La configuration charge tous les fichiers des répertoires de configuration suivis du fichier de configuration, dans l'ordre indiqué ci-dessous, le dernier ayant la priorité la plus élevée. Les modifications doivent être apportées aux configurations locales.

/usr/lib/sddm/sddm.conf.d
Répertoire de configuration système
/etc/sddm.conf.d
Répertoire de configuration locale
/etc/sddm.conf
Fichier de configuration locale pour la compatibilité

DESCRIPTION

Ce fichier configure divers paramètres du gestionnaire d'affichage sddm sddm(1). Si ce fichier n'est pas disponible, les valeurs par défaut sont utilisées.

OPTIONS

Section [General] :

DisplayServer=
Sélectionne le serveur d'affichage à utiliser pour l'écran de connexion. Les valeurs valides sont :
  • x11 : Serveur X s'exécutant en tant que root.
  • x11-user : Serveur X s'exécutant en tant qu'utilisateur non privilégié.
  • wayland : Compositeur Wayland en tant qu'utilisateur non privilégié. (Expérimental)

La valeur par défaut est « x11 ». Pour x11-user, vous pourriez avoir besoin de configurer Xorg.wrap(1).

HaltCommand=
Commande d'arrêt. La valeur par défaut est « /usr/bin/systemctl poweroff ».
RebootCommand=
Commande de redémarrage. La valeur par défaut est « /usr/bin/systemctl reboot ».
Numlock=
Change l'état du verrouillage numérique au démarrage de sddm-greeter. Les valeurs valides sont on, off ou none. Si la propriété est définie sur none, le verrouillage numérique ne sera pas modifié. La valeur par défaut est « none ».
InputMethod=
Définit la méthode de saisie Qt pour l'écran de connexion. Les utilisateurs de tablettes avec le clavier virtuel Qt installé peuvent définir ceci sur « qtvirtualkeyboard » pour le clavier à l'écran. D'autres valeurs connues sont « ibus » pour le bus de saisie intelligent, ou « compose » pour le support des touches mortes. Laissez vide si vous n'êtes pas sûr.
Namespaces=
Liste séparée par des virgules des chemins liés aux espaces de noms Linux à rejoindre avec setns() avant de démarrer la session utilisateur. Par exemple, pour rejoindre l'espace de noms réseau mynet créé avec ip netns add mynet, la valeur pourrait être /run/netns/mynet. La valeur par défaut est vide. (La valeur est ignorée si le système d'exploitation n'est pas Linux.)

Section [Theme] :

ThemeDir=
Chemin du répertoire contenant les fichiers de thème. La valeur par défaut est « /usr/share/sddm/themes ».
Current=
Nom du thème actuel. Par défaut, ce réglage est vide, ce qui signifie que le thème intégré sera utilisé.
FacesDir=
Chemin du répertoire contenant les fichiers de visages, les fichiers de visages doivent être au format username.face.icon. La valeur par défaut est « /usr/share/sddm/faces ».
CursorTheme=
Nom du thème du curseur à définir avant de démarrer le serveur d'affichage.
CursorSize=
Taille du curseur à définir avant de démarrer le serveur d'affichage.
Font=
Nom de la police à définir avant de démarrer le serveur d'affichage. Veuillez noter que le thème peut toujours outrepasser cette option.
EnableAvatars=
Lorsqu'il est activé, les répertoires personnels sont recherchés pour des images « .face.icon » à afficher comme avatars. Cela peut être lent sur certains systèmes de fichiers. Lorsqu'il est désactivé, tous les avatars seront par défaut. Les thèmes peuvent choisir de les masquer totalement. La valeur par défaut est true.

Section [X11] :

ServerPath=
Chemin du serveur X. La valeur par défaut est « /usr/bin/X ».
ServerArguments=
Arguments pour le serveur X. La valeur par défaut est « -nolisten tcp ».
XephyrPath=
Chemin de Xephyr. La valeur par défaut est « /usr/bin/Xephyr ».
SessionDir=
Liste séparée par des virgules des répertoires contenant les fichiers de session. La valeur par défaut est « /usr/local/share/xsessions,/usr/share/xsessions ».
SessionCommand=
Chemin du script à exécuter lors du démarrage de la session utilisateur. Ce script reçoit la valeur du paramètre « Exec » dans le fichier « .desktop » de la session sélectionnée et l'exécute. La valeur par défaut est « /usr/share/sddm/scripts/Xsession ».
SessionLogFile=
Chemin du fichier journal de la session utilisateur, relatif au répertoire personnel. La valeur par défaut est « .local/share/sddm/xorg-session.log ».
DisplayCommand=
Chemin du script à exécuter lors du démarrage du serveur d'affichage. Le script sera exécuté en tant que root lorsque General.DisplayServer est « x11 », sinon en tant qu'utilisateur sddm. La valeur par défaut est « /usr/share/sddm/scripts/Xsetup ».
DisplayStopCommand=
Chemin du script à exécuter lors de l'arrêt du serveur d'affichage. Le script sera exécuté en tant que root lorsque General.DisplayServer est « x11 », sinon en tant qu'utilisateur sddm. La valeur par défaut est « /usr/share/sddm/scripts/Xstop ».
MinimumVT=
Numéro du terminal virtuel minimum qui sera utilisé par le premier affichage. Le numéro du terminal virtuel augmentera à mesure que de nouveaux affichages seront ajoutés. Ce réglage n'est plus disponible depuis SDDM v0.20.
EnableHiDPI=
Active la mise à l'échelle HiDPI automatique de Qt. Peut être soit « true » soit « false ». La valeur par défaut est « true ».

L'option XauthPath= n'est plus nécessaire, libxau est utilisé à la place.

L'option UserAuthFile= a été supprimée, le fichier est toujours créé comme /tmp/xauth_XXXXX. Ceci est nécessaire pour l'utilisation des entrées FamilyWild.

Section [Wayland] :

CompositorCommand=
Chemin du compositeur à exécuter lors du démarrage de l'écran de connexion. La valeur par défaut est « weston --shell=kiosk ».
SessionDir=
Liste séparée par des virgules des répertoires contenant les fichiers de session. La valeur par défaut est « /usr/local/share/wayland-sessions,/usr/share/wayland-sessions ».
SessionCommand=

SessionLogFile=
Chemin du fichier journal de la session utilisateur, relatif au répertoire personnel. La valeur par défaut est « .local/share/sddm/wayland-session.log ».

[Users] section :

DefaultPath=
Chemin par défaut à définir après une connexion réussie. C'est aussi là que SDDM recherche les programmes. La valeur par défaut est "/usr/local/bin:/usr/bin:/bin".
MinimumUid=
Identifiant d'utilisateur minimum des utilisateurs à afficher dans l'interface utilisateur. La valeur par défaut est 1000.
MaximumUid=
Identifiant d'utilisateur maximum des utilisateurs à afficher dans l'interface utilisateur. La valeur par défaut est 60513.
HideUsers=
Liste des utilisateurs séparés par des virgules qui ne doivent pas apparaître dans la liste des utilisateurs. La valeur par défaut est vide.
HideShells=
Liste des shells d'utilisateurs séparés par des virgules qui ne doivent pas apparaître dans la liste des utilisateurs. La valeur par défaut est vide.
RememberLastUser=
Si ce drapeau est vrai, la valeur de LastUser sera mise à jour à chaque connexion réussie, sinon la valeur de last user ne sera pas mise à jour. La valeur par défaut est true.
RememberLastSession=
Si ce drapeau est vrai, la valeur de LastSession sera mise à jour à chaque connexion réussie, sinon la valeur de last session ne sera pas mise à jour. La valeur par défaut est true.

[Autologin] section :

User=
Nom de l'utilisateur à connecter automatiquement lorsque le système démarre pour la première fois. La valeur par défaut est vide.
Session=
Nom de la session à connecter automatiquement lorsque le système démarre pour la première fois. La valeur par défaut est vide.
Relogin=
Si vrai et que User et Session sont définis, la connexion automatique se réactivera à la sortie de la session, sinon elle ne fonctionnera que la première fois. La valeur par défaut est false.
