NOM

sdl-freerdp3 - Client FreeRDP SDL

SYNTAXE

sdl-freerdp3 [fichier] [options] [/v:serveur[:port]]

DESCRIPTION

sdl-freerdp3 est un client SDL (Remote Desktop Protocol) qui fait partie du projet FreeRDP. Un serveur RDP est intégré dans de nombreuses éditions de Windows. Des serveurs alternatifs incluent ogon, gnome-remote-desktop, xrdp et VRDP (VirtualBox).

FICHIER DE CONFIGURATION

Format et emplacement :

Le fichier de configuration est stocké par utilisateur.

La variable d'environnement XDG_CONFIG_HOME peut être utilisée pour remplacer le répertoire de base.

Cela correspond par défaut à ~/.config. L'emplacement par rapport à XDG_CONFIG_HOME est $XDG_CONFIG_HOME/freerdp/sdl-freerdp.json

La configuration est stockée au format JSON

Options prises en charge :

SDL_KeyModMask

Définit la combinaison de touches requise pour les raccourcis du client SDL.

Par défaut KMOD_RSHIFT

Un tableau de chaînes SDL_Keymod telles que définies sur https://wiki.libsdl.org/SDL3/SDL_Keymod
utilisez KEYMOD_NONE pour désactiver les raccourcis clavier

SDL_Fullscreen

Active/désactive l'état plein écran du client.

Par défaut SDL_SCANCODE_RETURN.

Une chaîne telle que définie sur https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Minimize

Minimise la fenêtre du client.

Par défaut SDL_SCANCODE_M.

Une chaîne telle que définie sur https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Resizeable

Active/désactive l'état redimensionnable de la fenêtre locale.

Par défaut SDL_SCANCODE_R.

Une chaîne telle que définie sur https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Grab

Active/désactive l'état de capture du clavier et de la souris.
Si le clavier est capturé, les raccourcis du système local ne fonctionnent plus et sont envoyés au système distant.
Si la souris est capturée (facultatif), la détection de gestes locale ne fonctionne pas et la souris pourrait ne pas pouvoir quitter la fenêtre RDP. Les événements de souris ne sont pas modifiés.

Par défaut SDL_SCANCODE_G.

Une chaîne telle que définie sur https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Disconnect

Déconnecte de la session RDP.

Par défaut SDL_SCANCODE_D.

Une chaîne telle que définie sur https://wiki.libsdl.org/SDL3/SDL_Scancode

CONFIGURATION GLOBALE (client commun)

Format et emplacement :

Les fichiers de configuration sont stockés dans la configuration système globale.

L'emplacement commun des paramètres de certificat est /etc/FreeRDP/certificates.json

Le format de fichier est JSON

Options prises en charge :

deny

Booléen JSON

Refuse le certificat si la vérification par rapport au magasin SSL du système n'a pas abouti

ignore

Booléen JSON

Ignore les échecs de certificat, ignore simplement le certificat

deny-userconfig

Booléen JSON

Si les vérifications dans la configuration globale n'acceptent pas le certificat, ne pas demander à l'utilisateur

certificate-db

Tableau JSON

Un tableau d'objets JSON avec :

type

Chaîne JSON

une chaîne identifiant l'algorithme de hachage utilisé, par exemple sha256

hash

Chaîne JSON

une chaîne de valeurs d'entiers hexadécimaux représentant le hachage du certificat, par exemple 0123456789abcdef

CONFIGURATION GLOBALE (client SDL3)

L'emplacement de configuration du client SDL3 est /etc/FreeRDP/sdl-freerdp.json

Le format de fichier est JSON

Options prises en charge :

isUserConfigEnabled

Booléen JSON

Autorise ou bloque la prise en charge du fichier de configuration par utilisateur.

Toutes les options de niveau utilisateur de FICHIER DE CONFIGURATION peuvent également être définies ici.

EXEMPLES

sdl-freerdp3 connection.rdp /p:Pwd123! /f

Se connecte en mode plein écran en utilisant une configuration stockée connection.rdp et le mot de passe Pwd123!

sdl-freerdp3 /u:USER /size:50%h /v:rdp.contoso.com

Se connecte à l'hôte rdp.contoso.com avec l'utilisateur USER et une taille de 50 % de la hauteur. Si la largeur (w) est définie au lieu de la hauteur (h) comme /size:50%w. 50 % de la largeur est utilisé.

sdl-freerdp3 /u:CONTOSO\\JohnDoe /p:Pwd123! /v:rdp.contoso.com

Se connecte à l'hôte rdp.contoso.com avec l'utilisateur CONTOSO\\JohnDoe et le mot de passe Pwd123!

sdl-freerdp3 /u:JohnDoe /p:Pwd123! /w:1366 /h:768 /v:192.168.1.100:4489

Se connecte à l'hôte 192.168.1.100 sur le port 4489 avec l'utilisateur JohnDoe, le mot de passe Pwd123!. La largeur de l'écran est définie sur 1366 et la hauteur sur 768

sdl-freerdp3 /u:JohnDoe /p:Pwd123! /vmconnect:C824F53E-95D2-46C6-9A18-23A5BB403532 /v:192.168.1.100

Établit une connexion à l'hôte 192.168.1.100 avec l'utilisateur JohnDoe, le mot de passe Pwd123! et se connecte à la console Hyper-V (utilise le port 2179, désactive la négociation) avec l'ID VM C824F53E-95D2-46C6-9A18-23A5BB403532
