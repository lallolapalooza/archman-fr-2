SDRVRF3

Objectif :

!>
!> SDRVRF3 teste les routines RFP de LAPACK :
!>     STFSM
!>

Paramètres

NOUT 
!>          NOUT est un entier
!>                Le numéro de l'unité pour la sortie.
!>

NN

!>          NN est un entier
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, de dimension (NN)
!>                Les valeurs de la dimension de matrice N.
!>

THRESH

!>          THRESH est un réel
!>                La valeur seuil pour les rapports de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>                chaque rapport de test soit imprimé, utiliser THRESH = 0.
!>

A

!>          A est un tableau de réels, de dimension (LDA,NMAX)
!>

LDA

!>          LDA est un entier
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

ARF

!>          ARF est un tableau de réels, de dimension ((NMAX*(NMAX+1))/2).
!>

B1

!>          B1 est un tableau de réels, de dimension (LDA,NMAX)
!>

B2

!>          B2 est un tableau de réels, de dimension (LDA,NMAX)
!>

S_WORK_SLANGE

!>          S_WORK_SLANGE est un tableau de réels, de dimension (NMAX)
!>

S_WORK_SGEQRF

!>          S_WORK_SGEQRF est un tableau de réels, de dimension (NMAX)
!>

TAU

!>          TAU est un tableau de réels, de dimension (NMAX)
!>
