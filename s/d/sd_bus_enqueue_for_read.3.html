NOM

sd_bus_enqueue_for_read - Ré-enfiler un message de bus sur une connexion de bus, pour lecture

SYNOPIS

#include <systemd/sd-bus.h>

int sd_bus_enqueue_for_read(sd_bus *bus, sd_bus_message *message);

DESCRIPTION

sd_bus_enqueue_for_read() peut être utilisé pour ré-enfiler un message de bus entrant dans la file de lecture locale, afin qu'il soit traité et émis localement à nouveau, de manière similaire au traitement d'un message entrant du pair. Prend un objet de connexion de bus et le message à enfiler. Une référence du message est prise et la référence de l'appelant reste donc en possession de l'appelant. Le message est enfilé à la fin de la file, il sera donc émis après tous les autres messages déjà enfilés.

Cet appel est principalement utile pour traiter les appels de méthode entrants qui ne peuvent être traités qu'après la fin d'une opération asynchrone supplémentaire. Un exemple est les requêtes d'autorisation PolicyKit qui s'avèrent nécessaires pour autoriser un nouvel appel de méthode entrant : lorsque la réponse PolicyKit est reçue, l'appel de méthode d'origine peut être ré-enfilé pour le traiter à nouveau, cette fois avec le résultat d'autorisation connu.

VALEUR DE RETOUR

En cas de succès, cette fonction retourne 0 ou un entier positif. En cas d'échec, elle retourne un code d'erreur négatif de style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion de bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à partir d'une phase précoce du programme où aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_enqueue_for_read() a été ajouté dans la version 245.
