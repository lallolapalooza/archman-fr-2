sd_hwdb_new_from_path(3)

Paquet: systemd-libs

Licences: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_HWDB_NEW(3) sd_hwdb_new SD_HWDB_NEW(3)

NOM

sd_hwdb_new, sd_hwdb_new_from_path, sd_hwdb_ref, sd_hwdb_unref - Créer un nouvel objet hwdb et créer ou détruire des références à celui-ci

SYNTAXE

#include <systemd/sd-hwdb.h>

int sd_hwdb_new(sd_hwdb **hwdb);

int sd_hwdb_new_from_path(const char *path, sd_hwdb **hwdb);

sd_hwdb* sd_hwdb_ref(sd_hwdb *hwdb);

sd_hwdb* sd_hwdb_unref(sd_hwdb *hwdb);

DESCRIPTION

sd_hwdb_new() crée un nouvel objet hwdb pour accéder à la base de données hwdb binaire. Lors de l'initialisation, le fichier contenant la représentation binaire de la base de données matérielle est localisé et ouvert. Le nouvel objet est retourné dans hwdb.

sd_hwdb_new_from_path() peut être utilisé pour spécifier le chemin à partir duquel la base de données matérielle binaire doit être ouverte.

L'objet hwdb est compté par références. sd_hwdb_ref() et sd_hwdb_unref() peuvent être utilisés pour obtenir une nouvelle référence ou détruire une référence existante à un objet. L'appelant doit se débarrasser de la référence acquise avec sd_hwdb_new() en appelant sd_hwdb_unref() lorsqu'il n'a plus besoin de l'objet.

Utilisez sd_hwdb_seek(3), sd_hwdb_get(3), et sd_hwdb_enumerate(3) pour accéder aux entrées.

VALEUR DE RETOUR

En cas de succès, sd_hwdb_new() et sd_hwdb_new_from_path() retournent un entier positif ou nul. En cas d'échec, un code d'erreur négatif de style errno est retourné.

sd_hwdb_ref() retourne toujours l'argument.

sd_hwdb_unref() retourne toujours NULL.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ENOENT

Le fichier binaire de la base de données matérielle n'a pas pu être localisé. Voir systemd-hwdb(8) pour plus d'informations.

Ajouté dans la version 246.

-EINVAL

Le fichier binaire de la base de données matérielle localisé est dans un format incompatible.

Ajouté dans la version 246.

-ENOMEM

Échec de l'allocation mémoire.

Ajouté dans la version 246.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour l'utilisation multi-thread. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() que dès le début du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_hwdb_new(), sd_hwdb_ref(), et sd_hwdb_unref() ont été ajoutés dans la version 246.

sd_hwdb_new_from_path() a été ajouté dans la version 252.
