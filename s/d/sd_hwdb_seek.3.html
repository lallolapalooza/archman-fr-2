sd_hwdb_seek(3)

Paquet: systemd-libs

Licences: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_HWDB_GET(3) sd_hwdb_get SD_HWDB_GET(3)

NOM

sd_hwdb_get, sd_hwdb_seek, sd_hwdb_enumerate, SD_HWDB_FOREACH_PROPERTY - Se positionner dans la hwdb ou accéder aux entrées

SYNTAXE

#include <systemd/sd-hwdb.h>

int sd_hwdb_get(sd_hwdb *hwdb, const char *modalias, const char *key, const char **value);

int sd_hwdb_seek(sd_hwdb *hwdb, const char *modalias);

int sd_hwdb_enumerate(sd_hwdb *hwdb, const char **key, const char **value);

SD_HWDB_FOREACH_PROPERTY(hwdb, modalias, key, value);

DESCRIPTION

sd_hwdb_get() interroge l'objet hwdb créé précédemment avec sd_hwdb_new(3) pour les entrées correspondant à la chaîne spécifiée modalias, et renvoie la valeur correspondant à la clé key. La valeur est renvoyée sous forme de chaîne terminée par un NUL dans value. Elle ne doit pas être modifiée par l'appelant et est valide tant qu'une référence à hwdb est conservée. Lorsque plusieurs motifs dans la base de données correspondent à modalias, celui ayant la priorité la plus élevée est utilisé. Voir hwdb(7) pour plus de détails.

sd_hwdb_seek() sélectionne les entrées correspondant à la chaîne spécifiée modalias. Les requêtes ultérieures avec sd_hwdb_enumerate() accéderont aux paires clé-valeur pour cette chaîne.

sd_hwdb_enumerate() renvoie (tour à tour) toutes les paires clé-valeur définies pour la chaîne utilisée avec sd_hwdb_seek(). Chaque paire est renvoyée sous forme de chaînes terminées par NUL dans key et value. Les chaînes ne doivent pas être modifiées par l'appelant et sont valides tant qu'une référence à hwdb est conservée. Lorsque plusieurs motifs dans la base de données correspondent à modalias, la combinaison de toutes les paires clé-valeur correspondantes est utilisée. Voir hwdb(7) pour plus de détails.

La macro SD_HWDB_FOREACH_PROPERTY() combine sd_hwdb_seek() et sd_hwdb_enumerate(). Aucune gestion d'erreur n'est effectuée et l'itération s'arrête simplement en cas d'erreur. Voir l'exemple ci-dessous.

VALEUR DE RETOUR

En cas de succès, sd_hwdb_get() et sd_hwdb_seek() renvoient un entier positif. En cas d'échec, elles renvoient un code d'erreur négatif de style errno.

sd_hwdb_enumerate() renvoie un entier positif si une autre paire clé-valeur a été trouvée ou zéro si toutes les entrées ont déjà été énumérées. En cas d'échec, elle renvoie un code d'erreur négatif de style errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Un paramètre est NULL.

Ajouté dans la version 246.

-ENOENT

Une entrée pour le modalias spécifié n'a pas été trouvée.

Ajouté dans la version 246.

-EAGAIN

sd_hwdb_seek() n'a pas été appelée avant sd_hwdb_enumerate().

Ajouté dans la version 246.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() que dès le début d'un programme, lorsqu'aucun autre thread n'a été démarré.

EXEMPLES

Exemple 1. Rechercher des entrées hwdb pour un périphérique USB

/* SPDX-License-Identifier: MIT-0 */
#define _GNU_SOURCE 1
#include <stdio.h>
#include <stdint.h>
#include <systemd/sd-hwdb.h>
int print_usb_properties(uint16_t vid, uint16_t pid) {
  char match[128];
  sd_hwdb *hwdb;
  const char *key, *value;
  int r;
  /* Correspondent à cette combinaison d'identifiant de vendeur et de produit USB */
  snprintf(match, sizeof match, "usb:v%04Xp%04X", vid, pid);
  r = sd_hwdb_new(&hwdb);
  if (r < 0)
    return r;
  SD_HWDB_FOREACH_PROPERTY(hwdb, match, key, value)
    printf("%s: \"%s\" → \"%s\"\n", match, key, value);
  sd_hwdb_unref(hwdb);
  return 0;
}
int main(int argc, char **argv) {
  print_usb_properties(0x046D, 0xC534);
  return 0;
}

L'effet est similaire à l'appel de systemd-hwdb query usb:v046DpC534.

HISTORIQUE

sd_hwdb_get(), sd_hwdb_seek(), sd_hwdb_enumerate(), et SD_HWDB_FOREACH_PROPERTY() ont été ajoutés dans la version 246.
