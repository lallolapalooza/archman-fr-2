NOM

sd_bus_is_open, sd_bus_is_ready - Vérifier si la connexion au bus est ouverte ou prête

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_is_open(sd_bus *bus);

int sd_bus_is_ready(sd_bus *bus);

DESCRIPTION

sd_bus_is_open() vérifie si la connexion au bus spécifiée est ouverte, c'est-à-dire en cours d'établissement, déjà établie ou en cours de démantèlement. Elle retourne zéro lorsque la connexion n'a pas encore été démarrée (c'est-à-dire que sd_bus_start(3) ou un appel équivalent n'a pas encore été invoqué), ou est complètement terminée à nouveau (par exemple après sd_bus_close(3)), elle retourne une valeur positive sinon.

sd_bus_is_ready() vérifie si la connexion spécifiée est entièrement établie, c'est-à-dire que les phases de connexion et d'authentification du protocole sont terminées et que la réponse à l'appel de méthode Hello() a été reçue, et qu'elle n'est pas en cours de démantèlement. Elle retourne zéro en dehors de cet état, et une valeur positive sinon. Effectivement, cette fonction retourne une valeur positive tant que des messages réguliers peuvent être envoyés ou reçus sur la connexion.

L'argument bus peut être NULL, zéro est également retourné dans ce cas.

Pour être notifié lorsque la connexion est entièrement établie, utilisez sd_bus_set_connected_signal(3) et installez une correspondance pour le signal Connected() sur l'interface « org.freedesktop.DBus.Local ». Pour être notifié lorsque la connexion est démantelée à nouveau, installez une correspondance pour le signal Disconnected() sur l'interface « org.freedesktop.DBus.Local ».

VALEUR DE RETOUR

Ces fonctions retournent 0 si le bus n'est pas dans l'état donné, et un entier positif lorsqu'il l'est. En cas d'échec, un code d'erreur négatif de style errno est retourné.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion au bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à partir d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_is_open() a été ajoutée dans la version 221.

sd_bus_is_ready() a été ajoutée dans la version 237.
