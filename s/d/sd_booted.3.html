NOM

sd_booted - Tester si le système utilise le système d'initialisation systemd

SYNTAXE

#include <systemd/sd-daemon.h>

int sd_booted(void);

DESCRIPTION

sd_booted() vérifie si le système a été démarré avec le système d'initialisation systemd.

VALEUR DE RETOUR

En cas d'échec, cet appel retourne un code d'erreur négatif de type errno. Si le système a été démarré avec systemd comme système d'initialisation, cet appel retourne une valeur de retour positive, sinon zéro.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

En interne, cette fonction vérifie si le répertoire /run/systemd/system/ existe. Une vérification simple comme celle-ci peut également être implémentée trivialement en shell ou dans tout autre langage.
