NOM

sd_bus_list_names - Récupérer des informations sur les noms enregistrés sur un bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_list_names(sd_bus *bus, char ***acquired, char ***activatable);

DESCRIPTION

sd_bus_list_names() récupère des informations sur les noms enregistrés sur un bus. Si acquired n'est pas NULL, cette fonction appelle org.freedesktop.DBus.ListNames[1] pour récupérer la liste des noms actuellement possédés sur le bus. Si activatable n'est pas NULL, la fonction appelle org.freedesktop.DBus.ListActivableNames[2] pour récupérer la liste de tous les noms sur le bus qui peuvent être activés. Notez que la propriété des tableaux retournés par sd_bus_list_names() dans acquired et activatable est transférée à l'appelant et donc, l'appelant est responsable de libérer ces tableaux et leur contenu.

VALEUR DE RETOUR

En cas de succès, sd_bus_list_names() retourne un entier non négatif. En cas d'échec, elle retourne un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

bus ou les deux acquired et activatable étaient NULL.

-ENOPKG

Le bus ne peut pas être résolu.

-ECHILD

Le bus a été créé dans un processus, une bibliothèque ou une instance de module différent.

-ENOMEM

Échec de l'allocation de mémoire.

-ENOTCONN

Le bus n'est pas connecté.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() qu'à partir d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_list_names() a été ajoutée dans la version 221.
