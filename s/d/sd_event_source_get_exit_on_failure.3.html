SD_EVENT_SOURCE_SET_EXIT_ON_FAILURE(3) sd_event_source_set_exit_on_failure SD_EVENT_SOURCE_SET_EXIT_ON_FAILURE(3)

NOM

sd_event_source_set_exit_on_failure, sd_event_source_get_exit_on_failure - Définir ou récupérer la fonctionnalité de sortie en cas d'échec des sources d'événements

SYNOPIS

#include <systemd/sd-event.h>

int sd_event_source_set_exit_on_failure(sd_event_source *source, int b);

int sd_event_source_get_exit_on_failure(sd_event_source *source);

DESCRIPTION

sd_event_source_set_exit_on_failure() peut être utilisé pour définir/désactiver le drapeau de sortie en cas d'échec de l'objet source d'événements spécifié par source. Le drapeau est désactivé par défaut. S'il est activé et que la fonction de rappel définie pour la source d'événements renvoie un code d'échec (c'est-à-dire une valeur négative), la boucle d'événements est également quittée, en utilisant le code de retour du rappel comme code de sortie pour sd_event_exit(3). S'il est désactivé, la source d'événements est désactivée mais la boucle d'événements continue de s'exécuter. L'activation de ce drapeau est utile pour les sources d'événements « dominantes » qui définissent le but et la raison de la boucle d'événements, et dont l'échec devrait donc se propager à la boucle d'événements elle-même — par opposition aux sources d'événements « auxiliaires » dont les échecs devraient rester locaux et affecter la source d'événements, mais ne pas se propager davantage.

sd_event_source_get_exit_on_failure() peut être utilisé pour interroger le drapeau actuellement défini pour l'objet source d'événements source.

VALEUR DE RETOUR

En cas de succès, sd_event_source_set_exit_on_failure() renvoie un entier non négatif. sd_event_source_get_exit_on_failure() renvoie 0 si le drapeau est désactivé, > 0 s'il est activé. En cas d'échec, les deux renvoient un code d'erreur négatif de style errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

source n'est pas un pointeur valide vers un objet sd_event_source.

Ajouté dans la version 247.

-EDOM

La source d'événements fait référence à une source de sortie d'événement (créée avec sd_event_add_exit(3)), pour laquelle cette fonctionnalité n'est pas prise en charge.

Ajouté dans la version 247.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour le multi-threading. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un fil d'exécution parallèle. Il est recommandé de n'effectuer des appels à setenv() que dès la phase précoce du programme, lorsque aucun autre fil d'exécution n'a été démarré.

HISTORIQUE

sd_event_source_set_exit_on_failure() et sd_event_source_get_exit_on_failure() ont été ajoutés dans la version 247.
