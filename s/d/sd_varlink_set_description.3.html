SD_VARLINK_SET_DESCRIPTION(3) sd_varlink_set_description SD_VARLINK_SET_DESCRIPTION(3)

NOM

sd_varlink_set_description, sd_varlink_get_description - Définir ou interroger la description d'un objet de connexion Varlink

SYNTAXE

#include <systemd/sd-varlink.h>

int sd_varlink_set_description(sd_varlink *link, const char *description);

const char* sd_varlink_get_description(sd_varlink *link);

DESCRIPTION

sd_varlink_set_description() définit la chaîne de description utilisée dans les journaux à la chaîne spécifiée. La chaîne est copiée en interne et libérée lorsque l'objet de connexion Varlink est désalloué. L'argument description peut être NULL, auquel cas la description est supprimée.

sd_varlink_get_description() renvoie une chaîne de description pour la connexion Varlink spécifiée. Cette chaîne peut avoir été précédemment définie avec sd_varlink_set_description(). Si elle n'a pas été définie de cette manière, une chaîne par défaut ou NULL peut être renvoyée, selon la manière dont la connexion a été allouée et configurée.

VALEUR DE RETOUR

En cas de succès, sd_varlink_set_description() renvoie un entier non négatif. En cas d'échec, il renvoie un code d'erreur négatif de style errno. sd_varlink_get_description() renvoie soit NULL, soit un pointeur vers la chaîne de description.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Un argument est invalide.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'appeler setenv() qu'à une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_varlink_set_description() a été ajoutée dans la version 257.

sd_varlink_get_description() a été ajoutée dans la version 258.
