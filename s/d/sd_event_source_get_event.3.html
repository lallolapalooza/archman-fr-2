NOM

sd_event_source_get_event - Récupérer la boucle d'événements d'une source d'événements

SYNTAXE

#include <systemd/sd-event.h>

sd_event* sd_event_source_get_event(sd_event_source *source);

DESCRIPTION

sd_event_source_get_event() peut être utilisé pour récupérer l'objet boucle d'événements auquel l'objet source d'événements spécifié par source est associé. L'objet boucle d'événements est spécifié lors de la création d'un objet source d'événements avec des appels tels que sd_event_add_io(3) ou sd_event_add_time(3).

VALEUR DE RETOUR

En cas de succès, sd_event_source_get_event() retourne l'objet boucle d'événements associé. En cas d'échec, il retourne NULL.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour l'utilisation multi-thread. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de ne faire des appels à setenv() que dans une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_event_source_get_event() a été ajouté dans la version 229.
