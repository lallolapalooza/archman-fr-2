NOM

sd_bus_get_name_machine_id - Récupère l'identité de la machine d'un client de bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_get_name_machine_id(sd_bus *bus, const char *name, sd_id128_t *machine);

DESCRIPTION

sd_bus_get_name_machine_id() récupère l'identité de la machine D-Bus sur laquelle le client de bus identifié par name est en cours d'exécution. En interne, elle appelle la méthode GetMachineId de l'interface org.freedesktop.DBus.Peer. L'identité de la machine D-Bus est un UUID de 128 bits. Sur les systèmes Linux exécutant systemd, cela correspond au contenu de /etc/machine-id. En cas de succès, l'identité de la machine est stockée dans machine.

VALEUR DE RETOUR

En cas de succès, cette fonction retourne un entier positif. En cas d'échec, elle retourne un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Un argument est invalide.

-ENOPKG

Le bus ne peut pas être résolu.

-ECHILD

Le bus a été créé dans un processus, une bibliothèque ou une instance de module différent.

-ENOMEM

Échec de l'allocation de mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() que dans une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_get_name_machine_id() a été ajoutée dans la version 221.
