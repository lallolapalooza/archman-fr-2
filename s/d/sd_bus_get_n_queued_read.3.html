NOM

sd_bus_get_n_queued_read, sd_bus_get_n_queued_write - Obtenir le nombre de messages de bus en attente dans les files d'attente de lecture et d'écriture d'un objet de connexion de bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_get_n_queued_read(sd_bus *bus, uint64_t *ret);

int sd_bus_get_n_queued_write(sd_bus *bus, uint64_t *ret);

DESCRIPTION

sd_bus_get_n_queued_read() peut être utilisé pour interroger le nombre de messages de bus dans la file d'attente de lecture d'un objet de connexion de bus. La file d'attente de lecture contient tous les messages lus depuis le support de transport (par exemple, socket réseau) mais non encore traités localement. La fonction attend deux arguments : l'objet de bus à interroger et un pointeur vers une variable compteur de 64 bits pour écrire la taille actuelle de la file d'attente. Utilisez sd_bus_process() afin de traiter les messages mis en file d'attente, c'est-à-dire pour réduire la taille de la file d'attente de lecture (ainsi que, en fait, la file d'attente d'écriture, voir ci-dessous).

De même, sd_bus_get_n_queued_write() peut être utilisé pour interroger le nombre de messages de bus actuellement en attente dans la file d'attente d'écriture d'un objet de connexion de bus. La file d'attente d'écriture contient tous les messages mis en file d'attente dans la connexion avec un appel tel que sd_bus_send() mais qui n'ont pas encore été écrits sur le support de transport. Les arguments attendus sont similaires à ceux de sd_bus_get_n_queued_read(). Ici aussi, utilisez sd_bus_process() pour réduire la taille de la file d'attente d'écriture. Alternativement, utilisez sd_bus_flush() pour écrire de manière synchrone tous les messages de bus en attente jusqu'à ce que la file d'attente d'écriture soit vide.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ou un entier positif. En cas d'échec, elles retournent un code d'erreur négatif de style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion de bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

HISTORIQUE

sd_bus_get_n_queued_read() et sd_bus_get_n_queued_write() ont été ajoutés dans la version 238.
