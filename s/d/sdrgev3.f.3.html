!>
!> SDRGEV3 teste la routine pilote pour le problème de valeurs propres généralisées non symétriques SGGEV3.
!>
!> SGGEV3 calcule pour une paire de matrices non symétriques (A,B) de taille n x n les
!> valeurs propres généralisées et, éventuellement, les vecteurs propres
!> à gauche et à droite.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une interprétation raisonnable
!> pour beta=0, et même pour les deux étant zéro.
!>
!> Un vecteur propre généralisé à droite correspondant à une valeur propre généralisée
!> w pour une paire de matrices (A,B) est un vecteur r tel que
!> (A - wB) * r = 0. Un vecteur propre généralisé à gauche est un vecteur l tel que
!> l**H * (A - wB) = 0, où l**H est la conjuguée transposée de l.
!>
!> Lorsque SDRGEV3 est appelée, un nombre de tailles de matrices et
!> un nombre de types de matrices sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les tests suivants
!> seront effectués et comparés au seuil THRESH.
!>
!> Résultats de SGGEV3 :
!>
!> (1) max sur toutes les paires de valeurs/vecteurs propres à gauche (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      où VL**H est la conjuguée transposée de VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp et si le plus grand composant est réel
!>
!>      VL(i) désigne la i-ème colonne de VL.
!>
!> (3) max sur toutes les paires de valeurs/vecteurs propres à gauche (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp et si le plus grand composant est réel
!>
!>      VR(i) désigne la i-ème colonne de VR.
!>
!> (5)  W(full) = W(partial)
!>      W(full) désigne les valeurs propres calculées lorsque l et r
!>      sont également calculés, et W(partial) désigne les valeurs propres
!>      calculées lorsque seuls W, W et r, ou W et l seulement
!>      sont calculés.
!>
!> (6)  VL(full) = VL(partial)
!>      VL(full) désigne les vecteurs propres à gauche calculés lorsque l et
!>      r sont calculés, et VL(partial) désigne le résultat
!>      lorsque seul l est calculé.
!>
!> (7)  VR(full) = VR(partial)
!>      VR(full) désigne les vecteurs propres à droite calculés lorsque l et
!>      r sont également calculés, et VR(partial) désigne le résultat
!>      lorsque seul l est calculé.
!>
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .VRAI., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  ( 0, 0 )         (une paire de matrices nulles)
!>
!> (2)  ( I, 0 )         (une matrice identité et une matrice nulle)
!>
!> (3)  ( 0, I )         (une matrice nulle et une matrice identité)
!>
!> (4)  ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5)  ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7)  ( D, I )         où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                       avec ces entrées diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) où big est proche du dépassement et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées O(1) aléatoires au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!>

DO THE TESTS DESCRIBED IN THE COMMENTS IN THE CALLING
PROGRAM. THE FOLLOWING PARAMETERS ARE USED:
*NN (INTEGER) Array, dimension (NMAX)
Specifies the sizes of the matrices to be tested.
NN(I) is the dimension of the matrices of size I.
NN(I) must be between 0 and MAXN.
*NTYPES (INTEGER)
The number of types of matrices to be generated.
NTYPES must be between 0 and MAXTYP.
*DOTYPE (LOGICAL) Array, dimension (NTYPES)
If DOTYPE(j) is .TRUE., then for each size in NN a
matrix of that size and of type j will be generated.
If NTYPES is smaller than the maximum number of types
defined (PARAMETER MAXTYP), then types NTYPES+1 through
MAXTYP will not be generated. If NTYPES is larger
than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
will be ignored.
*ISEED (INTEGER) Array, dimension (4)
On entry ISEED specifies the seed of the random number
generator. The array elements should be between 0 and
4095; if not they will be reduced mod 4096. Also,
ISEED(4) must be odd. The random number generator uses a
linear congruential sequence limited to small integers,
and so should produce machine independent random numbers.
The values of ISEED are changed on exit, and can be used
in the next call to SDRGEV3 to continue the same random
number sequence.
*THRESH (REAL)
A test will count as if the , computed as
described above, exceeds THRESH. Note that the error is
scaled to be O(1), so THRESH should be a reasonably small
multiple of 1, e.g., 10 or 100. In particular, it should
not depend on the precision (single vs. double) or the size
of the matrix. It must be at least zero.
*NOUNIT (INTEGER)
The FORTRAN unit number for printing out error messages
(e.g., if a routine returns IERR not equal to 0.)
*A (REAL) Array, dimension(LDA, max(NN))
Used to hold the original A matrix. Used as input only
if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
DOTYPE(MAXTYP+1)=.TRUE.
*LDA (INTEGER)
The leading dimension of A, B, S, and T.
It must be at least 1 and at least max( NN ).
*B (REAL) Array, dimension(LDA, max(NN))
Used to hold the original B matrix. Used as input only
if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
DOTYPE(MAXTYP+1)=.TRUE.
*S (REAL) Array, dimension (LDA, max(NN))
The Schur form matrix computed from A by SGGEV3. On exit, S
contains the Schur form matrix corresponding to the matrix
in A.
*T (REAL) Array, dimension (LDA, max(NN))
The upper triangular matrix computed from B by SGGEV3.
*Q (REAL) Array, dimension (LDQ, max(NN))
The (left) eigenvectors matrix computed by SGGEV3.
*LDQ (INTEGER)
The leading dimension of Q and Z. It must
be at least 1 and at least max( NN ).
*Z (REAL) Array, dimension( LDQ, max(NN) )
The (right) orthogonal matrix computed by SGGEV3.
*QE (REAL) Array, dimension( LDQ, max(NN) )
QE holds the computed right or left eigenvectors.
*LDQE (INTEGER)
The leading dimension of QE. LDQE >= max(1,max(NN)).
*ALPHAR (REAL) Array, dimension (max(NN))
*ALPHAI (REAL) Array, dimension (max(NN))
*BETA (REAL) Array, dimension (max(NN))
The generalized eigenvalues of (A,B) computed by SGGEV3.
( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th
generalized eigenvalue of A and B.
*ALPHR1 (REAL) Array, dimension (max(NN))
*ALPHI1 (REAL) Array, dimension (max(NN))
*BETA1 (REAL) Array, dimension (max(NN))
Like ALPHAR, ALPHAI, BETA, these arrays contain the
eigenvalues of A and B, but those computed when SGGEV3 only
computes a partial eigendecomposition, i.e. not the
eigenvalues and left and right eigenvectors.
*WORK (REAL) Array, dimension (LWORK)
*LWORK (INTEGER)
The number of entries in WORK. LWORK >= MAX( 8*N, N*(N+1) ).
*RESULT (REAL) Array, dimension (2)
The values computed by the tests described above.
The values are currently limited to 1/ulp, to avoid overflow.
*INFO (INTEGER)
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value.
> 0: A routine returned an error code. INFO is the
absolute value of the INFO value returned.

NN

NN est un tableau de type LOGICAL, dimensionné à (NMAX).
Il spécifie les tailles des matrices à tester.
NN(I) est la dimension des matrices de taille I.
NN(I) doit être compris entre 0 et MAXN.

NTYPES

NTYPES est un entier.
Le nombre de types de matrices à générer.
NTYPES doit être compris entre 0 et MAXTYP.

DOTYPE

DOTYPE est un tableau de type LOGICAL, dimensionné à (NTYPES).
Si DOTYPE(j) est égal à .TRUE., alors pour chaque taille dans NN, une
matrice de cette taille et de type j sera générée.
Si NTYPES est inférieur au nombre maximum de types
définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
MAXTYP ne seront pas générés. Si NTYPES est supérieur
à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
seront ignorés.

ISEED

ISEED est un tableau de type INTEGER, dimensionné à (4).
À l'entrée, ISEED spécifie la graine du générateur de nombres
aléatoires. Les éléments du tableau doivent être compris entre 0 et
4095 ;
s'ils ne le sont pas, ils seront réduits modulo 4096. De plus, ISEED(4)
doit être impair. Le générateur de nombres aléatoires utilise une
séquence congruente linéaire limitée à de petits entiers, et devrait
donc produire des nombres aléatoires indépendants de la machine. Les
valeurs de ISEED sont modifiées à la sortie et peuvent être utilisées
dans
l'appel suivant à SDRGEV3 pour continuer la même séquence de nombres
aléatoires.

THRESH

THRESH est un REAL.
Un test sera considéré comme réussi si la valeur calculée,
comme décrit ci-dessus, dépasse THRESH. Notez que l'erreur est
normalisée à O(1), donc THRESH devrait être un multiple raisonnablement petit
de 1, par exemple 10 ou 100. En particulier, il ne doit pas dépendre
de la précision (simple ou double) ni de la taille
de la matrice. Il doit être au moins zéro.

NOUNIT

NOUNIT est un INTEGER.
Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
(par exemple, si une routine renvoie IERR différent de 0).

A

A est un tableau de type REAL,
dimensionné (LDA, max(NN))
Utilisé pour contenir la matrice A originale. Utilisé en entrée uniquement
si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
DOTYPE(MAXTYP+1)=.TRUE.

LDA

LDA est un INTEGER.
La dimension principale de A, B, S et T.
Elle doit être au moins 1 et au moins max( NN ).

B

B est un tableau de type REAL,
dimensionné (LDA, max(NN))
Utilisé pour contenir la matrice B originale. Utilisé en entrée uniquement
si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
DOTYPE(MAXTYP+1)=.TRUE.

S

S est un tableau de type REAL,
dimensionné (LDA, max(NN))
La matrice de forme de Schur calculée à partir de A par SGGEV3. En sortie, S
contient la matrice de forme de Schur correspondant à la matrice
dans A.

T

T est un tableau de type REAL,
dimensionné (LDA, max(NN))
La matrice triangulaire supérieure calculée à partir de B par SGGEV3.

Q

Q est un tableau de type REAL,
dimensionné (LDQ, max(NN))
La matrice des vecteurs propres (à gauche) calculée par SGGEV3.

LDQ

LDQ est un INTEGER.
La dimension principale de Q et Z. Elle doit
être au moins 1 et au moins max( NN ).

Z

Z est un tableau de type REAL, dimensionné( LDQ, max(NN) )
La matrice orthogonale (à droite) calculée par SGGEV3.

QE

QE est un tableau de type REAL, dimensionné( LDQ, max(NN) )
QE contient les vecteurs propres droits ou gauches calculés.

LDQE

LDQE est un INTEGER.
La dimension principale de QE. LDQE >= max(1,max(NN)).

ALPHAR

ALPHAR est un tableau de type REAL, dimensionné (max(NN))

ALPHAI

ALPHAI est un tableau de type REAL, dimensionné (max(NN))

BETA

BETA est un tableau de type REAL, dimensionné (max(NN))
Les valeurs propres généralisées de (A,B) calculées par SGGEV3.
( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) est la k-ième
valeur propre généralisée de A et B.

ALPHR1

ALPHR1 est un tableau de type REAL, dimensionné (max(NN))

ALPHI1

ALPHI1 est un tableau de type REAL, dimensionné (max(NN))

BETA1

BETA1 est un tableau de type REAL, dimensionné (max(NN))
Comme ALPHAR, ALPHAI, BETA, ces tableaux contiennent les
valeurs propres de A et B, mais celles calculées lorsque SGGEV3
calcule uniquement une décomposition propre partielle, c'est-à-dire pas
les
valeurs propres et les vecteurs propres gauches et droits.

WORK

WORK est un tableau de type REAL, dimensionné (LWORK)

LWORK

LWORK est un INTEGER.
Le nombre d'éléments dans WORK. LWORK >= MAX( 8*N, N*(N+1) ).

RESULT

RESULT est un tableau de type REAL, dimensionné (2).
Les valeurs calculées par les tests décrits ci-dessus.
Les valeurs sont actuellement limitées à 1/ulp, pour éviter les débordements.

INFO

INFO est un INTEGER.
= 0: sortie réussie
< 0: si INFO = -i, le i-ème argument avait une valeur illégale.
> 0: une routine a renvoyé un code d'erreur. INFO est la
valeur absolue de la valeur INFO renvoyée.
