DESCRIPTION

En plus des noms d'erreur que les programmes utilisateurs définissent, D-Bus connaît un certain nombre de noms d'erreurs génériques et standardisés qui sont listés ci-dessous.

En plus de cette liste, dans sd-bus, l'espace de noms d'erreur spécial "System.Error." est utilisé pour mapper des erreurs système Linux arbitraires (telles que définies par errno(3)) vers et depuis des erreurs D-Bus. Par exemple, l'erreur EUCLEAN est mappée sur "System.Error.EUCLEAN" et vice-versa.

SD_BUS_ERROR_FAILED

NAME

sd-bus-errors — systemd D-Bus error codes

SYNOPSIS

/* Error codes are integer constants starting with SD_BUS_ERROR_... */

DESCRIPTION

The systemd D-Bus API defines a set of error codes that are returned by functions.

These error codes are defined as integer constants, which are returned by functions such as sd_bus_call(3), sd_bus_process(3), and others. They are described in more detail in sd_bus_error(3).

The following error codes are defined:

SD_BUS_ERROR_NULL_ERROR

The passed error object pointer is NULL.

Added in version 223.

SD_BUS_ERROR_UNEXPECTED_IO

An unexpected I/O error occurred.

Added in version 223.

SD_BUS_ERROR_REMOTE_CALL_FAILED

A remote procedure call failed. The specific error is contained in the error object.

Added in version 223.

SD_BUS_ERROR_SERVICE_NOT_FOUND

The requested service does not exist.

Added in version 223.

SD_BUS_ERROR_SERVICE_NOT_ACTIVATED

The requested service could not be activated.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_INTERFACE

The requested interface does not exist.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_MEMBER

The requested member (method or signal) does not exist.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_OBJECT

The requested object path does not exist.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_PROPERTY

The requested property does not exist.

Added in version 223.

SD_BUS_ERROR_PROPERTY_READ_ONLY

The requested property is read-only.

Added in version 223.

SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN

The requested PID is not known.

Added in version 223.

SD_BUS_ERROR_INVALID_SIGNATURE

The specified message signature is not valid.

Added in version 223.

SD_BUS_ERROR_INCONSISTENT_MESSAGE

The passed message does not validate correctly.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_NOT_FOUND

The specified match rule does not exist.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_INVALID

The specified match rule is invalid.

Added in version 223.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

Access to the requested operation is not permitted. However, it might be available after interactive authentication. This is usually returned by method calls supporting a framework for additional interactive authorization, when interactive authorization was not enabled with the sd_bus_message_set_allow_interactive_authorization(3) for the method call message.

Added in version 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.

SEE ALSO

systemd(1), libsystemd(3), sd-bus(3), sd_bus_error(3), sd_bus_message_set_allow_interactive_authorization(3), errno(3), strerror_r(3)

NOM

sd-bus-errors — codes d'erreur D-Bus de systemd

SYNTAXE

/* Les codes d'erreur sont des constantes entières commençant par SD_BUS_ERROR_... */

DESCRIPTION

L'API D-Bus de systemd définit un ensemble de codes d'erreur qui sont retournés par les fonctions.

Ces codes d'erreur sont définis comme des constantes entières, qui sont retournées par des fonctions telles que sd_bus_call(3), sd_bus_process(3), et d'autres. Ils sont décrits plus en détail dans sd_bus_error(3).

Les codes d'erreur suivants sont définis :

SD_BUS_ERROR_NULL_ERROR

Le pointeur de l'objet d'erreur passé est NULL.

Ajouté dans la version 223.

SD_BUS_ERROR_UNEXPECTED_IO

Une erreur d'E/S inattendue s'est produite.

Ajouté dans la version 223.

SD_BUS_ERROR_REMOTE_CALL_FAILED

Un appel de procédure distante a échoué. L'erreur spécifique est contenue dans l'objet d'erreur.

Ajouté dans la version 223.

SD_BUS_ERROR_SERVICE_NOT_FOUND

Le service demandé n'existe pas.

Ajouté dans la version 223.

SD_BUS_ERROR_SERVICE_NOT_ACTIVATED

Le service demandé n'a pas pu être activé.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_INTERFACE

L'interface demandée n'existe pas.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_MEMBER

Le membre (méthode ou signal) demandé n'existe pas.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_OBJECT

Le chemin d'objet demandé n'existe pas.

Ajouté dans la version 223.

SD_BUS_ERROR_UNKNOWN_PROPERTY

La propriété demandée n'existe pas.

Ajouté dans la version 223.

SD_BUS_ERROR_PROPERTY_READ_ONLY

La propriété demandée est en lecture seule.

Ajouté dans la version 223.

SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN

Ajouté dans la version 223.

SD_BUS_ERROR_INVALID_SIGNATURE

Ajouté dans la version 223.

SD_BUS_ERROR_INCONSISTENT_MESSAGE

Ajouté dans la version 223.

SD_BUS_ERROR_MATCH_RULE_NOT_FOUND

SD_BUS_ERROR_MATCH_RULE_INVALID

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

Ajouté dans la version 223.

NOTES

Les fonctions décrites ici sont disponibles en tant que bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'appeler setenv() que lors d'une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.
