SD_DEVICE_ENUMERATOR_ADD_MATCH_PARENT(3) sd_device_enumerator_add_match_parent SD_DEVICE_ENUMERATOR_ADD_MATCH_PARENT(3)

NOM

sd_device_enumerator_add_match_parent, sd_device_enumerator_add_match_property, sd_device_enumerator_add_match_property_required, sd_device_enumerator_add_match_subsystem, sd_device_enumerator_add_match_sysattr, sd_device_enumerator_add_match_sysname, sd_device_enumerator_add_nomatch_sysname, sd_device_enumerator_add_match_tag, sd_device_enumerator_allow_uninitialized, sd_device_enumerator_add_all_parents - Ajoute un filtre à l'énumérateur de périphériques

#include <systemd/sd-device.h>

int sd_device_enumerator_add_match_parent(sd_device_enumerator *enumerator, sd_device *parent);

int sd_device_enumerator_add_match_property(sd_device_enumerator *enumerator, const char *property, const char *value);

int sd_device_enumerator_add_match_property_required(sd_device_enumerator *enumerator, const char *property, const char *value);

int sd_device_enumerator_add_match_subsystem(sd_device_enumerator *enumerator, const char *subsystem, int match);

int sd_device_enumerator_add_match_sysattr(sd_device_enumerator *enumerator, const char *sysattr, const char *value, int match);

int sd_device_enumerator_add_match_sysname(sd_device_enumerator *enumerator, const char *sysname);

int sd_device_enumerator_add_nomatch_sysname(sd_device_enumerator *enumerator, const char *sysname);

int sd_device_enumerator_add_match_tag(sd_device_enumerator *enumerator, const char *tag);

int sd_device_enumerator_allow_uninitialized(sd_device_enumerator *enumerator);

int sd_device_enumerator_add_all_parents(sd_device_enumerator *enumerator);

DESCRIPTION

La fonction sd_device_enumerator_add_match_parent() ajoute un filtre à l'enumerator de sorte que seuls les périphériques sous l'arborescence du périphérique parent spécifié soient énumérés. Si cette fonction est appelée plusieurs fois, le périphérique parent précédemment défini est effacé et seul le dernier appel prend effet.

La fonction sd_device_enumerator_add_match_property() ajoute un filtre à l'enumerator de sorte que seuls les périphériques ayant la property spécifiée égale à la value soient énumérés. Le property et la value peuvent être un motif glob. Lorsque cette fonction est appelée plusieurs fois, les périphériques qui ont au moins une des propriétés spécifiées avec des valeurs correspondantes sont énumérés. C'est-à-dire que les filtres sont combinés par OU.

La fonction sd_device_enumerator_add_match_property_required() ajoute un filtre à l'enumerator de sorte que seuls les périphériques ayant la property spécifiée égale à la value soient énumérés. Cette fonction est similaire à sd_device_enumerator_add_match_property(), mais lorsque cette fonction est appelée plusieurs fois, les périphériques qui ont toutes les propriétés spécifiées avec des valeurs correspondantes sont énumérés. C'est-à-dire que les filtres sont combinés par ET.

La fonction sd_device_enumerator_add_match_subsystem() ajoute un filtre à l'enumerator de sorte que tous les périphériques du subsystem spécifié soient inclus, lorsque match est true. Lorsque match est false, alors tous les périphériques à l'exception de ceux du subsystem spécifié sont énumérés. Lorsque appelée plusieurs fois, les filtres positifs sont combinés par OU, et les négatifs par ET.

La fonction sd_device_enumerator_add_match_sysattr() ajoute un filtre sur l'attribut sysfs sysattr correspondant à value. value peut être un motif glob. Si value est NULL, les périphériques qui ont (si match est true) ou n'ont pas (si match est false) le sysattr spécifié sont inclus, quelle que soit sa valeur. C'est-à-dire que NULL est essentiellement équivalent à "*". Lorsque cette fonction est appelée plusieurs fois, seuls les périphériques qui correspondent à tous les filtres sysattr spécifiés sont énumérés. C'est-à-dire que ces filtres sont combinés par ET.

La fonction sd_device_enumerator_add_match_sysname() ajoute un filtre de sorte que seuls les périphériques dont le nom système (sysname) est égal à sysname soient énumérés. sysname peut être un motif glob. Lorsque appelée plusieurs fois, les filtres sont combinés par OU.

La fonction sd_device_enumerator_add_nomatch_sysname() ajoute un filtre de sorte que les périphériques dont le nom système (sysname) est égal à sysname soient exclus du processus d'énumération. Ceci est utile pour exclure des périphériques spécifiques du processus d'énumération. Lorsque appelée plusieurs fois, les fonctionnalités sont combinées par ET.

La fonction sd_device_enumerator_add_match_tag() ajoute un filtre de sorte que seuls les périphériques étiquetés avec tag soient énumérés. Lorsque appelée plusieurs fois, les filtres sont combinés par OU.

La fonction sd_device_enumerator_allow_uninitialized() permet aux périphériques qui n'ont pas encore été initialisés par udev d'être inclus dans l'énumération.

La fonction sd_device_enumerator_add_all_parents() énumère tous les périphériques parents des périphériques correspondants. Ceci est utile dans les cas où vous souhaitez inclure tous les périphériques parents dans l'énumération, par exemple lorsque vous êtes intéressé par l'intégralité de l'arborescence des périphériques menant à un périphérique spécifique.

VALEUR DE RETOUR

Toutes les fonctions retournent 0 ou un entier positif en cas de succès, ou un code d'erreur négatif de style errno en cas d'échec.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ENOMEM

Échec d'allocation de mémoire.

-EINVAL

L'un des arguments est invalide.

EXEMPLES

Exemple 1. Détecter les périphériques USB amovibles (en utilisant Match et Exclude)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* Créer un nouvel énumérateur de périphériques */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Échec de la création de l'énumérateur de périphériques : %s\n", strerror(-r));
        return 1;
    }
    /* Inclure uniquement les périphériques du sous-système "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout du filtre de sous-système : %s\n", strerror(-r));
        return 1;
    }
    /*
     * Exclure les périphériques où l'attribut sysfs "removable" est "0"
     * Ce sont généralement des périphériques non amovibles comme les interfaces USB intégrées
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "Échec de l'ajout du filtre sysattr : %s\n", strerror(-r));
        return 1;
    }
    /* Commencer l'énumération des périphériques correspondants */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* Obtenir le chemin sysfs pour le périphérique */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("Périphérique USB amovible trouvé : %s\n", syspath);
    }
    return 0;
}

sd_device_enumerator_add_all_parents(3) — systemd Manual

NOM

sd_device_enumerator_add_all_parents — ajouter tous les parents d'un périphérique

SYNTAXE

#include <systemd/sd-device.h>

int
sd_device_enumerator_add_all_parents(sd_device_enumerator *enumerator,
                                     sd_device *device);

DESCRIPTION

La fonction sd_device_enumerator_add_all_parents() ajoute une demande à enumerator pour inclure le périphérique device et tous ses parents (par exemple, les périphériques dont il est une partie, les bus dont il est attaché, etc.) dans le résultat de l'énumération.

Notez que cela ajoutera également des périphériques qui ne correspondent pas explicitement aux autres critères de filtrage définis dans enumerator.

Cette fonction ne doit être appelée qu'après sd_device_enumerator_new() et avant sd_device_enumerator_get_device_first().

VALEUR RENVOYÉE

La fonction sd_device_enumerator_add_all_parents() renvoie 0 en cas de succès, ou un code d'erreur négatif en cas d'échec. Les codes d'erreur possibles sont :

-EINVAL
L'un des arguments requis est invalide.
-ENOMEM
Pas assez de mémoire.

EXEMPLES

// Obtenir une énumération de tous les périphériques, y compris leurs parents
sd_device_enumerator *enumerator;
sd_device *device;
int r;

r = sd_device_enumerator_new(&enumerator);
if (r < 0)
    goto error;

r = sd_device_enumerator_add_all_parents(enumerator, device);
if (r < 0)
    goto error;

// Ensuite, itérez sur les périphériques trouvés

error:
// ... gérer l'erreur ...

HISTORIQUE

sd_device_enumerator_add_all_parents() a été ajoutée dans la version 258.
