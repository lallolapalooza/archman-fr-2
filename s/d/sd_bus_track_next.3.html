SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOM

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Ajouter, supprimer et récupérer les pairs de bus suivis dans un objet de suivi de pairs de bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPTION

sd_bus_track_add_name() ajoute une paire à suivre à un objet de suivi de paires de bus. Le premier argument doit faire référence à un objet de suivi de paires de bus créé avec sd_bus_track_new(3), le second nom doit faire référence à un nom de paire de bus D-Bus à suivre, sous forme de nom de service unique ou bien connu. Si le nom n'est pas encore suivi, il sera ajouté à la liste des noms à suivre. S'il est déjà suivi et que le mode non récursif est activé, aucune opération n'est exécutée par cet appel. Si le mode récursif est activé, un compteur par nom est incrémenté à chaque invocation de cet appel, et sd_bus_track_remove_name() doit être appelé autant de fois que sd_bus_track_add_name() a été invoqué avant pour arrêter le suivi du nom. Utilisez sd_bus_track_set_recursive(3) pour passer du mode non récursif par défaut au mode récursif, ou vice versa. Notez que le nom spécifié est suivi tel quel, les noms bien connus ne sont pas résolus en noms uniques par cet appel. Notez que plusieurs objets de suivi de paires de bus peuvent suivre le même nom.

sd_bus_track_remove_name() annule l'effet de sd_bus_track_add_name() et supprime un nom de paire de bus de la liste des paires à surveiller. Selon que le mode non récursif ou récursif est activé pour l'objet de suivi de paires de bus, cet appel supprimera complètement le nom de l'objet de suivi, ou incrémentera simplement le compteur par nom de un, ne supprimant le nom que lorsque le compteur atteint zéro (voir ci-dessus). Notez qu'une paire de bus se déconnectant du bus supprimera implicitement ses noms complètement de l'objet de suivi de paires de bus, indépendamment du compteur par nom actuel.

sd_bus_track_add_sender() et sd_bus_track_remove_sender() sont similaires à sd_bus_track_add_name() et sd_bus_track_remove_name() mais prennent un message de bus comme argument. L'expéditeur de ce message de bus est déterminé et ajouté/supprimé de l'objet de suivi de paires de bus. Les messages étant toujours originaires de noms uniques, et jamais de noms bien connus, cela signifie que cet appel n'ajoutera effectivement que des noms uniques à l'objet de suivi de paires de bus.

sd_bus_track_count() renvoie le nombre de noms actuellement suivis par l'objet de suivi de paires de bus spécifié. Notez que cette fonction renvoie toujours le nombre réel de noms suivis, et donc si sd_bus_track_add_name() a été invoqué plusieurs fois pour le même nom, il n'est compté qu'une seule fois, que le mode récursif soit utilisé ou non.

sd_bus_track_count_name() renvoie le compteur actuel par nom pour le nom spécifié. Si le mode non récursif est utilisé, cela renvoie soit 1 soit 0, selon que le nom spécifié a été ajouté à l'objet de suivi auparavant, ou non. Si le mode récursif a été activé, des valeurs supérieures à 1 peuvent également être retournées, si sd_bus_track_add_name() a été appelé plusieurs fois pour le même nom.

sd_bus_track_count_sender() est similaire à sd_bus_track_count_name(), mais prend un objet de message de bus et renvoie le compteur par nom correspondant à l'expéditeur du message.

sd_bus_track_contains() peut être utilisé pour déterminer si le nom spécifié a été ajouté au moins une fois à l'objet de suivi de paires de bus spécifié.

sd_bus_track_first() et sd_bus_track_next() peuvent être utilisés pour énumérer tous les noms actuellement suivis par l'objet de suivi de paires de bus passé. sd_bus_track_first() renvoie la première entrée de l'objet et réinitialise un index de lecture maintenu en interne. Chaque invocation subséquente de sd_bus_track_next() renvoie le nom suivant contenu dans l'objet de bus. Si la fin est atteinte, NULL est renvoyé. Si aucun nom n'a encore été ajouté à l'objet, sd_bus_track_first() renverra NULL immédiatement. L'ordre dans lequel les noms sont retournés n'est pas défini ; en particulier, quel nom est considéré comme le premier retourné n'est pas défini. Si le mode récursif est activé et que le même nom a été ajouté plusieurs fois à l'objet de suivi de paires de bus, il n'est retourné qu'une seule fois par cette énumération. Si de nouveaux noms sont ajoutés ou des noms existants supprimés de l'objet de suivi de paires de bus pendant son énumération, l'énumération se termine lors de la prochaine invocation de sd_bus_track_next() car NULL est renvoyé.

VALEUR DE RETOUR

En cas de succès, sd_bus_track_add_name() et sd_bus_track_add_sender() renvoient 0 si le nom spécifié a déjà été ajouté auparavant à l'objet de suivi de paires de bus et une valeur positive s'il ne l'a pas été. En cas d'échec, ils renvoient un code d'erreur négatif de type errno.

sd_bus_track_remove_name() et sd_bus_track_remove_sender() renvoient une valeur positive si le nom spécifié était précédemment suivi par l'objet de suivi de paires de bus et qu'il a maintenant été supprimé. En mode non récursif, 0 est renvoyé si le nom spécifié n'était pas encore suivi. En mode récursif, -EUNATCH est renvoyé dans ce cas. En cas d'échec, ils renvoient un code d'erreur négatif de type errno.

sd_bus_track_count() renvoie le nombre de noms actuellement suivis, ou 0 en cas d'échec.

sd_bus_track_count_name() et sd_bus_track_count_sender() renvoient le compteur actuel par nom pour le nom spécifié ou l'expéditeur du message spécifié. Zéro est renvoyé pour les noms qui ne sont pas encore suivis, une valeur positive pour les noms ajoutés au moins une fois. Des valeurs supérieures à 1 ne sont renvoyées qu'en mode récursif. En cas d'échec, un code d'erreur négatif de type errno est renvoyé.

sd_bus_track_contains() renvoie le nom passé s'il existe dans l'objet de suivi de paires de bus. En cas d'échec, et si le nom n'a pas encore été ajouté, NULL est renvoyé.

sd_bus_track_first() et sd_bus_track_next() renvoient le premier/le nom suivant contenu dans l'objet de suivi de paires de bus, et NULL si la fin de l'énumération est atteinte et en cas d'erreur.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EUNATCH

sd_bus_track_remove_name() ou sd_bus_track_remove_sender() ont été invoqués pour un nom qui n'a pas été précédemment ajouté à l'objet de paires de bus.

-EINVAL

Le paramètre spécifié est invalide.

-ENOMEM

Échec de l'allocation mémoire.

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_next(sd_bus_track *track);
int sd_bus_track_add_name(sd_bus_track *track, const char *name);

int sd_bus_track_remove_sender(sd_bus_track *track, uint64_t sender_id);

sd_bus_track_type sd_bus_track_first(sd_bus_track *track, const void **value);

DESCRIPTION

Les fonctions sd_bus_track_add_name() et sd_bus_track_add_sender() ajoutent un nom de service ou un ID d'expéditeur, respectivement, à l'ensemble des objets suivis. Les objets suivis sont utilisés pour compter les messages qui correspondent aux critères spécifiés. L'ensemble suivi est initialement vide.

Les fonctions sd_bus_track_remove_name() et sd_bus_track_remove_sender() suppriment un nom de service ou un ID d'expéditeur de l'ensemble des objets suivis.

La fonction sd_bus_track_count() renvoie le nombre total d'objets suivis dans l'ensemble.

Les fonctions sd_bus_track_count_name() et sd_bus_track_count_sender() renvoient le nombre d'occurrences d'un nom de service ou d'un ID d'expéditeur spécifiques dans l'ensemble, respectivement.

La fonction sd_bus_track_contains() vérifie si un objet de type type et de valeur value est présent dans l'ensemble suivi.

La fonction sd_bus_track_first() initialise une itération sur les objets suivis et renvoie le premier objet et sa valeur.

La fonction sd_bus_track_next() renvoie le prochain objet suivi dans l'itération.

VALEUR RENVOYÉE

En cas de succès, les fonctions renvoient un entier non négatif. En cas d'échec, elles renvoient un code d'erreur négatif.

NOTES

Les fonctions de suivi de bus sont destinées à être utilisées dans les premières phases du programme lorsque aucun autre thread n'a encore été démarré.
