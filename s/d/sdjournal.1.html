NOM

sdjournal - Fournit une interface pour capturer les entrées du journal systemd.

SYNTAXE

sdjournal [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --capture ] [ --fifo=<chemin vers fichier ou tube> ] [ --start-from=<nombre d’entrées> ]

DESCRIPTION

sdjournal est un outil extcap qui permet de capturer les entrées du journal systemd. Il peut être utilisé pour corréler les événements système avec le trafic réseau.

Interfaces prises en charge :

1.sdjournal

OPTIONS

--help

Affiche les arguments du programme.

--version

Affiche la version du programme.

--extcap-interfaces

Liste les interfaces disponibles.

--extcap-interface=<interface>

Utilise l'interface spécifiée.

--extcap-dlts

Liste les DLT de l'interface spécifiée.

--extcap-config

Liste les options de configuration de l'interface spécifiée.

--capture

Commence la capture à partir de l'interface spécifiée et écrit les données brutes des paquets à l'emplacement spécifié par --fifo.

--fifo=<chemin vers fichier ou tube>

Enregistre le paquet capturé dans un fichier ou l'envoie via un tube.

--start-from=<nombre d'entrées>

Commence à partir des <nombre d'entrées> dernières entrées, similaire à l'argument « -n » ou « --lines » de la commande tail(1). Les valeurs précédées d'un signe + commencent depuis le début du journal, sinon le décompte commence depuis la fin. La valeur par défaut est 10. Pour inclure toutes les entrées, utilisez +0.

EXEMPLES

Pour voir les arguments du programme :

sdjournal --help

Pour voir la version du programme :

sdjournal --version

Pour voir les interfaces :

sdjournal --extcap-interfaces

Une seule interface (sdjournal) est prise en charge.

Exemple de sortie

interface {value=sdjournal}{display=capture du journal systemd}

Pour voir les DLTs de l'interface :

sdjournal --extcap-interface=sdjournal --extcap-dlts

Exemple de sortie

dlt {number=147}{name=sdjournal}{display=USER0}

Pour voir les options de configuration de l'interface :

sdjournal --extcap-interface=sdjournal --extcap-config

Exemple de sortie

arg {number=0}{call=--start-from}{display=Position de départ}{type=string}
    {tooltip=La position de départ du journal. Les valeurs avec un "+" en préfixe commencent depuis le début, similaire à la commande "tail"}

Pour capturer :

sdjournal --extcap-interface=sdjournal --fifo=/tmp/sdjournal.pcap --capture

Pour capturer toutes les entrées depuis le démarrage du système :

sdjournal --extcap-interface=sdjournal --fifo=/tmp/sdjournal.pcap --capture --start-from +0

Note

Pour arrêter la capture, utilisez CTRL+C/kill/terminer l'application.
