SD_EVENT_SOURCE_SET_DESCRIPTION(3) sd_event_source_set_description SD_EVENT_SOURCE_SET_DESCRIPTION(3)

NOM

sd_event_source_set_description, sd_event_source_get_description - Définir ou récupérer des noms descriptifs des sources d'événements

SYNTAXE

#include <systemd/sd-event.h>

int sd_event_source_set_description(sd_event_source *source, const char *description);

int sd_event_source_get_description(sd_event_source *source, const char **ret);

DESCRIPTION

sd_event_source_set_description() peut être utilisée pour définir un nom descriptif arbitraire pour l'objet source d'événement spécifié par source. Ce nom sera utilisé dans les messages de débogage générés par sd-event(3) pour cette source d'événement, et pourra être interrogé à l'aide de sd_event_source_get_description() à des fins de débogage. Le paramètre description doit pointer vers une chaîne terminée par NUL ou être NULL. Dans ce dernier cas, le nom descriptif sera désactivé. La chaîne est copiée en interne, par conséquent, l'argument description n'est pas référencé après le retour de la fonction.

sd_event_source_get_description() peut être utilisée pour interroger le nom descriptif actuel attribué à l'objet source d'événement source. Elle renvoie un pointeur vers le nom actuel dans ret, stocké dans la mémoire interne à la source d'événement. La mémoire est invalidée lorsque la source d'événement est détruite ou que le nom descriptif est modifié.

Les objets sources d'événements n'ont généralement pas de description définie lorsqu'ils sont créés, à l'exception des sources d'événements de signaux UNIX créées avec sd_event_add_signal(3), dont le nom descriptif est initialisé au nom de constante C du signal (par exemple, "SIGINT" ou "SIGTERM").

VALEUR DE RETOUR

En cas de succès, sd_event_source_set_description() et sd_event_source_get_description() renvoient un entier non négatif. En cas d'échec, elles renvoient un code d'erreur négatif de style errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

source n'est pas un pointeur valide vers un objet sd_event_source ou l'argument description pour sd_event_source_get_description() est NULL.

-ENOMEM

Pas assez de mémoire pour copier le nom.

-ECHILD

La boucle d'événements a été créée dans un processus, une bibliothèque ou une instance de module différent.

-ENXIO

Aucun nom n'a été défini pour la source d'événement.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à partir d'une phase précoce du programme lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_event_source_set_description() et sd_event_source_get_description() ont été ajoutées dans la version 229.
