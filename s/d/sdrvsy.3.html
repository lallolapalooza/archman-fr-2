Documentation de la fonction/sous-programme

sous-programme sdrvsy (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nrhs, real thresh, logical tsterr, integer nmax, real, dimension( * ) a, real, dimension( * ) afac, real, dimension( * ) ainv, real, dimension( * ) b, real, dimension( * ) x, real, dimension( * ) xact, real, dimension( * ) work, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

SDRVSY

Purpose:

!>
!> SDRVSY teste les routines de pilotage SSYSV et -SVX.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, dimension (NN)
!>          Les valeurs de la dimension de matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de membre de droite à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un REEL
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur indiquant si les sorties d'erreur doivent être testées.
!>

NMAX

!>          NMAX est un ENTIER
!>          La valeur maximale autorisée pour N, utilisée dans le dimensionnement des
!>          tableaux de travail.
!>

A

!>          A est un tableau REEL, dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC est un tableau REEL, dimension (NMAX*NMAX)
!>

AINV

!>          AINV est un tableau REEL, dimension (NMAX*NMAX)
!>

B

!>          B est un tableau REEL, dimension (NMAX*NRHS)
!>

X

!>          X est un tableau REEL, dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau REEL, dimension (NMAX*NRHS)
!>

WORK

!>          WORK est un tableau REEL, dimension (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK est un tableau REEL, dimension (NMAX+2*NRHS)
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, dimension (2*NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité pour la sortie.
!>
