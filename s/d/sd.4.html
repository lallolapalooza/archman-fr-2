sd(4) Manuel des pilotes de périphériques sd(4)

NOM

sd - pilote pour disques durs SCSI

SYNTAXE

#include <linux/hdreg.h>        /* pour HDIO_GETGEO */
#include <linux/fs.h>           /* pour BLKGETSIZE et BLKRRPART */

CONFIGURATION

Le nom du périphérique bloc a la forme suivante : sdlp, où l est une lettre désignant le lecteur physique et p est un numéro désignant la partition sur ce lecteur physique. Souvent, le numéro de partition, p, sera omis lorsque le périphérique correspond au lecteur entier.

Les disques SCSI ont un numéro majeur de périphérique de 8, et un numéro mineur de périphérique de la forme (16 * numéro_disque) + numéro_partition, où numéro_disque est le numéro du lecteur physique dans l'ordre de détection, et numéro_partition est le suivant :

•
la partition 0 est le lecteur entier
•
les partitions 1 à 4 sont les partitions "primaires" DOS
•
les partitions 5 à 8 sont les partitions "étendues" (ou "logiques") DOS

Par exemple, /dev/sda aura le majeur 8, le mineur 0, et référencera l'intégralité du premier disque SCSI du système ; et /dev/sdb3 aura le majeur 8, le mineur 19, et référencera la troisième partition DOS "primaire" sur le deuxième disque SCSI du système.

Actuellement, seuls les périphériques bloc sont fournis. Les périphériques bruts n'ont pas encore été implémentés.

DESCRIPTION

Les ioctls suivants sont fournis :

HDIO_GETGEO
Retourne les paramètres du BIOS du disque dans la structure suivante :


struct hd_geometry {
    unsigned char  heads;
    unsigned char  sectors;
    unsigned short cylinders;
    unsigned long  start;
};
Un pointeur vers cette structure est passé comme paramètre à ioctl(2).
Les informations retournées dans le paramètre sont la géométrie du disque telle qu'elle est comprise par DOS ! Cette géométrie n'est pas la géométrie physique du disque. Elle est utilisée lors de la construction de la table de partitions du disque, et est nécessaire pour le bon fonctionnement de fdisk(1), efdisk(1), et lilo(1). Si les informations de géométrie ne sont pas disponibles, zéro sera retourné pour tous les paramètres.
BLKGETSIZE
Retourne la taille du périphérique en secteurs. Le paramètre de ioctl(2) devrait être un pointeur vers un long.
BLKRRPART
Force la relecture des tables de partitions du disque SCSI. Aucun paramètre n'est nécessaire.
Les opérations ioctl SCSI sont également prises en charge. Si le paramètre ioctl est requis et qu'il est NULL, alors ioctl échoue avec l'erreur EINVAL.

FICHIERS

/dev/sd[a-h]
le périphérique entier
/dev/sd[a-h][0-8]
partitions bloc individuelles
