sd_bus_interface_name_is_valid(3)

SD_BUS_INTERFACE_NAME_IS_VALID(3) sd_bus_interface_name_is_valid SD_BUS_INTERFACE_NAME_IS_VALID(3)

NOM

sd_bus_interface_name_is_valid, sd_bus_service_name_is_valid, sd_bus_member_name_is_valid, sd_bus_object_path_is_valid - Vérifier si une chaîne est un nom de bus ou un chemin d'objet valide

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_interface_name_is_valid(const char* p);

int sd_bus_service_name_is_valid(const char* p);

int sd_bus_member_name_is_valid(const char* p);

int sd_bus_object_path_is_valid(const char* p);

DESCRIPTION

sd_bus_interface_name_is_valid() vérifie si une chaîne donnée p est un nom d'interface de bus syntaxiquement valide. De même, sd_bus_service_name_is_valid() vérifie si l'argument est un nom de service de bus valide, sd_bus_member_name_is_valid() vérifie si l'argument est un nom de membre d'interface de bus valide, et sd_bus_object_path_is_valid() vérifie si l'argument est un chemin d'objet de bus valide. Ces fonctions vérifient généralement que seuls les caractères autorisés sont utilisés et que la longueur de la chaîne est dans les limites.

VALEUR RENVOYÉE

Ces fonctions renvoient 1 si l'argument est un nom d'interface / service / membre ou un chemin d'objet valide, et 0 s'il ne l'est pas. Si l'argument est NULL, une erreur est renvoyée.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre p est NULL.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les appels multi-thread. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() que dès les premières phases du programme, lorsque aucun autre thread n'a encore été démarré.

HISTORIQUE

sd_bus_interface_name_is_valid(), sd_bus_service_name_is_valid(), sd_bus_member_name_is_valid(), et sd_bus_object_path_is_valid() ont été ajoutées dans la version 246.
