sous-routine sdrgev (entier nsizes, entier, dimension( * ) nn, entier ntypes, logique, dimension( * ) dotype, entier, dimension( 4 ) iseed, réel thresh, entier nounit, réel, dimension( lda, * ) a, entier lda, réel, dimension( lda, * ) b, réel, dimension( lda, * ) s, réel, dimension( lda, * ) t, réel, dimension( ldq, * ) q, entier ldq, réel, dimension( ldq, * ) z, réel, dimension( ldqe, * ) qe, entier ldqe, réel, dimension( * ) alphar, réel, dimension( * ) alphai, réel, dimension( * ) beta, réel, dimension( * ) alphr1, réel, dimension( * ) alphi1, réel, dimension( * ) beta1, réel, dimension( * ) work, entier lwork, réel, dimension( * ) result, entier info)

SDRGEV

Objectif:

!>
!> SDRGEV teste la routine de pilotage du problème de valeurs propres généralisées non symétriques SGGEV.
!>
!> SGGEV calcule pour une paire de matrices carrées n x n non symétriques (A,B) les
!> valeurs propres généralisées et, éventuellement, les vecteurs propres généralisés gauches et droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un ratio alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une interprétation raisonnable pour beta=0, et même pour les deux étant zéro.
!>
!> Un vecteur propre généralisé droit correspondant à une valeur propre généralisée
!> w pour une paire de matrices (A,B) est un vecteur r tel que
!> (A - wB) * r = 0. Un vecteur propre généralisé gauche est un vecteur l tel que
!> l**H * (A - wB) = 0, où l**H est la transposée conjuguée de l.
!>
!> Lorsque SDRGEV est appelé, un nombre de tailles de matrices et un
!> nombre de types de matrices sont spécifiés. Pour chaque taille (NN(j))
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les tests
!> suivants seront effectués et comparés au seuil THRESH.
!>
!> Résultats de SGGEV:
!>
!> (1) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      où VL**H est la transposée conjuguée de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!>      VL(i) désigne la i-ème colonne de VL.
!>
!> (3) max sur toutes les paires de valeurs propres/vecteurs propres gauches (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!>      VR(i) désigne la i-ème colonne de VR.
!>
!> (5) W(full) = W(partial)
!>      W(full) désigne les valeurs propres calculées lorsque l et r
!>      sont également calculés, et W(partial) désigne les valeurs propres
!>      calculées lorsque seuls W, W et r, ou W et l sont calculés.
!>
!> (6) VL(full) = VL(partial)
!>      VL(full) désigne les vecteurs propres gauches calculés lorsque l et r
!>      sont calculés, et VL(partial) désigne le résultat
!>      lorsque seul l est calculé.
!>
!> (7) VR(full) = VR(partial)
!>      VR(full) désigne les vecteurs propres droits calculés lorsque l et r
!>      sont également calculés, et VR(partial) désigne le résultat
!>      lorsque seul l est calculé.
!>
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les types de matrices sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .VRAI., alors le type de matrice j sera généré.
!> Actuellement, la liste des types possibles est:
!>
!> (1) ( 0, 0 )         (une paire de matrices nulles)
!>
!> (2) ( I, 0 )         (une identité et une matrice nulle)
!>
!> (3) ( 0, I )         (une identité et une matrice nulle)
!>
!> (4) ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5) ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y )         où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1) ; k=(N-1)/2
!>
!> (7) ( D, I )         où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                       avec ces entrées diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) où big est proche du dépassement de capacité et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées aléatoires O(1) au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!>

Paramètres

NN

!>

NTYPES

!>          NTYPES est ENTIER
!>          Le nombre d'éléments dans DOTYPE. Si il est zéro, SDRGES
!>          ne fait rien. NTYPES >= 0.

DOTYPE

!>          DOTYPE est un tableau LOGIQUE, dimension (NTYPES)

ISEED

!>          ISEED est un tableau ENTIER, dimension (4)

THRESH

!>          THRESH est REEL

NOUNU

T

!>          Un tableau utilisé pour stocker la matrice T dans les tests 17-26.

Q

!>          La matrice orthogonale gauche utilisée dans les tests 16-26.

LDQ

Z

BETA

!>          BETA est un tableau REEL, dimension (*)
!>          Les valeurs propres généralisées beta.

ALPHR1

!>          ALPHR1 est un tableau REEL, dimension (*)

ALPHI1

!>          La partie imaginaire des valeurs propres généralisées alpha calculées avec des options différentes.

BETA1

!>          BETA1 est un tableau REEL, dimension (*)
!>          Les valeurs propres généralisées beta calculées avec des options différentes.

WORK

!>

LWORK

!>          LWORK est ENTIER
!>          La taille du tableau WORK. LWORK >= 1.

RESULT

!>          RESULT est un tableau REEL, dimension (*)
!>          Les résultats des tests. La signification dépend des tests effectués.
!>

INFO

!>          INFO est ENTIER
!>          INFO = 0:  Nombre de tests non réussis.
!>          INFO < 0:  Paramètre d'entrée non valide.

DOTYPE

!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.

ISEED

!>          ISEED est un tableau INTEGER, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres aléatoires.
!>          Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruente limitée à de petits entiers, et devrait donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées
!>          dans l'appel suivant à SDRGES pour continuer la même séquence de nombres
!>          aléatoires.
!>

THRESH

!>          THRESH est REAL
!>          Un test sera considéré comme réussi si le erreur, calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur est
!>          normalisée pour être de l'ordre de O(1), donc THRESH devrait être un multiple
!>          raisonnablement petit de 1, par exemple 10 ou 100. En particulier, il ne
!>          devrait pas dépendre de la précision (simple ou double) ou de la taille
!>          de la matrice. Il doit être au moins zéro.
