SD_DEVICE_REF(3) sd_device_ref SD_DEVICE_REF(3)

NOM

sd_device_ref, sd_device_unref, sd_device_unrefp - Créer ou détruire des références à un objet appareil

SYNTAXE

#include <systemd/sd-device.h>

sd_device* sd_device_ref(sd_device *device);

sd_device* sd_device_unref(sd_device *device);

void sd_device_unrefp(sd_device **device);

sd_device_ref() augmente le compteur de références interne de device de un.

sd_device_unref() diminue le compteur de références interne de device de un. Une fois que le compteur de références est tombé à zéro, device est détruit et ne peut plus être utilisé, donc des appels supplémentaires à sd_device_ref() ou sd_device_unref() sont illégaux.

sd_device_unrefp() est similaire à sd_device_unref() mais prend un pointeur vers un pointeur vers un objet sd_device. Cet appel est utile en conjonction avec l'attribut de variable de nettoyage de GCC et LLVM[1]. Notez que cette fonction est définie comme une fonction inline. Utilisez une déclaration comme la suivante, afin d'allouer un objet appareil qui est libéré automatiquement à la sortie du bloc de code :

{
  __attribute__((cleanup(sd_device_unrefp))) sd_device *device = NULL;
  int r;
  ...
  r = sd_device_new_from_syspath(&device, "...");
  if (r < 0) {
    errno = -r;
    fprintf(stderr, "Échec de l'allocation de l'appareil : %m\n");
  }
  ...
}

sd_device_ref() et sd_device_unref() n'effectuent aucune opération si l'argument est NULL. sd_device_unrefp() déréférencera d'abord son argument, qui ne doit pas être NULL, et n'effectuera aucune opération si *ce dernier* est NULL.

VALEUR RETOURNEE

sd_device_ref() retourne toujours l'argument, et sd_device_unref() retourne toujours NULL.

HISTORIQUE

sd_device_ref(), sd_device_unref(), et sd_device_unrefp() ont été ajoutés dans la version 251.
