Objectif :

!>
!> SDRVRFP teste les routines LAPACK RFP :
!> SPFTRF, SPFTRS et SPFTRI.
!>
!> Cette routine de test suit les mêmes tests que DDRVPO (test pour le solveur
!> symétrique défini positif en format complet).
!>
!> Les tests sont effectués en format complet, la conversion de et vers
!> le format RFP est effectuée à l'aide des routines STRTTF et
!> STFTTR.
!>
!> Premièrement, une matrice A spécifique de taille N est créée. Il existe neuf types
!> de matrices différentes possibles.
!>  1. Diagonale                        6. Aléatoire, CNDNUM = sqrt(0.1/EPS)
!>  2. Aléatoire, CNDNUM = 2              7. Aléatoire, CNDNUM = 0.1/EPS
!> *3. Première ligne et colonne zéro       8. Mise à l'échelle proche du sous-dépassement
!> *4. Dernière ligne et colonne zéro       9. Mise à l'échelle proche du dépassement
!> *5. Ligne et colonne du milieu zéro
!> (* - teste les sorties d'erreur de SPFTRF, aucun ratio de test n'est calculé)
!> Une solution XACT de taille N-par-NRHS est créée ainsi que le membre de droite
!> associé B. Ensuite, SPFTRF est appelée pour calculer L (ou U), le
!> facteur de Cholesky de A. Ensuite, L (ou U) est utilisé pour résoudre le système
!> linéaire d'équations AX = B. Cela donne X. Ensuite, L (ou U) est utilisé pour calculer
!> l'inverse de A, AINV. Les quatre tests suivants sont alors effectués :
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> où EPS est la précision machine, RCOND le nombre de condition de A, et
!> norm( . ) la norme 1 pour (1,2,3) et la norme infinie pour (4).
!> Des erreurs se produisent lorsque le paramètre INFO n'est pas celui attendu. Des échecs se produisent
!> lorsque le ratio de test est supérieur à THRES.
!>

NOM

sdrvrfp - Routine de driver pour la réduction de matrice par méthode de surrelaxation

SYNTAXE

SUBROUTINE SDRVRFP(N, NB, U, LDU, A, LDA, B, LDB, C, LDC, INFO)

Documentation de fonction/sous-routine

SDRVRFP est une routine de driver pour tester la sous-routine SSWSSPR.

Arguments :

  • N : (Entrée) Ordre de la matrice. N >= 0.
  • NB : (Entrée) Taille du bloc pour la réduction de matrice. NB >= 1.
  • U : (Sortie) Matrice U utilisée pour la réduction de matrice.
  • LDU : (Entrée) Leading dimension de U.
  • A : (Sortie) Matrice A (forme réduite).
  • LDA : (Entrée) Leading dimension de A.
  • B : (Sortie) Matrice B (forme réduite).
  • LDB : (Entrée) Leading dimension de B.
  • C : (Sortie) Matrice C (forme réduite).
  • LDC : (Entrée) Leading dimension de C.
  • INFO : (Sortie) Indicateur d'erreur. INFO = 0 si tout s'est bien passé, INFO < 0 si un des arguments d'entrée est invalide.
