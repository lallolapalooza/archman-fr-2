SD_BUS_SET_SERVER(3) sd_bus_set_server SD_BUS_SET_SERVER(3)

NOM

sd_bus_set_server, sd_bus_is_server, sd_bus_get_bus_id, sd_bus_set_bus_client, sd_bus_is_bus_client, sd_bus_set_monitor, sd_bus_is_monitor - Configurer le mode de connexion pour un objet bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_set_server(sd_bus *bus, int b, sd_id128_t id);

int sd_bus_is_server(sd_bus *bus);

int sd_bus_get_bus_id(sd_bus *bus, sd_id128_t *id);

int sd_bus_set_bus_client(sd_bus *bus, int b);

int sd_bus_is_bus_client(sd_bus *bus);

int sd_bus_set_monitor(sd_bus *bus, int b);

int sd_bus_is_monitor(sd_bus *bus);

DESCRIPTION

sd_bus_set_server() configure l'objet bus comme un serveur pour les connexions D-Bus directes. b active/désactive le mode serveur. Si zéro, le mode serveur est désactivé. Sinon, le mode serveur est activé. Configurer un objet bus comme serveur est nécessaire pour permettre l'établissement de connexions directes entre deux pairs sans passer par le démon D-Bus. id doit contenir un identifiant entier de 128 bits pour le serveur. Si les clients ajoutent un champ guid à leur chaîne d'adresse D-Bus, l'identifiant du serveur doit correspondre à ce guid ou la négociation d'authentification D-Bus échouera. Si aucun identifiant spécifique n'est défini pour le serveur, sd_id128_randomize(3) peut être utilisé pour générer un identifiant aléatoire à la place.

sd_bus_is_server() renvoie si le mode serveur est activé pour l'objet bus donné.

sd_bus_get_bus_id() enregistre l'identifiant du serveur D-Bus configuré à l'aide de sd_bus_set_server() (pour les objets bus serveurs) ou reçu lors de l'authentification D-Bus (pour les objets bus clients) dans id.

sd_bus_set_bus_client() configure l'objet bus comme un client du démon D-Bus. b active/désactive le mode client. Si zéro, le mode client est désactivé et l'objet bus devrait se connecter directement à un serveur D-Bus. Sinon, le mode client est activé et l'objet bus devrait se connecter à un démon D-Bus. Lors de la connexion à un bus existant en utilisant l'une des fonctions de la famille sd_bus_open(3) ou l'une des fonctions de la famille sd_bus_default(3), l'objet bus est automatiquement configuré comme un client de bus. Cependant, lors de la connexion à un démon D-Bus en appelant sd_bus_set_address(3) suivi de sd_bus_start(3), l'objet bus doit être configuré manuellement comme un client de bus en utilisant sd_bus_set_bus_client(). Par défaut, un objet bus n'est pas configuré comme un client de démon D-Bus.

sd_bus_is_bus_client() renvoie si le mode client est activé/désactivé pour l'objet bus donné.

sd_bus_set_monitor() configure l'objet bus comme un objet de surveillance D-Bus. b active/désactive le mode moniteur. Si zéro, le mode moniteur est désactivé. Si non nul, le mode moniteur est activé. Lorsque le mode moniteur est activé, aucun message ne peut être envoyé via l'objet bus et il ne peut exposer aucun objet sur le bus. Pour commencer à surveiller les messages, appelez la méthode org.freedesktop.DBus.Monitoring.BecomeMonitor du démon D-Bus et passez une liste de correspondances indiquant quels messages intercepter. Voir La spécification D-Bus[1] pour plus d'informations.

sd_bus_is_monitor() renvoie si le mode moniteur est activé/désactivé pour l'objet bus donné.

VALEUR DE RETOUR

En cas de succès, sd_bus_set_server(), sd_bus_get_bus_id(), sd_bus_set_bus_client() et sd_bus_set_monitor() renvoient un entier positif. En cas d'échec, ils renvoient un code d'erreur négatif de style errno.

sd_bus_is_server(), sd_bus_is_bus_client() et sd_bus_is_monitor() renvoient un entier positif lorsque le mode serveur ou client est activé, respectivement. Sinon, ils renvoient zéro.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants:

-ECHILD

La connexion bus a été créée dans un processus, une bibliothèque ou une instance de module différente.

Ajouté dans la version 246.

-EPERM

La connexion bus a déjà été démarrée.

Ajouté dans la version 246.

-ENOPKG

Le bus ne peut pas être résolu.

Ajouté dans la version 246.

-EINVAL

Un paramètre requis était NULL ou b était zéro et id n'était pas égal à SD_ID128_NULL.

Ajouté dans la version 246.

-ENOTCONN

Le bus n'est pas connecté.

Ajouté dans la version 246.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() que dès la phase initiale du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_set_server(), sd_bus_is_server(), sd_bus_get_bus_id(), sd_bus_set_bus_client(), sd_bus_is_bus_client(), sd_bus_set_monitor(), et sd_bus_is_monitor() ont été ajoutés dans la version 246.
