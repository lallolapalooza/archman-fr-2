SD_BUS_SET_CONNECTED_SIGNAL(3) sd_bus_set_connected_signal SD_BUS_SET_CONNECTED_SIGNAL(3)

NOM

sd_bus_set_connected_signal, sd_bus_get_connected_signal - Contrôler l'émission du signal de connexion locale sur les connexions de bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_set_connected_signal(sd_bus *bus, int b);

int sd_bus_get_connected_signal(sd_bus *bus);

DESCRIPTION

sd_bus_set_connected_signal() peut être utilisée pour contrôler si un message de signal local et synthétique Connected() doit être généré et mis en file d'attente pour être distribué lorsque la connexion est complètement établie. Si le paramètre b est zéro, le message n'est pas généré (par défaut), sinon il est généré.

sd_bus_get_connected_signal() peut être utilisée pour interroger si cette fonctionnalité est activée. Elle renvoie zéro si ce n'est pas le cas, et une valeur positive sinon.

Le message de signal Connected() est généré à partir du service et de l'interface "org.freedesktop.DBus.Local", et du chemin d'objet "/org/freedesktop/DBus/Local". Utilisez sd_bus_match_signal_async(3) pour correspondre à ce signal.

Ce message est particulièrement utile sur les transports lents où les connexions prennent beaucoup de temps à s'établir. C'est particulièrement le cas lorsque sd_bus_set_watch_bind(3) est utilisé. Le signal est généré lorsque sd_bus_is_ready(3) renvoie une valeur positive pour la première fois.

Le signal Connected() correspond au signal Disconnected() qui est synthétisé localement lorsque la connexion est terminée. Ce dernier est généré inconditionnellement, contrairement au premier qui doit être activé explicitement avant d'être généré, avec sd_bus_set_connected_signal().

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient 0 ou un entier positif. En cas d'échec, elles renvoient un code d'erreur négatif de type errno.

Erreurs

Les erreurs renvoyées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion de bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() qu'à partir d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_set_connected_signal() et sd_bus_get_connected_signal() ont été ajoutées dans la version 237.
