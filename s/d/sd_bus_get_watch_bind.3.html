sd_bus_get_watch_bind(3)

SD_BUS_SET_WATCH_BIND(3) sd_bus_set_watch_bind SD_BUS_SET_WATCH_BIND(3)

NOM

sd_bus_set_watch_bind, sd_bus_get_watch_bind - Contrôler la surveillance de la liaison des sockets sur les connexions bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_set_watch_bind(sd_bus *bus, int b);

int sd_bus_get_watch_bind(sd_bus *bus);

DESCRIPTION

sd_bus_set_watch_bind() peut être utilisé pour activer ou désactiver la surveillance côté client de la liaison des sockets du serveur pour un objet de connexion bus. Si b est vrai, la fonctionnalité est activée, sinon elle est désactivée (ce qui est le comportement par défaut). Lorsqu'elle est activée, et que l'adresse bus sélectionnée fait référence à un socket AF_UNIX dans le système de fichiers qui n'existe pas lors de la tentative de connexion, une surveillance inotify(7) est installée sur celui-ci, attendant que le socket apparaisse. Dès que le socket apparaît, la connexion est établie. Cette fonctionnalité est particulièrement utile dans les programmes de démarrage précoce qui doivent s'exécuter avant que le bus système ne soit disponible, mais qui souhaitent s'y connecter dès qu'il est possible de le faire.

sd_bus_get_watch_bind() peut être utilisé pour interroger le paramètre actuel de cette fonctionnalité. Il retourne zéro lorsque la fonctionnalité est désactivée et un nombre positif si elle est activée.

Notez qu'aucun délai d'attente n'est appliqué pendant que nous attendons que le socket apparaisse. Cela signifie que toute opération distante synchrone (telle que sd_bus_call(3), sd_bus_add_match(3) ou sd_bus_request_name(3)), utilisée sur une connexion avec cette fonctionnalité activée qui n'a pas encore été établie, pourrait bloquer indéfiniment si le socket n'est jamais créé. Cependant, les opérations distantes asynchrones (telles que sd_bus_send(3), sd_bus_call_async(3), sd_bus_add_match_async(3)) ne bloquent pas dans ce cas, et mettent en file d'attente de manière sûre les opérations demandées pour qu'elles soient distribuées dès que la connexion est établie.

Utilisez sd_bus_is_ready(3) pour déterminer si la connexion est entièrement établie, c'est-à-dire si le socket pair a été lié, connecté et authentifié. Utilisez sd_bus_set_connected_signal(3) pour être notifié lorsque la connexion est entièrement établie.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ou un entier positif. En cas d'échec, elles retournent un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-ECHILD

La connexion bus a été créée dans un processus, une bibliothèque ou une instance de module différent.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier libsystemd pkg-config(1).

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas sûr pour les threads multiples. Cela signifie que le code qui appelle les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() qu'à partir d'une phase précoce du programme, lorsqu'aucun autre thread n'a encore été démarré.

EXEMPLE

Exemple 1. Créer un service système simple qui publie une propriété sur le bus système et peut se reconnecter lorsque D-Bus se déconnecte et se reconnecte

/* SPDX-License-Identifier: MIT-0 */
/* Un service D-Bus qui se reconnecte automatiquement lorsque le bus système est
 * redémarré.
 *
 * Compiler avec 'cc sd_bus_service_reconnect.c $(pkg-config --libs --cflags libsystemd)'
 *
 * Pour permettre au programme de prendre possession du nom 'org.freedesktop.ReconnectExample',
 * ajoutez ce qui suit dans /etc/dbus-1/system.d/org.freedesktop.ReconnectExample.conf
 * puis rechargez le courtier avec 'systemctl reload dbus' :
<?xml version="1.0"?> <!--*-nxml-*-->
<!DOCTYPE busconfig PUBLIC "-//freedesktop//DTD D-BUS Bus Configuration 1.0//EN"
  "http://www.freedesktop.org/standards/dbus/1.0/busconfig.dtd">
<busconfig>
  <policy user="root">
    <allow own="org.freedesktop.ReconnectExample"/>
    <allow send_destination="org.freedesktop.ReconnectExample"/>
    <allow receive_sender="org.freedesktop.ReconnectExample"/>
  </policy>
  <policy context="default">
    <allow send_destination="org.freedesktop.ReconnectExample"/>
    <allow receive_sender="org.freedesktop.ReconnectExample"/>
  </policy>
</busconfig>
 *
 * Pour obtenir la propriété via busctl :
 *
 * $ busctl --user get-property org.freedesktop.ReconnectExample \
 *                              /org/freedesktop/ReconnectExample \
 *                              org.freedesktop.ReconnectExample \
 *                              Example
 * s "example"
 */
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
#include <systemd/sd-bus.h>
#define _cleanup_(f) __attribute__((cleanup(f)))
static int log_error(int r, const char *str) {
  fprintf(stderr, "%s a échoué : %s\n", str, strerror(-r));
  return r;
}
typedef struct object {
  const char *example;
  sd_bus **bus;
  sd_event **event;
} object;
static int property_get(
                sd_bus *bus,
                const char *path,
                const char *interface,
                const char *property,
                sd_bus_message *reply,
                void *userdata,
                sd_bus_error *error) {
  object *o = userdata;
  if (strcmp(property, "Example") == 0)
    return sd_bus_message_append(reply, "s", o->example);
  return sd_bus_error_setf(error,
                           SD_BUS_ERROR_UNKNOWN_PROPERTY,
                           "Propriété inconnue '%s'",
                           property);
}
/* https://www.freedesktop.org/software/systemd/man/sd_bus_add_object.html */
static const sd_bus_vtable vtable[] = {
  SD_BUS_VTABLE_START(0),
  SD_BUS_PROPERTY(
    "Example", "s",
    property_get,
    0,
    SD_BUS_VTABLE_PROPERTY_CONST),
  SD_BUS_VTABLE_END
};
static int setup(object *o);
static int on_disconnect(sd_bus_message *message, void *userdata, sd_bus_error *ret_error) {
  int r;
  r = setup((object *)userdata);
  if (r < 0) {
    object *o = userdata;
    r = sd_event_exit(*o->event, r);
    if (r < 0)
      return log_error(r, "sd_event_exit()");
  }
  return 1;
}
/* S'assurer que la boucle d'événements se termine avec une erreur claire si l'acquisition du nom de service bien connu échoue */
static int request_name_callback(sd_bus_message *m, void *userdata, sd_bus_error *ret_error) {
  int r;
  if (!sd_bus_message_is_method_error(m, NULL))
    return 1;
  const sd_bus_error *error = sd_bus_message_get_error(m);
  if (sd_bus_error_has_names(error, SD_BUS_ERROR_TIMEOUT, SD_BUS_ERROR_NO_REPLY))
    return 1; /* Le bus n'est pas disponible, réessayez plus tard */
  fprintf(stderr, "Échec de la demande de nom : %s\n", error->message);
  object *o = userdata;
  r = sd_event_exit(*o->event, -sd_bus_error_get_errno(error));
  if (r < 0)
    return log_error(r, "sd_event_exit()");
  return 1;
}
static int setup(object *o) {
  int r;
  /* Si nous nous reconnectons, l'objet bus doit être fermé, détaché
   * de la boucle d'événements et recréé.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_detach_event.html
   * https://www.freedesktop.org/software/systemd/man/sd_bus_close_unref.html
   */
  if (*o->bus) {
    r = sd_bus_detach_event(*o->bus);
    if (r < 0)
      return log_error(r, "sd_bus_detach_event()");
    *o->bus = sd_bus_close_unref(*o->bus);
  }
  /* Configurer un nouvel objet bus pour le bus système, le configurer pour attendre que D-Bus
   * soit disponible au lieu d'échouer s'il ne l'est pas, et le démarrer. Toutes les
   * opérations suivantes sont asynchrones et ne bloqueront pas en attendant que D-Bus
   * soit disponible.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_new.html
   * https://www.freedesktop.org/software/systemd/man/sd_bus_set_address.html
   * https://www.freedesktop.org/software/systemd/man/sd_bus_set_bus_client.html
   * https://www.freedesktop.org/software/systemd/man/sd_bus_negotiate_creds.html
   * https://www.freedesktop.org/software/systemd/man/sd_bus_set_watch_bind.html
   * https://www.freedesktop.org/software/systemd/man/sd_bus_set_connected_signal.html
   * https://www.freedesktop.org/software/systemd/man/sd_bus_start.html
   */
  r 
= sd_bus_new(o->bus);
  si r < 0
    retourner log_error(r, "sd_bus_new()");
  r = sd_bus_set_address(*o->bus, "unix:path=/run/dbus/system_bus_socket");
  si r < 0
    retourner log_error(r, "sd_bus_set_address()");
  r = sd_bus_set_bus_client(*o->bus, 1);
  si r < 0
    retourner log_error(r, "sd_bus_set_bus_client()");
  r = sd_bus_negotiate_creds(*o->bus, 1, SD_BUS_CREDS_UID|SD_BUS_CREDS_EUID|SD_BUS_CREDS_EFFECTIVE_CAPS);
  si r < 0
    retourner log_error(r, "sd_bus_negotiate_creds()");
  r = sd_bus_set_watch_bind(*o->bus, 1);
  si r < 0
    retourner log_error(r, "sd_bus_set_watch_bind()");
  r = sd_bus_start(*o->bus);
  si r < 0
    retourner log_error(r, "sd_bus_start()");
  /* Publier une interface sur le bus, en spécifiant notre chemin d'accès objet connu
   * et le nom de l'interface publique.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_add_object.html
   * https://dbus.freedesktop.org/doc/dbus-tutorial.html
   */
  r = sd_bus_add_object_vtable(*o->bus,
                               NULL,
                               "/org/freedesktop/ReconnectExample",
                               "org.freedesktop.ReconnectExample",
                               vtable,
                               o);
  si r < 0
    retourner log_error(r, "sd_bus_add_object_vtable()");
  /* Par défaut, le service se voit attribuer un nom éphémère. Ajoutez également un
   * nom bien connu, afin que les clients sachent qui appeler. Cela doit être
   * asynchrone, car D-Bus pourrait ne pas être encore disponible. Le rappel vérifiera
   * si l'erreur est attendue ou non, en cas d'échec.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_request_name.html
   */
  r = sd_bus_request_name_async(*o->bus,
                                NULL,
                                "org.freedesktop.ReconnectExample",
                                0,
                                request_name_callback,
                                o);
  si r < 0
    retourner log_error(r, "sd_bus_request_name_async()");
  /* Lorsque D-Bus est déconnecté, ce rappel sera invoqué, ce qui réinitialisera
   * la connexion. Cela doit être asynchrone, car D-Bus pourrait ne pas être encore
   * disponible.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_match_signal_async.html
   */
  r = sd_bus_match_signal_async(*o->bus,
                                NULL,
                                "org.freedesktop.DBus.Local",
                                NULL,
                                "org.freedesktop.DBus.Local",
                                "Disconnected",
                                on_disconnect,
                                NULL,
                                o);
  si r < 0
    retourner log_error(r, "sd_bus_match_signal_async()");
  /* Attacher l'objet bus à la boucle d'événements afin que les appels et les signaux soient
   * traités.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_attach_event.html
   */
  r = sd_bus_attach_event(*o->bus, *o->event, 0);
  si r < 0
    retourner log_error(r, "sd_bus_attach_event()");
  retourner 0;
}
int main(int argc, char **argv) {
  /* Le bus doit être libéré avant que le programme ne se termine. L'attribut cleanup
   * nous permet de le faire proprement et proprement chaque fois que nous quittons le bloc.
   */
  _cleanup_(sd_bus_flush_close_unrefp) sd_bus *bus = NULL;
  _cleanup_(sd_event_unrefp) sd_event *event = NULL;
  object o = {
    .example = "example",
    .bus = &bus,
    .event = &event,
  };
  int r;
  /* Créer une structure de données de boucle d'événements, avec des paramètres par défaut.
   * https://www.freedesktop.org/software/systemd/man/sd_event_default.html
   */
  r = sd_event_default(&event);
  si r < 0
    retourner log_error(r, "sd_event_default()");
  /* Par défaut, la boucle d'événements se terminera lorsque toutes les sources auront disparu,
   * nous devons donc la maintenir 'occupée'. Enregistrer la gestion des signaux pour ce faire.
   * https://www.freedesktop.org/software/systemd/man/sd_event_add_signal.html
   */
  r = sd_event_add_signal(event, NULL, SIGINT|SD_EVENT_SIGNAL_PROCMASK, NULL, NULL);
  si r < 0
    retourner log_error(r, "sd_event_add_signal(SIGINT)");
  r = sd_event_add_signal(event, NULL, SIGTERM|SD_EVENT_SIGNAL_PROCMASK, NULL, NULL);
  si r < 0
    retourner log_error(r, "sd_event_add_signal(SIGTERM)");
  r = setup(&o);
  si r < 0
    retourner EXIT_FAILURE;
  /* Entrer dans la boucle principale, elle ne se terminera que sur sigint/sigterm.
   * https://www.freedesktop.org/software/systemd/man/sd_event_loop.html
   */
  r = sd_event_loop(event);
  si r < 0
    retourner log_error(r, "sd_event_loop()");
  /* https://www.freedesktop.org/software/systemd/man/sd_bus_release_name.html */
  r = sd_bus_release_name(bus, "org.freedesktop.ReconnectExample");
  si r < 0
    retourner log_error(r, "sd_bus_release_name()");
  retourner 0;
}

Ceci est particulièrement utile pour les services configurés pour survivre à un redémarrage logiciel, voir systemd-soft-reboot.service(8) pour plus d'informations.
