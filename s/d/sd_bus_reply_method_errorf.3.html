sd_bus_reply_method_errorf(3)

SD_BUS_REPLY_METHOD_ERROR(3) sd_bus_reply_method_error SD_BUS_REPLY_METHOD_ERROR(3)

NOM

sd_bus_reply_method_error, sd_bus_reply_method_errorf, sd_bus_reply_method_errorfv, sd_bus_reply_method_errno, sd_bus_reply_method_errnof, sd_bus_reply_method_errnofv - Répondre avec une erreur à un appel de méthode D-Bus

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_reply_method_error(sd_bus_message *call, const sd_bus_error *e);

int sd_bus_reply_method_errorf(sd_bus_message *call, const char *name, const char *format, ...);

int sd_bus_reply_method_errorfv(sd_bus_message *call, const char *name, const char *format, va_list ap);

int sd_bus_reply_method_errno(sd_bus_message *call, int error, const sd_bus_error *p);

int sd_bus_reply_method_errnof(sd_bus_message *call, int error, const char *format, ...);

int sd_bus_reply_method_errnofv(sd_bus_message *call, int error, const char *format, va_list ap);

DESCRIPTION

La fonction sd_bus_reply_method_error() envoie une réponse d'erreur au message call. La structure d'erreur e spécifie l'erreur à envoyer et est utilisée comme décrit dans sd_bus_message_new_method_error(3). Si aucune réponse n'est attendue pour call, cette fonction réussit sans envoyer de réponse.

sd_bus_reply_method_errorf() est à sd_bus_reply_method_error() ce que sd_bus_message_new_method_errorf() est à sd_bus_message_new_method_error().

sd_bus_reply_method_errno() est à sd_bus_reply_method_error() ce que sd_bus_message_new_method_errno() est à sd_bus_message_new_method_error().

sd_bus_reply_method_errnof() est à sd_bus_reply_method_error() ce que sd_bus_message_new_method_errnof() est à sd_bus_message_new_method_error().

VALEUR DE RETOUR

Cette fonction retourne un entier non négatif si la réponse d'erreur a été envoyée avec succès ou si call n'attend pas de réponse. En cas d'échec, elle retourne un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre d'entrée call est NULL.

Le message call n'est pas un message d'appel de méthode.

Le message call n'est pas attaché à un bus.

Le paramètre d'erreur e de sd_bus_reply_method_error() n'est pas défini, voir sd_bus_error_is_set(3).

-EPERM

Le message call a été scellé.

-ENOTCONN

Le bus auquel le message call est attaché n'est pas connecté.

-ENOMEM

Échec de l'allocation mémoire.

De plus, toute erreur retournée par sd_bus_send(3) peut être retournée.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme n'étant pas thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de ne faire des appels à setenv() qu'à partir d'une phase précoce du programme lorsque aucun autre thread n'a été démarré.
