SD_SESSION_IS_ACTIVE(3) sd_session_is_active SD_SESSION_IS_ACTIVE(3)

NOM

sd_session_is_active, sd_session_is_remote, sd_session_get_state, sd_session_get_uid, sd_session_get_username, sd_session_get_seat, sd_session_get_start_time, sd_session_get_service, sd_session_get_type, sd_session_get_class, sd_session_get_desktop, sd_session_get_display, sd_session_get_tty, sd_session_get_vt, sd_session_get_remote_host, sd_session_get_remote_user, sd_session_get_leader - Déterminer l'état d'une session spécifique

SYNOPIS

#include <systemd/sd-login.h>

int sd_session_is_active(const char *session);

int sd_session_is_remote(const char *session);

int sd_session_get_state(const char *session, char **state);

int sd_session_get_uid(const char *session, uid_t *uid);

int sd_session_get_username(const char *session, char **username);

int sd_session_get_seat(const char *session, char **seat);

int sd_session_get_start_time(const char *session, uint64_t *usec);

int sd_session_get_service(const char *session, char **service);

int sd_session_get_type(const char *session, char **type);

int sd_session_get_class(const char *session, char **class);

int sd_session_get_desktop(const char *session, char **desktop);

int sd_session_get_display(const char *session, char **display);

int sd_session_get_leader(const char *session, pid_t *leader);

int sd_session_get_remote_host(const char *session, char **remote_host);

int sd_session_get_remote_user(const char *session, char **remote_user);

int sd_session_get_tty(const char *session, char **tty);

int sd_session_get_vt(const char *session, unsigned int *vt);

DESCRIPTION

sd_session_is_active() peut être utilisé pour déterminer si la session identifiée par l'identifiant de session spécifié est actuellement active (c'est-à-dire, actuellement au premier plan et disponible pour une entrée utilisateur) ou non.

sd_session_is_remote() peut être utilisé pour déterminer si la session identifiée par l'identifiant de session spécifié est une session à distance (c'est-à-dire, si son hôte distant est connu) ou non.

sd_session_get_state() peut être utilisé pour déterminer l'état de la session identifiée par l'identifiant de session spécifié. Les états suivants sont actuellement connus : « online » (session connectée, mais session pas active, c'est-à-dire pas au premier plan), « active » (session connectée et active, c'est-à-dire au premier plan), « closing » (session nominalement déconnectée, mais certains processus lui appartenant sont toujours présents). D'autres états pourraient être définis à l'avenir, le code client devrait être écrit pour être robuste face à des chaînes d'état supplémentaires retournées. Cette fonction est une version plus générique de sd_session_is_active(). La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_uid() peut être utilisé pour déterminer l'identifiant d'utilisateur de l'utilisateur Unix auquel appartient la session identifiée par l'identifiant de session spécifié.

sd_session_get_username() peut être utilisé pour déterminer le nom de l'utilisateur Unix auquel appartient la session identifiée par l'identifiant de session spécifié. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_seat() peut être utilisé pour déterminer l'identifiant du siège auquel appartient la session identifiée par l'identifiant de session spécifié. Notez que toutes les sessions ne sont pas attachées à un siège, cet appel échouera (retournant -ENODATA) pour elles. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_start_time() peut être utilisé pour déterminer l'heure de début de la session identifiée par l'identifiant de session spécifié. Le paramètre usec est en microsecondes depuis l'époque (CLOCK_REALTIME).

sd_session_get_service() peut être utilisé pour déterminer le nom du service (tel que passé lors de la configuration de session PAM) qui a enregistré la session identifiée par l'identifiant de session spécifié. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_type() peut être utilisé pour déterminer le type de la session identifiée par l'identifiant de session spécifié. La chaîne retournée est l'une des suivantes : « x11 », « wayland », « tty », « mir » ou « unspecified » et doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_class() peut être utilisé pour déterminer la classe de la session identifiée par l'identifiant de session spécifié. La chaîne retournée est l'une des suivantes : « user », « user-early », « user-light », « user-early-light », « user-incomplete », « greeter », « lock-screen », « background », « background-light », « manager » ou « manager-early » et doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_desktop() peut être utilisé pour déterminer la marque du bureau en cours d'exécution sur la session identifiée par l'identifiant de session spécifié. Ce champ peut être défini librement par les environnements de bureau et ne suit aucune format spécial. Cependant, il est fortement recommandé aux environnements de bureau d'utiliser les mêmes identifiants et la même capitalisation que pour $XDG_CURRENT_DESKTOP, tels que définis dans la Desktop Entry Specification[1]. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_display() peut être utilisé pour déterminer l'affichage X11 de la session identifiée par l'identifiant de session spécifié. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_leader() peut être utilisé pour déterminer le PID du leader de la session identifiée par l'identifiant de session spécifié.

sd_session_get_remote_host() peut être utilisé pour déterminer le nom d'hôte distant de la session identifiée par l'identifiant de session spécifié. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_remote_user() peut être utilisé pour déterminer le nom d'utilisateur distant de la session identifiée par l'identifiant de session spécifié. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation. Notez que cette valeur est rarement connue du système, et même lorsqu'elle l'est, il ne faut pas s'y fier.

sd_session_get_tty() peut être utilisé pour déterminer le périphérique TTY de la session identifiée par l'identifiant de session spécifié. La chaîne retournée doit être libérée avec l'appel free(3) de la libc après utilisation.

sd_session_get_vt() peut être utilisé pour déterminer le numéro de VT de la session identifiée par l'identifiant de session spécifié. Cette fonction retournera une erreur si le siège ne prend pas en charge les VT.

Si le paramètre session de l'une de ces fonctions est passé comme NULL, l'opération est exécutée pour la session dont le processus appelant est membre, s'il y en a une.

VALEUR DE RETOUR

NAME

sd_session_get_display, sd_session_get_desktop, sd_session_get_service, sd_session_get_scope, sd_session_get_seat, sd_session_get_tty, sd_session_get_vt, sd_session_get_remote_user, sd_session_get_remote_host, sd_session_get_remote_address, sd_session_get_service_pid, sd_session_get_unit, sd_session_get_slice, sd_session_get_state, sd_session_get_id, sd_session_get_name, sd_session_get_user, sd_session_get_uid, sd_session_get_gid, sd_session_get_start_time, sd_session_get_leader — Récupérer des informations sur une session

#include <systemd/sd-login.h>

int sd_session_get_display(const char *session_id, char **display);
int sd_session_get_desktop(const char *session_id, char **desktop);

int sd_session_get_scope(const char *session_id, char **scope);

int sd_session_get_tty(const char *session_id, char **tty);

int sd_session_get_remote_host(const char *session_id, char **host);
int sd_session_get_remote_address(const char *session_id, char **address);
int sd_session_get_service_pid(const char *session_id, pid_t *pid);
int sd_session_get_unit(const char *session_id, char **unit);

int sd_session_get_start_time(const char *session_id, struct timespec *ts);
int sd_session_get_leader(const char *session_id, pid_t *pid);

DESCRIPTION

The session functions allow querying information about user sessions. The session ID is a string, often derived from the SESSION environment variable, that uniquely identifies a session.

sd_session_get_display() retrieves the display name (e.g., ":0") for the session. sd_session_get_desktop() retrieves the desktop name (e.g., "GNOME") for the session. sd_session_get_service() retrieves the name of the login service (e.g., "login" or "sshd") that created the session. sd_session_get_scope() retrieves the systemd scope unit name associated with the session. sd_session_get_seat() retrieves the seat name (e.g., "seat0") associated with the session. sd_session_get_tty() retrieves the TTY name (e.g., "tty1") for the session. sd_session_get_vt() retrieves the virtual terminal number for the session. sd_session_get_remote_user() retrieves the username of the remote user if the session is remote. sd_session_get_remote_host() retrieves the hostname of the remote host if the session is remote. sd_session_get_remote_address() retrieves the IP address of the remote host if the session is remote. sd_session_get_service_pid() retrieves the PID of the login service that created the session. sd_session_get_unit() retrieves the systemd system unit name associated with the session. sd_session_get_slice() retrieves the systemd slice unit name associated with the session. sd_session_get_state() retrieves the state of the session (e.g., "active", "closing"). sd_session_get_id() retrieves the session ID for a given PID. sd_session_get_name() retrieves the session name for a given PID. sd_session_get_user() retrieves the username associated with the session. sd_session_get_uid() retrieves the UID associated with the session. sd_session_get_gid() retrieves the GID associated with the session. sd_session_get_start_time() retrieves the session start time. sd_session_get_leader() retrieves the PID of the session leader process.

All these functions allocate memory for the returned string (except for sd_session_get_vt(), sd_session_get_service_pid(), sd_session_get_uid(), sd_session_get_gid(), sd_session_get_start_time() and sd_session_get_leader()) which must be freed by the caller using free(3). If the return value is 0 or positive, the output parameter is set. If the output parameter is not needed, it may be passed as NULL.

RETURN VALUE

sd_session_get_display(), sd_session_get_desktop(), sd_session_get_service(), sd_session_get_scope(), sd_session_get_seat(), sd_session_get_tty(), sd_session_get_vt(), sd_session_get_remote_user(), sd_session_get_remote_host(), sd_session_get_remote_address(), sd_session_get_service_pid(), sd_session_get_unit(), sd_session_get_slice(), sd_session_get_state(), sd_session_get_id(), sd_session_get_name(), sd_session_get_user(), sd_session_get_uid(), sd_session_get_gid(), sd_session_get_start_time(), sd_session_get_leader() return 0 or a positive integer. On failure, these calls return a negative errno-style error code.

Errors

Returned errors may indicate the following problems:

-ENXIO

The specified session does not exist.

-ENODATA

The given field is not specified for the described session.

-EINVAL

An input parameter was invalid (out of range, or NULL, where that is not accepted).

-ENOMEM

Memory allocation failed.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
