NOM

sd_bus_add_object_manager - Ajouter un gestionnaire d'objets D-Bus pour un sous-arbre d'objets D-Bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_add_object_manager(sd_bus *bus, sd_bus_slot **slot, const char *path);

DESCRIPTION

sd_bus_add_object_manager() installe un gestionnaire pour le chemin donné qui implémente la méthode GetManagedObjects() de l'interface org.freedesktop.DBus.ObjectManager. Voir org.freedesktop.DBus.ObjectManager[1] pour plus d'informations.

Pour implémenter les signaux InterfacesAdded et InterfacesRemoved de l'interface org.freedesktop.DBus.ObjectManager, appelez sd_bus_emit_interfaces_added(3) et sd_bus_emit_interfaces_removed(3) chaque fois que des interfaces sont ajoutées ou supprimées du sous-arbre, respectivement.

Lorsque sd_bus_add_object_manager() réussit, une slot est créée en interne. Si le paramètre de sortie slot est NULL, un objet de slot "flottant" est créé, voir sd_bus_slot_set_floating(3). Sinon, un pointeur vers l'objet de slot est retourné. Dans ce cas, la référence à l'objet de slot doit être libérée lorsque le gestionnaire d'objets n'est plus nécessaire, voir sd_bus_slot_unref(3).

VALEUR DE RETOUR

En cas de succès, sd_bus_add_object_manager() retourne un entier non négatif. En cas d'échec, elle retourne un code d'erreur négatif de type errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Un des paramètres requis est NULL ou path n'est pas un chemin d'objet valide.

-ENOPKG

Le bus ne peut pas être résolu.

-ECHILD

Le bus a été créé dans un processus, une bibliothèque ou une instance de module différent.

-ENOMEM

Échec de l'allocation mémoire.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme non sûr pour les threads multiples. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) depuis un thread parallèle. Il est recommandé de n'effectuer des appels à setenv() qu'à partir d'une phase précoce du programme, lorsque aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_add_object_manager() a été ajouté dans la version 221.
