SD_BUS_SLOT_SET_FLOATING(3) sd_bus_slot_set_floating SD_BUS_SLOT_SET_FLOATING(3)

NOM

sd_bus_slot_set_floating, sd_bus_slot_get_floating - Contrôler si un objet de slot de bus est « flottant »

SYNTAXE

#include <systemd/sd-bus.h>

int sd_bus_slot_set_floating(sd_bus_slot *slot, int b);

int sd_bus_slot_get_floating(sd_bus_slot *slot);

DESCRIPTION

sd_bus_slot_set_floating() contrôle si l'objet de slot de bus spécifié slot est « flottant » ou non. La durée de vie d'un objet de slot de bus flottant est liée à la durée de vie de l'objet de bus auquel il est associé, ce qui signifie qu'il reste alloué tant que l'objet de bus lui-même et qu'il est libéré automatiquement lorsque l'objet de bus est libéré. Les objets de slot de bus réguliers (c'est-à-dire non flottants) maintiennent une référence sur le bus, de sorte que l'objet de bus reste alloué au moins tant qu'il reste au moins un objet de slot de bus référencé. L'état flottant contrôle donc la direction du référencement entre l'objet de bus et les objets de slot de bus : si flottant, le bus référence le slot, et sinon, le slot référence l'objet de bus. Utilisez sd_bus_slot_set_floating() pour basculer entre les deux modes : si le paramètre b est zéro, le slot est transformé en slot régulier (non flottant), sinon il est transformé en slot flottant.

Les objets de slot de bus peuvent être alloués par des appels tels que sd_bus_add_match(3). Si le slot de ces fonctions est non-NULL, l'objet de slot sera de type régulier (c'est-à-dire non flottant), sinon il sera créé flottant. Avec sd_bus_slot_set_floating(), un objet de slot de bus alloué comme régulier peut être converti en objet flottant et vice-versa. Ceci est particulièrement utile pour créer un objet de slot de bus, puis modifier ses paramètres, et ensuite le transformer en objet flottant, dont le cycle de vie est géré par l'objet de bus.

sd_bus_slot_get_floating() retourne l'état flottant actuel de l'objet de slot de bus spécifié. Il retourne une valeur négative en cas d'erreur, zéro si l'objet de slot de bus est un objet régulier (non flottant) et une valeur positive sinon.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ou un entier positif. En cas d'échec, elles retournent un code d'erreur négatif de style errno.

Erreurs

Les erreurs retournées peuvent indiquer les problèmes suivants :

-EINVAL

Le paramètre slot est NULL.

-ECHILD

La connexion de bus a été créée dans un processus, une bibliothèque ou une instance de module différente.

-ESTALE

L'objet de bus auquel l'objet de slot de bus spécifié est associé a déjà été libéré, et aucun changement d'état flottant ne peut donc plus être effectué.

NOTES

Les fonctions décrites ici sont disponibles sous forme de bibliothèque partagée, qui peut être compilée et liée avec le fichier pkg-config(1) de libsystemd.

Le code décrit ici utilise getenv(3), qui est déclaré comme non thread-safe. Cela signifie que le code appelant les fonctions décrites ici ne doit pas appeler setenv(3) à partir d'un thread parallèle. Il est recommandé de n'appeler setenv() qu'à une phase précoce du programme, lorsqu'aucun autre thread n'a été démarré.

HISTORIQUE

sd_bus_slot_set_floating() et sd_bus_slot_get_floating() ont été ajoutés dans la version 239.
