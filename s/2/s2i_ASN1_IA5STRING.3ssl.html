s2i_ASN1_IA5STRING(3ssl)

S2I_ASN1_IA5STRING(3ssl) OpenSSL S2I_ASN1_IA5STRING(3ssl)

NOM

i2s_ASN1_IA5STRING, s2i_ASN1_IA5STRING, i2s_ASN1_INTEGER, s2i_ASN1_INTEGER, i2s_ASN1_OCTET_STRING, s2i_ASN1_OCTET_STRING, i2s_ASN1_ENUMERATED, i2s_ASN1_ENUMERATED_TABLE, i2s_ASN1_UTF8STRING, s2i_ASN1_UTF8STRING - convertir des objets depuis/vers leur représentation ASN.1/chaîne de caractères

SYNTAXE

#include <openssl/x509v3.h>
char *i2s_ASN1_IA5STRING(X509V3_EXT_METHOD *method, ASN1_IA5STRING *ia5);
ASN1_IA5STRING *s2i_ASN1_IA5STRING(X509V3_EXT_METHOD *method,
                                  X509V3_CTX *ctx, const char *str);
char *i2s_ASN1_INTEGER(X509V3_EXT_METHOD *method, const ASN1_INTEGER *a);
ASN1_INTEGER *s2i_ASN1_INTEGER(X509V3_EXT_METHOD *method, const char *value);
char *i2s_ASN1_OCTET_STRING(X509V3_EXT_METHOD *method,
                           const ASN1_OCTET_STRING *oct);
ASN1_OCTET_STRING *s2i_ASN1_OCTET_STRING(X509V3_EXT_METHOD *method,
                                        X509V3_CTX *ctx, const char *str);
char *i2s_ASN1_ENUMERATED(X509V3_EXT_METHOD *method, const ASN1_ENUMERATED *a);
char *i2s_ASN1_ENUMERATED_TABLE(X509V3_EXT_METHOD *method,
                               const ASN1_ENUMERATED *e);
char *i2s_ASN1_UTF8STRING(X509V3_EXT_METHOD *method,
                          ASN1_UTF8STRING *utf8);
ASN1_UTF8STRING *s2i_ASN1_UTF8STRING(X509V3_EXT_METHOD *method,
                                     X509V3_CTX *ctx, const char *str);

DESCRIPTION

Ces fonctions convertissent les objets OpenSSL vers et depuis leur représentation ASN.1/chaîne de caractères. Cette fonction est utilisée pour les extensions X509v3.

NOTES

Les lettres i et s dans i2s et s2i signifient respectivement « internal » (interne, c'est-à-dire une structure C interne) et « string » (chaîne de caractères). Ainsi, i2s_ASN1_IA5STRING() convertit de l'interne vers la chaîne.

Il incombe à l'appelant de libérer la chaîne retournée. Dans la fonction i2s_ASN1_IA5STRING(), la chaîne est copiée et la propriété de la chaîne d'origine reste à l'appelant.

VALEURS DE RETOUR

i2s_ASN1_IA5STRING() retourne un pointeur vers une chaîne IA5 ou NULL si une erreur survient.

s2i_ASN1_IA5STRING() retourne une structure ASN1_IA5STRING valide ou NULL si une erreur survient.

i2s_ASN1_INTEGER() retourne une chaîne valide ou NULL si une erreur survient.

s2i_ASN1_INTEGER() retourne un pointeur vers une structure ASN1_INTEGER ou NULL si une erreur survient.

i2s_ASN1_OCTET_STRING() retourne un pointeur vers une chaîne OCTET_STRING ou NULL si une erreur survient.

s2i_ASN1_OCTET_STRING() retourne une structure ASN1_OCTET_STRING valide ou NULL si une erreur survient.

i2s_ASN1_ENUMERATED() retourne une chaîne valide ou NULL si une erreur survient.

s2i_ASN1_ENUMERATED() retourne un pointeur vers une structure ASN1_ENUMERATED ou NULL si une erreur survient.

s2i_ASN1_UTF8STRING() retourne une structure ASN1_UTF8STRING valide ou NULL si une erreur survient.

i2s_ASN1_UTF8STRING() retourne un pointeur vers une chaîne UTF-8 ou NULL si une erreur survient.

HISTORIQUE

i2s_ASN1_UTF8STRING() et s2i_ASN1_UTF8STRING() ont été rendus publics dans OpenSSL 3.0.
