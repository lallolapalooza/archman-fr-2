NOM

skopeo-generate-sigstore-key - Générer une paire de clés publique/privée sigstore.

SYNTAXE

skopeo generate-sigstore-key [options] --output-prefix préfixe

DESCRIPTION

Génère une paire de clés publique/privée adaptée à la création de signatures d'images sigstore. La clé privée est chiffrée avec une phrase secrète ; si aucune n'est fournie via une option, cette commande la demandera interactivement.

La clé privée est écrite dans préfixe.private. La clé publique est écrite dans préfixe.pub.

OPTIONS

Voir aussi skopeo(1) pour les options placées avant le nom de la sous-commande.

--help, -h

Affiche le message d'utilisation

--output-prefix préfixe

Obligatoire. Préfixe du chemin pour les clés de sortie (préfixe.private et préfixe.pub).

--passphrase-file chemin

La phrase secrète à utiliser pour chiffrer la clé privée. Seule la première ligne sera lue. Une phrase secrète stockée dans un fichier est d'une sécurité discutable si d'autres utilisateurs peuvent lire ce fichier. N'utilisez pas cette option si cela peut être évité.

EXEMPLES

$ skopeo generate-sigstore-key --output-prefix ma_cle
