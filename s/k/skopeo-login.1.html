NOM

skopeo-login - Connexion à un registre de conteneurs.

SYNTAXE

skopeo login [options] registre

DESCRIPTION

skopeo login se connecte à un serveur de registre spécifié avec le nom d'utilisateur et le mot de passe corrects. skopeo login lit le nom d'utilisateur et le mot de passe depuis STDIN. Le nom d'utilisateur et le mot de passe peuvent également être définis à l'aide des options username et password. Le chemin du fichier d'informations d'identification peut être spécifié par l'utilisateur en définissant l'option authfile.

OPTIONS

Voir aussi skopeo(1) pour les options placées avant le nom de la sous-commande.

--password, -p=motdepasse

Mot de passe pour le registre

--password-stdin

Prendre le mot de passe depuis stdin

--username, -u=nomutilisateur

Nom d'utilisateur pour le registre

--authfile=chemin

Chemin du fichier d'informations d'identification du registre géré. Sur Linux, la valeur par défaut est ${XDG_RUNTIME_DIR}/containers/auth.json. Voir containers-auth.json(5) pour plus de détails sur la valeur par défaut sur d'autres plates-formes.

La valeur par défaut de cette option est lue à partir de la variable d'environnement REGISTRY\_AUTH\_FILE.

--compat-auth-file=chemin

Au lieu de mettre à jour le fichier d'informations d'identification par défaut, mettez à jour celui situé dans chemin et utilisez un format compatible avec Docker.

--get-login

Retourne l'utilisateur connecté pour le registre. Retourne une erreur si aucune connexion n'est trouvée.

--cert-dir=chemin

Utiliser les certificats situés dans chemin (*.crt, *.cert, *.key) pour se connecter au registre. Le répertoire de certificats par défaut est /etc/containers/certs.d.

--help, -h

Affiche le message d'utilisation

--tls-verify=booléen

Exiger HTTPS et vérifier les certificats lors de la communication avec le registre ou le démon de conteneur. Par défaut, utilise le paramètre de registry.conf.

--verbose, -v

Écrire des informations plus détaillées sur stdout

EXEMPLES

$ skopeo login docker.io
Nom d'utilisateur : testuser
Mot de passe :
Connexion réussie !
$ skopeo login -u testuser -p motdepasetest localhost:5000
Connexion réussie !
$ skopeo login --authfile authdir/myauths.json docker.io
Nom d'utilisateur : testuser
Mot de passe :
Connexion réussie !
$ skopeo login --tls-verify=false -u test -p test localhost:5000
Connexion réussie !
$ skopeo login --cert-dir /etc/containers/certs.d/ -u foo -p bar localhost:5000
Connexion réussie !
$ skopeo login -u testuser  --password-stdin < testmotdepasse.txt docker.io
Connexion réussie !
$ echo $testmotdepasse | skopeo login -u testuser --password-stdin docker.io
Connexion réussie !
