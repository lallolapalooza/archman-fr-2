NOM

skopeo standalone-sign - Outil de débogage - Signer une image localement sans téléversement.

SYNTAXE

skopeo standalone-sign [options] manifest docker-reference key-fingerprint --output|-o signature

DESCRIPTION

Il s'agit principalement d'un outil de débogage, utile pour des cas spéciaux, et ne devrait généralement pas faire partie de votre flux de travail opérationnel normal ; utilisez skopeo copy --sign-by à la place pour publier et signer une image en une seule étape.

manifest Chemin d'accès à un fichier contenant le manifeste de l'image

docker-reference Une référence docker pour identifier l'image avec

key-fingerprint Identité de clé à utiliser pour la signature

OPTIONS

Voir également skopeo(1) pour les options placées avant le nom de sous-commande.

--help, -h

Afficher le message d'utilisation

--output, -o fichier de sortie

Écrire la signature dans le fichier de sortie.

--passphrase-file=chemin

La phrase de passe à utiliser lors de la signature avec l'ID de clé de --sign-by. Seule la première ligne sera lue. Une phrase de passe stockée dans un fichier présente une sécurité discutable si d'autres utilisateurs peuvent lire ce fichier. N'utilisez pas cette option si cela peut être évité.

EXEMPLES

$ skopeo standalone-sign busybox-manifest.json registry.example.com/example/busybox 1D8230F6CDB6A06716E414C1DB72F2188BB46CC8 --output busybox.signature
$

NOTES

Cette commande est destinée à être utilisée avec des signatures locales, par exemple OpenPGP (d'autres formats de signature pourront être ajoutés à l'avenir), conformément à containers-signature(5). De plus, cette commande n'interagit **pas** avec les artefacts générés par Docker Content Trust (DCT). Pour plus d'informations, veuillez consulter containers-signature(5) ⟨https://github.com/containers/image/blob/main/docs/containers-signature.5.md⟩.
