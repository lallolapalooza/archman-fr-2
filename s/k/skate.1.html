SKATE(1) Skate, un magasin clé-valeur personnel. SKATE(1)

NOM

skate - Skate, un magasin clé-valeur personnel.

SYNTAXE

skate [options...] [argument...]

DESCRIPTION

COMMANDES

supprimer CLÉ[@DB]
Supprime une clé avec une base de données @ optionnelle.
supprimer-db [@DB]
Supprime une base de données
obtenir CLÉ[@DB]
Obtient une valeur pour une clé avec une base de données @ optionnelle.
OPTIONS
--b --afficher-binaire imprime les valeurs binaires
aide [commande]
Aide sur n'importe quelle commande
lister [@DB]
Liste les paires clé-valeur avec une base de données @ optionnelle.
OPTIONS
--d --delimiteur délimiteur pour séparer les clés et les valeurs
--k --clés-seulement
imprime seulement les clés et ne récupère pas les valeurs de la base de données
--r --inversé
liste en ordre lexicographique inversé
--b --afficher-binaire
imprime les valeurs binaires
--v --valeurs-seulement
imprime seulement les valeurs
lister-dbs
Liste les bases de données.
définir CLÉ[@DB] [VALEUR]
Définit une valeur pour une clé avec une base de données @ optionnelle. Si VALEUR est omis, lit la valeur depuis l'entrée standard.
