NOM

sk-tmux - ouvrir sk dans un panneau divisé tmux

SYNTAXE

sk-tmux [-u|-d [HEIGHT[%]]] [-l|-r [WIDTH[%]]] [--] [OPTIONS sk]

DESCRIPTION

sk-tmux est un script d'enveloppement pour sk qui ouvre sk dans un panneau divisé tmux. Il est conçu pour fonctionner comme sk, sauf qu'il ne prend pas tout l'écran. Vous pouvez utiliser sk-tmux en toute sécurité à la place de sk dans vos scripts car les options supplémentaires seront ignorées silencieusement si vous n'êtes pas sur tmux.

OPTIONS

Disposition

(défaut : -d 50%)

-u [hauteur[%]]
Diviser au-dessus (vers le haut)
-d [hauteur[%]]
Diviser en dessous (vers le bas)
-l [largeur[%]]
Diviser à gauche
-r [largeur[%]]
Diviser à droite
