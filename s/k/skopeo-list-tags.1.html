NOM

skopeo-list-tags - Lister les noms d'images dans une collection d'images spécifique au transport.

SYNTAXE

skopeo list-tags [options] image-source

Retourne une liste d'étiquettes depuis image-source dans un registre ou un fichier docker-archive local.

image-source nom du dépôt à partir duquel récupérer une liste d'étiquettes ou un fichier docker-archive local.

OPTIONS

Voir aussi skopeo(1) pour les options placées avant le nom de la sous-commande.

--authfile chemin

Chemin du fichier de credentials de registre mis à jour. Sur Linux, la valeur par défaut est ${XDG_RUNTIME_DIR}/containers/auth.json. Voir containers-auth.json(5) pour plus de détails sur le mécanisme de recherche de credentials et les valeurs par défaut sur d'autres plateformes.

Utiliser skopeo login pour gérer les credentials.

La valeur par défaut de cette option est lue depuis la variable d'environnement REGISTRY\_AUTH\_FILE.

--creds nomutilisateur[:motdepasse] pour accéder au registre.

--cert-dir chemin

Utiliser les certificats dans chemin (*.crt, *.cert, *.key) pour se connecter au registre.

--help, -h

Imprimer l'énoncé d'utilisation

--no-creds

Accéder au registre anonymement.

--registry-token jeton Bearer

Jeton Bearer pour accéder au registre.

--retry-times

Le nombre de tentatives de réessai.

--retry-delay

Délai fixe entre les tentatives. S'il n'est pas défini (ou défini à 0s), le temps d'attente pour les tentatives augmentera exponentiellement en fonction du nombre d'échecs.

--tls-verify=bool

Exiger HTTPS et vérifier les certificats lors de la communication avec le registre ou le démon de conteneur. Par défaut, utilise le réglage de registry.conf.

--username

Le nom d'utilisateur pour accéder au registre.

--password

Le mot de passe pour accéder au registre.

NOMS DE DÉPOTS

Les noms de dépôts sont des références spécifiques au transport car chaque transport peut avoir son propre concept de "dépôt" et d'"étiquettes".

Cette commande fait référence aux dépôts en utilisant le format transport:détails. Les formats suivants sont pris en charge :

docker://référence-dépôt-docker
Un dépôt dans un registre implémentant la "Docker Registry HTTP API V2".
Une référence-dépôt-docker est de la forme : hôte-registre:port/nom-dépôt qui est similaire à une référence-image mais sans étiquette ni digest autorisés comme dernier composant (par exemple, pas de :latest ou @sha256:xyz)

  Exemples de références-dépôt-docker valides :
    "docker.io/myuser/myrepo"
    "docker.io/nginx"
    "docker.io/library/fedora"
    "localhost:5000/myrepository"
  Exemples de références invalides :
    "docker.io/nginx:latest"
    "docker.io/myuser/myimage:v1.0"
    "docker.io/myuser/myimage@sha256:f48c4cc192f4c3c6a069cb5cca6d0a9e34d6076ba7c214fd0cc3ca60e0af76bb"

**docker-archive:chemin[:référence-docker]
plusieurs images ont été stockées dans un fichier au format docker save.

EXEMPLES

Transport Docker

Pour obtenir la liste des étiquettes dans le dépôt "fedora" du registre docker.io (le nom du dépôt s'étend à "library/fedora" selon la forme canonique du transport docker) :

$ skopeo list-tags docker://docker.io/fedora
{
    "Repository": "docker.io/library/fedora",
    "Tags": [
        "20",
        "21",
        "22",
        "23",
        "24",
        "25",
        "26-modular",
        "26",
        "27",
        "28",
        "29",
        "30",
        "31",
        "32",
        "branched",
        "heisenbug",
        "latest",
        "modular",
        "rawhide"
    ]
}

Pour lister les étiquettes dans un registre docker/distribution hôte local sur le port 5000, dans ce cas pour le dépôt "fedora" :

$ skopeo list-tags docker://localhost:5000/fedora
{
    "Repository": "localhost:5000/fedora",
    "Tags": [
        "latest",
        "30",
        "31"
    ]
}

Transport Docker-archive

Pour lister les étiquettes dans un fichier docker-archive local :

$ skopeo list-tags docker-archive:/tmp/busybox.tar.gz
{
    "Tags": [
        "busybox:1.28.3"
    ]
}

Prend également en charge plusieurs étiquettes dans une archive :

$ skopeo list-tags docker-archive:/tmp/docker-two-images.tar.gz
{
    "Tags": [
        "example.com/empty:latest",
        "example.com/empty/but:different"
    ]
}

Inclura une entrée source-index pour chaque image sans étiquette :

$ skopeo list-tags docker-archive:/tmp/four-tags-with-an-untag.tar
{
    "Tags": [
        "image1:tag1",
        "image2:tag2",
        "@2",
        "image4:tag4"
    ]
}
