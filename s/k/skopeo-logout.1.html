NOM

skopeo-logout - Se déconnecter d'un registre de conteneurs.

SYNTAXE

skopeo logout [options] registre

DESCRIPTION

skopeo logout se déconnecte d'un serveur de registre spécifié en supprimant les identifiants mis en cache stockés dans le fichier auth.json. Le chemin du fichier d'identifiants peut être outrepassé par l'utilisateur en définissant le drapeau authfile. Tous les identifiants mis en cache peuvent être supprimés en définissant le drapeau all.

OPTIONS

Voir aussi skopeo(1) pour les options placées avant le nom de la sous-commande.

--authfile=chemin

Chemin du fichier d'identifiants de registre géré. Sous Linux, le défaut est ${XDG_RUNTIME_DIR}/containers/auth.json. Voir containers-auth.json(5) pour plus de détails sur le défaut sur d'autres plateformes.

La valeur par défaut de cette option est lue à partir de la variable d'environnement REGISTRY\_AUTH\_FILE.

--compat-auth-file=chemin

Au lieu de mettre à jour le fichier d'identifiants par défaut, mettez à jour celui à chemin, et utilisez un format compatible Docker.

--all, -a

Supprime les identifiants mis en cache pour tous les registres dans le fichier d'authentification.

--help, -h

Imprime l'énoncé d'utilisation.

--tls-verify=booléen

Exige HTTPS et vérifie les certificats lors de la communication avec le registre ou le démon de conteneur. Par défaut, utilise le réglage de registry.conf.

EXEMPLES

$ skopeo logout docker.io
Supprimer les identifiants de connexion pour docker.io
$ skopeo logout --authfile authdir/myauths.json docker.io
Supprimer les identifiants de connexion pour docker.io
$ skopeo logout --all
Supprimer les identifiants de connexion pour tous les registres

VOIR AUSSI

skopeo(1), skopeo-login(1), containers-auth.json(5)
