NOM

sg_bg_ctl - envoie une commande SCSI BACKGROUND CONTROL

SYNTAXE

sg_bg_ctl [--ctl=CTL] [--help] [--time=TN] [--verbose] [--version] DEVICE

DESCRIPTION

Envoie une commande SCSI BACKGROUND CONTROL au DEVICE. Cette commande a été trouvée pour la première fois dans le projet de norme SBC-4 révision 8 (sbc4r08.pdf). Elle peut être utilisée pour démarrer et arrêter les 'opérations d'arrière-plan avancées' sur le DEVICE. Seuls les périphériques à ressources ou à provisionnement fin (unités logiques qui sont généralement des disques (à état solide)) prennent en charge cette commande. Ces opérations d'arrière-plan avancées incluent souvent des opérations de type collecte de garbage qui peuvent dégrader les performances du disque pendant leur exécution.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-c, --ctl=CTL
CTL est la valeur placée dans le champ BO_CTL de la commande BACKGROUND CONTROL (cdb). C'est un champ de deux bits, il a donc 4 variantes : 0 ne change pas les opérations d'arrière-plan avancées initiées par l'hôte ; 1 démarre ces opérations ; 2 arrête ces opérations et 3 est réservé. La valeur par défaut est 0.
-h, --help
affiche le message d'utilisation puis quitte.
-t, --time=TN
TN est un temps maximum (avec une unité de 100 ms ou 1/10 de seconde) pendant lequel les opérations d'arrière-plan avancées peuvent avoir lieu. Cette valeur est ignorée si l'argument CTL est différent de 1. La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite de temps maximale. Seules les valeurs de 0 à 255 (soit 25,5 secondes) peuvent être données. Cette valeur est placée dans le champ BO_TIME de la commande BACKGROUND CONTROL.
-v, --verbose
augmente le niveau de verbosité, (c'est-à-dire les messages de débogage).
-V, --version
affiche la chaîne de version puis quitte.

NOTES

Selon T10, la prise en charge des 'opérations de contrôle en arrière-plan' est indiquée par le bit BOCS activé dans la page des caractéristiques du périphérique bloc VPD [0xb1]. L'état du bit BOCS peut être vérifié avec les utilitaires sg_vpd et sdparm (et il est en lecture seule). Il existe une page de mode de contrôle des opérations d'arrière-plan [0xa, 0x6] avec un champ BO_MODE pour modifier l'action de cette opération. Le champ BO_MODE peut être accédé et potentiellement modifié avec l'utilitaire sdparm. Le champ BO_STATUS se trouve dans la page de journal des opérations d'arrière-plan [0x15, 0x2] et peut être consulté avec l'utilitaire sg_logs.

Le projet actuel décrivant cette zone est SBC-4 révision 10 (sbc4r10.pdf) dans la clause 4.33. Il contient l'exemple suivant d'opération d'arrière-plan : "Les opérations d'arrière-plan avancées peuvent inclure des opérations d'effacement de bloc NAND, des opérations de lecture de média et des opérations d'écriture de média (par exemple, la collecte de garbage), qui peuvent affecter le temps de réponse des requêtes de lecture ou d'écriture normales du client applicatif."

STATUT DE SORTIE

Le statut de sortie de sg_bg_ctl est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
