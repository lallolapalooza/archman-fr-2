SGML2INFO(1) Manuel des commandes générales SGML2INFO(1)

NOM

sgml2info - créer une sortie GNU info à partir d'un fichier source SGML DTD LinuxDoc

SYNTAXE

sgml2info [option-générique...] fichier[.sgml]

DESCRIPTION

sgml2info est une forme ancienne et obsolète de la commande de conversion d'info de LinuxDoc-Tools (son nom peut être trompeur, car il ne s'agit pas d'un outil pour n'importe quelle DTD SGML, il ne prend en charge que la DTD SGML LinuxDoc). Il est recommandé de passer à la nouvelle forme linuxdoc -B info dès maintenant. Cette commande convertit un fichier source SGML DTD LinuxDoc au format GNU info. La sortie apparaîtra dans fichier.info où fichier est le nom du fichier source SGML.

La paire attribut/valeur "output=info" est définie pour les conditions.

OPTIONS

sgml2info accepte toutes les options génériques décrites dans linuxdoc(1).

fichier
spécifie le fichier source SGML, nommé soit fichier soit fichier.sgml

FICHIERS

De nombreux fichiers et exécutables dans /usr/share/linuxdoc-tools sont utilisés.

AUTEUR
