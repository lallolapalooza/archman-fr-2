Documentation de la fonction/sous-routine

sous-routine sgbbrd (character vect, integer m, integer n, integer ncc, integer kl, integer ku, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldpt, * ) pt, integer ldpt, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer info)

SGBBRD

Objectif:

!>
!> SGBBRD réduit une matrice bande générale réelle m par n A à la forme
!>   bidiagonale supérieure B par une transformation orthogonale : Q**T * A * P = B.
!>
!> La routine calcule B, et forme optionnellement Q ou P**T, ou calcule
!> Q**T*C pour une matrice C donnée.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          Spécifie si les matrices Q et P**T doivent être formées ou non.
!>          = 'N': ne former ni Q ni P**T ;
!>          = 'Q': former seulement Q ;
!>          = 'P': former seulement P**T ;
!>          = 'B': former les deux.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NCC

!>          NCC est INTEGER
!>          Le nombre de colonnes de la matrice C.  NCC >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales de la matrice A. KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales de la matrice A. KU >= 0.
!>

AB

!>          AB est un tableau REAL, dimension (LDAB,N)
!>          En entrée, la matrice bande A de m par n, stockée dans les lignes 1 à
!>          KL+KU+1. La j-ème colonne de A est stockée dans la j-ème colonne du
!>          tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(m,j+kl).
!>          En sortie, A est écrasée par les valeurs générées pendant la
!>          réduction.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau A. LDAB >= KL+KU+1.
!>

D

!>          D est un tableau REAL, dimension (min(M,N))
!>          Les éléments diagonaux de la matrice bidiagonale B.
!>

E

!>          E est un tableau REAL, dimension (min(M,N)-1)
!>          Les éléments super-diagonaux de la matrice bidiagonale B.
!>

Q

!>          Q est un tableau REAL, dimension (LDQ,M)
!>          Si VECT = 'Q' ou 'B', la matrice orthogonale m par m, Q.
!>          Si VECT = 'N' ou 'P', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.
!>          LDQ >= max(1,M) si VECT = 'Q' ou 'B' ; LDQ >= 1 sinon.
!>

PT

!>          PT est un tableau REAL, dimension (LDPT,N)
!>          Si VECT = 'P' ou 'B', la matrice orthogonale n par n, P'.
!>          Si VECT = 'N' ou 'Q', le tableau PT n'est pas référencé.
!>

LDPT

!>          LDPT est INTEGER
!>          La dimension principale du tableau PT.
!>          LDPT >= max(1,N) si VECT = 'P' ou 'B' ; LDPT >= 1 sinon.
!>

C

!>          C est un tableau REAL, dimension (LDC,NCC)
!>          En entrée, une matrice C de m par ncc.
!>          En sortie, C est écrasée par Q**T*C.
!>          C n'est pas référencée si NCC = 0.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C.
!>          LDC >= max(1,M) si NCC > 0 ; LDC >= 1 si NCC = 0.
!>

WORK

!>          WORK est un tableau REAL, dimension (2*max(M,N))
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
