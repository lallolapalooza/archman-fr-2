SGEES calcule les valeurs propres, la forme de Schur, et, optionnellement, la matrice des vecteurs de Schur pour les matrices GE

But :

!>
!> SGEES calcule pour une matrice réelle non symétrique A de taille N par N,
!> les valeurs propres, la forme de Schur réelle T, et, optionnellement, la matrice des
!> vecteurs de Schur Z. Cela donne la factorisation de Schur A = Z*T*(Z**T).
!>
!> Optionnellement, elle ordonne également les valeurs propres sur la diagonale de la
!> forme de Schur réelle de sorte que les valeurs propres sélectionnées soient en haut à gauche.
!> Les colonnes de tête de Z forment alors une base orthonormale pour le sous-espace
!> invariant correspondant aux valeurs propres sélectionnées.
!>
!> Une matrice est sous forme de Schur réelle si elle est quasi-triangulaire supérieure avec
!> des blocs de 1x1 et 2x2. Les blocs de 2x2 seront standardisés sous la forme
!>         [  a  b  ]
!>         [  c  a  ]
!>
!> où b*c < 0. Les valeurs propres d'un tel bloc sont a +- sqrt(bc).
!>

Paramètres

JOBVS 
!>          JOBVS est CHARACTER*1
!>          = 'N': les vecteurs de Schur ne sont pas calculés ;
!>          = 'V': les vecteurs de Schur sont calculés.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non sur la
!>          diagonale de la forme de Schur.
!>          = 'N': les valeurs propres ne sont pas ordonnées ;
!>          = 'S': les valeurs propres sont ordonnées (voir SELECT).
!>

SELECT

!>          SELECT est une FONCTION LOGIQUE de deux arguments REELS
!>          SELECT doit être déclarée EXTERNAL dans la sous-routine appelante.
!>          Si SORT = 'S', SELECT est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Si SORT = 'N', SELECT n'est pas référencée.
!>          Une valeur propre WR(j)+sqrt(-1)*WI(j) est sélectionnée si
!>          SELECT(WR(j),WI(j)) est vraie ; c'est-à-dire, si l'une des valeurs propres d'une paire
!>          conjuguée complexe est sélectionnée, alors les deux valeurs propres complexes sont sélectionnées.
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus
!>          satisfaire SELECT(WR(j),WI(j)) = .TRUE. après l'ordonnancement, car
!>          l'ordonnancement peut modifier la valeur des valeurs propres complexes
!>          (surtout si la valeur propre est mal conditionnée) ; dans ce cas, INFO est mis à N+2 (voir INFO ci-dessous).
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille N par N.
!>          À la sortie, A a été écrasée par sa forme de Schur réelle T.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>                         pour lesquelles SELECT est vraie. (Les paires conjuguées complexes
!>                         pour lesquelles SELECT est vraie pour l'une ou l'autre des valeurs propres comptent pour 2.)
!>

WR

!>          WR est un tableau REEL, dimension (N)
!>

WI

!>          WI est un tableau REEL, dimension (N)
!>          WR et WI contiennent les parties réelles et imaginaires,
!>          respectivement, des valeurs propres calculées dans le même ordre
!>          où elles apparaissent sur la diagonale de la forme de Schur T de sortie.
!>          Les paires de valeurs propres conjuguées complexes apparaîtront
!>          consécutivement, la valeur propre avec la partie imaginaire positive étant la première.
!>

VS

!>          VS est un tableau REEL, dimension (LDVS,N)
!>          Si JOBVS = 'V', VS contient la matrice orthogonale Z des vecteurs de Schur.
!>          Si JOBVS = 'N', VS n'est pas référencé.
!>

LDVS

!>          LDVS est INTEGER
!>          La dimension principale du tableau VS. LDVS >= 1 ; si
!>          JOBVS = 'V', LDVS >= N.
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,3*N).
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

BWORK

!>          BWORK est un tableau LOGIQUE, dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, et i est
!>             <= N : l'algorithme QR n'a pas réussi à calculer toutes les
!>                   valeurs propres ; les éléments 1:ILO-1 et i+1:N de WR et WI
!>                   contiennent les valeurs propres qui ont convergé ; si
!>                   JOBVS = 'V', VS contient la matrice qui réduit A
!>                   à sa forme de Schur partiellement convergée.
!>             = N+1 : les valeurs propres n'ont pas pu être réordonnées car certaines
!>                   valeurs propres étaient trop proches pour être séparées (le problème
!>                   est très mal conditionné) ;
!>             = N+2 : après réordonnancement, l'arrondi a modifié les valeurs de certaines
!>                   valeurs propres complexes de sorte que les valeurs propres principales
!>                   dans la forme de Schur ne satisfont plus SELECT=.TRUE. Cela
!>                   pourrait également être causé par un sous-dépassement dû à la mise à l'échelle.
!>

sgees(3)

sgees — Calcule les valeurs propres et les vecteurs propres droits d'une matrice générale réelle.

NOM

sgees — Calcule les valeurs propres et les vecteurs propres droits d'une matrice générale réelle.

SYNTAXE

SUBROUTINE SGEES( JOBVL, JOBVR, N, A, LDA, SDIM, WR, WI, VL, LDVL, VR, LDVR, WORK, LWORK, BWORK, INFO )

Paramètres

  • JOBVL character*1

    Indique si les vecteurs propres gauches sont calculés.

    • 'N' : Aucun vecteur propre gauche n'est calculé.
    • 'V' : Les vecteurs propres gauches sont calculés.
  • JOBVR character*1

    Indique si les vecteurs propres droits sont calculés.

    • 'N' : Aucun vecteur propre droit n'est calculé.
    • 'V' : Les vecteurs propres droits sont calculés.
  • N integer

    L'ordre de la matrice A. N >= 0.

  • A real*4, dimension (LDA,*)

    Sur l'entrée, la matrice carrée N x N à traiter.

    Sur la sortie, le contenu de A est indéterminé.

  • LDA integer

    La largeur de stockage de A. LDA >= max(1, N).

  • SDIM integer

    La dimension du sous-espace invariant sélectionné.

  • WR real*4, dimension (N)

    La partie réelle des valeurs propres.

  • WI real*4, dimension (N)

    La partie imaginaire des valeurs propres.

    WI[i] est nulle si WR[i] est une valeur propre réelle.

    WI[i] et WI[i+1] sont opposées et non nulles si WR[i] et WR[i+1] sont les parties réelles de deux valeurs propres complexes conjuguées.

  • VL real*4, dimension (LDVL,*)

    Si JOBVL = 'V', VL contient les vecteurs propres gauches de A.

    VL[i,j] est le vecteur propre gauche correspondant à la j-ième valeur propre.

    Si JOBVL = 'N', VL n'est pas utilisé.

  • LDVL integer

    La largeur de stockage de VL. LDVL >= N.

  • VR real*4, dimension (LDVR,*)

    Si JOBVR = 'V', VR contient les vecteurs propres droits de A.

    VR[i,j] est le vecteur propre droit correspondant à la j-ième valeur propre.

    Si JOBVR = 'N', VR n'est pas utilisé.

  • LDVR integer

    La largeur de stockage de VR. LDVR >= N.

  • WORK real*4, dimension (LWORK)

    Tableau de travail.

  • LWORK integer

    La taille du tableau WORK.

    LWORK >= max(1, 3*N).

    Pour un calcul optimal, LWORK doit être au moins max(1, 3*N).

    Si LWORK = -1, alors la taille optimale de WORK est calculée et retournée dans WORK[1].

  • BWORK logical, dimension (N)

    Tableau de travail booléen.

  • INFO integer

    INFO = 0 : succès.

    INFO < 0 : une erreur s'est produite, avec -INFO comme numéro de paramètre.

    INFO > 0 : l'algorithme QR n'a pas convergé. INFO indique le nombre d'éléments sur la diagonale pour lesquels la convergence n'a pas été atteinte.

Documentation de fonction/sous-routine

sgees est une sous-routine de la bibliothèque LAPACK (Linear Algebra PACKage) qui calcule les valeurs propres et, optionnellement, les vecteurs propres gauches et/ou droits d'une matrice générale réelle.

La routine procède en deux étapes principales :

  1. Réduction de la matrice A en une forme Hessenberg supérieure H en utilisant des transformations unitaires.
  2. Calcul des valeurs propres et des vecteurs propres de H en utilisant l'algorithme QR itératif.

Les vecteurs propres gauches et droits sont calculés si les options correspondantes JOBVL et JOBVR sont définies sur 'V'.

Les valeurs propres complexes sont retournées en paires conjuguées dans les tableaux WR et WI. Si WI[i] est non nulle, alors WR[i] et WR[i+1] sont les parties réelles des deux valeurs propres complexes conjuguées, et WI[i] et WI[i+1] sont leurs parties imaginaires opposées.

Le paramètre SDIM renvoie la dimension du sous-espace invariant sélectionné, qui est pertinent pour la subdivision de la matrice dans sa forme réduite.

Les tableaux de travail WORK et BWORK sont nécessaires pour les calculs intermédiaires.
