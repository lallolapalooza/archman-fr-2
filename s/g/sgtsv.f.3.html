sous-routine sgtsv (n, nrhs, dl, d, du, b, ldb, info)

SGTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Documentation de la fonction/sous-routine

sous-routine sgtsv (entier n, entier nrhs, reel, dimension( * ) dl, reel, dimension( * ) d, reel, dimension( * ) du, reel, dimension( ldb, * ) b, entier ldb, entier info)

SGTSV calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Objectif :

!>
!> SGTSV  résout l'équation
!>
!>    A*X = B,
!>
!> où A est une matrice tridiagonale de taille n par n, par élimination
!> de Gauss avec pivotage partiel.
!>
!> Notez que l'équation  A**T*X = B  peut être résolue en échangeant l'ordre
!> des arguments DU et DL.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est un tableau REEL, dimension (N-1)
!>          À l'entrée, DL doit contenir les (n-1) éléments sous-diagonaux
!>          de A.
!>
!>          À la sortie, DL est écrasé par les (n-2) éléments de la
!>          deuxième sur-diagonale de la matrice triangulaire supérieure U
!>          de la factorisation LU de A, dans DL(1), ..., DL(n-2).
!>

D

!>          D est un tableau REEL, dimension (N)
!>          À l'entrée, D doit contenir les éléments diagonaux de A.
!>
!>          À la sortie, D est écrasé par les n éléments diagonaux de U.
!>

DU

!>          DU est un tableau REEL, dimension (N-1)
!>          À l'entrée, DU doit contenir les (n-1) éléments sur-diagonaux
!>          de A.
!>
!>          À la sortie, DU est écrasé par les (n-1) éléments de la première
!>          sur-diagonale de U.
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des membres de droite B de taille N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N par NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, U(i,i) est exactement zéro, et la solution
!>               n'a pas été calculée. La factorisation n'a pas été
!>               achevée sauf si i = N.
!>
