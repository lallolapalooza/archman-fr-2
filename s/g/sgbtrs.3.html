Documentation de la fonction/sous-routine

sous-routine sgbtrs (caractère trans, entier n, entier kl, entier ku, entier nrhs, réel, dimension( ldab, * ) ab, entier ldab, entier, dimension( * ) ipiv, réel, dimension( ldb, * ) b, entier ldb, entier info)

SGBTRS

But:

!>
!> SGBTRS résout un système d'équations linéaires
!>    A * X = B  ou  A**T * X = B
!> avec une matrice bande générale A en utilisant la factorisation LU calculée
!> par SGBTRF.
!>

Paramètres

TRANS 
!>          TRANS est CARACTERE*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B  (Pas de transposée)
!>          = 'T':  A**T* X = B  (Transposée)
!>          = 'C':  A**T* X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est ENTIER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est ENTIER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AB

!>          AB est un tableau REEL, dimension (LDAB,N)
!>          Détails de la factorisation LU de la matrice bande A, tels que
!>          calculés par SGBTRF.  U est stockée comme une matrice bande triangulaire
!>          supérieure avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1, et
!>          les multiplicateurs utilisés lors de la factorisation sont stockés dans
!>          les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Les indices de pivot; pour 1 <= i <= N, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).
!>

B

!>          B est un tableau REEL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des côtés droits B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
