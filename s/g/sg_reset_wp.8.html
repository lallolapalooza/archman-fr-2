NOM

sg_reset_wp - envoie la commande SCSI RESET WRITE POINTER

SYNTAXE

sg_reset_wp [--all] [--count=ZC] [--help] [--verbose] [--version] [--zone=ID] PÉRIPHÉRIQUE

DESCRIPTION

Envoie une commande SCSI RESET WRITE POINTER au PÉRIPHÉRIQUE. Cette commande est décrite dans la norme ZBC (INCITS 536-2016) et les brouillons ZBC-2 sur T10 (par exemple, zbc2r12.pdf).

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-a, --all
définit le champ ALL dans le cdb. Cela déclenche une opération de réinitialisation du pointeur d'écriture de toutes les zones ouvertes et de toutes les zones pleines. Lorsque cette option est donnée, l'option --zone=ID est ignorée. Soit cette option, soit l'option --zone=ID est requise.
-C, --count=ZC
ZC est placé dans le champ Zone Count (Compte de zones) du cdb de la commande RESET WRITE POINTER supportée par cet utilitaire. ZC doit être une valeur comprise entre 0 et 65535 (0xffff) inclusivement.
L'action que le PÉRIPHÉRIQUE entreprend avec cette option dépend si l'option --all est définie. Voir la description de la commande RESET WRITE POINTER (par exemple, section 5.9, table 46 dans zbc2r12.pdf).
-h, --help
affiche le message d'utilisation puis quitte.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire la sortie de débogage).
-V, --version
imprime la chaîne de version puis quitte.
-z, --zone=ID
où ID est placé dans le champ ZONE ID du cdb. Un id de zone est une adresse logique de bloc (LBA) de début de zone. Cela déclenche une opération de réinitialisation du pointeur d'écriture sur la zone identifiée par le champ ZONE ID. La valeur par défaut est 0. Soit cette option, soit l'option --all est requise. ID est supposé être en décimal sauf s'il est préfixé par '0x' ou a un 'h' final qui indiquent l'hexadécimal.

NOTES

Le paramètre du journal Zones Emptied (Zones Vidées) dans la page de statistiques du périphérique de bloc zoné compte le nombre de fois où la commande RESET WRITE POINTER a été invoquée (avec succès).

STATUT DE SORTIE

Le statut de sortie de sg_reset_wp est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
