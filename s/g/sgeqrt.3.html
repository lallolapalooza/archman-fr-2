sous-routine sgeqrt (integer m, integer n, integer nb, real, dimension( lda, * ) a, integer lda, real, dimension( ldt, * ) t, integer ldt, real, dimension( * ) work, integer info)

SGEQRT

Objectif :

!>
!> SGEQRT calcule une factorisation QR bloquée d'une matrice réelle M par N, A,
!> en utilisant la représentation WY compacte de Q.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NB

!>          NB est un entier (INTEGER)
!>          La taille du bloc à utiliser pour la QR bloquée. MIN(M,N) >= NB >= 1.
!>

A

!>          A est un tableau de réels (REAL), de dimension (LDA,N)
!>          À l'entrée, la matrice M par N, A.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R de taille min(M,N) par N
!>          (R est triangulaire supérieure si M >= N) ; les éléments en dessous de la
!>          diagonale sont les colonnes de V.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau de réels (REAL), de dimension (LDT,MIN(M,N))
!>          Les réflecteurs de blocs triangulaires supérieurs stockés sous forme
!>          compacte en tant que séquence de blocs triangulaires supérieurs. Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T. LDT >= NB.
!>

WORK

!>          WORK est un tableau de réels (REAL), de dimension (NB*N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> La matrice V stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!> sous la diagonale. Par exemple, si M=5 et N=3, la matrice V est
!>
!>               V = (  1       )
!>                   ( v1  1    )
!>                   ( v1 v2  1 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!> où les vi représentent les vecteurs qui définissent H(i), qui sont retournés
!> dans la matrice A. Les 1 le long de la diagonale de V ne sont pas stockés dans A.
!>
!> Soit K=MIN(M,N). Le nombre de blocs est B = ceiling(K/NB), où chaque
!> bloc est de taille NB sauf le dernier bloc, qui est de taille
!> IB = K - (B-1)*NB. Pour chacun des B blocs, un facteur de réflecteur de bloc
!> triangulaire supérieur est calculé : T1, T2, ..., TB. Les matrices T de taille
!> NB par NB (et IB par IB pour le dernier bloc) sont stockées dans la matrice T
!> de taille NB par K comme suit :
!>
!>               T = (T1 T2 ... TB).
!>
