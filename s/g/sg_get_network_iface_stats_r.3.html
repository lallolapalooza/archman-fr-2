sg_get_network_iface_stats(3) sg_get_network_iface_stats(3)

NOM

sg_get_network_iface_stats, sg_get_network_iface_stats_r, sg_free_network_iface_stats, sg_network_iface_compare_name - obtenir les statistiques de l'interface réseau

SYNOPSIS

#include <statgrab.h>


sg_network_iface_stats *sg_get_network_iface_stats
(size_t *entries);


sg_network_iface_stats *sg_get_network_iface_stats_r
(size_t *entries);


sg_error sg_free_network_iface_stats
(sg_network_iface_stats *data);


int sg_network_iface_compare_name
(const void *va, const void *vb);

DESCRIPTION

Les fonctions sg_get_network_iface_stats() et sg_get_network_iface_stats_r() renvoient les statistiques des interfaces réseau de la machine. Plus précisément, elles renvoient la vitesse de l'interface, l'état du duplex et si elle est actuellement active. Les deux fonctions acceptent un paramètre optionnel entries, qui pointe (lorsqu'il est fourni) vers un size_t pour obtenir le nombre d'entrées du vecteur retourné.

Raccourci API

fonction retourne propriétaire des données
sg_get_network_iface_stats sg_network_iface_stats * libstatgrab (local au thread)
sg_get_network_iface_stats_r sg_network_iface_stats * appelant

Les vecteurs sg_network_iface_stats reçus de sg_get_network_iface_stats_r() doivent être libérés à l'aide de sg_free_network_iface_stats() lorsqu'ils ne sont plus nécessaires. L'appelant est responsable de cette opération.

De plus, une fonction d'aide pour qsort(3) est disponible : sg_network_iface_compare_name().

Exemple de tri

size_t entries;
sg_network_iface_stats *network_iface_stats = NULL;
while( NULL != ( network_iface_stats = sg_get_network_iface_stats(&entries) ) ) {
    /* ordonner les entrées alphabétiquement en utilisant le point de montage */
    qsort( network_iface_stats, entries, sizeof(network_iface_stats[0]), &sg_network_iface_compare_name );
    show_network_iface_stats( network_iface_stats );
}

VALEUR DE RETOUR

La fonction sg_get_network_iface_stats renvoie un pointeur vers une structure de type sg_network_iface_stats.

typedef enum{
        SG_IFACE_DUPLEX_FULL,
        SG_IFACE_DUPLEX_HALF,
        SG_IFACE_DUPLEX_UNKNOWN
}sg_iface_duplex;

Remarque : La valeur SG_IFACE_DUPLEX_UNKNOWN pourrait signifier que le duplex n'a pas encore été négocié.

typedef struct {
        char *interface_name;
        int speed;
        sg_iface_duplex duplex;
        int up;
        time_t systime;
} sg_network_iface_stats;
interface_name
Le nom connu du système d'exploitation. (par exemple, sous Linux, il pourrait s'agir de eth0)
speed
La vitesse de l'interface, en mégabits/seconde.
duplex
L'état du duplex dans lequel se trouve l'interface. Voir sg_iface_duplex pour les valeurs autorisées.
up
Si l'interface est active.
systime
L'horodatage lorsque les statistiques ci-dessus ont été collectées en secondes depuis l'époque

BOGUES

L'obtention de détails spécifiques peut nécessiter des privilèges élevés, par exemple sous Linux, la vitesse de l'interface n'est pas visible par les processus non privilégiés.

Les fonctions de comparaison existent plutôt pour des raisons de compatibilité ascendante que pour des améliorations fonctionnelles. La flexibilité limitée (par exemple, l'ordre inversé) et le manque d'opportunités d'optimisation pour le compilateur conduisent à la recommandation d'implémenter les routines de comparaison requises localement.
