NOM

sgml2xml-isoent - Convertir SGML en XML avec prise en charge des entités ISO

SYNTAXE


sgml2xml-isoent
[document-sgml]

DESCRIPTION

sgml2xml-isoent convertit un document SGML en XML, avec prise en charge des entités ISO. Ceci est réalisé en utilisant sgml2xml(1) du paquet SP (ou osx(1) du paquet OpenSP), et la déclaration pour la version XML des entités ISO est ajoutée à la sortie. Cela signifie que la sortie de cette conversion devrait fonctionner telle quelle avec n'importe quel outil XML.

Ce programme est souvent utilisé pour traiter les documents SGML DocBook avec des outils basés sur XML. En particulier, db2x_xsltproc(1) appelle ce programme dans le cadre de son option --sgml. D'un autre côté, il n'est probablement pas utile pour migrer un fichier texte SGML source vers XML, car la conversion altère le formatage original.

Étant donné que la version XML des entités ISO est référencée directement, et non via une DTD, cet outil fonctionne également avec des types de documents autres que DocBook.

NOTES

Les entités ISO sont référencées en utilisant les identifiants publics ISO 8879:1986//ENTITIES//...//EN//XML. Les catalogues utilisés lors de l'analyse du document converti devraient résoudre ces entités à l'emplacement approprié (sur le système de fichiers local). Si les entités ne sont pas résolues dans le catalogue, alors la solution de repli consiste à récupérer les fichiers d'entités à partir du site Web http://www.docbook.org/.
