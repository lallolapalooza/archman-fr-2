SG_REFERRALS(8) SG3_UTILS SG_REFERRALS(8)

NOM

sg_referrals - envoie la commande SCSI REPORT REFERRALS

SYNTAXE

sg_referrals [--aide] [--hex] [--lba=LBA] [--maxlen=LONGUEUR] [--one-segment] [--raw] [--readonly] [--verbose] [--version] APPAREIL

DESCRIPTION

Envoie la commande SCSI REPORT REFERRALS à l'APPAREIL et affiche la réponse. Cette commande a été introduite dans la version (brouillon) SBC-3 révision 24 et les appareils qui prennent en charge les renvois devraient prendre en charge cette commande.

L'action par défaut est de décoder la réponse pour tous les descripteurs de segments de données utilisateur de renvoi. La quantité de sortie peut être réduite par les options --lba et --one-segment.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-h, --aide
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse à cette commande en hexadécimal ASCII.
-l, --lba=LBA
où LBA est l'adresse de bloc logique (LBA) du premier segment de données utilisateur pour lequel l'APPAREIL doit signaler les données du paramètre de renvoi.
-m, --maxlen=LONGUEUR
où LONGUEUR est la longueur (maximale) de la réponse en octets. Elle est placée dans le champ « allocation length » du CDB. Si non spécifié, 256 est utilisé. 256 est suffisant pour l'en-tête de réponse et les descripteurs de segments de données utilisateur.
-s, --one-segment
signale uniquement le segment de données utilisateur du segment spécifié par le paramètre LBA.
-r, --raw
affiche la réponse en binaire (sur stdout).
-R, --readonly
ouvre l'APPAREIL en lecture seule (par exemple, sous Unix avec le drapeau O_RDONLY). L'ouverture par défaut est en lecture-écriture.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire les messages de débogage). La sortie supplémentaire causée par cette option est envoyée vers stderr.
-V, --version
affiche la chaîne de version puis quitte.

NOTES

Pour une discussion sur les renvois, voir la section 4.25 de sbc3r25.pdf sur https://www.t10.org (ou la section correspondante d'une version ultérieure).

STATUT DE SORTIE

Le statut de sortie de sg_referrals est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
