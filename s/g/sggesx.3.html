SGGESX calcule les valeurs propres, la forme de Schur, et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

Objectif :

!>
!> SGGESX calcule pour une paire de matrices réelles non symétriques N-par-N
!> (A,B), les valeurs propres généralisées, la forme réelle de Schur (S,T), et,
!> éventuellement, les matrices gauche et/ou droite des vecteurs de Schur (VSL et
!> VSR). Cela donne la factorisation généralisée de Schur
!>
!>      (A,B) = ( (VSL) S (VSR)**T, (VSL) T (VSR)**T )
!>
!> Éventuellement, il ordonne également les valeurs propres de sorte qu'un cluster sélectionné
!> de valeurs propres apparaisse dans les blocs diagonaux principaux de la matrice quasi-triangulaire
!> supérieure (S) et de la matrice triangulaire supérieure (T) ; calcule
!> un nombre de condition réciproque pour la moyenne des valeurs propres sélectionnées
!> (RCONDE) ; et calcule un nombre de condition réciproque pour les sous-espaces
!> déflateurs droit et gauche correspondant aux valeurs propres sélectionnées
!> (RCONDV). Les colonnes principales de VSL et VSR forment alors
!> une base orthonormée pour les sous-espaces gauche et droits correspondants
!> (sous-espaces déflateurs).
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un ratio alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0 ou pour que les deux soient zéro.
!>
!> Une paire de matrices (S,T) est en forme de Schur généralisée réelle si T est
!> triangulaire supérieure avec une diagonale non négative et S est bloc triangulaire supérieure
!> avec des blocs de 1x1 et 2x2. Les blocs de 1x1 correspondent
!> aux valeurs propres généralisées réelles, tandis que les blocs de 2x2 de S seront
!> [ s11 s12 ]
!> [ s21 s22 ]
!> où s12 != 0 et s21 = 0.
!> Les paires de blocs de 2x2 de S et T sont utilisés pour représenter
!> une paire de valeurs propres complexes conjuguées.
!> Ceci est réalisé en s'assurant que les éléments correspondants de T ont la
!> forme :
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> et la paire de blocs 2x2 correspondants dans S et T aura
!> une paire de valeurs propres généralisées complexes conjuguées.
!>
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V':  calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur droits ;
!>          = 'V':  calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non sur
!>          la diagonale de la forme de Schur généralisée.
!>          = 'N':  les valeurs propres ne sont pas ordonnées ;
!>          = 'S':  les valeurs propres sont ordonnées (voir SELCTG).
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de trois arguments REELS
!>          SELCTG doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Une valeur propre (ALPHAR(j)+ALPHAI(j)*i)/BETA(j) est sélectionnée si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) est vrai ; c'est-à-dire si l'une
!>          des valeurs propres d'une paire complexe conjuguée est sélectionnée,
!>          alors les deux valeurs propres complexes sont sélectionnées.
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus satisfaire
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) = .TRUE. après ordonnancement,
!>          car l'ordonnancement peut modifier la valeur des valeurs propres
!>          complexes (surtout si la valeur propre est mal conditionnée), dans ce
!>          cas INFO est mis à N+3.
!>

SENSE

!>          SENSE est CHARACTER*1
!>          Détermine quels nombres de condition réciproques sont calculés.
!>          = 'N':  Aucun n'est calculé ;
!>          = 'E':  Calculé pour la moyenne des valeurs propres sélectionnées uniquement ;
!>          = 'V':  Calculé pour les sous-espaces déflateurs sélectionnés uniquement ;
!>          = 'B':  Calculé pour les deux.
!>          Si SENSE = 'E', 'V', ou 'B', SORT doit être égal à 'S'.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA, N)
!>          À l'entrée, le premier de la paire de matrices.
!>          À la sortie, A a été remplacé par sa forme de Schur généralisée
!>          S.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau REEL, dimension (LDB, N)
!>          À l'entrée, le second de la paire de matrices.
!>          À la sortie, B a été remplacé par sa forme de Schur généralisée
!>          T.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après ordonnancement)
!>          pour lesquelles SELCTG est vrai. (Les paires complexes conjuguées pour lesquelles
!>          SELCTG est vrai pour l'une ou l'autre valeur propre comptent pour 2.)
!>

ALPHAR

!>          ALPHAR est un tableau REEL, dimension (N)
!>

ALPHAI

!>          ALPHAI est un tableau REEL, dimension (N)
!>

BETA

!>          BETA est un tableau REEL, dimension (N)
!>          À la sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, seront
!>          les valeurs propres généralisées. ALPHAR(j) + ALPHAI(j)*i
!>          et BETA(j),j=1,...,N sont les éléments diagonaux de la forme de Schur complexe
!>          (S,T) qui résulterait si les blocs diagonaux 2x2 de
!>          la forme de Schur réelle de (A,B) étaient réduits davantage
!>          en forme triangulaire à l'aide de transformations unitaires complexes 2x2.
!>          Si ALPHAI(j) est nul, alors la j-ème valeur propre est réelle ; si
!>          positive, alors la j-ème et la (j+1)-ème valeurs propres sont une
!>          paire complexe conjuguée, avec ALPHAI(j+1) négatif.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder ou sous-écouler, et BETA(j) peut même être zéro.
!>          Par conséquent, l'utilisateur doit éviter de calculer naïvement le ratio.
!>          Cependant, ALPHAR et ALPHAI seront toujours inférieurs et
!>          généralement comparables à norm(A) en magnitude, et BETA toujours
!>          inférieur et généralement comparable à norm(B).
!>

VSL

!>          VSL est un tableau REEL, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches V
!>

LDVSL

!>          La dimension principale de la matrice VSR. LDVSR >= 1, et

RCONDE

!>          RCONDE est un tableau REEL, de dimension ( 2 )
!>          Si SENSE = 'E' ou 'B', RCONDE(1) et RCONDE(2) contiennent les
!>          nombres conditionnels réciproques pour la moyenne des valeurs propres sélectionnées.
!>          Non référencé si SENSE = 'N' ou 'V'.
!>

RCONDV

!>          RCONDV est un tableau REEL, de dimension ( 2 )
!>          Si SENSE = 'V' ou 'B', RCONDV(1) et RCONDV(2) contiennent les
!>          nombres conditionnels réciproques pour les sous-espaces défléchissants sélectionnés.
!>          Non référencé si SENSE = 'N' ou 'E'.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>

LWORK

!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>          Si N = 0, LWORK >= 1, sinon si SENSE = 'E', 'V', ou 'B',
!>          LWORK >= max( 8*N, 6*N+16, 2*SDIM*(N-SDIM) ), sinon
!>          LWORK >= max( 8*N, 6*N+16 ).
!>          Notez que 2*SDIM*(N-SDIM) <= N*N/2.
!>          Notez également qu'une erreur n'est renvoyée que si
!>          LWORK < max( 8*N, 6*N+16), mais si SENSE = 'E' ou 'V' ou 'B'
!>          ceci peut ne pas être suffisant.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la borne de la taille optimale du tableau WORK
!>          et la taille minimale du tableau IWORK, renvoie ces
!>          valeurs comme premières entrées des tableaux WORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

IWORK

!>          IWORK est un tableau ENTIER, de dimension (MAX(1,LIWORK))
!>          En sortie, si INFO = 0, IWORK(1) contient la taille minimale LIWORK.
!>

LIWORK

!>          LIWORK est un entier
!>          La dimension du tableau IWORK.
!>          Si SENSE = 'N' ou N = 0, LIWORK >= 1, sinon
!>          LIWORK >= N+6.
!>
!>          Si LIWORK = -1, alors une requête d'espace de travail est supposée ; la
!>          routine calcule seulement la borne de la taille optimale du
!>          tableau WORK et la taille minimale du tableau IWORK, renvoie
!>          ces valeurs comme premières entrées des tableaux WORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LIWORK n'est émis par
!>          XERBLA.
!>

BWORK

!>          BWORK est un tableau LOGIQUE, de dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          = 1,...,N :
!>                L'itération QZ a échoué. (A,B) ne sont pas sous forme de Schur,
!>                mais ALPHAR(j), ALPHAI(j) et BETA(j) devraient être corrects pour j=INFO+1,...,N.
!>          > N : =N+1 : l'échec de l'itération QZ dans SHGEQZ
!>                =N+2 : après réordonnancement, l'erreur d'arrondi a modifié les valeurs de
!>                      certaines valeurs propres complexes de sorte que les
!>                      valeurs propres principales dans la forme de Schur généralisée
!>                      ne satisfont plus SELCTG=.TRUE. Ceci pourrait également
!>                      être causé par la mise à l'échelle.
!>                =N+3 : le réordonnancement a échoué dans STGSEN.
!>
