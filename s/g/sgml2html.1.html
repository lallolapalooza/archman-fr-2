SGML2HTML(1) Manuel des commandes générales SGML2HTML(1)

NOM

sgml2html - créer une sortie HTML à partir d'un fichier source SGML DTD LinuxDoc

SYNTAXE

sgml2html [option-générique...] [--split 0|1|2 ] [--toc 0|1|2 ] [--dosnames] [--imagebuttons] fichier[.sgml]

DESCRIPTION

sgml2html est une forme ancienne et obsolète de la commande de conversion HTML de LinuxDoc-Tools (son nom peut être trompeur, car ce n'est pas un outil pour n'importe quelle DTD SGML, il ne prend en charge que la DTD SGML LinuxDoc). Il est recommandé de passer à la nouvelle forme linuxdoc -B html maintenant. Ceci convertit un fichier source SGML DTD LinuxDoc en sortie HTML. La sortie apparaîtra dans le fichier de niveau supérieur fichier.html et fichier-n.html pour chaque section, où fichier est le nom du fichier source SGML et n est le nom de la section.

La paire attribut/valeur "output=html" est définie pour les conditionnelles.

OPTIONS

sgml2html accepte toutes les options génériques décrites dans linuxdoc(1), et les options spécifiques suivantes :

--split, -s
Niveau de division des documents sources. 0 = ne pas diviser, 1 = diviser par sections principales, 2 = diviser par sous-sections.
--toc, -T
Niveau de génération de la table des matières.
0 = ne génère pas de table des matières du tout,
1 = inclut les sections principales (/chapitres/parties),
2 = inclut les sous-sections.
--dosnames, -h
Utiliser ".htm" plutôt que ".html" comme extension des
--imagebuttons, -I
Utiliser les icônes d'image de flèche "suivant", "précédent" et "contenu" incluses dans /usr/share/linuxdoc-tools comme boutons de navigation.
--footer, -F
Utiliser le fichier spécifié comme pied de page dans chaque fichier html résultant. Le pied de page par défaut est simplement du texte brut 
 </BODY>\n </HTML>\n
--header, -H
Utiliser le fichier spécifié comme partie supérieure de l'en-tête dans chaque fichier html résultant. Notez qu'il ne s'agit pas de la partie complète de l'en-tête, c'est-à-dire que le titre et les liens (suivant, précédent, contenu) dans l'en-tête par défaut sont conservés. Le défaut est 
 <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">\n
 <HTML>\n <HEAD>\n
fichier
Le fichier source SGML, nommé soit fichier soit fichier.sgml.

FICHIERS

De nombreux fichiers et exécutables dans /usr/share/linuxdoc-tools et /usr/bin sont utilisés.
