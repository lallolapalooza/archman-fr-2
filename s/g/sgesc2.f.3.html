subroutine sgesc2 (n, a, lda, rhs, ipiv, jpiv, scale)

SGESC2 résout un système d'équations linéaires en utilisant la factorisation LU avec pivotement complet calculée par sgetc2.

Documentation de la fonction/sous-programme

sous-programme sgesc2 (entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) rhs, entier, dimension( * ) ipiv, entier, dimension( * ) jpiv, réel scale)

SGESC2 résout un système d'équations linéaires en utilisant la factorisation LU avec pivotement complet calculée par sgetc2.

Objectif :

!>
!> SGESC2 résout un système d'équations linéaires
!>
!>           A * X = scale* RHS
!>
!> avec une matrice carrée générale N-par-N A en utilisant la factorisation LU avec
!> pivotement complet calculée par SGETC2.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          À l'entrée, la partie LU de la factorisation de la matrice A de taille n-par-n
!>          calculée par SGETC2 :  A = P * L * U * Q
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1, N).
!>

RHS

!>          RHS est un tableau REEL, dimension (N).
!>          À l'entrée, le vecteur du second membre b.
!>          À la sortie, le vecteur solution X.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N).
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

JPIV

!>          JPIV est un tableau ENTIER, dimension (N).
!>          Les indices de pivot ; pour 1 <= j <= N, la colonne j de la
!>          matrice a été échangée avec la colonne JPIV(j).
!>

SCALE

!>          SCALE est un REEL
!>           À la sortie, SCALE contient le facteur d'échelle. SCALE est choisi
!>           tel que 0 <= SCALE <= 1 pour éviter le dépassement de capacité dans la solution.
!>
