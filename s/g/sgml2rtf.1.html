SGML2RTF(1) Manuel général des commandes SGML2RTF(1)

NOM

sgml2rtf - créer une sortie RTF à partir d'un fichier source SGML DTD LinuxDoc

SYNTAXE

sgml2rtf [option_générale...] [--twosplit] fichier[.sgml]

DESCRIPTION

sgml2rtf est une ancienne forme obsolète de la commande rtf converter de LinuxDoc-Tools (son nom peut être trompeur, car il ne s'agit pas d'un outil pour n'importe quelle DTD SGML, il ne prend en charge que la DTD LinuxDoc SGML). Il est recommandé de passer dès maintenant à la nouvelle forme linuxdoc -B rtf. Il convertit un fichier source SGML DTD LinuxDoc en RTF, le Rich Text Format utilisé par le système d'aide de Microsoft Windows. La sortie apparaîtra dans le fichier de niveau supérieur fichier.rtf et fichier-n.rtf pour chaque section, où fichier est le nom du fichier source SGML. La sortie RTF est conçue pour être compilée par le Windows Help Compiler (hc31.exe).

La paire attribut/valeur "output=rtf" est définie pour les conditionnelles.

OPTIONS

sgml2rtf accepte toutes les options génériques décrites dans linuxdoc(1),et :

--twosplit, -2
Divise les fichiers à la fois aux sections n. et aux sous-sections n.m.
fichier
Le fichier source SGML, nommé soit fichier, soit fichier.sgml

FICHIERS

De nombreux fichiers et exécutables dans /usr/share/linuxdoc-tools et /usr/bin sont utilisés.

BOGUES

Aucun connu.

AUTEUR
