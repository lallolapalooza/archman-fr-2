Documentation de fonction/sous-programme

sous-routine sgttrs (caractere trans, entier n, entier nrhs, reel, dimension( * ) dl, reel, dimension( * ) d, reel, dimension( * ) du, reel, dimension( * ) du2, entier, dimension( * ) ipiv, reel, dimension( ldb, * ) b, entier ldb, entier info)

SGTTRS

Objectif :

!>
!> SGTTRS résout un des systèmes d'équations
!>    A*X = B  ou  A**T*X = B,
!> avec une matrice tridiagonale A en utilisant la factorisation LU calculée
!> par SGTTRF.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations.
!>          = 'N':  A * X = B  (Pas de transposée)
!>          = 'T':  A**T* X = B  (Transposée)
!>          = 'C':  A**T* X = B  (Transposée conjuguée = Transposée)
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

DL

!>          DL est tableau REEL, dimension (N-1)
!>          Les (n-1) multiplicateurs qui définissent la matrice L de la
!>          factorisation LU de A.
!>

D

!>          D est tableau REEL, dimension (N)
!>          Les n éléments diagonaux de la matrice triangulaire supérieure U de la
!>          factorisation LU de A.
!>

DU

!>          DU est tableau REEL, dimension (N-1)
!>          Les (n-1) éléments de la première super-diagonale de U.
!>

DU2

!>          DU2 est tableau REEL, dimension (N-2)
!>          Les (n-2) éléments de la deuxième super-diagonale de U.
!>

IPIV

!>          IPIV est tableau ENTIER, dimension (N)
!>          Les indices de pivot; pour 1 <= i <= n, la ligne i de la matrice a été
!>          échangée avec la ligne IPIV(i).  IPIV(i) sera toujours soit
!>          i, soit i+1; IPIV(i) = i indique qu'un échange de ligne n'était pas
!>          nécessaire.
!>

B

!>          B est tableau REEL, dimension (LDB,NRHS)
!>          En entrée, la matrice des vecteurs membres droits B.
!>          En sortie, B est écrasé par les vecteurs solution X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
