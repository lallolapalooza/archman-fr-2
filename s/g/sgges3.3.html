sous-routine sgges3 (character jobvsl, character jobvsr, character sort, external selctg, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer sdim, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvsl, * ) vsl, integer ldvsl, real, dimension( ldvsr, * ) vsr, integer ldvsr, real, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

SGGES3 calcule les valeurs propres, la forme de Schur, et, optionnellement, la matrice des vecteurs de Schur pour les matrices GE (algorithme bloqué)

Objectif :

!>
!> SGGES3 calcule pour une paire de matrices réelles non symétriques (A,B) de taille N,
!> les valeurs propres généralisées, la forme réelle de Schur généralisée (S,T),
!> et optionnellement, les matrices de vecteurs de Schur gauche et/ou droite (VSL et
!> VSR). Ceci donne la factorisation de Schur généralisée
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Optionnellement, elle ordonne également les valeurs propres de sorte qu'un cluster
!> sélectionné de valeurs propres apparaisse dans les blocs diagonaux principaux de la
!> matrice quasi-triangulaire supérieure S et de la matrice triangulaire supérieure T.
!> Les colonnes principales de VSL et VSR forment alors une base orthonormée pour les
!> sous-espaces propres gauches et droits correspondants (sous-espaces de déflation).
!>
!> (Si seules les valeurs propres généralisées sont nécessaires, utiliser le pilote
!> SGGEV à la place, qui est plus rapide.)
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un ratio alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0 ou les deux étant zéro.
!>
!> Une paire de matrices (S,T) est en forme de Schur généralisée réelle si T est
!> triangulaire supérieure avec une diagonale non négative et S est bloquée supratriangulaire
!> avec des blocs de 1x1 et 2x2. Les blocs de 1x1 correspondent
!> aux valeurs propres généralisées réelles, tandis que les blocs de 2x2 de S seront
!>
!>  [ a b ]   et [ c d ]
!>  [ 0 e ]      [ 0 f ]
!>
!> en rendant les éléments correspondants de T de la forme :
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> et la paire de blocs 2x2 correspondants dans S et T auront une paire de valeurs propres
!> généralisées complexes conjuguées.
!>
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V' : calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N' : ne pas calculer les vecteurs de Schur droits ;
!>          = 'V' : calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées sur la
!>          diagonale de la forme de Schur généralisée.
!>          = 'N':  les valeurs propres ne sont pas ordonnées ;
!>          = 'S':  les valeurs propres sont ordonnées (voir SELCTG) ;
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de trois arguments REELS
!>          SELCTG doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Une valeur propre (ALPHAR(j)+ALPHAI(j))/BETA(j) est sélectionnée si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) est vrai ; c'est-à-dire si
!>          l'une des valeurs propres d'une paire complexe conjuguée est sélectionnée,
!>          alors les deux valeurs propres complexes sont sélectionnées.
!>
!>          Notez que dans le cas mal conditionné, une valeur propre complexe sélectionnée
!>          peut ne plus satisfaire SELCTG(ALPHAR(j),ALPHAI(j),
!>          BETA(j)) = .TRUE. après l'ordonnancement. INFO doit être mis à N+2
!>          dans ce cas.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA, N)
!>          À l'entrée, la première de la paire de matrices.
!>          À la sortie, A a été écrasé par sa forme de Schur généralisée
!>          S.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau REEL, dimension (LDB, N)
!>          À l'entrée, la seconde de la paire de matrices.
!>          À la sortie, B a été écrasé par sa forme de Schur généralisée
!>          T.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>          pour lesquelles SELCTG est vrai. (Les paires complexes conjuguées pour lesquelles
!>          SELCTG est vrai pour l'une des valeurs propres comptent pour 2.)
!>

ALPHAR

!>          ALPHAR est un tableau REEL, dimension (N)
!>

ALPHAI

!>          ALPHAI est un tableau REEL, dimension (N)
!>

BETA

!>          BETA est un tableau REEL, dimension (N)
!>          À la sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, seront
!>          les valeurs propres généralisées. ALPHAR(j) + ALPHAI(j)*i,
!>          et BETA(j), j=1,...,N sont les diagonales de la forme de Schur complexe
!>          (S,T) qui résulterait si les blocs diagonaux 2x2
!>          de la forme de Schur réelle de (A,B) étaient réduits davantage
!>          en triangulaire à l'aide de transformations unitaires complexes 2x2.
!>          Si ALPHAI(j) est zéro, alors la j-ième valeur propre est réelle ; si
!>          positive, alors la j-ième et la (j+1)-ième valeurs propres sont une
!>          paire complexe conjuguée, avec ALPHAI(j+1) négatif.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder ou sous-déborder, et BETA(j) peut même être zéro.
!>          Ainsi, l'utilisateur doit éviter de calculer naïvement le ratio.
!>          Cependant, ALPHAR et ALPHAI seront toujours inférieurs et
!>          généralement comparables à norm(A) en magnitude, et BETA toujours
!>          inférieur et généralement comparable à norm(B).
!>

VSL

!>          VSL est un tableau REEL, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches.
!>          Non référencé si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL est INTEGER
!>          La dimension principale de la matrice VSL. LDVSL >=1, et
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR est un tableau REEL, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contiendra les vecteurs de Schur droits.
!>          Non référencé si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR est INTEGER
!>          La dimension principale de la matrice VSR. LDVSR >= 1, et
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK est un tableau REEL, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si N = 0, LWO
