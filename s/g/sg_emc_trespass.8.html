NOM

sg_emc_trespass - changer la propriété d'un LUN SCSI d'un autre Service-Processor vers celui-ci

SYNTAXE

sg_emc_trespass [-d] [-hr] [-s] [-V] PÉRIPHÉRIQUE

DESCRIPTION

sg_emc_trespass envoie une commande Trespass spécifique à EMC au PÉRIPHÉRIQUE avec les options sélectionnées. Cette commande de sélection de mode change la propriété du LUN du périphérique d'un autre Service-Processor vers celui sur lequel la commande a été reçue.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-d
affiche des informations de débogage supplémentaires associées à l'exécution de cette commande
-hr
Définit le bit 'Honor Reservation' dans la commande. S'il est défini, le transfert ne réussira à changer la propriété du SP pair que si le SP pair n'a pas de réservation SCSI en suspens pour le LUN. Par défaut, l'état de la réservation sera ignoré.
-s
Envoie la version courte de la commande de transfert au lieu de la version longue. La version courte est prise en charge sur les EMC FC5300, FC4500 et FC4700. La version longue (par défaut) est prise en charge sur les baies CLARiiON CX et AX.
-V
affiche la chaîne de version puis quitte.

Dans la série 2.4 des noyaux Linux, le PÉRIPHÉRIQUE doit être un périphérique générique SCSI (sg). Dans la série 2.6, les périphériques en bloc (par exemple, disques SCSI et lecteurs DVD) peuvent également être spécifiés. Par exemple, « sg_start 0 /dev/sda » fonctionnera dans les noyaux de la série 2.6.

STATUT DE SORTIE

Le statut de sortie de sg_emc_trespass est 0 en cas de succès. Sinon, consultez la page de manuel sg3_utils(8).
