NOM

sg_prevent - envoie la commande SCSI PREVENT ALLOW MEDIUM REMOVAL

SYNOPIS

sg_prevent [--allow] [--help] [--prevent=PC] [--verbose] [--version] PÉRIPHÉRIQUE

DESCRIPTION

Envoie une commande SCSI PREVENT ALLOW MEDIUM REMOVAL au PÉRIPHÉRIQUE. L'action par défaut de cet utilitaire est d'empêcher le retrait ou l'éjection du support d'un lecteur. Ceci est fait en ignorant la commande SCSI START STOP UNIT (voir sg_start) et en ignorant le bouton d'éjection sur le lecteur lorsque l'utilisateur appuie dessus. Les lecteurs qui contiennent des disques amovibles, des cartouches de bande ou des supports cd/dvd implémentent généralement cette commande. La définition des codes de "prévention" pour cette commande diffère entre les disques et les bandes (couverts par SBC-3 et SSC-3) et les lecteurs cd/dvd (couverts par MMC-5). Les "codes de prévention" décrits ici proviennent de MMC-5.

OPTIONS

Les arguments pour les options longues sont obligatoires pour les options courtes également.

-a, --allow
autoriser le retrait du support. Ceci est équivalent à définir sur '--prevent=2'. Ne peut pas être utilisé avec l'option --prevent=PC (c'est-à-dire, soit utiliser aucune option (donc empêcher le retrait), cette option ou --prevent=PC).
-h, --help
afficher le message d'utilisation puis quitter.
-p, --prevent=PC
où PC est une valeur de code de prévention. Les valeurs définies sont : 0 autorise le retrait, 1 empêche le retrait (par défaut), 2 autorise le retrait persistant tandis que 3 empêche le retrait persistant. "Persistant" dans ce contexte signifie que l'initiateur (port) qui utilise avec succès le code 3 empêche les autres initiateurs (ports) d'autoriser le retrait. Un état de "prévention persistant" peut être effacé par le propriétaire autorisant le retrait persistant (code 2) ou un cycle d'alimentation (ou tout ce qui réinitialise le périphérique (LU)) ou certaines commandes spéciales (par exemple, diverses actions de service de Persistent Reserve Out, voir SPC-3).
-v, --verbose
augmenter le niveau de verbosité, (c'est-à-dire, sortie de débogage).
-V, --version
afficher la chaîne de version puis quitter.

STATUT DE SORTIE

Le statut de sortie de sg_prevent est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
