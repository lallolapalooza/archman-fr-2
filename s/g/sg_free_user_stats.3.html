sg_get_user_stats(3) sg_get_user_stats(3)

NOM

sg_get_user_stats, sg_get_user_stats_r, sg_free_user_stats - obtenir les utilisateurs connectés actuels

SYNTAXE

#include <statgrab.h>


sg_user_stats *sg_get_user_stats
(size_t *entries);


sg_user_stats *sg_get_user_stats_r
(size_t *entries);


sg_error sg_free_user_stats
(sg_user_stats *data);

DESCRIPTION

Le module de statistiques utilisateur fournit certaines informations sur les utilisateurs connectés. Chaque connexion est traitée séparément. Les deux fonctions de statistiques, sg_get_user_stats() et sg_get_user_stats_r(), retournent un vecteur de sg_user_stats avec entries éléments.

Raccourci API

fonction retourne propriétaire des données
sg_get_user_stats sg_user_stats * libstatgrab (local au thread)
sg_get_user_stats_r sg_user_stats * l'appelant

Le vecteur sg_user_stats reçu de sg_get_user_stats_r() doit être libéré en utilisant sg_free_user_stats() lorsqu'il n'est plus nécessaire. L'appelant est responsable de le faire.

VALEURS DE RETOUR

La structure retournée est de type sg_user_stats.

typedef struct {
        char *login_name;
        char *record_id;
        size_t record_id_size;
        char *device;
        char *hostname;
        pid_t pid;
        time_t login_time;
        time_t systime;
} sg_user_stats;
login_name
Le nom d'utilisateur utilisé pour se connecter
record_id
Identifiant d'enregistrement de la base de données hôte contenant les informations de connexion (pas nécessairement terminé par 0)
record_id_size
Taille de l'identifiant d'enregistrement
device
Nom de l'appareil (par ex. "pts/0") du tty assigné à la session de connexion
hostname
Nom d'hôte (distant) à partir duquel l'utilisateur est connecté, par ex. "infoterm7.some.kind.of.domain.local", "localhost", "10.42.17.4" ou ":0.0" (s'il s'agit d'une connexion locale via un nouveau xterm)
pid
Identifiant de processus du processus qui a créé l'entrée dans la base de données des utilisateurs connectés
login_time
Horodatage (temps en secondes depuis l'époque) de la connexion de l'utilisateur
systime
L'horodatage de la collecte des statistiques ci-dessus en secondes depuis l'époque
