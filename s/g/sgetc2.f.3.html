Documentation de la fonction/sous-programme

sous-programme sgetc2 (integer n, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv, integer info)

SGETC2 calcule la factorisation LU avec pivotement complet de la matrice générale n x n.

Objectif :

!>
!> SGETC2 calcule une factorisation LU avec pivotement complet de la
!> matrice A de taille n x n. La factorisation est de la forme A = P * L * U * Q,
!> où P et Q sont des matrices de permutation, L est triangulaire inférieure avec
!> des éléments diagonaux unitaires et U est triangulaire supérieure.
!>
!> C'est l'algorithme BLAS de niveau 2.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau de réels (REAL), de dimension (LDA, N)
!>          À l'entrée, la matrice A de taille n x n à factoriser.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A = P*L*U*Q; les éléments diagonaux unitaires de L ne sont pas stockés.
!>          Si U(k, k) semble inférieur à SMIN, U(k, k) reçoit la
!>          valeur de SMIN, c'est-à-dire qu'un système perturbé non singulier est donné.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau d'entiers (INTEGER), de dimension(N).
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

JPIV

!>          JPIV est un tableau d'entiers (INTEGER), de dimension(N).
!>          Les indices de pivot ; pour 1 <= j <= N, la colonne j de la
!>          matrice a été échangée avec la colonne JPIV(j).
!>

INFO

!>          INFO est un entier (INTEGER)
!>           = 0 : sortie réussie
!>           > 0 : si INFO = k, U(k, k) risque de provoquer un dépassement de capacité si
!>                nous essayons de résoudre pour x dans Ax = b. Donc U est perturbé pour
!>                éviter le dépassement de capacité.
!>
