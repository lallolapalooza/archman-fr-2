sous-programme sgtt02 (caractère trans, entier n, entier nrhs, réel, dimension( * ) dl, réel, dimension( * ) d, réel, dimension( * ) du, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldb, * ) b, entier ldb, réel resid)

SGTT02

But :

!>
!> SGTT02 calcule le résidu pour la solution d'un système d'équations
!> tridiagonales :
!>    RESID = norm(B - op(A)*X) / (norm(op(A)) * norm(X) * EPS),
!> où EPS est l'epsilon machine.
!> La norme utilisée est la 1-norme.
!>

Paramètres

TRANS 
!>          TRANS est CARACTÈRE
!>          Spécifie la forme du résidu.
!>          = 'N' :  B - A    * X  (Pas de transposée)
!>          = 'T' :  B - A**T * X  (Transposée)
!>          = 'C' :  B - A**H * X  (Conjuguée transposée = Transposée)
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

DL

!>          DL est un tableau RÉEL, de dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est un tableau RÉEL, de dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau RÉEL, de dimension (N-1)
!>          Les éléments super-diagonaux (n-1) de A.
!>

X

!>          X est un tableau RÉEL, de dimension (LDX,NRHS)
!>          Les vecteurs solutions calculés X.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau RÉEL, de dimension (LDB,NRHS)
!>          En entrée, les vecteurs membres de droite pour le système d'équations
!>          linéaires.
!>          En sortie, B est écrasé par la différence B - op(A)*X.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RESID

!>          RESID est RÉEL
!>          norm(B - op(A)*X) / (norm(op(A)) * norm(X) * EPS)
!>
