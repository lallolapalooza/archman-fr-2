Documentation de fonction/sous-routine

sous-routine sgbt02 (caractère trans, entier m, entier n, entier kl, entier ku, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldx, * ) x, entier ldx, réel, dimension( ldb, * ) b, entier ldb, réel, dimension( * ) rwork, réel resid)

SGBT02

Objectif :

!>
!> SGBT02 calcule le résidu pour une solution d'un système d'équations
!> de bandes op(A)*X = B :
!>    RESID = norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ),
!> où op(A) = A ou A**T, selon TRANS, et EPS est l'epsilon machine.
!> La norme utilisée est la 1-norme.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' :  A    * X = B  (Pas de transposée)
!>          = 'T' :  A**T * X = B  (Transposée)
!>          = 'C' :  A**H * X = B  (Conjuguée transposée = Transposée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de colonnes de B.  NRHS >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice originale A en stockage de bande, stockée dans les
!>          lignes 1 à KL+KU+1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,KL+KU+1).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>          Les vecteurs solution calculés pour le système d'équations
!>          linéaires.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  Si TRANS = 'N',
!>          LDX >= max(1,N) ; si TRANS = 'T' ou 'C', LDX >= max(1,M).
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          À l'entrée, les vecteurs de membre droit pour le système d'équations
!>          linéaires.
!>          À la sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  Si TRANS = 'N',
!>          LDB >= max(1,M) ; si TRANS = 'T' ou 'C', LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REAL, dimension (MAX(1,LRWORK)),
!>          où LRWORK >= M lorsque TRANS = 'T' ou 'C' ; sinon, RWORK
!>          n'est pas référencé.
!>

RESID

!>          RESID est REAL
!>          Le maximum sur le nombre de membres droits de
!>          norm(B - op(A)*X) / ( norm(op(A)) * norm(X) * EPS ).
!>
