SGGESX calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

But :

!>
!> SGGESX calcule pour une paire de matrices réelles N-par-N non symétriques
!> (A,B), les valeurs propres généralisées, la forme de Schur réelle (S,T), et,
!> éventuellement, les matrices gauche et/ou droite des vecteurs de Schur (VSL et
!> VSR). Ceci donne la factorisation de Schur généralisée
!>
!>      (A,B) = ( (VSL) S (VSR)**T, (VSL) T (VSR)**T )
!>
!> Éventuellement, elle ordonne également les valeurs propres de sorte qu'un cluster
!> sélectionné de valeurs propres apparaisse dans les blocs diagonaux principaux de la
!> matrice quasi-triangulaire supérieure S et de la matrice triangulaire supérieure T;
!> calcule un nombre de condition réciproque pour la moyenne des valeurs propres
!> sélectionnées (RCONDE); et calcule un nombre de condition réciproque pour les
!> sous-espaces défléchissants droit et gauche correspondant aux valeurs propres
!> sélectionnées (RCONDV). Les colonnes principales de VSL et VSR forment alors
!> une base orthonormée pour les sous-espaces propres (défléchissants) correspondants.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulier. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une
!> interprétation raisonnable pour beta=0 ou pour que les deux soient zéro.
!>
!> Une paire de matrices (S,T) est en forme de Schur généralisée réelle si T est
!> triangulaire supérieure avec une diagonale non négative et S est bloc triangulaire
!> supérieure avec des blocs de 1x1 et 2x2. Les blocs de 1x1 correspondent
!> à des valeurs propres généralisées réelles, tandis que les blocs de 2x2 de S seront
!>  en rendant les éléments correspondants de T de la forme :
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> et la paire de blocs 2x2 correspondants dans S et T aura une paire
!> de valeurs propres généralisées complexes conjuguées.
!>
!>

Paramètres

JOBVSL 
!>          JOBVSL est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur gauches ;
!>          = 'V':  calculer les vecteurs de Schur gauches.
!>

JOBVSR

!>          JOBVSR est CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs de Schur droits ;
!>          = 'V':  calculer les vecteurs de Schur droits.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non
!>          sur la diagonale de la forme de Schur généralisée.
!>          = 'N':  Les valeurs propres ne sont pas ordonnées ;
!>          = 'S':  Les valeurs propres sont ordonnées (voir SELCTG).
!>

SELCTG

!>          SELCTG est une FONCTION LOGIQUE de trois arguments RÉELS
!>          SELCTG doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'N', SELCTG n'est pas référencée.
!>          Si SORT = 'S', SELCTG est utilisée pour sélectionner les valeurs propres à trier
!>          en haut à gauche de la forme de Schur.
!>          Une valeur propre (ALPHAR(j)+ALPHAI(j))/BETA(j) est sélectionnée si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) est vraie ; c'est-à-dire si
!>          l'une des valeurs propres complexes conjuguées est sélectionnée,
!>          alors les deux valeurs propres complexes sont sélectionnées.
!>          Notez qu'une valeur propre complexe sélectionnée peut ne plus satisfaire
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) = .VRAI. après l'ordonnancement,
!>          car l'ordonnancement peut modifier la valeur des valeurs propres
!>          complexes (surtout si la valeur propre est mal conditionnée), dans ce
!>          cas INFO est mis à N+3.
!>

SENSE

!>          SENSE est CHARACTER*1
!>          Détermine quels nombres de condition réciproques sont calculés.
!>          = 'N':  Aucun n'est calculé ;
!>          = 'E':  Calculé pour la moyenne des valeurs propres sélectionnées uniquement ;
!>          = 'V':  Calculé pour les sous-espaces défléchissants sélectionnés uniquement ;
!>          = 'B':  Calculé pour les deux.
!>          Si SENSE = 'E', 'V' ou 'B', SORT doit être égal à 'S'.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, VSL et VSR. N >= 0.
!>

A

!>          A est un tableau RÉEL, dimension (LDA, N)
!>          En entrée, le premier de la paire de matrices.
!>          En sortie, A a été écrasé par sa forme de Schur généralisée
!>          S.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau RÉEL, dimension (LDB, N)
!>          En entrée, le second de la paire de matrices.
!>          En sortie, B a été écrasé par sa forme de Schur généralisée
!>          T.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM est ENTIER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres (après tri)
!>          pour lesquelles SELCTG est vrai. (Les paires complexes conjuguées pour lesquelles
!>          SELCTG est vrai pour l'une ou l'autre valeur propre comptent pour 2.)
!>

ALPHAR

!>          ALPHAR est un tableau RÉEL, dimension (N)
!>

ALPHAI

!>          ALPHAI est un tableau RÉEL, dimension (N)
!>

BETA

!>          BETA est un tableau RÉEL, dimension (N)
!>          En sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, seront
!>          les valeurs propres généralisées. ALPHAR(j) + ALPHAI(j)*i
!>          et BETA(j), j=1,...,N sont les diagonales de la forme de Schur complexe
!>          (S,T) qui résulterait si les blocs diagonaux 2x2 de
!>          la forme de Schur réelle de (A,B) étaient davantage réduits
!>          en forme triangulaire en utilisant des transformations unitaires complexes 2x2.
!>          Si ALPHAI(j) est zéro, alors la j-ème valeur propre est réelle ; si
!>          positive, alors la j-ème et la (j+1)-ème valeurs propres sont une
!>          paire complexe conjuguée, avec ALPHAI(j+1) négatif.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder ou sous-déborder, et BETA(j) peut même être zéro.
!>          Par conséquent, l'utilisateur doit éviter de calculer naivement le rapport.
!>          Cependant, ALPHAR et ALPHAI seront toujours inférieurs et
!>          généralement comparables à norm(A) en magnitude, et BETA toujours
!>          inférieur et généralement comparable à norm(B).
!>

VSL

!>          VSL est un tableau RÉEL, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contiendra les vecteurs de Schur gauches

NAME


sggesx — Computes the eigenvalues and, optionally, the left and right Schur
   vectors and the reciprocal condition numbers for eigenvalues and/or
   eigenvectors of a pair of real matrices (A,B) in general
   real Schur form.






SYNOPSIS


  SUBROUTINE SGGESX( JOBVSL, JOBVSR, SORT, SELCTG, N, A, LDA, B, LDB,
                  ALPHA, BETA, VSL, LDVSL, VSR, LDVSR, RCONDE, RCONDV,
                  WORK, LWORK, IWORK, LIWORK, BWORK, INFO )
  CHARACTER * 1           JOBVSL
  CHARACTER * 1           JOBVSR
  CHARACTER * 1           SORT
  LOGICAL                 SELCTG
  INTEGER                 N
  REAL                    A( LDA, * )
  INTEGER                 LDA
  REAL                    B( LDB, * )
  INTEGER                 LDB
  REAL                    ALPHA( * )
  REAL                    BETA( * )
  REAL                    VSL( LDVSL, * )
  INTEGER                 LDVSL
  REAL                    VSR( LDVSR, * )
  INTEGER                 LDVSR
  REAL                    RCONDE( * )
  REAL                    RCONDV( * )
  REAL                    WORK( * )
  INTEGER                 LWORK
  INTEGER                 IWORK( * )
  INTEGER                 LIWORK

Function/Subroutine Documentation


SGGESX computes for an N-by-N pair of real matrices (A,B),
   the generalized eigenvalues and, optionally, the matrices VSL and/or
   VSR of left and right Schur vectors, respectively.
   A generalized Schur decomposition is returned in the form:


   A = Q * ( A_tilde ) * Z**T
       (  T  )
   B = Q * ( B_tilde ) * Z**T
       (  0  )


   where Q and Z are orthogonal matrices.
   A_tilde and B_tilde are upper triangular matrices.
   The columns of VSL and VSR are the left and right Schur vectors
   respectively.
   The eigenvalues are computed as the roots of the characteristic equation
   det(A - omega * B) = 0; omega are the generalized eigenvalues.
   If the pair (A,B) is converted to the generalized upper triangular form
   (A_tilde, B_tilde) by the QR decomposition, then the generalized eigenvalues
   are computed as the roots of the characteristic equation
   det(A_tilde - omega * B_tilde) = 0;
   the roots are returned in the arrays ALPHA and BETA.
   If matrix B is singular, the standard eigenvalues are computed as
   the roots of the characteristic equation det(A - lambda * I) = 0;
   in this case, the problem is solved in the form (A, B) = (Q*A*Z^T, Q*B*Z^T)
   where Z is orthogonal and Q is orthogonal.
   If the pair (A,B) is converted to the generalized upper triangular form
   (A_tilde, B_tilde) by the QR decomposition, then the eigenvalues are
   computed as the roots of the characteristic equation det(A_tilde - lambda * I) = 0;
   the roots are returned in the arrays ALPHA and BETA.
   If matrix A is singular, the standard eigenvalues are computed as
   the roots of the characteristic equation det(B - lambda * I) = 0;
   in this case, the problem is solved in the form (A, B) = (Q*A*Z^T, Q*B*Z^T)
   where Z is orthogonal and Q is orthogonal.
   If the pair (A,B) is converted to the generalized upper triangular form
   (A_tilde, B_tilde) by the QR decomposition, then the eigenvalues are
   computed as the roots of the characteristic equation det(B_tilde - lambda * I) = 0;
   the roots are returned in the arrays ALPHA and BETA.
   The computation of the reciprocal condition numbers is based on SLAMCH for
   machine epsilon and the algorithm described in the Reference.
   

   
JOBVSL

   

   
JOBVSL is CHARACTER*1
          = 'N': do not compute the left Schur vectors VSL.
          = 'V': compute the left Schur vectors VSL.
   

   

   
JOBVSR

   

   
JOBVSR is CHARACTER*1
          = 'N': do not compute the right Schur vectors VSR.
          = 'V': compute the right Schur vectors VSR.
   

   

   
SORT

   

   
SORT is CHARACTER*1
          = 'N': do not permute the Schur vectors.
          = 'S': permute the Schur vectors so that the eigenvalues
                 are ordered according to the criterion specified by
                 SELCTG.
   

   

   
SELCTG

   

   
SELCTG is LOGICAL function, dimension (N).
          If SORT = 'S', SELCTG is used to select the eigenvalues.
          SELCTG(j) is true if the j-th eigenvalue is selected, and
          false otherwise.
          If SORT = 'N', SELCTG is not referenced.
   

   

   
N

   

   
N is INTEGER
          The order of the matrices A and B. N >= 0.
   

   

   
A

   

   
A is REAL array, dimension (LDA, N)
          On entry, the N-by-N matrix A.
          On exit, if INFO = 0 and LWORK is sufficiently large, A contains
          the generalized Schur form of the original matrix A.
   

   

   
LDA

   

   
LDA is INTEGER
          The leading dimension of A. LDA >= max(1, N).
   

   

   
B

   

   
B is REAL array, dimension (LDB, N)
          On entry, the N-by-N matrix B.
          On exit, if INFO = 0 and LWORK is sufficiently large, B contains
          the generalized Schur form of the original matrix B.
   

   

   
LDB

   

   
LDB is INTEGER
          The leading dimension of B. LDB >= max(1, N).
   

   

   
ALPHA

   

   
ALPHA is REAL array, dimension (N)
          BETA is REAL array, dimension (N)
          On exit, the complex generalized eigenvalues are returned in the
          arrays ALPHA and BETA, and represent the roots of the
          equation:
          det( A - omega * B ) = 0
          The eigenvalues omega are returned in the form
          omega = ALPHA(j) / BETA(j).
          Note that each calling for SGGEESX returns values of ALPHA and
          BETA that represent the same set of generalized eigenvalues.
   

   

   
VSL

   

   
VSL is REAL array, dimension (LDVSL, N)
          If JOBVSL = 'V', VSL will contain the left Schur vectors.
          Not referenced if JOBVSL = 'N'.
   

   

   
LDVSL

   

   
LDVSL is INTEGER
          The leading dimension of the matrix VSL. LDVSL >= 1, and
          if JOBVSL = 'V', LDVSL >= N.
   

   

   
VSR

   

   
VSR is REAL array, dimension (LDVSR,N)
          If JOBVSR = 'V', VSR will contain the right Schur vectors.
          Not referenced if JOBVSR = 'N'.
   

   

   
LDVSR

   

   
LDVSR is INTEGER
          The leading dimension of the matrix VSR. LDVSR >= 1, and
          if JOBVSR = 'V', LDVSR >= N.
   

   

   
RCONDE

   

   
RCONDE is REAL array, dimension ( 2 )
          If SENSE = 'E' or 'B', RCONDE(1) and RCONDE(2) contain the
          reciprocal condition numbers for the average of the selected
          eigenvalues.
          Not referenced if SENSE = 'N' or 'V'.
   

   

   
RCONDV

   

   
RCONDV is REAL array, dimension ( 2 )
          If SENSE = 'V' or 'B', RCONDV(1) and RCONDV(2) contain the
          reciprocal condition numbers for the selected deflating
          subspaces.
          Not referenced if SENSE = 'N' or 'E'.
   

   

   
WORK

   

   
WORK is REAL array, dimension (MAX(1,LWORK))
          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
   

   

   
LWORK

   

   
LWORK is INTEGER
          The dimension of the array WORK.
          If N = 0, LWORK >= 1, else if SENSE = 'E', 'V', or 'B',
          LWORK >= max( 8*N, 6*N+16, 2*SDIM*(N-SDIM) ), else
          LWORK >= max( 8*N, 6*N+16 ).
          Note that 2*SDIM*(N-SDIM) <= N*N/2.
          Note also that an error is only returned if
          LWORK < max( 8*N, 6*N+16), but if SENSE = 'E' or 'V' or 'B'
          this may not be large enough.

          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the bound on the optimal size of the WORK
          array and the minimum size of the IWORK array, returns these
          values as the first entries of the WORK and IWORK arrays, and
          no error message related to LWORK or LIWORK is issued by
          XERBLA.
   

   

   
IWORK

   

   
IWORK is INTEGER array, dimension (MAX(1,LIWORK))
          On exit, if INFO = 0, IWORK(1) returns the minimum LIWORK.
   

   

   
LIWORK

   

   
LIWORK is INTEGER
          The dimension of the array IWORK.
          If SENSE = 'N' or N = 0, LIWORK >= 1, otherwise
          LIWORK >= N+6.

          If LIWORK = -1, then a workspace query is assumed; the
          routine only calculates the bound on the optimal size of the
          WORK array and the minimum size of the IWORK array, returns
          these values as the first entries of the WORK and IWORK
          arrays, and no error message related to LWORK or LIWORK is
          issued by XERBLA.
   

   

   
BWORK

   

   
BWORK is LOGICAL array, dimension (N)
          Not referenced if SORT = 'N'.
   

   

   
INFO

   

   
INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value.
          = 1,...,N:
                The QZ iteration failed.  (A,B) are not in Schur
                form, but ALPHAR(j), ALPHAI(j), and BETA(j) should
                be correct for j=INFO+1,...,N.
          > N:  =N+1: other than QZ iteration failed in SHGEQZ
                =N+2: after reordering, roundoff changed values of
                      some complex eigenvalues so that leading
                      eigenvalues in the Generalized Schur form no
                      longer satisfy SELCTG=.TRUE.  This could also
                      be caused due to scaling.
                =N+3: reordering failed in STGSEN.

Further Details:




  An approximate (asymptotic) bound on the average absolute error of
  the selected eigenvalues is
  EPS * norm((A, B)) / RCONDE( 1 ).
  An approximate (asymptotic) bound on the maximum angular error in
  the computed deflating subspaces is
  EPS * norm((A, B)) / RCONDV( 2 ).
  See LAPACK User's Guide, section 4.11 for more information.
