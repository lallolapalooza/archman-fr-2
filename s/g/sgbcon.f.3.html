sous-programme sgbcon (caractère norm, entier n, entier kl, entier ku, réel, dimension( ldab, * ) ab, entier ldab, entier, dimension( * ) ipiv, réel anorm, réel rcond, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SGBCON

But :

!>
!> SGBCON estime l'inverse du nombre de condition d'une matrice bande réelle
!> générale A, soit dans la norme 1, soit dans la norme infini,
!> en utilisant la factorisation LU calculée par SGBTRF.
!>
!> Une estimation est obtenue pour norm(inv(A)), et l'inverse du
!> nombre de condition est calculé comme
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infini est requis :
!>          = '1' ou 'O' :  Norme 1 ;
!>          = 'I'      :  Norme infini.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KL

!>          KL est INTEGER
!>          Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est INTEGER
!>          Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est tableau de type REAL, dimension (LDAB,N)
!>          Détails de la factorisation LU de la matrice bande A, telle que
!>          calculée par SGBTRF.  U est stockée comme une matrice bande
!>          triangulaire supérieure avec KL+KU super-diagonales dans les
!>          lignes 1 à KL+KU+1, et les multiplicateurs utilisés lors de la
!>          factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est tableau de type INTEGER, dimension (N)
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la matrice a
!>          été échangée avec la ligne IPIV(i).
!>

ANORM

!>          ANORM est REAL
!>          Si NORM = '1' ou 'O', la norme 1 de la matrice originale A.
!>          Si NORM = 'I', la norme infini de la matrice originale A.
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est tableau de type REAL, dimension (3*N)
!>

IWORK

!>          IWORK est tableau de type INTEGER, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
