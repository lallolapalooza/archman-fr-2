DESCRIPTION

Les fonctions sg_get_process_stats fournissent des statistiques sur les processus en cours d'exécution. Les deux fonctions, sg_get_process_stats() et sg_get_process_stats_r(), prennent un paramètre optionnel `entries`, qui pointe (lorsqu'il est fourni) vers un `size_t` pour récupérer le nombre d'entrées du vecteur retourné.

Les fonctions sg_get_process_count_of() et sg_get_process_count_r() fournissent une vue agrégée de la table des processus - elles livrent le nombre de processus par état de processus. sg_get_process_count() est en fait une macro préprocesseur pour la compatibilité ascendante et appelle sg_get_process_count_of() avec le paramètre `pcs` de `sg_entire_process_count` pour émuler le comportement jusqu'à la version 0.17.

Raccourcis API

fonction retourne propriétaire des données
sg_get_process_stats sg_process_stats * libstatgrab (thread local)
sg_get_process_stats_r sg_process_stats * l'appelant
sg_get_process_count_of sg_process_count * libstatgrab (thread local)
sg_get_process_count_r sg_process_count * l'appelant

Les vecteurs `sg_process_stats` reçus de sg_get_process_stats_r() ou les résumés `sg_process_count` reçus de sg_get_process_count_r doivent être libérés en utilisant sg_free_process_stats() ou sg_free_process_count(), respectivement. L'appelant est responsable de le faire lorsque les données ne sont plus nécessaires.

sg_process_compare_name
sg_process_compare_pid
sg_process_compare_uid
sg_process_compare_gid
sg_process_compare_size
sg_process_compare_res
sg_process_compare_cpu
sg_process_compare_time

Ces fonctions comparent deux entrées `sg_process_stats` et retournent un entier pour représenter laquelle est la plus grande. L'utilisation principale de ces fonctions est d'être passée à `qsort` pour trier les `sg_process_stats` par le type donné.

Exemple

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* ordonner les entrées en comparant l'identifiant du processus */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

VALEUR DE RETOUR

La structure retournée par sg_get_process_stats est de type sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* identifiant du processus */
        pid_t parent; /* PID du parent */
        pid_t pgid;   /* PID du leader du groupe de processus */
        pid_t sessid; /* ID de session auquel le processus appartient */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* en octets */
        unsigned long long proc_resident; /* en octets */
        time_t start_time; /* Heure de démarrage du processus */
        time_t time_spent; /* temps passé à tourner en secondes */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
Le nom de la commande qui a été exécutée. Le contenu de ce champ dépend fortement du système d'exploitation sous-jacent, certains stockent le nom de base de l'exécutable passé à l'appel système exec(2), d'autres le chemin complet. La plupart des systèmes d'exploitation limitent la taille de ce champ - certains, comme la famille *BSD, à une valeur très faible de 15 octets.

Ce champ est généralement immuable pour les processus utilisateur.

proctitle
La ligne de commande (le "titre") du processus. Attention : cela peut être modifié par le processus, donc rien ne garantit que ce soit la ligne de commande d'origine.
pid
L'identifiant du processus.
parent
L'identifiant du processus parent.
pgid
L'identifiant du processus du leader du groupe de processus.
sessid
L'identifiant de session auquel le processus appartient.
uid
L'identifiant de l'utilisateur sous lequel le processus s'exécute.
euid
L'identifiant de l'utilisateur effectif sous lequel le processus s'exécute.
gid
L'identifiant du groupe sous lequel le processus s'exécute.
egid
L'identifiant du groupe effectif sous lequel le processus s'exécute.
context_switches
Le nombre de changements de contexte de ce processus (volontaires et involontaires).
voluntary_context_switches
Le nombre de changements de contexte volontaires de ce processus (par exemple, en appelant sched_yield() ou sleep()).
involuntary_context_switches
Le nombre de changements de contexte involontaires de ce processus (par exemple, expiration de la tranche de temps ou signal envoyé).
proc_size
La taille de la mémoire virtuelle du processus en octets.
proc_resident
La taille de la mémoire résidente (physique) du processus en octets.
start_time
Le temps (en secondes depuis l'epoch) auquel le processus a été démarré.
time_spent
Le temps total en secondes pendant lequel le processus a été dans l'état d'exécution.
cpu_percent
Le pourcentage d'utilisation du CPU par ce processus.
nice
La valeur nice du processus.
state
L'état actuel du processus, une des valeurs de l'énumération `sg_process_state`. Ces états sont–
SG_PROCESS_STATE_RUNNING
Le processus est en cours d'exécution ou prêt à être exécuté.
SG_PROCESS_STATE_SLEEPING
Le processus est en attente d'un événement.
SG_PROCESS_STATE_STOPPED
Le processus est arrêté (par exemple, par un signal).
SG_PROCESS_STATE_ZOMBIE
Le processus est terminé mais son entrée dans la table des processus n'a pas encore été libérée par son parent.
SG_PROCESS_STATE_UNKNOWN
L'état du processus est inconnu.
systime
Temps système utilisé par le processus en secondes.

La structure retournée par sg_get_process_count est de type sg_process_count.

typedef struct {
    unsigned long long running;
    unsigned long long sleeping;
    unsigned long long stopped;
    unsigned long long zombie;
    unsigned long long unknown;
} sg_process_count;

Les champs `running`, `sleeping`, `stopped`, `zombie` et `unknown` donnent le nombre de processus dans chacun de ces états.

Les fonctions de comparaison retournent un entier négatif si `va` est plus petit que `vb`, zéro s'ils sont égaux, et un entier positif si `va` est plus grand que `vb`.

sg_get_process_count(3) - libstatgrab

NAME

sg_get_process_count, sg_get_process_count_of, sg_get_process_count_r, sg_process_count_free - get process statistics

SYNOPSIS

#include <statgrab.h>

void *
sg_get_process_count(void);

void *
sg_get_process_count_of(enum sg_process_count_source source);

sg_process_count *
sg_get_process_count_r(enum sg_process_count_source source,
sg_error *error);

void
sg_process_count_free(sg_process_count *process_count);

DESCRIPTION

The sg_get_process_count function, and the sg_get_process_count_of function returns a pointer to a sg_process_count structure containing information about the processes on the system.

The sg_get_process_count_of function allows to specify if all processes should be counted or if only running processes should be counted by passing sg_entire_process_count or sg_last_process_count respectively.

The sg_get_process_count_r function is similar to sg_get_process_count_of, but it is thread safe and will return an error code in the sg_error structure pointed to by error.

The sg_process_count_free function frees the memory occupied by the sg_process_count structure.

The following structure is returned by sg_get_process_count, sg_get_process_count_of, and sg_get_process_count_r:

typedef struct{
        unsigned long long proc_resident;
        unsigned long long start_time;
        unsigned long long time_spent;
        unsigned long long cpu_percent;
        long nice;
        int state;
        time_t systime;
}sg_process_info;
proc_resident
La taille du processus qui réside en mémoire.
start_time
L'heure de démarrage du processus en secondes depuis l'époque.
time_spent
Le nombre de secondes pendant lesquelles le processus a été exécuté (temps utilisateur+système, sans le temps passé par les processus enfants).
cpu_percent
Le pourcentage actuel de CPU utilisé par le processus.
nice
La valeur nice du processus.
state
L'état actuel du processus. Voir sg_process_state pour les valeurs permises.
systime
Le temps en secondes depuis l'époque du moment où la statistique actuelle a été créée. Cela peut être (mais ne doit pas nécessairement être) le même moment pour toutes les entrées retournées, qu'elles soient récupérées avec un seul instantané ou assemblées à partir d'une sorte de procfs.

La structure retournée par sg_get_process_count_of et sg_get_process_count_r est de type sg_process_count.

typedef enum sg_process_count_source {
        sg_entire_process_count,
        sg_last_process_count
} sg_process_count_source;

typedef struct{
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long unknown;
        time_t systime;
}sg_process_count;
total
Le nombre total de processus.
running
Le nombre de processus en cours d'exécution.
sleeping
Le nombre de processus en sommeil.
stopped
Le nombre de processus arrêtés.
zombie
Le nombre de processus zombies.
unknown
Le nombre de processus ne correspondant à aucune des catégories nommées ci-dessus.
systime
Le temps en secondes depuis l'époque du moment où la statistique actuelle a été créée.

BUGS

Le tout premier appel de sg_get_process_count_of(sg_last_process_count) retournera la même chose que sg_get_process_count_of(sg_entire_process_count).

Les fonctions de comparaison existent plutôt pour des raisons de compatibilité descendante que pour des améliorations de fonctionnalités. Une flexibilité limitée (par exemple, ordre inverse) et le manque d'opportunités d'optimisation pour le compilateur conduisent à la recommandation d'implémenter localement les routines de comparaison requises.
