Documentation de la fonction/sous-routine

sous-routine sgemqr (caractère side, caractère trans, entier m, entier n, entier k, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) t, entier tsize, réel, dimension( ldc, * ) c, entier ldc, réel, dimension( * ) work, entier lwork, entier info)

SGEMQR

Purpose:

!>
!> SGEMQR écrase la matrice réelle M par N, C, avec
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>     TRANS = 'N':      Q * C          C * Q
!>     TRANS = 'T':      Q**T * C       C * Q**T
!>
!> où Q est une matrice orthogonale réelle définie comme le produit
!> de réflecteurs élémentaires bloqués calculés par la factorisation QR
!> mince et haute (SGEQR).
!>
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T à Gauche ;
!>          = 'R': appliquer Q ou Q**T à Droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, appliquer Q ;
!>          = 'T':  Transposée, appliquer Q**T.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >=0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est tableau de REEL, dimension (LDA,K)
!>          Partie de la structure de données représentant Q tel que retourné par SGEQR.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T est tableau de REEL, dimension (MAX(5,TSIZE)).
!>          Partie de la structure de données représentant Q tel que retourné par SGEQR.
!>

TSIZE

!>          TSIZE est INTEGER
!>          La dimension du tableau T. TSIZE >= 5.
!>

C

!>          C est tableau de REEL, dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>         (espace de travail) tableau de REEL, dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée. La routine
!>          calcule seulement la taille du tableau WORK, retourne cette
!>          valeur comme WORK(1), et aucun message d'erreur lié à WORK
!>          n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires

!>

!>
!>          T(2): taille de bloc de lignes (MB)
!>          T(3): taille de bloc de colonnes (NB)
!>          T(6:TSIZE): structure de données nécessaire pour Q, calculée par
!>                           SLATSQR ou SGEQRT
!>
!>  Selon les dimensions M et N, et les tailles de blocs de lignes et de colonnes
!>  MB et NB retournées par ILAENV, SGEQR utilisera soit
!>  SLATSQR (si la matrice est haute et mince) soit SGEQRT pour calculer
!>  la factorisation QR.
!>  Cette version de SGEMQR utilisera soit SLAMTSQR soit SGEMQRT pour
!>  multiplier la matrice Q par une autre matrice.
!>  Détails supplémentaires dans SLAMTSQR ou SGEMQRT.
!>
