Documentation de la fonction/sous-programme

sous-programme sgeev (caractere jobvl, caractere jobvr, entier n, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) wr, reel, dimension( * ) wi, reel, dimension( ldvl, * ) vl, entier ldvl, reel, dimension( ldvr, * ) vr, entier ldvr, reel, dimension( * ) work, entier lwork, entier info)

SGEEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices GE

Objectif :

!>
!> SGEEV calcule pour une matrice réelle N-par-N non symétrique A, les
!> valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits.
!>
!> Le vecteur propre droit v(j) de A satisfait
!>                  A * v(j) = lambda(j) * v(j)
!> où lambda(j) est sa valeur propre.
!> Le vecteur propre gauche u(j) de A satisfait
!>               u(j)**H * A = lambda(j) * u(j)**H
!> où u(j)**H dénote la transposée conjuguée de u(j).
!>
!> Les vecteurs propres calculés sont normalisés pour avoir une norme Euclidienne
!> égale à 1 et le plus grand composant réel.
!>

Paramètres

JOBVL 
!>          JOBVL est CARACTERE*1
!>          = 'N': les vecteurs propres gauches de A ne sont pas calculés ;
!>          = 'V': les vecteurs propres gauches de A sont calculés.
!>

JOBVR

!>          JOBVR est CARACTERE*1
!>          = 'N': les vecteurs propres droits de A ne sont pas calculés ;
!>          = 'V': les vecteurs propres droits de A sont calculés.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          En entrée, la matrice A de taille N-par-N.
!>          En sortie, A a été écrasée.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

WR

!>          WR est un tableau REEL, de dimension (N)
!>

WI

!>          WI est un tableau REEL, de dimension (N)
!>          WR et WI contiennent les parties réelles et imaginaires,
!>          respectivement, des valeurs propres calculées. Les paires
!>          de valeurs propres complexes conjuguées apparaissent consécutivement,
!>          la valeur propre avec la partie imaginaire positive étant en premier.
!>

VL

!>          VL est un tableau REEL, de dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres gauches u(j) sont stockés l'un après
!>          l'autre dans les colonnes de VL, dans le même ordre que leurs
!>          valeurs propres.
!>          Si JOBVL = 'N', VL n'est pas référencé.
!>          Si la j-ième valeur propre est réelle, alors u(j) = VL(:,j),
!>          la j-ième colonne de VL.
!>          Si la j-ième et la (j+1)-ième valeurs propres forment une paire
!>          complexe conjuguée, alors u(j) = VL(:,j) + i*VL(:,j+1) et
!>          u(j+1) = VL(:,j) - i*VL(:,j+1).
!>

LDVL

!>          LDVL est ENTIER
!>          La dimension principale du tableau VL. LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau REEL, de dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres droits v(j) sont stockés l'un après
!>          l'autre dans les colonnes de VR, dans le même ordre que leurs
!>          valeurs propres.
!>          Si JOBVR = 'N', VR n'est pas référencé.
!>          Si la j-ième valeur propre est réelle, alors v(j) = VR(:,j),
!>          la j-ième colonne de VR.
!>          Si la j-ième et la (j+1)-ième valeurs propres forment une paire
!>          complexe conjuguée, alors v(j) = VR(:,j) + i*VR(:,j+1) et
!>          v(j+1) = VR(:,j) - i*VR(:,j+1).
!>

LDVR

!>          LDVR est ENTIER
!>          La dimension principale du tableau VR. LDVR >= 1; si
!>          JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK est un tableau REEL, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie la taille optimale de LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,3*N), et
!>          si JOBVL = 'V' ou JOBVR = 'V', LWORK >= 4*N. Pour de bonnes
!>          performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, l'algorithme QR n'a pas réussi à calculer toutes les
!>                valeurs propres, et aucun vecteur propre n'a été calculé ;
!>                les éléments i+1:N de WR et WI contiennent les valeurs propres qui
!>                ont convergé.
!>
