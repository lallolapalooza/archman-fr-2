NOM

sg_rem_rest_elem - envoie une commande SCSI pour supprimer ou restaurer un élément

SYNTAXE

sg_rem_rest_elem [--capacity=RC] [--element=EID] [--help] [--quick] [--remove] [--restore] [--timeout=SE] [--verbose] [--version] PÉRIPHÉRIQUE

DESCRIPTION

Envoie une commande SCSI REMOVE ELEMENT AND TRUNCATE [RMEAT] ou RESTORE ELEMENTS AND REBUILD [RSEAR] au PÉRIPHÉRIQUE. Comme ces deux commandes ont un impact potentiellement énorme sur le PÉRIPHÉRIQUE (similaire à la commande FORMAT UNIT : destruction de données et longue durée d'exécution complète), elles donnent d'abord à l'utilisateur la possibilité de reconsidérer (3 fois en 15 secondes) avant d'agir.

Contrairement à la commande FORMAT UNIT, ces commandes semblent conçues pour fonctionner en arrière-plan. Elles retourneront donc rapidement (bien que sbc5r01.pdf ne le stipule pas) et le disque sera placé dans un état de fonctionnalité réduite où seul un nombre spécifié de commandes sera exécuté (par exemple, INQUIRY et REPORT LUNS) jusqu'à ce que l'opération soit terminée. D'autres commandes recevront des données de détection avec une clé de détection de NOT READY et un code de détection supplémentaire de 'Depopulation in progress' (pour RMEAT) ou 'Depopulation restoration in progress' (pour RSEAR).

La commande REMOVE ELEMENT AND TRUNCATE a un proche parent en ZBC-2 appelé REMOVE ELEMENT AND MODIFY ZONES [RMEMZ]. Voir l'utilitaire sg_zone pour une implémentation de cette dernière commande.
La différence entre RMEAT et RMEMZ est que la première "modifie l'association entre les LBAs et les blocs physiques" et la seconde ne modifie pas cette association. Les zones affectées par la commande RMEMZ sont placées dans la condition de zone : "Offline".

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-c, --capacity=RC
RC signifie Requested Capacity (Capacité Demandée) et est le nombre de blocs logiques que le PÉRIPHÉRIQUE devrait avoir après la suppression de l'élément avec la commande RMEAT. La valeur par défaut est 0, ce qui permet au PÉRIPHÉRIQUE de décider quelle sera la capacité réduite après la suppression de l'élément. La commande RSEAR ignore cette valeur.
-e, --element=EID
où EID est un identifiant d'élément, un entier non signé de 32 bits commençant à un. Ce champ est utilisé par la commande RMEAT et ignoré sinon. La valeur par défaut est zéro (ce qui est invalide). L'utilisateur doit donc fournir un identifiant d'élément valide lorsque --remove est utilisé.
-h, --help
affiche le message d'aide puis quitte.
-q, --quick
l'action par défaut (c'est-à-dire lorsque cette option n'est pas donnée) consiste à laisser à l'utilisateur 15 secondes pour reconsidérer une opération de suppression ou de restauration d'élément sur le PÉRIPHÉRIQUE. Lorsque cette option est donnée, cette étape (c'est-à-dire la période d'avertissement de 15 secondes) est contournée.
-r, --remove
provoque l'envoi de la commande REMOVE ELEMENT AND TRUNCATE au PÉRIPHÉRIQUE. En pratique, --element=EID doit également être fourni.
-R, --restore
provoque l'envoi de la commande RESTORE ELEMENTS AND REBUILD au PÉRIPHÉRIQUE.
-t, --timeout=SE
où SE est le délai d'attente de la commande en secondes. La valeur par défaut est 60 secondes et si 0 est donné, il est mappé à 60. Une forme longue alternative est --tmo=SE.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire les messages de débogage).
-V, --version
affiche la chaîne de version puis quitte.

NOTES

Une fois qu'un élément est supprimé avec succès, il est qualifié de "dépopulé". Les éléments dépopulés pour lesquels le bit 'Restoration Allowed' (RALWD) est défini (voir sg_get_elem_status) sont candidats pour une restauration future.

Un élément (de stockage) d'un disque dur rotatif est une face d'une plaque généralement associée à une tête. Ces disques durs ont généralement plusieurs plateaux avec deux têtes par plateau (c'est-à-dire une tête de chaque côté de la plaque).

STATUT DE SORTIE

Le statut de sortie de sg_rem_rest_elem est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
