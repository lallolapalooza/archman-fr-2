SGGSVP

But :

!>
!> Cette routine est obsolète et a été remplacée par la routine SGGSVP3.
!>
!> SGGSVP calcule des matrices orthogonales U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0 ;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0 ;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice A12 de taille KxK et la matrice B13 de taille LxL sont non singulières
!> et triangulaires supérieures ; A23 est triangulaire supérieure de taille LxL si M-K-L >= 0,
!> sinon A23 est trapézoïdale supérieure de taille (M-K)xL.  K+L = le rang
!> numérique effectif de la matrice (M+P)-by-N (A**T,B**T)**T.
!>
!> Cette décomposition est l'étape de pré-traitement pour calculer la
!> Décomposition en Valeurs Singulières Généralisées (GSVD), voir la sous-routine
!> SGGSVD.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          = 'U':  La matrice orthogonale U est calculée ;
!>          = 'N':  U n'est pas calculée.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          = 'V':  La matrice orthogonale V est calculée ;
!>          = 'N':  V n'est pas calculée.
!>

JOBQ

!>          JOBQ est CHARACTER*1
!>          = 'Q':  La matrice orthogonale Q est calculée ;
!>          = 'N':  Q n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est tableau de REAL, dimension (LDA,N)
!>          En entrée, la matrice A de taille M-par-N.
!>          En sortie, A contient la matrice triangulaire (ou trapézoïdale)
!>          décrite dans la section But.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est tableau de REAL, dimension (LDB,N)
!>          En entrée, la matrice B de taille P-par-N.
!>          En sortie, B contient la matrice triangulaire décrite dans
!>          la section But.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,P).
!>

TOLA

!>          TOLA est REAL
!>

TOLB

!>          TOLB est REAL
!>
!>          TOLA et TOLB sont les seuils pour déterminer le rang
!>          numérique effectif de la matrice B et d'un sous-bloc de A. Généralement,
!>          ils sont définis à
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          La taille de TOLA et TOLB peut affecter la taille des erreurs inverses
!>          de la décomposition.
!>

K

!>          K est INTEGER
!>

L

!>          L est INTEGER
!>
!>          En sortie, K et L spécifient la dimension des sous-blocs
!>          décrits dans la section But.
!>          K + L = rang numérique effectif de (A**T,B**T)**T.
!>

U

!>          U est tableau de REAL, dimension (LDU,M)
!>          Si JOBU = 'U', U contient la matrice orthogonale U.
!>          Si JOBU = 'N', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= max(1,M) si
!>          JOBU = 'U' ; LDU >= 1 sinon.
!>

V

!>          V est tableau de REAL, dimension (LDV,P)
!>          Si JOBV = 'V', V contient la matrice orthogonale V.
!>          Si JOBV = 'N', V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V. LDV >= max(1,P) si
!>          JOBV = 'V' ; LDV >= 1 sinon.
!>

Q

!>          Q est tableau de REAL, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contient la matrice orthogonale Q.
!>          Si JOBQ = 'N', Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q' ; LDQ >= 1 sinon.
!>

IWORK

!>          IWORK est tableau de INTEGER, dimension (N)
!>

TAU

!>          TAU est tableau de REAL, dimension (N)
!>

WORK

!>          WORK est tableau de REAL, dimension (max(3*N,M,P))
!>

INFO

!>          INFO est INTEGER
!>          = 0:  Sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

La sous-routine utilise la sous-routine LAPACK SGEQPF pour la factorisation QR avec pivotement de colonnes afin de détecter le rang numérique effectif de la matrice A. Elle peut être remplacée par une meilleure stratégie de détermination du rang.

sggsvp - Trouve les valeurs singulières et les vecteurs gauches et droits associés à une paire de matrices réelles symétriques généralisées.

SYNOPIS

SUBROUTINE SGGsvp( VECT, UPLO, N, A, LDA, B, LDB, work )

INTEGER N

REAL A( LDA, * ), B( LDB, * )

REAL work( * )

LOGICAL VECT

Documentation des fonctions/sous-routines

Cette sous-routine calcule les valeurs singulières et les vecteurs gauches et droits associés à une paire de matrices réelles symétriques généralisées.

VECT
Logique. Indique s'il faut calculer les vecteurs.
UPLO
Caractère. Indique si la partie triangulaire supérieure ou inférieure de A et B est stockée.
N
Entier. Ordre des matrices.
A
Réel (N,N). Première matrice.
LDA
Entier. Ligne principale de A.
B
Réel (N,N). Deuxième matrice.
LDB
Entier. Ligne principale de B.
work
Réel (dimension). Tableau de travail.
