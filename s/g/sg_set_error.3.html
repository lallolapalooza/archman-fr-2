NOM

sg_set_error, sg_set_error_with_errno, sg_set_error_with_errno_code, sg_clear_error - définit la condition d'erreur

SYNTAXE

#include <statgrab.h>


sg_error sg_set_error
(sg_error code, const char *arg);


sg_error sg_set_error_with_errno
(sg_error code, const char *arg);


sg_error sg_set_error_with_errno_code
(sg_error code, const char *arg, int errno_value);


void sg_clear_error
(void);

DESCRIPTION

sg_set_error() définit la condition d'erreur survenue avec un argument. L'argument est généralement descriptif, par exemple le nom du fichier qui n'a pas pu être ouvert.

sg_set_error_with_errno() définit la condition d'erreur survenue avec un argument et la valeur de la variable système errno. L'argument est généralement descriptif, par exemple le nom de l'appel sysctl() qui a échoué.

sg_set_error_with_errno_code() définit la condition d'erreur survenue avec un argument et une valeur d'erreur d'un appel de bibliothèque système qui ne définit pas la variable errno (par exemple, les appels pthread_*). L'argument est généralement descriptif, par exemple le nom du mutex qui n'a pas pu être verrouillé.

sg_clear_error() efface la condition d'erreur actuelle.
