Documentation de la fonction/sous-programme

sous-programme sgelqt (integer m, integer n, integer mb, real, dimension( lda, * ) a, integer lda, real, dimension( ldt, * ) t, integer ldt, real, dimension( * ) work, integer info)

SGELQT

But :

!>
!> SGELQT calcule une factorisation LQ bloquée d'une matrice réelle M par N, A,
!> en utilisant la représentation WY compacte de Q.
!>

Paramètres

M 
!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est de type INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

MB

!>          MB est de type INTEGER
!>          La taille de bloc à utiliser dans le QR bloqué.  MIN(M,N) >= MB >= 1.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          À l'entrée, la matrice M par N, A.
!>          À la sortie, les éléments sur et sous la diagonale du tableau
!>          contiennent la matrice trapézoïdale inférieure L (M par MIN(M,N))
!>          (L est triangulaire inférieure si M <= N) ; les éléments au-dessus
!>          de la diagonale sont les lignes de V.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau de type REAL, de dimension (LDT,MIN(M,N))
!>          Les réflecteurs de bloc triangulaires supérieurs stockés sous forme compacte
!>          en tant que séquence de blocs triangulaires supérieurs. Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est de type INTEGER
!>          La dimension principale du tableau T.  LDT >= MB.
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (MB*N)
!>

INFO

!>          INFO est de type INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  La matrice V stocke les réflecteurs élémentaires H(i) dans la i-ème ligne
!>  au-dessus de la diagonale. Par exemple, si M=5 et N=3, la matrice V est
!>
!>               V = (  1  v1 v1 v1 v1 )
!>                   (     1  v2 v2 v2 )
!>                   (         1 v3 v3 )
!>
!>
!>  où les vi représentent les vecteurs qui définissent H(i), qui sont retournés
!>  dans la matrice A. Les 1 le long de la diagonale de V ne sont pas stockés dans A.
!>  Soit K=MIN(M,N). Le nombre de blocs est B = ceiling(K/MB), où chaque
!>  bloc est d'ordre MB sauf le dernier bloc, qui est d'ordre
!>  IB = K - (B-1)*MB. Pour chacun des B blocs, un facteur de réflecteur
!>  de bloc triangulaire supérieur est calculé : T1, T2, ..., TB. Les T
!>  de taille MBxMB (et IBxIB pour le dernier bloc) sont stockés dans la matrice
!>  T de taille MBxK comme suit :
!>
!>               T = (T1 T2 ... TB).
!>

Définition à la ligne 123 du fichier sgelqt.f.
