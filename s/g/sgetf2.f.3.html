Documentation de la fonction/sous-programme

sous-programme sgetf2 (entier m, entier n, réel, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, entier info)

SGETF2 calcule la factorisation LU d'une matrice générale m-par-n en utilisant le pivotage partiel avec échanges de lignes (algorithme non bloqué).

Objectif :

!>
!> SGETF2 calcule une factorisation LU d'une matrice générale m-par-n A
!> en utilisant le pivotage partiel avec échanges de lignes.
!>
!> La factorisation a la forme
!>    A = P * L * U
!> où P est une matrice de permutation, L est triangulaire inférieure avec des
!> éléments diagonaux unitaires (trapézoïdale inférieure si m > n), et U est
!> triangulaire supérieure (trapézoïdale supérieure si m < n).
!>
!> C'est la version de l'algorithme de Niveau 2 BLAS orientée vers la droite.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REEL, dimension (LDA,N)
!>          À l'entrée, la matrice m par n à factoriser.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A = P*L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (min(M,N))
!>          Les indices de pivot ; pour 1 <= i <= min(M,N), la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -k, le k-ième argument était illégal
!>          > 0 : si INFO = k, U(k,k) est exactement zéro. La factorisation
!>               a été complétée, mais le facteur U est exactement
!>               singulier, et une division par zéro se produira si elle est
!>               utilisée pour résoudre un système d'équations.
!>
