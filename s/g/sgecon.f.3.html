sous-routine sgecon (caractère norm, entier n, réel, dimension( lda, * ) a, entier lda, réel anorm, réel rcond, réel, dimension( * ) work, entier, dimension( * ) iwork, entier info)

SGECON

But :

!>
!> SGECON estime le réciproque du nombre de condition d'une matrice réelle
!> générale A, en norme 1 ou en norme infinie, en utilisant la factorisation
!> LU calculée par SGETRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et le réciproque du nombre
!> de condition est calculé comme
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infinie est requis :
!>          = '1' ou 'O' :  norme 1 ;
!>          = 'I' :         norme infinie.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          Les facteurs L et U de la factorisation A = P*L*U
!>          calculée par SGETRF.
!>

LDA

!>          LDA est INTEGER
!>          Dimension principale du tableau A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM est REAL
!>          Si NORM = '1' ou 'O', la norme 1 de la matrice originale A.
!>          Si NORM = 'I', la norme infinie de la matrice originale A.
!>

RCOND

!>          RCOND est REAL
!>          Le réciproque du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (4*N)
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument était illégal.
!>                Les NaN sont des valeurs illégales pour ANORM, et ils se propagent
!>                vers le paramètre de sortie RCOND.
!>                L'infini est illégal pour ANORM, et il se propage vers le paramètre
!>                de sortie RCOND sous la forme 0.
!>          = 1 :  si RCOND = NaN, ou
!>                   RCOND = Inf, ou
!>                   la norme calculée de l'inverse de A est 0.
!>                Dans ce dernier cas, RCOND = 0 est retourné.
!>
