Documentation de la fonction/sous-programme

sous-programme sgebak (caractère job, caractère side, entier n, entier ilo, entier ihi, réel, dimension( * ) scale, entier m, réel, dimension( ldv, * ) v, entier ldv, entier info)

SGEBAK

But :

!>
!> SGEBAK forme les vecteurs propres droits ou gauches d'une matrice générale
!> réelle en appliquant la transformation inverse sur les vecteurs propres
!> calculés de la matrice équilibrée renvoyée par SGEBAL.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie le type de transformation inverse requis :
!>          = 'N' : ne rien faire, retourner immédiatement ;
!>          = 'P' : faire la transformation inverse pour la permutation seulement ;
!>          = 'S' : faire la transformation inverse pour la mise à l'échelle seulement ;
!>          = 'B' : faire les transformations inverses pour la permutation et la
!>                 mise à l'échelle.
!>          JOB doit être le même que l'argument JOB fourni à SGEBAL.
!>

SIDE

!>          SIDE est CHARACTER*1
!>          = 'R' : V contient les vecteurs propres droits ;
!>          = 'L' : V contient les vecteurs propres gauches.
!>

N

!>          N est un ENTIER
!>          Le nombre de lignes de la matrice V. N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>          Les entiers ILO et IHI déterminés par SGEBAL.
!>          1 <= ILO <= IHI <= N, si N > 0 ; ILO=1 et IHI=0, si N=0.
!>

SCALE

!>          SCALE est un tableau REEL, de dimension (N)
!>          Détails de la permutation et des facteurs de mise à l'échelle,
!>          tels que renvoyés par SGEBAL.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes de la matrice V. M >= 0.
!>

V

!>          V est un tableau REEL, de dimension (LDV,M)
!>          À l'entrée, la matrice des vecteurs propres droits ou gauches à
!>          transformer, telle que renvoyée par SHSEIN ou STREVC.
!>          À la sortie, V est écrasé par les vecteurs propres transformés.
!>

LDV

!>          LDV est un ENTIER
!>          La dimension principale du tableau V. LDV >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>
