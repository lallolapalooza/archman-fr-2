NOM

sg_rep_zones - envoie la commande SCSI REPORT ZONES, REALMS ou ZONE DOMAINS

SYNTAXE

sg_rep_zones [--bref] [--domaine] [--trouver=ZT] [--forcer] [--aide] [--hex] [--enhex=FN] [--json[=JO]] [--fich-js=JFN] [--localisateur=LBA] [--taille-max=LEN] [--num=NUM] [--partiel] [--brut] [--lecture-seule] [--releve] [--rapport=OPT] [--debut=LBA] [--statistiques] [--verbeux] [--version] [--wp] APPAREIL

DESCRIPTION

Envoie une commande SCSI REPORT ZONES, REPORT REALMS ou REPORT ZONE DOMAINS à APPAREIL et décode (ou affiche simplement) les données renvoyées. Ces commandes se trouvent dans la norme ZBC-2 révision 12 (zbc2r12.pdf). Seule la commande REPORT ZONES est définie dans la norme ZBC originale (INCITS 536-2017) et c'est la commande par défaut pour cet utilitaire.

La commande REPORT ZONE DOMAINS sera envoyée (et décodée) lorsque l'option --domaine est donnée. La commande REPORT REALMS sera envoyée (et décodée) lorsque l'option --releve est donnée.

Plutôt que d'envoyer une commande SCSI à APPAREIL, si l'option --enhex=FN est donnée, alors le contenu du fichier nommé FN est décodé en hexadécimal ASCII (ou binaire si --brut est également donné) puis traité comme s'il s'agissait de la réponse de la commande. Par défaut, la réponse de la commande REPORT ZONES est supposée ; si l'option --domaine ou --releve est donnée, alors la réponse de la commande correspondante est supposée.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-b, --bref
bien qu'un disque ZBC limite généralement la taille de la réponse à la commande REPORT ZONES (par exemple, en raison du champ "longueur d'allocation"), cela peut toujours représenter une quantité de sortie potentiellement importante. Cette option décodera et affichera uniquement les champs trouvés dans l'en-tête de réponse plus les champs du dernier descripteur dans la réponse actuelle.
-d, --domaine
envoie ou décode la commande SCSI REPORT ZONE DOMAINS.
-F, --trouver=ZT
où ZT est un numéro de type de zone ou une abréviation pour un type de zone. Si ZT est précédé de '-' ou '!', la vérification d'égalité est inversée pour devenir une vérification d'inégalité. Autrement dit, il fait : trouver la première occurrence qui n'est **pas** du type de zone donné.
L'algorithme utilisé par cette option prend en compte les options --hex, --taille-max=LEN, --num=NUM, --rapport=OPT et --debut=LBA, si elles sont données, et ignore les autres options. Il est actuellement implémenté uniquement pour la commande Report zones. L'algorithme peut appeler la commande Report zones de manière répétée, avec le bit PARTIAL activé et le champ LBA de début de zone étant augmenté au fur et à mesure. Cela continue jusqu'à ce qu'il y ait une correspondance sur la condition ZT, que --num=NUM soit épuisé ou que le nombre de zones soit épuisé.
Les numéros et abréviations de ZT sont listés lorsque l'option --aide est donnée deux fois. Attention : l'utilisation de '!' pour inverser la condition peut ne pas être très pratique car le shell (par exemple, bash) peut interpréter '!' comme ayant une signification spéciale. Placer des guillemets simples autour de ZT résout le problème pour le shell bash (par exemple, --find='!c' signifie trouver la première zone dont le type n'est pas conventionnel).
-f, --forcer
lors du décodage de la réponse à cette commande, certaines vérifications de validité sont effectuées et si elles échouent, un message est envoyé à stderr et un statut de sortie non nul est défini. Si cette option est donnée, ces vérifications de validité sont contournées.
-h, --aide
affiche le message d'utilisation puis quitte. Lorsqu'il est donné deux fois, des informations d'utilisation supplémentaires sont affichées.
-H, --hex
affiche la réponse en hexadécimal sur la sortie standard. Lorsqu'il est utilisé une fois, toute la réponse est affichée en hexadécimal ASCII avec une adresse précédente (commençant à 0) sur chaque ligne. Lorsqu'il est utilisé deux fois, chaque descripteur de zone dans la réponse est affiché séparément en hexadécimal. Lorsqu'il est utilisé trois fois, toute la réponse est affichée en hexadécimal sans adresse précédente (sur chaque ligne).
Lorsque cette option est utilisée deux fois, elle peut être utile avec l'option --bref ou --trouver=ZT pour afficher uniquement l'en-tête et le descripteur de zone que ces deux options afficheraient autrement en ASCII en l'absence de l'option --hex.
Le format de sortie lorsque cette option est donnée trois fois est adapté pour une invocation ultérieure avec l'option --enhex=FN.
-i, --enhex=FN
où FN est un nom de fichier dont le contenu est supposé être en hexadécimal ASCII. Si APPAREIL est également donné, alors APPAREIL est ignoré, un avertissement est émis et l'utilitaire continue, décodant le fichier nommé FN. Voir la section "FORMATS HEX, BINAIRE ET JSON" dans la page de manuel sg3_utils pour plus d'informations. Si l'option --brut est également donnée, alors le contenu de FN est traité comme binaire.
Notez que par défaut cet utilitaire suppose que le contenu est la réponse d'une commande REPORT ZONES. Utilisez l'option --domaine ou --releve pour décoder les deux autres commandes.
-j[=JO], --json[=JO]
la sortie est au format JSON au lieu du format texte brut. Notez que les arguments pour la forme courte et longue sont eux-mêmes optionnels et s'ils sont présents commencent par '=' sans espace blanc autorisé autour de ce '='.
Voir la page de manuel sg3_utils_json ou utiliser '?' pour JO afin d'obtenir un résumé.
-J, --fich-js=JFN
la sortie est au format JSON et elle est envoyée à un fichier nommé JFN. Si ce fichier existe, il est tronqué. Par défaut, la sortie JSON est envoyée à stdout.
Lorsque cette option est donnée, l'option --json[=JO] est implicite et n'a pas besoin d'être donnée. L'option --json[=JO] peut toujours être nécessaire pour définir la valeur JO à des valeurs non par défaut.
-l, --localisateur=LBA
où LBA joue un rôle similaire à celui de --debut=LBA. C'est le nom du champ utilisé dans les commandes REPORT REALMS et REPORT ZONE DOMAINS.
-m, --taille-max=LEN
où LEN est la longueur de réponse (maximale) en octets. Elle est placée dans le champ "longueur d'allocation" du cdb. Si elle n'est pas donnée (ou si LEN est zéro), 16384 est utilisé. La valeur maximale autorisée de LEN est 2097152.
-n, --num=NUM
où NUM est le nombre (maximal) de descripteurs de zone à imprimer. La valeur par défaut est zéro, ce qui signifie imprimer tous les descripteurs de zone renvoyés par la commande REPORT ZONES.
-p, --partiel
active le bit PARTIAL dans le cdb. Sans le bit PARTIAL activé, un disque ZBC tentera de former une réponse avec toutes les zones de LBA à la fin du disque. S'il y a un grand nombre de zones (par exemple, > 10 000), cette grande réponse sera tronquée afin de ne pas dépasser le champ "longueur d'allocation" dans le cdb (voir --taille-max=LEN). L'avantage est que le nombre de zones (restantes) sur le disque peut être calculé. L'inconvénient est le temps que cela peut prendre.
Avec le bit PARTIAL activé dans le cdb, seul le nombre de zones implicite par le champ "longueur d'allocation" est récupéré. Cela peut être considérablement plus rapide que la même commande sans le bit PARTIAL activé.
Lors de l'itération sur les zones d'un disque ZBC, le processus sera plus rapide lorsque le bit PARTIAL est activé. Typiquement, --debut=LBA est défini à zéro ou à [LBA + longueur_zone] de la dernière zone rapportée dans l'itération précédente.
-r, --brut
la sortie est en binaire (sur stdout) sauf si l'option --enhex=FN est également donnée. Dans ce cas, le nom du fichier d'entrée (FN) est décodé en binaire (et la sortie n'est **pas** en binaire (mais peut être en hexadécimal)).
-R, --lecture-seule
ouvre APPAREIL en lecture seule (par exemple, sous Unix avec le flag O_RDONLY).

sg_rep_zones(8)

NAME

sg_rep_zones

send SCSI REPORT ZONES, REPORT ZONES EXTENDED, REPORT REALMS or REPORT ZONE DOMAINS gcd

SYNOPSIS

  sg_rep_zones
  [-b | --bound]
  [-c | --config]
  [-d | --desc]
  [-e | --realm]
  [-h | --help]
  [-H | --hex]
  [-i | --immutable]
  [-k | --kilo]
  [-l | --lba]
  [-m | --mbp]
  [-n =NUM | --num=NUM]
  [-o =OPT | --report=OPT]
  [-p | --partial]
  [-r | --report_type]
  [-s =LBA | --start=LBA]
  [-S | --stats]
  [-t | --trimmed]
  [-v | --verbose]
  [-V | --version]
  [-w | --wp]
  [--locator=LBA]
  [--long_desc]
  [--pretty]
  [--raw]
  [--sa=HEX]
  [--sa_buf=HEX]
  [DEVICE]

DESCRIPTION

This utility sends a SCSI REPORT ZONES, REPORT ZONES EXTENDED, REPORT REALMS or REPORT ZONE DOMAINS command to the given DEVICE and outputs the response.

The Zoned Block Device (ZBD) commands are part of the SCSI Multi-Media Commands (MMC) standard and are also defined in the SBC-3 (SCSI Block Commands - 3) standard.

Zoned block devices have zones that are sequences of logical blocks. These zones can be written to in different ways, and often require specific ordering of writes. The commands supported by this utility are designed to report information about these zones.

The default action is to send a REPORT ZONES command and print zone information.

OPTIONS

-b, --bound
Set the BOUNDARY field in the cdb. Only applicable for REPORT ZONES command. When set, the command reports zones that are BOUNDARY aligned. When not set, the command reports zones that are NON-BOUNDARY aligned.
-c, --config
Set the CONFIGURATION field in the cdb. This is only relevant for the REPORT ZONES EXTENDED command. If set, the command reports zone configuration information. Otherwise, it reports zone operational information.
-d, --desc
Set the DESCEND bit in the cdb. Used with REPORT ZONES command to request zone information in descending order of LBA. By default, ASC is assumed.
-e, --realm
send or decode the SCSI REPORT REALMS command.
-h, --help
print out the usage message and exit.
-H, --hex
print out the raw response buffer in hex.
-i, --immutable
Set the IMMUTABLE bit in the cdb. This is only relevant for the REPORT ZONE DOMAINS command. If set, the command reports immutable zones. Otherwise, it reports all zones.
-k, --kilo
Interpret all numeric arguments as multiples of 1024 (KiB). Default is decimal.
-l, --lba
Set the LBA field in the cdb. This is used to specify the starting LBA for zone reporting. If not provided, the default is 0.
-m, --mbp
Set the MBP (Maximum Buffer Pages) field in the cdb. This limits the size of the response buffer. A value of 0 means no limit.
-n =NUM, --num=NUM
Limits the number of zones to be reported. This is equivalent to setting the Maximum Number of Zones field in the cdb.
-o, --report=OPT
where OPT will become the contents of the REPORTING OPTION field in the cdb. The reporting options differ between REPORT ZONES, REPORT ZONE DOMAINS and REPORT REALMS. If the --help option is given twice ( or the equivalent '-hh') a list of available reporting options (as of writing) for each command is output.
The default value for REPORT ZONES is 0 which means report a list of all zones. Some other values are 1 for list zones with a zone condition of empty; 2 for list zones with a zone condition of implicitly opened; 3 for list zones with a zone condition of explicitly opened; 4 for list zones with a zone condition of closed; 5 for list zones with a zone condition of full; 6 for list zones with a zone condition of read only; 7 for list zones with a zone condition of offline. Other values are 0x10 for list zones with 'RWP recommended' set to true; 0x11 for list zones with non-sequential write resource active set to true, 0x3e for list zones apart from GAP zones, and 0x3f for list zones with a zone condition of 'not write pointer'.
-p, --partial
Set the PARTIAL field in the cdb. This option is only relevant for the REPORT ZONES EXTENDED command. If set, the command reports partial zone information.
-r, --report_type
Set the REPORT TYPE field in the cdb. This option is only relevant for the REPORT ZONE DOMAINS command. The default value is 0 (Zone Domain List).
-s, --start=LBA
where LBA is at the start or within the first zone to be reported. The default value is 0. If LBA is not a zone start LBA then the preceding zone start LBA is used for reporting. Assumed to be in decimal unless prefixed with '0x' or has a trailing 'h' which indicate hexadecimal.
The zone start LBA field used in the REPORT ZONES command was changed to the zone domain/realm locator field for the two newer ZBC-2 commands. For this utility --locator=LBA and --start=LBA are interchangeable.
-S, --stats
reviews all or a limited number of report zones, collects statistics and prints them (on stdout). The number of zones reviewed may be limited by any combination of --num=NUM, --report=OPT and --start=LBA options. The long option name may be abbreviated to --stats.
-t, --trimmed
Set the TRIMMED field in the cdb. This option is only relevant for the REPORT ZONE DOMAINS command. If set, the command reports trimmed zones.
-v, --verbose
increase the level of verbosity, (i.e. debug output).
-V, --version
print the version string and then exit.
-w, --wp
print the write pointer (in hex) only. In the absence of errors, then a hex LBA will be printed on each line, one line for each zone. Can be usefully combined with the --num=NUM and --start=LBA options.
--locator=LBA
Same functionality as --start=LBA.
--long_desc
Used with REPORT ZONES command to request a longer description of the zones. This is equivalent to setting the Long Descriptor field in the cdb to 1.
--pretty
Prints the response in a more human-readable format.
--raw
Prints the response in a raw format, suitable for piping to other utilities.
--sa=HEX
Sets the Service Action field in the CDB. The HEX value is interpreted as a hexadecimal number.
--sa_buf=HEX
Sets the Service Action field in the CDB for the REPORT ZONES EXTENDED command. The HEX value is interpreted as a hexadecimal number.

EXIT STATUS

The exit status of sg_rep_zones is 0 when it is successful. Otherwise see the sg3_utils(8) man page.
