DESCRIPTION

Les fonctions sg_get_process_stats fournissent des statistiques sur les processus actuellement en cours d'exécution. Les deux fonctions, sg_get_process_stats() et sg_get_process_stats_r(), prennent un paramètre optionnel `entries`, qui pointe (lorsqu'il est fourni) vers un `size_t` pour obtenir le nombre d'entrées du vecteur retourné.

Les fonctions sg_get_process_count_of() et sg_get_process_count_r() fournissent une vue agrégée de la table des processus - elles livrent le nombre de processus par état. sg_get_process_count() est en fait une macro préprocesseur pour la compatibilité descendante et appelle sg_get_process_count_of() avec le paramètre `pcs` de `sg_entire_process_count` pour émuler le comportement jusqu'à la version 0.17.

Raccourci API

fonction retourne propriétaire des données
sg_get_process_stats sg_process_stats * libstatgrab (local au thread)
sg_get_process_stats_r sg_process_stats * appelant
sg_get_process_count_of sg_process_count * libstatgrab (local au thread)
sg_get_process_count_r sg_process_count * appelant

Les vecteurs `sg_process_stats` reçus de sg_get_process_stats_r() ou les résumés `sg_process_count` reçus de sg_get_process_count_r doivent être libérés en utilisant sg_free_process_stats() ou sg_free_process_count(), respectivement. L'appelant est responsable de le faire lorsque les données ne sont plus nécessaires.

Ces fonctions comparent deux entrées `sg_process_stats` et retournent un entier pour représenter laquelle est la plus grande. L'utilisation principale de ces fonctions est d'être passées à `qsort` pour trier les `sg_process_stats` par le type donné.

Exemple

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* ordonner les entrées en comparant l'identifiant du processus */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

VALEURS DE RETOUR

La structure retournée par sg_get_process_stats est de type sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* identifiant du processus */
        pid_t parent; /* PID parent */
        pid_t pgid;   /* identifiant du processus leader du groupe */
        pid_t sessid; /* identifiant de session du processus */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* en octets */
        unsigned long long proc_resident; /* en octets */
        time_t start_time; /* quand le processus a démarré */
        time_t time_spent; /* temps d'exécution en secondes */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
Le nom de la commande exécutée. Le contenu de ce champ dépend fortement du système d'exploitation sous-jacent, certains stockent le nom de base de l'exécutable passé à l'appel système exec(2), d'autres le chemin complet. La plupart des systèmes d'exploitation restreignent la taille de ce champ - certains, comme la famille *BSD, à une valeur très basse de 15 octets.

Ce champ est généralement immuable pour les processus en espace utilisateur.

proctitle
La ligne de commande (le "titre") du processus. Attention - cela peut être modifié par le processus, donc il n'est pas garanti que ce soit la ligne de commande d'origine.
pid
L'identifiant du processus.
parent
L'identifiant du processus parent.
pgid
L'identifiant du processus leader du groupe.
sessid
L'identifiant de session auquel le processus appartient.
uid
L'identifiant de l'utilisateur sous lequel le processus s'exécute.
euid
L'identifiant de l'utilisateur effectif sous lequel le processus s'exécute.
gid
L'identifiant du groupe sous lequel le processus s'exécute.
egid
L'identifiant du groupe effectif sous lequel le processus s'exécute.
context_switches
Le nombre de changements de contexte de ce processus (volontaires et involontaires).
voluntary_context_switches
Le nombre de changements de contexte volontaires de ce processus (par exemple, en appelant sched_yield() ou sleep()).
involuntary_context_switches
Le nombre de changements de contexte involontaires de ce processus (par exemple, tranche de temps épuisée ou signal envoyé).
proc_size
La taille de la mémoire virtuelle du processus en octets.

NOM

sg_get_process_count_r, sg_get_process_count_of, sg_process_count_source, sg_process_count - obtenir le nombre de processus

SYNTAXIS

#include <statgrab.h>

sg_process_count_r *
sg_get_process_count_r (sg_error **e);

sg_process_count *
sg_get_process_count_of (sg_process_count_source source, sg_error **e);

DESCRIPTION

La fonction sg_get_process_count_r retourne une structure sg_process_count_r remplie avec le nombre total de processus et le nombre de processus en cours d'exécution, en dormance, arrêtés, zombies et inconnus.

La fonction sg_get_process_count_of retourne une structure sg_process_count remplie avec le nombre de processus dans l'état spécifié par le paramètre source.

source
Spécifie si le comptage doit être effectué sur l'ensemble des processus ou uniquement sur les processus du dernier instantané. Les valeurs possibles sont :
sg_entire_process_count
Compter tous les processus.
sg_last_process_count
Compter les processus du dernier instantané.

La structure retournée par ces fonctions est la suivante :

typedef struct{
        long long proc_resident;
        long long start_time;
        long long time_spent;
        float cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
}sg_process_count_r;
proc_resident
La taille du processus résidant en mémoire.
start_time
L'heure de démarrage du processus en secondes depuis l'époque.
time_spent
Le nombre de secondes pendant lesquelles le processus a été exécuté (temps utilisateur+système, sans le temps passé par les processus enfants).
cpu_percent
Le pourcentage actuel du CPU utilisé par le processus.
nice
La valeur nice du processus.
state
L'état actuel du processus. Voir sg_process_state pour les valeurs permises.
systime
Le temps en secondes depuis l'époque du moment où la statistique présente a été créée. Ce moment peut être (mais n'est pas obligé de l'être) le même pour toutes les entrées retournées, qu'elles soient récupérées avec un seul instantané ou assemblées à partir d'une sorte de procfs.

La structure retournée par sg_get_process_count_of et sg_get_process_count_r est de type sg_process_count.

typedef enum sg_process_count_source {
        sg_entire_process_count,
        sg_last_process_count
} sg_process_count_source;

typedef struct{
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long unknown;
        time_t systime;
}sg_process_count;
total
Le nombre total de processus.
running
Le nombre de processus en cours d'exécution.
sleeping
Le nombre de processus en dormance.
stopped
Le nombre de processus arrêtés.
zombie
Le nombre de processus zombies.
unknown
Le nombre de processus ne correspondant à aucune des catégories nommées ci-dessus.
systime
Le temps en secondes depuis l'époque du moment où la statistique présente a été créée.

BOGUES

Le tout premier appel à sg_get_process_count_of(sg_last_process_count) retournera la même chose que sg_get_process_count_of(sg_entire_process_count).

Les fonctions de comparaison existent plutôt pour la compatibilité descendante que pour l'amélioration des fonctionnalités. La flexibilité limitée (par exemple, l'ordre inverse) et le manque d'opportunités d'optimisation pour le compilateur conduisent à la recommandation d'implémenter localement les routines de comparaison requises.
