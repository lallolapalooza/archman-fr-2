NOM

sg_zone - envoyer une commande de modification de zone SCSI

SYNTAXE

sg_zone [--all] [--close] [--count=ZC] [--element=EID] [--finish] [--help] [--open] [--remove] [--sequentialize] [--timeout=SE] [--verbose] [--version] [--zone=ID] PÉRIPH

DESCRIPTION

Envoie une commande SCSI OPEN ZONE, CLOSE ZONE, FINISH ZONE, REMOVE ELEMENT AND MODIFY ZONES ou SEQUENTIALIZE ZONE au PÉRIPH. Les deux dernières ne se trouvent pas dans la norme ZBC (INCITS 536-2016). La commande REMOVE ELEMENT AND MODIFY ZONES a été ajoutée dans zbc2r07 tandis que la commande SEQUENTIALIZE ZONE a été ajoutée dans zbc2r01b.

Une et une seule des options --open, --close, --finish, --remove et --sequentialize peuvent être choisies.

Les commandes REPORT ZONES, REPORT REALMS et REPORT ZONE DOMAINS peuvent être accessibles via l'utilitaire sg_rep_zones. Les commandes ZONE ACTIVATE et ZONE QUERY peuvent être accessibles via l'utilitaire sg_z_act_query. La commande RESET WRITE POINTER peut être accessible via l'utilitaire sg_reset_wp.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-a, --all
définit le champ ALL dans le cdb.
-c, --close
provoque l'envoi de la commande CLOSE ZONE au PÉRIPH.
-C, --count=ZC
ZC est placé dans le champ Zone Count du cdb des quatre commandes prises en charge par cet utilitaire. ZC doit être une valeur comprise entre 0 et 65535 (0xffff) inclusivement.
-e, --element=EID
où EID est un identifiant d'élément, un entier non signé de 32 bits commençant à un. Ce champ est utilisé par la commande REMOVE ELEMENT AND MODIFY ZONES et sa valeur par défaut est zéro (ce qui est invalide). Ainsi, l'utilisateur doit fournir un identifiant d'élément valide lorsque --remove est utilisé.
-f, --finish
provoque l'envoi de la commande FINISH ZONE au PÉRIPH.
-h, --help
affiche le message d'utilisation puis quitte.
-o, --open
provoque l'envoi de la commande OPEN ZONE au PÉRIPH.
-r, --remove
provoque l'envoi de la commande REMOVE ELEMENT AND MODIFY ZONES au PÉRIPH. En pratique, --element=EID doit également être donné.
-S, --sequentialize
provoque l'envoi de la commande SEQUENTIALIZE ZONE au PÉRIPH.
-t, --timeout=SE
où SE est le délai d'attente de la commande en secondes. La valeur par défaut est 60 secondes et si 0 est donné, il est mappé à 60. Une forme alternative est --tmo=SE.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire les messages de débogage).
-V, --version
affiche la chaîne de version puis quitte.
-z, --zone=ID
où ID est placé dans le champ ZONE ID du cdb. Un ID de zone est une adresse logique de bloc de début de zone (LBA). La valeur par défaut est 0. ID est supposé être en décimal sauf s'il est préfixé par '0x' ou a un 'h' final qui indique l'hexadécimal.

NOTES

Après qu'une commande REMOVE ELEMENT AND MODIFY ZONES soit terminée, l'élément en question est dit être dépeuplé et toute zone affectée est placée dans l'état de zone 'offline'.

SBC-4 a une commande similaire à REMOVE ELEMENT AND MODIFY ZONES appelée REMOVE ELEMENT AND TRUNCATE. La différence est que cette dernière "change l'association entre les LBA et les blocs physiques" et la première ne change pas cette association. Dans les deux cas, les éléments dépeuplés qui ont le bit 'Restoration Allowed' (RALWD) défini (voir sg_get_elem_status) peuvent être restaurés avec la commande RESTORE ELEMENTS AND REBUILD (voir sg_rem_rest_elem).

STATUT DE SORTIE

Le statut de sortie de sg_zone est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
