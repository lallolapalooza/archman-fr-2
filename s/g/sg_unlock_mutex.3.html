sg_unlock_mutex(3)

Paquet: libstatgrab

Licences: LGPL, GPL

sg_lock_mutex(3) sg_lock_mutex(3)

NOM

sg_lock_mutex, sg_unlock_mutex - API système non compatible MT (Thread-Safe) pour la protection

SYNTAXE

#include <statgrab.h>


sg_error sg_lock_mutex
(char const *mutex_name);


sg_error sg_unlock_mutex
(char const *mutex_name);

DESCRIPTION

VALEURS DE RETOUR

Les deux fonctions retournent un code d'erreur statgrab.

code d'erreur: SG_ERROR_NONE
description: Aucune erreur

code d'erreur: SG_ERROR_INVALID_ARGUMENT
description: Nom de mutex inconnu

code d'erreur: SG_ERROR_MUTEX_LOCK
description: Erreur de la bibliothèque de threads, le code d'erreur est défini avec la valeur fournie.

code d'erreur: SG_ERROR_MUTEX_UNLOCK
description: Erreur de la bibliothèque de threads, le code d'erreur est défini avec la valeur fournie.
