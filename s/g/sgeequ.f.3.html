subroutine sgeequ (m, n, a, lda, r, c, rowcnd, colcnd, amax, info)
SGEEQU

Documentation de la fonction/sous-programme

sous-routine sgeequ (entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) r, réel, dimension( * ) c, réel rowcnd, réel colcnd, réel amax, entier info)

SGEEQU

Objectif :

!>
!> SGEEQU calcule les facteurs d'échelle de lignes et de colonnes destinés à équilibrer une
!> matrice A de taille M par N et à réduire son nombre de conditionnement. R renvoie les
!> facteurs d'échelle des lignes et C les facteurs d'échelle des colonnes, choisis pour
!> essayer de faire en sorte que l'élément de plus grande valeur absolue dans chaque
!> ligne et colonne de la matrice B dont les éléments sont B(i,j)=R(i)*A(i,j)*C(j)
!> ait une valeur absolue de 1.
!>
!> R(i) et C(j) sont limités entre SMLNUM = plus petit nombre sûr et BIGNUM = plus grand nombre sûr.
!> L'utilisation de ces facteurs d'échelle n'est pas garantie de réduire le nombre de conditionnement de A
!> mais fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau RÉEL, dimension (LDA,N)
!>          La matrice M par N dont les facteurs d'équilibrage doivent
!>          être calculés.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

R

!>          R est un tableau RÉEL, dimension (M)
!>          Si INFO = 0 ou INFO > M, R contient les facteurs d'échelle
!>          des lignes de A.
!>

C

!>          C est un tableau RÉEL, dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle des colonnes de A.
!>

ROWCND

!>          ROWCND est un RÉEL
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du plus petit R(i)
!>          au plus grand R(i). Si ROWCND >= 0.1 et AMAX n'est ni trop grand ni
!>          trop petit, il n'est pas utile de mettre à l'échelle par R.
!>

COLCND

!>          COLCND est un RÉEL
!>          Si INFO = 0, COLCND contient le rapport du plus petit C(i)
!>          au plus grand C(i). Si COLCND >= 0.1, il n'est pas utile de
!>          mettre à l'échelle par C.
!>

AMAX

!>          AMAX est un RÉEL
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du débordement ou du sous-débordement, la matrice
!>          doit être mise à l'échelle.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement nulle
!>                >  M : la (i-M)-ème colonne de A est exactement nulle
!>
