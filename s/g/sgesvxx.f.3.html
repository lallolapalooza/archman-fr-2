Documentation de la fonction/sous-programme

sous-programme sgesvxx (character fact, character trans, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx , * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGESVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices GE

Objectif :

!>
!>    SGESVXX utilise la factorisation LU pour calculer la solution d'un
!>    système d'équations linéaires réelles A * X = B, où A est une matrice
!>    N-par-N et X et B sont des matrices N-par-NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et des bornes d'erreur composantes maximales
!>    sont retournées. SGESVXX retournera une solution avec une petite
!>    erreur garantie (O(eps) où eps est la précision de calcul machine) sauf si la matrice est très mal conditionnée,
!>    auquel cas un avertissement est retourné. Les numéros de condition pertinents sont également
!>    calculés et retournés.
!>
!>    SGESVXX accepte des factorisations et des facteurs d'équilibration fournis par l'utilisateur ; voir les définitions des options FACT et EQUED.
!>    Résoudre avec raffinement et utiliser une factorisation d'un appel précédent SGESVXX produira également une solution avec des erreurs O(eps)
!>    ou des avertissements, mais nous ne pouvons pas affirmer cela pour des factorisations et des facteurs d'équilibration fournis par l'utilisateur
!>    s'ils diffèrent de ce que SGESVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>
!>      TRANS = 'N' :  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T' : (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C' : (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasée par diag(R)*A*diag(C) et B par diag(R)*B (si TRANS='N')
!>    ou diag(C)*B (si TRANS = 'T' ou 'C').
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') en
!>
!>      A = P * L * U,
!>
!>    où P est une matrice de permutation, L est une matrice triangulaire inférieure unitaire, et U est triangulaire supérieure.
!>
!>    3. Si un U(i,i)=0, de sorte que U soit exactement singulière, alors la
!>    routine retourne avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le numéro de condition de la matrice A (voir
!>    l'argument RCOND). Si la réciproque du numéro de condition est inférieure
!>    à la précision machine, la routine continue à résoudre pour X
!>    et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera le raffinement itératif pour tenter d'obtenir une petite
!>    erreur et de petites bornes d'erreur. Le raffinement calcule le résidu
!>    à au moins deux fois la précision de calcul.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est pré-multipliée par
!>    diag(C) (si TRANS = 'N') ou diag(R) (si TRANS = 'T' ou 'C') de sorte
!>    qu'elle résolve le système original avant équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie
!>     en entrée, et sinon, si la matrice A doit être
!>     équilibrée avant d'être factorisée.
!>       = 'F' : En entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec les facteurs d'échelle donnés par R et C.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N' : La matrice A sera copiée dans AF et factorisée.
!>       = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Transposée Conjuguée = Transposée)
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau de REAL, dimension (LDA,N)
!>     En entrée, la matrice N-par-N A.  Si FACT = 'F' et EQUED
!>     n'est pas 'N', alors A doit avoir été équilibrée par les
!>     facteurs d'échelle dans R et/ou C.
!>     A n'est pas modifié si FACT = 'F' ou
!>     'N', ou si FACT = 'E' et EQUED = 'N' à la sortie.
!>
!>     À la sortie, si EQUED .ne. 'N', A est mis à l'échelle comme suit :
!>     EQUED = 'R' :  A := diag(R) * A
!>     EQUED = 'C' :  A := A * diag(C)
!>     EQUED = 'B' :  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau de REAL, dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et contient en entrée
!>     les facteurs L et U de la factorisation
!>     A = P*L*U calculée par SGETRF.  Si EQUED .ne. 'N', alors
!>     AF est la forme factorisée de la matrice équilibrée A.
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et contient à la sortie
!>     les facteurs L et U de la factorisation A = P*L*U
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et contient à la sortie
!>     les facteurs L et U de la factorisation A = P*L*U
!>     de la matrice équilibrée A (voir la description de A pour
!>     la forme de la matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau de INTEGER, dimension (N)
!>     Si FACT = 'F', alors IPIV est un argument d'entrée et contient en entrée
!>     les indices de pivot de la factorisation
n A = P*L*U
!>     tel que calculé par SGETRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>
!>     Si FACT = 'N', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice originale A.
!>
!>     Si FACT = 'E', alors IPIV est un argument de sortie et à la sortie
!>     contient les indices de pivot de la factorisation A = P*L*U
!>     de la matrice équilibrée A.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée.
!>       = 'N' : Pas d'équilibrage (toujours vrai si FACT = 'N').
!>       = 'R' : Équilibrage des lignes, c'est-à-dire que A a été pré-multiplié par
!>               diag(R).
!>       = 'C' : Équilibrage des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B' : Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>     EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>     argument de sortie.
!>

R

!>          R est un tableau REAL, de dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé. R est un argument d'entrée si FACT = 'F' ;
!>     sinon, R est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'R' ou 'B', chaque élément de R doit être positif.
!>     Si R est en sortie, chaque élément de R est une puissance de la base.
!>     Si R est en entrée, chaque élément de R doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat déborde ou sous-déborde. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à
!>     la matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau REAL, de dimension (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé. C est un argument d'entrée si FACT = 'F' ;
!>     sinon, C est un argument de sortie. Si FACT = 'F' et
!>     EQUED = 'C' ou 'B', chaque élément de C doit être positif.
!>     Si C est en sortie, chaque élément de C est une puissance de la base.
!>     Si C est en entrée, chaque élément de C doit être une puissance de la base
!>     pour garantir une solution et des estimations d'erreur fiables. La mise à l'échelle par
!>     des puissances de la base ne provoque pas d'erreurs d'arrondi sauf si le
!>     résultat déborde ou sous-déborde. Les erreurs d'arrondi pendant la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à
!>     la matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau REAL, de dimension (LDB,NRHS)
!>     À l'entrée, la matrice du second membre B de taille N-par-NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié ;
!>     si TRANS = 'N' et EQUED = 'R' ou 'B', B est écrasé par
!>        diag(R)*B ;
!>     si TRANS = 'T' ou 'C' et EQUED = 'C' ou 'B', B est
!>        écrasé par diag(C)*B.
!>

LDB

!>          LDB est un entier
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, de dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de taille N-par-NRHS du système
!>     d'équations original. Notez que A et B sont modifiés à la sortie
!>     si EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(C))*X si TRANS = 'N' et EQUED = 'C' ou 'B', ou
!>     inv(diag(R))*X si TRANS = 'T' ou 'C' et EQUED = 'R' ou 'B'.
!>

LDX

!>          LDX est un entier
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est un REAL
!>     Conditionnement réciproque mis à l'échelle. C'est une estimation du
!>     conditionnement réciproque de Skeel de la matrice A après
!>     équilibrage (si effectué). S'il est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut encore être faible même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

RPVGRW

!>          RPVGRW est un REAL
!>     Croissance réciproque du pivot. À la sortie, cela contient le facteur
!>     de croissance du pivot réciproque norm(A)/norm(U). La norme
!>     est utilisée. Si cela est beaucoup inférieur à 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être médiocre.
!>     Cela signifie également que la solution X, les conditionnements estimés,
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors cela contient le facteur de croissance du pivot réciproque
!>     pour les INFO colonnes principales de A. Dans SGESVX, cette quantité est
!>     renvoyée dans WORK(1).
!>

BERR

!>          BERR est un tableau REAL, de dimension (NRHS)
!>     Erreur résiduelle relative par composante. C'est l'
!>     erreur résiduelle relative par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans n'importe quel élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est un entier
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (par norme ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'
!>     erreur relative par norme, qui est définie comme suit :
!>
!>     Erreur relative par norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              faite confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque estimé
!>              par norme. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance de la
!>              base de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REAL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'
!>     erreur relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'
!>     erreur relative par composante), et le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations retournées pour chaque
!>     second membre. Si la précision par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait être
!>              faite confiance que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque estimé
!>              par composante. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation d'erreur
!>              est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base de sorte que toutes les sommes de lignes
!>              absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions supplémentaires.
!>

NPARAMS

!>          NPARAMS est un entier
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais accédé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau REAL, de dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accessibles ; les défauts
!>     sont utilisés pour les paramètres à numéro plus élevé.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer un raffinement itératif
!>            ou non.
!>         Défaut : 1.0
!>            = 0.0 : Aucun raffinement n'est effectué, et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0 : Utilise l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs en simple précision doublés si
!>                    l'environnement de compilation ne supporte pas la DOUBLE
!>                    PRECISION.
!>              (d'autres valeurs sont réservées pour un usage futur)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs de résidu
!>            autorisés pour le raffinement.
!>         Défaut : 10
!>

NAME

sgesvxx - sgesvxx

SYNOPSIS

SUBROUTINE SGESVXX(
     CHARACTER*1             EQUED,
     INTEGER                 N,
     INTEGER                 NRHS,
     REAL, dimension( lda, * )  A,
     INTEGER                 LDA,
     INTEGER, dimension( * )   IPIV,
     REAL, dimension( ldb, * )  B,
     INTEGER                 LDB,
     REAL, dimension( * )      RCOND,
     REAL, dimension( * )      SRFCOND,
     REAL, dimension( * )      BERR,
     REAL, dimension( * )      RES,
     REAL, dimension( * )      SE,
     INTEGER, dimension( * )   INFO_LWORK,
     REAL, dimension( * )      WORK,
     INTEGER                 LRWORK,
     REAL, dimension( * )      RWORK,
     INTEGER                 LRWORK_GLOBAL,
     REAL, dimension( * )      WORK_GLOBAL,
     INTEGER                 IWORK,
     INTEGER                 INFO )

Parameters

     EQUED
          EQUED is CHARACTER*1
          On entry, EQUED specifies whether the matrices A and B have
          equilibrated row and column permutations.
          EQUED = 'N': None of the rows or columns of A has been permuted
                     or scaled.
          EQUED = 'R': The matrix B has been permuted (balanced rows).
          EQUED = 'C': The matrix A has been permuted (balanced columns).
          EQUED = 'B': Both the rows and the columns of A and B have been
                     permuted and scaled.
          On exit, EQUED is set to 'B'. This is required if FACT = 'F'.

     N
     N is INTEGER, dimension of the matrix A. N >= 0.
     The number of rows in the array A and the number of columns in the
     array B.

     NRHS
     NRHS is INTEGER, number of right hand sides. NRHS >= 0.

     A
     A is REAL array, dimension ( LDA, N ).
     On entry, A contains the coefficient matrix A of size N x N.
     On exit, the LU factorization of A is in A and some other work
     space.

     LDA
     LDA is INTEGER, the leading dimension of the array A. LDA >= max(1,N).

     IPIV
     IPIV is INTEGER array, dimension (N).
     Details of the factorization of the general matrix A, i.e. the
     pivot indices.

     B
     B is REAL array, dimension ( LDB, NRHS ).
     On entry, B contains the right hand side matrix B of size N x NRHS.
     On exit, B is overwritten with the solution matrix X.

     LDB
     LDB is INTEGER, the leading dimension of the array B. LDB >= max(1,N).

     RCOND
     RCOND is REAL array, dimension (NRHS).
     On exit, RCOND(J) contains an estimate of the reciprocal condition
     number of the coefficient matrix of the J-th system.

Function/Subroutine Documentation

This subroutine is an analogue of SGBVX, but it applies to general matrices.

Aggressive Set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in err_bnds_norm and err_bnds_comp may no longer be trustworthy.

PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code will attempt to find a solution with small componentwise relative error in the double-precision algorithm. Positive is true, 0.0 is false. Default: 1.0 (attempt componentwise convergence)
