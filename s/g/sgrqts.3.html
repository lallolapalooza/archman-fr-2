sous-programme sgrqts (entier m, entier p, entier n, réel, dimension( lda, * ) a, réel, dimension( lda, * ) af, réel, dimension( lda, * ) q, réel, dimension( lda, * ) r, entier lda, réel, dimension( * ) taua, réel, dimension( ldb, * ) b, réel, dimension( ldb, * ) bf, réel, dimension( ldb, * ) z, réel, dimension( ldb, * ) t, réel, dimension( ldb, * )bwk, entier ldb, réel, dimension( * ) taub, réel, dimension( lwork ) work, entier lwork, réel, dimension( * ) rwork, réel, dimension( 4 ) result)

SGRQTS

But :

!>
!> SGRQTS teste SGGRQF, qui calcule la factorisation GRQ d'une
!> matrice A de taille M par N et d'une matrice B de taille P par N : A = R*Q et B = Z*T*Q.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de lignes de la matrice B.  P >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et B.  N >= 0.
!>

A

!>          A est un tableau de REELS, dimension (LDA,N)
!>          La matrice A de taille M par N.
!>

AF

!>          AF est un tableau de REELS, dimension (LDA,N)
!>          Détails de la factorisation GRQ de A et B, tels que retournés
!>          par SGGRQF, voir SGGRQF pour plus de détails.
!>

Q

!>          Q est un tableau de REELS, dimension (LDA,N)
!>          La matrice orthogonale Q de taille N par N.
!>

R

!>          R est un tableau de REELS, dimension (LDA,MAX(M,N))
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, R et Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA est un tableau de REELS, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGGQRC.
!>

B

!>          B est un tableau de REELS, dimension (LDB,N)
!>          En entrée, la matrice A de taille P par N.
!>

BF

!>          BF est un tableau de REELS, dimension (LDB,N)
!>          Détails de la factorisation GQR de A et B, tels que retournés
!>          par SGGRQF, voir SGGRQF pour plus de détails.
!>

Z

!>          Z est un tableau de REELS, dimension (LDB,P)
!>          La matrice orthogonale Z de taille P par P.
!>

T

!>          T est un tableau de REELS, dimension (LDB,max(P,N))
!>

BWK

!>          BWK est un tableau de REELS, dimension (LDB,N)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF, Z et T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB est un tableau de REELS, dimension (min(P,N))
!>          Les facteurs scalaires des réflecteurs élémentaires, tels que retournés
!>          par SGGRQF.
!>

WORK

!>          WORK est un tableau de REELS, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK, LWORK >= max(M,P,N)**2.
!>

RWORK

!>          RWORK est un tableau de REELS, dimension (M)
!>

RESULT

!>          RESULT est un tableau de REELS, dimension (4)
!>          Les rapports de test :
!>            RESULT(1) = norm( R - A*Q' ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Q - Z'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( N*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
