NOM

sg_comp_init, sg_comp_destroy, sg_comp_get_tls, sg_global_lock, sg_global_unlock - gestion de la diffusion des statistiques système

SYNTAXE

#include "tools.h"


void *get_global_static
(unsigned int id);


sg_error sg_global_lock
(void);


sg_error sg_global_unlock
(void);

DESCRIPTION

sg_comp_init() est appelée par sg_init() pour exécuter l'initialisation du composant global et de chaque composant libstatgrab enregistré. Cet enregistrement est effectué statiquement en ajoutant une structure d'informations d'initialisation de composant (instance de sg_comp_info) à la liste comp_info dans src/libstatgrab/globals.c. L'instance de sg_comp_info est généralement définie en utilisant soit EASY_COMP_SETUP() soit EXTENDED_COMP_SETUP().

sg_comp_destroy() est appelée par sg_shutdown() pour détruire toutes les ressources globales, par exemple, les tables de traduction des noms de périphériques ou les expressions régulières compilées pour faire correspondre les noms de chemins, etc. Les ressources statistiques sont gérées ailleurs et sont libérées (conceptuellement et généralement) avant que sg_comp_destroy() ne soit appelée.

sg_comp_get_tls() est la fonction interne pour accéder au stockage local de thread (anciennement variables globales statiques) du composant. Il est généralement plus facile de s'appuyer sur la macro encapsulante GLOBAL_GET_TLS().

NOTES

La diffusion des statistiques système est le travail de libstatgrab, la gestion de la diffusion est le travail du composant global. Pour remplir ce rôle, les composants à gérer doivent être préparés :

1.
déclarer la structure de données globale et TLS du composant (probablement seulement sur papier, pas dans le code)
2.
définir les fonctions d'initialisation globale, de destruction de thread et de destruction de processus (si requis par 1.)
3.
définir la structure d'informations du composant en utilisant *_COMP_SETUP()
4.
définir les accesseurs de composant en utilisant une ou plusieurs des

EASY_COMP_ACCESS()
EASY_COMP_DIFF()
MULTI_COMP_ACCESS()
MULTI_COMP_DIFF()

Après avoir suivi ces étapes, un nouveau composant fournissant de nouvelles statistiques est né et doit être "annoncé". En supposant que le composant s'appelle cpu, ajoutez la ligne { &sg_cpu_init, 0 } à la liste comp_info mentionnée ci-dessus.

Informations d'initialisation du composant en détail :

typedef sg_error (*comp_global_init_function)(unsigned id);

EASY_COMP_SETUP() s'occupe de tout ce qui doit être fait automatiquement pour instancier une structure d'informations de composant pour le composant spécifié comp. La structure de stockage TLS créée contiendra nvect éléments pointeurs, et c'est tout. Toutes les routines d'initialisation, de destruction et de nettoyage sont créées si nécessaire en utilisant EASY_COMP_INIT_FN(), EASY_COMP_DESTROY_FN() et EASY_COMP_CLEANUP_FN(). Après le nombre de pointeurs de vecteurs requis à stocker, la liste des mutex requis doit être spécifiée, terminée par un pointeur NULL.

EXTENDED_COMP_SETUP() s'occupe de tout ce qui doit être fait automatiquement pour instancier une structure d'informations de composant pour le composant spécifié comp, sauf la définition requise des routines d'initialisation, de destruction et de nettoyage. La structure de stockage TLS créée contiendra nvect éléments pointeurs, et c'est tout. Après le nombre de pointeurs de vecteurs requis à stocker, la liste des mutex requis doit être spécifiée, terminée par un pointeur NULL. Toutes les routines standard peuvent être créées semi-automatiquement en utilisant EASY_COMP_INIT_FN(), EASY_COMP_DESTROY_FN() et EASY_COMP_CLEANUP_FN().

DEFAULT_INIT_COMP() déclare simplement les prototypes pour les routines d'initialisation, de destruction et de nettoyage, définit le tampon d'état d'initialisation, la liste des noms de verrous et remplit finalement la structure d'initialisation du composant. Utilisez ceci lorsque votre stockage TLS contient plus que des pointeurs de vecteurs.

GLOBAL_GET_TLS() renvoie le pointeur vers le stockage local de thread du composant.

GLOBAL_SET_ID() stocke l'identifiant du composant, requis par exemple pour accéder à son TLS.

EASY_COMP_INIT_FN() définit une routine d'initialisation de composant par défaut. Elle stocke l'identifiant du composant et retourne avec SG_ERROR_NONE.

EASY_COMP_DESTROY_FN() définit un destructeur de composant par défaut, appelé à la fin de tout le processus (ou lorsque le dernier sg_shutdown() est appelé). Le destructeur par défaut ne fait rien et généralement une routine d'initialisation individuelle nécessite également un destructeur individuel.

EASY_COMP_CLEANUP_FN() définit une routine de nettoyage TLS par défaut, toujours appelée à la fin d'un thread pour libérer les vecteurs détenus dans le stockage local de thread.

sg_comp_init(3) — libstatgrab — Arch Linux

NAME

sg_comp_init — initialize a component

SYNOPSIS

#include <statgrab.h>

sg_error sg_comp_init(sg_component *comp);

sg_error sg_comp_init(sg_component *comp, void *data);

sg_error sg_comp_init(sg_component *comp, size_t size);

sg_error sg_comp_init(sg_component *comp, void *data, size_t size);

DESCRIPTION

This function initializes a component. A component is an object that collects statistics about a specific part of the system. Components can be enabled or disabled using the sg_enable_component(3) and sg_disable_component(3) functions, respectively. Components can be used to create other components. This function is used to initialize such a component.

The argument comp is a pointer to the component to initialize. The argument data is a pointer to data that will be associated with the component. The argument size is the size of the data in bytes.

The function returns 0 on success, or a negative value on error.

NOTES

This function is used internally by libstatgrab. It is not intended to be called directly by users.

The following macros are used to define and initialize components:

EASY_COMP_ACCESS() defines accessors to a specific statistic provided by the component: the functions fn() and the fn##_r(). The following function must exist:
sg_error fn##_int
(sg_vector **name##_vect);
It accesses the vector idx from TLS of component comp and returns sg_##name##_stats. It manages all standard things like memory and error management, return value etc.

EASY_COMP_DIFF() returns the difference between the two statistic collection runs. The variant dealing with statgrab owned statistics return the difference between the content currently in the vector specified by nowidx and the resulting vector of getfn(). The result is stored in the vector diffidx. If there is no current result, simply the result of getfn() is returned.

MULTI_COMP_ACCESS() defines accessors to a specific statistic containing 0..n elements provided by the component: the functions fn() and the fn##_r(). The following function must exists:
sg_error fn##_int
(sg_vector **name##_vect);
It accesses the vector idx from TLS of component comp and returns sg_##name##_stats. It manages all standard things like memory and error anagement, return values, entries update, etc.

MULTI_COMP_DIFF() does the same as EASY_COMP_DIFF() but for vectors with more than one element.

NOM

sg_comp_init — initialiser un composant

SYNTAXE

#include <statgrab.h>

sg_error sg_comp_init(sg_component *comp);

sg_error sg_comp_init(sg_component *comp, void *data);

sg_error sg_comp_init(sg_component *comp, size_t size);

sg_error sg_comp_init(sg_component *comp, void *data, size_t size);

DESCRIPTION

Cette fonction initialise un composant. Un composant est un objet qui collecte des statistiques sur une partie spécifique du système. Les composants peuvent être activés ou désactivés à l'aide des fonctions sg_enable_component(3) et sg_disable_component(3), respectivement. Les composants peuvent être utilisés pour créer d'autres composants. Cette fonction est utilisée pour initialiser un tel composant.

L'argument comp est un pointeur vers le composant à initialiser. L'argument data est un pointeur vers les données qui seront associées au composant. L'argument size est la taille des données en octets.

La fonction renvoie 0 en cas de succès, ou une valeur négative en cas d'erreur.

NOTES

Cette fonction est utilisée en interne par libstatgrab. Elle n'est pas destinée à être appelée directement par les utilisateurs.

Les macros suivantes sont utilisées pour définir et initialiser des composants :

EASY_COMP_ACCESS() définit des accesseurs pour une statistique spécifique fournie par le composant : les fonctions fn() et fn##_r(). La fonction suivante doit exister :
sg_error fn##_int
(sg_vector **name##_vect);
Elle accède à l'indice du vecteur depuis le TLS du composant comp et renvoie sg_##name##_stats. Elle gère toutes les choses standard comme la gestion de la mémoire et des erreurs, la valeur de retour, etc.

EASY_COMP_DIFF() renvoie la différence entre les deux exécutions de collecte de statistiques. La variante traitant les statistiques possédées par statgrab renvoie la différence entre le contenu actuel dans le vecteur spécifié par nowidx et le vecteur résultant de getfn(). Le résultat est stocké dans le vecteur diffidx. S'il n'y a pas de résultat actuel, le résultat de getfn() est simplement renvoyé.

MULTI_COMP_ACCESS() définit des accesseurs pour une statistique spécifique contenant 0..n éléments fournis par le composant : les fonctions fn() et fn##_r(). La fonction suivante doit exister :
sg_error fn##_int
(sg_vector **name##_vect);
Elle accède à l'indice du vecteur depuis le TLS du composant comp et renvoie sg_##name##_stats. Elle gère toutes les choses standard comme la gestion de la mémoire et des erreurs, les valeurs de retour, la mise à jour des entrées, etc.

MULTI_COMP_DIFF() fait la même chose que EASY_COMP_DIFF() mais pour des vecteurs ayant plus d'un élément.
