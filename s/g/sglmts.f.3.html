Documentation de la fonction/sous-routine

sous-routine sglmts (integer n, integer m, integer p, real, dimension( lda, * ) a, real, dimension( lda, * ) af, integer lda, real, dimension( ldb, * ) b, real, dimension( ldb, * ) bf, integer ldb, real, dimension( * ) d, real, dimension( * ) df, real, dimension( * ) x, real, dimension( * ) u, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real result)

SGLMTS

Objectif :

!>
!> SGLMTS teste SGGGLM - une sous-routine pour résoudre le problème
!> du modèle linéaire généralisé.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de lignes des matrices A et B.  N >= 0.
!>

M

!>          M est un ENTIER
!>          Le nombre de colonnes de la matrice A.  M >= 0.
!>

P

!>          P est un ENTIER
!>          Le nombre de colonnes de la matrice B.  P >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,M)
!>          La matrice NxM A.
!>

AF

!>          AF est un tableau REEL, de dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF. LDA >= max(M,N).
!>

B

!>          B est un tableau REEL, de dimension (LDB,P)
!>          La matrice NxF A.
!>

BF

!>          BF est un tableau REEL, de dimension (LDB,P)
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale des tableaux B, BF. LDB >= max(P,N).
!>

D

!>          D est un tableau REEL, de dimension( N )
!>          En entrée, le membre de gauche de la GLM.
!>

DF

!>          DF est un tableau REEL, de dimension( N )
!>

X

!>          X est un tableau REEL, de dimension( M )
!>          le vecteur solution X dans le problème GLM.
!>

U

!>          U est un tableau REEL, de dimension( P )
!>          le vecteur solution U dans le problème GLM.
!>

WORK

!>          WORK est un tableau REEL, de dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (M)
!>

RESULT

!>          RESULT est REEL
!>          Le ratio de test :
!>                           norme( d - A*x - B*u )
!>            RESULT = -----------------------------------------
!>                     (norme(A)+norme(B))*(norme(x)+norme(u))*EPS
!>
