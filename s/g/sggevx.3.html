SGGEVX calcule les valeurs propres généralisées et, éventuellement, les vecteurs propres généralisés gauches et/ou droits pour les matrices GE

Objectif :

!>
!> SGGEVX calcule pour une paire de matrices réelles non symétriques (A,B) de taille N*N
!> les valeurs propres généralisées, et éventuellement, les vecteurs propres généralisés gauches et/ou droits.
!>
!> En option, il calcule également une transformation d'équilibrage pour améliorer
!> le conditionnement des valeurs propres et des vecteurs propres (ILO, IHI,
!> LSCALE, RSCALE, ABNRM, et BBNRM), les inverses des nombres de condition pour
!> les valeurs propres (RCONDE), et les inverses des nombres de condition pour les
!> vecteurs propres droits (RCONDV).
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire
!> lambda ou un rapport alpha/beta = lambda, tel que A - lambda*B est
!> singulier. Elle est généralement représentée par la paire (alpha,beta), car
!> il existe une interprétation raisonnable pour beta=0, et même pour que les deux
!> soient zéro.
!>
!> Le vecteur propre droit v(j) correspondant à la valeur propre lambda(j)
!> de (A,B) satisfait
!>
!>                  A * v(j) = lambda(j) * B * v(j) .
!>
!> Le vecteur propre gauche u(j) correspondant à la valeur propre lambda(j)
!> de (A,B) satisfait
!>
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B.
!>
!> où u(j)**H est la transposée conjuguée de u(j).
!>
!>

Paramètres

BALANC 
!>          BALANC est de type CHARACTER*1
!>          Spécifie l'option d'équilibrage à effectuer.
!>          = 'N':  ne pas mettre à l'échelle diagonalement ni permuter ;
!>          = 'P':  permuter seulement ;
!>          = 'S':  mettre à l'échelle seulement ;
!>          = 'B':  permuter et mettre à l'échelle les deux.
!>          Les inverses des nombres de condition calculés seront pour les
!>          matrices après permutation et/ou équilibrage. La permutation ne
!>          change pas les nombres de condition (en arithmétique exacte),
!>          mais l'équilibrage le fait.
!>

JOBVL

!>          JOBVL est de type CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs propres généralisés gauches ;
!>          = 'V':  calculer les vecteurs propres généralisés gauches.
!>

JOBVR

!>          JOBVR est de type CHARACTER*1
!>          = 'N':  ne pas calculer les vecteurs propres généralisés droits ;
!>          = 'V':  calculer les vecteurs propres généralisés droits.
!>

SENSE

!>          SENSE est de type CHARACTER*1
!>          Détermine quels inverses des nombres de condition sont calculés.
!>          = 'N': aucun n'est calculé ;
!>          = 'E': calculé pour les valeurs propres seulement ;
!>          = 'V': calculé pour les vecteurs propres seulement ;
!>          = 'B': calculé pour les valeurs propres et les vecteurs propres.
!>

N

!>          N est de type INTEGER
!>          L'ordre des matrices A, B, VL et VR. N >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA, N)
!>          À l'entrée, la matrice A dans la paire (A,B).
!>          À la sortie, A a été écrasé. Si JOBVL='V' ou JOBVR='V'
!>          ou les deux, alors A contient la première partie de la forme de Schur réelle
!>          des versions des entrées A et B.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale de A. LDA >= max(1,N).
!>

B

!>          B est un tableau de type REAL, de dimension (LDB, N)
!>          À l'entrée, la matrice B dans la paire (A,B).
!>          À la sortie, B a été écrasé. Si JOBVL='V' ou JOBVR='V'
!>          ou les deux, alors B contient la deuxième partie de la forme de Schur réelle
!>          des versions des entrées A et B.
!>

LDB

!>          LDB est de type INTEGER
!>          La dimension principale de B. LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR est un tableau de type REAL, de dimension (N)
!>

ALPHAI

!>          ALPHAI est un tableau de type REAL, de dimension (N)
!>

BETA

!>          BETA est un tableau de type REAL, de dimension (N)
!>          À la sortie, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, seront
!>          les valeurs propres généralisées. Si ALPHAI(j) est zéro, alors
!>          la j-ème valeur propre est réelle ; si elle est positive, alors la j-ème et la
!>          (j+1)-ème valeurs propres forment une paire conjuguée complexe, avec
!>          ALPHAI(j+1) négatif.
!>
!>          Note : les quotients ALPHAR(j)/BETA(j) et ALPHAI(j)/BETA(j)
!>          peuvent facilement déborder ou sous-déborder, et BETA(j) peut même être zéro.
!>          Par conséquent, l'utilisateur doit éviter de calculer naïvement le rapport
!>          ALPHA/BETA. Cependant, ALPHAR et ALPHAI seront toujours inférieurs
!>          et généralement comparables à norm(A) en magnitude, et
!>          BETA toujours inférieur et généralement comparable à norm(B).
!>

VL

!>          VL est un tableau de type REAL, de dimension (LDVL,N)
!>          Si JOBVL = 'V', les vecteurs propres généralisés gauches u(j) sont stockés
!>          colonne par colonne dans VL, dans le même ordre que leurs
!>          valeurs propres. Si la j-ème valeur propre est réelle, alors
!>          u(j) = VL(:,j), la j-ème colonne de VL. Si la j-ème et la
!>          (j+1)-ème valeurs propres forment une paire conjuguée complexe, alors
!>          u(j) = VL(:,j)+i*VL(:,j+1) et u(j+1) = VL(:,j)-i*VL(:,j+1).
!>          Chaque vecteur propre sera mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVL = 'N'.
!>

LDVL

!>          LDVL est de type INTEGER
!>          La dimension principale de la matrice VL. LDVL >= 1, et
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR est un tableau de type REAL, de dimension (LDVR,N)
!>          Si JOBVR = 'V', les vecteurs propres généralisés droits v(j) sont stockés
!>          colonne par colonne dans VR, dans le même ordre que leurs
!>          valeurs propres. Si la j-ème valeur propre est réelle, alors
!>          v(j) = VR(:,j), la j-ème colonne de VR. Si la j-ème et la
!>          (j+1)-ème valeurs propres forment une paire conjuguée complexe, alors
!>          v(j) = VR(:,j)+i*VR(:,j+1) et v(j+1) = VR(:,j)-i*VR(:,j+1).
!>          Chaque vecteur propre sera mis à l'échelle de sorte que le composant le plus grand ait
!>          abs(partie réelle) + abs(partie imaginaire) = 1.
!>          Non référencé si JOBVR = 'N'.
!>

LDVR

!>          LDVR est de type INTEGER
!>          La dimension principale de la matrice VR. LDVR >= 1, et
!>          si JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO est de type INTEGER
!>

IHI

!>          IHI est de type INTEGER
!>          Si BALANC = 'P' ou 'B', ILO et IHI spécifient la plage d'indices
!>          des lignes et colonnes qui ont été permutées.
!>          1 <= ILO <= IHI <= N, si BALANC = 'P' ou 'B'.
!>          Sinon ILO = 0 et IHI = 0.
!>

LSCALE

!>          LSCALE est un tableau de type REAL, de dimension (N)
!>          Si BALANC = 'S' ou 'B', LSCALE contient les facteurs de mise à l'échelle
!>          gauches utilisés.
!>

RSCALE

!>          RSCALE est un tableau de type REAL, de dimension (N)
!>          Si BALANC = 'S' ou 'B', RSCALE contient les facteurs de mise à l'échelle
!>          droits utilisés.
!>

ABNRM

!>          ABNRM est de type REAL
!>          La norme 1 de la matrice équilibrée A.
!>

BBNRM

!>          BBNRM est de type REAL
!>          La norme 1 de la matrice équilibrée B.
!>

RCONDE

!>          RCONDE est un tableau de type REAL, de dimension (N)
!>          Si SENSE = 'E' ou 'B', RCONDE contient les inverses des nombres de condition
!>          pour les valeurs propres.
!>

RCONDV

!>          RCONDV est un tableau de type REAL, de dimension (N)
!>          Si SENSE = 'V' ou 'B', RCONDV contient les inverses des nombres de condition
!>          pour les vecteurs propres droits.
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (LWORK)
!>          Espace de travail pour les calculs intermédiaires.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La taille du tableau WORK. Pour une sélection optimale de la performance,
!>          LWORK doit être au moins MAX(2*N, 2620).
!>          Si LWORK = -1, alors le nombre d'éléments requis est calculé et stocké
!>          dans WORK(1), et aucune opération n'est effectuée.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (N)
!>          Espace de travail pour les entiers.
!>

BWORK

!>          BWORK est un tableau de type LOGICAL, de dimension (N)
!>          Espace de travail pour les booléens.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0:  exécution réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument était invalide.
!>          > 0:  si INFO = i > 0, alors la procédure de QR a échoué à converger ;
!>               i valeurs propres ne sont pas calculées.
!>

NAME

sggevx

computes the generalized eigenvalues and eigenvectors of a real pair (A,B).

SYNOPSIS

  SUBROUTINE SGGEVX(
           JOBVL, JOBVR, BALANC, HOWMNY,
           SRNAMC, N, A, LDA, B, LDB,
           ALPHA, BETA, VL, LDVL, VR, LDVR,
           ILO, IHI, LSCALE, RSCALE,
           ABNRM, BBNRM, RCONDE, RCONDV,
           WORK, LWORK, IWORK, BWORK,
           INFO )


  CHARACTER * 1 JOBVL, JOBVR, BALANC, HOWMNY
  INTEGER N, LDA, LDB, LDVL, LDVR, ILO, IHI, LWORK, INFO
  REAL A( LDA, * ), B( LDB, * ), VL( LDVL, * ), VR( LDVR, * )
  REAL ALPHA( * ), BETA( * )
  REAL LSCALE( * ), RSCALE( * )
  REAL ABNRM, BBNRM
  REAL RCONDE( * ), RCONDV( * )
  REAL WORK( * )
  INTEGER IWORK( * )
  LOGICAL BWORK( * )
  CHARACTER * 8 SRNAMC

Function/Subroutine Documentation

JOBVL 

!> JOBVL is CHARACTER*1
!>          = 'N': left generalized eigenvectors are not computed;
!>          = 'V': left generalized eigenvectors are computed.
!>

JOBVR 

!> JOBVR is CHARACTER*1
!>          = 'N': right generalized eigenvectors are not computed;
!>          = 'V': right generalized eigenvectors are computed.
!>

BALANC 

!> BALANC is CHARACTER*1
!>          Specifies the preconditioning balancing strategy.
!>          = 'N': No balancing of A and B.
!>          = 'P': Permutation balancing only.
!>          = 'S': Scaling balancing only.
!>          = 'B': Permutation and scaling balancing.
!>

HOWMNY 

!> HOWMNY is CHARACTER*1
!>          Indicates how many generalized eigenvalues/eigenvectors will be
!>          computed.
!>          = 'A': alpha and beta are computed for all N generalized eigenvalues.
!>          = 'S': alpha and beta are computed for the selected generalized
!>                 eigenvalues K eigenvalues.
!>

SRNAMC 

!> SRNAMC is CHARACTER*8
!>          The name of the subroutine called.
!>

N 

!> N is INTEGER
!>          The number of columns of the matrices A and B. N >= 0.
!>

A 

!> A is REAL array, dimension (LDA,N)
!>          On entry, the upper triangular part of matrix A.
!>          On exit, A is overwritten by its upper triangular factor
!>          in the QR factorization of the balanced input matrix.
!>

LDA 

!> LDA is INTEGER
!>          The leading dimension of A. LDA >= max(1,N).
!>

B 

!> B is REAL array, dimension (LDB,N)
!>          On entry, the upper triangular part of matrix B.
!>          On exit, B is overwritten by its upper triangular factor
!>          in the QR factorization of the balanced input matrix.
!>

LDB 

!> LDB is INTEGER
!>          The leading dimension of B. LDB >= max(1,N).
!>

ALPHA 

!> ALPHA is REAL array, dimension (N)
!>          On exit, ALPHA(j) and BETA(j) contain the parameters of the
!>          j-th generalized eigenvalue such that
!>          w = ALPHA(j) / BETA(j) is the j-th generalized eigenvalue.
!>          If BETA(j) is zero, then the j-th eigenvalue is infinite.
!>          If the j-th eigenvalue is a complex conjugate pair, then
!>          ALPHA(j) and ALPHA(j+1) have real and imaginary parts
!>          respectively, and BETA(j) and BETA(j+1) are real.
!>

BETA 

!> BETA is REAL array, dimension (N)
!>          On exit, ALPHA(j) and BETA(j) contain the parameters of the
!>          j-th generalized eigenvalue such that
!>          w = ALPHA(j) / BETA(j) is the j-th generalized eigenvalue.
!>          If BETA(j) is zero, then the j-th eigenvalue is infinite.
!>          If the j-th eigenvalue is a complex conjugate pair, then
!>          ALPHA(j) and ALPHA(j+1) have real and imaginary parts
!>          respectively, and BETA(j) and BETA(j+1) are real.
!>

VL 

!> VL is REAL array, dimension (LDVL,N)
!>          If JOBVL = 'V', VL contains the left eigenvectors.
!>          The normalized eigenvector V(j) is stored in the j-th column
!>          of VL.
!>

LDVL 

!> LDVL is INTEGER
!>          The leading dimension of VL. LDVL >= max(1,N).
!>

VR 

!> VR is REAL array, dimension (LDVR,N)
!>          If JOBVR = 'V', VR contains the right eigenvectors.
!>          The normalized eigenvector V(j) is stored in the j-th column
!>          of VR.
!>

LDVR 

!> LDVR is INTEGER
!>          The leading dimension of VR. LDVR >= max(1,N).
!>

ILO 

!> ILO is INTEGER
!>

IHI 

!> IHI is INTEGER
!>          ILO and IHI are integer values such that on exit
!>          A(i,j) = 0 and B(i,j) = 0 if i > j and
!>          j = 1,...,ILO-1 or i = IHI+1,...,N.
!>          If BALANC = 'N' or 'S', ILO = 1 and IHI = N.
!>

LSCALE 

!> LSCALE is REAL array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the left side of A and B.  If PL(j) is the index of the
!>          row interchanged with row j, and DL(j) is the scaling
!>          factor applied to row j, then
!>            LSCALE(j) = PL(j)  for j = 1,...,ILO-1
!>                      = DL(j)  for j = ILO,...,IHI
!>                      = PL(j)  for j = IHI+1,...,N.
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!>

RSCALE 

!> RSCALE is REAL array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the right side of A and B.  If PR(j) is the index of the
!>          column interchanged with column j, and DR(j) is the scaling
!>          factor applied to column j, then
!>            RSCALE(j) = PR(j)  for j = 1,...,ILO-1
!>                      = DR(j)  for j = ILO,...,IHI
!>                      = PR(j)  for j = IHI+1,...,N
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!>

ABNRM 

!> ABNRM is REAL
!>          The one-norm of the balanced matrix A.
!>

BBNRM 

!> BBNRM is REAL
!>          The one-norm of the balanced matrix B.
!>

RCONDE 

!> RCONDE is REAL array, dimension (N)
!>          If SENSE = 'E' or 'B', the reciprocal condition numbers of
!>          the eigenvalues, stored in consecutive elements of the array.
!>          For a complex conjugate pair of eigenvalues two consecutive
!>          elements of RCONDE are set to the same value. Thus RCONDE(j),
!>          RCONDV(j), and the j-th columns of VL and VR all correspond
!>          to the j-th eigenpair.
!>          If SENSE = 'N' or 'V', RCONDE is not referenced.
!>

RCONDV 

!> RCONDV is REAL array, dimension (N)
!>          If SENSE = 'V' or 'B', the estimated reciprocal condition
!>          numbers of the eigenvectors, stored in consecutive elements
!>          of the array. For a complex eigenvector two consecutive
!>          elements of RCONDV are set to the same value. If the
!>          eigenvalues cannot be reordered to compute RCONDV(j),
!>          RCONDV(j) is set to 0; this can only occur when the true
!>          value would be very small anyway.
!>          If SENSE = 'N' or 'E', RCONDV is not referenced.
!>

WORK 

!> WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK 

!> LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,2*N).
!>          If BALANC = 'S' or 'B', or JOBVL = 'V', or JOBVR = 'V',
!>          LWORK >= max(1,6*N).
!>          If SENSE = 'E', LWORK >= max(1,10*N).
!>          If SENSE = 'V' or 'B', LWORK >= 2*N*N+8*N+16.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK 

!> IWORK is INTEGER array, dimension (N+6)
!>          If SENSE = 'E', IWORK is not referenced.
!>

BWORK 

!> BWORK is LOGICAL array, dimension (N)
!>          If SENSE = 'N', BWORK is not referenced.
!>

INFO 

!> INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          = 1,...,N:
!>                The QZ iteration failed.  No eigenvectors have been
!>                calculated, but ALPHAR(j), ALPHAI(j), and BETA(j)
!>                should be correct for j=INFO+1,...,N.
!>          > N:  =N+1: other than QZ iteration failed in SHGEQZ.
!>                =N+2: error return from STGEVC.
!>

Further Details:

!>
!>  Balancing a matrix pair (A,B) includes, first, permuting rows and
!>  columns to isolate eigenvalues, second, applying diagonal similarity
!>  transformation to the rows and columns to make the rows and columns
!>  as close in norm as possible. The computed reciprocal condition
!>  numbers correspond to the balanced matrix. Permuting rows and columns
!>  will not change the condition numbers (in exact arithmetic) but
!>  diagonal scaling will.  For further explanation of balancing, see
!>  section 4.11.1.2 of LAPACK Users' Guide.
!>
!>  An approximate error bound on the chordal distance between the i-th
!>  computed generalized eigenvalue w and the corresponding exact
!>  eigenvalue lambda is
!>
!>       chord(w, lambda) <= EPS * norm(ABNRM, BBNRM) / RCONDE(I)
!>
!>  An approximate error bound for the angle between the i-th computed
!>  eigenvector VL(i) or VR(i) is given by
!>
!>       EPS * norm(ABNRM, BBNRM) / DIF(i).
!>
!>  For further explanation of the reciprocal condition numbers RCONDE
!>  and RCONDV, see section 4.11 of LAPACK User's Guide.
!>
