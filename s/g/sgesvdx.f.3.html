SGESVDX calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

Objectif :

!>
!>  SGESVDX calcule la décomposition en valeurs singulières (SVD) d'une matrice
!>  réelle A de taille M par N, en calculant éventuellement les vecteurs singuliers
!>  gauches et/ou droits. La SVD est écrite sous la forme :
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  où SIGMA est une matrice de taille M par N qui est nulle sauf sur sa
!>  diagonale dont les éléments sont min(m,n). U est une matrice orthogonale
!>  de taille M par M, et V est une matrice orthogonale de taille N par N. Les
!>  éléments diagonaux de SIGMA sont les valeurs singulières de A ; ils sont réels
!>  et non négatifs, et sont retournés dans l'ordre décroissant. Les min(m,n)
!>  premières colonnes de U et V sont les vecteurs singuliers gauches et droits
!>  de A.
!>
!>  SGESVDX utilise un problème de valeurs propres pour obtenir la SVD, ce qui
!>  permet le calcul d'un sous-ensemble de valeurs et vecteurs singuliers. Voir
!>  SBDSVDX pour plus de détails.
!>
!>  Notez que la routine retourne V**T, pas V.
!>

Paramètres

JOBU 
!>          JOBU est de type CHARACTER*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice U :
!>          = 'V':  les min(m,n) premières colonnes de U (les vecteurs singuliers
!>                  gauches) ou tels que spécifiés par RANGE sont retournées
!>                  dans le tableau U ;
!>          = 'N':  aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                  calculée.
!>

JOBVT

!>          JOBVT est de type CHARACTER*1
!>           Spécifie les options pour le calcul de tout ou partie de la matrice
!>           V**T :
!>           = 'V':  les min(m,n) premières lignes de V**T (les vecteurs singuliers
!>                   droits) ou tels que spécifiés par RANGE sont retournées
!>                   dans le tableau VT ;
!>           = 'N':  aucune ligne de V**T (aucun vecteur singulier droit) n'est
!>                   calculée.
!>

RANGE

!>          RANGE est de type CHARACTER*1
!>          = 'A': toutes les valeurs singulières seront trouvées.
!>          = 'V': toutes les valeurs singulières dans l'intervalle ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs singulières de rang IL à IU seront trouvées.
!>

M

!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est de type INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.  N >= 0.
!>

A

!>          A est un tableau de type REAL, de dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie, le contenu de A est détruit.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

VL

!>          VL est de type REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est de type REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est de type INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est de type INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur singulière à retourner.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

NS

!>          NS est de type INTEGER
!>          Le nombre total de valeurs singulières trouvées,
!>          0 <= NS <= min(M,N).
!>          Si RANGE = 'A', NS = min(M,N) ; si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S est un tableau de type REAL, de dimension (min(M,N))
!>          Les valeurs singulières de A, triées de telle sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau de type REAL, de dimension (LDU,UCOL)
!>          Si JOBU = 'V', U contient les colonnes de U (les vecteurs singuliers
!>          gauches, stockés par colonne) tels que spécifiés par RANGE ; si
!>          JOBU = 'N', U n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer que UCOL >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une limite
!>          supérieure doit être utilisée.
!>

LDU

!>          LDU est de type INTEGER
!>          La dimension principale du tableau U.  LDU >= 1 ; si
!>          JOBU = 'V', LDU >= M.
!>

VT

!>          VT est un tableau de type REAL, de dimension (LDVT,N)
!>          Si JOBVT = 'V', VT contient les lignes de V**T (les vecteurs singuliers
!>          droits, stockés par ligne) tels que spécifiés par RANGE ; si JOBVT = 'N',
!>          VT n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer que LDVT >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une limite
!>          supérieure doit être utilisée.
!>

LDVT

!>          LDVT est de type INTEGER
!>          La dimension principale du tableau VT.  LDVT >= 1 ; si
!>          JOBVT = 'V', LDVT >= NS (voir ci-dessus).
!>

WORK

!>          WORK est un tableau de type REAL, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale de LWORK ;
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) pour les chemins (voir
!>          les commentaires à l'intérieur du code) :
!>             - CHEMIN 1  (M beaucoup plus grand que N)
!>             - CHEMIN 1t (N beaucoup plus grand que M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) pour les autres chemins.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, de dimension (12*MIN(M,N))
!>          Si INFO = 0, les NS premiers éléments de IWORK sont zéro. Si INFO > 0,
!>          alors IWORK contient les indices des vecteurs propres qui n'ont pas
!>          convergé dans SBDSVDX/SSTEVX.
!>

INFO

!>     INFO est de type INTEGER
!>           = 0 :  fin réussie
!>           < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>           > 0 :  si INFO = i, alors i vecteurs propres n'ont pas convergé
!>                 dans SBDSVDX/SSTEVX.
!>                 si INFO = N*2 + 1, une erreur interne s'est produite dans
!>                 SBDSVDX
!>
