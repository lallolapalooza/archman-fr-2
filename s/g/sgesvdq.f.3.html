SGESVDQ calcule la décomposition en valeurs singulières (SVD) avec une méthode SVD QR préconditionnée par QR pour les matrices GE

Documentation des fonctions/sous-programmes

sous-programme sgesvdq (caractere joba, caractere jobp, caractere jobr, caractere jobu, caractere jobv, entier m, entier n, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) s, reel, dimension( ldu, * ) u, entier ldu, reel, dimension( ldv, * ) v, entier ldv, entier numrank, entier, dimension( * ) iwork, entier liwork, reel, dimension( * ) work, entier lwork, reel, dimension( * ) rwork, entier lrwork, entier info)

SGESVDQ calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle M par N, où M >= N. La SVD de A est écrite comme [++] [xx] [x0] [xx] A = U * SIGMA * V^*, [++] = [xx] * [ox] * [xx] [++] [xx] où SIGMA est une matrice diagonale N par N, U est une matrice orthonormée M par N, et V est une matrice orthogonale N par N. Les éléments diagonaux de SIGMA sont les valeurs singulières de A. Les colonnes de U et V sont les vecteurs singuliers gauches et droits de A, respectivement.

Paramètres

JOBA 
!>  JOBA est CHARACTER*1
!>  Spécifie le niveau de précision de la SVD calculée
!>  = 'A' La précision demandée correspond à une erreur arrière
!>        limitée par || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        où EPS = SLAMCH('Epsilon'). Ceci autorise CGESVDQ à
!>        tronquer le facteur triangulaire calculé dans une factorisation
!>        QR révélatrice de rang chaque fois que la partie tronquée est inférieure au
!>        seuil de l'ordre de EPS * ||A||_F. Ceci est un niveau de troncature agressif.
!>  = 'M' Similairement à 'A', mais la troncature est plus douce : elle
!>        n'est autorisée que lorsqu'il y a une chute sur la diagonale du
!>        facteur triangulaire dans la factorisation QR. Ceci est un niveau de troncature moyen.
!>  = 'H' Haute précision demandée. Aucune détermination numérique du rang basée
!>        sur la factorisation QR révélatrice de rang n'est tentée.
!>  = 'E' Identique à 'H', et en plus le conditionnement de A mis à l'échelle des colonnes
!>        est estimé et retourné dans  RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_scaled)||_2 <= N^(1/4)*RWORK(1)

JOBP

!>  JOBP est CHARACTER*1
!>  = 'P' Les lignes de A sont ordonnées par ordre décroissant par rapport à
!>        ||A(i,:)||_\infty. Ceci améliore la précision numérique au prix d'un mouvement de données supplémentaire. Recommandé pour la robustesse numérique.
!>  = 'N' Pas de pivotement de ligne.

JOBR

!>          JOBR est CHARACTER*1
!>          = 'T' Après la factorisation QR pivotée initiale, SGESVD est appliqué à
!>          la transposée R**T du facteur triangulaire calculé R. Ceci implique
!>          un mouvement de données supplémentaire (transpositions de matrices). Utile pour
!>          les expériences, la recherche et le développement.
!>          = 'N' Le facteur triangulaire R est donné en entrée à SGESVD. Ceci peut être
!>          préféré car cela implique moins de mouvement de données.

JOBU

!>          JOBU est CHARACTER*1
!>          = 'A' Tous les M vecteurs singuliers gauches sont calculés et retournés dans
!>          la matrice U. Voir la description de U.
!>          = 'S' ou 'U' N = min(M,N) vecteurs singuliers gauches sont calculés et retournés
!>          dans la matrice U. Voir la description de U.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seulement NUMRANK vecteurs singuliers gauches
!>          sont calculés et retournés dans la matrice U.
!>          = 'F' Les N vecteurs singuliers gauches sont retournés sous forme factorisée comme le
!>          produit du facteur Q de la factorisation QR initiale et des
!>          N vecteurs singuliers gauches de (R**T , 0)**T. Si le pivotement de ligne est utilisé,
!>          alors les informations nécessaires sur le pivotement de ligne sont stockées dans
!>          IWORK(N+1:N+M-1).
!>          = 'N' Les vecteurs singuliers gauches ne sont pas calculés.

JOBV

!>          JOBV est CHARACTER*1
!>          = 'A', 'V' Tous les N vecteurs singuliers droits sont calculés et retournés dans
!>          la matrice V.
!>          = 'R' Le rang numérique NUMRANK est déterminé et seulement NUMRANK vecteurs singuliers droits
!>          sont calculés et retournés dans la matrice V. Cette option est
!>          autorisée uniquement si JOBU = 'R' ou JOBU = 'N'; sinon, elle est illégale.
!>          = 'N' Les vecteurs singuliers droits ne sont pas calculés.

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice d'entrée A.  M >= N >= 0.

A

!>          A est un tableau REEL de dimensions LDA x N
!>          En entrée, la matrice d'entrée A.
!>          En sortie, si JOBU .NE. 'N' ou JOBV .NE. 'N', le triangle inférieur de A contient
!>          les vecteurs de Householder tels qu'ils sont stockés par SGEQP3. Si JOBU = 'F', ces vecteurs de
!>          Householder, ainsi que WORK(1:N), peuvent être utilisés pour restaurer les facteurs Q de
!>          la factorisation QR pivotée initiale de A. Voir la description de U.

LDA

!>          LDA est ENTIER.
!>          La dimension principale du tableau A.  LDA >= max(1,M).

S

!>          S est un tableau REEL de dimension N.
!>          Les valeurs singulières de A, ordonnées de telle sorte que S(i) >= S(i+1).

U

!>          U est un tableau REEL, dimension
!>          LDU x M si JOBU = 'A'; voir la description de LDU. Dans ce cas,
!>          en sortie, U contient les M vecteurs singuliers gauches.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; voir la description de LDU. Dans ce
!>          cas, U contient les N premiers ou les NUMRANK premiers vecteurs singuliers gauches.
!>          LDU x N si JOBU = 'F' ; voir la description de LDU. Dans ce cas, U
!>          contient une matrice orthogonale N x N qui peut être utilisée pour former les vecteurs singuliers gauches.
!>          Si JOBU = 'N', U n'est pas référencé.

LDU

!>          LDU est ENTIER.
!>          La dimension principale du tableau U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          Sinon,                     LDU >= 1.

V

!>          V est un tableau REEL, dimension
!>          LDV x N si JOBV = 'A', 'V', 'R' ou si JOBA = 'E' .
!>          Si JOBV = 'A', ou 'V',  V contient la matrice orthogonale N x N V**T;
!>          Si JOBV = 'R', V contient les NUMRANK premières lignes de V**T (les vecteurs singuliers droits, stockés ligne par ligne, des NUMRANK plus grandes valeurs singulières).
!>          Si JOBV = 'N' et JOBA = 'E', V est utilisé comme espace de travail.
!>          Si JOBV = 'N', et JOBA.NE.'E', V n'est pas référencé.

LDV

!>          LDV est ENTIER
!>          La dimension principale du tableau V.
!>          Si JOBV = 'A', 'V', 'R',  ou JOBA = 'E', LDV >= max(1,N).
!>          Sinon,                               LDV >= 1.

NUMRANK

NAME

sgesvdq — Function Description

SYNOPSIS

SUBROUTINE SGESVDQ(
 JOBU, JOBV, JOBP, JOBR, M, N, A, LDA, S, U, LDU, V, LDV, Q, LW,
 INFO )

 CHARACTER(1) JOBU, JOBV, JOBP, JOBR
 INTEGER M, N, LDA, LDU, LDV, LW, INFO
 REAL A( LDA, * ), S( * ), U( LDU, * ), V( LDV, * ), Q( LW, * )

Function/Subroutine Documentation

This routine computes the singular value decomposition (SVD) of a real M-by-N matrix A, which is a scaled version of the SVD described in [1]. The SVD is returned in four formats:

    A = Q * S * V**T * P**T
    or
    A = Q * S * V**T
    or
    A = Q * S * U**T
    or
    A = Q * S

where S is an M-by-N matrix whose only potentially non-zero entries are on the diagonal; U is an M-by-M orthogonal matrix; V is an N-by-N orthogonal matrix; and P is an M-by-M permutation matrix. Q is an M-by-K matrix of orthonormal columns, where K is the computed rank of A. The column scaling and the permutation matrices are computed by routines SGEQPF and SGEQP3. The matrices U and V are computed by SGESVD. The matrices Q and P are computed by SGEQPF.

The routine is designed to maintain high accuracy in the singular values and vectors.

Arguments:

JOBU
          CHARACTER*1.
          Specifies whether to compute the singular vectors of U.
          = 'U': U is computed;
          = 'N': U is not computed.
JOBV
          CHARACTER*1.
          Specifies whether to compute the singular vectors of V.
          = 'V': V is computed;
          = 'N': V is not computed.
JOBP
          CHARACTER*1.
          Specifies whether to compute the permutation matrix P.
          = 'P': P is computed;
          = 'N': P is not computed.
JOBR
          CHARACTER*1.
          Specifies whether to compute the row permutations P_R.
          = 'R': P_R is computed;
          = 'N': P_R is not computed.
M
          INTEGER.
          The number of rows of A. M >= 0.
N
          INTEGER.
          The number of columns of A. N >= 0.
A
          REAL array, dimension (LDA, N).
          On entry, the M-by-N matrix A.
          On exit, the elements of A are overwritten.
LDA
          INTEGER.
          The leading dimension of A. LDA >= max(1,M).
S
          REAL array, dimension (min(M,N)).
          On exit, S contains the singular values of A in descending order.
          The singular values are computed with high accuracy.
U
          REAL array, dimension (LDU, M).
          On exit, if JOBU = 'U', the M-by-M matrix U is computed.
          Otherwise, U is not used.
          The columns of U are the left singular vectors.
LDU
          INTEGER.
          The leading dimension of U. LDU >= max(1,M).
          On entry, LDU >= max(1, M) if JOBU = 'U'; otherwise, LDU is not
          referenced and can be set to any value.
V
          REAL array, dimension (LDV, N).
          On exit, if JOBV = 'V', the N-by-N matrix V is computed.
          Otherwise, V is not used.
          The columns of V are the right singular vectors.
LDV
          INTEGER.
          The leading dimension of V. LDV >= max(1,N).
          On entry, LDV >= max(1, N) if JOBV = 'V'; otherwise, LDV is not
          referenced and can be set to any value.
Q
          REAL array, dimension (LW, K), where K is the computed rank.
          On exit, the M-by-K matrix Q contains the orthonormal columns.
          Q is a scaled version of the first K columns of the Q matrix from the
          QR factorization of A, possibly further modified by the column
          pivoting and row permutation.
LW
          INTEGER.
          The dimension of the array Q.
          LW >= M.
INFO
          INTEGER.
          = 0:  successful exit.
          < 0:  if INFO = -i, the i-th argument had an illegal value.
          > 0:  if SBDSQR did not converge, INFO specifies how many superdiagonals
          of an intermediate bidiagonal form B (computed in SGESVD) did not
          converge to zero.

The remaining arguments are workspace arrays and their sizes.

IWORK

          IWORK is INTEGER array, dimension (max(1, LIWORK)).
          On exit, IWORK(1:N) contains column pivoting permutation of the
          rank revealing QR factorization.
          If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence
          of row swaps used in row pivoting. These can be used to restore the
          left singular vectors in the case JOBU = 'F'.
          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
          IWORK(1) returns the minimal LIWORK.

LIWORK

          LIWORK is INTEGER
          The dimension of the array IWORK.
          LIWORK >= N + M - 1,     if JOBP = 'P' and JOBA .NE. 'E';
          LIWORK >= N              if JOBP = 'N' and JOBA .NE. 'E';
          LIWORK >= N + M - 1 + N, if JOBP = 'P' and JOBA = 'E';
          LIWORK >= N + N          if JOBP = 'N' and JOBA = 'E'.
          If LIWORK = -1, then a workspace query is assumed; the routine
          only calculates and returns the optimal and minimal sizes
          for the WORK, IWORK, and RWORK arrays, and no error
          message related to LWORK is issued by XERBLA.

WORK

          WORK is REAL array, dimension (max(2, LWORK)), used as a workspace.
          On exit, if, on entry, LWORK.NE.-1, WORK(1:N) contains parameters
          needed to recover the Q factor from the QR factorization computed by
          SGEQP3.
          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
          WORK(1) returns the optimal LWORK, and
          WORK(2) returns the minimal LWORK.

LWORK

          LWORK is INTEGER
          The dimension of the array WORK. It is determined as follows:
          Let  LWQP3 = 3*N+1,  LWCON = 3*N, and let
          LWORQ = { MAX( N, 1 ),  if JOBU = 'R', 'S', or 'U'
                  { MAX( M, 1 ),  if JOBU = 'A'
          LWSVD = MAX( 5*N, 1 )
          LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 5*(N/2), 1 ), LWORLQ = MAX( N, 1 ),
          LWQRF = MAX( N/2, 1 ), LWORQ2 = MAX( N, 1 )
          Then the minimal value of LWORK is:
          = MAX( N + LWQP3, LWSVD )        if only the singular values are needed;
          = MAX( N + LWQP3, LWCON, LWSVD ) if only the singular values are needed,
                                   and a scaled condition estimate requested;
          = N + MAX( LWQP3, LWSVD, LWORQ ) if the singular values and the left
                                   singular vectors are requested;
          = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the singular values and the left
                                   singular vectors are requested, and also
                                   a scaled condition estimate requested;
          = N + MAX( LWQP3, LWSVD )        if the singular values and the right
                                   singular vectors are requested;
          = N + MAX( LWQP3, LWCON, LWSVD ) if the singular values and the right
                                   singular vectors are requested, and also
                                   a scaled condition etimate requested;
          = N + MAX( LWQP3, LWSVD, LWORQ ) if the full SVD is requested with JOBV = 'R';
                                   independent of JOBR;
          = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the full SVD is requested,
                                   JOBV = 'R' and, also a scaled condition
                                   estimate requested; independent of JOBR;
          = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
         N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ) ) if the
                         full SVD is requested with JOBV = 'A' or 'V', and
                         JOBR ='N'
          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
         N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) )
                         if the full SVD is requested with JOBV = 'A' or 'V', and
                         JOBR ='N', and also a scaled condition number estimate
                         requested.
          = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
         N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) if the
                         full SVD is requested with JOBV = 'A', 'V', and JOBR ='T'
          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
         N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) )
                         if the full SVD is requested with JOBV = 'A' or 'V', and
                         JOBR ='T', and also a scaled condition number estimate
                         requested.
          Finally, LWORK must be at least two: LWORK = MAX( 2, LWORK ).
          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates and returns the optimal and minimal sizes
          for the WORK, IWORK, and RWORK arrays, and no error
          message related to LWORK is issued by XERBLA.

RWORK

          RWORK is REAL array, dimension (max(1, LRWORK)).
          On exit,
          1. If JOBA = 'E', RWORK(1) contains an estimate of the condition
          number of column scaled A. If A = C * D where D is diagonal and C
          has unit columns in the Euclidean norm, then, assuming full column rank,
          N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1).
          Otherwise, RWORK(1) = -1.
          2. RWORK(2) contains the number of singular values computed as
          exact zeros in SGESVD applied to the upper triangular or trapezoidal
          R (from the initial QR factorization). In case of early exit (no call to
          SGESVD, such as in the case of zero matrix) RWORK(2) = -1.
          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
          RWORK(1) returns the minimal LRWORK.

LRWORK

          LRWORK is INTEGER.
          The dimension of the array RWORK.
          If JOBP ='P', then LRWORK >= MAX(2, M).
          Otherwise, LRWORK >= 2
          If LRWORK = -1, then a workspace query is assumed; the routine
          only calculates and returns the optimal and minimal sizes
          for the WORK, IWORK, and RWORK arrays, and no error
          message related to LWORK is issued by XERBLA.

Further Details:

   1. The data movement (matrix transpose) is coded using simple nested
   DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
   Those DO-loops are easily identified in this source code - by the CONTINUE
   statements labeled with 11**. In an optimized version of this code, the
   nested DO loops should be replaced with calls to an optimized subroutine.
   2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
   column norm overflow. This is the minial precaution and it is left to the
   SVD routine (CGESVD) to do its own preemptive scaling if potential over-
   or underflows are detected. To avoid repeated scanning of the array A,
   an optimal implementation would do all necessary scaling before calling
   CGESVD and the scaling in CGESVD can be switched off.
   3. Other comments related to code optimization are given in comments in the
   code, enclosed in [[double brackets]].
