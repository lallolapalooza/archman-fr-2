NOM

sg_rtpg - envoie la commande SCSI REPORT TARGET PORT GROUPS

SYNTAXE

sg_rtpg [--decode] [--help] [--hex] [--raw] [--readonly] [--verbose] [--version] PÉRIPHÉRIQUE

DESCRIPTION

Envoie une commande SCSI REPORT TARGET PORT GROUPS au PÉRIPHÉRIQUE et affiche la réponse.

L'accès aux groupes de ports cibles est décrit dans SPC-3 et SPC-4 disponibles sur www.t10.org. La version la plus récente de SPC-4 est la révision 37, dans laquelle les groupes de ports cibles sont décrits dans la section 5.15.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-d, --decode
décode le code d'état et l'état d'accès asymétrique de chaque descripteur de groupe de ports cibles retourné. L'action par défaut est de ne pas décoder ces valeurs.
-e, --extended
utilise le format d'en-tête étendu pour les données du paramètre. Ceci définit le champ PARAMETER DATA FORMAT dans le cdb à 1.
-h, --help
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse en hexadécimal (plutôt que de la décoder partiellement ou totalement).
-r, --raw
affiche la réponse en binaire sur la sortie standard.
-R, --readonly
ouvre le PÉRIPHÉRIQUE en lecture seule (par exemple, sous Unix avec le drapeau O_RDONLY). L'ouverture en lecture-écriture est le défaut.
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire les sorties de débogage).
-V, --version
imprime la chaîne de version puis quitte.

NOTES

La commande Report Target Port Groups devrait être supportée chaque fois que les bits TPGS dans une réponse INQUIRY standard sont supérieurs à zéro. [Voir avec l'utilitaire sg_inq.]

STATUT DE SORTIE

Le statut de sortie de sg_rtpg est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
