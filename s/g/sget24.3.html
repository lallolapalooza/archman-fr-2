Purpose:

!>
!>    SGET24 vérifie le problème de valeurs propres non symétriques (forme de Schur)
!>    pilote expert SGEESX.
!>
!>    Si COMP = .FALSE., les 13 premiers des tests suivants seront
!>    effectués sur la matrice d'entrée A, ainsi que les tests 14 et 15
!>    si LWORK est suffisamment grand.
!>    Si COMP = .TRUE., les 17 tests seront effectués.
!>
!>    (1)     0 si T est sous forme de Schur, 1/ulp sinon
!>           (pas de tri des valeurs propres)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Ici VS est la matrice des vecteurs propres de Schur, et T est sous forme de
!>      Schur (pas de tri des valeurs propres).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (pas de tri des valeurs propres).
!>
!>    (4)     0     si WR+sqrt(-1)*WI sont les valeurs propres de T
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (5)     0     si T(avec VS) = T(sans VS),
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (6)     0     si eigenvalues(avec VS) = eigenvalues(sans VS),
!>            1/ulp sinon
!>            (pas de tri des valeurs propres)
!>
!>    (7)     0 si T est sous forme de Schur, 1/ulp sinon
!>            (avec tri des valeurs propres)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Ici VS est la matrice des vecteurs propres de Schur, et T est sous forme de
!>      Schur (avec tri des valeurs propres).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (avec tri des valeurs propres).
!>
!>    (10)    0     si WR+sqrt(-1)*WI sont les valeurs propres de T
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également WR, WI avec et
!>            sans nombres conditionnels réciproques
!>            (avec tri des valeurs propres)
!>
!>    (11)    0     si T(avec VS) = T(sans VS),
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également T avec et sans
!>            nombres conditionnels réciproques
!>            (avec tri des valeurs propres)
!>
!>    (12)    0     si eigenvalues(avec VS) = eigenvalues(sans VS),
!>            1/ulp sinon
!>            Si l'espace de travail est suffisant, comparer également VS avec et sans
!>            nombres conditionnels réciproques
!>            (avec tri des valeurs propres)
!>
!>    (13)    si le tri a fonctionné et SDIM est le nombre de
!>            valeurs propres qui ont été SÉLECTIONNÉES
!>            Si l'espace de travail est suffisant, comparer également SDIM avec et
!>            sans nombres conditionnels réciproques
!>
!>    (14)    si RCONDE est le même, que VS et/ou RCONDV soient calculés ou non
!>
!>    (15)    si RCONDV est le même, que VS et/ou RCONDE soient calculés ou non
!>
!>    (16)  |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>       RCONDE est le nombre conditionnel moyen réciproque des valeurs propres
!>       calculé par SGEESX et RCDEIN (la vraie valeur précalculée)
!>       est fournie en entrée. cond(RCONDE) est le nombre conditionnel
!>       de RCONDE, et prend en compte les erreurs de calcul de RCONDE,
!>       de sorte que la quantité résultante devrait être O(ULP). cond(RCONDE)
!>       est essentiellement donné par norm(A)/RCONDV.
!>
!>    (17)  |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>       RCONDV est le nombre conditionnel réciproque du sous-espace invariant à droite
!>       calculé par SGEESX et RCDVIN (la vraie valeur précalculée)
!>       est fournie en entrée. cond(RCONDV) est le nombre conditionnel
!>       de RCONDV, et prend en compte les erreurs de calcul de RCONDV,
!>       de sorte que la quantité résultante devrait être O(ULP).
!>       cond(RCONDV) est essentiellement donné par norm(A)/RCONDE.
!>

NAME

SGET24 — routines for the computation of the condition number of a symmetric or Hermitian eigenvalue problem.

SYNOPSIS

    call SGET24( COMPS, N, T, VT, WR, WI, WRTMP, WITMP, VS, LDVS, VS1,
   &              RCDEIN, RCDVIN, NSLCT, ISLCT, RESULT, WORK, LWORK,
   &              IWORK, BWORK, INFO )

Function/Subroutine Documentation

SGET24 computes the condition number of the eigenvalue problem for a general matrix A.

The condition number estimates how sensitive the eigenvalues are to perturbations in the matrix A.

The routine has 17 tests which are computed, all of which are different variants of the condition number computation.

Arguments:

COMPS

COMPS is LOGICAL

When COMPS = .TRUE., the routine computes the condition number of the selected eigenvalue problem.

When COMPS = .FALSE., the routine computes the condition number of the entire eigenvalue problem.

N

N is INTEGER

The order of the matrix A.

T

T is REAL array, dimension (N, N)

The upper triangular matrix of the Schur decomposition.

VT

VT is REAL array, dimension (N, N)

The unitary matrix of the Schur decomposition.

WR

WR is REAL array, dimension (N)

The real parts of the eigenvalues of A.

WI

WI is REAL array, dimension (N)

The imaginary parts of the eigenvalues of A.

WRTMP

WRTMP is REAL array, dimension (N)

Like WR, WI, these arrays contain the eigenvalues of A, but sorted by increasing real part.

WITMP

WITMP is REAL array, dimension (N)

Like WR, WI, these arrays contain the eigenvalues of A, but sorted by increasing real part.

VS

VS is REAL array, dimension (LDVS, N)

VS holds the computed Schur vectors.

LDVS

LDVS is INTEGER

Leading dimension of VS. Must be at least max(1, N).

VS1

VS1 is REAL array, dimension (LDVS, N)

VS1 holds another copy of the computed Schur vectors.

RCDEIN

RCDEIN is REAL

When COMP = .TRUE. RCDEIN holds the precomputed reciprocal condition number for the average of selected eigenvalues.

RCDVIN

RCDVIN is REAL

When COMP = .TRUE. RCDVIN holds the precomputed reciprocal condition number for the selected right invariant subspace.

NSLCT

NSLCT is INTEGER

When COMP = .TRUE. the number of selected eigenvalues corresponding to the precomputed values RCDEIN and RCDVIN.

ISLCT

ISLCT is INTEGER array, dimension (NSLCT)

When COMP = .TRUE. ISLCT selects the eigenvalues of the input matrix corresponding to the precomputed values RCDEIN and RCDVIN. For I=1, ... ,NSLCT, if ISLCT(I) = J, then the eigenvalue with the J-th largest real part is selected. Not referenced if COMP = .FALSE.

RESULT

RESULT is REAL array, dimension (17)

The values computed by the 17 tests described above. The values are currently limited to 1/ulp, to avoid overflow.

WORK

WORK is REAL array, dimension (LWORK)

LWORK

LWORK is INTEGER

The number of entries in WORK to be passed to SGEESX. This must be at least 3*N, and N+N**2 if tests 14--16 are to be performed.

IWORK

IWORK is INTEGER array, dimension (N*N)

BWORK

BWORK is LOGICAL array, dimension (N)

INFO

INFO is INTEGER

If 0, successful exit. If <0, input parameter -INFO had an incorrect value. If >0, SGEESX returned an error code, the absolute value of which is returned.
