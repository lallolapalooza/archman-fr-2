sg_get_host_info(3) sg_get_host_info(3)

NOM

sg_get_host_info, sg_get_host_info_r, sg_free_host_info - obtenir les statistiques générales du système d'exploitation

SYNTAXE

#include <statgrab.h>


sg_host_info *sg_get_host_info
(size_t *entries);


sg_host_info *sg_get_host_info_r
(size_t *entries);


sg_error sg_free_host_info
(sg_host_info *data);

DESCRIPTION

Ces appels renvoient des détails sur le système d'exploitation et la machine sur laquelle il tourne.

Raccourci API

fonction renvoie propriétaire des données
sg_get_host_info sg_host_info * libstatgrab (thread local)
sg_get_host_info_r sg_host_info * appelant

Le tampon sg_host_info reçu de sg_get_host_info_r() doit être libéré à l'aide de sg_free_host_info() lorsqu'il n'est plus nécessaire. L'appelant est responsable de cette opération.

VALEURS DE RETOUR

La structure retournée est de type sg_host_info.

typedef enum {
        sg_unknown_configuration = 0,
        sg_physical_host,
        sg_virtual_machine,
        sg_paravirtual_machine,
        sg_hardware_virtualized
} sg_host_state;

typedef struct{
        char *os_name;
        char *os_release;
        char *os_version;
        char *platform;
        char *hostname;
        unsigned bitwidth;
        sg_host_state host_state;
        unsigned ncpus;
        unsigned maxcpus;
        time_t uptime;
        time_t systime;
}sg_host_info;
os_name
Le nom du système d'exploitation. (par ex. SunOS ou Linux)
os_release
La version du système d'exploitation. (par ex. 5.8 ou 5.9 ou Solaris)
os_version
Le niveau de version de l'OS.
platform
La plateforme matérielle (architecture) sur laquelle l'OS s'exécute.
hostname
Le nom de la machine.
uptime
La durée de fonctionnement de la machine en secondes.
systime
L'horodatage lorsque les statistiques ci-dessus ont été collectées en secondes depuis l'époque
