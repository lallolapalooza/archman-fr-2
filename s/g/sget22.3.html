Documentation de la fonction/sous-programme

sous-programme sget22 (caractère transa, caractère transe, caractère transw, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( lde, * ) e, entier lde, réel, dimension( * ) wr, réel, dimension( * ) wi, réel, dimension( * ) work, réel, dimension( 2 ) result)

SGET22

Objectif:

!>
!> SGET22 effectue une vérification de vecteur propre.
!>
!> Le test de base est :
!>
!>    RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>
!> en utilisant la norme 1. Il vérifie également la normalisation de E :
!>
!>    RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                 j
!>
!> où E(j) est le j-ème vecteur propre, et m-norm est la norme maximale d'un
!> vecteur. Si un vecteur propre est complexe, tel que déterminé par WI(j)
!> non nul, alors la norme maximale du vecteur ( er + i*ei ) est le maximum
!> de
!>    |er(1)| + |ei(1)|, ... , |er(n)| + |ei(n)|
!>
!> W est une matrice diagonale par blocs, avec un bloc de 1 par 1 pour chaque valeur propre réelle
!> et un bloc de 2 par 2 pour chaque paire conjuguée complexe.
!> Si les valeurs propres j et j+1 forment une paire conjuguée complexe, de sorte que
!> WR(j) = WR(j+1) = wr et WI(j) = - WI(j+1) = wi, alors le bloc de 2 par 2
!> correspondant à la paire sera :
!>
!>    (  wr  wi  )
!>    ( -wi  wr  )
!>
!> Un tel bloc multipliant une matrice n par 2 ( ur ui ) à droite
!> sera identique à la multiplication de ur + i*ui par wr + i*wi.
!>
!> Pour gérer divers schémas de stockage des vecteurs propres gauches, il existe
!> des options pour utiliser A-transposée au lieu de A, E-transposée au lieu de E,
!> et/ou W-transposée au lieu de W.
!>

Paramètres

TRANSA 
!>          TRANSA est CHARACTER*1
!>          Spécifie si A est transposée ou non.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée
!>          = 'C':  Conjuguée transposée (= Transposée)
!>

TRANSE

!>          TRANSE est CHARACTER*1
!>          Spécifie si E est transposée ou non.
!>          = 'N':  Pas de transposée, les vecteurs propres sont dans les colonnes de E
!>          = 'T':  Transposée, les vecteurs propres sont dans les lignes de E
!>          = 'C':  Conjuguée transposée (= Transposée)
!>

TRANSW

!>          TRANSW est CHARACTER*1
!>          Spécifie si W est transposée ou non.
!>          = 'N':  Pas de transposée
!>          = 'T':  Transposée, utilise -WI(j) au lieu de WI(j)
!>          = 'C':  Conjuguée transposée, utilise -WI(j) au lieu de WI(j)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice dont les vecteurs propres sont dans E.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau REAL, dimension (LDE,N)
!>          La matrice des vecteurs propres. Si TRANSE = 'N', les vecteurs propres
!>          sont stockés dans les colonnes de E, si TRANSE = 'T' ou 'C', les
!>          vecteurs propres sont stockés dans les lignes de E.
!>

LDE

!>          LDE est INTEGER
!>          La dimension principale du tableau E.  LDE >= max(1,N).
!>

WR

!>          WR est un tableau REAL, dimension (N)
!>

WI

!>          WI est un tableau REAL, dimension (N)
!>
!>          Les parties réelle et imaginaire des valeurs propres de A.
!>          Les valeurs propres purement réelles sont indiquées par WI(j) = 0.
!>          Les paires conjuguées complexes sont indiquées par WR(j)=WR(j+1) et
!>          WI(j) = - WI(j+1) non nul ; la partie réelle est supposée être
!>          stockée dans la ligne/colonne j et la partie imaginaire dans
!>          la ligne/colonne (j+1).
!>

WORK

!>          WORK est un tableau REAL, dimension (N*(N+1))
!>

RESULT

!>          RESULT est un tableau REAL, dimension (2)
!>          RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>          RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                       j
!>
