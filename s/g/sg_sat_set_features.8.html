NOM

sg_sat_set_features - utilise la commande ATA SET FEATURES via une couche de traduction SCSI vers ATA (SAT)

SYNTAXE

sg_sat_set_features [--count=CO] [--ck_cond] [--extended] [--feature=FEA] [--help] [--lba=LBA] [--len={16|12}] [--readonly] [--verbose] [--version] PÉRIPH

DESCRIPTION

Cet utilitaire envoie une commande ATA SET FEATURES au PÉRIPH. Cette commande est utilisée pour modifier les paramètres des périphériques ATA non-paquet (c'est-à-dire les disques) et des périphériques paquet (par exemple les lecteurs cd/dvd). Plutôt que d'envoyer la commande SET FEATURES directement au périphérique, elle est envoyée via un transport SCSI supposé contenir une couche de traduction SCSI vers ATA (SAT). La SATL peut être dans un pilote de système d'exploitation, dans le firmware d'un contrôleur d'hôte, ou dans un boîtier externe.

La norme SAT (SAT ANSI INCITS 431-2007, projet précédent: sat-r09.pdf sur www.t10.org) définit deux commandes SCSI "ATA PASS-THROUGH": une utilisant un "cdb" de 16 octets et l'autre avec un cdb de 12 octets. Cet utilitaire utilise par défaut la variante cdb de 16 octets. SAT-2 est également une norme: SAT-2 ANSI INCITS 465-2010 et le projet précédent est sat2r09.pdf. Le projet SAT-3 a commencé et le projet le plus récent est sat3r05b.pdf.

Les fonctionnalités peuvent être lues en utilisant l'utilitaire sg_sat_identify, qui utilise soit la commande ATA IDENTIFY DEVICE (pour les périphériques non-paquet), soit la commande IDENTIFY PACKET DEVICE (pour les périphériques paquet).

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-c, --count=CO
le nombre CO est placé dans le champ "count" de la commande ATA SET FEATURES. Seuls certains sous-commandes (terme utilisé pour la valeur placée dans le champ "feature") nécessitent que le champ count soit défini. La valeur par défaut placée dans le champ "count" est 0.
-C, --ck_cond
définit le bit CK_COND dans le cdb ATA PASS-THROUGH SCSI. Le réglage par défaut est effacé (c'est-à-dire 0). Lorsqu'il est défini, la SATL doit renvoyer un tampon de sense contenant un descripteur de résultat ATA, que la commande ATA ait réussi ou échoué. Lorsqu'il est effacé, la SATL ne doit renvoyer un tampon de sense contenant un descripteur de résultat ATA que si la commande ATA a échoué.
-e, --extended
permet les numéros LBA étendus (c'est-à-dire supérieurs à 32 bits). Cette valeur est automatiquement activée pour les grands numéros LBA, mais peut également être activée explicitement même pour les petits numéros LBA avec cette option.
-f, --feature=FEA
la valeur FEA est placée dans le champ "feature" de la commande ATA SET FEATURES. Le terme "sous-commande" est parfois utilisé pour cette valeur. La valeur par défaut placée dans le champ "feature" est 0, qui est réservé et donc ne devrait rien changer. Deux exemples courants sont 2h pour activer le cache d'écriture et 82h pour le désactiver.
-h, --help
affiche le message d'utilisation résumant les options de ligne de commande, puis quitte. Ignore PÉRIPH s'il est donné.
-L, --lba=LBA
le nombre LBA est placé dans le champ "lba" de la commande ATA SET FEATURES. Seules certaines sous-commandes (terme utilisé pour la valeur placée dans le champ "feature") nécessitent que le champ lba soit défini. Cette valeur n'est généralement pas une "adresse de bloc logique" comme l'acronyme pourrait le suggérer. La valeur par défaut placée dans le champ "lba" est 0. La valeur maximale autorisée pour LBA est 0xfffffffe (ou 0xffffff si --len=12).
-l, --len={16|12}
c'est la longueur du cdb SCSI utilisé pour les commandes ATA PASS-THROUGH. L'argument peut être 16 ou 12. La valeur par défaut est 16. Certains transports SCSI ne peuvent pas transmettre de commandes SCSI de plus de 12 octets.
-r, --readonly
cause l'ouverture du PÉRIPH avec le drapeau lecture seule (O_RDONLY sous Unix). L'action par défaut est d'ouvrir le PÉRIPH avec le drapeau lecture-écriture (O_RDWR sous Unix). Dans certains cas, l'envoi de commandes de gestion d'alimentation à des disques ATA est annulé par les actions du système d'exploitation lors de la fermeture (close()) si le PÉRIPH a été ouvert avec le drapeau lecture-écriture (par exemple, le système d'exploitation pourrait penser qu'il a besoin de vider quelque chose sur le disque).
-v, --verbose
augmente le niveau de verbosité.
-V, --version
affiche la chaîne de version

NOTES

Dans la série 2.4 des noyaux Linux, le PÉRIPH doit être un périphérique générique SCSI (sg). Dans les séries 2.6 et 3, les périphériques bloc (par exemple, disques et DVD ATAPI) peuvent également être spécifiés. Par exemple, "sg_inq /dev/sda" fonctionnera dans les noyaux de la série 2.6. À partir de lk 2.6.6, d'autres noms de périphériques "char" SCSI peuvent également être utilisés (par exemple, "/dev/st0m"). Avant lk 2.6.29, le stockage de masse USB limitait les données de sense à 18 octets, ce qui faisait que l'option --ck_cond produisait des résultats étranges (tronqués).

STATUT DE SORTIE

Le statut de sortie de sg_sat_set_features est 0 en cas de succès. Sinon, voir la page de manuel sg3_utils(8).
