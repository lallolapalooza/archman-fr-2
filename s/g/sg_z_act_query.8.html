NOM

sg_z_act_query - envoie une commande SCSI ZONE ACTIVATE ou ZONE QUERY

SYNTAXE

sg_z_act_query [--activate] [--all] [--force] [--help] [--hex] [--inhex=FN] [--maxlen=LEN] [--num=ZS] [--other=ZDID] [--query] [--raw] [--verbose] [--version] [--zone=ID] PÉRIPHÉRIQUE

DESCRIPTION

Envoie une commande SCSI ZONE ACTIVATE ou ZONE QUERY au PÉRIPHÉRIQUE. Si l'option --activate n'est pas donnée, alors une commande ZONE QUERY est envoyée. Ces commandes ont été ajoutées dans la révision 4 du brouillon ZBC-2 (zbc2r04.pdf).

Ces deux commandes ont des CDB et des réponses similaires, c'est pourquoi elles sont toutes les deux placées dans cet utilitaire. La différence est que seule la commande ZONE ACTIVATE peut activer ou désactiver des zones. Les deux commandes effectueront une "opération de vérification des activations" telle que définie dans ZBC-2.

OPTIONS

Les arguments des options longues sont obligatoires pour les options courtes également.

-A, --activate
envoie une commande ZONE ACTIVATE au PÉRIPHÉRIQUE. Par défaut (c'est-à-dire sans cette option), une commande ZONE QUERY est envoyée.
-a, --all
définit le champ ALL dans le CDB.
-f, --force
lors du décodage de la réponse à cette commande, certaines vérifications de cohérence sont effectuées et, si elles échouent, un message est envoyé sur stderr et un statut de sortie non nul est défini. Si cette option est donnée, ces vérifications de cohérence sont ignorées.
-h, --help
affiche le message d'utilisation puis quitte.
-H, --hex
affiche la réponse en hexadécimal sur la sortie standard. Utilisée une fois, toute la réponse est affichée en hexadécimal ASCII avec une adresse de début (commençant à 0) sur chaque ligne. Utilisée deux fois, chaque descripteur d'activation de zone dans la réponse est affiché séparément en hexadécimal. Utilisée trois fois, toute la réponse est affichée en hexadécimal sans adresse de début (sur chaque ligne).
Le format de sortie lorsque cette option est donnée trois fois est adapté pour une invocation ultérieure avec l'option --inhex=FN.
-i, --inhex=FN
où FN est un nom de fichier dont le contenu est supposé être en hexadécimal ASCII. Si PÉRIPHÉRIQUE est également donné, alors PÉRIPHÉRIQUE est ignoré, un avertissement est émis et l'utilitaire continue en décodant le fichier nommé FN. Voir la section "FORMATS HEXADÉCIMAL, BINAIRE ET JSON" dans la page de manuel de sg3_utils pour plus d'informations. Si l'option --raw est également donnée, alors le contenu de FN est traité comme binaire.
Par défaut, on suppose que la réponse provient d'une commande ZONE QUERY, mais cela ne devrait pas avoir d'importance car la réponse des commandes ZONE ACTIVATE et ZONE QUERY a la même forme.
-m, --maxlen=LEN
où LEN est la longueur maximale de la réponse en octets. Elle est placée dans le champ "longueur d'allocation" du CDB. Si elle n'est pas donnée (ou si LEN est zéro), 8192 est utilisé. La valeur maximale autorisée de LEN est 1048576.
La norme préliminaire interdit les longueurs d'allocation inférieures à 64.
-n, --num=ZS
où ZS est placé dans le champ "Nombre de zones" du CDB. Cette option est généralement ignorée si l'option --all est donnée. Si l'option --all n'est pas donnée, la valeur par défaut de ce champ est 1.
-o, --other=ZDID
où la valeur ZDID sera placée dans le champ "ID de domaine de zone autre" du CDB à envoyer au PÉRIPHÉRIQUE.
-q, --query
provoque l'envoi de la commande ZONE QUERY au PÉRIPHÉRIQUE. Comme il s'agit de l'action par défaut, cette option n'est généralement pas nécessaire. Si cette option et l'option --activate sont données, une erreur sera signalée (et aucune commande ne sera envoyée).
-r, --raw
affiche la réponse en binaire (sur la sortie standard) sauf si l'option --inhex=FN est également donnée. Dans ce cas, le nom du fichier d'entrée (FN) est décodé en binaire (et la sortie n'est pas en binaire (mais peut être en hexadécimal)).
-v, --verbose
augmente le niveau de verbosité (c'est-à-dire les messages de débogage).
-V, --version
affiche la chaîne de version puis quitte.
-z, --zone=ID
où ID est placé dans le champ ZONE ID du CDB. Un ID de zone est une adresse logique de bloc (LBA) de début de zone. La valeur par défaut est 0. ID est supposé être en décimal, sauf s'il est précédé de '0x' ou a un 'h' final qui indique l'hexadécimal. La valeur maximale qui peut être donnée est 2^64 - 2. Dans le cas improbable où vous voudriez donner 2^64 - 1, entrez "-1".

STATUT DE SORTIE

Le statut de sortie de sg_z_act_query est 0 en cas de succès. Sinon, voir la page de manuel de sg3_utils(8).
