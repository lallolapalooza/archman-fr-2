sous-routine sgtsvx (character fact, character trans, integer n, integer nrhs, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du, real, dimension( * ) dlf, real, dimension( * ) df, real, dimension( * ) duf, real, dimension( * ) du2, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices GT

Objectif:

!>
!> SGTSVX utilise la factorisation LU pour calculer la solution d'un système
!> linéaire réel A * X = B ou A**T * X = B, où A est une matrice tridiagonale
!> d'ordre N et X et B sont des matrices de taille N par NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont
!> également fournies.
!>

Description:

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la décomposition LU est utilisée pour factoriser la
!>    matrice A sous la forme A = L * U, où L est un produit de matrices
!>    de permutation et de matrices bidiagonales inférieures unitaires, et
!>    U est triangulaire supérieure avec des éléments non nuls uniquement
!>    sur la diagonale principale et les deux premières superdiagonales.
!>
!> 2. Si un U(i,i) = 0, rendant U singulière, la routine renvoie avec INFO = i.
!>    Sinon, la forme factorisée de A est utilisée pour estimer le nombre de
!>    conditionnement de la matrice A. Si l'inverse du nombre de
!>    conditionnement est inférieur à la précision machine, INFO = N+1 est
!>    renvoyé comme avertissement, mais la routine continue à résoudre pour
!>    X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 4. Le raffinement itératif est appliqué pour améliorer la solution
!>    calculée et obtenir des bornes d'erreur et des estimations d'erreur
!>    arrières pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de A a été fournie ou non à
!>          l'entrée.
!>          = 'F' : DLF, DF, DUF, DU2 et IPIV contiennent la forme
!>                  factorisée de A ; DL, D, DU, DLF, DF, DUF, DU2 et IPIV
!>                  ne seront pas modifiés.
!>          = 'N' : La matrice sera copiée dans DLF, DF, et DUF et factorisée.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' : A * X = B     (Pas de transposée)
!>          = 'T' : A**T * X = B  (Transposée)
!>          = 'C' : A**H * X = B  (Conjuguée transposée = Transposée)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

DL

!>          DL est un tableau de type REAL, de dimension (N-1)
!>          Les éléments sous-diagonaux (de longueur N-1) de A.
!>

D

!>          D est un tableau de type REAL, de dimension (N)
!>          Les éléments diagonaux (de longueur N) de A.
!>

DU

!>          DU est un tableau de type REAL, de dimension (N-1)
!>          Les éléments superdiagonaux (de longueur N-1) de A.
!>

DLF

!>          DLF est un tableau de type REAL, de dimension (N-1)
!>          Si FACT = 'F', alors DLF est un argument d'entrée et contient à
!>          l'entrée les multiplicateurs (de longueur N-1) qui définissent la
!>          matrice L de la factorisation LU de A telle que calculée par SGTTRF.
!>
!>          Si FACT = 'N', alors DLF est un argument de sortie et contient à
!>          la sortie les multiplicateurs (de longueur N-1) qui définissent la
!>          matrice L de la factorisation LU de A.
!>

DF

!>          DF est un tableau de type REAL, de dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient à
!>          l'entrée les éléments diagonaux (de longueur N) de la matrice
!>          triangulaire supérieure U de la factorisation LU de A.
!>
!>          Si FACT = 'N', alors DF est un argument de sortie et contient à
!>          la sortie les éléments diagonaux (de longueur N) de la matrice
!>          triangulaire supérieure U de la factorisation LU de A.
!>

DUF

!>          DUF est un tableau de type REAL, de dimension (N-1)
!>          Si FACT = 'F', alors DUF est un argument d'entrée et contient à
!>          l'entrée les éléments (de longueur N-1) de la première
!>          superdiagonale de U.
!>
!>          Si FACT = 'N', alors DUF est un argument de sortie et contient à
!>          la sortie les éléments (de longueur N-1) de la première
!>          superdiagonale de U.
!>

DU2

!>          DU2 est un tableau de type REAL, de dimension (N-2)
!>          Si FACT = 'F', alors DU2 est un argument d'entrée et contient à
!>          l'entrée les éléments (de longueur N-2) de la deuxième
!>          superdiagonale de U.
!>
!>          Si FACT = 'N', alors DU2 est un argument de sortie et contient à
!>          la sortie les éléments (de longueur N-2) de la deuxième
!>          superdiagonale de U.
!>

IPIV

!>          IPIV est un tableau de type INTEGER, de dimension (N)
!>          Si FACT = 'F', alors IPIV est un argument d'entrée et contient les
!>          indices de pivot de la factorisation LU de A calculée par SGTTRF.
!>
!>          Si FACT = 'N', alors IPIV est un argument de sortie et contient les
!>          indices de pivot de la factorisation LU de A ; la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i). IPIV(i) sera toujours
!>          égal à i ou i+1 ; IPIV(i) = i indique qu'un échange de ligne
!>          n'était pas requis.
!>

B

!>          B est un tableau de type REAL, de dimension (LDB,NRHS)
!>          La matrice B de membres de droite de taille N par NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau de type REAL, de dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille N par NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          L'estimation de l'inverse du nombre de conditionnement de la matrice
!>          A. Si RCOND est inférieur à la précision machine (en particulier,
!>          si RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau de type REAL, de dimension (NRHS)
!>          Les bornes d'erreur avant estimées pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la solution vraie correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que celle pour RCOND,
!>          et est presque toujours une légère surestimation de la vraie

NAME

sgtsvx - sequential (non-blocked) solution routine for the condition-on-the-fly.

SYNOPSIS

 CALL SGTSVX(FACT, TRANS, N, NRHS, DL, D, DU, DLUS, DS, DUS, B, LDB, X, LDX, RCOND, FERR, BERR, INFO)

Function/Subroutine Documentation

SGTSVX uses the after factorization routine SGTSLS to compute the solution to a set of linear equations.

Arguments

FACT
CHARACTER*1.
Specifies whether the factorization is already complete.
TRANS
CHARACTER*1.
Specifies the form of the system of equations.
N
INTEGER.
The order of the matrix A.
NRHS
INTEGER.
The number of right hand sides, i.e. the number of systems of equations to be solved.
DL
REAL array, dimension (N-1)
The N-1 elements of the lower diagonal of A.
D
REAL array, dimension (N)
The N elements of the main diagonal of A.
DU
REAL array, dimension (N-1)
The N-1 elements of the upper diagonal of A.
DLUS
REAL array, dimension (N-1)
DLUS is used to store the L-trapezoidal factors of A. DLUS(i) stores the multiples of the equations used to eliminate the below-diagonal elements.
DS
REAL array, dimension (N)
DS is used to store the U-trapezoidal factors of A. DS(i) stores the pivot elements.
DUS
REAL array, dimension (N-1)
DUS is used to store the U-trapezoidal factors of A. DUS(i) stores the multiples of the equations that result from the elimination.
B
REAL array, dimension (LDB, NRHS).
On entry, the N x NRHS matrix of right hand side vectors, X. On exit, B is overwritten by the solution vectors, X.
LDB
INTEGER.
The leading dimension of the array B. LDB >= max(N,NRHS).
X
REAL array, dimension (LDX, NRHS).
The N x NRHS matrix of solution vectors, X.
LDX
INTEGER.
The leading dimension of the array X. LDX >= N.
RCOND
REAL array, dimension (NRHS)
Estimate of the reciprocal condition number of the matrix A. RCOND is computed without recourse to looking at the accuracy of the reduced faulty. See Parkin, Shampine, and Allen (1985) for details.
FERR
REAL array, dimension (NRHS)
The estimated forward error bound for each approximate solution vector in the array X. If X is the computed solution and A is the exact coefficient matrix, then the componentwise relative forward error and its bound are defined as follows:

norm(X - X_true) / norm(X)
where norm means the infinity norm, and X_true is the exact solution. FERR(j) is an upper bound on the relative forward error of the j-th solution vector, i.e., FERR(j) >= norm(X(j) - X_true(j)) / norm(X(j)).

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>

WORK

!>          WORK is REAL array, dimension (3*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, and i is
!>                <= N:  U(i,i) is exactly zero.  The factorization
!>                       has not been completed unless i = N, but the
!>                       factor U is exactly singular, so the solution
!>                       and error bounds could not be computed.
!>                       RCOND = 0 is returned.
!>                = N+1: U is nonsingular, but RCOND is less than machine
!>                       precision, meaning that the matrix is singular
!>                       to working precision.  Nevertheless, the
!>                       solution and error bounds are computed because
!>                       there are a number of situations where the
!>                       computed solution can be more accurate than the
!>                       value of RCOND would suggest.
!>
