sous-routine sgeequ (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) r, real, dimension( * ) c, real rowcnd, real colcnd, real amax, integer info)

SGEEQU

But:

!>
!> SGEEQU calcule les facteurs d'échelle de lignes et de colonnes destinés à équilibrer une
!> matrice M par N, A, et à réduire son nombre de conditionnement. R renvoie les facteurs
!> d'échelle de ligne et C les facteurs d'échelle de colonne, choisis pour tenter de rendre
!> l'élément le plus grand de chaque ligne et colonne de la matrice B, avec
!> B(i,j)=R(i)*A(i,j)*C(j), ayant une valeur absolue de 1.
!>
!> R(i) et C(j) sont restreints à être compris entre SMLNUM = le plus petit nombre sûr
!> et BIGNUM = le plus grand nombre sûr. L'utilisation de ces facteurs d'échelle n'est pas garantie
!> de réduire le nombre de conditionnement de A, mais fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau réel (REAL), de dimension (LDA,N)
!>          La matrice M par N dont les facteurs d'équilibrage doivent être
!>          calculés.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

R

!>          R est un tableau réel (REAL), de dimension (M)
!>          Si INFO = 0 ou INFO > M, R contient les facteurs d'échelle de ligne
!>          pour A.
!>

C

!>          C est un tableau réel (REAL), de dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est un réel (REAL)
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport entre le plus
!>          petit R(i) et le plus grand R(i). Si ROWCND >= 0.1 et
!>          AMAX n'est ni trop grand ni trop petit, l'échelonnement par R
!>          n'est pas nécessaire.
!>

COLCND

!>          COLCND est un réel (REAL)
!>          Si INFO = 0, COLCND contient le rapport entre le plus petit
!>          C(i) et le plus grand C(i). Si COLCND >= 0.1, l'échelonnement par C
!>          n'est pas nécessaire.
!>

AMAX

!>          AMAX est un réel (REAL)
!>          Valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du débordement ou très proche de la sous-dépassement, la matrice
!>          doit être mise à l'échelle.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement nulle
!>                >  M : la (i-M)-ème colonne de A est exactement nulle
!>
