sous-programme sgesvd (caractère jobu, caractère jobvt, entier m, entier n, réel, dimension( lda, * ) a, entier lda, réel, dimension( * ) s, réel, dimension( ldu, * ) u, entier ldu, réel, dimension( ldvt, * ) vt, entier ldvt, réel, dimension( * ) work, entier lwork, entier info)

SGESVD calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

Objectif :

!>
!> SGESVD calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle
!> M par N, A, en calculant éventuellement les vecteurs singuliers gauches et/ou droits.
!> La SVD s'écrit :
!>
!>      A = U * SIGMA * transpose(V)
!>
!> où SIGMA est une matrice M par N, nulle sauf sur sa diagonale principale
!> pour min(m,n) éléments. U est une matrice orthogonale M par M et V est une
!> matrice orthogonale N par N. Les éléments diagonaux de SIGMA sont les
!> valeurs singulières de A ; elles sont réelles et non négatives, et sont
!> retournées dans l'ordre décroissant. Les min(m,n) premières colonnes de
!> U et V sont les vecteurs singuliers gauches et droits de A.
!>
!> Notez que la routine retourne V**T, pas V.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice U :
!>          = 'A':  toutes les M colonnes de U sont retournées dans le tableau U :
!>          = 'S':  les min(m,n) premières colonnes de U (les vecteurs singuliers
!>                  gauches) sont retournées dans le tableau U;
!>          = 'O':  les min(m,n) premières colonnes de U (les vecteurs singuliers
!>                  gauches) sont écrasées sur le tableau A;
!>          = 'N':  aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                  calculée.
!>

JOBVT

!>          JOBVT est CHARACTER*1
!>          Spécifie les options pour le calcul de tout ou partie de la matrice
!>          V**T :
!>          = 'A':  toutes les N lignes de V**T sont retournées dans le tableau VT;
!>          = 'S':  les min(m,n) premières lignes de V**T (les vecteurs singuliers
!>                  droits) sont retournées dans le tableau VT;
!>          = 'O':  les min(m,n) premières lignes de V**T (les vecteurs singuliers
!>                  droits) sont écrasées sur le tableau A;
!>          = 'N':  aucune ligne de V**T (aucun vecteur singulier droit) n'est
!>                  calculée.
!>
!>          JOBVT et JOBU ne peuvent pas être tous les deux 'O'.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.  N >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          En entrée, la matrice A de taille M par N.
!>          En sortie,
!>          si JOBU = 'O',  A est écrasée par les min(m,n) premières
!>                          colonnes de U (les vecteurs singuliers
!>                          gauches, stockés par colonnes);
!>          si JOBVT = 'O', A est écrasée par les min(m,n) premières
!>                          lignes de V**T (les vecteurs singuliers
!>                          droits, stockés par lignes);
!>          si JOBU .ne. 'O' et JOBVT .ne. 'O', le contenu de A
!>                          est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

S

!>          S est un tableau REAL, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de telle sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau REAL, dimension (LDU,UCOL)
!>          (LDU,M) si JOBU = 'A' ou (LDU,min(M,N)) si JOBU = 'S'.
!>          Si JOBU = 'A', U contient la matrice orthogonale U de taille M par M;
!>          Si JOBU = 'S', U contient les min(m,n) premières colonnes de
!>          U (les vecteurs singuliers gauches, stockés par colonnes);
!>          Si JOBU = 'N' ou 'O', U n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U.  LDU >= 1; si
!>          JOBU = 'S' ou 'A', LDU >= M.
!>

VT

!>          VT est un tableau REAL, dimension (LDVT,N)
!>          Si JOBVT = 'A', VT contient la matrice orthogonale N par N
!>          V**T;
!>          Si JOBVT = 'S', VT contient les min(m,n) premières lignes de
!>          V**T (les vecteurs singuliers droits, stockés par lignes);
!>          Si JOBVT = 'N' ou 'O', VT n'est pas référencé.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT.  LDVT >= 1; si
!>          JOBVT = 'A', LDVT >= N; si JOBVT = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK est un tableau REAL, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK;
!>          si INFO > 0, WORK(2:MIN(M,N)) contient les éléments non convergés
!>          de la surdiagonale d'une matrice B_bidiagonale, dont la diagonale
!>          est dans S (pas nécessairement triée). B satisfait A = U * B * VT,
!>          elle a donc les mêmes valeurs singulières que A, et des vecteurs
!>          singuliers liés par U et VT.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX(1,5*MIN(M,N)) pour les chemins (voir les commentaires dans le code) :
!>             - CHEMIN 1  (M beaucoup plus grand que N, JOBU='N')
!>             - CHEMIN 1t (N beaucoup plus grand que M, JOBVT='N')
!>          LWORK >= MAX(1,3*MIN(M,N)+MAX(M,N),5*MIN(M,N)) pour les autres chemins
!>          Pour une bonne performance, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  fin réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si SBDSQR n'a pas convergé, INFO spécifie combien de
!>                surdiagonales d'une forme bidiagonale intermédiaire B
!>                n'ont pas convergé vers zéro. Voir la description de WORK
!>                ci-dessus pour les détails.
!>

sgesvd - Décomposition en valeurs singulières de la matrice A de type real.

SYNTAXE

SUBROUTINE SGESVD(

CHARACTER JOBu, JOBv

REAL A(LDA,*)
REAL S(*)
REAL U(LDU,*)
REAL V(LDV,*)

Documentation des fonctions/sous-programmes

SGESVD calcule la décomposition en valeurs singulières (SVD) d'une matrice réelle M par N, A, de la forme :

A = U * S * VT

où S est une matrice diagonale de real positif ; les entrées diagonales de S sont les valeurs singulières de A, ordonnées par ordre décroissant.

U est une matrice orthogonale M par M.

V est une matrice orthogonale N par N.

Chaque colonne de U et V représente respectivement les vecteurs singuliers à gauche et à droite de A.

Arguments

JOBU (CHARACTER)
JOBU = 'A' : tous les M vecteurs singuliers à gauche de U sont calculés.
JOBU = 'S' : les M vecteurs singuliers à gauche de U sont calculés.
JOBU = 'O' : les min(M, N) premiers vecteurs singuliers à gauche de U sont calculés.
JOBU = 'N' : aucun vecteur singulier à gauche n'est calculé.
JOBV (CHARACTER)
JOBV = 'A' : tous les N vecteurs singuliers à droite de V sont calculés.
JOBV = 'S' : les min(M, N) premiers vecteurs singuliers à droite de V sont calculés.
JOBV = 'O' : les N vecteurs singuliers à droite de V sont calculés.
JOBV = 'N' : aucun vecteur singulier à droite n'est calculé.
M (INTEGER)
La dimension de la première dimension de A. M >= 0.
N (INTEGER)
La dimension de la deuxième dimension de A. N >= 0.
A (REAL, dimension (LDA, *))
Sur l'entrée, la matrice M par N à décomposer.
En sortie, A est écrasé par ses "facteurs généraux" pour la reconstruction de A.
LDA (INTEGER)
Le premier argument de dimensionnement de A. LDA >= max(1, M).
S (REAL, dimension (*))
Sur la sortie, le tableau de dimension min(M,N). Les valeurs singulières de A sont retournées dans les éléments S(1) à S(min(M,N)), par ordre décroissant.
U (REAL, dimension (LDU, *))
Sur la sortie, si JOBU != 'N', alors U contient les vecteurs singuliers à gauche.
Si JOBU = 'A' ou 'O', U est une matrice M par M.
Si JOBU = 'S', U est une matrice M par min(M, N).
LDU (INTEGER)
Le premier argument de dimensionnement de U. LDU >= max(1, M).
Si JOBU = 'S', LDU >= M.
V (REAL, dimension (LDV, *))
Sur la sortie, si JOBV != 'N', alors V contient les vecteurs singuliers à droite.
Si JOBV = 'A', V est une matrice N par N.
Si JOBV = 'S', V est une matrice min(M, N) par N.
LDV (INTEGER)
Le premier argument de dimensionnement de V. LDV >= max(1, N).
Si JOBV = 'S', LDV >= min(M, N).
WORK (REAL, dimension (*))
Tableau de travail. La dimension LWORK de WORK est :
Si LWORK = -1, alors WORK(1) contient la taille de mémoire requise.
LWORK (INTEGER)
La dimension du tableau de travail.
LWORK >= max(1, 3*min(M,N) + max(max(M,N), 5))
INFO (INTEGER)
INFO = 0 : succès.
INFO < 0 : si INFO = -i, le i-ième argument avait une valeur illégale.
INFO > 0 : le algorithme de convergence a échoué à converger, et la valeur d'INFO est la valeur du nombre d'itérations de la sous-routine de réduction de déflation.
