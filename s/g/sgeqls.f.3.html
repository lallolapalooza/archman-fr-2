sous-programme sgeqls (entier m, entier n, entier nrhs, reel, dimension( lda, * ) a, entier lda, reel, dimension( * ) tau, reel, dimension( ldb, * ) b, entier ldb, reel, dimension( lwork ) work, entier lwork, entier info)

SGEQLS

But :

!>
!> Résoudre le problème des moindres carrés
!>     min || A*X - B ||
!> en utilisant la factorisation QL
!>     A = Q*L
!> calculée par SGEQLF.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  M >= N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de colonnes de B.  NRHS >= 0.
!>

A

!>          A est un tableau REEL, de dimension (LDA,N)
!>          Détails de la factorisation QL de la matrice originale A tels
!>          qu'ils sont retournés par SGEQLF.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= M.
!>

TAU

!>          TAU est un tableau REEL, de dimension (N)
!>          Détails de la matrice orthogonale Q.
!>

B

!>          B est un tableau REEL, de dimension (LDB,NRHS)
!>          En entrée, la matrice B du membre de droite de dimension m x nrhs.
!>          En sortie, la matrice solution X de dimension n x nrhs, stockée dans
!>          les lignes m-n+1:m.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= M.
!>

WORK

!>          WORK est un tableau REEL, de dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur du tableau WORK.  LWORK doit être au moins NRHS,
!>          et devrait être au moins NRHS*NB, où NB est la taille du bloc
!>          pour cet environnement.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
