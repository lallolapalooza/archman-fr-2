SGERFSX

But:

!>
!>    SGERFSX améliore la solution calculée d'un système d'équations linéaires
!>    et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur normwise, le code
!>    fournit une borne d'erreur composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires original peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED, R
!>    et C ci-dessous. Dans ce cas, la solution et les bornes d'erreur retournées
!>    sont pour le système original non équilibré.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent la manière dont le raffinement est effectué, mais
!>     souvent les valeurs par défaut sont acceptables. Si les valeurs par défaut
!>     sont acceptables, les utilisateurs peuvent passer NPARAMS = 0, ce qui empêche
!>     le code source d'accéder à l'argument PARAMS.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N':  A * X = B     (Pas de transposée)
!>       = 'T':  A**T * X = B  (Transposée)
!>       = 'C':  A**H * X = B  (Transposée conjuguée = Transposée)
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     correctement la solution et les bornes d'erreur.
!>       = 'N':  Pas d'équilibration
!>       = 'R':  Équilibration des lignes, c'est-à-dire que A a été pré-multiplié par
!>               diag(R).
!>       = 'C':  Équilibration des colonnes, c'est-à-dire que A a été post-multiplié
!>               par diag(C).
!>       = 'B':  Équilibration des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(R) * A * diag(C).
!>               Le membre de droite B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>     La matrice originale A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau REAL, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation A = P*L*U
!>     tels que calculés par SGETRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>     Les indices de pivot de SGETRF ; pour 1<=i<=N, la ligne i de la
!>     matrice a été échangée avec la ligne IPIV(i).
!>

R

!>          R est un tableau REAL, dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'R' ou 'B', A est
!>     multiplié à gauche par diag(R) ; si EQUED = 'N' ou 'C', R
!>     n'est pas accédé.
!>     Si R est accédé, chaque élément de R doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle
!>     par puissances du radix n'entraîne pas d'erreurs d'arrondi, sauf si le
!>     résultat sous-flotte ou sur-flotte. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

C

!>          C est un tableau REAL, dimension (N)
!>     Les facteurs d'échelle des colonnes de A. Si EQUED = 'C' ou 'B', A est
!>     multiplié à droite par diag(C) ; si EQUED = 'N' ou 'R', C
!>     n'est pas accédé.
!>     Si C est accédé, chaque élément de C doit être une puissance du radix
!>     pour assurer une solution et des estimations d'erreur fiables. La mise à l'échelle
!>     par puissances du radix n'entraîne pas d'erreurs d'arrondi, sauf si le
!>     résultat sous-flotte ou sur-flotte. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>     La matrice du membre de droite B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau REAL, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par SGETRS.
!>     À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>     Conditionnement inverse mis à l'échelle. C'est une estimation du
!>     conditionnement inverse de Skeel de la matrice A après
!>     équilibration (si effectuée). Si cela est inférieur à la précision de la machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être faible même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>     Erreur arrière relative composante par composante. C'est l'erreur
!>     relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque membre de droite
!>     et chaque type (normwise ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur
!>     relative normwise, qui est définie comme suit :
!>
!>     Erreur relative normwise dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'erreur.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque membre de droite, ce tableau contient des informations sur
!!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur
!>     relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)) / abs(X(j,i)))
!>
!>     Le tableau est indexé par le type d'erreur.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Nombre de paramètres optionnels dans PARAMS. Si NPARAMS = 0, alors
!>     les valeurs par défaut sont utilisées pour tous les paramètres optionnels.
!>

PARAMS

!>          PARAMS est un tableau REAL, dimension (NPARAMS)
!>     Tableau des paramètres optionnels. Les paramètres actuellement pris en charge
!>     sont les suivants :
!>
!>       PARAMS(1)  :  Facteur de seuil pour la détection d'une matrice presque
!>                    singulière, et pour le calcul de l'erreur arrière
!>                    composante par composante.  Voir ERRS, par exemple.
!>                    Si elle est nulle, la valeur par défaut est le seuil des
!>                    erreurs relatives du composant.
!>
!>       PARAMS(2)  :  Seuil pour la perturbation des entrées de la matrice
!>                    lors du calcul de l'erreur arrière composante par composante.
!>                    Si elle est nulle, la valeur par défaut est le seuil des
!>                    erreurs relatives du composant.
!>
!>       PARAMS(3)  :  Seuil pour l'estimation de l'erreur arrière normwise.
!>                    Si elle est nulle, la valeur par défaut est le seuil des
!>                    erreurs relatives du composant.
!>
!>       PARAMS(4)  :  Seuil pour l'estimation de l'erreur arrière composante par
!>                    composante.  Voir ERR_BNDS_COMP.
!>                    Si elle est nulle, la valeur par défaut est le seuil des
!>                    erreurs relatives du composant.
!>
!>       PARAMS(5)  :  Seuil de raffinement de la solution.  Si la norme
!>                    maximale des résidus est inférieure à ce seuil, le
!>                    raffinement s'arrête.
!>                    Si elle est nulle, la valeur par défaut est le seuil des
!>                    erreurs relatives du composant.
!>
!>       PARAMS(6)  :  Permet de spécifier le type d'erreur arrière.
!>                    = 1.0 : Erreur arrière par composante (par défaut si
!>                            non spécifié).
!>                    = 2.0 : Erreur arrière normwise.
!>                    = 3.0 : Les deux erreurs arrière.
!>
!>
!>     Les autres paramètres sont réservés à des usages futurs.
!>

WORK

!>          WORK est un tableau REAL, dimension (N)
!>     Espace de travail utilisé par la routine.
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (N)
!>     Espace de travail utilisé par la routine.
!>

INFO

!>          INFO est INTEGER
!>     = 0:  Succès de l'exécution.
!>     < 0:  Si INFO = -i, alors le i-ème argument avait une valeur illégale.
!>           Si INFO = -12, alors les paramètres optionnels sont invalides.
!>     > 0:  La matrice est singulière (ou presque singulière). La valeur retournée
!>           est le nombre de pivots de zéro. Une estimation conditionnelle est
!>           retournée dans RCOND. Le raffinement peut ne pas être fiable.
!>

NAME

sgerfsx — computes the error bounds for the solution of a system of linear equations

SYNOPSIS

 SUBROUTINE SGERFSX(
  MATRIX_LAYOUT, TRANSPOSE, EQUILIBRATE, FACTORED,
  N, NRHS, A, LDA, AF, LDAF, IPIV,
  EQU, B, LDB, X, LDX, FERR, BERR,

  NPARAMS, PARAMS, WORK, IWORK, INFO
 )

Function/Subroutine Documentation

MATRIX_LAYOUT

!> Specifies the storage format of the matrices A and AF:
!>   = 0: ROW MAJOR
!>   = 1: COLUMN MAJOR

TRANSPOSE

!> Specifies the form of the system of equations:
!>   = .TRUE.:  Solve A^T X = B, or A^T X = B with A being factorized
!>   = .FALSE.: Solve A X = B, or A X = B with A being factorized

EQUILIBRATE

!> Specifies if matrix A or its factors AF has been equilibrated:
!>   = .TRUE.:  A has been scaled by diagonal matrices D and E so that
!>              1 / (sqrt(N) * slamch('Epsilon')) <= abs(D(i,i)*A(i,j)*E(j,j)) <=
!>              sqrt(N) * slamch('Epsilon')
!>              and norms of the factored matrix AF are approximately N.
!>   = .FALSE.: The equilibration information in EQU(1) and EQU(2) is not
!>              used.

FACTORED

!> Specifies if matrix AF is already factored:
!>   = .TRUE.:  AF contains the L and U factors of A.
!>   = .FALSE.: AF is to be computed by the routine.

N

!>           N is INTEGER
!>           The order of the matrix A. N >= 0.

NRHS

!>           NRHS is INTEGER
!>           The number of right-hand sides, i.e., the number of columns
!>           in the arrays B, X, FERR, and BERR. NRHS >= 0.

A

!>           A is REAL array, dimension (LDA, N)
!>           The original n x n coefficient matrix A.
!>           If FACTORED = .TRUE., A is not accessed.

LDA

!>           LDA is INTEGER
!>           The leading dimension of the array A.  LDA >= max(1, N).

AF

!>           AF is REAL array, dimension (LDAF, N)
!>           The factored form of the matrix A. AF contains the factored
!>           form of A. AF is the output of SGETRF or SGETRF.
!>           If FACTORED = .FALSE., AF is overwritten by the factored
!>           form of A.

LDAF

!>           LDAF is INTEGER
!>           The leading dimension of the array AF. LDAF >= max(1, N).

IPIV

!>           IPIV is INTEGER array, dimension (N)
!>           Details of the LU factorization of A, as returned by SGETRF.
!>           If FACTORED = .TRUE., IPIV is not accessed.

EQU

!>           EQU is REAL array, dimension (N)
!>           Details of scaling the matrix A if EQUILIBRATE = .TRUE.
!>           If EQUILIBRATE = .TRUE., EQU(i) is the i-th diagonal element
!>           of the (inverse of the) diagonal matrix D from the
!>           diagonal similarity transformation A = D*A*E.
!>           If EQUILIBRATE = .FALSE., EQU is not accessed.

B

!>           B is REAL array, dimension (LDB, NRHS)
!>           The right-hand side matrix of solutions to be computed.

LDB

!>           LDB is INTEGER
!>           The leading dimension of the array B. LDB >= max(1, N).

X

!>           X is REAL array, dimension (LDX, NRHS)
!>           The matrix of solutions computed by this routine.

LDX

!>           LDX is INTEGER
!>           The leading dimension of the array X. LDX >= max(1, N).

FERR

!>           FERR is REAL array, dimension (NRHS)
!>           FERR(j) is an estimate of the relative error in the j-th
!>           solution computed by this routine. If the j-th right-hand
!>           side is 0, then FERR(j) is set to 0.0.

BERR

!>           BERR is REAL array, dimension (NRHS)
!>           BERR(j) is an estimate of the backward error (in the relative
!>           sense) of the j-th solution computed by this routine. If the
!>           j-th right-hand side is 0, then BERR(j) is set to 0.0.

N_ERR_BNDS

!>           N_ERR_BNDS is INTEGER
!>           The number of error bounds to be computed.
!>           = 0: No error bounds are computed.
!>           = 1: Loopwise error bounds are computed and returned in FERR.
!>           = 2: Loopwise and componentwise error bounds are computed and
!>                returned in FERR and BERR.
!>           If N_ERR_BNDS < 0, the routine returns with INFO = -11.

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>                     norm(X - XTRUE, inf)
!>           -----------------------------------------
!>                    norm(X, inf)
!>
!>     The array is indexed by the right-hand side i (on which the
!>     normwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

NPARAMS

!>          NPARAMS is INTEGER
!>     Specifies the number of parameters set in PARAMS.  If <= 0, the
!>     PARAMS array is never referenced and default values are used.
!>

PARAMS

!>          PARAMS is REAL array, dimension NPARAMS
!>     Specifies algorithm parameters.  If an entry is < 0.0, then
!>     that entry will be filled with default value used for that
!>     parameter.  Only positions up to NPARAMS are accessed; defaults
!>     are used for higher-numbered parameters.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
!>            refinement or not.
!>         Default: 1.0
!>            = 0.0:  No refinement is performed, and no error bounds are
!>                    computed.
!>            = 1.0:  Use the double-precision refinement algorithm,
!>                    possibly with doubled-single computations if the
!>                    compilation environment does not support DOUBLE
!>                    PRECISION.
!>              (other values are reserved for future use)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
!>            computations allowed for refinement.
!>         Default: 10
!>         Aggressive: Set to 100 to permit convergence using approximate
!>                     factorizations or factorizations other than LU. If
!>                     the factorization uses a technique other than
!>                     Gaussian elimination, the guarantees in
!>                     err_bnds_norm and err_bnds_comp may no longer be
!>                     trustworthy.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
!>            will attempt to find a solution with small componentwise
!!>            relative error in the double-precision algorithm.  Positive
!>            is true, 0.0 is false.
!>         Default: 1.0 (attempt componentwise convergence)
!>

WORK

!>          WORK is REAL array, dimension (4*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit. The solution to every right-hand side is
!>         guaranteed.
!>       < 0:  If INFO = -i, the i-th argument had an illegal value
!>       > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
!>         has been completed, but the factor U is exactly singular, so
!>         the solution and error bounds could not be computed. RCOND = 0
!>         is returned.
!>       = N+J: The solution corresponding to the Jth right-hand side is
!>         not guaranteed. The solutions corresponding to other right-
!>         hand sides K with K > J may not be guaranteed as well, but
!>         only the first such right-hand side is reported. If a small
!>         componentwise error is not requested (PARAMS(3) = 0.0) then
