sous-programme sget38 (real, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

SGET38

Objectif :

!>
!> SGET38 teste STRSEN, une routine pour estimer les nombres de condition d'un
!> cluster de valeurs propres et/ou de son sous-espace invariant à droite associé
!>
!> Les matrices de test sont lues à partir d'un fichier avec l'unité logique NIN.
!>

Paramètres

RMAX 
!>          RMAX est un tableau REAL, de dimension (3)
!>          Valeurs des plus grands rapports de test.
!>          RMAX(1) = plus grands résidus de SHST01 ou comparaison entre
!>                    différents appels à STRSEN
!>          RMAX(2) = plus grande erreur dans le nombre de condition réciproque
!>                    en tenant compte de leur conditionnement
!>          RMAX(3) = plus grande erreur dans le nombre de condition réciproque
!>                    sans tenir compte de leur conditionnement (peut être plus grand que RMAX(2))
!>

LMAX

!>          LMAX est un tableau INTEGER, de dimension (3)
!>          LMAX(i) est le numéro d'exemple où le plus grand rapport de test
!>          RMAX(i) est atteint. Aussi :
!>          Si SGEHRD retourne INFO non nul à l'exemple i, LMAX(1)=i
!>          Si SHSEQR retourne INFO non nul à l'exemple i, LMAX(2)=i
!>          Si STRSEN retourne INFO non nul à l'exemple i, LMAX(3)=i
!>

NINFO

!>          NINFO est un tableau INTEGER, de dimension (3)
!>          NINFO(1) = Nombre de fois où SGEHRD a retourné INFO non nul
!>          NINFO(2) = Nombre de fois où SHSEQR a retourné INFO non nul
!>          NINFO(3) = Nombre de fois où STRSEN a retourné INFO non nul
!>

KNT

!>          KNT est un INTEGER
!>          Nombre total d'exemples testés.
!>

NIN

!>          NIN est un INTEGER
!>          Numéro d'unité logique d'entrée.
!>
