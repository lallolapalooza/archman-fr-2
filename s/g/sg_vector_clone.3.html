DESCRIPTION

sg_vector_create() alloue et initialise un nouveau vecteur statgrab avec initial_used éléments prêts à être utilisés. L'espace pour alloc_count éléments est initialement alloué (pour éviter trop d'appels à realloc() lors des appels ultérieurs à sg_vector_resize()). La valeur de block_size doit être une puissance de 2, elle est arrondie à la puissance de 2 supérieure si ce n'est pas le cas. Si alloc_count n'est pas un multiple de block_size, il est arrondi au multiple de block_size supérieur. Elle retourne un pointeur vers le vecteur nouvellement créé.

sg_vector_clear() détruit tous les éléments contenus dans le vecteur donné. Contrairement à sg_vector_resize( x, 0 ), la taille allouée du vecteur reste inchangée.

sg_vector_resize() augmente ou diminue la quantité d'éléments alloués dans le vecteur spécifié. La quantité d'éléments alloués est toujours un multiple du paramètre d'initialisation block_size. Dans le cas spécial où sg_vector_resize() est appelé avec 0 comme argument new_count, le vecteur est libéré après que tous les éléments du vecteur aient été détruits. Elle retourne le pointeur vers le vecteur redimensionné.

sg_vector_free() détruit tous les éléments du vecteur et désalloue le stockage appartenant au vecteur donné.

sg_vector_clone() clone tous les éléments du vecteur donné dans un nouveau vecteur créé avec la même spécification que celui référencé. Elle retourne un pointeur vers le vecteur cloné.

sg_vector_clone_into() clone tous les éléments du vecteur source donné dans le vecteur cible donné. Le vecteur cible doit être créé pour le même type de données d'élément que le vecteur source. Elle retourne un code d'erreur différent de SG_ERROR_NONE si quelque chose s'est mal passé.

sg_vector_compute_diff() calcule un vecteur de différence entre le vecteur contenant les statistiques actuelles et un autre vecteur contenant des statistiques plus anciennes. Si un élément existe dans le vecteur actuel mais pas dans l'autre, il est cloné dans le vecteur résultat. Si un élément existe uniquement dans le vecteur opposé, il n'apparaît pas dans le vecteur cible. sg_vector_compute_diff() retourne un code d'erreur différent de SG_ERROR_NONE si quelque chose s'est mal passé.

sg_prove_vector() prouve si un pointeur vers un vecteur pointe réellement vers un vecteur. Si le pointeur de vecteur donné pointe vers des données corrompues, le programme est interrompu. Lorsque sg_prove_vector() retourne, elle retourne SG_ERROR_NONE.

sg_get_nelements() retourne le nombre d'éléments que la zone de données donnée, englobée par un vecteur statgrab, contient. L'en-tête du vecteur est calculé en interne à partir du pointeur donné vers le premier élément du vecteur.

sg_free_stats_buf() libère le vecteur englobant la zone de données donnée.

NOTES

À l'exception de sg_get_nelements() et sg_free_stats_buf(), aucune des fonctions ci-dessus ne peut être appelée depuis l'extérieur des sources de libstatgrab. Les structures et API documentées peuvent changer sans préavis. La description de toutes les autres API est destinée à être lue uniquement par les développeurs de libstatgrab.

Chaque vecteur est créé à partir de deux éléments : les informations du vecteur et la liste des éléments :

template <class T, class Impl>
struct sg_vector {
        size_t used_count;
        size_t alloc_count;
        size_t block_shift;
        Impl vector_implementation;
        T elements[alloc_count];
};

Bien sûr, ce n'est pas du C valide, donc la solution a été d'être astucieux :

typedef struct sg_vector {
	size_t used_count;
	size_t alloc_count;
	size_t block_shift;
	struct sg_vector_init_info info;
} sg_vector;
struct sg_vector_size_helper {
	struct sg_vector v;
	long long ll;
};
#define VECTOR_SIZE offsetof(struct sg_vector_size_helper,ll)
/* Retourne le pointeur de données d'un vecteur */
#define VECTOR_DATA(vector) \
	(vector ? (void *)(((char *)vector)+VECTOR_SIZE) : NULL)
#define VECTOR_ADDR_ARITH(ptr) \
	(sg_vector *)(((char *)(ptr))-VECTOR_SIZE)
/* Retourne le vecteur pour des données */
#define VECTOR_ADDRESS(ptr) \
	((ptr) ? (SG_ERROR_NONE == sg_prove_vector(VECTOR_ADDR_ARITH(ptr)) ? VECTOR_ADDR_ARITH(ptr) : NULL ) : NULL)

Cela permet également aux fonctions utilisateur comme sg_get_nelements() et sg_free_stats_buf() de passer facilement entre la structure du vecteur et son contenu.

LA STRUCTURE DE SPÉCIALISATION DU VECTEUR

Comme mentionné, l'implémentation des vecteurs utilise des stratégies du concept de programmation orientée objet nommé « polymorphisme ». Un vecteur est décrit par un petit objet contenant des attributs inhérents tels que la taille de l'élément et un ensemble de « méthodes virtuelles » pour effectuer des tâches liées aux éléments, comme l'initialisation ou la destruction des éléments.

typedef void (*vector_init_function)(void *item);
typedef sg_error (*vector_copy_function)(const void *src, void *dst);
typedef sg_error (*vector_compute_diff_function)(void *dst, const void *src);
typedef int (*vector_compare_function)(const void *a, const void *b);
typedef void (*vector_destroy_function)(void *item);
struct sg_vector_init_info {
        size_t item_size;
        vector_init_function init_fn;
        vector_copy_function copy_fn;
        vector_compute_diff_function compute_diff_fn;
        vector_compare_function compare_fn;
        vector_destroy_function destroy_fn;
};

Les instances de struct sg_vector_init_info sont conceptuellement initialisées statiquement en utilisant soit la macro préprocesseur VECTOR_INIT_INFO_FULL_INIT(type) soit VECTOR_INIT_INFO_EMPTY_INIT(type). Voici quelques exemples pour démontrer comment cela est censé être fait :

Initialisation de la description du vecteur de statistiques CPU

VECTOR_INIT_INFO_EMPTY_INIT(sg_cpu_stats);

Initialisation de la description du vecteur de statistiques d'informations sur l'hôte

static void sg_os_stats_item_init(sg_os_stats *d);
static void sg_os_stats_item_destroy(sg_os_stats *d);
#define sg_os_stats_item_copy NULL
#define sg_os_stats_item_compute_diff NULL
#define sg_os_stats_item_compare NULL
VECTOR_INIT_INFO_FULL_INIT(sg_os_stats);

Initialisation de la description du vecteur de statistiques d'E/S disque

static void sg_disk_io_stats_item_init(sg_disk_io_stats *d);
static sg_error sg_disk_io_stats_item_copy(sg_disk_io_stats *d, const sg_disk_io_stats *s);
static sg_error sg_disk_io_stats_item_compute_diff(const sg_disk_io_stats *s, sg_disk_io_stats *d);
static int sg_disk_io_stats_item_compare(const sg_disk_io_stats *a, const sg_disk_io_stats *b);
static void sg_disk_io_stats_item_destroy(sg_disk_io_stats *d);
VECTOR_INIT_INFO_FULL_INIT(sg_disk_io_stats);

VECTOR_CREATE() appelle sg_vector_create() avec alloc_count = block_size et initial_used = 0 en utilisant le type de spécialisation de vecteur ##_vector_init_info.

VECTOR_CLEAR() appelle simplement sg_vector_clear(). Cette macro existe uniquement pour la conformité.

VECTOR_CREATE_OR_RESIZE() appelle sg_vector_create() lorsque le pointeur de vecteur donné pointe vers NULL ou sg_vector_resize() sinon. Le résultat de la fonction appropriée est retourné.

VECTOR_UPDATE() appelle VECTOR_CREATE_OR_RESIZE() et définit data sur le premier élément du vecteur résultant lorsqu'un pointeur non-NULL est obtenu, sinon à NULL. Lorsque VECTOR_CREATE_OR_RESIZE() renvoie un pointeur NULL et que new_count n'est pas égal à 0 (zéro), les instructions de la macro VECTOR_UPDATE_ERROR_CLEANUP sont exécutées pour nettoyer avant de retourner de la sous-routine actuelle avec l'erreur qui s'est produite.

VECTOR_ITEM_COUNT() renvoie 0 pour un vecteur inexistant (vector == 0) et le nombre d'éléments contenus sinon.

VALEURS DE RETOUR

Outre les codes d'erreur, les valeurs de retour, le cas échéant, sont toujours un pointeur vers des structures de vecteur (struct sg_vector *).
