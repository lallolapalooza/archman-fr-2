sous-programme sggbak (caractère job, caractère side, entier n, entier ilo, entier ihi, réel, dimension( * ) lscale, réel, dimension( * ) rscale, entier m, réel, dimension( ldv, * ) v, entier ldv, entier info)

SGGBAK

Objectif :

!>
!> SGGBAK forme les vecteurs propres droits ou gauches d'un problème aux valeurs
!> propres généralisé réel A*x = lambda*B*x, par transformation rétrograde sur
!> les vecteurs propres calculés de la paire équilibrée de matrices produite par
!> SGGBAL.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie le type de transformation rétrograde requise :
!>          = 'N' : ne rien faire, retourner immédiatement ;
!>          = 'P' : effectuer la transformation rétrograde pour la permutation seulement ;
!>          = 'S' : effectuer la transformation rétrograde pour la mise à l'échelle seulement ;
!>          = 'B' : effectuer les transformations rétrogrades pour la permutation et la
!>                 mise à l'échelle.
!>          JOB doit être le même que l'argument JOB fourni à SGGBAL.
!>

SIDE

!>          SIDE est CHARACTER*1
!>          = 'R' : V contient les vecteurs propres droits ;
!>          = 'L' : V contient les vecteurs propres gauches.
!>

N

!>          N est INTEGER
!>          Le nombre de lignes de la matrice V.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>          Les entiers ILO et IHI déterminés par SGGBAL.
!>          1 <= ILO <= IHI <= N, si N > 0 ; ILO=1 et IHI=0, si N=0.
!>

LSCALE

!>          LSCALE est un tableau REAL, dimension (N)
!>          Détails des permutations et/ou des facteurs d'échelle appliqués
!>          au côté gauche de A et B, tels que retournés par SGGBAL.
!>

RSCALE

!>          RSCALE est un tableau REAL, dimension (N)
!>          Détails des permutations et/ou des facteurs d'échelle appliqués
!>          au côté droit de A et B, tels que retournés par SGGBAL.
!>

M

!>          M est INTEGER
!>          Le nombre de colonnes de la matrice V.  M >= 0.
!>

V

!>          V est un tableau REAL, dimension (LDV,M)
!>          À l'entrée, la matrice des vecteurs propres droits ou gauches à transformer,
!>          telle que retournée par STGEVC.
!>          À la sortie, V est écrasé par les vecteurs propres transformés.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale de la matrice V. LDV >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
