Documentation de fonction/sous-programme

sous-programme sgelsx (entier m, entier n, entier nrhs, réel, dimension( lda, * ) a, entier lda, réel, dimension( ldb, * ) b, entier ldb, entier, dimension( * ) jpvt, réel rcond, entier rank, réel, dimension( * ) work, entier info)

SGELSX résout des systèmes surdéterminés ou sous-déterminés pour les matrices GE

Objectif :

!>
!> Cette routine est obsolète et a été remplacée par la routine SGELSY.
!>
!> SGELSX calcule la solution de norme minimale d'un problème de moindres carrés linéaires réels :
!>     minimiser || A * X - B ||
!> en utilisant une factorisation orthogonale complète de A. A est une matrice M par N
!> qui peut être de rang déficient.
!>
!> Plusieurs vecteurs second membre b et vecteurs solution x peuvent être
!> gérés en un seul appel ; ils sont stockés comme colonnes de la
!> matrice second membre B de dimension M par NRHS et de la matrice solution X de dimension N par NRHS.
!>
!> La routine calcule d'abord une factorisation QR avec pivotement de colonne :
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> avec R11 défini comme la plus grande sous-matrice principale dont le nombre de conditionnement estimé est inférieur à 1/RCOND. L'ordre de R11, RANK,
!> est le rang effectif de A.
!>
!> Ensuite, R22 est considéré comme négligeable, et R12 est annihilé
!> par des transformations orthogonales par la droite, aboutissant à la
!> factorisation orthogonale complète :
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solution de norme minimale est alors
!>    X = P * Z**T [ inv(T11)*Q1**T*B ]
!>                 [        0         ]
!> où Q1 est constitué des RANK premières colonnes de Q.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est tableau REEL, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimension M par N.
!>          À la sortie, A a été écrasée par les détails de sa
!>          factorisation orthogonale complète.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est tableau REEL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice second membre B de dimension M par NRHS.
!>          À la sortie, la matrice solution X de dimension N par NRHS.
!>          Si m >= n et RANK = n, la somme des carrés des résidus pour
!>          la solution dans la i-ème colonne est donnée par la somme des
!>          carrés des éléments N+1:M dans cette colonne.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT est tableau ENTIER, dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est une
!>          colonne initiale, sinon c'est une colonne libre. Avant
!>          la factorisation QR de A, toutes les colonnes initiales sont
!>          permutées vers les positions principales ; seules les colonnes
!>          libres restantes sont déplacées à la suite du pivotement de colonne
!>          pendant la factorisation.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

RCOND

!>          RCOND est REEL
!>          RCOND est utilisé pour déterminer le rang effectif de A, qui
!>          est défini comme l'ordre de la plus grande sous-matrice triangulaire
!>          principale R11 dans la factorisation QR avec pivotement de A,
!>          dont le nombre de conditionnement estimé est < 1/RCOND.
!>

RANK

!>          RANK est ENTIER
!>          Le rang effectif de A, c'est-à-dire l'ordre de la sous-matrice
!>          R11. C'est le même que l'ordre de la sous-matrice T11
!>          dans la factorisation orthogonale complète de A.
!>

WORK

!>          WORK est tableau REEL, dimension
!>                      (max( min(M,N)+3*N, 2*min(M,N)+NRHS )),
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
