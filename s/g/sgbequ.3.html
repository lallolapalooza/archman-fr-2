Documentation Fonction/Subroutine

subroutine sgbequ (integer m, integer n, integer kl, integer ku, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) r, real, dimension( * ) c, real rowcnd, real colcnd, real amax, integer info)

SGBEQU

But :

!>
!> SGBEQU calcule les échelles de lignes et de colonnes destinées à équilibrer
!> une matrice bande M-par-N A et à réduire son nombre de conditionnement. R renvoie les
!> facteurs d'échelle de ligne et C les facteurs d'échelle de colonne, choisis pour essayer
!> de faire en sorte que l'élément le plus grand de chaque ligne et colonne de la matrice B,
!> avec les éléments B(i,j)=R(i)*A(i,j)*C(j), ait une valeur absolue de 1.
!>
!> R(i) et C(j) sont limités à être entre SMLNUM = plus petit nombre sûr
!> et BIGNUM = plus grand nombre sûr. L'utilisation de ces facteurs d'échelle
!> n'est pas garantie de réduire le nombre de conditionnement de A, mais
!> fonctionne bien en pratique.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

KL

!>          KL est un ENTIER
!>          Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est un ENTIER
!>          Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

AB

!>          AB est un tableau REEL, dimension (LDAB,N)
!>          La matrice bande A, stockée dans les lignes 1 à KL+KU+1. La j-ème
!>          colonne de A est stockée dans la j-ème colonne du tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(m,j+kl).
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

R

!>          R est un tableau REEL, dimension (M)
!>          Si INFO = 0, ou INFO > M, R contient les facteurs d'échelle de ligne
!>          pour A.
!>

C

!>          C est un tableau REEL, dimension (N)
!>          Si INFO = 0, C contient les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est REEL
!>          Si INFO = 0 ou INFO > M, ROWCND contient le rapport du plus petit R(i)
!>          au plus grand R(i). Si ROWCND >= 0.1 et
!>          AMAX n'est ni trop grand ni trop petit, il n'est pas nécessaire
!>          d'effectuer une mise à l'échelle par R.
!>

COLCND

!>          COLCND est REEL
!>          Si INFO = 0, COLCND contient le rapport du plus petit
!>          C(i) au plus grand C(i). Si COLCND >= 0.1, il n'est pas
!>          nécessaire d'effectuer une mise à l'échelle par C.
!>

AMAX

!>          AMAX est REEL
!>          Valeur absolue de l'élément matriciel le plus grand. Si AMAX est très
!>          proche du débordement ou de la sous-estimation, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= M : la i-ème ligne de A est exactement zéro
!>                >  M : la (i-M)-ème colonne de A est exactement zéro
!>
